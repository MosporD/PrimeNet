MO Operations

MO operations are performed to add, remove, modify, and query MOs on an MML client or on the MAE-Deployment. These operations are described as follows:

  • ADD + MO name: is used to add an MO. Before executing this command, ensure that the mandatory parameters are specified.
  • RMV + MO name: is used to remove an MO.
  • MOD + MO name: is used to modify the MO attributes.
  • SET + MO name: is used to set the MO attributes.
  • LST + MO name: is used to list the static information about an MO.
  • DSP + MO name: is used to list the dynamic information about an MO.
NOTE:

For details about MO operations, see the description about the related MML commands to each MO in the MO Reference.
