MOM User Guide

MOM user guide describes managed object models (MOMs) and provides MO configuration methods.

  • Overview of MO Models
    MOMs comprise the user-oriented management view of system resources. Users can add, remove, or modify MOs to manage the eNodeB.
  • MO Attributes
    MO attributes, namely, the parameters of the MO. These attributes can be used to configure the MO.
