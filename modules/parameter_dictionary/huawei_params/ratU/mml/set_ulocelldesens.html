Set Desensitization Intensity (SET ULOCELLDESENS)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set the desensitization intensity of a specified cell.To match the uplink coverage capability with the downlink coverage capability, desensitization is applied to reduce the sensitivity of the receiver manually by adding proper noise to received signals.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • In a distributed cell or IMB cell, the execution of this command fails.
  • Desensitization is not supported by pico RRU, so when there are pico RRUs in local cell, desensitization setting is invalid to those pico RRUs. However, the MPMU of the LampSite product supports desensitization.
  • After this command is executed, the receiver sensitivity will be reduced. Use the command with discretion according to network planning and optimization.
  • After Micro Cell Dynamic Rx Sensitivity Control feature is activated, the desensitization value set by this command is replaced by the dynamic desensitization value.
  • If a cell is configured with a SECTOREQM MO whose ANTCFGMODE is set to BEAM, the desensitization setting is invalid to this cell.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
DI Desensitization Intensity

Meaning: Indicates the desensitization intensity, that is, the ratio of uplink noise intensity to background noise. If the desensitization intensity is set as 0, the desensitization is not applied.

GUI Value Range: 0~30

Unit: dB

Actual Value Range: 0~30

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • When BEAMCELLGROUPTYPE in the BEAMCELLGROUP MO is set to MASSIVEBEAM4T4R, MASSIVEBEAM8T8R, or COORDINATED2TBEAM, DI must be set to the same value in the ULOCELL MOs configured in the BEAMCELLGROUP MO. Otherwise, the actual desensitization value will be different from the configured one for one of the two cells.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the desensitization function is enabled and the background noise value is also modified on the RNC side, this parameter only affects the uplink coverage. If the value of this parameter is too large, the uplink coverage severely shrinks. If the value of this parameter is too small, the uplink coverage becomes larger than the downlink coverage. In either case, the base station has mismatching uplink and downlink coverage. If the desensitization function is enabled but the background noise value is not modified on the RNC side, this parameter affects the simulated uplink load. The larger the value of this parameter, the heavier the simulated uplink load.

Applicable Mode: U

Example

Set the desensitization intensity of local cell 14600 as 3 dB:
SET ULOCELLDESENS: ULOCELLID=14600, DI=3;
