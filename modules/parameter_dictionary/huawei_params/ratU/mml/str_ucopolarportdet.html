Start Antenna Port Co-Polarization Detection (STR UCOPOLARPORTDET)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start the antenna port co-polarization detection function for a cell. If the detection result is consistent with the co-polarization port mapping on the RF channels, the UMTS 4T Beam Optimization feature will deliver normal performance gains.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The command applies only to normal cells configured with four receive antennas (including single RF module scenarios or dual-RF module combination scenarios) and does not take effect for other types of cells.
  • UMTS UL Demodulation Mode must be set to 4-Channels Demodulation Mode or Self-adaption Demodulation Mode, and the uplink baseband equipment must contain at least one WBBPF or later boards.
  • When AUTORECFGSWITCH is set to ON, the COPOLARPORTMAPCFG parameter is automatically reconfigured based on the co-polarization detection results.
  • Automatic configuration of co-polarization grouping information may result in transient and abrupt cell coverage changes, causing call drops to some extent. Before running the command, you are advised to run the LST ULOCELLALGPARA command to query and save the co-polarization grouping information of each cell.
  • This command fails to be executed when the phase calibration capability detection has been started using the STR UPHASECALIBCHK command.
  • When the antenna port co-polarization detection is successful, phase calibration capability detection is enabled for the related 4T4R cell where the UMTS 4T Beam Optimization capability is available and two 2T RF modules are combined.

Parameters

ID Name Description
AUTORECFGSWITCH Automatic Reconfigure Switch

Meaning: Indicates whether the COPOLARPORTMAPCFG parameter is automatically reconfigured based on the antenna port co-polarization detection result. When this switch is turned off, antenna port co-polarization detection is performed without automatic reconfiguration of the COPOLARPORTMAPCFG parameter. When this switch is turned on, antenna port co-polarization detection is performed and the COPOLARPORTMAPCFG parameter is automatically reconfigured based on the detection result. This parameter takes effect only in scenarios with a single 4T RF module but not in scenarios with dual-RF module combination of 2T.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(ON)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: When this switch is turned off, the co-polarization port mapping configuration may be inconsistent with the actual co-polarization grouping, and consequently the UMTS 4T Beam Optimization feature cannot deliver normal performance gains. When this switch is turned on, the consistency between the co-polarization port mapping configuration and the actual co-polarization grouping is guaranteed, allowing the UMTS 4T Beam Optimization feature to deliver normal performance gains. However, automatic configuration of co-polarization grouping information may result in transient and abrupt cell coverage changes, causing call drops to some extent.

Applicable Mode: U
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Start antenna port co-polarization detection of No.12300 local cell:
STR UCOPOLARPORTDET: AUTORECFGSWITCH=ON, ULOCELLID=12300;

2.Start antenna port co-polarization detection for all local cells:
STR UCOPOLARPORTDET: AUTORECFGSWITCH=ON;
