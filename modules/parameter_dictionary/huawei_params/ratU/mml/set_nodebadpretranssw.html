Set HSUPA Adaptive Retransmission Control Switch (SET NODEBADPRETRANSSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set the HSUPA adaptive retransmission control switch.

Note

None

Parameters

ID Name Description
ADPRETRANSSW HSUPA AdaRetransSwitch

Meaning: Indicates the HSUPA Adaptive Retransmission Control Switch. The function will be enabled if this parameter is set to OPEN. The function will be disabled if this parameter is set to CLOSE. If this parameter is set to OPEN and there are adequate channel elements (CEs), this improves uplink HSUPA capacity and uplink HSUPA coverage.

GUI Value Range: OPEN(Open), CLOSE(Close)

Unit: None

Actual Value Range: OPEN, CLOSE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to OPEN and there are sufficient channel elements (CEs), large retransmission can be implemented to yield retransmission and HARQ combining gains. This improves uplink HSUPA capacity and uplink HSUPA coverage.

Applicable Mode: U

Example

Execute this command to set the HSUPA adaptive retransmission control switch:
SET NODEBADPRETRANSSW: ADPRETRANSSW=OPEN;
