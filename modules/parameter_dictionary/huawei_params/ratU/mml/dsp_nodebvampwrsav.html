Display Effective Status of VAM Power Saving (DSP NODEBVAMPWRSAV)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query whether the VAM Power Saving feature takes effect.

Note

None

Parameters

None.

Example

Display effective status of VAM power saving:
DSP NODEBVAMPWRSAV:;
The result is shown as follows:
+++    R16SIG21        2016-04-17 15:11:33
O&M    #537919571
%%DSP NODEBVAMPWRSAV:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RRU or RFU is located.

Subrack No.

Indicates the number of the subrack where the RRU or RFU is located.

Slot No.

Indicates the slot number of the RRU or RFU.

VAM Power Saving State

Indicates whether the VAM Power Saving feature is enabled. Enable indicates that the feature is enabled. Disable indicates that the feature is disabled.

VAM Power Saving Time

Indicates the effective duration of the VAM Power Saving feature from the time specified by the latest setting of the VAM Power Saving Start Time parameter to the current time.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05, indicating that the effective duration of the VAM Power Saving feature is 10 hours 20 minutes and 5 seconds.
