Display NodeB ULCoMP Group Status (DSP NODEBULCOMPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of the coordination relationship for the Uplink CoMP (Joint Reception) based on Coordinated BBU feature and the Coverage Expansion Under Interference feature.

Note

In some networking scenarios, the new ULCoMP group takes effect one minute after it is delivered. Running this command can query whether a new ULCoMP group takes effect.

Output Description

Field Description

Host Local Cell ID

Indicates the ID of the host cell where Uplink CoMP (Joint Reception) based on Coordinated BBU is enabled.

Neighbour Local Cell ID

Indicates the ID of the neighboring cell where Uplink CoMP (Joint Reception) based on Coordinated BBU is enabled.

Neighbour NodeB ID

Indicates the ID of the NodeB serving the neighboring cell where Uplink CoMP (Joint Reception) based on Coordinated BBU is enabled.

ULCoMP Status

Indicates the status of Uplink CoMP (Joint Reception) based on Coordinated BBU.Value range:ULCoMP Available, ULCoMP Unavailable-Local Cell Disabled, ULCoMP Unavailable-UL Baseband Resource Limited, ULCoMP Unavailable-DL Baseband Resource Limited, ULCoMP Unavailable-License Limited, ULCoMP Unavailable-Neighboring Cell Not Supported, ULCoMP Not Configured.

Coverage Expansion Status

Indicates the status of Coverage Expansion Under Interference. Value range:ULCOVEXP Available, ULCOVEXP Unavailable, ULCOVEXP Not Configured.
