Set Disable Cell Transmitter Timer (SET NODEBCLSPATIMER)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

In the case of a transmission fault or RNC upgrade, the transmitter will be disabled after the transmission on the NodeB is interrupted, and UEs are relocated to other systems such as a GSM network. This mechanism avoids that the NodeB fails to serve the UEs camping on the UMTS cell. If the transmitter of a NodeB with heavy traffic load is disabled immediately when the transmission is interrupted, a large number of handovers happen simultaneously, leading to congestion.

This command is used to set a time range during which transmitters in cells are shut down in the event of a transmission interruption. Specifically, once detecting a transmission interruption, the NodeB selects a random value from the specified time range and shuts down the transmitters after the random-value period elapses. In this case, transmitters in different cells are shut down at different time and handovers are initiated randomly. From the statistical perspective, UEs are evenly handed over to other systems, which avoids congestion.

Note

None

Parameters

ID Name Description
LOWERLIMIT Minimum Timer Value

Meaning: Indicates the minimum value of the timer for shutting down a transmitter in a cell.

GUI Value Range: 0~255

Unit: min

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBCLSPATIMER MO, the value of LOWERLIMIT must be smaller than or equal to UPPERLIMIT.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
UPPERLIMIT Maximum Timer Value

Meaning: Indicates the maximum value of the timer for shutting down a transmitter in a cell.

GUI Value Range: 0~255

Unit: min

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBCLSPATIMER MO, the value of LOWERLIMIT must be smaller than or equal to UPPERLIMIT.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Run the following command to set a time range during which transmitters in cells are shut down in the event of a transmission interruption:
SET NODEBCLSPATIMER: LOWERLIMIT=5, UPPERLIMIT=10;
