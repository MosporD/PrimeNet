Modify NodeB Baseband Equipment Parameters (MOD NODEBBASEBANDEQMPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify NodeB baseband equipment parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When the parameter ULBASEBANDEQMWORKMODE is set to AIR, running this command will interrupt ongoing services for less than 1 minute and decrease the maximum number of allowed for cells configured on the baseband equipment.

Parameters

ID Name Description
BASEBANDEQMID Baseband Equipment ID

Meaning: Indicates the ID of the baseband equipment.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ULBASEBANDEQMWORKMODE Uplink Baseband Equipment Work Mode

Meaning: Indicates the working mode of the uplink baseband equipment.

GUI Value Range: NORMAL(Normal), AIR(Adaptive Interference Rejection)

Unit: None

Actual Value Range: NORMAL, AIR

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to AIR and the Adaptive Interference Rejection parameter is set to TRUE for a cell, uplink coverage in cells configured on the baseband equipment improves in the event of strong wideband interference. Changes in the parameter value will lead to call drops.

Applicable Mode: U

Example

To modify the configuration of the NodeB baseband equipment parameters with the parameters as follows: Baseband Equipment ID: 0, Uplink Baseband Equipment Work Mode: AIR, run the following command: 
MOD NODEBBASEBANDEQMPARA: BASEBANDEQMID=0, ULBASEBANDEQMWORKMODE=AIR;
