List Beam Cell Group Item (LST BEAMCELLGROUPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list the configurations of beam cell group item.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the ID of beam cell group.

ULOCELLID Local Cell ID

Meaning: Indicates the ID of local cell in a beam cell group.

GUI Value Range: 0~268435455

1. To list the configurations of all beam cell group items, run the following command: 
LST BEAMCELLGROUPITEM:;
The result is shown as follows:

Output Description

Field Description

Beam Cell Group ID

Indicates the ID of beam cell group.

Local Cell ID

Indicates the ID of local cell in a beam cell group.

Beam Azimuth

Indicates the beam azimuth of a local cell in a beam cell group. When this parameter is set to LEFT(left), the cell coverage direction is relatively left to the beam azimuth of the antennas, and the cell can only select the four predefined left beams in Massive Beam 8T8R scenarios and use the left beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to RIGHT(Right), the cell coverage direction is relatively right to the beam azimuth of the antennas, and the cell can only select the four predefined right beams in Massive Beam 8T8R scenarios and use the right beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to NONE(None), the cell coverage direction is unrestricted, this setting is allowed only when BEAMCELLGROUPTYPE is set to NORMALBEAM or FOURTXSPLITSECTOR.

Beam Option Mode

Indicates the beam selection mode of a local cell in a beam cell group.
