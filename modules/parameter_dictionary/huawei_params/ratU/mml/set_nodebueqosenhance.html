Set Ue Qosenhance Para (SET NODEBUEQOSENHANCE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set parameters for the Improvement of User Experience in Low Traffic Service feature and the enhancement of the feature. This command can be used to set the burst packet size of UEs with different priorities, that is, the low-traffic data identification threshold. The UE priorities are gold, silver, and copper. For a UE with a certain priority, if the total data traffic is less than the set value within a statistic period, the resources assignment (scheduling and flow control) mechanism transmits the low-traffic data preferentially to optimize the delay.

Note

None

LOWTRAFFENHUSERNUMTHD UPA User Number Threshold for Enhanced Low Traffic

Meaning: Indicates the UPA UE quantity threshold for the low-traffic experience enhancement function to take effect. When the number of UPA UEs in a cell is less than or equal to the threshold, the low-traffic experience enhancement function takes effect. When the number of UPA UEs in a cell is greater than the threshold or the threshold is set to 0, the low-traffic experience enhancement function does not take effect.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, the low-traffic experience enhancement function is more likely to take effect, but more RTWP peaks occur in the cell. This increases the service drop rate and decreases the access success rate. If this parameter is set to a small value, the low-traffic experience enhancement function is less likely to take effect, and the impact on RTWP peaks is small.

Applicable Mode: U
TBSIZEFOR10MSLOWTRAFFENH Max UPA 10ms TTI TB Size for Enhanced Low Traffic

Meaning: Indicates the maximum TB size for scheduling grant of UPA 10 ms TTI UEs when the low-traffic experience enhancement function takes effect.

GUI Value Range: 0~19950

Unit: bit

Actual Value Range: 0~19950

MML Default Value: None

Recommended Value: 19860

Parameter Relationship:

-Others:

  • If LOWTRAFFENHUSERNUMTHD is set to 0, TBSIZEFOR10MSLOWTRAFFENH is invalid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a shorter delay in transmitting burst data and more significant increase in the average UPA rate. However, more RTWP peaks occur in the cell, increasing the service drop rate and decreasing the access success rate. A smaller value of this parameter indicates a longer delay in transmitting burst data, less significant increase in the average UPA rate, and less impact on RTWP peaks.

Applicable Mode: U

Example

Execute this command to set the burst packet size of the UE, that is, the small-traffic data threshold:
SET NODEBUEQOSENHANCE: ULGOLDUEBPS=10, ULSILVERUEBPS=11, ULCOPPERUEBPS=12, DLGOLDUEBPS=13, DLSILVERUEBPS=14, DLCOPPERUEBPS=15;
