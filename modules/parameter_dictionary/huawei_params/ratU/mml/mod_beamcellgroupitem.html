Modify Beam Cell Group Item (MOD BEAMCELLGROUPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify the configurations of beam cell group item.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Executing this command will change the cell coverage.

Parameters

ID Name Description
BEAMCELLGROUPID Beam Cell Group ID

Meaning: Indicates the ID of beam cell group.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ULOCELLID Local Cell ID

Meaning: Indicates the ID of local cell in a beam cell group.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BEAMAZIMUTH Beam Azimuth

Meaning: Indicates the beam azimuth of a local cell in a beam cell group. When this parameter is set to LEFT(left), the cell coverage direction is relatively left to the beam azimuth of the antennas, and the cell can only select the four predefined left beams in Massive Beam 8T8R scenarios and use the left beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to RIGHT(Right), the cell coverage direction is relatively right to the beam azimuth of the antennas, and the cell can only select the four predefined right beams in Massive Beam 8T8R scenarios and use the right beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to NONE(None), the cell coverage direction is unrestricted, this setting is allowed only when BEAMCELLGROUPTYPE is set to NORMALBEAM or FOURTXSPLITSECTOR.

GUI Value Range: LEFT(Left), RIGHT(Right), NONE(None)

Unit: None

Actual Value Range: LEFT, RIGHT, NONE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of this parameter must be consistent with the network planning. Any inconsistency will negatively affect the cell coverage area and scrambling code setting, leading to user access failures, increasing the call drop rate, decreasing the handover success rate, and increasing inter-cell interference.

Applicable Mode: U
BEAMOPTIONMODE Beam Option Mode

Meaning: Indicates the beam selection mode of a local cell in a beam cell group.

GUI Value Range: AUTO(Auto), FIXEDBEAM1(Fixed Beam 1), FIXEDBEAM2(Fixed Beam 2), FIXEDBEAM3(Fixed Beam 3), FIXEDBEAM4(Fixed Beam 4)

Unit: None

Actual Value Range: AUTO, FIXEDBEAM1, FIXEDBEAM2, FIXEDBEAM3, FIXEDBEAM4

MML Default Value: None

Recommended Value: AUTO(Auto)

Parameter Relationship:

-Others:

  • If BEAMCELLGROUPTYPE under the BEAMCELLGROUP MO is set to MASSIVEBEAM8T8R, BEAMOPTIONMODE is valid.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: It is recommended that this parameter be set to AUTO(Auto). If the beam selection is restricted to a fixed beam, adapt the selected beam to the service distribution. Inappropriate setting may affect the cell coverage, increasing the call drop rate of UEs at the edge of coverage and aggravating the interference from neighboring cells.

Applicable Mode: U

Example

To modify a beam cell group item with the parameters as follows: Beam Cell Group ID: 1, Local Cell ID: 103, Beam Azimuth: RIGHT, Beam Option Mode: AUTO, run the following command:
MOD BEAMCELLGROUPITEM: BEAMCELLGROUPID=1, ULOCELLID=103, BEAMAZIMUTH=RIGHT, BEAMOPTIONMODE=AUTO;
