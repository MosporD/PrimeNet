Set CHR Level (SET NODEBCHRLEVEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set the information level of CHR data and CHR user type.

Note

None

Parameters

ID Name Description
COMMCHREVENTSW Common CHR Event Switch

Meaning: Indicates the type of common CHR events. If an option is selected, corresponding contents will be automatically logged.

GUI Value Range: NODEBRESBLK(NodeB Resource Block), CELLRESBLK(Cell Resource Block), BRDRESBLK(Board Resource Block), BBINFOBLK1(BB Information Block 1), BBINFOBLK2(BB Information Block 2), TRANINFOBLK(Transmission Information Block), CQIBLK(Cell CQI Quality Information Block)

Unit: None

Actual Value Range: NODEBRESBLK, CELLRESBLK, BRDRESBLK, BBINFOBLK1, BBINFOBLK2, TRANINFOBLK, CQIBLK

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
USERCHREVENTSW User CHR Event Switch

Meaning: Indicates the type of user-level CHR events. If an option is selected, corresponding contents will be automatically logged.

GUI Value Range: DPAUSERINFOBLK1(HSDPA User Information Block 1), DPAUSERINFOBLK2(HSDPA User Information Block 2), UPAUSERINFOBLK1(HSUPA User Information Block 1), UPAUSERINFOBLK2(HSUPA User Information Block 2), R99USERINFOBLK1(R99 User Information Block 1), R99USERINFOBLK2(R99 User Information Block 2)

Unit: None

Actual Value Range: DPAUSERINFOBLK1, DPAUSERINFOBLK2, UPAUSERINFOBLK1, UPAUSERINFOBLK2, R99USERINFOBLK1, R99USERINFOBLK2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
COMMCHRPRDEVENTSW Common CHR Period Event Switch

Meaning: Indicates the type of common periodic CHR events. If an option is selected, corresponding contents will be automatically logged.

GUI Value Range: DPACELLPRDBLK1(DPA Cell Period Information Block 1), DPACELLPRDBLK2(DPA Cell Period Information Block 2), UPACELLPRDBLK1(UPA Cell Period Information Block 1), UPACELLPRDBLK2(UPA Cell Period Information Block 2), R99CELLPRDBLK1(R99 Cell Period Information Block 1), R99CELLPRDBLK2(R99 Cell Period Information Block 2)

Unit: None

Actual Value Range: DPACELLPRDBLK1, DPACELLPRDBLK2, UPACELLPRDBLK1, UPACELLPRDBLK2, R99CELLPRDBLK1, R99CELLPRDBLK2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
USERCHRPRDEVENTSW User CHR Period Event Switch

Meaning: Indicates the type of user-level periodic CHR events. If an option is selected, corresponding contents will be automatically logged.

GUI Value Range: DPAL2PRDBLK1(HSDPA L2 Period Information Block 1), DPAL2PRDBLK2(HSDPA L2 Period Information Block 2), UPAL2PRDBLK1(HSUPA L2 Period Information Block 1), UPAL2PRDBLK2(HSUPA L2 Period Information Block 2), R99ULUSERPRDBLK1(R99 Uplink Period Information Block 1), DPAL2PRDBLK3(HSDPA L2 Period Information Block 3), UPAL2PRDBLK3(HSUPA L2 Period Information Block 3)

Unit: None

Actual Value Range: DPAL2PRDBLK1, DPAL2PRDBLK2, UPAL2PRDBLK1, UPAL2PRDBLK2, R99ULUSERPRDBLK1, DPAL2PRDBLK3, UPAL2PRDBLK3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
HSDPAKQIDIAGTHPTHD HSDPA KQI Diagnosis Throughput Threshold

Meaning: Specifies whether the HSDPA throughput of a user is lower than the specified threshold.

GUI Value Range: 500, 1000, 1500, 2000, 2500, 3000, 3500, 4000, 4500, 5000

Unit: kbps

Actual Value Range: 500, 1000, 1500, 2000, 2500, 3000, 3500, 4000, 4500, 5000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If USERCHRPRDEVENTSW is set to DPAL2PRDBLK3, HSDPAKQIDIAGTHPTHD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
HSUPAKQIDIAGTHPTHD HSUPA KQI Diagnosis Throughput Threshold

Meaning: Specifies whether the HSUPA throughput of a user is lower than the specified threshold.

GUI Value Range: 100, 200, 300, 400, 500, 600, 700, 800, 900, 1000, 1100, 1200, 1300, 1400, 1500

Unit: kbps

Actual Value Range: 100, 200, 300, 400, 500, 600, 700, 800, 900, 1000, 1100, 1200, 1300, 1400, 1500

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If USERCHRPRDEVENTSW is set to UPAL2PRDBLK3, HSUPAKQIDIAGTHPTHD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Execute this command to set the CHR Level and CHR user type:
SET NODEBCHRLEVEL: COMMCHREVENTSW=CELLRESBLK-0, USERCHREVENTSW=UPAUSERINFOBLK2-0, COMMCHRPRDEVENTSW=UPACELLPRDBLK2-0, USERCHRPRDEVENTSW=R99ULUSERPRDBLK1-0;
