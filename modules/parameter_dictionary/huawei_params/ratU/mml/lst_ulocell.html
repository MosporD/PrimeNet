List Local Cell Configuration (LST ULOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the summarized information of the local cells and detailed information of the specified local cell by query mode.

Note

  • In the query mode of "ALLLOCALCELL", this command is executed to get the summarized information of all the local cells.
  • In the query mode of "LOCALCELL", if no local cell ID is specified, this command is executed to get the summarized information of all the local cells under the NodeB. If there is a local cell ID specified and the local cell exists, this command is executed to get the detailed information of the specified local cell.
  • In the query mode of "SECTOR", this command is executed to get the summarized information of all the local cells in this sector.
  • In the query mode of "ULBASEBANDEQM", this command is executed to get the summarized information of all the local cells in all the uplink baseband equipment under this NodeB if no uplink baseband equipment number is specified. If there is an uplink baseband equipment number specified and the uplink baseband equipment exists, this command is executed to get the summarized information of all the local cells in this uplink baseband equipment.
  • In the query mode of "DLBASEBANDEQM", this command is executed to get the summarized information of all the local cells in all the downlink baseband equipment under this NodeB if no downlink baseband equipment is specified. If there is a downlink baseband equipment number specified and the downlink baseband equipment exists, this command is executed to get the summarized information of all the local cells in this downlink baseband equipment.
  • In the query mode of "SECTOREQM", this command is executed to get the summarized information of all the local cells in all the Sector Equipment under this NodeB if no Sector Equipment is specified. If there is a Sector Equipment number specified and the Sector Equipment exists, this command is executed to get the summarized information of all the local cells in this Sector Equipment.

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. The local cell ID is unique for one NodeB.

Local Cell Type

Indicates the type of local cell.

Cell Scale Indication

Indicates whether the cell is configured as a macro cell or micro cell. It is recommended that the maximum transmit power of a cell be used as a criterion for CellScaleInd. For example, cells with their maximum transmit power of less than 10 w are configured as a micro cell. Otherwise, cells are configured as macro cells. In actual scenarios, the criterion for CellScaleInd is changed as required.

Cell ID

Indicates the Cell ID.

Cell Name

Indicates the cell name. The value of this parameter is consistent with that of the CellName parameter in the UCELL MO on the RNC. The value is automatically synchronized by the RNC and does not need to be specified.

Reserved Cell

This parameter specifies whether to continue with cell services when the cell voltage is insufficient. If this parameter is set to FALSE, the cell with insufficient voltage will stop providing services. If this parameter is set to TRUE, the cell with insufficient voltage continues providing some services until the voltage drops to a level that can support no services. In this case, if the smooth power change function has been enabled by running the SET NODEBSMTHPWRSW command, the cell gradually reduces its pilot power before services are stopped. This ensures that services are smoothly transferred to other normal carriers.

UL Baseband Equipment ID

Indicates the number of the uplink baseband equipment carrying baseband resources for the local cell. Uplink resources are shared by the cells in an uplink baseband equipment.

DL Baseband Equipment ID

Indicates the number of the downlink baseband equipment carrying baseband resources for the local cell. A local cell can be served by only one board in the downlink baseband equipment.

UlCoMP Algorithms Switch

Indicates whether a cell supports Uplink CoMP (Joint Reception) based on Coordinated BBU. A cell serves as a neighboring cell only after this switch is turned on.

UL 16QAM

Indicates whether the UL 16QAM feature is supported by the cell.

UL L2 Enhanced

Indicates whether UL L2 Enhanced is supported by the cell.

ERACH

Indicates whether Uplink Enhanced CELL_FACH is supported by the cell.

ERACH HSDPCCH Switch

Indicates whether to enable E-RACH over HS-DPCCH.

DL64QAM

Indicates whether to enable the downlink 64QAM function.

DL 64QAM+MIMO

Indicates whether the DL 64QAM_MIMO feature is supported by the cell.

DC-HSDPA+MIMO

Indicates whether the DC-HSDPA+MIMO feature is supported by the cell.

DB-HSDPA+MIMO

Indicates whether the DB-HSDPA+MIMO feature is supported by the cell.

4C-HSDPA+MIMO

Indicates whether the 4C-HSDPA+MIMO feature is supported by the cell.

GU Power Share Flag

Indicates whether the local cell supports GSM/UMTS power sharing. This parameter must be specified for a GSM/UMTS dual-mode base station.

BOOST

Indicates whether the BOOST feature is supported by the cell.

FDE

Indicates whether the cell supports the Frequency Domain Equalization (FDE) feature for HSUPA services.

IC

Indicates whether the cell supports the Interference Cancellation feature for HSUPA services.

Turbo IC

Indicates whether the cell supports Turbo IC.

Turbo IC Phase2

Indicates whether the cell supports Turbo IC Phase2.

Local Cell Radius(m)

Indicates the radius of a local cell, affecting cell coverage. It is set according to the network plan. A small cell radius causes user access failure to some or all coverage under certain configuration. Generally, use the default value of the cell radius.

Local Cell Inner Handover Radius(m)

Indicates the inner handover radius. The parameter value cannot be greater than cell radius.

Two Tx Way

Indicates whether the cell supports 2T mode.

UL Frequency Indicator

Indicates whether to configure the UL frequency channel number for a local cell. If this parameter is set to TRUE, the UL frequency channel number needs to be manually configured. If this parameter is set to FALSE, the UL frequency channel number is automatically configured by the system based on the relationship between uplink and downlink frequencies and therefore does not need to be manually configured. For details, see 3GPP TS 25.433.

Max Output Power(0.1dBm)

Indicates the maximum transmit power of the local cell is the maximum output power at the antenna connector on the cabinet top.

Dl BB Resource Allocation Mode

Indicates the downlink baseband resource allocation mode for the local cell. It determines the assignment scope of the DL baseband resources. The cell is assigned with baseband resources according to the selected DL baseband resource assignment mode. If the WBBPa board is not configured, any value is applicable to this parameter. Downlink resources are allocated from the WBBPb board and its compatible boards. The parameter value has no impact on the system. The default value is recommended. If 64QAM is required for the local cell, this parameter needs to be set to INEBOARD(From the WBBPb and other new boards).

Desensitization Intensity(dB)

Indicates the desensitization intensity, that is, the ratio of uplink noise intensity to background noise. If the desensitization intensity is set as 0, the desensitization is not applied.

High Speed Movement Mode

Indicates whether the High Speed Access feature is supported by the cell.

4C-HSDPA

Indicates whether to enable the 4C-HSDPA function of the local cell.

Frequency Bandwidth(kHz)

Indicates the bandwidth for a cell over the air interface.

1. This parameter is optional. When this parameter is set to UNSPECIFIED, the actual cell bandwidth is configured by running the SET FREQBWH command.

2. This parameter is invalid for the WRFU, MRFU V1, MRFU V2, MRFU V2a, RRU3804, RRU3805, RRU3806, RRU3808, RRU3801C, RRU3801E, RRU3908, and AAU3902. However, on these RF units, the cell bandwidth is still configured by running the SET FREQBWH command.

HSPA User Number Extend

Indicates the number of HSPA users served in a local cell. Value ON indicates that a local cell serves more than 128 HSPA users, and value OFF indicates that a local cell serves a maximum of 128 HSPA users.

Interference Rejection Combining Switch

Indicates the switch for interference rejection combining (IRC).

User Label

Indicates the user label of local cell.

MF-HSDPA Switch

Indicates whether the cell supports SFDC and DF3C.

Virtual CPC

Indicates whether the virtual CPC feature is supported by the cell.

Coverage Expansion Under Interference

Indicates whether a cell supports the Coverage Expansion Under Interference.

Precise Channel Estimation for HSUPA 2 ms UEs

Indicates whether the cell supports precise channel estimation for HSUPA 2 ms UEs.

Inter-NodeB Uplink CoMP

Indicates whether the cell supports the Moving Speed-based Adaptive Demodulation feature.

Adaptive Interference Rejection

Indicates whether the cell supports the Adaptive Interference Rejection feature.

Inter-NodeB HS-DPCCH CoMP

Indicates whether the cell supports the Inter-NodeB HS-DPCCH CoMP (Joint Reception) feature.

UL Super Narrow Band Filter(kHz)

Indicates the bandwidth for the UMTS uplink super narrow band filter in GSM+UMTS 5 MHz scenarios. If this parameter is set to a value other than NOTSUPPORT, Uplink Super Narrow Band Filter takes effect. If this parameter is set to NOTSUPPORT, Uplink Super Narrow Band Filter does not take effect. The cell bandwidth is specified by the FMBWH parameter in the SET FREQBWH command or the FREQUENCYBANDWIDTH parameter in the ADD ULOCELL and MOD ULOCELL commands. For details, see the FMBWH and FREQUENCYBANDWIDTH configuration specifications.

Indicates the UMTS bandwidth without overlapping GSM frequencies when uplink adaptive band-pass filter is enabled in GU@5 MHz scenarios. In this situation, the cell bandwidth is specified by FMBWH in the SET FREQBWH command or FREQUENCYBANDWIDTH in the ADD ULOCELL or MOD ULOCELL command. For details, see the FMBWH and FREQUENCYBANDWIDTH configuration descriptions.

DL Adaptive Band-Pass Filter

Indicates the algorithm for Downlink Adaptive Band-Pass Filter. When this parameter is set to NOTSUPPORT, the UMTS cell downlink adaptive band-pass filter is disabled. When this parameter is set to STATICBANDWIDTH, the UMTS cell downlink adaptive band-pass filter bandwidth remains unchanged. When this parameter is set to DYNAMICBANDWIDTH, the UMTS cell downlink adaptive band-pass filter bandwidth dynamically adapts to the GSM services. When this parameter is set to FIXEDBANDWIDTH, the 3.8 MHz downlink adaptive band-pass filter is used in the UMTS cell, requiring no bandwidth adjustment based on GSM services.

Dynamic Bandwidth Optimization

Indicates the algorithm of optimizing the dynamic bandwidth of the downlink adaptive band-pass filter. When this parameter is set to DBTOSBGUNOTSYN, dynamic filtering is changed to static filtering for the downlink adaptive band-pass filter with DLADAPTIVEBPFILTER set to DYNAMICBANDWIDTH when GSM and UMTS clocks are not synchronous. When this parameter is set to DBTOSDBGUNOTSYN, dynamic filtering is changed to semi-dynamic filtering for the downlink adaptive band-pass filter with DLADAPTIVEBPFILTER set to DYNAMICBANDWIDTH when GSM and UMTS clocks are not synchronous.

GSM Quality Based ROT Dynamic Control

Indicates the algorithm for UMTS Target RoT Adjustment Based on GSM Radio Quality. When the parameter is set to TRUE, UMTS Target RoT Adjustment Based on GSM Radio Quality is enabled. When the parameter is set to FALSE, UMTS Target RoT Adjustment Based on GSM Radio Quality is disabled.

Intelligent 2T VAM

Whether the Intelligent 2T VAM feature is supported by the cell. When this parameter is set to TRUE, the cell supports Intelligent 2T VAM. When this parameter is set to FALSE, the cell does not support Intelligent 2T VAM. Based on the quick phase adjustment capability of the baseband VAM, the Intelligent 2T VAM feature enables the NodeB to match the best phase difference for each user when they are being scheduled, improving use experience. Baseband VAM refers to virtual antenna mapping (VAM) implemented on the baseband.

NBIS Adaptive Forbid Switch

Indicates whether to disable the adaptive NBIS function for a cell. If this parameter is set to ON, the adaptive NBIS function is disabled for the cell.

DL Asymmetric Bandpass Filter

Indicates the function for downlink asymmetric band-pass filter. When this parameter is set to TRUE(TRUE), the cell supports this function. When this parameter is set to FALSE(FALSE), the cell does not support this function.

DL AsymFilter Neighbor Frequency Cell ID

ID of the neighboring frequency cell of a cell working at the downlink asymmetric narrowband carrier. The value 4294967295 is invalid, this parameter cannot be set to the value by users.

DL AsymFilter Left Bandwidth(kHz)

Indicates the bandwidth on the left, when the cell is working on the downlink asymmetric narrowband carrier. The left side indicates the frequencies lower than the center frequency. When DLASYMFILTER is set to TRUE(TRUE), this parameter takes effect. When this parameter is set to 2.5 MHz, more bandwidth is allotted to the lower frequencies. When this parameter is set to a value other than 2.5 MHz, more bandwidth is allotted to the higher frequencies. The bandwidth on the left and that on the right cannot be both set to 2.5 MHz.

DL AsymFilter Right Bandwidth(kHz)

Indicates the bandwidth on the right, when the cell is working on the downlink asymmetric narrowband carrier. The right side indicates the frequencies higher than the center frequency. When DLASYMFILTER is set to TRUE(TRUE), this parameter takes effect. When this parameter is set to 2.5 MHz, more bandwidth is allotted to the higher frequencies. When this parameter is set to a value other than 2.5 MHz, more bandwidth is allotted to the lower frequencies. The bandwidth on the left and that on the right cannot be both set to 2.5 MHz.

GU@5MHz Performance Optimize

Indicates whether to enable GU@5MHz Phase 2.

ULADAPTIVEBPFILTER: Indicates whether the cell supports uplink adaptive band-pass filter. When the option is selected, the cell supports uplink adaptive band-pass filter.

DLADAPTIVEBPFILTERPERFEOPT: Indicates whether the cell supports downlink adaptive band-pass filter optimization. When the option is selected, the cell supports downlink adaptive band-pass filter optimization.

GU Bufferzone Cell Type

Indicates the type of cells in GU Refarming or GU@5 MHz scenarios. Value NOTBUFZONECELL indicates that the cell is not in the buffer zone. Value BUFZONECELLWITHGSM indicates that the cell is a UMTS cell co-deployed with GSM cells in the buffer zone. Value BUFZONECELLWITHOUTGSM indicates that the cell is a UMTS cell not co-deployed with GSM cells in the buffer zone.

Beam Forming Mode

Indicates the beamforming mode. Value NOTSUPPORT indicates that the cell does not support beamforming on the baseband processing unit. Value MASSIVEBEAM indicates that the cell is enabled with beamforming on the baseband processing unit and supports the UMTS Massive Beam 4T4R or UMTS Massive Beam 8T8R capability. Value NORMALBEAM indicates that the cell supports the normal beamforming capability on the baseband processing unit. Value FOURTXBEAMOPT indicates that the cell supports the UMTS 4T Beam Optimization capability. Value COORDINATEDBEAM indicates that the cell supports the 2T Coordinated Beaforming capability. If this parameter is set to NORMALBEAM, MASSIVEBEAM, or COORDINATEDBEAM, the ring topology for RF modules is not supported. With the hot-backup ring topology, the local cell is unavailable if downlink RF signal combination is used for two Massive Beam cells.

UMTS and LTE Dynamic Power Sharing Flag

Indicates whether the local cell supports the UMTS and LTE Dynamic Power Sharing feature. This parameter applies to a UMTS/LTE dual-mode base station.

UMTS and LTE Spectrum Sharing Switch

Indicates whether the UMTS and LTE spectrum sharing function takes effect. If this parameter is set to FIXED_BANDWIDTH_COMP_MODE, the UMTS and LTE spectrum sharing function takes effect to allow sharing of some spectrums between UMTS and LTE networks.

Uplink Left Shared Bandwidth(10kHz)

Indicates the bandwidth that is on the left of the uplink spectrum of a UMTS cell and can be shared or overlapped with another UMTS cell or an inter-RAT cell.

Uplink Right Shared Bandwidth(10kHz)

Indicates the bandwidth that is on the right of the uplink spectrum of a UMTS cell and can be shared or overlapped with another UMTS cell or an inter-RAT cell.

Downlink Left Shared Bandwidth(10kHz)

Indicates the bandwidth that is on the left of the downlink spectrum of a UMTS cell and can be shared or overlapped with another UMTS cell or an inter-RAT cell.

Downlink Right Shared Bandwidth(10kHz)

Indicates the bandwidth that is on the right of the downlink spectrum of a UMTS cell and can be shared or overlapped with another UMTS cell or an inter-RAT cell.

UMTS and LTE Zero Bufferzone

Indicates whether the UMTS and LTE Zero Bufferzone feature takes effect for a UMTS cell. If this parameter is set to TRUE, no buffer zone is required between the UMTS cell and neighboring LTE cells during UMTS/LTE refarming. If this parameter is set to FALSE, this feature is not supported.

UMTS and LTE Zero Bufferzone Filter

Indicates the filter mode for UMTS and LTE Zero Bufferzone. Value ULADAPTIVEFILTER indicates that the uplink adaptive filtering is configured for the UMTS cell. Value ULNARROWBANDFILTER indicates that uplink narrowband filtering is configured for the UMTS cell.

DC-HSDPA Shared with GSM

Indicates whether the cell supports the DC-HSDPA function in the shared GSM spectrum.

Non Standard Bandwidth DL Filter Optimize(kHz)

Indicates whether the downlink filter optimization function is supported in non-standard bandwidth scenarios.

Sector Equipment ID

Indicates the number of sector equipment used for the local cell.

Max Output Power(0.1dBm)

Indicates the maximum output power of the sector equipment.

Sector Equipment Property

Indicates the property of sector equipment of a local cell.

UMTS and LTE Spectrum Sharing Phase2

Indicates whether the cell supports the UMTS and LTE spectrum sharing phase 2 feature. When this parameter is set to TRUE, the cell supports this feature.

DC-HSDPA Shared with LTE

Indicates whether a UMTS cell supports the UMTS and LTE Spectrum Sharing Based on DC-HSDPA feature. When this parameter is set to DYNAMICBANDWIDTH, UMTS and LTE spectrum sharing is supported.

Co-coverage LTE Cell ID

Indicates the ID of the EUTRAN cell with the same coverage as a UMTS cell. This parameter uniquely identifies an LTE cell in a PLMN. For a macro base station, EutranCellId consists of the 20-bit eNodeBID and the 8-bit CellID (Specifically, EutranCellId = eNodeBID x 256 + CellID). For details about the parameter definition, see 3GPP TS 25.413. The value 4294967295 indicates an invalid ID.

Co-coverage LTE Cell Sector ID

Indicates the ID of an LTE sector with the same coverage as a UMTS cell. Value 65536 indicates an invalid ID, and is used when the LTE SFN feature is disabled.

UU 0 DC-HSDPA

Indicates whether the cell supports the UU 0 DC-HSDPA function. If this parameter is set to FALSE or the cell is not in the HSDPA multi-carrier cell group, the UU 0 DC-HSDPA function does not take effect. When this parameter is set to TRUE and the cell is in the HSDPA multi-carrier cell group, the UU 0 DC-HSDPA function takes effect in the cell and the cell can be used only as a secondary cell for DC-HSDPA UEs.
