Set Congest Protection Parameters (SET NODEBCONGCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set congestion protection parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This command is used to ensure a satisfactory access success rate of CS and emergency calls when the NodeB control plane is overloaded by signaling, for example, when the excessive signaling load is caused by smart phones. This command will affect the RRC connection setup success rate of PS services and therefore must be used with caution.

Parameters

ID Name Description
FRTRJT First Reject Threshold

Meaning: Indicates the control plane congestion first reject threshold.

GUI Value Range: 80~90

Unit: %

Actual Value Range: 80~90

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this threshold is too high, the CPU easily gets overloaded. If this threshold is too low, PS access requests are rejected too early.

Applicable Mode: U

Example

Execute this command to set congest protection parameters: 
SET NODEBCONGCTRLPARA: FRTRJT=90;
