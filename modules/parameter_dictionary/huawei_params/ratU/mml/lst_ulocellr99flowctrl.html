List R99 Flow Control Function Switch (LST ULOCELLR99FLOWCTRL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the R99 flow control function switch.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Use the following command to list flow control function switch:
LST ULOCELLR99FLOWCTRL: ULOCELLID=100;
The result is shown as follows:
+++    HUAWEI        2011-09-26 09:50:15
O&M    #10223
%%LST ULOCELLR99FLOWCTRL: ULOCELLID=100;%%
RETCODE = 0  Operation succeeded.

List R99 Flow Control Function Switch
-------------------------------------
                   Local Cell ID  =  100
R99 Flow Control Function Switch  =  Close
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

R99 Flow Control Function Switch

Indicates the R99 Flow Control Function Switch. The function will be enabled if this parameter is set to OPEN. The function will be disabled if this parameter is set to CLOSE.
