Set R99 Flow Control Function Switch (SET ULOCELLR99FLOWCTRL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to set congest protection parameters.

Note

This command is used to ensure a satisfactory access success rate of CS and emergency calls when the NodeB control plane is overloaded by signaling, for example, when the excessive signaling load is caused by smart phones. This command will affect the RRC connection setup success rate of PS services and therefore must be used with caution.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
R99FLOWCTRLSW R99 Flow Control Function Switch

Meaning: Indicates the R99 Flow Control Function Switch. The function will be enabled if this parameter is set to OPEN. The function will be disabled if this parameter is set to CLOSE.

GUI Value Range: OPEN(Open), CLOSE(Close)

Unit: None

Actual Value Range: OPEN, CLOSE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is set to OPEN, the NodeB also performs flow control on uplink BE services carried on R99. As a result, R99 rates are affected, the packet loss rate may increase, and the service rates may decrease.

Applicable Mode: U

Example

Execute this command to set the R99 Flow Control Function Switch:
SET ULOCELLR99FLOWCTRL: ULOCELLID=17140, R99FLOWCTRLSW=OPEN;
