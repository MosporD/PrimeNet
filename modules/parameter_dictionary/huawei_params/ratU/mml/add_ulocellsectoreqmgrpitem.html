Add Sector Equipment Used by Sector Equipment Group (ADD ULOCELLSECTOREQMGRPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to add sector equipment to a specified sector equipment group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The local cell for the sector equipment group, the sector equipment group, and sector equipment must have been configured. Otherwise, execution of this command fails.
  • Sector equipment groups use only RRUs of the MPMU type for the LampSite product.
  • Only one set of sector equipment is added each time this command is executed.
  • A set of sector equipment cannot be shared by multiple sector equipment groups in a Mixed-Multi-RRU cell.
  • The sector equipment in a Mixed-Multi-RRU cell must have the same number of transmit antennas and receive antennas.
  • Executing this command interrupts ongoing services for less than 5 minutes if logical cells are configured.
  • The RF unit configured in DCU and the RF unit not configured in DCU cannot be both used by a Mixed-Multi-RRU cell. Otherwise, the local cell is unavailable.
