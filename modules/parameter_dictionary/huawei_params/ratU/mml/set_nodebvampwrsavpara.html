Set Parameters Related to VAM Power Saving (SET NODEBVAMPWRSAVPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set parameters related to the VAM Power Saving feature.

Note

  • If the value of VAM Power Saving Start Time is 1s greater than the value of VAM Power Saving Stop Time or VAM Power Saving Start Time is set to 00:00:00 and VAM Power Saving Stop Time is set to 23:59:59, the VAM Power Saving feature remains enabled all day. You are advised not to enable this feature all day.
  • It is recommended that both VAM Power Saving Start Time and VAM Power Saving Stop Time be set to off-peak time.
  • If the RF channel serving a cell is disabled for energy saving, the MIMO Prime feature does not take effect in this cell.

Parameters

ID Name Description
VAMPWRSAVSW VAM Power Saving Switch

Meaning: Indicates whether to enable the VAM Power Saving feature. If this parameter is set to ON, the VAM Power Saving feature is enabled to save energy.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
VAMPWRSAVSTARTTIME VAM Power Saving Start Time

Meaning: Indicates the time at which the VAM Power Saving feature takes effect. When the system time reaches the time specified by this parameter, the VAM Power Saving feature takes effect.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05, indicating that the VAM Power Saving feature takes effect at 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 00:00:00

Parameter Relationship:

-Configuration constraints:

  • Under the NODEBALGPARA MO, values of VAMPWRSAVSTARTTIME and VAMPWRSAVSTOPTIME must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
VAMPWRSAVSTOPTIME VAM Power Saving Stop Time

Meaning: Indicates the time at which the VAM Power Saving feature becomes ineffective. When the system time reaches the time specified by this parameter, the VAM Power Saving feature becomes ineffective.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05, indicating that the VAM Power Saving feature becomes ineffective at 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 06:00:00

Parameter Relationship:

-Configuration constraints:

  • Under the NODEBALGPARA MO, values of VAMPWRSAVSTARTTIME and VAMPWRSAVSTOPTIME must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
VAMPWRSAVTXPWRLOWTHD VAM Power Saving TX Power Low Threshold

Meaning: Indicates the threshold of the output power percentage for cells to use the VAM Power Saving feature. If the average output power percentage of each VAM cell served by an RF module is lower than this threshold, one power amplifier is disabled and all VAM cells emit power over only one power amplifier.

GUI Value Range: 20~45

Unit: %

Actual Value Range: 20~45

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the NODEBALGPARA MO, the value of VAMPWRSAVTXPWRLOWTHD must be less than that of VAMPWRSAVTXPWRHIGHTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value leads to a shorter effective duration of the VAM Power Saving feature and less saved energy. A larger parameter value leads to a longer effective duration of the VAM Power Saving feature and more saved energy.

Applicable Mode: U
VAMPWRSAVTXPWRHIGHTHD VAM Power Saving TX Power High Threshold

Meaning: Indicates the threshold of the output power percentage for cells to stop the VAM Power Saving feature. If the average output power percentage of any VAM cell served by an RF module is greater than this threshold, the disabled power amplifier is enabled to equally share the power emitted by VAM cells between two working power amplifiers.

GUI Value Range: 20~45

Unit: %

Actual Value Range: 20~45

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the NODEBALGPARA MO, the value of VAMPWRSAVTXPWRLOWTHD must be less than that of VAMPWRSAVTXPWRHIGHTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value leads to a shorter effective duration of the VAM Power Saving feature and less saved energy. A larger parameter value leads to a longer effective duration of the VAM Power Saving feature and more saved energy. However, an extremely large parameter value may lead to slow rise in the downlink rates of new HSDPA users.

Applicable Mode: U

Example

Set parameters related to VAM power saving:
SET NODEBVAMPWRSAVPARA: VAMPWRSAVSW=ON, VAMPWRSAVSTARTTIME=10&23&01, VAMPWRSAVSTOPTIME=10&23&02, VAMPWRSAVTXPWRLOWTHD=20, VAMPWRSAVTXPWRHIGHTHD=30;
