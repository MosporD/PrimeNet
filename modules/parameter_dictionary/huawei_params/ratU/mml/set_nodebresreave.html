Set Resource Reave Switch (SET NODEBRESREAVE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set resource reave switch.

Note

None

Parameters

ID Name Description
RESREAVESW Resource Reave Switch

Meaning: Indicates the BB Resource Reave Switch.

GUI Value Range: ON(ON), OFF(OFF)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Execute this command to set resource reave switch:
SET NODEBRESREAVE: RESREAVESW=ON;
