List NodeB Baseband Unit (LST NODEBBBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the information about a BBU.

Note

The BLADEBBU and BBU3910C do not support this command.

Parameters

ID Name Description
BBUNITID Baseband Unit ID

Meaning: Indicates the number of the BBU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1. Run the following command to query the information about all BBUs: 
LST NODEBBBUNIT:;
The result is shown as follows:
+++    Sig_Maintenance_A        2013-06-17 13:13:36
O&M    #12683
%%LST NODEBBBUNIT:;%%
RETCODE = 0  Operation succeeded.

List NodeB Baseband Unit
------------------------
Baseband Unit ID  Cabinet No.  Subrack No.  Slot No.

0                 0            0            0       
5                 0            0            5       
(Number of results = 2)


---    END

2. Run the following command to query the information about No.5 BBU:
LST NODEBBBUNIT: BBUNITID=5;
The result is shown as follows:
+++    Sig_Maintenance_A        2013-06-17 13:15:46
O&M    #12689
%%LST NODEBBBUNIT: BBUNITID=5;%%
RETCODE = 0  Operation succeeded.

List NodeB Baseband Unit
------------------------
Baseband Unit ID  Cabinet No.  Subrack No.  Slot No.

5                 0            0            5       
(Number of results = 1)


---    END

Output Description

Field Description

Baseband Unit ID

Indicates the number of the BBU.

Cabinet No.

Indicates the number of the cabinet where the BBU is located.

Subrack No.

Indicates the number of the subrack where the BBU is located.

Slot No.

Indicates the number of the slot where the BBU is located.
