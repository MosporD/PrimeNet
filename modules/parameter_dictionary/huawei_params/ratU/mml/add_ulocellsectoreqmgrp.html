Add Sector Equipment Group (ADD ULOCELLSECTOREQMGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to add sector equipment groups. Sector equipment groups were introduced for the "Mixed Multiple RRUs In One Cell" sector. Similar to each RRU in the Multi-RRU independent demodulation cell, data of each sector equipment group is processed on the baseband side. That is, all RRUs in the same sector equipment group and their data are allocated the same baseband resources and channel resources.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only one sector equipment group can be added and only one set of sector equipment can be added to the sector equipment group each time this command is executed. To add more sector equipment to the sector equipment group, run the ADD ULOCELLSECTOREQMGRPITEM command.
  • Sector equipment groups use only RRUs of the MPMU type for the LampSite product.
  • The MPMUs in a sector equipment group can be connected to different RHUBs only over the same optical port. If the MPMUs are connected over different optical ports, the sector equipment group is unavailable.
  • Executing this command interrupts ongoing services for less than 1 minute if logical cells are configured.
  • The RF unit configured in DCU and the RF unit not configured in DCU cannot be both used by a Mixed-Multi-RRU cell. Otherwise, the local cell is unavailable.
