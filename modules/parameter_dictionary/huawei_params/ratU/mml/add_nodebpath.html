Add NodeB IP Path (ADD NODEBPATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to declare NodeB IP PATH.

Note

  • Before running this command, ensure that NODEBFUNCTION exists.
  • Before running this command, ensure that PATHID referenced by the NODEBPATH has been added successfully by running the ADD IPPATH command.
  • In the scenario where the GSM, UMTS and LTE networks share a main control board, if PEERIPADDR and DSCP for the IP path used by the UMTS network are the same as those used by the GSM or LTE network, but the IPADDR for the IP path used by the networks is different, run this command to configure the IP path used by the current network.

Parameters

ID Name Description
PATHID PATH ID

Meaning: Indicates the IP path used for the NodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Add a No.1 NodeB IP path:
ADD NODEBPATH: PATHID=1;
