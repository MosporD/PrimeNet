Unblock Local Cell (UBL ULOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to unblock a specified or all the local cells

Note

The local cell supports repeated unblock.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1. Unblock all local cells:
UBL ULOCELL:;

2. Unblock the No.14600 local cell:
UBL ULOCELL: ULOCELLID=14600;
