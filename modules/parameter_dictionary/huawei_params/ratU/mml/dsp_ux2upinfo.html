Display uX2 User Plane Information (DSP UX2UPINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the user-plane information about the uX2 interface.

Note

  • If LOCIPV4 under USERPLANEHOST is modified, the IP address displayed in the DSP UX2UPINFO command output is incorrect.
  • If Static Check Switch is set to ON and no UE is running services or if Static Check Switch is set to OFF, the exceptions on user-plane links may not be accurately detected. If a user-plane link is in a status other than normal, uX2 User Plane Link State in the DSP UX2UPINFO command output is Unknown. If Static Check Switch is set to ON and UEs are running services, the exceptions on user-plane links are accurately detected. If a user-plane link is abnormal, uX2 User Plane Link State in the DSP UX2UPINFO command output is Abnormal. The setting of Static Check Switch can be queried by running the LST UX2 command.

1.To query the user-plane information about all the uX2 interfaces, run the following command:

Output Description

Field Description

uX2 Interface ID

Indicates the uX2 interface ID.

uX2 User Plane Host IP Address

Indicates the IP Address of the user-plane host of the uX2 interface.

uX2 User Plane Peer IP Address

Indicates the IP Address of the user-plane peer of the uX2 interface.

uX2 User Plane Link State

Indicates the user-plane link status of the uX2 interface. The value Abnormal means that the user-plane link is disconnected. The value Normal means that the user-plane link is connected. The value Unknown means that the user-plane link status information cannot be obtained.

uX2 UP Link Delay(0.1microsecond)

Indicates the user-plane Round-Trip Time (RTT) of the uX2 interface.

uX2 UP Link One-way Delay(0.1microsecond)

Indicates the one-way delay on the uX2 user-plane link.
