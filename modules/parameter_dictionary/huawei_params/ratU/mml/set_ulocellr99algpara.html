Set R99 Algorithm Parameters (SET ULOCELLR99ALGPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set R99 Algorithm Parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When PWRCNGCACSW is set to ON, this can prevent downlink power congestion caused by frequent RRC setup. In this way, the downlink performance does not quickly deteriorate, and RRC connections in progress do not experience low procedure success rates, but during non-peak hours, the RRC setup success rate may decrease.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
PWRCNGCACSW Power Congestion Call Admission Control Switch

Meaning: Indicates the power congestion admission switch. It controls whether the power congestion-based E2E flow control algorithm takes effect. When this switch is turned on, this can prevent downlink power congestion caused by frequent RRC setup. In this way, the downlink performance does not quickly deteriorate, and RRC connections in progress do not experience low procedure success rates. During non-peak hours, the RRC setup success rate may decrease, but the probability of this is low.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is set to ON, the NodeB singles out RL SETUP scenarios. By determining whether the downlink load meets the conditions, the NodeB approves or rejects the RL SETUP requests. By determining whether the current number of online RRC users meets the conditions, the NodeB approves or rejects RRC setup requests. This parameter can prevent downlink power congestion caused by frequent RRC setup. In this way, the downlink performance does not quickly deteriorate, and RRC connections in progress do not experience low procedure success rates. During non-peak hours, the RRC setup success rate may decrease, but the probability of this is low.

Applicable Mode: U
SHORTTH Short Threshold

Meaning: Indicates the short-term decision threshold for the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink transmitted carrier power (TCP) on the NodeB is congested corresponding to the RRC connections of non-real-time services.

GUI Value Range: 0~120

Unit: %

Actual Value Range: 0~120

MML Default Value: None

Recommended Value: 105

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, a large number of link setup requests for non-real-time services are approved. This causes downlink power congestion in the case of frequent RRC link setups. If this parameter is set to a small value, admission is difficult, affecting the admission success rate and wasting the cell capacity.

Applicable Mode: U
LONGTH Long Threshold

Meaning: Indicates the long-term decision threshold for the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink non-HSPA TCP on the NodeB is congested.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, a large number of link setup requests for non-real-time services are approved. This causes downlink power congestion in the case of frequent RRC link setups. If this parameter is set to a small value, admission is difficult, affecting the admission success rate and wasting the cell capacity.

Applicable Mode: U
SHORTTHFORRTRRC Short Threshold for RT RRC

Meaning: Indicates the short-term decision threshold for RRC connections of real-time services of the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink TCP on the NodeB is congested corresponding to the RRC connections of real-time services.

GUI Value Range: 0~200

Unit: %

Actual Value Range: 0~200

MML Default Value: None

Recommended Value: 120

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, a large number of link setup requests are approved. This causes downlink power congestion in the case of frequent RRC link setups. If this parameter is set to a small value, admission is difficult, affecting the admission success rate and wasting the cell capacity.

Applicable Mode: U

Example

Execute this command to set R99 algorithm parameters:
SET ULOCELLR99ALGPARA: ULOCELLID=100, PWRCNGCACSW=ON, SHORTTH=105, LONGTH=80, SHORTTHFORRTRRC=120;
