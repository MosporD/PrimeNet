Realloc All Local Cell Based BB Res Optimum (STR REALLOCLOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to start local cell reestablishment through baseband resource optimization in all local cells, a single local cell, all local cells served by the uplink baseband equipment, or all local cells served by the downlink baseband equipment.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The ongoing services of the local cell whose baseband resources are reallocated are interrupted for less than 1 minute when this command is executed.
