Add Local Cell Sector Equipment (ADD ULOCELLSECTOREQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to add sector equipment for local cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The value of MAXPWR cannot exceed the maximum power for a cell when the value is not 65535.
  • Setting power for each ULOCELLSECTOREQM is not recommended.
  • This command is used only to add sector equipment for the normal cell, distributed cell, multi-RRU cell with independent demodulation, Mixed-Multi-RRU cell and IMB cell. When the number of sector equipment exceeds the capability of the local cell, the execution of this command fails.
  • Executing this command interrupts ongoing services for less than 1 minute.
  • The RF unit configured in DCU cannot be used by non-Mixed-Multi-RRU cell. Otherwise, the local cell is unavailable or the local cell capability is degraded.
  • The RF unit configured in DCU and the RF unit not configured in DCU cannot be both used by a Mixed-Multi-RRU cell. Otherwise, the local cell is unavailable.

Example
