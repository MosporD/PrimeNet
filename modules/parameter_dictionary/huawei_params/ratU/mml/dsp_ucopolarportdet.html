Display Antenna Port Co-Polarization Detection Result (DSP UCOPOLARPORTDET)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the cell antenna port co-polarization detection result.

Note

  • The command applies only to normal cells configured with four receive antennas (including single RF module scenarios or dual-RF module combination scenarios) and displays invalid values for other types of cells.
  • UMTS UL Demodulation Mode must be set to 4-Channels Demodulation Mode or Self-adaption Demodulation Mode, and the uplink baseband equipment must contain at least one WBBPF or later boards.
  • The detection result will be cleared if the NodeB is reset or the cell status changes.

Output Description

Field Description

Local Cell ID

Indicates the local cell ID.

Co-Polarization Port Detection Completion Status

Indicates the completion status of co-polarization detection for the entire NodeB. Value NULL indicates that the NodeB has not started co-polarization detection. Value Incompleted indicates that the NodeB has not completed co-polarization detection. Value Completed indicates that the NodeB has completed co-polarization detection.

Cell Co-Polarization Port Detection Result

Indicates the antenna port co-polarization detection result for a cell. Value NULL indicates that co-polarization detection has not been executed for the cell. Value Completed indicates that the co-polarization detection result is valid for the cell. Value Detecting indicates that co-polarization detection is in progress for the cell. Value Not Supported indicates that co-polarization detection cannot be performed for the cell due to inappropriate configuration. Value Task Interrupt indicates that co-polarization detection is interrupted due to other tasks with higher priorities. Value Time Out indicates that co-polarization detection times out. That is, co-polarization detection is still in the incomplete state and no command is executed to stop the detection after the detection has been running for 24 hours.

Cell Co-Polarization Port Mapping

Indicates the co-polarization grouping of antenna ports on the RF channels. In scenarios with a 4T RF module, antenna ports 0, 1, 2, and 3 map RF channels A, B, C, and D. In scenarios with dual-RF module combination of 2T, antenna ports 0, 1, 2, and 3 map RF channels A, B, A, and B. Value 4T4P_abcd indicates that a cell has four TX channels and four antenna ports (a, b, c, and d) with signals of a and c and those of b and d separately belonging to a co-polarization group. For example, value 4T4P_0132 indicates that signals of antenna ports 0 and 3 and those of antenna ports 1 and 2 separately belong to a co-polarization group. Value NULL indicates invalid detection.
