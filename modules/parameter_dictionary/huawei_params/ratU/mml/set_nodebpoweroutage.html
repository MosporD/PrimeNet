Set NodeB ISD Switch (SET NODEBPOWEROUTAGE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to set an intelligent NodeB power-off switch.

Note

None.

Parameters

ID Name Description
ISDSW Intelligent Shutdown Switch

Meaning: Indicates whether to enable intelligent power-off. If this switch is turned on, some cells or all cells can be disabled when a Mains Input Out of Range alarm or a customized alarm is generated. If this switch is turned off, some cells or all cells cannot be disabled when a Mains Input Out of Range alarm or a customized alarm is generated.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
BAKPWRSAVPOLICY Standby Power Saving Policy

Meaning: Indicates the standby power saving policy when there is no mains power and storage batteries provide standby power. When different policies are used, level 1 shutdown delay and level 2 shutdown delay are automatically configured as follows: When this parameter is set to POLICY3, level 1 shutdown delay is 1800 seconds and level 2 shutdown is 36000 seconds. When this parameter is set to POLICY2, level 1 shutdown delay is 1800 seconds and level 2 shutdown is 7200 seconds. When this parameter is set to POLICY1, level 1 shutdown delay and level 2 shutdown delay are 60 seconds. When this parameter is set to CUSTOMIZED, level 1 shutdown delay and level 2 shutdown delay are customized.

GUI Value Range: CUSTOMIZED(CUSTOMIZED), POLICY1(POLICY1), POLICY2(POLICY2), POLICY3(POLICY3)

Unit: None

Actual Value Range: CUSTOMIZED, POLICY1, POLICY2, POLICY3

MML Default Value: None

Recommended Value: POLICY2(POLICY2)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When there is no mains power and storage batteries provide standby power, the higher the standby power saving policy level is, the longer the service duration of a NodeB is.

Applicable Mode: U
PHASE1PERIOD Level 1 Shutdown Delay

Meaning: Indicates the level 1 power-off delay. When the level 1 power-off delay is terminated, all non-reserved cells of the NodeB are disabled. Whether a cell is reserved or non-reserved can be set in the cell configuration.

GUI Value Range: 60~36000

Unit: s

Actual Value Range: 60~36000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBPOWEROUTAGE MO, the value of PHASE2PERIOD must be larger than or equal to PHASE1PERIOD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PHASE2PERIOD Level 2 Shutdown Delay

Meaning: Indicates the level 2 power-off delay. When the level 2 power-off delay is terminated, all reserved cells of the NodeB are disabled. Whether a cell is reserved or non-reserved can be set in the cell configuration.

GUI Value Range: 120~36000

Unit: s

Actual Value Range: 120~36000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBPOWEROUTAGE MO, the value of PHASE2PERIOD must be larger than or equal to PHASE1PERIOD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Modify NodeB ISD Switch:
SET NODEBPOWEROUTAGE: ISDSW=ON, BAKPWRSAVPOLICY=POLICY2;
