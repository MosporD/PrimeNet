Modify Iub Object (MOD IUB)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify a transmission object on the Iub interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before modifying the UPEPGROUPID, ensure that the EPGROUP MO referenced by the UPEPGROUPID in the IUB MO has been added successfully by running the ADD EPGROUP command.
  • Running this command interrupts ongoing services carried on the NodeB.
  • In the scenario where the UMTS and LTE networks share a main control board, EPGROUP MO referenced by UPEPGROUPID in the IUB MO must be different from EPGROUP MOs referenced by LTE interfaces.
  • When EPGROUP MO referenced by UPEPGROUPID in the IUB MO is the same as EPGROUP MO referenced by GSM interfaces, the Ping static detection function does not take effect.

Parameters

ID Name Description

Meaning: Indicates the IUB ID.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
UPEPGROUPID EndPoint Group ID

Meaning: Indicates the EndPoint Group ID used by Iub interface.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
USERLABEL User Label

Meaning: Indicates the user label of IUB.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
STATICCHKSW Static Check Switch

Meaning: Indicates whether to enable static Ping detection over the Iub interface. If this parameter is set to ICMP(ICMP), static ICMP Ping detection is enabled over the Iub interface. If this parameter is set to OFF(OFF), static Ping detection is disabled over the Iub interface.

GUI Value Range: OFF(OFF), ICMP(ICMP)

Unit: None

Actual Value Range: OFF, ICMP

MML Default Value: None

Recommended Value: When EPGROUP MO referenced by UPEPGROUPID in the IUB MO contains multiple user-plane hosts and the route is the source address route not configured in active/standby mode, it is recommended that this parameter be set to ICMP(ICMP). In other scenarios, the recommended value is OFF(OFF).

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To modify Iub Object:
MOD IUB: IUBID=30, UPEPGROUPID=50, USERLABEL="umts";
