Set NodeB Reserved Para (SET NODEBRSVDPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command sets the reserved field for the NodeB. The reserved field is used as the switch for a feature added in the future. This command requires support from the patch to be applied. If the patch contains a new feature, the reserved field can be used to determine whether to use the new feature.

Note

To avoid messing up future upgrades, seek help from Huawei engineers if you feel uncertain about how to use this command.
