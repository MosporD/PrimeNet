List algorithm parameter (LST ULOCELLALGPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to query the algorithm parameters of a specific cell or all cells.

Note

None.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Use the following command to List algorithm parameters:
LST ULOCELLALGPARA: ULOCELLID=1961;

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

RTWP Abnormal SIR Target Adjustment Switch

Indicates the RTWP Abnormal SIR target Adjustment Switch.

Switch for RTWP broadcasting optimization in SIB7

Specifies the algorithm for preventing RTWP peak on the RACH channel.

Anti-Antenna Imbalance Algorithm Switch

Indicates whether to enable anti-antenna imbalance. If this switch is turned on, the RTWP value and uplink load factor are corrected according to the RTWP values of each antenna and the multipath search energy.

CQI Sample Period(s)

Indicates the CQI information collection period. The CQI information collected is only used for geographical display. When CQISAMPLEPERIOD is set to 0, the NodeB does not collect CQI information.

CQI Collection User Number

Indicates the number of users whose CQI information needs to be collected for geographical display of the CQI information.

High-Speed Search Algorithm Optimization Switch

Indicates whether to enable high-speed search algorithm optimization.

DPCH Maximum Power Restriction Algorithm Switch

Whether to enable the DPCH maximum transmit power restriction algorithm. When this switch is turned on, the NodeB configures the maximum transmit power of the associated DPCH based on whether data is transmitted on the associated DPCH for HSDPA services. When this switch is turned off, the maximum transmit power of the associated DPCH for HSDPA services is set to the default value.

The Load State to Control DPCH Maximum Power Restriction Algorithm

Load state when the DPCH maximum power restriction algorithm takes effect. When the downlink non-HSPA power load is in the load state set by this parameter or a heavier load state, the maximum DPCH power restriction algorithm is triggered.

Based on load level in ascending order (from light load to heavy load), the downlink non-HSPA power load states are as follows:

DlLightState: indicates the downlink resource light load state threshold 0%.

DlNormalState: indicates the downlink resource normal load state threshold 30%.

DlLoadedState: indicates the downlink resource light congestion state threshold 50%.

DlHeavyState: indicates the downlink resource severe congestion state threshold 70%.

DlOverloadState: indicates the downlink resource extreme congestion state threshold 95%. The following provides the method for determining the downlink non-HSPA power load state:

If the non-HSPA power load for a cell exceeds the threshold corresponding to the load state when the DPCH maximum power restriction algorithm takes effect plus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a heavier load state. In this case, the DPCH maximum power restriction algorithm is triggered. Note that 10% is not added when the downlink non-HSPA power load is in the downlink resource extreme congestion state.

If the non-HSPA power load for a cell decreases below the threshold corresponding to the load state when the DPCH maximum power restriction algorithm takes effect minus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a lighter load state. In this case, the DPCH maximum power restriction algorithm is not triggered. Note that 10% is not subtracted when the downlink non-HSPA power load is in the downlink resource light load state.

Maximum RTWP Value in SIB7 Broadcast to the UE(dB)

Indicates the maximum RTWP value in the system information block 7 (SIB7) broadcast to the UE, in the unit of dBm. The broadcast RTWP value does not exceed -113 plus the value of Sib7MaxRtwp. When this parameter is set to 0, the RTWP value is not calculated using the formula.

Uplink Control Channel OLPC Switch

Indicates whether to enable uplink control channel-based outer loop power control (OLPC).

Uplink Control Channel OLPC Load High Threshold(%)

Indicates the air interface-based high-load threshold for uplink control channel-based OLPC.

Uplink Control Channel OLPC Load Low Threshold(%)

Indicates the air interface-based low-load threshold for uplink control channel-based OLPC.

Switch for DPCH Power Control Algorithm Based on Radio Quality

Indicates whether to enable the DPCH power control algorithm based on radio quality. If this switch is turned on, the DPCH power control algorithm based on radio quality is enabled. If this switch is turned off, the DPCH power control algorithm based on radio quality is disabled.

Load State for DPCH Power Control Algorithm Based on Radio Quality

Specifies the load state in which the DPCH/F-DPCH power control algorithm based on radio quality takes effect. When the downlink non-HSPA power load is in the load state set by this parameter or a heavier load state, the DPCH/F-DPCH power control algorithm based on signal quality is triggered.

Based on load level in ascending order (from light load to heavy load), the downlink non-HSPA power load states are as follows:

DlLightState: indicates the downlink resource light load state threshold 0%.

DlNormalState: indicates the downlink resource normal load state threshold 30%.

DlLoadedState: indicates the downlink resource light congestion state threshold 50%.

DlHeavyState: indicates the downlink resource severe congestion state threshold 70%.

DlOverloadState: indicates the downlink resource extreme congestion state threshold 95%. The following provides the method for determining the downlink non-HSPA power load state:

If the non-HSPA power load for a cell exceeds the threshold corresponding to the load state when the DPCH/F-DPCH power control algorithm based on radio quality takes effect plus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a heavier load state. In this case, the DPCH/F-DPCH power control algorithm based on radio quality is triggered. Note that 10% is not added when the downlink non-HSPA power load is in the downlink resource extreme congestion state.

If the non-HSPA power load for a cell decreases below the threshold corresponding to the load state when the DPCH/F-DPCH power control algorithm based on radio quality takes effect minus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a lighter load state. In this case, the DPCH/F-DPCH power control algorithm based on radio quality is not triggered. Note that 10% is not subtracted when the downlink non-HSPA power load is in the downlink resource light load state.

Power Offset for DPCH Power Control Algorithm Based on Radio Quality(0.1dB)

Specifies the offset added to the maximum transmit power of the associated DPCH after the power is adjusted by using the DPCH power control algorithm based on radio quality. Relationship between the GUI value and actual value: Actual value = (GUI value - 50) x 0.1.

HSDPA Inter-Cell Power Sharing Switch

Indicates the HSDPA inter-cell power sharing switch. If this parameter is set to ON, power sharing groups are automatically established between the cells that have this switch turned on and meet HSDPA inter-cell power sharing requirements. The groups allow for bidirectional power sharing.

Sharing Power Margin(%)

Indicates the power sharing margin. The margin is used to compensate for the required power for R99 users due to delayed power sharing and compensate for the power for the burst services in the HSDPA cell that provides power for sharing. This parameter is used in configuring the Dynamic Power Sharing in Multi-Carriers and HSDPA Inter-Cell Power Sharing features.

Max Sharing Power Ratio(%)

Indicates the maximum proportion of the available power that can be shared between two cells. The proportion is the ratio of the available power that a local cell can provide or request for sharing to the maximum transmit power of the local cell. This parameter is used in configuring the Dynamic Power Sharing in Multi-Carriers and HSDPA Inter-Cell Power Sharing features.

Optimization Switch for SRB over HSDPA

Indicates the SRB over HSDPA KPI performance optimization switch.

Maximum Downlink Power Restriction Enhancement Threshold(%)

Indicates the cell load threshold for the maximum downlink DPCH power restriction enhancement algorithm. Value 255 means to disable the maximum downlink DPCH power restriction enhancement algorithm; a value other than 255 indicates the cell load threshold for enabling this algorithm.

Trigger Threshold for Single HARQ Based on Load(dB)

Indicates the threshold for triggering a single HARQ process based on load.

R99 Cell to HSDPA Cell Power Sharing Switch

Indicates the R99-to-HSDPA cell power sharing switch. If this parameter is set to ON, power sharing groups are automatically established between the cells that have this switch turned on and meet R99-to-HSDPA cell power sharing requirements. The groups allow for unidirectional power sharing from R99 cells to HSDPA cells. If multiple R99 cells and HSDPA cells meet the power sharing requirements, unidirectional power sharing is preferentially achieved between R99 cells and HSDPA cells having smaller cell IDs.

HSDPA Inter-Cell Realtime Power Sharing Switch

Indicates the HSDPA inter-cell real-time power sharing switch. If this parameter is set to ON, power sharing groups are automatically established between the cells that have this switch turned on and meet HSDPA inter-cell real-time power sharing requirements. The groups allow for bidirectional power sharing. In a real-time power sharing group, a cell can use the available power resources of multiple cells and multiple cells can use the available power resources of a cell.

DPCH TPC Power Adjustment Switch

Indicates whether to enable DPCH TPC power adjustment. If this parameter is set to ON, the NodeB optimizes downlink DPCH TPC transmit power for HSDPA UEs whose SRBs are carried over the DCH based on downlink non-HSPA power load of the cell. If this parameter is set to OFF, the downlink DPCH TPC transmit power configured on the RNC applies for these UEs.

HSDPA Cell Throughput Threshold(kbps)

Indicates the HSDPA cell throughput threshold. This parameter is specified for measuring counters when the HSDPA cell throughput is less than a specified threshold. A larger parameter value leads to more samples used for the measurement. A smaller parameter value leads to fewer samples used for the measurement. You are advised to configure this parameter based on site requirements and the average HSDPA cell throughput of the live network. The average HSDPA cell throughput is calculated using the following formula: VS.HSDPA.DataOutput.Traffic / [(VS.DataTtiRatio.Mean - VS.HSDPA.InactiveDataTtiRatio.Mean) x SP x 60]. SP refers to the measurement period and is in the unit of minute.

HSDPA Power Margin Cancellation Switch

Indicates the HSDPA power margin cancellation switch. If this parameter is set to ON, the HSDPA power margin cancellation function is enabled.

Switch of Invalid Radio-Quality-based DPCH Power Control Algorithm for SHO Users

Indicates whether the radio-quality-based DPCH power control algorithm does not take effect for soft handover users or softer handover users. When the parameter is set to ON, the radio-quality-based DPCH power control algorithm does not take effect for soft handover users or softer handover users. When the parameter is set to OFF, the radio-quality-based DPCH power control algorithm takes effect for soft handover users or softer handover users.

UL Carrier Level Scheduling Switch

Indicates the switch for uplink carrier-level scheduling. When this switch is turned off, the scheduling priority of a carrier for an uplink multi-carrier user is calculated based on the sum of the rates of the two carriers. When this switch is turned on, the scheduling priority of a carrier for an uplink multi-carrier user is calculated based on the rate of this carrier.

Enhanced CQI-based DPCH Power Control Switch

Indicates the switch for enhanced DPCH power control based on radio quality. When the switch is set to ON, the CQI-based F-DPCH power control algorithm is enabled, and the scenarios in which CQI-based DPCH power control takes effect are expanded. When the switch is set to OFF, the CQI-based F-DPCH power control algorithm is disabled, and the scenarios in which CQI-based DPCH power control takes effect remain unchanged.

Power Offset of F-DPCH Power Control Based on Radio Quality(0.1dB)

Indicates the offset added to the maximum transmit power of the F-DPCH after the power adjustment by using the F-DPCH power control algorithm based on radio quality. Relationship between the GUI value and actual value: Actual value = (GUI value - 50) x 0.1.

Voice Coverage Improvement by Advanced Demodulation Switch

Indicates the switch for the Voice Coverage Improvement by Advanced Demodulation feature.

SRB over HSDPA Measurement Optimization Switch

Indicates the switch for SRB over HSDPA measurement optimization. When this parameter is set to ON, MAC-hs/ehs PDUs with TRBs and mixed SRBs and TRBs are measured. When this parameter is set to OFF, MAC-hs/ehs PDUs with SRBs, TRBs, and mixed SRBs and TRBs are measured.

Enhanced Turbo IC Switch

Indicates the switch for the enhanced Turbo IC feature.

AMR Voice Quality Improvement Based on PLVA Switch

Indicates the switch for AMR Voice Quality Improvement Based on PLVA in a cell. When this switch is turned on, the cell supports the AMR Voice Quality Improvement Based on PLVA function. When this switch is turned off, the cell does not support the AMR Voice Quality Improvement Based on PLVA function.

Enhanced Inter-NodeB Uplink CoMP Switch

Indicates the switch for the Enhanced Inter-NodeB Uplink CoMP (Joint Reception). When this switch is turned on, the Enhanced Inter-NodeB Uplink CoMP (Joint Reception) feature takes effect, improving the demodulation and decoding performance. When this switch is turned off, the Enhanced Inter-NodeB Uplink CoMP (Joint Reception) feature does not take effect.

Cell Algorithm Optimization Switch

Indicates the switch for cell algorithm optimization. UNSTABLEUSERSCHOPTSW: This option is used to control the HSDPA scheduling optimization function for UEs in the unstable state. When this option is selected, the HSDPA scheduling mechanism is optimized in unstable scenarios such as H2F state transition and call reestablishment. When this option is deselected, the optimized HSDPA scheduling mechanism does not take effect.

Co-Polarization Port Mapping Configuration

Indicates the co-polarization mapping configuration of antenna ports onto the RF channels in a cell. Value 4T4P_abcd indicates that a cell has four TX channels and four antenna ports (a, b, c, and d) with signals of a and c and those of b and d separately belonging to a co-polarization group. For example value 4T4P_0132 indicates that signals of antenna ports 0 and 3 and those of antenna ports 1 and 2 separately belong to a co-polarization group. This parameter takes effect only in scenarios with a single 4T RF module but not in scenarios with dual-RF module combination of 2T.

Machine Learning based PCPICH Power Optimization Switch

Indicates whether the Machine Learning based PCPICH Power Optimization feature takes effect. When this switch is turned on, the Machine Learning based PCPICH Power Optimization feature takes effect, and the RNC adaptively adjusts the pilot power based on the cell load and coverage. When this switch is turned off, the Machine Learning based PCPICH Power Optimization feature does not take effect, and the RNC does not adjust the pilot power.

OM Switch

Indicates whether to enable the operation and maintenance functions of the NodeB. CELLHSPAFULLBUFFERSW(Cell HSPA Full Buffer O&M Switch): When this option is selected, the NodeB checks the buffered data volume of UEs. If the buffered data volume of a UE is greater than the transmission capability of the air interface, the NodeB identifies the UE as a full buffer UE and sends the identification result to the RNC over the Iub interface for full buffer-related measurement. When this option is deselected, this function does not take effect.

RRM Parameters Optimization Based on Machine Learning Switch

Indicates whether the RRM Parameters Optimization Based on Machine Learning feature takes effect. When this parameter is set to ON, the RRM Parameters Optimization Based on Machine Learning feature takes effect. In this case, the network side performs policy optimization in the compressed mode, soft handover threshold optimization, and uplink target RoT optimization. When this parameter is set to OFF, RRM Parameters Optimization Based on Machine Learning does not take effect.

Spectrum Share Capacity Optimization Switch

Indicates whether the spectrum sharing capacity optimization algorithm for UMTS and LTE Spectrum Sharing Phase 2 or UMTS and LTE Spectrum Sharing Based on DC-HSDPA takes effect. When this parameter is set to ON(ON), the cell spectrum sharing capacity optimization algorithm takes effect. When this parameter is set to OFF(OFF), the cell spectrum sharing capacity optimization algorithm does not take effect.

Capacity Optimization Load Threshold(%)

Indicates the threshold for enabling capacity optimization for UMTS and LTE Spectrum Sharing Phase 2 or UMTS and LTE Spectrum Sharing Based on DC-HSDPA. When UMTS and LTE Spectrum Sharing Phase 2 is enabled, if the downlink TCP load of a cell is no less than this threshold, the UMTS side informs that the LTE side cannot use the shared spectrum or can use only some shared spectrum. If the downlink TCP load of a cell is less than this threshold, the UMTS side informs that the LTE side can use all the shared spectrum. When UMTS and LTE Spectrum Sharing Based on DC-HSDPA is enabled, in the HSDPA multi-carrier cell group where the spectrum sharing cell is located, if the downlink TCP load of the primary carrier cell is no less than this threshold and the proportion of DC-HSDPA UEs is no less than the proportion threshold (the value of DCHSDPAUERATIOTHD) of DC-HSDPA UEs, the UMTS side informs that the LTE side cannot use the shared spectrum or can use only some shared spectrum. If the downlink TCP load of the primary carrier cell is less than this threshold or the proportion of DC-HSDPA UEs is less than the proportion threshold (the value of DCHSDPAUERATIOTHD) of DC-HSDPA UEs, the UMTS side informs that the LTE side can use all the shared spectrum.

Dynamic PCPICH Power Switch

Indicates whether the dynamic PCPICH power adjustment algorithm for UMTS and LTE Spectrum Sharing Phase 2 takes effect. When this parameter is set to ON, the cell dynamic pilot power adjustment algorithm takes effect. When this parameter is set to OFF, the cell dynamic pilot power adjustment algorithm does not take effect.

Cell Sw-off Based on Auto Co-cvge Ident Switch

Indicates whether cell shutdown based on automatic co-coverage identification takes effect. If this parameter is set to ON, cell shutdown based on automatic co-coverage identification takes effect. In this case, the RAN identifies co-coverage cells and determines whether to shut down cells in a frequency band based on the status of co-coverage cells. If this parameter is set to OFF, cell shutdown based on automatic co-coverage identification does not take effect.

Core Bandwidth Sharing Outage Mode

Indicates the mode of disabling spectrum sharing based on the proportion of abnormal UEs. When this parameter is set to FIXED, UMTS cell notifies LTE cell not to use the UMTS core bandwidth (the bandwidth within 1.92 MHz from the UMTS center frequency) for 2 ms within a 6-ms period. When this parameter is set to AUTO, UMTS cell checks the proportion of abnormal UEs. If the proportion exceeds the threshold, UMTS cell notifies LTE cell not to use the UMTS core bandwidth for 2 ms within a 6-ms period. If the proportion is less than the threshold, UMTS cell notifies that LTE cell can use the UMTS core bandwidth. When this parameter is set to OFF, LTE cell can use the UMTS core spectrum.

Shared Bandwidth Periodic Shrink Time Ratio(%)

Indicates the percentage of time for rolling back the downlink adaptive filter within a one-second period for a UMTS cell when the UMTS and LTE Spectrum Sharing Phase 2 feature is enabled. When this parameter is set to default value 0, the function of rolling back the downlink adaptive filter bandwidth with a one-second period is disabled. When this parameter is set to a value other than 0 (for example, X), this function is enabled, and UMTS cell reduces the spectrum bandwidth shared with LTE cell continuously for X*10 ms within a one-second period. This rolls back the downlink adaptive filter bandwidth to a smaller value.

Initial Single HARQ Demodulation Optimization Switch for HSUPA 2ms TTI UEs

Indicates whether to enable the algorithm for optimizing the demodulation of initial single HARQ for HSUPA 2 ms TTI UEs. When this parameter is set to OFF, the algorithm for optimizing the demodulation of initial single HARQ for HSUPA 2 ms TTI UEs is disabled. When this parameter is set to ON, the algorithm for optimizing the demodulation of initial single HARQ for HSUPA 2 ms TTI UEs is enabled, improving the demodulation performance and reducing the bit error rate.

Voice Quality Improvement in CloudAIR Scenario Switch

Indicates whether to enable the Voice Quality Improvement in CloudAIR Scenario feature. If this switch is turned on, the NodeB compensates the maximum and minimum downlink transmit power for voice services based on the shared UMTS bandwidth in CloudAIR scenarios to improve downlink voice quality. If this switch is turned off, the NodeB does not compensate the maximum and minimum downlink transmit power for voice services in CloudAIR scenarios.

DC-HSDPA UEs Ratio Threshold(%)

Indicates the DC-HSDPA UEs ratio threshold of the UMTS and LTE Spectrum Sharing Based on DC-HSDPA feature. In the HSDPA multi-carrier cell group where the spectrum sharing cell is located, if the downlink TCP load of the primary carrier cell is no less than the capacity optimization load threshold (specified by CAPOPTLOADTHD) and the DC-HSDPA UEs ratio of the cell is no less than the value of this parameter, the UMTS side informs that the LTE side cannot use the shared spectrum or can use only some shared spectrum. If the downlink TCP load of the primary carrier cell is less than the capacity optimization load threshold (specified by CAPOPTLOADTHD) or the DC-HSDPA UEs ratio of the cell is less than the value of this parameter, the UMTS side informs that the LTE side can use all the shared spectrum.

Cell Digital Tilt(degree)

Indicates the digital tilt of a cell. This parameter takes effect only for cells served by the AAU5726.
