List NodeB ISD Switch (LST NODEBPOWEROUTAGE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list an intelligent NodeB power-off switch.

Note

None.

Parameters

None.

Example

List NodeB ISD Switch:
LST NODEBPOWEROUTAGE:;
The result is shown as follows:
+++    HUAWEI        2014-01-05 15:51:12
O&M    #8786
%%LST NODEBPOWEROUTAGE:;%%
RETCODE = 0  Operation succeeded.

List NodeB ISD Switch
---------------------
Intelligent Shutdown Switch  =  OFF
Standby Power Saving Policy  =  CUSTOMIZED
  Level 1 Shutdown Delay(s)  =  60
  Level 2 Shutdown Delay(s)  =  120
(Number of results = 1)


---    END

Output Description

Field Description

Intelligent Shutdown Switch

Indicates whether to enable intelligent power-off. If this switch is turned on, some cells or all cells can be disabled when a Mains Input Out of Range alarm or a customized alarm is generated. If this switch is turned off, some cells or all cells cannot be disabled when a Mains Input Out of Range alarm or a customized alarm is generated.

Standby Power Saving Policy

Indicates the standby power saving policy when there is no mains power and storage batteries provide standby power. When different policies are used, level 1 shutdown delay and level 2 shutdown delay are automatically configured as follows: When this parameter is set to POLICY3, level 1 shutdown delay is 1800 seconds and level 2 shutdown is 36000 seconds. When this parameter is set to POLICY2, level 1 shutdown delay is 1800 seconds and level 2 shutdown is 7200 seconds. When this parameter is set to POLICY1, level 1 shutdown delay and level 2 shutdown delay are 60 seconds. When this parameter is set to CUSTOMIZED, level 1 shutdown delay and level 2 shutdown delay are customized.

Level 1 Shutdown Delay(s)

Indicates the level 1 power-off delay. When the level 1 power-off delay is terminated, all non-reserved cells of the NodeB are disabled. Whether a cell is reserved or non-reserved can be set in the cell configuration.

Level 2 Shutdown Delay(s)

Indicates the level 2 power-off delay. When the level 2 power-off delay is terminated, all reserved cells of the NodeB are disabled. Whether a cell is reserved or non-reserved can be set in the cell configuration.
