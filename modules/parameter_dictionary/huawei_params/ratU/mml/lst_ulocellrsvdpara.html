List Local Cell Reserved Para (LST ULOCELLRSVDPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command queries the field reserved for the local cell.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.list the field reserved for all the local cells:
LST ULOCELLRSVDPARA:;
The result is shown as follows:
+++    HUAWEI        2016-11-29 09:09:55
O&M    #537931110
%%LST ULOCELLRSVDPARA:;%%
RETCODE = 0  Operation succeeded.
