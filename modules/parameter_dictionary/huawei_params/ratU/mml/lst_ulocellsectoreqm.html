List Local Cell Sector Equipment (LST ULOCELLSECTOREQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list sector equipment information of local cell.

Note

None.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.list sector equipment information of all local cell:
LST ULOCELLSECTOREQM:;
The result is shown as follows:
+++    DBS3900_221        2016-04-17 14:14:33
TRAFFIC    #537919510
%%LST ULOCELLSECTOREQM:;%%
RETCODE = 0  Operation succeeded.

List Local Cell Sector Equipment
--------------------------------
Local Cell ID  Sector Equipment ID  Max Output Power(0.1dBm)  Sector Equipment Property

22100          0                    65535                     Normal                   
22100          1                    65535                     Assistance                      
22101          2                    65535                     Normal                   
22101          3                    65535                     Assistance                      
(Number of results = 4)

2.list sector equipment information of No.22101 local cell:
LST ULOCELLSECTOREQM: ULOCELLID=22101;
The result is shown as follows:

TRAFFIC    #537919511
%%LST ULOCELLSECTOREQM: ULOCELLID=22101;%%

--------------------------------
Local Cell ID  Sector Equipment ID  Max Output Power(0.1dBm)  Sector Equipment Property

22101          2                    65535                     Normal                   
22101          3                    65535                     Assistance                      
(Number of results = 2)


---    END

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

Sector Equipment ID

Indicates the number of sector equipment used for the local cell.

Max Output Power(0.1dBm)

Indicates the maximum output power of the sector equipment.

Sector Equipment Property

Indicates the property of sector equipment of a local cell.
