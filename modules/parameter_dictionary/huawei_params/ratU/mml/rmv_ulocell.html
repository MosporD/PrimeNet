Remove Local Cell (RMV ULOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to delete a specified local cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the local cell has been configured in UL CoMP cell groups or cell groups for Coverage Expansion Under Interference, remove all such cell groups before running this command. Otherwise, this command fails to be executed.
  • If the local cell has been added to multiple-carrier cell groups, remove the local cell from all such cell groups or remove all such cell groups containing the local cell before running this command. Otherwise, this command fails to be executed.
  • Removing the local cell leads to interrupted services borne on this cell.
  • If UL Resource Work Mode is AUTO_CHAIN or MANUAL_CHAIN, running this command interrupts ongoing services carried by other cells served by the NodeB for one to two minutes.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove the No.14600 local cell:
RMV ULOCELL: ULOCELLID=14600;
