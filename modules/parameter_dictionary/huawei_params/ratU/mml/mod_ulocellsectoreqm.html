Modify Local Cell Sector Equipment (MOD ULOCELLSECTOREQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify sector equipment information of local cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The value of MAXPWR cannot exceed the maximum power for a cell when the value is not 65535.
  • Setting power for each ULOCELLSECTOREQM is not recommended.
  • In a PSP cell, when one sector equipment serves as the main transmit equipment, the maximum transmit power of the sector equipment can be set to the maximum transmit power of the PSP cell, and the maximum transmit power of the other one is set to the default value 65535.
  • This command can be executed to modify the maximum transmit power of the sector equipment in the local normal cell, distributed cell, multi-RRU cell with independent demodulation, and mixed multi-RRU cell.
  • Executing this command interrupts ongoing services for less than 1 minute.

Example

Modify sector equipment information of local cell:
MOD ULOCELLSECTOREQM: ULOCELLID=3000, SECTOREQMID=0, MAXPWR=500;
