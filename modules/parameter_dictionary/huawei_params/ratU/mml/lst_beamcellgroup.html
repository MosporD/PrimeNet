List Beam Cell Group (LST BEAMCELLGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list the configurations of beam cell group.

Note

None.

Parameters

ID Name Description
BEAMCELLGROUPID Beam Cell Group ID

Meaning: Indicates the ID of beam cell group.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1. To list the configurations of all beam cell groups, run the following command: 
LST BEAMCELLGROUP:;
The result is shown as follows:
+++    NodeB_1_0_0        2017-09-19 22:16:49
O&M    #537919502
%%LST BEAMCELLGROUP:;%%
RETCODE = 0  Operation succeeded.

List Beam Cell Group
--------------------
Beam Cell Group ID  Beam Cell Group Type  Beam Option Period

0                   Normal Beam           NULL              
1                   Massive Beam 4T4R     NULL              
2                   Massive Beam 8T8R     10min             
(Number of results = 3)


---    END

2. To list the configurations of the beam cell group with the parameter as follows: Beam Cell Group ID: 2, run the following command: 
LST BEAMCELLGROUP: BEAMCELLGROUPID=2;
The result is shown as follows:
+++    NodeB_1_0_0        2017-09-19 22:17:03
O&M    #537919504
%%LST BEAMCELLGROUP: BEAMCELLGROUPID=2;%%
RETCODE = 0  Operation succeeded.

List Beam Cell Group
--------------------
  Beam Cell Group ID  =  2
Beam Cell Group Type  =  Massive Beam 8T8R
  Beam Option Period  =  10min
(Number of results = 1)


---    END

Output Description

Field Description

Beam Cell Group ID

Indicates the ID of beam cell group.

Beam Cell Group Type

Indicates the type of beam cell group.

Beam Option Period

Indicates the beam selection period.
