List Ueqosenhancepara (LST NODEBUEQOSENHANCE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to query the burst packet size of gold, silver, and copper UEs and parameter settings of the enhancement of the Improvement of User Experience in Low Traffic Service feature.

Note

None

Parameters

None.

Example

Use the following command to query the burst packet size of gold, silver, and copper UEs and the configuration information of low-traffic experience enhancement:
LST NODEBUEQOSENHANCE:;
The result is shown as follows:

Output Description

Field Description

UL Gold UE Burst Packet Size(100byte)

Indicates the burst packet size of UL gold UE.

UL Silver UE Burst Packet Size(100byte)

Indicates the burst packet size of UL silver UE.

UL Copper UE Burst Packet Size(100byte)

Indicates the burst packet size of UL copper UE.

DL Gold UE Burst Packet Size(100byte)

Indicates the burst packet size of DL gold UE.

DL Silver UE Burst Packet Size(100byte)

Indicates the burst packet size of DL silver UE.

DL Copper UE Burst Packet Size(100byte)

Indicates the burst packet size of DL copper UE.

UPA User Number Threshold for Enhanced Low Traffic

Indicates the UPA UE quantity threshold for the low-traffic experience enhancement function to take effect. When the number of UPA UEs in a cell is less than or equal to the threshold, the low-traffic experience enhancement function takes effect. When the number of UPA UEs in a cell is greater than the threshold or the threshold is set to 0, the low-traffic experience enhancement function does not take effect.

Max UPA 10ms TTI TB Size for Enhanced Low Traffic(bit)

Indicates the maximum TB size for scheduling grant of UPA 10 ms TTI UEs when the low-traffic experience enhancement function takes effect.

Max UPA 2ms TTI TB Size for Enhanced Low Traffic(bit)

Indicates the maximum TB size for scheduling grant of UPA 2 ms TTI UEs when the low-traffic experience enhancement function takes effect.
