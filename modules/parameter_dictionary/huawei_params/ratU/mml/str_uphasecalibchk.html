Start Phase Calibration Capability Detection (STR UPHASECALIBCHK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to enable the phase calibration capability detection function.

Note

  • This command applies only to 4T4R cells (excluding cells that use the AAU5973e) where the UMTS 4T Beam Optimization capability is available and two 2T RF modules are combined.
  • This command fails to be executed when the antenna port co-polarization detection function has been started using the STR UCOPOLARPORTDET command.

Parameters

None.

Example

1. Start phase calibration capability detection:
STR UPHASECALIBCHK:;
