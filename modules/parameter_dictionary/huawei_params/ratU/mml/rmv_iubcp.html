Remove Iub Control Port (RMV IUBCP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove an Iub control port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Running this command interrupts ongoing services carried on the NodeB.

Parameters

ID Name Description
CPPT Port Type

Meaning: Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.

GUI Value Range: NCP(NCP Port), CCP(CCP Port)

Unit: None

Actual Value Range: NCP, CCP

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of IUBCP MOs under which CPPT is set to CCP cannot exceed 96.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
CPPN CP Port No.

Meaning: Indicates the number of the Iub control port.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the flag of the transport channel to which an Iub control port belongs.

GUI Value Range: MASTER(MASTER), SLAVE(SLAVE)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(MASTER)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove an Iub control port with the parameters as follows: Port Type: CCP, CP Port No.: 0: 
RMV IUBCP: CPPT=CCP, CPPN=0, BELONG=MASTER;
