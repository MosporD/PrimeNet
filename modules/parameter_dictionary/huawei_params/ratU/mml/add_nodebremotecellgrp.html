Add Remote Cell Group (ADD NODEBREMOTECELLGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to add a resource group of remote coverage cells.

Note

The resource group of remote coverage cells refers to that cells in the resource group enable the remote coverage. A single resource group of remote coverage cells supports a maximum of three cells for remote coverage. If the user needs to configure more than three cells for remote coverage and the system has such a capacity, the user needs to add the resource group for the remote coverage cells. The number of cells in a remote coverage cell group must be less than or equal to the number of remote coverage cells that can be carried by the DSP in the group.

Parameters

ID Name Description
REMOTECELLGRPINDEX Remote Cell Group No.

Meaning: Indicates the number of the resource group of remote coverage cells.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
REMOTECELLGRPNAME Remote Cell Group Name

Meaning: Indicates the name of the resource group of remote coverage cells.

GUI Value Range: 1~31 characters

Unit: None

Actual Value Range: 1~31 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBREMOTECELLGRP MO, the value of REMOTECELLGRPNAME cannot contain the following invalid characters: <>!?\.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Add a resource group of remote coverage cells named "JINMAO Mansion" and specifying the number of the group as "1":
ADD NODEBREMOTECELLGRP: REMOTECELLGRPINDEX =1, REMOTECELLGRPNAME ="JINMAO Mansion";
