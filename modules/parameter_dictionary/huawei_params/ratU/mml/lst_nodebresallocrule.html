List Resource Allocate Rule (LST NODEBRESALLOCRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the current NodeB resources allocation mode.

Note

None

Parameters

None.

Example

Use the following command to list the current NodeB resources allocation mode: 
LST NODEBRESALLOCRULE:;
The result is shown as follows:
+++    HUAWEI        2019-12-14 17:21:33
O&M    #7342
%%LST NODEBRESALLOCRULE:;%%
RETCODE = 0  Operation succeeded.

List Resource Allocate Rule
---------------------------
                             Resource Allocate Rule  =  Handover Performance First Rule
                           Auto Rebuild Cell Switch  =  OFF
                           Cs User Number Threshold  =  0
                           Ps User Number Threshold  =  0
Immediate Rebuilding Switch for Degraded Multi-Cell  =  OFF
      Immediate Rebuilding Switch for Degraded Cell  =  Spectrum-related Features or Functions:OFF
(Number of results = 1)


---    END

Output Description

Field Description

Resource Allocate Rule

Indicates the BB Resource Allocate Rule. Handover Performance First Rule: The local cells of the same frequency are allocated to the same processing chip. Capacity First Rule: The local cells are allocated to different processing chips in order that processing chips are used averagely.

Auto Rebuild Cell Switch

Indicates the automatic cell reestablishment switch.

Cs User Number Threshold

Indicates the threshold for the number of CS users. If the number of CS users in the downlink resource group is smaller than or equal to the threshold, cells are reestablished automatically.

Ps User Number Threshold

Indicates the threshold for the number of PS users. If the number of CELL_DCH PS users in the downlink resource group is smaller than or equal to the threshold, cells are reestablished automatically.

Immediate Rebuilding Switch for Degraded Multi-Cell

Indicates whether a cell needs to be reestablished immediately after the DC/MC degrades.

Immediate Rebuilding Switch for Degraded Cell

Indicates whether to enable immediate reestablishment in the case of cell derating. SPECTRUMFEAORFUNCTION(Spectrum-related Features or Functions) indicates that all cells under the base station are reestablished if any of the cells experiences derating of spectrum-related features or functions and the remaining resources of the base station are sufficient. Spectrum-related features or functions are as follows:

WRFD-191209 GU@5 MHz Phase 1

WRFD-200201 GU@5 MHz Phase 2

WRFD-210203 DC-HSDPA Shared with GSM

MRFD-130212 UMTS and LTE Spectrum Sharing (UMTS)

MRFD-150212 UMTS and LTE Spectrum Sharing Phase 2 (UMTS)

MRFD-150211 UMTS and LTE Zero Bufferzone (UMTS)

MRFD-151212 UMTS and LTE Spectrum Sharing Based on DC-HSDPA (UMTS)

WRFD-191212 Dual Carriers over Narrowband

GU 0 Buffer Zone
