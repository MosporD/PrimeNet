List NodeB Algorithm Parameter (LST NODEBALGPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list NodeB algorithm parameter.

Note

None.

Parameters

None.

Example

List NodeB algorithm parameter:
LST NODEBALGPARA:;
The result is shown as follows:

Output Description

Field Description

2ms User Minimum Admission CE

Indicates the minimum number of CEs for admitting 2 ms users when CE Overbooking is enabled.

Hsdpa Scheduler Pool Switch

Indicates whether to enable HSDPA scheduler pool.

Power Configuration Check Switch

Indicates whether to enable the power configuration check.

CCPIC Phase SIR Target Correction SW

Indicates whether to correct the SIR outer loop power control target value when CCPIC is enabled. If CCPIC Phase 2 is enabled, this parameter controls only the value corresponding to CCPIC phase 2. If CCPIC Phase 3 is enabled, this parameter controls both the value corresponding to CCPIC phase 2 and the value corresponding to CCPIC phase 3.

UL Resource Work Mode

Indicates the uplink resource allocation mode of a NodeB. If NORMAL is selected, the same uplink resources are allocated to one set of uplink baseband equipment. If AUTO_CHAIN is selected, the uplink resources allocated to one set of uplink baseband equipment are connected in chain mode to share the resources. If MANUAL_CHAIN is selected, the uplink resources can be manually specified for the uplink baseband equipment. If Normal Extension is selected, cell specifications can be expanded in the uplink baseband equipment configured with both the UBBP board in UMTS mode and the WBBP board.

CNBAP Capacity Extension Using UTRPc

Indicates whether to extend the CNBAP capacity using the UTRPc. When the value of this parameter changes, the base station needs to be manually reset.

RTWP Quantitative Accuracy Optimization

Indicates the RTWP quantitative accuracy optimization switch. It improves RTWP accuracy for multicarrier RRU3804 modules or WRFUs. This parameter is recommended to set to OFF when RTWP values are similar among carriers.

2ms TTI HSUPA Users CE Callback Detect Period Level

Indicates the callback detection period of CEs for 2 ms TTI HSUPA users.

CCPIC Phase Switch

Indicates the switch for selecting the CCPIC phase. The value DEFAULT indicates that CCPIC Phase 3 and CCPIC Phase 4 are disabled. The value CCPICPHASE3 indicates that CCPIC Phase 3 is enabled and CCPIC Phase 4 is disabled. The value CCPICPHASE4 indicates that CCPIC Phase 3 and CCPIC Phase 4 is enabled.

HSUPA High throughput Scheduling SW

Indicates the switch for scheduling HSUPA services.

HSUPA 2ms CE Efficiency Improvement Switch

Indicates the switch for CE efficiency improvement for 2 ms TTI HSUPA users.

Initial Single HARQ Switch for 2ms HSUPA Users

Indicates the switch for initial activation of single HARQ for 2 ms TTI HSUPA users. If this switch is turned on, single HARQ takes effect on newly admitted users.

KPI Fault Detection

Indicates the switch for potential KPI fault detection and reporting of related alarms. The items to be detected include the baseband resource R99 user BLER, baseband resource HSUPA user BLER, cell R99 user BLER, cell HSUPA user BLER, cell HSDPA user BLER, and Iub interface failure rate. If an option under this parameter is set to ON, the NodeB performs fault detection on the related detection item and reports related alarms. If an option under this parameter is set to OFF, the NodeB does not perform fault detection on the related detection item or report related alarms.

KPI Fault auto Recover Para

Indicates the self-healing level of potential KPI faults. Self-healing operations vary with the value of this parameter.If this parameter is set to NONE(NONE), the NodeB does not perform any operations. If this parameter is set to BBRESOURCERESET(BBRESOURCERESET), the NodeB supports self-healing at the BBRESOURCERESET(BBRESOURCERESET) level. Currently, self-healing operations at the CELLRESTART(BBRESOURCERESET) and CELLRFMODULERESET(BBRESOURCERESET) levels are unavailable. Therefore, do not use these functions.

Fixed CE Reserved for HSUPA 2ms TTI

Indicates the fixed number of CEs reserved for each 2 ms TTI user if CE Overbooking is enabled. Value 0 indicates that CE Overbooking takes effect separately and CE reservation for 2 ms TTI users does not take effect. A value ranging from 1 to 8 indicates that CE reservation for 2 ms TTI users takes effect and the corresponding parameter values specifies the fixed number of CEs reserved for each 2 ms TTI user.

DL Carrier Transmit Pwr Measurement Prd(ms)

Indicates the period of measuring the average downlink transmit carrier power and average downlink non-HSPA transmit carrier power in the power congestion-based E2E flow control algorithm.

Pwr Predict Switch for CAC

Indicates the switch used to predict the power of power congestion-based E2E flow control users. This parameter is valid when the power congestion-based E2E flow control algorithm takes effect. If this switch is turned on, admission decision is based on a comparison between the sum of access user initial power and measured cell power in the measurement period and the threshold. If this switch is turned off, admission decision is based on a comparison between the measured cell power and the threshold.

Downlink FP Window Adjustment Switch

Indicates the switch used to adjust the FP window. The soft handover success rate between a Huawei NodeB and few neighboring vendor's NodeBs is low because the vendors' NodeBs have poor performance. Turning on this switch increases the soft handover success rate.

MC Inter-Board Joint Scheduling Switch

Indicates whether the HSDPA multicarrier cell supports inter-board joint scheduling. If this parameter is set to ON, the HSDPA multicarrier cell supports inter-board joint scheduling, thereby improving the balance of baseband resources between boards and reducing the number of capability decline alarms for the following features: DC-HSDPA, DC-HSDPA+MIMO, Flexible Dual Carrier HSDPA, MC-HSDPA+MIMO, DB-HSDPA+MIMO, DB-HSDPA, 3C-HSDPA, 4C-HSDPA, and Macro-Micro DC-HSDPA.

Propagation Delay Measure Matrix Switch

Indicates whether to collect the propagation delay measurement matrix for the CCO feature.

Uplink Control Channel OLPC Minimum SIR Target(0.1dB)

Indicates the minimum SIR target for uplink control channel-based OLPC. Relationship between the GUI value and actual value: Actual value = (GUI value - 40) x 0.1.

Hsupa Scheduler Pool Switch

Indicates whether to enable HSUPA Scheduler Pool.

Coverage Expansion Neighbour Cell Configure Mode

Indicates the mode to establish neighboring cells (coordinating cells) when the Coverage Expansion Under Interference feature is enabled. If this parameter is set to AUTOMATIC, the coordination relationship is automatically identified by the NodeB and does not need to be configured. If this parameter is set to MANUAL, the coordination relationship must be manually configured.

Power Configuration Protection Switch

Indicates whether to enable power configuration protection. If this switch is turned on, the RRU checks the sum of power on the carrier served by the RRU. If the check fails, the power configuration will be limited to be below the power specifications, and the carrier fails to be set up.

Uplink CE Improvement for AMR-WB Switch

Indicates whether to enable uplink CE efficiency improvement for AMR-WB.

NBIS Adaptive Switch

Indicates the adaptive NBIS switch.

NBIS Initial Startup Threshold(dBm)

Indicates the NBIS initial startup threshold when NBIS Adaptive Switch is set to ON. If the average no-service RTWP of all cells working on a frequency within half an hour is greater than the threshold, NBIS is started. Otherwise, NBIS is not started.

NBIS Reselection Period(day)

Indicates the reselection period of Narrowband Interference Suppression (NBIS). When this parameter is set to a proper value, the NodeB disables the NBIS function on the current carrier and checks whether the narrowband interference is cleared on the current carrier or choose another carrier to perform the NBIS function. When this parameter is set to 0, the NodeB does not perform the reselection of NBIS.

uX2 SON Setup Switch

Indicates whether to enable the uX2 automatic setup function. If this parameter is set to ON, the NodeB supports automatic uX2 setup by the OSS. If this parameter is set to OFF, uX2 links must be manually set up.

Sleeping Cell Alarm Report Switch

Indicates whether to enable the sleeping cell alarm report function.

Sleeping Cell Detection Option

Indicates the scope of detecting sleeping cells.

CPC F-DPCH DTX Switch

Indicates whether to enable the CPC F-DPCH DTX function.

Iub Congestion KPI Improvement Switch

Indicates the switch for improving the RRC connection setup success rate in transmission congestion scenarios. When this parameter is set to ON, the RRC connection setup success rate increases in transmission congestion scenarios.

HSDPA Serving Cell Change Optimization Switch

Indicates the switch for HSDPA serving cell change optimization. When this switch is turned on, the data transmission policy during the HSDPA serving cell change is improved, increasing the user throughput and user experience. When this switch is turned off, the original algorithm applies.

Cell RTWP Excessive Alarm Report Switch

Indicates whether to enable the Cell RTWP Excessive alarm report function.

Cell RTWP Excessive Alarm Threshold(dBm)

Indicates the Cell RTWP Excessive alarm threshold. When Cell RTWP Excessive Alarm Report Switch is set to ON, the NodeB measures the RTWP of each uplink channel in a cell every second. In the alarm reporting period (2 hours), if more than 80% of the measured value on the uplink channel is higher than or equal to the threshold, the Cell RTWP Excessive alarm is reported. After the alarm is reported, in the alarm clearing period (3 minutes), if more than 80% of measured value on the cell uplink channel is lower than the threshold, the alarm is cleared. If the desensitization parameter is configured, the measured value on the uplink channel is modified based on the cell-level desensitization intensity. If the cell is enabled with GU@5 MHz, the threshold is modified based on the GU@5 MHz configurations.

DL Cell Auto Reshuffle Switch

Indicates the switch for automatic downlink hitless cell reshuffling.

Adjusting E-Tilt Flag

Indicates whether the electrical tilt of the antenna can be adjusted automatically.

AMR Transmission Bandwidth Compression

Indicates AMR transmission bandwidth compression switch. When this switch is turned on, the AMR transmission bandwidth compression function is enabled for all cells served by a NodeB. When this switch is turned off, the AMR transmission bandwidth compression function is disabled for all cells served by a NodeB. It is good practice to turn on this switch in satellite transmission over Iub scenarios.

Soft Fault Self-healing Switch

Indicates whether to enable soft failure self-healing. If BBPRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the baseband processing unit check result and the number of random access messages. If the soft failure affects services, the baseband processing unit is restarted to recover services. When BBPRESETSWITCH is set to ON, if BBPRESETDELAYSWITCH is set to ON, the baseband processing unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if BBPRESETDELAYSWITCH is set to OFF, the baseband processing unit restarts immediately upon detecting soft failures and service exceptions. If RFRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the RF unit check result and the number of random access messages. If the soft failure affects services, the RF unit is restarted to recover services. When RFRESETSWITCH is set to ON, if RFRESETDELAYSWITCH is set to ON, the RF unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if RFRESETDELAYSWITCH is set to OFF, the RF unit restarts immediately upon detecting soft failures and service exceptions. If BBSFRESHUFFLESWITCH is set to ON, the NodeB attempts to relocate cells served by the faulty baseband module to other baseband modules and restart the faulty module for self-healing after detecting a soft failure on the baseband module. If BBSFCORRECTSWITCH is set to ON, the NodeB attempts to correct the soft failure. This reduces the frequency of restarting the baseband module.

RRU Intelligent Dormancy Frequency Band

Frequency band that supports RRU Intelligent Dormancy. If this option is selected for all the frequency bands supported by the RRU or RFU, the RRU or RFU supports RRU Intelligent Dormancy.

Mode of the CE Sharing for the Operator

Indicates the CE sharing mode of the common group when MOCN is enabled. When this parameter is set to FULLSHARE, private operators can use the CE resources in the common group. When this parameter is set to OPTIONALSHARE, whether private operators can use the CE resources in the common group depends on the settings of the OPERATORINDEXSELECTION parameter.

Selection of the Operator Index

Indicates the index of operators not allowed to use the license CE resources in the common group. When MOCN is enabled and OPERATORSHARECEMODE is set to OPTIONALSHARE, the operator specified by this parameter cannot use the license CE resources in the common group.

RTWP Imbalance Alarm Threshold(0.1dB)

Indicates the RTWP imbalance alarm threshold. When the difference between the RTWP of the uplink channel of RRU and the RTWP of the uplink channel of the RFU exceeds the threshold, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is reported.

Private Operator License Alarm Policy

Indicates whether to optimize reporting of ALM-26812 System Dynamic Traffic Exceeding Licensed Limit for a private operator. With the optimization, ALM-26812 System Dynamic Traffic Exceeding Licensed Limit is reported when the number of licenses used by the private operator exceeds the total licensed threshold for the private operator and the common operator. This threshold is specified using the SET NODEBLICENSEALMTH command. Without the optimization, this alarm is reported when the number of licenses used by the private operator exceeds the licensed threshold for the private operator.

ACK Field Detect Threshold Opt Switch

Indicates whether to enable ACK field detection threshold optimization. When this switch is turned on, the NodeB optimizes the detection threshold of the ACK field. When this switch is turned off, the NodeB does not optimize the detection threshold of the ACK field.

Smart Scheduling Learning Mode

Indicates the machine leaning mode for smart scheduling. If this parameter is set to LEARNING, the NodeB performs real-time machine learning and activates the Machine Learning based Scheduling feature. If this parameter is set to HOLD, the NodeB suspends the learning and uses the current optimal learning result to activate the Machine Learning based Scheduling feature.

UMTS and LTE Dynamic Power Sharing Time Period

Indicates the time period in which the UMTS and LTE Dynamic Power Sharing feature is effective on a multimode base station.

Shutdown Fault Detection Switch

Indicates whether the NodeB shutdown fault identification function is enabled. When this parameter is set to ON, the cause of the NodeB shutdown fault can be promptly identified.

Inter Board Fault Detect Switch

Indicates whether to perform inter-board service link failure detection and report ALM-26215 Inter-Board Service Link Failure. When this switch is turned on, inter-board link failure detection is required. If an exception occurs, ALM-26215 Inter-Board Service Link Failure is reported. When this switch is turned off, inter-board link failure detection is not required. This parameter is valid only when the main control board is UMPT and the baseband board is WBBPa, WBBPb, or WBBPd.

RL Detection and Demodulation Optimization Switch

Indicates whether to enable RL detection and demodulation algorithm optimization. When this switch is turned on, the RL detection and demodulation functions are optimized to ensure that the SIR estimation is more accurate when the CS Voice Precise Power Control feature takes effect. When this switch is turned off, the RL detection and demodulation algorithm optimization does not take effect.

Power Control Performance Optimization Switch

Indicates whether to enable power control performance optimization in a cell. When this parameter is set to ON(ON), the power control performance in the cell on the board where this function takes effect improves. Currently, this parameter takes effect only on the UBBPg board.

Switch of Invalid TFCI Demodulation and Decoding Optimization Algorithm

Indicates whether the TFCI demodulation and decoding optimization algorithm does not take effect. If this parameter is set to ON(ON), the demodulation and decoding optimization algorithm does not take effect. If this parameter is set to OFF(OFF), the demodulation and decoding optimization algorithm takes effect.
