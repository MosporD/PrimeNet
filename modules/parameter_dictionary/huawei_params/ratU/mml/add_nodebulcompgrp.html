Add NodeB ULCoMP Group (ADD NODEBULCOMPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to configure the coordination relationship for the Uplink CoMP (Joint Reception) based on Coordinated BBU feature or the Coverage Expansion Under Interference feature. The host cell (primary cell) and neighboring cell (coordinating cell) in the coordination relationship combine received signals, thereby improving uplink performance.

Note

  • The coordination relationship for the Coverage Expansion Under Interference feature takes effect only when ULCOVEXPCFGMOD is set to MANUAL in SET NODEBALGPARA.
  • In some networking scenarios, the new ULCoMP group takes effect one minute after this command is executed.

ULCOMP ULCoMP Neighbour Cell Configure

Meaning: Indicates whether to configure the coordination relationship for the Uplink CoMP (Joint Reception) based on Coordinated BBU feature. If this parameter is set to TRUE, the coordination relationship configured using the ADD NODEBULCOMPGRP command is used for the Uplink CoMP (Joint Reception) based on Coordinated BBU feature.

Unit: None

Actual Value Range: FALSE, TRUE

MML Default Value: TRUE(TRUE)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ULCOVEXP Coverage Expansion Neighbour Cell Configure

Meaning: Indicates whether to configure the coordination relationship for the Coverage Expansion Under Interference feature. If this parameter is set to TRUE, the coordination relationship configured using the ADD NODEBULCOMPGRP command is used for the Coverage Expansion Under Interference feature.

Example

Add coordination relationship:
