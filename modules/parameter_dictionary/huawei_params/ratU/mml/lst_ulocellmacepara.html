List Mac-e Parameters (LST ULOCELLMACEPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the Mac-e parameters of specified or all local cells.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Use the following command to list Mac-e parameters of all local cells:
LST ULOCELLMACEPARA:;
The result is shown as follows:

RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

MAC-e Schedule Para

Indicates whether setting Mac-e scheduling parameters.

OverLoad Schedule Switch

Indicates the HSUPA overload scheduling switch. The function will be enabled if this parameter is set to OPEN. When this switch is turned on and the guaranteed bit rates (GBRs) of users are not met, the cell load will exceed the planned target and reach the congestion threshold, thereby guaranteeing users' GBRs.

Max Target RoT Difference Before and After IC(0.5dB)

Indicates the max target RoT difference before and after IC.

E-AGCH HPC Parameters

Indicates whether setting E-AGCH power control parameters.

E-AGCH HPC Mode

Indicates the E-AGCH power control policy. Fixed Tx power: The E-AGCH uses fixed transmit power. Tx Pwr Ctr based on Pilot or Tx Pwr Ctr based on TPC: The transmit power of the E-AGCH is reduced, and the downlink capacity is improved. Tx Pwr Ctr based on CQI or Tx Pwr Ctr based on HS-SCCH: The transmit power of the E-AGCH is further lowered, and the downlink capacity is further improved.

E-AGCH Power Offset(0.25dB)

Indicates the Power offset between the E-AGCH and the TPC. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-AGCH Power Offset in 3GPP TS 25.433.

E-AGCH Power(0.1dB)

Indicates the power offset of the E-AGCH from the power of the Common Pilot Channel.

E-AGCH Max Power(0.1dB)

Indicates the E-AGCH Max Power.

E-AGCH Min Power(0.1dB)

Indicates the E-AGCH Min Power.

E-RGCH HPC Parameters for Service Radio Links Set

Indicates whether to set E-RGCH power control parameters for Serving E-DCH RLS and E-HICH power control parameters for RLS containing the Serving E-DCH cell.

E-RGCH HPC Mode for Service Radio Links Set

Indicates the E-RGCH power control policy for Serving E-DCH RLS and E-HICH power control policy for RLS containing the Serving E-DCH cell. Fixed TX power: The E-RGCH for Serving E-DCH RLS and the E-HICH for RLS containing the Serving E-DCH cell use fixed transmit power. TX Pwr Ctr based on Pilot or TX Pwr Ctr based on TPC: The E-RGCH and E-HICH occupy less transmit power, and the downlink capacity is improved.

E-RGCH Power Offset for Service Radio Links Set(0.25dB)

Indicates the E-RGCH power offset for service radio link set from the associated DPCCH TPC field. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-RGCH Power Offset in 3GPP TS 25.433.

E-RGCH Power for Service Radio Links Set(0.1dB)

Indicates the power offset of the E-RGCH serving RLS from the power of the Common Pilot Channel.

E-RGCH HPC Parameters for Non-service Radio Links

Indicates whether to set E-RGCH power control parameters for Non-serving E-DCH RL and E-HICH power control parameters for RLS not containing the Serving E-DCH cell.

E-RGCH HPC Mode for Non-service Radio Links

Indicates the E-RGCH power control policy for Non-serving E-DCH RL and E-HICH power control policy for RLS not containing the Serving E-DCH cell. Fixed TX power: The E-RGCH for Non-serving E-DCH RL and the E-HICH for RLS not containing the Serving E-DCH cell use fixed transmit power. TX Pwr Ctr based on Pilot or TX Pwr Ctr based on TPC: The E-RGCH and E-HICH occupy less transmit power, and the downlink capacity is improved.

E-RGCH Power Offset for Non-service Radio Links(0.25dB)

Indicates the E-RGCH power offset from associated DPCCH TPC field for non-service radio links. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-RGCH Power Offset in 3GPP TS 25.433.

E-RGCH Power for Non-service Radio Links(0.1dB)

Indicates the power offset of the E-RGCH non-serving RL from the power of the Common Pilot Channel.

E-HICH Power Offset for Service Radio Links Set(0.25dB)

Indicates the E-HICH power offset for service radio link set from the associated DPCH_TPC field. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-HICH Power Offset in 3GPP TS 25.433.

E-HICH Power for Service Radio Links Set(0.1dB)

Indicates the power offset of the E-HICH serving RLS from the power of the Common Pilot Channel.

E-HICH Power Offset for Single Radio Link(0.25dB)

Indicates the E-HICH Power Offset for Single Radio Link Set. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-HICH Power Offset in 3GPP TS 25.433.

E-HICH Power for Single Radio Link(0.1dB)

Indicates the E-HICH Power for Single Radio Link Set.

E-HICH Power Offset for Non-service Radio Links Set(0.25dB)

Indicates the E-HICH power offset for non-service radio link set from associated DPCCH TPC field. The GUI value range and actual value range of this parameter are set according to 3GPP TS 25.433. For details, see the description of E-HICH Power Offset in 3GPP TS 25.433.

E-HICH Power for Non-service Radio Links Set(0.1dB)

Indicates the power offset of the E-HICH non-serving RLS from the power of the Common Pilot Channel.

Anti-Interference Scheduling Switch

Indicates the ratio of the cell load resources that needs to be guaranteed. When this switch is turned on, in scenarios where strong external interference exists, a large value for this parameter improves the throughput of the cell. At the same time, however, the cell coverage severely shrinks.

Own Cell UL Load Ratio(%)

Indicates the uplink load of the local cell required when the anti-interference scheduling algorithm is enabled. Increasing the parameter value helps increase cell throughput rate in strong interference scenarios.

RTWP Measurement Optimization Algorithm Switch

Indicates the Rtwp Measure Optimize Switch. The function will be enabled if this parameter is set to OPEN. When this switch is turned on, this improves the number of users that can be simultaneously admitted into the system and raises the access success rate.

Min UL Cover Load Threshold(dB)

Indicates the uplink load threshold for ensuring minimum cell coverage. That is, if a site has strong interference, the uplink load cannot exceed the threshold to ensure minimum cell coverage.

Hsupa Time Division Scheduling Switch

Indicates the HSUPA Time Division Scheduling Switch.

Chip Offset 2ms UE Number

Indicates the chip offset 2 ms UE number in HSUPA Time Division Scheduling.

TDM Schedule Enhance Switch

Indicates the switch for TDM scheduling enhance for HSUPA cells.

Secondary DC-HSUPA Cell Activation and Deactivation Switch Based on RTWP

Indicates to enable RTWP-based secondary DC-HSUPA cell activation and deactivation.

Secondary DC-HSUPA Cell Deactivation Rate Threshold(10kbps)

Indicates the minimum rate threshold supported by the uplink transmit power for ensuring the minimum coverage of activated DC-HSUPA UEs on the secondary carrier. To be specific, to meet the minimum coverage requirements of activated DC-HSUPA cell edge UEs (CEUs) on the secondary carrier, the maximum rate threshold supported by the uplink transmit power cannot be lower than this threshold. Otherwise, the CEUs on the secondary carrier need to be deactivated.

HSUPA Total Throughput Guarantee Switch

Indicates the total HSUPA throughput guarantee switch. When this switch is turned on, the algorithm for increasing total HSUPA throughput is enabled.

HSUPA Total Throughput Threshold(kbps)

Indicates the total throughput to be guaranteed when HSUPA Total Throughput Guarantee Switch is set to ON.

HSUPA TTI 2ms User SG Algorithm

Indicates the minimum SG that the SG reclaiming algorithm uses during the data transmission of HSUPA 2 ms TTI users. When this parameter is set to SGALGFIRSTFOR2MSUSER, the minimum SG during data transmission of HSUPA 2 ms TTI users is three RLC PDUs. When this parameter is set to SGALGSECONDFOR2MSUSER, the minimum SG during data transmission of HSUPA 2 ms TTI users is one RLC PDU.
