Block Local Cell (BLK ULOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to start to block a specified or all the local cells

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After the cell blocked successfully, the Local Cell Blocked alarm appears.
  • If the Local Cell ID is not specified, all the local cells in the NodeB will be blocked, and the Block PRI must be set to "HIGH". Otherwise, the execution of this command fails.
  • The local cell to be blocked must exist. Otherwise, the execution of this command fails.
  • If the local cell is not bearing any logical cell, you can block the local cell immediately no matter which block priority is applied to the cell. Otherwise, the local cell can be blocked only after the RNC responds a block message.
  • If you set the Block PRI to "HIGH", immediately the local cells shall be blocked no matter whether the local cell bears the logical cell.
  • Running this command interrupts ongoing services carried in the blocked cell.
  • The cell should be blocked within 60 minutes after the BLK ULOCELL command is executed.
  • After the NodeB resets, blocked local cells are unblocked.

Applicable Mode: U
PRI Block PRI

Meaning: Indicates the Block PRI. There are three block priorities: High priority, Normal priority and Low priority.

1. High priority: Blocking a cell immediately.

2. Normal priority: Blocking a cell once there are no CELL_DCH and CELL_FACH users in it within a specified time, or blocking it even if there are some CELL_DCH or CELL_FACH users when the specified time expires.

3. Low priority: Blocking a cell when there are no CELL_DCH and CELL_FACH users in the cell.

GUI Value Range: HIGH(High priority), NORMAL(Normal priority), LOW(Low priority)

Unit: None

Actual Value Range: HIGH, NORMAL, LOW

Example

Block the No.14600 local cell:
BLK ULOCELL: ULOCELLID=14600, PRI=HIGH;
