Display Rule Activation Status and Active Value (DSP NODEBRULEACTIONPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to query the activation status of a rule for a specified cell or all cells and the active value of the parameter associated with the rule.

Note

If no local cell ID is specified, this command is executed to get the summarized information of all the local cells using the specified rule under the NodeB. If a local cell ID is specified and the local cell exists, this command is executed to get the detailed information of the specified local cell using the specified rule.

Parameters

ID Name Description
RULEID Rule ID

Meaning: Indicates the ID of a rule. The parameter value range extends with the rule quantity. Rule IDs 0 and 1 indicate that the SIB7RTWPOPTSW and SIB7MAXRTWP parameters must be configured. Rule IDs 2 and 3 indicate that the RTWPSIRTGTADJSW parameter must be configured. Rule ID 4 indicates ICMODE parameter must be configured. Rule IDs 5 and 6 indicate that the EXTRAPOWER parameter must be configured. Rule ID 7 indicates that TURBOIC parameter must be configured. Rule ID 8 indicates that DPCHMAXTXPWRRESTRSW parameter must be configured. Rule ID 9 indicates that RADIOQUALITYDPCHPCSW parameter must be configured. Rule ID 10 indicates that DPCHTPCPOADJSW parameter must be configured.

Output Description

Field Description

Rule ID

Indicates the ID of a rule. The parameter value range extends with the rule quantity. Rule IDs 0 and 1 indicate that the SIB7RTWPOPTSW and SIB7MAXRTWP parameters must be configured. Rule IDs 2 and 3 indicate that the RTWPSIRTGTADJSW parameter must be configured. Rule ID 4 indicates ICMODE parameter must be configured. Rule IDs 5 and 6 indicate that the EXTRAPOWER parameter must be configured. Rule ID 7 indicates that TURBOIC parameter must be configured. Rule ID 8 indicates that DPCHMAXTXPWRRESTRSW parameter must be configured. Rule ID 9 indicates that RADIOQUALITYDPCHPCSW parameter must be configured. Rule ID 10 indicates that DPCHTPCPOADJSW parameter must be configured.

Local Cell ID

Indicates the local cell ID.

Local Cell Status

Indicates the local cell status. Value range: Local Cell Unavailable, Local Cell Unavailable-RF and Baseband Resource Fault, Local Cell Unavailable-RF Resource Fault, Local Cell Unavailable-Baseband Resource Fault, Local Cell Unavailable-License Limited, Local Cell Unavailable-Baseband Resource Fault and License Limited, Local Cell Unavailable-RF, Baseband Resource Fault and License Limited, Local Cell Unavailable-RF Resource Fault and License Limited, Local Cell Available-NCP Fault, Local Cell Unavailable-NCP Fault and License Limited, Local Cell Unavailable-Available Local Cells Reached Upper Limit, Local Cell Unavailable-Baseband Resource Fault and Available Local Cells Reached Upper Limit, Local Cell Unavailable-Available Local Cells Reached Upper Limit and RF Resource Fault, Local Cell Unavailable-NCP Fault and Available Local Cells Reached Upper Limit, Local Cell Unavailable-Available Local Cells Reached Upper Limit and License Limited, Local Cell Unavailable-RF, Baseband Resource Fault and Available Local Cells Reached Upper Limit, Local Cell Unavailable-Baseband Resource Fault, License Limited and Available Local Cells Reached Upper Limit, Local Cell Unavailable-RF Resource Fault, License Limited and Available Local Cells Reached Upper Limit, Local Cell Unavailable-RF, Baseband Resource Fault, License Limited and Available Local Cells Reached Upper Limit, Local Cell Unavailable-pRRU Deep Dormancy, Local Cell Unavailable-Beam Cell Group Not Configured or Configuration Incomplete, Local Cell Unavailable-Main Control Board Not Supported, Local Cell Available.

Local Cell Administration Status

Indicates the local cell administration status. Blocked: The previous services in the cell are released and the cell is unavailable. Shutting down: Non-high-priority cells are selected but the cells do not meet the blocking condition. UNBLOCKED: The local cell is not blocked. The local cell administration status can be modified by running the BLK ULOCELL and UBL ULOCELL commands.

Cell ID

Indicates the logical cell ID.

Rule Active Status

Indicates the active status of a rule.

MO Name

Indicates the name of an MO whose parameters are associated with a rule.

Parameter Name

Indicates the name of a parameter associated with a rule.

Active Interval Value

Indicates the active value of an interval-type parameter associated with a rule.
