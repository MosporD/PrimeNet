Modify Remote Cell Group (MOD NODEBREMOTECELLGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to modify the name of the resource group of remote coverage cells.

Note

  • The number of the resource group of remote coverage cells cannot be changed.
  • The resource group of remote coverage cells whose name needs to be modified must exist.

Parameters

ID Name Description
REMOTECELLGRPINDEX Remote Cell Group No.

Meaning: Indicates the number of the resource group of remote coverage cells.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
REMOTECELLGRPNAME Remote Cell Group Name

Meaning: Indicates the name of the resource group of remote coverage cells.

GUI Value Range: 1~31 characters

Unit: None

Actual Value Range: 1~31 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBREMOTECELLGRP MO, the value of REMOTECELLGRPNAME cannot contain the following invalid characters: <>!?\.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Modify the name of the resource group of remote coverage cells whose number is "1" to "JINMAO Mansion":
MOD NODEBREMOTECELLGRP: REMOTECELLGRPINDEX =1, REMOTECELLGRPNAME="JINMAO Mansion";
