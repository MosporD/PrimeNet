List NodeB KPI Fault Algorithm Parameter (LST NODEBKPIFAULTDETECTPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query invisible fault alarm-related parameters.

Note

None

Parameters

None.

Example

List the invisible fault alarm-related parameters:
LST NODEBKPIFAULTDETECTPARA:;
The result is shown as follows:

Output Description

Field Description

R99 User Fault Detect Threshold(%)

Indicates the threshold for determining whether an R99 user has a high BLER.

UPA User Fault Detect Threshold(%)

Indicates the threshold for determining whether an HSUPA user has a high BLER.

Process Unit Fault Detect Threshold(%)

Indicates the threshold for determining whether a processing unit has a high proportion of abnormal users.

Traffic Fault Detect Threshold protection(%)

Indicates the threshold of fault detection protection. The configured R99 User Fault Detect Threshold, UPA User Fault Detect Threshold, or Process Unit Fault Detect Threshold cannot be less than the difference between the corresponding default threshold and the fault detection protection threshold.

Process Unit Fault Clear Threshold(%)

Indicates the threshold of determining whether a processing unit is restored after its faults are rectified.

Board Invisible Fault Alarm Occur Period(15min)

Indicates the time segment during which invisible fault alarms are detected on the board through the service function.

Board Invisible Fault Alarm Clear Period(15min)

Indicates the number of times invisible fault alarms are cleared on the board through the service function within a measurement period.
