Add uX2 Configuration (ADD UX2)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a uX2 object.

Note

  • In the scenario where the UMTS and LTE networks share a main control board, EPGROUP MO referenced by CPEPGROUPID in the UX2 MO must be different from EPGROUP MOs referenced by LTE interfaces. EPGROUP MO referenced by UPEPGROUPID in the UX2 MO must be different from EPGROUP MOs referenced by the SO/S1/ECO/M1 MO.
  • In the scenario where the UMTS and GSM networks share a main control board, EPGROUP MO referenced by UPEPGROUPID in the UX2 MO must be different from EPGROUP MO referenced by the ABIS MO.

Meaning: Indicates whether to enable static UDP Ping detection over the uX2 interface. If this parameter is set to ON, static UDP Ping detection is enabled over the uX2 interface. If this parameter is set to OFF, static UDP Ping detection is disabled over the uX2 interface.

Applicable Mode: U

Example

To add a uX2 object with the parameters as follows: uX2 Object ID: 0, Control Plane End-Point Group ID: 1, User Plane End-Point Group ID: 2, uX2 Object Description: uX2, run the following command: 
ADD UX2: UX2ID=0, CPEPGROUPID=1, UPEPGROUPID=2, USERLABEL="uX2";
