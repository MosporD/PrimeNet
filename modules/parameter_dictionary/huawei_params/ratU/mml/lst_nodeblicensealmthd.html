List License Alarm Threshold (LST NODEBLICENSEALMTHD)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to obtain the license alarm threshold and detect period parameters.

Note

None

Parameters

None.

Example

Use the following command to list the license alarm threshold and detect period parameters:
LST NODEBLICENSEALMTHD:;
The result is shown as follows:
+++    HUAWEI        2011-09-26 11:41:13
O&M    #280
%%LST NODEBLICENSEALMTHD:;%%
RETCODE = 0  Operation succeeded.

List License Alarm Threshold
----------------------------
  Alarm Occur Threshold(%)  =  100
  Alarm Detect Period(min)  =  5
Alarm Recover Threshold(%)  =  90
 Alarm Recover Period(min)  =  5
(Number of results = 1)


---    END

Output Description

Field Description

Alarm Occur Threshold(%)

Indicates the threshold of triggering ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

Alarm Detect Period(min)

Indicates the interval for detecting ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

Alarm Recover Threshold(%)

Indicates the threshold of clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

Alarm Recover Period(min)

Indicates the interval for clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.
