Display Desensitization Intensity (DSP ULOCELLDESENS)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the desensitization intensity of a specified local cell or all local cells.

Note

  • Display the desensitization intensity of all local cells or a specified local cell only if it exists.
  • Desensitization is not supported by pico RRU, so when there are pico RRUs in local cell, desensitization setting is invalid to those pico RRUs. However, the MPMU of the LampSite product supports desensitization.
  • After Micro Cell Dynamic Rx Sensitivity Control feature is activated, the desensitization value set by this command is replaced by the dynamic desensitization value.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Display the desensitization intensity of all the local cells:
DSP ULOCELLDESENS:;
The result is shown as follows: 
+++    HUAWEI        2012-11-28 15:51:37
O&M    #8791
%%DSP ULOCELLDESENS:;%%
RETCODE = 0  Operation succeeded.

Display Desensitization Intensity
---------------------------------
Local Cell ID  Desensitization Intensity(dB)

14600          0                            
14601          0                            
(Number of results = 2)


---    END

2.Display the desensitization intensity of local cell 14600:
DSP ULOCELLDESENS: ULOCELLID=14600;
The result is shown as follows: 
+++    HUAWEI        2012-11-28 15:51:42
O&M    #8793
%%DSP ULOCELLDESENS: ULOCELLID=14600;%%
RETCODE = 0  Operation succeeded.

Display Desensitization Intensity
---------------------------------
                Local Cell ID  =  14600
Desensitization Intensity(dB)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. The local cell ID is unique for one NodeB.

Desensitization Intensity(dB)

Indicates the desensitization intensity, that is, the ratio of uplink noise intensity to background noise. If the desensitization intensity is set as 0, the desensitization is not applied.
