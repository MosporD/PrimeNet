List Extend Secondary Cell Group (LST NODEBEXSECCELLGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query an extend secondary cell group.

Note

None.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the primary cell in the extend secondary cell group.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBEXSECCELLGRP MO, the value of ULOCELLID must be different from that of EXSECULOCELLID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1. List the information of all the extend secondary cell groups: 
LST NODEBEXSECCELLGRP:;
The result is shown as follows:
+++    HUAWEI        2015-08-10 11:30:55
O&M    #806359201
%%LST NODEBEXSECCELLGRP:;%%
RETCODE = 0  Operation succeeded.

LST NODEBEXSECCELLGRP: ULOCELLID=0;

---    END

Output Description

Field Description

Local Cell ID

Indicates the primary cell in the extend secondary cell group.

Extend Secondary Local Cell ID

Indicates the secondary cell in the extend secondary cell group.
