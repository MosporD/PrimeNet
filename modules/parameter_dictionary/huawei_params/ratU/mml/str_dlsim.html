Start DL Load Simulation (STR DLSIM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to start the downlink network load simulation of a specified local cell or all local cells.

It is mainly used in the incipient period of the network to test the performance of the network.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be successfully executed only when the corresponding logical cell exists.
  • The downlink network load simulation uses the channelization codes from 112 to 127 whose SF = 128.
  • If downlink load simulation needs to be enabled, the corresponding channel codes must be reserved on the RNC.
  • Before starting the downlink load simulation, check that the power load is greater than the carrier transmit power. You can query the carrier transmit power by choosing Cell Performance Monitoring: Cell DL Carrier TX Power on the RNC.
  • After starting the DL load simulation, new service can not be built in the channel resource occupied by the simulation.
  • If the downlink load simulation is started in a cell carrying services, ensure that the simulated load is within the normal range of load value. If the simulated load is too high, the downlink channel is deteriorated and therefore the RNC terminates the valid services based on measurement reports, or call drops occur because of deteriorated SNR.
  • After the execution of this command, run the STP DLSIM command to stop the downlink network load simulation of a specified local cell or all local cells.
  • After the execution of this command, run the MOD DLSIM command to modify the load radio of downlink network load simulation of a specified local cell or all local cells.
  • After the execution of this command, run the DSP DLSIM command to display the current load ratio of downlink network load simulation of a specified local cell or all local cells.
  • After downlink network load simulation is started, do not run the BLK ULOCELL or UBL ULOCELL command or adjust the cell channel power. Otherwise, the cell transmit power may become abnormal.
  • After the UBL ULOCELL command is executed, wait for a moment (at most 1 minute) until the cell output power becomes stable before executing this command. Otherwise, the cell transmit power may become abnormal.
  • Do not run this command when SMTHPWRSWITCH in the NODEBSMTHPWR MO is set to OPEN or SHUTDOWNFAULTDETECTSW in the NODEBALGPARA MO is set to ON. Otherwise, the cell transmit power may become abnormal when the corresponding function takes effect.
  • Do not run this command when DYNAMICPCPICHSWITCH in the ULOCELLALGPARA MO is set to ON. Otherwise, the cell transmit power may become abnormal.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
LR Load Ratio

Meaning: Indicates the Load Ratio.

GUI Value Range: 1~99

Unit: %

Actual Value Range: 1~99

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
DLSIMOPTSW Downlink Network Load Simulation Optimization Switch

Meaning: Indicates the switch for downlink network load simulation optimization. When this switch is turned on, the NodeB optimizes the downlink network load simulation. When this switch is turned off, the NodeB does not optimize the downlink network load simulation.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(OFF)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Start the downlink network load simulation of the local cell whose ID is "10" and set the load ratio as 40%:
STR DLSIM: ULOCELLID=10, LR=40;
