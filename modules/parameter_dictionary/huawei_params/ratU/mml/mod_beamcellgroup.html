Modify Beam Cell Group (MOD BEAMCELLGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify the configurations of beam cell group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Executing this command will change the cell coverage.

Parameters

ID Name Description
BEAMCELLGROUPID Beam Cell Group ID

Meaning: Indicates the ID of beam cell group.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BEAMCELLGROUPTYPE Beam Cell Group Type

Meaning: Indicates the type of beam cell group.

GUI Value Range: NORMALBEAM(Normal Beam), MASSIVEBEAM8T8R(Massive Beam 8T8R), MASSIVEBEAM4T4R(Massive Beam 4T4R), FOURTXSPLITSECTOR(4T Split Sector Beam), COORDINATED2TBEAM(2T Coordinated Beamforming)

Unit: None

Actual Value Range: NORMALBEAM, MASSIVEBEAM8T8R, MASSIVEBEAM4T4R, FOURTXSPLITSECTOR, COORDINATED2TBEAM

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
BEAMOPTIONPERIOD Beam Option Period

Meaning: Indicates the beam selection period.

GUI Value Range: 1MIN(1min), 2MIN(2min), 5MIN(5min), 10MIN(10min), 15MIN(15min), 20MIN(20min), 30MIN(30min), 1H(1hour)

Unit: None

Actual Value Range: 1MIN, 2MIN, 5MIN, 10MIN, 15MIN, 20MIN, 30MIN, 1H

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If BEAMOPTIONMODE under the BEAMCELLGROUPITEM MO is set to AUTO, BEAMOPTIONPERIOD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A shorter period specified by this parameter indicates higher frequency of beam adjustment, more significant gains in capacity, but higher risks of KPI deterioration. A longer period specified by this parameter indicates lower frequency of beam adjustment, lower risks of KPI deterioration, but less significant gains in capacity.

Applicable Mode: U

Example

To modify the configuration of a beam cell group with the parameters as follows: Beam Cell Group ID: 0, Beam Cell Group Type: MASSIVEBEAM8T8R, Beam Option Period: 10MIN, run the following command: 
MOD BEAMCELLGROUP: BEAMCELLGROUPID=0, BEAMCELLGROUPTYPE=MASSIVEBEAM8T8R, BEAMOPTIONPERIOD=10MIN;
