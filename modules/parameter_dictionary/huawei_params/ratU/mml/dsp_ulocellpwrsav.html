Display Effective Status of Cell Power Saving (DSP ULOCELLPWRSAV)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the effective status of the power saving algorithm for a specified cell or all cells.

Note

None.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1. Display effective status of cell power saving of all local cells:
DSP ULOCELLPWRSAV:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

Multi-RAT Coordinated Channel Shutdown State

Indicates the state of the Multi-RAT Coordinated Channel Shutdown (UMTS) feature. Enable indicates that the Multi-RAT Coordinated Channel Shutdown (UMTS) feature is enabled. Disable indicates that the Multi-RAT Coordinated Channel Shutdown (UMTS) feature is disabled.

Multi-RAT Coordinated Channel Shutdown Time

Indicates the effective duration of the Multi-RAT Coordinated Channel Shutdown (UMTS) feature from the time specified by the latest setting of the PWRSAVSTARTTIME parameter to the current time.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05.

Cause of Multi-RAT Coordinated Channel Shutdown Failure

Indicates the cause why the Multi-RAT Coordinated Channel Shutdown(UMTS) feature does not take effect.
