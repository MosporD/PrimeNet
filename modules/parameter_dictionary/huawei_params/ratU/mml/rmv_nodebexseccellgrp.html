Remove Extend Secondary Cell Group (RMV NODEBEXSECCELLGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove an extend secondary cell group.

Note

If you run this command with EXSECULOCELLID specified, only the extend secondary cell group to which the extend secondary cell belongs is removed. In other cases, all extend secondary cell groups for the primary cell are deleted.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the primary cell in the extend secondary cell group.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBEXSECCELLGRP MO, the value of ULOCELLID must be different from that of EXSECULOCELLID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
EXSECULOCELLID Extend Secondary Local Cell ID

Meaning: Indicates the secondary cell in the extend secondary cell group.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the NODEBEXSECCELLGRP MO, the value of ULOCELLID must be different from that of EXSECULOCELLID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To delete the extend secondary cell group with the parameters as follows: Local Cell ID: 0, Extend Secondary Local Cell ID: 1, run the following command: 
RMV NODEBEXSECCELLGRP: ULOCELLID=0, EXSECULOCELLID=1;
