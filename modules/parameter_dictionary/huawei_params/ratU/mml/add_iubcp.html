Add Iub Control Port (ADD IUBCP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add the active/standby NodeB control port (NCP) or active/standby communication control port (CCP). The traffic on the NCP/CCP can be carried by IP transport or ATM transport. In IP transport mode, the NCP/CCP is carried on the SCTP link. In ATM transport mode, the NCP/CCP is carried on the SAAL link.

When both active and standby NCPs/CCPs are configured and channel switchover is enabled, the standby NCP/CCP becomes the active one and automatically takes over its services after the active NCP/CCP is faulty. If channel switchover is disabled, an active/standby switchover will not be triggered even if the active or standby NCP/CCP is faulty.

To support the disaster tolerance scheme for the RNC, the IUBCP can be set to either the primary homing mode or secondary homing mode. By default, the IUBCP is set to the primary homing mode. If the default configuration needs to be modified, ensure that disaster tolerance has been configured for the RNC.

Note

  • Before running this command, ensure that NODEBFUNCTION exists.
  • Before running this command, ensure that CPBEARID referenced by the IUBCP has been added successfully by running the ADD CPBEARER command.
  • Before running this command, ensure that the bearer SAAL or SCTP link is configured.
  • One SAAL or SCTP link can carry only one Iub control port.
  • Identical parameter settings must be made at the RNC before a standby Iub control port can take effect.
  • It is recommended that the active CCP or NCP be configured on an SAAL link.
  • In a dual-stack scenario (enabling active/standby switchover by running the SET CPSWITCH command), active and standby Iub control ports must be carried on an SAAL link and an SCTP link, respectively; In an active/standby scenario, active and standby Iub control ports can be carried on two SAAL links, respectively.

Parameters

ID Name Description
CPPT Port Type

Meaning: Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.

GUI Value Range: NCP(NCP Port), CCP(CCP Port)

Unit: None

Actual Value Range: NCP, CCP

MML Default Value: NCP(NCP Port)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of IUBCP MOs under which CPPT is set to CCP cannot exceed 96.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
CPBEARID CPBear ID

Meaning: Indicates the CP bearer ID.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
CPPN CP Port No.

Meaning: Indicates the number of the Iub control port.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the flag of the transport channel to which an Iub control port belongs.

GUI Value Range: MASTER(MASTER), SLAVE(SLAVE)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(MASTER)

Applicable Mode: U

Example

To add an Iub control port with the parameters as follows: Port Type: NCP,  CPBear Id: 0, run the following command: 
ADD IUBCP: CPPT=NCP, CPBEARID=0, BELONG=MASTER;
