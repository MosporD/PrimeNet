Display Iub Control Port Status (DSP IUBCP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of an Iub control port.

Note

None

Parameters

ID Name Description
CPPT Port Type

Meaning: Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.

GUI Value Range: NCP(NCP Port), CCP(CCP Port)

Unit: None

Actual Value Range: NCP, CCP

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of IUBCP MOs under which CPPT is set to CCP cannot exceed 96.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
CPPN CP Port No.

Meaning: Indicates the number of the Iub control port.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the flag of the transport channel to which an Iub control port belongs.

GUI Value Range: MASTER(MASTER), SLAVE(SLAVE)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(MASTER)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To query the status of an Iub control port with the parameters as follows: Port Type: CCP:
DSP IUBCP: CPPT=CCP;
The result is shown as follows:
+++    DBS3900_123        2012-12-28 08:14:12
O&M    #997
%%DSP IUBCP: CPPT=CCP;%%
RETCODE = 0  Operation succeeded.

Display Iub Control Port Status
-------------------------------
  Port Type  =  CCP Port
CP Port No.  =  0
Belong Flag  =  MASTER
Port Status  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

Port Type

Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.

CP Port No.

Indicates the number of the Iub control port.

Belong Flag

Indicates the flag of the transport channel to which an Iub control port belongs.

Port Status

Indicates the status of Iub control port. This parameter can be set to Normal or Fault.
