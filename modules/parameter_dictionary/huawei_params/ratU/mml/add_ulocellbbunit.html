Add Local Cell Baseband Unit (ADD ULOCELLBBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a BBU that serves a local cell.

Note

  • A BBU added to serve a local cell takes effect only when ULRESWORKMODE is set to MANUAL_CHAIN in SET NODEBALGPARA.
  • The added BBU must be configured in the uplink baseband equipment to which the local cell belongs.
  • The BLADEBBU and BBU3910C do not support this command.
  • If UL Resource Work Mode is MANUAL_CHAIN, running this command maybe interrupt ongoing services carried by the cells served by the NodeB for one to two minutes.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BBUNITID Baseband Unit ID

Meaning: Indicates the number of the BBU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Run the following command to add No.0 BBU that serves No.0 local cell:
ADD ULOCELLBBUNIT: ULOCELLID=0, BBUNITID=0;
