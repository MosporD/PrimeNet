Modify NodeB Function (MOD NODEBFUNCTION)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify the user label and NodeB ID of NodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After changing the NodeB ID, run the RST APP command to reset applications used by the NodeB. Before the reset, the system continues to use the NodeB ID before the change. After the RST APP command is executed, the NodeB ID changes, and the ULCoMP group cannot match specified coordinating cells. As a result, the ULCoMP relationship does not take effect.
  • If the local cell served by the NodeB has been configured in cell groups for Coverage Expansion Under Interference, remove all such cell groups before running this command. Otherwise, this command fails to be executed.
  • NodeB function name must be set the same as the logical NodeB name on the RNC. Otherwise, the MAE cannot associate the NodeBs with the logical NodeBs on the RNC.

Parameters

ID Name Description
NODEBFUNCTIONNAME NodeB Function Name

Meaning: Indicates the NodeB function name.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of NODEBFUNCTIONNAME is a string of characters. The string cannot be null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes(\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

-Others:

  • This parameter must be consistent with the NODEBNAME parameter under the UNodeB MO of the logical NodeB corresponding to the NodeB function on the RNC.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
NODEBID NodeB Identifier

Meaning: Indicates the NodeB ID.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
USERLABEL User Label

Meaning: Indicates the user label.

If a user requires multiple information, the format is "%Name1::Value1%Name2::Value2%other description".

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Modify the User Label of the NodeB to "US":
MOD NODEBFUNCTION: USERLABEL="US";
