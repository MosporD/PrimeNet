Start Downlink Adaptive Band-Pass Filter Test (STR GUDLFILTERTEST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start a Downlink Adaptive Band-Pass Filter test for a specified local cell.

Note

  • When the test function is enabled, Downlink Adaptive Band-Pass Filter in the GU@5 MHz feature or the DC-HSDPA feature on the shared GSM spectrum will use the static filtering function within a specified time period.
  • If the NodeB or app is reset, this function becomes invalid.
