Modify NodeB Algorithm Parameter (SET NODEBALGPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to modify NodeB algorithm parameter.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After Power Configuration Check Switch is turned on, alarms will be generated when the actual system power exceeds the power configuration.
  • When the logical cell is available, the UL Resource Work Mode can not be modified.
  • If the logical cell is available and MC Inter-Board Joint Scheduling Switch is turned off, running this command interrupts ongoing services for less than 1 minute.
  • If the MC Inter-Board Joint Scheduling Switch parameter is changed from OFF to ON, it is good practice to manually run the STR REALLOCLOCELL command to enable the cell configurations. If the command is not manually executed, the NodeB automatically restarts all local cells based on the settings of CSUSERNUM and PSUSERNUM under NODEBRESALLOCRULE to enable the cell configurations.
  • The Mixed-Multi-RRU cell and the distributed cell do not report the Cell RTWP Excessive alarm. The values of CELLRTWPEXCESSALMSW and CELLRTWPEXCESSALMTHD are invalid for the Mixed-Multi-RRU cell and the distributed cell.
  • If UX2SONSETUPSW is set to OFF, the uX2 link that is automatically set up will be automatically deleted, interrupting services on the uX2 link.
  • The value of parameter RTWPIMBALANCEALMTHD is invalid for the RF unit configured in DCU.
  • If the value of parameter UTRPCEXTCNBAPCAP changes, the base station needs to be manually reset.

SFSSWITCH Soft Fault Self-healing Switch

Meaning: Indicates whether to enable soft failure self-healing. When BBPRESETSWITCH is set to ON, if BBPRESETDELAYSWITCH is set to ON, the baseband processing unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if BBPRESETDELAYSWITCH is set to OFF, the baseband processing unit restarts immediately upon detecting soft failures and service exceptions. If BBSFRESHUFFLESWITCH is set to ON, the NodeB attempts to relocate cells served by the faulty baseband module to other baseband modules and restart the faulty module for self-healing after detecting a soft failure on the baseband module.
