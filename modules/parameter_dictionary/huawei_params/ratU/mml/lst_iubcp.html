List Iub Control Port Configuration (LST IUBCP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configuration of an Iub control port.

Note

None

Parameters

None.

Example

To list the configuration of an Iub control port, run the following command:
LST IUBCP:;
The result is shown as follows:
+++    HUAWEI        2012-11-28 15:53:12
O&M    #8814
%%LST IUBCP:;%%
RETCODE = 0  Operation succeeded.

List Iub Control Port Configuration
-----------------------------------
  Port Type  =  NCP Port
Belong Flag  =  MASTER
  CPBear ID  =  0
(Number of results = 1)

List Iub Control Port Configuration
-----------------------------------
  Port Type  =  CCP Port
CP Port No.  =  0
Belong Flag  =  MASTER
  CPBear ID  =  1
(Number of results = 1)


---    END

Output Description

Field Description

Port Type

Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.

CP Port No.

Indicates the number of the Iub control port.

Belong Flag

Indicates the flag of the transport channel to which an Iub control port belongs.

CPBear ID

Indicates the CP bearer ID.
