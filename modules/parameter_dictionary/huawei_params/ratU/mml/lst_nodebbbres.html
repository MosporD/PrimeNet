List NodeB Baseband Resource Configuration (LST NODEBBBRES)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the configuration of a NodeB baseband resource.

Note

  • If NodeB Baseband Resource Identifier is specified, the system queries the specified NodeB baseband resource. If NodeB Baseband Resource Identifier is not specified, the system queries all NodeB baseband resources by default.
  • The NODEBBBRES MO is automatically created based on parameter values in the BBP/MDU MO.

Parameters

ID Name Description
NODEBBBRESID NodeB Baseband Resource Identifier

Meaning: Indicates the ID of a NodeB baseband resource. If the BBWS parameter in the BBP/MDU MO is set to UMTS, the NodeB automatically creates a NODEBBBRES MO on the board and allocates a unique identifier to the MO.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Output Description

Field Description

NodeB Baseband Resource Identifier

Indicates the ID of a NodeB baseband resource. If the BBWS parameter in the BBP/MDU MO is set to UMTS, the NodeB automatically creates a NODEBBBRES MO on the board and allocates a unique identifier to the MO.

Cabinet Number

Indicates the number of the cabinet that houses the referenced multimode baseband board. The NodeB assigns a value to a NODEBBBRES MO created automatically based on the cabinet number in the BBP/MDU MO.

Subrack Number

Indicates the number of the subrack that houses the referenced multimode baseband board. The NodeB assigns a value to a NODEBBBRES MO created automatically based on the subrack number in the BBP/MDU MO.

Slot Number

Indicates the number of the slot that houses the referenced multimode baseband board. The NodeB assigns a value to a NODEBBBRES MO created automatically based on the slot number in the BBP/MDU MO.

Capacity

Indicates the required baseband resource capability if the NodeB needs to use a multimode baseband board. The NodeB assigns a value to a NODEBBBRES MO created automatically based on the BBWS in the BBP/MDU MO.

Administrative State

Indicates the management status of a NodeB baseband resource. Its value can be BLOCKED(Blocked) or UNBLOCKED(Unblocked). BLOCKED means that the baseband resource cannot be used to provide UMTS services. UNBLOCKED means that the baseband resource can be used to provide UMTS services.

Hardware Capacity Enhance

Indicates the hardware capability provided by the baseband board to the system. If this parameter is set to NORMAL, the baseband board provides the basic capability. If this parameter is set to PARTIAL, the baseband board provides the partial hardware capability. If this parameter is set to FULL, the baseband board provides the complete hardware capability. The NodeB assigns a value to a NODEBBBRES MO created automatically based on the HCE in the BBP MO. The BLADEBBU and BBU3910C support only FULL.
