Display uX2 Information (DSP UX2)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the information about a uX2 object.

Note

None.

Parameters

ID Name Description
UX2ID uX2 Object ID

Meaning: Indicates the uX2 object ID.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To query the information about the uX2 object, run the following command: 
DSP UX2:;
If multiple uX2 interfaces are configured, the result is shown as follows: 
+++    0        2015-05-15 15:45:20
O&M    #537919504
%%DSP UX2:;%%
RETCODE = 0  Operation succeeded.

Display uX2 Information
-----------------------
uX2 Object ID  uX2 Interface ID  uX2 Interface State  uX2 Interface CP Bearer ID  uX2 Interface CP Bearer State

0              5                 Normal               1                           Normal                      
0              6                 Abnormal             2                           Abnormal                     
(Number of results = 2)


---    END

If only one uX2 interface is configured, the result is shown as follows:  
DSP UX2:;
The result is shown as follows: 
+++    0        2015-05-15 15:46:20
O&M    #537919506
%%DSP UX2:;%%
RETCODE = 0  Operation succeeded.

Display uX2 Information
-----------------------
                uX2 Object ID  =  0
             uX2 Interface ID  =  5
          uX2 Interface State  =  Normal
   uX2 Interface CP Bearer ID  =  1
uX2 Interface CP Bearer State  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

uX2 Object ID

Indicates the uX2 object ID.

uX2 Interface ID

Indicates the uX2 interface ID.

uX2 Interface State

Indicates the status of the uX2 interface.

uX2 Interface CP Bearer ID

Indicates the control-plane bearer ID of the uX2 interface.

uX2 Interface CP Bearer State

Indicates the status of the control-plane bearer for the uX2 interface.
