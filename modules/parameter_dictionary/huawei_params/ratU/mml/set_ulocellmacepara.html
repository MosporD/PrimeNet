Set Mac-e Parameters (SET ULOCELLMACEPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set the Mac-e parameters.

Note

  • A modification on the following parameters does not affect ongoing services, but affects only the services that are established later: E-AGCH HPC Parameters, E-RGCH HPC Parameters, and E-HICH HPC Parameters.
  • If LOCELLTYPE is set to IMB_CELL, this command is invalid.

ULSECCELLDEACTCOVTHR Secondary DC-HSUPA Cell Deactivation Rate Threshold

Meaning: Indicates the minimum rate threshold supported by the uplink transmit power for ensuring the minimum coverage of activated DC-HSUPA UEs on the secondary carrier. To be specific, to meet the minimum coverage requirements of activated DC-HSUPA cell edge UEs (CEUs) on the secondary carrier, the maximum rate threshold supported by the uplink transmit power cannot be lower than this threshold. Otherwise, the CEUs on the secondary carrier need to be deactivated.

GUI Value Range: 0~1000

Unit: 10kbps

Actual Value Range: 0~10000, step: 10

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to 50 if uplink transmit power-based deactivation of UEs on the secondary carrier needs to be enabled.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter indicates a high probability of uplink transmit power-based deactivation of UEs on the secondary carrier. This operation improves the edge throughput of DC-HSUPA UEs (reaching SC-HSUPA performance), but decreases the number of activated DC-HSUPA UEs on the secondary carrier. A small value of this parameter indicates a low probability of uplink transmit power-based deactivation of UEs on the secondary carrier. There are available loads on the secondary carrier, which ensures data transmission of DC-HSUPA UEs and maximizes the usage of air interface resources on the secondary carrier.

GUI Value Range: SGALGFIRSTFOR2MSUSER(SG Algorithm 1 for 2ms TTI User), SGALGSECONDFOR2MSUSER(SG Algorithm 2 for 2ms TTI User)

Unit: None

Actual Value Range: SGALGFIRSTFOR2MSUSER, SGALGSECONDFOR2MSUSER

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to SGALGFIRSTFOR2MSUSER, the minimum SG for HSUPA 2 ms TTI users is three RLC PDUs during data transmission, which decreases the access delay and improves the user throughput. However, the BLER of HSUPA 2 ms TTI users slightly increases and the value of VS.MeanRTWP increases. When this parameter is set to SGALGSECONDFOR2MSUSER, the minimum SG for HSUPA 2 ms TTI users is one RLC PDU during data transmission. This decreases the BLER of HSUPA 2 ms TTI users and the value of VS.MeanRTWP, but affects the access delay and throughput of HSUPA 2 ms TTI users.

Applicable Mode: U

Example

Execute this command to modify the parameters of Mac-e scheduling:
SET ULOCELLMACEPARA: SCHEDULEPARA=NO, EAGCHPCPARA=NO, SERGCHPCPARA=NO, NSERGCHPCPARA=NO, HSUPATDSCHSW=ON, HSUPATDALIGNUENUM=8, HSUPATDSCHENSW=ON;
