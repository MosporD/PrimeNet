List uX2 Configuration (LST UX2)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configurations of uX2 object.

Note

None.

Parameters

ID Name Description
UX2ID uX2 Object ID

Meaning: Indicates the uX2 object ID.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To list the configurations of the uX2 object, run the following command: 
LST UX2:;
The result is shown as follows:
+++    0        2015-09-19 11:17:43
O&M    #806358168
%%LST UX2:;%%
RETCODE = 0  Operation succeeded.

List uX2 Configuration
----------------------
                   uX2 Object ID  =  0
Control Plane End-Point Group ID  =  1
   User Plane End-Point Group ID  =  2
          uX2 Object Description  =  NULL
             Static Check Switch  =  OFF
(Number of results = 1)


---    END

Output Description

Field Description

uX2 Object ID

Indicates the uX2 object ID.

Control Plane End-Point Group ID

Indicates the ID of the control-plane endpoint group used by the uX2 object.

User Plane End-Point Group ID

Indicates the ID of the user-plane endpoint group used by the uX2 object.

uX2 Object Description

Indicates the uX2 object description.

Static Check Switch

Indicates whether to enable static UDP Ping detection over the uX2 interface. If this parameter is set to ON, static UDP Ping detection is enabled over the uX2 interface. If this parameter is set to OFF, static UDP Ping detection is disabled over the uX2 interface.
