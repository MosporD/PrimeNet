Display CHR Level (DSP NODEBCHRLEVEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query effective CHR events.

Note

None.

Parameters

None.

Example

Query effective CHR events:
DSP NODEBCHRLEVEL:;
The result is shown as follows:

Output Description

Field Description

Common CHR Event Switch

Indicates the type of common CHR events. If an option is selected, corresponding contents will be automatically logged.

User CHR Event Switch

Indicates the type of user-level CHR events. If an option is selected, corresponding contents will be automatically logged.

Common CHR Period Event Switch

Indicates the type of common periodic CHR events. If an option is selected, corresponding contents will be automatically logged.

User CHR Period Event Switch

Indicates the type of user-level periodic CHR events. If an option is selected, corresponding contents will be automatically logged.
