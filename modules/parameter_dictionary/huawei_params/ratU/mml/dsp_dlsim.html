Display DL Load Simulation Result (DSP DLSIM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to display the current load ratio of downlink network load simulation of a specified local cell or all local cells.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Display the current load radio of downlink network load simulation of the local cell whose ID is "369":
DSP DLSIM: ULOCELLID=369;
The result is shown as follows:
+++    HUAWEI        2019-09-29 11:49:12
O&M    #93
%%DSP DLSIM: ULOCELLID=369;%%
RETCODE = 0  Operation succeeded.

Successful Local Cell List

                                       Local Cell ID  =  369
                               Simulating Load Ratio  =  29
                           Common Channel Load Ratio  =  24
                                  Service Load Ratio  =  0
                               Configured Load Ratio  =  50
Downlink Network Load Simulation Optimization Switch  =  OFF
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

Simulating Load Ratio

Indicates the load rate of analog channels after analog load is enabled.

Common Channel Load Ratio

Indicates the load rate of common channels.

Service Load Ratio

Indicates the load rate of actual traffic channels (dedicated channels) except common channels and analog channels.

Configured Load Ratio

Indicates the configured load rate after analog load is enabled.

Cause

Indicates the cause of failure.

Downlink Network Load Simulation Optimization Switch

Indicates the switch for downlink network load simulation optimization. When this switch is turned on, the NodeB optimizes the downlink network load simulation. When this switch is turned off, the NodeB does not optimize the downlink network load simulation.
