List Sector Equipment Used by Sector Equipment Group (LST ULOCELLSECTOREQMGRPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to query the configuration information of the sector equipment in the sector equipment group of a cell.

Note

  • If the sector equipment group ID is not specified, the number of sector equipment in the sector equipment group is displayed.
  • If the sector equipment group ID is specified, the ID of each sector equipment in the sector equipment group is displayed.
  • The local cell to be queried must be configured as a Mixed-Multi-RRU cell and the sector equipment group must have been configured. Otherwise, execution of this command fails.

Example

List parameters related to the sector equipment in sector equipment group 0 of local cell 14506:
LST ULOCELLSECTOREQMGRPITEM: ULOCELLID=14506, SECTOREQMGRPID=0;
