Set Smooth Power Change Parameters (SET NODEBSMTHPWRPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set parameters of smooth power change function.

Note

None

Parameters

ID Name Description
STEP Smart Default Step

Meaning: Indicates the smart default step.

GUI Value Range: 1~20

Unit: 0.5dB

Actual Value Range: 0.5~10, step: 0.5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PERIOD Smart Default Time Ratio

Meaning: Indicates the smart default time ratio.

GUI Value Range: 1~5

Unit: 100ms

Actual Value Range: 100~500, step: 100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Execute this command to set the smooth power change function parameters:
SET NODEBSMTHPWRPARA: STEP=3, PERIOD=5;
