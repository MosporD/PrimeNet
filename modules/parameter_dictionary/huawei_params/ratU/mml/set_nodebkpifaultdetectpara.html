Set NodeB KPI Fault Algorithm Parameter (SET NODEBKPIFAULTDETECTPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set invisible fault alarm-related parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that related detection functions are enabled by specifying the KPIFAULTDETECT parameter in the SET NODEBALGPARA command.
  • A small value of R99 User Fault Detect Threshold, UPA User Fault Detect Threshold, or Process Unit Fault Detect Threshold may cause false alarms.
  • A small value of Board Invisible Fault Alarm Occur Period may cause false alarms.

Parameters

ID Name Description
R99FAULTTHD R99 User Fault Detect Threshold

Meaning: Indicates the threshold for determining whether an R99 user has a high BLER.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of R99FAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of R99FAULTTHD(70%) and the value of PROTECTIONTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
UPAFAULTTHD UPA User Fault Detect Threshold

Meaning: Indicates the threshold for determining whether an HSUPA user has a high BLER.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of UPAFAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of UPAFAULTTHD(98%) and the value of PROTECTIONTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PROCUNITFAULTTHD Process Unit Fault Detect Threshold

Meaning: Indicates the threshold for determining whether a processing unit has a high proportion of abnormal users.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of PROCUNITFAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of PROCUNITFAULTTHD(90%) and the value of PROTECTIONTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PROTECTIONTHD Traffic Fault Detect Threshold protection

Meaning: Indicates the threshold of fault detection protection. The configured R99 User Fault Detect Threshold, UPA User Fault Detect Threshold, or Process Unit Fault Detect Threshold cannot be less than the difference between the corresponding default threshold and the fault detection protection threshold.

GUI Value Range: 0~50

Unit: %

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of R99FAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of R99FAULTTHD(70%) and the value of PROTECTIONTHD.
  • The value of UPAFAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of UPAFAULTTHD(98%) and the value of PROTECTIONTHD.
  • The value of PROCUNITFAULTTHD in the NODEBALGPARA MO cannot be less than the difference between the default value of PROCUNITFAULTTHD(90%) and the value of PROTECTIONTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PROCUNITFAULTCLEARTHD Process Unit Fault Clear Threshold

Meaning: Indicates the threshold of determining whether a processing unit is restored after its faults are rectified.

GUI Value Range: 0~50

Unit: %

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
ALMOCCURPRD Board Invisible Fault Alarm Occur Period

Meaning: Indicates the time segment during which invisible fault alarms are detected on the board through the service function.

GUI Value Range: 1~100

Unit: 15min

Actual Value Range: 15~1500, step: 15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
ALMCLEARPRD Board Invisible Fault Alarm Clear Period

Meaning: Indicates the number of times invisible fault alarms are cleared on the board through the service function within a measurement period.

GUI Value Range: 1~100

Unit: 15min

Actual Value Range: 15~1500, step: 15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Set invisible fault alarm-related parameters:
SET NODEBKPIFAULTDETECTPARA: R99FAULTTHD=70, UPAFAULTTHD=98, PROCUNITFAULTTHD=90, PROTECTIONTHD=10, PROCUNITFAULTCLEARTHD=15, ALMOCCURPRD=12, ALMCLEARPRD=2;
