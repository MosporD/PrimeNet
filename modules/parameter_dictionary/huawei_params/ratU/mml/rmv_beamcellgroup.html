Remove Beam Cell Group (RMV BEAMCELLGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to delete beam cell group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Executing this command will make the local cells in the beam cell group to be unavailable.

Parameters

ID Name Description
BEAMCELLGROUPID Beam Cell Group ID

Meaning: Indicates the ID of beam cell group.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove a beam cell group with the parameter as follows: Beam Cell Group ID: 0, run the following command:
RMV BEAMCELLGROUP: BEAMCELLGROUPID=0;
