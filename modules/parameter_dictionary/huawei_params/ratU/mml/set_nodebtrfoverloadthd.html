Set Traffic Over Load Alarm Threshold (SET NODEBTRFOVERLOADTHD)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set traffic overload threshold parameters. The parameters vary with the service characteristics of the base station.

Note

None

Parameters

ID Name Description
TRAFFICOVERLOADOTHD Traffic Over Load Alarm Occur Threshold

Meaning: Indicates the ratio of the number of times the system does not provide services to the number of attempts. The Base Station Traffic Overload alarm is reported when the ratio is higher than the preset threshold.

GUI Value Range: 10~100

Unit: %

Actual Value Range: 10~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
TRAFFICOVERLOADOPRD Traffic Over Load Alarm Detect Period

Meaning: Indicates the period of detecting traffic overload alarms.

GUI Value Range: 1~13107

Unit: 5s

Actual Value Range: 5~65535, step: 5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
TRAFFICOVERLOADRTHD Traffic Over Load Alarm Recover Threshold

Meaning: Indicates the ratio of the number of times the system does not provide services to the number of attempts. The Base Station Traffic Overload alarm is cleared when the ratio is smaller than the preset threshold.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
TRAFFICOVERLOADRPRD Traffic Over Load Alarm Recover Period

Meaning: Indicates the period of clearing traffic overload alarms.

GUI Value Range: 1~13107

Unit: 5s

Actual Value Range: 5~65535, step: 5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Execute this command to Set Traffic Over Load Alarm Threshold:
SET NODEBTRFOVERLOADTHD: TRAFFICOVERLOADOTHD=10, TRAFFICOVERLOADOPRD=600, TRAFFICOVERLOADRTHD=5, TRAFFICOVERLOADRPRD=600;
