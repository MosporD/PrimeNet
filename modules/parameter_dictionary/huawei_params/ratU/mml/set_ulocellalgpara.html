Set algorithm parameter (SET ULOCELLALGPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to set the algorithm parameters of a specific cell or all cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If R99TOHPWSHSW is set to ON, power can be shared between R99 and HSDPA cells only when they share a power amplifier and have this switch turned on.
  • If HTOHPWSHSW is set to ON, power can be shared between HSDPA cells only when they share a power amplifier and have this switch turned on.
  • If HTOHPWSHSW is set to ON, a local cell whose downlink resources are established on the WBBPa board cannot share available power with other cells.
  • Parameters associated with rules are introduced to accommodate the Automatic Congestion Handler (Phase2) feature. The mapping between parameters and rules is as follows: SIB7RTWPOPTSW and SIB7MAXRTWP associate with rules 0 and 1 respectively, and RTWPSIRTGTADJSW associates with rules 2 and 3. Parameters associated with rules are introduced to accommodate the Automatic Congestion Handler (Phase3) feature. The mapping between parameters and rules is as follows: DPCHMAXTXPWRRESTRSW associates with rule 8, RADIOQUALITYDPCHPCSW associates with rule 9 and DPCHTPCPOADJSW associates with rule 10. According to the mapping between a parameter and a rule, run the DSP NODEBRULEACTIONPARA command to query the rule activation status for a cell. If the rule is activated, run the LST NODEBRULEACTIONPARA command to query the setting of Administrative State. If Administrative State is ENABLE, the parameter settings in the SET ULOCELLALGPARA command will not take effect. Accordingly, the NODEBRULEACTIONPARA parameter settings take effect.
  • Configuration of co-polarization grouping information may result in transient and abrupt cell coverage changes, causing call drops to some extent. Before running the command, you are advised to run the LST ULOCELLALGPARA command to query and save the co-polarization grouping information of each cell.

DPCHMAXPWRRTRLOADSTAT The Load State to Control DPCH Maximum Power Restriction Algorithm

Meaning: Load state when the DPCH maximum power restriction algorithm takes effect. When the downlink non-HSPA power load is in the load state set by this parameter or a heavier load state, the maximum DPCH power restriction algorithm is triggered.

Based on load level in ascending order (from light load to heavy load), the downlink non-HSPA power load states are as follows:

DlLightState: indicates the downlink resource light load state threshold 0%.

DlNormalState: indicates the downlink resource normal load state threshold 30%.

DlLoadedState: indicates the downlink resource light congestion state threshold 50%.

DlHeavyState: indicates the downlink resource severe congestion state threshold 70%.

DlOverloadState: indicates the downlink resource extreme congestion state threshold 95%. The following provides the method for determining the downlink non-HSPA power load state:

If the non-HSPA power load for a cell exceeds the threshold corresponding to the load state when the DPCH maximum power restriction algorithm takes effect plus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a heavier load state. In this case, the DPCH maximum power restriction algorithm is triggered. Note that 10% is not added when the downlink non-HSPA power load is in the downlink resource extreme congestion state.

If the non-HSPA power load for a cell decreases below the threshold corresponding to the load state when the DPCH maximum power restriction algorithm takes effect minus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a lighter load state. In this case, the DPCH maximum power restriction algorithm is not triggered. Note that 10% is not subtracted when the downlink non-HSPA power load is in the downlink resource light load state.

Actual Value Range: DLLIGHTSTATE, DLNORMALSTATE, DLLOADEDSTATE, DLHEAVYSTATE, DLOVERLOADSTATE

MML Default Value: None

Recommended Value: DLLOADEDSTATE(DLLOADEDSTATE)

Impact on Radio Network Performance: A lighter load indicates that the algorithm is more easily triggered. That is, the transmit power of the associated DPCH more easily decreases, which affects the network KPIs such as the call drop rate. A heavier load indicates that the algorithm is more difficult to be triggered. This reduces the downlink non-HSPA power and throughput gains.
