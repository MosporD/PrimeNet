Add Multiple Carrier Cell Group Item (ADD NODEBMULTICELLGRPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to add local cell to multiple carrier cell group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Local cells in the multiple carrier cell group must exist.
  • If the local cells in the same multiple carrier cell group are distributed cells, their RRUs must have the same configuration.
  • DL Baseband Equipment of the local cells in a Multiple Carrier Cell Group must be same.
  • A macro cell can belong to a maximum of three multicarrier HSDPA cell groups, and a micro cell can belong to a maximum of one multicarrier HSDPA cell group.
  • A local cell belongs on only one MC-HSUPA group.
  • If the logical cell is available and MC Inter-Board Joint Scheduling Switch is turned off, adding a local cell to a multi-carrier cell group interrupts ongoing services carried in all the cells in the multi-carrier cell group for less than 5 minutes.

Example

Add a No.0 multiple carrier cell to the No.0 multiple carrier cell group:
ADD NODEBMULTICELLGRPITEM: MULTICELLGRPID=0, ULOCELLID=0;
