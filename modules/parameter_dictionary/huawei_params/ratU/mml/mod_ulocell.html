Modify Local Cell (MOD ULOCELL)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to modify some of the properties of the local cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The local cell ID and the type of the local cell cannot be modified.
  • Before modifying UL and DL UARFCNs of the local cell, ensure that the updated UL and DL UARFCNs are within the same frequency band.
  • If ULFREQ is not configured but DLFREQ is configured, the system will automatically configure ULFREQ according to the 3GPP specifications.
  • The ULFREQIND parameter indicates the uplink frequency indicator. This parameter cannot be set on the MML GUI. If ULFREQ is configured, ULFREQIND will be automatically set to TRUE, if ULFREQ is not configured but DLFREQ is configured, ULFREQIND will be automatically set to FALSE.
  • Different cells in a sector equipment must use unique UARFCNs.
  • The frequency of the local cell must be supported by the PA. Otherwise, the local cell is unavailable.
  • When the logical cell is available, services will be interrupted by the modification of radius larger than or less than 30 km. That is, when the radius exceeds 30 km, it is modified to the figure less than or equal to 30 km; when the radius is less than or equal to 30 km, it is modified to the figure larger than 30 km. Therefore, do not perform the operation when the logical cell exists.
  • When the parameter configuration exceeds the device capabilities, the command execution changes the operation status of the cell.
  • The uplink and downlink frequency spacing for the local cell should be the fixed frequency spacing specified by the protocol. The fixed frequency spacing varies with band. For details, see the fixed frequency spacing described in the ULFREQ and DLFREQ parameters. Otherwise, UEs fail to search for the network or network performance is not optimum.
  • For a 0.5/0.5 cell, if the coverage type is the same coverage, the ratio of the transmit power of the local cell under each sector equipment to the total cell power must be 50%. If the coverage type is the different coverage, the ratio of transmit power of the local cell under the sector equipment to the total cell power must be 100%.
  • During a change in the maximum transmit power of a multiple-RRU cell or Mixed-Multi-RRU cell, the changed power is less than the power of the sector equipment (except 65535), the power of the sector equipment will be changed to the maximum transmit power of the cell to ensure that power of the sector equipment of the local cell does not exceed the maximum transmit power.
  • Parameters associated with rules are introduced to accommodate the Automatic Congestion Handler (Phase2) feature. The mapping between parameters and rules is as follows: ICMODE and TURBOIC associate with rules 4 and 7 respectively. According to the mapping between a parameter and a rule, run the DSP NODEBRULEACTIONPARA command to query the rule activation status for a cell. If the rule is activated, run the LST NODEBRULEACTIONPARA command to query the setting of Administrative State. If Administrative State is ENABLE, the parameter settings in the MOD ULOCELL command will not take effect. Accordingly, the NODEBRULEACTIONPARA parameter settings take effect.
  • Uplink baseband equipment and downlink baseband equipment for all local cells must have the same number of cabinet where boards are located.
  • When LOCELLTYPE is set to NORMAL_CELL, BFMODE is set to NORMALBEAM for a 4T4R cell configured in the BEAMCELLGROUP MO: if the antenna device used by the cell is AAU5972/AAU5973e, the value range of MAXPWR is the intersection of value ranges [P1max - 15 dB, P1max + 4 dB], [P2max - 15 dB, P2max + 4 dB], [P3max - 15 dB, P3max + 4 dB], and [P4max - 15 dB, P4max + 4 dB]; if the antenna device used by the cell is AAU5973, the value range of MAXPWR is the intersection of value ranges [P1max - 13 dB, P1max + 6 dB], [P2max - 13 dB, P2max + 6 dB], [P3max - 13 dB, P3max + 6 dB], and [P4max - 13 dB, P4max + 6 dB]. Pnmax (n is the ID of the power amplifier) is the maximum output power of the power amplifier at the top of the cabinet.
  • When LOCELLTYPE is set to NORMAL_CELL, BFMODE is set to MASSIVEBEAM for a cell configured in the BEAMCELLGROUP MO under which BEAMCELLGROUPTYPE is MASSIVEBEAM8T8R: if the antenna device used by the cell is AAU5972/AAU5973, the value range of MAXPWR is the intersection of value ranges [P1max - 15 dB, P1max + 4 dB], [P2max - 15 dB, P2max + 4 dB], [P3max - 15 dB, P3max + 4 dB], and [P4max - 15 dB, P4max + 4 dB]; if the antenna device used by the cell is AAU5973e, the value range of MAXPWR is the intersection of value ranges [P1max - 15.2 dB, P1max + 3.8 dB], [P2max - 15.2 dB, P2max + 3.8 dB], [P3max - 15.2 dB, P3max + 3.8 dB], and [P4max - 15.2 dB, P4max + 3.8 dB]. Pnmax (n is the ID of the power amplifier) is the maximum output power of the power amplifier at the top of the cabinet.
