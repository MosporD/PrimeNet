Set Associated Parameters for a Rule (SET NODEBRULEACTIONPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to modify the configurations of associated parameters for a rule. The RNC delivers rules to NodeBs depending on network conditions.

Note

  • If this command is executed to modify the configurations of associated parameters for a rule, ensure that the new configurations match the scenario of the rule defined on the RNC.
  • It is recommended that the value of the PARAINTERVALVALUE parameter associated with rule 5 (when Rule ID is 5) be greater than that associated with rule 6 (when Rule ID is 6) and the value of the EXTRAPOWER parameter under the ULOCELLMACHSPARA MO.

Parameters

ID Name Description
RULEID Rule ID

Meaning: Indicates the ID of a rule. The parameter value range extends with the rule quantity. Rule IDs 0 and 1 indicate that the SIB7RTWPOPTSW and SIB7MAXRTWP parameters must be configured. Rule IDs 2 and 3 indicate that the RTWPSIRTGTADJSW parameter must be configured. Rule ID 4 indicates ICMODE parameter must be configured. Rule IDs 5 and 6 indicate that the EXTRAPOWER parameter must be configured. Rule ID 7 indicates that TURBOIC parameter must be configured. Rule ID 8 indicates that DPCHMAXTXPWRRESTRSW parameter must be configured. Rule ID 9 indicates that RADIOQUALITYDPCHPCSW parameter must be configured. Rule ID 10 indicates that DPCHTPCPOADJSW parameter must be configured.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
MOCNAME MO Name

Meaning: Indicates the name of an MO whose parameters are associated with a rule.

GUI Value Range: ULOCELLALGPARA(Local Cell Algorithm Para), ULOCELL(Local Cell), ULOCELLMACHSPARA(Local Cell Mac-hs Para)

Unit: None

Actual Value Range: ULOCELLALGPARA, ULOCELL, ULOCELLMACHSPARA

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If RULEID is set to 0~3 or 8~10, this parameter must be set to ULOCELLALGPARA. If RULEID is set to 4 or 7, this parameter must be set to ULOCELL. If RULEID is set to 5 or 6, this parameter must be set to ULOCELLMACHSPARA.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
PARANAME Parameter Name

Meaning: Indicates the name of a parameter associated with a rule.

GUI Value Range: RTWPSIRTGTADJSW(RTWP Abnormal SIR Target Adjust SW), SIB7RTWPOPTSW(SW for RTWP OPT in SIB7), SIB7MAXRTWP(Maximum RTWP Value in SIB7), ICMODE(IC), EXTRAPOWER(Extra Power), TURBOIC(Turbo IC), DPCHMAXTXPWRRESTRSW(DPCH Max Power Restriction SW), RADIOQUALITYDPCHPCSW(DPCH Power Control Based on CQI SW), DPCHTPCPOADJSW(DPCH TPC Power Adjustment SW)

Unit: None

Actual Value Range: RTWPSIRTGTADJSW, SIB7RTWPOPTSW, SIB7MAXRTWP, ICMODE, EXTRAPOWER, TURBOIC, DPCHMAXTXPWRRESTRSW, RADIOQUALITYDPCHPCSW, DPCHTPCPOADJSW

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If RULEID is set to 0 or 1, this parameter must be set to SIB7RTWPOPTSW or SIB7MAXRTWP. If RULEID is set to 2 or 3, this parameter must be set to RTWPSIRTGTADJSW. If RULEID is set to 4, this parameter must be set to ICMODE. If RULEID is set to 5 or 6, this parameter must be set to EXTRAPOWER. If RULEID is set to 7, this parameter must be set to TURBOIC. If RULEID is set to 8, this parameter must be set to DPCHMAXTXPWRRESTRSW. If RULEID is set to 9, this parameter must be set to RADIOQUALITYDPCHPCSW. If RULEID is set to 10, this parameter must be set to DPCHTPCPOADJSW.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
PARAENUMVALUE Enumerate Type Value

Meaning: Indicates the value of an enumeration-type parameter.

GUI Value Range: OFF(Off), ON(On), FALSE(False), TRUE(True)

Unit: None

Actual Value Range: OFF, ON, FALSE, TRUE

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If PARANAME is set to RTWPSIRTGTADJSW, SIB7RTWPOPTSW, DPCHMAXTXPWRRESTRSW, RADIOQUALITYDPCHPCSW or DPCHTPCPOADJSW, this parameter must be set to OFF or ON.
  • If PARANAME is set to ICMODE or TURBOIC, this parameter must be set to FALSE or TRUE.
  • If PARANAME is set to SIB7MAXRTWP or EXTRAPOWER, the value of this parameter will be automatically set to NULL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PARAINTERVALVALUE Interval Type Value

Meaning: Indicates the value of an interval-type parameter. The value 2147483647 is invalid and cannot be configured by users.

GUI Value Range: 0~60

Unit: None

Actual Value Range: 0~60,2147483647

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If PARANAME is set to SIB7MAXRTWP, the value of this parameter ranges from 0 to 60.
  • If PARANAME is set to EXTRAPOWER, the value of this parameter ranges from 0 to 40, the parameter value is in the unit of 0.25 dB.
  • If PARANAME is set to ICMODE, TURBOIC, RTWPSIRTGTADJSW, SIB7RTWPOPTSW, DPCHMAXTXPWRRESTRSW, RADIOQUALITYDPCHPCSW or DPCHTPCPOADJSW, the value of this parameter will be automatically set to NULL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
ADMINSTATE Administrative State

Meaning: Indicates the status of association between a parameter and a specified rule. DISABLE indicates that the parameter is disassociated from the specified rule. ENABLE indicates that the parameter is associated with the specified rule.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: For details about the impact of a parameter associated with a specified rule, see the description of Impact on Radio Network Performance for this parameter.

Applicable Mode: U
USERLABEL User Label

Meaning: Indicates user-defined information about a rule.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Set associated parameters for a rule:
SET NODEBRULEACTIONPARA: RULEID=5, MOCNAME=ULOCELLMACHSPARA, PARANAME=EXTRAPOWER, PARAINTERVALVALUE=12, ADMINSTATE=ENABLE, USERLABEL="EXTRAPOWER";
