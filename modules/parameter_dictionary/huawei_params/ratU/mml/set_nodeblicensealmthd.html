Set License Alarm Threshold (SET NODEBLICENSEALMTHD)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to modify the license alarm threshold and detect period parameters.

Note

None

Parameters

ID Name Description
OTHD Alarm Occur Threshold

Meaning: Indicates the threshold of triggering ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship:

-Configuration constraints:

  • In the NODEBLICENSEALMTHD MO, the value of OTHD must be larger than or equal to RTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
OPRD Alarm Detect Period

Meaning: Indicates the interval for detecting ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

GUI Value Range: 1~65535

Unit: min

Actual Value Range: 1~65535

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
RTHD Alarm Recover Threshold

Meaning: Indicates the threshold of clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

GUI Value Range: 49~99

Unit: %

Actual Value Range: 49~99

MML Default Value: None

Recommended Value: 90

Parameter Relationship:

-Configuration constraints:

  • In the NODEBLICENSEALMTHD MO, the value of OTHD must be larger than or equal to RTHD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
RPRD Alarm Recover Period

Meaning: Indicates the interval for clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.

GUI Value Range: 1~65535

Unit: min

Actual Value Range: 1~65535

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To modify the license alarm threshold and detect period parameters:
SET NODEBLICENSEALMTHD: OTHD=50, OPRD=1, RTHD=50, RPRD=1;
