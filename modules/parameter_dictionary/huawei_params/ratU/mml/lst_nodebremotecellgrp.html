Query Remote Cell Group (LST NODEBREMOTECELLGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the properties of the resource group of remote coverage cells, including group number and group name.

Note

  • If the number of the resource group of remote coverage cells is not specified, the information of all resource groups of remote coverage cells are listed.
  • If the number of the resource group of remote coverage cells is specified, the resource group to be queried must exist. Otherwise, the running of the command fails.

Parameters

ID Name Description
REMOTECELLGRPINDEX Remote Cell Group No.

Meaning: Indicates the number of the resource group of remote coverage cells.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Use the following command to list the information of all resource groups of remote coverage cells:
LST NODEBREMOTECELLGRP:;
The result is shown as follows:
+++    HUAWEI        2014-01-05 20:46:53
O&M    #2312
%%LST NODEBREMOTECELLGRP:;%%
RETCODE = 0  Operation succeeded.

List Remote Cell Group
----------------------
 Remote Cell Group No.  =  0
Remote Cell Group Name  =  REMOTECELLGRP-1
(Number of results = 1)


---    END

2.Use the following command to list the information of the resource group of remote coverage cell whose number is "0":
LST NODEBREMOTECELLGRP: REMOTECELLGRPINDEX=0;
The result is shown as follows:
+++    HUAWEI        2014-01-05 20:46:29
O&M    #2309
%%LST NODEBREMOTECELLGRP: REMOTECELLGRPINDEX=0;%%
RETCODE = 0  Operation succeeded.

List Remote Cell Group
----------------------
 Remote Cell Group No.  =  0
Remote Cell Group Name  =  REMOTECELLGRP-1
(Number of results = 1)


---    END

Output Description

Field Description

Remote Cell Group No.

Indicates the number of the resource group of remote coverage cells.

Remote Cell Group Name

Indicates the name of the resource group of remote coverage cells.
