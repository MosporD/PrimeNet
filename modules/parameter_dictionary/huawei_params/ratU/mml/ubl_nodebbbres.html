Unblock NodeB Baseband Resource (UBL NODEBBBRES)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to unblock a NodeB baseband resource.

Note

The NodeB baseband resource to be unblocked must have been configured. Otherwise, this command fails to be executed.

Parameters

ID Name Description
NODEBBBRESID NodeB Baseband Resource Identifier

Meaning: Indicates the ID of a NodeB baseband resource. If the BBWS parameter in the BBP/MDU MO is set to UMTS, the NodeB automatically creates a NODEBBBRES MO on the board and allocates a unique identifier to the MO.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Unblock the NodeB baseband resource with ID 0:
UBL NODEBBBRES: NODEBBBRESID=0;
