Modify DL Load Simulation (MOD DLSIM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to modify the load radio of downlink network load simulation of a specified local cell or all local cells.

After starting the DL load simulation, if the load radio is not suitable, use this command to modify the load radio.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The command can be successfully executed only when the load simulation of downlink network exists and the corresponding logical cell is available.
  • The load ratio takes effect right after the modification.
  • If the downlink load simulation is changed in a cell carrying services, ensure that the simulated load is within the normal range of load value. If the simulated load is too high, the downlink channel is deteriorated and therefore the RNC terminates the valid services based on measurement reports, or call drops occur because of deteriorated SNR.

LR Load Ratio

Meaning: Indicates the Load Ratio.

GUI Value Range: 1~99

Unit: %

Actual Value Range: 1~99

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
DLSIMOPTSW Downlink Network Load Simulation Optimization Switch

Meaning: Indicates the switch for downlink network load simulation optimization. When this switch is turned on, the NodeB optimizes the downlink network load simulation. When this switch is turned off, the NodeB does not optimize the downlink network load simulation.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Modify the load ratio of the downlink network simulation of the local cell whose ID is "10" to 50%:
MOD DLSIM: ULOCELLID=10, LR=50;
