Display uX2 Interface Information (DSP UX2INTERFACE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query uX2 interface information.

Note

None.

Parameters

ID Name Description
UX2INTERFACEID uX2 Interface ID

Meaning: Indicates the uX2 interface ID.

GUI Value Range: 0~95

Unit: None

Actual Value Range: 0~95

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.To query the information about all the uX2 interfaces, run the following command: 
DSP UX2INTERFACE:;
The result is shown as follows: 
+++    0        2015-05-15 15:18:04
O&M    #537919497
%%DSP UX2INTERFACE:;%%
RETCODE = 0  Operation succeeded.

Display uX2 Interface Information
---------------------------------
uX2 Interface ID  uX2 Interface CP Bearer ID  Peer RNC ID  Peer NodeB ID  uX2 Interface State  Abnormal Cause

5                 1                           100          150            Normal               Null          
6                 2                           NULL         NULL           Abnormal             Sctp Link Fault
(Number of results = 2)


---    END

2.To query the information about the uX2 interface whose ID is 5, run the following command: 
DSP UX2INTERFACE: UX2INTERFACEID=5;
The result is shown as follows: 
+++    0        2015-05-15 15:19:44
O&M    #537919499
%%DSP UX2INTERFACE: UX2INTERFACEID=5;%%
RETCODE = 0  Operation succeeded.

Display uX2 Interface Information
---------------------------------
          uX2 Interface ID  =  5
uX2 Interface CP Bearer ID  =  1
               Peer RNC ID  =  100
             Peer NodeB ID  =  150
       uX2 Interface State  =  Normal
            Abnormal Cause  =  Null
(Number of results = 1)


---    END

Output Description

Field Description

uX2 Interface ID

Indicates the uX2 interface ID.

uX2 Interface CP Bearer ID

Indicates the control-plane bearer ID of the uX2 interface.

Peer RNC ID

Indicates the ID of the peer RNC for the uX2 interface.

Peer NodeB ID

Indicates the ID of the peer NodeB for the uX2 interface.

uX2 Interface State

Indicates the status of the uX2 interface.

Abnormal Cause

Indicates the reason why the uX2 interface becomes abnormal.
