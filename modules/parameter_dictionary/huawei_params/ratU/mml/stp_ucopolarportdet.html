Stop Antenna Port Co-Polarization Detection (STP UCOPOLARPORTDET)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to stop the antenna port co-polarization detection function for all cells.

Note

Executing this command will stop the antenna port co-polarization detection function for all cells.

Parameters

None.

Example

1.Stop antenna port co-polarization detection for all local cells:
STP UCOPOLARPORTDET:;
