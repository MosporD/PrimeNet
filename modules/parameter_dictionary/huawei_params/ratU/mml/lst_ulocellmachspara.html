List Mac-hs Scheduling Parameters (LST ULOCELLMACHSPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to obtain the Mac-hs parameters of specified or all local cells.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

LST ULOCELLMACHSPARA:;

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

Resource Allocate Method

Indicates the Resource Allocate Method. Radio resources indicate HSDPA available power resources and code resources. Code Priority: The code resource priority allocation scheme mainly applies to scenarios where power resources are limited. In scenarios where power resources are not limited, this scheme lowers the system throughput. Power Priority: The power resource priority allocation scheme mainly applies to scenarios where code resources are limited. In scenarios where code resources are not limited, this scheme lowers the system throughput. Balance between Code and Power: The power-code balanced scheme avoids exhaustion of either type of resources, improves the resource use efficiency and improves the cell capacity.

Scheduling Method

Indicates the HSDPA Scheduling Method. PF: The differences between channel environments of users are considered in order to ensure equity among users. Enhanced PF: This algorithm is an enhancement to PF. Channel quality is considered in order to reach high resource efficiency and gain a high system capacity. Round Robin: Scheduling opportunities are allocated among users simply and effectively on a polling basis. The system throughput is low. Max C/I: This algorithm brings about the maximum system throughput, but it cannot ensures equity between users or meet users' QoS requirements. Location based EPF: Based on the Enhanced PF algorithm, the Location based EPF algorithm considers the impact of user location. Smart EPF: In heavy load scenarios, the smart EPF algorithm increases the weight of the impact of the channel quality on the scheduling priority while moderately guaranteeing the service differentiation and user fairness. In addition, this algorithm adaptively acquires its application scenarios based on machine learning.

Power Margin(%)

Indicates the power margin reserved for R99 channels. It specifies the power percentage relative to the maximum cell transmit power.

HS-SCCH Power Control Method in CELL DCH state

Indicates the HS-SCCH Power Control Method in CELL DCH state. Fixed Power-based Power Control: The HS-SCCH transmit power is determined depending on CEUs. This helps to save power resources. CQI-based Adaptive Power Control: The HS-SCCH transmit power is adjusted based on the CQIs and ACK/NACK feedback from users. This lowers the average HS-SCCH transmit power and improves the average throughput of the cell.

HS-SCCH Power(0.25dB)

Indicates the power of the HS-SCCH is an offset in dB to the transmit power of the PCPICH. Relationship between the GUI value and actual value: Actual value = (GUI value - 40) x 0.25.

HS-SCCH FER Target in CELL DCH State(per mill)

Indicates the HS-SCCH FER Target in CELL DCH State.

Resource Limiting Switch

Indicates the Resource Limiting Switch. The function will be enabled if this parameter is set to OPEN. When the resource usage is above the threshold, the throughput may be improved (for example, large GBRs configured for users at the cell edge).

Dynamic Code Switch

Indicates the Dynamic Code Switch. The function will be enabled if this parameter is set to OPEN. When this switch is turned on, the cell codes are used efficiently, and the system capacity is improved.

16QAM Switch

Indicates the 16QAM Switch. The function will be enabled if this parameter is set to OPEN. When this switch is turned on, the cell throughput improves.

Max Power Per Hs-user(%)

Indicates the ratio of the maximum instantaneous transmit power of a single HSDPA UE to the actual maximum transmit power of the cell.

CQI Filter Alpha

Indicates the Channel Quality Indicator(CQI) Filter Alpha.

MAX EFACH HARQ Retransmission Times

Indicates the maximum number of blind HARQ retransmissions for E-FACH users.

MAX HARQ Retransmission Times of Non-Conversational service in CELL DCH state

Indicates the MAX HARQ Retransmission Times of Non-Conversational service in CELL DCH state.

HS-SCCH Power Control Method in CELL FACH state

Indicates the HS-SCCH Power Control Method in CELL FACH state. Fixed Power-based Power Control: The HS-SCCH transmit power is determined considering the CEUs of the cell. Reliable HS-SCCH transmission can be ensured but the downlink power cannot efficiently used. CQI-based Adaptive Power Control: The HS-SCCH transmit power is adjusted based on the CQIs and ACK/NACK feedback from users. The probability of unreliable HS-SCCH transmission and power waste increases, and the cell throughput becomes low.

CQI Adjust Algorithm Switch of Conversational Service

Indicates the Channel Quality Indicator(CQI) Adjust Algorithm Switch of Conversational Service. Not CQI Adjust Algorithm: CQI correction is not performed. CQI Adjusted by RBLER: CQI correction is performed for conversational services based on the target value of the residual BLER. The residual BLER will converge to the target value.

CQI Adjust Algorithm Switch of non-Conversational Service

Indicates the Channel Quality Indicator(CQI) Adjust Algorithm Switch of non-Conversational Service. Not CQI Adjust Algorithm: CQI correction is not performed. CQI Adjusted by IBLER: CQI correction is performed for non-conversational services based on the fixed IBLER. The IBLER will converge to this target value. CQI Adjusted by Dynamic BLER: CQI correction is performed for non-conversational services based on the dynamic BLER. The dynamic BLER will converge to this target value.

Residual Bler Target(per mill)

Indicates the residual block error rate (RBLER) target.

IBler Target(%)

Indicates the Initial Block Error Rate(IBLER) Target.

Secondary DC-HSDPA,DB-HSDPA Cell Activation Switch

This parameter specifies whether to enable Traffic-Based Activation and Deactivation of the Supplementary Carrier in Multi-carrier HSDPA. Multi-carrier HSDPA cells fall into DC-HSDPA cells, DC-HSDPA+MIMO cells, DB-HSDPA cells, DB-HSDPA+MIMO cells, 3C-HSDPA cells, and 4C-HSDPA cells. If this parameter is set to ON, this function takes effect. If this parameter is set to OFF, this function does not take effect. When the switch is turned on, this function helps lower the uplink load and extend the battery life of UEs.

IIC Switch

Indicates the Intelligent Interference Control Switch. The function will be enabled if this parameter is set to OPEN. For MIMO+HSDPA co-carrier cells, when this switch is turned on, performance for HSDPA users is boosted but performance for MIMO users slightly decreases. When this switch is close, performance for MIMO users remains unchanged and performance for HSDPA users decreases.

SE Hsscch DTX Switch

Indicates the SE Hsscch DTX Switch. When this switch is turned on, Sony Ericsson terminals no longer experience PS call drops. However, it is possible to decrease the cell capacity.

MIMO Prime Switch

Indicates the MIMO Prime Switch. The function will be enabled if this parameter is set to OPEN.

Location Weight

Indicates the weight of the EPF_LOC (user location-based EPF) algorithm. A larger parameter value indicates more location factors should be considered in the user location-based HSDPA scheduling scheme that uses the EPF_LOC algorithm.

Extra Power(0.25dB)

Indicates the maximum power used for scheduled users after the scheduling.

Maximum HARQ Retransmission Number for EFACH over HS-DPCCH

Indicates the maximum number of HARQ retransmissions when the UE in CELL_FACH supports the feedbacks over the HS-DPCCH.

Optimization Switch for BLER of HSDPA Burst service

When this switch is turned on, estimated channel environment errors are corrected for burst services and full buffer services at the startup of data transmission to optimize the BLER.

DL BE Schedule When UL Unreliable Switch

Indicates the switch used to control whether scheduling and Transport Format Resource Combination (TFRC) are allowed for best effort (BE) services when the uplink signal quality of HSDPA users is not reliable. If this switch is turned off, scheduling and TFRC are not allowed for BE services when the uplink signal quality of HSDPA users is not reliable. If this switch is turned on, scheduling and TFRC are allowed for BE services even when the uplink signal quality of HSDPA users is not reliable. For multi-carrier HSDPA UEs, this function takes effect only on the primary carrier.

Extra Power For SRB(dB)

Indicates the extra power for the SRB queue. If SRBs are carried over HSDPA, the transmit power increases when there is remaining cell power or the data volume to be transmitted decreases when there is no remaining cell power. This reduces the BLER of the SRB queue, decreases the HSDPA service drop rate, and increases the HSDPA handover success rate.

Code Utilization Optimization Switch

Indicates the switch for code utilization optimization. If this switch is turned on, the HSDPA code utilization rate increases but the power usage decreases. If this switch is turned off, code utilization optimization does not take effect.

Preallocation BW Optimization Switch

Indicates the switch used to optimize the pre-allocation bandwidth algorithm. If the switch is turned on, the NodeB optimizes the pre-allocation bandwidth algorithm, improving HSDPA throughput. If this switch is turned off, the pre-allocation bandwidth algorithm does not take effect.

SFDC MAC-ehs Discard Timer(ms)

Indicates the length of the SFDC MAC-ehs discard timer, which defines the maximum duration within which an MAC-d PDU of the inter-NodeB SFDC-HSDPA service is transmitted after it is added to an MAC-ehs queue. If the timer expires, the MAC-d PDU will be discarded. Otherwise, the MAC-d PDU will be blocked in a NodeB, which causing a UE to receive an incorrect PDU at the RLC layer. For details about this parameter, see 3GPP TS 25.321.

DF3C MAC-ehs Discard Timer(ms)

Indicates the length of the DF3C MAC-ehs discard timer, which defines the maximum duration within which an MAC-d PDU of the inter-NodeB DF3C-HSDPA service is transmitted after it is added to an MAC-ehs queue. If the timer expires, the MAC-d PDU will be discarded. Otherwise, the MAC-d PDU will be blocked in a NodeB, which causing a UE to receive an incorrect PDU at the RLC layer. For details about this parameter, see 3GPP TS 25.321.

HSDPA L2 Optition Switch

Indicates whether to enable Layer 2 optimization for HSDPA services. If this switch is turned on, Layer 2 optimization for HSDPA services is enabled. If this switch is turned off, Layer 2 optimization for HSDPA services is disabled.

Power Margin Delta For Platinum User(%)

Indicates an adjustment to the reserved power margin for R99 channels when the Platinum User Prioritizing feature has been enabled. The reserved power margin for R99 channels of a cell serving platinum users in the CS domain equals the smaller value between 100 and the sum of PWRMGN and PWRMGNDELTAFORPT. The parameter value is a percentage relative to the maximum cell transmit power.

Video CQI Threshold

Indicates the CQI threshold for scheduling video users. If SM is set to EPF and the CQI after filtering for an HSDPA video user is below the specified threshold, absolute guarantee does not apply to the video user.

HSDPA Fullbuffer Data Threshold(bit)

Indicates the full buffer service traffic threshold for HSDPA UEs.

HSDPA Fullbuffer Throughput Threshold(kbps)

Indicates the full buffer service throughput threshold for HSDPA UEs.

Optimization Switch for HS-SCCH CQI-based Adaptive Power Control in CELL_DCH State

Indicates whether to optimize HS-SCCH CQI-based adaptive power control for UEs in CELL_DCH state. If this switch is turned on, the NodeB optimizes HS-SCCH CQI-based adaptive power control for UEs in CELL_DCH state.

MAX Extra Power for HS-SCCH in CELL_DCH State(dB)

Indicates the maximum extra power for HS-SCCH in CELL_DCH state.

Service CQI Threshold

Indicates the service CQI threshold for preferential service scheduling. If the CQI value of an HSDPA service is less than the threshold, preferential scheduling does not apply to the service.

E-FACH DTCH Resource Alloc Mode

Indicates the power resource allocation mode for E-FACH DTCH data. If this parameter is set to JOINTALLOC, power resources are jointly allocated to E-FACH DTCH data within multiple TTIs. If this parameter is set to INDALLOC, power resources are independently allocated to E-FACH DTCH data within each TTI.

Adjustment Switch for CQI Adjusted By IBLER

Indicates performance adjustment for the algorithm specified by CQI_ADJ_BY_IBLER under CQIADJALGOFNONCON. When this parameter is set to OFF, the algorithm specified by CQI_ADJ_BY_IBLER under CQIADJALGOFNONCON has optimized performance of the mainstream terminals on the live network. However, performance of some terminals deteriorates, leading to negative gains. In this case, if this parameter is set to ON, the system automatically adjusts the algorithm parameters to eliminate the negative gains.

Adjustment Switch for CQI Adjusted By Dynamic BLER

Indicates performance adjustment for the algorithm specified by CQI_ADJ_BY_DYN_BLER under CQIADJALGOFNONCON. In the single-user scenario, if this parameter is set to ON, the system optimizes the algorithm specified by CQI_ADJ_BY_DYN_BLER to improve downlink throughput.

Throughput Threshold for Activating Secondary Cell(kbps)

Indicates the throughput threshold for activating the secondary cell. If the UE throughput is greater than the threshold, the secondary cell is activated.

Throughput Threshold for Deactivating Secondary Cell(kbps)

Indicates the throughput threshold for deactivating the secondary cell. If the UE throughput is lower than the threshold, and the size of buffered user data is greater than the value of DEASECCELLDATABUFTHD, the secondary cell is deactivated.

Data Buffer Threshold for Activating Secondary Cell(%)

Indicates the data buffer threshold for activating the secondary cell. When the size of buffered user data is lower than the threshold, the secondary cell is activated.

Data Buffer Threshold for Deactivating Secondary Cell(%)

Indicates the data buffer threshold for deactivating the secondary cell. When the size of buffered user data is greater than the threshold and the user throughput is lower than the value of DEASECCELLTHPTHD, the secondary cell is deactivated.

Independent Carrier Scheduling Switch

Indicates the switch for independent carrier scheduling of multi-carrier HSDPA users. If this switch is turned on, only the rate of a carrier for a multi-carrier HSDPA user is used as the input of the carrier scheduling weight. If this switch is turned off, the total rate of several carriers for a multi-carrier user is used as the input of the carrier scheduling weight.

Buffer-based Scheduling Algorithm Switch

Indicates the switch of buffer-based HSDPA user scheduling algorithm. If this switch is turned on, the buffer-based scheduling algorithm is enabled and users with few queue buffers are preferentially scheduled. If this switch is turned off, the scheduling algorithm is not enabled. Buffer means the data in a NodeB user queue.

Dynamic Code Optimization Switch

Indicates the switch for HSDPA dynamic code optimization. When this parameter is set to ON, the HSDPA dynamic code optimization algorithm takes effect. When this parameter is set to OFF, the HSDPA dynamic code optimization algorithm does not take effect.

HARQ Retransmission Schedule Optimization Switch

Indicates the switch for HARQ retransmission schedule optimization. When this parameter is set to ON, the HARQ retransmission schedule optimization algorithm takes effect. When this parameter is set to OFF, the HARQ retransmission schedule optimization algorithm does not take effect.

Delta CQI Threshold for MC(dB)

Indicates the CQI difference threshold for multi-carrier HSDPA UEs. For a multi-carrier HSDPA UE that uses the local call as the primary well, if the result of subtracting carrier 2 CQI from carrier 1 CQI is greater than this threshold, the UE is scheduled with the lowest scheduling priority in carrier 2. (Carrier 1 is the carrier with the highest CQI, and carrier 2 is the one with the lowest CQI). Value 0 indicates that this function is disabled.

Combined TFRC Switch

Indicates whether the combined TFRC function takes effect. If this switch is turned on, the combined TFRC function takes effect. When the cell power resources are exhausted but the code resources are still available after the scheduling of a UE is completed, some power resources used by the UE will be released if another UE waits to be scheduled so that the new UE can send data. If this switch is turned off, the combined TFRC function does not take effect.

Smart Scheduling UE Number Threshold

Indicates the threshold of the number of UEs for which the Machine Learning based Scheduling feature is effective. When the number of HSDPA users in the cell is greater than the threshold value, activating the Machine Learning based Scheduling algorithm helps improve the cell throughput. If this parameter is set to 0, this parameter is invalid, and the NodeB adjusts the threshold based on the Machine Learning based Scheduling algorithm in real time.

Multi-carrier HSDPA Status Synchronization Optimization Switch

Indicates the switch for the multi-carrier HSDPA status synchronization optimization function. Multi-carrier HSDPA includes DC-HSDPA, DC-HSDPA+MIMO, DB-HSDPA, DB-HSDPA+MIMO, 3C-HSDPA, and 4C-HSDPA. When this switch is set to ON, the multi-carrier HSDPA status synchronization optimization function takes effect. Multi-carrier HSDPA status synchronization of new radio links between the network and UE sides are performed after the fast radio bearer setup succeeds. When this switch is set to OFF, the multi-carrier HSDPA status synchronization optimization function does not take effect.
