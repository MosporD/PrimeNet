Set Noaccessalm Para (SET ULOCELLNOACCESSPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to set parameters for sleeping cells. Sleeping cells refer to cells that no users access in a specified period of time.

Note

  • The NOUETIMER and NOFSTRLTIMER parameters have different application scenarios. Check whether the cell allows new access requests of UEs before setting these two parameters. When the cell allows handovers but does not allow new access requests, set the NOFSTRLTIMER parameter to 0 and the NOUETIMER parameter to a value greater than 0. When the cell allows new access requests, set the NOUETIMER parameter to 0 and the NOFSTRLTIMER parameter to a value greater than 0.
  • The SET ULOCELLNOACCESSPARA command is controlled by the SLEEPINGCELLDETECTOPTION in the SET NODEBALGPARA command. When the SLEEPINGCELLDETECTOPTION parameter is set to 0, the NodeB detects no traffic but does not report an alarm. In addition, self-healing is not performed.
  • When the NOUETIMER parameter is set to 0, the history traffic-based decision on whether RlSetup is 0 due to a fault is disabled. When the NOUETIMER parameter is set to a value other than 0, the history traffic-based decision on whether RlSetup is 0 due to a fault is enabled and the shortest decision period is configurable.
  • When the NOFSTRLTIMER parameter is set to 0, the history traffic-based decision on whether FST_RLS is 0 due to a fault is disabled. When the NOFSTRLTIMER parameter is set to a value other than 0, the history traffic-based decision on whether FST_RLS is 0 is enabled and the shortest decision period is configurable.
  • The AUTORCVRMTHD parameter takes effect only when the value of the SLEEPINGCELLDETECTOPTION parameter is not set to 0. The AUTORCVRMTHD parameter values are NONE(NONE), CELLRESTART(CELLRESTART), BBRESOURCERESET(BBRESOURCERESET), BBOARDRESET(BBOARDRESET), and CELLRFMODULERESET(CELLRFMODULERESET). The valid scopes of these values are in ascending order. When a NodeB detects a sleeping cell, the NodeB performs self-healing operations in ascending order of valid scopes of these values and the highest level is the value of the AUTORCVRMTHD parameter. For example, when the AUTORCVRMTHD parameter is set to BBRESOURCERESET(BBRESOURCERESET), the self-healing methods used for a NodeB to resolve a sleeping cell problem include CELLRESTART(CELLRESTART) and BBRESOURCERESET(BBRESOURCERESET) but does not include BBOARDRESET(BBOARDRESET) and CELLRFMODULERESET(CELLRFMODULERESET). When the level of a self-healing operation needs to be changed, the NodeB starts a new detection procedure and attempts to restore services. As a result, if No Traffic alarms have been reported, the alarms will be cleared after the level is changed. If services are not restored, the alarms will be reported again.
  • The BLADEBBU and BBU3910C do not support self-healing methods include BBOARDRESET(Baseband Board Restart).

Example

To set the cell as a sleeping cell as follows: Local Cell ID: 14600, Timer Length Of the Cell Without RL Setup: 0, Timer Length Of Cell Without RL Setup (First RLS): 24, Auto Recovery Method: NONE, run the following command:
SET ULOCELLNOACCESSPARA: ULOCELLID=14600, NOUETIMER=0, NOFSTRLTIMER=24, AUTORCVRMTHD=NONE;

To set the cell as a sleeping cell allowing only handovers with the parameters as follows: Local Cell ID: 14601, Timer Length Of the Cell Without RL Setup: 12, Timer Length Of Cell Without RL Setup (First RLS): 0, Auto Recovery Method: NONE, run the following command:
SET ULOCELLNOACCESSPARA: ULOCELLID=14601, NOUETIMER=12, NOFSTRLTIMER=0, AUTORCVRMTHD=NONE;
