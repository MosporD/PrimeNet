List Disable Cell Transmitter Timer (LST NODEBCLSPATIMER)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list the range of disabling the cell transmitter timer after transmissions are interrupted.

Note

None

Parameters

None.

Example

Use the following command to list range of disabling cell transmitter time: 
LST NODEBCLSPATIMER:;
The result is shown as follows:
+++    HUAWEI        2011-09-26 11:37:41
O&M    #260
%%LST NODEBCLSPATIMER:;%%
RETCODE = 0  Operation succeeded.

List Disable Cell Transmitter Timer
-----------------------------------
Minimum Timer Value(min)  =  6
Maximum Timer Value(min)  =  12
(Number of results = 1)


---    END

Output Description

Field Description

Minimum Timer Value(min)

Indicates the minimum value of the timer for shutting down a transmitter in a cell.

Maximum Timer Value(min)

Indicates the maximum value of the timer for shutting down a transmitter in a cell.
