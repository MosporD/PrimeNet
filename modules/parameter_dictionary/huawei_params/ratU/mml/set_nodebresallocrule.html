Set NodeB Resource Allocation Mode (SET NODEBRESALLOCRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the base station resource allocation mode and parameters for automatic cell reestablishment. Currently, base station resources can be allocated according to handover performance or capacity. If base station resources are allocated according to handover performance, the local cells at the same frequency are allocated to the same processing chip preferentially. If the CMB function must be configured, base station resources must be allocated according to handover performance. If base station resources are allocated according to capacity, different local cells are allocated to different processing chips preferentially, averaging the number of cells on the processing chips. The base station resource allocation mode can be set as required. By default, base station resources are allocated according to handover performance.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When a logical cell is available, parameter RULE cannot be modified.
  • After this command is executed to change the parameter RULE, all local cells of the base station are reestablished according to the new resource allocation mode.
  • If the value of parameter RULE is set to PERFFIRST(Handover Performance First Rule), cells in a multicarrier group are preferentially configured in one component.
  • If the value of parameter SW is set to ON(ON), all local cells will be reestablished properly according to the threshold of deciding the number of CS users and the threshold of deciding the number of PS users. The reestablishment interrupts all ongoing services for less than 1 minute.
  • If the value of parameter MULTICELLREBUILDSW is set to ON(ON), all cells will be reestablished immediately after the DC/MC capability degrades. The reestablishment interrupts all ongoing services for less than 1 minute.
  • If SPECTRUMFEAORFUNCTION(Spectrum-related Features or Functions) in the parameter MULTICELLREBUILDSW is set to ON, all cells will be reestablished immediately when a spectrum-related feature or function is derated and there are usable resources. The reestablishment interrupts all ongoing services for less than 1 minute.

Parameters

ID Name Description
RULE Resource Allocate Rule

Meaning: Indicates the BB Resource Allocate Rule. Handover Performance First Rule: The local cells of the same frequency are allocated to the same processing chip. Capacity First Rule: The local cells are allocated to different processing chips in order that processing chips are used averagely.

GUI Value Range: PERFFIRST(Handover Performance First Rule), CAPAFIRST(Capacity First Rule)

Unit: None

Actual Value Range: PERFFIRST, CAPAFIRST

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
SW Auto Rebuild Cell Switch

Meaning: Indicates the automatic cell reestablishment switch.

GUI Value Range: ON(ON), OFF(OFF)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to ON(ON) to enable automatic cell reestablishment. By default, the parameter is set to OFF(OFF).

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If automatic cell reestablishment is enabled and the NodeB decides that the cell needs to be automatically reestablished, the logical cell will be removed and the local cell will be reestablished based on the preset resource allocation mode.

Applicable Mode: U
CSUSERNUM Cs User Number Threshold

Meaning: Indicates the threshold for the number of CS users. If the number of CS users in the downlink resource group is smaller than or equal to the threshold, cells are reestablished automatically.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is not 0 and automatic cell reestablishment is enabled, existing CS users in this cell will be disconnected from the network.

Applicable Mode: U
PSUSERNUM Ps User Number Threshold

Meaning: Indicates the threshold for the number of PS users. If the number of CELL_DCH PS users in the downlink resource group is smaller than or equal to the threshold, cells are reestablished automatically.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is not 0 and automatic cell reestablishment is enabled, existing PS users in this cell will be disconnected from the network.

Applicable Mode: U
MULTICELLREBUILDSW Immediate Rebuilding Switch for Degraded Multi-Cell

Meaning: Indicates whether a cell needs to be reestablished immediately after the DC/MC degrades.

GUI Value Range: ON(ON), OFF(OFF)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to ON, the cell will be reestablished and the NodeB attempts to clear the fault when the DC/MC degrades. Cell reestablishment will interrupt all ongoing services carried on the NodeB.

Applicable Mode: U
CELLDEGRADEREBUILDSW Immediate Rebuilding Switch for Degraded Cell

Meaning: Indicates whether to enable immediate reestablishment in the case of cell derating. SPECTRUMFEAORFUNCTION(Spectrum-related Features or Functions) indicates that all cells under the base station are reestablished if any of the cells experiences derating of spectrum-related features or functions and the remaining resources of the base station are sufficient. Spectrum-related features or functions are as follows:

WRFD-191209 GU@5 MHz Phase 1

WRFD-200201 GU@5 MHz Phase 2

WRFD-210203 DC-HSDPA Shared with GSM

MRFD-130212 UMTS and LTE Spectrum Sharing (UMTS)

MRFD-150212 UMTS and LTE Spectrum Sharing Phase 2 (UMTS)

MRFD-150211 UMTS and LTE Zero Bufferzone (UMTS)

MRFD-151212 UMTS and LTE Spectrum Sharing Based on DC-HSDPA (UMTS)

WRFD-191212 Dual Carriers over Narrowband

GU 0 Buffer Zone

GUI Value Range: SPECTRUMFEAORFUNCTION(Spectrum-related Features or Functions)

Unit: None

Actual Value Range: SPECTRUMFEAORFUNCTION

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When SPECTRUMFEAORFUNCTION(Spectrum-related Features or Functions) is selected, all cells under the base station are reestablished if any of the cells experiences derating of spectrum-related features or functions and the remaining resources of the base station are sufficient. In this case, all services of the base station are interrupted.

Applicable Mode: U

Example

Execute this command to set resource allocate rule:
SET NODEBRESALLOCRULE: RULE =PERFFIRST;
