List Parameters for Cell Power Saving (LST ULOCELLPWRSAVPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list parameters for power saving for a specified cell or all cells.

Note

None.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

LST ULOCELLPWRSAVPARA:;

Output Description

Field Description

Local Cell ID

Indicates the Local Cell ID.

Multi-RAT Coordinated Channel Shutdown Switch

Indicates whether to enable the Multi-RAT Coordinated Channel Shutdown (UMTS) feature. When this parameter is set to ON(ON), the Multi-RAT Coordinated Channel Shutdown (UMTS) feature is enabled to save energy during off-peak hours.

Power Saving Start Time

Indicates the time at which the cell power saving algorithm starts to take effect. When the system time reaches the time specified by this parameter, the feature algorithm starts to take effect.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05.

Power Saving Stop Time

Indicates the time at which the cell power saving algorithm stops. When the system time reaches the time specified by this parameter, the feature algorithm becomes ineffective.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05.

Power Saving TX Power High Threshold(%)

Indicates the threshold of the output power percentage for a cell to stop power saving. If the average output power percentage of a cell is higher than this threshold, the cell stops power saving.

Power Saving TX Power Low Threshold(%)

Indicates the threshold of the output power percentage for a cell to start power saving. If the average output power percentage of a cell is lower than this threshold, the cell starts power saving.
