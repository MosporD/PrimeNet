Start Algorithm Simulation Test (STR NODEBALGSIMLTTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to start algorithm simulation tests for fault isolation.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • RF loopback tests and baseband loopback tests are performed per cell. That is, the two types of tests cannot be performed in one cell at the same time.
  • An RF loopback test interrupts ongoing services for a maximum of 10 seconds. However, the services on other cells of the TRX board are not interrupted. When the uplink RACH traffic is 0 or the bit error rate (BER) of the RACH reaches 100%, the test can be started.
  • An RF loopback test will automatically stop after 10 seconds elapse.
  • A distributed cell or Mixed-Multi-RRU cell does not support RF loopback tests.
  • When the cell bandwidth is set to 3.8 MHz (FMBWH or FREQUENCYBANDWIDTH is set to 3800), cells working on adjacent frequencies do not support the RF loopback test.
  • A baseband loopback test interrupts ongoing services for a maximum of one second. When the uplink dedicated channel has a high BER, this test can be performed.
  • After a baseband loopback test starts, it will automatically stop.
  • A baseband loopback test can be performed only on the WBBPf and other new boards.
  • When a user needs to access a non-two-antenna cell or a cell for independent demodulation of signals from multiple RRUs, a baseband loopback test cannot be performed.
  • When BFMODE in the ULOCELL MO is set to MASSIVEBEAM, NORMALBEAM, FOURTXBEAMOPT, or COORDINATEDBEAM, RF loopback tests and baseband loopback tests are not supported.
  • When ULSPECTRUMSHARINGSWITCH in the ULOCELL MO is set to FIXED_BANDWIDTH_COMP_MODE, RF loopback tests are not supported.
  • When ULADAPTIVEBPFILTER or DLADAPTIVEBPFILTERPERFEOPT is selected under the GU5MHZPERFOPT parameter in the ULOCELL MO, RF loopback tests are not supported.
  • When DLASYMFILTER in the ULOCELL MO is set to TRUE, RF loopback tests are not supported.
  • When UL0BUFFERZONE and UL0BUFFERZONEFILTER in the ULOCELL MO are set to TRUE and ULADAPTIVEFILTER, respectively, RF loopback tests are not supported.
  • When DCHSDPASHAREDWITHGSM in the ULOCELL MO is set to STATICBANDWIDTH, DYNAMICBANDWIDTHWITHGSM, or DYNAMICBANDWIDTHWITHOUTGSM, RF loopback tests are not supported.
  • When ULSPECTRUMSHARINGPHASE2 in the ULOCELL MO is set to TRUE, RF loopback tests are not supported.
  • When DCHSDPASHAREDWITHLTE in the ULOCELL MO is set to DYNAMICBANDWIDTH, RF loopback tests are not supported.

Example

1.Start RF loopback tests of No.12300 local cell:
STR NODEBALGSIMLTTST: ULOCELLID=12300, TESTMODULETYPE=RF;

2.Start baseband loopback tests of No.12300 local cell:
STR NODEBALGSIMLTTST: ULOCELLID=12300, TESTMODULETYPE=BB;
