List Multiple Carrier Cell Group Item (LST NODEBMULTICELLGRPITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list local cells of multiple carrier cell group.

Note

None.

Parameters

ID Name Description
MULTICELLGRPID Multiple Carrier Cell Group ID

Meaning: Uniquely identifies a multiple carrier cell group.

GUI Value Range: 0~95

Unit: None

Actual Value Range: 0~95

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

List the information of multiple carrier cell of the No.0 multiple carrier cell group:
LST NODEBMULTICELLGRPITEM: MULTICELLGRPID=0;
The result is shown as follows:
+++    HUAWEI        2014-01-05 07:29:56
TRAFFIC    #352
%%LST NODEBMULTICELLGRPITEM: MULTICELLGRPID=0;%%
RETCODE = 0  Operation succeeded.

List Multiple Carrier Cell Group Item
-------------------------------------
Multiple Carrier Cell Group ID  =  0
                 Local Cell ID  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Multiple Carrier Cell Group ID

Uniquely identifies a multiple carrier cell group.

Local Cell ID

Indicates the Local Cell ID.
