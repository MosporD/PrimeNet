Display Phase Calibration Capability Detection Result (DSP UPHASECALIBCHK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the phase calibration capability detection result.

Note

  • This command applies only to 4T4R cells (excluding cells that use the AAU5973e) where the UMTS 4T Beam Optimization capability is available and two 2T RF modules are combined. After the NodeB is reset, the value of Cell Phase Calibration Capability Detection Status in the DSP UPHASECALIBCHK command output is Undetected.
  • You can run the DSP UPHASECALIBCHK command to query the latest phase calibration result, involving the phase calibration automatically triggered or manually triggered by using the STR UPHASECALIBCHK command.

Parameters

None.

Example

1. Display phase calibration capability detection result:
DSP UPHASECALIBCHK:;

Output Description

Field Description

Local Cell ID

Indicates the local cell ID.

Cabinet No.

Indicates the cabinet number of the RF module used by the RX link.

Subrack No.

Indicates the subrack number of the RF module used by the RX link.

Slot No.

Indicates the slot number of the RF module used by the RX link.

Cell Phase Calibration Capability Detection Status

Indicates the detection result of the cell phase calibration capability. Undetected indicates that the cell has not started phase calibration capability detection. Detecting indicates that the cell phase calibration capability detection is in progress. Failed indicates that the cell phase calibration capability detection fails. Succeeded indicates that the cell phase calibration capability detection succeeds.
