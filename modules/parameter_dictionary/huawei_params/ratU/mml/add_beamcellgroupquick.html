Add Beam Cell Group Quickly (ADD BEAMCELLGROUPQUICK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to add beam cell group. After this command is executed, configuration information of beam cell group items for the beam cell group is automatically added.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
BEAMCELLGROUPID Beam Cell Group ID

Meaning: Indicates the ID of beam cell group.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BEAMCELLGROUPTYPE Beam Cell Group Type

Meaning: Indicates the type of beam cell group.

GUI Value Range: NORMALBEAM(Normal Beam), MASSIVEBEAM8T8R(Massive Beam 8T8R), MASSIVEBEAM4T4R(Massive Beam 4T4R), FOURTXSPLITSECTOR(4T Split Sector Beam), COORDINATED2TBEAM(2T Coordinated Beamforming)

Unit: None

Actual Value Range: NORMALBEAM, MASSIVEBEAM8T8R, MASSIVEBEAM4T4R, FOURTXSPLITSECTOR, COORDINATED2TBEAM

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
BEAMOPTIONPERIOD Beam Option Period

Meaning: Indicates the beam selection period.

GUI Value Range: 1MIN(1min), 2MIN(2min), 5MIN(5min), 10MIN(10min), 15MIN(15min), 20MIN(20min), 30MIN(30min), 1H(1hour)

Unit: None

Actual Value Range: 1MIN, 2MIN, 5MIN, 10MIN, 15MIN, 20MIN, 30MIN, 1H

MML Default Value: 10MIN(10min)

Recommended Value: None

Parameter Relationship:

-Others:

  • If BEAMOPTIONMODE under the BEAMCELLGROUPITEM MO is set to AUTO, BEAMOPTIONPERIOD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A shorter period specified by this parameter indicates higher frequency of beam adjustment, more significant gains in capacity, but higher risks of KPI deterioration. A longer period specified by this parameter indicates lower frequency of beam adjustment, lower risks of KPI deterioration, but less significant gains in capacity.

Applicable Mode: U

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ULOCELL1BEAMAZIMUTH Beam Azimuth of Local Cell 1

Meaning: Indicates the beam azimuth of local cell 1 in a beam cell group. When this parameter is set to LEFT(left), the cell coverage direction is relatively left to the beam azimuth of the antennas, and the cell can only select the four predefined left beams in Massive Beam 8T8R scenarios and use the left beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to RIGHT(Right), the cell coverage direction is relatively right to the beam azimuth of the antennas, and the cell can only select the four predefined right beams in Massive Beam 8T8R scenarios and use the right beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to NONE(None), the cell coverage direction is unrestricted.

GUI Value Range: LEFT(Left), RIGHT(Right), NONE(None)

Unit: None

Actual Value Range: LEFT, RIGHT, NONE

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If BEAMCELLGROUPTYPE is set to MASSIVEBEAM4T4R, MASSIVEBEAM8T8R, or COORDINATED2TBEAM, ULOCELL1BEAMAZIMUTH is valid.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: The setting of this parameter must be consistent with the network planning. Any inconsistency will negatively affect the cell coverage area and scrambling code setting, leading to user access failures, increasing the call drop rate, decreasing the handover success rate, and increasing inter-cell interference.

Applicable Mode: U
ULOCELL1BEAMOPTIONMODE Beam Option Mode of Local Cell 1

Meaning: Indicates the beam selection mode of local cell 1 in a beam cell group.

GUI Value Range: AUTO(Auto), FIXEDBEAM1(Fixed Beam 1), FIXEDBEAM2(Fixed Beam 2), FIXEDBEAM3(Fixed Beam 3), FIXEDBEAM4(Fixed Beam 4)

Unit: None

Actual Value Range: AUTO, FIXEDBEAM1, FIXEDBEAM2, FIXEDBEAM3, FIXEDBEAM4

MML Default Value: AUTO(Auto)

Recommended Value: AUTO(Auto)

Parameter Relationship:

-Others:

  • If BEAMCELLGROUPTYPE is set to MASSIVEBEAM8T8R, ULOCELL1BEAMOPTIONMODE is valid.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: It is recommended that this parameter be set to AUTO(Auto). If the beam selection is restricted to a fixed beam, adapt the selected beam to the service distribution. Inappropriate setting may affect the cell coverage, increasing the call drop rate of UEs at the edge of coverage and aggravating the interference from neighboring cells.

Applicable Mode: U

Example

1. To add a beam cell group with the parameters as follows: Beam Cell Group ID: 1, Beam Cell Group Type: MASSIVEBEAM8T8R, Beam Option Period: 10MIN, Local Cell ID 1: 101, Beam Azimuth of Local Cell 1: LEFT, Beam Option Mode of Local Cell 1: AUTO, Local Cell ID 2: 102, Beam Azimuth of Local Cell 2: RIGHT, Beam Option Mode of Local Cell 2: AUTO, run the following command: 
ADD BEAMCELLGROUPQUICK: BEAMCELLGROUPID=1, BEAMCELLGROUPTYPE=MASSIVEBEAM8T8R, BEAMOPTIONPERIOD=10MIN, ULOCELL1ID=101, ULOCELL1BEAMAZIMUTH=LEFT, ULOCELL1BEAMOPTIONMODE=AUTO, ULOCELL2ID=102, ULOCELL2BEAMAZIMUTH=RIGHT, ULOCELL2BEAMOPTIONMODE=AUTO;
