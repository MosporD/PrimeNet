Stop Downlink Adaptive Band-Pass Filter Test (STP GUDLFILTERTEST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to stop a Downlink Adaptive Band-Pass Filter test for a specified local cell.

Note

None

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the local cell ID. The local cell ID is unique for one NodeB.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Stop a downlink adaptive band-pass filter test of a local cell with the ID 12300:
STP GUDLFILTERTEST: ULOCELLID=12300;
