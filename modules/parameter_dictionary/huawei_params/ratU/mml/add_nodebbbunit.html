Add NodeB Baseband Unit (ADD NODEBBBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a BBU to a NodeB.

Note

  • Each uplink baseband board corresponds to only one BBU, even if the uplink baseband board is configured for different baseband equipment.
  • This command is only used for configuring BBUs. The relationship between a BBU and a local cell is established by running the ADD ULOCELLBBUNIT command.
  • The BLADEBBU and BBU3910C do not support this command.

Parameters

ID Name Description
BBUNITID Baseband Unit ID

Meaning: Indicates the number of the BBU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the BBU is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
SRN Subrack No.

Meaning: Indicates the number of the subrack where the BBU is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
SN Slot No.

Meaning: Indicates the number of the slot where the BBU is located.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

Run the following command to add No.0 BBU:
ADD NODEBBBUNIT: BBUNITID=0, CN=0, SRN=0, SN=0;
