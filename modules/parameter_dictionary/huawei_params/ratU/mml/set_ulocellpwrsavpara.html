Set Parameters for Cell Power Saving (SET ULOCELLPWRSAVPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set parameters for power saving for a specified cell or all cells.

Note

  • If the value of PWRSAVSTARTTIM is 1s greater than the value of PWRSAVSTOPTTIM or PWRSAVSTARTTIM is set to 00:00:00 and PWRSAVSTOPTTIM is set to 23:59:59, the channel shutdown function remains enabled all day. You are advised not to enable this function all day.
  • It is recommended that both PWRSAVSTARTTIM and PWRSAVSTOPTTIM be set to off-peak time.
  • If a cell stays in the channel shutdown state, the MIMO Prime feature does not take effect in this cell.
  • If a cell stays in the channel shutdown state, UMTS 4T Beam Optimization cells do not support co-polarization detection.
  • When the MULTIRATCHANNELSHUTDOWNSW parameter is set to ON(On), the Multi-RAT Coordinated Channel Shutdown (UMTS) feature can be enabled for the NodeB to enter the energy-saving state only when the working modes of all RF units used by the cell are set to multi-RAT and any of the following conditions is met: (1) In the ULOCELL MO, LOCELLTYPE is set to HALFFREQ_CELL(HALFFREQ_CELL) and COVERTYPE is set to SAMEZONE(Same Zone); (2) In the ULOCELL MO, VAM is set to TRUE(TRUE) and TTW is set to FALSE(FALSE); (3) INTEL2TVAM in the ULOCELL MO is set to TRUE(TRUE); (4) BFMODE in the ULOCELL MO is set to FOURTXBEAMOPT(4T Beam Optimization) and the RF unit is a single 4T module.

Parameters

ID Name Description
ULOCELLID Local Cell ID

Meaning: Indicates the Local Cell ID.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
MULTIRATCHANNELSHUTDOWNSW Multi-RAT Coordinated Channel Shutdown Switch

Meaning: Indicates whether to enable the Multi-RAT Coordinated Channel Shutdown (UMTS) feature. When this parameter is set to ON(ON), the Multi-RAT Coordinated Channel Shutdown (UMTS) feature is enabled to save energy during off-peak hours.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • This parameter is invalid if Subrack Type is set to BBU3910C.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON(ON), the Multi-RAT Coordinated Channel Shutdown (UMTS) feature is enabled for the cell within a specified period to reduce the power consumption of the RF module. In this case, the coverage remains unchanged but the data transmission rate of UEs in the cell decreases. When this parameter is set to OFF(OFF), the Multi-RAT Coordinated Channel Shutdown (UMTS) feature does not take effect.

Applicable Mode: U
PWRSAVSTARTTIME Power Saving Start Time

Meaning: Indicates the time at which the cell power saving algorithm starts to take effect. When the system time reaches the time specified by this parameter, the feature algorithm starts to take effect.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 00:00:00

Parameter Relationship:

-Configuration constraints:

  • Under the ULOCELLALGPARA MO, values of PWRSAVSTARTTIME and PWRSAVSTOPTIME must be different.

-Others:

  • If MULTIRATCHANNELSHUTDOWNSW under the ULOCELLALGPARA MO is set to ON, PWRSAVSTARTTIM is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PWRSAVSTOPTIME Power Saving Stop Time

Meaning: Indicates the time at which the cell power saving algorithm stops. When the system time reaches the time specified by this parameter, the feature algorithm becomes ineffective.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 06:00:00

Parameter Relationship:

-Configuration constraints:

  • Under the ULOCELLALGPARA MO, values of PWRSAVSTARTTIME and PWRSAVSTOPTIME must be different.

-Others:

  • If MULTIRATCHANNELSHUTDOWNSW under the ULOCELLALGPARA MO is set to ON, PWRSAVSTOPTIME is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U
PWRSAVTXPWRHIGHTHD Power Saving TX Power High Threshold

Meaning: Indicates the threshold of the output power percentage for a cell to stop power saving. If the average output power percentage of a cell is higher than this threshold, the cell stops power saving.

GUI Value Range: 20~45

Unit: %

Actual Value Range: 20~45

MML Default Value: None

Recommended Value: 40

Parameter Relationship:

-Configuration constraints:

  • Under the ULOCELLALGPARA MO, the value of PWRSAVTXPWRLOWTHD must be less than that of PWRSAVTXPWRHIGHTHD.

-Others:

  • If MULTIRATCHANNELSHUTDOWNSW under the ULOCELLALGPARA MO is set to ON, PWRSAVTXPWRHIGHTHD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value leads to a shorter effective duration of the feature and saves less energy. A larger parameter value leads to a longer effective duration of the feature and saves more energy. However, an extremely large parameter value may lead to a slow rise in the downlink rates of new HSDPA users.

Applicable Mode: U
PWRSAVTXPWRLOWTHD Power Saving TX Power Low Threshold

Meaning: Indicates the threshold of the output power percentage for a cell to start power saving. If the average output power percentage of a cell is lower than this threshold, the cell starts power saving.

GUI Value Range: 20~45

Unit: %

Actual Value Range: 20~45

MML Default Value: None

Recommended Value: 30

Parameter Relationship:

-Configuration constraints:

  • Under the ULOCELLALGPARA MO, the value of PWRSAVTXPWRLOWTHD must be less than that of PWRSAVTXPWRHIGHTHD.

-Others:

  • If MULTIRATCHANNELSHUTDOWNSW under the ULOCELLALGPARA MO is set to ON, PWRSAVTXPWRLOWTHD is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value leads to a shorter effective duration of the feature and saves less energy. A larger parameter value leads to a longer effective duration of the feature and saves more energy. However, an extremely large parameter value may lead to a slow rise in the downlink rates of new HSDPA users.

Applicable Mode: U

Example

Set Parameters for Cell Power Saving:
SET ULOCELLPWRSAVPARA: ULOCELLID=19730, MULTIRATCHANNELSHUTDOWNSW=ON, PWRSAVSTARTTIME=16&21&05, PWRSAVSTOPTIME=16&21&09, PWRSAVTXPWRHIGHTHD=40, PWRSAVTXPWRLOWTHD=30;
