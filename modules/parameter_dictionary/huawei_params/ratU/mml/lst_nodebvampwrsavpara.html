List Parameters Related to VAM Power Saving (LST NODEBVAMPWRSAVPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query parameter configurations related to the VAM Power Saving feature.

Note

None

Parameters

None.

Example

List parameters related to VAM power saving:
LST NODEBVAMPWRSAVPARA:;
The result is shown as follows:
+++    R16SIG21        2016-04-17 15:11:01
O&M    #537919570
%%LST NODEBVAMPWRSAVPARA:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

VAM Power Saving Switch

Indicates whether to enable the VAM Power Saving feature. If this parameter is set to ON, the VAM Power Saving feature is enabled to save energy.

VAM Power Saving Start Time

Indicates the time at which the VAM Power Saving feature takes effect. When the system time reaches the time specified by this parameter, the VAM Power Saving feature takes effect.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05, indicating that the VAM Power Saving feature takes effect at 10:20:05.

VAM Power Saving Stop Time

Indicates the time at which the VAM Power Saving feature becomes ineffective. When the system time reaches the time specified by this parameter, the VAM Power Saving feature becomes ineffective.

The parameter value is in the format of HH:MM:SS. For example, 10:20:05, indicating that the VAM Power Saving feature becomes ineffective at 10:20:05.

VAM Power Saving TX Power Low Threshold(%)

Indicates the threshold of the output power percentage for cells to use the VAM Power Saving feature. If the average output power percentage of each VAM cell served by an RF module is lower than this threshold, one power amplifier is disabled and all VAM cells emit power over only one power amplifier.

VAM Power Saving TX Power High Threshold(%)

Indicates the threshold of the output power percentage for cells to stop the VAM Power Saving feature. If the average output power percentage of any VAM cell served by an RF module is greater than this threshold, the disabled power amplifier is enabled to equally share the power emitted by VAM cells between two working power amplifiers.
