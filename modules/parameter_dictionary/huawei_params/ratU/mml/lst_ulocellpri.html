List Local Cell Priority (LST ULOCELLPRI)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to list the priority of local cells.

Note

None

Parameters

ID Name Description

GUI Value Range: ALLLOCELL(Query All Local Cell), LOCALCELL(Query Local Cell by ID), SECTOR(Query Local Cell by Sector Number), FREQUENCY(Query Local Cell by DL Frequency)

Unit: None

Actual Value Range: ALLLOCELL, LOCALCELL, SECTOR, FREQUENCY

MML Default Value: ALLLOCELL(Query All Local Cell)

Recommended Value: None

Impact on Radio Network Performance: None

Parameter Relationship:

-Configuration constraints:

  • In the ULOCELL MO, the value of DLFREQ must be within the permissible range.
  • In the ULOCELL MO under which ULFREQIND is set to TRUE, the relationships between ULFREQ and DLFREQ must meet the requirements specified by protocols when special uplink and downlink frequencies are used.
  • In the ULOCELL MO under which ULFREQIND is set to TRUE, the relationships between ULFREQ and DLFREQ must meet the requirements specified by protocols when no special uplink and downlink frequencies are used.

-Others:

  • The UL and DL UARFCNs of the local cell must be in the same frequency band.
  • The UARFCNs of the local cell must be the same as that of the logical cell carried on it.
  • Different cells in a sector must use unique UARFCNs.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

Example

1.Use the following command to list the priority of all the local cells:
LST ULOCELLPRI: PRIMODE=ALLLOCELL;
The result is shown as follows:
+++    HUAWEI        2012-11-19 12:05:42
O&M    #444
%%LST ULOCELLPRI: PRIMODE=ALLLOCELL;%%
RETCODE = 0  Operation succeeded.

List Local Cell Priority
------------------------
Local Cell ID  Local Cell Priority

14600          0                  
14601          0                  
(Number of results = 2)


---    END

2.List the priority of No.14600 local cell:
LST ULOCELLPRI: PRIMODE=LOCALCELL, ULOCELLID=14600;
The result is shown as follows:
+++    HUAWEI        2012-11-19 12:05:10
O&M    #439
%%LST ULOCELLPRI: PRIMODE=LOCALCELL, ULOCELLID=14600;%%
RETCODE = 0  Operation succeeded.

List Local Cell Priority
------------------------
      Local Cell ID  =  14600
Local Cell Priority  =  0
(Number of results = 1)


---    END

3.Use the following command to list the priority of all the local cells whose DLFREQ is "10562":
LST ULOCELLPRI: PRIMODE=FREQUENCY, DLFREQ=10562;
The result is shown as follows:
+++    HUAWEI        2012-11-19 12:10:04
O&M    #481
%%LST ULOCELLPRI: PRIMODE=FREQUENCY, DLFREQ=10562;%%
RETCODE = 0  Operation succeeded.

List Local Cell Priority
------------------------
      Local Cell ID  =  14600
Local Cell Priority  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. The local cell ID is unique for one NodeB.

Local Cell Priority

Indicates the priority of the local cell.
