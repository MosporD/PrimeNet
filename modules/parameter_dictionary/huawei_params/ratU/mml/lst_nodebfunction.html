List NodeB Function (LST NODEBFUNCTION)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to list NodeB function.

Note

None.

Parameters

None.

Example

Use the following command to list the NodeBFunction:
LST NODEBFUNCTION:;
The result is shown as follows:
+++    HUAWEI        2017-07-11 16:57:41
O&M    #537919955
%%LST NODEBFUNCTION:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

NodeB Function Name

Indicates the NodeB function name.

Application Reference

This parameter indicates the ID of the Application MO that is referenced by the NodeBFunction MO. The Application MO provides operating environments for the NodeBFunction MO.

NeRM Version

Indicates the NodeB NE resource model version. In the same model version, all MO types, attributes, and configuration rules in the model are defined in the same way.

If the model definition (MOC definition, attribute definition, and configuration rules) for different NE software is the same, these NE software uses the same model version.

Generally, a software version uniquely corresponds to a model version. A software version may correspond to multiple model versions in few cases, for example, the software version is upgraded but the model version is not upgraded, or a software version is compatible with multiple model versions.

User Label

Indicates the user label.

If a user requires multiple information, the format is "%Name1::Value1%Name2::Value2%other description".

NodeB Identifier

Indicates the NodeB ID.

Product Version

Indicates the product software version of the NodeBFunction.
