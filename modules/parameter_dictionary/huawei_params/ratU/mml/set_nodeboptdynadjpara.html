Set Dynamic Voltage Adjustment Parameters (SET NODEBOPTDYNADJPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

The command is used to set the switch, start time, and end time of the dynamic voltage adjustment function.

Note

  • This command is applicable to the entire NodeB Function. When the switch is turned on, the NodeB dynamically adjusts the PA bias voltage according to the traffic load, that is, output power of the PA. This improves the PA efficiency and reduces the power consumption by adjusting the bias voltage parameter when the output power is low.
  • If the value of DYNADJSTARTTIME is the same as that of DYNADJENDTIME, the dynamic voltage adjustment algorithm stays in effect for 24 hours.

Parameters

ID Name Description
DYNADJSW Dynamic Voltage Adjustment Switch

Meaning: Indicates the dynamic voltage adjustment switch. When this switch is turned on, the dynamic voltage adjustment function is enabled and energy conservation is achieved.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If ANTCFGMODE under the SECTOREQM MO used by the ULOCELL MO is not set to BEAM, this parameter is valid.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, energy saving will be achieved.

Applicable Mode: U
DYNADJSTARTTIME Start Time

Meaning: Indicates the time when the optimization algorithm for dynamic voltage adjustment starts working. This parameter is set on the hour. When the current time is later than this parameter, the dynamic voltage adjustment function takes effect.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the dynamic voltage adjustment time is too long, the HSDPA throughput is affected and the probability of call drops increases. If the time is too short, energy conservation cannot yield notable effects.

Applicable Mode: U
DYNADJENDTIME End Time

Meaning: Indicates the time when the optimization algorithm for dynamic voltage adjustment stops working. This parameter is set on the hour. When the current time is later than this parameter, the dynamic voltage adjustment function stops taking effect.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the dynamic voltage adjustment time is too long, the HSDPA throughput and the call drop rate are affected. If the time is too short, energy conservation cannot yield notable effects.

Applicable Mode: U

Example

Execute this command to set the dynamic voltage adjustment function with the parameters as follows:Dynamic Voltage Adjustment Switch: ON, Start Time: 0, End Time: 6, run the following command:
SET NODEBOPTDYNADJPARA: DYNADJSW=ON, DYNADJSTARTTIME=0, DYNADJENDTIME=6;
