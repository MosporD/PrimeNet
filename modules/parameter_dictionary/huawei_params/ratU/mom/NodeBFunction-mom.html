NodeBFunction MOM Description

This section describes the functions and concepts of NodeBFunction and also provides the managed object model (MOM) view and MOs related to NodeBFunction.

Functions and Concepts

NodeBFunction

NodeBFunction is the root node of a NodeB function and is used to perform UMTS radio access functions, including air interface management, access control, resource allocation.

MOM View

Figure 1 is a subset of the NodeB MOM and provides MOs related to NodeBFunction.

Figure 1 NodeBFunction MOM view

In the NodeBFunction MOM view, the NODEBFUNCTION MO is attributed to the NE MO which is the root node of NEs. The NODEBFUNCTION MO is the root node of a NodeB function. Before creating a NODEBFUNCTION MO, the Application ID (under the APLLICATION MO) referenced by the NODEBFUNCTION MO must be available and the application object type must be NodeB.

One NODEBFUNCTION MO corresponds to one NodeB instance, and a NodeB has only one NODEBFUNCTION MO.

The NodeBFunction MOM is divided into NodeB MOM, local cell MOM, and Iub MOM.

  • For detailed descriptions about the NodeB MOM, see NodeB MOM Description.
  • For detailed descriptions about the local cell MOM, see Local Cell MOM Description.
  • For detailed descriptions about the Iub MOM, see Iub MOM Description.
NOTE:
