Local Cell MOM Description

This section describes the functions and concepts of local cells and also provides the managed object model (MOM) view and related managed objects (MOs).

Functions and Concepts

Local cell (ULOCELL)

A UMTS cell defined by this MO is a wireless coverage area identified using a base transceiver station identity code (BSIC) or a cell global identification (CGI) and is the minimum service unit that allows a UE to access a network. Cell functions are implemented by the RNC and the NodeB. A local cell is the functional set of a UMTS cell on the NodeB.

SECTOR

A sector defined by this MO is the smallest radio coverage area. Each sector uses one or more radio carriers to provide coverage. Each radio carrier works at a frequency. A sector and a carrier together compose a cell that UEs can access.

Sector equipment (SECTOREQM)

This MO defines antenna channels and their working modes in a sector. An antenna channel can serve as a Tx channel, Rx channel, Tx/Rx channel, or active/standby channel. One sector can be equipped with multiple pieces of sector equipment.

Sector equipment of a local cell (ULOCELLSECTOREQM)

This MO defines sector equipment used in a cell and the configurations of each pieces of sector equipment. One piece of sector equipment can serve one or multiple cells in different manners, for example, transmitting signals with different maximum power.

Baseband equipment (BASEBANDEQM)

This MO defines configurations of uplink resource groups and downlink resource groups used in a cell, including the number of configured boards and the uplink demodulation capability.

The MOs related to a local cell are described as follows:

  • ULOCELL defines basic information about a local cell, including the local cell type, baseband resource group configurations, frequency, and activated features.
  • ULOCELLALGPARA defines parameters related to algorithms for a local cell, including parameters for suppressing RTWP surge.
  • ULOCELLNOACCESSPARA defines the switch for enabling Sleeping Cell Detection, parameters related to the detection algorithm, and postprocessing operations after a sleeping cell is detected.
  • ULOCELLMACHSPARA defines parameters related to the HSDPA algorithm, including parameters about resource allocation policies and power policies.
  • ULOCELLRSCLMTPARA defines the maximum percentage of the resources for services with different GBRs.
  • ULOCELLSECEQMGRP defines the pRRU grouping relationship of a hybrid multi-RRU cell.
  • ULOCELLSECTOREQM defines sector equipment used in a cell and the configurations of each pieces of sector equipment. One piece of sector equipment can serve one or multiple cells in different manners, for example, transmitting signals with different maximum power.
  • SECTOREQM defines antenna channels and their working modes in a sector. An antenna channel can serve as a Tx channel, Rx channel, Tx/Rx channel, or active/standby channel. One sector can be equipped with multiple pieces of sector equipment.
  • ULOCELLR99ALGPARA defines parameters related to the R99 algorithm, including power control parameters.
  • ULOCELLMACEPARA defines parameters related to the HSUPA algorithm, including Mac-e scheduling parameters and power control parameters.
  • NODEBREMOTECELLGRP defines a resource group of remote coverage cells and is referenced when a remote coverage cell is configured.
  • NODEBMULTICELLGRP defines a multi—carrier cell group and is referenced when a DC/MC cell is configured.
  • NODEBULCOMPGRP defines a coordinating cell of a UL CoMP cell. UL CoMP uses uplink antennas of the host cell (primary cell) and neighboring cell (coordinating cell) in a UL CoMP pair to combine received signals, thereby obtaining uplink gains.
  • BASEBANDEQM defines configurations of uplink resource groups and downlink resource groups used in a cell, including the number of configured boards and the uplink demodulation capability.
  • NODEBBBUNIT defines the ID of the BBU used in a cell. The parameters configured in this MO are used to readjust cell deployment policies of uplink resource groups, thereby improving sharing of uplink CEs.
