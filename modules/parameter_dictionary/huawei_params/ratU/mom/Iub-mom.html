Iub MOM Description

This section describes the functions and concepts of the Iub MOM and provides the managed object model (MOM) view and MOs related to the Iub interface.

Functions and Concepts

The UMTS Iub interface works between a NodeB and an RNC. The interface complies with the protocol stacks shown in Figure 1. By data to be transmitted, the Iub interface can be divided into the control plane and user plane.

Figure 1 Iub protocol stack

The network transport layer can use ATM or IP. In ATM transport mode, the physical layer uses E1/T1 and STM-1/OC-3 protocols. In IP transport mode, the physical layer uses FE/GE and E1/T1 protocols.

  • The control-plane data over the Iub interface is carried over SAAL in ATM transport mode and over SCTP in IP transport mode. The radio network layer uses NBAP.
  • The user-plane data over the Iub interface is carried over AAL2 in ATM transport mode and over UDP in IP transport mode. The radio network layer uses FP.

Figure 2 shows the relationship between MOs over the Iub interface.

Figure 2 Relationship between MOs over the Iub interface

The Iub data can be configured in Link or End-Point mode. In Link mode, both local and peer parameters, such as source and destination IP addresses, are manually configured. In End-Point mode, local parameters can only be manually configured and peer parameters can be automatically obtained by the NodeBFunction from signaling or manually configured.

  • The control-plane data over the Iub interface can be configured only in Link mode. The related MOs are SCTPLNK, IUBCP, and CPBEARER.
  • The user-plane data over the Iub interface can be configured in either Link or End-Point mode. In Link mode, the related MOs are IPPATH and (optional) NODEBPATH. In End-Point mode, the related MOs are IUB, EPGROUP, USERPLANEHOST, and USERPLANEPEER.
NOTE:
  • The user-plane data over the Iub interface can be configured in only one mode (Link mode or End-Point mode) at a time. The Link mode is recommended.
  • When the user-plane data over the Iub interface is configured in Link mode, the NODEBPATH MO is optional. For a co-MPT GSM/UMTS base station, if the GSM and UMTS modes use the same peer IP address and differentiated services code point (DSCP) but different local IP addresses under the IPPATH MO, the NODEBPATH MO must be configured.
  • When the user-plane data over the Iub interface is configured in End-Point mode, it is recommended that local parameters be manually configured and peer parameters be automatically obtained by the NodeBFunction from signaling.

MOM

Iub Control-Plane MOM

Figure 3 is a subset of the NodeB MOM and provides MOs related to the Iub control plane.

Figure 3 MOM view for Iub control plane
  • IUBCP defines the control port that carries the control-plane data over the Iub interface for a NodeBFunction. One IUBCP corresponds to one CPBEARER MO.
  • CPBEARER is the encapsulation and abstraction of the control port bearer and is used to shield lower-layer protocol information from the upper-layers and to provide transmission bearer for the control plane at the application layer. One CPBEARER MO corresponds to one SCTPLNK MO.
  • SCTPLNK defines an SCTP link over the Iub interface and is used to configure SCTP-related parameters.

Iub User-plane MOM

Figure 4 and Figure 5 are subnets of the NodeB MOM and provides MOs related to the Iub user plane.

Figure 4 MOM view for Iub user plane (in Link mode)
  • NODEBPATH, which is optional, defines the IPPATH MO that can be bound to the GBTSFunction. One NODEBPATH MO corresponds to one IPPATH MO.
  • IPPATH defines a path for transmitting user-plane data over the Iub interface.
Figure 5 MOM view for Iub user plane (in End-Point mode)
  • IUB defines a set of transmission resources bound to the Iub interface of a NodeBFunction. One IUB MO corresponds to one EPGROUP MO.
  • EPGROUP defines a set of transmission end point resources, including a set of control-plane end points, user-plane end points, or a combined set of both. The NodeBFunction can only use the set of user-plane end points. One EPGROUP MO can be configured with a maximum of 12 USERPLANEHOST MOs.
  • USERPLANEHOST defines local transmission parameters for the user-plane data.
  • USERPLANEPEER defines peer transmission parameters for the user-plane data.
