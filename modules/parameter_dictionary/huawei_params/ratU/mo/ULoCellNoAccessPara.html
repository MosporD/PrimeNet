ULOCELLNOACCESSPARA

+-NE
  +-NODEBFUNCTION
    +-ULOCELL
      +-ULOCELLNOACCESSPARA

Description

The ULOCELLNOACCESSPARA MO configures sleeping cell detection parameters and follow-up policies of sleeping cells, such as Timer Length Of the Cell Without RL Setup and Auto Recovery Method.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ULOCELL

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ULOCELLNOACCESSPARA

The command is used to list the parameters of a sleeping cell.
SET ULOCELLNOACCESSPARA

This command is used to set parameters for sleeping cells. Sleeping cells refer to cells that no users access in a specified period of time.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID.
Timer Length Of the Cell Without RL Setup

Indicates the period of no services in a cell. Value 0 means that the timer is disabled. If there are no services in the cell for a period longer than the duration specified by this parameter value, the NodeB reports the alarm ALM-28209 Cell No Traffic. For details about how to clear the alarm ALM-28209 Cell No Traffic, see the alarm reference.
Timer Length Of Cell Without RL Setup (First RLS)

Indicates the period of no initial access requests in a cell. 0 means that the timer is disabled. If there are no initial access requests in the cell for a period longer than the duration specified by this parameter value, the NodeB reports the alarm ALM-28209 Cell No Traffic. For details about how to clear the alarm ALM-28209 Cell No Traffic, see the alarm reference.
Auto Recovery Method

Indicates the auto recovery method when no services are carried in the cell or no user originates initial access for a period.
