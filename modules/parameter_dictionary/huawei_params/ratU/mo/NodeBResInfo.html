NODEBRESINFO

Description

The NODEBRESINFO MO is used to define common resource configurations of a NodeB and query resource usage.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP NODEBRESINFO

This command is used to query resource information of a NodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
NodeB Available CNBAP

Indicates the CNBAP capability for hardware in a NodeB.
NodeB Average CNBAP Usage

Indicates the average CNBAP usage of a NodeB in a measurement period. The maximum average usage calculated in a measurement period is adopted.
NodeB Maximum CNBAP Usage

Indicates the maximum CNBAP usage of a NodeB in a measurement period. The maximum usage calculated in a measurement period is adopted.
NodeB UL CE Number

Indicates the number of available uplink CEs for hardware in a NodeB.
NodeB DL CE Number

Indicates the number of available downlink CEs for hardware in a NodeB.
UL Baseband Equipment ID

Indicates the ID of the uplink baseband equipment.
Resource Group UL CE

Indicates the number of available CEs for hardware in an uplink resource group.
Resource Group Average UL CE

Indicates the average number of CEs used for an uplink resource group in a measurement period. The maximum average number of CEs calculated in a measurement period is adopted.
Resource Group Maximum UL CE

Indicates the maximum number of CEs used for an uplink resource group in a measurement period. The maximum number of CEs calculated in a measurement period is adopted.
Maximum Resource Group Gain

Indicates the maximum capacity gain achieved after all WBBPb or WBBPd boards are replaced by UBBPd boards in the uplink resource group in a measurement period. The maximum capacity gain calculated in a measurement period is adopted. The capacity gain is evaluated in scenarios where HSUPA 2 ms TTI is used. The replacement may lead to no gains in other scenarios.
Minimum Resource Group Gain

Indicates the minimum capacity gain achieved after all WBBPb or WBBPd boards are replaced by UBBPd boards in the uplink resource group in a measurement period. The minimum capacity gain calculated in a measurement period is adopted. The capacity gain is evaluated in scenarios where HSUPA 2 ms TTI is used. The replacement may lead to no gains in other scenarios.
Cabinet No.

Indicates the number of the cabinet where the board is located.
Subrack No.

Indicates the number of the subrack where the board is located.
Slot No.

Indicates the number of the slot where the board is located.
Maximum Board Gain

Indicates the maximum capacity gain achieved after a WBBPb or WBBPd board is replaced by a UBBPd board in a measurement period. The maximum capacity gain calculated in a measurement period is adopted. The capacity gain is evaluated in scenarios where HSUPA 2 ms TTI is used. The replacement may lead to no gains in other scenarios.
Minimum Board Gain

Indicates the minimum capacity gain achieved after a WBBPb or WBBPd board is replaced by a UBBPd board in a measurement period. The minimum capacity gain calculated in a measurement period is adopted. The capacity gain is evaluated in scenarios where HSUPA 2 ms TTI is used. The replacement may lead to no gains in other scenarios.
Average Ratio of HSDPA Users

Indicates the average ratio of HSDPA users on a board in a measurement period. The maximum average ratio calculated in a measurement period is adopted.
Maximum Ratio of HSDPA Users

Indicates the maximum ratio of HSDPA users on a board in a measurement period. The maximum ratio calculated in a measurement period is adopted.
Average Ratio of HSUPA Users

Indicates the average ratio of HSUPA users on a board in a measurement period. The maximum average ratio calculated in a measurement period is adopted.
Maximum Ratio of HSUPA Users

Indicates the maximum ratio of HSUPA users on a board in a measurement period. The maximum ratio calculated in a measurement period is adopted.
Maximum number of processed radio links

Indicates the maximum number of radio links processed by the NodeB per second within a measurement period.
Average number of used HS-PDSCH codes

Indicates the average number of HS-PDSCH codes used in a cell within a measurement period.
Maximum number of used HS-PDSCH codes

Indicates the maximum number of HS-PDSCH codes used in a cell within a measurement period.
Minimum number of used HS-PDSCH codes

Indicates the minimum number of HS-PDSCH codes used in a cell within a measurement period.
Maximum number of available HS-PDSCH codes

Indicates the maximum number of available HS-PDSCH codes used in a cell within a measurement period.
Maximum number of available hardware CEs

Indicates the number of available downlink hardware CEs by a board.
Average number of used downlink CEs

Indicates the average number of downlink CEs used by a board within a measurement period.
Local Cell ID

Indicates the local cell ID. The local cell ID is unique for one NodeB.
NodeB CNBAP Reject Rate

Indicates the CNBAP rejection rate of a NodeB in a measurement period. The maximum CNBAP rejection rate in a measurement period is adopted.
Average Dedicated Measurement Report Number

Indicates the average number of dedicated measurement reports of a NodeB in a measurement period. The maximum average number of dedicated measurement reports in a measurement period is adopted.
