NODEBSMTHPWR

+-NE
  +-NODEBFUNCTION
    +-NODEBSMTHPWR

Description

The NODEBSMTHPWR MO configures parameters related to smooth power change function, such as Smooth Power Change Function Switch, Smart default step, and Smart default time ratio.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NODEBSMTHPWRPARA

The command is used to obtain the smooth power change function parameters.
LST NODEBSMTHPWRSW

The command is used to obtain the smooth power change function switch.
SET NODEBSMTHPWRPARA

The command is used to set parameters of smooth power change function.
SET NODEBSMTHPWRSW

The command is used to set the smooth power change function switch.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Smooth Power Change Function Switch

Indicates the smooth power change function switch. The function will be enabled if this parameter is set to OPEN. The function will be not enabled if this parameter is set to CLOSE.
Smart Default Step

Indicates the smart default step.
Smart Default Time Ratio

Indicates the smart default time ratio.
