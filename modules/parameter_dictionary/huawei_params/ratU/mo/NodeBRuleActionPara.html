NODEBRULEACTIONPARA

+-NE
  +-NODEBFUNCTION
    +-NODEBRULEACTIONPARA

Description

The NODEBRULEACTIONPARA MO configures associated parameters of a rule, including MOs, parameters, administrative state, values of associated parameters, and user-defined information.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP NODEBRULEACTIONPARA

This command is used to query the activation status of a rule for a specified cell or all cells and the active value of the parameter associated with the rule.
LST NODEBRULEACTIONPARA

This command is used to query the parameter configurations of a specified rule or all rules.
SET NODEBRULEACTIONPARA

This command is used to modify the configurations of associated parameters for a rule. The RNC delivers rules to NodeBs depending on network conditions.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rule ID

Indicates the ID of a rule. The parameter value range extends with the rule quantity. Rule IDs 0 and 1 indicate that the SIB7RTWPOPTSW and SIB7MAXRTWP parameters must be configured. Rule IDs 2 and 3 indicate that the RTWPSIRTGTADJSW parameter must be configured. Rule ID 4 indicates ICMODE parameter must be configured. Rule IDs 5 and 6 indicate that the EXTRAPOWER parameter must be configured. Rule ID 7 indicates that TURBOIC parameter must be configured. Rule ID 8 indicates that DPCHMAXTXPWRRESTRSW parameter must be configured. Rule ID 9 indicates that RADIOQUALITYDPCHPCSW parameter must be configured. Rule ID 10 indicates that DPCHTPCPOADJSW parameter must be configured.
MO Name

Indicates the name of an MO whose parameters are associated with a rule.
Parameter Name

Indicates the name of a parameter associated with a rule.
Administrative State

Indicates the status of association between a parameter and a specified rule. DISABLE indicates that the parameter is disassociated from the specified rule. ENABLE indicates that the parameter is associated with the specified rule.
Interval Type Value

Indicates the value of an interval-type parameter. The value 2147483647 is invalid and cannot be configured by users.
Enumerate Type Value

Indicates the value of an enumeration-type parameter.
User Label

Indicates user-defined information about a rule.
