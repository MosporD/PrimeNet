NODEBALGPARA

+-NE
  +-NODEBFUNCTION
    +-NODEBALGPARA

Description

The NODEBALGPARA MO configures NodeB-level algorithm parameters.

Effective Scenario

Immediately

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
2ms User Minimum Admission CE

Indicates the minimum number of CEs for admitting 2 ms users when CE Overbooking is enabled.
CCPIC Phase Switch

Indicates the switch for selecting the CCPIC phase. The value DEFAULT indicates that CCPIC Phase 3 and CCPIC Phase 4 are disabled. The value CCPICPHASE3 indicates that CCPIC Phase 3 is enabled and CCPIC Phase 4 is disabled. The value CCPICPHASE4 indicates that CCPIC Phase 3 and CCPIC Phase 4 is enabled.
Hsdpa Scheduler Pool Switch

Indicates whether to enable HSDPA scheduler pool.
Power Configuration Check Switch

Indicates whether to enable the power configuration check.
CCPIC Phase SIR Target Correction SW

Indicates whether to correct the SIR outer loop power control target value when CCPIC is enabled. If CCPIC Phase 2 is enabled, this parameter controls only the value corresponding to CCPIC phase 2. If CCPIC Phase 3 is enabled, this parameter controls both the value corresponding to CCPIC phase 2 and the value corresponding to CCPIC phase 3.
HSUPA AdaRetransSwitch

Indicates the HSUPA Adaptive Retransmission Control Switch. The function will be enabled if this parameter is set to OPEN. The function will be disabled if this parameter is set to CLOSE. If this parameter is set to OPEN and there are adequate channel elements (CEs), this improves uplink HSUPA capacity and uplink HSUPA coverage.
First Reject Threshold

Indicates the control plane congestion first reject threshold.
Inter-board cancellation gain switch between the WBBPa and WBBPb boards

Indicates the inter-board cancellation gain switch between the WBBPa/WBBPb board and a board supporting IC. This parameter is valid when features related to inter-board cancellation take effect. Indicates the threshold of the output power percentage for cells to stop the VAM Power Saving feature. If the average output power percentage of any VAM cell served by an RF module is greater than this threshold, the disabled power amplifier is enabled to equally share the power emitted by VAM cells between two working power amplifiers.
HSDPA Serving Cell Change Optimization Switch

Indicates the switch for HSDPA serving cell change optimization. When this switch is turned on, the data transmission policy during the HSDPA serving cell change is improved, increasing the user throughput and user experience. When this switch is turned off, the original algorithm applies.

Indicates AMR transmission bandwidth compression switch. When this switch is turned on, the AMR transmission bandwidth compression function is enabled for all cells served by a NodeB. When this switch is turned off, the AMR transmission bandwidth compression function is disabled for all cells served by a NodeB. It is good practice to turn on this switch in satellite transmission over Iub scenarios.
Soft Fault Self-healing Switch

Indicates whether to enable soft failure self-healing. If BBPRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the baseband processing unit check result and the number of random access messages. If the soft failure affects services, the baseband processing unit is restarted to recover services. When BBPRESETSWITCH is set to ON, if BBPRESETDELAYSWITCH is set to ON, the baseband processing unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if BBPRESETDELAYSWITCH is set to OFF, the baseband processing unit restarts immediately upon detecting soft failures and service exceptions. If RFRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the RF unit check result and the number of random access messages. If the soft failure affects services, the RF unit is restarted to recover services. When RFRESETSWITCH is set to ON, if RFRESETDELAYSWITCH is set to ON, the RF unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if RFRESETDELAYSWITCH is set to OFF, the RF unit restarts immediately upon detecting soft failures and service exceptions. If BBSFRESHUFFLESWITCH is set to ON, the NodeB attempts to relocate cells served by the faulty baseband module to other baseband modules and restart the faulty module for self-healing after detecting a soft failure on the baseband module. If BBSFCORRECTSWITCH is set to ON, the NodeB attempts to correct the soft failure. This reduces the frequency of restarting the baseband module.
KPI Fault Detection

Indicates the switch for potential KPI fault detection and reporting of related alarms. The items to be detected include the baseband resource R99 user BLER, baseband resource HSUPA user BLER, cell R99 user BLER, cell HSUPA user BLER, cell HSDPA user BLER, and Iub interface failure rate. If an option under this parameter is set to ON, the NodeB performs fault detection on the related detection item and reports related alarms. If an option under this parameter is set to OFF, the NodeB does not perform fault detection on the related detection item or report related alarms.

NBIS Reselection Period

Indicates the reselection period of Narrowband Interference Suppression (NBIS). When this parameter is set to a proper value, the NodeB disables the NBIS function on the current carrier and checks whether the narrowband interference is cleared on the current carrier or choose another carrier to perform the NBIS function. When this parameter is set to 0, the NodeB does not perform the reselection of NBIS.
RTWP Imbalance Alarm Threshold

Indicates the RTWP imbalance alarm threshold. When the difference between the RTWP of the uplink channel of RRU and the RTWP of the uplink channel of the RFU exceeds the threshold, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is reported.
Cell RTWP Excessive Alarm Report Switch

Indicates whether to enable the Cell RTWP Excessive alarm report function.
Cell RTWP Excessive Alarm Threshold

Indicates the Cell RTWP Excessive alarm threshold. When Cell RTWP Excessive Alarm Report Switch is set to ON, the NodeB measures the RTWP of each uplink channel in a cell every second. In the alarm reporting period (2 hours), if more than 80% of the measured value on the uplink channel is higher than or equal to the threshold, the Cell RTWP Excessive alarm is reported. After the alarm is reported, in the alarm clearing period (3 minutes), if more than 80% of measured value on the cell uplink channel is lower than the threshold, the alarm is cleared. If the desensitization parameter is configured, the measured value on the uplink channel is modified based on the cell-level desensitization intensity. If the cell is enabled with GU@5 MHz, the threshold is modified based on the GU@5 MHz configurations.
NBIS Initial Startup Threshold

Indicates the NBIS initial startup threshold when NBIS Adaptive Switch is set to ON. If the average no-service RTWP of all cells working on a frequency within half an hour is greater than the threshold, NBIS is started. Otherwise, NBIS is not started.
ACK Field Detect Threshold Opt Switch

Indicates whether to enable ACK field detection threshold optimization. When this switch is turned on, the NodeB optimizes the detection threshold of the ACK field. When this switch is turned off, the NodeB does not optimize the detection threshold of the ACK field.
Smart Scheduling Learning Mode

Indicates the machine leaning mode for smart scheduling. If this parameter is set to LEARNING, the NodeB performs real-time machine learning and activates the Machine Learning based Scheduling feature. If this parameter is set to HOLD, the NodeB suspends the learning and uses the current optimal learning result to activate the Machine Learning based Scheduling feature.

Indicates the time period in which the UMTS and LTE Dynamic Power Sharing feature is effective on a multimode base station.
Private Operator License Alarm Policy

Indicates whether to optimize reporting of ALM-26812 System Dynamic Traffic Exceeding Licensed Limit for a private operator. This threshold is specified using the SET NODEBLICENSEALMTH command. Without the optimization, this alarm is reported when the number of licenses used by the private operator exceeds the licensed threshold for the private operator.
Shutdown Fault Detection Switch

Indicates whether the NodeB shutdown fault identification function is enabled. When this parameter is set to ON, the cause of the NodeB shutdown fault can be promptly identified.

Indicates whether to perform inter-board service link failure detection and report ALM-26215 Inter-Board Service Link Failure.
