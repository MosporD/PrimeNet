IUB

+-NE
  +-NODEBFUNCTION
    +-IUB

Description

The IUB MO configures Iub related parameters, such as Iub ID, EndPoint Group ID, and User Label.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the NODEBFUNCTION MO:
    • The NODEBFUNCTION MO associated with the IUB MO must have been configured.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO associated with the IUB MO must have been configured, and the APPTYPE value must be set to NULL.
    • The number of USERPLANEHOST configured in the EPGROUP MO used by IUB ranges from 1 to 4.
  • Relation with the UX2 MO:
    • UPEPGROUPID in any UX2 MO must be different from UPEPGROUPID in any IUB MO.
    • CPEPGROUPID in any UX2 MO must be different from UPEPGROUPID in any IUB MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Iub ID

Indicates the IUB ID.
EndPoint Group ID

Indicates the EndPoint Group ID used by Iub interface.
User Label

Indicates the user label of IUB.
Static Check Switch

Indicates whether to enable static Ping detection over the Iub interface. If this parameter is set to ICMP(ICMP), static ICMP Ping detection is enabled over the Iub interface. If this parameter is set to OFF(OFF), static Ping detection is disabled over the Iub interface.
