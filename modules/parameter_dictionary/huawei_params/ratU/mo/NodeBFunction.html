Description

The NODEBFUNCTION MO configures NodeB function parameters, such as NodeB Function Name, Application Reference, NodeB Identifier, and User Label.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NE

  • Possible children:

    BEAMCELLGROUP[0~24];IUB[0~1];IUBCP[0~100];NODEBALGPARA[1~1];NODEBBASEBANDEQMPARA[0~36];NODEBBBRES[0~12];NODEBBBUNIT[0~5];NODEBCHRLEVEL[1~1];NODEBCLSPATIMER[1~1];NODEBEXSECCELLGRP[0~96];NODEBLICENSEALMTHD[1~1];NODEBMULTICELLGRP[0~96];NODEBOPTDYNADJPARA[1~1];NODEBPATH[0~128];NODEBPOWEROUTAGE[1~1];NODEBREMOTECELLGRP[0~48];NODEBRESALLOCRULE[1~1];NODEBRSVDPARA[1~1];NODEBRULEACTIONPARA[0~500];NODEBSMTHPWR[1~1];NODEBTRFOVERLOADTHD[1~1];NODEBUEQOSENHANCE[1~1];NODEBULCOMPGRP[0~240];ULOCELL[0~48];UX2[0~1]
  • Relation with the ULOCELL MO:
    • The NODEBFUNCTION MO associated with the ULOCELL MO must have been configured.
    • A maximum of 12 ULOCELL MOs can be configured if the any of the following conditions is true: (1) ULSUPERNARROWBANDFILTER is not set to NOTSUPPORT. (2) DLADAPTIVEBPFILTER is not set to NOTSUPPORT. (3) GSMQLBASEDROTDYNACTRL is set to TRUE. (4) DCHSDPASHAREDWITHGSM is not set to NOTSUPPORT.
    • The number of ULOCELL MOs under which BFMODE is set to MASSIVEBEAM, NORMALBEAM, or COORDINATEDBEAM cannot be greater than 24.
  • Relation with the IUBCP MO:
    • The NODEBFUNCTION MO associated with the IUBCP MO must have been configured.
  • Relation with the NODEBPATH MO:
    • The NODEBFUNCTION MO associated with the NODEBPATH MO must have been configured.
  • Relation with the IUB MO:
    • The NODEBFUNCTION MO associated with the IUB MO must have been configured.
  • Relation with the NODEBMULTICELLGRP MO:
    • The NODEBFUNCTION MO associated with the NODEBMULTICELLGRP MO must have been configured.
  • Relation with the NODEBFUNCTION MO:
    • APPLICATIONREF in NODEBFUNCTION MO must have been set in the associated APPLICATION MO with NodeB AT.
  • Relation with the ULOCELL and NODEBULCOMPGRP MOs:
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, the NEIGHBOURLOCELLID must have been configured.
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, the LOCELLTYPE for all local cells associated with the NEIGHBOURLOCELLID can not be MULTIRRU_CELL, DIST_CELL, HALFFREQ_CELL or IMB_CELL or MIXED_MULTIRRU_CELL.
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, the RMTCM for all local cells associated with the NEIGHBOURLOCELLID must be FALSE and RADIUS can not be greater than 35 km.
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, the ULBASEBANDEQMID for the HOSTLOCELLID and the NEIGHBOURLOCELLID must be the same.
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID of the NODEBFUNCTION, the DLFREQ of the HOSTLOCELLID and the NEIGHBOURLOCELLID must be the same.
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID of the NODEBFUNCTION, if the ULFREQIND under the ULOCELL MO referenced by HOSTLOCELLID and the ULFREQIND under the ULOCELL MO referenced by NEIGHBOURLOCELLID are set to TRUE, the ULFREQ of the ULOCELL MOs must be the same.
  • Relation with the NODEBULCOMPGRP MO:
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, the HOSTLOCELLID and the NEIGHBOURLOCELLID can not be the same.
    • When ULCOVEXP under the NODEBULCOMPGRP MO is TRUE, the NODEBID under the NODEBULCOMPGRP MO and NODEBID under the NODEBFUNCTION MO must be the same.
  • Relation with the NODEBBASEBANDEQMPARA MO:
    • The NODEBFUNCTION MO associated with the NODEBBASEBANDEQMPARA MO must have been configured.
  • Relation with the ULOCELL and ULOCELLSECTOREQM MOs:
    • Of the ULOCELL MOs using the ULOCELLSECTOREQM MOs with SECTOREQMPROPERTY set to ASSISTANCE, the number of ULOCELL MOs, which have ULFREQIND set to TRUE but have different ULFREQ settings, must be less than or equal to 24.
    • Of the ULOCELL MOs using the ULOCELLSECTOREQM MOs with SECTOREQMPROPERTY set to ASSISTANCE, the number of ULOCELL MOs with different DLFREQ settings must be less than or equal to 24.
    • Of the ULOCELL MOs using the ULOCELLSECTOREQM MOs with SECTOREQMPROPERTY set to ASSISTANCE, the number of ULOCELL MOs, which have ULFREQIND set to TRUE but have different ULFREQ settings, plus the number of all ULOCELL MOs configured on the NodeB must be less than or equal to 48.
    • Of the ULOCELL MOs using the ULOCELLSECTOREQM MOs with SECTOREQMPROPERTY set to ASSISTANCE, the number of ULOCELL MOs with different DLFREQ settings plus the number of all ULOCELL MOs configured on the NodeB must be less than or equal to 48.
  • Relation with the ULOCELL, NODEBULCOMPGRP, BASEBANDEQM, and BBP MOs:
    • If NODEBID under the NODEBULCOMPGRP MO is the same as NODEBID under the NODEBFUNCTION MO, and RADIUS under the ULOCELL MO referenced by NEIGHBOURLOCELLID is greater than 30 km, TYPE under all BBP MOs configured in the BASEBANDEQM MO referenced by ULBASEBANDEQMID under the ULOCELL MO cannot be WBBP.
  • Relation with the ULOCELL, NODEBULCOMPGRP, BASEBANDEQM, ULOCELLSECTOREQM, and SECTOREQM MOs:
    • When the NODEBID under the NODEBULCOMPGRP MO is the same as the NODEBID under the NODEBFUNCTION MO, and UMTSDEMMODE under the BASEBANDEQM MOs used by the ULOCELL MOs corresponding to the HOSTLOCELLID and NEIGHBOURLOCELLID is DEM_ADPT_CHAN, for the local cells corresponding to HOSTLOCELLID and NEIGHBOURLOCELLID, the number of RX antennas configured under the SECTOREQM MOs associated with ULOCELLSECTOREQM MOs under which SECTOREQMPROPERTY is NORMAL must be either smaller than 4 or equal to 4.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NodeB Function Name

Indicates the NodeB function name.
Application Reference

This parameter indicates the ID of the Application MO that is referenced by the NodeBFunction MO. The Application MO provides operating environments for the NodeBFunction MO.
NeRM Version

Indicates the NodeB NE resource model version. In the same model version, all MO types, attributes, and configuration rules in the model are defined in the same way.

If the model definition (MOC definition, attribute definition, and configuration rules) for different NE software is the same, these NE software uses the same model version.

Generally, a software version uniquely corresponds to a model version. A software version may correspond to multiple model versions in few cases, for example, the software version is upgraded but the model version is not upgraded, or a software version is compatible with multiple model versions.
User Label

Indicates the user label.

If a user requires multiple information, the format is "%Name1::Value1%Name2::Value2%other description".
NodeB Identifier

Indicates the NodeB ID.
Product Version

Indicates the product software version of the NodeBFunction.
