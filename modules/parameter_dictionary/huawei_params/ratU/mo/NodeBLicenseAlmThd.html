NODEBLICENSEALMTHD

+-NE
  +-NODEBFUNCTION
    +-NODEBLICENSEALMTHD

Description

The NODEBLICENSEALMTHD MO configures NodeB license alarm parameters, such as Alarm Occur Threshold, Alarm Detect Period, Alarm Recover Threshold, and Alarm Recover Period.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NODEBLICENSEALMTHD

The command is used to obtain the license alarm threshold and detect period parameters.
SET NODEBLICENSEALMTHD

The command is used to modify the license alarm threshold and detect period parameters.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Alarm Occur Threshold

Indicates the threshold of triggering ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.
Alarm Detect Period

Indicates the interval for detecting ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.
Alarm Recover Threshold

Indicates the threshold of clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.
Alarm Recover Period

Indicates the interval for clearing ALM-26812 System Dynamic Traffic Exceeding Licensed Limit.
