NODEBBBUNIT

+-NE
  +-NODEBFUNCTION
    +-NODEBBBUNIT

Description

The NODEBBBUNIT MO configures BBU parameters, such as Baseband Unit ID, Cabinet No., Subrack No., and Slot No.. The BLADEBBU and BBU3910C do not support the configuration object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the NODEBBBUNIT MO:
    • CN, SRN, SN of a board cannot be added to different NODEBBBUNIT.
  • Relation with the ULOCELL MO:
    • The NODEBBBUNIT MO in the ULOCELL MO must be configured.
  • Relation with the BASEBANDEQM and ULOCELL MOs:
    • When UMTSDEMMODE under the BASEBANDEQM MO used by ULOCELL MO is DEM_ADPT_CHAN, the ULOCELL MO cannot use any NODEBBBUNIT MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NODEBBBUNIT

Use this command to add a BBU to a NodeB.
LST NODEBBBUNIT

Use this command to query the information about a BBU.
RMV NODEBBBUNIT

Use this command to remove a BBU from a NodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description

Indicates the number of the BBU.

Indicates the number of the cabinet where the BBU is located.
Subrack No.

Indicates the number of the subrack where the BBU is located.
Slot No.

Indicates the number of the slot where the BBU is located.
