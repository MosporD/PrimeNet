ULOCELLEXT

Description

The ULOCELLEXT MO is used to define extension information of a local cell.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP ULOCELLCPRIINFO

This command is used to query the CPRI information of a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
Upper Level Optical Module Information

Indicates the cabinet No., subrack No., slot No., and port No. of the upper-level optical module of the RF unit serving the cell.
Upper Level Optical Module Maximum Code Rate

Indicates the maximum rate supported by the upper-level optical module of the RF unit serving the cell.
Lower Level Optical Module Information

Indicates the cabinet No., subrack No., slot No., and port No. of the lower-level optical module of the RF unit serving the cell.
Lower Level Optical Module Maximum Code Rate

Indicates the maximum rate supported by the lower-level optical module of the RF unit serving the cell.
CPRI Bandwidth to be Allocated for the Cell

Indicates the CPRI bandwidth to be automatically allocated to the cell on the current CPRI link, including the bandwidth required for both payload and overhead transmissions. This parameter is valid when the cell capability is degraded or the cell is not activated.
Total Occupied Cell CPRI Link Bandwidth

Indicates the total CPRI bandwidth occupied by all cells on the CPRI link serving the cell, including the bandwidth required for both payload and overhead transmissions.
CPRI Rate

Indicates the rate over the CPRI port on the RF unit serving the cell.
