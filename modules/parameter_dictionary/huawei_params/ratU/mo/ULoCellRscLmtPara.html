ULOCELLRSCLMTPARA

+-NE
  +-NODEBFUNCTION
    +-ULOCELL
      +-ULOCELLRSCLMTPARA

Description

The MO configures the Mac-hs resource limitation ratios of different GBR services, such as Resource limiting for 8Kbit/s GBR and Resource limiting for 16Kbit/s GBR.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ULOCELL

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ULOCELLRSCLMTPARA

The command is used to list the Mac-hs resource limiting scheduling parameters of specified or all local cells.
SET ULOCELLRSCLMTPARA

This command is used to set the resource allocation proportions for different GBR services.
