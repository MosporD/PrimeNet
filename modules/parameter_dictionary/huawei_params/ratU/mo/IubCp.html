IUBCP

+-NE
  +-NODEBFUNCTION
    +-IUBCP

Description

The IUBCP MO configures NodeB Iub control port parameters, such as Port Type, CP Port No., CPBear ID, and Belong Flag.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the CPBEARER MO:
    • The CPBEARER MO associated with the IUBCP MO must have been configured.
    • Under the CPBEARER MO associated with the IUBCP MO, BEARTYPE must be set to SAAL or SCTP.
  • Relation with the IUBCP MO:
    • CPBEARID in each IUBCP MO must be unique.
  • Relation with the NODEBFUNCTION MO:
    • The NODEBFUNCTION MO associated with the IUBCP MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD IUBCP

Use this command to add the active/standby NodeB control port (NCP) or active/standby communication control port (CCP). The traffic on the NCP/CCP can be carried by IP transport or ATM transport. In IP transport mode, the NCP/CCP is carried on the SCTP link. In ATM transport mode, the NCP/CCP is carried on the SAAL link.

When both active and standby NCPs/CCPs are configured and channel switchover is enabled, the standby NCP/CCP becomes the active one and automatically takes over its services after the active NCP/CCP is faulty. If channel switchover is disabled, an active/standby switchover will not be triggered even if the active or standby NCP/CCP is faulty.

To support the disaster tolerance scheme for the RNC, the IUBCP can be set to either the primary homing mode or secondary homing mode. By default, the IUBCP is set to the primary homing mode. If the default configuration needs to be modified, ensure that disaster tolerance has been configured for the RNC.
DSP IUBCP

Use this command to query the status of an Iub control port.
LST IUBCP

Use this command to list the configuration of an Iub control port.
RMV IUBCP

Use this command to remove an Iub control port.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Port Type

Indicates the type of Iub control port. The control port type is classified into NodeB Control Port (NCP) and Communication Control Port (CCP). The NCP carries a common signaling channel, while the CCP carries a dedicated signaling channel of a cell. There is only one NCP and multiple CCPs in the system.
CP Port No.

Indicates the number of the Iub control port.
CPBear ID

Indicates the CP bearer ID.
Belong Flag

Indicates the flag of the transport channel to which an Iub control port belongs.
Table 3 Dynamic parameters

Parameter

Description
Port Status

Indicates the status of Iub control port. This parameter can be set to Normal or Fault.
