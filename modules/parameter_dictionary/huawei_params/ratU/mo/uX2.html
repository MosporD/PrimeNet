UX2

+-NE
  +-NODEBFUNCTION
    +-UX2

Description

The UX2 MO consists of parameters related to the transport resources used by the uX2 interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by CPEPGROUPID in a UX2 MO must be configured, and the APPTYPE value must be set to NULL.
    • The EPGROUP MO referenced by CPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO must reference an SCTPHOST MO.
    • The EPGROUP MO referenced by CPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can reference only one SCTPHOST MO whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by CPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can not reference the SCTPHOST MO whose IPVERSION is set to IPv6.
    • The EPGROUP MO referenced by CPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can not reference the SCTPPEER MO whose IPVERSION is set to IPv6.
    • The EPGROUP MO referenced by UPEPGROUPID in a UX2 MO must be configured, and the APPTYPE value must be set to NULL.
    • The EPGROUP MO referenced by UPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO must reference a USERPLANEHOST MO.
    • The EPGROUP MO referenced by UPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can reference only one USERPLANEHOST MO whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by UPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can not reference the USERPLANEHOST MO whose IPVERSION is set to IPv6.
    • The EPGROUP MO referenced by UPEPGROUPID in a UX2 MO must be configured, and this EPGROUP MO can not reference the USERPLANEPEER MO whose IPVERSION is set to IPv6.
  • Relation with the IUB MO:
    • UPEPGROUPID in any UX2 MO must be different from UPEPGROUPID in any IUB MO.
    • CPEPGROUPID in any UX2 MO must be different from UPEPGROUPID in any IUB MO.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description

Indicates the uX2 object ID.

Indicates the ID of the user-plane endpoint group used by the uX2 object.
uX2 Object Description

Indicates the uX2 object description.
Static Check Switch

Indicates whether to enable static UDP Ping detection over the uX2 interface. If this parameter is set to ON, static UDP Ping detection is enabled over the uX2 interface. If this parameter is set to OFF, static UDP Ping detection is disabled over the uX2 interface.
