NODEBOPTDYNADJPARA

+-NE
  +-NODEBFUNCTION
    +-NODEBOPTDYNADJPARA

Description

The NODEBOPTDYNADJPARA MO configures parameters related to dynamic voltage adjustment, such as Dynamic Voltage Adjustment Switch, Start Time, and End Time.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NODEBOPTDYNADJPARA

The command is used to list the parameters of the dynamic voltage adjustment function.
SET NODEBOPTDYNADJPARA

The command is used to set the switch, start time, and end time of the dynamic voltage adjustment function.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Dynamic Voltage Adjustment Switch

Indicates the dynamic voltage adjustment switch. When this switch is turned on, the dynamic voltage adjustment function is enabled and energy conservation is achieved.
Start Time

Indicates the time when the optimization algorithm for dynamic voltage adjustment starts working. This parameter is set on the hour. When the current time is later than this parameter, the dynamic voltage adjustment function takes effect.
End Time

Indicates the time when the optimization algorithm for dynamic voltage adjustment stops working. This parameter is set on the hour. When the current time is later than this parameter, the dynamic voltage adjustment function stops taking effect.
