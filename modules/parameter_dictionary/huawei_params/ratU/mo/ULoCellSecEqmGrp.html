ULOCELLSECEQMGRP

+-NE
  +-NODEBFUNCTION
    +-ULOCELL
      +-ULOCELLSECEQMGRP

Description

The ULOCELLSECEQMGRP MO configures sector equipment group parameters, such as Sector Equipment Group ID and SectorEqm Ref.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ULOCELL
  • Relation with the ULOCELL MO:
    • If LOCELLTYPE under the ULOCELL MO is set to MIXED_MULTIRRU_CELL, zero to twelve ULOCELLSECEQMGRP MOs are used.
    • The number of ULOCELLSECEQMGRP MOs is zero if the value of LOCELLTYPE under the ULOCELL MO is not MIXED_MULTIRRU_CELL.
    • If LOCELLTYPE under the ULOCELL MO is MIXED_MULTIRRU_CELL, the same SECTOREQM MO can only be configured in one ULOCELLSECEQMGRP MO under the ULOCELL MO.
  • Relation with the ULOCELLSECEQMGRP MO:
    • If LOCELLTYPE under the ULOCELL MO is set to MIXED_MULTIRRU_CELL, 0 to 16 SECTOREQM MOs corresponding to the ULOCELLSECEQMGRP MO are used.
  • Relation with the ULOCELL, ULOCELLSECTOREQM, and SECTOREQM MOs:
    • If LOCELLTYPE under the ULOCELL MO is set to MIXED_MULTIRRU_CELL, the SECTOREQM MOs configured in the ULOCELLSECEQMGRP MOs for the ULOCELL MO must exist in the ULOCELLSECTOREQM MOs.
  • Relation with the ULOCELL, ULOCELLSECTOREQM, BASEBANDEQM, SECTOREQM, and NODEBALGPARA MOs:
    • Assume that the sum of number of SECTOREQMs used by MULTIRRU_CELL, number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELL cells, and the number of DIST_CELL cells is x, and in the NORMAL_CELL and HALFFREQ_CELL cells, the number of ULOCELLs configured with less than four and greater than zero RX antennas is y, the number of ULOCELLs configured with four RX antennas is z, and the number of ULOCELL MOs, for which the used ULOCELLSECTOREQM MOs have SECTOREQMPROPERTY set to ASSISTANCE and different DLFREQ settings are used, is m. When ULRESWORKMODE under the NODEBALGPARA MO is set to NORMAL_EXTENSION and UMTSDEMMODE under the BASEBANDEQM MO is set to DEM_ADPT_CHAN, the sum of x, y, 2*z and m must be less than or equal to 12.
    • Assume that the sum of number of SECTOREQMs used by MULTIRRU_CELL, number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELL cells, and the number of DIST_CELL cells is x, and in the NORMAL_CELL and HALFFREQ_CELL cells, the number of ULOCELLs configured with less than four and greater than zero RX antennas is y, the number of ULOCELLs configured with four RX antennas is z, and the number of ULOCELL MOs, for which the used ULOCELLSECTOREQM MOs have SECTOREQMPROPERTY set to ASSISTANCE, ULFREQIND is set to TRUE, and different ULFREQ settings are used, is m. When ULRESWORKMODE under the NODEBALGPARA MO is set to NORMAL_EXTENSION and UMTSDEMMODE under the BASEBANDEQM MO is set to DEM_ADPT_CHAN, the sum of x, y, 2*z and m must be less than or equal to 12.
  • Relation with the BASEBANDEQM, ULOCELL, ULOCELLSECTOREQM, SECTOREQM, NODEBALGPARA, and BBP MOs:
    • When ULRESWORKMODE under the NODEBALGPARA MO is set to NORMAL_EXTENSION and UMTSDEMMODE under the BASEBANDEQM MO is set to DEM_2_CHAN, assume that x is the sum of the number of SECTOREQMs used by MULTIRRU_CELLs, the number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELLs, the number of NORMAL_CELLs, HALFFREQ_CELLs and DIST_CELLs, and y is the number of ULOCELLs for which the used ULOCELLSECTOREQM MOs have SECTOREQMPROPERTY set to ASSISTANCE, ULFREQIND is set to TRUE, and different ULFREQ settings are used. If the sum of x and y is greater than 6, the BASEBANDEQM MO must be configured with UBBP board on which UMTS must be selected for BBWS.
    • When UMTSDEMMODE under the BASEBANDEQM MO is set to DEM_2_CHAN and ULRESWORKMODE under the NODEBALGPARA MO is set to NORMAL_EXTENSION, assume that the sum of number of SECTOREQMs used by MULTIRRU_CELL cells, number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELL cells, and number of NORMAL_CELL, HALFFREQ_CELL and DIST_CELL cells is x, and the number of local cells, for which SECTOREQMPROPERTY of the used sector equipment is set to ASSISTANCE and frequency settings are different, is y. If the sum of x and y is greater than 6, the BASEBANDEQM MO must be configured with BBP MOs on which TYPE must be set to UBBP and UMTS must be selected for BBWS.
  • Relation with the ULOCELL, ULOCELLSECTOREQM, BASEBANDEQM, SECTOREQM, NODEBALGPARA, BEAMCELLGROUP, and BEAMCELLGROUPITEM MOs:
    • Assume that x is the sum of the number of SECTOREQMs used by MULTIRRU_CELLs, number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELLs, and the number of DIST_CELLs, y is the number of HALFFREQ_CELLs configured with a total of two or three RX antennas, z is the number of HALFFREQ_CELLs configured with four RX antennas, m is the number of NORMAL_CELLs with BFMODE set to MASSIVEBEAM, NORMALBEAM or COORDINATEDBEAM that are not configured in BEAMCELLGROUP MO, n and k are respectively the number of NORMAL_CELLs configured with a total of two or three RX antennas and that of NORMAL_CELLs configured with four RX antennas if BFMODE is set to NOTSUPPORT or FOURTXBEAMOPT and the NORMAL_CELLs are not configured in BEAMCELLGROUP MO, h and s are respectively the number of NORMAL_CELLs configured with four RX antennas and that of NORMAL_CELLs configured with eight RX antennas in BEAMCELLGROUP MO with BEAMCELLGROUPTYPE set to NORMALBEAM or FOURTXSPLITSECTOR, p is the number of NORMAL_CELLs that are added to the BEAMCELLGROUP MO with BEAMCELLGROUPTYPE set to NORMALBEAM and use the SECTOREQM MO whose ANTCFGMODE is set to BEAM, t is the number of BEAMCELLGROUP MOs that contain one NORMAL_CELL in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM8T8R, w is the number of BEAMCELLGROUP MOs that contain two NORMAL_CELLs in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM8T8R, r is the number of BEAMCELLGROUP MOs that contain one NORMAL_CELL in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM4T4R or COORDINATED2TBEAM, q is the number of BEAMCELLGROUP MOs that contain two NORMAL_CELLs in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM4T4R or COORDINATED2TBEAM, and g is the number of ULOCELLs for which the used ULOCELLSECTOREQM MOs have SECTOREQMPROPERTY set to ASSISTANCE and different DLFREQ settings are used. When UMTSDEMMODE under the BASEBANDEQM MO is set to DEM_ADPT_CHAN and ULRESWORKMODE under the NODEBALGPARA MO is set to NORMAL, the sum of x, y, 2 multiplied by z, m, n, 2 multiplied by k, 2 multiplied by h, 4 multiplied by s, 2 multiplied by p, t, 4 multiplied by w, r, 2 multiplied by q, and g must be less than or equal to 12.
    • Assume that x is the sum of the number of SECTOREQMs used by MULTIRRU_CELLs, number of ULOCELLSECEQMGRPs used by MIXED_MULTIRRU_CELLs, and the number of DIST_CELLs, y is the number of HALFFREQ_CELLs configured with a total of two or three RX antennas, z is the number of HALFFREQ_CELLs configured with four RX antennas, m is the number of NORMAL_CELLs with BFMODE set to MASSIVEBEAM, NORMALBEAM or COORDINATEDBEAM that are not configured in BEAMCELLGROUP MO, n and k are respectively the number of NORMAL_CELLs configured with a total of two or three RX antennas and that of NORMAL_CELLs configured with four RX antennas if BFMODE is set to NOTSUPPORT or FOURTXBEAMOPT and the NORMAL_CELLs are not configured in BEAMCELLGROUP MO, h and s are respectively the number of NORMAL_CELLs configured with four RX antennas and that of NORMAL_CELLs configured with eight RX antennas in BEAMCELLGROUP MO with BEAMCELLGROUPTYPE set to NORMALBEAM or FOURTXSPLITSECTOR, p is the number of NORMAL_CELLs that are added to the BEAMCELLGROUP MO with BEAMCELLGROUPTYPE set to NORMALBEAM and use the SECTOREQM MO whose ANTCFGMODE is set to BEAM, t is the number of BEAMCELLGROUP MOs that contain one NORMAL_CELL in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM8T8R, w is the number of BEAMCELLGROUP MOs that contain two NORMAL_CELLs in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM8T8R, r is the number of BEAMCELLGROUP MOs that contain one NORMAL_CELL in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM4T4R or COORDINATED2TBEAM, q is the number of BEAMCELLGROUP MOs that contain two NORMAL_CELLs in the BASEBANDEQM MO and have BEAMCELLGROUPTYPE set to MASSIVEBEAM4T4R or COORDINATED2TBEAM, and g is the number of ULOCELLs for which the used ULOCELLSECTOREQM MOs have SECTOREQMPROPERTY set to ASSISTANCE, ULFREQIND is set to TRUE, and different ULFREQ settings are used. Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ULOCELLSECTOREQMGRP

This command is used to add sector equipment groups. Sector equipment groups were introduced for the "Mixed Multiple RRUs In One Cell" sector. Similar to each RRU in the Multi-RRU independent demodulation cell, data of each sector equipment group is processed on the baseband side. That is, all RRUs in the same sector equipment group and their data are allocated the same baseband resources and channel resources.
ADD ULOCELLSECTOREQMGRPITEM

This command is used to add sector equipment to a specified sector equipment group.
LST ULOCELLSECTOREQMGRP

This command is used to query the configuration information of a sector equipment group.
LST ULOCELLSECTOREQMGRPITEM

This command is used to query the configuration information of the sector equipment in the sector equipment group of a cell.
RMV ULOCELLSECTOREQMGRP

This command is used to remove a specified sector equipment group.
RMV ULOCELLSECTOREQMGRPITEM

This command is used to remove specified sector equipment from a sector equipment group.
