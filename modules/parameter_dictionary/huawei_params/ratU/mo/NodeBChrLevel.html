NODEBCHRLEVEL

+-NE
  +-NODEBFUNCTION
    +-NODEBCHRLEVEL

Description

The NODEBCHRLEVEL MO configures the level of details of the CHR, the type of user involved in the CHR, and the type of cell-level CHR logs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP NODEBCHRLEVEL

Use this command to query effective CHR events.
LST NODEBCHRLEVEL

The command is used to query the setting of CHR information level.
SET NODEBCHRLEVEL

The command is used to set the information level of CHR data and CHR user type.
