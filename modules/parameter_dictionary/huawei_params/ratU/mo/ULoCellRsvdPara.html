ULOCELLRSVDPARA

+-NE
  +-NODEBFUNCTION
    +-ULOCELL
      +-ULOCELLRSVDPARA

Description

The ULOCELLRSVDPARA MO configures local cell-level reserved parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ULOCELL

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ULOCELLRSVDPARA

This command queries the field reserved for the local cell.
SET ULOCELLRSVDPARA

This command sets the reserved field for the local cell. The reserved field is used as the switch for a feature added in the future.This command requires support from the patch to be applied. If the patch contains a new feature, the reserved field can be used to determine whether to use the new feature.
