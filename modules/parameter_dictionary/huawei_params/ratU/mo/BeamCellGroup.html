BEAMCELLGROUP

+-NE
  +-NODEBFUNCTION
    +-BEAMCELLGROUP
      +-BEAMCELLGROUPITEM[0~8]

Description

The BEAMCELLGROUP MO configures beam cell group parameters, including Beam Cell Group ID, Beam Cell Group Type and Beam Option Period.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BEAMCELLGROUPQUICK

This command is used to add beam cell group. After this command is executed, configuration information of beam cell group items for the beam cell group is automatically added.

This command is used to list the configurations of beam cell group.
MOD BEAMCELLGROUP

This command is used to modify the configurations of beam cell group.
RMV BEAMCELLGROUP

This command is used to delete beam cell group.
