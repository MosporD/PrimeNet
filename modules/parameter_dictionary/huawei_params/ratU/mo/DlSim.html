DLSIM

Description

The DLSIM MO defines simulation test results of downlink network load in the local cell.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP DLSIM

The command is used to display the current load ratio of downlink network load simulation of a specified local cell or all local cells.
MOD DLSIM

The command is used to modify the load radio of downlink network load simulation of a specified local cell or all local cells.

After starting the DL load simulation, if the load radio is not suitable, use this command to modify the load radio.
STP DLSIM

The command is used to stop the downlink network load simulation of a specified local cell or all local cells.
STR DLSIM

The command is used to start the downlink network load simulation of a specified local cell or all local cells.

It is mainly used in the incipient period of the network to test the performance of the network.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
Simulating Load Ratio

Indicates the load rate of analog channels after analog load is enabled.
Common Channel Load Ratio

Indicates the load rate of common channels.
Service Load Ratio

Indicates the load rate of actual traffic channels (dedicated channels) except common channels and analog channels.
Configured Load Ratio

Indicates the configured load rate after analog load is enabled.
Cause

Indicates the cause of failure.
