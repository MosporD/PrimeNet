NODEBMULTICELLGRP

+-NE
  +-NODEBFUNCTION
    +-NODEBMULTICELLGRP

Description

The NODEBMULTICELLGRP MO configures multicarrier cell group parameters, such as Multiple Carrier Cell Group ID, Multiple Carrier Cell Group Type, and Local Cell ID.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the NODEBFUNCTION MO:
    • The NODEBFUNCTION MO associated with the NODEBMULTICELLGRP MO must have been configured.
  • Relation with the NODEBMULTICELLGRP MO:
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is set to HSUPA, the local cell must be unique.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is set to HSUPA, it is configured with at most two local cells.
  • Relation with the ULOCELL MO:
    • The ULOCELL in NODEBMULTICELLGRP MO must be configured.
    • When MULTICELLGRPTYPE is set to HSUPA, local cells in a group must exist in NODEBMULTICELLGRP with MULTICELLGRPTYPE set to HSDPA, or local cells must exist in NODEBMULTICELLGRP with MULTICELLGRPTYPE set to HSUPA. In this way, local cells cannot be removed from NODEBMULTICELLGRP with MULTICELLGRPTYPE set to HSDPA.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is set to HSDPA, the number of DLFREQ for local cells under the NODEBMULTICELLGRP MO can not be greater than 4.
    • The ULOCELL MO under which CELLSCALEIND is MACRO can be associated with a maximum of three NODEBMULTICELLGRP MOs under which MULTICELLGRPTYPE is HSDPA.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is set to HSDPA, all ULOCELL in the NODEBMULTICELLGRP must belong to one DLBASEBANDEQMID.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is HSDPA and CELLSCALEIND of local cells under the NODEBMULTICELLGRP MO is only set to MACRO, DLFREQ of local cells must be unique.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is HSDPA and CELLSCALEIND of local cells under the NODEBMULTICELLGRP MO is set to both MACRO and MICRO, DLFREQ of local cells whose CELLSCALEIND is MACRO must be unique.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is HSDPA and CELLSCALEIND of local cells under the NODEBMULTICELLGRP MO is set to both MACRO and MICRO, DLFREQ of local cells whose CELLSCALEIND is MICRO must be the same.
    • If MULTICELLGRPTYPE under the NODEBMULTICELLGRP MO is HSDPA and CELLSCALEIND of local cells under the NODEBMULTICELLGRP MO is only set to MICRO, DLFREQ of local cells under the NODEBMULTICELLGRP MO must be unique or the same.
    • The ULOCELL MO under which CELLSCALEIND is MICRO can be associated with one or no NODEBMULTICELLGRP MO under which MULTICELLGRPTYPE is HSDPA.
    • The narrowband carrier cell and the neighboring frequency cell in a cell pair cannot be configured in the same NODEBMULTICELLGRP.
    • When the MULTICELLGRPTYPE parameter in the NODEBMULTICELLGRP MO is set to HSUPA, the number of local cells in the NODEBMULTICELLGRP MO with the DCHSDPASHAREDWITHGSM parameter set to a value other than NOTSUPPORT is 0.
    • If MULTICELLGRPTYPE in a NODEBMULTICELLGRP MO is set to HSDPA, in the NODEBMULTICELLGRP MO, the number of ULOCELL MOs with DCHSDPASHAREDWITHGSM set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHLTE set to a value other than NOTSUPPORT, or UU0DCHSDPA set to TRUE must be less than or equal to 1.
    • When the MULTICELLGRPTYPE parameter in the NODEBMULTICELLGRP MO is set to HSUPA, the number of local cells in the NODEBMULTICELLGRP MO with the DCHSDPASHAREDWITHLTE parameter set to a value other than NOTSUPPORT is 0.
    • If MULTICELLGRPTYPE in a NODEBMULTICELLGRP MO is set to HSUPA, the value of UU0DCHSDPA under each ULOCELL MO configured in the NODEBMULTICELLGRP MO must be set to FALSE.
  • Relation with the ULOCELL and NODEBEXSECCELLGRP MOs:
    • For a ULOCELL MO, the total number of peer ULOCELL MOs in the NODEBMULTICELLGRP under which MULTICELLGRPTYPE is HSDPA and peer ULOCELL MOs in the NODEBEXSECCELLGRP cannot be greater than 5.
    • For a ULOCELL MO, the total number of peer ULOCELL MOs in the NODEBMULTICELLGRP under which MULTICELLGRPTYPE is HSDPA and peer ULOCELL MOs in the NODEBEXSECCELLGRP cannot be greater than 5.
  • Relation with the NODEBEXSECCELLGRP MO:
    • The ULOCELLID under the NODEBEXSECCELLGRP MO must have been configured in a NODEBMULTICELLGRP MO under which MULTICELLGRPTYPE is HSDPA.
    • The ULOCELLID and EXSECULOCELLID under a NODEBEXSECCELLGRP MO cannot be configured in the same NODEBMULTICELLGRP MO under which MULTICELLGRPTYPE is HSDPA.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NODEBMULTICELLGRP

The command is used to add multiple carrier cell group.
ADD NODEBMULTICELLGRPITEM

The command is used to add local cell to multiple carrier cell group.
LST NODEBMULTICELLGRP

The command is used to list multiple carrier cell group.
LST NODEBMULTICELLGRPITEM

The command is used to list local cells of multiple carrier cell group.
RMV NODEBMULTICELLGRP

The command is used to delete multiple carrier cell group.
RMV NODEBMULTICELLGRPITEM

The command is used to delete multiple carrier cell from multiple carrier cell group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Multiple Carrier Cell Group ID

Uniquely identifies a multiple carrier cell group.
Multiple Carrier Cell Group Type

Specifies the type of a multiple carrier cell group.
Local Cell Ref

Indicates the list of local cells in the multi-carrier cell group.
