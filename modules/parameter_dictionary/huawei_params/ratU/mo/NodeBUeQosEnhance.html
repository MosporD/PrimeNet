NODEBUEQOSENHANCE

+-NE
  +-NODEBFUNCTION
    +-NODEBUEQOSENHANCE

Description

The NODEBUEQOSENHANCE MO configures uplink and downlink burst packet thresholds of users at different priorities, such as UL Gold UE Burst Packet Size, UL Silver UE Burst Packet Size, UL Copper UE Burst Packet Size, DL Gold UE Burst Packet Size, DL Silver UE Burst Packet Size, and DL Copper UE Burst Packet Size.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NODEBUEQOSENHANCE

The command is used to query the burst packet size of gold, silver, and copper UEs and parameter settings of the enhancement of the Improvement of User Experience in Low Traffic Service feature.
SET NODEBUEQOSENHANCE

The command is used to set parameters for the Improvement of User Experience in Low Traffic Service feature and the enhancement of the feature. This command can be used to set the burst packet size of UEs with different priorities, that is, the low-traffic data identification threshold. The UE priorities are gold, silver, and copper. For a UE with a certain priority, if the total data traffic is less than the set value within a statistic period, the resources assignment (scheduling and flow control) mechanism transmits the low-traffic data preferentially to optimize the delay.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UL Gold UE Burst Packet Size

Indicates the burst packet size of UL gold UE.
UL Silver UE Burst Packet Size

Indicates the burst packet size of UL silver UE.
UL Copper UE Burst Packet Size

Indicates the burst packet size of UL copper UE.
DL Gold UE Burst Packet Size

Indicates the burst packet size of DL gold UE.
DL Silver UE Burst Packet Size

Indicates the burst packet size of DL silver UE.
DL Copper UE Burst Packet Size

Indicates the burst packet size of DL copper UE.
UPA User Number Threshold for Enhanced Low Traffic

Indicates the UPA UE quantity threshold for the low-traffic experience enhancement function to take effect. When the number of UPA UEs in a cell is less than or equal to the threshold, the low-traffic experience enhancement function takes effect. When the number of UPA UEs in a cell is greater than the threshold or the threshold is set to 0, the low-traffic experience enhancement function does not take effect.
Max UPA 10ms TTI TB Size for Enhanced Low Traffic

Indicates the maximum TB size for scheduling grant of UPA 10 ms TTI UEs when the low-traffic experience enhancement function takes effect.
Max UPA 2ms TTI TB Size for Enhanced Low Traffic

Indicates the maximum TB size for scheduling grant of UPA 2 ms TTI UEs when the low-traffic experience enhancement function takes effect.
