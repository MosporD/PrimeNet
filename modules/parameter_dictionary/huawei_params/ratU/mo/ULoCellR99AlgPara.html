ULOCELLR99ALGPARA

+-NE
  +-NODEBFUNCTION
    +-ULOCELL
      +-ULOCELLR99ALGPARA

Description

The ULOCELLR99ALGPARA MO configures the power congestion admission control switch and power congestion-based control algorithm parameters, such as Power Congestion Call Admission Control Switch, Short Threshold, Long Threshold, and Short Threshold for RT RRC.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the Local Cell ID.
Power Congestion Call Admission Control Switch

Indicates the power congestion admission switch. It controls whether the power congestion-based E2E flow control algorithm takes effect. When this switch is turned on, this can prevent downlink power congestion caused by frequent RRC setup. In this way, the downlink performance does not quickly deteriorate, and RRC connections in progress do not experience low procedure success rates. During non-peak hours, the RRC setup success rate may decrease, but the probability of this is low.
Short Threshold

Indicates the short-term decision threshold for the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink transmitted carrier power (TCP) on the NodeB is congested corresponding to the RRC connections of non-real-time services.
Long Threshold

Indicates the long-term decision threshold for the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink non-HSPA TCP on the NodeB is congested.
Short Threshold for RT RRC

Indicates the short-term decision threshold for RRC connections of real-time services of the power congestion-based E2E flow control algorithm. When this algorithm takes effect, this parameter is used to check whether the downlink TCP on the NodeB is congested corresponding to the RRC connections of real-time services.
