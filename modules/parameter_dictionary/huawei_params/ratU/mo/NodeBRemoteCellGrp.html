NODEBREMOTECELLGRP

+-NE
  +-NODEBFUNCTION
    +-NODEBREMOTECELLGRP

Description

The NODEBREMOTECELLGRP MO configures remote cell group parameters, such as Remote Cell Group No. and Remote Cell Group Name.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NODEBFUNCTION
  • Relation with the ULOCELL MO:
    • At most three ULOCELL MOs are configured under the same NODEBREMOTECELLGRP MO.
    • NODEBREMOTECELLGRP MOs associated with the ULOCELL MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NODEBREMOTECELLGRP

The command is used to add a resource group of remote coverage cells.
LST NODEBREMOTECELLGRP

The command is used to list the properties of the resource group of remote coverage cells, including group number and group name.
MOD NODEBREMOTECELLGRP

The command is used to modify the name of the resource group of remote coverage cells.
RMV NODEBREMOTECELLGRP

The command is used to delete a resource group of remote coverage cells.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Remote Cell Group No.

Indicates the number of the resource group of remote coverage cells.
Remote Cell Group Name

Indicates the name of the resource group of remote coverage cells.
