UX2INTERFACE

Description

The UX2INTERFACE MO specifies the uX2 interface used for interconnection between NodeBs and the support of inter-site service coordination.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP UX2INTERFACE

Use this command to query uX2 interface information.
DSP UX2UPINFO

Use this command to query the user-plane information about the uX2 interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
uX2 Interface CP Bearer ID

Indicates the control-plane bearer ID of the uX2 interface.
Peer RNC ID

Indicates the ID of the peer RNC for the uX2 interface.
Peer NodeB ID

Indicates the ID of the peer NodeB for the uX2 interface.
uX2 Interface State

Indicates the status of the uX2 interface.
Abnormal Cause

Indicates the reason why the uX2 interface becomes abnormal.
uX2 User Plane Host IP Address

Indicates the IP Address of the user-plane host of the uX2 interface.
uX2 User Plane Peer IP Address

Indicates the IP Address of the user-plane peer of the uX2 interface.
uX2 User Plane Link State

Indicates the user-plane link status of the uX2 interface. The value Abnormal means that the user-plane link is disconnected. The value Normal means that the user-plane link is connected. The value Unknown means that the user-plane link status information cannot be obtained.
uX2 UP Link Delay

Indicates the user-plane Round-Trip Time (RTT) of the uX2 interface.
uX2 UP Link One-way Delay

Indicates the one-way delay on the uX2 user-plane link.
