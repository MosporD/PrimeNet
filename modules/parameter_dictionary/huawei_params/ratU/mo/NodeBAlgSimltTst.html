NODEBALGSIMLTTST

Description

The NODEBALGSIMLTTST MO consists of the baseband loopback test result and the number of detected preambles, sector equipment-level RTWP measurement result of a LampSite base station, and cell antenna port co-polarization detection.

Effective Scenario

Immediately

Relations Between MOs

None

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP UCOPOLARPORTDET

Use this command to query the cell antenna port co-polarization detection result.
DSP UPHASECALIBCHK

Use this command to query the phase calibration capability detection result.
STP LOCELLRTWPREPORT

This command is used to disable the sector-equipment-level RTWP subscription function on LampSite base stations.
STP UCOPOLARPORTDET

Use this command to stop the antenna port co-polarization detection function for all cells.
STR LOCELLRTWPREPORT

This command is used to enable the sector-equipment-level RTWP subscription function on LampSite base stations. This function is used to generate RTWP statistics for sector-equipment-level fault isolation.
STR NODEBALGSIMLTTST

The command is used to start algorithm simulation tests for fault isolation.
STR UCOPOLARPORTDET

Use this command to start the antenna port co-polarization detection function for a cell. If the detection result is consistent with the co-polarization port mapping on the RF channels, the UMTS 4T Beam Optimization feature will deliver normal performance gains.
STR UPHASECALIBCHK

Use this command to enable the phase calibration capability detection function.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Dynamic parameters

Parameter

Description
Baseband Loopback Test Result

Indicates the result of a baseband loopback test.
Number of Preambles Detected in a Test

Indicates the number of preambles that are detected in an RF loopback test.
Co-Polarization Port Detection Completion Status

Indicates the completion status of co-polarization detection for the entire NodeB. Value NULL indicates that the NodeB has not started co-polarization detection. Value Incompleted indicates that the NodeB has not completed co-polarization detection. Value Completed indicates that the NodeB has completed co-polarization detection.
Cell Co-Polarization Port Detection Result

Indicates the antenna port co-polarization detection result for a cell. Value NULL indicates that co-polarization detection has not been executed for the cell. Value Completed indicates that the co-polarization detection result is valid for the cell. Value Detecting indicates that co-polarization detection is in progress for the cell. Value Not Supported indicates that co-polarization detection cannot be performed for the cell due to inappropriate configuration. Value Task Interrupt indicates that co-polarization detection is interrupted due to other tasks with higher priorities. Value Time Out indicates that co-polarization detection times out. That is, co-polarization detection is still in the incomplete state and no command is executed to stop the detection after the detection has been running for 24 hours.
Cell Co-Polarization Port Mapping

Indicates the co-polarization grouping of antenna ports on the RF channels. In scenarios with a 4T RF module, antenna ports 0, 1, 2, and 3 map RF channels A, B, C, and D. In scenarios with dual-RF module combination of 2T, antenna ports 0, 1, 2, and 3 map RF channels A, B, A, and B. Value 4T4P_abcd indicates that a cell has four TX channels and four antenna ports (a, b, c, and d) with signals of a and c and those of b and d separately belonging to a co-polarization group. For example, value 4T4P_0132 indicates that signals of antenna ports 0 and 3 and those of antenna ports 1 and 2 separately belong to a co-polarization group. Value NULL indicates invalid detection.
Cabinet No.

Indicates the cabinet number of the RF module used by the RX link.
Subrack No.

Indicates the subrack number of the RF module used by the RX link.
Slot No.

Indicates the slot number of the RF module used by the RX link.
Cell Phase Calibration Capability Detection Status

Indicates the detection result of the cell phase calibration capability. Undetected indicates that the cell has not started phase calibration capability detection. Detecting indicates that the cell phase calibration capability detection is in progress. Failed indicates that the cell phase calibration capability detection fails. Succeeded indicates that the cell phase calibration capability detection succeeds.
