Meaning

Indicates the algorithm for Downlink Adaptive Band-Pass Filter. When this parameter is set to NOTSUPPORT, the UMTS cell downlink adaptive band-pass filter is disabled. When this parameter is set to STATICBANDWIDTH, the UMTS cell downlink adaptive band-pass filter bandwidth remains unchanged. When this parameter is set to DYNAMICBANDWIDTH, the UMTS cell downlink adaptive band-pass filter bandwidth dynamically adapts to the GSM services. When this parameter is set to FIXEDBANDWIDTH, the 3.8 MHz downlink adaptive band-pass filter is used in the UMTS cell, requiring no bandwidth adjustment based on GSM services.

Parameter Relationship

-Configuration constraints:

  • In the ULOCELL MO, if RMTCM is set to TRUE or the value of RADIUS is greater than 30 km, DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if FDEMODE is set to TRUE, DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if TTW is set to TRUE, DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if INTEL2TVAM is set to TRUE, DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of BFMODE is set to MASSIVEBEAM or NORMALBEAM, the value of DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if DLADAPTIVEBPFILTER is set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if DLADAPTIVEBPFILTER is set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHLTE must be set to NOTSUPPORT.
  • In the ULOCELL MO, DLADAPTIVEBPFILTER cannot be set to FIXEDBANDWIDTH if any of the conditions is met: (1) ULSUPERNARROWBANDFILTER is not set to NOTSUPPORT. (2) GSMQLBASEDROTDYNACTRL is set to TRUE. (3) Values of GU5MHZPERFOPT contain ULADAPTIVEBPFILTER or DLADAPTIVEBPFILTERPERFEOPT. (4) GUBUFZONECELLTYPE is not set to NOTBUFZONECELL. (5) ULSPECTRUMSHARINGSWITCH is not set to NOTSUPPORT. (6) UL0BUFFERZONE is set to TRUE. (7) ULSPECTRUMSHARINGPHASE2 is set to TRUE.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to DIST_CELL, MULTIRRU_CELL, NORMAL_CELL, DLADAPTIVEBPFILTER is valid.

-Others:

  • When DLADAPTIVEBPFILTER is set to FIXEDBANDWIDTH in the ULOCELL MO, 3800 is used as the value of FREQUENCYBANDWIDTH. The bandwidth value configured in the SET FREQBWH command cannot be greater than the value of FREQUENCYBANDWIDTH.
  • When Subrack Type is set to BBU3910C, this parameter is valid only if its value is FIXEDBANDWIDTH.

Impact on Radio Network Performance

When this parameter is set to NOTSUPPORT, Downlink Adaptive Band-Pass Filter does not take effect. When this parameter is set to STATICBANDWIDTH, the cell downlink signal bandwidth is set to a fixed value. The more GSM frequencies need to be filtered out on the NodeB, the lower the UMTS downlink throughput. When this parameter is set to DYNAMICBANDWIDTH, the cell downlink signal bandwidth changes dynamically based on the GSM service activation status. If the number of GSM frequencies filtered on the NodeB remains unchanged, a lower GSM service activation rate allows higher UMTS downlink throughput. When this parameter is set to FIXEDBANDWIDTH, the 3.8 MHz downlink signal spectrum is used in the cell, delivering stable UMTS performance that is slightly affected by GSM services.
