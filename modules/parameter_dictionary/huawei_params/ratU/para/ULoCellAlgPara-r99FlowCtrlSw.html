Parameter Name

MML Command

SET ULOCELLR99FLOWCTRL

Meaning

Indicates the R99 Flow Control Function Switch. The function will be enabled if this parameter is set to OPEN. The function will be disabled if this parameter is set to CLOSE.

Impact on Radio Network Performance

When this switch is set to OPEN, the NodeB also performs flow control on uplink BE services carried on R99. As a result, R99 rates are affected, the packet loss rate may increase, and the service rates may decrease.
