Meaning

Indicates the length of the SFDC MAC-ehs discard timer, which defines the maximum duration within which an MAC-d PDU of the inter-NodeB SFDC-HSDPA service is transmitted after it is added to an MAC-ehs queue. If the timer expires, the MAC-d PDU will be discarded. Otherwise, the MAC-d PDU will be blocked in a NodeB, which causing a UE to receive an incorrect PDU at the RLC layer. For details about this parameter, see 3GPP TS 25.321.

Impact on Radio Network Performance

Parameter settings depend on the air interface capability in soft handover area of inter-NodeB SFDC-HSDPA UEs and traffic model. A large value of this parameter indicates a high probability that a UE receives an incorrect PDU at the RLC layer caused by data congestion in the MAC-ehs queue during high-speed transmission. A small value of this parameter indicates a high probability that the MAC-d PDU in a NodeB buffer is mistakenly discarded.
