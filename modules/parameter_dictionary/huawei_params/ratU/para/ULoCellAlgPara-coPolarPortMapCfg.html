Meaning

Indicates the co-polarization mapping configuration of antenna ports onto the RF channels in a cell. Value 4T4P_abcd indicates that a cell has four TX channels and four antenna ports (a, b, c, and d) with signals of a and c and those of b and d separately belonging to a co-polarization group. For example value 4T4P_0132 indicates that signals of antenna ports 0 and 3 and those of antenna ports 1 and 2 separately belong to a co-polarization group. This parameter takes effect only in scenarios with a single 4T RF module but not in scenarios with dual-RF module combination of 2T.

Impact on Radio Network Performance

The co-polarization port mapping configuration must be consistent with the actual co-polarization grouping to deliver normal performance gains for the UMTS 4T Beam Optimization feature. In the event of inconsistency, this feature cannot deliver expected performance gains. Modifying this parameter may cause transient and abrupt changes in cell coverage, causing call drops to some extent.
