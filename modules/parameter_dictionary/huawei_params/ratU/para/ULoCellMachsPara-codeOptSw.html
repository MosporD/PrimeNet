Meaning

Indicates the switch for code utilization optimization. If this switch is turned on, the HSDPA code utilization rate increases but the power usage decreases. If this switch is turned off, code utilization optimization does not take effect.

Impact on Radio Network Performance

During trade-off between power and code resource allocation, turning on this switch increases the code utilization rate and reduces the downlink load when the data source of users in a cell is insufficient and there are remaining downlink air interface resources (including power and code resources). As a result, interference to downlink channels decreases, which improves user experience. If this switch is turned off, code utilization optimization does not take effect. If the code utilization rate in cells is higher than 70% on average during peak hours and each cell is allocated not more than 10 codes due to limited license capacity, it is good practice to perform code expansion before turning on this switch.
