Meaning

Whether the Intelligent 2T VAM feature is supported by the cell. When this parameter is set to TRUE, the cell supports Intelligent 2T VAM. When this parameter is set to FALSE, the cell does not support Intelligent 2T VAM. Based on the quick phase adjustment capability of the baseband VAM, the Intelligent 2T VAM feature enables the NodeB to match the best phase difference for each user when they are being scheduled, improving use experience. Baseband VAM refers to virtual antenna mapping (VAM) implemented on the baseband.

Parameter Relationship

-Configuration constraints:

  • In the ULOCELL MO, if INTEL2TVAM is set to TRUE, DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL, INTEL2TVAM and DLASYMFILTER cannot be both set to TRUE.
  • In the ULOCELL, if INTEL2TVAM is TRUE, the values of GU5MHZPERFOPT cannot contain DLADAPTIVEBPFILTERPERFEOPT.
  • In the ULOCELL MO, if the value of INTEL2TVAM is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE, INTEL2TVAM must be FALSE.
  • In the ULOCELL MO, if INTEL2TVAM is set to TRUE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, INTEL2TVAM must be FALSE.
  • In the ULOCELL MO, if INTEL2TVAM is set to TRUE, DCHSDPASHAREDWITHLTE must be set to NOTSUPPORT.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to NORMAL_CELL, INTEL2TVAM is valid.
