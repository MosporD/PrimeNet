Caution

Before setting this parameter to AIR, ensure that the number of cells configured on the baseband equipment does not exceed the maximum number of cells allowed when the working mode of the baseband equipment is set to AIR. Modifying this parameter will cause call drops. Therefore, modify this parameter when traffic is light.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If this parameter is set to AIR and the Adaptive Interference Rejection parameter is set to TRUE for a cell, uplink coverage in cells configured on the baseband equipment improves in the event of strong wideband interference. Changes in the parameter value will lead to call drops.
