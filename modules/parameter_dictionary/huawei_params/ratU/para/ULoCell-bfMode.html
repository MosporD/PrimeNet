Meaning

Indicates the beamforming mode. Value NOTSUPPORT indicates that the cell does not support beamforming on the baseband processing unit. Value MASSIVEBEAM indicates that the cell is enabled with beamforming on the baseband processing unit and supports the UMTS Massive Beam 4T4R or UMTS Massive Beam 8T8R capability. Value NORMALBEAM indicates that the cell supports the normal beamforming capability on the baseband processing unit. Value FOURTXBEAMOPT indicates that the cell supports the UMTS 4T Beam Optimization capability. Value COORDINATEDBEAM indicates that the cell supports the 2T Coordinated Beaforming capability. If this parameter is set to NORMALBEAM, MASSIVEBEAM, or COORDINATEDBEAM, the ring topology for RF modules is not supported. With the hot-backup ring topology, the local cell is unavailable if downlink RF signal combination is used for two Massive Beam cells.

Parameter Relationship

-Configuration constraints:

  • In the ULOCELL MO, if the value of VAM is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of TTW is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of INTEL2TVAM is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of BFMODE is set to MASSIVEBEAM or NORMALBEAM, the value of ULSUPERNARROWBANDFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of BFMODE is set to MASSIVEBEAM or NORMALBEAM, the value of DLADAPTIVEBPFILTER must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of BFMODE is set to MASSIVEBEAM or NORMALBEAM, the value of GSMQLBASEDROTDYNACTRL must be FALSE.
  • In the ULOCELL MO, if the value of DLASYMFILTER is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if the value of AIR is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • If the value of ULPOWERSHARE is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • If the value of BFMODE under the ULOCELL MO is set to MASSIVEBEAM or NORMALBEAM, the value of GUBUFZONECELLTYPE must be NOTBUFZONECELL.
  • If the value of BFMODE under the ULOCELL MO is set to MASSIVEBEAM or NORMALBEAM, the value of GU5MHZPERFOPT cannot contain ULADAPTIVEBPFILTER or DLADAPTIVEBPFILTERPERFEOPT.
  • In the ULOCELL MO, if UL0BUFFERZONE is set to TRUE and UL0BUFFERZONEFILTER is set to ULADAPTIVEFILTER, BFMODE must be set to NOTSUPPORT, FOURTXBEAMOPT, or COORDINATEDBEAM.
  • In the ULOCELL MO, if BFMODE is set to MASSIVEBEAM or NORMALBEAM, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if BFMODE is set to MASSIVEBEAM or NORMALBEAM, DCHSDPASHAREDWITHLTE must be set to NOTSUPPORT.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to NORMAL_CELL, BFMODE is valid.

-Others:

  • This parameter is invalid if Subrack Type is set to BBU3910C.
