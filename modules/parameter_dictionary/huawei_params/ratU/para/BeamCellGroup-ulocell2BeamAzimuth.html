Beam Azimuth for Local Cell 2

MO BEAMCELLGROUP
Parameter ID ULOCELL2BEAMAZIMUTH
Parameter Name

Beam Azimuth for Local Cell 2
NE

BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA
MML Command

ADD BEAMCELLGROUPQUICK
Meaning

Indicates the beam azimuth of local cell 2 in a beam cell group. When this parameter is set to LEFT(left), the cell coverage direction is relatively left to the beam azimuth of the antennas, and the cell can only select the four predefined left beams in Massive Beam 8T8R scenarios and use the left beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to RIGHT(Right), the cell coverage direction is relatively right to the beam azimuth of the antennas, and the cell can only select the four predefined right beams in Massive Beam 8T8R scenarios and use the right beam of two predefined beams in Massive Beam 4T4R scenarios. When this parameter is set to NONE(None), the cell coverage direction is unrestricted.

Impact on Radio Network Performance

The setting of this parameter must be consistent with the network planning. Any inconsistency will negatively affect the cell coverage area and scrambling code setting, leading to user access failures, increasing the call drop rate, decreasing the handover success rate, and increasing inter-cell interference.
