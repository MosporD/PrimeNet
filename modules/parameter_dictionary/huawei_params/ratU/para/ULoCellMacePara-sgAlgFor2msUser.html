NE

MML Command

SET ULOCELLMACEPARA

LST ULOCELLMACEPARA
Meaning

Indicates the minimum SG that the SG reclaiming algorithm uses during the data transmission of HSUPA 2 ms TTI users. When this parameter is set to SGALGFIRSTFOR2MSUSER, the minimum SG during data transmission of HSUPA 2 ms TTI users is three RLC PDUs. When this parameter is set to SGALGSECONDFOR2MSUSER, the minimum SG during data transmission of HSUPA 2 ms TTI users is one RLC PDU.

Impact on Radio Network Performance

When this parameter is set to SGALGFIRSTFOR2MSUSER, the minimum SG for HSUPA 2 ms TTI users is three RLC PDUs during data transmission, which decreases the access delay and improves the user throughput. However, the BLER of HSUPA 2 ms TTI users slightly increases and the value of VS.MeanRTWP increases. When this parameter is set to SGALGSECONDFOR2MSUSER, the minimum SG for HSUPA 2 ms TTI users is one RLC PDU during data transmission. This decreases the BLER of HSUPA 2 ms TTI users and the value of VS.MeanRTWP, but affects the access delay and throughput of HSUPA 2 ms TTI users.
