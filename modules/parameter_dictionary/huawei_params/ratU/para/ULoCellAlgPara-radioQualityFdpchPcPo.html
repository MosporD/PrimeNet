Meaning

Indicates the offset added to the maximum transmit power of the F-DPCH after the power adjustment by using the F-DPCH power control algorithm based on radio quality. Relationship between the GUI value and actual value: Actual value = (GUI value - 50) x 0.1.

Impact on Radio Network Performance

A larger value of this parameter indicates a higher transmit power allowed for the F-DPCH and a less probability of conserving downlink non-HSPA power, causing decrease in HSDPA throughput. A smaller value of this parameter indicates a lower transmit power allowed for the F-DPCH and a higher probability of conserving downlink non-HSPA power. This improves HSDPA throughput but causes more PS call drops.
