Soft Fault Self-healing Switch

MO NODEBALGPARA
Parameter ID SFSSWITCH
Parameter Name

Soft Fault Self-healing Switch
NE

BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA
MML Command

SET NODEBALGPARA

LST NODEBALGPARA
Meaning

Indicates whether to enable soft failure self-healing. If BBPRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the baseband processing unit check result and the number of random access messages. If the soft failure affects services, the baseband processing unit is restarted to recover services. When BBPRESETSWITCH is set to ON, if BBPRESETDELAYSWITCH is set to ON, the baseband processing unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if BBPRESETDELAYSWITCH is set to OFF, the baseband processing unit restarts immediately upon detecting soft failures and service exceptions. If RFRESETSWITCH is set to ON, the NodeB determines whether a soft failure occurs based on the RF unit check result and the number of random access messages. If the soft failure affects services, the RF unit is restarted to recover services. When RFRESETSWITCH is set to ON, if RFRESETDELAYSWITCH is set to ON, the RF unit is postponed to restart at 03:00 in the early morning to recover services upon detecting soft failures and service exceptions; if RFRESETDELAYSWITCH is set to OFF, the RF unit restarts immediately upon detecting soft failures and service exceptions. If BBSFRESHUFFLESWITCH is set to ON, the NodeB attempts to relocate cells served by the faulty baseband module to other baseband modules and restart the faulty module for self-healing after detecting a soft failure on the baseband module. If BBSFCORRECTSWITCH is set to ON, the NodeB attempts to correct the soft failure. This reduces the frequency of restarting the baseband module.
