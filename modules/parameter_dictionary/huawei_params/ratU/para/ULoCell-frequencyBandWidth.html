Meaning

Indicates the bandwidth for a cell over the air interface.

1. This parameter is optional. When this parameter is set to UNSPECIFIED, the actual cell bandwidth is configured by running the SET FREQBWH command.

2. This parameter is invalid for the WRFU, MRFU V1, MRFU V2, MRFU V2a, RRU3804, RRU3805, RRU3806, RRU3808, RRU3801C, RRU3801E, RRU3908, and AAU3902. However, on these RF units, the cell bandwidth is still configured by running the SET FREQBWH command.
