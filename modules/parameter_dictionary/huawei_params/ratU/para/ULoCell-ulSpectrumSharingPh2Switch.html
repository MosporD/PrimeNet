Meaning

Indicates whether the cell supports the UMTS and LTE spectrum sharing phase 2 feature. When this parameter is set to TRUE, the cell supports this feature.

Parameter Relationship

-Configuration constraints:

  • In the ULOCELL MO, if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE, and ULSPECTRUMSHARINGPHASE2 is set to FALSE, and ULSUPERNARROWBANDFILTER is set to NOTSUPPORT and UL0BUFFERZONE is set to FALSE, the sum of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH must be less than or equal to 320.
  • In the ULOCELL MO, assume that: x = Max. (ULLEFTSHAREDBANDWIDTH x 10, (2500 - ULSUPERNARROWBANDFILTER x 0.5)), y = Max. (ULRIGHTSHAREDBANDWIDTH x 10, (2500 - ULSUPERNARROWBANDFILTER x 0.5)). Then the sum of x and y must be less than or equal to 3200 if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE and ULSPECTRUMSHARINGPHASE2 is set to FALSE, and ULSUPERNARROWBANDFILTER is set to a value other than NOTSUPPORT and UL0BUFFERZONE is set to FALSE.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE, ULSPECTRUMSHARINGPHASE2 is set to FALSE, and ULSUPERNARROWBANDFILTER is set to NOTSUPPORT, the sum of DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH must be less than or equal to 320.
  • In the ULOCELL MO, assume that: x = Max. (DLLEFTSHAREDBANDWIDTH x 10, (2500 - ULSUPERNARROWBANDFILTER x 0.5)), y = Max. (DLRIGHTSHAREDBANDWIDTH x 10, (2500 -ULSUPERNARROWBANDFILTER x 0.5)). Then the sum of x and y must be less than or equal to 3200 if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE, ULSPECTRUMSHARINGPHASE2 is set to FALSE, and ULSUPERNARROWBANDFILTER is set to a value other than NOTSUPPORT.
  • When the ULSPECTRUMSHARINGSWITCH in the ULOCELL MO is set to FIXED_BANDWIDTH_COMP_MODE, and the ULSPECTRUMSHARINGPHASE2 in the ULOCELL MO is set to FALSE, only the values 0, 20, 40, 60, 80, 100, 120, 140, 160, 180, 200, 220, 240, and 260 are valid for the DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH parameters.
  • When ULADAPTIVEBPFILTER is selected under the GU5MHZPERFOPT parameter and UL0BUFFERZONE is set to FALSE and ULSPECTRUMSHARINGPHASE2 is set to FALSE in the ULOCELL MO, only the values 0, 20, 40, 60, 80, 100, and 120 are valid for the ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH parameters.
  • When DLADAPTIVEBPFILTERPERFEOPT is selected under the GU5MHZPERFOPT parameter in the ULOCELL MO, and the GUBUFZONECELLTYPE parameter in the ULOCELL MO is set to NOTBUFZONECELL, and the ULSPECTRUMSHARINGSWITCH parameter in the ULOCELL MO is set to NOTSUPPORT, and the ULSPECTRUMSHARINGPHASE2 parameter in the ULOCELL MO is set to FALSE, only the values 0, 20, 40, and 60 are valid for the DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH parameter.
  • In the ULOCELL MO, if UL0BUFFERZONE is set to TRUE and UL0BUFFERZONEFILTER is set to ULADAPTIVEFILTER, and ULSPECTRUMSHARINGPHASE2 is set to FALSE, the value of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH cannot be greater than 208.
  • In the ULOCELL MO, if UL0BUFFERZONE is set to TRUE and UL0BUFFERZONEFILTER is set to ULADAPTIVEFILTER, and ULSPECTRUMSHARINGPHASE2 is set toFALSE, the sum of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH must be greater than 0 and be less than or equal to 266.
  • When the ULSPECTRUMSHARINGSWITCH parameter is set to FIXED_BANDWIDTH_COMP_MODE and UL0BUFFERZONE is set to FALSE and ULSPECTRUMSHARINGPHASE2 is set to FALSE and ULSPECTRUMSHARINGPHASE2 is set to FALSE in the ULOCELL MO, only the values 0, 20, 40, 60, 80, 100, and 120 are valid for the ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH parameters.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, TTW must be FALSE.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, INTEL2TVAM must be FALSE.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to be TRUE, RMTCM must be FALSE and the value of RADIUS must be less than or equal to 35km.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, FDEMODE must be FALSE.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, DCHSDPASHAREDWITHGSM must be NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, GUBUFZONECELLTYPE must be NOTBUFZONECELL.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, the value of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH must be less than or equal to 260.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, the sum of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH must be less than or equal to 320.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, only the values 10*N where N is 0~26 are valid for DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, AIR must be FALSE.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE and ULSUPERNARROWBANDFILTER is set to NOTSUPPORT, the sum of ULLEFTSHAREDBANDWIDTH and ULRIGHTSHAREDBANDWIDTH must be less than or equal to 320.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, DCHSDPASHAREDWITHLTE must be NOTSUPPORT.
  • In the ULOCELL MO, UL0BUFFERZONEFILTER must be set to ULADAPTIVEFILTER when the following conditions are met: (1) ULSUPERNARROWBANDFILTER is set to a value other than NOTSUPPORT; GU5MHZPERFOPT contains the ULADAPTIVEBPFILTER bit; ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE; ULSPECTRUMSHARINGPHASE2 is set to TRUE; or GUBUFZONECELLTYPE is set to a value other than NOTBUFZONECELL. (2) UL0BUFFERZONE is set to TRUE.
  • In the ULOCELL MO, when ULSPECTRUMSHARINGPHASE2 is set to TRUE or DCHSDPASHAREDWITHLTE is set to DYNAMICBANDWIDTH, COCOVERLTECI can not be invalid.
  • In the ULOCELL MO, DLADAPTIVEBPFILTER cannot be set to FIXEDBANDWIDTH if any of the conditions is met: (1) ULSUPERNARROWBANDFILTER is not set to NOTSUPPORT. (2) GSMQLBASEDROTDYNACTRL is set to TRUE. (3) Values of GU5MHZPERFOPT contain ULADAPTIVEBPFILTER or DLADAPTIVEBPFILTERPERFEOPT. (4) GUBUFZONECELLTYPE is not set to NOTBUFZONECELL. (5) ULSPECTRUMSHARINGSWITCH is not set to NOTSUPPORT. (6) UL0BUFFERZONE is set to TRUE. (7) ULSPECTRUMSHARINGPHASE2 is set to TRUE.
  • When DLADAPTIVEBPFILTERPERFEOPT is selected under the GU5MHZPERFOPT parameter in the ULOCELL MO, and the GUBUFZONECELLTYPE parameter in the ULOCELL MO is not set to NOTBUFZONECELL, and the ULSPECTRUMSHARINGSWITCH parameter in the ULOCELL MO is set to NOTSUPPORT, and the ULSPECTRUMSHARINGPHASE2 parameter in the ULOCELL MO is set to FALSE, only the values 0, 20, 40, 60, 80, 100, 120, 140, 160, 180, 200, 220, 240 and 260 are valid for the DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH parameter.
  • When DLADAPTIVEBPFILTERPERFEOPT is selected under the GU5MHZPERFOPT parameter in the ULOCELL MO, and the GUBUFZONECELLTYPE parameter in the ULOCELL MO is not set to NOTBUFZONECELL, and the ULSPECTRUMSHARINGSWITCH parameter in the ULOCELL MO is set to NOTSUPPORT, and the ULSPECTRUMSHARINGPHASE2 parameter in the ULOCELL MO is set to FALSE, the sum of DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH must be less than or equal to 320.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to NORMAL_CELL, ULSPECTRUMSHARINGPHASE2 is valid.

-Others:

  • This parameter is invalid if Subrack Type is set to BBU3910C.

Impact on Radio Network Performance

When this parameter is set to TRUE, whether the UMTS cell performs filtering on the UMTS and LTE shared spectrum is dynamically determined based on the service status of LTE cells. Compared with UMTS static filtering, the dynamic filtering delivers higher spectral efficiency. When this parameter is set to FALSE, this function does not take effect.
