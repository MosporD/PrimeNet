Meaning

Indicates the UPA UE quantity threshold for the low-traffic experience enhancement function to take effect. When the number of UPA UEs in a cell is less than or equal to the threshold, the low-traffic experience enhancement function takes effect. When the number of UPA UEs in a cell is greater than the threshold or the threshold is set to 0, the low-traffic experience enhancement function does not take effect.

Impact on Radio Network Performance

If this parameter is set to a large value, the low-traffic experience enhancement function is more likely to take effect, but more RTWP peaks occur in the cell. This increases the service drop rate and decreases the access success rate. If this parameter is set to a small value, the low-traffic experience enhancement function is less likely to take effect, and the impact on RTWP peaks is small.
