Parameter Relationship

-Configuration constraints:

  • In the ULOCELL MO, if TTW is set to TRUE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if BFMODE is set to MASSIVEBEAM or NORMALBEAM, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if GSMQLBASEDROTDYNACTRL is set to TRUE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGSWITCH is set to FIXED_BANDWIDTH_COMP_MODE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if ULSUPERNARROWBANDFILTER is set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if DLADAPTIVEBPFILTER is set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if DCHSDPASHAREDWITHGSM is set to a value other than NOTSUPPORT, neither ULADAPTIVEBPFILTER nor DLADAPTIVEBPFILTERPERFEOPT can be selected under GU5MHZPERFOPT.
  • In the ULOCELL MO, if GUBUFZONECELLTYPE is set to a value other than NOTBUFZONECELL, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if DCHSDPASHAREDWITHGSM is set to a value other than NOTSUPPORT, only the values 0, 20, 40, 60, 80, 100, and 120 are valid for the DLLEFTSHAREDBANDWIDTH and DLRIGHTSHAREDBANDWIDTH parameters.
  • In the ULOCELL MO, if UL0BUFFERZONE is set to TRUE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if RMTCM is set to TRUE or the radius specified by RADIUS is greater than 30 km, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if INTEL2TVAM is set to TRUE, DCHSDPASHAREDWITHGSM must be set to NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, DCHSDPASHAREDWITHGSM must be NOTSUPPORT.
  • In the ULOCELL MO, if DCHSDPASHAREDWITHGSM is set to a value other than NOTSUPPORT, DCHSDPASHAREDWITHLTE must be set to NOTSUPPORT.
  • In the ULOCELL MO, if DCHSDPASHAREDWITHGSM is set to a value other than NOTSUPPORT, UU0DCHSDPA must be set to FALSE.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to NORMAL_CELL, DCHSDPASHAREDWITHGSM is valid.

-Others:

  • This parameter is invalid if Subrack Type is set to BBU3910C.

Impact on Radio Network Performance

If this parameter is set to NOTSUPPORT, the DC-HSDPA function of the shared GSM spectrum does not take effect. When this parameter is set to STATICBANDWIDTH, the downlink signal spectrum width of the cell remains unchanged. The more GSM frequencies that need to be filtered by the NodeB, the lower the UMTS HSDPA throughput. If this parameter is set to DYNAMICBANDWIDTHWITHGSM, the cell is identified as the dynamic filtering-supported cell that is co-sited with GSM cells and support GSM/UMTS synchronization through the GSM cells. The downlink signal spectrum width of the cell is dynamically adjusted in line with the activation status of GSM services. When the number of GSM frequencies to be filtered remains unchanged, the lower the GSM service activation rate decreases, the higher the UMTS downlink throughput. If this parameter is set to DYNAMICBANDWIDTHWITHOUTGSM, the cell is identified as not co-sited with any GSM cells. An external clock source (for example, GPS) with high precision must be added to the cell in order for Downlink Adaptive Band-Pass Filter in dynamic mode to take effect.
