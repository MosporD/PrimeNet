Parameter Relationship

-Configuration constraints:

  • RMTCM and AIR in the ULOCELL MO cannot be both set to TRUE.
  • In the ULOCELL MO, if AIR is set to TRUE, the value of RADIUS cannot be greater than 35 km.
  • In the ULOCELL MO, if the value of AIR is set to TRUE, the value of BFMODE must be NOTSUPPORT.
  • In the ULOCELL MO, if ULSPECTRUMSHARINGPHASE2 is set to TRUE, AIR must be FALSE.

-Parameter relationship with conditions:

  • If LOCELLTYPE is set to NORMAL_CELL, AIR is valid.

-Others:

  • This parameter is invalid if Subrack Type is set to BBU3910C.

Impact on Radio Network Performance

If this parameter is set to TRUE and the working mode of the uplink baseband equipment is set to AIR, uplink coverage in cells improves in the event of strong wideband interference.
