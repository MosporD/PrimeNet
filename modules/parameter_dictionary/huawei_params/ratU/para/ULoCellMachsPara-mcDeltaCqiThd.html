Meaning

Indicates the CQI difference threshold for multi-carrier HSDPA UEs. For a multi-carrier HSDPA UE that uses the local call as the primary well, if the result of subtracting carrier 2 CQI from carrier 1 CQI is greater than this threshold, the UE is scheduled with the lowest scheduling priority in carrier 2. (Carrier 1 is the carrier with the highest CQI, and carrier 2 is the one with the lowest CQI). Value 0 indicates that this function is disabled.

Impact on Radio Network Performance

When this parameter is set to 0, scheduling optimization is not performed on multi-carrier HSDPA UEs with overly low CQIs. When this parameter is not set to 0, this function takes effect, and the cell HSDPA throughput is improved accordingly, but for a cell during busy hours, the experience of multi-carrier HSDPA UEs with big difference in CQIs is affected. If this parameter is set to a large value, this function takes effect in fewer scenarios.
