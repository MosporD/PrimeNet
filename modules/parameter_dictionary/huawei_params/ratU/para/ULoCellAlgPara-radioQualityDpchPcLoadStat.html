Parameter ID RADIOQUALITYDPCHPCLOADSTAT
Parameter Name

Load State for DPCH Power Control Algorithm Based on Radio Quality
NE

MML Command

SET ULOCELLALGPARA

Meaning

Specifies the load state in which the DPCH/F-DPCH power control algorithm based on radio quality takes effect. When the downlink non-HSPA power load is in the load state set by this parameter or a heavier load state, the DPCH/F-DPCH power control algorithm based on signal quality is triggered.

Based on load level in ascending order (from light load to heavy load), the downlink non-HSPA power load states are as follows:

DlLightState: indicates the downlink resource light load state threshold 0%.

DlNormalState: indicates the downlink resource normal load state threshold 30%.

DlLoadedState: indicates the downlink resource light congestion state threshold 50%.

DlHeavyState: indicates the downlink resource severe congestion state threshold 70%.

DlOverloadState: indicates the downlink resource extreme congestion state threshold 95%. The following provides the method for determining the downlink non-HSPA power load state:

If the non-HSPA power load for a cell exceeds the threshold corresponding to the load state when the DPCH/F-DPCH power control algorithm based on radio quality takes effect plus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a heavier load state. In this case, the DPCH/F-DPCH power control algorithm based on radio quality is triggered. Note that 10% is not added when the downlink non-HSPA power load is in the downlink resource extreme congestion state.

If the non-HSPA power load for a cell decreases below the threshold corresponding to the load state when the DPCH/F-DPCH power control algorithm based on radio quality takes effect minus 10%, the NodeB determines that the downlink non-HSPA power load for the cell is in the load state set when this algorithm takes effect or a lighter load state. In this case, the DPCH/F-DPCH power control algorithm based on radio quality is not triggered. Note that 10% is not subtracted when the downlink non-HSPA power load is in the downlink resource light load state.

Impact on Radio Network Performance

The lighter the load state specified by this parameter, the higher the probability of triggering the DPCH power control algorithm based on radio quality. This reduces non-HSPA power but increases the call drop rate. The heavier the load state specified by this parameter, the lower the probability of triggering the DPCH power control algorithm based on radio quality and the less the improvements in downlink non-HSPA power and throughput.
