Meaning

Indicates the power sharing margin. The margin is used to compensate for the required power for R99 users due to delayed power sharing and compensate for the power for the burst services in the HSDPA cell that provides power for sharing. This parameter is used in configuring the Dynamic Power Sharing in Multi-Carriers and HSDPA Inter-Cell Power Sharing features.

Impact on Radio Network Performance

A large value of this parameter indicates little power to be shared between cells. If this parameter is set to a value greater than 20, power sharing improvements decrease. A small value of this parameter indicates much power to be shared between cells. If the value of this parameter is too small, for example, less than 10, shared power cannot accommodate the required power for R99 users, and power sharing improvements decrease due to delayed power reclaim.
