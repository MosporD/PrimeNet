Meaning

Indicates the switch for independent carrier scheduling of multi-carrier HSDPA users. If this switch is turned on, only the rate of a carrier for a multi-carrier HSDPA user is used as the input of the carrier scheduling weight. If this switch is turned off, the total rate of several carriers for a multi-carrier user is used as the input of the carrier scheduling weight.

Impact on Radio Network Performance

If this switch is turned off, multi-carrier HSDPA users and single-carrier HSDPA users in a multi-carrier cell group have equal opportunity to be scheduled when channel conditions and SPI are the same; the multi-carrier HSDPA user rate is the same as the single-carrier HSDPA user rate, and HSDPA users with different carriers meet user-level fairness. If this switch is turned on, multi-carrier HSDPA users have more scheduling opportunity than single-carrier HSDPA users in the multi-carrier cell group when channel conditions and SPI are the same; the multi-carrier HSDPA user rate is higher than the single-carrier HSDPA user rate, and HSDPA users with different carriers do not meet user-level fairness.
