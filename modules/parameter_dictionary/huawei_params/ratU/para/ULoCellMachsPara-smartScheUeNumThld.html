Parameter Name

NE

MML Command

SET ULOCELLMACHSPARA

LST ULOCELLMACHSPARA
Meaning

Indicates the threshold of the number of UEs for which the Machine Learning based Scheduling feature is effective. When the number of HSDPA users in the cell is greater than the threshold value, activating the Machine Learning based Scheduling algorithm helps improve the cell throughput. If this parameter is set to 0, this parameter is invalid, and the NodeB adjusts the threshold based on the Machine Learning based Scheduling algorithm in real time.
