Meaning

Indicates the percentage of time for rolling back the downlink adaptive filter within a one-second period for a UMTS cell when the UMTS and LTE Spectrum Sharing Phase 2 feature is enabled. When this parameter is set to default value 0, the function of rolling back the downlink adaptive filter bandwidth with a one-second period is disabled. When this parameter is set to a value other than 0 (for example, X), this function is enabled, and UMTS cell reduces the spectrum bandwidth shared with LTE cell continuously for X*10 ms within a one-second period. This rolls back the downlink adaptive filter bandwidth to a smaller value.

Impact on Radio Network Performance

When this parameter is set to a value other than 0, the function of rolling back the downlink adaptive filter bandwidth within a one-second period is enabled for the UMTS and LTE Spectrum Sharing Phase 2 feature. The larger the value of this parameter, the higher the percentage of time when the downlink adaptive filter rolls back within a one-second period, the higher the percentage of time when UMTS cell uses large spectrum bandwidth in the downlink, the better the receive performance of UMTS UEs, the lower the percentage of time when LTE cell can use large spectrum bandwidth shared by UMTS cell, and the lower the capacity of LTE cell. The smaller the value of this parameter, the lower the percentage of time when the downlink adaptive filter rolls back within a one-second period, the higher the percentage of time when LTE cell can use large spectrum bandwidth shared by UMTS cell, the larger the capacity of LTE cell, the lower the percentage of time when UMTS cell uses large spectrum bandwidth in the downlink, and the poorer the receive performance of UMTS UEs.
