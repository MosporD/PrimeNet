Meaning

Indicates whether to enable X2 automatic removal based on X2 faults and X2 usage. This parameter includes the following options:

BASED_ON_X2FAULT: If this option is selected, X2 automatic removal based on X2 faults is enabled. This parameter applies only to X2 interfaces between eNodeBs in the LTE system. This option applies only to LTE FDD and LTE TDD.

BASED_ON_X2USAGE_WITH_NEGO: If this option is selected, X2 automatic removal based on X2 usage is enabled and the removal requires the negotiation between the local and peer eNodeBs. If the X2SonProtocolDelCooSwitch option is selected, as long as the peer eNodeB supports 3GPP-defined X2 automatic removal negotiation method, the BASED_ON_X2USAGE_WITH_NEGO option takes effect when the X2 interface is normal regardless of whether the peer eNodeB is a Huawei eNodeB. This parameter applies only to X2 interfaces between eNodeBs in the LTE system. This option applies only to LTE FDD and LTE TDD.

BASED_ON_X2USAGE_WITHOUT_NEGO: If this option is selected, X2 automatic removal based on X2 usage is enabled and the removal does not require the negotiation between the local and peer eNodeBs. This option takes effect when the X2 interface is normal, the peer eNodeB is not a Huawei eNodeB, and the X2SonProtocolDelCooSwitch option is deselected. This parameter applies only to X2 interfaces between eNodeBs in the LTE system. This option applies only to LTE FDD and LTE TDD.

BASED_ON_SPEC_DYNAMIC_SHARING: If this option is selected, X2 self-removal based on dynamic sharing of the X2 specification is enabled. When the X2 interface resources are insufficient and a new EN-DC X2 setup is triggered, this function automatically and preferentially removes a faulty inter-eNodeB X2 interface with the longest duration of the latest fault or removes an inter-eNodeB X2 interface with the lowest usage within the shared X2 interface resources to provide X2 interface resources for EN-DC X2 setup. This function takes effect on both faulty and normal inter-eNodeB X2 interfaces, but it cannot automatically remove EN-DC X2 interfaces. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

BASED_ON_X2FAULT: If this option is selected, the eNodeB can automatically remove faulty X2 interfaces. This prevents faulty X2 interfaces from occupying the X2 specification. The X2 automatic removal function based on X2 fault cannot identify the fault type. If an X2 interface is faulty throughout a certain time, the eNodeB automatically removes the X2 interface. If this option is not selected, the eNodeB cannot automatically remove faulty X2 interfaces. As a result, new X2 interfaces cannot be configured if the total number of X2 interfaces configured for an eNodeB has reached its maximum.

BASED_ON_X2USAGE_WITH_NEGO: If this option is selected, the eNodeB can automatically remove X2 interfaces with low usage. This prevents X2 interfaces with low usage from occupying the X2 specification. If this option is not selected, the eNodeB cannot automatically remove X2 interfaces with low usage. As a result, new X2 interfaces cannot be configured if the total number of X2 interfaces configured for an eNodeB has reached its maximum. In addition, if the local eNodeB removes the X2 interface, the X2 interface negotiation may fail on the peer base station, and X2 fault alarms are reported on the peer base station.

BASED_ON_X2USAGE_WITHOUT_NEGO: If this option is selected, the eNodeB can automatically remove X2 interfaces with low usage. This prevents X2 interfaces with low usage from occupying the X2 specification. If this option is not selected, the eNodeB cannot automatically remove X2 interfaces with low usage. As a result, new X2 interfaces cannot be configured if the total number of X2 interfaces configured for an eNodeB has reached its maximum. In addition, if the local eNodeB removes the X2 interface, the X2 interface negotiation may fail on the peer station, and X2 fault alarms are reported on the peer base station.

BASED_ON_SPEC_DYNAMIC_SHARING: If this option is selected and the X2 interface resources are insufficient, the eNodeB automatically removes inter-eNodeB X2 interfaces within the shared X2 interface resources to provide X2 interface resources for EN-DC X2 setup. In this case, the proportion of S1-based handovers may increase, the RRC connection reestablishment success rate may decrease, and the service drop rate may increase. These impacts depend on the number of RRC connection reestablishments without UE context triggered by the two eNodeB connected by each removed X2 interface. A smaller number results in fewer impacts. In addition, if the local eNodeB removes the X2 interface, the X2 interface negotiation may fail on the peer base station, and X2 fault alarms are reported on the peer base station. If this function is disabled and the X2 interface resources are insufficient, new EN-DC X2 interfaces cannot be set up and the eNodeB cannot perform NSA services with new gNodeBs.
