Impact on Radio Network Performance

A smaller value of this parameter results in higher reliability of Random Access Response and paging message reception and more RBs to be occupied by the messages. If there are many Random Access Response messages or paging messages, the cell throughput may decrease. A larger value of this parameter results in fewer RBs to be occupied by the messages and lower reliability of Random Access Response and paging message reception, which may cause a decrease in the access success rate and paging success rate.
