SRB Polling Timer Maximum Adjust Value

MO SrbCfg
Parameter ID SrbPollTimerMaxAdjustValue
Parameter Name

SRB Polling Timer Maximum Adjust Value
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD SRBCFG

LST SRBCFG
Meaning

Indicates the maximum adjustment step of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

In heavy-traffic scenarios, if this parameter is set to a small value, the timer adjustment range is small and the decrease in the number of retransmissions due to the timer expiration becomes slow. If this parameter is set to a large value, the uplink status report may not be sent in a timely manner.
