Meaning

Indicates whether the candidate SCell can be configured as an SCell for CA UEs in a blind manner.

In CA-group-based configuration mode, this parameter takes effect if the SccBlindCfgSwitch option of the CaAlgoSwitch parameter is selected. In adaptive configuration mode, this parameter takes effect regardless of the SccBlindCfgSwitch setting.

If this parameter is set to TRUE, the eNodeB can configure this candidate SCell as an SCell for CA UEs in a blind manner, without delivering A4-related measurement configurations to the CA UEs.

If this parameter is set to FALSE, the eNodeB cannot configure this candidate SCell as an SCell for CA UEs in a blind manner. The eNodeB must deliver the A4 measurement configurations related to the operating frequency of the cell to CA UEs before the eNodeB can configure the cell as an SCell. This parameter applies only to LTE FDD and LTE TDD.
