Meaning

Indicates the working modes for SRI reporting period configuration.

SriAdaptiveHoldForVoIPSW: Indicates whether to enable SRI reporting period adaptation for VoLTE UEs during resource adjustment for SRI reporting. If this option is selected, SRI reporting periods are configured based on the cell load. If the number of UEs is small, adaptively configured SRI reporting periods are shorter than the fixed long SRI reporting period, improving the MOS of VoLTE users. If this option is deselected, the fixed long SRI reporting period is retained. SriAdaptiveHoldForVoIPSW takes effect only when both PUCCH resource adjustment and SRI reporting period adaptation are enabled. This option applies only to LTE FDD and LTE TDD.

SriPeriodCfgOptSW: Indicates whether to optimize SRI reporting period configuration. If this option is selected, SRI reporting periods are configured based only on the SRI reporting resource usage in the cell. When CA and VoLTE are enabled, many UEs can be assigned short SRI reporting periods, the amount of PUCCH resource increases, but the amount of available PUSCH resource decreases. If this option is deselected, SRI reporting periods are configured based on the resource usage of SRI reporting, semi-persistent ACK reporting, and dynamic ACK reporting. When CA and VoLTE are enabled, few UEs can be assigned short SRI reporting periods, the amount of PUCCH resource decreases, but the amount of available PUSCH resource increases. This option applies only to LTE FDD and LTE TDD.

SriOffsetReConfigForDrxSW: Indicates whether to reconfigure the SRI subframe offset for DRX. This option takes effect only when DRX is enabled. This option applies only to LTE FDD. If this option is selected, the eNodeB adjusts SRI and DRX subframe offsets for power saving. If this option is deselected, the eNodeB does not perform this function.

SriPeriodOptForVoipSW: Indicates whether to perform VoLTE-based adaptive SRI period optimization. If this option is selected, the eNodeB preferentially allocates a short SRI reporting period for VoLTE UEs, improving user experience of VoLTE UEs. This option takes effect only when SriPeriodAdaptive is set to QCIADAPTIVE and SriReCfgInd is set to FALSE. This option applies only to LTE FDD. If this option is deselected, the eNodeB does not perform this function.

SriDetectEnhanceSW: Indicates whether to enable the L1 detection enhancement algorithm for PUCCH SRI. If this option is selected, the PUCCH SRI detection enhancement algorithm is enabled for the cell. In this case, an optimized interference and noise estimation algorithm applies to the PUCCH format 1 detection. This helps better suppress false SRI detections. If this option is deselected, the PUCCH SRI detection enhancement algorithm is not enabled, and the original demodulation algorithm is used for PUCCH format 1 detection. This option applies only to LTE FDD and LTE TDD.

SriPeriodAdaptEnhancedOptSw: Indicates whether to optimize enhanced SRI period adaptation. If this option is selected, the eNodeB allocates short-period SRI resources to more UEs. If this option is deselected, the optimization does not take effect. This option takes effect only if the PucchSwitch option of the PucchAlgoSwitch parameter is selected, the TddSrsCfgMode parameter in the SRSCfg MO is set to ACCESS_ENHANCED, and the SriPeriodAdaptive parameter in the PUCCHCfg MO is set to QCIADAPTIVE or NOQCIADAPTIVE. This option applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CELLEMTCALGO MO is deselected.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE, the HighSpeedFlag in the Cell MO is set to LOW_SPEED, the MultiRruCellMode parameter in the Cell MO is set to CELL_COMBINATION, and the TxRxMode in the Cell MO is set to 1T1R, 1T2R, 2T2R, or 2T4R; or the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the PucchSwitch option of the PucchAlgoSwitch parameter in the CELLALGOSWITCH MO is selected, the TddSrsCfgMode parameter in the SRSCFG MO is set to ACCESS_ENHANCED, and the SriPeriodAdaptive parameter in the PUCCHCFG MO is set to QCIADAPTIVE or NOQCIADAPTIVE.

Impact on Radio Network Performance

SriAdaptiveHoldForVoIPSW: If this option is selected, the eNodeB adaptively assigns SRI reporting periods based on cell load to VoLTE UEs that are newly admitted to the local cell, handed over to the local cell, or have RRC connections reestablished in the local cell. When there are a small number of UEs, the MOS of VoLTE users increases and user experience improves. If this option is deselected, the eNodeB assigns a fixed long SRI reporting period for such UEs; the MOS of VoLTE users decreases and user experience slightly deteriorates.

SriPeriodCfgOptSW: If this option is selected, the MOS of VoLTE UEs increases and user experience improves in CA scenarios. However, the PUCCH occupies more RBs, which may trigger early PUCCH resource adjustments and affect uplink cell throughput. In addition, the resources available for the PUCCH during PUCCH resource adjustment are restricted, and this may cause a decrease in the RRC connection setup success rate.

SriOffsetReConfigForDrxSW: If this option is selected, SRI subframe offsets are reconfigured to match DRX subframe offsets for power saving purposes. However, the reconfiguration may result in a waste of PUCCH resources and trigger an early PUCCH resource adjustment, which affects uplink cell throughput. In addition, the resources available for the PUCCH during PUCCH resource adjustment are restricted, and this may cause a decrease in the RRC connection setup success rate.

SriPeriodOptForVoipSW: If this option is selected, the eNodeB preferentially allocates a short SRI reporting period for VoLTE UEs on medium- or heavy-load networks. This helps decrease the uplink packet loss rate of VoLTE UEs but affects the uplink throughput of data-service UEs.

SriDetectEnhanceSW: If this option is selected, the PUCCH SRI detection enhancement algorithm is enabled. This helps suppress false SRI detections. When DRX is enabled, this enhancement algorithm reduces the proportion of PDCCH DTXs, the downlink ARQ retransmission ratio, and downlink and uplink BLERs. However, it increases the probability of missing SRI detection of UEs with poor channel quality. When this option is deselected, the PUCCH SRI detection enhancement algorithm is not enabled, which has no impact on network performance.

SriPeriodAdaptEnhancedOptSw: If this option is selected, the eNodeB allocates short-period SRI resources to more UEs, reducing the uplink response delay and improving user experience. This may also increase the number of PUCCH RBs and affect the uplink cell throughput. If this option is deselected, the optimization does not take effect, and network performance is not affected.
