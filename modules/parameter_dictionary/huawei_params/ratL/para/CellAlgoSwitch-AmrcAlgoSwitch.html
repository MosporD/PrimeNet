Meaning

Indicates the switches of algorithm policies used for adjusting the uplink speech rate and related functions.

UlAmrcExceedingInitialSw: Indicates whether the adjusted uplink AMR voice coding rate can exceed the initial coding rate for this call. The adjusted uplink AMR voice coding rate can exceed the initial coding rate only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UlAmrCheckSw: Indicates whether to adjust the uplink AMR voice coding rate if the eNodeB has not obtained the rate set information about this session and the UlAmrcMode parameter is set to ULAMRC_ENB_CONTROL. The uplink AMR voice coding rate can be adjusted only if this option is deselected. This option applies only to LTE FDD and LTE TDD.

VoiceCodingModeMeasSw: Indicates whether to measure the distribution of the numbers of uplink and downlink voice packets in different voice coding schemes on a per cell basis. If this option is deselected, the eNodeB does not measure the distribution of the numbers of uplink and downlink voice packets in different voice coding schemes on a per cell basis. If this option is selected, the corresponding counter is incremented based on the frame types (voice frame and silence frame in different voice coding schemes) each time the eNodeB PDCP layer receives an uplink or downlink PDCP SDU with a QCI of 1 in a cell. This option applies only to LTE FDD and LTE TDD.

VoLTELoadAmrcSw: Indicates whether to enable voice-load-based AMRC/EVS rate control. If voice-load-based AMRC/EVS rate control is enabled, the AMRC/EVS rate is reduced when voice load of the cell is high. Voice-load-based AMRC/EVS rate control is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UlEvsExceedingInitialSw: Indicates whether the adjusted uplink EVS voice coding rate can exceed the initial coding rate for this call. The adjusted uplink EVS voice coding rate can exceed the initial coding rate only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UlMcpttVoiceAmrcSw: Indicates whether to enable AMRC for uplink MCPTT voice services. AMRC is enabled for uplink MCPTT voice services only if this option is selected. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

UlAmrcExceedingInitialSw: If this option is selected and the uplink AMR voice coding rate increases significantly, the uplink voice quality is improved. However, the voice packet loss rate will slightly increase and the CCE and RB resources consumed by voice services will increase, causing a slight decrease in UE- and cell-specific throughput.

UlAmrCheckSw: If the UlAmrcMode parameter is set to ULAMRC_ENB_CONTROL, this option is deselected, and the adjusted target coding rate is not adopted by this session, then one-way audio may occur if the coding rate is incompatible on the UE.

VoiceCodingModeMeasSw: If this option is selected and a large number of UEs are processing voice services, the CPU usage of the BBP (indicated by L.Traffic.Board.UPlane.CPULoad.AVG) will increase. If this option is deselected, network performance is not affected.

VoLTELoadAmrcSw: If this option is selected, the uplink air interface load of the cell is high, and uplink VoLTE service packets are fragmented, then the AMR for voice services will be decreased to reduce uplink PRB and CCE congestion in the cell. As a result, the voice service quality may deteriorate. If this option is deselected, network performance is not affected.

UlEvsExceedingInitialSw: If this option is selected and the percentage of times the EVS coding rate is increased to a rate higher than the initial coding rate is large, the uplink voice quality is improved. However, the voice packet loss rate slightly increases and more CCE and RB resources are consumed by voice services, causing a slight decrease in UE- and cell-specific throughput.

UlMcpttVoiceAmrcSw: If this option is selected, a high voice coding rate is used when the uplink channel quality is good and a low voice coding rate is used when the uplink channel quality is poor, which improves uplink voice quality. If the percentage of times the voice coding rate is increased to a rate higher than the initial voice coding rate is large, more CCE and RB resources are consumed by voice services. In CCE-limited or full-buffer service scenarios, the traffic volume and throughput of data services are more likely to decrease. If the percentage of times the voice coding rate is decreased to a rate lower than the initial voice coding rate is large, fewer CCE and RB resources are consumed by voice services. In CCE-limited or full-buffer service scenarios, the traffic volume and throughput of data services are more likely to increase. If this option is deselected, there is no impact on radio network performance.
