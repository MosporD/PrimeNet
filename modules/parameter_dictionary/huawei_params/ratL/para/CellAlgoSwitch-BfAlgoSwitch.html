Meaning

BfSwitch: Indicates whether to enable the beamforming algorithm. If this option is selected, the beamforming algorithm is enabled for all UEs in the cell. If this option is deselected, the beamforming algorithm is disabled for all UEs in the cell. This option is deselected by default. If a cell supporting beamforming is established, manually select this option. This option applies only to LTE TDD.

LongSrsPeriodBfSwitch: Indicates whether to perform beamforming for UEs with the SRS period longer than 40 ms in non-massive MIMO cells. If this option is selected, the eNodeB can perform beamforming for UEs with the SRS period longer than 40 ms in non-massive MIMO cells. If this option is deselected, the eNodeB cannot perform beamforming for such UEs. This option takes effect only when the beamforming algorithm is enabled. This option applies only to LTE TDD.

AntSelEnhanceBfSwitch: Indicates whether to enable 4-antenna selective transmission. If this option is selected, 4-antenna selective transmission is enabled. If this option is deselected, 4-antenna selective transmission is disabled. This option applies only to LTE TDD.

FakeAntSelIdentificationSwitch: Indicates whether to enable identification of UEs that falsely claim their support for SRS transmit antenna selection. If this option is selected, the identification of UEs that falsely claim their support for transmit antenna selection is supported, and optimization of MCS index selection for dual-stream beamforming is supported on UEs that truly support transmit antenna selection. If this option is deselected, the identification and optimization are not performed. This option applies only to LTE TDD.

Impact on Radio Network Performance

LongSrsPeriodBfSwitch: If this option is selected, the eNodeB performs beamforming for UEs in non-massive MIMO cells who meet the beamforming criteria and have an SRS period longer than 40 ms. This increases the downlink throughput of such UEs. The function of performing beamforming for such UEs is dependent on UEs' beamforming performance. If this option is deselected, this function does not take effect, and network performance is not affected.

AntSelEnhanceBfSwitch: If this option is selected, 4-antenna selective transmission is enabled, and the eNodeB can obtain uplink SRS resource information of four UE antennas, improving downlink beamforming performance. If this option is deselected, 4-antenna selective transmission is disabled, and downlink beamforming performance is not affected.

FakeAntSelIdentificationSwitch: If this option is selected, the identification of UEs that falsely claim their support for SRS transmit antenna selection is supported, and optimization of MCS index selection for dual-stream beamforming is supported on UEs that truly support transmit antenna selection, increasing the downlink throughput of UEs that truly support SRS transmit antenna selection and those that falsely claim their support for SRS transmit antenna selection. If this option is deselected, identification of UEs that falsely claim their support for SRS transmit antenna selection is not supported and the optimization of MCS index selection for dual-stream beamforming is not supported on UEs that truly support transmit antenna selection. In this case, the downlink throughput of UEs that truly support SRS transmit antenna selection and those that falsely claim their support for SRS transmit antenna selection decreases. If this option is selected for a massive MIMO cell, the transmission mode of the UE may be affected.
