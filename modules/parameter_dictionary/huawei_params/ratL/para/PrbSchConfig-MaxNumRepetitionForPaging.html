Meaning

Indicates the maximum number of paging repetitions in the NPDCCH common search space. For details about this parameter, see descriptions of the npdcch-NumRepetitionPaging IE in 3GPP TS 36.331. When this parameter is set to NULL, the maximum number of PDCCH repetitions corresponding to the maximum coverage level configured for the carrier is used as the value of the npdcch-NumRepetitionPaging IE by default. (The maximum number of PDCCH repetitions is specified by the PdcchMaxRepetitionCnt parameter in the PrbPdcchCeConfig MO.). When this parameter is set to a value other than NULL, the MaxNumRepetitionForPaging parameter value is used as the value of the npdcch-NumRepetitionPaging IE. This parameter applies only to NB-IoT.
