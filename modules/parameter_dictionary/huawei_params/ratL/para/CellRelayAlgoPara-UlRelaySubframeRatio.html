Meaning

Indicates the ratio of uplink subframes used as relay subframes. The total number of subframes in each radio frame is 10. For example, the value 2/10 indicates that two uplink subframes in each radio frame are used as relay subframes. In the LTE FDD system, the number of uplink subframes used for common UEs is 8, which is the result of subtracting 2 from 10. In the LTE TDD system, the number of uplink subframes used for common UEs is calculated by subtracting the number of uplink subframes used as relay subframes from the number of uplink subframes specified by the subframe configuration. Relay subframes are preferentially scheduled for relay remote nodes (RRNs) while common subframes are preferentially scheduled for common UEs. If the relay subframes are not used up, they can be used for scheduling for common UEs and if the common subframes are not used up, they can be used for scheduling for RRNs. This parameter applies only to LTE FDD and LTE TDD.
