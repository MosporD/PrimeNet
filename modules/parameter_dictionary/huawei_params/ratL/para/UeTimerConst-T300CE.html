Meaning

Indicates the timer value of Timer 300 in coverage enhancement mode. If this parameter is set to a value indicating a timer length less than or equal to 2000 ms, the value of this parameter is broadcast only in the t300 IE of SIB2 and this value takes effect for UEs in all CE modes. If this parameter is set to a value indicating a timer length greater than 2000 ms, there are two consequences: (a) A fixed value of 2000 ms is broadcast in the t300 IE of SIB2 and this value takes effect for UEs that support only CE mode A. (b) The value of this parameter is broadcast in the t300-v1310 IE of SIB2 and this value takes effect only for UEs that support CE mode B. For details, see 3GPP TS 36.331.

This timer is started when the UE sends RRCConnectionRequest.

Before the timer expires, it is stopped if the UE receives RRCConnectionSetup or RRCConnectionReject.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.
