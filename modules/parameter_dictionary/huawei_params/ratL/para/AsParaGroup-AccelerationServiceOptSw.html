Meaning

Indicates whether to enable the acceleration service optimization algorithm.

ENTER_DRX_SWITCH: Indicates whether to enable DRX for acceleration guarantee UEs. If this option is deselected, DRX is disabled for acceleration guarantee UEs. If this option is selected, the eNodeB does not perform special processing on the DRX function for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

MLB_AND_MBOCS_PROHIBITION_SW: Indicates whether to disable MLB and MBOCS for acceleration guarantee UEs. If this option is deselected, acceleration guarantee UEs can be transferred by MLB and MBOCS. If this option is selected, acceleration guarantee UEs cannot be transferred by MLB and MBOCS. This option applies only to LTE FDD and LTE TDD.

PDCCH_BOUNDARY_PC_OPT_SW: Indicates whether to enable PDCCH boundary power control optimization for acceleration guarantee UEs. PDCCH boundary power control optimization is enabled for acceleration guarantee UEs only if this option is selected. This option applies only to LTE FDD.

PERIODIC_MEAS_OPT_SWITCH: Indicates whether to allow acceleration guarantee UEs to perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is deselected, such UEs can perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is selected, the UEs cannot perform these measurements. This option applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: Indicates whether the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is selected, the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is deselected, the eNodeB does not trigger fast-moving-UE smart carrier selection for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

ENTER_DRX_SWITCH: If this option is selected, the power consumption of acceleration guarantee UEs is further reduced when the UEs are triggered to enter DRX mode. However, the impact on network performance is subject to the DRX parameter configuration. If this option is deselected, acceleration guarantee UEs cannot enter DRX mode, shortening the delay on the UEs. However, this increases the UE power consumption and reconfiguration message overhead.

MLB_AND_MBOCS_PROHIBITION_SW: If this option is selected, acceleration guarantee UEs cannot be transferred by MLB and MBOCS, hindering load balancing on the network but helping ensure user experience of acceleration guarantee UEs. If this option is deselected, acceleration guarantee UEs can be transferred by MLB and MBOCS, facilitating load balancing on the network but possibly causing user experience deterioration for acceleration guarantee UEs.

PDCCH_BOUNDARY_PC_OPT_SW: If this option is selected and the PDCCH CCE aggregation level reaches the maximum for acceleration guarantee UEs, the power increases quickly and the delay decreases, but the equivalent CCE usage increases. If this option is deselected and the PDCCH CCE aggregation level reaches the maximum for acceleration guarantee UEs, the power increases slowly and the delay increases, but the equivalent CCE usage decreases.

PERIODIC_MEAS_OPT_SWITCH: If this option is selected, acceleration guarantee UEs cannot perform periodic inter-frequency or inter-RAT measurements and MDT measurements, which shortens the delay or increases the data rates of acceleration guarantee UEs. However, the number of periodic inter-frequency or inter-RAT measurement reports and MDT measurement reports may decrease. If this option is deselected, network performance is not affected.

SCS_FAST_MOVING_UE_SW: If this option is selected, fast-moving-UE smart carrier selection is adopted for acceleration guarantee UEs. In this case, if acceleration guarantee UEs are fast-moving UEs, downlink UE throughput can increase. If this option is deselected, network performance is not affected.
