Meaning

Indicates the configuration for uplink interference locating.

The combination of the settings of bit 0 to bit 2 indicates the maximum number of interference orientations used in interference locating. The corresponding decimal value range is 0 to 7. The larger the number of antennas, the stronger the space-domain detection capability and the larger the number of interference orientations that can be used to locate interference sources. On live networks, if both the number of antennas and the number of interference sources are large, it is recommended that this parameter be set to a large value to increase the number of interference sources located at a time. If the number of antennas is large but the number of interference sources is small, it is recommended that this parameter be set to a small value to improve interference locating accuracy. For example, it is recommended that this parameter be set to 2 in 2R scenarios and 3 in 4R scenarios. This parameter cannot be set to a value greater than 4 in these scenarios.

The combination of the settings of bit 3 to bit 7 indicates the uplink SINR threshold for strong interference measurement. The corresponding decimal value range is 0 to 31, and the actual value range is -10 dB to 21 dB. When the uplink SINR of a UE is greater than the actual value of this parameter, the coefficient of correlation between the UE and strong interference will be measured. The recommended value is 5, which corresponds to the actual value -5 dB. The combination of the settings of bit 8 to bit 13 indicates the threshold for determining symbol-level interference. If the interference level is greater than this threshold, symbol-level interference exists on the network and the interference suppression procedure ends. The corresponding decimal value range is 0 to 63, and the actual value range is 0 dB to 63 dB. The recommended value is 10. The combination of the settings of bit 14 to bit 19 indicates the evaluated ratio of the combination gain to the interference suppression gain, which is used for selecting cooperating cells for a UE. The corresponding decimal value range is 0 to 60, and the actual value range is 0 to 6. A larger value indicates a higher weight of the combination gain. The recommended value is 15, and the actual value is 1.5. This parameter applies only to LTE FDD.

Recommended Value

In 2R scenarios, the recommended maximum number of interference orientations for interference locating is 2, the recommended SINR threshold for strong interference measurement is 5 (meaning -5 dB), the symbol-level interference decision threshold is 10 dB, and the evaluated ratio of the combination gain to the interference suppression gain is 15 (which corresponds to the actual value 1.5). In light of these recommended values, the corresponding parameter value is 248362.

In 4R scenarios, the recommended maximum number of interference orientations for interference locating is 3, the recommended SINR threshold for strong interference measurement is 5 (meaning -5 dB), the symbol-level interference decision threshold is 10 dB, and the evaluated ratio of the combination gain to the interference suppression gain is 15 (which corresponds to the actual value 1.5). In light of these recommended values, the corresponding parameter value is 248363.

Impact on Radio Network Performance

The combination of the settings of bit 0 to bit 2 indicates the maximum number of interference orientations used in interference locating, and the combination of the settings of bit 3 to bit 7 indicates the uplink SINR threshold for strong interference measurement. These combinations do not affect network performance.

The combination of the settings of bit 8 to bit 13 indicates the threshold for determining symbol-level interference. A lower threshold leads to a higher probability that interference will be determined as symbol-level interference and the cell will exit interference suppression. A higher threshold leads to a lower probability that interference will be determined as symbol-level interference. In this case, if the symbol-level interference is strong, the uplink UE throughput may decrease and the uplink packet loss rate of voice-service UEs may increase.

The combination of the settings of bit 14 to bit 19 indicates the evaluated ratio of the combination gain to the interference suppression gain, which is used for selecting cooperating cells for a UE. A larger value indicates a higher weight of the combination gain. If the combination gain is lower than the interference suppression gain, the uplink UE throughput decreases and the uplink packet loss rate of voice-service UEs increases. A smaller value indicates a lower weight of the combination gain. If the combination gain is lower than the interference suppression gain, the uplink UE throughput increases and the uplink packet loss rate of voice-service UEs decreases.
