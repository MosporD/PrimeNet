EDT DL Data Waiting Timer

MO CellEdtConfig
Parameter ID EdtDlDataWaitingTimer
Parameter Name

EDT DL Data Waiting Timer
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLEDTCONFIG

LST CELLEDTCONFIG
Meaning

Indicates the length of the timer governing the period during which the eNodeB waits for downlink data from the core network when a UE initiates an EDT service. The timer length specified by this parameter must be less than the timer length specified by the CellRachCECfg.EdtContentionResTimer parameter when the EDT service does not use early contention resolution. Otherwise, the UE EDT service cannot be normally performed.

The eNodeB starts this timer when it receives an RRCConnectionResume message carrying data or an RRCEarlyDataRequest message.

If downlink data indication is received from the core network before the timer expires or the volume of downlink data that arrives before the timer expires is larger than the maximum data volume allowed for an EDT service, the timer will be stopped.

After the timer expires, the eNodeB starts EDT in the downlink. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

If this parameter is set to a too small value, there is a high probability that the timer expires before the core network delivers downlink data. As a result, the downlink data delivery may fail. If this parameter is set to a too large value, downlink service delays increase for UEs, and there is a high probability that UE EDT services are abnormal because the eNodeB fails to deliver the contention resolution MCE or Msg4.
