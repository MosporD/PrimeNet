Meaning

Indicates the CPRI compression type of the cell. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, QUADPLEX_COMPRESSION, TRIPLEX_COMPRESSION_10M, or 3_2_COMPRESSION. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that normal CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value QUADPLEX_COMPRESSION indicates that quadruple CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, which applies only to LTE FDD. The value 3_2_COMPRESSION indicates that the compression ratio of 3.2:1 is used. This compression ratio applies only to TDD cells and FDD massive MIMO cells. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. The LBBPc does not support CPRI compression. All types of LBBP boards do not support enhanced or quadruple CPRI compression. Only the UBBPe and UBBPg support triple CPRI compression for 10 MHz cells. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by the RRUs in the chain or ring are deactivated. After the parameter value is changed, activate the cells. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

NO_COMPRESSION(No Compression). For LampSite base stations, the recommended value is NORMAL_COMPRESSION(Normal Compression). Operators need to check whether the CPRI port bandwidth meets the actual bandwidth requirement. If the required bandwidth exceeds the CPRI port bandwidth obtained after normal compression, change the value from NORMAL_COMPRESSION(Normal Compression) to ENHANCED_COMPRESSION(Enhanced Compression) or QUADPLEX_COMPRESSION(Quadplex Compression).

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if FddTddInd is CELL_FDD and CPRICompression is NORMAL_COMPRESSION, DlBandWidth can be set to CELL_BW_N25, CELL_BW_N50, CELL_BW_N75, CELL_BW_N100.
  • In a Cell MO, if FddTddInd is CELL_FDD and CPRICompression is ENHANCED_COMPRESSION, DlBandWidth can be set to CELL_BW_N50, CELL_BW_N75, CELL_BW_N100.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_FDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE, SFN or MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_TDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE or CELL_COMBINATION, MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • CPRICompression in a Cell MO is set to TRIPLEX_COMPRESSION_10M, FddTddInd in this Cell MO must be set to CELL_FDD, and DlBandWidth and UlBandWidth in this Cell MO must be set to CELL_BW_N50.
  • When the CPRICompression parameter in the Cell MO is set to 3_2_COMPRESSION, the following conditions must be met: (1) If the FddTddInd parameter in this Cell MO is set to CELL_FDD, the TxRxMode and UlBandWidth parameters must be set to 32T32R and CELL_BW_N75 or CELL_BW_N100, respectively. (2) If the FddTddInd parameter in this Cell MO is set to CELL_TDD, the UlBandWidth parameter must be set to CELL_BW_N75 or CELL_BW_N100, respectively.

Caution

Changing the value of CPRICompression, UlBandWidth, or DlBandWidth may result in CPRI bandwidth insufficiency, which leads to cell unavailability. If the cell is unavailable and the CPRI bandwidth specification is not exceeded, you are advised to block and then unblock the CPRI port for the cell.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
