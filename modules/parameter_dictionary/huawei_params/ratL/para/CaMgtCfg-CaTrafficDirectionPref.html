Meaning

Indicates the policy according to which the eNodeB selects band combinations when configuring SCells for CA. If this parameter is set to DL_FIRST, the eNodeB preferentially selects a band combination with the maximum downlink CA capability when a candidate SCell is a multi-band cell. This band combination may not support uplink CA. If this parameter is set to UL_FIRST, the eNodeB preferentially selects a band combination supporting uplink CA when a candidate SCell is a multi-band cell, so that an uplink SCell can be configured for the UE. If this parameter is set to UL_CA_COMBINATION_FIRST, the eNodeB preferentially selects the serving cell combination with the strongest uplink capability in intelligent selection of serving cell combinations. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

Setting this parameter to DL_FIRST maximizes the downlink CA capability, improving downlink service experience. However, if the CA UE does not support uplink CA in the selected band combination, the uplink service experience is affected. Setting this parameter to UL_FIRST improves uplink service experience. However, for a UE with a higher downlink CA capability, the downlink service experience is affected because the candidate cell with its maximum downlink CA capability is not configured as an SCell. Setting this parameter to UL_CA_COMBINATION_FIRST improves uplink service experience but causes downlink service experience deterioration in intelligent selection of serving cell combinations.
