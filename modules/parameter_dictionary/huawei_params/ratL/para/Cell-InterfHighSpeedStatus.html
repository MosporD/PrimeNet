Meaning

Indicates the status of interference coordination in high-speed railway scenarios. The value of this parameter can be InterfHighSpeedStatus_NO_OP~0(Disable), InterfHighSpeedStatus_ACT~1(Run), or InterfHighSpeedStatus_RENEW~2(Restore).

When interference coordination in high-speed railway scenarios is disabled for a cell, the value of this parameter is InterfHighSpeedStatus_NO_OP~0(Disable) in the command output. When this function is being performed in the cell, the value of this parameter is InterfHighSpeedStatus_ACT~1(Run). When resources are restored to normal status, the value of this parameter is InterfHighSpeedStatus_RENEW~2(Restore). This parameter applies only to LTE FDD and LTE TDD.
