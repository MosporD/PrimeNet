Meaning

Indicates the coexistence mode of an LAA cell. The value ALWAYS_ON indicates that the LAA cell is always enabled and does not share channels with other equipment. The values LBT_TYPEA and LBT_TYPEB indicate two LBT types for coordination between LAA SCells when these cells are served by one RRU. For details, see "Channel access procedures for LAA" in 3GPP 36.213. The value LBT_TYPEA applies only to non-RF combination scenarios or scenarios where the LsbSwitch parameter is set to OFF. This parameter applies only to LTE TDD.

Since the LTE-U function has been removed, the values STATIC_DUTY and DYNAMIC_DUTY are invalid. Although the configuration interface in this version supports synchronization and delivery of these values, the system does not use these values. Therefore, avoid using the value STATIC_DUTY or DYNAMIC_DUTY.
