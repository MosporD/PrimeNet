Parameter Name

Handover Signaling Optimized Switch
NE

MML Command

MOD ENODEBALGOSWITCH

LST ENODEBALGOSWITCH
Meaning

Indicates whether to enable handover signaling optimization. This parameter provides the following options:

ReduceInvalidA1A2RptSigSwitch: Indicates whether to optimize the sequence in delivering A1/A2 measurement configurations during coverage- or frequency-priority-based handovers. If this option is selected: (1) In coverage-based handovers, the eNodeB delivers A2 measurement configurations to UEs first, and then delivers A1 measurement configurations to UEs after receiving event A2 reports, reducing signaling overheads in reporting unnecessary event A1. (2) In frequency-priority-based handovers, the eNodeB delivers A1 measurement configurations to UEs first, and then delivers A2 measurement configurations to UEs after receiving event A1 reports, reducing signaling overheads in reporting unnecessary event A2. This option applies only to LTE FDD and LTE TDD.

MultiQciHoExecOptSwitch: Indicates whether the handover decision is triggered based on the admission result of all QCIs in SPID-based handovers to HPLMN and frequency-priority-based handovers. If this option is selected, the handover decision is triggered only when all QCI services are successfully admitted. If this option is deselected, the handover decision is triggered when any of the QCI services is successfully admitted. This option applies only to LTE FDD and LTE TDD.

ReduceInvalidFreqPriHoSwitch: Indicates whether to avoid repeated switchovers between the frequency-priority-based intra-eNodeB handover algorithm and the load-based intra-eNodeB handover algorithm. If this option is selected, the eNodeB evaluates whether to perform a frequency-priority-based intra-eNodeB handover based on the settings of InterFreqMlbSwitch of the MlbAlgoSwitch parameter and the load status on the target cell. If the target cell is heavily loaded, the eNodeB does not trigger the handover. If this option is deselected, the eNodeB evaluates whether to perform a frequency-priority-based intra-eNodeB handover without checking the settings of InterFreqMlbSwitch of the MlbAlgoSwitch parameter on the target cell. This option applies only to LTE FDD and LTE TDD.

AddA2MeasIfQciAdjSwitch: Indicates whether an eNodeB delivers inter-frequency or inter-RAT A2-related measurement configuration to the UE when the QCI of services running on the UE changes in a coverage-based handover. If this option is selected, the eNodeB performs the following operations each time the QCI is changed: (1) Updates the delivered handover-related parameters; (2) Determines whether inter-frequency or inter-RAT measurement configurations need to be delivered; (3) Delivers the configurations if they are required and have not been delivered before, or updates the configurations if they have been delivered and the current event A2 thresholds for inter-frequency or inter-RAT measurements are less than or equal to the event A2 threshold for blind handling. If this option is deselected, the eNodeB only determines whether delivered handover-related parameters need to be updated each time the QCI is changed. This option applies only to LTE FDD and LTE TDD.

InterFreqHoA2OptSwitch: Indicates whether to deliver A2-related measurement configurations to UEs that do not support inter-frequency measurements. A2-related measurement configurations are not delivered to such UEs when this option is selected. This option is deselected by default. This option applies only to LTE FDD and LTE TDD.

McUtranNcellNumOptSwtich: Indicates the maximum number of neighboring cells contained in the measurement configuration delivered to a UE when ANR with UTRAN is enabled. If this option is deselected, the maximum number is specified according to 3GPP TS36.331 earlier than V10.12.0 and is equal to the value of minCellperMeasObjectRAT. If this option is selected, the maximum number is specified according to 3GPP TS 36.331 V10.12.0 and later versions and is equal to the minCellperMeasObjectRAT parameter value minus 1. For details about the minCellperMeasObjectRAT parameter, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

ReduceMeasCtrlMesNumSwitch: Indicates whether to reduce the number of Uu interface measurement configuration messages that are delivered for E-RAB setup, removal, and modification. If this option is selected, the eNodeB combines the E-RAB setup, removal, and modification and measurement configuration in a single RRC Connection Reconfiguration message. If this option is deselected, the eNodeB delivers the E-RAB setup, removal, and modification and measurement configuration separately in two RRC Connection Reconfiguration messages. This option applies only to LTE FDD and LTE TDD.

ServiceReqInterFreqBlindHoSw: Indicates whether to trigger a service-based blind inter-frequency handover. If this option is selected, when a service-based inter-frequency handover is triggered for an FDD+TDD CA UE using a TDD carrier as the PCC and the target cell is an FDD SCell of the UE, the eNodeB instructs the UE to perform a blind handover to the FDD SCell. If this option is deselected, the eNodeB triggers a measurement-based handover to an FDD SCell and configures SCells again for the preceding UE. This option applies only to LTE TDD.

HOSuccRateBoostOptSwitch: Indicates the selection of the PDCCH CCE aggregation level for RAR retransmission in the case of non-contention-based random access for handovers and the number of RBs allocated for Msg3 transmitted based on non-contention-based random access preamble. If this option is selected, the PDCCH CCE aggregation level can be changed to level 8 for both LTE FDD and TDD cells when the RAR message for non-contention-based random access handovers is retransmitted and, for TDD cells, the eNodeB allocates three RBs for Msg3 transmitted based on a non-contention-based random access preamble. If this option is deselected, the PDCCH CCE aggregation level for RAR transmission in the case of non-contention-based random access for handovers is fixed to the value of the ComSigCongregLv parameter in the CellPdcchAlgo MO in both LTE FDD and TDD cells and, for TDD cells, the eNodeB allocates eight RBs for Msg3 transmitted based on a non-contention-based random access preamble. For cells working on small bandwidths such as 1.4 MHz and 3 MHz, it is recommended that the HOSuccRateBoostOptSwitch option be deselected. This option applies only to LTE FDD and LTE TDD.

HoSuccCounterMeasCtrlSwitch: Indicates the measurement point for counting inter-RAT handover success from E-UTRAN to a different RAT. If this option is selected, a handover success is counted when the eNodeB receives a UE CONTEXT RELEASE COMMAND message from the MME with the cause value being Successful Handover. If this option is deselected, a handover success is counted when the eNodeB receives a UE CONTEXT RELEASE COMMAND message from the MME. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

ReduceInvalidA1A2RptSigSwitch: If this option is selected, resources are conserved by reducing signaling overheads in reporting unnecessary event A1 or A2. If this option is deselected, signaling of unnecessary events A1 and A2 increases. MultiQciHoExecOptSwitch: If this option is selected, signaling overheads for SPID-based handovers to HPLMN and frequency-priority-based handovers decreases, and the number of UEs triggering SPID-based handovers to HPLMN and frequency-priority-based handovers decreases. As a result, some UEs cannot be handed over back to the HPLMN or initiate frequency-priority-based handovers timely. If this option is deselected, the probability of triggering SPID-based handovers to HPLMN and frequency-priority-based handovers increases, but user experience for voice users deteriorates. ReduceInvalidFreqPriHoSwitch: If this option is selected, the eNodeB performs frequency-priority-based intra-eNodeB handovers based on the cell load detected during MLB. If the cell load is high, frequency-priority-based intra-eNodeB handovers are not performed. In this case, the UE does not experience ping-pong handovers when both frequency-priority-based intra-eNodeB handover and load-based intra-eNodeB handover are enabled. If this option is deselected, the eNodeB does not consider the cell load detected during MLB when performing frequency-priority-based intra-eNodeB handovers. There is a possibility that the UE experiences ping-pong handovers when both frequency-priority-based intra-eNodeB handover and load-based intra-eNodeB handover are enabled.

AddA2MeasIfQciAdjSwitch: If this option is selected, inter-frequency or inter-RAT measurement configurations for event A2 can be delivered or updated when the QCI is changed. However, this increases the signaling overheads over the Uu interface. If this option is deselected, only delivered handover-related parameters are updated. As a result, inter-frequency or inter-RAT measurement configurations for event A2 may not be delivered even when the QCI is changed. As a result, service drops occur.

InterFreqHoA2OptSwitch: If this option is selected, A2-related measurement configurations are not delivered to UEs that do not support inter-frequency measurements. In this case, if neighboring cells for blind handovers are not configured, A2-related measurement configurations may not be delivered, which may deteriorate the signal quality and even may cause service drops. Deselecting this option does not affect network performance.

McUtranNcellNumOptSwtich: If this option is deselected and the number of neighboring UTRAN cells contained in the measurement configuration reaches the maximum number stipulated in 3GPP specifications, some UEs cannot detect unknown neighboring UTRAN cells by using ANR. In this case, no new neighbor relationship with a UTRAN cell can be added to the NRT, and the UEs cannot be handed over to unknown neighboring UTRAN cells, causing service drops. If this option is selected, UEs can detect unknown neighboring UTRAN cells and be handed over to unknown neighboring UTRAN cells in the same situation.

ReduceMeasCtrlMesNumSwitch: If this option is selected, the eNodeB includes E-RAB update information and measurement configuration in a single RRC Connection Reconfiguration message. This reduces the probability of service drops due to too many such messages over the Uu interface. If this option is deselected, the number of RRC Connection Reconfiguration messages increases, which may increase the probability of service drops due to too many such messages over the Uu interface.

ServiceReqInterFreqBlindHoSw: If this option is selected, the number of measurements for service-based inter-frequency handovers decreases, reducing the VoIP service setup delay. However, UEs may be transferred to non-optimal cells because of blind handovers and the voice quality may deteriorate after the handovers.

HOSuccRateBoostOptSwitch: If the HOSuccRateBoostOptSwitch option is selected, more CCEs are consumed on the PDCCH, and fewer UEs can be scheduled on the PDCCH. More interference to PDCCH symbols of neighboring cells occurs, resulting in problems such as decrease in the cell throughput and the number of UEs accessing the network.

HoSuccCounterMeasCtrlSwitch: If this option is selected, the number of successful inter-RAT handovers decrease.
