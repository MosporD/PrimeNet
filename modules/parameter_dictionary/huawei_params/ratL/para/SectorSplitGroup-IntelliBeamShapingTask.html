MML Command

STR INTELLIGENTBEAMSHAPING
Meaning

Indicates whether to enable functions related to intelligent beam shaping tasks.

PATTERN_ADJ_SWITCH: Indicates whether to enable pattern adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

POWER_ADJ_SWITCH: Indicates whether to enable power adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

PATTERN_ADJ_ENH_SWITCH: Indicates whether to enable enhanced pattern adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

Impact on Radio Network Performance

PATTERN_ADJ_SWITCH: If this option is selected, the pattern adjustment function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the pattern adjustment function will take effect for one week. This function enables main lobe directions of the antennas for the split cells to adaptively change with UE distribution, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.

POWER_ADJ_SWITCH: If this option is selected, the power adjustment function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the power adjustment function will take effect for one week. This function enables the downlink transmit power of the split cell to be adjusted to maximize power usage, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.

PATTERN_ADJ_ENH_SWITCH: If this option is selected, the pattern adjustment enhancement function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the pattern adjustment enhancement function will take effect for one week. This function enhances the UE-distribution-based adjustment of main lobe directions of the antennas for the split cells, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.
