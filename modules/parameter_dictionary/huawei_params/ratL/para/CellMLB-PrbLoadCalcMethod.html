Meaning

Indicates the PRB load calculation method when the MlbTriggerMode parameter in the CellMLB MO is set to PRB_ONLY or PRB_OR_UE_NUMBER. The value PRB_USAGE indicates that the PRB usage is used as the PRB load. The value PRB_VALUATION_WITH_CTRL indicates that the PRB load is calculated based on PRB evaluation for channels including control channels. The value PRB_VALUATION_NO_CTRL indicates that the PRB load is calculated based on PRB evaluation for channels excluding control channels. If this parameter is set to PRB_USAGE, the total PRB usage of multiple cells is more likely to reach the maximum value. If this parameter is set to PRB_VALUATION_WITH_CTRL or PRB_VALUATION_NO_CTRL, the transmission rate of each service is more likely to exceed the minimum guaranteed value. Set this parameter based on network requirements. This parameter applies only to LTE FDD and LTE TDD.
