Meaning

Indicates the minimum interval of uplink compensation scheduling for UEs running unlimited voice services If this parameter is set to INTERVAL_OFF(OFF), uplink enhanced scheduling is disabled for UEs running unlimited voice services. If this parameter is not set to INTERVAL_OFF(OFF), uplink enhanced scheduling is enabled for UEs running unlimited voice services, and the value indicates the minimum interval of uplink compensation scheduling for such UEs. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

When this parameter is set to a value other than INTERVAL_OFF(OFF), UEs running unlimited voice services are scheduled with a higher priority in the uplink. A small value of this parameter indicates a small minimum interval of uplink compensation scheduling for such UEs during a call, increasing the probability of triggering uplink compensation scheduling. In this case, fewer voice packets are lost in the uplink due to missing SR detection. As a result, the voice quality is better, but more scheduling resources are consumed, lowering the traffic and the throughput. A large value of this parameter indicates a large minimum interval of uplink compensation scheduling for such UEs during a call, reducing the probability of triggering uplink compensation scheduling. In this case, less scheduling resources are consumed, but more voice packets are lost due to missing SR detection, lowering the voice quality.
