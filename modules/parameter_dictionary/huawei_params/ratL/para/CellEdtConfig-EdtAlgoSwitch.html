Meaning

Indicates whether to enable EDT.

EDT_SWITCH: Indicates whether to enable EDT in the cell. If this option is selected, the cell supports EDT and UEs can perform EDT services in the cell. If this option is deselected, the cell does not support EDT. This option applies only to NB-IoT.

EDT_L_VALUE_COMPAT_SWITCH: Indicates whether to determine the value of L based on Msg3 for EDT. If this option is selected, the value of L for NB-IoT UEs involved in single-tone transmission is determined based on the repetition count of Msg3 on the NPUSCH. If this option is deselected, the value of L is fixed at 1 for NB-IoT UEs involved in single-tone transmission. This option applies only to NB-IoT.

EDT_SWITCH: If the setting of this option is changed, the cell will be reestablished.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

EDT_SWITCH: If this option is selected, UEs in idle mode can transmit data using EDT, reducing the air interface delay and power consumption. However, EDT requires dedicated RACH resources to be configured, decreasing the cell uplink traffic volume. If this option is deselected, UEs can transmit data after an RRC connection is set up.

EDT_L_VALUE_COMPAT_SWITCH: If this option is selected, NB-IoT UEs for which the repetition count of Msg3 for EDT is 8 or greater and the value of L is 4 cannot access the network normally. If this option is deselected, NB-IoT UEs for which the repetition count of Msg3 for EDT is 8 or greater and the value of L is 1 cannot access the network normally.
