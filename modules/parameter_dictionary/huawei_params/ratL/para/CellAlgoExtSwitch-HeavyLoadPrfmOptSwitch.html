Meaning

Indicates whether to optimize performance in LampSite cells in scenarios where the inter-cell distance is small and the load is heavy.

INTRF_BASED_INTER_FREQ_HO_SW: Indicates whether to enable interference-based inter-frequency handover. Interference-based inter-frequency handover is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PUSCH_INTRF_RSRP_HIGH_THLD_SW: Indicates whether to optimize uplink power control. If this option is selected, the RSRP of interference to neighboring cells will be restricted to avoid exceeding the value of the PuschIntrfRsrpHighThld parameter in the CellPcAlgo MO in PUSCH closed-loop power control. If this option is deselected, this restriction does not take effect. This option applies only to LTE FDD and LTE TDD.

UL_RS_PWR_ADAPT_SW: Indicates whether to enable uplink RS power adaptation. If this option is selected, the cell supports uplink RS power adaptation. If this option is deselected, the cell does not support uplink RS power adaptation. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

INTRF_BASED_INTER_FREQ_HO_SW: If this option is selected in scenarios where the inter-cell distance is small and the load is heavy, uplink interference between cells decreases and uplink rates increase. If this option is deselected in these scenarios, the preceding effects will not be produced.

PUSCH_INTRF_RSRP_HIGH_THLD_SW: If this option is selected in scenarios where the inter-cell distance is small and the load is heavy, uplink interference between cells decreases, the uplink rates of non-cell-edge UEs increase, and the rates of cell-edge UEs decrease. If this option is deselected in these scenarios, the preceding effects will not be produced.

UL_RS_PWR_ADAPT_SW: If this option is selected in scenarios where the inter-cell distance is small and the load is heavy, the RS power of the cell serving a larger number of UEs decreases. This results in a decreased number of UEs and increased uplink rates in this cell, but an increased number of UEs and decreased uplink rates in neighboring cells. If this option is deselected in these scenarios, the preceding effects will not be produced.
