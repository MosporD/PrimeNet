NE

MML Command

MOD HOMEASCOMM

LST HOMEASCOMM
Meaning

Indicates the penalty timer length for not allowing handovers to an NG-RAN cell when handover preparation fails due to resource-related causes during a handover to this NG-RAN cell. If this parameter is set to 0, penalty is not performed. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter leads to a larger number of invalid handover requests initiated after handover preparation fails due to resource-related causes. A larger value of this parameter leads to a smaller number of such invalid handover requests. However, if this parameter is set to an excessively large value, UEs may experience service drops due to delayed handovers.
