MML Command

MOD CELLRICALGO

Meaning

Indicates whether to enable adaptive avoidance of remote interference. If this parameter is set to ON(On), characteristic sequences are sent and detected to adaptively avoid remote interference. This parameter applies only to LTE TDD cells.

Parameter Relationship

-Configuration constraints:

  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo is set to ON, the value of FddTddInd in a CELL MO is only to be set CELL_TDD, and the value of SubframeAssignment in a CELL MO is only to be set SA2, and the value of SpecialSubframePatterns in a CELL MO is only to be set SSP5 or SSP6 or SSP7 or SSP9.
  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo MO is set to ON, the value of MultiRruCellFlag in a CELL MO is only to be set BOOLEAN_FALSE.
  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DuctDLSubfrmShutoffSwitch parameter in the same MO is set to ON(On).
  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DUCT_DL_SUBFRM_SHUTOFF_OPT_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.
  • The DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the CellRicAlgo MO must be deselected when the RemoteInfAdpAvoidSwitch parameter in the same MO is set to ON.
