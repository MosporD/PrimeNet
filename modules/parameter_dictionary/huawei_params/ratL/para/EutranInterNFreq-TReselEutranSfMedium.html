Meaning

Indicates the scaling factor applied to the cell reselection duration for medium-mobility UEs. This parameter is delivered in SIB5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter leads to a shorter decision duration of reselection to a cell on a neighboring E-UTRAN frequency for a medium-mobility UE, and therefore a higher probability of reselection to a cell on the frequency for the UE. A larger value of this parameter leads to the opposite effects. If the value of this parameter is too large or too small, the access success rate is affected.
