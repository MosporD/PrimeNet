Meaning

Indicates the offset relative to the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. When the PRB usage is greater than the PRB usage threshold plus the threshold offset, the LTE network requires the spectrum shared with the NR network. When the PRB usage is less than or equal to the PRB usage threshold minus the threshold offset, the LTE network does not require the spectrum shared with the NR network. This parameter applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In an LteNrSpctShrCellGrp MO, the value of the PrbUsageThldOffset parameter must be less than or equal to that of the PrbUsageThld parameter.
  • In an LteNrSpctShrCellGrp MO, the sum of the PrbUsageThldOffset and PrbUsageThld parameter values must be less than or equal to 100.

Impact on Radio Network Performance

Set this parameter based on the load on the live network to allocate LTE spectrum suitably and maximize spectral efficiency. An excessively large value of this parameter may cause the LTE cell to retain its current spectrum usage and a low probability that the LTE cell shares spectrum or receives shared spectrum. An excessively small value of this parameter may lead to ping-pong handovers and cause the LTE cell to frequently share spectrum or receive shared spectrum.
