EDT Early Contention Resolution Mode

Parameter ID EdtEarlyContentionResMode

EDT Early Contention Resolution Mode
NE

MML Command

MOD CELLEDTCONFIG

LST CELLEDTCONFIG
Meaning

Indicates the early contention resolution mode used for EDT in a cell. If this parameter is set to OFF, early contention resolution is not supported. In this case, SRB0 and the contention resolution MCE must be delivered at the same time. If this parameter is set to SRB0_CONTENTION_RES_SPLIT_SCH, SRB0 and the contention resolution MCE are separately scheduled. If this parameter is set to ADAPTIVE, the cell adaptively determines whether to use early contention resolution based on the value of the contention resolution timer. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

If this parameter is set to OFF and the value of the EDT downlink data waiting timer is too large and that of the contention resolution timer is too small, the probability that UEs cannot receive Msg4 due to scheduling delay increases and UEs even cannot access the network. If this parameter is set to SRB0_CONTENTION_RES_SPLIT_SCH or ADAPTIVE, the contention resolution MCE occupies air interface resources, causing downlink traffic volume to decrease.
