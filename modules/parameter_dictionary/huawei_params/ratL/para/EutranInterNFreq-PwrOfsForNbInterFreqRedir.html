Meaning

Indicates the power offset of NB-IoT UEs used to trigger inter-frequency redirection. If this parameter is set to NULL, this parameter is not delivered in RRC Connection Release messages. In this case, the UEs regard that the power offset is 0 dB by default. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

When this parameter is set to a value other than NULL, a larger value leads to a higher probability that NB-IoT UEs in the coverage overlap area will be redirected to the target inter-frequency cell, and a smaller value leads to the opposite effect.
