LST NRSCGFREQCONFIG
Meaning

Indicates the time-to-trigger for NR frequency measurement event B1. Event B1 is not immediately reported at the moment that the signal quality of an NR cell meets the condition for triggering measurement reports for event B1. Instead, it is reported if the signal quality always meets the condition within the period specified by this parameter. This parameter reduces accidentally reported event B1. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
