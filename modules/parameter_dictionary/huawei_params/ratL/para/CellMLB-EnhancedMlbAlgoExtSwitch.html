Meaning

Indicates whether to enable extended MLB algorithm enhancement. This parameter provides the following options: UL_EXP_BASED_CA_TFC_STEER_SW: If this option is deselected, RRC_CONNECTED CA UEs configured with SCells cannot be transferred in uplink-experience-oriented service steering. If this option is selected, RRC_CONNECTED CA UEs configured with SCells can be transferred in uplink-experience-oriented service steering. This option applies only to LTE TDD.

BLIND_MM_LOAD_STEERING_SW: If this option is selected, blind load transfer from massive MIMO cells to inter-frequency non-massive-MIMO cells is enabled. If this option is deselected, blind load transfer from massive MIMO cells to inter-frequency non-massive-MIMO cells is disabled. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

UL_EXP_BASED_CA_TFC_STEER_SW: If this option is selected, the eNodeB can transfer CA UEs with large uplink traffic when uplink user experience deteriorates. This helps improve uplink user experience. Deselecting this option has no impact on network performance.

BLIND_MM_LOAD_STEERING_SW: If this option is selected, the eNodeB can transfer load from a massive MIMO cell to its neighboring cells with which there is no X2-interface-based information exchange. This helps increase user-perceived data rates. Deselecting this option has no impact on network performance.
