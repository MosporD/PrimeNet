Parameter Name

TCP MSS Threshold
NE

MML Command

MOD TCPMSSCTRL

LST TCPMSSCTRL
Meaning

Indicates the threshold for the value of the MSS field in packets for TCP link setups. If the TCP MSS function is enabled, the eNodeB first checks the MSS field in each packet for TCP link setups. If the value of the MSS field is greater than the predefined threshold, the eNodeB changes the value of the MSS field to the predefined threshold. Then, the eNodeB recalculates the TCP checksum and retransmits the packet with modified fields. For other packets, the eNodeB transparently transmits them.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

Caution

The value of this parameter is correlated with the minimum MTU among all devices on the transmission path. In addition, overheads of headers such as IP header, TCP header, and GTP-U header must be considered. The recommended formula for calculating the parameter is as follows: TcpMssThd value = Minimum MTU bytes - Bytes of all packet headers. The minimum MTU bytes can be queried by running the TRACERT command.

Generally, the size of all packet headers in non-security-tunnel scenarios is 80 bytes. The security-tunnel headers must be considered in security-tunnel scenarios.

The size of security-tunnel headers ranges from 58 bytes to 78 bytes, which differs according to the algorithm for negotiating between the eNodeB and SeGW. If the size of security-tunnel headers cannot be obtained, it is recommended that 78 bytes be used to calculate the TcpMssThd parameter value.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

A smaller value of this parameter indicates a smaller MSS field value in packets for TCP link setups. If this parameter value is too small, transmission efficiency decreases and the throughput is reduced. If this parameter value is too large, the MSS control function does not take effect.
