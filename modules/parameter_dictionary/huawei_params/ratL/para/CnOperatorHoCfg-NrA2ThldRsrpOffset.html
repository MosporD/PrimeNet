Parameter ID NrA2ThldRsrpOffset
Parameter Name

NR A2 Threshold RSRP Offset
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CNOPERATORHOCFG

LST CNOPERATORHOCFG
Meaning

Indicates the offset for NG-RAN event A2 relative to the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO. The sum of this offset, the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO, and the value of the NrA2RsrpThldOffset parameter in the CnOperatorQciPara MO is taken as the RSRP threshold for NG-RAN event A2. This parameter applies only to LTE FDD and LTE TDD.
