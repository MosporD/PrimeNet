Meaning

Indicates whether to optimize the power control algorithm.

OUTER_LOOP_PUCCH_PC_OPT_SW: Indicates whether to enable PUCCH outer-loop power control optimization. If this option is selected, PUCCH power decrease is allowed when there is no data transmission. If this option is deselected, PUCCH power decrease is not allowed when there is no data transmission. This option applies only to LTE TDD.

Impact on Radio Network Performance

OUTER_LOOP_PUCCH_PC_OPT_SW: If this option is selected, PUCCH power decrease is allowed when there is no data transmission. As a result, the BER of the local cell increases but interference to neighboring cells decreases. If this option is deselected, the BER of the local cell decreases but interference to neighboring cells increases when there is no data transmission.
