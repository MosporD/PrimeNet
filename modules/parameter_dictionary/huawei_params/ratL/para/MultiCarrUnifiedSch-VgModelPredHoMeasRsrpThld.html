Meaning

Indicates the RSRP prediction accuracy level threshold based on which a virtual grid model is selected for predicting the RSRP used for evaluation in inter-frequency unnecessary handovers. Inter-frequency unnecessary handovers include service-based inter-frequency handover, inter-frequency handover for load balancing, inter-frequency handover for smart carrier selection based on virtual grids.

If this parameter is set to ACCURACY95_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY90_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY80_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY80_OFFSET5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 10 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET15, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 15 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET20, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 20 dB before the evaluation.

If this parameter is set to ACCURACY100_OFFSET0, the eNodeB does not use virtual grid models to predict the RSRP used for evaluation in unnecessary handovers.

If this parameter is set to ACCURACY90_OFFSET_5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY90_OFFSET_10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 10 dB before the evaluation.

If this parameter is set to ACCURACY95_OFFSET_5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY95_OFFSET_10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 10 dB before the evaluation.

This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A lower accuracy level threshold specified by this parameter results in a higher probability that a virtual grid model is selected in measurement result prediction for unnecessary handovers, but lower accuracy of predicting the optimal neighboring cell.

A higher accuracy level threshold specified by this parameter results in a lower probability that a virtual grid model is selected in measurement result prediction for unnecessary handovers, but higher accuracy of predicting the optimal neighboring cell.

A larger RSRP offset specified by this parameter results in a higher probability of unnecessary handovers. A smaller RSRP offset specified by this parameter results in a lower probability of unnecessary handovers.
