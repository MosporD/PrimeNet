Meaning

Indicates whether LTE and NR share RRU carrier and CPRI data resources. If LTE and NR share optical fibers, they will share RRU carrier and CPRI data resources when this parameter is set ON. They will use their respective RRU carrier and CPRI data resources when this parameter is set to OFF. This parameter applies only to LTE FDD.

Caution

Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

When this parameter is set to ON, LTE and NR consume one set of carrier resources and CPRI bandwidth. When this parameter is set to OFF, LTE and NR consume two sets of carrier resources and CPRI bandwidth.
