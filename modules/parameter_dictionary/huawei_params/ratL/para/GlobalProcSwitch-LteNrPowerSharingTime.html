NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates the time segments in which dynamic power sharing between LTE and NR takes effect. Dynamic power sharing between LTE and NR can be enabled in different time segments based on traffic distribution on the live network. This parameter applies only to LTE TDD.
