Meaning

Indicates the operators corresponding to an SCC. The characters from the left to the right in the parameter value correspond to the operator indexes of the local eNodeB. The character can be assigned with a value either 0 or 1. If the character is assigned with a value 1, the SCC can be used by the corresponding operator. If the character is assigned with a value 0, the SCC cannot be used by the corresponding operator. The eNodeB filters the SCCs based on the operators which a CA UE accesses. If the corresponding operator index is invalid, the eNodeB ignores it. For example: 100100 indicates that the SCC belongs to the operators whose operator indexes are 0 and 3. This parameter does not take effect on the LMPT, and if the LMPT is used, the SCC can be used by all operators. This parameter applies only to LTE FDD and LTE TDD.
