Meaning

Indicates whether to continue delivering RRC Connection Release signaling carried by SRB1 when the number of SRB1 retransmissions has reached the maximum at the RLC layer. If this parameter is set to OFF, the eNodeB stops SRB1 scheduling and no longer delivers the RRC Connection Release signaling when the number of SRB1 retransmissions has reached the maximum at the RLC layer. If this parameter is set to ON, the eNodeB continues SRB1 scheduling and delivers RRC Connection Release signaling when the number of SRB1 retransmissions has reached the maximum at the RLC layer. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If abnormal UEs do not reply with RLC status reports and therefore service drops occur, setting this parameter to ON increases the number of RRC Connection Release message transmissions and decreases the number of RRC connection reestablishments. As a result, the downlink PRB usage, ARQ retransmission rate, and BLER increase. Setting this parameter to OFF has no impact on network performance.
