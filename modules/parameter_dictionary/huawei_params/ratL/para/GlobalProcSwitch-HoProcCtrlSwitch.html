Meaning

Indicates whether to control the handover process. This parameter provides the following options:

HoDataSendCtrlSwitch: If this option is selected, the eNodeB sends data packets to a handover-incoming UE after sending a random access response (RAR) in a non-contention-based random access procedure. If this option is deselected, the eNodeB sends data packets to the UE after receiving an Msg3 message in the non-contention-based random access procedure. This option applies only to LTE FDD and LTE TDD.

CsfbFlowFirstSwitch: Indicates the policy for handling the conflicts between handover and CSFB procedures. If this option is selected and the handover and CSFB procedures conflict, the eNodeB processes the CSFB procedure first. If this option is deselected in the preceding scenario, the eNodeB processes the handover procedure first. This option applies only to LTE FDD and LTE TDD.

GwcnIncomingHoWithoutHrlSwitch: Indicates whether the eNodeB determines whether to accept an incoming handover based on the HRL. If this option is deselected, the eNodeB directly rejects the incoming handover when not receiving the HRL from the EPC. If this option is selected, the eNodeB does not reject the incoming handover when not receiving the HRL from the EPC. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

HoDataSendCtrlSwitch: If this option is selected, the user-plane latency in handovers decreases because the eNodeB sends data packets ahead. If the UE fails to access the target cell during a handover, sending data packets ahead causes exceptions and the packet loss rate increases. If the UE does not support receiving data packets after receiving the RAR message, the BLER and packet loss rate of the target cell increase. Deselecting this option has no impact on network performance.

CsfbFlowFirstSwitch: If this option is selected and the eNodeB receives a CSFB request in the event of a handover, the eNodeB cancels the handover procedure and processes the CSFB procedure first. In this case, the UE cannot be handed over in time, increasing the service drop rate and decreasing the handover success rate. However, when the MME cannot handle conflicts between handover and CSFB procedures, selecting this option can increase the CSFB success rate. If this option is deselected in the preceding scenario, the eNodeB processes the handover procedure first. When the MME cannot handle conflicts between handover and CSFB procedures, deselecting this option can decrease the CSFB success rate.

GwcnIncomingHoWithoutHrlSwitch: If this option is selected, the success rates of incoming handovers to GWCN cells increase. However, UEs may not access the serving PLMN in this case.
