Meaning

Indicates whether to enable measurement-related optimization algorithms.

NSA_SA_MEAS_OBJ_PREEMPTION_SW: Indicates whether to enable preemption during measurement configuration when the number of measurement objects for an SA or NSA UE reaches the maximum. If this option is selected, preemption is enabled so that measurement configurations related to high-priority algorithms are preferentially delivered. If this option is deselected, preemption is disabled and the measurement configurations related to algorithms that are subsequently initiated are not delivered. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this option is selected and the number of measurement objects for a UE reaches the maximum, high-priority features or algorithms that are subsequently initiated can start up, improving user experience with critical KPIs (for example, reducing the service drop rate). If this option is deselected and the number of measurement objects for a UE reaches the maximum, high-priority features or algorithms that are subsequently initiated cannot start up. User experience with critical KPIs deteriorates. For example, coverage-based handovers cannot be performed. Only blind redirections can be used. As a result, the service interruption time increases, and service drops may occur.
