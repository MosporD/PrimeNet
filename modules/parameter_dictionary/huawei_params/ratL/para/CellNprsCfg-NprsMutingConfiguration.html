Meaning

Indicates NPRS muting configurations.

In Part A mode, each bit corresponds to 10 consecutive subframes. If the current bit is 1, NPRS is sent within the subframes. If the current bit is 0, NPRS is not sent.

In Part B mode, each bit indicates an NPRS period. If the bit is 1, NPRS is sent within the current NPRS period. If the bit is 0, NPRS is not sent.

For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.

Parameter Relationship

-Configuration constraints:

  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 2_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 3.
  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 4_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 15.
  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 8_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 255.

Caution

If the settings of parameters related to NPRS are changed, the Evolved Serving Mobile Location Center (E-SMLC) needs to resend a request of updating the parameter settings to the eNodeB. If the E-SMLC does not send the request, NPRS measurement for OTDOA-based positioning is affected in the cell.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

If the parameter value indicates more bits being 1, more subframes in the NPRS are sent within an NPRS period, and shorter time is required for the UE to measure NPRS, reducing UE power consumption. In this case, the interference of NPRS in the cell is greater. A parameter value indicating fewer bits being 1 leads to the opposite effects.
