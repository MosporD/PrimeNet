Recommended Value

This parameter can be set by the system by default. The default value is as follows:

If CatType is set to LTE or EUTRA_5GC, then:

QCI 4: Tstatprohibit_m50(50)

QCI 5: Tstatprohibit_m0(0)

QCI 6: Tstatprohibit_m50(50)

QCI 8: Tstatprohibit_m50(50)

QCI 9: Tstatprohibit_m50(50)

If CatType is set to EMTC_MODE_A and RlcPdcpParaGroupId is set to the same value as EmtcModeACl0RlcParaGroupId in the QciPara MO, then:

QCIs 4 to 6, QCI 8, QCI 9, QCI 69, and QCI 70: Tstatprohibit_m50(50)

If CatType is set to EMTC_MODE_A and RlcPdcpParaGroupId is set to the same value as EmtcModeARlcParaGroupId in the QciPara MO, then:

QCIs 4 to 6, QCI 8, QCI 9, QCI 69, and QCI 70: Tstatprohibit_m450(450)

If CatType is set to EMTC_MODE_B, then:

QCIs 4 to 6, QCI 8, QCI 9, QCI 69, and QCI 70: Tstatprohibit_m2000(2000)

If CatType is set to SHORT_TTI, then:

QCI 4: Tstatprohibit_m25(25)

QCI 5: Tstatprohibit_m0(0)

QCI 6: Tstatprohibit_m25(25)

QCI 8: Tstatprohibit_m25(25)

QCI 9: Tstatprohibit_m25(25)

Impact on Radio Network Performance

This parameter has an impact on status reporting in AM. A low frequency of status reporting results in a low frequency of status report scheduling but a high probability that the send window size changes to 0, thereby reducing the transmission rate. A high frequency of status reporting results in a high probability of timely acknowledgment to data in the send window and therefore a high probability of rate assurance. However, a high frequency of status reporting results in a high probability of status report scheduling and repeated transmissions, thereby wasting resources.
