Meaning

Indicates whether to configure Multimedia Broadcast multicast service Single Frequency Network (MBSFN) subframes. The ten options of this parameter map to the ten MBSFN subframes. If an option is selected, the corresponding subframe is configured. If an option is not selected, the corresponding subframe is not configured. PDSCH services with enhanced MIMO applied can be scheduled on configured MBSFN subframes. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

When UEs work in different transmission modes: (1) For TM9 UEs, a larger number of MBSFN subframes lead to higher throughput, and a smaller number of MBSFN subframes lead to lower throughput. (2) For non-TM9 UEs, a larger number of MBSFN subframes lead to lower throughput, and a smaller number of MBSFN subframes lead to higher throughput.
