Meaning

Indicates whether to enable the soft split resource duplex (SSRD) algorithm.

IFSSFuncSwitch: Indicates whether to enable inter-frequency SSRD. If this option is selected, inter-frequency SSRD is enabled. If this option is deselected, inter-frequency SSRD is disabled. This option applies only to LTE TDD.

SsrdSchOptSwitch: Indicates whether to enable scheduling optimization for intra-frequency soft split cells. If this option is selected, the eNodeB performs joint scheduling and multi-user pairing for intra-frequency soft split cells. If this option is deselected, the eNodeB does not perform joint scheduling or multi-user pairing for intra-frequency soft split cells. This option applies only to LTE TDD.

SsrdDlPwrShareSwitch: Indicates whether to enable downlink power sharing for intra-frequency soft split or intelligent beam sharing. If this option is selected, the eNodeB performs downlink power sharing for split cells. If this option is deselected, the eNodeB does not perform downlink power sharing for split cells. This option applies only to LTE TDD.

SsrdMultiBeamMeasSwitch: Indicates whether to perform multi-beam measurements for intra-frequency soft split cells. If this option is selected, the eNodeB performs multi-beam measurements for intra-frequency soft split cells. If this option is deselected, the eNodeB does not perform multi-beam measurements for intra-frequency soft split cells. This option applies only to LTE TDD.

SsrdPdcchAllocOptSwitch: Indicates whether to enable soft split PDCCH allocation optimization for intra-frequency split. If this option is selected, PDCCH allocation optimization is enabled for cells from a split. If this option is deselected, PDCCH allocation optimization is disabled for cells from a split. This option applies only to LTE TDD.

SsrdDynDlPwrSharingSwitch: Indicates whether to enable dynamic downlink power sharing for soft split or intelligent beam sharing. If this option is selected, downlink power sharing is performed for split cells in each TTI. If this option is deselected, downlink power sharing is not performed for split cells in each TTI. This option applies only to LTE TDD.

Impact on Radio Network Performance

IFSSFuncSwitch: If this option is selected, inter-frequency SSRD is enabled, improving network coverage and the user-perceived rate and reducing inter-cell interference and the service drop rate. If this option is deselected, network performance is not affected.

SsrdSchOptSwitch: If this option is selected, the eNodeB performs joint scheduling and multi-user pairing for soft split cells, improving cell capacity when UEs are unevenly distributed. If this option is deselected, network performance is not affected.

SsrdDlPwrShareSwitch: If this option is selected, the eNodeB performs downlink power sharing for split cells, improving cell capacity when UEs are unevenly distributed. If this option is deselected, network performance is not affected.

SsrdMultiBeamMeasSwitch: No impact.

SsrdPdcchAllocOptSwitch: If this option is selected, PDCCH allocation optimization is enabled for cells from a split to increase the MCS index and downlink throughput. If this option is deselected, network performance is not affected.

SsrdDynDlPwrSharingSwitch: If this option is selected, dynamic downlink power sharing is performed for split cells, increasing the MCS index and downlink throughput of QPSK and beamforming UEs. However, this causes interference in adjacent neighboring cells. If this option is deselected, network performance is not affected.
