MML Command

MOD RACHCFG

Meaning

Indicates whether to allow configuration of the PRACH start time. When this parameter is set to NOT_CFG, the PRACH start time is not configurable. The PRACH start time for coverage level 0 is always 8 ms. The PRACH start time for coverage level 1 is determined based on the following factors: the sum of the PRACH start time and PRACH time length for coverage level 0, and the restriction that the PRACH start time interval between two adjacent coverage levels is not less than 40 ms. The PRACH start time for coverage level 2 is determined in a way similar to that for determining the PRACH start time for coverage level 1. If there are PRACH resources used for early data transmission (EDT), the positions of the EDT PRACH subcarriers and those of the common PRACH subcarriers cannot overlap, and the start time and transmission interval of the EDT PRACH must be the same as those of the common PRACH. When this parameter is set to CFG, the PRACH start time for each coverage level is configurable. The PRACH start time interval between two adjacent coverage levels must not be less than 40 ms. Otherwise, cells cannot be activated. This parameter applies only to NB-IoT.
