LST CELLWTTXPARACFG
Meaning

Indicates the upper limit on the number of IPTV UEs for which rate acceleration is used for rate guarantee in a cell where IPTV admission control is used. When the number of UEs running IPTV services in the cell exceeds this limit, the eNodeB no longer accelerates rates for newly admitted IPTV UEs. If this parameter is set to 0, the IPTV admission control function does not take effect. That is, the eNodeB accelerates rates for all IPTV UEs in the cell. If multiple bearers have been set up for a UE, the number of identified IPTV UEs equals the number of bearers carrying IPTV data flows. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter leads to a smaller number of IPTV UEs which are preferentially scheduled for rate guarantee and better experience of IPTV UEs preferentially scheduled during busy hours. A larger value of this parameter leads to a larger number of IPTV UEs which are preferentially scheduled for rate guarantee and experience deterioration of IPTV UEs after the cell capacity is exceeded.
