Parameter Name

BfMimo Algorithm Optimization Switch

MML Command

MOD CELLBFMIMOPARACFG

Meaning

BFTOMIMOALGOOPTSWITCH: Indicates whether to optimize switching from beamforming to MIMO and rank detection for MIMO. If this option is selected, switching from beamforming to MIMO and rank detection for MIMO are optimized to increase the rank 2 success rate. If this option is deselected, switching from beamforming to MIMO or rank detection for MIMO is not optimized. This option applies only to LTE TDD.

BFMIMOADAPWITHOUTTM8: Indicates whether TM8 is available during adaptation between beamforming and MIMO or during open-loop beamforming adaptation. If this option is selected and the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE or TxD_BF_ADAPTIVE, the transmission mode cannot be switched to TM8. If this option is deselected and the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE or TxD_BF_ADAPTIVE, the transmission mode can be switched to TM8. This option applies only to LTE TDD.

FIXEDTM9WPMIOPTSWITCH: Indicates whether UEs can enter closed-loop TM9 mode that always requires PMI feedback from UEs, regardless of channel calibration results. If this option is selected, UEs can enter TM9 mode that always requires PMI feedback from UEs even when the channel calibration results do not meet requirements. If this option is deselected, UEs cannot enter this transmission mode when the channel calibration results do not meet requirements. This option applies only to LTE TDD.

BFMIMOADAPTATIONOPTSW: Indicates whether to enabled optimized adaptation between beamforming and MIMO. If this option is selected, optimized adaptation between beamforming and MIMO is enabled. If this option is deselected, optimized adaption between beamforming and MIMO is disabled. This option applies only to LTE TDD.

HEAVYLOADTRANSMODEADAPTBOOSTSW: Indicates whether to enable enhanced transmission mode adaptation in heavy-load scenarios. If this option is selected, enhanced transmission mode adaptation is enabled in heavy-load scenarios. The eNodeB automatically implements transmission mode adaptation or uses the target transmission mode in heavy-load scenarios to achieve optimal spectral efficiency in the cell. If this option is deselected, enhanced transmission mode adaptation is disabled in heavy-load scenarios. This option applies only to LTE TDD.

HISTORICALSPECTRALEFFOPTSW: Indicates whether to enable historical spectral efficiency optimization when enhanced transmission mode adaptation is enabled in heavy-load scenarios. If this option and the HEAVYLOADTRANSMODEADAPTBOOSTSW option are selected, historical spectral efficiency optimization takes effect. The eNodeB automatically learns historical cell spectral efficiency achieved during transmission mode adaptation and when the target transmission mode is used in heavy-load scenarios, and automatically selects a transmission mode to achieve optimal spectral efficiency in the cell. If this option is deselected when the HEAVYLOADTRANSMODEADAPTBOOSTSW option is selected, historical spectral efficiency optimization does not take effect. In this case, the cell always uses the target transmission mode in heavy-load scenarios. This option applies only to LTE TDD.

BF_WEIGHT_GRAN_OPT_SWITCH: Indicates whether to enable massive MIMO beamforming weight granularity optimization. If this option is selected, the weight granularity is selected based on the SRS SINR. If this option is deselected, the weight granularity is selected based on the original policy. This option applies only to LTE TDD.

NON_AS_UE_MAX_BF_RANK_CTRL_SW: Indicates the maximum number of beamforming multiplexing layers for non-antenna selection UEs in massive MIMO cells. If both the FakeAntSelIdentificationSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO and this option are selected, the maximum number of beamforming multiplexing layers is always rank 1 for non-antenna selection UEs (including fake antenna selection UEs). Otherwise, the maximum number of beamforming multiplexing layers for non-antenna selection UEs (including fake antenna UEs) is specified by the MaxBfRankPara parameter in the CELLBF MO. This option applies only to LTE TDD.

LOAD_BASED_TMA_OPT_SW: Indicates whether to enable load-based adaptive transmission mode optimization. If this option is selected, the transmission mode is selected for UEs based on the cell load during UE access. When the cell load is light, TM3 is preferentially selected. In addition, if the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, 4R UEs and 8R UEs entering PMI feedback-dependent TM9 is accelerated. When the cell load is heavy, beamforming mode is preferentially selected. If this option is deselected, the original transmission mode selection procedure applies. This option applies only to LTE TDD.

INCREASE_SM_LAYER_TMA_OPT_SW: Indicates whether to enable TMA optimization for increasing the number of spatial multiplexing layers in a cell. This function is enabled only if this option is selected. This option applies only to LTE TDD.

Impact on Radio Network Performance

BFTOMIMOALGOOPTSWITCH: If this option is selected when the SINR is high, the proportion of MIMO single codewords decreases, the proportion of MIMO dual codewords increases, and the UE traffic volume increases. If this option is deselected when the SINR is high, the proportion of MIMO single codewords increases, and the UE traffic volume slightly decreases.

BFMIMOADAPWITHOUTTM8: If this option is selected in scenarios where UEs do not support transmit antenna selection or the maximum rank is 1 in beamforming mode, the eNodeB does not switch the transmission mode to TM8, increasing the number of available RBs and UE throughput. If this option is deselected, the eNodeB switches the transmission mode to TM8, lowering the number of available RBs and slightly decreasing the UE traffic volume.

FIXEDTM9WPMIOPTSWITCH: If this option is selected, UEs can enter closed-loop TM9 mode when channel calibration results do not meet requirements, increasing the single UE peak traffic volume. If this option is deselected, UEs cannot enter closed-loop TM9 mode when channel calibration results do not meet requirements, lowering the single UE peak traffic volume.

BFMIMOADAPTATIONOPTSW: If this option is selected, adaptation between beamforming and MIMO is optimized, and UE transmission modes can be switched to better meet channel conditions, improving spectral efficiency and downlink throughput. If this option is deselected, adaptation between beamforming and MIMO is not optimized, and network performance is not affected.

HEAVYLOADTRANSMODEADAPTBOOSTSW: If this option is selected, the eNodeB automatically implements transmission mode adaptation or uses the target transmission mode in heavy-load scenarios to achieve optimal spectral efficiency in the cell, increasing the proportion of beamforming and spectral efficiency during busy hours throughout the network but also slightly increasing the service drop rate. If this option is deselected, this feature does not take effect and cell performance is not affected.

HISTORICALSPECTRALEFFOPTSW: If this option and the HEAVYLOADTRANSMODEADAPTBOOSTSW option are selected, the eNodeB automatically learns historical cell spectral efficiency achieved during transmission mode adaptation and when the target transmission mode is used in heavy-load scenarios, and automatically selects a transmission mode to achieve optimal spectral efficiency in the cell. This increases spectral efficiency during busy hours throughout the entire network but lowers the proportion of beamforming. If this option is deselected when the HEAVYLOADTRANSMODEADAPTBOOSTSW option is selected, the cell always uses the target transmission mode in heavy-load scenarios. In this case, spectral efficiency decreases during busy hours throughout the network, and the proportion of beamforming increases.

BF_WEIGHT_GRAN_OPT_SWITCH: If this option is selected, massive MIMO beamforming weight granularity optimization is enabled, and the weight granularity is selected based on the SRS SINR. If this option is deselected, the optimization is disabled, and the weight granularity is selected based on the original policy.

NON_AS_UE_MAX_BF_RANK_CTRL_SW: If both this option and the FakeAntSelIdentificationSwitch option are selected, the maximum number of beamforming multiplexing layers is always rank 1 for non-antenna selection UEs (including fake antenna selection UEs). This prevents non-antenna selection UEs from entering dual-stream beamforming mode, which leads to performance deterioration. If this option or the FakeAntSelIdentificationSwitch option is deselected, the maximum number of beamforming multiplexing layers is specified by the MaxBfRankPara parameter. If this parameter is set to DUAL_LAYER_BF, non-antenna selection UEs (including fake antenna selection UEs) can enter dual-stream beamforming mode, which lowers the downlink UE throughput when the performance of dual-stream beamforming is poor.

LOAD_BASED_TMA_OPT_SW: If this option is selected, there will be the following impacts: When the cell load is light, the proportion of rank-3 TM3 or PMI feedback-dependent TM9 increases, downlink user-perceived data rates increase, and downlink user spectral efficiency improves. When the cell load is heavy, the proportion of beamforming mode increases, the proportion of downlink multi-user pairing increases, downlink user-perceived data rates increase, and downlink user spectral efficiency improves. If this option is deselected, there will be the following impacts: When the cell load is light, the proportion of single-codeword UE scheduling is large, downlink user-perceived data rates are low, and downlink user spectral efficiency is low. When the cell load is heavy, the proportion of beamforming mode is small, the proportion of downlink multi-user pairing is small, downlink user-perceived data rates are low, and downlink user spectral efficiency is low.

INCREASE_SM_LAYER_TMA_OPT_SW: If this option is selected, a larger proportion of 4R/8R UEs near the cell center results in a lower proportion of transmissions in TM7, a higher proportion of transmissions in TM9, and a larger increase in the downlink user-perceived rate and downlink spectral efficiency. If this option is deselected, transmissions in TM7 are not reduced due to a high proportion of 4R/8R UEs near the cell center and the number of spatial multiplexing layers in a cell is not optimal.
