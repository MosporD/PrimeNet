PollByte for UE

Parameter ID UePollByte
Parameter Name

NE

MML Command

ADD RLCPDCPPARAGROUP

MOD RLCPDCPPARAGROUP

LST RLCPDCPPARAGROUP
Meaning

Indicates the UE-specific data volume threshold of PDUs to trigger polling. When the transmitted data volume reaches the value of this parameter, the Poll flag is set in the PDU header. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

To prevent buffer overflow caused by an excessively long queue, the transmitter sends status reports based on the data volume of transmitted PDUs. A small value of this parameter may result in a high frequency of sending polling PDUs. A large value leads to high buffer occupancy and a slow speed of send window movement.
