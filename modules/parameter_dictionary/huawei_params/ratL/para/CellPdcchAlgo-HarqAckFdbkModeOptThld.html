Meaning

Indicates the threshold for optimizing the HARQ-ACK feedback mode. If HARQ-ACK feedback mode optimization is enabled, the PDCCH load in the cell is greater than this threshold, and the single-frame scheduling mode is used for the UEs, the HARQ-ACK feedback mode of the UEs is reconfigured to the multiplexing mode. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

The HARQ-ACK feedback mode is reconfigured for UEs based on the PDCCH load and UE services in a cell.

A smaller value of this parameter results in a higher probability of reconfiguring Bundling as the HARQ-ACK feedback mode for UEs. A larger value of this parameter leads to the opposite effect. Compared with the Bundling mode, the Multiplexing mode increases the MCS index. In addition, DTX is unavailable in Multiplexing mode so that the CCE aggregation level of the PDCCH cannot be accurately determined and the PDCCH power control cannot be accurately performed. This affects the PDCCH reliability. Therefore, the handover success rate, service drop rate, ping delay, PUCCH coverage performance, and access delay may deteriorate, but the cell throughput, single-UE throughput, and user-perceived rate can be improved.
