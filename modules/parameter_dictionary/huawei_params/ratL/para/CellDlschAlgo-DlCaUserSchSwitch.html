Meaning

Indicates whether to enable functions related to downlink scheduling of CA UEs.

DlCaUserRbPriMcsSelSwitch: Indicates whether to enable the policy of MCS selection with prioritized RBs.

If this option is selected, the policy of MCS selection with prioritized RBs is used for any CA UE for which the traffic volume to be transmitted in the cell is larger than or equal to the maximum traffic volume allocated to the UE based on its capability in this cell on condition that the UE is not very near the cell center. In addition, if the IBLER measured within a period (5 seconds) is less than or equal to 1% for a CA UE after the MCS index is decreased, the CQI will not be adjusted for the UE regardless of whether the HARQ feedback to the scheduling using the decreased MCS index is ACK or NACK. If the IBLER measured within a period (5 seconds) is greater than 1% for this CA UE, the CQI is adjusted for the UE when the HARQ feedback to the scheduling using the decreased MCS index is NACK but not adjusted when the HARQ feedback to the scheduling using the decreased MCS index is ACK.

If this option is deselected, the policy of MCS selection with prioritized RBs is not used for CA UEs. If the MCS index is decreased for a CA UE, the CQI is adjusted for the UE when the HARQ feedback to the scheduling using the decreased MCS index is NACK but not adjusted when the HARQ feedback to the scheduling using the decreased MCS index is ACK. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

DlCaUserRbPriMcsSelSwitch: If this option is selected, the downlink data rate of CA UEs increases when CA UEs' capabilities are limited. However, the number of RBs scheduled in the downlink increases, which causes downlink interference to increase. This may further causes the downlink IBLER, downlink RBLER, and downlink MCS index to increase for non-CA UEs. Deselecting this option has no impacts on downlink network performance. It is recommended that this option be enabled in downlink CA data rate competitive tests.
