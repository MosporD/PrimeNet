MML Command

ADD UACPARAMGROUP

LST UACPARAMGROUP
Meaning

Indicates whether access barring check is required for UEs with a specific access ID. If an option is deselected, UEs with the access ID indicated in this option are allowed to access. If an option is selected, access barring check will be performed for UEs with the access ID indicated in this option when these UEs initiate access. During an access barring check, the UE determines whether it is allowed to access the network based on the uac-BarringFactor and uac-BarringTime IEs in SIB25. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
