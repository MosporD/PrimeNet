Meaning

JTUserCoCellPowerSwitch: Indicates whether to increase the power of the coordinating cell when joint transmission is performed for UEs running unlimited services. If this option is selected, the eNodeB increases the power of the coordinating cell when joint transmission is performed for UEs running unlimited services. If this option is deselected, the eNodeB does not increase the power of the coordinating cell when joint transmission is performed for UEs running unlimited services. This option applies only to LTE TDD. UsSrsOptSwitch: Indicates whether to optimize the SRS reporting period for UEs running unlimited services. If this option is selected, the eNodeB optimizes the SRS reporting period for UEs running unlimited services. If this option is deselected, the eNodeB does not optimize the SRS reporting period for UEs running unlimited services. This option applies only to LTE TDD. UsCellCrsOptSwitch: Indicates whether to perform CRS optimization for a cell where there are UEs running unlimited services. If this option is selected, the eNodeB performs CRS optimization for the cell. If this option is deselected, the eNodeB does not perform CRS optimization for the cell. This option applies only to LTE TDD. UsUeGapSchOptSwitch: Indicates whether to optimize downlink scheduling for UEs running unlimited services when gap-assisted measurement is started. If this option is selected, the eNodeB optimizes downlink scheduling for UEs running unlimited services when gap-assisted measurement is started. If this option is deselected, the eNodeB does not optimize downlink scheduling for UEs running unlimited services when gap-assisted measurement is started. This option applies only to LTE FDD and LTE TDD. UsCellMbsfnSchForbidSw: Indicates whether to prohibit scheduling of NS UEs in MBSFN subframes for a cell where there are UEs running unlimited services. If this option is selected, the eNodeB prohibits scheduling of NS UEs in MBSFN subframes for a cell where UEs running unlimited services reside. If this option is deselected, the eNodeB does not prohibit scheduling of NS UEs in MBSFN subframes for a cell where UEs running unlimited services reside. This option applies only to LTE TDD. MMUeGuaranteeSwitch: Indicates whether to enable all functions related to service guarantee for multiple UEs in massive MIMO scenarios. If this option is selected, the eNodeB enables all functions related to service guarantee for multiple UEs in massive MIMO scenarios. If this option is deselected, the eNodeB disables all functions related to service guarantee for multiple UEs in massive MIMO scenarios. This option applies only to LTE TDD. USPwrSharePaSwitch: If this option is selected, the eNodeB dynamically performs power sharing between carriers of a multi-carrier cell in which UEs running unlimited services reside. This increases the downlink rate of such UEs. If this option is deselected, the eNodeB does not perform power sharing within multi-carrier cells. This option applies only to 8T8R eNodeBs on band D. This option applies only to LTE TDD. EmtcDlThptOptSw: Indicates whether to enable the function of optimizing downlink peak rates of eMTC UEs and downlink throughput of eMTC UEs at the cell edge or at a medium distance from the cell center. The optimization function takes effect only when this option is selected. This option applies only to LTE FDD.

UsUePrdMeasOptSwitch: Indicates whether to enable periodic measurement optimization for UEs running unlimited services. If this option is selected, the eNodeB optimizes periodic measurement for cells serving US UEs and their intra-frequency neighboring cells. In this case, periodic measurement tasks configured on the MAE for these cells, such as periodic MR tasks, are paused. This improves the uplink drive-test data rate of UEs in comparison tests. If this option is deselected, periodic measurement optimization for US UEs does not take effect. This option applies only to LTE FDD and LTE TDD.

UsEmtcHarqAckBundleOptSw: Indicates whether to optimize HARQ-ACK bundling for eMTC UEs that support HARQ-ACK bundling. If this option is selected, the uplink and downlink scheduling time sequence is optimized for eMTC UEs that support HARQ-ACK bundling to increase the total uplink and downlink rates for these UEs. This option applies only to LTE FDD.

UsNbUeThptOptSw: Indicates whether to enable throughput optimization for single NB-IoT UEs. Uplink and downlink throughput optimization for single NB-IoT UEs is enabled only if this option is selected. This option applies only to NB-IoT.

UsPairingOptSwitch: Indicates whether UEs running unlimited services can be paired with common UEs in massive MIMO scenarios. If this option is selected, UEs running unlimited services can be paired with common UEs in the downlink in the cell. If this option is deselected, UEs running unlimited services cannot be paired with common UEs in the downlink in the cell. This option applies only to LTE TDD.

UsCellNsNsaUeSteeringSwitch: Indicates whether to enable user steering for NSA DC UEs running normal services when user steering for UEs running unlimited services is enabled. If this option is selected, user steering is enabled for NSA DC UEs running normal services. If this option is deselected, user steering is disabled for NSA DC UEs running normal services. This option applies only to LTE FDD and LTE TDD.

UsFreqPriStrategySw: Indicates which frequency priority policy is used for NSA DC UEs running unlimited services. If this option is selected, the frequency priority policy for PCC anchoring of NSA DC UEs running normal services is used as the frequency priority policy for NSA DC UEs running unlimited services. If this option is deselected, the frequency priority policy dedicated to LTE UEs running unlimited services is used as the frequency priority policy for NSA DC UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

LteAndNrUsCoordinationOptSw: Indicates whether to optimize the performance of UEs running unlimited services in an NR cell on LTE+NR networks. If this option is selected and there are UEs running unlimited services in an NR cell, the following functions are performed in the LTE cell whose spectrum overlaps with that of the NR cell: interference suppression for neighboring cells serving UEs running unlimited services, downlink RB restriction for common UEs, uplink RB restriction for common UEs, and uplink power reduction for common UEs. If LTE and NR spectrum sharing is enabled in the local cell, the NR_PRI value of the LteNrUlSpectrumShrPriority parameter in the LteNrSpctShrCellGrp MO associated with the cell takes effect. In this case, the LteNrSpctHoProtDuration parameter does not take effect for the NR cell receiving shared spectrum. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

Disuse statement: UsCellMbsfnSchForbidSw: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Parameter Relationship

-Configuration constraints:

  • The JTUserCoCellPowerSwitch option of the UsAlgoExSwitch parameter in a CellUSParaCfg MO can be selected only when the MBSFNSubJTOptSwitch option of the UsAlgoSwitch parameter in the CellUSParaCfg MO is selected.
  • When the UsSrsGuaranteeSwitch parameter in the CellUSParaCfg MO is set to 8_USERS_GUARANTEE(8_USERS_GUARANTEE), 16_USERS_GUARANTEE(16_USERS_GUARANTEE), or 24_USERS_GUARANTEE(24_USERS_GUARANTEE), the UsSrsOptSwitch option of the UsAlgoExSwitch parameter in the CellUSParaCfg MO must be deselected, and the MMUeGuaranteeSwitch option of the UsAlgoExSwitch parameter in the CellUSParaCfg MO must be selected.

Impact on Radio Network Performance

JTUserCoCellPowerSwitch: If this option is selected, the eNodeB increases the power of the coordinating cell when joint transmission is performed for UEs running unlimited services, increasing the downlink throughput. If this option is deselected, the network performance is not affected. UsSrsOptSwitch: If this option is selected, UEs running unlimited data services timely send SRSs, improving downlink beamforming performance and downlink throughput of such UEs. However, the service drop rate may increase. If this option is deselected, the network performance is not affected. UsCellCrsOptSwitch: If this option is selected, the downlink RSRP of UEs running unlimited downlink data services increases, raising the downlink MIMO throughput of such UEs. However, cell coverage may decrease. If this option is deselected, the network performance is not affected. UsUeGapSchOptSwitch: If this option is selected, the eNodeB increases the number of downlink scheduling times for UEs running unlimited services. If this option is deselected, the network performance is not affected. UsCellMbsfnSchForbidSw: If this option is selected and the eNodeB stops scheduling NS UEs in an MBSFN subframe, the impact of retransmission for NS UEs on the number of scheduling times for UEs running unlimited services and the number of RBs allocated to such UEs decreases. The scheduling delay of normal UEs may therefore increase. If this option is deselected, the network performance is not affected. MMUeGuaranteeSwitch: If this option is selected, the eNodeB performs service guarantee during massive MIMO multi-user tests, increasing the cell throughput. If this option is deselected, the network performance is not affected. USPwrSharePaSwitch: If this option is selected, the eNodeB dynamically performs power sharing between carriers of a multi-carrier cell in which UEs running unlimited services reside, increasing the downlink rate of such UEs on carriers with power increase but decreasing coverage of carriers with power decrease. If this option is deselected, the network performance is not affected. EmtcDlThptOptSw: If this option is selected, the downlink data rate of eMTC UEs increases. However, the reporting delay of certain eMTC UEs may be extended, which affects delay-related counters. Deselecting this option does not have this effect.

UsUePrdMeasOptSwitch: If this option is selected, the uplink throughput of US UEs increases when periodic measurement is enabled, but the number of X2 messages between cells serving US UEs and their intra-frequency neighboring cells increases. If this option is deselected, the network performance is not affected.

UsEmtcHarqAckBundleOptSw: If this option is selected, the scheduling time sequence for HARQ-ACK bundling is optimized for eMTC UEs, improving the total uplink and downlink rates. If this option is deselected, the network performance is not affected.

UsFreqPriStrategySw: If this option is selected, independent frequency priority policies are configured for LTE UEs running unlimited services and NSA DC UEs running unlimited services, which allows for the two types of UEs to camp on different frequencies, improving throughput and voice service experience. If this option is deselected, the frequency priority policy for PCC anchoring of NSA DC UEs running unlimited services is the same as the frequency priority policy dedicated to LTE UEs running unlimited services, and this may cause user experience deterioration for one of the two types of UEs.

UsNbUeThptOptSw: If this option is selected, the uplink and downlink rates of NB-IoT UEs increase. If this option is deselected, network performance is not affected.

UsPairingOptSwitch: If this option is selected, UEs running unlimited services can be paired with common UEs. This increases the number of MU beamforming pairing layers if there are UEs running unlimited services. If this option is deselected, UEs running unlimited services cannot be paired with common UEs. In this case, if there is only one UE running unlimited services in the cell, the number of MU beamforming pairing layers is 0.

UsCellNsNsaUeSteeringSwitch: If this option is selected, user steering is enabled for NSA DC UEs running normal services. This assures performance of UEs running unlimited services but may lead to performance loss of NSA DC UEs running normal services. If this option is deselected, performance of NSA DC UEs running normal services is not affected but performance of UEs running unlimited services may be affected.

LteAndNrUsCoordinationOptSw: If this option is selected, the interference of LTE cells to UEs running unlimited services in the NR cell decreases. If LTE and NR spectrum sharing is enabled in the local cell, the RB resources for UEs running unlimited services in the NR cell increase and the performance of these UEs improves. However, the downlink UE throughput, uplink UE throughput, and number of UEs decrease in LTE cells. If this option is deselected, there is no such impact.
