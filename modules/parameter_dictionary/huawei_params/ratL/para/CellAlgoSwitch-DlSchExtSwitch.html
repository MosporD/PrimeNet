MML Command

MOD CELLALGOSWITCH

LST CELLALGOSWITCH
Meaning

Indicates whether to enable downlink scheduling algorithms for a cell. This parameter is an extension of the DlSchSwitch parameter and includes the following options:

CONGEST_VIDEO_RES_CTRL_SWITCH: Indicates whether to restrict the amount of air interface resources allocated to UEs running video services when congestion occurs. If this option is selected, the eNodeB restricts air interface resources allocated to UEs running video services when congestion occurs. If this option is deselected, the eNodeB does not restrict air interface resources allocated to video UEs when congestion occurs. This option applies only to LTE FDD and LTE TDD.

PTT_TBS_BASED_MCS_SEL_SWITCH: Indicates whether to select the MCS index based on the TBS for PTT voice services (with QCI 65, QCI 66, or enhanced extended QCIs). The MCS index is selected based on the TBS in downlink dynamic scheduling for PTT voice services only if this option is selected.

DL_TIME_DIM_EXT_SCH_SWITCH: Indicates whether to adopt the service-based time-differentiated scheduling policy in the downlink. If this option is selected, the eNodeB performs the service-based time-differentiated scheduling policy in the downlink. If this option is deselected, the eNodeB does not perform the service-based time-differentiated scheduling policy in the downlink. This option applies only to LTE TDD.

MIMO_TBSIZE_OPT_SWITCH: Indicates whether to support the scheduling of transport blocks with TBS indexes of 26A and 33A for TM9 and TM10 UEs. The TBS indexes of 26A and 33A are supported only when this option is selected. This option applies only to LTE FDD and LTE TDD.

DL_AMBR_OPT_SWITCH: Indicates whether to enable downlink AMBR optimization. If this option is selected, the eNodeB more accurately restricts the scheduling of the last packet for UEs based on AMBRs. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD.

SN_COMPENSATION_HO_REEST_SW: Indicates whether the eNodeB estimates PDCP SNs at the UE side in immediate reestablishment after handovers. If this option is selected, the eNodeB estimates PDCP SNs at the UE side. The eNodeB adds an estimation amount to the minimum SN among the SNs of the PDCP packets for which an ACK is not received. The new SN is used as the starting SN after the reestablishment. If this option is deselected, the eNodeB does not estimate PDCP SNs received at the UE side. This option applies only to LTE FDD and LTE TDD.

DL_COORD_SCH_EXP_OPT_SW: Indicates whether to enable coordinating scheduling experience optimization for DL CoMP and inter-cell D-MIMO. If this option is selected, coordinating scheduling experience optimization for DL CoMP and inter-cell D-MIMO is enabled. If this option is deselected, coordinating scheduling experience optimization for DL CoMP and inter-cell D-MIMO is disabled. The setting of this option takes effect only if DL CoMP and inter-cell D-MIMO are enabled. This option applies only to LTE TDD.

BEST_EFFORT_GBR_SW: Indicates whether to ensure the best-effort GBR for UEs with a specific QCI or SPID. If this option is selected, the eNodeB ensures the best-effort GBR for UEs with a specific QCI or SPID. If this option is deselected, the eNodeB does not ensure the best-effort GBR for UEs with a specific QCI or SPID. This option applies only to LTE FDD and LTE TDD.

SMART_FSS_SWITCH: Indicates whether to enable smart frequency selective scheduling. If the FreqSelSwitch option of the DlSchSwitch parameter and the SMART_FSS_SWITCH option are both selected, smart frequency selective scheduling takes effect. The eNodeB dynamically adjusts the period of triggering aperiodic CQI reporting from UEs involved in frequency selective scheduling and also adjusts the validity period of aperiodically reported CQIs. Therefore, the settings of the FSUEAperCQITrigPeriod and FSUESbCQIValidityPeriod parameters are invalid in smart frequency selective scheduling. If the SMART_FSS_SWITCH option is deselected, the settings of the FSUEAperCQITrigPeriod and FSUESbCQIValidityPeriod parameters still take effect. This option applies only to LTE FDD and LTE TDD.

PUSCH_1X_SWITCH: Indicates whether to enable the PUSCH 1-0 and PUSCH 1-1 feedback modes. These modes can be used only for short-TTI UEs. If this option is selected, UEs that support reporting on PUSCH 1-0 or PUSCH 1-1 use the corresponding mode to aperiodically report CSI. If this option is deselected, the PUSCH 1-0 and PUSCH 1-1 feedback modes cannot be used. This option applies only to LTE FDD.

Impact on Radio Network Performance

CONGEST_VIDEO_RES_CTRL_SWITCH: If this option is deselected, network performance is not affected. If this option is selected, the eNodeB restricts the amount of resources allocated to UEs running high-rate video services in heavy-load scenarios to improve the experience of other services such as web browsing. However, video experience is affected.

PTT_TBS_BASED_MCS_SEL_SWITCH: If this option is selected, the number of HARQ retransmissions for downlink PTT voice services (with QCI 65, QCI 66, or an enhanced extended QCI) and the IBLER decrease.

DL_TIME_DIM_EXT_SCH_SWITCH: If this option is deselected, network performance is not affected. If this option is selected, the average UE throughput increases when the network is moderately or heavily loaded.

MIMO_TBSIZE_OPT_SWITCH: If this option is selected, the data rates of TM9 and TM10 UEs increase in the cell center. If this option is deselected, network performance is not affected.

DL_AMBR_OPT_SWITCH: If this option is selected, AMBR-based scheduling restriction is more accurate but the user-perceived downlink rate decreases when there are UEs with limited AMBRs. If this option is deselected, network performance is not affected.

SN_COMPENSATION_HO_REEST_SW: If this option is deselected, the PDCP SNs at the eNodeB side may be smaller than the PDCP SNs at the UE side. After a reestablishment, certain data sent to the UE will be discarded. As a result, the UE throughput decreases. If this option is selected, the eNodeB increases the eNodeB PDCP SNs based on the PDCP SN estimation result after a reestablishment. The PDCP SN inconsistency between the eNodeB and UE is relieved. However, the sudden change in PDCP SNs after the reestablishment may cause UE incompatibility.

SMART_FSS_SWITCH: If this option and the FreqSelSwitch option of the DlSchSwitch parameter are both selected, smart frequency selective scheduling is enabled. The eNodeB dynamically adjusts the period of triggering aperiodic CQI reporting from UEs involved in frequency selective scheduling and also adjusts the validity period of aperiodically reported CQIs. This reduces uplink overheads, improving downlink performance in multi-UE heavy-load scenarios. If this option is deselected, network performance is not affected.

PUSCH_1X_SWITCH: If this option is selected, UEs that support reporting on PUSCH 1-0 or PUSCH 1-1 report only wideband information during aperiodic CSI reporting, which reduces the PUSCH overheads. If this option is deselected, network performance is not affected.
