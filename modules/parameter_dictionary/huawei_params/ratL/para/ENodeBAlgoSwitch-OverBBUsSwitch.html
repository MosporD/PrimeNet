Meaning

Indicates whether to enable inter-eNodeB coordination algorithms. This parameter includes the following options:

UlJointReceptionOverBBUsSwitch: Indicates whether to enable uplink coordinated multi-point reception (UL CoMP) between inter-eNodeB cells. This function is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

FreqCfgCaOverBBUsSwitch: Indicates whether to enable inter-eNodeB carrier aggregation (CA) in adaptive CA mode. This function is enabled only when this option is selected. This option takes effect only when the FreqCfgSwitch option of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected. This option is used only if the inter-eNodeB links are eX2 links in ideal backhaul mode or open datalink interface (ODI) links. This option applies only to LTE FDD and LTE TDD.

UlJROverRelaxedBHSw: Indicates whether to enable UL CoMP between cells established on BBPs in different BBUs based on relaxed backhaul. This function is enabled only when this option is selected. This option applies only to LTE FDD.

UlSfnJROverBBUsSwitch: Indicates whether to enable inter-eNodeB joint reception in an SFN cell. This function is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

UlVoiceJROverRelaxedBHSw: Indicates whether to enable UL CoMP between inter-eNodeB cells in relaxed backhaul scenarios for UEs running voice services. This function is enabled only when this option is selected. This option applies only to LTE FDD.

UlDataJROverRelaxedBHSw: Indicates whether to enable UL CoMP between inter-eNodeB cells in relaxed backhaul scenarios for UEs running data services. This function is enabled only when this option is selected. This option applies only to LTE FDD.

TransportCongDetectSw: Indicates whether to detect congestion in X2/eX2 links in non-ideal backhaul mode carrying coordination-based services. This function is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

UlNonVoiceJROverRelaxedBHSw: Indicates whether to enable UL CoMP between inter-eNodeB cells in relaxed backhaul scenarios for UEs not running voice services. This function is enabled only when this option is selected. This option applies only to LTE FDD.

Impact on Radio Network Performance

UlJointReceptionOverBBUsSwitch:

If this option is selected, inter-eNodeB UL CoMP is enabled to increase the uplink throughput of cell edge users (CEUs) and average uplink cell throughput. The increased uplink CEU throughput indicates better uplink coverage performance.

FreqCfgCaOverBBUsSwitch:

If this option is selected, inter-eNodeB CA is enabled to increase the number of UEs with CA applied and improve user experience of UEs in the overlapping areas between eNodeBs.

UlJROverRelaxedBHSw:

If this option is selected, inter-eNodeB UL CoMP based on relaxed backhaul is enabled for UEs in TTI bundling mode to improve the performance of cell-edge UEs in TTI bundling mode and uplink coverage performance for VoLTE services.

UlSfnJROverBBUsSwitch: If this option is selected, UL CoMP is enabled in inter-eNodeB SFN cells to increase the uplink CEU throughput and average uplink cell throughput. The increased uplink CEU throughput indicates better uplink coverage performance.

UlVoiceJROverRelaxedBHSw:

If this option is selected, VoLTE CoMP can improve the performance of cell-edge UEs running VoLTE services and reduce the transmission delay and packet loss rate for such UEs.

UlDataJROverRelaxedBHSw:

If this option is selected, UL CoMP between cells established on BBPs in different eNodeBs based on relaxed backhaul improves the uplink throughput of cell-edge UEs running data services.

TransportCongDetectSw:

If this option is selected, the eNodeB can use available bandwidths to transmit data of coordination-based services, increasing the throughput of such services when transmission bandwidths are insufficient.

UlNonVoiceJROverRelaxedBHSw: If this option is selected, the eNodeB supports uplink inter-eNodeB joint reception based on relaxed backhaul for UEs not running voice services. As a result, the MCS index, IBLER, and uplink cell-edge UE throughput increase.
