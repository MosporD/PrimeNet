NSA DC UE SCG UL Power Rate

MO NsaDcMgmtConfig
Parameter ID NsaDcUeScgUlPowerRate
Parameter Name

NSA DC UE SCG UL Power Rate
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD NSADCMGMTCONFIG

LST NSADCMGMTCONFIG
Meaning

Indicates the index of the proportion of the uplink SCG power of UEs in the LTE-NR NSA DC state. Indexes 1 to 16 indicate proportions 0%, 5%, 10%, 15%, 20%, 30%, 37%, 44%, 50%, 56%, 63%, 70%, 80%, 90%, 95%, and 100%, respectively. If the sum of the proportion of the uplink MCG power and the proportion of the uplink SCG power is 1, the proportion of the uplink SCG power is the proportion indicated by the configured index. If the sum is not 1, the proportion of the uplink SCG power is one minus the proportion of the uplink MCG power. For details, see 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.
