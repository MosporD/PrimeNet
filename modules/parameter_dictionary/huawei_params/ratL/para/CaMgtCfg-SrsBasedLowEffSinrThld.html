SRS-based Low Efficiency UE SINR Threshold
NE

MML Command

MOD CAMGTCFG

LST CAMGTCFG
Meaning

Indicates the SINR threshold for SRSs of UEs. This threshold is used to determine whether a UE is a low-efficiency UE. If this parameter is set to a value other than 255, the eNodeB checks the SINR of a UE's SRSs to determine whether the UE is a low-efficiency UE when FDD+TDD CA is performed for the UE with an LTE TDD cell serving as the PCell. If the SINR of SRSs of the UE is less than this threshold, the eNodeB considers the UE as a low-efficiency UE and changes the LTE FDD cell on an SCC to be the PCell. If this parameter is set to 255, the eNodeB does not perform these operations in such scenarios. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a higher probability that the PCC will be switched to an FDD carrier for SRS-based low-efficient UEs, increasing SRS resource efficiency. However, there is also a higher probability that ping-pong switching occurs. A smaller value of this parameter results in a lower probability that the PCC will be switched to an FDD carrier.
