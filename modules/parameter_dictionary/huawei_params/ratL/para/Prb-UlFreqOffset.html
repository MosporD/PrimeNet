Meaning

Indicates the frequency offset of the PRB uplink central frequency to the uplink frequency. This parameter takes effect only when UlEarfcnCfgInd is set to CFG(Configure). Otherwise, the eNodeB calculates this parameter value based on the rule that RB positions in the uplink and downlink are consistent. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.

Parameter Relationship

-Configuration constraints:

  • If the DeployMode and AnchorCarrierFlag parameters in a Prb MO are set to STAND_ALONE and TRUE, respectively, the DlFreqOffset parameter in this Prb MO must be set to NEG_0DOT5. If the DeployMode parameter in a Prb MO is not set to STAND_ALONE, the AnchorCarrierFlag parameter in this Prb MO is set to TRUE, and the LteDlRbIndex parameter in this Prb MO is set to an invalid value, then the DlFreqOffset parameter in this Prb MO must be set to NEG_2, NEG_1, POS_0, or POS_1.
  • The differences between the uplink frequencies of the PRBs specified in the Prb MOs in which the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or UL_ONLY, and the DeployMode parameters are set to STAND_ALONE must not be greater than the result of 20 MHz minus 200 kHz.
  • If the number of Prb MOs in which the LocalCellId parameters are set to the same value and the DeployMode parameters are set to STAND_ALONE are greater than two, the spacing between the uplink center frequencies of the PRBs specified in the Prb MOs in which the WorkMode parameters are set to UL_DL or UL_ONLY must be an integer multiple of 15 kHz.

-Parameter relationship with conditions:

  • If LteUlRbIndex is set to 255, UlFreqOffset must be set.
