Meaning

Indicates whether the eNodeB supports UL 64QAM for UEs compliant with 3GPP Release 12 and later. This parameter is valid only when the Qam64Enabled parameter in the PUSCHCfg MO is set to BOOLEAN_TRUE. When R12Qam64Enabled is set to BOOLEAN_TRUE, the eNodeB supports UL 64QAM for UEs compliant with 3GPP TS 36.331 V12.7.0 or later as well as for UEs compliant with versions earlier than 3GPP TS 36.331 V12.7.0. When R12Qam64Enabled is set to BOOLEAN_FALSE, the eNodeB does not support UL 64QAM for certain UEs, except CAT5 and CAT8 UEs, that comply with versions later than 3GPP TS 36.331 V12.7.0.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

Setting this parameter to BOOLEAN_TRUE has no impact on network performance. If this parameter is set to BOOLEAN_FALSE, serious bit errors will occur in the demodulation of UL data modulated using MCSs of indexes 21 to 24, affecting network performance.
