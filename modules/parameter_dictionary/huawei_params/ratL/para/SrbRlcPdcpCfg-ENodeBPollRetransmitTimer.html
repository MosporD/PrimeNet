Meaning

Indicates the length of the polling PDU retransmission timer for the eNodeB. If you need to change the parameter value, contact Huawei technical support. This parameter applies only to LTE FDD and LTE TDD.

Default Value

Tpollretrans_m45(45)
Recommended Value

This parameter can be set by the system by default. The default value is as follows:

If SrbId is set to SRB1 or SRB2, then: Tpollretrans_m45(45)

If SrbId is set to SRB1_EMTC_MODEA_CL0 or SRB2_EMTC_MODEA_CL0, then: Tpollretrans_m45(45)

If SrbId is set to SRB1_EMTC_MODEA or SRB2_EMTC_MODEA, then: Tpollretrans_m800(800)

If SrbId is set to SRB1_EMTC_MODEB_CL2 or SRB2_EMTC_MODEB_CL2, then: Tpollretrans_m2000(2000)

If SrbId is set to SRB1_EMTC_MODEB or SRB2_EMTC_MODEB, then: Tpollretrans_m2000(2000)

If SrbId is set to SRB1_SHORT_TTI or SRB2_SHORT_TTI, then: Tpollretrans_m25(25)

Impact on Radio Network Performance

If this parameter is set to a small value, excessive polling PDUs are retransmitted. In addition, the number of ARQ retransmissions reaches its maximum due to consecutive PDU retransmissions, and therefore the RRC connection is reestablished. If this parameter is set to a large value, status reports cannot be sent promptly.
