Meaning

Indicates the type of UEs to be transferred for inter-frequency MLB excluding connected mode offload.

SynchronizedUE: If this option is selected, synchronized UEs are transferred for inter-frequency user-number-based MLB. This option applies only to LTE FDD and LTE TDD.

IdleUE: If this option is selected, UEs in idle mode are transferred for inter-frequency user-number-based MLB. This option applies only to LTE FDD and LTE TDD.

PrbMlbSynchronizedUE: If this option is selected, synchronized UEs are transferred for inter-frequency PRB-usage-based MLB. This option applies only to LTE FDD and LTE TDD.

PrbMlbIdleUE: If this option is selected, UEs in idle mode are transferred for inter-frequency PRB-usage-based MLB. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

SynchronizedUE: If this switch is on, UL-synchronized UEs are transferred for load balancing. The number of UEs in the source cell decreases quickly, and the average data rate for the rest UEs in the source cell increases.

IdleUE: If this switch is on, the RRC Connection Release messages containing dedicated cell reselection frequency priorities are sent to UEs with UE inactivity timers timing out, and these UEs are reselected to the specified frequencies. Because the transferred UEs are in idle mode, service interruption is irrelevant, and load balancing in the source cell is achieved in an implicit manner.

PrbMlbSynchronizedUE: If this switch is on, UL-synchronized UEs are transferred for PRB-usage-based load balancing. The PRB load in the source cell decreases quickly, and the average data rate for the rest UEs in the source cell increases.

PrbMlbIdleUE: If this switch is on, the RRC Connection Release messages containing dedicated cell reselection frequency priorities are sent to UEs with UE inactivity timers timing out, and these UEs are reselected to the specified frequencies. Because the transferred UEs are in idle mode, service interruption is irrelevant, and PRB-usage-based load balancing in the source cell is achieved in an implicit manner.

If multiple switches are on, UEs in corresponding types are transferred for load balancing.

If none of the switches are on, no UE is transferred for load balancing.
