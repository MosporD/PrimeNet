Meaning

Indicates whether an intelligent optimization rule is activated. If the parameter value is set to ACTIVATED, the intelligent optimization rule is activated. If the parameter value is set to DEACTIVATED, the intelligent optimization rule is deactivated and does not take effect. This parameter applies only to LTE FDD and LTE TDD.
