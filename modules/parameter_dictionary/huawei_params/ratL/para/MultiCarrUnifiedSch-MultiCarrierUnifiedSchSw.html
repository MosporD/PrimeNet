Meaning

Indicates whether to enable the multi-carrier unified scheduling algorithms.

SMART_CARRIER_SELECTION_SW: Indicates whether to enable smart carrier selection. If this option is selected, the eNodeB can select the optimal carriers or carrier combinations for UEs based on the air interface quality of inter-frequency neighboring E-UTRAN cells predicted using virtual grid models. When the UMPTb is used, the UMPTB_ENHANCEMENT_SWITCH option of the ServiceMode parameter in the eNodeBResModeAlgo MO must also be selected for smart carrier selection to take effect. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SMART_CARRIER_SELECTION_ENH_SW: Indicates whether to enable enhanced smart carrier selection, including improvement of virtual-grid-based spectral efficiency prediction accuracy and smart carrier selection for non-CA UEs at initial access. If this option is selected, enhanced smart carrier selection is enabled. When the UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the ServiceMode parameter in the eNodeBResModeAlgo MO must also be selected for improvement of virtual-grid-based spectral efficiency prediction accuracy to take effect. If this option is deselected, the preceding functions are disabled. This option applies only to LTE FDD and LTE TDD.

CA_CONCURRENCY_SCH_CAPB_ENH_SW: If this option is selected, the eNodeB increases the maximum number of concurrently processed CA UEs with SCells activated. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SPECTRUM_EFF_EVALUATION_OPT_SW: If this option is selected, the eNodeB selects carriers preferentially based on cell-level average spectral efficiency when the following conditions are met: (1) The eNodeB obtains the inter-frequency spectral efficiency using measurements. (2) UEs report the measurement results of only one inter-frequency neighboring cell on certain frequencies to be evaluated or the level of the serving frequency increases or decreases by 5 dB or more during evaluation. If this option is deselected, the eNodeB selects carriers based on UE-level spectral efficiency. This option applies only to LTE FDD and LTE TDD.

ULTRA_LOW_LATENCY_SCH_SW: If this option is selected, scheduling with ultra-low latency for CA is enabled. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SCC_ADAPT_COV_THLD_SW: If this option is selected, the RSRP thresholds used for SCell addition and removal are adaptively extended. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

MOBILITY_ADAPT_COV_THLD_SW: If this option is selected, the RSRP threshold of the serving cell used for coverage-based inter-frequency handovers and the level threshold of the target cell used for smart carrier selection are adaptively extended. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

FAST_MOVING_UE_LOAD_CALC_SW: If this option is selected, the eNodeB considers the load of each carrier when selecting carriers for fast-moving UEs. If this option is deselected, the eNodeB does not consider the load of each carrier when selecting carriers for fast-moving UEs. This option applies only to LTE FDD and LTE TDD.

Disuse statement: CA_CONCURRENCY_SCH_CAPB_ENH_SW: This option has been replaced by the ULTRA_LOW_LATENCY_SCH_SW option of the MultiCarrUnifiedSch.MultiCarrierUnifiedSchSw parameter (the corresponding command is MOD MULTICARRUNIFIEDSCH) and will be removed in a later version. Although the configuration interface in this version still supports synchronization and delivery of the setting of this option, the system no longer uses this option. Therefore, avoid using this option.

Impact on Radio Network Performance

SMART_CARRIER_SELECTION_SW: If this option is selected, user-perceived data rates increase. If this option is deselected, network performance is not affected.

SMART_CARRIER_SELECTION_ENH_SW: If this option is selected, user-perceived data rates increase. If this option is deselected, network performance is not affected.

CA_CONCURRENCY_SCH_CAPB_ENH_SW: If this option is selected, user-perceived data rates increase. If this option is deselected, network performance is not affected.

SPECTRUM_EFF_EVALUATION_OPT_SW: If this option is selected, the counters related to the handover success rate and service drop rate can be optimized but the downlink throughput decreases. If this option is deselected, network performance is not affected.

ULTRA_LOW_LATENCY_SCH_SW: If this option is selected, downlink average UE throughput increases. If this option is deselected, network performance is not affected.

SCC_ADAPT_COV_THLD_SW: If this option is selected, the configuration rate of CA UEs improves, thereby increasing downlink throughput. However, data transmission indicators, such as the IBLER, deteriorate. If this option is deselected, network performance is not affected.

MOBILITY_ADAPT_COV_THLD_SW: If this option is selected, the traffic absorbing capability of high frequency bands improves, thereby increasing downlink throughput. However, this may lead to deterioration of signaling-plane indicators, such as the handover success rate and the service drop rate. If this option is deselected, network performance is not affected.

FAST_MOVING_UE_LOAD_CALC_SW: If this option is set to its recommended value, downlink throughput of fast-moving UEs increases. Otherwise, downlink throughput of fast-moving UEs decreases.
