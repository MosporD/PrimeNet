Meaning

Indicates the reference signal received power (RSRP) threshold for triggering event A4 during higher-priority cell evaluation for PCell selection in scenarios where CA is configured based on CA groups. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a higher probability of a CA UE camping on the local cell and less impact on network performance. A smaller value of this parameter results in a higher probability of triggering event A4 and a larger number of handover failures caused by incorrect handover evaluations.
