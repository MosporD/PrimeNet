Meaning

Indicates whether to enable multi-user beamforming (MU beamforming). This parameter is valid only if the BfSwitch option of the BfAlgoSwitch parameter is selected.

MuBfSwitch: Indicates whether to enable MU beamforming in the downlink for a cell. If this option is selected, MU beamforming in the downlink is enabled for a cell (or an SFN physical cell). If this option is deselected, MU beamforming in the downlink is disabled for a cell (or an SFN physical cell). This option applies only to LTE TDD.

TM9MuBfSwitch: Indicates whether to enable MU beamforming in the downlink for closed-loop TM9 UEs in a cell. The setting of this option takes effect only when the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected. If this option is selected, the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected, and the TM9Switch option of the EnhMIMOSwitch parameter is selected, MU beamforming in the downlink is enabled for closed-loop TM9 UEs in a cell. If this option is deselected, MU beamforming in the downlink is disabled for closed-loop TM9 UEs in a cell. This option applies only to LTE TDD.

MubfResAdjSwitch: Indicates whether to enable MU beamforming resource adjustment. The setting of this option takes effect only when the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected. If this option is selected and the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected, downlink resource adjustment for MU beamforming is enabled for the cell. If this option is deselected, downlink resource adjustment for MU beamforming is disabled for the cell. This option applies only to LTE TDD.

HarqRetranPairSwitch: Indicates whether to enable MU beamforming for UEs subjected to HARQ retransmissions. This option is valid only if the MuBfSwitch option of the MuBfAlgoSwitch parameter is selected. If both the MuBfSwitch option and this option are selected, MU beamforming is enabled for UEs subjected to HARQ retransmissions in the cell. If this option is deselected, MU beamforming is disabled for UEs subjected to HARQ retransmissions in the cell. This option applies only to LTE TDD.

SplitSdmaSwitch: Indicates whether to enable split SDMA for massive MIMO cells. If this option is selected, adaptation between MU beamforming and split SDMA for the PDSCH is supported. If this option is deselected, split SDMA for the PDSCH is not supported. This option applies only to LTE TDD.

TurboBfSwitch: Indicates whether to enable turbo beamforming in WTTx scenarios. If both the MuBfSwitch and TurboBfSwitch options are selected, turbo beamforming takes effect in 8T8R normal cells.

TM9SplitSdmaSwitch: Indicates whether downlink closed-loop TM9 UEs can participate in split SDMA. When the TM9HybridPrecodingSwitch and SplitSdmaSwitch options are selected: (1) If this option is selected, closed-loop TM9 UEs can participate in split SDMA. (2) If this option is deselected, closed-loop TM9 UEs cannot participate in split SDMA. This option applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In the CellAlgoSwitch MO, the TM9MuBfSwitch option can be selected under the MuBfAlgoSwitch parameter only if the MuBfSwitch option is selected under the MuBfAlgoSwitch parameter or the SfnCbfSwitch option is selected under the SfnAlgoSwitch parameter.
  • In the CellAlgoSwitch MO, the MubfResAdjSwitch option can be selected under the MuBfAlgoSwitch parameter only if either of the following conditions is met: The MuBfSwitch option is selected under the MuBfAlgoSwitch parameter or the SfnCbfSwitch option is selected under the SfnAlgoSwitch parameter.
  • If DMIMOJTSwitch of DMIMOAlgoSwitch in a CellAlgoSwitch MO is selected, MuBfSwitch of MuBfAlgoSwitch in the CellAlgoSwitch MO must be selected.
  • The MuBfSwitch option of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO must be selected if the InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • When the NoSrsSccMuBfSwitch option of the NoSrsSccBfAlgoSwitch parameter in a CellAlgoSwitch MO is selected, the MuBfSwitch option of the MuBfAlgoSwitch parameter in this CellAlgoSwitch MO must be selected.

Impact on Radio Network Performance

The TM9MuBfSwitch and MubfResAdjSwitch options can be selected only when the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected. The HarqRetranPairSwitch option can be selected only when the MuBfSwitch option is selected.

If the MuBfSwitch option of this parameter or the SfnCbfSwitch option of the SfnAlgoSwitch parameter is selected, MU beamforming is enabled. The pairing can be performed between a maximum of two layers when LBBPd boards are used or four layers when UBBP boards are used, which increases the average downlink cell throughput in heavy-load scenarios.

MubfResAdjSwitch: It is recommended that this option be selected. If this option is selected, MU beamforming can be used to adjust resources in light-load scenarios, reducing the interference of the cell to neighboring cells or the number of residual small packets generated when two UEs are paired for MU beamforming.

TM9MuBfSwitch: If this option is selected, MU beamforming is enabled for closed-loop TM9 UEs in a heavily loaded cell, increasing the average downlink cell throughput. Do not select this option if a cell is lightly loaded or MU beamforming is not required for closed-loop TM9 UEs in a cell. It is recommended that the TM9MuBfSwitch option be deselected because MU beamforming for closed-loop TM9 UEs has poorer performance than that for TM8 or open-loop TM9 UEs.

HarqRetranPairSwitch: If this option is selected, MU beamforming is enabled for UEs subjected to HARQ retransmissions, increasing the average downlink cell throughput. However, the downlink BLER may increase. If this option is deselected, MU beamforming is disabled for UEs subjected to HARQ retransmissions, decreasing the gains in the average downlink cell throughput, but stabilizing the downlink BLER.

SplitSdmaSwitch: If this option is selected, split SDMA for the PDSCH is supported, improving spectral efficiency and the user-perceived rate. If this option is deselected, expected gains cannot be obtained.

TurboBfSwitch: If this option is selected, the MU beamforming algorithm in the turbo beamforming feature can be optimized in WTTx scenarios, increasing the number of pairing layers and spectral efficiency. If this option is deselected, the MU beamforming algorithm in the turbo beamforming feature cannot be optimized in WTTx scenarios. In this case, the number of pairing layers and spectral efficiency do not increase, and expected performance gains cannot be achieved.

TM9SplitSdmaSwitch: If this option is selected, closed-loop TM9 UEs can participate in split SDMA to obtain TM9 multi-stream pairing gains. However, some TM7 UEs cannot participate in pairing due to beam conflicts. If this option is deselected, no TM9 multi-stream pairing gains can be produced.
