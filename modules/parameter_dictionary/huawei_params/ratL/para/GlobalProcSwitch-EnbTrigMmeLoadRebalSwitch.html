Meaning

Indicates whether to enable eNodeB-triggered MME load rebalancing. When this parameter is set to ON(On), the eNodeB releases the RRC connection for a UE with the cause value "loadBalancingTAUrequired" if the UE accesses the cell using an S-TMSI that is associated with an overloaded MME. This ensures that the UE can be routed to a lightly loaded MME if it initiates another access request. When this parameter is set to OFF(Off), the eNodeB sends an RRCConnectionRelease message with the cause value "other" to the UE to release its RRC connection.

Impact on Radio Network Performance

If this parameter is set to ON, the number of RRC connection setup procedures drops in scenarios with overloaded MMEs.

The RRC connection setup success rate almost remains unchanged if UEs are evenly distributed.

In scenarios where the MMEs are overloaded and UEs are unevenly distributed with more cell edge users (CEUs) (such UEs have a relatively low RRC connection setup success rate), the number of RRC connection setup procedures drops, thereby decreasing RRC connection setup failures and possibly increasing the RRC connection setup success rate.

In scenarios where the MMEs are overloaded and UEs are unevenly distributed with more UEs near and at medium distances from the cell center (such UEs have a relatively high RRC connection setup success rate), the number of RRC connection setup procedures drops, thereby decreasing successful RRC connection setups and possibly decreasing the RRC connection setup success rate.
