Meaning

Indicates the SRS power control algorithm, which can be the SINR-based SRS power control algorithm, SRS power control algorithm based on the converged SINR and RSRP, and SINR-based adaptive SRS power control algorithm. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If SINR-based SRS power control is used, the weight evaluation accuracy of beamforming and DL CoMP UEs can be improved. In this case, there is a high probability that the performance is improved but the number of RRCReconfig messages increases.

If SRS power control based on the converged SINR and RSRP is used, the number of RRCReconfig messages is decreased with the weight evaluation accuracy of beamforming and DL CoMP UEs guaranteed (that is, performance of such UEs is guaranteed).

If SINR-based adaptive SRS power control is used, weight evaluation for beamforming and DL CoMP UEs is more accurate in dense networking mode. In this case, the performance is significantly improved, but the number of RRCReconfig messages may increase.
