NSA DC Algorithm Extension Switch

MO NsaDcMgmtConfig
Parameter ID NsaDcAlgoExtSwitch
Parameter Name

NSA DC Algorithm Extension Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD NSADCMGMTCONFIG

LST NSADCMGMTCONFIG
Meaning

Indicates whether to enable extended LTE-NR NSA DC algorithms.

SCG_ADD_PCC_ANCHOR_VOL_OPT_SW: If this option is selected, the eNodeB deducts the traffic volume of control PDUs when it evaluates the traffic volume for traffic-volume-based SCG addition or PCC anchoring. If this option is deselected, the function does not take effect. This option applies only to LTE FDD and LTE TDD.

INSTANT_JUDGEMENT_SW: Indicates whether to enable fast NSA DC traffic volume decision. If this option is selected, millisecond-level instantaneous values are used for decision of traffic-volume-based NSA DC PCC anchoring and SCG addition. If this option is deselected, second-level filtered values are used for decision of traffic-volume-based NSA DC PCC anchoring and SCG addition. This option applies only to LTE FDD and LTE TDD.

PERIODIC_SCG_ADD_OPT_SW: Indicates whether to decouple periodic PCC anchoring and periodic SCG addition for NSA DC UEs. If this option is selected, the interval between the eNodeB's periodic SCG addition attempt and the last SCG addition attempt should be greater than the NsaDcMgmtConfig.ScgAdditionInterval parameter value. If this option is deselected, then both the interval between the eNodeB's periodic SCG addition attempt and the last SCG addition attempt and the interval between the eNodeB's periodic SCG addition attempt and the last PCC anchoring attempt should be greater than the NsaDcMgmtConfig.ScgAdditionInterval parameter value. This option applies only to LTE FDD and LTE TDD.

INTRA_ENODEB_NSA_DC_HO_ADM_SW: Indicates whether a source cell determines whether an intra-eNodeB target cell is in the MLB high load state when intra-eNodeB NSA DC PCC anchoring is triggered. If this option is deselected for the target cell, the source cell determines whether the intra-eNodeB target cell is in the MLB high load state. If the target cell is in the MLB high load state, the handover will not be executed. If the target cell is not in the MLB high load state, the handover can be executed. If this option is selected for the target cell, the source cell does not determine whether the intra-eNodeB target cell is in the MLB high load state. In this case, handovers triggered for NSA DC PCC anchoring can be executed without considering whether the target cell is in the MLB high load status. This option applies only to LTE FDD and LTE TDD.

OTHER_CG_PHR_VIRTUAL_MODE_SW: In EN-DC dynamic power sharing scenarios, if this option is deselected, the "phr-ModeOtherCG-r12" IE is set to REAL and UEs report the power of the serving cell; if this option is selected, the "phr-ModeOtherCG-r12" IE is set to VIRTUAL and UEs do not report the power of the serving cell. For details about the "phr-ModeOtherCG-r12" IE, see 3GPP TS 36.331 and 3GPP TS 36.213. This option applies only to LTE FDD and LTE TDD.

A2_HO_SCG_ADD_PCC_ANCHOR_SW: Indicates whether to allow SCG addition or PCC anchoring after receiving A2 measurement reports related to coverage-based handovers of NSA DC UEs. If this option is selected, SCG addition and PCC anchoring are allowed. If this option is deselected, SCG addition and PCC anchoring are not allowed. This option applies only to LTE FDD and LTE TDD.

VOLUME_BASED_PCC_ANCHORING_SW: Indicates whether to enable traffic-volume-based PCC anchoring for NSA DC UEs for which SCGs have been added. If this option is selected, whether periodic PCC anchoring for NSA DC UEs for which SCGs have been added is triggered based on the traffic volume is controlled by the NsaDcMgmtConfig.NsaDcAlgoSwitch:VOLUME_BASED_PERIODIC_TRIG_SW option, and whether the first NR-coverage-based PCC anchoring for NSA DC UEs for which SCGs have been added after incoming coverage-based handovers is triggered based on the traffic volume is controlled by the NsaDcMgmtConfig.NsaDcAlgoSwitch:VOLUME_BASED_PERIODIC_TRIG_SW and NsaDcMgmtConfig.NsaDcAlgoSwitch:NSA_DC_VOLUME_BASED_SCG_ADD_SW options. If this option is deselected, traffic volume is not checked for the first NR-coverage-based PCC anchoring after incoming coverage-based handovers and periodic PCC anchoring for NSA DC UEs for which SCGs have been added. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

SCG_ADD_PCC_ANCHOR_VOL_OPT_SW: If this option is selected, invalid SCG addition or PCC anchoring triggered by control PDUs is prevented. As a result, the number of times an SCG is added and the number of handovers triggered by the PCC anchoring decrease. If this option is deselected, network performance is not affected.

INSTANT_JUDGEMENT_SW: If this option is selected, it is more likely that traffic-volume-based NSA DC PCC anchoring and SCG addition can be triggered. If this option is deselected, network performance is not affected.

PERIODIC_SCG_ADD_OPT_SW: If this option is selected, there are the following impacts: (1) The waiting time for periodic SCG addition is shortened under the following conditions: NR coverage is available, traffic volume is sufficient, the SCG is not released when periodic PCC anchoring is triggered, and the interval between SCG release and periodic PCC anchoring is less than the SCG addition interval. (2) The throughput of UEs in the NSA DC state fluctuates when periodic PCC anchoring is triggered by measurement-based SCG addition. If this option is deselected, periodic PCC anchoring for NSA DC UEs affects periodic SCG addition, and the waiting time for traffic-volume-based SCG addition is prolonged under the following conditions: NR coverage is available, traffic volume is sufficient, the SCG is not released when periodic PCC anchoring is triggered, and the interval between SCG release and periodic PCC anchoring is less than the SCG addition interval.

INTRA_ENODEB_NSA_DC_HO_ADM_SW: If this option is selected, the number of handovers and the number of NSA DC PCC anchoring procedures increase. If this option is deselected, network performance is not affected.

OTHER_CG_PHR_VIRTUAL_MODE_SW: If this option is deselected, UEs report the power of the serving cell, which occupies uplink resources. If this option is selected, UEs do not report the power of the serving cell, which does not occupy uplink resources.

A2_HO_SCG_ADD_PCC_ANCHOR_SW: If this option is deselected, SCG addition and NSA DC PCC anchoring are not allowed for NSA DC UEs in the handover area. In this case, user experience is not improved. If this option is selected, SCG addition and NSA DC PCC anchoring are allowed in the handover area. In this case, NSA services can be performed, improving user experience. However, if the handover area is narrow, the handover success rate may be affected and UEs may even experience service drops. Therefore, it is not recommended that this option be selected in this scenario.

VOLUME_BASED_PCC_ANCHORING_SW: If this option is selected, network performance is not affected. If this option is deselected, traffic volume is not checked for the first NR-coverage-based PCC anchoring after incoming coverage-based handovers and periodic PCC anchoring for NSA DC UEs for which SCGs have been added. In this case, NSA DC PCC anchoring can be triggered by small-packet services but UE measurements and UE power consumption increase.
