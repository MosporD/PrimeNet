Parameter Relationship

-Configuration constraints:

  • If the value of the FreqBand parameter in a Prb MO is set to Band 111 or Band 222, the UlEarfcnCfgInd parameter must be set to CFG.
  • If the DeployMode and AnchorCarrierFlag parameters in a Prb MO are set to STAND_ALONE and TRUE, respectively, the DlFreqOffset parameter in this Prb MO must be set to NEG_0DOT5. If the DeployMode parameter in a Prb MO is not set to STAND_ALONE, the AnchorCarrierFlag parameter in this Prb MO is set to TRUE, and the LteDlRbIndex parameter in this Prb MO is set to an invalid value, then the DlFreqOffset parameter in this Prb MO must be set to NEG_2, NEG_1, POS_0, or POS_1.
  • Among the Prb MOs with the same LocalCellId setting: (1) The DlEarfcn parameter must be set to different values in the Prb MOs in which the LteDlRbIndex parameter is set to an invalid value and the WorkMode parameter is set to UL_DL or DL_ONLY. (2) The DlEarfcn parameter must be set to different values in the Prb MOs in which the WorkMode parameter is set to UL_DL or UL_ONLY. Specifically, if the UlEarfcnCfgInd parameter in a Prb MO is set to CFG and the LteUlRbIndex parameter in this Prb MO is set to an invalid value, the UL EARFCN of the corresponding PRB is specified by the UlEarfcn parameter in this Prb MO; if the UlEarfcnCfgInd parameter in a Prb MO is not set to CFG and the WorkMode and LteDlRbIndex parameters in this Prb MO are set to UL_DL and an invalid value, respectively, the UL EARFCN of the corresponding PRB is automatically calculated based on the values of the DlEarfcn and DlFreqOffset parameters in this Prb MO given that the system is symmetrical in the uplink and downlink.
  • The differences between the uplink frequencies of the PRBs specified in the Prb MOs in which the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or UL_ONLY, and the DeployMode parameters are set to STAND_ALONE must not be greater than the result of 20 MHz minus 200 kHz.
  • In a Prb MO, if the DeployMode parameter is set to STAND_ALONE, the WorkMode parameter is set to UL_DL, and the DlFreqOffset parameter is not set to NEG_0DOT5, then the UlEarfcnCfgInd parameter in this Prb MO must be set to CFG.
  • If the number of Prb MOs in which the LocalCellId parameters are set to the same value and the DeployMode parameters are set to STAND_ALONE are greater than two, the spacing between the uplink center frequencies of the PRBs specified in the Prb MOs in which the WorkMode parameters are set to UL_DL or UL_ONLY must be an integer multiple of 15 kHz.
  • In a Prb MO, if WorkMode is set to UL_DL, DeployMode is set to IN_BAND, and UlEarfcnCfgInd is set to CFG, then LteDlRbIndex and LteUlRbIndex must be both set to invalid or valid values.

-Parameter relationship with conditions:

  • If WorkMode is set to UL_DL, UL_ONLY, UlEarfcnCfgInd is valid.
