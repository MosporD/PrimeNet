Meaning

Indicates a customized downlink bandwidth configured for a cell. A compact bandwidth can be configured only when a standard bandwidth 1.4 MHz, 5 MHz, 10 MHz, 15 MHz, or 20 MHz has been configured. This parameter applies only to LTE FDD.

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, when NbCellFlag in a Cell MO is set to FALSE and CustomizedBandWidthCfgInd is set to CFG: If DlBandWidth is set to CELL_BW_N6, CustomizedDLBandWidth must be set to a value in the range of 12 to 14; If DlBandWidth is set to CELL_BW_N25, CustomizedDLBandWidth must be set to a value in the range of 44 to 50; If DlBandWidth is set to CELL_BW_N50, CustomizedDLBandWidth must be set to a value in the range of 74, 75, 80 or 87 to 100; If DlBandWidth is set to CELL_BW_N75, CustomizedDLBandWidth must be set to a value in the range of 139 to 150; If DlBandWidth is set to CELL_BW_N100, CustomizedDLBandWidth must be set to a value in the range of 175 to 178 or 183 to 200.
  • In a Cell MO, if CustomizedBandWidthCfgInd is set to CFG, CustomizedULBandWidth and CustomizedDLBandWidth cannot both be set to 14, 50, 100, 150, or 200.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 12~14, 44~50, 139~150, or 175~178, DlPuncturedRbNum must be set to 255.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 96~100 or 193~200, DlPuncturedRbNum must be set to 255 or 0.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 92~95 or 190~192, DlPuncturedRbNum must be set to 255, 0, or 2.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 186~189, DlPuncturedRbNum must be set to 255, 0, 2, or 4.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 183~185, DlPuncturedRbNum must be set to 255, 0, 2, 4, or 6.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 88~91, DlPuncturedRbNum must be set to 255, 2, or 4.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 80, DlPuncturedRbNum must be set to 255 or 8.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74, 75, or 87, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to NORMAL, the DlPuncturedRbNum parameter in this Cell MO must be set to 255.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74 or 75, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 8, 9, 10, 11, 12, or 13.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 87 and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, REDUCED_LEFT, or REDUCED_RIGHT, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 3, 4, 5, 6, or 7.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74 or 75, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED_LEFT, or REDUCED_RIGHT, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 9, 10, 11, 12, or 13.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74 or 75, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED_LEFT or REDUCED_RIGHT, the UlPuncturedRbNumOffset parameter in this Cell MO must be set to 3, 2, 1, 0, -1, -2, -3, -4, or -5.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to a value in the range of 44 to 47, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, then the UlPuncturedRbNumOffset parameter in this Cell MO must be set to 4, 3, 2, 1, 0, or -1, and the MultiRruCellMode parameter in this Cell MO must not be set to MPRU_AGGREGATION.
  • The CompactBwCtrlIntrfMode parameter in a Cell MO can be set to REDUCED only if the CustomizedDLBandWidth parameter in this Cell MO is set to 74~75, 87, 146~149, or 175~178. In other situations, the CompactBwCtrlIntrfMode parameter in a Cell MO must be set to NORMAL.
  • When CustomizedBandWidthCfgInd parameter in a Cell MO is set to CFG, the CompactBwCtrlIntrfMode parameter in this Cell MO can be set to REDUCED_LEFT, or REDUCED_RIGHT only if the CustomizedDLBandWidth parameter in this Cell MO is set to 74 to 75, 87, or 175 to 178.

-Parameter relationship with conditions:

  • If CustomizedBandWidthCfgInd is set to CFG, CustomizedDLBandWidth must be set.
