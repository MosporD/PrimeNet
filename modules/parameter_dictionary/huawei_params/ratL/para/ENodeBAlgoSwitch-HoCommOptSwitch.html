Meaning

Indicates whether to enable optimization on handover-related common configurations and algorithms.

L2UBasedHoPolicyPenaltySwitch: Indicates whether to differentiate between PS HO and SRVCC for penalty and retry after E-UTRAN-to-UTRAN operation failures (which may be admission failures due to non-resource reasons or handover failures after handover command delivery). The eNodeB differentiates between PS HO and SRVCC for penalty and retry only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LaiCsfbBlindNCellSelSwitch: Indicates the policy of determining a target cell for LAI-based CSFB in a blind manner (not based on measurements). If this option is selected, the eNodeB preferentially selects the neighboring cell with the highest blind handover priority; if multiple cells have the same priority, the eNodeB selects a cell with the same LAI as the source cell. If this option is deselected, the eNodeB preferentially selects the neighboring cell with the same LAI as the source cell; if multiple cells have the same LAI, the eNodeB selects a cell with the highest blind handover priority. This option applies only to LTE FDD and LTE TDD.

TrigQuanBothMeasOptSw: Indicates whether to independently enable RSRP- and RSRQ-based inter-frequency or inter-RAT measurements when both inter-frequency and inter-RAT A1/A2 measurements are enabled. If this option is selected, the eNodeB starts RSRP-based inter-frequency or inter-RAT measurements after receiving RSRP-triggered event A2 and starts RSRQ-based inter-frequency or inter-RAT measurements after receiving RSRQ-triggered event A2. If this option is deselected, the eNodeB starts only one type of measurement. That is, the eNodeB starts only RSRP-based inter-frequency or inter-RAT measurements if it receives RSRP-triggered event A2 first and the same rules applies to RSRQ. This option applies only to LTE FDD and LTE TDD.

GapCfgOptSwitch: If this option is selected, the gap allocation algorithm optimizes scheduling resources in a unified manner. If this option is deselected, gaps are configured using the original gap allocation method. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

L2UBasedHoPolicyPenaltySwitch: If this option is selected, the eNodeB differentiates between PS HO and SRVCC when imposing penalties on UEs. During the PS-HO-induced penalty period, SRVCC can be initiated to ensure timely handovers for users using voice services, thereby decreasing the call drop rate. Similarly, during the SRVCC-induced penalty period, PS HO can be initiated to ensure timely PS handovers, thereby decreasing the service drop rate. If L2UBasedHoPolicyPenaltySwitch is off and a UE fails to be admitted due to a non-resource reason during PS HO, the eNodeB imposes a PS-HO-induced penalty on the UE and does not initiate SRVCC for the UE during the PS-HO-induced penalty period, which delays SRVCC and increases the service drop rate. If a UE fails to be admitted due to a non-resource reason during SRVCC, the eNodeB imposes an SRVCC-induced penalty on the UE and does not initiate PS HO during the SRVCC-induced penalty period, which delays PS HO and increases the service drop rate.

LaiCsfbBlindNCellSelSwitch: If this option is selected, the flash CSFB validation rate and PS-HO-based CSFB success rate increase, but location area update (LAU) may be required and the delay is prolonged. If this switch is off, LAU is avoided and therefore the delay is shortened, but the flash CSFB validation rate and PS-HO-based CSFB success rate decrease.

TrigQuanBothMeasOptSw: If this option is selected, the service drop rate decreases and the throughput increases. However, the number of handovers increases and the number of RRC connection reestablishments decreases. If this option is deselected, the service drop rate may increase and the throughput may decrease if the UE continuously performs measurements but failed to be handed over in time. In this case, the number of handovers decreases and the number of RRC connection reestablishments increases.

GapCfgOptSwitch: If this option is selected, there is a lower probability that gap measurement resources conflict with scheduling resources, improving UE scheduling performance. If this option is deselected, there is a lower probability that gap measurement resources conflict with scheduling resources, affecting UE throughput.
