Meaning

Indicates the threshold for the low load state of the SRI resources. The SRI resources enter the low load state if the PUCCH resource allocation algorithm detects that the number of admitted UEs is smaller than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

Default Value

10
Recommended Value

In FDD mode, the recommended value is 0 for bandwidths of 1.4 MHz and 3 MHz, 10 for bandwidths of 5 MHz and 10 MHz, and 20 for bandwidths of 15 MHz and 20 MHz.

In TDD mode with the SubframeAssignment parameter set to SA0 or SA1, the recommended value is 0 for bandwidths of 1.4 MHz and 3 MHz, and 5 for bandwidths of 5 MHz, 10 MHz, 15 MHz, and 20 MHz.

In TDD mode with the SubframeAssignment parameter set to SA2 or SA5, the recommended value is 0 for all bandwidths.

If a competition test on the access delay or handover delay is to be conducted with UL preallocation disabled, set this parameter to a value greater than 1.

It is recommended that the default value of the parameter be retained. If adjustments are mandatory, avoid setting this parameter to an excessively large value as it may lead to incorrect decisions on the load status of SRI resources.

A value smaller than or equal to 20 is recommended if the cell bandwidth is below 10 MHz. A value smaller than or equal to 40 is recommended if another cell bandwidth is used.

Impact on Radio Network Performance

A smaller value results in a larger SRI capacity in the cell, a smaller number of UEs for which short SRI periods are configured, and longer access delay of the network. A larger value results in a larger number of UEs for which short SRI periods are configured and a smaller SRI capacity in the cell.
