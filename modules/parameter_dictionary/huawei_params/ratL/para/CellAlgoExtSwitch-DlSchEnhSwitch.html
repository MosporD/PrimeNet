Meaning

Indicates whether to enable downlink scheduling algorithms in the cell. This parameter includes the following options:

OUTER_LOOP_DSCP_QOS_MGMT_SW: Indicates whether to enable QoS management based on outer-loop DSCP. If this option is selected, QoS management based on outer-loop DSCP takes effect. If this option is deselected, QoS management based on inner-loop DSCP instead of outer-loop DSCP takes effect. This option is valid only when the VideoRateAdaptSwitch option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO is selected. The setting of this option must be consistent with the DSCP policy set in the core network. This option applies only to LTE FDD and LTE TDD.

APERIODIC_CQI_RPT_OPT_SW: Indicates whether to optimize aperiodic CQI reporting. If this option is selected, aperiodic CQI reporting is more timely. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

2D_FSS_SWITCH: Indicates whether to enable two-dimensional frequency selective scheduling. When both the SMART_FSS_SWITCH and 2D_FSS_SWITCH options are selected, two-dimensional frequency selective scheduling takes effect. When either option is deselected, two-dimensional frequency selective scheduling does not take effect. This option applies only to LTE FDD.

SMALL_PKT_MCS_CQI_ADJ_SW: Indicates whether to adjust CQIs for small packets for which the MCS index is reduced. If this option is selected, the CQI will not be adjusted for the scheduling for which a low-index MCS is reselected and the HARQ feedback is ACK. Reselection of a low-index MCS is enabled when the SmallPktMcsSelectAlgoSw option is selected. If this option is deselected, the CQI will be adjusted for the scheduling meeting the preceding conditions. This option applies only to LTE FDD.

MIN_GBR_OPT_SWITCH: Indicates whether to enable downlink minimum GBR guarantee optimization. If this option is selected, downlink minimum GBR guarantee optimization is enabled. If this option is deselected, downlink minimum GBR guarantee optimization is disabled. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

OUTER_LOOP_DSCP_QOS_MGMT_SW: If this option is selected in weak coverage scenarios, the service drop rate may increase. If this option is selected in scenarios where the proportion of forwarded packets is high, delays are greatly affected, probably causing the downlink packet loss rate to increase in the cell. When this option is deselected, QoS management based on inner-loop DSCP is used, probably causing the service drop rate to increase in weak coverage scenarios.

APERIODIC_CQI_RPT_OPT_SW: If this option is selected, the number of aperiodic CQI reporting times increases. If downlink frequency selective scheduling is enabled, the number of PRBs that can be used for downlink frequency selective scheduling increases, and therefore downlink UE throughput also increases. If this option is deselected, network performance is not affected.

2D_FSS_SWITCH: When both the SMART_FSS_SWITCH and 2D_FSS_SWITCH options are selected, two-dimensional frequency selective scheduling takes effect. RBGs will be reordered in downlink frequency selective scheduling to produce more frequency selective scheduling gains and increase the downlink UE throughput. However, the number of uplink aperiodic CQI reporting times also increases. When this option is deselected, two-dimensional frequency selective scheduling does not take effect, and network performance is not affected.

SMALL_PKT_MCS_CQI_ADJ_SW: If this option is selected, the IBLER decreases when the small-packet and large-packet hybrid service model is used, and the MCS index may also decrease. If this option is deselected, network performance is not affected.

MIN_GBR_OPT_SWITCH: If this option is selected, downlink minimum GBR guarantee optimization takes effect and the minimum GBRs for non-GBR bearers and the GBRs for GBR bearers can be better guaranteed. If this option is deselected, downlink minimum GBR guarantee optimization does not take effect and network performance is not affected.
