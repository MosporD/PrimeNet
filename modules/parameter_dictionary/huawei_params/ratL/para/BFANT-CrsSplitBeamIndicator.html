Meaning

Indicates a split beam for the CRS of a cell from a split. If this parameter is set to a value ranging from 0 to 7, the eNodeB uses the split beam specified by this parameter to transmit the CRS of the soft split cell. The values 0 to 7 are divided into four groups: (0, 1), (2, 3), (4, 5), and (6, 7). This parameter must be set to different values in any of these groups for two split cells in a SSRDCellGroup MO. For example, if this parameter is set to 0 for the primary cell in a SSRDCellGroup MO, this parameter must be set to 1 for the split cell in the same MO. If this parameter is set to 255, the eNodeB uses the default split beam to transmit the CRS of the soft split cell. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

The eNodeB uses the split beam specified by this parameter to transmit the CRS of a soft split cell. Changing the split beam used for CRS transmission affects cell coverage and causes changes in network KPIs. Set this parameter based on cell coverage.
