Indicates the MCC of an MCE. An MCC and an MNC constitute a PLMN ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.
