Meaning

Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. The value of this parameter is invalid only when this parameter is set to 255 and the CnOpQciEventParam.EventType parameter is set to a value indicating event A1, A2, or A4 related to frequency-priority-based inter-frequency handovers. In this case, separate offsets are not specified on a per QCI basis. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the Qci parameter in a CnOpQciEventParam MO is set to 255, the EventType parameter in the same MO must be set to FREQ_PRI_INTER_FREQ_HO_A1, FREQ_PRI_INTER_FREQ_HO_A2, or FREQ_PRI_INTER_FREQ_HO_A4.
  • If the EventType parameter in a CnOpQciEventParam MO is set to FREQ_PRI_INTER_FREQ_HO_A1, FREQ_PRI_INTER_FREQ_HO_A2, or FREQ_PRI_INTER_FREQ_HO_A4, the Qci parameter in the same MO must be set to 255.
