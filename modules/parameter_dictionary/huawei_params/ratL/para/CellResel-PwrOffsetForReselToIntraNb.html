Meaning

Indicates the power offset for intra-frequency cell reselection of an NB-IoT UE with a power level of 14 dBm. When set to NULL, this parameter will not be delivered in the system information, and the UE takes 0 dB as the power offset by default. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

A larger value (excluding NULL) of this parameter results in a higher probability for an NB-IoT UE with a power level of 14 dBm to select a cell with good signal quality during an intra-frequency cell reselection. A smaller value of this parameter leads to the opposite effect.
