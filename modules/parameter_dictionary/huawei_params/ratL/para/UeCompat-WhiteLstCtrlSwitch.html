Meaning

Indicates whether to whitelist some features.

RANK_DETECT_SWITCH_ON: Indicates whether the eNodeB performs rank detection for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_AMRC_SWITCH_ON: Indicates whether to enable the function of uplink AMRC for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

FLASH_SRVCC_SWITCH_ON: Indicates whether the eNodeB performs flash SRVCC for specified UEs. If this option is selected, flash SRVCC is enabled for specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

CA_SRS_ONLY_SWITCH_ON: Indicates whether to enable the SCell polling sending SRS function for specified UEs. When this function is enabled, the SCell sends only SRSs instead of data in the uplink CA scenario. When multiple SCells exist, the SCells send SRSs in a polling manner. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_EVSC_SWITCH_ON: Indicates whether to enable the function of uplink EVSC for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

MDT_SWITCH_ON: Indicates whether to enable MDT for specified UEs. If this option of the WhiteLstCtrlSwitch parameter is deselected in this MO and this option of the WhiteLstCtrlSwitch parameter is selected for any of other UeCompat MOs, MDT is disabled regardless of whether the specified UEs support MDT. If this option of the WhiteLstCtrlSwitch parameter in this MO is selected, the eNodeB selects the specified UEs to perform MDT when the UEs support MDT. This option applies only to LTE FDD and LTE TDD.

TM9_SWITCH_ON: Indicates whether to enable the TM9 capability for the specified UEs. If this option is selected, the eNodeB considers the specified UEs to support TM9. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

SPECIAL_UE_STAT_SWITCH_ON: Indicates whether to enable performance measurement for special UEs. If this option is selected, counters related to special UEs are measured when RRC connection reestablishments, service drops, or E-RAB setup failures occur on these UEs. If this option is deselected, no differentiated measures are taken for these UEs. This option applies only to LTE FDD and LTE TDD.

VOLTE_QUALITY_SRVCC_SWITCH_ON: Indicates whether to enable voice-quality-based SRVCC for specified VoLTE UEs. If this option is selected, voice-quality-based SRVCC is allowed for the specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

AUTO_GAP_SWITCH_ON: Indicates whether to enable automatic gap-assisted measurement for specified UEs. If this option is selected, automatic gap-assisted measurement is enabled for the specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

CODE_RATE_RISE_SWITCH_ON: Indicates whether to remove the code rate restriction for specified UEs. If this option is selected, the code rate restriction is removed for specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This parameter applies only to LTE FDD and LTE TDD.

CSI_RS_ZERO_POWER_SWITCH_ON: Indicates whether to configure the zero-power setting for CSI-RS for on-TM9 and non-TM10 UEs that comply with 3GPP R10 or later. If this option is selected, zero-power setting for CSI-RS is configured for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.

8PORT_CSI_RS_SWITCH_ON: Indicates whether 8-port CSI-RS beams take effect for specified UEs. If this option is selected, 8-port CSI-RS beams take effect for these UEs. If this option is deselected, no differentiated measures are taken for these UEs. This option applies only to LTE TDD.

Impact on Radio Network Performance

RANK_DETECT_SWITCH_ON: If this option is selected, specified UEs are added to the whitelist of rank detection and the eNodeB performs rank detection for these UEs, increasing downlink throughput of the UEs. If this option is deselected, specified UEs are not added to the whitelist and UE performance is not affected.

UL_AMRC_SWITCH_ON: If this option is selected, the eNodeB may perform uplink AMRC for whitelisted UEs, improving speech quality for the UEs in the uplink. If this option is deselected, the UEs are not added to the whitelist of uplink AMRC and speech quality of the UEs is not affected.

FLASH_SRVCC_SWITCH_ON: If this option is selected, the eNodeB may perform flash SRVCC for whitelisted UEs, improving VoLTE service experience in weak coverage areas for those UEs. If this option is deselected, the UEs are not added to the whitelist of flash SRVCC and VoLTE services of the UEs are not affected.

UL_EVSC_SWITCH_ON: If this option is selected, the eNodeB can perform uplink EVSC for whitelisted UEs, improving speech quality for the UEs in the uplink. If this option is deselected, the UEs are not added to the whitelist of uplink EVSC and speech quality of the UEs is not affected.

MDT_SWITCH_ON: If this option is selected, the eNodeB selects whitelisted UEs to perform MDT. This increases the power consumption of the UEs and signaling overhead. If this option is deselected, specified UEs are not added to the MDT whitelist and UE performance is not affected.

SPECIAL_UE_STAT_SWITCH_ON: If this option is selected, the number of RRC connection reestablishment requests for special UEs is measured in the L.RRC.ReEst.Att.SpecialUE counter when the UEs experience RRC connection reestablishments. The number of abnormal E-RAB releases for special UEs is measured in the L.E-RAB.AbnormRel.SpecialUE counter and the number of abnormal UE context releases is measured in the L.UECNTX.AbnormRel.SpecialUE counter when the UEs experience service drops. The number of E-RAB setup failures for special UEs is measured in the L.E-RAB.FailEst.SpecialUE counter when the UEs experience E-RAB setup failures. If this option is deselected, measurements of performance counters are not affected.

VOLTE_QUALITY_SRVCC_SWITCH_ON: If this option is selected, experience with voice services improves. If this option is deselected, network performance is not affected.

AUTO_GAP_SWITCH_ON: If this option is selected, the eNodeB enables automatic gap-assisted measurement for whitelisted UEs, improving the uplink and downlink user-perceived data rates of the UEs during inter-frequency handovers. If this option is deselected, specified UEs are not added to the whitelist of automatic gap-assisted measurement and UE performance is not affected.

CODE_RATE_RISE_SWITCH_ON: If this option is selected, the code rate restriction is removed for specified UEs and downlink peak rates of the UEs increase. In this case, however, the number of retransmissions for the UEs increases. If this option is deselected, performance counters are not affected.

8PORT_CSI_RS_SWITCH_ON: If this option is selected, 8-port CSI-RS beams take effect for these UEs, increasing the downlink traffic volume of these UEs. If this option is deselected, performance counters are not affected.
