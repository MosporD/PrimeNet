Meaning

Indicates whether to enable optimization of repeated MIB transmission. If this parameter is set to OFF, the optimization is disabled. For LTE FDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 9. For LTE TDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 5. If this parameter is set to ON, the optimization is enabled, and the eNodeB transmits MIBs only in subframe 0. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to OFF, the eNodeB repeatedly transmits MIBs in subframes 0 and 9 for LTE FDD cells, and in subframes 0 and 5 for LTE TDD cells. In this case, eMTC coverage enhancement is supported. However, repeated MIB transmission consumes extra downlink PRB resources, lowering the peak LTE cell throughput and user-perceived throughput. If this parameter is set to ON, optimization of repeated MIB transmission is enabled, and the eNodeB transmits MIBs only in subframe 0. In this case, eMTC coverage gains are limited, and the peak LTE cell throughput and user-perceived throughput are not affected.
