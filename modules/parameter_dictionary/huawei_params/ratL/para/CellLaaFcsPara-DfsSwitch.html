Meaning

Indicates whether to enable dynamic frequency selection (DFS). This parameter includes the DfsFreqSwitch option.

DfsFreqSwitch: Indicates whether to enable DFS detection. If this option is selected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are detected for DFS. If this option is deselected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are not detected for DFS. This option applies only to LTE TDD.

Caution

Selecting the DfsFreqSwitch option of this parameter will enable DFS in the frequency band and may cause the pRRU to reset.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

DfsFreqSwitch: If this option is selected, an LAA cell working on a DFS frequency band has lower throughput than on common frequency bands. If this option is deselected, or if this option is selected but the LAA cell works on a non-DFS frequency band, the throughput of the LAA cell is not affected.
