MOD ENODEBALGOSWITCH

Meaning

Indicates whether to enable the ANR algorithm in RAN sharing mode. This parameter provides the following options:

NBSLTEPLMNRoundSwitch: If this option is selected, some neighboring eNodeBs provide cells that work in E-UTRAN sharing mode and broadcast their PLMN lists in a round robin (RR) manner. In this case, if the IntraRatEventAnrSwitch or IntraRatFastAnrSwitch option of the AnrSwitch parameter is selected for the local eNodeB, the local eNodeB obtains the actual cell global identifier (CGI) and serving PLMN list for a neighboring cell broadcasting PLMNs from the MAE in an RR manner after the UE reports the CGI of the cell during ANR measurements. If both the NBSLTEPLMNRoundSwitch and NBSLTERANSharingSwitch options are selected, the NBSLTEPLMNRoundSwitch option takes precedence over the NBSLTERANSharingSwitch option. This option applies only to LTE FDD and LTE TDD.

NBSLTERANSharingSwitch: If this option is selected, some neighboring eNodeBs provide cells that work in E-UTRAN sharing mode. In this case, if the IntraRatEventAnrSwitch or IntraRatFastAnrSwitch option of the AnrSwitch parameter is selected for the local eNodeB, the local eNodeB obtains the serving PLMN list for a neighboring cell from the MAE after the UE reports the CGI of the cell during ANR measurements. If the UE has reported the PLMN list, the local eNodeB does not need to obtain the serving PLMN list for a neighboring cell from the MAE. This option applies only to LTE FDD and LTE TDD.

NBSUTRANRANSharingSwitch: If this option is selected, some neighboring NodeBs provide cells that work in UTRAN sharing mode. In this case, if the UtranEventAnrSwitch or UtranFastAnrSwitch option of the AnrSwitch parameter is selected for the local eNodeB, the local eNodeB obtains the serving PLMN list for a neighboring cell from the MAE after the UE reports the CGI of the cell during ANR measurements. If the UE has reported the PLMN list, the local eNodeB does not need to obtain the serving PLMN list for a neighboring cell from the MAE. This option applies only to LTE FDD and LTE TDD.

NBSGERANRANSharingSwitch: If this option is selected, some neighboring BTSs provide cells that work in GERAN sharing mode. In this case, if the GeranEventAnrSwitch or GeranFastAnrSwitch option of the AnrSwitch parameter is selected for the local eNodeB, the local eNodeB obtains the serving PLMN list for a neighboring cell from the MAE after the UE reports the CGI of the cell during ANR measurements. This option applies only to LTE FDD and LTE TDD.
