Meaning

Indicates the measurement performance demand for whether to broadcast the frequency in SIB5. If this parameter is set to NORMAL, the frequency is broadcast in interFreqCarrierFreqList without carrying the IE reducedMeasPerformance. The measurement performance of a UE is normal when the UE measures the frequency. If this parameter is set to REDUCED, the frequency is broadcast in interFreqCarrierFreqListExt carrying the IE reducedMeasPerformance. The measurement performance of a UE supporting extended frequency measurement can be reduced to measure the frequency. If this parameter is set to UNDELIVER, the frequency is not broadcast in SIB5. This parameter value applies only to LTE FDD. For details about the IE reducedMeasPerformance, see 3GPP TS 36.331.

Parameter Relationship

-Configuration constraints:

  • In EutranInterNFreq MOs, the number of physical frequencies for which MeasPerformanceDemand in the EutranInterNFreq MOs is set to NORMAL must be greater than or equal to 1.
  • The number of physical frequencies for which MeasPerformanceDemand in the EutranInterNFreq MOs is set to NORMAL must be less than or equal to 8.
  • When FddTddInd in a Cell MO is set to CELL_TDD, MeasPerformanceDemand in an EutranInterNFreq MO associated with this Cell MO must not be set to UNDELIVER.

-Others:

  • The number of physical frequencies for which MeasPerformanceDemand in the EutranInterNFreq MOs is set to NORMAL must be less than or equal to 8.

Impact on Radio Network Performance

If a UE does not support extended frequency measurement, cell selection and reselection can only be applicable to a frequency with MeasPerformanceDemand set to NORMAL. If a UE selects a frequency not featuring large bandwidth and strong coverage as the frequency with MeasPerformanceDemand set to NORMAL, the access performance, retainability, and throughput rate may decrease.

If a UE supports extended frequency measurement, the duration that a UE reselects a frequency with MeasPerformanceDemand set to REDUCED is longer than the duration that the UE reselects a frequency with MeasPerformanceDemand set to NORMAL. If the UE selects a frequency not featuring strong coverage as the frequency with MeasPerformanceDemand set to NORMAL, the access performance and retainability may decrease.
