Meaning

Indicates the tracking area code (TAC) of an external NR cell. It is used to form a tracking area identifier (TAI) with the PLMN. The value 4294967295 is an invalid value. This parameter will be set to this invalid value when ANR adds neighboring NR cells that support only the NSA architecture. For details, see 3GPP TS 38.300. This parameter applies only to LTE FDD and LTE TDD.
