X2 Setup Failure TimetoWait

MO GlobalProcSwitch

Parameter Name

X2 Setup Failure TimetoWait
NE

MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates the time to wait for sending an X2 setup request again when an X2 setup fails. When an X2 setup procedure fails, the eNodeB that accepted the X2 setup request sends an X2 Setup Failure message to the peer eNodeB. This message contains the TimetoWait IE to inform the peer eNodeB of the time to wait for sending an X2 setup request again. As defined in 3GPP TS 36.423, the peer eNodeB shall wait at least for the time indicated by the TimetoWait IE before re-initiating the X2 Setup procedure towards the same eNodeB. If this parameter is set to TIMETOWAIT_NOTCARRY, the X2 Setup Failure message does not contain the TimetoWait IE. The values TIMETOWAIT_1s, TIMETOWAIT_2s, TIMETOWAIT_5s, TIMETOWAIT_10s, TIMETOWAIT_20s, and TIMETOWAIT_60s indicate that the waiting time are 1s, 2s, 5s, 10s, 20s, and 60s, respectively. Assume that the number of X2 setup failures is N. If this parameter is set to TIMETOWAIT_Default, the TimetoWait IE takes effect as follows:

1. If N < 10, the waiting time is 5s.

2. If 10 ≤ N < 20, the waiting time is 10s.

3. If 20 ≤ N < 60, the waiting time is 20s.

4. If N ≥ 60, the waiting time is 60s.
