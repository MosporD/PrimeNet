Parameter Relationship

-Configuration constraints:

  • When the AnchorCarrierFlag and DeployMode parameters in a Prb MO are set to TRUE and GUARD_BAND, respectively: For PRBs with the same LocalCellId in the Prb MO, if the AnchorCarrierFlag and DeployMode parameters are set to FALSE and GUARD_BAND, respectively, the LteDlEarfcn and LteBandWidth must be the same as the LteDlEarfcn and LteBandWidth parameters in the Prb MO instance with AnchorCarrierFlag set to TRUE.

-Parameter relationship with conditions:

  • If DeployMode is set to GUARD_BAND, LteDlEarfcn must be set.
