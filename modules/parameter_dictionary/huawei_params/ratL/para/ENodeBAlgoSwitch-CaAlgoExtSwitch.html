CA Algorithm Extend Switch

MO ENodeBAlgoSwitch
Parameter ID CaAlgoExtSwitch
Parameter Name

CA Algorithm Extend Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD ENODEBALGOSWITCH

LST ENODEBALGOSWITCH
Meaning

Indicates whether to enable carrier aggregation (CA) functions. This parameter extends the function of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO.

FTMtaAlgSwitch: Indicates whether to enable multiple timing advances (MTA) for uplink FDD+TDD CA. If this option is selected and uplink FDD+TDD CA is enabled, MTA is supported in uplink FDD+TDD CA scenarios. In this situation, if the capability information reported by a UE indicates that the UE supports FDD+TDD MTA in the uplink, uplink timing using multiple timing advance groups (TAGs) works for the UE in uplink FDD+TDD CA scenarios. If the capability information indicates that the UE does not support FDD+TDD MTA in the uplink, SCells will not be configured for the UE for uplink FDD+TDD CA. If this option is deselected, SCells will not be configured for the UE for uplink FDD+TDD CA. It is recommended that this option be selected when uplink FDD+TDD CA is enabled. This option applies only to LTE FDD and LTE TDD.

TddCloudbbUlCaSwitch: Indicates whether to enable uplink CA based on centralized Cloud BB for LTE TDD cells. If this option is selected, uplink CA based on centralized Cloud BB is enabled for LTE TDD cells. If this option is deselected, uplink CA based on centralized Cloud BB is disabled for LTE TDD cells. This option applies only to LTE TDD.

FreqBaseCaLicAlarmSwitch: Indicates whether to report the CA license alarm. If this option is selected, the eNodeB reports the insufficient CA license alarm in frequency-based CA. If this option is deselected, the eNodeB does not proactively report the insufficient CA license alarm in frequency-based CA. This option applies only to LTE FDD and LTE TDD.

FreqBaseIntereNBSccSwitch: Indicates whether cells configured on the local eNodeB can be configured as the SCells of cells configured on another eNodeB in frequency-based CA. If this option is selected, cells configured on the local eNodeB can be configured as the SCells of the cells configured on another eNodeB. If this option is deselected, cells configured on the local eNodeB cannot be configured as the SCells of the cells configured on another eNodeB. This option applies only to LTE FDD and LTE TDD.

SccDeactByUlDtxSwitch: Indicates whether to deactivate SCells based on the uplink DTX. If this option is selected, the eNodeB deactivates SCells if it detects that the CA status of the UE is inconsistent with that on the eNodeB side based on the DTX. The PCell and SCell statuses are analyzed based on the setting of this option for the corresponding eNodeB. The eNodeB deactivates the SCell based on the uplink DTX only when this option is selected for both eNodeBs serving the PCell and SCell. Selecting this option also improves performance of demodulating ACKs transmitted on the PUSCH in downlink 2CC CA scenarios. If this option is deselected, the eNodeB deactivates SCells if it detects that the CA status of the UE is inconsistent with that on the eNodeB side based on the uplink RBLER. This option applies only to LTE FDD and LTE TDD.

CaAnrGapOptSwitch: If this option is selected, the eNodeB requires a UE to start inter-frequency measurement if no neighboring cells are configured on an SCC. If this option is deselected, the eNodeB does not require a UE to start inter-frequency measurement when selecting an SCell if no neighboring cells are configured on an SCC. This option applies only to LTE FDD and LTE TDD.

SmartCaFastSccCfgSwitch: Indicates whether to preferentially configure SCCs that can be blindly configured before smart carrier grouping when smart carrier selection is enabled.

CaEnhancedPreAllocSwitch: Indicates whether to enable enhanced inter-carrier traffic distribution for CA. If this option is selected, the eNodeB adopts the enhanced inter-carrier traffic distribution policy for CA UEs. In this case, the eNodeB dynamically distributes traffic to CCs based on real-time traffic volume of CA UEs and scheduling capabilities of CCs. If this option is deselected, the eNodeB does not adopt this policy.

RelaxedBHCaEnh2Switch: Indicates whether to enable relaxed backhaul-based CA enhancement in phase 2. If this option is selected, inter-eNodeB CA works in relaxed backhaul scenarios where the inter-eNodeB one-way transmission delay is up to 16 ms. This maximum permissible delay is extended from 4 ms to 16 ms. If this option is deselected, the eNodeB disables relaxed backhaul-based CA enhancement in phase 2.

SmartCaPccSelSwitch: Indicates whether to enable preferential PCell selection during intelligent selection of serving cell combinations. If this option is selected, PCells are selected based on radio-interface capabilities. If this option is deselected, this selection does not take effect. This option applies only to LTE FDD and LTE TDD.

HoWithSccCfgBlindFirstSw: Indicates whether to preferentially select a blind-configurable candidate SCell as an SCell for the target cell of a handover when adaptive CA is enabled and the HoWithSccCfgSwitch option of the CaAlgoSwitch parameter is selected. This preferential selection takes effect only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UeBandCombReducedR13Sw: Indicates whether the eNodeB requests UEs to report compressed CA band combinations as defined in 3GPP Release 13 (TS 36.306 and TS 36.331). The IEs that UEs can use to report compressed CA band combinations include requestReducedFormat-r13, requestSkipFallbackComb-r13, requestedMaxCCsDL-r13, requestedMaxCCsUL-r13, requestReducedIntNonContComb-r13, and requestDiffFallbackCombList-r14. UEs are requested to report compressed CA band combinations only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LaaIdcSwitch: Indicates whether to allow UEs compliant with 3GPP TS 36.300 and 36.331 Release 13 to report LAA IDC interference indication. If this option is selected, the eNodeB allows newly admitted UEs to report LAA IDC interference indication and provides IDC interference cancellation methods for these UEs. If this option is deselected, the eNodeB does not allow the reporting. This option applies only to LTE FDD and LTE TDD.

CaA5HoEventEnhSwitch: Indicates whether to enhance the handling of changing event A4 to event A5 in the handover-related inter-frequency measurement configurations delivered to CA UEs. This enhancement takes effect only if this option is selected. This option applies only to LTE FDD and LTE TDD.

CaMubfPairingAdaptOptSwitch: Indicates whether to enable adaptive UE pairing optimization for MU beamforming in CA scenarios. If this option is selected and adaptive CA configuration is used, high-load candidate massive MIMO SCells cannot be configured as SCells for UEs that do not support UE pairing in SCells, and high-load common candidate SCells cannot be configured as SCells either. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

InterEnodebLaaSwitch: Indicates whether to enable inter-eNodeB LAA carrier aggregation. If this option is selected, cells served by the eNodeB are allowed to participate in inter-eNodeB LAA carrier aggregation. If this option is deselected, cells served by the eNodeB are not allowed to participate in inter-eNodeB LAA carrier aggregation. This option applies only to LTE FDD and LTE TDD.

X2MessageWithLaaCellInfoSwitch: Indicates whether X2 messages can carry LAA cell information when inter-eNodeB LAA carrier aggregation is enabled. If this option is selected, X2 messages can carry LAA cell information. If this option is deselected, X2 messages cannot carry LAA cell information. This option applies only to LTE FDD and LTE TDD.

ContigIntraBandCaSwitch: Indicates whether contiguous intra-band CA takes effect when the zero guard band between contiguous intra-band carriers feature is enabled. Assume that the zero guard band between contiguous intra-band carriers feature is enabled, spectrum overlapping exists for cells, and the cells do not meet the requirement of nominal channel spacing defined in 3GPP TS 36.101. Contiguous intra-band CA is not configured for these cells if this option is selected. Contiguous intra-band CA takes effect if this option is deselected. This option takes effect for a cell serving as a CA PCell or SCell when the zero guard band between contiguous intra-band carriers feature is enabled for the cell. This option applies only to LTE FDD and LTE TDD.

CaRoutePunishmentEnhSwitch: Indicates whether to enable enhanced CA route penalty. If this option is selected, enhanced CA route penalty is enabled and the base-station-level penalty policy is used. If the application for a CA route in a process fails for three consecutive times, the penalty on this CA route takes effect in all processes. If this option is deselected, enhanced CA route penalty is disabled and the process-level penalty policy is used. If the application for a CA route in a process fails for three consecutive times, the penalty on this CA route takes effect only in this process. This option applies only to LTE FDD and LTE TDD.

LaaRoutePunishmentSwitch: Indicates whether to enable LAA route penalty. If this option is selected, LAA route penalty is enabled. If the application for an LAA route continuously fails, the penalty on this LAA route is triggered. If this option is deselected, LAA route penalty is disabled. This option applies only to LTE FDD and LTE TDD.

SccMeasRptLocalCellPriorSw: Indicates whether to reserve only cells served by the local eNodeB in CA-related measurement reports when there is an activated intra-eNodeB cell on the frequency (excluding LAA frequencies) of an SCC to be measured. If this option is selected, the eNodeB filters out inter-eNodeB cells from the received CA-related measurement reports for the SCC and retains only the cells served by the local eNodeB. If this option is deselected, the eNodeB does not filter out inter-eNodeB cells. This option applies only to LTE FDD and LTE TDD.

MfbiSccFreqConfigMergeSw: Indicates whether not to merge SCC frequency configurations (defined in the SccFreqCfg MO) corresponding to the primary and secondary frequency bands and not to NR SCG frequency configurations (defined in the NrScgFreqConfig MO) corresponding to the primary and secondary frequency bands. If this option is selected, the eNodeB does not ignore the frequency band selected by the UE during network access and uses only the SCC frequency configurations and the NR SCG frequency configurations corresponding to this frequency band. If this option is deselected, the eNodeB ignores the frequency band selected by a UE accessing an MFBI cell and uses the merged SCC frequency configurations and the merged NR SCG frequency configurations corresponding to the primary and secondary frequency bands of this cell. This option applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the CaEnhancedPreAllocSwitch option of CaAlgoExtSwitch in the ENodeBAlgoSwitch MO is selected, the CaLoadBalancePreAllocSwitch option of CaAlgoSwitch in the ENodeBAlgoSwitch MO must be deselected.
  • If the InterEnodebLaaSwitch option of the CaAlgoExtSwitch parameter in an ENodeBAlgoSwitch MO is selected, the FreqCfgSwitch option of the CaAlgoSwitch parameter in the same ENodeBAlgoSwitch MO must be selected.
  • The CaSmartSelectionSwitch option of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO must be selected if the SmartCaFastSccCfgSwitch option of the CaAlgoExtSwitch parameter in the same MO is selected.
  • If the CaMubfPairingAdaptOptSwitch option of the CaAlgoExtSwitch parameter in the ENodeBAlgoSwitch is selected, the AdpCaSwitch and CaSmartSelectionSwitch options of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO must be selected and deselected, respectively.
  • If the CaEnhancedPreAllocSwitch option of CaAlgoExtSwitch in the ENodeBAlgoSwitch MO is selected, the DlCaLbAlgoSwitch option of CaLbAlgoSwitch in ENodeBAlgoSwitch must be deselected.
  • If the X2MessageWithLaaCellInfoSwitch option of the CaAlgoExtSwitch parameter in the ENodeBAlgoSwitch MO is selected, the InterEnodebLaaSwitch option of the same parameter must also be selected.

Impact on Radio Network Performance

FTMtaAlgSwitch: If this option is selected, uplink timing based on multiple TAGs is supported in FDD+TDD uplink CA scenarios. In this case, more resources are consumed for uplink timing and the uplink throughput decreases if the SCell and PCell have the same uplink timing offset; the uplink cell throughput increases if the SCell and PCell have different timing offsets (for example, in scenarios where inter-eNodeB CA is performed or RRUs are installed far away from BBUs). If this option is deselected, uplink timing based on multiple TAGs is not supported in uplink FDD+TDD CA scenarios. Network performance is not affected if the SCell and PCell share the same timing offset. If the SCell and PCell have different timing offsets, the uplink timing adjustment for UEs in the SCell is delayed, and therefore uplink throughput decreases.

FreqBaseCaLicAlarmSwitch: No impact.

FreqBaseIntereNBSccSwitch: If this option is deselected when frequency-based CA is enabled, cells served by the local eNodeB cannot be configured as SCells for cells served by another eNodeB, reducing the number of UEs served by SCells, the PRB usage of cells served by the local eNodeB, the number of CA UEs on the entire network, and the average throughput. If this option is selected, cells served by the local eNodeB can be configured as SCells for cells served by another eNodeB, increasing the number of UEs served by SCells, PRB usage of cells served by the local eNodeB, the number of CA UEs on the entire network, and the average throughput.

SccDeactByUlDtxSwitch: If this option is selected, the eNodeB does not deactivate the SCell when uplink channel quality is poor, increasing the downlink rate. However, this increases the uplink IBLER of the SCell and decreases the uplink throughput of the SCell when uplink PRBs are fully used in heavily loaded scenarios. At the same time, the false detection rate of ACKs transmitted on the PUSCH decreases in downlink 2CC CA scenarios, avoiding throughput drops to almost 0 Mbit/s when the SCC activation status is inconsistent on the UE and eNodeB sides. However, the missing detection rate of ACKs transmitted on the PUSCH for CEUs and resource overhead slightly increase. If this option is deselected, the eNodeB deactivates the SCell when uplink channel quality is poor, reducing the IBLER and the downlink throughput. This has no impact on the uplink throughput.

CaAnrGapOptSwitch: If this option is selected, the eNodeB requires the UE to start inter-frequency measurement events when no neighboring cells are configured on an SCC, increasing the number of measurement opportunities for the UE, the number of CA UEs, and the throughput of the entire eNodeB. However, the MAC throughput of the PCell decreases due to an increase in inter-frequency measurements. If this option is deselected, the eNodeB does not require a UE to start inter-frequency measurement when selecting an SCell if no neighboring cells are configured on an SCC. In this case, the number of measurement opportunities for the UE, the number of CA UEs, and the eNodeB throughput decrease. However, the MAC throughput of the PCell increases due to a decrease in inter-frequency measurements.

SmartCaFastSccCfgSwitch: If this option is selected, the eNodeB can configure SCells that can be blindly configured during smart carrier selection, allowing UEs to enter CA as soon as possible. However, if the carrier group needs to be changed after smart carrier selection, the number of RRC connection reconfiguration signaling messages increases.

CaEnhancedPreAllocSwitch: If this option is selected, the downlink perceived rate of CA UEs increases. If this option is deselected, network performance is not affected.

RelaxedBHCaEnh2Switch: No impact.

SmartCaPccSelSwitch: If this option is selected, the perceived downlink data rates of CA UEs increase and the number of inter-frequency handovers in the network also rises.

HoWithSccCfgBlindFirstSw: If this option is selected, user experience is affected if the blindly configured cell preferentially selected as the SCell has poor signal quality or a small bandwidth.

UeBandCombReducedR13Sw: If this option is selected, the length of the UECapabilityInformation message of UEs decreases and the L.Thrp.bits.UL.SRB counter value also decreases.

LaaIdcSwitch: If this option is selected, IDC interference is addressed for UEs, which increases the user-perceived downlink rates of LAA UEs. If this option is deselected, the user-perceived downlink rates of LAA UEs under IDC interference will decrease.

CaA5HoEventEnhSwitch: If this option is selected, inter-frequency handovers can be executed as expected. However, this may cause the values of related performance counters to fluctuate. Deselecting this option has no impact on network performance.

CaMubfPairingAdaptOptSwitch: If this option is selected, high-load massive MIMO cells can be prevented from being configured as SCells for UEs that do no support UE pairing in SCells and common high-load cells can also be prevented from being configured as SCells in adaptive CA configuration mode. If this option is deselected, network performance is not affected.

InterEnodebLaaSwitch: If this option is selected, the number of UEs in the LAA CA state increases, more X2 interface resources are occupied, and more X2 messages are exchanged. If this option is deselected, there is no impact.

X2MessageWithLaaCellInfoSwitch: If this option is selected, more information is contained in X2 messages. If this option is deselected, there is no impact.

ContigIntraBandCaSwitch: If this option is selected, the probability that CA takes effect decreases. If this option is deselected, the number of RRC connection reestablishments increases.

CaRoutePunishmentEnhSwitch: If this option is selected, the base-station-level penalty policy takes effect, which may lead to changes in the number of CA UEs. If this option is deselected, the base-station-level penalty policy does not take effect.

LaaRoutePunishmentSwitch: If this option is selected, LAA route penalty takes effect, which may lead to changes in the number of LAA CA UEs. If this option is deselected, network performance is not affected.

SccMeasRptLocalCellPriorSw: If this option is selected, the number of inter-eNodeB CA UEs decreases. If this option is deselected, the number of inter-eNodeB CA UEs increases.

MfbiSccFreqConfigMergeSw: If this option is selected, no available SCC frequency and NR SCG frequency can be selected for the UE when the SCC frequency configurations and NR SCG frequency configurations are inconsistent between the primary and secondary frequency bands. As a result, SCell addition and NR SCG addition fail, and the number of CA UEs and the number of NSA DC UEs may decrease. If this option is deselected, then more SCC frequency configurations and NR SCG frequency configurations are available for the UE in the MFBI cell, and the number of CA UEs and the number of NSA DC UEs may increase.
