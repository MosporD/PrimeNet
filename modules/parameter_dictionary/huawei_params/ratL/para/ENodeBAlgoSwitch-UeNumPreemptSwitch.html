Meaning

Indicates whether to enable preemption based on the number of UEs. IntraOpUeNumPreemptSwitch: Indicates whether to enable intra-operator-group preemption based on the number of UEs. When a UE fails to access the network due to the UE quantity restriction, this UE can attempt to preempt resources of other lower-priority UEs served by the operators in the operator group if this option is selected. If this option is deselected, such preemption is not allowed. This option applies only to LTE FDD and LTE TDD.

InterOpUeNumPreemptSwitch: Indicates whether to enable inter-operator-group preemption based on the number of UEs. This type of preemption is allowed only if this option is selected. This option applies only to LTE FDD.

NbUeNumPreemptSwitch: Indicates whether to allow NB-IoT UEs to preempt resources of other NB-IoT UEs based on the number of UEs. This type of preemption is allowed only if this option is selected. This option applies only to NB-IoT.

UeNumPreemptCapbEnhSwitch: Indicates whether to enhance the preemption capability of the UE-number-based preemption function. If this option is deselected and a large number of UEs initiate access at the same time, UEs that fail to access the network are not allowed to initiate preemption. If this option is selected and the AcUserNumber parameter in the CellRacThd MO is set to a value less than the maximum number of UEs that the eNodeB supports, UEs are still allowed to initiate preemption when a large number of UEs initiate access at the same time.

Impact on Radio Network Performance

IntraOpUeNumPreemptSwitch: If this option is selected, the access success rate of high-priority UEs rises, but the service drop rate of low-priority UEs served by the same operator also increases. If this option is deselected, neither the access success rate of high-priority UEs nor the service drop rate of low-priority UEs served by the same operator increases.

InterOpUeNumPreemptSwitch: If this option is selected, an operator that is dynamically sharing its RRC_CONNECTED UE number resources with other operators can reclaim the shared resources by preemption when needed. This increases the service drop rate of UEs served by those operators. If this option is deselected, an operator that is dynamically sharing its RRC_CONNECTED UE number resources with other operators cannot use preemption to reclaim the shared resources. Instead, it can only wait for UEs to release the shared resources. This decreases the throughput of this operator.

NbUeNumPreemptSwitch: If this option is selected, the access success rate of high-priority UEs rises, but the service drop rate of low-priority UEs also increases. If this option is deselected, neither the access success rate of high-priority UEs nor the service drop rate of low-priority UEs increases.

UeNumPreemptCapbEnhSwitch: If this option is selected, the RRC connection setup success rate increases, the E-RAB setup success rate decreases, and the service drop rate increases. If this option is deselected, these rates change in the reverse direction.
