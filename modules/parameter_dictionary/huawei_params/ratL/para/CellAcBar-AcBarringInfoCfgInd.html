Meaning

Indicates the AC barring information configuration mode.

If this parameter is set to NOT_CFG, AC barring information is not configured.

If this parameter is set to CFG, AC barring information is configured.

If this parameter is set to OPERATOR_BASED_CFG, AC barring information is configured based on operator information.

This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If AcBarringForMoDataCfgInd or AcBarringForMoSigCfgInd in SIB2 is set to CFG, the UE generates a random number in the range [0, 1). If the random number is smaller than the value of AcBarringFactorForCall or AcBarringFactorForSig, the UE considers access to the cell as allowed. That is, an RRC connection can be set up for the mobile-originated call or signaling. A larger value of AcBarringFactorForCall or AcBarringFactorForSig leads to a higher probability of granting access to a UE, which may increase cell load. A smaller value of AcBarringFactorForCall or AcBarringFactorForSig leads to a lower probability of granting access to a UE. As a result, a UE may fail to access the cell even when the cell load is relatively light. If this parameter is set to P00, no RRC connection for the mobile-originated call or signaling can be set up.
