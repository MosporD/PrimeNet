Meaning

Indicates the type of adaptive selection between beamforming and MIMO for a multi-antenna eNodeB. The values are described as follows:

NO_ADAPTIVE: A fixed beamforming or MIMO transmission mode is used. That is, transmission mode switching is not supported.

TxD_BF_ADAPTIVE: The transmission mode changes adaptively between TM2 and TM7 or between TM2 and TM8, depending on the 3GPP release with which UEs comply.

MIMO_BF_ADAPTIVE: The transmission mode changes adaptively among TM2, TM3, and TM7, among TM2, TM3, and TM8, or among TM2, TM3, TM8, and TM9, depending on the 3GPP release with which UEs comply. The TM9Switch option must be selected if the TM9 mode is required. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

This parameter is valid only when the BfSwitch option under the BfAlgoSwitch parameter is selected. The setting of this parameter determines the transmission modes that apply to UEs served by a multi-antenna eNodeB and therefore affects performance such as the throughput and coverage.

If this parameter is set to NO_ADAPTIVE, the transmission mode that applies to UEs in a cell is determined by the setting of the FixedBfMimoMode parameter. For details, see the description of impact on radio network performance of the FixedBfMimoMode parameter.

If this parameter is set to TxD_BF_ADAPTIVE, the transmission mode that applies to UEs in a cell can be TM2 or beamforming and the peak transmission rates of MIMO UEs are affected. This parameter can be set to TxD_BF_ADAPTIVE in scenarios without requiring TM3 transmission mode.

If this parameter is set to MIMO_BF_ADAPTIVE, the eNodeB adaptively uses beamforming or open-loop MIMO mode to transmit data in scenarios where the eNodeB is equipped with 4T or 8T antennas to serve UEs that move at different speeds and have different channel correlation and signal quality.

The best performance can be achieved only when the setting of this parameter matches the SINR and speed mobility of UEs. Otherwise, the performance such as the throughput and coverage is worse than that with the optimal transmission mode.
