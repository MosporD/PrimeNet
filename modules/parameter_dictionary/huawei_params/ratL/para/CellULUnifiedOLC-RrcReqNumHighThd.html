Meaning

Indicates the threshold of the number of RRC connection setup requests, which is used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when both of the following conditions are met: (1) The number of RRC connection setup requests is greater than the RrcReqNumHighThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is greater than the RrcRejectRateHighThd parameter value. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a higher probability that UMTS and LTE unified overload control is not triggered when the cell is overloaded. As a result, the RRC connection setup success rate decreases and the success rate of handovers between LTE and UMTS decreases. A smaller value of this parameter results in a higher probability that UMTS and LTE unified overload control is triggered. This causes an increase in the RRC connection setup success rate and the success rate of handovers between LTE and UMTS, and may also cause a decrease in the number of handovers between LTE and UMTS and cell reselections.
