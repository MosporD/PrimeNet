Meaning

Indicates the weight factor of uplink scheduling resource allocation for bearers with the scheduling type of WFQ. This parameter is valid when the SchedulingType parameter is set to WFQ or WFQ_L2OM. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • The sum of the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ_L2OM and the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ must be less than or equal to 100.

Impact on Radio Network Performance

This parameter affects the RB resource allocation proportion between multiple WFQ bearers on an RRN. When this RRN is scheduled and allocated RB resources and data transmission is required for multiple WFQ bearers on this RRN, the WFQ bearer configured with a larger uplink resource allocation weighting factor can obtain more RB resources, there is a higher probability that data is timely transmitted on this bearer, and service quality on this bearer is better.
