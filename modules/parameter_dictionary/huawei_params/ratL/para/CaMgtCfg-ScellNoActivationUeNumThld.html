SCell Not Active UE Number Threshold

MO CaMgtCfg
Parameter ID ScellNoActivationUeNumThld
Parameter Name

SCell Not Active UE Number Threshold
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CAMGTCFG

LST CAMGTCFG
Meaning

Indicates whether to prohibit SCell activation when the specified cell is heavily loaded. When the number of UEs in the cell is greater than the load threshold, the eNodeB determines that the cell is in the high load state and does not activate this cell as an SCell for any new CA UE. If this parameter is set to 0, this function is disabled. If this parameter is set to a value other than 0, this parameter indicates the load threshold. When the number of UEs in the cell (including non-CA UEs, CA UEs that treat the cell as their PCell, and CA UEs that treat this cell as their SCell and have this SCell activated) is greater than this parameter value, the eNodeB no longer activates this cell as an SCell for any CA UE. When the number of UEs in the cell is not greater than this parameter value, the eNodeB can activate this cell as an SCell for CA UEs. The eNodeB measures the number of UEs in the cell every second. When the number of UEs is a little smaller than this threshold, simultaneous SCell activation for a number of CA UEs will cause the number of UEs in the cell to exceed this threshold. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to 0, the average downlink user-perceived data rate of all CA UEs that treat the cell as their SCell and the average downlink user-perceived data rate on the entire network increase. If this parameter is set to a value other than 0 and the number of UEs in the cell exceeds the parameter value, then the average downlink user-perceived data rate of non-CA UEs in the cell increases, the average downlink user-perceived data rate of cell-edge UEs increases, the average downlink user-perceived data rate of all CA UEs that treat the cell as their SCell decreases, and the average downlink user-perceived data rate on the entire network decreases.
