Meaning

Indicates the system information broadcast policy for the cell.

DlOnlyCellSiSwitch(DlOnlyCellSiSwitch): Indicates whether to broadcast system information in the cell if the WorkMode parameter in the Cell MO is not set to UL_DL for the cell. System information is broadcast in the cell only if this option is selected. This option applies only to cells for which the WorkMode parameter is not set to UL_DL. This option applies only to LTE FDD.

Sib6Switch(Sib6Switch): Indicates whether to broadcast SIB6. If this option is deselected, SIB6 is not broadcast. If this option is selected and the CELLRESELUTRAN MO is created, SIB6 is broadcast. For details about the contents of SIB6, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

Sib7Switch(Sib7Switch): Indicates whether to broadcast SIB7. If this option is deselected, SIB7 is not broadcast. If this option is selected and the CELLRESELGERAN MO is created, SIB7 is broadcast. For details about the contents of SIB7, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

ForbidCellSiSwitch: Indicates the information broadcast in the system information of a cell with the WorkMode parameter in the Cell MO being not set to DL_ONLY and related handling for the cell. If this option is deselected, system information is normally broadcast in the cell. If this option is selected, system information broadcast in the cell indicates that the cell is in the barred state, preventing UEs from camping on the cell. In addition, the system does not allow handovers to the cell. This option applies only to LTE FDD and LTE TDD.

Sib24Switch(Sib24Switch): Indicates whether to broadcast SIB24. If this option is deselected, SIB24 is not broadcast. If this option is selected and the CELLRESELTONR MO is created, SIB24 is broadcast. For details about the contents of SIB24, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

Sib6Switch(Sib6Switch): If this option is deselected, UEs cannot be reselected to UTRAN cells. As a result, more UEs with poor signal quality exist on the LTE network, causing deterioration in the random access success rate, RRC connection setup success rate, E-RAB setup success rate, service drop rate, RRC connection reestablishment success rate, cell throughput, user throughput, IBLER, RBLER, packet loss rate, MOS, idle-to-active delay, attach delay, and other delay (including web browsing delay and FTP download delay). This may increase the number of online UEs and PRB usage. If this option is selected, UEs can be transferred to UTRAN cells by cell reselection, avoiding deterioration in the preceding performance indicators.

Sib7Switch(Sib7Switch): If this option is deselected, UEs cannot be reselected to GERAN cells. As a result, more UEs with poor signal quality exist on the LTE network, causing deterioration in the random access success rate, RRC connection setup success rate, E-RAB setup success rate, service drop rate, RRC connection reestablishment success rate, cell throughput, user throughput, IBLER, RBLER, packet loss rate, MOS, idle-to-active delay, attach delay, and other delay (including web browsing delay and FTP download delay). This may increase the number of online UEs and PRB usage. If this option is selected, UEs can be transferred to GERAN cells by cell reselection, avoiding deterioration in the preceding performance indicators.

Sib24Switch(Sib24Switch): If this option is deselected, UEs cannot reselect NR cells. As a result, more UEs with poor signal quality exist on the LTE network, causing deterioration in the random access success rate, RRC connection setup success rate, E-RAB setup success rate, service drop rate, RRC connection reestablishment success rate, cell throughput, user throughput, IBLER, RBLER, packet loss rate, MOS, idle-to-active delay, attach delay, and other delays (including web browsing delay and FTP download delay). This may increase the number of online UEs and PRB usage. If this option is selected, UEs can be transferred to NR cells by cell reselection, avoiding deterioration in the preceding performance indicators.
