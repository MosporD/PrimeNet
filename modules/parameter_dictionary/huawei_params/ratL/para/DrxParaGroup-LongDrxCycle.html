Meaning

Indicates the length of the long DRX cycle. Because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter, the actual value of this parameter assigned to a UE may be less than the configured value. In addition, the configured value will be rounded down to an integral multiple of 10. Therefore, you are advised to set this parameter to a value that is an integral multiple of 10.

If users hope that the value actually assigned to a UE is greater than or equal to 80 ms, set the TimeAlignmentTimer parameter to a value greater than or equal to 10240 ms. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the LongDrxCycle parameter be set to a value less than or equal to 320 ms. Otherwise, the uplink time alignment performance of UEs is affected. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the TimeAlignmentTimer parameter be set to sf10240. A smaller value of the TimeAlignmentTimer parameter (for example less than sf5120), increases the probability that UEs in DRX mode are out of synchronization in the uplink. The length of the long DRX cycle must be shorter than the length of the PDCP packet discarding timer for the corresponding QCI. Otherwise, packet loss occurs during a ping operation or low-traffic service. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

This parameter can be set by the eNodeB by default.

If CatType is set to LTE, the default value is the same as the recommended value with performance preferentially considered.

- FDD with performance preferentially considered:

QCI 1, QCI 65, QCI 66, and QCI 69: SF20(20 subframes)

QCI 4 and QCI 7: SF40(40 subframes)

QCI 5, QCI 6, QCI 8, QCI 9, and QCI 70: SF40(40 subframes)

- FDD with power saving preferentially considered:

QCI 1, QCI 65, QCI 66, and QCI 69: SF20(20 subframes)

QCI 4 and QCI 7: SF80(80 subframes)

QCI 5, QCI 6, QCI 8, QCI 9, and QCI 70: SF320(320 subframes)

- TDD with performance preferentially considered:

QCI 1, QCI 65, QCI 66, and QCI 69 for TDD in uplink-downlink configurations 0 to 6: SF20(20 subframes)

QCI 4 and QCI 7 for TDD in uplink-downlink configurations 0 to 6: SF40(40 subframes)

QCI 5, QCI 6, QCI 8, QCI 9, and QCI 70 for TDD in uplink-downlink configurations 0 to 6: SF40(40 subframes)

- TDD with power saving preferentially considered:

QCI 1, QCI 65, QCI 66, and QCI 69 for TDD in uplink-downlink configurations 0 to 6: SF20(20 subframes)

QCI 4 and QCI 7 for TDD in uplink-downlink configurations 0 to 6: SF80(80 subframes)

QCI 5, QCI 6, QCI 8, QCI 9, and QCI 70 for TDD in uplink-downlink configurations 0 to 6: SF320(320 subframes)

If CatType is set to EMTC_MODE_A, then:

QCI 1, QCI 65, QCI 66, and QCI 69: SF20(20 subframes)

QCIs 2 to 9 and QCI 70: SF320(320 subframes)

If CatType is set to EMTC_MODE_B, then:

QCI 1, QCI 65, QCI 66, and QCI 69: SF20(20 subframes)

QCIs 2 to 9 and QCI 70: SF2560(2560 subframes)

Impact on Radio Network Performance

This parameter, together with the OnDurationTimer, DrxInactivityTimer, ShortDrxCycle, DrxShortCycleTimer, and DrxReTxTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay and better KPIs such as the service drop rate and the handover success rate, and a larger value of this parameter results in the opposite effects.
