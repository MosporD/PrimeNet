Uplink Enhanced VoIP Schedule Switch

Meaning

Indicates whether to enable enhanced uplink scheduling for VoLTE services.

UlVoipPreAllocationSwitch: Indicates whether to perform preallocation for VoLTE UEs during talk spurts when the number of RRC_CONNECTED UEs exceeds 50 in a cell. Voice preallocation is performed only if this option is selected. This option applies only to LTE FDD.

UlVoipDelaySchSwitch: Indicates whether to perform delay-based scheduling on VoLTE UEs when there are a large number of VoLTE UEs and these UEs are evenly distributed. If this option is deselected, delay-based scheduling is not performed on VoLTE UEs. If this option is selected, the scheduling priorities are calculated based on delays. This option applies only to LTE TDD.

UlVoIPLoadBasedSchSwitch: Indicates whether to enable adaptive selection of scheduling modes for VoLTE UEs based on the cell load. Two scheduling modes are provided: dynamic scheduling and semi-persistent scheduling. If this option is deselected, adaptive selection of dynamic and semi-persistent scheduling cannot be performed for VoLTE UEs based on the cell load. If this option is selected, dynamic and semi-persistent scheduling can be adaptively selected for VoLTE UEs based on the cell load.

UlVoipSchOptSwitch: Indicates whether to enable scheduling optimization for VoLTE UEs in the uplink. If this option is deselected, this function is disabled. If this option is selected, an uplink dynamic scheduling is triggered for VoLTE UEs adopting uplink dynamic scheduling when the scheduling interval is greater than the uplink scheduling interval threshold for VoLTE UEs. This ensures timely uplink scheduling on VoLTE UEs even when SR missing detections occur, thereby avoiding packet loss caused by the expiration of the PDCP packet discarding timer.

UlVoLTEDataSizeEstSwitch: Indicates whether to enable the estimation of traffic volume dynamically scheduled for VoLTE services in the uplink. If this option is deselected, this function is disabled. If this option is selected, the eNodeB estimates the uplink traffic volume that is dynamically scheduled for VoLTE services, which shortens the VoLTE packet delay, reduces the packet loss rate, and improves the voice service quality.

UlVoipServStateEnhancedSw: Indicates whether to enable enhanced determination of VoLTE service states (either in talk spurts or silent period) in the uplink. If this option is deselected, enhanced determination is disabled. If this option is selected, enhanced determination is enabled. Selecting this option shortens the determination delay on voice service states in the uplink, decreases the probability of the voice service state being falsely determined as in the silent period, decreases the voice packet loss rate caused by SR missing detections when the UlVoipSchOptSwitch option is selected, and improves the voice quality, especially the voice quality during initial accesses and handovers.

UlVoipRblerControlSwitch: Indicates whether to enable retransmission optimization on uplink VoLTE services. If this option is deselected, retransmission optimization is disabled. If this option is selected, retransmission optimization is applied, and an MCS with a lower index is selected to decrease the voice packet loss rate caused by uplink HARQ retransmission failures when UEs running VoLTE services perform uplink adaptive retransmissions.

UlEdgeActiveSchSwitch: Indicates whether to enable active dynamic scheduling on VoLTE UEs located on cell edges. If this option is deselected, this function is disabled. If this option is selected, the eNodeB estimates the volume of traffic to be dynamically scheduled for VoLTE services in the uplink, and actively schedules VoLTE UEs if fragmentation is required due to limited uplink power according to the estimation results. By doing so, the eNodeB reduces the packet delay and timeout-caused packet loss rate for VoLTE services, and improves voice service quality. This option applies only to LTE TDD.

UlMcsRestraintAfterSpsRelSw: Indicates whether MCS restriction takes effect on uplink dynamic scheduling after uplink semi-persistent scheduling release. If this option is deselected, this function is disabled. If this option and the SpsSchSwitch option of the UlSchSwitch parameter are selected, this function is enabled, and the MCS for uplink dynamic scheduling is restricted after uplink semi-persistent scheduling release. In this way, the reliability of uplink dynamic scheduling transmission after uplink semi-persistent scheduling release can be guaranteed, and voice quality improves.

SpsAndDrxOptSwitch: Indicates whether to enable optimization of cooperation between semi-persistent scheduling and DRX. If this option is deselected, power control commands for semi-persistent scheduling can be delivered during the DRX sleep time. If this option is selected, power control commands for semi-persistent scheduling can be delivered only during the DRX On Duration period, but not during the DRX sleep time.

UlCallMuteRecoverSwitch: Indicates whether to enable voice mute recovery in the uplink. If this option is selected, the eNodeB performs voice activity detection (VAD) on UEs running voice services and performs intra-cell handovers or releases the RRC connections for UEs on which speech absence is detected to recreate the radio bearers.

UlVoipCrosslayerOptSwitch: Indicates whether to enable cross-layer optimization for VoLTE services in the uplink. If this option is deselected, the optimization is disabled. If this option is selected, the eNodeB estimates the amount of data to be dynamically scheduled in the uplink for voice services after optimizing the PDCP SDU discarding timer, eNodeB UM receiver-end reordering timer, and maximum number of MAC-layer transmissions for uplink services of QCI 1. Based on the estimation, the eNodeB selects an optimum MCS and an optimum RB number to decrease the uplink VoLTE packet loss rate and improve voice service quality.

UlVoLTEContinuousSchSw: Indicates whether to enable continuous scheduling for uplink VoLTE services. The continuous scheduling function is enabled only if this option is selected. When this function is enabled, the eNodeB continuously schedules VoLTE UEs during uplink talk spurts to reduce uplink scheduling delay, packet delay and packet jitter for VoLTE UEs and improve voice service quality.

UlMixVoLTEOptSwitch: Indicates whether to enable uplink voice and data service optimization. If this option is deselected, the optimization is disabled. If this option is selected, the eNodeB allocates bandwidths suitable for scheduling voice packets for VoLTE UEs performing both data and voice services. This ensures preferential scheduling of voice service UEs and decreases the packet loss rate of QCI 1 services in heavily loaded voice service scenarios. This option applies only to LTE TDD.

VoLTEPwrOptSwitch: Indicates whether to enable VoLTE power control optimization. If this option is selected, the power of cell edge VoLTE UEs is adjusted quickly. It is recommended that this option be selected only in high-speed railway scenarios.

UlVoLTEDelaySchEnhancedSw: Indicates whether to enhance delay-based dynamic scheduling for VoLTE services in the uplink. If this option is deselected, the eNodeB does not enhance delay-based dynamic scheduling for VoLTE services in the uplink. If this option is selected and the UlDelaySchStrategy parameter in the CellUlschAlgo MO is set to VOIP_AND_DATA_DELAYSCH(VoIP and Data Delay Scheduling), the eNodeB enhances delay-based dynamic scheduling for VoLTE services in the uplink. This option applies only to LTE TDD.

AmrVoiceFrameSmartCoverySw: Indicates whether to enable smart recovery of AMR voice frames. If this option is selected, the eNodeB recovers certain voice frames with transmission errors based on the importance of voice frames at the RLC layer. This option applies only to LTE FDD and LTE TDD.

EnhancedUlVoipAmcSw: Indicates whether to enable the enhanced uplink voice-specific AMC function. If this option is selected, this function takes effect. For UEs running voice services in LTE FDD cells, the eNodeB selects an initial SINR adjustment value based on the cell-specific adjustment value and increases uplink power based on the BLER. For UEs running voice services in LTE TDD cells, the eNodeB increases uplink power based on the BLER. If this option is deselected, this function does not take effect. This option applies only to LTE FDD and LTE TDD.

UlMcpttCrossLayerOptSw: Indicates whether to enable cross-layer optimization for MCPTT services in the uplink. If this option is deselected, the optimization is disabled. If this option is selected, the eNodeB estimates the amount of data to be dynamically scheduled in the uplink for MCPTT services after optimizing the uplink PDCP discarding timer and eNodeB UM receiver-end reordering timer for services of QCI 65 and QCI 66 and maximum number of uplink MAC-layer transmissions. Based on the estimation, the eNodeB selects an optimum MCS and an optimum number of RBs to decrease the uplink MCPTT packet loss rate and improve voice service quality. This option takes effect for services of QCI 65 only when the GlobalProcSwitch.LcgProfile parameter is set to LCG_PROFILE_3. This option applies only to LTE FDD and LTE TDD.

VoltePdcchDtxOptSwitch: Indicates whether to enable optimization when the PDCCH is not detected by VoLTE UEs or DTX is falsely detected on the PUSCH transmitted by VoLTE UEs. The function is enabled only if this option is selected. This option applies only to LTE FDD.

PttVoiceOptSw: Indicates whether to enable PTT voice optimization. If this option is selected, PTT voice optimization is enabled. If this option is deselected, PTT voice optimization is disabled. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

UlVoipPreAllocationSwitch: If this option is selected, preallocation applies to VoLTE services even in large traffic scenarios, decreasing the packet delay and packet loss rate of VoLTE services.

UlVoipDelaySchSwitch: If this option is selected, the voice service delay decreases and the voice service experience is improved for users at medium or long distances from the cell center.

UlVoIPLoadBasedSchSwitch: If this option is selected, the capacity for UEs running voice services increases compared with the capacity allowed when the option is deselected and dynamic scheduling is adopted, and the transmission efficiency is improved compared with when the option is deselected and semi-persistent scheduling is adopted.

UlVoipSchOptSwitch: If this option is selected, an uplink dynamic scheduling attempt is triggered for voice UEs adopting uplink dynamic scheduling if the scheduling interval is greater than the uplink scheduling interval threshold for voice UEs. This ensures timely uplink scheduling on VoLTE UEs even when SR missing detections occur, thereby avoiding packet loss caused by the expiration of the PDCP packet discarding timer.

UlVoLTEDataSizeEstSwitch: If this option is selected, traffic volume estimation on dynamically scheduled uplink VoLTE services is enabled. As a result, the packet delay and packet loss rate of VoLTE services decrease, and VoLTE service quality improves. However, the number of RBs and that of CCEs consumed by UEs running VoLTE services increase, and therefore the cell throughput and UE throughput decrease.

UlVoipServStateEnhancedSw: If this option and the UlVoipSchOptSwitch option are selected, the voice packet loss rate caused by SR missing detections decreases, and the voice quality improves, especially the voice quality during initial accesses and handovers. However, more RBs and CCEs are consumed by voice UEs in uplink dynamic scheduling, and therefore the cell throughput and UE throughput decrease.

UlVoipRblerControlSwitch: If this option is selected and UEs running voice services perform uplink adaptive retransmissions, retransmission optimization is applied. In this way, the voice packet loss rate caused by uplink HARQ retransmission failures decreases.

UlEdgeActiveSchSwitch: If this option is selected, the packet delay and packet loss rate of VoLTE UEs located on cell edges decrease, and voice quality increases. However, the number of RBs consumed by voice UEs increases, causing the cell throughput and UE throughput to decrease.

UlMcsRestraintAfterSpsRelSw: If this option is selected, the reliability of uplink dynamic scheduling transmission after uplink semi-persistent scheduling release improves. Especially, the uplink voice packet loss rate decreases and voice service quality improves after uplink semi-persistent scheduling release caused by poor channel quality. However, for UEs with dynamic scheduling applied after uplink semi-persistent scheduling release, the uplink average MCS index decreases, uplink RB usage increases, the probability of activating semi-persistent scheduling in the uplink decreases, and uplink CCE usage increases.

SpsAndDrxOptSwitch: If this option is deselected, transmit power control (TPC) commands can be delivered during DRX sleep time in semi-persistent scheduling, causing UEs' failure to receive the commands for uplink TPC. As a result, the packet loss rate increases and voice service quality deteriorates for UEs with semi-persistent scheduling applied. If this option is selected, TPC commands can be delivered only during DRX On Duration in semi-persistent scheduling. As a result, the packet loss rate decreases and voice service quality improves for UEs with semi-persistent scheduling applied.

UlCallMuteRecoverSwitch: If this option is selected, the eNodeB performs intra-cell handover or releases the RRC connection for UEs on which uplink speech absence is detected. The aim of the handover or RRC connection release is to reconfigure the radio bearer and attempt to recover the voice communication. However, if the handover fails, the service drop rate increases.

UlVoipCrosslayerOptSwitch: If this option is selected, the eNodeB increases the lengths of the PDCP SDU discarding timer and the eNodeB UM receiver-end reordering timer and the maximum number of MAC-layer transmissions for uplink services of QCI 1. As a result, radio interface delay increases for VoLTE UEs with poor uplink coverage. However, the uplink packet loss rate decreases for such UEs, improving the voice service quality.

UlVoLTEContinuousSchSw: If this option is selected, the uplink packet delay and jitter decrease for VoLTE services and voice service quality improves. However, the RB and CCE resource consumption by VoLTE UEs increases, causing cell throughput and UE throughput to decrease.

UlMixVoLTEOptSwitch: If this option is selected, the VoLTE UE packet loss rate decreases in heavily loaded scenarios and voice quality improves. However, the scheduling delay of data service UEs increases, causing cell throughput and UE throughput to decrease.

VoLTEPwrOptSwitch: If this option is selected, the power of cell edge VoLTE UEs is adjusted quickly, which decreases the packet loss rate of cell edge VoLTE UEs and increases the MOS of VoLTE UEs. Deselecting this option has no impact on the network performance.

UlVoLTEDelaySchEnhancedSw: If this option is selected and the UlDelaySchStrategy parameter in the CellUlschAlgo MO is set to VOIP_AND_DATA_DELAYSCH(VoIP and Data Delay Scheduling), the eNodeB enhances delay-based dynamic scheduling for VoLTE services in the uplink, reducing the impact of VoLTE services on data services and lowering the RRC connection reestablishment rate in heavy-load scenarios. This option applies only to LTE TDD.

AmrVoiceFrameSmartCoverySw: If this option is selected, the eNodeB compensates voice frames when unimportant voice frames experience transmission errors. This helps reduce the voice FER and improve the voice capacity and voice quality.

EnhancedUlVoipAmcSw: If this option is selected, the eNodeB selects an initial SINR adjustment value based on the cell-specific adjustment value for UEs running voice services, and therefore selects a more reliable MCS for such UEs. The eNodeB also increases uplink power based on the RBLER, achieving more timely power control and lowering the uplink QCI 1 packet loss rate. However, a power increase causes more interference to neighboring cells and a slight decrease in the uplink user-perceived rate. If this option is deselected, network performance is not affected.

UlMcpttCrossLayerOptSw: If this option is selected, the eNodeB increases the lengths of the uplink PDCP discarding timer and eNodeB UM receiver-end reordering timer for services of QCI 65 and QCI 66 and the maximum number of uplink MAC-layer transmissions. As a result, radio interface delay increases for MCPTT UEs with poor uplink coverage. However, the uplink packet loss rate decreases for these UEs, improving the voice service quality. If this option is deselected, there is no impact on radio network performance.

VoltePdcchDtxOptSwitch: If this option is selected, the CCE usage may increase in the cell. If this option is deselected, network performance is not affected.

PttVoiceOptSw: If this option is selected, PTT voice packet sizes can be accurately identified, improving PTT voice service quality; however, the quality of other services may be affected. If this option is deselected, network performance is not affected.
