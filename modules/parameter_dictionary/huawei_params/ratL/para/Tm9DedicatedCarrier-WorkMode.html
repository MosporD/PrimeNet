Meaning

Indicates the working mode of the TM9-dedicated carrier. When this parameter is set to TM9_DEDICATED_SCC, the TM9-dedicated carrier can be configured only as an SCC. When this parameter is set to TM9_DEDICATED_CC, the TM9-dedicated carrier can be configured as a PCC or an SCC. When this parameter is set to R10PLUS_DEDICATED_CC, the TM9-dedicated carrier can only be used by UEs complying with 3GPP Release 10 or later. If this parameter is set to NON_TM9_SCC, the TM9-dedicated carrier can be configured as an SCC for TM9-incapable UEs and as a PCC or SCC for TM9-capable UEs. This parameter applies only to LTE FDD.

Impact on Radio Network Performance

When this parameter is set to TM9_DEDICATED_SCC, the TM9-dedicated carrier can be configured with one CRS port, reducing the CRS overhead and interference and yielding large throughput gains. When this parameter is set to TM9_DEDICATED_CC, the TM9-dedicated carrier can be configured as a PCC or SCC for TM9 UEs. In this case, the configuration of two CRS ports is recommended. This yields smaller UE throughput gains than the dedicated TM9 carrier configured as an SCC, but assures the handover success rate and the service drop rate. Setting this parameter to R10PLUS_DEDICATED_CC has no impact on network performance. When this parameter is set to NON_TM9_SCC, the proportion of traffic volume absorbed by the TM9-dedicated carrier increases. Therefore, the value NON_TM9_SCC is favourable to scenarios with a low penetration rate of TM9-capable UEs.
