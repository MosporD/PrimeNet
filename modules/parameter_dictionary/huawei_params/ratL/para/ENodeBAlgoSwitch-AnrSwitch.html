ANR algorithm switch

MO ENodeBAlgoSwitch
Parameter ID AnrSwitch
Parameter Name

ANR algorithm switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD ENODEBALGOSWITCH

LST ENODEBALGOSWITCH
Meaning

Indicates whether to enable automatic neighbor relation (ANR). This parameter provides the following options:

IntraRatEventAnrSwitch: If this option is selected, intra-RAT event-triggered ANR is enabled. This type of ANR sets up and optimizes intra-RAT neighbor relationships based on intra-RAT handover events. This option applies only to LTE FDD and LTE TDD.

IntraRatFastAnrSwitch: If this option is selected, intra-RAT fast ANR is enabled. This type of ANR sets up and optimizes intra-RAT neighbor relationships based on periodic intra-RAT measurement. This option applies only to LTE FDD and LTE TDD.

IntraRatAnrAutoDelSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can automatically remove intra-RAT neighbor relationships with cells for which NoRmvFlag is set to PERMIT_RMV_ENUM. If the IntraRatAnrAutoDelSwitch option is deselected, the eNodeB cannot automatically remove intra-RAT neighbor relationships. This option applies only to LTE FDD and LTE TDD.

UtranEventAnrSwitch: If this option is selected, event-triggered ANR with UTRAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with UTRAN cells based on events for coverage-based handovers to UTRAN. This option applies only to LTE FDD and LTE TDD.

GeranEventAnrSwitch: If this option is selected, event-triggered ANR with GERAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with GERAN cells based on events for coverage-based handovers to GERAN. This option applies only to LTE FDD and LTE TDD.

UtranFastAnrSwitch: If this option is selected, fast ANR with UTRAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with UTRAN cells based on periodic UTRAN measurement. UEs measure only neighboring cells contained in measurement configurations, in which the eNodeB does not include external UTRAN cells. To enable external UTRAN cells added by fast ANR as neighboring cells to be measured for handovers, you are advised to also select the UtranEventAnrSwitch option. This option applies only to LTE FDD and LTE TDD.

GeranFastAnrSwitch: If this option is selected, fast ANR with GERAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with GERAN cells based on periodic GERAN measurement. This option applies only to LTE FDD and LTE TDD.

UtranAutoNrtDeleteSwitch: If both this option and the UtranEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with UTRAN cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with UTRAN cells. This option applies only to LTE FDD and LTE TDD.

GeranAutoNrtDeleteSwitch: If both this option and the GeranEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with GERAN cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with GERAN cells. This option applies only to LTE FDD and LTE TDD.

CdmaAutoNrtDeleteSwitch: If both this option and the CdmaEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with CDMA2000 cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with CDMA2000 cells. This option applies only to LTE FDD and LTE TDD.

CdmaEventAnrSwitch: If this option is selected, event-triggered ANR with CDMA is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with CDMA2000 cells based on events for handovers to CDMA2000 cells. This option applies only to LTE FDD and LTE TDD.

MlbBasedEventAnrSwitch: Indicates whether to enable MLB-based event-triggered ANR. If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can automatically set up and optimize inter-frequency neighbor relationships based on inter-frequency MLB measurement. If both this option and the option for event-triggered inter-RAT ANR (UtranEventAnrSwitch or GeranEventAnrSwitch) are selected, the eNodeB can automatically set up and optimize neighbor relationships with cells of that RAT based on measurement for MLB to that RAT. If this option is deselected, the eNodeB does not set up or optimize neighbor relationships based on MLB measurement. This option applies only to LTE FDD and LTE TDD.

IntraRatNoHoSetAnrSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB automatically sets the NoHoFlag parameter for intra-RAT neighbor relationships. If this option is deselected, the eNodeB does not modify the NoHoFlag parameter. When this option is selected, pay attention to the neighboring cells for which the NoHoFlag parameter is set to FORBID_HO_ENUM(Forbid Ho) by ANR so as to prevent any impact on handover performance. This option takes effect only when the OptMode parameter is set to FREE. This option applies only to LTE FDD and LTE TDD.

IntraRatDoubleThdAnrSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can automatically set up and optimize intra-RAT neighbor relationships based on events for intra-RAT ANR measurement. Configurations can ensure that the probability of triggering intra-RAT ANR measurement is higher than or equal to that of triggering measurement for coverage-based handovers. If this option is deselected, the eNodeB cannot set up or optimize intra-RAT neighbor relationships based on events for intra-RAT ANR measurement. This option applies only to LTE TDD.

ServiceBasedEventAnrSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can set up and optimize intra-RAT inter-frequency neighbor relationships based on service-based inter-frequency handovers. If both this option and the UtranEventAnrSwitch option are selected, the eNodeB can set up and optimize neighbor relationships with UTRAN cells based on service-based handovers. This option applies only to LTE FDD and LTE TDD.

ServiceReqEventAnrSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can set up and optimize intra-RAT inter-frequency neighbor relationships based on service-request-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

IntraRatEnhancedEventAnrSwitch: Indicates whether to enable event-triggered ANR based on handovers excluding coverage-based, MLB-based, service-based, and service-request-based handovers. If both this option and the IntraRatEventAnrSwitch option are selected and the frequency-specific ANR indicator is set to allow ANR, intra- and inter-frequency neighbor relationships can be set up and optimized based on corresponding intra-RAT handover events. If this option is deselected, neighbor relationships cannot be set up or optimized based on corresponding intra-RAT handover events. This option applies only to LTE FDD and LTE TDD.

InterFreqAngcAnrSwitch: Indicates whether to enable ANGC-based event-triggered inter-frequency ANR. If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB automatically adds a neighbor relationship with a neighboring cell detected based on ANGC. This option applies only to LTE FDD and LTE TDD.

CaBasedEventAnrSwitch: Indicates whether to enable event-triggered ANR based on CA measurements. If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can set up neighbor relationships with cells detected during CA measurement. In addition, when PCI confusions occur, the eNodeB acquires ECGIs to identify target cells. This option applies only to LTE FDD and LTE TDD.

UtranUpdateRacSwitch: If this option is selected and no RAC is configured for an inter-RAT external UTRAN cell, the eNodeB re-instructs UEs to read the CGI of this cell to obtain its RAC if these UEs detect that the cell provides the strongest signals during ANR. If this option is deselected, the eNodeB does not re-instruct UEs to read the CGI of the cell in the preceding scenario. This option applies only to LTE FDD and LTE TDD.

GeranUpdateRacSwitch: If this option is selected and no RAC is configured for an external GERAN cell, the eNodeB will re-instruct UEs to read the CGI of this cell to obtain its RAC if these UEs detect that the cell provides the strongest signals during fast ANR measurements. If this option is deselected, the eNodeB does not re-instruct UEs to read the CGI of the cell during fast ANR measurements in the preceding scenario. This option applies only to LTE FDD and LTE TDD.

MfbiAnrOptSwitch: If this option is selected, ANR does not update external cells that have the same physical frequency as the local cell and different downlink EARFCNs from the local cell when the master band flag is not configured. If this option is deselected, ANR updates external cells that have the same physical frequency as the local cell and smaller downlink EARFCNs than the local cell when the master band flag is not configured. This option applies only to LTE FDD and LTE TDD.

FastAnrUeSelOptSwitch: If this option is selected, the eNodeB selects only UEs that newly access its served cells and UEs that are newly handed over to its served cells for fast ANR measurements. If this option is deselected, the eNodeB selects UEs whose RRC connections are reestablished to the eNodeB in addition to the preceding two types of UEs for fast ANR measurements. This option applies only to LTE FDD and LTE TDD.

NrNetworkingOptionUptSwitch: If this option is selected, the eNodeB queries the networking information of external NR cells from the element management system and updates NrExternalCell.NrNetworkingOption and NrExternalCellPlmn.NrNetworkingOption based on the queried information. This option applies only to LTE FDD and LTE TDD.

NsaDcPccAnchoringEventAnrSw: Indicates whether to enable event-triggered ANR based on NSA DC PCC anchoring measurements. When the intra-RAT event-triggered ANR function is enabled, there are the following situations: If this option is selected, the eNodeB can add and optimize intra-RAT neighbor relationships based on intra-RAT NSA DC PCC anchoring measurements. If this option is deselected, the eNodeB does not add or optimize intra-RAT neighbor relationships based on intra-RAT NSA DC PCC anchoring measurements. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

IntraRatEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing intra-RAT neighboring cells, increasing the intra-RAT handover success rate and lowering the service drop rate. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing intra-RAT neighboring cells using intra-RAT event-triggered ANR. In this case, handovers fail or services drop due to missing neighboring cells.

IntraRatFastAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing intra-RAT neighboring cells, increasing the intra-RAT handover success rate and lowering the service drop rate. However, the throughput of UEs decreases during PCI measurements and CGI reading for fast ANR. If this option is deselected, the eNodeB cannot automatically detect missing intra-RAT neighboring cells using intra-RAT fast ANR. In this case, handovers fail or services drop due to missing neighboring cells.

IntraRatAnrAutoDelSwitch: If this option is selected, the eNodeB automatically detects and deletes incorrectly configured or redundant intra-RAT neighboring cells, increasing the intra-RAT handover success rate and lowering the service drop rate. If this option is deselected, the eNodeB cannot automatically delete such neighboring cells.

UtranEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring UTRAN cells, increasing the E-UTRAN-to-UTRAN handover success rate and lowering the service drop rate. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing neighboring UTRAN cells using event-triggered ANR with UTRAN. In this case, handovers fail or services drop due to missing neighboring cells.

GeranEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring GERAN cells, increasing the E-UTRAN-to-GERAN handover success rate and lowering the service drop rate. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing GERAN neighboring cells using event-triggered ANR with GERAN. In this case, handovers fail or services drop due to missing neighboring cells.

UtranFastAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring UTRAN cells, increasing the E-UTRAN-to-UTRAN handover success rate and lowering the service drop rate. However, the throughput of UEs decreases during fast ANR measurements. If this option is deselected, the eNodeB cannot automatically detect missing neighboring UTRAN cells using fast ANR with UTRAN. In this case, handovers fail or services drop due to missing neighboring cells.

GeranFastAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring GERAN cells, increasing the E-UTRAN-to-GERAN handover success rate and lowering the service drop rate. However, the throughput of UEs decreases during fast ANR measurements. If this option is deselected, the eNodeB cannot automatically detect missing neighboring GERAN cells using fast ANR with GERAN. In this case, handovers fail or services drop due to missing neighboring cells.

UtranAutoNrtDeleteSwitch: If this option is selected, the eNodeB automatically detects and deletes redundant UTRAN neighboring cells. If this option is deselected, the eNodeB cannot automatically detect and delete redundant UTRAN neighboring cells.

GeranAutoNrtDeleteSwitch: If this option is selected, the eNodeB automatically detects and deletes redundant neighboring GERAN cells. If this option is deselected, the eNodeB cannot automatically detect and delete such neighboring cells.

CdmaAutoNrtDeleteSwitch: If this option is selected, the eNodeB automatically detects and deletes redundant neighboring CDMA2000 cells. If this option is deselected, the eNodeB cannot automatically detect and delete such neighboring cells.

CdmaEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring CDMA2000 cells, increasing the E-UTRAN-to-CDMA handover success rate and lowering the service drop rate. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing neighboring CDMA2000 cells using event-triggered ANR with CDMA. In this case, handovers fail or services drop due to missing neighboring cells.

MlbBasedEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring cells based on measurements for MLB, increasing the success rate of handovers for MLB. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing neighboring cells based on measurements for MLB to set up or optimize neighbor relationships.

IntraRatDoubleThdAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring cells based on intra-RAT ANR measurements, typically before handovers are triggered. This type of ANR reduces the impact of ANR on intra-RAT handover delay while not affecting the intra-RAT handover success rate, but the signaling load over the Uu interface increases. If this option is deselected, intra-RAT neighbor relationships cannot be set up or optimized based on missing neighboring cells automatically detected using intra-RAT ANR measurements.

IntraRatEnhancedEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing neighboring cells based on intra-RAT handover events, increasing the intra-RAT handover success rate. However, the throughput of UEs decreases and the handover delay increases during CGI reading. If this option is deselected, the eNodeB cannot automatically detect missing neighboring cells based on intra-RAT handover events to set up or optimize neighbor relationships.

CaBasedEventAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing intra-RAT neighboring cells based on CA events. In this case, CA can be performed for missing neighboring cells, increasing the throughput of UEs. If this option is deselected, the eNodeB cannot automatically detect missing intra-RAT neighboring cells based on CA events. In this case, CA cannot be performed for missing intra-RAT neighboring cells.

InterFreqAngcAnrSwitch: If this option is selected, the eNodeB automatically detects and adds missing intra-RAT neighboring cells, and detects overlapping neighboring cells based on ANGC. However, the throughput of UEs decreases during CGI reading. If this option is deselected, the eNodeB does not automatically detect missing intra-RAT neighboring cells based on ANGC inter-frequency additional measurement events. In this case, the throughput of UEs is not affected.

GeranUpdateRacSwitch/UtranUpdateRacSwitch: If no RAC is configured for a GERAN or UTRAN cell, selecting this option increases the CGI reading delay of UEs to be handed over to this cell. This increase the risk of service drops. If an RAC is configured for a GERAN or UTRAN cell but the RAC is not set when this cell is added as a neighboring cell for the E-UTRAN cell, RIM procedures for flash CSFB and PS handovers to this GERAN or UTRAN cell cannot be initiated, and therefore only redirections can be performed.

MfbiAnrOptSwitch: If this option is selected, ANR does not update downlink EARFCNs of external cells, preventing the update from causing handover exceptions in scenarios where the primary-band-specific and secondary-band-specific EARFCNs of a multi-band cell are inconsistent. If this option is deselected, the primary-band-specific and secondary-band-specific EARFCNs must be consistent for all multi-band cells on the network. Otherwise, ANR may update incorrect downlink EARFCNs of external cells.

FastAnrUeSelOptSwitch: If this option is selected, the eNodeB does not select UEs whose RRC connections are reestablished to the eNodeB for fast ANR measurements. This prevents repeated RRC connection reestablishments caused by UE incompatibility. However, the number of UEs selected for fast ANR measurements decreases, and therefore the neighbor relationship building efficiency of fast ANR also decreases. If this option is deselected, UEs whose RRC connections are reestablished to the eNodeB are selected for fast ANR measurements, improving the neighbor relationship building efficiency of fast ANR.

NsaDcPccAnchoringEventAnrSw: If this option is selected, the eNodeB automatically detects intra-RAT missing neighboring cells based on NSA DC PCC anchoring measurements and adds neighbor relationships with these cells to the NRTs so that UEs can be handed over to these neighboring cells. However, ECGI reading decreases UE throughput. If this option is deselected, the eNodeB cannot automatically detect intra-RAT missing neighboring cells based on NSA DC PCC anchoring measurements. In this case, UE throughput is not affected.
