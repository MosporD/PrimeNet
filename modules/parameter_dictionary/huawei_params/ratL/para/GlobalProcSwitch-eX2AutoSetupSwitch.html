MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether eX2 self-setup in ideal backhaul mode, eX2 self-setup in non-ideal backhaul mode, and eX2 self-setup in intra-physical-network-domain ideal backhaul mode take effect. This parameter provides the following options:

BASED_ON_EX2_IDEAL_MODE: If this option is selected, eX2 self-setup in ideal backhaul mode takes effect. If this option is deselected, the local eNodeB does not initiate eX2 self-setup in ideal mode or respond to the eX2 self-setup request in deal backhaul mode sent from a peer eNodeB. This option applies only to LTE FDD and LTE TDD.

BASED_ON_EX2_NON_IDEAL_MODE: If this option is selected, eX2 self-setup in non-ideal backhaul mode takes effect. However, if there are multiple eX2 interfaces in non-ideal backhaul mode, this function does not take effect. If this option is deselected, the local eNodeB does not initiate eX2 self-setup in non-ideal mode or respond to the eX2 self-setup request in non-deal backhaul mode sent from a peer eNodeB. This option applies only to LTE FDD and LTE TDD.

EX2_INTRA_PHYNET_IDEAL: If this option is selected, eX2 self-setup in intra-physical-network-domain ideal backhaul mode takes effect. If this option is deselected, the local eNodeB does not initiate eX2 self-setup in intra-physical-network-domain ideal mode or respond to the eX2 self-setup request in intra-physical-network-domain deal backhaul mode sent from a peer eNodeB. This option applies only to LTE FDD and LTE TDD.
