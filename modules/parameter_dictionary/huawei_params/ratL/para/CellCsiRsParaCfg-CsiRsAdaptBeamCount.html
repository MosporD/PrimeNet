Meaning

Indicates the number of CSI-RS beams during CSI-RS beam adaptation. If this parameter is set to ADAPTIVE_BEAM_DISABLED, CSI-RS beam adaptation is disabled. If this parameter is set to a value other than ADAPTIVE_BEAM_DISABLED, the number in the value indicates the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation. For example, if this parameter is set to CSI_RS_BEAM_5, the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation is 5. This parameter applies only to LTE FDD.

Caution

Modification of this parameter triggers CSI-RS configuration addition or removal, increasing the number of RRC connection reconfiguration times. Therefore, do not modify this parameter frequently. It is recommended that this parameter be modified only when the TM9 penetration rate changes significantly.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If this parameter is set to ADAPTIVE_BEAM_DISABLED, network performance is not affected. If this parameter is set to a value other than ADAPTIVE_BEAM_DISABLED, a larger value leads to a greater impact on UEs that cannot identify CSI-RSs, but TM9 can be used for more UEs and therefore TM9-related features can produce higher performance gains.
