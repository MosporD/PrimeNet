Meaning

Indicates whether to enable TTI bundling optimization.

TTIB_EXIT_BASED_ON_QCI_SW: Indicates whether to enable exit from TTI bundling for specific QCIs. If this option is selected, UEs exit TTI bundling after beneficiary bearers (applicable to VoLTE, PTT, and video services) are removed. If this option is deselected, the exit is not supported. This option applies only to LTE FDD.

TTIBUNDLING_ALGO_ENHANCE_SW: Indicates whether to enable TTI bundling during handovers or RRC connection reestablishments and use high-index MCSs for TTI bundling. TTI bundling is enabled during handovers and RRC connection reestablishments (applicable to VoLTE and PTT) and high-index MCSs are used for TTI bundling (applicable to VoLTE, PTT, and video services) only when this option is selected. This option applies only to LTE FDD.

Impact on Radio Network Performance

TTIB_EXIT_BASED_ON_QCI_SW: If this option is selected and a UE exits TTI bundling at removal of bearers that benefit from TTI bundling in a weak coverage area, there is a risk of deterioration in the RRC connection reestablishment success rate and the service drop rate. If this option is deselected and a UE initiates an uplink data service after the bearer removal, the uplink service throughput of this UE, which is in the TTI bundling state, is limited.

TTIBUNDLING_ALGO_ENHANCE_SW: If this option is selected, TTI bundling is enabled in handover and reestablishment scenarios. TTI bundling uses a high-order MCS, which allows more UEs to enter TTI bundling, increases the uplink average MCS index, decreases the number of scheduling times, and saves PDCCH CCE resources. If this option is deselected, there is no impact on radio network performance.
