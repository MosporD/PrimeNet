Meaning

Indicates the threshold for an RRC connection penalty on NB-IoT UEs. Certain UEs may repeatedly fail to access the network because of compatibility issues. If this parameter is set to 0, the RRC connection penalty function is disabled. If this parameter is set to a non-zero value, the function is enabled. If the number of RRC connection setup requests that the base station receives from a UE within the RRC connection penalty period exceeds the threshold, the base station imposes a penalty on the UE, rejecting RRC connection setup requests from the UE. Alternatively, if the number of RRC connection resume requests that the base station receives from a UE within this period exceeds the threshold, the base station rejects RRC connection resume requests from the UE. The length of the RRC connection penalty period is equal to min{T300ForNb + FilterReptRrcConnReqTimer, MaxFilterTimer}. In V100R015C10 or an earlier version, the value of MaxFilterTimer is 17s. In other cases, the value of MaxFilterTimer is 35s.

This parameter takes effect for NB-IoT UEs. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

On networks with frequent RRC connection setups of abnormal UEs, a smaller value of this parameter results in a higher probability of triggering RRC connection penalties and less resource consumption for NB-IoT UE access, but longer delay for the affected NB-IoT UEs to re-access the networks. On such networks, a larger value of this parameter results in a lower probability of triggering RRC connection penalties. However, more frequent NB-IoT UE access causes consumption of more network resources.
