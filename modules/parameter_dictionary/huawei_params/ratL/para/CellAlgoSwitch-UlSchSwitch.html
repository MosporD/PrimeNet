Uplink schedule switch

MO CellAlgoSwitch
Parameter ID UlSchSwitch
Parameter Name

Uplink schedule switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLALGOSWITCH

LST CELLALGOSWITCH
Meaning

Indicates whether to enable uplink scheduling functions for the cell.

SpsSchSwitch: Indicates whether to enable semi-persistent scheduling during talk spurts of VoLTE services. If this option is selected, semi-persistent scheduling is applied. If this option is deselected, dynamic scheduling is applied. This option applies only to LTE FDD and LTE TDD.

PreAllocationSwitch: Indicates whether to enable uplink preallocation. If this option is selected: (1) If the SmartPreAllocationSwitch option is deselected and a UE is in the discontinuous reception (DRX) state, preallocation is stopped for the UE; (2) If the SmartPreAllocationSwitch option is deselected and the UE is not in the DRX state, preallocation is started for the UE; (3) If the SmartPreAllocationSwitch option is selected and the SmartPreAllocationDuration parameter value is greater than 0, smart preallocation is performed for the UE; (4) If the SmartPreAllocationSwitch option is selected and the SmartPreAllocationDuration parameter value is 0, preallocation is not performed for the UE. If this option is deselected, uplink preallocation is disabled. If bearer-level preallocation or bearer-level smart preallocation is enabled for a bearer of a specific QCI, cell-level preallocation and cell-level smart preallocation do not apply to UEs with bearers of this QCI. This option applies only to LTE FDD and LTE TDD.

UlVmimoSwitch: Indicates whether to enable multi-user MIMO (MU-MIMO) in the uplink. If this option is selected, the eNodeB performs MU-MIMO pairing among UEs based on related principles. UEs forming a pair transmit data using the same time-frequency resources, which improves the system throughput and spectral efficiency. This option applies only to LTE FDD and LTE TDD.

TtiBundlingSwitch: Indicates whether to enable transmission time interval (TTI) bundling. If TTI bundling is enabled, more transmission opportunities are available to UEs within the delay budget for VoLTE services on the Uu interface, improving uplink coverage. This option applies only to LTE FDD and LTE TDD.

SmartPreAllocationSwitch: Indicates whether to enable uplink smart preallocation when the PreAllocationSwitch option is selected. If both the PreAllocationSwitch option and this option are selected and the SmartPreAllocationDuration parameter in the CellPreallocGroup MO is set to a value greater than 0, uplink smart preallocation is enabled. Otherwise, uplink smart preallocation is disabled. This option applies only to LTE FDD and LTE TDD.

PuschDtxSwitch: Indicates whether the eNodeB uses the PUSCH discontinuous transmission (DTX) detection result during uplink scheduling. If this option is selected for an LTE FDD cell, the eNodeB determines whether to perform adaptive retransmission, and also adjusts the CCE aggregation level of the PDCCH carrying downlink control information (DCI) format 0 based on the PUSCH DTX detection result during uplink scheduling. If an LTE FDD cell is established on an LBBPc, this option takes effect only if the cell uses less than four RX antennas and normal cyclic prefix (CP) in the uplink and the SrsCfgInd parameter in the SRSCfg MO is set to BOOLEAN_TRUE(True). Note that the LBBPc does not support PUSCH DTX detection for MU-MIMO UEs. For an LTE TDD cell, this option takes effect only when uplink-downlink subframe configuration 2 or 5 is used. If this option takes effect, the eNodeB adjusts the CCE aggregation level based on the PUSCH DTX detection results. Note that LTE TDD cells established on LBBPc boards do not support PUSCH DTX detection. This option applies only to LTE FDD and LTE TDD.

UlIblerAdjustSwitch: Indicates whether to enable the uplink IBLER adjustment algorithm. If this option is selected, the target IBLER is adjusted for UEs based on the channel quality and fluctuation to increase the cell throughput. This option applies only to LTE FDD and LTE TDD. If this option is selected for FDD cells with the UlTargetIBlerAdaptType option deselected, the algorithm does not take effect.

UlEnhancedFssSwitch: Indicates whether to enable uplink load-based enhanced frequency selective scheduling. This option applies only to LTE FDD.

UlEnhancedSrSchSwitch: For FDD and TDD cells, this option indicates whether uplink re-scheduling is performed only when the On Duration timer for the DRX long cycle starts (if DRX is enabled). Uplink re-scheduling is required if the number of HARQ retransmissions in an SR-based uplink scheduling reaches the maximum value and the last retransmission still fails. If this option is selected, uplink re-scheduling is performed only when the On Duration timer for the DRX long cycle starts. If this option is deselected, uplink re-scheduling is performed immediately after the last retransmission fails. It is recommended that this option be selected for live networks. For NB-IoT cells, this option indicates whether to perform preallocation for SR-based uplink RRC signaling. Preallocation is performed for SR-based uplink RRC signaling only if this option is selected.

SchedulerCtrlPowerSwitch: Indicates whether the uplink scheduler performs scheduling without considering power control restrictions. If this option is selected, the uplink scheduler performs scheduling without considering power control restrictions, ensuring full utilization of the transmit power for UEs. If this option is deselected, the uplink scheduler considers power control restrictions when performing scheduling. In this case, the transmit power cannot be fully used for UEs at the cell edge or between the cell edge and cell center. This option applies only to LTE FDD and LTE TDD.

UlMinGbrSwitch: Indicates whether to ensure uplink minimum guaranteed bit rate (GBR). If this option is selected, the minimum GBR of non-GBR services is ensured by increasing the scheduling priority of UEs whose non-GBR service rates are lower than the minimum GBR. This option applies only to LTE FDD and LTE TDD.

UlMbrCtrlSwitch: Indicates whether to enable the uplink scheduling mode in support of the basic feature "MBR>GBR Configuration". If this option is selected, the eNodeB performs uplink scheduling on GBR bearers based on the MBR and GBR. If this option is deselected, the eNodeB performs uplink scheduling on GBR bearers based only on the GBR. This option applies only to LTE FDD and LTE TDD.

MbrUlSchSwitch: Indicates whether the eNodeB performs uplink scheduling based on the MBR. If this option is selected, the eNodeB prioritizes UEs based on the MBRs during uplink scheduling. This option applies only to LTE FDD and LTE TDD.

UeAmbrUlSchSwitch: Indicates whether the eNodeB performs uplink scheduling based on UE-AMBRs. If this option is selected, the eNodeB prioritizes UEs based on UE-AMBRs during uplink scheduling. This option applies only to LTE FDD and LTE TDD.

UlEnhancedDopplerSwitch: Indicates whether to enable enhanced uplink scheduling based on mobility speed estimation. If this option is selected, enhanced uplink scheduling based on mobility speed estimation is enabled. In enhanced uplink scheduling based on mobility speed estimation, the eNodeB uses Doppler measurement results to identify low-speed UEs to further improve uplink performance of low-speed UEs. If this option is deselected, enhanced uplink scheduling based on mobility speed estimation is disabled. Enhanced uplink scheduling based on mobility speed estimation takes effect only when the DopMeasLevel parameter is set to CLASS_1(CLASS_1) and the UlEnhancedDopplerSwitch option is selected. Enhanced uplink scheduling based on mobility speed estimation does not take effect for cells established on an LBBPc. Enhanced uplink scheduling based on mobility speed estimation applies only to LTE FDD. This option applies only to LTE FDD.

UlRaUserSchOptSw: Indicates whether the eNodeB raises the scheduling priority for UEs sending uplink access signaling, including MSG5 and the RRC Connection Reconfiguration Complete message. If this option is selected, the eNodeB raises the scheduling priority for UEs sending uplink access signaling. If this option is deselected, the eNodeB does not raise the scheduling priority for UEs sending uplink access signaling. In NB-IoT scenarios with air interface resource congestion, this option indicates whether to restrict the number of preambles to perform flow control on UEs accessing the cell.

UlLast2RetransSchOptSwitch: Indicates whether to optimize the scheduling policy for the last two retransmissions. If this option is selected, the scheduling policy is optimized for the last two retransmissions. If the UE transmit power is not limited, adaptive retransmission is used, and the number of RBs is increased in the last two retransmissions to increase the reception success rate of the last two retransmissions and decrease uplink RBLER. If this option is deselected, the scheduling policy is not optimized for the last two retransmissions. This option applies only to LTE FDD and LTE TDD.

UlInterfFssSwitch: Indicates whether to enable interference-based uplink frequency-selective scheduling. This option applies only to LTE FDD.

UlSmallRBSpectralEffOptSw: Indicates whether to optimize the spectral efficiency of small RBs in the uplink. For FDD and TDD cells: If this option is selected, the spectral efficiency of small RBs in the uplink is optimized, which ensures that the transport block size calculated based on the optimized spectral efficiency is not less than the traffic volume to be scheduled. If this option is deselected, the spectral efficiency of small RBs in the uplink is not optimized. For NB-IoT cells: If this option is selected, the number of PUSCH RUs for scheduling is determined based on available resources in case that continuous PUSCH resources are insufficient in the time domain. If this option is deselected, the number of PUSCH RUs for scheduling is determined based on the data volume.

PuschUsePucchRbSwitch: Indicates whether PUCCH RBs can be occupied by the PUSCH. In scenarios with a single user: If this option is selected, PUCCH RBs can be occupied by the PUSCH; if this option is deselected, PUCCH RBs cannot be occupied by the PUSCH. In scenarios with multiple users, PUCCH RBs cannot be occupied by the PUSCH regardless of the setting of this option. This option applies only to LTE FDD and LTE TDD.

PuschDtxSchOptSwitch: If this option is selected, the eNodeB determines whether to perform adaptive retransmission based on the PUSCH DTX detection result during uplink scheduling. This option takes effect only when uplink-downlink subframe configuration 2 or 5 is used. If an LTE TDD cell is established on an LBBPc, PUSCH DTX detection is not supported. This option applies only to LTE TDD.

PrachRbReuseSwitch: If this option is selected, the PUSCH and PRACH transmissions can use the same resource. If this option is deselected, the PUSCH and PRACH transmissions cannot use the same resource. This option applies only to LTE FDD and LTE TDD.

ULFSSAlgoswitch: If this option is deselected, uplink frequency-selective scheduling is disabled. If this option is selected, uplink frequency-selective scheduling is enabled. This option applies only to LTE TDD.

SrSchDataAdptSw: Indicates whether to enable data amount adaptation in SR-based scheduling. Data amount adaptation in SR-based scheduling is enabled only when this option is selected. This option applies only to LTE FDD.

UlFssUserThdStSwitch: If this option is selected, the UE number threshold is optimized for uplink frequency selective scheduling. If this option is deselected, the UE number threshold is not optimized for uplink frequency selective scheduling. This option applies only to LTE FDD and LTE TDD.

HighOrderVMIMOSwitch: Indicates whether to enable high order MU-MIMO. If this option is selected, high order MU-MIMO is enabled. If this option is deselected, high order MU-MIMO is disabled. This option applies only to LTE TDD.

VMIMOReduceMCSRiseRBSwitch: Indicates whether to reduce the MCS index and increase the number of RBs for UEs to enable them to participate in pairing for MU-MIMO in non-massive-MIMO scenarios, or whether the beam determination criteria are loosened up for uplink MU-MIMO pairing in massive MIMO scenarios. In non-massive MIMO scenarios: If this option is selected, uplink MU-MIMO can be performed for UEs for which the MCS index is reduced and the number of RBs is increased. If this option is deselected, uplink MU-MIMO cannot be performed for UEs for which the MCS index is reduced and the number of RBs is increased. In massive MIMO scenarios: (1) If the option is selected, the eNodeB loosens up the beam determination criteria for uplink MU-MIMO pairing. (2) If this option is deselected, the eNodeB does not loosen up the criteria. This option applies only to LTE TDD.

VoLTEUeVmimoSwitch: Indicates whether VoLTE UEs are allowed to participate in pairing for MU-MIMO. If this option is selected, VoLTE UEs are allowed to participate in pairing for MU-MIMO. If this option is deselected, VoLTE UEs are not allowed to participate in pairing for MU-MIMO. This option applies only to LTE TDD.

TtiBundlingForVideoSwitch: Indicates whether to enable TTI bundling for UEs running video services in weak coverage areas. If this option is selected, TTI bundling is enabled for UEs running video services in weak coverage areas, improving video service coverage at the cell edge. If this option is deselected, TTI bundling is disabled for UEs running video services in weak coverage areas. This option applies only to LTE FDD.

Impact

CellAlgoSwitch
Parameter Relationship

-Configuration constraints:

  • PsicSwitch in the CellAlgoSwitch MO can be set to On only if the UlVmimoSwitch option of UlSchSwitch in the CellAlgoSwitch MO is selected.
  • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, SpsSchSwitch of UlSchSwitch in the CellAlgoSwitch MO must be deselected.
  • Options UlPAMCSwitch of UlSchExtSwitch and UlIblerAdjustSwitch of UlSchSwitch in the CellAlgoSwitch cannot be selected simultaneously.
  • The OutOfBandRelaySwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO and the TtiBundlingSwitch option of the UlSchSwitch parameter in this MO cannot be both selected.
  • In the same CellAlgoSwitch MO, the InBandRelayDeNbSwitch option of the RelaySwitch parameter and the TtiBundlingSwitch option of the UlSchSwitch parameter cannot be both selected.
  • In the same CellAlgoSwitch MO, the InBandRelayReNbSwitch option of the RelaySwitch parameter and the TtiBundlingSwitch option of the UlSchSwitch parameter cannot be both selected.
  • If the NearBigPacketUeFastPcSwitch option of UlPcAlgoSwitch in a CellAlgoSwitch MO is selected, the SchedulerCtrlPowerSwitch option of UlSchSwitch in the CellAlgoSwitch MO must be selected.

Impact on Radio Network Performance

SmartPreAllocationSwitch: When DRX is disabled: (a) If this option is selected, the uplink delay increases, and the uplink interference is reduced, lowering UE power consumption. (b) If this option is deselected, the uplink delay decreases, and the uplink interference increases, raising UE power consumption. When DRX is enabled: (a) If this option is selected, the uplink delay decreases, and the downlink throughput increases. However, the uplink interference and UE power consumption increase. (b) If this option is deselected, the uplink delay increases, and the downlink throughput decreases. However, the uplink interference and UE power consumption decrease. The degree of impacts on network performance depends on the SmartPreAllocationDuration parameter value.

UlEnhancedFssSwitch: If this option is selected, the uplink MCS index and uplink throughput increase. If this option is deselected, the uplink MCS index and uplink throughput decrease.

UlEnhancedSrSchSwitch: For FDD and TDD cells, if uplink traffic is light in the cell and DRX is enabled, selecting this option decreases the BLERs of uplink initial transmission and retransmissions, reduces the waste of RBs and scheduling resources, mitigates interference to neighboring cells, and increases the cell throughput. However, uplink SR-based re-scheduling is performed only when the On Duration timer for the DRX long cycle starts. If normal SR-based scheduling fails, the ping delay increases. In scenarios where the uplink traffic volume is large or DRX is disabled, selecting this option has no impact on network performance. For NB-IoT cells, the attach success rate increases after this option is selected, and the attach success rate decreases after this option is deselected.

SchedulerCtrlPowerSwitch: If this option is selected in a network with a medium or light load, the uplink transmit power increases by 0.2 dBm to 0.5 dBm on average, the uplink MCS index increases, and uplink throughput increases for UEs not in the cell center. The uplink throughput of UEs in the cell center does not change. If this option is selected in a network with a heavy load (for example, when the RB usage is greater than 70%), uplink interference slightly increases and the throughput of UEs exposed to uplink interference slightly decreases.

UlMinGbrSwitch: If this option is deselected, the uplink data rate of non-GBR services cannot be ensured. There is a possibility that no resource can be allocated to non-GBR services and service drop occurs. If this option is selected, the uplink data rates of non-GBR services are ensured based on the QCI-specific Min_GBR of these services, reducing the service drop probability. However, the cell capacity may decrease, as the eNodeB attempts to ensure the Min_GBR of cell-edge UEs.

UlMbrCtrlSwitch: If this option is selected, the eNodeB allocates more uplink resources to UEs for which the MBR is greater than the GBR and GBR bearers are set up. This increases the uplink traffic volume when uplink resources are sufficient. If the MBR is equal to the GBR for UEs, selecting this option has no impacts on the network performance. If this option is deselected, the eNodeB performs scheduling based only on the GBR set for uplink GBR bearers and network performance is not affected.

MbrDlSchSwitch/UeAmbrDlSchSwitch: If this option is selected, throughput of UEs with higher MBR/UE-AMBR increases, and throughput of UEs with lower MBR/UE-AMBR decreases. In addition, the system throughput may also be affected. The impact on the system throughput depends on the difference in MBR/UE-AMBR between UEs and the distribution of UEs in the cell. If this option is deselected, the throughput differences between UEs with different MBRs/UE-AMBRs decrease. In addition, the system throughput is not affected by the difference in MBR/UE-AMBR between UEs or the distribution of UEs in the cell.

UlEnhancedDopplerSwitch: If this option is selected, the performance of low-speed UEs improves. The cell coverage and user-perceived rate of CEUs increase, and the PRB usage decreases.

UlRaUserSchOptSw: If this option is selected, the scheduling priority of access signaling is increased, improving the network access performance (denoted by KPIs such as the RRC connection setup success rate and average RRC connection setup delay). However, if a large number of UEs access the network at the same time and congestion occurs during signaling scheduling, uplink data transmission will be affected, causing uplink throughput to decrease. If this option is deselected, network performance is not affected.

UlLast2RetransSchOptSwitch: Indicates whether to optimize the scheduling policy for the last two retransmissions. If this option is selected, the scheduling policy is optimized for the last two retransmissions. If this option is deselected, the default scheduling policy is used.

Deselecting this option does not affect network performance.

Selecting this option decreases the RBLER in the uplink in most cases. However, the downlink cell throughput decreases when a large amount of PDCCH resources are consumed for retransmissions. In addition, the uplink cell throughput decreases and the scheduling delay for UEs not at the cell edge increases if excessive PDCCH resources or RBs are consumed because the last two retransmissions need to be performed for a large number of UEs.

UlInterfFssSwitch: Selecting this option decreases the uplink RBLER. Other network KPIs are not affected.

Deselecting this option has no impact on network performance.

UlSmallRBSpectralEffOptSw: For NB-IoT cells: (a) If this option is selected, the PUSCH scheduling success rate increases and the number of resource fragments decreases. (b) If this option is deselected, the PUSCH scheduling success rate decreases and the number of resource fragments increases.

PuschUsePucchRbSwitch: The number of activated L2 UEs in each TTI is used to determine whether the cell is serving a single UE. If the number of activated L2 UEs is 1, the cell is serving a single UE. In this case, if this option is selected, PUCCH RBs can be occupied by the PUSCH, the peak rate of UEs in the cell center increases, but interference to the PUCCH may increase. If the number of activated L2 UEs is greater than 1, this option does not take effect, and the network performance is not affected.

UlIblerAdjustSwitch: If this option is selected, the uplink throughput in benchmark drive tests increases. In live networks, if there are large-packet services in the uplink, selecting this option increases uplink throughput (especially at the cell edge) and slightly increases the RBLER. If there are no large-packet services in the uplink in live networks, selecting this option has no impact on network KPIs.

PuschDtxSchOptSwitch: If this option is selected, uplink scheduling resources can be saved and the cell throughput increases. If this option is deselected, the network performance is not affected.

PrachRbReuseSwitch: If this option is selected, the uplink data rate increases but the RRC connection setup success rate may decrease. If this option is deselected, the RRC connection setup success rate is not affected but the uplink data rate decreases.

ULFSSAlgoswitch: If this option is selected, uplink frequency-selective scheduling takes effect when the network load is light, which improves the uplink MCS index and increases throughput, and uplink frequency-selective scheduling does not take effect when the network load is heavy, which reduces the number of resource fragments and increases throughput. If this option is deselected, uplink frequency-selective scheduling is disabled. The uplink MCS index and throughput decrease when the network load is light.

SrSchDataAdptSw: If this option is deselected, data amount adaptation in SR-based scheduling is disabled, and ping delay may increase.

If this option is selected (the default setting), data amount adaption in SR-based scheduling is enabled, and the network performance is not affected.

UlFssUserThdStSwitch: If this option is selected, the proportion of UEs that are selected for uplink frequency selective scheduling increases, uplink user data rate increases, and uplink RBLER decreases.

If this option is deselected, network performance is not affected.

HighOrderVMIMOSwitch: If this option is selected, a maximum of four UEs can use the same time-frequency resource to transmit data, which increases the overall uplink throughput of the cell.

If this option is deselected, four UEs cannot use the same time-frequency resource to transmit data, which does not increase the overall uplink throughput of the cell.

VMIMOReduceMCSRiseRBSwitch: If this option is selected for a non-massive-MIMO cell, the MCS index can be reduced to increase the number of RBs for UEs to be paired for MU-MIMO, which increases the uplink cell throughput. If this option is selected for a massive MIMO cell, uplink beam evaluation for MU-MIMO pairing is less strict, further increasing the average number of layers paired in the uplink and improving the uplink cell throughput. However, the uplink BLER in the cell also increases.

If this option is deselected for a non-massive-MIMO cell, the MCS index cannot be reduced to increase the number of RBs for UEs to be paired for MU-MIMO, which decreases the uplink cell throughput. If this option is deselected for a massive MIMO cell, uplink beam evaluation for MU-MIMO pairing is remain unchanged. As a result, the average number of layers paired in the uplink, uplink cell throughput, and the uplink BLER in the cell remain unchanged.

VoLTEUeVmimoSwitch: If this option is selected, VoLTE UEs can be paired for MU-MIMO, which increases the number of VoLTE UEs supported in the cell.

If this option is deselected, VoLTE UEs cannot be paired for MU-MIMO, which decreases the number of VoLTE UEs supported in the cell.

TtiBundlingForVideoSwitch: Indicates whether to enable TTI bundling for UEs running video services in weak coverage areas. If this option is selected, TTI bundling is enabled for UEs running video services in weak coverage areas, improving video service coverage at the cell edge. If this option is deselected, TTI bundling is disabled for UEs running video services in weak coverage areas.
