Meaning

Indicates the preamble format used in the cell. For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the values of the CellActiveState, FddTddInd, and DlBandWidth parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, and CELL_BW_N6, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 4.
  • If the values of the CellActiveState, FddTddInd, TxRxMode, and SubframeAssignment parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, 64T64R, and SA1, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 1, 2, or 3.
  • In a Cell MO, if NbCellFlag is set to FALSE, FddTddInd is set to CELL_TDD and PreambleFmt is set to 4, RootSequenceIdx must be set to a value smaller than or equal to 137.
  • In a Cell MO, if NbCellFlag is set to FALSE, FddTddInd is set to CELL_TDD and PreambleFmt is set to 4, SpecialSubframePatterns must be set to a value greater than SSP4.
  • In a Cell MO, if NbCellFlag is set to FALSE and FddTddInd is set to CELL_TDD, PreambleFmt and SubframeAssignment must adhere to the following constraint:
  • (1) If PreambleFmt is set to 0, SubframeAssignment can be set to SA0, SA1, SA2, SA3, SA5, or NULL;
  • (2) If PreambleFmt is set to 1, SubframeAssignment can be set to SA0, SA1, or SA3;
  • (3) If PreambleFmt is set to 2, SubframeAssignment can be set to SA0, SA1, or SA3;
  • (4) If PreambleFmt is set to 3, SubframeAssignment can be set to SA0 or SA3;
  • (5) If PreambleFmt is set to 4, SubframeAssignment can be set to SA0, SA1, SA2, SA3, or SA5.
  • In a Cell MO, CellRadius cannot be set to a value greater than 32800 m when NbCellFlag is set to FALSE, PreambleFmt is set to a value less than 4, and HighSpeedFlag is set to HIGH_SPEED.

Caution

In a CELL MO, if the PreambleFmt parameter value is less than 4 and the HighSpeedFlag value is set to ULTRA_HIGH_SPEED:

(1) If the CellRadius parameter value ranges from 1 to 1000 and the RootSequenceIdx parameter value ranges from 333 to 547 or from 801 to 815, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 333 to 547 or 801 to 815.

(2) If the CellRadius parameter value ranges from 1000 to 1500 (1000 is excluded) and the RootSequenceIdx parameter value ranges from 311 to 551 or from 797 to 811, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 311 to 551 or 797 to 811.

(3) If the CellRadius parameter value ranges from 1500 to 2000 (1500 is excluded) and the RootSequenceIdx parameter value ranges from 311 to 551 or from 791 to 804, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 311 to 551 or 791 to 804.

(4) If the CellRadius parameter value ranges from 2000 to 2600 (2000 is excluded) and the RootSequenceIdx parameter value ranges from 311 to 551 or from 785 to 797, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 311 to 551 or 785 to 797.

(5) If the CellRadius parameter value ranges from 2600 to 3500 (2600 is excluded) and the RootSequenceIdx parameter value ranges from 311 to 551 or from 777 to 786, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 311 to 551 or 777 to 786.

(6) If the CellRadius parameter value ranges from 3500 to 4300 (3500 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 557 or from 771 to 779, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 255 to 557 or 771 to 779.

(7) If the CellRadius parameter value ranges from 4300 to 5500 (4300 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 557 or from 759 to 765, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 255 to 557 or 759 to 765.

(8) If the CellRadius parameter value ranges from 5500 to 6800 (5500 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 597 or is 747, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to 747 or a value in the range of 255 to 597.

(9) If the CellRadius parameter value ranges from 6800 to 8600 (6800 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 623, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 255 to 623.

(10) If the CellRadius parameter value ranges from 8600 to 10600 (8600 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 623, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 255 to 623.

(11) If the CellRadius parameter value ranges from 10600 to 13200 (10600 is excluded) and the RootSequenceIdx parameter value ranges from 255 to 629, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 255 to 629.

(12) If the CellRadius parameter value ranges from 13200 to 17200 (13200 is excluded) and the RootSequenceIdx parameter value ranges from 247 to 602, the UE access performance may deteriorate, and therefore it is not recommended that the RootSequenceIdx parameter be set to a value in the range of 247 to 602.

(13) If the CellRadius parameter value ranges from 17200 to 32800 (17200 is excluded), the valid value range for the RootSequenceIdx parameter is relatively small, and only a few UEs can access the cell. Therefore, it is not recommended that the CellRadius parameter be set to a value in the range of 17200 to 32800 (17200 is excluded).
