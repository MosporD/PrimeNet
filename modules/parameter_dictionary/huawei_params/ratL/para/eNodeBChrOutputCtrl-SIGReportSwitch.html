MML Command

SET ENODEBCHROUTPUTCTRL

DSP ENODEBCHROUTPUTCTRL
Meaning

Indicates whether to report SIG logs and signaling soft collection results. If this parameter is set to ON, SIG logs and signaling soft collection results that have been subscribed to are normally reported. If this parameter is set to OFF, reporting of these SIG logs and signaling soft collection results is forcibly terminated and new subscriptions no longer take effect.

Caution

The eNodeB cannot automatically restore the deleted external CHR subscription. When this parameter value is changed from OFF to ON, operators need to subscribe to external CHRs again. After the eNodeB is reset, the eNodeB automatically restores to the status that the subscription function is available, and the function of forcibly terminating the subscription does not take effect.
