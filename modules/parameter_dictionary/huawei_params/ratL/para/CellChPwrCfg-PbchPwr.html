Meaning

Indicates the offset of the PBCH transmit power relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

The setting of this parameter is recommended to be the same as the setting of PaPcOff. PbchPwr can be set as follows:

When PaPcOff is set to -6, you are advised to set PbchPwr to -1200.

When PaPcOff is set to -4.77, you are advised to set PbchPwr to -954.

When PaPcOff is set to -3, you are advised to set PbchPwr to -600.

When PaPcOff is set to -1.77, you are advised to set PbchPwr to -354.

When PaPcOff is set to 0, you are advised to set PbchPwr to 0.

When PaPcOff is set to 1, you are advised to set PbchPwr to 200.

When PaPcOff is set to 2, you are advised to set PbchPwr to 400.

When PaPcOff is set to 3, you are advised to set PbchPwr to 600.

Impact on Radio Network Performance

You are advised to set the parameter to a value that does not deviate from the value of the PA for even power distribution parameter by more than 3 dB. A larger value leads to a larger coverage of the PBCH but less available power for the PDSCH. A smaller value leads to opposite effects.
