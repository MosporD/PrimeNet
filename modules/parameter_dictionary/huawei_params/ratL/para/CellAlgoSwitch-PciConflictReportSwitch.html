Meaning

Indicates whether the eNodeB reports physical cell identifier (PCI) conflicts to the MAE.

COLLISION_REPORT_SWITCH: If this option is selected, check results about whether PCI collisions occur between the local cell and other cells served by the same base station as the local cell or between the local cell and external cells are reported to the MAE. If this option is deselected, these check results are not reported to the MAE. For details about PCI collisions, see 3GPP TS 36.902. This option applies only to LTE FDD and LTE TDD.

CONFUSION_REPORT_SWITCH: If this option is selected, check results about whether PCI confusions occur between candidate target neighboring cells whose neighbor relationships with the local cell are recorded in the NRTs are reported to the MAE. If this option is deselected, these check results are not reported to the MAE. For details about PCI confusion, see 3GPP TS 36.902. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

COLLISION_REPORT_SWITCH: If this option is selected and PCI collisions occur, information about PCI collisions is displayed on the PCI Self-Optimization page on the MAE. If the RRUs are installed remotely, PCI collisions may be falsely detected. If this option is deselected, information about PCI collisions is not displayed on the PCI Self-Optimization page on the MAE.

CONFUSION_REPORT_SWITCH: If this option is selected and PCI confusions occur, information about PCI confusions is displayed on the PCI Self-Optimization page on the MAE. If this option is deselected, information about PCI confusions is not displayed on the PCI Self-Optimization page on the MAE.
