Meaning

Indicates whether to enable eNodeB-level handovers to be activated in the cell when related eNodeB-level handover switches are on.

SrvBasedInterFreqHoSw: Indicates whether to enable service-based inter-frequency handover to be activated in the cell. Service-based inter-frequency handover is allowed to be activated in the cell only when this option is selected. This option applies only to LTE FDD and LTE TDD.

GeranSepOpMobilitySwitch: Indicates whether to differentiate mobility policies for GERAN operators. When this option is selected, different network policies can be applied to different GERAN operators. Such policies include SRVCC and SI obtaining through RIM procedures. When this option is deselected, different network policies cannot be applied to different GERAN operators. This option applies only to LTE FDD and LTE TDD.

UtranCsfbSwitch: Indicates whether to enable CSFB to UTRAN. When this option is selected, CSFB to UTRAN is allowed. When this option is deselected, the UTRAN CSFB algorithm is disabled. This option applies only to LTE FDD and LTE TDD.

GeranCsfbSwitch: Indicates whether to enable CSFB to GERAN. When this option is selected, CSFB to GERAN is allowed. When this option is deselected, the GERAN CSFB algorithm is disabled. This option applies only to LTE FDD and LTE TDD.

UtranFlashCsfbSwitch: This option does not take effect if UtranCsfbSwitch is off. When UtranFlashCsfbSwitch is on, flash CSFB to UTRAN is enabled, and UTRAN system information is carried during redirection. When UtranFlashCsfbSwitch is off, flash CSFB to UTRAN is disabled. This option applies only to LTE FDD and LTE TDD.

GeranFlashCsfbSwitch: This option does not take effect if GeranCsfbSwitch is off. When GeranFlashCsfbSwitch is on, flash CSFB to GERAN is enabled, and GERAN system information is carried during redirection. When GeranFlashCsfbSwitch is off, flash CSFB to GERAN is disabled. This option applies only to LTE FDD and LTE TDD.

CsfbAdaptiveBlindHoSwitch: This option does not take effect if BlindHoSwitch is off. If BlindHoSwitch is on and UFCsfbBlindHoDisSwitch is also on, CsfbAdaptiveBlindHoSwitch does not take effect and UEs fall back to UTRAN or GERAN through ultra-flash CSFB. When this option is selected, CSFB adaptive blind handover is enabled. In this situation, an optimal handover mode is used depending on UE position in the CSFB scenario. When this option is deselected, CSFB adaptive blind handover is disabled. This option applies only to LTE FDD and LTE TDD.

UtranCsfbSteeringSwitch: UTRAN CSFB steering is enabled when this option is selected. In this case, RRC_IDLE UEs can use separate configuration policies when triggering CSFB. UTRAN CSFB steering is disabled when this option is deselected. This option applies only to LTE FDD and LTE TDD.

GeranCsfbSteeringSwitch: GERAN CSFB steering is enabled when this option is selected. In this case, RRC_IDLE UEs can use separate configuration policies when triggering CSFB. GERAN CSFB steering is disabled when this option is deselected. This option applies only to LTE FDD and LTE TDD.

ServBasedHoBackSwitch: Indicates whether to allow service- or service-request-based inter-frequency handovers to source frequencies for UEs that have been handed over from the source frequencies to target frequencies. Such handovers to the source frequencies are allowed only if this option is selected. This switch takes effect for TDD cells with ServiceHoBearerPolicy set to SERVICE_HO_QCI_ALLOWED and does not take effect for TDD cells with ServiceHoBearerPolicy set to SERVICE_HO_QCI_NOT_ALLOWED. This option applies only to LTE FDD and LTE TDD.

ServiceReqInterFreqHoSwitch: If this option is selected, service-request-based inter-frequency handovers are enabled and UEs using a specific type of service can be handed over to inter-frequency cells. If this option is deselected, service-request-based inter-frequency handovers are disabled. This option applies only to LTE FDD and LTE TDD.

IdleCsfbRedirectOptSwitch: If this option is selected and the preferred CSFB policy is redirection, during CSFB of RRC_IDLE UEs, the eNodeB sends redirection messages without activating the security mode and performing RRC connection reconfiguration. However, if the eNodeB needs to query the UE capability information during redirection-based CSFB for RRC_IDLE UEs and the UeCapbEnquirySecurityEnhSwitch option of the ProtocolMsgOptSwitch parameter in the GlobalProcSwitch MO is selected, then the security mode activation, UE capability transfer, and RRC connection release procedures are processed in serial mode. In accordance with the security requirements of 3GPP CR (R2-1714284), this option takes effect only for redirections to UTRAN cells. This option applies only to LTE FDD and LTE TDD.

ServBasedNrHoSwitch: Indicates whether to enable service-based handover from E-UTRAN to NR. Service-based handover from E-UTRAN to NR is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

Caution

If the UtranCsfbSwitch and GeranCsfbSwitch options are deselected, UEs may fail to fall back to UTRAN or GERAN for voice services.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

SrvBasedInterFreqHoSw: If ServiceBasedInterFreqHoSwitch of the HoAlgoSwitch parameter in the ENodeBAlgoSwitch MO is off, the setting of SrvBasedInterFreqHoSw has no impact on network performance. If ServiceBasedInterFreqHoSwitch of the HoAlgoSwitch parameter in the ENodeBAlgoSwitch MO is on, turning on SrvBasedInterFreqHoSw enables the cell to use the same service steering policies as other cells and improves the network performance based on service steering; turning off SrvBasedInterFreqHoSw disables the cell to use service steering.

GeranSepOpMobilitySwitch: When this option is selected, different network policies can be applied to different GERAN operators. Such policies include SRVCC and SI obtaining through RIM procedures. In this way, operators supporting SRVCC or RIM procedures can select an optimal network policy to achieve the best performance. When this option is deselected, a uniform network policy is applied to different GERAN operators. That is, operators cannot utilize the best network performance according to their network characteristics.

ServBasedHoBackSwitch: When this option is deselected, service steering cannot be implemented. When this option is selected, service steering can be implemented, improving network performance.

ServiceReqInterFreqHoSwitch: If this option is selected, the E-RAB setup success rate of voice-related QCIs decreases and the number of voice service handovers increases.

IdleCsfbRedirectOptSwitch: If this option is selected, the number of signaling exchanges for CSFB decreases, shortening the CSFB delay.
