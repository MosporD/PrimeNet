Meaning

Indicates the access probability factor for signaling. Signaling from a UE is granted access if the random number generated by the UE is less than this access probability factor; otherwise, the access request is rejected. According to 3GPP TS 36.331, if any of the parameters AC11BarForSig, AC12BarForSig, AC13BarForSig, AC14BarForSig, and AC15BarForSig is set to BOOLEAN_TRUE, the eNodeB sends UEs P00 as the access probability factor for signaling in the system information block type 2 (SIB2), regardless of the actual setting of the AcBarringFactorForSig parameter. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If AcBarringForMoDataCfgInd or AcBarringForMoSigCfgInd in SIB2 is set to CFG, the UE generates a random number in the range [0,1). If the random number is smaller than the value of this parameter, the UE considers access to the cell as allowed. That is, an RRC connection can be set up for the signaling. A larger value of this parameter leads to a higher probability of granting access to a UE, which may increase cell load. A smaller value of this parameter leads to a lower probability of granting access to a UE. As a result, a UE may fail to access the cell even when the cell load is relatively light. If this parameter is set to P00, the RRC connection for signaling cannot be set up.
