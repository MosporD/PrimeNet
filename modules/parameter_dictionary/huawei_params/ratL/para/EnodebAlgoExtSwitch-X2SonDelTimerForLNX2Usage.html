MOD ENODEBALGOEXTSWITCH

LST ENODEBALGOEXTSWITCH
Meaning

Indicates the length of the timer for automatically removing LTE-NR X2 interfaces based on X2 usage.

When this timer is set to 0, the function of automatically removing of LTE-NR X2 interfaces based on X2 usage does not take effect.

When this timer is set to another value, this function takes effect. If the measured number of successful SgNB additions corresponding to an LTE-NR X2 interface within the timer length is less than or equal to a specified threshold and no NSA UEs perform services over the X2 interface, automatic removal of this LTE-NR X2 interface is triggered.

This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

The prerequisite of the impacts is that no NSA UEs perform services over the X2 interface when the removal is triggered.

A smaller value of this parameter results in a higher probability of meeting the conditions for automatically removing LTE-NR X2 interfaces. This may cause LTE-NR X2 interfaces to be mistakenly removed and then automatically set up, repeatedly.

A larger value of this parameter results in a lower probability of meeting the conditions for removing LTE-NR X2 interfaces. LTE-NR X2 interfaces with low usage cannot be removed in time, occupying the specification of LTE-NR X2 interfaces, and the addition of new LTE-NR X2 interfaces is affected.

If this parameter is set to 0, LTE-NR X2 interfaces that are rarely used will not be removed, wasting X2 resources.
