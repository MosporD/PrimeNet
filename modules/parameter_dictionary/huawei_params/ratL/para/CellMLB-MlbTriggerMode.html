Meaning

Indicates the trigger of the MLB algorithm. In MLB with load information exchange, if this parameter is set to PRB_ONLY, PRB usage is used as a trigger and the number of UEs is used as a supplementary trigger; PRB usage difference between cells is used as a UE transfer condition; the aim of MLB is to achieve the same number of remaining PRBs between cells. If this parameter is set to UE_NUMBER_ONLY, the number of UEs is used as a trigger; the difference of the number of UEs per unit of bandwidth between cells is used as a UE transfer condition; the aim of MLB is to achieve the same number of UEs per unit of bandwidth between cells. If this parameter is set to PRB_OR_UE_NUMBER, the combination of the triggers, UE transfer conditions, and MLB aims for the values UE_NUMBER_ONLY and PRB_ONLY are used.

In MLB without load information exchange, if this parameter is set to PRB_ONLY, PRB usage is used as a trigger and a UE transfer condition and the number of UEs is used as a supplementary trigger and a supplementary UE transfer condition; the aim of MLB is that the PRB usage is less than the InterFreqMlbThd or InterFreqIdleMlbUeNumThd parameter value. If this parameter is set to UE_NUMBER_ONLY, the number of UEs is used as a trigger and a UE transfer condition; the aim of MLB is that the number of UEs is less than the InterFreqMlbUeNumThd or InterFreqIdleMlbUeNumThd parameter value. If this parameter is set to PRB_OR_UE_NUMBER, the combination of the triggers, UE transfer conditions, and MLB aims for the values UE_NUMBER_ONLY and PRB_ONLY are used. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to PRB_ONLY, channel resource allocation among frequencies for transmitting user data is balanced, and the system throughput increases.

If this parameter is set to UE_NUMBER_ONLY, the packet transmission delay reduces, and user experience improves.
