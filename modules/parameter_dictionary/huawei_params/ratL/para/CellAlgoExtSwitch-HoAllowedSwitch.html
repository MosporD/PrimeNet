Meaning

Indicates whether to enable cell-level handover functions in the cell.

INTER_RAT_MOBILITY_TO_NR_SW: If this option is selected, cell reselection from E-UTRAN to NG-RAN is enabled and UEs can reselect to NG-RAN cells. In addition, the inter-RAT mobility from E-UTRAN to NG-RAN algorithm is enabled. With this algorithm enabled, handovers or redirections from the E-UTRAN cell back to NG-RAN cells are allowed for UEs in the E-UTRAN cell. If this option is deselected, both cell reselection from E-UTRAN to NG-RAN and the inter-RAT mobility from E-UTRAN to NG-RAN algorithm are disabled. This option applies only to LTE FDD and LTE TDD.

FAST_RETURN_TO_NR_SW: If this option is selected, the fast return from E-UTRAN to NG-RAN algorithm is enabled. With this algorithm enabled, handovers or redirections from the E-UTRAN cell back to NG-RAN cells are allowed for UEs that finish voice services in the E-UTRAN cell. If this option is deselected, this algorithm is disabled. This option applies only to LTE FDD and LTE TDD.

LAI_BASED_CSFB_TO_UTRAN_SW: Indicates whether to enable LAI-based CSFB to UTRAN. LAI-based CSFB to UTRAN is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LAI_BASED_CSFB_TO_GERAN_SW: Indicates whether to enable LAI-based CSFB to GERAN. LAI-based CSFB to GERAN is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SPID_L2N_TARGET_FREQ_CTRL_SW: Indicates whether to restrict the scope of target frequencies of handovers or redirections from LTE to NR for UEs with a specific SPID. If this option is selected and a RatFreqPriorityGroup MO is configured for an SPID, UEs with this SPID can be handed over or redirected only to the NR frequency specified in this RatFreqPriorityGroup MO. If this option is deselected, the scope of target NR frequencies of handovers or redirections from LTE to NR for UEs with this SPID is not restricted. This option applies only to LTE FDD and LTE TDD.

PS_RAT_STEERING_SW: If this option is selected, only the RAT with the highest data service priority for measurements is selected during coverage-based inter-RAT handovers for data services. If this option is deselected, multiple target RATs can be selected for measurements. This option takes effect only if the eNodeB-level option is deselected. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

INTER_RAT_MOBILITY_TO_NR_SW: If this option is selected, redirections to NG-RAN cells can be triggered for UEs that move to the coverage edge in the E-UTRAN cell. If this option is deselected, redirections cannot be triggered for UEs that move to the coverage edge in the E-UTRAN cell.

FAST_RETURN_TO_NR_SW: If this option is selected, redirections back to NG-RAN cells can be triggered for UEs that finish voice services in the E-UTRAN cell. If this option is deselected, redirections cannot be triggered for UEs that finish voice services in the E-UTRAN cell.

PS_RAT_STEERING_SW: If this option is selected and no target cells with the required signal quality are available in the highest-priority RAT during coverage-based inter-RAT handovers for data services, the data service drop rate increases. If this option is deselected, the data service drop rate is not affected.
