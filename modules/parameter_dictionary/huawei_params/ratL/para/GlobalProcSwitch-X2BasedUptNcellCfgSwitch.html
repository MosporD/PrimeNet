Meaning

Indicates whether the base station automatically updates neighboring cell configurations based on messages received over the X2 interface. The messages include X2 SETUP REQUEST, X2 SETUP RESPONSE, ENB CONFIGURATION UPDATE, EN-DC X2 SETUP REQUEST, EN-DC X2 SETUP RESPONSE, and EN-DC CONFIGURATION UPDATE. This parameter provides the following options:

ADD_NCELL_CFG_SW: The base station automatically adds external cells and related configurations based on received X2 messages only if this option is selected.

MOD_NCELL_CFG_SW: The base station automatically modifies neighboring cell and external cell configurations based on received X2 messages only if this option is selected. This option applies only to LTE FDD and LTE TDD.

DEL_NCELL_CFG_SW: The base station automatically deletes neighboring cell, blacklisted neighboring E-UTRAN cell, and external cell configurations based on received X2 messages only if this option is selected. This option applies only to LTE FDD and LTE TDD.

ADD_FREQ_CFG_SW: If this option is selected, based on the X2 messages received by a base station, the base station automatically adds new frequencies brought by new or updated neighboring cell information to the neighboring E-UTRA frequency list of the local cell. If this option is deselected, the base station does not add new frequencies based on received X2 messages to the neighboring E-UTRA frequency list of the local cell, does not add cells on the new frequencies to the NCL of the base station, and removes neighbor relationships with cells on the new frequencies from the NRTs of the local cell.

UPT_EXTERNALCELLBAND_CFG_SW: If this option is selected, the secondary frequency band configurations of cells served by the local base station can be delivered over the X2 interface and the secondary frequency band configurations of external cells can be updated for the local base station based on the configurations delivered over the X2 interfaces from other base stations. If this option is deselected, the local base station neither includes the secondary frequency band configurations in the X2 messages nor updates the secondary frequency band configurations of external cells based on received X2 messages.

MOD_NR_NCELL_CFG_SW: The base station automatically modifies neighboring NR cell and external NR cell configurations based on received X2 messages only if this option is selected.

DEL_NR_NCELL_CFG_SW: The base station automatically deletes neighboring NR cell and external NR cell configurations based on received X2 messages only if this option is selected.

UPT_NR_EXT_CELL_NW_OPT_CFG_SW: If this option is selected, the base station automatically updates NR architecture options for external NG-RAN cells based on received X2 messages. If this option is deselected, the base station does not automatically update NR architecture options for external NG-RAN cells based on received X2 messages.

UPT_NR_EXT_CELL_BAND_CFG_SW: If this option is selected in NSA scenarios, the base station updates local multi-band configuration of external NG-RAN cells based on the band list configuration delivered from the gNodeB over the X2 interface. If this option is deselected in NSA scenarios, the base station does not update the local multi-band configuration of external NG-RAN cells based on the band list configuration delivered from the gNodeB.

UPT_NR_EXT_CELL_PLMN_CFG_SW: If this option is selected, the local base station can update the PLMN-specific gNodeB IDs and PLMN-specific cell identities in an NR-external-cell PLMN list of the local base station based on the information about the PLMNs and cell identities of a cell delivered from the gNodeB over the X2 interface.

Recommended Value

When the MAE-Deployment is used for linked updates of base station configurations throughout the entire network and the peer base stations may be informed of modifications of certain parameters or MOs (such as eNodeBId, CellId, LocalCellId, CnOperator, CnOperatorTa, CellOp, PhyCellId, and DlEarfcn) through X2 messages, deselect the preceding options to disable automatic updates. If the options are selected, configuration loss or exceptions may occur because of conflicts between MAE-Deployment-based linked updates and X2-based automatic updates.

When MAE-Deployment-based linked updates are disabled and X2-based automatic updates are required, the preceding options must be selected so that the base station automatically updates neighboring cell configurations based on messages received over the X2 interface.

Impact on Radio Network Performance

If the ADD_NCELL_CFG_SW, MOD_NCELL_CFG_SW, MOD_NR_NCELL_CFG_SW, UPT_NR_EXT_CELL_NW_OPT_CFG_SW, or UPT_NR_EXT_CELL_PLMN_CFG_SW option is deselected and updates of neighboring cell configurations using the Cell Parameter Auto-Synchronization Policy on the MAE are not used, inter-base-station neighboring cell configurations will not be automatically updated. As a result, the handover success rate or DC SCC configuration success rate decreases. If the ADD_NCELL_CFG_SW, MOD_NCELL_CFG_SW, MOD_NR_NCELL_CFG_SW, UPT_NR_EXT_CELL_NW_OPT_CFG_SW, or UPT_NR_EXT_CELL_PLMN_CFG_SW option is selected and updates of neighboring cell configurations using the Cell Parameter Auto-Synchronization Policy on the MAE are used, configuration loss or exceptions may occur because of conflicts between automatic updates and MAE-based linked updates.

If the DEL_NCELL_CFG_SW or DEL_NR_NCELL_CFG_SW option is deselected, neighboring cell configurations are not modified using the MAE, neighbor relationship removal is not performed based on X2 update messages, duplicate PCIs are represented, then handover failures occur. If the DEL_NCELL_CFG_SW or DEL_NR_NCELL_CFG_SW option is selected, then neighbor relationships may be mistakenly removed and the handover success rate may decrease when cells are manually deactivated or S1 interfaces recover from short-term exceptions.
