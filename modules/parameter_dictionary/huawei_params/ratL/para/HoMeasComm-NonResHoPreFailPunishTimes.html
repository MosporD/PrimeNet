Non Resource Handover Prepare Fail Punish Times

MO HoMeasComm
Parameter ID NonResHoPreFailPunishTimes
Parameter Name

Non Resource Handover Prepare Fail Punish Times
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD HOMEASCOMM

LST HOMEASCOMM
Meaning

Indicates the number of penalty times none of the handovers is allowed to the target cell when a handover preparation fails due to non-resource-related causes on the target cell. If this parameter is set to 0, the target cell is not penalized or is penalized permanently if a handover fails due to non-resource-related causes. That is, the number of handover attempts to the target cell is unlimited. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller parameter value results in a larger number of invalid handover requests if a handover fails due to non-resource-related causes. A larger parameter value results in a smaller number of invalid handover requests, but UEs may experience service drops caused by untimely handovers due to a large number of penalty times.
