Meaning

Indicates whether to enable dynamic HARQ-ACK delay for eMTC UEs.

If this parameter is set to RANGE1 or RANGE2, dynamic HARQ-ACK delay is enabled for eMTC UEs. For eMTC UEs in CE mode A, the value of HARQ-ACK delay for the PDSCH is one of the values corresponding to RANGE1 or RANGE2, and the DCI is used to inform the eMTC UEs of the delay value. The values corresponding to RANGE1 are 4, 5, 7, 9, 11, 13, 15, and 17, and the values corresponding to RANGE2 are 4, 5, 6, 7, 8, 9, 10, and 11. For details, see 3GPP TS 36.213 R14.

If this parameter is set to OFF, dynamic HARQ-ACK delay is disabled for eMTC UEs. This parameter applies only to LTE FDD.
