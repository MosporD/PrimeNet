Meaning

Indicates whether to enable functions related to uplink resource optimization. UL_RBCALC_OPT_SWITCH: Indicates whether to enable the optimization of uplink RB quantity calculation for cell-edge UEs and optimization of UL CoMP resource pools. If this option is selected, the eNodeB optimizes uplink RB quantity calculation for cell-edge UEs and the use of UL CoMP resources when the scheduler-controlled power function is used. If this option is deselected, the eNodeB does not optimize uplink RB quantity calculation for cell-edge UEs and the use of UL CoMP resources when the scheduler-controlled power function is used. This option applies only to LTE FDD and LTE TDD.

MM_SRS_ALLOC_OPT_SWITCH: Indicates whether to enable SRS period adaptation in FDD massive MIMO cells. If this option is selected, the eNodeB adaptively adjusts the SRS period using the massive-MIMO-specific SRS algorithm to increase user-perceived uplink throughput of high-mobility UEs. If this option is deselected, the eNodeB does not adaptively adjust the SRS period for UEs. This option applies only to LTE FDD.

Impact on Radio Network Performance

UL_RBCALC_OPT_SWITCH: If this option is selected, the uplink throughput of cell-edge UEs running full buffer services increases, and the number of RBs for UL CoMP also increases as a result of UL CoMP resource pool sharing; therefore, the average uplink cell throughput and the uplink throughput of cell-edge UEs increase. If this option is selected for eNodeBs equipped with LBBPc, voice quality may deteriorate. Therefore, it is not recommended that this option be selected for these eNodeBs. If this option is deselected, network performance is not affected.

MM_SRS_ALLOC_OPT_SWITCH: If this option is selected, the user-perceived uplink throughput of high-speed moving UEs increases, which has no negative impact on other UEs. If this option is deselected, network performance is not affected.
