Meaning

Indicates whether to enable load balancing between baseband processing units (BBPs) in a baseband collaboration group. L2LoadBalanceSwitch: If this option is selected, lightly-loaded BBPs can share loads on heavily-loaded BBPs to decrease the CPU usage in the heavily-loaded BBPs, thereby avoiding BBP overload. If this option is deselected, load balancing between BBPs is disabled. At present, only the UBBPd and UBBPe can share loads on the LBBPc. This option applies only to LTE FDD and LTE TDD.

Disuse statement: BbpCollaborateSwitch: This option will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

Impact on Radio Network Performance

L2LoadBalanceSwitch: If this option is selected, load sharing from an LBBPc to an UBBPd or UBBPe has the following impact:

(1) The total number of UEs originally served by the UBBPd or UBBPe and UEs transferred from the LBBPc to the UBBPd or UBBPe cannot exceed the maximum number of UEs supported by the UBBPd or UBBPe.

(2) The UEs originally served by the UBBPd or UBBPe and the UEs transferred from the LBBPc to the UBBPd or UBBPe share the UBBPd or UBBPe capacity in terms of uplink throughput and downlink throughput.

(3) The CPU usage on the UBBPd or UBBPe increases.

(4) The maximum number of RRC_CONNECTED UEs supported by the LBBPc remains unchanged.

(5) The LBBPc throughput remains unchanged.

(6) The CPU usage on the LBBPc decreases.

Deselecting this option has no impact on the UBBPd, UBBPe, or LBBPc.
