Parameter Relationship

-Configuration constraints:

  • The FreqBand parameter in a Prb MO must be set to 1, 2, 3, 4, 5, 8, 11, 12, 13, 17, 18, 19, 20, 21, 25, 26, 28, 31, 66, 70, 71, 72, 73, 74, 85, 111, or 222. If the LteDlRbIndex parameter in a Prb MO is set to an invalid value and the WorkMode parameter in this Prb MO is set to UL_DL or DL_ONLY, the FreqBand and DlEarfcn parameters in this Prb MO must be configured in accordance with certain rules. For details about these parameters, see 3GPP TS 36.101. Band 111 and Band 222 are customized for operators. The downlink EARFCN range of Band 111 is 11131 to 11190 and that of Band 222 is 13111 to 13360. If the LteUlRbIndex parameter in a Prb MO is set to an invalid value and the WorkMode parameter in this Prb MO is set to UL_DL or UL_ONLY, the FreqBand and UlEarfcn parameters in this Prb MO must be configured in accordance with certain rules. For details about these parameters, see 3GPP TS 36.101. Band 111 and Band 222 are customized for operators. The uplink EARFCN range of Band 111 is 32111 to 32160 and that of Band 222 is 31111 to 31160.
