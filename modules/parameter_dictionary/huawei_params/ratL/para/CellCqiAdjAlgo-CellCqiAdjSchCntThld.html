Meaning

Indicates the threshold of the number of scheduling times for determining samples used to adaptively set the cell-level CQI adjustment value. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is deselected and the number of dynamic initial scheduling times of a MIMO UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is selected and the number of dynamic initial scheduling times of either a MIMO UE or beamforming UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If this parameter is set to 0, the algorithm of adaptively setting the initial cell-level CQI adjustment value does not take effect. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If this parameter is set to 0, the algorithm of adaptively setting the initial cell-level CQI adjustment value does not take effect. If this parameter is set to a non-0 value, the algorithm of adaptively setting the initial cell-level CQI adjustment value takes effect. A large value of this parameter leads to a small number of samples for the cell-level CQI adjustment value, accurate cell-level CQI adjustment, and large gains of the downlink cell rate and user-perceived rate. A small value of this parameter leads to a large number of samples for the cell-level CQI adjustment value, inaccurate cell-level CQI adjustment, and small gains of the downlink cell rate and user-perceived rate. If the numbers of MIMO UEs and packets are small, the number of the samples for the cell-level CQI adjustment value decreases, and cell-level CQI adjustment value is inaccurate in MIMO mode. In this case, the DTX proportion and packet error rate of beamforming UEs may increase. If the numbers of MIMO UEs and packets are large, the CQI adjustment value for MIMO UEs converges, cell-level CQI adjustment value is accurate, and the DTX proportion and packet error rate for beamforming UEs decrease. If the initial cell-level CQI adjustment value does not match UE channels, the service drop rate and bit error rate may increase.
