Meaning

Indicates the length of the long DRX cycle for a UE in the uplink out-of-synchronization state. Set this parameter to a value greater than the value of LongDrxCycle; otherwise, the power saving gain of the DRX for UEs in the uplink out-of-synchronization state may decrease. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

This parameter, together with the DrxInactivityTimerUnsync and OnDurationTimerUnsync parameters, affects the DRX mechanism for UEs in the out-of-synchronization state. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay and better KPIs such as the service drop rate and the handover success rate, and a larger value of this parameter results in the opposite effects.
