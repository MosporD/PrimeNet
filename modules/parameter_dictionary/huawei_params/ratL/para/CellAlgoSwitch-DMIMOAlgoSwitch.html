Meaning

Indicates whether to enable D-MIMO algorithms. This parameter applies only to LTE TDD.

DmimoJTSwitch: Indicates whether to enable D-MIMO joint transmission. If this option is selected, D-MIMO joint transmission is enabled. If this option is deselected, D-MIMO joint transmission is disabled. This option applies only to LTE TDD.

DmimoSchAttriOptSwitch: Indicates whether to enable scheduling attribute optimization for D-MIMO UEs. If this option is selected, scheduling attribute optimization is enabled for D-MIMO UEs. If this option is deselected, scheduling attribute optimization is disabled for D-MIMO UEs. This option applies only to LTE TDD.

InterCellDmimoJTSwitch: Indicates whether to enable inter-cell D-MIMO. If this option is selected, inter-cell D-MIMO is enabled. If this option is deselected, inter-cell D-MIMO is disabled. This option applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If DMIMOJTSwitch of DMIMOAlgoSwitch in a CellAlgoSwitch MO is selected, MuBfSwitch of MuBfAlgoSwitch in the CellAlgoSwitch MO must be selected.
  • The MuBfSwitch option of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO must be selected if the InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • The ULSUMIMO2LayersSwitch option of the UlSuMimoAlgoSwitch parameter in the CellAlgoSwitch MO and the DmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO cannot be both selected.
  • The BfSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO must be selected if the InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • The DmimoJTSwitch and InterCellDmimoJTSwitch options of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO must not be selected at the same time.
  • The DmimoSchAttriOptSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO can be selected only when the DmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected.

Impact on Radio Network Performance

DmimoJTSwitch: If this option is selected, average downlink user experience in multi-RRU cells and the experience of CEUs in such cells improve, but the RAR success rate decreases and the access delay increases. In this case, the total number of CCEs used in the uplink and downlink per TTI increases if CCE resources are sufficient, and CCE allocation failures per TTI increase if CCE resources are insufficient. If this option is deselected, average downlink user experience of multi-RRU cells and the experience of CEUs in such cells do not improve.

InterCellDmimoJTSwitch: If this option is selected, average downlink user experience and the experience of CEUs in cells improve, but the RAR success rate decreases and the access delay increases. In this case, the total number of CCEs used in the uplink and downlink per TTI increases if CCE resources are sufficient, and CCE allocation failures per TTI increase if CCE resources are insufficient. If this option is deselected, average downlink user experience and the experience of CEUs in cells do not improve.
