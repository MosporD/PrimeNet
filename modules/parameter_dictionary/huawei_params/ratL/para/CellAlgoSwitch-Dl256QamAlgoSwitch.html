Meaning

Indicates whether to enable the algorithms related to downlink (DL) 256 quadrature amplitude modulation (256QAM).

Dl256QamSwitch: Indicates whether to enable DL 256QAM. If this option is selected, DL 256QAM is enabled, and the highest-order DL modulation scheme is 256QAM for UEs that support DL 256QAM. If this option is deselected, DL 256QAM is disabled and the highest-order DL modulation scheme is 64QAM. This feature takes effect only when a UBBP or LBBPd board is configured. This option applies only to LTE FDD and LTE TDD.

Dl256QamAccessorySwitch: Indicates whether to enable DL 256QAM accessory. DL 256QAM accessory is enabled only if this option is selected. When this option is selected, error vector magnitude (EVM) is optimized for 256QAM in the TTIs in which DL 256QAM takes effect. The function takes effect only when a UBBP board is configured. This option applies only to LTE FDD.

Dl256QamTbsIndexExtSwitch: Indicates whether TBS index 33B can be used for DL 256QAM UEs. TBS index 33B can be used only if this option is selected. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

Dl256QamSwitch: If this option is selected, the throughput and spectral efficiency of 256QAM-capable UEs in the cell center are improved and data transmission delay is reduced. If this option is deselected, network performance is not affected. Dl256QamAccessorySwitch: If this option is selected, EVM is optimized for 256QAM-capable UEs in the TTIs in which DL 256QAM takes effect, improving the performance of these UEs and increasing user-perceived throughput of these UEs. If this option is deselected, network performance is not affected.

Dl256QamTbsIndexExtSwitch: If this option is selected, data rates of DL 256QAM UEs increase in the very cell center. If this option is deselected, network performance is not affected.
