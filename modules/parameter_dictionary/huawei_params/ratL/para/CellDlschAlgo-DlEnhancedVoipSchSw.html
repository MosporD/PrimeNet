Meaning

Indicates whether to enhance downlink scheduling for VoLTE services.

DlVoIPLoadBasedSchSwitch: Indicates whether to enable cell-load-based adaptive selection of dynamic scheduling and semi-persistent scheduling for VoLTE UEs. If this option is deselected, adaptive selection of dynamic and semi-persistent scheduling cannot be performed for VoLTE UEs based on the cell load. If this option is selected, dynamic and semi-persistent scheduling can be adaptively selected for VoLTE UEs based on the cell load. This option applies only to LTE FDD and LTE TDD.

DlSpsRevHarqUseSwitch: Indicates whether HARQ processes reserved for semi-persistent scheduling can be used for dynamic scheduling. If this option is deselected, HARQ processes reserved for semi-persistent scheduling cannot be used for dynamic scheduling. If this option is selected, HARQ processes reserved for semi-persistent scheduling can be used for dynamic scheduling. This option applies only to LTE FDD and LTE TDD.

DlSpsDrxDecouplingSwitch: Indicates whether the DRX long period affects semi-persistent scheduling configuration and activation. If this option is deselected, downlink semi-persistent scheduling cannot be configured or activated if the downlink semi-persistent scheduling period is not integral multiples of the DRX long period. If this option is selected, the DRX long period does not affect semi-persistent scheduling configuration and activation. This option applies only to LTE FDD and LTE TDD.

DlSchVoipDuringHoSwitch: Indicates whether to enable voice service scheduling in the downlink during scheduling of handover signaling. If this option is deselected, the eNodeB does not schedule voice services in the downlink when scheduling handover signaling. If this option is selected, the eNodeB can schedule voice services in the downlink when scheduling handover signaling, decreasing the downlink packet delay for voice services and improving voice quality during handovers, especially voice quality in DRX scenarios. This option applies only to LTE FDD and LTE TDD.

VoLTEDci1aSwitch: Indicates whether to send DL grant in the DCI1A format to VoLTE UEs. If this option is selected, the eNodeB sends DL grant in DCI1A format to UEs in TM3 rank 1 mode or during handovers, improving coverage. If this option is deselected, the eNodeB sends DL grant in default mode. This option applies only to LTE FDD and LTE TDD.

DlVoiceRetransOptSwitch: Indicates whether to assign a higher downlink retransmission priority to voice services than data services and whether to enable MCS selection optimization for downlink IMS signaling. If this option is deselected, the downlink retransmission priority is not differentiated between voice and data services and is determined by the waiting time. A longer waiting time indicates a higher priority. In addition, MCSs for downlink IMS signaling are selected in the same way as MCSs for initial transmission of data services. If this option is selected, the downlink retransmission priority is differentiated between services, and voice services have a higher downlink retransmission priority than data services. In addition, lower-order MCSs are selected for downlink IMS signaling than for initial transmission of data services. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

DlVoIPLoadBasedSchSwitch: If this option is selected, the capacity for VoLTE UEs increases compared with the capacity allowed when the option is deselected and dynamic scheduling is adopted, and transmission efficiency improves compared with the efficiency achieved when the option is deselected and semi-persistent scheduling is adopted.

DlSpsRevHarqUseSwitch: If this option is selected, HARQ processes reserved for semi-persistent scheduling can be used by dynamic scheduling, cell throughput increases, delay of VoIP packet transmission slightly increases, and MOS of VoIP services may decrease when all of the following conditions are met: (1) Both a VoIP connection and a data service connection are set up for a UE; (2) The amount of data on the data service bearer is sufficient; (3) Semi-persistent scheduling is performed for the VoIP connection. Selecting this option has no impact on network performance if condition 1 is not met.

If this option is deselected, network performance is not affected.

DlSpsDrxDecouplingSwitch: If this option is selected, the downlink packet loss rate increases and the MOS decreases for UEs that have poor compatibility performance and do not receive semi-persistently scheduled data during the sleep time. If this option is deselected, UEs compatibility is favorable; however, if the downlink semi-persistent scheduling period is not an integer multiple of the DRX long cycle, PDCCH resources cannot be saved due to an activation failure of downlink semi-persistent scheduling.

DlSchVoipDuringHoSwitch: Selecting this option reduces the downlink voice packet delay and improves voice quality during handovers, especially voice quality in DRX scenarios. However, the number of PDSCH RBs used for VoLTE UEs increases in the source cell, causing a decrease in the source cell throughput.

VoLTEDci1aSwitch: If this option is selected, the PDCCH coverage improves due to good demodulation performance of PUCCH format DCI1A. If this option is deselected, the default format is used, and the network performance is not affected.

DlVoiceRetransOptSwitch: If this option is selected, the transmission delay of downlink PDCP packets for QCI-1 services in heavy-traffic scenarios decreases, reducing the probability of poor downlink voice service quality and one-way audio under extreme conditions. However, the transmission delay of downlink PDCP packets for data services increases, and both downlink cell throughput and downlink UE throughput decrease. If this option is deselected, network performance is not affected.
