MML Command

MOD CELLPDCCHALGO

LST CELLPDCCHALGO
Meaning

Indicates whether to perform SDMA for PDCCH split beams.

MASSIVE_MIMO_PDCCH_SDMA_SW: If this option is selected, SDMA is performed for PDCCH split beams. If this option is deselected, joint transmission is always performed for PDCCH split beams. This option applies only to LTE TDD.

MASSIVE_MIMO_PDCCH_MEAS_SW: If this option is selected, PDCCH beam association measurement is performed for UEs in massive MIMO scenarios. If this option is deselected, PDCCH beam association measurement is disabled for UEs in massive MIMO scenarios. This option applies only to LTE TDD.

Caution

Ensure that the antenna weight is valid. Otherwise, changing the setting of the MASSIVE_MIMO_PDCCH_SDMA_SW option of the SplitBeamPdcchSdmaSw parameter will cause a cell activation failure.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

MASSIVE_MIMO_PDCCH_SDMA_SW: If this option is selected, SDMA is performed for PDCCH split beams in massive MIMO scenarios, increasing PDCCH capacity. If this option is deselected, SDMA is not performed for PDCCH split beams in massive MIMO scenarios.

MASSIVE_MIMO_PDCCH_MEAS_SW: This option has no impact on network performance.
