Meaning

Indicates the length of the timer contained in the RRC connection release message when an RRC connection release procedure is triggered for MLB. This timer specifies the length of a period during which cell-reselection priorities contained in the RRC connection release message retain valid. After the timer expires, the cell-reselection priorities contained in the RRC connection release message become invalid.

This timer starts when the UE receives an RRC connection release message containing the T320 timer and stops when the UE enters RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

After the T320 timer expires, the cell-reselection parameters contained in the RRC connection release message become invalid, and the cell-reselection parameters contained in the system information take effect. As the cell-reselection priorities contained in the system information are optional, frequency prioritization can be better guaranteed during cell reselection if the cell-reselection priorities contained in the RRC connection release message are used. If the value of this parameter is too large, cell-reselection parameters cannot be updated in time at the UE when cell-reselection parameter values change.
