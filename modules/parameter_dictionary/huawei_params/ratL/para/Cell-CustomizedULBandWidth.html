Meaning

Indicates a customized uplink bandwidth configured for a cell. A compact bandwidth can be configured only when a standard bandwidth 1.4 MHz, 5 MHz, 10 MHz, 15 MHz, or 20 MHz has been configured. This parameter applies only to LTE FDD.

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, when NbCellFlag is set to FALSE and CustomizedBandWidthCfgInd is set to CFG: If UlBandWidth is set to CELL_BW_N6, CustomizedULBandWidth must be set to a value in the range of 12 to 14; If UlBandWidth is set to CELL_BW_N25, CustomizedULBandWidth must be set to a value in the range of 44 to 50; If UlBandWidth is set to CELL_BW_N50, CustomizedULBandWidth must be set to a value in the range of 74, 75, 80 or 87 to 100; If UlBandWidth is set to CELL_BW_N75, CustomizedULBandWidth must be set to a value in the range of 139 to 150; If UlBandWidth is set to CELL_BW_N100, CustomizedULBandWidth must be set to a value in the range of 175 to 178 or 183 to 200.
  • In a Cell MO, if CustomizedBandWidthCfgInd is set to CFG, CustomizedULBandWidth and CustomizedDLBandWidth cannot both be set to 14, 50, 100, 150, or 200.
  • If the CustomizedULBandWidth parameter in a Cell MO is set to 74, 75, or 87, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, the UlPuncturedRbNumOffset parameter in this Cell MO must be set to 8, 7, 6, 5, 4, 3, 2, 1, 0, -1, -2, or -3.
  • If the CustomizedULBandWidth parameter in a Cell MO is set to a value in the range of 175 to 178, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, REDUCED_LEFT, or REDUCED_RIGHT, the UlPuncturedRbNumOffset parameter in this Cell MO must be set to 8, 7, 6, 5, 4, 3, 2, 1, 0, or -1.

-Parameter relationship with conditions:

  • If CustomizedBandWidthCfgInd is set to CFG, CustomizedULBandWidth must be set.
