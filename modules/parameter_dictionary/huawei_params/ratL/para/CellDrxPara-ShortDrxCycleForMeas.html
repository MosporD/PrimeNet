Impact on Radio Network Performance

This parameter, together with the LongDrxCycleForMeas, OnDurTimerForMeas, DrxInactTimerForMeas, ShortCycleTimerForMeas, and DrxReTxTimerForMeas parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay, and a larger value of this parameter results in the opposite effects.
