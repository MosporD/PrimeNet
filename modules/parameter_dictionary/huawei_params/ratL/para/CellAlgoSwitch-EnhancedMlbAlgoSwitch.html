LST CELLALGOSWITCH
Meaning

Indicates whether to enable MLB algorithm enhancements.

SpectralEffBasedLoadEvalSw: If this option is deselected, spectral efficiency differences are not considered during load comparison between the local cell and inter-frequency neighboring cells for intra-RAT user-number-based MLB. If this option is selected, spectral efficiency differences are considered in the preceding scenario, and cells with high spectral efficiency process more traffic. This option applies only to LTE FDD and LTE TDD.

VideoSrvLoadCtrlSw: If this option is deselected, handovers are not triggered for video service users based on the video service load in a cell. If this option is selected, handovers are triggered for video service users based on the video service load in a cell, improving video service experience. This option applies only to LTE FDD and LTE TDD.

CaUserLoadTransferSw: If this option is deselected, a CA UE is considered as one UL-sync UE separately in the PCell and SCell for cell-level MLB, and RRC_CONNECTED CA UEs configured with SCells cannot be transferred. If this option is selected, a CA UE is considered as one UL-sync UE only in the PCell for cell-level MLB, RRC_CONNECTED CA UEs configured with SCells can be transferred during user-number-based MLB. In addition, the PCC priority is considered, and a higher priority is allocated to the serving frequency when CA UEs with RRC connections released are to be transferred. This option applies only to LTE FDD and LTE TDD.

DediPrioManageOnLowLoadSw: If this option is deselected, UEs in lightly loaded cells do not carry the dedicated cell-reselection frequency priorities generated based on cell loads when the RRC connections of the UEs are released. If this option is selected and the eNodeB detects a different frequency with heavy loads, UEs in lightly-loaded cells carry the priorities when the RRC connections of the UEs are released, and the dedicated cell-reselection priority for the heavy-load frequency is lowered. This option applies only to LTE FDD and LTE TDD.

UlHeavyTrafficBaseLoadSw: If this option is deselected, loads of target FDD cells are not considered during uplink traffic-based MLB. If this option is selected, loads of target FDD cells are considered during uplink traffic-based MLB. If a target LTE FDD cell is heavily loaded, UEs cannot be handed over to this cell. This option applies only to LTE TDD.

UlExperiBasedTrafficSteerSw: If this option is deselected, the eNodeB does not transfer UEs with heavy uplink traffic based on uplink experience. If this option is selected, the eNodeB transfers UEs with heavy uplink traffic based on uplink experience, improving uplink user experience. This function takes effect only when the FreqSelectStrategy parameter is set to FAIRSTRATEGY. This option applies only to LTE TDD.

UlTrafficSteeringSw: If this option is deselected, the eNodeB transfers UEs regardless of whether uplink traffic is heavy or not during intra-RAT inter-duplex MLB. If this option is selected, the eNodeB does not transfer UEs with large uplink traffic volumes during intra-RAT inter-duplex MLB, allowing LTE FDD networks to handle more uplink services. This option takes effect only when the FreqSelectStrategy parameter in the CellMLB MO is set to FAIRSTRATEGY. This option applies only to LTE FDD.

ActiveUeBasedLoadEvalSw: If this option is selected, the eNodeB considers the difference in the number of active UEs when comparing loads of inter-frequency cells for intra-RAT user-number-based MLB. If this option is deselected, the eNodeB considers the difference of the number of uplink-synchronized UEs when comparing loads of inter-frequency cells for intra-RAT user-number-based MLB. This option applies only to LTE FDD and LTE TDD.

DediPrioManageOnLowLoadEnhSw: If this option is selected and the eNodeB detects a non-serving E-UTRA frequency with heavy loads, UEs in lightly-loaded cells carry the dedicated cell-reselection frequency priorities generated based on the cell loads when the RRC connections of the UEs are released (not only those caused by the UE Inactivity Timer timeout), and the dedicated priority for the heavy-load frequency is lowered.

LoadTransferEnhSw: If this option is selected, based on the frequency priorities and load differences, the eNodeB increases the upper limits of the numbers of UEs that can be transferred by idle mode MLB and connected mode MLB. In addition, the target for PRB-usage-based MLB is changed from balancing of the number of remaining PRBs to balancing of PRB usage. If this option is deselected, this algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

NCellTrigThldSmartOptAlgoSw: Indicates whether to enable smart optimization of neighboring-cell-specific MLB triggering thresholds. If this option is selected, the eNodeB sets a dedicated MLB triggering threshold for each inter-frequency neighboring cell of the serving cell, and checks whether the triggering thresholds are reached based on the load status of the serving and inter-frequency neighboring cells. Only the candidate cells that meet the condition are selected for MLB. In addition, the eNodeB periodically constructs a prediction model for the MLB triggering threshold to predict an optimum value for the neighboring-cell-specific MLB triggering threshold and change the threshold to the predicted value. If this option is deselected, this algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

Caution

1. If the setting of the CellCapacityScaleFactor parameter in the CellMLB MO has been optimized based on factors such as the uplink-downlink subframe configurations and the difference in spectral efficiency between frequency bands, it is recommended that the CellCapacityScaleFactor parameter be set to its default value before the SpectralEffBasedLoadEvalSw option is selected.

2. It is recommended that the CaUserLoadTransferSw option be selected when the CaSchStrategy parameter in the CellDlschAlgo MO is set to BASIC_SCHEDULE.

3. If an LTE TDD eNodeB and LTE FDD eNodeB are provided by the same vendor and the X2 interface has been configured between them, it is recommended that the UlHeavyTrafficBaseLoadSw option be selected. Otherwise, deselect the UlHeavyTrafficBaseLoadSw option.

4. In multi-frequency FDD and TDD networking, it is recommended that the UlExperiBasedTrafficSteerSw option be selected for TDD cells and the UlTrafficSteeringSw option be selected for FDD cells.

5. In roaming scenarios, if the DediPrioManageOnLowLoadSw option is selected, it is recommended that the DediPrioManageOnLowLoadEnhSw option be also selected.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

SpectralEffBasedLoadEvalSw: If this option is selected, UEs have similar average throughput in multi-band cells. If this option is deselected, similar amount of resources are allocated to UEs in multi-band cells, but each UE has a distinctly different average throughput.

VideoSrvLoadCtrlSw: If this option is selected, video service UEs in multi-band cells are more likely to require the same bandwidths. If this option is deselected, video service UEs in multi-band cells are more likely to require different bandwidths.

CaUserLoadTransferSw: If this option is selected, the MLB performance and user experience of CA UEs improve when a large proportion of UEs are CA UEs with SCells activated, but the number of handovers for CA UEs increases when the eNodeB transfers RRC_CONNECTED CA UEs. If this option is deselected, loads in cells may be imbalanced when the proportion of CA UEs with SCells activated is high, and the number of handovers for CA UEs does not increase because the eNodeB does not transfer RRC_CONNECTED CA UEs.

DediPrioManageOnLowLoadSw: If this option is selected, the eNodeB prevents UEs from being transferred back to high-load cells for MLB in the network where multiple frequency bands with different priorities are used. This avoids ping-pong cell reselections and ping-pong handovers. If this option is deselected, the number of ping-pong cell reselections or ping-pong handovers may increase.

UlHeavyTrafficBaseLoadSw: If this option is selected, the load of the target FDD cell is considered during uplink-traffic-based MLB. If the cell load is high, UEs cannot be handed over to the target FDD cell, avoiding user experience deterioration and ping-pong handovers.

UlExperiBasedTrafficSteerSw: If this option is selected, the eNodeB can transfer heavy-uplink-traffic UEs when uplink user experience deteriorates. This improves uplink user experience. If this option is deselected, the eNodeB does not consider the impact on uplink user experience.

UlTrafficSteeringSw: If this option is selected, the eNodeB does not transfer heavy-uplink-volume UEs in intra-RAT inter-duplex-mode MLB. In this case, FDD cells can carry more uplink traffic, improving uplink user experience. If this option is deselected, the eNodeB does not consider the impact of the heavy uplink traffic volume when transferring UEs in inter-duplex-mode MLB.

ActiveUeBasedLoadEvalSw: Selecting this option improves average UE throughput compared with deselecting this option when MLB is performed among three or more frequencies with different Uu interface capabilities.

DediPrioManageOnLowLoadEnhSw: If this option is selected, the eNodeB prevents UEs from being transferred back to high-load cells for MLB in the network where multiple frequency bands with different priorities are used or in roaming scenarios. This avoids ping-pong cell reselections and ping-pong handovers. If this option is deselected, the number of ping-pong cell reselections or ping-pong handovers may increase.

LoadTransferEnhSw: If this option is selected, the number of UEs and PRB usage are more balanced in multi-band cell, and the average user-perceived throughput increases. If this option is deselected, network performance is not affected.

NCellTrigThldSmartOptAlgoSw: Within seven days after this option is selected, the average user-perceived rates may decrease. After the seven days, the average user-perceived rates of light-load UEs increase if the network load is light. This is because the eNodeB will not transfer UEs to cells with a small bandwidth when the network load is light. If this option is deselected, network performance is not affected.
