Meaning

Indicates the power of GSM shared carrier in the GSM and LTE co-coverage area. The power value is used to calculate the difference in power spectrum density (PSD) between GSM and LTE, which can be used for selecting an appropriate GL guardband. This parameter is invalid when it is set to 65535. This parameter applies only to LTE FDD.

Impact on Radio Network Performance

If this parameter is set to a value the same as the actual power value configured for the co-coverage GSM shared carrier:

A larger value of this parameter results in a greater difference in PSD between GSM and LTE, larger guardband between GSM shared carrier and LTE RBs, fewer available LTE RBs, and lower LTE throughput.

A smaller value of this parameter results in the opposite effects.

If this parameter is set to a value different from the actual power value configured for the co-coverage GSM shared carrier:

If this parameter is set to a value greater than the actual power value, the calculated difference in PSD between GSM and LTE is greater than the actual difference and a larger guardband between the GSM shared carrier and LTE RBs will be selected. As a result, fewer RBs are available for LTE, causing LTE throughput to decrease.

If this parameter is set to a value smaller than the actual power value, the calculated difference in PSD between GSM and LTE is smaller than the actual difference and a smaller guardband between the GSM shared carrier and LTE RBs will be selected. As a result, the GSM and LTE cells covering the same area interfere with each other, causing GSM and LTE performance to deteriorate.
