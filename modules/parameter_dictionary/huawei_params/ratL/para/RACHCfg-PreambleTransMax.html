Impact on Radio Network Performance

A larger value of this parameter results in a higher probability that the eNodeB correctly receives preambles from UEs, but it leads to a longer delay of RRC connection reestablishments when radio link failure (RLF) occurs. A smaller value leads to the opposite effects.
