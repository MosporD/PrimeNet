Parameter Name

CA Algorithm Switch
NE

MML Command

MOD ENODEBALGOSWITCH

LST ENODEBALGOSWITCH
Meaning

Indicates whether to enable carrier aggregation (CA). This parameter includes the following options:

- PdcchOverlapSrchSpcSwitch:

Indicates whether CA UEs regard the overlapping PDCCH candidates of the common search space and UE-specific search space, which are transmitted by the primary serving cell (PCell), as PDCCH candidates of the common or UE-specific search space. When this option is selected, a CA UE determines that the overlapping PDCCH candidates belong to the common search space, if the CA UE supports cross-carrier scheduling and is assigned a carrier indicator field (CIF); otherwise, the CA UE determines that the overlapping PDCCH candidates belong to the UE-specific search space. When this option is deselected, a CA UE always determines that the overlapping PDCCH candidates belong to the common search space. This option applies only to LTE FDD and LTE TDD.

- PccAnchorSwitch:

Indicates whether to enable primary component carrier (PCC) anchoring for RRC_CONNECTED UEs. This option is not subject to the setting of the FreqCfgSwitch option of the CaAlgoSwitch parameter. This type of PCC anchoring is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- SccBlindCfgSwitch:

Indicates whether to allow blind SCell configuration. This option takes effect only in CA-group-based configuration mode. If this option is selected, the eNodeB can configure SCells for CA UEs without A4 measurements. If this option is deselected, the eNodeB delivers A4 measurement configurations to CA UEs before it can configure SCells for the UEs. This option applies only to LTE FDD and LTE TDD.

- FreqCfgSwitch:

Indicates whether the eNodeB performs CA procedures in adaptive mode or based on CA groups. If this option is selected, the eNodeB performs CA procedures in adaptive mode. If this option is deselected, the eNodeB performs CA procedures based on CA groups. This option applies only to LTE FDD and LTE TDD.

- SccA2RmvSwitch:

Indicates whether the eNodeB delivers A2 measurement configurations for SCells that have been configured for CA UEs. This option is not subject to the setting of the FreqCfgSwitch option of the CaAlgoSwitch parameter. SccA2RmvSwitch does not take effect if the FreqCfgSwitch option is deselected and the SccBlindCfgSwitch option is selected. The eNodeB delivers A2 measurement configurations for SCells after configuring the SCells for CA UEs only when the SccA2RmvSwitch option is selected. This option applies only to LTE FDD and LTE TDD.

- CaTrafficTriggerSwitch:

Indicates whether the eNodeB considers the traffic volume of CA UEs during SCell configuration and removal evaluation at initial access. This option is not subject to the setting of the FreqCfgSwitch option of the CaAlgoSwitch parameter but to the setting of the CarrierMgtSwitch parameter. If the CarrierMgtSwitch parameter is set to OFF and CaTrafficTriggerSwitch is selected, the eNodeB will not remove SCells based on the traffic volume after configuring them. This option applies only to LTE FDD and LTE TDD.

- HoWithSccCfgSwitch:

Indicates whether the base station can configure SCells for CA UEs during handovers and include the "reportAddNeighMeas" IE in the measurement configurations. This option is not subject to the setting of the frequency configuration switch. The base station (serving the source cell) includes the "candidateCellInfoList-r10" IE in the handover preparation message, configures SCells for CA UEs during handovers, and includes the "reportAddNeighMeas" IE in the measurement configurations only if this option is selected. This option applies only to LTE FDD and LTE TDD.

- SccModA6Switch:

Indicates whether the eNodeB delivers A6 (or A3 for PSCell) measurement configurations to CA/DC UEs after configuring SCells for the UEs. The eNodeB delivers the A6 (or A3 for PSCell) measurement configurations only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- GbrAmbrJudgeSwitch:

Indicates whether the eNodeB checks the bit rate of each GBR service or the total bit rate of non-GBR services when evaluating SCell activation in the downlink. If this option is selected, the eNodeB conducts the check and activates SCells only when the bit rate of a GBR service or the total bit rate of non-GBR services has not reached the GBR or AMBR, respectively. If this option is deselected, the eNodeB does not conduct the check. This option applies only to LTE FDD and LTE TDD.

- MtaAlgSwitch:

Indicates whether the eNodeB supports multiple timing advances (MTA) for uplink CA. When this option is selected, the eNodeB supports MTA for uplink CA. If the capability information reported by a UE indicates that the UE supports MTA in the uplink, uplink timing using multiple timing advance groups (TAGs) works for the UE in uplink CA scenarios. If the capability information indicates that the UE does not support MTA in the uplink, uplink timing using a single TAG works for the UE in uplink CA scenarios. When this option is deselected, the eNodeB does not support MTA for uplink CA, and uplink timing using a single TAG in uplink CA scenarios applies to all UEs in the served cells. It is recommended that this option be selected in inter-eNodeB CA scenarios or when RRUs are installed remotely. This option applies only to LTE FDD and LTE TDD.

- RelaxedBackhaulCaSwitch:

Indicates whether to enable inter-eNodeB CA based on relaxed backhaul. If this option is selected, inter-eNodeB CA works in relaxed backhaul scenarios where the inter-eNodeB one-way delay is up to 4 ms. If this option is deselected, inter-eNodeB CA based on relaxed backhaul is disabled. This option applies only to LTE FDD.

- AdpCaSwitch:

Indicates whether to enable adaptive CA, which incorporates blind SCell configuration into frequency-based CA. Adaptive CA is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaHoControlSwitch:

Indicates whether to prohibit unnecessary intra-RAT handovers to non-macro cells. CA UEs can be handed over to non-macro cells during unnecessary intra-RAT handovers only when this option is deselected. This option applies only to LTE FDD and LTE TDD.

- DistributeCloudbbCaSwitch:

Indicates whether to enable inter-eNodeB CA based on distributed Cloud BB. Inter-eNodeB CA based on distributed Cloud BB is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- SccSmartCfgSwitch:

Indicates whether to consider the load status of candidate SCells during SCell configuration. The eNodeB considers the load status only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- IdleModePccAnchorSwitch:

Indicates whether to enable PCC anchoring for RRC_IDLE UEs. This type of PCC anchoring is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- FreqPriBasedHoCaFiltSwitch:

Indicates whether the eNodeB filters CA UEs out when delivering measurement configurations related to frequency-priority-based handovers. The eNodeB filters CA UEs out only when this option is selected.

- CaSccSuspendSwitch:

Indicates whether the eNodeB stops scheduling CA UEs when the channel quality for the CA UEs in their SCells is poor. If this option is selected, the eNodeB stops scheduling CA UEs when the channel quality for the CA UEs is worse than that indicated by the value of SccDeactCqiThd in single-codeword transmission. The eNodeB resumes scheduling of the CA UEs in their SCells when the channel quality becomes higher than the value of SccDeactCqiThd plus 2 in single-codeword transmission. This option applies only to LTE FDD and LTE TDD.

- PccSmartCfgSwitch:

Indicates whether the eNodeB considers the load status of candidate PCells (or PSCells) during PCC anchoring for CA UEs (or DC UEs). The eNodeB considers the load status only if this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaA5HoEventSwitch:

Indicates whether to change event A4 to event A5 in the handover-related inter-frequency measurement configurations delivered to CA UEs. Such handovers include coverage-based inter-frequency handovers, uplink-quality-based inter-frequency handovers, distance-based inter-frequency handovers, inter-frequency handovers of all UEs due to carrier power-off, intra-RAT inter-frequency handovers for unlimited-service (US) UE assurance, outgoing inter-frequency handovers of non-US UEs, inter-frequency handovers for MLB, frequency-priority-based inter-frequency handovers, service-based inter-frequency handovers, SPID-based inter-frequency handovers back to the HPLMN, eMBMS-interest-based inter-frequency handovers, speed-based inter-frequency handovers, redirection to specified frequencies for high-mobility UEs (for LTE TDD only), service-request-based inter-frequency handovers, and inter-frequency handovers for PCC anchoring. When this option is selected, the eNodeB changes event A4 to event A5 only if the network and the UE both support CA. When this option is deselected, the eNodeB delivers inter-frequency measurement configurations related to the handover event determined by relevant algorithms, without changing event A4 to event A5. There are exceptions. One exception is that, if this option is deselected and SCells have been configured for the CA UEs, the eNodeB changes event A4 to event A5 for the following types of inter-frequency handovers: coverage-based handovers, uplink-quality-based handovers, distance-based handovers, handovers of all UEs due to carrier power-off, intra-RAT handovers for US UE assurance, outgoing handovers of non-US UEs, handovers for MLB, and handovers for PCC anchoring. The other exception is that, if this option is deselected, the CaA5HoEventEnhSwitch option of the CaAlgoExtSwitch parameter in the EnodeBAlgoSwitch MO is selected, and SCells have been configured for the CA UEs, the eNodeB changes event A4 to event A5 for the following types of inter-frequency handovers: frequency-priority-based handovers, service-based handovers, SPID-based handovers back to the HPLMN, eMBMS-interest-based handovers, speed-based handovers, redirection to specified frequencies for high-mobility UEs (for LTE TDD only), and service-request-based handovers. This option applies only to LTE FDD and LTE TDD.

- EnhancedPccAnchorSwitch:

Indicates whether to enable enhanced PCC anchoring at initial access, incoming handovers, and RRC connection reestablishments. This type of PCC anchoring is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaAdpPreSchSwitch:

Indicates whether to enable adaptive preallocation in CA. Adaptive preallocation is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaPreSchSwitch:

Indicates whether to enable preallocation in CA. Preallocation is enabled in intra-eNodeB inter-BBP CA as well as in inter-eNodeB CA in the centralized Cloud BB architecture only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaLoadBalancePreAllocSwitch:

Indicates whether to enable load-based traffic allocation in CA. If this option is selected, traffic is dynamically allocated among CA cells served by the eNodeB to achieve load balancing. If this option is deselected, traffic is evenly allocated. This option applies only to LTE FDD and LTE TDD.

- RelaxedBHCaArqSelectSwitch:

Indicates whether to enable HARQ optimization in relaxed-backhaul-based CA. HARQ optimization is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

- CaSmartSelectionSwitch:

Indicates whether to enable intelligent selection of serving cell combinations. The eNodeB provides the most suitable serving cell combination for each CA UE based on network status and UE capabilities only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- RelaxedBHCaEnhanceSwitch:

Indicates whether to enable enhanced relaxed-backhaul-based CA. If this option is selected, the maximum allowed inter-eNodeB one-way delay for relaxed-backhaul-based CA is extended from 4 ms to 8 ms. If this option is deselected, this extension is not supported. This option applies only to LTE FDD and LTE TDD.

- CaRlcPreAllocSwitch:

Indicates whether to enable preallocation in RLC traffic offloading for CA UEs with inter-eNodeB CA applied. Preallocation is enabled only when this option is selected. This option applies only to LTE FDD and LTE TDD.

- TddRelaxedBackhaulCaSwitch:

Indicates whether to enable inter-eNodeB CA based on relaxed backhaul for TDD cells. Inter-eNodeB CA based on relaxed backhaul is enabled for TDD cells only if this option is selected. This option applies only to LTE TDD.

- PccAnchorOptSwitch:

Indicates whether to enable PCC anchoring optimization. If this option is selected, the eNodeB performs PCC anchoring to select a lower-priority carrier as the PCC for a CA UE when the UE is served by a higher-priority carrier that cannot function as a PCC. If this option is deselected, the eNodeB does not perform PCC anchoring to select a lower-priority carrier as the PCC. This option applies only to LTE FDD and LTE TDD.

Disuse statement: CaPreSchSwitch:This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Parameter Relationship

-Configuration constraints:

  • The CaPreSchSwitch option of CaAlgoSwitch in the ENodeBAlgoSwitch MO can be selected only if the CaAdpPreSchSwitch option of CaAlgoSwitch in the ENodeBAlgoSwitch MO is selected.
  • If CaSmartSelectionSwitch of CaAlgoSwitch in the ENodeBAlgoSwitch MO is selected, FreqCfgSwitch of the same parameter must be selected.
  • The FreqCfgCaOverBBUsSwitch option of OverBBUsSwitch in the ENodeBAlgoSwitch MO can be selected only if the FreqCfgSwitch option of CaAlgoSwitch in the ENodeBAlgoSwitch MO is selected.
  • If the CaEnhancedPreAllocSwitch option of CaAlgoExtSwitch in the ENodeBAlgoSwitch MO is selected, the CaLoadBalancePreAllocSwitch option of CaAlgoSwitch in the ENodeBAlgoSwitch MO must be deselected.
  • If the InterEnodebLaaSwitch option of the CaAlgoExtSwitch parameter in an ENodeBAlgoSwitch MO is selected, the FreqCfgSwitch option of the CaAlgoSwitch parameter in the same ENodeBAlgoSwitch MO must be selected.
  • The CaSmartSelectionSwitch option of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO must be selected if the SmartCaFastSccCfgSwitch option of the CaAlgoExtSwitch parameter in the same MO is selected.
  • If the CaMubfPairingAdaptOptSwitch option of the CaAlgoExtSwitch parameter in the ENodeBAlgoSwitch is selected, the AdpCaSwitch and CaSmartSelectionSwitch options of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO must be selected and deselected, respectively.

Impact on Radio Network Performance

PdcchOverlapSrchSpcSwitch:

If this option is selected and a majority of CA UEs in the network comply with 3GPP TS 36.213 V10.9.0 or a later version, the aperiodic channel state information (CSI) demodulation success rate of the CA UEs in the secondary serving cells (SCells) increases, and throughput in the SCells also increases. If this option is selected but a majority of CA UEs in the network do not comply with 3GPP TS 36.213 V10.9.0 or a later version, these UEs may blindly detect or demodulate the PDCCH incorrectly, and throughput in the cell decreases.

If this option is not selected and a majority of CA UEs in the network comply with 3GPP TS 36.213 V10.9.0 or a later version, these UEs may blindly detect or demodulate the PDCCH incorrectly, and throughput in the cell decreases. If this option is not selected and a majority of CA UEs in the network do not comply with 3GPP TS 36.213 V10.9.0 or a later version, the aperiodic CSI demodulation success rate of the CA UEs in the SCells increases, and throughput in the SCells also increases.

If a majority of CA UEs in the network do not comply with 3GPP TS 36.213 V10.9.0 or a later version, you are advised not to select this option; otherwise, you are advised to select this option.

PccAnchorSwitch:

If this switch is On, the eNodeB attempts to select a PCell with a larger value of the PreferredPCellPriority or PreferredPccPriority parameter for a CA UE that has accessed a cell with a smaller value of this parameter, thereby increasing the number of inter-frequency handovers. If this switch is Off, no impact on network performance.

SccBlindCfgSwitch:

If this switch is On and an SCell provides poor coverage, the radio transmission efficiency of the CA UE in the SCell decreases, and therefore the SCell throughput decreases. If this switch is Off, no impact on network performance.

MtaAlgSwitch:

If this option is selected, uplink timing based on multiple TAGs is supported in uplink CA scenarios. In this case, more resources are consumed for uplink timing and uplink throughput decreases if the SCell and PCell share the same timing offset; uplink cell throughput increases if the SCell and PCell have different timing offsets (for example, in inter-BBU CA scenarios and scenarios where RRUs are installed remotely). If this option is deselected, uplink timing based on multiple TAGs is not supported in uplink CA scenarios. Network performance is not affected if the SCell and PCell share the same timing offset. If the SCell and PCell have different timing offsets, the uplink timing adjustment for UEs in the SCell is delayed, and therefore uplink throughput decreases.

RelaxedBackhaulCaSwitch:

Inter-eNodeB CA based on relaxed backhaul is enabled only when this switch is On. The performance of inter-eNodeB CA based on relaxed backhaul is dependent on the inter-eNodeB transmission quality and radio conditions over the air interfaces. If KPIs such as the transmission delay, jitter, and packet loss rate are unsatisfactory or radio conditions over air interfaces are poor, the data rate of UEs involved in inter-eNodeB CA based on relaxed backhaul fluctuates and decreases. If this switch is Off, no impact on network performance.

AdpCaSwitch:

If this switch is On, SCells can be configured rapidly, and the data transmission rate increases more quickly.

CaHoControlSwitch:

If this option is selected, CA UEs cannot be handed over to non-macro cells during unnecessary intra-RAT handovers. Therefore, the number of candidate cells for handovers of CA UEs decreases, and throughput of CA UEs increases. Deselecting this option has the opposite effects.

DistributeCloudbbCaSwitch:

If this option is selected, CA based on distributed Cloud BB is enabled. The performance of CA based on distributed Cloud BB is dependent on the inter-eNodeB transmission quality and radio conditions over the air interfaces. If KPIs such as the transmission delay, jitter, and packet loss rate are unsatisfactory or radio conditions over air interfaces are poor, the downlink data rate of UEs involved in CA based on distributed Cloud BB fluctuates and decreases. Deselecting this option has no impact on network performance.

SccSmartCfgSwitch:

None.

IdleModePccAnchorSwitch:

If this option is selected and the PccAnchorSwitch option is deselected, the proportion of CA UEs in the cell increases. If both this option and PccAnchorSwitch are selected, the number of inter-frequency handovers for CA UEs decreases. If this option is deselected, network performance is the same as that when PccAnchorSwitch is deselected.

FreqPriBasedHoCaFiltSwitch:

None.

CaSccSuspendSwitch:

If this option is deselected, an SCell can be deactivated when the channel quality for CA UEs is very poor. The eNodeB will reactivate the SCell and attempt to schedule the CA UEs in the SCell after a predefined period of time. This causes periodic throughput fluctuation.

If this option is selected, the eNodeB stops scheduling CA UEs in their SCells when the channel quality for the CA UEs is very poor. The eNodeB resumes scheduling CA UEs in their SCells when the channel quality becomes satisfactory. This prevents throughput fluctuation caused by frequent SCell activation and deactivation. However, selecting this option increases power consumption of CA UEs, the number of CA UEs with active SCells, and interference on the PUCCH.

CaAdpPreSchSwitch:

If this switch is on, adaptive preallocation is enabled in inter-eNodeB CA based on relaxed backhaul and inter-eNodeB CA based on distributed cloud BB. In this way, throughput of a single CA UE increases. Turning off this switch has no impact on network performance.

CaPreSchSwitch:

If this switch is on, preallocation is enabled in intra-eNodeB inter-BBP CA and inter-BBU CA based on centralized cloud BB. In this way, more inter-BBP or inter-BBU cells can be selected for CA, but throughput of a single CA UE decreases in inter-BBP or inter-BBU CA. Turning off this switch has no impact on network performance.

CaLoadBalancePreAllocSwitch:

If this switch is on, loads among carriers can be balanced, spectral efficiency increases, and the system capacity expands. Turning off this switch has no impact on network performance.

RelaxedBHCaArqSelectSwitch:

None.

TddRelaxedBackhaulCaSwitch:

Inter-eNodeB CA based on relaxed backhaul is enabled for LTE TDD if this option is selected. The performance of inter-eNodeB CA based on relaxed backhaul for LTE TDD depends on the inter-eNodeB transmission quality and radio conditions over the air interfaces. If the transmission delay, jitter, and packet loss rate increase or the radio conditions over the air interfaces are poor, the data rate of inter-eNodeB CA UEs fluctuates or decreases. Deselection of this option does not affect the network.

PccAnchorOptSwitch:

If this option is selected, the number of inter-frequency handovers triggered by PCC anchoring increases.
