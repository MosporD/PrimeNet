Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 12~14, 44~50, 139~150, or 175~178, DlPuncturedRbNum must be set to 255.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 96~100 or 193~200, DlPuncturedRbNum must be set to 255 or 0.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 92~95 or 190~192, DlPuncturedRbNum must be set to 255, 0, or 2.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 186~189, DlPuncturedRbNum must be set to 255, 0, 2, or 4.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 183~185, DlPuncturedRbNum must be set to 255, 0, 2, 4, or 6.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 88~91, DlPuncturedRbNum must be set to 255, 2, or 4.
  • In a Cell MO, if CustomizedDLBandWidth is set to a value in the range of 80, DlPuncturedRbNum must be set to 255 or 8.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74, 75, or 87, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to NORMAL, the DlPuncturedRbNum parameter in this Cell MO must be set to 255.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74 or 75, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 8, 9, 10, 11, 12, or 13.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 87 and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED, REDUCED_LEFT, or REDUCED_RIGHT, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 3, 4, 5, 6, or 7.
  • If the CustomizedDLBandWidth parameter in a Cell MO is set to 74 or 75, and the CompactBwCtrlIntrfMode parameter in this Cell MO is set to REDUCED_LEFT, or REDUCED_RIGHT, the DlPuncturedRbNum parameter in this Cell MO must be set to 255, 9, 10, 11, 12, or 13.

-Parameter relationship with conditions:

  • If CustomizedBandWidthCfgInd is set to CFG, DlPuncturedRbNum is valid.
