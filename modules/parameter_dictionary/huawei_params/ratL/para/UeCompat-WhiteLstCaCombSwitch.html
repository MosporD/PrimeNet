LST UECOMPAT
Meaning

Indicates whether a private CA band combination takes effect only on UEs in the whitelist. If an option is selected, the specified private CA band combination takes effect only on the whitelisted UEs. If the option is deselected, the combination takes effect on all CA UEs. For example, if PRIVATECACOMBID_0 is selected, the private CA band combination with an ID of 0 takes effect only on the whitelisted UEs. This parameter applies only to LTE FDD and LTE TDD.
