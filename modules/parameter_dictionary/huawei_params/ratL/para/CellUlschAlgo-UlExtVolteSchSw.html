Meaning

Indicates whether to turn on extended scheduling switches for VoLTE services in the uplink. This parameter includes the following options.

UlVolteRetransSchOptSwitch: Indicates whether to optimize retransmission scheduling for voice UEs in the uplink. If this option is deselected, retransmission scheduling is not optimized for voice UEs in the uplink. If this option is selected, the eNodeB lowers the MCS index, allocates more RBs, and boosts the transmit power for retransmission of voice UEs to increase the uplink retransmission success rate and lower the uplink packet loss rate of such UEs. This option applies only to LTE TDD.

UlVolteIcsSwitch: Indicates whether to optimize UL ICS for voice UEs in the uplink. If this option is deselected, UL ICS is not optimized for voice UEs in the uplink. If this option is selected, UL ICS is optimized for voice UEs in the uplink. This option applies only to LTE TDD.

UlVolteIcsPuschOptSwitch: Indicates whether to reuse PUSCH RBs for voice UEs when UL ICS is performed for such UEs. If this option is deselected, PUSCH RBs are not reused for voice UEs. If the UL_ICS_SWITCH option of the UlIcSwitch parameter is selected and both this option and the UlVolteIcsSwitch option of the UlExtVolteSchSw parameter are also selected, interference coordination is enhanced and optimized for voice UEs. This option applies only to LTE TDD.

Impact on Radio Network Performance

UlVolteRetransSchOptSwitch: If this option is selected, the eNodeB lowers the MCS index, allocates more RBs, and boosts the transmit power for retransmission of voice UEs to increase the retransmission success rate and improve the voice quality of such UEs. However, more RBs are consumed by these UEs in the uplink, lowering the uplink cell and user throughput.

UlVolteIcsSwitch: If this option is selected, UL ICS is performed for voice UEs, reducing interference between voice UEs at the cell edge and increasing the voice quality of such UEs. However, the use of RBs by data UEs in the uplink is affected, lowering the average uplink cell throughput and the spectral efficiency.

UlVolteIcsPuschOptSwitch: If this option is selected, PUSCH RBs can be reused for UL ICS performed for voice UEs, improving voice quality of voice CEUs and reducing the impact on the uplink throughput of data UEs. If this option is deselected, the impact is the same as when the UlVolteIcsSwitch option is selected.
