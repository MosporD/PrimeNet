eMTC Algorithm Switch

MO CellEmtcAlgo
Parameter ID EmtcAlgoSwitch
Parameter Name

eMTC Algorithm Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLEMTCALGO

LST CELLEMTCALGO
Meaning

Indicates whether to enable eMTC-related algorithms.

EMTC_SWITCH: Indicates whether to enable eMTC. If this option is selected, eMTC UEs can access the cell and perform services normally. If this option is deselected, eMTC UEs cannot access the cell to perform services. This option applies only to LTE FDD and LTE TDD.

IDLE_EDRX_SWITCH: Indicates whether to enable eDRX in idle mode. If this option is selected, eDRX takes effect in idle mode. If this option is deselected, eDRX does not take effect in idle mode. This option applies only to LTE FDD and LTE TDD.

G_VALUE_CFG_SWITCH: Indicates value G configured for eMTC UEs. If this option is deselected, the eNodeB adapts value G for eMTC UEs. If this option is selected, value G is fixed to 1 for eMTC UEs. If the value of this parameter is changed, the value of the mpdcch-startSF-CSS-RA-r13 IE is changed, and eMTC UEs that already accessed the cell will be proactively released. This option applies only to LTE TDD.

SI_UPDATE_REL_UE_SWITCH: Indicates whether to proactively release eMTC UEs when system information changes. If this option is selected, when system information changes due to the changes of cell-level SRS resources allocated to eMTC UEs, the eNodeB proactively releases eMTC UEs that accessed the network before the system information change. If this option is deselected, when system information changes due to the changes of cell-level SRS resources allocated to eMTC UEs, the eNodeB does not proactively release eMTC UEs that accessed the network before the system information change. This option applies only to LTE FDD.

EMTC_ONLY_CELL_SWITCH: Indicates whether a cell is an eMTC-only cell. When this option is selected, a cell enters the eMTC-only state, and common UEs cannot access this cell. When this option is deselected, the cell exits the eMTC-only state, and common UEs can access this cell. eMTC-only cells support only 1.4 MHz, 3 MHz, or 5 MHz bandwidth. This option applies only to LTE FDD.

MODE_A_UE_TA_SCHEDULING_SWITCH: Indicates whether the eNodeB proactively allocates PUSCH resources to ModeA UEs for uplink timing measurement. When ModeA UEs do not have sufficient PUSCH resources, the eNodeB proactively allocates PUSCH resources to ModeA UEs for uplink timing measurement only if this option is selected. This option applies only to LTE FDD and LTE TDD.

EMTC_UE_ACK_START_OFFSET_CFG: Indicates whether to enable configuration of UE-level ACK resource start positions for eMTC UEs. If this option is deselected, UE-level ACK resource start positions are not configured. If this option is selected, UE-level ACK resource start positions can be configured for eMTC UEs whose coverage level is 0. This option takes effect only if the cell has a 10 MHz or higher bandwidth and the DeltaShift parameter in the PUCCHCFG MO is set to DS1_DELTA_SHIFT(ds1) or DS2_DELTA_SHIFT(ds2) for the cell. This option applies only to LTE FDD.

DL_PERFORMANCE_ENHANCE_SWITCH: Indicates whether to enable downlink performance enhancement for eMTC UEs. The enhancement is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_PERFORMANCE_ENHANCE_SWITCH: Indicates whether to optimize the uplink and downlink scheduling cooperation and the resource allocation strategy for eMTC UEs so as to improve the uplink link adaptation performance for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

EMTC_CONG_CONTROL_OPT_SWITCH: Indicates whether to enable congestion control based on the eMTC air interface resource load. If this option is selected, access class (AC) control or enhanced AC control for eMTC UEs is triggered based on the load of air interface resources occupied by the signaling of eMTC UEs. If this option is deselected, AC control or enhanced AC control for eMTC UEs is triggered the same way as that for LTE UEs. This option applies only to LTE FDD and LTE TDD.

MPDCCH_MORE_AVAIL_NB_SWITCH: Indicates whether to allow more narrowbands to be allocated to the MPDCCH of the cell. If this option is selected, up to 12 narrowbands can be allocated to the MPDCCH. If this option is deselected, only the default narrowbands are allocated to the MPDCCH. This option takes effect only for cells with the 10 MHz, 15 MHz, or 20 MHz bandwidth. This option applies only to LTE FDD and LTE TDD.

UL_MCS_SCHEDULING_OPT_SWITCH: Indicates whether to enable selection of optimal RBs, MCS, and number of repetitions for uplink scheduling of eMTC UEs at the cell edge. This option applies only to LTE FDD.

EMTC_UL_MCS_SELECT_OPT_SWITCH: Indicates whether to enable eMTC PUSCH MCS selection optimization. This option applies only to LTE FDD and LTE TDD.

EMTC_RATE_ENH_SWITCH: Indicates whether to configure 10 HARQ processes and activate HARQ-ACK bundling for eMTC UEs in CE mode A. For details, see 3GPP TS 36.331 Release 14 and 3GPP TS 36.213 Release 14. If this option is selected, the eNodeB checks whether to configure 10 HARQ processes and activate HARQ-ACK bundling for UEs in CE mode A based on the UE capability reported using the ce-PDSCH-TenProcesses-r14, ce-HARQ-AckBundling-r14, and ce-SchedulingEnhancement-r14 IEs. This option applies only to LTE FDD.

BL_UE_INTER_FREQ_HO_SWITCH: Indicates whether to enable inter-frequency handover and emergency blind inter-frequency redirection for BL UEs. Inter-frequency handover and emergency blind inter-frequency redirection for BL UEs are enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_AMC_OPT_SWITCH: Indicates whether to optimize link adaptation performance for eMTC UEs in the uplink, and whether to extend the PUSCH repetition count and restrict PUSCH modulation for CE UEs in mode A as defined by the ce-PDSCH-PUSCH-Enhancement IE. For details, see 3GPP TS 36.213 Release 14. This option applies only to LTE FDD and LTE TDD.

DL_AMC_OPT_SWITCH: Indicates whether to optimize link adaptation performance for eMTC UEs in the downlink, and whether to restrict PDSCH modulation for CE UEs in mode A as defined by the ce-PDSCH-PUSCH-Enhancement IE. For details, see 3GPP TS 36.213 Release 14. This option applies only to LTE FDD and LTE TDD.

EMTC_CSI_RS_OPT_SWITCH: Indicates whether to optimize the cooperation between eMTC and CSI-RS. If this option is selected, the eNodeB uses an MCS with a low index for the scheduling of eMTC UEs so that eMTC UEs can be scheduled in CSI-RS subframes. This reduces the impact of CSI-RS subframe changes on eMTC UEs. If this option is deselected, the eNodeB sets CSI-RS subframes as invalid subframes and informs eMTC UEs of these subframes through system information. This option applies only to LTE FDD and LTE TDD.

EMTC_PRACH_IRC_SWITCH: Indicates whether to enable eMTC PRACH MRC/IRC adaptation. If this option is deselected, MRC is used for the eMTC PRACH. If this option is selected, MRC or IRC is used adaptively for the eMTC PRACH. This option applies only to LTE FDD and LTE TDD.

EMTC_MSG3_RETRANS_OPT_SWITCH: Indicates whether to optimize eMTC Msg3 retransmission. If this option is selected, the eNodeB predicts whether resources can be successfully allocated for eMTC Msg3 retransmission and attempts to allocate resources only if the prediction result indicates successful allocation. This reduces the probability of eMTC Msg3 retransmission failure. If this option is deselected, the eNodeB does not perform the prediction. This option applies only to LTE FDD and LTE TDD.

EMTC_SIG_MCS_ENH_SWITCH: Indicates whether to enable enhanced MCS selection for signaling transmission for eMTC UEs. If this option is selected, enhanced MCS selection for signaling transmission takes effect for eMTC UEs. If this option is deselected, a conservative MCS is used for signaling transmission for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

UL_PERCEIVED_AMC_SWITCH: Indicates whether to enable uplink perception-based AMC. If this option is selected, the eNodeB perceives the scheduling characteristics of eMTC UEs, which helps increase the uplink data rates of eMTC UEs. If this option is deselected, the algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

DL_AGILE_CQI_ADJ_SWITCH: Indicates whether to enable downlink flexible CQI adjustment. If this option is selected, IBLER convergence is accelerated during initial access or incoming handovers, which helps increase the downlink data rates of eMTC UEs. When this option is deselected, a fixed convergence rate is used. This option applies only to LTE FDD and LTE TDD.

PUSCH_DTX_SINR_OPT_SWITCH: Indicates whether to enable SINR processing optimization upon PUSCH DTX detection. If this option is selected, the eNodeB does not process the SINRs measured for UEs in the DTX state when DTX is detected on the PUSCH. If this option is deselected, the eNodeB still processes the SINRs measured for UEs in the DTX state when DTX is detected on the PUSCH. This option applies only to LTE FDD and LTE TDD.

Disuse statement: EMTC_UL_MCS_SELECT_OPT_SWITCH: This option will be removed in later versions. Although the configuration interface in this version still supports synchronization and delivery of the setting of this option, the system no longer uses this option. Therefore, avoid using this option.

Parameter Relationship

-Configuration constraints:

  • For a given cell, the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO can be selected only when the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is selected.
  • For a given cell, the EMTC_RATE_ENH_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO can be selected only if the EMTC_SWITCH option of this parameter is selected.
  • The PRACH_FREQ_HOPPING_SW, PUSCH_FREQ_HOPPING_SW, or MPDCCH_PDSCH_FREQ_HOPPING_SW option of the EmtcFreqHoppingSwitch parameter in the CellEmtcAlgo MO can be selected only if the EMTC_SWITCH or EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in this CellEmtcAlgo MO is selected.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CELLEMTCALGO MO is deselected.
  • The VOLTE_REPETITION_OPT_SWITCH or VOLTE_CROSS_LAYER_OPT_SWITCH option of the EmtcEnhancedVolteAlgoSw parameter in the CellEmtcAlgo MO for a cell can be selected only when the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in this CellEmtcAlgo MO is selected and the EmtcVolteSupportSwitch parameter in this CellEmtcAlgo MO is set to ON.

Caution

Changing the setting of EMTC_ONLY_CELL_SWITCH of the EmtcAlgoSwitch parameter will trigger a cell restart.

Impact on Radio Network Performance

EMTC_SWITCH: If this option is selected, eMTC UEs are allowed to access the cell, decreasing RB resources available for LTE UEs. If this option is deselected, eMTC UEs are not allowed to access the cell. In accordance with 3GPP Release 13 specifications, when eMTC is enabled in an LTE cell, the SIB1-BR indicator must be broadcast in the MIB. Some LTE UEs on the live network may fail to parse the MIB, which has the following impacts: (1) These LTE UEs cannot correctly parse the system information of the LTE cell enabled with eMTC and therefore will fail to access this LTE cell. (2) These LTE UEs cannot correctly parse the system information during handovers from a cell with eMTC disabled to the cell with eMTC enabled, the handovers will fail. As a result, the statistics of handover-related counters deteriorate. You are advised to perform an interoperability test for legacy UE types on the live network before enabling eMTC.

IDLE_EDRX_SWITCH: If this option is selected, UEs consume less power for paging monitoring, prolonging UE battery lives but delaying paging responses. If this option is deselected, UEs do not reduce power consumed for paging monitoring.

G_VALUE_CFG_SWITCH: If this option is selected, value G is fixed to 1 for eMTC UEs, increasing the peak UE throughput but decreasing cell coverage. If this option is deselected, the eNodeB adapts value G for eMTC UEs, improving cell coverage but decreasing the peak UE throughput. If value G changes, eMTC UEs that have already accessed the network need to reconnect to the network.

SI_UPDATE_REL_UE_SWITCH: If this option is selected, when system information changes due to the changes in cell-level SRS resources allocated to eMTC UEs, the eNodeB proactively releases eMTC UEs that access the network before the system information change. If this option is deselected, the eNodeB does not proactively release eMTC UEs that access the network before system information changes, affecting PUCCH and SRS performance of other UEs.

EMTC_ONLY_CELL_SWITCH: When this option is selected, the cell enters the eMTC-only state, and common UEs cannot access this cell. When this option is deselected, the cell exits the eMTC-only state, and common UEs can access this cell.

MODE_A_UE_TA_SCHEDULING_SWITCH: When this option is selected, MPDCCH and PUSCH resource overhead increases, but uplink timing performance can be ensured. When this option is deselected, MPDCCH and PUSCH resource overhead decreases, but uplink timing performance deteriorates.

EMTC_UE_ACK_START_OFFSET_CFG: If this option is selected, the configuration of UE-level ACK resource start positions for eMTC UEs at coverage level 0 can increase the ACK resource usage and downlink throughput in multi-UE scenarios. If this option is deselected, the use of cell-level ACK resource start position cannot increase the ACK resource usage and therefore cannot increase downlink throughput in multi-UE scenarios.

DL_PERFORMANCE_ENHANCE_SWITCH: If this option is selected, the downlink throughput of eMTC UEs increases, but the performance of LTE UEs may deteriorate. If this option is deselected, there is no impact on eMTC or LTE UEs.

UL_PERFORMANCE_ENHANCE_SWITCH: If this option is selected, eMTC UEs can have more scheduling opportunities and therefore the uplink throughput and downlink throughput of these UEs increase, but the LTE performance deteriorates. If this option is deselected, there is no impact on network performance.

EMTC_CONG_CONTROL_OPT_SWITCH: If this option is selected, the eNodeB controls UE access based on the current air interface load of the cell, which further increases the RRC connection and E-RAB setup success rates of UEs. However, access experience of blocked UEs is affected.

MPDCCH_MORE_AVAIL_NB_SWITCH: If this option is selected for a large-bandwidth cell in the center of which a large number of eMTC UEs are located, more cell-center UEs are scheduled and the uplink and downlink throughput of eMTC UEs increases. However, the downlink data rates of LTE UEs decrease because of non-contiguous downlink RBs in common eMTC-LTE co-existence scenarios. If this option is deselected for a cell in the center of which a large number of eMTC UEs are located, fewer UEs can be scheduled because of limited MPDCCH resources. In addition, eMTC UEs that have accessed the cell will be released.

UL_MCS_SCHEDULING_OPT_SWITCH: If this option is selected, the uplink data rate of eMTC UEs located at the cell edge in the uplink increases. However, the throughput of the cell serving the UEs will decrease. Deselecting this option does not have this effect.

EMTC_UL_MCS_SELECT_OPT_SWITCH: If this option is selected, the eNodeB selects the corresponding MSC selection table based on the number of RBs scheduled in the eMTC PUSCH. This increases the uplink throughput of UEs. If this option is deselected, this impact is not produced.

EMTC_RATE_ENH_SWITCH: If this option is selected, the peak data rates of eMTC UEs in CE mode A increase. If this option is deselected, the network performance is not affected.

UL_AMC_OPT_SWITCH: If this option is selected, uplink scheduling is optimized for eMTC UEs at the cell edge or a medium distance from the cell center, which improves uplink throughput of these UEs; alternatively, the uplink peak cell throughput increases in extremely heavy traffic scenarios. If this option is deselected, network performance is not affected.

DL_AMC_OPT_SWITCH: If this option is selected, downlink scheduling is optimized for eMTC UEs at the cell edge or a medium distance from the cell center, which improves downlink throughput of these UEs; alternatively, the downlink peak cell throughput increases in extremely heavy traffic scenarios. If this option is deselected, network performance is not affected.

EMTC_CSI_RS_OPT_SWITCH: If this option is selected, eMTC UEs can be scheduled in CSI-RS subframes using an MCS with a reduced index, and eMTC UEs on the network do not need to be released in the event of CSI-RS subframe change, reducing air interface signaling and resource consumption. For eMTC UEs in the cell center or at the cell edge, the use of an MCS with a reduced index has little negative impact. More subframe resources can be allocated to these eMTC UEs, increasing the throughput of these UEs. For eMTC UEs at a medium distance from the cell center, the use of an MCS with a reduced index will cause the throughput of these UEs to slightly decrease. If this option is deselected, the eNodeB configures CSI-RS subframes as invalid subframes, in which eMTC UEs cannot be scheduled. In accordance with 3GPP specifications, eMTC UEs in the connected state are not required to monitor system information. If CSI-RS subframes change, the eNodeB needs to release eMTC UEs to ensure that eMTC UEs obtain the latest system information. This increases air interface signaling and resource consumption.

EMTC_PRACH_IRC_SWITCH: If this option is selected, the probability of false eMTC PRACH detection decreases, increasing the success rates of random access, handovers, resynchronization, and RRC connection reestablishments. However, the probability that UEs in weak coverage areas attempt to access the network increases, which affects the RRC connection setup success rate.

EMTC_MSG3_RETRANS_OPT_SWITCH: If this option is selected, it is less likely that resource allocation fails for eMTC Msg3 retransmission in scenarios of heavy eMTC traffic or poor eMTC channel quality, and therefore the scheduling success rate increases. However, if it is predicted that resource allocation for eMTC Msg3 retransmission would fail, Msg3 scheduling delay may increase for eMTC UEs. If this option is deselected, it is more likely that resource allocation fails for eMTC Msg3 retransmission due to radio resource insufficiency in scenarios of heavy eMTC traffic or poor eMTC channel quality, affecting eMTC services.

EMTC_SIG_MCS_ENH_SWITCH: If this option is selected, the MCS distribution of eMTC UEs improves; however, the service drop rate may slightly increase and the RRC connection reconfiguration success rate may slightly decrease. If this option is deselected, the MCS distribution of eMTC UEs deteriorates; however, the service drop rate decreases and the RRC connection reconfiguration success rate increases.

UL_PERCEIVED_AMC_SWITCH: If this option is selected, the uplink throughput of eMTC UEs increases, but the uplink IBLER also increases. If this option is deselected, network performance is not affected.

DL_AGILE_CQI_ADJ_SWITCH: If this option is selected, the downlink throughput increases for eMTC UEs when they initially access the cell or are handed over to the cell. If this option is deselected, network performance is not affected.

PUSCH_DTX_SINR_OPT_SWITCH: If this option is selected, the uplink throughput of eMTC UEs at the cell edge increases, but the MPDCCH resource consumption also increases. If this option is deselected, network performance is not affected.
