MML Command

MOD CELLEMTCALGO

Meaning

Indicates the period of triggering aperiodic CQI reporting by eMTC UEs. The period can be 5 ms, 10 ms, 20 ms, 40 ms, 80 ms, 160 ms, and infinite (that is, no aperiodic CQI reporting is triggered). This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a large value, aperiodic CQI reporting by eMTC UEs is seldom triggered, reducing uplink overhead used for aperiodic CQI reporting. If this parameter is set to a small value, aperiodic CQI reporting by eMTC UEs is frequently triggered, bringing downlink gains in some specified scenarios.
