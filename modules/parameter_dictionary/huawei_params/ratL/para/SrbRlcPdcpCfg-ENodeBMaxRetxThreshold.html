Parameter Name

NE

MML Command

MOD SRBRLCPDCPCFG

LST SRBRLCPDCPCFG
Meaning

Indicates the maximum number of RLC ARQ retransmissions for the eNodeB, which limits the maximum number of AM PDU retransmissions. When the number of RLC ARQ retransmissions reaches the parameter value, the eNodeB releases the UE. If you need to change the parameter value, contact Huawei technical support. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in stronger resistance to interference. However, a larger number of retransmissions results in a longer delay on transmitting signaling messages. A smaller value of this parameter results in a smaller number of retransmissions and a weaker resistance to interference.
