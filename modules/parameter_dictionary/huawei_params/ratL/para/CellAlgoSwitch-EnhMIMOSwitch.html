Meaning

Indicates whether to enable the algorithms related to enhanced MIMO.

TM9Switch: Indicates whether to allow UEs to enter TM9. UEs are allowed to enter TM9 only if this option is selected. This option applies only to LTE FDD and LTE TDD.

TM4TM9AdaptiveSwitch: Indicates whether to allow UEs meeting certain conditions to adaptively enter TM4 and TM9. UEs are allowed to adaptively enter TM4 and TM9 only if this option is selected. The TM4TM9AdaptiveSwitch option can be selected only after the TM9Switch option is selected. TM4 and TM9 adaptation does not work in cells established on LBBPc boards. This option applies only to LTE FDD.

Disuse statement: This option will be deleted in a later version according the N+2 principle. Although the configuration interface in this version supports delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

TM10Switch: Indicates whether to allow UEs to enter TM10. UEs are allowed to enter TM10 only if this option is selected. This option applies only to LTE FDD.

ChannelRecSwitch: Indicates whether to enable channel reconstruction. Channel reconstruction is enabled only if this option is selected. This option applies only to LTE FDD.

TM9HybridPrecodingSwitch: Indicates whether to enable the TM9 hybrid precoding algorithm in massive MIMO scenarios. If this option is selected, the TM9 hybrid precoding algorithm is enabled to improve the beamforming capability of closed-loop TM9 UEs. If this option is deselected, the TM9 hybrid precoding function is disabled, and the beamforming capability of closed-loop TM9 UEs remains unchanged. This option applies only to LTE TDD.

8T4PortTM9EnhanceSwitch: Indicates whether to enable 4-port TM9 enhancement in 8T scenarios. If this option is selected, the enhancement is enabled. The eNodeB sets appropriate precoded 4-port CSI-RS beams for UEs based on SRSs, allowing an 8-port beamforming capability for 4-port TM9 UEs. If this option is deselected, the enhancement is disabled. The eNodeB does not configure TM9 for 4-port TM9 UEs in 8T scenarios. This option applies only to LTE FDD.

Impact on Radio Network Performance

TM9Switch: The setting of this option determines the transmission modes that the eNodeB with multiple antennas can select for the UEs served by this eNodeB. When this option is selected and there are TM9 UEs on the network, the average cell throughput increases. When this option is deselected, network performance is not affected.

The TM4TM9AdaptiveSwitch option is valid when the TM9 switch is on, and its setting determines the transmission modes that the eNodeB with multiple antennas can select for TM9 UEs. The specific impact of this option on throughput and coverage performance is as follows:

(1) If this option is deselected, the transmission modes of all TM9 UEs in the cell are TM9. For its impact, see the description of TM9Switch.

(2) If this option is selected, the transmission modes of TM9 UEs of category 6, 7, 9, 10, 11, 12, or 13 in the cell can only be TM4 or TM9, and the peak rates of these TM9 UEs increase.

TM10Switch: The setting of this option determines the transmission modes that the eNodeB with multiple antennas can select for the UEs served by this eNodeB. When this option is selected and there are TM10 UEs on the network, the average cell throughput increases. When this option is deselected, network performance is not affected.

ChannelRecSwitch: When this option is selected, the downlink channel reconstruction accuracy increases, improving the experience and throughput performance of TM9 UEs. When this option is deselected, network performance is not affected. For a massive MIMO cell where DDB (32T32R) is enabled, enabling channel reconstruction decreases throughput when the number of UEs is small.

TM9HybridPrecodingSwitch: When this option is selected, the experience and throughput performance of TM9 UEs improve. When this option is deselected, network performance is not affected.

8T4portTM9EnhanceSwitch: When this option is selected, the experience and throughput of 4-port TM9 UEs improve in 8T scenarios. When this option is deselected, network performance is not affected.
