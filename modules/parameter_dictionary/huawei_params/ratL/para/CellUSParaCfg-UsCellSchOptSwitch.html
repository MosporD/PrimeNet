Us Cell Schedule Optimization Switch

MO CellUSParaCfg
Parameter ID UsCellSchOptSwitch
Parameter Name

Us Cell Schedule Optimization Switch
NE

MML Command

MOD CELLUSPARACFG

LST CELLUSPARACFG
Meaning

Indicates whether to enable scheduling optimization for cells where UEs running unlimited services reside.

UsCellPdcchFixSymSwitch: Indicates whether to fix the CFI for cells where UEs running unlimited services reside. If this option is selected, the CFI is fixed for cells where UEs running unlimited services reside. If this option is deselected, the CFI is set based on the setting of the PdcchSymNumSwitch parameter in the CellPdcchAlgo MO for cells where UEs running unlimited services reside. This option applies only to LTE TDD.

NsSchRestrictOptSwitch: Indicates whether to restrict uplink and downlink scheduling of normal UEs in dual-carrier scenarios. If this option is deselected, the eNodeB does not restrict uplink and downlink scheduling of normal UEs. If this option is selected, the eNodeB restricts uplink and downlink scheduling of normal UEs. This option applies only to LTE FDD and LTE TDD.

UsVolteSchMcsOptSwitch: Indicates whether to optimize scheduling and MCS selection for UEs running unlimited VoLTE services. If this option is deselected, the optimization does not take effect. If this option is selected, the eNodeB adjusts the UL grant volume and optimizes uplink and downlink MCS selection for such UEs. This option applies only to LTE FDD and LTE TDD.

UlUsVmimoSwitch: Indicates whether to perform resource pairing for UEs running unlimited services in the uplink, UEs running unlimited services in the downlink and sending feedback messages through uplink channels, and UEs running video services. If this option is selected, the resource pairing takes effect. If this option is deselected, the resource pairing is disabled. This option applies only to 8T cells. This option applies only to LTE TDD.

UsInterfOptSwitch: Indicates whether to enable the interference optimization function for UEs running unlimited services. This option determines how uplink frequency selective scheduling, uplink scheduler-controlled power, and IoT-based power control take effect for these UEs. When the UsInterfOptSwitch option is selected: (a) If the ULFSSAlgoswitch option is selected, uplink frequency-selective scheduling does not take effect for the cell when UEs running unlimited services are camping on the cell. (b) If the SchedulerCtrlPowerSwitch option is deselected, the scheduler-controlled power function does not take effect for the cell when UEs running unlimited services are camping on the cell. (c) If the PuschIoTCtrlSwitch option is selected, IoT-based power control takes effect only for UEs running normal services but not for UEs running unlimited services. When the UsInterfOptSwitch option is deselected, the algorithms specified by the ULFSSAlgoswitch, SchedulerCtrlPowerSwitch, and PuschIoTCtrlSwitch options are implemented same way in cells on which US UEs camp and other cells. The PuschIoTCtrlSwitch option applies only to LTE TDD. This option applies only to LTE FDD and LTE TDD.

CsfbNsSchRestrictOptSwitch: Indicates whether to prohibit the scheduling of NS UEs in CSFB scenarios. Scheduling of NS UEs is prohibited in CSFB scenarios only when this option is selected. This option applies only to LTE FDD and LTE TDD.

Disuse statement: NsSchRestrictOptSwitch: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Impact on Radio Network Performance

UsCellPdcchFixSymSwitch: If this option is selected, the CFI value of cells where UEs running unlimited services reside decreases, increasing downlink spectral efficiency and the number of uplink RBs available for such UEs. However, the access success rate, service drop rate, and VoLTE service quality of NS UEs are affected. If this option is deselected, network performance is not affected.

NsSchRestrictOptSwitch: If this option is selected, the uplink and downlink throughput of UEs running unlimited services increase. However, the uplink and downlink throughput of NS UEs decrease, the handover success rate decreases, and the service drop rate increases. If this option is deselected, network performance is not affected.

UsVolteSchMcsOptSwitch: If this option is selected, the uplink throughput of NS UEs decreases, but the uplink and downlink throughput of concurrent services of VoLTE UEs running unlimited services increases. If this option is deselected, network performance is not affected.

UlUsVmimoSwitch: If this option is selected, the number of uplink RBs available for UEs running unlimited services increases, raising the uplink throughput. However, the downlink throughput and throughput of UEs running unlimited video services decrease. If this option is deselected, the downlink throughput and throughput of UEs running unlimited video services are not affected.

UsInterfOptSwitch: This option takes effect only if the ULFSSAlgoswitch option is selected, or the SchedulerCtrlPowerSwitch option is deselected or the PuschIoTCtrlSwitch option is selected. When the UsInterfOptSwitch option is selected, the uplink throughput of US UEs increases, but uplink interference to neighboring cells of the cell serving US UEs also increases. If this option is deselected, network performance is not affected.

CsfbNsSchRestrictOptSwitch: If this option is selected, the uplink and downlink throughput of US UEs increases in CSFB drive test scenario. However, the uplink and downlink throughput of NS UEs decreases. In addition, for NS UEs, the call completion rate and handover success rate decrease and the service drop rate increases. If this option is deselected, the network performance is not affected.
