Meaning

Indicates the security mode for X2 self-setup when the local eNodeB receives the control-plane SCTP IP address, security tunnel IP address, and user-plane GTP IP address of the peer eNodeB at the same time during an X2 self-setup. If this parameter is set to CP_UP, security tunnels will be automatically set up for both the user plane and control plane. If this parameter is set to UP, a security tunnel will be automatically set up only for the user plane. This parameter takes effect only when an IPv4 security tunnel address is received but no IPv6 security tunnel address is received. In other scenarios, for example, only an IPv6 security tunnel address is received or both IPv4 and IPv6 security tunnel addresses are received, this parameter does not take effect.

Caution

If the X2SonSecMode parameter is set to CP_UP, both the IPSECSWITCH parameter in the USERPLANEHOST MO and the SIGIP1SECSWITCH parameter in the SCTPHOST MO must be set to ENABLE. If the X2SonSecMode parameter is set to UP, the IPSECSWITCH parameter in the USERPLANEHOST MO must be set to ENABLE and the SIGIP1SECSWITCH parameter in the SCTPHOST MO must be set to DISABLE. Otherwise, link interruptions may occur after subsequent X2 interface self-updates.
