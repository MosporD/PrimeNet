MOD CELLWTTXPARACFG

LST CELLWTTXPARACFG
Meaning

Indicates the PRB upper limit control mode, which can be tight control or loose control. When this parameter is set to TIGHT_CONTROL, the PRB resources for WBB and MBB UEs are subject to their respective uplink and downlink PRB resource upper limits. That is, the amounts of PRB resources allocated to WBB and MBB UEs must not exceed the upper limits even if there are remaining PRB resources in the cell. When this parameter is set to MBB_LOOSE_CONTROL: For MBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after WBB UEs are scheduled, the preset upper limit can be exceeded to allow MBB UEs to use the remaining PRB resources; for WBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to WBB_LOOSE_CONTROL: For WBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after MBB UEs are scheduled, the preset upper limit can be exceeded to allow WBB UEs to use the remaining PRB resources; for MBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to LOOSE_CONTROL, if the amount of PRB resources allocated to MBB or WBB UEs has reached the preset upper limit and there are remaining PRB resources, the limit can be exceeded to allow MBB or WBB UEs to use the remaining PRBs. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to TIGHT_CONTROL, the upper limits of PRB resources for both WBB and MBB UEs can be accurately controlled. This leads to a smaller increase in the interference to neighboring cells than when loose control mode is used. If this parameter is set to MBB_LOOSE_CONTROL, WBB_LOOSE_CONTROL, or LOOSE_CONTROL, UEs can use spare PRBs in the cell more flexibly. In this case, the increase in the interference to neighboring cell is greater than when tight control mode is used.
