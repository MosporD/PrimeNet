Parameter Name

PRACH Configuration Index
NE

MML Command

MOD RACHCFG

LST RACHCFG
Meaning

Indicates the PRACH configuration index of a cell. If cells are established on an LBBPc in a 4T4R scenario, the PRACH configuration indexes of these cells must be staggered in the time domain.

If a cell is an ultra-high-speed cell and HighSpeedR14Switch is set to ON, the value of this parameter takes effect only for the 3GPP-defined IE prach-ConfigIndex, but not for the 3GPP-defined IE prach-ConfigIndexHighSpeed-r14. For LTE FDD cells: If PreambleFmt is 0, prach-ConfigIndex is 3 and prach-ConfigIndexHighSpeed-r14 is 5. If PreambleFmt is 1, prach-ConfigIndex is 19 and prach-ConfigIndexHighSpeed-r14 is 21. If PreambleFmt is 2, prach-ConfigIndex is 35 and prach-ConfigIndexHighSpeed-r14 is 37. If PreambleFmt is 3, prach-ConfigIndex is 51 and prach-ConfigIndexHighSpeed-r14 is 53. For LTE TDD cells: If PreambleFmt is 0, prach-ConfigIndex is 3 and prach-ConfigIndexHighSpeed-r14 is 4. If PreambleFmt is 1, prach-ConfigIndex is 23 and prach-ConfigIndexHighSpeed-r14 is 24. If PreambleFmt is 2, prach-ConfigIndex is 33 and prach-ConfigIndexHighSpeed-r14 is 34. If PreambleFmt is 3, prach-ConfigIndex is 43 and prach-ConfigIndexHighSpeed-r14 is 44. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If value of this parameter corresponds to a longer PRACH period, the eNodeB can support less load, and fewer uplink resources are used. If the value of this parameter corresponds to a shorter PRACH period, the eNodeB can support more access load, and more uplink resources are used.
