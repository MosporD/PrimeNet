Meaning

Indicates whether to enable intelligent power-off of carriers.

If this parameter is set to ON and the cell meets specific conditions, intelligent power-off of carriers is performed and the eNodeB does not identify co-coverage cells automatically.

If this parameter is set to ON_CO_COV_AUTO_IDENT, coverage analysis will be started for the cell. The proportion of overlapping coverage between the capacity cell and basic cells and the proportion of coverage holes that may be generated after the capacity cell is shut down are analyzed based on inter-frequency MRs. The analysis results are used to determine whether to enable intelligent power-off of carriers.

If this parameter is set to ON_MULTI_CARRIER_HIER_SHUTDOWN, coverage analysis will be started for the cell. The total load of multiple carriers in the coverage area of the cell is calculated based on the co-coverage identification result, and the total load is then compared with the PRB thresholds (specified by DlPrbThd and UlPrbThd in the CellShutdown MO) and offsets (specified by DlPrbOffset and UlPrbOffset in the CellShutdown MO) set for the capacity cell to determine whether to trigger hierarchical intelligent power-off of multiple carriers.

If this parameter is set to OFF, intelligent power-off of carriers does not take effect.
