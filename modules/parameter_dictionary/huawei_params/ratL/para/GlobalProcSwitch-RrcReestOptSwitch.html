RRC Reestablishment Optimize Switch

RRC Reestablishment Optimize Switch
NE

MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether the eNodeB supports RRC connection reestablishment in enhanced scenarios. This parameter provides the following options:

PCI_CONFUSION_REEST_SWITCH: Indicates whether the eNodeB supports RRC connection reestablishment in PCI confusion scenarios. The eNodeB supports reestablishment in scenarios where PCIs of neighboring cells are the same only if this option is selected. This option applies only to LTE FDD and LTE TDD.

S1_HANDOVER_REEST_SWITCH: Indicates whether the eNodeB supports RRC connection reestablishment in S1-based handovers. The eNodeB supports reestablishment in S1-based handovers only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NO_CONTEXT_REEST_SWITCH: Indicates whether the eNodeB uses 3GPP specifications-compliant RRC connection reestablishment without UE context. If this option is selected, the eNodeB uses 3GPP specifications-compliant RRC connection reestablishment without UE context. If this option is deselected, the eNodeB uses common RRC connection reestablishment without UE context. This option applies only to LTE FDD and LTE TDD.

SEC_CMD_REEST_SWITCH: Indicates whether the eNodeB responds to RRC connection reestablishment requests from UEs when the security mode is activated. The eNodeB responds to the requests if this option is selected and rejects the requests if this option is deselected. This option applies only to LTE FDD and LTE TDD.

WITH_X2_NO_NCELL_REEST_SWITCH: Indicates whether the eNodeB supports RRC connection reestablishment when an X2 interface is configured between the source and target eNodeBs but the source and target cells are not configured as neighboring cells of each other. This type of RRC connection reestablishment is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

R15_NO_CONTEXT_REEST_SWITCH: Indicates whether the eNodeB supports 3GPP release 15-compliant RRC connection reestablishment without UE context. If this option is selected, 3GPP release 15-compliant RRC connection reestablishment without UE context is supported. If this option is deselected, 3GPP release 15-compliant RRC connection reestablishment without UE context is not supported. 3GPP release 15-compliant RRC connection reestablishment without UE context is supported in PCI confusion scenarios and is not supported when an X2 interface is configured between the source and target eNodeBs but the source and target cells are not configured as neighboring cells of each other. This option applies only to LTE FDD and LTE TDD.

REEST_ENHANCED_CHECK_SWITCH: Indicates whether the eNodeB supports enhanced check during RRC connection reestablishment without UE context. If this option is selected, the source eNodeB checks the short MAC-I during RRC connection reestablishment without UE context. If this option is deselected, the source eNodeB does not check the short MAC-I during RRC connection reestablishment without UE.

Impact on Radio Network Performance

PCI_CONFUSION_REEST_SWITCH: In PCI confusion scenarios, if this option is selected, the RRC connection reestablishment success rate increases. Deselecting this option has no impact on network performance.

S1_HANDOVER_REEST_SWITCH: For RRC connection reestablishment after S1-based handovers, if this option is selected, the RRC connection reestablishment success rate increases. Deselecting this option has no impact on network performance.

NO_CONTEXT_REEST_SWITCH: If this option is selected and RRC connection reestablishment without UE context involving devices provided by other vendors exists in the network, the RRC connection reestablishment success rate increases. Deselecting this option has no impact on network performance.

SEC_CMD_REEST_SWITCH: If there are RRC connection reestablishment requests and the security mode is activated, the reestablishment success rate and E-RAB setup success rate increase. Deselecting this option has no impact on network performance.

WITH_X2_NO_NCELL_REEST_SWITCH: If this option is selected, the success rate of RRC connection reestablishment increases when the following conditions are all met: 1. An RRC connection reestablishment without the UE context procedure occurs. 2. The source and target cells are not configured as neighboring cells of each other. 3. An X2 interface is configured between the source and target eNodeBs. Deselecting this option has no impact on network performance.

R15_NO_CONTEXT_REEST_SWITCH: If this option is selected and RRC connection reestablishment without UE context involving devices provided by other vendors exists in the network, the RRC connection reestablishment success rate increases. Deselecting this option has no impact on network performance.

REEST_ENHANCED_CHECK_SWITCH: Assume that some RRC connection reestablishment requests on the network contain invalid short MAC-I during RRC connection reestablishment without UE context. If this option is selected, the service drop rate decreases. If this option is deselected, UEs experience service drops.
