Meaning

Indicates the UE number offset used in inter-frequency idle mode offload by transferring loads to neighboring cells with which the local cell does not exchange load information. Assume that the MlbTriggerMode parameter is set to UE_NUMBER_ONLY or PRB_OR_UE_NUMBER. When the number of UL-sync UEs in the local cell is greater than or equal to the sum of the InterFreqIdleMlbUeNumThd and InterFIdleUeNumOffloadOfs parameter values, UEs in idle mode can be transferred to neighboring cells with which the local cell does not exchange load information. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

This parameter must be set if both load balancing to cells having load information exchange with the source cell and offloading to cells not having load information exchange with the source cell are enabled. A smaller value of this parameter results in a higher probability that UEs in idle mode are transferred to cells not having load information exchange with the source cell. A larger parameter value results in the opposite effect. Set this parameter based on the curve indicating the relationship between the average UE throughput and UE number on the live network and the operator-expected average throughput. A proper setting reduces the percentage of low-mobility UEs.
