Caution

If S1_SWITCH is changed to on from off and different S1 MOs are planned to use the same user-plane host IP address, the S1 MOs must be configured with the same user-plane endpoint group. In this case, if the corresponding user-plane peer is configured in another user-plane endpoint group, the user-plane peer must be removed from this user-plane endpoint group and then configured with the same user-plane endpoint group as the same user-plane host. If different user-plane endpoint groups are configured for these S1 MOs, the S1 user plane may fail to be set up, causing the E-RAB setup success rate to decrease.
