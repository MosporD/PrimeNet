Protocol Message Optimization Switch

MO GlobalProcSwitch
Parameter ID ProtocolMsgOptSwitch
Parameter Name

Protocol Message Optimization Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether to optimize protocol messages sent by the eNodeB. This parameter provides the following options:

RrcSetupOptSwitch: If this option is selected, optimization of RRCConnectionSetup messages is enabled. In this case, IEs with protocol-defined default values are no longer included in the RRCConnectionSetup messages. For details about the protocol-defined default setting, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

IucsRrcRecfgMcCombSwitch: If this option is selected, the eNodeB includes the radio resource configuration and measurement configuration for a UE in one RRCConnectionReconfiguration message during initial access. This option applies only to LTE FDD and LTE TDD.

RcrpRrcRecfgMcCombSwitch: If this option is selected, the eNodeB includes the radio resource configuration and measurement configuration for a UE in one RRCConnectionReconfiguration message during RRC connection reestablishment. The option will not take effect on the interaction of RRC connection reestablishment and other signaling procedures. This option applies only to LTE FDD and LTE TDD.

RrcRecfgMcOptSwitch: If this option is selected, the cell measurement configurations with the CIO of 0 (indicated by cellIndividualOffset) are no longer included in the measurement configurations delivered to UEs. This option applies only to LTE FDD and LTE TDD.

IdleCsfbRedirectOptSwitch: If this option is selected and the preferred CSFB policy is redirection, during CSFB for UEs in idle mode, the eNodeB no longer activates the security mode or performs RRC connection reconfiguration, but directly sends a redirection message. In accordance with the security requirements of 3GPP CR (R2-1714284), this option takes effect only for redirections to UTRAN cells. This option applies only to LTE FDD and LTE TDD.

UlNasBufferSwitch: If this option is selected, the eNodeB buffers uplink NAS messages sent by the UE before the UE-associated logical S1 connection is available and sends these messages after the UE-associated logical S1 connection is available. If this option is deselected, the eNodeB releases this UE after the procedures end. This option applies only to LTE FDD and LTE TDD.

IratMeasCfgTransSwitch: If this option is selected, the Handover Required message that the eNodeB sends to a BSC contains the IE IRAT Measurement Configuration. This option applies only to LTE FDD and LTE TDD.

GeranAnrMcOptSwitch: This option controls whether measurement configuration optimization takes effect when ANR with GERAN is enabled. If this option is deselected, the optimization does not take effect. That is, when an eNodeB delivers measurement configuration to UEs to perform CGI reading for ANR with GERAN, the carrierFreqs IE can contain multiple GERAN frequencies. If this option is selected, the optimization takes effect, and the carrierFreqs IE contains only one GERAN frequency. This option applies only to LTE FDD and LTE TDD.

SRVCCHoBasedUeCapSwitch: If this option is selected, the eNodeB determines whether to trigger an SRVCC based only on the UE SRVCC capability information, not the SRVCCOperationPossible IE that the MME sends to the eNodeB. If this option is deselected, the eNodeB determines whether to trigger an SRVCC based on the SRVCCOperationPossible IE that the MME sends to the eNodeB. This option applies only to LTE FDD and LTE TDD.

L2GPLMNChooseOptSwitch: This option specifies whether to enable target PLMN ID optimization for handovers to GERAN. If this option is selected, the eNodeB takes the NCL-defined PLMN IDs and includes them in the handover request messages or RIM request messages. If this option is deselected, the optimization is not activated. This option applies only to LTE FDD and LTE TDD.

HoInRrcRecfgMcCombSwitch: If this option is selected, after a UE is handed over to a cell, the cell delivers the radio resource configuration and measurement configuration in a single RRC Connection Reconfiguration message to the UE during the resource reconfiguration procedure. This option applies only to LTE FDD and LTE TDD.

UeCapEnquiryCombSwitch: If this option is selected and a UE sends an Attach Request message to an eNodeB during initial access, the eNodeB queries capabilities of the UE immediately after the RRC connection for the UE is established. This option does not apply to subsequent UE capability query induced by the CA extended frequency band combination query. If this option is deselected and a UE sends an Attach Request message to an eNodeB during initial access, the eNodeB does not query capabilities of the UE until the MME sends a UE context setup request to the eNodeB. If the UeCapbEnquirySecurityEnhSwitch option of the ProtocolMsgOptSwitch parameter in the GlobalProcSwitch MO is selected, combined UE capability information query does not take effect. This option applies only to LTE FDD and LTE TDD.

UeTraceOptSwitch: If this option is selected, the eNodeB does not handle the DEACTIVATE TRACE message sent by the MME or stop the UE tracing task in the eNodeB until the UE is released or handed over to a cell served by another eNodeB. This option applies only to LTE FDD and LTE TDD.

PaDistributeMechOptSwitch: If this option is selected, the PaPcOff parameter value is taken as the PA value in the RRCConnectionSetup or RRC Connection Reestablishment message. If this option is deselected, the PA value is set to -3 dB by default. This option applies only to LTE FDD and LTE TDD.

InactReSyncCompatSwitch: If this option is selected and the eNodeB determines that the UE inactivity timer expires and the resynchronization procedure is being performed, the eNodeB preferentially processes the resynchronization procedure and the timer restarts. If this option is deselected, the optimization does not take effect. That is, the UE is directly released when the UE inactivity timer expires. This option applies only to LTE FDD and LTE TDD.

VolteX2HoDelayOptSwitch: If this option is selected, when receiving a VoLTE UE handover complete message, the target eNodeB for an X2-based handover starts to send uplink data with QCI of 1. If this option is deselected, the target eNodeB for an X2-based handover starts to send uplink data with QCI of 1 after receiving an MME PATH SWITCH REQUEST ACKNOWLEDGE message. This option applies only to LTE FDD and LTE TDD.

UeUtranCapEnquiryOptSwitch: If this option is selected, the following are true: If the local cell is not configured with neighboring UTRAN frequencies, UEs' UTRAN capability queries cannot be triggered. If the local cell is configured with neighboring UTRAN frequencies, the UtranFastAnrSwitch and UtranEventAnrSwitch options of the ENodeBAlgoSwitch.AnrSwitch parameter are deselected, and the local cell is configured with neighboring UTRAN cells, UEs' UTRAN capability queries cannot be triggered. If this option is deselected, this optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

FreqRandomOptSwitch: If this option is selected, the eNodeB randomly selects a target frequency when there are multiple candidate frequencies with the same priority. If this option is deselected, this optimization function does not take effect. This option applies only to LTE FDD and LTE TDD.

MrMdtMeasOptSwitch: If this option is selected, measurement configurations related to MR and MDT are delivered separately. If this option is deselected, this optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

CellReselectionOptSwitch: If this option is selected, when the cell reselection configuration needs to be contained in an RRC release message, the eNodeB performs as follows: - If inter-RAT cell reselection is not configured in the eNodeB, the eNodeB does not determine inter-RAT operator-dedicated cell reselection frequency priorities. - If inter-RAT cell reselection is configured in the eNodeB, the eNodeB determines inter-RAT operator-dedicated cell reselection frequency priorities. If this option is deselected, the eNodeB always determines inter-RAT operator-dedicated cell reselection frequency priorities regardless of whether inter-RAT cell reselection is configured in the eNodeB. The RAT system mentioned above does not involve NR. The operator-dedicated cell reselection frequency priorities for NR frequencies are not controlled by this option. This option applies only to LTE FDD and LTE TDD.

X2GuGroupIdInfoOptSwitch: If this option is selected, the eNodeB does not include any GU Group Id dedicated to NB-IoT in the IE GU Group Id List in X2 setup request, X2 setup response, and base station configuration update messages when the MME has multiple GU Group Ids. (For details about the IE, see 3GPP TS 36.423.) If all GU Group Ids are dedicated to NB-IoT, the eNodeB can include the GU Group Ids dedicated to NB-IoT. If this option is deselected, the eNodeB can include the GU group Ids dedicated to NB-IoT in the IE Group Id List in X2 setup request, X2 setup response, and base station configuration update messages. This option applies only to LTE FDD and LTE TDD.

CaBandCombQueryOptSwitch: If this option is selected, the eNodeB does not need to identify UE capability information. The eNodeB queries the CA band combination capability of a UE by including frequencies supported by the eNodeB in the UECapabilityEnquiry message delivered to the UE. If this option is deselected, the optimization does not take effect. If this option is selected, the SupportNetReqCaComboSwitch option of the ProtocolSupportSwitch parameter in the GlobalProcSwitch MO must be selected. This option applies only to LTE FDD and LTE TDD.

HighPriAcsUeCellReselPriCtrlSw: If this option is selected, for a UE with the RRC connection setup request cause of HighPriorityAccess, the eNodeB delivers the dedicated cell-reselection priorities to the UE when the MME initiates to release the S1 connection and the eNodeB does not obtain the frequency capabilities of the UE. If this option is deselected, the eNodeB does not deliver the dedicated cell-reselection priorities when not obtaining the frequency capabilities of the UE. This option applies only to LTE FDD and LTE TDD.

NbMeasurementReportSwitch: If this option is selected, the eNodeB delivers NRSRP and NRSRQ measurement indications through SIB2. UEs that support measurement reporting will report measured NRSRP and NRSRQ during access. If this option is deselected, UEs will not report NRSRP or NRSRQ. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

MdtMeasRptOptSwitch: If this option is selected, the maximum number of cells contained in periodic measurement reports and the triggering quantity and reporting quantity of periodic measurement reports for MDT-related intra- and inter-frequency event M1 is configured through the CellMcPara MO. If this option is deselected, MDT-related intra- and inter-frequency event M1 cannot be configured through the CellMcPara MO. This option applies only to LTE FDD and LTE TDD.

NbCqiReportSwitch: If this option is selected, the eNodeB delivers CQI measurement indications through SIB2. UEs that support measurement reporting will report measured CQIs during network access. If this option is deselected, UEs will not report CQIs. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

UeCapbEnquirySecurityEnhSwitch: Indicates whether to enable security enhancement for UE capability query. If this option is selected, security enhancement for UE capability query is enabled. With this function enabled, the eNodeB can initiate a UE capability query procedure to a UE only after the Uu interface security mode is activated. If this option is deselected, security enhancement for UE capability query is disabled. If the eNodeB needs to query the UE capability information during initial access, it initiates a UE capability query procedure before the security mode is activated. If this option is selected, the UeCapEnquiryCombSwitch option of the ProtocolMsgOptSwitch parameter in the GlobalProcSwitch MO does not take effect. If the eNodeB needs to query the UE capability information during initial access, then the UuMsgSimulSendSwitch parameter in the GlobalProcSwitch MO does not take effect and the security mode activation, UE capability query, and reconfiguration procedures are processed in sequence. If the eNodeB needs to query the UE capability information during redirection-based CSFB for RRC_IDLE UEs, then the security mode activation, UE capability query, and RRC connection release procedures are processed in sequence. This option applies only to LTE FDD and LTE TDD.

UtranMeasQuanBothOptSwitch: Indicates whether to enable handovers to UTRAN based on only RSCP when UEs in compliance with 3GPP release 10 or later have compatibility issues and report only RSCP and the InterRatHoUtranB1MeasQuan parameter in the InterRatHoComm MO is set to BOTH. If this option is selected, handovers to UTRAN are triggered based on only RSCP. If this option is deselected, handovers to UTRAN are triggered based on both RSCP and Ec/No. This option applies only to LTE FDD and LTE TDD.

Disuse statement: IdleCsfbRedirectOptSwitch: In later versions, this eNodeB-level option will be replaced by the cell-level option IdleCsfbRedirectOptSwitch of the HoAllowedSwitch parameter in the CellAlgoSwitch MO. The configuration interface in this version supports synchronization and delivery of the settings of both the cell-level and eNodeB-level options. When operators deliver the settings, the eNodeB-level option takes effect on all cells within the eNodeB if the eNodeB-level option is selected. If the eNodeB-level option is deselected, the cell-level option takes effect on individual cells. Therefore, operators should set the cell-level option and then deselect the eNodeB-level option. Operators avoid using the eNodeB-level option from then on.

Caution

SRVCCHoBasedUeCapSwitch: Before selecting this option, ensure that the MME supports SRVCC. If there are inter-RAT handovers to the E-UTRAN, this option can be selected. If this option is selected, the eNodeB determines whether to allow a UE to initiate an SRVCC-based handover based on the UE's SRVCC capability. It is possible that the handover preparation fails because the SRVCC function is not registered for the UE in the EPC.

VolteX2HoDelayOptSwitch: It is recommended that the option be deselected if the S-GW changes in the X2-based handover.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

RrcSetupOptSwitch: The configuration of IEs in the RRCConnectionSetup messages is changed when the option setting is changed. If a UE cannot accept an RRCConnectionSetup message with fewer or more IEs, the UE access is abnormal. As a result, access-related KPIs deteriorate. It is recommended that this option be selected or deselected after interworking tests between the eNodeB and popular UEs on the network are conducted.

IucsRrcRecfgMcCombSwitch: If this option is selected, the number of messages sent by the eNodeB decreases, thereby reducing the impact of signaling messages on the network. However, this may lead to incompatibility issues.

RcrpRrcRecfgMcCombSwitch: If this option is selected, the number of messages sent by the eNodeB decreases, thereby reducing the impact of signaling messages on the network. However, this may lead to incompatibility issues.

RrcRecfgMcOptSwitch: If this option is selected, the size of the message decreases, thereby reducing the signaling overheads. However, this may lead to incompatibility issues.

IdleCsfbRedirectOptSwitch: If this option is selected, the number of signaling exchanges for CSFB decreases and the CSFB delay is also shortened.

UlNasBufferSwitch: If this option is selected and a UE sends an uplink NAS message to the eNodeB while the UE-associated logical S1 connection does not exist, the eNodeB saves this uplink NAS message in the buffer and then sends this message to the MME after the UE-associated logical S1 connection is set up. In this case, the MME may detect an exception. In addition, if too many uplink NAS messages need to be buffered, the system load increases. If this option is deselected, the eNodeB will release the UE.

IratMeasCfgTransSwitch: None

GeranAnrMcOptSwitch: If this option is deselected, the carrierFreqs IE can contain multiple GERAN frequencies when an eNodeB delivers measurement configurations to UEs to perform CGI reading for ANR with GERAN. UEs cannot determine the GERAN frequency to be measured, and CGI reading may fail. If this option is selected, the IE contains only one GERAN frequency, CGI reading failures caused by uncertain GERAN frequencies to be measured can be avoided. During CGI reading for ANR, the UE does not perform other measurements on this GERAN frequency.

SRVCCHoBasedUeCapSwitch: For inter-RAT incoming handovers to an E-UTRAN, if this option is selected, the success rate of SRVCC-based handovers increases. If this option is deselected, the success rate of SRVCC-based handovers decreases.

L2GPLMNChooseOptSwitch: Consider that both the LTE and GSM networks are configured in MOCN mode. If this option is selected, the success rate of EUTRAN-to-GERAN handover requests or RIM requests increases. If this option is deselected, the request may fail because of an incorrect target PLMN ID.

HoInRrcRecfgMcCombSwitch: If this option is selected, the number of messages sent by the eNodeB decreases, thereby reducing the impact of signaling messages on the network.

UeCapEnquiryCombSwitch: If this option is selected, the attach delay is shorter than that if this option is deselected.

UeTraceOptSwitch: None

PaDistributeMechOptSwitch: If this option is selected, the size of the message decreases, thereby reducing the signaling overheads.

InactReSyncCompatSwitch: If this option is selected, the UE inactivity timer expires, and the resynchronization procedure is being performed, then the eNodeB does not directly release the UE. In this case, the number of normal UE context releases and the number of normal E-RAB releases decrease, increasing the service drop rate. If this option is deselected, there is no impact.

VolteX2HoDelayOptSwitch: If this option is selected, uplink QCI-1 packets are transmitted in advance in X2-based handovers for VoLTE UEs. This shortens the duration of user plane interruption caused by the handover, thereby increasing the MOS for VoLTE services.

UeUtranCapEnquiryOptSwitch: When a local cell is not configured with neighboring UTRAN cells, the eNodeB does not query the UTRAN capabilities of UEs if this option is selected. This reduces signaling overheads.

CellReselectionOptSwitch: If this option is selected, contents in the RRC connection release messages are changed, affecting camping frequency selection after UEs are released. This increases the number of times the high dedicated priority was assigned to E-UTRA frequencies as indicated in an IMMCI IE sent from a high-load cell.

X2GuGroupIdInfoOptSwitch: If this option is selected, the load distribution of MMEs may change, the number of X2-based handover attempts may decrease, and the X2-based handover preparation success rate may increase.

CaBandCombQueryOptSwitch: If this option is selected, network resources consumed by signaling messages decrease after the function takes effect.

HighPriAcsUeCellReselPriCtrlSw: If this option is selected, the contents of signaling messages for RRC connection release are changed, affecting the frequency selection for UE camping after the release.

MdtMeasRptOptSwitch: If this option is selected, the configured maximum number of cells to be reported is less than the default maximum number, the number of neighboring cells contained in the MDT measurement reports decreases. As a result, the effect of MDT in network optimization may be weakened. If this option is deselected, the number of cells to be reported is fixed and is not configurable. This may cause UEs to report excessive redundant data.

UeCapbEnquirySecurityEnhSwitch: If this option is selected, the UuMsgSimulSendSwitch parameter in the GlobalProcSwitch MO is set to ON, and the eNodeB needs to query the UE capability information during initial access, then the security mode activation, UE capability query, and reconfiguration procedures are processed in sequence, prolonging the E-RAB setup duration. If this option is deselected, network performance is not affected.
