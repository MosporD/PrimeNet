Meaning

Indicates the CCE threshold of enhanced CFI adaptation.

This parameter is valid only when the PdcchSymNumSwitch parameter is set to ECFIADAPTIONON.

This parameter applies only to LTE FDD.

Caution

In medium- and high-load scenarios where the downlink RB usage is greater than 50% and average CFI is greater than 2, this parameter can be set to a smaller value to offer more obvious gains to the downlink.

It is recommended that the recommended value be used in medium- and low-load scenarios.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If this parameter is set to a value other than INF, the average CFI is smaller than when this parameter is set to INF and the downlink throughput increases. However, the number of CCE allocation failures increases and the uplink throughput decreases slightly.

In medium- and high-load scenarios (downlink RB usage is greater than 50% and the average CFI is greater than 2), a smaller value of this parameter leads to a smaller average CFI and higher downlink throughput.

In medium- and low-load scenarios, the impact of the parameter setting on performance does not vary much between the values other than INF.
