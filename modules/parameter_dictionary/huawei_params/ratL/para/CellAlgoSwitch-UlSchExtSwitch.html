Uplink Schedule Extended Switch

MO CellAlgoSwitch
Parameter ID UlSchExtSwitch
Parameter Name

Uplink Schedule Extended Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLALGOSWITCH

LST CELLALGOSWITCH
Meaning

Indicates whether to enable extended functions of uplink scheduling.

UlPacketLenAwareSchSw: Indicates whether to optimize uplink packet length awareness performance. Packet length awareness performance is optimized in the uplink only if this option is selected. This option applies only to LTE FDD and LTE TDD.

EnhExtQCITtiBundlingSwitch: Indicates whether to enable TTI bundling for push-to-talk (PTT) services with QCI 65, QCI 66, or enhanced extended QCIs. If this option is selected, the number of transmission opportunities increases within the air interface delay budget of PTT services, and uplink coverage is improved. This option applies only to LTE FDD and LTE TDD.

EnhExtQCISpsSchSwitch: Indicates whether to enable semi-persistent scheduling during talk spurts of PTT services with QCI 65, QCI 66, or enhanced extended QCIs. If this option is selected, semi-persistent scheduling is applied. If this option is deselected, dynamic scheduling is applied. This option applies only to LTE FDD and LTE TDD.

UlVoipRbRsvSwitch: Indicates whether to reserve PUSCH RBs for UEs running voice services in the uplink. PUSCH RBs are reserved for these UEs only if this option is selected. This option does not take effect if the uplink cell bandwidth is less than 5 MHz. This option applies only to LTE FDD and LTE TDD.

UlThpEnhSwitch: Indicates whether to enable the enhanced uplink throughput improvement function. For TDD cells: If this option is selected, the eNodeB calculates the PUCCH overhead based on the actual number of RBs occupied by the PUCCH when the number of UEs is small in the cell, which improves the uplink throughput. If this option is deselected, the eNodeB calculates the PUCCH overhead based on the current PUCCH resource configuration. For an NB-IoT cell: If this option is selected, the eNodeB searches for NPUSCH resources first in the frequency domain and then in the time domain for uplink scheduling. If this option is deselected, the eNodeB searches for NPUSCH resources first in the time domain and then in the frequency domain for uplink scheduling. This option applies only to LTE TDD and NB-IoT.

UlDataFitterRbCalcSwitch: Indicates whether to enable the algorithm of RB calculation based on uplink data volume matching. The algorithm takes effect only when this option and the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter are selected. When this algorithm takes effect, the number of required RBs is estimated based on the UE capability and the data volume to be scheduled. If this algorithm does not take effect, the number of required RBs is estimated based on the UE spectral efficiency and the data volume to be scheduled. This option applies only to LTE FDD.

UlFssOptForAttach: For TDD cells, this option indicates whether to perform uplink frequency selective scheduling based on the interference level during network access. If this option is selected, uplink frequency selective scheduling is performed based on the interference level during network access. If this option is deselected, uplink frequency selective scheduling is performed based on the SINR during network access. This option can be selected when the ULFSSAlgoSwitch option of the UlSchSwitch parameter is selected. For NB-IoT cells, this option indicates whether to optimize SINR estimation during network access in multi-carrier scenarios. If this option is selected, SINR estimation will be optimized during network access in multi-carrier scenarios. During RRC connection setup, the SINR of the assigned carrier is estimated based on the check result during network access and the channel measurement on the assigned carrier. If this option is deselected, the SINR is estimated based only on the channel measurement on the assigned carrier during RRC connection setup. This option applies only to LTE TDD and NB-IoT.

SrbProbeSchSwitch: For FDD and TDD cells, this option indicates whether to proactively schedule uplink signaling. If this option is selected, the eNodeB triggers proactive scheduling of uplink signaling for once when the eNodeB determines that data correctly scheduled in the downlink is control-plane signaling that requires uplink signaling feedback and does not receive the feedback within a specified period of time. For NB-IoT cells, this option indicates whether to perform retransmissions in proactive scheduling of status reports. If this option is selected, the eNodeB triggers HARQ retransmissions in proactive scheduling of status reports in the same way as it triggers HARQ retransmissions in normal data scheduling. If this option is deselected, the eNodeB does not perform HARQ retransmissions in proactive scheduling of status reports.

UlSchCtrlPwrUserSetOptSw: Indicates whether to enable the algorithm of selecting UE sets for the scheduler-controlled power function. This algorithm takes effect only when this option and the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter are selected. When this algorithm takes effect, pre-scheduled UEs of a lower priority are not included in the UE set selected by the scheduler. When this algorithm does not take effect, all pre-scheduled UEs are included in the UE set selected by the scheduler. This option applies only to LTE FDD and LTE TDD.

UlPttSchOptSwitch: Indicates whether to enable dynamic scheduling for PTT services with QCI 65, QCI 66, or enhanced extended QCIs. If this option is selected, for PTT service UEs that are scheduled dynamically in the uplink, the eNodeB triggers uplink dynamic scheduling when the scheduling interval is greater than the uplink voice scheduling interval threshold. This ensures timely uplink scheduling for voice service users in heavy traffic scenarios, preventing packet discarding upon the timeout of PDCP packet discarding timer. If this option is deselected, the eNodeB does not trigger uplink dynamic scheduling for PTT services in the preceding scenario. This option applies only to LTE FDD and LTE TDD.

UlPttDataSizeEstSwitch: Indicates whether to estimate uplink traffic volume for dynamic scheduling of PTT services with QCI 65, QCI 66, or enhanced extended QCIs. If this option is selected, the eNodeB estimates uplink traffic volume for dynamic scheduling of PTT services, reducing the packet delay and packet loss rate and increasing voice quality of PTT services. If this option is deselected, the function does not take effect. This option applies only to LTE FDD and LTE TDD.

EnhancedSchForSparseSwitch: Indicates whether ping packets are subject to the preallocation bandwidth percentage restriction and whether to change the method of calculating the number of RBs to be allocated for SR-based dynamic scheduling of ping packets. If this option is selected, ping packets are not subject to the preallocation bandwidth percentage restriction, and the number of RBs to be allocated for SR-based dynamic scheduling of ping packets is calculated based on the size of the ping packets. If this option is deselected, ping packets are subject to the preallocation bandwidth percentage restriction, and the number of RBs to be allocated for SR-based dynamic scheduling of ping packets is calculated based on the average spectral efficiency. For FDD, this option indicates only whether ping packets are subject to the preallocation bandwidth percentage restriction. This option applies only to LTE FDD and LTE TDD.

UlSigSrSchDateLenAdapt: Indicates whether to enable data amount adaptation for SR-based scheduling of uplink signaling. The adaptation is enabled only if this option is selected. When the adaptation is enabled, the eNodeB adaptively allocates the amount of to-be-scheduled data and the number of RBs based on the signaling identification result in SR-based scheduling of uplink signaling. This option applies only to LTE FDD and LTE TDD.

UlFssWindSearchDirRandSw: Indicates whether to randomize the search window direction in uplink frequency selective scheduling. The randomization is enabled only if this option is selected. When the randomization is enabled, the eNodeB randomly specifies a search window direction for a cell in frequency selective scheduling. This option applies only to LTE FDD.

UlCellCenterMCSOptSwitch: For FDD and TDD cells, this option indicates whether to optimize MCSs for uplink transmissions by UEs in the cell center. The optimization is enabled only if this option is selected. When the optimization is enabled, the throughput of UEs running full-buffer services in the cell center or with medium distances to the cell center increases. For NB-IoT cells, this option indicates whether to optimize MCS selection for uplink transmissions by UEs in the cell center. The optimization is enabled only if this option is selected. When the optimization is enabled, the number of repetitions in common data scheduling for UEs in the cell center decreases.

PuschSchEscPucchSwitch: If this option is selected, PUCCH interference coordination takes effect, reducing PUCCH interference. This option applies only to LTE TDD.

HarqMcsOptSwitch: If this option is selected, the instantaneous DMRS measurement value can be used to select an MCS index for retransmission. This option applies only to LTE TDD.

PreambleSchEnhSwitch: If this option is selected, the preamble scheduling and demodulation success rates increase. If this option is deselected, the preamble scheduling and demodulation success rates do not increase. If this option is deselected in NB-IoT scenarios, the maximum backoff index included in MAC PDU is 12. If this option is selected in NB-IoT scenarios, the maximum backoff index included in MAC PDU is 7. This accommodates certain UEs not supporting higher backoff indexes.

UlPAMCSwitch: For FDD and TDD cells, this option indicates whether to enable the algorithm of AMC maximizing the uplink perceived throughput. If this option is selected, the algorithm takes effect and AMC adjustment and MCS index selection are performed in an optimized way. For an NB-IoT cell, this option indicates whether to enable AMC optimization for uplink scheduling. If this option is selected, uplink scheduling is performed based on the rule that the spectral efficiency is preferentially ensured. If this option is deselected, uplink scheduling is performed based on the rule that the coverage performance is preferentially ensured.

UlSchRbAllocOptSw: For FDD and TDD cells, this option indicates whether to enable RB allocation optimization in uplink scheduling. If this option is selected, PUSCH scheduling considers UE power status when the uplink resource block (RB) usage is less than or equal to 30%. In addition, uplink power control considers SINR fluctuation. Meanwhile, the scheduling priority precision increases. If this option is deselected, PUSCH scheduling does not consider UE power status or RB usage. In addition, uplink power control does not consider SINR fluctuation. Meanwhile, the scheduling priority precision decreases. For an NB-IoT cell, this option indicates whether resources are allocated on a per carrier or cell basis when multi-carrier scheduling is enabled. If this option is selected, resources are allocated on a per carrier basis. If this option is deselected, resources are allocated on a per cell basis.

UlMultiClusterSwitch: Indicates whether to enable the uplink multi-cluster function. This function is enabled only when the option is selected. Uplink discontinuous resource allocation is supported when this function is enabled. This option applies only to LTE FDD.

SrPairingSwitch: Indicates whether UEs can be paired for MU-MIMO-based SR transmission. If this option is selected, UEs can be paired for MU-MIMO-based SR transmission. If this option is deselected, UEs cannot be paired for MU-MIMO-based SR transmission. This option applies only to LTE TDD.

UlDrbProactiveSchSwitch: Indicates whether to enable proactive uplink scheduling. If this option is selected, proactive uplink scheduling is triggered once when only CQI-only scheduling is performed in the uplink within a period after downlink data transmission. If this option is deselected, proactive uplink scheduling is not triggered. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

UlPacketLenAwareSchSw: If this option is deselected, packet length awareness performance optimization is disabled, and the network performance is not affected. If this option is selected, packet length awareness performance optimization is enabled in the uplink, and the uplink perceived throughput increases when the network has heavy or medium loads in the uplink.

EnhExtQCITtiBundlingSwitch: If this option is selected, cell edge coverage of the PUSCH is improved when the channel quality for UEs running PTT services is poor and the TX power is limited.

EnhExtQCISpsSchSwitch: If this option is selected, the eNodeB performs semi-persistent scheduling of PTT services with standardized QCIs 65 and 66, and PDCCH resource overhead and CQI reporting overhead decrease, which increases the PTT UE capacity in unicast mode. If this option is deselected, the eNodeB performs dynamic scheduling of PTT services with standardized QCIs 65 and 66, and PDCCH resource overhead increases. As a result, the PTT UE capacity decreases in unicast mode, but the QoS of PTT services improves.

UlVoipRbRsvSwitch: If this option is selected, the packet loss rate and RBLER decrease in the uplink for UEs running voice services. However, throughput decreases, uplink interference increases and the access performance as well as service drop performance deteriorate slightly for UEs running non-voice services in the uplink, and the average UE data rate decreases. If this option is deselected, network performance is not affected.

UlThpEnhSwitch: For TDD cells: If this option is deselected, network performance is not affected. If this option is selected, uplink throughput increases when the number of UEs involved in uplink scheduling is small. For an NB-IoT cell: If this option is deselected, network performance is not affected. If this option is selected, user-perceived uplink data rates increase.

UlDataFitterRbCalcSwitch: If this option is deselected, the algorithm of RB calculation based on uplink data volume matching does not take effect and network performance is not affected. If this option and the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter are selected, the algorithm takes effect. In this way, cell capacity and user-perceived throughput increase when the network is heavily loaded in the uplink.

UlFssOptForAttach: If this option is selected for a TDD cell, uplink frequency selective scheduling is performed based on the interference level during network access. As a result, more frequency selective scheduling gains are obtained and the RRC connection setup success rate and E-RAB setup success rate increase. If this option is deselected for a TDD cell, uplink frequency selective scheduling is performed based on the SINR during network access. The SINR measured during network access is limited and cannot reflect the signal quality of the entire channel bandwidth. As a result, the frequency selective scheduling gains are small. The RRC connection setup success rate and E-RAB setup success rate achieved when this option is deselected are lower than those achieved when this option is selected. If this option is selected for NB-IoT, SINR estimation is optimized during network access in multi-carrier scenarios, reducing the average RRC connection setup delay when downlink channel conditions are poor. If this option is deselected, network performance is not affected.

SrbProbeSchSwitch: For FDD and TDD cells, if this option is selected, uplink scheduling of control-plane signaling can be guaranteed. This helps ensure that the RRC connection setup success rate, E-RAB setup success rate, and service drop rate do not deteriorate. If this option is deselected, network performance is not affected. For NB-IoT cells, if this option is selected, the attach success rate in high interference or deep coverage scenarios can be increased. If this option is deselected, network performance is not affected.

UlSchCtrlPwrUserSetOptSw: If this option and the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter are selected, the resource consumption by pre-scheduled UEs not running services is reduced in scenarios where the uplink PRB usage is high, improving the cell throughput and user-perceived throughput. If this option is deselected, the function does not take effect, and the network performance is not affected.

UlPttSchOptSwitch: If this option is selected, an uplink dynamic scheduling attempt is triggered for PTT UEs adopting uplink dynamic scheduling when the scheduling interval is greater than the uplink scheduling interval threshold for voice services. This ensures timely uplink scheduling on PTT UEs even when missing detections of SRs occur, thereby avoiding packet loss caused by the expiration of the PDCP packet discarding timer.

UlPttDataSizeEstSwitch: If this option is selected, traffic volume estimation on dynamically scheduled uplink PTT services is enabled. As a result, the packet delay and packet loss rate of PTT services decrease, and PTT service quality improves. However, the number of RBs and that of CCEs consumed by UEs running PTT services increase, and therefore the cell throughput and UE throughput decrease.

EnhancedSchForSparseSwitch: If this option is selected, the impact on network performance varies depending on the scheduling types as follows: When smart preallocation is performed for sparse-packet services with large packet sizes, the amount of resources preallocated per TTI is not restricted, preventing fragmentation and reducing delay. When dynamic scheduling is performed for sparse-packet services, the fragmentation probability is reduced, and the scheduling delay decreases. If this option is deselected, network performance is not affected.

UlSigSrSchDateLenAdapt: If this option is selected, the number of RBs allocated for SR-based scheduling of uplink signaling is reduced, increasing cell throughput and reducing inter-cell interference. However, the downlink CCE usage increases slightly. If this option is deselected, network performance is not affected.

UlFssWindSearchDirRandSw: If this option is deselected, network performance is not affected. If this option is selected, the average uplink interference level decreases and the uplink cell throughput and UE throughput increase when SRS is disabled and there is no external interference. However, if there is external interference, uplink cell throughput and UE throughput may decrease.

UlCellCenterMCSOptSwitch: For FDD and TDD cells, if this option is deselected, network performance is not affected; if this option is selected, the throughput of UEs running full-buffer services in the cell center increases, and KPIs do not change significantly in common commercial networks. For NB-IoT cells, if this option is deselected, network performance is not affected; if this option is selected, the number of NPUSCH repetitions may decrease for UEs in the cell center, uplink interference may also decrease, the RRC connection setup success rate may increase, and the uplink IBLER may also increase.

PuschSchEscPucchSwitch: If this option is selected, PUCCH interference is reduced and PUCCH demodulation performance improves. However, if the PUSCH resource usage is greater than 30%, PUSCH interference increases. If this option is deselected, network performance is not affected.

HarqMcsOptSwitch: If this option is selected, the uplink bit error rate decreases, but the uplink PRB usage and CCE usage increase. If this option is deselected, network performance is not affected.

PreambleSchEnhSwitch: If this option is selected, the handover success rate increases. If this option is deselected, network performance is not affected.

UlPAMCSwitch: For FDD and TDD cells: (a) If this option is selected, user-perceived uplink throughput increases; however, the IBLER and RBLER also increase. (b) If this option is deselected, network performance is not affected. For an NB-IoT cell: (a) If this option is selected, the cell spectral efficiency and UE rates increase. (b) If this option is deselected, the cell spectral efficiency and UE rates may decrease.

UlSchRbAllocOptSw: If this option is selected, uplink UE throughput increases, and UE differentiation performance improves in weak-coverage scenarios when the cell is heavily loaded. However, uplink spectral efficiency decreases due to modifications in resources allocated for uplink scheduling. If this option is deselected, network performance is not affected.

UlMultiClusterSwitch: Uplink spectral efficiency and uplink peak throughput of UEs improve if this option is selected. If this option is deselected, network performance is not affected.

SrPairingSwitch: If this option is selected, uplink spectral efficiency of the cell increases but the radio connection rate and service drop rate are affected. If this option is deselected, uplink spectral efficiency of the cell decreases but the radio connection rate and service drop rate are not affected.

UlDrbProactiveSchSwitch: If this option is selected, uplink scheduling is performed more frequently to ensure that the RRC or E-RAB setup success rate and service drop rate do not deteriorate. However, more frequent uplink scheduling increases the uplink RB and CCE usage. If this option is deselected, network performance is not affected.
