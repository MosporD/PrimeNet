Meaning

Indicates whether to enable neighboring cell measurement algorithms.

NcellDmrsMeasSwitch: Indicates whether to enable DMRS measurement for neighboring cells. If this option is selected, DMRS measurement is enabled for neighboring cells. If this option is deselected, DMRS measurement is disabled for neighboring cells. When this option is selected, the setting of the SrsAutoNCellMeasSwitch parameter does not take effect. This option applies only to LTE FDD and NB-IoT.

NcellSrsTimeMeasSwitch: Indicates whether to enable time-domain measurement of SRSs from neighboring cells. If this option is selected, the eNodeB supports time-domain measurement of SRSs from neighboring cells. If this option is deselected, the eNodeB does not support time-domain measurement of SRSs from neighboring cells and supports only frequency-domain measurement of the SRSs. This option takes effect only if measurement of SRSs from neighboring cells is triggered. Such measurement can be triggered by UL CoMP or automatic measurement of SRSs from neighboring cells (controlled by the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO). This option applies only to LTE TDD.
