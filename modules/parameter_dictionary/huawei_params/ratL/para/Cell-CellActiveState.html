Parameter Relationship

-Configuration constraints:

  • If the values of the CellActiveState, FddTddInd, and DlBandWidth parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, and CELL_BW_N6, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 4.
  • If the values of the CellActiveState, FddTddInd, TxRxMode, and SubframeAssignment parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, 64T64R, and SA1, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 1, 2, or 3.
  • In a Cell MO, if CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_FDD, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R. If CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_TDD, TxRxMode must be set to 1T1R, 2T2R, 4T4R, or 8T8R, 64T64R, 32T32R.
  • In a Cell MO, if FddTddInd, CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_TDD, CELL_ACTIVE, BOOLEAN_TRUE, and SFN, respectively, TxRxMode must be set to 2T2R, 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to NORMAL_COMPRESSION, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to ENHANCED_COMPRESSION or TRIPLEX_COMPRESSION_10M, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 8T8R or 32T32R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and CELL_COMBINATION, respectively, TxRxMode must be set to 1T1R, 2T2R or 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and TWO_RRU_COMBINATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and DIGITAL_COMBINATION, respectively, TxRxMode must be set to 1T1R or 2T2R.
  • The BfAnt MO associated with the WeightNO parameter in the eUCellSectorEqm MO associated with a Cell MO must be configured if all of the following conditions are met: 1. The CellActiveState parameter in the Cell MO is set to CELL_ACTIVE. 2. The FddTddInd parameter in the Cell MO is set to CELL_TDD. 3. The TxRxMode parameter in the Cell MO is set to 8T8R. 4. The SectorSplitCell MO associated with the Cell MO is configured.
