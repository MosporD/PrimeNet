MML Command

SET ENODEBMTFLOWCONTROL

LST ENODEBMTFLOWCONTROL
Meaning

Indicates the CPU flow control level of SIG logs on the main control board. A larger value of this parameter indicates a higher CPU threshold for triggering the main control board to discard SIG data and a lower probability of discarding SIG logs due to flow control. 0 indicates that SIG log reporting is disabled on the main control board. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger non-zero value of this parameter leads to a larger CPU usage threshold for triggering flow control over SIG data on the main control board. In heavy-load scenarios, this affects boards' accommodating capabilities and traffic volume, and may lead to service KPI deterioration. If this parameter is set to 0, the network performance is not affected.
