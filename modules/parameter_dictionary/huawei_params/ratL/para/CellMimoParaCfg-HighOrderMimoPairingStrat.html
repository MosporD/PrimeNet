MOD CELLMIMOPARACFG

LST CELLMIMOPARACFG
Meaning

Indicates the UE pairing policy for high-order MIMO. If this parameter is set to DEFAULT, UEs using rank 3 or rank 4 can be directly paired. If this parameter is set to FALLBACK_SU, UEs using rank 3 or rank 4 cannot be paired and therefore can perform only SU-MIMO. If this parameter is set to FALLBACK_RANK, UEs using rank 3 or rank 4 can be paired on condition that their current rank is reduced to rank 2. If this parameter is set to ADAPTIVE, the eNodeB determines whether to restrict codebook subsets for UEs using rank 3 or rank 4 or reduce the current rank of these UEs to rank 2 for pairing based on UE-level characteristics. This parameter applies only to LTE FDD.

Impact on Radio Network Performance

If this parameter is set to DEFAULT, network performance is not affected. If this parameter is set to FALLBACK_SU, downlink user-perceived rates of 4R UEs increase. If this parameter is set to FALLBACK_RANK, downlink user-perceived rates of 2R UEs increase. If this parameter is set to ADAPTIVE, downlink cell throughput increases.
