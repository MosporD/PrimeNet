NB-IoT Cell Algorithm Switch

Parameter Name

NB-IoT Cell Algorithm Switch
NE

MML Command

MOD CELLALGOSWITCH

LST CELLALGOSWITCH
Meaning

Indicates the NB-IoT cell-level algorithm switches.

IDLE_EDRX_SWITCH: Indicates whether eDRX paging is supported. eDRX paging can be delivered in the local cell only when this option is selected. This option applies only to NB-IoT.

COVERAGE_EXTENSION_SWITCH: Indicates whether to enable the NB-IoT cell coverage extension function. When this option is selected, the NB-IoT cell coverage extension function is supported, and the eNodeB supports coverage extension through scheduling. When this option is deselected, common coverage is supported, which means that coverage extension cannot be achieved. This option applies only to NB-IoT.

MULTITONE_SWITCH: Indicates whether to enable the NB-IoT Multi-tone feature. For uplink data transmission, when this option is selected, an eNodeB can allocate multiple subcarriers at a time to a multi-tone-capable UE. When this option is deselected, the Multi-tone feature is not supported, and the eNodeB allocates only one subcarrier at a time to a UE for uplink data transmission. This option applies only to NB-IoT.

SI_OFFSET_ADAPTIVE_CFG_SWITCH: Indicates whether to enable the adaptive configuration of the NB-IoT system information (SI) frame offset. If this option is selected, adaptive configuration takes effect for NB-IoT SI frame offset. If this option is deselected, adaptive configuration does not take effect for NB-IoT SI frame offset, and the NB-IoT SI frame offset is fixed and cannot be adaptively configured. This option applies only to NB-IoT.

DUAL_HARQ_SWITCH: Indicates whether the eNodeB supports dual-HARQ-process scheduling. If this option is selected, the eNodeB supports dual-HARQ-process scheduling and performs dual-HARQ-process scheduling for dual-HARQ-capable UEs. If this option is deselected, the eNodeB supports only single-HARQ-process scheduling. This option applies only to NB-IoT.

ADAPTIVE_STEP_SWITCH: Indicates whether to enable adaptive step adjustment in the NB-IoT cell. If this option is selected, the eNodeB uses a large step to adjust AMC to accelerate IBLER convergence when it determines that large-step adjustment is required based on HARQ feedback from the UE. If this option is deselected, the eNodeB uses a fixed step to adjust AMC. This option applies only to NB-IoT.

RETRIEVE_UE_INFO_SWITCH: Indicates whether the eNodeB needs to obtain UE information from the UE and MME in control plane CIoT EPS optimization. In control plane CIoT EPS optimization, the eNodeB needs to obtain UE capability information from the UE and requests the UE information from the MME through the Retrieve UE Information message based on the S-TMSI contained in Msg3 only if this option is selected. This option applies only to NB-IoT.

TBS_EXTENSION_SWITCH: Indicates whether to allow for scheduling using an extended TBS. If this option is selected, the eNodeB can use the extended TBS to schedule NB2 UEs that comply with 3GPP Release 14. If this option is deselected, the eNodeB schedules UEs using non-extended TBSs as specified in 3GPP Release 13. This option applies only to NB-IoT.

DL_SCHEDULING_OPT_SWITCH: Indicates whether to enable downlink scheduling optimization. NB-IoT cells support downlink signaling MCS index decrease and downlink retransmission mechanism optimization only if this option is selected. This option applies only to NB-IoT.

RU_ADAPTIVE_SWITCH: Indicates whether to enable the RU adaptation algorithm for uplink resource scheduling. This option applies only to NB-IoT.

UCI_REP_NUM_ADAPTIVE_SWITCH: Indicates whether to enable the UCI repetition count adaptation algorithm to adjust the number of ACK or NACK repetitions. This option applies only to NB-IoT.

SERVICE_BASED_QOS_MGMT_SWITCH: Indicates whether to enable service-based QoS management. If this option is selected, NB-IoT UEs allocated QCIs can be scheduled based on QoS in the cell. If this option is deselected, NB-IoT UEs cannot be scheduled based on QoS in the cell. This option applies only to NB-IoT.

CP_RRC_CONN_REESTABLISHMENT_SW: Indicates whether to allow UEs to initiate RRC connection reestablishment in control plane CIoT EPS optimization mode in the cell. UEs are allowed to initiate RRC connection reestablishment in control plane CIoT EPS optimization mode only if this option is selected. This option applies only to NB-IoT.

HIGH_SPEED_MOBILITY_SWITCH: Indicates whether to support high-speed mobility. If this option is selected, the eNodeB improves the performance of high-speed UEs by mitigating the Doppler effect. If this option is deselected, the eNodeB does not perform any differentiated processing for high-speed UEs. This option applies only to NB-IoT.

MULTI_CARRIER_ENH_SWITCH: Indicates whether to enable the multi-carrier enhancement function for NB-IoT. If this option is selected, multi-carrier enhancement is supported, and paging and random access can be performed for UEs on non-anchor carriers. If this option is deselected, multi-carrier enhancement is not supported. In this case, paging and random access can be performed for UEs only on anchor carriers. This option applies only to NB-IoT.

ADAPTIVE_PREAMBLE_TRANS_MAX_SW: Indicates whether to adaptively adjust the maximum number of preamble transmissions. If this option is selected, the eNodeB adaptively adjusts the maximum number of preamble transmissions based on the network load. If this option is deselected, the eNodeB does not adaptively adjust the maximum number of preamble transmissions. This option applies only to NB-IoT.

PWR_CLASS_6_PWR_OFS_SCH_OPT_SW: Indicates whether to allow power offset configuration for UEs of power class 6 at cell selection or reselection and whether to optimize the downlink scheduling of UEs of power class 6. The configuration is allowed and the scheduling is optimized only if this option is selected. This option applies only to NB-IoT.

NPDCCH_OFFSET_ADAPTIVE_SWITCH: Indicates whether to enable NPDCCH offset adaptation. If this option is selected, the NPDCCH offset of the UE-specific search space is adaptively configured. If this option is deselected, it is specified by the PdcchOffset parameter in the PrbPdcchCeConfig MO. This option applies only to NB-IoT.

DL_INTRF_RANDOMIZATION_SWITCH: Indicates whether to use interference randomization for NPDSCH and NPDCCH. This option applies only to NB-IoT.

100KM_CELL_RADIUS_SWITCH: Indicates whether to support cell coverage with a radius of 100 km. If this option is selected, cell coverage with a radius of 100 km is supported. If this option is deselected, cell coverage with a radius of 35 km is supported. This option applies only to NB-IoT.

Caution

MULTI_CARRIER_ENH_SWITCH: Changing the setting of this option will cause the NB-IoT cell to reset. Before setting this option, check whether the MME supports multi-carrier paging in compliance with 3GPP R14. If the MME does not support multi-carrier paging, do not select this option. If the MME does not support multi-carrier paging but this option is selected, UEs cannot receive paging messages.

CP_RRC_CONN_REESTABLISHMENT_SW: If the MME does not support RRC connection reestablishment in control plane CIoT EPS optimization mode, RRC connection reestablishment in control plane CIoT EPS optimization mode will fail. If the source eNodeB does not support RRC connection reestablishment in control plane CIoT EPS optimization mode, it does not forward the downlink data that has not been transmitted to the UE.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

IDLE_EDRX_SWITCH: If this option is deselected, the eNodeB does not deliver eDRX paging. If eDRX has been enabled on any UEs in the cell, paging failure occurs.

COVERAGE_EXTENSION_SWITCH: If this option is selected, UEs can normally perform services in the 20 dB coverage enhancement scenario. If this option is deselected, the service drop rate of UEs increases or UEs may not be able to perform services in poor coverage scenarios.

MULTITONE_SWITCH: If this option is selected, in areas with favorable coverage, the single-UE peak uplink data rate of a multi-tone-capable UE increases significantly, the transmission delay decreases accordingly, and the UE power consumption decreases. Deselecting this option leads to the opposite effects.

DL_SCHEDULING_OPT_SWITCH: If this option is selected in downlink co-channel interference scenarios, the downlink signaling or data demodulation success rate of NB-IoT UEs increases. If there is no downlink co-channel interference, more cell resources are consumed, decreasing the cell capacity.

DUAL_HARQ_SWITCH: When this option is selected, the eNodeB can use dual-HARQ-process scheduling for dual-HARQ-capable UEs. Dual-HARQ-process scheduling delivers higher peak uplink and downlink rates for these UEs than single-HARQ-process scheduling. When this option is deselected, the eNodeB can use only single-HARQ-process scheduling, the peak uplink and downlink rates of UEs are lower than when dual-HARQ-process scheduling is used.

ADAPTIVE_STEP_SWITCH: When this option is selected, large steps can be used to adjust MCSs to accelerate IBLER convergence, therefore increasing downlink UE throughput. When this option is deselected, a fixed step is used and the IBLER convergence is slow for UEs requiring large-step adjustment, affecting downlink throughput of these UEs.

RETRIEVE_UE_INFO_SWITCH: When this option is selected, the eNodeB sends a Retrieve UE Information message to the core network to obtain UE information in control plane CIoT EPS optimization, increasing the data transmission delay during access due to the related message exchange. If the MME does not support UE information retrieval, access-related counter values deteriorate because message responses time out over the S1 interface. When this option is deselected, the eNodeB does not send a Retrieve UE Information message to the core network to obtain UE information. As a result, the UE capability cannot be fully utilized due to the failure to obtain UE capability information.

TBS_EXTENSION_SWITCH: When this option is selected, the eNodeB can use an extended TBS to schedule NB2 UEs that comply with 3GPP Release 14. As a result, the peak uplink and downlink rates of these UEs significantly increase and the transmission delay decreases. When this option is deselected, the eNodeB uses non-extended TBSs to schedule UEs as specified in 3GPP Release 13. As a result, the peak uplink and downlink rates of NB2 UEs significantly decrease, the transmission delay increases, and UE power consumption also increases.

RU_ADAPTIVE_SWITCH: When this option is selected, the eNodeB can increase the single-user peak uplink throughput of UEs that support only 3GPP Release 13.

UCI_REP_NUM_ADAPTIVE_SWITCH: When this option is selected, the eNodeB adjusts the number of UCI repetitions for UEs that are admitted in the cell center in accordance with ECL1 or ECL2 in interference-limited scenarios, reducing power consumption of these UEs and interference to neighboring cells. When this option is deselected, the number of UCI repetitions of cell-center UEs is large and the UE TX power is high, and therefore interference to neighboring cells is high.

SERVICE_BASED_QOS_MGMT_SWITCH: If this option is selected, the power consumption of UEs that have high requirements for power consumption is significantly reduced using the DRX function, and the coverage performance is improved for UEs under poor coverage.

CP_RRC_CONN_REESTABLISHMENT_SW: If this option is selected, a moving UE can initiate RRC connection reestablishment in control plane CIoT EPS optimization mode in the cell and the source eNodeB can send the downlink data (that has not been transmitted to the UE) back to the MME, which then forwards the data to the target eNodeB. This improves data transmission continuity for the UE and reduces the number of data retransmissions. If this option is deselected, UEs cannot initiate RRC connection reestablishment in control plane CIoT EPS optimization mode in the cell. As a result, data transmission is interrupted for moving UEs and the number of data retransmissions increases.

HIGH_SPEED_MOBILITY_SWITCH: If this option is selected, the eNodeB mitigates the uplink channel Doppler effect for high-speed UEs, improving network access performance and increasing uplink throughput in high-speed mobility scenarios. If this option is deselected, the eNodeB does not mitigate the uplink channel Doppler effect for high-speed UEs, causing the network access performance of these UEs to deteriorate and decreasing the uplink throughput of these UEs.

MULTI_CARRIER_ENH_SWITCH: If this option is selected, non-anchor carriers support paging and random access, improving cell paging and access capacity. However, interference between carriers increases, the IBLER increases, and the cell throughput decreases.

ADAPTIVE_PREAMBLE_TRANS_MAX_SW: If this option is selected, the maximum number of preamble transmissions is dynamically adjusted based on the network load. When the network load is high, the maximum number of preamble transmissions is changed to the minimum value among the GUI setting of the PreambleTransMax parameter, the MaxNumPreambleAttempt parameter setting for coverage level 0, and the MaxNumPreambleAttempt parameter setting for coverage level 1. The coverage level is not increased for UEs, which increases the access success rate. When the network load is low, the maximum number of preamble transmissions is restored to the value of the PreambleTransMax parameter in the RACHCfg MO.

PWR_CLASS_6_PWR_OFS_SCH_OPT_SW: If this option is selected, cell selection and reselection parameters and neighboring frequency parameters can be set for UEs of power class 6 to enable these UEs to camp on cells with better signal quality, and the number of downlink repetitions can be adjusted for UEs of power class 6 to reduce downlink resource wastage by these UEs.

NPDCCH_OFFSET_ADAPTIVE_SWITCH: If this option is selected, the cell throughput increases, but the BER slightly increases in the access procedure. When multiple UEs (for example, more than five UEs) initiate access simultaneously, the RRC connection setup success rate decreases. If this option is deselected, the cell throughput decreases.

DL_INTRF_RANDOMIZATION_SWITCH: If this option is selected, the interference resistance performance of NPDCCH and NPDSCH improves, increasing the downlink throughput of UEs.

100KM_CELL_RADIUS_SWITCH: If this option is selected, the random access success rate decreases. If this option is deselected, the random access success rate increases.
