Meaning

Indicates the length of the uplink time alignment timer for UEs in the cell. A UE is considered not time-aligned in the uplink if the timer expires. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

If TimingAdvCmdOptSwitch is off, it is recommended that TimeAlignmentTimer be set to SF1920 in low-speed cells or SF500 in high- or ultra-high-speed cells. If TimingAdvCmdOptSwitch is on, it is recommended that TimeAlignmentTimer be set to SF10240.

If TimingAdvCmdOptSwitch is off, the TimeAlignmentTimer value determines the valid value of LongDrxCycle. To ensure that the valid value of LongDrxCycle is greater than or equal to SF80, it is recommended that TimeAlignmentTimer be set to INFINITY. If TimingAdvCmdOptSwitch is on, the TimeAlignmentTimer value does not determine the valid value of LongDrxCycle. However, to avoid an increase in the uplink out-of-synchronization probability of UEs in DRX mode, it is recommended that TimeAlignmentTimer be set to SF5120 or larger and LongDrxCycle be set to SF320 or smaller.

Impact on Radio Network Performance

If TimingAdvCmdOptSwitch is off, a smaller value of TimeAlignmentTimer leads to more uplink timing advance commands delivered over the air interface and more radio resources occupied, but it results in more prompt tracking and correction of uplink timing errors and in particular better uplink time alignment performance for high-mobility UEs. A larger value of TimeAlignmentTimer leads to the opposite effects.

If TimingAdvCmdOptSwitch is on, it is recommended that TimeAlignmentTimer be set to SF10240. A smaller value of TimeAlignmentTimer, such as SF5120, leads to a higher probability that UEs in DRX mode become out-of-synchronization in the uplink.
