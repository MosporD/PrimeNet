Meaning

Indicates whether to enable location service (LCS) functions.

OtdoaSwitch: OTDOA-based positioning is enabled when either this option or the NB_OTDOA_SWITCH option of the CellLcsSwitch parameter in the CELLLCSCFG MO is selected, and is disabled when both options are deselected. This option applies only to LTE FDD and LTE TDD.

EcidInterFreqMeasSwitch: If this option is selected, ECID-based RSRP and RSRQ measurement for inter-frequency neighboring cells is enabled. If this option is deselected, ECID-based RSRP and RSRQ measurement for inter-frequency neighboring cells is disabled. This option applies only to LTE FDD and LTE TDD.

OTDOAInterFreqRSTDMeasSwitch: If this option is selected, OTDOA-based inter-frequency RSTD measurement is enabled. If this option is deselected, OTDOA-based inter-frequency RSTD measurement is disabled. This option applies only to LTE FDD and LTE TDD.

EmtcEcidSwitch: If this option is selected, ECID-based positioning is enabled for eMTC UEs. If this option is disabled, ECID-based positioning is disabled for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

EcidOptSwitch: If this option is selected, ECID-based positioning optimization is enabled, increasing measurement accuracy for UE positioning. If this option is deselected, ECID-based positioning optimization is disabled. This option applies only to LTE TDD.

Impact on Radio Network Performance

OtdoaSwitch: If this option is selected, positioning reference signals (PRSs) will be sent over the air interface for OTDOA-based positioning. A shorter PRS period will lead to a larger number of consecutive PRS subframes and a larger amount of radio resources occupied. If this option is deselected, fewer air interface resources are consumed.

EcidInterFreqMeasSwitch: If this option is selected, the eNodeB starts RSRP and RSRQ measurement for inter-frequency neighboring cells, which results in an increase in S1 and gap overhead. The amount of the overhead has a positive correlation with the number of reported messages. If this option is deselected, the measurement is disabled and therefore S1 and gap overheads do not increase.

OTDOAInterFreqRSTDMeasSwitch: If this option is selected, inter-frequency RSTD measurement is enabled. The eNodeB allocates appropriate measurement gap resources to UEs. A larger number of RSTD measurements will require more gaps. If this option is deselected, inter-frequency RSTD measurement is disabled. The eNodeB does not allocate appropriate gap resources to UEs, and therefore gap overhead does not increase.

EmtcEcidSwitch: If this option is selected, the eNodeB triggers ECID-based positioning upon receiving ECID-based positioning requests from eMTC UEs, consuming more air interface resources. A large number of eMTC UEs for which ECID-based positioning is performed leads to a high ratio of consumed air interface resources. If this option is deselected, ECID-based positioning is disabled for eMTC UEs.

EcidOptSwitch: If this option is selected, the eNodeB instructs UEs to adopt a new measurement reporting method, increasing measurement accuracy for UE positioning but consuming air interface resources. If this option is deselected, the eNodeB disables ECID-based positioning optimization, and network performance is not affected.
