Meaning

Indicates whether to prioritize frequencies in a multi-frequency network.

FixedMeasObjIDSwitch: Indicates whether the eNodeB maps each neighboring frequency to a MeasObjectID based on the frequency measurement priorities. If this option is selected, the eNodeB maps each neighboring frequency to a corresponding MeasObjectID based on the frequency measurement priorities. A higher-priority frequency is mapped to a smaller MeasObjectID. If this option is deselected, the eNodeB does not map neighboring frequencies to MeasObjectIDs based on the frequency measurement priorities. This option applies only to LTE FDD and LTE TDD.

VoipMeasFreqPriSwitch: Indicates whether the frequency priorities specified by the VoipPriority parameter take effect for coverage-based handovers of VoIP UEs. If this option is selected, the eNodeB includes only intra-RAT neighboring frequencies with the highest priority based on the settings of the VoipPriority parameter when the eNodeB delivers measurement configurations to VoIP UEs for coverage-based inter-frequency handovers. If this option is deselected, the eNodeB does not consider the settings of the VoipPriority parameter when delivering measurement configurations to VoIP UEs for coverage-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

PsMeasFreqPriSwitch: Indicates whether frequency priorities specified by the PsPriority parameter take effect for coverage-based handovers of UEs running data services. If this option is selected, the eNodeB includes only intra-RAT neighboring frequencies with the highest priority based on the settings of the PsPriority parameter when the eNodeB delivers measurement configurations to UEs running data services for coverage-based inter-frequency handovers. If this option is deselected, the eNodeB does not consider the settings of the PsPriority parameter when delivering measurement configurations to UEs running data services for coverage-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

FixedMeasObjIDSwitch: If this option is selected, UEs that preferentially measure neighboring frequencies with small MeasObjectIDs are more likely to measure neighboring frequencies with high priorities, and therefore these UEs can be preferentially handed over to cells on these neighboring frequencies.

VoipMeasFreqPriSwitch: If this option is selected, the frequencies measured by VoIP UEs for coverage-based inter-frequency handovers are fixed, and these UEs can be preferentially handed over to high-priority frequencies. This mechanism applies when operators require UEs to be handed over to low frequencies with good coverage, so that the number of handovers can be reduced during continuous UE movement and the voice quality can be improved. If the bandwidth of a low frequency is small, data service rates of VoIP UEs decrease.

PsMeasFreqPriSwitch: If this option is selected, the frequencies measured by UEs running data services for coverage-based inter-frequency handovers are fixed, and these UEs can be preferentially handed over to high-priority frequencies. This mechanism applies when operators require UEs to be handed over to low frequencies with good coverage, so that the number of handovers can be reduced during continuous UE movement. If this option is deselected, the measurement target frequency cannot be specified for coverage-based inter-frequency handovers of UEs running data services. In this case, multiple handovers may occur during UE movement.
