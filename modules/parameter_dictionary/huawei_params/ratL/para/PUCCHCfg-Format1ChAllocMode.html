Meaning

Indicates the mode for allocating PUCCH format 1/1a/1b code channel resources. The setting of this parameter takes effect only when the DeltaShift parameter is set to DS1_DELTA_SHIFT(ds1). If the Format1ChAllocMode parameter is set to FIXEDMODE(Fixed Mode), consecutive PUCCH format 1/1a/1b code channel resources are always allocated. If the Format1ChAllocMode parameter is set to RANDOMMODE(Random Mode), PUCCH format 1/1a/1b code channel resources are randomly allocated. If this parameter is set to OPTISELECTMODE(OPTISELECTMODE), PUCCH format 1 code channel resources are allocated based on the optimized selection mode. If this parameter is set to RBSAVINGMODE(RB Saving Mode), PUCCH format 1/1a/1b code channel resources are allocated in such a way where an RB is allocated to as many UEs as possible to save RBs. The RBSAVINGMODE value takes effect only in LTE FDD. When this parameter is set to RBSAVINGMODE for LTE TDD, the effect is the same as that set to RANDOMMODE. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

When the number of UEs in the cell is small (in newly deployed sites or in off-peak hours), this parameter can be set to either FIXEDMODE(Fixed Mode) or RANDOMMODE(Random Mode).

When the number of UEs in the cell is large, the parameter value RANDOMMODE(Random Mode) is recommended.

In high speed railway scenarios, if a small number of PUCCH RB resources is required, the parameter value OPTISELECTMODE(OPTISELECTMODE) is recommended.

It is recommended that this parameter be set to RBSAVINGMODE(RB Saving Mode) when uplink PRBs may be insufficient.

Impact on Radio Network Performance

If this parameter is set to FIXEDMODE and the power differences between adjacent code channels are large, strong inter-symbol interference causes deterioration in format 1/1a/1b PUCCH demodulation performance. As a result, missing detection of format 1/1a/1b PUCCH occurs. If this parameter is set to RANDOMMODE, non-adjacent code channel resources are allocated to UEs for format 1/1a/1b PUCCH transmission. Therefore, the detection performance of format 1/1a/1b PUCCH improves. If this parameter is set to OPTISELECTMODE, the probability that adjacent code channel resources are allocated is minimized, the inter-symbol interference is reduced, and therefore the detection performance of format 1 PUCCH improves. In addition, the SRI demodulation performance achieved when the DeltaShift parameter is set to DS1_DELTA_SHIFT in high speed railway scenarios is the same as that achieved when the DeltaShift parameter is set to DS2_DELTA_SHIFT but with a smaller number of PUCCH RBs used. If this parameter is set to RBSAVINGMODE, the number of UEs reused in each RB increases, the number of PUCCH RBs decreases, and the number of available PUSCH RBs increases. However, interference between code channels increases, and demodulation performance of Format 1 code channel resources may deteriorate.
