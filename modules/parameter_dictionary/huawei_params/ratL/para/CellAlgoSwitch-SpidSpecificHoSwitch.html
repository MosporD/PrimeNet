Meaning

Indicates the switches that control SPID-based handover.

INTER_FREQ_LIST_CTL_SW: This option controls SPID-based target frequency list in inter-frequency handovers. If this option is selected and an RatFreqPriorityGroup MO is configured for an SPID, UEs with the SPID can be handed over to cells on the frequency indicated in the RatFreqPriorityGroup MO in inter-frequency handovers. If this option is deselected, the target frequency for UEs with the SPID in inter-frequency handovers is not controlled. This option applies only to LTE FDD and LTE TDD.

L2U_FREQ_LIST_CTL_SW: This option controls SPID-based target frequency list in E-UTRAN-to-UTRAN handovers and redirections. If this option is selected and an RatFreqPriorityGroup MO is configured for an SPID, UEs with the SPID can be handed over or redirected to UTRAN cells on the frequency indicated in the RatFreqPriorityGroup MO in E-UTRAN-to-UTRAN handovers or redirections. If this option is deselected, the target frequency for UEs with the SPID in E-UTRAN-to-UTRAN handovers and redirections is not controlled. This option applies only to LTE FDD and LTE TDD.
