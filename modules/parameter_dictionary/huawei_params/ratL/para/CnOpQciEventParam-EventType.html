Meaning

Indicates the type of an event related to a handover. The value INTER_FREQ_HO_A1 indicates event A1 related to coverage-based inter-frequency handovers. The value INTER_FREQ_HO_A3 indicates event A3 related to coverage-based inter-frequency handovers. The value INTER_FREQ_HO_A4 indicates event A4 related to coverage-based inter-frequency handovers. The value HO_TO_UTRAN_B1 indicates event B1 related to coverage-based handovers to UTRAN. FREQ_PRI_INTER_FREQ_HO_A1 indicates event A1 related to frequency-priority-based inter-frequency handovers. FREQ_PRI_INTER_FREQ_HO_A2 indicates event A2 related to frequency-priority-based inter-frequency handovers. FREQ_PRI_INTER_FREQ_HO_A4 indicates event A4 related to frequency-priority-based inter-frequency handovers. This parameter applies only to LTE FDD and LTE TDD.
