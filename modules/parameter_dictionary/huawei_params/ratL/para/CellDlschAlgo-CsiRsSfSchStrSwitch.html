MOD CELLDLSCHALGO

LST CELLDLSCHALGO
Meaning

Indicates the scheduling policy of CSI-RS subframes.

UnCfgCsiRsUESchSwitch: Indicates whether UEs for which CSI-RSs are not configured can be scheduled in CSI-RS subframes. These UEs can be scheduled in these subframes only when this option is selected. UEs for which CSI-RSs are not configured refer to the CSI-RSs that cannot identify CSI-RSs transmitted in the CSI-RS subframes. This option applies only to LTE TDD.

UnCfgCsiRsUEDeOrderSchSwitch: Indicates whether UEs for which CSI-RSs are not configured can be scheduled in CSI-RS subframes using the MCS index decreasing policy. These UEs can be scheduled in CSI-RS subframes using the MCS index decreasing policy only if this option is selected. This option does not take effect for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

UnconfigCsiRsUeEnDeOrderSchSw: Indicates whether UEs for which CSI-RSs are not configured can be scheduled in CSI-RS subframes using an enhanced MCS index decreasing policy. These UEs can be scheduled in CSI-RS subframes using an enhanced MCS index decreasing policy only if this option is selected. This option does not take effect for eMTC UEs. This option applies only to LTE FDD.

Impact on Radio Network Performance

UnCfgCsiRsUESchSwitch: If this option is selected, UEs that are not configured with CSI-RSs can be scheduled in CSI-RS subframes, thereby increasing the scheduling opportunities of such UEs. This can also increase average cell throughput when the penetration rate of TM9 or TM10 UEs in the cell is low. If this option is deselected, UEs that are not configured with CSI-RSs cannot be scheduled in CSI-RS subframes, thereby decreasing the scheduling opportunities of such UEs. This may decrease average cell throughput when the penetration rate of TM9 or TM10 UEs in the cell is low. Currently, TDD supports only TM9.

UnCfgCsiRsUEDeOrderSchSwitch: If this option is selected, UEs that are not configured with CSI-RSs can be scheduled in CSI-RS subframes using the new MCS index lowering policy, thereby increasing the MCS indexes of such UEs in CSI-RS subframes. This can also increase average cell throughput when the penetration rate of TM9 or TM10 UEs in the cell is low. If this option is deselected, UEs that are not configured with CSI-RSs cannot be scheduled in CSI-RS subframes using the new MCS index lowering policy, thereby decreasing the MCS indexes of such UEs. This may decrease average cell throughput when the penetration rate of TM9 or TM10 UEs in the cell is low. Currently, TDD supports only TM9, and FDD supports both TM9 and TM10.

UnconfigCsiRsUeEnDeOrderSchSw: If this option is selected, MCSs of higher indexes are used for the scheduling of UEs for which CSI-RSs are not configured in CSI-RS subframes compared with when the non-enhanced MCS index decreasing policy is used. This increases the average cell throughput in cells with a low penetration rate of TM9 and TM10 UEs. If this option is deselected, MCSs of lower indexes are used for the scheduling of UEs for which CSI-RSs are not configured in CSI-RS subframes. This may decrease the average cell throughput in cells with a low penetration rate of TM9 and TM10 UEs.
