Meaning

Indicates the eNodeB-expected target receive power level of the NPRACH preambles sent from NB-IoT UEs at coverage level 1.

For details about this parameter, see 3GPP TS 36.321. This parameter is optional. The value NOT_CFG indicates that this parameter is not configured. This parameter applies only to NB-IoT.

Impact on Radio Network Performance

A larger value of this parameter results in a higher probability that a UE at coverage level 1 successfully accesses the network after initially transmitting a preamble but stronger interference on neighboring cells. A smaller value leads to the opposite effects.
