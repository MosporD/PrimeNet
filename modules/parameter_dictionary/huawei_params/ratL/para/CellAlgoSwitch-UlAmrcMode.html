Meaning

Indicates the uplink voice rate control mode.

If this parameter is set to ULRATECTRL_OFF, uplink voice rate control does not take effect. If RTP packets are encrypted, this parameter must be set to ULRATECTRL_OFF.

If this parameter is set to ULAMRC_ENB_CONTROL, the eNodeB executes uplink voice AMR control.

If this parameter is set to ULAMRC_SBC_CONTROL, the session border controller (SBC) on the EPC executes uplink voice AMR control. The SBC must be a Huawei SBC supporting voice AMR control.

If this parameter is set to ULEVSC_ENB_CONTROL, the eNodeB executes uplink EVS rate control.

If this parameter is set to ADAPTIVE_ENB_CONTROL, the eNodeB executes uplink AMR/EVS adaptive coding rate control. This parameter applies only to LTE FDD and LTE TDD.

Disuse statement: The enumerated value ULAMRC_SBC_CONTROL in this parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this enumerated value, the system does not use this enumerated value. Therefore, avoid using this enumerated value ULAMRC_SBC_CONTROL.

Impact on Radio Network Performance

If uplink voice rate control is enabled and the uplink channel quality is good, a high voice coding rate is used. If the uplink channel quality is poor, a low coding rate is used to improve uplink voice quality.

If the percentage of times the initial voice coding rate is increased to a higher voice coding rate is large, more CCE and RB resources are consumed by voice services. In CCE-limited or full-buffer service scenarios, the traffic volume and throughput of data services are more likely to decrease. If the percentage of times the initial voice coding rate is decreased to a lower voice coding rate is large, less CCE and RB resources are consumed by voice services. In CCE-limited or full-buffer service scenarios, the traffic volume and throughput of data services are more likely to increase.
