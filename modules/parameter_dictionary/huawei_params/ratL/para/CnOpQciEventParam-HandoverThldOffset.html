Meaning

Indicates the offset relative to the QCI-specific RSRP or RSCP threshold for a specific handover-related event of a specific operator. If this parameter is set to 0, the event threshold for handovers is configured regardless of the PLMN and QCI. This parameter applies only to LTE FDD and LTE TDD.

Caution

When modifying the parameter, ensure that the sum of the threshold for event A2 related to a specific type of handovers and the corresponding offset is less than the sum of the threshold for event A1 related to the specific type of handovers and the corresponding offset. The details are as follows:

Assume that the CnOpQciEventParam.EventType parameter is set to INTER_FREQ_HO_A1.

1. The A4- or A5-based inter-frequency A2 RSRP threshold must be less than the sum of the InterFreqHoGroup.InterFreqHoA1ThdRsrp and CnOpQciEventParam.HandoverThldOffset parameter values. The A4- or A5-based inter-frequency A2 RSRP threshold is equal to the sum of the values of the InterFreqHoGroup.InterFreqHoA2ThdRsrp parameter, the CnOperatorQciPara.InterFreqA2RsrpThldOffset parameter, and the eNodeB-level parameter CnOperatorHoCfg.FddIfHoA2ThdRsrpOffset or CnOperatorHoCfg.TddIfHoA2ThdRsrpOffset or the cell-level parameter CellOpHoCfg.FddIfHoA2ThdRsrpOffset or CellOpHoCfg.TddIfHoA2ThdRsrpOffset.

2. The A3-based inter-frequency A2 RSRP threshold must be less than the sum of the InterFreqHoGroup.A3InterFreqHoA1ThdRsrp and CnOpQciEventParam.HandoverThldOffset parameter values. The A3-based inter-frequency A2 RSRP threshold is equal to the sum of the values of the InterFreqHoGroup.InterFreqHoA2ThdRsrpA3 parameter, the CnOperatorQciPara.InterFreqA2RsrpThldOffset parameter, and the eNodeB-level parameter CnOperatorHoCfg.FddIfHoA2ThdRsrpOffset or CnOperatorHoCfg.TddIfHoA2ThdRsrpOffset or the cell-level parameter CellOpHoCfg.FddIfHoA2ThdRsrpOffset or CellOpHoCfg.TddIfHoA2ThdRsrpOffset.

Assume that the CnOpQciEventParam.EventType parameter is set to FREQ_PRI_INTER_FREQ_HO_A1 or FREQ_PRI_INTER_FREQ_HO_A2.

The threshold for event A2 related to frequency-priority-based inter-frequency handovers must be less than the sum of the values of the InterFreqHoGroup.FreqPriInterFreqHoA1ThdRsrp parameter and the CnOpQciEventParam.HandoverThldOffset parameter (with the CnOpQciEventParam.EventType parameter set to FREQ_PRI_INTER_FREQ_HO_A1). The threshold for event A2 related to frequency-priority-based inter-frequency handovers is equal to the sum of the values of the InterFreqHoGroup.FreqPriInterFreqHoA2ThdRsrp parameter and the CnOpQciEventParam.HandoverThldOffset parameter (with the CnOpQciEventParam.EventType parameter set to FREQ_PRI_INTER_FREQ_HO_A2).
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

Assume that the CnOpQciEventParam.EventType parameter is set to INTER_FREQ_HO_A1 or FREQ_PRI_INTER_FREQ_HO_A1. A smaller value of this parameter results in a higher probability of entering event A1 related to the corresponding type of handovers for the specific operator and a higher probability of stopping inter-frequency measurements. A larger value of this parameter results in a lower probability of entering event A1 related to the corresponding type of handovers for the specific operator and a lower probability of stopping inter-frequency measurements.

Assume that the CnOpQciEventParam.EventType parameter is set to FREQ_PRI_INTER_FREQ_HO_A2. A smaller value of this parameter results in a lower probability of entering event A2 related to the corresponding type of handovers for the specific operator and a lower probability of stopping inter-frequency measurements. A larger value of this parameter results in a higher probability of entering event A2 related to the corresponding type of handovers for the specific operator and a higher probability of starting inter-frequency measurements.

Assume that the CnOpQciEventParam.EventType parameter is set to INTER_FREQ_HO_A3. A smaller value of this parameter results in a higher probability of entering event A3 related to the corresponding type of handovers for the specific operator and a higher probability of triggering handovers. A larger value of this parameter results in a lower probability of entering event A3 related to the corresponding type of handovers for the specific operator and a lower probability of triggering handovers.

Assume that the CnOpQciEventParam.EventType parameter is set to INTER_FREQ_HO_A4 or FREQ_PRI_INTER_FREQ_HO_A4. A smaller value of this parameter results in a higher probability of entering event A4 related to the corresponding type of handovers for the specific operator and a higher probability of incorrect decisions and ping-pong handovers. A larger value of this parameter results in a lower probability of entering event A4 related to the corresponding type of handovers for the specific operator and a lower probability of triggering handovers, affecting user experience.

Assume that the CnOpQciEventParam.EventType parameter is set to HO_TO_UTRAN_B1. A smaller value of this parameter results in a higher probability of triggering inter-RAT handovers for the specific operator. A larger value of this parameter results in a lower probability of triggering inter-RAT handovers for the specific operator.
