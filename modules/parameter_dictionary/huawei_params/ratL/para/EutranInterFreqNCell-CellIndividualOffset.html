Meaning

Indicates the cell individual offset for the inter-frequency neighboring cell. It affects the probability of triggering inter-frequency measurement reports. A larger value of this parameter indicates a higher probability. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a larger probability of triggering measurement reporting and handovers, increasing the number of handovers. A smaller value of this parameter results in the opposite effects. Whether the value of this parameter is too large or too small, the handover success rate decreases.
