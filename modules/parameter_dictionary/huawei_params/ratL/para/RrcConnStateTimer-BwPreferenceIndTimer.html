MML Command

MOD RRCCONNSTATETIMER

LST RRCCONNSTATETIMER
Meaning

Indicates the length of the timer during which UEs are prohibited from reporting the bw-Preference-r14 IE to the eNodeB. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
