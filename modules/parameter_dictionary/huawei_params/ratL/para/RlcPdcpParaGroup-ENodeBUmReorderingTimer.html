Impact on Radio Network Performance

A small value of this parameter results in invalid HARQ retransmissions from the transmitter and a large number of lost packets. A large value of this parameter leads to a long delay for the receiver to determine an out-of-order packet transmission failure, thereby increasing service delay and reducing the throughput.
