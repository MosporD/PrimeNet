Meaning

Indicates whether to enable eMIMO-related algorithms.

Virtual4T4RSwitch: Indicates whether to enable the virtual 4T4R function. This option applies to FDD and TDD. The function is enabled only if this option is selected.

EmimoMuMimoSwitch: Indicates whether to enable the eMIMO MU-MIMO function. This option applies only to FDD. The function is enabled only if this option is selected.

EmimoCpsSwitch: Indicates whether to enable coordinated pilot scheduling for eMIMO. This option applies only to FDD. The function is enabled only if this option is selected. If this option is selected, the eNodeB determines the pilot transmission mode based on inter-cell load status.

EmimoFbaSwitch: Indicates whether to enable the following functions: fast beam alignment for eMIMO and extending UE rank reporting period in non-high-speed-railway scenarios when the CQI reporting period is adaptively changed to 40 ms. The preceding two functions are enabled only if this option is selected. This option applies only to LTE FDD.

New4TCodebookSwitch: Indicates whether to use the new 4T codebook. The new 4T codebook can be used for UEs that support the new 4T codebook only if this option is selected. This option applies only to LTE FDD.

4TxTM9MuMimoSwitch: Indicates whether to enable the 4TX TM9 MU-MIMO function. This option applies only to FDD. The function is enabled only if this option is selected.

DrxSimulAckNackAndCqiSwitch: Indicates whether to allow UEs in DRX mode to send CQI and ACK/NACK simultaneously on the PUCCH when SimulAckNackAndCqiSwitch is set to ON and CqiMask is set to OFF. This option takes effect when the number of configured downlink transmit antennas of the cell is greater than two. This option applies only to LTE FDD. If this option is selected, UEs in DRX mode can send CQI and ACK/NACK simultaneously on the PUCCH when SimulAckNackAndCqiSwitch is set to ON and CqiMask is set to OFF. If this option is deselected, the settings of the SimulAckNackAndCqiSwitch and CqiMask parameters determine whether to allow UEs in DRX mode to send CQI and ACK/NACK simultaneously on the PUCCH.

PreciseAmcSwitch: Indicates whether to enable precise AMC. This option applies only to LTE FDD and LTE TDD. If this option is selected, target IBLERs are adjusted based on the interference level information exchanged with neighboring cells. If this option is deselected, the function does not take effect.

EmimoCsiEnhanceSwitch: Indicates whether to enable CSI reporting enhancement. If this option is selected, CSI reporting enhancement for eMIMO is enabled. A shorter CSI reporting period can be set for UEs running large-packet services and fast beam alignment does not take effect. This option applies only to LTE FDD. If this option is deselected, CSI reporting enhancement for eMIMO is disabled.

PUSCH12Switch: Indicates whether to enable the PUSCH 1-2 feedback mode. This option applies only to LTE FDD. If this option is selected, UEs that support reporting on PUSCH 1-2 use this mode to aperiodically report CQIs. If this option is deselected, the mode cannot be used.

Parameter Relationship

-Configuration constraints:

  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, options of TM9Switch and TM10Switch of EnhMIMOSwitch must be deselected.
  • In the CellAlgoSwitch MO, if the Virtual4T4RSwitch option of EmimoSwitch is selected, the DlCellCoverEnhanceAlgoSw option of CellDlCoverEnhanceSwitch must be deselected.
  • If the Virtual4T4RSwitch or Tm4MuMimoSwitch option of the EmimoSwitch parameter in a CellAlgoSwitch MO is selected, AdptCellEdgePwrAllocSw under the CellDlCoverEnhanceSwitch parameter in the same CellAlgoSwitch MO must be deselected.
  • In the CellAlgoSwitch MO, if the Virtual4T4RSwitch option of EmimoSwitch is selected, GLPwrShare must be set to OFF.
  • Only if the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, then the Dl256QamAccessorySwitch option of Dl256QamAlgoSwitch in the CellAlgoSwitch MO can be selected.
  • When the PUSCH12Switch option of the EmimoSwitch parameter is selected, the New4TCodebookSwitch option of the EmimoSwitch parameter must be deselected.

Impact on Radio Network Performance

Virtual4T4RSwitch: If this option is selected, resources can be reused in independent scheduling areas and multi-stream spatial multiplexing can be implemented in overlapping areas. This setting increases the peak cell data rate and the user-perceived data rate in the overlapping areas. If this option is deselected, the virtual 4T4R function does not take effect and common networking is used.

EmimoMuMmoSwitch: If this option is selected, MU-MIMO is used for UEs meeting the pairing requirements for MU-MIMO to increase the spectral efficiency of the cell and user-perceived data rates. If this option is deselected, SU-MIMO is used and MU-MIMO gains cannot be obtained.

EmimoCpsSwitch: If this option is selected, the eNodeB determines the pilot transmission mode based on inter-cell load status to increase UE throughput. If this option is deselected, the default pilot transmission mode is used and network performance is not affected.

EmimoFbaSwitch: If this option is selected, the eNodeB forms more accurate beams for UEs, increasing the downlink SINR for UEs and user-perceived downlink data rates; however, the uplink throughput may slightly decrease. If this option is deselected, cell performance is not affected.

New4TCodebookSwitch: If this option is selected and close-loop MIMO is used, new 4T codebook is used for UEs that support new 4T codebook and original codebook is used for UEs that do not support new 4T codebook, increasing user-perceived downlink data rates. If this option is deselected and close-loop MIMO is used, original codebook is used for all UEs without affecting the network performance.

4TxTM9MuMimoSwitch: If this option is selected, the cell adaptively determines whether to enter or exit TM9 MU-MIMO mode based on factors such as UE capability, channel condition, and cell load. Then, the cell selects UEs meeting the pairing conditions for 4TX TM9 MU-MIMO scheduling, thereby increasing the cell spectral efficiency and user-perceived rate. After the adaptive TM9 MU-MIMO switch is enabled, the cell adaptively exits TM9 MU-MIMO mode when network conditions are not met. Within the period of determining whether to exit TM9 MU-MIMO mode, negative gains of TM9 SU relative to TM4 SU may be produced for UEs controlled by TM9 MU-MIMO to enter TM9 from TM4. If this option is deselected, network performance is not affected.

DrxSimulAckNackAndCqiSwitch: If this option is selected, UEs in DRX mode can send CQI and ACK/NACK simultaneously on the PUCCH if SimulAckNackAndCqiSwitch is set to ON and CqiMask is set to OFF. This increases the CQI reporting times so that the CQI can quickly adapt to the channel quality, increasing the UE throughput. However, UE compatibility problem may occur. If this option is deselected, network performance is not affected.

PreciseAmcSwitch: If this option is selected, the downlink data rates of UEs increase in scenarios where interference with neighboring cells fluctuates. However, RBLERs may also increase. If this option is deselected, network performance is not affected.

EmimoCsiEnhanceSwitch: If this option is selected, the eNodeB sets shorter CSI feedback periods for UEs, increasing the reporting accuracy of the downlink CSI for UEs and user-perceived downlink data rates; however, the uplink throughput may slightly decrease. In the case of initial access, the uplink IBLER decreases. If this option is deselected, cell performance is not affected.

PUSCH12Switch: If this option is deselected, the network performance is not affected. If this option is selected, UEs that support reporting on PUSCH 1-2 report subband PMIs in aperiodic CQI reporting, increasing user-perceived downlink data rates. However, the PUSCH resource consumption increases and the uplink data rate slightly decreases.
