Meaning

Indicates the allocation mode of sounding reference signal (SRS) resources in LTE FDD. This parameter must be set when the SrsCfgInd parameter is set to BOOLEAN_TRUE(True). If the FddSrsCfgMode parameter is set to DEFAULTMODE(Default Mode), SRS resource allocation is activated by default after a cell is established, and SRS resources are allocated to UEs that access the cell. If this parameter is set to ADAPTIVEMODE(Adaptive Mode), SRS resource allocation can be adaptively activated or deactivated based on the cell load. After this parameter is set to ADAPTIVEMODE(Adaptive Mode), settings of parameters SrsAlgoSwitch, SrsSubframeCfg, and UserSrsPeriod do not take effect. The parameter value ADAPTIVEMODE(Adaptive Mode) is recommended in heavy-traffic scenarios where there is a large number of UEs in the cell. The parameter value ADAPTIVEMODE(Adaptive Mode) does not apply to cells established on an LBBPc. This parameter applies only to LTE FDD.

Caution

Modification of this parameter will cause the cell to automatically restart. It is recommended that FddSrsCfgMode be set to ADAPTIVEMODE for an FDD cell with a bandwidth of 3 MHz or 5 MHz if the cell load is light and there is a small number of UEs in the cell. If the cell load is heavy and there is a large number of UEs in the cell, it is recommended that FddSrsCfgMode be set to DEFAULTMODE to reduce the number of DMRS-based TA scheduling times and CCE and uplink PRB overheads in the cell.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

If this parameter is set to DEFAULTMODE, higher performance gains are obtained in features that are dependent on SRS measurements. However, the peak uplink data rate in the cell decreases because of SRS overheads. If this parameter is set to ADAPTIVEMODE, then: (1) SRS resource allocation can be adaptively deactivated when there is a small number of UEs in the cell and the traffic volume is small. In this case, no SRS overheads are generated, and therefore uplink performance improves. (2) SRS resource allocation can be adaptively activated when there is a large number of UEs in the cell and the traffic volume is large. In this case, resources used for uplink timing are reduced, cell performance in the uplink and downlink improves, and the access success rate increases.
