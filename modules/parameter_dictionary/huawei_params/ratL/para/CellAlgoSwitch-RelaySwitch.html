Meaning

Indicates whether to enable relay-related functions.

OutOfBandRelaySwitch: Indicates whether to enable out-of-band relay. If this option is selected, out-of-band relay is enabled. If this option is deselected, out-of-band relay is disabled. This option applies only to LTE FDD and LTE TDD.

InBandRelayDeNbSwitch: Indicates whether to enable in-band relay for the DeNB. If this option is selected, in-band relay is enabled for the DeNB. If this option is deselected, in-band relay is disabled for the DeNB. This option applies only to LTE FDD and LTE TDD.

InBandRelayReNbSwitch: Indicates whether to enable in-band relay for the ReNB. If this option is selected, in-band relay is enabled for the ReNB. If this option is deselected, in-band relay is disabled for the ReNB. This option applies only to LTE FDD and LTE TDD.

InBandRelayDistantDeploySw: Indicates whether to allow the first-hop ReNB to be deployed as far as 20 km from the DeNB in in-band relay scenarios. If this option is selected, the first-hop ReNB can be deployed as far as 20 km from the DeNB in in-band relay scenarios. If this option is deselected, the first-hop ReNB cannot be deployed as far as 20 km from the DeNB in in-band relay scenarios. This option applies only to LTE FDD and LTE TDD.

Caution

Changing the InBandRelayReNbSwitch setting causes cells under the ReNB to automatically restart.

Changing the InBandRelayDeNbSwitch or InBandRelayDistantDeploySw setting will release all relay UEs in the cell.

If RRN services are configured in the cell, the RRN and the ReBTS connected to the RRN will be disconnected from the NMS after the state of the OutOfBandRelaySwitch, InBandRelayDeNbSwitch, InBandRelayReNbSwitch, or InBandRelayDistantDeploySw option of RelaySwitch is changed from on to off.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

OutOfBandRelaySwitch: If this option is selected, the number of common UEs that can access the cell decreases, both the total throughput of common UEs in the cell and the peak throughput of a single common UE decrease (the decrease rate is in positive correlation with the number of resources occupied by relay subframes), and the relayed UEs can access the cell. If this option is deselected, the number of common UEs that can access the cell increases, the throughput of common UEs may increase, and relayed UEs that have accessed the cell are released, and services of the relayed UEs are interrupted.

InBandRelayDeNbSwitch: If this option is selected, the number of common UEs that can access the cell decreases, both the total throughput of common UEs in the cell and the peak throughput of a single common UE decrease (the decrease rate is in positive correlation with the number of resources occupied by backhaul subframes), and the backhaul UEs can access the cell. If this option is deselected, the number of common UEs that can access the cell increases, the throughput of common UEs may increase, backhaul UEs that have accessed the cell are released, and services of the relayed UEs are interrupted.

InBandRelayReNbSwitch: If this option is selected, UEs cannot be scheduled on certain subframes. As a result, the number of UEs that can access the cell decreases, both the total throughput of UEs in the cell and the peak throughput of a single UE decrease (the decrease rate is in negative correlation with the number of resources occupied by in-band relay backhaul subframes). If this option is deselected, the number of UEs that can access the cell increases and the UE throughput may increase if S1 and X2 interfaces are available. If S1 and X2 interfaces are unavailable, UEs cannot access the cell.

InBandRelayDistantDeploySw: When relay UEs are deployed from the DeNB at a distance greater than 9.5 km and less than 20 km, this option must be selected. This will reduce interference of relay UEs on ReNB symbols but have no impact on common UEs. If this option is deselected in such scenarios, relay UEs interfere with ReNB symbols. When relay UEs are deployed from the DeNB at a distance less than 9.5 km, deselect this option. If this option is selected in such scenarios, the uplink throughput of relay UEs served by the DeNB and peak throughput of a single relay UE decrease.
