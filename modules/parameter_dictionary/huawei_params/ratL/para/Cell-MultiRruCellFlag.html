Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and CELL_COMBINATION, respectively, FddTddInd must be set to TDD.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and MultiRruCellMode in a Cell MO is set to DIGITAL_COMBINATION, FddTddInd in Cell MO must be set to CELL_FDD.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and MultiRruCellMode in a Cell MO is set to DIGITAL_COMBINATION, DlCyclicPrefix and UlCyclicPrefix in Cell MO must be set to NORMAL_CP.
  • In a Cell MO, if FddTddInd, CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_TDD, CELL_ACTIVE, BOOLEAN_TRUE, and SFN, respectively, TxRxMode must be set to 2T2R, 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to NORMAL_COMPRESSION, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to ENHANCED_COMPRESSION or TRIPLEX_COMPRESSION_10M, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 8T8R or 32T32R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and CELL_COMBINATION, respectively, TxRxMode must be set to 1T1R, 2T2R or 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and TWO_RRU_COMBINATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and DIGITAL_COMBINATION, respectively, TxRxMode must be set to 1T1R or 2T2R.
  • In a Cell MO, if FddTddInd is set to TDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if FddTddInd is set to FDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R or 2T2R or 1T1R.
  • If FddTddInd, MultiRruCellFlag, and MultiRruCellMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, TxRxMode in the Cell MO must be set to 4T4R, 2T4R, 2T2R, 1T2R or 1T1R.
  • In a Cell MO, if FddTddInd, MultiRruCellFlag, and MultiRruCellMode are set to CELL_FDD, BOOLEAN_TRUE, and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R, 2T2R, or 1T1R.
  • In a Cell MO, if FddTddInd, MultiRruCellFlag and MultiRruCellMode are set to CELL_FDD, BOOLEAN_TRUE and SFN, respectively, DlCyclicPrefix and UlCyclicPrefix must be set to NORMAL_CP.
  • In a Cell MO, MultiRruCellFlag set to BOOLEAN_TRUE and MultiRruCellMode set to SFN or MPRU_AGGREGATION, or MultiRruCellFlag set to BOOLEAN_FALSE if EuCellStandbyMode is set to STANDBY.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_TDD, or if MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_FDD and MultiRruCellMode in the Cell MO is set to a value other than SFN and MPRU_AGGREGATION, CrsPortMap in the Cell MO must be set to NOT_CFG.
  • Assume that MultiRruCellFlag is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION, SFN, or CELL_COMBINATION in a Cell MO. If NbCellFlag is set to FALSE and CpriEthCompressionRatio is set to 3_TO_1, DlBandWidth must be set to CELL_BW_N75 or CELL_BW_N100. If NbCellFlag is set to FALSE and CpriEthCompressionRatio is set to 4_TO_1, DlBandWidth must not be set to CELL_BW_N25 or CELL_BW_N15. If NbCellFlag is set to TRUE, CpriEthCompressionRatio must be set to 2_TO_1.
  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo MO is set to ON, the value of MultiRruCellFlag in a CELL MO is only to be set BOOLEAN_FALSE.
  • The MultiCellShareMode parameter in the Cell MO can be set to SPLIT only if the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE.
  • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, and TxRxMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, MPRU_AGGREGATION, and 4T4R, respectively, CrsPortNum in the Cell MO must be set to CRS_PORT_4 with NbCellFlag set to FALSE, or CrsPortNum in the Cell MO must be set to CRS_PORT_2 with NbCellFlag set to TRUE.
  • When the FddTddInd parameter in the Cell MO is set to CELL_TDD and the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, the EuCellStandbyMode and MultiRruCellFlag parameters in the Cell MO must be set to ACTIVE and BOOLEAN_FALSE respectively.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_FDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE, SFN or MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_TDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE or CELL_COMBINATION, MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE, the HighSpeedFlag in the Cell MO is set to LOW_SPEED, the MultiRruCellMode parameter in the Cell MO is set to CELL_COMBINATION, and the TxRxMode in the Cell MO is set to 1T1R, 1T2R, 2T2R, or 2T4R; or the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE.
  • When the NbCellFlag parameter in a Cell MO is set to TRUE, and the MultiRruCellFlag parameter in a Cell MO is set to BOOLEAN_TRUE, value of the MultiRruCellMode parameter must be set to MPRU_AGGREGATION or SFN.
  • If the UL_RS_PWR_ADAPT_SW option of the HeavyLoadPrfmOptSwitch parameter in the CellAlgoExtSwitch MO under a Cell MO is selected, the MultiRruCellFlag and MultiRruCellMode parameters in this Cell MO must be set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively.
