eX2 Dynamic BlackList Switch

MO GlobalProcSwitch
Parameter ID eX2DynBlackListSwitch
Parameter Name

eX2 Dynamic BlackList Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether dynamic eX2 blacklist in ideal backhaul or non-ideal backhaul modes takes effect. This parameter provides the following options:

BASED_ON_EX2_IDEAL_MODE: If this option is selected, the function of dynamic eX2 blacklist in ideal backhaul mode takes effect. In this case, when an eX2 interface self-setup attempt fails, the eNodeB adds the eX2 interface to the dynamic eX2 blacklist. If this option is deselected, this function does not take effect and all generated dynamic eX2 blacklists are removed. This option applies only to LTE FDD and LTE TDD.

BASED_ON_EX2_NON_IDEAL_MODE: If this option is selected, the functions of dynamic eX2 blacklist in non-ideal backhaul mode and eX2 automatic removal triggered by initial eX2 self-setup failures take effect. In this case, when an eX2 interface self-setup attempt fails, the eNodeB adds the eX2 interface to the dynamic eX2 blacklist. If this option is deselected, these functions do not take effect and all generated dynamic eX2 blacklists are removed. This option applies only to LTE FDD and LTE TDD.

Caution

When any of these options is selected, the eX2 interface cannot be reestablished in a timely manner after the eX2 self-setup fails. The eX2 interface can be reestablished only after the eX2 dynamic blacklist aging timer expires. As a result, coordination services cannot be activated in a timely manner.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

BASED_ON_EX2_IDEAL_MODE: If this option is selected, the local eNodeB cannot initiate eX2 self-setup in ideal backhaul mode when the peer eNodeB is in the dynamic eX2 blacklist. If this option is deselected, the local eNodeB periodically re-initiates eX2 self-setup if an eX2 self-setup procedure in ideal backhaul mode fails, which increases signaling overhead.

BASED_ON_EX2_NON_IDEAL_MODE: If this option is selected, the local eNodeB removes eX2 interfaces that fail to be set up during initial self-setup in non-ideal backhaul mode. This prevents such eX2 interfaces from occupying eX2 specifications. The local eNodeB cannot initiate eX2 self-setup in non-ideal backhaul mode when the peer eNodeB is in the dynamic eX2 blacklist. If this option is deselected, the local eNodeB cannot automatically and promptly remove eX2 interfaces that fail to be set up during initial self-setup in non-ideal backhaul mode. Such eX2 interfaces occupy eX2 specifications. When the number of eX2 interfaces reaches its maximum, the local eNodeB can set up a new eX2 interface only if another eX2 interface meets automatic removal conditions and is removed.
