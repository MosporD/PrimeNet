Meaning

Indicates whether to enable short TTI in a cell.

SHORT_TTI_SW: Indicates whether to enable short TTI. This option applies only to LTE FDD.

SHORT_TTI_PREALLOCATION_SW: Indicates whether to enable preallocation for the short TTI mode. This option applies only to LTE FDD.

SPDCCH_BOUNDARY_POWER_CTRL_SW: Indicates whether to enable SPDCCH boundary power control. With this option selected, the power can be increased to hold the SPDCCH bit error rate under control when the maximum aggregation level is in use. This option applies only to LTE FDD.

Impact on Radio Network Performance

SHORT_TTI_SW: When this option is selected, the eNodeB will attempt to enable UEs meeting the service QCI and coverage conditions to enter the short TTI mode to shorten service delay. When this option is deselected, network performance is not affected.

SHORT_TTI_PREALLOCATION_SW: When this option is selected, the service delay will be shorter, the SPDCCH will consume more resources, and the uplink interference will increase. When this option is deselected, the preceding impacts are not produced.

SPDCCH_BOUNDARY_POWER_CTRL_SW: When this option is selected, the SPDCCH coverage performance will increase but its capacity will decrease. When this option is deselected, the SPDCCH coverage performance will decrease but its capacity will increase.
