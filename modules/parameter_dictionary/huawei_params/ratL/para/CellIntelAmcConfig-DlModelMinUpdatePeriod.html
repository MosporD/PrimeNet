Meaning

Indicates the minimum period of updating the downlink intelligent AMC model. The value 0MIN indicates that the model is updated continuously. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter indicates a shorter minimum period of starting downlink intelligent AMC model training, which leads to quicker updating of the model and therefore a closer matching between downlink MCS selection and instantaneous channel quality fluctuation on the live network. A larger value of this parameter indicates a longer minimum period of starting downlink intelligent AMC model training, which leads to slower updating of the model and a closer matching between downlink MCS selection and average channel quality fluctuation on the live network.
