Meaning

Indicates the maximum number of UEs that can be included in a paging message on each paging occasion. This parameter applies only to LTE FDD and LTE TDD.

Caution

You are advised to set this parameter based on the average number of UEs included in a paging message on each paging occasion in busy hours and the average number growth trend. In addition, the coding rate and power offset used for sending paging message must also be considered. In the scenarios with a given coding rate and power offset, when the number of UEs included in a paging message reaches the maximum, the power and the number of RBs required for sending the paging message cannot exceed the total power of the cell and the number of RBs in the corresponding bandwidth.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If a large number of paging messages are to be sent in a cell, a smaller value of this parameter results in a higher probability of paging message discard or delayed paging message delivery due to paging message overload and therefore a lower paging success rate or worse user experience. If this parameter is set to a large value and there are many paging messages, one paging message may occupy too many resource blocks (RBs), which may result in an increased coding rate for paging messages due to insufficient system power or resources. As a result, the success rate of paging message reception decreases.
