Meaning

Indicates the measurement time used to determine whether an inter-RAT handover is an unnecessary handover. After an inter-RAT handover, if the reference signal received power (RSRP) value of the source E-UTRAN cell measured by the UE in the target cell is consecutively greater than a preset threshold within the period of time specified by this parameter, the eNodeB considers that the inter-RAT handover is an unnecessary handover. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a lower probability that inter-RAT handovers are considered as unnecessary handovers and a longer time that a UE in the target cell performs inter-RAT measurements, which decreases UE throughput due to the fact that inter-RAT measurements interrupt services. A smaller value of this parameter results in a higher probability that inter-RAT handovers are considered as unnecessary handovers, including incorrect evaluation. As a result, the inter-RAT handover success rate may decrease and the service drop rate may increase.
