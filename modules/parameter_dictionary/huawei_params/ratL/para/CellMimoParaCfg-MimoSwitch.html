Meaning

Indicates MIMO algorithm switches.

8T_TM9_MU-MIMO_SW: Indicates whether to enable 8T TM9 MU-MIMO. The function is enabled only if this option is selected. This option applies only to LTE FDD.

MM_SCC_TM9_MU_MIMO_SW: Indicates whether to enable TM9 MU-MIMO in a massive MIMO SCell. If this option is selected, then TM9 MU-MIMO is enabled and the massive MIMO SCell adaptively selects an MIMO mode and determines whether to perform multiple UE pairing based on the TM9 UE penetration rate and load. If this option is deselected, then TM9 MU-MIMO is disabled and the massive MIMO SCell only uses SU-MIMO. This option applies only to LTE FDD.

TM9_RANK8_SCH_OPT_SW: Indicates whether to enable TM9 rank 8 UE scheduling optimization. If this option is selected, TM9 rank 8 UE scheduling optimization is enabled. If this option is deselected, the optimization does not take effect. This option applies only to LTE TDD.

FREQ_DIFF_AMEND_SW: Indicates whether to enable frequency difference amendment in the cell. If this option is selected, frequency difference amendment is enabled. This function reduces the impact of excessive spacing between uplink and downlink center frequencies for FDD cells. This option applies only to massive MIMO cells. This option applies only to LTE FDD.

PRECISE_DL_CSI_SW: Indicates whether to enable high-precision downlink CSI in the cell. If this option is selected, this function is enabled. This option applies only to LTE FDD.

MASSIVE_MIMO_SUBBAND_BF_SW: Indicates whether to enable subband beamforming in the cell. If this option is selected, aperiodic subband feedback mode can be configured for UEs to trigger feedback and subband beamforming is enabled. This option applies only to LTE FDD.

MASSIVE_MIMO_MU_RANK_OPT_SW: Indicates whether to enable MU-MIMO rank optimization in the cell. If this option is selected, the maximum rank values that UEs can report are adaptively tuned in the cell. This option applies only to LTE FDD.

4T_TM9_ADAPTATION_SW: Indicates whether to enable TM9 adaptation in 4T cells. If this option is selected, some TM9-capable UEs are allowed to enter TM9 in 4T cells. If this option is deselected, the function does not take effect. This option applies only to LTE FDD.

Impact on Radio Network Performance

8T_TM9_MU_MIMO_SW: When this option is selected, the cell adaptively determines whether to enter or exit 8T TM9 MU-MIMO mode based on factors such as UE capability, channel condition, and cell load. Then, the cell schedules and pairs UEs meeting the pairing conditions for MU-MIMO, thereby increasing the cell spectral efficiency and user-perceived rate. When this option is deselected, network performance is not affected.

MM_SCC_TM9_MU_MIMO_SW: If this option is selected, user-perceived data rates improve. If this option is deselected, network performance is not affected.

TM9_RANK8_SCH_OPT_SW: If this option is selected, the eNodeB optimizes the scheduling policy for rank 8 UEs continuously performing large-packet services, which may increase the downlink UE throughput. If this option is deselected, network performance is not affected.

FREQ_DIFF_AMEND_SW: If this option is selected, user-perceived data rates increase when the spacing between uplink and downlink center frequencies is large. If this option is deselected, network performance is not affected.

PRECISE_DL_CSI_SW: If this option is selected, downlink channel information precision and user-perceived rates are improved. If this option is deselected, network performance is not affected.

MASSIVE_MIMO_SUBBAND_BF_SW: If this option is selected, the eNodeB configures and triggers UEs to report subband channel information, increasing user-perceived data rates. The uplink data rates are affected because the uplink feedback overhead is increased. If this option is deselected, network performance is not affected.

MASSIVE_MIMO_MU_RANK_OPT_SW: If this option is selected, the downlink cell data rate increases. If this option is deselected, network performance is not affected.

4T_TM9_ADAPTATION_SW: If this option is selected, some TM9-capable UEs that meet certain conditions can enter TM9 in 4T cells, which has no impact on network performance.
