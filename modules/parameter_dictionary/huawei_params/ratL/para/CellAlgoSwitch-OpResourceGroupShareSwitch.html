Meaning

Indicates whether to enable RAN sharing so that admission and scheduling take effect in RAN sharing mode. When the switch is on, operators share the resources specified by the RAN-sharing operator group. When the OpPrbGroupshareSwitch option is selected, PRB resources can be shared by operator groups. This parameter applies only to LTE FDD and LTE TDD.
