Meaning

Indicates the rule for matching a to-be-identified application (for example, a video) with the domain name. The service classification (SC) function uses the domain name to identify an application in two methods. If this parameter is set to Query, the query method is applied. If the IP address that a UE attempts to visit and a configured domain name match, the UE can obtain the service type (video service) through a reverse query of the domain name by using the IP address.

If this parameter is set to Relevancy, the relevancy method is applied. Assume that a UE accesses a video service and the IP address of the video does not match any configured domain name. After an initial identification of the video service, SC checks the domain names that the UE visited to find out whether there are domain names related to the video service. If yes, SC concludes the service as a video service. This parameter must be set under the consideration of the video service access characteristics in the place where the network locates.

This parameter must be set to Query when the domain name or IP address is configured for air interface acceleration guarantee for network services or simplified KQI tracing, or the TCP port is configured for TCP link setup acceleration. Otherwise, the configured domain name, IP address, or TCP port does not take effect.

This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the AccelerateInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the ServiceTraceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the LowDelayServiceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the PortNumber parameter is set to a value other than 0 and the ProtocolType parameter is set to BOTH or UDP, the MatchRule parameter must be set to Query.
  • If the VideoIdentInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 443 or 0.
  • If the AccelerateInd or ServiceTraceInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 0.
