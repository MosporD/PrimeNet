Meaning

Indicates whether to enable PDCCH power control enhancement and specifies the enhancement scope. If this parameter is set to ON_ALL, ON_EXPANDED_RANGE, or ON_BASIC_RANGE, the eNodeB selects an appropriate power value based on the PDCCH quality to increase the PDCCH capacity. The value ON_ALL indicates that the enhancement takes effect in all scenarios. The value ON_BASIC_RANGE indicates that the enhancement takes effect only in basic scenarios. The value ON_EXPANDED_RANGE indicates that the enhancement takes effect in more scenarios than when this parameter is set to ON_BASIC_RANGE.

For FDD, this parameter can be configured in all scenarios.

For TDD, this parameter applies only to massive MIMO cells where the aggregation level is selected based on capacity and cannot be set to ON_EXPANDED_RANGE or ON_BASIC_RANGE.

Impact on Radio Network Performance

If this parameter is set to OFF, power control enhancement does not take effect. The eNodeB selects a high aggregation level and uses the configured transmit power value. This reduces the maximum number of UEs supported by the PDCCH, and decreases the PDCCH resource allocation success rate in case of CCE insufficiency, affecting throughput.

If this parameter is set to ON_ALL, power control enhancement takes effect in all scenarios. The eNodeB selects a small aggregation level and increases the PDCCH transmit power to ensure PDCCH demodulation performance. This lifts the maximum number of UEs supported by the PDCCH, and increases the PDCCH resource allocation success rate in case of CCE insufficiency. However, negative gains may be produced.

If this parameter is set to ON_EXPANDED_RANGE, power control enhancement takes effect in a relatively large scope. However, the are fewer scenarios with negative gains than when this parameter is set to ON_ALL. This parameter value is available only for LTE FDD.

If this parameter is set to ON_BASIC_RANGE, power control enhancement takes effect in a small scope, but this parameter setting can minimize the scenarios with negative gains. This parameter value is available only for LTE FDD.
