Meaning

Indicates the number of ports for transmitting cell-specific reference signal (CRS). As defined in 3GPP specifications, this parameter can be set to CRS_PORT_1, CRS_PORT_2, or CRS_PORT_4. The value CRS_PORT_1 indicates that one CRS port (port 0) is configured. The value CRS_PORT_2 indicates that two CRS ports (ports 0 and 1) are configured. The value CRS_PORT_4 indicates that four CRS ports (ports 0, 1, 2, and 3) are configured.

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • In a Cell MO, if TxRxMode and CrsPortNum are set to 4T4R and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 8T2P_00001111, 8T2P_00110011, or 8T2P_01010101.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, or 4T4P_0132.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 8T4P_00112233, or 8T4P_01230123.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • The MultiCellShareMode parameter in the Cell MO can be set to SPLIT only if the CrsPortNum parameter in the Cell MO is set to CRS_PORT_2.
  • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, and TxRxMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, MPRU_AGGREGATION, and 4T4R, respectively, CrsPortNum in the Cell MO must be set to CRS_PORT_4 with NbCellFlag set to FALSE, or CrsPortNum in the Cell MO must be set to CRS_PORT_2 with NbCellFlag set to TRUE.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, and MultiCellShareMode is set to NORMAL, CrsPortNum must be set to CRS_PORT_4 or CRS_PORT_2.
  • When the NbCellFlag and TxRxMode parameters in a Cell MO are set to TRUE and a value among 2T2R, 2T4R, or 4T4R, respectively, the CrsPortNum parameter in this Cell MO must be set to CRS_PORT_2.
