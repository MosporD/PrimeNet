Meaning

Indicates the SRS configuration for LTE TDD. If this parameter is set to ACCESS_FIRST, the SRS configuration designed to preferentially guarantee the maximum number of UEs that can access a cell and BHCA is used. If this parameter is set to EXPERIENCE_FIRST, the SRS configuration designed to preferentially guarantee user experience (for example, beamforming performance) is used. If this parameter is set to EXPERIENCE_ENHANCED, downlink experience improves compared with that obtained when this parameter is set to ACCESS_FIRST. If this parameter is set to ACCESS_ENHANCED, more UEs can access the network compared with that obtained when this parameter is set to EXPERIENCE_ENHANCED. The values EXPERIENCE_ENHANCED and ACCESS_ENHANCED are not supported by the LBBPc. If this parameter is set to EXPERIENCE_ENHANCED or ACCESS_ENHANCED for a cell established on an LBBPc board, the value is automatically changed to ACCESS_FIRST when this parameter takes effect. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If this parameter is set to ACCESS_FIRST, a maximum number of UEs can access TDD cells, but the performance of features that are dependent on SRS measurements cannot be ensured.

If this parameter is set to EXPERIENCE_FIRST, large uplink throughput of TDD cells and good beamforming performance in the downlink can be ensured.

If this parameter is set to EXPERIENCE_ENHANCED, a maximum number of UEs (the same number as that in ACCESS_FIRST mode) can access TDD cells and performance of features that are dependent on SRS measurements can be ensured for all UEs when there are few UEs and for certain UEs if there are many UEs.

If this parameter is set to ACCESS_ENHANCED, the number of UEs that can access TDD cells exceeds the specifications in EXPERIENCE_ENHANCED mode, and performance of features that are dependent on SRS measurements can be ensured for all UEs when there are few UEs and for certain UEs if there are many UEs. When there are many UEs, a large amount of PUCCH resources are used. As a result, PUSCH resources decrease and average uplink throughput in the cell may decrease.
