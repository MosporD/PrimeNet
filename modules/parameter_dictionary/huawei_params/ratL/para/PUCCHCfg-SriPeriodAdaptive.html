Meaning

Indicates whether to enable scheduling request indicator (SRI) reporting period adaptation. If this parameter is set to QCIADAPTIVE, the eNodeB adaptively changes the SRI reporting period based on the cell load and bearers with different QCIs. If this parameter is set to NOQCIADAPTIVE, the eNodeB adaptively changes the SRI reporting period only based on the cell load. If this parameter is set to OFF and the FixedSriPeriod parameter in the PUCCHCFG MO is set to Disable, the SRI reporting period equals the value of the FixedSriPeriod parameter in the CELLQCIPARA MO. If this parameter is set to OFF and the FixedSriPeriod parameter in the PUCCHCFG MO is not set to Disable, the SRI reporting period equals the value of the FixedSriPeriod parameter in the PUCCHCFG MO. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to NOQCIADAPTIVE, the eNodeB adaptively changes the SRI reporting period for UEs only based on the cell load. This avoids SRI reporting period reconfiguration caused by changes of bearers with different QCIs or changes of the effective status of some features, reducing signaling resource consumption. The decrease in the number of SRI reporting period reconfiguration attempts helps to resolve the issue where the E-RAB setup success rate decreases when abnormal UEs on the live network randomly do not send SRIs. The quality of voice services deteriorates slightly in a cell serving only a few UEs. In addition, the maximum number of UEs does not change after the SRI reporting period adaptively changes based on the SRI algorithm.

If this parameter is set to QCIADAPTIVE, the SRI reporting period adaptively changes based on the SRI algorithm, and the maximum number of UEs does not change.

If this parameter is set to OFF, the maximum number of UEs is determined based on the configured SRI reporting period.
