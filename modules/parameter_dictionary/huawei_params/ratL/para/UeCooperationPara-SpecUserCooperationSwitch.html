Meaning

Indicates whether to enable device-pipe synergy functions for specific UEs and support for high-power UEs.

SpecUeIdentifySwitch: Indicates whether to identify specific UEs. If this option is selected, specific UEs can be identified in the cell. If this option is deselected, specific UEs cannot be identified in the cell.

HighPowerUeSupportSwitch: Indicates whether the cell can serve high-power UEs. If this option is selected, the cell can serve high-power UEs. If this option is deselected, the cell cannot serve high-power UEs.

UlAntennaSmartSelectSwitch: Indicates whether to enable intelligent selection of antennas for the uplink. If this option is selected, intelligent selection of antennas for the uplink is enabled in the cell. If this option is deselected, intelligent selection of antennas for the uplink is disabled in the cell. This option applies only to LTE TDD.

UlQosEnhancementSwitch: Indicates whether to enable uplink QoS enhancement. If this option is selected, uplink QoS enhancement is enabled in the cell. If this option is deselected, uplink QoS enhancement is disabled in the cell. This option applies only to LTE FDD and LTE TDD.

UlClosedloopIntelAntSelSwitch: Indicates whether to enable intelligent uplink closed-loop antenna selection. If this option is selected, intelligent uplink closed-loop antenna selection is supported in the cell. If this option is deselected, intelligent uplink closed-loop antenna selection is not supported in the cell. This option applies only to LTE TDD.

Tm9Port5Switch: Indicates whether to allow the use of port 5 for data transmission in TM9. If this option is selected, antenna port 5 can be allocated for data transmission in TM9. If this option is deselected, antenna port 5 cannot be allocated for data transmission in TM9. This option applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • HighPowerUESupportSwitch option of SpecUserCooperationSwitch parameter in a UeCooperationPara MO can be selected only if the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch in the UeCooperationPara MO is selected.
  • The UlAntennaSmartSelectSwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO can be selected only when the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.
  • When the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in a UeCooperationPara MO is selected, the VoltePagingPriority parameter in the UeCooperationPara MO can be set to a value other than OFF.
  • The SpecUserSmartDrxSwitch parameter in the UeCooperationPara MO can be set to ON only when the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.

Impact on Radio Network Performance

SpecUeIdentifySwitch: This option controls the basic function for enhanced device-pipe synergy functions. If this option is selected, the eNodeB broadcasts UE-specific identification information through system information, slightly increasing the downlink RB usage. If this option is deselected, enhanced device-pipe functions are disabled, and network performance is not affected.

HighPowerUeSupportSwitch: If this option is selected, the maximum transmit power of specific UEs increases. As a result, the uplink throughput of these specific UEs increases, but the uplink IoT also slightly increases. If this option is deselected, support for high-power UEs is disabled, and the uplink throughput of such UEs cannot be improved.

UlAntennaSmartSelectSwitch: If this option is selected, the uplink signal quality of specific UEs can be improved, and the uplink throughput of such specific UEs can be improved. If this option is deselected, intelligent selection of transmit antennas is disabled, and the uplink signal quality cannot be improved for specific UEs.

UlQosEnhancementSwitch: If this option is selected, VoLTE quality can be improved for indoor UEs in LampSite Libero scenarios. If this option is deselected, uplink QoS enhancement is disabled in LampSite Libero scenarios, and VoLTE quality cannot be improved for indoor UEs in such scenarios.

UlClosedloopIntelAntSelSwitch: If this option is selected, the eNodeB selects the antenna with the best signal quality as the uplink transmit antenna based on the uplink signal quality of each antenna of a specific UE, improving the uplink throughput of this UE. If this option is deselected, intelligent uplink closed-loop antenna selection does not take effect, affecting uplink signal quality improvement for specific UEs.

Tm9Port5Switch: If this option is selected, antenna port 5 can be used for data transmission in TM9 for specific UEs, increasing the throughput of these UEs. If this option is deselected, antenna port 5 cannot be used for data transmission in TM9 for specific UEs, preventing throughput increase for these UEs.
