Meaning

Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
