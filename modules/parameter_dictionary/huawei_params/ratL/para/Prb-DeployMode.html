Meaning

Indicates the NB-IoT PRB deployment mode. STAND_ALONE indicates that out-of-band LTE spectrum resources are used to deploy NB-IoT PRB. GUARD_BAND indicates that NB-IoT PRB is deployed on the LTE guardband. IN_BAND indicates that PRB is deployed on the LTE RB resources, which means that fewer RBs are available for LTE. This parameter applies only to NB-IoT.

Parameter Relationship

-Configuration constraints:

  • When the AnchorCarrierFlag and DeployMode parameters in a Prb MO are set to TRUE and IN_BAND, respectively: For other PRBs with the same LocalCellId, if the AnchorCarrierFlag and DeployMode parameters are set to FALSE and IN_BAND, respectively, the LteCellId parameter must be the same as that in the Prb MO instance with AnchorCarrierFlag set to TRUE.
  • When the AnchorCarrierFlag and DeployMode parameters in a Prb MO are set to TRUE and GUARD_BAND, respectively: For PRBs with the same LocalCellId in the Prb MO, if the AnchorCarrierFlag and DeployMode parameters are set to FALSE and GUARD_BAND, respectively, the LteDlEarfcn and LteBandWidth must be the same as the LteDlEarfcn and LteBandWidth parameters in the Prb MO instance with AnchorCarrierFlag set to TRUE.
  • If the DeployMode and AnchorCarrierFlag parameters in a Prb MO are set to STAND_ALONE and TRUE, respectively, the DlFreqOffset parameter in this Prb MO must be set to NEG_0DOT5. If the DeployMode parameter in a Prb MO is not set to STAND_ALONE, the AnchorCarrierFlag parameter in this Prb MO is set to TRUE, and the LteDlRbIndex parameter in this Prb MO is set to an invalid value, then the DlFreqOffset parameter in this Prb MO must be set to NEG_2, NEG_1, POS_0, or POS_1.
  • If the DeployMode parameter in the Prb MO is set to IN_BAND and the OtdoaSwitch option of the LcsSwitch parameter in the ENodeBAlgoSwitch MO and the NB_OTDOA_SWITCH option of the CellLcsSwitch parameter in the CellLcsCfg MO are selected, the NprsId parameter (if not set to 65535) in the EuPrbSectorEqm MO must be set to the same value as the PhyCellId parameter in the Cell MO for the LTE cell associated with the NB-IoT cell, or has a different mod 6 value from the PhyCellId parameter.
  • When the DeployMode parameter in a Prb MO is STAND_ALONE or GUARD_BAND, the NbDlBitmapSize parameter in the associated PrbSchConfig MO must be set to SF10.
  • When the DeployMode parameter in a Prb MO is IN_BAND, the NprsSubframeConfigMode parameter in the associated CellNprsCfg MO must not be set to PART_B.
  • In a Prb MO, if the DeployMode parameter is set to STAND_ALONE, the WorkMode parameter is set to UL_DL, and the DlFreqOffset parameter is not set to NEG_0DOT5, then the UlEarfcnCfgInd parameter in this Prb MO must be set to CFG.
  • Among the Prb MOs (under a Cell MO) in which DeployMode is set to STAND_ALONE, the downlink center frequencies of the PRBs specified by the Prb MOs in which WorkMode is set to UL_DL or DL_ONLY and AnchorCarrierFlag is set to FALSE must all be greater than or less than the downlink center frequencies of PRBs specified by the Prb MOs in which AnchorCarrierFlag is set to TRUE, when the following conditions are met: (1). The number of Prb MOs in which DeployMode is set to STAND_ALONE is greater than 2 and AnchorCarrierFlag is set to TRUE in at least one of these MOs. (2). The difference between the downlink center frequencies of the PRBs specified by the Prb MO in which WorkMode is set to UL_DL or DL_ONLY and AnchorCarrierFlag is set to FALSE and those of the PRBs specified by the Prb MOs in which AnchorCarrierFlag is set to TRUE is not an integer multiple of 15 kHz.
  • The spacing between the downlink center frequencies of the PRBs meeting the following conditions must be an integer multiple of 15 kHz: In the Prb MOs for these PRBs, the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or DL_ONLY, the DeployMode parameters are set to STAND_ALONE, and the AnchorCarrierFlag parameters are set to FALSE.
  • If the number of Prb MOs in which the LocalCellId parameters are set to the same value and the DeployMode parameters are set to STAND_ALONE are greater than two, the spacing between the uplink center frequencies of the PRBs specified in the Prb MOs in which the WorkMode parameters are set to UL_DL or UL_ONLY must be an integer multiple of 15 kHz.
  • In a Prb MO, if WorkMode is set to UL_DL, DeployMode is set to IN_BAND, and UlEarfcnCfgInd is set to CFG, then LteDlRbIndex and LteUlRbIndex must be both set to invalid or valid values.
