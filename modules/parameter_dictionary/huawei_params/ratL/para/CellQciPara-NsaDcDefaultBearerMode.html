Meaning

Indicates the type of bearers to be set up for UEs that access the cell or are handed over to the cell in the LTE-NR NSA DC architecture.

If this parameter is set to SCG_SPLIT_BEARER, SCG split bearers are set up for UEs by default.

If this parameter is set to MCG_SPLIT_BEARER, MCG split bearers are set up for UEs by default.

If this parameter is set to MCG_BEARER, MCG bearers using the NR PDCP are set up for UEs by default. The NR PDCP complies with 3GPP TS 38.323.

If this parameter is set to MCG_BEARER_EUTRA_PDCP, MCG bearers using the E-UTRA PDCP are set up for UEs by default. The E-UTRA PDCP complies with 3GPP TS 36.323.

In separate-MPT co-transmission scenarios, split bearers are set up at the co-transmission port. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the Qci parameter is set to 1 or 5, the NsaDcDefaultBearerMode parameter must be set to MCG_BEARER or MCG_BEARER_EUTRA_PDCP.
  • The NsaDcDefaultBearerMode parameter cannot be set to MCG_SPLIT_BEARER if the Qci parameter is set to one of the following values: 2, 3, 4, 65, 66, 67, 75, 82, 83, 84, and 85.
