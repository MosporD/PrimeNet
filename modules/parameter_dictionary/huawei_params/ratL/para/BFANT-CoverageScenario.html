Meaning

Indicates the coverage scenario of a massive MIMO antenna. This parameter is used to adjust the antenna beam pattern. The values EXPANDSCENARIO_1, EXPANDSCENARIO_2, and EXPANDSCENARIO_3 indicate user-defined coverage scenarios. For 64T64R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. For 32T32R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_5, SCENARIO_6, SCENARIO_7, SCENARIO_8, SCENARIO_9, SCENARIO_15, or SCENARIO_17. Due to the limited vertical beamwidth of a single 32T32R channel, it is not recommended that this parameter be set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. This parameter applies only to LTE TDD.
