NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD PRBRACHCECONFIG

LST PRBRACHCECONFIG
Meaning

Indicates the probability of random access on the anchor carrier for UEs supporting multi-carrier access. If this parameter is set to ONE, UEs perform random access only on an anchor carrier. This parameter is valid only for anchor carriers. This parameter applies only to NB-IoT.
