MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates the threshold of the number of SgNB additions for automatically removing X2 interfaces based on NSA X2 usage. If the measured number of successful SgNB additions corresponding to an X2 interface within a timer length is less than or equal to this threshold and no NSA UEs use the X2 interface, automatic removal of this X2 interface is triggered. This parameter applies only to LTE FDD and LTE TDD.

Disuse statement: This parameter has been replaced by the X2SonDeleteGnbAddCntThld parameter in the EnodeBAlgoExtSwitch MO and will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

Impact on Radio Network Performance

A smaller value of this parameter results in a stricter condition for automatic X2 removal based on NSA X2 usage. X2 interfaces with low usage may be retained, and therefore new NSA X2 interfaces fail to be added. A larger value of this parameter results in a less strict condition. NSA X2 interfaces may be mistakenly removed and then added back, causing ping-pong removal and addition.
