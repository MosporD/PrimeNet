Meaning

Indicates the length of the UE inactivity timer for NB-IoT UEs that have bearers of a QCI. If the eNodeB detects that an NB-IoT UE has neither received nor sent data for a period exceeding the value of this parameter, the eNodeB releases the RRC connection for this UE. The parameter value 65535 indicates an invalid timer. In this case, the UE inactivity timer specified by the NBUeInactiveTimer parameter in the RrcConnStateTimer MO takes effect for the NB-IoT UEs. This parameter takes effect only for UEs that access the network after the parameter is set. If a UE has bearers of several QCIs, the eNodeB selects the longest QCI-specific UE inactivity timer with the highest priority as the UE inactivity timer for the UE. The QCI-specific priority of a QCI-specific UE inactivity timer is specified by the UeInactiveTimerPri parameter. This parameter applies only to NB-IoT.

Disuse statement: This parameter is replaced by the TimerDuration parameter in the QciUeTimerConfig MO with the TimerType parameter set to NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, or NB_CL2_UE_INACTIVITY_TIMER and will be deleted in later versions. (Although the configuration interface in this version supports delivery of the setting of this parameter, the system no longer uses this parameter.) Therefore, avoid using this parameter.

Impact on Radio Network Performance

A smaller value of this parameter results in earlier RRC connection releases for NB-IoT UEs without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger value of this parameter results in later RRC connection releases for NB-IoT UEs without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.
