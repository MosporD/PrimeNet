Meaning

Indicates whether to allow the upperLayerIndication-r15 IE to be broadcast in SIB2.

If this parameter is set to ON, the upperLayerIndication-r15 IE can be broadcast in SIB2. However, whether the upperLayerIndication-r15 IE for a PLMN can be broadcast in the E-UTRAN cell is subject to the setting of the UPPER_LYR_IND_NO_BROADCAST_SW option of the CnOperator.OperatorFunSwitch parameter. The upperLayerIndication-r15 IE for a PLMN can be broadcast in SIB2 only if this option is deselected.

If this parameter is set to NR_NCELL_BASED_BROADCAST, the upperLayerIndication-r15 IE can be broadcast in SIB2 only when the E-UTRAN cell is configured with at least one neighboring NG-RAN cell. However, whether the upperLayerIndication-r15 IE for a PLMN can be broadcast in the E-UTRAN cell is subject to the setting of the UPPER_LYR_IND_NO_BROADCAST_SW option of the CnOperator.OperatorFunSwitch parameter. The upperLayerIndication-r15 IE for a PLMN can be broadcast in SIB2 only if this option is deselected.

If this parameter is set to OFF, the upperLayerIndication-r15 IE cannot be broadcast in SIB2. That is, the upperLayerIndication-r15 IE for any PLMN will not be broadcast in the E-UTRAN cell, regardless of the setting of the UPPER_LYR_IND_NO_BROADCAST_SW option of the CnOperator.OperatorFunSwitch parameter.

This parameter applies only to LTE FDD and LTE TDD.
