Meaning

Indicates whether to enable congestion control algorithms for machine type communication (MTC), enhanced Machine Type Communication (eMTC), and NB-IoT UEs.

EABAlgoSwitch: Indicates whether to enable extended access barring (EAB). When EAB is enabled, an eNodeB implements access class control for EAB-applicable UEs if the E-UTRAN or core network is overloaded. EAB is enabled only if this option is selected. When MtcSwitch is set to ON, you are advised to select the EABAlgoSwitch option to reduce the impact caused by a large number of MTC UEs.

ExtendedwaittimeSwitch: Indicates whether the eNodeB includes the extendedWaitTime parameter into the message sent to UEs when the UEs' RRC connection setup requests are rejected or their RRC connections are released due to core network overload. If this option is selected, the eNodeB includes the extendedWaitTime parameter into the message sent to UEs in either of the following conditions: (a) After receiving an overload message from the MME, the eNodeB rejects the RRC connection setup requests with the cause value DelayTolerant or releases the RRC connections with the cause value DelayTolerant. (b) The eNodeB releases the RRC connections when the NB-IoT cell is congested. If this option is deselected, the eNodeB does not include the extendedWaitTime parameter into the message sent to UEs in the preceding situations. In an NB-IoT cell, this option also specifies whether to enable the overload control function for RRC connection request messages and connection resume messages.

Impact on Radio Network Performance

EABAlgoSwitch: When this option is selected, the eNodeB delivers or stops delivering SIB14 based on the cell load status. SIB14 contains EAB parameters, which are used for access class control over EAB-applicable UEs. The adaptive delivery of SIB14 helps reduce cell load; however, access experience is affected if UEs' access is barred. When this option is deselected, the eNodeB does not deliver SIB14 or implement access class control over EAB-applicable UEs based on cell load status. As a result, the cell load is not reduced.

ExtendedwaittimeSwitch: When this option is selected, the eNodeB includes the extendedWaitTime parameter into the message sent to UEs in the situations described previously. Before the time specified by the extendedWaitTime parameter expires, these UEs cannot initiate RRC connection setup requests with the cause value DelayTolerant. When this option is deselected, the eNodeB does not include the extendedWaitTime parameter into the message sent to UEs in the preceding situations.
