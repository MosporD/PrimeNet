Meaning

Indicates which type of high-load cells cannot be configured as SCells. If this parameter is set to MASSIVE_MIMO_CELL, a high-load massive MIMO cell cannot be configured as an SCell when this massive MIMO cell cannot be configured as an uplink SCell for a CA UE or the CA UE cannot be paired with other UEs in this massive MIMO cell. If this parameter is set to NORMAL_CELL, high-load common cells (except LAA cells) cannot be configured as SCells. If this parameter is set to ALL_CELL, both of the MASSIVE_MIMO_CELL and NORMAL_CELL values take effect. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to MASSIVE_MIMO_CELL, high-load massive MIMO cells are not configured as SCells. In this case, the average number of paired layers in massive MIMO cells may increase, and fewer CA UEs treat massive MIMO cells as SCells. If this parameter is set to NORMAL_CELL, high-load common cells are not configured as SCells, and fewer CA UEs treat common cells as SCells. If this parameter is set to ALL_CELL, no high-load cells are configured as SCells. In this case, the average number of paired layers in massive MIMO cells may increase, fewer CA UEs treat massive MIMO cells as SCells, and fewer CA UEs treat common cells as SCells.
