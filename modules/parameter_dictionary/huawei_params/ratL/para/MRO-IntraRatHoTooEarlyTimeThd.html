Meaning

Indicates the duration threshold for determining whether an abnormal intra-RAT handover due to an unstable target cell. If the time during which a UE camps on a cell after an intra-RAT handover is less than or equal to this parameter value, the eNodeB considers that the cell is unstable.

A larger value of this parameter results in a higher probability that intra-RAT MRO determines intra-RAT handovers as premature handovers and adjusts parameters to reduce the number of premature handovers. This decreases the number of handovers and increases the probability of delayed handovers.

A smaller value of this parameter results in a higher probability that intra-RAT MRO determines intra-RAT handovers as delayed handovers and adjusts parameters to reduce the number of delayed handovers. This increases the number of handovers.

For details, see descriptions of "short time" in "Intra-RAT MRO use case" in 3GPP TS 36.300. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of parameter results in a higher probability that intra-RAT handovers are determined as premature handovers based on MRO, and a higher probability that optimization on premature handovers is triggered, which in turn decreases the number of handover attempts and increases the probability of delayed handovers.

A smaller value of this parameter results in a higher probability that intra-RAT handovers are determined as delayed handovers based on MRO and a higher probability that optimization on delayed handovers is triggered, which in turn increases the number of handover attempts.
