Meaning

Indicates whether to enable interference avoidance in the cell.

AvoidGeranInterfSwitch: Indicates whether to enable the GSM and LTE buffer zone optimization feature. If this option is selected, the feature is enabled.

Before selecting this option, pay attention to the following:

1. Change the uplink and downlink bandwidths of the LTE cell in advance to the immediate higher level of standard bandwidth. For example, if the current uplink and downlink bandwidths of the LTE cell are 15 MHz, change them to 20 MHz.

2. It is recommended that this option be deselected if the cell bandwidth is 1.4 MHz, 3 MHz, 5 MHz, or 10 MHz.

3. To avoid co-channel interference from GERAN cells to the PUCCH, select the PucchFlexCfgSwitch option of the PucchAlgoSwitch parameter.

TddAvoidUpPTSInterfSwitch: Indicates whether to enable UpPTS interference detection and avoidance. If this option is selected, UpPTS interference detection and avoidance are enabled for LTE TDD.

AvoidPrachInterfSwitch: Indicates whether to enable PRACH interference avoidance in the frequency domain. If this option is selected, PRACH interference avoidance in the frequency domain is enabled for LTE TDD.

AvoidUtranInterfSwitch: Indicates whether to enable the UMTS and LTE buffer zone optimization feature. If this option is selected, the feature is enabled. This option applies only to LTE FDD.

IntraBandInterfMonitorSwitch: Indicates whether to enable in-band interference monitoring. In-band interference monitoring is enabled for the cell only if this option is selected. The setting of this option does not take effect for LTE TDD cells established on LBBPc boards or LTE FDD cells established on LBBPc and LBBPd boards.

AvoidSpurEmissInterfSwitch: Indicates whether to enable spurious interference avoidance. If this option is selected, spurious interference avoidance is enabled. This option applies only to LTE FDD.

UlInterfSuppressionSwitch: Indicates whether to automatically adjust uplink power control parameters based on interference and perform conservative scheduling for access signaling. If this option is selected, uplink power control parameters are automatically adjusted based on interference, and conservative scheduling is performed for access signaling. This option applies only to LTE TDD.

AvoidCDMAInterfSwitch: Indicates whether to enable the CDMA and LTE zero buffer zone feature. It is recommended that this option be selected at the buffer zone of CDMA and LTE refarming. Because of frequency band differences between RATs, the CDMA and LTE zero buffer zone feature is mutually exclusive with the GL DSS, GSM and LTE zero buffer zone, and UMTS and LTE buffer zone optimization features. You are advised not to enable CDMA and LTE zero buffer zone with GL DSS, GSM and LTE zero buffer zone, or UMTS and LTE buffer zone optimization. This option applies only to LTE FDD.

AvoidCrsConflictInterfSw: Indicates whether to enable interference avoidance optimization when CRS conflicts occur due to inter-cell D-MIMO. If this option is selected, interference avoidance optimization takes effect when CRS conflicts occur. If this option is deselected, interference avoidance optimization does not take effect when CRS conflicts occur. This option applies only to LTE TDD. To deploy inter-cell D-MIMO, PCIs must be replanned, which causes interference due to CRS conflicts. It is recommended that this option be selected if inter-cell D-MIMO causes CRS conflicts and be deselected in other CRS conflict scenarios.

Sa1Sa2InterfCoordSwitch: Indicates whether to enable interference coordination for cells with uplink-downlink subframe configuration 1 or 2. Interference coordination is enabled for such cells only if this option is selected. This option applies only to LTE TDD.

Impact on Radio Network Performance

AvoidGeranInterfSwitch: If this option is deselected, the LTE spectrum does not overlap with the GSM spectrum and accordingly network KPIs are not affected. If this option is selected, the available bandwidth of the E-UTRAN cell increases. In this situation, more RBs can be dynamically used to improve the average cell throughput based on whether UEs can resist GERAN interference. However, because the LTE spectrum may overlap with the GSM spectrum, the access success rate and handover success rate may drop, and the service drop rate may increase.

TddAvoidUpPTSInterfSwitch: If this option is deselected, downlink beamforming does not take effect for CEUs when UpPTS interference is severe. If this option is selected, the eNodeB adjusts the SRSs originally transmitted on the UpPTS to common uplink subframes after severe UpPTS interference occurs, and downlink beamforming becomes effective for CEUs. After SRSs are adjusted to common uplink subframes, the last symbol in each uplink subframe cannot be used to transmit the PUSCH. Only 10 instead of 11 symbols are used to transfer data in each uplink subframe after SRSs are adjusted to the uplink subframe. If the number of RBs used by a UE and the MCS index remain unchanged, the uplink throughput of the UE decreases by 9% under the worst conditions.

AvoidPrachInterfSwitch: If this option is deselected, PRACH modulation quality is poor if severe PRACH interference occurs, and access to the cell becomes difficult for UEs. If this option is selected, the eNodeB moves the PRACH to a frequency domain position with weak interference if severe PRACH interference occurs, improving PRACH modulation quality and UE access experience.

AvoidUtranInterfSwitch: If this option is deselected, LTE uplink scheduling may cause strong interference to UMTS intra-frequency neighboring cells in the uplink. If this option is selected, the eNodeB restricts uplink RB scheduling to reduce interference to UMTS intra-frequency neighboring cells, which reduces LTE uplink capacity.

AvoidSpurEmissInterfSwitch: If this option is deselected, the eNodeB does not perform differentiated UE scheduling on uplink RBs with severe interference, lowering the throughput of CEUs that are scheduled on such RBs, access success rate, and handover success rate while increasing the service drop rate. If this option is selected, the eNodeB schedules only UEs between the cell center and edge or not at the cell edge on uplink RBs with severe interference. In this case, the access success rate and handover success rate increase, and the service drop rate decreases, but LTE uplink capacity is affected.

UlInterfSuppressionSwitch: If this option is selected, KPIs such as the service drop rate and the handover success rate are optimized when uplink interference exceeds the value of the UlInterfsuppressionThd parameter in the UlInterfSuppressCfg MO.

AvoidCDMAInterfSwitch: If this option is selected, the eNodeB restricts uplink and downlink RB scheduling to alleviate interference to CDMA intra-frequency neighboring cells, reducing LTE uplink and downlink capacity. If this option is deselected, LTE uplink and downlink scheduling may cause strong interference to CDMA intra-frequency neighboring cells in the uplink and downlink.

TddAvoidUpPTSInterfSwitch: If this option is selected, the eNodeB automatically reestablishes cells when interference occurs or required signal quality recovers from deterioration due to interference.

AvoidCrsConflictInterfSw: If this option is selected, interference between cells with CRS conflicts decreases, improving the experience of CEUs in the cells. If this option is deselected, no optimization is performed to avoid inter-cell interference to cells when CRS conflicts occur, and the interference causes lowering of the MCS index and deterioration of user experience.

IntraBandInterfMonitorSwitch: If this option is selected, the eNodeB checks whether there is in-band interference in uplink muted subframes (there is one muted radio frame each 512 radio frames), and the uplink throughput decreases by a maximum of 0.2%.

Sa1Sa2InterfCoordSwitch: During key event assurance on a network consisting of cells with different uplink-downlink configurations, selecting this option will increase the uplink and downlink throughput of cells with uplink-downlink configuration 1 and decrease the uplink and downlink throughput of cells with uplink-downlink configuration 2, and deselecting this option has no impact on network performance. Any modification to the setting of this option will lead to an automatic cell reset.
