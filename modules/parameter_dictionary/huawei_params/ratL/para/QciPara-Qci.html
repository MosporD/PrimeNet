Meaning

Indicates the QCI, which is an attribute of EPS bearers. Different QCIs represent different QoS specifications such as the packet delay budget, packet loss rate (PLR) and packet error rate (PER), and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203.
