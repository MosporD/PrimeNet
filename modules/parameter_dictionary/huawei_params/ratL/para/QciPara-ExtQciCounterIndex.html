Meaning

Indicates the counter index to which the extended QCI is mapped. If this parameter is set to Index0, the counters (for example, uplink PDCP-layer service traffic volume) related to this extended QCI can be observed by the mapping counters (for example, the L.Thrp.bits.UL.ExtQCI.Index0 counter). If this parameter is set to NO_COUNTER, performance about this extended QCI is not measured. Each extended QCI can be mapped to a counter index. This parameter can be set to NO_COUNTER for different extended QCIs, and this parameter cannot be set to the same value other than NO_COUNTER for any two extended QCIs. This parameter takes effect only when a new extended QCI is added.

Parameter Relationship

-Configuration constraints:

  • ExtQciCounterIndex in different QciPara MOs can be set to NO_COUNTER. ExtQciCounterIndex cannot be set to the same value other than NO_COUNTER in any two QciPara MOs. ExtQciCounterIndex does not take effect when the QCI is 1 to 9, 65, 66, 69, 70, 75 or 79.

-Parameter relationship with conditions:

  • If Qci is set to 10~64, 67~68, 71~74, 76~78, 80~254, ExtQciCounterIndex is valid.
