MML Command

MOD CELLULICIC

LST CELLULICIC
Meaning

Indicates the band division scheme used in uplink ICIC. The band division in the cell is changed according to the setting of this parameter so that the edge bands do not overlap between neighboring cells. If this parameter is set to INVALID, the cell does not distinguish center and edge bands. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

If this parameter is not set to INVALID(Invalid UL band division scheme), it is recommended that this parameter be set to different values in neighboring cells. If it is impossible for neighboring cells to use mutually different band modes, it is recommended that this parameter be set to the same value in neighboring cells that has the weakest interference to each other.
