Meaning

Indicates the working mode of the carrier for an NB-IoT cell. This parameter must be set to UL_DL for the anchor carrier. This parameter applies only to NB-IoT.

Parameter Relationship

-Configuration constraints:

  • The differences between the downlink frequencies of the PRBs specified in the Prb MOs in which the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or DL_ONLY, and the DeployMode parameters are set to STAND_ALONE must not be greater than the result of 20 MHz minus 200 kHz.
  • The differences between the uplink frequencies of the PRBs specified in the Prb MOs in which the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or UL_ONLY, and the DeployMode parameters are set to STAND_ALONE must not be greater than the result of 20 MHz minus 200 kHz.
  • If AnchorCarrierFlag in a Prb MO is set to TRUE, WorkMode in this Prb MO must be set to UL_DL.
  • In a Prb MO, if the DeployMode parameter is set to STAND_ALONE, the WorkMode parameter is set to UL_DL, and the DlFreqOffset parameter is not set to NEG_0DOT5, then the UlEarfcnCfgInd parameter in this Prb MO must be set to CFG.
  • Among the Prb MOs (under a Cell MO) in which DeployMode is set to STAND_ALONE, the downlink center frequencies of the PRBs specified by the Prb MOs in which WorkMode is set to UL_DL or DL_ONLY and AnchorCarrierFlag is set to FALSE must all be greater than or less than the downlink center frequencies of PRBs specified by the Prb MOs in which AnchorCarrierFlag is set to TRUE, when the following conditions are met: (1). The number of Prb MOs in which DeployMode is set to STAND_ALONE is greater than 2 and AnchorCarrierFlag is set to TRUE in at least one of these MOs. (2). The difference between the downlink center frequencies of the PRBs specified by the Prb MO in which WorkMode is set to UL_DL or DL_ONLY and AnchorCarrierFlag is set to FALSE and those of the PRBs specified by the Prb MOs in which AnchorCarrierFlag is set to TRUE is not an integer multiple of 15 kHz.
  • The spacing between the downlink center frequencies of the PRBs meeting the following conditions must be an integer multiple of 15 kHz: In the Prb MOs for these PRBs, the LocalCellId parameters are set to the same value, the WorkMode parameters are set to UL_DL or DL_ONLY, the DeployMode parameters are set to STAND_ALONE, and the AnchorCarrierFlag parameters are set to FALSE.
  • If the number of Prb MOs in which the LocalCellId parameters are set to the same value and the DeployMode parameters are set to STAND_ALONE are greater than two, the spacing between the uplink center frequencies of the PRBs specified in the Prb MOs in which the WorkMode parameters are set to UL_DL or UL_ONLY must be an integer multiple of 15 kHz.
  • In a Prb MO, if WorkMode is set to UL_DL, DeployMode is set to IN_BAND, and UlEarfcnCfgInd is set to CFG, then LteDlRbIndex and LteUlRbIndex must be both set to invalid or valid values.

Caution

Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

If this parameter is set to DL_ONLY for a carrier, the number of uplink carriers and that of downlink carriers for the cell will be unbalanced, causing uplink throughput of the cell to decrease. The paging success rate also decreases if a large number of UEs are paged.

If this parameter is set to UL_ONLY for a carrier, the number of uplink carriers and that of downlink carriers for the cell will be unbalanced, causing downlink throughput of the cell to decrease. The access success rate also decreases if a large number of UEs attempt to access the cell.
