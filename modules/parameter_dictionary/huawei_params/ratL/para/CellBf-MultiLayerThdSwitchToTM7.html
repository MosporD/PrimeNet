Meaning

Indicates the threshold of the number of pairing layers for switching the UE transmission mode to TM7. If the number of layers of UEs to be paired in the cell reaches this threshold, the eNodeB switches the transmission mode of TM8, open-loop TM9, and MIMO UEs to TM7 to achieve more pairing gains. Set this parameter based on network conditions such as the downlink cell load. The value 0 indicates that this function does not take effect. This parameter indicates the threshold of the number of UEs to be scheduled in the downlink when the DmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected and downlink D-MIMO takes effect. If the number of UEs to be scheduled in the downlink reaches this threshold, the transmission mode of UEs that newly access the network and UEs newly handed over to the cell quickly switches to TM7, TM8, or open-loop TM9. The value 0 indicates the function does not take effect. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

A small value of this parameter leads to a high probability of switching the UE transmission mode to TM7 when transmission mode adaptation is enabled. A large value of this parameter leads to a low probability of switching the transmission mode to TM7 when transmission mode adaptation is enabled. If this parameter is set to a small value when multi-layer pairing can be performed, the eNodeB is more likely to switch the UE transmission mode to TM7 for multi-user pairing, increasing the cell throughput.

If this parameter is set to a small value when multi-layer pairing cannot be performed, UEs cannot be paired even when their transmission mode is switched to TM7, decreasing the cell throughput. Therefore, you are advised to set this parameter to a large value when multi-layer pairing cannot be performed.

If downlink D-MIMO takes effect and the network is heavily loaded, a small value of this parameter leads to a high probability of switching the transmission mode of UEs that newly access the network and UEs newly handed over to the cell to TM7, TM8, or open-loop TM9, increasing the pairing probability.
