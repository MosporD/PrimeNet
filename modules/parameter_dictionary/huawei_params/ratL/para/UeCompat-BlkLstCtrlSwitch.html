Parameter ID BlkLstCtrlSwitch
Parameter Name

Black List Control Switch

MML Command

ADD UECOMPAT

MOD UECOMPAT

LST UECOMPAT
Meaning

Indicates whether to blacklist some features.

LTE_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: intra-RAT event-triggered ANR, intra-RAT fast ANR, active PCI conflict detection, ANR based on specified PCI groups, and E-UTRAN measurement functions controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

UTRAN_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: event-triggered ANR with UTRAN, fast ANR with UTRAN, and UTRAN measurements controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

GERAN_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: event-triggered ANR with GERAN, fast ANR with GERAN, and GERAN measurements controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

CDMA_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: fast ANR with CDMA2000 and event-triggered ANR with CDMA2000. This option applies only to LTE FDD and LTE TDD.

DYNAMIC_DRX_SWITCH_OFF: If this option is selected, dynamic DRX is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

CA_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: SCell configuration and PCC anchoring. This option applies only to LTE FDD and LTE TDD.

TTI_BUNDLING_SWITCH_OFF: If this option is selected, TTI bundling is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

MIMO_TM_MODE_SET: If this option is selected, the MimoAdaptiveSwitch and InitialMimoType parameters are set to OL_ADAPTIVE and ADAPTIVE, respectively, for defective UEs. This option applies only to LTE FDD and LTE TDD.

APERIODIC_CQI_RPT_SWITCH_OFF: If this option is selected, enhanced aperiodic CQI reporting is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

ROHC_SWITCH_OFF: If this option is selected, ROHC is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

DL_2CC_CA_ENHANCE_SWITCH_OFF: If this option is selected, the function of enhanced DL ACK demodulation with two component carriers aggregated is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

DRX_SWITCH_OFF: If this option is selected, DRX for UEs in RRC_CONNECTED mode is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

OSS_INTER_RAT_MR_SWITH_OFF: Indicates whether to disable periodic inter-RAT measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, the eNodeB disables the function for defective UEs. If this option is deselected, the eNodeB does not take measures for defective UEs. This option applies only to LTE FDD and LTE TDD.

OSS_INTER_FREQ_MR_SWITH_OFF: Indicates whether to disable periodic inter-frequency measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, the eNodeB disables the function for defective UEs. If this option is deselected, the eNodeB does not take measures for defective UEs. This option applies only to LTE FDD and LTE TDD.

UL_AMRC_SWITCH_OFF: Indicates whether to disable uplink AMRC for defective UEs. If this option is selected, uplink AMRC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

AUTO_GAP_SWITCH_OFF: Indicates whether to disable automatic gap-assisted measurement configuration of defective UEs. Automatic gap-assisted measurement configuration is disabled for defective UEs only if this option is selected. This option applies only to LTE FDD and LTE TDD.

FORBID_HIGH_CAPABILITY_OFF: Indicates whether the eNodeB forbids capabilities beyond the UE protocol version for defective UEs that comply with 3GPP Release 10 or later. If this option is deselected, capabilities beyond the UE protocol version are allowed to take effect on the eNodeB. If this option is selected, the eNodeB ignores capabilities beyond the UE protocol version that are reported by the UEs. This option applies only to LTE FDD and LTE TDD.

SPS_SWITCH_OFF: Indicates whether the eNodeB disables semi-persistent scheduling in the uplink and downlink for defective UEs. If this option is selected, this function is disabled for the UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTERMODE_FREQ_MEAS_OFF: Indicates whether to disable inter-duplex-mode frequency measurement of defective UEs. If this option is selected, the measurement function is disabled for the UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FLASH_SRVCC_SWITCH_OFF: Indicates whether to disable flash SRVCC for defective UEs. If this option is selected, flash SRVCC is disabled for the UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTER_FREQ_HO_SWITCH_OFF: Indicates whether coverage-based inter-frequency handovers are allowed for blacklisted UEs. If this option is selected, coverage-based inter-frequency handovers are not allowed for blacklisted UEs. The eNodeB performs inter-frequency redirections for such UEs after receiving inter-frequency measurement reports from the UEs. If this option is deselected, coverage-based inter-frequency handovers are allowed for the UEs. The eNodeB performs inter-frequency handovers for the UEs after receiving inter-frequency handovers from the UEs. This option applies only to LTE FDD and LTE TDD.

UL_EVSC_SWITCH_OFF: Indicates whether to disable uplink EVSC for defective UEs. If this option is selected, uplink EVSC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

EICIC_SWITCH_OFF: Indicates whether to disable TDM eICIC for defective UEs. If this option is selected, TDM eICIC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This parameter applies only to LTE FDD and NB-IoT.

OSS_INTRA_FREQ_MR_SWITCH_OFF: Indicates whether to disable periodic intra-frequency measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, this function is disabled for defective UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FLASH_CSFB_SWITCH_OFF: Indicates whether to disable flash CSFB for defective UEs. If this option is selected, flash CSFB is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

MIMO_4T_HANDOVER_SET: Indicates whether to take differentiated measures for incompatible UEs (service-drop UEs) in a 4T cell. If this option is selected, the eNodeB transfers incompatible UEs identified in a 4T cell to inter-frequency cells operating on 2T-cell frequencies through blind redirection. If this option is deselected, the eNodeB does not handle such UEs. This option applies only to LTE FDD.

WTCP_SWITCH_OFF: Indicates whether to disable WTCP for defective UEs. If this option is selected, WTCP is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

256QAM_SWITCH_OFF: Indicates whether to disable downlink 256 QAM for defective UEs. If this option is selected, downlink 256 QAM is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

CSI_RS_ZERO_POWER_OFF: Indicates whether to disable zero-power setting for CSI-RS for defective non-TM9 and non-TM10 UEs that comply with 3GPP R10 or later. If this option is selected, zero-power setting for CSI-RS is not configured for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.

RRC_REEST_DATA_FWD_SWITCH_OFF: Indicates whether to disable data forwarding in RRC connection reestablishment for defective UEs. If this option is selected, data forwarding in RRC connection reestablishment is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

MBSFN_SCHEDULING_SWITCH_OFF: Indicates whether to schedule defective UEs in MBSFN subframes. If this option is selected, it is considered that defective UEs have compatibility issues and cannot be scheduled in MBSFN subframes. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

TM9_SWITCH_OFF: Indicates whether to disable the TM9 capability for defective UEs. If this option is selected, the base station considers the specified UEs to have abnormal TM9 capabilities and processes the UEs as TM9-incapable UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If some UEs on the network do not support some features and thereby network KPIs are affected, turning on corresponding switches can disable related features on defective UEs and therefore the KPIs are improved.

INTERMODE_FREQ_MEAS_OFF: If this option is selected, the number of RRC connection reestablishments of defective UEs decreases and the UEs cannot perform inter-duplex-mode handovers, thereby increasing the possibility of service drops. Deselecting this option has no impact on network performance.

INTER_FREQ_HO_SWITCH_OFF: If this option is selected, the number of times such UEs experience handover failures decreases, the inter-frequency handover success rate increases, the service drop rate decreases, and the ratio of the number of RRC connection reestablishments to the number of UE access procedures increases. Deselecting this option has no impact on network performance.

UL_EVSC_SWITCH_OFF: If this option is selected, uplink EVSC is disabled for blacklisted UEs and speech quality is not affected for these UEs. If this option is deselected, UEs may perform uplink EVSC, improving speech quality in the uplink.

MIMO_4T_HANDOVER_SET: If this option is selected, the eNodeB transfers incompatible UEs (service-drop UEs) identified in a 4T cell to inter-frequency cells operating on 2T-cell frequencies through blind redirection. This decreases the service drop rate of the 4T cell. If this option is deselected, the service drop rate of such UEs deteriorates in the 4T cell.

WTCP_SWITCH_OFF: If the TcpAccelerationSwitch parameter is set to ON and this option is selected, WTCP does not take effect for defective UEs. In this case, the number of service drops decreases and the data rate in the initial TCP phase decreases. If the TcpAccelerationSwitch parameter is set to ON and this option is deselected, WTCP can take effect for defective UEs. In this case, the number of service drops increases and the data rate in the initial TCP phase increases. If the TcpAccelerationSwitch parameter is set to OFF, the setting of this option has no impact on network performance.
