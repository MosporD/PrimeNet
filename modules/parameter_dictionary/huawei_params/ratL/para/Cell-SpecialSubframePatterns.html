Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if FddTddInd is set to CELL_TDD, the following requirements must be met during the setting of UlCyclicPrefix, DlCyclicPrefix, and SpecialSubframePatterns:
  • (1) If UlCyclicPrefix and DlCyclicPrefix are both set to NORMAL_CP, SpecialSubframePatterns can be set to SSP4, SSP5, SSP6, SSP7, SSP9, or NULL;
  • (2) If UlCyclicPrefix and DlCyclicPrefix are both set to EXTENDED_CP, SpecialSubframePatterns can be set to SSP3, SSP4, SSP5, or SSP6;
  • (3) If UlCyclicPrefix is set to EXTENDED_CP and DlCyclicPrefix is set to NORMAL_CP, SpecialSubframePatterns can be set to SSP4, SSP5, SSP6, or SSP7;
  • (4) If UlCyclicPrefix is set to NORMAL_CP and DlCyclicPrefix is set to EXTENDED_CP, SpecialSubframePatterns can be set to SSP3, SSP4, SSP5, or SSP6.
  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo is set to ON, the value of FddTddInd in a CELL MO is only to be set CELL_TDD, and the value of SubframeAssignment in a CELL MO is only to be set SA2, and the value of SpecialSubframePatterns in a CELL MO is only to be set SSP5 or SSP6 or SSP7 or SSP9.
  • In a Cell MO, if NbCellFlag is set to FALSE, FddTddInd is set to CELL_TDD and PreambleFmt is set to 4, SpecialSubframePatterns must be set to a value greater than SSP4.
  • When the FddTddInd and WorkMode parameters in a Cell MO are set to CELL_TDD and LAA, respectively, the SpecialSubframePatterns parameter in this Cell MO must be set to NULL.
  • When the SpecialSubframePatterns parameter in a Cell MO is set to NULL, the FddTddInd and WorkMode parameters in this Cell MO must be set to CELL_TDD and LAA respectively.

-Parameter relationship with conditions:

  • If FddTddInd is set to CELL_TDD, SpecialSubframePatterns must be set.
