Meaning

Indicates the prioritized bit rate of the logical channel. The UE scheduler guarantees prioritized bit rates of logical channels in descending order of logical channel priority. For details, see 3GPP TS 36.321. When the parameter is set to a value greater than PBR_256_KBps and not PBR_INFINITY, the parameter value takes effect on UEs complying with 3GPP R10 or later and PBR_256_KBps takes effect on other UEs. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter indicates a higher prioritized bit rate of logical channels for services with the specific QCI and results in a higher probability that low-priority services fail to be scheduled. If this parameter is set to PBR_INFINITY and the traffic volume of services with the QCI is high, there is a risk that the services with QCIs indicating lower priorities will never be scheduled. A smaller value of this parameter indicates a lower prioritized bit rate of logical channels for services with the QCI and results in a lower probability that low-priority services fail to be scheduled. If this parameter is set to PBR_0_KBps, there is a risk that the services with the corresponding QCI will never be scheduled.
