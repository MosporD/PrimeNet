Meaning

Indicates the uplink bandwidth of the cell. The bandwidth is expressed in the number of RBs. For example, the value CELL_BW_N25 indicates a cell bandwidth of 25 RBs and the value CELL_BW_N50 indicates a cell bandwidth of 50 RBs. For details, see 3GPP TS 36.104. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, when NbCellFlag is set to FALSE and CustomizedBandWidthCfgInd is set to CFG: If UlBandWidth is set to CELL_BW_N6, CustomizedULBandWidth must be set to a value in the range of 12 to 14; If UlBandWidth is set to CELL_BW_N25, CustomizedULBandWidth must be set to a value in the range of 44 to 50; If UlBandWidth is set to CELL_BW_N50, CustomizedULBandWidth must be set to a value in the range of 74, 75, 80 or 87 to 100; If UlBandWidth is set to CELL_BW_N75, CustomizedULBandWidth must be set to a value in the range of 139 to 150; If UlBandWidth is set to CELL_BW_N100, CustomizedULBandWidth must be set to a value in the range of 175 to 178 or 183 to 200.
  • CPRICompression in a Cell MO is set to TRIPLEX_COMPRESSION_10M, FddTddInd in this Cell MO must be set to CELL_FDD, and DlBandWidth and UlBandWidth in this Cell MO must be set to CELL_BW_N50.
  • When the CPRICompression parameter in the Cell MO is set to 3_2_COMPRESSION, the following conditions must be met: (1) If the FddTddInd parameter in this Cell MO is set to CELL_FDD, the TxRxMode and UlBandWidth parameters must be set to 32T32R and CELL_BW_N75 or CELL_BW_N100, respectively. (2) If the FddTddInd parameter in this Cell MO is set to CELL_TDD, the UlBandWidth parameter must be set to CELL_BW_N75 or CELL_BW_N100, respectively.

-Parameter relationship with conditions:

  • If NbCellFlag is set to FALSE, UlBandWidth must be set.

Caution

Changing the value of UlBandWidth may result in CPRI bandwidth insufficiency, which leads to cell unavailability. If the cell is unavailable and the CPRI bandwidth specification is not exceeded, you are advised to block and then unblock the CPRI port for the cell.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
