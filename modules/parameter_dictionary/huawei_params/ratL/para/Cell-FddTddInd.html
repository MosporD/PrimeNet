Parameter Relationship

-Configuration constraints:

  • If the values of the CellActiveState, FddTddInd, and DlBandWidth parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, and CELL_BW_N6, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 4.
  • If the values of the CellActiveState, FddTddInd, TxRxMode, and SubframeAssignment parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, 64T64R, and SA1, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 1, 2, or 3.
  • In a Cell MO, if NbCellFlag is set to FALSE, FddTddInd is set to CELL_TDD and PreambleFmt is set to 4, RootSequenceIdx must be set to a value smaller than or equal to 137.
  • In a Cell MO, if NbCellFlag is set to FALSE, FddTddInd is set to CELL_TDD and PreambleFmt is set to 4, SpecialSubframePatterns must be set to a value greater than SSP4.
  • In a Cell MO, if NbCellFlag is set to FALSE and FddTddInd is set to CELL_TDD, PreambleFmt and SubframeAssignment must adhere to the following constraint:
  • (1) If PreambleFmt is set to 0, SubframeAssignment can be set to SA0, SA1, SA2, SA3, SA5, or NULL;
  • (2) If PreambleFmt is set to 1, SubframeAssignment can be set to SA0, SA1, or SA3;
  • (3) If PreambleFmt is set to 2, SubframeAssignment can be set to SA0, SA1, or SA3;
  • (4) If PreambleFmt is set to 3, SubframeAssignment can be set to SA0 or SA3;
  • (5) If PreambleFmt is set to 4, SubframeAssignment can be set to SA0, SA1, SA2, SA3, or SA5.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_FDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE, SFN or MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • When the CPRICompression and FddTddInd parameters in a Cell MO are set to QUADPLEX_COMPRESSION and CELL_TDD, respectively, the MultiRruCellFlag, MultiRruCellMode, and DlBandWidth in this Cell MO must be set to BOOLEAN_TRUE or CELL_COMBINATION, MPRU_AGGREGATION, and CELL_BW_N75 or CELL_BW_N100, respectively.
  • CPRICompression in a Cell MO is set to TRIPLEX_COMPRESSION_10M, FddTddInd in this Cell MO must be set to CELL_FDD, and DlBandWidth and UlBandWidth in this Cell MO must be set to CELL_BW_N50.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, both UlCyclicPrefix and DlCyclicPrefix must be set to NORMAL_CP.
  • When the CPRICompression parameter in the Cell MO is set to 3_2_COMPRESSION, the following conditions must be met: (1) If the FddTddInd parameter in this Cell MO is set to CELL_FDD, the TxRxMode and UlBandWidth parameters must be set to 32T32R and CELL_BW_N75 or CELL_BW_N100, respectively. (2) If the FddTddInd parameter in this Cell MO is set to CELL_TDD, the UlBandWidth parameter must be set to CELL_BW_N75 or CELL_BW_N100, respectively.
  • In a Cell MO, if FddTddInd is set to CELL_TDD, CustomizedBandWidthCfgInd must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd is set to CELL_TDD, the following requirements must be met during the setting of UlCyclicPrefix, DlCyclicPrefix, and SpecialSubframePatterns:
  • (1) If UlCyclicPrefix and DlCyclicPrefix are both set to NORMAL_CP, SpecialSubframePatterns can be set to SSP4, SSP5, SSP6, SSP7, SSP9, or NULL;
  • (2) If UlCyclicPrefix and DlCyclicPrefix are both set to EXTENDED_CP, SpecialSubframePatterns can be set to SSP3, SSP4, SSP5, or SSP6;
  • (3) If UlCyclicPrefix is set to EXTENDED_CP and DlCyclicPrefix is set to NORMAL_CP, SpecialSubframePatterns can be set to SSP4, SSP5, SSP6, or SSP7;
  • (4) If UlCyclicPrefix is set to NORMAL_CP and DlCyclicPrefix is set to EXTENDED_CP, SpecialSubframePatterns can be set to SSP3, SSP4, SSP5, or SSP6.
  • In a Cell MO, PreambleFmt cannot be set to 4 if NbCellFlag is set to FALSE, FddTddInd is set to CELL_FDD.
  • In a Cell MO, if MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and CELL_COMBINATION, respectively, FddTddInd must be set to TDD.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and MultiRruCellMode in a Cell MO is set to DIGITAL_COMBINATION, FddTddInd in Cell MO must be set to CELL_FDD.
  • In a Cell MO, if CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_FDD, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R. If CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_TDD, TxRxMode must be set to 1T1R, 2T2R, 4T4R, or 8T8R, 64T64R, 32T32R.
  • In a Cell MO, if FddTddInd, CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_TDD, CELL_ACTIVE, BOOLEAN_TRUE, and SFN, respectively, TxRxMode must be set to 2T2R, 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to NORMAL_COMPRESSION, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to ENHANCED_COMPRESSION or TRIPLEX_COMPRESSION_10M, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 8T8R or 32T32R.
  • In a Cell MO, if FddTddInd is set to TDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if FddTddInd is set to FDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R or 2T2R or 1T1R.
  • If FddTddInd, MultiRruCellFlag, and MultiRruCellMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, TxRxMode in the Cell MO must be set to 4T4R, 2T4R, 2T2R, 1T2R or 1T1R.
  • In a Cell MO, if FddTddInd, MultiRruCellFlag, and MultiRruCellMode are set to CELL_FDD, BOOLEAN_TRUE, and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R, 2T2R, or 1T1R.
  • In a Cell MO, if FddTddInd, MultiRruCellFlag and MultiRruCellMode are set to CELL_FDD, BOOLEAN_TRUE and SFN, respectively, DlCyclicPrefix and UlCyclicPrefix must be set to NORMAL_CP.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • In a Cell MO, if TxRxMode and CrsPortNum are set to 4T4R and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 8T2P_00001111, 8T2P_00110011, or 8T2P_01010101.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, or 4T4P_0132.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 8T4P_00112233, or 8T4P_01230123.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_TDD, or if MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_FDD and MultiRruCellMode in the Cell MO is set to a value other than SFN and MPRU_AGGREGATION, CrsPortMap in the Cell MO must be set to NOT_CFG.
  • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, and InterDlCompCbfSwitch or InterDlCompDcsSwitch under the DlCompSwitch parameter in the CellAlgoSwitch MO is set to 1, IntraDlCompSwitch under the DlCompSwitch parameter in the CellAlgoSwitch MO must be set to 1.
  • If the FddTddInd in Cell MO is set to CELL_TDD, the TaEnhancePuschDmrs option of TaEnhance must be deselected.
  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo is set to ON, the value of FddTddInd in a CELL MO is only to be set CELL_TDD, and the value of SubframeAssignment in a CELL MO is only to be set SA2, and the value of SpecialSubframePatterns in a CELL MO is only to be set SSP5 or SSP6 or SSP7 or SSP9.
  • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, and TxRxMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, MPRU_AGGREGATION, and 4T4R, respectively, CrsPortNum in the Cell MO must be set to CRS_PORT_4 with NbCellFlag set to FALSE, or CrsPortNum in the Cell MO must be set to CRS_PORT_2 with NbCellFlag set to TRUE.
  • When the FddTddInd parameter in the Cell MO is set to CELL_TDD and the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, the EuCellStandbyMode and MultiRruCellFlag parameters in the Cell MO must be set to ACTIVE and BOOLEAN_FALSE respectively.
  • In a Cell MO, if FddTddInd is CELL_FDD and CPRICompression is ENHANCED_COMPRESSION, DlBandWidth can be set to CELL_BW_N50, CELL_BW_N75, CELL_BW_N100.
  • In a Cell MO, if FddTddInd is CELL_FDD and CPRICompression is NORMAL_COMPRESSION, DlBandWidth can be set to CELL_BW_N25, CELL_BW_N50, CELL_BW_N75, CELL_BW_N100.
  • When FddTddInd in a Cell MO is set to CELL_TDD, MeasPerformanceDemand in an EutranInterNFreq MO associated with this Cell MO must not be set to UNDELIVER.
  • In a Cell MO, if FddTddInd, TxRxMode are set to CELL_FDD, 8T8R, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, and MultiCellShareMode is set to NORMAL, CrsPortNum must be set to CRS_PORT_4 or CRS_PORT_2.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, HighSpeedFlag must be set to LOW_SPEED.
  • In a Cell MO, if FddTddInd is set to CELL_TDD and UlEarfcnCfgInd is set to CFG, DlEarfcn and UlEarfcn must be set to the same value.
  • In a Cell MO, SubframeAssignment can be set to SA0, SA1, SA2, SA3, SA5, or NULL, if FddTddInd is set to CELL_TDD.
  • In a Cell MO, WorkMode must be set to UL_DL or LAA if FddTddInd is set to CELL_TDD.
  • When the FddTddInd and WorkMode parameters in a Cell MO are set to CELL_TDD and LAA, respectively, the SubframeAssignment parameter in this Cell MO must be set to NULL.
  • When the SubframeAssignment parameter in a Cell MO is set to NULL, the FddTddInd and WorkMode parameters in this Cell MO must be set to CELL_TDD and LAA respectively.
  • When the FddTddInd and WorkMode parameters in a Cell MO are set to CELL_TDD and LAA, respectively, the SpecialSubframePatterns parameter in this Cell MO must be set to NULL.
  • When the SpecialSubframePatterns parameter in a Cell MO is set to NULL, the FddTddInd and WorkMode parameters in this Cell MO must be set to CELL_TDD and LAA respectively.
  • When the FddTddInd and WorkMode parameters in a Cell MO are set to CELL_TDD and LAA, respectively, the DlCyclicPrefix parameter in this Cell MO must be set to NORMAL_CP.
  • If FddTddInd in a Cell MO is set to CELL_TDD, the value of VolteQualRecoveryQci1PlrThld must be less than VolteQualIfHoQci1PlrThld.
  • If FddTddInd in a Cell MO is set to CELL_TDD, the value of VolteQualRecoveryQci1PlrThld must be less than Qci1PlrThldForVolteQualHo.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the PucchSwitch option of the PucchAlgoSwitch parameter in the CELLALGOSWITCH MO is selected, the TddSrsCfgMode parameter in the SRSCFG MO is set to ACCESS_ENHANCED, and the SriPeriodAdaptive parameter in the PUCCHCFG MO is set to QCIADAPTIVE or NOQCIADAPTIVE.

-Others:

  • In a Cell MO, if FddTddInd and WorkMode are set to CELL_FDD and DL_ONLY, respectively, DlBandWidth must be set to CELL_BW_N25, CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100.
