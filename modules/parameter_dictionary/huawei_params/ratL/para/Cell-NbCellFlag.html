Meaning

Indicates whether a local cell is an NB-IoT cell. When this parameter is set to TRUE, the local cell is an NB-IoT cell. When this parameter is set to FALSE, the local cell is not an NB-IoT cell. This parameter applies only to NB-IoT.

Caution

Changing the value of this parameter will cause the cell to automatically restart. If the value is changed from TRUE to FALSE, the values of FreqBand, DlEarfcn, UlBandWidth, DlBandWidth, and RootSequenceIdx must be also changed. Otherwise, the system may be greatly affected.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
