Meaning

Indicates whether to enable the two functions related to downlink coverage enhancement in the cell.

DlCellCoverEnhanceAlgoSw: Indicates whether to enable cell coverage enhancement. After this function is enabled, the throughput of cell-edge UEs with rank-1 transmissions for which low MCS indexes are used increases in light-load wide-coverage scenarios, and the coverage capability of the cell improves. This function requires that the RRU serving the cell have power headroom, work in FDD-only mode, and be configured with a single carrier. This option applies only to LTE FDD.

AdptCellEdgePwrAllocSw: Indicates whether to enable adaptive power matching. Enabling this function in a lightly loaded wide coverage cell helps improve the performance of CEUs. This function is enabled only when this option is selected. This option applies only to LTE FDD.

Disuse statement: DlCellCoverEnhanceAlgoSw: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Parameter Relationship

-Configuration constraints:

  • The DlCellCoverEnhanceAlgoSw option of CellDlCoverEnhanceSwitch in the CellAlgoSwitch MO can be selected only if GLPwrShare of the CellAlgoSwitch MO is set to OFF.
  • In the CellAlgoSwitch MO, if the Virtual4T4RSwitch option of EmimoSwitch is selected, the DlCellCoverEnhanceAlgoSw option of CellDlCoverEnhanceSwitch must be deselected.
  • If the Virtual4T4RSwitch or Tm4MuMimoSwitch option of the EmimoSwitch parameter in a CellAlgoSwitch MO is selected, AdptCellEdgePwrAllocSw under the CellDlCoverEnhanceSwitch parameter in the same CellAlgoSwitch MO must be deselected.
  • If AdptCellEdgePwrAllocSw of CellDlCoverEnhanceSwitch in a CellAlgoSwitch MO is selected, FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch of DlCompSwitch in the CellAlgoSwitch MO must be deselected.

Caution

Cell coverage enhancement is applicable when only a single LTE FDD carrier is configured and nominal power is not configured for RRUs. Check these conditions before enabling this function.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

DlCellCoverEnhanceAlgoSw: If this option is selected, cell coverage enhancement is enabled to increase downlink transmit power based on RRU capability for UEs that meet a specific MCS threshold. In wide or intensive coverage areas, this function increases the throughput of CEUs and improves cell coverage. If this option is deselected, cell coverage enhancement is disabled and network performance is not affected.

AdptCellEdgePwrAllocSw: If this option is selected, the throughput of CEUs increases by about 5% in a lightly loaded wide coverage area. If this option is deselected, the function is disabled and network performance is not affected.
