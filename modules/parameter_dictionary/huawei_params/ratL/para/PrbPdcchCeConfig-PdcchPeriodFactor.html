PDCCH Period Factor

Parameter Name

PDCCH Period Factor
NE

MML Command

MOD PRBPDCCHCECONFIG

LST PRBPDCCHCECONFIG
Meaning

Indicates the PDCCH period factor. The PDCCH period factor multiplied by the maximum number of PDCCH repetitions is the PDCCH period.

Multiple PDCCH periods without PDCCH resources are generated when this parameter is set to G_4(G_4) and the PdcchMaxRepetitionCnt parameter is set to REP_1(REP_1) or when this parameter is set to G_2(G_2) and the PdcchMaxRepetitionCnt parameter is set to REP_4(REP_4).

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is one of the preceding configurations, it is recommended that the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO be set to REP_1(REP_1) and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO be set to a value greater than or equal to MCS_2(MCS2). This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is not one of the preceding combinations and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value less than MCS_2(MCS2), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.74. This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_2(MCS2) and less than MCS_5(MCS5), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.3.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_5(MCS5) and less than MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.87.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.43.

This parameter applies only to NB-IoT.

-Configuration constraints:

  • The PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO must not be set to G_1DOT5(G_1DOT5) or G_48(G_48). The product of the values of the PdcchPeriodFactor and PdcchMaxRepetitionCnt parameters in the PrbPdcchCeConfig MO must be within the range of 8 to 2048.
