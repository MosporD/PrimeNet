Meaning

Indicates whether to enable compatibility solutions, based on which the eNodeB determines whether to handle compatibility issues. This parameter includes the following options:

UECapRprtAbnormalCtrlSwitch: If this option is selected, the eNodeB handles compatibility issues of UEs that cannot report their capabilities. This option applies only to LTE FDD and LTE TDD.

ApCqiRptAbnormalCtrlSwitch: Indicates whether to apply a compatibility solution to abnormal aperiodic channel quality indicator (CQI) reporting. If this option is selected, the compatibility solution takes effect. The configuration IEs related to aperiodic CQI reporting are always included in RRC Connection Reconfiguration messages used to reconfigure CQIs. If this option is deselected, the compatibility solution does not take effect. The configuration IEs related to aperiodic CQI reporting are not included in RRC Connection Reconfiguration messages used to reconfigure CQIs if the IEs remain unchanged. This option applies only to LTE FDD and LTE TDD.

UeInterRatMeasCtrlSwitch: Indicates whether the eNodeB checks the QCI-specific inter-RAT handover policies when evaluating an inter-RAT handover. This function does not allow the eNodeB to deliver inter-RAT measurement configurations to some special UEs anymore and applies to the following types of inter-RAT handovers: coverage-based handover, distance-based handover, uplink-quality-based handover, service-based handover, and SPID-specific handover back to the HPLMN. If this option is selected, the eNodeB determines whether to deliver inter-RAT A1/A2, blind A1/A2, and inter-RAT B1/B2 measurement configurations to the UE for a measurement-based or blind inter-RAT handover based on the setting of the NoHoFlag parameters in the InterRatPolicyCfgGroup MO for QCIs of services running on the UE. If this option is deselected, the eNodeB does not perform the evaluation based on the values of the NoHoFlag parameters in the InterRatPolicyCfgGroup MO.

ApCqiAndAckAbnCtrlSwitch: Indicates whether to enable a workaround of problems that may occur when aperiodic CQI reports in 3-1 reporting mode and ACKs/NACKs are transmitted simultaneously in a cell. If this option is selected, the eNodeB performs preallocation for aperiodic CQI reports. If this option is deselected, the eNodeB performs CQI_ONLY scheduling on aperiodic CQI reports. This option applies only to LTE FDD and LTE TDD.

UeSRSAntSelectCtrlSwitch: Indicates whether to disable antenna selection for SRS transmission. If this option is selected, antenna selection for SRS transmission is disabled. If this option is deselected, antenna selection for SRS transmission is enabled. This option applies only to LTE TDD.

CaCqiAndAckAbnCtrlSwitch: Indicates whether to enable a workaround of problems that may occur when periodic CQI reports and ACKs/NACKs are transmitted simultaneously in a cell in CA scenarios. If this option is selected, the eNodeB sets the SimulAckNackAndCqiSwitch parameter to OFF(Off) for CA UEs. If this option is deselected, the eNodeB sets the SimulAckNackAndCqiSwitch parameter based on the original algorithm for CA UEs.

HoRlcSnSizeSwitch: Controls the configuration of RLC sn-FieldLength during handovers. If this option is selected, the configuration of RLC sn-FieldLength for the target cell is the same as that for the source cell. If this option is deselected, RLC sn-FieldLength for the target cell is set to the value configured at the target side.

FddTddCaPcellDuplexFdd: Indicates whether the eNodeB regards that a UE supports FDD+TDD CA with an FDD cell serving as its PCell when the UE complies with 3GPP release 12 or earlier, reports the FDD+TDD CA band combination, but does not report IE tdd-FDD-CA-PCellDuplex-r12. If this option is selected, the eNodeB regards that the UE supports this type of CA. If this option is deselected, the eNodeB regards that the UE does not support this type of CA. This option applies only to LTE FDD and LTE TDD.

FddTddCaPcellDuplexTdd: Indicates whether the eNodeB regards that a UE supports FDD+TDD CA with a TDD cell serving as its PCell when the UE complies with 3GPP release 12 or earlier, reports the FDD+TDD CA band combination, but does not report IE tdd-FDD-CA-PCellDuplex-r12. If this option is selected, the eNodeB regards that the UE supports this type of CA. If this option is deselected, the eNodeB regards that the UE does not support this type of CA. This option applies only to LTE FDD and LTE TDD.

Tm3Tm4Max4LayerCtrlSwitch: Indicates whether UEs of category 6 and above (excluding category 5) support four-layer MIMO based on TM3/TM4. If this option is selected, UEs of category 6 or above (excluding category 5) support MIMO at a maximum of four layers based on TM3/TM4. If this option is deselected, UEs of category 6 or above (excluding category 5) support MIMO at a maximum of two layers based on TM3/TM4. This option applies only to LTE FDD and LTE TDD.

UeCsiRsCfigCtrlSwitch: Indicates whether to configure CSI-RSs for TM9-incapable UEs complying with 3GPP Release 10 or later after the cell sends CSI-RSs. If this option is selected, CSI-RSs are configured for such UEs. If this option is deselected, CSI-RSs are not configured for such UEs. This option applies only to LTE FDD and LTE TDD.

FreqBwVerificationSwitch: Indicates whether to check if the frequency and bandwidth configurations of cells or neighboring E-UTRAN frequencies exceed the corresponding frequency band boundary. If this option is selected, the configured frequency and bandwidth cannot exceed the boundary values of the corresponding frequency band. If this option is deselected, the eNodeB does not check frequency or bandwidth configurations.

Impact on Radio Network Performance

UECapRprtAbnormalCtrlSwitch: If this option is selected, the eNodeB performs compatibility handling on UEs with defects in capability reporting, lowering the service drop rate. If this option is deselected, such UEs have to experience handover failures and service drops.

ApCqiRptAbnormalCtrlSwitch: If this option is selected, the RRC signaling overhead slightly increases. If this option is deselected, the network performance is not affected.

UeInterRatMeasCtrlSwitch: If this option is selected and the No handover flag parameter value is FORBID_HO_ENUM only for some QCIs of services on a UE, the UE may experience an inter-RAT handover failure because inter-RAT event A1/A2, blind A1/A2, or inter-RAT measurement configurations are not delivered to the UE or are not delivered in time. However, for UEs that are not allowed to be handed over to inter-RAT cells, selecting this option prohibits the inter-RAT handover measurements and increases throughput of such UEs. If this option is deselected, the eNodeB does not consider the No handover flag parameter setting when evaluating delivery of inter-RAT event A1/A2, blind A1/A2, or inter-RAT measurement configurations, and the inter-RAT handover success rate is not affected.

VoipExProtSwitch: If this option is selected, the service drop rate decreases for UEs experiencing abnormal VoLTE access. If this option is deselected, the eNodeB does not provide protection against VoLTE exceptions. This option has no impact on UEs.

UeSRSAntSelectCtrlSwitch: If this option is selected, the downlink throughput increases for UEs that report they can select antennas for transmission but actually cannot. If this option is deselected, the network performance is not affected.

ApCqiAndAckAbnCtrlSwitch: When there are defective UEs on the network with downlink closed-loop MIMO enabled, selecting this option results in an increase in the downlink throughput and decreases in the downlink RBLER and service drop rate, but a decrease in the uplink throughput and increases in the uplink interference, uplink RBLER, and service drop rate. In the preceding scenario, deselecting this option results in a decrease in the downlink throughput and increases in the downlink RBLER and service drop rate, without an impact on uplink performance. It is recommended that this option be selected only if downlink closed-loop MIMO is enabled and there are a large number of defective UEs on the network.

CaCqiAndAckAbnCtrlSwitch: If this option is selected and abnormal CA UEs exist in the downlink, the throughput loss in downlink SCCs decreases, and downlink throughput may decrease due to a prolonged CQI reporting period in the scenario where only ACKs/NACKs to transmission on the PCC are required and periodic CQI reports and ACKs/NACKs can be transmitted simultaneously. The uplink performance is not affected. If this option is deselected and abnormal CA UEs exist in the downlink, the downlink throughput decreases, but uplink performance is not affected. It is recommended that this option be selected when there are a large number of abnormal CA UEs in the downlink and be deselected in other scenarios.

RlcSnSizeSwitch: If this option is selected, the configuration of RLC sn-FieldLength in the target cell is the same as that in the source cell. This avoids the situation that some abnormal UEs experience compatibility problems and avoids inconsistent configurations of RLC sn-FieldLength on the eNodeB side and the UE side in abnormal scenarios. If this option is deselected and the configuration of RLC sn-FieldLength for the target cell is different from that for the source cell, compatibility problems may occur on some abnormal UEs or in some abnormal scenarios. This causes handover failures.

Tm3Tm4Max4LayerCtrlSwitch: If this option is selected,

- In a common cell: Four-layer MIMO can be performed on UEs that are category 6 or above and capable of a maximum of four-layer MIMO based on TM3/TM4. This improves cell downlink throughput.

- In an SFN or adaptive SFN cell: Demodulation for such UEs is affected in joint scheduling areas if one of the combination cells does not support four-layer MIMO. In this case, you are advised to disable four-layer MIMO.

If this option is deselected, a maximum of two-layer MIMO based on TM3/TM4 can be performed on UEs that are category 6 or above.

UeCsiRsCfigCtrlSwitch: If this option is selected, CSI-RSs are configured for TM9-incapable UEs complying with 3GPP Release 10 or later, improving the performance of such UEs. However, UE compatibility problems may occur, causing service drops. Whether a UE is a UE complying with 3GPP Release 10 or later needs to be checked before this option is selected. If this option is deselected, CSI-RSs are not configured for TM9-incapable UEs complying with 3GPP Release 10 or later. In this case, no CSI-RS-related UE compatibility problems occur, but the downlink throughput decreases.

FreqBwVerificationSwitch: If this option is selected, the eNodeB checks the measurement frequencies and bandwidths for UEs, which prevents UE compatibility issues. If this option is deselected and UEs check frequency and bandwidth configurations and find that the configurations exceed the boundary values of the corresponding frequency bands, service drops may occur on these UEs. To prevent this, check whether UEs on the network are capable of checking frequency and bandwidth configurations.
