Meaning

Indicates whether to enable intelligent selection for massive MIMO parameters.

BIG_EVENT_THLD_LEARN_SW: Indicates whether to enable massive MIMO big event threshold learning. If this option is selected, massive MIMO big event threshold learning is enabled. If this option is deselected, massive MIMO big event threshold learning is disabled. In this case, the default user number threshold for triggering massive MIMO big event assurance is used. This option applies only to LTE TDD.

BIG_EVENT_PDCCH_CAPC_ADAPT_SW: Indicates whether to enable PDCCH capacity adaptation in massive MIMO big event scenarios. If this option is selected, PDCCH capacity adaptation is enabled. If this option is deselected, PDCCH capacity adaptation is disabled. This option applies only to LTE TDD.

BIG_EVENT_AUTO_ASSURANCE_SW: Indicates whether to enable automatic assurance for massive MIMO big events. If this option is selected, automatic assurance for massive MIMO big events is enabled. If this option is deselected, automatic assurance for massive MIMO big events is disabled. This option applies only to LTE TDD.

BIG_EVENT_NON_GBR_BUNDLING_SW: Indicates whether to enable non-GBR packet bundling in big event scenarios. If this option is selected and the NonGbrBundlingSwitch option of the DlSchSwitch parameter in the CellAlgoSwitch MO is also selected, non-GBR packet bundling is enabled in big event scenarios. If the NonGbrBundlingSwitch option is deselected, non-GBR packet bundling cannot be enabled. If this option is deselected, non-GBR packet bundling is disabled in big event scenarios. This option takes effect only if the BIG_EVENT_AUTO_ASSURANCE_SW option is selected. This option applies only to LTE TDD.

Disuse statement: BIG_EVENT_PDCCH_CAPC_ADAPT_SW: The BIG_EVENT_PDCCH_CAPC_ADAPT_SW option will be removed in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option. The function of this option is now controlled by the BIG_EVENT_AUTO_ASSURANCE_SW option of the MmParamIntelSelectSw parameter.

Impact on Radio Network Performance

BIG_EVENT_THLD_LEARN_SW: If this option is selected, the threshold for triggering massive MIMO big event assurance changes depending on specific scenarios, improving user experience in massive MIMO big events. If this option is deselected, the default user number threshold for triggering massive MIMO big event assurance is used.

BIG_EVENT_PDCCH_CAPC_ADAPT_SW: If this option is selected, the PDCCH capacity increases, the CCE allocation failure rate decreases, and user experience in massive MIMO big event scenarios is ensured. If this option is deselected, network performance is not affected.

BIG_EVENT_AUTO_ASSURANCE_SW: If this option is selected, the CCE usage increases, the uplink and downlink interference decreases, network load is optimized, and user experience in massive MIMO big events is ensured. However, service overload protection reduces the number of admitted UEs. If this option is deselected, the average user experience in the cell does not improve in massive MIMO big events.

BIG_EVENT_NON_GBR_BUNDLING_SW: If this option is selected and the NonGbrBundlingSwitch option of the DlSchSwitch parameter in the CellAlgoSwitch MO and the BIG_EVENT_AUTO_ASSURANCE_SW option are also selected, the PDCCH consumption reduces, but the initial packet delay increases and the downlink throughput is affected. Other configurations have no impact on network performance.
