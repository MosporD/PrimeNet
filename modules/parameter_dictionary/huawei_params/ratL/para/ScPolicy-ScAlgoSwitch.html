Meaning

Indicates the general switch of the service classification (SC) algorithm. This parameter provides the following options:

SC_SERVICE_IDENTITY_SW: The eNodeB identifies services based on service characteristics only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SC_MODULE_LOAD_SW: The eNodeB identifies and measures services of specified UEs when operators use end-to-end UE tracing only if this option is selected.

SC_DEFAULT_DNS_DISABLE_SW: If this option is selected, the default DNS does not take effect. If this option is deselected, the default DNS takes effect.

This option applies only to LTE FDD and LTE TDD.

SC_SUPPORT_IPV6_SW: If this option is selected, the SC module supports both the IPv6 and IPv4 protocols. Otherwise, the SC module supports only the IPv4 protocol. This option applies only to LTE FDD and LTE TDD.

LOW_LATENCY_QCI_SC_LOAD_SW: If this option is selected, the eNodeB loads service identification based on service characteristics for services of bearers with QCIs for which the LowLatencyFlag parameter in the CellQciPara is set to TRUE. In this case, the eNodeB identifies and measures these services. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.
