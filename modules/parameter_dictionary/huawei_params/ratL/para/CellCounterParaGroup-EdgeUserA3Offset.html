Meaning

Indicates the offset for cell edge user (CEU) identification event A3. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter results that better signal quality of the neighboring cell is required for the reporting of CEU identification event A3 and the eNodeB has a lower probability of identifying a UE as a CEU. A smaller value of this parameter results in a higher probability that a UE is identified as a CEU. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter results in a higher probability of reporting event A3. A larger number of UEs sending A3-related measurement reports leads to a larger probability that the eNodeB identifies a UE as a cell edge user and more signaling messages. A larger value of this parameter results in the opposite effects.
