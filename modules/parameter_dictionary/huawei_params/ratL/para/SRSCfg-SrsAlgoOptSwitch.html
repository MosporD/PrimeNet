Meaning

Indicates whether to enable SRS algorithm optimization.

SrsSubframeRecfgOptSwitch: Indicates whether to perform SRS subframe reconfiguration optimization. This option applies only to LTE FDD. If this option is selected, the SRS subframe reconfiguration path is optimized to avoid the configurations that may cause UE compatibility issues. If this option is deselected, the SRS subframe reconfiguration path is not optimized.

UlVolteSrsFssSwitch: The function controlled by this option does not take effect. Non-service-specific uplink frequency selective scheduling takes effect no matter whether this option is selected or not. This option applies only to LTE FDD.

Impact on Radio Network Performance

SrsSubframeRecfgOptSwitch: If this option is deselected, the SRS subframe reconfiguration path is not optimized. If SrsCfgInd is set to BOOLEAN_TRUE and FddSrsCfgMode is set to DEFAULTMODE for the FDD cell in FDD+TDD networking scenarios, UE compatibility issues may occur when UEs are handed over from a TDD cell to the FDD cell, causing handover failures. If this option is selected, the preceding UE compatibility issues are avoided. However, when the cell load is medium or high, the increase in the number of SRS subframes, that is, the increase in SRS overhead can cause uplink cell performance to deteriorate.

UlVolteSrsFssSwitch: If this option is selected and the SrsCfgInd parameter is set to BOOLEAN_TRUE, SRS-measurement-based frequency selective scheduling takes effect for VoLTE services, and this decreases the uplink voice packet loss rate. If this option is deselected, uplink frequency selective scheduling is performed without differentiating between services, which has no impact on network performance.
