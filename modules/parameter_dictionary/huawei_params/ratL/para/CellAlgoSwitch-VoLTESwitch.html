Meaning

Indicates whether to enable VoLTE-related algorithms. AcBarForVoLTEPreferSwitch: Indicates whether to allow preferential access of voice services during access class control. If this option is selected, voice preference information (specified by the VoLTEPreferCfgInd parameter in the CellAcBar MO) is included in SIB2. This ensures that AC barring does not take effect at the access layer for UEs initiating any of the following services: MMTEL voice, MMTEL video, IP-based SMS, and SMS. If this option is deselected, SIB2 does not contain any voice preference information and AC barring takes effect for these UEs at the access layer. This option applies only to LTE FDD and LTE TDD.

VoLTEMoPrefSwitch: Indicates whether to perform preferential processing for UEs that originate VoLTE services. If this option is deselected, the eNodeB does not perform preferential processing for these UEs. If this option is selected, the eNodeB optimizes procedures such as admission, scheduling, and flow control for these UEs to increase the VoLTE service success rate. This option applies only to LTE FDD and LTE TDD.

VoLTEOffOptSwitch: Indicates whether to reject the setup of QCI 1 bearers for optimization when VoLTE is disabled. If this option is selected, the eNodeB rejects the setup of QCI 1 bearers (and QCI 2 bearers if there are QCI 2 videotelephony services) but accepts the setup of other bearers during initial context setup, bearer setup, or bearer modification procedures. This option takes effect only if the ServiceReqInterFreqHoSwitch option of the HoAlgoSwitch parameter in the ENodeBAlgoSwitch MO is deselected. This option applies only to LTE FDD and LTE TDD.

VoLTECallConnDelayOptSw: Call connection delay optimization for UEs running voice services takes effect only when this option is selected. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

AcBarForVoLTEPreferSwitch: Selecting this option improves access experience of UEs initiating any of the following services: MMTEL voice, MMTEL video, IP-based SMS, and SMS. The service type is determined based on the setting of the VoLTEPreferCfgInd parameter in the CellAcBar MO. Deselecting this option affects access experience of these UEs.

VoLTEMoPrefSwitch: Selecting this option helps increase the VoLTE UE access success rate but also increases the service drop rate of data service UEs.

VoLTEOffOptSwitch: Selecting this option helps increase the bearer setup success rates of bearers with a QCI other than 1 and 2.

VoLTECallConnDelayOptSw: Selecting this option decreases the call connection delay for UEs running voice services but increases the resource usage when QCI 5 DRX is enabled. When this option is deselected, network performance is not affected.
