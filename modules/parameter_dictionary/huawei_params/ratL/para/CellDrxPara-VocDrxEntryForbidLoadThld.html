Meaning

Indicates the cell load threshold for forbidding newly accessed voice UEs to enter the DRX mode. The algorithm does not take effect when this parameter is set to 0. When this parameter is set to a value in the range of 1 to 100, the eNodeB forbids newly accessed voice UEs to enter the DRX mode only if the cell load is higher than the threshold value. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A larger value of this parameter results in a lower probability of forbidding voice UEs to enter the DRX mode. In this situation, the uplink and downlink packet loss rates of voice services increase as cell load increases. However, the UE power saving effect improves. A smaller value of this parameter results in a higher probability of forbidding voice UEs to enter the DRX mode. In this situation, the uplink and downlink packet loss rates of voice services decrease as cell load increases. However, the UE power saving effect deteriorates. In addition, the downlink cell throughput and downlink user-perceived rate decrease slightly.
