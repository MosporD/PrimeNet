Meaning

Indicates whether to enable VoLTE marking in PS paging and the paging priority for VoLTE UEs. If this parameter is set to OFF, PS paging call flag addition is disabled. If this parameter is set to a value other than OFF, PS paging call flag addition is enabled. For the value range, see the definition of the paging priority IE in 3GPP TS 36.413. If PS paging call flag addition is enabled, the eNodeB identifies the paging priority of VoLTE services in S1 paging messages, and uses an extended bit in paging messages sent over the air interface to inform UEs of VoLTE paging. Then, UEs send the mo-VoiceCall-v1280 IE during network access. The eNodeB interprets this IE and handles these services by following the procedure for preferential access of mobile-originated VoLTE services. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a value other than OFF and the UE supports PS paging call flag addition, the eNodeB optimizes procedures such as admission, scheduling, and flow control for identified VoLTE paging. This increases the VoLTE call success rate but also the service drop rate of UEs running data services. If the UE is experiencing weak coverage, the VoLTE quality is poor, and the voice packet loss rate increases. The UE includes mo-VoiceCall-v1280, instead of mt-Access, as the establishment cause in the RRC Connection Request message. The values of the L.Paging.UU.Succ and L.RRC.ConnReq.Msg.Mt counters decrease, and that of the L.RRC.ConnReq.Msg.MoVoiceCall counter increases. Since the eNodeB uses an extended bit during paging, the paging overhead increases, and the downlink cell throughput slightly decreases.
