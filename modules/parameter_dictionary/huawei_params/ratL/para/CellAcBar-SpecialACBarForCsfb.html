AC 11-15 barring state for CSFB

Parameter Name

AC 11-15 barring state for CSFB
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLACBAR

LST CELLACBAR
Meaning

Indicates whether CS fallback (CSFB) services initiated by UEs of AC 11 to AC 15 are granted access.

AC11BARSTATE: If this option is selected, the CSFB services initiated by UEs of AC 11 in idle mode are barred. This option applies only to LTE FDD and LTE TDD.

AC12BARSTATE: If this option is selected, the CSFB services initiated by UEs of AC 12 in idle mode are barred. This option applies only to LTE FDD and LTE TDD.

AC13BARSTATE: If this option is selected, the CSFB services initiated by UEs of AC 13 in idle mode are barred. This option applies only to LTE FDD and LTE TDD.

AC14BARSTATE: If this option is selected, the CSFB services initiated by UEs of AC 14 in idle mode are barred. This option applies only to LTE FDD and LTE TDD.

AC15BARSTATE: If this option is selected, the CSFB services initiated by UEs of AC 15 in idle mode are barred. This option applies only to LTE FDD and LTE TDD.
