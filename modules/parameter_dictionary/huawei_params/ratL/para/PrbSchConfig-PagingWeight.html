Meaning

Indicates the paging weight of each carrier. For details, see 3GPP TS 36.331. If this parameter is set to W0 for all carriers including anchor and non-anchor carriers, paging is performed only on the anchor carrier. If this parameter is set to W0 for the anchor carrier and a value other than W0 for any non-anchor carrier, paging is not performed on the anchor carrier. If this parameter is set to W0 for a non-anchor carrier, this non-anchor carrier does not support paging. If this parameter is set to a value other than W0 for a carrier, the value of this parameter is used as the paging weight of the carrier. For details, see 3GPP TS 36.304. This option applies only to NB-IoT.

Caution

If this parameter is modified, the cell will be reestablished.

Before configuring the non-anchor carrier paging weight, check whether peer MMEs support paging on multiple carriers specified in 3GPP Release 14. If not, UEs may not receive paging messages.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

The larger the value of this parameter, the larger the paging weight of the current carrier. The smaller the value of this parameter, the smaller the paging weight of the current carrier.
