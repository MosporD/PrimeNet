Caution

The setting of the P0NominalPUSCH parameter affects that of the PassLossCoeff parameter. If P0NominalPUSCH is set to a large value, it is recommended that PassLossCoeff be set to a small value to achieve higher sector throughput. If P0NominalPUSCH is set to a small value, it is recommended that PassLossCoeff be set to a large value to ensure higher data rates for cell edge users (CEUs).
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If this parameter value is too large, the interference to neighboring cells increases and the overall network throughput decreases. If this parameter value is too small, the interference to neighboring cells decreases and the throughput of the local cell also decreases.
