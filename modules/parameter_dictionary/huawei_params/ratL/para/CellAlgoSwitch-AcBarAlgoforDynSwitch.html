Meaning

Indicates whether to enable dynamic access barring algorithms. This parameter controls whether to enable dynamic access barring on mobile-originated (MO) signaling, MO data, service-specific access control (SSAC) for multimedia telephony (MMTEL) voice services, or SSAC for MMTEL video services. This parameter takes effect only when the AcBarAlgoSwitch parameter in the CellAlgoSwitch MO is set to ACBAR_SWITCH_DYNAMIC.

DYNAMIC_FOR_MO: Indicates whether to enable dynamic access barring on UEs running MO signaling or MO data.

If this switch is on, dynamic access barring applies to UEs running MO signaling or MO data.

If this switch is off, dynamic access barring does not apply to UEs running MO signaling or MO data. This option applies only to LTE FDD and LTE TDD.

DYNAMIC_FOR_SSAC: Indicates whether to enable dynamic access barring on UEs running MMTEL voice services or MMTEL video services.

If this switch is on, dynamic access barring applies to UEs running MMTEL voice services or MMTEL video services.

If this switch is off, dynamic access barring does not apply to UEs running MMTEL voice services or MMTEL video services. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

DYNAMIC_FOR_MO: If this switch is on, the access probability factors for MO Data and MO signaling are dynamically adjusted based on the current cell load. In this way, the probability of UEs accessing the cell can be controlled to relieve the cell load. However, user experience of barred UEs is affected. If this switch is off, it has the opposite effects.

DYNAMIC_FOR_SSAC: If this switch is on, the access probability factors for MMTEL voice services and MMTEL video services are dynamically adjusted based on the current cell load. In this way, the probability of UEs accessing the cell can be controlled to relieve the cell load. However, user experience of barred UEs is affected. If this switch is off, it has the opposite effects.
