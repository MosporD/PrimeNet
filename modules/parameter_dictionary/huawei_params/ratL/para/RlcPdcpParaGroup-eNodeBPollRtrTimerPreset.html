Meaning

Indicates the length of the Polling PDU retransmission timer for the eNodeB when the RlcParaAdaptSwitch parameter is set to ON and the number of UEs on the network is large. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a small value, excessive polling PDUs will be sent. In addition, the number of ARQ retransmissions reaches its maximum due to consecutive PDU retransmissions. Then, the RRC connection is reestablished, and the UE experiences the service drop. If this parameter is set to a large value, status reports cannot be sent promptly, thereby affecting the RLC send window movement and UE throughput.
