Protocol Procedure Support Switch

MO GlobalProcSwitch
Parameter ID ProtocolSupportSwitch
Parameter Name

Protocol Procedure Support Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether the eNodeB supports some protocol-defined procedures.

SupportS1UeCapMatchMsg: If this option is selected, the eNodeB can process and respond to the UE RADIO CAPABILITY MATCH REQUEST message over the S1 interface. For details, see 3GPP TS 36.413. If the option is deselected, the eNodeB cannot process the UE RADIO CAPABILITY MATCH REQUEST message and responds with an error indication message. This option applies only to LTE FDD and LTE TDD.

SupportS1UELocationInfoSwitch: If this option is selected, the eNodeB reports the PCell location information about UEs in the E-RAB and UE context release messages to an MME and reports the NR PSCell location information about UEs configured with an NR SCG in some UE-level S1 messages to the MME. If this option is deselected, the eNodeB does not report the location information about UEs to the MME. PCell-related messages include UE CONTEXT RELEASE COMPLETE, E-RAB RELEASE INDICATION, and E-RAB RELEASE RESPONSE. NR-PSCell-related messages include UE CONTEXT RELEASE COMPLETE, E-RAB RELEASE INDICATION, E-RAB RELEASE RESPONSE, PATH SWITCH REQUEST, UPLINK NAS TRANSPORT, and HANDOVER NOTIFY. For details about the messages, see 3GPP TS 36.413. This option applies only to LTE FDD and LTE TDD.

SupportDrbRlcRelUecntSwitch: If this option is selected, the eNodeB proactively releases UE contexts when the maximum number of DRB RLC retransmission times is reached. If this option is deselected, the eNodeB proactively releases UE bearers when the maximum number of DRB RLC retransmission times is reached. This option applies only to LTE FDD and LTE TDD.

SupportNetReqCaComboSwitch: If this option is selected, the eNodeB queries the CA band combinations supported by a UE that supports CA band combination reporting. A maximum of 384 CA band combinations can be queried. If this option is deselected, the query procedure is disabled.

X2SonProtocolDelCooSwitch: If this option is selected, the eNodeB interacts with the peer for X2 self-removal using the method defined in 3GPP Release 12 specifications. If this option is deselected, the eNodeB interacts with the peer for X2 self-removal using the method defined by Huawei. This option applies only to X2 interfaces between eNodeBs. This option applies only to LTE FDD and LTE TDD.

X2MessageWithNbCellInfoSw: If this option is selected for an eNodeB with NB-IoT cells and the TargetENodeBRelease parameter in the X2 MO is set to Release_14 or a value indicating a later version, the NB-IoT cells are included in the serving cell IE in X2 setup request, X2 self-setup request response, and eNodeB configuration update messages. If this option is deselected for such an eNodeB, the NB-IoT cells are not included in the serving cell IE in X2 setup request, X2 self-setup request response, and eNodeB configuration update messages. This option applies only to LTE FDD and NB-IoT.

PwsRestartIndicationSwitch: Indicates whether to enable the public warning system (PWS) restart indication function. If this option is selected, the eNodeB sends a PWS Restart Indication message to the MME when a local cell becomes available. If this option is deselected, the eNodeB does not send the PWS Restart Indication message to the MME. This option applies only to LTE FDD and LTE TDD.

OverheatingProtectionSwitch: Indicates whether to enable overheating protection. If this option is selected, the eNodeB allows UEs that support overheating protection to report the IE OverheatingAssistance-r14. After receiving this IE from a UE, the eNodeB reduces the traffic volume of the UE or reduces the number of LTE SCells for the UE to relieve UE overheating. If this option is deselected, overheating protection is disabled. This option applies only to LTE FDD and LTE TDD.

SftdMeasSwitch: Indicates whether to enable the SFTD measurement function in the eNodeB. If this option is selected, the eNodeB periodically delivers SFTD-related measurement configurations to some SFTD-capable UEs to measure the time difference between the serving LTE frequency and neighboring NR frequencies. If this option is deselected, the eNodeB does not deliver SFTD-related measurement configurations. This option applies only to LTE FDD and LTE TDD.

MaxReportRsIndexSwitch: Indicates whether the eNodeB includes the maxReportRS-Index-r15 IE in LTE frequency measurement configurations in NSA DC scenarios. If this option is selected, the eNodeB includes the maxReportRS-Index-r15 IE in LTE frequency measurement configurations. If this option is deselected, the eNodeB does not include the maxReportRS-Index-r15 IE in LTE frequency measurement configurations. This option applies only to LTE FDD and LTE TDD.

NsaDcPerFr1GapSwitch: Indicates whether to configure per-FR1 measurement gaps during inter-frequency or inter-RAT measurements of UEs that support independent measurement gaps and are in the NSA DC state. If this option is selected, per-FR1 measurement gaps are configured for these UEs during inter-frequency or inter-RAT measurements. If this option is deselected, per-FR1 measurement gaps are not configured for these UEs during inter-frequency or inter-RAT measurements. For details about the configuration of independent measurement gaps in NSA networking, see 3GPP TS 37.340. This option applies only to LTE FDD and LTE TDD.

Sib12WarningAreaGeoInfoSw: Indicates whether SIB12 includes the warning area geographical location information element which is introduced in 3GPP Release 15. If this option is selected, SIB12 includes the IE warningAreaCoordinatesSegment-r15. If this option is deselected, SIB12 does not include the IE warningAreaCoordinatesSegment-r15. This option applies only to LTE FDD and LTE TDD.

UeCapbEnquirySimulSwitch: Indicates whether to adopt simultaneous message transmission for security mode activation and UE capability query. If this option is selected and the UE capability needs to be queried during initial access, then parallel mode is adopted for security mode activation and UE capability query. If this option is deselected, sequence mode is adopted. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

SupportS1UeCapMatchMsg: If this option is selected, access delay increases when the UE RADIO CAPABILITY MATCH REQUEST message reaches the eNodeB earlier than the INITIAL CONTEXT SETUP REQUEST message, affecting user experience of service establishment. If this option is deselected, user experience of service establishment is not affected.

SupportDrbRlcRelUecntSwitch: If this option is selected, the eNodeB proactively releases UE contexts when the maximum number of DRB RLC retransmission times is reached. This will increase the value of the counter related to abnormal service drops. Deselecting this option has no impact on the eNodeB.

SupportNetReqCaComboSwitch: Selecting this option increases the E-RAB setup duration and the duration for completing CA carrier configuration to enter the CA state. In addition, the service drop rate increases slightly. Deselecting this option has no impact on network performance.

OverheatingProtectionSwitch: If this option is selected, the user-perceived throughput and the number of carriers aggregated for UEs that support overheating protection may decrease. If this option is deselected, network performance is not affected.

SftdMeasSwitch: If this option is selected, the eNodeB selects some SFTD-capable UEs to perform SFTD measurements. During the measurements, the traffic volume of the UEs decreases. If this option is deselected, there is no impact.

MaxReportRsIndexSwitch: If this option is selected, measurement results reported by NSA DC UEs include the NR SSB index. In this situation, the NSA DC UEs perform non-contention-based random access to NR cells during handovers. The probability of NR resynchronization failures decreases. If this option is deselected, measurement results reported by NSA DC UEs do not include the NR SSB index. In this situation, the NSA DC UEs perform contention-based random access to NR cells. The probability of NR resynchronization failures rises.

NsaDcPerFr1GapSwitch: If this option is selected, per-FR1 measurement gaps are configured for UEs that support independent measurement gaps and are in the NSA DC state. This avoids a conflict with the per-FR2 measurement gaps on the NR side. If this option is deselected, the measurement gaps of these UEs may conflict with per-FR2 measurement gaps on the NR side, affecting performance on the NR side.

UeCapbEnquirySimulSwitch: If this option is selected, parallel mode is adopted for security mode activation and UE capability query, shortening the access delay. If this option is deselected, the access delay is large.
