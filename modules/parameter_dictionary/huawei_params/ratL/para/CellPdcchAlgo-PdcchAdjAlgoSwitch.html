Meaning

Indicates whether to enable optimization functions related to the PDCCH adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.

CCE8PcOptSwitch: Indicates the basis of performing dynamic power control for UEs with a CCE aggregation level of 8 when the CCE aggregation level is adjusted based on capacity. If this option is selected, the PDCCH power for UEs with a CCE aggregation level of 8 is dynamically adjusted based on PDCCH quality. This option applies only to LTE TDD.

AggLvl8PwrIncreaseUpperLimitSw: Indicates whether to enable power increase limiting for the PDCCH aggregation level 8. If this option is selected, the PDCCH aggregation level of downlink retransmission UEs is 8, and the number of RRC_CONNECTED UEs is greater than the value of the PdcchPwrCtrlUserNumThd parameter in the CellPdcchAlgo MO, an upper power increase limit is set for this aggregation level. If this option is deselected, no upper power increase limit is set for downlink retransmission UEs with the PDCCH aggregation level 8. This option applies only to LTE TDD.

EnhCfiAdptOptSwitch: Indicates whether to enable enhanced CFI adaptation optimization for 8T8R. This option is valid only when the PdcchSymNumSwitch parameter is set to ECFIADAPTIONON. If this option is selected, CCE resources increase in 8T8R heavy-load scenarios and therefore the number of scheduled UEs also increases in these scenarios. When this option is deselected, the optimization does not take effect and the enhanced CFI adaptation function is used. This option applies only to LTE TDD.

PdcchRobustnessEnhSw: Indicates whether to enable the PDCCH robustness enhancement algorithm. If this option is selected, the PDCCH robustness enhancement algorithm is enabled. If this option is deselected, the PDCCH robustness enhancement algorithm is disabled. This option applies only to LTE FDD.

Impact on Radio Network Performance

CCE8PcOptSwitch: If this option is selected, the cell throughput increases when the PDCCH resources are insufficient, and the user-perceived rate in weak coverage scenarios decreases. If this option is deselected, the eNodeB selects a high CCE aggregation level for UEs in weak coverage scenarios, consuming more PDCCH resources but lowering the probability of missing detection of the PDCCH in weak coverage scenarios.

AggLvl8PwrIncreaseUpperLimitSw: If this option is selected and the number of RRC_CONNECTED UEs is greater than the UE quantity threshold for PDCCH power control, an upper power increase limit is set for downlink retransmission UEs with the PDCCH aggregation level 8. This improves the capacity when PDCCH CCEs are insufficient but increases the probability of missing PDCCH detection for CEUs and lowers the CEU-perceived rate.

EnhCfiAdptOptSwitch: If this option is selected and enhanced CFI adaptation is being used, the CFI value increases, and therefore the number of scheduled UEs and the traffic volume in the cell also increase. If this option is deselected, network performance is not affected.

PdcchRobustnessEnhSw: If this option is selected, the PDCCH allocation success rate for common messages increases and the PDCCH BLER for UEs at the cell edge decreases. However, the CFI value and the aggregation level for UEs at the cell edge may increase. If this option is deselected, the CFI value and the PDCCH aggregation level for UEs at the cell edge are relatively low, but the PDCCH allocation success rate for common messages decreases and the PDCCH BLER for UEs at the cell edge increases.
