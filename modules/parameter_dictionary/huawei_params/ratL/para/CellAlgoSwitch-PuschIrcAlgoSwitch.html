Meaning

Indicates whether to apply the interference rejection combining (IRC) algorithms to the PUSCH. This parameter includes the MrcIrcAdptSwitch, SmartIrcSwitch, MrcIrcAdaptivefor2R, and NoIntrfSmartIRCEnhSwitch options. The SmartIrcSwitch option applies only to 8R and 4R CoMP and Massive MIMO scenarios. The NoIntrfSmartIRCEnhSwitch option applies only to 8R scenarios. The SmartIRCSwitch and NoIntrfSmartIRCEnhSwitch options apply only to LTE TDD macro cells.

MrcIrcAdptSwitch: Indicates whether to enable MRC/IRC adaptation. When this option is selected, MRC/IRC adaptation is enabled. When this option is deselected, MRC is used.

SmartIrcSwitch: Indicates whether to enable smart IRC. Smart IRC is enabled only if this option is selected. This option applies only to LTE TDD.

MrcIrcAdaptivefor2R: Indicates whether to enable MRC/IRC adaptation in uplink 2R scenarios. This option takes effect only when the MrcIrcAdptSwitch option is selected. When this option is selected, MRC/IRC adaptation is enabled in 2R scenarios. When this option is deselected, MRC is used. This option applies only to LTE FDD and LTE TDD.

NoIntrfSmartIRCEnhSwitch: Indicates whether to enable enhanced smart IRC for scenarios without interference. Enhanced no-interference IRC is enabled only if this option is selected. This option applies only to LTE TDD.

In 2R cells established on LBBPc boards: If the MrcIrcAdptSwitch option is selected, IRC is used. If the MrcIrcAdptSwitch option is deselected, MRC is used. In 2R cells established on LBBPd boards: The setting of MrcIrcAdaptivefor2R takes effect only when the MrcIrcAdptSwitch option is selected. If the MrcIrcAdptSwitch and MrcIrcAdaptivefor2R options are selected, MRC/IRC adaptation is used. If the MrcIrcAdptSwitch option is selected and the MrcIrcAdaptivefor2R option is deselected, IRC is used. If the MrcIrcAdptSwitch option is deselected, MRC is used. In 2R cells established on the UBBP boards: If the MrcIrcAdptSwitch option is selected, MRC/IRC adaptation is used. If the MrcIrcAdptSwitch option is deselected, MRC is used. In 4R cells established on the LBBPc, LBBPd, or UBBP boards: If the MrcIrcAdptSwitch option is selected, MRC/IRC adaptation is used. If the MrcIrcAdptSwitch option is deselected, MRC is used.

Impact on Radio Network Performance

MrcIrcAdptSwitch: If this option is selected, both the uplink coverage and the uplink throughput of CEUs in interference scenarios increase. If this option is deselected, the uplink coverage decreases in interference scenarios. SmartIrcSwitch: If this option is selected, both the uplink average throughput and throughput at the cell edge increase. In addition, the service drop rate decreases. If this option is deselected, both the uplink average throughput and throughput at the cell edge decrease in interference scenarios. In addition, the service drop rate increases. MrcIrcAdaptivefor2R: This option takes effect for 2-antenna reception only when the MrcIrcAdptSwitch option of this parameter is selected. If the MrcIrcAdaptivefor2R option is selected, MRC/IRC adaptation is used for 2-antenna reception; if this option is deselected, IRC is used for 2-antenna reception. If MRC/IRC adaptation is used for 2-antenna reception, the uplink coverage improves in no-interference scenarios and deteriorates in strong interference scenarios, as compared with fixed IRC.NoIntrfSmartIRCEnhSwitch: If this option is selected, interference suppression gains can be obtained and network performance in no-interference scenarios improves. If this option is deselected, smart IRC is used and only interference suppression gains can be obtained.
