Ue Compatibility Switch

MO GlobalProcSwitch
Parameter ID UeCompatSwitch
Parameter Name

Ue Compatibility Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD GLOBALPROCSWITCH

LST GLOBALPROCSWITCH
Meaning

Indicates whether to enable compatibility optimization functions for UEs to control the differentiated handling of defective UEs.

AbnormalUeHandleSwitch: Indicates whether to enable handling of defective UEs. If this option is selected, the eNodeB is allowed to take differentiated measures for defective UEs. If this option is deselected, the eNodeB is not allowed to take differentiated measures for defective UEs. This option applies only to LTE FDD and LTE TDD.

UltraFlashCsfbComOptSw: Indicates whether to enable the optimization of UE incompatibility risks in ultra-flash CSFB. If this option is selected, an eNodeB triggers an ultra-flash CSFB procedure based on the proprietary IE "SRVCC based eCSFB operation possible" that the MME sends to the eNodeB. If this option is deselected, the eNodeB does not trigger an ultra-flash CSFB procedure based on this IE. This option applies only to LTE FDD and LTE TDD.

ForbidR8R9UeAccessB41Sw: Indicates whether to forbid 3GPP R8- or R9-compliant UEs to access frequencies ranging from 2575 MHz to 2595 MHz in band 41. If this option is selected, all 3GPP R8- or R9-compliant UEs are forbidden to access frequencies ranging from 2575 MHz to 2595 MHz in band 41. If this option is deselected, 3GPP R8- or R9-compliant UEs are allowed to access frequencies ranging from 2575 MHz to 2595 MHz in band 41. It is recommended that this option be selected when there are UEs reporting that they report band 41 but actually do not support frequencies ranging from 2575 MHz to 2595 MHz in band 41. This option applies only to LTE FDD and LTE TDD.

PerExtendBitSw: Indicates whether to encode extended bit indicators for Uu messages if extended IEs specified by later 3GPP releases are not included in Uu message code. If this option is selected, extended bit indicators are not encoded. If this option is deselected, extended bit indicators are encoded. This option applies only to LTE FDD and LTE TDD.

InterFddTddMeasComOptSw: Indicates whether to enable compatibility optimization on inter-duplex-mode measurements for UEs. If a UE reports the inter-duplex-mode measurement capability but actually does not support inter-duplex-mode measurements, this UE incompatibility issue may cause an increase in the service drop rate. If this option is selected, the eNodeB is not allowed to deliver inter-duplex-mode measurement configurations to such UEs. This option applies only to LTE FDD and LTE TDD.

NbR13CompatSw: Indicates whether to enable error correction of 3GPP Release 13 on NB-IoT-related functions. For details about the related functions, see 3GPP TS 36.211, 36.213, 36.302, 36.331, 36.212, 36.321, 36.300, 36.302, 36.403, 36.322, and 36.323. If this option is selected, the eNodeB can interconnect with UEs complying with 3GPP Release 13 published in March 2017. If this option is deselected, the eNodeB can interconnect with only UEs complying with 3GPP Release 13 published earlier than March 2017. This option applies only to NB-IoT.

HashedIdCompatSw: Indicates whether the eNodeB calculates hashed IDs for eDRX paging using the method defined in 3GPP TS 36.304 released in March 2017. When this option is selected, the eNodeB calculates hashed IDs for eDRX paging using the protocol-defined method. When this option is deselected, the eNodeB calculates hashed IDs for eDRX paging using the Huawei-proprietary method.

PuschAndGapConflictOptSw: Indicates whether adaptive retransmission is used for the second retransmission when the first retransmission of PUSCH conflicts with a gap-assisted measurement and the PHICH for the first retransmission does not fall into any measurement gap. If this option is selected, adaptive retransmission is used for the second retransmission. If this option is deselected, non-adaptive retransmission is used for the second retransmission. This option applies only to LTE FDD.

Disuse statement: NbR13CompatSw: This option will be removed in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

HashedIdCompatSw: This option will be removed in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

Caution

UltraFlashCsfbComOptSw: Ultra-flash CSFB is a Huawei-proprietary feature. To resolve possible UE incompatibility risks in ultra-flash CSFB, Huawei eNodeBs and Huawei MMEs are required and cooperated.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

AbnormalUeHandleSwitch: If some UEs in the network do not support some features and thereby network KPIs are affected, selecting AbnormalUeHandleSwitch can disable related features on UEs and therefore the KPIs are improved.

UltraFlashCsfbComOptSw: If this option is deselected and a UE does not support ultra-flash CSFB, the UE fails to perform ultra-flash CSFB and then initiates a standardized CSFB procedure, which extends latency or causes a service drop, affecting user experience. If this option is selected, the preceding incompatibility risk can be avoided.

ForbidR8R9UeAccessB41Sw: If this option is selected, abnormal UEs that support band 41 according to its capability report but actually do not support band 41 will not measure band 41 frequencies and therefore will not be handed over or redirected to the cells working at band 41 frequencies. In this way, the service drop rate decreases and the handover success rate and RRC connection reestablishment success rate increase. If this option is deselected, the special processing mechanism is not performed for UEs compliant with 3GPP Release 8 and Release 9. In this case, the service drop rate increases and the handover success rate and RRC connection reestablishment success rate decrease if abnormal UEs compliant with 3GPP Release 8 and Release 9 exist on the network.

InterFddTddMeasComOptSw: When an eNodeB delivers inter-duplex-mode measurement configurations to a UE that reports the inter-duplex-mode measurement capability but actually does not support inter-duplex-mode measurements, the UE may initiate an RRC connection reestablishment during the measurements and then experience a service drop, increasing the service drop rate and affecting user experience. If this option is selected, the preceding situation can be avoided. If this option is deselected, the preceding situation cannot be avoided.

NbR13CompatSw: This option applies only to UEs complying with 3GPP Release 13 published in February 2017. If a UE does not comply with this specification, the UE fails to access the network.

PuschAndGapConflictOptSw: If this option is deselected and there are UEs with compatibility issues, the uplink packet loss rate of QCI-1 services increases and the CCE usage decreases. If this option is selected, the uplink packet loss rate of QCI-1 services decreases and the CCE usage increases.
