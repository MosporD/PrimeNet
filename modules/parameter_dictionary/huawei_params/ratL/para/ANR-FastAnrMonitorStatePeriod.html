Meaning

Indicates the monitoring state period of fast ANR. During monitoring state periods, the eNodeB does not select new UEs for fast ANR measurements. If a neighboring cell with an unknown PCI is reported for event-triggered ANR during a monitoring state period, fast ANR exits the monitoring state and a new measurement period for fast ANR starts. If this parameter is set to 0, fast ANR does not enter the monitoring state. When the accumulative number of UEs performing fast ANR measurements is cleared, a new measurement period for fast ANR immediately starts. If this parameter is set to 65535, fast ANR does not exit the monitoring state unless a neighboring cell with an unknown PCI is reported for event-triggered ANR. After fast ANR exits the monitoring state, a new measurement period for fast ANR starts. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter leads to a shorter monitoring state period of fast ANR and a longer time in which the throughput of UEs performing measurements for fast ANR is affected but a higher efficiency of detecting unknown neighboring cells by fast ANR. A larger value of this parameter leads to the opposite effects.
