Meaning

Indicates the amount of uplink interference that can be suppressed for pRRUs. If this parameter is set to 0, pRRU uplink interference suppression does not take effect. If this parameter is set to a non-0 value, pRRU uplink interference suppression is triggered. This parameter is valid only when the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE, the MultiRruCellMode parameter in the Cell MO is set to SFN, CELL_COMBINATION, or MPRU_AGGREGATION, and an EuSectorEqmGroup MO is configured for the cell. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

It is recommended that this parameter be set to 0 if LampSite and macro eNodeBs use the same frequencies or LampSite eNodeBs suffer from inter-RAT interference, and the average uplink interference noise of LampSite eNodeBs is less than -110 dBm.

It is recommended that this parameter be set to 20 if LampSite and macro eNodeBs use the same frequencies or LampSite eNodeBs suffer from inter-RAT interference, and the average uplink interference noise of LampSite eNodeBs is greater than -90 dBm.

It is recommended that this parameter be set to 10 if LampSite and macro eNodeBs use the same frequencies or LampSite eNodeBs suffer from inter-RAT interference, and the average uplink interference noise of LampSite eNodeBs is between -110 dBm and -90 dBm.

Impact on Radio Network Performance

Many factors need to be considered for setting this parameter, including coverage and a balance between inter-cell uplink interference and capacity.

1. Inter-cell uplink interference: A large value of this parameter leads to large UE power in the local cell and large interference to neighboring cells. A small value of this parameter leads to poor interference suppression capability in the local cell.

2. Capacity: A large value of this parameter leads to high uplink spectral efficiency in the local cell but great interference to neighboring cells and capacity decreases of neighboring cells.

3. Coverage: A large value of this parameter leads to a power increase for UEs in the local cell, a larger proportion of power-limited UEs using MCS index 0 in the uplink, and a higher VoLTE call drop rate.
