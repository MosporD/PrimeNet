Meaning

Indicates whether to enable NB-IoT multi-carrier functions.

PAGING_PRB_SELECTION_SW: Indicates the carrier range for NB-IoT UEs that support R15-defined mixed operation modes to monitor paging messages. If this option is deselected, the UEs monitor paging messages on all carriers that support paging. If this option is selected, the UEs monitor paging messages on non-anchor carriers that support paging and are deployed in multi-carrier mode in compliance with 3GPP Release 15. This option is valid only when both paging on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 14 and paging on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 15 are enabled. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

NPRACH_PRB_SELECTION_SW: Indicates the carrier range for NB-IoT UEs that support R15-defined mixed operation modes to access the cell. If this option is deselected, the UEs can initiate random access on all carriers that support random access. If this option is selected, the UEs can initiate random access on non-anchor carriers that support random access and are deployed in multi-carrier mode in compliance with 3GPP Release 15. This option is valid only when both access on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 14 and access on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 15 are enabled. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

PWR_DIFF_BASED_PRB_LB_SW: Indicates whether an NB-IoT cell supports load sharing based on the power difference between carriers. If this option is selected, the cell supports load sharing based on the power difference between carriers. If this option is deselected, whether loads can be shared between carriers varies as follows: If the NB-IoT cell has two carriers, UEs at coverage level 2 can perform services only on the anchor carrier; if the NB-IoT cell has more than two carriers, UEs at coverage level 2 can be assigned to non-anchor carriers whose power difference from the anchor carrier is at least -4 dB. This option applies only to NB-IoT.
