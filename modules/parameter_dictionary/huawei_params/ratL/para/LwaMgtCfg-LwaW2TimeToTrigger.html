Impact on Radio Network Performance

A smaller value of this parameter results in a higher probability of reporting LWA event W2. A larger value of this parameter results in the opposite effect. If this parameter is set to a small value, there is a high probability of premature event A2 triggering, and therefore the LWA offloading carrier is mistakenly configured, affecting user experience. If this parameter is set to a large value, there is a high probability that event W2 cannot be triggered, and therefore the LWA offloading carrier cannot not be changed.
