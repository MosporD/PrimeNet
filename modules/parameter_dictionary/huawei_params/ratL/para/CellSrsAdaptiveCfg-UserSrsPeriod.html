Meaning

Indicates the fixed SRS reporting period. This parameter takes effect only when the SrsPeriodAdaptive parameter is set to OFF(Off). This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

The setting of this parameter applies to all UEs in the cell. Set this parameter to achieve a tradeoff between the number of UEs served and network performance. A shorter SRS reporting period results in a shorter interval of SRS measurements, better user experience, and a lower SRS capacity in the cell. A longer SRS period results in the opposite effects.
