Indicates the rank for the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. This parameter applies only to FDD.

Parameter Relationship

-Configuration constraints:

  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, all values of CellSimuloadRank, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 cannot be the same simultaneously.
  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, values of CellSimuloadRank and CellSimuloadPmi cannot be the same simultaneously.

Impact on Radio Network Performance

This parameter requires the setting of multiple PMIs to simulate the interference when the eNodeB schedules multiple UEs, reflecting the inter-cell interference suppression gain. As this parameter is recommended only in test scenarios (rather than in live networks), it has no impact on network performance.
