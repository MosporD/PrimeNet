Meaning

Indicates the MU beamforming scheme selected for moving UEs when massive MIMO is enabled. An appropriate MU beamforming scheme increases the throughput of MU beamforming UEs. This parameter applies only to LTE TDD.

If this parameter is set to MOVING_MUBF_SCHEME_OFF, the eNodeB disables the MU beamforming scheme for moving UEs.

If this parameter is set to HEAVY_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in heavy-load scenarios.

If this parameter is set to LIGHT_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in light-load scenarios.

If this parameter is set to SPLIT_SDMA_SCHEME, the eNodeB enables split SDMA for moving UEs. This value takes effect after split SDMA is enabled.

If this parameter is set to BIG_EVENT_PROTECT_SCHEME, the eNodeB optimizes MU beamforming pairing for coverage areas with a large number of UEs in mobility state during major events.

If this parameter is set to HIGH_SPEED_OPT_SCHEME, the eNodeB enables MU beamforming pairing optimization in high-speed scenarios.

Impact on Radio Network Performance

If this parameter is set to MOVING_MUBF_SCHEME_OFF, the UE throughput decreases when MU beamforming pairing is performed for moving UEs.

If this parameter is set to HEAVY_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in heavy-load scenarios, increasing the throughput of MU beamforming UEs.

If this parameter is set to LIGHT_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in light-load scenarios, increasing the throughput of MU beamforming UEs.

If this parameter is set to SPLIT_SDMA_SCHEME, the eNodeB enables split SDMA for moving UEs, improving the throughput of such UEs.

If this parameter is set to BIG_EVENT_PROTECT_SCHEME, the eNodeB selects an MU beamforming scheme for coverage areas with a large number of walking UEs or UEs moving faster than the walking speed during major events. This increases the average cell throughput but reduces the number of layers paired for MU beamforming.

The eNodeB uses the counter measuring the number of layers successfully paired for MU beamforming to determine whether the network is heavily or lightly loaded, and then selects an appropriate MU beamforming scheme.

If this parameter is set to HIGH_SPEED_OPT_SCHEME, the eNodeB enables MU beamforming pairing optimization to improve the throughput of moving UEs in high-speed scenarios.
