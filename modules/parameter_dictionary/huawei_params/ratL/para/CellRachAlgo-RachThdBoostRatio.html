Meaning

This parameter indicates the percentage by which the PRACH false alarm detection threshold increases. For example, the value x indicates that the configured PRACH false alarm detection threshold increases by x%, and the value -x indicates that the configured PRACH false alarm detection threshold decreases by x%.

Impact on Radio Network Performance

If this parameter is set to 0, network performance is not affected.

If PRACH false alarm detection is disabled, a larger non-zero value of this parameter leads to a lower probability that preambles are detected, and accordingly a lower probability that preambles are considered as false alarms; a smaller non-zero value of this parameter leads to the opposite effects.

If PRACH false alarm detection is enabled, a larger non-zero value of this parameter leads to a higher probability that preambles are considered as false alarms, a longer delay for UEs to send contention-based preambles, and accordingly a higher probability of contention-based access failures; a smaller non-zero value of this parameter leads to the opposite effects.
