Meaning

Indicates whether to enable spectrum cloudification. If this parameter is set to OFF, spectrum cloudification is disabled. If this parameter is set to GL_SPECTRUM_CONCURRENCY, GSM and LTE spectrum concurrency is enabled. If this parameter is set to UL_SPECTRUM_SHARING, UMTS and LTE spectrum sharing is enabled. If this parameter is set to LTE_NR_UPLINK_SPECTRUM_SHR, LTE and NR uplink spectrum sharing is enabled. If this parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, LTE, UMTS, and GSM spectrum sharing is enabled with GSM statically deployed on the LTE guard band. If this parameter is set to DC_HSDPA_BASED_UL_SPECTRUM_SHR, DC-HSDPA-based UMTS and LTE spectrum sharing is enabled. If this parameter is set to LTE_NR_SPECTRUM_SHR, LTE FDD and NR flash dynamic spectrum sharing or LTE TDD and NR dynamic spectrum sharing is enabled. If this parameter is set to LTE_NR_COORD_SPECTRUM_SHR, LTE and NR spectrum sharing coordination is enabled. This function determines the spectrum requirement status of an LTE cell based on the shared spectrum and supports incoming UE handovers when the LTE cell is in the power silence state. The LTE_NR_COORD_SPECTRUM_SHR value applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In a SpectrumCloud MO, if SpectrumCloudSwitch is set to UL_SPECTRUM_SHARING, only the UL_SPECTRUM_SHR_PH2_SW option of SpectrumCloudEnhSwitch can be selected.
  • If SpectrumCloudSwitch in the SpectrumCloud MO is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, the GL_SPCT_CONCURRENCY_PH2_SW and UL_SPECTRUM_SHR_PH2_SW options of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO must be deselected.
  • If the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, SpectrumCloudSwitch in the SpectrumCloud MO must be set to UL_SPECTRUM_SHARING.
  • If the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in a SpectrumCloud MO is selected, the SpectrumCloudSwitch parameter in the SpectrumCloud MO must be set to GL_SPECTRUM_CONCURRENCY.

Impact on Radio Network Performance

If this parameter is set to GL_SPECTRUM_CONCURRENCY, the impact varies depending on the BE interface. If a BE interface is not set up between the BSC and eNodeB, E-UTRAN cells use the spectrum not overlapping with GSM. Therefore, resource utilization is inefficient but the interference between LTE and GSM is light. If a BE interface is set up between the BSC and eNodeB, E-UTRAN cells dynamically use the spectrum overlapping with GSM. Therefore, resource utilization is efficient but the interference between LTE and GSM increases.

If this parameter is set to UL_SPECTRUM_SHARING, spectrum resource usage increases and more RBs are available than when the standard bandwidth is used, which increases the system capacity. However, UMTS and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to LTE_NR_UPLINK_SPECTRUM_SHR, LTE and NR share uplink spectrum resources, decreasing uplink LTE throughput.

If this parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, spectrum resource usage increases; however, GSM, UMTS, and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to DC_HSDPA_BASED_UL_SPECTRUM_SHR, spectrum resource usage increases; however, UMTS and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to LTE_NR_SPECTRUM_SHR to enable LTE FDD and NR flash dynamic spectrum sharing, uplink and downlink spectrum resources available to LTE decrease, and uplink and downlink LTE throughput decreases. If this parameter is set to LTE_NR_SPECTRUM_SHR to enable LTE TDD and NR dynamic spectrum sharing, the LTE handover success rate fluctuates during traffic migration and the fluctuation is within the normal range.
