Meaning

Indicates the threshold of the RSRP difference between a neighboring cell and the serving cell to trigger event A3 report for inter-cell D-MIMO when the neighboring cell has better signal quality than the serving cell. A large value of this parameter indicates that neighboring cells must have better signal quality to trigger measurement reporting for inter-cell D-MIMO. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a small value, the eNodeB performs UE attribute determination for a large number of UEs, a large number of UEs are identified as joint transmission UEs, and the experience rate of CEUs increases by a large margin, but the signaling overhead used for event A3 report increases. If this parameter is set to a large value, the eNodeB performs UE attribute determination for a small number of UEs, a small number of UEs are identified as joint transmission UEs, and the experience rate of CEUs increases by a small margin. If this parameter is set to a value greater than the RSRP difference threshold used to trigger handovers, the eNodeB performs handovers before UE attribute determination is triggered. In this case, no UEs are identified as joint transmission UEs.
