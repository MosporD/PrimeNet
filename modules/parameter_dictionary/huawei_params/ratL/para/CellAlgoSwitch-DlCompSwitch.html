Meaning

Indicates whether to enable the DL CoMP algorithm.

If the IntraDlCompSwitch option is selected and the InterDlCompDcsSwitch and InterDlCompCbfSwitch options are deselected, intra-BBP adaptive DL CoMP is enabled, and the eNodeB adaptively selects DCS, CBF, or JT as the transmission mode.

If the IntraDlCompSwitch and InterDlCompDcsSwitch options are selected and the InterDlCompCbfSwitch option is deselected, intra-BBP adaptive DL CoMP, inter-BBP DCS, and inter-eNodeB DCS are enabled.

If the IntraDlCompSwitch, InterDlCompDcsSwitch, and InterDlCompCbfSwitch options are selected, intra-BBP adaptive DL CoMP, inter-BBP adaptive DL CoMP, and inter-eNodeB adaptive DL CoMP are enabled. In inter-BBP adaptive DL CoMP and inter-eNodeB adaptive DL CoMP, the eNodeB adaptively selects DCS or CBF as the transmission mode.

The IntraDlCompSwitch, InterDlCompDcsSwitch, and InterDlCompCbfSwitch options apply only to LTE TDD.

FDDHomNetDlCompSwitch: Indicates whether to enable DL CoMP in a homogeneous network (consisting of only macro or micro cells) under a Cloud BB architecture. DL CoMP is enabled in such a network only if this option is selected. This option applies only to LTE FDD.

FDDHetNetDlCompSwitch: Indicates whether to enable DL CoMP in a heterogeneous network (consisting of macro and micro cells) under a Cloud BB architecture. DL CoMP is enabled in such a network only if this option is selected. This option applies only to LTE FDD.

Tm9JtSwitch: Indicates whether to enable JT in TM9 in FDD networks. JT in TM9 is enabled only if this option is selected. This option applies only to LTE FDD.

IntraDlCompJtSwitch: Indicates whether to enable the intra-eNodeB SU-JT algorithm. Intra-BBP SU-JT is enabled only if this option is selected. This option applies only to LTE TDD.

Parameter Relationship

-Configuration constraints:

  • If the InterDlCompCbfSwitch option of the DlCompSwitch parameter is selected, the InterDlCompDcsSwitch option cannot be deselected.
  • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, and InterDlCompCbfSwitch or InterDlCompDcsSwitch under the DlCompSwitch parameter in the CellAlgoSwitch MO is set to 1, IntraDlCompSwitch under the DlCompSwitch parameter in the CellAlgoSwitch MO must be set to 1.
  • If AdptCellEdgePwrAllocSw of CellDlCoverEnhanceSwitch in a CellAlgoSwitch MO is selected, FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch of DlCompSwitch in the CellAlgoSwitch MO must be deselected.
  • The SfnJtSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO can be selected only when the FDDHomNetDlCompSwitch, FDDHetNetDlCompSwitch, and Tm9JtSwitch options of the DlCompSwitch parameter in the CellAlgoSwitch MO are deselected.
  • The InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO must be deselected if the IntraDlCompSwitch, InterDlCompDcsSwitch, or InterDlCompCbfSwitch option of the DlCompSwitch parameter in this CellAlgoSwitch MO is selected.

Impact on Radio Network Performance

If the IntraDlCompSwitch option is selected, the throughput of CEUs increases, but the average cell throughput may decrease.

If the InterDlCompCbfSwitch or InterDlCompDcsSwitch option is selected, the throughput of CEUs in cells in an inter-eNodeB cluster increases, but the average cell throughput may decrease.

If the Tm9JtSwitch option is selected, the throughput of CEUs and the average cell throughput increase.

If the DL CoMP feature is disabled, the throughput of CEUs decreases due to co-channel interference.
