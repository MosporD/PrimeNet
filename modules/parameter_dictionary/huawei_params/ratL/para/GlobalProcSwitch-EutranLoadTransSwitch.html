Meaning

Indicates whether to send E-UTRAN cell load information.

RimUtranSwitch: Indicates whether to send E-UTRAN cell load information through RAN information management (RIM) procedures to the UTRAN. If this option is selected, the eNodeB sends cell load information through RIM procedures to the UTRAN and notifies the UTRAN of cell load changes through RIM procedures. This option applies only to LTE FDD.

EcoSwitch: Indicates whether to send cell load information to the eCoordinator. If this option is selected, the eNodeB sends load information to the eCoordinator and notifies the eCoordinator of cell load changes. This option applies only to LTE FDD and LTE TDD.

ProhibitCceLoadInfoExchangeSw: Indicates whether proprietary IEs can carry CCE load information. If this option is selected, both parties do not allow proprietary IEs to carry CCE load information during load information exchange when inter-vendor MLB is initiated. If this option is deselected, both parties allow proprietary IEs to carry CCE load information during load information exchange when inter-vendor MLB is initiated. For details, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

ProhibitTHLoadInfoExchangeSw: Indicates whether to request TNL load Ind Periodic and HW load Ind Periodic information from neighboring cells served by equipment of other vendors during load information exchange for inter-vendor load equalization. If this option is selected, TNL load Ind Periodic and HW load Ind Periodic are not requested during load information exchange for inter-vendor load equalization. If this option is deselected, TNL load Ind Periodic and HW load Ind Periodic are requested during load information exchange for inter-vendor load equalization. For details, see 3GPP TS 36.423. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

RimUtranSwitch: If this option is selected, the eNodeB sends cell load information through RIM procedures to the UTRAN and lightly loaded E-UTRAN cells are preferentially selected during UTRAN-to-EUTRAN handovers and redirections, increasing the handover preparation success rate and reducing the number of ping-pong handovers.

EcoSwitch: If this option is selected, the eNodeB sends load information to the eCoordinator. The eCoordinator adjusts the WiFi transmit power and access threshold based on the E-UTRAN cell load information, achieving load balancing between WLAN and LTE networks.

ProhibitCceLoadInfoExchangeSw: If this option is selected and standard IEs support CCE load information exchange, redundant X2 signaling exchange decreases. If this option is deselected, network performance is not affected.

ProhibitTHLoadInfoExchangeSw: If this option is selected, the inter-vendor load equalization algorithm can transfer load to a neighboring cell with high transport load or hardware load, increasing the load of the neighboring cell. If this option is deselected, network performance is not affected.
