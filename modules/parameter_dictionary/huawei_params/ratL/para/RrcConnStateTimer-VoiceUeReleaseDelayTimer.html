Meaning

Indicates the delay release timer for a voice UE. The eNodeB checks whether the UE sends and receives data. After QCI-1 bearers are released, the UE context cannot be released until the timer expires. If this parameter is set to 0, the timer does not take effect. If this parameter is set to a value other than 0, the UE context cannot be released until the timer expires after the QCI-1 bearers are released. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter results in an earlier release for a UE without performing services after QCI-1 bearers are released, more frequent RRC connection setup requests initiated by the UE, and better KPIs such as a lower service drop rate due to more normal RRC connection releases. A larger value of this parameter results in a later release for a UE without performing services after QCI-1 bearers are released, a longer UE online duration in which radio resources are occupied, and worse KPIs such as a higher service drop rate due to fewer normal RRC connection releases.
