Meaning

Indicates the low rate coding mode for the corresponding parameter group ID. This parameter is used to configure the low rate coding mode for the corresponding parameter group ID. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In a VoiceAmrControl MO, the value of HighAmrCodingMode must be greater than the value of LowAmrCodingMode. In addition, HighAmrCodingMode and LowAmrCodingMode must be set to AMR-WB or AMR-NB or EVS-SWB at the same time. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of HighAmrCodingMode in those VoiceAmrControl MOs must be different. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of LowAmrCodingMode in those VoiceAmrControl MOs must be different.
