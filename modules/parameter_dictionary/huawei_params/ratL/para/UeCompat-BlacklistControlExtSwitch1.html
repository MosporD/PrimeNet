Meaning

Indicates whether to blacklist some features.

UL_64QAM_SWITCH: Indicates whether to disable uplink 64QAM for defective UEs. If this option is selected, uplink 64QAM is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FULL_CONFIG_SWITCH: Indicates whether to disable the full configuration function for defective UEs. If this option is selected, the full configuration function is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

LOGGED_MDT_SWITCH: Indicates whether to disable logged MDT for defective UEs. If this option is selected, defective UEs are not selected to perform logged MDT measurement and data reporting. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SRVCC_SWITCH_OFF: Indicates whether to disable SRVCC for defective UEs. If this option is selected, SRVCC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_PSHO_SWITCH_OFF: Indicates whether to disable inter-RAT PS handover for defective UEs. If this option is selected, inter-RAT PS handovers are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

LTE_HANDOVER_TO_EMTC_SWITCH: Indicates whether the base station prohibits defective LTE UEs from being handed over to cells with eMTC enabled. If this option is deselected, no differentiated measures are taken for the defective UEs. If this option is selected, the base station prohibits the defective UEs from being handed over to cells with eMTC enabled. This is because the base station regards that access of defective UEs to cells with eMTC enabled will fail. This option applies only to LTE FDD and LTE TDD.

SCS_BASED_HO_SWITCH: Indicates whether to disable smart-carrier-selection-based handover for defective UEs. If this option is selected, smart-carrier-selection-based handovers are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SCS_FDD_TO_TDD_HO_WITH_SCC_SW: Indicates whether to disable smart-carrier-selection-based FDD-to-TDD handover with SCell configuration for defective UEs. If this option is selected, smart-carrier-selection-based FDD-to-TDD handovers with SCell configuration are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

CONTIG_INTRA_BAND_CA_SWITCH: Indicates whether to disable aggregation of contiguous intra-band carriers for defective UEs in cells with Zero Guard Band Between Contiguous Intra-Band Carriers enabled. If this option is deselected, aggregation of contiguous intra-band carriers is not disabled for defective UEs. If this option is selected, aggregation of contiguous intra-band carriers is disabled for defective UEs. This parameter applies only to LTE FDD and LTE TDD.

NSA_DC_SWITCH: Indicates whether to disable NSA DC for defective UEs. If this option is selected, NSA DC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SN_TERMN_MCG_BEARER_SWITCH: Indicates whether to disable the SN-terminated MCG bearer function for defective UEs. If this option is selected, the SN-terminated MCG bearer function is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

DRB_ID_INCREMENTAL_ALLOC_SW: Indicates whether to enable incremental DRB ID allocation for special UEs. If this option is selected, incremental DRB ID allocation is disabled for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If some UEs on the network do not support some features and thereby network KPIs are affected, turning on corresponding switches can disable related features on defective UEs and therefore the KPIs are improved.

UL_64QAM_SWITCH: If this option is selected, the eNodeB does not apply 64QAM in the uplink for UEs configured in the blacklist. In this case, network KPIs are not affected. There is a possibility that 64QAM is disabled for undesired UEs and throughput near the cell center decreases. If this option is deselected, the eNodeB allows UEs configured in the blacklist to use 64QAM in the uplink, thereby affecting network KPIs.

FULL_CONFIG_SWITCH: If this option is deselected, the eNodeB delivers the IE fullconfig-r9 to defective UEs, which do not support the IE. This causes exceptions such as service drops and RRC connection reestablishments, affecting UE experience. If this option is selected, the eNodeB does not deliver the IE to defective UEs, improving UE experience.

LOGGED_MDT_SWITCH: If this option is selected, the eNodeB does not deliver logged MDT measurement configurations to blacklisted UEs and therefore network KPIs are not affected. If this option is deselected, the eNodeB can deliver logged MDT measurement configurations to these UEs, affecting the RRC connection setup success rate.

SRVCC_SWITCH_OFF: If this option is selected, the eNodeB does not allow SRVCC for defective UEs. This increases the SRVCC success rate. If this option is deselected, the SRVCC success rate is not affected.

INTER_RAT_PSHO_SWITCH_OFF: If this option is selected, the eNodeB does not allow inter-RAT PS handover for defective UEs. This increases the inter-RAT PS handover success rate. If this option is deselected, the inter-RAT PS handover success rate is not affected.

LTE_HANDOVER_TO_EMTC_SWITCH: If this option is selected, the eNodeB prohibits handovers to cells with eMTC enabled for defective UEs. This may cause inter-frequency cell loads to become imbalanced and the cell-edge service drop rate to increase. If this option is deselected, KPIs related to handovers and RRC connection reestablishment may deteriorate due to MIB reading failures when the defective UEs are handed over to cells with eMTC enabled.

SCS_BASED_HO_SWITCH: If this option is selected, the eNodeB does not allow smart-carrier-selection-based handovers for blacklisted UEs. This prevents poor handover performance of defective UEs from affecting KPIs such as the handover success rate. If this option is deselected, there are no such impacts.

SCS_FDD_TO_TDD_HO_WITH_SCC_SW: If this option is selected, the eNodeB does not allow smart-carrier-selection-based FDD-to-TDD handovers with SCell configuration for blacklisted UEs. This prevents poor performance of FDD-to-TDD handover with SCell configuration of defective UEs from affecting KPIs such as the service drop rate. If this option is deselected, there are no such impacts.

CONTIG_INTRA_BAND_CA_SWITCH: If this option is selected, the number of RRC connection reestablishments of defective UEs decreases. If this option is deselected, defective UEs may experience exceptions such as RRC connection reestablishments.

NSA_DC_SWITCH: If this option is selected, the eNodeB disables NSA DC for blacklisted UEs. This prevents abnormal NSA DC procedures of defective UEs from affecting network KPIs. If this option is deselected, there is no such impact.

SN_TERMN_MCG_BEARER_SWITCH: If this option is selected, the base station disables the SN-terminated MCG bearer function for blacklisted UEs. This prevents UEs that do not support the SN-terminated MCG bearer function from affecting network KPIs such as the service drop rate. If this option is deselected, there is no such impact.
