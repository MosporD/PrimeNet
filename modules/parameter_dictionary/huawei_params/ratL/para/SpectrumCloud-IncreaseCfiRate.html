ADD SPECTRUMCLOUD

LST SPECTRUMCLOUD
Meaning

Indicates the threshold, expressed as a percentage of CFIs, for triggering increase of the CFI configured for UMTS. If the percentage of actual CFIs greater than the CFI configured for UMTS is greater than the value of this parameter, the CFI configured for UMTS will be increased. This parameter applies only to LTE FDD.

Parameter Relationship

-Parameter relationship with conditions:

  • If SpectrumCloudSwitch is set to DC_HSDPA_BASED_UL_SPECTRUM_SHR, UL_SPECTRUM_SHARING, UL_SPECTRUM_SHR_PH2_WITH_GSM, IncreaseCfiRate is valid.

-Others:

  • The IncreaseCfiRate parameter is valid when the SpectrumCloudSwitch parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, or when the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch parameter is selected.
