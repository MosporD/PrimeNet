MOD CELLBFMIMOPARACFG

LST CELLBFMIMOPARACFG
Meaning

Indicates the transmission mode during an E-RAB setup procedure and an incoming handover procedure for a UE in a massive MIMO cell with the BfMimoAdaptiveSwitch parameter of the CellBfMimoParaCfg MO set to MIMO_BF_ADAPTIVE. If this parameter is set to TM7, TM7 is used. If this parameter is set to AUTOMATIC, MIMO is used. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

In a massive MIMO TDD cell with the BfMimoAdaptiveSwitch parameter of the CellBfMimoParaCfg MO set to MIMO_BF_ADAPTIVE, if this parameter is set to AUTOMATIC, MIMO is used during an E-RAB setup procedure and an incoming handover procedure for a UE, decreasing the downlink traffic volume of the cell.

If this parameter is set to TM7, TM7 is used in the preceding scenario. In this case, the UE can obtain link gains from TM7, increasing the downlink traffic volume of the cell.
