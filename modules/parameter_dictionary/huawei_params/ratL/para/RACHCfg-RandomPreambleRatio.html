Meaning

Indicates the proportion of the number of random preambles in a cell to the number of preambles in the cell. The number of random preambles in a cell is calculated by this parameter value multiplied by the number of preambles in the cell. Preambles in a cell can be classified as random preambles and dedicated preambles, which are used for contention-based random access and non-contention-based random access, respectively. For details, see section 5.1.1 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter results in a higher probability of preamble collision and a longer delay of contention-based random access, and a higher probability of allocating dedicated preambles to and a short delay of non-contention-based random access. A larger value of this parameter results in the opposite effects. A longer access delay may result in a greater service drop rate.
