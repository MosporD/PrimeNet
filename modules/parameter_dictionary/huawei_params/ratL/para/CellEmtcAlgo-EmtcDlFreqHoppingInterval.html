Meaning

Indicates the downlink frequency hopping interval for eMTC in CE mode A or CE mode B. If the MPDCCH_PDSCH_FREQ_HOPPING_SW option is selected, the downlink frequency hopping interval is the value specified by this parameter. If CE mode B is used, the value INTERVAL1 does not take effect. This parameter has different values for FDD and TDD as follows:

For an FDD cell, this parameter can be set to INTERVAL1, INTERVAL2, INTERVAL4, or INTERVAL8.

For a TDD cell, this parameter can be set to INTERVAL1, INTERVAL5, INTERVAL10, or INTERVAL20.

This parameter applies only to LTE FDD and LTE TDD.

Caution

Modifying the EmtcDlFreqHoppingInterval parameter will result in an eMTC system information change, which triggers release of online eMTC UEs in the cell.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

When the eMTC frequency hopping switch is turned on, modifying eMTC frequency hopping parameters will change system information for eMTC UEs. To ensure consistent frequency hopping parameters for eMTC UEs and reduce resource fragments caused by eMTC frequency hopping, the eNodeB will release eMTC UEs that have accessed the network. As a result, the released eMTC UEs have to re-access the network.

If the number of repetitions has not reached the maximum, a larger value of this parameter leads to a larger downlink frequency hopping interval for eMTC UEs and therefore smaller frequency diversity gains for these UEs, and a smaller value of this parameter leads to the opposite effects.
