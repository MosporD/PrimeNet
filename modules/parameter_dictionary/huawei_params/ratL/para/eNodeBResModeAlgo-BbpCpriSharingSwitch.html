Meaning

Indicates whether to support CPRI sharing between baseband processing units (BBPs). When this parameter is set to ON, CPRI sharing is supported and CPRI ports of a BBP or CPRI interface board are shared between specified BBPs to enable baseband processing to be independent of CPRI ports. When this parameter is set to OFF, CPRI sharing is not supported.

Caution

Before changing the setting of CPRI Sharing Switch from ON to OFF, deactivate all the cells using CPRI sharing. Otherwise, the cells will be deactivated after the setting of CPRI Sharing Switch is changed from ON to OFF, and each of the cells will be reestablished on the BBP where the CPRI port for the cell is located.
Validation of Modification

The cell should be reset to validate the parameter modification.
Impact on Radio Network Performance

When this parameter is set to ON, there is no impact on the cells that have already been established. When this parameter is set to OFF, all cells using CPRI sharing are deactivated and each of them is reestablished on the BBP where the CPRI port for the cell is located.
