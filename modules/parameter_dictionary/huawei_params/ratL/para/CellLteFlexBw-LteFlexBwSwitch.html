Meaning

Indicates whether to enable flexible bandwidth optimization.

LTE_FB_CFG_SWITCH: Indicates whether to enable the LTE flexible bandwidth algorithm. This option applies only to LTE FDD.

PDCCH_CAPACITY_OPT_SWITCH: Indicates whether to enable the PDCCH capacity improvement algorithm. This option applies only to LTE FDD.

UL_WEAK_GSM_ITF_PROCESS_SW: Indicates the uplink weak GSM interference processing switch. This option applies only to LTE FDD.

UL_STRONG_GSM_ITF_PROCESS_SW: Indicates the uplink strong GSM interference processing switch. This option applies only to LTE FDD.

The PDCCH_CAPACITY_OPT_SWITCH, UL_WEAK_GSM_ITF_PROCESS_SW, and UL_STRONG_GSM_ITF_PROCESS_SW options take effect only when the LTE_FB_CFG_SWITCH option is selected.

Impact on Radio Network Performance

LTE_FB_CFG_SWITCH: When this option is selected, spectral efficiency improves, and the number of available RBs increases, comparing with that when standardized bandwidth is used. The system capacity improves. However, UEs using RBs in the flexible bandwidth are more prone to inter-RAT interference than UEs using RBs in the standard bandwidth. When the RBs at the start and end positions are used under flexible bandwidth, the uplink and downlink throughput decreases, comparing with that when the same number of RBs is used under standardized bandwidth.

PDCCH_CAPACITY_OPT_SWITCH: When this option is selected, the PDCCH does not have power output in frequencies with strong GSM interference. The PDCCH capacity decreases but interference to the GERAN decreases when compared with that when the option is deselected. When this option is deselected, the PDCCH has power output over the full bandwidth. The PDCCH capacity increases but interference to the GERAN increases when compared with that when the option is selected.

UL_WEAK_GSM_ITF_PROCESS_SW: When this option is selected, uplink interference is regarded as GSM weak interference. In this case, the interference is processed according to the GSM weak interference algorithm.

UL_STRONG_GSM_ITF_PROCESS_SW: When this option is selected, uplink interference is regarded as GSM strong interference. In this case, the interference is processed according to the GSM strong interference algorithm.
