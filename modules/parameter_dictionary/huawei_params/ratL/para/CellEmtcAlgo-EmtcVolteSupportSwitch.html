eMTC Cell VoLTE Capability Switch

MO CellEmtcAlgo
Parameter ID EmtcVolteSupportSwitch
Parameter Name

eMTC Cell VoLTE Capability Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CELLEMTCALGO

LST CELLEMTCALGO
Meaning

Indicates whether to enable VoLTE for an eMTC cell. If this parameter is set to ON, VoLTE is enabled for the eMTC cell. If this parameter is set to OFF, VoLTE is disabled for the eMTC cell. This parameter is invalid when the EutranVoipSupportSwitch parameter is set to OFF. This parameter applies only to LTE FDD and LTE TDD.
