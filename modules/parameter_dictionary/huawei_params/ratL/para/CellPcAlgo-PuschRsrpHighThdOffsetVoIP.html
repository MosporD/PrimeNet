Meaning

Indicates the offset of the upper limit of PUSCH RSRP used for voice (VoLTE and PTT) service users relative to the upper limit of PUSCH RSRP used for data service users. If this parameter is set to a value in the range of 0 to 30, the value of this parameter plus the upper limit of PUSCH RSRP used for data service users is the upper limit of PUSCH RSRP used for voice service users. If this parameter is set to 255, there is no upper limit on the PUSCH RSRP used for voice service users. This parameter is valid only if the PuschRsrpHighThdSwitch option of the UlPcAlgoSwitch parameter, the ACHSwitch option of the IOptAlgoSwitch parameter, or the UL_COORD_PC_SWITCH option of the UlCsSw parameter is selected. This parameter applies only to LTE FDD.

Recommended Value

If the cell load is light or at a medium level, the default value 0 is recommended. If the cell load is heavy, for example, the average number of UEs in the cell is over 400 and the number of voice service users is 20, 255 is recommended to mitigate the impact on the performance of voice service users near or at the cell center.

Impact on Radio Network Performance

When the PuschRsrpHighThdSwitch option of the UlPcAlgoSwitch parameter, the ACHSwitch option of the IOptAlgoSwitch parameter, or the UL_COORD_PC_SWITCH option of the UlCsSw parameter is selected for a heavily loaded cell experiencing high interference in the uplink, a larger value of this parameter results in higher PUSCH TX power of voice service users at or near the cell center, better uplink voice service performance for these users, but higher interference to neighboring cells. A smaller value of this parameter results in the opposite effects.
