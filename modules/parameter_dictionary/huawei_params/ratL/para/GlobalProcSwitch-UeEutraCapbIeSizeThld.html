Meaning

Indicates the size threshold of the IE "UE-EUTRA-Capability" which is used to trigger network-requested CA band combination reporting. Assume that the SupportNetReqCaComboSwitch option is selected. If this parameter is set to a non-zero value, network-requested CA band combination reporting is triggered when the size of the IE "UE-EUTRA-Capability" in UE capability information is greater than the parameter value. If this parameter is set to 0, the threshold is invalid. In this case, network-requested CA band combination reporting is triggered when the number of CA band combinations in the UE capability information reaches 128. For details about the definition of the IE "UE-EUTRA-Capability", see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller non-zero value of this parameter results in a higher probability that network-requested CA band combination reporting takes effect. When the number of CA band combinations in UE capability information does not reach 128 but the size of the IE "UE-EUTRA-Capability" exceeds the parameter value, both the E-RAB setup duration of a UE and the duration in which the CA cell configuration finishes and the UE enters the CA state increase. In this case, the service drop rate slightly increases. If this parameter is set to 0, there are no such impacts.
