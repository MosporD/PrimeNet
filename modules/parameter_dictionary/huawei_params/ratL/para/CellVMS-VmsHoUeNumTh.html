Meaning

Indicates the maximum number of UEs that can be transferred within 10s. This parameter is used to prevent too many UEs from being transferred at a time to neighboring cells to cause significant impact on neighboring cells. This parameter applies only to LTE FDD.

Impact on Radio Network Performance

If this parameter is set to a large value, a large number of UEs can be transferred to neighboring cells at a time, leading to a significant UE number decrease in the serving cell but a quick UE number increase and a load increase in neighboring cells. If this parameter is set to a small value, the number of UEs in the serving cell decreases slowly.
