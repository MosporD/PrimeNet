Meaning

Indicates the frequency band in which a cell operates. For details about this parameter, see 3GPP TS 36.104.

The LTE-U function has been removed, and the values in the range of 252 to 255 are invalid. Although the configuration interface in this version supports synchronization and delivery of the values in this range, the system does not use these values. Therefore, avoid setting this parameter to these values.
