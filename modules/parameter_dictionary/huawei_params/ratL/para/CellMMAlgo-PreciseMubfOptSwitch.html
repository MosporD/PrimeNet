Meaning

Indicates whether to enable the precise MU beamforming optimization algorithm.

PRECISE_PAIRING_OPT_SW: Indicates whether to enable the precise UE pairing optimization algorithm. If this option is selected, the eNodeB implements a downlink multi-user pairing process aimed to improve spectral efficiency in massive MIMO cells and selects an MCS index more suitable for paired UEs. This improves the downlink cell throughput. If this option is deselected, the precise MU beamforming optimization algorithm is disabled. This option applies only to LTE TDD.

ABN_WBB_UE_PRI_SUPPRESS_SW: Indicates whether to enable the suppression of the downlink scheduling priority for abnormal WBB UEs in massive MIMO cells. If this option is selected, there is a lower probability for abnormal WBB UEs to be scheduled. If this option is deselected, the suppression does not take effect. This option applies only to LTE TDD.

DL_CLUSTER_PAIRING_SW: Indicates whether the downlink cluster pairing algorithm takes effect. If this option is selected, the downlink cluster pairing algorithm is used for massive MIMO cells. If this option is deselected, the cluster pairing algorithm is disabled. This option applies only to LTE TDD.

MUBF_PWR_ENH_SW: Indicates whether to enable MU beamforming power enhancement in massive MIMO scenarios. If this option is selected, the power of antennas with weak power is enhanced based on the antenna power difference without affecting the orthogonality among paired UEs. If this option is deselected, the original orthogonalization remains unchanged. This option applies only to LTE TDD.

Impact on Radio Network Performance

PRECISE_PAIRING_OPT_SW: If this option is selected, the accuracy of selecting UEs for downlink multi-user pairing in massive MIMO cells and the accuracy of selecting an MCS index for paired UEs improve. As a result, the pairing performance and downlink cell throughput improve. If this option is deselected, network performance is not affected.

ABN_WBB_UE_PRI_SUPPRESS_SW: If this option is selected, the downlink spectral efficiency of the cell increases, but the downlink rate perceived by abnormal WBB UEs decreases and the proportion of UEs with a low downlink rate in the cell increases. If this option is deselected, network performance is not affected.

DL_CLUSTER_PAIRING_SW: If this option is selected, the downlink cluster pairing algorithm is used to optimize the downlink pairing process, improving the downlink multi-user pairing performance and downlink cell spectral efficiency. If this option is deselected, network performance is not affected.

MUBF_PWR_ENH_SW: If this option is selected, the power of antennas with weak power is enhanced based on the antenna power difference, improving the overall power usage without affecting the orthogonality among paired UEs. If this option is deselected, the original orthogonalization remains unchanged, which has no impact on network performance.
