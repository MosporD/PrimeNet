Parameter Name

NB-IoT eNodeB Polling Retransmission Timer
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD SRBRLCPDCPCFG

LST SRBRLCPDCPCFG
Meaning

Indicates the length of the polling PDU retransmission timer of the RLC layer for the NB-IoT eNodeB. If you need to change the value of this parameter, contact Huawei technical support for assistance. This parameter applies only to NB-IoT.

Recommended Value

This parameter can be set by the system by default. The default value is as follows:

If SrbId is set to SRB1_NBIOT_CE0, then: ms2000(2000)

If SrbId is set to SRB1_NBIOT_CE1, then: ms3000(3000)

If SrbId is set to SRB1_NBIOT_CE2, then: ms15000(15000)

Impact on Radio Network Performance

If this parameter is set to a small value, excessive polling PDUs are retransmitted. In addition, the maximum number of retransmissions at the RLC layer is triggered due to the excessively delayed retransmission timer, and therefore the RLF ratio is affected. If this parameter is set to a large value, status reports cannot be sent promptly.
