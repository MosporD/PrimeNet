Meaning

Indicates the length of the SPID-specific On Duration Timer. This timer takes effect only on non-power-saving UEs configured with a specific SPID or UEs whose capability information indicates that they do not support power saving. For details about this timer, see 3GPP TS 36.321. If the configured value of the OnDurationTimerSpecial parameter does not meet the restrictions of CQI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. This parameter applies only to LTE FDD and LTE TDD.

Parameter Relationship

-Configuration constraints:

  • In the CellDrxSpecialPara MO, the value of OnDurationTimerSpecial must not be greater than the value of LongDrxCycleSpecial. If ShortDrxCycleSwitchSpecial is set to UU_ENABLE, the value of OnDurationTimerSpecial must not be greater than the value of ShortDrxCycleSpecial.

-Others:

  • For LTE TDD cells, the unit for the value of the OnDurationTimerSpecial parameter is PSF while that for the value of the LongDrxCycleSpecial or ShortDrxCycleSpecial parameter is SF. Before comparing the periods specified by these parameters and whether these parameters are effective, unify the value units.
  • If the value of the FddTddInd parameter in the Cell MO is CELL_TDD, the relationship between the values of OnDurationTimerSpecial and LongDrxCycleSpecial must meet the following requirements; If the value of the FddTddInd parameter in the Cell MO is CELL_TDD, and the value of ShortDrxCycleSwitchSpecial is UU_ENABLE, the relationship between the values of OnDurationTimerSpecial and ShortDrxCycleSpecial also must meet the following requirements:
  • In the following formula, x indicates the value of the LongDrxCycleSpecial or ShortDrxCycleSpecial parameter divided by 10 and rounded down, and y indicates the remainder of the value of the LongDrxCycleSpecial or ShortDrxCycleSpecial parameter divided by 10.
  • If SA0 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*4 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 2; y = 6, temp = 3; y = 8, temp = 4.
  • If SA1 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*6 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 3; y = 6, temp = 4; y = 8, temp = 5.
  • If SA2 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*8 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 3; y = 5, temp = 4; y = 6, temp = 5; y = 8, temp = 6.
  • If SA3 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*7 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 2; y = 6, temp = 3; y = 8, temp = 5.
  • If SA4 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*8 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 3; y = 6, temp = 4; y = 8, temp = 6.
  • If SA5 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*9 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 3; y = 5, temp = 4; y = 6, temp = 5; y = 8, temp = 7.
  • If SA6 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*5 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 2; y = 6, temp = 3; y = 8, temp = 4.
  • The value of LongDrxCycleSpecial calculated based on the preceding formula must be greater than or equal to the value of OnDurationTimerSpecial. If the value of ShortDrxCycleSwitchSpecial is UU_ENABLE, the value of the ShortDrxCycleSpecial calculated based on the preceding formula must be greater than or equal to the value of OnDurationTimerSpecial.

Impact on Radio Network Performance

This parameter, together with the LongDrxCycleSpecial, DrxInactivityTimerSpecial, ShortDrxCycleSpecial, and DrxShortCycleTimerSpecial parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.
