MML Command

MOD CELLHOPARACFG

LST CELLHOPARACFG
Meaning

Indicates the number of inter-RAT handover retries initiated to the same target cell after the handover fails over the air interface in the target cell. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter results in a smaller number of inter-RAT handover retries initiated after the handover fails over the air interface in the target cell and a lower probability of handover failures. A larger value of this parameter results in the opposite effects.
