Meaning

Indicates the interval for sending Timing Advance Commands to UEs. This parameter must be set only when the TimingAdvCmdOptSwitch parameter is set to ON. If this parameter is set to INVALID, none of the parameter settings in the MML Command window takes effect. This parameter applies only to LTE FDD.

Impact on Radio Network Performance

If this parameter is set to a smaller value, Timing Advance Commands are sent at a higher frequency, more radio resources are consumed, and more power is consumed for UEs in discontinuous reception (DRX) state even when the DRX period is long. However, UEs can move at a higher speed, and the uplink timing performance of UEs in high-speed mobility can be ensured.

If this parameter is set to a larger value, Timing Advance Commands are sent at a lower frequency, fewer radio resources are consumed, and less power is consumed for UEs in DRX state. However, only UEs move at a lower speed can be supported, and the uplink timing performance of UEs in high-speed mobility cannot be ensured. In addition, untimely adjustments of uplink offsets result in RRC reestablishment or service drops.
