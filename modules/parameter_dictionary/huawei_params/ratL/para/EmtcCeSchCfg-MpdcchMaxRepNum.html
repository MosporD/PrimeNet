MML Command

MOD EMTCCESCHCFG

LST EMTCCESCHCFG
Meaning

Indicates the maximum number of MPDCCH repetitions for UEs at the specified coverage level. For details, see 3GPP TS 36.213. To prevent UE access failures as a result of contention resolution timer expiration caused by a large number of repetitions, it is recommended that this parameter be set to a value in which the number does not exceed half of the number included in the value specified by the ContentionResolutionTimer parameter in the CeRachCfg MO. This parameter applies only to LTE FDD and LTE TDD.

Caution

If this parameter is modified, UEs may fail to access the cell because a large number of MPDCCH repetitions may take a longer time than the contention resolution timer.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

A larger value of this parameter leads to better MPDCCH demodulation performance, higher resource consumption, and a higher probability that UEs cannot access the cell due to contention resolution timer expiration. A smaller value of this parameter leads to poorer MPDCCH demodulation performance and lower resource consumption.
