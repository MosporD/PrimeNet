Meaning

Indicates whether to enhance uplink channels when remote interference (atmospheric duct interference) occurs.

RMT_INF_PUSCH_ENH_SW: Indicates whether to enhance the PUSCH when remote interference occurs. If this option is selected, the PUSCH is enhanced when remote interference occurs. If this option is deselected, the PUSCH is not enhanced when remote interference occurs. This option applies only to LTE TDD.

RMT_INF_AVOID_SCH_SW: Indicates whether to enable interference avoidance and frequency-selective adaptation when remote interference occurs in non-massive MIMO cells. Interference avoidance and frequency-selective adaptation are enabled for non-massive MIMO cells only if this option is selected. This option takes effect only when the InterferenceRbRatioThld parameter in the UlInterfSuppressCfg MO is not set to 100. This option applies only to LTE TDD.

CHN_CALIB_SHIFT_SW: Indicates whether to enable the channel calibration shift function. If this option is selected, channel calibration shift is enabled. If this option is deselected, channel calibration shift is disabled. This option applies only to LTE TDD.

Impact on Radio Network Performance

RMT_INF_PUSCH_ENH_SW: If this option is selected, the uplink throughput increases when remote interference occurs. If this option is deselected, the channel performance is not enhanced when remote interference occurs.

RMT_INF_AVOID_SCH_SW: If this option is selected, the uplink throughput can be improved when remote interference occurs. If this option is deselected, network performance cannot be improved when remote interference occurs.

CHN_CALIB_SHIFT_SW: If this option is selected, the channel calibration success rate increases when channel calibration fails for a long time due to remote interference. If this option is deselected, the channel calibration success rate does not increase when there is remote interference.
