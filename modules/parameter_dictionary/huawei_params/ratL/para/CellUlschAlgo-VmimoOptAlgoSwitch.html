Meaning

Indicates whether to enable uplink MU-MIMO optimization functions. VmimoOptResSwitch: Indicates whether to enable uplink MU-MIMO resource optimization. This option applies only to LTE TDD. HarqVmimoSwitch: Indicates whether UEs that perform retransmission in the uplink can be paired for MU-MIMO. This option applies only to LTE TDD. PreSchVmimoSwitch: Indicates whether pre-scheduled UEs in the uplink can be paired for MU-MIMO. This option applies only to LTE TDD. VMIMOResRandomSwitch: Indicates whether to enable MU-MIMO resource randomization. This option applies only to LTE TDD. HighSpeedSdmaSwitch: Indicates whether to enable uplink spatial division in high-speed railway scenarios. This option takes effect only when subframe configuration SA2 is used. This option applies only to LTE TDD. MmUlHeavyLoadOptSwitch: Indicates whether to enable uplink heavy-load optimization in massive MIMO scenarios. This option applies only to LTE TDD. MmVmimoUePairingOptSw: Indicates whether to enable uplink MU-MIMO pairing optimization in massive MIMO scenarios. This option applies only to LTE TDD.

Impact on Radio Network Performance

VmimoOptResSwitch:

If this option is selected in non-massive MIMO scenarios, UEs are more likely to be paired for MU-MIMO and there are more rate gains after the pairing.

If this option is deselected in non-massive MIMO scenarios, UEs are less likely to be paired for MU-MIMO and there are fewer rate gains after the pairing.

If this option is selected in massive MIMO scenarios, the uplink bit error rate decreases and the uplink user-perceived rate increases.

If this option is deselected in massive MIMO scenarios, the uplink bit error rate does not decrease and the uplink user-perceived rate does not increase.

HarqVmimoSwitch: If this option is selected, the MU-MIMO pairing probability and spectral efficiency gains increase.

If this option is deselected, the MU-MIMO pairing probability and spectral efficiency gains decrease.

PreSchVmimoSwitch: If this option is selected, the MU-MIMO pairing probability and spectral efficiency gains increase.

If this option is deselected, the MU-MIMO pairing probability and spectral efficiency gains decrease.

VMIMOResRandomSwitch: If this option is selected, the user-perceived rate of neighboring cells does not decrease after MU-MIMO is enabled.

If this option is deselected, the user-perceived rate of neighboring cells decreases after MU-MIMO is enabled.

HighSpeedSdmaSwitch: If this option is selected, uplink spectral efficiency and the uplink user-perceived rate of high-speed cells increase.

If this option is deselected, uplink spectral efficiency and the uplink user-perceived rate of high-speed cells do not increase.

MmUlHeavyLoadOptSwitch: If this option is selected, the uplink spectral efficiency and the uplink user-perceived rate of heavy-load massive MIMO cells increase.

If this option is deselected, the uplink spectral efficiency and the uplink user-perceived rate of heavy-load massive MIMO cells do not increase.

MmVmimoUePairingOptSwitch: If this option is selected, the uplink spectral efficiency increases in heavy-load massive MIMO cells.

If this option is deselected, the uplink spectral efficiency does not increase in heavy-load massive MIMO cells.
