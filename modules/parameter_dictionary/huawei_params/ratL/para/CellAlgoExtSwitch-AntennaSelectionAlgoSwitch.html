Meaning

Indicates whether to enable the algorithms related to antenna selection.

ANT_SEL_SCHEDULING_OPT_SWITCH: Indicates whether to enable scheduling optimization for UEs capable of antenna selection in massive MIMO cells. The optimization is enabled only if this option is selected. When this option is selected, the eNodeB optimizes UE pairing for dual-stream beamforming for UEs capable of antenna selection, and allows these UEs to enter dual-stream beamforming when the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter is selected. This option applies only to LTE TDD.

CARRIER_BASED_ANT_SEL_SWITCH: Indicates whether to enable carrier-level antenna selection for UEs capable of antenna selection. If this option is selected, the eNodeB identifies the carrier-level antenna selection capability of UEs capable of antenna selection and enables TDD-carrier antenna selection for UEs capable of carrier-level antenna selection. If this option is deselected, the eNodeB does not identify the carrier-level antenna selection capability of UEs capable of antenna selection. This option applies only to LTE TDD.
