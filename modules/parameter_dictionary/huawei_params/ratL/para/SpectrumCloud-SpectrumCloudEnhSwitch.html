Meaning

Indicates whether to enable spectrum cloudification enhancement.

GL_SPCT_CONCURRENCY_PH2_SW: Indicates whether to enable enhanced GL spectrum concurrency phase 2. When this option is selected, the maximum number of ARFCNs of interfering GSM frequencies that can be configured in LTE in-band increases.

UL_SPECTRUM_SHR_PH2_SW: Indicates whether to enable enhanced UL spectrum sharing phase 2. When this option is selected, spectrum can be dynamically shared between LTE and UMTS. This option applies only to LTE FDD.

LNR_SPECTRUM_SHR_SUPERUL_SW: Indicates whether to enable superior uplink spectrum sharing. When this option is selected, superior uplink spectrum sharing is enabled between LTE and NR. This option applies only to LTE FDD.

Parameter Relationship

-Configuration constraints:

  • In a SpectrumCloud MO, if SpectrumCloudSwitch is set to UL_SPECTRUM_SHARING, only the UL_SPECTRUM_SHR_PH2_SW option of SpectrumCloudEnhSwitch can be selected.
  • If SpectrumCloudSwitch in the SpectrumCloud MO is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, the GL_SPCT_CONCURRENCY_PH2_SW and UL_SPECTRUM_SHR_PH2_SW options of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO must be deselected.
  • If the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, SpectrumCloudSwitch in the SpectrumCloud MO must be set to UL_SPECTRUM_SHARING.
  • If the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in a SpectrumCloud MO is selected, the SpectrumCloudSwitch parameter in the SpectrumCloud MO must be set to GL_SPECTRUM_CONCURRENCY.
  • If the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, the GL_SPCT_CONCURRENCY_PH2_SW option cannot be selected.

Impact on Radio Network Performance

GL_SPCT_CONCURRENCY_PH2_SW: If this option is selected, supported GSM capacity increases when GL spectrum concurrency is enabled. If more ARFCNs of interfering GSM frequencies are configured, the lower limit of the gain in LTE network capacity becomes smaller, which means more severe impact on LTE performance. UL_SPECTRUM_SHR_PH2_SW: If this option is selected, more resources can be shared between UMTS and LTE. As a result, the lower limit of the gain in LTE network capacity becomes smaller, which means more severe impact on LTE performance.

LNR_SPECTRUM_SHR_SUPERUL_SW: If this option is selected, and superior uplink spectrum sharing is also enabled on the NR side, more LTE resources can be shared with NR, increasing the uplink capacity of NR.
