Meaning

Indicates the intra-RAT neighbor relationship classification mode. If the intra-RAT neighbor relationship classification algorithm is enabled and this parameter is set to CONFIGURATION_MODE, intra-RAT extended neighboring cells are saved in the configuration database. If this parameter is set to INTERNAL_STORAGE_MODE, intra-RAT extended neighboring cells are saved in the eNodeB memory. INTERNAL_STORAGE_MODE takes effect only when the OptMode parameter in the ANR MO is set to FREE. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to INTERNAL_STORAGE_MODE, data of intra-RAT extended neighboring cells is saved in the eNodeB memory, reducing the number of configured neighboring cells and improving neighboring cell OM experience. However, the data stored in the eNodeB memory is deleted after the eNodeB resets. In this case, if UEs are handed over to these neighboring cells, they need to read the CGIs of the neighboring cells again, reducing UE throughput and causing service drops due to delayed UE handovers. Setting this parameter to CONFIGURATION_MODE does not affect network performance.
