Meaning

Indicates whether to enable the DL ICIC algorithm. The parameter has three values:

DlIcicSwitch_OFF_ENUM: Indicates that DL ICIC is disabled.

DlIcicDynamicSwitch_ON_ENUM: Indicates that dynamic DL ICIC is enabled.

DlIcicStaticSwitch_ON_ENUM: Indicates that static DL ICIC is enabled.

This parameter applies only to LTE TDD.

Impact on Radio Network Performance

When this parameter is set to DlIcicDynamicSwitch_ON_ENUM or DlIcicStaticSwitch_ON_ENUM, the DL ICIC feature is enabled. Cell edge users (CEUs) will transmit signals using high transmit power in edge frequency bands, and cell center users (CCUs) will transmit signals using low transmit power in center frequency band. In this situation, the average cell throughput decreases, and downlink throughput of CEUs increases.

When this parameter is set to DlIcicSwitch_OFF_ENUM, the DL ICIC feature is disabled, and the throughput of CEUs will not increase.
