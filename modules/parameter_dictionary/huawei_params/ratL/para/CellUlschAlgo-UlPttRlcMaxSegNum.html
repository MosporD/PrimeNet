Meaning

Indicates whether to enable limit control on the number of RLC-layer data segments in the uplink for PTT services scheduled in non-TTI-bundling mode and the maximum number of RLC-layer data segments. If this parameter is set to 0, the limit control is disabled. If this parameter is set to a non-zero value, the limit control is enabled and this value is the maximum number of RLC-layer data segments that an uplink PTT voice packet dynamically scheduled in non-TTI-bundling mode can be divided into. The limit control must be enabled when the UlMcpttCrosslayerOptSw option of the CellUlschAlgo.UlEnhencedVoipSchSw parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a non-zero value, a smaller value leads to poorer uplink coverage for PTT voice services but lower consumption of CCE resources for uplink dynamic scheduling of PTT voice services, and a larger value leads to the opposite effects.

If this parameter is set to 0 or a value larger than a duplex-mode-specific recommended value, the number of RLC-layer data segments of an uplink PTT voice packet dynamically scheduling in non-TTI-bundling mode may exceed this recommended value in weak coverage areas; as a result, more packets are proactively discarded by the UE due to expiration of the UE PDCP-layer packet discarding timer, and uplink coverage of PTT voice services deteriorates. Enabling the limit control and setting the UlPttRlcMaxSegNum parameter to a duplex-mode-specific recommended value help increase the MOS of PTT voice service UEs in weak coverage areas. Setting this parameter to a value less than a recommended value will increase the IBLER and RBLER for PTT voice service UEs.
