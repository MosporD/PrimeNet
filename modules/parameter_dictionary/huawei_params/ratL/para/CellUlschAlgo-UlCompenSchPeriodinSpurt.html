Meaning

Indicates the minimum interval of triggering uplink compensation scheduling for VoLTE UEs in talk spurts when UlVoipSchOptSwitch is selected.

If this parameter is set to INTERVAL_ADAPTIVE, this minimum interval is adaptively adjusted based on the SR period.

If this parameter is set to any other value, this value is the minimum interval. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

A smaller value of this parameter results in a smaller interval of triggering uplink compensation scheduling for VoLTE UEs in talk spurts, a higher probability of triggering uplink compensation scheduling, fewer lost voice packets in the uplink caused by SR missing detections, better voice quality, and more resources to be consumed, which may decrease service volume and throughput.

A larger value of this parameter results in a greater interval of triggering uplink compensation scheduling for VoLTE UEs in talk spurts, a lower probability of triggering uplink compensation scheduling, more lost voice packets in the uplink caused by SR missing detections, worse voice quality, and less resources to be consumed.
