Parameter Name

Mobility Load Balancing UE Selection PRB Usage Threshold
NE

MML Command

MOD CELLMLB

LST CELLMLB
Meaning

Indicates the UE PRB usage threshold for selecting UEs for MLB. If the MlbTriggerMode parameter is set to PRB_ONLY: (1) When downlink MLB is triggered, the eNodeB selects UEs whose downlink PRB usage is greater than this threshold and uplink PRB usage is less than the sum of this threshold and the UeUlPrbLowThdOffset parameter value. (2) When uplink MLB is triggered, the eNodeB selects UEs whose uplink PRB usage is greater than the sum of this threshold and the UeUlPrbHighThdOffset parameter value and downlink PRB usage is less than the sum of this threshold and the UeDlPrbLowThdOffset parameter value. If the MlbTriggerMode parameter is set to UE_NUMBER_ONLY, the eNodeB selects UEs whose downlink PRB usage is less than or equal to the sum of this threshold and the UeDlPrbLowThdOffset parameter value and uplink PRB usage is less than or equal to the sum of this threshold and the UeUlPrbLowThdOffset parameter value. If the MlbTriggerMode parameter is set to PRB_OR_UE_NUMBER, the eNodeB selects UEs that meet the UE selection criterion for either PRB-usage-based or UE-quantity-based MLB. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a larger value, the eNodeB can select fewer UEs for MLB in the transmission direction that triggers the MLB procedure and can select more UEs for MLB in opposite transmission direction when the MlbTriggerMode parameter is set to PRB_ONLY, and the eNodeB selects more UEs for MLB when the MlbTriggerMode parameter is set to UE_NUMBER_ONLY.

A smaller value of this parameter leads to the opposite effects.

When the MlbTriggerMode parameter is set to PRB_ONLY, it is not recommended that the MlbUeSelectPrbThd parameter be set to a value too large. If the parameter value is too large, there is a possibility that no UEs can be selected for MLB and MLB does not take effect.
