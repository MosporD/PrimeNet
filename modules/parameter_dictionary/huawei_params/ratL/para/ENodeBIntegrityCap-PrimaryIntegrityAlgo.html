Meaning

Indicates the highest-priority integrity protection algorithm supported by the eNodeB. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the integrity protection algorithm.

Impact on Radio Network Performance

If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the integrity protection algorithm. If the integrity protection algorithm list that the eNodeB supports and integrity protection algorithms that the UE supports have no intersection, the security mode configuration fails for the UE, resulting in an E-RAB setup failure or handover failure.
