SCC Quiet Time

Parameter Name

SCC Quiet Time
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD CAMGTCFG

LST CAMGTCFG
Meaning

Indicates the SCC unavailability duration. Some multi-mode UEs (for example, SRLTE/SLTE UEs) periodically stop receiving signals of SCells but detect signals of another RAT in CA scenarios. This causes an increase in the number of residual erroneous blocks in the SCells, triggering SCell deactivation. This parameter is used to ensure that the SCells are not deactivated when such UEs are detecting signals of another RAT in CA scenarios.

The parameter value must be greater than the duration for such UEs to detect signals of another RAT. If this parameter is set to 0, the eNodeB triggers SCell deactivation once the eNodeB detects an abnormal level of residual erroneous blocks. If this parameter is set to a value greater than 0, the eNodeB does not trigger SCell deactivation because of residual erroneous blocks within the duration. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value

If an operator deploys both an LTE and an inter-RAT network and there are CA-capable multi-mode UEs that are periodically performing detection of inter-RAT signals, set this parameter based on the UEs' detection period of inter-RAT paging messages.

For example, if the operator deploys both an LTE and a CDMA2000 network and there are CA-capable LTE-CDMA2000 dual-mode UEs, this parameter can be set based on the UEs' detection period of CDMA2000 paging messages. The detection period is usually 40 ms or 80 ms, and therefore this parameter can be set to 40 ms or 80 ms in the preceding scenario.

If the operator deploys only an LTE network or there are no such UEs, the recommended value is 0 ms.

Impact on Radio Network Performance

When this parameter is set to a larger value, it takes a longer time for the SCell to be deactivated when its channel quality is poor. During this time, the number of times residual block errors occur increases and the cell throughput decreases. However, setting this parameter to a larger value decreases the probability for the SCell to get deactivated. SCell deactivation may occur when SRLTE/SLTE UEs periodically detect signals of another RAT on an SCell frequency and cause a large number of residual erroneous blocks.

When this parameter is set to a smaller value, it takes a shorter time for the SCell to be deactivated when its channel quality is poor. This reduces the number of times residual block errors occur. However, setting this parameter to a smaller value increases the probability for the SCell to get deactivated.
