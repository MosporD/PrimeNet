A default value is set for this parameter. The default value is as follows:

MS20(20ms) if the DlBandWidth or UlBandWidth parameter in the Cell MO is set to CELL_BW_N6(1.4M)

MS10(10ms) if the DlBandWidth and UlBandWidth parameter in the Cell MO are set to values other than CELL_BW_N6(1.4M)
