Meaning

Indicates the maximum percentage of RBs that can be used in the low-speed cell, for which the RbBasedInterfAvoid or UlRbBasedInterfAvoid option of the InterfAvoidMode parameter is selected. When high-speed trains travel through a high-speed cell, the eNodeB stops scheduling non-GBR bearers for non-emergency calls in the low-speed cell to reduce interference to high-speed UEs if the number of downlink or uplink RBs used per TTI in the low-speed cell is greater than a specified threshold. (This threshold is the result of the number of RBs of the bandwidth multiplied by the value of this parameter.) This parameter applies only to LTE FDD.

Impact on Radio Network Performance

A smaller value of this parameter results in a more significant effect of interference avoidance based on downlink or uplink RB usage (that is, high-speed UEs experience lower interference) and a greater impact on the low-speed cells when high-speed trains pass by. A larger value of this parameter leads to a less significant effect of interference avoidance based on downlink or uplink RB usage (that is, high-speed UEs experience higher interference) and a smaller impact on the low-speed cells when high-speed trains pass by.
