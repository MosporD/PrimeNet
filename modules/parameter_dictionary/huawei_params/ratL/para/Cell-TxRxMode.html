Parameter Relationship

-Configuration constraints:

  • If the values of the CellActiveState, FddTddInd, TxRxMode, and SubframeAssignment parameters in a Cell MO are CELL_ACTIVE, CELL_TDD, 64T64R, and SA1, respectively, the PreambleFmt parameter in this Cell MO cannot be set to 1, 2, or 3.
  • When the NbCellFlag and TxRxMode parameters in a Cell MO are set to TRUE and a value among 2T2R, 2T4R, or 4T4R, respectively, the CrsPortNum parameter in this Cell MO must be set to CRS_PORT_2.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, both UlCyclicPrefix and DlCyclicPrefix must be set to NORMAL_CP.
  • The SriPeriodAdaptEnhancedOptSw option of the SriAlgoSwitch parameter in the CELLPUCCHALGO MO can be selected only if the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE, the HighSpeedFlag in the Cell MO is set to LOW_SPEED, the MultiRruCellMode parameter in the Cell MO is set to CELL_COMBINATION, and the TxRxMode in the Cell MO is set to 1T1R, 1T2R, 2T2R, or 2T4R; or the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE.
  • When the CPRICompression parameter in the Cell MO is set to 3_2_COMPRESSION, the following conditions must be met: (1) If the FddTddInd parameter in this Cell MO is set to CELL_FDD, the TxRxMode and UlBandWidth parameters must be set to 32T32R and CELL_BW_N75 or CELL_BW_N100, respectively. (2) If the FddTddInd parameter in this Cell MO is set to CELL_TDD, the UlBandWidth parameter must be set to CELL_BW_N75 or CELL_BW_N100, respectively.
  • In a Cell MO, if CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_FDD, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R. If CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_TDD, TxRxMode must be set to 1T1R, 2T2R, 4T4R, or 8T8R, 64T64R, 32T32R.
  • In a Cell MO, if FddTddInd, CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_TDD, CELL_ACTIVE, BOOLEAN_TRUE, and SFN, respectively, TxRxMode must be set to 2T2R, 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to NORMAL_COMPRESSION, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, 8T8R, or 32T32R.
  • In a Cell MO, if CellActiveState is CELL_ACTIVE, FddTddInd is set to CELL_FDD, and CPRICompression is set to ENHANCED_COMPRESSION or TRIPLEX_COMPRESSION_10M, TxRxMode must be set to 1T1R, 1T2R, 2T2R, 2T4R, 4T4R, 8T8R or 32T32R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and CELL_COMBINATION, respectively, TxRxMode must be set to 1T1R, 2T2R or 4T4R or 8T8R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and TWO_RRU_COMBINATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if CellActiveState, MultiRruCellFlag, and MultiRruCellMode are set to CELL_ACTIVE, BOOLEAN_TRUE, and DIGITAL_COMBINATION, respectively, TxRxMode must be set to 1T1R or 2T2R.
  • In a Cell MO, if FddTddInd is set to TDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 2T2R.
  • In a Cell MO, if FddTddInd is set to FDD, MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R or 2T2R or 1T1R.
  • If FddTddInd, MultiRruCellFlag, and MultiRruCellMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, TxRxMode in the Cell MO must be set to 4T4R, 2T4R, 2T2R, 1T2R or 1T1R.
  • In a Cell MO, if FddTddInd, MultiRruCellFlag, and MultiRruCellMode are set to CELL_FDD, BOOLEAN_TRUE, and MPRU_AGGREGATION, respectively, TxRxMode must be set to 4T4R, 2T2R, or 1T1R.
  • In a Cell MO, if TxRxMode is set to 2T8R, both UlCyclicPrefix and DlCyclicPrefix must be set to NORMAL_CP.
  • In a Cell MO, if TxRxMode is set to 4T8R, both UlCyclicPrefix and DlCyclicPrefix must be set to NORMAL_CP.
  • In a Cell MO, if TxRxMode is set to 2T8R, HighSpeedFlag cannot be set to ULTRA_HIGH_SPEED or EXTRA_HIGH_SPEED.
  • In a Cell MO, if TxRxMode is set to 4T8R, HighSpeedFlag cannot be set to ULTRA_HIGH_SPEED or EXTRA_HIGH_SPEED.
  • In a Cell MO, if TxRxMode is set to 2T8R, CustomizedBandWidthCfgInd cannot be set to CFG.
  • In a Cell MO, if TxRxMode is set to 4T8R, CustomizedBandWidthCfgInd cannot be set to CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • In a Cell MO, if TxRxMode and CrsPortNum are set to 4T4R and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 8T2P_00001111, 8T2P_00110011, or 8T2P_01010101.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, or 4T4P_0132.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 8T4P_00112233, or 8T4P_01230123.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, and TxRxMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, MPRU_AGGREGATION, and 4T4R, respectively, CrsPortNum in the Cell MO must be set to CRS_PORT_4 with NbCellFlag set to FALSE, or CrsPortNum in the Cell MO must be set to CRS_PORT_2 with NbCellFlag set to TRUE.
  • When the FddTddInd parameter in the Cell MO is set to CELL_TDD and the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, the EuCellStandbyMode and MultiRruCellFlag parameters in the Cell MO must be set to ACTIVE and BOOLEAN_FALSE respectively.
  • In a Cell MO, if FddTddInd, TxRxMode are set to CELL_FDD, 8T8R, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, and MultiCellShareMode is set to NORMAL, CrsPortNum must be set to CRS_PORT_4 or CRS_PORT_2.
  • In a Cell MO, if FddTddInd is CELL_FDD, TxRxMode is set to 8T8R, HighSpeedFlag must be set to LOW_SPEED.
  • The CompactBwCtrlIntrfMode parameter in a Cell MO can be set to REDUCED_LEFT or REDUCED_RIGHT only if the CustomizedBandWidthCfgInd parameter in this Cell MO is set to CFG and the TxRxMode parameter in this Cell MO is set to 2T4R, 1T1R, 1T2R, or 2T2R.
  • The FakeAntSelIdentificationSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO under a Cell MO must not be selected if FddTddInd in this Cell MO is set to CELL_TDD and TxRxMode in this Cell MO is set to 1T1R or 2T2R.
  • In a Cell MO, if WorkMode is set to LAA, UlEarfcnCfgInd must be set to NOT_CFG.
  • In a Cell MO, if WorkMode is set to LAA, TxRxMode must be set to 2T2R.
