Meaning

Indicates the processing policy applied when there is a conflict between the expiration of the inactivity timer and signaling procedures. The signaling procedures are procedures in which the eNodeB is waiting for Uu interface response messages from UEs, and the messages include RRCConnectionReconfigurationComplete, SecurityModeComplete, RRCConnectionReestablishmentComplete, UECapabilityInformation, and CounterCheckResponse messages. If this parameter is set to DEFAULT, the eNodeB directly releases a UE and terminates the ongoing signaling procedures when the UE inactivity timer expires. If this parameter is set to ALL_SIGNALING_FLOW_FIRST, the eNodeB continues processing the ongoing signaling procedures and does not directly release the UE when the UE inactivity timer expires. If this parameter is set to ONLY_ERAB_SETUP_FLOW_FIRST, the eNodeB does not directly release the UE and continues processing a bearer setup procedure only when the UE inactivity timer expires and the bearer setup procedure is ongoing. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to DEFAULT, there is no impact on network performance. If this parameter is set to ALL_SIGNALING_FLOW_FIRST, ongoing signaling procedures cannot be interrupted when the UE inactivity timer expires. In this case, the number of normal releases decreases, the number of abnormal releases increases. If the signaling procedures fail at the end, the corresponding KPIs deteriorate. If this parameter is set to ONLY_ERAB_SETUP_FLOW_FIRST, ongoing E-RAB setup procedures cannot be interrupted when the UE inactivity timer expires. If the procedures succeed at the end, the number of successful E-RAB setups increases. If the procedures fail at the end, the number of abnormal E-RAB releases increases.
