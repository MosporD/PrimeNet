Meaning

Indicates the SRS period for resources always reserved in the first half frame for inter-cell D-MIMO, DL CoMP, and UL CAMC. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If this parameter is set to 10ms(10ms), the SRS period for UEs with reserved resources is short, and user experience is good. However, the number of UEs supported for measurement is small. If this parameter is set to 40ms(40ms), the SRS period for UEs with reserved resources is long, and user experience is poor. However, the number of UEs supported for measurement is large. If this parameter is set to 20ms(20ms), the SRS period for UEs with reserved resources, user experience, and the number of UEs supported for measurement are in the middle. If this parameter is modified after resource reservation takes effect, the reserved resources are no longer available for UEs that use them before the parameter modification, and the SRS period for these resources is reconfigured.
