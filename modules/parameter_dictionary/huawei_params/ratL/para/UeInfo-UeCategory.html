Meaning

Indicates the UE categories of defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-Category, ue-Category-v1020, ue-Category-v1170, ue-Category-v11a0, ue-Category-v1250, and ue-Category-NB-r13.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bit 0 stands for category 1, bit 1 stands for category 2, bit 2 stands for category 3, ..., bit 9 stands for category 10, bit 10 stands for category 11, bit 11 stands for category 12, bit 12 stands for category 0, and bit 13 stands for category_nb1. Other bits are reserved. If the value of a bit is 1, the corresponding UE category is supported by a UE. For example, if a UE supports both categories 4 and 6, the binary number indicating the UE category information is 101000. This binary number can be converted into 40 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.
