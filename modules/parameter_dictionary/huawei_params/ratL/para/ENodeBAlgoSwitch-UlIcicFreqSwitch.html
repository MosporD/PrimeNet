Meaning

Indicates whether to enable uplink ICIC in the frequency domain. If this parameter is set to OFF(Off), uplink ICIC in the frequency domain is disabled for cells served by the eNodeB. If this parameter is set to STATIC(Static), uplink static CIC in the frequency domain is enabled for cells served by the eNodeB. If this parameter is set to DYNAMIC(Dynamic), uplink dynamic ICIC in the frequency domain is enabled for cells served by the eNodeB. If uplink adaptive ICIC is enabled, neither static nor dynamic ICIC is enabled. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

When this parameter is set to STATIC or DYNAMIC, the UL ICIC feature is enabled. Cell edge users (CEUs) will transmit signals in edge frequency bands, and cell center users (CCUs) will transmit signals in center frequency band. In this situation, the average cell throughput decreases, and UL throughput of CEUs increases.

When this parameter is set to OFF, the UL ICIC feature is disabled. The UL throughput of CEUs will not increase.
