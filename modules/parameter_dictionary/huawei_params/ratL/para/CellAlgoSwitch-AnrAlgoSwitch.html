Meaning

Indicates whether to enable automatic neighbor relation (ANR). This parameter provides the following options:

BACKWARD_ANR_SW: When intra-RAT event-triggered ANR or intra-RAT fast ANR is enabled and the BACKWARD_ANR_SW option is selected for the target cell of an ANR procedure, the cell can add the source cell to its NCL and NRT after obtaining source cell information. If BACKWARD_ANR_SW is deselected, the target cell does not add the source cell to its NCL or NRT. This option applies only to LTE FDD and LTE TDD.

INTRA_RAT_OVERDISTANCE_SW: If this option is selected and intra-RAT neighboring cell classification takes effect in memory mode, the eNodeB reports information about intra-RAT neighboring cells to the MAE for the MAE to detect over-distant neighboring cells and handles the detection result returned by the MAE. If this option is deselected, the eNodeB does not report information about intra-RAT neighboring cells to the MAE or handle the over-distant neighboring cell detection result returned by the MAE. This option applies only to LTE FDD and LTE TDD.

UTRAN_OVERDISTANCE_SW: If this option is selected and neighboring UTRAN cell classification takes effect, the eNodeB reports information about neighboring UTRAN cells to the MAE for the MAE to detect over-distant neighboring UTRAN cells and handles the detection result returned by the MAE. If this option is deselected, the eNodeB does not report information about neighboring UTRAN cells to the MAE or handle the over-distant neighboring UTRAN cell detection result returned by the MAE. This option applies only to LTE FDD and LTE TDD.

LTE_AUTON_GAP_CGI_SW: If this option is selected, the eNodeB instructs UEs that support autonomous gaps to use autonomous gaps to read the CGIs of neighboring cells. If this option is deselected, the eNodeB does not instruct such UEs to use autonomous gaps to read the CGIs of neighboring cells. This option applies only to LTE FDD and LTE TDD.

Disuse statement: BACKWARD_ANR_SW: The option will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

Impact on Radio Network Performance

BACKWARD_ANR_SW: If this option is deselected, addition of neighbor relationships by backward ANR does not take effect, preventing the addition of redundant neighbor relationships and PCI confusion. However, the efficiency of adding unknown neighbor relationships decreases, reducing the handover success rate and increasing the service drop rate in the case of PCI confusion between neighboring cells. If this option is selected, addition of neighbor relationships by backward ANR takes effect and unknown neighbor relationships can be added promptly. However, redundant neighbor relationships may also be added and confused neighboring cell PCI configurations may be introduced, reducing the handover success rate and increasing the service drop rate in the case of CGI reading failure before handovers.

INTRA_RAT_OVERDISTANCE_SW: If this option is selected, the eNodeB identifies intra-RAT over-distant neighboring cells and does not hand over UEs to such cells, reducing handover failures and increasing the intra-RAT handover success rate. If this option is deselected, the eNodeB may hand over UEs to over-distant neighboring cells, causing handover failures.

UTRAN_OVERDISTANCE_SW: If this option is selected, the eNodeB identifies over-distant neighboring UTRAN cells and does not hand over UEs to such cells, reducing handover failures and increasing the success rate of handovers to neighboring UTRAN cells. If this option is deselected, the eNodeB may hand over UEs to over-distant neighboring UTRAN cells, causing handover failures.

LTE_AUTON_GAP_CGI_SW: If this option is selected, UEs use autonomous gaps to read the CGIs of neighboring cells, which reduces the CGI reading time. However, data transmission is temporarily suspended between the UEs and the network, which reduces UE throughput.
