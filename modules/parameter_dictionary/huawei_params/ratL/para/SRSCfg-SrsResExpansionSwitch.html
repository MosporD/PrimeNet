SRS Resource Expansion Switch

Parameter ID SrsResExpansionSwitch
Parameter Name

SRS Resource Expansion Switch
NE

BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE
MML Command

MOD SRSCFG

LST SRSCFG
Meaning

Indicates whether to enable SRS resource expansion. If this parameter is set to OFF, SRS resource expansion is disabled. If this parameter is set to SRS_RES_EXPANSION_MODE, SRS resource expansion is enabled. This parameter applies only to LTE TDD.

Impact on Radio Network Performance

If this parameter is set to OFF, the current SRS resource allocation mode is used, and network performance is not affected. If this parameter is set to SRS_RES_EXPANSION_MODE, the air interface resources used for transmitting SRS in a cell increase, and the downlink spectral efficiency of the cell increases.
