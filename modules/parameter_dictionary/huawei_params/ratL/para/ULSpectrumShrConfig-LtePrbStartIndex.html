Caution

If UMTS and LTE spectrum sharing is enabled and the PrbRsvType parameter is set to LTE_DL_AVAILABLE_PRB or LTE_UL_AVAILABLE_PRB, modification of the LtePrbStartIndex or LtePrbEndIndex parameter will cause cells referencing the parameter configurations for UMTS and LTE spectrum sharing to restart.

If UMTS and LTE Spectrum Sharing Based on DC-HSDPA is enabled and the PrbRsvType parameter is set to LTE_DL_AVAILABLE_PRB or LTE_UL_AVAILABLE_PRB, modification of the LtePrbStartIndex or LtePrbEndIndex parameter will cause cells referencing the parameter configurations for UMTS and LTE Spectrum Sharing Based on DC-HSDPA to restart.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

When the PrbRsvType parameter is set to LTE_DL_AVAILABLE_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more available PRBs in the downlink of LTE, higher throughput, but fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_UL_AVAILABLE_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more available PRBs in the uplink of LTE, higher throughput, but fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_HIGH_PRIORITY_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more high-priority LTE PRBs and less impact on UMTS performance; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, or UMTS_CORE_SPECTRUM_4, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more UMTS preferential spectrum resources, higher UMTS cell capacity in the uplink, fewer spectrum resources available to LTE CEUs in the uplink, and lower LTE cell capacity in the uplink; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to UMTS_LTE_SHARED_SPECTRUM, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that can be shared by UMTS and LTE and lower uplink capacity of LTE cells in the bufferzone; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_PUCCH_AVAILABLE_PRB, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that can be used for LTE PUCCH, and fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that UMTS can share with LTE, but fewer spectrum resources for LTE PUCCH, which may lead to cell activation failure.
