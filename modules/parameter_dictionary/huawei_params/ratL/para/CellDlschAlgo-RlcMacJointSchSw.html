Meaning

Indicates whether to enable RLC and MAC joint scheduling. RetransOptSwitch(RetransOptSwitch): Indicates whether to enable retransmission optimization of RLC/MAC joint scheduling. If this option is selected, retransmission optimization of RLC and MAC joint scheduling is enabled. If this option is deselected, retransmission optimization of RLC and MAC joint scheduling is disabled. This option applies only to UEs running unlimited services. This parameter does not apply to LBBPc boards. This parameter applies only to LTE TDD cells.
