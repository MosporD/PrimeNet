Impact on Radio Network Performance

If this parameter is set to BW_2DOT6M, BW_10DOT8M, BW_12DOT5M, BW_14DOT4M, BW_17DOT4M, or BW_23DOT9M, it has no impact on the throughput of a single cell. If this parameter is set to BW_4M, BW_5DOT7M, BW_7DOT3M, BW_7DOT6M, BW_12DOT2M, BW_17DOT1M, BW_27DOT6M, BW_28DOT5M, BW_8DOT6M, BW_8DOT9M, BW_14DOT1M, BW_18DOT7M, or BW_19M and RB puncture is performed in a single cell, the number of available RBs is lower than that of a standard cell with the same bandwidth, causing the uplink and downlink throughput to decrease.
