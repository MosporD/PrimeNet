Meaning

Indicates the threshold of downlink RSRP difference used to maintain the interference measurement sets of UEs in intra-eNodeB and inter-eNodeB coordinated uplink AMC algorithms. This parameter applies only to LTE TDD.

The interference measurement sets of UEs are maintained based on this parameter after the downlink RSRP measurement value is received.

The eNodeB selects two intra-frequency neighboring cells with large downlink RSRP differences (calculated by the RSRP of the neighboring cell minus the RSRP of the serving cell) from the CoMP set. If both large downlink RSRP differences are greater than this threshold, the neighboring cells are added to the interference measurement set.

If both the UlCamcSw and UlInterEnbCamcSw options of the CamcSwitch parameter are selected, the interference measurement set must be determined based on the interference factor.

Impact on Radio Network Performance

A smaller value of this parameter results in a higher probability that a cell is added to the interference measurement set, more accurate MCS selection in the uplink coordinated AMC algorithm, higher uplink throughput, but more signaling overheads over the air interface and a more complex processing mechanism.
