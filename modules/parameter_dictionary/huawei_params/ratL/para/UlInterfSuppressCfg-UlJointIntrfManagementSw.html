Meaning

Indicates whether to enable functions related to uplink multi-cell joint interference management.

UL_JOINT_INTRF_POSITION_SW: Indicates whether to enable uplink multi-cell joint interference locating. Uplink multi-cell joint interference locating takes effect only if this option is selected. This option applies only to LTE FDD.

UL_JOINT_INTRF_SUPPRESS_SW: Indicates whether to enable uplink joint interference suppression. Uplink joint interference suppression takes effect only if this option is selected. This option applies only to LTE FDD.

UL_NARROWBAND_INTRF_SCH_OPT_SW: Indicates whether to enable scheduling optimization for uplink narrowband interference reduction. Scheduling optimization for uplink narrowband interference reduction takes effect only if this option is selected. This option applies only to LTE FDD.

Impact on Radio Network Performance

UL_JOINT_INTRF_POSITION_SW: This option has no impact on radio network performance.

UL_JOINT_INTRF_SUPPRESS_SW: If this option is selected, the interference resistance capability improves in scenarios where there is external interference and the gain-producing conditions of uplink joint interference suppression are met. As a result, the uplink UE throughput increases and the uplink voice packet loss rate decreases. If this option is deselected, network performance is not affected.

UL_NARROWBAND_INTRF_SCH_OPT_SW: If this option is selected and there is narrowband interference, the impact of narrowband interference can be reduced through scheduling. As a result, the uplink throughput of cell edge UEs increases and the uplink voice packet loss rate decreases. If this option is deselected, network performance is not affected.
