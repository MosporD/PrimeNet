MML Command

MOD ENODEBALGOSWITCH

LST ENODEBALGOSWITCH
Meaning

Indicates whether to enable virtual grid algorithms.

AI_GRID_FUN_SW: Indicates whether to enable virtual-grid-based measurement result prediction. If this option is selected, the eNodeB constructs a virtual grid model used to predict measurement results for algorithm optimization. If this option is deselected, the eNodeB does not construct such a virtual grid model. This option applies only to LTE FDD and LTE TDD.

PCC_MEAS_PREDICT_SW: Indicates whether to enable virtual-grid-based measurement result prediction for PCC anchoring. If this option is selected, the eNodeB uses the virtual grid to predict PCC frequencies and signal quality of cells during PCC anchoring. If this option is deselected, the eNodeB does not use the virtual grid to predict PCC frequencies or signal quality of cells. This option applies only to LTE FDD and LTE TDD.

SCC_MEAS_PREDICT_SW: Indicates whether to enable virtual-grid-based measurement result prediction for SCC configuration. If this option is selected, the eNodeB uses the virtual grid to predict SCC frequencies and signal quality of cells during SCC configuration. If this option is deselected, the eNodeB does not use the virtual grid to predict SCC frequencies or signal quality of cells. This option applies only to LTE FDD and LTE TDD.

MLB_MEAS_PREDICT_SW: Indicates whether to enable virtual-grid-based measurement result prediction for MLB. If this option is selected, the eNodeB uses the virtual grid to predict target frequencies and signal quality of target cells for MLB. If this option is deselected, the eNodeB does not use the virtual grid to predict target frequencies or signal quality of target cells for MLB. This option applies only to LTE FDD and LTE TDD.

COV_IF_HO_MEAS_PREDICT_SW: Indicates whether to enable virtual-grid-based measurement result prediction for coverage-based inter-frequency handovers. If this option is selected, the eNodeB uses the virtual grid to predict target frequencies and signal quality of target cells for coverage-based inter-frequency handovers. If this option is deselected, the eNodeB does not use the virtual grid to predict target frequencies or signal quality of target cells for coverage-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

SERV_IF_HO_MEAS_PREDICT_SW: Indicates whether to enable virtual-grid-based measurement result prediction for service-based inter-frequency handovers. If this option is selected, the eNodeB uses the virtual grid to predict target frequencies and signal quality of target cells for service-based inter-frequency handovers. If this option is deselected, the eNodeB does not use the virtual grid to predict target frequencies or signal quality of target cells for service-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

Disuse statement: AI_GRID_FUN_SW:This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Impact on Radio Network Performance

AI_GRID_FUN_SW: If this option is selected, the eNodeB collects data on the live network and trains the collected data, which may slightly decrease cell throughput and increase the CPU usage of the main control board. If this option is deselected, network performance is not affected.

PCC_MEAS_PREDICT_SW: If this option is selected, the virtual-grid-based prediction of PCC frequencies and cell signal quality helps decrease inter-frequency measurements and increase the user-perceived rate and cell throughput. If this option is deselected, network performance is not affected.

SCC_MEAS_PREDICT_SW: If this option is selected, the virtual-grid-based prediction of SCC frequencies and cell signal quality helps decrease inter-frequency measurements and increase the user-perceived rate and cell throughput. If this option is deselected, network performance is not affected.

MLB_MEAS_PREDICT_SW: If this option is selected, the virtual-grid-based prediction of target frequencies and target cell signal quality for MLB helps decrease inter-frequency measurements and increase the user-perceived rate and cell throughput. If this option is deselected, network performance is not affected.

COV_IF_HO_MEAS_PREDICT_SW: If this option is selected, the virtual-grid-based prediction of target frequencies and target cell signal quality for coverage-based inter-frequency handovers helps decrease inter-frequency measurements and increase user-perceived rate and cell throughput. If this option is deselected, network performance is not affected.

SERV_IF_HO_MEAS_PREDICT_SW: If this option is selected, the virtual-grid-based prediction of target frequencies and target cell signal quality for service-based inter-frequency handovers helps decrease inter-frequency measurements and increase user-perceived rate and cell throughput. If this option is deselected, network performance is not affected.
