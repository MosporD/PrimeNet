Meaning

Indicates the period for automatic optimization on neighboring cell measurement priorities. The neighboring cell measurement priorities are determined based on the number of times each neighboring cell is measured within the optimization period. Suggestions on the priorities are provided after the optimization period has elapsed. The period is one week by default. Neighboring cell selection for handovers does not take these priorities into consideration before the suggestions are available. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Caution

A smaller value of this parameter, indicating a shorter evaluation period, results in less data sampled in this period and lower accuracy of statistical results. A larger value of this parameter leads to the opposite effects.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If this parameter is set to a smaller value, neighboring cell measurement priorities are less stable, and therefore neighboring cell selection is less accurate.
