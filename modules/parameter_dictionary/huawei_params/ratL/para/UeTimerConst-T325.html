Meaning

Indicates the length of timer 325. For details, see 3GPP TS 36.331. This timer starts when a UE receives an RRCConnectionReject message containing the deprioritisationReq IE. When the timer expires, the cell reselection priorities that have been reduced using RRCConnectionReject for E-UTRAN frequencies are restored. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

If this parameter is set to a larger value, the cell reselection priority of an E-UTRAN frequency which is contained in the RRCConnectionReject message including the deprioritisationReq IE is lowered for a longer time, the number of RRC connection setup failures on a high-priority frequency becomes smaller, but the UE cannot camp on a high-priority frequency for a longer time. If this parameter is set to a smaller value, the cell reselection priority of an E-UTRAN frequency which is contained in the RRCConnectionReject message including the deprioritisationReq IE is lowered for a shorter time, the number of RRC connection setup failures on a high-priority frequency becomes larger, and the UE attempts to camp on a high-priority frequency more frequently.
