Meaning

Indicates the mapping between a cell-specific reference signal (CRS) port and a transmit (TX) channel in an RRU. In cells with one or two TX channels, this parameter cannot be set. In cells with four or eight TX channels, this parameter can be set. As defined in 3GPP specifications, the CrsPortNum parameter can be set to CRS_PORT_1, CRS_PORT_2, or CRS_PORT_4. The value CRS_PORT_1 indicates that one CRS port (port 0) is configured. The value CRS_PORT_2 indicates that two CRS ports (ports 0 and 1) are configured. The value CRS_PORT_4 indicates that four CRS ports (ports 0, 1, 2 and 3) are configured. In values of this parameter, mTnP indicates that the number of TX channels configured for a cell is "m" and the number of CRS ports is "n". The parameter value 4TnP_abcd indicates that reference signals transmitted over CRS ports a, b, c, and d are mapped to TX channels 1, 2, 3, and 4 in an RRU, respectively (The TX channel number here is for reference only and may be R0A to R0D, or others). The parameter value 8TnP_abcdefgh indicates that reference signals transmitted over CRS ports a to h are mapped to TX channels 1 to 8 in an RRU, respectively. Duplicate numbers of abcd or abcdefgh indicate that virtual antenna mapping (VAM) is applied, that is, the reference signals transmitted over the CRS ports are mapped to corresponding TX channels. The parameter value NOT_CFG indicates that the mapping between a CRS port and a TX channel in an RRU is not configured, and CRS ports are mapped to TX channels in an RRU in a default manner. In TDD cells, "n" in mTnP must be equal to the CrsPortNum parameter value. For cells established on LBBPc boards, the parameter value NOT_CFG takes effect regardless of the actual parameter setting. This parameter applies only to LTE FDD and LTE TDD.

Default Value

NOT_CFG(Not configure)
Recommended Value

This parameter requires TX channels in an RRU and the physical antennas be connected in the corret sequence. The recommended values of this parameter vary as follows:

1. In an FDD cell served by two combined RRUs and with four TX channels and four CRS ports configured, the parameter value 4T4P_0213 is recommended.

2. In an FDD cell served by an integrated RRU and with four TX channels and four CRS ports configured, the parameter value 4T4P_0321 is recommended.

3. In a TDD cell with four TX channels and two CRS ports configured, the parameter value 4T2P_0011 is recommended.

4. In a TDD cell with four TX channels and four CRS ports configured, the parameter value 4T4P_0213 is recommended.

5. In a TDD cell in broadcast beamforming and with eight TX channels and two CRS ports configured, the parameter value 8T2P_00001111 is recommended.

6. In a TDD cell in phase shift diversity and with eight TX channels and two CRS ports configured, the parameter value 8T2P_00110011 is recommended.

7. In a TDD cell in broadcast beamforming and with eight TX channels and four CRS ports configured, the parameter value 8T4P_00112233 is recommended.

8. In a TDD cell in phase shift diversity and with eight TX channels and four CRS ports configured, the parameter value 8T4P_01230123 is recommended.

9. In an FDD cell with four TX channels and two CRS ports configured, the parameter value 4T2P_0011 is recommended.

Parameter Relationship

-Configuration constraints:

  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • In a Cell MO, if TxRxMode and CrsPortNum are set to 4T4R and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_1, respectively, CrsPortMap must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 8T2P_00001111, 8T2P_00110011, or 8T2P_01010101.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 4T4R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, or 4T4P_0132.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_TDD, 8T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 8T4P_00112233, or 8T4P_01230123.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_2, respectively, CrsPortMap must be set to NOT_CFG, 4T2P_0011, 4T2P_0101, or 4T2P_0110.
  • In a Cell MO, if FddTddInd, TxRxMode, and CrsPortNum are set to CELL_FDD, 4T8R, and CRS_PORT_4, respectively, CrsPortMap must be set to NOT_CFG, 4T4P_0213, 4T4P_0231, 4T4P_0123, 4T4P_0132, 4T4P_0312, or 4T4P_0321.
  • If MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_TDD, or if MultiRruCellFlag in a Cell MO is set to BOOLEAN_TRUE and FddTddInd in the Cell MO is set to CELL_FDD and MultiRruCellMode in the Cell MO is set to a value other than SFN and MPRU_AGGREGATION, CrsPortMap in the Cell MO must be set to NOT_CFG.
  • In a Cell MO, if FddTddInd, TxRxMode are set to CELL_FDD, 8T8R, respectively, CrsPortMap must be set to NOT_CFG.

-Parameter relationship with conditions:

  • If TxRxMode is set to 4T4R, 4T8R, 8T8R, CrsPortMap is valid.

Impact on Radio Network Performance

For different installation orders of TX channels in RRUs and physical antennas, the setting of this parameter also determines the mapping between CRS ports and physical antenna ports. Downlink multiple-input multiple-output (MIMO) performance is determined by the polarization and spacing between antennas. Assume that TX channels in an RRU and physical antennas are connected in order. Setting this parameter to NOT_CFG has no impact on network performance. Setting this parameter to recommended values improves downlink throughput, especially in RRU combination networking. Setting this parameter to other values may degrade network performance. The recommended value for this parameter differs according to networking, the number of configured TX channels, and the number of configured CRS ports.
