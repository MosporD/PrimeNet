MML Command

MOD CELLUSPARACFG

Meaning

Indicates whether to enable functions related to US VoLTE UEs.

US_VOLTE_UE_STEERING_SW: Indicates whether to allow steering of US VoLTE UEs with QCI-1 bearers. Steering of US VoLTE UEs with QCI-1 bearers is allowed only if this option is selected. This option applies only to LTE FDD and LTE TDD.

US_VOLTE_RTP_REORDER_SW: Indicates whether to enable RTP reordering for US VoLTE UEs. RTP reordering is enabled for US VoLTE UEs only if this option is selected. This option applies only to LTE FDD and LTE TDD.

US_VOLTE_UE_STEERING_SW: When this option is selected, the number of handovers increases. When this option is deselected, network performance is not affected.

US_VOLTE_RTP_REORDER_SW: When this option is selected, voice packet disorder caused by transmission issues can be fixed. When this option is deselected, network performance is not affected.
