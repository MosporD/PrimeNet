Meaning

Indicates whether to enable network performance optimization when the network is heavily loaded. This parameter consists of the following options:

SPECSIGRETRANSOPTSWITCH: Indicates whether to optimize special signaling retransmission. If this option is selected, the eNodeB adaptively configures the maximum number of special signaling retransmissions that can be initiated by the RLC layer based on the number of UEs in the cell. If this option is deselected, the eNodeB cannot adaptively configure the maximum number of special signaling retransmissions that can be initiated by the RLC layer based on the number of UEs in the cell. This option applies only to LTE FDD and LTE TDD.

FlowCtrlTriBackoffSwitch: Indicates whether to enable flow-control-triggered backoff. Consider that the network is heavily loaded and Msg3 flow control starts. If this option is selected, flow-control-triggered backoff is enabled, and UEs that fail random accesses are postponed to reinitiate random access requests, thereby relieving RACH congestion. If this option is deselected, flow-control-triggered backoff is disabled. During random access procedures, if flow-control-triggered backoff is required and the lengths of timers T300 and T301 are too short, the number of initiated access requests decreases and the access success rate decreases. Therefore, if this option is selected, 2000 ms is recommended for the timers T300 and T301. This option applies only to LTE FDD and LTE TDD.

FlowCtrlForwardSwitch: Indicates whether to perform flow control at the initial stage of a signaling procedure. If this option is selected, when Msg3 flow control starts, the Msg1 flow control threshold is set to a smaller value to reduce the number of UEs' random access requests, reducing system load. This option applies only to LTE FDD and LTE TDD.

FlowCtrlBaseOnUuRsrSwitch: Indicates whether to enable the flow control based on air interface resources. If this option is selected, cell-level MSG3 flow control is triggered to reduce the CCE resource consumption for signaling transmission when CCE resources for signaling transmission are insufficient in a cell with subframe configuration 2. This option applies only to LTE FDD and LTE TDD.

Msg3FlowCtrlOptSwitch: Indicates whether to optimize Msg3 flow control. If this option is selected, the Msg3 flow control protection threshold for the LBBPd is increased. This option applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

FlowCtrlBaseOnUuUlRsrSwitch: If this option is selected, the inter-RAT handover command and the maximum times of retransmissions of the RRC Connection Release message can be adjusted based on the number of UEs in a cell, to reduce the retransmissions and save air interface resources.

If this option is deselected, the eNodeB may retransmit inter-RAT handover command many times because the UE may not send the HARQ/ARQ to confirm the inter-RAT handover command, and the eNodeB may retransmit the RRC Connection Release message many times because the UE does not send ACK to confirm the reception of the RRC Connection Release message. The uplink and downlink throughput of the cell may deteriorate if retransmissions occur.

FlowCtrlTriBackoffSwitch: If this option is selected, the backoff value is adjusted based on the MSG3 flow control. If contention and conflict resolution for a UE fails, the UE reinitiates random access with a delay, relieving the RACH congestion. However, the random access delay for the UE increases and the number of preambles sent by the UE decreases, increasing the service drop rate. If this option is deselected, the RACH congestion cannot be relieved, but the random access delay for the UE decreases.

FlowCtrlForwardSwitch: If this option is selected, the MSG1 flow control threshold decreases when the MSG3 flow control is performed, reducing the number of random access requests and saving air interface resources.

FlowCtrlBaseOnUuRsrSwitch: If this option is selected, cell-level MSG3 flow control is triggered to reduce the CCE resource consumption for signaling transmission when CCE resources for signaling transmission are insufficient in a cell.

Msg3FlowCtrlOptSwitch: If this option is selected, the Msg3 flow control protection threshold for the LBBPd board is increased. In scenarios where the LBBPd CPU load is not high and Msg3 flow control is triggered by simultaneous network access of a large number of UEs in a short time, the number of RRC Connection Request messages discarded due to flow control may decrease and the number of successful RRC connection setups increases. In scenarios where the signaling loads of multiple LBBPd boards are heavy and signaling overhead occurs on the main control board, the number of RRC Connection Reject messages sent as a result of flow control may increase, and therefore the RRC connection setup success rate decreases; in addition, the random access response rate will fluctuate. If this option is deselected, there is no impact.
