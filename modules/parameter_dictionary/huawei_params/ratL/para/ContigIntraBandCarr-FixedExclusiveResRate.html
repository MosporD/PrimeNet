Meaning

Indicates the proportion of resources that are always exclusively used in a cell to the total resources in the cell. If this parameter is set to 80, 80% of the resources in the cell are always exclusively used. If this parameter is set to 100, all resources in the cell are always exclusively used, that is, resources in the cell are not shared. If this parameter is set to 255, the proportion does not take effect. This parameter applies only to LTE FDD.

Caution

Changing the value of this parameter will cause the local cell and the cells that use the same RF equipment as the local cell and have spectrum overlap with the local cell to restart.

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

A smaller value of this parameter leads to a smaller network capacity and lower average UE throughput. A larger value of this parameter leads to the opposite effects.
