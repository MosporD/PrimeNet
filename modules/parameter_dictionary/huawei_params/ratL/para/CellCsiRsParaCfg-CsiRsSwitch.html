Meaning

Indicates whether to configure CSI-RSs for UEs. If this parameter is set to NOT_CFG(Not configure), the eNodeB does not configure CSI-RSs for UEs. If this parameter is set to FIXED_CFG(Fixed configure), the eNodeB configures CSI-RSs for UEs that support CSI-RSs. If this parameter is set to ADAPTIVE_CFG(ADAPTIVE_CFG), the eNodeB determines whether to configure CSI-RSs for UEs that support CSI-RSs based on the proportion of TM9 UEs. When SfnLoadBasedAdptSwitch is deselected in a TDD cell with adaptive SFN enabled, neither FIXED_CFG nor ADAPTIVE_CFG takes effect. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

The setting of this parameter determines the CSI-RS configuration mode of a cell. If this parameter is set to NOT_CFG, CSI-RSs are not transmitted in a cell, which does not affect the performance of UEs that access the cell after the parameter is set. If this parameter is set to FIXED_CFG, CSI-RSs are always transmitted in a cell, and TM9 UEs directly enter TM9 mode to obtain TM9 gains. However, CSI-RSs cause performance loss on R8 and R9 UEs. If this parameter is set to ADAPTIVE_CFG, the eNodeB adaptively determines to configure or not configure CSI-RSs based on the proportion of TM9 UEs in a cell. This reduces the negative impact of a low TM9 penetration rate on the network and increases the average cell throughput when CSI-RSs are configured. Changing the parameter value affects the performance of UEs who are running services. When the value of this parameter is changed from FIXED_CFG or ADAPTIVE_CFG to NOT_CFG, CSI-RSs are no longer configured. In this case, as stipulated in 3GPP specifications, online UEs in TM9 mode switch from closed-loop rank adaptation to open-loop rank 1 and experience significant performance deterioration. When the value of this parameter is changed from NOT_CFG to FIXED_CFG or ADAPTIVE_CFG, CSI-RS configuration does not notably affect UEs complying with 3GPP R10 or a later version, and performance loss occurs on UEs complying with 3GPP R8 or R9. You are advised not to change the value of this parameter frequently.
