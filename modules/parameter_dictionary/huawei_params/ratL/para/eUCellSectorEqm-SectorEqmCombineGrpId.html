Meaning

Indicates the ID of a sector equipment combination group, which contains multiple sets of sector equipment. The value 255 indicates that the sector equipment is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.

Caution

Changes in the parameter value will update the relationship between the cell and the sector equipment and therefore cause service interruption.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

If the Virtual4T4RSwitch option is selected and the TX/RX mode is 2T2R or 2T4R, the SectorEqmCombineGrpId parameter must be set to 0 for some pieces of sector equipment of the cell and to 1 for the other pieces of sector equipment of the cell. If the SectorEqmCombineGrpId parameter is set to 0 or 1 for all pieces of sector equipment of the cell, the cell does not support Rank 3 or Rank 4 4x4 MIMO, and the throughput decreases.
