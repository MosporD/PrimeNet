Meaning

LOADNOTBALANCESCHSWITCH: Indicates whether to enable MAC scheduling optimization for cells with unbalanced inter-cell or intra-cell (uplink and downlink) loads in heavy traffic scenarios. The optimization is enabled only when this switch is on.

SFNDLSCHCAPBOOSTSWITCH: Indicates whether to enable downlink scheduling optimization for SFN cells in which adaptive scheduling is used in the downlink. If this option is deselected, downlink scheduling optimization is disabled for SFN cells. If this option is selected, downlink scheduling optimization is enabled for SFN cells and the eNodeB allocates more scheduling processing resources to such SFN cells. This option is invalid for non-SFN cells or SFN cells that do not use adaptive scheduling in the downlink. This parameter applies only to LTE FDD.

DL_SCH_TIME_SEQUENCE_ADAPT_SW: Indicates whether to adaptively adjust the downlink scheduling time sequence. The scheduling time sequence for retransmissions and initial transmissions is adaptively adjusted based on the load status only if this option is selected. This option applies only to LTE FDD.

NB_LOAD_BALANCING_SCH_OPT_SW: Indicates whether to optimize NB-IoT scheduling for load balancing. NB-IoT scheduling is optimized for load balancing only if this option is selected. This option applies only to NB-IoT.

NB_LB_SCH_THREAD_ADAPT_SW: Indicates whether to enable scheduling thread adaptation for NB-IoT load balancing. Scheduling thread adaptation for NB-IoT load balancing is enabled only if this option is selected. This option applies only to NB-IoT.

DL_SIG_SCH_LATENCY_OPT_SW: Indicates whether to enable fast scheduling of downlink signaling. If this option is selected, fast scheduling of downlink signaling is enabled. If this option is deselected, fast scheduling of downlink signaling is not supported. This option applies only to LTE FDD.

Impact on Radio Network Performance

LOADNOTBALANCESCHSWITCH:

If this switch is off, this switch has no impact on network performance.

If this switch is on, the uplink scheduling end time and downlink scheduling end time are dynamically adjusted and scheduling request indicators (SRIs) are hashed for cells with unbalanced inter-cell or intra-cell (uplink and downlink) loads in heavy traffic scenarios. As a result, the number of UEs scheduled per transmission time interval (TTI) and the physical resource block (PRB) usage increase for cells established in LBBPc boards.

SFNDLSCHCAPBOOSTSWITCH: If this option is deselected, default scheduling processing is used and there is no impact on radio network performance and KPIs. If this option is selected, the number of UEs scheduled per TTI in the downlink and the PRB usage increase in heavily loaded SFN cells in large traffic scenarios.

DL_SCH_TIME_SEQUENCE_ADAPT_SW: If this option is selected, the probability of successful scheduling for initial transmissions increases and the performance indicators such as the number of downlink scheduled UEs, downlink PRB usage, and downlink throughput in the cell improve in heavy load scenarios. The user-plane CPU-usage-related counter values increase. If this option is deselected, network performance is not affected.

NB_LOAD_BALANCING_SCH_OPT_SW: If this option is selected, the uplink and downlink subcarrier usage increases in multi-carrier heavy-traffic scenarios. If this option is deselected, radio network performance and related KPIs are not affected.

NB_LB_SCH_THREAD_ADAPT_SW: If this option is selected, the uplink and downlink subcarrier usage and throughput increase when the cell is heavily loaded. If this option is deselected, network performance and KPIs are not affected.

DL_SIG_SCH_LATENCY_OPT_SW: If this option is selected, the downlink signaling scheduling delay is shortened. If this option is deselected, there is no impact on wireless network performance and KPIs.
