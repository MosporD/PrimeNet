MOD CSFALLBACKBLINDHOCFG

LST CSFALLBACKBLINDHOCFG
Meaning

Indicates whether the eNodeB selects the target frequency in a round robin (RR) manner from frequencies with the same priority in blind redirections for CSFB to UTRAN. If this parameter is set to ON(On), the function of target frequency selection in an RR manner is enabled. If this parameter is set to OFF(Off), this function is disabled. This parameter applies only to LTE FDD and LTE TDD.

Disuse statement: The UtranCsfbBlindRedirRrSw parameter will be replaced by the CsfbFlowOptSwitch parameter in the GlobalProcSwitch MO. The configuration interface in the version supports the delivery of the settings of both the UtranCsfbBlindRedirRrSw and CsfbFlowOptSwitch parameters. The UtranCsfbBlindRedirRrSw parameter takes effect if the UtranCsfbBlindRedirRrSw parameter is set to ON. The CsfbFlowOptSwitch parameter takes effect if the UtranCsfbBlindRedirRrSw parameter is set to OFF. Therefore, avoid using this parameter.

Impact on Radio Network Performance

If this parameter is set to ON, the eNodeB selects the target frequency from frequencies with the same priorities in an RR manner and therefore load balancing between different UTRAN cells can be achieved. If this parameter is set to OFF, the load of cells on some UTRA frequencies increases.
