Meaning

Indicates the UE number offset used in inter-frequency offload by transferring UEs to neighboring cells with which the local cell does not exchange load information. Assume that the MlbTriggerMode parameter is set to UE_NUMBER_ONLY or PRB_OR_UE_NUMBER. If the number of UL-sync UEs in the local cell is greater than or equal to the sum of the InterFreqMlbUeNumThd and InterFrqUeNumOffloadOffset parameter values, neighboring cells with which the local cell does not exchange load information can be selected as the target cells for offload, and the local cell rejects incoming load-based handovers. If the number of UL-sync UEs in the local cell is less than the result of (UE number threshold for inter-frequency MLB + UE number offset for inter-frequency offload - UE number threshold for MLB), the local cell allows incoming load-based handovers. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance

This parameter needs to be set in scenarios where load-exchange-required load balancing and load-exchange-omitted offload are enabled simultaneously. A smaller value of this parameter results in a higher probability of transferring load to neighboring cells with which the source cell does not exchange load information. A larger value of this parameter results in a lower probability. Set this parameter based on the expected average UE throughput and the relationship between the average UE throughput and UE number in live networks. Setting this parameter to a proper value helps decrease the proportion of low-speed UEs in the network.
