Meaning

Indicates whether the external cell is a specified-service cell. Set this parameter based on the operator policy. If this parameter is set to SPECSERCELL, the external cell is a specified-service cell, and non-WBB UEs cannot be transferred to this cell. If this parameter is set to MBBSERCELL, the external cell is a cell that provides only MBB services, and WBB UEs cannot be transferred to this cell. If this parameter is set to NONE, the external cell is a common cell, and both WBB and MBB UEs can be transferred to this cell. The value of this parameter must be the same as that of the SpecifiedCellFlag parameter in the Cell MO associated to the external cell. This parameter applies only to LTE FDD and LTE TDD.
