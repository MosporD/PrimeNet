eNodeBFunction MOM Description

This chapter describes the functions, concepts, and child MOMs of the eNodeBFunction MOM. MOM is short for managed object models.

Functions and Concepts

The eNodeBFunction MOM provides radio access functions for an eNodeB, which involve radio resource management functions such as air interface management, access control, mobility management, and UE resource allocation.

Managed Object Model

Figure 1 shows the eNodeBFunction MOM and its child MOMs. Managed objects (MOs) are categorized as different MOMs based on their functions.
Figure 1 eNodeBFunction MOM
The MOs related to the MOMs shown in Figure 1 are defined as follows:
  • The eNodeBFunction MO is the root node of an eNodeB function domain. This MO provides the radio access functions for an eNodeB, which involve radio resource management functions such as air interface management, access control, mobility control, and UE resource allocation.
  • The other MOs are defined in the following sections:
    • Cell and Channel MOM Description: describes the MOs related to cells and channels.
    • RAN Sharing MOM Description: describes the MOs related to RAN sharing.
    • eNodeB Interface MOM Description: describes the MOs related to interfaces.
    • QCI MOM Description: describes the MOs related to QoS class identifies (QCIs). QoS is short for quality of service.
    • User Steering MOM Description: describes the MOs related to user steering.
    • Neighboring Cell and Neighbor Relationship MOM Description: describes the MOs related to neighboring cells and neighbor relationships.
  • Cell and Channel MOM Description
    This section describes the functions and concepts of managed object models (MOMs) and managed objects (MOs) of cells and channels.
  • eNodeB Interface MOM Description
    This section describes the functions and concepts of eNodeB interfaces, including S1, X2, M2, M3, ECO, SO, eX2, and Xw interfaces. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to the interfaces.
  • Neighboring Cell and Neighbor Relationship MOM Description
    This section describes the functions and concepts of neighboring cells and neighbor relationships. It illustrates managed object models (MOMs) and explains managed objects (MOs) related to neighboring cells and neighbor relationships.
  • QCI MOM Description
    This section describes the functions and concepts of eNodeB-level QoS class identifies (QCIs), cell-level QCIs, operator-level QCIs, and parameter groups. It illustrates managed object models (MOMs) of eNodeB-, cell-, and operator-level QCIs and also explains managed objects (MOs) related to the QCIs.
  • RAN Sharing MOM Description
    This section describes the functions and concepts of radio access network (RAN) sharing. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to RAN sharing.
  • User Steering MOM Description
    This section describes the functions and concepts of user steering, illustrates the managed object model (MOM) of user steering, and explains managed objects (MOs) related to user steering.
