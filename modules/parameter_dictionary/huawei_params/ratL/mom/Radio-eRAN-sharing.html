RAN Sharing MOM Description

This section describes the functions and concepts of radio access network (RAN) sharing. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to RAN sharing.

Functions and Concepts

RAN sharing enables multiple operators to share a RAN. In network sharing, multiple operators share the infrastructure or equipment of a network. Networks that can be shared include radio access networks (RANs), core networks (CNs), and transport networks. This section describes the RAN sharing with independent CNs.

Sharing Modes

RAN sharing has the following sharing modes: RAN sharing with common carriers, RAN sharing with dedicated carriers, and hybrid RAN sharing.
  • RAN sharing with common carriers: In this mode, multiple operators share RAN resources, which include carrier resources and eNodeB hardware resources.
  • RAN sharing with dedicated carriers: In this mode, operators share eNodeB hardware resources and have independent carrier resources.
  • Hybrid RAN sharing: In this mode, resources of at least one carrier are shared by multiple operators and resources of at least one carrier are exclusively occupied by one operator.

Primary and Secondary Operators

The type of an operator is specified by the CnOperatorType parameter in a CnOperator MO. The PLMN ID of the primary operator is listed at the top of the PLMN list contained in the broadcast message of a cell. According to 3GPP TS 36.331, such a PLMN ID is the ID of the primary PLMN and is used to form an eNodeB ID or cell ID. The primary and secondary operators can share eNodeB resources based on specified proportions. The primary operator does not have any privileges.

RAN Sharing Operator Group

The operators owning cells with the same primary PLMN ID belong to a RAN sharing operator group. Each group has an unique primary PLMN ID. A CnOperatorSharingGroup MO is used to configure the primary and secondary operators in a RAN sharing operator group.

License

A license is an authorization agreement between a vendor and a customer in terms of the application scope and service lifetime of products. The control items of licenses involved in RAN sharing are classified into feature items and capacity items.

Tracking Area

An evolved packet core (EPC) determines the scope for transmitting paging messages based on tracking areas (TAs). A TA may contain one or more cells. When hardware resources of an eNodeB are shared by multiple operators, carrier resources of cells under this eNodeB may also be shared by multiple operators in RAN sharing with common carriers mode. A cell may belong to TAs of multiple operators, and therefore the mapping between cells and TAs must be configured.

Managed Object Model

Figure 1 shows the RAN sharing MOM, which is a subset of the eNodeB MOM.
Figure 1 RAN sharing MOM
MOs related to RAN sharing, which are shown in Figure 1, are defined as follows:
  • The ENodeBSharingMode MO defines the RAN sharing mode, which can be independent operator, RAN sharing with common carriers, RAN sharing with dedicated carriers, or hybrid RAN sharing.
  • A CnOpSharingGroup MO defines a RAN sharing operator group. A RAN sharing operator group consists of a primary operator and a maximum of five secondary operators. An operator can belong to multiple groups but the primary operator of each group must be unique.
  • A CnOperator MO defines an operator. A maximum of six operators (including one primary operator) can share resources of an eNodeB.
  • A LicenseSharingPolicy MO defines a license sharing policy, which consists of the parameters about the policy among operators. The parameters are set to determine the proportion of the maximum number of users for each operator. If a LicenseSharingPolicy MO is not configured for an operator, the proportion of the maximum number of users for this operator is 0 by default. Users of this operator cannot access the shared eNodeB.
  • A Cell MO defines the basic information about a cell. For details, see Cell and Channel MOM Description.
  • A CnOperatorTa MO defines the information about a TA for an operator. The information includes the tracking area identifier (TAI), tracking area code (TAC), and operator index corresponding to the TAC. An eNodeB supports a maximum of 108 TAs.
  • A CellOp MO defines the operator information for a cell. The number of CellOp MOs that can be configured for a cell depends on the RAN sharing mode.
    • For RAN sharing with dedicated carriers, only one CellOp MO can be configured for each cell.
    • For RAN sharing with common carriers, a maximum of six CellOp MOs can be configured for each cell. The operator specified by one of the CellOp MOs must be configured as the primary operator.
  • The eNodeBFunction MO is the root node of an eNodeB function domain. This MO provides the radio access functions for an eNodeB, which involve radio resource management functions such as air interface management, access control, mobility control, and UE resource allocation.
