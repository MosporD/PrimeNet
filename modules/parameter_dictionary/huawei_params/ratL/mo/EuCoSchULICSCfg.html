EuCoSchULICSCfg

+-NE
  +-eNodeBFunction
    +-EuCoSchULICSCfg

Description

An EuCoSchULICSCfg MO consists of parameters set for uplink interference coordination scheduling.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 Related MML commands

MML Command

Function

Use this command to modify the parameters related to UL ICS.

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
