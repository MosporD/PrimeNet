UeNFreqCompat

+-NE
  +-eNodeBFunction
    +-UeNFreqCompat

Description

A UeNFreqCompat MO consists of parameters related to UE-specific neighboring frequency compatibility. This MO is used to configure a blacklisted neighboring frequency for specific UEs to reduce the impact of UE compatibility issues on the network performance.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UENFREQCOMPAT

Use this command to add the configurations of neighboring frequency compatibility parameters for specific UEs.
LST UENFREQCOMPAT

Use this command to list the configurations of neighboring frequency compatibility parameters for specific UEs.
RMV UENFREQCOMPAT

Use this command to remove the configurations of neighboring frequency compatibility parameters for specific UEs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Blacklisted Neighboring Freq EARFCN

Indicates the downlink EARFCN of the blacklisted neighboring frequency. For defective UEs, the eNodeB performs as follows: 1. The eNodeB does not deliver measurement configuration for this frequency. 2. The eNodeB does not add this frequency as an SCC. 3. The eNodeB does not perform handovers or redirections to this frequency. 4. The eNodeB does not handle measurement reports about this frequency. If some UEs have a defect in some functions on a specific frequency, it is recommended that this frequency be configured as a blacklisted neighboring frequency. This parameter applies only to LTE FDD and LTE TDD.
UeCompatIndex

Indicates the index of a compatibility processing action for defective UEs. This parameter applies only to LTE FDD and LTE TDD.
