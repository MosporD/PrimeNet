UeCompat

+-NE
  +-eNodeBFunction
    +-UeCompat
      +-UeCompatRsvdPara[1~1]

Description

A UeCompat MO consists of parameters related to UE compatibility optimization. These parameters can reduce the impact of UE incompatibility issues on network performance.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    UeCompatRsvdPara[1~1]
  • Relation with the UeInfo MO:
    • The UeInfo MO referenced by UeCapIndex in a UeCompat MO must have been configured.
  • Relation with the UeDiffConfig MO:
    • UeInfoIndex in a UeDiffConfig MO must have been set in the associated UeCompat MO.
  • Relation with the UeSpecificPara MO:
    • If the UeSpecificConfigIndex parameter in a UeCompat MO is set to a value greater than 0, the associated UeSpecificPara MO must be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UECOMPAT

Use this command to add a group of parameters for UE-type-specific differentiated handling of UEs.

Use this command to list the configurations of a group of parameters for UE-type-specific differentiated handling of UEs.
MOD UECOMPAT

Use this command to modify the configurations of a group of parameters for UE-type-specific differentiated handling of UEs.

Use this command to remove a group of parameters for UE-type-specific differentiated handling of UEs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Index

Indicates the index of a UE compatibility processing action. This parameter applies only to LTE FDD and LTE TDD.
UE Information Type

Indicates the information type to identify UEs. The information includes the specified TAC, the specified TAC and SVN, and the specified capability.

If this parameter is set to IMEISV_TAC, the ImeisvTac parameter must be configured.

If this parameter is set to IMEISV_TAC_SVN, the ImeisvTac and ImeisvSvn parameters must be configured.

If this parameter is set to UE_CAPABILITY, the UeCapIndex parameter must be configured. This parameter applies only to LTE FDD and LTE TDD.
Imeisv Tac

Indicates the type allocation code (TAC) in the IMEISVs of UEs. Each TAC identifies a UE model. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases.

If the UeInfoType parameter is set to IMEISV_TAC or IMEISV_TAC_SVN, this parameter must be set. This parameter applies only to LTE FDD and LTE TDD.
Imeisv Svn

Indicates the software version number (SVN) in the IMEISVs of UEs. Each SVN identifies a software version of UEs. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases.

If the UeInfoType parameter is set to IMEISV_TAC_SVN, this parameter must be set. This parameter applies only to LTE FDD and LTE TDD.
UE Capability Index

Indicates the UE capability index. This parameter is mapped to the UeCapIndex parameter in the UeInfo MO.

The index must be set if the UeInfoType parameter is set to UE_CAPABILITY. This parameter applies only to LTE FDD and LTE TDD.
Black List Control Switch

Indicates whether to blacklist some features.

LTE_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: intra-RAT event-triggered ANR, intra-RAT fast ANR, active PCI conflict detection, ANR based on specified PCI groups, and E-UTRAN measurement functions controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

UTRAN_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: event-triggered ANR with UTRAN, fast ANR with UTRAN, and UTRAN measurements controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

GERAN_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: event-triggered ANR with GERAN, fast ANR with GERAN, and GERAN measurements controlled by MlbBasedEventAnrSwitch. This option applies only to LTE FDD and LTE TDD.

CDMA_ANR_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: fast ANR with CDMA2000 and event-triggered ANR with CDMA2000. This option applies only to LTE FDD and LTE TDD.

DYNAMIC_DRX_SWITCH_OFF: If this option is selected, dynamic DRX is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

CA_SWITCH_OFF: If this option is selected, the following functions are disabled for defective UEs: SCell configuration and PCC anchoring. This option applies only to LTE FDD and LTE TDD.

TTI_BUNDLING_SWITCH_OFF: If this option is selected, TTI bundling is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

MIMO_TM_MODE_SET: If this option is selected, the MimoAdaptiveSwitch and InitialMimoType parameters are set to OL_ADAPTIVE and ADAPTIVE, respectively, for defective UEs. This option applies only to LTE FDD and LTE TDD.

APERIODIC_CQI_RPT_SWITCH_OFF: If this option is selected, enhanced aperiodic CQI reporting is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

ROHC_SWITCH_OFF: If this option is selected, ROHC is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

DL_2CC_CA_ENHANCE_SWITCH_OFF: If this option is selected, the function of enhanced DL ACK demodulation with two component carriers aggregated is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

DRX_SWITCH_OFF: If this option is selected, DRX for UEs in RRC_CONNECTED mode is disabled for defective UEs. This option applies only to LTE FDD and LTE TDD.

OSS_INTER_RAT_MR_SWITH_OFF: Indicates whether to disable periodic inter-RAT measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, the eNodeB disables the function for defective UEs. If this option is deselected, the eNodeB does not take measures for defective UEs. This option applies only to LTE FDD and LTE TDD.

OSS_INTER_FREQ_MR_SWITH_OFF: Indicates whether to disable periodic inter-frequency measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, the eNodeB disables the function for defective UEs. If this option is deselected, the eNodeB does not take measures for defective UEs. This option applies only to LTE FDD and LTE TDD.

UL_AMRC_SWITCH_OFF: Indicates whether to disable uplink AMRC for defective UEs. If this option is selected, uplink AMRC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

AUTO_GAP_SWITCH_OFF: Indicates whether to disable automatic gap-assisted measurement configuration of defective UEs. Automatic gap-assisted measurement configuration is disabled for defective UEs only if this option is selected. This option applies only to LTE FDD and LTE TDD.

FORBID_HIGH_CAPABILITY_OFF: Indicates whether the eNodeB forbids capabilities beyond the UE protocol version for defective UEs that comply with 3GPP Release 10 or later. If this option is deselected, capabilities beyond the UE protocol version are allowed to take effect on the eNodeB. If this option is selected, the eNodeB ignores capabilities beyond the UE protocol version that are reported by the UEs. This option applies only to LTE FDD and LTE TDD.

SPS_SWITCH_OFF: Indicates whether the eNodeB disables semi-persistent scheduling in the uplink and downlink for defective UEs. If this option is selected, this function is disabled for the UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTERMODE_FREQ_MEAS_OFF: Indicates whether to disable inter-duplex-mode frequency measurement of defective UEs. If this option is selected, the measurement function is disabled for the UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FLASH_SRVCC_SWITCH_OFF: Indicates whether to disable flash SRVCC for defective UEs. If this option is selected, flash SRVCC is disabled for the UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTER_FREQ_HO_SWITCH_OFF: Indicates whether coverage-based inter-frequency handovers are allowed for blacklisted UEs. If this option is selected, coverage-based inter-frequency handovers are not allowed for blacklisted UEs. The eNodeB performs inter-frequency redirections for such UEs after receiving inter-frequency measurement reports from the UEs. If this option is deselected, coverage-based inter-frequency handovers are allowed for the UEs. The eNodeB performs inter-frequency handovers for the UEs after receiving inter-frequency handovers from the UEs. This option applies only to LTE FDD and LTE TDD.

UL_EVSC_SWITCH_OFF: Indicates whether to disable uplink EVSC for defective UEs. If this option is selected, uplink EVSC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

EICIC_SWITCH_OFF: Indicates whether to disable TDM eICIC for defective UEs. If this option is selected, TDM eICIC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This parameter applies only to LTE FDD and NB-IoT.

OSS_INTRA_FREQ_MR_SWITCH_OFF: Indicates whether to disable periodic intra-frequency measurement of strongest cells triggered by OSS subscription tasks for defective UEs. If this option is selected, this function is disabled for defective UEs. If this option is deselected, no measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FLASH_CSFB_SWITCH_OFF: Indicates whether to disable flash CSFB for defective UEs. If this option is selected, flash CSFB is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

MIMO_4T_HANDOVER_SET: Indicates whether to take differentiated measures for incompatible UEs (service-drop UEs) in a 4T cell. If this option is selected, the eNodeB transfers incompatible UEs identified in a 4T cell to inter-frequency cells operating on 2T-cell frequencies through blind redirection. If this option is deselected, the eNodeB does not handle such UEs. This option applies only to LTE FDD.

WTCP_SWITCH_OFF: Indicates whether to disable WTCP for defective UEs. If this option is selected, WTCP is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

256QAM_SWITCH_OFF: Indicates whether to disable downlink 256 QAM for defective UEs. If this option is selected, downlink 256 QAM is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

CSI_RS_ZERO_POWER_OFF: Indicates whether to disable zero-power setting for CSI-RS for defective non-TM9 and non-TM10 UEs that comply with 3GPP R10 or later. If this option is selected, zero-power setting for CSI-RS is not configured for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.

RRC_REEST_DATA_FWD_SWITCH_OFF: Indicates whether to disable data forwarding in RRC connection reestablishment for defective UEs. If this option is selected, data forwarding in RRC connection reestablishment is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

MBSFN_SCHEDULING_SWITCH_OFF: Indicates whether to schedule defective UEs in MBSFN subframes. If this option is selected, it is considered that defective UEs have compatibility issues and cannot be scheduled in MBSFN subframes. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

TM9_SWITCH_OFF: Indicates whether to disable the TM9 capability for defective UEs. If this option is selected, the base station considers the specified UEs to have abnormal TM9 capabilities and processes the UEs as TM9-incapable UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.
White List Control Switch

Indicates whether to whitelist some features.

RANK_DETECT_SWITCH_ON: Indicates whether the eNodeB performs rank detection for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_AMRC_SWITCH_ON: Indicates whether to enable the function of uplink AMRC for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

FLASH_SRVCC_SWITCH_ON: Indicates whether the eNodeB performs flash SRVCC for specified UEs. If this option is selected, flash SRVCC is enabled for specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

CA_SRS_ONLY_SWITCH_ON: Indicates whether to enable the SCell polling sending SRS function for specified UEs. When this function is enabled, the SCell sends only SRSs instead of data in the uplink CA scenario. When multiple SCells exist, the SCells send SRSs in a polling manner. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_EVSC_SWITCH_ON: Indicates whether to enable the function of uplink EVSC for specified UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

MDT_SWITCH_ON: Indicates whether to enable MDT for specified UEs. If this option of the WhiteLstCtrlSwitch parameter is deselected in this MO and this option of the WhiteLstCtrlSwitch parameter is selected for any of other UeCompat MOs, MDT is disabled regardless of whether the specified UEs support MDT. If this option of the WhiteLstCtrlSwitch parameter in this MO is selected, the eNodeB selects the specified UEs to perform MDT when the UEs support MDT. This option applies only to LTE FDD and LTE TDD.

TM9_SWITCH_ON: Indicates whether to enable the TM9 capability for the specified UEs. If this option is selected, the eNodeB considers the specified UEs to support TM9. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

SPECIAL_UE_STAT_SWITCH_ON: Indicates whether to enable performance measurement for special UEs. If this option is selected, counters related to special UEs are measured when RRC connection reestablishments, service drops, or E-RAB setup failures occur on these UEs. If this option is deselected, no differentiated measures are taken for these UEs. This option applies only to LTE FDD and LTE TDD.

VOLTE_QUALITY_SRVCC_SWITCH_ON: Indicates whether to enable voice-quality-based SRVCC for specified VoLTE UEs. If this option is selected, voice-quality-based SRVCC is allowed for the specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

AUTO_GAP_SWITCH_ON: Indicates whether to enable automatic gap-assisted measurement for specified UEs. If this option is selected, automatic gap-assisted measurement is enabled for the specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This option applies only to LTE FDD and LTE TDD.

CODE_RATE_RISE_SWITCH_ON: Indicates whether to remove the code rate restriction for specified UEs. If this option is selected, the code rate restriction is removed for specified UEs. If this option is deselected, no differentiated measures are taken for the specified UEs. This parameter applies only to LTE FDD and LTE TDD.

CSI_RS_ZERO_POWER_SWITCH_ON: Indicates whether to configure the zero-power setting for CSI-RS for on-TM9 and non-TM10 UEs that comply with 3GPP R10 or later. If this option is selected, zero-power setting for CSI-RS is configured for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.

8PORT_CSI_RS_SWITCH_ON: Indicates whether 8-port CSI-RS beams take effect for specified UEs. If this option is selected, 8-port CSI-RS beams take effect for these UEs. If this option is deselected, no differentiated measures are taken for these UEs. This option applies only to LTE TDD.
Ue Type Description

Indicates the user-defined description of UEs. This parameter applies only to LTE FDD and LTE TDD.
White List Private CA Band Combination

Indicates whether a private CA band combination takes effect only on UEs in the whitelist. If an option is selected, the specified private CA band combination takes effect only on the whitelisted UEs. If the option is deselected, the combination takes effect on all CA UEs. For example, if PRIVATECACOMBID_0 is selected, the private CA band combination with an ID of 0 takes effect only on the whitelisted UEs. This parameter applies only to LTE FDD and LTE TDD.
UE Differential DRX Switch

Indicates whether to enable UE-specific differentiated DRX configuration. UE-specific differentiated DRX configuration is allowed only when this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.
Blacklist Control Extension Switch 1

Indicates whether to blacklist some features.

UL_64QAM_SWITCH: Indicates whether to disable uplink 64QAM for defective UEs. If this option is selected, uplink 64QAM is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

FULL_CONFIG_SWITCH: Indicates whether to disable the full configuration function for defective UEs. If this option is selected, the full configuration function is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SRVCC_SWITCH_OFF: Indicates whether to disable SRVCC for defective UEs. If this option is selected, SRVCC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_PSHO_SWITCH_OFF: Indicates whether to disable inter-RAT PS handover for defective UEs. If this option is selected, inter-RAT PS handovers are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

LTE_HANDOVER_TO_EMTC_SWITCH: Indicates whether the base station prohibits defective LTE UEs from being handed over to cells with eMTC enabled. If this option is deselected, no differentiated measures are taken for the defective UEs. If this option is selected, the base station prohibits the defective UEs from being handed over to cells with eMTC enabled. This is because the base station regards that access of defective UEs to cells with eMTC enabled will fail. This option applies only to LTE FDD and LTE TDD.

SCS_BASED_HO_SWITCH: Indicates whether to disable smart-carrier-selection-based handover for defective UEs. If this option is selected, smart-carrier-selection-based handovers are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SCS_FDD_TO_TDD_HO_WITH_SCC_SW: Indicates whether to disable smart-carrier-selection-based FDD-to-TDD handover with SCell configuration for defective UEs. If this option is selected, smart-carrier-selection-based FDD-to-TDD handovers with SCell configuration are disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

CONTIG_INTRA_BAND_CA_SWITCH: Indicates whether to disable aggregation of contiguous intra-band carriers for defective UEs in cells with Zero Guard Band Between Contiguous Intra-Band Carriers enabled. If this option is deselected, aggregation of contiguous intra-band carriers is not disabled for defective UEs. If this option is selected, aggregation of contiguous intra-band carriers is disabled for defective UEs. This parameter applies only to LTE FDD and LTE TDD.

NSA_DC_SWITCH: Indicates whether to disable NSA DC for defective UEs. If this option is selected, NSA DC is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

SN_TERMN_MCG_BEARER_SWITCH: Indicates whether to disable the SN-terminated MCG bearer function for defective UEs. If this option is selected, the SN-terminated MCG bearer function is disabled for defective UEs. If this option is deselected, no differentiated measures are taken for defective UEs. This option applies only to LTE FDD and LTE TDD.

DRB_ID_INCREMENTAL_ALLOC_SW: Indicates whether to enable incremental DRB ID allocation for special UEs. If this option is selected, incremental DRB ID allocation is disabled for such UEs. If this option is deselected, no differentiated measures are taken for such UEs. This option applies only to LTE FDD and LTE TDD.
UE-specific Configuration Index

Indicates the index of a UE-specific configuration. The index is the value of the UeSpecificConfigIndex parameter in the associated UeSpecificPara MO. The parameter value 0 indicates an invalid index. This parameter applies only to LTE FDD and LTE TDD.
Blacklisted Neighboring Freq 1 EARFCN

Indicates the downlink EARFCN of blacklisted neighboring frequency 1. If this parameter is set to 0, this parameter does not take effect. If this parameter is set to a non-zero value, the following functions do not take effect for defective UEs: 1. The eNodeB does not deliver measurement configuration for this frequency. 2. The eNodeB does not add this frequency as an SCC. 3. The eNodeB does not perform handovers or redirections to this frequency. 4. The eNodeB does not handle measurement reports about this frequency. If some UEs have a defect in some functions on a specific frequency, it is recommended that this frequency be configured as a blacklisted neighboring frequency. This parameter applies only to LTE FDD and LTE TDD. This parameter will be deleted in later versions. Although the configuration interface in this version still supports synchronization and delivery of the setting of this parameter, the system no longer uses this parameter. Therefore, avoid using this parameter. This parameter will be replaced by the BlacklistedNFreqEarfcn parameter in the UeNFreqCompat MO.
Blacklisted Neighboring Freq 2 EARFCN

Indicates the downlink EARFCN of blacklisted neighboring frequency 2. If this parameter is set to 0, this parameter does not take effect. If this parameter is set to a non-zero value, the following functions do not take effect for defective UEs: 1. The eNodeB does not deliver measurement configuration for this frequency. 2. The eNodeB does not add this frequency as an SCC. 3. The eNodeB does not perform handovers or redirections to this frequency. 4. The eNodeB does not handle measurement reports about this frequency. If some UEs have a defect in some functions on a specific frequency, it is recommended that this frequency be configured as a blacklisted neighboring frequency. This parameter applies only to LTE FDD and LTE TDD. This parameter will be deleted in later versions. Although the configuration interface in this version still supports synchronization and delivery of the setting of this parameter, the system no longer uses this parameter. Therefore, avoid using this parameter. This parameter will be replaced by the BlacklistedNFreqEarfcn parameter in the UeNFreqCompat MO.
NSA DC Max Inter-Freq Measurement Object Num

Indicates the maximum total number of inter-frequency measurement objects that can be contained in the inter-frequency measurement configurations delivered to specified NSA UEs in both the LTE PCell and NR PSCell. The default value 0 indicates that this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
