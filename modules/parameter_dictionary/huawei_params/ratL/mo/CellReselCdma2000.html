CellReselCdma2000

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellReselCdma2000

Description

The CellReselCdma2000 MO consists of the parameters related to cell reselection to CDMA2000. This MO contains the SIB8 information and is optional.

If this MO is not configured, cell reselection to CDMA2000 is not allowed.

For details on cell reselection to CDMA2000, see 3GPP TS 36.304.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
System time information configure indicator

Indicates whether to configure the CDMA2000 system time information. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA and EUTRA network synchronised indicator

Indicates the network synchronization status. If this parameter is set to BOOLEAN_TRUE, the E-UTRAN and the CDMA2000 RAN are synchronized without drifts. If this parameter is set to BOOLEAN_FALSE, the E-UTRAN and the CDMA2000 RAN are not synchronized. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA search window size configure indicator

Indicates whether to set the search window size. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Search window size

Indicates the size of the CDMA2000 search window, which can be used to assist in searching for the neighboring pilots. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
HRPD parameters configure indicator

Indicates whether the eNodeB includes the information about CDMA2000 HRPD in SIB8. If this parameter is set to CFG, the eNodeB includes the parametersHRPD field in SIB8. If this parameter is set to NOT_CFG, the eNodeB does not include the parametersHRPD field in SIB8. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
HRPD cell reselection configure indicator

Indicates whether to set the parameters related to cell reselection to CDMA2000 HRPD. This parameter applies only to LTE FDD and LTE TDD.
Cell reselection timer for HRPD

Indicates the evaluation period for a UE to determine whether to reselect a neighboring CDMA2000 HRPD cell to camp on. During the evaluation period, if the signal quality in a neighboring CDMA2000 HRPD cell is better than that in the serving cell and a UE camps on the serving cell for more than 1s, the UE attempts to reselect the neighboring CDMA2000 HRPD cell to camp on. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Speed state scale factor configure indicator

Indicates whether to set the speed-dependent scaling parameters related to cell reselection to CDMA2000 HRPD. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of TReselCdmaHrpd in high mobility state

Indicates the scaling factor applied to TReselCdmaHrpd for high-mobility UEs. The actual duration of cell reselection of high-mobility UEs to CDMA2000 HRPD is equal to TReselCdmaHrpd multiplied by TReselCdmaHrpdSfHigh. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of TReselCdmaHrpd in medium mobility state

Indicates the scaling factor applied to TReselCdmaHrpd for medium-mobility UEs. The actual duration of cell reselection of medium-mobility UEs to CDMA2000 HRPD is equal to TReselCdmaHrpd multiplied by TReselCdmaHrpdSfMedium. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
1XRTT parameters configure indicator

Indicates whether the eNodeB includes the information about CDMA2000 1xRTT in SIB8. If this parameter is set to CFG, the eNodeB includes the parameters1xRTT field in SIB8. If this parameter is set to NOT_CFG, the eNodeB does not include the parameters1xRTT field in SIB8. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
1XRTT state of long code generation registers configure indicator

Indicates whether the information element (IE) longCodeState1XRTT is contained in system information message 8 (SIB8). When this parameter is set to CFG(Configure), the IE longCodeState1XRTT is contained in SIB 8. When this parameter is set to NOT_CFG(Not configure), the IE longCodeState1XRTT is not contained in SIB 8. The CDMA2000 1xRTT-specific long code state is automatically generated based on system time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
1XRTT cell reselection configure indicator

Indicates whether the parameters applicable only for cell reselection to CDMA2000 1xRTT need to be set. This parameter applies only to LTE FDD and LTE TDD.
Cell reselection timer for 1XRTT

Indicates the evaluation period for a UE to determine whether to reselect a neighboring CDMA2000 1xRTT cell to camp on. During the evaluation period, if the signal quality in a neighboring CDMA2000 1xRTT cell is better than that in the serving cell and a UE camps on the serving cell for more than 1s, the UE attempts to reselect the neighboring CDMA2000 1xRTT cell to camp on. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
1XRTT speed state scale factors configure indicator

Indicates whether speed-dependent scaling parameters need to be set for cell reselection to CDMA2000 1xRTT. This parameter applies only to LTE FDD and LTE TDD.
1XRTT medium speed scale factor

Indicates the scaling factor applicable to cell reselection of medium-mobility UEs to CDMA2000 1xRTT. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
1XRTT high speed scale factor

Indicates the scaling factor applicable to cell reselection of high-mobility UEs to CDMA2000 1xRTT. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Dual Rx CSFB configure indicator

Indicates whether to configure the network capability of dual-receiver enhanced circuit switched fallback (CSFB). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Dual Rx CSFB supported indication

Indicates whether the network supports dual-receiver enhanced circuit switched fallback (CSFB). If this parameter is set to BOOLEAN_TRUE, the network supports dual-receiver enhanced CSFB. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
