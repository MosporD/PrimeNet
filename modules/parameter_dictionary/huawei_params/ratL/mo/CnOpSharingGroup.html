CnOpSharingGroup

+-NE
  +-eNodeBFunction
    +-CnOpSharingGroup

Description

A CnOpSharingGroup MO consists of the parameters related to a carrier-sharing operator group. A carrier-sharing operator group consists of a primary operator and a maximum of five secondary operators. An operator can belong to multiple carrier-sharing operator group. The primary operator of each carrier-sharing operator group must be unique. When an eNodeB works in hybrid RAN sharing mode, the S1Interface, X2Interface, S1, X2, and Cell MOs that associated with a CnOpSharingGroup MO provide RAN sharing services on a per carrier-sharing operator group basis..

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the EutranExternalCell, eNodeBFunction, ENodeBSharingMode, and CnOperator MOs:
    • If eNodeBId in an EutranExternalCell MO is set to the same value as eNodeBId in the eNodeBFunction MO and ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, the combination of Mcc and Mnc in this EutranExternalCell MO must be different from that of Mcc and Mnc in the CnOperator MO referenced by PrimaryOperatorId in any CnOpSharingGroup MO.
  • Relation with the EutranInterFreqNCell, CellOp, CnOperator, CnOperatorTa, Cell, and ENodeBSharingMode MOs:
    • A CellOp MO must be configured for each EutranInterFreqNCell MO that corresponds to an intra-eNodeB inter-frequency neighboring cell. If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, Mcc and Mnc in such an EutranInterFreqNCell MO must be set to the same values as Mcc and Mnc, respectively, in the CnOperator MO referenced by PrimaryOperatorId in the CnOpSharingGroup MO for the intra-eNodeB inter-frequency neighboring cell.
  • Relation with the EutranIntraFreqNCell, CellOp, CnOperator, CnOperatorTa, Cell, and ENodeBSharingMode MOs:
    • A CellOp MO must be configured for each EutranIntraFreqNCell MO that corresponds to an intra-eNodeB intra-frequency neighboring cell. If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, Mcc and Mnc in such an EutranIntraFreqNCell MO must be set to the same values as Mcc and Mnc, respectively, in the CnOperator MO referenced by PrimaryOperatorId in the CnOpSharingGroup MO for the intra-eNodeB intra-frequency neighboring cell.
  • Relation with the Cell, CellOp, CnOperatorTa, and ENodeBSharingMode MOs:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, CnOperatorId in the CnOperatorTa corresponding to TrackingAreaId in the CellOp MO under the Cell MO must be configured in PrimaryOperatorId or SecondaryOperatorList in the CnOpSharingGroup associated with the Cell MO.
  • Relation with the ENodeBSharingMode, Cell, CellOp, and CnOperatorTa MOs:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED and CellActiveState in a Cell MO is set to CELL_ACTIVE, CnOperatorId in a CnOperatorTa MO associated with the CellOp MO under the Cell MO must be set to the same value as PrimaryOperatorId in the CnOpSharingGroup MO associated with the Cell MO.
  • Relation with the CnOperator MO:
    • PrimaryOperatorId in a CnOpSharingGroup MO must have been configured in the associated CnOperator MO.
    • SecondaryOperatorId referenced by SecondaryOperatorList in a CnOpSharingGroup MO must have been configured in the associated CnOperator MO.
  • Relation with the S1 MO:
    • CnOpSharingGroupId in the S1 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
    • The operator corresponding to CnOperatorId in the S1 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
  • Relation with the S1Interface MO:
    • CnOpSharingGroupId in the S1Interface MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255 and CtrlMode in the S1Interface MO is set to MANUAL_MODE.
    • The operator corresponding to CnOperatorId in the S1Interface MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255 and CtrlMode in the S1Interface MO is set to MANUAL_MODE.
  • Relation with the X2 MO:
    • CnOpSharingGroupId in the X2 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
    • The operator corresponding to CnOperatorId in the X2 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
  • Relation with the X2Interface MO:
    • CnOpSharingGroupId in the X2Interface MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255 and CtrlMode in the X2Interface MO is set to MANUAL_MODE.
    • The operator corresponding to CnOperatorId in the X2Interface MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255 and CtrlMode in the X2Interface MO is set to MANUAL_MODE.
  • Relation with the MmeCapInfo, ENodeBSharingMode, S1, and CnOperatorTa MOs:
    • If the NbCiotEpsOptCap parameter in an MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT), and the S1CfgType parameter in an MmeCapInfo MO is set to S1_CFG, and the ENodeBSharingMode parameter in the eNodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing), then the NbIotTaFlag parameter must be set to BOOLEAN_TRUE in at least one of the CnOperatorTa MOs for primary and secondary operators in a carrier-sharing operator group associated with the CnOpSharingGroupId parameter in the S1 MO associated with the MmeCapInfo MO.
    • The NbIotTaFlag parameter must be set to BOOLEAN_FALSE(BOOLEAN_FALSE) in at least one of the CnOperatorTa MOs for primary and secondary operators in a carrier-sharing operator group associated with the CnOpSharingGroupId parameter in the S1 MO associated with the MmeCapInfo MO if all of the conditions are met: (1) The NbCiotEpsOptCap parameter in the MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT). (2) The NbLteSupportCap or MmeSupportEmtcDedEpcCap parameter in the MmeCapInfo MO is set to SUPPORT(SUPPORT). (3) The S1CfgType parameter in the MmeCapInfo MO is set to S1_CFG(S1_CFG). (4) The ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing).
  • Relation with the MmeCapInfo, ENodeBSharingMode, S1Interface, and CnOperatorTa MOs:
    • If the NbCiotEpsOptCap parameter in an MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT), and the S1CfgType parameter in an MmeCapInfo MO is set to S1INTERFACE_CFG, and the ENodeBSharingMode parameter in the eNodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing), then the NbIotTaFlag parameter must be set to BOOLEAN_TRUE in at least one of the CnOperatorTa MOs for primary and secondary operators in a carrier-sharing operator group associated with the CnOpSharingGroupId parameter in the S1Interface MO associated with the MmeCapInfo MO.
    • The NbIotTaFlag parameter must be set to BOOLEAN_FALSE(BOOLEAN_FALSE) in at least one of the CnOperatorTa MOs for primary and secondary operators in a carrier-sharing operator group associated with the CnOpSharingGroupId parameter in the S1Interface MO associated with the MmeCapInfo MO if all of the conditions are met: (1) The NbCiotEpsOptCap parameter in the MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT). (2) The NbLteSupportCap or MmeSupportEmtcDedEpcCap parameter in the MmeCapInfo MO is set to SUPPORT(SUPPORT). (3) The S1CfgType parameter in the MmeCapInfo MO is set to S1INTERFACE_CFG(S1INTERFACE_CFG). (4) The ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing).
  • Relation with the NG MO:
    • CnOpSharingGroupId in the NG MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
    • The operator corresponding to CnOperatorId in the NG MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
