S1Interface

+-NE
  +-eNodeBFunction
    +-S1Interface
      +-MmeFeatureCfg[1~1]

Description

An S1Interface MO consists of user-configured parameters related to an S1 interface between an eNodeB and a mobility management entity (MME). The parameters specify information about the S1 interface and the MME, including the control port bearer used for the S1 interface, the operator to which the S1 interface belongs, and the global unique MME identifier (GUMMEI) and public land mobile network (PLMN) ID of the MME.

Effective Scenario

Immediately

Relations Between MOs

    eNodeBFunction

    MmeFeatureCfg[1~1]

    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED and CtrlMode in the S1Interface MO is set to MANUAL_MODE, CnOpSharingGroupId in the S1Interface MO must have been configured in the associated CnOpSharingGroup MO.
  • Relation with the CnOpSharingGroup MO:
    • CnOpSharingGroupId in the S1Interface MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255 and CtrlMode in the S1Interface MO is set to MANUAL_MODE.

    • The NbIotTaFlag parameter must be set to BOOLEAN_FALSE(BOOLEAN_FALSE) in at least one of the CnOperatorTa MOs in which the CnOperatorId parameter is set to the same value as the CnOperatorId parameter in the S1Interface MO associated with the MmeCapInfo MO if all of the conditions are met: (1) The NbCiotEpsOptCap parameter in the MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT).     • The NbIotTaFlag parameter must be set to BOOLEAN_FALSE(BOOLEAN_FALSE) in at least one of the CnOperatorTa MOs in which the CnOperatorId parameter is set to the same value as the CnOperatorId parameter in the S1Interface MO associated with the MmeCapInfo MO if all of the conditions are met: (1) The NbCiotEpsOptCap parameter in the MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT).   • Relation with the MmeCapInfo, ENodeBSharingMode, CnOperatorTa, and CnOpSharingGroup MOs:
    • If the NbCiotEpsOptCap parameter in an MmeCapInfo MO is not set to NOT_SUPPORT(NOT_SUPPORT), and the S1CfgType parameter in an MmeCapInfo MO is set to S1INTERFACE_CFG, and the ENodeBSharingMode parameter in the eNodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing), then the NbIotTaFlag parameter must be set to BOOLEAN_TRUE in at least one of the CnOperatorTa MOs for primary and secondary operators in a carrier-sharing operator group associated with the CnOpSharingGroupId parameter in the S1Interface MO associated with the MmeCapInfo MO.

(2) The NbLteSupportCap or MmeSupportEmtcDedEpcCap parameter in the MmeCapInfo MO is set to SUPPORT(SUPPORT). (3) The S1CfgType parameter in the MmeCapInfo MO is set to S1INTERFACE_CFG(S1INTERFACE_CFG). (4) The ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to HYBRID_SHARED(Hybrid RAN Sharing).
  • Relation with the MmeCapInfo MO:
    • If S1CfgType parameter in an MmeCapInfo MO is set to S1INTERFACE_CFG, the MmeCapInfo MO referenced by S1InterfaceId in an S1Interface MO must be configured.
  • Relation with the MmeFeatureCfg MO:
    • If an S1Interface MO is configured, the MmeFeatureCfg MO that references S1InterfaceId in the S1Interface MO must exist.
  • Relation with the CPBEARER MO:
    • If CtrlMode in the S1Interface MO is set to MANUAL_MODE, a CTRLMODE in the CPBEARER MO referenced by an S1Interface MO must set to MANUAL_MODE.
    • If CtrlMode in the S1Interface MO is set to MANUAL_MODE, the S1CpBearerId in an S1Interface MO must have been set in the associated CPBEARER MO, and must not have been set in the SAAL type.
  • Relation with the CnOperator MO:
    • If CtrlMode in the S1Interface MO is set to MANUAL_MODE, the CnOperatorId in an S1Interface MO must have been set in the associated CnOperator MO.
  • Relation with the X2Interface MO:
    • S1CpBearerId in an S1Interface MO must be different from X2CpBearerId in any X2Interface MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD S1INTERFACE

Use this command to add an S1 interface.
BLK S1INTERFACE

Use this command to block an S1 interface.
DSP S1INTERFACE

Use this command to query the information about an S1 interface, such as the information about the CP, S1 interface status, and peer MME status. If the status of an S1 interface is abnormal, the command output displays the information about the peer MME that is connected to the eNodeB for the last time before the interface is abnormal.
MOD S1INTERFACE

Use this command to modify the parameters related to an S1 interface.
RMV S1INTERFACE

Use this command to remove an S1 interface.
RST S1INTERFACE

Use this command to reset an S1 interface.
UBL S1INTERFACE

Use this command to unblock an S1 interface. The unblocked S1 interface allows admission of new users.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
S1 Interface ID

Indicates the S1 interface ID. If the S1 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65534. If the S1 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.
S1 Interface CP Bearer ID

Indicates the ID of the control port bearer for the S1 interface.
CN Operator ID

Indicates the ID of the operator that owns the S1 interface.
MME Release

Indicates the compliance protocol release of the MME to which the eNodeB is connected through the S1 interface. The eNodeB sends S1 messages complying with the protocol release specified by this parameter. The value of this parameter must be the same as the MME-complied protocol release. If the parameter value is different from the MME-complied protocol release, the way in which the MME handles these message is subject to the MME implementation.
S1 Interface Is Blocked

Indicates whether the S1 interface is blocked. An S1 interface is blocked after the execution of BLK S1INTERFACE and is unblocked after the execution of UBL S1INTERFACE.
Control Mode

Indicates the control mode of the S1 interface, which determines the control policies of operators and the SON functions on the S1 interface. This parameter is set by the system and cannot be modified by operators. If the S1 interface was set up by operators by using the MAE or MML commands, this parameter is set to MANUAL_MODE and operators can configure the interface. If the S1 interface was set up automatically based on the endpoint configuration mode, then: 1. This parameter is set to AUTO_MODE. 2. Operators can reset, block, and unblock the interface and query the information about the interface. 3. Operators can modify only the Priority parameter. 4. Operators cannot delete the interface.
Auto Config Flag

Indicates whether the S1 interface was created automatically or manually. This parameter is set by the system and cannot be modified by operators. The system sets this parameter to AUTO_CREATED when the S1 interface was created automatically using SON and to MANUAL_CREATED when the S1 interface was created manually by using the MAE or running MML commands.
MME Selection Priority

Indicates the priority of an MME to which the eNodeB is connected through the S1 interface. A large parameter value indicates a high priority. After this parameter is set for MMEs, the eNodeB can select a high-priority MME for UEs attempting to access the network.
CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group that shares the S1Interface MO. If the eNodeB works in hybrid RAN sharing mode, set this parameter to a value within the range from 0 to 5. If the eNodeB works in independent operator mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, retain the default value 255, which is an invalid value.
Served GUMMEIs

Indicates the Global Unique MME Identifiers (GUMMEIs) of all MMEs to which the eNodeB is connected. A GUMMEI of a serving MME consists of the MCC, MNC, MME group ID, and MME code. GUMMEIs are separated by commas (,).
Table 3 Dynamic parameters

Parameter

Description
S1 Interface State

Indicates the status of the S1 interface.
S1 CP Bearer State

Indicates the status of the control port bearer for the S1 interface.
MME Is Overloaded

Indicates whether the MME connected to the eNodeB over the S1 interface is overloaded. This parameter is valid after the S1 interface is established. Before the S1 interface is established, the MME load status is NULL. For details about the MME load status after the S1 interface is established, see 3GPP TS 36.413.
S1 Interface User Number

Indicates the number of users that have accessed the S1 interface.
MME Name

Indicates the name of the MME to which the eNodeB is connected through the S1 interface. This parameter is valid after the S1 interface is established and the MME name is contained in the S1 interface establishing response message or the MME configuration update message. In other conditions, the parameter value is NULL. For details, see 3GPP TS 36.413.
Served PLMNs

Indicates the IDs of all served PLMNs of the MME to which the eNodeB is connected. The ID of a served PLMN consists of the MCC and MNC. PLMN IDs are separated by commas (,).
MME Relative Capacity

Indicates the capacity of the connected MME relative to that of other MMEs. A larger value of this parameter indicates a larger capacity allowing UE access.
S1 Interface Fault Reason

Indicates the reason of the fault on the S1 link.
