SidelinkV2xPsschCfg

+-NE
  +-eNodeBFunction
    +-SidelinkV2xCarrier
      +-SidelinkV2xPsschCfg

Description

The SidelinkV2xPsschCfg MO consists of parameters related to sidelink PSSCH transmission.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SidelinkV2xCarrier

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SIDELINKV2XPSSCHCFG

Use this command to configure a sidelink V2X PSSCH.
LST SIDELINKV2XPSSCHCFG

Use this command to query the configuration of a sidelink V2X PSSCH.
MOD SIDELINKV2XPSSCHCFG

Use this command to modify the configuration of a sidelink V2X PSSCH.
RMV SIDELINKV2XPSSCHCFG

Use this command to remove the configuration of a sidelink V2X PSSCH.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sidelink V2X Carrier ID

Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
PSSCH Configuration Index

Indicates the PSSCH ID. This parameter applies only to LTE FDD and LTE TDD.
UE Speed Threshold

Indicates the UE speed threshold for sidelink V2X. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
