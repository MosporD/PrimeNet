CellIfInfo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellIfInfo

Description

The CellIfInfo MO consists of parameters related to the cell intermediate frequency (IF), which is used to interconnect with an IF repeater. This MO applies only to LTE FDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLIFINFO

Use this command to add cell intermediate frequency information.
LST CELLIFINFO

Use this command to list cell intermediate frequency information.
MOD CELLIFINFO

Use this command to modify cell intermediate frequency information.
RMV CELLIFINFO

Use this command to remove cell intermediate frequency information.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.
Intermediate Frequency DL Center Frequency

Indicates the downlink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.
Intermediate Frequency Output Power

Indicates the output power of the intermediate frequency. This parameter applies only to LTE FDD.
Intermediate Frequency Power Offset

Indicates the output power offset of the intermediate frequency. This parameter applies only to LTE FDD.
Intermediate Frequency RX Channel Gain

Indicates the RX channel gains of the intermediate frequency. This parameter applies only to LTE FDD.
Intermediate Frequency UL Center Frequency

Indicates the uplink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.
