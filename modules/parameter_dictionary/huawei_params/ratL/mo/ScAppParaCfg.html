ScAppParaCfg

+-NE
  +-eNodeBFunction
    +-ScAppParaCfg

Description

An ScAppParaCfg MO consists of eNodeB-level parameters related to the service classification (SC) application.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoSwitch MO:
    • The AsForTcpSw option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO can be selected only when the AppIdentType parameter in at least one ScAppParaCfg MO is set to TCPPORT.
  • Relation with the WtcpProxyAlgo MO:
    • The WtcpDlRttTimer parameter in the WtcpProxyAlgo MO can be set to a value greater than 0 only when there is at least one ScAppParaCfg MO instance with AppIdentType being WTCP.
  • Relation with the AsParaGroup MO:
    • If the MainAppDnsFlag parameter in an ScAppParaCfg MO is set to Main, the AsParaGroup MO referenced by the AsParaGroupID parameter in the ScAppParaCfg MO must be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SCAPPPARACFG

Use this command to add the configurations of an SC application.
DSP SCAPPINFO

Use this command to query the information about the applications (video services) that service classification supports. The information includes operator-defined and system default application information. The eNodeB supports query of a maximum of 350 pieces of information. The domain name is not case sensitive. Characters in lower case take effect, and the query result shows domain names in lower case.
LST SCAPPPARACFG

Use this command to list the configurations of an SC application, which contain only the operator-defined application domain name information.
MOD SCAPPPARACFG

Use this command to modify the configurations of an SC application.
RMV SCAPPPARACFG

Use this command to remove the configurations of an SC application.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Application Index

Indicates the index of an application. This parameter applies only to LTE FDD and LTE TDD.
Application DNS

Indicates the domain name of the to-be-identified application or website. This parameter must be set only if the AppIdentType parameter is set to DNS. A single domain name specified by the AppDns parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single domain name be repeatedly configured for different application domain names. This parameter must be set to specific application domain names. It is not recommended that this parameter be set to domain names without specific meanings, such as *, *.*, *.com, or a*.c*. If such domain names are configured, the identification of application (such as video) domain names with specific meanings is affected. This parameter applies only to LTE FDD and LTE TDD.
Match Rule

Indicates the rule for matching a to-be-identified application (for example, a video) with the domain name. The service classification (SC) function uses the domain name to identify an application in two methods. If this parameter is set to Query, the query method is applied. If the IP address that a UE attempts to visit and a configured domain name match, the UE can obtain the service type (video service) through a reverse query of the domain name by using the IP address.

If this parameter is set to Relevancy, the relevancy method is applied. Assume that a UE accesses a video service and the IP address of the video does not match any configured domain name. After an initial identification of the video service, SC checks the domain names that the UE visited to find out whether there are domain names related to the video service. If yes, SC concludes the service as a video service. This parameter must be set under the consideration of the video service access characteristics in the place where the network locates.

This parameter must be set to Query when the domain name or IP address is configured for air interface acceleration guarantee for network services or simplified KQI tracing, or the TCP port is configured for TCP link setup acceleration. Otherwise, the configured domain name, IP address, or TCP port does not take effect.

This parameter applies only to LTE FDD and LTE TDD.
Application Name

Indicates the name of the to-be-identified application or website. For YouTube, Dailymotion, and Vimeo, the code rate can be correctly identified only if the parameter is set to YouTube, Dailymotion, and Vimeo_HLS, respectively, which are case-insensitive. The value NULL is invalid, and this parameter cannot be set to NULL. This parameter applies only to LTE FDD and LTE TDD.
Application Identification Type

Indicates the application identification method. If the AppIdentType parameter is set to DNS, the AppDns parameter must be set. If the AppIdentType parameter is set to IPv4, the AppIpv4 parameter must be set. If the AppIdentType parameter is set to IPv6, the AppIpv6 parameter must be set. You are advised to set the IP address for an application when the application is not configured with a domain name. You must not set both an IP address and a domain name for an application at the same time. If the AppIdentType parameter is set to TCPPORT, the TCP port number does not need to be configured and port 80, 8080, or 443 takes effect by default. The value 100 of the AppDnsId parameter is reserved for TCP link setup acceleration. That is, when the AppDnsId parameter is set to 100, the AppIdentType parameter can be set to only TCPPORT. If the AppIdentType parameter is set to WTCP, the WTCP service identification does not need to be configured but the AppDnsId parameter must be set to 101. The value 101 of the AppDnsId parameter is reserved for WTCP. That is, when the AppDnsId parameter is set to 101, the AppIdentType parameter can be set to only WTCP. This parameter applies only to LTE FDD and LTE TDD.
Application IPv4

Indicates the IPv4 address of an application, which is used for application (website) identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv4. A single IPv4 address specified by the AppIpv4 parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single IPv4 address be repeatedly configured for different application domain names. This parameter applies only to LTE FDD and LTE TDD.
Application IPv6

Indicates the IPv6 address of an application, which is used for application (website) identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv6. A single IPv6 address specified by the AppIpv6 parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single IPv6 address be repeatedly configured for different application domain names. This parameter applies only to LTE FDD and LTE TDD.
Application Config Target Indicator

Indicates whether the configured DNS or IP address can be used for video service identification, air interface acceleration guarantee for network services, service tracing, or low-delay service identification.

VideoIdentInd: The configured DNS or IP address is used for video service identification only when this option is selected.

AccelerateInd: The configured DNS, IP address, or TCP port is used for air interface acceleration guarantee for network services, TCP link setup acceleration guarantee, and WTCP air interface acceleration only when this option is selected. When a UE accesses a configured DNS, IP address, or TCP port, the eNodeB performs air interface acceleration guarantee for network services, TCP link setup acceleration guarantee, and WTCP air interface acceleration for the UE if any of the following conditions is met: (1) The AsAlgoSwitch parameter is set to ON. (2) The AsForTcpSw option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO is selected. (3) The WtcpDlRttTimer parameter in the WtcpProxyAlgo MO is set to ON.

ServiceTraceInd: Service-related external CHRs are recorded for a UE visiting the configured DNS or IP address only when this option is selected.

LowDelayServiceInd: External CHRs related to low-delay services are recorded for a UE visiting the configured DNS or IP address only when this option is selected.

UeMatchInd: If this option is selected, the configured DNS is used for UE identification. If this option is deselected, the configured DNS is not used for UE identification.

If all of the VideoIdentInd, AccelerateInd, ServiceTraceInd, LowDelayServiceInd, and UeMatchInd options are deselected, this parameter is invalid. This parameter applies only to LTE FDD and LTE TDD.
Main Application DNS Flag

Indicates whether the domain name or IP address configured for acceleration guarantee is a main or auxiliary domain name or IP address. The value Null is invalid. This parameter takes effect only when the AccelerateInd option of the AppCfgTargetInd parameter in the ScAppParaCfg MO is selected. This parameter applies only to LTE FDD and LTE TDD.
Accelerate Service Para Group ID

Indicates the ID of the acceleration guarantee parameter group. The value 255 is invalid. This parameter takes effect if both the following conditions are met:

(1) The AccelerateInd option of the AppCfgTargetInd parameter in the ScAppParaCfg MO is selected.

(2) The MainAppDnsFlag parameter in the ScAppParaCfg MO is set to Main or the AppIdentType parameter in the ScAppParaCfg MO is set to TCPPORT or WTCP. This parameter applies only to LTE FDD and LTE TDD.
Main Application DNS ID

Indicates the main application index corresponding to the configured domain name or IP address. The value 65535 is invalid. This parameter takes effect only when the AccelerateInd option of the AppCfgTargetInd parameter in the ScAppParaCfg MO is selected and the MainAppDnsFlag parameter is set to Aid in the same MO. If this parameter is set to 100 or 101 or the associated AppIdentType parameter is set to TCPPORT or WTCP, this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Service End Time Threshold

Indicates the service end time threshold used in service tracing. If this parameter is set to a value in the range from 1 to 255, the configured value takes effect. If this parameter is set to 0, the value 255 takes effect. This parameter takes effect only when the ServiceTraceInd or AccelerateInd option of the AppCfgTargetInd parameter in the ScAppParaCfg MO is selected. This parameter applies only to LTE FDD and LTE TDD.
Port Number

Indicates the server port number used for SC-based UE identification. The value 0 is an invalid value and indicates that the eNodeB identifies only the default port number. If this parameter is set to a non-zero value, only the configured port number takes effect. This parameter applies only to LTE FDD and LTE TDD.
Protocol Type

Indicates the type of protocol used for UE identification in SC. If this parameter is set to BOTH, both TCP and UDP apply. This parameter applies only to LTE FDD and LTE TDD.

Description

Indicates the description that defines an application. This parameter applies only to LTE FDD and LTE TDD.
Configuration Type

Indicates the configuration type of the to-be-identified DNS. This parameter applies only to LTE FDD and LTE TDD.
