CellSidelinkV2xCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSidelinkV2xCfg

Description

The CellSidelinkV2xCfg MO consists of parameters used to configure the sidelink V2X function of a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • When the SIDELINK_V2X_SWITCH option of the SidelinkV2xCfgSwitch parameter in a CellSidelinkV2xCfg MO is selected, the NbCellFlag parameter in the associated Cell MO must be set to FALSE.
  • Relation with the CellSLV2xCarrCfg MO:
    • When the SIDELINK_V2X_SWITCH option of the SidelinkV2xCfgSwitch parameter in a CellSidelinkV2xCfg MO is selected, the CellSLV2xCarrCfg MO must be configured in the associated cell.
  • Relation with the CellEmtcAlgo MO:
    • When the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected, the SIDELINK_V2X_SWITCH option of the SidelinkV2xCfgSwitch in the associated CellSidelinkV2xCfg MO under the same cell as the CellEmtcAlgo MO must be deselected.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CELLSIDELINKV2XCFG

Use this command to query the sidelink V2X configuration of a cell.
MOD CELLSIDELINKV2XCFG

Use this command to modify the sidelink V2X configuration of a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.
Sidelink V2X Configuration Switch

Indicates whether to enable sidelink V2X functions for the cell. This parameter applies only to LTE FDD and LTE TDD. If the LBBPc is used, all functions controlled by this parameter do not take effect.

SIDELINK_V2X_SWITCH: If this option is selected, the eNodeB can broadcast SIB21 in the cell and support mode 4 communication used by UEs.
