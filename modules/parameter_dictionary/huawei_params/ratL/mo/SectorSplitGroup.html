SectorSplitGroup

+-NE
  +-eNodeBFunction
    +-SectorSplitGroup
      +-SectorSplitCell[0~256]

Description

A SectorSplitGroup MO consists of the parameters used to configure a sector split group.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    SectorSplitCell[0~256]
  • Relation with the CellCsiRsParaCfg, CellAlgoSwitch, CellAlgoExtSwitch, and SectorSplitCell MOs:
    • When CsiRsSwitch in a CellCsiRsParaCfg MO is set to FIXED_CFG or ADAPTIVE_CFG, TM9Switch or TM10Switch of EnhMIMOSwitch, FDDHomNetDlCompSwitch or FDDHetNetDlCompSwitch or Tm9JtSwitch of DlCompSwitch, SfnJtSwitch of SfnAlgoSwitch, or 4TxTM9MuMimoSwitch of EmimoSwitch in the associated CellAlgoSwitch MO must be selected, or Tm9FourLayerPairSwitch of WttxMuMimoSwitch in a CellAlgoExtSwitch MO must be selected, or JOINT_SCHEDULING_SWITCH of IntelligentBeamSchSwitch in SectorSplitGroup MO must be selected.
  • Relation with the Cell and SectorSplitCell MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and a SectorSplitCell MO is configured for the Cell MO, the PATTERN_ADJ_SWITCH and POWER_ADJ_SWITCH options of the SectorSplitSwitch parameter in the SectorSplitGroup MO must be deselected.
    • If the values of the CellActiveState, FddTddInd, and TxRxMode parameters in the Cell MO for a cell are CELL_ACTIVE, CELL_TDD, and 64T64R, respectively, and the number of SectorSplitCell MOs under the SectorSplitGroup MO including this cell is greater than or equal to 2 and less than or equal to 4, the PreambleFmt parameter in this Cell MO must be set to 0.
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R, 32T32R, or 8T8R, and the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the number of SectorSplitCell MOs associated to the SectorSplitGroup MO for the corresponding Cell MO must be 2, 3, or 4.
    • The MassiveMimoEmfPowerLimit parameter in the SectorSplitGroup MO can be set to a non-zero value only if the TxRxMode and FddTddInd parameters in the Cell MO are set to 32T32R and CELL_FDD, respectively.
    • If the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, a SectorSplitCell MO is configured for the Cell MO, the FddTddInd parameter in the Cell MO is set to CELL_FDD, and the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter in the SectorSplitGroup MO associated with the Cell MO is selected, three or four FDD cells must be configured in the SectorSplitCell MOs associated with the SectorSplitGroup corresponding to the Cell.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, there is a SectorSplitCell MO that corresponds to this Cell MO, and the BeamDeploymentMode parameter in the SectorSplitGroup MO that includes this SectorSplitCell MO is set to MODE_3, then the following parameters in the Cell MO must be set as follows: CrsPortNum must be set to CRS_PORT_4, CustomizedBandWidthCfgInd must be set to NOT_CFG, NbCellFlag must be set to FALSE, TxRxMode must be set to 8T8R.
    • The BeamDeploymentMode parameter in a SectorSplitGroup MO must be set to MODE_3 when the parameters in a Cell MO corresponding to a SectorSplitCell MO under this SectorSplitGroup MO are set as follows: The FddTddInd parameter is set to CELL_FDD, the TxRxMode parameter is set to 8T8R, and the MultiCellShareMode parameter is set to NORMAL.
    • For all Cell MOs associated with the SectorSplitCell MOs in the same SectorSplitGroup MO, if the FddTddInd parameter in one of these Cell MOs is set to CELL_TDD and the TxRxMode parameter in the same Cell MO is set to 64T64R or 32T32R, the SubframeAssignment and SpecialSubframePatterns parameters in these Cell MOs must be set to the same values.
    • For all Cell MOs associated with the SectorSplitCell MOs in the same SectorSplitGroup MO, if the FddTddInd parameter in one of these Cell MOs is set to CELL_TDD and the TxRxMode parameter in the same Cell MO is set to 8T8R and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, the SubframeAssignment and SpecialSubframePatterns parameters in these Cell MOs must be set to the same values.
    • If the FddTddInd and TxRxMode parameters in a Cell MO are set to CELL_FDD and 32T32R, respectively, and the cell specified by this Cell MO is configured in a SectorSplitCell MO, then the BeamDeploymentMode parameter in the SectorSplitGroup MO where the SectorSplitCell MO is included cannot be set to NOT_CFG. If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the cell specified by this Cell MO is configured in a SectorSplitCell MO, then the BeamDeploymentMode parameter in the SectorSplitGroup MO where the SectorSplitCell MO is included must be set to NOT_CFG or MODE_3. In addition, if the TxRxMode parameter in this Cell MO is set to 8T8R, the BeamTemplateId parameter in the SectorSplitGroup MO must be set to 0.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then in Cell MO: the CrsPortNum parameter must be set to CRS_PORT_2 or CRS_PORT_4, the DlCyclicPrefix and UlCyclicPrefix parameters must be set to NORMAL_CP, the SubframeAssignment parameter must be set to SA1 or SA2, the SpecialSubframePatterns parameter must be set to SSP5, SSP6, or SSP7, the DlBandWidth parameter must be set to CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100, and the UlBandWidth parameter must be set to CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then in the Cell MO: the HighSpeedFlag parameter must be set to LOW_SPEED, the MultiRruCellFlag parameter must be set to BOOLEAN_FALSE, and the CPRICompression parameter must be set to NO_COMPRESSION or NORMAL_COMPRESSION.
    • If the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then the BeamTemplateId parameter in the SectorSplitGroup MO must be set to 0.
    • If the Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to MODE_3, then the CellBeamIndex parameter in the SectorSplitCell MO must be set to 0 or 1.
  • Relation with the CellAlgoSwitch, CellCsiRsParaCfg, CellAlgoExtSwitch, and SectorSplitCell MOs:
    • When TM9Switch and TM10Switch of EnhMIMOSwitch, FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch and Tm9JtSwitch of DlCompSwitch, and SfnJtSwitch of SfnAlgoSwitch, and 4TxTM9MuMimoSwitch of EmimoSwitch in a CellAlgoSwitch MO, and Tm9FourLayerPairSwitch of WttxMuMimoSwitch in a CellAlgoExtSwitch MO, and JOINT_SCHEDULING_SWITCH of IntelligentBeamSchSwitch in SectorSplitGroup MO are deselected, CsiRsSwitch in the associated CellCsiRsParaCfg MO must be set to NOT_CFG.
  • Relation with the SectorSplitCell MO:
    • A SectorSplitGroup MO includes a maximum of 12 SectorSplitCell MO instances.
    • The values of CellBeamIndex parameters of SectorSplitCell MO instances in the same SectorSplitGroup MO must be different.
    • If the SectorSplitGroup MO contains 0 SectorSplitCell MO, the MM_INTELLIGENT_BEAM_SHAPING_SW option of SectorSplitSwitch in a SectorSplitGroup MO cannot be selected.
    • If the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in a SectorSplitGroup MO is selected, the CellBeamAzimuth and CellBeamwidth parameters in the SectorSplitCell MOs under this SectorSplitGroup MO must be set to 255 and DEFAULT, respectively.
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met:
    • The number of SectorSplitCell MO instances under this SectorSplitGroup MO must be greater than 2.
    • If the number of SectorSplitCell MOs under a SectorSplitGroup MO is greater than two and the MassiveMimoEmfPowerLimit parameter in this SectorSplitGroup MO is set to a non-zero value, the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in this SectorSplitGroup MO must be selected.
  • Relation with the eUCellSectorEqm, Cell, and SectorSplitCell MOs:
    • If the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, and the CrsPortNum parameter in the Cell MO corresponding to the eUCellSectorEqm MO is set to CRS_PORT_4, the number of SectorSplitCell MO instances under the SectorSplitGroup MO must not exceed 8.
  • Relation with the SectorSplitCell and Cell MOs:
    • Under a SectorSplitGroup MO, the values of the DlEarfcn, DlBandWidth, UlEarfcnCfgInd, UlEarfcn, UlBandWidth, TxRxMode, CrsPortNum, and CPRICompression parameters in the Cell MO instances corresponding to SectorSplitCell MO instances must be the same.
    • In the Cell MOs corresponding to the SectorSplitCell MOs under the SectorSplitGroup MO, if TxRxMode and FddTddInd are set to 8T8R and CELL_FDD respectively, and MultiCellShareMode is set to SPLIT or CrsPortNum is set to CRS_PORT_4, the values of CustomizedBandWidthCfgInd, CustomizedULBandWidth, and CustomizedDLBandWidth must be the same in these Cell MOs.
  • Relation with the Cell, eUCellSectorEqm, SectorSplitCell, and CellCspcPara MOs:
    • The IntraEnbCspcSw parameter in the CellCspcPara MO under a Cell MO must be set to OFF when the following conditions are met: The CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the CellBeamMode parameter in the eUCellSectorEqm MO under the Cell MO is set to MASSIVE_MIMO_Ph2, and the number of SectorSplitCell MO instances under the SectorSplitGroup MO associated with the Cell MO is not greater than 2.
  • Relation with the Cell, CellSiMap, and SectorSplitCell MOs:
    • If the value of CellActiveState in the Cell MO for a cell is CELL_ACTIVE and this cell is added to a sector split group specified by a SectorSplitGroup MO, the setting of the ForbidCellSiSwitch option of SiSwitch in the CellSiMap MOs for all cells corresponding to the SectorSplitCell MOs under the SectorSplitGroup MO must be the same.
  • Relation with the Cell, eUCellSectorEqm, and SectorSplitCell MOs:
    • The TM4WeightScheme parameter in the SectorSplitGroup MO that includes a cell specified by a Cell MO can be set to COVERAGE_MODE_1 when all of the following conditions are met: The value of the CellActiveState parameter in this Cell MO is CELL_ACTIVE, the CellBeamMode parameter in the eUCellSectorEqm MO under this Cell MO is set to MASSIVE_MIMO_Ph2, the number of SectorSplitCell MO instances under the SectorSplitGroup MO is four, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_2.
  • Relation with the SectorSplitCell and SRSCfg MOs:
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met:
    • The SrsCfgInd parameter in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to BOOLEAN_TRUE.
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met:
    • The FddSrsCfgMode parameter must be set to the same value in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO.
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met:
    • The SrsSubframeCfg parameter must be set to the same value in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO if the FddSrsCfgMode parameter in these SRSCfg MOs is set to DEFAULTMODE.
  • Relation with the SectorSplitCell and CellAlgoSwitch MOs:
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met: The SrsSubframeRecfSwitch option of the SrsAlgoSwitch parameter must be set to the same value in the CellAlgoSwitch MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO.
  • Relation with the CellCsiRsParaCfg, CellAlgoSwitch, eUCellSectorEqm, SectorSplitCell, and Cell MOs:
    • If the CsiRsAdaptBeamCount parameter in the CellCsiRsParaCfg MO is not set to ADAPTIVE_BEAM_DISABLED and cell is active, the following requirements must be met:
    • The JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO corresponding to the Cell MO must be selected, the 8T4PortTM9EnhanceSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must be selected, or the CellBeamMode parameter in the eUCellSectorEqm MO under the Cell MO must be set to MASSIVE_MIMO_Ph2 and the number of SectorSplitCell MO instances under the SectorSplitGroup MO corresponding to the Cell MO is less than or equal to 2 and the TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must be selected.
  • Relation with the SectorSplitCell and eUCellSectorEqm MOs:
    • If the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, all the following requirements must be met:
    • The CellBeamMode parameter in the eUCellSectorEqm MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to MASSIVE_MIMO_Ph2.
    • The number of SectorSplitCell MO instances under this SectorSplitGroup MO must be greater than 2.
  • Relation with the SectorSplitCell and CellMimoParaCfg MOs:
    • The HighOrderMimoPairingStrat parameter in the CellMimoParaCfg MO under a Cell MO can be set to a value other than DEFAULT only if the number of SectorSplitCell MOs under the SectorSplitGroup MO in which the cell specified by the Cell MO is included is less than 3.
  • Relation with the Cell, SpectrumCloud, and SectorSplitCell MOs:
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO under a Cell MO is set to UL_SPECTRUM_SHARING, the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, and the TxRxMode parameter in the Cell MO is set to 32T32R, then the number of SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must be less than or equal to 4.
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO under a Cell MO is set to GL_SPECTRUM_CONCURRENCY, and the TxRxMode parameter in the Cell MO is set to 32T32R, then the number of SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must be less than or equal to 6.
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO under a Cell MO is set to GL_SPECTRUM_CONCURRENCY, the CellActiveState in the Cell MO is set to CELL_ACTIVE, then all cells specified in the SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must meet the following requirements: The SpectrumCloud MOs of these cells must exist, the GsmArfcnGroupId parameter in these SpectrumCloud MOs is set to the same value, the SpectrumCloudSwitch parameter in these SpectrumCloud MOs is set to GL_SPECTRUM_CONCURRENCY.
  • Relation with the Cell, SectorSplitCell, and CellAlgoSwitch MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, and the SectorSplitCell MO corresponding to the Cell MO exists, then the TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, and the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to NOT_CFG, then the BfSwitch option of the BfAlgoSwitch parameter, the MuBfSwitch option of the MuBfAlgoSwitch parameter, and the TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then the ULSUMIMO2LayersSwitch option of the UlSuMimoAlgoSwitch parameter in the CellAlgoSwitch MO must be deselected.
  • Relation with the Cell, SRSCfg, CellAlgoSwitch, and SectorSplitCell MOs:
    • When the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in a SectorSplitGroup MO is selected, and the FddTddInd parameter in the Cell MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO is set to CELL_FDD, all the following requirements must be met:
    • (a) The SrsCfgInd parameter in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to BOOLEAN_TRUE.
    • (b) The FddSrsCfgMode parameter in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to Default Mode.
    • (c) The SrsSubframeCfg parameter in the SRSCfg MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to the same value.
    • (d) The SrsSubframeRecfSwitch option of the SrsAlgoSwitch parameter in the CellAlgoSwitch MOs corresponding to all SectorSplitCell MOs under this SectorSplitGroup MO must be set to the same value.
  • Relation with the Cell, SectorSplitCell, and CellMimoParaCfg MOs:
    • If the PRECISE_DL_CSI_SW option of the MimoSwitch parameter in the CellMimoParaCfg MO under a Cell MO corresponding to a SectorSplitCell is selected and the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, then the following parameter setting requirements must be met: (a) The FddTddInd parameter in the Cell MO must be set to CELL_FDD. (b) The TxRxMode parameter in the Cell MO must be set to 32T32R. (c) The number of SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must be less than 3; alternatively, if the number is greater than or equal to 3, the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO must be selected.
    • If the MASSIVE_MIMO_MU_RANK_OPT_SW option of the MimoSwitch parameter in the CellMimoParaCfg MO under a Cell MO corresponding to a SectorSplitCell is selected and the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, then the following parameter setting requirements must be met: (a) The FddTddInd parameter in the Cell MO must be set to CELL_FDD. (b) The TxRxMode parameter in the Cell MO must be set to 32T32R. (c) The number of SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must be less than 3; alternatively, if the number is greater than or equal to 3, the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO must be selected.
    • If the FREQ_DIFF_AMEND_SW option of the MimoSwitch parameter in the CellMimoParaCfg MO under a Cell MO corresponding to a SectorSplitCell MO is selected and the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, then the following parameter setting requirements must be met: (a) The FddTddInd parameter in the Cell MO must be set to CELL_FDD. (b) The TxRxMode parameter in the Cell MO must be set to 32T32R. (c) The number of SectorSplitCell MOs under the SectorSplitGroup MO that includes the cell specified by the Cell MO must be less than 3; alternatively, if the number is greater than or equal to 3, the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO must be selected.
  • Relation with the Cell, eUCellSectorEqm, SectorSplitCell, and CellAlgoSwitch MOs:
    • If the CellActiveState parameter in a Cell MO is CELL_ACTIVE, the CellBeamMode parameter in the eUCellSectorEqm MO under this Cell MO is set to MASSIVE_MIMO_Ph2, and the TM4WeightScheme parameter in the SectorSplitGroup MO (under which a SectorSplitCell MO identifies the cell defined by this Cell MO) is set to COVERAGE_MODE_2, then one of the following configuration requirements must be met: (a) The BeamDeploymentMode parameter in the SectorSplitGroup MO must be set to MODE_1, and the number of SectorSplitCell MO instances under the SectorSplitGroup MO must be 2. (b) The BeamDeploymentMode parameter in the SectorSplitGroup MO must be set to MODE_1, the number of SectorSplitCell MO instances under the SectorSplitGroup MO must be 3, and the New4TCodebookSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO must be deselected. (c) The BeamDeploymentMode parameter in the SectorSplitGroup MO must be set to MODE_2, the number of SectorSplitCell MO instances under the SectorSplitGroup MO must be 4 or 5, and the New4TCodebookSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO must be deselected.
  • Relation with the Cell, CellShutdown, eUCellSectorEqm, and SectorSplitCell MOs:
    • If CellShutdownSwitch in the CellShutdown MO under a Cell MO is not set to OFF, CellBeamMode in the eUCellSectorEqm MO under this Cell MO is set to MASSIVE_MIMO_Ph2, and the number of SectorSplitCell MOs under the SectorSplitGroup MO in which the cell specified by this Cell MO is included is greater than or equal to 2, then neither of DlPrbThd and UlPrbThd in the CellShutdown MO can be set to 0.
  • Relation with the CellShutdown, eUCellSectorEqm, Cell, and SectorSplitCell MOs:

  • Relation with the Cell, SectorSplitCell, and CellShutdown MOs:
    • If the FddTddInd parameters in the CELL MO are set to CELL_FDD, the CellBeamMode parameter in the eUCellSectorEqm is set to MASSIVE_MIMO_Ph2, and the number of SectorSplitCell MOs under the SectorSplitGroup MO in which the cell specified by this Cell MO is included is greater than or equal to 2, the CellShutdownSwitch parameter in the CellShutdown MO cannot be set to ON_MULTI_CARRIER_HIER_SHUTDOWN.
    • If the FddTddInd parameter in the CELL MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R, and the number of SectorSplitCell MOs under the SectorSplitGroup MO in which the cell specified by this Cell MO is included is greater than or equal to 2, the CellShutdownSwitch parameter in the CellShutdown MO cannot be set to ON_MULTI_CARRIER_HIER_SHUTDOWN.
  • Relation with the Cell, SectorSplitCell, and CellDynPowerSharing MOs:
    • For all Cell MOs associated with the SectorSplitCell MOs in a SectorSplitGroup MO, if the FddTddInd, TxRxMode, and CellActiveState parameters in one of the Cell MOs are set to CELL_TDD, 8T8R, and CELL_ACTIVE, respectively, and the cell specified by this Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to NOT_CFG, then the setting of the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO for all these Cell MOs must be the same.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sector Split Group ID

Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.
Beam Template ID

Indicates the beam template ID. This parameter needs to be set to 0 for 8T cells. This parameter applies only to LTE FDD and LTE TDD.
Beam Deployment Mode

Indicates the beam deployment mode for a multi-antenna cell. MODE_0 indicates that the number of outer-cell beams is the same as or one more than that of inner-cell beams. MODE_1 indicates that the number of outer-cell beams is two or three more than that of inner-cell beams. MODE_2 indicates that the number of outer-cell beams is four or five more than that of inner-cell beams. MODE_3 indicates smart 8T8R. NOT_CFG indicates that beams are not deployed. The difference between the numbers of outer-cell and inner-cell beams depends on the AAU type and the total number of selected beams. For details, see the related feature parameter description. The beam deployment mode can be set based on the distribution of UEs on the network to achieve even UE distribution in each beam. This helps increase the capacity and UE-perceived rates. This parameter applies to LTE FDD and LTE TDD.
Sector Split Switch

Indicates whether to enable functions related to sector split in massive MIMO scenarios.

MM_INTELLIGENT_BEAM_SHAPING_SW: Indicates whether to enable intelligent beam shaping in massive MIMO scenarios. Intelligent beam shaping in massive MIMO scenarios is enabled only if this option is selected. The PATTERN_ADJ_SWITCH and POWER_ADJ_SWITCH options are valid only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected. This option applies only to LTE FDD and LTE TDD.

PATTERN_ADJ_SWITCH: Indicates whether to adjust the pattern for intelligent beam shaping in massive MIMO scenarios. If UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the eNodeBResModeAlgo.ServiceMode parameter must also be selected for the pattern adjustment function to take effect. If this option is selected, the CellBeamAzimuth and CellBeamwidth parameters do not take effect, and the beam azimuth and beamwidth are adaptively adjusted based on UE distribution. If this option is deselected, the beam azimuth and horizontal 3 dB beamwidth are determined by the CellBeamAzimuth and CellBeamwidth parameters, respectively. This option applies only to LTE FDD.

POWER_ADJ_SWITCH: Indicates whether to enable power adjustment for intelligent beam shaping in massive MIMO scenarios. This option takes effect only when the TM4WeightScheme parameter is set to DEFAULT_MODE. If this option is selected, the traffic channel power is adjusted based on the principle of power usage maximization. If this option is deselected, the traffic channel power is not adjusted based on the principle of power usage maximization. This option applies only to LTE FDD.

PATTERN_ADJ_ENH_SWITCH: Indicates whether to enable enhanced pattern adjustment. If this option is selected, the pattern adjustment enhancement function is enabled. If this option is deselected, the pattern adjustment enhancement function is disabled. The PATTERN_ADJ_ENH_SWITCH option is valid only when both the MM_INTELLIGENT_BEAM_SHAPING_SW and PATTERN_ADJ_SWITCH options of this parameter are selected. This option applies only to LTE FDD.

POWER_ALLOCATION_SWITCH: Indicates whether to enable power allocation. If this option is selected, the PDSCHCfg.ReferenceSignalPwr parameter becomes invalid. Instead, the reference signal power is determined based on the cell power, which is specified by the SectorSplitCell.CellBeamPower parameter. The reference signal power can be queried by running the DSP MASSIVEMIMOPOWER command. If this option is deselected, power allocation is disabled. The POWER_ALLOCATION_SWITCH option takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter is selected. This option applies only to LTE FDD.
Massive MIMO Beam Azimuth Adjustment Step

Indicates the beam azimuth adjustment step used for smart beam adjustment in massive MIMO scenarios.

If this parameter is set to 0, only the beam width can be adjusted in smart beam adjustment in massive MIMO scenarios, and the beam azimuth cannot be adjusted. If this parameter is set to 60, the beam azimuth is adjusted based on the clustering result instead of being restricted by the adjustment step.

This parameter applies only to LTE FDD.
TM4 Weight Scheme

Indicates the scheme for setting the weight of TM4 in massive MIMO. The eNodeB sets the weight of TM4 based on the AAU type and coverage requirements. The value DEFAULT_MODE is applicable to common scenarios. When this parameter is set to DEFAULT_MODE, the CellBeamTilt parameter is valid. The value COVERAGE_MODE_1 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_1, the CellBeamTilt parameter is invalid if the CrsPortNum parameter is set to CRS_PORT_4 or is valid if CrsPortNum parameter is set to CRS_PORT_2. The value COVERAGE_MODE_2 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_2, the CellBeamTilt parameter is valid. This parameter applies only to LTE FDD.
Intelligent Beam Scheduling Switch

Indicates whether to enable algorithms related to intelligent beam scheduling.

JOINT_SCHEDULING_SWITCH: Indicates whether to enable joint scheduling for intelligent beam scheduling in massive MIMO scenarios. Joint scheduling is enabled for intelligent beam scheduling in massive MIMO scenarios only if this option is selected. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.

ENH_JOINT_SCHEDULING_SWITCH: Indicates whether to enable enhanced joint scheduling for intelligent beam scheduling in massive MIMO scenarios. When this option is selected, the enhanced joint scheduling is enabled. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.
Massive MIMO EMF Power Limit

Indicates the maximum transmit power that can be used by UEs in massive MIMO cells. This parameter is used to prevent UE transmit power from exceeding the EMF limit. If this parameter is set to 0, the maximum transmit power of UEs in massive MIMO cells is not restricted. If this parameter is set to a non-zero value, the maximum transmit power of UEs in massive MIMO cells cannot exceed the power value specified by this parameter. This parameter applies only to LTE FDD.
Massive MIMO Beam Scheme

Indicates the massive MIMO beam scheme. This parameter applies only to LTE FDD.
Power Sharing TM9 UE Max Pa Offset

Indicates the offset relative to the maximum PA for the shared power received by TM9 UEs when intelligent beam scheduling is enabled. The actual maximum PA for the shared power received by TM9 UEs is the result of 90 minus the configured value. This parameter applies only to LTE FDD.
Beam Optimization PRB Usage Threshold

Indicates the PRB usage threshold for triggering TM9 beam optimization. When the average PRB usage of the split sector group is higher than the threshold, TM9 beam optimization is enabled to reduce interference from TM9 beams to UEs using other beams and increase the average downlink UE throughput. This parameter applies only to LTE FDD.
Power Sharing High Load Threshold

Indicates the load threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the PRB usage of a high-load cell exceeds this threshold, the condition for the sharing to take effect is met. If this parameter is set to 100, this power sharing algorithm does not take effect. This parameter applies only to LTE FDD.
Power Sharing Load Multiple Threshold

Indicates the load ratio threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the ratio of the load of a high-load cell to that of a low-load cell exceeds this threshold, the condition for the sharing to take effect is met. This parameter applies only to LTE FDD.
