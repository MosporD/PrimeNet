DefaultDcnCfg

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-DefaultDcnCfg

Description

A DefaultDcnCfg MO consists of parameters related to a default dedicated core network (DCN). A maximum of 18 DefaultDcnCfg MOs can be configured for an operator. A maximum of 18 DefaultDcnCfg MOs can be configured for all operators.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD DEFAULTDCNCFG

Use this command to add the configuration of a default DCN.
LST DEFAULTDCNCFG

Use this command to list the configurations of one or more default DCNs.
RMV DEFAULTDCNCFG

Use this command to remove the configuration of a default DCN.
