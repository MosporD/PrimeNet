CellLaaFcsPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellLaaFcsPara

Description

The CellLaaFcsPara MO consists of parameters used when FCS is applied to cells operating on unlicensed frequency bands.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and CellLaaCoexistPara MOs:
    • If WorkMode in a Cell MO is set to LAA, a maximum of one CellLaaCoexistPara MO and four CellLaaFcsPara MOs can be configured under this Cell MO.
    • If WorkMode in a Cell MO is set not to LAA, CellLaaCoexistPara MO or CellLaaFcsPara MO cannot be configured under this Cell MO.
  • Relation with the CellDlpcPdschPa MO:
    • For the same cell, when the DL_TPC_SWITCH option in DlTpcAlgoSwitch is selected, the constraints between the CellTpcPowerAdjRange parameter in the CellLaaFcsPara MO and the PaPcOff parameter in the CellDlpcPdschPa MO are as follows: 1. CellTpcPowerAdjRange parameter is set to 1, the PaPcOff parameter must be set to -3, -1.77, 0, 1, 2, or 3. 2. CellTpcPowerAdjRange parameter is set to 2, the PaPcOff parameter must be set to -1.77, 0, 1, 2, or 3. 3. CellTpcPowerAdjRange parameter is set to 3, the PaPcOff parameter must be set to 0, 1, 2, or 3. 4. CellTpcPowerAdjRange parameter is set to 4, the PaPcOff parameter must be set to 0, 1, 2, or 3. 5. CellTpcPowerAdjRange parameter is set to 5, the PaPcOff parameter must be set to 1, 2, or 3. 6. CellTpcPowerAdjRange parameter is set to 6, the PaPcOff parameter must be set to 2 or 3.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.
FCS Start Frequency

Indicates the starting frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS. The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.
FCS Stop Frequency

Indicates the cut-off frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.
FCS Interference Threshold

Indicates the threshold of the interference level detected in an LAA cell. If the interference level exceeds this threshold, the channel is considered occupied. Otherwise, the channel is considered available. This parameter applies only to LTE TDD.
DFS Switch

Indicates whether to enable dynamic frequency selection (DFS). This parameter includes the DfsFreqSwitch option.

DfsFreqSwitch: Indicates whether to enable DFS detection. If this option is selected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are detected for DFS. If this option is deselected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are not detected for DFS. This option applies only to LTE TDD.
Cell TPC Maximum Power

Indicates the maximum power during TPC for the LAA cell in the specified frequency range. Set this parameter based on local radio regulations. This parameter applies only to LTE TDD.
Cell TPC Power Adjustment Range

Indicates the power adjustment range of TPC for the LAA cell in the specified frequency range. Set this parameter based on local radio regulations. This parameter applies only to LTE TDD.
Downlink TPC Algorithm Switch

Indicates whether to enable TPC for the LAA cell in the specified frequency range.

DL_TPC_SWITCH: Indicates whether to enable downlink TPC for an LAA cell. If this option is selected, downlink TPC is enabled. If this option is deselected, downlink TPC is disabled. This option applies only to LTE TDD.
