CellRelayAlgoPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellRelayAlgoPara

Description

Indicates cell-specific parameters related to the Relay feature.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • The value of the UlRelaySubframeRatio parameter in the CellRelayAlgoPara MO can be a value from 1/10 to 4/10 when the FddTddInd and SubframeAssignment parameters in the Cell MO are set to CELL_TDD and SA1, respectively.
    • The value of the UlRelaySubframeRatio parameter in the CellRelayAlgoPara MO can be a value from 1/10 to 2/10 when the FddTddInd and SubframeAssignment parameters in the Cell MO are set to CELL_TDD and SA2, respectively.
    • The value of the UlRelaySubframeRatio parameter in the CellRelayAlgoPara MO is 1/10 when the FddTddInd and SubframeAssignment parameters in the Cell MO are set to CELL_TDD and SA5, respectively.
    • If the FddTddInd and SubframeAssignment parameters in a Cell MO are set to CELL_TDD and SA1, respectively, and the OutOfBandRelaySwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the value range of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO is [1/10, 6/10].
    • If the FddTddInd and SubframeAssignment parameters in a Cell MO are set to CELL_TDD and SA2, respectively, and the OutOfBandRelaySwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the value range of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO is [1/10, 8/10].
    • If the FddTddInd and SubframeAssignment parameters in a Cell MO are set to CELL_TDD and SA5, respectively, and the OutOfBandRelaySwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the value range of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO is [1/10, 9/10].
  • Relation with the Cell and CellAlgoSwitch MOs:
    • If any of the OutOfBandRelaySwitch, InBandRelayDeNbSwitch, or InBandRelayReNbSwitch options of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, there must be a CellRelayAlgoPara MO instance under the Cell MO. The CellRelayAlgoPara MO instance under the Cell MO can be deleted only if the OutOfBandRelaySwitch, InBandRelayDeNbSwitch, and InBandRelayReNbSwitch options are deselected.
  • Relation with the CellAlgoSwitch MO:
    • If the OutOfBandRelaySwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the value of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO must be 1_10, 2_10, 3_10, 4_10, 5_10, 6_10, 7_10, 8_10, 9_10, or 10_10.
    • If the InBandRelayConCnt parameter in the CellRelayAlgoPara MO is set to NON_CON, the InBandRelayReNbSwitch and InBandRelayDeNbSwitch options of the RelaySwitch parameter in the CellAlgoSwitch MO cannot be both selected.
  • Relation with the CellAlgoSwitch and Cell MOs:
    • If the InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_TDD, the value of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO must be 1_10, 2_10, or 3_10.
    • If the InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_FDD, the value of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO must be 3_40, 6_40, 9_40, 12_40, 15_40, 18_40, 21_40, 24_40, or 10_10.
    • If the InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_TDD, the value of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO must be 1_10, 2_10, or 3_10.
    • If the InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_FDD, the value of the DlRelaySubframeRatio parameter in the CellRelayAlgoPara MO must be 3_40, 6_40, 9_40, 12_40, 15_40, 18_40, 21_40, 24_40, or 10_10.
    • If the InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_TDD, the value of the InBandRelayConCnt parameter in the CellRelayAlgoPara MO must be NON_CON.
    • If the InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, and the FddTddInd parameter in the Cell MO is set to CELL_TDD, the value of the InBandRelayConCnt parameter in the CellRelayAlgoPara MO must be NON_CON.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the Local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Uplink Relay Subframe Ratio

Indicates the ratio of uplink subframes used as relay subframes. The total number of subframes in each radio frame is 10. For example, the value 2/10 indicates that two uplink subframes in each radio frame are used as relay subframes. In the LTE FDD system, the number of uplink subframes used for common UEs is 8, which is the result of subtracting 2 from 10. In the LTE TDD system, the number of uplink subframes used for common UEs is calculated by subtracting the number of uplink subframes used as relay subframes from the number of uplink subframes specified by the subframe configuration. Relay subframes are preferentially scheduled for relay remote nodes (RRNs) while common subframes are preferentially scheduled for common UEs. If the relay subframes are not used up, they can be used for scheduling for common UEs and if the common subframes are not used up, they can be used for scheduling for RRNs. This parameter applies only to LTE FDD and LTE TDD.
Downlink Relay Subframe Ratio

Indicates the ratio of downlink subframes used as relay subframes in out-of-band relay and in-band relay scenarios. In out-of-band relay scenarios, the parameter value takes 10 (the number of subframes in one radio frame) as the denominator. For example, the value 2/10 indicates that two downlink subframes in each radio frame are used as relay subframes. In the LTE FDD system, the number of downlink common subframes is 8, which is the result of subtracting 2 from 10. In the LTE TDD system, the number of downlink common subframes is calculated by subtracting the number of downlink subframes used as relay subframes from the number of downlink subframes specified by the uplink-downlink configuration. Relay subframes are preferentially scheduled for relay remote nodes (RRNs) and common subframes are preferentially scheduled for common UEs. If the relay subframes are not used up, they can be used for scheduling for common UEs. If the common subframes are not used up, they can be used for scheduling for RRNs. In in-band relay scenarios of an LTE FDD network, the parameter value takes 40 (the total number of subframes in four radio frames) as the denominator. The value 12/40 indicates that 12 downlink subframes in four radio frames are used as relay subframes. The value range is 3/40 to 21/40. In in-band relay scenarios of an LTE TDD network, the parameter value takes 10 (the number of subframes in one radio frame) as the denominator. The value can be 1/10, 2/10, and 3/10. In in-band relay scenarios, relay subframes are preferentially scheduled for RRNs and common subframes are scheduled only for common UEs. In in-band relay scenarios of an LTE FDD network, uplink relay subframes in a cell map to downlink relay subframes in the cell and do not need to be configured. In an LTE TDD cell with uplink-downlink configuration 2, the uplink relay subframes in the cell are fixed and the ratio does not need to be configured. In out-of-band relay or in-band relay scenarios, the value 10/10 indicates that the DeNB is used for transmission only and S1 and X2 interfaces do not need to be configured. This parameter applies only to LTE FDD and LTE TDD.
Rrn Pre-Allocation Minimum Period

Indicates the minimum interval between uplink preallocations for a relay remote node (RRN). The interval between two preallocations for the same RRN cannot be smaller than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
Rrn Pre-Allocation Size

Indicates the uplink preallocation data volume of a relay remote node (RRN), that is, the data volume that can be transmitted during an RRN preallocation. This parameter applies only to LTE FDD and LTE TDD.
Uplink SINR Adjustment Target IBLER

Indicates the target IBLER used in the SINR adjustment algorithm for uplink dynamic scheduling of RRNs. A larger value of this parameter leads to a greater SINR adjustment value, and therefore a higher MCS index is used. This parameter applies only to LTE FDD and LTE TDD.
Downlink SINR Adjustment Target IBLER

Indicates the target IBLER used in the SINR adjustment algorithm for downlink dynamic scheduling of RRNs. A larger value of this parameter leads to a greater SINR adjustment value, and therefore a higher MCS index is used. This parameter applies only to LTE FDD and LTE TDD.
Uplink Enhanced Relay Schedule Switch

Indicates whether to enable the enhanced uplink scheduling function related to RRNs.

UlSPSDegradeSwitch: If this option is selected, the uplink SPS priority of normal UEs becomes lower than the uplink scheduling priority of RRNs in uplink relay subframes. If this option is deselected, the uplink SPS priority is not lowered. This option applies only to LTE FDD and LTE TDD.
Downlink Enhanced Relay Schedule Switch

Indicates whether to enable the enhanced downlink scheduling function related to RRNs.

DlSPSDegradeSwitch: If this option is selected, downlink SPS does not take effect in downlink relay subframes. If this option is deselected, downlink SPS is not affected. This option applies only to LTE FDD and LTE TDD.
In Band Relay Concatenation Count

Indicates the position of the RRN for the cell in a concatenation when RRNs are concatenated in in-band relay scenarios. The value NON_CON indicates that concatenation is not supported. The other values affect the subframe scheduling template. This parameter applies only to LTE FDD and LTE TDD.
