SidelinkV2xResPlCfg

+-NE
  +-eNodeBFunction
    +-SidelinkV2xCarrier
      +-SidelinkV2xResPlCfg

Description

The SidelinkV2xResPlCfg MO consists of parameters used to configure and manage sidelink V2X transmission and reception resource pools.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    SidelinkV2xCarrier
  • Relation with the SidelinkV2xCarrier MO:
    • Under each SidelinkV2xCarrier MO instance, the number of SidelinkV2xResPlCfg MO instances with PoolType set to TX_POOL must be less than or equal to 2, and the number of SidelinkV2xResPlCfg MO instances with PoolType set to RX_POOL must be less than or equal to 1.
    • The product of the SubchannelPrbCount and SubchannelCount parameter values plus the SubchannelStartRbIndex parameter value must not exceed the number of RBs indicated by the SidelinkV2xBandwidth parameter in the SidelinkV2xCarrier MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to query the configuration of a sidelink V2X resource pool.

Use this command to modify the configuration of a sidelink V2X resource pool.

Use this command to remove the configuration of a sidelink V2X resource pool.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sidelink V2X Carrier ID

Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Pool ID

Indicates the resource pool ID. This parameter applies only to LTE FDD and LTE TDD.
Pool Type

Indicates the resource pool type. This parameter applies only to LTE FDD and LTE TDD.
Pool Subframe Bitmap

Indicates the bitmap of the subframe used for the resource pool. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
PSCCH PSSCH Adjacency

Indicates whether adjacent RBs in the same subframe are used to transmit the PSSCH and PSCCH. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subchannel Count

Indicates the number of subchannels of the current resource pool. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subchannel PRB Count

Indicates the number of PRBs used for each subchannel. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subchannel Start RB Index

Indicates the index of the starting RB of the subchannel. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
PSCCH Pool Start RB Index

Indicates the index of the starting RB of the PSCCH resource pool. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
