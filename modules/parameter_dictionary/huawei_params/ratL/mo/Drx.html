Drx

+-NE
  +-eNodeBFunction
    +-Drx

Description

The Drx MO consists of parameters related to discontinuous reception (DRX). If DRX is enabled, a UE turns on its receiver for reception only when necessary.

DRX is introduced for the following purposes:

1. To reduce the UE power consumption and stretch the service time.

2. To increase system resource efficiency.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
DRX Flexibility Control Switch

Indicates whether to enable DRX flexibility. If this parameter is set to OFF, DRX configuration for UEs is restricted based on the UE number. If this parameter is set to ON, DRX configuration for UEs is restricted based on CPU flow control. This parameter does not support LBBPc. This parameter applies only to LTE FDD and LTE TDD.
