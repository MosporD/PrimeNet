ContigIntraBandCarr

+-NE
  +-eNodeBFunction
    +-Cell
      +-ContigIntraBandCarr

Description

The ContigIntraBandCarr MO consists of the cell-level parameters used to configure the Zero Guard Band Between Contiguous Intra-Band Carriers feature.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the PDSCHCfg and SpectrumCloud MOs:
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to OFF, the EmfPowerLimitSwitch parameter in the PDSCHCfg MO is set to OFF and the POWER_RAISE_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is deselected, the CellPowerLimit parameter in the PDSCHCfg MO must be set to 0.
  • Relation with the CellAlgoSwitch, SRSCfg, RACHCfg, Cell, SpectrumCloud, and CellLteFlexBw MOs:
    • The PUCCH_SRS_ADAPT_SWITCH option of the NonStandardBwAlgoSw parameter in the CellAlgoSwitch MO can be selected when all the following five conditions are true: The PucchSwitch option of the PucchAlgoSwitch parameter in the CellAlgoSwitch MO is selected; the PrachFreqOffsetStrategy parameter in the RACHCfg MO is set to AUTOMATIC or FULLY_AUTOMATIC; the AnSrsSimuTrans parameter in the SRSCfg MO is set to BOOLEAN_TRUE; the UlVmimoSwitch option of the UlSchSwitch parameter in the CellAlgoSwitch MO is deselected; the CustomizedBandWidthCfgInd parameter in the Cell MO is set to CFG, and the CompactBwCtrlIntrfMode parameter in the Cell MO is set to a value other than NORMAL, or the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, UL_SPECTRUM_SHR_PH2_WITH_GSM, DC_HSDPA_BASED_UL_SPECTRUM_SHR or UL_SPECTRUM_SHARING, or the LTE_FB_CFG_SWITCH option of the LteFlexBwSwitch parameter in the CellLteFlexBw MO is selected, or the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is selected.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the FddTddInd in the Cell is set to CELL_FDD, and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw in the ContigIntraBandCarr MO must be deselected.
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR or LTE_NR_COORD_SPECTRUM_SHR, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO must not be selected for this cell.
  • Relation with the Cell, SpectrumCloud, and CellAlgoSwitch MOs:
    • The PCFICH_POWER_OPT_SWITCH and PDCCH_POWER_OPT_SWITCH options of the NonStandardBwAlgoSw parameter in the CellAlgoSwitch MO can be selected only if the CustomizedBandWidthCfgInd parameter in the Cell MO is set to CFG or the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to ON or CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw in the ContigIntraBandCarr is selected.
  • Relation with the SpectrumCloud MO:
    • At least one between SpectrumCloudSwitch in the SpectrumCloud MO and CONTIG_INTRA_BAND_CARR_SW of ContigIntraBandCarrSw in the ContigIntraBandCarr MO must be turned off.
  • Relation with the CellAlgoSwitch MO:
    • If the GLZeroBufferZoneSwitch or GLDynSpectrumShareSwitch option of the DynSpectrumShareSwitch parameter in the CellAlgoSwitch MO is selected, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO must be deselected.
    • If the AvoidUtranInterfSwitch or AvoidCDMAInterfSwitch option of the AvoidInterfSwitch parameter in the CellAlgoSwitch MO is selected, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO must be deselected.
    • The InBandRelayDeNbSwitch or InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO and the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be both selected.
    • GLPwrShare in the CellAlgoSwitch MO and CONTIG_INTRA_BAND_CARR_SW of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be both turned on.
    • If the DynAdjVoltSwitch option of the DynAdjVoltSwitch parameter in the CellAlgoSwitch MO is selected, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be selected.
    • When the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is selected, the PwrDeratSwitch parameter in the CellAlgoSwitch MO must not be set to ON.
  • Relation with the Cell MO:
    • If CustomizedBandWidthCfgInd in the Cell MO is set to CFG, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw in the ContigIntraBandCarr MO must be deselected.
    • For cells that have the same setting of FreqBand, if the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the these cells, UlEarfcnCfgInd must be set to an identical value for all these cells: either CFG or NOT_CFG.
    • The difference between the values of DlEarfcn of two cells meeting the following conditions must be an integer multiple of 15 kHz: The two cells have the same setting of FreqBand and different settings of DlEarfcn, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the two cells, and the difference between the values of DlEarfcn of the two cells is less than half of the sum of the bandwidths specified by DlBandWidth of the two cells.
    • The difference between the values of UlEarfcn of two cells meeting the following conditions must be an integer multiple of 15 kHz: UlEarfcnCfgInd is set to CFG for the two cells and the two cells have the same setting of FreqBand and different settings of UlEarfcn, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the two cells, and the difference between the values of UlEarfcn of the two cells is less than half of the sum of the bandwidths specified by UlBandWidth of the two cells.
    • The difference between the values of DlEarfcn of two cells meeting the following conditions must be greater than or equal to half of the sum of the bandwidths occupied by the RBs of the quantities indicated in the values of DlBandWidth of the two cells: The two cells have the same setting of FreqBand and different settings of DlEarfcn, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the two cells, FddTddInd is set to CELL_FDD for the two cells, and the values of DlBandWidth of the two cells are CELL_BW_N6(1.4M) and CELL_BW_N6(1.4M), or CELL_BW_N6(1.4M) and CELL_BW_N15(3M), or CELL_BW_N15(3M) and CELL_BW_N15(3M).
    • The difference between the values of UlEarfcn of two cells meeting the following conditions must be greater than or equal to half of the sum of the bandwidths occupied by the RBs of the quantities indicated in the values of UlBandWidth of the two cells: UlEarfcnCfgInd is set to CFG for the two cells and the two cells have the same setting of FreqBand and different settings of UlEarfcn, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the two cells, FddTddInd is set to CELL_FDD for the two cells, and the values of UlBandWidth of the two cells are CELL_BW_N6(1.4M) and CELL_BW_N6(1.4M), or CELL_BW_N6(1.4M) and CELL_BW_N15(3M), or CELL_BW_N15(3M) and CELL_BW_N15(3M).
    • If the [OPTION]CONTIG_INTRA_BAND_CARR_SW[/OPTION] option of the ContigIntraBandCarrSw parameter is selected in the ContigIntraBandCarr MOs corresponding to two cells having the same FreqBand parameter value but different DlEarfcn parameter values and the FddTddInd parameter is set to CELL_FDD for both cells, then the bandwidth overlap between the two cells must be less than or equal to either 40% of the bandwidth occupied by the RBs of the quantity indicated in the smaller DlBandWidth parameter value between the two cells or the bandwidth occupied by 25 RBs, whichever is smaller.
    • If the FreqBand parameter is set to the same value for two cells, the UlEarfcnCfgInd parameter is set to CFG for both cells, the UlEarfcn parameter is set to different values for the two cells, the [OPTION]CONTIG_INTRA_BAND_CARR_SW[/OPTION] option of the ContigIntraBandCarrSw parameter is selected in the ContigIntraBandCarr MOs corresponding to the two cells, and the FddTddInd parameter is set to CELL_FDD for both cells, then the bandwidth overlap between the two cells must be less than or equal to either 40% of the bandwidth occupied by the RBs of the quantity indicated in the smaller UlBandWidth parameter value between the two cells or the bandwidth occupied by 25 RBs, whichever is smaller.
    • If NbCellFlag in the Cell MO is set to TRUE, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw in the ContigIntraBandCarr MO cannot be selected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO under this Cell MO is selected, the TxRxMode parameter in the Cell MO can only be set to 1T1R, 1T2R, 2T2R, 2T4R, or 4T4R.
    • If the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MOs corresponding to two cells having the same FreqBand parameter value but different DlEarfcn parameter values is selected and the FddTddInd parameter is set to CELL_TDD for both cells, then the bandwidth overlap between the two cells must be smaller than or equal to 14% of the smaller DlBandWidth parameter value between the two cells or the bandwidth occupied by 25 RBs, whichever is smaller.
    • When FddTddInd in the Cell MO is set to CELL_FDD and NbCellFlag is set to FALSE, the GUARDBAND_COMPACT_SW and POWER_RAISE_SW options of the ContigIntraBandCarrSw parameter in a ContigIntraBandCarr MO can be selected and FixedExclusiveResRate can be set to a value other than 255.
  • Relation with the DdCellGroup MO:
    • If the setting of LocalCellId in the ContigIntraBandCarr MO is the same as that of LocalCellId1 or LocalCellId2 in the DdCellGroup MO, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw in the ContigIntraBandCarr MO must be deselected.
  • Relation with the CellMBMSCfg MO:
    • MBMSSwitch in the CellMBMSCfg MO and CONTIG_INTRA_BAND_CARR_SW of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be both turned on.

    • If the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw in the ContigIntraBandCarr MO is selected, UlHoppingType in the CellUlschAlgo MO must be set to HOPPING_OFF.

  • Relation with the Cell and CellRbReserve MOs:

    • The spectrum ranges specified by RbRsvStartIndex and RbRsvEndIndex for two cells meeting the following conditions must not overlap: UlEarfcnCfgInd is set to NOT_CFG for the two cells and the two cells have the same setting of FreqBand and different settings of DlEarfcn, the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw is selected in the ContigIntraBandCarr MOs corresponding to the two cells, the difference between the values of DlEarfcn of the two cells is less than half of the sum of the bandwidths occupied by the RBs of the quantities indicated in the values of UlBandWidth of the two cells, RbRsvMode is set to NB_DEPLOYMENT or NB_RESERVED for the two cells, and RbRsvType is set to UPLINK_MODE for the two cells.
  • Relation with the Cell and Prb MOs:

The difference between the value of DlEarfcn of any of the two cells and the value of DlEarfcn of any other cell except the cells where these NB-IoT cells are deployed must be greater than half of the bandwidth specified by DlBandWidth corresponding to DlEarfcn of this other cell.
  • Relation with the Cell, eUCellSectorEqm, and SECTOREQM MOs:

If the SECTORID parameter is set to the same value in these SECTOREQM MOs, each of the BEAMSHAPE, BEAMLAYERSPLIT, and BEAMAZIMUTHOFFSET parameters must be set to the same value in these SECTOREQM MOs.

    • Among the cells that are served by the same sector equipment, have the same setting of FreqBand and different settings of DlEarfcn, and have the CONTIG_INTRA_BAND_CARR_SW option of ContigIntraBandCarrSw selected in the ContigIntraBandCarr MOs corresponding to these cells, any given cell can have the following relationship with only one of the other cells: The difference between the values of DlEarfcn of the two cells is less than half of the sum of the bandwidths occupied by the RBs of the quantities indicated in the values of DlBandWidth of the two cells.

  • Relation with the EuSectorEqmGroup MO:
    • When the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is selected, the EuSectorEqmGroup MO cannot be configured for this cell.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MOs under all Cell MOs with the same LteNrSpectrumShrCellGrpId parameter value as this Cell MO must be deselected.
  • Relation with the CellAutoShutdown MO:
    • If the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO under a Cell MO is selected, the CellAutoShutdownSwitch parameter in the CellAutoShutdown MO under this Cell MO can only be set to OFF.
  • Relation with the CellSmartPwrLock MO:
    • If the POWER_RAISE_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is selected, the SmartPowerLockMode parameter in the CellSmartPwrLock MO must be set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Contiguous Intra-Band Carriers Switch

Indicates whether to enable the algorithms related to the Zero Guard Band Between Contiguous Intra-Band Carriers feature.

CONTIG_INTRA_BAND_CARR_SW: If this option is selected, Zero Guard Band Between Contiguous Intra-Band Carriers is enabled. Multiple LTE carriers can be deployed in such a way that these carriers overlap. When the spectrum resources of two cells overlap, the overlapping spectrum resources can be used by both cells. If this option is deselected, Zero Guard Band Between Contiguous Intra-Band Carriers is disabled. This option applies only to LTE FDD and LTE TDD.

GUARDBAND_COMPACT_SW: If this option is selected, the guard band compression function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is enabled, allowing guard bands that do not overlap with other spectrum resources to be compressed. The center frequency of the cell can be re-configured to obtain more RBs. If this option is deselected, the guard band compression function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is disabled. This option applies only to LTE FDD.

POWER_RAISE_SW: If this option is selected, the power increase function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is enabled, allowing UEs to increase power. If this option is deselected, the power increase function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is disabled. This option applies only to LTE FDD.

LOW_QUALITY_RB_SCH_SW: If this option is selected, low-quality RBs cannot be allocated. If this option is deselected, low-quality RBs can be allocated. This option applies only to LTE FDD and LTE TDD.
Fixed Exclusive Resource Rate

Indicates the proportion of resources that are always exclusively used in a cell to the total resources in the cell. If this parameter is set to 80, 80% of the resources in the cell are always exclusively used. If this parameter is set to 100, all resources in the cell are always exclusively used, that is, resources in the cell are not shared. If this parameter is set to 255, the proportion does not take effect. This parameter applies only to LTE FDD.
