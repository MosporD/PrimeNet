DMIMOAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-DMIMOAlgo

Description

The DMIMOAlgo MO consists of parameters related to distributed MIMO (D-MIMO), including D-MIMO A3 offset and RSRP difference threshold of cooperating cells for joint transmission.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.
D-MIMO A3 RSRP Offset

Indicates the threshold of the RSRP difference between a neighboring cell and the serving cell to trigger event A3 report for inter-cell D-MIMO when the neighboring cell has better signal quality than the serving cell. A large value of this parameter indicates that neighboring cells must have better signal quality to trigger measurement reporting for inter-cell D-MIMO. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.
D-MIMO JT Cell RSRP Difference Threshold

Indicates the RSRP difference threshold for D-MIMO joint transmission UEs in selecting coordinating cells. If this parameter is set to a large value, neighboring cells must have better signal quality to be coordinating cells, and a small number of UEs are identified as joint transmission UEs. If this parameter is set to a small value, a large number of UEs are identified as joint transmission UEs. This parameter applies only to LTE TDD.
