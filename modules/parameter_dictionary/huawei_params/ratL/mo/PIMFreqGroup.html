PIMFreqGroup

+-NE
  +-eNodeBFunction
    +-PIMFreqGroup
      +-PIMFreqCfg[0~4]

Description

The PIMFreqGroup MO consists of parameters used to configure PIM frequency groups.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    PIMFreqCfg[0~4]
  • Relation with the ENodeBAlgoSwitch MO:
    • If a PIMFreqGroup MO is configured, the PIM_ADP_CELL_SEL_SWITCH option of PimSwitch in the ENodeBAlgoSwitch MO must be selected.
  • Relation with the MPT MO:
    • If TYPE in an MPT MO instance is set to LMPT for an eNodeB, PimMitigationMode in a PIMFreqGroup MO instance cannot be set to BASED_ON_JOINT_SCH for the eNodeB.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to query the configuration information about PIM cell group.

Use this command to list the configuration information about PIM frequency group.

Use this command to remove a PIM frequency group.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
PIM Frequency Group ID

Indicates the ID of a passive intermodulation (PIM) frequency group. It uniquely identifies a PIM frequency group within an eNodeB. This parameter applies only to LTE FDD.
PIM Mitigation Mode

Indicates the PIM mitigation mode. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
PIM Downlink EARFCN

Indicates the downlink EARFCN of a carrier involved in passive intermodulation (PIM) mitigation. This parameter applies only to LTE FDD.
Local Cell ID

Indicates the local cell ID of a cell involved in passive intermodulation (PIM) mitigation. This parameter applies only to LTE FDD.
Cell PIM State

Indicates whether PIM mitigation is enabled for cells involved in PIM mitigation. This parameter applies only to LTE FDD.
Sector Equipment ID

Indicates the ID of the sector equipment that serves the cell involved in passive intermodulation (PIM) mitigation. This parameter applies only to LTE FDD.
Sector ID

Indicates the ID of the sector for the cell involved in passive intermodulation (PIM) mitigation. This parameter applies only to LTE FDD.
Cell Punctured RB Count

Indicates the number of RBs to be blocked in the cell. For SFN cells, the number of blocked RBs of a single physical cell is displayed. This parameter applies only to LTE FDD.
