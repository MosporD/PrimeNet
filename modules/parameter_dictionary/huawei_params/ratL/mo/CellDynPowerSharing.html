CellDynPowerSharing

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDynPowerSharing

Description

A CellDynPowerSharing MO consists of parameters used to configure dynamic power sharing, including the local cell ID, dynamic power sharing switch, and maximum power sharing rate.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CspcAlgoPara, CellCspcPara, CellAlgoSwitch, Cell, and PHICHCfg MOs:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only when the following conditions are met: The GLPwrShare parameter in the CellAlgoSwitch MO, the CspcAlgoSwitch parameter in the CspcAlgoPara MO, and the CellCspcSwitch and CelleCspcSwitch parameters in the CellCspcPara MO are set to OFF, the PhichInnerLoopPcSwitch option of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, and the PhichDuration parameter in the PHICHCfg MO is not set to EXTENDED.
  • Relation with the Cell MO:
    • The LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected when the MultiRruCellMode parameter in the Cell MO is not set to MPRU_AGGREGATION, TWO_RRU_COMBINATION, or DIGITAL_COMBINATION.
    • The UMTS_LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO under a Cell MO can be selected only if the FddTddInd parameter in this Cell MO is set to CELL_FDD.
    • If the LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO under a Cell MO is selected, the MultiRruCellFlag parameter in this Cell MO cannot be set to BOOLEAN_TRUE.
    • The LTE_NR_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the LTE_NR_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, then the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO must be selected.
    • The LTE_NR_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R.
  • Relation with the PDSCHCfg MO:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO under a Cell MO can be selected only if the TxPowerOffsetAnt0, TxPowerOffsetAnt1, TxPowerOffsetAnt2, and TxPowerOffsetAnt3 parameters in the PDSCHCfg MO under this Cell MO are all set to 255.
    • If the LTE_DYN_POWER_SHARING_SW, UMTS_LTE_DYN_POWER_SHARING_SW, or LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, the CrsPowerBoostingAmplitude parameter in the PDSCHCfg MO can only be set to DB_0.
    • If the LTE_DYN_POWER_SHARING_SW, UMTS_LTE_DYN_POWER_SHARING_SW, or LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, the PdschPowerBoostingSwitch parameter in the PDSCHCfg MO can only be set to OFF.
    • If the LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO under a Cell MO is selected, the SINGLE_CA_PWR_SHARE_SW_FOR_4T option of the TxChnPowerCfgSw parameter in the PDSCHCfg MO under this Cell MO must be deselected.
  • Relation with the Cell, CellUSParaCfg, and CellAlgoSwitch MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD and the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, the MultiCellShareMode and SubframeAssignment parameters in the Cell MO must be set to NORMAL and SA2 respectively, and both the USPwrSharePaSwitch option of the UsAlgoExSwitch parameter in the CellUSParaCfg MO and InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO must be deselected.
  • Relation with the Cell and CellEmtcAlgo MOs:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only when the NbCellFlag parameter in the Cell MO is not set to TRUE, the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is deselected, and the DlBandWidth parameter in the Cell MO is not set to CELL_BW_N6(1.4M) or CELL_BW_N15(3M).
  • Relation with the ENodeBAlgoSwitch, CspcAlgoPara, and CellAlgoSwitch MOs:
    • The LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only if the DlIcicSwitch parameter in the ENodeBAlgoSwitch MO is set to DlIcicSwitch_OFF_ENUM, the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO is deselected, and both the BFModeUserAdptPwrSwitch and BFModeUserPwrSwitch options of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO are deselected.
  • Relation with the CellAuxEnbBind and CellAuxDuBind MOs:
    • When the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, no CellAuxEnbBind and CellAuxDuBind MO can be added.
  • Relation with the CellCounterParaGroup MO:
    • The InterferenceControlSwitch parameter in the CellDynPowerSharing MO can be set to ON only if the BasedA3EdgeUserSwitch option of the CellCounterAlgoSwitch parameter in the CellCounterParaGroup MO is selected.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the FddTddInd in the Cell is set to CELL_FDD, and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the LTE_DYN_POWER_SHARING_SW and UMTS_LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO cannot be selected.
  • Relation with the ContigIntraBandCarr MO:

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Dynamic Power Sharing Switch

Indicates whether to enable dynamic power sharing. This parameter consists of the following options:

LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers. These LTE carriers can be FDD carriers or TDD carriers, but cannot be any combination of FDD and TDD carriers. When this option is selected, power can be shared between LTE carriers. This option applies only to LTE FDD and LTE TDD.

UMTS_LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and UMTS carriers. When this option is selected, power can be shared between LTE and UMTS carriers. This option applies only to LTE FDD.

LTE_NR_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and NR carriers. When this option is selected, power can be shared between LTE and NR carriers. This option applies only to LTE TDD.

LTE_EXTREME_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers that share the same channel and between split cells. When this option is selected, power can be shared between LTE carriers that share the same channel and between split cells. This option applies only to LTE FDD.
Max Power Sharing Rate

Indicates the maximum percentage of power that the LTE carrier can share from other carriers. This parameter applies only to LTE FDD and LTE TDD.
Interference Control Switch

Indicates whether to enable interference control. If this parameter is set to ON, interference control is enabled. The eNodeB periodically predicts the impact of the local cell's reception of shared power on neighboring cells in terms of interference. If the prediction results indicate that the overall performance of the local and neighboring cells will be better after power sharing, the eNodeB allows the local cell to receive shared power in the next period. If this parameter is set to OFF, interference control is disabled. This parameter applies only to LTE FDD and LTE TDD.
Power Adjustment Mode

Indicates the power adjustment mode of the cell that receives shared power. If this parameter is set to PDSCH_ONLY, the eNodeB increases only PDSCH power in the cell. If this parameter is set to CRS_AND_PDSCH, the eNodeB increases both CRS power and PDSCH power in the cell. This option applies only to LTE FDD.
Power Insufficiency Time Rate Threshold

Indicates the threshold, which is a percentage of the scheduling time with power insufficiency, for LTE extreme power sharing to take effect. The larger the value of this parameter, the longer the allowed duration of power insufficiency and the higher the probability that power sharing takes effect. The smaller the value of this parameter, the shorter the allowed duration of power insufficiency and the lower the probability that power sharing takes effect. This parameter applies only to LTE FDD.
