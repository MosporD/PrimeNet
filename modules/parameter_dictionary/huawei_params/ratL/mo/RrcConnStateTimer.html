RrcConnStateTimer

+-NE
  +-eNodeBFunction
    +-RrcConnStateTimer

Description

The RrcConnStateTimer MO contains the timers related to RRC connection control. These timers are defined in 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST RRCCONNSTATETIMER

Use this command to list the parameters related to the timers of RRC connection control.
MOD RRCCONNSTATETIMER

Use this command to modify the parameters related to the timers of RRC connection control.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Timer302

Indicates the length of the timer T302.

T302 specifies the time during which a UE whose RRC connection request is rejected has to wait before the UE can initiate a request again.

This timer starts when the UE receives an RRCConnectionReject message and stops when the UE enters the RRC_CONNECTED mode or performs cell reselection. This parameter applies only to LTE FDD and LTE TDD.
Timer320 for load balance

Indicates the length of the timer contained in the RRC connection release message when an RRC connection release procedure is triggered for MLB. This timer specifies the length of a period during which cell-reselection priorities contained in the RRC connection release message retain valid. After the timer expires, the cell-reselection priorities contained in the RRC connection release message become invalid.

This timer starts when the UE receives an RRC connection release message containing the T320 timer and stops when the UE enters RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.
Timer304 for EUTRAN

Indicates the length of the timer T304 for intra-RAT handover. If the UE does not complete the handover before this timer expires, the UE reverts to the associated configuration and initiates an RRC connection reestablishment procedure. This parameter applies only to LTE FDD and LTE TDD.
Timer304 for GERAN

Indicates the length of the timer T304 for inter-RAT handover to GERAN. If the UE does not complete the handover before this timer expires, the UE reverts to the associated configuration and initiates an RRC connection re-establishment procedure. This parameter applies only to LTE FDD and LTE TDD.
Timer320 for other

Indicates the length of the timer contained in the RRC connection release message when an RRC connection release procedure is triggered for reasons other than MLB. This timer specifies the length of a period during which cell-reselection priorities contained in the RRC connection release message retain valid. After the timer expires, the cell-reselection priorities contained in the RRC connection release message become invalid. This parameter is invalid for UEs to be redirected and reselected based on the SPID-specific frequency priorities.

This timer starts when the UE receives an RRC connection release message containing the T320 timer and stops when the UE enters RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.
NB-IoT Ue inactive timer

Indicates the length of the UE inactivity timer for NB-IoT UEs. If the eNodeB detects that an NB-IoT UE has neither received nor sent data for a duration exceeding the value of this parameter, the eNodeB releases the RRC connection for the NB-IoT UE. This parameter takes effect only for UEs that will access the network after the parameter is set. This parameter applies only to NB-IoT.
Filter Repeated RRCConnReq Timer

Indicates the length of the timer for the eNodeB to filter repeated RRC Connection Request messages. For LTE FDD and LTE TDD, the actually used timer length is the sum of the length of T300 timer and the value of the FilterReptRrcConnReqTimer parameter. For NB-IoT, the actually used timer length is equal to min{T300 + FilterReptRrcConnReqTimer, MaxFilterTimer}. In V100R015C10 or an earlier version, the value of MaxFilterTimer is 17s. In other cases, the value of MaxFilterTimer is 35s.
Uplink Sync Timer Dynamic DRX

Indicates the timer used to govern the period in which the eNodeB maintains uplink synchronization for a DRX UE when dynamic DRX is enabled. After this timer expires, the eNodeB does not send Timing Advance Command to the UE. You are advised to set this parameter to a value less than the value of UeInactivityTimerDynDrxQci in the QciPara MO. In power saving mode, you are advised to set this parameter significantly different to the value of the UeInactivityTimerDynDrxQci parameter in the QciPara MO, for example a gap of 10 seconds, to avoid power consumption increase due to the increase of signaling. This parameter applies only to LTE FDD and LTE TDD.
RRC Connection Release Timer

Indicates the time that the eNodeB waits for a response message after sending an RRC Connection Release message to a UE.
RRC Connection Release Offset Timer in DRX

Indicates the offset of the value of the RRC connection release timer that actually takes effect for UEs in the DRX state relative to the RrcConnRelTimer parameter value in the RrcConnStateTimer MO. This parameter applies only to LTE FDD and LTE TDD.
RRC Connection Release Offset Timer For SRLTE

Indicates the offset of the value of the RRC connection release timer that actually takes effect for SRLTE UEs relative to the RrcConnRelTimer parameter value in the RrcConnStateTimer MO. This parameter applies only to LTE FDD and LTE TDD.
Extended Wait Time

Indicates the waiting time for a UE to send an RRCConnectionRequest message again in either of the following conditions:

1. After the previous RRC connection setup request with the cause value delayTolerantAccess initiated by the UE was rejected when the MME is overloaded

2. After the RRC connection was released for the cause delayTolerantAccess.

In NB-IoT, this parameter is used when the MME is overloaded and flow control is implemented by the eNodeB.
Power Preference Indication Timer

Indicates the waiting time for a UE reporting UEAssistanceInformation after the UE reports Power Preference Indication with the value normal. The duration ranges from 0 to 600 seconds. This option applies only to LTE FDD.
Repeated RRC Reest Protection Timer

Indicates the length of the protection timer of repeated RRC connection reestablishments. If this parameter is set to a non-zero value and the interval between RRC connection reestablishment requests repeatedly initiated by a UE is less than this parameter value, the repeated requests and successful reestablishments are not counted. If this parameter is set to 0, this function does not take effect. This parameter applies only to LTE FDD and LTE TDD.
RRC Release Timer Offset for Out-of-Sync UE

Indicates the offset of the value of the RRC connection release timer that actually takes effect for out-of-synchronization UEs relative to the RrcConnRelTimer parameter value in the RrcConnStateTimer MO.
Bandwidth Preference Indication Timer

Indicates the length of the timer during which UEs are prohibited from reporting the bw-Preference-r14 IE to the eNodeB. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Voice UE Release Delay Timer

Indicates the delay release timer for a voice UE. The eNodeB checks whether the UE sends and receives data. After QCI-1 bearers are released, the UE context cannot be released until the timer expires. If this parameter is set to 0, the timer does not take effect. If this parameter is set to a value other than 0, the UE context cannot be released until the timer expires after the QCI-1 bearers are released. This parameter applies only to LTE FDD and LTE TDD.
eMTC RRC Connection Release Timer Offset

Indicates the offset of the eMTC RRC connection release timer that takes effect relative to the value of the RrcConnRelTimer parameter in the RrcConnStateTimer MO. This parameter applies only to LTE FDD and LTE TDD.
