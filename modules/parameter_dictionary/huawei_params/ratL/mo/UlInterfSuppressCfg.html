UlInterfSuppressCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-UlInterfSuppressCfg

Description

The UlInterfSuppressCfg MO consists of the parameters related to uplink interference suppression. This MO depends on the Cell MO. The UlInterfSuppressCfg MO is automatically added when a cell is added and is automatically removed when the cell is removed.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and EuSectorEqmGroup MOs:
    • The UlIntrfSuppressionValue parameter in the UlInterfSuppressCfg MO can be set to a non-zero value only for a cell with the EuSectorEqmGroup MO configured.
  • Relation with the Cell MO:
    • The ChnCalOptSwitch parameter in the UlInterfSuppressCfg MO can be set to ON only if the FddTddInd and TxRxMode parameters in the Cell MO are set to CELL_TDD and 64T64R or 32T32R respectively.
    • The UlIntrfDetectionTrigThld parameter in the UlInterfSuppressCfg MO can be set to a value other than 127 when all of the following conditions are met: The TxRxMode parameter in the Cell MO is set to 1T2R, 2T2R, 2T4R, or 4T4R, the CellBeamMode parameter in the eUCellSectorEqm MO is set to NORMAL, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE, the InBandRelayDeNbSwitch, InBandRelayReNbSwitch, and OutOfBandRelaySwitch options of the RelaySwitch parameter in the CellAlgoSwitch MO are deselected, the UlHoppingType parameter in the CellUlschAlgo MO is set to HOPPING_OFF, and the CellRadius parameter in the Cell MO is set to a value smaller than or equal to 15000 m.
    • The UL_JOINT_INTRF_SUPPRESS_SW option of the UlJointIntrfManagementSw parameter in a UlInterfSuppressCfg MO can be selected only when the UlIntrfDetectionTrigThld parameter in the UlInterfSuppressCfg MO is not set to 127 and the UlBandWidth parameter in the Cell MO is set to CELL_BW_N6, CELL_BW_N15, CELL_BW_N25, or CELL_BW_N50.
  • Relation with the Cell, SectorSplitCell, and CellAlgoSwitch MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, the REMOTE_INTRF_BF_ENH_SW option of the RemoteIntrfDlEnhSwitch parameter in the UlInterfSuppressCfg MO can be selected only if the UlInterfSuppressionSwitch option of the AvoidInterfSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the CellAlgoSwitch MO:
    • The PucchFlexCfgSwitch option of the PucchAlgoSwitch parameter in the CellAlgoSwitch MO and the REMOTE_INTRF_BF_ENH_SW option of the RemoteIntrfDlEnhSwitch parameter in the UlInterfSuppressCfg MO cannot be selected at the same time.
    • If the InterferenceRbRatioThld parameter in the UlInterfSuppressCfg MO must be set 100 if the InterFreqBackoffSwitch option of the BackoffAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
    • The UL_JOINT_INTRF_POSITION_SW option of the UlJointIntrfManagementSw parameter in the UlInterfSuppressCfg MO can be selected only when all the following conditions are met: The UlIntrfDetectionTrigThld parameter in the UlInterfSuppressCfg MO is set to a value other than 127, the UlVmimoSwitch option of the UlSchSwitch parameter in the CellAlgoSwitch MO is deselected, the ULSUMIMO2LayersSwitch option of the UlSuMimoAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the UL_HIGH_ORDER_COMP_FOR_2R option of the UlHighOrderCompSwitch parameter in the CellAlgoSwitch MO is deselected.
    • If the UlInterSiteIcSwitch or UlIntraSiteIcSwitch option of the UplinkIcSwitch parameter in the CellAlgoSwitch MO for a cell is selected or the UlPAMCSwitch option of the UlSchExtSwitch parameter in the CellAlgoSwitch MO is deselected, the UL_JOINT_INTRF_SUPPRESS_SW option of the UlJointIntrfManagementSw parameter in the UlInterfSuppressCfg MO for this cell must be deselected.
  • Relation with the ENodeBSharingMode, UlCsAlgoPara, CellEmtcAlgo, and CellAlgoSwitch MOs:
    • The UlSingleSideIntrfImpMitSw parameter in the UlInterfSuppressCfg MO must be set to OFF when one of the following conditions is met: - The ENodeBSharingMode parameter in the ENodeBSharingMode MO is not set to INDEPENDENT. - The UL_COORD_RES_ALLOC_SWITCH or UL_COORD_PC_SWITCH option of the UlCsSw parameter in the UlCsAlgoPara MO is selected. - The EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is selected. - The ULSUMIMO2LayersSwitch option of the UlSuMimoAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the Cell and SectorSplitCell MOs:

    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and the SectorSplitCell MO associated with the Cell MO is configured, then the RMT_INF_AVOID_SCH_SW option of the RemoteInfULEnhanceSw parameter in the UlInterfSuppressCfg MO must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and the SectorSplitCell MO associated with the Cell MO is configured, then the REMOTE_INTRF_BF_ENH_SW option of the RemoteIntrfDlEnhSwitch parameter in the UlInterfSuppressCfg MO must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and the SectorSplitCell MO associated with the Cell MO is configured, then the ChnCalOptSwitch parameter in the UlInterfSuppressCfg MO must be set to OFF.
  • Relation with the SRSCfg MO:
    • The WTTxSRSIntrfAvoidanceSw option of the SrsCfgPolicySwitch parameter in the SRSCfg MO and the REMOTE_INTRF_BF_ENH_SW option of the RemoteIntrfDlEnhSwitch parameter in the UlInterfSuppressCfg MO cannot be selected at the same time.
  • Relation with the Cell, CellAlgoSwitch, and CellAlgoExtSwitch MOs:
    • The UlIntrfDetectionTrigThld parameter in the UlInterfSuppressCfg must be set to 127 when the FddTddInd parameter in the Cell MO is set to CELL_TDD, the NbCellFlag parameter in the Cell MO is set to TRUE, the Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO is selected, the UlCoverageEnhancementSw parameter in the CellAlgoExtSwitch MO is set to ON, or the UlCyclicPrefix parameter in the Cell MO is set to EXTENDED_CP.
  • Relation with the CellAlgoSwitch, eUCellSectorEqm, and CellUlschAlgo MOs:
    • The UlIntrfDetectionTrigThld parameter in the UlInterfSuppressCfg MO can be set to a value other than 127 when all of the following conditions are met: The TxRxMode parameter in the Cell MO is set to 1T2R, 2T2R, 2T4R, or 4T4R, the CellBeamMode parameter in the eUCellSectorEqm MO is set to NORMAL, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_FALSE, the InBandRelayDeNbSwitch, InBandRelayReNbSwitch, and OutOfBandRelaySwitch options of the RelaySwitch parameter in the CellAlgoSwitch MO are deselected, the UlHoppingType parameter in the CellUlschAlgo MO is set to HOPPING_OFF, and the CellRadius parameter in the Cell MO is set to a value smaller than or equal to 15000 m.
  • Relation with the CellEmtcAlgo MO:
    • If the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected, the UlIntrfDetectionTrigThld parameter in the associated UlInterfSuppressCfg MO must be set to 127.
  • Relation with the CellAlgoExtSwitch and CellAlgoSwitch MOs:
    • The UL_JOINT_INTRF_SUPPRESS_SW option of the UlJointIntrfManagementSw parameter in the UlInterfSuppressCfg MO for a cell can be selected only when the UlCoverageEnhancementSw parameter in the CellAlgoExtSwitch MO for the cell is set to OFF and the UL_HIGH_ORDER_COMP_FOR_2R option of the UlHighOrderCompSwitch parameter in the CellAlgoSwitch MO for the cell is deselected.
  • Relation with the Cell and RACHCfg MOs:
    • If the CHN_CALIB_SHIFT_SW option of the RemoteInfULEnhanceSw parameter in the UlInterfSuppressCfg MO is selected, then the FddTddInd parameter in the Cell MO must be set to CELL_TDD, the TxRxMode parameter in the Cell MO must be set to 32T32R or 64T64R, the PrachConfigIndex parameter in the RACHCfg MO must be set to 4, and the ChnCalOptSwitch parameter in the UlInterfSuppressCfg MO must be set to OFF.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Up Interference Suppression Threshold

Indicates the threshold for determining whether the interference detected in an uplink subframe is strong. When interference detected in an uplink subframe is greater than this threshold, the uplink interference detection and suppression algorithm is automatically enabled and the uplink power control policy is automatically adjusted. Conservative scheduling is performed for access signaling. As a result, the impact of interference on the system performance is reduced. This parameter applies only to LTE TDD cells.
P0 UE PUSCH Offset

Indicates the P0_UE_PUSCH adjustment, which represents the adjustment of the PUSCH transmit power of UEs. This parameter applies only to LTE TDD cells.
Rand Attach Signal MCS Offset

Indicates the MCS index adjustment of access signaling. This parameter applies only to LTE TDD cells.
P0 UE Pucch Offset

Indicates the P0_UE_PUCCH adjustment, which represents the adjustment of the PUCCH transmit power of UEs. This parameter applies only to LTE TDD cells.
Delta Msg2 Offset

Indicates the power offset adjustment for MSG3 transmission during uplink random access, which is sent to the UE in an RAR message. This parameter applies only to LTE TDD cells.
Strong Interference UE Threshold Boost Ratio

Indicates the increase ratio of the threshold for identifying UEs with strong interference and of the PRACH detection threshold. The value x of this parameter indicates that the PRACH detection threshold increases by x%. The value -x indicates that the PRACH detection threshold decreases by x%. This parameter applies only to LTE TDD cells.
Uplink Interference Statistic Period

TDD: Indicates the period during which interference detection statistics are collected for triggering the uplink interference suppression algorithm. If the average interference noise on each PRB in normal uplink subframes during the period specified by this parameter is greater than the interference suppression threshold, the eNodeB reports that interference occurs. FDD: Indicates the period in which uplink interference detection is performed and the detection results are reported. This parameter applies only to LTE FDD and LTE TDD.
Uplink Interference Statistic Period Number

Indicates the number of periods during which interference detection statistics are collected, for disabling the uplink interference suppression algorithm. If the interference detected during x (x is specified by this parameter) consecutive periods are smaller than the value of the UlInterfsuppressionThd parameter in the UlInterfSuppressCfg MO, the eNodeB reports that there is no interference. This parameter applies only to LTE TDD cells.
VoIP MCS Offset

Indicates the MCS index adjustment for voice services. This parameter applies only to LTE TDD cells.
VoIP PUCCH Power Control Target SINR Offset

Indicates the SINR target offset of PUCCH power control for voice services. This parameter applies only to LTE FDD and LTE TDD.
VoIP PUSCH PSD Control Target

Indicates the transmit power spectral density for the PUSCH of voice UEs when the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter is selected. A large value of this parameter indicates a high transmit power spectral density for the PUSCH of voice UEs. This parameter applies only to LTE TDD cells.
Remote Interference Uplink Enhance Switch

Indicates whether to enhance uplink channels when remote interference (atmospheric duct interference) occurs.

RMT_INF_PUSCH_ENH_SW: Indicates whether to enhance the PUSCH when remote interference occurs. If this option is selected, the PUSCH is enhanced when remote interference occurs. If this option is deselected, the PUSCH is not enhanced when remote interference occurs. This option applies only to LTE TDD.

RMT_INF_AVOID_SCH_SW: Indicates whether to enable interference avoidance and frequency-selective adaptation when remote interference occurs in non-massive MIMO cells. Interference avoidance and frequency-selective adaptation are enabled for non-massive MIMO cells only if this option is selected. This option takes effect only when the InterferenceRbRatioThld parameter in the UlInterfSuppressCfg MO is not set to 100. This option applies only to LTE TDD.

CHN_CALIB_SHIFT_SW: Indicates whether to enable the channel calibration shift function. If this option is selected, channel calibration shift is enabled. If this option is deselected, channel calibration shift is disabled. This option applies only to LTE TDD.
Delta SINR Thld for UL PUSCH Enhancement

Indicates the threshold of the difference between the SINR before SINR balancing and that after balancing for starting enhanced PUSCH demodulation. If the SINR difference is smaller than or equal to this threshold, enhanced PUSCH demodulation is started. If the SINR difference exceeds this threshold, enhanced PUSCH demodulation is terminated. This parameter applies only to LTE TDD.
Access Signaling Power Control Switch

Indicates whether to enable signaling power control during network access. If this parameter is set to ON(On), a conservative power control policy is used to increase signaling power and thereby to ensure signaling reliability during network access. If this parameter is set to OFF(Off), the power control policy used during network access is the same as that used during serving provisioning. In such a case, the signaling power is low during network access. This parameter is valid only when the UlInterfSuppressionSwitch option of the AvoidInterfSwitch parameter in the CellAlgoSwitch MO is selected. This parameter applies only to LTE TDD.
UL Interference Symbol Pwr Difference Thld

Indicates the threshold of the power difference between the symbol with the maximum receive power and that with the minimum receive power in a TDD uplink subframe. This threshold is used to identify atmospheric duct interference. If the power difference exceeds this threshold, the eNodeB determines that the uplink subframe is subject to atmospheric duct remote interference. This parameter applies only to LTE TDD.
Uplink Interference Suppression Value

Indicates the amount of uplink interference that can be suppressed for pRRUs. If this parameter is set to 0, pRRU uplink interference suppression does not take effect. If this parameter is set to a non-0 value, pRRU uplink interference suppression is triggered. This parameter is valid only when the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE, the MultiRruCellMode parameter in the Cell MO is set to SFN, CELL_COMBINATION, or MPRU_AGGREGATION, and an EuSectorEqmGroup MO is configured for the cell. This parameter applies only to LTE FDD and LTE TDD.
Channel Calibration Optimization Switch

Indicates whether to enable channel calibration optimization. If this parameter is set to ON, channel calibration optimization is enabled. If this parameter is set to OFF, channel calibration optimization is disabled. This parameter applies only to LTE TDD.
Remote Interference Downlink Enhancement Sw

Indicates whether to enable downlink enhancement in the case of remote interference (atmospheric duct interference).

REMOTE_INTRF_BF_ENH_SW: Indicates whether to enable beamforming enhancement when remote interference occurs. If this option is selected, beamforming enhancement is enabled when remote interference occurs. If this option is deselected, beamforming enhancement is disabled when remote interference occurs. This option applies only to LTE TDD.
Interference RB Ratio Threshold

Indicates the threshold of the percentage of interference RBs for identifying whether a cell suffers from severe atmospheric duct interference. This parameter also indicates whether to enable inter-frequency MLB of low-efficiency UEs when interference occurs. The value 100 indicates that inter-frequency MLB of low-efficiency UEs is disabled when interference occurs. A value other than 100 indicates that inter-frequency MLB of low-efficiency UEs is enabled when interference occurs. If inter-frequency MLB of low-efficiency UEs is enabled when interference occurs and the percentage of interference RBs in a cell is greater than this threshold, the cell suffers from severe atmospheric duct interference. Otherwise, the cell does not suffer from severe atmospheric duct interference. This parameter applies only to LTE TDD.
UL Single Side Intrf Impact Mitigation Sw

Indicates whether to enable PUCCH interference impact mitigation and PUSCH interference impact mitigation in single-side intra-band interference scenarios. If this parameter is set to OFF, both PUCCH interference impact mitigation and PUSCH interference impact mitigation are disabled. If this parameter is set to PUCCH_INTRF_IMPACT_MITIGATION, only PUCCH interference impact mitigation is enabled. If this parameter is set to PUSCH_INTRF_IMPACT_MITIGATION, only PUSCH interference impact mitigation is enabled. If this parameter is set to ADAPTIVE_PROCESSING, PUCCH interference impact mitigation and PUSCH interference impact mitigation take effect adaptively. This parameter applies only to LTE FDD.
UL Homologous Interference Percentage Thld

Indicates the uplink homologous interference percentage threshold. If the percentage of homologous interference between the serving cell and a cooperating cell for uplink interference detection is higher than this threshold, the two cells meet the homologous interference condition for multi-cell joint interference management. This parameter applies only to LTE FDD.
UL Interference Detection A3 Offset

Indicates the event A3 offset, a value by which the neighboring cell quality should be higher than the serving cell quality, for uplink interference detection. This parameter applies only to LTE FDD.
UL Interference Detection Triggering Thld

Indicates the threshold for triggering uplink interference detection in uplink wideband interference management. If this parameter is set to 127, uplink interference detection is disabled and uplink interference detection is not performed. If this parameter is set to a value in the range of -120 to 0, uplink interference detection is enabled. If the strength of interference is greater than or equal to this threshold, interference detection will be performed. This parameter applies only to LTE FDD.
UL Joint Interference Management Switch

Indicates whether to enable functions related to uplink multi-cell joint interference management.

UL_JOINT_INTRF_POSITION_SW: Indicates whether to enable uplink multi-cell joint interference locating. Uplink multi-cell joint interference locating takes effect only if this option is selected. This option applies only to LTE FDD.

UL_JOINT_INTRF_SUPPRESS_SW: Indicates whether to enable uplink joint interference suppression. Uplink joint interference suppression takes effect only if this option is selected. This option applies only to LTE FDD.

UL_NARROWBAND_INTRF_SCH_OPT_SW: Indicates whether to enable scheduling optimization for uplink narrowband interference reduction. Scheduling optimization for uplink narrowband interference reduction takes effect only if this option is selected. This option applies only to LTE FDD.
UL Strong Intrf Correlation Coefficient Thld

Indicates the correlation coefficient threshold for determining strong interference. When it is detected that the coefficient of correlation between a UE and strong interference is greater than the actual value of this parameter, this coefficient is recorded and reported. This parameter applies only to LTE FDD.
Uplink Interference Positioning Config

Indicates the configuration for uplink interference locating.

The combination of the settings of bit 0 to bit 2 indicates the maximum number of interference orientations used in interference locating. The corresponding decimal value range is 0 to 7. The larger the number of antennas, the stronger the space-domain detection capability and the larger the number of interference orientations that can be used to locate interference sources. On live networks, if both the number of antennas and the number of interference sources are large, it is recommended that this parameter be set to a large value to increase the number of interference sources located at a time. If the number of antennas is large but the number of interference sources is small, it is recommended that this parameter be set to a small value to improve interference locating accuracy. For example, it is recommended that this parameter be set to 2 in 2R scenarios and 3 in 4R scenarios. This parameter cannot be set to a value greater than 4 in these scenarios.

The combination of the settings of bit 3 to bit 7 indicates the uplink SINR threshold for strong interference measurement. The corresponding decimal value range is 0 to 31, and the actual value range is -10 dB to 21 dB. When the uplink SINR of a UE is greater than the actual value of this parameter, the coefficient of correlation between the UE and strong interference will be measured. The recommended value is 5, which corresponds to the actual value -5 dB. The combination of the settings of bit 8 to bit 13 indicates the threshold for determining symbol-level interference. If the interference level is greater than this threshold, symbol-level interference exists on the network and the interference suppression procedure ends. The corresponding decimal value range is 0 to 63, and the actual value range is 0 dB to 63 dB. The recommended value is 10. The combination of the settings of bit 14 to bit 19 indicates the evaluated ratio of the combination gain to the interference suppression gain, which is used for selecting cooperating cells for a UE. The corresponding decimal value range is 0 to 60, and the actual value range is 0 to 6. A larger value indicates a higher weight of the combination gain. The recommended value is 15, and the actual value is 1.5. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
Uplink Interference Suppression Status

Indicates the uplink interference suppression status of a pRRU. The value of this parameter can be SUCCESS, FAILURE_DUE_TO_INABILITY, or FAILURE_DUE_TO_OTHER_CAUSE. The value SUCCESS indicates that the feature has been successfully activated. The value FAILURE_DUE_TO_INABILITY indicates that the feature fails to be activated because hardware in the sector equipment group for the cell does not support this feature. The value FAILURE_DUE_TO_OTHER_CAUSE indicates that the feature fails to be activated for other reasons. This parameter applies only to LTE FDD and LTE TDD.
