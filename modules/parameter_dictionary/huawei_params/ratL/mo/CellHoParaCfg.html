CellHoParaCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellHoParaCfg

Description

The CellHoParaCfg MO consists of cell-specific handover parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in a CellHoParaCfg MO must have been set in the associated Cell MO.
  • Relation with the CellAlgoSwitch MO:
    • If the ServBasedNrHoSwitch option of the HoAllowedSwitch parameter in the CellAlgoSwitch MO is selected, at least one of the NrRedirectSwitch and NrHoSwitch options of the HoModeSwitch parameter in the CellHoParaCfg MO is selected.
  • Relation with the CellAlgoExtSwitch and CellSiMap MOs:
    • If the INTER_RAT_MOBILITY_TO_NR_SW option of the HoAllowedSwitch parameter in the CellAlgoExtSwitch MO is selected, at least one option among the Sib24Switch option of the SiSwitch parameter in the CellSiMap MO and the NrRedirectSwitch and NrHoSwitch options of the HoModeSwitch parameter in the CellHoParaCfg MO is selected.
  • Relation with the CellAlgoExtSwitch MO:
    • If the FAST_RETURN_TO_NR_SW option of the HoAllowedSwitch parameter in the CellAlgoExtSwitch MO is selected, at least one of the NrRedirectSwitch and NrHoSwitch options of the HoModeSwitch parameter in the CellHoParaCfg MO is selected.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
BlindHO A1A2 RSRP trigger threshold

Indicates the RSRP threshold for events A1 and A2 related to coverage-based inter-frequency blind handover and coverage-based inter-RAT blind handover. If the RSRP of the serving cell exceeds the threshold, event A1 is reported. If the RSRP of the serving cell is lower than the threshold, event A2 is reported.

This parameter applies only to LTE FDD and LTE TDD.
BlindHO A1A2 RSRQ trigger threshold

Indicates the RSRQ threshold for events A1 and A2 related to coverage-based inter-frequency blind handover and coverage-based inter-RAT blind handover. If the RSRQ of the serving cell exceeds the threshold, event A1 is reported. If the RSRQ of the serving cell is lower than the threshold, event A2 is reported. This parameter applies only to LTE FDD and LTE TDD.
High Speed Handover Threshold

Indicates the threshold that determines whether a UE moves at a high or low speed. If the UE moves at a speed lower than this threshold, the UE is a low-speed UE. Otherwise, it is a high-speed UE. This parameter applies only to LTE FDD and LTE TDD.
Handover Mode switch

Indicates the handover method switches based on which the eNodeB determines handover policies.

BlindHoSwitch: This option specifies whether to enable blind handover for CSFB. Bind handover for CSFB is enabled only if this option is selected. A blind handover for CSFB can be triggered only if both this option and the BlindHoSwitch option of the HoModeSwitch parameter in the ENodeBAlgoSwitch MO are selected. This option applies only to LTE FDD and LTE TDD.

UtranPsHoSwitch: PS handover to UTRAN is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UtranSrvccSwitch: SRVCC to UTRAN is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GeranSrvccSwitch: SRVCC to GERAN is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UtranRedirectSwitch: Redirection to UTRAN is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GeranRedirectSwitch: Redirection to GERAN is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UFCsfbBlindHoDisSwitch: If blind handover is enabled and the UFCsfbBlindHoDisSwitch option is selected, the eNodeB performs a measurement-based handover for a UE during an ultra-flash CSFB to UTRAN or GERAN. If blind handover is enabled and the UFCsfbBlindHoDisSwitch option is deselected, the eNodeB performs a blind handover for the UE during the ultra-flash CSFB to UTRAN or GERAN. This option applies only to LTE FDD and LTE TDD.

HighSpeedCsfbBlindSwitch: If this option is selected, the eNodeB can perform blind handovers for high-speed UEs in CSFB. If this option is deselected, whether the eNodeB can perform blind handovers is controlled by the BlindHoSwitch option of the HoModeSwitch parameter in the ENodeBAlgoSwitch MO and the BlindHoSwitch option of the HoModeSwitch parameter in the CellHoParaCfg MO, and blind handovers can be triggered only if these two options are selected. This option applies only to LTE FDD and LTE TDD.

NrRedirectSwitch: Redirection to NR is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NrHoSwitch: Handover to NR is supported only if this option is selected. This option applies only to LTE FDD and LTE TDD.
SRVCC Handover Optimization Switch

Indicates the switches used to control whether to enable optimization algorithms for SRVCC-based handovers.

SRVCCWITHPSCSRETRYSWITCH(SrvccWithPsCsRetrySwitch): Assume that a PS+CS handover preparation for SRVCC fails. If this option is selected, the eNodeB reinitiates a CS handover preparation attempt in the original target cell. If this option is deselected, the eNodeB does not reinitiate a CS handover preparation attempt in the original target cell. This option applies only to LTE FDD and LTE TDD.
Uplink Bad Quality Handover MCS Threshold

Indicates the MCS index threshold for triggering uplink-quality-based handovers. If the uplink MCS index selected for a UE is less than the UlBadQualHoMcsThd parameter value, the eNodeB measures the uplink IBLER of the UE. The eNodeB determines whether to trigger an uplink-quality-based handover for a UE based on the measurement result. If the selected uplink MCS index is greater than the UlBadQualHoMcsThd parameter value, the uplink-quality-based handover is terminated for the UE. This parameter applies only to LTE FDD and LTE TDD.
Uplink Bad Quality Handover IBLER Threshold

Indicates the IBLER threshold for triggering uplink-quality-based handovers. If the uplink IBLER of a UE minus the target IBLER is greater than the UlBadQualHoIblerThd parameter value, an uplink-quality-based handover is triggered for the UE. If the uplink IBLER of a UE minus the target IBLER and minus 10% is greater than the UlBadQualHoIblerThd parameter value, an uplink-quality-based blind handover is triggered for the UE. If the uplink IBLER of a UE minus the target IBLER is less than the UlBadQualHoIblerThd parameter value, the uplink-quality-based handover is terminated for the UE. This parameter applies only to LTE FDD and LTE TDD.
Speed Evaluated Period

Indicates the period during which the number of handovers is used to determine whether a UE in RRC_CONNECTED mode moves at a high speed. If the number of handovers of a UE in an evaluation period specified by SpeedEvaluatedPeriod is greater than SpeedEvaluatedNum, the eNodeB determines that the UE moves at a high speed and initiates a measurement-based redirection to a high-speed frequency. If the number of handovers of the UE in the period is greater than or equal to SpeedEvaluatedNumForFastUe, the eNodeB determines that the UE moves at a fast speed. In this situation, if the UE has GBR bearers, the eNodeB initiates a handover for the UE to a frequency for which the SpeedMobilityTargetInd option of the MobilityTargetInd parameter is selected. This parameter applies only to LTE FDD and LTE TDD.
HO Num in Speed Evaluated Period

Indicates the threshold of the number of handovers for UEs in RRC_CONNECTED mode within a mobility speed evaluation period defined by the SpeedEvaluatedPeriod parameter. If the number of handovers of a UE is greater than the threshold during the period defined by the SpeedEvaluatedPeriod parameter, the eNodeB identifies the UE as a high-speed UE and triggers a measurement-based redirection to a high-speed frequency. This option applies only to LTE FDD and LTE TDD.
LTE To UTRAN CSFB Measurement Processing Mode

Indicates how measurement reports are handled in measurement-based CSFB to UTRAN. If this parameter is set to HANDOVER_IMMEDIATELY, the eNodeB immediately performs handover decision after receiving a measurement report for CSFB to UTRAN. If this parameter is set to BASED_ON_SIGNAL_STRENGTH, the eNodeB transfers UEs to the strongest cell. If this parameter is set to BASED_ON_FREQ_PRIORITY, the eNodeB hands over UEs to a cell on a frequency with a priority as high as possible. If this parameter is set to BASED_ON_LOAD, the eNodeB hands over UEs to a cell with load as light as possible or redirects UEs to the frequency of a cell with load as light as possible. This parameter applies only to LTE FDD and LTE TDD.
CSFB Measurement Waiting Timer

Indicates the length of the timer that the eNodeB waits for the next measurement report after receiving the first measurement report for measurement-based CSFB to UTRAN. This parameter applies only to LTE FDD and LTE TDD.
Handover Algo Switch

Indicates whether to enable handover algorithms. This parameter provides the following options:

InterFreqCoverHoSwitch: If this option is selected, coverage-based inter-frequency handovers are enabled to ensure service continuity. If this option is deselected, coverage-based inter-frequency handovers are disabled. This option applies only to LTE FDD and LTE TDD.

EmcInterFreqBlindHoSwitch: If this option is selected, the eNodeB preferentially performs an inter-frequency blind redirection when an emergency blind handover is triggered. If this option is deselected, the eNodeB only performs an inter-RAT blind handover when an emergency blind handover is triggered. This option applies only to LTE FDD and LTE TDD.

InterFreqSpeedHoSwitch: If this option is selected, speed-based inter-frequency handovers are enabled. This algorithm allows UEs that are running GBR services and move at a high speed to be handed over to operator-specific neighboring frequencies with better coverage. In addition, the eNodeB does not perform load-based and other unnecessary handovers for these UEs. If this option is deselected, speed-based inter-frequency handovers are disabled. This option applies only to LTE FDD and LTE TDD.

IfCoverPreBlindHoSwitch: If this option is selected, the eNodeB preferentially performs coverage-based inter-frequency handovers in a blind manner. That is, the eNodeB does not have to deliver measurement configuration to UEs in the handovers. If this option is deselected, the eNodeB performs the handovers in a measurement-based manner. That is, the eNodeB delivers measurement configuration to UEs in the handovers. This option applies only to LTE FDD and LTE TDD.

InterFreqLcsHoSwitch: If this option is selected and the OTDOA function is enabled, OTDOA-capable emergency UEs in the cell are allowed to be handed over to cells on a frequency with the LcsMobilityTargetInd option of the MobilityTargetInd parameter selected and such UEs are not allowed to be handed over to cells on other frequencies through unnecessary low-priority handovers. If this option is deselected, the serving eNodeB does not perform positioning-based inter-frequency handovers and can perform other types of unnecessary inter-frequency handovers for OTDOA-capable emergency UEs. This option applies only to LTE FDD and LTE TDD.

SevReqHoFailNotifyMmeSw: If the eNodeB re-receives a QCI 1 bearer setup request that is re-sent from the MME after a service-request-based inter-frequency handover is triggered, the eNodeB and the MME perform as follows: If this option is selected and the eNodeB does not receive any measurement report for a service-request-based handover, the eNodeB responds with a special cause value "Failure in the Radio Interface Procedure" to the MME. The MME immediately transfers the voice call procedure from the VoIP procedure to a CSFB procedure when receiving the cause value. If this option is deselected, the eNodeB directly responds with a cause value "S1 intra system Handover triggered" to the MME. The MME does not transfer the voice call procedure from the VoIP procedure to a CSFB procedure when receiving the cause value. This option applies only to LTE FDD and LTE TDD.

NsaDcUeCovBasedHoOptSw: Indicates whether NR coverage is considered during coverage-based handovers of NSA DC UEs with NR-coverage-based PCC anchoring enabled. NR coverage is considered during coverage-based handovers of NSA DC UEs only if this option is selected. This option is valid only if the inter-frequency handover policy group of NSA DC UEs specified by the CellQciPara.NsaDcInterFreqHoGroupId parameter and that of LTE-only UEs specified by the CellQciPara.InterFreqHoGroupId parameter are different. NR-coverage-based PCC anchoring is valid only if the NsaDcPccAnchoringPolicy parameter is set to BASED_ON_NR_COVERAGE and the NSA_PCC_ANCHORING_SWITCH option is selected. This option applies only to LTE FDD and LTE TDD.

HoPlmnFilterOptSw: If this option is selected, the optimized PLMN filtering method is used to filter frequencies to be measured, select target cells, and select UEs for MLB in RAN sharing scenarios. The base station sends UEs only the frequencies of their own operator. In RAN sharing with special dedicated carrier, this ensures that intra- and inter-eNodeB handovers to secondary-operator cells with the EutranExternalCell.MasterPlmnReservedFlag parameter set to TRUE are not initiated for UEs of the primary operator. During UE selection for MLB, the base station selects UEs with a PLMN the same as that of the target cell. If this option is deselected, the eNodeB does not use the optimized PLMN filtering method. This option takes effect in mobility algorithms, MLB, handovers or redirections for PCC anchoring, and cell reselection based on SPID- or operator-specific dedicated priorities. This option is valid only if the FLEXIBLE_SHARING_SWITCH option of the CellAlgoExtSwitch.OperatorFunSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.
Speed Evaluated Number For Fast UE

Indicates the number of handovers used to determine whether a UE in RRC_CONNECTED mode moves at a high speed during a specified period. If the number of handovers of a UE within the time specified by the SpeedEvaluatedPeriod parameter exceeds the value of this parameter, the eNodeB identifies the UE as a high-speed one and performs a speed-based inter-frequency handover for the UE. This parameter applies only to LTE FDD and LTE TDD.
Handover Use UE Inactive Timer Switch

HoUseInactiveTimerSwitch: Indicates whether the source cell delivers information of the elapsed time of the inactivity timer of a UE to the target cell in a handover or an RRC connection reestablishment and the target cell inherits the elapsed time. If this option is selected, the source cell delivers information of the elapsed time of the inactivity timer of the UE in the handover or the RRC connection reestablishment and the target cell inherits the elapsed time. If this option is deselected, the source cell does not deliver the information of the elapsed time of the inactivity timer of the UE in the handover or the RRC connection reestablishment and the target cell does not inherit the elapsed time.
High Speed Cell Sleep User Number

Indicates the UE quantity threshold for triggering blind redirection in a high-speed railway cell when the train leaves the cell. This parameter is used for interference coordination in high-speed railway scenarios. When the train leaves a high-speed railway cell, the eNodeB blindly redirects all the remaining UEs in this cell to a nearby low-speed frequency if the number of the remaining UEs is lower than the threshold specified by this parameter. After the redirection is complete, the cell sends a request for entering the sleeping mode to the eCoordinator. This parameter applies only to LTE TDD.
Low Speed Users Selection Protection Timer

Indicates the protection timer for low-speed UEs used in the Handover Enhancement at Speed Mobility feature. After a high-speed or ultra-high-speed cell hands over low-speed UEs to other cells, the cell does not hand over more low-speed UEs until the protection timer expires. This prevents a large number of UEs from being handed over to other cells when the train slows down or is stopping. If the number of low-speed users on the ground in a high-speed railway cell is large, decreasing this parameter value can improve migration efficiency. This parameter applies only to LTE FDD and LTE TDD.
High Speed Cell Handover-in Protect Timer

Indicates the period during which a UE's handover back to the source cell is not allowed after the UE is handed over to a high-speed cell. This parameter suppresses ping-pong handovers. If this parameter is set to 0, UEs' handover back to the source cell is not suppressed after they are handed over to high-speed cells. This parameter applies to high speed railway scenarios. This parameter can be set based on the length of the handover zone and the train speed. This option applies only to LTE FDD and LTE TDD.
Flash SRVCC Switch

Indicates whether to enable the flash SRVCC algorithm. If this parameter is set to ON(On), the flash SRVCC algorithm is enabled. The eNodeB identifies UEs with weak coverage, rejects such UEs' requests for setting up VoLTE service bearers, and returns a specified cause value to the EPC. After receiving the cause value, the EPC instructs the UEs to immediately change the voice call procedure from VoLTE to CSFB. If this parameter is set to OFF(Off), the flash SRVCC algorithm is disabled. The eNodeB does not identify UEs with weak coverage or reject UEs' requests for setting up VoLTE service bearers because of the weak coverage. This parameter applies only to LTE FDD and LTE TDD.
Ul Poor Coverage Path Loss Threshold

Indicates the path loss threshold for uplink weak coverage identification in the flash SRVCC algorithm. If the FlashSrvccSwitch parameter in the CellHoParaCfg MO is set to ON(On), the eNodeB determines that the UE resides in a weak coverage area when the uplink SINR of the UE is less than the UlPoorCoverSinrThd parameter value or the uplink path loss is greater than the UlPoorCoverPathLossThd parameter value. It rejects the UE's QCI-1 E-RAB setup request, and sends a specified cause value to the EPC. The EPC instructs the UE to change the voice call process from VoIP to CSFB immediately when receiving the cause value. This parameter applies only to LTE FDD and LTE TDD.
Ul Poor Coverage SINR Threshold

Indicates the SINR threshold for uplink weak coverage identification in the flash SRVCC algorithm. If the FlashSrvccSwitch parameter in the CellHoParaCfg MO is set to ON(On), the eNodeB determines that the UE resides in a weak coverage area when the uplink SINR of the UE is less than the UlPoorCoverSinrThd parameter value or the uplink path loss is greater than the UlPoorCoverPathLossThd parameter value. It rejects the UE's QCI-1 E-RAB setup request, and sends a specified cause value to the EPC. The EPC instructs the UE to change the voice call process from VoIP to CSFB immediately when receiving the cause value. This parameter applies only to LTE FDD and LTE TDD.
VoLTE Qual Based Inter-RAT HO QCI1 PLR Thld

Indicates the threshold of the QCI-1 packet loss rate for triggering speech-quality-based handovers. If the QCI-1 packet loss rate is greater than this threshold, UEs are allowed to trigger speech-quality-based inter-RAT handovers. If the QCI-1 packet loss rate is less than VolteQualRecoveryQci1PlrThld, speech-quality-based inter-RAT handovers are stopped. This parameter, if required, must be set to a value greater than or equal to VolteQualRecoveryQci1PlrThld. This parameter applies only to LTE FDD and LTE TDD.
PLR Evaluate Period for VoLTE Quality HO

Indicates the period of evaluating the voice packet loss rate for speech-quality-based handovers. If the period of measuring the voice packet loss rate is longer than this threshold, decisions of triggering speech-quality-based handovers can be made for UEs suffering from low voice quality. This parameter applies only to LTE FDD and LTE TDD.
Measurement Report Delay Timer for QCI 1

Indicates the duration of the handover processing timer started after a dedicated QCI 1 bearer is set up. If this parameter is set to 0, the timer does not take effect. If this parameter is set to a value other than 0, the eNodeB does not process a received handover-oriented measurement report or start the handover processing until the timer expires. This parameter applies only to LTE FDD and LTE TDD.
VoLTE Quality Handover Algo Switch

Indicates whether to turn on switches related to the speech-quality-based handover algorithm.

GeranVolteQualityHoSwitch: If this option is selected, UEs suffering from low speech quality can be handed over to GERAN cells. If this option is deselected, such UEs cannot be handed over to GERAN cells. This option applies only to LTE FDD and LTE TDD.

UtranVolteQualityHoSwitch: If this option is selected, UEs suffering from low speech quality can be handed over to UTRAN cells. If this option is deselected, such UEs cannot be handed over to UTRAN cells. This option applies only to LTE FDD and LTE TDD.

InterFreqVolteQualityHoSwitch: If this option is selected, UEs suffering from low speech quality can be handed over to inter-frequency cells. If this option is deselected, such UEs cannot be handed over to inter-frequency cells. This option applies only to LTE FDD and LTE TDD.
High Speed UE Judge Mode

Indicates the mode for determining whether a UE moves at a high speed. If this parameter is set to HANDOVERNUMBASED, the eNodeB determines whether a UE moves at a high speed based on the number of handovers during a specified period. If this parameter is set to FREQSHIFTBASED, the eNodeB determines whether a UE moves at a high speed based on frequency offset measurement results. This option applies only to LTE FDD and LTE TDD.
Ringing Message Check Switch

Indicates whether to check the SIP Ringing message when the processing delay of SRVCC measurement reports is enabled. The eNodeB identifies the SIP Ringing message and stops the timer defined by SrvccMrDelayTimer after the identification is successful if this parameter is set to ON(On). The eNodeB does not identify the message if this parameter is set to OFF(Off).
SRVCC Measurement Report Delay Timer

Indicates the length of the processing delay timer of inter-RAT handover measurement reports that UEs send when running QCI-1 services. This timer starts when a VoLTE service is successfully set up. It is used to avoid SRVCC before phones ring or users answer calls. This parameter applies only to LTE FDD and LTE TDD.
VoLTE Qual Based Inter-Freq HO QCI1 PLR Thld

Indicates the threshold of the QCI-1 packet loss rate for triggering speech-quality-based inter-frequency handovers. If the QCI-1 packet loss rate is greater than this threshold, UEs are allowed to trigger speech-quality-based inter-frequency handovers. If the QCI-1 packet loss rate is less than VolteQualRecoveryQci1PlrThld, speech-quality-based inter-frequency handovers are stopped.

This parameter, if required, must be set to a value greater than or equal to VolteQualRecoveryQci1PlrThld.

This parameter applies only to LTE FDD and LTE TDD.
VoLTE Quality Recovery QCI1 PLR Thld

Indicates the threshold of the QCI-1 packet loss rate for evaluating whether the speech quality is recovered. When the QCI-1 packet loss rate is less than or equal to this threshold, UEs' speech quality is recovered and speech quality-based inter-frequency and inter-RAT handovers are terminated.

This parameter, if required, must be set to a value less than both VolteQualIfHoQci1PlrThld and Qci1PlrThldForVolteQualHo. This parameter applies only to LTE FDD and LTE TDD.
Coverage-based Intra RAT Meas Period

Indicates the threshold for determining whether LTE measurements have been performed prior to emergency blind redirections. When event A2 for blind redirections is reported, if the elapsed time after the eNodeB delivers the last coverage-based inter-frequency measurement configurations exceeds this threshold, the eNodeB determines that LTE measurements have been performed; if the elapsed time is smaller than this threshold, the eNodeB determines that no LTE measurements have been performed.
Inter-RAT Uu Handover Failure Retry Times

Indicates the number of inter-RAT handover retries initiated to the same target cell after the handover fails over the air interface in the target cell. This parameter applies only to LTE FDD and LTE TDD.
E-UTRAN RSRP Filter Coefficient

Indicates the upper-layer filtering coefficient for the RSRP of E-UTRAN. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
E-UTRAN RSRQ Filter Coefficient

Indicates the upper-layer filtering coefficient for the RSRQ of E-UTRAN. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Emerg Blind Redirect A1 A2 RSRP Thld for CE Mode A

Indicates the RSRP threshold for events A1 and A2 related to coverage-based inter-frequency and inter-RAT emergency blind redirections for UEs in coverage enhancement (CE) mode A. If the measured RSRP value of the serving cell exceeds the threshold, event A1 is reported. If the measured RSRP value of the serving cell is lower than the threshold, event A2 is reported. In CE mode B, the actual RSRP threshold is equal to the value of this parameter minus 10 dB. If the actual RSRP threshold is less than the minimum value, the minimum value takes effect. This parameter applies only to LTE FDD and LTE TDD.
Emerg Blind Redirect A1 A2 RSRQ Thld for CE Mode A

Indicates the RSRQ threshold for events A1 and A2 related to coverage-based inter-frequency and inter-RAT emergency blind redirections for UEs in coverage enhancement (CE) mode A. If the measured RSRQ value of the serving cell exceeds the threshold, event A1 is reported. If the measured RSRQ value of the serving cell is lower than the threshold, event A2 is reported. This parameter also takes effect for UEs in CE mode B. This parameter applies only to LTE FDD and LTE TDD.
Inter-RAT Measurement Report Delay Timer

Indicates the length of the timer for delaying processing measurement reports related to inter-RAT interoperations (excluding interoperations to NR) involving QCI 5. This timer starts after a QCI-5 bearer is set up for a VoLTE UE. This timer is used to decrease the probability of connection failures caused by inter-RAT interoperations involving QCI 5 before QCI-1 bearers are set up. This parameter applies only to LTE FDD and LTE TDD.
Service-based NR Measurement Timer

Indicates the length of the timer for NR measurements for service-based handovers from E-UTRAN to NG-RAN. If this parameter is set to 0, periodic NR measurements for service-based handovers from E-UTRAN to NG-RAN are disabled. If this parameter is set to a value in the range of 5 to 60, the value indicates the length of the timer for NR measurements for service-based handovers from E-UTRAN to NG-RAN. This parameter applies only to LTE FDD and LTE TDD.
CQI-based Inter-Freq HO Thld

Indicates the threshold for triggering CQI-based inter-frequency handovers. This parameter is equivalent to the Release-8 CQI threshold. When the channel quality of the serving cell reported by a UE is worse than or equal to the channel quality corresponding to the threshold in the case of single-codeword transmission, a CQI-based inter-frequency handover is triggered. If this parameter is set to 0, this threshold does not take effect. This parameter applies only to LTE FDD.
VoLTE Handover to NR Delay Timer

Indicates the length of the timer during which the eNodeB does not process the coverage-based or service-based LTE-to-NR measurement report that is received before a QCI 1 bearer is set up. If this parameter is set to 0, this parameter does not take effect. If this parameter is set to a non-zero value, the eNodeB performs the following operations:

1. If a service-based LTE-to-NR measurement report is received before the timer expires, the eNodeB will discard this report.

2. If a coverage-based LTE-to-NR measurement report is received before the timer expires and the RsvdSwPara7_bit22 option of the eNBCellRsvdPara.RsvdSwPara7 parameter is selected, the eNodeB will discard this report.

3. If a fast-return-induced LTE-to-NR measurement report is received before the timer expires, the eNodeB will process this report.

This parameter applies only to LTE FDD and LTE TDD.
Intra-eNodeB Freq-Pri-based HO DL PRB Thld

Indicates the downlink PRB usage threshold for the cell to become a candidate target cell for intra-eNodeB frequency-priority-based handovers when frequency-priority-based inter-frequency handover is enabled for the cell. The cell can be selected as a candidate target cell only when the downlink PRB usage of the cell is less than this threshold. Otherwise, the cell cannot be selected as a candidate target cell. This parameter applies only to LTE FDD and LTE TDD.
Intra-eNodeB Freq-Pri-based HO UL PRB Thld

Indicates the uplink PRB usage threshold for the cell to become a candidate target cell for intra-eNodeB frequency-priority-based handovers when frequency-priority-based inter-frequency handover is enabled for the cell. The cell can be selected as a candidate target cell only when the uplink PRB usage of the cell is less than this threshold. Otherwise, the cell cannot be selected as a candidate target cell. This parameter applies only to LTE FDD and LTE TDD.
