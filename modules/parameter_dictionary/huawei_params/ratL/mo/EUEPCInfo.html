EUEPCInfo

+-NE
  +-eNodeBFunction
    +-EUEPCInfo

Description

The EUEPCInfo MO consists of common information about a compact EPC.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoSwitch MO:
    • The OutOfBandRelaySwitch or InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO can be selected only when there is an EUEPCInfo MO instance.
  • Relation with the ENodeBAlgoSwitch MO:
    • The EUCompactRANSwitch parameter in the ENodeBAlgoSwitch MO can be set to ON only when at least one EUEPCInfo MO is configured. An EUEPCInfo MO can be deleted only when the EUCompactRANSwitch parameter in the ENodeBAlgoSwitch MO is set to OFF.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD EUEPCINFO

Use this command to add compact EPC information.
LST EUEPCINFO

Use this command to query information about the compact EPC.
MOD EUEPCINFO

Use this command to modify compact EPC information.
RMV EUEPCINFO

Use this command to delete compact EPC information.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local EPC ID

Indicates the local ID of the compact EPC. This parameter applies only to LTE FDD and LTE TDD.
MME Group ID

Indicates the ID of the MME group in the compact EPC. This parameter applies only to LTE FDD and LTE TDD.
MME Code

Indicates the code of the MME in the compact EPC. This parameter applies only to LTE FDD and LTE TDD.
Full Name for Network

This parameter specifies the full name of a network service provider. This parameter applies only to LTE FDD and LTE TDD.
Short Name for Network

This parameter specifies the abbreviation for the name of a network service provider. This parameter applies only to LTE FDD and LTE TDD.
