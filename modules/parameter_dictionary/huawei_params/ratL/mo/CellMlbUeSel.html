CellMlbUeSel

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMlbUeSel

Description

The CellMlbUeSel MO consists of cell-specific parameters related to UE selection for MLB. After MLB algorithms are enabled, UEs meeting certain criteria are selected for MLB-oriented data transfer. This MO includes parameters related to UE priorities and thresholds used for the selection criteria.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
UE Select PRB Priority

Indicates the priority of the UEs' PRB usage used as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the PRB usage is not regarded as a criterion for MLB-oriented UE selection. The parameter value 255 indicates that the PRB usage is regarded as a mandatory criterion for MLB-oriented UE selection. The parameter value ranging from 1 through 254 indicates that the PRB usage is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and this UE selection criterion has a higher priority. This parameter applies only to LTE FDD and LTE TDD.
UE Select QCI Priority

Indicates the priority of the UEs' QCI as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the QCI is not regarded as a criterion for MLB-oriented UE selection, the parameter value 255 indicates that the QCI is regarded as a mandatory criterion for MLB-oriented UE selection, and the parameter value ranging from 1 to 254 indicates that the QCI is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.
UE Select ARP Priority

Indicates the priority of the UEs' ARP as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the ARP is not regarded as a criterion for MLB-oriented UE selection, the parameter value 255 indicates that the ARP is regarded as a mandatory criterion for MLB-oriented UE selection, and the parameter value ranging from 1 to 254 indicates that the ARP is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.
UE Select DL MCS Priority

Indicates the priority of the UEs' downlink MCS as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the downlink MCS is not regarded as a criterion for MLB-oriented UE selection. The parameter value 255 indicates that the downlink MCS is regarded as a mandatory criterion for MLB-oriented UE selection. The parameter value ranging from 1 to 254 indicates that the downlink MCS is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq MLB UE Select ARP Threshold

Indicates the ARP threshold for selecting UEs to be transferred for MLB. A UE is selected only if the ARPs of all the UE's services is higher than or equal to this threshold. The parameter value 1 indicates the highest priority and the parameter value 15 indicates the lowest priority. If this parameter is set to a large value, UEs with low service priorities are selected to perform MLB. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq MLB UE Select DL MCS Threshold

Indicates the downlink MCS index threshold for selecting UEs to be transferred for MLB. A UE is selected only if the downlink MCS index of the UE is greater than or equal to this threshold. If this parameter is set to a large value, UEs with favorable downlink channel quality are selected for MLB. This parameter applies only to LTE FDD and LTE TDD.
MM Load Steering UE PRB Thld

Indicates the PRB usage threshold for selecting UEs to be transferred after massive MIMO load transfer is triggered for non-massive MIMO cells. If the downlink PRB usage of a UE is greater than or equal to this threshold, the UE can be selected for load steering. This parameter applies only to LTE FDD and LTE TDD.
UL-Exp-oriented Serv Steering UE Sel MCS Thld

Indicates the uplink MCS index threshold for UE selection in uplink-experience-oriented service steering. If this parameter is set to 0, the eNodeB does not consider the uplink MCS index when selecting a UE. If this parameter is set to a value other than 0 and the uplink MCS index of a UE is less than this threshold, the UE is selected as a target UE to be transferred. This parameter applies only to LTE TDD.
NSA DC UE Selection Strategy

Indicates the policy of selecting NSA DC UEs for user-number-based connected mode load equalization and PRB-usage-based connected mode load equalization. If this parameter is set to LTE_NSA_DC_FAIR, NSA DC UEs and LTE UEs are selected at random for load equalization. If this parameter is set to LTE_UE_PREFERRED, UEs not supporting NSA DC and NSA DC UEs are selected for load equalization in descending order of preference. If this parameter is set to NSA_DC_UE_PREFERRED, UEs supporting NSA DC and UEs not supporting NSA DC are selected for load equalization in descending order of preference. This parameter applies only to LTE FDD and LTE TDD.
