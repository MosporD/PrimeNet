CnOperatorQciPara

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-CnOperatorQciPara

Description

A CnOperatorQciPara MO consists of parameters related to the QCI-specific service-based inter-RAT handover policy for an operator.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator
  • Relation with the CnOperator MO:
    • A maximum of 75 CnOperatorQciPara MOs can be configured for each CnOperator MO.
    • CnOperatorQciPara MOs with the Qci parameters set to 1 to 9, 65, 66, 69, 70, 75 and 79 must have been configured.
  • Relation with the ServiceIfHoCfgGroup MO:
    • The ServiceIfHoCfgGroup MO referenced by the ServiceIfHoCfgGroupId parameter in the CnOperatorQciPara MO must be configured.
  • Relation with the ServiceIrHoCfgGroup MO:
    • The ServiceIrHoCfgGroup MO referenced by the ServiceIrHoCfgGroupId parameter in the CnOperatorQciPara MO must be configured.
    • The ServiceIrHoCfgGroup MO referenced by the ServiceHoNrPolicyGroupId parameter in the CnOperatorQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.
QoS Class Indication

Indicates the QoS Class Identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications such as the packet delay budget, packet loss rate (PLR) and packet error rate (PER), and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.
Service-based Inter-RAT Handover Policy Group ID

Indicates the ID of a service-based inter-RAT handover (excluding handover to NR) policy group. This parameter applies only to LTE FDD and LTE TDD.
Service-based Interfreq Handover Policy Group ID

Indicates the ID of a service-based inter-frequency handover policy group. This parameter applies only to LTE FDD and LTE TDD.
Service-based Handover Bearer Policy

Indicates the bearer policy for service-based handovers.

If the ServiceBasedInterFreqHoSwitch, UtranServiceHoSwitch, GeranServiceHoSwitch, CdmaHrpdServiceHoSwitch, Cdma1xRttServiceHoSwitch, or ServiceReqInterFreqHoSwitch option of the HoAlgoSwitch parameter is selected, and a UE fails to be handed over to the target eNodeB, the source eNodeB reads the ServiceHoBearerPolicy parameter value for each QCI of bearers. If this parameter is set to SERVICE_HO_QCI_NOT_ALLOWED(QCI Bear Not Allowed) for a QCI, the eNodeB removes the bearers with this QCI. If this parameter is set to SERVICE_HO_QCI_ALLOWED(QCI Bear Allowed) for a QCI, the eNodeB does not remove the bearers with this QCI.

If the ServiceBasedInterFreqHoSwitch, UtranServiceHoSwitch, GeranServiceHoSwitch, CdmaHrpdServiceHoSwitch, Cdma1xRttServiceHoSwitch, or ServiceReqInterFreqHoSwitch option of the HoAlgoSwitch parameter is selected, and an incoming handover is triggered, the target eNodeB reads the ServiceHoBearerPolicy parameter value for each QCI of bearers. If this parameter is set to SERVICE_HO_QCI_NOT_ALLOWED(QCI Bear Not Allowed), the target eNodeB sends a handover preparation failure message to the source eNodeB and rejects the handover request. If this parameter is set to SERVICE_HO_QCI_ALLOWED(QCI Bear Allowed), the target eNodeB does not reject the handover request. This parameter applies only to LTE TDD.
Local QCI ARP

Indicates the ARP of the QCI configured on the eNodeB. A specific ARP is configured on the eNodeB for each standardized QCI to replace the ARP settings delivered from the EPC. If this parameter is set to 0, the local ARP settings for QCIs do not take effect. This parameter applies only to LTE FDD and LTE TDD.
InterRAT A2 RSRP Threshold Offset

Indicates the offset for inter-RAT event A2 (excluding NG-RAN event A2) relative to the value of the InterRatHoA2ThdRsrp parameter in the InterRatHoCommGroup MO. The RSRP threshold for inter-RAT event A2 is obtained by adding up this offset, the value of the InterRatHoA2ThdRsrp parameter in the InterRatHoCommGroup MO, and the value of the UtranA2ThdRsrpOffset or GeranA2ThdRsrpOffset parameter in the CnOperatorHoCfg MO. If an SpidCfg MO is configured, the SpidCfg.InterRatA2RsrpThldOffset parameter value must also be added. This parameter applies only to LTE FDD and LTE TDD.
Inter-Frequency A2 RSRP Threshold Offset

Indicates the QCI-specific RSRP threshold offset for event A2 related to coverage-based inter-frequency handovers of an operator. If the offset is set to 0, the inter-frequency A2 RSRP threshold is set without distinguishing PLMNs and QCIs. This parameter applies only to LTE FDD and LTE TDD.
Uplink Scheduling Priority Weight Factor

Indicates the weight factor used in the calculation of connection priorities during uplink scheduling. If this parameter is set to 65535, the uplink scheduling weight set for the operator does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Downlink Scheduling Priority Weight Factor

Indicates the weight factor used in the calculation of connection priorities during downlink scheduling. If this parameter is set to 65535, the downlink scheduling weight set for the operator does not take effect. This parameter applies only to LTE FDD and LTE TDD.
QCI Algorithm Switch

Indicates QCI algorithm switches for a specific operator.

EMERGENCY_CALL_UE_ARP_IDENT_SW: Indicates whether this QCI is used for identifying UEs performing emergency calls. If this option is selected, the eNodeB attempts to match the ARP corresponding to this QCI with the ARP for an emergency call. If this option is deselected, this QCI is not used for identifying UEs performing emergency calls. This option applies only to LTE FDD and LTE TDD.
Service-based Handover to NR Policy Group ID

Indicates the ID of a policy group related to service-based handovers to NG-RAN. This parameter applies only to LTE FDD and LTE TDD.
NR A2 RSRP Threshold Offset

Indicates the offset for NG-RAN event A2 relative to the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO. The sum of this offset, the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO, and the value of the NrA2ThldRsrpOffset parameter in the CnOperatorHoCfg MO is taken as the RSRP threshold for NG-RAN event A2. This parameter applies only to LTE FDD and LTE TDD.
