NrExternalCellPlmn

+-NE
  +-eNodeBFunction
    +-NrExternalCell
      +-NrExternalCellPlmn

Description

The NrExternalCellPlmn MO consists of parameters related to the PLMN list information of external NR cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NrExternalCell
  • Relation with the NrExternalCell MO:
    • A maximum of five NrExternalCellPlmn MOs can be configured for each Nr external cell MO.
    • Before adding a NrExternalCellPlmn MO, ensure that the associated NrExternalCell MO has been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NREXTERNALCELLPLMN

Use this command to add an additional PLMN ID for an external NR cell.
LST NREXTERNALCELLPLMN

Use this command to list an additional PLMN ID for an external NR cell.
MOD NREXTERNALCELLPLMN

Use this command to modify the PLMN list of an external NR cell.
RMV NREXTERNALCELLPLMN

Use this command to remove one or more PLMN IDs of an external NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the mobile country code of an external NR cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the mobile network code of an external NR cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
gNodeB ID

Indicates the ID of the gNodeB serving the external NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the cell ID of an external NR cell served by a gNodeB. It uniquely identifies an NR cell in the gNodeB. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.
Shared Mobile Country Code

Indicates the mobile country code of an external NR cell shared among operators.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Shared Mobile Network Code

Indicates the mobile network code of an external NR cell shared among operators.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
NR Networking Option

Indicates the PLMN-specific architecture option of an NR cell that is shared between operators. The value UNLIMITED indicates that the architecture option of the NR cell is not yet determined and is in its initial state in the PLMN. The value SA indicates that the PLMN-specific architecture option of the NR cell is SA. The value NSA indicates that the PLMN-specific architecture option of the NR cell is NSA. The value SA_NSA indicates that the PLMN-specific architecture options of the cell include both SA and NSA. This parameter applies only to LTE FDD and LTE TDD.
Tracking Area Code

Indicates the tracking area code (TAC) of a secondary operator of the external NG-RAN cell. The TAC and the PLMN ID together form a tracking area identifier (TAI). If this parameter is set to the invalid value 4294967295, no operator-specific TAC is configured, and the TAC specified by the NrExternalCell.Tac parameter is used when handovers to the NG-RAN cell are triggered. This parameter is mandatory when operator-specific TACs are planned for the NG-RAN cell. For details, see 3GPP TS 38.300. This parameter applies only to LTE FDD and LTE TDD.
Shared PLMN gNodeB ID

Indicates the ID of base station serving the external NR cell for a RAN sharing operator. The ID uniquely identifies the base station for the operator. The setting of this parameter does not take effect if the NrExternalCellPlmn.SharedPlmnCellId parameter is set to 65535. In this case, the operator does not have an independent gNodeB ID and the NrExternalCellPlmn.GnodebId parameter value is used for the operator. This parameter applies only to LTE FDD and LTE TDD.
Shared PLMN Cell ID

Indicates the ID of the external NR cell for a RAN sharing operator. The ID uniquely identifies the cell for the operator within the base station of the external NR cell. The parameter value 65535 indicates that the operator does not have an independent cell ID. In this case, the NrExternalCellPlmn.CellId parameter value is used for the operator. This parameter applies only to LTE FDD and LTE TDD.
