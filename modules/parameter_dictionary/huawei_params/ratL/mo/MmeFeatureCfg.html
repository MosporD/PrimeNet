MmeFeatureCfg

+-NE
  +-eNodeBFunction
    +-S1Interface

Description

The MmeFeatureCfg MO consists of parameters related to MME feature configurations.

With MDT, operators replace some of the traditional drive tests with measurement reporting by commercial UEs of subscribers or friendly users. In this way, UE measurement results are automatically collected to detect problems and faults in radio networks for network optimization.

Among UEs complying with 3GPP Release 9 or Release 10, some UEs support positioning methods such as Observed Time Difference Of Arrival (OTDOA) and Network-Assisted GPS (A-GPS). According to the current specifications, a positioning procedure is as follows: An MME initiates the procedure, an Evolved Serving Mobile Location Center (E-SMLC) obtains assistance data from the UE and eNodeB using LTE Positioning Protocol (LPP) and LTE Positioning Protocol Annex (LPPa), and finally the E-SMLC derives the location information about the UE from calculation.

The MDT feature includes Huawei-proprietary positioning procedures between eNodeBs and Huawei MMEs. In such a procedure, an eNodeB sends a proprietary message to an MME to initiate network-assisted positioning, and the MME obtains location information from an E-SMLC and then sends the eNodeB a proprietary message containing the location information.

Before the eNodeB sends the positioning request to the MME, the eNodeB must check whether the MME supports Huawei-proprietary positioning procedures.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
S1Interface ID

Indicates the ID of an S1 interface. This parameter applies only to LTE FDD and LTE TDD.
MME supporting MDT or not

Indicates whether the MME at the other end of the S1 interface supports Huawei-proprietary positioning procedures, which are included in minimization of drive tests (MDT). The value DISABLE indicates that the MME does not support the procedures and therefore the eNodeB cannot obtain UE location information from the MME through the procedures. The value ENABLE indicates the opposite. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control mode of the MmeFeatureCfg MO, which determines the control policies of operators and the SON functions in the MmeFeatureCfg MO. For an S1 interface that is manually set up, the parameter is set to MANUAL_MODE in the related MmeFeatureCfg MO. Operators, but not SON functions, can set this MO. For an S1 interface that is automatically set up, the parameter is set to AUTO_MODE in the related MmeFeatureCfg MO. SON functions can modify the configurations of the MO or remove the MO, but operators cannot set this MO directly. Operators can modify the parameter settings in this MO only by modifying the settings of related parameters in the associated S1 MO. This parameter applies only to LTE FDD and LTE TDD.
