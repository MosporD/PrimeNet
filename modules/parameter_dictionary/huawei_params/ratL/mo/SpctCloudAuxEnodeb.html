SpctCloudAuxEnodeb

+-NE
  +-eNodeBFunction
    +-LteNrSpctShrCellGrp
      +-SpctCloudAuxEnodeb

Description

The SpctCloudAuxEnodeb MO consists of parameters related to cell-level spectrum cloudification on an auxiliary base station. The parameters are used to configure cooperating cells served by an auxiliary eNodeB involved in LTE TDD and NR dynamic spectrum sharing.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    LteNrSpctShrCellGrp
  • Relation with the SpectrumCloud, LteNrSpctShrCellGrp, and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the maximum number of cells with the same value of the LteNrSpectrumShrCellGrpId parameter in the SpectrumCloud MO as this cell, including cells with the same value of the LteNrSpectrumShrCellGrpId parameter in the SpctCloudAuxEnodeb MO, is 15.
  • Relation with the eNodeBFunction MO:
    • The value of the EnodebId parameter in a SpctCloudAuxEnodeb MO and the eNodeBId parameter in the eNodeBFunction MO cannot be the same.
  • Relation with the SpctCloudAuxEnodeb MO:
    • A maximum of 96 SpctCloudAuxEnodeb MO instances can be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
LTE and NR Spectrum Sharing Cell Group ID

Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile Country Code

Indicates the MCC of a cell served by an auxiliary base station involved in spectrum sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the MNC of a cell served by an auxiliary base station involved in spectrum sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the ID of an eNodeB serving as an auxiliary eNodeB in spectrum sharing. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the ID of a cell served by an auxiliary base station involved in spectrum sharing. It uniquely identifies a cell within a base station. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
