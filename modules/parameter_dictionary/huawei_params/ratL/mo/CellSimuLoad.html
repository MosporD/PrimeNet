CellSimuLoad

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSimuLoad
        +-SimuloadPmiTemplate[0~16]

Description

The CellSimuLoad MO consists of the parameters related to simulated load configuration of a cell. When there are few UEs accessing the cell or the number of UEs that can access the cell is limited, the load simulation is started to test the DL scheduling. During the test, parameters such as the RB usage and power utilization are monitored to evaluation the effect of DL scheduling.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

  • Possible children:

    SimuloadPmiTemplate[0~16]
  • Relation with the CellAlgoSwitch MO:
    • If BfAlgoSwitch in the CellAlgoSwitch MO is set to Off, SimuLoadTransMode in the CellSimuLoad MO cannot be set to TM7 or TM8.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, SimuLoadTransMode in the related CellSimuLoad MO must be set to TM4.
  • Relation with the Cell MO:
    • If TxRxMode in a Cell MO is set to 1T1R or 1T2R, SimuLoadTransMode in a CellSimuLoad MO under this Cell MO must be set to TM1.
    • Consider that MultiRruCellMode in a Cell MO is not set to CELL_COMBINATION or MPRU_AGGREGATION. If CrsPortNum in the Cell MO is set to CRS_PORT_1, SimuLoadTransMode in a CellSimuLoad MO under this Cell MO cannot be set to TM4.
    • If FddTddInd in a Cell MO is set to CELL_TDD and MultiRruCellMode in the same Cell MO is set to CELL_COMBINATION or MPRU_AGGREGATION and the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, SimuLoadTransMode in the CellSimuLoad MO cannot be set to TM4 or TM9.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • Consider that MultiRruCellMode in a Cell MO is not set to CELL_COMBINATION or MPRU_AGGREGATION. If the TM9Switch option of EnhMIMOSwitch in the CellAlgoSwitch MO under this Cell MO is deselected, SimuLoadTransMode in a CellSimuLoad MO under this Cell MO cannot be set to TM9.
  • Relation with the Cell and SimuloadPmiTemplate MOs:
    • Consider that SimuLoadTransMode in a CellSimuLoad MO is set to TM9. If TxRxMode in the corresponding Cell MO is set to 2T2R, 2T4R, or 2T8R, CellSimuloadPmi in a SimuloadPmiTemplate MO under this CellSimuLoad MO must be set to a value in the range of 0 to 3.
    • If SimuLoadTransMode in a CellSimuLoad MO is set to TM4 and CrsPortNum in the related Cell MO is set to CRS_PORT_2, CellSimuloadPmi in associated SimuloadPmiTemplate MOs must be set to a value ranging from 0 to 3.
  • Relation with the SimuloadPmiTemplate MO:
    • If SimuLoadTransMode in a CellSimuLoad MO is set to TM4 or TM9, a maximum of 16 SimuloadPmiTemplate MOs can be configured under this CellSimuLoad MO.
    • If SimuLoadTransMode in a CellSimuLoad MO is not set to TM4 or TM9, no SimuloadPmiTemplate MOs can be configured under this CellSimuLoad MO.
  • Relation with the SymbolPwrSaving MO:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell, the number of CellSimuLoad MO instances in the same Cell must be 0

Function

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.
Configure Index

Indicates the index of a simulated load configuration. One eNodeB can store a maximum of 10 simulated load configurations. They are identified by indexes ranging from 0 to 9 and correspond to RB usage thresholds (specified by the SimuLoadRbThd parameter) 10% to 100% at a step of 10%. For example, the RB usage thresholds for simulated load configurations 1 and 4 are 20% and 50%, respectively. Alternatively, you can also manually specify the RB usage threshold for a simulated load configuration by setting the SimuLoadRbThd parameter.
SimuLoad transmission mode

Indicates the transmission mode adopted by the simulated load configuration, including:

TM1: indicates transmission mode 1 for the simulated load configuration.

TM2: indicates transmission mode 2 for the simulated load configuration.

TM4: indicates transmission mode 4 for the simulated load configuration.

TM7: indicates transmission mode 7 for the simulated load configuration.

TM8: indicates transmission mode 8 for the simulated load configuration.

TM9: indicates transmission mode 9 for the simulated load configuration.

Load simulation for TM4 and TM9 is used in 4T/8T MIMO cells to simulate interference for 4T/8T transmissions.
Cell Simuload Automatic Remove Time

Indicates the period of time exceeding which the cell simulated load is automatically removed. After this parameter value is changed, the time for automatically removing the cell simulated load restarts. If this parameter is changed to a value the same as the previous value of this parameter, the time does not restart. If this parameter is set to 0, the cell simulated load will not be automatically removed.
Table 3 Dynamic parameters

Parameter

Description
SimuLoad allocated RB Number

Indicates the number of RBs allocated to a simulated load configuration in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
Commercial service RB number

Indicates the number of RBs allocated for commercial services in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
SimuLoad allocated power

Indicates the power allocated to a simulated load configuration in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
Commercial service power

Indicates the power allocated for commercial services in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
SimuLoad allocated user Number

Indicates the number of UEs allocated for a simulated load configuration in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
Commercial service user number

Indicates the number of users to be scheduled in each transmission time interval (TTI) in downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.
Cell Simuload Automatic Remove Remain Time

Indicates the remaining time before the cell simulated load is automatically removed.
