EutranInterNFreq

+-NE
  +-eNodeBFunction
    +-Cell
      +-EutranInterNFreq
        +-EutranNFreqRanShare[0~6]
        +-EutranNFreqSCellOp[0~6]

Description

An EutranInterNFreq MO consists of the common parameters related to a neighboring E-UTRAN frequency. The parameters include the frequency priority for cell reselection and the measurement bandwidth. They are used in measurement control for reselection to inter-frequency neighboring cells. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

    Cell

    • If CellReselPriorityCfgInd in EutranInterNFreq MO and UtranNFreq MO is both set to CFG, CellReselPriority cannot be set to a same value for each cell.

  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to FALSE, DlEarfcn in a Cell MO must be different from that in each associated EutranInterNFreq MO.
    • If NbCellFlag in a Cell MO is set to TRUE, MeasBandWidth in an EutranInterNFreq MO associated with this Cell MO must be set to MBW6(1.4M).
    • A maximum of eight EutranInterNFreq MOs can be configured for each Nb-IoT cell.
    • A maximum of sixteen EutranInterNFreq MOs can be configured for each cell.
    • If the NbCellFlag parameter in a Cell MO is set to FALSE, the QRxLevMin parameter in the EutranInterNFreq MOs whose LocalCellId is corresponding to this Cell MO must be set to a value in the range of -70 to -22.

    • DlEarfcn in the EutranExternalCell MO corresponding to an inter-eNodeB EutranInterFreqNCell MO must be the same as DlEarfcn in an EutranInterNFreq MO.
    • In inter-eNodeB scenarios, the value of DlEarfcn in the EutranExternalCell MO associated with an EutranInterFreqNCell MO of a Cell MO must be the same as one of the values of DlEarfcn in the EutranInterNFreq MOs associated with this Cell MO and the values of DlFreqOffset and DlFreqOffset must be the same.
  • Relation with the Cell and Prb MOs:
    • If NbCellFlag in a Cell MO is set to TRUE and an EutranInterNFreq MO is to be added for this Cell MO, a Prb MO whose AnchorCarrierFlag is TRUE must be added first for this Cell MO.
    • If the NbCellFlag in the Cell MO is set to TRUE, the DlEarfcn in the EutranInterNFreq MO for this local cell cannot be the same as the DlEarfcn in the Prb whose AnchorCarrierFlag is set to TRUE when the LteDlRbIndex is set to an invalid value, or the downlink frequency point calculated based on the DlEarfcn and DlBandWidth in the Cell MO corresponding to LteDlRbIndex.
  • Relation with the EutranInterFreqNCell and Cell MOs:
    • DlEarfcn in the Cell MO corresponding to an intra-eNodeB EutranInterFreqNCell MO must be the same as DlEarfcn in an EutranInterNFreq MO.

  • Relation with the Cdma2000BandClass MO:
    • If CellReselPriorityCfgInd in EutranInterNFreq MO is set to CFG, and if Cdma20001XrttCellReselInd in Cdma2000BandClass MO is set to CFG, Cdma20001XrttCellReselPri in Cdma2000BandClass MO cannot be set same as CellReselPriority in EutranInterNFreq MO for each cell, and if Cdma2000HrpdCellReselInd in Cdma2000BandClass MO is set to CFG, Cdma2000HrpdCellReselPri in Cdma2000BandClass MO cannot be set same as CellReselPriority in EutranInterNFreq MO for each cell.

  • Relation with the EutranInterNFreq MO:
    • If downlink carrier frequencies calculated based on DlEarfcn in EutranInterNFreq MOs under a Cell MO are the same, MasterBandFlag in at most one of the EutranInterNFreq MOs can be set to TRUE.
  • Relation with the EutranBlkNCell and Cell MOs:
    • In intra-eNodeB scenarios, the value of DlEarfcn in the Cell MO under which an EutranBlkNCell MO is configured must be the same as the value of either DlEarfcn in this Cell MO or DlEarfcn in the related EutranInterNFreq MO.
  • Relation with the EutranBlkNCell, EutranExternalCell, and Cell MOs:
    • In inter-eNodeB scenarios, the value of DlEarfcn in the EutranExternalCell MO associated with an EutranBlkNCell MO must be the same as the value of either DlEarfcn in the corresponding Cell MO or DlEarfcn in the EutranInterNFreq MO.
  • Relation with the CellMLB MO:
    • The sum of values of InterFreqMlbThd in the CellMLB MO and InterFreqMlbDlPrbOffset in the EutranInterNFreq MO must be less than or equal to 100.
    • The sum of values of InterFreqMlbUlThd in the CellMLB MO and InterFreqMlbUlPrbOffset in the EutranInterNFreq MO must be less than or equal to 100.
  • Relation with the Cell and UtranNFreq MOs:
    • MlbFreqUlPriority in the EutranInterNFreq MO associated with this Cell MO cannot be set to the same value as MlbFreqPriority in the UtranNFreq MO associated with this Cell MO.

    • A maximum of eight EutranInterNFreq MOs can be configured for a Cell MO when the eNodeB is equipped with only the LMPT.
  • Relation with the NrNFreq and CellReselToNr MOs:
    • If CellReselPriorityCfgInd in EutranInterNFreq MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the ServiceIfHoCfgGroup and ServiceIfDlEarfcnGrp MOs:
    • DlEarfcn must have been set in the associated EutranInterNFreq MO when the ServiceIfDlEarfcnGrp MO associated ServiceIfHoCfgGroup's InterFreqHoState is PERMIT_HO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of a local cell. It uniquely identifies a cell within an eNodeB.
Downlink EARFCN

Indicates the DL EARFCN of the neighboring cell on the neighboring E-UTRAN frequency. For details, see the 3GPP TS 36.104.
Uplink EARFCN configure indicator

Indicates whether to configure the uplink E-UTRA absolute radio frequency channel number (EARFCN) for the inter-frequency neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Uplink EARFCN

Indicates the uplink E-UTRA absolute radio frequency channel number (EARFCN) of the inter-frequency neighboring cell. If the value of this parameter is not specified, the default uplink EARFCN is used, which is calculated based on the downlink EARFCN. For details about this parameter, see 3GPP TS 36.104. This parameter applies only to LTE FDD and LTE TDD.
Inter frequency cell resel priority configure indicator

Indicates whether to set the reselection priority of the neighboring E-UTRAN frequency. For details about how UEs process frequency priorities during cell reselection, see section 5.2.4.1 of 3GPP TS 36.304 (V12.4.0). This parameter applies only to LTE FDD and LTE TDD.
Inter frequency cell resel priority

Indicates the cell reselection priority of the neighboring E-UTRAN frequency. The value 0 indicates the lowest priority. It is contained in SIB5. A UE determines whether to reselect to a neighboring cell on the frequency based on the value of this parameter and the absolute priority of the serving cell.

If the priority specified by this parameter is higher than the priority of the serving cell, the UE starts measuring neighboring cells on the frequency. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection.

If the priority specified by this parameter is lower than or equal to the priority of the serving cell, the UE starts the measurements only when the signal quality of the serving cell is poor. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection. Cell reselection priorities in different RATs cannot be the same. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
EUTRAN reselection time

Indicates the evaluation duration for a UE to determine whether to reselect the inter-frequency neighboring cell to camp on. If the signal quality in an inter-frequency neighboring cell is better than that in the serving cell for the period specified by this parameter and a UE camps on the serving cell for more than 1s, the UE attempts to reselect the inter-frequency neighboring cell to camp on. This parameter is contained in SIB5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Speed dependent resel parameter configuring indicator

Indicates whether to set the speed-dependent scaling parameters related to cell reselection.

If this parameter is set to NOT_CFG, speed-dependent cell reselections are not supported by default. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of treseleutran in medium mobility state

Indicates the scaling factor applied to the cell reselection duration for medium-mobility UEs. This parameter is delivered in SIB5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of treseleutran in high mobility state

Indicates the scaling factor applied to the cell reselection duration for high-mobility UEs. This parameter is delivered in SIB5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Measurement bandwidth

Indicates the measurement bandwidth of the inter-frequency neighboring cell on the frequency. The setting of this parameter depends on the bandwidth configuration of the cell. In E-UTRAN, a cell bandwidth is also expressed in units of resource blocks (RBs). Cell bandwidths 1.4 MHz, 3 MHz, 5 MHz, 10 MHz, 15 MHz, and 20 MHz correspond to 6 RBs, 15 RBs, 25 RBs, 50 RBs, 75 RBs, and 100 RBs, respectively. For details, see 3GPP TS 36.331. This parameter does not take effect for NB-IoT cells and it must be set to a fixed value of MBW6(1.4M) for NB-IoT cells. This parameter applies only to LTE FDD and LTE TDD.
Frequency offset

Indicates the frequency-specific offset for the neighboring E-UTRAN frequency that applies to UEs in idle mode. It is contained in system information block type 5 (SIB5) and delivered to UEs in idle mode for cell reselection. For details, see 3GPP TS 36.331.
Inter frequency high priority threshold

Indicates the minimum RX level required for a neighboring cell on the neighboring frequency to become a candidate for cell reselection if the cell reselection priority of the neighboring frequency is higher than that of the serving frequency.

After measurements are started for cells on the target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter for a period of time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Inter frequency lower priority threshold

Indicates the minimum RX level required for a neighboring cell on the frequency to become a candidate for reselection if the priority of the frequency is lower than that of the serving frequency.

After measurements are started for neighboring cells on the frequency, the UE reselects to a neighboring cell on the frequency only if the RX level of the serving cell is lower than the ThrshServLow parameter value and that of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Minimum required RX level

Indicates the minimum receive level required for an inter-frequency E-UTRAN cell to become a candidate for cell selection. The level is included in S criteria and used in the evaluation of cell selection. During the evaluation for cell reselection, the UE performs the following calculation: Srxlev = Measured RSRP value of a cell on the neighboring frequency - Value of this parameter - Compensated power. If Srxlev for a cell is better than a threshold for a time-to-trigger, reselection to the cell is started. The value range of this parameter is -70 to -22 for LTE FDD and TDD, and -78 to -22 for LTE NB-IoT. For details, see 3GPP TS 36.304.
PMAX configure indicator

Indicates whether to set the maximum power that the UE can apply to transmission on the neighboring E-UTRAN frequency. If the value of this parameter is not specified, the maximum power is subject to the UE capability.
PMAX

Indicates the maximum power that the UE can apply to transmission on the neighboring E-UTRAN frequency. It is used in cell reselection criteria to calculate the compensated power. If the value of this parameter is not specified, the maximum power is subject to the UE capability. For details, see 3GPP TS 36.304.
Neighbor Cell Configuration

Indicates the inter-frequency neighboring cell configuration of the local cell.

The value BitString00 indicates that some inter-frequency neighboring cells have the same MBSFN subframe configuration as the local cell.

The value BitString01 indicates that none of the inter-frequency neighboring cells is configured with MBSFN subframes.

The value BitString10 indicates that the MBSFN subframe configurations of all neighboring cells are the same as or subsets of that of the local cell.

The value BitString11 indicates that some inter-frequency neighboring cells have different UL-DL subframe configurations from the local TDD cell.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Presence antenna port1

Indicates whether all inter-frequency neighboring cells on this frequency are configured with at least two antenna ports.

Set this parameter to BOOLEAN_TRUE if all inter-frequency neighboring cells on this frequency are configured with at least two antenna ports.

Set this parameter to BOOLEAN_FALSE if one inter-frequency neighboring cell on this frequency is configured with only one antenna port. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq HO trigger Event Type

Indicates the event to trigger coverage-based inter-frequency handovers. This parameter can be set to EventA3, EventA4, or EventA5. This parameter applies only to LTE FDD and LTE TDD.
Inter frequency high priority RSRQ threshold

Indicates the RSRQ-based minimum RX level required for a neighboring cell on the frequency to become a candidate for reselection if the RSRQ-based priority of the frequency is higher than that of the serving frequency.

After measurements are started for neighboring cells on the neighboring E-UTRAN frequency, the UE reselects to a neighboring cell on the frequency only if the RSRQ-based RX level of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Inter frequency low priority RSRQ threshold

Indicates the RSRQ-based minimum RX level required for a neighboring cell on the frequency to become a candidate for reselection if the RSRQ-based priority of the frequency is lower than that of the serving frequency.

After measurements are started for neighboring cells on a frequency, the UE reselects to a neighboring cell on the frequency only if the RSRQ-based RX level of the serving cell is lower than a specified threshold and that of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Minimum RX signal quality configuration indicator

Indicates whether to set the minimum required RX level.
Minimum RX signal quality

Indicates the minimum RX level of an inter-frequency neighboring cell, which is required for it to become a candidate for cell reselection. It determines the probability of triggering cell reselection to inter-frequency neighboring cells on the frequency. The value of this parameter is contained in SIB5. For details, see 3GPP TS 36.331.
Frequency Priority for Connected Mode

Indicates the frequency priority based on which the eNodeB selects a target frequency for blind redirection or contains a frequency in a measurement configuration. If a blind redirection is triggered and the target neighboring cell is not specified, the eNodeB selects a target frequency based on this priority. If a measurement configuration is to be delivered, the eNodeB preferentially delivers a frequency with the highest priority. If this parameter is set to 0 for a frequency, this frequency has the lowest priority for measurements and can be selected as a measurement target; however, this frequency cannot be selected as the target frequency for a blind redirection. A larger value indicates a higher priority. This parameter applies only to LTE FDD and LTE TDD.
Mobility Load Balancing Target Indicator

Indicates whether the neighboring E-UTRAN frequency can be a target frequency for MLB. The value ALLOWED indicates that the neighboring E-UTRAN frequency can be a target frequency for MLB. The value NOT_ALLOWED indicates that the neighboring E-UTRAN frequency cannot be a target frequency for MLB. The value ALLOWED_WITHOUT_IDLE_MLB indicates that the neighboring E-UTRAN frequency cannot be a target frequency for user-number-based MLB to transfer RRC_REL UEs. The value ALLOWED_WITHOUT_CONNECT_MLB indicates that the neighboring E-UTRAN frequency cannot be a target frequency for user-number-based MLB to transfer uplink-synchronized UEs. This parameter applies only to LTE FDD and LTE TDD.
Frequency Priority Based Ho Measure Flag

Indicates whether to enable or disable measurement for frequency-priority-based inter-frequency handovers to neighboring frequencies. In frequency-priority-based handovers, if the eNodeB delivers frequencies to be measured based on frequency configuration, the frequencies with the FreqPriBasedHoMeasFlag parameter set to ENABLE can be measured, and the frequencies with the FreqPriBasedHoMeasFlag parameter set to DISABLE cannot be measured. This parameter applies only to LTE FDD and LTE TDD.
Idle MLB UE Release Ratio

Indicates the preset proportion of UEs in idle mode on the neighboring frequency. This parameter takes effect when both the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter and the Proportion option of the InterFreqIdleMlbMode parameter in the CellMLB MO are selected. The eNodeB transfers normally released UEs to frequencies based on the preset proportions, so that UEs in idle mode reach the expected proportion on each frequency. The sum of UE proportions among all frequencies cannot exceed 100%. UE proportion for the serving frequency = 100% - (UE proportion for frequency 1 + UE proportion for frequency 2 + … + UE proportion for frequency n). If the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the proportions are the expected UE proportions for the frequencies involved. The eNodeB adaptively adjusts the proportions of UEs in idle mode among frequencies based on UE distribution in the network, ensuring that the proportions of UEs in idle mode among frequencies approach the preset proportions.
MLB Frequency Priority

Indicates the priority of the neighboring E-UTRAN frequency for MLB. The value 0 indicates the lowest priority. The eNodeB selects a high-priority frequency as the target frequency for MLB. For LTE TDD, if the eNodeB performs MLB that distinguishes between the uplink and downlink transmission directions, the parameter indicates the downlink priority of the neighboring E-UTRAN frequency for MLB. The value 0 indicates the lowest priority. The eNodeB selects a downlink high-priority frequency as the target frequency for MLB in the downlink. This parameter applies only to LTE FDD and LTE TDD.
Downlink Frequency Offset

Indicates the frequency offset of the PRB downlink central frequency to the downlink frequency. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.
Uplink Frequency Offset

Indicates the frequency offset of the PRB uplink central frequency to the uplink frequency. This parameter takes effect only when UlEarfcnCfgInd is set to CFG(Configure). Otherwise, the offset is calculated based on the uplink/downlink symmetric system. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.
Frequency Offset for Connected Mode

Indicates the frequency-specific offset for the neighboring E-UTRAN frequency that applies to UEs in connected mode. It is contained in the event A3/A4/A5 measurement configuration and delivered to UEs in connected mode. The offset affects the probability of reporting events A3, A4, and A5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Measurement Frequency Priority

Indicates the frequency measurement priority. A larger value indicates a higher priority. If the CovBasedInterfreqHoMode parameter is set to BASEDONSIGNALSTRENGTH or BASEDONFREQPRIORITY or the FixedMeasObjIDSwitch option of the MultiFreqPriControlSwitch parameter is selected, the eNodeB delivers frequencies for measurement based on the priority specified by this parameter in inter-frequency handovers except service- and service-request-based inter-frequency handovers. If this parameter is set to 0, the measurement priority of the neighboring E-UTRA frequency is the lowest and this frequency can still be delivered for measurement. This parameter applies only to LTE FDD and LTE TDD.
Cov-based Inter-Freq HO Thd RSRP Offset

Indicates the offset to the RSRP threshold for events A4 and A5 that trigger coverage-based inter-frequency handovers. In coverage-based handovers, the eNodeB delivers the RSRP threshold for event A4 or A5 to UEs, which is equal to the sum of the InterFreqHoA4ThdRsrp and IfHoThdRsrpOffset parameter values. If the RSRP threshold for event A4 or A5 is less than the minimum RSRP value, the minimum value is delivered instead. If the RSRP threshold for event A4 or A5 is greater than the maximum RSRP value, the maximum value is delivered instead. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq Mlb Threshold RSRP Offset

Indicates the offset to the RSRP threshold related to load-based inter-frequency handovers. In load-based inter-frequency handovers, the RSRP threshold for event A4 or A5 that the eNodeB delivers is equal to the sum of the RSRP threshold for event A4 (specified by the InterFreqLoadBasedHoA4ThdRsrp parameter in the InterFreqHoGroup MO or the MmLoadSteeringA4ThldRsrp parameter in the InterFreqHoGroupMO) and this offset. If the RSRP threshold for event A4 or A5 with the offset added is less than the minimum RSRP value, the minimum value is delivered instead. If the RSRP threshold for event A4 or A5 with the offset added is greater than the maximum RSRP value, the maximum value is delivered instead. This parameter applies only to LTE FDD and LTE TDD.
Master Band Flag

Indicates whether the EARFCN is specific to the primary frequency band. Among the EARFCNs of the same frequency, if the MasterBandFlag parameter is set to TRUE for one EARFCN and FALSE for other EARFCNs, the former EARFCN is specific to the primary frequency band while the latter EARFCNs are specific to secondary frequency bands. In this case, only the EARFCN specific to the primary frequency band is broadcast in system information block type 5 (SIB5). If the MasterBandFlag parameter is set to FALSE for all EARFCNs of the same frequency, only the smallest EARFCN is broadcast in SIB5.
Inter Frequency RAN Sharing Indication

Indicates whether an intra-RAT inter-frequency neighboring cell is a shared neighboring cell. If this parameter is set to BOOLEAN_TRUE, the neighboring E-UTRAN frequency is a shared frequency, and the shared operator information must be checked on the OSS before all inter-frequency neighboring cells are added. If this parameter is set to BOOLEAN_FALSE, the neighboring E-UTRAN frequency is not a shared frequency, and the shared operator information does not need to be checked on the OSS before all inter-frequency neighboring cells are added. This parameter applies only to LTE FDD and LTE TDD.
Inter-frequency Highspeed Flag

Indicates whether the inter-frequency cells on the frequency are low-speed, high-speed, ultra-high-speed, or extra-high-speed cells. This parameter indicates the handover direction when high- or low-speed handover algorithm is enabled for high-speed railway UEs. This parameter applies only to LTE FDD and LTE TDD. This parameter can be set only to LOW_SPEED(LOW_SPEED) or HIGH_SPEED(HIGH_SPEED) for LTE TDD cells.
ANR Indication

Indicates whether information about inter-frequency neighboring cells on the neighboring E-UTRA frequency can be maintained by ANR. If this parameter is set to ALLOWED, the information can be maintained by ANR. If this parameter is set to NOT_ALLOWED, the information cannot be maintained by ANR. This parameter applies only to LTE FDD and LTE TDD.
Voip Priority

Indicates the frequency priority of providing VoIP services on the intra-RAT neighboring frequency. A larger value of this parameter indicates a higher priority. During coverage-based inter-frequency handovers of UEs with voice bearers, if the VoIP directional handover function takes effect, the eNodeB selects and delivers the neighboring frequencies based on the frequency priorities when starting measurements. The eNodeB preferentially delivers the non-serving E-UTRA frequency with the highest VoIP priorities. If this parameter is set to 0, this neighboring frequency is not prioritized. If the VoipMeasFreqPriSwitch option of the CellAlgoSwitch.MultiFreqPriControlSwitch parameter is selected and the HO_USE_VOIP_FREQ_ALLOWED option of the CellQciPara.QciAlgoSwitch parameter is selected, the VoIP directional handover function takes effect. This parameter applies only to LTE FDD and LTE TDD.
PS Service Priority

Indicates the priority of a neighboring E-UTRAN frequency for carrying PS services. A large value indicates a high priority. If PsMeasFreqPriSwitch is on, the eNodeB preferentially selects the neighboring E-UTRAN frequency with the highest PS service priority for measurement during a coverage-based inter-frequency handover procedure. If PsPriority is set to 0 for a frequency, this frequency is not prioritized. This parameter applies only to LTE FDD and LTE TDD.
VoLTE HO Target Frequency Indication

This parameter specifies whether the neighboring E-UTRAN frequency can be a target frequency for VoLTE UEs in handovers. If this parameter is set to ALLOWED, the neighboring E-UTRAN frequency can be a target frequency for VoLTE UEs in handovers. If this parameter is set to NOT_ALLOWED, the neighboring E-UTRAN frequency cannot be a target frequency for VoLTE UEs in handovers. This parameter applies only to LTE FDD and LTE TDD.
Backoff Target Indicator

Indicates whether a neighboring E-UTRA frequency can be selected as the target frequency for backoff MLB. If this parameter is set to ALLOWED(ALLOWED), the neighboring frequency can be selected as the target frequency for backoff MLB. If this parameter is set to NOT_ALLOWED(NOT_ALLOWED), the neighboring frequency cannot be selected as the target frequency for backoff MLB. This parameter applies only to LTE TDD.
MLB Inter-Freq Handover Event Type

Indicates the event type used to trigger MLB-based inter-frequency handovers. The handovers can be triggered based on event A3, event A4, or event A5. Event A3 only applies to LTE TDD. If an inter-frequency neighboring cell and the serving cell are served by the same eNodeB, you are advised to set this parameter to EventA4(EventA4); otherwise, you are advised to set this parameter to EventA3(EventA3) or EventA5(EventA5). This parameter applies only to LTE FDD and LTE TDD.
Mobility Target Indicator

Indicates whether the frequency can be selected as the target frequency for mobility.

SpeedMobilityTargetInd: If both this option and the InterFreqSpeedHoSwitch option are selected, the frequency can be selected as a target frequency for speed-based inter-frequency handovers. If this option is deselected, the frequency cannot be selected as a target frequency for speed-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

LcsMobilityTargetInd: If both this option and the InterFreqLcsHoSwitch option are selected, the frequency can be selected as a target frequency for location-based inter-frequency handovers. If this option is deselected, the frequency cannot be selected as a target frequency for location-based inter-frequency handovers. This option applies only to LTE FDD and LTE TDD.

InterFreqHoCqiInd: If this option is selected, the frequency can be selected as a target frequency for CQI-based inter-frequency handovers. If this option is deselected, the frequency cannot be selected as a target frequency for CQI-based inter-frequency handovers. This option applies only to LTE FDD.

AbnReestUeInterFreqHoTargetInd: If this option is selected, this frequency can be selected as a target frequency for inter-frequency handovers of UEs that experience abnormal RRC connection reestablishments. If this option is deselected, this frequency cannot be selected as a target frequency for inter-frequency handovers of these UEs.
MLB Inter-Freq Efficiency Ratio

Indicates the ratio of spectral efficiency of the local cell to that of a neighboring cell. If PRB-usage-based MLB is triggered in the local cell, the eNodeB considers the ratio of spectral efficiency of the local cell to that of a neighboring cell when determining load differences between the local and neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
SNR Based UE Selection Mode

Indicates the SNR-based UE selection mode during MLB. If this parameter is set to Random(Random), UEs are selected without considering the SNR. If this parameter is set to Best(Best), UEs with good SNRs are preferentially transferred. If this parameter is set to Worst(Worst), UEs with poor SNRs are preferentially transferred. This parameter takes effect only if FreqSelectStrategy is set to FAIRSTRATEGY(FairStrategy) and the UE-number-based inter-frequency MLB algorithm is operating. This parameter applies only to LTE FDD and LTE TDD.
UL Traffic MLB Target Indicator

Indicates whether the neighboring E-UTRAN frequency can be selected as a target frequency for uplink-traffic-based MLB. If this parameter is set to ALLOWED, this frequency can be selected as the target frequency. If this parameter is set to NOT_ALLOWED, this frequency cannot be selected as the target frequency. This parameter applies only to LTE TDD.
UL Traffic MLB Priority

Indicates the priority of the neighboring E-UTRAN frequency to be selected as a target frequency for uplink traffic-based MLB. The value 0 indicates the lowest priority. The eNodeB selects a high-priority frequency as the target frequency for uplink traffic-based MLB. This parameter applies only to LTE TDD.
MLB Inter-Freq Handover A3 Offset

Indicates the offset of signal quality of a neighboring cell to that of the serving cell. This parameter is used to trigger event A3-based handovers for inter-frequency MLB. A larger value of this parameter indicates that better signal quality of the neighboring cells is required to trigger a handover for event A3-based inter-frequency MLB. For details, see 3GPP TS 36.331. This parameter applies only to TDD.
Inter-Freq Service HO Thd RSRP Offset

Indicates the offset to the RSRP threshold for triggering service-based inter-frequency handovers. In service-based inter-frequency handovers, the eNodeB delivers the RSRP threshold for event A4 or A5 to UEs, which is equal to the sum of the InterFreqLoadBasedHoA4ThdRsrp and IfSrvHoThdRsrpOffset parameter values. In service-request-based inter-frequency handovers, the eNodeB delivers the RSRP threshold for event A4 or A5 to UEs, which is equal to the sum of the SrvReqHoA4ThdRsrp and IfSrvHoThdRsrpOffset parameter values. If the RSRP threshold for event A4 or A5 is less than the minimum RSRP value, the minimum value is delivered instead. If the RSRP threshold for event A4 or A5 is greater than the maximum RSRP value, the maximum value is delivered instead. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq Service HO Thd RSRQ Offset

Indicates the offset of the RSRQ threshold for triggering service-based inter-frequency handovers. In service-based inter-frequency handovers, the eNodeB delivers the RSRQ threshold for event A4 or A5 to UEs, which is equal to the sum of the InterFreqLoadBasedHoA4ThdRsrq and IfSrvHoThdRsrqOffset parameter values. In service-request-based inter-frequency handovers, the eNodeB delivers the RSRQ threshold for event A4 or A5 to UEs, which is equal to the sum of the SrvReqHoA4ThdRsrq and IfSrvHoThdRsrqOffset parameter values. If the RSRQ threshold for event A4 or A5 is less than the minimum RSRQ value, the minimum value is delivered instead. If the RSRQ threshold for event A4 or A5 is greater than the maximum RSRQ value, the maximum value is delivered instead. This parameter applies only to LTE FDD and LTE TDD.
MLB Frequency UL Priority

Indicates the priority of a neighboring frequency in the uplink for inter-frequency MLB. The value 0 indicates the lowest priority. The eNodeB selects a high-priority frequency in the uplink preferentially as the target frequency for uplink MLB. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq MLB DL PRB Usage Offset

Indicates the offset relative to the downlink PRB usage threshold used to trigger load transfer to inter-frequency neighboring cells on the neighboring frequency for MLB. If the MlbTriggerMode parameter is set to PRB_ONLY or PRB_OR_UE_NUMBER and the PrbLoadCalcMethod parameter is set to PRB_USAGE, among all the neighboring cells working on the frequency, only those that have load information exchange with the local cell can be selected as target cells for downlink load transfer on condition that the downlink PRB usage of the cell is greater than the sum of the values of the InterFreqMlbThd and InterFreqMlbDlPrbOffset parameters. The neighboring cells that work on the frequency and have no load information exchange with the local cell can be selected as target cells for downlink offload only when downlink PRB usage of the cell is greater than or equal to the sum of the values of the InterFreqMlbThd, InterFreqOffloadOffset, and InterFreqMlbDlPrbOffset parameters. This parameter applies only to LTE FDD and LTE TDD.

Indicates the offset relative to the uplink PRB usage threshold used to trigger load transfer to inter-frequency neighboring cells on the neighboring frequency for MLB. If the InterFreqMlbThd parameter is set to PRB_ONLY or PRB_OR_UE_NUMBER, among all the neighboring cells working on the frequency, only those that have load information exchange with the local cell can be selected as target cells for load transfer on condition that the uplink PRB usage of the cell is greater than the sum of the InterFreqMlbUlThd and the InterFreqMlbUlPrbOffset parameter values. The neighboring cells that work on the frequency and have no load information exchange with the local cell can be selected as target cells for uplink offload only when uplink PRB usage of the cell is greater than or equal to the sum of the InterFreqMlbUlThd, InterFreqOffloadOffset, and InterFreqMlbUlPrbOffset parameter values. This parameter applies only to LTE FDD and LTE TDD.
Neighbouring Cell Number for ANR

Indicates the minimum number of neighboring cells on the neighboring E-UTRAN frequency. The value 0 indicates that the minimum number of neighboring cells on the specified frequency is not restricted. This parameter applies only to LTE FDD and LTE TDD.
Measurement Performance Demand

Indicates the measurement performance demand for whether to broadcast the frequency in SIB5. If this parameter is set to NORMAL, the frequency is broadcast in interFreqCarrierFreqList without carrying the IE reducedMeasPerformance. The measurement performance of a UE is normal when the UE measures the frequency. If this parameter is set to REDUCED, the frequency is broadcast in interFreqCarrierFreqListExt carrying the IE reducedMeasPerformance. The measurement performance of a UE supporting extended frequency measurement can be reduced to measure the frequency. If this parameter is set to UNDELIVER, the frequency is not broadcast in SIB5. This parameter value applies only to LTE FDD. For details about the IE reducedMeasPerformance, see 3GPP TS 36.331.
Inter-Freq Backoff Threshold RSRP Offset

To trigger handovers for inter-frequency backoff MLB, the eNodeB delivers the RSRP threshold for event A4 or A5 to UEs, which equals the sum of this offset and the InterFreqLoadBasedHoA4ThdRsrp parameter value in the InterFreqHoGroup MO. If the RSRP threshold for event A4 or A5 is greater than the maximum RSRP value, the maximum value is delivered as the RSRP threshold for event A4 or A5. This parameter applies only to LTE TDD.
Inter-Freq Backoff Threshold RSRQ Offset

Indicates the offset to the RSRQ threshold for triggering handovers for inter-frequency backoff MLB. To trigger handovers for inter-frequency backoff MLB, the eNodeB delivers the RSRQ threshold for event A4 or A5 to UEs, which equals the sum of this offset and the InterFreqLoadBasedHoA4ThdRsrq parameter value in the InterFreqHoGroup MO. Idle eMTC UE Release Ratio for MLB

Indicates the proportion of eMTC UEs in RRC_IDLE state transferred to different frequencies for MLB. This parameter takes effect when both the InterFreqIdleMlbSwitch option of the MlbAlgoSwitch parameter and the eMtcProportion option of the InterFreqIdleMlbMode parameter are selected. The eNodeB transfers normally released eMTC UEs to frequencies based on the preset proportions, so that RRC_IDLE eMTC UEs reach the expected proportion on each frequency. The sum of frequency-specific proportions cannot exceed 100%.

Proportion on the serving frequency = 100% - (Proportion of RRC_IDLE eMTC UEs transferred to frequency 1 for MLB + Proportion of RRC_IDLE eMTC UEs transferred to frequency 2 for MLB + ... + Proportion of RRC_IDLE eMTC UEs transferred to frequency n for MLB)

This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq CIO Adjustment Configuration Ind

Indicates how to set the upper and lower limits of the inter-frequency CIO adjustment range for the cell. If this parameter is set to NOT_CFG, the CIO adjustment range for the cell in inter-frequency MRO is not configured separately. Instead, the value range is the same as that in intra-frequency MRO. For details, see the value ranges in the CellMro.CioAdjLimitCfgInd, CellMro.CioAdjUpperLimit, and CellMro.CioAdjLowerLimit parameters. If this parameter is set to MANUAL_CFG, the inter-frequency CIO for the cell can be changed by an amount within the range specified by the upper and lower limits. If this parameter is set to AUTO_CFG, then:

(1) If the inter-frequency handover triggering event is event A4/A5, the upper and lower limits of the CIO adjustment range for the cell in inter-frequency MRO are calculated by using the following formulas: InterFreqCioAdjLowerLimit = -24, InterFreqCioAdjUpperLimit < Thresh + 110 - Ofn + Hys.

(2) If the inter-frequency handover triggering event is event A3, the upper and lower limits of the CIO adjustment range for the cell in inter-frequency MRO are calculated by using the following formulas: InterFreqCioAdjLowerLimit = Off + Ofs + Ocs - Ofn + Hys - 5, InterFreqCioAdjUpperLimit = Off + Ofs + Ocs - Ofn + Hys - 2.

In the preceding formulas, Thresh is the coverage-based inter-frequency RSRP triggering threshold, Off is the offset for inter-frequency handover, Ofs and Ofn are the frequency-specific offsets for the serving frequency and neighboring frequency respectively, Ocs is the cell-specific offset for the serving cell, and Hys is the hysteresis for inter- or intra-frequency handover.
Inter-Freq CIO Adjustment Lower Limit

Indicates the lower limit of inter-frequency cell individual offset (CIO) adjustment range for the cell in mobility robustness optimization (MRO). This parameter takes effect only when the InterFreqCioAdjLimitCfgInd parameter is set to MANUAL_CFG.

Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
Meas Priority for Freq-Priority-based HO

Indicates the measurement priority of the frequency for frequency-priority-based handovers. Before delivering frequencies to measure for frequency-priority-based handovers, the eNodeB selects frequencies based on the settings of this parameter. It preferentially selects high-priority frequencies. The larger the value of this parameter, the higher the priority level. This parameter applies only to LTE FDD and LTE TDD.
eMTC Inter-Frequency Cell Resel Priority

Indicates the cell reselection priority of the E-UTRAN frequency for eMTC UEs. The value 0 indicates the lowest priority. A eMTC UE compares the value of this parameter and the absolute priority of the serving cell to decide whether to reselect a neighboring cell on the target frequency:

If the value of this parameter is greater than the absolute priority of the serving cell, the UE starts measuring neighboring cells on neighboring frequencies. Then, if the signal quality of a neighboring cell meets the requirements, the UE reselects the cell.

If the value of this parameter is smaller than the absolute priority of the serving cell, the UE starts measuring neighboring cells on neighboring frequencies only when the signal quality of the serving cell is poor. Then, if the signal quality of a neighboring cell meets the requirements, the UE reselects the cell. For details, see 3GPP TS 36.331. The value 255 indicates that no priority is configured for the frequency. This parameter applies only to LTE FDD and LTE TDD.
