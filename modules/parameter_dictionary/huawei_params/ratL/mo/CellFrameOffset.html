CellFrameOffset

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellFrameOffset

Description

A CellFrameOffset MO consists of parameters related to cell frame offset.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If FddTddInd in the Cell MO identified by LocalCellId in a CellFrameOffset MO is set to CELL_FDD(FDD), FrameOffsetMode in the CellFrameOffset MO must be set to CustomFrameOffset.
    • When the following conditions are met, the FrameOffsetMode and FrameOffset parameters in a CellFrameOffset MO under a Cell MO must be set to CustomFrameOffset and 0, respectively: The CellActiveState, FddTddInd, and WorkMode parameters in the associated Cell MO are set to CELL_ACTIVE, CELL_TDD, and LAA, respectively, and the CellFrameOffset MO under this Cell MO has been configured.
  • Relation with the Cell, eUCellSectorEqm, SECTOREQM, and RRU MOs:
    • If the CellActiveState, FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters are set to CELL_ACTIVE, CELL_TDD, BOOLEAN_TRUE, and CELL_COMBINATION respectively in a Cell MO, the FreqBand parameter is not set to 34 or 39 in a Cell MO, and no CellFrameOffset MO is configured under this Cell MO, then the values of the RS parameter in RRU MOs associated with this Cell MO must be the same.
  • Relation with the Cell and ENodeBFrameOffset MOs:
    • The TddFrameOffset parameter in an ENodeBFrameOffset MO must be set to 0 when the following conditions are met: The CellActiveState, FddTddInd, and WorkMode parameters in the associated Cell MO are set to CELL_ACTIVE, CELL_TDD, and LAA, respectively, and the CellFrameOffset MO under this Cell MO has not been configured.
  • Relation with the CellAlgoSwitch MO:
    • If the InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the CellFrameOffset MO must be configured and the FrameOffsetMode parameter in this MO must be set to CustomFrameOffset.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLFRAMEOFFSET

Use this command to add frame offset configurations for a cell.
DSP CELLFRAMEOFFSET

Use this command to query information about frame offset that takes effect in the cell. The unit of frame offset is Ts. A Tc is equal to eight times of a Ts. If the DlEarfcn parameter value equals 4294967295, the queried frame offset is invalid.
LST CELLFRAMEOFFSET

Use this command to list frame offset configurations in cells.
MOD CELLFRAMEOFFSET

Use this command to modify frame offset configurations of a cell.
RMV CELLFRAMEOFFSET

Use this command to remove frame offset configurations of a cell.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.
Frame Offset Mode

Indicates the frame offset configuration mode for the cell.

The value CustomFrameOffset(User-defined frame offset) indicates that the frame offset is user-defined. Only this value applies to FDD cells and NB-IoT cells.

The value TL_FrameOffset(T-L Dual Mode frame offset) indicates that the frame offset is automatically determined based on the subframe configuration in a TD-SCDMA + LTE TDD dual-RAT network.

The value TL_FrameOffset_SA2_SSP5(T-L Dual Mode SA2+SSP5 frame offset) indicates that the frame offset is automatically determined based on uplink-downlink configuration 2 and special subframe configuration 5 in a TD-SCDMA + LTE TDD dual-RAT network.
Frame Offset

Indicates the offset of the start time of a cell frame against a reference clock source.
Table 3 Dynamic parameters

Parameter

Description
Frame Offset Effect Value

Indicates the offset of the cell start frame against a reference clock source. If the parameter value is a hyphen (-), the cell has not been activated.
