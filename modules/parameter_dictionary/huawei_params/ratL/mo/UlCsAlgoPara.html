UlCsAlgoPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-UlCsAlgoPara

Description

The UlCsAlgoPara MO consists of the parameters related to uplink coordinated scheduling.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • UL_COORD_RES_ALLOC_SWITCH of UlCsSw in a UlCsAlgoPara MO can be set on only if HighSpeedFlag in the associated Cell MO is set to LOW_SPEED(Low speed cell flag).
    • If CellRadius in a Cell MO is set to a value greater than 15000, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • UL_COORD_PC_SWITCH of UlCsSw in a UlCsAlgoPara MO can be set on only if HighSpeedFlag in the associated Cell MO is set to LOW_SPEED(Low speed cell flag).
    • If CellRadius in a Cell MO is set to a value greater than 15000, UL_COORD_PC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • When the NbCellFlag in a Cell MO is set to FALSE, if UlBandWidth in a Cell MO is set to CELL_BW_N6(1.4M) or CELL_BW_N15(3M), UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If FddTddInd in a Cell MO is set to CELL_TDD, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If FddTddInd in a Cell MO is set to CELL_TDD, UL_COORD_PC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If NbCellFlag in a Cell MO is set to TRUE, the UL_COORD_RES_ALLOC_SWITCH option of the UlCsSw in the UlCsAlgoPara must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the UL_COORD_PC_SWITCH option of the UlCsSw in the UlCsAlgoPara must be deselected.
  • Relation with the CellAlgoSwitch MO:
    • UL_COORD_PC_SWITCH of UlCsSw in a UlCsAlgoPara MO can be set on only if InnerLoopPuschSwitch of UlPcAlgoSwitch in the associated CellAlgoSwitch MO is set on.
    • If UlVoipRbRsvSwitch of UlSchExtSwitch in a CellAlgoSwitch MO is set on, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If PucchFlexCfgSwitch of PucchAlgoSwitch in a CellAlgoSwitch MO is set on, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If GLZeroBufferZoneSwitch of DynSpectrumShareSwitch in a CellAlgoSwitch MO is set on, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If AvoidCDMAInterfSwitch of AvoidInterfSwitch in a CellAlgoSwitch MO is set on, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
    • If UL_COORD_PC_SWITCH of UlCsSw in a UlCsAlgoPara MO is set on, SchedulerCtrlPowerSwitch of UlSchSwitch in the associated CellAlgoSwitch MO must be set on.
    • The InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO can be selected only if the UL_COORD_RES_ALLOC_SWITCH and UL_COORD_PC_SWITCH options of the UlCsSw parameter in the associated UlCsAlgoPara MO are deselected.
    • The InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO can be selected only if the UL_COORD_RES_ALLOC_SWITCH and UL_COORD_PC_SWITCH options of the UlCsSw parameter in the associated UlCsAlgoPara MO are deselected.
  • Relation with the ENodeBSharingMode, CellAlgoSwitch, and LicRatio MOs:
    • The UlCraSupportMocnSwitch parameter in the UlCsAlgoPara MO can be set to ON only if the following conditions are true: The ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ or HYBRID_SHARED, the RanShareModeSwitch parameter in the CellAlgoSwitch MO is set to OFF, and the TrafficSharingType parameter in the LicRatio MO is set to SHARING.
  • Relation with the CellUlschAlgo MO:
    • UL_COORD_RES_ALLOC_SWITCH of UlCsSw in a UlCsAlgoPara MO can be set on only if UlHoppingType in the associated CellUlschAlgo MO is set to Hopping_OFF.
  • Relation with the Cell and Cell MOs:
    • If CustomizedBandWidthCfgInd in a Cell MO is set to CFG and CustomizedULBandWidth in the Cell MO is set to a value less than 50, UL_COORD_RES_ALLOC_SWITCH of UlCsSw in the associated UlCsAlgoPara MO must be set off.
  • Relation with the SpectrumCloud MO:
    • When the UL_COORD_RES_ALLOC_SWITCH or UL_COORD_PC_SWITCH option of the UlCsSw parameter in the UlCsAlgoPara MO is selected, the SpectrumCloudSwitch parameter cannot be set to LTE_NR_UPLINK_SPECTRUM_SHR.
  • Relation with the CellShortTtiAlgo MO:
    • When the UL_COORD_RES_ALLOC_SWITCH and UL_COORD_PC_SWITCH options of the UlCsSw parameter in the UlCsAlgoPara MO are deselected, the SHORT_TTI_SW option of the SttiAlgoSwitch parameter in the CellShortTtiAlgo MO can be selected.
    • When the UL_COORD_RES_ALLOC_SWITCH and UL_COORD_PC_SWITCH options of the UlCsSw parameter in the UlCsAlgoPara MO are deselected, the SHORT_TTI_SW option of the SttiAlgoSwitch parameter in the CellShortTtiAlgo MO can be selected.
  • Relation with the ENodeBSharingMode, CellEmtcAlgo, CellAlgoSwitch, and UlInterfSuppressCfg MOs:
    • The UlSingleSideIntrfImpMitSw parameter in the UlInterfSuppressCfg MO must be set to OFF when one of the following conditions is met: - The ENodeBSharingMode parameter in the ENodeBSharingMode MO is not set to INDEPENDENT. - The UL_COORD_RES_ALLOC_SWITCH or UL_COORD_PC_SWITCH option of the UlCsSw parameter in the UlCsAlgoPara MO is selected. - The EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is selected. - The ULSUMIMO2LayersSwitch option of the UlSuMimoAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the UL_COORD_RES_ALLOC_SWITCH and UL_COORD_PC_SWITCH options of the UlCsSw parameter in the UlCsAlgoPara MO under this Cell MO must be deselected.
  • Relation with the Prb MO:
    • The UL_COORD_RES_ALLOC_SWITCH option of UlCsSw in the UlCsAlgoPara MO under the LTE Cell MO associated with LteCellId in a Prb MO can be selected only when NbCellFlag in the Cell MO is set to TRUE and the number of Prb MO instances with DeployMode set to IN_BAND is less than three.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.
UL Coordinated PC IN Threshold

Indicates the interference noise threshold for triggering UL coordinated power control (CPC). If the uplink interference noise level in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.
UL Coordinated PC Rollback RSRP Threshold

Indicates the RSRP threshold used for UEs involved in UL coordinated power control (CPC) rollback. This parameter applies only to LTE FDD.
UL Coordinated PC User Number Threshold

Indicates the UE number threshold for triggering UL coordinated power control (CPC). If the number of UL-synchronized UEs in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.
UL Coordinated Resource Allocation Band Mode

Indicates the mode of arranging the guard bands of cells for UL coordinated resource allocation. The mode determines the guard band positions. This parameter applies only to LTE FDD.
UL Coordinated Resource Allocation RB Load Thld

Indicates the load threshold for triggering UL coordinated resource allocation. If the PUSCH RB usage in a cell is higher than this threshold, the eNodeB allocates protected UEs only resources in the guard bands. This parameter applies only to LTE FDD.
UL CS A3 Offset

Indicates the offset for event A3 for UL coordinated scheduling (CS). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
UL CS Switch

Indicates whether to enable functions of UL coordinated scheduling (CS) for a cell.

UL_COORD_RES_ALLOC_SWITCH: Indicates whether to enable UL coordinated resource allocation. UL coordinated resource allocation is enabled only if this option is selected. This option applies only to LTE FDD.

UL_COORD_PC_SWITCH: Indicates whether to enable UL coordinated power control (CPC). UL CPC is enabled only if this option is selected. This option applies only to LTE FDD.
UL Coordinated Resource Alloc IN Threshold

Indicates the interference noise threshold for enabling uplink coordinated resource allocation (UL CRA). If the average interference noise level of the cells in the cluster for UL CRA is greater than this threshold, the interference condition for enabling UL CRA is met. This parameter applies only to LTE FDD.
UL CRA User Number Threshold

Indicates the UE number threshold for enabling uplink coordinated resource allocation (UL CRA). UL CRA takes effect in a cell if the number of served UEs is lower than this threshold. This parameter applies only to LTE FDD.
Uplink CRA Support MOCN Switch

Indicates whether to enable UL CRA in MOCN scenarios where air interface resources and traffic are fully shared. When this parameter is set to ON, UL CRA can be enabled. When this parameter is set to OFF, UL CRA cannot be enabled. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
Macro Cell Indicator

Indicates whether the local cell involved in uplink coordinated scheduling (CS) is a macro cell. This parameter applies only to LTE FDD.
Neighbour Cell eNodeB ID

Indicates the ID of the eNodeB serving a neighboring cell in the UL CS coordination set. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD.
Neighbour Cell ID

Indicates the local ID of a neighboring cell in the UL CS coordination set, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.
Neighbour Cell Macro Cell Indicator

Indicates whether a neighboring cell in the UL CS coordination set is a macro cell. This parameter applies only to LTE FDD.
Neighbour Cell Physical Cell ID

Indicates the physical ID of a neighboring cell in the UL CS coordination set. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
Neighbour Cell SFN Cell Indicator

Indicates whether a neighboring cell in the UL CS coordination set is an SFN cell. This parameter applies only to LTE FDD.
Round Trip Transmission Delay

Indicates the average round trip time of a link. This parameter applies only to LTE FDD.
SFN Cell Indicator

Indicates whether a local cell is an SFN cell. This parameter applies only to LTE FDD.
Neighbour Cell UL CS Relation Indicator

Indicates the specific UL CS function for which neighboring cells are grouped into a UL CS coordination set. This parameter applies only to LTE FDD.
