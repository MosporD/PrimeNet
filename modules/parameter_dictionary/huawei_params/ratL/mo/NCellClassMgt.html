NCellClassMgt

+-NE
  +-eNodeBFunction
    +-NCellClassMgt

Description

The NCellClassMgt MO consists of parameters related to neighboring cell classification management. Parameters in this MO are used for automatic setting of the classification label for neighboring cells included in NRTs. The eNodeB performs differentiated management on the classified neighboring cells to improve operation and maintenance efficiency.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Statistic Period For Neighbor Cell Classification

Indicates the statistical period for intra-RAT neighbor relationship classification. The eNodeB measures the number of handover attempts from a source cell to a target cell, the number of successful handovers from the source cell to the target cell, and the number of times a neighboring cell is configured as an SCell for CA UEs within the statistical period. Based on the measurement results, the eNodeB determines whether the intra-RAT neighboring cell is a formal or extended neighboring cell. If the predefined criteria are met within the statistical period, the intra-RAT neighboring cell is regarded as a formal neighboring cell. If the predefined criteria are not met within each of four consecutive statistical periods, the intra-RAT neighboring cell is regarded as an extended neighboring cell. This parameter also indicates the statistical period for determining whether an intra-RAT neighboring cell is an over-distant neighboring cell. If the number of handovers to a neighboring cell reaches the specified threshold and the handover success rate reaches the specified handover success rate threshold within a statistical period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.
Handover Attempt Threshold

Indicates the threshold of the number of handover attempts used for intra-RAT neighbor relationship classification. If the number of handover attempts from a source cell to a target cell within a statistical period of intra-RAT neighbor relationship classification reaches this threshold and the number of successful handovers reaches the threshold of the number of successful handovers, the intra-RAT neighboring cell is regarded a formal neighboring cell. Otherwise, the intra-RAT neighboring cell is regarded an extended neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Threshold of SCell Configured

Indicates the threshold of the number of times a neighboring cell is successfully configured as SCells for CA UEs used in neighbor relationship classification. If the number of times that a neighboring cell is successfully configured as SCells for CA UEs reaches this threshold within a measurement period, the neighboring cell is labeled as FORMAL. If the number cannot reach this threshold within a specified measurement period, the neighboring cell is labeled as EXTENDED. This parameter applies only to LTE FDD and LTE TDD.
Handover Success Threshold

Indicates the threshold of the number of successful handovers for intra-RAT neighbor relationship classification. If the number of handover attempts from a source cell to a target cell within a statistical period of intra-RAT neighbor relationship classification reaches the threshold of the number of handover attempts and the number of successful handovers reaches this threshold, the intra-RAT neighboring cell is a regarded formal neighboring cell. Otherwise, the intra-RAT neighboring cell is regarded an extended neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Intra-RAT Neighbor Cell Management Mode

Indicates the intra-RAT neighbor relationship classification mode. If the intra-RAT neighbor relationship classification algorithm is enabled and this parameter is set to CONFIGURATION_MODE, intra-RAT extended neighboring cells are saved in the configuration database. If this parameter is set to INTERNAL_STORAGE_MODE, intra-RAT extended neighboring cells are saved in the eNodeB memory. INTERNAL_STORAGE_MODE takes effect only when the OptMode parameter in the ANR MO is set to FREE. This parameter applies only to LTE FDD and LTE TDD.
