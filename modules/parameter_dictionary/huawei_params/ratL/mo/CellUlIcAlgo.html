CellUlIcAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellUlIcAlgo

Description

The CellUlIcAlgo MO consists of parameters related to the offset for uplink interference cancellation (IC) event A3. This parameter is delivered with the RRC Connection Reconfiguration message. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, CellAlgoSwitch, NCellSrsMeasPara, PUSCHCfg, and SectorSplitCell MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, the MASSIVE_MIMO_SRS_IC_SW option of the SrsIcSwitch parameter in the CellUlIcAlgo MO can be selected only if the SrsTimeMeasSwitch option of the SrsAlgoSwitch parameter in the CellAlgoSwitch MO is selected, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO is set to ON, the NCellSrsTimeMeasSwitch option of the NCellMeasSwitch parameter in the NCellSrsMeasPara MO is selected, the GroupHoppingEnabled in the PUSCHCfg MO is set to BOOLEAN_FALSE, and the SeqHoppingEnabled parameter in the PUSCHCfg MO is set to BOOLEAN_FALSE.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
UL IC A3 Offset

Indicates the A3 offset for interference cancellation (IC) event A3, that is, the A3 offset of the neighboring cell's signal quality to the serving cell. A larger value indicates that a neighboring cell must have better signal quality for reporting the event. This parameter applies only to LTE FDD.
SRS IC Switch

Indicates whether to enable the SRS IC algorithm for a cell.

MASSIVE_MIMO_SRS_IC_SW: If this option is selected, the SRS IC algorithm for massive MIMO is enabled. If this option is deselected, the SRS IC algorithm for massive MIMO is disabled. This option applies only to LTE TDD.
