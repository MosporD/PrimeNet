CaGroupCell

+-NE
  +-eNodeBFunction
    +-CaGroup
      +-CaGroupCell

Description

The CaGroupCell MO defines a cell in a carrier aggregation (CA) group.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CaGroup
  • Relation with the Cell and eNodeBFunction MOs:
    • If eNodeBId in a CaGroupCell MO is equal to eNodeBId in the eNodeBFunction MO, the Cell MO corresponding to the LocalCellId in the CaGroupCell MO must have been configured.
    • If eNodeBId in a CaGroupCell MO is equal to eNodeBId in the eNodeBFunction MO, the NbCellFlag in the Cell MO corresponding to the LocalCellId in the CaGroupCell MO must be set to FALSE.
  • Relation with the CaGroup, Cell, and eNodeBFunction MOs:
    • If CaGroupTypeInd in a CaGroup MO is set to FDD, the Cell MOs associated with the CaGroupCell MO under this CaGroup MO must also work in CELL_FDD mode.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, the Cell MOs associated with the CaGroupCell MO under this CaGroup MO must also work in CELL_TDD mode.
    • If CaGroupTypeInd in a CaGroup MO is set to FDDTDD, FddTddInd in Cell MO associated with a CaGroupCell MO under this CaGroup MO must be CELL_TDD, SubframeAssignment must be SA1 or SA2.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, FddTddInd in Cell MO associated with a CaGroupCell MO under this CaGroup MO must be CELL_TDD, SubframeAssignment must be SA1 or SA2.
  • Relation with the CaGroup MO:
    • If CaGroupTypeInd in a CaGroup MO is set to FDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
    • If CaGroupTypeInd in a CaGroup MO is set to FDDTDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
  • Relation with the CaGroupCell MO:
    • One Cell can be configured only as one CaGroupCell MO.
  • Relation with the Cell MO:
    • UlCyclicPrefix or DlCyclicPrefix in the Cell MOs associated with a CaGroupCell MO must be set to the same value.
    • When the NbCellFlag in a Cell MO is set to FALSE, if CellRadius in a Cell MO representing a cell is set to a value greater than 100000 m, this cell cannot be added to a CaGroupCell MO.
  • Relation with the CellAlgoSwitch MO:
    • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, the cell could not be configured as CA cell in CaGroupCell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CAGROUPCELL

Use this command to add a cell to a CA group.
DSP CAGROUPCELL

Use this command to query the settings of dynamic parameters for a carrier aggregation (CA) group and the use of licenses in cells of the CA group.
LST CAGROUPCELL

Use this command to list the cells in a CA group.
MOD CAGROUPCELL

Use this command to modify a CA group cell.
RMV CAGROUPCELL

Use this command to remove a cell from a CA group.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CA Group Identity

Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the ID of the eNodeB serving the cell. This parameter applies only to LTE FDD and LTE TDD.
Preferred PCell Priority

Indicates the priority of the cell being treated as a primary serving cell (PCell). A larger parameter value represents a higher priority level. This parameter is valid only if the IdleModePccAnchorSwitch(IdleModePccAnchorSwitch), PccAnchorSwitch(PccAnchorSwitch), or EnhancedPccAnchorSwitch(EnhancedPccAnchorSwitch) option of the CaAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.
PCell A4 RSRP Threshold

Indicates the reference signal received power (RSRP) threshold for triggering event A4 during higher-priority cell evaluation for PCell selection in scenarios where CA is configured based on CA groups. This parameter applies only to LTE FDD and LTE TDD.
PCell A4 RSRQ Threshold

Indicates the reference signal received quality (RSRQ) threshold for triggering event A4 during higher-priority cell evaluation for PCell selection in scenarios where CA is configured based on CA groups. If the measured RSRQ of an inter-frequency neighboring cell in the CA group is greater than this parameter value, the CA UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.
