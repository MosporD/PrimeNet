Tm9DedicatedCarrier

+-NE
  +-eNodeBFunction
    +-Tm9DedicatedCarrier

Description

The Tm9DedicatedCarrier MO consists of the parameters related to downlink EARFCNs and CRS transmission strategies for TM9-dedicated carriers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell MO:
    • The CrsPortMap parameter in the Cell MO must be set to NOT_CFG when the following conditions are true: In the Cell MO, the FddTddInd, TxRxMode, and CrsPortNum parameters are set to CELL_FDD, 4T4R, and CRS_PORT_1, respectively; there is a Tm9DedicatedCarrier MO instance with Tm9CcDlEarfcn the same as DlEarfcn in the Cell MO.
    • The CrsPortMap parameter in the Cell MO must be set to NOT_CFG when the following conditions are true: In the Cell MO, the FddTddInd, TxRxMode, and CrsPortNum parameters are set to CELL_FDD, 4T8R, and CRS_PORT_1, respectively; there is a Tm9DedicatedCarrier MO instance with Tm9CcDlEarfcn the same as DlEarfcn in the Cell MO.
  • Relation with the PccFreqCfg MO:
    • WorkMode parameter in a Tm9DedicatedCarrier MO is set to TM9_DEDICATED_SCC, the Tm9CcDlEarfcn parameter in the same MO cannot be set to the same value as the PccDlEarfcn parameter in the PccFreqCfg MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
TM9 CC Downlink EARFCN

Indicates the downlink EARFCN of a TM9-dedicated carrier. This parameter applies only to LTE FDD.
CRS Transmission Strategy

Indicates whether to transmit PDSCH CRSs across the entire channel bandwidth or using only central RBs on the TM9-dedicated carrier. If this parameter is set to ALL_RB_ON, the CRSs are transmitted across the entire channel bandwidth. If this parameter is set to CENTRAL_RB_ON, the CRSs are transmitted using only the six RBs in the center of the channel bandwidth. This parameter applies only to LTE FDD.
Work Mode

Indicates the working mode of the TM9-dedicated carrier. When this parameter is set to TM9_DEDICATED_SCC, the TM9-dedicated carrier can be configured only as an SCC. When this parameter is set to TM9_DEDICATED_CC, the TM9-dedicated carrier can be configured as a PCC or an SCC. When this parameter is set to R10PLUS_DEDICATED_CC, the TM9-dedicated carrier can only be used by UEs complying with 3GPP Release 10 or later. If this parameter is set to NON_TM9_SCC, the TM9-dedicated carrier can be configured as an SCC for TM9-incapable UEs and as a PCC or SCC for TM9-capable UEs. This parameter applies only to LTE FDD.
