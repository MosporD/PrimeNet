Pmch

+-NE
  +-eNodeBFunction
    +-Mce
      +-MbsfnArea
        +-Pmch
          +-Session[0~28]

Description

The Pmch MO includes the parameters used to configure the PMCH for an MBSFN area.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    MbsfnArea

  • Possible children:

    Session[0~28]
  • Relation with the MbsfnArea MO:
    • The value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO must be less than or equal to the value of the MchSchedulingPeriod parameter in the Pmch MO.
    • If the FddTddInd parameter in the MbsfnArea MO is set to CELL_FDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 6. If the FddTddInd parameter in the MbsfnArea MO is set to CELL_TDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 5.
    • If the FddTddInd parameter in the MbsfnArea MO is set to CELL_FDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 6. If the FddTddInd parameter in the MbsfnArea MO is set to CELL_TDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 5.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local MCE ID

Indicates the local MCE ID, which is unique on the local NE. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Area ID

Indicates the MBSFN area ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
PMCH ID

Indicates the PMCH ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
Allocation End Subframe

Indicates the end subframe for PMCH allocation. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
Data Modulation and Coding Scheme

Indicates the MCS of the PMCH. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
MCH Scheduling Period

Indicates the PMCH scheduling period. The PMCH scheduling period must be a multiple of the MBSFN subframe allocation period. The MBSFN subframe allocation period is specified by the CommonSubframeAllocPeriod parameter in the MbsfnArea MO. The PMCH scheduling period must not be greater than the value of the RepetitionPeriod parameter in the Mcch MO. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
QoS Class Identifier

Indicates the QCI of GBR bearers for MBMS services. This parameter applies only to LTE FDD and LTE TDD.
