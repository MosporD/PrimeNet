LicRatio

+-NE
  +-eNodeBFunction
    +-LicRatio

Description

The LicRatio MO includes the parameter indicating the proportion of the UL licensed traffic to the total licensed traffic of the eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the ENodeBSharingMode, CellAlgoSwitch, and UlCsAlgoPara MOs:
    • The UlCraSupportMocnSwitch parameter in the UlCsAlgoPara MO can be set to ON only if the following conditions are true: The ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ or HYBRID_SHARED, the RanShareModeSwitch parameter in the CellAlgoSwitch MO is set to OFF, and the TrafficSharingType parameter in the LicRatio MO is set to SHARING.
  • Relation with the CellAlgoSwitch and ENodeBSharingMode MOs:
    • If OutOfBandRelaySwitch, InBandRelayDeNbSwitch, or InBandRelayReNbSwitch under RelaySwitch in the CellAlgoSwitch MO is selected and ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, TrafficSharingType in this LicRatio MO must be set to SHARING.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Uplink Traffic License Ratio

Indicates the proportion of the UL licensed traffic to the total licensed traffic of the eNodeB. The total licensed traffic is the sum of UL and DL licensed traffic. If this parameter is set to 100%, there is no DL licensed traffic, affecting service admission. This parameter applies only to LTE FDD and LTE TDD.
Traffic Sharing Type

Indicates the mode of traffic sharing between the operators in RAN sharing scenarios. If this parameter is set to SHARING, all the operators share the total traffic of the eNodeB without proportional limits. If this parameter is set to DEDICATE and the ENodeBSharingMode parameter is not set to INDEPENDENT, all the operators share the total traffic of the eNodeB based on specific proportions. However, the vacant traffic of an operator can be used by other operators. This parameter applies only to LTE FDD and LTE TDD.
