InterRatHoNrParamGrp

+-NE
  +-eNodeBFunction
    +-Cell
      +-InterRatHoNrParamGrp

Description

An InterRatHoNrParamGrp MO represents a group of parameters related to inter-RAT handovers to NR cells. Different handover parameter settings can be mapped to different QCIs, meeting differentiated requirements of services for cells. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in an InterRatHoNrParamGrp MO must have been set in the associated Cell MO.
  • Relation with the CellQciPara MO:
    • The InterRatHoNrParamGrp MO referenced by the NrHoParamGroupId parameter in the CellQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
NR Handover Parameter Group ID

Indicates the group ID of parameters for handovers from the E-UTRAN to NR. This parameter applies only to LTE FDD and LTE TDD.
NR B1B2 Hysteresis

Indicates the hysteresis for events B1 and B2 related to EUTRAN-to-NR handovers. This parameter prevents frequent handover measurement triggering and release caused by radio signal fluctuations and reduces the probability of incorrect handover decisions and ping-pong handovers. The larger the parameter value, the lower this probability. This parameter applies only to LTE FDD and LTE TDD.
NR B1B2 Time-to-Trigger

Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-NR handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.
Coverage-based NR B1 RSRP Threshold

Indicates the RSRP threshold for triggering event B1 related to coverage-based EUTRAN-to-NR handovers. If the measured RSRP value of any neighboring cell exceeds this threshold, B1 measurement reports will be sent to the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Service-based NR B1 RSRP Threshold

Indicates the RSRP threshold for triggering event B1 related to service-based EUTRAN-to-NR handovers. If the measured RSRP value of any neighboring cell exceeds this threshold, B1 measurement reports will be sent to the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
NSA DC SA NR HO No-Gap HO B1 Time-to-Trigger

Indicates the time-to-trigger for event B1 reported based on non-gap-assisted measurements for inter-RAT handovers of NSA DC UEs to NG-RAN in SA networking. This parameter applies only to LTE FDD and LTE TDD.
