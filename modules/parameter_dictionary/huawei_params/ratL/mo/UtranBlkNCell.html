UtranBlkNCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-UtranBlkNCell

Description

A UtranBlkNCell MO consists of parameters related to the list of blacklisted neighboring UTRAN cells. The list stores overshooting neighboring cells, abnormal neighboring cells, and the blacklisted neighboring UTRAN cells that RRC_CONNECTED UEs cannot be handed over to.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the UtranExternalCell MO:
    • The UtranExternalCell MO must be configured first before the associated UtranBlkNCell MO is configured.
  • Relation with the UtranNFreq and UtranExternalCell MOs:
    • UtranDlArfcn and UtranFddTddType in the UtranExternalCell MO associated with a UtranBlkNCell MO must have been configured in the corresponding UtranNFreq MO.
  • Relation with the UtranNCell, Cell, and UtranExternalCell MOs:
    • Values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranBlkNCell MO configured for the serving cell cannot be the same as values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranNCell MO configured for the serving cell at the same time.
  • Relation with the Cell MO:
    • A maximum of 16 UtranBlkNCell MOs can be configured for a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile country code

Indicates the mobile country code (MCC) of the neighboring UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code (MNC) of the neighboring UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
RNC ID

Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
Auto Config Flag

Indicates whether a blacklisted neighboring UTRAN cell is automatically generated by the eNodeB or manually created. If this parameter is set to AUTO_CREATED, the eNodeB automatically generates the blacklisted neighboring UTRAN cell. If this parameter is set to MANUAL_CREATED, operators create the blacklisted neighboring UTRAN cell using the MAE or MML commands. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control mode on a blacklisted neighboring UTRAN cell. This parameter specifies the policy of controlling the UtranBlkNCell MO by operators or SON. If this parameter is set to MANUAL_MODE(Manual Mode), this object can be modified or removed only by operators. If this parameter is set to AUTO_MODE(Auto Mode), this object can be modified or removed by either operators or SON. This parameter is set to AUTO_MODE(Auto Mode) by default for objects created by SON. This parameter can be set to AUTO_MODE(Auto Mode) or MANUAL_MODE(Manual Mode) for objects created by an operator. This parameter applies only to LTE FDD and LTE TDD.
