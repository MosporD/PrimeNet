CellDlCompAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDlCompAlgo

Description

The CellDlCompAlgo MO defines the offset for DL CoMP event A3. This offset is delivered with the RRC Connection Reconfiguration message. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in a CellDlCompAlgo MO must have been set in the associated Cell MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
LocalCellId

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
DlCompA3Offset

Indicates the offset for reporting the DL CoMP measurement event. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better quality for reporting the event. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.
DPS Coordinating Cell User Ratio Threshold

Indicates the threshold for the ratio of the number of uplink synchronized UEs in a dynamic point selection (DPS) serving cell to a DPS coordinating cell when DL CoMP is enabled. When the ratio of the number of uplink synchronized UEs in the coordinating cell (including those transferred to the coordinating cell) to that in the serving cell is smaller than this threshold, the coordinating cell can function as the target cell of DPS UEs. This parameter applies only to LTE FDD cells.
DPS Load Difference Threshold

Indicates the threshold of the difference between the PRB usage of a DPS serving cell and that of a DPS coordinating cell when DL CoMP is enabled. When the difference between the PRB usage of the serving cell and the coordinating cell exceeds this threshold, the coordinating cell can function as the target cell of DPS UEs. This parameter applies only to LTE FDD cells.
DPS Serving cell download PRB Threshold

Indicates the threshold of the downlink PRB usage for a DPS serving cell when DL CoMP is enabled. When the PRB usage of a candidate cell exceeds this threshold, the cell can be selected as a DPS serving cell. This parameter applies only to LTE FDD cells.
HetNet DPS Coordinating Cell RSRP Threshold

Indicates the RSRP offset threshold for DPS UEs in selecting a coordinating cell in a HetNet. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of DPS UEs selecting a coordinating cell in a HetNet. A small value of this parameter indicates a large number of DPS UEs selecting a coordinating cell in a HetNet. This parameter applies only to LTE FDD cells.
HomNet DPS Coordinating Cell RSRP Threshold

Indicates the RSRP offset threshold for DPS UEs in selecting a coordinating cell in a HomNet. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of DPS UEs selecting a coordinating cell in a HomNet. A small value of this parameter indicates a large number of DPS UEs selecting a coordinating cell in a HomNet. This parameter applies only to LTE FDD cells.
JT Coordinating Cell DL PRB Threshold

Indicates the threshold of the downlink PRB usage for selecting a candidate cell as a coordinating cell when DL CoMP is enabled. When the PRB usage of a candidate cell is lower than this threshold, the cell can be selected as a coordinating cell for joint transmission. This parameter applies only to LTE FDD.
JT Coordinating Cell RSRP Threshold

Indicates the RSRP offset threshold for joint transmission UEs in selecting a coordinating cell. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of joint transmission UEs. A small value of this parameter indicates a large number of joint transmission UEs. This parameter applies only to LTE FDD.
JT Serving Cell DL PRB Threshold

Indicates the threshold of the downlink PRB usage for a serving cell for joint transmission when DL CoMP is enabled. When the PRB usage of a candidate cell is smaller than this threshold, the cell can be selected as a serving cell for joint transmission. This parameter applies only to LTE FDD cells.
DL CoMP Scheduling Priority Factor

Indicates the scheduling priority for DL CoMP UEs. This parameter takes effect only for downlink non-GBR services of DL CoMP UEs. This parameter applies only to LTE FDD.
DL CoMP Report Interval

Indicates the interval at which TM9- or TM10-capable UEs periodically send A3 or A6 measurement reports when at least one of DL CoMP with TM 10 and joint transmission with TM9 takes effect. For details about the reporting interval, see 3GPP TS 36.331. If this parameter is set to OFF, the A3 or A6 reporting interval is the same as the reporting interval (specified by the ReportInterval parameter in the CellMcPara MO) of common event A3 or A6. This parameter applies only to LTE FDD.
