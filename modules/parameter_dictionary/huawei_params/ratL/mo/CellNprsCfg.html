CellNprsCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellNprsCfg

Description

This MO consists of parameters used to configure NPRS for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of two CellNprsCfg MO instances can be configured for a Cell MO.
  • Relation with the Prb MO:
    • If the NprsParaGroupId parameter in the PRB MO is not set to 255, this parameter must be set in the CellNprsCfg MO.
    • When the DeployMode parameter in a Prb MO is IN_BAND, the NprsSubframeConfigMode parameter in the associated CellNprsCfg MO must not be set to PART_B.
  • Relation with the Prb and PrbSchConfig MOs:
    • If the value of the NprsParaGroupId parameter in the CellNprsCfg MO is the same as the value of the NprsParaGroupId parameter in the Prb MO associated by the LocalCellId parameter, the value of each bit of the NprsSubframeBitmap10 parameter in the CellNprsCfg MO must be within the subset of bit negation of the NbDlBitmap10 parameter value in the PrbSchConfig MO associated by the PrbId parameter.
    • If the value of the NprsParaGroupId parameter in the CellNprsCfg MO is the same as the value of the NprsParaGroupId parameter in the Prb MO associated by the LocalCellId parameter, the value of each bit of the NprsSubframeBitmap30 parameter in the CellNprsCfg MO must be within the subset of bit negation of the NbDlBitmap30 parameter value in the PrbSchConfig MO associated by the PrbId parameter.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.
NPRS Parameter Group ID

Indicates the NPRS parameter group ID. This parameter applies only to NB-IoT.
NPRS Subframe Config Mode

Indicates the NPRS configuration mode of an NB-IoT cell. This parameter cannot be set to PART_B in NB-IoT cells configured in LTE in-band mode. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
NPRS Period

Indicates the NPRS sending period of an NB-IoT cell in Part B mode. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
Consecutive NPRS Subframe Count

Indicates the number of consecutive subframes in which NPRSs in part B mode are transmitted in an NB-IoT cell. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
NPRS Start Subframe Offset

Indicates the start subframe offset in the NPRS of an NB-IoT cell in Part B mode. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
Number of NPRS Muting Bits

Indicates the number of PRS muting bits in the cell. If the cell is an NB-IoT cell, this parameter indicates the number of NPRS muting bits. This parameter applies only to NB-IoT.
NPRS Muting Configuration

Indicates NPRS muting configurations.

In Part A mode, each bit corresponds to 10 consecutive subframes. If the current bit is 1, NPRS is sent within the subframes. If the current bit is 0, NPRS is not sent.

In Part B mode, each bit indicates an NPRS period. If the bit is 1, NPRS is sent within the current NPRS period. If the bit is 0, NPRS is not sent.

For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
NPRS Subframe Bitmap10

Indicates a 10-bit bitmap used to specify the set of subframes for NPRS transmission in the NB-IoT cell when NPRS subframe configuration Part A is used. The value of this parameter needs to be converted into a binary number, and the least significant 10 bits of the number are used as the bitmap, with each bit representing a subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, only this parameter is used to specify the NPRS subframe configuration for the NB-IoT cell. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the first 10 subframes, and it is used together with the NprsSubframeBitmap30 parameter to specify the NPRS subframe configuration for the NB-IoT cell.

The value 1 in the bitmap indicates that NPRSs are transmitted in the corresponding subframe and the subframe is invalid for downlink transmission. The value 0 in the bitmap indicates that NPRSs are not transmitted in the corresponding subframe.

For details, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
NPRS Subframe Bitmap30

Indicates a 30-bit bitmap used to specify the set of subframes for NPRS transmission in the NB-IoT cell when NPRS subframe configuration Part A is used. The value of this parameter needs to be converted into a binary number, and the least significant 30 bits of the number are used as the bitmap, with each bit representing a subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, this parameter is invalid. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the last 30 subframes, and it is used together with the NprsSubframeBitmap10 parameter to specify the NPRS subframe configuration for the NB-IoT cell.

The value 1 in the bitmap indicates that NPRSs are transmitted in the corresponding subframe and the subframe is invalid for downlink transmission. The value 0 in the bitmap indicates that NPRSs are not transmitted in the corresponding subframe.

For details, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
