CnOperatorIpPath

+-NE
  +-eNodeBFunction
    +-CnOperatorIpPath

Description

A CnOperatorIpPath MO consists of the parameters used to associate an IP path with an operator of the eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CnOperator MO:
    • CnOperatorId in a CnOperatorIpPath MO must have been set in the associated CnOperator MO.
  • Relation with the IPPATH MO:
    • IPMUXSWITCH in the IPPATH that is associated with IpPathId in the CnOperatorIpPath cannot be set to ENABLE.
    • IpPathId in a CnOperatorIpPath MO must have been set in the associated IPPATH MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CNOPERATORIPPATH

Use this command to add the operator that owns the IP path.
LST CNOPERATORIPPATH

Use this command to list the operator that owns the IP path.
MOD CNOPERATORIPPATH

Use this command to modify the operator to which the IP path belongs.
RMV CNOPERATORIPPATH

Use this command to remove the operator that owns the IP path.
