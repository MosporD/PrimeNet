AblMsg

+-NE
  +-eNodeBFunction
    +-AblMsg

Description

An AblMsg MO consists of parameters related to a debugging message for 3GPP-defined interfaces. The eNodeB compares messages (either received or to be sent) with the debugging message for UEs of the specified configuration type (all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified UE capability). If the messages meet the specified matching criteria (matching offset, length, and content), the eNodeB discards or modifies the messages.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the UeInfo MO:
    • The UeInfo MO referenced by UeCapIndex in a AblMsg MO must have been configured.

Function
ADD ABLMSG

Use this command to add a debugging message. The eNodeB compares messages (either received or to be sent) with the debugging message for UEs of the specified configuration type (all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified UE capability). Use this command to list the configuration of debugging messages.

Use this command to remove a debugging message.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rule Index

Indicates the index of a rule for the debugging message.
Rule Configuration Type

Indicates whether the rule takes effect on all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified capability.

If this parameter is set to ALL, none of ImeisvTac, ImeisvSvn, and UeCapIndex needs to be configured.

If this parameter is set to IMEISV_TAC, the ImeisvTac parameter must be configured.

If this parameter is set to IMEISV_TAC_SVN, the ImeisvTac and ImeisvSvn parameters must be configured.

If this parameter is set to UE_CAPABILITY, the UeCapIndex parameter must be configured.
IMEISV TAC

Indicates the type allocation code (TAC) in the IMEISVs of UEs. Each TAC identifies a UE model. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
IMEISV SVN

Indicates the software version number (SVN) in the IMEISVs of UEs. Each SVN identifies a software version of UEs. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
IMEISV Description

Indicates the user-defined description of the UE type.
Interface Protocol Name

Indicates the interface or protocol type of the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
Message Type

Indicates the number of the message transmitted over 3GPP-defined interfaces. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
Operate Type

Indicates the operation performed by the eNodeB on a matched message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
Match Count

Indicates the number of items in the debugging message for matching. Each item contains the offset, length, and content.

The value ZERO indicates that the eNodeB discards or modifies the messages with a specific ID.

The value ONE indicates that the eNodeB discards or modifies the messages with the matching result of one item to be positive.

The value TWO indicates that the eNodeB discards or modifies the messages with the matching result of two items to be positive.

The value THREE indicates that the eNodeB discards or modifies the messages with the result of three items to be positive. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
