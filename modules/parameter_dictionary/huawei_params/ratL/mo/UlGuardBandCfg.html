UlGuardBandCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-UlGuardBandCfg

Description

A UlGuardBandCfg MO consists of NB-IoT PRB uplink guardband parameters to avoid the interference caused by unorthogonal subcarriers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Prb
  • Relation with the PrbRachCeConfig MO:
    • The subcarrier index value indicated in the value of the PrachSubcarrierOffset parameter in a PrbRachCeConfig MO must not be lower than the value of the LowFreqGuardBand parameter in the associated UlGuardBandCfg MO. In addition, the sum of the subcarrier index value, the value of HighFreqGuardBand in the associated UlGuardBandCfg MO, and the value of the PrachSubcarrierNumber parameter in the PrbRachCeConfig MO must not exceed 48.
    • The subcarrier index indicated in the value of the EdtPrachSubcarrierOffset parameter in the PrbRachCeConfig MO must not be less than the value of the LowFreqGuardBand parameter in the UlGuardBandCfg MO for the corresponding cell; in addition, the sum of the subcarrier index value, the value of the HighFreqGuardBand parameter in the UlGuardBandCfg MO, and 12 (the number of EDT PRACH subcarriers) must not be not greater than 48.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.
PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within an eNodeB. This parameter applies only to NB-IoT.
High Frequency Guard Band

Indicates the NB-IoT high frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.
Low Frequency Guard Band

Indicates the NB-IoT low frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.
Guard Band Between NPRACH and NPUSCH

Indicates the width of the guard band between the NPRACH and NPUSCH. This parameter applies only to NB-IoT.
