LIOptFeature

+-NE
  +-eNodeBFunction
    +-LIOptFeature

Description

An LIOptFeature MO consists of parameters specifying the intelligent optimization features. Intelligent optimization features support adaptive parameter adjustment based on scenarios, thereby optimizing the overall network performance. An intelligent optimization feature is allowed to include multiple intelligent optimization functions.

Effective Scenario

Immediately

  • Possible parents:
