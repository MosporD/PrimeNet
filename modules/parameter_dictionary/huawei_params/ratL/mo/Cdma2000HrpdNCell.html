Cdma2000HrpdNCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-Cdma2000HrpdNCell

Description

A Cdma2000HrpdNCell MO consists of parameters related to a neighboring CDMA2000 HRPD cell. The parameters are used for handover or reselection from an E-UTRAN cell to a CDMA2000 HRPD cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 32 Cdma2000HrpdNCell MOs can be configured for each cell.
  • Relation with the Cdma2000HrpdExtCell MO:
    • Before adding a Cdma2000HrpdNCell MO, ensure that the associated Cdma2000HrpdExtCell MO has been configured.
  • Relation with the Cdma2000Nfreq MO:
    • Before adding a Cdma2000HrpdNCell MO, ensure that the associated Cdma2000Nfreq MO with the same LocalCellId, BandClass, and Frequency has been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CDMA2000HRPDNCELL

Use this command to add the neighboring relation with a CDMA2000 HRPD cell.

Use this command to list the parameters of the neighboring relation with the CDMA2000 HRPD cell.
MOD CDMA2000HRPDNCELL

Use this command to modify the configuration of the neighboring relation with a CDMA2000 HRPD cell.

Use this command to remove one or more neighbor relationships with CDMA2000 HRPD cells.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
SectorID104

Indicates the value for SectorID104 of the neighboring CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 26 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.
SectorID24

Indicates the value for SectorID24 of the neighboring CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 6 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.
Band class

Indicates the band class on which the neighboring CDMA2000 high rate packet data (HRPD) cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Frequency

Indicates the frequency on which the neighboring CDMA2000 high rate packet data (HRPD) cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
No handover indicator

Indicates whether to permit or prohibit handovers from the local cell to the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
No remove indicator

Indicates whether to permit or prohibit removal of the neighbor relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether ANR with neighboring CDMA2000 high rate packet data (HRPD) cells is enabled. This parameter applies only to LTE FDD and LTE TDD.
Local cell name

Indicates the name of the local cell. This parameter applies only to LTE FDD and LTE TDD.
Neighbour cell name

Indicates the name of the neighboring CDMA2000 HRPD cell. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
