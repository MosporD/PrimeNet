PrivateCaBandComb

+-NE
  +-eNodeBFunction
    +-PrivateCaBandComb
      +-PrivateBand[0~8]

Description

A PrivateCaBandComb MO consists of parameters related to a private CA band combination supported by an eNodeB. The eNodeB preferentially matches the CA capability of UEs based on the private CA band combination configuration.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    PrivateBand[0~8]

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD PRIVATECABANDCOMB

Use this command to add a private CA band combination for an eNodeB. If the number and IDs of combination bands of different private CA band combinations are identical, the eNodeB uses the private CA band combination with the smallest band combination ID.
DSP PRIVATECABANDCOMB

Use this command to query the conflict status of a private CA band combination for an eNodeB. The Combination Status parameter indicates whether the private CA band combination conflicts with solidified CA band combinations supported by an eNodeB. The solidified CA band combinations supported by the eNodeB include the solidified private CA band combinations and 3GPP-defined CA band combinations of the related protocol version that the eNodeB complies with.
LST PRIVATECABANDCOMB

Use this command to list the configurations of private CA band combinations for an eNodeB.
MOD PRIVATECABANDCOMB

Use this command to modify the configuration of a private CA band combination for an eNodeB.
RMV PRIVATECABANDCOMB

Use this command to remove a private CA band combination for an eNodeB.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Private CA Band Combination ID

Indicates the ID of the private CA band combination. It uniquely identifies a private CA band combination in an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Maximum Aggregated Bandwidth

Indicates the maximum aggregated bandwidth supported by the CA band combination. This parameter applies only to LTE FDD and LTE TDD.
Bandwidth Combination Set ID

Indicates the protocol-defined ID of a CA bandwidth combination set. As defined in 3GPP TS 36.101, an operating frequency band supports different bandwidth combinations, which are identified by using different set IDs. For details, see section 5.6A.1 in 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.
Combination Band 1 Band Identity

Indicates combination band 1. For details, see 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.
Combination Band 2 Band Identity

Indicates combination band 2. For details, see 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.
Combination Band 3 Band Identity

Indicates combination band 3. For details, see 3GPP TS 36.101. If the value is 0, combination band 3 is invalid. This parameter applies only to LTE FDD and LTE TDD.
Combination Band 4 Band Identity

Indicates combination band 4. For details, see 3GPP TS 36.101. If the value is 0, combination band 4 is invalid. This parameter applies only to LTE FDD and LTE TDD.
Combination Band 1 Bandwidth

Indicates the bandwidth set supported in the first band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the first band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

This parameter applies only to LTE FDD and LTE TDD.

If a bandwidth is selected, the carrier with this bandwidth in the third band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Indicates combination band 5. For details, see 3GPP TS 36.101. If the value is 0, combination band 5 is invalid. This parameter applies only to LTE FDD and LTE TDD.

Indicates the bandwidth set supported in the fifth band in the band combination. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
Combination Status

Indicates whether the private CA band combination conflicts with solidified CA band combinations supported by an eNodeB. The solidified CA band combinations supported by the eNodeB include the solidified private CA band combinations and 3GPP-defined CA band combinations of the related protocol version that the eNodeB complies with. If a conflict occurs, the eNodeB preferentially uses the private CA band combination configured in the PrivateCaBandComb MO to match with the CA capabilities of UEs. For details about the solidified CA band combinations supported by the eNodeB, see carrier aggregation feature parameter description. This parameter applies only to LTE FDD and LTE TDD.
