Emc

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-Emc

Description

An Emc MO consists of parameters related to emergency calls. The parameters include the switches that control whether an operator supports emergency calls and provide the ARP values of bearers when emergency call is enabled.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator
  • Relation with the CnOperator MO:
    • If a CnOperator MO is configured, the Emc MO that references CnOperatorId in the CnOperator MO must exist.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST EMC

Use this command to list the emergency call configuration.
MOD EMC

Use this command to modify the emergency call configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.
Emergency call enabled switch

Indicates whether the operator supports emergency calls. It is recommended that this parameter be set to a value in accordance with the actual emergency call capability of the operator. This parameter applies only to LTE FDD and LTE TDD.
Emergency call enabled switch in limited mode

Indicates whether the operator supports emergency calls initiated by UEs in the limited service state. This parameter applies only to LTE FDD and LTE TDD.
The ARP of EMC dedicated bearer

Indicates the Allocation and Retention Priority (ARP) value of the dedicated bearer for an emergency call. This parameter applies only to LTE FDD and LTE TDD.
The ARP of EMC default bearer

Indicates the Allocation and Retention Priority (ARP) value of the default bearer for an emergency call. This parameter applies only to LTE FDD and LTE TDD.
Emergency Call Optimization Switch

Indicates whether to enable optimization functions of emergency calls.

TM_RESTRICTION_DISABLE_SW: Indicates whether to cancel TM mode selection restriction for emergency calls. If this option is selected, emergency calls do not always use TM2 but use the same TM mode as common calls. If this option is deselected, emergency calls always use TM2 in non-single-port scenarios. This parameter applies only to LTE FDD and LTE TDD.
