eNBLicenseAlmThd

+-NE
  +-eNodeBFunction
    +-eNBLicenseAlmThd

Description

The eNBLicenseAlmThd MO consists of parameters related to ALM-26812 System Dynamic Traffic Exceeding Licensed Limit in an eNodeB. The parameters include intervals for detecting and clearing this alarm and thresholds for generating and clearing this alarm. Currently, this MO applies only to license control items "Throughput Capacity", "RRC Connected User", "eMTC BHCA", "NB-IoT BHCA", "eMTC BDCA", and "NB-IoT BDCA", specifying the licensed traffic throughput, the licensed number of RRC_CONNECTED UEs, and the licensed number of successfully accessed UEs, respectively.

Effective Scenario

Immediately

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ENBLICENSEALMTHD

Use this command to query the license alarm threshold and detection period. Currently, this command applies to the following license items: "Throughput Capacity", "RRC Connected User","eMTC BHCA","NB-IoT BHCA","eMTC BDCA"and"NB-IoT BDCA". The related alarm is System Dynamic Traffic Exceeding Licensed Limit.
SET ENBLICENSEALMTHD

Use this command to modify interval and threshold parameter settings related to ALM-26812 System Dynamic Traffic Exceeding Licensed Limit. Currently, this command applies only to license control items "Throughput Capacity", "RRC Connected User", "eMTC BHCA", "NB-IoT BHCA", "eMTC BDCA", and "NB-IoT BDCA".

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
OPRD

Indicates the license alarm detection period. The eNodeB checks license control items in each period and reports a license-related alarm if the corresponding reporting condition is met.
OTHD

Indicates the license alarm reporting threshold. A license alarm is reported if the proportion of the actually used value to the allocated value of the license control item exceeds this threshold.
RPRD

Indicates the license alarm clearing period. During this period, the eNodeB checks license control items and clears license alarms if the condition for clearing license alarms is met.
RTHD

Indicates the license alarm clearing threshold. A license alarm is cleared if the proportion of the actually used value to the allocated value of the license control item is below this threshold. If this parameter is set to 0, the capacity license alarm must be cleared manually.
