ScPolicy

+-NE
  +-eNodeBFunction
    +-ScPolicy

Description

The ScPolicy MO consists of parameters related to the service classification (SC) policy, including the SC algorithm switch and other settings.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the BRDRESASSIGNMENT MO:
    • If the SC_SERVICE_IDENTITY_SW option of ScAlgoSwitch in the ScPolicy MO is selected, the BRDASSIGNMENT in the BRDRESASSIGNMENT MO cannot be set to MODE2.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP SCSTATE

Use this command to query the running status of the SC component.
LST SCPOLICY

Use this command to list the configuration of the SC policy.
MOD SCPOLICY

Use this command to modify the configuration of the SC policy.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SC Algorithm Switch

Indicates the general switch of the service classification (SC) algorithm. This parameter provides the following options:

SC_SERVICE_IDENTITY_SW: The eNodeB identifies services based on service characteristics only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SC_MODULE_LOAD_SW: The eNodeB identifies and measures services of specified UEs when operators use end-to-end UE tracing only if this option is selected.

SC_DEFAULT_DNS_DISABLE_SW: If this option is selected, the default DNS does not take effect. If this option is deselected, the default DNS takes effect.

This option applies only to LTE FDD and LTE TDD.

SC_SUPPORT_IPV6_SW: If this option is selected, the SC module supports both the IPv6 and IPv4 protocols. Otherwise, the SC module supports only the IPv4 protocol. This option applies only to LTE FDD and LTE TDD.

LOW_LATENCY_QCI_SC_LOAD_SW: If this option is selected, the eNodeB loads service identification based on service characteristics for services of bearers with QCIs for which the LowLatencyFlag parameter in the CellQciPara is set to TRUE. In this case, the eNodeB identifies and measures these services. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.
Video Initial Buffer Time

Indicates the evaluation time of video initial caching. This parameter applies only to LTE FDD and LTE TDD.
Video SYN-ACK to ACK Delay Threshold

Indicates the threshold of delays between SYN-ACK packets and ACK packets in the three-way handshake processes of video services. If the delay between a SYN-ACK packet and an ACK packet in the three-way handshake process of a video service in a cell exceeds the threshold, the L.Exp.Video.Time.SynackToAck.OverThld.Num counter is incremented by 1. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
SC Run State

Indicates the SC running status on a board. This parameter applies only to LTE FDD and LTE TDD.
SC Abnormal Cause

Indicates the reason why the SC status is abnormal. This parameter applies only to LTE FDD and LTE TDD.
SC Rule File Loading Error

Indicates the loading error information about the rule files. This parameter applies only to LTE FDD and LTE TDD.
SC Running Rule File Version

Indicates the version of the rule files running on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
SC Software Version

Indicates the software version of SC. This parameter applies only to LTE FDD and LTE TDD.
