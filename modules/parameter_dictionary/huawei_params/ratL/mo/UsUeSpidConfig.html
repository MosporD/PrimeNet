UsUeSpidConfig

+-NE
  +-eNodeBFunction
    +-UsUeSpidConfig

Description

A UsUeSpidConfig MO consists of parameters related to an SPID of unlimited-service (US) UEs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD USUESPIDCONFIG

Use this command to add an SPID for US UEs.
LST USUESPIDCONFIG

Use this command to list the SPID of US UEs.
RMV USUESPIDCONFIG

Use this command to remove an SPID of US UEs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
US UE SPID

Indicates the SPID of unlimited-service (US) UEs. This parameter applies only to LTE FDD and LTE TDD.
