FddResMode

+-NE
  +-eNodeBFunction
    +-FddResMode

Description

The FddResMode MO consists of parameters related to operating modes of LTE FDD resources in the eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the eNodeBResModeAlgo and TddResModeSwitch MOs:
    • If the BbpResAutoConfigSw parameter in the eNodeBResModeAlgo MO is set to ON, both the BbResExclusiveSwitch parameter in the TddResModeSwitch MO and the BbResExclusiveSwitch parameter in the FddResMode MO cannot be set to ON_WITH_BIND.
    • If the BbpResAutoConfigSw parameter in the eNodeBResModeAlgo MO is set to ON_BIND, both the BbResExclusiveSwitch parameter in the TddResModeSwitch MO and the BbResExclusiveSwitch parameter in the FddResMode MO can only be set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
BbResCapacityMode

Indicates the operating mode of LBBPd for LTE FDD in the eNodeB.

If this parameter is set to NORMAL, the number of cells that can be established on the LBBP and features supported by the LBBP remain unchanged.

The parameter value LBBP_LARGE_CAPACITY is applicable only to LBBPd3 boards. With the LBBP_LARGE_CAPACITY setting, an LBBPd3 supports a larger number of cells but features are adversely affected. Before setting this parameter to LBBP_LARGE_CAPACITY, disable ultra-high speed mobility, extended CP, intra-subframe frequency hopping, and PUCCH-based uplink timing. All cells established on the LBBPd3 are automatically reactivated after this parameter is set to LBBP_LARGE_CAPACITY. If PUCCH-based uplink timing is enabled and this parameter is set to LBBP_LARGE_CAPACITY, the feature does not take effect after the cells are reactivated. If ultra-high speed mobility, extended CP, and intra-subframe frequency hopping are enabled and then this parameter is set to LBBP_LARGE_CAPACITY, the cells cannot be reactivated.

This parameter applies only to LTE FDD and NB-IoT.
Baseband Equipment Exclusive Switch

Indicates whether the cell sector equipment, PRB sector equipment or cell sector equipment group that is not bound to a piece of baseband equipment can be set up on this baseband equipment to which other cell sector equipment, PRB sector equipment, or cell sector equipment group has been bound. If this parameter is set to OFF and cell sector equipment, PRB sector equipment or a cell sector equipment group is bound to a piece of baseband equipment, the cell sector equipment, PRB sector equipment or cell sector equipment group bound to or not bound to this piece of baseband equipment can be set up on this baseband equipment. If this parameter is set to ON and cell sector equipment, PRB sector equipment or a cell sector equipment group is bound to a piece of baseband equipment, the cell sector equipment, PRB sector equipment or cell sector equipment group not bound to this piece of baseband equipment cannot be set up on this baseband equipment. If this parameter is set to ON_WITH_BIND and cell sector equipment, PRB sector equipment, or a cell sector equipment group is bound to a piece of baseband equipment, then: (a) cells that are bound to this baseband equipment can be set up on other baseband equipment to which other cells are bound, on condition that this baseband equipment is faulty and all cells not bound to this baseband equipment have been activated; (b) cells that are not bound to this baseband equipment cannot be set up on this baseband equipment. This parameter applies to LTE FDD and NB-IoT.
