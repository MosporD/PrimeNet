LaaExternalCell

+-NE
  +-eNodeBFunction
    +-LaaExternalCell

Description

The LaaExternalCell MO consists of parameters used to specify information about an inter-eNodeB LAA cell that can be aggregated with cells served by the local eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the eNodeBFunction MO:
    • The eNodeB ID specified by the EnodebId parameter in an LaaExternalCell MO must be different from the eNodeB ID specified by the eNodeBId parameter in the eNodeBFunction MO.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the MCC of the external LAA cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Mobile Network Code

Indicates the MNC of a neighboring LAA cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
eNodeB ID

Indicates the ID of the eNodeB serving the external LAA cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID. The eNodeB ID is the most significant 20 bits of the E-UTRAN cell ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the cell ID of an external LAA cell. It uniquely identifies an LAA cell in the eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID. The cell ID is the least significant eight bits of the E-UTRAN cell ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Tracking Area Code

Indicates the TAC of the external LAA cell. 3GPP specifications stipulate that the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration.
Table 3 Dynamic parameters

Parameter

Description
Physical Cell ID

Indicates the physical cell ID of the external LAA cell. For details, see 3GPP TS 36.331.
Downlink EARFCN

Indicates the EARFCN of the external LAA cell. This parameter applies only to LTE FDD and LTE TDD.
LAA External Cell Status

Indicates the status of the external LAA cell. This parameter applies only to LTE FDD and LTE TDD.

The status can be:

AVAILABLE

UNAVAILABLE

The cause of unavailability can be any of the following: The external LAA cell is not activated, the external LAA cell is removed, and the link is abnormal.
