RruJointCalParaCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-RruJointCalParaCfg

Description

The RruJointCalParaCfg MO consists of parameters related to TX channels calibration for a cell with four TX antennas and combined RRUs equipped with two channels each, such as parameters TxChnCalSwitch, TxChnCalPeriod, and TxChnCalTime.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • When the NbCellFlag and TxRxMode parameters in a Cell MO are set to TRUE and 4T4R, respectively, the TxChnCalSwitch parameter in the RruJointCalParaCfg under the Cell MO must be set to OFF.
    • The UlCyclicPrefix and DlCyclicPrefix parameters in a Cell MO must be set to NORMAL_CP when the AauPassivePortCalibPeriod parameter in the RruJointCalParaCfg MO is not set to 0.
  • Relation with the RruJointCalParaCfg MO:
    • The TxChnCalSwitch parameter in an RruJointCalParaCfg MO must be set to OFF when the AauPassivePortCalibPeriod parameter in this RruJointCalParaCfg MO is not set to 0.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Joint Channel Calibration Switch

Indicates whether to enable joint TX channel calibration for a 4T4R or 4T8R cell served by a combined RRU. If this parameter is set to ON for a cell, initial channel calibration is started after the cell is activated and then channel calibration is performed periodically for the cell. If this parameter is set to OFF for a cell, channel calibration is disabled for the cell. If the setting of this parameter is changed from ON to OFF during normal operating of a cell, channel calibration is stopped. If the setting of this parameter is changed from OFF to ON during normal operating of a cell, initial channel calibration is started and then channel calibration is performed periodically for the cell. This parameter applies only to LTE FDD.
Joint Channel Periodic Calibration Time

Indicates the local time to perform periodic TX channel calibration in a cell with combined RRUs and four TX antennas. This parameter works together with the TxChnCalPeriod parameter to determine the time to perform periodic TX channel calibration. For details, see descriptions of the TxChnCalPeriod parameter. This parameter applies only to LTE FDD and LTE TDD.
Joint Channel Calibration Period

Indicates the interval at which periodic TX channel calibration is performed in a cell with combined RRUs and four TX antennas. This parameter works together with the TxChnCalTime parameter to determine the time to perform periodic TX channel calibration. The following examples clarify the criteria:

(1) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 48 (indicating that the TX channel calibration period is 24 hours), periodic TX channel calibration is performed at 03:00:00 every day.

(2) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 24 (indicating that the TX channel calibration period is 12 hours), periodic TX channel calibration is performed at 03:00:00 and 15:00:00 every day.

(3) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 96 (indicating that the TX channel calibration period is 48 hours), periodic TX channel calibration is performed at 03:00:00 every other day. This parameter applies only to LTE FDD and LTE TDD.
Aau Passive Port Calibration Period

Indicates whether to enable AAU passive port channel calibration in 3D beamforming, RPCU-based SDA antenna channel calibration, and channel calibration for SDL cells, and also indicates the period for periodic calibration when calibration is enabled. The calibration is enabled only when this parameter is set to a non-zero value. If this parameter is set to 65535, the eNodeB performs periodic calibration using a short period, which is longer than or equal to 1 minute and shorter than 5 minutes. If this parameter is set to a non-zero value other than 65535, the eNodeB performs periodic calibration using the period specified by the parameter value. This parameter applies only to LTE FDD. RPCU-based SDA antenna channel calibration cycle is not recommended for 65535.
Table 3 Dynamic parameters

Parameter

Description
Calibration Signal CINR

Indicates the carrier-to-interference-and-noise ratio (CINR) of calibrated signals between two RRUs. This parameter applies only to LTE TDD cells.
