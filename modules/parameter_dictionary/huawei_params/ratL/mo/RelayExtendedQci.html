RelayExtendedQci

+-NE
  +-eNodeBFunction
    +-RelayExtendedQci

Description

A RelayExtendedQci MO consists of extended QCI parameters used for and specific to relay features. After an RRN successfully accesses the network, the eNodeB sets up a bearer with the extended QCI specified by this MO for the RRN.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoSwitch MO:
    • If the OutOfBandRelaySwitch or InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, one and only one RelayExtendedQci MO instance with DefaultBearerInd set to YES must be configured.
  • Relation with the RlcPdcpParaGroup MO:
    • When CatType is set to LTE, The RlcPdcpParaGroup MO corresponding to the RlcPdcpParaGroupId parameter in the RelayExtendedQci MO must be configured.
  • Relation with the EuRrn MO:
    • If the SchType parameter is set to WFQ_L2OM in a RelayExtendedQci MO, the RrnType parameter in the EuRrn MO cannot be set to RRN3201 or RRN3901.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Extended QoS Class Indication

Indicates the extended QCI of an E-RAB on an RRN. After an RRN successfully accesses the network, the eNodeB sets up a bearer with the extended QCI specified by this parameter for the RRN. QCIs 65, 66, 69, 70, 75, and 79 are standardized QCIs, and therefore values 65, 66, 69, 70, 75, and 79 are not recommended for this parameter. Otherwise, services of these QCIs are affected. This parameter applies only to LTE FDD and LTE TDD.
Default Bearer Indication

Indicates whether a bearer on an RRN is a default bearer. A maximum of one default bearer can be configured for an RRN. This parameter applies only to LTE FDD and LTE TDD.
RLC PDCP parameter group ID

Indicates the ID of an RLC/PDCP parameter group. This parameter applies only to LTE FDD and LTE TDD.
Schedule Type

Indicates the scheduling type of E-RABs of an RRN. The value PQ indicates that scheduling based on the absolute priority is adopted for a bearer. The value WFQ indicates that fair scheduling based on the value of the UlSchWeight or DlSchWeight parameter in the RelayExtendedQci MO is adopted for a bearer. This scheduling type is used for service data carried on the RRN. The value WFQ_L2OM indicates that fair scheduling based on the value of the UlSchWeight or DlSchWeight parameter in the RelayExtendedQci MO is adopted for a bearer in the L2OM channel. This scheduling type is used for OM data of the RRN. The priority for a PQ bearer is always higher than that for a WFQ bearer. This parameter applies only to LTE FDD and LTE TDD.
Uplink Schedule Weight

Indicates the weight factor of uplink scheduling resource allocation for bearers with the scheduling type of WFQ. This parameter is valid when the SchedulingType parameter is set to WFQ or WFQ_L2OM. This parameter applies only to LTE FDD and LTE TDD.
Downlink Schedule Weight

Indicates the weight factor of downlink scheduling resource allocation for bearers with the scheduling type of WFQ. This parameter is valid when the SchedulingType parameter is set to WFQ or WFQ_L2OM. This parameter applies only to LTE FDD and LTE TDD.
Dscp Lower

Indicates the lower limit of the DSCP value contained in the IP packets mapped to a bearer on an RRN. This parameter applies only to LTE FDD and LTE TDD.
Dscp Upper

Indicates the upper limit of the DSCP value contained in the IP packets mapped to a bearer on an RRN. This parameter applies only to LTE FDD and LTE TDD.
RRN Pre-allocation Weight

Indicates the service preallocation weight of the RRN. If the SchedulingType parameter is set to PQ, the preallocation weight of services corresponding to the priority queuing (PQ) is used. If the SchedulingType parameter is set to WFQ or WFQ_L2OM, the preallocation weight of services corresponding to the largest weighted fair queuing (WFQ) is used. Preallocation possibilities are proportional to preallocation weights. When resources are limited, the preallocation weight affects the preallocation possibilities for an RRN. This parameter applies only to LTE FDD and LTE TDD.
PQ Type

Indicates the PQ bearer type when the SchType parameter is set to PQ(PQ). The value L3PQ indicates the PQ bearer of L3 Relay. The value L2OM indicates the RRN O&M PQ bearer of L2 Relay. The value L2HIGH indicates the high-priority PQ bearer of L2 Relay. The value L2LOW indicates the low-priority PQ bearer of L2 Relay. A maximum of one bearer of each type can be configured. This parameter applies only to LTE FDD and LTE TDD.
