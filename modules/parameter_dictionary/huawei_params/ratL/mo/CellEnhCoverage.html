CellEnhCoverage

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellEnhCoverage

Description

The CellEnhCoverage MO consists of parameters used to set the switch and thresholds for the channel coverage enhancement algorithm.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoExtSwitch and CellAlgoSwitch MOs:
    • The PUSCH_JR_COVERAGE_ENH_SW option of the EnhChCoverageSw parameter in a CellEnhCoverage MO can be selected only when the UlCoverageEnhancementSw parameter in the corresponding CellAlgoExtSwitch MO is set to ON and the UlJointReceptionSwitch option of the UplinkCompSwitch parameter in the corresponding CellAlgoSwitch MO is selected.
  • Relation with the CellAlgoExtSwitch MO:
    • The PRACH_PUCCH_COVERAGE_ENH_SW option of the EnhChCoverageSw parameter in a CellEnhCoverage MO can be selected only when the UlCoverageEnhancementSw parameter in the corresponding CellAlgoExtSwitch MO is set to ON.
    • The TTIB_SMART_RETRANS_SW option of the EnhChCoverageSw parameter in a CellEnhCoverage MO can be selected only when the UlCoverageEnhancementSw parameter in the corresponding CellAlgoExtSwitch MO is set to ON.
  • Relation with the CellAlgoSwitch MO:
    • The PUSCH_JR_COVERAGE_ENH_SW option of the EnhChCoverageSw parameter in a CellEnhCoverage MO can be selected only when all the following conditions are met: The UL_HIGH_ORDER_COMP_FOR_2R option of the UlHighOrderCompSwitch parameter in the corresponding CellAlgoSwitch MO is deselected, and the EnhancedUlCompSwitch and WideRangeCompSwitch options of the UplinkCompSwitch parameter in this CellAlgoSwitch MO are also deselected.
  • Relation with the CellRbReserve MO:
    • The PUSCH_JR_COVERAGE_ENH_SW option of the EnhChCoverageSw parameter in the CellEnhCoverage MO can be selected only when the RbRsvMode parameter in a CellRbReserve MO is set to COVERAGE_ENH_RB_RESERVED.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
Channel Coverage Enhancement Switch

Indicates whether to enable channel coverage enhancement.

PRACH_PUCCH_COVERAGE_ENH_SW: Indicates whether to enable coverage enhancement for the PRACH and PUCCH. This option is valid when the UlCoverageEnhancementSw parameter is set to ON. This option applies only to LTE FDD.

PUSCH_JR_COVERAGE_ENH_SW: Indicates whether to enable UL CoMP for UEs for which coverage is enhanced. This option is valid when the UlCoverageEnhancementSw parameter is set to ON and the UlJointReceptionSwitch option of the UplinkCompSwitch parameter is selected. UL CoMP is supported for UEs for which coverage is enhanced only if the PUSCH_JR_COVERAGE_ENH_SW option is selected. This option applies only to LTE FDD.

TTIB_SMART_RETRANS_SW: Indicates whether to enable intelligent retransmission for UEs in the TTI bundling state. This option is valid when the UlCoverageEnhancementSw parameter is set to ON. This option applies only to LTE FDD.
