SfnEdgeRruRelation

+-NE
  +-eNodeBFunction
    +-Cell
      +-SfnEdgeRruRelation

Description

An SfnEdgeRruRelation MO consists of parameters related to the configurations of neighbor relationships between physical cells in neighboring SFN cell edges. Parameter settings in this MO take effect when super cell combination is enabled. This MO applies only to LTE FDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the EutranIntraFreqNCell, EutranExternalCell, Cell, and CellAlgoSwitch MOs:
    • PhyCellId in the EutranExternalCell MO associated with an EutranIntraFreqNCell MO (representing an inter-eNodeB intra-frequency neighboring cell of the local cell) can be the same as PhyCellId in the Cell MO representing the local cell if both conditions are met: (1) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO is selected in the local cell; (2) All values of parameters Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO are the same with values of parameters Mcc, Mnc, EnodeBId, and NeighborCellId in at least one SfnEdgeRruRelation MO configured for the local cell. If either condition is not met, PhyCellId in the EutranExternalCell MO cannot be the same as PhyCellId in the Cell MO.
  • Relation with the EutranIntraFreqNCell, Cell, and CellAlgoSwitch MOs:
    • PhyCellId in the Cell MO representing the local cell can be the same as PhyCellId in the Cell MO associated with the EutranIntraFreqNCell MO (representing an intra-eNodeB inter-frequency neighboring cell of the local cell) if both conditions are met: (1) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO is selected in the local cell; (2) All values of parameters Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO are the same with values of parameters Mcc, Mnc, EnodeBId, and NeighborCellId in at least one SfnEdgeRruRelation MO configured for the local cell. If either condition is not met, values of PhyCellId in the two Cell MOs cannot be the same.
  • Relation with the CellAlgoSwitch MO:
    • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, one or more SfnEdgeRruRelation MOs must have been configured for the cell.
  • Relation with the Cell MO:
    • A maximum of two SfnEdgeRruRelation MO with the same Cell MO.
  • Relation with the eUCellSectorEqm MO:
    • LocalCellId and SectorEqmId in a SfnEdgeRruRelation MO must have been configured in the eUCellSectorEqm MO.
  • Relation with the Cell, eUCellSectorEqm, and eNodeBFunction MOs:
    • If eNodeBId in the SfnEdgeRruRelation MO is equal to eNodeBId in the eNodeBFunction MO, the Cell MO corresponding to NeighborCellId must already exist and be other cells, and eUCellSectorEqm MO belong to this cell corresponding to NeighborSectorEqmId should exist.
  • Relation with the CnOperator MO:
    • Mcc and Mnc in SfnEdgeRruRelation MO must be set to the same values as Mcc and Mnc in CnOperator MO that represents the primary operator.
  • Relation with the SfnEdgeRruRelation MO:
    • Each SfnEdgeRruRelation MO must have a unique value of eNodeBId and NeighborCellId for the same cell.
    • Each SfnEdgeRruRelation MO must have a unique value of eNodeBId, NeighborCellId and NeighborSectorEqmId.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SFNEDGERRURELATION

Use this command to add a relationship between RRUs in edges of neighboring SFN cells.
DSP SFNEDGERRURELATION

Use this command to query the configuration status and reasons for abnormal configurations of neighboring SFN cells in a super combined cell.
LST SFNEDGERRURELATION

Use this command to list parameters related to relationship between RRUs in edges of neighboring SFN cells.
MOD SFNEDGERRURELATION

Use this command to modify parameters related to relationships between RRUs in edges of neighboring SFN cells.
RMV SFNEDGERRURELATION

Use this command to remove a relationship between RRUs in edges of neighboring SFN cells.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.
Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment used by an SFN cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to LTE FDD.
Mobile Country Code

Indicates the MCC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD.
Mobile Network Code

Indicates the MNC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD.
eNodeB ID

Indicates the eNodeB ID of a neighboring SFN cell. This parameter applies only to LTE FDD.
Neighbor Cell ID

Indicates the ID of a neighboring SFN cell. This parameter applies only to LTE FDD.
Neighbor Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment of a neighboring SFN cell. This parameter applies only to LTE FDD.
