CellSiMap

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSiMap

Description

The CellSiMap MO consists of the parameters related to the mapping between the system information block (SIB) and SI algorithm. It ensures the coverage of system broadcast and provides configurable interfaces of system broadcast parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the eUCellSectorEqm, Cell, and CellEmtcAlgo MOs:
    • The ForbidCellSiSwitch option of the SiSwitch parameter in the CellSiMap MO can be selected only when the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, or when all the following conditions are met: the TxRxMode parameter in the Cell MO is set to 1T1R, 1T2R, 2T2R, 2T4R, or 4T4R, or 8T8R, or 32T32R, or 64T64R, the WorkMode parameter in the Cell MO is set to UL_DL, the NbCellFlag parameter in the Cell MO is set to FALSE, and the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO under the Cell MO is deselected.
  • Relation with the Cell, SectorSplitCell, and SectorSplitGroup MOs:
    • If the value of CellActiveState in the Cell MO for a cell is CELL_ACTIVE and this cell is added to a sector split group specified by a SectorSplitGroup MO, the setting of the ForbidCellSiSwitch option of SiSwitch in the CellSiMap MOs for all cells corresponding to the SectorSplitCell MOs under the SectorSplitGroup MO must be the same.
  • Relation with the Cell and CellIntelAmcConfig MOs:
    • When the FddTddInd parameter in a Cell MO is set to CELL_FDD, and the ForbidCellSiSwitch option of the SiSwitch parameter in a CellSiMap MO is set to ON, the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO must be deselected under the same cell.
  • Relation with the CellShutdown and Cell MOs:
    • If the FddTddInd parameter in a CELL MO is set to CELL_FDD, the CellShutdownSwitch parameter in the CellShutdown MO under this Cell MO is set to a value other than OFF, and at least one of the UlPrbThd and DlPrbThd parameters in this CellShutdown MO is set to 0, then the ForbidCellSiSwitch option of the SiSwitch parameter in the CellSiMap MO under the Cell MO cannot be selected.
  • Relation with the CellAlgoExtSwitch and CellHoParaCfg MOs:
    • If the INTER_RAT_MOBILITY_TO_NR_SW option of the HoAllowedSwitch parameter in the CellAlgoExtSwitch MO is selected, at least one option among the Sib24Switch option of the SiSwitch parameter in the CellSiMap MO and the NrRedirectSwitch and NrHoSwitch options of the HoModeSwitch parameter in the CellHoParaCfg MO is selected.

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.
SIB mapping SI algorithm switch

Indicates whether the mapping from SIBs to SI messages is enabled. If it is disabled, a fixed configuration is used for the mapping from SIBs to SI messages and the SI window size. This parameter applies only to LTE FDD and LTE TDD.

ETWS PN message duration time

Indicates the duration of the primary notification (PN) broadcast for the Earthquake and Tsunami Warning System (ETWS). This parameter applies only to LTE FDD and LTE TDD.
ETWS SN message overlap policy

Indicates the policy of processing repeated secondary notification (SN) broadcasts for the Earthquake and Tsunami Warning System (ETWS). A repeated SN is a second SN that has the same IEs Message Identifier and Serial Number as those in the first SN. The value MERGE indicates that the eNodeB stops broadcasting the first SN and then broadcasts the second SN. The value DISCARD indicates that the eNodeB ignores the second SN and continues broadcasting the first SN. This parameter applies only to LTE FDD and LTE TDD.
ETWS PN message overlap policy

Indicates the policy of processing repeated primary notification (PN) broadcasts for the Earthquake and Tsunami Warning System (ETWS). A repeated PN is a second PN that has the same Message Identifier and Serial Number IEs as those in the first PN. If this parameter is set to MERGE, the eNodeB stops broadcasting the first PN and starts broadcasting the second PN. If this parameter is set to DISCARD, the eNodeB discards the second PN and continues broadcasting the first PN. This parameter applies only to LTE FDD and LTE TDD.
SIB12 period

Indicates the transmission period for system information block type 12 (SIB12). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Effective code rate for SI transmission

Indicates the code rate of system information transmission. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SIB13 period

Indicates the transmission period for system information block type 13 (SIB13). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SIB15 period

Indicates the transmission period for system information block type 15 (SIB15). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SIB16 period

Indicates the transmission period for system information block type 16 (SIB16). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SIB Transmission Control Switch

Indicates whether the eNodeB uses a new mechanism to send system information block (SIB) messages. When this parameter is set to OFF, the eNodeB uses the default mechanism to send SIB messages. When this parameter is set to ON, the eNodeB uses the new mechanism to send SIB messages. In this case, the probability of SIB repetitions decreases. As a result, fewer PDCCH resources are consumed for FDD and TDD and fewer downlink resources are consumed for NB-IoT.
Cell System Information Switch

Indicates the system information broadcast policy for the cell.

DlOnlyCellSiSwitch(DlOnlyCellSiSwitch): Indicates whether to broadcast system information in the cell if the WorkMode parameter in the Cell MO is not set to UL_DL for the cell. System information is broadcast in the cell only if this option is selected. This option applies only to cells for which the WorkMode parameter is not set to UL_DL. This option applies only to LTE FDD.

Sib6Switch(Sib6Switch): Indicates whether to broadcast SIB6. If this option is deselected, SIB6 is not broadcast. If this option is selected and the CELLRESELUTRAN MO is created, SIB6 is broadcast. For details about the contents of SIB6, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

Sib7Switch(Sib7Switch): Indicates whether to broadcast SIB7. If this option is deselected, SIB7 is not broadcast. If this option is selected and the CELLRESELGERAN MO is created, SIB7 is broadcast. For details about the contents of SIB7, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

ForbidCellSiSwitch: Indicates the information broadcast in the system information of a cell with the WorkMode parameter in the Cell MO being not set to DL_ONLY and related handling for the cell. If this option is deselected, system information is normally broadcast in the cell. If this option is selected, system information broadcast in the cell indicates that the cell is in the barred state, preventing UEs from camping on the cell. In addition, the system does not allow handovers to the cell. This option applies only to LTE FDD and LTE TDD.

Sib24Switch(Sib24Switch): Indicates whether to broadcast SIB24. If this option is deselected, SIB24 is not broadcast. If this option is selected and the CELLRESELTONR MO is created, SIB24 is broadcast. For details about the contents of SIB24, see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.
System Information Scheduling Resource Ratio

Indicates the resource proportion in SI scheduling and controls whether SI-based gap-assisted measurement optimization takes effect. If this parameter is set to 0 (corresponding to the actual value 0), the specified resource proportion in SI scheduling does not take effect and SI-based gap-assisted measurement optimization does not take effect. If this parameter is set to a value within the range of 40 to 100 (corresponding to the actual value within the range of 0.4 to 1.0), the specified resource proportion in SI scheduling and SI-based gap-assisted measurement optimization takes effect to guarantee SI demodulation performance. This parameter applies only to LTE FDD and LTE TDD.
SIB Update Optimization Switch

Indicates whether to enable the optimization scheme switch that controls SIB message update.

SibPagingOptCtrlSwitch: Indicates whether to enable the optimization of paging triggered by system information update. If this option is selected, the optimization scheme takes effect, and the paging cycle is the same as the BCCH modification period. If this option is deselected, the optimization scheme does not take effect, and the paging cycle is occasionally less than the BCCH modification period. This option applies only to LTE FDD and LTE TDD.

Sib12BroadcastOptSwitch: Indicates whether SIB12 messages are broadcast over the air interface during CMAS paging. This option applies only to LTE FDD and LTE TDD.
SIB14 Period

Indicates the transmission period for system information block type 14 (SIB14). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
NB-IoT SIB1 Repetition Number

Indicates the number of current cell's NB-IoT SIB1 repetition times within the period. This parameter applies only to NB-IoT.
NB-IoT SIB2 Period

Indicates the current cell's NB-IoT SIB2 transmission period. This parameter applies only to NB-IoT.
NB-IoT SIB3 Period

Indicates the current cell's NB-IoT SIB3 transmission period. This parameter applies only to NB-IoT.
NB-IoT SIB4 Period

NB-IoT SIB16 Period

Indicates the current cell's NB-IoT SIB16 transmission period. This parameter applies only to NB-IoT.
Sidelink V2X SIB21 Period

Indicates the SIB21 transmission period for sidelink V2X. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
MIB Repetition Control Opt Switch

Indicates whether to enable optimization of repeated MIB transmission. If this parameter is set to OFF, the optimization is disabled. For LTE FDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 9. For LTE TDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 5. If this parameter is set to ON, the optimization is enabled, and the eNodeB transmits MIBs only in subframe 0. This parameter applies only to LTE FDD and LTE TDD.
NB-IoT SIB22 Period

Indicates the NB-IoT SIB22 broadcast period in the current cell. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.
SIB24 period

Indicates the transmission period for system information block type 24(SIB24). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
High Precision Time Serving Switch

Indicates whether to broadcast high-precision time. This parameter specifies the policy of broadcasting time information in SIB16 over the air interface. If this parameter is set to ON, the system broadcasts the time obtained from the clock system. If this parameter is set to OFF, the system broadcasts the local time. This parameter applies only to NB-IoT.
SIB25 period

Indicates whether to broadcast SIB25. This parameter is also used to specify the SIB25 transmission period. If this parameter is set to OFF, the eNodeB does not broadcast SIB25. If this parameter is set to a value other than OFF, the eNodeB broadcasts SIB25 and the transmission period is indicated by the value of this parameter. For details about the period, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
