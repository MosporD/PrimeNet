RlcPdcpParaGroup

+-NE
  +-eNodeBFunction
    +-RlcPdcpParaGroup

Description

An RlcPdcpParaGroup MO consists of parameters related to Radio Link Control (RLC) and Packet Data Convergence Protocol (PDCP).

RLC provides data transmission service for the upper layer.

PDCP provides encryption and integrity protection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoSwitch MO:
    • For all the RlcPdcpParaGroup MOs with the RlcMode parameter set to RlcMode_AM, if the RlcParaAdaptSwitch parameter is set to OFF, the DlRLCStateReportSchDelaySw option of the DlSchSwitch parameter in the CellAlgoSwitch MO cannot be selected.
  • Relation with the QciPara MO:
    • When CatType is set to LTE, RlcPdcpParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to EMTC_MODE_A, EmtcModeARlcParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to EMTC_MODE_B, EmtcModeBRlcParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to NBIOT, NbRlcPdcpParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to NBIOT, NbCe0RlcPdcpParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to NBIOT, NbCe1RlcPdcpParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to EMTC_MODE_A, EmtcModeACl0RlcParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to EMTC_MODE_B, EmtcModeBCl2RlcParaGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to SHORT_TTI, ShortTtiRlcParamGroupId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • When CatType is set to EUTRA_5GC, Eutra5gcRlcPdcpParamGrpId in a QciPara MO must have been set in the associated RlcPdcpParaGroup MO.
    • The RlcPdcpParaGroup MO referenced by the RlcPdcpParaGroupId parameter in the QciPara MO must be configured.
  • Relation with the eNodeBFunction MO:
    • The number of RlcPdcpParaGroup MOs must be from 1 to 241.
  • Relation with the RelayExtendedQci MO:
    • When CatType is set to LTE, The RlcPdcpParaGroup MO corresponding to the RlcPdcpParaGroupId parameter in the RelayExtendedQci MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RLC PDCP parameter group ID

Indicates the ID of the RLC/PDCP parameter group.
Discard timer

Indicates the length of the PDCP discard timer. This parameter applies only to LTE FDD and LTE TDD. For NSA DC UEs for which the NsaDcDefaultBearerMode parameter in the CellQciPara MO is not set to MCG_BEARER_EUTRA_PDCP and E-UTRA/5GC UEs, this parameter can be set to any value and the configured value takes effect. For other UEs, the following values do not take effect: DiscardTimer_10, DiscardTimer_20, DiscardTimer_30, DiscardTimer_40, DiscardTimer_60, DiscardTimer_75, DiscardTimer_200, and DiscardTimer_250. If this parameter is set to one of the preceding values, the eNodeB replaces the configured value with a value that is greater than and closest to the configured value.
RLC-UM or RLC-AM mode

Indicates the RLC transmission mode. Only the AM and UM modes are available. In NB-IoT, the RCL protocols support only the AM mode. This parameter must be set to RlcMode_AM if RLC-related parameters are required in NB-IoT.
MaxretxThreshold for UE

Indicates the maximum number of RLC ARQ retransmissions for UEs, which limits the maximum number of AM PDU retransmissions. When the number of RCL ARQ retransmissions reaches the parameter value, an RRC connection reestablishment procedure is initiated. This option applies only to LTE FDD and LTE TDD.
MaxRetxThreshold for eNodeB

Indicates the maximum number of RLC ARQ retransmissions for the eNodeB, which limits the maximum number of AM PDU retransmissions. When the number of RLC ARQ retransmissions reaches the parameter value, the eNodeB releases the UE. This option applies only to LTE FDD and LTE TDD.
PollByte for UE

Indicates the UE-specific data volume threshold of PDUs to trigger polling. When the transmitted data volume reaches the value of this parameter, the Poll flag is set in the PDU header. This parameter applies only to LTE FDD and LTE TDD.
PollByte for eNodeB

Indicates the eNodeB-specific data volume threshold of PDUs to trigger polling. When the transmitted data volume reaches the value of this parameter, the Poll flag is set in the PDU header. This parameter applies only to LTE FDD and LTE TDD.
PollPdu for UE

Indicates the UE-specific number of PDUs to trigger polling. When the transmitted number of PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. This parameter applies only to LTE FDD and LTE TDD.
PollPdu for eNodeB

Indicates the eNodeB-specific number of PDUs to trigger polling. When the transmitted number of PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. This parameter applies only to LTE FDD and LTE TDD.
Poll retransmit timer for UE

Indicates the length of the Polling PDU retransmission timer for the UE. This parameter applies only to LTE FDD and LTE TDD.
Poll retransmit timer for eNodeB

Indicates the length of the Polling PDU retransmission timer for the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Status prohibit timer for UE

Indicates the length of the UE-specific timer for prohibiting status reporting from the receiver in AM. This parameter applies only to LTE FDD and LTE TDD.
Status prohibit timer for eNodeB

Indicates the length of the eNodeB-specific timer for prohibiting status reporting from the receiver in AM. This parameter applies only to LTE FDD and LTE TDD.
AM reordering timer for UE

Indicates the length of the UE-specific timer for reordering at the receiver in AM.
AM reordering timer for eNodeB

Indicates the length of the eNodeB-specific timer for reordering at the receiver in AM.
UM PDCP-SN size

Indicates the length of a PDCP sequence number of an uplink or downlink DRB in RLC UM. For NSA DC UEs for which the NsaDcDefaultBearerMode parameter in the CellQciPara MO is not set to MCG_BEARER_EUTRA_PDCP and E-UTRA/5GC UEs, the parameter value PdcpSnsize_7bits does not take effect. For other UEs, the parameter value PdcpSnsize_18bits does not take effect. When the configured parameter value does not take effect, the eNodeB preferentially replaces the parameter value with PdcpSnsize_12bits. The value that takes effect depends on UE capability information. This parameter applies only to LTE FDD and LTE TDD.
Uplink RLC-SN size

Indicates the length of a UL RLC sequence number in UM. The length is permanently 10 bits in AM. This parameter applies only to LTE FDD and LTE TDD.
Downlink RLC-SN size

Indicates the length of a downlink RLC sequence number. In AM mode, the parameter value RlcSnSize_size5 does not take effect and the eNodeB automatically replaces it with RlcSnSize_size10. This parameter applies only to LTE FDD and LTE TDD.
UM reordering timer for UE

Indicates the length of the UE-specific timer for reordering at the receiver in UM. This parameter applies only to LTE FDD and LTE TDD.
UM reordering timer for eNodeB

Indicates the length of the eNodeB-specific timer for reordering at the receiver in UM. This parameter applies only to LTE FDD and LTE TDD.
AM PDCP status report required indication

Indicates whether a PDCP status report is required upon handover in AM. This parameter applies only to LTE FDD and LTE TDD.
RLC Parameter Adaptive Switch

Indicates whether to enable adaptive configuration of parameters related to Radio Link Control (RLC).

If this parameter is set to ON, the eNodeB adaptively configures the eNodeB- and UE-specific polling PDU retransmission timer and eNodeB- and UE-specific timer for prohibiting status reporting for UEs that access the eNodeB after the parameter is set. When the number of UEs in a cell exceeds a certain number, the following timers are used: eNodeBPollRtrTimerPreset, eNodeBStatProhTimerPreset, UePollRtrTimerPreset, and UeStatProhTimerPreset. Otherwise, the following timers are used: ENodeBPollRetransmitTimer, ENodeBStatusProhibitTimer, UePollRetransmitTimer, and UeStatusProhibitTimer.

If this parameter is set to OFF, the following timers are used by the UEs and the base station regardless of the number of UEs in the cell: ENodeBPollRetransmitTimer, ENodeBStatusProhibitTimer, UePollRetransmitTimer, and UeStatusProhibitTimer.

If the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected, for a small-bandwidth cell (cell with a bandwidth of 5 MHz, 3 MHz, or 1.4 MHz), this adaptive configuration function is enabled regardless of the RlcParaAdaptSwitch parameter setting. This parameter applies only to LTE FDD and LTE TDD.
Preset eNodeB Poll Retransmit Timer

Indicates the length of the Polling PDU retransmission timer for the eNodeB when the RlcParaAdaptSwitch parameter is set to ON and the number of UEs on the network is large. This parameter applies only to LTE FDD and LTE TDD.
Preset eNodeB Status Prohibit Timer

Indicates the length of the eNodeB-specific timer for prohibiting status reporting from the receiver when the RlcParaAdaptSwitch parameter is set to ON and the number of UEs on the network is large. This parameter applies only to LTE FDD and LTE TDD.
Preset UE Poll Retransmit Timer

Indicates the length of the Polling PDU retransmission timer for the UE when the RlcParaAdaptSwitch parameter is set to ON and the number of UEs on the network is large. This parameter applies only to LTE FDD and LTE TDD.
Preset UE Status Prohibit Timer

Indicates the length of the UE-specific timer for prohibiting status reporting when the RlcParaAdaptSwitch parameter is set to ON and the number of UEs on the network is large. This parameter applies only to LTE FDD and LTE TDD.
Nonsupport Um UE Adaptive Switch

Indicates whether the eNodeB is compatible with the UE that does not support the RLC transmission in unacknowledged mode (UM) mode. Assume that an eNodeB configures the RLC transmission mode to UM mode for QCI 1, 4, 6, 7, 8, or 9, and a UE that does not support the RLC transmission in UM mode attempts to set up bearers of the corresponding QCIs. If this switch is turned on, the eNodeB finds the QCI with the RLC transmission mode set to acknowledged mode (AM) in the sequence of QCIs 9, 8, 6, and 4 and sets up the bearers in the AM mode of the queried QCI. This parameter applies only to LTE FDD and LTE TDD.
Discardtimer Separate Config Switch

Indicates whether to enable separate configuration of the PDCP discard timer for the uplink and downlink.
Downlink PDCP Discard Timer

Indicates the length of the downlink PDCP discard timer in the eNodeB. If PDCP packets have been buffered for a period longer than the timer length, the eNodeB discards the packets. This timer takes effect only on DRBs. This parameter applies only to LTE FDD and LTE TDD. For NSA DC UEs for which the NsaDcDefaultBearerMode parameter in the CellQciPara MO is not set to MCG_BEARER_EUTRA_PDCP and E-UTRA/5GC UEs, this parameter can be set to any value and the configured value takes effect. For other UEs, the following values do not take effect: DiscardTimer_10, DiscardTimer_20, DiscardTimer_30, DiscardTimer_40, DiscardTimer_60, DiscardTimer_75, DiscardTimer_200, and DiscardTimer_250. If this parameter is set to one of the preceding values, the eNodeB replaces the configured value with a value that is greater than and closest to the configured value.
CA UE RLC Parameter Adaptive Threshold

Indicates the threshold used for adaptive selection of RLC parameters for CA UEs.

When the number of UEs connected to the PCell of a CA UE exceeds the threshold, the following parameters take effect on non-GBR bearers in RLC AM for the CA UE: UeAmReorderingTimer, ENodeBAmReorderingTimer, UeStatusProhibitTimer, and ENodeBStatusProhibitTimer. When the number does not exceed the threshold, the parameters that take effect vary as follows:

For the UE in the intra-eNodeB 2CC or 3CC CA state, in the eNodeB-coordination-based 2CC or 3CC state, or in the relaxed-backhaul-based inter-eNodeB CA state:

- CaUeReorderingTimer or UeAmReorderingTimer, whichever parameter with a smaller value

- CaUeReorderingTimer or ENodeBAmReorderingTimer, whichever parameter with a smaller value

- CaUeStatProhTimer or UeStatusProhibitTimer, whichever parameter with a smaller value

- CaUeStatProhTimer or ENodeBStatusProhibitTimer, whichever parameter with a smaller value

For the UE in the intra-eNodeB 4CC or 5CC CA state or in the eNodeB-coordination-based 4CC or 5CC state:

- Dl4cc5ccUeReorderingTimer or UeAmReorderingTimer, whichever parameter with a smaller value

- CaUeReorderingTimer or ENodeBAmReorderingTimer, whichever parameter with a smaller value

- Dl4cc5ccUeStatProhTimer or UeStatusProhibitTimer, whichever parameter with a smaller value

- CaUeStatProhTimer or ENodeBStatusProhibitTimer, whichever parameter with a smaller value

This parameter applies only to LTE FDD and LTE TDD.
CA UE Reordering Timer(ms)

Indicates the length of the reordering timer that applies to non-GBR bearers in RLC AM for CA UEs in the 2CC CA, 3CC CA, and relaxed-backhaul-based CA states in their PCell when the number of UEs in RRC_CONNECTED mode does not exceed the value of CaUeRlcParaAdptiveThd. This option applies only to LTE FDD and LTE TDD.
CA UE Status Prohibit Timer(ms)

Indicates the length of the status reporting prohibition timer that applies to non-GBR bearers in RLC AM for CA UEs in the 2CC CA, 3CC CA, and relaxed-backhaul-based CA states in their PCell when the number of UEs in RRC_CONNECTED mode does not exceed the value of CaUeRlcParaAdptiveThd. This option applies only to LTE FDD and LTE TDD.
AM Mode PDCP SN Length

Indicates the length of a PDCP sequence number in RLC AM. For NSA DC UEs and E-UTRA/5GC UEs, the parameter value AmPdcpSnsize_15bits does not take effect, and the eNodeB preferentially replaces this value with AmPdcpSnsize_18bits. The value that takes effect depends on capabilities of UEs. This parameter applies only to LTE FDD and LTE TDD.
eNodeB Reordering Timer Adaptive

Indicates whether to enable eNodeB receiver-end reordering timer adaptation. The timer length adapts based on the uplink transmission mode (TTI bundling or non-TTI bundling) and the maximum number of uplink HARQ transmissions only if this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.
UE PDCP Reordering Timer

Indicates the length of the UE-specific timer for PDCP reordering. For details, see 3GPP TS 36.331. This parameter is used for detection of PDCP packet loss. If the timer expires, the PDCP packet is regarded as lost, triggering reordering.

This parameter also indicates the length of the UE-specific timer for PDCP reordering when UEs are in the LTE-NR NSA DC state. This parameter is used for reordering PDCP packets in the two data flows based on the sequence numbers before these packets are delivered to the upper layer. This parameter also indicates the length of the UE-specific timer for PDCP reordering when UEs connect to the 5GC and the CatType parameter is set to EUTRA_5GC. For details, see 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD. For NSA DC UEs for which the NsaDcDefaultBearerMode parameter in the CellQciPara MO is not set to MCG_BEARER_EUTRA_PDCP and E-UTRA/5GC UEs, this parameter can be set to any value and the configured value takes effect. For other UEs, the following parameter values do not take effect: ms1, ms2, ms4, ms5, ms8, ms10, ms15, ms30, ms50, ms1000, ms1250, ms1500, ms1750, ms2000, ms2250, ms2500, ms2750, and ms3000. If this parameter is set to one of the preceding values, the eNodeB replaces the configured value with a value that is less than and closest to the configured value.
Category Type

Indicates the UE category type. Other parameters in this MO apply to LTE UEs, eMTC UEs in mode A, eMTC UEs in mode B, NB-IoT UEs, short TTI UEs, and E-UTRA/5GC UEs if this parameter is set to LTE, EMTC_MODE_A, EMTC_MODE_B, NBIOT, SHORT_TTI, and EUTRA_5GC respectively.
NB-IoT PDCP Discard Timer

Indicates the length of the PDCP discard timer. For details about this parameter, see 3GPP TS 36.323. This parameter applies only to NB-IoT.
NB-IoT Downlink PDCP Discard Timer

Indicates the length of the downlink PDCP discard timer in the eNodeB. If PDCP PDUs have been buffered for a period longer than the timer length, the eNodeB discards the PDUs. This timer takes effect only on DRBs. For details about this parameter, see 3GPP TS 36.323. This parameter applies only to NB-IoT.
NB-IoT Poll Retransmit Timer for eNodeB

Indicates the length of the Polling PDU retransmission timer for the eNodeB. For details about this parameter, see 3GPP TS 36.322. This parameter applies only to NB-IoT.
NB-IoT Poll Retransmit Timer for UE

Indicates the length of the Polling PDU retransmission timer for the UE. For details about this parameter, see 3GPP TS 36.322. This parameter applies only to NB-IoT.
Max Retransmission Thld for NB-IoT eNodeB

Indicates the maximum number of RLC ARQ retransmissions for the NB-IoT eNodeB, which limits the maximum number of RLC ARQ retransmissions in AM mode for the NB-IoT eNodeB. When the number of RLC ARQ retransmissions reaches the parameter value, the eNodeB releases the UE. This parameter applies only to NB-IoT.
Max Retransmission Thld for NB-IoT UE

Indicates the maximum number of RLC ARQ retransmissions for NB-IoT UEs, which limits the maximum number of RLC ARQ retransmissions in AM mode for NB-IoT UEs. When the number of RLC ARQ retransmissions reaches the parameter value, the UE initiates an RRC connection reestablishment procedure. This parameter applies only to NB-IoT.
DL Beyond 3CC UE Reordering Timer

Indicates the length of the reordering timer that applies to non-GBR bearers in RLC AM for CA UEs in intra-eNodeB CA or CA based on eNodeB coordination with more than three CCs aggregated when the number of UEs in RRC_CONNECTED mode is less than or equal to the value of the CaUeRlcParaAdptiveThd parameter in their PCell. This parameter applies only to LTE FDD and LTE TDD.
DL Beyond 3CC UE Status Prohibit Timer

Indicates the length of the status reporting prohibition timer that applies to non-GBR bearers in RLC AM for CA UEs in intra-eNodeB CA or CA based on eNodeB coordination with more than three CCs aggregated when the number of UEs in RRC_CONNECTED mode is less than or equal to the value of the CaUeRlcParaAdptiveThd parameter in their PCell. This parameter applies only to LTE FDD and LTE TDD.
eNodeB PDCP Reordering Timer

Indicates the length of the eNodeB-specific timer for PDCP reordering when UEs are in the LTE-NR NSA DC state. This parameter is used for reordering PDCP packets in the two data flows based on the sequence numbers before these packets are transmitted to the upper layer. This parameter also indicates the length of the eNodeB-specific timer for PDCP reordering when UEs connect to the 5GC. For details, see 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD.
PDCP Out Of Order Delivery Indication

Indicates whether the NR PDCP is allowed to send out-of-order packets to the upper layer. If this parameter is set to TRUE, the NR PDCP receive end can directly deliver packets to the upper layer without reordering them. If this parameter is set to FALSE, the NR PDCP receive end must reorder these packets by the PDCP sequence numbers before these packets are transmitted to the upper layer. For details, see 3GPP TS 38.323. This parameter takes effect only when CatType is set to EUTRA_5GC. This parameter applies only to LTE FDD and LTE TDD.
eNodeB PDCP Reordering Switch

Indicates whether the base station supports PDCP reordering for NSA UEs in the following scenarios: 1. The NsaDcDefaultBearerMode parameter is set to MCG_BEARER. 2. The NsaDcDefaultBearerMode parameter is set to MCG_SPLIT_BEARER and no SCGs are added for the UEs. 3. The NsaDcDefaultBearerMode parameter is set to SCG_SPLIT_BEARER and no SCGs are added for the UEs. If this switch is turned on, the eNodeB supports PDCP reordering in the preceding scenarios. If this switch is turned off, the eNodeB does not support PDCP reordering in the preceding scenarios. This parameter applies only to LTE FDD and LTE TDD.
