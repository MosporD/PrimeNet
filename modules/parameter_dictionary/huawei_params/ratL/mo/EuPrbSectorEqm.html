EuPrbSectorEqm

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-EuPrbSectorEqm

Description

An EuPrbSectorEqm MO consists of parameters used to specify the sector equipment and baseband equipment used by PRBs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Prb
  • Relation with the Cell, eUCellSectorEqm, EuSectorEqmGroup, and EuPrbSectorEqmGroup MOs:
    • In a Cell MO, if MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, and the value of CellActiveState is CELL_ACTIVE: When NbCellFlag is set to FALSE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of eUCellSectorEqm MOs and EuSectorEqmGroup MOs under this Cell MO; when NbCellFlag is set to TRUE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of EuPrbSectorEqm MOs and EuPrbSectorEqmGroup MOs under all Prb MOs that are under this Cell MO.
    • When FddTddInd in a Cell MO is set to CELL_FDD, MultiRruCellFlag and MultiRruCellMode in the Cell MO are set to BOOLEAN_TRUE and SFN, if NbCellFlag is set to FALSE, at most eight eUCellSectorEqm and EuSectorEqmGroup MOs can be configured under the Cell MO, if NbCellFlag is set to TRUE, at most sixteen EuPrbSectorEqm and EuPrbSectorEqmGroup MOs can be configured under the Cell MO.
    • In a Cell MO, if NbCellFlag is TRUE, eUCellSectorEqm and EuSectorEqmGroup cannot be configured under the Cell, if NbCellFlag is FALSE, EuPrbSectorEqm and EuPrbSectorEqmGroup cannot be configured under the Cell.
  • Relation with the Cell and eUCellSectorEqm MOs:
    • A maximum of eight eUCellSectorEqm or sixteen EuPrbSectorEqm can be configured for each Cell in which MultiRruCellMode is not set to MPRU_AGGREGATION or CELL_COMBINATION.
  • Relation with the Cell, Prb, and EuPrbSectorEqmGroup MOs:
    • When CellActiveState and FddTddInd in a Cell MO are set to CELL_ACTIVE and CELL_FDD, respectively, one to six EuPrbSectorEqm and EuPrbSectorEqmGroup MOs must be configured under each Prb of the Cell if MultiRruCellFlag, MultiRruCellMode and NbCellFlag in the Cell MO are set to BOOLEAN_TRUE, TRUE and SFN, respectively.
  • Relation with the Prb and Cell MOs:
    • When the CellActiveState parameter in a Cell MO is set to CELL_ACTIVE, the MultiRruCellFlag parameter in the Cell MO is not configured, and multiple EuPrbSectorEqm MO instances are configured for one Prb of this Cell MO, the ReferenceSignalPwr, BasebandEqmId, AutoConfigFlag parameters in these EuPrbSectorEqm MO instances must be set to the same values.
    • One or two EuPrbSectorEqm instances must be configured for a Prb MO instance under the Cell in which the MultiRruCellFlag parameter is not configured and the CellActiveState, FddTddInd, and TxRxMode parameters are set to CELL_ACTIVE, CELL_FDD, and 4T4R, respectively. When the settings of these parameters in the Cell MO instance differ from the preceding settings, only one EuPrbSectorEqm instance must be configured.
  • Relation with the Cell, eUCellSectorEqm, SECTOREQM, RRU, and RFU MOs:
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE and MultiRruCellFlag is set to BOOLEAN_FALSE, a maximum of two RRU MOs or RFU MOs can be associated with a SECTOREQM MO corresponding to the eUCellSectorEqm or EuPrbSectorEqm MO under this Cell MO.
  • Relation with the Cell, eUCellSectorEqm, and SECTOREQM MOs:
    • In a Cell MO, CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag is set to BOOLEAN_FALSE, and two RRU or RFU are associated with a SECTOREQM MO corresponding to the eUCellSectorEqm or EuPrbSectorEqm MO under this Cell MO. If FddTddInd is set to CELL_FDD, TxRxMode must be set to 2T2R, 2T4R, 4T4R, 2T8R, 4T8R, or 8T8R. If FddTddInd is set to CELL_TDD, TxRxMode must be set to 2T2R or 8T8R.
  • Relation with the Cell, eNodeBFunction, eUCellSectorEqm, SfnAuxResBind, EuSectorEqmGroup, SfnAuxResGrpBind, MPT, Node, eNodeBResModeAlgo, and EuPrbSectorEqmGroup MOs:
    • The sum of the numbers of the following MO instances must meet a certain requirement: Cell MO instances in which MultiRruCellFlag and EuCellStandbyMode are set to BOOLEAN_FALSE and ACTIVE, respectively; Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and TWO_RRU_COMBINATION (or DIGITAL_COMBINATION), respectively; EuSectorEqmGroup and EuPrbSectorEqmGroup MO instances corresponding to the Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively; eUCellSectorEqm and eUPrbSectorEqm MO instances of other cells; SfnAuxResBind and SfnAuxResGrpBind MO instances. The requirement varies as follows: (1) The sum is less than or equal to 216 if UMPT boards are configured in the MPT MO and the conditions listed in (2) to (9) are not met. (2) The sum is less than or equal to 144 if one UMPT board is configured in the MPT MO, the BRDSPEC of the UMPT is UMPTe or UMPTg, and the conditions listed in (3) to (9) are not met. (3) The sum is less than or equal to 72 if UMPT boards are configured in the MPT MO, WM in the NODE MO is set to CONCURRENT, and the conditions listed in (4) to (9) are not met. (4) The sum is less than or equal to 72 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTga. (5) The sum is less than or equal to 36 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTa, UMPTb, or UMPTa/b. (6) The sum is less than or equal to 36 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTa, UMPTb, or UMPTa/b, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (7) The sum is less than or equal to 72 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (8) The sum is less than or equal to 144 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to ENHANCED_MODE. (9) The sum is less than or equal to 18 if no UMPT board is configured in the MPT MO.
  • Relation with the Cell and SECTOREQM MOs:
    • In a Cell MO, if CellActiveState is CELL_ACTIVE and TxRxMode is set to 1T2R, the total number of TX antennas and the total number of RX antennas are calculated as follows: If WorkMode is set to UL_DL, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) associated with the SECTOREQM MO corresponding to the EuPrbSectorEqm MO under this Cell MO must be 1 or 2, and the total number of RX antennas associated with this SECTOREQM MO must be 2. If WorkMode is set to DL_ONLY, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) associated with the SECTOREQM MO corresponding to the EuPrbSectorEqm MO under this Cell MO must be 1 or 2, and the total number of RX antennas associated with this SECTOREQM MO must be 2 or 0.
    • The SECTOREQM MO referenced by the EuPrbSectorEqm MO under a Cell MO must be configured with two or four TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) and four RX antennas when the following conditions are met: (1) TxRxMode in this Cell MO is set to 2T4R. (2) CellActiveState in this Cell MO is CELL_ACTIVE. (3) MultiRruCellFlag in this Cell MO is set to BOOLEAN_TRUE and MultiRruCellMode in this Cell MO is not set to SFN. Alternatively, MultiRruCellFlag is set to BOOLEAN_FALSE.
    • Assume that in the Cell MO, FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, CellActiveState is CELL_ACTIVE, and TxRxMode is set to 2T4R, the total numbers of both TX and RX antennas specified in the SECTOREQM MO associated with the EuPrbSectorEqm MO in the Cell MO must be 1 and 1, 1 and 2, 2 and 2, or 2 and 4. The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER. Assume that in the Cell MO, FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, CellActiveState is CELL_ACTIVE, and TxRxMode is set to 2T2R, the total numbers of both TX and RX antennas specified in the SECTOREQM MO associated with the EuPrbSectorEqm MO in the Cell MO must be 1 and 1, 1 and 2, or 2 and 2. The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER. Assume that in the Cell MO, the FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, CellActiveState is CELL_ACTIVE, and TxRxMode is set to 1T2R, the total numbers of both TX and RX antennas specified in the SECTOREQM MO associated with the EuPrbSectorEqm MO in the Cell MO must be 1 and 1, or 1 and 2. The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER.
    • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, TxRxMode, CrsPortNum, and CellActiveState in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, SFN, 4T4R, CRS_PORT_2, and CELL_ACTIVE, respectively, sector equipment specified in the SECTOREQM MO associated with the EuPrbSectorEqm of the Cell MO must be configured with four TX antennas and four RX antennas, two TX antennas and four RX antennas, two TX antennas and two RX antennas, one TX antennas and two RX antennas, or one TX antenna and one RX antenna.
    • In a Cell MO, if CellActiveState is CELL_ACTIVE and MultiRruCellMode is not set to CELL_COMBINATION, and MultiRruCellMode is not set to SFN, the total number of TX antennas and the total number of RX antennas are calculated as follows: If TxRxMode is set to 1T1R or 2T2R and WorkMode is set to UL_DL, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) and that of RX antennas associated with the SECTOREQM MO corresponding to the EuPrbSectorEqm MO under this Cell MO must be equal to the number of TX antennas and that of RX antennas specified by the value of TxRxMode, respectively. If TxRxMode is set to 1T1R or 2T2R and WorkMode is set to DL_ONLY, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) associated with the SECTOREQM MO corresponding to the EuPrbSectorEqm MO under this Cell MO must be equal to 0 or the number of TX antennas specified by the value of TxRxMode, and the total number of RX antennas associated with this SECTOREQM MO must be equal to the number of RX antennas specified by the value of TxRxMode.
    • If one EuPrbSectorEqm MO instance is configured for a Cell MO instance in which the MultiRruCellFlag parameter is not configured and the CellActiveState, FddTddInd, and TxRxMode parameters are set to CELL_ACTIVE, CELL_FDD, and 4T4R, respectively, and the ANTCFGMODE parameter in the SECTOREQM MO corresponding to the EuPrbSectorEqm MO is not set to BEAM, the numbers of TX antennas and RX antennas in the sector equipment configured using the SECTOREQM MO corresponding to this EuPrbSectorEqm MO instance must be both 4 (the TX antennas refer to those whose TX Antenna Master/Slave Mode is set to MASTER). If two EuPrbSectorEqm MO instances are configured for the Cell MO instance and the ANTCFGMODE parameter in the SECTOREQM MO corresponding to the EuPrbSectorEqm MO is not set to BEAM, the numbers of TX antennas and RX antennas in the sector equipment configured using the SECTOREQM MO corresponding to each EuPrbSectorEqm MO instance must be both 2 and the antennas must correspond to one RRU or RFU.
    • If CellActiveState in a Cell MO is set to CELL_ACTIVE, each antenna associated with the SECTOREQM MO corresponding to the EuPrbSectorEqm MO under this Cell MO must be unique.
  • Relation with the Cell, EuSectorEqmGroup, CellAuxEnbBind, CellAuxDuBind, eUCellSectorEqm, and EuPrbSectorEqmGroup MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE(TRUE), the eUCellSectorEqm, EuSectorEqmGroup, CellAuxDuBind and CellAuxEnbBind MOs could not be configured; When the NbCellFlag parameter in the Cell is set to FALSE, the EuPrbSectorEqm, EuPrbSectorEqmGroup could not be configured.
  • Relation with the eUCellSectorEqm, CoProcRes, EuSectorEqmGroup, EuCellPriBBEqm, SfnAuxResBind, and EuPrbSectorEqmGroup MOs:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected and the BASEBAND_PROCESSING option of this parameter is deselected, the BaseBandEqmId parameter in the CoProcRes MO must not equal the BaseBandEqmId parameter in the eUCellSectorEqm MO, the BaseBandEqmId parameter in the EuSectorEqmGroup MO, the PriBaseBandEqmId parameter in the EuCellPriBBEqm MO, the BaseBandEqmId parameter in the SfnAuxResBind MO, the BasebandEqmId parameter in the EuPrbSectorEqm MO, and the BasebandEqmId parameter in the EuPrbSectorEqmGroup MO.
  • Relation with the Cell and Prb MOs:
    • In a Cell MO, when NbCellFlag is TRUE, CellActiveState is CELL_ACTIVE, and the number of Prb MOs under the Cell is more than one, EuPrbSectorEqm MOs under the Cell with the same SectorEqmId must use the same AutoConfigFlag.
    • In a Cell MO, if NbCellFlag is FALSE, Prb and EuPrbSectorEqm cannot be configured under the Cell.
    • In a Cell MO, when NbCellFlag is TRUE, CellActiveState is CELL_ACTIVE, and the number of Prb MOs under the Cell is more than one, the number of EuPrbSectorEqm MOs under the Cell with the same SectorEqmId must be equal to the number of Prb MOs.
  • Relation with the Cell and EuPrbSectorEqmGroup MOs:
    • In a Cell MO, when NbCellFlag is TRUE and CellActiveState is CELL_ACTIVE, if MultiRruCellFlag is BOOLEAN_FALSE, EuPrbSectorEqm of the Cell must be configured, if MultiRruCellFlag is BOOLEAN_TRUE and MultiRruCellMode is SFN, EuPrbSectorEqm or EuPrbSectorEqmGroup of the Cell must be configured, if MultiRruCellFlag is BOOLEAN_TRUE and MultiRruCellMode is MPRU_AGGREGATION, EuPrbSectorEqmGroup of the Cell must be configured.
  • Relation with the Prb and EuPrbSectorEqmGroup MOs:
    • Up to 8 EuPrbSectorEqm and EuPrbSectorEqmGroup MOs can be configured for a Prb MO.
  • Relation with the Cell MO:
    • If the NbCellFlag, MultiRruCellFlag and MultiRruCellMode parameters in a Cell MO are set to TRUE, BOOLEAN_TRUE and MPRU_AGGREGATION, respectively, the number of EuPrbSectorEqm MO must be equal to 0.
  • Relation with the Cell, BASEBANDEQM, and BBP MOs:
    • When CellActiveState in an FDD Cell MO is CELL_ACTIVE, BasebandEqmId in the EuPrbSectorEqm MO under the Cell MO has been set, and TYPE is set to UBBP in at least one BBP MO corresponding to the EuPrbSectorEqm MO, BBWS in the BBP MO must be set to NBIOT if NbCellFlag is set to TRUE.
  • Relation with the Cell, SECTOREQM, RFU, RRU, and PrbSectorEqmGrpItem MOs:
    • In a Cell MO, if NbCellFlag in a Cell MO is set to TRUE, CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to the EuPrbSectorEqm MO or PrbSectorEqmGrpItem MO under this Cell MO must be associated with an RRU or RFU MO supporting NBIOT.
  • Relation with the Cell, SECTOREQM, BASEBANDEQM, EuPrbSectorEqmGroup, and PrbSectorEqmGrpItem MOs:
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to the EuPrbSectorEqm MO or the EuPrbSectorEqmGroup MO under this Cell MO must be configured, and if BasebandEqmId in the EuPrbSectorEqm MO or BasebandEqmId in the EuPrbSectorEqmGroup MO is not set to 255, BASEBANDEQMTYPE in all BASEBANDEQM MOs corresponding to EuPrbSectorEqm or EuPrbSectorEqmGroup MOs under this Cell MO must be set to ULDL.
  • Relation with the Cell, eNodeBFunction, eUCellSectorEqm, SfnAuxResBind, EuSectorEqmGroup, SfnAuxResGrpBind, MPT, Node, EuPrbSectorEqmGroup, and eNodeBResModeAlgo MOs:
    • When UMPT is configured in an MPT MO and WM in the corresponding NODE MO is set to CONCURRENT, the sum of the numbers of the following MO instances must meet a certain requirement: Cell MO instances in which MultiRruCellFlag and EuCellStandbyMode are set to BOOLEAN_FALSE and ACTIVE, respectively; Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and TWO_RRU_COMBINATION (or DIGITAL_COMBINATION), respectively; EuSectorEqmGroup and EuPrbSectorEqmGroup MO instances corresponding to the Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively; eUCellSectorEqm and EuPrbSectorEqm MO instances of other cells; SfnAuxResBind and SfnAuxResGrpBind MO instances. The requirement varies as follows: (1) The sum must be less than or equal to 36 if the value of BRDSPEC for the UMPT configured in the MPT MO is UMPTa, UMPTb, or UMPTa/b. (2) The sum must be less than or equal to 72 in other scenarios.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.
Sector Equipment ID

Indicates the ID of the sector equipment that serves the cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to NB-IoT.
Reference Signal Power

Indicates the reference signal power of the sector equipment for the PRB (the precision of converting dBm to mW is 0.01 mW). If this parameter is set to 32767, this value is invalid for reference signal power. In this case, the reference signal power defined in the PDSCHCFG MO takes effect. For details, see 3GPP TS 36.213. In accordance with 3GPP specifications, the difference in reference signal power between the non-anchor carrier and the anchor carrier of a multi-carrier NB-IoT cell can be -12 dB, -10 dB, -8 dB, -6 dB, -4 dB, -2 dB, 0 dB, or 3 dB. If the configured reference signal power difference value is different from the protocol-specified values, the protocol-specified value closest to and greater than the configured difference value is delivered in a Uu message. If the configured difference value is greater than 3 dB, the value 3 dB is delivered in a Uu message. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
Baseband Equipment ID

Indicates the ID of the baseband equipment that serves the cell.

The value 255 indicates that no baseband equipment is specified for the cell. In this scenario, any of the BBPs in the eNodeB can be selected to serve the cell. The BBP to which the cell's serving RRU is directly connected is preferentially selected.

When this parameter is set to a value other than 255, the cell can be served only by the BBPs included in the specified baseband equipment, and the BBP to which the cell's serving RRU is directly connected is preferentially selected. This parameter applies only to NB-IoT.
Auto Config Flag

Indicates whether to automatically or manually control the setting of baseband equipment ID. To allow for automatic setting, set this parameter to AUTO_MODE. To allow for manual object creation, set this parameter to MANUAL_MODE or AUTO_MODE. This parameter applies only to NB-IoT.
NPRS ID

Indicates the narrowband positioning reference signal (NPRS) ID of an NB-IoT cell. If this parameter is set to 65535, the specified NPRS ID is invalid. In this case, the NPRS ID is the same as the PCI. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
