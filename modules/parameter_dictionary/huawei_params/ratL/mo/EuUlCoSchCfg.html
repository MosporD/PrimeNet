EuUlCoSchCfg

+-NE
  +-eNodeBFunction
    +-EuUlCoSchCfg

Description

An EuUlCoSchCfg MO consists of parameters related to uplink coordinated scheduling configuration on the centralized cluster node.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CoProcRes MO:
    • If the UlInterEnbCamcSw parameter in the EuUlCoSchCfg MO is set to ON(On), there must be at least one CoProcRes MO in which both the CLUSTER_MANAGEMENT and COORDINATING_PROCESSING options of the WorkMode parameter are selected and the BASEBAND_PROCESSING option is deselected.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST EUULCOSCHCFG

Use this command to list the settings of parameters related to inter-eNodeB CAMC, such as the delay for coordinated information to take effect.
MOD EUULCOSCHCFG

Use this command to modify the settings of parameters related to inter-eNodeB CAMC, such as the delay for coordinated information to take effect.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UL Inter eNodeB Coordinated AMC Switch

Indicates whether to enable inter-eNodeB coordinated uplink AMC in the centralized Cloud BB networking. This parameter applies only to LTE TDD.
