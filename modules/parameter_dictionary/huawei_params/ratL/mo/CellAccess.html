CellAccess

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellAccess

Description

The CellAccess MO consists of the parameters related to access information in System Information Block 1 (SIB1).

For details about the access control procedure, see the 3GPP TS 36.304.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Table 1 Related MML commands

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.
Cell barring state

Indicates whether the cell is barred. If the cell is barred, the UE cannot camp on the serving cell. During cell reselection, the serving cell is not selected as a candidate cell.
Intra-frequency reselection indication

Indicates whether the cell can initiate the intra-frequency cell reselection when the cell is barred.

NOT_ALLOWED means that the UE cannot initiate the intra-frequency cell reselection, and ALLOWED means that the UE can initiate the intra-frequency cell reselection.
Plmn Broadcast Mode

Indicates the public land mobile network (PLMN) broadcast mode of the cell. If RAN sharing with common carrier or hybrid RAN sharing is enabled in some cells on the live network and the PLMN ID at the top of the broadcast PLMN list is rotated in at least one of these cells, NBSLTEPLMNRoundSwitch under the RanSharingAnrSwitch parameter must be selected for eNodeBs meeting the following condition: The cells in which the PLMN ID at the top of the broadcast PLMN list is rotated may be configured as neighboring cells for cells served by these eNodeBs. Otherwise, these eNodeBs may experience failures in handing over UEs to ANR-established neighboring cells in which the PLMN ID at the top of the broadcast PLMN list is rotated. If this parameter is set to NORMAL_MODE, PLMN IDs are broadcast in a fixed sequence in the cell. If this parameter is set to RR_MODE, the PLMN ID at the top of the PLMN ID list is rotated in RR mode at a cell-specific interval. If this parameter is set to FREE_MODE, the PLMN ID at the top of the PLMN ID list is rotated at an operator-specific interval. This parameter applies only to LTE FDD and LTE TDD.
Plmn Round Broadcast Period

Indicates the changing period of cell PLMN.
Plmn Round Action Time

Indicates the start time for broadcasting PLMN-specific information in round robin mode.
Repeat Synchronization Avoid Indication

Indicates whether all synchronization procedures repeatedly initiated by a UE having compatibility problems can trigger the RRC connection reconfiguration procedure. If this parameter is set to CFG, all synchronization procedures repeatedly initiated by a UE having compatibility problems do not trigger the RRC connection reconfiguration procedure. If this parameter is set to NOT_CFG, all synchronization procedures repeatedly initiated by a UE having compatibility problems trigger the RRC connection reconfiguration procedure. This parameter applies only to LTE FDD and LTE TDD.
Repeat Synchronization Avoid Time

Indicates the period during which synchronization procedures repeatedly initiated by a UE having compatibility problems are prohibited from triggering multiple RRC connection reconfiguration procedures. Multiple synchronization procedures initiated by a UE having compatibility problems within the period specified by this parameter trigger only one RRC connection reconfiguration procedure. This parameter applies only to LTE FDD and LTE TDD.
