SrbRlcPdcpCfg

+-NE
  +-eNodeBFunction
    +-SrbRlcPdcpCfg

Description

An SrbRlcPdcpCfg MO consists of parameters related to Radio Link Control (RLC) and Packet Data Convergence Protocol (PDCP) for signaling radio bearers (SRBs). According to 3GPP TS 36.331, RLC AM is the only applicable RLC mode for SRB1 and SRB2. If you need to change the parameter values in this MO, ask for assistance from Huawei technical support personnel.

RLC provides data transmission services for the upper layer.

PDCP provides encryption and integrity protection.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SRB ID

Indicates the SRB ID of an SRB RLC/PDCP parameter group. The SRB ID can be SRB1 or SRB2 for LTE, eMTC, NB-IoT, and short TTI.
MaxRetxThreshold for UE

Indicates the maximum number of RLC ARQ retransmissions for UEs, which limits the maximum number of AM PDU retransmissions. When the number of RCL ARQ retransmissions reaches the parameter value, an RRC connection reestablishment procedure is initiated. If you need to change the parameter value, contact Huawei technical support. This option applies only to LTE FDD and LTE TDD.
MaxRetxThreshold for eNodeB

Indicates the maximum number of RLC ARQ retransmissions for the eNodeB, which limits the maximum number of AM PDU retransmissions. When the number of RLC ARQ retransmissions reaches the parameter value, the eNodeB releases the UE. If you need to change the parameter value, contact Huawei technical support. This option applies only to LTE FDD and LTE TDD.
PollByte for UE

Indicates the UE-specific data volume threshold of PDUs to trigger polling. When the data volume of transmitted PDUs reaches this parameter value, a Poll flag is set in the PDU headers. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
PollByte for eNodeB

Indicates the eNodeB-specific data volume threshold of PDUs to trigger polling. When the data volume of transmitted PDUs reaches this parameter value, a Poll flag is set in the PDU headers. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
PollPdu for UE

Indicates the UE-specific number of PDUs to trigger polling. When the number of transmitted PDUs reaches this parameter value, a Poll flag is set in the PDU headers. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
PollPdu for eNodeB

Indicates the eNodeB-specific number of PDUs to trigger polling. When the number of transmitted PDUs reaches this parameter value, a Poll flag is set in the PDU headers. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
Poll retransmit timer for UE

Indicates the length of the polling PDU retransmission timer for the UE. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
Poll retransmit timer for eNodeB

Indicates the length of the polling PDU retransmission timer for the eNodeB. If you need to change the parameter value, contact Huawei technical support. This parameter applies only to LTE FDD and LTE TDD.
Status prohibit timer for UE

Indicates the length of the UE-specific timer for prohibiting the receiver from sending status reports in AM. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
Status prohibit timer for eNodeB

Indicates the length of the eNodeB-specific timer for prohibiting status reporting from the receiver in AM. If you need to change the value of this parameter, turn to Huawei technical support personnel for assistance. This parameter applies only to LTE FDD and LTE TDD.
AM reordering timer for UE

Indicates the length of the UE-specific timer for reordering at the receiver in AM. If you need to change the parameter value, contact Huawei technical support.
AM reordering timer for eNodeB

Indicates the length of the eNodeB-specific timer for reordering at the receiver in AM. If you need to change the parameter value, contact Huawei technical support.
NB-IoT eNodeB Polling Retransmission Timer

Indicates the length of the polling PDU retransmission timer of the RLC layer for the NB-IoT eNodeB. If you need to change the value of this parameter, contact Huawei technical support for assistance. This parameter applies only to NB-IoT.
NB-IoT UE Polling Retransmission Timer

Indicates the length of the polling PDU retransmission timer of the RLC layer for the NB-IoT UE. If you need to change the value of this parameter, contact Huawei technical support for assistance. This parameter applies only to NB-IoT.
Max Retransmission Thld for NB-IoT eNodeB

Indicates the maximum number of RLC ARQ retransmissions for the NB-IoT eNodeB, which limits the maximum number of RLC ARQ retransmissions in AM mode for the NB-IoT eNodeB. When the number of RLC ARQ retransmissions reaches the parameter value, the eNodeB releases the UE. This parameter applies only to NB-IoT.
Max Retransmission Thld for NB-IoT UE

Indicates the maximum number of RLC ARQ retransmissions for NB-IoT UEs, which limits the maximum number of RLC ARQ retransmissions in AM mode for NB-IoT UEs. When the number of RLC ARQ retransmissions reaches the parameter value, the UE initiates an RRC connection reestablishment procedure. This parameter applies only to NB-IoT.
