NbSharingPolicy

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-NbSharingPolicy

Description

The NbSharingPolicy MO consists of parameters related to the sharing policy for an operator in the NB-IoT eNodeB. This MO is used to set the proportion of UEs allocated to the operator in UP scenario. If the MO is not configured, all operators share the UE contexts saved in the eNodeB for UEs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator
  • Relation with the NbSharingPolicy MO:
    • The sum of UeContextProportion in all NbSharingPolicy MOs cannot exceed 100.
  • Relation with the CnOperator MO:
    • Among the CnOperator MO instances corresponding to CnOperatorId in the associated NbSharingPolicy MO instances, the number of CnOperator MO instances in which PlmnMode is set to IOPS_PLMN must be zero.
  • Relation with the ENodeBSharingMode MO:
    • NbSharingPolicy MO can be configured only if ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ or HYBRID_SHARED.

Related MML Commands

Function

Description
