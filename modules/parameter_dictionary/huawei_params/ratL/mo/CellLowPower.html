CellLowPower

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellLowPower

Description

The CellLowPower MO consists of the parameters related to the low power consumption mode of a cell. The eNodeB enters the low power consumption mode when the eNodeB receiving a command for forcibly entering the low power consumption mode or an alarm indicating that the mains input is abnormal (Specific Problem: AC Failure) is reported. The service time of an eNodeB can be prolonged by taking the following measures in low power consumption mode: (1) reducing the transmit power for services in a cell; (2) reducing the transmit power for reference signals in a cell; (3) shutting down half of the transmit diversity channels in a cell; (4) shutting down all transmit diversity channels in a cell. A cell enters the low power consumption mode when both of the following conditions are met: (1) The switch for the low power consumption mode is turned on. (2) The switch for forcibly entering the low power consumption mode is turned on; alternatively, the low power consumption mode can be used at the current time, and an alarm indicating that the mains input is abnormal (Specific Problem: AC Failure) is reported.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the SECTOREQM, Cell, and eUCellSectorEqm MOs:
    • When the FddTddInd parameter in a Cell MO is set to CELL_FDD and the ANTCFGMODE parameter in the SECTOREQM MO referenced by the Cell MO is set to BEAM(BEAM), the LowPwrSwitch parameter in the CellLowPower MO must not be set to ON(On).
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to TRUE, LowPwrSwitch in the CellLowPower must be set OFF.
  • Relation with the Cell and CellRbReserve MOs:
    • When the RbRsvMode parameter in a CellRbReserve MO is set to NB_DEPLOYMENT(NB_DEPLOYMENT), the LowPwrSwitch parameter in the CellLowPower MO under the same cell as the CellRbReserve MO must be set to Off.
  • Relation with the eUCellSectorEqm MO:
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 or MASSIVE_MIMO_Ph2, the LowPwrSwitch parameter in CellLowPower MO must be deselected.
  • Relation with the CellChPwrCfg MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the LowPwrSwitch parameter in the CellLowPower MO is set to OFF.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the LowPwrSwitch parameter in the CellLowPower MO under this Cell MO must be set to OFF.
  • Relation with the Cell and SectorSplitCell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in this Cell MO is set to 8T8R, the cell specified by this Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to NOT_CFG, then the LowPwrSwitch parameter in the CellLowPower MO must be set to OFF.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 32T32R or 64T64R, and the SectorSplitCell MO associated with the Cell MO is configured, then the LowPwrSwitch parameter in the CellLowPower MO must be set to OFF.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR or LTE_NR_COORD_SPECTRUM_SHR, the LowPwrSwitch parameter in the CellLowPower MO cannot be set to ON for this cell.
  • Relation with the SectorSplitGroup, SectorSplitCell, and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in this Cell MO is set to 8T8R, the cell specified by this Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to MODE_3, then the LowPwrSwitch parameter in the CellLowPower MO must be set to OFF.
  • Relation with the ContigIntraBandCarr MO:
    • LowPwrSwitch in the CellLowPower MO and CONTIG_INTRA_BAND_CARR_SW of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be both turned on.
  • Relation with the Cell, eUCellSectorEqm, CellAlgoSwitch, and CellRfShutdown MOs:
    • If the value of the CellActiveState parameter in a Cell MO is CELL_ACTIVE, the FddTddInd and TxRxMode parameters in this Cell MO are set to CELL_FDD and 8T8R, respectively, and the CellBeamMode parameter in the eUCellSectorEqm MO under this Cell MO is set to NORMAL, then the DynAdjVoltSwitch option of the DynAdjVoltSwitch parameter in the CellAlgoSwitch MO under this Cell MO must be set deselected, the LowPwrSwitch parameter in the CellLowPower MO under this Cell MO must be set to OFF, and the RfShutdownSwitch parameter in the CellRfShutdown MO under this Cell MO must also be set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Low power consumption mode switch

Indicates the switch for the functionality of the low power consumption mode. The cell can enter the low power consumption mode only when this parameter is set to ON and specific conditions are met. This parameter applies only to LTE FDD and LTE TDD.
Low power consumption mode order

Indicates the switch for forcibly entering the low power consumption mode. When both this switch and the functionality switch are set to ON, the cell enters the low power consumption mode as soon as the wait time for entering the mode elapses, regardless of whether the cell is within the low power consumption period. When the functionality switch is set to ON but this switch is set to OFF and if a mains input out of range (Specific Problem: AC Failure) alarm is reported, the cell enters the low power consumption mode as soon as the wait time for entering the mode elapses on condition that the cell is within the low power consumption period. This parameter applies only to LTE FDD and LTE TDD.
Start time

Indicates the start time of the low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
Stop time

Indicates the stop time of the low power consumption mode. If the stop time is earlier than or the same as the start time, the stop time is assumed to be a time of the next day. This parameter applies only to LTE FDD and LTE TDD.
Cell used power reduce time length

Indicates the duration in which the transmit power for services is reduced in the cell in low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
Reference signal power reduce time length

Indicates the duration in which the reference signal transmit power is reduced in the cell in low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
RF shutdown time length

Indicates the duration in which RF channels are shut down in the cell in low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
Cell used power ratio

Indicates the percentage of the transmit power for services to the total transmit power for services when the low power consumption mode is implemented by means of reducing the transmit power for services. This parameter applies only to LTE FDD and LTE TDD.
Reference signal power adjust offset

Indicates the amount by which the reference signal transmit power is reduced in the cell in low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
Time length for entering the low power consumption mode

Indicates the duration when the cell stays in normal mode before entering the low power consumption mode. In low power consumption mode, a cell automatically takes the following actions in sequence: 1. lowers the transmit power for services; 2. lowers the transmit power for reference signals; 3. shuts down some RF channels in the cell; 4. shuts down the cell. This duration smooths the transition from the normal mode to the low power consumption mode for the cell. If the conditions for the cell to enter the low power consumption mode are no longer met during this period of time, the cell will not enter the low power consumption mode; otherwise, it enters the low power consumption mode and takes the preceding actions in sequence. This parameter applies only to LTE FDD and LTE TDD.
Back power save policy

Indicates the backup power saving policy of the eNodeB when the mains supply is cut off and the eNodeB is powered by storage batteries. The degradation duration in each policy is automatically configured as follows: If this parameter is set to POLICY3, the duration of service power degradation and that of reference signal power degradation are both 120 minutes, and the maximum duration of RF channel intelligent shutdown is 1440 minutes. If this parameter is set to POLICY2, the duration of service power degradation, reference signal power degradation, and RF channel intelligent shutdown is all 120 minutes. If this parameter is set to POLICY1, the duration of service power degradation, that of reference signal power degradation, and that of RF channel intelligent shutdown are all 0 minutes. If this parameter is set to POLICY1, POLICY2 or POLICY3, the ratio of available service power to total service power is 50%, the adjustment offset for reference signal power is -1 dB, and the wait time for entering the low power consumption mode is 5 minutes. If this parameter is set to CUSTOMIZED, you can customize the duration of power degradation, the ratio of available service power to total service power, the adjustment offset for reference signal power, and the wait time for entering the low power consumption mode. This parameter applies only to LTE FDD and LTE TDD.
