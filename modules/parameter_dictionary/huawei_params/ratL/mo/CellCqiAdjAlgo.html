CellCqiAdjAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellCqiAdjAlgo

Description

The CellCqiAdjAlgo MO consists of the parameters related to CQI adjustment for the cell. These parameters control the CQI adjustment efficiency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to TRUE, the PUSCH_CQI_FALSE_DETECTION_SW option of the CqiOptSwitch in the CellCqiAdjAlgo MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the PUCCH_CQI_FALSE_DETECTION_SW option of the CqiOptSwitch in the CellCqiAdjAlgo MO must be deselected.

Related MML Commands

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Initial Downlink IBLER Target

Indicates the initial value of the downlink target IBLER. For LTE FDD cells, this parameter does not specify the target IBLER when downlink target IBLER adaption and enhanced downlink target IBLER adaption are enabled. For LTE TDD cells, this parameter specifies the target IBLER when downlink target IBLER adaption and enhanced downlink target IBLER adaption are enabled. If this parameter is set to 100, the CQI adjustment amount is not updated. This parameter applies only to LTE FDD and LTE TDD.
Initial Delta Cqi

Indicates the initial CQI adjustment amount. This parameter applies only to LTE FDD and LTE TDD.
CQI Adjust Step

Indicates the adjustment efficiency of the baseline step in the CQI adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.
CQI Filter Coefficient for MCS

Indicates the CQI filtering coefficient in the CQI adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.
CQI Optimization Algorithm Switch

Indicates whether to enable optimization algorithms for CQI transmission on the PUCCH and PUSCH.

PUSCH_CQI_FALSE_DETECTION_SW: Indicates whether to enable the algorithm of counteracting false detection of CQIs on the PUSCH. The algorithm effectively reduces the probability of false CQI detection. False CQI detection occurs if a UE does not report a CQI but the eNodeB detects a CQI from the UE. The algorithm is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PUCCH_CQI_FALSE_DETECTION_SW: Indicates whether to enable the algorithm of counteracting false detection of CQIs on the PUCCH. The algorithm is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.
Volte NACK Delta CQI Adjustment

Indicates the decrease in CQI adjustment value when a voice UE returns an NACK message. If the DLDeltaCqiOptSwitch option of the DlVolteCqiAdjOptSw parameter in the CellCqiAdjAlgo MO is selected, the CQI adjustment value decreases by the amount specified by this parameter when a voice UE returns an NACK message. This parameter applies only to LTE FDD and LTE TDD.
DL Volte CQI Adjust Optimization Switch

Indicates whether to optimize downlink CQI adjustment for voice UEs.

DLDeltaCqiOptSwitch: Indicates whether to optimize the downlink CQI adjustment value for voice UEs. If this option is selected, the eNodeB lowers the downlink CQI adjustment value for voice UEs and the MCS index of voice services. If this option is deselected, the downlink CQI adjustment value of voice UEs is processed in the same way as that for other UEs. This option applies only to LTE FDD and LTE TDD.

DlRetxTbsOptSwitch: Indicates whether to optimize the TBS indexes for downlink retransmissions to voice UEs. If this option is selected, the eNodeB decreases the TBS indexes for downlink retransmissions to voice UEs. If this option is deselected, the eNodeB selects TBS indexes for downlink retransmissions to voice UEs in the same way as it selects TBS indexes for downlink retransmissions to other UEs. This option applies only to LTE TDD.

DlPttCqiOptSwitch: Indicates whether to optimize CQIs for downlink PTT services. CQIs for downlink PTT services are optimized only if this option is selected. This option applies only to LTE FDD and LTE TDD.
MU Beamforming Packet Count Threshold

Indicates the threshold, which is the number of packets transmitted using MU beamforming, used to trigger MCS index selection optimization for MU beamforming subframes when MU beamforming is enabled. This threshold is used to determine whether the eNodeB performs MCS index selection optimization for MU beamforming based on only out-loop information of MU beamforming. If this parameter is set to 65535, MCS index selection optimization is disabled for MU beamforming subframes. This parameter takes effect only when the massive MIMO feature is enabled. This parameter applies only to LTE TDD.
Cell CQI Adjustment Sample Selection Thld

Indicates the threshold for selecting samples for the CQI adjustment value for massive MIMO and beamforming in the cell. In massive MIMO scenarios, if the number of times of dynamic initial transmission for a MIMO UE (excluding beamforming UEs) is greater than or equal to this threshold, the UE-specific CQI adjustment value of this UE can be used as a maintenance sample for cell-specific CQI adjustment and provides a reference for selecting an aggregation level for beamforming UEs if the capacity-based aggregation level selection policy is implemented. In non-massive MIMO scenarios, if the number of times of dynamic initial transmission for either a MIMO UE or beamforming UE is greater than or equal to this threshold, the UE-specific CQI adjustment value of this UE can be used as a maintenance sample for cell-specific CQI adjustment and provides a reference for selecting an aggregation level for beamforming UEs if the PDSCH and capacity-based PDCCH aggregation level selection policy is implemented. If this parameter is set to 0, the cell-specific CQI adjustment value for MIMO and beamforming is not used for PDSCH and PDCCH aggregation level selection for beamforming UEs. This parameter applies only to LTE TDD.
Cell CQI Adjustment Schedule Count Thld

Indicates the threshold of the number of scheduling times for determining samples used to adaptively set the cell-level CQI adjustment value. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is deselected and the number of dynamic initial scheduling times of a MIMO UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is selected and the number of dynamic initial scheduling times of either a MIMO UE or beamforming UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If this parameter is set to 0, the algorithm of adaptively setting the initial cell-level CQI adjustment value does not take effect. This parameter applies only to LTE TDD.
VoLTE CQI Report Difference Limit Value

Indicates the maximum difference between the CQI reported for the filtering algorithm and the previously reported CQI. The value 0 indicates that no limit is imposed on the maximum difference. A non-0 value indicates the maximum difference. This parameter applies only to LTE FDD and LTE TDD.
