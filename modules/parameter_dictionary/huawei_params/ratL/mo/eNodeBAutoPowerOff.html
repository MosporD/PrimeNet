eNodeBAutoPowerOff

+-NE
  +-eNodeBFunction
    +-eNodeBAutoPowerOff

Description

The eNodeBAutoPowerOff MO consists of the parameters related to RF module regular time sleep in energy conservation and emission reduction.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the ContigIntraBandCarr MO:
    • If the AutoPowerOffSwitch parameter in the eNodeBAutoPowerOff MO is set to ON, the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be selected.
  • Relation with the CellAutoShutdown and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD or the NbCellFlag parameter in a Cell MO is set to TRUE, and the AutoPowerOffSwitch parameter in the eNodeBAutoPowerOff MO is set to ON, then the CellAutoShutdownSwitch parameter in the CellAutoShutdown MO under this Cell MO can only be set to OFF.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP ENODEBAUTOPOWEROFF

Use this command to query the RF module regular time sleep information about the eNodeB.
LST ENODEBAUTOPOWEROFF

Use this command to list the RF module regular time sleep configurations about the eNodeB.
MOD ENODEBAUTOPOWEROFF

Use this command to modify the RF module regular time sleep configurations about the eNodeB.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RF module sleep switch

Indicates the switch for RF module regular time sleep. Cells are unavailable after the eNodeB enters RF module regular time sleep. After the eNodeB exits RF module regular time sleep, it is in the normal state. This parameter applies only to LTE FDD and NB-IoT.
RF module sleep start time

Indicates the time for entering RF module regular time sleep. This parameter applies only to LTE FDD and NB-IoT.
RF module sleep stop time

Indicates the time for exiting RF module regular time sleep. This parameter applies only to LTE FDD and NB-IoT.
Table 3 Dynamic parameters

Parameter

Description
RF module sleep status

Indicates the sleep status of the RF modules of the eNodeB. The value POWER_OFF indicates that cells on the eNodeB are unavailable. The value NORMAL indicates that the eNodeB is working normally. This parameter applies only to LTE FDD and NB-IoT.
