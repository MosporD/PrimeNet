EmtcCeSchCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-EmtcCeSchCfg

Description

An EmtcCeSchCfg MO consists of the parameters used to specify scheduling configurations for eMTC UEs at a specific coverage level.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If the NbCellFlag parameter in the Cell MO is set to FALSE and the CoverageLevel parameter in the EmtcCeSchCfg MO is set to COVERAGE_LEVEL_0 or COVERAGE_LEVEL_1, the PdschInitRepNum parameter in the EmtcCeSchCfg MO can be set to INVALID, PDSCH_INIT_REP_INDEX_1, PDSCH_INIT_REP_INDEX_2, PDSCH_INIT_REP_INDEX_3, or PDSCH_INIT_REP_INDEX_4.
    • If the NbCellFlag parameter in the Cell MO is set to FALSE and the CoverageLevel parameter in the EmtcCeSchCfg MO is set to COVERAGE_LEVEL_0 or COVERAGE_LEVEL_1, the PuschInitRepNum parameter in the EmtcCeSchCfg MO can be set to INVALID, PUSCH_INIT_REP_INDEX_1, PUSCH_INIT_REP_INDEX_2, PUSCH_INIT_REP_INDEX_3, or PUSCH_INIT_REP_INDEX_4.
    • If the NbCellFlag parameter in the Cell MO is set to FALSE and the MpdcchInitRepNumType1Css parameter in the EmtcCeSchCfg MO is set to INVALID, the PdschInitRepNumType1Css parameter in the EmtcCeSchCfg MO must be set to INVALID. If the NbCellFlag parameter in the Cell MO is set to FALSE and the MpdcchInitRepNumType1Css parameter in the EmtcCeSchCfg MO is set to a value other than INVALID, the PdschInitRepNumType1Css parameter in the EmtcCeSchCfg MO must be set to a value other than INVALID.
  • Relation with the CellEmtcAlgo MO:
    • If the MPDCCH_PDSCH_FREQ_HOPPING_SW option of the EmtcFreqHoppingSwitch parameter in the CellEmtcAlgo MO is selected, the EmtcDlFreqHoppingInterval parameter in the CellEmtcAlgo MO must be less than or equal to the ratio of the smallest one of the MpdcchMaxRepNum parameter values (in the EmtcCeSchCfg MO associated with the CellEmtcAlgo MO through the LocalCellId parameter) for different coverage levels to the value of the MpdcchPdschHoppingNbCnt parameter in the CellEmtcAlgo MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Coverage Level

Indicates the coverage level for UEs. If this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, or COVERAGE_LEVEL_3, the coverage level for UEs is coverage level 0, coverage level 1, coverage level 2, or coverage level 3, respectively. This parameter applies only to LTE FDD and LTE TDD.
Initial Number of MPDCCH Repetitions

Indicates the initial number of MPDCCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Initial Number of MPDCCH Rep for Type1 CSS

Indicates the initial number of repetitions of the type-1 CSS MPDCCH for UEs at the specified coverage level. Given that UE coverage level information is unavailable in type-1 CSS, the number specified by this parameter for the highest coverage level supported by the cell takes effect. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Max Number of MPDCCH Repetitions

Indicates the maximum number of MPDCCH repetitions for UEs at the specified coverage level. For details, see 3GPP TS 36.213. To prevent UE access failures as a result of contention resolution timer expiration caused by a large number of repetitions, it is recommended that this parameter be set to a value in which the number does not exceed half of the number included in the value specified by the ContentionResolutionTimer parameter in the CeRachCfg MO. This parameter applies only to LTE FDD and LTE TDD.
Initial Number of PDSCH Repetitions

Indicates the initial number of PDSCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Initial Number of PDSCH Rep for Type1 CSS

Indicates the initial number of repetitions of the type-1 CSS PDSCH for UEs at the specified coverage level. Given that UE coverage level information is unavailable in type-1 CSS, the number specified by this parameter for the highest coverage level supported by the cell takes effect. For details, see 3GPP TS 36.213. A larger value of this parameter leads to a higher probability that UEs cannot access the cell due to failures of RAR resource allocation within the RAR window. It is recommended that this parameter be set based on the setting of the MpdcchInitRepNumType1Css parameter (in the EmtcCeSchCfg MO) as follows:

If the MpdcchInitRepNumType1Css parameter is set to MPDCCH_INIT_REP_INDEX_3, set the PdschInitRepNumType1Css parameter to PDSCH_INIT_REP_INDEX_5 or a value with a smaller index number.

If the MpdcchInitRepNumType1Css parameter is set to MPDCCH_INIT_REP_INDEX_4, set the PdschInitRepNumType1Css parameter to PDSCH_INIT_REP_INDEX_2 or a value with a smaller index number.

This parameter applies only to LTE FDD and LTE TDD.
Initial Number of PUSCH Repetitions

Indicates the initial number of PUSCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
