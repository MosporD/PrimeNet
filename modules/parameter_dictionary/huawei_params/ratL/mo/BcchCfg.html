BcchCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-BcchCfg

Description

The BcchCfg MO consists of the parameters used to configure the Broadcast Control Channel (BCCH) in a cell.

The BCCH is a downlink logical channel that is used to broadcast the control information in the system.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the PCCHCfg MO:
    • The product of DefaultPagingCycle in the PCCHCfg MO and ModifyPeriodCoeff in the BcchCfg MO cannot exceed 1024 radio frames, that is 10, 240 milliseconds.
  • Relation with the Cell and PCCHCfg MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, the value of the ModifyPeriodCoeffForNb parameter in the BcchCfg MO multiplied by the value of the DefaultPagingCycleForNb parameter in the PCCHCfg MO must be an integer multiple of 40.96 seconds.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.
Modification period coefficient

Indicates the modification period coefficient for the BCCH. The BCCH modification period is equal to Modification period coefficient multiplied by Default paging cycle, where the BCCH modification period and default paging cycle are measured in unit of radio frames, and the modification period coefficient is specified by this parameter. This parameter applies only to LTE FDD and LTE TDD.
NB-IoT Modification Period Coefficient

Indicates the BCCH modification period coefficient of an NB-IoT cell. The BCCH modification period is equal to Modification period coefficient of an NB-IoT cell multiplied by Default paging cycle, where the BCCH modification period and default paging cycle are measured in unit of radio frames, and the modification period coefficient of an NB-IoT cell is specified by this parameter. This parameter applies only to NB-IoT.
