Session

+-NE
  +-eNodeBFunction
    +-Mce
      +-MbsfnArea
        +-Pmch
          +-Session

Description

The Session MO includes the parameters used to configure session information.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Pmch

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SESSION

Use this command to add configuration data for a session.
LST SESSION

Use this command to list the configuration data of a session.
RMV SESSION

Use this command to remove the configuration data of a session.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local MCE ID

Indicates the local MCE ID, which is unique on the local NE. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Area ID

Indicates the MBSFN area ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
PMCH ID

Indicates the PMCH ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
Service ID

Indicates the eMBMS service ID, which is unique in a PLMN. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
