CellSLV2xCarrCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSLV2xCarrCfg

Description

The CellSLV2xCarrCfg MO consists of parameters related to cell sidelink V2X carrier configuration and management.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the SidelinkV2xCarrier MO:
    • The SidelinkV2xCarrierId parameter in a CellSLV2xCarrCfg MO must have been configured in a SidelinkV2xCarrier MO.
  • Relation with the CellSidelinkV2xCfg MO:
    • When the SIDELINK_V2X_SWITCH option of the SidelinkV2xCfgSwitch parameter in a CellSidelinkV2xCfg MO is selected, the CellSLV2xCarrCfg MO must be configured in the associated cell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLSLV2XCARRCFG

Use this command to add a sidelink V2X carrier for a cell.
LST CELLSLV2XCARRCFG

Use this command to query the sidelink V2X carrier configuration for a cell.
RMV CELLSLV2XCARRCFG

Use this command to remove a sidelink V2X carrier for a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.
Sidelink V2X Carrier ID

Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
