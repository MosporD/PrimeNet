CellMro

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMro

Description

The CellMro MO consists of the parameters related to inter-cell Mobility Robustness Optimization (MRO), such as the upper and lower limits of the cell individual offset (CIO) adjustment range for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CELLMRO

Use this command to list the configuration of inter-cell Mobility Robustness Optimization (MRO).
MOD CELLMRO

Use this command to modify the configuration of inter-cell Mobility Robustness Optimization (MRO).

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
CIO adjustment range configuration indicator

Indicates whether to set the upper and lower limits of the CIO adjustment range for the cell for intra-frequency MRO. If this parameter is set to CFG(Configure), the CIO for the cell can be changed by an amount within the range specified by the upper and lower limits. If this parameter is set to NOT_CFG(Not configure), the upper and lower limits of the CIO adjustment range for the cell in intra-frequency MRO are calculated by using the following formulas: Lower limit = Off + Ofs + Ocs - Ofn + Hys - 5, Upper limit = Off + Ofs + Ocs - Ofn + Hys - 2. This parameter applies only to LTE FDD and LTE TDD.
CIO adjustment upper limit

Indicates the upper limit of intra-frequency cell individual offset (CIO) adjustment range for the cell in mobility robustness optimization (MRO). This parameter needs to be set only when the CioAdjLimitCfgInd parameter is set to CFG. This parameter applies only to LTE FDD and LTE TDD.
CIO adjustment lower limit

Indicates the lower limit of intra-frequency cell individual offset (CIO) adjustment range for the cell in mobility robustness optimization (MRO). This parameter needs to be set only when the CioAdjLimitCfgInd parameter is set to CFG. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A2 RSRP Upper Limit

Indicates the upper limit used to adjust the reference signal received power (RSRP) threshold for triggering inter-frequency event A2. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A2 RSRP Lower Limit

Indicates the lower limit used to adjust the reference signal received power (RSRP) threshold for triggering inter-frequency event A2. This parameter applies only to LTE FDD and LTE TDD.
A3 based Interfreq A2 RSRP Upper Limit

Indicates the upper limit used to adjust the reference signal received power (RSRP) threshold for triggering A3-oriented inter-frequency event A2. This parameter applies only to LTE FDD and LTE TDD.
A3 based Interfreq A2 RSRP Lower Limit

Indicates the lower limit used to adjust the reference signal received power (RSRP) threshold for triggering A3-oriented inter-frequency event A2. This parameter applies only to LTE FDD and LTE TDD.
Interfreq MRO Adjust Parameters Selection

Indicates the selection of inter-frequency adjustable parameters in inter-frequency MRO.

InterfreqA1RsrpSwitch: Indicates whether the RSRP threshold for triggering inter-frequency event A1 in the inter-frequency handover parameter group can be adjusted. The RSRP threshold can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

InterfreqA2RsrpSwitch: Indicates whether the RSRP threshold for triggering inter-frequency event A2 in the inter-frequency handover parameter group can be adjusted. The RSRP threshold can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

A3InterfreqA1RsrpSwitch: Indicates whether the RSRP threshold for triggering A3-oriented inter-frequency event A1 in the inter-frequency handover parameter group can be adjusted. The RSRP threshold can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

A3InterfreqA2RsrpSwitch: Indicates whether the RSRP threshold for triggering A3-oriented inter-frequency event A2 in the inter-frequency handover parameter group can be adjusted. The RSRP threshold can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

InterfreqA3CioSwitch: Indicates whether the cell individual offset (CIO) of the inter-frequency neighboring cell for inter-frequency event A3 can be adjusted. The CIO can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

InterfreqA4CioSwitch: Indicates whether the CIO of the inter-frequency neighboring cell for inter-frequency event A4 can be adjusted. The CIO can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.

InterfreqA5Switch: Indicates whether the CIO of the inter-frequency neighboring cell for inter-frequency event A5 and related threshold 1 for triggering inter-frequency event A5 can be adjusted. The CIO and related threshold 1 can be adjusted only when this option is selected. This option applies only to LTE FDD and LTE TDD.
