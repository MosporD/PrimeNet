BbpAssistGroup

+-NE
  +-eNodeBFunction
    +-BbpAssistGroup

Description

A BbpAssistGroup MO consists of the parameters used to configure an assistance group comprised of old and new BBPs. New BBPs are used to assist old BBPs to improve the capability of the old BBPs on live networks.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD BBPASSISTGROUP

Use this command to configure BBP assistance groups.
DSP BBPASSISTGROUP

Use this command to query the status of baseband processing units in the baseband equipment associated with the LTE baseband assistance group.
LST BBPASSISTGROUP

Use this command to list BBP assistance group configurations.
MOD BBPASSISTGROUP

Use this command to modify BBP assistance group configurations.
RMV BBPASSISTGROUP

Use this command to remove BBP assistance groups.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
BBP Assist Group Id

Indicates the ID of an LTE BBP assistance group. It uniquely identifies an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Master Board Cabinet No.

Indicates the cabinet number of the master baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Master Board Subrack No.

Indicates the subrack number of the master baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Master Board Slot No.

Indicates the slot number of the master baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Assist Board Cabinet No.

Indicates the cabinet number of the assistant baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Assist Board Subrack No.

Indicates the subrack number of the assistant baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Assist Board Slot No.

Indicates the slot number of the assistant baseband processing unit (BBP) in a user-created LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Assist Start Time

Indicates the assistance start time of a user-created LTE BBP assistance group. When the time specified by this parameter arrives, the eNodeB transfers a cell from the master BBP in the assistance group to the assistant BBP to assist the master BBP.

When the start time arrives, a cell on the master BBP will be deactivated and reactivated. You are advised to set this parameter to a time when there are only a few UEs on the network. This parameter applies only to LTE FDD and LTE TDD.
Cell Load Stat Period

Indicates the period of collecting load statistics of the cells established on the master BBP in an LTE BBP assistance group. When the specified assistance start time arrives and load statistics of the cells established on the master BBP have been collected for at least one period, the eNodeB selects one cell on the master BBP based on the load statistics and related algorithm and transfers the selected cell to the assistant BBP. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
Assist Status

Indicates the status of an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
Failed Reason

Indicates the cause of the last failure to transfer a cell from the master BBP to the assistant BBP in an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
