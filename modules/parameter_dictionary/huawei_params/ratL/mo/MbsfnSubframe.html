MbsfnSubframe

+-NE
  +-eNodeBFunction
    +-Mce
      +-MbsfnArea
        +-MbsfnSubframe

Description

The MbsfnSubframe MO includes the parameters used to set a subframe configuration template for an MBSFN area.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    MbsfnArea
  • Relation with the MbsfnArea MO:
    • The value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO must be greater than or equal to the value of the RadioFrameAllocPrd parameter in the MbsfnSubframe MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD MBSFNSUBFRAME

Use this command to add configuration data for an MBSFN subframe.
LST MBSFNSUBFRAME

Use this command to list the configuration data of MBSFN subframes.
MOD MBSFNSUBFRAME

Use this command to modify the configuration data of MBSFN subframes.
RMV MBSFNSUBFRAME

Use this command to remove the configuration data of an MBSFN subframe.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Area ID

Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Subframe Configuration ID

Indicates the ID of an MBSFN subframe configuration. A maximum of eight MBSFN subframe configurations are allowed for an MBSFN area. This parameter applies only to LTE FDD and LTE TDD.
Four Frame Allocation

Indicates the MBSFN subframes allocated in four consecutive radio frames when the MBSFN subframe allocation mode is Four Frame.

If the cells in the MBSFN area work in TDD mode, the subframes that can be allocated for MBSFN in each radio frame include SF3, SF4, SF7, SF8, and SF9. These subframes in the four radio frames are represented by bit 23 to bit 19, bit 17 to bit 13, bit 11 to bit 7, and bit 5 to bit 1 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN.

If the cells in the MBSFN area work in FDD mode, the subframes that can be allocated for MBSFN in each radio frame include SF1, SF2, SF3, SF6, SF7, and SF8. These subframes in the four radio frames are represented by bit 23 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
One Frame Allocation

Indicates the MBSFN subframes allocated in one radio frame when the MBSFN subframe allocation mode is One Frame.

If the cells in the MBSFN area work in TDD mode, the subframes that can be allocated for MBSFN in a radio frame are SF3, SF4, SF7, SF8, and SF9. These subframes are represented by bit 5 to bit 1 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN.

If the cells in the MBSFN area work in FDD mode, the subframes that can be allocated for MBSFN in a radio frame are SF1, SF2, SF3, SF6, SF7, and SF8. These subframes are represented by bit 5 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Radio Frame Allocation Offset

Indicates radio frame allocation offset, which is used together with the RadioFrameAllocPrd parameter to determine the radio frames that contain MBSFN subframes. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Radio Frame Allocation Period

Indicates the allocation period of the radio frames that contain MBSFN subframes. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subframe Allocation Mode

Indicates whether one radio frame or four consecutive radio frames contain MBSFN subframes. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
