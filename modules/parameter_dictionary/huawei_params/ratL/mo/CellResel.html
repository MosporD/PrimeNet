CellResel

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellResel

Description

The CellResel MO consists of the parameters related to cell reselection in the cell System Information Block 3 (SIB3). For details of cell reselection, see 3GPP TS 36.304.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the UtranNFreq MO:
    • If CellReselPriorityCfgInd in UtranNFreq MO is set to CFG, CellReselPriority in CellResel MO cannot be set same as CellReselPriority in UtranNFreq MO for each cell.
  • Relation with the GeranNfreqGroup MO:
    • If CellReselPriorityCfgInd in GeranNfreqGroup MO is set to CFG, CellReselPriority in CellResel MO cannot be set same as CellReselPriority in GeranNfreqGroup MO for each cell.
  • Relation with the Cdma2000BandClass MO:
    • If Cdma20001XrttCellReselInd in Cdma2000BandClass MO is set to CFG, Cdma20001XrttCellReselPri in Cdma2000BandClass MO cannot be set same as CellReselPriority in CellResel MO for each cell, and if Cdma2000HrpdCellReselInd in Cdma2000BandClass MO is set to CFG, Cdma2000HrpdCellReselPri in Cdma2000BandClass MO cannot be set same as CellReselPriority in CellResel MO for each cell.
  • Relation with the Cell MO:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, the values of the SIntraSearchCfgInd and SNonIntraSearchCfgInd parameters in the CellResel MO must be CFG(Configure).
    • If the NbCellFlag parameter in a Cell MO that corresponds to LocalCellId in a CellResel MO is set to FALSE, the value range of QRxLevMin parameter in the CellResel MO is from -70 to -22.
    • If the NbCellFlag parameter in a Cell MO that corresponds to LocalCellId in a CellResel MO is set to FALSE, the value range of SIntraSearch parameter in the CellResel MO is from 0 to 31.
    • If the NbCellFlag parameter in a Cell MO is set to TRUE, the SpeedDepReselCfgInd, MeasBandWidthCfgInd, SpeedStateSfCfgInd, and ThrshServLowQCfgInd parameters in the CellResel MO must be set to NOT_CFG.
  • Relation with the NrNFreq and CellReselToNr MOs:
    • If a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.
Hysteresis value for ranking criteria

Indicates the hysteresis for the measured RSRP of the serving cell, which is used for cell reselection evaluation. This parameter must be set based on the slow fading characteristic of the area covered by the cell. The greater the slow fading variance is, the larger the value of this parameter must be set to. A larger value of the hysteresis results in a larger boundary of the serving cell and a lower probability of cell reselection to neighboring cells.
Speed-dependent reselection parameter configure indicator

Indicates whether to set the parameters related to speed-dependent cell reselection. This parameter applies only to LTE FDD and LTE TDD.
The duration for evaluating criteria to enter mobility states

Indicates the duration in which the mobility status of the UE is evaluated. This parameter is one of the key parameters in deciding on the UE mobility state. A smaller value of this parameter may lead to more frequent state transitions and lower decision accuracy. A larger value of this parameter leads to the opposite effect. This parameter applies only to LTE FDD and LTE TDD.
Additional time hysteresis for normal speed

Indicates the extra duration required in the evaluation before the UE can enter the normal-mobility state. This parameter can prevent UEs from frequently switching from the high- or medium-mobility state to the normal-mobility state, and is one of the key parameters in deciding on the UE mobility. A larger value of this parameter leads to a lower probability of transition from the high- or medium-mobility state to the normal-mobility state but higher decision accuracy. A smaller value of this parameter leads to the opposite effect. This parameter applies only to LTE FDD and LTE TDD.
The number of cell changes to enter medium mobility state

Indicates the threshold of the number of cell reselections, which is used for a UE to enter the medium-mobility state. This parameter is one of the key parameters in determining the mobility state of the UE. During the UE mobility evaluation, if the number of cell reselections is greater than this parameter value and is less than or equal to the NCellChangeHigh parameter value, the UE enters the medium-mobility state. This parameter applies only to LTE FDD and LTE TDD.
The number of cell changes to enter high mobility state

Indicates the threshold of the number of cell reselections, which is used for a UE to enter the high-mobility state. This parameter is one of the key parameters in determining the mobility state of the UE. During the UE mobility evaluation, if the number of cell reselections is greater than this parameter value, the UE enters the high-mobility state. This parameter applies only to LTE FDD and LTE TDD.
Additional hysteresis for medium speed

Indicates the scaling factor (or known as additional hysteresis) applied to Qhyst for medium-mobility UEs. For details, see 3GPP TS 36.304 and 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Additional hysteresis for high speed

Indicates the scaling factor (or known as additional hysteresis) applied to Qhyst for high-mobility UEs. For details, see 3GPP TS 36.304 and 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Threshold for non-intra freq measurements configure indicator

Indicates whether to configure the measurement triggering threshold for cell reselection to inter-frequency or inter-RAT cells. If this parameter is set to NOT_CFG and the QQualMinCfgInd parameter is set to NOT_CFG, the UE continuously measures intra-frequency and inter-RAT cells, regardless of the signal quality of the serving cell.
Threshold for non-intra frequency measurements

Indicates the measurement triggering threshold for reselection to inter-frequency or inter-RAT cells. If the cell reselection priority of a frequency or RAT is higher than that of the serving frequency, the UEs always start inter-frequency or inter-RAT measurements. If the cell reselection priority of a frequency is lower than or equal to that of the serving frequency or if the cell reselection priority of an RAT is lower than that of the serving frequency, the UEs start inter-frequency or inter-RAT measurements only when the value of Cell selection RX level value (dB) is lower than or equal to the value of this parameter.
Serving frequency lower priority threshold

Indicates the threshold used in the evaluation of reselection to a cell on a lower priority E-UTRAN frequency or on an inter-RAT frequency. Cell reselection to a cell on a lower priority E-UTRAN frequency or on an inter-RAT frequency is performed if no cell on the serving frequency or on a higher priority E-UTRAN frequency fulfills criteria 1 for inter-frequency and inter-RAT reselections. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Cell reselection priority

Indicates the absolute cell reselection priority of the serving frequency. The value 0 indicates the lowest priority, and the value 7 indicates the highest priority. The value of this parameter must be determined together with the priorities of other frequencies during network planning. Frequencies used for different RATs must be assigned different absolute cell reselection priorities. This parameter applies only to LTE FDD and LTE TDD.
Minimum required RX level

Indicates the minimum receive level required for an intra-frequency E-UTRAN cell to become a candidate for cell reselection. This parameter corresponds to the IE q-RxLevMin in SIB3. The level is included in the cell reselection criteria and used in the evaluation of cell reselection. The value range of this parameter is -70 to -22 for LTE FDD and TDD, and -78 to -22 for LTE NB-IoT. For details, see 3GPP TS 36.304.
Ue max power allowed configure indicator

Indicates whether to configure the maximum TX power of the UE in the intra-frequency neighboring cell. If the value of this parameter is not specified, the maximum power is subject to the UE capability.
Max transmit power allowed

Indicates the maximum power that the UE can apply to transmission in the intra-frequency neighboring cell. It is used in cell reselection criteria to calculate the compensated power. If the value of this parameter is not specified, the maximum power is subject to the UE capability. For details, see 3GPP TS 36.304.
Threshold for intra freq measurements configure indicator

Indicates whether to set the measurement triggering threshold for reselection to intra-frequency cells.
Threshold for intra frequency measurements

Indicates the measurement triggering threshold for intra-frequency cell reselection. UEs start intra-frequency measurements only if the value of Cell selection RX level value (dB) is less than or equal to the value of this parameter. The value range of this parameter is 0 to 31 for LTE FDD and TDD, and 0 to 63 for LTE NB-IoT.

Note: When this parameter is set to a value within the range of 32 to 63 for LTE NB-IoT, the delivered s-IntraSearchP-v1360 in SIB3-NB takes the value of this parameter and the delivered s-IntraSearchP-r13 takes the value 31. In this case, only the NB-IoT UEs complying with 3GPP TS 36.331 V13.6.0 can receive s-IntraSearchP-v1360. Other UEs can receive s-IntraSearchP-r13 only.
Measurement bandwidth configure indicator

Indicates whether to set the measurement bandwidth.
Measurement bandwidth

Indicates the measurement bandwidth on the serving frequency on which the UE camps. It is used in intra-frequency measurements for cell reselection and those by UEs in RRC_CONNECTED mode. This parameter is optional; if it is not set, the downlink bandwidth of the serving cell is used by default. This parameter applies only to LTE FDD and LTE TDD.
Cell reselection timer value for EUTRAN

Indicates the evaluation period for a UE to determine whether to perform cell reselections to a new E-UTRAN cell. If the signal quality of a new E-UTRAN cell is better than that of the serving cell within the period specified by this parameter and a UE camps on the serving cell for more than 1s, the UE initiates cell reselections to the new E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Speed state scale factor configure indicator

Indicates whether to set the scaling parameters for rate-dependent cell reselection within E-UTRAN. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of TReselEutran in medium mobility state

Indicates the scaling factor applied to TReselEutran for medium-mobility UEs. The actual duration of cell reselection for medium-mobility UEs to E-UTRAN is equal to the product of TReselEutran and TReselEutranSfMedium. This parameter applies only to LTE FDD and LTE TDD.
Scaling factor of TReselEutran in high mobility state

Indicates the scaling factor applied to TReselEutran for high-mobility UEs. The actual duration of cell reselection of high-mobility UEs to E-UTRAN is equal to TReselEutran multiplied by TReselEutranSfHigh. This parameter applies only to LTE FDD and LTE TDD.
Neighbor Cell Configuration

Indicates the information related to MBSFN and TDD UL/DL configurations of intra-frequency neighboring cells of the serving cell.

The value 00 indicates that some neighboring cells have the same MBSFN subframe configuration as the serving cell.

The value 01 indicates that none of the neighboring cells is configured with MBSFN subframes.

The value 10 indicates that the MBSFN subframe configurations of all neighboring cells are the same as or subsets of that of the serving cell.

The value 11 indicates that some neighboring cells have different UL-DL configurations from the serving TDD cell.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Presence antenna port1

Indicates whether all the intra-frequency neighboring cells are configured with at least two antenna ports.

Set this parameter to BOOLEAN_TRUE when all the intra-frequency neighboring cells are configured with at least two antenna ports.

Set this parameter to BOOLEAN_FALSE when one of the intra-frequency neighboring cells is configured with only one antenna port.

It is recommended that PresenceAntennaPort1 be set to BOOLEAN_TRUE if the antennas are configured to work in single-port mode, antenna port 0 is not used, and antenna port 1 is used. Otherwise, handover failures will occur. This parameter applies only to LTE FDD and LTE TDD.
RSRQ Threshold for intra frequency measurements

Indicates the RSRQ threshold for starting intra-frequency measurements. It determines the probability of triggering cell reselection to an intra-frequency neighboring cell. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
RSRQ Threshold for non-intra frequency measurements

Indicates the RSRQ threshold for starting inter-frequency or inter-RAT measurements. It determines the probability of triggering cell reselection to an inter-frequency or inter-RAT neighboring cell. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Serving frequency lower priority RSRQ threshold configure indicator

Indicates whether to set the RSRQ threshold for reselection to cells on the serving frequency. This parameter applies only to LTE FDD and LTE TDD.
Serving frequency lower priority RSRQ threshold

Indicates the RSRQ threshold for cell reselection to cells on lower-priority frequencies. It determines the probability of triggering cell reselection to inter-frequency or inter-RAT neighboring cells on lower-priority frequencies. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Minimum required quality level configure indicator

Indicates whether to configure the parameters related to received signal quality for cell reselection in SIB3.
Minimum required quality level

Indicates the minimum required RX signal quality used in intra-frequency E-UTRAN cell reselection, which corresponds to the IE q-QualMin in SIB3. This value is included in R criteria and used in the evaluation of cell reselection. For details, see 3GPP TS 36.304.
NB-IoT Intra-Freq Reselection Time

Indicates the evaluation period for a UE to determine whether to perform cell reselections to an NB-IoT cell. If the signal quality of a new cell is better than that of the serving cell within the period specified by this parameter and a UE camps on the serving cell for more than 1s, the UE initiates cell reselections to the new cell. For details, see 3GPP TS 36.304. This parameter applies only to NB-IoT.
NB-IoT Inter-Freq Reselection Time

Indicates the evaluation period for a UE to determine whether to perform cell reselections to an inter-frequency NB-IoT cell. If the signal quality of the inter-frequency neighboring cell meets a threshold within the period specified by this parameter and a UE camps on the serving cell for more than 1s, the UE initiates cell reselections to the inter-frequency neighboring cell. The period is sent in SIB5. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
Cell Reselection Time for E-UTRAN CE

Indicates the duration for determining whether to reselect an E-UTRAN cell with enhanced coverage. If an E-UTRAN cell with enhanced coverage constantly provides stronger signals than the serving cell in this duration and the UE camps on the serving cell for more than 1s, the UE triggers reselection to this E-UTRAN cell with enhanced coverage. This parameter applies only to LTE FDD and LTE TDD.
eMTC Cell Reselection Priority

Indicates the reselection priority of a cell on the serving frequency for eMTC UEs. The value 0 indicates the lowest priority. The value of this parameter must be determined together with the priorities of other frequencies during network planning. This parameter applies only to LTE FDD and LTE TDD.
Power Offset for Resel to Intra Freq NB-IoT Cell

Indicates the power offset for intra-frequency cell reselection of an NB-IoT UE with a power level of 14 dBm. When set to NULL, this parameter will not be delivered in the system information, and the UE takes 0 dB as the power offset by default. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
Min Required Quality Level for CE Mode A

Indicates the minimum received signal quality required by UEs in CE mode A for cell reselection to intra-frequency neighboring E-UTRAN cells. It is used as an input parameter for cell reselection criterion. If this parameter is set to 0, SIB3 does not contain the q-QualMin IE, and UEs use the default value negative infinity. In this case, only the signal level is used for UEs to select and reselect cells. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Min Required Quality Level for CE Mode B

Indicates the minimum received signal quality required by UEs in CE mode B for cell reselection to intra-frequency neighboring E-UTRAN cells. It is used as an input parameter for cell reselection criterion. If this parameter is set to 0, SIB3 does not contain the q-QualMin IE, and UEs use the default value negative infinity. In this case, only the signal level is used for UEs to select and reselect cells. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Min Required RX Level for CE Mode A

Indicates the minimum receive level required by UEs in CE mode A for cell reselection to intra-frequency neighboring E-UTRAN cells. It is used as an input parameter for cell reselection criterion. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Min Required RX Level for CE Mode B

Indicates the minimum receive level required by UEs in CE mode B for cell reselection to intra-frequency neighboring E-UTRAN cells. It is used as an input parameter for cell reselection criterion. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
NB-IoT Resel Relaxed Monitoring Meas Thld

Indicates the threshold for starting intra- or inter-frequency measurements for cell reselection for NB-IoT UEs that support relaxed monitoring measurement for cell reselection. If this parameter is set to NULL, relaxed monitoring measurements for cell reselection do not take effect in the NB-IoT cell. If this parameter is set to another value, a UE starts intra- or inter-frequency measurements for cell reselection when the difference between the reference signal quality and the current signal quality is greater than or equal to the value of this parameter. For details, see 3GPP TS 36.304. This parameter applies only to NB-IoT.
