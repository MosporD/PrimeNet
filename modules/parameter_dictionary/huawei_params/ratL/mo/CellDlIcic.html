CellDlIcic

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDlIcic

Description

The CellDlIcic MO consists of the parameters related to DL ICIC in the cell. It is used to set the band division scheme adopted by DL ICIC in the cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellDlpcPdschPa MO:
    • In the CellDlIcic MO, the value of AIcicPlusPCAdjRange must be less than PaPcOff value in CellDlpcPdschPa.

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP CELLAICICPLUSSTATUS

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Downlink band division scheme

Indicates the band division scheme used in downlink ICIC. The band division in the cell is adjusted according to the setting of this parameter so that the edge bands for neighboring cells do not overlap. If this parameter is set to INVALID, the cell does not distinguish center and edge bands. This parameter applies only to LTE FDD and LTE TDD.
User Attribution Gfactor Threshold

Indicates the G factor threshold for user attribute determination in downlink adaptive Inter-Cell Interference Coordination (ICIC). If downlink adaptive ICIC is enabled, the eNodeB selects cell edge users (CEUs) from the users whose G factors are less than this threshold. Determine the parameter value based on the distribution of UEs' modulation and coding scheme (MCS) indexes within an area so that about one third user are determined to be CEUs. For example, if an area is covered by 155 cells and the percentages of users whose MCS indexes are less than 6 and 7 are about 30% and 40%, respectively, you can set this parameter to 1. (The G factors corresponding to MCS indexes 6 and 7 are 0.5 dB and 1.45 dB, respectively.) The G factors corresponding to MCS indexes 0 to 28 are -5.65, -4.5, -3.55, -2.35, -1.5, -0.5, 0.5, 1.45, 2.45, 3.4, 3.7, 4.4, 5.4, 6.3, 7.25, 8.3, 8.95, 9.6, 10.15, 11.15, 12.1, 13.15, 14.05, 15.1, 16, 17, 18.1, 19, and 20.1, respectively. This parameter applies only to LTE FDD and LTE TDD.
Noise User RSRP Threshold

Indicates the RSRP threshold used to determine noise-limited UEs on the network. If none of the neighboring-cell RSRP values included in A3 reports sent by a UE exceeds this threshold, the eNodeB does not consider these A3 reports when calculating interference. In most cases, the recommended RSRP threshold is -102. In tests on small-scale networks, this parameter can be set to other values. (The actual RSRP value is equal to -140 plus the GUI value of this parameter.) This parameter applies only to LTE FDD and LTE TDD.
AICIC Plus A3 Offset

Indicates the A3 offset for enhanced AICIC. A large value of this parameter indicates a small number of cell edge users and a small value of this parameter indicates a large number of cell edge users. If the parameter value is increased, the probability of UEs reporting event A3 is reduced. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD cells.
AICIC Plus Power Control Adjustment Range

Indicates the cell power adjustment range in enhanced AICIC. This parameter must be set to a PDSCH PA value that is less than the value of the PaPcOff parameter. At most two values can be selected for the AIcicPlusPCAdjRange parameter. If one value is selected for the AIcicPlusPCAdjRange parameter, the power can be changed to the selected value and the PDSCH PA value specified by the PaPcOff parameter. If two values are selected for the AIcicPlusPCAdjRange parameter, the power can be changed to the selected two values and the PDSCH PA value specified by the PaPcOff parameter. This parameter must be set before the enhanced AICIC feature is enabled. This parameter applies only to LTE FDD.
