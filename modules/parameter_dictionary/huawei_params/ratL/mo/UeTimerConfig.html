UeTimerConfig

+-NE
  +-eNodeBFunction
    +-UeTimerConfig

Description

A UeTimerConfig MO consists of parameters related to a timer.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST UETIMERCONFIG

Use this command to list UE timer configurations.
MOD UETIMERCONFIG

Use this command to modify UE timer configurations.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Timer Type

Indicates the timer type. This parameter applies only to NB-IoT.
Timer Duration

Indicates the duration of the timer. If the parameter setting is changed, the change applies only to UEs that access the network afterwards.
Millisecond-level Timer Duration

Indicates the length of the UE timer.

If the TimerType parameter is set to NB_CL0_T310, NB_CL1_T310, or NB_CL2_T310, this parameter can be set to 0, 200, 500, 1000, 2000, 4000, or 8000.

If the TimerType parameter is set to NB_CL0_T311, NB_CL1_T311, or NB_CL2_T311, this parameter can be set to 1000, 3000, 5000, 10000, 15000, 20000, 30000, 40000, 60000, 90000, or 120000.

If this parameter is set to 4294967295, the corresponding T310 and T311 timers do not take effect. If the parameter setting is changed, the change applies only to UEs that access the network afterwards. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
Max Num of UE Sync or Out-of-Sync Indication

Indicates the maximum number of consecutive synchronization or out-of-synchronization indications that a UE receives from lower layers. If the TimerType parameter is set to NB_CL0_N310, NB_CL1_N310, or NB_CL2_N310, this parameter can be set to 1, 2, 3, 4, 6, 8, 10, or 20. If the TimerType parameter is set to NB_CL0_N311, NB_CL1_N311, or NB_CL2_N311, this parameter can be set to 1, 2, 3, 4, 5, 6, 8, or 10. If this parameter is set to 0, this parameter does not take effect. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
