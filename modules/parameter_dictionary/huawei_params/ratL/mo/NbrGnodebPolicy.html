NbrGnodebPolicy

+-NE
  +-eNodeBFunction
    +-NbrGnodebPolicy

Description

This MO is used to configure the policy of a neighboring gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NBRGNODEBPOLICY

Use this command to add a neighboring gNodeB policy.
LST NBRGNODEBPOLICY

Use this command to list one or more neighboring gNodeB policies.
MOD NBRGNODEBPOLICY

Use this command to modify a neighboring gNodeB policy.
RMV NBRGNODEBPOLICY

Use this command to remove a neighboring gNodeB policy.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the MCC of an external NR cell. A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
gNodeB ID

Indicates the gNodeB ID of an external NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.
LTE to NR PLMN Selection Mode

Indicates the PLMN filling mode in LTE-to-NR procedures, including LTE-to-NR handovers and EN-DC X2 self-setup in NSA networking.

If this parameter is set to NOT_CFG, the PLMN filling mode is dependent on the EnodebAlgoExtSwitch.LteToNrPlmnSelectionMode parameter value. If this parameter is set to PRIMARY_PLMN_ID, the primary PLMN of the cell served by the gNodeB is filled in. If this parameter is set to SELECTED_PLMN_ID, the PLMN selected by the UE in the cell served by the gNodeB is filled in. If this parameter is set to HYBRID_PLMN_ID, the PLMN to be filled in depends on the cell identities corresponding to different PLMNs for the same NR cell served by the gNodeB. If different PLMNs correspond to different cell identifies, the PLMN selected by the UE is filled in. If different PLMNs correspond to the same cell identify, the primary PLMN of the cell served by the gNodeB is filled in. This parameter applies only to LTE FDD and LTE TDD.
