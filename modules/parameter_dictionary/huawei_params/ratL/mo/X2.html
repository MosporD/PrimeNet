X2

+-NE
  +-eNodeBFunction
    +-X2

Description

An X2 MO consists of parameters related to the transport resources for X2 interfaces. The configuration items include the control-plane end point group ID, user-plane end point group ID, and the CN operator that owns the X2 object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the ENodeBSharingMode MO:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, CnOpSharingGroupId in the X2 MO must have been configured in the associated CnOpSharingGroup MO.
  • Relation with the CnOpSharingGroup MO:
    • CnOpSharingGroupId in the X2 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
    • The operator corresponding to CnOperatorId in the X2 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
  • Relation with the EPGROUP MO:
    • If the eNodeB works in hybrid RAN sharing mode, the value of the SCTPHOSTID parameter in the SCTPHOST MOs referenced by the X2 MOs with the same CnOperatorId parameter value and the same CnOpSharingGroupId parameter value must be the same.
    • If the eNodeB works in hybrid RAN sharing mode, the value of the UPHOSTID parameter in the USERPLANEHOST MOs referenced by the X2 MOs with the same CnOperatorId parameter value and the same CnOpSharingGroupId parameter value must be the same.
    • The EPGROUP MO referenced by CpEpGroupId in an X2 MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by UpEpGroupId in an X2 MO must have been configured, and at most six USERPLANEHOST MOs with IPVERSION set to IPv6 can be configured for the EPGROUP.
  • Relation with the EPGROUP, SCTPHOST, and ENodeBSharingMode MOs:
    • In hybrid RAN sharing, the X2 MOs with different CnOpSharingGroupId values cannot reference the SCTPHOST MOs with the same PN value and IPv4 address.
    • In RAN sharing with dedicated carriers mode, the X2 MOs with different CnOperatorId values cannot reference the EPGROUP MOs that contain theSCTPHOST MOs with the same PN and IPv4 address.
    • In RAN sharing with dedicated carriers mode, the X2 MOs with different CnOperatorId values cannot reference the EPGROUP MOs that contain theSCTPHOST MOs with the same PN and IPv6 address.
    • In hybrid RAN sharing, the X2 MOs with different CnOpSharingGroupId values must not reference the SCTPHOST MOs with the same PN value and IPv6 address.
  • Relation with the ENodeBSharingMode and SCTPHOST MOs:
    • If the eNodeB works in independent mode, RAN sharing with common carriers mode, RAN sharing with dedicated carriers mode, or RAN sharing with special dedicated carriers mode, the value of the SCTPHOSTID parameter in the SCTPHOST MOs referenced by the X2 MOs with the same CnOperatorId parameter value must be the same.
  • Relation with the ENodeBSharingMode, USERPLANEHOST, and EPGROUP MOs:
    • If the eNodeB works in independent mode, RAN sharing with common carriers mode, RAN sharing with dedicated carriers mode, or RAN sharing with special dedicated carriers mode, the value of the UPHOSTID parameter in the USERPLANEHOST MOs referenced by the X2 MOs with the same CnOperatorId parameter value must be the same.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by the UpEpGroupId parameter in an X2 MO must be configured. In addition, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to DISABLE.
  • Relation with the S1 MO:
    • CpEpGroupId in an X2 MO must be different from CpEpGroupId in any S1 MO.
    • UpEpGroupId in an X2 MO must be different from UpEpGroupId in any S1 MO.
    • CpEpGroupId in an X2 MO must be different from UpEpGroupId in any S1 MO.
    • UpEpGroupId in an X2 MO must be different from CpEpGroupId in any S1 MO.
  • Relation with the CnOperator MO:
    • CnOperatorId in an X2 MO must have been configured in the associated CnOperator MO.
  • Relation with the M2 MO:
    • CpEpGroupId in an X2 MO must be different from M2EpGroupId in any M2 MO.
    • UpEpGroupId in an X2 MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the M1 MO:
    • UpEpGroupId in an X2 MO must be different from M1EpGroupId in any M1 MO.
    • CpEpGroupId in an X2 MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the EPGROUP, USERPLANEHOST, and ENodeBSharingMode MOs:
    • In RAN sharing with dedicated carriers mode, the X2 MOs with different CnOperatorId values cannot reference the EPGROUP MOs that contain theUSERPLANEHOST MOs with the same IPv4 address.
    • In RAN sharing with dedicated carriers mode, the X2 MOs with different CnOperatorId values cannot reference the EPGROUP MOs that contain theUSERPLANEHOST MOs with the same IPv6 address.
  • Relation with the eX2 MO:
    • CpEpGroupId in an X2 MO must be different from CpEpGroupId in any eX2 MO.
  • Relation with the SO MO:
    • CpEpGroupId in an X2 MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an X2 MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an X2 MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an X2 MO must be different from CpEpGroupId in any SO MO.
  • Relation with the EPGROUP and GTRANSPARA MOs:
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by CpEpGroupId in an X2 MO must have been configured.
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by UpEpGroupId in an X2 MO must have been configured.
  • Relation with the EPGROUP, GTRANSPARA, and SCTPHOST MOs:
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by CpEpGroupId in an X2 MO must have been configured. And the SCTPHOST MO referenced by the EPGROUP MO must have been configured.
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by CpEpGroupId in an X2 MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
  • Relation with the EPGROUP, GTRANSPARA, and USERPLANEHOST MOs:
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by UpEpGroupId in an X2 MO must have been configured. And the USERPLANEHOST MO referenced by the EPGROUP MO must have been configured.
    • If EPCFGMODE in the GTRANSPARA MO is not set to X2SIMPLE_MODE, the EPGROUP MO referenced by UpEpGroupId in an X2 MO must have been configured, and at most six USERPLANEHOST MOs with IPVERSION set to IPv4 can be configured for the EPGROUP.
  • Relation with the eX2 and GTRANSPARA MOs:
    • If X2 and eX2 MO are all existed, the value X2SIMPLE_MODE and EX2SIMPLE_MODE of EPCFGMODE in GTRANSPARA MO must be the same.
  • Relation with the GTRANSPARA MO:
    • If EPCFGMODE in the GTRANSPARA MO is set to X2SIMPLE_MODE, EpGroupCfgFlag in the X2 MO must be set to CP_UP_CFG.
    • If EPCFGMODE in the GTRANSPARA MO is set to X2SIMPLE_MODE, CnOperatorId in X2 MOs cannot be set to the same value.
  • Relation with the SCTPHOST and GTRANSPARA MOs:
    • If EPCFGMODE in a GTRANSPARA MO is set to X2SIMPLE_MODE, an SCTPHOST MO with SIMPLEMODESWITCH set to X2SIMPLE_MODE_ON must have been configured, and CpEpGroupId in the X2 MO must be equal to CPEPGROUPID1 and UpEpGroupId in the X2 MO must be equal to UPEPGROUPID1, or CpEpGroupId in the X2 MO must be equal to CPEPGROUPID2 and UpEpGroupId in the X2 MO must be equal to UPEPGROUPID2.
  • Relation with the XW MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any X2 MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any X2 MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any X2 MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any X2 MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD X2

Use this command to add an X2 object.
DSP X2

Use this command to query the control-plane configuration of X2 interfaces for which the Control Mode parameter in the X2Interface MO is set to AUTO_MODE.
LST X2

Use this command to list the X2 object information, including the X2 ID, CN Operator ID, End Point Group Config Flag, Control Plane End Point Group ID, User Plane End Point Group ID, Target eNodeB Release, User Label, and CN Operator Sharing Group ID.
MOD X2

Use this command to modify the parameters in an X2 MO.
RMV X2

Use this command to remove an X2 object.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
X2 ID

Indicates the X2 MO ID.
CN Operator ID

Indicates the ID of the operator to which the X2 MO belongs.
Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the X2 MO.
User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the X2 MO. This parameter applies only to LTE FDD and LTE TDD.
Peer Base Station Release

Indicates the protocol release with which the peer base station connected to the local base station through the X2 interface complies. This parameter applies only to LTE FDD and LTE TDD.
User Label

Indicates the description of the X2 MO.
End Point Group Config Flag

Indicates whether to configure the control-plane or user-plane endpoint group.
CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group that shares the X2 MO. If the eNodeB works in hybrid RAN sharing mode, set this parameter to a value within the range from 0 to 5. If the eNodeB works in independent mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, retain the default value 255, which is an invalid value.
