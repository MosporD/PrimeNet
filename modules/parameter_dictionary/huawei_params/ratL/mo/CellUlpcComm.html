CellUlpcComm

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellUlpcComm

Description

The CellUlpcComm MO consists of the parameters related to UL power control over common radio resources in the cell, such as the target UE transmit power for the PUCCH expected by the eNodeB on condition that normal demodulation can be performed.

For details about UL power control, see 3GPP TS 36.213.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.
Path loss coefficient

Indicates the compensation factor for path loss. It is used in UL power control. For details, see 3GPP TS 36.213.
P0 nominal PUCCH

Indicates the target UE transmit power for the PUCCH expected by the eNodeB on condition that normal demodulation can be performed. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
P0 nominal PUSCH

Indicates the nominal P0 value of the PUSCH. It is used in UL power control. For details, see 3GPP TS 36.213.
DeltaF for PUCCH format 1

Indicates the Delta value corresponding to PUCCH format 1. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
DeltaF for PUCCH format 1b

Indicates the Delta value corresponding to PUCCH format 1b. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
DeltaF for PUCCH format 2

Indicates the Delta value corresponding to PUCCH format 2. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
DeltaF for PUCCH format 2a

Indicates the Delta value corresponding to PUCCH format 2a. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
DeltaF for PUCCH format 2b

Indicates the Delta value corresponding to PUCCH format 2b. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Delta preamble value for msg3

Indicates the power offset (delta value) of message 3 relative to the preamble. This power offset has a step size of 2. For details, see 3GPP TS 36.213.
Delta Message 2

Indicates the power offset of Msg3 transmitted during uplink random access. This parameter is also used to set the initial power of the PUSCH or PUCCH for closed-loop power control. This parameter applies only to LTE FDD and LTE TDD.
PUCCH Format 1bcs Delta

Indicates the delta of PUCCH format 1bcs. For details about how to use this parameter, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
PUCCH Format 3 Delta

Indicates the delta of PUCCH format 3. For details about how to use this parameter, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
