MBMSPara

+-NE
  +-eNodeBFunction
    +-MBMSPara

Description

The MBMSPara MO consists of parameters related to Multimedia Broadcast Multicast Service (MBMS) provided by the eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP MBMSPARA

Use this command to query eNodeB MBMS information.
LST MBMSPARA

Use this command to list the eNodeB MBMS parameter.
MOD MBMSPARA

Use this command to modify eNodeB MBMS parameter.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Synchronisation Period

Indicates the synchronization period of the SYNC protocol. This parameter applies only to LTE FDD and LTE TDD.
MBMS Control Switch

Indicates the switches to control eNodeB-level MBMS services. This parameter provides the following options:

SessionForMultiMASwitch: A single MBMS session can be broadcasted in multiple MBSFN areas in an eNodeB only if this option is selected. This option applies only to LTE FDD and LTE TDD.

M2DisconnProtectSwitch: Indicates whether to delete eMBMS sessions on the eNodeB with time delays after the M2 interface is interrupted. If this option is selected, eMBMS sessions on the eNodeB are deleted with a time delay after the M2 interface is interrupted. Otherwise, eMBMS sessions are immediately deleted in this situation. This option applies only to LTE FDD and LTE TDD.

SyncPduCompatibilitySwitch: Indicates whether the M1 interface complies with the R13 SYNC protocol. The switch setting must be consistent with that in the SYNC protocol version of the BMSC. If this option is selected, SYNC PDU counting does not include SYNC PDU headers. If this option is deselected, SYNC PDU counting includes SYNC PDU headers. This option applies only to LTE FDD and LTE TDD.
M2 Interface Disconnect Protect Time

Indicates the delay after which the eNodeB deletes MBMS sessions if the M2 interface is interrupted. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
MBSFN Area ID

Indicates the ID of a Multimedia Broadcast Single Frequency Network (MBSFN) area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.
Cell Reservation Info

Indicates whether the cell is a reserved cell for Multimedia Broadcast Multicast Service (MBMS) services. This parameter applies only to LTE FDD and LTE TDD.
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
