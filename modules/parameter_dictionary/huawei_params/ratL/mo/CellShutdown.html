CellShutdown

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellShutdown

Description

The CellShutDown MO consists of the parameters related to intelligent power-off of carriers in the same coverage. This feature applies to scenarios where the local cell has inter-frequency neighboring cells under the same eNodeB. If the local cell and its intra-eNodeB inter-frequency neighboring cells are all lightly loaded and the PRB usage of the local cell meets the conditions for intelligent power-off of carriers in the same coverage, the local cell enters intelligent power-off of carriers in the same coverage mode after all UEs are diverted to these inter-frequency neighboring cells. Then, if the intra-eNodeB inter-frequency neighboring cells become heavily loaded, the local cell automatically exits intelligent power-off of carriers in the same coverage mode. With this feature, the power consumption is reduced. A cell enters intelligent power-off of carriers in the same coverage mode when all the following conditions are met: (1) the local cell has at least an intra-eNodeB inter-frequency neighboring cell whose intelligent power-off of carriers switch is enabled and the UL or DL PRB usage threshold is set to 0, which is also called a basic cell; (2) the basic cell works properly and serves the same PLMNs as the local cell; (3) intelligent power-off of carriers switch is enabled in the local cell and the time is within the duration when intelligent power-off of carriers in the same coverage is active in both cells; (4) both cells are lightly loaded and the PRB usage of the local cell meets the conditions to start intelligent power-off of carriers in the same coverage; (5) (this condition is required when there are ongoing services in the local cell) inter-frequency handover is enabled.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellMLB and CellAlgoSwitch MOs:
    • When option InterFreqMlbSwitch or InterFreqBlindMlbSwitch of MlbAlgoSwitch in CellAlgoSwitch is selected, MlbTriggerMode in CellMLB is set to PRB_ONLY or PRB_OR_UE_NUMBER and CellShutdownSwitch in CellShutdown is set to a value other than OFF, the sum of InterFreqMlbThd and LoadOffset in the CellMLB MO must be greater than that of DlPrbThd and DlPrbOffset in the CellShutdown MO. In addition, the sum of InterFreqMlbThd and LoadOffset in the CellMLB MO must be greater than that of UlPrbThd and UlPrbOffset in the CellShutdown MO.
    • When option InterFreqMlbSwitch or InterFreqBlindMlbSwitch of MlbAlgoSwitch in CellAlgoSwitch is selected, MlbTriggerMode in CellMLB is set to PRB_ONLY or PRB_OR_UE_NUMBER and CellShutdownSwitch in CellShutdown is set to a value other than OFF, InterFreqMlbThd in the CellMLB MO must be greater than DlPrbThd in the CellShutdown MO. In addition, InterFreqMlbThd in the CellMLB MO must be greater than UlPrbThd in the CellShutdown MO.

    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR and the LteNrCoCarrCoCpriDataSw parameter in the LteNrSpctShrCellGrp MO is set to ON, the CellShutdownSwitch parameter in the CellShutdown MO must be set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
Intelligent power-off of carriers switch

Indicates whether to enable intelligent power-off of carriers.

If this parameter is set to ON and the cell meets specific conditions, intelligent power-off of carriers is performed and the eNodeB does not identify co-coverage cells automatically.

If this parameter is set to ON_CO_COV_AUTO_IDENT, coverage analysis will be started for the cell. The proportion of overlapping coverage between the capacity cell and basic cells and the proportion of coverage holes that may be generated after the capacity cell is shut down are analyzed based on inter-frequency MRs. The analysis results are used to determine whether to enable intelligent power-off of carriers.

If this parameter is set to ON_MULTI_CARRIER_HIER_SHUTDOWN, coverage analysis will be started for the cell. The total load of multiple carriers in the coverage area of the cell is calculated based on the co-coverage identification result, and the total load is then compared with the PRB thresholds (specified by DlPrbThd and UlPrbThd in the CellShutdown MO) and offsets (specified by DlPrbOffset and UlPrbOffset in the CellShutdown MO) set for the capacity cell to determine whether to trigger hierarchical intelligent power-off of multiple carriers.

If this parameter is set to OFF, intelligent power-off of carriers does not take effect.
Start time

Indicates the start time of intelligent power-off of carriers.
Stop time

Indicates the stop time of intelligent power-off of carriers. If the stop time is earlier than or the same as the start time, the stop time is assumed to be a time of the next day.
Downlink PRB threshold

For FDD and TDD cells, this parameter indicates the downlink PRB usage threshold for starting intelligent power-off of carriers. For NB-IoT cells, this parameter indicates the downlink subcarrier usage threshold.
Downlink PRB offset

For FDD and TDD cells, this parameter indicates the offset to the downlink PRB usage for stopping intelligent power-off of carriers. The downlink PRB usage threshold for stopping intelligent power-off of carriers is equal to the sum of the value of this parameter and the value of the DlPrbThd parameter in the CellShutdown MO. For NB-IoT cells, this parameter indicates the offset to the downlink subcarrier usage.
Uplink PRB threshold

For FDD and TDD cells, this parameter indicates the uplink PRB usage threshold for starting intelligent power-off of carriers. For NB-IoT cells, this parameter indicates the uplink subcarrier usage threshold.
Uplink PRB offset

For FDD and TDD cells, this parameter indicates the offset to the uplink PRB usage for stopping intelligent power-off of carriers. The uplink PRB usage threshold for stopping intelligent power-off of carriers is equal to the sum of the value of this parameter and the value of the UlPrbThd parameter in the CellShutdown MO. For NB-IoT cells, this parameter indicates the offset to the uplink subcarrier usage.
Force Shutdown UE Number Threshold

Indicates the UE quantity threshold for forcible cell shutdown in intelligent power-off of carriers. If a capacity cell meets the conditions for triggering intelligent power-off of carriers, the eNodeB hands over UEs in the capacity cell to a basic cell within 60s. At the end of the 60-second period, if the number of RRC_CONNECTED UEs in the capacity cell is smaller than or equal to this threshold and no UEs with QCI 1 exist in the capacity cell, the eNodeB shuts down the capacity cell. If there are UEs in the capacity cell when the eNodeB is shutting down the cell, service drops occur on these UEs.
Punish Time

Indicates the duration of penalty on triggering condition evaluation for the intelligent power-off of carriers feature if UEs in the capacity cell cannot be completely transferred to basic cells after intelligent power-off of carriers is triggered.
Inter-BBU Carrier Shutdown Switch

Indicates whether intelligent power-off of carriers in the same coverage supports inter-BBU carrier shutdown. If this parameter is set to ON, intelligent power-off of carriers in the same coverage supports inter-BBU carrier shutdown, and inter-BBU carrier shutdown is performed when certain conditions are met. If this parameter is set to OFF, intelligent power-off of carriers in the same coverage does not support inter-BBU carrier shutdown. This parameter applies only to LTE FDD and LTE TDD.
UE Number Threshold

Indicates the UE quantity threshold for triggering intelligent power-off of carriers in the cell. If the number of RRC_CONNECTED UEs in the capacity cell is less than this threshold and the loads of the capacity cell and basic cell meet the preset uplink and downlink PRB usage thresholds for triggering intelligent power-off of carriers, intelligent power-off of carriers is started for the capacity cell.
