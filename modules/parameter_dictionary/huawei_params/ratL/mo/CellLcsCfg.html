CellLcsCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellLcsCfg

Description

This MO consists of parameters used to configure LCS for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, eUCellSectorEqm, BASEBANDEQM, BBP, EuSectorEqmGroup, CellAlgoSwitch, and ENodeBAlgoSwitch MOs:
    • For a Cell MO in which the values of CellActiveState, FddTddInd, and NbCellFlag are CELL_ACTIVE, CELL_FDD, and FALSE, respectively, if the eUCellSectorEqm or EuSectorEqmGroup MOs corresponding to this Cell MO are bound to BASEBANDEQM MOs, and WM is set to SPEC_MODE1 and only the LTE_FDD option or only the LTE_FDD and NBIOT options of BBWS are selected in the BBP MOs corresponding to these BASEBANDEQM MOs, then: (1) UlCyclicPrefix and DlCyclicPrefix in the Cell MO cannot be set to EXTENDED_CP. (2) CellRadius cannot be set to a value larger than 100000. (3) MultiRruCellMode cannot be set to TWO_RRU_COMBINATION. (4) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO cannot be selected. (5) The NB_OTDOA_SWITCH option of CellLcsSwitch in the CellLcsCfg MO and the OtdoaSwitch option of LcsSwitch in the ENodeBAlgoSwitch MO cannot be selected. (6) TxRxMode in the Cell MO cannot be set to a value larger than 4T4R. (7) CellBeamMode in the eUCellSectorEqm MOs cannot be set to MASSIVE_MIMO_Ph1 or MASSIVE_MIMO_Ph2. (8) ANTCFGMODE in the SECTOREQM MOs corresponding to the eUCellSectorEqm or EuSectorEqmGroup MOs cannot be set to BEAM.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.
NB-IoT E-CID-based Positioning UE Count

Indicates the maximum number of UEs that can simultaneously perform measurements for E-CID-based positioning in a cell. E-CID-based positioning is enabled in a cell only if this parameter is set to a non-zero value. This parameter applies only to NB-IoT.
Cell LCS Switch

Indicates whether to enable location service (LCS) functions in the cell.

NB_OTDOA_SWITCH: Indicates whether to enable OTDOA-based positioning for NB-IoT cells. OTDOA-based positioning is enabled for NB-IoT cells only if this option is selected.

For FDD and TDD cells, OTDOA-based positioning is enabled when either this option or the OtdoaSwitch option of the LcsSwitch parameter in the ENodeBAlgoSwitch MO is selected, and is disabled when both options are deselected.
