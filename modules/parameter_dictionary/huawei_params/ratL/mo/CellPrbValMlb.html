CellPrbValMlb

+-NE
  +-eNodeBFunction

Description

The CellPrbValMlb MO consists of parameters related to load balancing algorithms based on RB evaluation values.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
PRB Valuation MLB Trigger Threshold

Indicates the threshold of the PRB evaluation value for triggering MLB based on the PRB evaluation value. This parameter takes effect only when the MlbTriggerMode parameter in the CellMLB MO is set to PRB_ONLY or PRB_OR_UE_NUMBER and the PrbLoadCalcMethod parameter in the CellMLB MO is set to PRB_VALUATION_WITH_CTRL or PRB_VALUATION_NO_CTRL. If the number of UEs meets the minimum UE quantity condition for triggering MLB and the PRB evaluation value is greater than or equal to the sum of this threshold and the load offset, MLB is triggered. If the number of UEs meets the minimum UE quantity condition for terminating MLB or the PRB evaluation value is less than this threshold, MLB is terminated. This parameter applies only to LTE FDD and LTE TDD.
PRB Valuation MLB Admit Threshold

Indicates the threshold of the PRB evaluation value for determining a target neighboring cell for inter-frequency MLB. This parameter takes effect only when the MlbTriggerMode parameter in the CellMLB MO is set to PRB_ONLY or PRB_OR_UE_NUMBER and the PrbLoadCalcMethod parameter in the CellMLB MO is set to PRB_VALUATION_WITH_CTRL or PRB_VALUATION_NO_CTRL. If the PRB evaluation value of a neighboring cell is less than this threshold, this neighboring cell can be selected as a target cell for MLB. If the PRB evaluation value of a neighboring cell is greater than or equal to this threshold, this neighboring cell cannot be selected as a target cell for MLB. This parameter applies only to LTE FDD and LTE TDD.
Mlb UE Selection PRB Valuation Threshold

Indicates the threshold of the UE-specific PRB evaluation value for selecting UEs for MLB. A UE is transferred for MLB based on PRB evaluation only when the downlink or uplink PRB evaluation value of the UE is higher than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
PRB Valuation Filter Factor

Indicates the filtering coefficient used to calculate the PRB evaluation value. The filtering value is calculated by weighting the measured PRB evaluation value and historical filtering value based on the filtering coefficient. If this parameter is set to a smaller value, the filtering value is more close to the historical filtering value. If this parameter is set to a larger value, the filtering value is more close to the measured value. This parameter applies only to LTE FDD and LTE TDD.
