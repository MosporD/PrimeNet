Qci5qiConfig

+-NE
  +-eNodeBFunction
    +-Qci5qiConfig

Description

A Qci5qiConfig MO consists of parameters related to the mapping between a QCI and a 5G QoS Identifier (5QI). This MO is used to map a 5QI to a QCI when the eNodeB is connected to the 5GC.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR 5G QoS Identifier

Indicates the 5G QoS Identifier (5QI) of a QoS flow that needs to be mapped to a QCI. Different 5QIs represent different QoS specifications such as the packet delay budget, packet loss rate, average window, and service type (whether the service is a GBR service or not). For details, see 3GPP TS 23.501.

When a new 5QI is configured on the core network:

1. If no Qci5qiConfig MO is added for this 5QI, this 5QI is mapped to QCI 9 by default.

2. If a Qci5qiConfig MO is added for this 5QI but the QCI mapped to this 5QI is not configured on the base station side, the base station processes this 5QI as if the mapping between the 5QI and QCI is not configured.

This parameter applies only to LTE FDD and LTE TDD.
Access Service Reflective QoS Switch

Indicates whether to enable the AS reflective QoS function. For details about reflective QoS, see 3GPP TS 23.501. If the parameter is set to ON, the UE can obtain the mapping between QoS flows and the DRBs by monitoring the QoS flow identity (QFI) of the data packet transmitted on each DRB. If this parameter is set to OFF, this function is disabled. This parameter applies only to LTE FDD and LTE TDD.
QoS Class Identifier

Indicates the QCI that is mapped to the 5QI. This parameter applies only to LTE FDD and LTE TDD.
