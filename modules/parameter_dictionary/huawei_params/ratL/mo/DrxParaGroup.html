DrxParaGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-DrxParaGroup

Description

A DrxParaGroup MO consists of a group of QCI-specific discontinuous reception (DRX) parameters. DRX parameter groups are mapped to different QCIs to meet different service requirements.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.
DRX parameter group ID

Indicates the ID of the DRX parameter group.
Enter DRX Switch

Indicates whether bearers to which the parameter group applies support DRX. The value ON indicates that the bearers support DRX. The value OFF indicates that the bearers do not support DRX. For NB-IoT UEs, this parameter applies only to the service-based QoS management feature. If this parameter is set to ON, the bearers support QCI-level DRX. If this parameter is set to OFF, the bearers do not support QCI-level DRX, and the eNodeB delivers DRX parameters defined in the CellDrxPara MO of the cell that a UE accesses to the UE.
On Duration Timer

Indicates the length of the On Duration Timer. If the configured value does not meet the restrictions of CQI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. This parameter applies only to LTE FDD and LTE TDD.
DRX Inactivity Timer

Indicates the length of the DRX inactivity timer. This parameter applies only to LTE FDD and LTE TDD.
DRX Retransmission Timer

Indicates the length of the DRX Retransmission Timer. This parameter applies only to LTE FDD and LTE TDD.
Long DRX Cycle

Indicates the length of the long DRX cycle. Because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter, the actual value of this parameter assigned to a UE may be less than the configured value. In addition, the configured value will be rounded down to an integral multiple of 10. Therefore, you are advised to set this parameter to a value that is an integral multiple of 10.

If users hope that the value actually assigned to a UE is greater than or equal to 80 ms, set the TimeAlignmentTimer parameter to a value greater than or equal to 10240 ms. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the LongDrxCycle parameter be set to a value less than or equal to 320 ms. Otherwise, the uplink time alignment performance of UEs is affected. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the TimeAlignmentTimer parameter be set to sf10240. A smaller value of the TimeAlignmentTimer parameter (for example less than sf5120), increases the probability that UEs in DRX mode are out of synchronization in the uplink. The length of the long DRX cycle must be shorter than the length of the PDCP packet discarding timer for the corresponding QCI. Otherwise, packet loss occurs during a ping operation or low-traffic service. This parameter applies only to LTE FDD and LTE TDD.
Short-Cycle DRX Supported Indication

Indicates whether short DRX cycles are enabled. This parameter applies only to LTE FDD and LTE TDD.
Short DRX Cycle

Indicates the length of the short DRX cycle. According to 3GPP specifications, the length of a long DRX cycle must be an integer multiple of that of a short DRX cycle. In addition, the actual value of LongDrxCycle assigned to a UE may be less than the configured value because of the restrictions of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter. Therefore, the actual value of ShortDrxCycle assigned to a UE may be less than the configured value. This parameter applies only to LTE FDD and LTE TDD.
DRX Short Cycle Timer

Indicates the length of the DRX Short Cycle Timer. If this parameter is set to 1, the length of this timer is one short DRX cycle. If this parameter is set to 2, the length of this timer is two short DRX cycles. If this parameter is set to a large value, a UE for which short DRX cycles are enabled stays in short-cycle DRX for a long time. For details, see section 5.7 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.
Uplink DRX Retransmission Timer

Indicates the length of the uplink DRX Retransmission Timer. This parameter applies only to LTE FDD and LTE TDD.
Extended Long DRX Cycle

Indicates the length of the extended long DRX cycle. This parameter applies only to LTE FDD and LTE TDD.
Extended Long DRX Cycle Switch

Indicates whether to enable extended long DRX cycles. This parameter applies only to LTE FDD and LTE TDD.
Category Type

Indicates the UE category type. If this parameter is set to LTE, EMTC_MODE_A, or EMTC_MODE_B, other parameters in this MO apply to LTE UEs, eMTC UEs in mode A, or eMTC UEs in mode B, respectively. If this parameter is set to NB-IoT, other parameters in this MO apply to NB-IoT UEs.
NB-IoT DRX Inactivity Timer

Indicates the length of the DRX Inactivity Timer of an NB-IoT UE. The unit is the PDCCH period of the coverage level corresponding to a UE. This parameter applies only to NB-IoT.
NB-IoT DRX Retransmission Timer

Indicates the length of the DRX Retransmission Timer for an NB-IoT UE. The unit is the PDCCH period of the coverage level corresponding to a UE. This parameter applies only to NB-IoT.
NB-IoT DRX Uplink Retransmission Timer

Indicates the length of the DRX Uplink Retransmission Timer for an NB-IoT UE. The unit is the PDCCH period of the coverage level corresponding to a UE. This parameter applies only to NB-IoT.
NB-IoT Long DRX Cycle

Indicates the length of the Long DRX Cycle for an NB-IoT UE. This parameter applies only to NB-IoT.
NB-IoT On Duration Timer

Indicates the length of the On Duration Timer for an NB-IoT UE. The unit is the PDCCH period of the coverage level corresponding to a UE. This parameter applies only to NB-IoT.
