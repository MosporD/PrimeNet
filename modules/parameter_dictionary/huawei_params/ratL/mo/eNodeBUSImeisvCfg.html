eNodeBUSImeisvCfg

+-NE
  +-eNodeBFunction
    +-eNodeBUSImeisvCfg

Description

The eNodeBUSImeisvCfg MO consists of parameters related to IMEISV configuration for identifying UEs running unlimited services. If the IMEISV carried in an initial context setup request or handover request message sent from the CN matches the configured IMEISV information, the eNodeB determines that the UE runs unlimited services.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ENODEBUSIMEISVCFG

Use this command to add IMEISV information, which is used for identifying UEs running unlimited services.
LST ENODEBUSIMEISVCFG

Use this command to display all configured ImeisvTac and ImeisvSvn information and related descriptions for identifying UEs running unlimited services.
MOD ENODEBUSIMEISVCFG

Use this command to modify IMEISV information, which is used for identifying UEs running unlimited services.
RMV ENODEBUSIMEISVCFG

Use this command to remove information about a configured IMEISV.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IMEISV TAC

Indicates the type allocation code (TAC) in the IMEISV of UEs. The TAC identifies the UE model. For details about the definition of IMEISV, see section 6.2.2 in 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.
IMEISV SVN

Indicates the software version number (SVN) which is an element of the international mobile station equipment identity and software version (IMEISV) and specifies the software version of UEs. For details about the definition of IMEISV, see section 6.2.2 in 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.
Ue Type Description

Indicates the description of the model of UE. This parameter applies only to LTE FDD and LTE TDD.
