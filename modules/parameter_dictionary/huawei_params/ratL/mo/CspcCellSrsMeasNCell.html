CspcCellSrsMeasNCell

+-NE
  +-eNodeBFunction
    +-CspcCellSrsMeasNCell

Description

Information about a neighboring cell on which uplink reference signal received power (RSRP) measurement is conducted for coordinated scheduling and power control (CSPC) in Cloud BB scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CSPCCELLSRSMEASNCELL

Use this command to add a neighboring cell (for SRS measurement) for a local CSPC cell. This command takes effect only on the centralized control node.
LST CSPCCELLSRSMEASNCELL

Use this command to list the configuration of neighboring cells (for SRS measurement) of a local CSPC cell or all local CSPC cells. This command takes effect only on the centralized control node.
RMV CSPCCELLSRSMEASNCELL

Use this command to remove a neighboring cell (for SRS measurement) of a local CSPC cell. This command takes effect only on the centralized control node.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile country code

Indicates the mobile country code (MCC) of the local CSPC cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code (MNC) of the local CSPC cell.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the eNodeB identity of the local CSPC cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell identity is comprised of the cell identity and the eNodeB identity (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the cell identity of the local CSPC cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell identity (represented by the least significant eight bits) and the eNodeB identity. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Neighbor mobile country code

Indicates the mobile country code (MCC) of the neighboring cell performing sounding reference signal (SRS) measurements on UEs in the local CSPC cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Neighbor mobile network code

Indicates the mobile network code (MNC) of the neighboring cell performing sounding reference signal (SRS) measurements on UEs in the local CSPC cell.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Neighbor eNodeB ID

Indicates the eNodeB identity of the neighboring cell performing sounding reference signal (SRS) measurements on UEs in the local CSPC cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell identity is comprised of the cell identity and the eNodeB identity (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Neighbor Cell ID

Indicates the identity of the neighboring cell performing sounding reference signal (SRS) measurements on UEs in the local CSPC cell under the same eNodeB. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell identity (represented by the least significant eight bits) and the eNodeB identity. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
