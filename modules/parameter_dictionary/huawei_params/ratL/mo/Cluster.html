Cluster

+-NE
  +-eNodeBFunction
    +-Cluster
      +-ClusterCell[0~36]

Description

A Cluster MO consists of parameters related to a static cluster configured for coordinated scheduling and power control in Cloud BB scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    ClusterCell[0~36]
  • Relation with the ClusterCell MO:
    • If the ClusterType parameter in the Cluster MO is set to DLCOMP, a maximum of 36 ClusterCell MOs with the ClusterId parameter set to the same value can be configured.
    • If the ClusterType parameter in the Cluster MO is set to CAMC, a maximum of six ClusterCell MOs with the ClusterId parameter set to the same value can be configured.
    • For the Cluster MOs with the ClusterType parameter set to the same value, the combination of the values of the CellId, eNodeBId, Mcc, and Mnc parameters must be unique among all ClusterCell MOs.
    • If the ClusterType parameter in the Cluster MO is set to ULICS, a maximum of 12 ClusterCell MOs with the ClusterId parameter set to the same value can be configured.
    • If the ClusterType parameter in the Cluster MO is set to CSPC~0, a maximum of 72 ClusterCell MOs with the ClusterId parameter set to the same value can be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CLUSTER

Use this command to add a cluster. This command takes effect only on the centralized control node.
LST CLUSTER

Use this command to list cluster configuration. This command takes effect only on the centralized control node.
RMV CLUSTER

Use this command to remove a cluster. This command takes effect only on the centralized control node.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cluster ID

Indicates the ID of a cluster in Cloud BB scenarios. When static clusters are configured, the value of this parameter ranges from 0 to 999. This parameter applies only to LTE FDD and LTE TDD.
Cluster Type

Indicates the feature type of a cluster, which can be CSPC, DL CoMP, CAMC, or UL ISC. This parameter applies only to LTE TDD when it is set to DLCOMP(DLCOMP), CAMC(CAMC), or ULICS(ULICS).
