PrbSchConfig

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-PrbSchConfig

Description

A PrbSchConfig MO consists of non-coverage-level-specific scheduling parameters for PRB carriers of NB-IoT cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Prb
  • Relation with the Cell, PrbPdcchCeConfig, PrbDlGapConfig, and CellRachCECfg MOs:
    • If the NbCellFlag parameter in a Cell MO is set to BOOLEAN_TRUE and the DL_GAP_SWITCH option of the DlSchedulingSwitch parameter in the PrbSchConfig MO is selected, parameter adjustment is allowed for the coverage level for which the PdcchMaxRepetitionCnt parameter value is greater than or equal to the DlGapThreshold parameter value only when the following condition is met: The rounded-up result of (DlGapPeriod x DlGapDurationCoeff/(PdcchMaxRepetitionCnt x PdcchPeriodFactor) + 3) is less than the value of ContentionResolutionTimer and RaResponseWindowSize.
  • Relation with the Cell, PrbPdcchCeConfig, and PrbDlGapConfig MOs:
    • When the NbCellFlag parameter in a Cell is set to TRUE, the DL_GAP_SWITCH option of the DlSchedulingSwitch parameter in the PrbSchConfig MO can be selected for a PRB in the cell only if the PRB meets the following condition: The PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO is set to a value greater than G_4 for the coverage level for which the PdcchMaxRepetitionCnt parameter in the PrbPdcchCeConfig MO is set to a value greater than or equal to the value of the DlGapThreshold parameter in the PrbDlGapConfig MO or the PdcchMaxRepetitionCnt parameter less than the DlGapThreshold parameter corresponding to all the coverage levels.
  • Relation with the Prb and CellNprsCfg MOs:
    • If the value of the NprsParaGroupId parameter in the CellNprsCfg MO is the same as the value of the NprsParaGroupId parameter in the Prb MO associated by the LocalCellId parameter, the value of each bit of the NprsSubframeBitmap10 parameter in the CellNprsCfg MO must be within the subset of bit negation of the NbDlBitmap10 parameter value in the PrbSchConfig MO associated by the PrbId parameter.
    • If the value of the NprsParaGroupId parameter in the CellNprsCfg MO is the same as the value of the NprsParaGroupId parameter in the Prb MO associated by the LocalCellId parameter, the value of each bit of the NprsSubframeBitmap30 parameter in the CellNprsCfg MO must be within the subset of bit negation of the NbDlBitmap30 parameter value in the PrbSchConfig MO associated by the PrbId parameter.
  • Relation with the Prb MO:
    • Other than 65535, the values of the PrbIndexOfDlPdcchCarrier parameter in the PrbSchConfig MO must be one of the value of the PrbId parameter in the Prb MO associated with the LocalCellId parameter in the PrbSchConfig MO.
    • For all Prb MOs (under the same the Cell MO) in which the DeployMode parameter is set to GUARD_BAND or IN_BAND, the PrbIndexOfDlPdcchCarrier parameters in the PrbSchConfig MOs under these Prb MOs cannot be set to the same value as the PrbId parameter in any Prb MO in which the DeployMode parameter is set to STAND_ALONE.
    • For all Prb MOs (under the same the Cell MO) in which the DeployMode parameter is set to STAND_ALONE, the PrbIndexOfDlPdcchCarrier parameters in the PrbSchConfig MOs under these Prb MOs cannot be set to the same value as the PrbId parameter in any Prb MO in which the DeployMode parameter is set to GUARD_BAND or IN_BAND.
    • If WorkMode in a Prb MO is set to UL_ONLY, PagingWeight in the PrbSchConfig MO under this Prb MO must be set to W0.
  • Relation with the Prb and CellAlgoSwitch MOs:
    • If the MULTI_CARRIER_ENH_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO is selected, the AnchorCarrierFlag parameter in a Prb MO is set to FALSE and the PagingWeight parameter in the PrbSchConfig MO under this Prb MO is not set to W0, the PrbBlockPriority parameter in this Prb MO must be set to UNBLOCKED.
    • When the MULTI_CARRIER_ENH_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO under a Cell MO referenced by a Prb MO through the LocalCellId parameter is selected: If the WorkMode parameter in the Prb MO is set to UL_ONLY, the PrbIndexOfDlPdcchCarrier parameter in the PrbSchConfig MO under the Prb MO cannot be set to 65535 or the value of the PrbId parameter in any Prb MO in which the WorkMode parameter is set to UL_ONLY.
    • When the MULTI_CARRIER_ENH_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO under a Cell MO referenced by a Prb MO through the LocalCellId parameter is selected: If the WorkMode parameter in the Prb MO is set to UL_DL, the PrbIndexOfDlPdcchCarrier parameter in the PrbSchConfig MO under the Prb MO cannot be set to the value of the PrbId parameter in any Prb MO in which the WorkMode parameter is set to UL_ONLY.
  • Relation with the NbCellMultiPrbConfig MO:
    • For an NB-IoT cell, the sum of the values of the PrbUlScUsageDiffThld parameter in the NbCellMultiPrbConfig MO and the UlSubcarrierUsageOffset parameter in the PrbSchConfig MO must be less than or equal to 100.
    • For an NB-IoT cell, the sum of the values of the PrbDlScUsageDiffThld parameter in the NbCellMultiPrbConfig MO and the DlSubcarrierUsageOffset parameter in the PrbSchConfig MO must be less than or equal to 100.
  • Relation with the NbCellMultiPrbConfig, CellAlgoSwitch, and Prb MOs:
    • If AnchorCarrierFlag is set to FALSE and DeployMode is set to STAND_ALONE in some Prb MOs under a Cell MO for an NB-IoT cell meeting specific conditions, PagingWeight must be set to a value other than W0 in the PrbSchConfig MO under at least one of these Prb MOs. The specific conditions are as follows: The MULTI_CARRIER_ENH_SWITCH option of NbCellAlgoSwitch in the CellAlgoSwitch MO under the Cell MO is selected, the PAGING_PRB_SELECTION_SW option of MultiCarrierOptSwitch in the NbCellMultiPrbConfig MO under the Cell MO is selected, and AnchorCarrierFlag and DeployMode in a Prb MO under the Cell MO are set to TRUE and GUARD_BAND or IN_BAND, respectively.
    • If AnchorCarrierFlag is set to FALSE and DeployMode is set to GUARD_BAND or IN_BAND in some Prb MOs under a Cell MO for an NB-IoT cell meeting specific conditions, PagingWeight must be set to a value other than W0 in the PrbSchConfig MO under at least one of these Prb MOs. The specific conditions are as follows: The MULTI_CARRIER_ENH_SWITCH option of NbCellAlgoSwitch in the CellAlgoSwitch MO under the Cell MO is selected, the PAGING_PRB_SELECTION_SW option of MultiCarrierOptSwitch in the NbCellMultiPrbConfig MO under the Cell MO is selected, and AnchorCarrierFlag and DeployMode in a Prb MO under the Cell MO are set to TRUE and STAND_ALONE, respectively.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.
Maximum Number of Paging Repetition

Indicates the maximum number of paging repetitions in the NPDCCH common search space. For details about this parameter, see descriptions of the npdcch-NumRepetitionPaging IE in 3GPP TS 36.331. When this parameter is set to NULL, the maximum number of PDCCH repetitions corresponding to the maximum coverage level configured for the carrier is used as the value of the npdcch-NumRepetitionPaging IE by default. (The maximum number of PDCCH repetitions is specified by the PdcchMaxRepetitionCnt parameter in the PrbPdcchCeConfig MO.). When this parameter is set to a value other than NULL, the MaxNumRepetitionForPaging parameter value is used as the value of the npdcch-NumRepetitionPaging IE. This parameter applies only to NB-IoT.
Downlink Scheduling Switch

Indicates whether to enable downlink scheduling for NB-IoT carriers.

DL_GAP_SWITCH: Indicates whether to enable the downlink gap function in an NB-IoT cell. If this option is selected, the downlink gap function can be started in the cell. If this option is deselected, the downlink gap function cannot be started in the cell.
NB-IoT DL Bitmap Size

Indicates the downlink subframe pattern size of an NB-IoT cell. This parameter applies only to NB-IoT.
NB-IoT DL Bitmap10

Indicates a 10-bit bitmap used to specify the set of downlink subframes for downlink transmission in the NB-IoT cell. The value of this parameter needs to be converted into a binary number, and the 10 least significant bits of the number are used as the bitmap, with each bit representing one subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, only this parameter is used to specify the downlink subframe configuration for the NB-IoT cell. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the first 10 subframes, and it is used together with the NbDlBitmap30 parameter to specify the downlink subframe configuration for the NB-IoT cell.

The value 0 in the bitmap indicates that the corresponding subframe is invalid for downlink transmission, and the value 1 in the bitmap indicates that the corresponding subframe is valid for downlink transmission.

For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
NB-IoT DL Bitmap30

Indicates a 30-bit bitmap used to specify the set of downlink subframes for downlink transmission in the NB-IoT cell. The value of this parameter needs to be converted into a binary number, and the 30 least significant bits of the number are used as the bitmap, with each bit representing one subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, this parameter is invalid. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the last 30 subframes, and it is used together with the NbDlBitmap10 parameter to specify the downlink subframe configuration for the NB-IoT cell.

The value 0 in the bitmap indicates that the corresponding subframe is invalid for downlink transmission, and the value 1 in the bitmap indicates that the corresponding subframe is valid for downlink transmission.

For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
PRB Index of DL PDCCH Carrier

Indicates the downlink carrier ID for the UE to receive RAR and Msg4 when the UE initiates random access on the current carrier. If this parameter is set to 65535, the UE receives RAR and Msg4 on the current carrier. This parameter is valid only for non-anchor carriers. This option applies only to NB-IoT.
Paging Weight

Indicates the paging weight of each carrier. For details, see 3GPP TS 36.331. If this parameter is set to W0 for all carriers including anchor and non-anchor carriers, paging is performed only on the anchor carrier. If this parameter is set to W0 for the anchor carrier and a value other than W0 for any non-anchor carrier, paging is not performed on the anchor carrier. If this parameter is set to W0 for a non-anchor carrier, this non-anchor carrier does not support paging. If this parameter is set to a value other than W0 for a carrier, the value of this parameter is used as the paging weight of the carrier. For details, see 3GPP TS 36.304. This option applies only to NB-IoT.
DL Subcarrier Usage Offset

Indicates the offset to downlink subcarrier resource usage. This offset is used to determine whether to trigger load balancing between NB-IoT carriers.

If the difference in downlink subcarrier resource usage between the carriers is greater than or equal to the sum of the values of this parameter and the PrbDlScUsageDiffThld parameter in the NbCellMultiPrbConfig MO, load balancing will be triggered between the carriers. This parameter applies only to NB-IoT.
UL Subcarrier Usage Offset

Indicates the offset to uplink subcarrier resource usage. This offset is used to determine whether to trigger load balancing between NB-IoT carriers.

If the difference in uplink subcarrier resource usage between the carriers is greater than or equal to the sum of the values of this parameter and the PrbUlScUsageDiffThld parameter in the NbCellMultiPrbConfig MO, load balancing will be triggered between the carriers. This parameter applies only to NB-IoT.
