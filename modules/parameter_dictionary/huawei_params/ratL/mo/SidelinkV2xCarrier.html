SidelinkV2xCarrier

+-NE
  +-eNodeBFunction
    +-SidelinkV2xCarrier
      +-SidelinkV2xPsschCfg[0~2]
      +-SidelinkV2xResPlCfg[0~3]

Description

The SidelinkV2xCarrier MO consists of parameters used to configure sidelink V2X carriers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    SidelinkV2xPsschCfg[0~2];SidelinkV2xResPlCfg[0~3]
  • Relation with the SidelinkV2xResPlCfg MO:
    • Under each SidelinkV2xCarrier MO instance, the number of SidelinkV2xResPlCfg MO instances with PoolType set to TX_POOL must be less than or equal to 2, and the number of SidelinkV2xResPlCfg MO instances with PoolType set to RX_POOL must be less than or equal to 1.
    • The product of the SubchannelPrbCount and SubchannelCount parameter values plus the SubchannelStartRbIndex parameter value must not exceed the number of RBs indicated by the SidelinkV2xBandwidth parameter in the SidelinkV2xCarrier MO.
  • Relation with the CellSLV2xCarrCfg MO:
    • The SidelinkV2xCarrierId parameter in a CellSLV2xCarrCfg MO must have been configured in a SidelinkV2xCarrier MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sidelink V2X Carrier ID

Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Sidelink V2X EARFCN

Indicates the sidelink V2X EARFCN. This parameter can be set to a value ranging from 46790 to 55239. This parameter applies only to LTE FDD and LTE TDD.
Maximum Sidelink V2X Transmit Power

Indicates the maximum transmit power of a UE for V2X sidelink transmission. This parameter applies only to LTE FDD and LTE TDD.
Sidelink V2X Bandwidth

Indicates the operating carrier bandwidth for sidelink V2X. Sidelink adopts the same RX and TX bandwidths. This parameter applies only to LTE FDD and LTE TDD.
