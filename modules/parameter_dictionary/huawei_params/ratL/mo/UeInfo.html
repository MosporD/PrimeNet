UeInfo

+-NE
  +-eNodeBFunction
    +-UeInfo

Description

A UeInfo MO consists of UE-information-related parameters for UE identification on the eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the AblMsg MO:
    • The UeInfo MO referenced by UeCapIndex in a AblMsg MO must have been configured.
  • Relation with the UeCompat MO:
    • The UeInfo MO referenced by UeCapIndex in a UeCompat MO must have been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UEINFO

Use this command to add a group of parameters for UE identification on the eNodeB.
LST UEINFO

Use this command to list the UE-information-related configuration for UE identification on the eNodeB.
MOD UEINFO

Use this command to modify the UE-information-related configuration for UE identification on the eNodeB.
RMV UEINFO

Use this command to remove the UE-information-related configuration for UE identification on the eNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UE Capability Index

Indicates the UE capability index. This parameter applies only to LTE FDD and LTE TDD.
Access Stratum Release

Indicates the access stratum capability of defective UEs, which corresponds to the field AccessStratumRelease in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331. Parameter values 0 through 7 indicate the field value rel8, rel9, rel10, rel11, rel12, rel13, rel14, and rel15, respectively. Other parameter values are reserved and have no corresponding field values.

If this parameter is set to 255, this parameter is not used for UE selection. If this parameter is set to a non-255 value, a UE can be identified as a defective UE only when the parameter value indicates the same UE capability information of the UE. This parameter applies only to LTE FDD and LTE TDD.
UE Category

Indicates the UE categories of defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-Category, ue-Category-v1020, ue-Category-v1170, ue-Category-v11a0, ue-Category-v1250, and ue-Category-NB-r13.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bit 0 stands for category 1, bit 1 stands for category 2, bit 2 stands for category 3, ..., bit 9 stands for category 10, bit 10 stands for category 11, bit 11 stands for category 12, bit 12 stands for category 0, and bit 13 stands for category_nb1. Other bits are reserved. If the value of a bit is 1, the corresponding UE category is supported by a UE. For example, if a UE supports both categories 4 and 6, the binary number indicating the UE category information is 101000. This binary number can be converted into 40 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.
Feature Group Indicator

Indicates the FGIs of Release 8 or earlier supported by defective UEs, which correspond to the bit string in the field featureGroupIndicators in the information element (IE) UE-EUTRA-Capability in 3GPP TS 36.331. When setting this parameter, convert the hexadecimal FGI into a decimal one.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
E-UTRAN Band List 1

Indicates the E-UTRA band list 1 supported by defective UEs, which corresponds to the field bandEUTRA in the information element (IE) SupportedBandListEUTRA in 3GPP TS 36.331.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for an E-UTRA band. Bit 0 stands for band 1, bit 1 stands for band 2, bit 2 stands for band 3, ..., and bit 31 stands for band 32. If the value of a bit is 1, the corresponding E-UTRA band is supported by the UEs. For example, if a UE supports both bands 4 and 7, the binary number indicating the E-UTRA band list is 1001000. This binary number can be converted into 72 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
E-UTRAN Band List 2

Indicates the E-UTRA band list 2 supported by defective UEs, which corresponds to the field bandEUTRA in the information element (IE) SupportedBandListEUTRA in 3GPP TS 36.331.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for an E-UTRA band. Bit 0 stands for band 33, bit 1 stands for band 34, bit 2 stands for band 35, ..., and bit 31 stands for band 63. If the value of a bit is 1, the corresponding E-UTRA band is supported by the UEs. For example, if a UE supports both bands 35 and 41, the binary number indicating the E-UTRA band list is 100000100. This binary number can be converted into 260 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
Feature Group Indicator Release 9

Indicates the Release 9 FGIs supported by defective UEs, which correspond to the bit string in the field featureGroupIndicators-r9 in the information element (IE) fdd-Add-UE-EUTRA-Capabilities-r9 or tdd-Add-UE-EUTRA-Capabilities-r9 defined in 3GPP TS 36.331. A UE matches the UE type when the parameter value matches the field in any of the IEs.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
Feature Group Indicator Release 9 Add

Indicates the Release-9-additional FGIs supported by defective UEs, which correspond to the bit string in the field featureGroupIndRel9Add-r9 in the information element (IE) UE-EUTRA-Capability-v9a0-IEs, fdd-Add-UE-EUTRA-Capabilities-r9, or tdd-Add-UE-EUTRA-Capabilities-r9 as defined in 3GPP TS 36.331. A UE matches the UE type when the parameter value matches the field in any of the IEs.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
Feature Group Indicator Release 10

Indicates the Release 10 FGIs supported by defective UEs, which correspond to the bit string in the field featureGroupIndRel10-r10 in the information element (IE) UE-EUTRA-Capability-v1020-IEs, fdd-Add-UE-EUTRA-Capabilities-v1060, or tdd-Add-UE-EUTRA-Capabilities-v1060 defined in 3GPP TS 36.331. A UE matches the UE type when the parameter value matches the field in any of the IEs.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
DL UE Category

Indicates the downlink UE categories supported by defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryDL-r12, ue-CategoryDL-v1260, ue-CategoryDL-v1310, ue-CategoryDL-v1330, ue-CategoryDL-v1350, ue-CategoryDL-v1450, and ue-CategoryDL-v1460.

When setting this parameter, you need to combine field values indicating the UE categories in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bit 0 to 16 stand for categories 0 to 16, respectively. Bits 17, 18, 19, 20, 21, 22, and 23 stand for category_n17, category_m1, category 18, category 19, category 1bis, category 20, and category 21. Other bits are reserved. If a bit value is 1, the corresponding UE category is supported by the UEs. For example, if a UE supports both categories 19 and 16, the binary number indicating the UE capabilities is 100010000000000000000. This binary number can be converted into 1114112 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to a non-zero value, this parameter takes effect. In this case, a UE matches the UE category when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.
UL UE Category

Indicates the uplink UE categories supported by defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryUL-r12, ue-CategoryUL-v1310, ue-CategoryUL-v1340, ue-CategoryUL-v1350, ue-CategoryUL-v1430, and ue-CategoryUL-v1430b.

When setting this parameter, you need to combine field values indicating the UE categories in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category defined in 3GPP specifications. Bits 0 to 13 stand for categories 0 to 13, respectively. Bits 14 and 15 stand for category_n14 and category_m1, respectively. Bits 16 to 21 stand for categories 15 to 20, respectively. Bits 22 and 23 stand for categories 1bis and category 21. Other bits are reserved. If a bit value is 1, the corresponding UE category is supported by defective UEs. For example, if a defective UE supports both category_n14 and category 8, the binary number indicating the UE capabilities is 100000100000000. This binary number can be converted into 16640 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to a non-zero value, this parameter takes effect. In this case, a UE matches the UE category when the parameter value is completely identical to the UE capability information.
UE Specific Capability Information

Indicates the capability information about a defective UE.

Bit 0 indicates the NSA DC capability of the UE, corresponding to the value of en-DC-r15 in the IE IRAT-ParametersNR-r15 in 3GPP 36.331. Other bits are reserved.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from right to left represents a type of UE capability. If a bit is set to 1, it indicates that the UE supports a corresponding type of capability.

If this parameter is set to 0, this parameter is not used for UE matching. This parameter applies only to LTE FDD and LTE TDD.
