EuSectorEqmGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-EuSectorEqmGroup

Description

An EuSectorEqmGroup MO consists of the parameters used to specify baseband equipment and a list of sector equipment for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, eUCellSectorEqm, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • In a Cell MO, if MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, and the value of CellActiveState is CELL_ACTIVE: When NbCellFlag is set to FALSE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of eUCellSectorEqm MOs and EuSectorEqmGroup MOs under this Cell MO; when NbCellFlag is set to TRUE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of EuPrbSectorEqm MOs and EuPrbSectorEqmGroup MOs under all Prb MOs that are under this Cell MO.
    • When FddTddInd in a Cell MO is set to CELL_FDD, MultiRruCellFlag and MultiRruCellMode in the Cell MO are set to BOOLEAN_TRUE and SFN, if NbCellFlag is set to FALSE, at most eight eUCellSectorEqm and EuSectorEqmGroup MOs can be configured under the Cell MO, if NbCellFlag is set to TRUE, at most sixteen EuPrbSectorEqm and EuPrbSectorEqmGroup MOs can be configured under the Cell MO.
    • In a Cell MO, if NbCellFlag is TRUE, eUCellSectorEqm and EuSectorEqmGroup cannot be configured under the Cell, if NbCellFlag is FALSE, EuPrbSectorEqm and EuPrbSectorEqmGroup cannot be configured under the Cell.
  • Relation with the Cell and eUCellSectorEqm MOs:
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to CELL_COMBINATION, the number of eUCellSectorEqm MOs configured under this Cell MO ranges from 1 to 12. If the EuSectorEqmGroup MO is configured under this Cell MO, the number of eUCellSectorEqm MO instances, and the number of EuSectorEqmGroup instances must be less than 13.
    • In a Cell MO, if FddTddInd is set to CELL_TDD and MultiRruCellFlag is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION, the number of EuSectorEqmGroup plus the number of different values of SectorEqmRef between eUCellSectorEqm and EuSectorEqmGroup must be less than 8.
    • In a Cell MO, if CellActiveState, NbCellFlag and MultiRruCellMode are set to CELL_ACTIVE, FALSE and MPRU_AGGREGATION, respectively, the eUCellSectorEqm MO or EuSectorEqmGroup MO under this Cell MO must have been configured.
    • In a Cell MO, if FddTddInd is set to CELL_FDD and MultiRruCellFlag is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION, the number of EuSectorEqmGroup plus the number of different values of SectorEqmRef between eUCellSectorEqm and EuSectorEqmGroup must be less than 7.
    • When CellActiveState and FddTddInd in a Cell MO are set to CELL_ACTIVE and CELL_FDD, respectively, one to six eUCellSectorEqm and EuSectorEqmGroup MOs must be configured under the Cell MO if MultiRruCellFlag and MultiRruCellMode in the Cell MO are set to BOOLEAN_TRUE and SFN and NbCellFlag is set to FALSE, respectively.
    • When the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, if the value of the FddTddInd parameter is set to CELL_TDD, and the BaseBandEqmId in the eUCellSectorEqm MO or BaseBandEqmId parameter in the EuSectorEqmGroup MO corresponding to the Cell MO is configured, the SubframeAssignment parameter must be set to the same value for the cells for which the CellActiveState parameter in the corresponding Cell MO is set to CELL_ACTIVE.
    • In a Cell MO, if FddTddInd is set to CELL_FDD, NbCellFlag is set to FALSE, CellActiveState is set to CELL_ACTIVE and MultiRruCellMode is set to SFN, the eUCellSectorEqm MO or EuSectorEqmGroup MO under this Cell MO must have been configured.
  • Relation with the Cell and EuPrbSectorEqmGroup MOs:
    • EuSectorEqmGroup MOs can be configured under a Cell MO only when FddTddInd, MultiRruCellFlag, and MultiRruCellMode in the Cell MO are set to CELL_TDD, BOOLEAN_TRUE, and MPRU_AGGREGATION or CELL_COMBINATION, respectively. EuSectorEqmGroup and EuPrbSectorEqmGroup MOs can be configured under a Cell MO only when FddTddInd, MultiRruCellFlag, and MultiRruCellMode in the Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and MPRU_AGGREGATION or SFN, respectively.
  • Relation with the Cell, CellAlgoSwitch, eUCellSectorEqm, CellAuxEnbBind, and CellAuxDuBind MOs:
    • Assume that: The FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, the AsfnFastAttSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, and the CellAuxDuBind, and CellAuxEnbBind MOs are not configured. Then: The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO can be selected only when either of the following conditions is met: (a) The SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to JOINT. (b) The sum of the number of eUCellSectorEqm MO instances and the number of EuSectorEqmGroup MO instances is 2 and the SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to ADAPTIVE.
  • Relation with the Cell, CellAlgoSwitch, and eUCellSectorEqm MOs:
    • Assume that: The FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and MPRU_AGGREGATION, respectively, and the AsfnFastAttSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is deselected. Then: The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO can be selected only when either of the following conditions is met: (a) The SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to JOINT. (b) The sum of the number of eUCellSectorEqm MO instances and the number of EuSectorEqmGroup MO instances is 2 and the SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to ADAPTIVE.
  • Relation with the Cell MO:
    • When the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, if the value of the FddTddInd parameter is set to CELL_TDD, and the BaseBandEqmId in the eUCellSectorEqm MO or BaseBandEqmId parameter in the EuSectorEqmGroup MO corresponding to the Cell MO is configured, the SubframeAssignment parameter must be set to the same value for the cells for which the CellActiveState parameter in the corresponding Cell MO is set to CELL_ACTIVE.
    • Consider that FddTddInd, MultiRruCellFlag, and MultiRruCellMode in a Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, SectorGroupCpriCompression in EuSectorEqmGroup MOs under this Cell MO must be set based on the setting of DlBandWidth in the Cell MO. (1) If DlBandWidth is set to CELL_BW_N6 or CELL_BW_N15, SectorGroupCpriCompression must be set to NULL or NO_COMPRESSION. (2) If DlBandWidth is set to CELL_BW_N25, SectorGroupCpriCompression must be set to NULL, NO_COMPRESSION, or NORMAL_COMPRESSION. (3) If DlBandWidth is set to CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100, SectorGroupCpriCompression must be set to NULL, NO_COMPRESSION, NORMAL_COMPRESSION, or ENHANCED_COMPRESSION.
    • When SectorGroupLinkCompression in the EuSectorEqmGroup MO is set to a value other than NULL, DlBandWidth must be set to CELL_BW_N75 or CELL_BW_N100.
    • In a Cell MO, if FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to MPRU_AGGREGATION or SFN, and CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to each EuSectorEqmGroup MO under this Cell MO must be associated with one TX antenna (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) or two TX antennas, one RX antenna or two RX antennas.
    • If WorkMode and MultiRruCellFlag in a Cell MO are set to LAA and BOOLEAN_TRUE, respectively, MultiRruCellMode in this Cell MO must be set to MPRU_AGGREGATION. In addition, only one EuSectorEqmGroup MO can be configured for this Cell MO and this EuSectorEqmGroup MO can contain a maximum of four pieces of cell sector equipment.
    • When the SectorGroupCpriCompression parameter in the EuSectorEqmGroup MO is set to QUADPLEX_COMPRESSION, the DlBandWidth parameter in this Cell MO must be set to CELL_BW_N75 or CELL_BW_N100.
    • If FddTddInd, MultiRruCellFlag, MultiRruCellMode, and CellActiveState in a Cell MO are set to CELL_TDD, BOOLEAN_TRUE, CELL_COMBINATION, and CELL_ACTIVE, respectively, and the EuSectorEqmGroup MO is configured under this Cell MO, the TxRxMode in this Cell MO are set to 2T2R.
  • Relation with the CellAlgoSwitch and Cell MOs:
    • The TxRxMode parameter in a Cell MO must be set to 2T2R or 4T4R when the following conditions are met: The Virtual4T4RSwitch option of the EmimoSwitch parameter in the associated CellAlgoSwitch MO is selected, and the MultiRruCellFlag and MultiRruCellMode parameters in the Cell MO are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively. If the TxRxMode parameter in the Cell MO is set to 4T4R, only one EuSectorEqmGroup MO instance can be configured for this Cell MO.
    • If MultiRruCellFlag in an Cell MO is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION, only one set of cell sector equipment can be configured in each EuSectorEqmGroup MO for the cell when the DMIMOAlgoSwitch option under DMIMOAlgoSwitch in the CellAlgoSwitch MO is selected.
  • Relation with the Cell and UlInterfSuppressCfg MOs:
    • The UlIntrfSuppressionValue parameter in the UlInterfSuppressCfg MO can be set to a non-zero value only for a cell with the EuSectorEqmGroup MO configured.
  • Relation with the eUCellSectorEqm and Cell MOs:
    • In a Cell MO, if the CellActiveState parameter is set to CELL_ACTIVE, the MultiRruCellFlag parameter is set to BOOLEAN_TRUE, the MultiRruCellMode parameter is set to CELL_COMBINATION, and an EuSectorEqmGroup MO has been configured, then the sum of the EuSectorEqmGroup and eUCellSectorEqm MO instances configured in the Cell MO must be less than 7.
  • Relation with the Cell and SECTOREQM MOs:
    • In a Cell MO, if FddTddInd is set to CELL_TDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to MPRU_AGGREGATION or CELL_COMBINATION and CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to each EuSectorEqmGroup MO under this Cell MO must be associated with two TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) and two RX antennas.
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, SectorEqmRef in each EuSectorEqmGroup MO under this Cell MO must be unique.
    • If the value of CellActiveState in a Cell MO is CELL_ACTIVE, and MultiRruCellMode in the Cell MO is set to MPRU_AGGREGATION or SFN or CELL_COMBINATION, respectively, EuSectorEqmGroup MOs cannot be configured under this Cell MO after the cell is activated. If the EuSectorEqmGroup MO has been configured under this Cell MO before the cell is activated, the SECTOREQM MO associated with this EuSectorEqmGroup MO must already exist.
    • The sector represented by a SECTOREQM MO under the EuSectorEqmGroup MO associated with a Cell MO can be configured with four TX antennas and four RX antennas, two TX antennas and four RX antennas, or two TX antennas and two RX antennas if FddTddInd, MultiRruCellFlag, MultiRruCellMode, CrsPortNum, TxRxMode, and CellActiveState in this Cell MO are set to CELL_FDD, BOOLEAN_TRUE, SFN, CRS_PORT_4, 4T4R, and CELL_ACTIVE, respectively, and ANTCFGMODE is set to ANTENNAPORT.
    • The total numbers of TX antennas and RX antennas in at least one piece of sector equipment configured using the SECTOREQM MO corresponding to each EuSectorEqmGroup MO for a Cell MO must be both 4 when the following conditions are met: The Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO is selected, and the MultiRruCellFlag, MultiRruCellMode, CellActiveState, and TxRxMode parameters in the Cell MO are set to BOOLEAN_TRUE, MPRU_AGGREGATION, CELL_ACTIVE, and 4T4R, respectively.
  • Relation with the Cell, BASEBANDEQM, and EuPrbSectorEqmGroup MOs:
    • If CellActiveState in a Cell MO is set to CELL_ACTIVE, BaseBandEqmId in the EuSectorEqmGroup MO or BasebandEqmId in the EuPrbSectorEqmGroup MO under this Cell MO is not 255, the BASEBANDEQM MO corresponding to BaseBandEqmId or BasebandEqmId must have been configured.
  • Relation with the Cell, BASEBANDEQM, and BBP MOs:
    • When the value of CellActiveState in a Cell MO is CELL_ACTIVE: (1) If FddTddInd in this Cell MO is set to CELL_FDD and BaseBandEqmId in a EuSectorEqmGroup MO under this Cell MO has been set, TYPE in all BBP MOs corresponding to the EuSectorEqmGroup MO must be set to UBBP or LBBP, and WM in all BBP MOs must be set to FDD or FDD_NBIOT or FDD_NBIOT_ENHANCE or FDD_NBIOT_CUSTOM; (2) If FddTddInd in this Cell MO is set to CELL_TDD and BaseBandEqmId in a EuSectorEqmGroup MO under this Cell MO has been set, TYPE in all BBP MOs corresponding to the EuSectorEqmGroup MO must be set to UBBP or UBBP-W or LBBP, and WM in all BBP MOs cannot be set to FDD, FDD_NBIOT, FDD_NBIOT_ENHANCE, FDD_NBIOT_CUSTOM and NBIOT.
    • When CellActiveState in a Cell MO is CELL_ACTIVE, BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has been set, and TYPE is set to UBBP or UBBP-W in at least one BBP MO corresponding to the EuSectorEqmGroup MO, BBWS in the BBP MO must be set to LTE_FDD or LTE_TDD if FddTddInd is set to CELL_FDD or CELL_TDD, respectively.
  • Relation with the Cell, SECTOREQM, RRU, RRUCHAIN, and BBP MOs:
    • When the CellActiveState and CPRICompression parameters in a Cell MO are set to CELL_ACTIVE and NO_COMPRESSION, respectively, and the SectorGroupCpriCompression parameter in the EuSectorEqmGroup MO under the Cell MO is set to NULL, the CPRIEX parameter in the BBP MO connected to the RRU MO used by the SECTOREQM MO corresponding to the EuSectorEqmGroup MO under the Cell MO must be set to OFF.
    • When the CellActiveState in the Cell MO is set to CELL_ACTIVE and the SectorGroupCpriCompression in the EuSectorEqmGroup MO under the Cell MO is set to NO_COMPRESSION, the CPRIEX parameter in the BBP MO connected to the RRU MO used by the SECTOREQM MO corresponding to the EuSectorEqmGroup MO under the Cell MO must be set to OFF.
  • Relation with the Cell, SECTOREQM, RRUCHAIN, and RHUB MOs:
    • In the Cell MO, if CellActiveState is set to CELL_ACTIVE and MultiRruCellMode is set to MPRU_AGGREGATION or SFN or CELL_COMBINATION, the maximum of RRUs specified in the SECTOREQM MO under the EuSectorEqmGroup MO is 32, and these RRUs must be on the same BBI CPRI Port, and their connected RHUB number on the chain cannot be more than 4.
  • Relation with the Cell and BBP MOs:
    • BBWS is set to LTE_FDD in at least one BBP MO when all the following conditions are met: (1) CellActiveState in a Cell MO is CELL_ACTIVE; (2) FddTddInd in the Cell MO is set to CELL_FDD; (3) BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has not been set; (4) the number of BBP MOs with TYPE set to LBBP is zero; (5) the number of BBP MOs with TYPE set to UBBP is not zero.
    • BBWS is set to LTE_TDD in at least one BBP MO when all the following conditions are met: (1) CellActiveState in a Cell MO is CELL_ACTIVE; (2) FddTddInd in the Cell MO is set to CELL_TDD; (3) BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has not been set; (4) the number of BBP MOs with TYPE set to LBBP is zero; (5) the number of BBP MOs with TYPE set to UBBP or UBBP-W is not zero.
  • Relation with the Cell, BASEBANDEQM, and MDU MOs:
    • When CellActiveState in a Cell MO is CELL_ACTIVE, BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has been set, and TYPE is set to UMDU in at least one MDU MO corresponding to the EuSectorEqmGroup MO, BBWS in the MDU MO must be set to LTE_FDD or LTE_TDD if FddTddInd is set to CELL_FDD or CELL_TDD, respectively.
  • Relation with the Cell and MDU MOs:
    • BBWS is set to LTE_FDD in at least one BBP or MDU MO when all the following conditions are met: (1) CellActiveState in a Cell MO is CELL_ACTIVE; (2) FddTddInd in the Cell MO is set to CELL_FDD; (3) BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has not been set; (4) the number of MDU MOs with TYPE set to UMDU is not zero.
    • BBWS is set to LTE_TDD in at least one BBP or MDU MO when all the following conditions are met: (1) CellActiveState in a Cell MO is CELL_ACTIVE; (2) FddTddInd in the Cell MO is set to CELL_TDD; (3) BaseBandEqmId in the EuSectorEqmGroup MO under the Cell MO has not been set; (4) the number of MDU MOs with TYPE set to UMDU is not zero.
  • Relation with the Cell, eNodeBFunction, eUCellSectorEqm, SfnAuxResBind, SfnAuxResGrpBind, EuPrbSectorEqm, MPT, Node, eNodeBResModeAlgo, and EuPrbSectorEqmGroup MOs:
    • The sum of the numbers of the following MO instances must meet a certain requirement: Cell MO instances in which MultiRruCellFlag and EuCellStandbyMode are set to BOOLEAN_FALSE and ACTIVE, respectively; Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and TWO_RRU_COMBINATION (or DIGITAL_COMBINATION), respectively; EuSectorEqmGroup and EuPrbSectorEqmGroup MO instances corresponding to the Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively; eUCellSectorEqm and eUPrbSectorEqm MO instances of other cells; SfnAuxResBind and SfnAuxResGrpBind MO instances. The requirement varies as follows: (1) The sum is less than or equal to 216 if UMPT boards are configured in the MPT MO and the conditions listed in (2) to (9) are not met. (2) The sum is less than or equal to 144 if one UMPT board is configured in the MPT MO, the BRDSPEC of the UMPT is UMPTe or UMPTg, and the conditions listed in (3) to (9) are not met. (3) The sum is less than or equal to 72 if UMPT boards are configured in the MPT MO, WM in the NODE MO is set to CONCURRENT, and the conditions listed in (4) to (9) are not met. (4) The sum is less than or equal to 72 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTga. (5) The sum is less than or equal to 36 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTa, UMPTb, or UMPTa/b. (6) The sum is less than or equal to 36 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTa, UMPTb, or UMPTa/b, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (7) The sum is less than or equal to 72 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (8) The sum is less than or equal to 144 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to ENHANCED_MODE. (9) The sum is less than or equal to 18 if no UMPT board is configured in the MPT MO.
  • Relation with the Cell, CellAlgoSwitch, and SECTOREQM MOs:
    • The total numbers of TX antennas and RX antennas in the sector equipment configured using the SECTOREQM MO corresponding to each EuSectorEqmGroup MO for a Cell MO must be both 4 or 2 (the TX antennas refer to those whose TX Antenna Master/Slave Mode is set to MASTER) when the following conditions are met: The Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO is selected, and the MultiRruCellFlag, MultiRruCellMode, CellActiveState, and TxRxMode parameters in the Cell MO are set to BOOLEAN_TRUE, MPRU_AGGREGATION, CELL_ACTIVE, and 4T4R, respectively.
    • When the Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO associated with a Cell MO is selected and the CellActiveState, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_ACTIVE or CELL_COMBINATION, BOOLEAN_TRUE, and SFN, respectively, the SectorEqmGrpCombineId parameter in each EuSectorEqmGroup MO under the Cell MO must not be 255, and the total numbers of TX antennas and RX antennas configured in all the SECTOREQM MOs corresponding to each EuSectorEqmGroup MO must be both 2.
  • Relation with the SECTOREQM MO:
    • ANTCFGMODE cannot be set to BEAM in the SECTOREQM MO that corresponds to the EuSectorEqmGroup MO.
  • Relation with the CellAlgoSwitch, Cell, and SECTOREQM MOs:

    • The SectorEqmGrpCombineId parameter in the EuSectorEqmGroup MO must not be 255 and the total numbers of TX antennas and RX antennas in the sector equipment configured using the SECTOREQM MO corresponding to each EuSectorEqmGroup MO for a Cell MO must be both 2 (the TX antennas refer to those whose TX Antenna Master/Slave Mode is set to MASTER) when the following conditions are met: The CellActiveState, MultiRruCellFlag, MultiRruCellMode, and TxRxMode parameters in the Cell MO are set to CELL_ACTIVE, BOOLEAN_TRUE, MPRU_AGGREGATION, and 2T2R, respectively, and the Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the CellAlgoSwitch and SECTOREQM MOs:
    • The SfnJtSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO can be selected only when the total numbers of both TX and RX antennas specified in the SECTOREQM MO associated with the EuSectorEqmGroup MO in the Cell MO are 2. The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER.
    • If the Cell MO is associated with at least one EuSectorEqmGroup MO which is configured with more than 16 SECTOREQM MOs, the TDOA_SWITCH option of the RruUeMapSwitch and LbsSwitch parameters in the CellAlgoSwitch MO cannot be selected.

  • Relation with the SRSCfg, Cell, BASEBANDEQM, and BBP MOs:
    • When the SrsResOptSwitch parameter in the SRSCfg MO is set to ON(On), and the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the BaseBandEqmId parameter in the EuSectorEqmGroup MO must not be set to 255, the AutoCfgFlag parameter in the EuSectorEqmGroup MO must not be set to AUTO_MODE_CFG, and the associated BASEBANDEQM MO can be configured with only one BBP board.
    • When the SrsResOptSwitch parameter in the SRSCfg MO is set to ON(On), and the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, TYPE in an BBP MO corresponding to BaseBandEqmId in the EuSectorEqmGroup MO cannot be set to LBBP.
  • Relation with the Cell, eUCellSectorEqm, and SECTOREQM MOs:
    • If the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE and the MultiRruCellMode parameter in the Cell MO is set to MPRU_AGGREGATION, SFN, or CELL_COMBINATION, a maximum of 96 RRU MOs can be used for the SECTOREQM MO corresponding to the EuSectorEqmGroup associated with the Cell MO and for the SECTOREQM MO corresponding to the eUCellSectorEqm MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Sector Equipment Group ID

Indicates the group ID of the sector devices that serve the cell, it uniquely identifies a group of sector devices within a cell. This parameter applies only to LTE FDD and LTE TDD.
Sector Equipment Reference

Indicates the list of the sector devices that serve the cell. This parameter applies only to LTE FDD and LTE TDD.
Baseband equipment ID

Indicates the number of the baseband equipment used by a cell.

When this parameter is set to 255, the baseband equipment serving a cell is not specified. In this scenario, any baseband processing unit (BBP) in the base station can be selected to serve a cell, and the BBPs to which the cell's serving RRU is connected are preferentially selected.

When this parameter is set to a value other than 255, the baseband equipment serving a cell is specified. In this scenario, only BBPs in the specified baseband equipment can be selected to serve a cell. This parameter applies only to LTE FDD and LTE TDD.
Reference signal power

Indicates the reference signal power of a sector equipment group for a cell (all sets of sector equipment in the sector equipment group have the same reference signal power). If this parameter is set to 32767, the parameter value is invalid, and the cell uses the reference signal power specified by the ReferenceSignalPwr parameter in the PDSCHCFG MO. For details, see 3GPP TS 36.213. This parameter takes effect only when parameter MultiRruCellFlag is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION or FDD SFN, respectively. This parameter applies only to LTE FDD and LTE TDD.
Sector Group CPRI Compression

Indicates the common public radio interface (CPRI) compression type for the sector equipment group. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that normal CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value QUADPLEX_COMPRESSION indicates that quadruple CPRI compression is used. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than the performance of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cell served by the sector equipment group automatically restarts.

This parameter is used only when MultiRruCellMode is set to SFN, MPRU_AGGREGATION, or CELL_COMBINATION. This parameter can be set based on the sector equipment group. When this parameter is set to NULL, the CPRI compression type of carriers depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the sector equipment group CPRI compression type of carriers depends on the setting of this parameter. Before changing the value of this parameter for a cell served RRUs in the same RRU chain or ring, ensure that all cells served by the RRU chain or ring are deactivated. Activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.
Auto Config Flag

Indicates whether to automatically or manually bind a baseband equipment ID to a cell. To enable automatic binding, set this parameter to AUTO_MODE_CFG. To enable manual binding, set this parameter to MANUAL_MODE_CFG. This parameter applies only to LTE FDD and LTE TDD.
Sector Equipment Group Combine ID

Indicates the ID of a sector equipment group combination, which contains multiple sector equipment groups. This parameter takes effect only in scenarios with virtual 4T4R enabled. The value 255 indicates that the sector equipment group is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.
Virtual Cell ID

Indicates a virtual cell ID used for DMRS and CSI-RS scrambling when adaptive SFN and TM10 are enabled. This parameter should be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to FDD.
Sector Group Carrier PassThrough Compression

Indicates the compression type on CPRI over optical fibers and CPRI over Ethernet cables for the sector equipment group. This parameter applies to LampSite eNodeBs where both optical fibers and Ethernet cables are used for RRU cascading and the compression ratio on CPRI over optical fibers and that on CPRI over Ethernet cables are the same. This parameter is used to specify the compression ratio on both CPRI over optical fibers and CPRI over Ethernet cables. With the same compression ratio on CPRI over optical fibers and CPRI over Ethernet cables, the number of cells on a single CPRI link in a LampSite eNodeB is increased without changing the data rate over the CPRI. This parameter can be set to NORMAL_3_TO_1_COMPRESSION(NORMAL_3_TO_1_COMPRESSION), NORMAL_4_TO_1_COMPRESSION(NORMAL_4_TO_1_COMPRESSION), or NULL(NULL). NORMAL_3_TO_1_COMPRESSION indicates a standard compression ratio of 3:1. NORMAL_4_TO_1_COMPRESSION indicates a standard compression ratio of 4:1. NULL indicates that the parameter is invalid. The default value is NULL. Only UBBPd and UBBPe boards support the compression. When this parameter is modified, the cell served by the sector equipment group is automatically reactivated.

When this parameter is set to NULL, the CPRI compression type for the sector equipment group is determined by the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the CPRI compression type for the sector equipment group is determined by the value of the SectorGroupCpriCompression parameter. This parameter applies only to LTE FDD and LTE TDD.
