CellReselToNr

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellReselToNr

Description

The CellReselToNr MO includes the parameters used to configure NR cell reselection information, which is delivered in SIB24. This MO is optional. If NR cell reselection information is not configured for a cell, the cell does not support NR cell reselection. For details about NR cell reselection, see 3GPP TS 36.304.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the EutranInterNFreq and NrNFreq MOs:
    • If CellReselPriorityCfgInd in EutranInterNFreq MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the UtranNFreq and NrNFreq MOs:
    • If CellReselPriorityCfgInd in UtranNFreq MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the GeranNfreqGroup and NrNFreq MOs:
    • If CellReselPriorityCfgInd in GeranNfreqGroup MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the CellResel and NrNFreq MOs:
    • If a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
NR Cell Reselection Timer

Indicates the timer used for NR cell reselection. A UE initiates NR cell reselection if the signal quality of the serving cell and that of the NR cell constantly meet reselection threshold requirements before the timer expires and the UE has stayed in the serving cell for more than one second. This parameter applies only to LTE FDD and LTE TDD.
