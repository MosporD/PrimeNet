SO

+-NE
  +-eNodeBFunction
    +-SO

Description

An SO MO consists of parameters related to the transport resources used by the SO interface between the eNodeB and a service anchor. The configuration items include the control-plane and user-plane end point groups used by the SO MO and the CN operator that owns the SO MO.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the eX2 MO:
    • CpEpGroupId in an eX2 MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an eX2 MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an eX2 MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an eX2 MO must be different from CpEpGroupId in any SO MO.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by CpEpGroupId in an SO MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by UpEpGroupId in an SO MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
    • EPGROUP MO referenced by CpEpGroupId in an SO MO must have been configured.
    • EPGROUP MO referenced by CpEpGroupId in an SO MO must have been configured. And the SCTPHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced by CpEpGroupId in an SO MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • EPGROUP MO referenced by UpEpGroupId in an SO MO must have been configured.
    • EPGROUP MO referenced by UpEpGroupId in an SO MO must have been configured. And the USERPLANEHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced by UpEpGroupId in an SO MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
  • Relation with the SCTPHOST MO:
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, CpEpGroupId in the SO MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, UpEpGroupId in the SO MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
  • Relation with the X2 MO:
    • CpEpGroupId in an SO MO must be different from CpEpGroupId in any X2 MO.
    • UpEpGroupId in an SO MO must be different from UpEpGroupId in any X2 MO.
    • CpEpGroupId in an SO MO must be different from UpEpGroupId in any X2 MO.
    • UpEpGroupId in an SO MO must be different from CpEpGroupId in any X2 MO.
    • CpEpGroupId in an SO MO must be different from CpEpGroupId in any S1 MO.
    • UpEpGroupId in an SO MO must be different from UpEpGroupId in any S1 MO.
    • CpEpGroupId in an SO MO must be different from UpEpGroupId in any S1 MO.
    • UpEpGroupId in an SO MO must be different from CpEpGroupId in any S1 MO.
    • CpEpGroupId in an SO MO must be different from M1EpGroupId in any M1 MO.
    • UpEpGroupId in an SO MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the ECO MO:
    • CpEpGroupId in an SO MO must be different from CpEpGroupId in any ECO MO.
    • UpEpGroupId in an SO MO must be different from UpEpGroupId in any ECO MO.
    • CpEpGroupId in an SO MO must be different from UpEpGroupId in any ECO MO.
    • UpEpGroupId in an SO MO must be different from CpEpGroupId in any ECO MO.
  • Relation with the M2 MO:
    • CpEpGroupId in an SO MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the M1 MO:
    • UpEpGroupId in an SO MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the XW MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any SO MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by the UpEpGroupId parameter in an SO MO must be configured. In addition, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to DISABLE.
