EnDcX2BlackWhiteList

+-NE
  +-eNodeBFunction
    +-EnDcX2BlackWhiteList

Description

An EnDcX2BlackWhiteList MO consists of the parameters related to an EN-DC X2 interface blacklist or whitelist. This list is used to control the X2 interfaces between the eNodeB and gNodeBs and X2 self-configuration.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ENDCX2BLACKWHITELIST

Use this command to add a peer gNodeB to an EN-DC X2 blacklist or whitelist. If a peer gNodeB is blacklisted, the X2 interface between the local eNodeB and this gNodeB is abnormal and this interface cannot be automatically set up. If a peer gNodeB is whitelisted or blacklisted, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed.
LST ENDCX2BLACKWHITELIST

Use this command to list the EN-DC X2 blacklist and whitelist configurations. If a peer gNodeB is blacklisted, the X2 interface between the local eNodeB and this gNodeB is abnormal and this interface cannot be automatically set up. If a peer gNodeB is whitelisted or blacklisted, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed.
RMV ENDCX2BLACKWHITELIST

Use this command to remove a peer gNodeB from the EN-DC X2 blacklist or whitelist. If a peer gNodeB is blacklisted, the X2 interface between the local eNodeB and this gNodeB is abnormal and this interface cannot be automatically set up. If a peer gNodeB is whitelisted or blacklisted, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile country code

Indicates the mobile country code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of three decimal digits. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD.
gNodeB ID

Indicates the ID of the peer base station in the EN-DC X2 blacklist or whitelist. This parameter applies only to LTE FDD and LTE TDD.
List Type

Indicates whether the EN-DC X2 list is a blacklist or whitelist. If a peer gNodeB is in the blacklist, an X2 interface between the local eNodeB and this gNodeB cannot be automatically set up and the X2 interface set up between the local eNodeB and this gNodeB is abnormal. If a peer gNodeB is in the whitelist or blacklist, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed. This parameter applies only to LTE FDD and LTE TDD.
