CeRachCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CeRachCfg

Description

A CeRachCfg MO consists of parameters related to RACH configuration for coverage-level-specific cell common radio resources. For details about the RACH procedure. See 3GPP TS 36.321.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellCeCfg MO:
    • Under the same cell, the sum of the PreambleRatio parameter values in the CeRachCfg MO corresponding to the coverage levels specified by the CoverageLevel parameter in the CellCeCfg MO must not exceed 100.
    • Under the same cell, the value of the PreambleRatio parameter in the CeRachCfg MO corresponding to the coverage levels specified by the CoverageLevel parameter in the CellCeCfg MO must not be 0.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to list the RACH coverage enhancement configurations.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Coverage Level

Indicates the coverage level of the cell. The values of this parameter correspond to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancement.

The value COVERAGE_LEVEL_0(COVERAGE_LEVEL_0) indicates 0 dB coverage enhancement. The value COVERAGE_LEVEL_1(COVERAGE_LEVEL_1) indicates 5 dB coverage enhancement. The value COVERAGE_LEVEL_2(COVERAGE_LEVEL_2) indicates 10 dB coverage enhancement. The value COVERAGE_LEVEL_3(COVERAGE_LEVEL_3) indicates 15 dB coverage enhancement. This parameter applies only to LTE FDD and LTE TDD.
Timer for Contention Resolution

Indicates the period in which a UE waits for Msg4 during a random access (RA) procedure. This timer starts when a UE initially transmits or retransmits Msg3. If the UE receives Msg4 or NACK to Msg3 before the timer expires, the timer stops. If the UE does not receive either message until the timer expires, the RA fails. In this case, the UE must re-initiate an RA procedure. For details about this parameter, see 3GPP TS 36.321. To prevent UE access failures as a result of contention resolution timer expiration caused by a large number of repetitions, it is recommended that this parameter be set to a value not less than two times the sum of the actual initial numbers of repetitions indicated by the MpdcchInitRepNum and PdschInitRepNum parameters in the EmtcCeSchCfg MO. For details about the actual initial numbers of repetitions, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Maximum Number of Preamble Attempt

Indicates the maximum number of preamble transmission attempts for the corresponding coverage level. For details, see 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.
Preamble Ratio

Indicates the proportion of preambles corresponding to a coverage level to all preambles of the cell. This parameter is used to calculate the number of preambles corresponding to a coverage level. The number of preambles corresponding to a coverage level (excluding the maximum coverage level) is calculated by rounding down the value of this parameter multiplied by the total number of preambles of the cell. No preambles are allocated to a coverage level if the cell does not support this coverage level. The number of preambles corresponding to the maximum coverage level supported by the cell equals the total number of preambles subtracted by the number of preambles corresponding to other coverage levels. Therefore, the proportion of preambles corresponding to the maximum coverage level supported by the cell may be greater than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
Preamble Repetition Number

Indicates the number of repeated preamble transmissions for the corresponding coverage level. This parameter applies only to LTE FDD and LTE TDD.
Random Preamble Ratio

Indicates the proportion of random preambles corresponding to the cell coverage level to the total number of preambles for this coverage level. The number of random preambles corresponding to the cell coverage level equals the value of this parameter multiplied by the total number of preambles corresponding to the cell coverage level. Preambles are classified into random and dedicated preambles. Random preambles are used for contention-based access, and dedicated preambles are used for non-contention-based access. For details, see section 5.1.1 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.
RACH Threshold Increase Coefficient

Indicates the coefficient for increasing the RACH detection threshold under the corresponding coverage level. For example, if this parameter is set to the GUI value 400, the RACH detection threshold under the current coverage level increases by four times. If this parameter is set to the GUI value -50, the RACH detection threshold under the current coverage level decreases by 0.5 times. If this parameter is set to the GUI value 0, the RACH detection threshold under the current coverage level remains unchanged. This parameter applies only to LTE FDD and LTE TDD.
High Load Threshold for Adaptive RACH

Indicates whether to enable eMTC RACH adaptation and the high-load threshold for triggering eMTC RACH adaptation. If this parameter is set to 255, the function does not take effect. If this parameter is set to a value other than 255 and the load is higher than the value, the function takes effect. This parameter applies only to LTE FDD and LTE TDD.
