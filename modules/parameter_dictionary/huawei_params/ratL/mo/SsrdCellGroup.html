SsrdCellGroup

+-NE
  +-eNodeBFunction
    +-SsrdCellGroup

Description

An SsrdCellGroup MO consists of parameters related to soft split resource duplex. It is used to configure the mapping between primary cells and split cells. This MO applies only to LTE TDD networks.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell MO:
    • When the primary cell is in the active state, the UlCyclicPrefix, DlCyclicPrefix, FreqBand, DlEarfcn, DlBandWidth, SubframeAssignment, SpecialSubframePatterns, and CPRICompression parameters related to the PrimaryLocalCellID parameter must be set to the same values as the soft split cell specified by the SsrdLocalCellID parameter, and the cells corresponding to the PrimaryLocalCellID and SsrdLocalCellID parameters are configured under the same sector equipment specified by the SECTOREQM.
    • When the primary cell is in the active state, the UlCyclicPrefix, DlCyclicPrefix, FreqBand, DlEarfcn, DlBandWidth, SubframeAssignment, SpecialSubframePatterns, and CPRICompression parameters related to the PrimaryLocalCellID parameter must be set to the same values as the soft split cell specified by the SsrdLocalCellID parameter, and the cells corresponding to the PrimaryLocalCellID and SsrdLocalCellID parameters are configured under the same sector equipment specified by the SECTOREQM.
    • When an SsrdCellGroup MO is to be added, the cells specified by the PrimaryLocalCellID must have been configured in the Cell MO and the MultiCellShareMode parameter for these cells must be set to SPLIT.
    • When an SsrdCellGroup MO is to be added, the cells specified by the SsrdLocalCellID parameters must have been configured in the Cell MO and the MultiCellShareMode parameter for these cells must be set to SPLIT.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the MultiCellShareMode parameter in the Cell MO is set to SPLIT, the TxRxMode parameter in the Cell MO is set to a value other than 32T32R or 64T64R, and the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, then the PrimaryLocalCellID or SsrdLocalCellID parameter in the SsrdCellGroup MO with the same value as the LocalCellId parameter in the Cell MO must be configured.
    • If the PrimaryLocalCellID parameter in the SsrdCellGroup MO corresponds to an activated cell, the CellActiveState parameter for the cell specified by the SsrdLocalCellID parameter must be set to CELL_ACTIVE(Active).
    • When a cell corresponding to a split cell is to be activated, the UlCyclicPrefix, DlCyclicPrefix, FreqBand, DlEarfcn, DlBandWidth, SubframeAssignment, SpecialSubframePatterns, and CPRICompression parameters related to the SsrdLocalCellID parameter must be set to the same values as the cell specified by the PrimaryLocalCellID parameter, and the cells corresponding to the SsrdLocalCellID and the PrimaryLocalCellID parameter are configured under the same SECTOREQM MO.
    • When a cell corresponding to a split cell is to be activated, the UlCyclicPrefix, DlCyclicPrefix, FreqBand, DlEarfcn, DlBandWidth, SubframeAssignment, SpecialSubframePatterns, and CPRICompression parameters related to the SsrdLocalCellID parameter must be set to the same values as the cell specified by the PrimaryLocalCellID parameter, and the cells corresponding to the SsrdLocalCellID and the PrimaryLocalCellID parameter are configured under the same SECTOREQM MO.
  • Relation with the Cell, eUCellSectorEqm, BASEBANDEQM, and BBP MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the SsrdCellGroup MO with the PrimaryLocalCellID or SsrdLocalCellID parameter set to the same value as the LocalCellId parameter of the Cell MO is configured, the BaseBandEqmId parameter in an eUCellSectorEqm MO associated with the Cell MO is configured, and the LTE_TDD option of BBWS is selected in the BBP under the corresponding BASEBANDEQM MO, then the WM parameter cannot be set to SPEC_MODE1.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SSRDCELLGROUP

Use this command to add a soft split cell group.
LST SSRDCELLGROUP

Use this command to list the configuration of a specific or all soft split cell groups.
RMV SSRDCELLGROUP

Use this command to remove a soft split cell group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Primary Local Cell ID

Indicates the local cell ID of a primary cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Ssrd Local Cell ID

Indicates the local cell ID of a split cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
