BbpCollaborationGrp

+-NE
  +-eNodeBFunction
    +-BbpCollaborationGrp

Description

A BbpCollaborateGrp MO consists of parameters related to BBP collaboration for certain features. When a BbpCollaborationGrp object is created, it can be associated with a piece of inventory baseband equipment and a piece of collaborating baseband equipment so that inventory BBPs and collaborating BBPs are added to the BBP collaboration group. Through collaboration, a collaborating BBP provides new features that supported only by the collaborating BBP for UEs that are served by an inventory BBP. Currently, the supported new features include only Turbo Receiver.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the eNodeBResModeAlgo MO:
    • If Cfg BbpCollaborationGrp, eNodeBResModeAlgoBbpCpriSharingSwitch should be OFF.
  • Relation with the BbpCollaborationGrp MO:
    • In BbpCollaborationGrp, InventoryBaseBandEqmId cannot be equal to CoBaseBandEqmId.
    • In BbpCollaborationGrp, InventoryBaseBandEqmId Only with one CoBaseBandEqmId.
    • In BbpCollaborationGrp, CoBaseBandEqmId Only with one InventoryBaseBandEqmId.
  • Relation with the BASEBANDEQM and BBP MOs:
    • In BbpCollaborationGrp, InventoryBaseBandEqmId not has BASEBANDEQMID in BASEBANDEQM.
    • In BbpCollaborationGrp, CoBaseBandEqmId not has BASEBANDEQMID in BASEBANDEQM.
  • Relation with the BASEBANDEQM MO:
    • In BbpCollaborationGrp, the baseband type of InventoryBaseBandEqmId cannot be downlink.
    • In BbpCollaborationGrp, the baseband type of CoBaseBandEqmId cannot be downlink.
  • Relation with the CoProcRes MO:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in a CoProcRes MO is selected, the BaseBandEqmId parameter in this CoProcRes MO must not equal the CoBaseBandEqmId parameter in the BbpCollaborationGrp MO.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
BBP Collaboration Group ID

Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.
Inventory Baseband Equipment ID

Indicates the ID of the inventory baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, an inventory BBP in a BBU is added to the inventory baseband equipment and the ID of the inventory baseband equipment is associated with the ID of the BBP collaboration group. In this way, an inventory BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.
Collaborating Baseband Equipment ID

Indicates the ID of the collaborating baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, a collaborating BBP in a BBU is added to the collaborating baseband equipment and the ID of the collaborating baseband equipment is associated with the ID of the BBP collaboration group. In this way, a collaborating BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.
Collaborating Features

Indicates the feature that a BBP collaboration group supports. The feature is specified when the group is created. Currently, only the Turbo Receiver feature is supported. This parameter applies only to LTE FDD and LTE TDD.
Collaboration Group Block Indication

Indicates the blocking method of a baseband processing unit (BBP) collaboration group. If this parameter is set to HIGH_PRIORITY_BLOCK(HIGH_PRIORITY_BLOCK), the UEs transferred from inventory BBPs to collaborating BBPs for assistance are immediately released. If this parameter is set to LOW_PRIORITY_BLOCK(LOW_PRIORITY_BLOCK), a BBP collaboration group is blocked when there are no UEs transferred from inventory BBPs to collaborating BBPs for assistance. If this parameter is set to UNBLOCK(Unblock), a BBP collaboration group is unblocked. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
Collaborating Group Status

Indicates the status of a BBP collaboration group. The status can be normal, blocked, being blocked, or being punished, or the group may experience board faults, configuration errors, or board blocking. This parameter applies only to LTE FDD and LTE TDD.
