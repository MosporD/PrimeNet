+-NE
  +-eNodeBFunction

Description

The ULSpectrumShrConfig MO consists of parameters used to configure spectrum sharing between UMTS and LTE.

Effective Scenario

Immediately

    • If the UlBandWidth parameter in a Cell MO is set to CELL_BW_N100, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, DC_HSDPA_BASED_UL_SPECTRUM_SHR (or the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to UL_SPECTRUM_SHARING and the UL_SPECTRUM_SHR_PH2_SW option of the SpectrumCloudEnhSwitch in the SpectrumCloud MO is selected), and the PrbRsvType parameter in the ULSpectrumShrConfig MO is set to LTE_UL_AVAILABLE_PRB, then the value of the LtePrbEndIndex parameter must be greater than or equal to the value calculated using the following formula: Value of the LtePrbStartIndex parameter + Value obtained by rounding up the result of the number of RBs indicated by the value of the UlBandWidth parameter multiplied by 0.5 + 1.
    • When the UlBandWidth parameter in a Cell MO is set to CELL_BW_N15, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to UL_SPECTRUM_SHARING, DC_HSDPA_BASED_UL_SPECTRUM_SHR or UL_SPECTRUM_SHR_PH2_WITH_GSM, and the PrbRsvType parameter in the ULSpectrumShrConfig MO under the Cell MO is set to LTE_UL_AVAILABLE_PRB, the value ranges of the LtePrbStartIndex and LtePrbEndIndex parameters in the ULSpectrumShrConfig MO must be 0 to 14.
  • Relation with the SpectrumCloud and CellRbReserve MOs:
    • Under the same cell, when the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to UL_SPECTRUM_SHARING, DC_HSDPA_BASED_UL_SPECTRUM_SHR or UL_SPECTRUM_SHR_PH2_WITH_GSM, the RbRsvMode and RbRsvType parameters in a CellRbReserve MO are set to NB_RESERVED or NB_DEPLOYMENT and DOWNLINK_MODE, respectively, and the PrbRsvType parameter is set to LTE_DL_AVAILABLE_PRB, the upper and lower limits of the RbRsvStartIndex and RbRsvEndIndex parameter values are the values of the LtePrbStartIndex and LtePrbEndIndex parameters, respectively.
    • Under the same cell, when the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to UL_SPECTRUM_SHARING or UL_SPECTRUM_SHR_PH2_WITH_GSM, the RbRsvMode and RbRsvType parameters in a CellRbReserve MO are set to NB_RESERVED or NB_DEPLOYMENT and UPLINK_MODE, respectively, and the PrbRsvType parameter is set to LTE_UL_AVAILABLE_PRB, the upper and lower limits of the RbRsvStartIndex and RbRsvEndIndex parameter values are the values of the LtePrbStartIndex and LtePrbEndIndex parameters, respectively.
