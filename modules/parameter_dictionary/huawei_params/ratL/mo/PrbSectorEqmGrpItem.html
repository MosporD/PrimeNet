PrbSectorEqmGrpItem

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-EuPrbSectorEqmGroup
          +-PrbSectorEqmGrpItem

Description

The PrbSectorEqmGrpItem MO consists of parameters used to specify the sectors served by the sector equipment group used by PRBs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EuPrbSectorEqmGroup
  • Relation with the Cell, EuPrbSectorEqm, SECTOREQM, RFU, and RRU MOs:
    • In a Cell MO, if NbCellFlag in a Cell MO is set to TRUE, CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to the EuPrbSectorEqm MO or PrbSectorEqmGrpItem MO under this Cell MO must be associated with an RRU or RFU MO supporting NBIOT.
  • Relation with the Cell, EuPrbSectorEqm, SECTOREQM, BASEBANDEQM, and EuPrbSectorEqmGroup MOs:
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to the EuPrbSectorEqm MO or the EuPrbSectorEqmGroup MO under this Cell MO must be configured, and if BasebandEqmId in the EuPrbSectorEqm MO or BasebandEqmId in the EuPrbSectorEqmGroup MO is not set to 255, BASEBANDEQMTYPE in all BASEBANDEQM MOs corresponding to EuPrbSectorEqm or EuPrbSectorEqmGroup MOs under this Cell MO must be set to ULDL.
  • Relation with the SECTOREQM MO:
    • ANTCFGMODE cannot be set to BEAM in the SECTOREQM MO associated with SectorEqmId in a PrbSectorEqmGrpItem MO.
  • Relation with the Cell and Prb MOs:
    • If CellActiveState in a Cell MO is set to CELL_ACTIVE, SectorEqmId in all PrbSectorEqmGrpItem MO instances in the Prb MO under this Cell MO must be unique.
    • If NbCellFlag and CellActiveState in a Cell MO are set to TRUE and CELL_ACTIVE, respectively, the number of PrbSectorEqmGrpItem instances with the same SectorEqmGroupId and SectorEqmId parameter settings must be equal to the number of Prb MO instances under this Cell MO.
  • Relation with the Cell, EuPrbSectorEqmGroup, and SECTOREQM MOs:
    • If CellActiveState in a Cell MO is CELL_ACTIVE, and MultiRruCellMode in this Cell MO is set to MPRU_AGGREGATION or SFN, EuPrbSectorEqmGroup MOs cannot be configured under this Cell MO after the cell is activated. If the EuPrbSectorEqmGroup MO has been configured under this Cell MO before the cell is activated, the PrbSectorEqmGrpItem MO associated with this EuPrbSectorEqmGroup MO must be configure, and the SECTOREQM MO corresponding to the PrbSectorEqmGrpItem MO must be configured.
  • Relation with the Cell, SECTOREQM, RRU, RRUCHAIN, and BBP MOs:
    • When the CellActiveState and CPRICompression parameters in a Cell MO are set to CELL_ACTIVE and NO_COMPRESSION, respectively, the CPRIEX parameter in the BBP MO connected to the RRU MO used by the SECTOREQM MO corresponding to the PrbSectorEqmGrpItem MO under the Cell MO must be set to OFF.
  • Relation with the Cell and SECTOREQM MOs:
    • The sector represented by a SECTOREQM MO under the PrbSectorEqmGrpItem MO associated with a Cell MO can be configured with one TX antenna and one RX antenna if the following conditions are met in the Cell MO: FddTddInd is set to CELL_FDD, CellActiveState is set to CELL_ACTIVE, TxRxMode is set to 1T1R, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to SFN or MPRU_AGGREGATION. The sector represented by the SECTOREQM MO under the PrbSectorEqmGrpItem MO associated with the Cell MO can be configured with two TX antennas and two RX antennas if the following condition is met in the Cell MO: TxRxMode, MultiRruCellFlag, and MultiRruCellMode are set to 2T2R, BOOLEAN_TRUE, and MPRU_AGGREGATION, respectively. The sector represented by the SECTOREQM MO under the PrbSectorEqmGrpItem MO associated with the Cell MO can be configured with one TX antenna and one RX antenna or two TX antennas and two RX antennas if the following condition is met in the Cell MO: TxRxMode, MultiRruCellFlag, and MultiRruCellMode are set to 2T2R, 2T4R, or 4T4R, BOOLEAN_TRUE, and SFN, respectively.
  • Relation with the EuPrbSectorEqmGroup MO:
    • Up to 16 PrbSectorEqmGrpItem MOs can be configured for the EuPrbSectorEqmGroup MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD PRBSECTOREQMGRPITEM

Use this command to configure a sector equipment group item for a PRB.
LST PRBSECTOREQMGRPITEM

Use this command to list the sector equipment group item configuration of a PRB.
RMV PRBSECTOREQMGRPITEM

Use this command to remove the sector equipment group item configuration of a PRB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.
Sector Equipment ID

Indicates the ID of the sector equipment that serves the PRB. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the NB-IoT PRB ID. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.
Sector Equipment Group ID

Indicates the ID of the sector equipment group that serves the PRB. It uniquely identifies a sector equipment group within an eNodeB. This parameter applies only to NB-IoT.
