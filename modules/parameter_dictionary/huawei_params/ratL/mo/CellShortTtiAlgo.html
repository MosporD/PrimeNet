CellShortTtiAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellShortTtiAlgo

Description

An CellShortTtiAlgo MO consists of parameters related to the cell-level short TTI algorithm, involving reasonable scheduling configuration, control channel allocation, power control, short TTI mode switching, and related items.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and Cell MOs:
    • When the FddTddInd parameter is set to CELL_FDD, the NbCellFlag parameter is set to FALSE, the DlCyclicPrefix and UlCyclicPrefix parameters in the Cell MO are set to NORMAL_CP, the SHORT_TTI_SW option of the SttiAlgoSwitch parameter in the CellShortTtiAlgo MO can be selected.
    • When the DlBandWidth and UlBandWidth parameters in the Cell MO are set to values greater than CELL_BW_N25, the SHORT_TTI_SW option of the SttiAlgoSwitch parameter in the CellShortTtiAlgo MO can be selected.
  • Relation with the ENodeBAlgoSwitch and CellAlgoSwitch MOs:

    • When the SHORT_TTI_SW option of the SttiAlgoSwitch parameter in the CellShortTtiAlgo MO is selected and the DlBandWidth parameter in the Cell MO is set to CELL_BW_N100, the value of the DlSrbgCntReservedForStti parameter in the CellShortTtiAlgo MO must be smaller than 9.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD.
DL SRBG Count Reserved for Short TTI

Indicates the number of short resource block groups (SRBGs) reserved for SPDSCH scheduling in short TTI mode. This parameter applies only to LTE FDD.
DeltaF for SPUCCH Format 1 and 1a

Indicates the delta of subslot SPUCCH formats 1 and 1a. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD.
DeltaF for SPUCCH Format 1b

Indicates the delta of subslot SPUCCH format 1b. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD.
SPUCCH RB Count

Indicates the number of RBs that can be used by the SPUCCH. This parameter is valid only when the PucchSwitch option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to LTE FDD.
UL SRBG Count Reserved for Short TTI

Indicates the number of uplink short resource block groups (SRBGs) reserved for UEs in short TTI mode. When the NttiSttiRbAdjStrategy parameter is set to STATIC, it is recommended that the value of this parameter be smaller than or equal to the value calculated by using the formula: (Number of RBs allowed by the system bandwidth - 4)/4. This parameter applies only to LTE FDD.
Normal TTI and Short TTI RB Adjustment Strategy

Indicates the policy of adjusting the maximum number of RBs available to the PDSCH/PUSCH. When this parameter is set to STATIC, the maximum number of RBs always equals the configured value. When this parameter is set to DYNAMIC, the maximum number of RBs is adaptively adjusted by the algorithm. This parameter applies only to LTE FDD.
SPDCCH RB Count

Indicates the number of RBs occupied by the SPDCCH. This parameter affects the maximum aggregation level available to the SPDCCH. When this parameter is set to RB_4, the SPDCCH occupies 4 RBs and the maximum aggregation level for the SPDCCH is 1. When this parameter is set to RB_8, the SPDCCH occupies 8 RBs and the maximum aggregation level for the SPDCCH is 2. When this parameter is set to RB_16, the SPDCCH occupies 16 RBs and the maximum aggregation level for the SPDCCH is 4. When this parameter is set to RB_32, the SPDCCH occupies 32 RBs and the maximum aggregation level for the SPDCCH is 8. This parameter applies only to LTE FDD.
Beta Offset Subslot ACK Index1

Indicates the index 1 mapped to the MCS offset for ACKs transmitted on subslot-based SPUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, value 15 is reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to LTE FDD.
Beta Offset Subslot ACK Index2

Indicates the index 2 mapped to the MCS offset for ACKs transmitted on subslot-based SPUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, value 15 is reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to LTE FDD.
Beta Offset Subslot CQI Index

Indicates the index mapped to the MCS offset for CQIs transmitted on subslot-based SPUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, values 0 and 1 are reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to LTE FDD.
Beta Offset Subslot RI Index1

Indicates the index 1 mapped to the MCS offset for RIs transmitted on subslot-based SPUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, values 13, 14, and 15 are reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to LTE FDD.
Short TTI DL HARQ Maximum Transmission Count

Indicates the maximum number of downlink HARQ transmissions of a UE in short TTI mode. This parameter applies only to LTE FDD.
Short TTI SRI Period

Indicates the scheduling request indicator (SRI) reporting period of UEs in subslot-based Short TTI mode. This parameter applies only to LTE FDD.
Beta Offset Subslot RI Index2

Indicates the index 2 mapped to the MCS offset for RIs transmitted on subslot-based SPUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, values 13, 14, and 15 are reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to LTE FDD.
PDCCH CCE Count Reserved for Short TTI

Indicates the maximum number of CCEs on the PDCCH reserved for UEs in short TTI mode. The short downlink control information (SDCI) carried in the first subslot in a subframe is transmitted on the PDCCH, and therefore CCEs on the PDCCH need to be reserved for UEs in short TTI mode. This parameter applies only to LTE FDD.
Short TTI Algorithm Switch

Indicates whether to enable short TTI in a cell.

SHORT_TTI_SW: Indicates whether to enable short TTI. This option applies only to LTE FDD.

SHORT_TTI_PREALLOCATION_SW: Indicates whether to enable preallocation for the short TTI mode. This option applies only to LTE FDD.

SPDCCH_BOUNDARY_POWER_CTRL_SW: Indicates whether to enable SPDCCH boundary power control. With this option selected, the power can be increased to hold the SPDCCH bit error rate under control when the maximum aggregation level is in use. This option applies only to LTE FDD.
Short TTI Entry DL RB Usage Threshold

Indicates the downlink RB usage threshold for entering the short TTI mode. This parameter applies only to LTE FDD.
Short TTI Entry UL RB Usage Threshold

Indicates the uplink RB usage threshold for entering the short TTI mode. This parameter applies only to LTE FDD.
Short TTI Entry UL SINR Threshold

Indicates the uplink SINR threshold for entering the short TTI mode. This parameter applies only to LTE FDD.
Short TTI Preallocation Duration

Indicates the maximum preallocation duration for a UE in short TTI mode. This parameter applies only to LTE FDD.
Short TTI Preallocation Minimum Period

Indicates the minimum interval between preallocations for UEs in Short TTI mode. The interval between two consecutive preallocations for a UE in Short TTI mode must not be less than the value of this parameter. One subframe is divided into six subslots. Each subslot contains two or three OFDM symbols. For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD.
Short TTI Preallocation Size

Indicates the size of data in each preallocation for UEs in Short TTI mode. The number of RBs in each preallocation is calculated based on the value of this parameter. This parameter applies only to LTE FDD.
Short TTI UL HARQ Maximum Transmission Count

Indicates the maximum number of uplink HARQ transmissions of a UE in Short TTI mode. This parameter applies only to LTE FDD.
Short TTI Entry DCCH Quality Hysteresis

Indicates the downlink control channel quality hysteresis used for configuring short TTIs for UEs. The eNodeB configures short TTIs for a UE only if the downlink control channel quality for the UE is higher than the sum of the demodulation threshold for the maximum aggregation level of the SPDCCH and this hysteresis. This parameter applies only to LTE FDD.
