NrNRelationship

+-NE
  +-eNodeBFunction
    +-Cell
      +-NrNRelationship

Description

This MO consists of parameters related to a neighbor relationship with an NR cell, which can be used for SgNB addition for LTE-NR NSA DC, and LTE-to-NR handover, redirection, and cell reselection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 128 NrNRelationship MOs can be configured for each cell when equipped with UMPTa/b/e board.
    • A maximum of 256 NrNRelationship MOs can be configured for each cell.
  • Relation with the NrNRelationship MO:
    • A maximum of 36*128 NrNRelationship MOs can be configured in the same eNodeB when equipped with UMPTe.
    • A maximum of 2304 NrNRelationship MOs can be configured in the same eNodeB when equipped with UMPTa/b.
    • A maximum of 36*256 NrNRelationship MOs can be configured in the same eNodeB when equipped with UMPTga.
    • A maximum of 72*256 NrNRelationship MOs can be configured in the same eNodeB.
  • Relation with the NODE MO:
    • WM in the NODE MO is set to CONCURRENT, a maximum of 36*256 NrNRelationship MOs can be configured in the same eNodeB.
  • Relation with the NrExternalCell MO:
    • Before adding a NrNRelationship MO, ensure that the associated NrExternalCell MO has been configured.
  • Relation with the NrNFreq and NrExternalCell MOs:
    • DlArfcn in the NrExternalCell MO associated with a NrNRelationship MO must have been configured in a NrNFreq MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile Country Code

Indicates the mobile country code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the mobile network code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
gNodeB ID

Indicates the ID of the gNodeB serving the neighboring NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the ID of a neighboring NR cell served by a gNodeB. It uniquely identifies an NR cell in the gNodeB. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.
Blind Configuration Indicator

Indicates whether an NR neighboring cell can be configured as an SCG cell through blind configuration. If this parameter is set to TRUE, an NR neighboring cell can be configured as an SCG cell through blind configuration. If this parameter is set to FALSE, an NR neighboring cell cannot be configured as an SCG cell through blind configuration. This parameter applies only to LTE FDD and LTE TDD.
Aggregation Attribute

Indicates the aggregation attribute of a neighboring NG-RAN cell.

CONTROL_MODE_FLAG: If this option is deselected, users can modify and delete an object, but ANR cannot modify or delete an object. If users add an object whose name is the same as an existing object, the addition fails. If this option is selected, both ANR and users can modify or delete an object (the operation of deleting a non-existing object is also successful), and add an object whose name is not the same as any existing object. Users can add (modify actually) an object whose name is the same as an existing object. ANR cannot add an object whose name is the same as an existing object. This option is selected by default for objects automatically created by ANR. Users can either select or deselect this option for the objects they create. This option applies only to LTE FDD and LTE TDD.

NO_REMOVE_FLAG: If this option is selected, ANR cannot remove a neighbor relationship. If this option is deselected, ANR can remove a neighbor relationship. This option applies only to LTE FDD and LTE TDD.

NO_HO_FLAG: If this option is selected, UEs in the E-UTRAN cell cannot be handed over to the neighboring NG-RAN cell. If this option is deselected, UEs in the E-UTRAN cell can be handed over to the neighboring NG-RAN cell. This option applies only to LTE FDD and LTE TDD.

CO_DEPLOYMENT_NSA_FLAG: If this option is selected, the neighboring NG-RAN cell can be added as a PSCell in the frequency band combination for collocated deployment. If this option is deselected, the neighboring NG-RAN cell cannot be added as a PSCell in the frequency band combination for collocated deployment. This option takes effect when the PCell and PSCell meet the requirements of the frequency band combination for collocated deployment. For details about the configuration of frequency band combinations for collocated deployment, see the AggregationAttribute parameter in the NrScgFreqConfig MO. This option applies only to LTE FDD and LTE TDD.
Neighboring Cell Addition Time

Indicates the time the neighboring cell was added by ANR for the first time. In free mode, this time is the local time of the NE. In control mode, this time is the local time of the OSS when optimization suggestions are delivered. The format is YYYY-MM-DD. For example, the value 2018-01-01 indicates January 1, 2018. The value 2001-01-01 indicates that the neighboring cell was manually added. This parameter applies only to LTE FDD and LTE TDD.
