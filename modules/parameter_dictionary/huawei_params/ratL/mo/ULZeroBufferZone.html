ULZeroBufferZone

+-NE
  +-eNodeBFunction
    +-Cell
      +-ULZeroBufferZone

Description

The ULZeroBufferZone MO consists of parameters related to the UL Refarming Zero Bufferzone feature.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • When the NbCellFlag in a Cell MO is set to FALSE, in the ULZeroBufferZone MO, the ULSharedFreqEndRB parameter must be set to a value smaller than Resource Block of the UlBandWidth parameter.
    • The UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO can be selected only when the FddTddInd parameter in the associated Cell MO is set to CELL_FDD.
    • When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in the ULZeroBufferZone MO is selected, the UlBandWidth parameter in the associated Cell MO must be set to CELL_BW_N25, CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100.
    • The UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO under the Cell MO can be selected only when the NbCellFlag parameter in this Cell MO is set to FALSE.
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the HighSpeedFlag parameter in the Cell MO must not be set to HIGH_SPEED, ULTRA_HIGH_SPEED, or EXTRA_HIGH_SPEED.
  • Relation with the ENodeBAlgoSwitch MO:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the UlIcicFreqSwitch parameter in the ENodeBAlgoSwitch MO must be set to OFF.
  • Relation with the CellAlgoSwitch MO:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the AvoidGeranInterfSwitch, AvoidCDMAInterfSwitch, AvoidUtranInterfSwitch, and AvoidSpurEmissInterfSwitch options of the AvoidInterfSwitch parameter in the CellAlgoSwitch MO must be deselected.
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the GLDynSpectrumShareSwitch and GLZeroBufferZoneSwitch options of the DynSpectrumShareSwitch parameter in the CellAlgoSwitch MO must be deselected.
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the SuperCombCellSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO must be deselected.
  • Relation with the CellLteFlexBw MO:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the LTE_FB_CFG_SWITCH option of the LteFlexBwSwitch parameter in the CellLteFlexBw MO must be deselected.
  • Relation with the SpectrumCloud MO:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the SpectrumCloudSwitch parameter in the SpectrumCloud MO cannot be set to GL_SPECTRUM_CONCURRENCY.
  • Relation with the ULSpectrumShrConfig MO:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the ULSpectrumShrConfig MO corresponding to the ULSpectrumSharingConfigId parameter in the ULZeroBufferZone MO must be configured.
  • Relation with the ULSpectrumShrConfig and Cell MOs:
    • Under the same cell, if the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the PrbRsvType parameter in the ULSpectrumShrConfig MO is set to UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, or UMTS_CORE_SPECTRUM_4, and the LtePrbStartIndex parameter value is 0 or the LtePrbEndIndex parameter value is equal to the number of RBs corresponding to the UlBandWidth parameter in the Cell MO minus 1, the difference between the LtePrbEndIndex and LtePrbStartIndex parameter values must be greater than or equal to 13.
    • Under the same cell, if the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in a ULZeroBufferZone MO is selected, the PrbRsvType parameter in the ULSpectrumShrConfig MO is set to UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, UMTS_CORE_SPECTRUM_4, or UMTS_LTE_SHARED_SPECTRUM, the LtePrbStartIndex and LtePrbEndIndex parameter values must be smaller than the number of RBs corresponding to the UlBandWidth parameter in the Cell MO.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in an ULZeroBufferZone MO is selected, and the FddTddInd in the Cell is set to CELL_FDD, the SpectrumCloudSwitch parameter in the SpectrumCloud MO must not be set to LTE_NR_UPLINK_SPECTRUM_SHR or LTE_NR_SPECTRUM_SHR.
  • Relation with the CellAlgoSwitch, RACHCfg, Cell, PUCCHCfg, CellPdcchAlgo, and SpectrumCloud MOs:
    • The PrachFreqOffset parameter in the RACHCfg MO must be properly set so that the PRACH RBs and PUCCH RBs do not overlap in the frequency domain under the following conditions: (a) The SpectrumCloudSwitch parameter in the SpectrumCloud MO is not set to UL_SPECTRUM_SHARING, UL_SPECTRUM_SHR_PH2_WITH_GSM, or DC_HSDPA_BASED_UL_SPECTRUM_SHR, the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in the ULZEROBUFFERZONE MO is deselected, or the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in the ULZEROBUFFERZONE MO and the PucchFlexCfgSwitch option of the PucchAlgoSwitch parameter in the CellAlgoSwitch MO are selected. (b) The NbCellFlag, FddTddInd, and UlBandWidth parameters in the Cell MO are set to FALSE, CELL_FDD, and CELL_BW_N15, respectively. (c) The PucchSwitch option of the PucchAlgoSwitch parameter in the CellAlgoSwitch MO is deselected. (d) The PrachFreqOffsetStrategy parameter in the RACHCfg MO is not set to FULLY_AUTOMATIC.
    • The PrachFreqOffset parameter in the RACHCfg MO must be properly set so that the PRACH RBs and PUCCH RBs do not overlap in the frequency domain under the following conditions: (a) The SpectrumCloudSwitch parameter in the SpectrumCloud MO is not set to UL_SPECTRUM_SHARING, UL_SPECTRUM_SHR_PH2_WITH_GSM, or DC_HSDPA_BASED_UL_SPECTRUM_SHR, the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in the ULZEROBUFFERZONE MO is deselected, or the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of the ZeroBufZoneSwitch parameter in the ULZEROBUFFERZONE MO and the PucchFlexCfgSwitch option of the PucchAlgoSwitch parameter in the CellAlgoSwitch MO are selected. Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
UL Shared Spectrum Start RB

Indicates the location of the start RB in the UMTS and LTE shared spectrum. This parameter is valid only when the UL Refarming Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UL Shared Spectrum End RB

Indicates the location of the end RB in the UMTS and LTE shared spectrum. This parameter is valid only when the UL Refarming Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UL Zero Buffer Zone Uplink PRB Threshold

Indicates the uplink physical resource block (PRB) threshold in UL Refarming Zero Bufferzone. This parameter applies only to LTE FDD.
UL Zero Buffer Zone Uplink PRB Offset

Indicates the uplink physical resource block (PRB) offset in UL Refarming Zero Bufferzone. This parameter applies only to LTE FDD.
UL Zero Buffer Zone Downlink RSRP Threshold

Indicates the RSRP threshold used for UE location determination. This parameter is valid only when the UL Refarming Zero Bufferzone feature or UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UL Zero Buffer Zone Downlink RSRP Offset

Indicates the RSRP offset used for UE location determination. This parameter is valid only when the UL Refarming Zero Bufferzone feature or UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UL Zero Buffer Zone B1 Remove Offset

Indicates the threshold for stopping event B1 measurements. This parameter is valid only when the UL Refarming Zero Bufferzone feature or UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UTRAN RSCP Report Threshold

Indicates the UMTS RSCP reporting threshold. This parameter is valid only when the UL Refarming Zero Bufferzone feature or UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UL Zero Buffer Zone Inter Rat B1 Timer

Indicates the period of inter-RAT event B1 measurements. This parameter is valid only when the UL Refarming Zero Bufferzone feature or UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
UMTS and LTE Spectrum Sharing Config ID

Indicates the cell-specific configuration ID of UMTS and LTE spectrum sharing. This parameter is valid only when the UMTS and LTE Zero Bufferzone feature is enabled. This parameter applies only to LTE FDD.
Zero Buffer Zone Switch

Indicates whether to enable zero bufferzone. When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of this parameter is selected, UMTS and LTE zero bufferzone is enabled. When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of this parameter is deselected, UMTS and LTE zero bufferzone is disabled. This parameter applies only to LTE FDD.
