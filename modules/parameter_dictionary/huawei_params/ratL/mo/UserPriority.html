UserPriority

+-NE
  +-eNodeBFunction
    +-UserPriority

Description

A UserPriority MO consists of parameters related to the switches of ARP- and QCI-based user-differentiated scheduling and the mapping between ARP values and user priorities.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CnOperator MO:
    • If the ARP_QCI_BASED_DIFF_SCH_SW option of the OperatorFunSwitch parameter in the CnOperator MO is selected, the ArpSchSwitch parameter in the UserPriority MO must be selected.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST USERPRIORITY

Use this command to list the configurations of policies applied to UEs running unlimited services in an eNodeB.
MOD USERPRIORITY

Use this command to modify the configurations of policies applied to UEs running unlimited services in an eNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ARP Schedule Switch

Indicates whether to enable ARP- and QCI-based user-differentiated scheduling. If the ArpPrioritySchSwitch option is selected, ARP- and QCI-based user-differentiated scheduling is enabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 do not take effect. If the ArpPrioritySchSwitch option is deselected, ARP- and QCI-based user-differentiated scheduling is disabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 take effect. This option applies only to LTE FDD and LTE TDD.
