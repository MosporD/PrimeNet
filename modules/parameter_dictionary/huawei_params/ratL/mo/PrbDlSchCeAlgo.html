  +-eNodeBFunction

Description

A PrbDlSchCeAlgo MO consists of coverage-level-specific parameters related to the downlink scheduling algorithm for PRB carriers of NB-IoT cells. Coverage-level-specific downlink scheduling parameters determine the downlink scheduling policies and functions for different coverage levels.

Effective Scenario

Immediately

  • Possible parents:

    Prb

Related MML Commands

Table 1 Related MML commands

MML Command

Function

Use this command to query coverage-level-specific parameters related to the downlink scheduling algorithm for PRB carriers of an NB-IoT cell.

Use this command to modify coverage-level-specific parameters related to the downlink scheduling algorithm for PRB carriers of an NB-IoT cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the NB-IoT PRB ID. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.
Coverage Level

Indicates the UE's coverage level. The value 0 indicates 0 dB coverage enhancement; the value 1 indicates 10 dB coverage enhancement; and the value 2 indicates 20 dB coverage enhancement. This parameter applies only to NB-IoT.
DL Initial Transmission Repetition Count

Indicates the PDSCH initial transmission repetition times for UEs corresponding to a certain coverage level. This parameter applies only to NB-IoT.
Downlink Initial MCS

Indicates the initial downlink MCS index of UEs of a coverage level. This parameter applies only to NB-IoT.
Uu Message Waiting Timer

Indicates the timer governing the period the eNodeB waits for a Uu response message from a UE. If the timer expires, the eNodeB initiates to release the UE. If this parameter is set to 0, the UuMessageWaitingTimer parameter in the ENodeBConnStateTimer MO, rather than this parameter, takes effect. If this parameter is set to 1 to 200, this parameter takes effect. This parameter applies only to NB-IoT.
Proportion of Downlink Scheduling Duration

Indicates the proportion of downlink scheduling duration for a specific coverage level. This parameter applies only to NB-IoT.
Power Difference Thld

Indicates the threshold of the power difference between the non-anchor and anchor carriers at a specific coverage level. When the result of non-anchor carrier power minus anchor carrier power is less than this threshold, UEs at this specific coverage level cannot be assigned to a downlink-only carrier for services. If this parameter is set to -128, carrier assignment for UEs is not restricted by power difference. This parameter is valid only for non-anchor carriers. This parameter applies only to NB-IoT.
DL AMC MCS Adjustment Step

Indicates the MCS adjustment step used in downlink AMC based on path loss difference. If this parameter is set to 0 for a coverage level, downlink AMC based on path loss difference does not take effect for the coverage level. This parameter applies only to NB-IoT.
DL AMC Path Loss Adjustment Step

Indicates the path loss adjustment step used in downlink AMC based on path loss difference. If this parameter is set to 0, the downlink MCS index is adjusted at the step specified by the DlAmcMcsAdjustStep parameter in each downlink scheduling occasion for UEs at the coverage level where downlink AMC based on path loss difference has taken effect. The adjustment does not stop until the conditions for stopping the adjustment are met. This parameter applies only to NB-IoT.
