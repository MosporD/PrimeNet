Mcch

+-NE
  +-eNodeBFunction
    +-Mce
      +-MbsfnArea
        +-Mcch

Description

The Mcch MO includes the parameters used to configure the MCCH.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    MbsfnArea

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST MCCH

Use this command to list MCCH configuration data.
MOD MCCH

Use this command to modify MCCH configuration data.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Area ID

Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
Modulation and Coding Scheme

Indicates the MCS for information transmitted over the MCCH. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Modification Period

Indicates the interval between MCCH updates. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
PDCCH Length

Indicates the number of OFDM symbols (in an MBSFN subframe) used for the PDCCH. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Repetition Period

Indicates the interval between transmissions of MCCH information. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Repetition Period Offset

Indicates the repetition period offset, which is used together with the RepetitionPeriod parameter in the Mcch MO to specify the radio frames in which MCCH information is transmitted. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subframe Allocation Information

Indicates the subframes in a radio frame in which MCCH information can be sent. If the cells in an MBSFN area work in TDD mode, SF3, SF4, SF7, SF8, and SF9 (represented by bit 5 to bit 1 in sequence) can be configured as MBSFN subframes. If a bit is set to 1, the corresponding subframe can be used for MCCH information transmission. If the cells in an MBSFN area work in FDD mode, SF1, SF2, SF3, SF6, SF7, and SF8 (represented by bit 5 to bit 0 in sequence) can be configured as MBSFN subframes. If a bit is set to 1, the corresponding subframe can be used for MCCH information transmission. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
