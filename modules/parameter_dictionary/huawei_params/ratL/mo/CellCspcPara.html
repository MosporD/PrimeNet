CellCspcPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellCspcPara

Description

The CellCspcPara MO consists of parameters related to coordinated scheduling and power control (CSPC) in an E-UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellDlschAlgo MO:
    • If the CellCspcSwitch in the CellCspcPara MO is ON, DlschStrategy in the CellDlschAlgo MO must be set to DLSCH_PRI_TYPE_EPF.
    • If the CelleCspcSwitch in the CellCspcPara MO is ON, DlschStrategy in the CellDlschAlgo MO must be set to DLSCH_PRI_TYPE_EPF.
    • If the IntraEnbCspcSw in the CellCspcPara MO is ON, any option under the MbsfnSfCfg parameter in the CellDlschAlgo MO cannot be selected.
  • Relation with the ENodeBAlgoSwitch MO:
    • If the CellCspcSwitch in the CellCspcPara MO is ON, DlIcicSwitch in the ENodeBAlgoSwitch MO must be set to DlIcicSwitch_OFF_ENUM.
  • Relation with the Cell MO:
    • If the CellCspcSwitch in the CellCspcPara MO is ON, HighSpeedFlag in the Cell MO cannot be set to HIGH_SPEED or ULTRA_HIGH_SPEED.
    • When the NbCellFlag in a Cell MO is set to FALSE, if CellRadius in a Cell MO is set to a value greater than 100000 m, CellCspcSwitch in the CellCspcPara MO under this Cell MO must be set to OFF.
    • If the CelleCspcSwitch in the CellCspcPara MO is ON, HighSpeedFlag in the Cell MO cannot be set to HIGH_SPEED, ULTRA_HIGH_SPEED, or EXTRA_HIGH_SPEED.
    • When the NbCellFlag in a Cell MO is set to FALSE, if CellRadius in a Cell MO is set to a value greater than 15000m, CelleCspcSwitch in the CellCspcPara MO under this Cell MO must be set to OFF.
    • If NbCellFlag in a Cell MO is set to TRUE, CellCspcSwitch in the CellCspcPara must be set OFF.
    • If NbCellFlag in a Cell MO is set to TRUE, CelleCspcSwitch in the CellCspcPara must be set OFF.
    • If NbCellFlag in a Cell MO is set to TRUE, IntraEnbCspcSw in the CellCspcPara must be set OFF.
    • The CelleCspcSwitch parameter in the CellCspcPara MO can be set to ON only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the MultiCellShareMode parameter in the Cell MO is set to NORMAL.
  • Relation with the CellAlgoSwitch MO:
    • If the CellCspcSwitch in the CellCspcPara MO is ON, EicicSwitch in the CellAlgoSwitch MO cannot be set to STATIC or DYNAMIC.
    • The DlCellCoverEnhanceAlgoSw option of CellDlCoverEnhanceSwitch in the CellAlgoSwitch MO can be selected only if CellCspcSwitch of the CellCspcPara MO is set to OFF.
    • The DlCellCoverEnhanceAlgoSw option of CellDlCoverEnhanceSwitch in the CellAlgoSwitch MO can be selected only if CelleCspcSwitch of the CellCspcPara MO is set to OFF.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, CellCspcSwitch in the related CellCspcPara MO must be set to OFF.
    • If the IntraEnbCspcSw of the CellCspcPara MO is set to ON, the DlCellCoverEnhanceAlgoSw option under the CellDlCoverEnhanceSwitch parameter in the CellAlgoSwitch MO cannot be selected.
    • If the IntraEnbCspcSw in the CellCspcPara MO is ON, the GLPwrShare parameter in the CellAlgoSwitch cannot be set to ON.
    • If the IntraEnbCspcSw in the CellCspcPara MO is ON, the GLDynSpectrumShareSwitch option of the DynSpectrumShareSwitch parameter in the associated CellAlgoSwitch MO cannot be turned on.
    • If the CelleCspcSwitch in the CellCspcPara MO is ON, EicicSwitch in the CellAlgoSwitch MO cannot be set to STATIC or DYNAMIC.
    • If the IntraEnbCspcSw in the CellCspcPara MO is ON, the EicicSwitch parameter in the CellAlgoSwitch MO cannot be set to STATIC or DYNAMIC.
    • The CelleCspcSwitch parameter in a CellCspcPara MO and AdptPwrMatchingAlgoSw under the CellDlCoverEnhanceSwitch parameter in the associated CellAlgoSwitch MO cannot be both set on.
    • The CellCspcSwitch parameter in a CellCspcPara MO and AdptPwrMatchingAlgoSw under the CellDlCoverEnhanceSwitch parameter in the associated CellAlgoSwitch MO cannot be both set on.
    • The Tm9JtSwitch of DlCompSwitch in a CellAlgoSwitch MO must be set off if EicicSwitch in the CellAlgoSwitch MO is set to DYNAMIC, CelleCspcSwitch in the associated CellCspcPara MO is set to ON, or Virtual4T4RSwitch of EmimoSwitch in the CellAlgoSwitch MO is set on.
    • InBandRelayDeNbSwitch of the RelaySwitch parameter in the CellAlgoSwitch MO and CellCspcSwitch in the CellCspcPara MO cannot be both set on.
    • InBandRelayReNbSwitch of the RelaySwitch parameter in the CellAlgoSwitch MO and CellCspcSwitch in the CellCspcPara MO cannot be both set on.
    • The CelleCspcSwitch parameter in the CellCspcPara MO can be selected only when the InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is deselected.
  • Relation with the CellAlgoSwitch and Cell MOs:
    • If the Virtual4T4RSwitch option of the EmimoSwitch parameter in the CellAlgoSwitch MO is selected and the FddTddInd parameter in the Cell MO is set to CELL_TDD, the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF.
    • FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch of DlCompSwitch in a CellAlgoSwitch MO must be set off if TxRxMode in the associated Cell MO is set to 1T1R or 1T2R, EicicSwitch in the CellAlgoSwitch MO is set to DYNAMIC, CelleCspcSwitch in the associated CellCspcPara MO is set to ON, or Virtual4T4RSwitch of EmimoSwitch in the CellAlgoSwitch MO is set on.
  • Relation with the Cell and ENodeBAlgoSwitch MOs:
    • If the CellActiveState in a Cell MO is set to CELL_ACTIVE and the CelleCspcSwitch in the CellCspcPara MO is ON, DlIcicSwitch in the ENodeBAlgoSwitch MO must be set to DlIcicSwitch_OFF_ENUM.
    • If the CellActiveState in a Cell MO is set to CELL_ACTIVE and the IntraEnbCspcSw in the CellCspcPara MO is ON, the DlIcicSwitch parameter in the ENodeBAlgoSwitch MO must be set to DlIcicSwitch_OFF_ENUM.
  • Relation with the CellDlpcPdschPa MO:
    • Values represented by selected options of eCspcPCAdjRange in the CellCspcPara MO must be less than the value of PaPcOff in the CellDlpcPdschPa MO.
  • Relation with the NCellSrsMeasPara MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the CellCspcSwitch parameter in the associated CellCspcPara MO is set to OFF.
  • Relation with the CellDynPowerSharing, CspcAlgoPara, CellAlgoSwitch, Cell, and PHICHCfg MOs:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only when the following conditions are met: The GLPwrShare parameter in the CellAlgoSwitch MO, the CspcAlgoSwitch parameter in the CspcAlgoPara MO, and the CellCspcSwitch and CelleCspcSwitch parameters in the CellCspcPara MO are set to OFF, the PhichInnerLoopPcSwitch option of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, and the PhichDuration parameter in the PHICHCfg MO is not set to EXTENDED.
  • Relation with the Cell, eUCellSectorEqm, SectorSplitCell, and SectorSplitGroup MOs:
    • The IntraEnbCspcSw parameter in the CellCspcPara MO under a Cell MO must be set to OFF when the following conditions are met: The CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the CellBeamMode parameter in the eUCellSectorEqm MO under the Cell MO is set to MASSIVE_MIMO_Ph2, and the number of SectorSplitCell MO instances under the SectorSplitGroup MO associated with the Cell MO is not greater than 2.
  • Relation with the CellShortTtiAlgo MO:
    • The SHORT_TTI_SW option of the SttiAlgoSwitch parameter in a CellShortTtiAlgo MO can be selected only when all of the CellCspcSwitch, IntraEnbCspcSw, and CelleCspcSwitch parameters in the associated CellCspcPara MO are set to OFF.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the FddTddInd in the Cell is set to CELL_FDD, and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_UPLINK_SPECTRUM_SHR or LTE_NR_SPECTRUM_SHR, the CellCspcSwitch parameter in a CellCspcPara MO must be set to OFF.
  • Relation with the eUCellSectorEqm MO:
    • If the CellBeamMode parameter in an eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, the CellCspcSwitch parameter in the associated CellCspcPara MO must be set to OFF.
    • If the CellBeamMode parameter in an eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, the CelleCspcSwitch parameter in the associated CellCspcPara MO must be set to OFF.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • The CelleCspcSwitch parameter in the CellCspcPara MO can be set to ON only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the BFModeUserPwrSwitch, BFModeUserAdptPwrSwitch, and BfEnhChnPwrFormSwitch options of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO are deselected.
    • The CelleCspcSwitch parameter in the CellCspcPara MO can be set to ON only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the InterDlCompDcsSwitch, and InterDlCompCbfSwitch options of the DlCompSwitch parameter in the CellAlgoSwitch are deselected.
  • Relation with the CellAlgoExtSwitch MO:
    • If UlCoverageEnhancementSw in the CellAlgoExtSwitch MO is set to ON, CellCspcSwitch in the CellCspcPara MO must be set to OFF.
  • Relation with the Cell and PDSCHCfg MOs:
    • The CelleCspcSwitch parameter in the CellCspcPara MO can be set to ON only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the EmfPowerLimitSwitch parameter in the PDSCHCfg MO is deselected.
  • Relation with the SymbolPwrSaving, CspcAlgoPara, and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the same cell, then the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected and the CellCspcSwitch parameter in the CellCspcPara MO must be set to OFF for the cell.
  • Relation with the SymbolPwrSaving and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF for the cell.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the CelleCspcSwitch parameter in the CellCspcPara MO must not be set to ON.
  • Relation with the Cell, SectorSplitCell, SectorSplitGroup, and CspcAlgoPara MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to NOT_CFG, then the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected.
  • Relation with the Cell and CellDlschAlgo MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the DL_INTRA_JAMC_ALGO_SW option of the DlJointAMCAlgoSw parameter in the CellDlschAlgo MO is selected, the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the DL_INTRA_JAMC_ALGO_SW option of the DlJointAMCAlgoSw parameter in the CellDlschAlgo MO is selected, the CellCspcSwitch parameter in the CellCspcPara MO must be set to OFF.
  • Relation with the CellIntelAmcConfig MO:
    • When the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in the CellIntelAmcConfig MO is selected, the CellCspcSwitch parameter in a CellCspcPara MO must not be set to ON.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP CELLCSPCSTATUS

Use this command to query whether CSPC is enabled in a cell or all cells.
DSP CELLDLCOMPCOCELLS

Use this command to query the DL CoMP status of the cell and the list of cooperating cells for the cell. This command applies only to LTE FDD.
DSP CELLDLCOMPSTATUS

Use this command to query the DL CoMP state in all cells in DL CoMP scenarios.
DSP CELLECSPCSTATUS

Use this command to query information about the coordinating neighboring cells after eCSPC is activated.
DSP CELLINTRAENBCSPCSTATUS

Use this command to query information about the coordinating neighboring cells in intra-eNodeB CSPC. This command applies only to LTE FDD.
LST CELLCSPCPARA

Use this command to list the CSPC configuration in a cell or all cells.
MOD CELLCSPCPARA

Use this command to modify the CSPC configuration in a cell.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
eCSPC PC Adjustment UE Number Threshold

Indicates the UE number threshold for power coordination to take effect. The eNodeB samples the number of activated UEs in the downlink in a cell multiple times and calculates the average number. If the average number is not 0 and greater than or equal to the threshold, power coordination takes effect. If the average number is 0 or less than the threshold, power coordination does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Cell CSPC Switch

Indicates whether to enable CSPC in the cell. This parameter applies only to LTE FDD and LTE TDD.
CSPC UE SRS Config Rapid Report Switch

Indicates whether to report the changed sounding reference signal (SRS) configurations of UEs with CSPC applied in the serving cell to the centralized control node immediately after the configurations are changed. This parameter applies only to LTE FDD.
CSPC UE SRS Config Report Period

Indicates the interval at which the local cell reports its UE-specific SRS configurations to the centralized control node. This parameter applies only to LTE FDD.
Uplink RSRP Measurement Report Period

Indicates the interval at which neighboring cells report their uplink reference signal received power (RSRP) measurement results to the local cell. This parameter applies only to LTE FDD.
CSPC CQI Filter Coefficient

Indicates the filtering coefficient for channel quality indicators (CQIs) in CSPC-based power optimization. This filtering makes the reported CQIs more stable. This parameter applies only to LTE FDD and LTE TDD.
eCSPC A3 Offset

Indicates the A3 offset for eCSPC. If the parameter value is increased, the probability of UEs reporting event A3 is reduced. A larger value of this parameter indicates a smaller number of cell edge users, and a smaller value of this parameter indicates a larger number of cell edge users. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Cell eCSPC Switch

Indicates whether to enable cell-level enhanced CSPC (eCSPC). eCSPC is enabled only when this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.
eCSPC Power Control Adjustment Range

Indicates the cell power adjustment range for eCSPC. This parameter must be set to a PDSCH PA value less than the value of the PaPcOff parameter. At most two values can be selected for the eCspcPCAdjRange parameter. If one value is selected for the eCspcPCAdjRange parameter, only one-level adjustment is applicable. If two values are selected for this parameter, two-level adjustment is supported. This parameter applies only to LTE FDD and LTE TDD.
Intra Enodeb Cspc Switch

Indicates whether to enable intra-eNodeB CSPC. Intra-eNodeB CSPC is enabled only when this parameter is set to ON(On). This parameter applies only to LTE FDD.
