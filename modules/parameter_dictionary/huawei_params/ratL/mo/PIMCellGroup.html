PIMCellGroup

+-NE
  +-eNodeBFunction
    +-PIMCellGroup
+-NE
  +-eNodeBFunction
    +-PIMCellGroup

Description

A PIMCellGroup MO consist of parameters related to a passive inter-modulation (PIM) cell group. A PIM mitigation cell group consists of two cells sharing an antenna system.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction;eNodeBFunction
  • Relation with the CellAlgoSwitch, Cell, and ENodeBAlgoSwitch MOs:
    • If CellPIMInterMitigSwitch in the CellAlgoSwitch MO is set to ON and CellActiveState in the Cell MO associated with this CellAlgoSwitch MO is CELL_ACTIVE, LocalCellId in the CellAlgoSwitch MO must have been set in a PIMCellGroup MO. This constraint applies only when the PIM_ADP_CELL_SEL_SWITCH option of the PimSwitch parameter in the ENodeBAlgoSwitch MO is deselected.
  • Relation with the DdCellGroup MO:
    • If PimMitigationMode in a PIMCellGroup MO instance is set to BASED_ON_JOINT_SCH, the local cell IDs specified by Cell1Id and Cell2Id must be different from the local cell IDs specified by LocalCellId1 and LocalCellId2 in a DdCellGroup instance.
  • Relation with the Cell MO:
    • If PimMitigationMode in a PIMCellGroup MO instance is set to BASED_ON_JOINT_SCH, CustomizedBandWidthCfgInd cannot be set to CFG for the cells specified by Cell1Id and Cell2Id in the PIMCellGroup MO instance.
  • Relation with the CellDlschAlgo MO:
    • If PimMitigationMode in a PIMCellGroup MO instance is set to BASED_ON_JOINT_SCH, BreathingPilotSwitch of BreathingPilotAlgoSwitch cannot be set on in the CellDlschAlgo MO instance for either of the cells specified by Cell1Id and Cell2Id in the PIMCellGroup MO instance.
  • Relation with the CellAlgoSwitch MO:
    • If PimMitigationMode in a PIMCellGroup MO instance is set to BASED_ON_JOINT_SCH, EmimoCpsSwitch of EmimoSwitch cannot be set on in the CellAlgoSwitch MO instance for either of the cells specified by Cell1Id and Cell2Id in the PIMCellGroup MO instance.
  • Relation with the ENodeBAlgoSwitch MO:
    • If a PIMCellGroup MO is configured, the PIM_ADP_CELL_SEL_SWITCH option of PimSwitch in the ENodeBAlgoSwitch MO must be deselected.
  • Relation with the MPT MO:
    • If TYPE in an MPT MO instance is set to LMPT for an eNodeB, PimMitigationMode in a PIMCellGroup MO instance cannot be set to BASED_ON_JOINT_SCH for the eNodeB.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
PIM Cell Group Identity

Indicates the ID of a passive intermodulation (PIM) cell group. It uniquely identifies a PIM cell group within an eNodeB. A PIM cell group consists of two cells sharing an antenna system. This parameter applies only to LTE FDD.
Cell1 Local Cell ID

Indicates the local identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.
Cell2 Local Cell ID

Indicates the local identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.
Cell1 Sector Equipment Identity

Indicates the sector equipment identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.
Cell2 Sector Equipment Identity

Indicates the sector equipment identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.
PIM Mitigation Mode

Indicates the PIM mitigation mode. This parameter applies only to FDD.
Table 3 Dynamic parameters

Parameter

Description
Cell1 PIM State

Indicates the passive intermodulation (PIM) configuration state of cell 1 in the PIM cell group. This parameter applies only to FDD.
Cell2 PIM State

Indicates the passive intermodulation (PIM) configuration status of cell 2 in the PIM cell set. This parameter applies only to FDD.
Cell1 Punctured RB Count

Indicates the number of RBs to be blocked in cell 1. This parameter applies only to FDD.
Cell2 Punctured RB Count

Indicates the number of RBs to be blocked in cell 2. This parameter applies only to FDD.
