CellIntelAmcConfig

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellIntelAmcConfig

Description

The CellIntelAmcConfig MO consists of the parameters related to intelligent AMC.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellCspcPara MO:
    • When the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in the CellIntelAmcConfig MO is selected, the CellCspcSwitch parameter in a CellCspcPara MO must not be set to ON.
  • Relation with the CellDlschAlgo MO:
    • When the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in the CellIntelAmcConfig MO is selected, none of the options of the DlRankDetectSwitch parameter in the CellDlschAlgo MO can be selected.
  • Relation with the CellAlgoSwitch MO:
    • When the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in the CellIntelAmcConfig MO is selected, the EicicSwitch parameter in a CellAlgoSwitch MO must be set to OFF.
    • The DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO can be selected only if CqiAdjAlgoSwitch option of the CqiAdjAlgoSwitch parameter in a CellAlgoSwitch MO is set to ON.
  • Relation with the Cell MO:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO must be deselected under the same cell.
    • When the HighSpeedFlag parameter in a Cell MO is set to HIGH_SPEED, ULTRA_HIGH_SPEED or EXTRA_HIGH_SPEED, the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO must be deselected under the same cell.
    • When the FddTddInd in a Cell MO is set to CELL_FDD, and the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in the CellIntelAmcConfig MO is selected, the CrsPortNum in the Cell MO must be set to CRS_PORT_4.
  • Relation with the CellEmtcAlgo MO:
    • When the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is set to ON, the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO must be deselected under the same cell.
  • Relation with the Cell and CellSiMap MOs:
    • When the FddTddInd parameter in a Cell MO is set to CELL_FDD, and the ForbidCellSiSwitch option of the SiSwitch parameter in a CellSiMap MO is set to ON, the DL_INTEL_AMC_SELECTION_SW option of the IntelligentAmcSwitch parameter in a CellIntelAmcConfig MO must be deselected under the same cell.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell Id

Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.
Intelligent AMC Switch

Indicates whether to enable intelligent MCS selection. DL_INTEL_AMC_SELECTION_SW: Indicates whether to enable downlink intelligent selection. Downlink intelligent selection is enabled only if this option is selected. This parameter applies only to LTE FDD and LTE TDD.
Downlink Prediction Error Upper Limit

Indicates the upper limit on the error of the IBLER predicted for downlink scheduling. When the error of the predicted IBLER exceeds the upper limit, the prediction is recorded as incorrect. This parameter applies only to LTE FDD and LTE TDD.
Downlink Data Collection Interval

Indicates the interval at which data is collected for downlink intelligent AMC model training. This parameter applies only to LTE FDD and LTE TDD.
Downlink Model Min Update Period

Indicates the minimum period of updating the downlink intelligent AMC model. The value 0MIN indicates that the model is updated continuously. This parameter applies only to LTE FDD and LTE TDD.
