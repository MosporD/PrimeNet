CellCsiRsParaCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellCsiRsParaCfg

Description

The CellCsiRsParaCfg MO consists of parameters related to channel state information (CSI) reference signal (RS) configuration.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoSwitch, CellAlgoExtSwitch, SectorSplitCell, and SectorSplitGroup MOs:
    • When CsiRsSwitch in a CellCsiRsParaCfg MO is set to FIXED_CFG or ADAPTIVE_CFG, TM9Switch or TM10Switch of EnhMIMOSwitch, FDDHomNetDlCompSwitch or FDDHetNetDlCompSwitch or Tm9JtSwitch of DlCompSwitch, SfnJtSwitch of SfnAlgoSwitch, or 4TxTM9MuMimoSwitch of EmimoSwitch in the associated CellAlgoSwitch MO must be selected, or Tm9FourLayerPairSwitch of WttxMuMimoSwitch in a CellAlgoExtSwitch MO must be selected, or JOINT_SCHEDULING_SWITCH of IntelligentBeamSchSwitch in SectorSplitGroup MO must be selected.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • If the FddTddInd and MultiRruCellFlag parameters in the Cell MO are set to CELL_TDD and BOOLEAN_TRUE respectively and the CsiRsSwitch parameter in the CellCsiRsParaCfg MO is set to FIXED_CFG or ADAPTIVE_CFG, the MultiRruCellMode parameter in the Cell MO must be set to CELL_COMBINATION, SFN, or MPRU_AGGREGATION.
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD and the MultiRruCellFlag parameter in the same MO is set to BOOLEAN_FALSE, if TM9Switch(TM9Switch) under the EnhMIMOSwitch parameter is selected in the CellAlgoSwitch MO, the CsiRsSwitch parameter in the CellCsiRsParaCfg MO is not set to NOT_CFG, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_8, the TxRxMode parameter in the Cell MO must be set to 8T8R or 32T32R or 64T64R.
    • If the SfnJtSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is selected and the FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_TDD, BOOLEAN_TRUE, and MPRU_AGGREGATION respectively, the SfnUlSchSwitch and SfnDlSchSwitch parameters in the CellAlgoSwitch MO must be set to JOINT, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO must be set to CSI_RS_PORT_4.
  • Relation with the CellAlgoSwitch, CellAlgoExtSwitch, SectorSplitGroup, and SectorSplitCell MOs:
    • When TM9Switch and TM10Switch of EnhMIMOSwitch, FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch and Tm9JtSwitch of DlCompSwitch, and SfnJtSwitch of SfnAlgoSwitch, and 4TxTM9MuMimoSwitch of EmimoSwitch in a CellAlgoSwitch MO, and Tm9FourLayerPairSwitch of WttxMuMimoSwitch in a CellAlgoExtSwitch MO, and JOINT_SCHEDULING_SWITCH of IntelligentBeamSchSwitch in SectorSplitGroup MO are deselected, CsiRsSwitch in the associated CellCsiRsParaCfg MO must be set to NOT_CFG.
  • Relation with the Cell, CellAlgoSwitch, and SectorSplitCell MOs:
    • The TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, no SectorSplitCell MO is configured for the Cell MO, and the CsiRsSwitch parameter in the CellCsiRsParaCfg MO is set to FIXED_CFG or ADAPTIVE_CFG.
  • Relation with the CellDlschAlgo and CellAlgoSwitch MOs:
    • The TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must not be selected if the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_4 and the CsiRsPeriod parameter in the CellCsiRsParaCfg MO is set to ms5, or the UnCfgCsiRsUEDeOrderSchSwitch option of the CsiRsSfSchStrSwitch parameter in the CellDlschAlgo MO is selected, or the UnCfgCsiRsUESchSwitch option of the CsiRsSfSchStrSwitch parameter in the CellDlschAlgo MO is selected.
  • Relation with the CellAlgoSwitch, eUCellSectorEqm, SectorSplitGroup, SectorSplitCell, and Cell MOs:
    • If the CsiRsAdaptBeamCount parameter in the CellCsiRsParaCfg MO is not set to ADAPTIVE_BEAM_DISABLED and cell is active, the following requirements must be met:
    • The JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO corresponding to the Cell MO must be selected, the 8T4PortTM9EnhanceSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must be selected, or the CellBeamMode parameter in the eUCellSectorEqm MO under the Cell MO must be set to MASSIVE_MIMO_Ph2 and the number of SectorSplitCell MO instances under the SectorSplitGroup MO corresponding to the Cell MO is less than or equal to 2 and the TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO must be selected.
  • Relation with the eUCellSectorEqm, SectorEqm, Cell, and CellAlgoSwitch MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD, the MultiRruCellFlag parameter in the same MO is set to BOOLEAN_TRUE, and the MultiRruCellMode parameter in the Cell MO is set to CELL_COMBINATION or SFN, if TM9Switch(TM9Switch) under the EnhMIMOSwitch parameter is selected in the CellAlgoSwitch MO, the CsiRsSwitch parameter in the CellCsiRsParaCfg MO is not set to NOT_CFG, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to 8, the TxRxMode parameter in the Cell MO must be set to 8T8R, and the number of TX antennas (whose TX Antenna Master/Slave Mode is set to MASTER) specified by the SECTOREQMANTENNA parameter in the SECTOREQM MO corresponding to the eUCellSectorEqm MO must not be 4.
  • Relation with the Cell, eUCellSectorEqm, and SectorSplitCell MOs:
    • When the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the CellBeamMode parameter in the eUCellSectorEqm MO associated with the Cell MO is set to MASSIVE_MIMO_Ph2, and there is only one SectorSplitCell MO in the SectorSplitGroup MO to which the Cell MO belongs, the CsiRsPeriod parameter in the CellCsiRsParaCfg MO associated with the Cell MO must not be set to ms80.
  • Relation with the CellEmtcAlgo MO:
    • If the CsiRsSwitch parameter in the CellCsiRsParaCfg MO is set to FIXED_CFG or ADAPTIVE_CFG, the MPDCCH_PDSCH_FREQ_HOPPING_SW option of the EmtcFreqHoppingSwitch parameter in the CellEmtcAlgo MO associated through LocalCellId must not be selected.
  • Relation with the Cell and SpectrumCloud MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, and the CsiRsSwitch parameter in the CellCsiRsParaCfg MO under this Cell MO is set to a value other than NOT_CFG, the CsiRsPeriod parameter in the CellCsiRsParaCfg MO cannot be set to ms5.
  • Relation with the CellAlgoSwitch, Cell, and CellBf MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the cell is activated, the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_8, then the PdschSplitBeamConfigIndex parameter in the CellBf MO must be set to CONFIG_INDEX4.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the cell is activated, the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, and the PdschSplitBeamConfigIndex parameter in the CellBf MO is set to CONFIG_INDEX4, then the CsiRsPortNum parameter in the CellCsiRsParaCfg MO must be set to CSI_RS_PORT_8.
  • Relation with the CellAlgoSwitch MO:
    • If the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_8 and the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, the TM9SplitSdmaSwitch option of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO must be deselected.
  • Relation with the SectorSplitCell and SectorSplitGroup MOs:
    • If the ENH_JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, the CsiRsAdaptBeamCount parameter in the CellCsiRsParaCfg MOs that correspond to all the SectorSplitCell MOs under this SectorSplitGroup MO must be set to CSI_RS_BEAM_6, CSI_RS_BEAM_7, CSI_RS_BEAM_8, CSI_RS_BEAM_9, CSI_RS_BEAM_10, or ADAPTIVE_BEAM_DISABLED.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Switch

Indicates whether to configure CSI-RSs for UEs. If this parameter is set to NOT_CFG(Not configure), the eNodeB does not configure CSI-RSs for UEs. If this parameter is set to FIXED_CFG(Fixed configure), the eNodeB configures CSI-RSs for UEs that support CSI-RSs. If this parameter is set to ADAPTIVE_CFG(ADAPTIVE_CFG), the eNodeB determines whether to configure CSI-RSs for UEs that support CSI-RSs based on the proportion of TM9 UEs. When SfnLoadBasedAdptSwitch is deselected in a TDD cell with adaptive SFN enabled, neither FIXED_CFG nor ADAPTIVE_CFG takes effect. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Period

Indicates the channel state information (CSI) reference signal (RS) measurement period. This parameter does not take effect if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_8. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Config User Number Threshold

Indicates the threshold, which is the number of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state when adaptive CSI-RS configuration is used. The number must be equal to or larger than this threshold for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Unconfig User Number Threshold

Indicates the threshold, which is the number of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state when adaptive CSI-RS configuration is adopted. The number must be smaller than this threshold for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Config User Ratio Threshold

Indicates the threshold, which is the proportion of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state when adaptive CSI-RS configuration is adopted. The proportion must be equal to or larger than this threshold for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Unconfig User Ratio Threshold

Indicates the threshold, which is the proportion of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state when adaptive CSI-RS configuration is adopted. The proportion must be equal to or smaller than this threshold for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Set Judge Hysteresis Timer

Indicates whether to trigger the hysteresis timer for a switch to the CSI-RS unconfigured state for UEs in the CSI-RS state when adaptive CSI-RS configuration is adopted. The timer is triggered when a UE enters the CSI-RS configured state and the decision mechanism for a switch to the CSI-RS unconfigured state is triggered after the timer expires. This parameter applies only to LTE FDD and LTE TDD.
CSI-RS Set Judge Timer

Indicates the length of the timer for determining a switch between the CSI-RS unconfigured state and the CSI-RS configured state when adaptive CSI-RS configuration is adopted. This parameter applies only to LTE FDD and LTE TDD.
CsiRs Port Number

Indicates the number of CSI-RS ports. This parameter applies only to LTE TDD.
CSI-RS Adaptive Beam Count

Indicates the number of CSI-RS beams during CSI-RS beam adaptation. If this parameter is set to ADAPTIVE_BEAM_DISABLED, CSI-RS beam adaptation is disabled. If this parameter is set to a value other than ADAPTIVE_BEAM_DISABLED, the number in the value indicates the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation. For example, if this parameter is set to CSI_RS_BEAM_5, the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation is 5. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
CsiRs State

Indicates whether the CSI-RS is configured. This parameter applies only to LTE FDD and LTE TDD.
