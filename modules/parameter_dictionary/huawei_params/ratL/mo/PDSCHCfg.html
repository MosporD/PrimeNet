PDSCHCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-PDSCHCfg

Description

The PDSCHCfg MO consists of the parameters used to configure the PDSCH in a cell.

The PDSCH carries the following channels:

Downlink shared channel (DL-SCH)

Paging channel (PCH)

Effective Scenario

Immediately

Use this command to query the power configurations of a specified or all massive MIMO cells, including the reference signal power (ReferenceSignalPwr), PA for even PDSCH power distribution (PaPcOff), PB, and cell beam power. The displayed values of the reference signal power, PA for even PDSCH power distribution, and PB are the values that actually take effect in the massive MIMO cell. This command applies only to LTE FDD.
LST PDSCHCFG

Use this command to list the PDSCH configuration.
MOD PDSCHCFG

Use this command to modify the PDSCH configuration.

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.
Reference signal power

Indicates the cell reference signal power of each physical antenna (the precision of converting dBm to mW is 0.01 mW). If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of this parameter is changed, the eNodeB will proactively release eMTC UEs that have already accessed the cell. For FDD 8T8R and 32T32R cells, this parameter indicates the cell reference signal power of each logical antenna.
PB

Indicates the scaling factor index of the Energy Per Resource Element (EPRE) on the PDSCH. This scaling factor is determined by the value of this parameter and the antenna port. For details, see 3GPP TS 36.213. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of this parameter is changed, eMTC UEs that already accessed the cell will be proactively released.
Reference Signal Power Margin

Indicates the cell reference signal power headroom of each physical antenna. This parameter applies only to LTE TDD.

TX Channel Power Config Switch

Indicates whether to enable algorithms related to transmit channel power configurations.

SINGLE_CA_PWR_SHARE_SW_FOR_4T: Indicates whether to enable single carrier power sharing for 4T. This option applies only to LTE FDD.
Cell Power Limit

Indicates the maximum transmit power of a single channel for a cell. If this parameter is set to 0, the maximum transmit power of a single channel for the cell is not limited. If this parameter is set to a value other than 0, the maximum transmit power of a single channel for the cell is limited. In this case, the eNodeB controls the number of scheduling resources to ensure that the power of a single channel does not exceed the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
EMF Power Limit Switch

Indicates whether to enable the on-demand TX power allocation under EME. If this parameter is set to ON, the maximum transmit power of a cell is limited by an EME policy. In this case, the eNodeB controls scheduling resources to ensure that the cell power does not exceed the preset limit. This parameter applies only to LTE FDD and LTE TDD.
CRS Power Boosting Amplitude

Indicates the amount of increase in cell-specific reference signal (CRS) power.

If this parameter is set to DB_0, the CRS power will not increase.

If this parameter is set to DB_1DOT77, the CRS power will increase by 1.77 dB.

If this parameter is set to DB_3, the CRS power will increase by 3 dB.

This parameter applies only to LTE FDD.
Logical Port Swap Switch

Indicates whether to change the mapping between logical antenna ports and physical channels.

If this parameter is set to OFF, the mapping between logical antenna ports and physical channels, which is specified by the CrsPortMap parameter in the Cell MO, cannot be changed.

If this parameter is set to SWAP_MODE_1, the physical TX channels corresponding to logical antenna ports 0 and 2 are swapped, and the physical TX channels corresponding to logical antenna ports 1 and 3 are swapped.

This parameter applies only to logical cells configured with four logical CRS ports. This parameter applies only to LTE FDD.
PDSCH Power Boosting Switch

Indicates whether to enable PDSCH power boosting. If this parameter is set to ON, PDSCH power boosting for TM9 UEs will be enabled. If this parameter is set to OFF, PDSCH power boosting will not be enabled. This parameter applies only to LTE FDD.
