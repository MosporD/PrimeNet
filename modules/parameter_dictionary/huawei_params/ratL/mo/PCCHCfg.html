PCCHCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-PCCHCfg

Description

The PCCHCfg MO consists of the parameters used to configure the Paging Control Channel (PCCH) in a cell.

The PCCH is a downlink logical channel that transmits paging messages and system information modification indicators.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the BcchCfg MO:
    • The product of DefaultPagingCycle in the PCCHCfg MO and ModifyPeriodCoeff in the BcchCfg MO cannot exceed 1024 radio frames, that is 10, 240 milliseconds.
  • Relation with the Cell MO:
    • When the NbCellFlag in a Cell MO is set to FALSE, if DlBandWidth in a Cell MO is set to CELL_BW_N6, CELL_BW_N15, or CELL_BW_N25, ENHNCD_HIGH_PRI_PAGING_SWITCH and ENHNCD_CSFB_PAGING_SWITCH of EnhPagingSwitch in the associated PCCHCfg MO must be set off.
    • When the NbCellFlag parameter in a Cell MO is set to FALSE, values of the DefaultPagingCycleForNb and NbForNbIoT parameters in the associated PCCHCfg MO cannot be changed and are always rf256(256 radio frames) and ONE_64TH_T(ONE_64TH_T), respectively.
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, values of the DefaultPagingCycle, Nb, PagingSentNum, and MaxPagingRecordsNum parameters in the associated PCCHCfg MO cannot be changed and are always rf128(128 radio frames), ONET, 1, and 16, respectively.
    • If the PagingStrategy parameter in the PCCHCfg MO is set to DIFFERENTIATION_BY_NB_COV_LVL, the NbCellFlag parameter in the Cell MO must be set to TRUE.
  • Relation with the CellDlschAlgo MO:
    • If ENHNCD_HIGH_PRI_PAGING_SWITCH or ENHNCD_CSFB_PAGING_SWITCH of EnhPagingSwitch in the PCCHCfg MO is set on, EnhPagingCR in the PCCHCfg must be set to a value less than or equal to the value of RarAndPagingCR in the CellDlschAlgo MO.
  • Relation with the Cell and BcchCfg MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, the value of the ModifyPeriodCoeffForNb parameter in the BcchCfg MO multiplied by the value of the DefaultPagingCycleForNb parameter in the PCCHCfg MO must be an integer multiple of 40.96 seconds.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.
Default paging cycle

Indicates the default paging period for the cell. It is also called the default discontinuous reception (DRX) period. If the EPC specifies a DRX period for a UE, the UE compares this period with the value of this parameter and uses the smaller one as its DRX period. If the EPC does not specify a DRX period, the UE uses the value of this parameter, which is delivered in the system information, as its DRX period. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
NB

Indicates the number of paging occasions (a type of subframe) within a paging period. This parameter value also indicates the number of paging groups within a paging period. For details, see 3GPP TS 36.304.
Paging Sent Number

Indicates the number of paging messages transmitted to UEs over the air interface. This parameter applies only to LTE FDD and LTE TDD.
Maximum Number of Paging Records

Indicates the maximum number of UEs that can be included in a paging message on each paging occasion. This parameter applies only to LTE FDD and LTE TDD.
Paging Message Sending Strategy

Indicates the policy of sending paging messages. There are three policies: first in first out (FIFO), priority-based, and coverage-level-based.

If the FIFO policy is used, paging messages that arrive earlier are preferentially transmitted on a paging occasion.

If the priority-based policy is used, high-priority paging messages are preferentially transmitted on a paging occasion.

If the coverage-level-based policy is used, different priorities are assigned to NB-IoT paging messages intended for UEs at different coverage levels and paging messages are transmitted based on the assigned priorities on a paging occasion. The coverage-level-based policy applies only to NB-IoT.
Enhanced Paging Code Rate

Indicates the code rate used for paging messages when enhanced paging is enabled. An eNodeB identifies high-priority paging and CSFB-triggered paging and uses the code rate specified by this parameter to send high-priority paging messages and CSFB-triggered paging messages. If a paging message sent from the EPC contains the Paging Priority field, the paging is high-priority paging. This parameter applies only to LTE FDD and LTE TDD.
Enhanced Paging Switch

Indicates whether to enable enhanced paging. This parameter applies only to cells with a 10 MHz bandwidth or higher.

ENHNCD_HIGH_PRI_PAGING_SWITCH: If this option is selected, enhanced paging is enabled for high-priority paging and high-priority paging messages are transmitted at the code rate specified by the EnhPagingCR parameter in the PCCHCfg MO. If this option is deselected, high-priority paging messages are transmitted at the code rate specified by the RarAndPagingCR parameter in the CellDlschAlgo MO. This option applies only to LTE FDD and LTE TDD.

ENHNCD_CSFB_PAGING_SWITCH: If this option is selected, enhanced paging is enabled for CSFB-triggered paging and CSFB-triggered paging messages are transmitted at the code rate specified by the EnhPagingCR parameter in the PCCHCfg MO. If this option is deselected, CSFB-triggered paging messages are transmitted at the code rate specified by the RarAndPagingCR parameter in the CellDlschAlgo MO. This option applies only to LTE FDD and LTE TDD.
NB-IoT Default Paging Cycle

Indicates the default paging period for the cell. It is also called the default discontinuous reception (DRX) period. For details, see 3GPP TS 36.304. This parameter applies only to NB-IoT.
NB-IoT nB

Indicates the number of paging occasions (a type of subframe) of an NB-IoT cell within a paging period. This parameter value also indicates the number of paging groups within a paging period. For details, see 3GPP TS 36.304. This parameter is correlated with the repetition count of initial PDCCH transmission and the repetition count needs to be considered when this parameter is set. This parameter applies only to NB-IoT.
Paging Timeout Discard Timer

Indicates the length of the paging message discarding timer. If this parameter is set to 0, the timer does not take effect. If this parameter is set to a non-zero value, the timer takes effect. The eNodeB discards paging messages not yet sent and measures the number of discarded paging messages when this timer expires. If this timer is required, it is recommended that this parameter be set to a value at least greater than a paging cycle but less than the MME paging retransmission interval. This parameter applies only to LTE FDD and LTE TDD.
Default Coverage Level of NB-IoT Paging

Indicates the default coverage level for paging messages. Paging messages in which coverage level information is not included by the core network are scheduled based on the coverage level specified by this parameter. This parameter applies only to NB-IoT.
eMTC Default Paging Cycle

Indicates the default paging cycle for eMTC. It is also called the DRX cycle. If the EPC delivers a DRX cycle, the eNodeB compares the cycle specified by this parameter with that delivered by the EPC and uses the smaller cycle for eMTC UEs. If the EPC does not deliver a DRX cycle, the eNodeB sends the cycle specified by this parameter to eMTC UEs through system information.

Note: In accordance with 3GPP specifications, the product of the value of this parameter and that of the PagingGroupNum parameter must be greater than or equal to 1. Otherwise, the network cannot perform paging normally. As a result, UEs cannot receive paging messages. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
Max Paging Queue Buffer Length

Indicates the maximum buffer length of a single paging queue.

If this parameter is set to a value in the range of 0 to 299, the maximum buffer length of a single paging queue is not controlled. If this parameter is set to another value, the maximum buffer length of a single paging queue is controlled. When the number of buffered paging messages in a paging queue reaches this value, subsequent paging messages that need to enter this paging queue will be discarded. To prevent paging message congestion in a single paging queue from occupying excessive paging buffer resources and affecting the paging success rates of other paging queues, you are advised to set this parameter to 1000. This parameter applies only to LTE FDD and LTE TDD.
