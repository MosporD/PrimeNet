NCellParaCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-NCellParaCfg

Description

An NCellParaCfg MO consists of parameters related to neighboring cell management, including parameters used to configure conditions for determining whether a neighboring cell is an over-distant neighboring cell and ANR optimization.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Table 1 Related MML commands

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.
Rat Type

Indicates the RAT of neighboring cells for management. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Distance Threshold

Indicates the distance threshold for over-distant neighboring cell detection. If this parameter is set to a value other than 0, the eNodeB detects over-distant neighboring cells based on the distance. If the distance between the serving cell and a neighboring cell is greater than this threshold, the neighboring cell is an over-distant neighboring cell. If this parameter is set to 0, the eNodeB detects over-distant neighboring E-UTRAN cells based on the access radius but does not detect over-distant neighboring UTRAN cells. If the distance between the serving cell and a neighboring E-UTRAN cell is greater than the sum of access radii of both cells, this neighboring cell is an over-distant neighboring cell. This parameter is valid only when RatType is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.
Handover Statistic Threshold

Indicates the threshold, which is the number of handovers, used for over-distant neighboring cell detection. If the number of handovers to a neighboring cell reaches this threshold and the handover success rate reaches the related threshold within a measurement period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. This parameter is valid only when the RatType parameter is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.
Handover Success Rat Threshold

Indicates the threshold, which is a handover success rate, used for over-distant neighboring cell detection. If the number of handovers to a neighboring cell reaches the related threshold and the handover success rate reaches the threshold specified by this parameter within a measurement period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. This parameter is valid only when the RatType parameter is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.
Neighbouring Cell Number for ANR

Indicates the threshold of the number of intra-RAT intra-frequency neighboring cells used in the automatic neighbor relationship removal function of ANR. The value 0 indicates no requirement for the minimum number of neighboring cells on the serving frequency. This parameter applies only to LTE FDD and LTE TDD.
Cell ANR Optimization Mode

Indicates whether to report neighbor relationships of the local cell with cells in different RATs when the OptMode parameter in the ANR MO is set to CONTROLLED. The RAT of a neighboring cell is specified by the RatType parameter in the NCellParaCfg MO. If this parameter is set to CONTROLLED, the eNodeB reports the neighbor relationships with cells in the specified RAT to the MAE. These neighbor relationships will be updated only if they are manually confirmed on the MAE. If this parameter is set to FREE, the eNodeB automatically handles the neighbor relationships with cells in the specified RAT, except the blacklisted neighbor relationships with E-UTRAN and UTRAN cells. This parameter applies only to LTE FDD and LTE TDD.
