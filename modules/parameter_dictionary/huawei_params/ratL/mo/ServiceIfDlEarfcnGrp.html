ServiceIfDlEarfcnGrp

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-ServiceIfHoCfgGroup
        +-ServiceIfDlEarfcnGrp

Description

A ServiceIfDlEarfcnGrp MO is used for adding a group of DL EARFCNs to a service-based inter-frequency handover policy group.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    ServiceIfHoCfgGroup
  • Relation with the ServiceIfHoCfgGroup and EutranInterNFreq MOs:
    • DlEarfcn must have been set in the associated EutranInterNFreq MO when the ServiceIfDlEarfcnGrp MO associated ServiceIfHoCfgGroup's InterFreqHoState is PERMIT_HO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SERVICEIFDLEARFCNGRP

Use this command to add a group of DL EARFCNs to service-based inter-frequency handover policy group.
LST SERVICEIFDLEARFCNGRP

Use this command to list a DL EARFCN group for service-based inter-frequency handover.
MOD SERVICEIFDLEARFCNGRP

Use this command to modify a DL EARFCN group for service-based inter-frequency handover.
RMV SERVICEIFDLEARFCNGRP

Use this command to remove a DL EARFCN group for service-based inter-frequency handover.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.
Service Interfreq Ho Policy Group Id

Indicates the ID of the service-based inter-frequency handover policy group. This parameter applies only to LTE FDD and LTE TDD.
Downlink EARFCN Index

Indicates the index of a DL EARFCN in a DL EARFCN group for service-based inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
Downlink EARFCN

Indicates a DL EARFCN for service-based inter-frequency handover. Only the value with DlEarfcnIndex 0 in the DL EARFCN group is valid for LTE FDD cells when ServiceHoMultiTargetFreqSw is set to OFF(Off). All values of this parameter are valid for LTE TDD cells when ServiceHoMultiTargetFreqSw is set to ON(On). This parameter applies only to LTE FDD and LTE TDD.
Service Handover Frequency Priority

Indicates the priority for the frequency to be the target frequency for service-based and service-request-based inter-frequency handovers. A larger value indicates a higher priority. When setting measurement configurations for service-based and service-request-based inter-frequency handovers, the eNodeB selects the neighboring E-UTRA frequencies in descending order of priority. This parameter applies only to LTE FDD and LTE TDD.
