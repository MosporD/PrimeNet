CellPrsCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellPrsCfg

Description

The CellPrsCfg MO consists of the parameters related to positioning reference signal (PRS).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • When the NbCellFlag in a Cell MO is set to FALSE, if FddTddInd in a Cell MO is set to CELL_FDD, the value of PrsBandwidth cannot exceed the value of DlBandWidth.
  • Relation with the Cell and CellMBMSCfg MOs:
    • If FddTddInd in a Cell MO is set to CELL_FDD and the MBMSSwitch option of MBMSSwitch is selected, the last digit of the value of PrsConfigurationIndex must be 0, 4, 5, or 9.
    • If FddTddInd in a Cell MO is set to CELL_FDD and the MBMSSwitch option of MBMSSwitch is selected, NumberofDlFramesforPrs must be set to SF1 or SF2 when the last digit of the value of PrsConfigurationIndex is 4 or 9, or NumberofDlFramesforPrs must be set to SF1 when the last digit of the value of PrsConfigurationIndex is 0 or 5.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLPRSCFG

Use this command to add a cell-specific PRS configuration.
LST CELLPRSCFG

Use this command to list the PRS configuration in a cell.
MOD CELLPRSCFG

Use this command to modify the PRS configuration of a cell.
RMV CELLPRSCFG

Use this command to remove a cell PRS configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
PRS Bandwidth

Indicates the transmission bandwidth of PRS. This parameter corresponds to the PRS Bandwidth parameter defined in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.
PRS Configuration Index

Indicates the PRS period and the start subframe. This parameter corresponds to the PRS Configuration Index parameter defined in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.
Number of DL Frames for PRS

Indicates the number of consecutive downlink subframes for PRSs. This parameter corresponds to the Number of DL Frames parameter specified in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.
Num of PRS Muting Bit

Indicates the number of PRS muting bits in the cell. This parameter applies only to LTE FDD and LTE TDD.
PRS Muting Configuration

Indicates the PRS muting configuration. See 3GPP TS 36.455 to learn details about this parameter. The value range of this parameter is determined by the value of the NumofPRSMutingBit parameter. The NumofPRSMutingBit values 2_BITS, 4_BITS, 8_BITS, and 16_BITS indicate that the value ranges of PrsMutingConfiguration are 0-3, 0-15, 0-255, and 0-65535, respectively. This parameter applies only to LTE FDD and LTE TDD.
