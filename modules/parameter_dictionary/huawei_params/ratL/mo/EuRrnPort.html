EuRrnPort

+-NE
  +-eNodeBFunction
    +-EuSubscriber
      +-EuRrn
        +-EuRrnPort

Description

An EuRrnPort MO consists of parameters related to the transmission port on the RRN. It is used to configure status-related parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EuRrn

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST EURRNPORT

Use this command to list the RRN port configuration.
MOD EURRNPORT

Use this command to modify the RRN port configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Port No.

Indicates the transmission port number on the RRN. This parameter applies only to LTE FDD and LTE TDD.
Port Switch

Indicates the switch controlling the transmission port on the RRN. This parameter applies only to LTE FDD and LTE TDD.
