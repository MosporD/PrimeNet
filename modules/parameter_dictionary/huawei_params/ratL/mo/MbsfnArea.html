MbsfnArea

+-NE
  +-eNodeBFunction
    +-Mce
      +-MbsfnArea
        +-MbsfnAreaCell[0~144]
        +-MbsfnSubframe[0~8]
        +-Mcch[1~1]
        +-Pmch[0~15]

Description

The MbsfnArea MO includes the parameters used to configure MBSFN areas to support distributed MCEs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Mce

  • Possible children:

    MbsfnAreaCell[0~144];MbsfnSubframe[0~8];Mcch[1~1];Pmch[0~15]
  • Relation with the MbsfnSubframe MO:
    • The value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO must be greater than or equal to the value of the RadioFrameAllocPrd parameter in the MbsfnSubframe MO.
  • Relation with the Pmch MO:
    • The value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO must be less than or equal to the value of the MchSchedulingPeriod parameter in the Pmch MO.
    • If the FddTddInd parameter in the MbsfnArea MO is set to CELL_FDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 6. If the FddTddInd parameter in the MbsfnArea MO is set to CELL_TDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 5.
    • If the FddTddInd parameter in the MbsfnArea MO is set to CELL_FDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 6. If the FddTddInd parameter in the MbsfnArea MO is set to CELL_TDD, the value of the AllocationEndSubframe parameter in the Pmch MO must be less than or equal to the value of the CommonSubframeAllocPeriod parameter in the MbsfnArea MO multiplied by 5.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Area ID

Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.
FDD TDD Indication

Indicates the duplex mode of the cells in an MBSFN area. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode. All the cells in an MBSFN area must work in the same duplex mode. This parameter applies only to LTE FDD and LTE TDD.
Downlink Bandwidth

Indicates the downlink bandwidth of the cells in an MBSFN area. The bandwidth is represented by the number of RBs. For example, the value CELL_BW_N25 indicates a bandwidth of 25 RBs, and the value CELL_BW_N50 indicates a bandwidth of 50 RBs. For details, see 3GPP TS 36.104. All the cells in an MBSFN area must have the same downlink bandwidth. This parameter applies only to LTE FDD and LTE TDD.
Common Subframe Allocation Period

Indicates the MBSFN subframe allocation period. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Uplink-Downlink Subframe Configuration

Indicates the uplink-downlink subframe configuration for LTE TDD cells in an MBSFN area. For details, see 3GPP TS 36.211. All cells in an MBSFN area must use the same uplink-downlink subframe configuration. This parameter applies only to LTE TDD.
