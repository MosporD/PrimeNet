CnOpQciEventParam

+-NE
  +-eNodeBFunction
    +-CnOpQciEventParam

Description

A CnOpQciEventParam MO consists of QCI-specific event-related threshold and offset parameters of an operator. The threshold offset configured in this MO is valid only if the FLEXIBLE_SHARING_SWITCH option of the CellAlgoExtSwitch.OperatorFunSwitch parameter is selected.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.
QoS Class Indication

Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. The value of this parameter is invalid only when this parameter is set to 255 and the CnOpQciEventParam.EventType parameter is set to a value indicating event A1, A2, or A4 related to frequency-priority-based inter-frequency handovers. In this case, separate offsets are not specified on a per QCI basis. This parameter applies only to LTE FDD and LTE TDD.
Event Type

Indicates the type of an event related to a handover. The value INTER_FREQ_HO_A1 indicates event A1 related to coverage-based inter-frequency handovers. The value INTER_FREQ_HO_A3 indicates event A3 related to coverage-based inter-frequency handovers. The value INTER_FREQ_HO_A4 indicates event A4 related to coverage-based inter-frequency handovers. The value HO_TO_UTRAN_B1 indicates event B1 related to coverage-based handovers to UTRAN. FREQ_PRI_INTER_FREQ_HO_A1 indicates event A1 related to frequency-priority-based inter-frequency handovers. FREQ_PRI_INTER_FREQ_HO_A2 indicates event A2 related to frequency-priority-based inter-frequency handovers. FREQ_PRI_INTER_FREQ_HO_A4 indicates event A4 related to frequency-priority-based inter-frequency handovers. This parameter applies only to LTE FDD and LTE TDD.
Handover Threshold Offset

Indicates the offset relative to the QCI-specific RSRP or RSCP threshold for a specific handover-related event of a specific operator. If this parameter is set to 0, the event threshold for handovers is configured regardless of the PLMN and QCI. This parameter applies only to LTE FDD and LTE TDD.
