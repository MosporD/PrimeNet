CellCeCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellCeCfg

Description

A CellCeCfg MO consists of parameters related to cell coverage enhancement mode.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CeRachCfg MO:
    • Under the same cell, the sum of the PreambleRatio parameter values in the CeRachCfg MO corresponding to the coverage levels specified by the CoverageLevel parameter in the CellCeCfg MO must not exceed 100.
    • Under the same cell, the value of the PreambleRatio parameter in the CeRachCfg MO corresponding to the coverage levels specified by the CoverageLevel parameter in the CellCeCfg MO must not be 0.
  • Relation with the CellEmtcAlgo, Cell, and CellCeSchCfg MOs:
    • Under the same cell, the SIB1RepNum parameter in the CellCeSchCfg MO corresponding to the CoverageLevel parameter in the CellCeCfg MO must be set to SIB1_NUM_R4(SIB1_NUM_R4) when the following conditions are true: The FddTddInd and UlBandWidth or DlBandWidth parameters in the Cell MO are set to CELL_FDD(FDD) and CELL_BW_N6(1.4M) or CELL_BW_N15(3M), respectively; the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is selected.
  • Relation with the CellEmtcAlgo MO:
    • If the MPDCCH_PDSCH_FREQ_HOPPING_SW option of the EmtcFreqHoppingSwitch parameter in the CellEmtcAlgo MO is selected, and the CoverageLevel parameter in the CellCeCfg MO is set to COVERAGE_LEVEL_2 or COVERAGE_LEVEL_3, the EmtcDlFreqHoppingInterval parameter in the CellEmtcAlgo MO associated through LocalCellId must not be set to INTERVAL1.
    • If the PRACH_FREQ_HOPPING_SW or PUSCH_FREQ_HOPPING_SW option of the EmtcFreqHoppingSwitch parameter in the CellEmtcAlgo MO is selected, and the CoverageLevel parameter in the CellCeCfg MO is set to COVERAGE_LEVEL_2 or COVERAGE_LEVEL_3, the EmtcUlFreqHoppingInterval parameter in the CellEmtcAlgo MO associated through LocalCellId must not be set to INTERVAL1.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Coverage Level

Indicates the cell coverage level. A maximum of four levels are supported, corresponding to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancements. When this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, and COVERAGE_LEVEL_3, the maximum coverage level supported by the cell is coverage level 0, coverage level 1, coverage level 2, and coverage level 3, respectively. If the value of this parameter is changed, the value of the SIB1RepNum parameter or SiTransEcr parameter may be changed, which causes eMTC UEs that already accessed the cell to be proactively released. This parameter applies only to LTE FDD and LTE TDD.
RACH RSRP First Threshold

Indicates the RSRP level-1 threshold. When the measured RSRP value of a UE is higher than the RSRP level-1 threshold, the UE initiates random access in the cell at coverage level 0. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, or COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.
RACH RSRP Second Threshold

Indicates the RSRP level-2 threshold. When the measured RSRP value of a UE is between the RSRP level-1 threshold and RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 1. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_2 or COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.
RACH RSRP Third Threshold

Indicates the RSRP level-3 threshold. When the measured RSRP value of a UE is between the RSRP level-2 threshold and RSRP level-3 threshold, the UE initiates random access in the cell at coverage level 2. When the measured RSRP value of a UE is lower than the RSRP level-3 threshold, the UE initiates random access in the cell at coverage level 3. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.
