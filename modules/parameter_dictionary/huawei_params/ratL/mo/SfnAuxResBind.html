SfnAuxResBind

+-NE
  +-eNodeBFunction
    +-SfnAuxResBind

Description

The SFNAUXRESBIND MO consists of parameters used to configure auxiliary eNodeB resource binding relationships.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell MO:
    • A maximum of six SfnAuxResBind MOs and SfnAuxResGrpBind MOs can be configured when the same main eNodeB local cell ID and the same main eNodeB ID are configured in these MOs.
    • A maximum of six SfnAuxResGrpBind MOs and SfnAuxResBind MOs can be configured when the same main eNodeB local cell ID and the same main eNodeB ID are configured in these MOs.
  • Relation with the eNodeBFunction and SfnAuxResGrpBind MOs:
    • A total of 24 SfnAuxResBind and SfnAuxResGrpBind MOs with eNodeBId and eNodeBId set to different values can be configured.
  • Relation with the eNodeBFunction MO:
    • eNodeBId in the SfnAuxResBind MO must be different from eNodeBId in the eNodeBFunction MO.
  • Relation with the SECTOREQM, RRU, RRUCHAIN, and BBP MOs:
    • In the SfnAuxResBind MO, if CPRIEX in the BBP MO corresponding to the RRU MO that serves the SECTOREQM MO is set to ON, SectorCpriCompression must be set to NULL or NORMAL_COMPRESSION.
  • Relation with the Cell, eNodeBFunction, eUCellSectorEqm, EuSectorEqmGroup, SfnAuxResGrpBind, EuPrbSectorEqm, MPT, Node, eNodeBResModeAlgo, and EuPrbSectorEqmGroup MOs:
    • The sum of the numbers of the following MO instances must meet a certain requirement: Cell MO instances in which MultiRruCellFlag and EuCellStandbyMode are set to BOOLEAN_FALSE and ACTIVE, respectively; Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and TWO_RRU_COMBINATION (or DIGITAL_COMBINATION), respectively; EuSectorEqmGroup and EuPrbSectorEqmGroup MO instances corresponding to the Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively; eUCellSectorEqm and eUPrbSectorEqm MO instances of other cells; SfnAuxResBind and SfnAuxResGrpBind MO instances. The requirement varies as follows: (1) The sum is less than or equal to 216 if UMPT boards are configured in the MPT MO and the conditions listed in (2) to (9) are not met. (2) The sum is less than or equal to 144 if one UMPT board is configured in the MPT MO, the BRDSPEC of the UMPT is UMPTe or UMPTg, and the conditions listed in (3) to (9) are not met. (3) The sum is less than or equal to 72 if UMPT boards are configured in the MPT MO, WM in the NODE MO is set to CONCURRENT, and the conditions listed in (4) to (9) are not met. (4) The sum is less than or equal to 72 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTga. (5) The sum is less than or equal to 36 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTa, UMPTb, or UMPTa/b. (6) The sum is less than or equal to 36 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTa, UMPTb, or UMPTa/b, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (7) The sum is less than or equal to 72 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (8) The sum is less than or equal to 144 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to ENHANCED_MODE. (9) The sum is less than or equal to 18 if no UMPT board is configured in the MPT MO.
  • Relation with the Cell, eNodeBFunction, SfnAuxResGrpBind, eNodeBResModeAlgo, Node, and MPT MOs:
    • The sum of the number of Cell MO instances in which EuCellStandbyMode is set to ACTIVE and the number of SfnAuxResBind and SfnAuxResGrpBind MO instances in which both Main eNodeB ID and Main eNodeB Local cell ID are set to different values must meet one of the following requirements: (1) The sum is less than or equal to 216 if UMPT boards are configured in the MPT MO and the conditions listed in (2) to (9) are not met. (2) The sum is less than or equal to 144 if one UMPT board is configured in the MPT MO, the BRDSPEC of the UMPT is UMPTe or UMPTg, and the conditions listed in (3) to (9) are not met. (3) The sum is less than or equal to 72 if UMPT boards are configured in the MPT MO, WM in the NODE MO is set to CONCURRENT, and the conditions listed in (4) to (9) are not met. (4) The sum is less than or equal to 72 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTga. (5) The sum is less than or equal to 36 if one UMPT is configured in the MPT MO and the BRDSPEC of the UMPT is UMPTa, UMPTb, or UMPTa/b. (6) The sum is less than or equal to 36 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTa, UMPTb, or UMPTa/b, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (7) The sum is less than or equal to 72 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to NORMAL_MODE. (8) The sum is less than or equal to 144 if two UMPT boards are configured in the MPT MO, the BRDSPEC of both UMPT boards is UMPTga, and eNBCellNumCapabilityMode in the eNodeBResModeAlgo MO is set to ENHANCED_MODE. (9) The sum is less than or equal to 18 if no UMPT board is configured in the MPT MO.
  • Relation with the SECTOREQM MO:
    • ANTCFGMODE cannot be set to BEAM in the SECTOREQM MO associated with SectorEqmId in an SfnAuxResBind MO.
    • When the CellBeamMode parameter in an SfnAuxResBind MO is set to ADVANCED_BEAMFORMING, the ANTCFGMODE parameter in the SECTOREQM MO must be set to BEAM.
  • Relation with the SECTOREQM and eUCellSectorEqm MOs:
    • If the ANTCFGMODE in a SECTOREQM MO is set to BEAM, the CellBeamMode parameters must be set consistently in all eUCellSectorEqm MO instances corresponding to the SECTOREQM MO. In addition, these CellBeamMode parameters must be set consistently with the CellBeamMode parameters in all SfnAuxResBind MO instances corresponding to the SECTOREQM MO.
  • Relation with the eUCellSectorEqm, CoProcRes, EuSectorEqmGroup, EuCellPriBBEqm, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected and the BASEBAND_PROCESSING option of this parameter is deselected, the BaseBandEqmId parameter in the CoProcRes MO must not equal the BaseBandEqmId parameter in the eUCellSectorEqm MO, the BaseBandEqmId parameter in the EuSectorEqmGroup MO, the PriBaseBandEqmId parameter in the EuCellPriBBEqm MO, the BaseBandEqmId parameter in the SfnAuxResBind MO, the BasebandEqmId parameter in the EuPrbSectorEqm MO, and the BasebandEqmId parameter in the EuPrbSectorEqmGroup MO.
  • Relation with the Cell, eNodeBFunction, eUCellSectorEqm, EuSectorEqmGroup, SfnAuxResGrpBind, EuPrbSectorEqm, MPT, Node, EuPrbSectorEqmGroup, and eNodeBResModeAlgo MOs:
    • When UMPT is configured in an MPT MO and WM in the corresponding NODE MO is set to CONCURRENT, the sum of the numbers of the following MO instances must meet a certain requirement: Cell MO instances in which MultiRruCellFlag and EuCellStandbyMode are set to BOOLEAN_FALSE and ACTIVE, respectively; Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and TWO_RRU_COMBINATION (or DIGITAL_COMBINATION), respectively; EuSectorEqmGroup and EuPrbSectorEqmGroup MO instances corresponding to the Cell MO instances in which MultiRruCellFlag and MultiRruCellMode are set to BOOLEAN_TRUE and MPRU_AGGREGATION, respectively; eUCellSectorEqm and EuPrbSectorEqm MO instances of other cells; SfnAuxResBind and SfnAuxResGrpBind MO instances. The requirement varies as follows: (1) The sum must be less than or equal to 36 if the value of BRDSPEC for the UMPT configured in the MPT MO is UMPTa, UMPTb, or UMPTa/b. (2) The sum must be less than or equal to 72 in other scenarios.
  • Relation with the Cell, eNodeBFunction, SfnAuxResGrpBind, Node, MPT, and eNodeBResModeAlgo MOs:
    • When UMPT is configured in an MPT MO and WM in the corresponding NODE MO is set to CONCURRENT, the sum of the number of Cell MO instances in which EuCellStandbyMode is set to ACTIVE and the number of SfnAuxResBind and SfnAuxResGrpBind MO instances in which both Main eNodeB ID and Main eNodeB Local cell ID are set to different values must meet one of the following requirements: (1) The sum must be less than or equal to 36 if the value of BRDSPEC for the UMPT configured in the MPT MO is UMPTa, UMPTb, or UMPTa/b. (2) The sum must be less than or equal to 72 in other scenarios.
  • Relation with the BBP, BASEBANDEQM, and SfnAuxResGrpBind MOs:
    • If the WM parameter in a BBP MO for a base station is set to SPEC_MODE1, the SfnAuxResBind and SfnAuxResGrpBind MOs for this base station must be all bound to a BASEBANDEQM MO. In addition, this BASEBANDEQM MO must correspond to a unique BBP MO.
    • If the WM parameter in a BBP MO for a base station is set to SPEC_MODE1, the SfnAuxResBind and SfnAuxResGrpBind MOs for this base station must be all bound to a BASEBANDEQM MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sector equipment ID

Indicates the ID of the sector equipment. It uniquely identifies a piece of sector equipment within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Main eNodeB ID

Indicates the ID of the main eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Main eNodeB Local cell ID

Indicates the local ID of a cell of the primary eNodeB. It uniquely identifies a cell within the primary eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Baseband equipment ID

Indicates the ID of the baseband equipment serving a cell.

When this parameter is set to 255, the baseband equipment serving a cell is not specified. In this scenario, the LTE baseband processing units (LBBPs) serving a cell are selected among all LBBPs in the eNodeB, and the LBBPs to which the cell's serving RRU is connected are preferentially selected.

When this parameter is set to a value other than 255, the cell is served by LBBPs in the specified baseband equipment, and the LBBPs to which the cell's serving RRU is connected are preferentially selected. This parameter applies only to LTE FDD and LTE TDD.
Reference signal power

Indicates the reference signal power of the single frequency network (SFN) auxiliary eNodeB resource. The value 32767 indicates that this reference signal power parameter is invalid. In this case, the cell uses the reference signal power specified in the PDSCHCfg MO. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
Reference Signal Power Margin

Indicates the reference signal power headroom of each physical antenna.

If this parameter is set to 0, the parameter does not take effect. That is, the reference signal power headroom of the cell equals the value of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO. If this parameter is set to a value other than 0, the reference signal power headroom of the cell equals this value regardless of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO set for the sector equipment of the cell. This parameter applies only to LTE TDD.
Sector CPRI Compression

Indicates the CPRI compression type of the sector equipment. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, or NULL. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that normal CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, and this parameter value is applicable only to LTE FDD. The parameter value 3_2_COMPRESSION indicates a compression ratio of 3.2:1, and this parameter value is applicable only to TDD cells including 2T2R, 4T4R, and 8T8R TDD cells. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than that of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cells served by the sector equipment group automatically restarts. This parameter is used only when MultiRruCellMode is set to SFN or CELL_COMBINATION. This parameter can be set on a per sector equipment group basis. When this parameter is set to NULL, the CPRI compression type of carriers depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the CPRI compression type of the sector equipment is determined by the setting of this parameter. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by RRUs in the RRU chain or ring are deactivated. Then, activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.
Auto Config Flag

Indicates whether to automatically or manually control the setting of baseband equipment ID. To enable automatic binding, set this parameter to AUTO_MODE_CFG. To enable manual binding, set this parameter to MANUAL_MODE_CFG or AUTO_MODE_CFG. This parameter applies only to LTE FDD and LTE TDD.
Sector Equipment Combine Group ID

Indicates the ID of a sector equipment combination group, which contains multiple sets of sector equipment. The value 255 indicates that the sector equipment is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.
Virtual Cell ID

Indicates a virtual cell ID used for DMRS scrambling and CSI-RS pattern configuration when adaptive SFN and TM10 are enabled. This parameter needs to be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to LTE FDD.
Cell Beam Mode

Indicates the beam mode of the cell. This parameter has two values: NORMAL and ADVANCED_BEAMFORMING. The value NORMAL indicates that the cell is a normal cell. The value ADVANCED_BEAMFORMING indicates that the cell uses AAU-based advanced beamforming. This parameter applies only to LTE FDD.
