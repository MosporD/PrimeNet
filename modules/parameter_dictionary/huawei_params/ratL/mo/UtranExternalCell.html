UtranExternalCell

+-NE
  +-eNodeBFunction
    +-UtranExternalCell
      +-UtranExternalCellPlmn[0~3]

Description

A UtranExternalCell MO consists of the parameters related to an external UTRAN cell, which can be configured as a neighboring cell of one or more cells under the local eNodeB. The neighboring cell list (NCL) of an eNodeB contains the common information about its external UTRAN cells. In RAN sharing mode, additional PLMN IDs must be added for each external UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    UtranExternalCellPlmn[0~3]
  • Relation with the UtranNCell MO:
    • Before adding a UtranNCell MO, ensure that the associated UtranExternalCell MO has been configured.
  • Relation with the UtranNCell and UtranNFreq MOs:
    • UtranDlArfcn and UtranFddTddType in the UtranExternalCell MO associated with a UtranNCell MO must have been configured in a UtranNFreq MO.
  • Relation with the UtranBlkNCell MO:
    • The UtranExternalCell MO must be configured first before the associated UtranBlkNCell MO is configured.
  • Relation with the UtranBlkNCell and UtranNFreq MOs:
    • UtranDlArfcn and UtranFddTddType in the UtranExternalCell MO associated with a UtranBlkNCell MO must have been configured in the corresponding UtranNFreq MO.
  • Relation with the UtranBlkNCell, UtranNCell, and Cell MOs:
    • Values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranBlkNCell MO configured for the serving cell cannot be the same as values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranNCell MO configured for the serving cell at the same time.
  • Relation with the UtranNCell and Cell MOs:
    • In all UtranNCell MOs of a local Cell MO, the combination of UtranDlArfcn and PScrambCode in the UtranExternalCell MO corresponding to each UtranNCell MO must be unique.
  • Relation with the MDU MO:
    • A maximum of 3*128 UtranExternalCell MOs can be configured in the same eNodeB if the parameter TYPE in MDU is set to MDUC.

Mobile country code

Indicates the mobile country code of the external UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

RNC ID

Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
RNC cell ID

Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. UTRAN cell type indicator

Indicates the duplex mode of the UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Routing area code configure indicator

Indicates whether to set the routing area code (RAC). This parameter must be set to CFG(Configure) if the eNodeB needs to perform routing and addressing procedures, such as handover and RIM, to target neighboring UTRAN cells. This parameter applies only to LTE FDD and LTE TDD.
Routing area code

Indicates the routing area code. This parameter applies only to LTE FDD and LTE TDD.
Primary scrambling code

Indicates the primary DL scrambles of the external UTRAN cell. For details, see 3GPP TS 25.331. This parameter applies only to LTE FDD and LTE TDD.

Indicates the LAC of the external UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Cell name

Indicates the name of the external UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
CS and PS handover indicator

Indicates whether the external UTRAN cell supports single radio voice call continuity (SRVCC) for concurrent CS and PS services. If this parameter is set to BOOLEAN_FALSE, the external UTRAN cell does not support SRVCC for concurrent CS and PS services. This parameter applies only to LTE FDD and LTE TDD.
External UTRAN Cell Slave Band

Indicates slave frequency bands of an external UTRAN cell. If the operating frequency of an external UTRAN cell belongs to multiple frequency bands, the downlink frequency of the frequency band with the highest priority is configured by the UtranDlArfcn parameter, and frequency bands with other priorities are configured by the UtranExternalCellSlaveBand parameter and added in descending order based on frequency band priorities. The frequency band priorities of an external UTRAN cell are determined in network planning. It is recommended that the frequency bands supporting UEs that comply with 3GPP TS 36.331 V8.16.0, 3GPP TS 36.331 V9.1.0, 3GPP TS 36.331 V10.5.0, or a later vision be configured as slave frequency bands. This parameter applies only to LTE FDD and LTE TDD.
Roaming Area Handover Indicator

Indicates whether the neighbor cell can be selected for handovers during roaming. This parameter is set to NO(No) by default.

If this parameter is set to YES(Yes), this neighboring cell can be selected for handovers during roaming. If this parameter is set to NO(No), this neighboring cell cannot be selected for handovers during roaming.

If the PLMN of the neighboring cell is included in the SPID-based handover-allowable HPLMN list or this parameter is set to YES(Yes), this neighboring cell can be selected for handovers.

In the boundaries of roaming areas and non-roaming areas, you are advised to set this parameter to YES(Yes) to ensure that neighboring cells in roaming areas can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether the external UTRAN cell is automatically detected by Automatic Neighbor Relation (ANR). This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
