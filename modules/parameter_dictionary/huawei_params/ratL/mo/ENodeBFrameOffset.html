ENodeBFrameOffset

+-NE
  +-eNodeBFunction
    +-ENodeBFrameOffset

Description

The ENodeBFrameOffset MO consists of parameters related to the offset of all cell frames against the reference time.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell and CellFrameOffset MOs:
    • The TddFrameOffset parameter in an ENodeBFrameOffset MO must be set to 0 when the following conditions are met: The CellActiveState, FddTddInd, and WorkMode parameters in the associated Cell MO are set to CELL_ACTIVE, CELL_TDD, and LAA, respectively, and the CellFrameOffset MO under this Cell MO has not been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ENODEBFRAMEOFFSET

Use this command to list TDD frame offset configurations in cells served by the eNodeB.
MOD ENODEBFRAMEOFFSET

Use this command to modify the offset of the start of LTE TDD cell frames against the reference time.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
TDD Frame Offset

Indicates the offset of the start time of a cell frame against a reference clock source. This offset applies to all LTE TDD cells served by an eNodeB.
FDD Frame Offset

Indicates the offset of the start time of a cell frame against a reference clock source. This offset applies to all LTE FDD cells and all NB-IoT cells served by an eNodeB. This parameter applies only to LTE FDD and NB-IoT.
Frame Offset Auto Correct Switch

Indicates whether to enable automatic frame offset correction. If this option is selected and the frame offset of a cell is different from that of its neighboring cells, the eNodeB automatically changes the frame offset of this cell to that of the neighboring cells. If this option is deselected, the eNodeB cannot automatically change the frame offset of a cell. This parameter applies only to LTE TDD.
