PccFreqCfg

+-NE
  +-eNodeBFunction
    +-PccFreqCfg
      +-NrScgFreqConfig[0~8]
      +-SccFreqCfg[0~16]

Description

A PccFreqCfg MO consists of parameters related to a candidate primary component carrier (PCC). Only the carriers configured in the PccFreqCfg MOs can work as PCCs for UEs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    NrScgFreqConfig[0~8];SccFreqCfg[0~16]
  • Relation with the NrScgFreqConfig MO:
    • A maximum of eight NrScgFreqConfig MOs can be configured for each PccFreqCfg MO.
  • Relation with the Tm9DedicatedCarrier MO:
    • WorkMode parameter in a Tm9DedicatedCarrier MO is set to TM9_DEDICATED_SCC, the Tm9CcDlEarfcn parameter in the same MO cannot be set to the same value as the PccDlEarfcn parameter in the PccFreqCfg MO.
  • Relation with the SccFreqCfg MO:
    • A maximum of sixteen SccFreqCfg MOs can be configured under this PccFreqCfg MO.
  • Relation with the ENodeBAlgoSwitch MO:
    • If the CaSmartSelectionSwitch option of the CaAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the number of PccFreqCfg MO instances cannot exceed nine.
  • Relation with the MultiCarrUnifiedSch MO:
    • If the SMART_CARRIER_SELECTION_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is deselected, the number of PccFreqCfg MO instances cannot exceed nine.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD PCCFREQCFG

Use this command to add a candidate primary component carrier (PCC).
DSP PCCSCELLLIST

Use this command to query the secondary serving cells (SCells) that are dynamically configured for the primary serving cells (PCells) on one primary component carrier (PCC) or all PCCs under the eNodeB. If the PccDlEarfcn parameter is set, SCells for PCells on the frequency specified by the PccDlEarfcn parameter are queried. If the PccDlEarfcn parameter is not set, SCells for PCells on all candidate PCCs in the eNodeB are queried. When the operating frequencies of the queried PCells or the SCells dynamically configured for the PCells belong to multiple bands, multiple downlink ARFCNs corresponding to the cell are displayed.
DSP SMARTCARRIERSELECTIONFREQ

Use this command to query the frequency sequence arranged after smart carrier selection is enabled.
LST PCCFREQCFG

Use this command to list the primary component carrier (PCC) configurations.
MOD PCCFREQCFG

Use this command to modify a candidate primary component carrier (PCC).
RMV PCCFREQCFG

Use this command to remove a candidate primary component carrier (PCC).

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
PCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the candidate PCC. This parameter applies only to LTE FDD and LTE TDD.
Preferred PCC Priority

Indicates the PCC priority of a frequency. A small value of this parameter leads to a low PCC priority of a carrier working on the frequency specified by the PCCDlEarfcn parameter in the PccFreqCfg MO for the carrier to be selected as the PCC for CA UEs. A large value of this parameter leads to a high PCC priority of a carrier working on the frequency specified by the PCCDlEarfcn parameter for the carrier to be selected as the PCC for CA UEs. This parameter takes effect when the IdleModePccAnchorSwitch, PccAnchorSwitch, or EnhancedPccAnchorSwitch option of the CaAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.
PCC A4 RSRP Threshold

Indicates the reference signal received power (RSRP) threshold for triggering event A4 during higher-priority carrier evaluation for PCC selection. This parameter applies only to LTE FDD and LTE TDD.
PCC A4 RSRQ Threshold

Indicates the reference signal received quality (RSRQ) threshold for triggering event A4 during higher-priority carrier evaluation for PCC selection in scenarios where CA is configured based on frequencies. If the measured RSRQ of an inter-frequency neighboring cell in the CA group is greater than this parameter value, the CA UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.
NSA PCC Anchoring Priority

Indicates the NSA DC PCC anchoring priority. A larger value of this parameter indicates a higher priority. If this parameter is set to 0, this frequency cannot be selected as a target frequency for NSA DC PCC anchoring. The setting of this parameter is valid only if the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO is selected. This parameter applies only to LTE FDD and LTE TDD.
NSA DC PCC A4 RSRP Threshold

Indicates the RSRP threshold for event A4 related to NSA DC PCC anchoring. If the measured RSRP of an inter-frequency neighboring cell is greater than this parameter value, the NSA DC UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.
NSA DC PCC A4 RSRQ Threshold

Indicates the RSRQ threshold for event A4 related to NSA DC PCC anchoring. If the measured RSRQ of an inter-frequency neighboring cell is greater than this parameter value, the NSA DC UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
PCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the PCell. This parameter applies only to LTE FDD and LTE TDD.
SCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of an SCell. This parameter applies only to LTE FDD and LTE TDD.

Indicates the downlink EARFCN of the to-be-measured frequency selected by smart carrier selection. This parameter applies only to LTE FDD and LTE TDD.
