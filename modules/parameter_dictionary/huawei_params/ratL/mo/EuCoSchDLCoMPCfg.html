EuCoSchDLCoMPCfg

+-NE
  +-eNodeBFunction
    +-EuCoSchDLCoMPCfg

Description

The EuCoSchDLCoMPCfg MO consists of parameters specifying inter-eNodeB DL CoMP.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CspcAlgoPara MO:
    • If the InterEnbDlCompSwitch parameter in the EuCoSchDLCoMPCfg MO is set to ON, the CspcAlgoSwitch parameter in the CspcAlgoPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be cleared.
  • Relation with the CoProcRes MO:
    • If the InterEnbDlCompSwitch parameter in the EuCoSchDLCoMPCfg MO is set to ON(On), there must be at least one CoProcRes MO in which both the CLUSTER_MANAGEMENT and COORDINATING_PROCESSING options of the WorkMode parameter are selected.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST EUCOSCHDLCOMPCFG

Use this command to list the settings of parameters related to inter-eNodeB DL CoMP, such as the delay for coordinated information to take effect.
MOD EUCOSCHDLCOMPCFG

Use this command to modify the settings of parameters related to inter-eNodeB DL CoMP, such as the delay for coordinated information to take effect.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Coordinated Information Effective Delay

Indicates the interval between the time that the eNodeB reports measurement information and the time that the coordinated information delivered to the eNodeB takes effect. This parameter applies only to LTE FDD and LTE TDD.
Inter-eNodeB DlCoMP Algorithm Switch

Indicates whether to enable inter-eNodeB DL CoMP in cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE FDD and LTE TDD.
Coordinated Schedule Ue Specification

Indicates the number of UEs scheduled by the centralized control node. This parameter applies only to LTE FDD and LTE TDD.
