EutranSpePciCell

+-NE
  +-eNodeBFunction
    +-EutranSpePciCell

Description

An EutranSpePciCell MO consists of parameters related to special PCIs. Parameters in this MO take effect when the Specified PCI Group-based Neighboring Cell Management feature is enabled. If the PCI of a cell is specified in this MO, the cell is a cell configured with a special PCI. If the PCI of a cell is not included in the list, the cell is a common cell.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Downlink EARFCN

Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) of the E-UTRAN cell with a specified physical cell identifier (PCI). This parameter applies only to LTE FDD and LTE TDD.
Start Physical Cell ID

Indicates the start physical cell identifier (PCI) of E-UTRAN cells with specified PCIs. This parameter applies only to LTE FDD and LTE TDD.
Specified Physical Cell ID Range

Indicates the number of physical cell identifiers (PCIs) of E-UTRAN cells with specified PCIs. This parameter applies only to LTE FDD and LTE TDD.
Specified PCI Group Policy Switch

Indicates the algorithm policy switch of a specified PCI group. This parameter provides the following option:

NO_HO_BASED_X2_AUTO_SETUP_SW: Indicates whether to forbid handover-based X2 self-setup to an eNodeB that serves a cell with a PCI in the specified PCI group. This function is enabled only if this option is selected. This parameter applies only to LTE FDD and LTE TDD.
