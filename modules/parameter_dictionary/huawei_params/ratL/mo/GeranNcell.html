GeranNcell

+-NE
  +-eNodeBFunction
    +-Cell
      +-GeranNcell

Description

A GERANNCELL MO consists of the parameters related to a GERAN neighboring cell of the local cell, which can be the target cell of an inter-RAT handover.

For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the GeranExternalCell MO:
    • Before adding a GeranNcell MO, ensure that the associated GeranExternalCell MO has been configured.
  • Relation with the GeranExternalCell, GeranNfreqGroup, and GeranNfreqGroupArfcn MOs:
    • GeranArfcn and BandIndicator in a GeranExternalCell MO corresponding to a GeranNcell MO must be the same as GeranArfcn in a GeranNfreqGroupArfcn MO and BandIndicator in the GeranNfreqGroup MO associated with the GeranNfreqGroupArfcn MO, respectively. Alternatively, GeranArfcn and BandIndicator in a GeranExternalCell MO corresponding to a GeranNcell MO must be the same as StartingArfcn and BandIndicator in a GeranNfreqGroup MO, respectively.
  • Relation with the Cell MO:
    • A maximum of 128 GeranNcell MOs can be configured for each cell.
  • Relation with the Cell MO and MPT MO:
    • If the MPT type is LMPT, UMPTa, or UMPTb, a maximum of 64 GeranNcell MOs can be configured for each cell.
  • Relation with the GeranNcell MO:
    • A maximum of 18*64 GeranNcell MOs can be configured in the same eNodeB when equipped with LMPT.
    • A maximum of 36*64 GeranNcell MOs can be configured in the same eNodeB when equipped with UMPTa/b.
    • A maximum of 72*128 GeranNcell MOs can be configured in the same eNodeB.
  • Relation with the MDU MO:
    • A maximum of 3*128 GeranNcell MOs can be configured in the same eNodeB if the parameter TYPE in MDU is set to MDUC.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GERANNCELL

Use this command to add the neighboring relation with a GERAN cell.
DSP GERANEXTENDEDNCELL

Use this command to query neighbor relationships with GERAN cells labeled with EXTENDED when neighboring GERAN cell classification management is enabled.
DSP GERANNCELL

Use this command to dynamically query GERAN neighbor relationship records.
DSP GERANRIMINFO

Use this command to query the status of the RIM procedure in Multiple Report mode for neighboring GERAN cells.

If the LocalCellId parameter is not specified, the result is the RIM status of all neighboring GERAN cells.

If the LocalCellId parameter is specified, the result is the RIM status of neighboring GERAN cells related to this specified local cell.
LST GERANNCELL

Use this command to list the parameters of the neighboring relation with the GERAN cell.
MOD GERANNCELL

Use this command to modify the neighboring relation with a GERAN cell.
RMV GERANEXTENDEDNCELL

Use this command to remove one or more neighbor relationships with GERAN cells labeled with EXTENDED.
RMV GERANNCELL

Use this command to remove one or more neighbor relationships with GERAN cells.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile country code

Indicates the mobile country code of the neighboring GERAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code of the neighboring GERAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.
Location area code

Indicates the LAC of the GERAN neighboring cell. It uniquely identifies a location within a PLMN. This parameter applies only to LTE FDD and LTE TDD.
GERAN cell ID

Indicates the cell ID of the GERAN neighboring cell. It uniquely identifies a GERAN cell within the area specified by the location area identity (LAI). An LAI consists of the MCC, MNC, and LAC. This parameter applies only to LTE FDD and LTE TDD.
No remove indicator

Indicates whether to permit or prohibit removal of the neighboring relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.
No handover indicator

Indicates whether handovers of UEs to the neighboring cell are prohibited. This parameter applies only to LTE FDD and LTE TDD.
Blind handover priority

Indicates the priority of the neighboring cell during blind handovers. Blind handover is a process in which the eNodeB instructs a UE to hand over to a specified neighboring cell. There are 32 priorities altogether. The priority has a positive correlation with the value of this parameter. Note that the value 0 indicates that blind handovers to the neighboring cell are not allowed. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether this neighboring cell is automatically discovered by the ANR algorithm. This parameter applies only to LTE FDD and LTE TDD.
Local cell name

Indicates the name of the local cell. This parameter applies only to LTE FDD and LTE TDD.
Neighbour cell name

Indicates the name of the GERAN neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Overlap Indicator

Indicates whether the neighboring GERAN cell overlaps the E-UTRAN cell. The default value is NO.

The parameter value YES indicates that the neighboring GERAN cell overlaps the E-UTRAN cell. The parameter value NO indicates that the neighboring GERAN cell does not overlap the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Measure Priority

Indicates the measurement priority of the neighboring GERAN cell. A larger value indicates a higher priority. The measurement priorities can be periodically and automatically arranged based on the number of times each neighboring GERAN cell is measured. The neighboring GERAN cells for fast blind redirections to GERAN or blind redirections for flash CSFB to GERAN can be selected based on the measurement priorities of neighboring GERAN cells. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Addition Time

Indicates the time the neighboring cell was added by ANR for the first time. In free mode, this time is the local time of the NE. In control mode, this time is the local time of the OSS when optimization suggestions are delivered. The format is YYYY-MM-DD. For example, the value 2018-01-01 indicates January 1, 2018. The value 2001-01-01 indicates that the neighboring cell was manually added. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
eNodeB ID

Indicates the eNodeB ID defined in the service protocol interface, which uniquely identifies an eNodeB within a PLMN. For details, see 3GPP TS 36.300. This parameter applies only to LTE FDD and LTE TDD.
