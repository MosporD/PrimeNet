LicenseSharingPolicy

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-LicenseSharingPolicy

Description

A LicenseSharingPolicy MO consists of the parameters about a license sharing policy among operators. The parameters are set to determine the proportion of the maximum number of users for each operator. If a LicenseSharingPolicy MO is not configured for an operator, the proportion of the maximum number of users for this operator is 0 by default. Users of this operator cannot access the shared eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator
  • Relation with the LicenseSharingPolicy MO:
    • The sum of MaxUserNumRate in all LicenseSharingPolicy MOs cannot exceed 100.
  • Relation with the ENodeBSharingMode MO:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to INDEPENDENT, no LicenseSharingPolicy MO can be configured.
  • Relation with the CnOperator MO:
    • Among the CnOperator MO instances corresponding to CnOperatorId in the associated LicenseSharingPolicy MO instances, the number of CnOperator MO instances in which PlmnMode is set to IOPS_PLMN must be zero.
  • Relation with the CellAlgoSwitch and ENodeBSharingMode MOs:
    • If the OutOfBandRelaySwitch, InBandRelayDeNbSwitch, or InBandRelayReNbSwitch of the RelaySwitch parameter in a CellAlgoSwitch MO is selected and the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, the LicenseSharingPolicy MO must not be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.
The proportion of the maximum number of users

Indicates the proportion of the number of UEs in RRC_CONNECTED mode of the operator when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD and LTE TDD.
The proportion of the sharing number of users

Indicates the proportion of users that the operator can share with other operators when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD.
User Number Sharing Group ID

Indicates the ID of the sharing group of UEs in RRC_CONNECTED mode. Operators with the same UserNumSharingGroupId parameter value share the sum of the proportions of UEs in RRC_CONNECTED mode of each operator and the sum of the penetration rates of UEs in RRC_CONNECTED mode of each operator. The value 255 is an invalid ID, indicating that the operator is not configured with a sharing group of UEs in RRC_CONNETED mode. This parameter applies only to LTE FDD and LTE TDD.
