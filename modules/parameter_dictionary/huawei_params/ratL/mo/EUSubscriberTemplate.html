EUSubscriberTemplate

+-NE
  +-eNodeBFunction
    +-EUSubscriberTemplate

Description

An EUSubscriberTemplate MO consists of parameters related to a subscriber template.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the EUAPNTemplate MO:
    • The value of the APN parameter in the EUAPNTemplate MO corresponding to the APNTemplateID parameter in the EUSubscriberTemplate MO cannot be the same as that corresponding to the SecondaryAPNTemplateID parameter in the EUSubscriberTemplate.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD EUSUBSCRIBERTEMPLATE

Use this command to add a subscriber template.
LST EUSUBSCRIBERTEMPLATE

Use this command to list a subscriber template.
MOD EUSUBSCRIBERTEMPLATE

Use this command to modify a subscriber template.
RMV EUSUBSCRIBERTEMPLATE

Use this command to remove a subscriber template.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Subscriber Template ID

Indicates the ID of a subscriber template. This parameter applies only to LTE FDD and LTE TDD.
APN Template ID

Indicates the ID of an APN template. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.
Template Name

Indicates the name of a subscriber template. This parameter applies only to LTE FDD and LTE TDD.
Secondary APNTemplate Configuration Indicator

Indicates whether the second PDN connection configured in the user template takes effect. This parameter applies only to LTE FDD and LTE TDD.
Secondary APN Template ID

Indicates the ID of the secondary APN template for second PDN connection configuration. This parameter applies only to LTE FDD and LTE TDD.
