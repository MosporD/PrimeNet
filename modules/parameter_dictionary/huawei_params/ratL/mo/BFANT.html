BfAnt

+-NE
  +-eNodeBFunction
    +-BfAnt

Description

A BFANT MO defines a beamforming (BF) antenna. By adjusting the amplitude and phase of output signals at each port of a BF antenna, the eNodeB can transmit a beam of a specific width to achieve increased gains.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell, eUCellSectorEqm, and SectorSplitCell MOs:
    • If the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, a BfAnt MO must be associated with the WeightNO parameter in the eUCellSectorEqm MO bound to the cell, and the FreqBand parameter in the Cell MO must be set to the same value as the Band parameter.
  • Relation with the Cell, SectorSplitCell, and eUCellSectorEqm MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, a BfAnt MO must be associated with the WeightNO parameter in the eUCellSectorEqm MO bound to the cell, and the CoverageScenario parameter in the BfAnt MO must not be set to NONE.
  • Relation with the Cell, CellPdcchAlgo, and eUCellSectorEqm MOs:
    • When the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE(Active) and the MASSIVE_MIMO_PDCCH_SDMA_SW option of the SplitBeamPdcchSdmaSw parameter in the CellPdcchAlgo MO is selected, the BfAnt MO associated with the WeightNO parameter in the eUCellSectorEqm MO bound to the cell must exist, and the CoverageScenario parameter in the BfAnt MO must be set to SCENARIO_2(HBW 65 Degree, VBW 8 Degree), SCENARIO_3(HBW 45 Degree, VBW 8 Degree), SCENARIO_4(HBW 25 Degree, VBW 8 Degree), SCENARIO_6(HBW 65 Degree, VBW 17 Degree), SCENARIO_7(HBW 45 Degree, VBW 17 Degree), SCENARIO_8(HBW 25 Degree, VBW 17 Degree), SCENARIO_10(HBW 65 Degree, VBW 35 Degree), SCENARIO_11(HBW 45 Degree, VBW 35 Degree), or SCENARIO_12(HBW 25 Degree, VBW 35 Degree).
  • Relation with the Cell, CellMMAlgo, and eUCellSectorEqm MOs:
    • When the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE(Active) and the BeamGainLimitSwitch parameter in the CellMMAlgo MO is set to ON(On), the BfAnt MO associated with the WeightNO parameter in the eUCellSectorEqm MO bound to the cell must exist, and the CoverageScenario parameter in the BfAnt MO must not be set to SCENARIO_3(HBW 45 Degree, VBW 8 Degree), SCENARIO_4(HBW 25 Degree, VBW 8 Degree), SCENARIO_8(HBW 25 Degree, VBW 17 Degree), SCENARIO_9(HBW 15 Degree, VBW 17 Degree), or SCENARIO_13(HBW 15 Degree, VBW 35 Degree).
  • Relation with the CellPdcchAlgo MO:
    • The PdcchSdmaWeightType parameter in a CellPdcchAlgo MO can be set to PREFERENTIAL_ENHANCED_SDMA(PREFERENTIAL_ENHANCED_SDMA) only when the CoverageScenario parameter in the BfAnt is set to SCENARIO_2(HBW 65 Degree, VBW 8 Degree) or SCENARIO_6(HBW 65 Degree, VBW 17 Degree).

Table 1 Related MML commands

Function

Use this command to activate the weight database file for a beamforming antenna. This command applies only to LTE TDD non-massive MIMO scenarios.

Use this command to query the dynamic information about one or all beamforming antennas.

Use this command to remove a beamforming antenna.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Device No.

Indicates the device number of a beamforming antenna. It uniquely identifies a beamforming antenna within an eNodeB. This parameter is associated with the WeightNO parameter in the eUCellSectorEqm MO. If the WeightNO parameter in the eUCellSectorEqm MO is set to 255, the weight corresponding to the smallest DeviceNo parameter value is used. This parameter applies only to LTE TDD.
Manufactory

Indicates the manufacturer of a beamforming antenna. This parameter applies only to LTE TDD.
CRS Split Beam Indicator

Indicates a split beam for the CRS of a cell from a split. If this parameter is set to a value ranging from 0 to 7, the eNodeB uses the split beam specified by this parameter to transmit the CRS of the soft split cell. The values 0 to 7 are divided into four groups: (0, 1), (2, 3), (4, 5), and (6, 7). This parameter must be set to different values in any of these groups for two split cells in a SSRDCellGroup MO. For example, if this parameter is set to 0 for the primary cell in a SSRDCellGroup MO, this parameter must be set to 1 for the split cell in the same MO. If this parameter is set to 255, the eNodeB uses the default split beam to transmit the CRS of the soft split cell. This parameter applies only to LTE TDD.
Vertical Beam Width

Indicates the vertical beam width. This parameter only applies to LTE TDD cells.
Connect RRU cabinet No.

Indicates the cabinet number of the RRU to which a beamforming antenna is connected. This parameter applies only to LTE TDD.
Connect RRU subrack No.

Indicates the subrack number of the RRU to which a beamforming antenna is connected. This parameter applies only to LTE TDD.
Connect RRU slot No.

Indicates the slot number of the RRU to which a beamforming antenna is connected. This parameter applies only to LTE TDD.
Antenna model number

Indicates the model of a beamforming antenna. Set this parameter to RAE if the antenna weight must be queried on the RAE. The value RAE is case-insensitive, while other values are case-sensitive. In massive MIMO broadcast scenarios, this parameter must be set to MassiveAntenna. For details about this parameter setting in split-related and other scenarios, see related FPD documents. This parameter applies only to LTE TDD.
Tilt

Indicates the integral part of the tilt corresponding to the beamforming weighting value. This parameter is used with the TiltFractionalPart parameter, which indicates the fractional part (tenths) of the tilt. This parameter applies only to LTE TDD.
Beamwidth

Indicates the horizontal beamwidth formed after beamforming. This parameter is not used in massive MIMO scenarios. This parameter applies only to LTE TDD networks.
Band

Indicates the frequency band used by a beamforming antenna. The value 0 is a broad frequency band, indicating that the object weight is applicable to all frequency bands. This parameter applies only to LTE TDD.
Antenna Type

Indicates the type of a beamforming antenna. This parameter applies only to LTE TDD.
BFANTBEARING

Indicates angle at which an antenna deflects the horizontal azimuth of the beam (weight-based deflection relative to the mechanical azimuth). In non-massive MIMO scenarios, this parameter indicates only the degree at which a smart antenna deflects. In massive MIMO scenarios, this parameter indicates the degree at which an antenna deflects. With the mechanical azimuth of the antenna as the normal line, a clockwise deflection requires a positive value and a counterclockwise deflection requires a negative value. This parameter applies only to broadcast beams, but not to traffic beams. This parameter applies only to LTE TDD.
Coverage Scenario

Indicates the coverage scenario of a massive MIMO antenna. This parameter is used to adjust the antenna beam pattern. The values EXPANDSCENARIO_1, EXPANDSCENARIO_2, and EXPANDSCENARIO_3 indicate user-defined coverage scenarios. For 64T64R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. For 32T32R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_5, SCENARIO_6, SCENARIO_7, SCENARIO_8, SCENARIO_9, SCENARIO_15, or SCENARIO_17. Due to the limited vertical beamwidth of a single 32T32R channel, it is not recommended that this parameter be set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. This parameter applies only to LTE TDD.
Tilt Fractional Part

Indicates the fractional part (tenths) of the tilt corresponding to the beamforming weighting value. This parameter is used with the Tilt parameter, which indicates the integral part of the tilt. This parameter applies only to massive MIMO scenarios. This parameter applies only to LTE TDD.
