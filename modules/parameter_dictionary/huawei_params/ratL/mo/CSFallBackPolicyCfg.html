CSFallBackPolicyCfg

+-NE
  +-eNodeBFunction
    +-CSFallBackPolicyCfg

Description

The CSFallBackPolicyCfg MO defines circuit switched fallback (CSFB) policies. Depending on whether UEs are in connected or idle mode, eNodeBs can use different CSFB policies when handing over UEs from the E-UTRAN to another inter-RAT network.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CSFB handover policy Configuration

Indicates the CSFB policy for a UE in connected mode. If the CSFB steering function is disabled, this parameter also applies to UEs in idle mode. The policy can be PS handover, CCO, or redirection.
CSFB handover policy Configuration for idle ue

Indicates the CSFB policy for a UE in idle mode. The policy can be PS handover, CCO, or redirection. This parameter applies only to LTE FDD and LTE TDD.
Csfb User Arp Configuration Switch

Indicates whether to allow the eNodeB to change the ARPs for CSFB UEs. If this parameter is set to ON, the ARPs for CSFB UEs in common calls are specified by the NormalCsfbUserArp parameter in the CsFallbackPolicyCfg MO, and the ARPs for CSFB UEs in emergency calls are always 1. If this parameter is set to OFF, admission of CSFB UEs is performed based on the ARPs delivered from the EPC. For details about ARP, see 3GPP TS 23.401. This parameter applies only to LTE FDD and LTE TDD.
Normal Csfb User Arp

Indicates the allocation/retention priority (ARP) of a CSFB service triggered by a common call. When this parameter is set to 1, the service priority is the same as that of an emergency call. For details about the ARP, see 3GPP TS 23.401. This parameter applies only to LTE FDD and LTE TDD.
