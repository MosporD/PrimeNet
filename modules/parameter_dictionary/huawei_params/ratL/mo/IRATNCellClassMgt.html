IRATNCellClassMgt

+-NE
  +-eNodeBFunction

Description

An IRATNCellClassMgt MO consists of parameters related to inter-RAT neighboring cell classification management.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rat Type

Indicates the RAT corresponding to the inter-RAT neighbor relationship classification algorithm. This parameter applies only to LTE FDD and LTE TDD.
Statistic Period For NCell Class

Indicates the statistical period for inter-RAT neighbor relationship classification. The number of times a target cell is measured by UEs in the source cell is measured within the statistical period. The eNodeB determines whether the inter-RAT neighboring cell is a formal or extended neighboring cell based on the measurement result. If the predefined criteria are met within the statistical period, the inter-RAT neighboring cell is regarded as a formal neighboring cell. If the predefined criteria are not met within each of four consecutive statistical periods, the inter-RAT neighboring cell is regarded an extended neighboring cell. This parameter also indicates the statistical period for determining whether a neighboring UTRAN cell is an over-distant neighboring cell. If the number of handovers to a neighboring UTRAN cell reaches the specified threshold and the handover success rate meets the specified handover success rate threshold within a statistical period, the neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.
NCell Measure Number Threshold

Indicates the measurement times threshold for inter-RAT neighbor relationship classification. If the number of times a target cell is measured within the statistical period for inter-RAT neighbor relationship classification reaches this threshold, this inter-RAT neighboring cell is regarded a formal neighboring cell. If the number of times the target cell is measured does not reach this threshold within each of four consecutive statistical periods, this inter-RAT neighboring cell is regarded an extended neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
