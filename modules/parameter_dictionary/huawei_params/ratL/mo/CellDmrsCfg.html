CellDmrsCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDmrsCfg

Description

The CellDmrsCfg MO consists of parameters related to the configuration of the uplink demodulation reference signal (DMRS) in the NB-IoT cell. This MO is used for generating DMRS sequences.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLDMRSCFG

Use this command to add uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell, which are used to generate the DMRS sequence.
LST CELLDMRSCFG

Use this command to list uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell, which are used to generate the DMRS sequence.
MOD CELLDMRSCFG

Use this command to modify uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell, which are used to generate the DMRS sequence.
RMV CELLDMRSCFG

Use this command to remove uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies to LTE FDD, LTE TDD, and NB-IoT.
DMRS Six Tone Base Sequence

Indicates the DMRS six tone base sequence of a cell. This parameter and the SixToneCyclicShift parameter are used together to generate the DMRS sequence for the NPUSCH when six tone transmission is used. This parameter applies only to NB-IoT.
DMRS Twelve Tone Base Sequence

Indicates the DMRS twelve tone base sequence of a cell, which is used to generate the DMRS sequence for the NPUSCH when twelve tone transmission is used. This parameter applies only to NB-IoT.
DMRS Three Tone Base Sequence

Indicates the DMRS three tone base sequence of a cell. This parameter and the ThreeToneCyclicShift parameter are used together to generate the DMRS sequence for the NPUSCH when three tone transmission is used. This parameter applies only to NB-IoT.
DMRS Six Tone Cyclic Shift

Indicates the six tone cyclic shift for the uplink DMRS. The DMRS sequence is generated by using the base sequence and cyclic shift. With cyclic shift used, the number of DMRS sequences is increased to 56 (14 multiplied by 4) from 14 when six tone transmission is used. This decreases the possibility of interference among intra-frequency neighboring cells. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
DMRS Three Tone Cyclic Shift

Indicates the three tone cyclic shift for the uplink DMRS. The DMRS sequence is generated by using the base sequence and cyclic shift. With cyclic shift used, the number of DMRS sequences is increased to 36 (3 multiplied by 12) from 12 when three tone transmission is used. This decreases the possibility of interference among intra-frequency neighboring cells. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
