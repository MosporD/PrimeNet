SpidCfg

+-NE
  +-eNodeBFunction
    +-SpidCfg

Description

An SpidCfg MO consists of parameters related to a subscriber profile ID. Parameters in an SpidCfg MO include the priority of camping of a UE in idle mode, inter-frequency or inter-RAT handover priority of a UE in connected mode, support of special DRX, support of pre-allocation, SPID-based inter-frequency or inter-RAT load balancing switch, and SPID-based handover back to HPLMN switch. Special DRX is used for UEs that do not require power saving.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the UeCooperationPara, CellWttxParaCfg, CellQciPara, and CellBf MOs:
    • The BfWeightOptDegreeFactor parameter in the CellBf MO must be set to 0 when none of the following conditions are met: The SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to SPID_BASED, the SpecifiedUserFlag parameter in a SpidCfg MO is set to SPECSERUSER; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to QCI_BASED, the ServiceFlag parameter in a CellQciPara is set to WBB_Service. Otherwise, the value range of the BfWeightOptDegreeFactor parameter in the CellBf MO is 0 to 255.
  • Relation with the CellWttxParaCfg, CellQciPara, and CellBfMimoParaCfg MOs:
    • The TM9_DL_4LAYER_BOOST_SW option of the Tm9Dl4LayerMimoEnhSw parameter in the CellBfMimoParaCfg MO can be selected only if either of the following conditions is met:
    • 1. The WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to SPID_BASED, and the SpecifiedUserFlag parameter in the SpidCfg MO is set to SPECSERUSER for any SPID.
    • 2. The WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to QCI_BASED, and the ServiceFlag parameter is set to WBB_SERVICE for any QCI used in the cell specified in the CellQciPara MO.
  • Relation between the CnOperatorSpidCfg and SpidCfg MOs:
    • The sum of the number of CnOperatorSpidCfg MOs in which INTER_FREQUENCY_OFFLOAD_SWITCH of OffloadSwitch is selected and the number of SpidCfg MOs in which INTER_FREQUENCY_OFFLOAD_SWITCH of OffloadSwitch is selected cannot be greater than 8.
    • The sum of the number of CnOperatorSpidCfg MOs in which INTER_RAT_OFFLOAD_SWITCH of OffloadSwitch is selected and the number of SpidCfg MOs in which INTER_RAT_OFFLOAD_SWITCH of OffloadSwitch is selected cannot be greater than 8.
  • Relation with the RatFreqPriorityGroup MO:
    • RatFreqPriorityGroupId in a SpidCfg MO must have been set in the associated RatFreqPriorityGroup MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Spid

Indicates the subscriber profile ID (SPID). According to 3GPP specifications, the SPID can be from 1 to 256. When this parameter is set to 0, the eNodeB does not obtain the SPID from the MME or the eNodeB is not configured with an SPID for UEs. This parameter applies only to LTE FDD and LTE TDD.
Drx status

Indicates whether to use normal or special DRX. If this parameter is set to TRUE, ordinary DRX parameters are applied to UEs with the SPID. If this parameter is set to FALSE, special DRX parameters are applied to UEs with the SPID. This parameter applies only to LTE FDD and LTE TDD.
RAT frequency priority indication

Indicates whether to set the priority for the intra-RAT frequency. If this parameter is set to CFG(CFG), UEs select the target frequency based on the priority setting. If this parameter is set to NOT_CFG(NOT_CFG), UEs do not select the target frequency based on the priority setting. This parameter applies only to LTE FDD and LTE TDD.
RAT frequency priority group ID

Indicates the ID of the intra-RAT frequency priority group. This parameter applies only to LTE FDD and LTE TDD.
PreallocationStatus

Indicates whether to support preallocation. If this parameter is set to TRUE and PreAllocationSwitch under the UlSchSwitch parameter in the CellAlgoSwitch MO is set to selected, resources can be preallocated to UEs. Otherwise, resources are not preallocated to UEs. This parameter applies only to LTE FDD and LTE TDD.
InterFreq Mlb Switch

Indicates whether to enable or disable inter-frequency load balancing for the SPID. The value TRUE or FALSE indicates that inter-frequency load balancing is allowed or prohibited for UEs with the SPID, respectively. This parameter applies only to LTE FDD and LTE TDD.
InterRat Mlb Switch

Indicates whether to enable or disable inter-RAT load sharing for the SPID. The value TRUE or FALSE indicates that inter-RAT load sharing is allowed or prohibited for UEs with the SPID, respectively. This parameter applies only to LTE FDD and LTE TDD.
SPID-based Handover Back To HPLMN Switch

Indicates whether to allow SPID-based handovers back to the home public land mobile network (HPLMN). If this parameter is set to TRUE(TRUE), a roaming UE can be handed over to the HPLMN network when it moves back to the coverage of the HPLMN network based on the SPID. If this parameter is set to FALSE(FALSE), this UE cannot be handed over to the HPLMN network based on the SPID. This parameter applies only to LTE FDD and LTE TDD.
Intra-Freq Handover Offset Factor

Indicates the offset of the IntraFreqHoA3Offset parameter for specified-service UEs. The value of the IntraFreqHoA3Offset parameter for specified-service UEs equals the value of the IntraFreqHoA3Offset parameter in the IntraFreqHoGroup MO plus the value of this parameter. If the value of the IntraFreqHoA3Offset parameter for specified-service UEs is less than the lower limit or greater than the upper limit of the IntraFreqHoA3Offset parameter in the IntraFreqHoGroup MO, the lower or upper limit is regarded as the value of IntraFreqHoA3Offset parameter for specified-service UEs.

Specified-service UEs refer to UEs with SPIDs identified and the SpecifiedUserFlag parameter set to SPECSERUSER. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq A2 RSRP Threshold Factor

Indicates the offset of the A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter for specified-service UEs. The value of the A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter for specified-service UEs equals the value of the A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter in the InterFreqHoGroup MO plus the value of this parameter. If the value of the A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter for specified-service UEs is less than the lower limit or greater than the upper limit of the A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter in the InterFreqHoGroup MO, the lower or upper limit is regarded as the value of A3InterFreqHoA2ThdRsrp or InterFreqHoA2ThdRsrp parameter for specified-service UEs.

Specified-service UEs refer to UEs with SPIDs identified and the SpecifiedUserFlag parameter set to SPECSERUSER. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq A2 RSRQ Threshold Factor

Indicates the offset of the A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter for specified-service UEs. The value of the A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter for specified-service UEs equals the value of the A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter in the InterFreqHoGroup MO plus the value of this parameter. If the value of the A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter for specified-service UEs is less than the lower limit or greater than the upper limit of the A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter in the InterFreqHoGroup MO, the lower or upper limit is regarded as the value of A3InterFreqHoA2ThdRsrq or InterFreqHoA2ThdRsrq parameter for specified-service UEs.

Specified-service UEs refer to UEs with SPIDs identified and the SpecifiedUserFlag parameter set to SPECSERUSER. This parameter applies only to LTE FDD and LTE TDD.
Specified User Flag

Indicates whether UEs with the SPID are dedicated to specific services. This parameter is used to implement differentiated processing. Set this parameter according to the operator's policy. The value SPECSERUSER indicates that UEs are dedicated to specific services. The value NONE indicates common UEs. If the SpecifiedCellFlag parameter in the Cell MO is set to SPECSERCELL(Specified service cell), common UEs are transferred out of the cell. This parameter applies only to LTE FDD and LTE TDD.
Idle Mlb Switch

Indicates whether to enable the function of MLB by transferring RRC_IDLE UEs with the specified SPID. If this parameter is set to TRUE(TRUE), the eNodeB can transfer RRC_IDLE UEs with the SPID for MLB. If the parameter is set to FALSE(FALSE), the eNodeB cannot transfer RRC_IDLE UEs with the SPID for MLB. This parameter applies only to LTE FDD and LTE TDD.
Offload Switch

Indicates whether to enable SPID-specific offload.

INTER_FREQUENCY_OFFLOAD_SWITCH: Indicates whether to enable inter-frequency offload. In inter-frequency offload, the eNodeB transfers UEs from a local cell to its inter-frequency neighboring cells to decrease the local cell load without considering the load difference between the local cell and the neighboring cells. The eNodeB can transfer UEs with the specific SPID by inter-frequency offload from the local cell to inter-frequency neighboring cells with load information exchange only if this option is selected. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_OFFLOAD_SWITCH: The eNodeB can transfer UEs with the specific SPID by inter-RAT offload from the local cell to UTRAN or GERAN neighboring cells only if this option is selected. This option applies only to LTE FDD and LTE TDD.
UL Scheduling Priority Coeff

Indicates the coefficient corresponding to the uplink scheduling priority factor configured for UEs with the SPID. The uplink scheduling priority factor for UEs with the SPID equals the value of the UlschPriorityFactor parameter multiplied by the value of this parameter. This parameter is valid only for QCIs 6 to 9. This parameter applies only to LTE FDD and LTE TDD.
DL Scheduling Priority Coeff

Indicates the coefficient corresponding to the downlink scheduling priority factor configured for UEs with the SPID. The downlink scheduling priority factor for UEs with the SPID equals the value of the DlschPriorityFactor parameter multiplied by the value of this parameter. This parameter is valid only for QCIs 6 to 9. This parameter applies only to LTE FDD and LTE TDD.
SPID-based AMBR Limit Factor

Indicates the SPID-based AMBR limit factor for UEs whose rate is limited in DACQ scenarios. This parameter is valid only when the EnhancementCtrlSwitch option of the DacqEnhancementSwitch parameter in the CellAlgoSwitch MO is selected. If this parameter is set to 0, the rate of UEs with this SPID is not limited. If the GUI value is set to 100, the SPID-based AMBR limit factor does not take effect. If this parameter is set to another value, in DACQ scenarios, the actual maximum rate limited in a specific transmission direction at a specific level of UEs with this SPID is equal to the product of the rate threshold in the specific transmission direction at the specific level in the CellDacqCfg MO, the QCI-specific AMBR limit factor in the CellQciPara MO, and SPID-based AMBR limit factor in the SpidCfg MO. This parameter applies only to LTE FDD and LTE TDD.
PUCCH Format 3 for 2CC Indication

Indicates whether UEs of the SPID in the 2CC CA state support PUCCH format 3. If this parameter is set to FALSE, UEs of the SPID in the 2CC CA state do not support PUCCH format 3. If this parameter is set to TRUE, UEs of the SPID in the 2CC CA state support PUCCH format 3. This parameter applies only to LTE FDD and LTE TDD.
SPID-specific Best Effort GBR

Indicates the SPID-specific best-effort GBR.

If this parameter is set to 0, the eNodeB does not assure the best-effort GBR for UEs with a specific SPID.

If this parameter is set to a value greater than 0 and less than 1000, the eNodeB guarantees the SPID-specific best-effort GBR of 1000 Kbit/s for UEs with the specific SPID.

If this parameter is set to a value greater than or equal to 1000, the eNodeB guarantees the SPID-specific best-effort GBR of the configured value for UEs with the specific SPID.

When both the SPID-specific best-effort GBR and QCI-specific best-effort GBR are set to non-zero values and configured for the same UE, the eNodeB performs SPID-specific best-effort GBR for the UE.

This parameter applies only to LTE FDD and LTE TDD.
Handover to GERAN Forbid Switch

Indicates whether to allow handovers to GERAN. Handovers to GERAN are allowed only if this parameter is set to OFF. This parameter applies only to LTE FDD and LTE TDD.
Inter-RAT A2 RSRP Threshold Offset

Indicates the offset relative to the inter-RAT handover A2 RSRP triggering threshold for specified UEs. The UTRAN (or GERAN) A2 RSRP triggering threshold is equal to the sum of this offset, InterRatHoCommGroup.InterRatHoA2ThdRsrp, CnOperatorHoCfg.UtranA2ThdRsrpOffset (or CnOperatorHoCfg.GeranA2ThdRsrpOffset), and CnOperatorQciPara.InterRatA2RsrpThldOffset. The UTRAN (or GERAN) A2 RSRP triggering threshold cannot be greater than the maximum value of InterRatHoCommGroup.InterRatHoA2ThdRsrp or be less than the minimum value of InterRatHoCommGroup.InterRatHoA2ThdRsrp. If the sum value is greater than the maximum value of InterRatHoCommGroup.InterRatHoA2ThdRsrp or less than the minimum value of InterRatHoCommGroup.InterRatHoA2ThdRsrp, the maximum or minimum value of InterRatHoCommGroup.InterRatHoA2ThdRsrp is taken as the UTRAN (or GERAN) A2 RSRP triggering threshold. This parameter applies only to LTE FDD and LTE TDD.
Maximum Number of Carriers

Indicates the maximum number of component carriers (CCs) that can be aggregated for UEs with the specified SPID. If this parameter is set to 0, there is no restriction on the maximum number of CCs. If this parameter is set to a non-zero value, this value is the maximum number. This parameter applies only to LTE FDD and LTE TDD.
Uplink MinGBR

Indicates the uplink minimum guaranteed bit rate (GBR) for UEs with the SPID. The uplink minimum GBR for UEs with the SPID takes effect only if this parameter is not set to 0. If this parameter is set to 0, the QCI-specific uplink minimum GBR takes effect. This parameter applies only to LTE FDD and LTE TDD.
SPID-Specific UE Inactivity Timer

Indicates the length of the UE inactivity timer for UEs with the SPID. If the eNodeB detects that such a UE has neither received nor sent data for a period exceeding the value of this parameter, the eNodeB releases the RRC connection for the UE. If this parameter is set to 0, the UE inactivity timer is not used. If this parameter is set to 65535, this parameter does not take effect and the UeInactiveTimerForQci parameter in the QciPara MO takes effect. If the parameter setting is changed, the change applies only to UEs that access the network afterwards. This parameter applies only to LTE FDD and LTE TDD.
SPID Algorithm Switch

Indicates whether to enable SPID-related algorithms.

CA_IDLE_MLB_SWITCH: Assume that the SpidCfg.IdleMlbSwitch parameter is set to TRUE. If this option is selected, idle mode MLB takes effect for CA-capable UEs of the SPID. If this option is deselected, idle mode MLB does not take effect for CA-capable UEs of the SPID. This option does not take effect if the SpidCfg.IdleMlbSwitch parameter is set to FALSE. This parameter applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: If this option is selected, the eNodeB triggers fast-moving-UE smart carrier selection for UEs of this SPID. If this option is deselected, the eNodeB does not trigger fast-moving-UE smart carrier selection for UEs of this SPID. This option applies only to LTE FDD and LTE TDD.
