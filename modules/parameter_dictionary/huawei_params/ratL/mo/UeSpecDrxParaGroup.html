UeSpecDrxParaGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-UeSpecDrxParaGroup

Description

A UeSpecDrxParaGroup MO consists of a group of DRX parameters for specific UEs. Some types of UEs can use specific groups of DRX parameters based on traffic models of the UEs and request the eNodeB to deliver these parameters to meet the requirements of different traffic models.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
DRX Parameter Group Index

Indicates the index of a DRX parameter group. This parameter applies only to LTE FDD and LTE TDD.
DRX Parameter Group Status

Indicates whether to enable the DRX parameter group. When a UE requests the DRX parameter group, the eNodeB can deliver the DRX parameter group to the UE only if this parameter is set to ENABLE. This parameter applies only to LTE FDD and LTE TDD.
On Duration Timer

Indicates the length of the On Duration Timer. Because of the impact of CQI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. This parameter applies only to LTE FDD and LTE TDD.
DRX Inactivity Timer

Indicates the length of the DRX Inactivity Timer. This parameter applies only to LTE FDD and LTE TDD.
DRX Retransmission Timer

Indicates the length of the DRX Retransmission Timer. This parameter applies only to LTE FDD and LTE TDD.
Long DRX Cycle

Indicates the length of the long DRX cycle. This parameter applies only to LTE FDD and LTE TDD.
Short-Cycle DRX Supported Indication

Indicates whether to enable or disable short DRX cycles. This parameter applies only to LTE FDD and LTE TDD.
Short DRX Cycle

Indicates the length of the short DRX cycle. According to 3GPP specifications, the length of a long DRX cycle must be an integer multiple of that of a short DRX cycle. In addition, the actual value of LongDrxCycle assigned to a UE may be less than the configured value because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter. Therefore, the actual value of ShortDrxCycle assigned to a UE may be less than the configured value. This parameter applies only to LTE FDD and LTE TDD.
DRX Short Cycle Timer

Indicates the length of the DRX Short Cycle Timer. If this parameter is set to a large value, a UE for which short DRX cycles are enabled stays in short-cycle DRX for a long time. For details, see section 5.7 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.
