CaMgtCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CaMgtCfg

Description

A CaMgtCfg MO consists of parameters related to carrier management. The parameters are used to measure the channel quality of SCells. If the measurement results meet the corresponding conditions, the UE sends a measurement report.

Effective Scenario

Immediately

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Carrier Aggregation A2 RSRP threshold

Indicates the RSRP threshold for CA event A2. When the measured RSRP of an SCell is lower than this threshold, event A2 is reported. This parameter applies only to LTE FDD and LTE TDD.
Carrier Aggregation A4 RSRP threshold

Indicates the RSRP threshold for CA event A4. When the measured RSRP of a candidate SCell is greater than this threshold, event A4 is reported. This parameter applies only to LTE FDD and LTE TDD.
Carrier Management Switch

Indicates whether to enable carrier management. If this parameter is set to ON, the eNodeB deactivates SCells for a CA UE when the traffic volume of the CA UE is small or the channel quality of the SCells is poor. If this parameter is set to OFF, an SCell is always active after being activated, unless a radio link failure (RLF) is detected on the SCell. This parameter applies only to LTE FDD and LTE TDD.
CA Active Buffer Length Threshold

Indicates the buffer length threshold used to evaluate the activation of an SCell. The SCell can be activated for a CA UE only when its buffered data on the eNodeB exceeds this threshold. This parameter applies only to LTE FDD and LTE TDD.
CA Deactive Buffer Length Threshold

Indicates the buffer length threshold used to evaluate the deactivation of an SCell. The SCell can be deactivated for a CA UE only when its buffered data on the eNodeB is less than this threshold. This parameter applies only to LTE FDD and LTE TDD.
CA Active Buffer Delay Threshold

Indicates the buffer delay threshold used to evaluate the activation of an SCell. The SCell can be activated for a CA UE only when its buffer delay on the eNodeB exceeds this threshold. This parameter applies only to LTE FDD and LTE TDD.
CA Deactive Throughput Threshold

Indicates the throughput threshold used to evaluate the deactivation of an SCell. The SCell can be deactivated for a CA UE only when its throughput is less than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
Carrier Aggregation A6 Offset

Indicates the offset for CA event A6. This offset is the difference between the quality of a neighboring cell and that of an SCell. A larger value indicates that a neighboring cell must have a better quality than the SCell before event A6 can be reported. This parameter applies only to LTE FDD and LTE TDD.
SCell Aging Time

Indicates the length of aging time of the SCells that are dynamically configured for CA UEs in a cell in adaptive CA configuration scenarios. If there is no carrier aggregation between an SCell and the PCell within the aging time, the eNodeB cancels the association between the SCell and the PCell. This parameter applies only to LTE FDD and LTE TDD.
CA A6 Report Amount

Indicates the number of periodic measurement reports sent after CA event A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CA A6 Report Interval

Indicates the interval between periodic measurement reports that are sent after CA event A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SCC Deactive CQI Threshold

Indicates the Release-8-equivalent CQI threshold used to evaluate the deactivation of an SCell for a CA UE based on channel quality. If the channel quality of the CA UE is lower than that corresponding to the CQI threshold in single-codeword transmission, the eNodeB deactivates the SCell for the UE. If this parameter is set to 0, the eNodeB does not deactivate SCells based on channel quality. This parameter specifies the CQI threshold for deactivating the SCell that the local cell acts as, and takes effect only when the CarrierMgtSwitch parameter for the associated PCell is set to ON. This parameter applies only to LTE FDD and LTE TDD.
SCC Configuration Interval

Indicates the minimum interval after which the eNodeB attempts to configure an SCell again for a CA UE. The interval at which the eNodeB attempts to configure an SCell again for a CA UE must be greater than this value. The eNodeB makes the attempt only if the traffic volume of the UE always meets the SCell activation condition throughout a certain time and the eNodeB fails to configure an SCell for the UE. This parameter applies only to LTE FDD and LTE TDD.
Cell Level CA Algorithm Switch

Indicates whether to enable cell-level CA. This parameter provides the following options:

CaDl3CCSwitch: Indicates whether to enable aggregation of three component carriers in the downlink. This type of aggregation works only if this option is selected and at least two SccFreqCfg MOs or three CaGroupCell MOs are configured. This option applies only to LTE FDD and LTE TDD.

CaUl2CCSwitch: Indicates whether to enable aggregation of two component carriers in the uplink. This type of aggregation works only if this option is selected and at least one SccFreqCfg MO or two CaGroupCell MOs are configured. This option applies only to LTE FDD and LTE TDD.

CaDl4CCSwitch: Indicates whether to enable aggregation of four component carriers in the downlink. This type of aggregation works only if this option is selected and at least three SccFreqCfg MOs or four CaGroupCell MOs are configured. This option applies only to LTE FDD and LTE TDD.

InterFddTddCaSwitch: Indicates whether to enable aggregation of TDD and FDD component carriers. This type of aggregation works only if this option is selected. In a combination of FDD and TDD cells for CA, either an FDD cell or a TDD cell can act as the PCell. This option applies only to LTE FDD and LTE TDD.

2CCDlCaEnhanceSwitch: Indicates whether to enable enhanced DL ACK demodulation when two component carriers are aggregated. If this option is selected, DL ACK demodulation is enhanced, increasing the downlink throughput of UEs using CA. However, there might be an impact on the uplink, because PUCCH format 3 increases the UE transmit power. If this option is deselected, PUCCH format 1b with channel selection is used. As a result, a large number of bit errors occur, decreasing downlink throughput of CA UEs. This option applies only to LTE FDD and LTE TDD.

CaDl5CCSwitch: Indicates whether to enable aggregation of five component carriers in the downlink. This type of aggregation works only if this option is selected and at least four SccFreqCfg MOs or five CaGroupCell MOs are configured. This option applies only to LTE FDD and LTE TDD.

CaInstantlyJudgeSwitch: Indicates whether to use instantaneous millisecond-level values or filtered second-level values to evaluate SCell activation based on traffic volume. If this option is selected, instantaneous values are used. If this option is deselected, filtered values are used. This option applies only to LTE FDD and LTE TDD.

LaaCaDlSwitch: Indicates whether to enable downlink licensed-assisted access (LAA) CA. Downlink LAA CA is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

FddTddCaUlServiceFirstSwitch: Indicates whether to prioritize uplink services for UEs in both uplink and downlink CA states. When a UE performs CA in both the uplink and downlink in a cell, the eNodeB preferentially guarantees uplink throughput of the UE if this option is selected. If this option is deselected, the benefit cannot be obtained. This option applies to FDD-only CA, TDD-only CA, and FDD+TDD CA. This option applies only to LTE FDD and LTE TDD.

RcvA2CfgSccSwitch: Indicates whether the base station allows SCell configuration and PCC anchoring for CA UEs after receiving A2 measurement reports from the UEs. If this option is selected, the base station can perform SCell configuration and PCC anchoring after receiving an A2 measurement report from a CA UE. If this option is deselected, the base station cannot perform SCell configuration and PCC anchoring after receiving an A2 measurement report from a CA UE. This option applies only to LTE FDD and LTE TDD.

Dc3cSwitch: Indicates whether to enable dual connectivity (DC) in the option-3C architecture. If this option is selected, DC in the option-3C architecture is enabled, and the local cell can serve as a PCell or PSCell in DC. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

MultiCarrierFlexCaSwitch: Indicates whether to enable flexible CA. Flexible CA is enabled in the cell only if this option is selected. This option takes effect only in frequency-based CA. This option applies only to LTE FDD and LTE TDD.

NackDtxIdentifySwitch: Indicates whether the eNodeB regards NACK/DTX confusions as DTXs or NACKs during PUSCH demodulation. If this option is selected, the eNodeB regards NACK/DTX confusions as DTXs. If this option is deselected, the eNodeB regards NACK/DTX confusions as NACKs. This option applies only to LTE FDD and LTE TDD.

CaDl2CCExtSwitch: Indicates whether to enable downlink 2CC CA to an extended bandwidth. Downlink FDD 2CC CA can reach an aggregated bandwidth between 20 MHz and 40 MHz (inclusive) and downlink TDD 2CC CA can reach an aggregated bandwidth between 30 MHz and 40 MHz (inclusive) only if this option is selected. This option must be selected for each cell before the cells can be aggregated to the extended bandwidth. This option takes effect only in adaptive CA, which is based on frequencies. This option applies only to LTE FDD and LTE TDD.

CaDl3CCExtSwitch: Indicates whether to enable downlink 3CC CA to an extended bandwidth. Downlink FDD 3CC CA can reach an aggregated bandwidth between 40 MHz and 60 MHz (inclusive) only if this option is selected. This option must be selected for each cell before the cells can be aggregated to the extended bandwidth. This option takes effect only in adaptive CA, which is based on frequencies. This option applies only to LTE FDD.

VolteSupportCaInterFreqMeasSw: Indicates whether to enable the following functions for VoLTE UEs: SCell configuration based on inter-frequency measurements, PCC anchoring for RRC_CONNECTED UEs based on inter-frequency measurements, and PCC anchoring for RRC_CONNECTED UEs based on virtual grids. For CA-capable UEs running VoLTE services, if this option is selected, then the eNodeB can deliver inter-frequency measurement configurations to the UEs for SCell configuration or PCC anchoring; alternatively, the eNodeB can initiate PCC anchoring based on the results of prediction using virtual grids. For CA-capable UEs running VoLTE services, if this option is deselected, then the eNodeB neither delivers inter-frequency measurement configurations to the UEs for SCell configuration or PCC anchoring nor initiates PCC anchoring based on the results of prediction using virtual grids. This option applies only to LTE FDD and LTE TDD.

DlMassiveCaSwitch: Indicates whether to enable downlink massive CA. If this option is selected, this function works when more than five candidate SCCs are configured by using the SccFreqCfg MO. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

CaEnhAperiodicCqiRptSwitch: Indicates the aperiodic CQI reporting mechanism in CA. If this option is selected, enhanced aperiodic CQI reporting is used by CA UEs whose SCells have been activated to accompany the local cell (acting as the PCell) and PCell or SCell uses closed-loop MIMO. In addition, CA UEs with the simultaneousAckNackAndCQI-Format3-r11 IE set to "False" are not configured to perform periodic CQI reporting of SCells that use closed-loop MIMO. If this option is deselected, this function is disabled. If both this option and the EnAperiodicCqiRptSwitch option are selected for the local cell, this option overrides the EnAperiodicCqiRptSwitch option if this cell acts as an SCell, and the EnAperiodicCqiRptSwitch option overrides this option if this cell acts as a PCell. If both this option and the SccCqiRptEnhancedSwitch option are selected for the local cell, this option overrides the SccCqiRptEnhancedSwitch option. This option applies only to LTE FDD.

SpectrumCoordinationSwitch: Spectrum coordination is enabled only if this option is selected. With spectrum coordination enabled, PCell changes are triggered based on uplink quality. This option applies only to LTE FDD and LTE TDD.

VolteUlCaControlSwitch: If this option is selected, the eNodeB is not allowed to configure uplink TDD SCells for CA UEs that treat FDD cells as their PCells and are running VoLTE services. In addition, for CA UEs in the FDD+TDD CA state configured with uplink TDD SCells, the eNodeB removes the uplink TDD SCells for the CA UEs before VoLTE services can be set up. If this option is deselected, the eNodeB is allowed to configure uplink TDD SCells for CA UEs that treat FDD cells as their PCells and are running VoLTE services. This option applies only to LTE FDD.

CaDataAllocEnhancementSwitch: Indicates whether to enable enhanced data distribution between carriers aggregated for CA. When the local cell serves as an SCell, it can carry RLC-layer retransmitted data only if this option is deselected. This option applies only to LTE TDD.

McpttVoiceCaSwitch: Indicates whether UEs running PTT services can perform inter-frequency measurements and whether NSA DC UEs running PTT services can perform NR frequency measurements. The measurements are used for SCell configuration or "PCC anchoring for RRC_CONNECTED UEs" for former UEs and used for SCG configuration or triggering NSA DC PCC anchoring for latter UEs. The eNodeB delivers inter-frequency measurement configurations to CA-capable UEs running PTT services and delivers NR frequency measurement configurations to NSA-DC-capable UEs running PTT services only if this option is selected. The measurements are used for SCell configuration or triggering PCC anchoring for former UEs and used for SCG configuration or triggering NSA DC PCC anchoring for latter UEs. This option applies only to LTE FDD and LTE TDD.

WbbCaMultiCarrierCoordSw: Indicates whether to enable multi-carrier coordination for service-specified CA UEs. If this option is selected, a service-specified CA UE can be handed over to an MBB carrier when its downlink signal quality becomes poor. When the PCell is an MBB cell, downlink data of RRNs and service-specified UEs are scheduled only in SCells. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

CaRouteNumberExtensionSwitch: Indicates the maximum number of cells that a cell can be associated with for CA. If this option is selected, the cell can be associated with up to 48 other cells. If this option is deselected, the cell can be associated with up to 24 other cells. This option applies only to LTE FDD and LTE TDD.

CaUlSmartSelectionSwitch: Indicates whether the eNodeB considers the downlink load during uplink carrier selection for CA. If this option is selected, the downlink load is considered. If this option is deselected, uplink carriers are selected randomly. This option applies only to LTE TDD.
UL CA Time To Trigger

Indicates the time-to-trigger for activating an SCell for a UE in the uplink. If the uplink traffic volume of a CA UE is greater than the ActiveBufferLenThd parameter value throughout the period specified by the UlCaActiveTimeToTrigger parameter, the eNodeB initiates the SCell activation procedure. This parameter applies only to LTE FDD and LTE TDD.
Measurement Cycle of SCell

Indicates the sampling period of the radio resource measurement on SCells by CA UEs when the SCells are deactivated. If the sampling period is not configured, the measurement configuration messages that the eNodeB sends to CA UEs do not contain the IE measCycleSCell. This parameter applies only to LTE FDD and LTE TDD.
Cell Maximum PCC Number

Indicates the maximum number of UEs that are allowed to treat the cell as their PCell. If the number of CA UEs that treat the cell as their PCell has reached the parameter value, no more CA UEs can treat the cell as their PCell. A smaller value of this parameter results in fewer CA UEs that are allowed to treat the cell as their PCell. If this parameter is set to 0, the eNodeB cannot configure the cell as a PCell for any CA UE but it can configure the cell as an SCell for a CA UE. If the total value of this parameter for all cells on a BBP exceeds the UE number specification of the BBP, the specification overrides the total value. This parameter applies only to LTE FDD and LTE TDD.
Offload Threshold of PCC User Number

Indicates the threshold used to determine the PCell high load state for cells. This threshold is used for load-based PCC anchoring and is expressed as a percentage of UEs that treat the cell as their PCell. If the percentage is greater than the threshold, the cell is in the PCell high load state. Otherwise, the cell is in the PCell low load state. This parameter applies only to LTE FDD and LTE TDD.
A1 RSRP Threshold for Enhanced PCC Anchor

Indicates the RSRP threshold for event A1 used in enhanced PCC anchoring for RRC_CONNECTED UEs. Event A1 is reported if the measured RSRP value exceeds the threshold. This parameter applies only to LTE FDD and LTE TDD.
Additional Measurement Configuration

Indicates whether the eNodeB can instruct UEs to perform additional measurements to provide more samples for collecting statistics. During Auto Neighbor Group Configuration (ANGC) for CA, if the number of collected samples is insufficient, the eNodeB instructs UEs to perform additional measurements so that the number of samples may reach the preset quantity threshold.

If this parameter is set to ALLOWED, the eNodeB instructs UEs to perform additional measurements in an extension period that automatically starts when the number of samples in a measurement period does not reach the preset target. If this parameter is set to NOT_ALLOWED, the eNodeB does not instruct UEs to perform additional measurements. This parameter applies only to LTE FDD and LTE TDD.
Blind Scell Sample Number

Indicates the minimum required number of A4 and A5 report samples for starting coverage evaluation during ANGC for CA. The eNodeB starts coverage evaluation only if the number of samples reaches or exceeds the value of this parameter. Based on the samples, the eNodeB will calculate the coverage overlap proportion and adds, changes, or clears blind SCell configuration flag settings for neighboring cells. This parameter applies only to LTE FDD and LTE TDD.
Optimization Mode

Indicates the working mode of ANGC for CA.

If this parameter is set to FREE, the eNodeB automatically adds, changes, or clears blind SCell configuration flag settings for neighboring cells. If this parameter is set to CONTROLLED, the eNodeB reports the optimization advice on the flag settings to the MAE, and operators determine whether to take the advice. This parameter applies only to LTE FDD and LTE TDD.
Sleep Period

Indicates the sleep period during which ANGC for CA stops working after one round of statistics collection and configuration. The function resumes after the sleep period if the network topology changed during the sleep period. If this parameter is set to 65535, ANGC for CA does not enter the sleep period but periodically works. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This option applies only to LTE FDD and LTE TDD.
Statistic Period

Indicates the measurement period of ANGC for CA. If the number of samples collected in a period meets the requirement, the eNodeB calculates the coverage overlap proportion and adds, changes, or clears blind SCell configuration flag settings for neighboring cells within the period. If the number of samples collected in the period does not meet the requirement, the eNodeB automatically extends a second period and performs accumulated statistics collection. To ensure the work efficiency of the algorithm, the eNodeB extends only one period for sample counting.

A shorter measurement period results in faster addition, changes, or clearing of blind SCell configuration flag settings for neighboring cells. A longer measurement period results in the opposite effects. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.
Relaxed Backhaul SCC Deactive CQI Threshold

Indicates the Release-8-equivalent CQI threshold used to evaluate the deactivation of an SCell for a CA UE based on channel quality in relaxed-backhaul-based CA. If the channel quality of the CA UE is lower than that corresponding to the CQI threshold in single-codeword transmission, the eNodeB deactivates the SCell for the UE. If this parameter is set to 0, the eNodeB does not deactivate SCells based on channel quality. This parameter specifies the CQI threshold for deactivating the SCell that the local cell acts as, and takes effect only when the CarrierMgtSwitch parameter for the associated PCell is set to ON. This parameter applies only to LTE FDD and LTE TDD.
Relaxed Backhaul Ca Max Component Carrier Number

Indicates the maximum number of component carriers (CCs) that can be aggregated in relaxed backhaul scenarios. If this parameter is set to DL_MASSIVE_CA, the maximum number is eight. This parameter value takes effect only in LTE FDD. This parameter applies only to LTE FDD and LTE TDD.
Distribute Cloud BB CA Max Component Carrier Number

Indicates the maximum number of component carriers (CCs) that can be aggregated in the distributed Cloud BB architecture. If this parameter is set to DL_MASSIVE_CA, the maximum number is eight. This parameter value takes effect only in LTE FDD. This parameter applies only to LTE FDD and LTE TDD.
CA A2 Time To Trigger

CA A6 Time To Trigger

CA A4 Time To Trigger

Indicates the time-to-trigger for CA event A4. If the measurement result meets the entering condition of event A4 throughout the time specified by this parameter, the UE reports CA event A4. This parameter applies only to LTE FDD and LTE TDD.
SCC Quiet Time

Indicates the SCC unavailability duration. Some multi-mode UEs (for example, SRLTE/SLTE UEs) periodically stop receiving signals of SCells but detect signals of another RAT in CA scenarios. This causes an increase in the number of residual erroneous blocks in the SCells, triggering SCell deactivation. This parameter is used to ensure that the SCells are not deactivated when such UEs are detecting signals of another RAT in CA scenarios.

The parameter value must be greater than the duration for such UEs to detect signals of another RAT. If this parameter is set to 0, the eNodeB triggers SCell deactivation once the eNodeB detects an abnormal level of residual erroneous blocks. If this parameter is set to a value greater than 0, the eNodeB does not trigger SCell deactivation because of residual erroneous blocks within the duration. This parameter applies only to LTE FDD and LTE TDD.
FDD TDD Relaxed BH CA DL Max CC Num

Indicates the maximum number of FDD and TDD component carriers (CCs) that can be aggregated in the downlink for FDD+TDD CA in relaxed backhaul scenarios. If this parameter is set to DL0CC, relaxed-backhaul-based downlink FDD+TDD CA is not supported. If this parameter is set to DL2CC, the maximum number is two. If this parameter is set to DL_MASSIVE_CA, the maximum number is eight. This parameter value takes effect only in LTE FDD. This parameter applies only to LTE FDD and LTE TDD.
FDD TDD CA UL Max CC Number

Indicates the maximum number of FDD and TDD component carriers that can be aggregated in the uplink. FDD+TDD CA in the uplink is not supported when this parameter is set to 0CC. If this parameter is set to 2CC(2CC), the maximum number is two. This parameter must be configured only for the PCell. This parameter applies only to LTE FDD and LTE TDD.
FDD TDD CA DL Max CC Number

Indicates the maximum number of FDD and TDD component carriers (CCs) that can be aggregated in the downlink. If this parameter is set to 2CC, the maximum number is two. If this parameter is set to DL_MASSIVE_CA, the maximum number is eight. The value DL_MASSIVE_CA takes effect only in LTE FDD. This parameter applies only to LTE FDD and LTE TDD.
LAA Carrier Aggregation A1 RSRP Threshold

Indicates the RSRP threshold for event A1 of the PCell in LAA CA. If the measured RSRP value exceeds this threshold, an A1 measurement report will be sent. This parameter applies only to LTE FDD.

Disuse statement: This parameter will be removed in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.
Anchor Policy for FDD and TDD 2CC

Indicates whether to prioritize an FDD or TDD CC in PCC anchoring for FDD+TDD 2CC CA. For FDD+TDD 2CC CA, if a TDD CC serves as the PCC for a UE, the UE can obtain the gains brought by downlink beamforming, increasing downlink UE throughput. Therefore, it is recommended that this parameter be set to TDD(TDD). If this parameter is set to NULL(NULL), FDD and TDD CCs are not prioritized in PCC anchoring for FDD+TDD 2CC CA. This parameter applies only to LTE FDD and LTE TDD.
Anchor Policy for FDD and TDD Multi CC

Indicates whether to prioritize an FDD or TDD CC in PCC anchoring for FDD+TDD multi-CC CA, where the number of CCs is greater than or equal to three. For FDD+TDD multi-CC CA, if a TDD CC serves as the PCC for a UE, information about downlink data is limited, decreasing downlink throughput. Therefore, it is recommended that this parameter be set to FDD(FDD). If this parameter is set to NULL(NULL), FDD and TDD CCs are not prioritized in PCC anchoring for FDD+TDD multi-CC CA. This parameter applies only to LTE FDD and LTE TDD.
UL Heavy Traffic MLB Optimize Switch

Indicates whether to trigger an uplink traffic-based blind handover of an FDD+TDD CA UE for MLB from its TDD PCell to an FDD cell that is acting as one of its SCells. This parameter applies only to LTE TDD.
SCC Reactivation Time

Indicates the minimum interval to reactivate an SCell based on the traffic volume after the eNodeB deactivates the SCell based on the CQI or RBLER. The recommended value is 5s for a commercial network. In a benchmark test, if the channel quality is occasionally poor, a small value, for example, 1s is recommended. This can increase the duration within which the SCell stays active. This parameter applies only to LTE FDD and LTE TDD.
FDD and TDD Relaxed Backhaul CA UL Max CC Num

Indicates the maximum number of carriers that can be aggregated in the uplink for FDD+TDD CA in relaxed backhaul scenarios. Relaxed-backhaul-based FDD+TDD CA in the uplink is not supported when this parameter is set to 0CC. The maximum number is two when this parameter is set to 2CC. This parameter applies only to LTE FDD and LTE TDD.
Relaxed Backhaul CA UL Max CC Num

Indicates the maximum number of carriers that can be aggregated in the uplink for CA in relaxed backhaul scenarios. Relaxed-backhaul-based CA in the uplink is not supported when this parameter is set to 0CC. The maximum number is two when this parameter is set to 2CC. This parameter needs to be configured only for the PCell. This parameter applies only to LTE FDD and LTE TDD.
CA Traffic Direction Preference

Indicates the policy according to which the eNodeB selects band combinations when configuring SCells for CA. If this parameter is set to DL_FIRST, the eNodeB preferentially selects a band combination with the maximum downlink CA capability when a candidate SCell is a multi-band cell. This band combination may not support uplink CA. If this parameter is set to UL_FIRST, the eNodeB preferentially selects a band combination supporting uplink CA when a candidate SCell is a multi-band cell, so that an uplink SCell can be configured for the UE. If this parameter is set to UL_CA_COMBINATION_FIRST, the eNodeB preferentially selects the serving cell combination with the strongest uplink capability in intelligent selection of serving cell combinations. This parameter applies only to LTE FDD and LTE TDD.
CA and MIMO Priority Strategy Switch

Indicates whether CA or MIMO takes precedence over each other for CA- and MIMO-capable UEs that select between CA and MIMO.

CA_PRIOR: CA takes precedence over MIMO.

MIMO_PRIOR: High-order MIMO takes precedence over CA.

PEAK_RATE_PRIOR: The feature providing the highest peak data rate takes precedence over the other feature.

This parameter applies only to LTE FDD and LTE TDD.
A1 RSRP Threshold for Enhanced SCC Selection

Indicates the RSRP threshold of event A1 related to A1-based enhanced SCell selection. A1-based enhanced SCell selection is disabled if this parameter is set to -40. Event A1 is reported if the measured RSRP value exceeds the threshold. This parameter applies only to LTE FDD and LTE TDD.
Fast SCell Selection After SCell Removal

Indicates whether to start SCell selection immediately after all SCells of a UE are removed based on coverage. The immediate selection is enabled only if this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.
SRS-based Low Efficiency UE SINR Threshold

Indicates the SINR threshold for SRSs of UEs. This threshold is used to determine whether a UE is a low-efficiency UE. If this parameter is set to a value other than 255, the eNodeB checks the SINR of a UE's SRSs to determine whether the UE is a low-efficiency UE when FDD+TDD CA is performed for the UE with an LTE TDD cell serving as the PCell. If the SINR of SRSs of the UE is less than this threshold, the eNodeB considers the UE as a low-efficiency UE and changes the LTE FDD cell on an SCC to be the PCell. If this parameter is set to 255, the eNodeB does not perform these operations in such scenarios. This parameter applies only to LTE TDD.
RSRP Offset

Indicates the offset used to evaluate whether to trigger RSRP-based PCC and SCC switchover. RSRP-based PCC and SCC switchover is disabled if this parameter is set to 0. This parameter applies only to LTE FDD and LTE TDD.
Spectrum Coordination SINR Threshold

Indicates the uplink SINR threshold used in scheduling for triggering spectrum coordination. If the uplink SINR used in scheduling of a serving cell is less than this threshold, PCell change for spectrum coordination is triggered. This parameter applies only to LTE FDD and LTE TDD.
Min DL Average To-Be-Scheduled UE Number

Indicates the minimum allowed number of UEs to be scheduled in the downlink in the formula that flexible CA and Multi-Carrier Unified Scheduling use for evaluating the cell capability. If this parameter is set to 0, the eNodeB does not consider the average number of UEs to be scheduled in the downlink when calculating the cell capability. If this parameter is set to 255, the eNodeB uses the eNodeB non-linear fitting result as the average number of UEs to be scheduled in the downlink used in the formula. If this parameter is set to another value, the number of UEs to be scheduled in the downlink used in the formula is the larger one between the actual number of UEs to be scheduled in the downlink and the parameter value. This parameter applies only to LTE FDD and LTE TDD.
Smart CA PCC Anchoring Hysteresis

Indicates the minimum amount of gain required by PCC anchoring for intelligent selection of serving cell combinations. When evaluating a candidate serving cell combination that will trigger PCC anchoring, this intelligent selection function selects this combination only if the amount of gain brought by the PCC anchoring exceeds the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.
SCell Heavy Load UE Number Threshold

Indicates the threshold of the number of UEs for identifying heavy-load cells. This threshold is used to determine whether to activate a massive MIMO SCell based on the cell load. If the average number of UEs that can be paired in a massive MIMO cell exceeds this threshold, the eNodeB determines that the cell is heavily loaded. In this case, this massive MIMO cell cannot be activated as an SCell for CA UEs without an uplink SCell. If the average number of UEs that can be paired in a massive MIMO cell is less than or equal to the larger value between 0 and this threshold subtracted by 20, the eNodeB determines that the cell is lightly loaded. In this case, this massive MIMO cell can be activated as an SCell for CA UEs without an uplink SCell. The value 65535 indicates that this parameter does not take effect. This parameter applies only to LTE TDD.
CA Preallocation SCC UE Count

Indicates the minimum number of UEs in the SCell for massive MIMO cell preallocation pairing in CA scenarios. If this parameter is set to 0, preallocation pairing is disabled. If this parameter is set to a value other than 0, preallocation pairing is enabled. This parameter applies only to LTE TDD.
Massive MIMO Gain Coefficient

Indicates the gain coefficient for massive MIMO cells. After smart carrier selection takes effect, the eNodeB multiplies the capability of a candidate massive MIMO cell by the value of this parameter when it calculates this capability for a UE that can benefit from UE pairing for MU-MIMO. The function of this parameter does not take effect when this parameter is set to 10, which indicates an actual gain coefficient 1. This parameter applies only to LTE FDD and LTE TDD.
SCell Not Active UE Number Threshold

Indicates whether to prohibit SCell activation when the specified cell is heavily loaded. When the number of UEs in the cell is greater than the load threshold, the eNodeB determines that the cell is in the high load state and does not activate this cell as an SCell for any new CA UE. If this parameter is set to 0, this function is disabled. If this parameter is set to a value other than 0, this parameter indicates the load threshold. When the number of UEs in the cell (including non-CA UEs, CA UEs that treat the cell as their PCell, and CA UEs that treat this cell as their SCell and have this SCell activated) is greater than this parameter value, the eNodeB no longer activates this cell as an SCell for any CA UE. When the number of UEs in the cell is not greater than this parameter value, the eNodeB can activate this cell as an SCell for CA UEs. The eNodeB measures the number of UEs in the cell every second. When the number of UEs is a little smaller than this threshold, simultaneous SCell activation for a number of CA UEs will cause the number of UEs in the cell to exceed this threshold. This parameter applies only to LTE FDD and LTE TDD.
Heavy-Load UE Count Thld for SCell Config

Indicates the UE number threshold for determining whether a cell is a high-load cell, the result of which is used to evaluate SCell configuration for CA UEs. If the number of UEs in a cell exceeds this threshold, the eNodeB determines that the cell is a high-load cell. If this cell is a massive MIMO cell, it cannot be configured as an SCell for CA UEs for which this SCell does not work in the uplink or for CA UEs that cannot be paired. If this cell is a common cell, it cannot be configured as an SCell. If the number of UEs in a cell is less than or equal to the value of this parameter minus 20, the eNodeB determines that the cell is lightly loaded and allows the cell to be configured as an SCell. If the value of this parameter minus 20 is less than 0, 0 is used during the evaluation instead. For massive MIMO cells, the number of UEs that can be paired in a cell is used in the evaluation. For a common cell, the total number of UEs in the cell is used in the evaluation. The value 65535 indicates that this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
CA SCC Freq Measurement Optimization Switch

Indicates gap-assisted measurement parameters is required to be configured during the measurement of frequencies configured as CA SCCs.

When this parameter is set to ON, gap-assisted measurement parameters are not configured during the measurement of frequencies configured as CA SCCs. If this parameter is set to OFF, gap-assisted measurement parameter needs to be configured during the measurement of frequencies configured as CA SCCs.

This parameter applies only to LTE FDD and LTE TDD.
VoLTE CA A2 RSRP Thld

Indicates the RSRP threshold for event A2 of the PCell for VoLTE UEs. When the RSRP of the PCell measured by a UE is less than this threshold, event A2 is reported.

If this parameter is set to 0, SCell configuration and PCC anchoring are disabled for VoLTE UEs, regardless of the VolteSupportCaInterFreqMeasSw setting of the CellCaAlgoSwitch parameter in the CaMgtCfg MO.

If this parameter is set to 255, SCell configuration and PCC anchoring for VoLTE UEs are controlled by the VolteSupportCaInterFreqMeasSw option of the CellCaAlgoSwitch parameter in the CaMgtCfg MO.

If this parameter is set to a value in the range from -140 to -43, then the following takes place: If the PCell RSRP of a VoLTE UE is less than or equal to the value of this parameter, the UE reports VoLTE CA event A2. In this case, SCell configuration and PCC anchoring are disabled for the VoLTE UE, regardless of the VolteSupportCaInterFreqMeasSw setting of the CellCaAlgoSwitch parameter in the CaMgtCfg MO. Otherwise, SCell configuration and PCC anchoring for the VoLTE UE are controlled by the VolteSupportCaInterFreqMeasSw option of the CellCaAlgoSwitch parameter in the CaMgtCfg MO.

This parameter applies only to LTE FDD and LTE TDD.
Min Rsv Route Number for CA with LAA

Indicates the minimum number of routes between the cell and LAA cells for CA.

If this parameter is set to 0, routes are not reserved for LAA cells.

If this parameter is set to a non-zero value, this value is the number of routes reserved for LAA cells. This number should not exceed the maximum number of routes supported by the cell.

This parameter applies only to LTE FDD and LTE TDD.
High Load Cell Type Not As SCell

Indicates which type of high-load cells cannot be configured as SCells. If this parameter is set to MASSIVE_MIMO_CELL, a high-load massive MIMO cell cannot be configured as an SCell when this massive MIMO cell cannot be configured as an uplink SCell for a CA UE or the CA UE cannot be paired with other UEs in this massive MIMO cell. If this parameter is set to NORMAL_CELL, high-load common cells (except LAA cells) cannot be configured as SCells. If this parameter is set to ALL_CELL, both of the MASSIVE_MIMO_CELL and NORMAL_CELL values take effect. This parameter applies only to LTE FDD and LTE TDD.
SCC Detection CQI Decrease Step

Indicates the CQI decrease step used during SCell deactivation evaluation. If this parameter is set to a non-zero value, the outer-loop CQI adjustment value for CQI decrease is further extended by the value of this parameter. If this parameter or the CaMgtCfg.SccQuietTime parameter is set to 0, the further decrease does not take effect. This parameter applies only to LTE FDD and LTE TDD.
