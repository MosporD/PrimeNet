MMEDomainName

+-NE
  +-eNodeBFunction
    +-MMEDomainName

Description

An MMEDomainName MO consists of parameters related to an MME domain name. Using the domain name, the eNodeB can query the connected DNS server for the IP address of the relevant MME.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CnOperator MO:
    • The CnOperator MO referenced by CnOperatorId in a MMEDomainName MO must be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD MMEDOMAINNAME

Use this command to add an MME domain name.
LST MMEDOMAINNAME

Use this command to list the configurations of an MME domain name.
MOD MMEDOMAINNAME

Use this command to modify the configurations of an MME domain name.
RMV MMEDOMAINNAME

Use this command to remove an MME domain name.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
MME Domain Name ID

Indicates the index of the MME domain name.
CN Operator ID

Indicates the ID of the operator.
MME Domain Name

Indicates the domain name of an MME or an MME pool. If MMEs are configured as an MME pool, you are advised to specify the domain name of the MME pool to simplify the configuration.
