Description

The eNodeBFunction MO consists of parameters related to the root node of the eNodeB function domain. The eNodeB function is used for radio access in the LTE system. It mainly performs radio resource management (RRM) functions such as air interface management, access control, mobility control, and UE resource allocation.

(2) The sum must be less than or equal to 72 in other scenarios.

    • ApplicationRef in eNodeBFunction MO must have been set in the associated APPLICATION MO with eNodeB AT.
