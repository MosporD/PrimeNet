ParaAutoOptCfg

+-NE
  +-eNodeBFunction
    +-ParaAutoOptCfg

Description

The ParaAutoOptCfg MO consists of parameters related to automatic congestion handling, which automatically adjusts related parameters when network load is high to optimize the network performance and prevent serious user experience deterioration and restores the parameters to their original values when network load is low.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
PUSCH RSRP High Threshold for Auto Optimization

Indicates the target upper limit of RSRP used in automatic optimization for PUSCH closed-loop power control. This parameter takes effect only when PuschRsrpHighThdSwitch is on. This parameter applies only to LTE FDD and LTE TDD.
PUCCH PC SINR Offset for Auto Optimization

Indicates the target offset to the target SINR used in automatic optimization for PUCCH power control. This parameter applies only to LTE FDD and LTE TDD.
P0 Nominal PUCCH for Auto Opt

Indicates the target eNodeB-expected PUCCH transmit power used in automatic optimization for correct PUCCH demodulation. This parameter applies only to LTE FDD and LTE TDD.
Handover Times Threshold

Indicates the threshold of the number of handovers required for selecting a neighboring cell as a coordinated neighboring cell in automatic congestion handling. If the number of handovers from a serving cell to a neighboring cell exceeds the threshold in the last 5-minute period and the neighboring cell is ranked at the top according to the number of handovers, the neighboring cell is selected as a coordinated neighboring cell. Then, the serving cell will send a parameter adjustment request to the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
ACH Effective Type

Indicates the ACH effective type.

TDD_ACH_SWITCH: If this option is selected, the ACH feature takes effect for LTE TDD cells. If both this option and the ACHSwitch option of the IOptAlgoSwitch parameter in the ENodeBAlgoSwitch MO are deselected, the ACH feature does not take effect for LTE TDD cells. This option applies only to LTE TDD.

FDD_ACH_SWITCH: If this option is selected, the ACH feature takes effect for LTE FDD cells. If both this option and the ACHSwitch option of the IOptAlgoSwitch parameter in the ENodeBAlgoSwitch MO are deselected, the ACH feature does not take effect for LTE FDD cells. This option applies only to LTE FDD.
