CellAutoShutdown

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellAutoShutdown

Description

The CellAutoShutdown MO consists of the parameters related to automatic cell shutdown.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the SpectrumCloud MO:
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the CellAutoShutdownSwitch parameter in the CellAutoShutdown MO under this Cell MO can only be set to OFF.
  • Relation with the ContigIntraBandCarr MO:
    • If the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO under a Cell MO is selected, the CellAutoShutdownSwitch parameter in the CellAutoShutdown MO under this Cell MO can only be set to OFF.
  • Relation with the Cell and eNodeBAutoPowerOff MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD or the NbCellFlag parameter in a Cell MO is set to TRUE, and the AutoPowerOffSwitch parameter in the eNodeBAutoPowerOff MO is set to ON, then the CellAutoShutdownSwitch parameter in the CellAutoShutdown MO under this Cell MO can only be set to OFF.
