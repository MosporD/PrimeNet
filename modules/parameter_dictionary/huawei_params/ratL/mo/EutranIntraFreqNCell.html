EutranIntraFreqNCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-EutranIntraFreqNCell

Description

An EutranIntraFreqNCell MO consists of the parameters related to the neighbor relationship with an intra-frequency E-UTRAN cell. These parameters include those used in measurement control for intra-frequency handovers and those in system information block type 4 (SIB4) for intra-frequency cell reselections. Intra-frequency neighboring relations can be maintained by automatic neighbor relation (ANR). Intra-frequency neighboring relations are used in mobility load balancing (MLB), mobility robustness optimization (MRO), and inter-cell interference coordination (ICIC).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • The CGI of the local cell must be different from that of any intra-eNodeB intra-frequency neighboring cell. A CGI is comprised of Mcc, Mnc, eNodeBId and CellId. Two CGIs are considered to be the same if they have an identical combination of the four parameters. The CGI of an intra-frequency neighboring cell is comprised of Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO. The CGI of the local cell is comprised of Mcc and Mnc in one associated CnOperator MO, eNodeBId in the associated eNodeBFunction MO, and CellId in the Cell MO.
    • Before adding an intra-eNodeB EutranIntraFreqNCell for a serving cell, ensure that a Cell MO corresponding to this intra-eNodeB intra-frequency cell has been configured, and the parameter NbCellFlag must be set to the same value for the two cells.
    • A maximum of eight EutranIntraFreqNCell MOs with AttachCellSwitch set to ON can be configured under a Cell MO.
    • If NbCellFlag in a Cell MO is set to FALSE, the carrier frequency calculated based on DlEarfcn in the Cell MO that represents an intra-eNodeB EutranIntraFreqNCell must be the same as the carrier frequency calculated based on DlEarfcn in the local Cell MO.
  • Relation with the EutranExternalCell, Cell, CellAlgoSwitch, and SfnEdgeRruRelation MOs:
    • PhyCellId in the EutranExternalCell MO associated with an EutranIntraFreqNCell MO (representing an inter-eNodeB intra-frequency neighboring cell of the local cell) can be the same as PhyCellId in the Cell MO representing the local cell if both conditions are met: (1) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO is selected in the local cell; (2) All values of parameters Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO are the same with values of parameters Mcc, Mnc, EnodeBId, and NeighborCellId in at least one SfnEdgeRruRelation MO configured for the local cell. If either condition is not met, PhyCellId in the EutranExternalCell MO cannot be the same as PhyCellId in the Cell MO.
  • Relation with the Cell, CellAlgoSwitch, and SfnEdgeRruRelation MOs:
    • PhyCellId in the Cell MO representing the local cell can be the same as PhyCellId in the Cell MO associated with the EutranIntraFreqNCell MO (representing an intra-eNodeB inter-frequency neighboring cell of the local cell) if both conditions are met: (1) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO is selected in the local cell; (2) All values of parameters Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO are the same with values of parameters Mcc, Mnc, EnodeBId, and NeighborCellId in at least one SfnEdgeRruRelation MO configured for the local cell. If either condition is not met, values of PhyCellId in the two Cell MOs cannot be the same.
  • Relation with the EutranExternalCell, CnOperator, eNodeBFunction, and ENodeBSharingMode MOs:
    • Before adding an inter-eNodeB EutranIntraFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured.
  • Relation with the EutranExternalCell and Cell MOs:
    • Before adding an inter-eNodeB EutranIntraFreqNCell, ensure that the associated EutranExternalCell MO has been configured, and the NbCellFlag of the server Cell of the inter-eNodeB intra-frequency neighboring cell must be same with the NbCellFlag of EutranExternalCell.
    • The carrier frequency calculated based on DlEarfcn in the EutranExternalCell MO that represents an inter-eNodeB EutranIntraFreqNCell must be the same as the carrier frequency calculated based on DlEarfcn in the local Cell MO.
  • Relation with the Cell and Prb MOs:
    • If NbCellFlag in a Cell MO is set to TRUE and an intra-eNodeB cell is to be added in an EutranIntraFreqNCell MO for this Cell MO, Prb MO whose AnchorCarrierFlag is TRUE must be configured first for the two cells.
  • Relation with the CnOperator and ENodeBSharingMode MOs:
    • In intra-eNodeB scenarios, when the ENodeBSharingMode parameter in an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, the Mcc and Mnc parameters in the EutranIntraFreqNCell MO must be the same as the Mcc and Mnc parameters in the CnOperator MO corresponding to the primary operator, respectively.
  • Relation with the CellOp, CnOperator, CnOperatorTa, and ENodeBSharingMode MOs:
    • A CellOp MO must be configured for each EutranIntraFreqNCell MO that corresponds to an intra-eNodeB intra-frequency neighboring cell. If the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ, Mcc and Mnc in such an EutranIntraFreqNCell MO must be the same as the Mcc and Mnc specified in the CnOperator MO representing the primary operator. If ENodeBSharingMode is set to INDEPENDENT or SEPARATED_FREQ, Mcc and Mnc in such an EutranIntraFreqNCell MO must be set to the same values as Mcc and Mnc specified in the CnOperator MO corresponding to the CellOp MO associated with this EutranIntraFreqNCell MO.
  • Relation with the Prb MO:
    • If an intra-eNodeB intra-frequency neighboring cell is to be configured using an EutranIntraFreqNCell MO for a local cell whose NbCellFlag is set to TRUE, the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset or by DlEarfcn and DlBandWidth in the Cell corresponding to LteDlRbIndex in the Prb MO with AnchorCarrierFlag set to TRUE for the neighboring cell must be the same as the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset or by DlEarfcn and DlBandWidth in the Cell corresponding to LteDlRbIndex in the Prb MO with AnchorCarrierFlag set to TRUE for the local cell.
  • Relation with the CellOp, CnOperator, CnOperatorTa, CnOpSharingGroup, Cell, and ENodeBSharingMode MOs:
    • A CellOp MO must be configured for each EutranIntraFreqNCell MO that corresponds to an intra-eNodeB intra-frequency neighboring cell. If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, Mcc and Mnc in such an EutranIntraFreqNCell MO must be set to the same values as Mcc and Mnc, respectively, in the CnOperator MO referenced by PrimaryOperatorId in the CnOpSharingGroup MO for the intra-eNodeB intra-frequency neighboring cell.
  • Relation with the EutranIntraFreqNCell MO:
    • The CGI specified by parameters in an EutranBlkNCell MO cannot be the same with the CGI specified by parameters in an EutranIntraFreqNCell MO. The CGI consists of the MCC, MNC, eNodeB ID, and cell ID. Two CGIs are considered the same when the four items are the same. In the EutranBlkNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId. In the EutranIntraFreqNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId.
  • Relation with the EutranInterFreqNCell MO:
    • A maximum of 72*256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total in the same eNodeB when equipped with UMPTe or UMPTga board and did not equipped with UMPTg.
    • A maximum of 144*256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total in the same eNodeB.
    • A maximum of 18*256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total in the same eNodeB when equipped with LMPT board.
    • A maximum of 36*256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total in the same eNodeB when equipped with UMPTa/b board.
  • Relation with the EutranInterFreqNCell and NODE MOs:
    • WM in the NODE MO is set to CONCURRENT, a maximum of 72*256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total in the same eNodeB.
  • Relation with the EutranInterFreqNCell, Cell, and MDU MOs:
    • A maximum of 384 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total for a Cell MO in the eNodeB when equipped with UMPT board or MDU type is MDUC or UMDU.
  • Relation with the EutranInterFreqNCell and Cell MOs:
    • A maximum of 256 EutranInterFreqNCell and EutranIntraFreqNCell MOs can be configured in total for a Cell MO in the eNodeB when equipped with LMPT board.
  • Relation with the EutranExternalCell, Cell, and Prb MOs:
    • In inter-eNodeB scenarios, if NbCellFlag in a Cell MO is set to TRUE and an EutranIntraFreqNCell MO is to be added for this Cell MO, a Prb MO whose AnchorCarrierFlag is TRUE must be configured first for this Cell MO.
  • Relation with the EutranExternalCell and Prb MOs:
    • If an inter-eNodeB intra-frequency neighboring cell is to be configured using an EutranIntraFreqNCell MO for a local cell whose NbCellFlag is set to TRUE, the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset in the EutranExternalCell MO that the EutranIntraFreqNCell MO depends on must be the same as the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset or by DlEarfcn and DlBandWidth in the Cell corresponding to LteDlRbIndex in the Prb MO with AnchorCarrierFlag set to TRUE for the local cell.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB.
Mobile country code

Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.
Mobile network code

Indicates the mobile network code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.
eNodeB ID

Indicates the eNodeB ID of the intra-frequency neighboring cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the local ID of the intra-frequency neighboring cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell individual offset

Indicates the cell individual offset for the intra-frequency neighboring cell. It affects the probability of triggering intra-frequency measurement reports. A larger value of this parameter indicates a higher probability. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Cell offset

Indicates the offset for the intra-frequency neighboring cell, which is used in evaluation for cell reselections. A larger value of this parameter results in a lower probability of cell reselections to this neighboring cell. If this parameter is not set to dB0, it is delivered in SIB4. For details, see 3GPP TS 36.331. If this parameter is set to dB0, it is not delivered in SIB4. In this situation, UEs use 0 dB as the offset for cell reselections. For details, see 3GPP TS 36.304.
No handover indicator

Indicates whether handovers of UEs to the neighboring cell are prohibited. This parameter applies only to LTE FDD and LTE TDD.
No remove indicator

Indicates whether to permit or prohibit removal of the neighbor relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether this neighboring cell is automatically discovered by the ANR algorithm. This parameter applies only to LTE FDD and LTE TDD.
Local cell name

Indicates the name of the local cell.
Neighbour cell name

Indicates the name of the intra-frequency neighboring E-UTRAN cell.
Cell Measure Priority

Indicates the priority of measurement on the intra-frequency neighboring cell. The eNodeB preferentially contains the information about a neighboring cell with this priority set to HIGH_PRIORITY while delivering a measurement configuration. This parameter applies only to LTE FDD and LTE TDD.
Cell Range Expansion

Indicates the maximum cell coverage offset. This parameter is specified to achieve coverage expansion of micro base stations. The offset that actually takes effect depends on UE capabilities. The parameter value is added to or subtracted from the handover parameter cell individual offset (CIO) to obtain a new CIO, which must meet protocol-defined constraints. The updated CIO is delivered to UEs so that handovers from an eNodeB to a micro base station can be triggered more easily or handovers from a micro base station to an eNodeB can be triggered less easily. In this manner, the cell coverage of a micro base station is expanded. This parameter applies only to LTE FDD and LTE TDD.
Neighbor Cell Classification Label

Indicates the neighboring cell classification label. The parameter values FORMAL and EXTENDED represent different neighboring cell management policies. If the number of handovers to a neighboring cell reaches a predefined threshold, the parameter is set to FORMAL for this neighboring cell; otherwise, the parameter is set to EXTENDED for this neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
Attach Cell Switch

Indicates whether to enable the macro-micro homing relationship of the intra-frequency neighboring cell. In HetNet networking, the macro cell and micro cell that greatly interfere each other are added to one cluster, and homing relationships are configured between the macro and micro cells in each cluster. A cluster consists of one macro cell and a maximum of eight homed micro cells.

If this parameter is set to ON(On), the neighboring cell is the homed cell of the local cell.

If this parameter is set to OFF(Off), the neighboring cell is not the homed cell of the local cell.

The homing relationship between a macro cell and a micro cell takes effect only when the parameter settings are the same in the two cells. This parameter applies only to LTE FDD and LTE TDD.
High Speed Cell Individual Offset

Indicates the individual cell offset for event A3 related to intra-frequency handovers for high-speed UEs in high-speed cells. This parameter applies only to LTE FDD and LTE TDD.
Vector Cell Flag

Indicates whether an intra-frequency neighboring cell is a vector cell. A vector cell is a neighboring cell with coverage adjacent to that of the serving cell along a high-speed railway. This type of cell requires planning during network construction. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Addition Time

Indicates the time the neighboring cell was added by ANR for the first time. In free mode, this time is the local time of the NE. In control mode, this time is the local time of the OSS when optimization suggestions are delivered. The format is YYYY-MM-DD. For example, the value 2018-01-01 indicates January 1, 2018. The value 2001-01-01 indicates that the neighboring cell was manually added. This parameter applies only to LTE FDD and LTE TDD.
Aggregation Attribute

Indicates the aggregation attribute of an intra-frequency neighboring E-UTRAN cell. UL_INTRF_DET_COORD_NCELL_FLAG: If this option is selected, the neighboring cell is a coordinating cell for uplink interference detection of the serving cell. If this option is deselected, the neighboring cell is not a coordinating cell for uplink interference detection of the serving cell. This option applies only to LTE FDD.
