CellUSParaCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellUSParaCfg

Description

The CellUSParaCfg MO consists of parameters related to cell-level configurations of UEs running unlimited services. These parameters determine policies for identifying such UEs and policies for guaranteeing services of such UEs.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.
Us Guarantee Algorithm Switch

Indicates whether to guarantee services for UEs running unlimited services in a cell.

UsUeGuaranteeSwitch: Indicates whether all options related to service guarantee for UEs running unlimited services take effect. If this option is selected, functions and parameters of service guarantee for UEs running unlimited services take effect. If this option is deselected, functions and parameters of service guarantee for UEs running unlimited services do not take effect.

UsHoSwitch: Indicates whether to enable handovers based on UEs running unlimited services. If this option is selected, this type of handover is enabled. If this option is deselected, this type of handover is disabled. This option applies only to LTE FDD and LTE TDD.

UsCellReselSwitch: Indicates whether to enable cell reselection based on UEs running unlimited services. If this option is selected, the eNodeB triggers cell reselection to the frequencies in the configured target frequency group for UEs running unlimited services. If this option is deselected, the eNodeB does not trigger cell reselection to the frequencies in the configured target frequency group for UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

UsUePuschPcPrioritySwitch: Indicates whether to enable optimization on closed-loop PUSCH power control for UEs running unlimited services near the cell center, to prevent these UEs from unnecessarily lowering the PUSCH transmit power due to inter-RAT or abrupt interference. When the NearPointUeOptPUSCHSwitch option of the UlPcAlgoSwitch parameter is deselected, if the UsUePuschPcPrioritySwitch is selected, optimization on closed-loop PUSCH power control for UEs running unlimited services near the cell center is enabled; if the UsUePuschPcPrioritySwitch is deselected, optimization on closed-loop PUSCH power control for UEs running unlimited services near the cell center is disabled. When the NearPointUeOptPUSCHSwitch option of the UlPcAlgoSwitch parameter is selected, optimization on closed-loop PUSCH power control for UEs running unlimited services near the cell center is enabled regardless of whether the UsUePuschPcPrioritySwitch option is selected or not. This option applies only to LTE FDD and LTE TDD.

DlUsVoIPCqiAdjOptSwitch: Indicates whether to enable optimization on downlink channel quality indicator (CQI) adjustment for UEs running unlimited voice services, to accelerate the convergence of the IBLER of voice packets. If this option is selected, optimization on downlink CQI adjustment for UEs running unlimited voice services is enabled. If this option is deselected, optimization on downlink CQI adjustment for UEs running unlimited voice services is disabled. This option applies only to LTE FDD and LTE TDD.

UsCellNotDriveNsSwitch: Indicates whether to enable user steering in cells where UEs' unlimited services must be guaranteed to distinguish these UEs from NS UEs. If this option is deselected, user steering is enabled in such scenarios. If this option is selected, user steering is disabled in such scenarios. This option applies only to LTE FDD and LTE TDD.

UsCtrlDRXSwitch: If this option is deselected, the eNodeB does not perform special processing on the DRX function of UEs running unlimited services. If this option is selected, the DRX function is disabled for UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

SfCtrlAsScell: Indicates whether to enable intelligent subframe control when a cell functions as a serving cell. If this option is deselected, intelligent subframe control is disabled when a cell functions as a serving cell. If this option is selected, intelligent subframe control is enabled when a cell functions as a serving cell. This option applies only to LTE FDD and LTE TDD.

SfCtrlAsInterNcell: Indicates whether to enable intelligent subframe control when the cell serves as an inter-eNodeB neighboring cell and whether to enable scheduling prohibition in MBSFN subframes when the cell serves UEs running unlimited services. For FDD cells: If this option is deselected, intelligent subframe control is disabled when the cell serves as an inter-eNodeB neighboring cell. If this option is selected, intelligent subframe control is enabled when the cell serves as an inter-eNodeB neighboring cell. For TDD cells: If this option is deselected, downlink scheduling of UEs running normal services is allowed in MBSFN subframes in the cell when the cell serves UEs running unlimited services. In addition, intelligent subframe control is disabled when the cell serves as an inter-eNodeB neighboring cell. If this option is selected, downlink scheduling of UEs running normal services is prohibited in MBSFN subframes in the cell when the cell serves UEs running unlimited services. In addition, intelligent subframe control is enabled when the cell serves as an inter-eNodeB neighboring cell. This option can be selected only when all eNodeBs on the network are time-synchronized. This option applies only to LTE FDD and LTE TDD.

UsSccHoSwitch: Indicates whether to enable handovers triggered for UEs running unlimited services based on their SCCs. If this option is selected, handovers triggered for UEs running unlimited services based on their SCCs are enabled. If this option is deselected, this type of handover is disabled. This option applies only to LTE FDD and LTE TDD.

UlUsVoipRbRsvSwitch: Indicates whether to enable the RB reservation and related parameter configuration for UEs running unlimited voice services in the uplink. If this option is selected, the RB reservation and related parameter configuration are enabled for UEs running unlimited voice services in the uplink. If this option is deselected, the RB reservation and related parameter configuration are disabled for UEs running unlimited voice services in the uplink. This option applies only to LTE FDD and LTE TDD.

ULCoMPResourceCtrl: Indicates whether to perform UL CoMP resource control for a cell. If this option is selected, UL CoMP resource control can be performed for a cell. If this option is deselected, UL CoMP resource control cannot be performed for a cell. This option applies only to LTE FDD.

UsUlCaSchSwitch: Indicates whether to enable uplink scheduling based on CA UEs running unlimited services. If this option is selected, uplink scheduling based on CA UEs running unlimited services is enabled. If this option is deselected, uplink scheduling based on CA UEs running unlimited services is disabled. This option applies only to LTE FDD and LTE TDD.

UlUsDiffRatFreqPri: Indicates whether to enable frequency priority differentiation for UEs running unlimited data services in the uplink. If this option is selected, the eNodeB selects frequencies from dedicated target frequency groups to perform handovers or cell reselection for UEs running unlimited data services in the uplink. If this option is deselected, the eNodeB uses identical target frequency groups to perform handovers or cell reselection for UEs running unlimited data services in the uplink and UEs running the same type of services in the downlink. This option applies only to LTE FDD and LTE TDD.

UsNbInterfHoSwitch: Indicates whether to enable optimization on handover parameters based on the interference suppression threshold in an intra-frequency neighboring cell of the local cell serving UEs running unlimited services. If this option is selected, handover parameters of a cell are optimized based on the interference suppression threshold in an intra-frequency neighboring cell of the local cell serving UEs running unlimited services, to ensure that the handovers are performed smoothly. If this option is deselected, handover parameters of a cell are not optimized based on the interference suppression threshold in an intra-frequency neighboring cell of the local cell serving UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

MBSFNSubJTOptSwitch: Indicates whether to enable JT optimization in MBSFN subframes. If this option is selected, JT optimization is enabled in MBSFN subframes. If this option is deselected, JT optimization is disabled in MBSFN subframes. This option applies only to LTE TDD.

UsPdcchOptSwitch: Indicates whether to enable PDCCH optimization for UEs using unlimited services. If this option is selected, PDCCH optimization for UEs using unlimited services is enabled. If this option is deselected, PDCCH optimization for UEs using unlimited services is disabled. This option applies only to LTE FDD and LTE TDD.

UsCellDlStartRBOptSwitch: Indicates whether to optimize RB start position in the downlink for UEs running unlimited services in cells where the services of such UEs must be guaranteed. If this option is selected, optimization of RB start position in the downlink is enabled for UEs running unlimited services in cells where the services of such UEs must be guaranteed. If this option is deselected, optimization of RB start position in the downlink is disabled for UEs running unlimited services in such cells. This parameter applies only to LTE TDD.

CellBFAnt: Indicates whether to enable selection of antenna weights for a cell. If this option is selected, the serving cell selects a specified new antenna weight. This option applies only to 8T8R LTE TDD eNodeBs working on band 39. This option applies only to LTE TDD.

UsAutoGapSwitch: Indicates whether to enable automatic measurement gap configuration for UEs running unlimited services. If this option is selected and UEs running unlimited services support automatic measurement gap configurations on the target frequency, the eNodeB does not deliver gap configurations to such UEs. If this option is deselected, the eNodeB delivers gap configurations to UEs for inter-frequency and inter-RAT measurements. This option applies only to LTE FDD and LTE TDD.

UsCellDlAdSchOptSwitch: Indicates whether to optimize downlink advance scheduling and downlink start RB positions for UEs running unlimited services in cells where the services of such UEs must be guaranteed. If this option is selected, downlink advance scheduling is optimized for UEs using unlimited services in cells where the services of such UEs must be guaranteed. If this option is deselected, downlink advance scheduling is not optimized for UEs using unlimited services in such cells. This option applies only to LTE TDD.

UsCqiSrsPeriodOptSwitch: Indicates whether to enable smooth handover optimization for VoLTE UEs running unlimited services. Smooth handover optimization is enabled for VoLTE UEs running unlimited services only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UsCfiOptSwitch: Indicates whether to optimize the CFI for the cell in which UEs running unlimited services reside. If this option is selected, the CFI is optimized for the cell in which UEs running unlimited services reside. If this option is deselected, the CFI is not optimized for the cell in which UEs running unlimited services reside. This option applies only to LTE FDD and LTE TDD.

UsUlcompPuschSchSwtich: Indicates whether to optimize UL CoMP and PUSCH scheduling for UEs running unlimited services. If this option is selected, UL CoMP and PUSCH scheduling are optimized for UEs running unlimited services in LTE TDD cells, and only UL CoMP is optimized for UEs running unlimited services in LTE FDD cells or NB-IoT cells. If this option is deselected, UL CoMP and PUSCH scheduling are not optimized for UEs running unlimited services.

UsHoCoverEnhanceSwitch: Indicates whether to delay beamforming for UEs that are handed over to the cell and run unlimited services, to reduce the interference of such UEs to CEUs in the source cell. If this option is selected, the eNodeB delays beamforming for UEs that are handed over to the cell and run unlimited services, reducing the interference of such UEs to CEUs in the source cell. If this option is deselected, the eNodeB does not delay beamforming for UEs that are handed over to the cell and run unlimited services. This option applies only to LTE TDD.

NsUlDlSchRestrictSwitch: Indicates whether to restrict uplink and downlink scheduling of NS UEs. If this option is deselected, uplink and downlink scheduling of NS UEs is not restricted. If this option is selected, uplink and downlink scheduling of NS UEs is restricted. The setting of this option takes effect in both single-carrier and multi-carrier scenarios. This option applies only to LTE FDD and LTE TDD.

UsCceGuaranteeSwitch: Indicates whether to guarantee PDCCH CCE resources for UEs running unlimited services. If this option is selected, PDCCH CCE resources are guaranteed for UEs running unlimited services. If this option is deselected, PDCCH CCE resources are not guaranteed for UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

UsEmtcCrntiOptSwitch: Indicates whether to optimize C-RNTI usage for UEs running unlimited services in a cell where the eMTC function is enabled. If this option is selected, UEs use specified C-RNTIs. If this option is deselected, UEs are normally allocated C-RNTIs. This option applies only to LTE FDD and LTE TDD.
US Data Minimal Period of Preallocation

Indicates the minimum interval between two consecutive preallocations for a UE running unlimited data services. When the DRX algorithm is enabled and the UE is in the DRX state, the actual minimum interval does not exceed the DrxInactivityTimer parameter value.
US VoIP Packet Size of Preallocation

Indicates the amount of data preallocated to a UE running unlimited voice services. This parameter applies only to LTE FDD and LTE TDD.
US Data Packet Size of Preallocation

Indicates the amount of data that can be preallocated resources for a UE running unlimited services.
US Data Smart Preallocation Duration

Indicates the duration of smart preallocation each time it is performed for a UE running unlimited data services. If this parameter is set to 0, preallocation does not take effect. For an NB-IoT cell, the actual duration is 10 times the value configured on the GUI.
US Ul VoIP Ibler Target

Indicates the uplink target initial block error rate (IBLER) of UEs running unlimited voice services. This parameter applies only to LTE FDD and LTE TDD.
NS Number Thd Based on US Handover

Indicates the minimum number of UEs running normal services that is used in steering mobility management for such UEs when steering mobility management for UEs running unlimited services is enabled. This parameter applies only to LTE FDD and LTE TDD.
US PUCCH SINR Target Offset

Indicates the offset of the target signal to interference plus noise ratio (SINR) on the PUCCH for UEs running unlimited services relative to the target SINR on the PUCCH for UEs running normal services. This parameter applies only to LTE FDD and LTE TDD.
US PUCCH RSRP High Threshold Offset

Indicates the offset of the reference signal received power (RSRP) upper limit on the PUCCH for UEs running unlimited services to the RSRP upper limit on the PUCCH for UEs running normal services. This parameter applies only to LTE FDD and LTE TDD.
US Data Rat Freq Priority Group ID

Indicates the ID of the intra-RAT frequency priority group for UEs running unlimited data services. If the UlUsDiffRatFreqPri option is selected for UEs running unlimited data services, the uplink and downlink are differentiated for UEs running unlimited data services and this parameter indicates the ID of the intra-RAT frequency priority group for UEs running unlimited data services in the downlink. Otherwise, the uplink and downlink are not differentiated for UEs running unlimited data services, and this parameter indicates the ID of the intra-RAT frequency priority group for UEs running unlimited data services. This parameter applies only to LTE FDD and LTE TDD.

NS_VOLTE_RESTRICTED: Indicates that the scheduling of UEs running normal services is restricted when the number of UEs running unlimited services in the cell is less than or equal to that configured using the MML command. In addition, the scheduling of VoLTE UEs is restricted.

This parameter applies only to LTE FDD and LTE TDD.
Downlink CCE Sch Priority Penalty Level

Indicates the level of penalty on scheduling priorities. The penalty takes effect on a per PDCCH aggregation level basis.

The value NONE indicates that the penalty is disabled.

The value LEVEL_ONE indicates that a low level of penalty is imposed only on UEs for which PDCCH aggregation level 8 is used.

The value LEVEL_TWO indicates that a medium level of penalty is imposed on UEs for which PDCCH aggregation level 4 or 8 is used.

The value LEVEL_THREE indicates that a high level of penalty is imposed on UEs for which PDCCH aggregation level 4 or 8 is used.

This parameter applies only to LTE TDD.
Uplink CCE Sch Priority Penalty Level

Indicates the level of penalty on uplink scheduling priorities based on the PDCCH aggregation level.

The value NONE indicates that penalty on uplink scheduling priorities based on the PDCCH aggregation level is disabled.

If this parameter is set to LEVEL_ONE, the penalty is imposed on only the uplink scheduling priority of UEs with PDCCH aggregation level 8, and the penalty level is low.

If this parameter is set to LEVEL_TWO, the penalty is imposed on the uplink scheduling priorities of UEs with PDCCH aggregation levels 4 and 8, and the penalty level is medium.

If this parameter is set to LEVEL_THREE, the penalty is imposed on the uplink scheduling priorities of UEs with PDCCH aggregation levels 4 and 8, and the penalty level is high.

This parameter applies only to LTE TDD.
US UE DL Adaptive Power Boost Threshold

Indicates the downlink power boost threshold for eMTC and NB-IoT UEs running unlimited services. If this parameter is set to 0, downlink power boost is disabled for these UEs.
US UE Neighboring Cell Guarantee Timer

Indicates the length of the timer that governs the period of performance guarantee for the cell serving UEs running unlimited services (US UEs for short) through control over neighboring cells. If the length of time in which no UE is running unlimited services in the cell exceeds the sum of the values of this parameter and the UsDetectTimer parameter (which specifies the length of the timer for detecting US UEs), the eNodeB stops guaranteeing performance of the cell through control over neighboring cells. Specifically, the following parameters stop taking effect: NsRbRestrictRatio, SfCtrlAsScell, SfCtrlAsInterNcell, UsNbInterfCtrl, CrsShutDownStrategy, UsNbUlRbRestrictRat, and UsNbUlSinrHighThdOffset. This parameter applies only to LTE FDD and LTE TDD.
