IntraRatHoComm

+-NE
  +-eNodeBFunction
    +-IntraRatHoComm

Description

The IntraRatHoComm MO consists of the eNodeB-level parameters that are related to intra-RAT handovers. The configuration of this MO is delivered with the RRCConnectionReconfiguration message. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST INTRARATHOCOMM

Use this command to list the eNodeB-level parameters that are related to intra-RAT handovers.
MOD INTRARATHOCOMM

Use this command to modify the common parameters for intra-RAT handover.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Max report cell number

Indicates the maximum number of cells to be included in the measurement report after an intra-RAT inter-frequency or intra-RAT intra-frequency measurement event for handover purposes or a periodic intra-RAT measurement for ANR purposes is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Measurement report amount

Indicates the number of periodic measurement reports to be sent after an event for the intra- or inter-frequency handover within the E-UTRAN is triggered.

It is used to prevent the impact of measurement report loss and internal processing failure on the handover. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A3 measurement trigger quantity

Indicates the triggering quantity used to evaluate the triggering condition for intra-frequency handovers. The quantity can be RSRP or RSRQ.

The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal quality fluctuation. The measured RSRQ values vary greatly with the load and better reflect the signal quality of the cell in real time.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A3 measurement report quantity

Indicates the quantity to be included in the measurement report after an event for intra-frequency handover is triggered. The quantity can be RSRP, RSRQ, or both.

The measured RSRP values are stable, varying little with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and better reflect the signal quality of the cell in real time. Even when this parameter is set to BOTH, the eNodeB triggers handovers based on the setting of the IntraFreqHoA3TrigQuan parameter. The value of this parameter is also used as the quantity to be included in inter-frequency event A3 measurement reports. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A3 measurement report interval

Indicates the interval between periodic measurement reports that are sent after an intra-frequency handover is triggered. The value of this parameter is also used as the interval between A3-related inter-frequency measurement reports.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Measurement A4 report quantity

Indicates the quantity to be included in the measurement reports for inter-frequency handovers. The quantity can be RSRP, RSRQ, or both.

The measured RSRP values are stable, varying little with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and better reflect the signal quality of the cell in real time. This parameter applies to measurements for events A4 and A5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Interfreq measurement report interval

Indicates the interval at which periodic measurement reports are sent after an inter-frequency handover event is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
InterFreq A1A2 Measurement trigger quantity

Indicates the triggering quantity for events A1 and A2 related to A4- or A5-based inter-frequency handovers. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A1A2 Measurement trigger quantity of Freq Priority

Indicates the triggering quantity for events A1 and A2 related to frequency-priority-based inter-frequency handovers. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based o RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A4 Measurement Trigger Quantity

Indicates the triggering quantity for events A4 and A5 related to all non-coverage-based inter-frequency handovers. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based A4 or A5 measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A4 or A5 is met, the UE reports event A4 or A5. This parameter applies only to LTE FDD and LTE TDD.
Coverage Based Inter Frequency HO Waiting Timer

Indicates the timer governing the period of time that the eNodeB waits for more measurement reports to evaluate whether to perform a coverage-based inter-frequency handover after it receives a measurement report. This parameter takes effect only when the CovBasedInterFreqHoMode parameter is set to BASEDONSIGNALSTRENGTH or BASEDONFREQPRIORITY. This parameter applies only to LTE FDD and LTE TDD.
A3 InterFreq A1A2 Measurement TrigQuan

Indicates the triggering quantity for events A1 and A2 related to A3-based inter-frequency handovers. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Freq Pri Ho Candidate UE Select Period

Indicates the interval at which the eNodeB selects candidate UEs in the cell to perform frequency-priority-based inter-frequency measurement. If this parameter is set to 0, the eNodeB does not periodically select candidate UEs in the cell. This parameter applies only to LTE FDD and LTE TDD.
Freq-Pri-based Inter-Freq HO Waiting Timer

Indicates the time within which the eNodeB waits for measurement reports for frequency-priority-based inter-frequency handovers. The value 0 indicates that the eNodeB handles a measurement report upon receiving it. If this parameter is set to a value greater than 0, the eNodeB waits for other measurement reports after receiving any measurement report for a frequency-priority-based inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
Intra-RAT HO A1 A2 Meas Trigger Quantity for CE

Indicates the triggering type of A1/A2 event measurement for coverage-based intra-RAT handovers of UEs in coverage enhancement mode. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Freq-Pri-based Incoming HO Protection Timer

Indicates the length of the timer that governs the period in which UEs handed over from other cells to the local cell through unnecessary handovers are not allowed to be handed over to other cells through frequency-priority-based handovers. If this parameter is set to 0, the protection mechanism does not take effect. The unnecessary handovers include intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based handovers, X2-based inter-eNodeB handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover", and S1-based inter-eNodeB handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover". This parameter applies only to LTE FDD and LTE TDD.
Max Num of HO Fwd PDCP Pkt with SN

Indicates the maximum number of PDCP packets that can be forwarded with SNs during handovers when the actually effective PdcpSnSize value is less than 18 bits. This parameter applies only to LTE FDD and LTE TDD.
