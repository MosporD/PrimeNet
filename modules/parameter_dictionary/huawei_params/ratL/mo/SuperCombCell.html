SuperCombCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-SuperCombCell

Description

A SuperCombCell MO consists of parameters related to super cell combination, including the SFN cell ID that must be configured based on the network plan. This MO applies only to LTE FDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoSwitch MO:
    • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, SuperCombCell MO must have been configured for the cell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SUPERCOMBCELL

Use this command to add a super combined cell.
LST SUPERCOMBCELL

Use this command to list parameter settings of a super combined cell.
MOD SUPERCOMBCELL

Use this command to modify parameter settings of a super combined cell.
RMV SUPERCOMBCELL

Use this command to remove a super combined cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.
SFN Cell ID

Indicates the ID of an SFN cell in a super combined cell. This parameter value must be set based on network planning. This parameter applies only to LTE FDD.
