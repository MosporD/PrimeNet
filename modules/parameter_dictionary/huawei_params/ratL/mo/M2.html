M2

+-NE
  +-eNodeBFunction
    +-M2

Description

An M2 MO consists of parameters related to the control-plane of the M2 interface between the eNodeB and a multi-cell/multicast coordination entity (MCE).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the S1 MO:
    • M2EpGroupId in a M2 MO must be different from CpEpGroupId in any S1 MO.
    • M2EpGroupId in a M2 MO must be different from UpEpGroupId in any S1 MO.
  • Relation with the X2 MO:
    • M2EpGroupId in a M2 MO must be different from UpEpGroupId in any X2 MO.
    • M2EpGroupId in a M2 MO must be different from CpEpGroupId in any X2 MO.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by M2EpGroupId in a M2 MO must already exist.
    • The EPGROUP MO referenced by M2EpGroupId in a M2 MO must already exist, and the EPGROUP MO must contain at least one SCTPHOST MO.
    • The EPGROUP MO referenced by M2EpGroupId in a M2 MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by M2EpGroupId in a M2 MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
  • Relation with the eX2 MO:
    • M2EpGroupId in the M2 MO must be different from CpEpGroupId in any eX2 MO.
    • M2EpGroupId in the M2 MO must be different from UpEpGroupId in any eX2 MO.
  • Relation with the SO MO:
    • M2EpGroupId in a M2 MO must be different from CpEpGroupId in any SO MO.
    • M2EpGroupId in a M2 MO must be different from UpEpGroupId in any SO MO.
  • Relation with the SCTPHOST MO:
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, M2EpGroupId in an M2 MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
  • Relation with the XW MO:
    • CpEpGroupId in an XW MO must be different from M2EpGroupId in any M2 MO.
    • UpEpGroupId in an XW MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the EPGROUP and SCTPPEER MOs:
    • When M2NetworkType is IOPSType, only one SCTPPEER can be configured for the SCTP peer list in the EPGROUP object corresponding to M2EpGroupId.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
M2 ID

Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.
M2 Network Type

Indicates the type of network served by the M2 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.
M2 End Point Group ID

Indicates the ID of the endpoint group used by the M2 MO. This parameter applies only to LTE FDD and LTE TDD.
User Label

Indicates the descriptions of the M2 MO. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
M2 Interface CP Bearer ID

Indicates the control port (CP) bearer ID of the M2 interface. This parameter applies only to LTE FDD and LTE TDD.
M2 Interface CP Bearer State

Indicates the control port bearer status of the M2 interface. This parameter applies only to LTE FDD and LTE TDD.
M2 Interface State

Indicates the M2 interface status. This parameter applies only to LTE FDD and LTE TDD.
M2 Interface Session Number

Indicates the number of sessions on the M2 interface. This parameter applies only to LTE FDD and LTE TDD.
MCE Name

Indicates the name of the Multi-cell/multicast Coordination Entity (MCE) to which the eNodeB is connected over the M2 interface. This parameter applies only to LTE FDD and LTE TDD.
GlobalMceId

Indicates the global unique ID of the Multi-cell/multicast Coordination Entity (MCE) connected to the eNodeB through the M2 interface. The global unique ID of the MCE is represented as "MCC-MNC-MCE ID". MCC is short for mobile country code and MNC is short for mobile network code. This parameter applies only to LTE FDD and LTE TDD.
M2InterfaceFaultReason

Indicates the fault reason of the M2 link. This parameter applies only to LTE FDD and LTE TDD.
M2 Interface Session TMGI

Indicates the temporary mobile group identities (TMGIs) of all incoming sessions over the M2 interface. This parameter applies only to LTE FDD and LTE TDD.
