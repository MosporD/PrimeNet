UeCompatRsvdPara

+-NE
  +-eNodeBFunction
    +-UeCompat
      +-UeCompatRsvdPara

Description

The UeCompatRsvdPara MO consists of UE compatibility parameters that are reserved for future requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    UeCompat

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST UECOMPATRSVDPARA

Use this command to list the configurations of UE compatibility reserved parameters.
MOD UECOMPATRSVDPARA

Use this command to modify the configurations of UE compatibility reserved parameters.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Index

Indicates the index of a UE compatibility processing action. This parameter applies only to LTE FDD and LTE TDD.
Reserved Switch Parameter 0

Indicates reserved 32-bit switch parameter 0 that is reserved for future requirements. Note on parameter replacement: Reserved parameters are temporarily used in patch versions and will be replaced with new parameters. For example, the ID of a new parameter can signify the parameter function. Therefore, avoid using this parameter.
Reserved Switch Parameter 1

Indicates reserved 32-bit switch parameter 1 that is reserved for future requirements. Note on parameter replacement: Reserved parameters are temporarily used in patch versions and will be replaced with new parameters. For example, the ID of a new parameter can signify the parameter function. Therefore, avoid using this parameter.
