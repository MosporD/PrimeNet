ECO

+-NE
  +-eNodeBFunction
    +-ECO

Description

An ECO MO consists of parameters that specify the transport resources used by the interface between the eNodeB and an eCoordinator, including the control- and user-plane endpoint groups used by the ECO MO.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the X2 MO:
    • CpEpGroupId in an ECO MO must be different from CpEpGroupId in any X2 MO.
    • UpEpGroupId in an ECO MO must be different from UpEpGroupId in any X2 MO.
    • CpEpGroupId in an ECO MO must be different from UpEpGroupId in any X2 MO.
    • UpEpGroupId in an ECO MO must be different from CpEpGroupId in any X2 MO.
    • CpEpGroupId in an ECO MO must be different from M1EpGroupId in any M1 MO.
    • UpEpGroupId in an ECO MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the S1 MO:
    • CpEpGroupId in an ECO MO must be different from CpEpGroupId in any S1 MO.
    • UpEpGroupId in an ECO MO must be different from UpEpGroupId in any S1 MO.
    • CpEpGroupId in an ECO MO must be different from UpEpGroupId in any S1 MO.
    • UpEpGroupId in an ECO MO must be different from CpEpGroupId in any S1 MO.
  • Relation with the EPGROUP MO:
    • EPGROUP MO referenced by CpEpGroupId in an ECO MO must have been configured.
    • EPGROUP MO referenced by CpEpGroupId in an ECO MO must have been configured. And the SCTPHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced byCpEpGroupId in an ECO MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • EPGROUP MO referenced by UpEpGroupId in an ECO MO must have been configured.
    • EPGROUP MO referenced by UpEpGroupId in an ECO MO must have been configured. And the USERPLANEHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced by UpEpGroupId in an ECO MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by CpEpGroupId in an ECO MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by UpEpGroupId in an ECO MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
  • Relation with the M2 MO:
    • CpEpGroupId in an ECO MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the M1 MO:
    • UpEpGroupId in an ECO MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the eX2 MO:
    • CpEpGroupId in the ECO MO must be different from CpEpGroupId in any eX2 MO.
    • UpEpGroupId in the ECO MO must be different from UpEpGroupId in any eX2 MO.
    • CpEpGroupId in the ECO MO must be different from UpEpGroupId in any eX2 MO.
    • UpEpGroupId in the ECO MO must be different from CpEpGroupId in any eX2 MO.
  • Relation with the SO MO:
    • CpEpGroupId in an ECO MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an ECO MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an ECO MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an ECO MO must be different from CpEpGroupId in any SO MO.
  • Relation with the SCTPHOST MO:
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, CpEpGroupId in the ECO MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, UpEpGroupId in the ECO MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by the UpEpGroupId parameter in an ECO MO must be configured. In addition, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to DISABLE.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
ECO ID

Indicates the ID of the ECO MO. This parameter applies only to LTE FDD and LTE TDD.
End Point Group Config Flag

Indicates whether to configure the control-plane endpoint group, user-plane endpoint group, or both endpoint groups for the ECO MO. This parameter applies only to LTE FDD and LTE TDD.
Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the ECO MO. This parameter applies only to LTE FDD and LTE TDD.
User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the ECO MO. This parameter applies only to LTE FDD and LTE TDD.
User Label

Indicates the descriptions of the ECO MO. This parameter applies only to LTE FDD and LTE TDD.

Parameter

Description

Indicates the status of the control port (CP) bearer for the ECO interface. This parameter applies only to LTE FDD and LTE TDD.
