LIOptRuleMember

+-NE
  +-eNodeBFunction
    +-LIOptRuleMember

Description

An LIOptRuleMember MO consists of parameters specifying the intelligent optimization rule members. Intelligent optimization rule members are used to associate intelligent optimization atom rules to a specific intelligent optimization rule.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rule ID

Indicates the ID of the intelligent optimization rule to which the intelligent optimization rule members are associated. This parameter applies only to LTE FDD and LTE TDD.
Atom Rule ID

Indicates the ID of the intelligent optimization atom rule to which the intelligent optimization rule members are associated. This parameter applies only to LTE FDD and LTE TDD.
Active Status

Indicates whether an intelligent optimization rule member is activated. If this parameter is set to ACTIVATED, the intelligent optimization atom rules apply to the evaluation of the associated intelligent optimization rule. If this parameter is set to DEACTIVATED, the intelligent optimization atom rules do not apply to the evaluation of the associated intelligent optimization rule. This parameter applies only to LTE FDD and LTE TDD.
