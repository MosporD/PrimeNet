UeSpecificPara

+-NE
  +-eNodeBFunction
    +-UeSpecificPara

Description

A UeSpecificPara MO consists of parameters related to UE compatibility and optimization to reduce the impact of UE incompatibility issues on network performance and improve end user experience.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the UeCompat MO:
    • If the UeSpecificConfigIndex parameter in a UeCompat MO is set to a value greater than 0, the associated UeSpecificPara MO must be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UESPECIFICPARA

Use this command to add a UE-specific configuration.
LST UESPECIFICPARA

Use this command to list one or more UE-specific configurations.
MOD UESPECIFICPARA

Use this command to modify a UE-specific configuration.
RMV UESPECIFICPARA

Use this command to remove a UE-specific configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UE-specific Configuration Index

Indicates the index of a UE-specific configuration. If there are two or more UeSpecificPara MOs with the same combination of the MoId, ParaId, and ParaBitId parameter values but different indexes configured for the same type of UE, only the UeSpecificPara MO with the smallest index takes effect.
MO ID

Indicates the number of an MO in the UE-specific configuration. Set this parameter under the guidance of Huawei technical support.
Parameter ID

Indicates the number of a parameter within the specified MO. Set this parameter under the guidance of Huawei technical support.
Parameter Bit ID

Indicates the number of an option within the specified parameter when the parameter is of bit field type. If this parameter is set to a value greater than 31, this parameter is invalid. Other values are valid. Set this parameter under the guidance of Huawei technical support.
Configured Value

Indicates the value of the specified parameter or option. Set this parameter under the guidance of Huawei technical support.

1. The value of the ConfigValue parameter must be within the GUI value range of the parameter or option specified by MoId, ParaId, and ParaBitId unless the ConfigValue parameter value is processed in a special manner. For details about value meanings, see Terminal Awareness Differentiation Feature Parameter Description.

2. If the ParaBitId parameter value is valid, the ConfigValue parameter specifies whether to enable the function that is controlled by the option identified by the ParaBitId parameter. The values 0 and 1 indicate that the function is disabled and enabled, respectively.

3. If the ParaBitId parameter value is invalid, the ConfigValue parameter specifies whether to enable the function that is controlled by the parameter identified by the ParaId parameter. Set ConfigValue based on the setting of the identified parameter.

4. If the ParaBitId parameter value is invalid and the magnitude of the ConfigValue parameter value needs to be greater than 2147483647 (0x7FFFFFFF in the hexadecimal format), set ConfigValue on the GUI to the negation of the number in two's complement. The unsigned number takes effect. For example, if the expected parameter value is 4294967294 (0xFFFFFFFE in the hexadecimal format), set ConfigValue on the GUI to -2 (0xFFFFFFFE in the hexadecimal format).
UE-specific Configuration Description

Indicates the description of the UE-specific configuration.
