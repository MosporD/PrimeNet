EuRrnRt

+-NE
  +-eNodeBFunction
    +-EuSubscriber
      +-EuRrnRt

Description

The EuRrnRt MO indicates the static IP route through which an RRN forwards IP packets.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EuSubscriber
  • Relation with the EuSubscriber MO:
    • Before configuring the LocalSubscriberId parameter in the EuRrnRt MO, ensure that the SubscriberType parameter corresponding to LocalSubscriberId in the EuSubscriber MO be set to RRN.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD EURRNRT

Use this command to add an EU RRN route.
LST EURRNRT

Use this command to list parameters in the EuRrnRt MO.
MOD EURRNRT

Use this command to modify the configuration of an EU RRN route.
RMV EURRNRT

Use this command to remove an EU RRN route.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Route ID

Indicates the ID of an IP route on an RRN. This parameter applies only to LTE FDD and LTE TDD.
Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Destination IP

Indicates the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.
Destination Mask

Indicates the subnet mask of the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.
Next Hop

Indicates the next-hop IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.
