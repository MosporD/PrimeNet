S1

+-NE
  +-eNodeBFunction
    +-S1

Description

An S1 MO is used to configure transport resources for S1 interfaces. The configuration items include the control-plane end point group ID, user-plane end point group ID, and the CN operator that owns the S1 object.

Effective Scenario

Immediately

    • CnOpSharingGroupId in the S1 MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
S1 ID

Indicates the S1 object ID.
CN Operator ID

Indicates the ID of the operator that owns the S1 object.
Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the S1 object.
User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the S1 object.
MME Release

Indicates the compliance protocol release of the MMEs to which the eNodeB is connected through the S1 interfaces under this S1 object. This parameter applies only to LTE FDD and LTE TDD.
User Label

Indicates the description of the S1 object.
End Point Group Config Flag

Indicates whether to configure the control-plane or user-plane endpoint group.
MME Selection Priority

Indicates the priority of an MME to which the eNodeB is connected through the S1 interface. A large parameter value indicates a high priority. After this parameter is set for MMEs, the eNodeB can select a high-priority MME for UEs attempting to access the network.
CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group that shares the S1 MO. If the eNodeB works in hybrid RAN sharing mode, set this parameter to a value within the range from 0 to 5. If the eNodeB works in independent operator mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, retain the default value 255, which is an invalid value.
MME supporting MDT or not

Indicates whether the MME at the other end of the S1 interface supports Huawei-proprietary positioning procedures, which are included in minimization of drive tests (MDT). The value DISABLE(disable) indicates that the MME does not support the procedures and therefore the eNodeB cannot obtain UE location information from the MME through the procedures. The value ENABLE(enable) indicates the opposite. For an S1 interface that is automatically set up, the MdtEnable parameter value in the MmefeatureCfg MO is obtained from the MdtEnable parameter in the S1 MO. This parameter applies only to LTE FDD and LTE TDD.
