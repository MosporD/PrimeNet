LwaMgtCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-LwaMgtCfg

Description

A LwaMgtCfg MO consists of parameters related to LWA carrier management, including LWA measurement configuration, and LWA algorithm switches.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST LWAMGTCFG

Use this command to list the settings of parameters related to LWA carrier management.
MOD LWAMGTCFG

Use this command to modify the settings of parameters related to LWA carrier management.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
LWA W1 Threshold

Indicates the threshold for LWA measurement events W1 and W2. When the RSSI value of a WLAN AP measured by a UE is greater than this threshold, an event W1 measurement report is triggered. This parameter can also be taken as the threshold 2 for event W2. This parameter applies only to LTE FDD.
LWA W2 Threshold 1

Indicates the threshold 1 for LWA measurement event W2. When the RSSI values of all WLAN APs in the mobility set of a UE are less than the threshold 1 of event W2 and the RSSI values of WLAN APs that are not in the mobility set are greater than threshold 2 of event W2, an event W2 measurement report is sent. This parameter applies only to LTE FDD.
LWA W3 Threshold

Indicates the triggering threshold for LWA measurement event W3. When the RSSI values of all WLAN APs in a mobility set measured by a UE are less than the threshold, an event W3 measurement report is sent. This parameter applies only to LTE FDD.
LWA W1 Time To Trigger

Indicates the time-to-trigger for LWA event W1. This parameter applies only to LTE FDD.
LWA W2 Time To Trigger

Indicates the time-to-trigger for LWA event W2. This parameter applies only to LTE FDD.
LWA W3 Time To Trigger

Indicates the time-to-trigger for LWA event W3. This parameter applies only to LTE FDD.
WLAN Measurement Hysteresis

Indicates the hysteresis for LWA measurement events. This parameter decreases the number of LWA measurement event triggering times due to radio signal fluctuations and reduces the probability of LWA offloading configuration decision errors and ping-pong configurations. A larger value of this parameter results in a lower probability. This parameter applies to W1, W2, and W3 measurements. This parameter applies only to LTE FDD.
Cell LWA Algorithm Switch

Indicates whether to enable cell-level LTE WLAN Aggregation (LWA). This parameter provides the following option:

LWA_DL_3C_SWITCH: Indicates whether to enable downlink 3C offloading in LWA. This function is enabled only if this option is selected. This option applies only to LTE FDD.
