UeCooperationPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-UeCooperationPara

Description

The UeCooperationPara MO consists of cell-level parameters related to UE cooperation. This MO is used to set the switch and parameters related to UE cooperation.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the TimeAlignmentTimer MO:
    • UEAwarePowerSavingSwitch in the UeCooperationPara can be set to ON(On) when Uplink timing advance command optimization switch in the Time Alignment Timer is set to ON(On).
  • Relation with the CellAlgoSwitch MO:
    • When the UlHCodeSwitch option of the UdcAlgoSwitch parameter in a CellAlgoSwitch is selected, the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO must also be selected.
    • When the VoLTEMoPrefSwitch option of the VoLTESwitch parameter in a CellAlgoSwitch MO is selected, the VoltePagingPriority parameter in the UeCooperationPara MO can be set to a value other than OFF.
  • Relation with the CellWttxParaCfg, SpidCfg, CellQciPara, and CellBf MOs:
    • The BfWeightOptDegreeFactor parameter in the CellBf MO must be set to 0 when none of the following conditions are met: The SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to SPID_BASED, the SpecifiedUserFlag parameter in a SpidCfg MO is set to SPECSERUSER; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to QCI_BASED, the ServiceFlag parameter in a CellQciPara is set to WBB_Service. Otherwise, the value range of the BfWeightOptDegreeFactor parameter in the CellBf MO is 0 to 255.
  • Relation with the Cell MO:
    • In TDD, the Tm9Port5Switch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO can be selected only when the SpecUeIdentifySwitch option of the same parameter is selected.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • The Tm9Port5Switch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO can be selected only when all of the following conditions are met: 1. The FddTddInd parameter in the Cell MO is set to CELL_TDD. 2. The TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R. 3. The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected. 4. The SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.
  • Relation with the Cell, CellMMAlgo, CellAlgoSwitch, and ENodeBAlgoSwitch MOs:
    • The MM_ANT_SEL_ENH_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only if the FddTddInd and TxRxMode parameters in the Cell MO are set to CELL_TDD and 64T64R or 32T32R respectively, the BfSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO is selected, and the UeSRSAntSelectCtrlSwitch option of the CompatibilityCtrlSwitch parameter in the ENODEBALGOSWITCH MO is deselected, the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UECOOPERATIONPARA MO is selected.
  • Relation with the Cell and ENodeBAlgoSwitch MOs:
    • The UlClosedloopIntelAntSelSwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO can be selected only if all of the following conditions are met: 1. The FddTddInd parameter in the associated Cell MO is set to CELL_TDD. 2. The UeSRSAntSelectCtrlSwitch option of the CompatibilityCtrlSwitch parameter in the ENodeBAlgoSwitch MO is deselected. 3. The TxRxMode parameter in the associated Cell MO is set to 64T64R, 32T32R, 8T8R, or 4T4R. 4. The SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.
LCID of MAC CE Message

Indicates the reserved LCID used by a Media Access Control control element (MAC CE) message. An eNodeB converts the specified value of this parameter to an enumerated value and then sends the enumerated value to the UE. The UE converts the received enumerated value back to the specified value of this parameter (that is, the actual reserved LCID). If this parameter is set to 17, 18, or 19, an eNodeB coverts the value to 1, 2, or 3, respectively. This parameter applies only to LTE FDD and LTE TDD.
A2 Handover Threshold Offset

Indicates the offset to the A2 threshold for UEs to request for restoring default DRX parameter settings. This offset is configured for UEs. UEs add this offset to another A2 threshold delivered from the eNodeB and use the sum as the threshold for triggering restoration of default DRX parameter settings. This parameter applies only to LTE FDD and LTE TDD.
A3 Handover Threshold Offset

Indicates the offset to the A3 threshold for UEs to request for restoring default DRX parameter settings. This offset is configured for UEs. UEs add this offset to another A3 threshold delivered from the eNodeB and use the sum as the threshold for triggering restoration of default DRX parameter settings. This parameter applies only to LTE FDD and LTE TDD.
UE Awareness Power Saving Switch

Indicates whether to allow UE-triggered power saving. If this parameter is set to ON, functions such as UE-triggered DRX parameter configuration and fast entering into the idle state are supported to save UE power. If this parameter is set to OFF, UE-triggered power saving functions are not supported. This parameter takes effect only on UEs that support UE-triggered power saving functions. This parameter applies only to LTE FDD and LTE TDD.
UE Forbidden Messages Threshold

Indicates the threshold for disabling power saving coordination for a UE. If the number of MAC CE messages sent by a UE within 10s exceeds this threshold, power saving coordination will be disabled for the current connection of the UE. This parameter applies only to LTE FDD and LTE TDD.
Specified User Cooperation Switch

Indicates whether to enable device-pipe synergy functions for specific UEs and support for high-power UEs.

SpecUeIdentifySwitch: Indicates whether to identify specific UEs. If this option is selected, specific UEs can be identified in the cell. If this option is deselected, specific UEs cannot be identified in the cell.

HighPowerUeSupportSwitch: Indicates whether the cell can serve high-power UEs. If this option is selected, the cell can serve high-power UEs. If this option is deselected, the cell cannot serve high-power UEs.

UlAntennaSmartSelectSwitch: Indicates whether to enable intelligent selection of antennas for the uplink. If this option is selected, intelligent selection of antennas for the uplink is enabled in the cell. If this option is deselected, intelligent selection of antennas for the uplink is disabled in the cell. This option applies only to LTE TDD.

UlQosEnhancementSwitch: Indicates whether to enable uplink QoS enhancement. If this option is selected, uplink QoS enhancement is enabled in the cell. If this option is deselected, uplink QoS enhancement is disabled in the cell. This option applies only to LTE FDD and LTE TDD.

UlClosedloopIntelAntSelSwitch: Indicates whether to enable intelligent uplink closed-loop antenna selection. If this option is selected, intelligent uplink closed-loop antenna selection is supported in the cell. If this option is deselected, intelligent uplink closed-loop antenna selection is not supported in the cell. This option applies only to LTE TDD.

Tm9Port5Switch: Indicates whether to allow the use of port 5 for data transmission in TM9. If this option is selected, antenna port 5 can be allocated for data transmission in TM9. If this option is deselected, antenna port 5 cannot be allocated for data transmission in TM9. This option applies only to LTE TDD.
DSDS Cooperation Reporting Switch

Indicates whether to enable algorithms of the coordinated control feature for dual-SIM dual-standby (DSDS) single-pass UEs. DSDS_STATUS_RPT_SWITCH: Indicates whether to allow DSDS UEs to timely report information about leaving and returning to the LTE network. If this option is selected, such UEs can report MCEs containing information about leaving and returning to the LTE network. If this option is deselected, such UEs cannot report MCEs containing information about leaving and returning to the LTE network. This option applies to LTE FDD and LTE TDD.

SCELL_ABNORMAL_RPT_SWITCH: Indicates whether to allow UEs to report abnormal SCCs. If this option is selected, the eNodeB allows UEs to report abnormal SCC status and sends an MCE for SCell deactivation to UEs to synchronize the SCC status between the eNodeB and UEs. If this option is deselected, the eNodeB does not allow UEs to report abnormal SCC status. This option applies to LTE FDD and LTE TDD.

TA_ABNORMAL_RPT_SWITCH: Indicates whether to allow UEs to report abnormal TAs. If this option is selected, the eNodeB allows UEs to report abnormal TAs and triggers the resynchronization process. If this option is deselected, the eNodeB does not allow UEs to report abnormal TAs. This option applies to LTE FDD and LTE TDD.
DSDS LCID

Indicates the LCID in the MAC control element (MCE) for coordinated control of dual-SIM dual-standby (DSDS) single-pass UEs. This parameter cannot be set to the same value as the MacCeMsgLCID parameter in the UeCooperationPara MO. This parameter applies only to LTE FDD and LTE TDD.
Special User Smart DRX Switch

Indicates whether to enable the power-saving function for specific UEs capable of device-pipe synergy. When this parameter is set to ON, smart DRX for such UEs is supported, reducing power consumption of these UEs. When this parameter is set to OFF, smart DRX is not supported for these UEs. This function requires support from specific UEs capable of device-pipe synergy. This parameter applies only to LTE FDD and LTE TDD.
VoLTE Paging Priority

Indicates whether to enable VoLTE marking in PS paging and the paging priority for VoLTE UEs. If this parameter is set to OFF, PS paging call flag addition is disabled. If this parameter is set to a value other than OFF, PS paging call flag addition is enabled. For the value range, see the definition of the paging priority IE in 3GPP TS 36.413. If PS paging call flag addition is enabled, the eNodeB identifies the paging priority of VoLTE services in S1 paging messages, and uses an extended bit in paging messages sent over the air interface to inform UEs of VoLTE paging. Then, UEs send the mo-VoiceCall-v1280 IE during network access. The eNodeB interprets this IE and handles these services by following the procedure for preferential access of mobile-originated VoLTE services. This parameter applies only to LTE FDD and LTE TDD.
