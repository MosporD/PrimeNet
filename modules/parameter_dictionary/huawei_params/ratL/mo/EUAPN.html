EUAPN

+-NE
  +-eNodeBFunction
    +-EUAPN
      +-EUAPNTemplate[0~64]

Description

Network identifier defined in the GPRS system.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    EUAPNTemplate[0~64]

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
APN

Indicates the network identification code. The value of this parameter can contain a maximum of seven dots (.). Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.
Primary Domain Name Server

This parameter specifies the IP address of the primary DNS. This parameter applies only to LTE FDD and LTE TDD.
Secondary Domain Name Server

This parameter specifies the IP address of the secondary DNS. This parameter applies only to LTE FDD and LTE TDD.
Address Pool ID

Indicates the ID of the IP address pool corresponding to the APN. This parameter applies only to LTE FDD and LTE TDD.
