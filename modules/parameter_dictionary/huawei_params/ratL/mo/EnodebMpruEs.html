EnodebMpruEs

+-NE
  +-eNodeBFunction
    +-EnodebMpruEs

Description

The EnodebMpruEs MO consists of the parameters used to configure eNodeB-level MPRU power saving.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the Cell and CellAlgoSwitch MOs:
    • The TDOA_SWITCH option of the LbsSwitch parameter in the CellAlgoSwitch MO cannot be selected for cells with the DlEarfcn parameter in the Cell MO set to the same value as the MpruDormancyDlEarfcn parameter in the EnodebMpruEs MO.
  • Relation with the EuSectorEqmGroup, SECTOREQM, and Cell MOs:
    • If the Cell MO is associated with at least one EuSectorEqmGroup MO which is configured with more than 16 SECTOREQM MOs, the DlEarfcn parameter in the Cell MO cannot be set to the same value as the MpruDormancyDlEarfcn parameter in the EnodebMpruEs MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP ENODEBMPRUDORMANCY

Use this command to display the MPRU dormancy state of an eNodeB. When the time and load conditions are met, the MPRUs available for dormancy are displayed in the command output.
LST ENODEBMPRUES

Use this command to list the settings of eNodeB-level MPRU energy saving parameters.
MOD ENODEBMPRUES

Use this command to modify the settings of eNodeB-level MPRU energy saving parameters.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
MPRU Dormancy Downlink EARFCN

Indicates the downlink EARFCN of the basic coverage carrier to be reserved after the MPRU enters dormancy. If this parameter is set to -1, MPRU dormancy is disabled. This parameter applies only to LTE FDD and LTE TDD.
MPRU Dormancy Downlink PRB Usage Threshold

Indicates the downlink PRB usage threshold for MPRU dormancy. If the downlink PRB usage of a carrier is lower than the value of this threshold, the MPRU enters dormancy. If the downlink PRB usage of a carrier is higher than the sum of the value of this threshold and a preset offset (5%), the MPRU exits dormancy. This parameter applies only to LTE FDD and LTE TDD.
MPRU Dormancy Minimum RSRP

Indicates the minimum RSRP of the basic coverage carrier to be reserved after the MPRU enters dormancy. This parameter applies only to LTE FDD and LTE TDD.
MPRU Dormancy Start Time

Indicates the start time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.
MPRU Dormancy Stop Time

Indicates the end time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.
