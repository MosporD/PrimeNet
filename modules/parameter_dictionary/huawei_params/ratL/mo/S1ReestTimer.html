S1ReestTimer

+-NE
  +-eNodeBFunction
    +-S1ReestTimer

Description

An S1ReestTimer MO consists of parameters related to the S1 reestablishment timer. This timer is used to prevent MME breakdown or exceptions caused by signaling storms that occur when multiple eNodeBs initiate S1 interface setup requests to one mobility management entity (MME) at the same time. If the S1 establishment requested by an eNodeB fails, the eNodeB initiates S1 reestablishment after a period. The length of the period is a random value within the range from the minimum length of the timer to the maximum length of the timer.

Effective Scenario

Immediately
