NrNFreqSCellOp

+-NE
  +-eNodeBFunction
    +-Cell
      +-NrNFreq
        +-NrNFreqSCellOp

Description

An NrNFreqSCellOp MO consists of parameters related to the serving-cell-PLMN-specific dedicated cell-reselection priority for an NR frequency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NrNFreq
  • Relation with the EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, Cdma2000BcSCellOp, EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs:
    • Cell reselection priorities based on operators of the local cell (which are specified in the NrNFreqSCellOp, EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, and Cdma2000BcSCellOp MOs) cannot coexist with cell reselection priorities based on operators of neighboring frequencies (which are specified in the EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs).
  • Relation with the CnOperator MO:
    • CnOperatorId in an NrNFreqSCellOp MO must have been set in the associated CnOperator MO.
  • Relation with the GeranNFGroupSCellOp MO:
    • Cell reselection priorities specified in the NrNFreqSCellOp and GeranNFGroupSCellOp MOs for the same operator cannot be the same.
  • Relation with the UtranNFreqSCellOp MO:
    • Cell reselection priorities specified in the NrNFreqSCellOp and UtranNFreqSCellOp MOs for the same operator cannot be the same.
  • Relation with the EutranNFreqSCellOp MO:
    • Cell reselection priorities specified in the NrNFreqSCellOp and EutranNFreqSCellOp MOs for the same operator cannot be the same.
  • Relation with the Cdma2000BcSCellOp MO:
    • Cell reselection priorities specified in the NrNFreqSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.
Downlink ARFCN

Indicates the downlink SSB ARFCN of neighboring NR frequency dedicated to the operator of the serving cell. This parameter applies only to LTE FDD and LTE TDD.
Cn Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.
Cell Reselection Priority Config Indicator

Indicates whether to configure the serving-cell-PLMN-specific cell-reselection priority for the NR frequency. This parameter applies only to LTE FDD and LTE TDD.
Cell Reselection Priority

Indicates the serving-cell-PLMN-specific dedicated cell-reselection priority for the NR frequency. The value 0 indicates the lowest priority. If SPIDs are configured, the SPID-specific dedicated cell-reselection priority is used. If SPIDs are not configured but this parameter is configured, the base station includes the cell-reselection priority specific to the PLMN that a UE supports in the IE idleModeMobilityControlInfo in the RRC connection release message. If operator-specific cell-reselection priority for the NR frequency is not configured, the UE uses the common cell-reselection priority for the NR frequency delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.
