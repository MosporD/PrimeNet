NbCellDynPwrShrPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-NbCellDynPwrShrPara

Description

The NbCellDynPwrShrPara MO consists of parameters used to configure dynamic power sharing for NB-IoT cells in in-band scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoSwitch and Cell MOs:
    • When the DlPrbUsageThld parameter in an NbCellDynPwrShrPara MO is set to a non-zero value, the NbCellFlag parameter in the associated Cell MO must be set to TRUE, and the COVERAGE_EXTENSION_SWITCH option of the NbCellAlgoSwitch parameter in a CellAlgoSwitch MO under this Cell MO must be selected.
  • Relation with the Cell, Prb, and CellEmtcAlgo MOs:
    • The DlPrbUsageThld parameter in an NbCellDynPwrShrPara MO can be set to a non-zero value only if the following conditions are met: The NbCellFlag parameter in the associated Cell MO is set to TRUE, the DeployMode parameter in the Prb MO under the Cell MO is set to IN_BAND(IN_BAND), the AnchorCarrierFlag parameter is set to TRUE, the bandwidth of the LTE cell associated by the LteCellId parameter in this Prb MO is higher than 5 MHz, and the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO of the LTE cell is deselected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

This parameter specifies the local ID of a cell. It uniquely identifies a cell within a eNodeB. This parameter applies only to NB-IoT.
Downlink PRB Usage Threshold

Indicates the LTE cell downlink PRB usage threshold for sharing power with NB-IoT cells in in-band deployment scenarios where NB-IoT dynamic power sharing is used. When this parameter is set to 0, NB-IoT dynamic power sharing does not take effect. When this parameter is set to a non-zero value, the eNodeB checks the downlink PRB usage of the LTE cell at intervals of 10s. If the downlink PRB usage is lower than or equal to this value for six consecutive times, the LTE cell can share its power with NB-IoT cells during the time when NB-IoT dynamic power sharing is effective. If the PRB usage of the LTE cell is greater than the threshold by 10% or more, or if the condition that the PRB usage of the LTE cell is greater than the threshold by 5% or more is satisfied for 20 times or more within 10 minutes, the LTE cell stops sharing its power with the NB-IoT cells.

This parameter applies only to NB-IoT.
Start Time

Indicates the time when NB-IoT dynamic power sharing starts to take effect. This parameter and the EndTime parameter define the time segment in which NB-IoT dynamic power sharing takes effect. This parameter applies only to NB-IoT.
End Time

Indicates the time when NB-IoT dynamic power sharing stops taking effect. This parameter and the StartTime parameter define the time segment in which NB-IoT dynamic power sharing takes effect. This parameter applies only to NB-IoT.
