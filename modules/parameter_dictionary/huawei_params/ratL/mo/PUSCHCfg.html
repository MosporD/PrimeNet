PUSCHCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-PUSCHCfg

Description

The PUSCHCfg MO consists of the parameters used to configure the physical uplink shared channel (PUSCH) in a cell.

The PUSCH carries the UL shared channel (UL-SCH).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellUlschAlgo MO:
    • If HoppingMode in the PUSCHCfg MO is set to INTRA_AND_INTER_SUB_FRAME and UlHoppingType in the CellUlschAlgo MO is set to HOPPING_TYPE2, Nsb in the PUSCHCfg MO must be set to 1.
    • If HoppingMode in the PUSCHCfg MO is set to INTER_SUB_FRAME and UlHoppingType in the CellUlschAlgo MO is set to HOPPING_TYPE2_RANDOM, Nsb in the PUSCHCfg MO cannot be set to 1.
    • If the UlHoppingType parameter in the CellUlschAlgo MO is set to HOPPING_OFF and the HoppingOffset parameter in the PUSCHCfg MO is set to 0, the IntvlOfUlSpsWithSkipping parameter in the CellUlschAlgo MO can be set to a value other than MS0.
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to FALSE, the number of RB resources corresponding to the value of UlBandWidth in a Cell MO must be greater than or equal to the value of HoppingOffset in the PUSCHCfg MO. If UlBandWidth is set to CELL_BW_N6(1.4M), the number of RB resources is 6. If UlBandWidth is set to CELL_BW_N15(3M), the number of RB resources is 15. If UlBandWidth is set to CELL_BW_N25(5M), the number of RB resources is 25. If UlBandWidth is set to CELL_BW_N50(10M), the number of RB resources is 50. If UlBandWidth is set to CELL_BW_N75(15M), the number of RB resources is 75. If UlBandWidth is set to CELL_BW_N100(20M), the number of RB resources is 100.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, and the TxRxMode parameter in this MO is set to 8T8R or 32T32R, the HoppingMode parameter in the PUSCHCfg MO must be set to INTER_SUB_FRAME.
    • The HoppingMode parameter in the PUSCHCfg MO can be set to INTRA_AND_INTER_SUB_FRAME only if the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED.
  • Relation with the CellUlschAlgo and Cell MOs:
    • Let A be the number of RB resources corresponding to the value of UlBandWidth in a Cell MO, B the even number that HoppingOffset in the PUSCHCfg MO is rounded up to, and C the difference between A and B. When the NbCellFlag in a Cell MO is set to FALSE, if UlHoppingType in the CellUlschAlgo MO is set to HOPPING_TYPE1, C must be greater than A modulo 2. If UlHoppingType in the CellUlschAlgo MO is set to HOPPING_TYPE2 or HOPPING_TYPE2_RANDOM, and Nsb in the PUSCHCfg MO is greater than 1, the integer value of C divide Nsb in the PUSCHCfg MO must be greater than 0. If UlBandWidth is set to CELL_BW_N6(1.4M), the number of RB resources is 6. If UlBandWidth is set to CELL_BW_N15(3M), the number of RB resources is 15. If UlBandWidth is set to CELL_BW_N25(5M), the number of RB resources is 25. If UlBandWidth is set to CELL_BW_N50(10M), the number of RB resources is 50. If UlBandWidth is set to CELL_BW_N75(15M), the number of RB resources is 75. If UlBandWidth is set to CELL_BW_N100(20M), the number of RB resources is 100.
  • Relation with the Cell, CellAlgoSwitch, NCellSrsMeasPara, CellUlIcAlgo, and SectorSplitCell MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, the MASSIVE_MIMO_SRS_IC_SW option of the SrsIcSwitch parameter in the CellUlIcAlgo MO can be selected only if the SrsTimeMeasSwitch option of the SrsAlgoSwitch parameter in the CellAlgoSwitch MO is selected, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO is set to ON, the NCellSrsTimeMeasSwitch option of the NCellMeasSwitch parameter in the NCellSrsMeasPara MO is selected, the GroupHoppingEnabled in the PUSCHCfg MO is set to BOOLEAN_FALSE, and the SeqHoppingEnabled parameter in the PUSCHCfg MO is set to BOOLEAN_FALSE.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Subband number

Indicates the number of PUSCH sub-bands.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Hopping mode

Indicates the hopping mode of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Hopping offset

Indicates the hopping offset of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Group hopping enabled

Indicates whether group hopping of the PUSCH is enabled.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Group assignment PUSCH

Indicates the group assignment of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Sequence hopping enabled

Indicates whether sequence hopping of the PUSCH is enabled.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Cyclic shift

Indicates the cyclic shift of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
Qam64 enabled

Indicates whether 64QAM of the PUSCH is enabled.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
R12 UL 64QAM Enabled

Indicates whether the eNodeB supports UL 64QAM for UEs compliant with 3GPP Release 12 and later. This parameter is valid only when the Qam64Enabled parameter in the PUSCHCfg MO is set to BOOLEAN_TRUE. When R12Qam64Enabled is set to BOOLEAN_TRUE, the eNodeB supports UL 64QAM for UEs compliant with 3GPP TS 36.331 V12.7.0 or later as well as for UEs compliant with versions earlier than 3GPP TS 36.331 V12.7.0. When R12Qam64Enabled is set to BOOLEAN_FALSE, the eNodeB does not support UL 64QAM for certain UEs, except CAT5 and CAT8 UEs, that comply with versions later than 3GPP TS 36.331 V12.7.0.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
UL 256QAM Algorithm Switch

Indicates whether to enable uplink 256QAM.

UL_256QAM_SWITCH: If this option is selected, uplink 256QAM is enabled. The maximum uplink modulation scheme can be 256QAM for UEs supporting uplink 256QAM. If this option is deselected, uplink 256QAM is disabled. The maximum uplink modulation scheme is 64QAM. This option applies only to LTE TDD.
UL 256QAM MCS Table Adaptive Period

Indicates the period for adaptation of the MCS table for uplink 256QAM. This parameter is valid only if the adaptive MCS table configuration policy is used. This parameter applies only to LTE TDD.
UL 256QAM MCS Table Configuration Strategy

Indicates the MCS table configuration policy for uplink 256QAM. The policy can be fixed or adaptive.

If this parameter is set to FIXED_CONFIGURATION, the MCS table supporting 256QAM is always used for uplink scheduling of UEs supporting 256QAM. If this parameter is set to ADAPTIVE_CONFIGURATION, the eNodeB adaptively selects the MCS table supporting or not supporting 256QAM based on channel quality for UEs supporting uplink 256QAM. This parameter is valid only if the UL_256QAM_SWITCH option is selected. This parameter applies only to LTE TDD.
