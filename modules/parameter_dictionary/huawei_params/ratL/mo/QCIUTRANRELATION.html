QCIUTRANRELATION

+-NE
  +-eNodeBFunction
    +-Cell
      +-QCIUTRANRELATION

Description

A QCIUTRANRELATION MO consists of parameters related to the relationship between a UTRAN frequency and a QCI to deploy QCI-specific policies for the frequency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the UtranNFreq MO:
    • Before adding an QCIUTRANRELATION, ensure that the associated UtranNFreq has been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD QCIUTRANRELATION

Use this command to add a relationship between a QCI and a UTRAN frequency.
LST QCIUTRANRELATION

Use this command to list the configurations of the relationship between a QCI and a UTRAN frequency.
MOD QCIUTRANRELATION

Use this command to modify the configurations of the relationship between a QCI and a UTRAN frequency.
RMV QCIUTRANRELATION

Use this command to remove a relationship between a QCI and a UTRAN frequency.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
UTRAN Downlink EARFCN

Indicates the downlink (DL) UTRA absolute radio frequency channel number (UARFCN) associated with the QCI. This parameter applies only to LTE FDD and LTE TDD.
QCI UTRAN Frequency Relation ID

Indicates the ID of the QCI and UTRAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.
Mobility Target Indicator

Indicates whether the UTRAN frequency can be a target frequency in QCI-specific mobility management.

MlbTargetInd(MlbTargetInd): The UTRAN frequency can be a target frequency in QCI-specific MLB only if this option is selected. You are advised to select this option for the default bearer. Otherwise, MLB may not transfer UEs. This option applies only to LTE FDD and LTE TDD.
