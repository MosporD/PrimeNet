NrNFreq

+-NE
  +-eNodeBFunction
    +-Cell
      +-NrNFreq
        +-NrNFreqSCellOp[0~6]

Description

This MO consists of parameters related to a neighboring NR frequency, which can be used for SgNB addition for LTE-NR NSA DC, and LTE-to-NR handover, redirection, and cell reselection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

  • Possible children:

    NrNFreqSCellOp[0~6]
  • Relation with the Cell MO:
    • A maximum of 16 NrNFreq MOs can be configured for each cell.
  • Relation with the NrNRelationship and NrExternalCell MOs:
    • DlArfcn in the NrExternalCell MO associated with a NrNRelationship MO must have been configured in a NrNFreq MO.
  • Relation with the EutranInterNFreq and CellReselToNr MOs:
    • If CellReselPriorityCfgInd in EutranInterNFreq MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the UtranNFreq and CellReselToNr MOs:
    • If CellReselPriorityCfgInd in UtranNFreq MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the GeranNfreqGroup and CellReselToNr MOs:
    • If CellReselPriorityCfgInd in GeranNfreqGroup MO is set to CFG and a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.
  • Relation with the CellResel and CellReselToNr MOs:
    • If a minimum of one CellReselToNr MO instances can be configured, CellReselPriority and the sum of NrFreqReselPriority and NrFreqReselSubPriority cannot be set to a same value for each cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Downlink ARFCN

Indicates the downlink SSB ARFCN of the neighboring NR cell. This parameter applies only to LTE FDD and LTE TDD.
Uplink ARFCN Configuration Indicator

Indicates whether to configure the uplink ARFCN. If the uplink ARFCN does not need to be configured, the system calculates the uplink ARFCN based on the default spacing between transmit (TX) and receive (RX) frequencies defined in 3GPP specifications. This parameter applies only to LTE FDD and LTE TDD.
Uplink ARFCN

Indicates the uplink ARFCN of the neighboring NR cell. This parameter applies only to LTE FDD and LTE TDD.
Frequency Priority for Connected Mode

Indicates the frequency priority for measurement frequency delivery. During measurement configuration delivery, higher-priority frequencies are preferentially delivered to UEs in connected mode. A larger value indicates a higher priority. This parameter applies only to LTE FDD and LTE TDD.
Frequency-specific Offset

Indicates the offset to the NR frequency. It determines the probability of triggering measurement reports for events B1 and B2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Minimum RX Level

Indicates the minimum receive level required for an NR cell. It is included in criterion S and for cell selection. During the evaluation for cell reselection, the UE calculates Srxlev using the following formula: Srxlev = Measured RSRP value of a cell on the target frequency - Value of this parameter - Power ompensation value. If the Srxlev value is always greater than the level threshold for target cell reselection during the time-to-trigger, the cell is the target cell for reselection. For details, see 3GPP TS 38.304. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency High Priority Reselection Thld

Indicates the threshold of the receive level required for a cell on a frequency on the higher-priority NR band class to become a candidate for cell reselection, when the reselection priority of cells on the target frequency is higher than that of the serving cell.

After measurements are started for neighboring cells on the target frequency, the UE reselects a neighboring cell on this frequency only if the receive level of this cell is always greater than this parameter value during the time-to-trigger. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency Low Priority Reselection Thld

Indicates the threshold of the receive level required for a cell on a frequency on the lower-priority NR band class to become a candidate for cell reselection, when the reselection priority of cells on the target frequency is lower than that of the serving cell. After measurements are started for neighboring cells on the target frequency, the UE reselects a cell on this frequency only if the receive level of the serving cell is always lower than this parameter value and that of the cell is always greater than this parameter value during the time-to-trigger. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency Reselection Priority

Indicates the cell reselection priority of the NR frequency. The value 0 indicates the lowest priority. The value 255 indicates that no cell reselection priority is configured for the NR frequency. A UE obtains the sum of the value of this parameter and the value of the NrFreqReselSubPriority parameter in the NrNFreq MO and then compares the sum and the value of the CellReselPriority parameter in the CellResel MO for the serving cell. If the sum is greater than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency. The UE starts cell reselection when the signal quality of a cell on the neighboring NR frequency meets the specified requirement throughout the time specified by the NrCellReselectionTimer parameter in the CellReselToNr MO. If the sum is less than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency only when the signal quality of the serving cell is poor. The UE starts cell reselection when the following conditions are met: (a) The signal quality of the serving cell is lower than the threshold specified by the ThrshServLow parameter in the CellResel MO and the signal quality of a cell on the neighboring NR frequency is higher than the threshold specified by the NrFreqLowPriReselThld parameter in the NrNFreq MO throughout the time specified by the NrCellReselectionTimer parameter in the CellReselToNr MO; (b) The UE has camped on the serving cell for more than 1s. The sum of the cell reselection priority and cell reselection sub-priority cannot be the same for inter-RAT frequencies. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SSB Offset

Indicates the SSB offset for NR cells. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD. If the SsbPeriod parameter is set to 5MS, this parameter value ranges from 0 to 4. If the SsbPeriod parameter is set to 10MS, this parameter value ranges from 0 to 9. If the SsbPeriod parameter is set to 20MS, this parameter value ranges from 0 to 19. If the SsbPeriod parameter is set to 40MS, this parameter value ranges from 0 to 39. If the SsbPeriod parameter is set to 80MS, this parameter value ranges from 0 to 79. If the SsbPeriod parameter is set to 160MS, this parameter value ranges from 0 to 159.
SSB Measurement Duration

Indicates the duration in which UEs measure the SSB burst set of NR cells. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
SSB Period

Indicates the SSB period for NR cells. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Subcarrier Spacing

Indicates the SSB subcarrier spacing of the neighboring NR frequency. Set this parameter based on the NR network plan. For details about this parameter, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.
Aggregation Attribute

Indicates the aggregation attributes of the neighboring NG-RAN frequency.

ANR_INDICATION: Indicates whether ANR can maintain the information of NR neighboring cells and external cells on the neighboring NG-RAN frequency. If this option is selected, ANR can maintain the information. If this option is deselected, ANR cannot maintain the information. This option applies only to LTE FDD and LTE TDD.

SSB_INDEX_FROM_CELL_INDICATION: Indicates whether UEs can deduce the SSB index of the cell based on the given SSB frequency and subcarrier spacing as well as the time sequence of any cell detected to be with the same SSB frequency and subcarrier spacing as the given SSB frequency and subcarrier spacing. If this option is selected, UEs assume that the SFNs and frame boundaries of cells are aligned on the same NR carrier specified in 3GPP TS 36.133, and then deduce the SSB index of the cell. If this option is deselected, UEs do not make the preceding assumption or deduction. This option applies only to LTE FDD and LTE TDD.

SIB24_EXCLUDE_FREQ_INDICATION: Indicates whether SIB24 contains the NR frequency. If this option is selected, SIB24 does not contain the NR frequency. If this option is deselected, SIB24 contains the NR frequency. This option applies only to FDD and TDD.
Maximum Allowed Transmit Power

Indicates the maximum uplink UE transmit power allowed by the NR system. This parameter is used in the decision of the cell selection criterion (criterion S) to calculate the power compensation value. For details, see 3GPP TS 38.304. This parameter applies only to LTE FDD and LTE TDD.
RS Quality Thld for Cell Quality Calc

Indicates the threshold for determining the beam-level SSB measurement results that can be used to calculate cell-level SSB values. If the RSRP values of one or more SSB-generated beams in the cell are greater than the value of this parameter, the linear average of the RSRP values of at most N of these beams is used as the cell-level RSRP (N is less than the value of MaxRsQtyForCellQltyCalc). If none of the RSRP values of SSB-generated beams is greater than the value of this parameter, the largest RSRP value out of the RSRP values of all the beams is used as the cell-level RSRP. This parameter corresponds to the ThresholdListNR-r15:nr-RSRP-r15 IE described in 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Max RS Quantity for Cell Quality Calc

Indicates the maximum number of SSBs whose RSRP values can be used by UEs to calculate cell-level RSRP values. This parameter corresponds to the MaxRS-IndexCellQualNR-r15 parameter described in 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency High Priority RSRQ Resel Thld

Indicates the RSRQ threshold used for cell reselection to the NR frequency with a higher cell reselection priority than the serving frequency. If this parameter is set to 255, RSRQ-based measurement configurations are not delivered for cell reselection to NR. This parameter specifies the RX level required for a cell on the target frequency to become a candidate for cell reselection if the cell reselection priority of the target frequency is higher than that of the serving frequency.

After a UE starts to measure neighboring cells on the target frequency, the UE can reselect to a neighboring cell on this frequency if the RSRQ of this cell is consistently higher than the value of this parameter for a period of time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency Low Priority RSRQ Resel Thld

Indicates the RSRQ threshold used for cell reselection to the NR frequency with a lower cell reselection priority than the serving frequency. If this parameter is set to 255, RSRQ-based measurement configurations are not delivered for cell reselection to NR. This parameter specifies the RX level required for a cell on the target frequency to become a candidate for cell reselection if the cell reselection priority of the target frequency is lower than that of the serving frequency.

After a UE starts to measure neighboring cells on the target frequency, the UE can reselect to a cell on this frequency if the RSRQ of the serving cell is consistently lower than a specific cell reselection threshold and that of the cell on the target frequency is consistently higher than the value of this parameter for a period of time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NR Frequency Reselection Sub-Priority

Indicates the cell reselection sub-priority of the NR frequency. If this parameter is set to ZERO, the cell reselection sub-priority will not be delivered for the NR frequency. A UE obtains the sum of the value of this parameter and the value of the NrFreqReselPriority parameter in the NrNFreq MO and then compares the sum with the value of the CellReselPriority parameter in the CellResel MO for the serving cell.

If the sum is greater than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency. The UE starts cell reselection when the signal quality of a cell on the neighboring NR frequency meets the specified requirement throughout the time specified by the NrCellReselectionTimer parameter in the CellReselToNr MO. If the sum is less than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency only when the signal quality of the serving cell is poor. The UE starts cell reselection when the following conditions are met: (a) The signal quality of the serving cell is lower than the threshold specified by the CellResel.ThrshServLow parameter and the signal quality of a cell on the neighboring NR frequency is higher than the threshold specified by the NrNFreq.NrFreqLowPriReselThld parameter throughout the time specified by the CellReselToNr.NrCellReselectionTimer parameter; (b) The UE has camped on the serving cell for more than 1s. The sum of the cell reselection priority and cell reselection sub-priority cannot be the same for inter-RAT frequencies. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
VoNR Priority

Indicates the VoNR priority of the neighboring NR frequency. If this parameter is set to 255, the frequency does not support VoNR. If this parameter is set to a value in the range of 0 to 16, the frequency supports VoNR and the value indicates the VoNR priority of the frequency. A larger value indicates a higher priority. Frequencies with high VoNR priorities are preferentially delivered to UEs for measurements. This parameter applies only to LTE FDD and LTE TDD.
