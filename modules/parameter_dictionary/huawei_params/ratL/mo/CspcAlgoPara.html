CspcAlgoPara

+-NE
  +-eNodeBFunction
    +-CspcAlgoPara

Description

The CspcAlgoPara MO consists of parameters related to the coordinated scheduling and power control (CSPC) algorithm. The parameters take effect on the centralized control node in Cloud BB scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the EuCoSchDLCoMPCfg MO:
    • If the InterEnbDlCompSwitch parameter in the EuCoSchDLCoMPCfg MO is set to ON, the CspcAlgoSwitch parameter in the CspcAlgoPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be cleared.
  • Relation with the CoProcRes MO:
    • If the CspcAlgoSwitch parameter in the CspcAlgoPara MO is set to ON(On), there must be at least one CoProcRes MO in which the CLUSTER_MANAGEMENT option of the WorkMode parameter is selected.
  • Relation with the CellDynPowerSharing, CellCspcPara, CellAlgoSwitch, Cell, and PHICHCfg MOs:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only when the following conditions are met: The GLPwrShare parameter in the CellAlgoSwitch MO, the CspcAlgoSwitch parameter in the CspcAlgoPara MO, and the CellCspcSwitch and CelleCspcSwitch parameters in the CellCspcPara MO are set to OFF, the PhichInnerLoopPcSwitch option of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, and the PhichDuration parameter in the PHICHCfg MO is not set to EXTENDED.
  • Relation with the CellDynPowerSharing, ENodeBAlgoSwitch, and CellAlgoSwitch MOs:
    • The LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only if the DlIcicSwitch parameter in the ENodeBAlgoSwitch MO is set to DlIcicSwitch_OFF_ENUM, the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO is deselected, and both the BFModeUserAdptPwrSwitch and BFModeUserPwrSwitch options of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO are deselected.
  • Relation with the CellAlgoSwitch MO:
    • The switches indicated by the Sa1Sa2InterfCoordSwitch option of the AvoidInterfSwitch parameter in the CellAlgoSwitch MO and the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO cannot be both turned on.
  • Relation with the SymbolPwrSaving and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_FDD for the same cell, the CspcAlgoSwitch parameter in the CspcAlgoPara MO must be set to OFF.
  • Relation with the SymbolPwrSaving, Cell, and CellCspcPara MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the same cell, then the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected and the CellCspcSwitch parameter in the CellCspcPara MO must be set to OFF for the cell.
  • Relation with the Cell, SectorSplitCell, SectorSplitGroup, and CellCspcPara MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to NOT_CFG, then the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, the SectorSplitCell MO associated with the Cell MO is configured, and the BeamDeploymentMode parameter in the SectorSplitGroup MO is set to MODE_3, then the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF and the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected.
  • Relation with the Cell and CellDlschAlgo MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the DL_INTRA_JAMC_ALGO_SW option of the DlJointAMCAlgoSw parameter in the CellDlschAlgo MO is selected, the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CSPC Algorithm Switch

Indicates whether to enable CSPC in cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE FDD.
CSPC RSRP Measurement Mode

Indicates the measurement mode of the reference signal received power (RSRP) used in CSPC. The uplink RSRP is measured based on the uplink sounding reference signal (SRS) measurement. This parameter applies only to LTE FDD.
CSPC Cluster Mode

Indicates the mode of grouping cells into clusters for CSPC. If this parameter is set to STATIC_CONFIG, cells must be manually grouped into clusters for CSPC based on site scenarios. If this parameter is set to DYNAMIC_PARTITION_CONFIG, the centralized control node periodically groups cells into clusters for CSPC based on site scenarios. The DYNAMIC_PARTITION_CONFIG value does not take effect currently. This parameter applies only to LTE FDD and LTE TDD.
CSPC Cluster Partition Period

Indicates the interval at which cells are grouped into clusters for CSPC. The interval can be configured based on site scenarios. This parameter currently does not take effect because dynamic clustering is not supported. This parameter applies only to LTE FDD.
CSPC Power Config Delay

Indicates the interval between the time that an eNodeB reports measurement information to the centralized control node and the time that the power configuration delivered by the centralized control node takes effect on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
CSPC Schedule UE Specification

Indicates the maximum number of UEs that can be selected for CSPC. This parameter applies only to LTE FDD and LTE TDD.
CSPC Enable Downlink PRB Ratio Threshold

Indicates the physical resource block (PRB) usage threshold for enabling coordinated scheduling-based power control (CSPC). CSPC is enabled when the highest PRB usage among all cells in a CSPC cluster is greater than this parameter value. To prevent CSPC from being enabled and disabled frequently in the cluster, the PRB usage threshold for disabling CSPC is lower than this parameter value. This parameter applies only to LTE FDD.
TDD Cspc Algorithm Switch

Indicates whether to enable CSPC for cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE TDD.
CSPC Capacity Factor

Indicates the acceptable capacity loss proportion in a network with CSPC enabled. This parameter affects the gain for cell edge UEs. Set this parameter in heavily-loaded networks to adjust cell downlink throughput and the downlink throughput gain of cell edge UEs. If this parameter is set to 100, network capacity loss is not considered, and the downlink throughput gain of cell edge UEs reaches the maximum. If this parameter is set to 0, it is preferential to guarantee that capacity loss does not occur in heavily-loaded networks. However, the downlink throughput gain of cell edge UEs decreases. This parameter applies only to LTE FDD.
