PHICHCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-PHICHCfg

Description

The PHICHCfg MO consists of the parameters used to configure the physical HARQ indicator channel (PHICH) in a cell. The PHICH carries HARQ ACK/NACK messages for the UL data.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If CustomizedBandWidthCfgInd is set to CFG, CustomizedDLBandWidth is set to a value in the range of 44 to 47 or 80 or 89 to 95 or 183 to 192, and DlPuncturedRbNum is set to a value other than 0 in a Cell MO, PhichResource in the associated PHICHCfg MO cannot be set to TWO.
  • Relation with the CellPdcchAlgo and Cell MOs:
    • When the NbCellFlag in a Cell MO is set to FALSE, if PhichDuration in the PHICHCfg MO is set to NORMAL, and PdcchSymNumSwitch in the CellPdcchAlgo MO is set to OFF, InitPdcchSymNum in the CellPdcchAlgo MO cannot be set to 1 if the cell bandwidth is 1.4 MHz.
    • When the NbCellFlag in a Cell MO is set to FALSE, if PhichDuration in the PHICHCfg MO is set to NORMAL, InitPdcchSymNum in the CellPdcchAlgo MO cannot be set to 4 if the cell bandwidth is not 1.4 MHz.
    • When the NbCellFlag in a Cell MO is set to FALSE, if PhichDuration in the PHICHCfg MO is set to EXTENDED, InitPdcchSymNum in the CellPdcchAlgo MO can be set to 3 or 4 if the cell bandwidth is 1.4 MHz.
    • When the NbCellFlag in a Cell MO is set to FALSE, if PhichDuration in the PHICHCfg MO is set to EXTENDED, InitPdcchSymNum in the CellPdcchAlgo MO must be set to 3 when the cell bandwidth is not 1.4 MHz.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, the DlBandWidth parameter in a Cell MO is set to CELL_BW_N50, and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the PhichResource parameter in the associated PHICHCfg MO cannot be set to TWO.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the PhichDuration parameter in the associated PHICHCfg MO must be set to NORMAL.
  • Relation with the CellDynPowerSharing, CspcAlgoPara, CellCspcPara, CellAlgoSwitch, and Cell MOs:
    • The LTE_DYN_POWER_SHARING_SW and LTE_EXTREME_POWER_SHARING_SW options of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only when the following conditions are met: The GLPwrShare parameter in the CellAlgoSwitch MO, the CspcAlgoSwitch parameter in the CspcAlgoPara MO, and the CellCspcSwitch and CelleCspcSwitch parameters in the CellCspcPara MO are set to OFF, the PhichInnerLoopPcSwitch option of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED, and the PhichDuration parameter in the PHICHCfg MO is not set to EXTENDED.
  • Relation with the CellAlgoExtSwitch MO:
    • If UlCoverageEnhancementSw in the CellAlgoExtSwitch MO is set to ON, PhichDuration in the PHICHCfg MO must be set to NORMAL.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
PHICH duration

Indicates the PHICH duration type. If this parameter is set to NORMAL, the number of OFDM symbols occupied by the PDCCH is automatically adjusted. If this parameter is set to EXTENDED, the number of OFDM symbols occupied by the PDCCH is fixed. Specifically, this number is fixed to 3 or 4 for 1.4 MHz cells and 3 for cells with other bandwidths. For the mapping between the type and the duration, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
PHICH resource

Indicates a coefficient that is used to calculate the resources used by the PHICH for the cell. It corresponds to the Ng parameter in the protocol.

For details on the usage of the Ng parameter, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
