eX2

+-NE
  +-eNodeBFunction
    +-eX2

Description

An eX2 MO consists of parameters related to the transport resources used by the eX2 interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the S1 MO:
    • CpEpGroupId in an eX2 MO must be different from CpEpGroupId in any S1 MO.
    • UpEpGroupId in an eX2 MO must be different from UpEpGroupId in any S1 MO.
    • CpEpGroupId in an eX2 MO must be different from UpEpGroupId in any S1 MO.
    • UpEpGroupId in an eX2 MO must be different from CpEpGroupId in any S1 MO.
  • Relation with the X2 MO:
    • CpEpGroupId in an eX2 MO must be different from CpEpGroupId in any X2 MO.
  • Relation with the ECO MO:
    • CpEpGroupId in an eX2 MO must be different from CpEpGroupId in the ECO MO.
    • UpEpGroupId in an eX2 MO must be different from UpEpGroupId in the ECO MO.
    • CpEpGroupId in an eX2 MO must be different from UpEpGroupId in the ECO MO.
    • UpEpGroupId in an eX2 MO must be different from CpEpGroupId in the ECO MO.
  • Relation with the M1 MO:
    • CpEpGroupId in an eX2 MO must be different from M1EpGroupId in the M1 MO.
    • UpEpGroupId in an eX2 MO must be different from M1EpGroupId in the M1 MO.
  • Relation with the M2 MO:
    • CpEpGroupId in an eX2 MO must be different from M2EpGroupId in the M2 MO.
    • UpEpGroupId in an eX2 MO must be different from M2EpGroupId in the M2 MO.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by CpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO must reference an SCTPHOST MO.
    • The EPGROUP MO referenced by CpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO can reference only one SCTPHOST MO whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by CpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO can reference only one SCTPHOST MO whose IPVERSION is set to IPv6.
    • The EPGROUP MO referenced by UpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO must reference a USERPLANEHOST MO.
    • The EPGROUP MO referenced by UpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO can reference at most six USERPLANEHOST MOs whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by UpEpGroupId in an eX2 MO must be configured, and this EPGROUP MO can reference at most six USERPLANEHOST MOs whose IPVERSION is set to IPv6.
  • Relation with the EPGROUP and GTRANSPARA MOs:
    • If EPCFGMODE in the GTRANSPARA MO is not set to EX2SIMPLE_MODE, the EPGROUP MO referenced by CpEpGroupId in an eX2 MO must be configured.
    • If EPCFGMODE in the GTRANSPARA MO is not set to EX2SIMPLE_MODE, the EPGROUP MO referenced by UpEpGroupId in an eX2 MO must be configured.
  • Relation with the SO MO:
    • CpEpGroupId in an eX2 MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an eX2 MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an eX2 MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an eX2 MO must be different from CpEpGroupId in any SO MO.
  • Relation with the SCTPHOST and GTRANSPARA MOs:
    • If EPCFGMODE in a GTRANSPARA MO is set to EX2SIMPLE_MODE, an SCTPHOST MO with SIMPLEMODESWITCH set to EX2SIMPLE_MODE_ON must have been configured, and CpEpGroupId in the eX2 MO must be equal to CPEPGROUPID1 and UpEpGroupId in the eX2 MO must be equal to UPEPGROUPID1.
  • Relation with the GlobalProcSwitch MO:
    • If ItfTypeForNonIdealModeServ in the GlobalProcSwitch MO is set to X2, no eX2 MOs with BackhaulType set to NON_IDEAL can be configured.
  • Relation with the X2 and GTRANSPARA MOs:
    • If X2 and eX2 MO are all existed, the value X2SIMPLE_MODE and EX2SIMPLE_MODE of EPCFGMODE in GTRANSPARA MO must be the same.
  • Relation with the XW MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any eX2 MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any eX2 MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any eX2 MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any eX2 MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by the UpEpGroupId parameter in an eX2 MO must be configured. In addition, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to DISABLE.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
eX2 Object ID

Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.
End-Point Group Configuration Flag

Indicates whether to configure the control-plane or user-plane end point group. This parameter applies only to LTE FDD and LTE TDD.
Control Plane End-Point Group ID

Indicates the ID of the control-plane end point group used by the eX2 object. This parameter applies only to LTE FDD and LTE TDD.
User Plane End-Point Group ID

Indicates the ID of the user-plane end point group used by the eX2 object. This parameter applies only to LTE FDD and LTE TDD.
eX2 Interface Backhaul Type

Indicates the transport type of the eX2 interface. SRIO- or Ethernet-based transport system connecting through the USU is called ideal backhaul. IPRAN- or PTN-based transport system shared with the S1 or X2 interface is called non-ideal backhaul. The transport type of eX2 interfaces between logical eNodeBs contained in a physical network (for example, a physical eNodeB) is called intra physical network domain ideal backhaul. This parameter applies only to LTE FDD and LTE TDD.
eX2 Object Description

Indicates the description of the eX2 object. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates whether the MO can be automatically modified or removed by the eNodeB. If this parameter is set to MANUAL_MODE(Manual Mode), both operators and the eNodeB can modify or remove this MO. If this parameter is set to AUTO_MODE(Auto Mode), only the eNodeB can modify or remove this MO.
Table 3 Dynamic parameters

Parameter

Description
eX2 Interface ID

Indicates the eX2 interface ID. This parameter applies only to LTE FDD and LTE TDD.
eX2 Interface State

Indicates the status of the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.
eX2 Interface CP Bearer ID

Indicates the control port (CP) bearer ID of the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.
eX2 Interface CP Bearer State

Indicates the status of the CP bearer for the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.
