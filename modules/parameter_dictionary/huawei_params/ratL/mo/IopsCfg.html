IopsCfg

+-NE
  +-eNodeBFunction
    +-IopsCfg

Description

The IopsCfg MO consists of the IOPS switch and related parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the ENodeBSharingMode MO:
    • IopsSwitch in the IopsCfg MO can be set to ON only if ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST IOPSCFG

Use this command to list the configuration of the IOPS switch and related parameters.
MOD IOPSCFG

Use this command to modify the configuration of the IOPS switch and related parameters.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IOPS Switch

Indicates whether to enable IOPS for the eNodeB. IOPS is enabled only if this parameter is set to ON(On).
Enter IOPS Mode Time Threshold

Indicates the time threshold for delaying entering the IOPS mode for the eNodeB. This parameter avoids ping-pong switching between the macro network mode and IOPS mode. The eNodeB enters the IOPS mode when all S1-C interfaces on the macro network are faulty for the duration exceeding the value of this parameter.
Exit IOPS Mode Time Threshold

Indicates the time threshold for delaying exiting the IOPS mode for the eNodeB. This parameter avoids ping-pong handovers between the macro network mode and IOPS mode. The eNodeB returns from the IOPS mode to the macro network mode when any faulty S1-C interface on the macro network is recovered and the duration exceeds the value of this parameter.
