CellAuxDuBind

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellAuxDuBind

Description

A CellAuxDuBind MO consists of parameters related to binding relationships between single frequency network (SFN) cells and auxiliary eNodeBs among the distributed units in CU-DU Split deployment.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If FddTddInd in a Cell MO is set to CELL_TDD, a maximum of six CellAuxEnbBind and CellAuxDuBind MOs can be configured under the Cell MO. If FddTddInd in a Cell MO is set to CELL_FDD, a maximum of five CellAuxEnbBind and CellAuxDuBind MOs can be configured in total under the Cell MO.
    • If MultiRruCellMode is not set to SFN, CellAuxDuBind with the same LocalCellId cannot be exist.
  • Relation with the Cell, CellAlgoSwitch, eUCellSectorEqm, EuSectorEqmGroup, and CellAuxEnbBind MOs:
    • Assume that: The FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, the AsfnFastAttSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, and the CellAuxDuBind, and CellAuxEnbBind MOs are not configured. Then: The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO can be selected only when either of the following conditions is met: (a) The SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to JOINT. (b) The sum of the number of eUCellSectorEqm MO instances and the number of EuSectorEqmGroup MO instances is 2 and the SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to ADAPTIVE.
  • Relation with the CellAlgoSwitch MO:
    • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, CellAuxDuBind MO cannot be configured for the cell.
  • Relation with the DdCellGroup MO:
    • CellAuxDuBind MO instances cannot be configured under the Cell MO instances for cells specified by LocalCellId1 and LocalCellId2 in a DdCellGroup instance.
  • Relation with the CellAuxEnbBind and eNodeBFunction MOs:
    • A maximum of 216 CellAuxEnbBind, CellAuxDuBind MOs can be configured in total in the eNodeB.
  • Relation with the Cell, EuSectorEqmGroup, CellAuxEnbBind, eUCellSectorEqm, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE(TRUE), the eUCellSectorEqm, EuSectorEqmGroup, CellAuxDuBind and CellAuxEnbBind MOs could not be configured; When the NbCellFlag parameter in the Cell is set to FALSE, the EuPrbSectorEqm, EuPrbSectorEqmGroup could not be configured.
  • Relation with the SpectrumCloud MO:
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY or UL_SPECTRUM_SHARING, CellAuxDuBind MO instances under the cell corresponding to the SpectrumCloud MO cannot be configured.
  • Relation with the CellDynPowerSharing and CellAuxEnbBind MOs:
    • When the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, no CellAuxEnbBind and CellAuxDuBind MO can be added.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • In a Cell MO, if FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN and CellActiveState is set to CELL_ACTIVE, and the CellAuxDuBind MO is configured for the cell, the FDDHomNetDlCompSwitch and FDDHetNetDlCompSwitch option of the DlCompSwitch parameter in the associated CellAlgoSwitch MO must be deselected.
  • Relation with the ContigIntraBandCarr, Cell, and CellAuxEnbBind MOs:
    • If the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO under a Cell MO is selected, the CellAuxEnbBind, and CellAuxDuBind MOS cannot be configured under this Cell MO.
  • Relation with the CellDlschAlgo, Cell, and CellAuxEnbBind MOs:
    • If the AdaptPilotOffPrbThld parameter in the CellDlschAlgo MO for a cell is set to a value greater than 0, the FddTddInd parameter in the Cell MO for this cell must be set to CELL_FDD and the CellAuxEnbBind and CellAuxDuBind MOs cannot be added for this cell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLAUXDUBIND

Use this command to add the binding relationship between a distributed unit and an auxiliary eNodeB for a cell.
LST CELLAUXDUBIND

Use this command to list the binding relationship between a distributed unit and an auxiliary eNodeB for a cell.
RMV CELLAUXDUBIND

Use this command to remove the binding relationship between a distributed unit and an auxiliary eNodeB for a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

This parameter indicates the ID of the auxiliary eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile Country Code

Indicates the mobile country code (MCC) of the operator. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the mobile network code (MNC) of the operator. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD.
Auxiliary eNodeB Distributed Unit ID

Indicates the ID of the DU of an auxiliary eNodeB that serves an SFN cell. This parameter applies only to LTE FDD and LTE TDD.
