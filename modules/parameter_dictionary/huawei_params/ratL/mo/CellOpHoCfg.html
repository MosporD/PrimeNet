CellOpHoCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellOpHoCfg

Description

A CellOpHoCfg MO consists of parameters related to cell-level operator-specific handovers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 6 CellOpHoCfg MOs can be configured for each cell.
  • Relation with the CnOperator MO:
    • CnOperatorId in an CellOpHoCfg MO must have been set in the associated CnOperator MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLOPHOCFG

Use this command to add handover configurations for a specific operator in a cell.
LST CELLOPHOCFG

Use this command to list handover configurations for a specific operator in a cell.
MOD CELLOPHOCFG

Use this command to modify handover configurations for a specific operator from a cell.
RMV CELLOPHOCFG

Use this command to remove handover configurations for a specific operator from a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
CN Operator ID

Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.
Highest Priority InterRAT

Indicates the highest-priority target RAT for handovers. It is UTRAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the highest-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. This parameter applies only to LTE FDD and LTE TDD.
Second Priority InterRAT

Indicates the medium-priority target RAT for handovers. It is GERAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the medium-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. If this parameter is set to NULL, no medium-priority target RAT is specified and only the highest-priority target RAT can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.
Lowest Priority InterRAT

Indicates the lowest-priority target RAT for handovers. It is CDMA2000 by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the lowest-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. If this parameter is set to NULL, no lowest-priority target RAT is specified and only the highest- or medium-priority target RAT can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.
CSFB Highest Priority InterRAT for Idle UE

Indicates the highest-priority target RAT for CSFB initiated by UEs in idle mode. It is UTRAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the highest-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. This parameter applies only to LTE FDD and LTE TDD.
CSFB Second Priority InterRAT for Idle UE

Indicates the medium-priority target RAT for CSFB initiated by UEs in idle mode. It is GERAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the medium-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. If this parameter is set to NULL, no medium-priority target RAT is specified and only the highest-priority target RAT can be selected for CSFB initiated by UEs in idle mode. This parameter applies only to LTE FDD and LTE TDD.
CSFB Lowest Priority InterRAT for Idle UE

Indicates the lowest-priority target RAT for CSFB initiated by UEs in idle mode. It is CDMA2000 by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the lowest-priority target RAT is UTRAN, GERAN, or CDMA2000, respectively. If this parameter is set to NULL, no lowest-priority target RAT is specified and only the highest- or medium-priority target RAT can be selected for CSFB initiated by UEs in idle mode. This parameter applies only to LTE FDD and LTE TDD.
First RAT Priority

Indicates the priority of E-UTRAN TDD or E-UTRAN FDD in inter-frequency blind handover or blind redirection scenarios. To prioritize E-UTRAN TDD or E-UTRAN FDD, set this parameter to EUTRAN_TDD or EUTRAN_FDD, respectively. To treat E-UTRAN TDD and E-UTRAN FDD equally, set this parameter to EUTRAN. This parameter applies only to LTE FDD and LTE TDD.
LTE TDD Inter-Freq A2 Thd RSRP Offset

Indicates the offset for LTE TDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE TDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE TDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter or the FddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the TddIfHoA2ThdRsrpOffset parameter is set to -100 and the FddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE TDD measurement is not triggered, and the eNodeB delivers only LTE FDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE FDD inter-frequency measurement. The RSRP threshold for LTE FDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.
LTE FDD Inter-Freq A2 Thd RSRP Offset

Indicates the offset for LTE FDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE FDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE FDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter or the TddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the FddIfHoA2ThdRsrpOffset parameter is set to -100 and the TddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE FDD measurement is not triggered, and the eNodeB delivers only LTE TDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE TDD inter-frequency measurement. The RSRP threshold for LTE TDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.
Handover Mode Switch

Indicates whether to enable different types of handovers for a specific operator, based on which the base station determines handover policies.

REDIRECTION_TO_NR_SW: Redirection to NR is supported only when this option is selected. This option takes effect only when the NrRedirectSwitch option of the CellHoParaCfg.HoModeSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.

HANDOVER_TO_NR_SW: Handover to NR is supported only when this option is selected. This option takes effect only when the NrHoSwitch option of the CellHoParaCfg.HoModeSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.
Serving Frequency Reselection Priority

Indicates the PLMN-specific dedicated cell-reselection priority for the serving frequency. 0 indicates the lowest priority, 7 indicates the highest priority, and 255 indicates that the parameter is invalid. If this parameter is set to a value other than 255 and the IE "idleModeMobilityControlInfo" needs to be delivered to a UE during RRC connection release, the eNodeB delivers dedicated cell-reselection priorities for the serving frequency of PLMNs that the UE supports. If this parameter is set to 255, PLMN-specific dedicated cell-reselection priorities for the serving frequency are not configured and the UE uses the cell-reselection priority of the serving frequency broadcast in system information. The value of this parameter must be determined together with that of other frequencies during network planning. Frequencies used for different RATs must be assigned different absolute cell-reselection priorities. This parameter applies only to LTE FDD and LTE TDD.
