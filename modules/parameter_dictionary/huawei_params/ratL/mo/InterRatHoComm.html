InterRatHoComm

+-NE
  +-eNodeBFunction
    +-InterRatHoComm

Description

The InterRatHoComm MO consists of the common eNodeB-level parameters that are related to inter-RAT handovers. The configuration of this MO is delivered with the RRCConnectionReconfiguration message. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Table 1 describes the MML commands related to this MO.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Max report cell number

Indicates the maximum number of cells to be included in the measurement report after an inter-RAT handover event or a periodic inter-RAT measurement for ANR purposes is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Measurement report amount

Indicates the number of periodic measurement reports to be sent after an inter-RAT handover event is triggered. It is used to prevent the impact of measurement report loss and internal processing failure on the handover. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Geran measurement report interval

Indicates the interval at which periodic measurement reports are sent to the eNodeB after the event for inter-RAT handover to GERAN is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Utran measurement trigger quantity

Indicates the quantity to be measured for handovers to UTRAN FDD cells. RSCP values are relatively stable while Ec/N0 values fluctuate with the network load. The value BOTH applies only to UEs complying with 3GPP Release 10 or later. UEs complying with 3GPP Release 10 or later include both RSCP and Ec/N0 values in measurement reports. When both RSCP- and Ec/N0-based trigger conditions are met, handovers can be triggered. For UEs complying with 3GPP Release 8 or 9, the value BOTH produces the same effect as the value RSCP. QoE-based handover algorithms do not apply to UEs complying with 3GPP Release 8 and Release 9, and the applicable quantity is always Ec/N0. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
UTRAN FDD measurement report interval

Indicates the interval at which periodic measurement reports are sent after the event for the handover to UTRAN is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA20001XRTT measurement trigger quantity

Indicates the quantity to be measured for inter-RAT handovers to CDMA2000 1xRTT. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA20001XRTT measurement report interval

Indicates the interval at which periodic measurement reports are sent to the eNodeB after the event for inter-RAT handover to CDMA2000 1xRTT is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000HRPD measurement trigger quantity

Indicates the quantity to be measured for inter-RAT handovers to CDMA2000 HRPD. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000HRPD measurement report interval

Indicates the interval at which periodic measurement reports are sent to the eNodeB after the event for inter-RAT handover to CDMA2000 HRPD is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
InterRat A1A2 measurement trigger quantity

Indicates the triggering quantity of inter-RAT events A1 and A2. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Inter RAT HO Trigger Event Type

Indicates the type of the inter-RAT handover event except handovers to NG-RAN. The event type can be B1 or B2. This parameter applies only to coverage-based handovers. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 1xRTT Measure Timer

Indicates the timer for measurements on CDMA2000 1xRTT cells. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 1xRTT Judge PN Number

Indicates the number of CDMA2000 1xRTT cells whose reference signal strength is used to calculate the target reference signal strength. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 HRPD Frequency Select Mode

Indicates the mode of selecting a CDMA2000 HRPD frequency. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 1xRTT Frequency Select Mode

Indicates the mode of selecting a CDMA2000 1xRTT frequency. This parameter applies only to LTE FDD and LTE TDD.
eCSFB PS Concurrent Mode

Indicates the eCSFB concurrency mode. This parameter applies only to LTE FDD and LTE TDD.
eCSFB Measurement Mode

Indicates the measurement mode for eCSFB. This parameter applies only to LTE FDD and LTE TDD.
eCSFB SectorID Select Mode

Indicates the mode of selecting a sector ID during eCSFB. This parameter applies only to LTE FDD and LTE TDD.
Max Utran cell num in redirection

Indicates the maximum number of UTRAN cell system information messages that can be transmitted during a flash redirection procedure. This parameter applies only to LTE FDD and LTE TDD.
Max Geran cell num in redirection

Indicates the maximum number of GERAN cell system information messages that can be transmitted during a flash redirection procedure. This parameter applies only to LTE FDD and LTE TDD.
Max Geran cell num in CSFB EMC redirection

Indicates the maximum number of GERAN cell system information messages that can be transmitted during an emergency CSFB-based redirection procedure. This parameter applies only to LTE FDD and LTE TDD.
Max Utran cell num in CSFB EMC redirection

Indicates the maximum number of UTRAN cell system information messages that can be transmitted during an emergency CSFB-based redirection procedure. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 eHRPD SectorID Select Mode

Indicates the method of selecting reference cells during an optimized handover from E-UTRAN to CDMA2000 eHRPD. One method is selecting reference cells configured on the eNodeB. The other method is selecting neighboring CDMA2000 eHRPD cells with the best signal quality indicated by measurement reports. This parameter applies only to LTE FDD and LTE TDD.
InterRAT Blind Redir PLMN Cfg Simplify Sw

Indicates the PLMN determination mechanism used in blind redirections from E-UTRAN to UTRAN/GERAN when the PLMN for the neighboring frequency (or frequency group) is not configured. If this parameter is set to ON, the PLMN for the neighboring frequency (or frequency group) is the serving PLMN of UEs. If this parameter is set to OFF, the neighboring frequency (or frequency group) does not belong to any PLMN. This parameter applies only to LTE FDD and LTE TDD.
NR Measurement Reporting Interval

Indicates the interval at which periodic measurement reports are sent to the eNodeB after the event for inter-RAT handover to NR is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
NSA DC SA NR HO No-Gap B1 Reporting Interval

Indicates the interval at which NSA-DC UEs send reports of non-gap-assisted B1 measurements related to inter-RAT handovers to NG-RAN in SA networking. This parameter applies only to LTE FDD and LTE TDD.
Inter-RAT HO NR Triggering Event Type

Indicates the event to trigger coverage-based handovers to NG-RAN. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
