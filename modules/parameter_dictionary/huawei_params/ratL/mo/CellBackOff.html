CellBackOff

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellBackOff

Description

The CellBackOff MO consists of parameters related to load balancing by transferring UEs with low spectral efficiency. This MO applies only to LTE TDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CELLBACKOFF

Use this command to query parameters related to load balancing by transferring UEs with low spectral efficiency in a cell.
MOD CELLBACKOFF

Use this command to modify parameters related to load balancing by transferring UEs with low spectral efficiency in a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Inter-Frequency Backoff PRB Threshold

Indicates the PRB usage threshold for triggering inter-frequency MLB for low-efficiency UEs. When the UE quantity-related trigger conditions are met and the cell load is greater than or equal to the value of this parameter plus the load offset, inter-frequency MLB is triggered for low-efficiency UEs. When the UE quantity-related exit conditions are met or the cell load is lower than the value of this parameter, inter-frequency MLB is stopped for low-efficiency UEs. This parameter applies only to LTE TDD.
Inter-Frequency Backoff UE Number Threshold

Indicates the threshold of the number of synchronized UEs for triggering inter-frequency MLB for low-efficiency UEs. When the PRB usage-related trigger conditions are met and the number of synchronized UEs in the local cell is greater than or equal to the value of this parameter plus the offset of the minimum number of UEs for MLB, inter-frequency MLB is triggered for low-efficiency UEs. When the PRB usage-related exit conditions are met or the number of synchronized UEs in the local cell is less than the value of this parameter, inter-frequency MLB is stopped for low-efficiency UEs. This parameter applies only to LTE TDD.
RB Priority MCS Selection Trigger PRB Threshold

Indicates the PRB usage threshold for triggering RB priority-based MCS index selection. When inter-frequency MLB for low-efficiency UEs is enabled and the PRB usage of the cell is less than the value of this parameter, RB priority-based MCS index selection can be performed. This parameter applies only to LTE TDD.
RB Priority MCS Selection Stop PRB Threshold

Indicates the PRB usage threshold for stopping RB priority-based MCS index selection. When inter-frequency MLB for low-efficiency UEs is enabled and the PRB usage of the cell is greater than or equal to the value of this parameter, RB priority-based MCS index selection cannot be performed. This parameter applies only to LTE TDD.
Lowest Efficiency DL MCS Threshold

Indicates the downlink MCS index threshold for selecting extra-low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when either of the following conditions are met: (a) The downlink MCS index of the UE is less than the value of this parameter. (b) The downlink MCS index of the UE is greater than or equal to the value of this parameter and is less than or equal to the value of the LowEffDlMcsThd parameter, and the PRB usage criteria are met. This parameter also indicates the downlink MCS index threshold for selecting low-efficiency UEs for inter-frequency load steering in massive MIMO scenarios. The eNodeB considers a UE as a low-efficiency UE if the downlink MCS index of the UE is lower than this threshold. This option applies only to LTE FDD and LTE TDD.
Low Efficiency DL MCS Threshold

Indicates the downlink MCS index threshold for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the PRB usage-related conditions are met and the downlink MCS index of the UE is greater than or equal to the value of the LowestEffDlMcsThd parameter and is less than or equal to the value of this parameter. This parameter applies only to LTE TDD.
Low Efficiency DL Factor A

Indicates downlink factor A for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the downlink MCS index is lower than the value of the LowEffDlFactorK parameter plus the product of the UE's PRB usage and the value of this parameter. This parameter applies only to LTE TDD.
Low Efficiency DL Factor K

Indicates downlink factor K for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the downlink MCS index is less than the value of this parameter plus the product of the UE's PRB usage and the value of the LowEffDlFactorA parameter. This parameter applies only to LTE TDD.
Lowest Efficiency UL MCS Threshold

Indicates the lowest-efficiency uplink MCS index threshold for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when either of the following conditions are met: The uplink MCS index of the UE is less than the value of this parameter. The uplink MCS index of the UE is greater than or equal to the value of this parameter and is less than or equal to the value of the LowEffUlMcsThd parameter, and the PRB usage-related conditions are met. This parameter applies only to LTE TDD.
Low Efficiency UL MCS Threshold

Indicates the uplink MCS index threshold for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the PRB usage-related conditions are met and the uplink MCS index of the UE is greater than or equal to the value of the LowestEffUlMcsThd parameter and is less than or equal to the value of this parameter. This parameter applies only to LTE TDD.
Low Efficiency UL Factor A

Indicates uplink factor A for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the uplink MCS index is lower than the value of the LowEffUlFactorK parameter plus the product of the UE's PRB usage and the value of this parameter. This parameter applies only to LTE TDD.
Low Efficiency UL Factor K

Indicates uplink factor K for selecting low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when the uplink MCS index is lower than the value of this parameter plus the product of the UE's PRB usage and the value of the LowEffUlFactorA parameter. This parameter applies only to LTE TDD.
UL Heavy Traffic TTI Proportion Threshold

Indicates the uplink heavy-traffic TTI proportion threshold for identifying UEs with heavy uplink traffic. If the proportion of heavy-traffic TTIs to the total number of TTIs in which the UE is scheduled exceeds the threshold specified by this parameter within a period defined by UlHeavyTrafficJudgePeriod, the UE is identified as a UE with heavy uplink traffic. This parameter applies only to LTE TDD.
UL Traffic MLB UE Number Threshold

Indicates the threshold of the number of uplink-sync UEs for triggering uplink-traffic-based MLB and service steering intended for guaranteeing uplink experience. If the number of uplink-sync UEs is greater than or equal to this threshold plus the offset to the number of UEs for triggering MLB, uplink-traffic-based MLB and service steering intended for guaranteeing uplink experience are triggered. If the number of uplink-sync UEs is less than this threshold, uplink-traffic-based MLB and service steering intended for guaranteeing uplink experience stop. This parameter applies only to LTE TDD.
UL Heavy Traffic Judge Period

Indicates the period of identifying UEs with heavy uplink traffic. This parameter applies only to LTE TDD.
Handover In Reject PRB Threshold

Indicates the PRB usage threshold for triggering rejection of incoming handover requests of UEs from inter-duplex-mode cells after inter-frequency low-efficient MLB is triggered. When the InterFreqBackoffSwitch option of the BackoffAlgoSwitch parameter is selected and the IfBackoffHoInRejectSwitch option of the MlbMatchOtherFeatureMode parameter is selected, the eNodeB rejects incoming handover requests of UEs from inter-duplex-mode cells if the PRB usage of the target cell is greater than or equal to this threshold. This parameter applies only to LTE TDD.
Handover In Reject UE Number Threshold

Indicates the UE quantity threshold for triggering rejection of incoming handover requests of UEs from inter-duplex-mode cells after inter-frequency low-efficient MLB is triggered. When the InterFreqBackoffSwitch option of the BackoffAlgoSwitch parameter is selected and the IfBackoffHoInRejectSwitch option of the MlbMatchOtherFeatureMode parameter is selected, the eNodeB rejects incoming handover requests of UEs from inter-duplex-mode cells if the number of synchronized UEs in the cell is greater than or equal to this threshold. This parameter applies only to LTE TDD.
Rejected Handover In Cause

Indicates the handover cause values carried by incoming handover requests of UEs from inter-duplex-mode cells that must be rejected after inter-frequency low-efficient MLB is triggered. After inter-frequency low-efficient MLB is triggered, if the cause value indicated by the selected option of this parameter is contained in an incoming handover request of a UE from an inter-duplex-mode cell, the eNodeB rejects the handover request. If the cause value indicated by the selected option of this parameter is not contained in the handover request, the eNodeB accepts the handover request. This parameter is valid only if the IfBackoffHoInRejectSwitch option of the MlbMatchOtherFeatureMode parameter is selected. This parameter applies only to LTE TDD.
Backoff CA User HO Switch

Indicates whether to enable load balancing for low-efficiency CA UEs.

If this parameter is set to ON, load balancing is enabled for low-efficiency CA UEs. The eNodeB selects low-efficiency CA UEs and initiates blind handovers for low-efficiency FDD+TDD CA UEs. If this parameter is set to OFF, load balancing is disabled for low-efficiency CA UEs. This parameter applies only to LTE TDD.
Backoff MLB Enhancement Switch

Indicates whether to enable MLB enhancement for low-efficiency UEs.

ADAPTIVE_MCS_THLD_SW: Indicates whether to enable MCS index threshold adaptation. If this option is selected, MCS index threshold adaptation is performed during UE selection after MLB for low-efficiency UEs is enabled. If this option is deselected, a fixed MCS index threshold is used to select UEs after MLB for low-efficiency UEs is enabled. This option applies only to LTE TDD.
