EutranBlkNCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-EutranBlkNCell

Description

An EutranBlkNCell MO consists of parameters related to the list of blacklisted intra-RAT neighboring cells. The list stores overshooting neighboring cells, abnormal neighboring cells, and the blacklisted neighboring E-UTRAN cells that RRC_CONNECTED UEs cannot be handed over to.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • In intra-eNodeB scenarios, the CGI of a blacklisted neighboring cell represented by an EutranBlkNCell MO cannot be the same as the CGI of the serving cell represented by the associated Cell MO. The CGI consists of the MCC, MNC, eNodeB ID, and cell ID. Two CGIs are considered the same when the four items are the same. The CGI of a blacklisted neighboring cell is specified by Mcc, Mnc, eNodeBId, and CellId in an EutranBlkNCell MO. The CGI of the serving cell is specified by Mcc and Mnc in an associated CnOperator MO, eNodeBId in the eNodeBFunction MO, and CellId in the Cell MO.
    • In intra-eNodeB scenarios, before an intra-eNodeB cell is configured as a blacklisted neighboring cell (represented by the EutranBlkNCell MO) of the serving cell, the Cell MO representing the intra-eNodeB cell must be configured first.
    • In intra-eNodeB scenarios, the downlink EARFCN and physical cell ID of a blacklisted neighboring cell represented by the EutranBlkNCell MO cannot be the same as values of DlEarfcn and PhyCellId in the Cell MO representing the serving cell at the same time.
    • A maximum of 16 EutranBlkNCell MOs can be configured for a cell.
  • Relation with the EutranExternalCell, CnOperator, eNodeBFunction, and ENodeBSharingMode MOs:
    • In inter-eNodeB scenarios, before an inter-eNodeB cell is configured as a blacklisted neighboring E-UTRAN cell (represented by the EutranBlkNCell MO) of the serving cell, the EutranExternalCell MO associated with the EutranBlkNCell MO must be configured first.
  • Relation with the CnOperator and ENodeBSharingMode MOs:
    • In intra-eNodeB scenarios, when the ENodeBSharingMode parameter in an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, the Mcc and Mnc parameters in the EutranBlkNCell MO must be the same as the Mcc and Mnc parameters in the CnOperator MO corresponding to the primary operator, respectively.
  • Relation with the CellOp, CnOperator, CnOperatorTa, and ENodeBSharingMode MOs:
    • In intra-eNodeB scenarios, the CellOp MO must be configured for the intra-eNodeB cell that is represented by an EutranBlkNCell MO and is configured as a blacklisted neighboring cell of the serving cell. If ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ, Mcc and Mnc in the EutranBlkNCell MO must be set to the same values as Mcc and Mnc in the CnOperator of the primary operator. If ENodeBSharingMode in the ENodeBSharingMode MO is set to INDEPENDENT or SEPARATED_FREQ, Mcc and Mnc in the EutranBlkNCell MO must be set to the same values of Mcc and Mnc in the CnOperator MO corresponding to the CellOp MO configured for the intra-eNodeB cell that is added as the blacklisted neighboring cell.
  • Relation with the EutranIntraFreqNCell MO:
    • The CGI specified by parameters in an EutranBlkNCell MO cannot be the same with the CGI specified by parameters in an EutranIntraFreqNCell MO. The CGI consists of the MCC, MNC, eNodeB ID, and cell ID. Two CGIs are considered the same when the four items are the same. In the EutranBlkNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId. In the EutranIntraFreqNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId.
  • Relation with the EutranInterFreqNCell MO:
    • The CGI specified by parameters in an EutranBlkNCell MO cannot be the same with the CGI specified by parameters in an EutranInterFreqNCell MO. The CGI consists of the MCC, MNC, eNodeB ID, and cell ID. Two CGIs are considered the same when the four items are the same. In the EutranBlkNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId. In the EutranInterFreqNCell MO, the CGI is specified by Mcc, Mnc, eNodeBId, and CellId.
  • Relation with the EutranExternalCell and Cell MOs:
    • In inter-eNodeB scenarios, values of DlEarfcn and PhyCellId in the EutranExternalCell MO associated with an EutranBlkNCell MO cannot be the same as values of DlEarfcn and PhyCellId in the corresponding Cell MO.
  • Relation with the Cell and EutranInterNFreq MOs:
    • In intra-eNodeB scenarios, the value of DlEarfcn in the Cell MO under which an EutranBlkNCell MO is configured must be the same as the value of either DlEarfcn in this Cell MO or DlEarfcn in the related EutranInterNFreq MO.
  • Relation with the EutranExternalCell, Cell, and EutranInterNFreq MOs:
    • In inter-eNodeB scenarios, the value of DlEarfcn in the EutranExternalCell MO associated with an EutranBlkNCell MO must be the same as the value of either DlEarfcn in the corresponding Cell MO or DlEarfcn in the EutranInterNFreq MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the ID of a local cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile country code

Indicates the MCC of a neighboring E-UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the MNC of a neighboring E-UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the eNodeB ID of a blacklisted neighboring E-UTRAN cell, which uniquely identifies an eNodeB within a PLMN. A cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Cell ID

Indicates the cell ID of a blacklisted E-UTRAN cell, which uniquely identifies a cell within an eNodeB. A cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the local cell ID is represented by the 8 least significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Auto Config Flag

Indicates whether a blacklisted neighboring E-UTRAN cell is automatically generated by the eNodeB or manually created. The parameter value AUTO_CREATED indicates that the neighboring E-UTRAN cell is automatically blacklisted by the system. The parameter value MANUAL_CREATED indicates that the neighboring E-UTRAN cell is manually blacklisted by operators using the MAE or MML commands. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control mode of a blacklisted neighboring E-UTRAN cell, which determines the control policies of operators and the SON functions on this MO. If this parameter is set to MANUAL_MODE(Manual Mode), users can modify or delete this MO but the SON cannot automatically modify or delete this MO. If this parameter is set to AUTO_MODE(Auto Mode), both users and the SON can modify or delete this MO. If this MO is created by SON, this parameter is set to AUTO_MODE(Auto Mode). When users create this MO, this parameter can be set to AUTO_MODE(Auto Mode) or MANUAL_MODE(Manual Mode). This parameter applies only to LTE FDD and LTE TDD.
