CellChPwrCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellChPwrCfg

Description

The CellChPwrCfg MO consists of the parameters related to the power for all types of channels in the cell. It is also used in DL power control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • When the TxRxMode parameter in the Cell MO is set to 32T32R and the FddTddInd parameter in the same MO is set to CELL_FDD, or when the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R and the FddTddInd parameter in the same MO is set to CELL_TDD, the PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value.
  • Relation with the CellRfShutdown MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the RfShutdownSwitch parameter in the CellRfShutdown MO is set to OFF.
  • Relation with the CellLowPower MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the LowPwrSwitch parameter in the CellLowPower MO is set to OFF.
  • Relation with the CellShutdown MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the CellShutdownSwitch parameter in the CellShutdown MO is set to OFF.
  • Relation with the CellAlgoSwitch MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the BFModeUserAdptPwrSwitch option of the DlPcAlgoSwitch parameter in the CellAlgoSwitch MO is deselected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
PCFICH power

Indicates the offset of the PCFICH transmit power relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
PBCH power

Indicates the offset of the PBCH transmit power relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
SCH power

Indicates the offset of the transmit power for the cell synchronization signals relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
DBCH power

Indicates the offset of the transmit power for broadcast information on the PDSCH channel relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
PCH power

Indicates the offset of the transmit power for the paging information on the PDSCH channel relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
Rach response power

Indicates the offset of the transmit power for the random access responses on the PDSCH channel relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
Prs power

Indicates the offset of the pilot power relative to the reference signal power. This parameter applies only to LTE FDD and LTE TDD.
Antenna Output Power

Indicates the transmit power for the entire channel bandwidth at the antenna port. This parameter is valid only when the AntRsPwrSwitch option of the RepeaterSwitch parameter in the CellAlgoSwitch MO is selected. This parameter is used to calculate the reference signal (RS) power to be delivered in system information block type 2 (SIB2).
PMCH Power Offset

Indicates the offset of PMCH power to the maximum PDSCH power. The maximum PDSCH power is calculated by using the following formula: Max(P_PDSCH_A, P_PDSCH_B). For details about formulas to calculate P_PDSCH_A and P_PDSCH_B, see section "Basics of PDSCH Power Calculation" in Power Control Feature Parameter Description. This parameter applies only to LTE FDD and LTE TDD.
Handover RAR Power Enhanced Switch

Indicates whether the eNodeB increases the transmit power of the Random Access Response (RAR) message when a UE is being handed over to the target cell and repeatedly sends dedicated preambles. If this parameter is set to OFF(OFF), the eNodeB does not increase the transmit power of the RAR message sent to the UE that is being handed over to the target cell. If this parameter is set to ON(ON) and a UE that is being handed over to the target cell repeatedly sends dedicated preambles, the eNodeB increases the transmit power of the RAR message by another 3 dB each time on the basis of the RaRspPwr parameter value. The transmit power of the RAR message can be increased by a maximum of 6 dB. This parameter applies only to LTE FDD and LTE TDD.
Output Power Rate

Indicates the cell output power usage. This parameter is valid only when the AntRsPwrSwitch option is selected. The eNodeB calculates the reference signal (RS) transmit power to be delivered in system information block type 2 (SIB2) based on OutputPowerRate and AntOutputPwr. When the AntRsPwrSwitch option is selected for NB-IoT cells in in-band scenarios and the corresponding LTE cells and the OutputPowerRate parameter is set to 0, the eNodeB calculates the output power usage of the NB-IoT and LTE cells. Then, the eNodeB calculates the RS power based on the power usage and broadcasts the power in SIB2. In other scenarios with the AntRsPwrSwitch option selected and the OutputPowerRate parameter set to 0, the eNodeB handles the parameter value 0 as 1000.
PDCCH Power Increase Offset

Indicates the power increase offset of the PDCCH in a cell. This parameter applies only to LTE FDD and LTE TDD.
