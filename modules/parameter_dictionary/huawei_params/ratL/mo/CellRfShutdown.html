CellRfShutdown

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellRfShutdown

Description

The CellRfShutdown MO consists of parameters related to radio frequency (RF) channel intelligent shutdown in a cell. In a specified time span, if RF channel intelligent shutdown is enabled, the conditions for triggering intelligent shutdown in specific scenarios are as follows: For an FDD cell, the cell status is normal, the number of UEs in the cell does not exceed the predefined UE number threshold, and both uplink and downlink cell loads are less than or equal to the uplink and downlink PRB usages, respectively. For a TDD cell with 2T2P or 4T4P, the cell status is normal and no UE accesses the cell. For a TDD cell with 4T2P, 8T2P, or 8T4P scenario, the cell status is normal and both uplink and downlink cell loads are less than or equal to the uplink and downlink PRB usages, respectively. If the conditions are met, the eNodeB automatically shuts down the power amplifiers (PAs) for half RF channels. Otherwise, the eNodeB automatically starts the PAs that have been shut down. In this way, energy conservation and emission reduction are fulfilled. A cell can enter the RF channel intelligent shutdown mode when all of the following conditions are met: (1) The cell is configured with more than one TX antenna and RF channel intelligent shutdown is enabled; (2) RF channel intelligent shutdown is allowed to take effect in the current time; (3) For an FDD cell, the cell status is normal, the number of UEs in the cell does not exceed the predefined UE number threshold, and both uplink and downlink cell loads are less than or equal to the uplink and downlink PRB usages, respectively. For a TDD cell with 2T2P or 4T4P, the cell status is normal and no UE accesses the cell. For a TDD cell with 4T2P, 8T2P, or 8T4P scenario, the cell status is normal and both uplink and downlink cell loads are less than or equal to the uplink and downlink PRB usages, respectively.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If CellActiveState in a Cell MO is set to CELL_ACTIVE, FddTddInd is CELL_TDD Model and DlBandWidth is CELL_BW_N25, RfShutdownSwitch in the CellRfShutdown must be set OFF.
    • If the DlBandWidth parameter in a Cell MO is set to CELL_BW_N50, CELL_BW_N75, or CELL_BW_N100, the TxRxMode parameter in this Cell MO is set to 2T2R, 2T4R, 4T4R, 2T8R, or 4T8R, the FddTddInd parameter in this Cell MO is set toCELL_FDD, and the MultiRatJointChnShutdownSw parameter in the CellRfShutdown MO under this Cell MO is set to ON, then the RfShutdownSwitch parameter in this CellRfShutdown MO must be set to ON.
    • If the MultiRruCellFlag parameter in a Cell MO is set to BOOLEAN_TRUE, the MultiRruCellMode parameter in the Cell MO is set to SFN, and a CellAuxEnbBind, or CellAuxDuBind MO is configured under this Cell MO, then the MultiRatJointChnShutdownSw parameter in the CellRfShutdown MO under this Cell MO must be set to OFF.
    • If the TxRxMode parameter in a Cell MO is set to 8T8R, 32T32R, or 64T64R, the MultiRatJointChnShutdownSw parameter in the CellRfShutdown MO under this Cell MO must be set to OFF.
    • If the MultiRruCellMode parameter in a Cell MO is set to MPRU_AGGREGATION, the MultiRatJointChnShutdownSw parameter in the CellRfShutdown under this Cell MO must be set to OFF.
  • Relation with the PDSCHCfg MO:
    • If the LogicalPortSwapSwitch parameter in the PDSCHCfg MO is set to SWAP_MODE_1, the RfShutdownSwitch parameter in the CellRfShutdown MO must be set to OFF.
    • The CellPowerLimit parameter in the PDSCHCfg MO must be set to 0 if the RfShutdownSwitch parameter in the CellRfShutdown is set to ON.
  • Relation with the SECTOREQM, Cell, and eUCellSectorEqm MOs:
    • When the FddTddInd parameter in a Cell MO is set to CELL_FDD and the TxRxMode parameter in the Cell is not set to 32T32R and the ANTCFGMODE parameter in the SECTOREQM MO referenced by the Cell MO is set to BEAM(BEAM), the RfShutdownSwitch parameter in theCellRfShutdown MO must not be set to ON(On).
  • Relation with the eUCellSectorEqm MO:
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1, the RfShutdownSwitch parameter in CellRfShutdown MO must be deselected.
  • Relation with the CellChPwrCfg MO:
    • The PdcchPowerIncreaseOffset parameter in the CellChPwrCfg MO can be set to a non-zero value only when the RfShutdownSwitch parameter in the CellRfShutdown MO is set to OFF.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the RfShutdownSwitch parameter in the associated CellRfShutdown MO must be set to OFF.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the RfShutdownSwitch parameter in the CellRfShutdown MO must be set to OFF.
  • Relation with the Cell and SectorSplitCell MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R, 32T32R, or 8T8R, and the SectorSplitCell MO is configured for the Cell MO, the RfShutdownSwitch parameter in the CellRfShutdown MO must be set to OFF.
  • Relation with the SectorSplitGroup, SectorSplitCell, and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in this Cell MO is set to 8T8R, the cell specified by this Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to MODE_3, then the RfShutdownSwitch parameter in the CellRfShutdown MO must be set to OFF.
  • Relation with the Cell and MDU MOs:
    • If the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE and the TYPE parameter in the MDU MO is set to MDUC, the MultiRatJointChnShutdownSw parameter in the corresponding CellRfShutdown MO must be set to OFF.
  • Relation with the ContigIntraBandCarr MO:
    • RfShutdownSwitch in the CellRfShutdown MO must be set to OFF when CONTIG_INTRA_BAND_CARR_SW of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is turned on.
  • Relation with the Cell and eUCellSectorEqm MOs:
    • The RsPwrAdjOffset parameter in a CellRfShutdown MO must be set to 0 if all the following conditions are met: The value of the CellActiveState parameter in this Cell MO is CELL_ACTIVE, the TxRxMode, FddTddInd, and CrsPortNum parameters in this Cell MO are set to 32T32R, CELL_FDD, and CRS_PORT_4, respectively, the CellBeamMode parameter in the eUCellSectorEqm MO under this Cell MO is set to MASSIVE_MIMO_Ph2, and the RfShutdownSwitch parameter in the CellRfShutdown MO under this Cell MO is set to ON.
  • Relation with the Cell, eUCellSectorEqm, CellAlgoSwitch, and CellLowPower MOs:
    • If the value of the CellActiveState parameter in a Cell MO is CELL_ACTIVE, the FddTddInd and TxRxMode parameters in this Cell MO are set to CELL_FDD and 8T8R, respectively, and the CellBeamMode parameter in the eUCellSectorEqm MO under this Cell MO is set to NORMAL, then the DynAdjVoltSwitch option of the DynAdjVoltSwitch parameter in the CellAlgoSwitch MO under this Cell MO must be set deselected, the LowPwrSwitch parameter in the CellLowPower MO under this Cell MO must be set to OFF, and the RfShutdownSwitch parameter in the CellRfShutdown MO under this Cell MO must also be set to OFF.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
RF intelligent shutdown switch

Indicates whether to enable intelligent RF channel shutdown. The eNodeB can perform intelligent RF channel shutdown when specific criterion is met only if this parameter is set to ON. If this parameter is set to DETECTION, the eNodeB only detects and measures the duration when intelligent RF channel shutdown can be triggered, but does not perform intelligent RF channel shutdown.
Start time

Indicates the start time of RF channel intelligent shutdown for the cell.
Stop time

Indicates the stop time of RF channel intelligent shutdown for the cell. If the stop time is earlier than or the same as the start time, the stop time is assumed to be a time of the next day.
Reference signal power adjust offset

Indicates the value by which the reference signal power is increased during the RF channel intelligent shutdown period. The reference signal power increases by the value specified by this parameter to ensure coverage of the cell. If this parameter is set to a value greater than 3, the value 3 is used. Otherwise, the configuration value is used. This parameter applies only to LTE FDD and LTE TDD.
Downlink PRB threshold

Indicates the downlink PRB usage threshold for RF channel intelligent shutdown. For NB-IoT cells, this parameter indicates the downlink subcarrier usage threshold for RF channel intelligent shutdown. A cell enters the RF channel intelligent shutdown mode when the current cell load is less than or equal to both the uplink PRB usage threshold and downlink PRB usage threshold. A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a lower probability that the cell will enter the RF channel intelligent shutdown mode, which does not facilitate eNodeB power saving. A larger value of this parameter leads to a higher probability that the cell will enter the RF channel intelligent shutdown mode, which affects services.
Uplink PRB threshold

Indicates the uplink PRB usage threshold for RF channel intelligent shutdown. For NB-IoT cells, this parameter indicates the uplink subcarrier usage threshold for RF channel intelligent shutdown. A cell enters the RF channel intelligent shutdown mode when the current cell load is less than or equal to both the uplink PRB usage threshold and downlink PRB usage threshold. A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a lower probability that the cell will enter the RF channel intelligent shutdown mode, which does not facilitate eNodeB power saving. A larger value of this parameter leads to a higher probability that the cell will enter the RF channel intelligent shutdown mode, which affects services.
Downlink PRB offset

Indicates the offset to the downlink PRB usage for RF channel intelligent shutdown.

For NB-IoT cells, this parameter indicates the offset to the downlink subcarrier usage for RF channel intelligent shutdown.

A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a higher probability that the cell will exit the RF channel intelligent shutdown mode and also a higher probability of ping-pong switchover between entry into and exit from the RF channel shutdown mode. A larger value of this parameter leads to a lower probability that the cell will exit the RF channel intelligent shutdown mode, which affects services.
Uplink PRB offset

Indicates the offset to the uplink PRB usage for RF channel intelligent shutdown.

For NB-IoT cells, this parameter indicates the offset to the uplink subcarrier usage for RF channel intelligent shutdown.

A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a higher probability that the cell will exit the RF channel intelligent shutdown mode and also a higher probability of ping-pong switchover between entry into and exit from the RF channel shutdown mode. A larger value of this parameter leads to a lower probability that the cell will exit the RF channel intelligent shutdown mode, which affects services.
UE Number Threshold

Indicates the UE number threshold for RF channel intelligent shutdown. The cell enters RF channel intelligent shutdown mode if all of the following conditions are met: (1) the number of RRC_CONNECTED UEs is less than or equal to this threshold; (2) the uplink cell load is lower than or equal to the preset uplink PRB usage; (3) the downlink cell load is lower than or equal to the preset downlink PRB usage. The cell exits RF channel intelligent shutdown mode if any of the following conditions is met: (1) the number of RRC_CONNECTED UEs exceeds this threshold; (2) the uplink cell load is higher than the sum of the uplink PRB usage threshold and the uplink PRB usage offset; (3) the downlink cell load is higher than the sum of the downlink PRB usage threshold and the downlink PRB usage offset. A smaller value of this parameter leads to a lower probability that the cell will enter RF channel intelligent shutdown, which does not facilitate base station power saving. A larger value of this parameter leads to a higher probability that the cell will enter RF channel intelligent shutdown, which affects services. For LTE TDD cells, this parameter takes effect only when the RfShutdownJudgingPolicy parameter in the CellRfShutdown MO is set to PRB_AND_UE_NUMBER.
RF Intelligent Shutdown Judging Policy

Indicates the basis for entering or exiting RF channel intelligent shutdown. If this parameter is set to PRB(PRB), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage of the cell. If this parameter is set to PRB_AND_UE_NUMBER(PRB_AND_UE_NUMBER), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage and the number of online UEs in the cell. This parameter applies only to LTE TDD.
RF Channel Shutdown Power Check Switch

Indicates whether to enable power check for RF channel shutdown. SYMBOL_0_POWER_CHECK_OPT_SW: Indicates whether to enable symbol 0 power check optimization for RF channel shutdown. If this option is selected, symbol 0 power check optimization is performed after RF channel shutdown takes effect, preventing continuous PDCCH allocation failures. If this option is deselected, symbol 0 power check optimization is not performed after RF channel shutdown takes effect, which may lead to continuous PDCCH allocation failures. This option applies only to LTE TDD.
Multi-RAT Joint Channel Shutdown Switch

Indicates whether to enable multi-RAT joint channel shutdown. If this parameter is set to ON for a cell, multi-RAT joint channel shutdown takes effect in the cell under certain conditions. If this parameter is set to OFF, the function does not take effect. This parameter applies only to LTE FDD.
Penalty Duration

Indicates the duration of penalty imposed on a cell that has exited RF channel intelligent shutdown and meets the penalty condition. In the penalty period, the conditions for triggering RF channel intelligent shutdown will not be checked for the cell.
