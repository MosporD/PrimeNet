LIOptAtomRule

+-NE
  +-eNodeBFunction
    +-LIOptAtomRule

Description

An LIOptAtomRule MO consists of parameters specifying the intelligent optimization atom rules. The intelligent optimization atom rules specify items, such as the scenario evaluation condition, measurement object, and threshold, for determining whether parameter adjustment can be performed.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST LIOPTATOMRULE

Use this command to query settings of parameters related to intelligent optimization atom rules.
MOD LIOPTATOMRULE

Use this command to modify settings of parameters related to intelligent optimization atom rules.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Atom Rule ID

Indicates the ID of an intelligent optimization atom rule. This parameter applies only to LTE FDD and LTE TDD.
Measurement Object Type

Indicates the measurement object type in intelligent optimization atom rules. If this parameter is set to Cell, the measurement objects are cell-level atom rules. If this parameter is set to eNodeB, the measurement objects are eNodeB-level atom rules. This parameter applies only to LTE FDD and LTE TDD.
Condition Type

Indicates the relationship between measurement objects and thresholds in intelligent optimization atom rules. The parameter values BIGGERTHAN, EQUALTO, SMALLERTHAN, SMALLERTHANOREQUALTO, BIGGERTHANOREQUALTO, and NOTEQUALTO indicate the conditions of greater than, equal to, smaller than, smaller than or equal to, greater than or equal to, and not equal to, respectively. This parameter applies only to LTE FDD and LTE TDD.
Threshold for Numerical Parameter

Indicates the threshold for selecting measurement objects with numerical values in intelligent optimization atom rules. This parameter applies only to LTE FDD and LTE TDD.
Measurement Object

Indicates the measurement object in an intelligent optimization atom rule. USER_SPEC_OCCUPY_RATE: Indicates the proportion of UL-sync UEs to the specifications. UL_PRB_UTILIZATION_RATE: Indicates the uplink PRB usage. DL_PRB_UTILIZATION_RATE: Indicates the downlink PRB usage. PDCCH_CCE_UTILIZATION_RATE: Indicates the PDCCH CCE usage. ENB_USER_SPEC_EQU_OCCUPY_RATE: Indicates the maximum value among the proportion of UL-sync UEs to the corresponding capacity of every single cell and the proportion of UL-sync UEs to the corresponding capacity of every single BBP within an eNodeB. USER_SPEC_OCCUPY_RATE indicates the ratio of UL-sync UEs in all cells served by a BBP to the corresponding capacity of the BBP. PUSCH_IN: Indicates interference on the PUSCH. PUCCH_IN: Indicates interference on the PUCCH. ULSYNC_USER_NUM: Indicates the number of UL-sync UEs. EQV_BW_ULSYNC_USER_NUM: Indicates the number of UL-sync UEs served on the equivalent bandwidth. VOICE_UL_PRB_UTILIZATION_RATE: Indicates the uplink PRB usage of voice services. VOICE_DL_PRB_UTILIZATION_RATE: Indicates the downlink PRB usage of voice services. VOICE_CCE_UTILIZATION_RATE: Indicates the CCE usage of voice services. PDCCH_CCE_FAILURE_RATE: Indicates the PDCCH CCE allocation failure rate. EQV_BW_SF_ULSYNC_USER_NUM: Indicates the number of UL-sync UEs with equivalent bandwidths and uplink-downlink subframe configurations. RL_EQV_BW_SF_ULSYNC_USER_NUM: Indicates the number of UL-sync UEs with relative equivalent bandwidths and uplink-downlink subframe configurations. This parameter applies only to LTE FDD and LTE TDD.
