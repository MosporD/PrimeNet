NCellDlRsrpMeasPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-NCellDlRsrpMeasPara

Description

The NCellDlRsrpMeasPara MO consists of the parameters related to automatic downlink RSRP measurements on neighboring cells of the local cell. The automatic measurement function selects neighboring cells for downlink RSRP measurements, which reduces manual configurations.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoSwitch MO:
    • If FDDHomNetDlCompSwitch or FDDHetNetDlCompSwitch of DlCompSwitch in a CellAlgoSwitch MO is set on, DlRsrpAutoNCellMeasSwitch in the associated NCellDlRsrpMeasPara MO must be set to ON.
  • Relation with the CellDlschAlgo MO:
    • The DlRsrpAutoNCellMeasSwitch in the NCellDlRsrpMeasPara must be set to ON when the PilotOffRateIncreaseSw in the CellDlschAlgo is set to BASED_ON_MEASUREMENT.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell Id

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.
DL RSRP Auto NCell Measurement Switch

Indicates whether automatic measurement of downlink RSRP in neighboring cells is supported by the local cell. If this parameter is set to ON, automatic measurement of downlink RSRP in neighboring cells takes effect. If this parameter is set to OFF, automatic measurement of downlink RSRP in neighboring cells is disabled. This parameter applies only to LTE FDD and LTE TDD.
DL RSRP NCell Measurement A3 Offset

Indicates the offset for reporting the event of automatic measurement of downlink RSRP in neighboring cells. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality to report the event. This parameter applies only to LTE FDD and LTE TDD.
DL RSRP NCell Measurement A6 Offset

Indicates the offset for reporting the event of automatic measurement of downlink RSRP in neighboring cells for UEs in SCells. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality to report the event. The value 127 indicates that event A6 measurement is not triggered. This parameter applies only to LTE FDD and LTE TDD.
