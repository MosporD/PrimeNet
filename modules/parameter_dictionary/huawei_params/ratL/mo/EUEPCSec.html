EUEPCSec

+-NE
  +-eNodeBFunction
    +-EUEPCSec

Description

The EUEPCSec MO consists of parameters related to the security policies and algorithms of the compact EPC.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoSwitch MO:
    • If the OutOfBandRelaySwitch or InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO is selected, the CiphAlgo parameter in the EUEPCSec MO must not be set to EEA0(NULL).

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST EUEPCSEC

Use this command to list the configurations of security policies and algorithms of the compact EPC.
MOD EUEPCSEC

Use this command to modify the security policies and algorithms of the compact EPC.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cipher Algorithm

Indicates the algorithm that the compact EPC preferentially selects to encrypt NAS messages. For example, if this parameter is set to EEA2, the EEA2 algorithm is preferentially selected to encrypt NAS messages. This parameter applies only to LTE FDD and LTE TDD.
Integrity Algorithm

Indicates the algorithm that the compact EPC preferentially selects to ensure NAS message integrity. If this parameter is set to EIA2, the EIA2 algorithm is preferentially selected to ensure NAS message integrity. This parameter applies only to LTE FDD and LTE TDD.
