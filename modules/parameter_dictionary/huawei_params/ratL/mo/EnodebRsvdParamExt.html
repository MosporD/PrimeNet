EnodebRsvdParamExt

+-NE
  +-eNodeBFunction
    +-EnodebRsvdParamExt

Description

An EnodebRsvdParamExt MO consists of the eNodeB-level parameters that are reserved for future use.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ENODEBRSVDPARAMEXT

Use this command to list the extended reserved eNodeB-level parameters.
MOD ENODEBRSVDPARAMEXT

Use this command to modify the settings of extended reserved eNodeB-level parameters.
