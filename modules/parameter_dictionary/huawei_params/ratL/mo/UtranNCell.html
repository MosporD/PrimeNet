UtranNCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-UtranNCell

Description

A UtranNCell MO consists of the parameters related to a neighboring UTRAN cell. It is used in measurement control and cell reselection that is controlled by SIB6. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 128 UtranNCell MOs can be configured for each cell.
  • Relation with the UtranExternalCell MO:
    • Before adding a UtranNCell MO, ensure that the associated UtranExternalCell MO has been configured.
  • Relation with the UtranNFreq and UtranExternalCell MOs:
    • UtranDlArfcn and UtranFddTddType in the UtranExternalCell MO associated with a UtranNCell MO must have been configured in a UtranNFreq MO.
  • Relation with the UtranBlkNCell, Cell, and UtranExternalCell MOs:
    • Values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranBlkNCell MO configured for the serving cell cannot be the same as values of UtranDlArfcn and PScrambCode in the UtranExternalCell MO associated with the UtranNCell MO configured for the serving cell at the same time.
  • Relation with the UtranExternalCell and Cell MOs:
    • In all UtranNCell MOs of a local Cell MO, the combination of UtranDlArfcn and PScrambCode in the UtranExternalCell MO corresponding to each UtranNCell MO must be unique.
  • Relation with the UtranNCell MO:
    • A maximum of 18*128 UtranNCell MOs can be configured in the same eNodeB when equipped with LMPT.
    • A maximum of 36*128 UtranNCell MOs can be configured in the same eNodeB when equipped with UMPTa/b.
    • A maximum of 72*128 UtranNCell MOs can be configured in the same eNodeB.
  • Relation with the MDU MO:
    • A maximum of 3*256 UtranNCell MOs can be configured in the same eNodeB if the parameter TYPE in MDU MO is set to MDUC.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UTRANNCELL

Use this command to add the neighboring relation with a UTRAN cell.
DSP UTRANEXTENDEDNCELL

Use this command to query neighbor relationships with UTRAN cells labeled with EXTENDED when neighboring UTRAN cell classification management is enabled.
DSP UTRANNCELL

Use this command to dynamically query UTRAN neighbor relationship records.
DSP UTRANRIMINFO

Use this command to query the status of the RIM procedure in Multiple Report mode for neighboring UTRAN cells.

If the LocalCellId parameter is not specified, the result is the RIM status of all neighboring UTRAN cells.

If the LocalCellId parameter is specified, the result is the RIM status of neighboring UTRAN cells related to this specified local cell.
DSP UTRANRIMLOADINFO

Use this command to query the load information about neighboring UTRAN cells, which is obtained through the RAN information management (RIM) procedure.

If the LocalCellId parameter is not specified, the result is the load information about all neighboring UTRAN cells.

If the LocalCellId parameter is specified, the result is the load information about neighboring UTRAN cells related to this specified local cell.
LST UTRANNCELL

Use this command to list the parameters of the neighboring relation with UTRAN cell.
MOD UTRANNCELL

Use this command to modify the neighboring relation with a UTRAN cell.
RMV UTRANEXTENDEDNCELL

Use this command to remove one or more neighbor relationships with UTRAN cells labeled with EXTENDED.
RMV UTRANNCELL

Use this command to remove one or more neighbor relationships with UTRAN cells.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile country code

Indicates the mobile country code of the neighboring UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code of the neighboring UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.
RNC ID

Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
RNC cell ID

Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
No handover indicator

Indicates whether to allow handover of UEs to the neighboring cell that is determined by the neighboring relation. This parameter applies only to LTE FDD and LTE TDD.
No remove indicator

Indicates whether to permit or prohibit removal of the neighboring relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether this neighboring cell is automatically discovered by the ANR algorithm. This parameter applies only to LTE FDD and LTE TDD.
Blind handover priority

Indicates the priority of the neighboring cell during blind handovers. Blind handover is a process in which the eNodeB instructs a UE to hand over to a specified neighboring cell. There are 32 priorities altogether. The priority has a positive correlation with the value of this parameter. Note that the value 0 indicates that blind handovers to the neighboring cell are not allowed. This parameter applies only to LTE FDD and LTE TDD.
Cell Measure Priority

Indicates the priority of measurement on the neighboring UTRAN cell. The eNodeB preferentially contains the information about a neighboring cell with this priority set to HIGH_PRIORITY while delivering a measurement configuration. This parameter applies only to LTE FDD and LTE TDD.
Overlap Indicator

Indicates whether the neighboring UTRAN cell is manually identified as a neighboring cell overlapping the E-UTRAN cell. The default value is NO.

The parameter value YES indicates that the neighboring UTRAN cell is manually identified as a neighboring cell overlapping the E-UTRAN cell. The parameter value NO indicates that the neighboring UTRAN cell is not manually identified as a neighboring cell overlapping the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Measure Priority

Indicates the measurement priority of the neighboring UTRAN cell. A larger value indicates a higher priority. The measurement priorities can be periodically and automatically arranged based on the number of times each neighboring UTRAN cell is measured. The neighboring UTRAN cells for UTRAN measurement control, fast blind redirections to UTRAN, and blind redirections for flash CSFB to UTRAN can be selected based on the measurement priorities of neighboring UTRAN cells. This parameter applies only to LTE FDD and LTE TDD.
Local cell name

Indicates the name of the local cell. This parameter applies only to LTE FDD and LTE TDD.
Neighbour cell name

Indicates the name of the UTRAN neighboring cell. This parameter applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
Neighboring Cell Addition Time

Indicates the time the neighboring cell was added by ANR for the first time. In free mode, this time is the local time of the NE. In control mode, this time is the local time of the OSS when optimization suggestions are delivered. The format is YYYY-MM-DD. For example, the value 2018-01-01 indicates January 1, 2018. The value 2001-01-01 indicates that the neighboring cell was manually added. This parameter applies only to LTE FDD and LTE TDD.
