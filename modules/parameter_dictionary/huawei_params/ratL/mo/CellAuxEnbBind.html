CellAuxEnbBind

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellAuxEnbBind

Description

The CellAuxEnbBind MO consists of parameters used to configure a binding relationship between a single frequency network (SFN) cell and an auxiliary eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If FddTddInd in a Cell MO is set to CELL_TDD, a maximum of six CellAuxEnbBind and CellAuxDuBind MOs can be configured under the Cell MO. If FddTddInd in a Cell MO is set to CELL_FDD, a maximum of five CellAuxEnbBind and CellAuxDuBind MOs can be configured in total under the Cell MO.
    • If the MultiRruCellMode parameter in the Cell object is not set to SFN, the CellAuxEnbBind object with the same LocalCellId parameter of the Cell object cannot exist.
  • Relation with the Cell, CellAlgoSwitch, eUCellSectorEqm, EuSectorEqmGroup, and CellAuxDuBind MOs:
    • Assume that: The FddTddInd, MultiRruCellFlag, and MultiRruCellMode parameters in the Cell MO are set to CELL_FDD, BOOLEAN_TRUE, and SFN, respectively, the AsfnFastAttSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, and the CellAuxDuBind, and CellAuxEnbBind MOs are not configured. Then: The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO can be selected only when either of the following conditions is met: (a) The SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to JOINT. (b) The sum of the number of eUCellSectorEqm MO instances and the number of EuSectorEqmGroup MO instances is 2 and the SfnDlSchSwitch parameter in the CellAlgoSwitch MO is set to ADAPTIVE.
  • Relation with the CellAlgoSwitch MO:
    • When the SuperCombCellSwitch option of the SfnAlgoSwitch parameter in the CellAlgoSwitch MO is ON, the CellAuxEnbBind MO cannot be configured for this cell.
  • Relation with the DdCellGroup MO:
    • CellAuxEnbBind MO instances cannot be configured for the cells specified by the LocalCellId1 and LocalCellId2 parameters in a DdCellGroup MO instance.
  • Relation with the eNodeBFunction MO:
    • The value of the EnodebId parameter in an CellAuxEnbBind MO and the eNodeBId parameter in the eNodeBFunction MO cannot be the same.
  • Relation with the eNodeBFunction and CellAuxDuBind MOs:
    • A maximum of 216 CellAuxEnbBind, CellAuxDuBind MOs can be configured in total in the eNodeB.
  • Relation with the Cell, EuSectorEqmGroup, CellAuxDuBind, eUCellSectorEqm, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE(TRUE), the eUCellSectorEqm, EuSectorEqmGroup, CellAuxDuBind and CellAuxEnbBind MOs could not be configured; When the NbCellFlag parameter in the Cell is set to FALSE, the EuPrbSectorEqm, EuPrbSectorEqmGroup could not be configured.
  • Relation with the CellDynPowerSharing and CellAuxDuBind MOs:
    • When the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected, no CellAuxEnbBind and CellAuxDuBind MO can be added.
  • Relation with the SpectrumCloud MO:
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, UL_SPECTRUM_SHARING, DC_HSDPA_BASED_UL_SPECTRUM_SHR or UL_SPECTRUM_SHR_PH2_WITH_GSM, the CellAuxEnbBind MO cannot be configured for this cell.
  • Relation with the CellDlschAlgo, Cell, and CellAuxDuBind MOs:
    • If the AdaptPilotOffPrbThld parameter in the CellDlschAlgo MO for a cell is set to a value greater than 0, the FddTddInd parameter in the Cell MO for this cell must be set to CELL_FDD and the CellAuxEnbBind and CellAuxDuBind MOs cannot be added for this cell.
  • Relation with the ContigIntraBandCarr, Cell, and CellAuxDuBind MOs:
    • If the CONTIG_INTRA_BAND_CARR_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO under a Cell MO is selected, the CellAuxEnbBind, and CellAuxDuBind MOS cannot be configured under this Cell MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLAUXENBBIND

Use this command to add single frequency network (SFN) cell binding relationship to an auxiliary eNodeB.
LST CELLAUXENBBIND

Use this command to list a single frequency network (SFN) cell binding relationship to an auxiliary eNodeB.
RMV CELLAUXENBBIND

Use this command to remove a single frequency network (SFN) cell binding relationship to an auxiliary eNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Slave site eNodeB ID

Indicates the ID of the auxiliary eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Mobile Country Code

Indicates the mobile country code (MCC) of the operator that operates an auxiliary eNodeB. This parameter applies only to LTE FDD and LTE TDD. This parameter is valid only when the USU3910 is used.
Mobile Network Code

Indicates the mobile network code (MNC) of the operator that operates an auxiliary eNodeB. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD. This parameter is valid only when the USU3910 is used.
