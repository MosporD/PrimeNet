TypDrbBsr

+-NE
  +-eNodeBFunction
    +-TypDrbBsr

Description

A TypDrbBsr MO consists of the parameters related to buffer status reports (BSRs), which are sent from UEs to their serving eNodeBs.

A BSR indicates the total amount of data in the uplink UE buffer. For details, see 3GPP TS 36.321.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the eNodeBFunction MO:
    • The number of TypDrbBsr MOs must be fifteen.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST TYPDRBBSR

Use this command to list timer settings related to buffer status reports (BSRs) for one or all QoS class identifiers (QCIs).
MOD TYPDRBBSR

Use this command to modify timer settings related to buffer status reports (BSRs) for one or all QoS class identifiers (QCIs).

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
QoS Class Identifier

Indicates the QoS class identifier (QCI).

QCI 1 indicates the requirements for traditional voice services.

QCI 2 indicates the requirements for traditional video (live streaming) services.

QCI 3 indicates the requirements for traditional real-time gaming services and Internet of Vehicles (IoV) services.

QCI 4 indicates the requirements for traditional video (buffered streaming) services.

QCI 5 indicates the requirements for traditional IP multimedia subsystem (IMS) signaling.

QCI 7 indicates the requirements for traditional voice, video, and interactive gaming services.

QCIs 6, 8, and 9 indicate the requirements for video services and TCP-based services.

QCI 65 indicates the requirements for mission-critical push-to-talk (MCPTT) voice services.

QCI 66 indicates the requirements for non-mission-critical PTT voice services.

QCI 69 indicates the requirements for mission-critical PTT signaling.

QCI 70 indicates the requirements for mission-critical data services.

QCIs 75 and 79 indicate the requirements for IoV services. This parameter applies only to LTE FDD and LTE TDD.
Periodic BSR Timer

Indicates the length of the timer for periodic transmission of buffer status reports (BSRs).

BSRs are sent periodically or as triggered by events.

Periodic transmission of BSRs uses the timer specified by this parameter.

When the timer expires, a BSR is sent.

After the BSR is sent, the timer is restarted. This parameter applies only to LTE FDD and LTE TDD.
BSR Retransmission Timer

Indicates the length of the buffer status report (BSR) retransmission timer. This timer is started after a BSR is sent. This parameter applies only to LTE FDD and LTE TDD.
