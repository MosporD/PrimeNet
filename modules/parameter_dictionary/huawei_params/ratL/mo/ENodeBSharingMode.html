ENodeBSharingMode

+-NE
  +-eNodeBFunction
    +-ENodeBSharingMode

Description

The eNodeBSharingMode MO consists of the parameter that specifies the eNodeB sharing mode. The eNodeB supports the following modes: independent operator mode, RAN sharing with common carrier, RAN sharing with dedicated carrier, hybrid RAN sharing, and RAN sharing with special dedicated carrier.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellOp and Cell MOs:
    • If the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SEPARATED_FREQ, a maximum of one CellOp MO with the same LocalCellId as that in a Cell MO can be configured.
    • If the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to INDEPENDENT, a maximum of one CellOp MO with the same LocalCellId as that in a Cell MO can be configured.
    • When the ENodeBSharingMode parameter of an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, for each LocalCellId parameter in the associated Cell MO, a maximum of two CellOp MO instances can exist and a maximum of one CellOp MO instance with CellReservedForOp set to CELL_NOT_RESERVED_FOR_OP can exist.
    • If ENodeBSharingMode in ENodeBSharingMode is set to SHARED_FREQ or HYBRID_SHARED, a maximum of six CellOp MO with the same LocalCellId as that in a Cell MO can be configured.
  • Relation with the CellOp, Cell, and CnOperator MOs:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ and CellActiveState in a Cell MO is CELL_ACTIVE, one of the CellOp MOs with the same local cell ID as that specified by LocalCellId in the Cell MO must meet the following requirement: CnOperatorType is set to CNOPERATOR_PRIMARY in the CnOperator MO corresponding to the CnOperatorTa MO with the same tracking area ID as that specified by TrackingAreaId in the CellOp MO.
  • Relation with the EutranExternalCell, eNodeBFunction, and CnOperator MOs:
    • When the value of eNodeBId in an EutranExternalCell MO is the same as that in the eNodeBFunction MO, the values of Mcc and Mnc in the EutranExternalCell MO depend on the value of ENodeBSharingMode in the ENodeBSharingMode MO: If ENodeBSharingMode in the ENodeBSharingMode MO is set to SEPARATED_FREQ, Mcc and Mnc in an EutranExternalCell MO must be set to values different from those in any CnOperator MO. If ENodeBSharingMode in the ENodeBSharingMode MO is set to INDEPENDENT or SHARED_FREQ, Mcc and Mnc in the EutranExternalCell MO must be set to values different from those in the CnOperator MO that represents the primary operator.
  • Relation with the EutranIntraFreqNCell, EutranExternalCell, CnOperator, and eNodeBFunction MOs:
    • Before adding an inter-eNodeB EutranIntraFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured.
  • Relation with the EutranInterFreqNCell, EutranExternalCell, CnOperator, eNodeBFunction, and Cell MOs:
    • Before adding an inter-eNodeB EutranInterFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured.
  • Relation with the CellAlgoSwitch MO:
    • If SuperCombCellSwitch of SfnAlgoSwitch in the CellAlgoSwitch MO is selected, ENodeBSharingMode in the ENodeBSharingMode MO must be INDEPENDENT.
    • If OutOfBandRelaySwitch, InBandRelayDeNbSwitch, or InBandRelayReNbSwitch under RelaySwitch in the CellAlgoSwitch MO is selected, ENodeBSharingMode in the ENodeBSharingMode MO must be set to INDEPENDENT, SHARED_FREQ, or SEPARATED_FREQ.
    • If OutOfBandRelaySwitch, InBandRelayDeNbSwitch, or InBandRelayReNbSwitch under RelaySwitch in the CellAlgoSwitch MO is selected and ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ, RanShareModeSwitch in this CellAlgoSwitch MO must be set to OFF.
  • Relation with the EutranBlkNCell, EutranExternalCell, CnOperator, and eNodeBFunction MOs:
    • In inter-eNodeB scenarios, before an inter-eNodeB cell is configured as a blacklisted neighboring E-UTRAN cell (represented by the EutranBlkNCell MO) of the serving cell, the EutranExternalCell MO associated with the EutranBlkNCell MO must be configured first.
  • Relation with the EutranIntraFreqNCell and CnOperator MOs:
    • In intra-eNodeB scenarios, when the ENodeBSharingMode parameter in an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, the Mcc and Mnc parameters in the EutranIntraFreqNCell MO must be the same as the Mcc and Mnc parameters in the CnOperator MO corresponding to the primary operator, respectively.
  • Relation with the EutranInterFreqNCell and CnOperator MOs:
    • In intra-eNodeB scenarios, when the ENodeBSharingMode parameter in an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, the Mcc and Mnc parameters in the EutranInterFreqNCell MO must be the same as the Mcc and Mnc parameters in the CnOperator MO corresponding to the primary operator, respectively.

  • Relation with the CellOp, Cell, and CnOperatorTa MOs:

    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ or HYBRID_SHARED and CellActiveState in a Cell MO is set to CELL_ACTIVE, CnOperatorId in the CnOperatorTa MO corresponding to TrackingAreaId in each CellOp MO must be unique.
  • Relation with the CellOp, Cell, CnOperatorTa, and CnOperator MOs:

    • When the ENodeBSharingMode parameter of an ENodeBSharingMode MO is set to SEPARATED_FREQ_SPEC, for each LocalCellId parameter in the associated Cell MO, a maximum of one CellOp MO instance can exist if: the CnOperatorType parameter in a CnOperator MO associated by the TrackingAreaId parameter in the CellOp MO is set to CNOPERATOR_PRIMARY, and the CellReservedForOp parameter of the CellOp MO is set to CELL_NOT_RESERVED_FOR_OP.

    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to SHARED_FREQ or HYBRID_SHARED and CellActiveState in a Cell MO is set to CELL_ACTIVE, Tac in the CnOperatorTa MO corresponding to TrackingAreaId in each CellOp MO must have the same value.
  • Relation with the EutranIntraFreqNCell, CellOp, CnOperator, and CnOperatorTa MOs:

If the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ, Mcc and Mnc in such an EutranIntraFreqNCell MO must be the same as the Mcc and Mnc specified in the CnOperator MO representing the primary operator. If ENodeBSharingMode is set to INDEPENDENT or SEPARATED_FREQ, Mcc and Mnc in such an EutranIntraFreqNCell MO must be set to the same values as Mcc and Mnc specified in the CnOperator MO corresponding to the CellOp MO associated with this EutranIntraFreqNCell MO.
  • Relation with the EutranInterFreqNCell, CellOp, CnOperator, and CnOperatorTa MOs:
    • A CellOp MO must be configured for each EutranInterFreqNCell MO that corresponds to an intra-eNodeB inter-frequency neighboring cell. If the ENodeBSharingMode parameter in the ENodeBSharingMode MO is set to SHARED_FREQ, Mcc and Mnc in such an EutranInterFreqNCell MO must be the same as the Mcc and Mnc specified in the CnOperator MO representing the primary operator. If ENodeBSharingMode is set to INDEPENDENT or SEPARATED_FREQ, Mcc and Mnc in such an EutranInterFreqNCell MO must be set to the same values as Mcc and Mnc specified in the CnOperator MO corresponding to the CellOp MO associated with this EutranInterFreqNCell MO.

  • Relation with the EutranExternalCell, eNodeBFunction, CnOperator, and CnOpSharingGroup MOs:

    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED and CellActiveState in a Cell MO is set to CELL_ACTIVE, CnOperatorId in a CnOperatorTa MO associated with the CellOp MO under the Cell MO must be set to the same value as PrimaryOperatorId in the CnOpSharingGroup MO associated with the Cell MO.
