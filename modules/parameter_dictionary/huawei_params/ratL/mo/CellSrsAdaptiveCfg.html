CellSrsAdaptiveCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSrsAdaptiveCfg

Description

The CellSrsAdaptiveCfg MO consists of parameters related to user-level SRS adaptation. If the SrsPeriodAdaptive parameter is set to ON, the cell adaptively configures the SRS-related parameters. If this parameter is set to OFF, the cell uses fixed SRS configurations.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellUSParaCfg, SRSCfg, and CellRicAlgo MOs:
    • When the UsSrsGuaranteeSwitch parameter in the CellUSParaCfg MO is set to 8_USERS_GUARANTEE(8_USERS_GUARANTEE), 16_USERS_GUARANTEE(16_USERS_GUARANTEE), or 24_USERS_GUARANTEE(24_USERS_GUARANTEE), the SrsPeriodAdaptive parameter in the CellSrsAdaptiveCfg MO must be set to ON(On), the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter in the SRSCfg MO must be deselected, and the MuteUpPTSSymNum parameter in the CellRicAlgo MO must be set to 0.
  • Relation with the ENodeBAlgoSwitch, Cell, eUCellSectorEqm, SectorSplitCell, SRSCfg, and CellAlgoSwitch MOs:
    • When the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE, and FddTddInd in this Cell MO is set to CELL_FDD, and the CellBeamMode parameter in the eUCellSectorEqm MO under related Cell MO is set to MASSIVE_MIMO_Ph2, and related SectorSplitGroup MO includes one or two SectorSplitCell MO instances, and the MM_SRS_ALLOC_OPT_SWITCH option of the UlResManageOptSw parameter in the ENodeBAlgoSwitch MO is selected, all of the following conditions must be met: (a) The SrsCfgInd parameter in the SRSCfg MO is set to BOOLEAN_TRUE. (b) The FddSrsCfgMode parameter in the SRSCfg MO is set to DEFAULTMODE. (c) The SrsPeriodAdaptive parameter in the CellSrsAdaptiveCfg MO is set to ON. (d) The SrsSubframeRecfSwitch option of the SrsAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the CellAlgoSwitch MO:
    • In a CellAlgoSwitch, if SuperCombCellSwitch under SfnAlgoSwitch is set to On, SrsPeriodAdaptive in CellSrsAdaptiveCfg must be configured to Off.
    • In a CellAlgoSwitch, if SuperCombCellSwitch under SfnAlgoSwitch is set to ON, UserSrsPeriod in CellSrsAdaptiveCfg can not be configured to ms5.
    • In a CellAlgoSwitch, if SuperCombCellSwitch under SfnAlgoSwitch is set to ON, UserSrsPeriod in CellSrsAdaptiveCfg can not be configured to ms10.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
SRS Period Adaptive Switch

Indicates whether to enable SRS reporting period adaptation. If this parameter is set to ON(On), the SRS reporting period adaptively changes based on the SRS algorithm. If this parameter is set to OFF(Off), the SRS reporting period is specified by the UserSrsPeriod parameter. This parameter applies only to LTE FDD and LTE TDD.
User SRS Period

Indicates the fixed SRS reporting period. This parameter takes effect only when the SrsPeriodAdaptive parameter is set to OFF(Off). This parameter applies only to LTE FDD and LTE TDD.
