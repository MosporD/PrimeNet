CellRachAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellRachAlgo

Description

The CellRachAlgo MO consists of parameters related to the physical random access channel (PRACH) algorithm in an E-UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.
PRACH False Alarm Detect Radius Threshold

Indicates the threshold of the distance between a UE and the eNodeB for determining whether a contention-based preamble sent by the UE is a PRACH false alarm. If this parameter is set to 0, the eNodeB does not consider a preamble as a false alarm based on the distance. If this parameter is set to a non-zero value and the eNodeB detects that the distance is longer than this parameter value, the preamble is considered as a false alarm. The distance is calculated based on the timing advance (TA) of the contention-based preamble that the eNodeB received for the first time from a UE. This parameter applies only to LTE FDD and LTE TDD.
RACH Threshold Boosting Ratio

This parameter indicates the percentage by which the PRACH false alarm detection threshold increases. For example, the value x indicates that the configured PRACH false alarm detection threshold increases by x%, and the value -x indicates that the configured PRACH false alarm detection threshold decreases by x%.
Prach Interference Period

Indicates the period for an eNodeB to avoid PRACH interference. This parameter is used to control the speed of PRACH frequency domain position adjustment to prevent ping-pong adjustments due to interference fluctuation. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.
Prach Interference Threshold

Indicates the threshold for an eNodeB to determine whether PRACH interference is severe. When the value of PRACH interference (per PRB) is greater than or equal to the value of this parameter, an eNodeB determines that PRACH interference is severe. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.
Prach Interference Hysteresis

Indicates the hysteresis for an eNodeB to determine PRACH interference. This parameter is used to reduce the number of ping-pong adjustments due to interference fluctuation. This parameter is used with the Prach Interference Threshold parameter to determine weak PRACH interference and moderate PRACH interference. When the value of PRACH interference is less than the value of Prach Interference Threshold minus the value of Prach Interference Hysteresis, the eNodeB determines that PRACH interference is weak. When the value of PRACH interference is greater than or equal to the value of Prach Interference Threshold minus the value of Prach Interference Hysteresis and less than the value of Prach Interference Threshold, the eNodeB determines that PRACH interference is moderate. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
Conflict Cell Mobile Network Code

Indicates the MNC of a conflict cell. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two to three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Conflict eNodeB ID

Indicates the eNodeB ID of a conflict cell located in the same PLMN as the local cell. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Conflict Cell ID

Indicates the ID of the cell that conflicts with the local cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell ID in the most significant eight bits and the eNodeB ID. The E-UTRAN cell identity and the PLMN ID form the E-UTRAN cell global identifier (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
Conflict Cell Mobile Country Code

Indicates the MCC of a conflict cell. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two to three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
