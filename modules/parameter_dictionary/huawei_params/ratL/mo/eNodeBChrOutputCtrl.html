eNodeBChrOutputCtrl

+-NE
  +-eNodeBFunction
    +-eNodeBChrOutputCtrl

Description

The eNodeBChrOutputCtrl MO is used to configure the mode of outputting internal call history records (CHRs).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP ENODEBCHROUTPUTCTRL

Use this command to query the dynamic information about the output control of eNodeB CHRs.
LST ENODEBCHROUTPUTCTRL

Use this command to list the eNodeB call history record (CHR) output control settings.
MOD ENODEBCHROUTPUTCTRL

Use this command to modify the eNodeB call history record (CHR) output control settings.
SET ENODEBCHROUTPUTCTRL

Use this command to set whether to report SIG logs and signaling soft collection results. If the SIGReportSwitch parameter is set to ON, SIG logs and signaling soft collection results subscribed are normally reported. If this parameter is set to OFF, SIG logs and signaling soft collection results subscribed are forcibly terminated and new subscriptions also do not take effect.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CHR UpLoading Time Switch

Indicates the time when CHRs are uploaded. If this parameter is set to FIXED_TIME, CHRs are uploaded at a fixed time based on the standard time. If this parameter is set to NON_FIXED_TIME, CHRs are uploaded at a specific interval since system startup.
SIG Output Mode

Indicates the mode of exporting periodically exported UE-level SIG events. (This parameter does not apply to non-periodically exported UE-level SIG events, periodically exported UE-level SIG events with instantaneous values, or cell-level SIG events.) If this parameter is set to ALL_OUTPUT(ALL_OUTPUT), the eNodeB exports UE-level SIG events periodically and upon bearer or UE release. If this parameter is set to PERIOD_OUTPUT(PERIOD_OUTPUT), the eNodeB exports UE-level SIG events periodically and does not export such events upon bearer or UE release.
CHR Output Control Switch

Indicates the switches that control the output of CHR and SIG logs of the eNodeB.

STMSI_MASK_SW: If this option is selected, S-TMSI mask enabled. With this function, all S-TMSIs in internal and external CHRs are replaced by 0. If this option is deselected, this function is disabled.

PUBLIC_TRC_ALIGN_SW: Indicates whether to align the output of the external CHR event PUBLIC INFO with the output of TRC logs. If this option is selected, the alignment is enabled. If this option is deselected, the alignment is disabled.

PUBLIC_SIG_ALIGN_SW: Indicates whether to align the output of the external CHR event PUBLIC INFO with the output of the periodic event of SIG logs. If this option is selected, the alignment is enabled. If this option is deselected, the alignment is disabled.

AOA_REPORT_SW: Indicates whether to enable the reporting of the angle of arrival (AoA) of UE signals received at the eNodeB. If this option is selected, AoA reporting is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
SIG Report Switch

Indicates whether to report SIG logs and signaling soft collection results. If this parameter is set to ON, SIG logs and signaling soft collection results that have been subscribed to are normally reported. If this parameter is set to OFF, reporting of these SIG logs and signaling soft collection results is forcibly terminated and new subscriptions no longer take effect.
Event Subscription Info

Indicates the IDs of successfully subscribed events displayed in the result of the DSP ENODEBCHROUTPUTCTRL command.
