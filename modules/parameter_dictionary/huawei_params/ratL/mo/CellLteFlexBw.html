CellLteFlexBw

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellLteFlexBw

Description

The CellLteFlexBw MO consists of parameters related to RB configurations when non-standard LTE bandwidth is used. The parameters include the start and end RB positions that can be used by LTE. Such information must be configured by network planning engineers based on site requirements.

Effective Scenario

Immediately
