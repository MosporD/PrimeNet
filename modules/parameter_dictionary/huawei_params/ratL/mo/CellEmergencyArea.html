CellEmergencyArea

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellEmergencyArea

Description

This MO consists of parameters identifying emergency areas for a cell. A maximum of 16 CellEmergencyArea MO instances can be configured for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 16 CellEmergencyArea MOs can be configured for each cell.
  • Relation with the CellEmergencyArea MO:
    • A maximum of 144 different EmergencyAreaId in CellEmergencyArea MOs can be configured for each eNB.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLEMERGENCYAREA

Use this command to add cell emergency area information.
LST CELLEMERGENCYAREA

Use this command to list the configuration of Cell Emergency Area.
RMV CELLEMERGENCYAREA

Use this command to remove cell emergency area information.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local primary cell ID. It uniquely identifies a cell within an eNodeB. This option applies only to LTE FDD and LTE TDD.
Emergency Area ID

Indicates the ID of an emergency area in which an alarm message is to be broadcast. The emergency area ID is defined by the operator. An emergency area consists of one or several cells. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
