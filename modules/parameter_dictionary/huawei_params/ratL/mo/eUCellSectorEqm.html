eUCellSectorEqm

+-NE
  +-eNodeBFunction
    +-Cell
      +-eUCellSectorEqm

Description

An eUCellSectorEqm MO consists of parameters related to the sector device and baseband device that serve the cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, EuSectorEqmGroup, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • In a Cell MO, if MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to SFN, and the value of CellActiveState is CELL_ACTIVE: When NbCellFlag is set to FALSE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of eUCellSectorEqm MOs and EuSectorEqmGroup MOs under this Cell MO; when NbCellFlag is set to TRUE, SectorEqmNum must be set to a value greater than or equal to the sum of the numbers of EuPrbSectorEqm MOs and EuPrbSectorEqmGroup MOs under all Prb MOs that are under this Cell MO.
    • When FddTddInd in a Cell MO is set to CELL_FDD, MultiRruCellFlag and MultiRruCellMode in the Cell MO are set to BOOLEAN_TRUE and SFN, if NbCellFlag is set to FALSE, at most eight eUCellSectorEqm and EuSectorEqmGroup MOs can be configured under the Cell MO, if NbCellFlag is set to TRUE, at most sixteen EuPrbSectorEqm and EuPrbSectorEqmGroup MOs can be configured under the Cell MO.
    • In a Cell MO, if NbCellFlag is TRUE, eUCellSectorEqm and EuSectorEqmGroup cannot be configured under the Cell, if NbCellFlag is FALSE, EuPrbSectorEqm and EuPrbSectorEqmGroup cannot be configured under the Cell.
  • Relation with the Cell MO:
    • One or two eUCellSectorEqm instances can be configured for a Cell MO instance in which the MultiRruCellFlag parameter is not configured and the CellActiveState, FddTddInd, NbCellFlag, and TxRxMode parameters are set to CELL_ACTIVE, CELL_FDD, FALSE, and 4T4R, respectively. When the settings of these parameters in the Cell MO instance differ from the preceding settings, only one eUCellSectorEqm instance can be configured.
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to TWO_RRU_COMBINATION, two eUCellSectorEqm MOs must be configured under this Cell MO.
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to DIGITAL_COMBINATION, the number of eUCellSectorEqm MOs configured under this Cell MO ranges from 2 to 8.
    • In the Cell MO, BaseBandEqmId must be set to the same value if CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag to BOOLEAN_TRUE, and MultiRruCellMode to CELL_COMBINATION for the cells under the Cell MO, and the following condition is met: UlBandWidth is set to CELL_BW_N25.
    • When CellActiveState and FddTddInd in a Cell MO are set to CELL_ACTIVE and CELL_TDD, respectively, a minimum of one and a maximum of seven eUCellSectorEqm MOs must be configured under the Cell MO if MultiRruCellFlag and MultiRruCellMode in the Cell MO are set to BOOLEAN_TRUE and SFN, respectively.
    • If FddTddInd is set to CELL_FDD, MultiRruCellMode is not set to SFN, SectorCpriCompression in eUCellSectorEqm can be set to NULL only.
    • If FddTddInd is set to CELL_TDD, MultiRruCellMode is not set to SFN or CELL_COMBINATION, SectorCpriCompression in eUCellSectorEqm can be set to NULL only.
    • If FddTddInd is set to CELL_TDD, MultiRruCellMode is set to SFN or CELL_COMBINATION, and DlBandWidth is set to CELL_BW_N25, SectorCpriCompression in eUCellSectorEqm can be set to NULL or NO_COMPRESSION.
    • When the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, if the value of the FddTddInd parameter is set to CELL_TDD, and the BaseBandEqmId in the eUCellSectorEqm MO or BaseBandEqmId parameter in the EuSectorEqmGroup MO corresponding to the Cell MO is configured, the SubframeAssignment parameter must be set to the same value for the cells for which the CellActiveState parameter in the corresponding Cell MO is set to CELL_ACTIVE.
    • If FddTddInd in Cell is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to SFN. If DlBandWidth is set to CELL_BW_N6 or CELL_BW_N15, SectorCpriCompression in eUCellSectorEqm in Cell can be set to NULL or NO_COMPRESSION. If DlBandWidth is set to CELL_BW_N25, SectorCpriCompression in eUCellSectorEqm in Cell can be set to NULL, NO_COMPRESSION or NORMAL_COMPRESSION. If DlBandWidth is set to CELL_BW_N50, CELL_BW_N75, CELL_BW_N100, SectorCpriCompression in eUCellSectorEqm in Cell can be set to NULL, NO_COMPRESSION, NORMAL_COMPRESSION or ENHANCED_COMPRESSION.
    • When the CellActiveState parameter in a Cell MO is set to CELL_ACTIVE, the MultiRruCellFlag parameter in the Cell MO is not configured, and multiple eUCellSectorEqm MO instances are configured for this Cell MO, the ReferenceSignalPwr, BaseBandEqmId, SectorCpriCompression, AutoCfgFlag, and VisualCellId parameters in these eUCellSectorEqm MO instances must be set to the same values.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to ADVANCED_BEAMFORMING, the FddTddInd and TxRxMode parameters in the Cell MO must be set to CELL_FDD and 4T4R, respectively.
    • In a Cell MO, if FddTddInd is set to CELL_FDD, MultiRruCellFlag is set to BOOLEAN_TRUE, MultiRruCellMode is set to MPRU_AGGREGATION and CellActiveState is set to CELL_ACTIVE, the SECTOREQM MO corresponding to each eUCellSectorEqm MO under this Cell MO must be associated with one TX antenna, two TX antennas, or four TX antennas (the preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER), one RX antenna, two RX antennas, or four RX antennas.
    • In a Cell MO, if CellActiveState is CELL_ACTIVE and MultiRruCellMode is not set to CELL_COMBINATION, and MultiRruCellMode is not set to SFN, the total number of TX antennas and the total number of RX antennas are calculated as follows: If TxRxMode is set to 1T1R or 2T2R and WorkMode is set to UL_DL, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) and that of RX antennas associated with the SECTOREQM MO corresponding to the eUCellSectorEqm MO under this Cell MO must be equal to the number of TX antennas and that of RX antennas specified by the value of TxRxMode, respectively. If TxRxMode is set to 1T1R or 2T2R and WorkMode is set to DL_ONLY, the total number of TX antennas (The preceding TX antennas refer to the TX antennas whose TX Antenna Master/Slave Mode is set to MASTER) associated with the SECTOREQM MO corresponding to the eUCellSectorEqm MO under this Cell MO must be equal to 0 or the number of TX antennas specified by the value of TxRxMode, and the total number of RX antennas associated with this SECTOREQM MO must be equal to the number of RX antennas specified by the value of TxRxMode.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 or MASSIVE_MIMO_Ph2, the DlCyclicPrefix and UlCyclicPrefix parameters in the associated Cell MO must be set to NORMAL_CP.
    • If the CellBeamMode parameter in an eUCellSectorEqm MO under a Cell MO is set to MASSIVE_MIMO_Ph1, the CellRadius parameter in this Cell MO cannot be set to a value greater than 15000.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1, the FddTddInd parameter in Cell MO must be set to CELL_FDD.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1, the TxRxMode parameter in the associated Cell MO must be set to 4T4R or 8T8R.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 and the TxRxMode parameter in the associated Cell MO is set to 4T4R, the CrsPortNum and CrsPortMap parameters in the Cell MO must be set to CRS_PORT_4 and 4T4P_0321 or NOT_CFG, respectively.
    • If the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 or MASSIVE_MIMO_Ph2, the MultiRruCellFlag parameter in the associated Cell MO must be set to BOOLEAN_FALSE.
    • If the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 or MASSIVE_MIMO_Ph2, the HighSpeedFlag parameter in the associated Cell MO must be set to LOW_SPEED.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, the DlBandWidth parameter in the associated Cell MO must not be set to CELL_BW_N6 or CELL_BW_N15.
    • When SectorCpriCompression in the eUCellSectorEqm MO is set to TRIPLEX_COMPRESSION_10M, FddTddInd in the associated Cell MO must be set to CELL_FDD, and DlBandWidth and UlBandWidth in this Cell MO must be set to CELL_BW_N50.
    • When the CellActiveState in Cell is set to CELL_ACTIVE and the CellBeamMode parameter in eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph1 and the TxRxMode parameter in the associated Cell MO is set to 8T8R, or the CellBeamMode parameter in eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, the SectorEqmCombineGrpId in the eUCellSectorEqm MO must be invalid value.
    • When the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2, the FddTddInd and TxRxMode parameters in the Cell MO must be set to CELL_FDD and 32T32R, respectively, the CPRICompression parameter in the Cell MO must be set based on the setting of UlBandWidth in the Cell MO. (1) If the UlBandWidth parameter is set to CELL_BW_N100 or CELL_BW_N75, the CPRICompression parameter must be set to NORMAL_COMPRESSION, ENHANCED_COMPRESSION, or 3_2_COMPRESSION. (2) If the UlBandWidth parameter is set to CELL_BW_N50, the CPRICompression parameter must be set to NORMAL_COMPRESSION, ENHANCED_COMPRESSION, or TRIPLEX_COMPRESSION_10M. (3) If the UlBandWidth parameter is set to CELL_BW_N25, the CPRICompression parameter must be set to NORMAL_COMPRESSION.
    • When the FddTddInd and TxRxMode parameters in the Cell MO are set to CELL_FDD and 32T32R, respectively, the CellBeamMode parameter in the eUCellSectorEqm MO must be set to MASSIVE_MIMO_Ph2.
    • If the CellBeamMode parameter in an eUCellSectorEqm MO under a Cell MO is set to MASSIVE_MIMO_Ph2, the CellRadius parameter in the Cell MO cannot be set to a value greater than 77300 when the PreambleFmt parameter in this Cell MO is set to 1 or a value greater than 15000 when the PreambleFmt parameter in this Cell MO is set to a value other than 1.
    • If the CellBeamMode parameter in an eUCellSectorEqm MO under a Cell MO is set to MASSIVE_MIMO_Ph2, the CellRadius parameter in the Cell MO cannot be set to a value greater than 77300 when the PreambleFmt parameter in this Cell MO is set to 1 or a value greater than 15000 when the PreambleFmt parameter in this Cell MO is set to a value other than 1.
    • In the Cell MO, if CellActiveState is set to CELL_ACTIVE, FddTddInd is set to CELL_FDD, TxRxMode is set to 8T8R, and CrsPortNum is set to CRS_PORT_2, CellBeamMode in the eUCellSectorEqm MO associated with this cell must be set to MASSIVE_MIMO_Ph1.
    • If the SectorCpriCompression parameter in an eUCellSectorEqm MO is set to 3_2_COMPRESSION, then in the corresponding Cell MO, the FddTddInd parameter must be set to CELL_TDD and the UlBandWidth parameter must be set to CELL_BW_N75 or CELL_BW_N100.
    • If the value of CellActiveState in a Cell MO is CELL_ACTIVE, FddTddInd and TxRxMode in this Cell MO are set to CELL_FDD and 8T8R, respectively, and CellBeamMode in the eUCellSectorEqm MO under this Cell MO is set to NORMAL, then CellRadius in this Cell MO must be set to a value less than or equal to 15000.
    • If the value of CellActiveState in a Cell MO is CELL_ACTIVE, FddTddInd and TxRxMode in this Cell MO are set to CELL_FDD and 8T8R, respectively, and CellBeamMode in the eUCellSectorEqm MO under this Cell MO is set to NORMAL, then SectorEqmCombineGrpId in the eUCellSectorEqm MO under this Cell MO must be set to an invalid value.
  • Relation with the Cell and EuSectorEqmGroup MOs:
    • In a Cell MO, if CellActiveState is set to CELL_ACTIVE, MultiRruCellFlag is set to BOOLEAN_TRUE, and MultiRruCellMode is set to CELL_COMBINATION, the number of eUCellSectorEqm MOs configured under this Cell MO ranges from 1 to 12. If the EuSectorEqmGroup MO is configured under this Cell MO, the number of eUCellSectorEqm MO instances, and the number of EuSectorEqmGroup instances must be less than 13.

    • In a Cell MO, if FddTddInd is set to CELL_FDD and MultiRruCellFlag is set to BOOLEAN_TRUE and MultiRruCellMode is set to MPRU_AGGREGATION, the number of EuSectorEqmGroup plus the number of different values of SectorEqmRef between eUCellSectorEqm and EuSectorEqmGroup must be less than 7.

    • When the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE, if the value of the FddTddInd parameter is set to CELL_TDD, and the BaseBandEqmId in the eUCellSectorEqm MO or BaseBandEqmId parameter in the EuSectorEqmGroup MO corresponding to the Cell MO is configured, the SubframeAssignment parameter must be set to the same value for the cells for which the CellActiveState parameter in the corresponding Cell MO is set to CELL_ACTIVE.
    • In a Cell MO, if FddTddInd is set to CELL_FDD, NbCellFlag is set to FALSE, CellActiveState is set to CELL_ACTIVE and MultiRruCellMode is set to SFN, the eUCellSectorEqm MO or EuSectorEqmGroup MO under this Cell MO must have been configured.
    • In a Cell MO, if the CellActiveState parameter is set to CELL_ACTIVE, the MultiRruCellFlag parameter is set to BOOLEAN_TRUE, the MultiRruCellMode parameter is set to CELL_COMBINATION, and an EuSectorEqmGroup MO has been configured, then the sum of the EuSectorEqmGroup and eUCellSectorEqm MO instances configured in the Cell MO must be less than 7.
  • Relation with the Cell and EuPrbSectorEqm MOs:

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.
Reference signal power

Indicates the reference signal power of cell-specific sector equipment. If this parameter is set to 32767, it is invalid, and the cell uses the reference signal power specified in the PDSCHCfg MO to transmit reference signals. For details, see 3GPP TS 36.213. This parameter is valid only when the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE and the MultiRruCellMode parameter in the Cell MO is set to SFN, CELL_COMBINATION, or MPRU_AGGREGATION. This parameter applies only to LTE FDD and LTE TDD.
Baseband equipment ID

Indicates the ID of a piece of baseband equipment that serves the cell.

If this parameter is set to 255 for a cell, baseband equipment is not specified for the cell. In this case, the eNodeB selects BBPs for a cell among all the local available BBPs. The BBP directly connected to the RRU serving the cell is preferentially selected.

If this parameter is set to another value, baseband equipment is specified for the cell. In this case, the cell can use only the BBPs included in the baseband equipment, and the BBP directly connected to the RRU is preferentially selected. This parameter applies only to LTE FDD and LTE TDD.
Reference Signal Power Margin

Indicates the reference signal power headroom of each physical antenna. This parameter is valid only when the MultiRruCellFlag parameter of the Cell MO is set to BOOLEAN_TRUE(True) and the MultiRruCellMode parameter in the Cell MO is set to SFN(SFN) or CELL_COMBINATION(Cell Combination). This parameter applies only to LTE TDD.

If this parameter is set to 0, the parameter does not take effect. That is, the reference signal power headroom of the cell equals the value of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO. If this parameter is set to a non-zero value, the reference signal power headroom of the cell equals this value regardless of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO set for the sector equipment of the cell.
Sector CPRI Compression

Indicates the CPRI compression type of the sector equipment. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, or NULL. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, and this parameter value is applicable only to LTE FDD. The value 3_2_COMPRESSION indicates that the compression ratio of 3.2:1 is used, and this value is applicable only to TDD. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than that of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cell served by the sector equipment automatically restarts. This parameter is used only when MultiRruCellMode is set to SFN or CELL_COMBINATION. This parameter can be set based on the sector equipment. When this parameter is set to NULL, the CPRI compression type of the carrier of the cell depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the sector equipment CPRI compression type of carriers depends on the value of the SectorCpriCompression parameter in the eUCellSectorEqm MO. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by RRUs in the RRU chain or ring are deactivated. Activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.
Auto Config Flag

Indicates whether to automatically or manually bind a baseband equipment ID to a cell. To enable automatic binding, set this parameter to AUTO_MODE_CFG. To enable manual binding, set this parameter to MANUAL_MODE_CFG. This parameter applies only to LTE FDD and LTE TDD.
Weight Number

Indicates the weight number configured for cell-specific sector equipment. If this parameter is not set to 255, the value of this parameter has a mapping relationship with the DEVICENO parameter in the BFANT MO. If this parameter is set to 255, the smallest weight number specified by the DEVICENO parameter in the BFANT is used. If the value of DEVICENO in the DSP BFANT command output is not equal to the value of this parameter, the default weight is used. This parameter applies only to LTE TDD.
Virtual Cell ID

Indicates a virtual cell ID used for DMRS and CSI-RS scrambling when adaptive SFN and TM10 are enabled. This parameter should be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to FDD.
Sector Equipment Combine Group ID

Indicates the ID of a sector equipment combination group, which contains multiple sets of sector equipment. The value 255 indicates that the sector equipment is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.
Cell Beam Mode

Indicates the beam mode of the cell. This parameter has four values: NORMAL, ADVANCED_BEAMFORMING, MASSIVE_MIMO_Ph1, and MASSIVE_MIMO_Ph2. The value NORMAL indicates that the cell is a normal cell. The value ADVANCED_BEAMFORMING indicates that the cell uses AAU-based advanced beamforming. The value MASSIVE_MIMO_Ph1 indicates that the cell uses phase-1 massive MIMO. The value MASSIVE_MIMO_Ph2 indicates that the cell uses phase-2 massive MIMO. This parameter applies only to LTE FDD.
Table 3 Dynamic parameters

Parameter

Description
RRU Cabinet No.

Indicates the cabinet number of the RRU.
RRU Subrack No.

Indicates the subrack number of the RRU.
RRU Slot No.

Indicates the slot number of the RRU.
Received total wideband power

Indicates the RTWP for the carrier. The normal value range is from -130 dBm to -40 dBm. If the value is out of this range, the SINR may be too low, or power saturation occurs (which leads to signal distortion), affecting air interface performance. The value 65535 is invalid, which indicates that the RTWP of the target module cannot be queried.
RX Channels No.

Indicates the RX channel number of the RRU. An RRU is configured with multiple RX channels.
eNodeB ID

Indicates the ID of the eNodeB.
