eNodeBSonDBCfg

+-NE
  +-eNodeBFunction
    +-eNodeBSonDBCfg

Description

The eNodeBSonDBCfg MO consists of parameters related to data configuration management for the SON algorithm.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ENODEBSONDBCFG

Use this command to query the start time to write the changes generated by the automatic grouping configuration function of SON into the database. The changes include overlapping indicator changes of inter-frequency neighboring cells or the switch status changes of the cell to which intra-frequency neighboring cells belong.
MOD ENODEBSONDBCFG

Use this command to modify the start time to write the changes generated by the automatic grouping configuration function of SON into the database. The changes include overlapping indicator changes of inter-frequency neighboring cells or the switch status changes of the cell to which intra-frequency neighboring cells belong.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Start Time

Indicates the start time to write the changes generated by the ANGC function of SON into the database, including overlapping indicator changes of inter-frequency neighboring cells or the switch status changes of the cell to which intra-frequency neighboring cells belong. The results calculated by the ANGC function are written into the database after the time in the system reaches the start time specified by this parameter. This parameter applies only to LTE FDD and LTE TDD.
