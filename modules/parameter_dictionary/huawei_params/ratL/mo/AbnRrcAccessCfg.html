AbnRrcAccessCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-AbnRrcAccessCfg

Description

The AbnRrcAccessCfg MO consists of parameters used to configure the characteristics of abnormal RRC connection setups. The eNodeB uses the configured parameters to detect abnormal RRC connection setups. Detected abnormal RRC connection setups are not measured by performance counters used to measure normal RRC connection setups.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 Related MML commands

MML Command

Function

Use this command to configure parameters for the detection of abnormal RRC connection setups.

Use this command to query the parameters used to detect abnormal RRC connection setups.
MOD ABNRRCACCESSCFG

Use this command to modify parameters for the detection of abnormal RRC connection setups.
RMV ABNRRCACCESSCFG

Use this command to remove parameters for the detection of abnormal RRC connection setups.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within the local or peer base station. This parameter applies only to NB-IoT.
Access Period

Indicates the period of abnormal RRC connection setup. This parameter applies only to NB-IoT.
Access Period Offset

Indicates the offset to the period of abnormal RRC connection setup. This parameter applies only to NB-IoT.
TA

Indicates the TA value of abnormal RRC connection setup. This parameter applies only to NB-IoT.
TA Offset

Indicates the offset to the TA value of abnormal RRC connection setup. This parameter applies only to NB-IoT.
