CaGroup

+-NE
  +-eNodeBFunction
    +-CaGroup
      +-CaGroupCell[0~9]

Description

The CaGroup MO defines a carrier aggregation (CA) group.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    CaGroupCell[0~9]
  • Relation with the CaGroupCell, Cell, and eNodeBFunction MOs:
    • If CaGroupTypeInd in a CaGroup MO is set to FDD, the Cell MOs associated with the CaGroupCell MO under this CaGroup MO must also work in CELL_FDD mode.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, the Cell MOs associated with the CaGroupCell MO under this CaGroup MO must also work in CELL_TDD mode.
    • If CaGroupTypeInd in a CaGroup MO is set to FDDTDD, FddTddInd in Cell MO associated with a CaGroupCell MO under this CaGroup MO must be CELL_TDD, SubframeAssignment must be SA1 or SA2.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, FddTddInd in Cell MO associated with a CaGroupCell MO under this CaGroup MO must be CELL_TDD, SubframeAssignment must be SA1 or SA2.
  • Relation with the CaGroupCell MO:
    • If CaGroupTypeInd in a CaGroup MO is set to FDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
    • If CaGroupTypeInd in a CaGroup MO is set to TDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
    • If CaGroupTypeInd in a CaGroup MO is set to FDDTDD, a maximum of nine CaGroupCell MOs can be configured under this CaGroup MO.
  • Relation with the MPT MO:
    • If the number of MPT MOs in which TYPE is set to UMPT is 0, CaGroupId in the CaGroup MO must be set to a value smaller than or equal to 17.
  • Relation with the MDU MO:
    • If the TYPE parameter in the MDU MO is set to MDUC, values of CaGroupId in all CaGroup MOs must be equal to or less than 2.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CA Group Identity

Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
CA Group Type Indication

Indicates the type of the CA group. This parameter applies only to LTE FDD and LTE TDD.
Operator List

Indicates the operators of which CA is allowed in cells of the group specified by the CaGroup.CaGroupId parameter. The characters in sequence in the parameter value correspond to the operator indexes of the local eNodeB. A character can be either 0 or 1. If a character is 1, CA is allowed for UEs served by the corresponding operator in the cells. If the character is 0, CA is not allowed for UEs served by the corresponding operator in the cells. The eNodeB filters the CA cell groups based on the operator which a CA UE accesses. If the corresponding operator index is invalid, the eNodeB ignores it. For example, 100100 indicates that the CA cell group belongs to the operators whose operator indexes are 0 and 3. This parameter does not take effect on the LMPT, and if the LMPT is used, the CA cell group can be used by all operators. This parameter applies only to LTE FDD and LTE TDD.
