ENodeBConnStateTimer

+-NE
  +-eNodeBFunction
    +-ENodeBConnStateTimer

Description

The ENodeBConnStateTimer MO consists of parameters related to the timers indicating eNodeB connection states.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST ENODEBCONNSTATETIMER

Use this command to list the eNodeB connection state timers.
MOD ENODEBCONNSTATETIMER

Use this command to modify the eNodeB connection state timers.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
S1 Message Waiting Timer

Indicates the timer governing the period that the eNodeB waits for a response message from the MME when the UE is running non-QCI1 services. If the UE is running services with a QCI of 1, the S1MsgWaitingTimerQci1 parameter controls the period that the eNodeB waits for a response message from the MME.
X2 Message Waiting Timer

Indicates the length of the timer governing the period in which the eNodeB waits for an X2 response message from a peer eNodeB when a UE is not performing any QCI-1 service. If the eNodeB performs an X2-based handover for a UE performing a QCI-1 service, the period is determined by the value of the X2MessageWaitingTimerQci1 parameter.
UU Message Waiting Timer

Indicates the timer governing the period the eNodeB waits for a response message from a UE when the UE is running non-QCI1 services. If the timer expires, the eNodeB initiates a UE context release over the S1 interface.
CDMA2000 1xRTT HO Uu Prepare Timer

Indicates the timer for the eNodeB to wait for a handover preparation completion message when a UE is being handed over to a CDMA2000 1xRTT cell. The eNodeB starts the timer after sending a Handover From EUTRA Preparation Request message to the UE and stops the timer after receiving a UL Handover Preparation Transfer message from the UE. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 1xRTT HO S1 Waiting Timer

Indicates the timer for the eNodeB to wait for a Downlink S1 CDMA2000 Tunneling message when a UE being is handed over to a CDMA2000 1xRTT cell. The eNodeB starts the timer after sending an UPLINK S1 CDMA2000 TUNNELING message to the MME and stops the timer after receiving a Downlink S1 CDMA2000 Tunneling message containing CDMA2000 HO Status. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 1xRTT HO Complete Timer

Indicates the timer for the eNodeB to release resources for a UE after the UE is handed over to a CDMA2000 1xRTT cell. The eNodeB starts the timer after sending a MobilityFromEUTRACommand message. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 HRPD HO Complete Timer

Indicates the timer for the eNodeB to release resources for a UE after the UE is handed over to a CDMA2000 HRPD cell. The eNodeB starts the timer after sending a MobilityFromEUTRACommand message. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 HRPD HO S1 Waiting Timer

Indicates the timer for the eNodeB to wait for a Downlink S1 CDMA2000 Tunneling message when a UE is being handed over to a CDMA2000 HRPD cell. The eNodeB starts the timer after sending an UPLINK S1 CDMA2000 TUNNELING message to the MME and stops the timer after receiving a Downlink S1 CDMA2000 Tunneling message containing CDMA2000 HO Status. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000 HRPD HO Uu Prepare Timer

Indicates the timer for the eNodeB to wait for a handover preparation completion message when a UE is being handed over to a CDMA2000 HRPD cell. The eNodeB starts the timer after sending a Handover From EUTRA Preparation Request message to the UE and stops the timer after receiving a UL Handover Preparation Transfer message from the UE. This parameter applies only to LTE FDD and LTE TDD.
RRCConnSetupCmp Waiting Timer

Indicates the timer for the eNodeB to wait for an RRC Connection Setup Complete message.
SecurityModeComplete Waiting Timer

Indicates the length of the timer governing the period in which the eNodeB waits for a Security Mode Complete message from a UE. If the UuMsgSimulSendSwitch parameter in the GlobalProcSwitch MO is set to ON and the UeCapbEnquirySecurityEnhSwitch option of the ProtocolMsgOptSwitch parameter in this MO is deselected, the SecCmpWaitingTimer parameter does not take effect and the UuMessageWaitingTimer parameter is used instead.
UE Capability Info Message Waiting Timer

Indicates the length of the timer governing the period in which the eNodeB waits for a UE Capability Information message from a UE. For details about this message, see 3GPP TS 36.331.
First Forward Packet Timer

Indicates the timer for the eNodeB to wait for the first forwarded packet. This parameter applies only to LTE FDD and LTE TDD.
End Marker Timer

Indicates the timer for the eNodeB to wait for the endmarker packet. This parameter applies only to LTE FDD and LTE TDD.
S1 Message Waiting Timer for Qci1

Indicates the timer governing the period that the eNodeB waits for a response message from the MME when the UE is running services with the QCI of 1. If the timer expires, the eNodeB initiates a UE context release over the S1 interface. This parameter applies only to LTE FDD and LTE TDD.
X2 Message Waiting Timer for Qci1

Indicates the length of the timer governing the period in which the eNodeB waits for an X2 response message from a peer eNodeB when a UE is performing a QCI-1 service. If this timer expires, the eNodeB processes in the same way as it processes when the timer specified by the X2MessageWaitingTimer parameter expires. This parameter applies only to LTE FDD and LTE TDD.
UU Message Waiting Timer for Qci1

Indicates the timer governing the period the eNodeB waits for a response message from a UE when the UE is running services with the QCI of 1. If the timer expires, the eNodeB initiates a UE context release over the S1 interface. This parameter applies only to LTE FDD and LTE TDD.
Bearer Activity Threshold

Indicates the threshold used to determine bearer activity. The eNodeB consistently monitors the consecutive no-transmission duration for each bearer. If the duration for a bearer is less than or equal to the threshold, the eNodeB determines that the bearer is active. If this parameter is set to 65535, the eNodeB does not determine bearer activity for performance counter measurement. This parameter applies only to LTE FDD and LTE TDD.
RRC Reestablishment Activity Threshold

Indicates the switch that controls the measurement optimization of service drops for UEs in the active state and the threshold based on which the eNodeB determines whether RRC connection reestablishments are for UEs in the active state.

When this parameter is used as the switch: If this parameter is set to a value other than 0, the measurement optimization is enabled, and the eNodeB collects statistics on services drops for UEs in the active state at the PDCP layer. If this parameter is set to 0, the measurement optimization is disabled, and the eNodeB collects statistics on service drops for UEs in the active state at the MAC layer. You are advised to set this parameter to a value other than 0 only in network swapping scenarios.

When this parameter is used as the threshold: If this parameter is set to a value other than 0, the eNodeB consistently monitors how long a UE consecutively does not transmit or receive data. If the duration is shorter than the threshold, the eNodeB determines that an RRC connection reestablishment for the UE is an RRC connection reestablishment for a UE in the active state. If this parameter is set to 0, the eNodeB does not determine the UE active state for performance counter measurements related to RRC connection reestablishment.

This parameter applies only to LTE FDD.
E-CID Waiting Timer

Indicates the length of the timer that controls how the eNodeB responds to an E-CID-based positioning request message after receiving the message from the E-SMLC. Before the timer expires, if the eNodeB has already collected all E-CID measurement results, the eNodeB immediately responds to the request. If the timer expires, the eNodeB sends all measurement results that are already collected to the E-SMLC, or responds to the E-SMLC with a failure if the eNodeB does not collect any measurement result. This parameter applies only to LTE FDD and LTE TDD.
NSA DC X2 Message Waiting Timer

Indicates the timer governing the period in which the eNodeB waits for an X2 response message from a peer gNodeB. This parameter applies only to LTE FDD and LTE TDD.
