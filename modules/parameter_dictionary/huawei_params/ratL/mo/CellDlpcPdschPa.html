CellDlpcPdschPa

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDlpcPdschPa

Description

A CellDlPcPdschPa MO consists of the PA parameters related to Physical Downlink Shared Channel (PDSCH) power control in a cell.

Effective Scenario

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
PA for even power distribution

Indicates the PA to be used when PA adjustment for PDSCH power control is disabled, DL ICIC is disabled, and the even power distribution is used for the PDSCH. This parameter applies only to LTE FDD and LTE TDD.
Nominal PDSCH-to-RS-EPRE Offset

Indicates the power offset of the PDSCH EPRE relative to the reference signal (RS) EPRE. If this parameter is set to -1 to 6, nomPDSCH-RS-EPRE-Offset is set to -1 to 6. The parameter is set to 0 by default. This parameter applies only to LTE FDD and LTE TDD.
EPRE Offset Adjustment Threshold

Indicates the threshold for triggering the adjustment of the PDSCH power offset relative to the reference signal power. If this parameter is set to a value within the range of 0 to 26, the PDSCH power offset adjustment is triggered when the absolute value of the CQI adjustment is greater than this threshold. If this parameter is set to 255, the power offset adjustment does not take effect. The default value is 255. This parameter applies only to LTE FDD.
TM9 Rank Correct Threshold

Indicates the threshold for triggering rank correction for 4R TM9 UEs. If this parameter is set to a value within the range of 0 to 28, a codebook subset constraint is activated so that high-rank UEs report a maximum of rank 2 when their MCS indexes are lower than this threshold. If this parameter is set to 255, the constraint does not take effect. The default value is 255. This parameter applies only to LTE FDD.
Cell-Level NPREO Adjustment Threshold

Indicates the threshold used for starting the cell-level NPREO (the IE nomPDSCH-RS-EPRE-Offset) adjustment algorithm. If this parameter is set to 255, this algorithm does not take effect. If this parameter is not set to 255, the parameter value indicates the predicted gain threshold for searching for the optimal cell-level NPREO. When the algorithm searches for the optimal cell-level NPREO, if the predicted UE throughput gain yielded by changing the NPREO from B to A is greater than the threshold, A is regarded as better than B. This parameter applies only to LTE FDD.
UE-Level NPREO Adjustment Threshold

Indicates the threshold used for starting the UE-level NPREO (the IE nomPDSCH-RS-EPRE-Offset) adjustment algorithm. If this parameter is set to 127, this algorithm does not take effect. If this parameter is not set to 127, the parameter value indicates the compensation value used in the UE-level NPREO adjustment algorithm. This parameter applies only to LTE FDD.
