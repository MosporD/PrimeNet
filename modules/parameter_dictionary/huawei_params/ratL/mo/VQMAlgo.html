VQMAlgo

+-NE
  +-eNodeBFunction
    +-VQMAlgo

Description

The VQMAlgo MO consists of the voice quality monitoring parameter, that is, the maximum UL voice packet delay variation allowed on the Uu interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST VQMALGO

Use this command to list voice quality monitoring (VQM) algorithm parameters.
MOD VQMALGO

Use this command to modify voice quality monitoring (VQM) algorithm parameters.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
UL Delay Jitter

Indicates the maximum UL voice packet delay variation allowed on the Uu interface. If the actual delay variation of a UL voice packet exceeds this limit, this packet is regarded as lost during the evaluation of voice quality indicator (VQI). The delay variation is measured at the eNodeB PDCP layer. This parameter applies only to LTE FDD and LTE TDD.
VQI Good Threshold

Indicates the voice quality indicator (VQI) threshold for determining the voice quality is good. If the VQI evaluation value is greater than the VqiGoodThd parameter value and less than or equal to the VqiExcellentThd parameter value, the voice quality is considered as good. If the VQI evaluation value is less than or equal to the VqiGoodThd parameter value and greater than the VqiPoorThd parameter value, the voice quality is considered as accepted. This parameter applies only to LTE FDD and LTE TDD.
VQI Poor Threshold

Indicates the voice quality indicator (VQI) threshold for determining the voice quality is poor. If the VQI evaluation value is greater than the VqiBadThd parameter value and less than or equal to the VqiPoorThd parameter value, the voice quality is considered as poor. If the VQI evaluation value is less than or equal to the VqiGoodThd parameter value and greater than the VqiPoorThd parameter value, the voice quality is considered as accepted. This parameter applies only to LTE FDD and LTE TDD.
VQI Bad Threshold

Indicates the voice quality indicator (VQI) threshold equal to or below which the voice quality is considered as bad. This parameter applies only to LTE FDD and LTE TDD.
Release Threshold of Radio Low Quality for Amr Wideband

Indicates the threshold of the packet loss rate over the air interface for normally releasing AMR-WB and EVS voice services. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON and the uplink or downlink packet loss rate of AMR-WB UEs over the air interface exceeds this threshold, the eNodeB considers that AMR-WB UEs release calls due to poor voice quality. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_ADAPTIVE_ON and the uplink or downlink packet loss rate of AMR-WB and EVS UEs over the air interface exceeds this threshold, the eNodeB considers that AMR-WB and EVS UEs release calls due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.
Release Threshold of Radio Low Quality for Amr Narrowband

Indicates the threshold of the packet loss rate over the air interface for normally releasing AMR-NB voice services. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON or VQM_ALGO_SWITCH_ADAPTIVE_ON and the uplink or downlink packet loss rate of AMR-NB UEs over the air interface exceeds this threshold, the eNodeB considers that UEs release calls due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.
Period Number of Silent for Amr

Indicates the number of periods that is used to evaluate whether a voice service is muted due to poor voice quality. If an AMR or EVS voice service performed by a UE is muted in consecutive periods specified by this parameter, voice mute is regarded to occur during communication. This parameter applies only to LTE FDD and LTE TDD.
Period Number of Low Quality Release for Amr

Indicates the number of periods that is used to evaluate whether a voice service is released due to poor voice quality. If the voice quality of an AMR or EVS voice service is poor in consecutive periods specified by this parameter, the UE is regarded to normally release the voice service due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.
VQI Excellent Threshold

Indicates the voice quality indicator (VQI) threshold above which the voice quality is considered as excellent. This parameter applies only to LTE FDD and LTE TDD.
Threshold of Silent for Amr Narrowband

Indicates the threshold of the packet loss rate for determining whether AMR-NB services are muted. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON or VQM_ALGO_SWITCH_ADAPTIVE_ON and the uplink or downlink packet loss rate of AMR-NB UEs exceeds this threshold, the eNodeB considers that AMR-NB services are muted. This parameter applies only to LTE FDD and LTE TDD.
Release Threshold of Receive Low Quality for Amr Wideband

Indicates the threshold of the received packets loss rate for normally releasing AMR-WB and EVS voice services due to poor voice quality. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON and the received packets loss rate of AMR-WB UEs in the uplink or downlink exceeds this threshold, the eNodeB considers that AMR-WB UEs release calls due to poor voice quality. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_ADAPTIVE_ON and the received packets loss rate of AMR-WB and EVS UEs in the uplink or downlink exceeds this threshold, the eNodeB considers that AMR-WB and EVS UEs release calls due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.
Release Threshold of Receive Low Quality for Amr Narrowband

Indicates the threshold of the received packets loss rate for normally releasing AMR-NB voice services due to poor voice quality. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON or VQM_ALGO_SWITCH_ADAPTIVE_ON and the received packets loss rate of AMR-NB UEs in the uplink or downlink exceeds this threshold, the eNodeB considers that AMR-NB UEs release calls due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.
Threshold of Silent for Amr Wideband

Indicates the threshold of the packet loss rate for determining whether AMR-WB and EVS services are muted. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON and the uplink or downlink packet loss rate of AMR-WB UEs exceeds this threshold, the eNodeB considers that AMR-WB services are muted. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_ADAPTIVE_ON and the uplink or downlink packet loss rate of AMR-WB and EVS UEs exceeds this threshold, the eNodeB considers that AMR-WB and EVS services are muted. This parameter applies only to LTE FDD and LTE TDD.
VQM Algorithm Period

Indicates the VQM evaluation period. During VQM-based voice quality evaluation, voice quality is evaluated and a score is exported periodically. This parameter applies only to LTE FDD and LTE TDD.
Voice Call Setup Delay Threshold

Indicates the threshold for determining abnormal voice call setup delay. If the voice call setup delay (the duration between the INVITE message and the 180RINGING message) is greater than this threshold, an SIP exception event will be recorded in the internal CHR. If the voice call setup delay is less than or equal to this threshold, no SIP exception event will be recorded in the internal CHR. If this parameter is set to 0, the eNodeB does not check whether there are delay exceptions or record SIP exception events in the internal CHR. This parameter applies only to LTE FDD and LTE TDD.
