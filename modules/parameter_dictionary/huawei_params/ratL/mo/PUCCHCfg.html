Description

The PUCCHCfg MO consists of the parameters related to the Physical Uplink Control Channel (PUCCH), which is common radio resources in a cell.

The PUCCH has the following features:

1. Carries HARQ ACKs/NACKs of downlink data.

2. Carries scheduling requests.

3. Carries CQI reports.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Delta shift

Indicates the interval between cyclic shifts used for the PUCCH. The interval between cyclic shifts used for the PUCCH can be acquired based on the average delay spread in the cell, where the average delay spread is acquired based on the networking environment. The parameter value DS1_DELTA_SHIFT is not supported by the LBBPc. If a cell is established on an LBBPc but this parameter is set to DS1_DELTA_SHIFT, the value of this parameter is automatically changed to DS2_DELTA_SHIFT when this parameter takes effect. For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
ACK/SRI Channel Number

Indicates the number of resource indexes allocated to SRI and semi-persistent ACK at the RRC layer for the cell. If this parameter is set to 0, UEs may fail to access the cell. This parameter applies only to LTE FDD and LTE TDD.
CQI RB number

Indicates the number of RBs allocated to the CQI at the RRC layer of cell. This parameter applies only to LTE FDD and LTE TDD.
PUCCH Extended RB Number

Indicates the total number of RBs reserved for the PUSCH at both ends of the system band. This parameter is valid only if the PucchFlexCfgSwitch option of the PucchAlgoSwitch parameter is selected. For LTE FDD, consider the number of RBs used by the PRACH, SRSs, and PUCCH when you set this parameter. For LTE TDD, consider the number of RBs used by the PRACH and PUCCH when you set this parameter. If this parameter is set to a too large value, RBs within the cell bandwidth are not enough for the aforementioned physical resources, which cause failures in cell establishment. This parameter applies only to LTE FDD and LTE TDD.
Format1 Channel Allocation Mode

Indicates the mode for allocating PUCCH format 1/1a/1b code channel resources. The setting of this parameter takes effect only when the DeltaShift parameter is set to DS1_DELTA_SHIFT(ds1). If the Format1ChAllocMode parameter is set to FIXEDMODE(Fixed Mode), consecutive PUCCH format 1/1a/1b code channel resources are always allocated. If the Format1ChAllocMode parameter is set to RANDOMMODE(Random Mode), PUCCH format 1/1a/1b code channel resources are randomly allocated. If this parameter is set to OPTISELECTMODE(OPTISELECTMODE), PUCCH format 1 code channel resources are allocated based on the optimized selection mode. If this parameter is set to RBSAVINGMODE(RB Saving Mode), PUCCH format 1/1a/1b code channel resources are allocated in such a way where an RB is allocated to as many UEs as possible to save RBs. The RBSAVINGMODE value takes effect only in LTE FDD. When this parameter is set to RBSAVINGMODE for LTE TDD, the effect is the same as that set to RANDOMMODE. This parameter applies only to LTE FDD and LTE TDD.
SRI Period Adaptive Switch

Indicates whether to enable scheduling request indicator (SRI) reporting period adaptation. If this parameter is set to QCIADAPTIVE, the eNodeB adaptively changes the SRI reporting period based on the cell load and bearers with different QCIs. If this parameter is set to NOQCIADAPTIVE, the eNodeB adaptively changes the SRI reporting period only based on the cell load. If this parameter is set to OFF and the FixedSriPeriod parameter in the PUCCHCFG MO is set to Disable, the SRI reporting period equals the value of the FixedSriPeriod parameter in the CELLQCIPARA MO. If this parameter is set to OFF and the FixedSriPeriod parameter in the PUCCHCFG MO is not set to Disable, the SRI reporting period equals the value of the FixedSriPeriod parameter in the PUCCHCFG MO. This parameter applies only to LTE FDD and LTE TDD.
Format2 Channel Allocation Mode

Indicates the channel resource allocation mode for PUCCH format 2/2a/2b. If this parameter is set to FIXEDMODE, consecutive channel resources are allocated for PUCCH format 2/2a/2b. If this parameter is set to RANDOMMODE, channel resource allocation is optimized for PUCCH format 2/2a/2b. This parameter applies only to LTE FDD and LTE TDD.
PUCCH Allocation Policy

Indicates the PUCCH resource allocation policy. RbPriorityModeSW: Indicates whether to preferentially use RBs different from those already allocated when allocating new PUCCH code channel resources. If this option is selected, the eNodeB preferentially uses different RBs when allocating new PUCCH code channel resources. In this case, UEs are scheduled on all RBs, reducing inter-code-channel interference to UEs in a cell and improving PUCCH detection performance. If this option is deselected, the eNodeB fully uses each RB available for the PUCCH when allocating new PUCCH code channel resources. For LTE FDD, this option takes effect only when the PUCCHSWITCH option of the PucchAlgoSwitch parameter is deselected.
Format3 RB Number

Indicates the maximum number of RBs that can be used by PUCCH resources in Format 3. This parameter takes effect only when the SCCAckResourceCfgSw option of the PucchAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.
Max 2CC ACK Channel Number

Indicates the maximum number of code channels that can be used by SCC ACKs in 2CC CA scenarios. This parameter takes effect only when options Dl2CCAckResShareSw and SCCAckResourceCfgSw of the PucchAlgoSwitch parameter are selected. This parameter applies only to LTE FDD and LTE TDD.
Fixed SRI Period

Indicates the SRI period for UEs. This parameter takes effect only when the SriPeriodAdaptive parameter in the PUCCHCfg MO is set to OFF. If this parameter is set to Disable(Disable), the SRI period is specified by the SriPeriodAdaptive parameter in the PUCCHCfg MO. This parameter specifies the SRI period for UEs if it is set to a value other than Disable. This parameter applies only to LTE FDD and LTE TDD.
Format1 Code Channel Expansion Threshold

Indicates the threshold for increasing the number of code channels for PUCCH format 1 in the cell. When the number of remaining format 1 code channels is less than this threshold, the number of format-1 code channels will be increased. This parameter is valid only when the PucchSwitch option of the CellAlgoSwitch.PucchAlgoSwitch parameter is selected and the DeltaShift parameter is set to DS1_DELTA_SHIFT. This parameter is invalid for the LBBPc. If this parameter is set to 0, the function does not take effect. This parameter applies only to LTE FDD.
