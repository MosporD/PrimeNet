ENodeBCluster

+-NE
  +-eNodeBFunction
    +-ENodeBCluster

Description

An ENodeBCluster MO consists of parameters related to eNodeB cluster management. It is used to specify an eNodeB in an eNodeB cluster.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ENODEBCLUSTER

Use this command to add an eNodeB to the eNodeB cluster. This command takes effect only on the centralized cluster node.
LST ENODEBCLUSTER

Use this command to query information about an eNodeB in the eNodeB cluster. This command takes effect only on the centralized cluster node.
MOD ENODEBCLUSTER

Use this command to modify information about an eNodeB in the eNodeB cluster. This command takes effect only on the centralized cluster node.
RMV ENODEBCLUSTER

Use this command to remove an eNodeB from the eNodeB cluster. This command takes effect only on the centralized cluster node.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
eNodeB Index

Indicates the index of an eNodeB managed by the centralized clustering node. It uniquely identifies an eNodeB on the centralized clustering node. This parameter applies only to LTE FDD and LTE TDD.
Mobile Country Code

Indicates the MCC of an eNodeB managed by the centralized clustering node. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the MNC of an eNodeB managed by the centralized clustering node. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the ID of an eNodeB managed by the centralized clustering node. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
