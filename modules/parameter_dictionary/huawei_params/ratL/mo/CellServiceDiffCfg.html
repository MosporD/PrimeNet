CellServiceDiffCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellServiceDiffCfg

Description

The CellServiceDiffCfg MO consists of parameters related to service differentiation in a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoExtSwitch MO:
    • If the FPIGTPUSwitch or DSCPRemarkSwitch option of ServiceDiffSwitch in the CellServiceDiffCfg MO is selected, the DSCP_PREALLOCATION_SW option of UlSchEnhSwitch in the CellAlgoExtSwitch MO cannot be selected. If the DSCP_PREALLOCATION_SW option is selected, neither FPIGTPUSwitch nor DSCPRemarkSwitch can be selected.
  • Relation with the CellAlgoSwitch MO:
    • If the FPIGTPUSwitch or DSCPRemarkSwitch option of ServiceDiffSwitch in the CellServiceDiffCfg MO is selected, neither the VideoRateAdaptSwitch nor DownLoadRateLimitSwitch option of ServiceDiffSwitch in the CellAlgoSwitch MO can be selected. If the VideoRateAdaptSwitch or DownLoadRateLimitSwitch option is selected, neither the FPIGTPUSwitch nor DSCPRemarkSwitch option can be selected.
    • If the FPIGTPUSwitch or DSCPRemarkSwitch option of ServiceDiffSwitch in the CellServiceDiffCfg MO is selected, the ScVideoRateAdaptSwitch option of ScVideoOptSwitch in the CellAlgoSwitch MO cannot be selected. If the ScVideoRateAdaptSwitch option is selected, neither FPIGTPUSwitch nor DSCPRemarkSwitch can be selected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Service differentiation switch

Indicates the switches related to service differentiation in a cell.

CellConStaReportSwitch: Indicates the switch used to control whether the RLC-buffered-based cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. This option applies only to LTE FDD and LTE TDD.

FPIGTPUSwitch: Indicates whether to enable the service differentiation feature using the extended GTP-U header containing the FPI value. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority.

DSCPRemarkSwitch: Indicates whether to enable the DSCP Remark-based service differentiation feature. If this option is selected, the eNodeB guarantees differentiated quality of service (QoS) based on the service type specified by the DSCP field in the IP packet sent by the PDN gateway to the eNodeB. This option applies only to LTE FDD.

CellUuConStaReportSwitch: Indicates the switch used to control whether the PRB-based and UL-sync UE cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. When both the CellConStaReportSwitch and CellUuConStaReportSwitch options are selected, the CellConStaReportSwitch option takes effect but the CellUuConStaReportSwitch option does not take effect. This option applies only to LTE FDD and LTE TDD.
Cell Congestion State PRB Threshold

Indicates the threshold for determining the cell congestion status based on the physical resource block (PRB) usage. The eNodeB generates a cell congestion indicator based on this parameter and the CellConStateUeNumThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and the number of UL-sync UEs are greater than or equal to their respective congestion thresholds but do not exceed their respective overload thresholds, the eNodeB sends a cell congestion indicator to the EPC. If either the downlink PRB usage or the number of UL-sync UEs is less than the corresponding congestion threshold, the eNodeB sends a congestion indicator indicating that the cell is in the normal state to the EPC. This parameter applies only to LTE FDD and LTE TDD.
Cell Overload State PRB Threshold

Indicates the threshold for determining the cell overload status based on the PRB usage. This parameter applies only to LTE FDD and LTE TDD.

When DSCPRemarkSwitch is turned on, this parameter indicates the weight of non-P2P service queue. This parameter applies only to LTE FDD and LTE TDD.
