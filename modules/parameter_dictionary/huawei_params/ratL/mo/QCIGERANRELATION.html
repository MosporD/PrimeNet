QCIGERANRELATION

+-NE
  +-eNodeBFunction
    +-Cell
      +-QCIGERANRELATION

Description

A QCIGERANRELATION MO consists of parameters related to the relationship between a GERAN frequency group and a QCI to deploy QCI-specific policies for the frequency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the GeranNfreqGroup MO:
    • Before adding an QCIGERANRELATION, ensure that the associated GeranNfreqGroup has been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD QCIGERANRELATION

Use this command to add a relationship between a QCI and a GERAN frequency group.
LST QCIGERANRELATION

Use this command to list the configurations of the relationship between a QCI and a GERAN frequency group.
MOD QCIGERANRELATION

Use this command to modify the configurations of the relationship between a QCI and a GERAN frequency group.
RMV QCIGERANRELATION

Use this command to remove the relationship between a QCI and a GERAN frequency group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
BCCH Group ID

Indicates the ID of the GERAN frequency group associated with the QCI. This parameter applies only to LTE FDD and LTE TDD.
QCI GERAN Frequency Relation ID

Indicates the ID of the relationship group of the QCI and the GERAN frequency group. This parameter applies only to LTE FDD and LTE TDD.
Mobility Target Indicator

Indicates whether the GERAN frequency group can be a target frequency in QCI-specific mobility management.

MlbTargetInd(MlbTargetInd): The GERAN frequency group can be a target in QCI-specific MLB only if this option is selected. You are advised to select this option for the default bearer. Otherwise, MLB may not transfer UEs. This option applies only to LTE FDD and LTE TDD.
