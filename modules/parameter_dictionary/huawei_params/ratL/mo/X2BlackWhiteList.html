X2BlackWhiteList

+-NE
  +-eNodeBFunction
    +-X2BlackWhiteList

Description

An X2BlackWhiteList MO consists of the parameters for adding a neighboring eNodeB to the X2 blacklist or whitelist. The blacklist or whitelist prohibits or allows configuration of X2 interfaces between the local eNodeB and neighboring eNodeBs, respectively.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD X2BLACKWHITELIST

Use this command to add a neighboring eNodeB to the X2 blacklist or whitelist. If a neighboring eNodeB is added to the X2 blacklist, an X2 interface between the local eNodeB and this neighboring eNodeB is abnormal and the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up. If a neighboring eNodeB is added to the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed.
LST X2BLACKWHITELIST

Use this command to list the configuration of the X2 blacklist or whitelist. If a neighboring eNodeB is in the X2 blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up and the X2 interface manually set up between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is in the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed.
RMV X2BLACKWHITELIST

Use this command to remove a neighboring eNodeB from the X2 blacklist or whitelist. If a neighboring eNodeB is in the X2 blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up and the X2 interface between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is in the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile country code

Indicates the mobile country code of the neighboring eNodeB to be added to the list. The value of this parameter is a string of three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code of the neighboring eNodeB to be added to the list. The value of this parameter is a string of two or three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.
eNodeB ID

Indicates the ID of the neighboring eNodeB to be added to the list. This parameter applies only to LTE FDD and LTE TDD.
X2 Black or White List Type

Indicates whether the X2 list is a blacklist or whitelist. If a neighboring eNodeB is added to the X2 blacklist, an X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up or the X2 interface set up between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is added to the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed. This parameter applies only to LTE FDD and LTE TDD.
