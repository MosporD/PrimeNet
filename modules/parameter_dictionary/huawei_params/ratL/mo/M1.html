M1

+-NE
  +-eNodeBFunction
    +-M1

Description

An M1 MO consists of user-plane parameters related to the M1 interface between the eNodeB and a multi-cell/multicast coordination entity (MCE).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the S1 MO:
    • M1EpGroupId in a M1 MO must be different from CpEpGroupId in any S1 MO.
    • M1EpGroupId in a M1 MO must be different from UpEpGroupId in any S1 MO.
  • Relation with the X2 MO:
    • M1EpGroupId in a M1 MO must be different from UpEpGroupId in any X2 MO.
    • M1EpGroupId in a M1 MO must be different from CpEpGroupId in any X2 MO.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by M1EpGroupId in a M1 MO must already exist.
    • The EPGROUP MO referenced by M1EpGroupId in an M1 MO must already exist, and the EPGROUP MO must contain at least one USERPLANEHOST MO.
    • The EPGROUP MO referenced by M1EpGroupId in a M1 MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by M1EpGroupId in a M1 MO must have been configured, and only six USERPLANEHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
  • Relation with the eX2 MO:
    • M1EpGroupId in the M1 MO must be different from CpEpGroupId in any eX2 MO.
    • M1EpGroupId in the M1 MO must be different from UpEpGroupId in any eX2 MO.
  • Relation with the SO MO:
    • M1EpGroupId in a M1 MO must be different from CpEpGroupId in any SO MO.
    • M1EpGroupId in a M1 MO must be different from UpEpGroupId in any SO MO.
  • Relation with the SCTPHOST MO:
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, M1EpGroupId in an M1 MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
  • Relation with the XW MO:
    • CpEpGroupId in an XW MO must be different from M1EpGroupId in any M1 MO.
    • UpEpGroupId in an XW MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • In the EPGROUP MO referenced by the M1EpGroupId parameter in an M1 MO, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to ENABLE.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
M1 ID

Indicates the M1 object ID. This parameter applies only to LTE FDD and LTE TDD.
M1 Network Type

Indicates the type of network served by the M1 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.
M1 End Point Group ID

Indicates the ID of the endpoint group used by the M1 MO. This parameter applies only to LTE FDD and LTE TDD.
User Label

Indicates the descriptions of the M1 MO. This parameter applies only to LTE FDD and LTE TDD.
