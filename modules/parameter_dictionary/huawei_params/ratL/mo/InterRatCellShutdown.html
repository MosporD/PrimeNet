InterRatCellShutdown

+-NE
  +-eNodeBFunction
    +-Cell
      +-InterRatCellShutdown

Description

The InterRatCellShutdown MO consists of the parameters related to inter-RAT cell shutdown. In UMTS+LTE networking, if the E-UTRAN cell and the co-coverage neighboring UTRAN cell are lightly loaded, the eNodeB hands over or redirects UEs in the E-UTRAN cell to the neighboring UTRAN cell, and then shuts down the carrier of the E-UTRAN cell to save energy after all UEs are transferred to the neighboring UTRAN cell. In GSM+LTE networking, if the E-UTRAN cell and the co-coverage neighboring GERAN cell are lightly loaded and there is no UE in RRC_CONNECTED mode in the E-UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell to save energy.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and CellRbReserve MOs:
    • When the RbRsvMode parameter in a CellRbReserve MO is set to NB_DEPLOYMENT(NB_DEPLOYMENT), and the CellActiveState in the Cell MO associated with the CellRbReserve MO is set to CELL_ACTIVE, the ForceShutdownSwitch parameter in the InterRatCellShutdown MO must be set to OFF(Off) for the cell.
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to TRUE, ForceShutdownSwitch in the InterRatCellShutdown must be set OFF.
  • Relation with the Cell and SpectrumCloud MOs:
    • When the FddTddInd in the Cell is set to CELL_FDD, and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, ForceShutdownSwitch in the InterRatCellShutdown must be set OFF.
  • Relation with the SectorSplitCell, Cell, and SectorSplitGroup MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD, the cell specified by this Cell MO is added in a SectorSplitCell MO under a SectorSplitGroup MO, and the BeamDeploymentMode parameter in this SectorSplitGroup MO is set to MODE_3, then the ForceShutdownSwitch parameter in the InterRatCellShutdown MO must be set to OFF.

Related MML Commands

Function
LST INTERRATCELLSHUTDOWN

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Inter-RAT cell shutdown switch

Indicates whether to enable inter-RAT joint shutdown. This parameter applies only to LTE FDD.
Start time

Indicates the start time of inter-RAT cell shutdown. If the switch for inter-RAT cell shutdown is turned on, inter-RAT cell shutdown can be performed during the period specified by the start time and stop time of inter-RAT cell shutdown. This parameter applies only to LTE FDD and LTE TDD.
Stop time

Indicates the stop time of inter-RAT cell shutdown. If the stop time is earlier than or the same as the start time, the stop time is assumed to be the time of the next day. If the switch for inter-RAT cell shutdown is turned on, inter-RAT cell shutdown can be performed during the period specified by the start time and stop time of inter-RAT cell shutdown. This parameter applies only to LTE FDD and LTE TDD.
UE number threshold

Indicates the UE number threshold for the E-UTRAN cell to enter the inter-RAT co-coverage cell shutdown.

In inter-RAT cell shutdown, the eNodeB automatically hands over or redirects the UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: (1) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITHOUT_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration and uplink and downlink resource block (RB) usages in the E-UTRAN cell are met, and the number of UEs served by the E-UTRAN cell is less than or equal to this parameter value.

(2) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, uplink and downlink RB usages in the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell, and load status of the neighboring UTRAN cell are met, and the number of UEs served by the E-UTRAN cell is less than or equal to this parameter value. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Downlink PRB threshold

In inter-RAT cell shutdown, the eNodeB automatically hands over or redirects the UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: (1) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITHOUT_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration and the number of UEs served by the E-UTRAN cell are met, and uplink and downlink resource block (RB) usages in the E-UTRAN cell are less than or equal to the UlPrbThd and DlPrbThd parameter values, respectively.

(2) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, the number of UEs served by the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell, and load status of the neighboring UTRAN cell are met, and uplink and downlink resource block (RB) usages in the E-UTRAN cell are less than or equal to the UlPrbThd and DlPrbThd parameter values, respectively. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Uplink PRB threshold

Indicates the uplink resource block (RB) usage threshold for the E-UTRAN cell to enter inter-RAT co-coverage cell shutdown mode.

In inter-RAT cell shutdown, the eNodeB automatically hands over or redirects the UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: (1) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITHOUT_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration and the number of UEs served by the E-UTRAN cell are met, and uplink and downlink resource block (RB) usages in the E-UTRAN cell are less than or equal to the UlPrbThd and DlPrbThd parameter values, respectively.

(2) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, the number of UEs served by the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell, and load status of the neighboring UTRAN cell are met, and uplink and downlink resource block (RB) usages in the E-UTRAN cell are less than or equal to the UlPrbThd and DlPrbThd parameter values, respectively. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Shut Down Type

Indicates the type of the inter-RAT co-coverage cell shutdown.

If this parameter is set to BY_UTRAN_WITHOUT_LOAD, the eNodeB does not obtain the load status of the co-coverage neighboring UTRAN cell, and shuts down the carrier of the E-UTRAN cell based on only the load status of the E-UTRAN cell.

If this parameter is set to BY_UTRAN_WITH_LOAD, the eNodeB obtains the load status of the co-coverage neighboring UTRAN cell, and shuts down the carrier of the E-UTRAN cell based on the load status of both the E-UTRAN cell and the neighboring UTRAN cell.

If this parameter is set to BY_GERAN_WITH_LOAD, the eNodeB obtains the load status of the co-coverage neighboring GERAN cell, and shuts down the carrier of the E-UTRAN cell based on the load status of both the E-UTRAN cell and the neighboring GERAN cell.

If this parameter is set to BY_UTRAN_AND_GERAN_WITH_LOAD, the eNodeB obtains the load status of co-coverage neighboring UTRAN and GERAN cells, and shuts down the carrier of the E-UTRAN cell based on the load status of the E-UTRAN cell, neighboring UTRAN cell, and neighboring GERAN cell. This parameter applies only to LTE FDD and LTE TDD.
High Priority ARP Threshold

Indicates the allocation/retention priority (ARP) threshold for high-priority services. If the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the eNodeB does not shut down the carrier of the E-UTRAN cell when the cell has a service whose ARP is lower than or equal to this parameter value. This parameter applies only to LTE FDD and LTE TDD.
UTRAN Cell Downlink Load Threshold

Indicates the downlink load threshold of a co-coverage neighboring UTRAN cell for the E-UTRAN cell to enter inter-RAT co-coverage cell shutdown mode.

In inter-RAT cell shutdown, the eNodeB hands over or redirects UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, the number of UEs served by the E-UTRAN cell, uplink and downlink RB usages in the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell are met, and uplink and downlink load of the neighboring UTRAN cell are less than values of UtranCellUlLoadThd and UtranCellDlLoadThd, respectively. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
UTRAN Cell Downlink Load Offset

Indicates the downlink load offset of a co-coverage neighboring UTRAN cell for enabling the carrier of the E-UTRAN cell that has been shut down.

A shutdown E-UTRAN cell is enabled when the following conditions are met: (1) The ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD. (2) The load of a co-coverage neighboring UTRAN cell is larger than or equal to the sum of this parameter value and the UtranCellDlLoadThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
UTRAN Cell Uplink Load Threshold

Indicates the uplink load threshold of a co-coverage neighboring UTRAN cell for the E-UTRAN cell to enter inter-RAT co-coverage cell shutdown mode.

In inter-RAT cell shutdown, the eNodeB hands over or redirects UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, the number of UEs served by the E-UTRAN cell, uplink and downlink RB usages in the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell are met, and uplink and downlink load of the neighboring UTRAN cell are less than values of UtranCellUlLoadThd and UtranCellDlLoadThd, respectively. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
UTRAN Cell Uplink Load Offset

Indicates the uplink load offset of a co-coverage neighboring UTRAN cell for enabling the carrier of the E-UTRAN cell that has been shut down.

A shutdown E-UTRAN cell is enabled when the following conditions are met: (1) The ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD. (2) The load of a co-coverage neighboring UTRAN cell is larger than or equal to the sum of this parameter value and the UtranCellUlLoadThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
GERAN Cell Load Threshold

Indicates the load threshold of a co-coverage neighboring GERAN cell for the E-UTRAN cell to enter inter-RAT co-coverage cell shutdown mode.

In inter-RAT cell shutdown, the eNodeB shuts down the carrier of the E-UTRAN cell when related conditions are met: The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_GERAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration and no UE served by the E-UTRAN cell are met, and the load of a co-coverage neighboring GERAN cell is less than this parameter value. This parameter applies only to LTE FDD and LTE TDD.
GERAN Cell Load Offset

Indicates the load offset of a co-coverage neighboring GERAN cell for enabling the carrier of the E-UTRAN cell that has been shut down.

A shutdown E-UTRAN cell is enabled when the following conditions are met: (1) The ShutDownType parameter is set to BY_GERAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD. (2) The load of a co-coverage neighboring GERAN cell is larger than or equal to the sum of this parameter value and the GeranCellLoadThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
