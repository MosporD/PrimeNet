CoProcRes

+-NE
  +-eNodeBFunction
    +-CoProcRes

Description

The CoProcRes MO consists of the parameters used to configure coordinated processing resources. This MO applies only to LTE TDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the BASEBANDEQM and BBP MOs:
    • One value of CoProcResId in the CoProcRes MO only corresponds to one value of BaseBandEqmId in the CoProcRes MO, and the BASEBANDEQM MO corresponds to only one BBP MO.
    • TYPE in an BBP MO corresponding to BaseBandEqmId in the CoProcRes MO cannot be set to LBBP.
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in a CoProcRes MO is selected, the WM parameter in the BBP MO corresponding to the BaseBandEqmId parameter in this CoProcRes MO cannot be set to SPEC_MODE1.
  • Relation with the DMIMOCluster MO:
    • The CoProcRes MO corresponding to the value of CoProcResId in the DMIMOCluster MO must exist.
  • Relation with the CoProcRes MO:
    • The value of CoProcResId in an CoProcRes MO corresponds to a maximum of one value of BaseBandEqmId in an CoProcRes MO.
  • Relation with the eUCellSectorEqm, EuSectorEqmGroup, EuCellPriBBEqm, SfnAuxResBind, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected and the BASEBAND_PROCESSING option of this parameter is deselected, the BaseBandEqmId parameter in the CoProcRes MO must not equal the BaseBandEqmId parameter in the eUCellSectorEqm MO, the BaseBandEqmId parameter in the EuSectorEqmGroup MO, the PriBaseBandEqmId parameter in the EuCellPriBBEqm MO, the BaseBandEqmId parameter in the SfnAuxResBind MO, the BasebandEqmId parameter in the EuPrbSectorEqm MO, and the BasebandEqmId parameter in the EuPrbSectorEqmGroup MO.
  • Relation with the CspcAlgoPara MO:
    • If the CspcAlgoSwitch parameter in the CspcAlgoPara MO is set to ON(On), there must be at least one CoProcRes MO in which the CLUSTER_MANAGEMENT option of the WorkMode parameter is selected.
  • Relation with the BBP MO:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected and the BASEBAND_PROCESSING option of this parameter is deselected, the TYPE parameter in the BBP MO associated with the BaseBandEqmId parameter in the CoProcRes MO must not be set to LBBP, and the BBWS parameter in the BBP MO must be set to LTE_FDD or LTE_TDD.
    • If both the COORDINATING_PROCESSING and BASEBAND_PROCESSING options of the WorkMode parameter in the CoProcRes MO are selected, in the BBP MOs that specify the baseband processing units corresponding to the baseband processing equipment specified by the BaseBandEqmId parameter in the CoProcRes MO, the TYPE parameter must be set to UBBP, and the BBWS must be set to LTE_TDD.
    • If the BBWS parameter in the BBP MO specified by the BaseBandEqmId parameter in the CoProcRes MO is set to LTE_FDD, the BundlingClusterType parameter in the CoProcRes MO must be set to ADAPTIVE or CSPC.
    • If the BASEBAND_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected, the TYPE parameter in the BBP MO configured for the BBP board specified by the BaseBandEqmId parameter in the CoProcRes MO must not be set to LCOP.
  • Relation with the EuCoSchDLCoMPCfg MO:
    • If the InterEnbDlCompSwitch parameter in the EuCoSchDLCoMPCfg MO is set to ON(On), there must be at least one CoProcRes MO in which both the CLUSTER_MANAGEMENT and COORDINATING_PROCESSING options of the WorkMode parameter are selected.
  • Relation with the EuUlCoSchCfg MO:
    • If the UlInterEnbCamcSw parameter in the EuUlCoSchCfg MO is set to ON(On), there must be at least one CoProcRes MO in which both the CLUSTER_MANAGEMENT and COORDINATING_PROCESSING options of the WorkMode parameter are selected and the BASEBAND_PROCESSING option is deselected.
  • Relation with the BbpCollaborationGrp MO:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in a CoProcRes MO is selected, the BaseBandEqmId parameter in this CoProcRes MO must not equal the CoBaseBandEqmId parameter in the BbpCollaborationGrp MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Coordinate Process Resource ID

Indicates a co-processing resource index. This parameter applies only to LTE FDD and LTE TDD.
BaseBand Equipment ID

Indicates the ID of the baseband equipment providing co-processing resources. When this parameter is set to 255, no baseband equipment is specified. In this scenario, the eNodeB selects baseband processing units (BBPs) for providing co-processing resources among all BBPs in the eNodeB. When this parameter is set to a value other than 255, the eNodeB selects BBPs contained in the specified baseband equipment for providing co-processing resources. This parameter applies only to LTE FDD and LTE TDD.
Bundling Cluster Type

Indicates the type of the cluster bound to co-processing resources. If this parameter is set to ADAPTIVE, no cluster type is specified and the eNodeB adaptively specifies a cluster type based on the coordination processing requirements of coordination features. This parameter applies only to LTE FDD and LTE TDD.
Work Mode

Indicates the working mode of co-processing resources. This parameter includes the following options:

BASEBAND_PROCESSING: Indicates that the baseband equipment performs general baseband processing.

COORDINATING_PROCESSING: Indicates that the baseband equipment performs coordination processing.

CLUSTER_MANAGEMENT: Indicates that the baseband equipment performs cluster management. Only one piece of baseband equipment can be configured in an eNodeB for cluster management.

This option applies only to LTE FDD and LTE TDD.
