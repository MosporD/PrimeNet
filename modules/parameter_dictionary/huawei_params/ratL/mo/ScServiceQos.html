ScServiceQos

+-NE
  +-eNodeBFunction
    +-ScServiceQos

Description

The ScServiceQoS consists of parameters used for video optimization based on SC identification results.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SCSERVICEQOS

Use this command to add SC-based service QoS.
LST SCSERVICEQOS

Use this command to list SC-based service QoS.
MOD SCSERVICEQOS

Use this command to modify SC-based service QoS.
RMV SCSERVICEQOS

Use this command to remove SC-based service QoS.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Sc Qos ID

Indicates a QoS ID. An ID is allocated to each service (video) to be optimized. The value range is from 0 to 49. This parameter applies only to LTE FDD and LTE TDD.
Application Dns

Indicates the domain name of the to-be-identified application or website. This parameter must be set only if the AppIdentType parameter is set to DNS. "NULL" is an invalid value and cannot be entered. This parameter applies only to LTE FDD and LTE TDD.
Downlink Service Grant Bit Rate

Indicates the guaranteed bit rate (GBR) for downlink services. This parameter applies only to LTE FDD and LTE TDD.
Application Identification Type

Indicates the application identification type. If the AppIdentType parameter is set to DNS, the AppDns parameter must be set. If the AppIdentType parameter is set to IPv4, the AppIpv4 parameter must be set. If the AppIdentType parameter is set to IPv6, the AppIpv6 parameter must be set. Currently, IPv6 is not supported. This parameter applies only to LTE FDD and LTE TDD.
Application IPv4

Indicates the IPv4 address of a service, which is used for service identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv4. This parameter applies only to LTE FDD and LTE TDD.
Application IPv6

Indicates the IPv6 address of a service, which is used for service identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv6. This parameter applies only to LTE FDD and LTE TDD.
