QoEHoCommonCfg

+-NE
  +-eNodeBFunction
    +-QoEHoCommonCfg

Description

The QoEHoCommonCfg MO consists of parameters related to configurations of QoE-based handover algorithms.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST QOEHOCOMMONCFG

Use this command to list common parameters related to QoE-based handovers.
MOD QOEHOCOMMONCFG

Use this command to modify common parameters related to QoE-based handovers.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
QoE-Based Handover Stat

Indicates the value N in the P/N rule for QoE-based handover decision. If the throughput is unsatisfactory for P consecutive times during the measurement period N, QoE-based handover is triggered. This parameter applies only to LTE FDD and LTE TDD.
QoE-Based Handover Last

Indicates the value P in the P/N rule for QoE-based handover decision. If the throughput is unsatisfactory for P consecutive times during the measurement period N, QoE-based handover is triggered. This parameter applies only to LTE FDD and LTE TDD.
