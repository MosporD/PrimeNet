XW

+-NE
  +-eNodeBFunction
    +-XW

Description

The XW MO consists of parameters related to the transport resources used by the Xw interface between the eNodeB and a WLAN termination. The configuration items include the control-plane and user-plane end point groups used by the XW MO and the CN operator that owns the XW MO.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by CpEpGroupId in an XW MO must be configured.
    • The EPGROUP MO referenced by CpEpGroupId in an XW MO must be configured, and this EPGROUP MO must reference an SCTPHOST MO.
    • The EPGROUP MO referenced by CpEpGroupId in an XW MO must be configured, and this EPGROUP MO can reference only one SCTPHOST MO whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by UpEpGroupId in an XW MO must be configured.
    • The EPGROUP MO referenced by UpEpGroupId in an XW MO must be configured, and this EPGROUP MO must reference a USERPLANEHOST MO.
    • The EPGROUP MO referenced by UpEpGroupId in an XW MO must be configured, and this EPGROUP MO can reference at most six USERPLANEHOST MOs whose IPVERSION is set to IPv4.
    • The EPGROUP MO referenced by CpEpGroupId in an XW MO must be configured, and this EPGROUP MO can reference only one SCTPHOST MO whose IPVERSION is set to IPv6.
    • The EPGROUP MO referenced by UpEpGroupId in an XW MO must be configured, and this EPGROUP MO can reference at most six USERPLANEHOST MOs whose IPVERSION is set to IPv6.
  • Relation with the M1 MO:
    • CpEpGroupId in an XW MO must be different from M1EpGroupId in any M1 MO.
    • UpEpGroupId in an XW MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the M2 MO:
    • CpEpGroupId in an XW MO must be different from M2EpGroupId in any M2 MO.
    • UpEpGroupId in an XW MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the S1 MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any S1 MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any S1 MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any S1 MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any S1 MO.
  • Relation with the SO MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any SO MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any SO MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any SO MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any SO MO.
  • Relation with the X2 MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any X2 MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any X2 MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any X2 MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any X2 MO.
  • Relation with the eX2 MO:
    • CpEpGroupId in an XW MO must be different from CpEpGroupId in any eX2 MO.
    • UpEpGroupId in an XW MO must be different from UpEpGroupId in any eX2 MO.
    • CpEpGroupId in an XW MO must be different from UpEpGroupId in any eX2 MO.
    • UpEpGroupId in an XW MO must be different from CpEpGroupId in any eX2 MO.
  • Relation with the SCTPHOST MO:
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, CpEpGroupId in the XW MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
    • If SIMPLEMODESWITCH in an SCTPHOST MO is set to S1SIMPLE_MODE_ON or X2SIMPLE_MODE_ON or EX2SIMPLE_MODE_ON, UpEpGroupId in the XW MO cannot be set to the same value as CPEPGROUPID1, UPEPGROUPID1, CPEPGROUPID2 or UPEPGROUPID2 in the SCTPHOST MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by the UpEpGroupId parameter in an XW MO must be configured. In addition, if the IPVERSION parameter in the USERPLANEHOST MO in the EPGROUP MO is set to IPv6, the MULTICASTLISTENERSW parameter must be set to DISABLE.
