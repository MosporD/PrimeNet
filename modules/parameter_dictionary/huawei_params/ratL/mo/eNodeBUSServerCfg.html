eNodeBUSServerCfg

+-NE
  +-eNodeBFunction
    +-eNodeBUSServerCfg

Description

The eNodeBUSServerCfg MO consists of the parameters related to servers that UEs running unlimited services can access.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ENODEBUSSERVERCFG

Use this command to add configurations to the server which allows UEs who gain access to then be determined as UEs running unlimited services.
LST ENODEBUSSERVERCFG

Use this command to list configurations of the server which allows UEs who gain access to then be determined as UEs running unlimited services.
MOD ENODEBUSSERVERCFG

Use this command to modify configurations of the server which allows UEs who gain access to then be determined as UEs running unlimited services.
RMV ENODEBUSSERVERCFG

Use this command to remove configurations from the server which allows UEs who gain access to then be determined as UEs running unlimited services.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
US Server Index

Indicates the index of the server which allows UEs who gain access to then be determined as UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.
US Server IP

Indicates the IP address of the server which allows UEs who gain access to then be determined as UEs running unlimited services. Server-IP-address-based unlimited-service-supported UE identification can be performed based on any of the following methods: (1) Server IP address; (2) Server IP address + server protocol type; (3) Server IP address + server protocol type + server port number. This parameter applies only to LTE FDD and LTE TDD.
US Server Port

Indicates whether to check the port number of the server which allows UEs who gain access to then be determined as UEs running unlimited services. The value 0 indicates that the port number of the server that a UE running unlimited services accesses does not need to be checked. This parameter applies only to LTE FDD and LTE TDD.
US Protocol Type

Indicates whether to check the protocol type of the server which allows UEs who gain access to then be determined as UEs running unlimited services. If this parameter is set to None, the eNodeB does not check the protocol type of downlink packets. If this parameter is set to UDP, the eNodeB checks whether the protocol type of downlink packets is UDP. If this parameter is set to TCP, the eNodeB checks whether the protocol type of downlink packets is TCP. This parameter applies only to LTE FDD and LTE TDD.
