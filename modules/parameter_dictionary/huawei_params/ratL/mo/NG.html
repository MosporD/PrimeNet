NG

+-NE
  +-eNodeBFunction
    +-NG

Description

An NG MO consists of parameters related to the transmission resources used by NG interfaces. The configuration items include the control-plane and user-plane endpoint groups used by the NG interfaces and the operator information.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the S1 MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any S1 MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any S1 MO.
  • Relation with the X2 MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any X2 MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any X2 MO.
  • Relation with the eX2 MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any eX2 MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any eX2 MO.
  • Relation with the M1 MO:
    • CpEpGroupId in an NG MO must be different from M1EpGroupId in any M1 MO.
    • UpEpGroupId in an NG MO must be different from M1EpGroupId in any M1 MO.
  • Relation with the M2 MO:
    • CpEpGroupId in an NG MO must be different from M2EpGroupId in any M2 MO.
    • UpEpGroupId in an NG MO must be different from M2EpGroupId in any M2 MO.
  • Relation with the SO MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any SO MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any SO MO.
  • Relation with the ECO MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any ECO MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any ECO MO.
  • Relation with the XW MO:
    • CpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any XW MO.
    • UpEpGroupId in an NG MO must be different from CpEpGroupId or UpEpGroupId in any XW MO.
  • Relation with the CnOperator MO:
    • CnOperatorId in an S1 MO must have been configured in the associated CnOperator MO.
  • Relation with the CnOpSharingGroup MO:
    • CnOpSharingGroupId in the NG MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
    • The operator corresponding to CnOperatorId in the NG MO must have been configured in the associated CnOpSharingGroup MO if CnOpSharingGroupId is not set to the invalid value 255.
  • Relation with the EPGROUP MO:
    • The EPGROUP MO referenced by CpEpGroupId in an NG MO must have been configured.
    • EPGROUP MO referenced by UpEpGroupId in an NG MO must have been configured.
  • Relation with the EPGROUP and SCTPHOST MOs:
    • The EPGROUP MO referenced by CpEpGroupId in an NG MO must have been configured. And the SCTPHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced by CpEpGroupId in an NG MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by CpEpGroupId in an NG MO must have been configured, and only one SCTPHOST MO with IPVERSION set to IPv6 can be configured for the EPGROUP.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The EPGROUP MO referenced by UpEpGroupId in an NG MO must have been configured. And the USERPLANEHOST MO referenced by the EPGROUP MO must have been configured.
    • The EPGROUP MO referenced by UpEpGroupId in an NG MO must have been configured, and at most six USERPLANEHOST MOs with IPVERSION set to IPv4 can be configured for the EPGROUP.
    • The EPGROUP MO referenced by UpEpGroupId in an NG MO must have been configured, and at most six USERPLANEHOST MOs with IPVERSION set to IPv4 can be configured for the EPGROUP.
  • Relation with the ENodeBSharingMode MO:
    • If ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, CnOpSharingGroupId in the NG MO must have been configured in the associated CnOpSharingGroup MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NG

Use this command to add an NG object.
DSP NG

Use this command to query the information about an NG interface that is managed by an NG object and for which the control mode is automatic mode. The DSP NG command output does not include user-plane information.
LST NG

Use this command to list configurations of an NG object, including the NG object ID, operator ID, endpoint group configuration flag, control-plane endpoint group ID, user-plane endpoint group ID, peer eNodeB release version, user-defined information, and carrier-sharing group ID.
MOD NG

Use this command to modify the configurations of an NG object.
RMV NG

Use this command to remove an NG object.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NG ID

Indicates the ID of the NG object. This parameter applies only to LTE FDD and LTE TDD.
CN Operator ID

Indicates the ID of the operator that owns the NG object. This parameter applies only to LTE FDD and LTE TDD.
Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the NG object. This parameter applies only to LTE FDD and LTE TDD.
User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the NG object. This parameter applies only to LTE FDD and LTE TDD.
End Point Group Config Flag

Indicates whether to configure the control-plane endpoint group or user-plane endpoint group. This parameter applies only to LTE FDD and LTE TDD.
CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group that owns the NG object. If the eNodeB works in hybrid RAN sharing mode, you can set this parameter to a value within the range of 0-5. These IDs are valid. If the eNodeB works in independent mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, this parameter does not take effect. In this case, you can set this parameter to its default value 255. The value 255 is invalid. This parameter applies only to LTE FDD and LTE TDD.
