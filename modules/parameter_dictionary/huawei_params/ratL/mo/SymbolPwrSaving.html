SymbolPwrSaving

+-NE
  +-eNodeBFunction
    +-Cell
      +-SymbolPwrSaving

Description

The SymbolPwrSaving MO consists of parameters related to symbol power saving for energy conservation and emission reduction.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and ENodeBAlgoSwitch MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_FDD for the cell, the SymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the DlIcicSwitch parameter in the ENodeBAlgoSwitch MO must be set to DlIcicSwitch_OFF_ENUM.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the DEEP_SYMBOL_SHUTDOWN_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO under this Cell MO is selected, the TddSymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the DEEP_SYMBOL_SHUTDOWN_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO under this Cell MO is selected, the SymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the MultiRatSymbolShutdownSw parameter in the SymbolPwrSaving MO corresponding to the LocalCellId parameter in the Cell MO is set to ON, the TddSymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the MultiRatSymbolShutdownSw parameter in the SymbolPwrSaving MO corresponding to the Cell is set to ON, the SymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
  • Relation with the ENodeBAlgoSwitch and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the TddSymbolShutdownSwitch option of the PowerSaveSwitch parameter in the ENodeBAlgoSwitch MO must be selected.
  • Relation with the Cell MO:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell, the NbCellFlag parameter in a Cell MO must be set to FALSE for the cell.
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the MultiCellShareMode parameter in the Cell MO must be set to NORMAL.
    • If the FddTddInd parameter a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 8T8R, and the SectorSplitCell MO associated with the Cell MO is configured, then the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO in the Cell MO MO must be set to 0.
    • If the DEEP_SYMBOL_SHUTDOWN_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO under a Cell MO is selected, the MultiRruCellMode parameter in this Cell MO cannot be set to MPRU_AGGREGATION.
    • If the LNR_BUNDLED_SCHEDULING_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO under a Cell MO is selected, the MultiRruCellMode parameter in this Cell MO cannot be set to MPRU_AGGREGATION.
  • Relation with the CellAlgoSwitch and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO under a Cell MO is set to a value other than 0, the MultiRruCellFlag parameter in this Cell MO is set to BOOLEAN_TRUE, and the MultiRruCellMode parameter in this Cell MO is set to SFN or MPRU_AGGREGATION, then the SfnDlSchSwitch parameter in the CellAlgoSwitch MO under this Cell MO must be set to JOINT.
  • Relation with the CellAlgoSwitch MO:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the DL_TIME_DIM_EXT_SCH_SWITCH option of the DlSchExtSwitch parameter in the CellAlgoSwitch MO must be deselected for the cell.
  • Relation with the SectorSplitCell and Cell MOs:
    • The TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO must be set to 0 for a cell if the following conditions are met for the cell: 1. The CellActiveState parameter in the Cell is set to CELL_ACTIVE. 2. The CellBeamMode parameter in the eUCellSectorEqm MO in the associated Cell MO is set to MASSIVE_MIMO_Ph2. 3. The number of SectorSplitCell MO instances in a SectorSplitGroup MO to which the Cell MO belongs is greater than 1.
  • Relation with the CspcAlgoPara and Cell MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_FDD for the same cell, the CspcAlgoSwitch parameter in the CspcAlgoPara MO must be set to OFF.
  • Relation with the CspcAlgoPara, Cell, and CellCspcPara MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the same cell, then the TddCspcMacroMicroSwitch option of the TddCspcAlgoSwitch parameter in the CspcAlgoPara MO must be deselected and the CellCspcSwitch parameter in the CellCspcPara MO must be set to OFF for the cell.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the DmimoJTSwitch and InterCellDmimoJTSwitch options of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO must be deselected for the cell.
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_FDD for the cell, the GLPwrShare parameter in the CellAlgoSwitch MO must be set to OFF for the same cell.
  • Relation with the Cell and CellDlschAlgo MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the MULTI_CARRIER_COSCH_SW option of the MultiCarrierCoSchAlgoSw parameter in the CellDlschAlgo MO must be deselected for the cell.
  • Relation with the CellSimuLoad MO:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell, the number of CellSimuLoad MO instances in the same Cell must be 0
  • Relation with the Cell and CellDynPowerSharing MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_FDD for the same cell, the UMTS_LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO must be deselected for the cell.
  • Relation with the Cell and CellCspcPara MOs:
    • If the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO is not set to 0 for a cell and the FddTddInd parameter in a Cell MO is set to CELL_TDD for the cell, the CelleCspcSwitch parameter in the CellCspcPara MO must be set to OFF for the cell.
  • Relation with the Cell and SectorSplitCell MOs:
    • If the FddTddInd parameter a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R, and the SectorSplitCell MO associated with the Cell MO is configured, then the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO in the Cell MO MO must be set to 0.
  • Relation with the Cell and MDU MOs:
    • If the value of the CellActiveState parameter in the Cell MO is CELL_ACTIVE and the TYPE parameter in the MDU MO is set to MDUC, the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO cannot be set to a value greater than 0.
  • Relation with the CellEmtcAlgo MO:
    • If both the EMTC_SWITCH and EMTC_ONLY_CELL_SWITCH options of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO for a cell are selected, the TrigBndlSchDlAvgPrbThld parameter in the SymbolPwrSaving MO for this cell cannot be set to a value greater than 0.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB.
Stop Bundling DL TTI-Level PRB Thld

Indicates the downlink TTI-level PRB usage threshold used to determine whether to continue bundled scheduling in a TTI. If the PRB usage in the current TTI is higher than this threshold, the eNodeB stops bundled scheduling in this TTI. This parameter applies only to LTE FDD and LTE TDD.
Trig Bundled Scheduling DL Avg PRB Thld

Indicates the average downlink PRB usage threshold for triggering bundled scheduling. When the average PRB usage of a cell is less than this threshold, bundled scheduling takes effect in the cell. When the average PRB usage of a cell is greater than or equal to the sum of this threshold and the PRB usage offset, bundled scheduling stops taking effect. If this parameter is set to 0, bundled scheduling is disabled. This parameter applies only to LTE FDD and LTE TDD.
Multi-RAT Symbol Shutdown Switch

Indicates whether to enable the functions related to multi-RAT symbol power saving in the cell. If this parameter is set to ON, multi-RAT symbol power saving is enabled. If this parameter is set to OFF, multi-RAT symbol power saving is disabled.
Symbol Shutdown Enhanced Switch

Indicates whether to enable enhanced symbol power saving functions in the cell.

LNR_BUNDLED_SCHEDULING_SW: Indicates whether to enable LTE and NR bundled scheduling in multi-RAT symbol power saving. This option applies only to LTE FDD and LTE TDD.

DEEP_SYMBOL_SHUTDOWN_SW: Indicates whether to enable deep symbol power saving for RF modules.
MBSFN Shutdown Start Time

Indicates the start time of MBSFN enhanced symbol shutdown. This parameter applies only to LTE FDD and LTE TDD.
MBSFN Shutdown Stop Time

Indicates the stop time of MBSFN enhanced symbol shutdown. This parameter applies only to LTE FDD and LTE TDD.
