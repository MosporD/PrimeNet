EuCellPriBBEqm

+-NE
  +-eNodeBFunction
    +-Cell
      +-EuCellPriBBEqm

Description

An EuCellPriBBEqm MO includes the parameters used to specify the primary baseband equipment for a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and BASEBANDEQM MOs:
    • If CellActiveState in the Cell MO is set to CELL_ACTIVE, the BASEBANDEQM MO corresponding to PriBaseBandEqmId in the EuCellPriBBEqm MO has been configured.
  • Relation with the Cell, BASEBANDEQM, BBP, and MDU MOs:
    • In the Cell MO, if CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_FDD, the baseband processing units corresponding to the PriBaseBandEqmId parameters correlated to the EuCellPriBBEqm in the BASEBANDEQM MO must be LBBPs and the related WM parameters must be set to FDD, FDD_ATG, FDD_NBIOT, FDD_NBIOT_ENHANCE or FDD_NBIOT_CUSTOM, or must be UBBPs and the related BBWS parameters must be set to LTE_FDD.
    • In the Cell MO, if CellActiveState is set to CELL_ACTIVE and FddTddInd is set to CELL_TDD, the baseband processing units corresponding to the PriBaseBandEqmId parameters correlated to the EuCellPriBBEqm in the BASEBANDEQM MO must be LBBPs and the related WM parameters cannot be set to FDD, FDD_ATG, FDD_NBIOT_ENHANCE or FDD_NBIOT_CUSTOM, or must be UBBPs and the related BBWS parameters cannot be set to LTE_FDD.
  • Relation with the Cell, BASEBANDEQM, and BBP MOs:
    • In the Cell MO, if CellActiveState is set to CELL_ACTIVE, FddTddInd is set to CELL_FDD, and NbCellFlag is set to TRUE, if all the baseband processing units corresponding to the PriBaseBandEqmId parameters correlated to the EuCellPriBBEqm in the BASEBANDEQM MO are UBBPs, then the related BBWS parameters must be set to NBIOT, or the EuCellPriBBEqm in the BASEBANDEQM MO are LBBPs and the related WM parameters must be set to NBIOT, FDD_NBIOT, FDD_NBIOT_ENHANCE or FDD_NBIOT_CUSTOM.
  • Relation with the eUCellSectorEqm, CoProcRes, EuSectorEqmGroup, SfnAuxResBind, EuPrbSectorEqm, and EuPrbSectorEqmGroup MOs:
    • If the COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO is selected and the BASEBAND_PROCESSING option of this parameter is deselected, the BaseBandEqmId parameter in the CoProcRes MO must not equal the BaseBandEqmId parameter in the eUCellSectorEqm MO, the BaseBandEqmId parameter in the EuSectorEqmGroup MO, the PriBaseBandEqmId parameter in the EuCellPriBBEqm MO, the BaseBandEqmId parameter in the SfnAuxResBind MO, the BasebandEqmId parameter in the EuPrbSectorEqm MO, and the BasebandEqmId parameter in the EuPrbSectorEqmGroup MO.

Function

Use this command to modify the primary baseband equipment configuration of a cell.

Use this command to remove the primary baseband equipment configuration from a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB.
Primary Baseband Equipment ID

Indicates the ID of the primary baseband equipment that serves a cell.

If the primary baseband equipment is not configured for a cell, the eNodeB selects baseband processing units for the cell among all baseband processing units that have not been bound to cells.

If this parameter is configured, the cell uses specified primary baseband equipment. In this case, the cell can use only the baseband processing units included in the primary baseband equipment.
