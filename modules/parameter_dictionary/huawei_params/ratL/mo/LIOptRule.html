LIOptRule

+-NE
  +-eNodeBFunction
    +-LIOptRule

Description

An LIOptRule MO consists of parameters specifying the intelligent optimization rules. The intelligent optimization rules specify items, such as the specific parameter adjustment measure and evaluation period. An intelligent optimization rule can be activated or deactivated.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ACT LIOPTRULE

Use this command to activate an intelligent optimization rule.
DEA LIOPTRULE

Use this command to deactivate an intelligent optimization rule. Condition evaluation and parameter adjustments related to a deactivated intelligent optimization rule cannot be implemented on the eNodeB.
DSP LIOPTRULE

Use this command to query the status of intelligent optimization rules. If the value of Rule ID is displayed as 65535, the intelligent optimization rule is an eNodeB-level rule.
LST LIOPTRULE

Use this command to list settings of parameters related to intelligent optimization rules.
MOD LIOPTRULE

Use this command to modify settings of parameters related to intelligent optimization rules.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rule ID

Indicates the ID of an intelligent optimization rule. This parameter applies only to LTE FDD and LTE TDD.
Action Type

Indicates the type of parameter adjustment when the trigger conditions in an intelligent optimization rule are met. If this parameter is set to MODIFY, the intelligent optimization rule is used to modify parameters. If this parameter is set to RESUME, the intelligent optimization rule is used to restore parameters to the initial settings. This parameter applies only to LTE FDD and LTE TDD.
Relationship Type of Atom Rule

Indicates the type of relationships between atom rules under an intelligent optimization rule. If this parameter is set to AND, optimization actions corresponding to the intelligent optimization rule are triggered only when all atom rules under this intelligent optimization rule meet related requirements. If this parameter is set to OR, optimization actions corresponding to the intelligent optimization rule are triggered when any atom rule under this intelligent optimization rule meets related requirements. This parameter applies only to LTE FDD and LTE TDD.
Period

Indicates the evaluation period of an intelligent optimization rule. This parameter applies only to LTE FDD and LTE TDD.
Action

Indicates a parameter adjustment action corresponding to an intelligent optimization rule. Note: When a network is no longer heavily loaded, restore the parameter value to the pre-optimization GUI value. The corresponding value of ActionType is RESUME and the corresponding value of Action is NULL. This parameter applies only to LTE FDD and LTE TDD.
Intelligent Optimization Function ID

Indicates the ID of the intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.
Penalty Time

Indicates the penalty duration of intelligent optimization rules under an intelligent optimization function. If related conditions for an intelligent optimization rule under an intelligent optimization function are met and related adjustment measures are taken, the penalty duration starts. During the penalty duration, parameter adjustment cannot be triggered even if conditions for an intelligent optimization rule under this intelligent optimization function are met. If this parameter is set to 0, no penalty is imposed on intelligent optimization rules under an intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.
Adaptive RAT

Indicates the duplex mode to which an intelligent optimization rule applies. If this parameter is set to FDD, the intelligent optimization rule applies to FDD. If this parameter is set to TDD, the intelligent optimization rule applies to TDD. If this parameter is set to BOTH, the intelligent optimization rule applies to both FDD and TDD. This parameter applies only to LTE FDD and LTE TDD.
Active Status

Indicates whether an intelligent optimization rule is activated. If the parameter value is set to ACTIVATED, the intelligent optimization rule is activated. If the parameter value is set to DEACTIVATED, the intelligent optimization rule is deactivated and does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
Local Cell ID

Indicates the ID of the local cell with an intelligent optimization rule applied. This parameter can only be queried by running the DSP LIOPTRULE command. If the local cell ID is displayed as 65535 in the command output, this intelligent optimization rule takes effect on the eNodeB level. This parameter applies only to LTE FDD and LTE TDD.
Executive Status

Indicates the state of parameter adjustment corresponding to an intelligent optimization rule. This parameter can only be queried by running the DSP LIOPTRULE command. If this parameter value is UN-EXECUTED, parameter adjustment is not performed. If this parameter value is EXECUTING, parameter adjustment is being performed. If this parameter is EXECUTED, parameter adjustment has been performed. This parameter applies only to LTE FDD and LTE TDD.
