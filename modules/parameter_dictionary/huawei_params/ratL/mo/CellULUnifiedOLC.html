CellULUnifiedOLC

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellULUnifiedOLC

Description

The CellULUnifiedOLC MO consists of parameters related to UMTS and LTE unified overload control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CELLULUNIFIEDOLC

Use this command to list parameters related to UL unified overload control in cells.
MOD CELLULUNIFIEDOLC

Use this command to modify parameters related to UL unified overload control in cells.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
High RRC Reject Rate Thd for UL Uni-OLC

Indicates the threshold of the resource-insufficiency-induced RRC connection rejection rate, which is used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when both of the following conditions are met: (1) The resource-insufficiency-induced RRC connection rejection rate is greater than the RrcRejectRateHighThd parameter value; (2) The number of RRC connection setup requests is greater than the RrcReqNumHighThd parameter value. The actual threshold equals the percentage value of this parameter divided by 10. For example, the GUI value 10 indicates that the actual value is 1% (= 10 x 1%/10). This parameter applies only to LTE FDD and LTE TDD.
Low RRC Reject Rate Thd for UL Uni-OLC

Indicates the threshold of the resource-insufficiency-induced RRC connection rejection rate, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. The actual threshold equals the percentage value of this parameter divided by 10. For example, the GUI value 10 indicates that the actual value is 1% (= 10 x 1%/10). This parameter applies only to LTE FDD and LTE TDD.
High RRC Request Number Thd for UL Uni-OLC

Indicates the threshold of the number of RRC connection setup requests, which is used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when both of the following conditions are met: (1) The number of RRC connection setup requests is greater than the RrcReqNumHighThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is greater than the RrcRejectRateHighThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
Low RRC Request Number Thd for UL Uni-OLC

Indicates the threshold of the RRC connection setup request number, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
High UE Number Thd for UL Uni-OLC

Indicates the RRC_CONNECTED UE number threshold used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when the number of RRC_CONNECTED UEs is greater than this parameter value. This parameter applies only to LTE FDD and LTE TDD.
Low UE Number Thd for UL Uni-OLC

Indicates the threshold of the RRC_CONNECTED UE number, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. This parameter applies only to LTE FDD and LTE TDD.
