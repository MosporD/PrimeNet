GeranNfreqGroupArfcn

+-NE
  +-eNodeBFunction
    +-Cell
      +-GeranNfreqGroup
        +-GeranNfreqGroupArfcn

Description

A GeranNfreqGroupArfcn MO consists of the parameters related to an ARFCN in a neighboring GERAN carrier frequency group. It is used in measurement control for both inter-RAT handover to and cell reselection to GERAN. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GeranNfreqGroup
  • Relation with the Cell MO:
    • A maximum of 64 neighboring GERAN frequencies can be configured for each cell. Neighboring GERAN frequencies consist of those specified by GeranNfreqGroup MOs and GeranNfreqGroupArfcn MOs.
  • Relation with the GeranNfreqGroup MO:
    • A maximum of 31 GeranNfreqGroupArfcn MOs can be configured for each Geran Neighbour freq group MO.
    • In GeranNfreqGroup MOs of a cell, if BandIndicator values are the same, the value of StartingArfcn in a GeranNfreqGroup must be different from the value of GeranArfcn in a GeranNfreqGroupArfcn MO associated to BcchGroupId.
    • In GeranNfreqGroup MOs of a cell, if BandIndicator values are the same, the GeranArfcn values in GeranNfreqGroupArfcn MOs under GeranNfreqGroup MOs cannot be the same.
  • Relation with the GeranNcell, GeranExternalCell, and GeranNfreqGroup MOs:
    • GeranArfcn and BandIndicator in a GeranExternalCell MO corresponding to a GeranNcell MO must be the same as GeranArfcn in a GeranNfreqGroupArfcn MO and BandIndicator in the GeranNfreqGroup MO associated with the GeranNfreqGroupArfcn MO, respectively. Alternatively, GeranArfcn and BandIndicator in a GeranExternalCell MO corresponding to a GeranNcell MO must be the same as StartingArfcn and BandIndicator in a GeranNfreqGroup MO, respectively.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GERANNFREQGROUPARFCN

Use this command to add a GERAN ARFCN to a neighboring GERAN carrier frequency group.
LST GERANNFREQGROUPARFCN

Use this command to list the parameters related to the neighboring GERAN ARFCN.
RMV GERANNFREQGROUPARFCN

Use this command to remove one or more records of neighboring ARFCNs of the GERAN BCCHs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
BCCH group ID

Indicates the index of the BCCH carrier frequency group. It identifies a BCCH carrier frequency group. This parameter applies only to LTE FDD and LTE TDD.
GERAN ARFCN

Specifies the ARFCN of the GERAN BCCH. If the GERAN ARFCN value is not between 512 and 810, one ARFCN can only in one frequency band. For details about this parameter, see 3GPP TS 45.005. This parameter applies only to LTE FDD and LTE TDD.
