eNodeBUSParaCfg

+-NE
  +-eNodeBFunction
    +-eNodeBUSParaCfg

Description

The eNodeBUSParaCfg MO consists of parameters related to the eNodeB-level policies for UEs running unlimited services. The eNodeB-level policy configuration specifies the identification and assurance policies for such UEs.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CellAlgoExtSwitch and CellUSParaCfg MOs:
    • If the SpeedTestSwitch parameter in the CellAlgoExtSwitch MO is set to WBB_SPEED_TEST, the UsUeGuaranteeSwitch option of the UsAlgoSwitch parameter in the CellUSParaCfg MO must be deselected and the BigPackageIdentify parameter in the eNodeBUSParaCfg MO must be set to OFF.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the BigPackageIdentify parameter in the eNodeBUSParaCfg MO must be set to OFF.
  • Relation with the CellUSParaCfg MO:
    • If the UsBasedSpecificSpidIpAddress option of the UsStrategy parameter in the eNodeBUSParaCfg MO is selected, the ConsVolteFrameNum1stSpurt parameter in the CellUSParaCfg MO must be set to 0.
    • If the UsBasedSpecificSpidIpAddress option of the UsStrategy parameter in the eNodeBUSParaCfg MO is selected, the ConsVolteFrameNum2ndSpurt parameter in the CellUSParaCfg MO must be set to 0.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
US Ue Strategy Select

Indicates the policy based on which the eNodeB identifies UEs running unlimited services.

If the UsBasedSpecificSPID option is selected, the eNodeB identifies UEs running unlimited services based on the SPIDs specified by the operator using the UsUeSpid parameter in the UsUeSpidConfig MO. This option applies only to LTE FDD and LTE TDD.

If the UsBasedSpecificIPAdd option is selected, the eNodeB identifies UEs running unlimited services based on the IP address of the server dedicated to UEs running unlimited services. Operators need to set the parameters in the ServerConfig MO for this server. This option applies only to LTE FDD and LTE TDD.

If the UsBasedSpecificTraceID option is selected, the eNodeB identifies that UEs are running unlimited services if an end-to-end tracing task with a dedicated trace ID starts for the UEs.

If the UsBasedIMEISV option is selected, the eNodeB identifies UEs running unlimited services based on the IMEISVs. Operators need to configure parameters related to the IMEISV information for UEs running unlimited services. This option applies only to LTE TDD.

If the UsBasedSpecificSpidIpAddress option is selected, the eNodeB identifies UEs running unlimited services based on both the SPIDs and server IP address. Operators need to specify the SPIDs and server IP address of UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.
Configurate US SPID

Indicates the SPID for UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.
US Ue Inactive Timer

Indicates the length of the UE inactivity timer for UEs. If the eNodeB detects that such a UE has neither received nor sent data for a duration exceeding the value of this parameter, the eNodeB releases the RRC connection for the UE. If this parameter is set to 0, the UE inactivity timer is not used. If the parameter setting is changed, the change applies to UEs that newly access the network.
US IP Detect Interval

Indicates the packet interval at which the eNodeB parses the IP headers of the downlink packets for UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.
US Downlink scheduling priority factor

Indicates the weight factor used to calculate DL scheduling priorities for UEs running unlimited services. This parameter is used to provide preferential guarantee for UEs running unlimited services. If the parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weight factor. If this parameter is set to 1000, UEs running unlimited services have the highest priority. This parameter applies only to LTE FDD and LTE TDD.
US Large Packet UlSch Priority Factor

Indicates the weight factor used to calculate the connection priorities during UL scheduling for large-packet services of UEs running unlimited services. If the parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weight factor. If this parameter is set to 1000, UEs running unlimited services have the highest priority. This parameter applies only to LTE FDD and LTE TDD.
US Small Packet UlSch Priority Factor

Indicates the weight factor used to calculate the connection priorities during UL scheduling for small-packet services of UEs running unlimited services. If the parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weight factor. If this parameter is set to 1000, UEs running unlimited services have the highest priority. This parameter applies only to LTE FDD and LTE TDD.
US UE S-TMSI Keep Alive Timer

Indicates the length of the S-TMSI keep-alive timer for UEs running unlimited services. When the eNodeB detects such a UE based on the IP address of a dedicated server, the eNodeB starts the S-TMSI keep-alive timer for the UE. If the UE initiates an RRC connection setup procedure towards the eNodeB before the timer expires, the eNodeB treats the UE as an unlimited-service UE. If the UE initiates the procedure after the timer expires, the eNodeB treats the UE as a common UE. For details about S-TMSIs, see 3GPP TS 36.331. If this parameter is set to 0, the timer mechanism does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Big Package Identification

Indicates whether to use large-packet services as criterion for identifying UEs with unlimited services. If the volume of data to be transmitted for a service in the UE buffer exceeds a specified threshold, this service is a large-packet service. If this parameter is set to ON, a UE is identified based on the buffered data volume and the number of times the UE is scheduled. If certain conditions are met, the UE is identified as a UE running unlimited services. If this parameter is set to OFF, this identification criterion does not work. This parameter applies only to LTE FDD and LTE TDD.
UL DL US User Detect Period

Indicates the identification period of UEs running unlimited data services in the uplink and downlink. If this parameter is set to 0, the detection in the uplink and downlink is disabled. This parameter applies only to LTE FDD and LTE TDD.
US NB-IoT UE Status Response Timer

Indicates the length of the RLC-layer status report response timer for NB-IoT UEs running unlimited services (US NB-IoT UEs). If you need to change the parameter value, contact Huawei technical support. This parameter applies only to NB-IoT.
NB-IoT US UE Scheduling Priority Weight Factor

Indicates the weight factor of NB-IoT basic scheduling priorities for UEs running unlimited services. This parameter is used to preferentially guarantee services for UEs running unlimited services. This parameter applies only to NB-IoT.
US UE Exit Detection Times

Indicates the number of times it is detected that a UE running unlimited services (referred to as a US UE) exits a specific SPID and a specific IP address before the UE is finally determined to have exited the US state. This parameter takes effect only if the UsBasedSpecificSpidIpAddress option of the UsStrategy parameter is selected. This parameter applies only to LTE FDD and LTE TDD.
