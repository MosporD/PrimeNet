SimuloadPmiTemplate

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSimuLoad
        +-SimuloadPmiTemplate

Description

A SimuloadPmiTemplate MO consists of parameters related to a PMI template. If the SimuLoadTransMode parameter is set to TM4 or TM9, a SimuloadPmiTemplate MO must be configured for a CellSimuLoad MO to enable this CellSimuLoad MO to take effect.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CellSimuLoad
  • Relation with the Cell and CellSimuLoad MOs:
    • Consider that SimuLoadTransMode in a CellSimuLoad MO is set to TM9. If TxRxMode in the corresponding Cell MO is set to 2T2R, 2T4R, or 2T8R, CellSimuloadPmi in a SimuloadPmiTemplate MO under this CellSimuLoad MO must be set to a value in the range of 0 to 3.
    • If SimuLoadTransMode in a CellSimuLoad MO is set to TM4 and CrsPortNum in the related Cell MO is set to CRS_PORT_2, CellSimuloadPmi in associated SimuloadPmiTemplate MOs must be set to a value ranging from 0 to 3.
  • Relation with the SimuloadPmiTemplate MO:
    • The sum of values of CellSimuloadPmiCfgDuration in SimuloadPmiTemplate MOs cannot be greater than 2000 ms.
  • Relation with the CellSimuLoad MO:
    • If SimuLoadTransMode in a CellSimuLoad MO is set to TM4 or TM9, a maximum of 16 SimuloadPmiTemplate MOs can be configured under this CellSimuLoad MO.
    • If SimuLoadTransMode in a CellSimuLoad MO is not set to TM4 or TM9, no SimuloadPmiTemplate MOs can be configured under this CellSimuLoad MO.
  • Relation with the CellAlgoSwitch MO:
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, PmiType in related SimuloadPmiTemplate MOs must be set to Emimo.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected and CellSimuloadRank in a SimuloadPmiTemplate MO is set to RANK_2, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 must be set to 11 and 10, respectively.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected and CellSimuloadRank in a SimuloadPmiTemplate MO is set to RANK_2, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 must be set to 11 and 10, respectively.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected and CellSimuloadRank in a SimuloadPmiTemplate MO is set to RANK_2, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 must be set to 11 and 10, respectively.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, PmiType in related SimuloadPmiTemplate MOs must be set to Normal.
    • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, CellSimuloadRank in the related SimuloadPmiTemplate MO must be set to RANK_1 or RANK_2.
  • Relation with the Cell, CellAlgoSwitch, eUCellSectorEqm, PDSCHCfg, and CellAlgoExtSwitch MOs:
    • The SINGLE_CA_PWR_SHARE_SW_FOR_4T option of TxChnPowerCfgSw in the PDSCHCfg MO for a cell must be deselected if any of the following condition is met: TxRxMode in the Cell MO is set to a value other than 4T4R, FddTddInd in the Cell MO is set to CELL_TDD, CrsPortNum in the Cell MO is set to a value other than CRS_PORT_4, CellSimuloadPmi in the SimuloadPmiTemplate MO is set to 4, 5, 6, or 7, the 4TxTM9MuMimoSwitch, Virtual4T4Rswitch, or New4TcodebookSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, the Dl256QamAccessorySwitch option of Dl256QamAlgoSwitch in the CellAlgoSwitch MO is selected, or CellBeamMode in the eUCellSectorEqm MO is set to ADVANCED_BEAMFORMING, or Tm9FourLayerPairSwitch of WttxMuMimoSwitch in a CellAlgoExtSwitch MO is selected.
  • Relation with the CellDlpcPdsch, Cell, and eUCellSectorEqm MOs:
    • When FddTddInd in Cell is configured as CELL_TDD, or NbCellFlag in Cell is configured as TRUE, or CrsPortNum in Cell is not configured as CRS_PORT_4, or TxRxMode in Cell is not configured as 4T4R, or CellBeamMode in eUCellSectorEqm is not NORMAL, or SimuloadPmiTemplate in CellSimuloadPmi is configured as 4, 5, 6, or 7, RemainingPwrUseStrategy in CellDlpcPdsch must be configured as OFF.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SIMULOADPMITEMPLATE

Use this command to add a simuload PMI template in simulated load configurations with transmission mode 4 or 9. A maximum of 16 PMI templates can be added for a cell.
DSP SIMULOADPMITEMPLATE

Use this command to query information about simuload PMI templates.
LST SIMULOADPMITEMPLATE

Use this command to list settings of parameters related to simuload PMI templates in simulated load configurations with the transmission mode 4 or 9.
MOD SIMULOADPMITEMPLATE

Use this command to modify the settings of parameters related to simuload PMI templates in simulated load configurations with the transmission mode 4 or 9.
RMV SIMULOADPMITEMPLATE

Use this command to remove simuload PMI templates in simulated load configurations with the transmission modes 4 and 9. If only the LocalCellId parameter is specified during command execution, all PMI templates configured for the cell are removed. If parameters LocalCellId, CellSimuloadPmi, and CellSimuloadRank are specified during command execution, the PMI template specified by these parameters is removed.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Simuload PMI Template ID

Indicates the number of a PMI template used in interference simulation. This parameter applies only to FDD.
Cell Simuload PMI

Indicates the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. This parameter applies only to FDD.
Cell Simuload Rank

Indicates the rank for the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. This parameter applies only to FDD.
Cell Simuload PMI Config Duration

Indicates the duration of interference simulation using the PMI with the SimuLoadTransMode parameter set to TM4 or TM9. The total configured duration of interference simulation using the PMIs in all PMI templates configured for a cell is the PMI polling cycle. The configuration-dependent probability of scheduling a PMI is equal to the configured duration of interference simulation using this PMI divided by the PMI polling cycle. This parameter applies only to FDD.
Cell Simuload PMI Extend 0

Indicates the PMI for TM4 during virtual 4T4R feature load simulation. This parameter indicates the PMI for beam 0 (the left beam serving the virtual 4T4R cell) during load simulation. PMI values used for load simulation in a cell must be unique. This parameter applies only to LTE FDD and LTE TDD.
Cell Simuload PMI Extend 1

Indicates the PMI for TM4 during virtual 4T4R feature load simulation. This parameter indicates the PMI for beam 1 (the left beam serving the virtual 4T4R cell) during load simulation. PMI values used for load simulation in a cell must be unique. This parameter applies only to LTE FDD and LTE TDD.
PMI Type

Indicates the cell type for load simulation. If the cell is a normal cell, set this parameter to Normal. If the cell is an eMIMO cell, set this parameter to Virtual4T4R. This parameter applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
Cell Simuload PMI Period

Indicates the PMI polling cycle used in load simulation with the SimuLoadTransMode parameter is set to TM4 or TM9. This parameter applies only to FDD.
Cell Simuload PMI Schedule Duration

Indicates the scheduling duration for the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. The total configured duration of interference simulation using the PMIs in all PMI templates configured for a cell is the PMI polling cycle. The actual probability of scheduling a PMI is equal to the scheduling duration for this PMI divided by the PMI polling cycle. This parameter applies only to FDD.
