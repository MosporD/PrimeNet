CellQciPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellQciPara

Description

A CellQciPara MO consists of parameters related to a QoS class identifier (QCI) for a cell. The parameters include those related to DRX, SRI, and handovers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • For extended QCI sets of 10 to 64, 67 to 68, and 71 to 254, the sum of QCIs with QciAmbrLimitFlag in a CellQciPara MO under a Cell MO not set to NORMAL must be less than or equal to 5.
    • The FddTddInd parameter in the Cell MO must be set to CELL_TDD when the ADMISSION_FORBIDDEN option of the QciAlgoSwitch parameter in the CELLQCIPARA MO is selected.
    • A maximum of 75 CellQciPara MOs can be configured for each Cell MO.
    • CellQciPara MOs with the Qci parameters set to 1 to 9, 65, 66, 69, 70, 75 and 79 must have been configured.
  • Relation with the CellRacThd MO:
    • When the QCI is set to 1, 2, 3, or 4, the sum of the value of the HandoverAdmissionThreshold parameter in a CellQciPara MO for the corresponding QCI and the value of the NewIronServiceOffset parameter in the CellRacThd MO must be less than or equal to 100.
    • When the QCI is set to 1, 2, 3, or 4, the sum of the value of the CongestionThreshold parameter in a CellQciPara MO for the corresponding QCI and the value of the CongRelOffset parameter in the CellRacThd MO must be less than the value of the HandoverAdmissionThreshold parameter in a CellQciPara MO.
    • When the QCI is set to 3, the sum of the value of the CongestionThreshold parameter in a CellQciPara MO for this QCI and the value of the CongRelOffset parameter in the CellRacThd MO must be less than the value of the HandoverAdmissionThreshold parameter in a CellQciPara MO for QCI-75 services.
    • When the QCI is set to 75, the sum of the value of the HandoverAdmissionThreshold parameter in a CellQciPara MO for this QCI and the value of the NewIronServiceOffset parameter in the CellRacThd MO must be less than or equal to 100.
  • Relation with the CellRacThd and CellAlgoSwitch MOs:
    • When the McpttCongCtrlSwitch option of the McpttSwitch parameter in a CellAlgoSwitch MO is selected, the sum of the HandoverAdmissionThreshold parameter in the CellQciPara MO for QCI-65 services and the value of the NewIronServiceOffset parameter in the CellRacThd MO must be less than or equal to 100.
    • When the McpttCongCtrlSwitch option of the McpttSwitch parameter in a CellAlgoSwitch MO is selected, the sum of the HandoverAdmissionThreshold parameter in the CellQciPara MO for QCI-66 services and the value of the NewIronServiceOffset parameter in the CellRacThd MO must be less than or equal to 100.
    • When the McpttCongCtrlSwitch option of the McpttSwitch parameter in a CellAlgoSwitch MO is selected, the sum of the CongestionThreshold parameter in the CellQciPara MO for QCI-1 services and the value of the CongRelOffset parameter in the CellRacThd MO must be less than the value of the HandoverAdmissionThreshold parameter in the CellQciPara MO for QCI-66 services.
    • When the McpttCongCtrlSwitch option of the McpttSwitch parameter in a CellAlgoSwitch MO is selected, the sum of the CongestionThreshold parameter in the CellQciPara MO for QCI-65 services and the value of the CongRelOffset parameter in the CellRacThd MO must be less than the value of the HandoverAdmissionThreshold parameter in the CellQciPara MO for QCI-65 services.
  • Relation with the UeCooperationPara, CellWttxParaCfg, SpidCfg, and CellBf MOs:
    • The BfWeightOptDegreeFactor parameter in the CellBf MO must be set to 0 when none of the following conditions are met: The SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to SPID_BASED, the SpecifiedUserFlag parameter in a SpidCfg MO is set to SPECSERUSER; when the WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to QCI_BASED, the ServiceFlag parameter in a CellQciPara is set to WBB_Service. Otherwise, the value range of the BfWeightOptDegreeFactor parameter in the CellBf MO is 0 to 255.
  • Relation with the CellWttxParaCfg, SpidCfg, and CellBfMimoParaCfg MOs:
    • The TM9_DL_4LAYER_BOOST_SW option of the Tm9Dl4LayerMimoEnhSw parameter in the CellBfMimoParaCfg MO can be selected only if either of the following conditions is met:
    • 1. The WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to SPID_BASED, and the SpecifiedUserFlag parameter in the SpidCfg MO is set to SPECSERUSER for any SPID.
    • 2. The WbbOrMbbUserDefMode parameter in the CellWttxParaCfg MO is set to QCI_BASED, and the ServiceFlag parameter is set to WBB_SERVICE for any QCI used in the cell specified in the CellQciPara MO.
  • Relation with the DrxParaGroup MO:
    • When CatType is set to LTE, DrxParaGroupId in a CellQciPara MO must have been set in the associated DrxParaGroup MO.
    • When CatType is set to EMTC_MODE_A, EmtcModeADrxParaGroupId in a CellQciPara MO must have been set in the associated DrxParaGroup MO.
    • When CatType is set to EMTC_MODE_B, EmtcModeBDrxParaGroupId in a CellQciPara MO must have been set in the associated DrxParaGroup MO.
    • If NsaDcDrxParaGroupId in the CellQciPara MO is not set to an invalid value 255, the DrxParaGroup MO in which NsaDcDrxParaGroupId in the CellQciPara MO depends must exist, and the CatType parameter in the DrxParaGroup MO must be set to LTE.
    • When CatType is set to EMTC_MODE_B, EmtcModeBCl2DrxParaGroupId in a CellQciPara MO must have been set in the associated DrxParaGroup MO.
    • When CatType is set to EMTC_MODE_A, EmtcModeACl0DrxParaGroupId in a CellQciPara MO must have been set in the associated DrxParaGroup MO.
    • The DrxParaGroup MO referenced by the DrxParaGroupId parameter in the CellQciPara MO must be configured.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
QoS Class Indication

Indicates the QoS class identifier (QCI), which is an attribute of evolved packet system (EPS) bearers. Different QCIs indicate different QoS requirements, such as the packet delay budget, packet loss rate (PLR) and packet error rate (PER), and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.
Interfreq Handover Group ID

Indicates the ID of a parameter group related to inter-frequency handovers. This parameter applies only to LTE FDD and LTE TDD.
InterRAT Handover to CDMA20001xRTT Group ID

Indicates the ID of a parameter group related to inter-RAT handover to CDMA2000 HRPD. This parameter applies only to LTE FDD and LTE TDD.
InterRAT Handover Common Group ID

DRX Parameter Group ID

Indicates the ID of a DRX parameter group. This parameter applies only to LTE FDD and LTE TDD.
SRI Period

Indicates the interval at which scheduling request indicators are sent. This parameter applies only to LTE FDD and LTE TDD.
RLF Timer and Constants Indication

Indicates the RLF timer and constant configuration indication. This parameter applies only to LTE FDD and LTE TDD.
RLF Timer and Constants Group ID

Indicates the RLF timer and constant group ID. This parameter applies only to LTE FDD and LTE TDD.
Traffic Release Delay

Indicates the time that the eNodeB waits to release services with a specific QCI after the eNodeB detects that the radio link is abnormal. When the eNodeB detects that the radio link is abnormal, the eNodeB waits for the UE to initiate an RRC connection reestablishment procedure to restore services. If the waiting duration times out, the eNodeB releases the services. This parameter applies only to LTE FDD and LTE TDD.
QCI Priority For Handover

Indicates the QCI priority used by each QCI-based handover algorithm. A larger value of this parameter indicates a lower priority. This parameter applies to handover parameter selection based on QCI priorities, target frequency selection in service-based inter-frequency handovers, and inter-RAT handover policy selection. For a service that involves all the preceding selection, the setting of this parameter determines the handover parameter, target frequency, and handover policy corresponding to a QCI. This parameter applies only to LTE FDD and LTE TDD.
Mlb QCI Group ID

Indicates the ID of a mobility load balancing (MLB) parameter group for a QCI. The value 255 is invalid. If this parameter is set to a value ranging from 0 to 9, the ID must be set in the associated MlbQciGroup MO. This parameter is valid only when the Qci parameter in the CellQciPara MO is set to 6, 7, 8, or 9. This parameter applies only to LTE FDD and LTE TDD.
Preallocation Parameter Group ID

Indicates the ID of the parameter group related to preallocations. The value 255 indicates an invalid preallocation parameter group. This parameter applies only to LTE FDD and LTE TDD.
QCI Priority For DRX

Indicates the QCI-specific priority for selecting a DRX parameter group. A larger value of this parameter indicates a lower priority. If the bearers for a UE have multiple QCIs and the DrxPolicyMode parameter is set to QCIPRIORITY(QCI priority), the eNodeB selects the DRX parameter group for the UE based on the QCI-specific priorities. This parameter applies only to LTE FDD and LTE TDD.
QCI Algorithm Switch

Indicates whether to enable QCI-specific algorithms.

INTER_FREQ_MLB_ALLOWED: If this option is selected, inter-frequency mobility load balancing (MLB) can be performed for UEs with bearers of this QCI. You are advised to select this option for the default bearers. Otherwise, the eNodeB may fail to transfer UEs for MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_FREQ_MLB_LOW_PRIO_IND: If this option is selected, the eNodeB does not preferentially select UEs with bearers of this QCI for inter-frequency MLB. If this option is deselected, no policy is applied to selection of such UEs for inter-frequency MLB. You are advised to deselect this option for the default bearers. Otherwise, QCI-based UE selection policies for MLB may not take effect. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_MLB_ALLOWED: If this option is selected, UEs with bearers of this QCI can be selected for inter-RAT MLB. If this option is deselected, UEs with bearers of this QCI cannot be selected for inter-RAT MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_MLB_LOW_PRIO_IND: If this option is selected, the eNodeB does not preferentially select UEs with bearers of this QCI for inter-RAT MLB. If this option is deselected, no policy is applied to selection of such UEs for inter-RAT MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

HO_USE_VOIP_FREQ_ALLOWED: If this option is selected and inter-frequency directional handovers for VoIP services are enabled, then the eNodeB selects handover target frequencies for UEs with bearers of this QCI based on the value of the VoIPPriority parameter in the EutranInterNFreq MO and frequency-priority-based handovers are disabled for UEs with bearers of this QCI. If this option is deselected, then the eNodeB does not select handover target frequencies for UEs with bearers of this QCI based on the value of the VoIPPriority parameter in the EutranInterNFreq MO and frequency-priority-based handovers are enabled for UEs with bearers of this QCI. This option applies only to LTE FDD and LTE TDD.

SMART_CA_ALLOWED: If this option is selected, the eNodeB triggers a procedure for intelligent selection of serving cell combinations to reselect an optimal serving cell combination after the QCI-specific bearer is set up in the eNodeB. If this option is deselected, the eNodeB does not trigger the procedure in the preceding scenario. This option applies only to LTE FDD and LTE TDD.

ADMISSION_FORBIDDEN: If this option is selected, the eNodeB directly rejects bearers of this QCI during admission upon receiving the E-RAB SETUP REQUEST message from the MME and does not allow preemption. If this option is deselected, the eNodeB admits such bearers. This option applies only to LTE TDD.

SRI_PERIOD_OPT_SW: If this option is selected, the eNodeB preferentially allocates short SRI periods to UEs with bearers of this QCI, improving user experience with delay on UEs with such bearers. In FDD, this option takes effect only when SriPeriodAdaptive is set to QCIADAPTIVE and the SriReCfgInd parameter is set to FALSE. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

DL_SCH_PRIORITY_OPT_SW: If this option is selected, the eNodeB allocates higher scheduling priorities for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

PDCCH_BOUNDARY_PWR_CTRL_OPT_SW: If this option is selected, PDCCH boundary power control optimization is enabled for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

SR_PRIORITY_DATA_OPT_SW: If this option is selected, SR-based scheduling priority and data amount optimization is enabled for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

QCI_TTI_BUNDLING_SWITCH: Indicates whether to enable QCI-specific TTI bundling. If this option is selected, TTI bundling is allowed for UEs with bearers of this QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

QCI_ROHC_SWITCH: Indicates whether to enable QCI-specific ROHC. If this option is selected, ROHC is allowed for UEs with bearers of this QCI, thereby improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

LOW_DELAY_UE_UL_SCH_OPT_SW: Indicates whether to enable uplink scheduling optimization for UEs running low-latency services. If this option is selected, uplink scheduling optimization is allowed for UEs with bearers of the specified QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

LOW_DELAY_UE_UL_MCS_IDX_RDC_SW: Indicates whether to enable uplink MCS index reduction for UEs running low-latency services. If this option is selected, uplink MCS index reduction is allowed for UEs with bearers of the specified QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: If this option is selected, the base station triggers smart carrier selection for fast-moving UEs after bearers of this QCI are set up in the base station. If this option is deselected, the eNodeB does not trigger smart carrier selection for fast-moving UEs after the bearers are set up. This option applies only to LTE FDD and LTE TDD.

UE_REL_FORBID_IMMCI_FOR_MLB_SW: Indicates whether the eNodeB is prohibited from delivering the IMMCI IE for MLB when the RRC connection of a UE is to be released and the UE is changed from RRC_CONNECTED mode to RRC_IDLE mode. If this option is selected, the IMMCI IE is not allowed to be delivered. If this option is deselected, this IE can be delivered. This option applies only to LTE FDD and LTE TDD.

FORBID_MLB_SWITCH: Indicates whether to prohibit MLB-triggered transfer of RRC_CONNECTED UEs with services of the specified QCI. If this option is selected, MLB-triggered transfer of such UEs is prohibited. If this option is deselected, MLB-triggered transfer of such UEs is not prohibited. This option applies only to LTE FDD and LTE TDD.
QCI EUTRAN Frequency Relation ID

Indicates the ID of the QCI and E-UTRAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.
QCI UTRAN Frequency Relation ID

Indicates the ID of the QCI and UTRAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.
QCI GERAN Frequency Relation ID

Indicates the ID of the QCI and GERAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.
eMTC Mode A CL 1 DRX Parameter Group ID

Indicates the ID of a DRX parameter group used for eMTC UEs in CE mode A at coverage level 1. This parameter is invalid when it is set to 255. This parameter applies only to LTE FDD and LTE TDD.
eMTC Mode B CL 3 DRX Parameter Group ID

Indicates the ID of a DRX parameter group used for eMTC UEs in CE mode B at coverage level 3. This parameter is invalid when it is set to 255. This parameter applies only to LTE FDD and LTE TDD.
Service Flag

Indicates the service type of the bearers of the QCI. This parameter is set based on the operator's policy. Bearers of the QCI carry WBB services if this parameter is set to WBB_SERVICE. Bearers of the QCI carry non-WBB services if this parameter is set to NONE. This parameter applies only to LTE FDD and LTE TDD.
DL AMBR Rate Limiting Factor

Indicates the downlink AMBR limit factor for QCI-identified UEs whose rate is limited in DACQ scenarios. When DACQ is performed, the actual maximum data rate of a specific direction limited at a specific level equals the product of the following items: the maximum data rate of the corresponding direction limited at the corresponding level in the CellDacqCfg MO, the AMBR limit factor of the corresponding QCI in the CellQciPara MO, and the AMBR limit factor of the corresponding SPID in the SpidCfg MO. This parameter takes effect only when the EnhancementCtrlSwitch option of the DacqEnhancementSwitch parameter in the CellAlgoSwitch MO is selected and DACQ is enabled for the QCI. This parameter applies only to LTE FDD and LTE TDD.
QCI-specific AMBR Limit Flag

Indicates whether to limit or protect the AMBR of QCI-specific UEs when dynamic AMBR control by QCI (DACQ) or enhanced DACQ is performed.

When a cell meets the DACQ or enhanced DACQ triggering criteria, the AMBR of UEs with the specified QCI is processed based on the value of this parameter. If this parameter is set to NORMAL, the AMBR of UEs with the specified QCI is neither limited nor protected. If this parameter is set to LIMIT and the SpidBasedAmbrLimitFactor parameter is set to a non-zero value for an SPID, the AMBR of UEs with the specified QCI and SPID is limited. If this parameter is set to PROTECT, the AMBR of UEs with the specified QCI is protected. This parameter takes effect only for certain QCIs. For details, see QoS Management Feature Parameter Description. This parameter applies only to LTE FDD and LTE TDD.
UL AMBR Limit Factor

Indicates the uplink AMBR limit factor for QCI-identified UEs whose rate is limited in DACQ scenarios. When DACQ is performed, the actual maximum data rate of a specific direction limited at a specific level equals the product of the following items: the maximum data rate of the corresponding direction limited at the corresponding level in the CellDacqCfg MO, the AMBR limit factor of the corresponding QCI in the CellQciPara MO, and the AMBR limit factor of the corresponding SPID in the SpidCfg MO. This parameter takes effect only when the EnhancementCtrlSwitch option of the DacqEnhancementSwitch parameter in the CellAlgoSwitch MO is selected and DACQ is enabled for the QCI. This parameter applies only to LTE FDD and LTE TDD.
Congestion Threshold

Indicates the QCI-specific service congestion threshold. This threshold applies to both the uplink and downlink. If the service QoS satisfaction rate of the QCI in the cell is lower than the threshold, the services of this QCI are congested. If the QoS satisfaction rate is higher than the sum of the threshold and the CongRelOffset parameter value, the service congestion is relieved. This parameter applies only to LTE FDD and LTE TDD. Parameter relationship with conditions: When Qci is set to a value in the range of 1 to 4 or set to 65, the CongestionThreshold parameter is valid. QCIs 66 and 1 share the same congestion threshold. QCIs 75 and 3 share the same congestion threshold. QCI 75 applies to macro eNodeB FDD, macro eNodeB TDD, LampSite eNodeB FDD, and LampSite eNodeB TDD.
Handover Admission Threshold

Indicates the QCI-specific handover admission threshold. This threshold applies to both the uplink and downlink. Handovers of such services can be admitted only if the service QoS satisfaction rate of the QCI in the cell is greater than or equal to the threshold. This parameter applies only to LTE FDD and LTE TDD. Parameter relationship with conditions: When Qci is set to a value in the range of 1 to 4, 65, 66, or 75, the HandoverAdmissionThreshold parameter is valid. QCI 75 supports macro eNodeB FDD, macro eNodeB TDD, LampSite eNodeB FDD, and LampSite eNodeB TDD.
Initial Downlink Target IBLER

Indicates the initial downlink target IBLER for UEs with bearers of the QCI. If this parameter is set to 0, this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
SINR Adjustment Target IBLER

Indicates the target IBLER of the SINR adjustment algorithm for UEs with bearers of the QCI. If this parameter is set to 0, this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
eMTC SRI Period

Indicates the SRI reporting period of eMTC UEs. This parameter applies only to LTE FDD and LTE TDD.
Max Queue Duration

Indicates the longest time during which QCI-65 bearers that failed to be admitted due to insufficient cell resources can queue. If there are not sufficient cell resources after the time specified by this parameter, the eNodeB rejects admission requests of QCI-65 bearers. If this parameter is set to 0, the QCI-65 bearers cannot queue after admission failures. This parameter takes effect only when both the MCPTT QoS Management and Congestion Control for Public Safety features are enabled. This parameter applies only to LTE FDD and LTE TDD. Parameter relationship with conditions: When Qci is set to 65, the MaxQueueDuration parameter is valid.
US UE Control Rate

Indicates the maximum QCI-specific data rate controlled for UEs. If this parameter is set to 65535, this parameter is invalid. This parameter takes effect only for QCIs 1 to 4. This parameter applies only to LTE FDD and LTE TDD.
QCI PDCCH SINR Offset

Indicates the PDCCH SINR offset of UEs having bearers with the QCI. This parameter is used to adjust the PDCCH aggregation level and PDCCH power for such UEs. If this parameter is set to 0, adjustment of the PDCCH aggregation level and PDCCH power does not take effect. This parameter applies only to LTE FDD and LTE TDD.
Decrease in NACK CQI Adjustment

Indicates the decrease in the CQI adjustment value when a UE returns a NACK message. If this parameter is set to a non-zero value, the CQI adjustment value decreases by the value of this parameter. If this parameter is set to 0, the CQI adjustment value is not modified. This parameter applies only to LTE FDD and LTE TDD.
CEU Uplink Path Loss Threshold

Indicates the uplink path loss threshold of CEUs used in the measurement of the number of expected to-be-received uplink PDCP SDUs for services carried on DRBs for UEs far away from the cell center in a cell and the number of lost uplink PDCP SDUs for services carried on DRBs for the same UEs. When the uplink path loss of a UE is greater than or equal to the threshold, the corresponding counter is measured. For details about the counters related to this parameter, see the performance counter reference. This parameter applies only to LTE FDD and LTE TDD.
NR Handover Parameter Group ID

Indicates the ID of a parameter group related to inter-RAT handovers to NR cells. This parameter applies only to LTE FDD and LTE TDD.
SINR Thld for Triggering QCI TTI Bundling

Indicates the SINR threshold for UEs to enter QCI-specific TTI bundling. This parameter applies only to LTE FDD.
Low Latency Flag

Indicates whether bearers of this QCI are used for low-latency services. If this parameter is set to TRUE, bearers of this QCI are used for low-latency services. If this parameter is set to FALSE, bearers of this QCI are not used for low-latency services. This parameter does not take effect for QCI 1, QCI 2, QCI 5, and PTT-related QCIs (including QCI 65, QCI 66, QCI 69, and QCI 70). This parameter applies only to LTE FDD and LTE TDD.
NSA DC Default Bearer Mode

Indicates the type of bearers to be set up for UEs that access the cell or are handed over to the cell in the LTE-NR NSA DC architecture.

If this parameter is set to SCG_SPLIT_BEARER, SCG split bearers are set up for UEs by default.

If this parameter is set to MCG_SPLIT_BEARER, MCG split bearers are set up for UEs by default.

If this parameter is set to MCG_BEARER, MCG bearers using the NR PDCP are set up for UEs by default. The NR PDCP complies with 3GPP TS 38.323.

If this parameter is set to MCG_BEARER_EUTRA_PDCP, MCG bearers using the E-UTRA PDCP are set up for UEs by default. The E-UTRA PDCP complies with 3GPP TS 36.323.

Low Delay CEU Preallocation Opt Thld

Indicates whether to enable short-period preallocation optimization for cell edge users (CEUs) running low-latency services and the threshold for the optimization to take effect. If this parameter is set to -51, this function does not take effect. If this parameter is set to a value other than -51, the parameter value is the SINR threshold for short-period preallocation optimization for CEUs running low-latency services. When the uplink SINR of a UE is less than the value of this parameter, the optimization function takes effect for this UE. This parameter applies only to LTE FDD and LTE TDD.

Uplink HARQ Maximum Transmission Number

Indicates the maximum number of uplink HARQ transmissions, excluding the HARQ transmission based on TTI bundling. For details, see 3GPP TS 36.331. This parameter takes effect only if QCI-1 bearers exist and the UlVoipCrosslayerOptSwitch option is deselected. This parameter has coupling relationships with the ENodeBAmReorderingTimer and ENodeBUmReorderingTimer parameters. If the UlHarqMaxTxNum parameter is set to N7, it is recommended that the ENodeBAmReorderingTimer and ENodeBUmReorderingTimer parameter values be greater than or equal to a value indicating 50ms(FDD)/70ms(TDD). If the UlHarqMaxTxNum parameter is set to N8, it is recommended that the ENodeBAmReorderingTimer and ENodeBUmReorderingTimer parameter values be greater than or equal to a value indicating 70ms(FDD)/80ms(TDD). This parameter applies only to LTE FDD and LTE TDD.
