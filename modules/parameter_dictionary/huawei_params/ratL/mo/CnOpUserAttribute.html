CnOpUserAttribute

+-NE
  +-eNodeBFunction
    +-CnOperator
      +-CnOpUserAttribute

Description

A CnOpUserAttribute MO consists of parameters related to operator-specific user attributes.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    CnOperator

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CNOPUSERATTRIBUTE

Use this command to list operator-specific user attributes.
MOD CNOPUSERATTRIBUTE

Use this command to modify operator-specific user attributes.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
CN Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.
Allocation and Retention Priority

Indicates the allocation and retention priority (ARP) of EPS bearers. This parameter applies only to LTE FDD and LTE TDD.
User Priority

Indicates the user priority. This parameter applies only to LTE FDD and LTE TDD.
