UserVpfmPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-UserVpfmPara

Description

A UserVpfmPara MO consists of parameters used to evaluate user experience.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST USERVPFMPARA

Use this command to list parameters used to evaluate user experience.
MOD USERVPFMPARA

Use this command to modify parameters used to evaluate user experience.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.
Downlink User Throughput Threshold 0

Indicates the downlink user throughput threshold 0. If the downlink user throughput falls into the interval [0, Downlink User Throughput Threshold 0), the data rate is considered in the interval of Index0.
Downlink User Throughput Threshold 1

Indicates the downlink user throughput threshold 1. If the downlink user throughput falls into the interval [Downlink User Throughput Threshold 0, Downlink User Throughput Threshold 1), the data rate is considered in the interval of Index1.
Downlink User Throughput Threshold 2

Indicates the downlink user throughput threshold 2. If the downlink user throughput falls into the interval [Downlink User Throughput Threshold 1, Downlink User Throughput Threshold 2), the data rate is considered in the interval of Index2.
Downlink User Throughput Threshold 3

Indicates the downlink user throughput threshold 3. If the downlink user throughput falls into the interval [Downlink User Throughput Threshold 2, Downlink User Throughput Threshold 3), the data rate is considered in the interval of Index3.
Downlink User Throughput Threshold 4

Indicates the downlink user throughput threshold 4. If the downlink user throughput falls into the interval [Downlink User Throughput Threshold 3, Downlink User Throughput Threshold 4), the data rate is considered in the interval of Index4.
Uplink Access Delay Good Threshold

Indicates the access delay threshold of uplink services initiated by UEs in idle mode, which is used to determine whether the access delay is good.
Uplink Access Delay Bad Threshold

Indicates the access delay threshold of uplink services initiated by UEs in idle mode, which is used to determine whether the access delay is poor.
Downlink Access Delay Good Threshold

Indicates the access delay threshold of downlink services initiated by UEs in idle mode, which is used to determine whether the access delay is good.
Downlink Access Delay Bad Threshold

Indicates the access delay threshold of downlink services initiated by UEs in idle mode, which is used to determine whether the access delay is poor.
