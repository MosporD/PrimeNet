QCIEUTRANRELATION

+-NE
  +-eNodeBFunction
    +-Cell
      +-QCIEUTRANRELATION

Description

A QCIEUTRANRELATION MO consists of parameters related to the relationship between an E-UTRAN frequency and a QCI to deploy QCI-specific policies for the frequency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the EutranInterNFreq MO:
    • Before adding an QCIEUTRANRELATION, ensure that the associated EutranInterNFreq has been configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD QCIEUTRANRELATION

Use this command to add a relationship between a QCI and an E-UTRAN frequency.
LST QCIEUTRANRELATION

Use this command to list the configurations of the relationship between a QCI and an E-UTRAN frequency.
MOD QCIEUTRANRELATION

Use this command to modify the configurations of the relationship between a QCI and an E-UTRAN frequency.
RMV QCIEUTRANRELATION

Use this command to remove a relationship between a QCI and an E-UTRAN frequency.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Downlink EARFCN

Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) associated with the QCI. This parameter applies only to LTE FDD and LTE TDD.
QCI Eutran Frequency Relation ID

Indicates the ID of the QCI and E-UTRAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.
Mobility Target Indicator

Indicates whether the neighboring E-UTRAN frequency can be a target frequency in QCI-specific mobility management.

MlbTargetInd(MlbTargetInd): The neighboring E-UTRAN frequency can be a target frequency in QCI-specific MLB only if this option is selected. You are advised to select this option for the default bearer. Otherwise, MLB may not transfer UEs. This option applies only to LTE FDD and LTE TDD.
