GsmInterfArfcnCfg

+-NE
  +-eNodeBFunction
    +-GsmInterfArfcnCfg

Description

The GsmInterfArfcnCfg MO consists of parameters used to configure frequencies used by GSM in standard LTE bandwidths.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the SpectrumCloud MO:
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcnGroupId parameter must be configured in each SpectrumCloud MO instance, and the corresponding GsmInterfArfcnCfg MO instance must also be configured.
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY or UL_SPECTRUM_SHR_PH2_WITH_GSM, the GsmArfcnGroupId parameter must be configured in each SpectrumCloud MO instance, and the corresponding GsmInterfArfcnCfg MO instance must also be configured.
  • Relation with the Cell and SpectrumCloud MOs:
    • When the FreqBand parameter in a Cell MO is set to 2 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be within the range of 512 to 810.
    • When the FreqBand parameter in a Cell MO is set to 3 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be within the range of 512 to 885.
    • When the FreqBand parameter in a Cell MO is set to 5 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be within the range of 128 to 251.
    • When the FreqBand parameter in a Cell MO is set to 8 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be within the range of 0 to 124 or 975 to 1023.
    • When the FreqBand parameter in a Cell MO is set to 9 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be within the range of 711 to 885.
    • When the DlBandWidth parameters in a Cell MO are set to CELL_BW_N25 and the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the GsmArfcn parameter in the GsmInterfArfcnCfg MO corresponding to the SpectrumCloud MO under the Cell MO must be set to a value indicating a frequency within 1.1 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N50, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 2.8 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N75, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 3.8 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N100, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is selected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 4.8 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N50, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is deselected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 2.1 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N75, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is deselected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 2.5 MHz from the LTE start/end frequency.
    • If the DlBandWidth parameters in the Cell MO are set to CELL_BW_N100, the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, and the GL_SPCT_CONCURRENCY_PH2_SW option of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO is deselected, the GsmArfcn parameter in the GsmInterfArfcnCfg MO associated with the SpectrumCloud MO under this Cell MO must be set to a value indicating a frequency within 3.1 MHz from the LTE start/end frequency.
  • Relation with the SpectrumCloud and CellRbReserve MOs:
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the RbRsvType parameter in a CellRbReserve MO is set to DOWNLINK_MODE, and the RbRsvMode parameter in the CellRbReserve MO is set to NB_RESERVED or NB_DEPLOYMENT, the following applies: If shared frequencies of ARFCNs specified by GsmArfcn and LTE RBs do not overlap, the RbRsvStartIndex and RbRsvEndIndex parameters in the CellRbReserve MO must be set in such a way that the reserved RBs are 200 kHz away from the center frequency of shared ARFCNs. If the shared frequencies of ARFCNs specified by GsmArfcn and LTE RBs overlap, the RbRsvStartIndex and RbRsvEndIndex parameters in the CellRbReserve MO must be set in such a way that the reserved RBs are 550 kHz away from the center frequency of shared ARFCNs.
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the RbRsvType parameter in a CellRbReserve MO is set to UPLINK_MODE, and the RbRsvMode parameter in the CellRbReserve MO is set to NB_RESERVED or NB_DEPLOYMENT, the following applies: If shared frequencies of ARFCNs specified by GsmArfcn and LTE RBs do not overlap, the RbRsvStartIndex and RbRsvEndIndex parameters in the CellRbReserve MO must be set in such a way that the reserved RBs are 200 kHz away from the center frequency of shared ARFCNs. If the shared frequencies of ARFCNs specified by GsmArfcn and LTE RBs overlap, the RbRsvStartIndex and RbRsvEndIndex parameters in the CellRbReserve MO must be set in such a way that the reserved RBs are 280 kHz away from the center frequency of shared ARFCNs.
  • Relation with the SpectrumCloud and Cell MOs:
    • When SpectrumCloudSwitch in the SpectrumCloud MO is set to UL_SPECTRUM_SHR_PH2_WITH_GSM and the cell bandwidth is 3 MHz, 5 MHz, 10 MHz, 15 MHz, or 20 MHz, the downlink GSM frequency determined by GsmArfcn in the GsmInterfArfcnCfg MO corresponding to GsmArfcnGroupId in the SpectrumCloud must meet the following requirements:
    • 1. If the cell bandwidth is 3 MHz, the GSM frequency is not within the RB range of [0, 14].
    • 2. If the cell bandwidth is 5 MHz, the GSM frequency is not within the RB range of [0, 24].
    • 3. If the cell bandwidth is 10 MHz, the GSM frequency is not within the RB range of [0, 49].
    • 4. If the cell bandwidth is 15 MHz, the GSM frequency is not within the RB range of [0, 74].
    • 5. If the cell bandwidth is 20 MHz, the GSM frequency is not within the RB range of [0, 99].

Function

Use this command to list ARFCNs of interfering GSM frequencies for GL spectrum cloudification features.

Use this command to remove ARFCNs of interfering GSM frequencies for GL spectrum cloudification features.
