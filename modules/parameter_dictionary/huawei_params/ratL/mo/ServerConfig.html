ServerConfig

+-NE
  +-eNodeBFunction
    +-ServerConfig

Description

A ServerConfig MO consists of server parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD SERVERCONFIG

Use this command to configure a server.
LST SERVERCONFIG

Use this command to list the parameter settings for a server.
MOD SERVERCONFIG

Use this command to change the parameter settings for a server.
RMV SERVERCONFIG

Use this command to remove the parameter settings for a server.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Server Index

Indicates the index of the server accessed by UEs. This parameter applies only to LTE FDD and LTE TDD.
IPv4 Server IP Address

Indicates the IPv4 address of the server accessed by UEs. UEs can access the server based on the IP address, a combination of the IP address and protocol type, or a combination of the IP address, protocol type, and port number. This parameter applies only to LTE FDD and LTE TDD.
Server Port Number

Indicates the server port accessed by UEs. The value 0 indicates that no detection is performed for the port number of IP packets. This parameter applies only to LTE FDD and LTE TDD.
Protocol Type

Indicates the protocol type of the server visited by UEs. The value NONE indicates that no detection is performed for the protocol type of downlink packets. The value UDP indicates that the eNodeB checks whether the protocol type of downlink packets is UDP. The value TCP indicates that the eNodeB checks whether the protocol type of downlink packets is TCP. This parameter applies only to LTE FDD and LTE TDD.
IP Version

Indicates the IP version. This parameter applies only to LTE FDD and LTE TDD.
IPv6 Server IP Address

Indicates the IPv6 address of the server accessed by UEs. UEs can access the server based on the IP address, a combination of the IP address and protocol type, or a combination of the IP address, protocol type, and port number. This parameter applies only to LTE FDD and LTE TDD.
IP Address Detection Purpose Control Switch

Indicates the purpose of IP address detection.

ACTIVE_TEST_SPEED_DETECT_SW: Indicates whether to check a specified IP address for active speed tests. The specified IP address is checked only if this option is selected.

MAX_CARRIER_NUM_CONTROL_SW: Indicates whether to check a specified IP address for the control over the maximum number of carriers. This option is valid only when the MaximumNumberOfCarriers parameter in the SpidCfg MO is set to a value other than 0. If this option is selected, the eNodeB checks the specified IP address and cancels the limitation specified by the MaximumNumberOfCarriers parameter in the SpidCfg MO for UEs that are accessing the IP address. If this option is deselected, the eNodeB does not check the specified IP address or cancel the limitation. This option applies only to LTE FDD and LTE TDD.
