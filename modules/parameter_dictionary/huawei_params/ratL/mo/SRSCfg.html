SRSCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-SRSCfg

Description

The SRSCfg MO consists of the parameters related to the configuration of sounding reference signals (SRSs). For details about the SRSs, see 3GPP TS 36.211.

Effective Scenario

Immediately

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
SRS subframe configuration

Indicates the index of SRS subframe configuration for the cell.

The value SCn, where n is variable, represents configuration n. For example, the value SC0 indicates subframe configuration 0, and the value SC1 indicates subframe configuration 1. For an FDD cell, value SC15 is reserved; for a TDD cell, values SC14 and SC15 are both reserved. Reserved values are not used for configuration. For the relationship between the subframe configuration index and the cell-specific subframe cycle/offset, see 3GPP TS 36.211. In FDD mode, this parameter is always valid. In TDD mode, this parameter is valid only if TddSrsCfgMode is set to EXPERIENCE_FIRST. This parameter applies only to LTE FDD and LTE TDD.
SRS ACK/NACK simultaneous transmission

Indicates whether the sounding reference signal (SRS) of a UE and the ACK/NACK or scheduling request (SR) on the PUCCH are allowed to use the same time resources for simultaneous transmission in the case of time domain conflict. This parameter does not take effect on eMTC UEs. In the case of time domain conflict, the SRS of eMTC UEs and the ACK/NACK or SR on the PUCCH are allowed to use the same time resources for simultaneous transmission.

If this parameter is set to BOOLEAN_FALSE, simultaneous transmission is not allowed. In this situation, the UE discards the SRS and only transmits the ACK/NACK or SR on the PUCCH.

If this parameter is set to BOOLEAN_TRUE, simultaneous transmission is allowed. In this situation, the UE transmits the truncated ACK/NACK or SR. For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
SRS Configuration Indicator

Indicates whether to configure sounding reference signal (SRS) resources for UEs in a cell. The value BOOLEAN_TRUE indicates that SRS resources are available in the cell and can be configured for UEs in the cell. The value BOOLEAN_FALSE indicates that no SRS resource is available in the cell, and therefore no UE in the cell is configured with SRS resources. This parameter does not take effect on: (1) FDD cell that is established on an LBBPc and uses four or more RX antennas. (2) FDD cell that is established on an LBBPc and uses extended cyclic prefix (CP) in the uplink. (3) TDD cell established on an LBBPc. If this parameter does not take effect on a cell but SRS resources are available in the cell, SRS resources can be configured for UEs in the cell. This parameter applies only to LTE FDD and LTE TDD.
TDD SRS Configuration Mode

Indicates the SRS configuration for LTE TDD. If this parameter is set to ACCESS_FIRST, the SRS configuration designed to preferentially guarantee the maximum number of UEs that can access a cell and BHCA is used. If this parameter is set to EXPERIENCE_FIRST, the SRS configuration designed to preferentially guarantee user experience (for example, beamforming performance) is used. If this parameter is set to EXPERIENCE_ENHANCED, downlink experience improves compared with that obtained when this parameter is set to ACCESS_FIRST. If this parameter is set to ACCESS_ENHANCED, more UEs can access the network compared with that obtained when this parameter is set to EXPERIENCE_ENHANCED. The values EXPERIENCE_ENHANCED and ACCESS_ENHANCED are not supported by the LBBPc. If this parameter is set to EXPERIENCE_ENHANCED or ACCESS_ENHANCED for a cell established on an LBBPc board, the value is automatically changed to ACCESS_FIRST when this parameter takes effect. This parameter applies only to LTE TDD.
FDD SRS Configuration Mode

Indicates the allocation mode of sounding reference signal (SRS) resources in LTE FDD. This parameter must be set when the SrsCfgInd parameter is set to BOOLEAN_TRUE(True). If the FddSrsCfgMode parameter is set to DEFAULTMODE(Default Mode), SRS resource allocation is activated by default after a cell is established, and SRS resources are allocated to UEs that access the cell. If this parameter is set to ADAPTIVEMODE(Adaptive Mode), SRS resource allocation can be adaptively activated or deactivated based on the cell load. After this parameter is set to ADAPTIVEMODE(Adaptive Mode), settings of parameters SrsAlgoSwitch, SrsSubframeCfg, and UserSrsPeriod do not take effect. The parameter value ADAPTIVEMODE(Adaptive Mode) is recommended in heavy-traffic scenarios where there is a large number of UEs in the cell. The parameter value ADAPTIVEMODE(Adaptive Mode) does not apply to cells established on an LBBPc. This parameter applies only to LTE FDD.
SRS Algorithm Optimization Switch

Indicates whether to enable SRS algorithm optimization.

SrsSubframeRecfgOptSwitch: Indicates whether to perform SRS subframe reconfiguration optimization. This option applies only to LTE FDD. If this option is selected, the SRS subframe reconfiguration path is optimized to avoid the configurations that may cause UE compatibility issues. If this option is deselected, the SRS subframe reconfiguration path is not optimized.

UlVolteSrsFssSwitch: The function controlled by this option does not take effect. Non-service-specific uplink frequency selective scheduling takes effect no matter whether this option is selected or not. This option applies only to LTE FDD.
SRS Configure Policy Switch

Indicates the SRS configuration policy. This parameter applies only to LTE TDD.

SRSPolicyforUL2LayersMIMO: Indicates the two-antenna-port SRS configuration policy if two antenna ports are configured for a UE in the uplink. If this option is deselected, the eNodeB preferentially allocates short-term SRSs (including single-antenna-port SRSs). If this option is selected, the eNodeB preferentially allocates two-antenna-port SRSs (including long-term SRSs).

SrvBasedSRSAdjAlgo: Indicates whether to enable service-based SRS adjustment. If this option is selected, the eNodeB can adjust SRSs for UEs based on the identified UE services for SRS adjustment. If this option is deselected, the eNodeB does not identify UE services for SRS adjustment. This option applies only to LTE TDD.

WTTxSRSIntrfAvoidanceSw: Indicates whether to enable SRS interference avoidance in WTTx scenarios. If this option is selected, the eNodeB uses resources at different positions for SRS transmission in WTTx cells. If this option is deselected, the eNodeB uses resources at the original positions for SRS transmission in WTTx cells. This option applies only to LTE TDD.
Reserved Resource SRS Period 1

Indicates the SRS period for resources always reserved in the first half frame for inter-cell D-MIMO, DL CoMP, and UL CAMC. This parameter applies only to LTE TDD.
Reserved Resource SRS Period 2

Indicates the SRS period for resources always reserved in the second half frame for inter-cell D-MIMO, DL CoMP, and UL CAMC. This parameter applies only to LTE TDD.
SRS Resource Optimization Switch

Indicates whether to optimize SRS resource allocation for 2R access enhancement. If this parameter is set to ON(On), quadruple code division can be used for SRS resource allocation to enhance 2R access. If this parameter is set to OFF(Off), quadruple code division cannot be used for SRS resource allocation to enhance 2R access. This parameter applies only to LTE TDD.
SRS Interference Avoid Optimization Switch

Indicates how SRS allocation is optimized to avoid interference based on the physical beam serving UEs. The default value OFF indicates that the optimization does not take effect. If this parameter is set to CLOCKWISE_COMB1, comb 1 SRS resources are preferentially allocated to UEs in the clockwise direction to the boundary beam, and comb 0 SRS resources are preferentially allocated to UEs in the counterclockwise direction to the boundary beam. If this parameter is set to ANTICLOCKWISE_COMB1, comb 0 SRS resources are preferentially allocated to UEs in the clockwise direction to the boundary beam, and comb 1 SRS resources are preferentially allocated to UEs in the counterclockwise direction to the boundary beam. A changed parameter value takes effect only for UEs that newly access the network or move from one side to the other side of the boundary beam. This parameter applies only to LTE TDD.
SRS Resource Expansion Switch

Indicates whether to enable SRS resource expansion. If this parameter is set to OFF, SRS resource expansion is disabled. If this parameter is set to SRS_RES_EXPANSION_MODE, SRS resource expansion is enabled. This parameter applies only to LTE TDD.

Cell srs bandwidth configuration

Indicates the cell-specific SRS bandwidth. It corresponds to the srs-BandwidthConfig parameter in the protocol. For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
