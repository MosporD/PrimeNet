CellRicAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellRicAlgo

Description

The CellRicAlgo MO consists of the parameters related to remote interference cancellation. This function detects downlink interference between TDD eNodeBs that are distant from each other and also prevents or eliminates the interference. Remote interference cancellation applies to an LTE TDD network consisting of more than 200 eNodeBs or consisting of multiple subnetworks with inter-subnetwork spacing greater than 21.4 km. The time that related commands begin to take effect must be specified according to the Greenwich Mean Time (GMT).

Effective Scenario

Immediately

Function

This command can be used to query the signal strength from different directions in a massive MIMO cell and quickly locate strong signal sources, such as interference sources. Use this command to list the configuration of the remote interference cancellation algorithm in one or all cells.
MOD CELLRICALGO

Use this command to modify the configuration of the remote interference cancellation algorithm in a cell.
SND CELLRICPCISEQ

Use this command to send data about TDD cell remote interference. Dedicated signals (DSs) are generated based on the equivalent PCI of a cell. The equivalent PCI equals the sum of the cell PCI and the PCI offset set in this command. DSs are used to distinguish cells with the same PCI and help identify the cells that cause remote interference.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
RIC algorithm switch

Indicates the switch for the remote interference cancellation algorithm. If this switch is turned on, the eNodeB performs remote interference detection and records in call history record (CHR) logs if any interference is detected. If this switch is turned off, the eNodeB does not perform remote interference detection. This parameter applies only to LTE FDD and LTE TDD.
Mute UpPTS Symbol Number

Indicates the number of symbols during which no SRSs are transmitted in an uplink pilot timeslot (UpPTS). If this parameter is set to a non-zero value N, no SRSs are transmitted within N symbols starting from the first symbol during which SRS transmission is allowed in the UpPTS. For any given special subframe configuration, the value of this parameter must not be greater than the total number of symbols during which SRS transmission is allowed in the UpPTS. This parameter applies only to LTE TDD.
Whether to mute UL symbol

Indicates whether to mute the last symbol in an uplink subframe. If this parameter is set to ON, the last symbol in an uplink subframe is muted. If this parameter is set to OFF, the last symbol in an uplink subframe is not muted. This parameter applies only to LTE TDD cells using uplink-downlink subframe configuration 1. This parameter applies only to LTE TDD.
UL Interference Threshold

Indicates the relative threshold used to determine whether uplink interference occurs in a cell. If the average uplink interference and noise received on each PRB in a cell is at least 15 dBm greater than this threshold or the average UpPTS interference is at least 15 dBm greater than this threshold minus 10, it is considered that severe interference has occurred in the cell. At this point, the eNodeB records an entry of interference-related characteristic (which can be queried by running the DSP INREC command) and collects inverse spectrum data. This parameter applies only to LTE TDD.
Ducting Remote Interfer Threshold

Indicates the threshold for identifying remote interference caused by an atmospheric duct by detecting characteristic sequences. This parameter applies only to LTE TDD cells.
Interfer Avoid Detect Period Num

Indicates the number of characteristic sequence detection periods in which the detection results are used to determine whether to perform remote interference avoidance. This parameter applies only to LTE TDD cells.
Interf Avoid Recovery Detect Period Num

Indicates the number of characteristic sequence detection periods in which the detection results are used to determine whether to stop remote interference avoidance. This parameter applies only to LTE TDD cells.
Remote Interfer Adaptive Avoid Switch

Indicates whether to enable adaptive avoidance of remote interference. If this parameter is set to ON(On), characteristic sequences are sent and detected to adaptively avoid remote interference. This parameter applies only to LTE TDD cells.
Max Difference of UL Inter-Symbol RX Power

Indicates the threshold of the difference between the maximum and minimum receive power of uplink symbols measured in the full time domain. If the difference between the maximum and minimum receive power of uplink symbols exceeds this threshold, the eNodeB determines that abnormal interference occurs. This parameter can be used only to trigger automatic recording of one interference record and reverse spectrum data collection. This parameter applies only to LTE TDD.
Atmospheric Duct DL Subframe Shutdown Switch

Indicates whether to enable atmospheric duct DL subframe shutdown. If this parameter is set to ON(On), the eNodeB shuts down downlink subframes. If this parameter is set to OFF(Off), the eNodeB does not shut down downlink subframes. This parameter applies only to LTE TDD.
UL Interference Duration

Indicates the threshold of the number of consecutive monitoring periods (5s for each period) during which abnormal interference meets the related threshold criteria, for interference recording. For example, if this parameter is set to 12 and the eNodeB detects interference that meets the criteria for 1 minute, the eNodeB records interference for maintenance. This parameter can be used only to trigger automatic recording of one interference record and reverse spectrum data collection. This parameter applies only to LTE TDD.
Duct DL Subframe Shutoff Opt Inf Thld

Indicates the absolute interference threshold for determining whether atmospheric duct interference occurs in an uplink subframe. The eNodeB may optimize downlink subframe shutdown due to atmospheric duct interference only when interference occurring in an uplink subframe on the 72 subcarriers in the middle of the frequency domain exceeds this threshold. This parameter applies only to LTE TDD.
Duct DL Subframe Shutoff Opt Sw

DUCT_DL_SUBFRM_SHUTOFF_OPT_SW: If this option is selected, the eNodeB automatically detects atmospheric duct interference and shuts down downlink subframes when the interference meets the preset condition. If this option is deselected, the eNodeB does not detect atmospheric duct interference or shut down downlink subframes. This option applies only to LTE TDD.

DUCT_DL_SF_SCHED_SHUTOFF_SW: If this option is selected, the eNodeB automatically detects atmospheric duct interference in the cell within the specified detection period, and shuts down downlink subframes when the interference condition is met. If this option is deselected, the eNodeB neither detects atmospheric duct interference nor shuts down downlink subframes. This option applies only to LTE TDD.
Duct Inf Det Period Count

Indicates the number of interference detection periods for determining whether to optimize downlink subframe shutdown when atmospheric duct interference occurs. This parameter applies only to LTE TDD.
Duct DL Subfrm Shutoff Opt Inf Pwr Diff In Thld

For 2T2R, 4T4R and 8T8R cells: Indicates the threshold of receive power difference between the first half slot and the second half slot of a TDD uplink subframe on the 72 subcarriers in the middle of the frequency domain. This threshold is used to determine whether there is atmospheric duct interference. Optimized atmospheric duct downlink subframe shutdown takes effect only when the receive power difference exceeds this threshold. This parameter applies only to LTE TDD.

For 32T32R and 64T64R cells: Indicates the threshold of the power difference between the symbol with the maximum receive power and that with the minimum receive power in a TDD uplink subframe on the 72 subcarriers in the middle of the frequency domain. This threshold is used to determine whether there is atmospheric duct interference. Optimized atmospheric duct downlink subframe shutdown takes effect only when the power difference exceeds this threshold. This parameter applies only to LTE TDD.
Duct DL Subfrm Shutoff Opt Inf Pwr Diff Out Thld

For 2T2R, 4T4R and 8T8R cells: Indicates the threshold of receive power difference between the first half slot and the second half slot of a TDD uplink subframe on the 72 subcarriers in the middle of the frequency domain. This threshold is used to determine whether atmospheric duct interference meets the conditions for terminating optimized atmospheric duct downlink subframe shutdown. If the receive power difference is less than this threshold, optimized atmospheric duct downlink subframe shutdown may terminate. Otherwise, this function remains unchanged. This parameter applies only to LTE TDD.

For 32T32R and 64T64R cells: Indicates the threshold of the power difference between the symbol with the maximum receive power and that with the minimum receive power in a TDD uplink subframe on the 72 subcarriers in the middle of the frequency domain. This threshold is used to determine whether atmospheric duct interference meets the conditions for terminating optimized atmospheric duct downlink subframe shutdown. If the power difference is less than this threshold, optimized atmospheric duct downlink subframe shutdown may terminate. Otherwise, this function remains unchanged. This parameter applies only to LTE TDD.
Atmospheric Duct Subframe Shutoff Depth

Indicates which downlink subframes to shut down and how to shut them down when atmospheric duct interference occurs. If this parameter is set to DWPTS_SHUTOFF(DWPTS_SHUTOFF), the eNodeB shuts down only special subframes 1 and 6 and stops scheduling services in DwPTSs. If this parameter is set to SLOT01_SHUTOFF(SLOT01_SHUTOFF), the eNodeB shuts down special subframes and subframes 0 and 5, performs scheduling only for paging in subframe 0, and transmits only SIB1 in subframe 5. This parameter applies only to LTE TDD.
Atmospheric Duct UL Average Intrf Pwr Thld

Indicates the threshold of average uplink interference for identifying atmospheric duct interference. The eNodeB can send characteristic sequences only if the average uplink interference is greater than this threshold. This parameter applies only to LTE TDD.
Atmospheric Duct UL Pwr Difference Thld

For 4T4R and 8T8R cells: Indicates the threshold of the power difference between symbols 0 and 11 in a TDD uplink subframe. This threshold is used to determine whether there is atmospheric duct interference. The characteristic sequence can be sent only when the power difference exceeds this threshold. This parameter applies only to LTE TDD.

For 32T32R and 64T64R cells: Indicates the threshold of the power difference between the symbol with the maximum receive power and that with the minimum receive power in a TDD uplink subframe. This threshold is used to determine whether there is atmospheric duct interference. The characteristic sequence can be sent only when the power difference exceeds this threshold. This parameter applies only to LTE TDD.
Duct DL Subframe Shutdown Detection Start Time

Indicates the start time of a detection period for the function of scheduled atmospheric-duct-based downlink subframe shutdown. If this function is enabled, the eNodeB automatically detects atmospheric duct interference in the cell within the specified detection period, and shuts down downlink subframes when the interference condition is met. If this function is disabled, the eNodeB neither detects atmospheric duct interference nor shuts down downlink subframes. This parameter applies only to LTE TDD.
Duct DL Subframe Shutdown Detection End Time

Indicates the end time of a detection period for the function of scheduled atmospheric-duct-based downlink subframe shutdown. If this function is enabled, the eNodeB automatically detects atmospheric duct interference in the cell within the specified detection period, and shuts down downlink subframes when the interference condition is met. If this function is disabled, the eNodeB neither detects atmospheric duct interference nor shuts down downlink subframes. This parameter applies only to LTE TDD.
