CqiAdaptiveCfg

+-NE
  +-eNodeBFunction
    +-CqiAdaptiveCfg

Description

The CqiAdaptiveCfg MO configures the adaptive CQI reporting switch, UE-level CQI reporting period configuration, the CQI and Ack or Nack simultaneous sending switch, and the aperiodic CQI reporting configuration applying switch.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the CaMgtCfg MO:
    • If the DlMassiveCaSwitch option of the CellCaAlgoSwitch parameter is selected or the FddTddCaDlMaxCcNum parameter is set to DL_MASSIVE_CA in a CaMgtCfg MO, the SimulAckNackAndCqiFmt3Sw parameter in the CqiAdaptiveCfg MO must be set to ON.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
PUCCH Periodic CQI Optimize Switch

Indicates whether to enable the optimization on CQI reporting periods and RB resources for CQI reporting on the PUCCH. If this parameter is set to ON, the eNodeB configures fewer UEs with a short CQI reporting period, decreasing PUCCH resources to be used and increasing available PUSCH resources. If this parameter is set to OFF, the eNodeB configures more UEs with a short CQI reporting period, increasing PUCCH resources to be used and decreasing available PUSCH resources. This parameter applies only to LTE FDD.
PUCCH Format 3 CQI Reporting Switch

Indicates whether CQI and ACK/NACK can be simultaneously transmitted over the PUCCH of format 3. For details about PUCCH format 3, see 3GPP TS 36.213. When this parameter is set to OFF, simultaneous transmission is not allowed. When this parameter is set to ON, the IE simultaneousAckNackAndCQI-Format3-r11 takes the value "Setup", meaning that simultaneous transmission is allowed. This parameter applies only to LTE FDD and LTE TDD.
