NCellPlmnList

+-NE
  +-eNodeBFunction
    +-NCellPlmnList

Description

An NCellPlmnList MO consists of parameters related to a listed PLMN. Parameters in this MO are used to apply differentiated management to the PLMNs to improve operation and maintenance efficiency.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NCELLPLMNLIST

Use this command to add a neighboring cell PLMN list.
LST NCELLPLMNLIST

Use this command to query a neighboring cell PLMN list.
MOD NCELLPLMNLIST

Use this command to modify a neighboring cell PLMN list.
RMV NCELLPLMNLIST

Use this command to remove a neighboring cell PLMN list.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the mobile country code (MCC) of the listed PLMN of neighboring cells. An MCC is a string of three decimal digits, each of which must be a digit ranging from 0 to 9. This parameter applies only to LTE FDD and LTE TDD.
Mobile Network Code

Indicates the mobile network code (MNC) of the listed PLMN of neighboring cells. An MNC is a string of two or three decimal digits, each of which must be a digit ranging from 0 to 9. This parameter applies only to LTE FDD and LTE TDD.
Rat Type

Indicates the RAT of a listed PLMN of neighboring cells. This parameter applies only to LTE FDD and LTE TDD.
Plmn List Type

Indicates the type of a PLMN list. If this parameter is set to BLACK_LIST, the cell of the blacklisted PLMN cannot be configured as a neighboring cell or an external cell by ANR. If this parameter is set to GREY_LIST, the cell of the graylisted PLMN can be added as a neighboring cell and an external cell by ANR, and the ANR marks a PLMN graylist label on the neighboring cell. If this parameter is set to WHITE_LIST, the cell of the whitelisted PLMN can be added as a neighboring cell and an external cell by ANR, and the ANR marks a PLMN whitelist label on the neighboring cell. This parameter can be set to only two of the three values for all PLMNs in an E-UTRAN, UTRAN, GERAN, or NG-RAN. The type of PLMNs for which this parameter is not configured is considered the third type by default. This parameter applies only to LTE FDD and LTE TDD.
gNodeB ID Length

Indicates the length of a gNodeB ID. This parameter specifies the number of bits of the gNodeB ID in the NCI to uniquely identify an NCI. For details, see 3GPP TS 38.423. This parameter is valid only when the RatType parameter in the NCellPlmnList MO is set to NR. This parameter must be set to the gNodeB ID length of the gNodeB in the specified PLMN on the 5G network. This parameter applies only to LTE FDD and LTE TDD.
