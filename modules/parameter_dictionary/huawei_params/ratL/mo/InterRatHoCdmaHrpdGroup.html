InterRatHoCdmaHrpdGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-InterRatHoCdmaHrpdGroup

Description

An InterRatHoCdmaHrpdGroup MO consists of parameters related to inter-RAT handover to CDMA2000 HRPD. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in an InterRatHoCdmaHrpdGroup MO must have been set in the associated Cell MO.
  • Relation with the CellQciPara MO:
    • The InterRatHoCdmaHrpdGroup MO referenced by the InterRatHoCdmaHrpdGroupId parameter in the CellQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
InterRAT handover to CDMA2000HRPD group ID

Indicates the ID of the QCI-specific parameter group related to inter-RAT handover to CDMA2000 HRPD. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000HRPD handover hysteresis

Indicates the hysteresis for event B1 related to inter-RAT handover to CDMA2000 HRPD. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. This parameter applies only to LTE FDD and LTE TDD.
CoverageBased CDMA2000HRPD trigger threshold

Indicates the pilot strength threshold for event B1 related to load- or service-based inter-RAT handover to CDMA2000 HRPD.

When the measurement value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
CDMA2000HRPD time to trigger

Indicates the time-to-trigger for event B1 related to inter-RAT handover to CDMA2000 HRPD.

When detecting that the signal quality in at least one neighboring cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting, the average number of handovers, and the number of wrong handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.
Cdma2000 HRPD Optimized handover B2 RSRP thld1

Indicates the B2 RSRP threshold 1 used during optimized handovers from E-UTRAN to CDMA2000 eHRPD. This parameter applies only to LTE FDD and LTE TDD.
Cdma2000 HRPD Optimized handover B2 RSRQ thld1

Indicates the B2 RSRQ threshold 1 used during optimized handovers from E-UTRAN to CDMA2000 eHRPD. This parameter applies only to LTE FDD and LTE TDD.
Cdma2000 HRPD Non Optimized HO B2 RSRP Thd

Indicates the RSRP threshold for event B2 related to measurement-based non-optimized handovers from E-UTRAN to CDMA2000 eHRPD. This parameter applies only to LTE FDD and LTE TDD.
Cdma2000 HRPD Non Optimized HO B2 RSRQ Thd

Indicates the RSRQ threshold for event B2 related to measurement-based non-optimized handovers from E-UTRAN to CDMA2000 eHRPD. This parameter applies only to LTE FDD and LTE TDD.
