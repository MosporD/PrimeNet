IntraFreqBlkCell

+-NE
  +-eNodeBFunction
    +-Cell
      +-IntraFreqBlkCell

Description

An IntraFreqBlkCell MO consists of the parameters related to a blacklisted intra-frequency cell. The blacklist is contained in system information block type 4 (SIB4). Handover and reselection to blacklisted cells are prohibited for UEs in connected mode and those in idle mode, respectively. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • A maximum of 32 IntraFreqBlkCell MOs can be configured for each cell.
    • PhyCellId of the local Cell MO cannot be within the intra-frequency blacklist cell range specified by PhyCellId and PhyCellIdRange in an IntraFreqBlkCell MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD INTRAFREQBLKCELL

Use this command to add intra-frequency E-UTRAN cells to the blacklist.
LST INTRAFREQBLKCELL

Use this command to list the parameters of the blacklisted intra-frequency E-UTRAN cell.
MOD INTRAFREQBLKCELL

Use this command to modify a blacklisted intra-frequency E-UTRAN cell.
RMV INTRAFREQBLKCELL

Use this command to remove an intra-frequency E-UTRAN cell from the blacklist.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Start physical cell ID

Indicates the starting PCI of the intra-frequency blacklisted cell. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Cell name

Indicates the name of the intra-frequency blacklisted cell. This parameter applies only to LTE FDD and LTE TDD.
Physical cell ID range

Indicates the PCI range of the intra-frequency blacklisted cell. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Application Scope

Indicates the UEs that the cell blacklist applies to. If this parameter is set to 65535, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through reselection or handover. If this parameter is set to 65534, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through handover. If this parameter is set to a value from 0 to 255, the blacklist applies to UEs with the SPID in an SPID group with the SpidGrpId parameter value the same as the ApplicationScope parameter and such UEs cannot be handed over to the blacklisted cell. This parameter applies only to LTE FDD and LTE TDD.
