CellSmartPwrLock

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellSmartPwrLock

Description

The CellSmartPwrLock MO consists of the parameters related to smart power lock.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • If the NbCellFlag parameter in a Cell MO is set to TRUE, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the DlBandWidth parameter in a Cell MO is set to CELL_BW_N6 or CELL_BW_N15, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO is set to AVERAGE_POWER_CONTROL, the TxRxMode parameter in the Cell MO can only be set to 2T2R, 2T4R, 2T8R, 4T4R, or 4T8R.
    • If the FddTddInd parameter in a Cell MO is set to CELL_TDD and SmartPowerLockMode in the associated CellSmartPwrLock MO is set to AVERAGE_POWER_CONTROL, the TxRxMode parameter in this Cell MO can only be set to 2T2R, or 4T4R.
    • If the MultiRruCellFlag parameter in a Cell MO is set to BOOLEAN_TRUE, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
  • Relation with the CellUSParaCfg MO:
    • If the UsUeGuaranteeSwitch option of the UsAlgoSwitch parameter in a CellUSParaCfg MO is selected, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
  • Relation with the PDSCHCfg MO:
    • If the CrsPowerBoostingAmplitude parameter in the PDSCHCfg MO is set to a value other than DB_0, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the PdschPowerBoostingSwitch parameter in the PDSCHCfg MO is set to ON, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the CellPowerLimit parameter in the PDSCHCfg MO is set to a value other than 0, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
  • Relation with the CellAlgoSwitch MO:
    • If the BfEnhChnPwrFormSwitch, EDlMaxTXPwrSwitch, or DlNonStandardBwMaxPwrSwitch option of the DlPcAlgoSwitch parameter in a CellAlgoSwitch MO is selected, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the SuperCombCellSwitch option of the SfnAlgoSwitch parameter in a CellAlgoSwitch MO is selected, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
    • If the Virtual4T4RSwitch option of the EmimoSwitch parameter in a CellAlgoSwitch MO is selected, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
  • Relation with the ENodeBAlgoSwitch MO:
    • If the SsrdDynDlPwrShareSwitch option of the SSRDAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the SmartPowerLockMode parameter in the associated CellSmartPwrLock MO must be set to OFF.
  • Relation with the ContigIntraBandCarr MO:
    • If the POWER_RAISE_SW option of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO is selected, the SmartPowerLockMode parameter in the CellSmartPwrLock MO must be set to OFF.
  • Relation with the Cell and eUCellSectorEqm MOs:
    • If the MultiRruCellFlag parameter in a Cell MO is set to BOOLEAN_FALSE and the SmartPowerLockMode parameter in the corresponding CellSmartPwrLock MO is set to AVERAGE_POWER_CONTROL, the total number of eUCellSectorEqm MOs corresponding to the Cell MO must not be greater than 1.
  • Relation with the SpectrumCloud MO:
    • If the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the SmartPowerLockMode parameter in the CellSmartPwrLock MO corresponding to the LocalCellId parameter must be set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
Smart Power Lock Mode

Indicates the control mode of smart power lock. The value OFF indicates that the smart power lock feature is disabled. The value AVERAGE_POWER_CONTROL indicates that the average power control function of the smart power lock feature is enabled. This parameter applies only to LTE FDD and LTE TDD.
Power Control Threshold

Indicates the power control threshold for the smart power lock feature. The average transmit power of the cell within the average power measurement period for the smart power lock feature must be lower than this threshold. This parameter applies only to LTE FDD and LTE TDD.
Average Power Measurement Period

Indicates the average power measurement period for the smart power lock feature. This parameter applies only to LTE FDD and LTE TDD.
