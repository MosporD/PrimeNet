+-NE

Description

A SectorSplitCell MO consists of the parameters used to configure a sector split cell.

Effective Scenario

Immediately

Indicates the horizontal azimuth corresponding to the beamforming weight for a massive MIMO cell. The mechanical azimuth of the antenna is used as the normal line. This parameter applies only to LTE FDD and LTE TDD.
Cell Beamwidth

Indicates the horizontal 3 dB beamwidth corresponding to the beamforming weight for a massive MIMO cell. This parameter takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected and the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in the SectorSplitGroup MO is deselected. The sector beamwidth is specified by the CellBeamwidth parameter in the SectorSplitCell MO. When this parameter is set to DEFAULT, the beamwidth set in the sector beam weight database is used. This parameter applies only to LTE FDD and LTE TDD.
Cell Beam Tilt Fraction Part

Indicates the fractional part of the downtilt angle corresponding to the beamforming weight of a massive MIMO cell. This parameter is used together with the CellBeamTilt parameter, which indicates the integer part of the downtilt angle. The CellBeamTiltFractionPart parameter indicates the fractional part (decimal part) of the downtilt angle. This parameter is valid only for massive MIMO scenarios. This parameter applies only to LTE FDD and LTE TDD.
Cell Beam Power

Indicates the cell beam power. This parameter takes effect only when the POWER_ALLOCATION_SWITCH option of the SectorSplitGroup.SectorSplitSwitch parameter is selected. This parameter applies only to LTE FDD.
