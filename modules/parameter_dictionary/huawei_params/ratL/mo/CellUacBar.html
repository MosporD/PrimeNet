CellUacBar

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellUacBar

Description

A CellUACBar MO consists of parameters related to cell access barring. Different access control parameters can be configured for different access classes.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the UacParamGroup MO:
    • It is required that the AccessControlParamGrpId parameter in a CellUacBar MO have been set in the associated UacParamGroup MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLUACBAR

Use this command to add UAC barring configurations for a cell.
LST CELLUACBAR

Use this command to query UAC barring configurations for a cell.
MOD CELLUACBAR

Use this command to modify UAC barring configurations for a cell.
RMV CELLUACBAR

Use this command to remove UAC barring configurations for a cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Access Category

Indicates the access category of services in a cell. For details, see 3GPP TS 22.261. This parameter applies only to LTE FDD and LTE TDD.
Access Control Parameter Group ID

Indicates the access control parameter group ID mapping to an access category. This parameter applies only to LTE FDD and LTE TDD.
