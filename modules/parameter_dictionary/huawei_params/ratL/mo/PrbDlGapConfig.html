PrbDlGapConfig

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-PrbDlGapConfig

Description

A PrbDlGapConfig MO consists of PRB-level parameters related to the downlink gap function in NB-IoT.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Prb
  • Relation with the PrbSchConfig, Cell, PrbPdcchCeConfig, and CellRachCECfg MOs:
    • If the NbCellFlag parameter in a Cell MO is set to BOOLEAN_TRUE and the DL_GAP_SWITCH option of the DlSchedulingSwitch parameter in the PrbSchConfig MO is selected, parameter adjustment is allowed for the coverage level for which the PdcchMaxRepetitionCnt parameter value is greater than or equal to the DlGapThreshold parameter value only when the following condition is met: The rounded-up result of (DlGapPeriod x DlGapDurationCoeff/(PdcchMaxRepetitionCnt x PdcchPeriodFactor) + 3) is less than the value of ContentionResolutionTimer and RaResponseWindowSize.
  • Relation with the PrbSchConfig, Cell, and PrbPdcchCeConfig MOs:
    • When the NbCellFlag parameter in a Cell is set to TRUE, the DL_GAP_SWITCH option of the DlSchedulingSwitch parameter in the PrbSchConfig MO can be selected for a PRB in the cell only if the PRB meets the following condition: The PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO is set to a value greater than G_4 for the coverage level for which the PdcchMaxRepetitionCnt parameter in the PrbPdcchCeConfig MO is set to a value greater than or equal to the value of the DlGapThreshold parameter in the PrbDlGapConfig MO or the PdcchMaxRepetitionCnt parameter less than the DlGapThreshold parameter corresponding to all the coverage levels.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the NB-IoT PRB ID, which uniquely identifies a PRB within an NB-IoT cell. This parameter applies only to NB-IoT.
Downlink Gap Duration Coefficient

Indicates the coefficient for the duration of a downlink gap for NB-IoT. The duration of a downlink gap is equal to the interval between downlink gaps multiplied by this coefficient. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.
Downlink Gap Period

Indicates the interval between downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.
Downlink Gap Threshold

Indicates the threshold for applying downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.
