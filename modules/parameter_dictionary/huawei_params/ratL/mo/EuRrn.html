EuRrn

+-NE
  +-eNodeBFunction
    +-EuSubscriber
      +-EuRrn
        +-EuRrnLanIp[0~16]
        +-EuRrnPort[2~2]

Description

The EuRrn MO consists of parameters specifying basic information about an RRN, such as the serving cell, OM IP address, and interface IP addresses that are configured for an RRN as planned.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    EuSubscriber

  • Possible children:

    EuRrnLanIp[0~16];EuRrnPort[2~2]
  • Relation with the EuSubscriber MO:
    • Before configuring the LocalSubscriberId parameter in the EuRrn MO, ensure that the SubscriberType parameter corresponding to LocalSubscriberId in the EuSubscriber MO be set to RRN.
  • Relation with the RelayExtendedQci MO:
    • If the SchType parameter is set to WFQ_L2OM in a RelayExtendedQci MO, the RrnType parameter in the EuRrn MO cannot be set to RRN3201 or RRN3901.

Related Parameters

Table 2 Configuration parameters

Parameter

Description
Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
OM IP

Indicates the O&M IP address of an RRN. Modification to this parameter leads to network exit and reaccess of the RRN. This parameter applies only to LTE FDD and LTE TDD.
DHCP Server IP

Indicates the destination IP address of the DHCP server. The DHCP packets sent from the downstream base station to an RRN are relayed to this destination IP address. This parameter applies only to LTE FDD and LTE TDD.
RRN Type

Indicates the RRN type. This parameter applies only to LTE FDD and LTE TDD.
Extended DHCP Server IP

Indicates the destination IP address of the extended DHCP server. The DHCP packets sent from the downstream eNodeB to an RRN are relayed to this destination IP address. This parameter applies only to LTE FDD and LTE TDD.
SyncEth Clock Switch

Indicates whether the RRN performs synchronous Ethernet clock broadcast. This parameter applies only to LTE FDD and LTE TDD.
Relay Type

Indicates the relay type of an RRN, which can be L3 Relay (IP Based) or L2 Relay (MAC Based). This parameter applies only to LTE FDD and LTE TDD.
OM Interface ID

Indicates the interface ID assigned to the O&M channel of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2). This parameter applies only to LTE FDD and LTE TDD.
Service InterfaceID

Indicates the interface ID assigned to the service channel of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2). This parameter applies only to LTE FDD and LTE TDD.
RRN MAC Aging Time

Indicates the aging time of the dynamic MAC address of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2). If this parameter is set to 0, the dynamic MAC address is not aged. This parameter applies only to LTE FDD and LTE TDD.
RRN VLAN Tag Switch

Indicates whether the RRN adds a VLAN tag in the O&M data. This parameter is valid only if the RelayType parameter is set to L2(L2). This parameter applies only to LTE FDD and LTE TDD.
RRN VLAN ID

Indicates the value of VLAN ID in the VLAN tag contained in the O&M data of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2) and the RrnVlanTagSwitch parameter is set to ON(ON). This parameter applies only to LTE FDD and LTE TDD.
RRN VLAN Priority

Indicates the value of VLAN Priority in the VLAN tag contained in the O&M data of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2) and the RrnVlanTagSwitch parameter is set to ON(ON). This parameter applies only to LTE FDD and LTE TDD.
OM IP Mask

Indicates the subnet mask of the O&M IP address of an RRN. This parameter is valid only if the RelayType parameter is set to L2(L2). This parameter applies only to LTE FDD and LTE TDD.
Enhanced Function Switch

Indicates whether to enable RRN enhancement functions.

AUTOMATIC_ANTENNA_ADJ_SW: Indicates whether to enable automatic antenna alignment. Automatic antenna alignment is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

INTERFERENCE_CANCELLATION_SW: Indicates whether to enable interference cancellation. Interference cancellation is enabled only if this option is selected. This option applies only to LTE FDD.
Local WAP Channel Number

Indicates the channel number used by the local Wireless Access Protocol (WAP) of the RRN. Different countries and regions may use different channel policies. For example, indoor and outdoor WLANs use different channels. When the LocalWapRegionCode parameter is set to REGION_0, REGION_1, REGION_2, or REGION_3, the LocalWapChannelNumber parameter can be set to CHANNEL_AUTOMATIC. In this case, the WLAN module automatically selects the most appropriate channel, that is, the channel with the minimum interference. When the LocalWapRegionCode parameter is set to REGION_USER_DEFINED, the LocalWapChannelNumber parameter cannot be set to CHANNEL_AUTOMATIC, and the WLAN module cannot automatically select the most appropriate channel. The channel number must be set to a specific value. The parameter value must meet the laws, regulations, and industry standard requirements of the country or region where the base station is located. The typical rate is 6 Mbit/s when there is neither obstacle nor obvious interference within a radius of five meters. If the data rate is low, you can modify the value of this parameter to avoid co-channel interference. It is recommended that the parameter value be far away from the current value or you can attempt other channels one by one. In addition, ensure that the terminal is close to the WLAN module and there is no obstacle between them. The weather and strong magnetic field affect the WLAN transmission rate. This parameter applies only to LTE FDD and LTE TDD.
Local WAP Policy

Indicates the policy in which the local WAP of the RRN works.

If this parameter is set to AUTOMATIC, local WAP is disabled after the RRN accesses a cell and local WAP is enabled when the RRN cannot access the cell. If this parameter is set to ALWAYS_ON, local WAP is always enabled. If this parameter is set to ALWAYS_OFF, local WAP is always disabled.

This parameter applies only to LTE FDD and LTE TDD.
Local WAP Region Code

Indicates the region code of the country where the RRN is located. Different regions support different 2.4 GHz WLAN channels. The RRN supports five types of region codes. REGION_0 indicates North America, where channels 1 to 11 are available. REGION_1 indicates part of Europe, Japan, and China, where channels 1 to 13 are available. REGION_2 indicates France, where channels 1 to 9 are available. REGION_3 indicates Israel, where channels 5 to 13 are available. REGION_USER_DEFINED indicates all areas, where channels 1 to 14 are available. If REGION_0, REGION_1, REGION_2, and REGION_3 do not match the location of the base station, set this parameter to REGION_USER_DEFINED. This parameter applies only to LTE FDD and LTE TDD.
