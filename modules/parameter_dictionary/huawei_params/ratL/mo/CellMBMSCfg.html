CellMBMSCfg

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMBMSCfg

Description

The CellMBMSCfg MO consists of the parameters related to cell MBMS service.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, CellEicic, and CellAlgoSwitch MOs:
    • The AbsPattern parameter in the CellEicic MO that is related to the Cell MO can be configured only with subframe 0 and subframe 5 when the following conditions are met: In a Cell MO, the FddTddInd parameter is set to CELL_TDD, and the SubframeAssignment parameter is set to SA1 or SA2. In the CellMBMSCfg MO that is related to the Cell MO, the MBMSSwitch parameter is set to 1. In the CellAlgoSwitch MO that is related to the Cell MO, the EicicSwitch parameter is set to STATIC.
  • Relation with the Cell and CellPrsCfg MOs:
    • If FddTddInd in a Cell MO is set to CELL_FDD and the MBMSSwitch option of MBMSSwitch is selected, the last digit of the value of PrsConfigurationIndex must be 0, 4, 5, or 9.
    • If FddTddInd in a Cell MO is set to CELL_FDD and the MBMSSwitch option of MBMSSwitch is selected, NumberofDlFramesforPrs must be set to SF1 or SF2 when the last digit of the value of PrsConfigurationIndex is 4 or 9, or NumberofDlFramesforPrs must be set to SF1 when the last digit of the value of PrsConfigurationIndex is 0 or 5.
  • Relation with the Cell and CellRbReserve MOs:
    • If RbRsvMode in a CellRbReserve MO under a Cell MO is set to NB_DEPLOYMENT and the value of CellActiveState in this Cell MO is CELL_ACTIVE, the MBMSSwitch option of MBMSSwitch in the CellMBMSCfg MO under this Cell MO must be deselected.
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to TRUE, the MBMSSwitch option of the MBMSSwitch in the CellMBMSCfg MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the SERVICECONTINUITYSWITCH option of the MBMSServiceSwitch in the CellMBMSCfg MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the NEIGHCELLCONFIGADAPTIVESWITCH option of the NCellMbmsCfgSwitch in the CellMBMSCfg MO must be deselected.
  • Relation with the CellEmtcAlgo and Cell MOs:
    • Under the same cell, when the NbCellFlag parameter in a Cell MO is set to FALSE and the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected, the MBMSSwitch parameter in a CellMBMSCfg MO must not be set to MBMSSwitch-1.
  • Relation with the SpectrumCloud MO:
    • When the SpectrumCloudSwitch parameter in a SpectrumCloud MO is set to GL_SPECTRUM_CONCURRENCY, the MBMSSwitch option of the MBMSSwitch parameter in the associated CellMBMSCfg MO must be deselected.
  • Relation with the eUCellSectorEqm MO:
    • The MBMSSwitch option of the MBMSSwitch parameter in the CellMBMSCfg MO must be deselected if the CellBeamMode parameter in the eUCellSectorEqm MO is set to MASSIVE_MIMO_Ph2.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the associated SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR, the MBMSSwitch parameter in the associated CellMBMSCfg MO must be set to OFF.
  • Relation with the CellAlgoSwitch MO:
    • The InBandRelayDeNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO and the MBMSSwitch option of the MBMSSwitch parameter in the CellMBMSCfg MO cannot be both selected.
    • The InBandRelayReNbSwitch option of the RelaySwitch parameter in the CellAlgoSwitch MO and the MBMSSwitch option of the MBMSSwitch parameter in the CellMBMSCfg MO cannot be both selected.
  • Relation with the ContigIntraBandCarr MO:
    • MBMSSwitch in the CellMBMSCfg MO and CONTIG_INTRA_BAND_CARR_SW of the ContigIntraBandCarrSw parameter in the ContigIntraBandCarr MO cannot be both turned on.
  • Relation with the CellDynPowerSharing, CellDlschAlgo, SectorSplitCell, and SectorSplitGroup MOs:
    • If the LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO under a Cell MO is selected, and any option of the MbsfnSfCfg parameter in the CellDlschAlgo MO under this Cell MO is selected or the MBMSSwitch option of the MBMSSwitch parameter in the CellMBMSCfg MO under this Cell MO is selected, then the PwrSharingHighLoadThld parameter can only be set to 100 in the SectorSplitGroup MO that includes the SectorSplitCell MO corresponding to this Cell MO.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
MBSFN synchronization Area ID

Indicates the ID of an MBSFN synchronization area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.
MBMS switch

Indicates whether to enable the MBMS function.

MBMSSwitch: If this option is selected, the MBMS function is enabled, and the cell supports the MBMS service. If this option is deselected, the MBMS function is disabled. This parameter applies only to LTE FDD and LTE TDD.
Service Area ID List

Indicates the list of MBMS service areas to which cells belong. This parameter applies only to LTE FDD and LTE TDD.
MBMS Service Switch

SERVICECONTINUITYSWITCH: Indicates whether MBMS service continuity can be maintained. MBMS service continuity can be maintained in inter-frequency networking by selecting this option.

If this option is selected, MBMS service continuity can be maintained. The eNodeB broadcasts SIB15 and determines whether to perform inter-frequency handovers for MBMS service continuity on an RRC_CONNECTED UE based on the MBMS Interest Indication message sent by the UE. In addition, the eNodeB sends the service area ID (SAI) of the serving cell to neighboring cells over the X2 interface.

If this option is deselected, MBMS service continuity cannot be maintained, the eNodeB does not broadcast SIB15, perform inter-frequency handovers for MBMS service continuity, or send the SAI of the serving cell. This option applies only to LTE FDD and LTE TDD.
Neighbor Cell MBMS Config Switch

NEIGHCELLCONFIGADAPTIVESWITCH: Indicates whether the neighboring cell configurations take effect adaptively. In the eMBMS feature, the MBSFN subframe configuration for a cell dynamically changes based on the MBMS session setups. Neighboring cell configurations can be dynamically updated based on the changes of MBSFN subframe configurations of neighboring cells.

If this option is selected, neighboring cell configurations in the local cell are updated and broadcast according to the MBSFN subframe configurations of the neighboring cells transmitted over X2 interfaces.

If this option is deselected, neighboring cell configurations use static parameter settings. This option applies only to LTE FDD and LTE TDD.
Table 3 Dynamic parameters

Parameter

Description
MBSFN Area ID

Indicates the ID of an MBSFN area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.
MBMS Session TMGI

Indicates the TMGI of an MBMS session. The TMGI consists of the MCC, MNC, and ServiceID with each two parts connected by a hyphen (-). TMGIs are separated by comma (,). This parameter applies only to LTE FDD and LTE TDD.
Dynamic Service Area ID List

Indicates the dynamic list of MBSFN service areas to which cells belong. This parameter applies only to LTE FDD and LTE TDD.
