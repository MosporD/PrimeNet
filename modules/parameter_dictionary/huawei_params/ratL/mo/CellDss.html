CellDss

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellDss

Description

The CELLDSS MO consists of parameters used for GSM and LTE dynamic spectrum sharing and GSM and LTE Zero BufferZone in the E-UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellAlgoSwitch and Cell MOs:
    • When the NbCellFlag in a Cell MO is set to FALSE, if GLDynSpectrumShareSwitch under DynSpectrumShareSwitch in the CellAlgoSwitch MO is turned on, the frequency supporting the sum of RB quantities specified by HighFreqShareRbNum and LowFreqShareRbNum in the CellDss MO cannot exceed one third of the value of DlBandWidth in the Cell.
  • Relation with the Cell MO:
    • If NbCellFlag in a Cell MO is set to TRUE, the ReMuteSwitch in the CellDss MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the FlexSpecSchSwitch option of the SpecShrPfmOptSwitch in the CellDss MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the UlSchInterfAvdSwitch option of the SpecShrPfmOptSwitch in the CellDss MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the HoZoneUserSchSwitch option of the SpecShrPfmOptSwitch in the CellDss MO must be deselected.
    • If NbCellFlag in a Cell MO is set to TRUE, the UlShrSpecSchSwitch option of the SpecShrPfmOptSwitch in the CellDss MO must be deselected.
  • Relation with the CellEmtcAlgo and Cell MOs:
    • Under the same cell, when the NbCellFlag parameter in a Cell MO is set to FALSE and the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected, the ReMuteSwitch parameter in a CellDss MO must not be set to ON.
  • Relation with the NbCellMultiPrbConfig, Cell, Prb, CellAlgoSwitch, and CellRbReserve MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE, the NbRfCarrierStrategy parameter in the NbCellMultiPrbConfig under the same cell is set to SHARE, and under the LTE cell associated by the LteCellId of the Prb, the DynSpectrumShareSwitch parameter in the CellAlgoSwitch MO is set to GLDynSpectrumShareSwitch switch on, the RbRsvType parameter in a CellRbReserve MO is set to UPLINK_MODE, and the RbRsvMode parameter in the CellRbReserve MO is set to NB_RESERVED or NB_DEPLOYMENT, then the RbRsvStartIndex and RbRsvEndIndex parameters in the CellRbReserve MO must be set in such a way that the reserved RBs are 2 RBs away from the shared RBs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Shared RB Number in High Frequency

Indicates the number of high-band RBs that the E-UTRAN cell can share with GERAN cells when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. A larger number of shared RBs results in a higher gain that an LTE cell can achieve. For GSM and LTE FDD Dynamic Spectrum Sharing, however, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/5. For GSM and LTE Zero BufferZone, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/2. This parameter applies only to FDD.
Shared RB Number in Low Frequency

Indicates the number of low-band RBs that the E-UTRAN cell can share with GERAN cells when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. A larger number of shared RBs results in a higher gain that an LTE cell can achieve. For GSM and LTE FDD Dynamic Spectrum Sharing, however, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/5. For GSM and LTE Zero BufferZone, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/2. This parameter applies only to FDD.
Mute RE Switch

Indicates whether to send REs if the corresponding REs in the shared spectrum are being used by GSM when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If this switch is on, the eNodeB cannot send these REs. If this switch is off, the eNodeB can send these REs. This parameter applies only to FDD.
UL Narrowband Interference Restriction Mode

Indicates the UL narrowband interference restriction mode used in the GSM and LTE FDD Dynamic Spectrum Sharing(LTE FDD) feature and GSM and LTE Zero Bufferzone feature. The value NONE indicates that UL narrowband interference restriction is not enabled. The value BASEBANDPROCESS indicates that UL narrowband interference is restricted through baseband processing. The interference scope of GSM is reduced and only RBs close to the GSM spectrum are affected. As a result, RBs far away from the GSM spectrum and the LTE spectrum can work properly and LTE performance improves. The value ADAPTIVEPROCESS indicates that UL narrowband interference is restricted through adaptive processing. This algorithm further enhances the interference restriction capability and improves LTE performance. The value INFERIORINTERFPROCESS indicates that only interference from GSM in a neighboring cell is handled through baseband processing. When the setting of the UlInterfRestrictionMode parameter is changed from INFERIORINTERFPROCESS to another value or from another value to INFERIORINTERFPROCESS, the cell must be restarted for the setting change to take effect. This parameter applies only to LTE FDD.
A3 Offset

Indicates the offset of a neighboring cell's signal level that triggers event A3 used after the GSM and LTE FDD Dynamic Spectrum Sharing feature or the GSM and LTE Zero Bufferzone feature is enabled. Measurement reports for this event A3 are reported only when the signal quality of at least one neighboring cell is better than that of the local cell by this offset. If this parameter is set to a larger value, the probability of UEs reporting this event A3 is lower. This parameter applies only to FDD.
A6 Offset

Indicates the offset of a neighboring cell's signal level that triggers event A6 used in the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature. Measurement reports for this event A6 are reported only when the signal quality of at least one neighboring cell is better than that of the secondary serving cell (SCell) in carrier aggregation (CA) by this offset. If this parameter is set to a larger value, the probability of UEs reporting this event A6 is lower. This parameter applies only to FDD.
Near Area Sinr Threshold

Indicates the SINR threshold used to determine whether RBs in the shared spectrum can be allocated to UEs that are located in the cell center when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If the actual SINR of RBs is greater than or equal to this threshold, these RBs can be allocated to these UEs. This parameter applies only to FDD.
Middle Area Sinr Threshold

Indicates the SINR threshold used to determine whether shared RBs can be allocated to UEs that are located at medium distances away from the cell center when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If the SINR of shared RBs is greater than or equal to this threshold, these RBs can be allocated to these UEs. This parameter applies only to FDD.
Far Area Sinr Threshold

Indicates the SINR threshold used to determine whether RBs in the shared spectrum can be allocated to UEs that are located far away from the cell center when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If the actual SINR of RBs is greater than or equal to this threshold, these RBs can be allocated to these UEs. This parameter applies only to FDD.
Spectrum Sharing Performance Opt Switch

Indicates whether to enable spectrum sharing optimization. This parameter provides four options: FlexSpecSchSwitch, UlSchInterfAvdSwitch, HoZoneUserSchSwitch, and UlShrSpecSchSwitch. HoZoneUserSchSwitch and UlShrSpecSchSwitch apply only when GSM and LTE (GL) zero bufferzone is used. This option applies only to LTE FDD.

FlexSpecSchSwitch: Indicates whether to enable flexible exclusive scheduling of shared RBs in GL dynamic spectrum sharing and GL zero bufferzone. This option applies only to LTE FDD.

UlSchInterfAvdSwitch: Indicates whether to enable avoidance of GSM interference when uplink exclusive scheduling of shared RBs is enabled in GL dynamic spectrum sharing and GL zero bufferzone. This option applies only to LTE FDD.

HoZoneUserSchSwitch: Indicates whether to enable scheduling of UEs in handover zones when GL zero bufferzone is used. This option applies only to LTE FDD.

UlShrSpecSchSwitch: Indicates whether to enable scheduling of uplink shared spectrum resources when GL zero bufferzone is used. This option applies only to LTE FDD.
SINR Threshold Without GSM Interference

Indicates the threshold for determining no GSM interference to shared RBs when exclusive scheduling of shared RBs is to be enabled in GSM and LTE (GL) dynamic spectrum sharing and GL zero bufferzone. If the estimated SINR of shared RBs is greater than the threshold, shared RBs are free of GSM interference and can be exclusively scheduled for LTE. This parameter applies only to LTE FDD.
GSM Interference Noise Threshold

Indicates the threshold for determining strong GSM interference in the high frequency band or low frequency band when uplink scheduling in dedicated spectrum is enabled in GSM and LTE (GL) dynamic spectrum sharing or GL zero bufferzone. When the difference between the IN values of the high and low frequency bands is greater than the value of this parameter, there is strong GSM interference to the frequency band with the higher IN value. This parameter applies only to LTE FDD cells.
Near Point User Rsrp Threshold

Indicates the threshold for scheduling uplink shared spectrum resources for UEs located near the center of the E-UTRAN cell when the GL zero bufferzone feature is used. If the downlink RSRP reported by a UE is greater than the threshold, the UE is located near the center of the E-UTRAN cell. This parameter applies only to LTE FDD cells.
