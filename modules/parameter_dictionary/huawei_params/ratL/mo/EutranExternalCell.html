EutranExternalCell

+-NE
  +-eNodeBFunction
    +-EutranExternalCell
      +-EutranExternalCellPlmn[0~5]

Description

An EutranExternalCell MO consists of the parameters related to an external E-UTRAN cell. Each external E-UTRAN cell is under a different eNodeB from the local eNodeB and can be configured as an intra- or inter-frequency neighboring cell of one or more cells under the local eNodeB. The neighboring cell list (NCL) of an eNodeB contains the common information about its external E-UTRAN cells. If an external cell works in RAN sharing mode, additional PLMN IDs must be added for the external cell. If a connection setup request or update message transmitted over an X2 interface contains information about cells under the peer eNodeB, the local eNodeB automatically configures the cells as external E-UTRAN cells. If one of the external E-UTRAN cells works in eRAN sharing with common carrier mode or in hybrid RAN sharing mode, additional PLMN IDs are automatically configured for the external E-UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction

  • Possible children:

    EutranExternalCellPlmn[0~5]
  • Relation with the eNodeBFunction, ENodeBSharingMode, and CnOperator MOs:
    • When the value of eNodeBId in an EutranExternalCell MO is the same as that in the eNodeBFunction MO, the values of Mcc and Mnc in the EutranExternalCell MO depend on the value of ENodeBSharingMode in the ENodeBSharingMode MO: If ENodeBSharingMode in the ENodeBSharingMode MO is set to SEPARATED_FREQ, Mcc and Mnc in an EutranExternalCell MO must be set to values different from those in any CnOperator MO. If ENodeBSharingMode in the ENodeBSharingMode MO is set to INDEPENDENT or SHARED_FREQ, Mcc and Mnc in the EutranExternalCell MO must be set to values different from those in the CnOperator MO that represents the primary operator.
  • Relation with the EutranIntraFreqNCell, CnOperator, eNodeBFunction, and ENodeBSharingMode MOs:
    • Before adding an inter-eNodeB EutranIntraFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured.
  • Relation with the EutranIntraFreqNCell and Cell MOs:
    • Before adding an inter-eNodeB EutranIntraFreqNCell, ensure that the associated EutranExternalCell MO has been configured, and the NbCellFlag of the server Cell of the inter-eNodeB intra-frequency neighboring cell must be same with the NbCellFlag of EutranExternalCell.
    • The carrier frequency calculated based on DlEarfcn in the EutranExternalCell MO that represents an inter-eNodeB EutranIntraFreqNCell must be the same as the carrier frequency calculated based on DlEarfcn in the local Cell MO.
  • Relation with the EutranInterFreqNCell, CnOperator, eNodeBFunction, ENodeBSharingMode, and Cell MOs:
    • Before adding an inter-eNodeB EutranInterFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured.
  • Relation with the EutranInterFreqNCell and Cell MOs:
    • Before adding an inter-eNodeB EutranInterFreqNCell MO, ensure that the associated EutranExternalCell MO has been configured, and the NbCellFlag of the server Cell of the inter-eNodeB EutranInterFreqNCell MO must be same with the NbCellFlag of EutranExternalCell.
    • If NbCellFlag in a Cell MO is set to FALSE, and DlEarfcn in the local Cell MO belongs to an LTE FDD frequency band, the carrier frequency calculated based on DlEarfcn in the EutranExternalCell MO that represents an inter-eNodeB EutranInterFreqNCell MO must be different from the carrier frequency calculated based on DlEarfcn in the local Cell MO.
    • Before adding an inter-eNodeB inter-frequency neighboring cell, ensure that the associated EutranExternalCell MO has been configured, and the NbCellFlag of the server Cell of the inter-eNodeB EutranInterFreqNCell MO must be same with the NbCellFlag of EutranExternalCell.
  • Relation with the EutranBlkNCell, CnOperator, eNodeBFunction, and ENodeBSharingMode MOs:
    • In inter-eNodeB scenarios, before an inter-eNodeB cell is configured as a blacklisted neighboring E-UTRAN cell (represented by the EutranBlkNCell MO) of the serving cell, the EutranExternalCell MO associated with the EutranBlkNCell MO must be configured first.
  • Relation with the EutranInterFreqNCell and Prb MOs:
    • If an inter-eNodeB inter-frequency neighboring cell is to be configured using an EutranInterFreqNCell MO for a local cell whose NbCellFlag is set to TRUE, the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset in the EutranExternalCell MO that the EutranInterFreqNCell MO depends on cannot be the same as the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset or by DlEarfcn and DlBandWidth in the Cell corresponding to LteDlRbIndex in the Prb MO with AnchorCarrierFlag set to TRUE for the local cell.
  • Relation with the EutranIntraFreqNCell, Cell, CellAlgoSwitch, and SfnEdgeRruRelation MOs:
    • PhyCellId in the EutranExternalCell MO associated with an EutranIntraFreqNCell MO (representing an inter-eNodeB intra-frequency neighboring cell of the local cell) can be the same as PhyCellId in the Cell MO representing the local cell if both conditions are met: (1) The SuperCombCellSwitch option of SfnAlgoSwitch in the CellAlgoSwitch MO is selected in the local cell; (2) All values of parameters Mcc, Mnc, eNodeBId, and CellId in the EutranIntraFreqNCell MO are the same with values of parameters Mcc, Mnc, EnodeBId, and NeighborCellId in at least one SfnEdgeRruRelation MO configured for the local cell. If either condition is not met, PhyCellId in the EutranExternalCell MO cannot be the same as PhyCellId in the Cell MO.
  • Relation with the EutranInterFreqNCell, EutranInterNFreq, and Cell MOs:
    • DlEarfcn in the EutranExternalCell MO corresponding to an inter-eNodeB EutranInterFreqNCell MO must be the same as DlEarfcn in an EutranInterNFreq MO.
    • In inter-eNodeB scenarios, the value of DlEarfcn in the EutranExternalCell MO associated with an EutranInterFreqNCell MO of a Cell MO must be the same as one of the values of DlEarfcn in the EutranInterNFreq MOs associated with this Cell MO and the values of DlFreqOffset and DlFreqOffset must be the same.
  • Relation with the EutranIntraFreqNCell, Cell, and Prb MOs:
    • In inter-eNodeB scenarios, if NbCellFlag in a Cell MO is set to TRUE and an EutranIntraFreqNCell MO is to be added for this Cell MO, a Prb MO whose AnchorCarrierFlag is TRUE must be configured first for this Cell MO.
  • Relation with the EutranInterFreqNCell, Cell, and Prb MOs:
    • In inter-eNodeB scenarios, if NbCellFlag in a Cell MO is set to TRUE and an EutranInterFreqNCell MO is to be added for this Cell MO, a Prb MO whose AnchorCarrierFlag is TRUE must be configured first for this Cell MO.
  • Relation with the eNodeBFunction, ENodeBSharingMode, CnOperator, and CnOpSharingGroup MOs:
    • If eNodeBId in an EutranExternalCell MO is set to the same value as eNodeBId in the eNodeBFunction MO and ENodeBSharingMode in the ENodeBSharingMode MO is set to HYBRID_SHARED, the combination of Mcc and Mnc in this EutranExternalCell MO must be different from that of Mcc and Mnc in the CnOperator MO referenced by PrimaryOperatorId in any CnOpSharingGroup MO.
  • Relation with the EutranBlkNCell, Cell, and EutranInterNFreq MOs:
    • In inter-eNodeB scenarios, the value of DlEarfcn in the EutranExternalCell MO associated with an EutranBlkNCell MO must be the same as the value of either DlEarfcn in the corresponding Cell MO or DlEarfcn in the EutranInterNFreq MO.
  • Relation with the EutranBlkNCell and Cell MOs:
    • In inter-eNodeB scenarios, values of DlEarfcn and PhyCellId in the EutranExternalCell MO associated with an EutranBlkNCell MO cannot be the same as values of DlEarfcn and PhyCellId in the corresponding Cell MO.
  • Relation with the EutranIntraFreqNCell and Prb MOs:
    • If an inter-eNodeB intra-frequency neighboring cell is to be configured using an EutranIntraFreqNCell MO for a local cell whose NbCellFlag is set to TRUE, the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset in the EutranExternalCell MO that the EutranIntraFreqNCell MO depends on must be the same as the carrier frequency identified by the combination of DlEarfcn and DlFreqOffset or by DlEarfcn and DlBandWidth in the Cell corresponding to LteDlRbIndex in the Prb MO with AnchorCarrierFlag set to TRUE for the local cell.
  • Relation with the NODE MO:
    • WM in the NODE MO is set to CONCURRENT, a maximum of 2304 EutranExternalCell MOs can be configured in the same eNodeB.
  • Relation with the MDU MO:
    • A maximum of 3*256 EutranExternalCell MOs can be configured in the same eNodeB if the parameter TYPE in MDU MO is set to MDUC.
  • Relation with the EutranExternalCell MO:
    • A maximum of 2304 EutranExternalCell MOs can be configured in the same eNodeB when equipped with LMPT or UMPTa/b/e or UMPTga board.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile country code

Indicates the mobile country code of the external E-UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.
Mobile network code

Indicates the mobile network code of the external E-UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.
eNodeB ID

Indicates the eNodeB ID of the external E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the cell ID of the external E-UTRAN cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details, see 3GPP TS 36.413.
Downlink EARFCN

Indicates the DL EARFCN of the external E-UTRAN cell. For details, see 3GPP TS 36.104.
Uplink EARFCN indicator

Indicates whether to configure the uplink E-UTRA absolute radio frequency channel number (EARFCN) for the external E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.
Uplink EARFCN

Indicates the uplink E-UTRA absolute radio frequency channel number (EARFCN) of the external E-UTRAN cell. If the value of this parameter is not specified, the default uplink EARFCN is used, which is calculated based on the downlink EARFCN. For details about this parameter, see 3GPP TS 36.104. This parameter applies only to LTE FDD and LTE TDD.
Physical cell ID

Indicates the physical cell identifier (PCI) of the external E-UTRAN cell. For details, see 3GPP TS 36.331.
Tracking area code

Indicates the tracking area code (TAC) of the external E-UTRAN cell. Two TAC values 0x0000(0) and 0xFFFE(65534) are reserved according to the protocol and will not be used in future versions. Therefore, do not use 0 or 65534 as a TAC value in TAC planning or configuration.
Cell name

Indicates the name of the external E-UTRAN cell.
External E-UTRAN Cell Slave Band

Indicates slave frequency bands of an external E-UTRAN cell. If the operating frequency of an external E-UTRAN cell belongs to multiple frequency bands, the downlink frequency of the frequency band with the highest priority is configured by the DlEarfcn parameter, and frequency bands with other priorities are configured by the EutranExternalCellSlaveBand parameter and added in descending order based on frequency band priorities. The frequency band priorities of an external E-UTRAN cell are determined in network planning. It is recommended that the frequency bands supporting UEs that comply with 3GPP TS 36.331 V8.16.0, 3GPP TS 36.331 V9.1.0, 3GPP TS 36.331 V10.5.0, or a later vision be configured as slave frequency bands.
Roaming Area Handover Indicator

Indicates whether the external cell can be selected for handovers during roaming. This parameter is set to NO(No) by default.

If this parameter is set to YES(Yes), this external cell can be selected for handovers during roaming. If this parameter is set to NO(No), this external cell cannot be selected for handovers during roaming.

If the PLMN of the external cell is included in the SPID-based handover-allowable HPLMN list or this parameter is set to YES(Yes), this external cell can be selected as a target cell for handovers.

In the boundaries of roaming areas and non-roaming areas, you are advised to set this parameter to YES(Yes) to ensure that cells in roaming areas can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.
Specified Cell Flag

Indicates whether the external cell is a specified-service cell. Set this parameter based on the operator policy. If this parameter is set to SPECSERCELL, the external cell is a specified-service cell, and non-WBB UEs cannot be transferred to this cell. If this parameter is set to MBBSERCELL, the external cell is a cell that provides only MBB services, and WBB UEs cannot be transferred to this cell. If this parameter is set to NONE, the external cell is a common cell, and both WBB and MBB UEs can be transferred to this cell. The value of this parameter must be the same as that of the SpecifiedCellFlag parameter in the Cell MO associated to the external cell. This parameter applies only to LTE FDD and LTE TDD.
ANR flag

Indicates whether an external cell is automatically detected by ANR. This parameter applies only to LTE FDD and LTE TDD.
High Speed Flag

Indicates whether the adjacent cell is a high-speed or ultra-high-speed cell. The high-speed or ultra-high-speed attribute of an adjacent cell is modified through the X2 interface setup or update message of an X2 interface connecting an adjacent eNodeB. This parameter applies only to LTE FDD.
Uplink Frequency Offset

Indicates the frequency offset of the PRB uplink central frequency to the uplink frequency. This parameter takes effect only when UlEarfcnCfgInd is set to CFG(Configure). Otherwise, the offset is calculated based on the uplink/downlink symmetric system. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.
Downlink Frequency Offset

Indicates the frequency offset of the PRB downlink central frequency to the downlink frequency. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.
NB-IoT Cell Flag

Indicates whether an external E-UTRAN cell is an NB-IoT cell. When this parameter is set to TRUE, the external cell is an NB-IoT cell. When this parameter is set to FALSE, the external cell is not an NB-IoT cell. This parameter applies only to NB-IoT.
NCL Update Mode

Indicates the external-cell update mode.

MFBI_UPDATE_MODE: If this switch is off, the secondary band for the external cell can be set by operators, updated through the X2 interface, and updated based on UE measurements. If this switch is on, the secondary band for the external cell can be set by operators and updated through the X2 interface, but it cannot be updated based on UE measurements. After the secondary band for the external cell is updated through the X2 interface, the eNodeB automatically turns on the MFBI_UPDATE_MODE switch.
Support eMTC Flag

Indicates the mode of an external cell, which can be LTE only, eMTC only, and LTE/eMTC dual-mode. This parameter can be queried on the neighboring eNodeB providing the external cell, through an X2 interface. This parameter applies only to LTE FDD and LTE TDD.
Aggregation Attribute

Indicates the aggregation attributes of an external E-UTRAN cell.

MASTER_PLMN_RESERVED_FLAG: Indicates whether to reserve the primary PLMN ID of the external E-UTRAN cell. If this option is selected, the primary PLMN ID of the external E-UTRAN cell is reserved and this cell cannot be selected as a target cell for UEs served by the primary PLMN. If this option is deselected, this cell can be selected as a target cell for UEs served by the primary PLMN. This option applies only to LTE FDD and LTE TDD.
Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. The policy specified by this parameter also applies to the EutranExternalCellPlmn MOs under this MO. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
