CellMultiCarrUniSch

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMultiCarrUniSch

Description

The CellMultiCarrUniSch MO consists of parameters used to configure multi-carrier joint scheduling in a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST CELLMULTICARRUNISCH

Use this command to query the configurations of cell-level parameters for the Multi-Carrier Joint Scheduling feature.
MOD CELLMULTICARRUNISCH

Use this command to modify cell-level parameter configurations for the Multi-Carrier Joint Scheduling feature.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.
A1 RSRP Thld for Non-CA Connected-Mode UE SCS

Indicates the RSRP threshold for event A1 related to the smart carrier selection function for non-CA UEs in connected mode. When this parameter is set to 0, this function is disabled. If this parameter is set to a value other than 0, smart carrier selection based on virtual grids is triggered when the measured RSRP exceeds this threshold. This parameter applies only to LTE FDD and LTE TDD.
SCell Deactivation Waiting Timer

Indicates the length of the SCell deactivation waiting timer. If this parameter is set to 0, the timer is not used. If this parameter is set to a non-zero value, the timer is used. The timer starts when the downlink buffer for a UE that has an SCell activated is cleared. The eNodeB deactivates the SCell for the UE when the buffer has been empty for a period longer then the length of this timer. This parameter applies only to LTE FDD and LTE TDD.
Mobility Adapt Cov DL Efficiency Thld

Indicates the downlink spectral efficiency threshold used in coverage threshold adaptation for mobility management. When the MOBILITY_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the downlink spectral efficiency is lower than the value of this parameter, coverage-based inter-frequency handovers will still be triggered for UEs. This parameter applies only to LTE FDD and LTE TDD.
Mobility Adapt Cov UL Efficiency Thld

Indicates the uplink spectral efficiency threshold used in coverage threshold adaptation for mobility management. When the MOBILITY_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the uplink spectral efficiency is lower than the value of this parameter, coverage-based inter-frequency handovers will still be triggered for UEs. This parameter applies only to LTE FDD and LTE TDD.
SCC Adapt Cov RSRP Thld

Indicates the RSRP threshold for adding an SCell when SCell coverage threshold adaptation is enabled. If the SCC_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the number of carriers aggregated for a UE has not reached the maximum, cells whose measured RSRP values are higher than the value of this parameter can be added as SCells. This parameter applies only to LTE FDD and LTE TDD.
