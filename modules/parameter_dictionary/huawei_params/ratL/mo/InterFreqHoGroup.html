InterFreqHoGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-InterFreqHoGroup

Description

An InterFreqHoGroup MO consists of parameters related to inter-frequency handover. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CnOperatorHoCfg MO:
    • The sum of the value of InterFreqHoA2ThdRsrp in the InterFreqHoGroup MO and the value of TddIfHoA2ThdRsrpOffset in the CnOperatorHoCfg MO cannot be greater than the value of InterFreqHoA1ThdRsrp in the InterFreqHoGroup MO.
    • The sum of the value of InterFreqHoA2ThdRsrp in the InterFreqHoGroup MO and the value of FddIfHoA2ThdRsrpOffset in the CnOperatorHoCfg MO cannot be greater than the value of InterFreqHoA1ThdRsrp in the InterFreqHoGroup MO.
    • The sum of the value of A3InterFreqHoA2ThdRsrp in the InterFreqHoGroup MO and the value of TddIfHoA2ThdRsrpOffset in the CnOperatorHoCfg MO cannot be greater than the value of A3InterFreqHoA1ThdRsrp in the InterFreqHoGroup MO.
    • The sum of the value of A3InterFreqHoA2ThdRsrp in the InterFreqHoGroup MO and the value of FddIfHoA2ThdRsrpOffset in the CnOperatorHoCfg MO cannot be greater than the value of A3InterFreqHoA1ThdRsrp in the InterFreqHoGroup MO.
  • Relation with the Cell MO:
    • LocalCellId in an InterFreqHoGroup MO must have been set in the associated Cell MO.
  • Relation with the CellQciPara MO:
    • The InterFreqHoGroup MO referenced by the InterFreqHoGroupId parameter in the CellQciPara MO must be configured.
    • When the NsaDcInterFreqHoGroupId parameter in the CellQciPara is not 255, the InterFreqHoGroup MO referenced by the NsaDcInterFreqHoGroupId parameter in the CellQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Interfreq handover group ID

Indicates the ID of the parameter group related to inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A1A2 hysteresis

Indicates the hysteresis of events A1/A2 for triggering inter-frequency measurement. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A1A2 time to trigger

Indicates the time-to-trigger of event A1/A2 for triggering inter-frequency measurement.

When detecting that the signal quality in the serving cell meets the triggering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of wrong handovers. In summary, it helps prevent unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.
A4A5 Based Interfreq A1 RSRP Threshold

Indicates the RSRP threshold for event A1 of A4/A5-based inter-frequency handover. When the measured RSRP value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
A4A5 Based Interfreq A1 RSRQ Threshold

Indicates the RSRQ threshold for event A1 of A4/A5 based inter-frequency handover.

When the measured RSRQ value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
A4A5 Based Interfreq A2 RSRP Threshold

Indicates the RSRP threshold for event A2 of A4/A5-based inter-frequency handover.

When the measured RSRP value is below the threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
A4A5 Based Interfreq A2 RSRQ Threshold

Indicates the RSRQ threshold for event A2 of A4/A5-based inter-frequency handover.

When the measured RSRQ value is below this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Interfreq handover hysteresis

Indicates the hysteresis for inter-frequency measurements. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability. This parameter applies only to LTE FDD and LTE TDD.
CoverageBased Interfreq RSRP threshold

Indicates the RSRP threshold for triggering a coverage-based inter-frequency measurement event. When the measured RSRP value exceeds this threshold, an inter-frequency measurement report will be sent. Distance-based handover, uplink power-control-based handover, SPID-based handover back to the home PLMN, and speech-quality-based handover also use this parameter as the RSRP threshold for triggering an inter-frequency measurement event. This parameter applies to A4 and A5 measurements. This parameter applies only to LTE FDD and LTE TDD.
CoverageBased Interfreq RSRQ threshold

Indicates the RSRQ threshold for triggering a coverage-based inter-frequency measurement event. When the measured RSRQ value exceeds this threshold, an inter-frequency measurement report will be sent. Distance-based handover, uplink power-control-based handover, SPID-based handover back to the home PLMN, and speech-quality-based handover also use this parameter as the RSRQ threshold for triggering an inter-frequency measurement event. This parameter applies to A4 and A5 measurements. This parameter applies only to LTE FDD and LTE TDD.
Interfreq HandOver Time to Trigger

Indicates the time-to-trigger for event A4 for the inter-frequency handover. When detecting that the signal quality in at least one neighboring cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of wrong handovers. In summary, it helps prevent unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.
Load Based Interfreq RSRP threshold

Indicates the RSRP threshold for event A4 related to load-based inter-frequency handovers. When the measured RSRP value exceeds this threshold, event A4 is reported. This parameter also specifies the RSRP threshold for inter-frequency event A4 related to frequency-priority-based handovers, service-based handovers, handovers of low-mobility UEs, or redirection of high-mobility UEs. This parameter applies only to LTE FDD and LTE TDD.
Load Based Interfreq RSRQ threshold

Indicates the RSRQ threshold for event A4 related to load-based inter-frequency handovers. When the measured RSRQ value exceeds this threshold, event A4 is reported. This parameter also specifies the RSRQ threshold for inter-frequency event A4 related to frequency-priority-based handovers, service-based handovers, handovers of low-mobility UEs, or redirection of high-mobility UEs. This parameter applies only to LTE FDD and LTE TDD.
Freq Priority Based Interfreq A1 RSRP threshold

Indicates the RSRP threshold for frequency-priority-based inter-frequency measurement event A1.

When the measured RSRP value exceeds this threshold, an event A1 report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Freq Priority Based Interfreq A1 RSRQ threshold

Indicates the RSRQ threshold for frequency-priority-based inter-frequency measurement event A1.

When the measured RSRQ value exceeds this threshold, an event A1 report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A3 offset

Indicates the offset for event A3 associated with inter-frequency handover. This parameter determines the border between the serving cell and the neighboring cell. If the parameter is set to a large value, an inter-frequency handover is performed only when the signal quality of the neighboring cell is significantly better than that of the serving cell and other triggering conditions are met. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
A3 based interfreq A1 RSRP threshold

Indicates the RSRP threshold for event A1 of A3-based inter-frequency handover.

When the measured RSRP value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
A3 based Interfreq A2 RSRP threshold

Indicates the RSRP threshold for event A2 of A3-based inter-frequency handover.

When the measured RSRP value is less than this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Freq Priority Based Interfreq A2 RSRP threshold

Indicates the RSRP threshold for frequency-priority-based inter-frequency measurement event A2.

If the measured RSRP value is less than this threshold, an event A2 report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Freq Priority Based Interfreq A2 RSRQ threshold

Indicates the RSRQ threshold for inter-frequency measurement event A2.

When the measured RSRQ value is below this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
InterFreq MLB A1A2 RSRP Threshold

Indicates the RSRP threshold for the A1/A2 event that is used for location-based UE priority selection during MLB that is based on the number of UEs performing downlink data transmission. If cell center users are preferably selected, the UEs whose RSRP values are higher than this threshold and reports A1 events are selected to perform MLB. If cell edge users are preferably selected, the UEs whose RSRP values are lower than this threshold and reports A2 events are selected to perform MLB. This parameter applies only to LTE TDD.
Interfreq A5 RSRP threshold 1

Indicates the RSRP threshold 1 in the serving cell of event A5 for triggering inter-frequency handovers.

When the measured RSRP in the serving cell is smaller than the value of this parameter and the RSRP or RSRQ in the neighboring cell is higher than the value of InterFreqHoA4ThdRsrp or InterFreqHoA4ThdRsrq, the UE reports event A5. This parameter applies only to LTE FDD and LTE TDD.
Interfreq A5 RSRQ threshold 1

Indicates the RSRQ threshold 1 in the serving cell of event A5 for triggering inter-frequency handovers.

When the measured RSRQ in the serving cell is smaller than the value of this parameter and the RSRP or RSRQ in the neighboring cell is higher than the value of InterFreqHoA4ThdRsrp or InterFreqHoA4ThdRsrq, the UE reports event A5. This parameter applies only to LTE FDD and LTE TDD.
Service-Request based handover A4 RSRP threshold

Indicates the RSRP threshold used to trigger event A4 report for service request-based inter-frequency handovers.

If the RSRP of the neighboring cell exceeds this threshold, the UE reports event A4.

A small value of this parameter leads to a high probability of triggering handovers. A large value of this parameter leads to a low probability of triggering handovers. This parameter applies only to LTE FDD and LTE TDD.
Service-Request based handover A4 RSRQ threshold

Indicates the RSRQ threshold used to trigger event A4 report for service request-based inter-frequency handovers.

If the RSRQ of the neighboring cell exceeds this threshold, the UE reports event A4.

A small value of this parameter leads to a high probability of triggering handovers. A large value of this parameter leads to a low probability of triggering handovers. This parameter applies only to LTE FDD and LTE TDD.
MLB Inter-Freq Handover A5 Threshold1 RSRP

Indicates the RSRP threshold 1 of the serving cell for event A5 related to inter-frequency measurements for MLB. If the measured RSRP of the serving cell is lower than the MlbInterFreqHoA5Thd1Rsr parameter value and the measured RSRP of a neighboring cell is higher than the InterFreqLoadBasedHoA4ThdRsrp parameter value, the UE reports event A5. This parameter applies only to LTE FDD and LTE TDD.
MLB Inter-Freq Handover A5 Threshold1 RSRQ

Indicates the RSRQ threshold 1 of the serving cell for event A5 related to inter-frequency measurements for MLB. If the measured RSRQ of the serving cell is lower than the MlbInterFreqHoA5Thd1Rsr parameter value and the measured RSRQ of a neighboring cell is higher than the InterFreqLoadBasedHoA4ThdRsrq parameter value, the UE reports event A5. This parameter applies only to LTE FDD and LTE TDD.
Uplink Bad Quality Handover A4 Offset

Indicates the offset of the A4 threshold of the target cell related to UL-quality-based inter-frequency handovers to the A4 threshold related to coverage-based inter-frequency handovers. This offset applies to RSRP- and RSRQ-based A4 thresholds. The actual threshold for event A4 is equal to the sum of the threshold for event A4 related to coverage-based inter-frequency handovers and the UlBadQualHoA4Offset parameter value. If the sum is less than the 3GPP-defined minimum value or greater than the 3GPP-defined maximum value, the 3PGG-defined minimum or maximum value is delivered, respectively. This parameter applies only to LTE FDD and LTE TDD.
A3 Based Interfreq A1 RSRQ Threshold

Indicates the RSRQ threshold for event A1 of A3-based inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
A3 Based Interfreq A2 RSRQ Threshold

Indicates the RSRQ threshold for event A2 of A3-based inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
Ul High Traffic Handover A4 Threshold of RSRP

Indicates the RSRP threshold for triggering inter-frequency measurement event A4 during handovers for uplink heavy traffic-based MLB. When the measured RSRP exceeds the threshold specified by this parameter, inter-frequency measurement event A4 is reported. This parameter applies only to LTE TDD.
Ul High Traffic Handover A4 Threshold of RSRQ

Indicates the RSRQ threshold for triggering inter-frequency measurement event A4 during handovers for uplink heavy traffic-based MLB. When the measured RSRQ exceeds the threshold specified by this parameter, inter-frequency measurement event A4 is reported. This parameter applies only to LTE TDD.
Inter-Freq A1 RSRP Threshold for CE

Indicates the RSRP threshold for event A1 related to coverage-based A4- or A5-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRP value exceeds the threshold, such a UE sends a measurement report. In CE mode B, the actual RSRP threshold is equal to the value of this parameter minus 10 dB. If the actual RSRP threshold is less than the minimum value, the minimum value takes effect. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq A2 RSRP Threshold for CE

Indicates the RSRP threshold for event A2 related to coverage-based A4- or A5-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRP value is less than the threshold, such a UE sends a measurement report. In CE mode B, the actual RSRP threshold is equal to the value of this parameter minus 10 dB. If the actual RSRP threshold is less than the minimum value, the minimum value takes effect. This parameter applies only to LTE FDD and LTE TDD.
MM Load Steering A4 RSRP Threshold

Indicates the RSRP threshold used to trigger report of inter-frequency measurement event A4 for massive MIMO load steering. When the measured RSRP value exceeds this threshold, an inter-frequency measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq A4 RSRP Threshold for CE

Indicates the RSRP threshold for event A4 related to coverage-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRP value exceeds the threshold, such a UE sends a measurement report. In CE mode B, the actual RSRP threshold is equal to the value of this parameter minus 10 dB. If the actual RSRP threshold is less than the minimum value, the minimum value takes effect. This parameter is also used as the RSRP threshold 2 for event A5. This parameter applies only to LTE FDD and LTE TDD.
A3-based Inter-Freq HO A2 RSRP Thld for CE Mode A

Indicates the RSRP threshold for event A2 related to coverage-based A3-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRP value is less than the threshold, such a UE sends a measurement report. In CE mode B, the actual RSRP threshold is equal to the value of this parameter minus 10 dB. If the actual RSRP threshold is less than the minimum value, the minimum value takes effect. This parameter applies only to LTE FDD and LTE TDD.
A3-based Inter-Freq HO A2 RSRQ Thld for CE Mode A

Indicates the RSRQ threshold for event A2 related to coverage-based A3-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRQ value is less than the threshold, such a UE sends a measurement report. This parameter also takes effect for UEs in CE mode B. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq HO A2 RSRQ Threshold for CE Mode A

Indicates the RSRQ threshold for event A2 related to coverage-based A4- or A5-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRQ value is less than the threshold, such a UE sends a measurement report. This parameter also takes effect for UEs in CE mode B. This parameter applies only to LTE FDD and LTE TDD.
Inter-Freq HO A4 RSRQ Threshold for CE Mode A

Indicates the RSRQ threshold for event A4 related to coverage-based inter-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRQ value exceeds the threshold, such a UE sends a measurement report. This parameter also takes effect for UEs in CE mode B. This parameter is also used as the RSRQ threshold 2 for event A5. This parameter applies only to LTE FDD and LTE TDD.
