InterRatHoGeranGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-InterRatHoGeranGroup

Description

An InterRatHoGeranGroup MO consists of parameters related to inter-RAT handover to GERAN. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in an InterRatHoGeranGroup MO must have been set in the associated Cell MO.
  • Relation with the CellQciPara MO:
    • The InterRatHoGeranGroup MO referenced by the InterRatHoGeranGroupId parameter in the CellQciPara MO must be configured.
    • The InterRatHoGeranGroup MO referenced by the NsaDcGeranHoGroupId parameter in the CellQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
InterRAT handover to GERAN group ID

Indicates the ID of the QCI-specific parameter group related to inter-RAT handover to GERAN. This parameter applies only to LTE FDD and LTE TDD.
GERAN handover hysteresis

Indicates the hysteresis for event B1 related to inter-RAT handover to GERAN. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers or handover decision errors. This parameter applies only to LTE FDD and LTE TDD.
CoverageBased GERAN trigger threshold

Indicates the RSSI threshold for event B1 related to coverage-based inter-RAT handover to GERAN.

A UE sends a measurement report related to event B1 to the eNodeB when the RSSI in at least one GERAN cell reaches this threshold and other triggering conditions are met. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
GERAN time to trigger

Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-GERAN handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.
Load Service Based Geran EventB1 trigger threshold

Indicates the RSSI threshold for event B1 related to load- or service-based inter-RAT handover to GERAN.

When the measured RSSI value exceeds this threshold, a B1 measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.
