CellMMAlgo

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMMAlgo

Description

The CellMMAlgo MO consists of parameters used to configure algorithms related to Massive MIMO.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell, eUCellSectorEqm, and BfAnt MOs:
    • When the CellActiveState parameter in the Cell MO is set to CELL_ACTIVE(Active) and the BeamGainLimitSwitch parameter in the CellMMAlgo MO is set to ON(On), the BfAnt MO associated with the WeightNO parameter in the eUCellSectorEqm MO bound to the cell must exist, and the CoverageScenario parameter in the BfAnt MO must not be set to SCENARIO_3(HBW 45 Degree, VBW 8 Degree), SCENARIO_4(HBW 25 Degree, VBW 8 Degree), SCENARIO_8(HBW 25 Degree, VBW 17 Degree), SCENARIO_9(HBW 15 Degree, VBW 17 Degree), or SCENARIO_13(HBW 15 Degree, VBW 35 Degree).
  • Relation with the Cell, CellAlgoSwitch, and SectorSplitCell MOs:
    • The MU_PAIRING_MCS_EXACT_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only when the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R and the SectorSplitCell MO associated with the Cell MO is not configured and the MuBfSwitch option of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
    • The PRECISE_PAIRING_OPT_SW option of the PreciseMubfOptSwitch parameter in the CellMMAlgo MO can be selected only when the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R and the SectorSplitCell MO associated with the Cell MO is not configured and the MuBfSwitch option of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the Cell, SectorSplitCell, and CellUlschAlgo MOs:
    • When the FddTddInd parameter in a Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 32T32R, and no SectorSplitCell MO is configured for the Cell MO, the EnhancedVmimoSwitch parameter in the CellUlschAlgo MO can be set to ON only if the PUSCH_RECEIVE_ENH_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO is selected.
  • Relation with the Cell and SectorSplitCell MOs:
    • When the FddTddInd and TxRxMode parameters in the Cell MO are set to CELL_TDD and 64T64R or 32T32R respectively and the SectorSplitCell MO associated with the Cell MO is not configured, the PUSCH_RECEIVE_ENH_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected.
  • Relation with the Cell, SectorSplitCell, CellAlgoSwitch, SRSCfg, and CellBf MOs:
    • The MaxBfRankPara parameter in the CellBf MO can be set to FOUR_LAYER_BF only when all of the following conditions are met: 1. The FddTddInd parameter in the Cell MO is set to CELL_TDD. 2. The TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R. 3. The SectorSplitCell MO associated with the Cell MO is not configured. 4. The CrsPortNum parameter in the Cell MO is set to CRS_PORT_2. 5. The MM_ANT_SEL_ENH_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO is selected. 6. The TM9Switch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected. 7. The SrsResExpansionSwitch parameter in the SRSCfg MO is set to OFF.
  • Relation with the Cell and CellAlgoSwitch MOs:
    • The MM_ACCESS_CONTROL_OPT_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and the AcBarAlgoSwitch parameter in the CellAlgoSwitch MO is set to ACBAR_SWITCH_DYNAMIC or the EABAlgoSwitch option of the MTCCongControlSwitch parameter in the CellAlgoSwitch MO is selected.
    • The DL_CLUSTER_PAIRING_SW option of the PreciseMubfOptSwitch parameter in the CellMMAlgo MO under a Cell MO can be selected only when all the following conditions are met: The TxRxMode parameter in this Cell MO is set to 64T64R or 32T32R, the MuBfSwitch and SplitSDMASwitch options of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO under this Cell MO are selected and deselected, respectively, and the PRECISE_PAIRING_OPT_SW option of the PreciseMubfOptSwitch parameter in the CellMMAlgo MO is deselected.
    • The MubfTbsForecastPairLyrThld parameter in the CellMMAlgo MO under a Cell MO is not equal to zero only when all the following conditions are met: (1) The FddTddInd in the Cell is set to CELL_TDD; (2) The TxRxMode parameter in this Cell MO is set to 64T64R or 32T32R; (3) The MuBfSwitch options of the MuBfAlgoSwitch parameter in the CellAlgoSwitch MO under this Cell MO is selected.
  • Relation with the Cell, CellAlgoSwitch, ENodeBAlgoSwitch, and UeCooperationPara MOs:
    • The MM_ANT_SEL_ENH_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only if the FddTddInd and TxRxMode parameters in the Cell MO are set to CELL_TDD and 64T64R or 32T32R respectively, the BfSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO is selected, and the UeSRSAntSelectCtrlSwitch option of the CompatibilityCtrlSwitch parameter in the ENODEBALGOSWITCH MO is deselected, the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UECOOPERATIONPARA MO is selected.
  • Relation with the Cell and CellBf MOs:
    • The UE_STATUS_BASED_MLB_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only if the FddTddInd parameter in the Cell MO is set to CELL_TDD and the SRS_LMT_AND_ABN_UE_IDENT_SW option of the UeIdentificationSwitch parameter in the CellBf MO is selected.
  • Relation with the Cell, CellBf, SectorSplitCell, ENodeBAlgoSwitch, CellAlgoSwitch, and CellBfMimoParaCfg MOs:
    • The TM8_PORT_ALLOC_OPT_SWITCH option of the MMAlgoOptSwitch parameter in the CellMMAlgo MO can be selected only when all of the following conditions are met: 1. The FddTddInd parameter in the Cell MO is set to CELL_TDD. 2. The TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R. 3. The SectorSplitCell MO associated with the Cell MO is not configured. 4. The Tm8PairingOptSwitch parameter in the CellBf MO is set to ON. 5. The UeSRSAntSelectCtrlSwitch option of the CompatibilityCtrlSwitch parameter in the ENodeBAlgoSwitch MO is deselected. 6. The FakeAntSelIdentificationSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO is selected. 7. The NON_AS_UE_MAX_BF_RANK_CTRL_SW option of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO is selected.
  • Relation with the Cell, SectorSplitCell, and CellBf MOs:
    • The MUBF_PWR_ENH_SW option of the PreciseMubfOptSwitch parameter in the CellMMAlgo MO can be selected only when all of the following conditions are met: 1. The FddTddInd parameter in the Cell MO is set to CELL_TDD. 2. The TxRxMode parameter in the Cell MO is set to 64T64R. 3. The SectorSplitCell MO associated with the Cell MO is not configured. 4. The MubfPowerNormAdptFactor parameter in the CellBf MO is set to 0. 5. The MovingUeMuBfScheme parameter in the CellBf MO is not set to HEAVY_LOAD_SCHEME, LIGHT_LOAD_SCHEME, or SPLIT_SDMA_SCHEME.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.
Beam Gain Limit Switch

Indicates the beam gains of massive MIMO. If this parameter is set to ON(On) and the number of admitted UEs is smaller than or equal to three, the eNodeB forcibly performs MIMO for these UEs. If this parameter is set to ON(On) and the number of admitted UEs is greater than three, the eNodeB adaptively changes the transmission mode for these UEs. If this parameter is set to OFF(Off), the eNodeB adaptively performs beamforming or MIMO for UEs. This parameter takes effect only when the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE(MIMO_BF_ADAPTIVE) or TxD_BF_ADAPTIVE(TxD_BF_ADAPTIVE). This parameter applies only to LTE TDD.
Massive MIMO Algorithm Optimization Switch

Indicates whether to enable massive MIMO optimization algorithms.

MUBF_UE_POWER_FIXED_SWITCH: Indicates whether to assign fixed power to paired UEs. This option takes effect only in massive MIMO scenarios. If this option is selected, the base station assigns fixed power to paired UEs. If this option is deselected, the base station does not assign fixed power to paired UEs. This option applies only to LTE TDD.

PUSCH_RECEIVE_ENH_SWITCH: Indicates whether to enable enhanced PUSCH reception. If this option is selected, enhanced PUSCH reception is enabled. If this option is deselected, enhanced PUSCH reception is disabled. This option takes effect only in massive MIMO scenarios. It is recommended that this option be selected in massive MIMO scenarios. This option applies only to LTE TDD.

MU_PAIRING_MCS_EXACT_SWITCH: Indicates whether to enable optimized MCS index selection for UE pairing. If this option is selected, optimized MCS index selection for UE pairing is enabled. If this option is deselected, the baseline MCS index selection algorithm is used. This option takes effect only in massive MIMO scenarios. It is recommended that this option be selected in massive MIMO scenarios. This option applies only to LTE TDD.

MUBF_ABNORMAL_UE_OPT_SWITCH: Indicates whether to enable optimization for UEs of extremely low efficiency. If this option is selected, the base station identifies UEs of extremely low efficiency and transfers such UEs to inter-frequency cells. If this option is deselected, the optimization is disabled. This option applies only to LTE TDD.

DL_RB_ASSIGN_OPT_SWITCH: Indicates whether to enable optimized downlink RB allocation. If this option is selected, optimized downlink RB allocation is enabled. If this option is deselected, optimized downlink RB allocation is disabled. This option takes effect only in massive MIMO scenarios. This option applies only to LTE TDD.

MU_PAIRING_VOLTE_SWITCH: Indicates whether VoLTE UEs can be paired for MU beamforming. If this option is selected, VoLTE UEs can be paired for MU beamforming. If this option is deselected, VoLTE UEs cannot be paired for MU beamforming. This option applies only to LTE TDD.

MM_DL_SCH_AND_MCS_OPT_SWITCH: Indicates whether to enable downlink scheduling and MCS optimization in massive MIMO scenarios. If this option is selected, the optimization is enabled. If this option is deselected, the optimization is disabled. This option applies only to LTE TDD.

SRS_SDNR_SWITCH: Indicates whether to enable the SRS space-domain noise reduction (SDNR) function. If this option is selected, the SRS SDNR function is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

MM_ANT_SEL_ENH_SWITCH: Indicates whether to enable SRS transmission by four antennas in turn. If this option is selected, this function is enabled. If this option is deselected, this function is disabled. This option takes effect only in massive MIMO scenarios. This option applies only to LTE TDD.

MM_ACCESS_CONTROL_OPT_SWITCH: Indicates whether to enable access control optimization to ensure that the user-experienced rate reaches the target value during major events in massive MIMO scenarios. If this option is selected, access control optimization takes effect. If this option is deselected, access control optimization does not take effect. This option applies only to LTE TDD.

TM9_HIGH_ORDER_PAIRING_SWITCH: Indicates whether to enable downlink TM9 high-order pairing for massive MIMO. If this option is selected, TM9 high-order pairing is enabled. If this option is deselected, TM9 high-order pairing is disabled. This option applies only to LTE TDD.

DL_CORR_UE_PAIRING_OPT_SWITCH: Indicates whether to enable UE pairing optimization based on downlink correlation in MU beamforming scenarios. If this option is selected, this function takes effect. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

UE_STATUS_BASED_MLB_SWITCH: Indicates whether to enable MLB between massive MIMO common cells and non-massive MIMO cells or between massive MIMO common cells and massive MIMO split cells based on UE status identification results. If this option is selected, this type of MLB takes effect. If this option is deselected, this type of MLB does not take effect. This option applies only to LTE TDD.

TM8_PORT_ALLOC_OPT_SWITCH: Indicates whether to enable port allocation optimization for massive MIMO TM8 pairing. If this option is selected, port allocation optimization for massive MIMO TM8 pairing is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

ABN_UE_PAIRING_PROT_SWITCH: Indicates whether to enable multi-UE pairing protection for defective UEs. If this option is selected, this function is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.
Massive MIMO Initial Delta CQI

Indicates the initial CQI adjustment value for UEs paired for massive MIMO. This parameter applies only to LTE TDD.
Adaptive Split SDMA SRS Limit UE Prop Thld

Indicates the threshold of the proportion of UEs with insufficient SRSs in a cell for adaptation between entry to and exit from split SDMA in massive MIMO scenarios. If the SplitSdmaAdaptionPeriod parameter is set to FORCE_SPLIT_SDMA, split SDMA takes effect regardless of the setting of this parameter. This parameter applies only to LTE TDD.
Adaptive Split SDMA TM9 UE Proportion Thld

Indicates the threshold of the proportion of closed-loop TM9 UEs in a cell for triggering adaptation between entry to and exit from split SDMA in massive MIMO scenarios. If the SplitSdmaAdaptionPeriod parameter is set to FORCE_SPLIT_SDMA, split SDMA takes effect regardless of the setting of this parameter. This parameter applies only to LTE TDD.
Split SDMA UE Identification SRS SINR Thld

Indicates the SRS SINR threshold for identifying UEs available for split SDMA in massive MIMO scenarios. A UE is identified as available for split SDMA only if the SRS SINR of the UE is smaller than this threshold for a specific number of consecutive times. This parameter applies only to LTE TDD.
MM VMIMO Outer-Loop Initial Offset

Indicates an offset used to determine the initial outer-loop SINR adjustment value after uplink MU-MIMO pairing in massive MIMO cells or in 8T8R cells with the space-domain-preferred pairing algorithm enabled. This parameter applies only to LTE TDD.
MUBF SINR Thld Ofs Before SRS Balance

Indicates the offset to the SINR threshold before SRS balancing for downlink MU beamforming pairing in cells. A UE can participate in MU beamforming pairing only if the SINR of the UE reaches the sum of the SINR threshold before SRS balancing and this offset. This parameter applies only to LTE TDD.
Beamforming Weight Type

Indicates the massive MIMO beamforming weight type. If this parameter is set to PEBF, the PE beamforming weight selection algorithm is used. If this parameter is set to ADAPT, the adaptive weight selection algorithm is used. This parameter applies only to LTE TDD.
Precise MUBF Optimization Switch

Indicates whether to enable the precise MU beamforming optimization algorithm.

PRECISE_PAIRING_OPT_SW: Indicates whether to enable the precise UE pairing optimization algorithm. If this option is selected, the eNodeB implements a downlink multi-user pairing process aimed to improve spectral efficiency in massive MIMO cells and selects an MCS index more suitable for paired UEs. This improves the downlink cell throughput. If this option is deselected, the precise MU beamforming optimization algorithm is disabled. This option applies only to LTE TDD.

ABN_WBB_UE_PRI_SUPPRESS_SW: Indicates whether to enable the suppression of the downlink scheduling priority for abnormal WBB UEs in massive MIMO cells. If this option is selected, there is a lower probability for abnormal WBB UEs to be scheduled. If this option is deselected, the suppression does not take effect. This option applies only to LTE TDD.

DL_CLUSTER_PAIRING_SW: Indicates whether the downlink cluster pairing algorithm takes effect. If this option is selected, the downlink cluster pairing algorithm is used for massive MIMO cells. If this option is deselected, the cluster pairing algorithm is disabled. This option applies only to LTE TDD.

MUBF_PWR_ENH_SW: Indicates whether to enable MU beamforming power enhancement in massive MIMO scenarios. If this option is selected, the power of antennas with weak power is enhanced based on the antenna power difference without affecting the orthogonality among paired UEs. If this option is deselected, the original orthogonalization remains unchanged. This option applies only to LTE TDD.
BF Gain Thld for Saturated UE Identification

Indicates the beamforming gain threshold for identifying UEs with saturated power in massive MIMO scenarios. This parameter applies only to LTE TDD.
Outloop Thld for Saturated UE Identification

Indicates the SU beamforming outer-loop threshold for identifying UEs with saturated power in massive MIMO scenarios. The default value 127 indicates that the power saturation avoidance algorithm does not take effect. This parameter applies only to LTE TDD.
Split SDMA Beam RSRP Isolation Threshold

Indicates the RSRP isolation threshold for split SDMA UEs in massive MIMO scenarios. If the RSRP isolation between the target beams of two UEs is greater than this threshold, split SDMA can be performed for the two UEs. If the RSRP isolation between the target beams of two UEs is less than or equal to this threshold, split SDMA cannot be performed for the two UEs. This parameter applies only to LTE TDD.
Massive MIMO Param Intelligent Selection Sw

Indicates whether to enable intelligent selection for massive MIMO parameters.

BIG_EVENT_THLD_LEARN_SW: Indicates whether to enable massive MIMO big event threshold learning. If this option is selected, massive MIMO big event threshold learning is enabled. If this option is deselected, massive MIMO big event threshold learning is disabled. In this case, the default user number threshold for triggering massive MIMO big event assurance is used. This option applies only to LTE TDD.

BIG_EVENT_PDCCH_CAPC_ADAPT_SW: Indicates whether to enable PDCCH capacity adaptation in massive MIMO big event scenarios. If this option is selected, PDCCH capacity adaptation is enabled. If this option is deselected, PDCCH capacity adaptation is disabled. This option applies only to LTE TDD.

BIG_EVENT_AUTO_ASSURANCE_SW: Indicates whether to enable automatic assurance for massive MIMO big events. If this option is selected, automatic assurance for massive MIMO big events is enabled. If this option is deselected, automatic assurance for massive MIMO big events is disabled. This option applies only to LTE TDD.

BIG_EVENT_NON_GBR_BUNDLING_SW: Indicates whether to enable non-GBR packet bundling in big event scenarios. If this option is selected and the NonGbrBundlingSwitch option of the DlSchSwitch parameter in the CellAlgoSwitch MO is also selected, non-GBR packet bundling is enabled in big event scenarios. If the NonGbrBundlingSwitch option is deselected, non-GBR packet bundling cannot be enabled. If this option is deselected, non-GBR packet bundling is disabled in big event scenarios. This option takes effect only if the BIG_EVENT_AUTO_ASSURANCE_SW option is selected. This option applies only to LTE TDD.
MUBF TBS Forecast Pairing Layer Thld

Indicates the threshold of the number of pairing layers for TBS prediction. If the number of downlink pairing layers of a cell is greater than or equal to this threshold, TBS prediction takes effect. If this parameter is set to 0, TBS prediction does not take effect. If UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the ServiceMode parameter in the eNodeBResModeAlgo MO must also be selected for TBS prediction to take effect. This parameter applies only to LTE TDD.
MM Param Intel Selection DL User Exp Thld

Indicates the downlink experience threshold for intelligent massive MIMO parameter selection. This parameter applies only to LTE TDD.
MM Param Intel Selection UL User Exp Thld

Indicates the uplink experience threshold for intelligent massive MIMO parameter selection. This parameter applies only to LTE TDD.
Low SRS SINR UE Pairing Layer Thld

Indicates the threshold of the number of MU beamforming pairing layers for low-SRS-SINR UE pairing optimization. If this parameter is set to 0 or 1, low-SRS-SINR UE pairing optimization does not take effect. If this parameter is set to a value greater than 1, the optimization takes effect and this parameter indicates the maximum number of pairing layers for low-SRS-SINR UEs. This parameter applies only to LTE TDD.
DL SUBF PRB Usage Restriction Thld

Indicates the threshold for enabling downlink PRB usage restriction for SU beamforming UEs. If this parameter is set to 100, downlink PRB usage restriction for SU beamforming UEs does not take effect. If this parameter is not set to 100, this function takes effect. In this case, if the PRB usage of SU beamforming UEs is greater than this threshold, this function is enabled and the eNodeB restricts the scheduling of SU beamforming UEs. This parameter applies only to massive MIMO or 8T adaptive MU beamforming scenarios. This parameter applies only to LTE TDD.
Large-Packet Thld Upper Limit

Indicates the upper limit of the large packet threshold for enabling user-experience-based scheduling enhancement and optimization. If this parameter is set to 0, the function does not take effect. If both the DlSchPriIncreaseUeProp parameter in the CellDlschAlgo MO and this parameter are not set to 0, the function takes effect. In this case, this parameter indicates the upper limit of the number of TTIs for determining whether a UE is a large-packet UE. This parameter applies only to massive MIMO scenarios. This parameter applies only to LTE TDD.
Abnormal UE Packet Delay Thld

Indicates whether to enable downlink scheduling interval protection for defective UEs. If this parameter is set to a non-zero value, this function is enabled. If this parameter is set to 0, this function is disabled. This parameter applies only to LTE TDD.
Active UE Number Thld

Indicates the threshold for the number of UEs to be scheduled used in the function of downlink scheduling interval protection for defective UEs. A larger value of this parameter indicates a higher probability that the function takes effect in heavy-traffic scenarios. A smaller value of this parameter indicates a higher probability that the function takes effect in light-traffic scenarios. This parameter applies only to LTE TDD.
