IpServiceQos

+-NE
  +-eNodeBFunction
    +-IpServiceQos

Description

An IpServiceQos MO consists of parameters related to the mapping between DSCPs of IP packets and QoS policies. After receiving an IP packet with a specific DSCP, the eNodeB automatically puts the IP packet into a priority queue based on the mapping and adopts the QoS parameters related to the priority queue to schedule the IP packet.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    eNodeBFunction
  • Relation with the QosPolicy MO:
    • If the FirQosPolicyId parameter in an IpServiceQos MO is set to a value other than 255, ensure that the value is the same as the QosPolicyId parameter value set in a QosPolicy MO.
    • If the QosPolicyTimeSwitch parameter in an IpServiceQos MO is set to ON, ensure that the SecQosPolicyId parameter value in this IpServiceQos MO is the same as the QosPolicyId parameter value set in a QosPolicy MO.
    • If QosPolicyTimeSwitch in an IpServiceQos MO is set to ON, both TrafficType in a QosPolicy MO associated with FirQosPolicyId in the IpServiceQos MO and TrafficType in another QosPolicy MO associated with SecQosPolicyId in the IpServiceQos MO must be set to VIDEO.
    • If QosPolicyTimeSwitch in an IpServiceQos MO is set to ON, PriQueueId in a QosPolicy MO associated with FirQosPolicyId in the IpServiceQos MO must be set to the same value as PriQueueId in another QosPolicy MO associated with SecQosPolicyId in the IpServiceQos MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Differentiated Services Code Point

Indicates a differentiated services code point (DSCP) for IP packets. Different types of traffic can be assigned different DSCPs within the range of 1 to 63. This parameter applies only to LTE FDD and LTE TDD.
Traffic Description

Indicates a service description. This parameter applies only to LTE FDD and LTE TDD.
QoS Policy Time Switch

Indicates whether to use different rate measures in two phases for QoS purposes. This switch is required only for video services, not for other services. If this switch is turned on for video services, the eNodeB provides an initial acceleration in the first phase and a normal rate guarantee in the second phase. If this switch is turned off, the eNodeB provides a normal rate guarantee from the start. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.
First QoS Policy Identity

Indicates the ID of the QoS policy used in the first phase of a video service. If the QosPolicyTimeSwitch parameter is set to ON, the QoS policy is used in the initial phase of the service; if this parameter is set to OFF, the QoS policy is used across the entire process of the service. The FirQosPolicyId parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). In this case, the system sets FirQosPolicyId to 255 by default, which is an invalid value. This parameter applies only to LTE FDD and LTE TDD.
First QoS Policy Time Length

Indicates the time length of the first phase in which the eNodeB provides initial acceleration for video services. When the QosPolicyTimeSwitch parameter is set to ON, the FirQosPolicyTimeLength parameter must be set to a value greater than 0. A larger value indicates longer acceleration time. When the QosPolicyTimeSwitch parameter is set to OFF, the FirQosPolicyTimeLength parameter does not need to be set, and the default value 0 is used. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.
Second QoS Policy Identity

Indicates the QoS policy to be used after initial acceleration is complete for a video service. If the QosPolicyTimeSwitch parameter is set to ON, set the SecQosPolicyId parameter to an existing QosPolicyId value in the range of 0 to 127. If the QosPolicyTimeSwitch parameter is set to OFF, the SecQosPolicyId parameter does not need to be set. In this case, the system sets SecQosPolicyId to 255 by default, which is an invalid value. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.
Application Range

Indicates the scope of functions to which a QoS policy is applicable.

VIDEO_AND_DWNLD_RATE_CTRL_SW: If this option is selected, the QoS policy is applicable to DSCP-based video service rate adaptation and busy-hour download rate control. If this option is deselected, the QoS policy is not applicable to DSCP-based video service rate adaptation and busy-hour download rate control. This option applies only to LTE FDD and LTE TDD.

PREALLOCATION_SW: If this option is selected, the QoS policy is applicable to DSCP-based preallocation. If this option is deselected, the QoS policy is not applicable to DSCP-based preallocation. This option applies only to LTE FDD and LTE TDD.
