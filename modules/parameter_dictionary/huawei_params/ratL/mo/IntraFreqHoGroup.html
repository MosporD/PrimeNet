IntraFreqHoGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-IntraFreqHoGroup

Description

An IntraFreqHoGroup MO consists of parameters related to intra-frequency handover. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 36.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell MO:
    • LocalCellId in an IntraFreqHoGroup MO must have been set in the associated Cell MO.
  • Relation with the CellQciPara MO:
    • The IntraFreqHoGroup MO referenced by the IntraFreqHoGroupId parameter in the CellQciPara MO must be configured.
    • The IntraFreqHoGroup MO referenced by the NsaDcIntraFreqHoGroupId parameter in the CellQciPara MO must be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.
Intrafreq handover group ID

Indicates the ID of the parameter group related to intra-frequency handover. This parameter applies only to LTE FDD and LTE TDD.
Intrafreq handover hysteresis

Indicates the hysteresis for intra-frequency and inter-frequency handover event A3. This parameter decreases frequent event triggering due to radio signal fluctuations and reduces the probability of handover decision errors and ping-pong handovers. A larger value of this parameter results in a lower probability. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Intrafreq handover offset

Indicates the offset for event A3. If the parameter is set to a large value, an intra-frequency handover is performed only when the signal quality of the neighboring cell is significantly better than that of the serving cell and other triggering conditions are met. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
Intrafreq handover time to trigger

Indicates the time-to-trigger for intra-frequency and inter-frequency handover event A3.

When the entering condition for intra-frequency or inter-frequency handover event A3 is met, the UE does not immediately report event A3 to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports, preventing unnecessary handovers. As a result, the average number of handovers and the number of incorrect handovers decrease. This parameter applies only to LTE FDD and LTE TDD.
High Speed Intra Frequency A3 Time To Trigger

Indicates the time-to-trigger for event A3 related to intra-frequency handovers for high-speed UEs in high-speed cells.

When the entering condition for intra-frequency handover event is met, the UE does not immediately report event A3 to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger. This option applies only to LTE FDD and LTE TDD.
Intra-Freq A2 RSRP Threshold for CE

Indicates the RSRP threshold for triggering event A2 related to coverage-based intra-frequency handover for eMTC UEs in coverage enhancement mode. If the measured RSRP value is less than this parameter value, such a UE sends a measurement report. This parameter applies only to LTE FDD and LTE TDD.
Mode A Adjustment A1 RSRP Threshold

Indicates the threshold for triggering event A1 based on which UEs switch the coverage mode to coverage enhancement (CE) mode A at coverage level 1. This parameter applies only to LTE FDD and LTE TDD.
Mode A Adjustment A2 RSRP Threshold

Indicates the threshold for triggering event A2 based on which UEs switch the coverage mode from normal coverage mode to coverage enhancement (CE) mode A or switch the coverage level from coverage level 0 to coverage level 1. This parameter applies only to LTE FDD and LTE TDD.
Mode B Adjustment A2 RSRP Threshold

Indicates the threshold for triggering event A2 based on which UEs switch the coverage mode to coverage enhancement (CE) mode B. This parameter applies only to LTE FDD and LTE TDD.
Normal Coverage Adjustment A1 RSRP Threshold

Indicates the threshold for triggering event A1 based on which UEs switch the coverage mode to normal coverage mode or coverage level 0. This parameter applies only to LTE FDD and LTE TDD.
Intra-Freq HO A2 RSRQ Threshold for CE Mode A

Indicates the RSRQ threshold for event A2 related to coverage-based A3-based intra-frequency handovers for UEs in coverage enhancement (CE) mode A. If the measured RSRQ value is less than the threshold, such a UE sends a measurement report. This parameter also takes effect for UEs in CE mode B. This parameter applies only to LTE FDD and LTE TDD.
eMTC Handover A3 Time to Trigger

Indicates the time-to-trigger of event A3 related to intra-frequency and inter-frequency handovers for eMTC UEs. When the entering condition for the event is met, the UE does not immediately report event A3. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, preventing undesirable handovers. As a result, the average number of handovers and the number of incorrect handovers decrease. This parameter applies only to LTE FDD and LTE TDD.
