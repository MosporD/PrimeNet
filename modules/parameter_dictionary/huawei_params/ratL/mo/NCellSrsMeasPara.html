NCellSrsMeasPara

+-NE
  +-eNodeBFunction
    +-Cell
      +-NCellSrsMeasPara

Description

The NCellSrsMeasPara MO consists of parameters related to cell-level sounding reference signal (SRS) automatic neighboring cell measurement. The SRS automatic neighboring cell measurement function automatically selects neighboring cells for the local cell and performs SRS measurements. This reduces manual configurations.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the Cell and CellAlgoSwitch MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD and the UL_ICS_SWITCH option under the UlIcSwitch parameter is selected, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO must be set to ON.
    • When the NbCellFlag parameter in the Cell MO is set to TRUE and the UlJointReceptionSwitch option of the UplinkCompSwitch parameter in the associated CellAlgoSwitch MO is selected, the NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in the associated NCellSrsMeasPara MO must be selected.
  • Relation with the Cell MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the HighSpeedFlag parameter in the associated Cell MO is set to LOW_SPEED.
    • The NCellSrsTimeMeasSwitch option of the NCellMeasSwitch parameter in the NCellSrsMeasPara MO must be deselected if the DlBandWidth parameter in the Cell MO is set to CELL_BW_N25
  • Relation with the CellAlgoSwitch MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the UlHetnetCompOnUlRsrpSw option of the UplinkCompSwitch parameter in the associated CellAlgoSwitch MO is deselected.
    • The SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO must be set to ON(On) if the InterCellDmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected.
  • Relation with the CellUlschAlgo MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the UlHoppingType parameter in the associated CellUlschAlgo MO is set to HOPPING_OFF.
  • Relation with the SRSCfg MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO must be deselected if the SrsCfgInd, FddSrsCfgMode, and SrsSubframeCfg parameters in the associated SRSCfg MO are set to BOOLEAN_TRUE, DEFAULTMODE, and a value among SC3, SC4, or SC5, respectively.
  • Relation with the CellCspcPara MO:
    • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the CellCspcSwitch parameter in the associated CellCspcPara MO is set to OFF.
  • Relation with the CellPcAlgo MO:
    • The SrsPcStrategy parameter in the CellPcAlgo MO can be set to SRSPC_SINR_ADAPTIVE only if the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO is set to ON.
  • Relation with the Cell, CellPcAlgo, and SectorSplitCell MOs:
    • The SrsPcStrategy parameter in the CellPcAlgo MO can be set to SRSPC_SINR_ADAPTIVE only if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, no SectorSplitCell MO is configured for the Cell MO, and the NCellSrsTimeMeasSwitch option of the NCellMeasSwitch parameter in the NCellSrsMeasPara MO is selected.
  • Relation with the SpectrumCloud MO:
    • When the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO is set to OFF, the SpectrumCloudSwitch parameter can be set to LTE_NR_UPLINK_SPECTRUM_SHR.
  • Relation with the SpectrumCloud and Cell MOs:
    • If the FddTddInd parameter in a Cell MO is set to CELL_FDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is set to LTE_NR_SPECTRUM_SHR, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO under this Cell MO must be set to OFF.
  • Relation with the Cell, CellAlgoSwitch, PUSCHCfg, CellUlIcAlgo, and SectorSplitCell MOs:
    • When the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and no SectorSplitCell MO is configured for the Cell MO, the MASSIVE_MIMO_SRS_IC_SW option of the SrsIcSwitch parameter in the CellUlIcAlgo MO can be selected only if the SrsTimeMeasSwitch option of the SrsAlgoSwitch parameter in the CellAlgoSwitch MO is selected, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO is set to ON, the NCellSrsTimeMeasSwitch option of the NCellMeasSwitch parameter in the NCellSrsMeasPara MO is selected, the GroupHoppingEnabled in the PUSCHCfg MO is set to BOOLEAN_FALSE, and the SeqHoppingEnabled parameter in the PUSCHCfg MO is set to BOOLEAN_FALSE.
  • Relation with the Cell and SectorSplitCell MOs:
    • If the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TxRxMode parameter in the Cell MO is set to 64T64R or 32T32R, and SectorSplitCell MO is configured for the Cell MO, the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO must not be set to ON.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell Id

Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
SRS Auto Neighbour Cell Measurement Switch

Indicates whether a cell supports SRS automatic neighboring cell measurements. If this parameter is set to ON(On), the UlHetnetCompOnUlRsrpSw and UlHetnetCompManualNcellCfgSw options of the UplinkCompSwitch parameter do not take effect. This parameter applies only to LTE FDD and LTE TDD.
SRS or DMRS Auto Neighbour Cell Measurement A3 Offset

Indicates the offset for events related to the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter requires better signal quality of a neighboring cell for sending measurement reports of the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. SRS automatic neighboring cell measurement applies to LTE FDD and LTE TDD. DMRS neighboring cell measurement applies only to LTE FDD.
Neighbouring Cell Measurement Switch

Indicates whether to enable neighboring cell measurement algorithms.

NcellDmrsMeasSwitch: Indicates whether to enable DMRS measurement for neighboring cells. If this option is selected, DMRS measurement is enabled for neighboring cells. If this option is deselected, DMRS measurement is disabled for neighboring cells. When this option is selected, the setting of the SrsAutoNCellMeasSwitch parameter does not take effect. This option applies only to LTE FDD and NB-IoT.

NcellSrsTimeMeasSwitch: Indicates whether to enable time-domain measurement of SRSs from neighboring cells. If this option is selected, the eNodeB supports time-domain measurement of SRSs from neighboring cells. If this option is deselected, the eNodeB does not support time-domain measurement of SRSs from neighboring cells and supports only frequency-domain measurement of the SRSs. This option takes effect only if measurement of SRSs from neighboring cells is triggered. Such measurement can be triggered by UL CoMP or automatic measurement of SRSs from neighboring cells (controlled by the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO). This option applies only to LTE TDD.
