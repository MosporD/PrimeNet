UtranExternalCellPlmn

+-NE
  +-eNodeBFunction
    +-UtranExternalCell
      +-UtranExternalCellPlmn

Description

A UtranExternalCellPlmn MO consists of the parameters related to an additional PLMN ID for an external UTRAN cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    UtranExternalCell
  • Relation with the UtranExternalCell MO:
    • A maximum of three UtranExternalCellPlmn MOs can be configured for each Utran external cell MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD UTRANEXTERNALCELLPLMN

Use this command to add an additional PLMN ID for an external UTRAN cell.
LST UTRANEXTERNALCELLPLMN

Use this command to list an additional PLMN ID for an external UTRAN cell.
RMV UTRANEXTERNALCELLPLMN

Use this command to remove one or more PLMN IDs of an external UTRAN cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile country code

Indicates the mobile country code of the external UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Mobile network code

Indicates the mobile network code of the external UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
RNC ID

Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
RNC cell ID

Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.
Share mobile country code

Indicates the mobile country code of the external UTRAN cell that is shared among multiple operators.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
Share mobile network code

Indicates the mobile network code of the external UTRAN cell that is shared among multiple operators.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.
