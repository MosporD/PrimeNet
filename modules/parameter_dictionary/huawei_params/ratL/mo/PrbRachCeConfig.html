PrbRachCeConfig

+-NE
  +-eNodeBFunction
    +-Cell
      +-Prb
        +-PrbRachCeConfig

Description

A PrbRachCeConfig MO consists of cell-level coverage-level-specific parameters related to the PRACH configuration for PRB carriers of NB-IoT cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Prb
  • Relation with the UlGuardBandCfg MO:
    • The subcarrier index value indicated in the value of the PrachSubcarrierOffset parameter in a PrbRachCeConfig MO must not be lower than the value of the LowFreqGuardBand parameter in the associated UlGuardBandCfg MO. In addition, the sum of the subcarrier index value, the value of HighFreqGuardBand in the associated UlGuardBandCfg MO, and the value of the PrachSubcarrierNumber parameter in the PrbRachCeConfig MO must not exceed 48.
    • The subcarrier index indicated in the value of the EdtPrachSubcarrierOffset parameter in the PrbRachCeConfig MO must not be less than the value of the LowFreqGuardBand parameter in the UlGuardBandCfg MO for the corresponding cell; in addition, the sum of the subcarrier index value, the value of the HighFreqGuardBand parameter in the UlGuardBandCfg MO, and 12 (the number of EDT PRACH subcarriers) must not be not greater than 48.
  • Relation with the Cell MO:
    • If the COVERAGE_LEVEL_2 option of the CoverageLevelType parameter in the Cell MO is selected, the PrachSubcarrierNumber parameter in the PrbRachCeConfig MO with any coverage level corresponding to all carriers cannot be set to SC_NUM_48.
    • When the NbCellFlag parameter in a Cell MO associated by the LocalCellId parameter in the PrbRachCeConfig MO is set to TRUE(TRUE) and the CellActiveState parameter in this Cell MO is set to CELL_ACTIVE, the PrachRepetitionCount parameter in the PrbRachCeConfig MO under this Cell MO must meet the following condition: When COVERAGE_LEVEL_1 in the CoverageLevelType parameter in the Cell MO is set to 1, the PrachRepetitionCount parameter value for CoverageLevel of 0 must be less than that for CoverageLevel of 1.
    • When the NbCellFlag parameter in a Cell MO associated by the LocalCellId parameter in the PrbRachCeConfig MO is set to TRUE(TRUE) and the CellActiveState parameter in this Cell MO is set to CELL_ACTIVE, the PrachRepetitionCount parameter in the PrbRachCeConfig MO under this Cell MO must meet the following condition: When COVERAGE_LEVEL_2 in the CoverageLevelType parameter in the Cell MO is set to 1, the PrachRepetitionCount parameter value for CoverageLevel of 1 must be less than that for CoverageLevel of 2.
    • If the value of the CellActiveState parameter in the Cell MO for a cell is CELL_ACTIVE and the NbCellFlag parameter in this Cell MO is set to TRUE, the EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter in the PrbRachCeConfig MO with a specific coverage level under any Prb MO of the cell can be selected only when the option indicating that coverage level is selected in the CoverageLevelType parameter in this Cell MO.
  • Relation with the Cell and RACHCfg MOs:
    • When the NbCellFlag parameter in a Cell MO is set to TRUE and the PrachStartTimeCfgInd parameter in the RACHCfg MO is set to CFG, the value of the PrachTransmissionPeriod parameter with a specific coverage level must not be lower than the value of the PrachStartTime parameter with the same coverage level in the PrbRachCeConfig MO associated with the same LocalCellId.
  • Relation with the RACHCfg, Prb, and CellAlgoSwitch MOs:
    • The actual duration corresponding to the value of the PrachTransmissionPeriod parameter in the PrbRachCeConfig MO for a PRB at a certain coverage level must not be less than the PRACH transmission duration for this coverage level of the PRB. The details are as follows: If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 66DOT7(66.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 5.6. If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 266DOT7(266.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 6.4.
    • The actual duration corresponding to the value of the PrachTransmissionPeriod parameter in the PrbRachCeConfig MO for a PRB at a certain coverage level must not be less than the PRACH transmission duration for this coverage level of the PRB. The details are as follows: If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 66DOT7(66.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 5.6. If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 266DOT7(266.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 6.4.
    • The actual duration corresponding to the value of the PrachTransmissionPeriod parameter in the PrbRachCeConfig MO for a PRB at a certain coverage level must not be less than the PRACH transmission duration for this coverage level of the PRB. The details are as follows: If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 66DOT7(66.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 5.6. If the NbCyclicPrefixLength parameter in the RACHCfg MO referenced by the PRB MO through the LocalCellId parameter is set to 266DOT7(266.7us), the PRACH transmission duration for the corresponding coverage level is the result of the value of the PrachRepetitionCount parameter for the anchor carrier multiplied by 6.4.
  • Relation with the Cell and CellEdtConfig MOs:
    • The EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter in the PrbRachCeConfig MO can be selected for a cell only when the NbCellFlag parameter in the Cell MO is set to TRUE and the EDT_SWITCH option of the EdtAlgoSwitch parameter in the CellEdtConfig MO is selected for the cell.
  • Relation with the Prb and Cell MOs:
    • If the AnchorCarrierFlag parameter in a PRB MO is set to TRUE, the MtNprachRangeMsg3InitTone parameter in the PrbRachCeConfig MO with the highest coverage level under this Prb MO cannot be set to ZERO_12TONE, ZERO_6TONE, ZERO_3TONE, or ZERO_1TONE.
    • If the MtNprachRangeMsg3InitTone parameter is set to ZERO_1TONE, ZERO_3TONE, ZERO_6TONE, or ZERO_12TONE in a PrbRachCeConfig MO under a PRB MO in which the AnchorCarrierFlag parameter is set to FALSE, the PrachProbabilityForAnchor parameter in the PrbRachCeConfig MO with the highest coverage level under the associated PRB MO in which the AnchorCarrierFlag parameter is set to TRUE cannot be set to ZERO.
  • Relation with the CellAlgoSwitch MO:
    • If the 100KM_CELL_RADIUS_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO is selected, the PrachSubcarrierNumber parameter in the PrbRachCeConfig MOs for all coverage levels and all carriers in the NB-IoT cell can only be set to SC_NUM_12.
  • Relation with the Cell and Prb MOs:
    • If the AnchorCarrierFlag parameter in a Prb MO is TRUE and the EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter in a PrbRachCeConfig MO with that coverage level under this Prb MO is also selected, or if an option (indicating a coverage level) of the PrachCoverageLevelType parameter in a Prb MO is selected and the AnchorCarrierFlag parameter in the Prb MO is FALSE and the EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter in a PrbRachCeConfig MO with that coverage level under this Prb MO is also selected, the following parameter setting requirements must be met for this Prb at the corresponding coverage level: (1) The PrachSubcarrierNumber parameter cannot be set to SC_NUM_36 or SC_NUM_48. (2) The sum of the subcarrier index indicated in the value of the PrachSubcarrierOffset parameter and the subcarrier quantity indicated in the value of the PrachSubcarrierNumber parameter must be equal to the subcarrier index indicated in the value of the EdtPrachSubcarrierOffset parameter, or the sum of the subcarrier index indicated in the value of the EdtPrachSubcarrierOffset parameter and 12 must be equal to the subcarrier index indicated in the value of the PrachSubcarrierOffset parameter.
    • If the value of CellActiveState in a Cell MO is CELL_ACTIVE, the EDT_RANDOM_ACCESS_SW option of PrachAlgoSw cannot be selected in the PrbRachCeConfig MOs set for a specific coverage level under the Prb MOs in which AnchorCarrierFlag is set to FALSE when the following conditions are met: (1) The option of PrachCoverageLevelType indicating that specific coverage level is deselected in the Prb MOs in which AnchorCarrierFlag is set to FALSE. Alternatively, the option of PrachCoverageLevelType indicating that specific coverage level is selected in a Prb MO in which AnchorCarrierFlag is set to FALSE but PrachProbabilityForAnchor is set to ONE in the PrbRachCeConfig MO set for that specific coverage level under the Prb MO in which AnchorCarrierFlag is set to TRUE. (2) The EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter is selected in the PrbRachCeConfig MO under the Prb MO in which AnchorCarrierFlag is set to TRUE.
    • If the value of CellActiveState in a Cell MO is CELL_ACTIVE, the EDT_RANDOM_ACCESS_SW option of PrachAlgoSw cannot be selected in the PrbRachCeConfig MOs set for a specific coverage level under the Prb MO in which AnchorCarrierFlag is set to TRUE when the following conditions are met: (1) The option of PrachCoverageLevelType indicating that specific coverage level is selected in a Prb MO in which AnchorCarrierFlag is set to FALSE and PrachProbabilityForAnchor is set to a value other than ONE in the PrbRachCeConfig MO set for that specific coverage level under the Prb MO in which AnchorCarrierFlag is set to TRUE. (2) The EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter is deselected in the PrbRachCeConfig MOs under the Prb MOs in which AnchorCarrierFlag is set to FALSE.
  • Relation with the Cell, CellAlgoSwitch, and Prb MOs:
    • If the 100KM_CELL_RADIUS_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO is selected for a cell, any option (indicating a coverage level) of the PrachCoverageLevelType parameter in any Prb MO of this cell and the AnchorCarrierFlag parameter in the Prb MO is FALSE and the EDT_RANDOM_ACCESS_SW option of the PrachAlgoSw parameter in the PrbRachCeConfig MO with that coverage level under that Prb MO cannot be both selected, and the AnchorCarrierFlag parameter in the Prb MO is TRUE and the option in the PrachAlgoSw parameter in the PrbRachCeConfig MO under that Prb cannot be selected.
  • Relation with the CellAlgoSwitch and PrbUlSchCeAlgo MOs:
    • The MtNprachRangeMsg3InitTone parameter in the PrbRachCeConfig MO can only be set to ONE_1TONE if the MULTITONE_SWITCH option of the NbCellAlgoSwitch parameter in the CellAlgoSwitch MO is deselected, the UlInitialTransRptCount parameter in the PrbUlSchCeAlgo MO is set to a value indicating a repetition count greater than or equal to 2, or the PrachRepetitionCount parameter in the PrbRachCeConfig MO is set to REP_32, REP_64, or REP_128.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.
PRB ID

Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.
Coverage Level

Indicates the coverage level associated with RACH parameters. The value COVERAGE_LEVEL_0 indicates coverage level 0, value COVERAGE_LEVEL_1 indicates coverage level 1, and value COVERAGE_LEVEL_2 indicates coverage level 2. This parameter applies only to NB-IoT.
PRACH Transmission Period

Indicates the PRACH transmission period. If the PrachStartTimeCfgInd parameter in the RACHCfg MO is set to CFG, this parameter can be set to different values for different coverage levels of a cell. Ensure that PRACH resources for different coverage levels do not overlap. Otherwise, the random access success rate is affected. This parameter applies only to NB-IoT.
PRACH Subcarrier Offset

Indicates the frequency-domain PRACH subcarrier offset. If the number of the PRACH subcarriers at each coverage level of a PRB is not 48, it is required that this parameter be set to the same value for all coverage levels of the PRB or the sum of the value of this parameter and the number of PRACH subcarriers be the same for all coverage levels of the PRB. Otherwise, the NB-IoT cell cannot work. This parameter applies only to NB-IoT.
PRACH Repetition Count

Indicates the number of repeated preamble transmissions at the corresponding coverage level. Set this parameter to a proper value. Otherwise, PRACH resources for different coverage levels overlap or RA-RNTIs of different coverage levels conflict, leading to cell activation failures. This parameter is valid only for anchor carriers. This parameter applies only to NB-IoT.
PRACH Start Time

Indicates the PRACH start time. If the PrachStartTimeCfgInd parameter in the RACHCfg MO is set to CFG, the eNodeB can set different PRACH start time for different coverage levels of a cell, but the interval between these time points must be 40 ms or longer. Otherwise, the cell cannot be activated. This parameter applies only to NB-IoT.
PRACH Detection Threshold

Indicates the level of the PRACH detection threshold. The value LEVEL_0 indicates a low level, and the value LEVEL_3 indicates a high level. If the PrachRepetitionCount parameter in the CellRachCECfg MO is set to 1, 2, 4, or 128, LEVEL_3 always takes effect regardless of the parameter setting. This parameter applies only to NB-IoT.
PRACH Probability for Anchor

Indicates the probability of random access on the anchor carrier for UEs supporting multi-carrier access. If this parameter is set to ONE, UEs perform random access only on an anchor carrier. This parameter is valid only for anchor carriers. This parameter applies only to NB-IoT.
PRACH Subcarrier Number

Indicates the number of subcarriers used for the PRACH. The number of PRACH subcarriers for EDT is not configurable. Currently, the number is fixed at 12. This parameter applies only to NB-IoT.
PRACH CBRA Subcarrier Number

Indicates the number of PRACH subcarriers for contention-based random access. This parameter does not take effect if the CFRA_WITH_SR_SWITCH option of the NbCellAlgoExtSwitch parameter in the CellAlgoExtSwitch MO is deselected. This parameter applies only to NB-IoT.
Backoff High Load Threshold

Indicates the high load threshold for backoff in a cell at a coverage level. When the load of the cell is greater than or equal to the value of this parameter, backoff takes effect or the backoff indicator (used to indicate backoff time) increases by one level. For details about backoff time, see 3GPP TS 36.321. The value 0 indicates that this parameter does not take effect. This parameter applies only to NB-IoT.
Backoff Low Load Threshold

Indicates the low load threshold for backoff in a cell at a coverage level. If the load of the cell is less than the value of this parameter, the backoff indicator (used to indicate backoff time) decreases by one level or backoff becomes invalid. For details about backoff time, see 3GPP TS 36.321. The value 0 indicates that this parameter does not take effect. This parameter applies only to NB-IoT.
EDT PRACH Subcarrier Offset

Indicates the frequency offset of the PRACH subcarrier for early data transmission (EDT). This parameter must be set to the same value for different coverage levels and the location of the PRACH subcarrier for EDT cannot overlap that of the common PRACH subcarrier. Otherwise, the NB-IoT cell cannot work. This parameter applies only to NB-IoT.
PRACH Algorithm Switch

Indicates whether to enable PRACH-related algorithms.

EDT_RANDOM_ACCESS_SW: Indicates whether random access for EDT is supported at the corresponding coverage level of the PRB. This parameter applies only to NB-IoT.
Multi-Tone UE NPRACH Range and MSG3 Init Tone

Indicates the factor for the range of dedicated NPRACH resources used by UEs with the multi-tone transmission capability and also indicates the initial number of tones used for the scheduling of Msg3. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
