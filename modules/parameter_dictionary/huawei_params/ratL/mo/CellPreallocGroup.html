CellPreallocGroup

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellPreallocGroup

Description

A CellPreallocGroup MO consists of a group of parameters related to preallocation for a cell. Preallocation parameter groups can be selected based on QCIs to meet different service requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellQciPara MO:
    • When the PreallocationParaGroupId parameter in the CellQciPara MO is not set to the invalid value 255, the CellPreallocGroup MO referenced by the PreallocationParaGroupId parameter in the CellQciPara MO must be configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD CELLPREALLOCGROUP

Use this command to add a preallocation parameter group for a cell.
LST CELLPREALLOCGROUP

Use this command to list one or all preallocation parameter groups.
MOD CELLPREALLOCGROUP

Use this command to modify a preallocation parameter group.
RMV CELLPREALLOCGROUP

Use this command to remove a preallocation parameter group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
Preallocation Parameter Group ID

Indicates the ID of the parameter group related to preallocations. This parameter applies only to LTE FDD and LTE TDD.
Preallocation Switch

Indicates whether to enable or disable preallocation for a bearer with a specified preallocation parameter group ID. If this parameter is set to ON(On), preallocation is enabled for this bearer. If this parameter is set to OFF(Off), preallocation is disabled for this bearer. This switch is a bearer-level switch and takes effect when the cell-level switch PreAllocationSwitch in the CellAlgoSwitch MO is turned on. This parameter applies only to LTE FDD and LTE TDD.
Smart Preallocation Switch

Indicates whether smart preallocation is enabled or disabled for a bearer with a specified preallocation parameter group ID when PreAllocationSwitch is turned on. If both PreAllocationSwitch and SmartPreAllocationSwitch are turned on, and SmartPreAllocationDuration is set to a value greater than 0, uplink smart preallocation is enabled; otherwise, uplink smart preallocation is disabled. This switch is a bearer-level switch and takes effect when the cell-level switch PreAllocationSwitch in the CellAlgoSwitch MO is turned on. This parameter applies only to LTE FDD and LTE TDD.
Minimal Period of Preallocation

Indicates the minimum interval between two preallocations, that is, the interval between two times that a UE is preallocated must be greater than or equal to this parameter value. When the DRX algorithm switch is on and the UE is in DRX mode, the actual value of this parameter cannot be greater than the DrxInactivityTimer parameter value. This parameter applies only to LTE FDD and LTE TDD.
Data Size of Preallocation

Indicates the data amount preallocated to each UE. This parameter applies only to LTE FDD and LTE TDD.
Smart Preallocation Duration

Indicates the duration of each smart preallocation. This parameter applies only to LTE FDD and LTE TDD.
