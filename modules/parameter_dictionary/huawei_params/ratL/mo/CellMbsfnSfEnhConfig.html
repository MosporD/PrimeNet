CellMbsfnSfEnhConfig

+-NE
  +-eNodeBFunction
    +-Cell
      +-CellMbsfnSfEnhConfig

Description

The CellMbsfnSfEnhConfig MO consists of the parameters related to one-frame and four-frame MBSFN subframe configurations in a cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    Cell
  • Relation with the CellDlschAlgo and Cell MOs:
    • If the SubframeAllocationMode parameter in the CellMbsfnSfEnhConfig MO under a Cell MO is set to ONE_FRAME or FOUR_FRAME, none of the options of the MbsfnSfCfg parameter in the CellDlschAlgo MO under this Cell MO can be selected, the FddTddInd parameter in the Cell MO must be set to CELL_FDD.
  • Relation with the SpectrumCloud MO:
    • The SubframeAllocationMode parameter in a CellMbsfnSfEnhConfig MO under a Cell MO can be set to ONE_FRAME or FOUR_FRAME only if the LTE_NR_SPECTRUM_SHR option of the SpectrumCloudSwitch parameter in the SpectrumCloud MO under this Cell MO is selected.
  • Relation with the CellMbsfnSfEnhConfig MO:
    • If the RadioFrameAllocPrd parameter in a CellMbsfnSfEnhConfig MO is set to N1, the RadioFrameAllocOfs parameter in this MO must be set to 0.
    • If the SubframeAllocationMode parameter in a CellMbsfnSfEnhConfig MO is set to FOUR_FRAME, the RadioFrameAllocPrd parameter in this MO must be set to N4 or a larger value.
    • If the RadioFrameAllocPrd parameter in a CellMbsfnSfEnhConfig MO is set to N2, the RadioFrameAllocOfs parameter in this MO cannot be set to a value greater than 1.
    • If the RadioFrameAllocPrd parameter in a CellMbsfnSfEnhConfig MO is set to N4, the RadioFrameAllocOfs parameter in this MO cannot be set to a value greater than 3.
  • Relation with the Cell and SpectrumCloud MOs:
    • The RadioFrameAllocOfs in the CellMbsfnSfEnhConfig must be set to 0 when the FddTddInd is set to CELL_FDD and the SpectrumCloudSwitch is set to LTE_NR_SPECTRUM_SHR and the SubframeAllocationMode is not set to NOT_CONFIG.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
Subframe Allocation Mode

Indicates whether one radio frame or four consecutive radio frames contain MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
One Frame Allocation

Indicates the MBSFN subframes allocated in one radio frame. For an FDD cell, the subframes that can be allocated for MBSFN in a radio frame are SF1, SF2, SF3, SF6, SF7, and SF8. These subframes are represented by bit 5 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. When you set this parameter, change the binary value into a decimal value and set this parameter to this decimal value. For details about how to use this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD. This parameter is valid only when the SubframeAllocationMode parameter in the CellMbsfnSfEnhConfig MO is set to ONE_FRAME.
Four Frame Allocation

Indicates the MBSFN subframes allocated in four consecutive radio frames. For an FDD cell, the subframes that can be allocated for MBSFN in each radio frame include SF1, SF2, SF3, SF6, SF7, and SF8. These subframes in the four radio frames are represented by bit 23 to bit 0 in sequence starting from the first radio frame. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. When you set this parameter, change the binary value into a decimal value and set this parameter to this decimal value. For details about how to use this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD. This parameter is valid only when the SubframeAllocationMode parameter in the CellMbsfnSfEnhConfig MO is set to FOUR_FRAME.
Radio Frame Allocation Period

Indicates the allocation period of the radio frames that contain MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
Radio Frame Allocation Offset

Indicates the frame offset used for MBSFN subframe configuration. This parameter and the RadioFrameAllocPrd parameter together determine the radio frame that contains MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.
