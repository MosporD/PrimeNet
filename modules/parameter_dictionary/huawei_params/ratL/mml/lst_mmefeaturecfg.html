List MME Feature Configuration (LST MMEFEATURECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of the MME features.

Note

None.

Parameters

ID Name Description
S1InterfaceId S1Interface ID

Meaning: Indicates the ID of an S1 interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List MME Feature Configuration:
LST MMEFEATURECFG:;
The result is shown as follows:
+++    0        2019-12-05 15:55:28
O&M    #806355278
%%LST MMEFEATURECFG:;%%
RETCODE = 0  Operation succeeded.

(Number of results = 1)

Output Description

Field Description

S1Interface ID

Indicates the ID of an S1 interface. This parameter applies only to LTE FDD and LTE TDD.

MME supporting MDT or not

Indicates whether the MME at the other end of the S1 interface supports Huawei-proprietary positioning procedures, which are included in minimization of drive tests (MDT). The value DISABLE indicates that the MME does not support the procedures and therefore the eNodeB cannot obtain UE location information from the MME through the procedures. The value ENABLE indicates the opposite. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates the control mode of the MmeFeatureCfg MO, which determines the control policies of operators and the SON functions in the MmeFeatureCfg MO. For an S1 interface that is manually set up, the parameter is set to MANUAL_MODE in the related MmeFeatureCfg MO. Operators, but not SON functions, can set this MO. For an S1 interface that is automatically set up, the parameter is set to AUTO_MODE in the related MmeFeatureCfg MO. SON functions can modify the configurations of the MO or remove the MO, but operators cannot set this MO directly. Operators can modify the parameter settings in this MO only by modifying the settings of related parameters in the associated S1 MO. This parameter applies only to LTE FDD and LTE TDD.
