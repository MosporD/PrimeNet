Modify Cell DL ICIC Algorithm Configuration (MOD CELLDLICIC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell DL ICIC algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandMode Downlink band division scheme

Meaning: Indicates the band division scheme used in downlink ICIC. The band division in the cell is adjusted according to the setting of this parameter so that the edge bands for neighboring cells do not overlap. If this parameter is set to INVALID, the cell does not distinguish center and edge bands. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MODE1(DL band division scheme No.1), MODE2(DL band division scheme No.2), MODE3(DL band division scheme No.3), INVALID(Invalid DL band division scheme)

Unit: None

Actual Value Range: MODE1, MODE2, MODE3, INVALID

MML Default Value: None

Recommended Value: If this parameter is not set to INVALID(Invalid DL band division scheme), it is recommended that this parameter be set to a different value from those of neighboring cells. If it is impossible for neighboring cells to use mutually different band modes, it is recommended that this parameter be set to the same value as that of a neighboring cell that has the weakest interference with the current cell.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlIcicUserAttrGfactorThd User Attribution Gfactor Threshold

Meaning: Indicates the G factor threshold for user attribute determination in downlink adaptive Inter-Cell Interference Coordination (ICIC). If downlink adaptive ICIC is enabled, the eNodeB selects cell edge users (CEUs) from the users whose G factors are less than this threshold. Determine the parameter value based on the distribution of UEs' modulation and coding scheme (MCS) indexes within an area so that about one third user are determined to be CEUs. For example, if an area is covered by 155 cells and the percentages of users whose MCS indexes are less than 6 and 7 are about 30% and 40%, respectively, you can set this parameter to 1. (The G factors corresponding to MCS indexes 6 and 7 are 0.5 dB and 1.45 dB, respectively.) The G factors corresponding to MCS indexes 0 to 28 are -5.65, -4.5, -3.55, -2.35, -1.5, -0.5, 0.5, 1.45, 2.45, 3.4, 3.7, 4.4, 5.4, 6.3, 7.25, 8.3, 8.95, 9.6, 10.15, 11.15, 12.1, 13.15, 14.05, 15.1, 16, 17, 18.1, 19, and 20.1, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -5~15

Unit: dB

Actual Value Range: -5~15

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to more users determined as CEUs in a cell and worse user experience of CEUs. A smaller value of this parameter leads to the opposites effects. It is recommended that this parameter be set to a value at which the proportion of CEUs to the total users in an area is approximately one third.

Applicable Mode: L-FDD, L-TDD
DlIcicNoiseUserRsrpThd Noise User RSRP Threshold

Meaning: Indicates the RSRP threshold used to determine noise-limited UEs on the network. If none of the neighboring-cell RSRP values included in A3 reports sent by a UE exceeds this threshold, the eNodeB does not consider these A3 reports when calculating interference. In most cases, the recommended RSRP threshold is -102. In tests on small-scale networks, this parameter can be set to other values. (The actual RSRP value is equal to -140 plus the GUI value of this parameter.) This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~97

Unit: None

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: 38

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more noise-limited UEs and fewer interference-limited UEs, and a smaller value produces the opposite effect. If the value is too large or too small, inter-cell interference calculation results are inaccurate, which lowers ICIC performance gains for cell edge users (CEUs). Therefore, you are not advised to change the parameter settings on commercial networks.

Applicable Mode: L-FDD, L-TDD
AIcIcPlusA3Offset AICIC Plus A3 Offset

Meaning: Indicates the A3 offset for enhanced AICIC. A large value of this parameter indicates a small number of cell edge users and a small value of this parameter indicates a large number of cell edge users. If the parameter value is increased, the probability of UEs reporting event A3 is reduced. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD cells.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, enhanced AICIC takes effect for a large number of cell edge users in the downlink and the downlink cell edge date rate increases greatly. A large value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
AIcicPlusPCAdjRange AICIC Plus Power Control Adjustment Range

Meaning: Indicates the cell power adjustment range in enhanced AICIC. This parameter must be set to a PDSCH PA value that is less than the value of the PaPcOff parameter. At most two values can be selected for the AIcicPlusPCAdjRange parameter. If one value is selected for the AIcicPlusPCAdjRange parameter, the power can be changed to the selected value and the PDSCH PA value specified by the PaPcOff parameter. If two values are selected for the AIcicPlusPCAdjRange parameter, the power can be changed to the selected two values and the PDSCH PA value specified by the PaPcOff parameter. This parameter must be set before the enhanced AICIC feature is enabled. This parameter applies only to LTE FDD.

GUI Value Range: DB_6_P_A(-6 dB), DB_4DOT77_P_A(-4.77 dB), DB_3_P_A(-3 dB), DB_1DOT77_P_A(-1.77 dB), DB0_P_A(0 dB), DB1_P_A(1 dB), DB2_P_A(2 dB), DB3_P_A(3 dB)

Unit: None

Actual Value Range: DB_6_P_A, DB_4DOT77_P_A, DB_3_P_A, DB_1DOT77_P_A, DB0_P_A, DB1_P_A, DB2_P_A, DB3_P_A

MML Default Value: None

Recommended Value: When the PaPcOff parameter is set to DB_4DOT77_P_A, the recommended setting is as follows: DB_6_P_A:ON, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB_3_P_A, the recommended setting is as follows: DB_6_P_A:ON, DB_4DOT77_P_A~1:ON, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB_1DOT77_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:ON, DB_3_P_A~2:ON, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB0_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:ON, DB_1DOT77_P_A~3:ON, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB1_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:ON, DB0_P_A~4:ON, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB2_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:ON, DB1_P_A~5:ON, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB3_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:ON, DB2_P_A~6:ON, DB3_P_A~7:OFF.

Parameter Relationship:

-Configuration constraints:

  • In the CellDlIcic MO, A maximum of two options of AIcicPlusPCAdjRange parameter can be selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If two values are selected for this parameter, cell power adjustment is frequent, the gains for hot spot cells are large, but radio signaling increases. If one value is selected for this parameter, cell power adjustment is less frequent, the gains for hot spot cells are reduced, but radio signaling decreases.

Applicable Mode: L-FDD

Example

To modify the configuration of the cell DL ICIC band division with the parameters as follows: Local cell ID: 0, Downlink band division scheme: MODE1, run the following command:
MOD CELLDLICIC: LocalCellId=0, BandMode=MODE1;
