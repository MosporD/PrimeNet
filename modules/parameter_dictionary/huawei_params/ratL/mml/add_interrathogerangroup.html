Add Parameter Group for Handover to GERAN (ADD INTERRATHOGERANGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a parameter group related to inter-RAT handover to GERAN.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoGeranGroupId InterRAT handover to GERAN group ID

Meaning: Indicates the ID of the QCI-specific parameter group related to inter-RAT handover to GERAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoGeranB1Hyst GERAN handover hysteresis

Meaning: Indicates the hysteresis for event B1 related to inter-RAT handover to GERAN. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers or handover decision errors. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The entering condition of event B1 is as follows: Mn + Ofn - Hys > Thresh.

Mn is the measurement value of the neighboring cell. Ofn is the frequency-specific offset of the neighboring cell. Thresh is the threshold for event B1. Hys is the hysteresis for event B1.

A larger value of Hys results in a lower probability of triggering event B1 and therefore a lower probability of handover. A large value may affect user experience. A smaller value of Hys leads to a higher probability of triggering event B1. A small value may cause handover decision errors and ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
InterRatHoGeranB1Thd CoverageBased GERAN trigger threshold

Meaning: Indicates the RSSI threshold for event B1 related to coverage-based inter-RAT handover to GERAN.

A UE sends a measurement report related to event B1 to the eNodeB when the RSSI in at least one GERAN cell reaches this threshold and other triggering conditions are met. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -110~-48

Unit: dBm

Actual Value Range: -110~-48

MML Default Value: -100

Recommended Value: -100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handover to the GERAN cell, and a smaller value leads to a higher probability.

Applicable Mode: L-FDD, L-TDD
InterRatHoGeranB1TimeToTrig GERAN time to trigger

Meaning: Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-GERAN handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: 640ms(640ms)

Recommended Value: 640ms(640ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handover to the GERAN cell, and a smaller value results in a higher probability.

Applicable Mode: L-FDD, L-TDD
LdSvBasedHoGeranB1Thd Load Service Based Geran EventB1 trigger threshold

Meaning: Indicates the RSSI threshold for event B1 related to load- or service-based inter-RAT handover to GERAN.

When the measured RSSI value exceeds this threshold, a B1 measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -110~-48

Unit: dBm

Actual Value Range: -110~-48

MML Default Value: -98

Recommended Value: -98

Parameter Relationship:

-Others:

  • If this parameter value is greater than the coverage-based handover threshold and coverage-based handover is enabled, a coverage-based handover is triggered first when the triggering conditions of coverage-based handover are met. In addition, load- and service-based handover cannot happen.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handovers to GERAN. A larger value of this parameter results in the opposite effect.

Applicable Mode: L-FDD, L-TDD

Example

To add a parameter group related to inter-RAT handover to GERAN with Local cell identity of 0, InterRatHoGeranGroupID of 9, and other parameters retaining their default values, run the following command:
ADD INTERRATHOGERANGROUP: LocalCellId=0, InterRatHoGeranGroupId=9;
