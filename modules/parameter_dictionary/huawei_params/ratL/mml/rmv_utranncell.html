Remove Neighboring Relation with UTRAN Cell (RMV UTRANNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more neighbor relationships with UTRAN cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If all parameters are specified, only the configuration of the one neighboring UTRAN cell with the same parameter settings is removed after the command is executed.

  • If some parameters are specified, configurations of the neighboring UTRAN cells with the same parameter settings are removed after this command is executed, and a maximum of 640 neighboring UTRAN cell configurations can be removed at a time.

  • If no parameter is specified, configurations of all neighboring UTRAN cells are removed after this command is executed, and a maximum of 640 neighboring UTRAN cell configurations can be removed at a time.

Mcc Mobile country code

Meaning: Indicates the mobile country code of the neighboring UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

RncId RNC ID

Meaning: Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellId RNC cell ID

Meaning: Indicates the RNC-wide cell ID of the external UTRAN cell. It uniquely identifies a cell within an RNC. There are two RNC ID patterns: RNC-ID and extended RNC-ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.

Example

To remove a neighboring relation with the UTRAN cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", RNC ID: 48, RNC cell ID: 12, run the following command:
RMV UTRANNCELL: LocalCellId=0, Mcc="460", Mnc="20", RncId=48, CellId=12;
To remove the neighboring relations with the UTRAN cell with the parameters as follows: Mobile country code: "460", Mobile network code: "20", run the following command:
RMV UTRANNCELL: Mcc="460", Mnc="20";
