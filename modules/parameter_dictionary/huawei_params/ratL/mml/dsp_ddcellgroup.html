Display Double Deck Cell Information (DSP DDCELLGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of cells in a double deck cell group.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To display Double Deck Cell Information, run the following command:
DSP DDCELLGROUP: LocalCellId=101;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Double Deck Cell Group Paired Cell ID

Indicates the ID of a paired cell in a Double Deck cell group. This parameter is used to display the information about a paired cell in the DSP command. This parameter applies only to LTE FDD.

Double Deck Cell Group Bandwidth

Indicates the bandwidth of a Double Deck cell group. This parameter applies only to FDD.

Downlink bandwidth

Indicates the downlink bandwidth of the cell. The bandwidth is expressed in the number of RBs. For example, the value CELL_BW_N25 indicates a cell bandwidth of 25 RBs and the value CELL_BW_N50 indicates a cell bandwidth of 50 RBs. For details, see 3GPP TS 36.104. This parameter applies only to LTE FDD and LTE TDD.

Cell instance state

Indicates the state of the cell instance.

In the case of access barring, the state can be CELL_INST_BARRED(Barred), CELL_INST_EMTC_BARRED(eMTC Barred), or CELL_INST_LTE_EMTC_BARRED(LTE and eMTC Barred). If NB-IoT or LTE UEs are barred from accessing the cell, CELL_INST_BARRED(Barred) is displayed as the state of the cell instance. If eMTC UEs are barred from accessing the cell, CELL_INST_EMTC_BARRED(eMTC Barred) is displayed as the state of the cell instance. If both LTE and eMTC UEs are barred from accessing the cell, CELL_INST_LTE_EMTC_BARRED(LTE and eMTC Barred) is displayed as the state of the cell instance.

Double Deck Cell Punctured RB State

Indicates the status of punctured RBs of a local cell in the Double Deck cell group. This parameter applies only to LTE FDD.
