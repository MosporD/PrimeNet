Start RTWP Test (STR LRTWPRTTST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start RTWP tests.

Note

1. Interference data collection currently applies only to LBBPd and UBBP boards among baseband processing units.

2. This command can be executed in a maximum of six cells simultaneously. If the IDs of more than six cells are specified, this command is executed in the first six active cells.

3. If the LocalCellId parameter is not specified, this command is executed in the first six active cells by default.

4. If a cell being tested is deactivated, the RTWP test in the cell stops.

5. The command cannot be executed in multi-RRU cells, combined cells, or split cells.

6. You can view the RTWP test results by uploading radio interference detection logs (by running the ULD FILE command with the file type set to RNFILE) after the tests finish.

Example

To start an RTWP test for a cell, run the following command:
STR LRTWPRTTST:;
