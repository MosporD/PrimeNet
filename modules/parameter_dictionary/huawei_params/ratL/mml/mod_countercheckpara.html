Modify Counter Check Configuration (MOD COUNTERCHECKPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to counter check.

Note

None.

Parameters

ID Name Description
CounterCheckTimer Counter check timer

Meaning: Indicates the length of the counter check timer. When the timer expires, a counter check procedure is initiated. After the procedure is complete, the timer is restarted. A length of 0 indicates that the timer is invalid. In this case, the eNodeB cannot initiate periodic counter check procedures. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0,10~600

Unit: s

Actual Value Range: 0,10~600

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the values of CounterCheckTimer and CounterCheckCountNum are too small, the counter check procedures are performed too frequently, which wastes radio interface resources. If the values are too large, the counter check procedure fails to be initiated during a long time, which results in the failure to check the HFN on the UE side and that on the eNodeB side.

Applicable Mode: L-FDD, L-TDD
CounterCheckCountNum Counter check count number

Meaning: Indicates the COUNT value for initiating counter check procedures. When the COUNT value (used at the PDCP layer) of any DRB for a UE is a multiple of the value of this parameter, the eNodeB initiates a counter check procedure. The value 0 indicates that the eNodeB does not initiate a counter check procedure based on the COUNT value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0,128~4294967295

Unit: None

Actual Value Range: 0,128~4294967295

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the values of CounterCheckTimer and CounterCheckCountNum are too small, the counter check procedures are performed too frequently, which wastes radio interface resources. If the values are too large, the counter check procedure fails to be initiated during a long time, which causes the failure to check the HFN on the UE side and that on the eNodeB side.

Applicable Mode: L-FDD, L-TDD
CounterCheckUserRelSwitch Counter check user Release switch

Meaning: Indicates whether to release a DRB when the counter check detects an unexpected result in the DRB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this switch is set to ON, a DRB is released when the counter check detects an unexpected result in the DRB. If this switch is set to OFF, a DRB is not released even if the counter check detects an unexpected result in the DRB.

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameters related to counter checks as follows: CounterCheckTimer: 0, CounterCheckCountNum: 0, run the following command:

MOD COUNTERCHECKPARA: CounterCheckTimer=0, CounterCheckCountNum=0;
