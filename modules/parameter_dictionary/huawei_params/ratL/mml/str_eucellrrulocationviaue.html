Start MDT UE-based RRU Locating Task (STR EUCELLRRULOCATIONVIAUE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start an MDT UE-based RRU locating task.

Note

None.

Parameters

ID Name Description
eNodeBId eNodeB ID

Meaning: Indicates the ID of the eNodeB.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • SECTORID on which SectorEqmId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
MaxUserNumForLocationPerMin Maximum User Number for Location per Minute

Meaning: Indicates the maximum number of UEs involved within one minute during RRU locating. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~60

Unit: None

Actual Value Range: 1~60

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to less inter-cell uplink interference and smaller impacts on the uplink cell rate and UE rate but longer locating time. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L
RbNumForLocation RB Number for Location

Meaning: Indicates the number of RBs used for RRU locating. If this parameter is set to 255:

For 5 MHz LTE bandwidth, 6 RBs are used for RRU locating.

For 10 MHz LTE bandwidth, 10 RBs are used for RRU locating.

For 15 MHz or 20 MHz LTE bandwidth, 15 RBs are used for RRU locating.

If this parameter is not set to 255:

For 5 MHz LTE bandwidth, set this parameter to a value less than or equal to 12.

For 10 MHz LTE bandwidth, set this parameter to a value less than or equal to 30. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 4~50,255

Unit: None

Actual Value Range: 4~50,255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to less inter-cell uplink interference and smaller impacts on the uplink cell rate and UE rate but greater locating errors. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L
MaxSampleNumForLocation Maximum Sample Number for Location

Meaning: Indicates the maximum number of samples that need to be collected during RRU locating. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 500~10000

Unit: None

Actual Value Range: 500~10000

MML Default Value: 2100

Recommended Value: 2100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to less inter-cell uplink interference and smaller impacts on the uplink cell rate and UE rate but greater locating errors. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L

Example

To start an RRU locating task based on MDT UEs with the parameters as follows: eNodeB ID: 10, Local Cell ID: 100, Sector Equipment ID: 200, Maximum User Number for Location per Minute: 2, RB Number for Location: 255, Maximum Sample Number for Location: 2100, run the following command:
STR EUCELLRRULOCATIONVIAUE: eNodeBId=10, LocalCellId=100, SectorEqmId=200, MaxUserNumForLocationPerMin=2, RbNumForLocation=255, MaxSampleNumForLocation=2100;
