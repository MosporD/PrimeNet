Modify RRN Port (MOD EURRNPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the RRN port configuration.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PN Port No.

Meaning: Indicates the transmission port number on the RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PortSwitch Port Switch

Meaning: Indicates the switch controlling the transmission port on the RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: Port 0:On, Port 1:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the RRN port configuration as follows: Local Subscriber ID: 10, Port No.: 0, Port Switch: OFF, run the following command:
MOD EURRNPORT: LocalSubscriberId=10, PN=0, PortSwitch=OFF;
