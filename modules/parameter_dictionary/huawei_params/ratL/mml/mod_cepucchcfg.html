Modify Coverage Pucch Configuration (MOD CEPUCCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PUCCH coverage enhancement configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the UE's coverage level.

COVERAGE_LEVEL0: Indicates the UE's coverage level is 0.

COVERAGE_LEVEL1: Indicates the UE's coverage level is 1.

COVERAGE_LEVEL2: Indicates the UE's coverage level is 2.

COVERAGE_LEVEL3: Indicates the UE's coverage level is 3.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL0(COVERAGE_LEVEL0), COVERAGE_LEVEL1(COVERAGE_LEVEL1), COVERAGE_LEVEL2(COVERAGE_LEVEL2), COVERAGE_LEVEL3(COVERAGE_LEVEL3)

Unit: None

Actual Value Range: COVERAGE_LEVEL0, COVERAGE_LEVEL1, COVERAGE_LEVEL2, COVERAGE_LEVEL3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PucchRepNum PUCCH Repetition Number

Meaning: Indicates the number of PUCCH transmission repetitions for UEs at a specific coverage level in the cell. This parameter takes effect only for UEs that will access the network after the parameter is set. If the CoverageLevel parameter in the CePucchCfg MO is set to COVERAGE_LEVEL0 or COVERAGE_LEVEL1, the following values of the PucchRepNum parameter are valid: - PUCCH_REP_NUM_R1 - PUCCH_REP_NUM_R2 - PUCCH_REP_NUM_R4 - PUCCH_REP_NUM_R8 If the CoverageLevel parameter in the CePucchCfg MO is set to COVERAGE_LEVEL2 or COVERAGE_LEVEL3, the following values of the PucchRepNum parameter are valid: - PUCCH_REP_NUM_R4 - PUCCH_REP_NUM_R8 - PUCCH_REP_NUM_R16 - PUCCH_REP_NUM_R32 This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PUCCH_REP_NUM_R1(PUCCH_REP_NUM_R1), PUCCH_REP_NUM_R2(PUCCH_REP_NUM_R2), PUCCH_REP_NUM_R4(PUCCH_REP_NUM_R4), PUCCH_REP_NUM_R8(PUCCH_REP_NUM_R8), PUCCH_REP_NUM_R16(PUCCH_REP_NUM_R16), PUCCH_REP_NUM_R32(PUCCH_REP_NUM_R32)

Unit: None

Actual Value Range: PUCCH_REP_NUM_R1, PUCCH_REP_NUM_R2, PUCCH_REP_NUM_R4, PUCCH_REP_NUM_R8, PUCCH_REP_NUM_R16, PUCCH_REP_NUM_R32

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

CoverageLevel is set to COVERAGE_LEVEL0: PUCCH_REP_NUM_R1

CoverageLevel is set to COVERAGE_LEVEL1: PUCCH_REP_NUM_R4

CoverageLevel is set to COVERAGE_LEVEL2: PUCCH_REP_NUM_R16

CoverageLevel is set to COVERAGE_LEVEL3: PUCCH_REP_NUM_R32

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more PUCCH transmission repetitions of UEs and better PUCCH demodulation performance, consuming more resources. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
EmtcSriPeriodAdaptSw eMTC SRI Period Adaptation Switch

Meaning: Indicates whether to enable SRI period adaptation for eMTC UEs. If this parameter is set to QCI_ADAPTIVE, the SRI period adaptively changes for eMTC UEs based on the cell load and bearers with different QCIs. If this parameter is set to NON_QCI_ADAPTIVE, the SRI period adaptively changes for eMTC UEs based on only the cell load. If the parameter is set to OFF, the SRI period for eMTC UEs is the value of the EmtcSriPeriod parameter in the CellQciPara MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), QCI_ADAPTIVE(QCI_ADAPTIVE), NON_QCI_ADAPTIVE(NON_QCI_ADAPTIVE)

Unit: None

Actual Value Range: OFF, QCI_ADAPTIVE, NON_QCI_ADAPTIVE

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default as follows:

FDD:

CoverageLevel is set to COVERAGE_LEVEL0:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL1:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL2:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL3:OFF(OFF)

TDD:

CoverageLevel is set to COVERAGE_LEVEL0:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL1:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL2:OFF(OFF)

CoverageLevel is set to COVERAGE_LEVEL3:OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to NON_QCI_ADAPTIVE, the eNodeB adaptively changes the SRI period for eMTC UEs based on only the cell load. This avoids SRI period reconfiguration caused by bearers with different QCIs and reduces signaling overhead. If abnormal eMTC UEs are present on the network and sometimes do not send SRIs, the E-RAB setup success rate increases significantly because the number of SRI period reconfigurations is reduced. The quality of voice services may deteriorate slightly when there are only a few UEs on the network. In addition, the maximum number of UEs does not change after the SRI period adaptively changes based on the SRI algorithm.

If this parameter is set to QCI_ADAPTIVE, the SRI period adaptively changes based on the SRI algorithm, and the maximum number of UEs does not change.

If this parameter is set to OFF, the maximum number of UEs is determined based on the configured SRI period.

Applicable Mode: L-FDD, L-TDD
FullDuplexVoltePucchRepNum Full Duplex VoLTE PUCCH Repetition Number

Meaning: Indicates the number of PUCCH repetitions used by eMTC full-duplex VoLTE UEs. This parameter is valid only if the VOLTE_REPETITION_OPT_SWITCH option of the EmtcEnhancedVolteAlgoSw parameter in the CellEmtcAlgo MO is selected. TDD does not distinguish between full duplex and half duplex. For eMTC VoLTE UEs in LTE TDD, the PUCCH repetition count is determined by the HalfDuplexVoltePucchRepNum parameter in the CePucchCfg MO. This parameter applies only to LTE FDD.

GUI Value Range: PUCCH_REP_NUM_R1(PUCCH_REP_NUM_R1), PUCCH_REP_NUM_R2(PUCCH_REP_NUM_R2), PUCCH_REP_NUM_R4(PUCCH_REP_NUM_R4), PUCCH_REP_NUM_R8(PUCCH_REP_NUM_R8)

Unit: None

Actual Value Range: PUCCH_REP_NUM_R1, PUCCH_REP_NUM_R2, PUCCH_REP_NUM_R4, PUCCH_REP_NUM_R8

MML Default Value: None

Recommended Value: PUCCH_REP_NUM_R2(PUCCH_REP_NUM_R2)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more PUCCH repetitions of UEs and better PUCCH demodulation performance, consuming more resources. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
HalfDuplexVoltePucchRepNum Half Duplex VoLTE PUCCH Repetition Number

Meaning: Indicates the number of PUCCH repetitions used by eMTC half-duplex VoLTE UEs. This parameter is valid only if the VOLTE_REPETITION_OPT_SWITCH option of the EmtcEnhancedVolteAlgoSw parameter in the CellEmtcAlgo MO is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PUCCH_REP_NUM_R1(PUCCH_REP_NUM_R1), PUCCH_REP_NUM_R2(PUCCH_REP_NUM_R2), PUCCH_REP_NUM_R4(PUCCH_REP_NUM_R4), PUCCH_REP_NUM_R8(PUCCH_REP_NUM_R8)

Unit: None

Actual Value Range: PUCCH_REP_NUM_R1, PUCCH_REP_NUM_R2, PUCCH_REP_NUM_R4, PUCCH_REP_NUM_R8

MML Default Value: None

Recommended Value: PUCCH_REP_NUM_R1(PUCCH_REP_NUM_R1)
