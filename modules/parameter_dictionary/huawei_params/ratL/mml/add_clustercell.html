Add Cluster Cell Config (ADD CLUSTERCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a cell to a cluster. This command takes effect only on the centralized control node.

Note

None.

Parameters

ID Name Description
ClusterId Cluster ID

Meaning: Indicates the ID of a cluster in Cloud BB scenarios. When static clusters are configured, the value of this parameter ranges from 0 to 999. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a ClusterCell MO must be set to a number.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in a ClusterCell MO must be set to a number.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
eNodeBId eNodeB ID

Meaning: Indicates the eNodeB identity of the cluster cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell identity is comprised of the cell identity and the eNodeB identity (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellId Cell ID

Meaning: Indicates the identity of the local cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell identity (represented by the least significant eight bits) and the eNodeB identity. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a cell to a cluster with the parameters as follows: Cluster ID: 2, Mobile country code: 460, Mobile network code: 01, eNodeB ID: 32, Cell ID: 1, run the following command:
ADD CLUSTERCELL: ClusterId=2, Mcc="460", Mnc="01", eNodeBId=32, CellId=1;
The result is shown as follows:
