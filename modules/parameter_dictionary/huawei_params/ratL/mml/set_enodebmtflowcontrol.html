Set Enodeb Mt Flow Control (SET ENODEBMTFLOWCONTROL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify eNodeB MT flow control parameter configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
HighPriUeMtFlowCtrlLevel High-Priority UE MT Flow Control Level

Meaning: Indicates the MT flow control level for the cell DT and internal CHRs of high-priority UEs. A larger value (non-zero) of this parameter leads to a higher flow control threshold for the cell DT and internal CHRs of high-priority UEs. If this parameter is set to 0, the flow control level is not configurable. For the definition of high-priority UEs, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value (non-zero) of this parameter leads to a larger CPU usage threshold for discarding the cell DT data and internal CHRs of BBPs and MPTs. In heavy-load scenarios, this affects boards' accommodating capabilities and traffic volume, and may lead to service KPI deterioration. If this parameter is set to 0, the network performance is not affected.

Applicable Mode: L-FDD, L-TDD
ChrFlowControlSwitch CHR Flow Control Switch

Meaning: Indicates whether to enable flow control on external CHRs. ChrFlowControlSwitch: Indicates whether to enable enhanced flow control on external CHRs. If this option is selected, the number of external CHR sampling points is reduced to decrease the system load and improve user experience. If this option is deselected, the number of external CHR sampling points is not reduced, and the system load is not affected. This option applies only to LTE FDD and LTE TDD.

ChrUeFlowControlOptSwitch: Indicates whether to optimize UE-specific flow control on external CHRs. If this option is selected, the period of UE-specific flow control on external CHRs is shortened to improve the flow control effect. If this option is deselected, flow control on external CHRs is not affected. This option applies only to LTE FDD and LTE TDD.

ChrCceFlowControlOptSwitch: Indicates whether to optimize CCE-usage-based flow control on external CHRs. If this option is selected, the formula for calculating the CCE usage is optimized to increase the CHRs reported in light-load scenarios with poor signal quality. If this option is deselected, flow control on external CHRs is not affected. This option applies only to LTE TDD.

ChrQueueFlowControlOptSwitch: Indicates whether to optimize UE-specific flow control based on queue congestion for external CHRs. If this option is selected, the system monitors the congestion state of message queues and improves flow control for external CHRs. If this option is deselected, flow control for external CHRs remains unchanged. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: ChrFlowControlSwitch(ChrFlowControlSwitch), ChrUeFlowControlOptSwitch(ChrUeFlowControlOptSwitch), ChrCceFlowControlOptSwitch(ChrCceFlowControlOptSwitch), ChrQueueFlowControlOptSwitch(ChrQueueFlowControlOptSwitch)

Unit: None

Actual Value Range: ChrFlowControlSwitch, ChrUeFlowControlOptSwitch, ChrCceFlowControlOptSwitch, ChrQueueFlowControlOptSwitch

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: ChrFlowControlSwitch: If this option is selected, the system load decreases and user experience improves. If this option is deselected, network performance is not affected.

ChrUeFlowControlOptSwitch: If this option is selected, user experience improves as a result of enhanced effect of flow control on external CHRs. If this option is deselected, network performance is not affected.

ChrCceFlowControlOptSwitch: If this option is selected, the formula for calculating the CCE usage is optimized to increase the CHRs reported in light-load scenarios with poor signal quality. If this option is deselected, network performance is not affected.

ChrQueueFlowControlOptSwitch: This option has no impact on network performance when the ChrFlowControlSwitch option is selected. If this option is selected with the ChrFlowControlSwitch option deselected, the CPU load decreases and user experience improves. If this option is deselected with the ChrFlowControlSwitch option deselected, the CPU load increases and user experience deteriorates.

Applicable Mode: L
SigLogMtFlowCtrlLevel SIG Log MT Flow Control Level

Meaning: Indicates the CPU flow control level of SIG logs on the main control board. A larger value of this parameter indicates a higher CPU threshold for triggering the main control board to discard SIG data and a lower probability of discarding SIG logs due to flow control. 0 indicates that SIG log reporting is disabled on the main control board. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger non-zero value of this parameter leads to a larger CPU usage threshold for triggering flow control over SIG data on the main control board. In heavy-load scenarios, this affects boards' accommodating capabilities and traffic volume, and may lead to service KPI deterioration. If this parameter is set to 0, the network performance is not affected.

Applicable Mode: L-FDD, L-TDD
TrcLogMtFlowCtrlLevel TRC Log MT Flow Control Level

Meaning: Indicates the CPU flow control level of TRC logs on the main control board. A larger value of this parameter indicates a higher CPU threshold for triggering the main control board to discard TRC data and a lower probability of discarding TRC logs due to flow control. 0 indicates that TRC log reporting is disabled on the main control board. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger non-zero value of this parameter leads to a larger CPU usage threshold for triggering flow control over TRC data on the main control board. In heavy-load scenarios, this affects boards' accommodating capabilities and traffic volume, and may lead to service KPI deterioration. If this parameter is set to 0, the network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To modify the  eNodeB MT flow control parameters as follows:HighPriUeMtFlowCtrlLevel equals to 0, run the following command:
SET ENODEBMTFLOWCONTROL: HighPriUeMtFlowCtrlLevel=0;
