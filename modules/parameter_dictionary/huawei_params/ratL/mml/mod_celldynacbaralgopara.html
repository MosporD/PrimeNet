Modify Cell Dynamic AC Barring Control Parameter (MOD CELLDYNACBARALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell dynamic access barring control.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DynAcBarStatPeriod Dynamic AC Barring Control Statistic Period

Meaning: Indicates the statistic period of dynamic access class (AC) barring in a cell, during which the proportion of time that the cell is in the congestion state is exported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 6~60

Unit: s

Actual Value Range: 6~60

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger parameter value leads to a lower frequency to export the proportion of time that the cell is in the congestion state and longer time to relieve cell congestion, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
DynAcBarTriggerThd Dynamic AC Barring Control Trigger Threshold

Meaning: Indicates the threshold for triggering dynamic access class (AC) barring in the cell. This threshold specifies the proportion of time that the cell is in the congestion state. If the proportion of time that the cell is in the congestion state is greater than or equal to this parameter value within a statistic period (specified by the DynAcBarStatPeriod parameter), the conditions for triggering dynamic AC barring are met. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship:

-Configuration constraints:

  • In the CellDynAcBarAlgoPara MO, DynAcBarTriggerThd must be greater than DynAcBarCancelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger parameter value leads to a lower probability of triggering dynamic AC barring and relieving cell congestion, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
DynAcBarCancelThd Dynamic AC Barring Control Cancel Threshold

Meaning: Indicates the threshold for canceling dynamic access class (AC) barring in the cell. This threshold specifies the proportion of time that the cell is in the congestion state. If the proportion of time that the cell is in the congestion state is less than or equal to this parameter value within a statistic period (specified by the DynAcBarStatPeriod parameter), the conditions for canceling dynamic AC barring are met. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship:

-Configuration constraints:

  • In the CellDynAcBarAlgoPara MO, DynAcBarTriggerThd must be greater than DynAcBarCancelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger parameter value leads to a higher probability of canceling dynamic AC barring and a lower probability of relieving cell congestion, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
SsacTriggerCondSatiPeriods Ssac Trigger Condition Satisfied Periods

Meaning: Indicates the number of consecutive periods for triggering intelligent access barring on specific services. If related triggering conditions are met for the specified number of consecutive periods, intelligent access barring on specific services is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering intelligent access barring on specific services, and therefore more UEs running multimedia telephony (MMTEL) voice services or MMTEL video services are rejected and user experience of more UEs is affected. However, a smaller value of this parameter results in a larger increase in the eNodeB stability. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
SsacCancelCondSatiPeriods Ssac Cancel Condition Satisfied Periods

Meaning: Indicates the number of consecutive periods for canceling intelligent access barring on specific services. If related cancellation conditions are met for the specified number of consecutive periods, intelligent access barring on specific services is canceled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of canceling intelligent access barring on specific services, and therefore fewer UEs running multimedia telephony (MMTEL) voice services or MMTEL video services are rejected and user experience of fewer UEs is affected. However, a smaller value of this parameter results in a smaller increase in the eNodeB stability. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DisasterReferenceInd Disaster Reference Indication

Meaning: Indicates the disaster reference indications used for determining whether a cell is in the disaster state. If all options included in this parameter are deselected, the disaster state of the cell does not need to be determined.

ETWS_PN: Indicates whether Primary notifications (PNs) in the earthquake and tsunami warning system (ETWS) are used in the disaster state determination. The PNs for ETWS do not include PNs used for ETWS tests.

If this option is selected, PNs in ETWS are used in the disaster state determination.

If this option is deselected, PNs in ETWS are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

ETWS_PN_TEST: Indicates whether PNs for ETWS tests are used in the disaster state determination.

If this option is selected, PNs in ETWS tests are used in the disaster state determination.

If this option is deselected, PNs in ETWS tests are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

CMAS: Indicates whether commercial mobile alert system (CMAS) warning notifications are used in the disaster state determination.

If this option is selected, CMAS warning notifications are used in the disaster state determination.

If this option is deselected, CMAS warning notifications are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: ETWS_PN(ETWS PN), ETWS_PN_TEST(ETWS PN FOR TEST), CMAS(CMAS)

Unit: None

Actual Value Range: ETWS_PN, ETWS_PN_TEST, CMAS

MML Default Value: None

Recommended Value: ETWS_PN:On, ETWS_PN_TEST:Off, CMAS:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DisasterDuration Disaster Duration

Meaning: Indicates the duration that the cell is in the disaster state. The cell is out of the disaster state after the duration specified by this parameter ends. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~10080

Unit: min

Actual Value Range: 1~10080

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MoTriggerCondSatiPeriods MO Trigger Condition Satisfied Periods

Meaning: Indicates the number of consecutive periods for triggering intelligent access class control on mobile-originated (MO) calls or signaling if related triggering conditions are met. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering intelligent access class control on MO calls or signaling, more UEs that initiate MO calls or signaling to be barred to access, user experience of more UEs to be affected, and a larger increase in the eNodeB stability. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
MoCancelCondSatiPeriods MO Cancel Condition Satisfied Periods

Meaning: Indicates the number of consecutive periods for canceling intelligent access class control on mobile-originated (MO) calls or signaling if related cancellation conditions are met. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of canceling intelligent access class control on MO calls or signaling, fewer UEs that initiate MO calls or signaling to be barred to access, user experience of fewer UEs to be affected, and a smaller increase in the eNodeB stability. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
MoFactorAdjStep MO Factor Adjusting Step

Meaning: Indicates the MO factor adjustment step used after intelligent AC control is triggered. The adjustment target factor is the factor that is ahead of the current factor by the value of this parameter. For example, if this parameter is set to 2 and the current factor is p95, the target factor is p85, which is ahead of p95 by two factors. If the adjustment step required for adjusting the current factor to p05 is less than the value of this parameter, the factor is directly adjusted to p05. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, cell congestion relief is slow and the impact on user experience is limited. If this parameter is set to a large value, cell congestion relief is fast and the impact on user experience is large.

Applicable Mode: L-FDD, L-TDD
MoFactorRetreatStep MO Factor Retreating Step

Meaning: Indicates the MO factor retreating step used after the conditions for canceling intelligent AC control are met but the number of consecutive periods in which the conditions are met has not reached the value of the MoCancelCondSatiPeriods parameter. The retreating target factor is the factor that is behind the current factor by the value of the MO Factor Retreating Step parameter. For example, if this parameter is set to 2 and the current factor is p85, the target factor is p95, which is behind p85 by two factors. If the step required for retreating the current factor to p95 is less than the value of this parameter, the factor is directly adjusted to p95. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the cell congestion relief effect is significant and the impact on user experience is large. If this parameter is set to a large value, the cell congestion relief effect is modest and the impact on user experience is limited.

Applicable Mode: L-FDD, L-TDD

MoFactorInitialValue MO Factor Initial Value

Meaning: Indicates the initial value of the probability factor used after dynamic AC barring on mobile-originated calls or signaling is started. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: P00(0%), P05(5%), P10(10%), P15(15%), P20(20%), P25(25%), P30(30%), P40(40%), P50(50%), P60(60%), P70(70%), P75(75%), P80(80%), P85(85%), P90(90%), P95(95%)

Unit: None

Actual Value Range: P00, P05, P10, P15, P20, P25, P30, P40, P50, P60, P70, P75, P80, P85, P90, P95

MML Default Value: None

Recommended Value: P95(95%)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a smaller impact on access experience but higher cell load. A smaller value leads to a greater impact on access experience and a higher probability that UEs cannot access the cell even if the cell load is relatively low.

Applicable Mode: L-FDD, L-TDD
RrcRejectCongTriggerThld RRC Reject Rate Congestion Trigger Thld

Meaning: Indicates the threshold of RRC connection reject rate for triggering access control. If the RRC connection reject rate of a cell is continuously higher than this threshold for N (N = the value of the MoTriggerCondSatiPeriods parameter) consecutive statistic periods specified by the DynAcBarStatPeriod parameter, the cell enters the automatic AC barring control process. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability of triggering access control based on the RRC connection reject rate. Therefore, the access congestion status is less likely to be relieved and UEs are less likely to be barred from accessing the cell. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
UeNumCongClearThld Ue-Number-based Congestion Clear Thld

Meaning: Indicates the UE number threshold for relieving the congestion state of a cell. If the number of UEs in a cell in the UE number congestion state becomes less than the value of this parameter, the cell exits this congestion state. If this parameter is set to 0, the function of this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2000

Unit: None

Actual Value Range: 0~2000

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher probability of canceling UE-number-based access control, a less significant access congestion relief effect, and a lower probability of restricting UE access. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
UeNumCongThld UE-Number-based Congestion Thld

Meaning: Indicates the UE number threshold for entering the congestion state of a cell. If the number of UEs in a cell not in the UE number congestion state exceeds the value of this parameter, the cell enters the UE number congestion state. If this parameter is set to 0, the function of this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2000

Unit: None

Actual Value Range: 0~2000

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to lower probabilities of triggering UE-number-based access control, relieving access congestion, and restricting UE access. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameter of cell dynamic AC barring control with the parameters as follows: Local Cell ID: 0, Dynamic AC Barring Control Statistic Period: 30, Dynamic AC Barring Control Trigger Threshold: 80, Dynamic AC Barring Control Cancel Threshold: 50, run the following command:
MOD CELLDYNACBARALGOPARA: LocalCellId=0, DynAcBarStatPeriod=30, DynAcBarTriggerThd=80, DynAcBarCancelThd=50;
