Remove PRB Sector Equipment Group (RMV EUPRBSECTOREQMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the sector equipment group configuration of a PRB.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB ID, which uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
SectorEqmGroupId Sector Equipment Group ID

Meaning: Indicates the ID of the sector equipment group that serves the PRB. It uniquely identifies a sector equipment group within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To remove prb sector equipment group with the parameters as follows:  LocalCellId: 0, PrbId:0, SectorEqmGroupId: 0, run the following command:
+++    0        2017-10-20 15:15:36
O&M    #806354956
%%RMV EUPRBSECTOREQMGROUP: LocalCellId=0, PrbId=0, SectorEqmGroupId=0;%%
RETCODE = 0  Operation succeeded.
