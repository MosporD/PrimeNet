Add External NR Cell (ADD NREXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an external NR cell.

Note

  • A UMPTg allows a maximum of 1344 external NR cells to be configured, and a main control board other than UMPTg allows a maximum of 672 external NR cells to be configured.

  • This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of the external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

Meaning: Indicates the aggregation attributes of an external NG-RAN cell.

CONTROL_MODE_FLAG: If this option is deselected, this MO can be modified or removed by users but cannot be modified or removed by ANR. A failure message is displayed when a user adds an existing MO (with identical keywords). If this option is selected, this MO can be modified or removed by both ANR and users. NrNetworkingOption NR Networking Option

Meaning: Indicates the architecture option of an NR cell. The value UNLIMITED indicates that the cell is in its initial state, that is, the cell is in unlimited mode. The value SA indicates that the cell works in SA networking mode. The value NSA indicates that the cell works in NSA networking mode. The value SA_NSA indicates that the cell can work in both SA and NSA networking modes. This parameter applies only to LTE FDD and LTE TDD.

The recommended value is NSA if NrNetworkingOption is set to NSA for the primary operator of the peer gNodeB.

Example

To add an external NR cell with the parameters as follows: Mobile country code: 460, Mobile network code: 20, gNodeB ID: 255, Cell ID: 1, Downlink ARFCN: 151600, Uplink ARFCN configuration indicator: NOT_CFG, Physical cell ID: 1, Tracking area code: 1, run the following command:
ADD NREXTERNALCELL: Mcc="460", Mnc="20", GnodebId=255, CellId=1, DlArfcn=151600, UlArfcnConfigInd=NOT_CFG, PhyCellId=1, Tac=1;
