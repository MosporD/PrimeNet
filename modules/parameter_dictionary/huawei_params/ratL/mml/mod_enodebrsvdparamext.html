Modify Extended Reserved eNodeB Parameter (MOD ENODEBRSVDPARAMEXT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of extended reserved eNodeB-level parameters.

Note

None.
