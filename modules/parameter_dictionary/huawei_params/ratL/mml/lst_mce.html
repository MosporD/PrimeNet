List Mce (LST MCE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list MCE configuration data.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the basic MCE information with the parameters as follows: Local MCE ID: 0, run the following command:
LST MCE: LocalMceId=0;
The result is shown as follows:

Output Description

Field Description

Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

MCE ID

Indicates the ID of an MCE. It uniquely identifies an MCE within a PLMN. The PLMN ID and the MCE ID together constitute the global MCE ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Mobile Country Code

Indicates the MCC of an MCE. An MCC and an MNC constitute a PLMN ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Mobile Network Code

Indicates the MNC of an MCE. An MCC and an MNC constitute a PLMN ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

MCE Type

Indicates whether different types of RATs support distributed MCE. DISTRIBUTED_MCE(FDD_DISTRIBUTED_MCE): Indicates whether FDD supports distributed MCE. This option applies only to LTE FDD. TDD_DISTRIBUTED_MCE(TDD_DISTRIBUTED_MCE): Indicates whether TDD supports distributed MCE. This option applies only to LTE TDD.

MCE Name

Indicates the name of an MCE. For details, see 3GPP TS 36.443. The value of this parameter is a string of a maximum of 150 characters. The string cannot be null characters or contain any of the following characters: double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three plus signs (+++), two or more consecutive spaces, and two or more consecutive percentage signs (%). This parameter applies only to LTE FDD and LTE TDD.
