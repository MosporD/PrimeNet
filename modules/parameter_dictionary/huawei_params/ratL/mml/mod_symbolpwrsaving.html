Modify Parameters of Symbol Power Saving (MOD SYMBOLPWRSAVING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to symbol power saving for energy conservation and emission reduction.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
StopBundlingDlTtiPrbThld Stop Bundling DL TTI-Level PRB Thld

Meaning: Indicates the downlink TTI-level PRB usage threshold used to determine whether to continue bundled scheduling in a TTI. If the PRB usage in the current TTI is higher than this threshold, the eNodeB stops bundled scheduling in this TTI. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~500

Unit: %

Actual Value Range: 0~500

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer new symbols that can be shut down during bundled scheduling and slighter impacts on the first-packet delay. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
TrigBndlSchDlAvgPrbThld Trig Bundled Scheduling DL Avg PRB Thld

Meaning: Indicates the average downlink PRB usage threshold for triggering bundled scheduling. When the average PRB usage of a cell is less than this threshold, bundled scheduling takes effect in the cell. When the average PRB usage of a cell is greater than or equal to the sum of this threshold and the PRB usage offset, bundled scheduling stops taking effect. If this parameter is set to 0, bundled scheduling is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70

Unit: %

Actual Value Range: 0~70

MML Default Value: None

Recommended Value: 50

Parameter Relationship:

-Configuration constraints:

  • If the LNR_BUNDLED_SCHEDULING_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO is selected, the TrigBndlSchDlAvgPrbThld parameter in the same MO cannot be set to 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MultiRatSymbolShutdownSw Multi-RAT Symbol Shutdown Switch

Meaning: Indicates whether to enable the functions related to multi-RAT symbol power saving in the cell. If this parameter is set to ON, multi-RAT symbol power saving is enabled. If this parameter is set to OFF, multi-RAT symbol power saving is disabled.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship:

-Configuration constraints:

  • If the LNR_BUNDLED_SCHEDULING_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO is selected, the MultiRatSymbolShutdownSw parameter in the same MO must be set to ON.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SymbolShutdownEnhancedSw Symbol Shutdown Enhanced Switch

Meaning: Indicates whether to enable enhanced symbol power saving functions in the cell.

LNR_BUNDLED_SCHEDULING_SW: Indicates whether to enable LTE and NR bundled scheduling in multi-RAT symbol power saving. This option applies only to LTE FDD and LTE TDD.

DEEP_SYMBOL_SHUTDOWN_SW: Indicates whether to enable deep symbol power saving for RF modules.

GUI Value Range: LNR_BUNDLED_SCHEDULING_SW(LNR_BUNDLED_SCHEDULING_SW), DEEP_SYMBOL_SHUTDOWN_SW(DEEP_SYMBOL_SHUTDOWN_SW)

Unit: None

Actual Value Range: LNR_BUNDLED_SCHEDULING_SW, DEEP_SYMBOL_SHUTDOWN_SW

MML Default Value: None

Recommended Value: LNR_BUNDLED_SCHEDULING_SW:Off, DEEP_SYMBOL_SHUTDOWN_SW:Off

Parameter Relationship:

-Configuration constraints:

  • If the LNR_BUNDLED_SCHEDULING_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO is selected, the MultiRatSymbolShutdownSw parameter in the same MO must be set to ON.
  • If the LNR_BUNDLED_SCHEDULING_SW option of the SymbolShutdownEnhancedSw parameter in the SymbolPwrSaving MO is selected, the TrigBndlSchDlAvgPrbThld parameter in the same MO cannot be set to 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: LNR_BUNDLED_SCHEDULING_SW: If this option is selected, the power consumption of the multimode base station decreases but the transmission delay increases for UEs when LTE and NR bundled scheduling takes effect. If this option is deselected, LTE and NR bundled scheduling does not take effect and network performance is not affected.

DEEP_SYMBOL_SHUTDOWN_SW: If this option is selected, the cell already in the symbol power saving state enters the deep symbol power saving state, further reducing the power consumption of RF modules. If this option is deselected, the cell returns to the basic power saving state, which has no impact on network performance.

Applicable Mode: L
MbsfnShutdownStartTime MBSFN Shutdown Start Time

Meaning: Indicates the start time of MBSFN enhanced symbol shutdown. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 00:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnShutdownStopTime MBSFN Shutdown Stop Time

Meaning: Indicates the stop time of MBSFN enhanced symbol shutdown. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 06:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify super combined cell configuration with the parameters as follows: Local Cell ID: 0, Stop Bundling DL TTI-Level PRB Thld: 60, Trig Bundled Scheduling DL Avg PRB Thld: 0, Multi-RAT Symbol Shutdown Switch: OFF, run the following command:
MOD SYMBOLPWRSAVING: LocalCellId=0, StopBundlingDlTtiPrbThld=60, TrigBndlSchDlAvgPrbThld=0, MultiRatSymbolShutdownSw=OFF;
