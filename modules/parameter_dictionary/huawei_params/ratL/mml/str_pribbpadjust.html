Start to Adjust Cell Primary BBP (STR PRIBBPADJUST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to adjust the primary BBP for a cell. Some cells are automatically reestablished in sequence.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be used to adjust BBPs for normal cells, SFN cells, and LampSite cells only.

  • The execution of this command causes some cells with normal cell instance state to be reestablished.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To adjust primary BBP with the local cell ID of 2, run the following command:
STR PRIBBPADJUST: LocalCellId=2;

Output Description

Field Description

Number of Cells Where Adjustment Succeeds

Indicates the number of cells for which the adjustment is successful in the one-click manner.

Number of Cells Where Adjustment Fails

Indicates the number of cells for which the adjustment fails in the one-click manner.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Reason for latest state change

Indicates the reason for the latest state change of the cell, which can be a cell activation success or a cell setup failure.
