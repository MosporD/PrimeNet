Reset Mutually Exclusive Baseband Equipment (RST EXCLUSIVERES)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to re-establish cells on a piece of baseband equipment in the following scenario: Other cells are bound to this baseband equipment but these cells are set up on other baseband equipment to which they are not bound.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The cell may be reestablished after the execution of this command.

Parameters

None.

Example

To reset exclusive baseband equipments, run the following command:
RST EXCLUSIVERES:;
The result is shown as follows:
+++    0    2014-06-10 17:35:53
O&M    #806355357
%%RST EXCLUSIVERES:;%%
RETCODE = 0  Operation succeeded.
