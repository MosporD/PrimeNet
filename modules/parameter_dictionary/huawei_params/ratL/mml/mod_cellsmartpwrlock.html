Modify Cell Smart Power Lock Configuration (MOD CELLSMARTPWRLOCK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the smart power lock configuration of a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Changing the value of the SmartPowerLockMode parameter will change the output power of the cell. Therefore, network planning engineers need to set this parameter based on site conditions.

  • Changing the value of the PowerControlThreshold parameter will change the output power of the cell. Therefore, network planning engineers need to set this parameter based on site conditions.

  • Changing the value of the AveragePowerMeasPeriod parameter will change the output power of the cell. Therefore, network planning engineers need to set this parameter based on site conditions.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SmartPowerLockMode Smart Power Lock Mode

Meaning: Indicates the control mode of smart power lock. The value OFF indicates that the smart power lock feature is disabled. The value AVERAGE_POWER_CONTROL indicates that the average power control function of the smart power lock feature is enabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), AVERAGE_POWER_CONTROL(AVERAGE_POWER_CONTROL)

Unit: None

Actual Value Range: OFF, AVERAGE_POWER_CONTROL

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to OFF, network performance is not affected. If this parameter is set to AVERAGE_POWER_CONTROL, the downlink cell throughput decreases.

Applicable Mode: L-FDD, L-TDD
PowerControlThreshold Power Control Threshold

Meaning: Indicates the power control threshold for the smart power lock feature. The average transmit power of the cell within the average power measurement period for the smart power lock feature must be lower than this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65500

Unit: 0.01W

Actual Value Range: 0~655

MML Default Value: None

Recommended Value: 65500

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to higher average power available for the cell and therefore a smaller decrease in downlink cell throughput. A smaller value of this parameter leads to the opposite effects. If this parameter is set to a too small value, the cell may fail to be normally set up. A valid value range is determined based on the PDSCH configuration, PA-related parameters for PDSCH power control, and other factors. The minimum allowed power control threshold is a power value that can ensure the normal transmission of RSs and system information.

Applicable Mode: L-FDD, L-TDD
AveragePowerMeasPeriod Average Power Measurement Period

Meaning: Indicates the average power measurement period for the smart power lock feature. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~86400

Unit: s

Actual Value Range: 1~86400

MML Default Value: None

Recommended Value: 360

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration about cell smart power lock as follows:Local cell ID:0, Smart Power Lock Mode:AVERAGE_POWER_CONTROL, Power Control Threshold(0.01W):1000, Average Power Measurement Period(s):10, run the following command:
MOD CELLSMARTPWRLOCK: LocalCellId=0, SmartPowerLockMode=AVERAGE_POWER_CONTROL, PowerControlThreshold=1000, AveragePowerMeasPeriod=10;
