List Cell Access Barring Configuration (LST CELLACBAR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters about cell access barring.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of access barring of a cell:
LST CELLACBAR: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

AC barring information configure indicator

Indicates the AC barring information configuration mode.

If this parameter is set to NOT_CFG, AC barring information is not configured.

If this parameter is set to CFG, AC barring information is configured.

If this parameter is set to OPERATOR_BASED_CFG, AC barring information is configured based on operator information.

This parameter applies only to LTE FDD and LTE TDD.

Emergency call barring state

Indicates the barring status of access class 10. This parameter specifies whether UEs are allowed to initiate emergency calls.

If this parameter is set to BOOLEAN_TRUE, UEs of access classes 0 to 9 or UEs without IMSIs are not allowed to initiate emergency calls. If this parameter is set to BOOLEAN_FALSE, UEs of access classes 0 to 9 or UEs without IMSIs are allowed to initiate emergency calls.

A UE of access class 11 to 15 are not allowed to initiate emergency calls only when its access class and access class 10 are both barred. If its access class or access class 10 is not barred, the UE is allowed to initiate emergency calls. This parameter applies only to LTE FDD and LTE TDD.

AC barring for mobile data configure indicator

Indicates whether to configure the AC barring information for mobile-originated calls. This parameter applies only to LTE FDD and LTE TDD.

Access probability factor for originating call(%)

Indicates the access probability factor for mobile-originated calls. A mobile-originated call is granted access if the random number generated by the UE is less than this access probability factor; otherwise, the access request is rejected. According to 3GPP TS 36.331, if any of the parameters AC11BarforCall, AC12BarforCall, AC13BarforCall, AC14BarforCall, and AC15BarforCall is set to BOOLEAN_TRUE, the eNodeB sends UEs P00 as the access probability factor for mobile-originated calls in the system information block type 2 (SIB2), regardless of the actual setting of the AcBarringFactorForCall parameter. This parameter applies only to LTE FDD and LTE TDD.

Mean access barring time for originating call(s)

Indicates the average access barring duration for mobile-originated calls. This parameter applies only to LTE FDD and LTE TDD.

AC11 barring state for originating call

Indicates whether UEs of access class 11 are barred from initiating mobile-originated calls.

If this parameter is set to BOOLEAN_TRUE, UEs of access class 11 cannot initiate mobile-originated calls. If this parameter is set to BOOLEAN_FALSE, UEs of access class 11 can initiate mobile-originated calls. This parameter applies only to LTE FDD and LTE TDD.

AC12 barring state for originating call

Indicates whether UEs of access class 12 are barred from initiating mobile-originated calls.

If this parameter is set to BOOLEAN_TRUE, UEs of access class 12 are not allowed to initiate mobile-originated calls. If this parameter is set to BOOLEAN_FALSE, UEs of access class 12 are allowed to initiate mobile-originated calls. This parameter applies only to LTE FDD and LTE TDD.

AC13 barring state for originating call

Indicates whether UEs of access class 13 are barred from initiating mobile-originated calls.

If this parameter is set to BOOLEAN_TRUE, UEs of access class 13 cannot initiate mobile-originated calls. If this parameter is set to BOOLEAN_FALSE, UEs of access class 13 can initiate mobile-originated calls. This parameter applies only to LTE FDD and LTE TDD.

AC barring for mobile signal configure indicator

Indicates whether to configure the AC barring information for mobile-originated signaling. This parameter applies only to LTE FDD and LTE TDD.

Indicates whether to configure the access barring information for CS fallback (CSFB) services. This parameter applies only to LTE FDD and LTE TDD.

VoLTE Preference Configuration Indication

Indicates whether to allow preferential accesses for MMTEL video services, MMTEL voice services, or short messages during AC control. This parameter takes effect only when the AcBarforVoLTEPreferSwitch option of the VoLTESwitch parameter in the CellAlgoSwitch MO is selected.

MMTELVoicePreferCfgInd: Indicates whether to allow preferential accesses for MMTEL voice services during AC control. This option applies only to LTE FDD and LTE TDD.

MMTELVideoPreferCfgInd: Indicates whether to allow preferential accesses for MMTEL video services during AC control. This option applies only to LTE FDD and LTE TDD.

SMSPreferCfgInd: If this option is selected, the eNodeB allows preferential accesses for short messages during AC control. This option applies only to LTE FDD and LTE TDD.
