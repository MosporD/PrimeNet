List Clock Detection Parameter (LST CLKDETECT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list clock detection parameter configurations.

Note

None.

Parameters

None.

Example

To List Clock Detection Parameter:
LST CLKDETECT:;
The result is shown as follows:
+++    0        2019-12-05 17:29:38
O&M    #806355907
%%LST CLKDETECT: ;%%
RETCODE = 0  Operation succeeded.

List Clock Detection Parameter
------------------------------

            Clock Async Interf Report Thld(dBm)  =  -95
                     Clock Async PRB Usage Thld  =  50
Clock Async Silence Detect Interf Diff Thld(dB)  =  6
    Clock Async Silence Detect Interf Thld(dBm)  =  -105
                        Post Processing Measure  =  NO_PROCESSING
(Number of results = 1)


---    END

Output Description

Field Description

Clock Async Detection Switch

Indicates whether to enable clock asynchronization detection. If this parameter is set to ON(On), the eNodeB enables clock asynchronization detection. If this parameter is set to OFF(Off), the eNodeB disables clock asynchronization detection. This parameter applies only to LTE TDD.

Clock Async Interf Report Thld(dBm)

Indicates the interference threshold for interference reporting. This parameter applies only to LTE TDD.

Clock Async PRB Usage Thld

Indicates the uplink PRB usage threshold for a cell. This threshold is used to filter out scenarios where interference occurs due to heavy traffic. This parameter applies only to LTE TDD.

Clock Async Silence Detect Interf Diff Thld(dB)

Indicates the threshold of interference fluctuations during silence detection for locating eNodeBs with clock asynchronization. This parameter applies only to LTE TDD.

Clock Async Silence Detect Interf Thld(dBm)

Indicates the interference detection threshold when interference fluctuates during silence detection. This threshold is used to locate eNodeBs with clock asynchronization. This parameter applies only to LTE TDD.

Post Processing Measure

Indicates the measure to be taken after eNodeB clock out-of-synchronization. If this parameter is set to NO_PROCESSING, the eNodeB does not take any measure after clock out-of-synchronization. If this parameter is set to CLK_ASYNC_ENB_DEACTIVATE, the eNodeB deactivates all LTE TDD cells after clock out-of-synchronization. This parameter applies only to LTE TDD.
