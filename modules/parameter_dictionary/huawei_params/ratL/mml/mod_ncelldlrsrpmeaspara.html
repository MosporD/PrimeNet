Modify Neighboring Cell Downlink RSRP Measurement Parameters (MOD NCELLDLRSRPMEASPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of downlink RSRP measurements on neighboring cells of a local cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell Id

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlRsrpAutoNCellMeasSwitch DL RSRP Auto NCell Measurement Switch

Meaning: Indicates whether automatic measurement of downlink RSRP in neighboring cells is supported by the local cell. If this parameter is set to ON, automatic measurement of downlink RSRP in neighboring cells takes effect. If this parameter is set to OFF, automatic measurement of downlink RSRP in neighboring cells is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NCellDlRsrpMeasA3Offset DL RSRP NCell Measurement A3 Offset

Meaning: Indicates the offset for reporting the event of automatic measurement of downlink RSRP in neighboring cells. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality to report the event. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in more reports of automatic neighboring cell downlink RSRP measurement results, more air interface signaling, and more neighboring cells for downlink RSRP measurements. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DlRsrpNCellMeasA6Offset DL RSRP NCell Measurement A6 Offset

Meaning: Indicates the offset for reporting the event of automatic measurement of downlink RSRP in neighboring cells for UEs in SCells. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality to report the event. The value 127 indicates that event A6 measurement is not triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30,127

Unit: 0.5dB

Actual Value Range: -15~15,127

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter leads to more MRs for automatic measurement of downlink RSRP in neighboring cells, more signaling messages over the air interface, and more neighboring cells that meet RSRP measurement conditions for the local cell. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To disable downlink RSRP automatic neighboring cell measurement for the cell whose local cell ID is 0, run the following command:
MOD NCELLDLRSRPMEASPARA: LocalCellId=0, DlRsrpAutoNCellMeasSwitch=OFF;
