Modify Cell Position Reference Signal Configuration (MOD CELLPRSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PRS configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PrsBandwidth PRS Bandwidth

Meaning: Indicates the transmission bandwidth of PRS. This parameter corresponds to the PRS Bandwidth parameter defined in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BW_N6(1.4M), BW_N15(3M), BW_N25(5M), BW_N50(10M), BW_N75(15M), BW_N100(20M)

Unit: None

Actual Value Range: BW_N6, BW_N15, BW_N25, BW_N50, BW_N75, BW_N100

MML Default Value: None

Recommended Value: Same as the cell bandwidth if it is lower than 10 MHz

BW_N50 if the cell bandwidth is 10 MHz or higher

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller parameter value results in a lower PRS bandwidth, a smaller impact on cell throughput, and a lower probability that a UE receives PRSs. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
PrsConfigurationIndex PRS Configuration Index

Meaning: Indicates the PRS period and the start subframe. This parameter corresponds to the PRS Configuration Index parameter defined in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2399

Unit: None

Actual Value Range: 0~2399

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller parameter value results in a smaller start PRS subframe number, a shorter PRS configuration period, a larger number of RBs occupied, and a higher probability that a UE receives PRSs. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
NumberofDlFramesforPrs Number of DL Frames for PRS

Meaning: Indicates the number of consecutive downlink subframes for PRSs. This parameter corresponds to the Number of DL Frames parameter specified in 3GPP TS 36.455. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SF1(SF1), SF2(SF2), SF4(SF4), SF6(SF6)

Unit: None

Actual Value Range: SF1, SF2, SF4, SF6

MML Default Value: None

Recommended Value: SF6 for 1.4 MHz

SF6 for 3 MHz

SF4 for 5 MHz

SF2 for 10 MHz or higher

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a smaller number of consecutive downlink subframes for PRSs, a smaller number of RBs occupied, and a lower probability that a UE receives PRSs. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
NumofPRSMutingBit Num of PRS Muting Bit

Meaning: Indicates the number of PRS muting bits in the cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2_BITS(2_BITS), 4_BITS(4_BITS), 8_BITS(8_BITS), 16_BITS(16_BITS)

Unit: None

Actual Value Range: 2_BITS, 4_BITS, 8_BITS, 16_BITS

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 2_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 3.
  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 4_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 15.
  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 8_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 255.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PrsMutingConfiguration PRS Muting Configuration

Meaning: Indicates the PRS muting configuration. See 3GPP TS 36.455 to learn details about this parameter. The value range of this parameter is determined by the value of the NumofPRSMutingBit parameter. The NumofPRSMutingBit values 2_BITS, 4_BITS, 8_BITS, and 16_BITS indicate that the value ranges of PrsMutingConfiguration are 0-3, 0-15, 0-255, and 0-65535, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 2_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 3.
  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 4_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 15.
  • In the CellPrsCfg, if the NumofPRSMutingBit parameter is set to 8_BITS, the value range of PrsMutingConfiguration in the CellPrsCfg is from 0 to 255.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If a bit in the parameter value's corresponding binary value is 1, the PRS is transmitted in the PRS transmission period indicated by the position of this bit. If a bit is 0, the PRS is not transmitted in the PRS transmission period indicated by the position of this bit. A large number of bits with the value of 1 indicates a higher PRS reception success rate.

Applicable Mode: L-FDD, L-TDD

Example

To modify a cell PRS configuration with the following parameters: Local Cell ID: 2, PRS Bandwidth: BW_N6, PRS Configuration Index: 0, and Number of DL Frames for PRS: SF1, run the following command:
MOD CELLPRSCFG: LocalCellId=2, PrsBandwidth=BW_N6, PrsConfigurationIndex=0, NumberofDlFramesforPrs=SF1;
