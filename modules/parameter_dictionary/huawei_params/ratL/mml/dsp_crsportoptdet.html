Display CRS Antenna Port Mapping Optimization Detection Result (DSP CRSPORTOPTDET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the result of CRS antenna port mapping optimization detection of the cell.

Note

This command applies only to 4T4R Cells.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the CRS antenna port mapping optimization detection result of the cells, run the following command:
DSP CRSPORTOPTDET:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

Cell Name

Indicates the name of the cell.

CRS Antenna Port Opt Mapping Detection Result

Indicates the CRS antenna port mapping optimization detection result of the cell. This parameter applies only to LTE FDD.

Current CRS Antenna Port Mapping

Indicates the current mapping between cell-specific reference signal (CRS) ports and transmit (TX) channels in an RRU. As defined in 3GPP specifications, the CrsPortNum parameter can be set to CRS_PORT_1, CRS_PORT_2, or CRS_PORT_4. The value CRS_PORT_1 indicates that one CRS port (port 0) is configured. The value CRS_PORT_2 indicates that two CRS ports (ports 0 and 1) are configured. The value CRS_PORT_4 indicates that four CRS ports (ports 0, 1, 2 and 3) are configured. In values of this parameter, mTnP indicates that the number of TX channels configured for a cell is "m" and the number of CRS ports is "n". The parameter value 4TnP_abcd indicates that reference signals transmitted over CRS ports a, b, c, and d are mapped to TX channels 1, 2, 3, and 4 in an RRU, respectively (The TX channel number here is for reference only, and the actual number is R0A to R0D, or others). The parameter value NOT_CFG indicates that the mapping between CRS ports and TX channels in an RRU is not configured, and CRS ports are mapped to TX channels in an RRU in a default manner. This parameter applies only to LTE FDD.

Optimal CRS Antenna Port Mapping

Indicates the optimal mapping between cell-specific reference signal (CRS) ports and transmit (TX) channels in an RRU. As defined in 3GPP specifications, the CrsPortNum parameter can be set to CRS_PORT_1, CRS_PORT_2, or CRS_PORT_4. The value CRS_PORT_1 indicates that one CRS port (port 0) is configured. The value CRS_PORT_2 indicates that two CRS ports (ports 0 and 1) are configured. The value CRS_PORT_4 indicates that four CRS ports (ports 0, 1, 2 and 3) are configured. In values of this parameter, mTnP indicates that the number of TX channels configured for a cell is "m" and the number of CRS ports is "n". The parameter value 4TnP_abcd indicates that reference signals transmitted over CRS ports a, b, c, and d are mapped to TX channels 1, 2, 3, and 4 in an RRU, respectively (The TX channel number here is for reference only, and the actual number is R0A to R0D, or others). The parameter value NOT_CFG indicates that the mapping between CRS ports and TX channels in an RRU is not configured, and CRS ports are mapped to TX channels in an RRU in a default manner. This parameter applies only to LTE FDD.

CRS Optimization Detection Progress(%)

Indicates the execution progress of CRS optimization detection in the entire eNodeB. This parameter applies only to LTE FDD.

CRS Opt Det Completion Status

Indicates the detection status of CRS optimization in the entire eNodeB. This parameter applies only to LTE FDD.
