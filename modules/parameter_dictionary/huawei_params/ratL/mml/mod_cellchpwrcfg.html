Modify Cell Channel Power Configuration (MOD CELLCHPWRCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell channel power.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

HoRarPwrEnhancedSwitch Handover RAR Power Enhanced Switch

Meaning: Indicates whether the eNodeB increases the transmit power of the Random Access Response (RAR) message when a UE is being handed over to the target cell and repeatedly sends dedicated preambles. If this parameter is set to OFF(OFF), the eNodeB does not increase the transmit power of the RAR message sent to the UE that is being handed over to the target cell. If this parameter is set to ON(ON) and a UE that is being handed over to the target cell repeatedly sends dedicated preambles, the eNodeB increases the transmit power of the RAR message by another 3 dB each time on the basis of the RaRspPwr parameter value. The transmit power of the RAR message can be increased by a maximum of 6 dB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: When downlink coverage is weak or interference is strong, setting this parameter to ON increases the dedicated-preamble-based access success rate in the cell, increases the handover success rate, and decreases the handover delay. However, if the traffic volume is large or the number of handovers is large, setting this parameter to ON increases downlink interference on neighboring cells and decreases power for transmitting downlink services in the local cell, which in turn decreases network downlink throughput.

Applicable Mode: L-FDD, L-TDD
OutputPowerRate Output Power Rate

Meaning: Indicates the cell output power usage. This parameter is valid only when the AntRsPwrSwitch option is selected. The eNodeB calculates the reference signal (RS) transmit power to be delivered in system information block type 2 (SIB2) based on OutputPowerRate and AntOutputPwr. When the AntRsPwrSwitch option is selected for NB-IoT cells in in-band scenarios and the corresponding LTE cells and the OutputPowerRate parameter is set to 0, the eNodeB calculates the output power usage of the NB-IoT and LTE cells. Then, the eNodeB calculates the RS power based on the power usage and broadcasts the power in SIB2. In other scenarios with the AntRsPwrSwitch option selected and the OutputPowerRate parameter set to 0, the eNodeB handles the parameter value 0 as 1000.

GUI Value Range: 0~1000

Unit: per mill

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
PdcchPowerIncreaseOffset PDCCH Power Increase Offset

Meaning: Indicates the power increase offset of the PDCCH in a cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: 0.1dB

Actual Value Range: 0~1.5

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller decrease in CCE allocation failures, and a smaller increase in the number of scheduled UEs. A larger number of this parameter results in a greater decrease in CCE allocation failures, and a greater increase in the number of scheduled UEs. However, in such a case, higher RRU transmit power is occupied. As a result, other cells cannot use the power, causing deterioration of cell performance counters in these cells, such as the average number of scheduled UEs, spectral efficiency, and cell throughput.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the cell channel power configuration parameters: Local cell ID: 0, PCFICH power: 1, run the following command:
MOD CELLCHPWRCFG: LocalCellId=0, PcfichPwr=1;
Example 2: To modify the cell channel power configuration parameters: Local cell ID: 0, PCFICH power: 10, run the following command:
MOD CELLCHPWRCFG: LocalCellId=0, PbchPwr=10;
