Modify UE Timer and Constant Configuration (MOD UETIMERCONST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of UE timers and constants.

Note

None.

Parameters

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

T310 Timer 310

Meaning: Indicates the length of timer 310. For details, see 3GPP TS 36.331.

This timer is started when the UE detects any fault at the physical layer.

The timer is stopped if the UE detects one of the following before the timer expires: (1) The physical-layer fault is rectified; (2) A handover is triggered; (3) The UE initiates an RRC connection reestablishment procedure.

After the timer expires, the UE enters the RRC_IDLE mode if the security mode is not activated. If the security mode is activated, the UE initiates an RRC connection reestablishment procedure. This parameter applies only to LTE FDD and LTE TDD.

T325 Timer 325

Meaning: Indicates the length of timer 325. For details, see 3GPP TS 36.331. This timer starts when a UE receives an RRCConnectionReject message containing the deprioritisationReq IE. When the timer expires, the cell reselection priorities that have been reduced using RRCConnectionReject for E-UTRAN frequencies are restored. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MIN5_T325(MIN5_T325), MIN10_T325(MIN10_T325), MIN15_T325(MIN15_T325), MIN30_T325(MIN30_T325)

Unit: None

Actual Value Range: MIN5_T325, MIN10_T325, MIN15_T325, MIN30_T325

MML Default Value: None

Recommended Value: MIN5_T325(MIN5_T325)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a larger value, the cell reselection priority of an E-UTRAN frequency which is contained in the RRCConnectionReject message including the deprioritisationReq IE is lowered for a longer time, the number of RRC connection setup failures on a high-priority frequency becomes smaller, but the UE cannot camp on a high-priority frequency for a longer time. If this parameter is set to a smaller value, the cell reselection priority of an E-UTRAN frequency which is contained in the RRCConnectionReject message including the deprioritisationReq IE is lowered for a shorter time, the number of RRC connection setup failures on a high-priority frequency becomes larger, and the UE attempts to camp on a high-priority frequency more frequently.

Applicable Mode: L-FDD, L-TDD

T300CE Timer 300 in CE Mode

Meaning: Indicates the timer value of Timer 300 in coverage enhancement mode. Example

Example 1: To modify the settings of UE timers and constants with the parameters as follows: Local cell ID: 0, Timer 300: MS100_T300, Timer 301: MS200_T301, Timer 310: MS50_T310, Timer 311: MS3000_T311, run the following command:
MOD UETIMERCONST: LocalCellId=0, T300=MS100_T300, T301=MS200_T301, T310=MS50_T310, T311=MS3000_T311;
Example 2: To modify the settings of UE timers and constants with the parameters as follows: Local cell ID: 0, Timer 300: MS600_T300, Timer 301: MS1000_T301, Timer 310: MS100_T310, Timer 311: MS10000_T311, run the following command:
