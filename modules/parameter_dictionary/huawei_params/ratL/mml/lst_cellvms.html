List Cell VMS Configuration (LST CELLVMS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the cell configuration of VMS.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the configurations of VMS:
LST CELLVMS:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

Max UE Number for Handover Out

Indicates the maximum number of UEs that can be transferred within 10s. This parameter is used to prevent too many UEs from being transferred at a time to neighboring cells to cause significant impact on neighboring cells. This parameter applies only to LTE FDD.

Load Difference Threshold(%)

Indicates the threshold of PRB usage difference between the serving cell and a neighboring cell. When the result of the PRB usage of the serving cell minus that of a neighboring cell in a cluster is greater than the parameter value, this neighboring cell can be a target cell for MLB. This parameter applies only to LTE FDD.

Load Balancing Threshold(%)

Indicates the PRB usage threshold for triggering MLB. MLB is triggered if the PRB usage of the serving cell is higher than this parameter value. This parameter applies only to LTE FDD.

VMS A3 Offset(dB)

Indicates the offset for intra-frequency handovers between the inner and outer cells in VMS scenarios. This parameter also indicates the intra-frequency handover offset between cells served by the same AAU in massive MIMO (32T32R) scenarios. This parameter applies only to LTE FDD.
