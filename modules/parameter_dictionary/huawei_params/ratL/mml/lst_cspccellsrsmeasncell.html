List CSPC Cell SRS Measure Neighbor Cell (LST CSPCCELLSRSMEASNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of neighboring cells (for SRS measurement) of a local CSPC cell or all local CSPC cells. This command takes effect only on the centralized control node.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the local CSPC cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a CspcCellSrsMeasNCell MO must be set to a number.
  • In a CspcCellSrsMeasNCell MO, the combination of Mcc, Mnc, eNodeBId, and CellId that identify the local cell cannot be the same as the combination of NCellMcc, NCellMnc, NCellId, and NCellENodeBId that identify the neighboring SRS measurement cell.
