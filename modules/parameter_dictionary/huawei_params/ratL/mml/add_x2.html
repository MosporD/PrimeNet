Add X2 Configuration (ADD X2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an X2 object.

Note

  • The X2 self-setup is supported for the operator only after the CpEpGroupId parameter under the X2 MO for this operator is added.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in X2 or S1 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in X2 or S1 MOs cannot overlap.

  • If the SELECTED_PLMNID check box under the X2SonTNLSelectMode parameter is selected, only UEs served by the operator specified by the CpEpGroupId parameter can trigger X2 self-setup in X2_OVER_OSS or X2_OVER_S1 mode. If the PRIMARY_PLMNID check box under the X2SonTNLSelectMode parameter is selected for an LTE TDD network and the CpEpGroupId parameter specifies the primary operator, UEs served by secondary operators can also trigger X2 self-setup.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the X2 or ECO MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the X2 or ECO MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in X2 or EX2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in X2 or EX2 MOs cannot overlap.

  • The EPGROUP MO referenced by CpEpGroupId in an X2 MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an X2 MO and the EPGROUP MO referenced by the IUB or ABIS MO must be different.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the X2 MOs or the M1EpGroupId parameter in the M1 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the X2 MOs or the M2EpGroupId parameter in the M2 MOs cannot overlap.

  • If the value of the CnOpSharingGroupId parameter in an X2 MO is not set to the invalid value 255, ensure that the associated CnOpSharingGroup MO has been added before adding the X2 MO and the operator to which the X2 MO belongs is in the carrier-sharing operator group. In hybrid RAN sharing mode, the CnOpSharingGroup MO referenced by the X2 MO must be configured and the CnOpSharingGroupId parameter must be set to a valid value.

Example

To add an X2 object with the parameters as follows: X2 ID: 0, CN Operator ID: 0, End Point Config Flag: CP_UP_CFG, Control Plane End Point Group ID: 123, User Plane End Point Group ID: 123, and other parameters set to the default values, run the following command:
ADD X2: X2Id=0, CnOperatorId=0, EpGroupCfgFlag=CP_UP_CFG, CpEpGroupId=123, UpEpGroupId=123;
