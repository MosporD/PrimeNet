Modify High Speed Adaption Control Configuration (MOD HIGHSPDADAPTIONPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to high-speed mobility.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserLowSpeedJudgeNum Low Speed Judge Number

Meaning: Indicates the threshold of the number of consecutive low-speed judgments required for an initially admitted UE or a high-speed UE to be identified as a low-speed UE in a high-speed or ultra-high-speed cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~30

Unit: None

Actual Value Range: 1~30

MML Default Value: None

Recommended Value: 8 for FDD

3 for TDD

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on equipment)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability that a UE is identified as a low-speed UE, a higher probability that a low-speed UE is handed over to another cell when the Handover Enhancement at Speed Mobility feature is enabled, but a higher probability that a high-speed UE is erroneously identified as a low-speed UE and handed over to another cell. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DopplerFactor Doppler Factor

Meaning: Indicates the impact of the Doppler effect on UE speed estimation in high-speed or ultra-high speed scenarios. The change in frequency for a UE moving relative to an eNodeB (that is, the Doppler shift) is equal to the Doppler frequency multiplied by cosθ, where θ is the angle between the UE movement direction and the signal emission direction. The angle is highly correlated with the UE location and the distance between the eNodeB and the track. When the distance is large, the UE speed cannot be well estimated. This parameter is used to address this issue. The parameter is defined as a percentage of the Doppler frequency multiplied by cosθ', where θ' is the smallest refraction angle within the eNodeB coverage. When the distance is less than or equal to 200 m, you can retain the default parameter value. When the distance is greater than 200 m, set the parameter according to instructions in High Speed Mobility Feature Parameter Description. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on equipment)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability that UEs are identified as high-speed UEs, a higher probability that high-speed UEs are correctly identified as high-speed UEs, and a higher success rate of high-speed UE handovers; however, a smaller value also leads to a higher probability that low-speed UEs are erroneously identified as high-speed UEs, a higher probability of ping-pong handovers between cells, and a higher service drop rate. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
HighSpeedUserNumThd High Speed User Number Threshold

Meaning: Indicates the minimum number of high-speed UEs required to determine that high-speed trains are passing by. It is recommended that this parameter be set, based on the operators' levels of traffic volume at high-speed railways, to the maximum appropriate value that can be used to identify high-speed trains in off-peak hours to minimize the impact on low-speed UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~200

Unit: None

Actual Value Range: 1~200

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability that a cell is identified as a high-speed cell but also a higher probability that a cell is erroneously identified as a high-speed cell. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
HoHisJudgeHighThd Handover History Judge High Threshold

Meaning: Indicates the maximum duration of stay in the previous cell for a UE to be identified as a high-speed UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3~120

Unit: s

Actual Value Range: 3~120

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a lower probability that a UE is identified as a high-speed UE and also a lower probability of erroneous identification. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
InterfAvoidCellNum Interference Avoid Cell Number

Meaning: Indicates the maximum number of a high-speed cell's neighboring low-speed cells that perform interference avoidance when high-speed trains pass by. This parameter applies only to LTE FDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller impact on the neighboring low-speed cells at the time when high-speed trains pass by; however, high-speed UEs experience higher interference. A larger value of this parameter leads to a greater impact on the neighboring low-speed cells at the time when high-speed trains pass by; however, high-speed UEs experience lower interference.

Applicable Mode: L-FDD
InterfAvoidMode Interference Avoid Mode

Meaning: RbBasedInterfAvoid: Indicates whether to enable downlink RB-based interference avoidance. When this option is selected, the proportion of available downlink PRBs is reduced in low-speed cells to reduce the downlink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

PowerBasedInterfAvoid: Indicates whether to enable downlink power-based interference avoidance. When this option is selected, the downlink transmit power is reduced in low-speed cells to reduce the downlink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

UlRbBasedInterfAvoid: Indicates whether to enable uplink PRB-based interference avoidance. When this option is selected, the proportion of available uplink PRBs is reduced in low-speed cells to reduce the interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

UlPowerBasedInterfAvoid: Indicates whether to enable uplink power-based interference avoidance. When this option is selected, the uplink UE transmit power is reduced in low-speed cells to reduce the uplink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

RbBasedAbsoluteAvoidInd: Indicates whether to disable scheduling of high-priority services, such as signaling, in the HighSpeedOverlapBandInd-specified range of overlapping frequency bands between public cells and high-speed railway dedicated cells. This option requires that RbBasedInterfAvoid or UlRbBasedInterfAvoid has been selected. This option applies only to LTE FDD and LTE TDD.

HSCellSleepInterfAvoidSwitch: Indicates whether to allow high-speed cells to enter sleep mode. If this option is selected, the eNodeB allows high-speed cells to adaptively enter sleep mode. When a high-speed train arrives at a high-speed cell, the cell exits from sleep mode. After the high-speed rain has left the high-speed cell for a specified period of time, the high-speed cell enters sleep mode. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: RbBasedInterfAvoid(RbBasedInterfAvoid), PowerBasedInterfAvoid(PowerBasedInterfAvoid), UlRbBasedInterfAvoid(UlRbBasedInterfAvoid), UlPowerBasedInterfAvoid(UlPowerBasedInterfAvoid), RbBasedAbsoluteAvoidInd(RbBasedAbsoluteAvoidInd), HSCellSleepInterfAvoidSwitch(HSCellSleepInterfAvoidSwitch)

Unit: None

Actual Value Range: RbBasedInterfAvoid, PowerBasedInterfAvoid, UlRbBasedInterfAvoid, UlPowerBasedInterfAvoid, RbBasedAbsoluteAvoidInd, HSCellSleepInterfAvoidSwitch

MML Default Value: None

Recommended Value: RbBasedInterfAvoid: Off, PowerBasedInterfAvoid: Off, UlRbBasedInterfAvoid: Off, UlPowerBasedInterfAvoid: Off, RbBasedAbsoluteAvoidInd: Off, HSCellSleepInterfAvoidSwitch: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: RbBasedInterfAvoid: If this option is selected, interfering neighboring cells adjacent to high-speed cells control available downlink RBs when high-speed trains pass by, reducing downlink interference to high-speed UEs but affecting the real-time experience of UEs in these neighboring cells. If this option is deselected, network performance is not affected.

PowerBasedInterfAvoid: If this option is selected, interfering neighboring cells adjacent to high-speed cells control the offset to downlink transmit power when high-speed trains pass by, reducing downlink interference to high-speed UEs but affecting the real-time coverage in these neighboring cells. If this option is deselected, network performance is not affected.

UlRbBasedInterfAvoid: If this option is selected, interfering neighboring cells adjacent to high-speed cells control available uplink RBs when high-speed trains pass by, reducing uplink interference to high-speed UEs but affecting the real-time experience of UEs in these neighboring cells. If this option is deselected, network performance is not affected.

UlPowerBasedInterfAvoid: If this option is selected, interfering neighboring cells adjacent to high-speed cells control the offset to uplink transmit power when high-speed trains pass by, reducing uplink interference to high-speed UEs but affecting the real-time experience of UEs in these neighboring cells. If this option is deselected, network performance is not affected.

RbBasedAbsoluteAvoidInd: If this option is selected, high-priority services, such as signaling, cannot be scheduled in the overlapping frequency bands between high-speed dedicated networks and public networks when high-speed trains pass by. This further reduces interference to UEs on high-speed dedicated networks, but affects user experience and KPIs on public networks. If this option is deselected when the RbBasedInterfAvoid or UlRbBasedInterfAvoid option is selected, network performance is the same as that achieved when the RbBasedInterfAvoid or UlRbBasedInterfAvoid option is selected.

HSCellSleepInterfAvoidSwitch: If this option is selected, high-speed cells adaptively enter sleep mode, conserving energy in these cells and reducing interference to adjacent cells. However, the performance of low-speed UEs in these high-speed cells deteriorates when these cells are in sleep mode. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
InterfBasedPowerOff Interference Based Power Offset

Meaning: Indicates the offset to the downlink transmit power or the offset used with the uplink high-SINR threshold in the low-speed cell adjacent to a high-speed cell. When high-speed trains pass by, the downlink transmit power of the low-speed cell or the uplink transmit power for low-priority services in this cell is decreased to reduce the downlink or uplink interference to high-speed UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a less significant power-based interference avoidance effect (that is, high-speed UEs experience higher downlink or uplink interference) and a smaller impact on the low-speed cells when high-speed trains pass by. A larger value of this parameter leads to a more significant power-based interference avoidance effect (that is, high-speed UEs experience lower downlink or uplink interference) and a greater impact on the low-speed cells when high-speed trains pass by.

Applicable Mode: L-FDD, L-TDD
InterfBasedRbRatio Interference Based RB Ratio

Meaning: Indicates the maximum percentage of RBs that can be used in the low-speed cell, for which the RbBasedInterfAvoid or UlRbBasedInterfAvoid option of the InterfAvoidMode parameter is selected. When high-speed trains travel through a high-speed cell, the eNodeB stops scheduling non-GBR bearers for non-emergency calls in the low-speed cell to reduce interference to high-speed UEs if the number of downlink or uplink RBs used per TTI in the low-speed cell is greater than a specified threshold. (This threshold is the result of the number of RBs of the bandwidth multiplied by the value of this parameter.) This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a more significant effect of interference avoidance based on downlink or uplink RB usage (that is, high-speed UEs experience lower interference) and a greater impact on the low-speed cells when high-speed trains pass by. A larger value of this parameter leads to a less significant effect of interference avoidance based on downlink or uplink RB usage (that is, high-speed UEs experience higher interference) and a smaller impact on the low-speed cells when high-speed trains pass by.

Applicable Mode: L-FDD

GUI Value Range: OFF(Off), ON(On)

HighSpeedOverlapBandInd High-Speed Overlapping Band Indicator

Meaning: Indicates the range of overlapping frequency bands between public cells and high-speed dedicated cells. The eNodeB cannot schedule PRBs within this range for public cells. This parameter takes effect only when the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED for public cells and the RbBasedInterfAvoid or UlRbBasedInterfAvoid option of the InterfAvoidMode parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OVERLAP_BAND_HIGH_5M(OVERLAP_BAND_HIGH_5M), OVERLAP_BAND_LOW_5M(OVERLAP_BAND_LOW_5M), OVERLAP_BAND_HIGH_10M(OVERLAP_BAND_HIGH_10M), OVERLAP_BAND_LOW_10M(OVERLAP_BAND_LOW_10M), OVERLAP_BAND_HIGH_15M(OVERLAP_BAND_HIGH_15M), OVERLAP_BAND_LOW_15M(OVERLAP_BAND_LOW_15M), OVERLAP_BAND_20M(OVERLAP_BAND_20M)

Unit: None

Actual Value Range: OVERLAP_BAND_HIGH_5M, OVERLAP_BAND_LOW_5M, OVERLAP_BAND_HIGH_10M, OVERLAP_BAND_LOW_10M, OVERLAP_BAND_HIGH_15M, OVERLAP_BAND_LOW_15M, OVERLAP_BAND_20M

MML Default Value: None

Recommended Value: OVERLAP_BAND_HIGH_5M(OVERLAP_BAND_HIGH_5M)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to more RBs available for adjacent public cells when high-speed trains pass the high-speed dedicated cell and smaller gains in interference suppression for high-speed UEs in the high-speed dedicated cell, but better user experience in public cells.

A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
HighSpeedCellSleepMode High Speed Cell Sleep Mode

Meaning: Indicates whether to allow high-speed cells to enter different sleep modes.

HS_CARR_POWER_DECREASE_MODE: If this option is selected, the eNodeB disables power decrease in the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells. After the train has left the local high-speed cell for a period, the eNodeB enables power decrease in this cell to conserve energy and reduce interference to adjacent cells. This option applies only to LTE FDD and LTE TDD.

HS_CARR_INTEL_SHUTDOWN_MODE: If this option is selected, the eNodeB disables intelligent carrier shutdown in the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells. After the train has left the local high-speed cell for a period, the eNodeB enables intelligent carrier shutdown in this cell to conserve energy and reduce interference to adjacent cells. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: HS_CARR_POWER_DECREASE_MODE(HS_CARR_POWER_DECREASE_MODE), HS_CARR_INTEL_SHUTDOWN_MODE(HS_CARR_INTEL_SHUTDOWN_MODE)

Unit: None

Actual Value Range: HS_CARR_POWER_DECREASE_MODE, HS_CARR_INTEL_SHUTDOWN_MODE

MML Default Value: None

Recommended Value: HS_CARR_POWER_DECREASE_MODE(HS_CARR_POWER_DECREASE_MODE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: HS_CARR_POWER_DECREASE_MODE: If this option is selected, power decrease is disabled in both the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells, and power decrease is enabled in the local high-speed cell when no high-speed train passes the local high-speed cell. This conserves energy in the cell and reduces interference to adjacent cells. However, power decrease in high-speed cells causes deterioration in the performance of low-speed UEs in these cells.

HS_CARR_INTEL_SHUTDOWN_MODE: If this option is selected, intelligent carrier shutdown is disabled in both the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells, and intelligent carrier shutdown is enabled in the local high-speed cell when no high-speed train passes the local high-speed cell. This conserves energy in the cell and reduces interference to adjacent cells. However, low-speed UEs cannot camp on high-speed cells when these cells are in the intelligent carrier shutdown state.

Applicable Mode: L-FDD, L-TDD
HighSpeedOptSwitch High Speed Optimization Switch

Meaning: Indicates whether to enable optimization algorithms in high speed mobility scenarios.

DL_AFC_OPT_SW: Indicates whether to enable the downlink AFC optimization algorithm. If this option is selected, this algorithm takes effect. If this option is deselected, the algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

LOW_SPEED_VOLTE_HO_SW: Indicates whether to hand over low-speed VoLTE UEs to low-speed frequencies. Select this option only for high-speed cells in high-speed railway scenarios. This option applies only to LTE FDD and LTE TDD.

HIGH_SPEED_INTRF_COORD_OPT_SW: Indicates whether to enable coordinated scheduling and interference suppression between public and dedicated networks in high-speed railway scenarios. If this option is selected, coordinated scheduling and interference suppression between public and dedicated networks are supported in high-speed railway scenarios. If this option is deselected, only public network interference avoidance is supported in high-speed railway scenarios. This option applies only to LTE FDD.

GUI Value Range: DL_AFC_OPT_SW(DL_AFC_OPT_SW), LOW_SPEED_VOLTE_HO_SW(LOW_SPEED_VOLTE_HO_SW), HIGH_SPEED_INTRF_COORD_OPT_SW(HIGH_SPEED_INTRF_COORD_OPT_SW)

Unit: None

Actual Value Range: DL_AFC_OPT_SW, LOW_SPEED_VOLTE_HO_SW, HIGH_SPEED_INTRF_COORD_OPT_SW

MML Default Value: None

Recommended Value: DL_AFC_OPT_SW: On for high-speed cells if the proportion of areas in which downlink AFC takes effect is low

LOW_SPEED_VOLTE_HO_SW: On for high-speed cells if there are a large number of low-speed VoLTE UEs in these cells

HIGH_SPEED_INTRF_COORD_OPT_SW: On for high-speed railway dedicated cells

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DL_AFC_OPT_SW: If this option is selected, the proportion of occasions where downlink AFC takes effect will increase, improving the downlink performance of high-speed UEs. If this option is deselected, downlink AFC is disabled and network performance is not affected.

LOW_SPEED_VOLTE_HO_SW: If this option is selected, VoLTE UEs may be handed over to low-speed neighboring cells, increasing the number of handovers of VoLTE UEs. If this option is deselected, VoLTE UEs will not be handed over to low-speed neighboring cells, which has no impact on the number of handovers of VoLTE UEs.

HIGH_SPEED_INTRF_COORD_OPT_SW: If this option is selected, PRB scheduling in coordinated cells is restricted based on the spectrum overlap range. If this option is deselected, PRB scheduling in coordinated cells is restricted based on the RB usage.

Applicable Mode: L-FDD, L-TDD

Example

To modify the HIGHSPDADAPTIONPARA configuration with the parameters as follows: Local cell ID: 0, High Speed User Number Threshold: 2, run the following command:
MOD HIGHSPDADAPTIONPARA: LocalCellId=0, HighSpeedUserNumThd=2;
