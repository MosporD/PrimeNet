Add CA group SCell configuration (ADD CAGROUPSCELLCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add CA group SCell configuration.

Note

The number of candidate SCells configured to accompany a candidate PCell cannot exceed the product specification if the AdpCaSwitch option is selected. If the number exceeds the specification, any extra CaGroupSCellCfg MOs will not take effect and the eNodeB cannot change candidate SCells accompanying the candidate PCell through UE measurements. The candidate SCells are not necessarily active SCells. They may be SCells configured but not activated, cells to which routes are not set up, or invalid cells.

SCellBlindCfgFlag SCell Blind Configuration Flag

Meaning: Indicates whether the candidate SCell can be configured as an SCell for CA UEs in a blind manner.

In CA-group-based configuration mode, this parameter takes effect if the SccBlindCfgSwitch option of the CaAlgoSwitch parameter is selected. In adaptive configuration mode, this parameter takes effect regardless of the SccBlindCfgSwitch setting.

If this parameter is set to TRUE, the eNodeB can configure this candidate SCell as an SCell for CA UEs in a blind manner, without delivering A4-related measurement configurations to the CA UEs.

If this parameter is set to FALSE, the eNodeB cannot configure this candidate SCell as an SCell for CA UEs in a blind manner. The eNodeB must deliver the A4 measurement configurations related to the operating frequency of the cell to CA UEs before the eNodeB can configure the cell as an SCell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: FALSE(FALSE), TRUE(TRUE)

Unit: None

Actual Value Range: FALSE, TRUE

MML Default Value: FALSE(FALSE)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SCellPriority SCell Priority

Meaning: Indicates the priority of the cell being configured as an SCell. A larger value of this parameter indicates a higher priority level. The value 0 indicates that this cell cannot be configured as an SCell for CA UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

SCellA4Offset SCell A4 Offset

Meaning: Indicates the offset to CarrAggrA4ThdRsrp in CA-group-based configuration mode. When a CA UE treats the cell specified by the LocalCellId parameter in the local eNodeB as its PCell, the UE reports event A4 pertaining to the candidate SCell specified by the SCelleNodeBId and SCellLocalCellId parameters to the eNodeB if the RSRP for the candidate SCell exceeds the sum of the CarrAggrA4ThdRsrp and SCellA4Offset parameter values. If the sum is greater than -43 dBm or less than -140 dBm, the threshold for event A4 takes the value -43 dBm or -140 dBm, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -35~62

Unit: dB

Actual Value Range: -35~62

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SCellA2Offset SCell A2 Offset

Meaning: Indicates the offset to CarrAggrA2ThdRsrp in CA-group-based configuration mode. When a CA UE treats the cell specified by the LocalCellId parameter in the local eNodeB as its PCell, the UE reports event A2 pertaining to the SCell specified by the SCelleNodeBId and SCellLocalCellId parameters to the eNodeB if the RSRP for the SCell falls below the sum of the CarrAggrA2ThdRsrp and SCellA2Offset parameter values. If the sum is greater than -43 dBm or less than -140 dBm, the threshold for event A2 takes the value -43 dBm or -140 dBm, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -31~66

Unit: dB

SpidGrpId SPID Group ID

Meaning: Indicates the ID of an SPID group. If this parameter is set to a value ranging from 0 to 255, the candidate SCell cannot be configured as an SCell for UEs in this SPID group. If this parameter is set to 65535, this cell can be configured as an SCell for these UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255,65535

Unit: None

Actual Value Range: 0~255,65535

MML Default Value: 65535

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value ranging from 0 to 255, the gains brought by CA for UEs in this SPID group decrease. If this parameter is set to 65535, the CA performance is not affected for the UEs.

Applicable Mode: L-FDD, L-TDD

Example

To add CA group SCell configuration with the parameters as follows: Local cell identity: 0,  SCell eNodeB identity: 1, SCell local cell identity: 1, SCell priority: 5, run the following command:
ADD CAGROUPSCELLCFG: LocalCellId=0, SCelleNodeBId=1, SCellLocalCellId=1, SCellPriority=5;
