Modify Cell Backoff Algorithm Configuration (MOD CELLBACKOFF)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to load balancing by transferring UEs with low spectral efficiency in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterFreqBackoffPrbThd Inter-Frequency Backoff PRB Threshold

Meaning: Indicates the PRB usage threshold for triggering inter-frequency MLB for low-efficiency UEs. When the UE quantity-related trigger conditions are met and the cell load is greater than or equal to the value of this parameter plus the load offset, inter-frequency MLB is triggered for low-efficiency UEs. When the UE quantity-related exit conditions are met or the cell load is lower than the value of this parameter, inter-frequency MLB is stopped for low-efficiency UEs. This parameter applies only to LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship:

-Configuration constraints:

  • In the CellBackOff MO, the RBPriMcsSelectStopPrbThd parameter must be set to a value smaller than that of the InterFreqBackoffPrbThd parameter.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter decreases the possibility that low-efficiency UEs are handed over from the local cell during inter-frequency MLB, thereby decreasing the average cell throughput and the number of handovers. A small value of this parameter increases this possibility, thereby increasing the average cell throughput and the number of handovers.

Applicable Mode: L-TDD
InterFreqBackoffUeNumThd Inter-Frequency Backoff UE Number Threshold

Meaning: Indicates the threshold of the number of synchronized UEs for triggering inter-frequency MLB for low-efficiency UEs. When the PRB usage-related trigger conditions are met and the number of synchronized UEs in the local cell is greater than or equal to the value of this parameter plus the offset of the minimum number of UEs for MLB, inter-frequency MLB is triggered for low-efficiency UEs. When the PRB usage-related exit conditions are met or the number of synchronized UEs in the local cell is less than the value of this parameter, inter-frequency MLB is stopped for low-efficiency UEs. This parameter applies only to LTE TDD.

LowestEffDlMcsThd Lowest Efficiency DL MCS Threshold

Meaning: Indicates the downlink MCS index threshold for selecting extra-low-efficiency UEs for MLB. The eNodeB considers a UE as a low-efficiency UE when either of the following conditions are met: (a) The downlink MCS index of the UE is less than the value of this parameter. (b) The downlink MCS index of the UE is greater than or equal to the value of this parameter and is less than or equal to the value of the LowEffDlMcsThd parameter, and the PRB usage criteria are met. The eNodeB considers a UE as a low-efficiency UE if the downlink MCS index of the UE is lower than this threshold. This option applies only to LTE FDD and LTE TDD.

HoInRejectPrbThd Handover In Reject PRB Threshold

Meaning: Indicates the PRB usage threshold for triggering rejection of incoming handover requests of UEs from inter-duplex-mode cells after inter-frequency low-efficient MLB is triggered. When the InterFreqBackoffSwitch option of the BackoffAlgoSwitch parameter is selected and the IfBackoffHoInRejectSwitch option of the MlbMatchOtherFeatureMode parameter is selected, the eNodeB rejects incoming handover requests of UEs from inter-duplex-mode cells if the PRB usage of the target cell is greater than or equal to this threshold. This parameter applies only to LTE TDD.

MML Default Value: None

RejectedHoInCause Rejected Handover In Cause

Meaning: Indicates the handover cause values carried by incoming handover requests of UEs from inter-duplex-mode cells that must be rejected after inter-frequency low-efficient MLB is triggered. After inter-frequency low-efficient MLB is triggered, if the cause value indicated by the selected option of this parameter is contained in an incoming handover request of a UE from an inter-duplex-mode cell, the eNodeB rejects the handover request. If the cause value indicated by the selected option of this parameter is not contained in the handover request, the eNodeB accepts the handover request. This parameter is valid only if the IfBackoffHoInRejectSwitch option of the MlbMatchOtherFeatureMode parameter is selected. This parameter applies only to LTE TDD.

BackoffCAUserHOSw Backoff CA User HO Switch

Meaning: Indicates whether to enable load balancing for low-efficiency CA UEs.

If this parameter is set to ON, load balancing is enabled for low-efficiency CA UEs. The eNodeB selects low-efficiency CA UEs and initiates blind handovers for low-efficiency FDD+TDD CA UEs. If this parameter is set to OFF, load balancing is disabled for low-efficiency CA UEs. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the eNodeB selects low-efficiency CA UEs and preferentially performs blind handovers for low-efficiency FDD+TDD CA UEs, reducing the impact of inter-frequency measurement on user perception. However, the handover success rate decreases if SCC handover parameters are improperly set. If this parameter is set to OFF, the eNodeB does not select low-efficiency CA UEs for load balancing.

Applicable Mode: L-TDD
BackoffMlbEnhSw Backoff MLB Enhancement Switch

Meaning: Indicates whether to enable MLB enhancement for low-efficiency UEs.

ADAPTIVE_MCS_THLD_SW: Indicates whether to enable MCS index threshold adaptation. If this option is selected, MCS index threshold adaptation is performed during UE selection after MLB for low-efficiency UEs is enabled. If this option is deselected, a fixed MCS index threshold is used to select UEs after MLB for low-efficiency UEs is enabled. This option applies only to LTE TDD.

GUI Value Range: ADAPTIVE_MCS_THLD_SW(ADAPTIVE_MCS_THLD_SW)

Unit: None

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: ADAPTIVE_MCS_THLD_SW: If this option is selected and the LowestEffUlMcsThd parameter in the CellBackOff MO is set to a larger value, more low-efficiency UEs can be selected for MLB. If this option is deselected, network performance is not affected.

Applicable Mode: L-TDD

Example

To modify the cell Backoff Algorithm Configuration with the parameters as follows: Local cell ID: 0, Inter-Frequency Backoff PRB Threshold: 60, run the following command:
MOD CELLBACKOFF: LocalCellId=0, InterFreqBackoffPrbThd=60;
