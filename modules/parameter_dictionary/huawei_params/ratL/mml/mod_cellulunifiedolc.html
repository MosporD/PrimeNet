Modify Configurations of UMTS and LTE Unified Overload Control (MOD CELLULUNIFIEDOLC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to UL unified overload control in cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RrcRejectRateHighThd High RRC Reject Rate Thd for UL Uni-OLC

Meaning: Indicates the threshold of the resource-insufficiency-induced RRC connection rejection rate, which is used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when both of the following conditions are met: (1) The resource-insufficiency-induced RRC connection rejection rate is greater than the RrcRejectRateHighThd parameter value; (2) The number of RRC connection setup requests is greater than the RrcReqNumHighThd parameter value. The actual threshold equals the percentage value of this parameter divided by 10. For example, the GUI value 10 indicates that the actual value is 1% (= 10 x 1%/10). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~200

Unit: %

Actual Value Range: 0~200

MML Default Value: None

Recommended Value: 50

Parameter Relationship:

-Configuration constraints:

  • In the CellULUnifiedOLC MO, the value of RrcRejectRateLowThd must be less than the value of RrcRejectRateHighThd.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that UMTS and LTE unified overload control is triggered when the cell is overloaded. As a result, the RRC connection setup success rate decreases and the success rate of handovers between LTE and UMTS decreases. A smaller value of this parameter results in a higher probability that UMTS and LTE unified overload control is triggered, which causes an increase in the RRC connection setup success rate and the success rate of handovers between LTE and UMTS, and may also cause a decrease in the number of handovers between LTE and UMTS and cell reselections.

Applicable Mode: L-FDD, L-TDD
RrcRejectRateLowThd Low RRC Reject Rate Thd for UL Uni-OLC

Meaning: Indicates the threshold of the resource-insufficiency-induced RRC connection rejection rate, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. The actual threshold equals the percentage value of this parameter divided by 10. For example, the GUI value 10 indicates that the actual value is 1% (= 10 x 1%/10). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~200

Unit: %

Actual Value Range: 0~200

MML Default Value: None

Recommended Value: 10

Parameter Relationship:

-Configuration constraints:

  • In the CellULUnifiedOLC MO, the value of RrcRejectRateLowThd must be less than the value of RrcRejectRateHighThd.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that UMTS and LTE unified overload control is not triggered when the cell is overloaded. As a result, the RRC connection setup success rate decreases and the LTE-to-UMTS handover success rate decreases. A smaller value of this parameter results in a higher probability that UMTS and LTE unified overload control is triggered, which causes an increase in the RRC connection setup success rate and the LTE-to-UMTS handover success rate, but may also cause a decrease in the number of LTE-to-UMTS handovers and cell reselections.

Applicable Mode: L-FDD, L-TDD
RrcReqNumHighThd High RRC Request Number Thd for UL Uni-OLC

Meaning: Indicates the threshold of the number of RRC connection setup requests, which is used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when both of the following conditions are met: (1) The number of RRC connection setup requests is greater than the RrcReqNumHighThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is greater than the RrcRejectRateHighThd parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~20000

Unit: None

Actual Value Range: 1~20000

MML Default Value: None

Recommended Value: 2000

Parameter Relationship:

-Configuration constraints:

  • In the CellULUnifiedOLC MO, the value of RrcReqNumLowThd must be less than the value of RrcReqNumHighThd.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that UMTS and LTE unified overload control is not triggered when the cell is overloaded. As a result, the RRC connection setup success rate decreases and the success rate of handovers between LTE and UMTS decreases. A smaller value of this parameter results in a higher probability that UMTS and LTE unified overload control is triggered. This causes an increase in the RRC connection setup success rate and the success rate of handovers between LTE and UMTS, and may also cause a decrease in the number of handovers between LTE and UMTS and cell reselections.

Applicable Mode: L-FDD, L-TDD
RrcReqNumLowThd Low RRC Request Number Thd for UL Uni-OLC

Meaning: Indicates the threshold of the RRC connection setup request number, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~20000

Unit: None

Actual Value Range: 1~20000

MML Default Value: None

Recommended Value: 1000

Parameter Relationship:

-Configuration constraints:

  • In the CellULUnifiedOLC MO, the value of RrcReqNumLowThd must be less than the value of RrcReqNumHighThd.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of stopping UMTS and LTE unified overload control. Therefore, the RRC connection setup success rate increases and the success rate of handovers between LTE and UMTS increases, and the number of handovers between LTE and UMTS and cell reselections may decrease. A larger value of this parameter results in a higher probability of stopping UMTS and LTE unified overload control even when the cell is overloaded. This causes a decrease in the RRC connection setup success rate and the success rate of handovers between LTE and UMTS.

Applicable Mode: L-FDD, L-TDD
UeNumHighThd High UE Number Thd for UL Uni-OLC

Meaning: Indicates the RRC_CONNECTED UE number threshold used to determine whether to start UMTS and LTE unified overload control. UMTS and LTE unified overload control starts when the number of RRC_CONNECTED UEs is greater than this parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1200

Unit: None

Actual Value Range: 1~1200

MML Default Value: None

Recommended Value: 400

Parameter Relationship:

-Configuration constraints:

  • In the CellULUnifiedOLC MO, the value of UeNumLowThd must be less than the value of UeNumHighThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that UMTS and LTE unified overload control is not triggered when the cell is overloaded. As a result, the RRC connection setup success rate decreases and the success rate of handovers between LTE and UMTS decreases. A smaller value of this parameter results in a higher probability that UMTS and LTE unified overload control is triggered. Therefore, the RRC connection setup success rate increases and the success rate of handovers between LTE and UMTS increases. In addition, the number of handovers between LTE and UMTS and cell reselections may decrease.

Applicable Mode: L-FDD, L-TDD
UeNumLowThd Low UE Number Thd for UL Uni-OLC

Meaning: Indicates the threshold of the RRC_CONNECTED UE number, which is used to determine whether to stop UMTS and LTE unified overload control. UMTS and LTE unified overload control stops if all of the following conditions are met: (1) The number of RRC_CONNECTED UEs is less than the UeNumLowThd parameter value; (2) The resource-insufficiency-induced RRC connection rejection rate is less than the RrcRejectRateLowThd parameter value; (3) The number of RRC connection setup requests is less than the RrcReqNumLowThd parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1200

Unit: None

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of stopping UMTS and LTE unified overload control. Therefore, the RRC connection setup success rate increases and the success rate of handovers between LTE and UMTS increases, and the number of handovers between LTE and UMTS and cell reselections may decrease. A larger value of this parameter results in a higher probability of stopping UMTS and LTE unified overload control even when the cell is overloaded. This causes a decrease in the RRC connection setup success rate and the success rate of handovers between LTE and UMTS.

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of the UL Uni-OLC with the parameters as follows: Local cell ID: 1, High RRC Reject Rate Thd for UL Uni-OLC:51%, run the following command:
MOD CELLULUNIFIEDOLC:LocalCellId=1, RrcRejectRateHighThd=51;
