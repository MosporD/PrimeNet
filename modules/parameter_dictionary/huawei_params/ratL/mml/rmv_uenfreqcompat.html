Remove UE Neighboring Frequency Compatibility Parameter (RMV UENFREQCOMPAT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the configurations of neighboring frequency compatibility parameters for specific UEs.

Note

None.

Parameters

ID Name Description
BlacklistedNFreqEarfcn Blacklisted Neighboring Freq EARFCN

Meaning: Indicates the downlink EARFCN of the blacklisted neighboring frequency. For defective UEs, the eNodeB performs as follows: 1. The eNodeB does not deliver measurement configuration for this frequency. 2. The eNodeB does not add this frequency as an SCC. 3. The eNodeB does not perform handovers or redirections to this frequency. 4. The eNodeB does not handle measurement reports about this frequency. If some UEs have a defect in some functions on a specific frequency, it is recommended that this frequency be configured as a blacklisted neighboring frequency. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~229575

Unit: None

Actual Value Range: 1~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When network KPIs are affected because some UEs have a defect in some functions on a specific frequency, setting this frequency as a blacklisted frequency helps decrease the number of RRC connection reestablishments, service drop rate, and number of SCell addition attempts for CA UEs and increase the inter-frequency handover success rate.

Applicable Mode: L-FDD, L-TDD
UeCompatIndex UeCompatIndex

Meaning: Indicates the index of a compatibility processing action for defective UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the configurations of neighboring frequency compatibility parameters for specific UEs, where BlacklistedNFreqEarfcn is 1, UeCompatIndex is 1: RMV UENFREQCOMPAT: BlacklistedNFreqEarfcn=1, UeCompatIndex=1;
