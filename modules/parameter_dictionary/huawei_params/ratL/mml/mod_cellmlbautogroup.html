Modify Cell MLB Auto Group Configuration (MOD CELLMLBAUTOGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify automatic grouping information for MLB between cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
OverlapIndAddThd Overlap Indicator Addition Threshold

Meaning: Indicates the threshold for setting the overlap indicator. The eNodeB compares the measured proportion of coverage overlap between the serving cell and each inter-frequency neighboring cell with this threshold. If the proportion for an inter-frequency neighboring cell exceeds or equals this threshold, the eNodeB sets the overlap indicator for the neighboring cell.

A smaller value of this parameter indicates a lower coverage overlap requirement for setting the overlap indicator. A larger value of this parameter results in the opposite effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 40

Parameter Relationship:

-Configuration constraints:

  • In a CellMlbAutoGroup MO, the value of OverlapIndAddThd must be larger than OverlapIndDelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
OverlapIndDelThd Overlap Indicator Deletion Threshold

Meaning: Indicates the threshold for clearing the overlap indicator. With auto neighbor group configuration (ANGC) for MLB, the eNodeB compares the measured proportion of coverage overlap between the serving cell and an inter-frequency neighboring cell with this threshold. If the overlap indicator has been set for the inter-frequency neighboring cell and the proportion for the neighboring cell is less than the threshold, the eNodeB clears the overlap indicator for the cell.

A smaller value of this parameter results in a lower probability of clearing the overlap indicator. A larger value results in a higher probability. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 30

Parameter Relationship:

-Configuration constraints:

  • In a CellMlbAutoGroup MO, the value of OverlapIndAddThd must be larger than OverlapIndDelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StatPeriod Statistic Period

Meaning: Indicates the measurement period of ANGC for MLB. If the number of samples collected in a period meets the requirement, the eNodeB calculates the coverage overlap proportion and sets or clears overlap indicators within the period. If the number of samples collected in the period does not meet the requirement, the eNodeB automatically extends a second period and performs accumulated statistics collection. To ensure the work efficiency of the algorithm, the eNodeB extends only one period for sample counting.

A shorter measurement period results in faster setting or clearing of overlap indicators. A longer measurement period results in the opposite effect. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65535

Unit: min

Actual Value Range: 1~65535

MML Default Value: None

Recommended Value: 1440

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell reselection for UEs in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SleepPeriod Sleep Period

Meaning: Indicates the sleep period during which ANGC for MLB stops working after one round of statistics collection and configuration. The function resumes after the sleep period if the network topology changed during the sleep period. If this parameter is set to 65535, ANGC for MLB does not enter the sleep period but periodically works. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: min

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 1440

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell reselection for UEs in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AddedMeasCfg Additional Measurement Configuration

Meaning: Indicates whether the eNodeB can instruct UEs to perform additional measurements to provide more samples for collecting statistics. During Auto Neighbor Group Configuration (ANGC) for MLB, if the number of collected samples is insufficient, the eNodeB instructs UEs to perform additional measurements so that the number of samples may reach the preset quantity threshold.

If this parameter is set to ALLOWED, the eNodeB instructs UEs to perform additional measurements in an extension period that automatically starts when the number of samples in a measurement period does not reach the preset target. If this parameter is set to NOT_ALLOWED, the eNodeB does not instruct UEs to perform additional measurements. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_ALLOWED(NOT_ALLOWED), ALLOWED(ALLOWED)

Unit: None

Actual Value Range: NOT_ALLOWED, ALLOWED

MML Default Value: None

Recommended Value: NOT_ALLOWED(NOT_ALLOWED)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_ALLOWED, it has no impact on network performance. If this parameter is set to ALLOWED, the additional measurement may decrease the downlink throughput of UEs that are involved in the additional measurements.

Applicable Mode: L-FDD, L-TDD
OverlapIndAutoSampleNum Overlap Indicator Auto Sample Number

Meaning: Indicates the minimum required number of A4 and A5 measurement report samples for starting coverage evaluation during ANGC for MLB. The eNodeB starts coverage evaluation only if the number of samples reaches or exceeds the value of this parameter. Based on the samples, the eNodeB will calculate the coverage overlap proportion and sets or clears the overlap indicator for the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65535

Unit: None

Actual Value Range: 1~65535

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell reselection for UEs in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
OptMode Optimization Mode

Meaning: Indicates the working mode of auto neighbor group configuration (ANGC) for MLB.

If this parameter is set to FREE, the eNodeB automatically sets or clears the overlap indicator. If this parameter is set to CONTROLLED, the eNodeB reports the advice on setting or clearing the overlap indicator to the MAE, and operators determine whether to take the advice. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: FREE(FREE), CONTROLLED(CONTROLLED)

Unit: None

Actual Value Range: FREE, CONTROLLED

MML Default Value: None

Recommended Value: FREE(FREE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MicroOverlapIndAddThd Micro Overlap Indicator Addition Threshold

Meaning: Indicates the threshold for adding an overlap indicator to a micro cell. The automatic overlap indicator configuration function of the micro cell checks the percentage of the overlapping area between the micro cell and inter-frequency macro cell. If the percentage is greater than or equal to this threshold, the micro cell requests the macro cell to add an overlap indicator to the micro cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 95

Parameter Relationship:

-Configuration constraints:

  • In a CellMlbAutoGroup MO, the value of MicroOverlapIndAddThd must be larger than MicroOverlapIndDelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MicroOverlapIndDelThd Micro Overlap Indicator Deletion Threshold

Meaning: Indicates the threshold for clearing the overlap indicator of a micro cell. The automatic overlap indicator configuration function of the micro cell checks the percentage of the overlapping area between the micro cell and inter-frequency macro cell. If the percentage is smaller than this threshold and the micro cell is labeled an overlap indicator, the micro cell requests the macro cell to clear the overlap indicator of the micro cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 85

Parameter Relationship:

-Configuration constraints:

  • In a CellMlbAutoGroup MO, the value of MicroOverlapIndAddThd must be larger than MicroOverlapIndDelThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
