Modify Service Identify Parameter (MOD SERVICEIDENTIFYPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to service identify.

Note

None.

Parameters

ID Name Description
HeartbeatPacketLengthThld Heartbeat Packet Length Threshold

Meaning: Indicates the threshold of the length of an IP packet for identifying heartbeat services. If the length of any IP packet of a service sent in 2s after RRC connection setup exceeds this threshold, the service is not identified as a heartbeat service. This parameter takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected. This parameter applies only to LTE TDD.

GUI Value Range: 40~1500

Unit: Byte

Actual Value Range: 40~1500

MML Default Value: None

Recommended Value: 180

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, a small number of services are identified as heartbeat services. If this parameter is set to a large value, a large number of services are identified as heartbeat services.

Applicable Mode: L-TDD
HeartbeatPacketNumberThld Heartbeat Packet Number Threshold

Meaning: Indicates the threshold of the number of IP packets of a service for identifying heartbeat services. If the number of IP packets of a service sent within 2s after RRC connection setup exceeds this threshold, the service is not identified as a heartbeat service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

GUI Value Range: 4~50

Unit: None

Actual Value Range: 4~50

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, a small number of services are identified as heartbeat services. If this parameter is set to a large value, a large number of services are identified as heartbeat services.

Applicable Mode: L-TDD
MassFlowBigPacketRateThld Mass Flow Big Packet Rate Threshold

Meaning: Indicates the threshold of the proportion of large downlink IP packets of a service to all IP packets in a measurement period. This threshold is used together with the MassFlowPacketNumberThld parameter to identify heavy-traffic services. If the proportion of large downlink IP packets of a service exceeds this threshold and the number of downlink IP packets of the service exceeds the MassFlowPacketNumberThld parameter, the service is identified as a heavy-traffic service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, a large number of services are identified as heavy-traffic services. If this parameter is set to a large value, a small number of services are identified as heavy-traffic services.

Applicable Mode: L-TDD
MassFlowDuration Mass Flow Monitor Duration

Meaning: Indicates the measurement period for identification of heavy-traffic services. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

GUI Value Range: 2~60

Unit: s

Actual Value Range: 2~60

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the eNodeB identifies heavy-traffic services quickly but less accurately. If this parameter is set to a large value, the eNodeB identifies heavy-traffic services more accurately but relatively slowly.

Applicable Mode: L-TDD
MassFlowPacketNumberThld Mass Flow Packet Number Threshold

Meaning: Indicates the threshold of the number of downlink IP packets of a service, which is used together with the MassFlowBigPacketRateThld parameter to identify heavy-traffic services. If the proportion of large downlink IP packets of a service exceeds the value of the MassFlowBigPacketRateThld parameter and the number of downlink IP packets of the service exceeds the value of the MassflowPacketNumberThd parameter, the service is identified as a heavy-traffic service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

GUI Value Range: 50~65535

Unit: None

Actual Value Range: 50~65535

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, a large number of services are identified as heavy-traffic services. If this parameter is set to a large value, a small number of services are identified as heavy-traffic services.

Applicable Mode: L-TDD

Example

To modify service identify parameter as follows: Heartbeat Packet Length Threshold: 40,  run the following command:
MOD SERVICEIDENTIFYPARA: HeartbeatPacketLengthThld=40;
