Display parameters of an LTE and NR spectrum sharing cell group (DSP LTENRSPCTSHRCELLGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query parameters of an LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
LteNrSpectrumShrCellGrpId LTE and NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Display LteNrSpctShrCellGrp:
DSP LTENRSPCTSHRCELLGRP:;
The result is shown as follows:

Output Description

Field Description

LTE and NR Spectrum Sharing Cell Group ID

Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

PLMN ID

Indicates the PLMN ID of the eNodeB that serves as an auxiliary base station and on which the LTE and NR spectrum sharing cell group is configured. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the ID of the eNodeB that serves as an auxiliary base station and on which the LTE and NR spectrum sharing cell group is configured. This parameter applies only to LTE FDD and LTE TDD.

Peer NR Spectrum Sharing Cell Group ID

Indicates the ID of the NR spectrum sharing cell group (configured on the gNodeB) that corresponds to the LTE and NR spectrum sharing cell group configured on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Peer PLMN ID

Indicates the primary-operator PLMN ID of the gNodeB for the NR spectrum sharing cell group that corresponds to the LTE and NR spectrum sharing cell group configured on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Peer gNodeB ID

Indicates the ID of the gNodeB for the NR spectrum sharing cell group that corresponds to the LTE and NR spectrum sharing cell group configured on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Spectrum Sharing Status

Indicates the spectrum sharing status of the LTE and NR spectrum sharing cell group on the LTE side and the corresponding NR spectrum sharing cell group on the NR side. This parameter applies only to LTE FDD and LTE TDD.

Local Cell Id

Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

Cell ID

Indicates the ID of a cell served by a base station involved in spectrum sharing. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

Cell Spectrum Sharing Status

Indicates the spectrum sharing status of an LTE cell in LTE and NR spectrum sharing scenarios. This parameter applies only to LTE FDD and LTE TDD.

Downlink Filtered PRB Usage(%)

Indicates the alpha filtered value of the downlink PRB usage of an LTE cell in LTE TDD and NR spectrum sharing scenarios. Since the downlink PRB usage is an integer, the filtered value of the downlink PRB usage may be 0 when the traffic volume in the LTE cell is extremely low. This parameter applies only to LTE FDD and LTE TDD.

Uplink Filtered PRB Usage(%)

Indicates the alpha filtered value of the uplink PRB usage of an LTE cell in LTE TDD and NR spectrum sharing scenarios. Since the uplink PRB usage is an integer, the filtered value of the uplink PRB usage may be 0 when the traffic volume in the LTE cell is extremely low. This parameter applies only to LTE FDD and LTE TDD.

DL Filtered Value of Spectral Efficiency(bits/RB)

Indicates the filtered value of the downlink spectral efficiency of an LTE cell in LTE TDD and NR spectrum sharing scenarios. This parameter applies only to LTE FDD and LTE TDD.

UL Filtered Value of Spectral Efficiency(bits/RB)

Indicates the filtered value of the uplink spectral efficiency of an LTE cell in LTE TDD and NR spectrum sharing scenarios. When a UE does not perform services, measurement of the uplink spectral efficiency may include empty MAC packets. This parameter applies only to LTE FDD and LTE TDD.

Filtered RRC Connected User Number

Indicates the alpha filtered value of the number of RRC_CONNECTED UEs in an LTE cell in LTE TDD and NR spectrum sharing scenarios. This parameter applies only to LTE FDD and LTE TDD.

LNR Spectrum Conversion Protection Timer(S)

Indicates the timer used for protection of LTE and NR spectrum conversion in LTE TDD and NR spectrum sharing scenarios. The timer starts when LTE and NR spectrum conversion is triggered. The conversion is not allowed before the protection timer expires. This parameter applies only to LTE TDD.
