Add External GERAN Cell (ADD GERANEXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an external GERAN cell.

Note

  • GERAN RAN Information Management (RIM) requires the routing area code (RAC) of the GERAN cell.

  • If the external GERAN cell to be added operates in RAN sharing with common carriers or hybrid RAN sharing mode, an additional PLMN ID must be added for the external GERAN cell.

  • A maximum of 1152 external GERAN cells can be configured for an eNodeB.

If this parameter is set to BOOLEAN_FALSE, the external GERAN cell does not support ultra-flash CSFB to GERAN. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: If this parameter is set to BOOLEAN_TRUE, the external GERAN cell supports ultra-flash CSFB and UEs fall back to the GERAN cell based on the ultra-flash CSFB procedure, thereby decreasing delay and improving user experience, compared with the standard CSFB procedure. Meaning: Indicates whether the neighbor cell can be selected for handovers during roaming. This parameter is set to NO(No) by default.

If this parameter is set to YES(Yes), this neighboring cell can be selected for handovers during roaming. If this parameter is set to NO(No), this neighboring cell cannot be selected for handovers during roaming.

If the PLMN of the neighboring cell is included in the SPID-based handover-allowable HPLMN list or this parameter is set to YES(Yes), this neighboring cell can be selected for handovers.

In the boundaries of roaming areas and non-roaming areas, you are advised to set this parameter to YES(Yes) to ensure that neighboring cells in roaming areas can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.

CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. The policy specified by this parameter also applies to the GeranExternalCellPlmn MOs under this MO. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AUTO_MODE(Auto Mode), MANUAL_MODE(Manual Mode)

Unit: None

Actual Value Range: AUTO_MODE, MANUAL_MODE

MML Default Value: AUTO_MODE(Auto Mode)

Recommended Value: AUTO_MODE(Auto Mode)

Example

Example 1: To add an external GERAN cell with the parameters as follows: Mobile country code: "460", Mobile network code: "20", GERAN cell ID: 15, Location area code: 12, Routing area code indicator: CFG, Routing area code: 14, Band indicator: GSM_dcs1800, GERAN ARFCN: 10, Network colour code: 0, Base station colour code: 0, CS and PS handover indication :BOOLEAN_FALSE, run the following command:
ADD GERANEXTERNALCELL: Mcc="460", Mnc="20", GeranCellId=15, Lac=12, RacCfgInd=CFG, Rac=14, BandIndicator=GSM_dcs1800, GeranArfcn=10, NetworkColourCode=0, BaseStationColourCode=0, CsPsHOInd = BOOLEAN_FALSE;
Example 2: To add an external GERAN cell with the parameters as follows: Mobile country code: "460", Mobile network code: "20", GERAN cell ID: 17, Location area code: 13, Routing area code indicator: CFG, Routing area code: 16, Band indicator: GSM_pcs1900, GERAN ARFCN: 12, Network colour code: 0, Base station colour code: 0, CS and PS handover indication :BOOLEAN_FALSE, run the following command:
ADD GERANEXTERNALCELL: Mcc="460", Mnc="20", GeranCellId=17, Lac=13, RacCfgInd=CFG, Rac=16, BandIndicator=GSM_pcs1900, GeranArfcn=12, NetworkColourCode=0, BaseStationColourCode=0, CsPsHOInd = BOOLEAN_FALSE;
