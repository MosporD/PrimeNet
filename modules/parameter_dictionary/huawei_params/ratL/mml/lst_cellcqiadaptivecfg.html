List Cell Adaptive CQI Configuration (LST CELLCQIADAPTIVECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to CQI adaptation.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Cell Adaptive CQI Configuration:
LST CELLCQIADAPTIVECFG:;
The result is shown as follows:
+++    0        2019-12-05 09:07:26
O&M    #806355225
%%LST CELLCQIADAPTIVECFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local Cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

CQI Period Adaptive Switch

Indicates whether to enable CQI reporting period adaptation. If this parameter is set to ON, the CQI reporting period adaptively changes based on the air interface load of the cell. If this parameter is set to OFF, the CQI reporting period is specified by the UserCqiPeriod parameter in the CellCqiAdaptiveCfg MO. This parameter applies only to LTE FDD and LTE TDD.

User CQI period(ms)

Indicates the fixed CQI reporting period. This parameter takes effect only if the CqiPeriodAdaptive parameter is set to OFF(Off). If the UserCqiPeriod parameter is set to ms2(2ms), the period is automatically changed to 5ms for the TDD cell. This parameter applies only to LTE FDD and LTE TDD.

SimulAckNackAndCQI Config Switch

Indicates whether CQI and ACK/NACK can be simultaneously sent on the PUCCH. For details about PUCCH formats, see 3GPP TS 36.213.

If this parameter is set to OFF, the value of simultaneousAckNackAndCQI is set to False.

If this parameter is set to ON, the value of simultaneousAckNackAndCQI depends on the DRX status of a UE, the settings of the DrxSimulAckNackAndCqiSwitch and CqiMask parameters.

(1) If the UE is not in the DRX state, the value of simultaneousAckNackAndCQI varies depending on the CA state of the UE. If the UE is not in the CA state, the value is set to True. If the UE is in the CA state, the value depends on the setting of CaCqiAndAckAbnCtrlSwitch for the eNodeB.

(2) If the UE is in the DRX state and:

(i) If CqiMask is set to ON, the value of simultaneousAckNackAndCQI varies depending on the CA state of the UE. If the UE is not in the CA state, the value is set to True. If the UE is in the CA state, the value depends on the setting of CaCqiAndAckAbnCtrlSwitch for the eNodeB.

(ii) If CqiMask is set to OFF, the value of simultaneousAckNackAndCQI varies depending on the setting of DrxSimulAckNackAndCqiSwitch. If DrxSimulAckNackAndCqiSwitch is selected and the number of configured transmit antennas for the cell is greater than two, the value of simultaneousAckNackAndCQI is set to True for the UE not in the CA state or depends on the setting of CaCqiAndAckAbnCtrlSwitch for the UE in the CA state. If DrxSimulAckNackAndCqiSwitch is deselected, the value of simultaneousAckNackAndCQI is set to False.

If the value of simultaneousAckNackAndCQI is set to True, CQI and ACK/NACK can be simultaneously sent on the PUCCH. If the value of simultaneousAckNackAndCQI is set to False, CQI and ACK/NACK cannot be simultaneously sent on the PUCCH.

Handover Aperiodic CQI Config Switch

Indicates the aperiodic CQI resource configurations and the triggering condition of aperiodic CQI reporting during handovers. If this parameter is set to ON(On), aperiodic CQI resource configurations are included in handover commands. When no periodic CQI resources are configured for a UE, an aperiodic CQI reporting is triggered when the handed-over UE receives data. If this parameter is set to OFF(Off), aperiodic CQI resource configurations are not included in handover commands. The aperiodic CQI resource is configured after the UE is handed over. This parameter applies only to LTE FDD and LTE TDD.

Minimal CQI Period(ms)

Indicates the minimum period of periodic CQI reporting. If the CqiPeriodAdaptive parameter is set to ON, the CQI reporting period cannot be less than this parameter value under different PUCCH load conditions. This parameter is valid only if the CqiPeriodAdaptive parameter is set to ON. This parameter applies only to LTE FDD.

Enhanced SCC CQI Reporting Switch

Indicates whether to enable SCell CQI reporting enhancement. If this parameter is set to ON, SCell periodic CQI reporting is not configured for UEs treating the local cell as their PCell and only SCell aperiodic CQI reporting can be triggered. If this parameter is set to OFF, the UEs send SCell periodic and aperiodic CQI reports following the common process. This parameter applies only to LTE FDD.
