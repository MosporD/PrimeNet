Modify PrbRachCeConfig Configuration in an NB-IoT Cell (MOD PRBRACHCECONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the coverage-level-specific RACH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • For a cell, modifications on the PrachSubcarrierOffset, EdtPrachSubcarrierOffset, PrachAlgoSw parameter of an active cell would result in the automatic reset of the cell or prb.

  • For a cell, modifications on the offset to the starting position of PRACH Transmission Period domain of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the offset to the starting position of PRACH Repetition Count domain of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the PRACH Start Time of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the PRACH Probability for Anchor of an active cell would result in the automatic reset of the cell.

  • The start time difference between coverage levels of a cell must not be less than 40 ms.

  • For a cell, modifications on the PRACH Subcarrier Number of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the Competitive PRACH Subcarrier Number of an active cell would result in the automatic reset of the cell.

Otherwise, the NB-IoT cell cannot work. This parameter applies only to NB-IoT.

PrachSubcarrierNumber PRACH Subcarrier Number

Meaning: Indicates the number of subcarriers used for the PRACH. The number of PRACH subcarriers for EDT is not configurable. Currently, the number is fixed at 12. This parameter applies only to NB-IoT.

GUI Value Range: SC_NUM_12(SC_NUM_12), SC_NUM_24(SC_NUM_24), SC_NUM_36(SC_NUM_36), SC_NUM_48(SC_NUM_48)

Unit: None

Actual Value Range: SC_NUM_12, SC_NUM_24, SC_NUM_36, SC_NUM_48

MML Default Value: None

Recommended Value: SC_NUM_12(SC_NUM_12)

Parameter Relationship:

-Configuration constraints:

  • The PrachCbraSubcarrierNumber parameter in a PrbRachCeConfig MO must be set to value less than or equal to the value of the PrachSubcarrierNumber parameter in this MO.
  • If the CoverageLevel parameter in a PrbRachCeConfig MO is set to COVERAGE_LEVEL_2, the PrachSubcarrierNumber parameter in the same MO must be set to SC_NUM_12.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a larger value, a larger amount of resources are available for the PRACH and a smaller amount of resources are available for the PUSCH, reducing the probability of random access collision but increasing the probability of PUSCH resource allocation failure. If this parameter is set to a smaller value, opposite impacts are produced.

Applicable Mode: L-NB-IOT

Applicable Mode: L-NB-IOT

This parameter must be set to the same value for different coverage levels and the location of the PRACH subcarrier for EDT cannot overlap that of the common PRACH subcarrier. Otherwise, the NB-IoT cell cannot work. This parameter applies only to NB-IoT.

GUI Value Range: SC0(SC0), SC12(SC12), SC24(SC24), SC36(SC36), SC2(SC2), SC18(SC18), SC34(SC34)

Unit: None

Example

To modify PrbRachCeConfig PrachRepetitionCount to REP_8:
MOD PRBRACHCECONFIG: LocalCellId=0, PrbId=20, CoverageLevel=COVERAGE_LEVEL_0, PrachRepetitionCount=REP_8;
