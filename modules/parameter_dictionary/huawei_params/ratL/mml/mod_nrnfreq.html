Modify Neighboring NR Frequency (MOD NRNFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a neighboring NR frequency.

Note

This command do not take effect when the LMPT is used as the main control board.

FreqSpecificOffset Frequency-specific Offset

Meaning: Indicates the offset to the NR frequency. It determines the probability of triggering measurement reports for events B1 and B2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Triggering condition for event B1: Mn + Ofn - Hys > Thresh

Triggering condition for event B2: Ms + Hys < Thresh1 and Mn + Ofn - Hys > Thresh2

Ms is the measured value of the serving cell, and Mn is the measured value of the neighboring cell. Ofn is the frequency-specific offset of the neighboring cell. Thresh is the threshold for event B1. Thresh1 and Thresh2 are thresholds for event B2. Hys is the hysteresis for the event.

A smaller Ofn value results in a lower probability of triggering events B1 and B2. This postpones handovers and affects user experience. A larger Ofn value results in a higher probability of triggering events B1 and B2 but also a higher probability of incorrect handover decisions and ping-pong handovers.

NrFreqReselPriority NR Frequency Reselection Priority

Meaning: Indicates the cell reselection priority of the NR frequency. The value 0 indicates the lowest priority. The value 255 indicates that no cell reselection priority is configured for the NR frequency. A UE obtains the sum of the value of this parameter and the value of the NrFreqReselSubPriority parameter in the NrNFreq MO and then compares the sum and the value of the CellReselPriority parameter in the CellResel MO for the serving cell. If the sum is greater than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency. The UE starts cell reselection when the signal quality of a cell on the neighboring NR frequency meets the specified requirement throughout the time specified by the NrCellReselectionTimer parameter in the CellReselToNr MO. If the sum is less than the value of the CellReselPriority parameter in the CellResel MO for the serving cell, the UE starts to measure the neighboring NR frequency only when the signal quality of the serving cell is poor. The UE starts cell reselection when the following conditions are met: (a) The signal quality of the serving cell is lower than the threshold specified by the ThrshServLow parameter in the CellResel MO and the signal quality of a cell on the neighboring NR frequency is higher than the threshold specified by the NrFreqLowPriReselThld parameter in the NrNFreq MO throughout the time specified by the NrCellReselectionTimer parameter in the CellReselToNr MO; (b) The UE has camped on the serving cell for more than 1s. The sum of the cell reselection priority and cell reselection sub-priority cannot be the same for inter-RAT frequencies. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

VonrPriority VoNR Priority

Meaning: Indicates the VoNR priority of the neighboring NR frequency. If this parameter is set to 255, the frequency does not support VoNR. If this parameter is set to a value in the range of 0 to 16, the frequency supports VoNR and the value indicates the VoNR priority of the frequency. A larger value indicates a higher priority. Frequencies with high VoNR priorities are preferentially delivered to UEs for measurements. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16,255

Unit: None

Actual Value Range: 0~16,255

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a lower VoNR priority of the neighboring NR frequency and therefore a lower probability that VoLTE UEs will be handed over to this frequency for VoNR services. A larger value of this parameter indicates a higher VoNR priority of the neighboring NR frequency and therefore a higher probability that VoLTE UEs will be handed over to this frequency for VoNR services. It is recommended that this parameter be set to a small value for neighboring NR frequencies with poor coverage and a large value for neighboring NR frequencies with good coverage. In this way, UEs can be handed over to neighboring NR frequencies with better coverage, improving voice service quality.

Applicable Mode: L-FDD, L-TDD

Example

To modify a neighboring NR frequency with the parameters as follows: Local cell ID: 0, Downlink ARFCN: 151600, Uplink ARFCN configuration indicator: NOT_CFG, run the following command:
MOD NRNFREQ: LocalCellId=0, DlArfcn=151600, UlArfcnConfigInd=NOT_CFG;
