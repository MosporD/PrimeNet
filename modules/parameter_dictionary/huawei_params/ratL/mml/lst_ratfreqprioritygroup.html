List RAT/Freq Priority Group (LST RATFREQPRIORITYGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of one or all RAT/frequency priority groups.

Note

None.

Output Description

Field Description

RAT frequency priority group ID

Indicates the ID of the RAT/frequency priority group. This parameter applies only to LTE FDD and LTE TDD.

RAT Type

Indicates the Radio Access Technology (RAT). This parameter applies only to LTE FDD and LTE TDD.

DL Earfcn or Bandclass

Indicates the downlink frequency. In CDMA2000, this parameter indicates the bandclass. Before configuring a priority for a frequency specified by this parameter, ensure that an external or local cell operating on this frequency has been configured. This parameter applies only to LTE FDD and LTE TDD.

Priority

Indicates the priority of the intra-RAT frequency band or frequency. The value 0 indicates the lowest priority. The value of this parameter must be determined together with the priorities of other frequencies during the network planning. Cell reselection priorities in different RATs cannot be the same. This parameter applies only to LTE FDD and LTE TDD.

GERAN Frequency Indicator

Indicates the GERAN frequency band. This parameter applies only to LTE FDD and LTE TDD.

Inter-Frequency Offload UE Number Threshold

Indicates the UE number threshold used for SPID-specific inter-frequency offload. When user-number-based MLB is triggered in a cell operating on a specified frequency and the number of UEs in the cell is greater than this parameter value, the eNodeB attempts to transfer UEs with the specific SPID from the local cell to inter-frequency neighboring cells. This parameter applies only to LTE FDD and LTE TDD.

UE Number Offload Prohibition Threshold

Indicates the UE number threshold for prohibiting admission of UEs with the specified SPID. If the number of UEs in a cell on a specified frequency is greater than or equal to this parameter value, the eNodeB prohibits the transfer of UEs with the specific SPID to the local cell. This parameter applies only to LTE FDD and LTE TDD.

Inter-RAT Offload UE Number Threshold

Indicates the user number threshold used for SPID-specific inter-RAT offload. When the number of uplink-synchronized (UL-sync) UEs in a local cell is greater than or equal to this threshold, the eNodeB attempts to transfer UEs with the specific SPID to inter-RAT neighboring cells. When the number of UL-sync UEs in the local cell is greater than or equal to the sum of the cell-level user number threshold and the related offset, the eNodeB attempts to transfer UEs without the specific SPID or UEs whose SPIDs are not obtained to inter-RAT neighboring cells. This parameter applies only to LTE FDD and LTE TDD.

Frequency Priority for Connected Mode

Indicates the frequency priority for the connected mode. Operators can configure different frequency priorities for the connected mode by PLMN. This parameter applies only to LTE FDD and LTE TDD.
