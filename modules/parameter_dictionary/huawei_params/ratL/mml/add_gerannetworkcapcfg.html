Add Geran Network Capability Configuration (ADD GERANNETWORKCAPCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a GERAN capability configuration.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the target GERAN cell. This parameter applies only to LTE FDD.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the target GERAN cell. This parameter applies only to LTE FDD.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Lac Location Area Code

Meaning: Indicates the location area code (LAC) of the GERAN cell. It uniquely identifies a location within a PLMN. A value in the range of 1-65533 and 65535 indicates a specific LAC on the network, and 4294967295 indicates all LACs under the PLMN. That is, the policy applies to all LACs under the PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65533,65535,4294967295

Unit: None

Actual Value Range: 1~65533,65535,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When more than one GeranNetworkCapCfg is configured with the same Mcc and Mnc, Lac 4294967295 cannot be co-exist with other Lac values.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NetworkCapCfg Network Capability Configuration

Meaning: Indicates the GERAN capabilities for an operator including the capability of obtaining system information (SI) of the GERAN through RAN information management (RIM) procedures, ultra-flash CSFB capability, and SRVCC capability. If the MME, SGSN, MSC, or BSC of the operator does not support RIM procedures, ultra-flash CSFB, or SRVCC, set this parameter to indicate the incapabilities. If this parameter is not set, GERAN capabilities are supported by default. This parameter provides the following options:

SiByRimCapCfg: Indicates whether SI of the GERAN can be obtained through RIM procedures. This capability is supported only if this option is selected. This option applies only to LTE FDD.

UltraFlashCsfbCapCfg: Indicates whether ultra-flash CSFB is supported by the GERAN. This capability is supported only if this option is selected. This option applies only to LTE FDD.

SrvccCapCfg: Indicates whether SRVCC is supported by the GERAN. This capability is supported only if this option is selected. Using SRVCC, voice services can be handed over to the GERAN. This option applies only to LTE FDD.

GUI Value Range: SiByRimCapCfg(SiByRimCapCfg), UltraFlashCsfbCapCfg(UltraFlashCsfbCapCfg), SrvccCapCfg(SrvccCapCfg)

Unit: None

Actual Value Range: SiByRimCapCfg, UltraFlashCsfbCapCfg, SrvccCapCfg

MML Default Value: None

Recommended Value: SiByRimCapCfg:On, UltraFlashCsfbCapCfg:On, SrvccCapCfg:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SiByRimCapCfg: If this option is selected, SI of neighboring GERAN cells can be obtained through RIM procedures. In this case, the eNodeB can use fast redirection to GERAN and set up voice services through flash CSFB, shortening the redirection delay and voice service setup delay, respectively. Deselecting this option results in the opposite effects.

UltraFlashCsfbCapCfg: If this option is selected, the eNodeB can perform SRVCC-based CSFB to GERAN to set up voice services. Compared with common CSFB, SRVCC-based CSFB shortens the voice service setup delay. Deselecting this option results in the opposite effects.

SrvccCapCfg: If this option is selected, the eNodeB can transfer voice services to the CS domain of a GERAN through SRVCC to keep continuity of voices services. If this option is deselected, service drops may occur as the eNodeB performs the transfer.

Applicable Mode: L-FDD, L-TDD

Example

To add GERAN capability configurations with the following parameters: Mobile country code: 460, Mobile network code: 20, Location Area Code: 1, Network Capability Configuration: SiByRimCapCfg-0 & SrvccCapCfg-0, run the following command:
ADD GERANNETWORKCAPCFG: Mcc="460", Mnc="20", Lac=1, NetworkCapCfg=SiByRimCapCfg-0&SrvccCapCfg-0;
