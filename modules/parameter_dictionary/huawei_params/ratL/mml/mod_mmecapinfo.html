Modify MME Capability Information (MOD MMECAPINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the MME features.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may result in an inconsistency between the S1 interface settings and the S1 object settings in the MmeCapInfo MO. The eNodeB determines the MME capability information preferentially based on the setting of the S1 interface.

Parameters

ID Name Description
MmeCapCfgId MME Capability Configuration ID

Meaning: Indicates the MME capability configuration index.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
NbCiotEpsOptCap NB-IoT CIoT EPS Optimization Capability

Meaning: Indicates the MME's capability of supporting EPS optimized transmission for NB-IoT CIoT. If this parameter is set to NOT_SUPPORT, the MME does not support EPS optimized transmission for NB-IoT CIoT. If this parameter is set to CP, the MME supports control-plane EPS optimized transmission for NB-IoT CIoT. If this parameter is set to CP_UP, the MME supports control-plane and user-plane EPS optimized transmission for NB-IoT CIoT. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: NOT_SUPPORT(NOT_SUPPORT), CP(CP), CP_UP(CP_UP)

Unit: None

Actual Value Range: NOT_SUPPORT, CP, CP_UP

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the S1CfgType parameter is set to S1_CFG(S1_CFG) in an MmeCapInfo MO, then the NbCiotEpsOptCap parameter, the NbLteSupportCap parameter, and the MmeSupportEmtcDedEpcCap parameter in the same MO cannot all be set to NOT_SUPPORT(NOT_SUPPORT).
  • If the S1CfgType parameter is set to S1INTERFACE_CFG(S1INTERFACE_CFG) in an MmeCapInfo MO, then the NbCiotEpsOptCap parameter, the NbLteSupportCap parameter, and the MmeSupportEmtcDedEpcCap parameter in the same MO cannot all be set to NOT_SUPPORT(NOT_SUPPORT).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
NbLteSupportCap MME Support LTE Capability

Meaning: Indicates the MME's capability of supporting LTE FDD and LTE TDD. If this parameter is set to NOT_SUPPORT, the MME does not support LTE FDD or LTE TDD. If this parameter is set to SUPPORT, the MME supports LTE FDD and LTE TDD.

GUI Value Range: NOT_SUPPORT(NOT_SUPPORT), SUPPORT(SUPPORT)

Unit: None

Actual Value Range: NOT_SUPPORT, SUPPORT

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the S1CfgType parameter is set to S1INTERFACE_CFG(S1INTERFACE_CFG) in an MmeCapInfo MO, then the NbCiotEpsOptCap parameter, the NbLteSupportCap parameter, and the MmeSupportEmtcDedEpcCap parameter in the same MO cannot all be set to NOT_SUPPORT(NOT_SUPPORT).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MmeSupportEmtcDedEpcCap MME Support eMTC-Dedicated EPC Capability

Meaning: Indicates whether the MME supports eMTC UEs to access a dedicated EPC.

If this parameter is set to NOT_SUPPORT, the MME does not support eMTC UEs to access a dedicated EPC. eMTC UEs access a common EPC if either of the following conditions is met:

- The MmeCapInfo MO is not configured for any MME.

- The MmeCapInfo MOs are configured and the MmeSupportEmtcDedEpcCap parameter in every MmeCapInfo MO is set to NOT_SUPPORT.

If this parameter is set to SUPPORT, the MME supports eMTC UEs to access a dedicated EPC. If the MmeSupportEmtcDedEpcCap parameter in one of the MmeCapInfo MOs is set to SUPPORT, eMTC UEs can only access a dedicated EPC.

GUI Value Range: NOT_SUPPORT(NOT_SUPPORT), SUPPORT(SUPPORT)

Unit: None

Actual Value Range: NOT_SUPPORT, SUPPORT

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the S1CfgType parameter is set to S1_CFG(S1_CFG) in an MmeCapInfo MO, then the NbCiotEpsOptCap parameter, the NbLteSupportCap parameter, and the MmeSupportEmtcDedEpcCap parameter in the same MO cannot all be set to NOT_SUPPORT(NOT_SUPPORT).
  • If the S1CfgType parameter is set to S1INTERFACE_CFG(S1INTERFACE_CFG) in an MmeCapInfo MO, then the NbCiotEpsOptCap parameter, the NbLteSupportCap parameter, and the MmeSupportEmtcDedEpcCap parameter in the same MO cannot all be set to NOT_SUPPORT(NOT_SUPPORT).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
MmeNsaDcCapability MME NSA DC Capability

Meaning: Indicates whether the MME supports NSA DC. If this parameter is set to NOT_SUPPORT, the MME does not support NSA DC. If this parameter is set to SUPPORT, the MME supports NSA DC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_SUPPORT(NOT_SUPPORT), SUPPORT(SUPPORT)

Unit: None

Actual Value Range: NOT_SUPPORT, SUPPORT

MML Default Value: None

Recommended Value: If an MME that does not support NSA DC is connected to an eNodeB that supports NSA DC, you are advised to set this parameter to NOT_SUPPORT for this MME.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the MME capability information with the parameters as follows: MME Capability Configuration ID: 0, NB-IoT CIoT EPS Optimization Capability: CP, NB-IoT MME Support LTE Capability: NOT_SUPPORT, run the following command:
MOD MMECAPINFO: MmeCapCfgId=0, NbCiotEpsOptCap=CP, NbLteSupportCap=NOT_SUPPORT;
