Activate Beam Weight Database (ACT BEAMDB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to activate a weight database file for a beam.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may disrupt cell services.

Parameters

ID Name Description
AldActPowerType Device type

Meaning: Indicates the mode for activating the beam weight file. This parameter applies to LTE TDD massive MIMO and LTE FDD.

GUI Value Range: SWFILE, DLDFILE

Unit: None

Actual Value Range: SWFILE, DLDFILE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To Act Beam DB, run the following command:
+++    0        2018-03-16 10:43:16
O&M    #807403567
%%ACT BEAMDB: AldActPowerType=DLDFILE;%%
RETCODE = 0  Operation succeeded.
