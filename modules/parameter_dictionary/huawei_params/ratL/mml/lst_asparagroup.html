List Configurations of Air Interface Acceleration Guarantee Parameter Group (LST ASPARAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of one or all air interface acceleration guarantee parameter groups.

Note

None.

Parameters

ID Name Description
AsParaGroupID Accelerate Service Para Group ID

Meaning: Indicates the acceleration service guarantee parameter group ID. Acceleration service guarantee parameters differ depending on acceleration service guarantee parameter groups.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the parameters about an air interface acceleration guarantee parameter group with Accelerate Service Para Group ID of 0, run the following command:
LST ASPARAGROUP: AsParaGroupID=0;
The result is shown as follows:

Output Description

Field Description

Accelerate Service Para Group ID

Indicates the acceleration service guarantee parameter group ID. Acceleration service guarantee parameters differ depending on acceleration service guarantee parameter groups.

Accelerate Service Prealloc Duration(ms)

Indicates the maximum duration for the preallocation of acceleration services.

When this parameter is used for air interface acceleration guarantee, it indicates the preallocation duration for guaranteed UEs. When this parameter is set to a value within the range of 0-60000, it indicates the actual preallocation duration. When this parameter is set to 65535, preallocation is not stopped until guarantee for the identified acceleration service ends.

When this parameter is used for TCP link setup acceleration guarantee, it indicates the duration when preallocation and scheduling priority take effect for guaranteed UEs. The control precision is 20 ms.

When this parameter is used for WTCP acceleration, it does not take effect.

This parameter applies only to LTE FDD and LTE TDD.

Accelerate Service Prealloc Min Period(ms)

Indicates the minimum preallocation interval for acceleration services.

Accelerate Service Prealloc Pkt Size(byte)

Indicates the amount of data pre-allocated for acceleration services.

Accelerate Service Schedule Priority Factor

Indicates the weighting factor used to calculate scheduling priorities for acceleration services. This parameter is used to preferentially guarantee services for acceleration guarantee UEs. This parameter is shared in the uplink and downlink. For FDD cells: If this parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weighting factor. If this parameter is set to 1000 or 65535, acceleration guarantee UEs have the highest priority. For TDD cells: If this parameter is set to a value in the range of 1 to 1000, the priority is calculated using the specified weighting factor. If this parameter is set to 65535, acceleration guarantee UEs have the highest priority. This parameter applies only to LTE FDD and LTE TDD.

Accelerate Service NACK CQI Adj Value(0.1dB)

Indicates the decrease in the CQI adjustment value when an acceleration guarantee UE returns an NACK message. If this parameter is set to a non-zero value, the outer-loop CQI adjustment value decreases by the value of this parameter. If this parameter is set to 0, the optimization does not take effect. This parameter applies only to LTE FDD and LTE TDD.

Acceleration Service Optimization Switch

Indicates whether to enable the acceleration service optimization algorithm.

ENTER_DRX_SWITCH: Indicates whether to enable DRX for acceleration guarantee UEs. If this option is deselected, DRX is disabled for acceleration guarantee UEs. If this option is selected, the eNodeB does not perform special processing on the DRX function for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

MLB_AND_MBOCS_PROHIBITION_SW: Indicates whether to disable MLB and MBOCS for acceleration guarantee UEs. If this option is deselected, acceleration guarantee UEs can be transferred by MLB and MBOCS. If this option is selected, acceleration guarantee UEs cannot be transferred by MLB and MBOCS. This option applies only to LTE FDD and LTE TDD.

PDCCH_BOUNDARY_PC_OPT_SW: Indicates whether to enable PDCCH boundary power control optimization for acceleration guarantee UEs. PDCCH boundary power control optimization is enabled for acceleration guarantee UEs only if this option is selected. This option applies only to LTE FDD.

PERIODIC_MEAS_OPT_SWITCH: Indicates whether to allow acceleration guarantee UEs to perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is deselected, such UEs can perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is selected, the UEs cannot perform these measurements. This option applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: Indicates whether the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is selected, the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is deselected, the eNodeB does not trigger fast-moving-UE smart carrier selection for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

Acceleration Service UE Inactivity Timer(s)

Indicates the length of the UE inactivity timer for only acceleration-involved UEs that do not have QCI-1 services and which this parameter group applies to. If the eNodeB detects that such a UE has neither received nor sent data throughout a period specified by this timer, the eNodeB releases the RRC connection for the UE. If the parameter is set to 0, the eNodeB does not release the RRC connection. If the parameter is set to 65535, the parameter is invalid. If the parameter setting is changed, the change applies to UEs that newly access the network. When used for TCP link setup acceleration guarantee or WTCP acceleration, this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
