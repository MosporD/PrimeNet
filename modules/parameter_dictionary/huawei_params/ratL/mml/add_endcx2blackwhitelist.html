Add Peer gNodeB to EN-DC X2 Blacklist or Whitelist (ADD ENDCX2BLACKWHITELIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a peer gNodeB to an EN-DC X2 blacklist or whitelist. If a peer gNodeB is blacklisted, the X2 interface between the local eNodeB and this gNodeB is abnormal and this interface cannot be automatically set up. If a peer gNodeB is whitelisted or blacklisted, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed.

Note

  • Mobile country code is a string of three characters, each of which must be a digit in the range of 0 to 9.

  • The total number of EN-DC X2 blacklists and EN-DC X2 whitelists cannot exceed 128.

  • Mobile network code is a string of two or three characters, each of which must be a digit in the range from 0 to 9.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of three decimal digits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an EnDcX2BlackWhiteList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in an EnDcX2BlackWhiteList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
gNodeBId gNodeB ID

Meaning: Indicates the ID of the peer base station in the EN-DC X2 blacklist or whitelist. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ListType List Type

Meaning: Indicates whether the EN-DC X2 list is a blacklist or whitelist. If a peer gNodeB is in the blacklist, an X2 interface between the local eNodeB and this gNodeB cannot be automatically set up and the X2 interface set up between the local eNodeB and this gNodeB is abnormal. If a peer gNodeB is in the whitelist or blacklist, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BLACKLIST(Blacklist), WHITELIST(Whitelist)

Unit: None

Actual Value Range: BLACKLIST, WHITELIST

MML Default Value: BLACKLIST(Blacklist)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a peer gNodeB to EN-DC X2 blacklist with the parameters as follows: Mobile country code: 460, Mobile network code: 20, gNodeB ID: 255, run the following command:
ADD ENDCX2BLACKWHITELIST: Mcc="460", Mnc="20", gNodeBId=255, ListType=BLACKLIST;
