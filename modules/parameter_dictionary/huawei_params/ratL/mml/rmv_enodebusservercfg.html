Remove eNodeB US Server Parameters Configuration (RMV ENODEBUSSERVERCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove configurations from the server which allows UEs who gain access to then be determined as UEs running unlimited services.

Note

None.

Parameters

ID Name Description
UsServerIndex US Server Index

Meaning: Indicates the index of the server which allows UEs who gain access to then be determined as UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter is replaced by the ServerConfig.ServerIndex and will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: 0~49

Unit: None

Actual Value Range: 0~49

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the parameters of eNodeB US server configuration with Us Server Index of 0, run the following command:
RMV ENODEBUSSERVERCFG: UsServerIndex=0;
