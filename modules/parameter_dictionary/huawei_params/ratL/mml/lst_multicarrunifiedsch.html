List Configurations of Multi-carrier Unified Scheduling (LST MULTICARRUNIFIEDSCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of multi-carrier unified scheduling.

Note

None.

Parameters

None.

Example

List Configurations of Multi-carrier Unified Scheduling:
LST MULTICARRUNIFIEDSCH:;

Output Description

Field Description

Intra-Freq Measurement A3 Time-to-Trigger

Indicates the time-to-trigger for intra-frequency event A3 based on the measurement reports of which the eNodeB queries virtual grid models.

Before the model query for a UE, the eNodeB delivers intra-frequency event A3 measurement configurations to the UE. When the entering condition of intra-frequency event A3 is met, the UE does not report the event to the eNodeB immediately. Instead, the UE reports the event only when the entering condition is continuously met throughout the time-to-trigger specified by this parameter.

This parameter reduces the probability that occasional events are reported, and also reduces the probability of incorrect inter-frequency information provided by virtual grid models. This parameter applies only to LTE FDD and LTE TDD.

Multi-Carrier Unified Sch Switch

Indicates whether to enable the multi-carrier unified scheduling algorithms.

SMART_CARRIER_SELECTION_SW: Indicates whether to enable smart carrier selection. If this option is selected, the eNodeB can select the optimal carriers or carrier combinations for UEs based on the air interface quality of inter-frequency neighboring E-UTRAN cells predicted using virtual grid models. When the UMPTb is used, the UMPTB_ENHANCEMENT_SWITCH option of the ServiceMode parameter in the eNodeBResModeAlgo MO must also be selected for smart carrier selection to take effect. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SMART_CARRIER_SELECTION_ENH_SW: Indicates whether to enable enhanced smart carrier selection, including improvement of virtual-grid-based spectral efficiency prediction accuracy and smart carrier selection for non-CA UEs at initial access. If this option is selected, enhanced smart carrier selection is enabled. When the UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the ServiceMode parameter in the eNodeBResModeAlgo MO must also be selected for improvement of virtual-grid-based spectral efficiency prediction accuracy to take effect. If this option is deselected, the preceding functions are disabled. This option applies only to LTE FDD and LTE TDD.

CA_CONCURRENCY_SCH_CAPB_ENH_SW: If this option is selected, the eNodeB increases the maximum number of concurrently processed CA UEs with SCells activated. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SPECTRUM_EFF_EVALUATION_OPT_SW: If this option is selected, the eNodeB selects carriers preferentially based on cell-level average spectral efficiency when the following conditions are met: (1) The eNodeB obtains the inter-frequency spectral efficiency using measurements. (2) UEs report the measurement results of only one inter-frequency neighboring cell on certain frequencies to be evaluated or the level of the serving frequency increases or decreases by 5 dB or more during evaluation. If this option is deselected, the eNodeB selects carriers based on UE-level spectral efficiency. This option applies only to LTE FDD and LTE TDD.

ULTRA_LOW_LATENCY_SCH_SW: If this option is selected, scheduling with ultra-low latency for CA is enabled. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SCC_ADAPT_COV_THLD_SW: If this option is selected, the RSRP thresholds used for SCell addition and removal are adaptively extended. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

MOBILITY_ADAPT_COV_THLD_SW: If this option is selected, the RSRP threshold of the serving cell used for coverage-based inter-frequency handovers and the level threshold of the target cell used for smart carrier selection are adaptively extended. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

FAST_MOVING_UE_LOAD_CALC_SW: If this option is selected, the eNodeB considers the load of each carrier when selecting carriers for fast-moving UEs. If this option is deselected, the eNodeB does not consider the load of each carrier when selecting carriers for fast-moving UEs. This option applies only to LTE FDD and LTE TDD.

Virtual Grid Mdl Pred Unnec HO Meas RSRP Thld

Indicates the RSRP prediction accuracy level threshold based on which a virtual grid model is selected for predicting the RSRP used for evaluation in inter-frequency unnecessary handovers. Inter-frequency unnecessary handovers include service-based inter-frequency handover, inter-frequency handover for load balancing, inter-frequency handover for smart carrier selection based on virtual grids.

If this parameter is set to ACCURACY95_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY90_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY80_OFFSET0, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation.

If this parameter is set to ACCURACY80_OFFSET5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 10 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET15, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 15 dB before the evaluation.

If this parameter is set to ACCURACY80_OFFSET20, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 80% as the RSRP for handover evaluation and can increase the RSRP by a maximum of 20 dB before the evaluation.

If this parameter is set to ACCURACY100_OFFSET0, the eNodeB does not use virtual grid models to predict the RSRP used for evaluation in unnecessary handovers.

If this parameter is set to ACCURACY90_OFFSET_5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY90_OFFSET_10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 90% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 10 dB before the evaluation.

If this parameter is set to ACCURACY95_OFFSET_5, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 5 dB before the evaluation.

If this parameter is set to ACCURACY95_OFFSET_10, the eNodeB uses the RSRP value derived from the virtual grid model that can provide an RSRP prediction accuracy level of greater than or equal to 95% as the RSRP for handover evaluation and can decrease the RSRP by a maximum of 10 dB before the evaluation.

This parameter applies only to LTE FDD and LTE TDD.

Carrier Capability Hysteresis(%)

Indicates the hysteresis for carriers or carrier combinations evaluated during smart carrier selection. If the difference in air interface capability between two carriers or carrier combinations is greater than the hysteresis, the eNodeB considers that the two have different air interface capabilities. If the difference does not exceed the hysteresis, the eNodeB considers that the two have the same air interface capability. This parameter applies only to LTE FDD and LTE TDD.

G Factor Thld for Handover Target Cell

Indicates the G factor threshold used in target cell selection for handovers in smart carrier selection based on virtual grids. The G factor is the RSRP linear value of a cell divided by the sum of RSRP linear values of all of its intra-frequency neighboring cells and the noise floor. If this parameter is set to 32767, handover to a target cell does not take the G factor into consideration. If this parameter is set to another value, handover to a cell is allowed only if the G factor of this cell is greater than the parameter value. This parameter applies only to LTE FDD and LTE TDD.

Carrier Capb Hyst for Fast Moving UE(%)

Indicates the hysteresis of carrier or carrier combination capabilities in smart carrier selection for fast-moving UEs. A carrier or carrier combination is considered to have higher capabilities than another carrier or carrier combination only if the former has higher capabilities and the capability difference is greater than this hysteresis. Otherwise, the two carriers or carrier combinations are considered to have the same capabilities. This parameter applies only to LTE FDD and LTE TDD.

SCS Fast Moving UE Judge Mode

Indicates the mode of identifying fast-moving UEs. If a UE is identified as a fast-moving UE, the smart carrier selection policy for fast-moving UEs takes effect for the UE.

If this parameter is set to NONE, fast-moving UEs are not identified. If this parameter is set to QCI, UEs with bearers of a specific QCI, for which the SCS_FAST_MOVING_UE_SW option of the CellQciPara.QciAlgoSwitch parameter is selected, are identified as fast-moving UEs. If this parameter is set to AS, acceleration guarantee UEs for which the SCS_FAST_MOVING_UE_SW option of the AsParaGroup.AccelerationServiceOptSw parameter is selected are identified as fast-moving UEs. If this parameter is set to SPID, UEs of an SPID for which the SCS_FAST_MOVING_UE_SW option of the SpidCfg.SpidAlgoSwitch parameter is selected are identified as fast-moving UEs. This option applies only to LTE FDD and LTE TDD.

Bandwidth Hysteresis(%)

Indicates the bandwidth hysteresis for carriers or carrier combinations in smart carrier selection. If this parameter is set to 255, the bandwidth factor is not used as the highest-priority weight in carrier or carrier combination selection. If this parameter is set to another value, a carrier or carrier combination is considered to have a larger bandwidth than another carrier or carrier combination only if the former has a larger bandwidth and the bandwidth difference is greater than this hysteresis. Otherwise, the two carriers or carrier combinations are considered to have the same bandwidth. This parameter applies only to LTE FDD and LTE TDD.
