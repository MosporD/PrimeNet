Modify TPE Algorithm Parameter (MOD TPEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the TPE algorithm.

Note

Before parameters related to the TPE algorithm are modified by running this command, ensure that the TPE switch has been turned on.

Parameters

ID Name Description
PortListNum TCP Port Number

Meaning: Indicates the number of ports to which TCP acceleration is to be applied. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0~20

Unit: None

Actual Value Range: 0~20

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates that fewer service types can be enabled with the TPE algorithm and therefore lower efficiency of the TPE algorithm for throughput increasing. A larger value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the configuration of the TPE algorithm with the parameters as follows: TCP Port Number: 2, TCP Port 1: 21, TCP Port 2: 23, run the following command:
MOD TPEALGO: PortListNum=2, Port1=21, Port2=23;
Example 2: To modify the configuration of the TPE algorithm with the parameters as follows: TCP Port Number: 3, TCP Port 1: 21, TCP Port 2: 22, TCP Port 3: 23, run the following command:
MOD TPEALGO: PortListNum=3, Port1=21, Port2=22, Port3=23;
