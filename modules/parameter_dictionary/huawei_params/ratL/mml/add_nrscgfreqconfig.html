Add NR SCG Frequency Configuration (ADD NRSCGFREQCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a candidate SCC to an NR SCG.

Note

None.

Parameters

ID Name Description
PccDlEarfcn PCC DL EARFCN

Meaning: Indicates the downlink EARFCN of the PCC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The PccDlEarfcn parameter value in an NrScgFreqConfig MO must be a valid frequency number.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ScgDlArfcn SCG DL ARFCN

Meaning: Indicates the downlink SSB ARFCN of a candidate SCC in the NR SCG. For details about this parameter, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0,123400~130400,145800~149200,151600~164200,173800~178800,185000~192000,285400~303600,361000~384000,386000~405000,422000~440000,460000~480000,499200~538000,620000~680000,693333~733333,2016667~2104166,2229166~2279166

Unit: None

Actual Value Range: 0,123400~130400,145800~149200,151600~164200,173800~178800,185000~192000,285400~303600,361000~384000,386000~405000,422000~440000,460000~480000,499200~538000,620000~680000,693333~733333,2016667~2104166,2229166~2279166

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ScgDlArfcnPriority SCG DL ARFCN Priority

Meaning: Indicates the downlink frequency priority for a candidate SCC in the NR SCG. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability that the candidate SCC specified by ScgDlArfcn in the NR SCG is configured as an SCC for an EN-DC UE when the PCC specified by PccDlEarfcn is configured for the UE. As a result, the traffic volume of cells on the frequency corresponding to the candidate SCC is smaller. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
NsaDcB1ThldRsrp NSA DC B1 Event RSRP Threshold

Meaning: Indicates the RSRP threshold for event B1 during NR SCG configuration by the eNodeB. When the measured RSRP exceeds this threshold, event B1 is reported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: -105

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The NsaDcSulB1ThldRsrp parameter in an NrScgFreqConfig MO must be set to a value less than or equal to the NsaDcB1ThldRsrp parameter value in the same MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NrB1TimeToTrigger NR B1 Time To Trigger

Meaning: Indicates the time-to-trigger for NR frequency measurement event B1. Event B1 is not immediately reported at the moment that the signal quality of an NR cell meets the condition for triggering measurement reports for event B1. Instead, it is reported if the signal quality always meets the condition within the period specified by this parameter. This parameter reduces accidentally reported event B1. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0MS(0MS), 40MS(40MS), 64MS(64MS), 80MS(80MS), 100MS(100MS), 128MS(128MS), 160MS(160MS), 256MS(256MS), 320MS(320MS), 480MS(480MS), 512MS(512MS), 640MS(640MS), 1024MS(1024MS), 1280MS(1280MS), 2560MS(2560MS), 5120MS(5120MS)

Unit: None

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: 40MS(40MS)

Recommended Value: 40MS(40MS)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to faster event B1 measurement reporting. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
NsaDcSulB1ThldRsrp NSA DC SUL B1 Event RSRP Threshold

Meaning: Indicates the RSRP threshold for reporting event B1, based on which the eNodeB configures NR SCGs for SUL-capable UEs. If the measured RSRP value exceeds this threshold, an event B1 measurement report will be reported. This parameter applies only to LTE FDD.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: -115

Recommended Value: -115

Parameter Relationship:

-Configuration constraints:

  • The NsaDcSulB1ThldRsrp parameter in an NrScgFreqConfig MO must be set to a value less than or equal to the NsaDcB1ThldRsrp parameter value in the same MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
NrFrequencyBand NR Frequency Band

Meaning: Indicates the NR SUL frequency bands. If the option corresponding to a frequency band is selected, the SCG supports this frequency band. In this case, the ScgDlArfcnPriority, NsaDcB1ThldRsrp, and NrB1TimeToTrigger parameters for the frequency band become invalid. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: N80(N80), N81(N81), N82(N82), N83(N83), N84(N84), N86(N86)

Unit: None

Actual Value Range: N80, N81, N82, N83, N84, N86

MML Default Value: None

Recommended Value: N80:Off, N81:Off, N82:Off, N83:Off, N84:Off, N86:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AggregationAttribute Aggregation Attribute

Meaning: Indicates the aggregation attributes of the combination of the PCC frequency band and the corresponding NR SCG frequency band.

CO_DEPLOYMENT_NSA_FLAG: If this option is selected, mobility management procedures specific to co-site deployment are allowed in the frequency band combination. If this option is deselected, mobility management procedures specific to co-site deployment are not allowed in the frequency band combination. This option applies only to LTE FDD and LTE TDD.

SINGLE_UL_NSA_FLAG: If this option is selected, the support of only uplink single-side transmission is allowed in the frequency band combination in NSA DC scenarios. If this option is deselected, the support of only uplink single-side transmission is not allowed in the frequency band combination in NSA DC scenarios. This option applies only to LTE FDD.

GUI Value Range: CO_DEPLOYMENT_NSA_FLAG(CO_DEPLOYMENT_NSA_FLAG), SINGLE_UL_NSA_FLAG(SINGLE_UL_NSA_FLAG)

Unit: None

Actual Value Range: CO_DEPLOYMENT_NSA_FLAG, SINGLE_UL_NSA_FLAG

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a candidate SCC to an NR SCG with the parameters as follows: PCC DL EARFCN: 1500, SCG DL ARFCN: 151600, SCG DL ARFCN Priority: 6, run the following command:
ADD NRSCGFREQCONFIG: PccDlEarfcn=1500, ScgDlArfcn=151600, ScgDlArfcnPriority=6;
