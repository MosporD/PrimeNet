List eNodeBResModeAlgo (LST ENODEBRESMODEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the eNodeBResModeAlgo.

Note

None.

Parameters

None.

To list the configurations of eNodeB resource modes, run the following command: :
LST ENODEBRESMODEALGO:;

Output Description

Field Description

BBP Resource Auto Config Switch

Indicates whether to automatically or manually bind a baseband equipment ID to a cell. If this parameter is set to ON, the eNodeB automatically changes the BaseBandEqmId parameter value within 5 minutes after all cells are successfully activated, to bind the cells to baseband resources. If this parameter is set to ON_BIND, the eNodeB periodically changes the BaseBandEqmId parameter value for all activated cells to bind the cells to baseband resources. If a BASEBANDEQM MO has been configured for each BBP, the automatic baseband allocation algorithm can take effect. If a BASEBANDEQM MO is not configured for each BBP, the eNodeB automatically configures a BASEBANDEQM MO for each BBP. The MO contains information about only the corresponding BBP. If the automatic configuration fails due to causes such as a specification limit of the baseband equipment, the automatic baseband allocation algorithm does not take effect.

TDD BBP Resource Auto Deploy Algorithm

Indicates the baseband resource allocation policy for LTE TDD cells. If this parameter is set to RESOURCE_PRIMARY, baseband resources are preferentially allocated based on the minimum resource allocation policy, ensuring that baseband resources can be allocated to as many cells as possible. If this parameter is set to LOAD_BALANCE, the eNodeB allocates baseband resources to cells based on the principle of load balancing to ensure that a cell obtains as many baseband resources as possible. If this parameter is set to ADAPTIVE, the eNodeB automatically allocates baseband resources to cells based on the number of cells. This parameter applies only to LTE TDD.

FDD BBP Resource Auto Deploy Algorithm

Indicates the baseband resource allocation policy for FDD cells. If this parameter is set to RESOURCE_PRIMARY, baseband resources are allocated preferentially based on the minimum resource allocation policy, ensuring that baseband resources can be allocated to as many cells as possible. If this parameter is set to LOAD_BALANCE, baseband resources are allocated to cells preferentially based on the principle of load balancing, ensuring that cells obtain as many baseband resources as possible. If this parameter is set to ADAPTIVE, baseband resources are automatically allocated to cells based on the number of cells. If this parameter is set to ADAPTIVE_POLICY1, baseband resources are automatically allocated to cells based on the number of cells. In addition, resources are allocated preferentially in load balancing mode to both common cells and physical cells in SFN cells if these cells are established on UBBP boards. This parameter applies only to LTE FDD and NB-IoT.

BBP Resource Auto Reconfig Timer(min)

Indicates the maximum period of time available for cell activation on the bound BBP. When a cell fails to be activated within this period and the BbpResAutoConfigSw parameter is set to ON(On), the eNodeB automatically allocates available baseband resources to the cell until the cell is successfully activated. This parameter is also used to specify the internal protection time length, which is the value of this parameter minus 8 minutes. During the internal protection time, a cell fails to be activated if a fault occurs in the baseband resources bound to the cell or the baseband resources bound to the cell are occupied by another cell.

eNodeB Cell Number Capability Mode

Indicates how to define the maximum number of cells on a single base station. If this parameter is set to NORMAL_MODE, a single UMPTa or UMPTb supports a maximum of 36 cells, a single UMPTga supports a maximum of 72 cells, and a single UMPTg supports a maximum of 144 cells. If this parameter is set to ENHANCED_MODE, two UMPTa or UMPTb boards in a single base station support a maximum of 48 cells, two UMPTga boards in a single base station support a maximum of 144 cells, and two UMPTg boards in a single base station support a maximum of 216 cells. This parameter is a base-station-level parameter and applies only to UMPTa, UMPTb, UMPTga, and UMPTg boards.

CPRI Sharing Switch

Indicates whether to support CPRI sharing between baseband processing units (BBPs). When this parameter is set to ON, CPRI sharing is supported and CPRI ports of a BBP or CPRI interface board are shared between specified BBPs to enable baseband processing to be independent of CPRI ports. When this parameter is set to OFF, CPRI sharing is not supported.

eNodeB Cell Distributed Deployment Switch

Indicates whether to enable distributed cell deployment. This parameter takes effect only when a base station is equipped with two main control boards. If this parameter is set to ON, the cell management function can be deployed on two UMPT boards or UMPT+LMPT boards to increase the cell number capacity. If this parameter is set to OFF, the cell management function is deployed only on the primary UMPT.

Backplane Bandwidth Lack Protection Switch

Indicate whether to establish cells with reduced capacity if the backplane bandwidth is insufficient. If this parameter is set to ON(On) and the backplane bandwidth is insufficient, cells are not established with reduced capacity. If this parameter is set to OFF(Off) and the backplane bandwidth is insufficient, cells are established with reduced capacity. It is recommended that this parameter be set to ON(On) if the IR protocol is used. This parameter applies only to LTE FDD and LTE TDD.

Service Mode

Indicates the service running mode of the eNodeB. The product specifications vary according to the serving running mode.

AI_ENHANCEMENT_SWITCH: If this option is selected and the UMPTe or UMPTga board is used, the eNodeB works under the enhanced product specifications applicable when smart features are activated. If this option is deselected, the eNodeB works under the normal product specifications applicable when smart features are deactivated.

UMPTB_ENHANCEMENT_SWITCH: If this option is selected and UMPTb is used, the eNodeB works under the enhanced product specifications applicable when intelligent features are activated. If this option is deselected, the eNodeB works under the normal product specifications applicable when intelligent features are deactivated.
