Remove Cell (RMV CELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a cell. The execution of this command deactivates the cell, interrupts the services provided by the cell, and removes all configurations related to the cell from the data base.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before removing a cell, ensure that the neighboring cells and optional configurations are removed.

  • The execution of this command deactivates the cell, interrupts the services provided by the cell, and removes all configurations related to the cell from the data base.

  • This operation will interrupt services in the cell. If RRN services are configured in the cell, the RRN and the ReBTS connected to the RRN will be disconnected from the NMS after this operation is executed.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
ForceExecute Force Execute

Meaning: Indicates whether to forcibly remove the cell. This parameter is used to resolve the issue that a cell cannot be completely removed when its sub-objects are missing. If this parameter is set to NO, the cell cannot be removed if its sub-objects are missing. If this parameter is set to YES, the cell can be successfully removed even if its sub-objects are missing.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove the cell with the local cell ID of 0, run the following command:
RMV CELL: LocalCellId=0;
