Modify NSA DC Management Configuration (MOD NSADCMGMTCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the LTE-NR NSA DC data split configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

TDM_SWITCH: Changing the setting of this switch from Off to On for an LTE cell for which the RbRsvType parameter in the CellRbReserve MO is set to UPLINK_MODE and the RbRsvMode parameter in the same MO is set to NB_RESERVED or NB_DEPLOYMENT may result in deactivation of this LTE cell.

NsaDcAlgoSwitch NSA DC Algorithm Switch

Meaning: Indicates whether to enable LTE-NR NSA DC algorithms. This parameter provides the following options:

NSA_DC_CAPABILITY_SWITCH: LTE-NR NSA DC is enabled for the cell only if this option is selected. This option applies only to LTE FDD and LTE TDD.

INTERFERENCE_AVOID_SW: LTE supports secondary harmonic signal and cross-modulation interference signal avoidance only if this option is selected. Avoidance of interference from secondary intermodulation signals also requires that the TDM_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO be selected. This option applies only to LTE FDD and LTE TDD.

NSA_PCC_ANCHORING_SWITCH: NSA DC PCC anchoring based on the NSA DC PCC anchoring priority (specified by the NsaPccAnchoringPriority parameter in the PccFreqCfg MO) takes effect for NSA DC UEs during initial access, incoming handovers, or incoming RRC connection reestablishment only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NSA_BLIND_SCG_ADDITION_SWITCH: If this option is selected, blind SCG addition is enabled. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

NSA_DC_ENH_UL_POWER_CONTROL_SW: Indicates whether to enable the enhanced uplink power control function for NSA DC UEs, that is, whether to trigger the TDM function on the LTE side to increase the maximum uplink transmit power. If this option is selected, the enhanced function is enabled. If this option is deselected, the enhanced function is disabled. This option applies only to LTE FDD.

TDM_SWITCH: Indicates whether to enable the time division multiplexing (TDM) function. If this option is selected, this function is enabled. If this option is deselected, this function is disabled. This option applies only to LTE FDD. For details about the TDM function, see 3GPP TS 38.306.

NSA_DC_VOLUME_BASED_SCG_ADD_SW: Indicates whether to enable the traffic-volume-based SCG addition for NSA DC UEs during initial access, incoming handovers, or incoming RRC connection reestablishment. If this option is selected, SCG addition is not triggered until the traffic volume meets certain conditions. If this option is deselected, this function does not take effect. This option applies only to LTE FDD and LTE TDD.

VOLTE_NSA_DC_IF_NR_MEAS_SW: Indicates whether to enable the following functions for VoLTE UEs in NSA DC scenarios: NR SCG addition based on gap-assisted NR measurements and PCC anchoring for RRC_CONNECTED UEs based on inter-frequency measurements. If the option is selected, the eNodeB delivers gap-assisted NR measurement configurations for NR SCG addition or inter-frequency measurement configurations for PCC anchoring for RRC_CONNECTED UEs to VoLTE UEs in NSA DC scenarios. For UEs running VoLTE services in NSA DC scenarios, if this option is deselected, then the eNodeB neither delivers gap-assisted NR measurement configurations to these UEs for NR SCG addition nor delivers inter-frequency measurement configurations to these UEs for PCC anchoring for RRC_CONNECTED UEs. This option applies only to LTE FDD and LTE TDD.

NSA_DC_FLEXIBLE_PCC_ANCHOR_SW: If this option is selected, flexible NSA DC PCC anchoring is enabled. PCC anchoring is performed based on the PCC anchoring priorities, loads, and uplink and downlink coverage of target frequencies. If this option is deselected, flexible NSA DC PCC anchoring is disabled. Before selecting this option, select the NSA_PCC_ANCHORING_SWITCH option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter. This option applies only to LTE FDD and LTE TDD.

NSA_DC_DPS_CONTROL_SW: If this option is selected, uplink dynamic power sharing for NSA DC is enabled in a cell. If this option is deselected, uplink dynamic power sharing for NSA DC is disabled in the cell. This option applies only to LTE FDD and LTE TDD.

PERIODIC_PCC_ANCHORING_SW: If this option is selected, periodic NSA DC PCC anchoring is enabled. If this option is deselected, periodic NSA DC PCC anchoring is disabled. This option applies only to LTE FDD and LTE TDD.

NSA_DC_STATE_PCC_ANCHORING_SW: If this option is selected, PCC anchoring can be triggered for UEs in the NSA DC state. If this option is deselected, PCC anchoring cannot be triggered for UEs in the NSA DC state. This option applies only to LTE FDD and LTE TDD.

VOLUME_BASED_PERIODIC_TRIG_SW: If this option is selected, the eNodeB performs periodic NSA DC PCC anchoring or periodic SCG addition based on traffic volume. If this option is deselected, the eNodeB performs periodic NSA DC PCC anchoring or periodic SCG addition not based on traffic volume. This option applies only to LTE FDD and LTE TDD.

S1_HO_DATA_FORWARDING_SW: If this option is selected, data can be forwarded through the core network during an S1-based handover for an NSA DC UE. This function takes effect only if this option is selected for both the source and target base stations. If this option is deselected, data cannot be forwarded through the core network during an S1-based handover for an NSA DC UE. This option applies only to LTE FDD and LTE TDD.

SN_TERMN_MCG_BEARER_SWITCH: The cell supports SN-terminated MCG bearers only if this option is selected. SN is short for secondary node. This option applies only to LTE FDD and LTE TDD.

NSA_DC_HO_ADM_STRAT_SW: Indicates whether NSA DC UEs are controlled by the MLB admission policy for target cells during handovers. If this option is selected, NSA DC UEs are controlled by the MLB admission policy for target cells during handovers. If this option is deselected, NSA DC UEs are not controlled by the MLB admission policy for target cells during handovers. This option applies only to LTE FDD and LTE TDD.

IDLE_MODE_NSA_PCC_ANCHORING_SW: Indicates whether to enable NSA DC PCC anchoring for RRC_IDLE UEs. If this option is selected, NSA DC PCC anchoring for RRC_IDLE UEs is enabled. If this option is deselected, NSA DC PCC anchoring for RRC_IDLE UEs is disabled. This option applies only to LTE FDD and LTE TDD.

VOLUME_BASED_SCG_ADD_OPT_SW: Indicates whether to enable optimization of traffic-volume-based NSA DC PCC anchoring and optimization of traffic-volume-based SCG addition. These optimization functions are enabled only if this option is selected. This option takes effect only if the INSTANT_JUDGEMENT_SW option of the NsaDcMgmtConfig.NsaDcAlgoExtSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.

NR_COV_PCC_ANCHORING_OPT_SW: Indicates whether to enable NR-coverage-based NSA DC PCC anchoring optimization. This function takes effect only if this option is selected. This function is recommended when NR-coverage-based NSA DC PCC anchoring is deployed and LTE CA is disabled. This option applies only to LTE FDD and LTE TDD.

NSA_DC_PREALLOCATION_SW: Indicates whether to enable preallocation in NSA DC scenarios. Preallocation is enabled in NSA DC scenarios only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NSA_DC_COV_HO_ENH_SW: Indicates whether to enable enhanced coverage-based handovers for NSA DC UEs. Enhanced coverage-based handovers for NSA DC UEs are enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NSA_DC_UL_PATH_SELECTION_SW: Indicates whether to enable NSA DC uplink path selection. Uplink paths are selected for data transmission based on factors such as load and air interface quality only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NSA_DC_COOPERATION_DPS_SW: Indicates whether to enable the cooperation-based dynamic power sharing function. Cooperation-based dynamic power sharing function in NSA DC scenarios is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LNR_DRX_SYNCHRONIZE_SW: Indicates whether to enable DRX parameter synchronization for NSA DC UEs. If this option is selected, the function takes effect. The eNodeB sends the DrxInfo-MCG IE to the gNodeB over the X2 interface, and the gNodeB aligns the DRX sleep time on both sides as much as possible. In this way, NSA DC UEs can save power. If this option is deselected, the function does not take effect. This parameter is valid only if the DrxAlgSwitch parameter in the CellDrxPara MO is set to ON. This option applies only to LTE FDD and LTE TDD.

Parameter Relationship:

-Configuration constraints:

  • The NSA_DC_CAPABILITY_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO must be selected when the NSA_DC_UL_PATH_SELECTION_SW option of the same parameter is selected.
  • If the NSA_DC_ENH_UL_POWER_CONTROL_SW option of the NsaDcAlgoSwitch parameter of the NsaDcMgmtConfig MO is selected, the TDM_SWITCH option of the same parameter must be selected.
  • If the TDM_SWITCH of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig is selected, the NSA_DC_CAPABILITY_SWITCH option of the same parameter must be selected.
  • If the NSA_BLIND_SCG_ADDITION_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgMtConfig MO is selected, then the NSA_DC_CAPABILITY_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgMtConfig MO must be selected.
  • If the NSA_DC_FLEXIBLE_PCC_ANCHOR_SW option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO is selected, the NSA_PCC_ANCHORING_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO must be selected.
  • The NSA_DC_DPS_CONTROL_SW and NSA_DC_COOPERATION_DPS_SW options of the NsaDcAlgoSwitch parameter in the same NsaDcMgmtConfig MO cannot be both selected for the same cell.
  • If the NSA_DC_COOPERATION_DPS_SW option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO is selected for a cell, the NSA_DC_CAPABILITY_SWITCH option of the NsaDcAlgoSwitch parameter in the same MO for the same cell must be selected.
  • If the SN_TERMN_MCG_BEARER_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO is selected, the NSA_DC_CAPABILITY_SWITCH option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO must be selected.
  • If the ImdIntrfFreqAvoidanceType parameter in the NsaDcMgMtConfig MO is set to PRIOR_ALLOC_NO_INTRF_RB, the INTERFERENCE_AVOID_SW option of the NsaDcAlgoSwitch parameter in the NsaDcMgMtConfig must be selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NSA_DC_CAPABILITY_SWITCH: If this option is selected, both the total traffic volume of downlink data sent and that of uplink data received by the PDCP layer in the cell increase. If this option is deselected, both the total traffic volume of downlink data sent and that of uplink data received by the PDCP layer in the cell decrease.

INTERFERENCE_AVOID_SW: UEs can avoid the impact of secondary harmonic signals and cross-modulation interference signals only if this option is selected.

NSA_BLIND_SCG_ADDITION_SWITCH: If this option is selected, blind SCG addition is enabled, shortening the time to add an SCG. If this option is deselected, the eNodeB adds an SCG based on measurement results and the time for adding an SCG is relatively long.

NSA_DC_ENH_UL_POWER_CONTROL_SW: If this option is selected, the maximum uplink transmit power increases when an NSA DC UE is located at the edge of LTE or NR coverage areas. If this option is deselected, the maximum uplink transmit power does not increase when the NSA DC UE is located at the edge of LTE or NR coverage areas.

TDM_SWITCH: If this option is selected, the new UCI uses format3, which increases the number of occupied RBs and decreases the number of RBs occupied by the PUSCH.

NSA_DC_VOLUME_BASED_SCG_ADD_SW: If this option is selected, SCG addition is based on traffic volume and signaling overhead induced by SCG addition triggered by small-packet services decreases. If this option is deselected, SCG addition is not based on traffic volume and signaling overhead does not change.

VOLTE_NSA_DC_IF_NR_MEAS_SW: If this option is selected, concurrent data services of NSA DC UEs running VoLTE services can obtain NR gains so that the user-perceived rates of the data services increase, but the scheduling delay of VoLTE services during measurement gaps increases. The uplink transmit power on the LTE side decreases after the NR SCG is added, affecting user experience with voice services at the LTE cell edge. If this option is deselected, user experience with VoLTE services is not affected, but UEs cannot obtain NR gains.

NSA_DC_FLEXIBLE_PCC_ANCHOR_SW: If this option is selected, PCC anchoring is performed based on factors such as loads and uplink coverage, improving user experience. If this option is deselected, PCC anchoring is performed without considering factors such as loads and uplink coverage.

NSA_DC_DPS_CONTROL_SW: If this option is selected, the maximum transmit power on the LTE and NR sides configured for an NSA DC UE is equal to the UE's maximum transmit power. This improves LTE coverage but most or all UE power may be allocated to the LTE side in the uplink. In this case, the uplink NR power is insufficient, decreasing the uplink NR throughput or causing service drops on the NR side. If this option is deselected, the maximum transmit power on the LTE side for the UE may not reach the UE's maximum transmit power, decreasing LTE coverage.

PERIODIC_PCC_ANCHORING_SW: If this option is selected, PCC anchoring can be periodically triggered for an NSA-DC-capable UE so that the NSA-DC-capable UE camps on a high-priority frequency to perform NSA DC. This improves user experience of such UEs but increases the number of inter-frequency measurements. If this option is deselected, PCC anchoring cannot be periodically triggered for the NSA-DC-capable UE to camp on a high-priority PCC to perform NSA DC. The UE may camp on a frequency that does not support NSA DC and cannot perform NSA DC, affecting user experience.

NSA_DC_STATE_PCC_ANCHORING_SW: If this option is selected, UEs in the NSA DC state can be handed over to a high-priority frequency through NSA DC PCC anchoring. During measurements and handovers, throughput of these UEs may be affected. If this option is deselected, NSA DC PCC anchoring is disabled for UEs in the NSA DC state, decreasing the impacts of handovers on throughput of UEs in the NSA DC state.

VOLUME_BASED_PERIODIC_TRIG_SW: If this option is selected, the probability of triggering periodic NSA DC PCC anchoring or periodic SCG addition decreases and small-packet services may not trigger NSA DC PCC anchoring or SCG addition. If this option is deselected, the probability of triggering periodic NSA DC PCC anchoring or periodic SCG addition increases and small-packet services can trigger NSA DC PCC anchoring or SCG addition. However, in this case, UEs perform more measurements, increasing UE power consumption.

S1_HO_DATA_FORWARDING_SW: If this option is selected, data forwarding is supported for NSA DC UEs during S1-based handovers, decreasing the packet loss rate and preventing throughput from decreasing sharply during the handovers. If this option is deselected, buffered data is discarded during S1-based handovers for NSA DC UEs. As a result, throughput decreases sharply during S1-based handovers.

SN_TERMN_MCG_BEARER_SWITCH: If this option is selected and the SCG needs to be deleted due to limited NR coverage or other causes, the bearer is terminated on the NR side if possible. This avoids the need of changing the termination point of a bearer between NR and LTE. In this case, the number of ERAB MOD IND messages over the S1 interface is reduced. If this option is deselected, the termination point of a bearer is changed to LTE if the SCG needs to be deleted due to limited NR coverage or other causes. In this case, ERAB MOD IND messages need to be sent over the S1 interface.

NSA_DC_HO_ADM_STRAT_SW: If this option is selected, NSA DC UEs are controlled by the MLB admission policy for target cells during handovers. These UEs cannot be admitted during unnecessary handovers and cannot obtain NSA DC gains brought by high-priority frequencies. If this option is deselected, NSA DC UEs are not controlled by the MLB admission policy for target cells during handovers. These UEs can obtain NSA DC gains on high-priority frequencies during unnecessary handovers, but the number of load-based handovers increases.

IDLE_MODE_NSA_PCC_ANCHORING_SW: If both this option and the NSA_PCC_ANCHORING_SWITCH option are selected, the number of inter-frequency handovers for NSA DC UEs decreases. If this option is deselected, there is no impact on network performance.

VOLUME_BASED_SCG_ADD_OPT_SW: If this option is selected, traffic volume evaluation is more accurate in traffic-volume-based NSA DC PCC anchoring and traffic-volume-based SCG addition. If this option is deselected, network performance is not affected.

NR_COV_PCC_ANCHORING_OPT_SW: If this option is selected and an NSA DC UE cannot enter the EN-DC state in the local cell, the eNodeB hands over this UE to another LTE carrier. This increases the user data rate and the number of inter-frequency handovers. If this option is deselected, network performance is not affected.

NSA_DC_PREALLOCATION_SW: If this option is selected, uplink data transmission latency of NSA DC UEs is shortened but uplink interference and UE power consumption increase. If this option is deselected, network performance is not affected.

NSA_DC_COV_HO_ENH_SW: If this option is selected, the probability of handing over NSA DC UEs to cells on the anchor frequency is higher when coverage-based handovers are triggered. If this option is deselected, network performance is not affected.

NSA_DC_UL_PATH_SELECTION_SW: If this option is selected, uplink data transmission paths are selected based on factors such as load and air interface quality, increasing uplink throughput of NSA DC UEs. If this option is deselected, network performance is not affected.

NSA_DC_COOPERATION_DPS_SW: If this option is selected and the UE supports dynamic power sharing, the maximum power is configured for the LTE side and NR side of the UE to improve the LTE and NR uplink coverage of the UE. If this option is deselected, network performance is not affected.

LNR_DRX_SYNCHRONIZE_SW: If this option is selected, the DRX sleep time on the LTE side is aligned with that on the NR side, and the power consumption of NSA DC UEs is further reduced. This option has no impact on network performance.
