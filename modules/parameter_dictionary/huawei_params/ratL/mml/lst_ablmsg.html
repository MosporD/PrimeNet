List Debugging Message (LST ABLMSG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of debugging messages.

Note

None.

Parameters

ID Name Description
RuleIndex Rule Index

Meaning: Indicates the index of a rule for the debugging message.

GUI Value Range: 0~49

Unit: None

Actual Value Range: 0~49

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configuration of debugging messages, run the following command:
LST ABLMSG:;

Output Description

Field Description

Rule Index

Indicates the index of a rule for the debugging message.

Rule Configuration Type

Indicates whether the rule takes effect on all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified capability.

If this parameter is set to ALL, none of ImeisvTac, ImeisvSvn, and UeCapIndex needs to be configured.

If this parameter is set to IMEISV_TAC, the ImeisvTac parameter must be configured.

If this parameter is set to IMEISV_TAC_SVN, the ImeisvTac and ImeisvSvn parameters must be configured.

If this parameter is set to UE_CAPABILITY, the UeCapIndex parameter must be configured.

IMEISV TAC

Indicates the type allocation code (TAC) in the IMEISVs of UEs. Each TAC identifies a UE model. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

IMEISV SVN

Indicates the software version number (SVN) in the IMEISVs of UEs. Each SVN identifies a software version of UEs. For details about IMEISVs, see section 6.2.2 in 3GPP TS 23.003 V10.1.0 or later releases. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

IMEISV Description

Indicates the user-defined description of the UE type.

UE Capability Index

Indicates the UE capability index. This parameter is mapped to the UeCapIndex parameter in the UeInfo MO.

The index must be set if the UeInfoType parameter is set to UE_CAPABILITY.

Interface Protocol Name

Indicates the interface or protocol type of the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Message Type

Indicates the number of the message transmitted over 3GPP-defined interfaces. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Operate Type

Indicates the operation performed by the eNodeB on a matched message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Count

Indicates the number of items in the debugging message for matching. Each item contains the offset, length, and content.

The value ZERO indicates that the eNodeB discards or modifies the messages with a specific ID.

The value ONE indicates that the eNodeB discards or modifies the messages with the matching result of one item to be positive.

The value TWO indicates that the eNodeB discards or modifies the messages with the matching result of two items to be positive.

The value THREE indicates that the eNodeB discards or modifies the messages with the result of three items to be positive. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Field Offset 1

Indicates the offset for the matching field used when the eNodeB compares each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Length 1

Indicates the length of information used by the eNodeB to compare each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Content 1

Indicates the content with which the eNodeB compares each message received or to be sent by the eNodeB. The content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Field Offset 2

Indicates the offset for the matching field used when the eNodeB compares each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Length 2

Indicates the length of information used by the eNodeB to compare each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Content 2

Indicates the content with which the eNodeB compares each message received or to be sent by the eNodeB. The content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Field Offset 3

Indicates the offset for the matching field used when the eNodeB compares each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Length 3

Indicates the length of information used by the eNodeB to compare each message received or to be sent by the eNodeB with the debugging message. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Match Content 3

Indicates the content with which the eNodeB compares each message received or to be sent by the eNodeB. The content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Count

Indicates the number of items in the debugging message for modification. Each item contains the offset, length, and content.

The value ZERO indicates that the eNodeB does not modify the messages with a positive matching result.

The value ONE indicates that the eNodeB makes one modification to the messages with a positive matching result.

The value TWO indicates that the eNodeB makes two modifications to the messages with a positive matching result.

The value THREE indicates that the eNodeB makes three modifications to the messages with a positive matching result.

Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Field Offset 1

Indicates the offset for the modification field used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Length 1

Indicates the modification length used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Content 1

Indicates the modification content used when the eNodeB modifies a message received or to be sent by the eNodeB. The modification content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Field Offset 2

Indicates the offset for the modification field used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Length 2

Indicates the modification length used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Content 2

Indicates the modification content used when the eNodeB modifies a message received or to be sent by the eNodeB. The modification content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Field Offset 3

Indicates the offset for the modification field used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Length 3

Indicates the modification length used when the eNodeB modifies a message received or to be sent by the eNodeB. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.

Modify Content 3

Indicates the modification content used when the eNodeB modifies a message received or to be sent by the eNodeB. The modification content consists of 0 to 100 hexadecimal digits. Do not change the setting of this parameter without the guidance from Huawei Customer Service Center.
