Modify Cell Short TTI Algorithm Configuration (MOD CELLSHORTTTIALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-level parameter settings related to the short TTI algorithm.

Note

None.

When this parameter is set to RB_32, the SPDCCH occupies 32 RBs and the maximum aggregation level for the SPDCCH is 8. This parameter applies only to LTE FDD.

SttiAlgoSwitch Short TTI Algorithm Switch

Meaning: Indicates whether to enable short TTI in a cell.

SHORT_TTI_SW: Indicates whether to enable short TTI. This option applies only to LTE FDD.

SHORT_TTI_PREALLOCATION_SW: Indicates whether to enable preallocation for the short TTI mode. This option applies only to LTE FDD.

SPDCCH_BOUNDARY_POWER_CTRL_SW: Indicates whether to enable SPDCCH boundary power control. With this option selected, the power can be increased to hold the SPDCCH bit error rate under control when the maximum aggregation level is in use. This option applies only to LTE FDD.

GUI Value Range: SHORT_TTI_SW(SHORT_TTI_SW), SHORT_TTI_PREALLOCATION_SW(SHORT_TTI_PREALLOCATION_SW), SPDCCH_BOUNDARY_POWER_CTRL_SW(SPDCCH_BOUNDARY_POWER_CTRL_SW)

Unit: None

Actual Value Range: SHORT_TTI_SW, SHORT_TTI_PREALLOCATION_SW, SPDCCH_BOUNDARY_POWER_CTRL_SW

MML Default Value: None

Recommended Value: SHORT_TTI_SW:Off, SHORT_TTI_PREALLOCATION_SW:Off, SPDCCH_BOUNDARY_POWER_CTRL_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SHORT_TTI_SW: When this option is selected, the eNodeB will attempt to enable UEs meeting the service QCI and coverage conditions to enter the short TTI mode to shorten service delay. When this option is deselected, network performance is not affected.

SHORT_TTI_PREALLOCATION_SW: When this option is selected, the service delay will be shorter, the SPDCCH will consume more resources, and the uplink interference will increase. When this option is deselected, the preceding impacts are not produced.

SPDCCH_BOUNDARY_POWER_CTRL_SW: When this option is selected, the SPDCCH coverage performance will increase but its capacity will decrease. When this option is deselected, the SPDCCH coverage performance will decrease but its capacity will increase.

Applicable Mode: L-FDD

SttiEntryDcchQualityHyst Short TTI Entry DCCH Quality Hysteresis

Meaning: Indicates the downlink control channel quality hysteresis used for configuring short TTIs for UEs. The eNodeB configures short TTIs for a UE only if the downlink control channel quality for the UE is higher than the sum of the demodulation threshold for the maximum aggregation level of the SPDCCH and this hysteresis. This parameter applies only to LTE FDD.

Unit: dB

Actual Value Range: -20~20

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher probability that short TTIs will be configured for UEs and a higher SPDCCH bit error rate of UEs for which short TTIs are configured. A larger value of this parameter leads to a lower probability that short TTIs will be configured for UEs and a lower SPDCCH bit error rate of UEs for which short TTIs are configured.

Example

To modify the cell Short TTI configuration with the parameters as follows: Local cell ID: 0, SPUCCH RB Count(2RB): 4, run the following command:
MOD CELLSHORTTTIALGO: LocalCellId=0, SpucchRbCnt=4;
