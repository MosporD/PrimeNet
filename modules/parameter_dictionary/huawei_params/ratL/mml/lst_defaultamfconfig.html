List Default AMF Configuration (LST DEFAULTAMFCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the default AMF.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator that owns the NG object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DefaultAmfRegionId Default AMF Region ID

Meaning: Indicates the default AMF region ID. For details, see 3GPP TS 23.501.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
