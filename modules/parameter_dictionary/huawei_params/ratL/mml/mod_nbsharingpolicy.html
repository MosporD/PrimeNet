Modify Nb-IoT Sharing Policy (MOD NBSHARINGPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the sharing policy for an operator in the NB-IoT eNodeB.

Note

If only some operators adopt the sharing policy, the proportion allocated to an operator without adopting the policy is zero. In this case, UE contexts cannot be saved in the eNodeB for UEs of the operator.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the index of the operator. This parameter applies only to NB-IoT.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
UeContextProportion UE Context Proportion

Meaning: Indicates the proportion of UE contexts of the operator in the eNodeB in RAN sharing scenarios. This parameter applies only to NB-IoT.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • The sum of UeContextProportion in all NbSharingPolicy MOs cannot exceed 100.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To modify the configuration of a Nb-IoT Sharing Policy MO with the parameters as follows: Cn Operator ID: 0, UE Context Proportion: 10, run the following command:
MOD NBSHARINGPOLICY: CnOperatorId=0, UeContextProportion=10;
