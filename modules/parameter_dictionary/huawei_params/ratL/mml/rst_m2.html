Reset M2 Configuration (RST M2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to reset an M2 interface.

Note

  • Resetting the M2 MO may interrupt ongoing eMBMS services.

  • If the M2CpBearerId parameter is not specified in the command, all M2 interfaces will be reset.

Parameters

ID Name Description
M2Id M2 ID

Meaning: Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M2CpBearerId M2 Interface CP Bearer ID

Meaning: Indicates the control port (CP) bearer ID of the M2 interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To reset an M2 interface whose ID is 0, run the following command:
RST M2: M2Id=0;
