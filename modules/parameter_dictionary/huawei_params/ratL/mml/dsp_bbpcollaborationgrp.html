Display Bbp Collaboration Group status (DSP BBPCOLLABORATIONGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of a specified BBP collaboration group or all BBP collaboration groups.

Note

None.

Parameters

ID Name Description
BbCoGroupId BBP Collaboration Group ID

Meaning: Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Display Bbp Collaboration Group status:

+++    0        2016-04-21 18:48:37
O&M    #806355038
%%DSP BBPCOLLABORATIONGRP: BbCoGroupId=2;%%
RETCODE = 0  Operation succeeded.

Display Bbp Collaboration Group status
--------------------------------------
BBP Collaboration Group ID  =  2
Collaborating Group Status  =   Normal
(Number of results = 1)

Display Collaboration Cell status
---------------------------------
eNodeB ID  Local Cell ID  Sector equipment ID  Sector Equipment Group ID  Work Status

15383      60             60                   255                        Normal     
(Number of results = 1)


---    END

Output Description

Field Description

BBP Collaboration Group ID

Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

Collaborating Group Status

Indicates the status of a BBP collaboration group. The status can be normal, blocked, being blocked, or being punished, or the group may experience board faults, configuration errors, or board blocking. This parameter applies only to LTE FDD and LTE TDD.
