List Cell Measurement Control Parameters (LST CELLMCPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of the measurement control parameters.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Cell Measurement Control Parameters:
LST CELLMCPARA:;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

A3 Offset(0.5dB)

Indicates the offset for event A3. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates a higher requirement on neighboring cell quality for reporting event A3. This parameter applies only to LTE FDD and LTE TDD.

Hysteresis(0.5dB)

Indicates the hysteresis for reporting event A3 or A6. This parameter is used to prevent frequent entering or leaving of event A3 or A6 and decision errors due to radio signal fluctuation. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Time to Trigger(ms)

Indicates the time-to-trigger for reporting event A3 or A6. When the entering condition of the event is met, the UE does not report the event to the eNodeB immediately. Instead, the UE reports the event only when the entering condition is continuously met throughout the time-to-trigger. This parameter applies only to LTE FDD and LTE TDD.

Max Report Cell Number

Indicates the maximum number of cells to be included in each measurement report after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Report Amount

Indicates the number of periodic measurement reports that are sent after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Report Interval

Indicates the interval between periodic measurement reports that are sent after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Report Quantity

Indicates the type of the value to be included in the measurement report after event A3 or A6 is triggered, which can be set to SAME_AS_TRIG_QUAN or BOTH. The value SAME_AS_TRIG_QUAN indicates that the type of the value to be included in the measurement report is the same as that specified by the TriggerQuantity parameter. The value BOTH indicates that both RSRP and RSRQ values are to be included in the measurement report. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Trigger Quantity

Indicates whether event A3 or A6 is triggered based on RSRP or RSRQ values. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. This parameter applies only to LTE FDD and LTE TDD.

A6 Offset(0.5dB)

Indicates the offset for event A6. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates a higher requirement on neighboring cell quality for reporting event A6. This parameter applies only to LTE FDD and LTE TDD.

IntraFreq Period MR Max Report Cell

Indicates the maximum number of cells to be included in each intra-frequency periodic measurement report. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

IntraFreq Period MR Trigger Quantity

Indicates the type of value used to evaluate the triggering condition for the intra-frequency periodic measurement. The type of value can be RSRP or RSRQ. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

IntraFreq Period MR Report Quantity

Indicates the type of value to be included in the intra-frequency periodic measurement report, which can be set to SAME_AS_TRIG_QUAN or BOTH. The value SAME_AS_TRIG_QUAN(Same as Trig Quan) indicates that the type of value to be included in the measurement report is the same as that specified by the IntraFreqTriggerQuantity parameter. The value BOTH(Both) indicates that both RSRP and RSRQ values are included in the measurement report. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Period MR Max Report Cell

Indicates the maximum number of cells to be included in each inter-frequency periodic measurement report. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Period MR Trigger Quantity

Indicates the type of value used to evaluate the triggering condition for the inter-frequency periodic measurement. The type of value can be RSRP or RSRQ. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Period MR Report Quantity

Indicates the type of value to be included in the inter-frequency periodic measurement report, which can be set to SAME_AS_TRIG_QUAN or BOTH. The value SAME_AS_TRIG_QUAN(Same as Trig Quan) indicates that the type of value to be included in the measurement report is the same as that specified by the InterFreqTriggerQuantity parameter. The value BOTH(Both) indicates that both RSRP and RSRQ values are included in the measurement report. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

A3 Measurement Control Adaptive Switch

Indicates whether parameter configurations related to A3 measurement report can be adaptively modified. This parameter provides the following options:

UlCoMPA3RptIntervalAdapt: If this option is selected, parameter configurations related to A3 measurement report can be adaptively modified. If this option is deselected, parameter configurations related to A3 measurement report cannot be adaptively modified. This option applies only to LTE FDD and LTE TDD.

AoA Detect Threshold(0.01dB)

Indicates the channel quality threshold for measuring the angle of arrival (AOA) of UE signals to the eNodeB. When the channel quality of a UE reaches this threshold, the AOA is measured and the measurement results are reported periodically. This parameter applies only to LTE FDD and LTE TDD.

E-CID Report Amount

Indicates the number of times periodic measurement reports are sent after an E-CID-based OnDemand positioning request is triggered.

E-CID Report Interval

Indicates the interval at which periodic measurement reports are sent after an E-CID-based OnDemand positioning request is triggered.
