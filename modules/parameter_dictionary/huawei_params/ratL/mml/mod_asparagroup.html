Modify Configurations of Air Interface Acceleration Guarantee Parameter Group (MOD ASPARAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of an air interface acceleration guarantee parameter group.

Note

None.

Parameters

ID Name Description
AsParaGroupID Accelerate Service Para Group ID

Meaning: Indicates the acceleration service guarantee parameter group ID. Acceleration service guarantee parameters differ depending on acceleration service guarantee parameter groups.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
AsPreallocDuration Accelerate Service Prealloc Duration

Meaning: Indicates the maximum duration for the preallocation of acceleration services.

When this parameter is used for air interface acceleration guarantee, it indicates the preallocation duration for guaranteed UEs. When this parameter is set to a value within the range of 0-60000, it indicates the actual preallocation duration. When this parameter is set to 65535, preallocation is not stopped until guarantee for the identified acceleration service ends.

When this parameter is used for TCP link setup acceleration guarantee, it indicates the duration when preallocation and scheduling priority take effect for guaranteed UEs. The control precision is 20 ms.

When this parameter is used for WTCP acceleration, it does not take effect.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~60000,65535

Unit: ms

Actual Value Range: 0~60000,65535

MML Default Value: None

Recommended Value: 2000 for air interface acceleration guarantee

400 for TCP link setup acceleration guarantee

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, smart preallocation for an air interface acceleration UE performing data services does not take effect. A larger value of this parameter results in a shorter service delay but more UE power consumption and stronger uplink interference. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
AsPreallocMinPeriod Accelerate Service Prealloc Min Period

Meaning: Indicates the minimum preallocation interval for acceleration services.

GUI Value Range: 1~80

Unit: ms

Actual Value Range: 1~80

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter uplink service delay but more UE power consumption and stronger uplink interference. A larger value of this parameter results in the opposite effects.

Applicable Mode: L
AsPreallocSize Accelerate Service Prealloc Pkt Size

Meaning: Indicates the amount of data pre-allocated for acceleration services.

GUI Value Range: 45~1500

Unit: byte

Actual Value Range: 45~1500

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in shorter uplink data transmission delay but more UE power consumption and stronger uplink interference. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L
AsSchPriFactor Accelerate Service Schedule Priority Factor

Meaning: Indicates the weighting factor used to calculate scheduling priorities for acceleration services. This parameter is used to preferentially guarantee services for acceleration guarantee UEs. This parameter is shared in the uplink and downlink. For FDD cells: If this parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weighting factor. If this parameter is set to 1000 or 65535, acceleration guarantee UEs have the highest priority. For TDD cells: If this parameter is set to a value in the range of 1 to 1000, the priority is calculated using the specified weighting factor. If this parameter is set to 65535, acceleration guarantee UEs have the highest priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000,65535

Unit: None

Actual Value Range: 1~1000,65535

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher scheduling priority and better service rate guarantee for acceleration guarantee UEs, but a lower scheduling priority and poorer user experience for non-acceleration-guarantee UEs. A smaller value of this parameter leads to a smaller difference between the scheduling priorities of acceleration guarantee UEs and non-acceleration-guarantee UEs, and fewer benefits for acceleration guarantee UEs in terms of user experience. If this parameter is set to 1000 or 65535 for LTE FDD cells or to 65535 for TDD cells, acceleration guarantee UEs have the highest priority. In this situation, user experience of non-acceleration-guarantee UEs cannot be ensured, and performance such as uplink and downlink throughput is affected significantly. Therefore, set this parameter to 1000 or 65535 for LTE FDD cells or to 65535 for TDD cells only when there are special requirements on specific services.

Applicable Mode: L-FDD, L-TDD
AsNackCqiAdjValue Accelerate Service NACK CQI Adj Value

Meaning: Indicates the decrease in the CQI adjustment value when an acceleration guarantee UE returns an NACK message. If this parameter is set to a non-zero value, the outer-loop CQI adjustment value decreases by the value of this parameter. If this parameter is set to 0, the optimization does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~330

Unit: 0.1dB

Actual Value Range: 0~33

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller decrease in the downlink CQI adjustment value for acceleration guarantee UEs and a smaller decrease in the downlink packet delay for such UEs, but fewer PDSCH RBs consumed for such UEs. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
AccelerationServiceOptSw Acceleration Service Optimization Switch

Meaning: Indicates whether to enable the acceleration service optimization algorithm.

ENTER_DRX_SWITCH: Indicates whether to enable DRX for acceleration guarantee UEs. If this option is deselected, DRX is disabled for acceleration guarantee UEs. If this option is selected, the eNodeB does not perform special processing on the DRX function for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

MLB_AND_MBOCS_PROHIBITION_SW: Indicates whether to disable MLB and MBOCS for acceleration guarantee UEs. If this option is deselected, acceleration guarantee UEs can be transferred by MLB and MBOCS. If this option is selected, acceleration guarantee UEs cannot be transferred by MLB and MBOCS. This option applies only to LTE FDD and LTE TDD.

PDCCH_BOUNDARY_PC_OPT_SW: Indicates whether to enable PDCCH boundary power control optimization for acceleration guarantee UEs. PDCCH boundary power control optimization is enabled for acceleration guarantee UEs only if this option is selected. This option applies only to LTE FDD.

PERIODIC_MEAS_OPT_SWITCH: Indicates whether to allow acceleration guarantee UEs to perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is deselected, such UEs can perform periodic inter-frequency or inter-RAT measurements and MDT measurements. If this option is selected, the UEs cannot perform these measurements. This option applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: Indicates whether the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is selected, the eNodeB triggers fast-moving-UE smart carrier selection for acceleration guarantee UEs. If this option is deselected, the eNodeB does not trigger fast-moving-UE smart carrier selection for acceleration guarantee UEs. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: ENTER_DRX_SWITCH(ENTER_DRX_SWITCH), MLB_AND_MBOCS_PROHIBITION_SW(MLB_AND_MBOCS_PROHIBITION_SW), PDCCH_BOUNDARY_PC_OPT_SW(PDCCH_BOUNDARY_PC_OPT_SW), PERIODIC_MEAS_OPT_SWITCH(PERIODIC_MEAS_OPT_SWITCH), SCS_FAST_MOVING_UE_SW(SCS_FAST_MOVING_UE_SW)

Unit: None

Actual Value Range: ENTER_DRX_SWITCH, MLB_AND_MBOCS_PROHIBITION_SW, PDCCH_BOUNDARY_PC_OPT_SW, PERIODIC_MEAS_OPT_SWITCH, SCS_FAST_MOVING_UE_SW

MML Default Value: None

Recommended Value: ENTER_DRX_SWITCH:On, MLB_AND_MBOCS_PROHIBITION_SW:Off, PERIODIC_MEAS_OPT_SWITCH:Off, PDCCH_BOUNDARY_PC_OPT_SW:On,

SCS_FAST_MOVING_UE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: ENTER_DRX_SWITCH: If this option is selected, the power consumption of acceleration guarantee UEs is further reduced when the UEs are triggered to enter DRX mode. However, the impact on network performance is subject to the DRX parameter configuration. If this option is deselected, acceleration guarantee UEs cannot enter DRX mode, shortening the delay on the UEs. However, this increases the UE power consumption and reconfiguration message overhead.

MLB_AND_MBOCS_PROHIBITION_SW: If this option is selected, acceleration guarantee UEs cannot be transferred by MLB and MBOCS, hindering load balancing on the network but helping ensure user experience of acceleration guarantee UEs. If this option is deselected, acceleration guarantee UEs can be transferred by MLB and MBOCS, facilitating load balancing on the network but possibly causing user experience deterioration for acceleration guarantee UEs.

PDCCH_BOUNDARY_PC_OPT_SW: If this option is selected and the PDCCH CCE aggregation level reaches the maximum for acceleration guarantee UEs, the power increases quickly and the delay decreases, but the equivalent CCE usage increases. If this option is deselected and the PDCCH CCE aggregation level reaches the maximum for acceleration guarantee UEs, the power increases slowly and the delay increases, but the equivalent CCE usage decreases.

PERIODIC_MEAS_OPT_SWITCH: If this option is selected, acceleration guarantee UEs cannot perform periodic inter-frequency or inter-RAT measurements and MDT measurements, which shortens the delay or increases the data rates of acceleration guarantee UEs. However, the number of periodic inter-frequency or inter-RAT measurement reports and MDT measurement reports may decrease. If this option is deselected, network performance is not affected.

SCS_FAST_MOVING_UE_SW: If this option is selected, fast-moving-UE smart carrier selection is adopted for acceleration guarantee UEs. In this case, if acceleration guarantee UEs are fast-moving UEs, downlink UE throughput can increase. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
AccServiceUeInactivityTmr Acceleration Service UE Inactivity Timer

Meaning: Indicates the length of the UE inactivity timer for only acceleration-involved UEs that do not have QCI-1 services and which this parameter group applies to. If the eNodeB detects that such a UE has neither received nor sent data throughout a period specified by this timer, the eNodeB releases the RRC connection for the UE. If the parameter is set to 0, the eNodeB does not release the RRC connection. If the parameter is set to 65535, the parameter is invalid. If the parameter setting is changed, the change applies to UEs that newly access the network. When used for TCP link setup acceleration guarantee or WTCP acceleration, this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3600,65535

Unit: s

Actual Value Range: 0~3600,65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in earlier RRC connection releases for UEs not performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger value of this parameter results in later RRC connection releases for UEs not performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases. If the UE inactivity timer is set to a smaller value, the number of times UEs near a cell center access the cell becomes larger, resulting in smaller values of the L.RRC.ConnSetup.TimeAvg and L.E-RAB.Est.TimeAvg counters.

Applicable Mode: L

Example

To modify an air interface acceleration guarantee parameter group with the parameters as follows: Accelerate Service Para Group ID: 0, Accelerate Service Prealloc Duration: 2100, Accelerate Service Prealloc Min Period: 10, Accelerate Service Prealloc Pkt Size: 100, Accelerate Service Schedule Priority Factor: 100, Accelerate Service NACK CQI Adj Value:10, Acceleration Service Optimization Switch: ENTER_DRX_SWITCH:ON, Acceleration Service UE Inactivity Timer: 30, run the following command:
MOD ASPARAGROUP: AsParaGroupID=0, AsPreallocDuration=2100, AsPreallocMinPeriod=10, AsPreallocSize=100, AsSchPriFactor=100, AsNackCqiAdjValue=10, AccelerationServiceOptSw=ENTER_DRX_SWITCH-1, AccServiceUeInactivityTmr=30;
