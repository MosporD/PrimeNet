Modify Cell ULZeroBufferZone Configuration (MOD ULZEROBUFFERZONE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of UL Refarming Zero Bufferzone Parameters.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

MML Default Value: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

ZeroBufZoneSwitch Zero Buffer Zone Switch

Meaning: Indicates whether to enable zero bufferzone. When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of this parameter is selected, UMTS and LTE zero bufferzone is enabled. When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option of this parameter is deselected, UMTS and LTE zero bufferzone is disabled. This parameter applies only to LTE FDD.

GUI Value Range: UMTS_LTE_ZERO_BUFFER_ZONE_SW(UMTS_LTE_ZERO_BUFFER_ZONE_SW)

Unit: None

MML Default Value: None

Recommended Value: UMTS_LTE_ZERO_BUFFER_ZONE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When the UMTS_LTE_ZERO_BUFFER_ZONE_SW option is deselected, uplink scheduling for LTE may cause strong interference to intra-frequency neighboring UMTS cells in the uplink. If this option is selected, the eNodeB restricts uplink RB scheduling and optimizes SRS resource configuration to reduce interference to intra-frequency neighboring UMTS cells, which reduces uplink LTE capacity.

Applicable Mode: L-FDD

Example

To modify the configuration of the ULBufferzone optimization as follows: Local cell ID: 0, UL Shared Spectrum Start RB: 50, run the following command:
MOD ULZEROBUFFERZONE: LocalCellId=0, ULSharedFreqStartRB=50;
