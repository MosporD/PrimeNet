Modify Cell Preallocation Group (MOD CELLPREALLOCGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a preallocation parameter group.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PreallocationParaGroupId Preallocation Parameter Group ID

Meaning: Indicates the ID of the parameter group related to preallocations. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PreallocationSwitch Preallocation Switch

Meaning: Indicates whether to enable or disable preallocation for a bearer with a specified preallocation parameter group ID. If this parameter is set to ON(On), preallocation is enabled for this bearer. If this parameter is set to OFF(Off), preallocation is disabled for this bearer. This switch is a bearer-level switch and takes effect when the cell-level switch PreAllocationSwitch in the CellAlgoSwitch MO is turned on. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: After preallocation is enabled, the delay of uplink data transmission is shortened, but the uplink interference and UE power consumption are increased. After preallocation is disabled, the delay of uplink data transmission is increased, but the uplink interference and UE power consumption are decreased.

Applicable Mode: L-FDD, L-TDD
SmartPreallocationSwitch Smart Preallocation Switch

Meaning: Indicates whether smart preallocation is enabled or disabled for a bearer with a specified preallocation parameter group ID when PreAllocationSwitch is turned on. If both PreAllocationSwitch and SmartPreAllocationSwitch are turned on, and SmartPreAllocationDuration is set to a value greater than 0, uplink smart preallocation is enabled; otherwise, uplink smart preallocation is disabled. This switch is a bearer-level switch and takes effect when the cell-level switch PreAllocationSwitch in the CellAlgoSwitch MO is turned on. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: After smart preallocation is enabled, the delay of uplink data transmission is shortened, but the uplink interference and UE power consumption are increased. After smart preallocation is disabled, the delay of uplink data transmission is increased, but the uplink interference and UE power consumption are decreased.

Applicable Mode: L-FDD, L-TDD
PreallocationMinPeriod Minimal Period of Preallocation

Meaning: Indicates the minimum interval between two preallocations, that is, the interval between two times that a UE is preallocated must be greater than or equal to this parameter value. When the DRX algorithm switch is on and the UE is in DRX mode, the actual value of this parameter cannot be greater than the DrxInactivityTimer parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~40

Unit: ms

Actual Value Range: 1~40

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in shorter uplink delay but more UE power consumption and greater uplink interference. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
PreallocationSize Data Size of Preallocation

Meaning: Indicates the data amount preallocated to each UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 45~1500

Unit: byte

Actual Value Range: 45~1500

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SmartPreallocationDuration Smart Preallocation Duration

Meaning: Indicates the duration of each smart preallocation. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2000

Unit: ms

Actual Value Range: 0~2000

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, smart preallocation does not take effect. A larger value of this parameter leads to shorter uplink delay but more UE power consumption and greater uplink interference. A smaller value of this parameter results in the opposite effects. If this parameter value is greater than 1000, delay of ping packets can be reduced.

Applicable Mode: L-FDD, L-TDD

Example

To modify a cell preallocation group as follows: Local Cell ID: 0, Preallocation Parameter Group ID: 5, Smart Preallocation Switch: ON, run the following command:
MOD CELLPREALLOCGROUP: LocalCellId=0, PreallocationParaGroupId=5, SmartPreallocationSwitch=ON;
