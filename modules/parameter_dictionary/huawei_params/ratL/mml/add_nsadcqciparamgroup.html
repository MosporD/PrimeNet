Add QCI-specific NSA DC Parameter Group (ADD NSADCQCIPARAMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a QCI-specific NSA DC parameter group.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NsaDcQciParamGroupId NSA DC QCI Parameter Group ID

Meaning: Indicates the ID of the QCI-specific NSA DC parameter group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlDataSplitThreshold Uplink Data Split Threshold

Meaning: Indicates the uplink data split threshold when the UE performs LTE-NR NSA DC. If the UE PDCP buffer data size is greater than the threshold, the UE transfers data to the master and secondary base stations at the same time. For details, see 3GPP TS 38.323 and 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BYTE0(BYTE0), BYTE100(BYTE100), BYTE200(BYTE200), BYTE400(BYTE400), BYTE800(BYTE800), BYTE1600(BYTE1600), BYTE3200(BYTE3200), BYTE6400(BYTE6400), BYTE12800(BYTE12800), BYTE25600(BYTE25600), BYTE51200(BYTE51200), BYTE102400(BYTE102400), BYTE204800(BYTE204800), BYTE409600(BYTE409600), BYTE819200(BYTE819200), BYTE1228800(BYTE1228800), BYTE1638400(BYTE1638400), BYTE2457600(BYTE2457600), BYTE3276800(BYTE3276800), BYTE4096000(BYTE4096000), BYTE4915200(BYTE4915200), BYTE5734400(BYTE5734400), BYTE6553600(BYTE6553600), INFINITY(INFINITY)

Unit: Byte

Actual Value Range: BYTE0, BYTE100, BYTE200, BYTE400, BYTE800, BYTE1600, BYTE3200, BYTE6400, BYTE12800, BYTE25600, BYTE51200, BYTE102400, BYTE204800, BYTE409600, BYTE819200, BYTE1228800, BYTE1638400, BYTE2457600, BYTE3276800, BYTE4096000, BYTE4915200, BYTE5734400, BYTE6553600, INFINITY

MML Default Value: INFINITY(INFINITY)

Recommended Value: INFINITY(INFINITY)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering uplink data split and a higher uplink cell throughput. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
UlDataSplitPrimaryPath Uplink Data Split Primary Path

Meaning: Indicates the primary path for uplink data split. If this parameter is set to MCG, the primary path for uplink data split is the path towards the MCG. If this parameter is set to SCG, the primary path for uplink data split is the path towards the SCG. For details, see 3GPP TS 38.323. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MCG(MCG), SCG(SCG)

Unit: None

Actual Value Range: MCG, SCG

MML Default Value: SCG(SCG)

Recommended Value: SCG(SCG)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to MCG, uplink data is preferentially transmitted in the MCG, increasing uplink traffic volume in the MCG. If the parameter is set to SCG, uplink data is preferentially transmitted in the SCG, which increases the uplink traffic volume in the SCG.

Applicable Mode: L-FDD, L-TDD
DlDataPdcpSplitMode Downlink Data PDCP Split Mode

Meaning: Indicates the downlink PDCP-layer data split mode. If this parameter is set to SCG_AND_MCG, dynamic data split is adopted and data is dynamically transferred to the eNodeB and gNodeB based on the split algorithm. If this parameter is set to MCG_ONLY, data is transferred only to the eNodeB. If this parameter is set to SCG_ONLY, data is transferred only to the gNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SCG_AND_MCG(SCG_AND_MCG), MCG_ONLY(MCG_ONLY), SCG_ONLY(SCG_ONLY)

Unit: None

Actual Value Range: SCG_AND_MCG, MCG_ONLY, SCG_ONLY

MML Default Value: SCG_ONLY(SCG_ONLY)

Recommended Value: SCG_ONLY(SCG_ONLY)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to SCG_AND_MCG, data is dynamically transferred (to both the master base station and secondary base station). If this parameter is set to MCG_ONLY, data is transferred only to the master base station. If this parameter is set to SCG_ONLY, data is transferred only to the secondary base station.

Applicable Mode: L-FDD, L-TDD
NsaDcB1RsrpThldOffset NSA DC B1 RSRP Threshold Offset

Meaning: Indicates the offset relative to the RSRP threshold for event B1 related to SCG addition by the eNodeB for UEs. The sum of this offset and the value of the NsaDcB1ThldRsrp parameter in the NrScgFreqConfig MO is taken as the RSRP threshold for event B1 related to SCG addition. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -20~20

Unit: dB

Actual Value Range: -20~20

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of reporting event B1. A smaller value of this parameter results in the opposite effect.

Applicable Mode: L-FDD, L-TDD

Example

To add a NSA DC QCI parameter group with Local Cell ID of 0, NSA DC QCI parameter GroupID of 0, and other parameters retaining their default values, run the following command:
ADD NsaDcQciParamGroup: LocalCellId=0, NsaDcQciParamGroupId=0;
