Display Cluster Cell Config (DSP CLUSTERCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query whether all cells are correctly added to the cluster in Cloud BB scenarios.

Note

None.

Parameters

ID Name Description
ClusterId Cluster ID

Meaning: Indicates the ID of a cluster in Cloud BB scenarios. When static clusters are configured, the value of this parameter ranges from 0 to 999. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query dynamic information about the cells in a cluster, run the following command: :
DSP CLUSTERCELL:;
The result is shown as follows:

Output Description

Field Description

Cluster ID

Indicates the ID of a cluster in Cloud BB scenarios. When static clusters are configured, the value of this parameter ranges from 0 to 999. This parameter applies only to LTE FDD and LTE TDD.

Mobile country code

Indicates the mobile country code (MCC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code (MNC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the eNodeB identity of the cluster cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell identity is comprised of the cell identity and the eNodeB identity (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

Cell ID

Indicates the identity of the local cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell identity (represented by the least significant eight bits) and the eNodeB identity. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

Cell Cluster Status

Indicates information about a cell in a cluster. This parameter applies only to LTE FDD and LTE TDD.

Cluster Type

Indicates the feature type of a cluster, which can be CSPC, DL CoMP, CAMC, or UL ISC. This parameter applies only to LTE TDD when it is set to DLCOMP(DLCOMP), CAMC(CAMC), or ULICS(ULICS).

Schedule Node Mobile Country Code

Indicates the MCC of the eNodeB on which the associated centralized scheduling node is deployed. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Schedule Node Mobile Network Code

Indicates the MNC of the eNodeB on which the associated centralized scheduling node is deployed. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Schedule Node eNodeB ID

Indicates the ID of the eNodeB on which the associated centralized scheduling node is deployed. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, in which the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
