Add TceIdIpMapping Information (ADD TCEIPMAPPING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a mapping between the Trace Collection Entity (TCE) ID and IP address.

Note

None.

Parameters

ID Name Description
TceId TCE ID

Meaning: Indicates the ID of the TCE for MDT. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IPMode IP Mode

Meaning: Indicates the IP address version. IPv4~0 indicates that the IP version is IPv4. IPv6~1 indicates that the IP version is IPv6.

GUI Value Range: IPv4(IPv4 Address), IPv6(IPv6 Address)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: IPv4(IPv4 Address)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
TceIpV4Addr TCE IPv4 Address

Meaning: Indicates the IPv4 address of the TCE.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: 0.0.0.0

Recommended Value: None

Parameter Relationship:

-Others:

  • When the IPMODE parameter is set to IPV4(IPv4), the TceIpV4Addr parameter must be set. When the IPMODE parameter is set to IPV6(IPv6), the TceIpV4Addr parameter does not need to be set.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
TceIpV6Addr TCE IPv6 Address

Meaning: Indicates the IPv6 address of the TCE.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: 0:0:0:0:0:0:0:0

Recommended Value: None

Parameter Relationship:

-Others:

  • When the IPMODE parameter is set to IPV6(IPv6), the TceIpV6Addr parameter must be set. When the IPMODE parameter is set to IPV4(IPv4), the TceIpV6Addr parameter does not need to be set.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Add the mapping relationship between TceId and TceIP: TCEId=0, IP mode is IPV4, and IP address is "10.168.168.168", run the following command:
ADD TCEIPMAPPING:TceId=0, IPMode=IPv4, TceIpV4Addr="10.168.168.168";
