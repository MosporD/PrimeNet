Modify Cell-Level Parameter Configurations for Multi-Carrier Joint Scheduling (MOD CELLMULTICARRUNISCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-level parameter configurations for the Multi-Carrier Joint Scheduling feature.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NonCaConnUeScsA1RsrpThld A1 RSRP Thld for Non-CA Connected-Mode UE SCS

Meaning: Indicates the RSRP threshold for event A1 related to the smart carrier selection function for non-CA UEs in connected mode. When this parameter is set to 0, this function is disabled. If this parameter is set to a value other than 0, smart carrier selection based on virtual grids is triggered when the measured RSRP exceeds this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43,0

Unit: dBm

Actual Value Range: -140~-43,0

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Set this parameter based on the networking scenario. If this parameter is set to a too large value, the percentage of UEs for which this function takes effect is low. If this parameter is set to a too small value, no target frequency meets the carrier selection condition when smart carrier selection is triggered for UEs. If this parameter is set to a too large or too small value, UE throughput decreases.

Applicable Mode: L-FDD, L-TDD
ScellDeactvWaitingTimer SCell Deactivation Waiting Timer

Meaning: Indicates the length of the SCell deactivation waiting timer. If this parameter is set to 0, the timer is not used. If this parameter is set to a non-zero value, the timer is used. The timer starts when the downlink buffer for a UE that has an SCell activated is cleared. The eNodeB deactivates the SCell for the UE when the buffer has been empty for a period longer then the length of this timer. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~200

Unit: 0.1s

Actual Value Range: 0~20

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer duration in which SCells are in the active state for UEs, which leads to higher downlink UE throughput and higher UE power consumption. A smaller value of this parameter results in a shorter duration in which SCells are in the active state for UEs, which leads to lower downlink UE throughput and lower UE power consumption. However, if this parameter is set to a too large value, flow control may be triggered, which affects user experience.

Applicable Mode: L-FDD, L-TDD
MobilAdaptCovDlSpctEffThld Mobility Adapt Cov DL Efficiency Thld

Meaning: Indicates the downlink spectral efficiency threshold used in coverage threshold adaptation for mobility management. When the MOBILITY_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the downlink spectral efficiency is lower than the value of this parameter, coverage-based inter-frequency handovers will still be triggered for UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~255

Unit: 0.1bit/s/Hz

Actual Value Range: 0.1~25.5

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs that can perform services in the cell, but the proportion of UEs at the cell edge increases. As a result, KPIs related to access, handover, and service drop deteriorate. A larger value of this parameter results in a smaller number of UEs that can perform services in the cell, and less deterioration in KPIs related to access, handover, and service drop.

Applicable Mode: L-FDD, L-TDD
MobilAdaptCovUlSpctEffThld Mobility Adapt Cov UL Efficiency Thld

Meaning: Indicates the uplink spectral efficiency threshold used in coverage threshold adaptation for mobility management. When the MOBILITY_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the uplink spectral efficiency is lower than the value of this parameter, coverage-based inter-frequency handovers will still be triggered for UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~255

Unit: 0.1bit/s/Hz

Actual Value Range: 0.1~25.5

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs that can perform services in the cell, but the proportion of UEs at the cell edge increases. As a result, KPIs related to access, handover, and service drop deteriorate. A larger value of this parameter results in a smaller number of UEs that can perform services in the cell, and less deterioration in KPIs related to access, handover, and service drop.

Applicable Mode: L-FDD, L-TDD
SccAdaptCovRsrpThld SCC Adapt Cov RSRP Thld

Meaning: Indicates the RSRP threshold for adding an SCell when SCell coverage threshold adaptation is enabled. If the SCC_ADAPT_COV_THLD_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected and the number of carriers aggregated for a UE has not reached the maximum, cells whose measured RSRP values are higher than the value of this parameter can be added as SCells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -125

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs that treat the cell as their SCell, but transmission-related KPIs such as the IBLER and RBLER will deteriorate. A larger value of this parameter results in a smaller number of UEs that treat the cell as their SCell, and less deterioration in transmission-related KPIs.

Applicable Mode: L-FDD, L-TDD

Example

To modify the Multi-Carrier Unified Scheduling parameters as follows: Local cell ID: 100, A1 RSRP Thld for Non-CA Connected-Mode UE SCS: -43, run the following command:
MOD CELLMULTICARRUNISCH: LocalCellId=100, NonCaConnUeScsA1RsrpThld=-43;
