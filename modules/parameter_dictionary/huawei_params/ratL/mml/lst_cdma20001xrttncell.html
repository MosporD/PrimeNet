List Neighboring Relation with CDMA20001XRTT Cell (LST CDMA20001XRTTNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters of the neighboring relation with the CDMA2000 1xRTT cell.

Note

None.

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT cell ID

Indicates the cell ID of the neighboring CDMA2000 1xRTT cell. The cell ID and sector ID together uniquely identify a CDMA2000 cell in the entire network. In the CDMA2000 1xRTT network, a cell ID uniquely identifies a cell within the mobile switching center (MSC). A cell ID consists of 12 bits. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT sector ID

Indicates the sector ID of the neighboring CDMA2000 1xRTT cell. The cell ID and sector ID together uniquely identify a CDMA2000 cell within the MSC. A sector ID is unique in a CDMA2000 cell and consists of 4 bits. This parameter applies only to LTE FDD and LTE TDD.

Band class

Indicates the band class on which the neighboring CDMA2000 1xRTT cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Frequency

Indicates the frequency on which the neighboring CDMA2000 1xRTT cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

System ID

Indicates the system ID of the neighboring CDMA2000 1xRTT cell. A system ID is assigned to each local mobile network and is used to determine whether a UE is in the roaming state. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Network ID

Indicates the network ID of the neighboring CDMA2000 1xRTT cell. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

No handover indicator

Indicates whether to permit or prohibit handovers from the local cell to the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

No remove indicator

Indicates whether to permit or prohibit removal of the neighbor relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.

ANR flag

Indicates whether ANR with CDMA2000 1xRTT cells is enabled. This parameter applies only to LTE FDD and LTE TDD.

Local cell name

Indicates the name of the local cell. This parameter applies only to LTE FDD and LTE TDD.

Neighbour cell name

Indicates the name of the neighboring CDMA2000 1xRTT cell. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
