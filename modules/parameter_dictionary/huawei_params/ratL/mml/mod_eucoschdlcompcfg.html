Modify Parameters Related to Inter-eNodeB DL CoMP (MOD EUCOSCHDLCOMPCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to inter-eNodeB DL CoMP, such as the delay for coordinated information to take effect.

Note

None.

Parameters

ID Name Description
CordInfoEffDelay Coordinated Information Effective Delay

Meaning: Indicates the interval between the time that the eNodeB reports measurement information and the time that the coordinated information delivered to the eNodeB takes effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3~20

Unit: ms

Actual Value Range: 3~20

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that CoMP optimization adapts to UE movements and network services in a timely manner, and accordingly lower CoMP performance gains. A smaller value of this parameter results in a higher probability that CoMP optimization adapts to UE movements and network services in a timely manner, and accordingly higher CoMP performance gains, but a heavier system load.

Applicable Mode: L-FDD, L-TDD
InterEnbDlCompSwitch Inter-eNodeB DlCoMP Algorithm Switch

Meaning: Indicates whether to enable inter-eNodeB DL CoMP in cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to ON, inter-eNodeB DL CoMP in cells under the centralized control node in Cloud BB scenarios is enabled.

Applicable Mode: L-FDD, L-TDD
EuCoSchUeSpec Coordinated Schedule Ue Specification

Meaning: Indicates the number of UEs scheduled by the centralized control node. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~25

Unit: None

Actual Value Range: 1~25

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter leads to higher complexity of the CoMP algorithm, higher CoMP performance gains, but heavier load on the centralized control node. A smaller value of this parameter leads to lower complexity of the CoMP algorithm and lower CoMP performance gains.

Applicable Mode: L-FDD, L-TDD

Example

Modify Parameters Relationed To Inter-eNodeB DL CoMP
MOD EUCOSCHDLCOMPCFG: CordInfoEffDelay=20;
