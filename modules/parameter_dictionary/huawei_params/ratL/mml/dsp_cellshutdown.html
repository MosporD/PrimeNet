Display Intelligent Power-Off of Carriers in the Same Coverage Information (DSP CELLSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the dynamic information about intelligent power-off of carriers in the cell.

Note

When coverage analysis is not complete, the current coverage hole proportion cannot be queried.

When the hierarchical power-off of multiple carriers function has not taken effect, the uplink and downlink PRB usage of multiple carriers in the coverage area of the current cell cannot be queried.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the proportion of coverage holes with the local cell ID of 1, run the following command:
DSP CELLSHUTDOWN: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Coverage Hole Proportion(%)

Indicates the percentage of coverage hole in the coverage area of a capacity cell after this cell is shut down. If the coverage analysis function is not started or coverage analysis has not been completed, NULL will be displayed as the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

Learning Progress(%)

Indicates the sample learning progress for automatic co-coverage identification based on inter-frequency measurement. If coverage analysis has not been started, NULL will be displayed in the command output of DSP CELLSHUTDOWN. This parameter applies only to LTE FDD and LTE TDD.

Carrier Shutdown Status

Indicates the current status of intelligent power-off of carriers for the cell.

Coverage Area DL PRB Usage(%)

Indicates the downlink PRB usage of multiple carriers in the coverage area of the cell. If hierarchical power-off of multiple carriers is disabled, NULL will be displayed. This parameter applies only to LTE FDD and LTE TDD.

Coverage Area UL PRB Usage(%)

Indicates the uplink PRB usage of multiple carriers in the coverage area of the cell. If hierarchical power-off of multiple carriers is disabled, NULL will be displayed. This parameter applies only to LTE FDD and LTE TDD.
