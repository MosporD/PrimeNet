Modify UE-specific Parameter (MOD UESPECIFICPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a UE-specific configuration.

Note

  • Parameters including MoId, ParaId, ParaBitId, and ConfigValue in this command must be specified following the guidance of Huawei technical support. Run this command only under the guidance of Huawei technical support. The UeSpecificPara MO with incorrect parameter settings must be manually deleted.

  • If a switch-type parameter or option is associated with one or more UeSpecificPara MOs and the UeSpecificPara MO with the ConfigValue parameter value indicating that the switch is ON is associated with at least one UeCompat MO, this UeSpecificPara MO functions as a whitelist switch. The eNodeB enables the function controlled by the parameter or option only for whitelisted UEs on the network.

Parameters

ID Name Description
UeSpecificConfigIndex UE-specific Configuration Index

Meaning: Indicates the index of a UE-specific configuration. If there are two or more UeSpecificPara MOs with the same combination of the MoId, ParaId, and ParaBitId parameter values but different indexes configured for the same type of UE, only the UeSpecificPara MO with the smallest index takes effect.

ConfigValue Configured Value

Meaning: Indicates the value of the specified parameter or option. Set this parameter under the guidance of Huawei technical support.

1. The value of the ConfigValue parameter must be within the GUI value range of the parameter or option specified by MoId, ParaId, and ParaBitId unless the ConfigValue parameter value is processed in a special manner. For details about value meanings, see Terminal Awareness Differentiation Feature Parameter Description.

2. If the ParaBitId parameter value is valid, the ConfigValue parameter specifies whether to enable the function that is controlled by the option identified by the ParaBitId parameter. The values 0 and 1 indicate that the function is disabled and enabled, respectively.

3. If the ParaBitId parameter value is invalid, the ConfigValue parameter specifies whether to enable the function that is controlled by the parameter identified by the ParaId parameter. Set ConfigValue based on the setting of the identified parameter.

4. If the ParaBitId parameter value is invalid and the magnitude of the ConfigValue parameter value needs to be greater than 2147483647 (0x7FFFFFFF in the hexadecimal format), set ConfigValue on the GUI to the negation of the number in two's complement. The unsigned number takes effect. For example, if the expected parameter value is 4294967294 (0xFFFFFFFE in the hexadecimal format), set ConfigValue on the GUI to -2 (0xFFFFFFFE in the hexadecimal format).

GUI Value Range: -2147483648~2147483647

Unit: None
