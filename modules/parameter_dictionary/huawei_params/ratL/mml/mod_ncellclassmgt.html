Modify Neighboring Cell Classification Management Parameters (MOD NCELLCLASSMGT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of Neighboring Cell Classification Management.

Note

None.

Parameters

ID Name Description
StatPeriodForNcellClass Statistic Period For Neighbor Cell Classification

Meaning: Indicates the statistical period for intra-RAT neighbor relationship classification. The eNodeB measures the number of handover attempts from a source cell to a target cell, the number of successful handovers from the source cell to the target cell, and the number of times a neighboring cell is configured as an SCell for CA UEs within the statistical period. Based on the measurement results, the eNodeB determines whether the intra-RAT neighboring cell is a formal or extended neighboring cell. If the predefined criteria are met within the statistical period, the intra-RAT neighboring cell is regarded as a formal neighboring cell. If the predefined criteria are not met within each of four consecutive statistical periods, the intra-RAT neighboring cell is regarded as an extended neighboring cell. This parameter also indicates the statistical period for determining whether an intra-RAT neighboring cell is an over-distant neighboring cell. If the number of handovers to a neighboring cell reaches the specified threshold and the handover success rate reaches the specified handover success rate threshold within a statistical period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~50400

Unit: min

Actual Value Range: 1~50400

MML Default Value: None

Recommended Value: 1440

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in lower stability of both the neighbor relationship classification labels and the neighbor relationship classification algorithm. A larger value of this parameter results in higher stability of but lower timeliness of the neighbor relationship classification labels.

Applicable Mode: L-FDD, L-TDD
HoAttemptThd Handover Attempt Threshold

Meaning: Indicates the threshold of the number of handover attempts used for intra-RAT neighbor relationship classification. If the number of handover attempts from a source cell to a target cell within a statistical period of intra-RAT neighbor relationship classification reaches this threshold and the number of successful handovers reaches the threshold of the number of successful handovers, the intra-RAT neighboring cell is regarded a formal neighboring cell. Otherwise, the intra-RAT neighboring cell is regarded an extended neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10000

Unit: None

Actual Value Range: 0~10000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that neighboring cells are labeled as FORMAL, a lower probability of detecting potential neighboring cells with conflicted PCIs, and a higher probability that UEs are handed over to inappropriate neighboring cells in PCI conflict scenarios. A larger value of this parameter results in a lower probability that neighboring cells are labeled as FORMAL, a larger number of handovers that are performed based on ECGI reading results, a greater impact on UE throughput due to ECGI reading, and a higher probability of detecting potential neighboring cells with conflicted PCIs.

Applicable Mode: L-FDD, L-TDD
CaSCellCfgThd Threshold of SCell Configured

Meaning: Indicates the threshold of the number of times a neighboring cell is successfully configured as SCells for CA UEs used in neighbor relationship classification. If the number of times that a neighboring cell is successfully configured as SCells for CA UEs reaches this threshold within a measurement period, the neighboring cell is labeled as FORMAL. If the number cannot reach this threshold within a specified measurement period, the neighboring cell is labeled as EXTENDED. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~10000

Unit: None

Actual Value Range: 1~10000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that neighboring cells are labeled as FORMAL, a higher probability that cells with PCI confusion are labeled as FORMAL, and in turn a larger number of PCI conflicts.

A larger value of this parameter results the opposite effects.

Applicable Mode: L-FDD, L-TDD
HoSuccThd Handover Success Threshold

Meaning: Indicates the threshold of the number of successful handovers for intra-RAT neighbor relationship classification. If the number of handover attempts from a source cell to a target cell within a statistical period of intra-RAT neighbor relationship classification reaches the threshold of the number of handover attempts and the number of successful handovers reaches this threshold, the intra-RAT neighboring cell is a regarded formal neighboring cell. Otherwise, the intra-RAT neighboring cell is regarded an extended neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10000

Unit: None

Actual Value Range: 0~10000

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntraRatNcellMgtMode Intra-RAT Neighbor Cell Management Mode

Meaning: Indicates the intra-RAT neighbor relationship classification mode. If the intra-RAT neighbor relationship classification algorithm is enabled and this parameter is set to CONFIGURATION_MODE, intra-RAT extended neighboring cells are saved in the configuration database. If this parameter is set to INTERNAL_STORAGE_MODE, intra-RAT extended neighboring cells are saved in the eNodeB memory. INTERNAL_STORAGE_MODE takes effect only when the OptMode parameter in the ANR MO is set to FREE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CONFIGURATION_MODE(ConfigMode), INTERNAL_STORAGE_MODE(StorageMode)

Unit: None

Actual Value Range: CONFIGURATION_MODE, INTERNAL_STORAGE_MODE

MML Default Value: None

Recommended Value: INTERNAL_STORAGE_MODE(StorageMode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to INTERNAL_STORAGE_MODE, data of intra-RAT extended neighboring cells is saved in the eNodeB memory, reducing the number of configured neighboring cells and improving neighboring cell OM experience. However, the data stored in the eNodeB memory is deleted after the eNodeB resets. In this case, if UEs are handed over to these neighboring cells, they need to read the CGIs of the neighboring cells again, reducing UE throughput and causing service drops due to delayed UE handovers. Setting this parameter to CONFIGURATION_MODE does not affect network performance.

Applicable Mode: L-FDD, L-TDD

Example

To modify the NCELLCLASSMGT with the parameters as follows: Statistic Period For Neighbor Cell Classification: 1440, Handover Attempt Threshold: 20, run the following command:
MOD NCELLCLASSMGT: StatPeriodForNcellClass=1440, HoAttemptThd=20;
