Modify Intelligent Power-Off of Carriers in the Same Coverage Configuration (MOD CELLSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of intelligent power-off of carriers.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If any basic neighboring cell that covers the same area as the local cell cannot provide services normally or cannot support PLMNs of the local cell, intelligent power-off of carriers cannot be performed for the local cell.

  • If the ForceShutdownUENumThd parameter is set to a non-zero value and the conditions for triggering forcible shutdown are met, capacity cells are forcibly shut down. In this case, UEs that are not handed over from capacity cells to basic cells experience service drops.

CellShutdownSwitch Intelligent power-off of carriers switch

Meaning: Indicates whether to enable intelligent power-off of carriers.

If this parameter is set to ON and the cell meets specific conditions, intelligent power-off of carriers is performed and the eNodeB does not identify co-coverage cells automatically.

If this parameter is set to ON_CO_COV_AUTO_IDENT, coverage analysis will be started for the cell. The proportion of overlapping coverage between the capacity cell and basic cells and the proportion of coverage holes that may be generated after the capacity cell is shut down are analyzed based on inter-frequency MRs. The analysis results are used to determine whether to enable intelligent power-off of carriers.

If this parameter is set to ON_MULTI_CARRIER_HIER_SHUTDOWN, coverage analysis will be started for the cell. The total load of multiple carriers in the coverage area of the cell is calculated based on the co-coverage identification result, and the total load is then compared with the PRB thresholds (specified by DlPrbThd and UlPrbThd in the CellShutdown MO) and offsets (specified by DlPrbOffset and UlPrbOffset in the CellShutdown MO) set for the capacity cell to determine whether to trigger hierarchical intelligent power-off of multiple carriers.

If this parameter is set to OFF, intelligent power-off of carriers does not take effect.

GUI Value Range: OFF(off), ON(ON), ON_CO_COV_AUTO_IDENT(ON_CO_COV_AUTO_IDENT), ON_MULTI_CARRIER_HIER_SHUTDOWN(ON_MULTI_CARRIER_HIER_SHUTDOWN)

Unit: None

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship:

-Configuration constraints:

  • If the CellShutdownSwitch parameter in the CellShutdown MO is set to OFF, the InterBbuCarrierShutdownSw parameter in the CellShutdown MO must not be set to ON.

ForceShutdownUENumThd Force Shutdown UE Number Threshold

Meaning: Indicates the UE quantity threshold for forcible cell shutdown in intelligent power-off of carriers. If a capacity cell meets the conditions for triggering intelligent power-off of carriers, the eNodeB hands over UEs in the capacity cell to a basic cell within 60s. At the end of the 60-second period, if the number of RRC_CONNECTED UEs in the capacity cell is smaller than or equal to this threshold and no UEs with QCI 1 exist in the capacity cell, the eNodeB shuts down the capacity cell. If there are UEs in the capacity cell when the eNodeB is shutting down the cell, service drops occur on these UEs.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, the eNodeB is more likely to trigger forcible cell shutdown, bringing a greater impact on the service drop rate. If this parameter is set to a small value, the eNodeB is less likely to trigger forcible cell shutdown, bringing a smaller impact on the service drop rate. If this parameter is set to 0, the service drop rate is not affected.

Applicable Mode: L
PunishTime Punish Time

Meaning: Indicates the duration of penalty on triggering condition evaluation for the intelligent power-off of carriers feature if UEs in the capacity cell cannot be completely transferred to basic cells after intelligent power-off of carriers is triggered.

GUI Value Range: 0~360

Unit: min

Actual Value Range: 0~360

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter has more significant impact on the energy-saving effects. That is, UEs are less likely to be frequently handed over between a capacity cell and a basic cell. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L
InterBbuCarrierShutdownSw Inter-BBU Carrier Shutdown Switch

Meaning: Indicates whether intelligent power-off of carriers in the same coverage supports inter-BBU carrier shutdown. If this parameter is set to ON, intelligent power-off of carriers in the same coverage supports inter-BBU carrier shutdown, and inter-BBU carrier shutdown is performed when certain conditions are met. If this parameter is set to OFF, intelligent power-off of carriers in the same coverage does not support inter-BBU carrier shutdown. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: N/A

UENumThd UE Number Threshold

Meaning: Indicates the UE quantity threshold for triggering intelligent power-off of carriers in the cell. If the number of RRC_CONNECTED UEs in the capacity cell is less than this threshold and the loads of the capacity cell and basic cell meet the preset uplink and downlink PRB usage thresholds for triggering intelligent power-off of carriers, intelligent power-off of carriers is started for the capacity cell.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of triggering intelligent power-off of carriers in the same coverage. A smaller value of this parameter results in a lower probability.

Applicable Mode: L

Example

To modify the configuration of intelligent power-off of carriers in the same coverage with the parameters as follows: Local cell ID: 0, Intelligent power-off of carriers switch: ON, Start time: 00:00:00; Stop time: 06:00:00, Downlink PRB threshold: 20, Downlink PRB offset: 20, Uplink PRB threshold: 20, Uplink PRB offset: 20, run the following command:
MOD CELLSHUTDOWN: LocalCellId=0, CellShutdownSwitch=ON, StartTime=00&00&00, StopTime=06&00&00, DlPrbThd=20, DlPrbOffset=20, UlPrbThd=20, UlPrbOffset=20;
