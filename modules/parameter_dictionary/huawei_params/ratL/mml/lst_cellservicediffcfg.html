List Cell Service Differentiation Configuration (LST CELLSERVICEDIFFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of cell service differentiation.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of service differentiation of a cell:
LST CELLSERVICEDIFFCFG:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Service differentiation switch

Indicates the switches related to service differentiation in a cell.

CellConStaReportSwitch: Indicates the switch used to control whether the RLC-buffered-based cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. This option applies only to LTE FDD and LTE TDD.

FPIGTPUSwitch: Indicates whether to enable the service differentiation feature using the extended GTP-U header containing the FPI value. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority.

DSCPRemarkSwitch: Indicates whether to enable the DSCP Remark-based service differentiation feature. If this option is selected, the eNodeB guarantees differentiated quality of service (QoS) based on the service type specified by the DSCP field in the IP packet sent by the PDN gateway to the eNodeB. This option applies only to LTE FDD.

CellUuConStaReportSwitch: Indicates the switch used to control whether the PRB-based and UL-sync UE cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. When both the CellConStaReportSwitch and CellUuConStaReportSwitch options are selected, the CellConStaReportSwitch option takes effect but the CellUuConStaReportSwitch option does not take effect. This option applies only to LTE FDD and LTE TDD.

Cell Congestion State PRB Threshold(%)

Indicates the threshold for determining the cell congestion status based on the physical resource block (PRB) usage. The eNodeB generates a cell congestion indicator based on this parameter and the CellConStateUeNumThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and the number of UL-sync UEs are greater than or equal to their respective congestion thresholds but do not exceed their respective overload thresholds, the eNodeB sends a cell congestion indicator to the EPC. If either the downlink PRB usage or the number of UL-sync UEs is less than the corresponding congestion threshold, the eNodeB sends a congestion indicator indicating that the cell is in the normal state to the EPC. This parameter applies only to LTE FDD and LTE TDD.

Cell Overload State PRB Threshold(%)

Indicates the threshold for determining the cell overload status based on the PRB usage. The eNodeB generates a cell overload indicator based on this parameter and the CellOverloadStateUeNumThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and the number of UL-sync UEs are greater than or equal to their respective overload thresholds, the eNodeB sends a cell overload indicator to the EPC. This parameter applies only to LTE FDD and LTE TDD.

Cell Congestion State UE Number Threshold

Indicates the threshold for determining the cell congestion status based on the number of UL-sync UEs. The eNodeB generates a cell congestion indicator based on this parameter and the CellConStatePrbThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and the number of UL-sync UEs are greater than or equal to their respective congestion thresholds but do not exceed their respective overload thresholds, the eNodeB sends a cell congestion indicator to the EPC. If either the downlink PRB usage or the number of UL-sync UEs is less than the corresponding congestion threshold, the eNodeB sends a congestion indicator indicating that the cell is in the normal state to the EPC. This parameter applies only to LTE FDD and LTE TDD.

The eNodeB generates a cell overload indicator based on this parameter and the CellOverloadStatePrbThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and UL-sync UEs are greater than or equal to their respective overload thresholds, the eNodeB sends a cell overload indicator to the EPC. This parameter applies only to LTE FDD and LTE TDD.

Weight of queue 0

Indicates the weight of the queue, which is used in service differentiation scheduling. The value of this parameter is used in calculating the priority of a UE during scheduling and therefore determines the scheduling probability of this UE. The scheduling probability and priority of services in a queue has a positive correlation with the value of this parameter. This parameter is valid only if FPIGTPUSwitch(FPIGTPUSwitch) or DSCPRemarkSwitch(DSCPRemarkSwitch) is turned on. When DSCPRemarkSwitch is turned on, this parameter indicates the weight of non-P2P service queue. This parameter applies only to LTE FDD and LTE TDD.
