Modify License Sharing Policy (MOD LICENSESHARINGPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to license sharing policy.

Note

If a LicenseSharingPolicy MO is not configured for an operator, the proportion of RRC connected users for this operator is 0 by default. Users of this operator cannot access the shared eNodeB.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MaxUserNumRate The proportion of the maximum number of users

Meaning: Indicates the proportion of the number of UEs in RRC_CONNECTED mode of the operator when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the LicenseSharingPolicy MO, the value of UserNumSharingRate must be less than or equal to that of MaxUserNumRate

-Others:

  • The sum of MaxUserNumRate in all LicenseSharingPolicy MOs cannot exceed 100.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserNumSharingRate The proportion of the sharing number of users

Meaning: Indicates the proportion of users that the operator can share with other operators when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the LicenseSharingPolicy MO, the value of UserNumSharingRate must be less than or equal to that of MaxUserNumRate

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
UserNumSharingGroupId User Number Sharing Group ID

Meaning: Indicates the ID of the sharing group of UEs in RRC_CONNECTED mode. Operators with the same UserNumSharingGroupId parameter value share the sum of the proportions of UEs in RRC_CONNECTED mode of each operator and the sum of the penetration rates of UEs in RRC_CONNECTED mode of each operator. The value 255 is an invalid ID, indicating that the operator is not configured with a sharing group of UEs in RRC_CONNETED mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~6,255

Unit: None

Actual Value Range: 1~6,255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To change the value of The proportion of the maximum number of users to 60 for the operator with Cn Operator ID of 0, run the following command:
MOD LICENSESHARINGPOLICY: CnOperatorId=0, MaxUserNumRate=60;
