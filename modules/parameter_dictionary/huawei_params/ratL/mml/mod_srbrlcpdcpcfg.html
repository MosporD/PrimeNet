Modify SRB RLC and PDCP Configuration (MOD SRBRLCPDCPCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of an SRB RLC/PDCP parameter group.

Note

None.
