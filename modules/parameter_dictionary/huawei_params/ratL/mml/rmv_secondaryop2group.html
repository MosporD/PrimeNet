Remove CN Operator from Secondary Operator List (RMV SECONDARYOP2GROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a secondary operator from a carrier-sharing operator group.

Note

If the CnOpSharingGroup MO is referenced by the following associated MOs such as, S1Interface, S1, X2Interface, X2, Cell, the operator to which these MOs belong must be in the carrier-sharing operator group. In this case, when running this command, ensure that the secondary operator to which these MOs belong must be in the carrier-sharing operator group after the command execution. Otherwise, the execution of this command fails

Parameters

ID Name Description
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group. This parameter uniquely specifies a carrier-sharing operator group.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SecondaryOperatorId Secondary Operator Id

Meaning: Indicates the ID of a secondary operator in a carrier-sharing operator group.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove a secondary operator from a carrier-sharing group with the parameters as follows: CN Operator Sharing Group ID: 0, Secondary Operator ID: 1, run the following command:
RMV SECONDARYOP2GROUP: CnOpSharingGroupId=0, SecondaryOperatorId=1;
