Modify eNodeB ANR Measurement Parameter (MOD ANRMEASUREPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations related to ANR measurements. This command applies only to LTE TDD.

Note

None.

Parameters

ID Name Description
A3TimeToTrigForANR Intrafreq Measure Time to Trigger for ANR

Meaning: Indicates the time-to-trigger for the ANR-based intra-frequency measurement event A3.

When a UE detects that the signal quality in the serving cell and that in at least one intra-frequency neighboring cell meets the entering condition, it does not immediately send an ANR-based measurement report to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports and invalid decisions on triggering intra-frequency ANR. This parameter must be set to a value less than or equal to the time-to-trigger for the intra-frequency handover event. This parameter applies only to LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: 256ms(256ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter helps decrease the number of ANR intra-frequency measurement reports and invalid decisions on triggering ANR-based intra-frequency measurements. A larger value of this parameter leads to less invalid decisions and a lower probability of adding unknown target neighboring cells before coverage-based intra-frequency handovers are triggered. As a result, the intra-frequency handover delay cannot be greatly decreased.

Applicable Mode: L-TDD
A3HystForANR Intrafreq Hysteresis for ANR

Meaning: Indicates the hysteresis for the ANR-based intra-frequency measurement event. This parameter is used to decrease the number of invalid decisions on triggering intra-frequency ANR due to radio signal fluctuations. This parameter must be set to a value less than or equal to the hysteresis for intra-frequency handovers. This parameter applies only to LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability of ANR-based intra-frequency measurement reporting, a decreased number of invalid decisions on triggering intra-frequency ANR, but a lower probability of adding unknown target neighboring cells before coverage-based inter-frequency handovers are triggered. As a result, the intra-frequency handover delay cannot be greatly decreased. A smaller value of this parameter leads to a higher probability of ANR-based intra-frequency measurement reporting and a higher probability of adding redundant intra-frequency neighboring cells based on ANR.

Applicable Mode: L-TDD
A3OffsetForANR Intrafreq Measure Offset for ANR

Meaning: Indicates the offset for the signal quality in a neighboring cell relative to that in the serving cell in the ANR-based intra-frequency measurement. A large value indicates that a neighboring cell must have a noticeably better quality than the serving cell before ANR measurement reports can be sent. This parameter must be set to a value less than or equal to the offset for intra-frequency handovers. This parameter applies only to LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability of ANR-based intra-frequency measurement reporting and a decreased number of invalid decisions on triggering intra-frequency ANR. A smaller value of this parameter leads to a higher probability of ANR-based intra-frequency measurement reporting and a higher probability of adding redundant intra-frequency neighboring cells based on ANR.

Applicable Mode: L-TDD

This parameter must be set to a value less than or equal to the time-to-trigger for the inter-frequency handover event. This parameter applies only to LTE TDD.

Unit: ms

A larger value of this parameter leads to less invalid decisions and a lower probability of adding unknown target neighboring cells before coverage-based inter-frequency handovers are triggered. This parameter is used to decrease the number of invalid decisions on triggering inter-frequency ANR due to radio signal fluctuations. This parameter must be set to a value smaller less than or equal to the InterFreqHoA4Hyst parameter. This parameter applies only to LTE TDD.

A4ThdRsrpForANR Interfreq RSRP Threshold for ANR

Meaning: Indicates the RSRP threshold for triggering the ANR-based inter-frequency measurement event. When the measured RSRP value exceeds this threshold, an ANR-based inter-frequency measurement report is sent. This parameter must be set to a value less than or equal to the RSRP threshold for coverage-based inter-frequency handovers. This parameter applies only to LTE TDD.

Unit: dBm

Actual Value Range: -141~-43

Example

To modify the value of Intrafreq Measure Time to Trigger for ANR to 320ms and the value of Interfreq RSRP Threshold for ANR to -103dBm, run the following command:
MOD ANRMEASUREPARAM: A3TimeToTrigForANR=320ms, A4ThdRsrpForANR=-103dBm;
