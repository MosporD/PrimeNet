List License Alarm Threshold (LST ENBLICENSEALMTHD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the license alarm threshold and detection period. Currently, this command applies to the following license items: "Throughput Capacity", "RRC Connected User","eMTC BHCA","NB-IoT BHCA","eMTC BDCA"and"NB-IoT BDCA". The related alarm is System Dynamic Traffic Exceeding Licensed Limit.

Note

None.

Parameters

None.

Example

To list the thresholds related to license alarms, run the following command: :
LST ENBLICENSEALMTHD:;
The result is shown as follows:
+++    0        2019-12-05 17:30:57
O&M    #806355950
%%LST ENBLICENSEALMTHD: ;%%
RETCODE = 0  Operation succeeded.

List License Alarm Threshold
---------------------
OPRD(min)  =  5
  OTHD(%)  =  100
RPRD(min)  =  5
  RTHD(%)  =  90
(Number of results = 1)


---    END

Output Description

Field Description

OPRD(min)

Indicates the license alarm detection period. The eNodeB checks license control items in each period and reports a license-related alarm if the corresponding reporting condition is met.

OTHD(%)

Indicates the license alarm reporting threshold. A license alarm is reported if the proportion of the actually used value to the allocated value of the license control item exceeds this threshold.

RPRD(min)

Indicates the license alarm clearing period. During this period, the eNodeB checks license control items and clears license alarms if the condition for clearing license alarms is met.

RTHD(%)

Indicates the license alarm clearing threshold. A license alarm is cleared if the proportion of the actually used value to the allocated value of the license control item is below this threshold. If this parameter is set to 0, the capacity license alarm must be cleared manually.
