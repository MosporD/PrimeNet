Modify MbsfnAreaCell (MOD MBSFNAREACELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration data of the cells in an MBSFN area.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Unit: None

Actual Value Range: 0~71

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellId Cell ID

Meaning: Indicates the cell identity of an E-UTRAN cell. The cell identity is a string of 28 bits, of which the 20 leftmost bits represent the eNodeB ID and the 8 rightmost bits represent the cell ID. The PLMN ID and the cell identity constitute the ECGI. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EnodebId eNodeB ID

Meaning: Indicates the eNodeB ID, which is a string of at most 20 bits. The ID is unique within a PLMN. The PLMN ID and the eNodeB ID together constitute the global eNodeB ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ReservedCellIndication Reserved Cell Indication

Meaning: Indicates whether an E-UTRAN cell is a reserved cell for MBSFN. If the E-UTRAN cell is a reserved cell, multicast transmission is not performed in the cell. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RESERVED(RESERVED), NONRESERVED(NONRESERVED)

Unit: None

Actual Value Range: RESERVED, NONRESERVED

MML Default Value: None

Recommended Value: NONRESERVED(NONRESERVED)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the MCC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-PLMN and multi-operator scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the MNC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-PLMN and multi-operator scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the following MBSFNAREACELL parameters, Local MCE ID:0, MBSFN Area ID:0, Cell ID:130, eNodeB ID:35566, Reserved Cell Indication:NONRESERVED, run the following command:
MOD MBSFNAREACELL: LocalMceId=0, MbsfnAreaId=0, CellId=130, EnodebId=35566, ReservedCellIndication=NONRESERVED;
