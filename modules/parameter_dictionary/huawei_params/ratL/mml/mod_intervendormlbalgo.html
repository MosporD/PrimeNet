Modify Inter-vendor MLB Algorithm Configuration (MOD INTERVENDORMLBALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameter configuration of inter-vendor MLB algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlCceUsageAdmissionThld DL CCE Usage Admission Threshold

Meaning: Indicates the downlink CCE usage threshold for UE admission in inter-vendor MLB. If the downlink CCE usage of a local cell is greater than or equal to this threshold, the cell cannot be used as a target cell for inter-vendor MLB. If the downlink CCE usage of the cell is lower than this threshold, the eNodeB checks the uplink CCE usage, the proportion of RRC_CONNECTED UEs, and uplink and downlink PRB usages to determine whether the cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship:

-Configuration constraints:

  • The sum of the values of the DlCceUsageAdmissionThld and DlCceUsageOffset parameters in the InterVendorMlbAlgo MO must be smaller than or equal to 100.
  • The value of the DlCceUsageAdmissionThld parameter must be larger than the DlCceUsageOffset parameter in the InterVendorMlbAlgo MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower probability of triggering inter-frequency handovers for inter-vendor MLB. A larger value of this parameter leads to a higher probability of triggering inter-frequency handovers for inter-vendor MLB.

Applicable Mode: L-FDD, L-TDD
DlCceUsageOffset DL CCE Usage Offset

Meaning: Indicates the offset to the downlink CCE usage. When the duration in which the downlink CCE usage is continuously greater than or equal to the sum of the values of this parameter and the DlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the downlink CCE usage. When the duration in which the downlink CCE usage is continuously less than the value of the DlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the downlink CCE usage. The sum of the values of this parameter and the DlCceUsageAdmissionThld parameter cannot exceed 100%. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Meaning: Indicates the RRC_CONNECTED UE proportion threshold for UE admission in inter-vendor MLB. MlbEnhParamAdjustmentRange MLB Enh Param Adjustment Range

Meaning: Indicates the maximum adjustment range of inter- and intra-frequency CIOs and the reselection Qoffset parameter after enhanced coverage-based MLB is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~6

Unit: dB

Actual Value Range: 1~6

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller adjustment range, a smaller number of UEs transferred out of the cell during the same amount of time, a slower load decrease in the serving cell if it is heavily loaded, and a smaller increase in the throughput. A larger value of this parameter leads to a larger adjustment range, a larger number of UEs transferred out of the cell during the same amount of time, a faster load decrease in the serving cell if it is heavily loaded, and a larger increase in the throughput but also more ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
MlbEnhParamRollbackEvalPrd MLB Enh Param Rollback Evaluation Period

Meaning: Indicates the evaluation period of a parameter rollback for enhanced coverage-based MLB. From the moment the process for adjusting CIOs and the reselection Qoffset parameter is terminated, the eNodeB checks whether loads (the proportion of RRC_CONNECTED UEs, PDSCH PRB usage, PUSCH PRB usage, and uplink and downlink PDCCH CCE usages) are less than the rollback thresholds (the corresponding load admission threshold subtracted by the load offset) throughout this evaluation period. If the loads are less than the rollback thresholds, the eNodeB starts the rollback process and rolls back CIOs and the reselection Qoffset parameter step by step for target cells in each implementation period (specified by the InterFreqLoadEvalPrd parameter in the CellMLB MO). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~180

Unit: min

Actual Value Range: 1~180

MML Default Value: None

Recommended Value: 180

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a short evaluation period, a less accurate evaluation of load fluctuations, and earlier triggering of the rollback process. A larger value of this parameter leads to a long evaluation period and a more accurate evaluation of load fluctuations, but delayed triggering of the rollback process.

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameters of inter-vendor MLB algorithm configuration as follows: Local cell ID: 0, MLB Enhance Parameter Rollback Evaluation Period is 60 minute, run the following command:
MOD INTERVENDORMLBALGO: LocalCellId=0, MlbEnhParamRollbackEvalPrd=60;
