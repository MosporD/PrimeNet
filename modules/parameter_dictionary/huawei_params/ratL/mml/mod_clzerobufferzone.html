Modify CLZeroBufferzone (MOD CLZEROBUFFERZONE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to the CDMA and LTE zero bufferzone feature. This command applies only to LTE FDD.

Note

None.

Parameters

ID Name Description
LocalCellId LocalCellId

Meaning: This parameter uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
ClZeroBufzoneDlSharedInd CL Zero Buffer Zone DL Shared Freq Indication

Meaning: Indicates the downlink sharing spectrum scheduling indicator for the CL Zero Bufferzone feature. The parameter is used to configure the policy of using downlink shared spectrum. This parameter applies only to FDD.

GUI Value Range: NOT_SCHEDULING(Not Scheduling Shared Spectrum), CCU_SCHEDULING(CCU Scheduling Shared Spectrum), SCHEDULING(Scheduling Shared Spectrum)

Unit: None

Actual Value Range: NOT_SCHEDULING, CCU_SCHEDULING, SCHEDULING

MML Default Value: None

Recommended Value: CCU_SCHEDULING is recommended when interference to neighboring CDMA intra-frequency cells is acceptable. This value helps improve the spectral efficiency of LTE cells.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to NOT_SCHEDULING, UEs cannot occupy downlink shared spectrum, thereby affecting user experience and downlink cell capacity.

If this parameter is set to CCU_Scheduling, cell center UEs can occupy downlink shared spectrum, thereby improving user experience and downlink cell capacity.

If this parameter is set to SCHEDULING, all UEs can occupy downlink shared spectrum, thereby improving user experience and downlink cell capacity.

Applicable Mode: L-FDD

ClSharedFreqStartRb1 CL Shared Spectrum Start RB1

Meaning: Indicates the start location of resource blocks (RBs) in CL Phase1 Refarming Zero Bufferzone. This parameter applies only to LTE FDD.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: The recommended value is dependent on the frequency relationship between intra-frequency neighboring CDMA carriers and LTE carriers. For example, it is recommended that ClSharedFreqStartRb1 be set to 0 for CDMA (ARFCN 78 and 201) and LTE (EARFCN 2452 and 5 MHz bandwidth).

Parameter Relationship:

-Configuration constraints:

  • In the CLZeroBufferzone MO, the value of ClSharedFreqEndRb1 must be greater than the value of ClSharedFreqStartRb1.

ClZeroBufferZoneUlPrbThd CL Zero Buffer Zone Uplink PRB Threshold

Meaning: Indicates the uplink PRB usage threshold for the CL Zero Bufferzone feature. This parameter takes effect only when ClZeroBufzoneUlSharedInd is set to CCU_SCHEDULING. When the uplink PRB usage is higher than the threshold, the eNodeB determines whether to use uplink shared spectrum. This parameter applies only to FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 25

Parameter Relationship:

-Configuration constraints:

  • In the CLZeroBufferzone MO, the value of ClZeroBufferZoneUlPrbThd must be greater than the value of ClZeroBufferZoneUlPrbOst.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
ClZeroBufferZoneUlPrbOst CL Zero Buffer Zone Uplink PRB Offset

Meaning: Indicates the uplink PRB usage offset for the CL Zero Bufferzone feature. This parameter takes effect only when ClZeroBufzoneUlSharedInd is set to CCU_SCHEDULING. When the uplink PRB usage of a cell is lower than the difference between the uplink PRB threshold and uplink PRB offset for CL intra-frequency bufferzone optimization, uplink shared spectrum decision procedure is exited. This parameter applies only to FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 5

Parameter Relationship:

-Configuration constraints:

  • In the CLZeroBufferzone MO, the value of ClZeroBufferZoneUlPrbThd must be greater than the value of ClZeroBufferZoneUlPrbOst.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
UlNearPtUserRsrpThd Ul Near Point User Rsrp Threshold

Meaning: Indicates the threshold for enabling uplink sharing spectrum scheduling for UEs in or near the cell center in the CL Zero Bufferzone feature. When the UE downlink RSRP is greater than the value of this parameter, the UE is regarded as in or near the cell center. The UE is regarded as far from the cell center only if the UE downlink RSRP is smaller than this parameter value minus 5 dB. This is to prevent signal fluctuation. This parameter applies only to LTE FDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -75

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A large value of this parameter results in a low probability that a UE is regarded as in or near the cell center and therefore a low probability that shared downlink RBs can be used. A small value of this parameter results in a high probability that a UE is regarded as in or near the cell center and therefore a high probability that shared downlink RBs can be used. However, if this parameter is set to an extremely small value, mutual interference between adjacent sites sharing CDMA frequencies increases, thereby deteriorating the downlink performance.

Applicable Mode: L-FDD

Applicable Mode: L-FDD

Example

To modify the configuration of the CLZeroBufferzone optimization as follows: Local cell ID: 0, CL Shared Spectrum End RB1: 10, run the following command:
MOD CLZEROBUFFERZONE: LocalCellId=0, ClSharedFreqEndRb1=10;
