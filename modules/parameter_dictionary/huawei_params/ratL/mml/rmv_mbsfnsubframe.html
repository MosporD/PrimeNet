Remove MbsfnSubframe (RMV MBSFNSUBFRAME)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the configuration data of an MBSFN subframe.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Unit: None

Actual Value Range: 0~71

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnSfConfigId MBSFN Subframe Configuration ID

Meaning: Indicates the ID of an MBSFN subframe configuration. A maximum of eight MBSFN subframe configurations are allowed for an MBSFN area. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove an MBSFNSUBFRAME with the parameters as follows: LocalMceId=0, MbsfnAeraId:0, MbsfnSfConfigId:0, run the following command:
RMV MBSFNSUBFRAME: LocalMceId=0, MbsfnAreaId=0, MbsfnSfConfigId=0;
