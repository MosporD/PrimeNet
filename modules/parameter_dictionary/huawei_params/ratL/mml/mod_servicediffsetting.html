Modify Service Differentiation Configuration (MOD SERVICEDIFFSETTING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to differentiated service settings.

Note

None.

Parameters

ID Name Description
QueueWeight0 Queue0 Weight

Meaning: Indicates the scheduling weight of queue 0. A larger parameter value indicates a higher priority. If the value is 0, queue 0 is not scheduled. The sum of scheduling weight values of all queues must not exceed 100. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~1, step: 0.01

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of ServiceDiffSetting with the parameters as follows: QueueWeight0: 5, QueueWeight1: 10, QueueWeight2: 5, QueueWeight3: 20, QueueWeight4: 5, QueueWeight5: 5, QueueWeight6: 5, QueueWeight7: 10, run the following command:
