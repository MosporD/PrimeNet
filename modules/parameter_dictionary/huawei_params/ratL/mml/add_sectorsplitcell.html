Add Sector Split Cell (ADD SECTORSPLITCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a sector splitting cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of a local cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorSplitGroupId Sector Split Group ID

Meaning: Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellBeamIndex Cell Beam Index

Meaning: Indicates the beam index of a cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellBeamTilt Cell Beam Tilt

Meaning: Indicates the downtilt angle corresponding to the beamforming weight for a massive MIMO cell. This parameter does not take effect for non-massive-MIMO cells and it is recommended that this parameter be set to 0 for non-massive-MIMO cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -15~15

Unit: degree

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellBeamAzimuthOffset Cell Beam Azimuth Offset

Meaning: Indicates the offset to the horizontal azimuth corresponding to the beamforming weight for a massive MIMO cell. The mechanical azimuth of the antenna is used as the normal line. The azimuth is a positive number for clockwise deviation from the normal line or a negative number for counterclockwise deviation from the normal line. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: degree

Actual Value Range: -30~30

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellBeamPowerOffset Cell Beam Power Offset

Meaning: Indicates the offset of the reference signal transmit power used when FDD massive MIMO (32T32R) is enabled relative to the reference signal power set for the cell using the ReferenceSignalPwr parameter. This parameter is valid only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter is selected. This parameter applies only to LTE FDD.

GUI Value Range: -30~30

Unit: 0.1dB

Actual Value Range: -3~3

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a larger increase in data channel power, but the coverage deteriorates.

A smaller value of this parameter leads to a smaller increase in data channel power, but the coverage improves.

Applicable Mode: L-FDD
CellBeamAzimuth Cell Beam Azimuth

Meaning: Indicates the horizontal azimuth corresponding to the beamforming weight for a massive MIMO cell. The mechanical azimuth of the antenna is used as the normal line. The azimuth is a positive number for clockwise deviation from the normal line or a negative number for counterclockwise deviation from the normal line. This parameter takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected and the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in the SectorSplitGroup MO is deselected. The eNodeB can generate a static beam weight file based on the beam azimuth and beam width set for the split sector. The beam azimuth is determined by the SectorSplitCell.CellBeamAzimuth parameter. If this parameter is set to 255, the beam azimuth is the sum of the azimuth configured in the sector beam weight database and the value of the SectorSplitCell.CellBeamAzimuthOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -60~60,255

Unit: degree

Actual Value Range: -60~60,255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The horizontal azimuth of the beam varies with the configured angle. The closer the azimuth specified by this parameter to the direction in which most UEs in the cell are located, the higher the spectral efficiency of transmissions in the cell. The more apart the azimuth from that direction, the lower the spectral efficiency.

Applicable Mode: L-FDD, L-TDD
CellBeamwidth Cell Beamwidth

Meaning: Indicates the horizontal 3 dB beamwidth corresponding to the beamforming weight for a massive MIMO cell. This parameter takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected and the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in the SectorSplitGroup MO is deselected. The sector beamwidth is specified by the CellBeamwidth parameter in the SectorSplitCell MO. When this parameter is set to DEFAULT, the beamwidth set in the sector beam weight database is used. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DEFAULT(DEFAULT), BEAM_WIDTH_15_DEGREE(BEAM_WIDTH_15_DEGREE), BEAM_WIDTH_18_DEGREE(BEAM_WIDTH_18_DEGREE), BEAM_WIDTH_21_DEGREE(BEAM_WIDTH_21_DEGREE), BEAM_WIDTH_26_DEGREE(BEAM_WIDTH_26_DEGREE), BEAM_WIDTH_34_DEGREE(BEAM_WIDTH_34_DEGREE), BEAM_WIDTH_45_DEGREE(BEAM_WIDTH_45_DEGREE), BEAM_WIDTH_70_DEGREE(BEAM_WIDTH_70_DEGREE)

Unit: None

Actual Value Range: DEFAULT, BEAM_WIDTH_15_DEGREE, BEAM_WIDTH_18_DEGREE, BEAM_WIDTH_21_DEGREE, BEAM_WIDTH_26_DEGREE, BEAM_WIDTH_34_DEGREE, BEAM_WIDTH_45_DEGREE, BEAM_WIDTH_70_DEGREE

MML Default Value: DEFAULT(DEFAULT)

Recommended Value: DEFAULT

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a larger beam coverage area. However, the level of interference between beams becomes higher. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
CellBeamTiltFractionPart Cell Beam Tilt Fraction Part

Meaning: Indicates the fractional part of the downtilt angle corresponding to the beamforming weight of a massive MIMO cell. This parameter is used together with the CellBeamTilt parameter, which indicates the integer part of the downtilt angle. The CellBeamTiltFractionPart parameter indicates the fractional part (decimal part) of the downtilt angle. This parameter is valid only for massive MIMO scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -9~9

Unit: 0.1degree

Actual Value Range: -0.9~0.9

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellBeamPower Cell Beam Power

Meaning: Indicates the cell beam power. This parameter takes effect only when the POWER_ALLOCATION_SWITCH option of the SectorSplitGroup.SectorSplitSwitch parameter is selected. This parameter applies only to LTE FDD.

GUI Value Range: 1~10000

Unit: 0.1W

Actual Value Range: 0.1~1000

MML Default Value: 400

Recommended Value: 400

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in lower cell beam power and therefore insufficient cell coverage or lower user-perceived rates. A larger value of this parameter results in higher cell beam power and therefore overshoot coverage or higher user-perceived rates.

Applicable Mode: L-FDD

Example

To add a sector splitting cell with the parameters as follows: LocalCellId: 73, SectorSplitGroupId: 4, CellBeamIndex: 3, run the following command:
+++    0        2017-11-14 19:26:45
O&M    #806354965
%%ADD SECTORSPLITCELL: LocalCellId=73, SectorSplitGroupId=4, CellBeamIndex=3, CellBeamTilt=0;%%
RETCODE = 0  Operation succeeded.


---    END
