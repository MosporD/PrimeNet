Add Cell Operator HO Cfg (ADD CELLOPHOCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add handover configurations for a specific operator in a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the target RAT selection policies are configured in both the CellOpHoCfg MO and CSFallBackBlindHoCfg or CnOperatorHoCfg MO for a specific operator, the parameter configurations in the CellOpHoCfg MO take effect.

TddIfHoA2ThdRsrpOffset LTE TDD Inter-Freq A2 Thd RSRP Offset

Meaning: Indicates the offset for LTE TDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE TDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE TDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter or the FddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the TddIfHoA2ThdRsrpOffset parameter is set to -100 and the FddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE TDD measurement is not triggered, and the eNodeB delivers only LTE FDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE FDD inter-frequency measurement. The RSRP threshold for LTE FDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates whether to enable different types of handovers for a specific operator, based on which the base station determines handover policies.

ServingFreqReselPriority Serving Frequency Reselection Priority

Meaning: Indicates the PLMN-specific dedicated cell-reselection priority for the serving frequency. 0 indicates the lowest priority, 7 indicates the highest priority, and 255 indicates that the parameter is invalid. If this parameter is set to a value other than 255 and the IE "idleModeMobilityControlInfo" needs to be delivered to a UE during RRC connection release, the eNodeB delivers dedicated cell-reselection priorities for the serving frequency of PLMNs that the UE supports. If this parameter is set to 255, PLMN-specific dedicated cell-reselection priorities for the serving frequency are not configured and the UE uses the cell-reselection priority of the serving frequency broadcast in system information. The value of this parameter must be determined together with that of other frequencies during network planning. Frequencies used for different RATs must be assigned different absolute cell-reselection priorities. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7,255

Unit: None

Actual Value Range: 0~7,255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of cell reselections of UEs to cells on the serving frequency. A larger value of this parameter results in the opposite effect.

Applicable Mode: L-FDD, L-TDD

Example

To add the handover configurations for a specific operator in from a cell,  with the parameters as follow: Local cell ID: 0, CN Operator ID: 0, run the following command:
ADD CELLOPHOCFG: LocalCellId=0, CnOperatorId=0;
