Create Mce (ADD MCE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add MCE configuration data.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MceId MCE ID

Meaning: Indicates the ID of an MCE. It uniquely identifies an MCE within a PLMN. The PLMN ID and the MCE ID together constitute the global MCE ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the MCC of an MCE. An MCC and an MNC constitute a PLMN ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the MNC of an MCE. An MCC and an MNC constitute a PLMN ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MceType MCE Type

Meaning: Indicates whether different types of RATs support distributed MCE. DISTRIBUTED_MCE(FDD_DISTRIBUTED_MCE): Indicates whether FDD supports distributed MCE. This option applies only to LTE FDD. TDD_DISTRIBUTED_MCE(TDD_DISTRIBUTED_MCE): Indicates whether TDD supports distributed MCE. This option applies only to LTE TDD.

GUI Value Range: DISTRIBUTED_MCE(FDD_DISTRIBUTED_MCE), TDD_DISTRIBUTED_MCE(TDD_DISTRIBUTED_MCE)

Unit: None

Actual Value Range: DISTRIBUTED_MCE, TDD_DISTRIBUTED_MCE

MML Default Value: None

Recommended Value: DISTRIBUTED_MCE:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MceName MCE Name

Meaning: Indicates the name of an MCE. For details, see 3GPP TS 36.443. The value of this parameter is a string of a maximum of 150 characters. The string cannot be null characters or contain any of the following characters: double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three plus signs (+++), two or more consecutive spaces, and two or more consecutive percentage signs (%). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~150 characters

Unit: None

Actual Value Range: 0~150

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an MCE with the parameters as follows: Local MCE ID: 0, MCE ID:1,  MCE Type:DISTRIBUTED_MCE, MCE Name:"mce", run the following command:
ADD MCE: LocalMceId=0, MceId=1, MceType=DISTRIBUTED_MCE-0, MceName="mce";
