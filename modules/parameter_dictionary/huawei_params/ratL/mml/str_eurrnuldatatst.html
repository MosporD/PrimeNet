Start RRN Uplink Data Test (STR EURRNULDATATST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start the uplink data test of the RRN.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The uplink data test of the RRN must be executed on an existing service. If the service does not exist, the test fails.

  • When operators start an uplink data test, the source IP address, source port number, destination IP address, and destination port number can be set randomly within their value ranges. They are used to simulate IP data packets.

  • This operation will affect backhaul service provided by the RRN. As a result, the ReBTS connected to the RRN may be disconnected from the NMS.

  • This operation increases the load of the BBP serving the RRN UEs. If the load increases too fast, the BBP enters the flow control state, affecting services of other UEs carried on the baseband processing unit. Run this command only under the guidance of Huawei technical support.
