Modify Cell Access Configuration (MOD CELLACCESS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell access.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifications of CellBarred parameter will affect the cell on which the UE in idle mode camps

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
CellBarred Cell barring state

Meaning: Indicates whether the cell is barred. If the cell is barred, the UE cannot camp on the serving cell. During cell reselection, the serving cell is not selected as a candidate cell.

GUI Value Range: CELL_BARRED(Barred), CELL_NOT_BARRED(Not Barred)

Unit: None

Actual Value Range: CELL_BARRED, CELL_NOT_BARRED

MML Default Value: None

Recommended Value: CELL_NOT_BARRED(Not Barred)

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter will affect the cell on which the UE in idle mode camps.)

Impact on Radio Network Performance: None

Applicable Mode: L
IntraFreqResel Intra-frequency reselection indication

Meaning: Indicates whether the cell can initiate the intra-frequency cell reselection when the cell is barred.

NOT_ALLOWED means that the UE cannot initiate the intra-frequency cell reselection, and ALLOWED means that the UE can initiate the intra-frequency cell reselection.

GUI Value Range: ALLOWED, NOT_ALLOWED

Unit: None

Actual Value Range: ALLOWED, NOT_ALLOWED

MML Default Value: None

Recommended Value: ALLOWED

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter will affect the cell on which the UE in idle mode camps.)

Impact on Radio Network Performance: None

Applicable Mode: L
BroadcastMode Plmn Broadcast Mode

Meaning: Indicates the public land mobile network (PLMN) broadcast mode of the cell. If RAN sharing with common carrier or hybrid RAN sharing is enabled in some cells on the live network and the PLMN ID at the top of the broadcast PLMN list is rotated in at least one of these cells, NBSLTEPLMNRoundSwitch under the RanSharingAnrSwitch parameter must be selected for eNodeBs meeting the following condition: The cells in which the PLMN ID at the top of the broadcast PLMN list is rotated may be configured as neighboring cells for cells served by these eNodeBs. Otherwise, these eNodeBs may experience failures in handing over UEs to ANR-established neighboring cells in which the PLMN ID at the top of the broadcast PLMN list is rotated. If this parameter is set to NORMAL_MODE, PLMN IDs are broadcast in a fixed sequence in the cell. If this parameter is set to RR_MODE, the PLMN ID at the top of the PLMN ID list is rotated in RR mode at a cell-specific interval. If this parameter is set to FREE_MODE, the PLMN ID at the top of the PLMN ID list is rotated at an operator-specific interval. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NORMAL_MODE(Normal Mode), RR_MODE(Round Robin Mode), FREE_MODE(Free Mode)

Unit: None

Actual Value Range: NORMAL_MODE, RR_MODE, FREE_MODE

MML Default Value: None

Recommended Value: NORMAL_MODE(Normal mode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
RoundPeriod Plmn Round Broadcast Period

Meaning: Indicates the changing period of cell PLMN.

GUI Value Range: 1~720

Unit: h

Actual Value Range: 1~720

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
RoundActionTime Plmn Round Action Time

Meaning: Indicates the start time for broadcasting PLMN-specific information in round robin mode.

GUI Value Range: 2000-01-01T00:00:00+00:00~2099-12-31T23:59:59+00:00

Unit: None

Actual Value Range: 2000-01-01T00:00:00+00:00~2099-12-31T23:59:59+00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the CellAccess MO, the year, month, day, and hour in RoundActionTime can be set to non-zero values, and others (such as the minute and second) in this parameter must be set to 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
ReptSyncAvoidInd Repeat Synchronization Avoid Indication

Meaning: Indicates whether all synchronization procedures repeatedly initiated by a UE having compatibility problems can trigger the RRC connection reconfiguration procedure. If this parameter is set to CFG, all synchronization procedures repeatedly initiated by a UE having compatibility problems do not trigger the RRC connection reconfiguration procedure. If this parameter is set to NOT_CFG, all synchronization procedures repeatedly initiated by a UE having compatibility problems trigger the RRC connection reconfiguration procedure. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: None

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Assume that there are UEs with the compatibility issue of repeatedly initiating synchronization. If this parameter is set to CFG, signaling overheads on the network decrease, and the access delay of normal UEs is not affected. If this parameter is set to NOT_CFG, signaling overheads on the network may increase.

Applicable Mode: L-FDD, L-TDD
ReptSyncAvoidTime Repeat Synchronization Avoid Time

Meaning: Indicates the period during which synchronization procedures repeatedly initiated by a UE having compatibility problems are prohibited from triggering multiple RRC connection reconfiguration procedures. Multiple synchronization procedures initiated by a UE having compatibility problems within the period specified by this parameter trigger only one RRC connection reconfiguration procedure. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: ms

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If UEs having compatibility problems exist in the network, a larger value of this parameter leads to a larger decrease in the signaling generated due to repeatedly initiated synchronization procedures by such UEs but a longer delay for such UEs to access the network. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

Example 1:To modify the cell access information with the parameters as follows: Local cell ID: 0, 
Cell barring state: CELL_BARRED, Intra-frequency reselection indication: ALLOWED, run the following command: 
MOD CELLACCESS: LocalCellId=0, CellBarred=CELL_BARRED, IntraFreqResel=ALLOWED;
Example 2: To modify the cell access information with the parameters as follows: Local cell ID: 0, 
Cell barring state: CELL_NOT_BARRED, Intra-frequency reselection indication: NOT_ALLOWED, run the following command: 
MOD CELLACCESS: LocalCellId=0, CellBarred=CELL_NOT_BARRED, IntraFreqResel=NOT_ALLOWED;
