Modify S1 Reestablishment Timer Setting (MOD S1REESTTIMER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to the S1 interface reestablishment timer.

Note

None.

Parameters

ID Name Description
S1ReestMinTimer S1 reestablish min timer length

Meaning: Indicates the minimum length of the S1 re-establishment timer.

GUI Value Range: 1~300

Unit: s

Actual Value Range: 1~300

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • In the S1ReestTimer MO, the value of S1ReestMinTimer must be less than or equal to that of S1ReestMaxTimer.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
S1ReestMaxTimer S1 reestablish max timer length

Meaning: Indicates the maximum length of the S1 re-establishment timer.

GUI Value Range: 1~300

Unit: s

Actual Value Range: 1~300

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the S1ReestTimer MO, the value of S1ReestMinTimer must be less than or equal to that of S1ReestMaxTimer.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the parameters related to the S1 reestablishment timer as follows: S1 Reestablish Min Timer Length: 1, S1 Reestablish Max Timer Length: 300, run the following command:
MOD S1REESTTIMER: S1ReestMinTimer=1, S1ReestMaxTimer=300;
