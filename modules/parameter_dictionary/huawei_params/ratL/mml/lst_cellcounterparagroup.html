List Cell Counter Parameter Group (LST CELLCOUNTERPARAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list settings of parameters related to cell-level performance counter measurement.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of parameters related to cell-level performance counters:
LST CELLCOUNTERPARAGROUP:;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Cell User Number PDF Counter Threshold

Indicates the interval in which the statistics on the number of UEs in RRC_CONNECTED mode are collected. Eleven ranges are divided into based on this parameter value (referred as "N"): [0, N/10), [N/10, 2N/10), [2N/10, 3N/10), [3N/10, 4N/10), [4N/10, 5N/10), [5N/10, 6N/10), [6N/10, 7N/10), [7N/10, 8N/10), [8N/10, 9N/10), [9N/10, N), and [N, infinity). Each range corresponds to a performance counter. The number of UEs in RRC_CONNECTED mode is periodically sampled. A counter is incremented by one each time a sampled value falls into the corresponding range. For detailed descriptions of the performance counters affected by this parameter, see "Description" of counters related to UE distribution in the performance counter reference. To ensure that all sampled values fall into proper ranges, set this parameter based on the number of UEs in the cell. For example, if the average number of UEs in the cell is large, set this parameter to a large value; otherwise, set this parameter to a small value. This parameter applies only to LTE FDD and LTE TDD.

Uplink Ibler Optimization Switch

Indicates whether to enable uplink IBLER optimization. If this parameter is set to ON, for LTE TDD cells, the TBs not received are not taken into account for the IBLER calculation if DTX is detected based on the PUSCH. This function applies only to subframe configurations 2 and 5. If LTE TDD cells are established on the LBBPc, PUSCH DTX detection is not supported. If the PuschDtxSchOptSwitch option is deselected, the uplink IBLER is not affected even if this parameter is set to ON. For NB-IoT cells, uplink IBLER measurement is optimized. false PRACH detection due to interference is not considered during IBLER and RBLER measurement. The counters related to the number of TBs involved in uplink BPSK and QPSK modulation schemes are not taken into account. If this parameter is set to OFF, uplink IBLER measurement is not optimized for LTE TDD cells, and uplink IBLER and RBLER measurement is not optimized for NB-IoT cells. This parameter applies only to LTE TDD and NB-IoT.

Cell Counter Algorithm Switch

Indicates whether to enable cell-level algorithms related to performance counters. This parameter includes the following options: BasedA3EdgeUserSwitch: Indicates whether to enable A3-based cell edge user (CEU) identification. If this option is selected, the eNodeB starts to identify CEUs based on A3-related measurement reports and collects related performance counters based on the identified CEUs. This option applies only to LTE FDD and LTE TDD.

UlStatOptmizeSwitch: Indicates whether to optimize measurement of uplink interference. If this option is selected, the eNodeB optimizes measurement of uplink interference, and interference noise caused by RRUs is not measured. If this option is deselected, the eNodeB does not optimize measurement of uplink interference, and interference noise caused by RRUs is measured. This option applies only to LTE FDD and LTE TDD.

InSessionUeQtyUlDlAccSwitch: Indicates the method of collecting statistics about Number of UEs with Service Data to Be Transmitted in a Cell. When this option is deselected, the eNodeB samples the number of UEs in RRC_CONNECTED mode with data in the buffer every 100 ms in a cell, regardless of whether the data is in the uplink or downlink. When this option is selected, the eNodeB samples the number of UEs with uplink data in the buffer and the number of UEs with downlink data in the buffer every 100 ms in a cell. The numbers sampled in the uplink and the numbers sampled in the downlink are then separately added up. When a single UE performs services with multiple QCIs in the uplink or downlink, the number is then incremented on a per QCI basis. This option applies only to LTE FDD and LTE TDD.

RrcConnectedUserCountOptSwitch: Indicates the method of calculating the average number of users in a cell (L.Traffic.User.Avg) and maximum number of users in a cell (L.Traffic.User.Max). If this option is selected, downlink CA UEs that treat the cell as their SCell are counted while calculating the preceding counters. This option applies only to LTE FDD and LTE TDD.

RrcSetupSuccRateByRadiusOptSw: Indicates the method of measuring the RRC connection setup success rate when the ForbidAcByRadiusSwitch option of the RachAlgoSwitch parameter in the CellAlgoSwitch MO is selected. If this option is selected, the number of rejected RRC connection setup requests of UEs initiating access beyond the cell radius is not taken into account for RRC connection setup success rate measurements. If this option is deselected, the number is taken into account for the measurements. This option applies only to LTE FDD and LTE TDD.

UlIntrfMeasOptSw: Indicates whether to change the interference value for protection. When this option is selected, measurements are optimized in low-interference scenarios. If this option is deselected, the function does not take effect. This option applies only to LTE FDD and LTE TDD.

TaDistanceMappingSwitch: Indicates whether to exclude the impact of UL CoMP when TA-related statistics are collected in the cell. If this option is selected, the impact of UL CoMP will be excluded when TA-related statistics are collected. If this option is deselected, the impact of UL CoMP will not be excluded when TA-related statistics are collected. This option applies only to LTE FDD and LTE TDD.

VolteE2eVqiMeasOptSw: Indicates whether to optimize E2E VQI measurement. If this option is selected, packets received within a 2.5s period are measured with delay considered during the measurement of E2E VQI counters for calculating the MOS. If this option is deselected, measurement of E2E VQI counters is not optimized. This option applies only to LTE FDD and LTE TDD.

Edge User Distinguish A3 Offset(0.5dB)

Indicates the offset for cell edge user (CEU) identification event A3. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter results that better signal quality of the neighboring cell is required for the reporting of CEU identification event A3 and the eNodeB has a lower probability of identifying a UE as a CEU. A smaller value of this parameter results in a higher probability that a UE is identified as a CEU. This parameter applies only to LTE FDD and LTE TDD.

Ue Abnormal Judge Thd(%)

Indicates the uplink reception error rate threshold for identifying abnormal UEs. If this parameter is set to 0, abnormal UE identification based on the service drop rate is disabled. If this parameter is set to a non-zero value, an eNodeB identifies UEs with an uplink reception error rate greater than or equal to the specified threshold as abnormal UEs and counts the releases of such UEs as normal releases in context- and E-RAB-related statistics collection. In FDD networks, if this parameter is set to a non-zero value and the UELinkAbnormalDetectSwitch parameter is set to ON, the setting of the UELinkAbnormalDetectSwitch parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

Statistical Policy for Throughput PDF

Indicates the policy of collecting statistics on throughput distribution. When this parameter is set to NORMAL, statistics about the downlink PDCP SDU throughput are collected based on the following formula: (L.Thrp.bits.DL - L.Thrp.bits.DL.LastTTI)/L.Thrp.Time.DL.RmvLastTTI. The statistics are collected in the corresponding throughput distribution ranges. When this parameter is set to BEARER, statistics about the downlink PDCP SDU throughput of services in the cell are collected based on the entire service period. When a service is released, the eNodeB collects statistics about the rate of the service in the entire service period. When this parameter is set to SMALL_PKT_CONVERT, statistics about the downlink PDCP SDU throughput are collected based on the following formula: L.Thrp.bits.DL/L.Thrp.Time.DL.SmallPktConverted. The statistics are collected in the corresponding throughput distribution ranges. For details about the descriptions of related counters about the downlink throughput distribution in different ranges, see eNodeB Performance Counter Reference. This parameter applies only to LTE FDD and LTE TDD.

Edge User Serving Cell RSRP Threshold(dBm)

Indicates the serving cell RSRP threshold for determining CEUs when the BasedA3EdgeUserSwitch option of the CellCounterAlgoSwitch parameter is selected. A larger value of this parameter indicates a higher probability of identifying a UE as a CEU. A smaller value of this parameter indicates a lower probability of identifying a UE as a CEU. The value 255 indicates that the serving cell RSRP is not used in the identification. This parameter applies only to LTE FDD and LTE TDD.

Edge User SRS Offset(0.5dB)

Indicates the signal quality offset used for identifying CEUs in SRS-based CEU identification. A larger value of this parameter results in a smaller number of relative CEUs involved in counter-based performance statistics collection. A smaller value of this parameter results in a greater number of relative CEUs involved in counter-based performance statistics collection. This parameter applies only to LTE FDD and LTE TDD.

CHR Output Mode Switch

Indicates the mode of exporting CHR logs. VoLTECHRSamplingSwitch: Indicates whether to sample VoLTE LowQual events. If this option is deselected, VoLTE LowQual events are sampled. If this option is selected, VoLTE LowQual events are not sampled, and all such events are exported. CHRDelayReportSwitch: Indicates whether to delay the reporting of external CHRs after UE access. If this option is selected, external UE-level CHRs are reported at the end of the first CHR reporting period after network access. If this option is deselected, external UE-level CHRs are reported immediately after network access. ChrReportingPeriodCtrlSw: Indicates the period of reporting the external CHR UE-level event PERIOD_UE_RRU_INFO. If this option is selected, the event is reported every 2s. If this option is deselected, the event is reported every 5s. This parameter applies only to LTE FDD and LTE TDD.

DL User Experience Unsatisfied Threshold(kbit/s)

Indicates the threshold of defining the unsatisfied downlink user-perceived data rate. This parameter is used to collect statistics about the number of times the downlink user-perceived data rates are poor. This parameter is configured depending on the requirement of operators on user-perceived data rates. A data rate higher than this parameter value is regarded as a satisfied data rate.

DL Traffic Volume Threshold (kB)

Indicates the traffic volume threshold for collecting statistics about counters related to the downlink user-perceived data rate.

DL Packet Delay Measurement Policy

Indicates the policy of collecting statistics about the downlink packet delay. When this parameter is set to DEFAULT, the delay starts from the time the PDCP layer receives packets and ends at the time the MAC layer on the eNodeB side sends packets. The eNodeB measures the delay only if it receives HARQ ACK feedback of the packets from the UE. When this parameter is set to START_FROM_ARRIVE, the delay starts from the time the PDCP layer receives packets and ends at the time the MAC layer on the eNodeB side receives HARQ ACK feedback of the packets from the UE. If this parameter is set to START_FROM_SEND, the delay starts from the time the MAC layer sends packets and ends at the time the MAC layer on the eNodeB side receives HARQ ACK feedback of the packets from the UE. This parameter applies only to LTE FDD and LTE TDD.

QCI1 Continuous Packet Loss Threshold

Indicates the threshold of the number of QCI 1 packets consecutively lost in the uplink and downlink. This threshold is used as a criterion to start measuring the numbers of times words are skipped and voice intermittence occurs due to consecutive packet loss in the uplink and downlink and the number of calls. If the number of consecutively lost packets is greater than or equal to this threshold, the corresponding counters start measurement. For details about the corresponding counters, see the descriptions of counters that measure consecutive packet loss in the uplink and downlink in Performance Counter Reference. This parameter applies only to LTE FDD and LTE TDD.

MTT Traffic Ratio Threshold(%)

Indicates the traffic percentage threshold used for calculating main traffic time (MTT). In a measurement period, the traffic volumes reported every second are sorted in descending order and are added up starting from the largest traffic volume. When the percentage of the sum of the first N traffic volumes reaches or exceeds the value of this parameter, the MTT is N seconds. This parameter applies only to LTE FDD and LTE TDD.

QCI-Level Throughput Measurement Policy

Indicates the policy of measuring QCI-specific uplink and downlink UE throughput.

If this parameter is set to DEFAULT: Counters L.Thrp.Time.DL.RmvLastTTI and L.Thrp.Time.DL.RmvLastTTI.QCI.1 to L.Thrp.Time.DL.RmvLastTTI.QCI.9 measure QCI-specific downlink data transmission duration excluding the last TTIs in which the downlink buffer becomes empty. Counters L.Thrp.bits.UE.UL.LastTTI.QCI.1 to L.Thrp.bits.UE.UL.LastTTI.QCI.9 measure QCI-specific uplink traffic volume received in the TTIs in which the uplink buffer becomes empty. Counters L.Thrp.Time.UE.UL.RmvLastTTI.QCI.1 to L.Thrp.Time.UE.UL.RmvLastTTI.QCI.9 measure QCI-specific total uplink data transmission duration excluding the last TTIs in which the UE buffer becomes empty.

If this parameter is set to SPECIFIC_TTI_REMOVED: Counters L.Thrp.Time.DL.RmvLastTTI and L.Thrp.Time.DL.RmvLastTTI.QCI.1 to L.Thrp.Time.DL.RmvLastTTI.QCI.9 measure QCI-specific downlink data transmission duration except the TTIs in which no DRBs are scheduled and the last TTIs in which the downlink buffer becomes empty. Counters L.Thrp.bits.UE.UL.LastTTI.QCI.1 to L.Thrp.bits.UE.UL.LastTTI.QCI.9 measure the QCI-specific uplink PDCP-layer traffic volume of specific small packets transmitted in the last TTIs. Counters L.Thrp.Time.UE.UL.RmvLastTTI.QCI.1 to L.Thrp.Time.UE.UL.RmvLastTTI.QCI.9 measure the QCI-specific uplink UE data transmission duration except the last TTIs in which specific small packets are transmitted.

This parameter applies only to LTE FDD and LTE TDD.

Downlink High AMBR Threshold(Mbps)

Indicates the downlink AMBR threshold for identifying UEs with a high downlink AMBR. If the downlink AMBR of a UE is greater than or equal to this threshold, the eNodeB identifies the UE as a UE with a high downlink AMBR. The eNodeB uses specific counters to measure UEs with a high downlink AMBR. If this parameter is set to 0, the eNodeB identifies all UEs as UEs with a high downlink AMBR. This parameter applies only to LTE FDD and LTE TDD.
