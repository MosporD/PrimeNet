Display RRN Information (DSP EURRNINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information about an RRN.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RrnInfoParmType RRN Information Parameter Type

Meaning: Indicates the RRN information parameter type to be queried. If this parameter is set to BASICINFO, basic statistic information about the RRN is to be queried. If this parameter is set to KEYUPDINFO, the OP/KI update records of the RRN are to be queried. If this parameter is set to MACTABLEQUERY, a maximum of 40 valid MAC entries in the MAC forwarding table on the RRN are to be queried. If this parameter is set to RRNINFOPARMSPEC, user-defined information about the RRN is to be queried. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BASICINFO(BASICINFO), KEYUPDINFO(KEYUPDINFO), MACTABLEQUERY(MACTABLEQUERY), RRNINFOPARMSPEC(RRNINFOPARMSPEC)

Unit: None

Actual Value Range: BASICINFO, KEYUPDINFO, MACTABLEQUERY, RRNINFOPARMSPEC

MML Default Value: BASICINFO(BASICINFO)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RrnInfoParam RRN Information Parameter

Meaning: Indicates RRN information. This parameter provides the following fields: BasicInfo, KeyUpdInfo, MacTableQuery, and MacTableQuery-XXXX-XXXX-XXXX-Num. BasicInfo indicates that the basic information about the RRN is to be queried. KeyUpdInfo indicates that the OP/KI update records of the RRN are to be queried, MacTableQuery indicates that a maximum of 40 valid MAC entries from the start in the MAC forwarding table on the RRN are to be queried. MacTableQuery-XXXX-XXXX-XXXX-Num indicates that a maximum of N (specified by Num) valid MAC entries from the MAC address "XXXX-XXXX-XXXX" in the MAC forwarding table on the RRN are to be queried. This parameter takes effect only if the RrnInfoParmType parameter in the DSP EURRNINFO command is set to RRNINFOPARMSPEC. In the EXE RRNCMD command, this parameter indicates the RRN command to be queried. For details about the command list, see the RRN release documentation. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~128 characters

Unit: None

Actual Value Range: 0~128 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

To query the information about an RRN with LocalSubscriberId set to 2 and RrnInfoParmType set to KEYUPDINFO, run the following command:

O&M    #806354955
%%DSP EURRNINFO: LocalSubscriberId=2, RrnInfoParmType=KEYUPDINFO;%%
RETCODE = 0  Operation succeeded
