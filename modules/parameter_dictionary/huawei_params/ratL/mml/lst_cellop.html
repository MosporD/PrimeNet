List Cell Operator (LST CELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters about a cell operator.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
TrackingAreaId Local tracking area ID

Meaning: Indicates the local tracking area identity of the cell, which uniquely identifies an operator's record of tracking area information within a cell. This parameter is used only in the eNodeB and is different from the tracking area identity configured in the tracking area list on the MME.

This parameter applies to LTE FDD, LTE TDD, and NB-IoT. According to NB-IoT specifications, the TAIs planned for NB-IoT must be different from the TAIs planned for LTE.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

Local tracking area ID

Indicates the local tracking area identity of the cell, which uniquely identifies an operator's record of tracking area information within a cell. This parameter is used only in the eNodeB and is different from the tracking area identity configured in the tracking area list on the MME.

This parameter applies to LTE FDD, LTE TDD, and NB-IoT. According to NB-IoT specifications, the TAIs planned for NB-IoT must be different from the TAIs planned for LTE.

Cell reserved for operator

Indicates whether the cell is reserved for an operator.

If this parameter is set to CELL_RESERVED_FOR_OP, the cell is reserved for the operator. UEs of AC11 or AC15 in their HPLMN or EHPLMN can consider this cell as a candidate cell for cell selection or reselection. UEs of AC11 or AC15 outside their HPLMN/EHPLMN and UEs of AC0 to AC9 and AC12 to AC14 consider this cell as a barred cell during cell selection or reselection.

If this parameter is set to CELL_NOT_RESERVED_FOR_OP, the cell is not reserved for the operator. All UEs can consider this cell as a candidate cell for cell selection or reselection.

If this parameter is set to CELL_DYNAMIC_RESERVED_FOR_OP, the cell is dynamically reserved for the operator based on the cell load. When the cell is overloaded, the cell is reserved for the operator. When the cell is lightly loaded, the cell is not reserved for the operator. The CELL_DYNAMIC_RESERVED_FOR_OP value is valid only when the AcBarAlgoSwitch parameter in the CellAlgoSwitch MO is set to ACBAR_SWITCH_DYNAMIC.

This parameter applies to LTE FDD, LTE TDD, and NB-IoT.

Operator uplink RB used ratio(%)

Indicates the percentage of resource blocks (RBs) occupied by the operator on the physical uplink shared channel (PUSCH) when RAN sharing is enabled on the eNodeB and the RanShareModeSwitch parameter of the CellAlgoSwitch MO is set to ON(On). If the data volume is sufficient, the percentage of RBs occupied by each operator will reach the preset value. Modifications on this parameter affect the percentages of RBs occupied by operators on the PUSCH. When the OpPrbGroupshareSwitch option is selected in RAN sharing mode, this parameter is used to calculate the percentage of RBs occupied by the operator resource group on the PUSCH. The percentage of RBs occupied by an operator resource group is the sum of percentages of RBs occupied by operators in the group. This parameter takes effect only in RAN sharing with common carrier mode or in hybrid RAN sharing mode with more than one CellOp MO being configured. This parameter applies only to LTE FDD and LTE TDD.

Operator downlink RB used ratio(%)

Indicates the percentage of resource blocks (RBs) occupied by the operator on the physical downlink shared channel (PDSCH) when RAN sharing is enabled on the eNodeB and the RanShareModeSwitch parameter of the CellAlgoSwitch MO is set to ON(On). If the data volume is sufficient, the percentage of RBs occupied by each operator will reach the preset value. Modifications on this parameter affect the percentage of RBs occupied by operators on the PDSCH. When the OpPrbGroupshareSwitch option is selected in RAN sharing mode, this parameter is used to calculate the percentage of RBs occupied by the operator resource group on the PDSCH. The percentage of RBs occupied by an operator resource group is the sum of percentages of RBs occupied by operators in the group. This parameter takes effect only in RAN sharing with common carrier mode or in hybrid RAN sharing mode with more than one CellOp MO being configured. This parameter applies only to LTE FDD and LTE TDD.

MME configure number

Indicates the number of cell-specific MMEs. This parameter also indicates whether dedicated-MME configuration is allowed for a cell.

If this parameter is set to 0, dedicated-MME configuration is not allowed for the cell and no dedicated MMEs can be configured for the cell.

If this parameter is set to a value in the range of 1 to 4, dedicated-MME configuration is allowed for the cell and the number of MME parameter groups that can be configured for the cell equals the value of this parameter. Each MME parameter group consists of an MME group identifier (MMEGI) and an MME code (MMEC)

First MME group identity

Indicates the MMEGI of the first MME configured for a cell. This parameter can be configured only when the MMECfgNum parameter is greater than or equal to 1.

When setting this parameter, ensure that the globally unique MME identifier (GUMMEI), consisting of the PLMN, MMEGI, and MMEC, must be unique.

The S1 link between an MME configured for a cell and the eNodeB supporting the cell must be available, and the GUMMEI of the MME must be specified in the ServedGummeis parameter of the S1Interface MO. Otherwise, the cell cannot broadcast the PLMN in system information.

If all MMEs configured for a cell cannot establish S1 links to the eNodeB supporting the cell, the cell cannot be established.

Operator Ue Number Ratio(%)

Indicates the percentage of activated UEs served by the operator in a cell when inter-frequency load balancing and RAN sharing are enabled. Modifications on this parameter affect the percentage of activated UEs served by operators. This parameter applies only to LTE FDD and LTE TDD.

Operator PTT UL RB Utilization High Thd(%)

Indicates the upper usage threshold of the uplink PRBs that an operator allocates to PTT services in a cell. Based on the parameter value, the eNodeB determines whether to admit PTT services in the uplink. If the uplink PRB usage of PTT services is greater than the parameter value, PTT services are not admitted. This parameter applies only to LTE FDD and LTE TDD.

Operator PTT UL RB Utilization Low Thd(%)

Indicates the lower usage threshold of the uplink PRBs that an operator allocates to PTT services in a cell. Based on the parameter value, the eNodeB determines whether to admit PTT services in the uplink. If the uplink PRB usage of PTT services is less than the parameter value, PTT services are admitted. This parameter applies only to LTE FDD and LTE TDD.

Operator PTT DL RB Utilization High Thd(%)

Indicates the upper usage threshold of the downlink PRBs that an operator allocates to PTT services in a cell. Based on the parameter value, the eNodeB determines whether to admit PTT services in the downlink. If the downlink PRB usage of PTT services is greater than the value of this parameter, PTT services are not admitted. This parameter applies only to LTE FDD and LTE TDD.

Operator PTT DL RB Utilization Low Thd(%)

Indicates the lower usage threshold of the downlink PRBs that an operator allocates to PTT services in a cell. Based on the parameter value, the eNodeB determines whether to admit PTT services in the downlink. If the downlink PRB usage of PTT services is less than the parameter value, PTT services are admitted. This parameter applies only to LTE FDD and LTE TDD.

Operator Non-GBR Resource Reservation Ratio(%)

Indicates the proportion of resources that an operator reserves for downlink non-GBR services to the total resources of the operator when RAN sharing is enabled on the eNodeB and the RanShareModeSwitch parameter of the CellAlgoSwitch MO is set to ON(On). If this parameter is set to 0 for all operators in a cell, this parameter does not take effect. The proportion of resources reserved for downlink non-GBR services is subject to the cell-level non-GBR reservation parameter. If this parameter is set to a non-zero value for at least one operator in the cell, the cell-level non-GBR reservation parameter does not take effect. In this case, this parameter specifies the proportion of resources reserved for downlink non-GBR services of the operator. This parameter applies only to LTE FDD and LTE TDD.

Operator PLMN Round Period(h)

Indicates the operator-specific interval for changing the PLMN at the top of the broadcast PLMN list in round robin mode.

Operator Resource Group Index

Indicates the index of the resource group to which the operator belongs. The default value is 255, which indicates an invalid value. The OpPrbGroupshareSwitch option takes effect only when the OpResourceGroupIndex parameter is set to a valid value.

RAT Frequency Priority Group ID

Indicates the eNodeB-level inter-frequency or inter-RAT frequency priority group ID for LTE UEs of an operator. This parameter applies only to LTE FDD and LTE TDD.

Uplink Rate Control Mode

Indicates the uplink voice rate control mode for the operator. This parameter is valid only if RAN sharing with common carriers mode or hybrid RAN sharing mode is used and there is more than one CellOp MO instance for the cell.

If this parameter is set to INVALID, this parameter does not take effect.

If this parameter is set to ULRATECTRL_OFF, voice rate control does not take effect. If RTP packets are encrypted, this parameter must be set to ULRATECTRL_OFF.

If this parameter is set to ULAMRC_ENB_CONTROL, the eNodeB adjusts the uplink AMR rate.

If this parameter is set to ULAMRC_SBC_CONTROL, the eNodeB instructs the session border controller (SBC) in the EPC to adjust the uplink AMR rate. The SBC must be a Huawei SBC that supports voice rate control.

If this parameter is set to ULEVSC_ENB_CONTROL, the eNodeB adjusts the uplink EVS rate.

If this parameter is set to ADAPTIVE_ENB_CONTROL, the eNodeB adaptively adjusts the uplink AMR/EVS rate.

This parameter applies only to LTE FDD and LTE TDD.

For a specific operator, this operator-level parameter and the cell-level parameter UlAmrcMode in the CellAlgoSwitch MO take effect in the following way:

1. If the cell-level parameter is set to ULRATECTRL_OFF, rate control does not take effect for the operator regardless of the operator-level parameter setting.

2. If the operator-level parameter is set to ULRATECTRL_OFF, rate control does not take effect for the operator regardless of the cell-level parameter setting.

3. If the operator-level parameter is set to INVALID, this parameter does not take effect. Rate control defined by the cell-level parameter takes effect for the operator.

4. If the cell-level parameter and the operator-level parameter are set to other values, rate control takes effect for the operator based on the intersection of the meanings of the two parameter values. There is no intersection between any two of the ULAMRC_ENB_CONTROL, ULEVSC_ENB_CONTROL, and ULAMRC_SBC_CONTROL values. The value ADAPTIVE_ENB_CONTROL includes ULAMRC_ENB_CONTROL and ULEVSC_ENB_CONTROL but does not intersect with ULAMRC_SBC_CONTROL.

RB Sharing Ratio with Other Operator(%)

Indicates the proportion of RBs that can be shared by the operator with other operators to the total number of RBs in the cell when the operators share cell RB resources. The value 255 indicates that there is no restriction on the proportion of RBs that can be shared by the operator with other operators. This parameter applies only to LTE FDD and LTE TDD.

Operator-Level MLB Thld Adj Value(%)

Indicates the adjustment value of the inter-frequency MLB threshold for operator-level PRB-usage-based MLB. If this parameter is set to a value in the range of -50 to -1, the value indicates a decrease in the original threshold. If this parameter is set to a value in the range of 1 to 50, the value indicates an increase in the original threshold. If this parameter is set to 0, the original threshold remains unchanged. Actual PRB usage threshold for the operator = PRB usage threshold for the cell x (1 + The value of this parameter). This parameter applies only to LTE FDD and LTE TDD.

NSA DC RAT Frequency Priority Group ID

Indicates the ID of a RAT-specific frequency priority group for NSA DC UEs served by a base-station-level operator. The parameter value 65535 indicates that this parameter has not been set. This parameter applies only to LTE FDD and LTE TDD.

Operator Max Available RB Ratio(%)

Indicates the proportion of the maximum number of RBs available for the operator to the total number of RBs available in the cell when operators share the cell RB resources. This parameter is valid only when the RbSharingRatioWithOtherOp parameter is set to a value other than 255 for an operator of the cell. This parameter applies only to LTE FDD and LTE TDD.
