Modify Parameter Configurations for VoLTE (MOD VOLTEALGOCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of parameters related to VoLTE.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VolteOptSwitch VoLTE Optimization Switch

Meaning: Indicates whether to enable VoLTE-related functions in the cell.

VOLTE_PUSCH_ACK_OPT_SW: Indicates whether to optimize signaling transmission over the PUSCH for VoLTE UEs. If this option is selected, the eNodeB triggers uplink scheduling for a VoLTE UE with a QCI-1 bearer when the eNodeB schedules the UE in the downlink. In this way, the UE can transmit HARQ feedback on the PUSCH. If this option is deselected, this function does not take effect. This option applies only to LTE FDD and LTE TDD.

VOICE_QUALITY_PLR_MEAS_OPT_SW: Indicates whether to optimize the measurement of packet loss rates based on voice quality evaluation. If this option is selected, measurement of packet loss rates based on voice quality evaluation considers only packets lost over the air interface, without taking delayed packets into account. If this option is deselected, measurement of packet loss rates based on voice quality evaluation takes both packets lost over the air interface and delayed packets into account. This option applies only to LTE FDD and LTE TDD.

VOICE_FRAME_RECOVERY_SW: Indicates whether to enable voice frame recovery. If this option is selected and the eNodeB detects packet loss, the eNodeB selects an appropriate voice packet based on the correlation between the lost packet and the voice packets prior to and following the lost packet and fills the selected packet in the position of the lost packet. If this option is deselected, the function does not take effect. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: VOLTE_PUSCH_ACK_OPT_SW(VOLTE_PUSCH_ACK_OPT_SW), VOICE_QUALITY_PLR_MEAS_OPT_SW(VOICE_QUALITY_PLR_MEAS_OPT_SW), VOICE_FRAME_RECOVERY_SW(VOICE_FRAME_RECOVERY_SW)

Unit: None

Actual Value Range: VOLTE_PUSCH_ACK_OPT_SW, VOICE_QUALITY_PLR_MEAS_OPT_SW, VOICE_FRAME_RECOVERY_SW

MML Default Value: None

Recommended Value: VOLTE_PUSCH_ACK_OPT_SW:On, VOICE_QUALITY_PLR_MEAS_OPT_SW:On, VOICE_FRAME_RECOVERY_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: VOLTE_PUSCH_ACK_OPT_SW: If this option is selected, UEs with QCI-1 bearers can transmit HARQ feedback on the PUSCH, which decreases the DTX probability and the downlink QCI-1 packet loss rate but increases the uplink PRB usage and uplink interference. If this option is deselected, radio network performance is not affected.

VOICE_QUALITY_PLR_MEAS_OPT_SW: If this option is selected, functions such as voice-quality-based DRX exit, SCell deactivation, and AMRC rate adjustment are less likely to take effect, and therefore the number of incorrect function triggering times decreases. If this option is deselected, network performance is not affected.

VOICE_FRAME_RECOVERY_SW: If this option is selected, the MOS of voice services increases. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
VoiceRbRsvRsrpThld Voice RB Reservation RSRP Thld

Meaning: Indicates the RSRP threshold for RB reservation to take effect for UEs running voice services. If this parameter is set to 0, RB reservation enhancement does not take effect for UEs running voice services and the locations of RBs selected for these UEs are not restricted. If this parameter is set to a value in the range of -140 to -43, RB selection for UEs running voice services varies as follows: (1) If the measured uplink RSRP of a UE is less than or equal to the value of this parameter, reserved RBs are selected for the scheduling of the UE. (2) If the measured uplink RSRP of a UE is greater than this threshold, non-reserved RBs are selected for the scheduling of the UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43,0

Unit: None

Actual Value Range: -140~-43,0

MML Default Value: None

Recommended Value: -120

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, network performance is not affected. If this parameter is set to a value in the range of -140 to -43, the impact varies as follows: (1) A smaller value results in fewer voice service UEs that use reserved RBs, more gains in cell edge coverage, and a smaller decrease in the uplink voice packet loss rate in the cell. (2) A larger value results in more voice service UEs that use reserved RBs, fewer gains in cell edge coverage, and a larger decrease in the uplink voice packet loss rate in the cell.

Applicable Mode: L-FDD, L-TDD

Example

To modify the VoLTE Configuration, local cell ID is 1:
MOD VOLTEALGOCONFIG: LocalCellId=1, VolteOptSwitch=VOLTE_PUSCH_ACK_OPT_SW-1&VOICE_QUALITY_PLR_MEAS_OPT_SW-1, VoiceRbRsvRsrpThld=0;
The result is shown as follows:

RETCODE = 0  Operation succeeded.
