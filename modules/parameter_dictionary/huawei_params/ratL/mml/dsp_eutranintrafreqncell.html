Display Intra-Frequency Neighboring Relation with E-UTRAN Cell (DSP EUTRANINTRAFREQNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters of the neighboring relations with intra-frequency E-UTRAN cell.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Actual Value Range: 0~255

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
Mcc Mobile country code

Meaning: Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

Unit: None

Output Description

Field Description

Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB.

Mobile country code

Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

Mobile network code

Indicates the mobile network code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

eNodeB ID

Indicates the eNodeB ID of the intra-frequency neighboring cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Cell ID

Indicates the local ID of the intra-frequency neighboring cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Physical cell ID

Indicates the physical cell identifier (PCI) of the neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.331.

Downlink EARFCN

Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) of the neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.104.

Downlink Frequency Offset

Indicates the frequency offset of the PRB downlink central frequency to the downlink frequency. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.

Neighbor Cell Classification Flag

Indicates the neighboring cell classification flag. The parameter values FORMAL, EXTENDED, and ALL represent different neighboring cell types.

Neighbor Cell Plmn Label

Indicates the PLMN list label of the neighboring cell. The parameter value BLACK(BLACK) indicates that the PLMN of the neighboring cell is blacklisted. The parameter value GREY(GREY) indicates that the PLMN of the neighboring cell is gray-listed. The parameter value WHITE(WHITE) indicates that the PLMN of the neighboring cell is white-listed. The parameter value ALL(ALL) indicates that the PLMN of the neighboring cell is not distinguished.

Dynamic CRE Value(dB)

Indicates the cell range expansion (CRE) value in the current adjustment period after eICIC adaptation is enabled. This parameter applies only to LTE FDD and LTE TDD.
