Remove External GERAN Cell (RMV GERANEXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more external GERAN cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the neighboring relations with the external cell are removed.

  • After this command is executed, an additional PLMN ID for the external GERAN cell is automatically removed.

  • If no parameters are specified, running this command deletes all external GERAN cell records in the eNodeB. A maximum of 640 external cell records can be deleted at a time by running this command.

  • If some of the parameters are specified, running this command deletes records that meet all the specified parameter requirements. A maximum of 640 external cell records can be deleted at a time by running this command.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the external cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a GeranExternalCell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code of the external cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in a GeranExternalCell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GeranCellId GERAN cell ID

Meaning: Indicates the cell ID of the external GERAN cell. It uniquely identifies a GERAN cell within the area specified by the location area identity (LAI). An LAI consists of the MCC, MNC, and LAC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Lac Location area code

Meaning: Indicates the LAC of the external GERAN cell. It uniquely identifies a location within a PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65533,65535

Unit: None

Actual Value Range: 1~65533,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the external GERAN cell with the parameters as follows: Mobile country code: "460", Mobile network code: "20", GERAN cell ID: 17, Location area code: 13, run the following command:
RMV GERANEXTERNALCELL: Mcc="460", Mnc="20", GeranCellId=17, Lac=13;
