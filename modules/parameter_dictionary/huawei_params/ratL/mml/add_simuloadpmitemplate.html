Add Simuload Pmi Template (ADD SIMULOADPMITEMPLATE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a simuload PMI template in simulated load configurations with transmission mode 4 or 9. A maximum of 16 PMI templates can be added for a cell.

Note

  • In multi-PMI-based interference simulation, the load simulation accuracy cannot be ensured if the cell bandwidth is 1.4 MHz, 3 MHz, or 5 MHz.

  • Multi-PMI-based interference simulation can be used only when the simulated load configuration reaches 100%.

  • In multi-PMI-based interference simulation, the load simulation accuracy cannot be ensured if the cell serves actual UEs.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If values of LocalCellId in SimuloadPmiTemplate MOs are the same, PmiType in these SimuloadPmiTemplate MOs must be the same.
  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, all values of CellSimuloadRank, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 cannot be the same simultaneously.
  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, values of CellSimuloadRank and CellSimuloadPmi cannot be the same simultaneously.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

CellSimuloadPmiCfgDuration Cell Simuload PMI Config Duration

Meaning: Indicates the duration of interference simulation using the PMI with the SimuLoadTransMode parameter set to TM4 or TM9. The total configured duration of interference simulation using the PMIs in all PMI templates configured for a cell is the PMI polling cycle. The configuration-dependent probability of scheduling a PMI is equal to the configured duration of interference simulation using this PMI divided by the PMI polling cycle. This parameter applies only to FDD.

GUI Value Range: 1~1000

Unit: ms

Actual Value Range: 1~1000

MML Default Value: 100

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

As this parameter is recommended only in test scenarios (rather than in live networks), it has no impact on network performance.

PMI values used for load simulation in a cell must be unique. This parameter applies only to LTE FDD and LTE TDD.

Example

To add simuload pmi template with the parameters as follows: Local cell ID: 0, Simuload Pmi Template ID: 0, PMI Type: Normal, Cell Simuload Pmi: 0, run the following command:
ADD SIMULOADPMITEMPLATE: LocalCellId=0, SimuloadPmiTemplateId=0, PmiType=Normal, CellSimuloadPmi=0;
