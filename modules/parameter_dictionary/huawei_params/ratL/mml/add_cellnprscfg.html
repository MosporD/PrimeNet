Add Cell NPRS Configuration (ADD CELLNPRSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add NPRS parameter settings for the Observed Time Difference Of Arrival (OTDOA) feature.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

NprsMutingConfiguration NPRS Muting Configuration

Meaning: Indicates NPRS muting configurations.

In Part A mode, each bit corresponds to 10 consecutive subframes. If the current bit is 1, NPRS is sent within the subframes. If the current bit is 0, NPRS is not sent.

In Part B mode, each bit indicates an NPRS period. If the bit is 1, NPRS is sent within the current NPRS period. If the bit is 0, NPRS is not sent.

For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 15

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 2_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 3.
  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 4_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 15.
  • When the NumberofNprsMutingBits parameter in the CellNprsCfg MO is set to 8_BITS, the value range of the NprsMutingConfiguration parameter is 0 to 255.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the parameter value indicates more bits being 1, more subframes in the NPRS are sent within an NPRS period, and shorter time is required for the UE to measure NPRS, reducing UE power consumption. In this case, the interference of NPRS in the cell is greater. A parameter value indicating fewer bits being 1 leads to the opposite effects.

Applicable Mode: L-NB-IOT
NprsSubframeBitmap10 NPRS Subframe Bitmap10

Meaning: Indicates a 10-bit bitmap used to specify the set of subframes for NPRS transmission in the NB-IoT cell when NPRS subframe configuration Part A is used. The value of this parameter needs to be converted into a binary number, and the least significant 10 bits of the number are used as the bitmap, with each bit representing a subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, only this parameter is used to specify the NPRS subframe configuration for the NB-IoT cell. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the first 10 subframes, and it is used together with the NprsSubframeBitmap30 parameter to specify the NPRS subframe configuration for the NB-IoT cell.

The value 1 in the bitmap indicates that NPRSs are transmitted in the corresponding subframe and the subframe is invalid for downlink transmission. The value 0 in the bitmap indicates that NPRSs are not transmitted in the corresponding subframe.

For details, see 3GPP TS 36.455. This parameter applies only to NB-IoT.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller number of subframes in which NPRSs are sent and therefore a smaller impact on downlink cell performance. However, the measurement time for UE positioning is longer, causing the performance of OTDOA-based positioning to deteriorate. A larger value of this parameter leads to a larger number of subframes in which NPRSs are sent and therefore a greater impact on downlink cell performance. However, the measurement time for UE positioning is shorter, improving the performance of OTDOA-based positioning.

Applicable Mode: L-NB-IOT
NprsSubframeBitmap30 NPRS Subframe Bitmap30

Meaning: Indicates a 30-bit bitmap used to specify the set of subframes for NPRS transmission in the NB-IoT cell when NPRS subframe configuration Part A is used. The value of this parameter needs to be converted into a binary number, and the least significant 30 bits of the number are used as the bitmap, with each bit representing a subframe.

If the NB-IoT downlink subframe pattern is a configuration of 10 subframes, this parameter is invalid. If the NB-IoT downlink subframe pattern is a configuration of 40 subframes, this parameter indicates the last 30 subframes, and it is used together with the NprsSubframeBitmap10 parameter to specify the NPRS subframe configuration for the NB-IoT cell.

The value 1 in the bitmap indicates that NPRSs are transmitted in the corresponding subframe and the subframe is invalid for downlink transmission. The value 0 in the bitmap indicates that NPRSs are not transmitted in the corresponding subframe.

For details, see 3GPP TS 36.455. This parameter applies only to NB-IoT.

Example

Use this command to add a cell Cell NPRS configuration, with LocalCellId=130, NPRS Parameter Group ID=0, NPRS Subframe Config Mode  =  PART_A : 
ADD CELLNPRSCFG: LocalCellId=130, NprsParaGroupId=0, NprsSubframeConfigMode=PART_A;
