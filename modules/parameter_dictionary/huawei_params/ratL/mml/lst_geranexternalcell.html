List External GERAN Cell (LST GERANEXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the external GERAN cell.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the external cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

MML Default Value: None

Recommended Value: None

Output Description

Field Description

Mobile country code

Indicates the mobile country code of the external cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code of the external cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

GERAN cell ID

Indicates the cell ID of the external GERAN cell. It uniquely identifies a GERAN cell within the area specified by the location area identity (LAI). An LAI consists of the MCC, MNC, and LAC. This parameter applies only to LTE FDD and LTE TDD.

Location area code

Indicates the LAC of the external GERAN cell. It uniquely identifies a location within a PLMN. This parameter applies only to LTE FDD and LTE TDD.

Routing area code configure indicator

Indicates whether to set the routing area code (RAC). This parameter must be set to CFG(Configure) if the eNodeB performs routing and addressing procedures, such as handover and RIM, to target neighboring GERAN cells. This parameter applies only to LTE FDD and LTE TDD.

Routing area code

Indicates the routing area code. This parameter applies only to LTE FDD and LTE TDD.

Band indicator

Indicates the GERAN band indicator. If the GERAN ARFCN is a value in the range of 512 to 810, the value of this parameter is used to indicate whether the GERAN ARFCN is in the 1800 MHz band or the 1900 MHz band. If the GERAN ARFCN is not in either band, this parameter does not take effect and can be set to either value. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GERAN ARFCN

Indicates the GERAN BCCH ARFCN. For details, see 3GPP TS 45.005. This parameter applies only to LTE FDD and LTE TDD.

Network color code

Indicates the network color code (NCC) of GERAN. It is operator-specific and identifies a network within the whole country.

The base transceiver station identity code (BSIC) consists of the NCC and the base station color code (BCC). For details, see 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.

Base station color code

Indicates the base station color code (BCC) of an external GERAN cell. This parameter is used to discriminate external GERAN cells working at the same frequency. The base transceiver station identity code (BSIC) consists of the BCC and the network color code (NCC). For details, see 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.

DTM indication

Indicates whether the cell supports the dual transmission mode. If the cell supports the dual transmission mode, both CS and PS services can be handed over to the cell at the same time. Otherwise, only the CS service or the PS service can be handed over to the cell. This parameter applies only to LTE FDD and LTE TDD.

Cell name

Indicates the name of the external GERAN cell. This parameter applies only to LTE FDD and LTE TDD.

CS and PS handover indication

Indicates whether the external GERAN cell supports single radio voice call continuity (SRVCC) for concurrent CS and PS services. If this parameter is set to BOOLEAN_FALSE, the external GERAN cell does not support SRVCC for concurrent CS and PS services. This parameter applies only to LTE FDD and LTE TDD.

Ultra-Flash CSFB Capability Indication

Indicates whether an external GERAN cell supports ultra-flash CSFB to GERAN. If this parameter is set to BOOLEAN_TRUE, the external GERAN cell supports ultra-flash CSFB to GERAN. If this parameter is set to BOOLEAN_FALSE, the external GERAN cell does not support ultra-flash CSFB to GERAN. This parameter applies only to LTE FDD and LTE TDD.

Roaming Area Handover Indicator

Indicates whether the neighbor cell can be selected for handovers during roaming. This parameter is set to NO(No) by default.

If this parameter is set to YES(Yes), this neighboring cell can be selected for handovers during roaming. If this parameter is set to NO(No), this neighboring cell cannot be selected for handovers during roaming.

If the PLMN of the neighboring cell is included in the SPID-based handover-allowable HPLMN list or this parameter is set to YES(Yes), this neighboring cell can be selected for handovers.

In the boundaries of roaming areas and non-roaming areas, you are advised to set this parameter to YES(Yes) to ensure that neighboring cells in roaming areas can be selected for handovers. This parameter applies only to LTE FDD and LTE TDD.

ANR flag

Indicates whether an external cell is automatically detected by ANR. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. The policy specified by this parameter also applies to the GeranExternalCellPlmn MOs under this MO. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
