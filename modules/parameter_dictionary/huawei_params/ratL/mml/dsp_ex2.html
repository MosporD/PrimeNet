Display eX2 interface information (DSP EX2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information of an eX2 object.

Note

None.

Parameters

ID Name Description
eX2Id eX2 Object ID

Meaning: Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5,10

Unit: None

Actual Value Range: 0~5,10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the information about the eX2 object, run the following command: 
DSP EX2:;
The result is shown as follows: 
+++    HUAWEI        2014-04-16 15:18:20
O&M    #806358170
%%DSP EX2:;%%
RETCODE = 0  Operation succeeded.

Display eX2 interface information
---------------------------------
                eX2 Object ID  =  0
             eX2 Interface ID  =  7
          eX2 Interface State  =  Normal
   eX2 Interface CP Bearer ID  =  70000
eX2 Interface CP Bearer State  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

eX2 Object ID

Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.

eX2 Interface ID

Indicates the eX2 interface ID. This parameter applies only to LTE FDD and LTE TDD.

eX2 Interface State

Indicates the status of the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.

eX2 Interface CP Bearer ID

Indicates the control port (CP) bearer ID of the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.

eX2 Interface CP Bearer State

Indicates the status of the CP bearer for the eX2 interface. This parameter applies only to LTE FDD and LTE TDD.
