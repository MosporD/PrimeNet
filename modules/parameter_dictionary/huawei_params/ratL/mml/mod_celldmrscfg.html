Modify DMRS Configuration in an NB-IoT Cell (MOD CELLDMRSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell, which are used to generate the DMRS sequence.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies to LTE FDD, LTE TDD, and NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SixToneBaseSeq DMRS Six Tone Base Sequence

Meaning: Indicates the DMRS six tone base sequence of a cell. This parameter and the SixToneCyclicShift parameter are used together to generate the DMRS sequence for the NPUSCH when six tone transmission is used. This parameter applies only to NB-IoT.

GUI Value Range: 0~13

Unit: None

Actual Value Range: 0~13

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
TwelveToneBaseSeq DMRS Twelve Tone Base Sequence

Meaning: Indicates the DMRS twelve tone base sequence of a cell, which is used to generate the DMRS sequence for the NPUSCH when twelve tone transmission is used. This parameter applies only to NB-IoT.

GUI Value Range: 0~29

Unit: None

Actual Value Range: 0~29

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
ThreeToneBaseSeq DMRS Three Tone Base Sequence

Meaning: Indicates the DMRS three tone base sequence of a cell. This parameter and the ThreeToneCyclicShift parameter are used together to generate the DMRS sequence for the NPUSCH when three tone transmission is used. This parameter applies only to NB-IoT.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
SixToneCyclicShift DMRS Six Tone Cyclic Shift

Meaning: Indicates the six tone cyclic shift for the uplink DMRS. The DMRS sequence is generated by using the base sequence and cyclic shift. With cyclic shift used, the number of DMRS sequences is increased to 56 (14 multiplied by 4) from 14 when six tone transmission is used. This decreases the possibility of interference among intra-frequency neighboring cells. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of interference among intra-frequency neighboring cells and thereby better network performance.

Applicable Mode: L-NB-IOT
ThreeToneCyclicShift DMRS Three Tone Cyclic Shift

Meaning: Indicates the three tone cyclic shift for the uplink DMRS. The DMRS sequence is generated by using the base sequence and cyclic shift. With cyclic shift used, the number of DMRS sequences is increased to 36 (3 multiplied by 12) from 12 when three tone transmission is used. This decreases the possibility of interference among intra-frequency neighboring cells. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: 0~2

Unit: None

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of interference among intra-frequency neighboring cells and thereby better network performance.

Applicable Mode: L-NB-IOT

Example

To set uplink DMRS(demodulation reference signal) configurations for an NB-IoT cell with the parameters as follows: Local cell ID: 0, DMRS Six Tone Base Sequence: 0, run the following command:
MOD CELLDMRSCFG: LocalCellId=0, SixToneBaseSeq=0;
