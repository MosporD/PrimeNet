Display SC Application Info (DSP SCAPPINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information about the applications (video services) that service classification supports. The information includes operator-defined and system default application information. The eNodeB supports query of a maximum of 350 pieces of information. The domain name is not case sensitive. Characters in lower case take effect, and the query result shows domain names in lower case.

Note

None.

Parameters

None.

Example

To display the application(video) information of Service Classification supported, run the following command:
DSP SCAPPINFO:;
and then return the following result:

Output Description

Field Description

App Index

Indicates the application index. In the command output of DSP SCAPPINFO for querying applications supported by SC, each piece of displayed application DNS information has an index. This parameter applies only to LTE FDD and LTE TDD.

Application Identification Type

Indicates the application identification method. If the AppIdentType parameter is set to DNS, the AppDns parameter must be set. If the AppIdentType parameter is set to IPv4, the AppIpv4 parameter must be set. If the AppIdentType parameter is set to IPv6, the AppIpv6 parameter must be set. You are advised to set the IP address for an application when the application is not configured with a domain name. You must not set both an IP address and a domain name for an application at the same time. If the AppIdentType parameter is set to TCPPORT, the TCP port number does not need to be configured and port 80, 8080, or 443 takes effect by default. The value 100 of the AppDnsId parameter is reserved for TCP link setup acceleration. That is, when the AppDnsId parameter is set to 100, the AppIdentType parameter can be set to only TCPPORT. If the AppIdentType parameter is set to WTCP, the WTCP service identification does not need to be configured but the AppDnsId parameter must be set to 101. The value 101 of the AppDnsId parameter is reserved for WTCP. That is, when the AppDnsId parameter is set to 101, the AppIdentType parameter can be set to only WTCP. This parameter applies only to LTE FDD and LTE TDD.

Application DNS Info

Indicates the information about the domain name of the to-be-identified application, and it can contain only the following characters: lower-case letters (a to z), digits (0 to 9), wildcard character (*), hyphens (-), full stops (.), and at-signs (@). This parameter applies only to LTE FDD and LTE TDD.

Application IPv4

Indicates the IPv4 address of an application, which is used for application (website) identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv4. A single IPv4 address specified by the AppIpv4 parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single IPv4 address be repeatedly configured for different application domain names. This parameter applies only to LTE FDD and LTE TDD.

Application IPv6

Indicates the IPv6 address of an application, which is used for application (website) identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv6. A single IPv6 address specified by the AppIpv6 parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single IPv6 address be repeatedly configured for different application domain names. This parameter applies only to LTE FDD and LTE TDD.

App Desc

Indicates the description that defines an application. This parameter applies only to LTE FDD and LTE TDD.

Configuration Type

Indicates the configuration type of the to-be-identified DNS. This parameter applies only to LTE FDD and LTE TDD.
