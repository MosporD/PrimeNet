Display Cell Baseband Resource Fragment Pre-adjustment Information (DSP CELLFRAGPREADJUST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to:

(1) Query the cells for which baseband resources need to be adjusted (which will cause cell reestablishment) for the establishment of a target cell if the target cell is specified. (The target cell establishment previously failed due to baseband resource fragmentation.)

(2) Query the cells for which baseband resources need to be adjusted (which will cause cell reestablishment) to eliminate resource fragments on the eNodeB if no target cell is specified.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If a target cell is specified, the specified cell must be an 8T8R FDD or Static Shared Beam Mode for which the MultiRruCellFlag parameter is set to BOOLEAN_FALSE and that has failed to be established, or the specified cell must be a cell whose baseband equipment allows hybrid configuration of massive MIMO and common cells and that has failed to be established.

  • Run this command when the environment configuration and hardware resources are stable. If the environment configuration or hardware resources are changed after this command is executed, run this command again.

  • Resource pre-adjustment information is stored for at most 10 minutes. Run the STR CELLFRAGPREADJUST command within 10 minutes after the information is displayed.

Output Description

Field Description

eNodeB ID

Indicates the ID of the eNodeB.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Sector Equipment ID

Indicates the ID of the sector equipment that serves the cell. It uniquely identifies a set of sector equipment within an eNodeB.

Sector Equipment Group ID

Indicates the ID of the sector equipment group that serves the cell. It uniquely identifies a sector equipment group within a cell.

Source Baseband Processing Unit

Indicates the cabinet, subrack, and slot information about the source BBP of cell baseband resource adjustment.

Destination Baseband Processing Unit

Indicates the cabinet, subrack, and slot information about the target BBP of cell baseband resource adjustment.
