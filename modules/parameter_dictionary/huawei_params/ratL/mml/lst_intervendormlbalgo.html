List Inter-vendor MLB Algorithm Configuration (LST INTERVENDORMLBALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameter configuration of inter-vendor MLB algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters configuration of inter-vendor MLB Algorithm:
LST INTERVENDORMLBALGO:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

DL CCE Usage Admission Threshold(%)

Indicates the downlink CCE usage threshold for UE admission in inter-vendor MLB. If the downlink CCE usage of a local cell is greater than or equal to this threshold, the cell cannot be used as a target cell for inter-vendor MLB. If the downlink CCE usage of the cell is lower than this threshold, the eNodeB checks the uplink CCE usage, the proportion of RRC_CONNECTED UEs, and uplink and downlink PRB usages to determine whether the cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

DL CCE Usage Offset(%)

Indicates the offset to the downlink CCE usage. When the duration in which the downlink CCE usage is continuously greater than or equal to the sum of the values of this parameter and the DlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the downlink CCE usage. When the duration in which the downlink CCE usage is continuously less than the value of the DlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the downlink CCE usage. The sum of the values of this parameter and the DlCceUsageAdmissionThld parameter cannot exceed 100%. This parameter applies only to LTE FDD and LTE TDD.

DL PRB Usage Admission Threshold(%)

Indicates the downlink PRB usage threshold for UE admission in inter-vendor MLB. If the downlink PRB usage of a local cell is greater than or equal to this threshold, the cell cannot be used as a target cell for inter-vendor MLB. If the downlink PRB usage of the cell is lower than this threshold, the eNodeB checks the uplink PRB usage, the proportion of RRC_CONNECTED UEs, and uplink and downlink CCE usages to determine whether the cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

PRB Usage Offset(%)

Indicates the offset to the PRB usage. When the duration in which the downlink PRB usage is continuously greater than or equal to the sum of the values of this parameter and the DlPrbUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the downlink PRB usage. When the duration in which the downlink PRB usage is continuously less than the value of the DlPrbUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the downlink PRB usage. The sum of the values of this parameter and the DlPrbUsageAdmissionThld parameter cannot exceed 100%. When the duration in which the uplink PRB usage is continuously greater than or equal to the sum of the values of this parameter and the UlPrbUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the uplink PRB usage. When the duration in which the uplink PRB usage is continuously less than the value of the UlPrbUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the uplink PRB usage. The sum of the values of this parameter and the UlPrbUsageAdmissionThld parameter cannot exceed 100%. This parameter applies only to LTE FDD and LTE TDD.

RRC Connected UE Number Rate Admission Thld(%)

Indicates the RRC_CONNECTED UE proportion threshold for UE admission in inter-vendor MLB. If the proportion of RRC_CONNECTED UEs in a neighboring cell is greater than or equal to the threshold set for the local cell, this neighboring cell cannot be used as a target cell for inter-vendor MLB. If the proportion of RRC_CONNECTED UEs in a neighboring cell is lower than this threshold, the eNodeB checks the uplink and downlink PRB usages and uplink and downlink CCE usages to determine whether this neighboring cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

RRC Connected UE Number Rate Offset(%)

Indicates the offset to the proportion of RRC_CONNECTED UEs. When the duration in which the proportion of RRC_CONNECTED UEs is continuously greater than or equal to the sum of the values of this parameter and the RrcConnUeNumRateAdmThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the proportion of RRC_CONNECTED UEs. When the duration in which the proportion of RRC_CONNECTED UEs is less than the value of the RrcConnUeNumRateAdmThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the proportion of RRC_CONNECTED UEs. The sum of the values of this parameter and the RrcConnUeNumRateAdmThld parameter cannot exceed 100%. This parameter applies only to LTE FDD and LTE TDD.

RRC Connected UE Number Rate Triggering Thld(%)

Indicates the RRC_CONNECTED UE proportion threshold for starting inter-vendor MLB. When the proportion of RRC_CONNECTED UEs in the serving cell is less than this threshold, inter-vendor MLB cannot be started. When the proportion of RRC_CONNECTED UEs in the serving cell is greater than this threshold, inter-vendor MLB can be started. This parameter applies only to LTE FDD and LTE TDD.

UL CCE Usage Admission Threshold(%)

Indicates the uplink CCE usage threshold for UE admission in inter-vendor MLB. If the uplink CCE usage of a local cell is greater than or equal to this threshold, the cell cannot be used as a target cell for inter-vendor MLB. If the uplink CCE usage of the cell is lower than this threshold, the eNodeB checks the downlink CCE usage, the proportion of RRC_CONNECTED UEs, and uplink and downlink PRB usages to determine whether the cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

UL CCE Usage Offset(%)

Indicates the offset to the uplink CCE usage. When the duration in which the uplink CCE usage is continuously greater than or equal to the sum of the values of this parameter and the UlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB can initiate inter-vendor MLB based on the uplink CCE usage. When the duration in which the uplink CCE usage is continuously less than the value of the UlCceUsageAdmissionThld parameter reaches the value of the MlbTrigJudgePeriod parameter in the CellMLB MO, the eNodeB stops inter-vendor MLB based on the uplink CCE usage. The sum of the values of this parameter and the UlCceUsageAdmissionThld parameter cannot exceed 100%. This parameter applies only to LTE FDD and LTE TDD.

UL PRB Usage Admission Threshold(%)

Indicates the uplink PRB usage threshold for UE admission in inter-vendor MLB. If the uplink PRB usage of a local cell is greater than or equal to this threshold, the cell cannot be used as a target cell for inter-vendor MLB. If the uplink PRB usage of the cell is lower than this threshold, the eNodeB checks the downlink PRB usage, the proportion of RRC_CONNECTED UEs, and uplink and downlink CCE usages to determine whether the cell can be used as a target cell for inter-vendor MLB. This parameter applies only to LTE FDD and LTE TDD.

MLB Enh Param Adjustment Range(dB)

Indicates the maximum adjustment range of inter- and intra-frequency CIOs and the reselection Qoffset parameter after enhanced coverage-based MLB is triggered. This parameter applies only to LTE FDD and LTE TDD.

MLB Enh Param Rollback Evaluation Period(min)

Indicates the evaluation period of a parameter rollback for enhanced coverage-based MLB. From the moment the process for adjusting CIOs and the reselection Qoffset parameter is terminated, the eNodeB checks whether loads (the proportion of RRC_CONNECTED UEs, PDSCH PRB usage, PUSCH PRB usage, and uplink and downlink PDCCH CCE usages) are less than the rollback thresholds (the corresponding load admission threshold subtracted by the load offset) throughout this evaluation period. If the loads are less than the rollback thresholds, the eNodeB starts the rollback process and rolls back CIOs and the reselection Qoffset parameter step by step for target cells in each implementation period (specified by the InterFreqLoadEvalPrd parameter in the CellMLB MO). This parameter applies only to LTE FDD and LTE TDD.
