Modify BBP Assist Group (MOD BBPASSISTGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify BBP assistance group configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
BbpAssistGrpId BBP Assist Group Id

Meaning: Indicates the ID of an LTE BBP assistance group. It uniquely identifies an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

AssistStartTime Assist Start Time

Meaning: Indicates the assistance start time of a user-created LTE BBP assistance group. When the time specified by this parameter arrives, the eNodeB transfers a cell from the master BBP in the assistance group to the assistant BBP to assist the master BBP.

When the start time arrives, a cell on the master BBP will be deactivated and reactivated. You are advised to set this parameter to a time when there are only a few UEs on the network. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 02:00:00

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellLoadStatPeriod Cell Load Stat Period

Meaning: Indicates the period of collecting load statistics of the cells established on the master BBP in an LTE BBP assistance group. When the specified assistance start time arrives and load statistics of the cells established on the master BBP have been collected for at least one period, the eNodeB selects one cell on the master BBP based on the load statistics and related algorithm and transfers the selected cell to the assistant BBP. This parameter applies only to LTE FDD.

GUI Value Range: 24~2160

Unit: hour

Actual Value Range: 24~2160

MML Default Value: None

Parameter Relationship: None

Applicable Mode: L-FDD

Example

To modify an LTE baseband assist group, BbpAssistGrpId=0, MasterCabinetNo=0, MasterSubRackNo=0, MasterSlotNo=3, AssistCabinetNo=0, AssistSubRackNo=0, AssistSlotNo=1, run the following command:
MOD BBPASSISTGROUP: BbpAssistGrpId=0, MasterCabinetNo=0, MasterSubRackNo=0, MasterSlotNo=3, AssistCabinetNo=0, AssistSubRackNo=0, AssistSlotNo=1;
