List SPID-specific HPLMN List (LST SPIDHPLMNLIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of an HPLMN to which SPID-specific UEs are allowed to be handed over.

Note

None.

Parameters

ID Name Description
StartSpid Start SPID

Meaning: Indicates the start value of the SPID segment. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • In the SpidHPlmnList MO, the EndSpid parameter value must be greater than or equal to the StartSpid parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EndSpid End SPID

Meaning: Indicates the end value of the SPID segment. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • In the SpidHPlmnList MO, the EndSpid parameter value must be greater than or equal to the StartSpid parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the mobile country code (MCC) of the HPLMN to which SPID-specific UEs are allowed to be handed over. A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in each SpidHPlmnList MO consists of digits only.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the mobile network code (MNC) of the HPLMN to which SPID-specific UEs are allowed to be handed over.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in each SpidHPlmnList MO consists of digits only.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configuration of the HPLMN to which SPID-specific UEs are allowed to be handed over, run the following command:
LST SPIDHPLMNLIST:;
