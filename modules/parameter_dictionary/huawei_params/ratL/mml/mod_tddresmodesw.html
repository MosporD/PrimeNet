MOD TDDRESMODESW (MOD TDDRESMODESW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to specify the TDD cell resource mode.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The activated cell automatically resets if the Baseband Equipment Exclusive Switch parameter is modified.

Parameters

ID Name Description
ClkResExcludeSwitch Clock-Unavailable Cell Activation Switch

Meaning: Indicates whether to forcibly activate an LTE TDD cell. If this parameter is set to ON(On), an LTE TDD cell can be activated even when no clock resource is available. If this parameter is set to OFF(Off), an LTE TDD cell cannot be activated when no clock resource is available. This parameter cannot be set to ON(On) when inter-BBU services are ongoing. Otherwise, the services will be affected. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The parameter values have different impacts when the clock is faulty or no clock source is used. If this parameter is set to ON, interference in neighboring cells occurs, which decreases the handover success rate. If this parameter is set to OFF, no cell can be activated.

Applicable Mode: L-TDD
BbResExclusiveSwitch Baseband Equipment Exclusive Switch

Meaning: Indicates whether cells can be set up a piece of baseband equipment to which these cells have not been bound but other cells have been bound. If this parameter is set to OFF and cells have been bound to a piece of baseband equipment, both these cells and cells that have not been bound to this piece of baseband equipment can be set up on this piece of baseband equipment. If this parameter is set to ON and cells have been bound to a piece of baseband equipment, cells that have not been bound to this piece of baseband equipment cannot be set up on this piece of baseband equipment. If this parameter is set to ON_WITH_BIND and cells have been bound to a piece of baseband equipment, then: (a) cells that have been bound to this baseband equipment can be set up on other baseband equipment to which other cells have been bound, on condition that this baseband equipment is faulty, and all cells not bound to this baseband equipment have been activated; (b) cells that have not been bound to this baseband equipment cannot be set up on this baseband equipment. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On), ON_WITH_BIND

Unit: None

Actual Value Range: OFF, ON, ON_WITH_BIND

MML Default Value: None

Recommended Value: You are advised to set this parameter to ON in either of the following scenarios:

Only some cells served by the eNodeB are bound to baseband processing units.

The UBBPd is installed in the eNodeB, and cell combination must be enabled.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NoClkCellActSwExpiryTime No Clock Cell Activate Sw Expiry Time

Meaning: Indicates the time after which the no-clock cell activation switch does not take effect for LTE TDD cells. If the system time is later than the parameter value, the no-clock cell activation switch becomes invalid. This parameter is precise to minutes, not seconds. The time is the local time of the NE (including the DST). If no value is set for this parameter, this parameter is automatically set to the system time, indicating that the no-clock cell activation switch does not take effect. This parameter applies only to LTE TDD.

GUI Value Range: 2000-01-01T00:00:00+00:00~2033-12-31T23:59:59+00:00

Unit: None

Actual Value Range: 2000-01-01T00:00:00+00:00~2033-12-31T23:59:59+00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • If the ClkResExcludeSwitch parameter in the TddResModeSwitch MO is set to ON, this parameter must be set.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If a clock is unavailable or no clock source is in use, the no-clock cell activation switch becomes invalid after the time specified by this parameter, and all LTE TDD cells served by the local eNodeB are deactivated.

Applicable Mode: L-TDD

Example

+++    HUAWEI        2013-11-26 17:23:37
O&M    #806355062
%%MOD TDDRESMODESW: ClkResExcludeSwitch=ON, BbResExclusiveSwitch=ON;%%
RETCODE = 0  Operation succeeded.


---    END
