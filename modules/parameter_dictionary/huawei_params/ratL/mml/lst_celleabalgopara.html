List Configuration of Cell EAB Algorithm Parameter (LST CELLEABALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters related to cell EAB algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of extended access barring of a cell:
LST CELLEABALGOPARA:;

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station.

EAB Control Trigger Threshold(%)

Indicates the threshold for triggering extended access barring (EAB). The threshold is denoted by a percentage of cell congestion duration. If the percentage of time when the cell is in a congestion state is greater than or equal to the value of this parameter within a statistics collection period (specified by the EABStatPeriod parameter), the conditions for triggering EAB are met.

EAB Control Statistic Periods(s)

Indicates the period for measuring the percentage of cell congestion duration for extended access barring (EAB). An eNodeB periodically determines the cell status based on the setting of this parameter.

EAB Category

Indicates the category of UEs to which EAB information is applied. If this parameter is set to CATEGORY_A, EAB information is applied to all EAB-applicable UEs. If this parameter to CATEGORY_B, EAB information is applied to EAB-applicable UEs that are not in the HPLMN and EHPLMN. If this parameter is set to CATEGORY_C, EAB information is applied to EAB-applicable UEs that are not in the HPLMN, EHPLMN, and preferred PLMN.

EAB Control Cancel Threshold(%)

Indicates the threshold for canceling extended access barring (EAB). The threshold is denoted by a percentage of cell congestion duration. If the percentage of time when the cell is in a congestion state is less than or equal to the value of this parameter within a statistics collection period (specified by the EABStatPeriod parameter), the conditions for canceling EAB are met.

EAB Cancel Condition Satisfied Period

Indicates the number of consecutive periods in which the conditions for canceling extended access barring (EAB) are met. EAB can be canceled only when the number of consecutive periods in which the conditions for canceling EAB are met reaches the value of this parameter.

NB-IoT Access Barring For Exception Data

Indicates the access barring status of abnormal data. This parameter specifies whether NB-IoT UEs can initiate access with the cause value being mo-ExceptionData. When this parameter is set to BOOLEAN_TRUE, NB-IoT UEs are not allowed to initiate access with the cause value being mo-ExceptionData. When this parameter is set to BOOLEAN_FALSE, NB-IoT UEs can initiate access with the cause value being mo-ExceptionData. This parameter applies only to NB-IoT.

NB-IoT Access Barring For AC11-15

Indicates the access barring status of UEs with access classes 11 to 15. This parameter specifies whether NB-IoT UEs with access classes 11 to 15 can initiate access.

AC11BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 11 in idle mode is barred. This option applies only to NB-IoT.

AC12BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 12 in idle mode is barred. This option applies only to NB-IoT.

AC13BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 13 in idle mode is barred. This option applies only to NB-IoT.

AC14BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 14 in idle mode is barred. This option applies only to NB-IoT.

AC15BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 15 in idle mode is barred. This option applies only to NB-IoT.

Access Class Count for Manual Access Barring

Indicates the number of barred access classes for AC0-AC9 UEs indicated in SIB14. When this parameter is set to the invalid value 255, the number of barred access classes in SIB14 is dynamically controlled by the access barring algorithm.
