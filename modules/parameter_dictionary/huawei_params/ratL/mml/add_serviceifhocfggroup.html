Add Configuration group of Service InterFreq Handover (ADD SERVICEIFHOCFGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a service-based inter-frequency handover policy group.

Note

If other DL EARFCNs are included in the information about the neighboring EUTRAN frequency and correspond to the same frequency as that of the service-based inter-frequency handover policy group, those DL EARFCNs must be added to the same policy group too. Other configuration parameters must be the same except for the DL EARFCN.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServiceIfHoCfgGroupId Service-based inter-Freq handover policy group ID

Meaning: Indicates the ID of the service-based or service-request-based inter-frequency handover policy group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterFreqHoState Inter-Freq handover state

Meaning: Indicates whether to allow service-based or service-request-based inter-frequency handovers of the policy group to a specified frequency. If this parameter is set to NO_HO, service-based or service-request-based inter-frequency handovers of services with a specific QCI to a specified frequency are not allowed. If this parameter is set to PERMIT_HO, such handovers are allowed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO_HO, PERMIT_HO

Unit: None

Actual Value Range: NO_HO, PERMIT_HO

MML Default Value: NO_HO

Recommended Value: NO_HO

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The same parameter settings are recommended for QCI 5 and relevant QCIs. The reason is that a bearer with a QCI of 5 carries IMS signaling and IMS signaling is usually associated with other services.

Handovers are not recommended for the QCI of a default bearer. If the QCI of the default bearer is configured to allow handovers, the UE is handed over immediately after accessing the network.

Applicable Mode: L-FDD, L-TDD
A4RptWaitingTimer Service-based InterFreq A4 Report Waiting Timer

Meaning: Indicates the length of the inter-frequency A4 measurement report waiting timer. If an inter-frequency measurement is triggered, the duration for a UE performing inter-frequency measurement must be restricted. This prevents the UE from continuously performing gap-assisted measurements when the base station does not receive measurement reports within a period, ensuring that data transmission will not be affected.

When this timer is used for coverage-based inter-frequency handovers, there are the following situations: If the value range is 10 to 20000, then this parameter applies only to LTE TDD and the actual length of the timer is equal to the configured value. If the value range is 20010 to 40000, then this parameter applies only to LTE FDD and LTE TDD and the actual length of the timer is equal to the configured value minus 20000.

When this timer is used for service-request- or carrier-attribute-based handovers, this parameter applies only to LTE FDD and LTE TDD. If the value range is 10 to 20000, the actual length of the timer is equal to the configured value. If the value range is 20010 to 40000, the actual length of the timer is equal to the configured value minus 20000.

GUI Value Range: 10~20000,20010~40000

Unit: ms

Actual Value Range: 10~20000

MML Default Value: 3000

Recommended Value: 3000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter results in prolonged waiting time. A small value of this parameter causes measurements for service-, service request-, or carrier-attribute-based inter-frequency handovers to stop before the measurements are completed or reported.

Applicable Mode: L-FDD, L-TDD
A4TimeToTriger Service-based InterFreq A4 time to trigger

Meaning: Indicates the time-to-trigger for service-based inter-frequency event A4.

When the UE detects that the signal quality in the serving cell and that in at least one inter-frequency neighboring cell meets the entering condition for a service- or service request-based handover, it does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers.

This parameter applies only to LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: 640ms(640ms)

Recommended Value: 640ms(640ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter causes that a UE is difficult to be handed over to an inter-frequency cell. A small value of this parameter enables a UE to be easily handed over to an inter-frequency cell and causes an

increased number of handovers.

Applicable Mode: L-TDD

Example

To add a service-based inter-Freq handover policy group with the parameters as follows: Cn Operator ID: 0, ServiceIfHoCfgGroupId: 9, run the following command:
ADD SERVICEIFHOCFGGROUP: CnOperatorId=0, ServiceIfHoCfgGroupId=9;
