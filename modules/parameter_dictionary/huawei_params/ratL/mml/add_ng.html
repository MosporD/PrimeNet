ADD NG Configuration (ADD NG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an NG object.

Note

None.

Parameters

ID Name Description
NgId NG ID

Meaning: Indicates the ID of the NG object. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator that owns the NG object. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EpGroupConfigFlag End Point Group Config Flag

Meaning: Indicates whether to configure the control-plane endpoint group or user-plane endpoint group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CP_CFG(CP Config), UP_CFG(UP Config), CP_UP_CFG(CPUP Config)

Unit: None

Actual Value Range: CP_CFG, UP_CFG, CP_UP_CFG

MML Default Value: CP_UP_CFG(CPUP Config)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CpEpGroupId Control Plane End Point Group ID

Meaning: Indicates the ID of the control-plane endpoint group used by the NG object. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The CpEpGroupId value in each NG MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UpEpGroupId User Plane End Point Group ID

Meaning: Indicates the ID of the user-plane endpoint group used by the NG object. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group that owns the NG object. If the eNodeB works in hybrid RAN sharing mode, you can set this parameter to a value within the range of 0-5. These IDs are valid. If the eNodeB works in independent mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, this parameter does not take effect. In this case, you can set this parameter to its default value 255. The value 255 is invalid. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5,255

Unit: None

Actual Value Range: 0~5,255

MML Default Value: 255

Recommended Value: If the eNodeB works in hybrid RAN sharing mode, you can set this parameter to a value within the range of 0-5; otherwise, set this parameter to the invalid value 255.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
