Modify Cell Operator Reserved Parameter (MOD ENBCELLOPRSVDPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify reserved cell-operator-level parameters.

Note

  • Do not modify a not-in-use reserved parameter.

  • If an in-use reserved parameter that has been configured is set to a value not in the value range, the default parameter value will be used.

  • Modify in-use reserved parameters according to the descriptions in (eNodeB) Used Reserved Parameter List in the 03-Reserved List folder that is delivered with Release Documents-EN of the corresponding version.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

Service Interrupted After Modification: N/A

Applicable Mode: L-FDD, L-TDD
TrackingAreaId Local tracking area ID

Meaning: Indicates the local tracking area identity of the cell, which uniquely identifies an operator's record of tracking area information within a cell. This parameter is used only in the eNodeB and is different from the TAI configured in the TAL on the MME. This parameter applies only to LTE FDD and LTE TDD.
