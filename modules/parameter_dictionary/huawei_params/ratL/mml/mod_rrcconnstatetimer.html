Modify UE Timer Configuration (MOD RRCCONNSTATETIMER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to the timers of RRC connection control.

Note

None.

Parameters

ID Name Description
T302 Timer302

Meaning: Indicates the length of the timer T302.

T302 specifies the time during which a UE whose RRC connection request is rejected has to wait before the UE can initiate a request again.

This timer starts when the UE receives an RRCConnectionReject message and stops when the UE enters the RRC_CONNECTED mode or performs cell reselection. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~16

Unit: s

Actual Value Range: 1~16

MML Default Value: None

Recommended Value: 16

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the eNodeB rejects access of the UE again for the same reason. If this parameter is set to a large value, the UE cannot access the network for a long period of time, which affects user experience.

Applicable Mode: L-FDD, L-TDD
T320ForLoadBalance Timer320 for load balance

Meaning: Indicates the length of the timer contained in the RRC connection release message when an RRC connection release procedure is triggered for MLB. This timer specifies the length of a period during which cell-reselection priorities contained in the RRC connection release message retain valid. After the timer expires, the cell-reselection priorities contained in the RRC connection release message become invalid.

This timer starts when the UE receives an RRC connection release message containing the T320 timer and stops when the UE enters RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: min5(5), min10(10), min20(20), min30(30), min60(60), min120(120), min180(180)

Unit: min

Actual Value Range: min5, min10, min20, min30, min60, min120, min180

MML Default Value: None

Recommended Value: min10(10)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: After the T320 timer expires, the cell-reselection parameters contained in the RRC connection release message become invalid, and the cell-reselection parameters contained in the system information take effect. As the cell-reselection priorities contained in the system information are optional, frequency prioritization can be better guaranteed during cell reselection if the cell-reselection priorities contained in the RRC connection release message are used. If the value of this parameter is too large, cell-reselection parameters cannot be updated in time at the UE when cell-reselection parameter values change.

Applicable Mode: L-FDD, L-TDD

Unit: ms

Actual Value Range: ms50, ms100, ms150, ms200, ms500, ms1000, ms2000

MML Default Value: None

Recommended Value: ms500(500)

Parameter Relationship: None

Impact on Radio Network Performance: If the UE does not complete an intra-RAT handover before this timer expires, the UE reverts to the associated configuration and initiates an RRC connection reestablishment procedure.

Applicable Mode: L-FDD, L-TDD

If the UE does not complete the handover before this timer expires, the UE reverts to the associated configuration and initiates an RRC connection re-establishment procedure. T320ForOther Timer320 for other

Meaning: Indicates the length of the timer contained in the RRC connection release message when an RRC connection release procedure is triggered for reasons other than MLB. This timer specifies the length of a period during which cell-reselection priorities contained in the RRC connection release message retain valid. After the timer expires, the cell-reselection priorities contained in the RRC connection release message become invalid. This parameter is invalid for UEs to be redirected and reselected based on the SPID-specific frequency priorities.

This timer starts when the UE receives an RRC connection release message containing the T320 timer and stops when the UE enters RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: min5(5), min10(10), min20(20), min30(30), min60(60), min120(120), min180(180)

Unit: min

Actual Value Range: min5, min10, min20, min30, min60, min120, min180

MML Default Value: None

Recommended Value: min120(120)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: After the T320 timer expires, the cell-reselection parameters contained in the RRC connection release message become invalid, and the cell-reselection parameters contained in the system information take effect. As the cell-reselection priorities contained in the system information are optional, frequency prioritization can be better guaranteed during cell reselection if the cell-reselection priorities contained in the RRC connection release message are used. If the value of this parameter is too large, cell-reselection parameters cannot be updated in time at the UE when cell-reselection parameter values change.

Applicable Mode: L-FDD, L-TDD
NBUeInactiveTimer NB-IoT Ue inactive timer

Meaning: Indicates the length of the UE inactivity timer for NB-IoT UEs. If the eNodeB detects that an NB-IoT UE has neither received nor sent data for a duration exceeding the value of this parameter, the eNodeB releases the RRC connection for the NB-IoT UE. This parameter takes effect only for UEs that will access the network after the parameter is set. This parameter applies only to NB-IoT.

DisuseStatement: This parameter is replaced by the TimerDuration parameter in the UeTimerConfig MO with the TimerType parameter set to NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, or NB_CL2_UE_INACTIVITY_TIMER and will be deleted in later versions. (Although the configuration interface in this version supports delivery of the setting of this parameter, the system no longer uses this parameter.) Therefore, avoid using this parameter.

GUI Value Range: 1~3600

Unit: s

Actual Value Range: 1~3600

MML Default Value: None

Recommended Value: DeployMode is set to STAND_ALONE or GUARD_BAND: 20

DeployMode is set to IN_BAND: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in earlier RRC connection releases for UEs without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger value of this parameter results in later RRC connection releases for UEs without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.

Applicable Mode: L-NB-IOT
FilterReptRrcConnReqTimer Filter Repeated RRCConnReq Timer

Meaning: Indicates the length of the timer for the eNodeB to filter repeated RRC Connection Request messages. For LTE FDD and LTE TDD, the actually used timer length is the sum of the length of T300 timer and the value of the FilterReptRrcConnReqTimer parameter. For NB-IoT, the actually used timer length is equal to min{T300 + FilterReptRrcConnReqTimer, MaxFilterTimer}. In V100R015C10 or an earlier version, the value of MaxFilterTimer is 17s. In other cases, the value of MaxFilterTimer is 35s.

GUI Value Range: 0~15

Unit: s

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: After the eNodeB receives the first RRC Connection Request message, if the eNodeB receives more RRC Connection Request messages within the length of T300 plus FilterReptRrcConnReqTimer, the eNodeB considers that these messages are sent for one RRC connection request and the L.RRC.ConnReq.Att counter increases only by one.

Applicable Mode: L
UlSynTimerDynDrx Uplink Sync Timer Dynamic DRX

Meaning: Indicates the timer used to govern the period in which the eNodeB maintains uplink synchronization for a DRX UE when dynamic DRX is enabled. After this timer expires, the eNodeB does not send Timing Advance Command to the UE. You are advised to set this parameter to a value less than the value of UeInactivityTimerDynDrxQci in the QciPara MO. In power saving mode, you are advised to set this parameter significantly different to the value of the UeInactivityTimerDynDrxQci parameter in the QciPara MO, for example a gap of 10 seconds, to avoid power consumption increase due to the increase of signaling. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 5~3600

Unit: s

Actual Value Range: 5~3600

MML Default Value: None

Recommended Value: 20

Parameter Relationship:

-Others:

  • This parameter is valid only when the DynDrxSwitch option of the DynDrxSwitch parameter in the CellAlgoSwitch MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that UEs enter the out-of-synchronization state when they should not and, therefore, a larger number of random access procedures triggered for maintaining uplink synchronization and more occupied resources for random access.

A larger value of this parameter results in fewer prompt changes of UE status from uplink-synchronized to out-of-synchronization, more power consumption of UEs, and more occupied PUCCH and SRS resources.

Applicable Mode: L-FDD, L-TDD
RrcConnRelTimer RRC Connection Release Timer

Meaning: Indicates the time that the eNodeB waits for a response message after sending an RRC Connection Release message to a UE.

GUI Value Range: 450~10000

Unit: ms

Actual Value Range: 450~10000

MML Default Value: None

Recommended Value: 450

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a longer time that the eNodeB sends the RRC connection release message and a lower probability that UEs fail to receive the RRC connection release message. As a result, the numbers of RRC connection reestablishment requests and reestablishment rejections decrease, which in turn increases the reestablishment success rate. However, more radio interface resources are required, which causes a higher probability that the throughput decreases. A smaller value of this parameter leads to a higher probability that UEs fail to receive the RRC connection release message. As a result, the numbers of RRC connection reestablishment requests and reestablishment rejections increase, which in turn decreases the reestablishment success rate.

Applicable Mode: L
DRXRrcConnRelTimerOffset RRC Connection Release Offset Timer in DRX

Meaning: Indicates the offset of the value of the RRC connection release timer that actually takes effect for UEs in the DRX state relative to the RrcConnRelTimer parameter value in the RrcConnStateTimer MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9000

Unit: ms

Actual Value Range: 0~9000

MML Default Value: None

Recommended Value: 5120

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter increases the release waiting time of the eNodeB, decreases the total number of normal releases, and reduces the number of times that RRC connection reestablishment requests are rejected. More resources are occupied if the waiting time prolongs. The service drop rate increases, the RRC connection reestablishment success rate decreases, and throughput drops when the number of UEs in a cell reaches the upper limit. A smaller value of this parameter results in a higher probability that UEs fail to receive the RRC Connection Release message and more RRC connection reestablishments.

Applicable Mode: L-FDD, L-TDD

ExtendedWaitTime Extended Wait Time

Meaning: Indicates the waiting time for a UE to send an RRCConnectionRequest message again in either of the following conditions:

1. After the previous RRC connection setup request with the cause value delayTolerantAccess initiated by the UE was rejected when the MME is overloaded

2. After the RRC connection was released for the cause delayTolerantAccess.

In NB-IoT, this parameter is used when the MME is overloaded and flow control is implemented by the eNodeB.

GUI Value Range: 1~1800

Unit: s

Actual Value Range: 1~1800

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the eNodeB rejects UE access for the same reason. If this parameter is set to a large value, UEs cannot access the cell for a long time, affecting user experience.

Applicable Mode: L

GUI Value Range: s0(0), s0dot5(0.5), s1(1), s2(2), s5(5), s10(10), s20(20), s30(30), s60(60), s90(90), s120(120), s300(300), s600(600)

Unit: s

MML Default Value: None

Recommended Value: s600(600)

ReptRrcReestProtectTimer Repeated RRC Reest Protection Timer

Meaning: Indicates the length of the protection timer of repeated RRC connection reestablishments. If this parameter is set to a non-zero value and the interval between RRC connection reestablishment requests repeatedly initiated by a UE is less than this parameter value, the repeated requests and successful reestablishments are not counted. If this parameter is set to 0, this function does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3600

Unit: s

Actual Value Range: 0~3600

MML Default Value: None

Recommended Value: If the function of RRC connection reestablishment protection is used, you are advised to set this parameter to 20.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability that the interval between RRC connection reestablishment requests initiated by the same UE is less than the parameter value, a larger number of RRC connection reestablishments counted, and a larger RRC connection reestablishment success rate. A larger value of this parameter results in the opposite effects. If this parameter is set to 0, the preceding impacts do not exist.

Applicable Mode: L-FDD, L-TDD

If this parameter is set to a value other than 0, the UE context cannot be released until the timer expires after the QCI-1 bearers are released. This parameter applies only to LTE FDD and LTE TDD.

Actual Value Range: 0~3600

Parameter Relationship: None
