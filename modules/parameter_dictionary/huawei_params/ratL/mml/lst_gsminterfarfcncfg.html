List GSM Interference ARFCN Configuration (LST GSMINTERFARFCNCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list ARFCNs of interfering GSM frequencies for GL spectrum cloudification features.

Note

GsmArfcnGroupId must be manually set. If GsmArfcnGroupId is not specified, the eNodeB queries all ARFCN configurations in all GSM interference ARFCN groups. If GsmArfcnGroupId is specified, the eNodeB queries all GSM ARFCNs in the specified interference ARFCN group.

Parameters

ID Name Description
GsmArfcnGroupId GSM ARFCN Group ID

Meaning: Indicates the GSM ARFCN group ID used in GSM and LTE spectrum concurrency. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of 25 GsmArfcn can be configured for a GsmArfcnGroupId.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the interference configuration of GsmInterfArfcnCfg with the parameters as follows: GSM ARFCN Group ID: 0, run the following command:
LST GSMINTERFARFCNCFG: GsmArfcnGroupId=0;
The result is shown as follows:

Indicates the GSM ARFCN used in GSM and LTE spectrum concurrency. This parameter applies only to LTE FDD.
