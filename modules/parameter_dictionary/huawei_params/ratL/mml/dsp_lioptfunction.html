Display Intelligent Optimization Function Parameter (DSP LIOPTFUNCTION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of intelligent optimization functions.

Note

None.

Parameters

ID Name Description
IOptFunctionID Intelligent Optimization Function ID

Meaning: Indicates the ID of the intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the status of intelligent optimization functions, run the following command: :
DSP LIOPTFUNCTION:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the ID of the cell with which intelligent optimization atom rules are applied. This parameter can only be queried by running the DSP LIOPTFUNCTION command. Information displayed in the DSP LIOPTFUNCTION command output is specific to the cell. This parameter setting does not take effect when the MeasureObjType parameter is set to eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Intelligent Optimization Function ID

Indicates the ID of the intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.

Intelligent Optimization Feature ID

Indicates the ID of the intelligent optimization feature. This parameter applies only to LTE FDD and LTE TDD.

Intelligent Optimization Function Name

Indicates the name of the intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.

Status

Indicates the status of intelligent optimization atom rules. This parameter can only be queried by running the DSP LIOPTFUNCTION command. If this parameter value is NORMAL, the intelligent optimization is in the normal state. If this parameter value is PENALTY, the intelligent optimization is under penalty, and all related intelligent optimization measures cannot be taken. This parameter applies only to LTE FDD and LTE TDD.

Trigger List

Indicates information about the neighboring cells that request the local cell to perform intelligent optimization functions. The ECGI identifying a neighboring cell is displayed in format of Mcc-Mnc-eNodeBID-CellID. This parameter applies only to LTE FDD and LTE TDD.
