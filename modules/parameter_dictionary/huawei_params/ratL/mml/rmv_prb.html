Remove Physical Resource Block (RMV PRB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a physical carrier for an NB-IoT cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

Remove one PRB:
RMV PRB: LocalCellId=0, PrbId=0;
