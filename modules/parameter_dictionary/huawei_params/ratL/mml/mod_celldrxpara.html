Modify Cell DRX Parameters (MOD CELLDRXPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify DRX parameters of a cell.

Note

None.

FddEnterDrxThd FDD enter DRX threshold

Meaning: Indicates the threshold for UEs to enter the discontinuous reception (DRX) mode in a cell that operates in FDD mode. This threshold is used in the DRX algorithm. It is expressed as a proportion of the transmission time intervals (TTIs) with data transmission to the total TTIs. If the measurement result of UE traffic is equal to or lower than this threshold, the eNodeB determines that the UE should remain in DRX mode or the UE should be triggered to enter DRX mode. If both the values of the FddExitDrxThd and FddEnterDrxThd parameters are small and close to each other, the UE frequently enters and exits the DRX mode. When both the FddEnterDrxThd parameter and the FddExitDrxThd parameter are set to 1000 and DRX is enabled, the eNodeB directly determines that the UE should enter or exit the DRX mode, but not according to the measurement result of UE traffic. This parameter applies only to LTE FDD.

GUI Value Range: 0~1000

Unit: per mill

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 1000

Parameter Relationship:

-Configuration constraints:

DrxPolicyMode DRX Policy Mode

Meaning: Indicates the policy for selecting a DRX parameter group and the policy for enabling DRX for a UE whose bearers have different QCIs.

If this parameter is set to DEFAULT, the eNodeB preferentially selects the DRX parameter group with the shortest long DRX cycle specified by the LongDrxCycle parameter for the UE when the EnterDrxSwitch parameter in the DrxParaGroup MOs is set to ON for all bearers of the UE. Specially, if the LongDrxCycle parameter values for multiple QCIs are the same, the eNodeB selects the DRX parameter groups based on the QCI-specific ARP priorities delivered from the EPC. The eNodeB selects the DRX parameter group mapped to the highest-ARP-priority QCI for the UE. However, if the EnterDrxSwitch parameter in the DrxParaGroup MO is set to OFF for any bearer of the UE, the eNodeB does not configure DRX parameters for the UE.

If this parameter is set to QCIPRIORITY, the eNodeB selects the DRX parameter group mapped to the highest-priority QCI for the UE. Specially, if the EnterDrxSwitch parameter in the DrxParaGroup MO mapped to the highest-priority QCI is set to OFF, the eNodeB does not configure DRX parameters for the UE.

If this parameter is set to 3GPPDEFINEDQCIPRIORITY, the eNodeB preferentially selects the DRX parameter group with the shortest long DRX cycle specified by the LongDrxCycle parameter for the UE when the EnterDrxSwitch parameter in the DrxParaGroup MOs is set to ON for all bearers of the UE. Specially, if the LongDrxCycle parameter values for multiple QCIs are the same, the eNodeB selects the DRX parameter groups based on the 3GPP-defined QCI priorities. The eNodeB selects the DRX parameter group mapped to the highest-priority QCI for the UE. However, if the EnterDrxSwitch parameter in the DrxParaGroup MO is set to OFF for any bearer of the UE, the eNodeB does not configure DRX parameters for the UE.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DEFAULT(Default), QCIPRIORITY(QCI priority), 3GPPDEFINEDQCIPRIORITY(3GPP Defined Qci priority)

DrxStartOffsetOptSwitch DRX Start Offset Optimization Switch

Meaning: Indicates whether to enable optimized random distribution of DrxStartOffset values for UEs that are configured with only sounding reference signal (SRS) resources, or periodic channel quality indicator (CQI), or neither. If this parameter is set to OFF, then DrxStartOffset takes the value of SrsOffset, CqiOffset, or 0 when a UE is configured with only SRS resources, or periodic CQI, or neither, respectively. This prevents DrxStartOffset values from being randomly distributed within the range of 0 to (LongDrxCycle - 1). If this parameter is set to ON, DrxStartOffset values can be randomly distributed within the range of 0 to (LongDrxCycle - 1) for UEs that are configured with only SRS resources, or periodic CQI, or neither. This parameter applies only to LTE FDD eNodeBs and is recommended to be set to ON when SRS resources are not allocated for UEs or there is a large number of UEs in the cell. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to OFF and the cell serves a large number of UEs that are configured with only SRS resources, or periodic CQI, or neither, UEs are scheduled in the downlink in a centralized manner, thereby increasing the downlink scheduling delay for UEs and decreasing downlink UE throughput in the cell.

If this parameter is set to ON and the cell serves a large number of UEs that are configured with only SRS resources, or periodic CQI, or neither, the probability that UEs are scheduled in a centralized manner decreases. As a result, the downlink scheduling delay for UEs decreases, and downlink UE throughput increases.

DrxRcvDtxProSwitch DRX Receive DTX Process Switch

Meaning: If this parameter is set to ON and two consecutive discontinuous transmissions (DTXs) are detected in the downlink, the eNodeB continues the scheduling within the valid inactivity timer period. Otherwise, the eNodeB instructs the UE to enter the DRX sleep time. The valid inactivity timer period refers to the running period of the DrxInactivityTimer (excluding the timer running triggered by situations such as false SR detections and missing PDCCH detections). In carrier aggregation (CA) scenarios, the eNodeB regards DTXs on the PCC and SCCs as one DTX only when the PCC and SCCs are scheduled. If this parameter is set to OFF, the eNodeB instructs the UE to enter the DRX sleep time when detecting two consecutive DTXs, irrespective of whether the inactivity timer period is valid. In addition, when the PCC and SCC have data scheduling, the eNodeB regards DTXs on either the PCC or the SCC as one DTX.

In CA scenarios, the setting of this parameter in the PCell and SCells must be the same. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, downlink throughput increases in weak coverage areas. The eNodeB no longer enables the UE to forcibly enter the DRX sleep time when detecting two consecutive DTXs, which may cause the following impact:

1. The activity period ratio increases. The increase in scheduling probabilities causes both uplink and downlink BLERs to increase slightly.

2. It takes a shorter time to reach the maximum number of downlink RLC data retransmissions. Therefore, the service drop rate increases slightly.

3. The CA activation and deactivation success rates decrease slightly.

4. The uplink throughput fluctuates slightly.

If this parameter is set to OFF, the preceding impacts do not exist.

CaDrxOptSwitch CA DRX Optimization Switch

Meaning: Indicates the DRX optimization algorithms in CA scenarios.

PCC_SCC_DRX_STATE_SYNC_SW: If this option is selected, a PCC or SCC informs other CCs of its DRX status change. If this option is deselected, each CC maintains its own DRX status. This option applies only to LTE FDD and LTE TDD.

FDD_TDD_ON_DUR_TIMER_EXT_SW: Indicates whether to extend the length of the On Duration Timer in FDD+TDD CA scenarios. If this option is selected and a UE is in the FDD+TDD CA state with an FDD cell serving as the PCell, the length of the On Duration Timer is extended when the number of downlink subframes within the length of the On Duration Timer in a TDD cell is less than four. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PCC_SCC_DRX_STATE_SYNC_SW(PCC_SCC_DRX_STATE_SYNC_SW), FDD_TDD_ON_DUR_TIMER_EXT_SW(FDD_TDD_ON_DUR_TIMER_EXT_SW)

Unit: None

Actual Value Range: PCC_SCC_DRX_STATE_SYNC_SW, FDD_TDD_ON_DUR_TIMER_EXT_SW

MML Default Value: None

Recommended Value: PCC_SCC_DRX_STATE_SYNC_SW:Off, FDD_TDD_ON_DUR_TIMER_EXT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: PCC_SCC_DRX_STATE_SYNC_SW: If this option is selected, the downlink average throughput of CA UEs increases and the BER increases in scenarios such as false SR alarms and weak coverage.

FDD_TDD_ON_DUR_TIMER_EXT_SW: If this option is selected, more UEs enter DRX mode, the number of TTIs in which UEs are in sleep time increases, the number of TTIs in which UEs are in active time decrease, and the downlink PDCP-layer delay increases slightly.

Applicable Mode: L-FDD, L-TDD
VoltePlrThldForExitingDrx VoLTE Packet Loss Rate Thld for Exiting DRX

Meaning: Indicates the VoLTE packet loss rate threshold for exiting DRX, which is used by the DRX algorithm to determine whether UEs exit DRX. If this parameter is set to 0, this function does not take effect. If the uplink or downlink packet loss rate in a 2.5s time window is greater than or equal to this threshold, the eNodeB stops voice quality monitoring and determines that the voice quality is poor and then instructs UEs to exit DRX. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~99

Unit: %

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to 5 when DRX is enabled.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter value is greater than 0, the VoLTE packet loss rate caused by false SR alarms in DRX decreases. However, the power saving effect deteriorates, and the number of UEs in DRX and proportion of VoLTE UEs in the active state of DRX decrease. A larger parameter value leads to a lower probability of exiting DRX, and the VoLTE packet loss rate caused by false SR alarms in DRX increases. However, the power saving effect improves, and the number of UEs in DRX and proportion of VoLTE UEs in the active state of DRX increase. When this parameter is set to 0, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
VocDrxEntryForbidLoadThld Cell Load Thld for Forbidding Voice UE DRX Entry

Meaning: Indicates the cell load threshold for forbidding newly accessed voice UEs to enter the DRX mode. The algorithm does not take effect when this parameter is set to 0. When this parameter is set to a value in the range of 1 to 100, the eNodeB forbids newly accessed voice UEs to enter the DRX mode only if the cell load is higher than the threshold value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to 50 when DRX is enabled.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of forbidding voice UEs to enter the DRX mode. In this situation, the uplink and downlink packet loss rates of voice services increase as cell load increases. However, the UE power saving effect improves. A smaller value of this parameter results in a higher probability of forbidding voice UEs to enter the DRX mode. In this situation, the uplink and downlink packet loss rates of voice services decrease as cell load increases. However, the UE power saving effect deteriorates. In addition, the downlink cell throughput and downlink user-perceived rate decrease slightly.

Applicable Mode: L-FDD, L-TDD
