Remove Serving-Cell-Operator-Dedicated Config of Neighboring NR Frequency (RMV NRNFREQSCELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a serving-cell-operator-specific dedicated configuration of a neighboring NR frequency.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlArfcn Downlink ARFCN

Meaning: Indicates the downlink SSB ARFCN of neighboring NR frequency dedicated to the operator of the serving cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 123400~130400,145800~149200,151600~164200,173800~178800,185000~192000,285400~303600,361000~384000,386000~405000,422000~440000,460000~480000,499200~538000,620000~680000,693333~733333,2016667~2104166,2229166~2279166

Unit: None

Actual Value Range: 123400~130400,145800~149200,151600~164200,173800~178800,185000~192000,285400~303600,361000~384000,386000~405000,422000~440000,460000~480000,499200~538000,620000~680000,693333~733333,2016667~2104166,2229166~2279166

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOperatorId Cn Operator ID

Meaning: Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove a serving-cell-operator-specific dedicated configuration of a neighboring NR frequency,  LocalCellId=0, DlArfcn=620000, CnOperatorId=0:
RMV NRNFREQSCELLOP: LocalCellId=0, DlArfcn=620000, CnOperatorId=0;
