List Cn Operator SPID Configuration (LST CNOPERATORSPIDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the dedicated subscriber profile ID (SPID) configuration for one or all operators.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: This parameter indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • CnOperatorId in an CnOperatorSpidCfg MO must be set in the associated CnOperator MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Spid Spid

Meaning: Indicates the dedicated SPID for an operator. According to 3GPP specifications, the SPID can be from 1 to 256. When this parameter is set to 0, the eNodeB does not obtain the SPID from the MME or the eNodeB is not configured with an SPID for UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

To list the dedicated SPID configuration for one or all operators, run the following command:
LST CNOPERATORSPIDCFG:;

Output Description

Field Description

CN Operator ID

This parameter indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

Spid

Indicates the dedicated SPID for an operator. According to 3GPP specifications, the SPID can be from 1 to 256. When this parameter is set to 0, the eNodeB does not obtain the SPID from the MME or the eNodeB is not configured with an SPID for UEs. This parameter applies only to LTE FDD and LTE TDD.

RAT frequency priority indication

Indicates whether to set a RAT/frequency priority. If this parameter is set to CFG, UEs preferentially camp on the RAT or frequency. If this parameter is set to NOT_CFG, UEs do not preferentially camp on the RAT or frequency. This parameter applies only to LTE FDD and LTE TDD.

RAT frequency priority group ID

Indicates the ID of a RAT/frequency priority group. This parameter applies only to LTE FDD and LTE TDD.

Offload Switch

Indicates whether to enable SPID-specific offload.

INTER_FREQUENCY_OFFLOAD_SWITCH: Indicates whether to enable inter-frequency offload. In inter-frequency offload, the eNodeB transfers UEs from a local cell to its inter-frequency neighboring cells to decrease the local cell load without considering the load difference between the local cell and the neighboring cells. The eNodeB can transfer UEs with the specific SPID by inter-frequency offload from the local cell to inter-frequency neighboring cells with load information exchange only if this option is selected. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_OFFLOAD_SWITCH: The eNodeB can transfer UEs with the specific SPID by inter-RAT offload from the local cell to UTRAN or GERAN neighboring cells only if this option is selected. This option applies only to LTE FDD and LTE TDD.
