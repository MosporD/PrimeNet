Remove Frequency Layer Group (RMV FREQLAYERGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a frequency steering group.

Note

None.

Parameters

ID Name Description
FreqLayerEarfcn Frequency Layer EARFCN

Meaning: Indicates a frequency involved in edge frequency steering. This parameter applies only to LTE TDD.

GUI Value Range: 0~70545,229376~229575,255144~256143,260894~262143

Unit: None

Actual Value Range: 0~70545,229376~229575,255144~256143,260894~262143

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FreqLayerGroupId Frequency Layer Group Identity

Meaning: Indicates the ID of a frequency group involved in edge frequency steering. It uniquely identifies an edge frequency steering group within a base station. This parameter applies only to LTE TDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
