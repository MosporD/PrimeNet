Modify MbsfnSubframe (MOD MBSFNSUBFRAME)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration data of MBSFN subframes.

Note

None.

Parameters

OneFrameAllocation One Frame Allocation

Meaning: Indicates the MBSFN subframes allocated in one radio frame when the MBSFN subframe allocation mode is One Frame.

If the cells in the MBSFN area work in TDD mode, the subframes that can be allocated for MBSFN in a radio frame are SF3, SF4, SF7, SF8, and SF9. These subframes are represented by bit 5 to bit 1 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN.

If the cells in the MBSFN area work in FDD mode, the subframes that can be allocated for MBSFN in a radio frame are SF1, SF2, SF3, SF6, SF7, and SF8. These subframes are represented by bit 5 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

FourFrameAllocation Four Frame Allocation

Meaning: Indicates the MBSFN subframes allocated in four consecutive radio frames when the MBSFN subframe allocation mode is Four Frame.

If the cells in the MBSFN area work in TDD mode, the subframes that can be allocated for MBSFN in each radio frame include SF3, SF4, SF7, SF8, and SF9. These subframes in the four radio frames are represented by bit 23 to bit 19, bit 17 to bit 13, bit 11 to bit 7, and bit 5 to bit 1 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN.

If the cells in the MBSFN area work in FDD mode, the subframes that can be allocated for MBSFN in each radio frame include SF1, SF2, SF3, SF6, SF7, and SF8. These subframes in the four radio frames are represented by bit 23 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Example

To modify the following MBSFNSUBFRAME parameters, Local MCE ID:0, MBSFN Area ID:0, MBSFN Subframe Configuration ID:0, Subframe Allocation Mode:ONE_FRAME, Four Frame Allocation:2, Radio Frame Allocation Period:N1, Radio Frame Allocation Offset:1, run the following command:
MOD MBSFNSUBFRAME: LocalMceId=0, MbsfnAreaId=0, MbsfnSfConfigId=0, SubframeAllocationMode=ONE_FRAME, OneFrameAllocation=2, RadioFrameAllocPrd=N1, RadioFrameAllocOfs=1;
