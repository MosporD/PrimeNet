Modify User Qci Priority (MOD USERQCIPRIORITY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to ARP- and QCI-based scheduling weight factors.

Note

None.

Parameters

ID Name Description
Qci QoS Class Identifier

Meaning: Indicates the QCI of an EPS bearer. Different QCIs represent different QoS specifications such as the packet delay budget, packet error loss rate, and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: QCI6(QCI6), QCI7(QCI7), QCI8(QCI8), QCI9(QCI9)

Unit: None

Actual Value Range: QCI6, QCI7, QCI8, QCI9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GoldUlSchPriorityFactor Gold Uplink Schedule Priority Factor

Meaning: Indicates the weight factor used to calculate the connection priorities during uplink scheduling for gold users. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 0.001~1, step: 0.001

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

QCI 6: 1000, QCI 7: 950, QCI 8: 900, and QCI 9: 850

Parameter Relationship:

-Configuration constraints:

  • In a UserQciPriority MO, the value of GoldUlSchPriorityFactor must be greater than or equal to the value of SilverUlSchPriorityFactor, and the value of SilverUlSchPriorityFactor must be greater than or equal to the value of BronzeUlSchPriorityFactor, and the value of BronzeUlSchPriorityFactor must be greater than or equal to the value of IronUlSchPriorityFactor.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in smaller uplink bandwidth to be allocated to services with the QCI when the uplink transport bandwidth or uplink licensed traffic volume is limited. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
GoldDlSchPriorityFactor Gold Downlink Schedule Priority Factor

Meaning: Indicates the weight factor used to calculate the connection priorities during downlink scheduling for gold users. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher downlink scheduling priority for services with the QCI and also a higher priority with which the data rate for these services is guaranteed. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
