Add QoS Policy (ADD QOSPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a QoS policy.

Note

None.

Parameters

ID Name Description
QosPolicyId QoS Policy Identity

Meaning: Indicates the ID of a user-defined QoS policy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TrafficType Traffic Type

Meaning: Indicates a traffic type for service differentiation. Currently, there are three types of traffic: VIDEO, DOWNLOAD, and OTHER. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: VIDEO(VIDEO), DOWNLOAD(DOWNLOAD), OTHER(OTHER)

Unit: None

Actual Value Range: VIDEO, DOWNLOAD, OTHER

MML Default Value: OTHER(OTHER)

Recommended Value: OTHER(OTHER)

Parameter Relationship:

-Configuration constraints:

  • In a QosPolicy MO, if TrafficType is set to VIDEO, DlSgbr must be set to a value greater than 0.
  • In a QosPolicy MO, if TrafficType is set to DOWNLOAD, DlSmbr must be set to a value greater than 0.
  • In a QosPolicy MO, if TrafficType is set to VIDEO, PriQueueId must be set to QUEUE5, QUEUE6, or QUEUE7.
  • In a QosPolicy MO, if TrafficType is set to DOWNLOAD, PriQueueId must be set to QUEUE0, QUEUE1, or QUEUE2.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PriQueueId Priority Queue Identity

Meaning: Indicates the ID of a prioritized queue. The eNodeB can provide differentiated services for a maximum of eight prioritized queues. Multiple DSCPs can be mapped to one queue, but one DSCP cannot be mapped to multiple queues. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: QUEUE0(QUEUE0), QUEUE1(QUEUE1), QUEUE2(QUEUE2), QUEUE3(QUEUE3), QUEUE4(QUEUE4), QUEUE5(QUEUE5), QUEUE6(QUEUE6), QUEUE7(QUEUE7)

Unit: None

Actual Value Range: QUEUE0, QUEUE1, QUEUE2, QUEUE3, QUEUE4, QUEUE5, QUEUE6, QUEUE7

MML Default Value: QUEUE0(QUEUE0)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a QosPolicy MO, if TrafficType is set to VIDEO, PriQueueId must be set to QUEUE5, QUEUE6, or QUEUE7.
  • In a QosPolicy MO, if TrafficType is set to DOWNLOAD, PriQueueId must be set to QUEUE0, QUEUE1, or QUEUE2.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlSgbr Downlink Service Grant Bit Rate

Meaning: Indicates the guaranteed bit rate of downlink services. This parameter must be set to a value greater than 0 if the TrafficType parameter value is VIDEO. Otherwise, commands containing this parameter fail to be executed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: Kbit/s

Actual Value Range: 0~4294967295

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a QosPolicy MO, if TrafficType is set to VIDEO, DlSgbr must be set to a value greater than 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value larger than that necessary for video, more radio resources are occupied, and the cell throughput is lower.

Applicable Mode: L-FDD, L-TDD
DlSmbr Downlink Service Maximum Bit Rate

Meaning: Indicates the maximum bit rate for downlink services. If the downlink data rate of a UE exceeds the value of this parameter, rate control will be triggered for the UE. This parameter must be set to a value greater than 0 if the TrafficType parameter is set to DOWNLOAD. Otherwise, the command for QoS policy addition or modification cannot be successfully executed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: Kbit/s

Actual Value Range: 0~4294967295

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a QosPolicy MO, if TrafficType is set to DOWNLOAD, DlSmbr must be set to a value greater than 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value and there are many download services, these download services have a lower priority and the cell throughput is lower, but user experience of higher-priority services is better.

Applicable Mode: L-FDD, L-TDD
RateControlSwitch Rate Control Switch

Meaning: Indicates whether to limit the UE rate based on the UE-AMBR.

When the eNodeB detects that the UE has sufficient traffic in the queue:

If this parameter is set to ON, the eNodeB limits the UE rate based on the UE-AMBR.

If this parameter is set to OFF, the eNodeB does not limit the UE rate based on the UE-AMBR.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(ON)

Recommended Value: ON(ON)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON for all queues, the eNodeB limits the UE rate based on the UE-AMBR, and the cell throughput is not affected.

If this parameter is set to OFF and there is sufficient traffic in the corresponding queue, the eNodeB does not limit the UE rate based on the UE-AMBR. In this case, the traffic of UEs with ongoing services in the queue and cell throughput increase.

Applicable Mode: L-FDD, L-TDD

Example

To add QosPolicy with the parameters as follows: QoS Policy Identity:40, Traffic Type:OTHER, run the following command:
ADD QOSPOLICY: QosPolicyId=40, TrafficType=OTHER;
