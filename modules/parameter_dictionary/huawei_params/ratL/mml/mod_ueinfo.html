Modify Ue Information (MOD UEINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the UE-information-related configuration for UE identification on the eNodeB.

Note

None.

AccessStratumRelease Access Stratum Release

Meaning: Indicates the access stratum capability of defective UEs, which corresponds to the field AccessStratumRelease in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331. Parameter values 0 through 7 indicate the field value rel8, rel9, rel10, rel11, rel12, rel13, rel14, and rel15, respectively. Other parameter values are reserved and have no corresponding field values.

If this parameter is set to 255, this parameter is not used for UE selection. If this parameter is set to a non-255 value, a UE can be identified as a defective UE only when the parameter value indicates the same UE capability information of the UE. This parameter applies only to LTE FDD and LTE TDD.

UeCategory UE Category

Meaning: Indicates the UE categories of defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-Category, ue-Category-v1020, ue-Category-v1170, ue-Category-v11a0, ue-Category-v1250, and ue-Category-NB-r13.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bit 0 stands for category 1, bit 1 stands for category 2, bit 2 stands for category 3, ..., bit 9 stands for category 10, bit 10 stands for category 11, bit 11 stands for category 12, bit 12 stands for category 0, and bit 13 stands for category_nb1. Other bits are reserved. If the value of a bit is 1, the corresponding UE category is supported by a UE. For example, if a UE supports both categories 4 and 6, the binary number indicating the UE category information is 101000. This binary number can be converted into 40 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.

DlUeCategory DL UE Category

Meaning: Indicates the downlink UE categories supported by defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryDL-r12, ue-CategoryDL-v1260, ue-CategoryDL-v1310, ue-CategoryDL-v1330, ue-CategoryDL-v1350, ue-CategoryDL-v1450, and ue-CategoryDL-v1460.

When setting this parameter, you need to combine field values indicating the UE categories in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bit 0 to 16 stand for categories 0 to 16, respectively. Bits 17, 18, 19, 20, 21, 22, and 23 stand for category_n17, category_m1, category 18, category 19, category 1bis, category 20, and category 21. Other bits are reserved. If a bit value is 1, the corresponding UE category is supported by the UEs. For example, if a UE supports both categories 19 and 16, the binary number indicating the UE capabilities is 100010000000000000000. This binary number can be converted into 1114112 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to a non-zero value, this parameter takes effect. In this case, a UE matches the UE category when the parameter value is completely identical to the UE capability information. This parameter applies only to LTE FDD and LTE TDD.

UlUeCategory UL UE Category

Meaning: Indicates the uplink UE categories supported by defective UEs, which correspond to the following fields in the information element (IE) UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryUL-r12, ue-CategoryUL-v1310, ue-CategoryUL-v1340, ue-CategoryUL-v1350, ue-CategoryUL-v1430, and ue-CategoryUL-v1430b.

When setting this parameter, you need to combine field values indicating the UE categories in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category defined in 3GPP specifications. Bits 0 to 13 stand for categories 0 to 13, respectively. Bits 14 and 15 stand for category_n14 and category_m1, respectively. Bits 16 to 21 stand for categories 15 to 20, respectively. Bits 22 and 23 stand for categories 1bis and category 21. Other bits are reserved. If a bit value is 1, the corresponding UE category is supported by defective UEs. For example, if a defective UE supports both category_n14 and category 8, the binary number indicating the UE capabilities is 100000100000000. This binary number can be converted into 16640 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to a non-zero value, this parameter takes effect. In this case, a UE matches the UE category when the parameter value is completely identical to the UE capability information.

UeSpecificCapabilityInfo UE Specific Capability Information

Meaning: Indicates the capability information about a defective UE.

Bit 0 indicates the NSA DC capability of the UE, corresponding to the value of en-DC-r15 in the IE IRAT-ParametersNR-r15 in 3GPP 36.331. Other bits are reserved.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from right to left represents a type of UE capability. If a bit is set to 1, it indicates that the UE supports a corresponding type of capability.

If this parameter is set to 0, this parameter is not used for UE matching. This parameter applies only to LTE FDD and LTE TDD.

Example

To modify UE-information-related parameters with the UE Capability Index set to 1, the UE Category set to 2, and the Feature Group Indicator set to 6, run the following command:
MOD UEINFO: UeCapIndex=1, UeCategory=2, Fgi=6;
