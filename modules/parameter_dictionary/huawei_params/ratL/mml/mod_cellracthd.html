Modify Threshold for Admission Control and Load Control (MOD CELLRACTHD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the thresholds for admission and load control.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Therefore, the parameter has no obvious impact on admission. In addition, when the value of the parameter is too small, excessive overload control actions may be taken.

CellCapacityMode Cell Capacity Mode

Meaning: Indicates the cell capacity mode, which is used to set the maximum number of UEs that can access a single cell. The parameter value can be SMALLCAPACITY, NORMALCAPACITY, or LARGECAPACITY, indicating the number of UEs that can access a cell in ascending order. This parameter applies only to LTE FDD.

The SMALLCAPACITY value applies to FDD SFN or LampSite cells. A cell with a bandwidth of 5 MHz or lower supports a maximum of 200 UEs and a cell with a bandwidth of 10 MHz or higher supports a maximum of 400 UEs.

The NORMALCAPACITY value indicates that an FDD cell with a bandwidth of 5 MHz or lower supports a maximum of 600 UEs and a cell with a bandwidth of 10 MHz or higher supports a maximum of 1200 UEs.

The LARGECAPACITY value indicates that an FDD cell supports a maximum of 1800 UEs if the cell meets the following conditions: (1) The cell bandwidth is 10 MHz or higher. (2) The cell is a low-speed cell. (3) Normal CP is configured for the cell. If any of the preceding conditions is not met, the NORMALCAPACITY value applies. For a common cell, the LARGECAPACITY value applies when the following conditions are met: (1) The cell is an intra-BBP cell. (2) The CPU that serves the cell does not serve any SFN cells. (3) The PucchPeriodicCqiOptSwitch parameter is set to ON. (4) The cell is not established on the LBBPc/LBBPd/UBBPd3/UBBPd4 board. If any of the preceding conditions is not met, the NORMALCAPACITY value applies. If this parameter is set to LARGECAPACITY for an SFN cell whose physical cells are established on the LBBPc/LBBPd/UBBPd/UBBPea board, these physical cells cannot be activated. The LARGECAPACITY value does not apply to 2T8R and 4T8R cells. If this parameter is set to LARGECAPACITY for a 2T8R or 4T8R cell, the NORMALCAPACITY value takes effect for the cell. If the TYPE parameter in the MDU MO is set to MDUC, the number of UEs supported by a cell with a specific bandwidth when this parameter is set to LARGECAPACITY is the same as when this parameter is set to NORMALCAPACITY.

GUI Value Range: SMALLCAPACITY(SMALLCAPACITY), NORMALCAPACITY(NORMALCAPACITY), LARGECAPACITY(LARGECAPACITY)

Unit: None

Actual Value Range: SMALLCAPACITY, NORMALCAPACITY, LARGECAPACITY

MML Default Value: None

Recommended Value: NORMALCAPACITY(NORMALCAPACITY)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the cell is configured to allow a larger number of UEs to access, the cell can accept more UEs for data transmission. In such a case, more PUCCH and SRS resources are occupied and resources of shared channels such as PDCCH, PDSCH, and PUSCH are shared by more UEs. As a result, user experience of each UE deteriorates. For example, the average UE throughput decreases. If the number of UEs increases, cell interference increases, and the average spectral efficiency decreases, affecting network KPIs (for example, the cell throughput decreases and the service drop rate increases). If PDCCH CCEs are limited, UE performance in the cell deteriorates and the network access success rate decreases.

NsaArpOverride NSA User ARP Override

Meaning: Indicates whether to change the ARP value of a bearer that is requested to be set up as indicated in the initial UE context setup request message for a UE that supports NSA networking. If this parameter is set to 0, the ARP value will not be changed. If this parameter is set to a value in the range of 1 to 15, the ARP value will be changed to the value of this parameter or the ARP value delivered by the MME, whichever is smaller. In addition, the pre-emption vulnerability is "not pre-emptable", and the pre-emption capability is "may trigger preemption". If this parameter is set to a value in the range of 16 to 30, the ARP value will be changed to the ARP value delivered by the MME or the result of the value of this parameter minus 15, whichever is smaller. In addition, the pre-emption vulnerability is "not pre-emptable", and the pre-emption capability is "may trigger preemption" regardless of the pre-emption vulnerability setting of other UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: None

Actual Value Range: 0~30

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, network performance is not affected. If this parameter is set to a non-zero value that indicates a high ARP priority, the RRC connection setup success rate increases but the number of service drops as a result of preemption also increases when the number of UEs in the cell reaches the upper limit. If this parameter is set to a non-zero value that indicates a low ARP priority, the RRC connection setup success rate decreases but the number of service drops as a result of preemption also decreases when the number of UEs in the cell reaches the upper limit.

Applicable Mode: L-FDD, L-TDD
