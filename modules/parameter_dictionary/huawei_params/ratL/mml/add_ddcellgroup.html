Add Double Deck Cell Group (ADD DDCELLGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add double deck cell groups.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId1 Local Cell 1 ID

Meaning: Indicates the ID of cell 1 in a Double Deck cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
LocalCellId2 Local Cell 2 ID

Meaning: Indicates the ID of cell 2 in a Double Deck cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
DdBandwidth Double Deck Cell Group Bandwidth

Meaning: Indicates the bandwidth of a Double Deck cell group. This parameter applies only to FDD.

GUI Value Range: BW_2DOT6M(2.6M), BW_4M(4M), BW_5DOT7M(5.7M), BW_7DOT3M(7.3M), BW_7DOT6M(7.6M), BW_10DOT8M(10.8M), BW_12DOT2M(12.2M), BW_12DOT5M(12.5M), BW_17DOT1M(17.1M), BW_17DOT4M(17.4M), BW_27DOT6M(27.6M), BW_28DOT5M(28.5M), BW_23DOT9M(23.9M), BW_8DOT6M(8.6M), BW_8DOT9M(8.9M), BW_14DOT1M(14.1M), BW_14DOT4M(14.4M), BW_18DOT7M(18.7M), BW_19M(19M)

Unit: None

Actual Value Range: BW_2DOT6M, BW_4M, BW_5DOT7M, BW_7DOT3M, BW_7DOT6M, BW_10DOT8M, BW_12DOT2M, BW_12DOT5M, BW_17DOT1M, BW_17DOT4M, BW_27DOT6M, BW_28DOT5M, BW_23DOT9M, BW_8DOT6M, BW_8DOT9M, BW_14DOT1M, BW_14DOT4M, BW_18DOT7M, BW_19M

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to BW_2DOT6M, BW_10DOT8M, BW_12DOT5M, BW_14DOT4M, BW_17DOT4M, or BW_23DOT9M, it has no impact on the throughput of a single cell. If this parameter is set to BW_4M, BW_5DOT7M, BW_7DOT3M, BW_7DOT6M, BW_12DOT2M, BW_17DOT1M, BW_27DOT6M, BW_28DOT5M, BW_8DOT6M, BW_8DOT9M, BW_14DOT1M, BW_18DOT7M, or BW_19M and RB puncture is performed in a single cell, the number of available RBs is lower than that of a standard cell with the same bandwidth, causing the uplink and downlink throughput to decrease.

Applicable Mode: L-FDD

Example

To add a DdCellGroup with the parameters as follows: Local Cell 1 ID: 6, Local Cell 2 ID: 7, Double Deck Cell Group Bandwidth: 28.5M, run the following command:
ADD DDCELLGROUP: LocalCellId1=6, LocalCellId2=7, DdBandwidth=BW_28DOT5M;
