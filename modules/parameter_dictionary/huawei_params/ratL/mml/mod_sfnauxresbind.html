Modify SFN Auxiliary eNodeB Resource Binding Relationship (MOD SFNAUXRESBIND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a single frequency network (SFN) cell binding relationship with an auxiliary eNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During the modification of the BaseBandEqmId parameter associated with an activated cell, the cell automatically resets if the BaseBandEqmId parameter value is changed to an ID representing a baseband equipment on which the cell is not established.

    A cell automatically resets during the modification of the SectorCpriCompression.

  • A cell may automatically resets during the modification of the CellBeamMode parameter.

  • Modifying the SectorEqmCombineGrpId parameter may result in cell reestablishment and service interruption.

BaseBandEqmId Baseband equipment ID

Meaning: Indicates the ID of the baseband equipment serving a cell.

When this parameter is set to 255, the baseband equipment serving a cell is not specified. In this scenario, the LTE baseband processing units (LBBPs) serving a cell are selected among all LBBPs in the eNodeB, and the LBBPs to which the cell's serving RRU is connected are preferentially selected.

When this parameter is set to a value other than 255, the cell is served by LBBPs in the specified baseband equipment, and the LBBPs to which the cell's serving RRU is connected are preferentially selected. This parameter applies only to LTE FDD and LTE TDD.

ReferenceSignalPwrMargin Reference Signal Power Margin

Meaning: Indicates the reference signal power headroom of each physical antenna.

If this parameter is set to a value other than 0, the reference signal power headroom of the cell equals this value regardless of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO set for the sector equipment of the cell. SectorCpriCompression Sector CPRI Compression

Meaning: Indicates the CPRI compression type of the sector equipment. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, or NULL. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that normal CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, and this parameter value is applicable only to LTE FDD. The parameter value 3_2_COMPRESSION indicates a compression ratio of 3.2:1, and this parameter value is applicable only to TDD cells including 2T2R, 4T4R, and 8T8R TDD cells. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than that of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cells served by the sector equipment group automatically restarts. This parameter is used only when MultiRruCellMode is set to SFN or CELL_COMBINATION. This parameter can be set on a per sector equipment group basis. When this parameter is set to NULL, the CPRI compression type of carriers depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the CPRI compression type of the sector equipment is determined by the setting of this parameter. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by RRUs in the RRU chain or ring are deactivated. Then, activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO_COMPRESSION(No Compression), NORMAL_COMPRESSION(Normal Compression), ENHANCED_COMPRESSION(Enhanced Compression), TRIPLEX_COMPRESSION_10M(Triplex Compression for 10M), 3_2_COMPRESSION(3.2 times Compression), NULL(Invalid)

Unit: None

Meaning: Indicates a virtual cell ID used for DMRS scrambling and CSI-RS pattern configuration when adaptive SFN and TM10 are enabled. This parameter needs to be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to LTE FDD.

Example

To modify SFN auxiliary eNodeB resource binding relationship with the parameters as follows: SectorEqmId: 0, eNodeBId: 110, LocalCellId: 0, ReferenceSignalPwr: 92, run the following command:
MOD SFNAUXRESBIND: SectorEqmId=0, eNodeBId=110, LocalCellId=0, ReferenceSignalPwr=92;
