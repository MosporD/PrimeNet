List M2 Configuration (LST M2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of an M2 object.

Note

None.

Parameters

ID Name Description
M2Id M2 ID

Meaning: Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the M2 object information, run the following command:
+++    HUAWEI        2013-04-25 10:49:44
O&M    #2423
%%LST M2:;%%
RETCODE = 0  Operation succeeded.

List M2 Configuration
---------------------
                M2 ID  =  0
M2 End Point Group ID  =  456
           User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

M2 ID

Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.

M2 Network Type

Indicates the type of network served by the M2 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.

M2 End Point Group ID

Indicates the ID of the endpoint group used by the M2 MO. This parameter applies only to LTE FDD and LTE TDD.

User Label

Indicates the descriptions of the M2 MO. This parameter applies only to LTE FDD and LTE TDD.
