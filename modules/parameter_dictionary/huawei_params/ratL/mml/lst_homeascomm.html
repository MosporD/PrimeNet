List Common Measurement Parameters for Handover (LST HOMEASCOMM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the common measurement parameters for handover.

Note

None.

Parameters

None.

Example

To list the configurations of common handover parameters:
LST HOMEASCOMM:;

Output Description

Field Description

GAP measurement pattern

Indicates the measurement gap pattern.

With gap-assisted measurement, the eNodeB configures periodic idle time for UEs in RRC_CONNECTED mode to measure cell signal quality on specified frequencies.

There are two gap patterns: pattern 0 and pattern 1. In pattern 0, the gap width is 6 ms and the repetition period is 40 ms. In pattern 1, the gap width is 6 ms and the repetition period is 80 ms. For details, see 3GPP TS 36.331. Pattern 0 and pattern 1 correspond to Gap Pattern Id "0" and Gap Pattern Id "1" in 3GPP TS 36.331, respectively. This parameter applies only to LTE FDD and LTE TDD.

EUTRAN RSRP filter coefficient

Indicates the upper-layer filtering coefficient for RSRP measurements on E-UTRAN.

A larger value of this parameter indicates a stronger smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

EUTRAN RSRQ filter coefficient

Indicates the upper-layer filtering coefficient for RSRQ measurements on E-UTRAN.

A larger value of this parameter indicates a stronger signal smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GERAN filter coefficient

Indicates the upper-layer filtering coefficient used for the measurement quantity in inter-RAT measurements of GERAN.

A larger value of this parameter indicates a stronger signal smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

SMeasureInd

Indicates whether the measurement threshold needs to be set. This parameter applies only to LTE FDD and LTE TDD.

SMeasure(dBm)

Indicates the threshold below which measurements on neighboring cells are started. If the signal quality of the serving cell exceeds this threshold, the UE is not required to perform intra-frequency, inter-frequency, or inter-RAT measurements, leading to reduced power consumption. This parameter applies only to LTE FDD and LTE TDD.

SpeedDependInd

Indicates whether rate-based cell handover measurement parameters need to be set. This parameter applies only to LTE FDD and LTE TDD.

TCRmax in connected mode(s)

Indicates the cycle during which evaluations of the UE medium- and high-mobility states in RRC_CONNECTED mode are performed. It is one of the key parameters in deciding on a UE's mobility state. If this parameter is set to a small value, transitions among mobility states may be frequent and the decision precision may be relatively low. If this parameter is set to a large value, transitions among mobility states are less frequent and the decision precision is relatively high. This parameter applies only to LTE FDD and LTE TDD.

TCRmaxHyst in connected mode(s)

Indicates the cycle during which evaluations of the UE normal-mobility state in RRC_CONNECTED mode are performed. It is one of the key parameters in deciding on a UE's mobility state. If this parameter is set to a small value, transitions among mobility states may be frequent and the decision precision may be relatively low. If this parameter is set to a large value, transitions among mobility states are less frequent and the decision precision is relatively high. This parameter applies only to LTE FDD and LTE TDD.

NCR Medium in connected mode

Indicates the handover number threshold used in the UE medium mobility state evaluation. If the number of handovers performed during a period of time specified by the TcrMaxConnMode parameter exceeds the value of this parameter, the UE is considered to be in medium mobility state and its handover-related parameters are adjusted. This parameter applies only to LTE FDD and LTE TDD.

NCR High in connected mode

Indicates the handover number threshold used in the UE high-mobility state evaluation. If the number of handovers performed during a period of time specified by the TcrMaxConnMode parameter exceeds the value of this parameter, the UE is considered to be in high-mobility state and its handover-related parameters are adjusted based on the UE speed. This parameter applies only to LTE FDD and LTE TDD.

TTT Scaling factor for Medium mobility state in connected mode

Indicates the scaling factor for the time-to-trigger defined for medium-mobility UEs. For a UE in medium mobility, the time-to-trigger used in event evaluation is multiplied by this scaling factor, to facilitate triggering of the handover. This parameter applies only to LTE FDD and LTE TDD.

TTT Scaling factor for High mobility state in connected mode

Indicates the scaling factor for the time-to-trigger defined for high-mobility UEs. For a UE in high mobility, the time-to-trigger used in event evaluation is multiplied by this scaling factor, to facilitate triggering of the handover. This parameter applies only to LTE FDD and LTE TDD.

UTRAN RSCP filter coefficient

Indicates the filtering coefficient for RSCP measurements on UTRAN.

A larger value of this parameter indicates a stronger smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

UTRAN ECN0 filter coefficient

Indicates the upper-layer filtering coefficient for Ec/No measurements on UTRAN.

A larger value of this parameter indicates a stronger smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Optimized Handover Prepare Fail Punish Timer(30s)

Indicates the penalty timer length for not allowing handovers (excluding MLB) to the target cell when a handover preparation fails due to optimization-related causes during handovers (including frequency-priority-based handovers, service-based handovers, SPID-based handovers back to the HPLMN, and QoE-based handovers) to the target cell. This parameter applies only to LTE FDD and LTE TDD.

Resource Handover Prepare Fail Punish Timer(s)

Indicates the penalty timer length for not allowing handovers (excluding MLB) to the target cell when a handover preparation fails due to resource-related causes during handovers (including CSFB, coverage-based, uplink-quality-based, and distance-based handovers) to the target cell. If this parameter is set to 0, no penalty is performed. This parameter applies only to LTE FDD and LTE TDD.

Non Resource Handover Prepare Fail Punish Times(time)

Indicates the number of penalty times none of the handovers is allowed to the target cell when a handover preparation fails due to non-resource-related causes on the target cell. If this parameter is set to 0, the target cell is not penalized or is penalized permanently if a handover fails due to non-resource-related causes. That is, the number of handover attempts to the target cell is unlimited. This parameter applies only to LTE FDD and LTE TDD.

Non Resource Handover Prepare Fail Retry Times(time)

Indicates the number of handover attempts to the target cell when a handover preparation fails due to non-resource-related causes on the target cell. If this parameter is set to 200, the number of handover attempts is unlimited. This parameter applies only to LTE FDD and LTE TDD.

Dedicated Gap Pattern Type

Indicates the CSFB gap-assisted measurement mode.

With gap-assisted measurement, the eNodeB configures periodic idle time for UEs in RRC_CONNECTED mode to measure cell signal quality on specified frequencies.

If the parameter is set to GAP_PATTERN_TYPE_0, the gap width is 6 ms and the repetition period is 40 ms. If the parameter is set to GAP_PATTERN_TYPE_1, the gap width is 6 ms and the repetition period is 80 ms. GAP_PATTERN_TYPE_0 maps to Gap Pattern Id "0" and GAP_PATTERN_TYPE_1 maps to Gap Pattern Id "1" in 3GPP specifications. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

SRVCC HO Failure Penalty Timer(min)

Indicates the timer length for SRVCC penalty. If SRVCC to a neighboring GERAN cell fails, the subsequent SRVCC to this cell will be prohibited throughout the time specified by this parameter. If this parameter is set to 0, the eNodeB does not impose an SRVCC penalty on the neighboring GERAN cell. This parameter applies only to LTE FDD and LTE TDD.

HO to NR Res Prep Failure Penalty Timer(s)

Indicates the penalty timer length for not allowing handovers to an NG-RAN cell when handover preparation fails due to resource-related causes during a handover to this NG-RAN cell. If this parameter is set to 0, penalty is not performed. This parameter applies only to LTE FDD and LTE TDD.
