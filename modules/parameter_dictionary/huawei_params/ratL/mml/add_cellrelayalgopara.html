Add Cell Relay Algorithm Parameter (ADD CELLRELAYALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add parameters related to the relay algorithm for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the Local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlRelaySubframeRatio Uplink Relay Subframe Ratio

Meaning: Indicates the ratio of uplink subframes used as relay subframes. The total number of subframes in each radio frame is 10. For example, the value 2/10 indicates that two uplink subframes in each radio frame are used as relay subframes. In the LTE FDD system, the number of uplink subframes used for common UEs is 8, which is the result of subtracting 2 from 10. In the LTE TDD system, the number of uplink subframes used for common UEs is calculated by subtracting the number of uplink subframes used as relay subframes from the number of uplink subframes specified by the subframe configuration. Relay subframes are preferentially scheduled for relay remote nodes (RRNs) while common subframes are preferentially scheduled for common UEs. If the relay subframes are not used up, they can be used for scheduling for common UEs and if the common subframes are not used up, they can be used for scheduling for RRNs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1_10(1/10), 2_10(2/10), 3_10(3/10), 4_10(4/10), 5_10(5/10), 6_10(6/10), 7_10(7/10), 8_10(8/10), 9_10(9/10), 10_10(10/10)

Unit: None

Actual Value Range: 1_10, 2_10, 3_10, 4_10, 5_10, 6_10, 7_10, 8_10, 9_10, 10_10

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

DlRelaySubframeRatio Downlink Relay Subframe Ratio

Meaning: Indicates the ratio of downlink subframes used as relay subframes in out-of-band relay and in-band relay scenarios. In out-of-band relay scenarios, the parameter value takes 10 (the number of subframes in one radio frame) as the denominator. For example, the value 2/10 indicates that two downlink subframes in each radio frame are used as relay subframes. In the LTE FDD system, the number of downlink common subframes is 8, which is the result of subtracting 2 from 10. In the LTE TDD system, the number of downlink common subframes is calculated by subtracting the number of downlink subframes used as relay subframes from the number of downlink subframes specified by the uplink-downlink configuration. Relay subframes are preferentially scheduled for relay remote nodes (RRNs) and common subframes are preferentially scheduled for common UEs. If the relay subframes are not used up, they can be used for scheduling for common UEs. If the common subframes are not used up, they can be used for scheduling for RRNs. In in-band relay scenarios of an LTE FDD network, the parameter value takes 40 (the total number of subframes in four radio frames) as the denominator. The value 12/40 indicates that 12 downlink subframes in four radio frames are used as relay subframes. The value range is 3/40 to 21/40. In in-band relay scenarios of an LTE TDD network, the parameter value takes 10 (the number of subframes in one radio frame) as the denominator. The value can be 1/10, 2/10, and 3/10. In in-band relay scenarios, relay subframes are preferentially scheduled for RRNs and common subframes are scheduled only for common UEs. In in-band relay scenarios of an LTE FDD network, uplink relay subframes in a cell map to downlink relay subframes in the cell and do not need to be configured. In an LTE TDD cell with uplink-downlink configuration 2, the uplink relay subframes in the cell are fixed and the ratio does not need to be configured. In out-of-band relay or in-band relay scenarios, the value 10/10 indicates that the DeNB is used for transmission only and S1 and X2 interfaces do not need to be configured. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1_10(1_10), 2_10(2_10), 3_10(3_10), 4_10(4_10), 5_10(5_10), 6_10(6_10), 7_10(7_10), 8_10(8_10), 9_10(9_10), 10_10(10_10), 3_40(3_40), 6_40(6_40), 9_40(9_40), 12_40(12_40), 15_40(15_40), 18_40(18_40), 21_40(21_40)

Unit: None

RrnPreAllocationMinPeriod Rrn Pre-Allocation Minimum Period

Meaning: Indicates the minimum interval between uplink preallocations for a relay remote node (RRN). The interval between two preallocations for the same RRN cannot be smaller than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~40

Unit: ms

Actual Value Range: 1~40

MML Default Value: 5

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a larger number of times that the eNodeB proactively schedules transmissions for the RRN. This will further lead to shorter periods for uplink packets to be buffered in the RRN, improving RRN service experience. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
RrnPreAllocationSize Rrn Pre-Allocation Size

Meaning: Indicates the uplink preallocation data volume of a relay remote node (RRN), that is, the data volume that can be transmitted during an RRN preallocation. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 45~1500

Unit: byte

Actual Value Range: 45~1500

MML Default Value: 80

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a shorter delay of uplink data transmission for RRNs and higher uplink interference. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
UlSinrAdjTargetIbler Uplink SINR Adjustment Target IBLER

Meaning: Indicates the target IBLER used in the SINR adjustment algorithm for uplink dynamic scheduling of RRNs. A larger value of this parameter leads to a greater SINR adjustment value, and therefore a higher MCS index is used. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~99

Unit: None

Actual Value Range: 0.01~0.99, step: 0.01

MML Default Value: 10

Recommended Value: 10

Parameter Relationship:

-Others:

  • It is recommended that this parameter be set to a value smaller than the default value only in scenarios where short delay and low jitter are required and the throughput is not a concern.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to smaller delay and jitter of RRNs and lower air interface throughput. A larger value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

UlEnhancedRelaySchSw Uplink Enhanced Relay Schedule Switch

Meaning: Indicates whether to enable the enhanced uplink scheduling function related to RRNs.

UlSPSDegradeSwitch: If this option is selected, the uplink SPS priority of normal UEs becomes lower than the uplink scheduling priority of RRNs in uplink relay subframes. If this option is deselected, the uplink SPS priority is not lowered. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: UlSPSDegradeSwitch(UlSPSDegradeSwitch)

Unit: None

Actual Value Range: UlSPSDegradeSwitch

MML Default Value: None

Recommended Value: UlSPSDegradeSwitch:Off

Parameter Relationship:

-Others:

  • It is recommended that the UlSPSDegradeSwitch option be selected when uplink SPS is enabled on a network.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UlSPSDegradeSwitch: If this option is selected, the uplink SPS priority of normal UEs becomes lower than the uplink scheduling priority of RRNs in uplink relay subframes, facilitating RRN scheduling.

Applicable Mode: L-FDD, L-TDD
DlEnhancedRelaySchSw Downlink Enhanced Relay Schedule Switch

Meaning: Indicates whether to enable the enhanced downlink scheduling function related to RRNs.

DlSPSDegradeSwitch: If this option is selected, downlink SPS does not take effect in downlink relay subframes. If this option is deselected, downlink SPS is not affected. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: DlSPSDegradeSwitch(DlSPSDegradeSwitch)

Unit: None

Actual Value Range: DlSPSDegradeSwitch

MML Default Value: None

Recommended Value: DlSPSDegradeSwitch:Off

Parameter Relationship:

-Others:

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DlSPSDegradeSwitch: If this option is selected, downlink SPS does not take effect in downlink relay subframes, facilitating RRN scheduling.

Applicable Mode: L-FDD, L-TDD
InBandRelayConCnt In Band Relay Concatenation Count

Meaning: Indicates the position of the RRN for the cell in a concatenation when RRNs are concatenated in in-band relay scenarios. The value NON_CON indicates that concatenation is not supported. The other values affect the subframe scheduling template. This parameter applies only to LTE FDD and LTE TDD.

Example

To add relay parameters for a cell with Local Cell ID set to 0, Uplink Relay Subframe Ratio set to (1_10)1/10, Downlink Relay Subframe Ratio set to (1_10)1/10, run the followingcommand:
ADD CELLRELAYALGOPARA: LocalCellId=0, UlRelaySubframeRatio=1_10, DlRelaySubframeRatio=1_10;
