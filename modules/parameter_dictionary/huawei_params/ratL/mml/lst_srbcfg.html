List SrbCfg (LST SRBCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the SRB configurations.

Note

None.

Parameters

None.

Example

List SrbCfg:
LST SRBCFG:;
The result is shown as follows:
+++    0        2019-12-05 08:56:05
O&M    #806355187

RETCODE = 0  Operation succeeded.

Output Description

Field Description

SRB RLC Parameter Adaptive Switch

Indicates whether to enable adaptive configuration of parameters related to Radio Link Control (RLC) on SRBs. If this parameter is set to ON, the eNodeB adaptively adjusts the SRB polling PDU retransmission timer for the eNodeB based on the timer expiration information and the number of scheduled UEs in the uplink. This aims to match the timer length and the interval at which UEs send the status report and reduces the number of invalid retransmissions due to the timer expiration. If the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected, for a small-bandwidth cell (cell with a bandwidth of 5 MHz, 3 MHz, or 1.4 MHz), the eNodeB proceeds as the SrbRlcParaAdaptSwitch parameter is set to ON regardless of the SrbRlcParaAdaptSwitch parameter setting. This parameter applies only to LTE FDD and LTE TDD.

SRB Polling Timer Adjust Step

Indicates the adjustment step of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

Preset eNodeB SRB Poll Retransmit Timer

Indicates the initial value of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. If the SrbPollTimerPreset parameter value is greater than the SrbPollTimerMaxAdjustValue parameter value, the SrbPollTimerMaxAdjustValue parameter value is taken as the initial value. It is recommended that the SrbPollTimerPreset parameter value be greater than or equal to the ENodeBPollRetransmitTimer parameter value. This parameter applies only to LTE FDD and LTE TDD.

SRB Polling Timer Adjust User Threshold

Indicates the UE number threshold for triggering the SRB RLC parameter adaptation. If the SrbRlcParaAdaptSwitch parameter is set to ON(On) and the number of UEs in a cell is greater than the SrbPollTimerAdjUserNumThd parameter value, the adaptive adjustment of the SRB polling PDU retransmission timer for the eNodeB is triggered. If the SMALL_BAND_RLC_OPT_SWITCH(SMALL_BAND_RLC_OPT_SWITCH) option of the SmallBandOptSwitch parameter is selected, this parameter does not take effect and the UE number threshold specified by the system is used. The threshold value is 75 for a 5 MHz bandwidth, 45 for a 3 MHz bandwidth, and 20 for a 1.4 MHz bandwidth. This parameter applies only to LTE FDD and LTE TDD.

RRCConnRel Maximum Retransmit Times

Indicates the maximum number of RRC Connection Release message retransmissions. This parameter applies only to LTE FDD and LTE TDD.

SRB Polling Timer Maximum Adjust Value

Indicates the maximum adjustment step of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

HO Command RRC Release Msg Retran Adp Sw

Indicates whether to optimize invalid retransmission of handover signaling and RRC release messages. The eNodeB optimizes invalid retransmission of handover signaling and RRC release messages only if this parameter is set to ON(On).
