List Configurations of Sector Split Cells (LST SECTORSPLITCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the SectorSplitCell configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of a local cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorSplitGroupId Sector Split Group ID

Meaning: Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Output Description

Field Description

Local cell ID

Indicates the ID of a local cell. This parameter applies only to LTE FDD and LTE TDD.

Sector Split Group ID

Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Index

Indicates the beam index of a cell. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Tilt(degree)

Indicates the downtilt angle corresponding to the beamforming weight for a massive MIMO cell. This parameter does not take effect for non-massive-MIMO cells and it is recommended that this parameter be set to 0 for non-massive-MIMO cells. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Azimuth Offset(degree)

Indicates the offset to the horizontal azimuth corresponding to the beamforming weight for a massive MIMO cell. The mechanical azimuth of the antenna is used as the normal line. The azimuth is a positive number for clockwise deviation from the normal line or a negative number for counterclockwise deviation from the normal line. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Power Offset(0.1dB)

Indicates the offset of the reference signal transmit power used when FDD massive MIMO (32T32R) is enabled relative to the reference signal power set for the cell using the ReferenceSignalPwr parameter. This parameter is valid only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter is selected. This parameter applies only to LTE FDD.

Cell Beam Azimuth(degree)

Indicates the horizontal azimuth corresponding to the beamforming weight for a massive MIMO cell. The mechanical azimuth of the antenna is used as the normal line. The azimuth is a positive number for clockwise deviation from the normal line or a negative number for counterclockwise deviation from the normal line. This parameter takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected and the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in the SectorSplitGroup MO is deselected. The eNodeB can generate a static beam weight file based on the beam azimuth and beam width set for the split sector. The beam azimuth is determined by the SectorSplitCell.CellBeamAzimuth parameter. If this parameter is set to 255, the beam azimuth is the sum of the azimuth configured in the sector beam weight database and the value of the SectorSplitCell.CellBeamAzimuthOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

Cell Beamwidth

Indicates the horizontal 3 dB beamwidth corresponding to the beamforming weight for a massive MIMO cell. This parameter takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected and the PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter in the SectorSplitGroup MO is deselected. The sector beamwidth is specified by the CellBeamwidth parameter in the SectorSplitCell MO. When this parameter is set to DEFAULT, the beamwidth set in the sector beam weight database is used. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Tilt Fraction Part(0.1degree)

Indicates the fractional part of the downtilt angle corresponding to the beamforming weight of a massive MIMO cell. This parameter is used together with the CellBeamTilt parameter, which indicates the integer part of the downtilt angle. The CellBeamTiltFractionPart parameter indicates the fractional part (decimal part) of the downtilt angle. This parameter is valid only for massive MIMO scenarios. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Power(0.1W)

Indicates the cell beam power. This parameter takes effect only when the POWER_ALLOCATION_SWITCH option of the SectorSplitGroup.SectorSplitSwitch parameter is selected. This parameter applies only to LTE FDD.
