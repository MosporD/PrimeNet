List QCI-specific UE Timer (LST QCIUETIMERCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of QCI-specific UE timers.

Note

None.

Parameters

ID Name Description
TimerType Timer Type

Meaning: Indicates the timer type. This parameter applies only to NB-IoT.

GUI Value Range: NB_CL0_UE_INACTIVITY_TIMER(NB_CL0_UE_INACTIVITY_TIMER), NB_CL1_UE_INACTIVITY_TIMER(NB_CL1_UE_INACTIVITY_TIMER), NB_CL2_UE_INACTIVITY_TIMER(NB_CL2_UE_INACTIVITY_TIMER), NB_T310(NB_T310), NB_N310(NB_N310), NB_T311(NB_T311), NB_N311(NB_N311)

Unit: None

Actual Value Range: NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, NB_CL2_UE_INACTIVITY_TIMER, NB_T310, NB_N310, NB_T311, NB_N311

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Output Description

Field Description

Timer Type

Indicates the timer type. This parameter applies only to NB-IoT.

QoS Class Identifier

Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203.

Timer Duration(s)

Indicates the duration of the timer. If the parameter setting is changed, the change applies only to UEs that access the network afterwards.

Max Num of UE Sync or Out-of-Sync Indication

Indicates the maximum number of consecutive synchronization or out-of-synchronization indications that a UE receives from lower layers. If the TimerType parameter is set to NB_N310, this parameter can be set to 1, 2, 3, 4, 6, 8, 10, or 20. If the TimerType parameter is set to NB_N311, this parameter can be set to 1, 2, 3, 4, 5, 6, 8, or 10. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

Millisecond-level Timer Duration(ms)

Indicates the length of the UE timer.

If the TimerType parameter is set to NB_T310, this parameter can be set to 0, 200, 500, 1000, 2000, 4000, or 8000. If the TimerType parameter is set to NB_T311, this parameter can be set to 1000, 3000, 5000, 10000, 15000, 20000, 30000, 40000, 60000, 90000, or 120000.

If the parameter setting is changed, the change applies only to UEs that access the network afterwards. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
