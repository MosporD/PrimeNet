Modify Carrier Aggregation Management Configuration (MOD CAMGTCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to carrier aggregation management.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Do not execute this command in busy hours.

  • Changing the setting of the option CaDl3CCSwitch, CaDl4CCSwitch, 2CCDlCaEnhanceSwitch, InterFddTddCaSwitch, or DlMassiveCaSwitch of the CellCaAlgoSwitch parameter from Off to On for an LTE cell for which the RbRsvType parameter in the CellRbReserve MO is set to UPLINK_MODE and the RbRsvMode parameter in the same MO is set to NB_RESERVED or NB_DEPLOYMENT may result in deactivation of this LTE cell.

  • FddTddCaDlMaxCcNum: Changing the setting of this parameter for an LTE cell for which the RbRsvType parameter in the CellRbReserve MO is set to UPLINK_MODE and the RbRsvMode parameter in the same MO is set to NB_RESERVED or NB_DEPLOYMENT may result in deactivation of this LTE cell.

CarrierMgtSwitch Carrier Management Switch

Meaning: Indicates whether to enable carrier management. If this parameter is set to ON, the eNodeB deactivates SCells for a CA UE when the traffic volume of the CA UE is small or the channel quality of the SCells is poor. If this parameter is set to OFF, an SCell is always active after being activated, unless a radio link failure (RLF) is detected on the SCell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, SCells can be deactivated based on the traffic volume of the CA UE or the channel quality of the SCells. This can reduce the UE power consumption when the UE performs no service or a few services. When the channel quality of an SCell is poor, the eNodeB deactivates the SCell for the CA UE to prevent an SCell throughput decrease due to scheduling on the SCell.

If this parameter is set to OFF, an SCell is always active after being activated, unless an RLF is detected on the SCell. In this case, a CA UE can use the SCell immediately when the traffic volume becomes large. However, the SCell throughput decreases if the eNodeB performs scheduling on the SCell with poor channel quality for the CA UE.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: CaDl3CCSwitch: If this option is selected, UEs that support downlink 3CC CA can reach higher downlink peak data rates. If this option is deselected, there are no such impacts.

CaUl2CCSwitch: If this option is selected, UEs that support uplink 2CC CA can reach higher uplink peak data rates. If this option is deselected, there are no such impacts.

CaDl4CCSwitch: If this option is selected, UEs that support downlink 4CC CA can reach higher downlink peak data rates. If this option is deselected, there are no such impacts.

InterFddTddCaSwitch: If this option is selected, UEs that support FDD+TDD CA can reach higher peak data rates. If this option is deselected, there are no such impacts.

2CCDlCaEnhanceSwitch: If this option is selected, DL ACK demodulation is enhanced, increasing the downlink throughput of UEs using CA. However, there might be an impact on the uplink, because PUCCH format 3 increases the UE transmit power. If this option is deselected, PUCCH format 1b with channel selection is used. As a result, a large number of bit errors occur, decreasing downlink throughput of CA UEs.

CaDl5CCSwitch: If this option is selected, UEs that support downlink 5CC CA can reach higher downlink peak data rates. If this option is deselected, there are no such impacts.

CaInstantlyJudgeSwitch: If this option is selected, SCell activation is more probably to be triggered. The procedure is initiated through MAC control elements, which are transmitted using MCSs with small indexes. If there are a large number of CA UEs, frequent SCell activations decrease UE throughput. However, for small-packet services such as web browsing and small-size file transfer, selecting this option ensures a higher probability of SCell activation, increasing UE throughput more quickly. If this option is deselected, the eNodeB activates SCells for a CA UE typically when the UE is downloading large-size files. This decreases the number of MAC control elements transmitted. However, there is low probability of SCell activation, causing a low UE throughput and long downloading delay.

LaaCaDlSwitch: If this option is selected, UEs that support LAA CA can reach higher peak data rates. If this option is deselected, there are no such impacts.

FddTddCaUlServiceFirstSwitch: Indicates whether to prioritize uplink services for a UE in both uplink and downlink CA states. When a UE performs CA in both the uplink and downlink in a cell, the eNodeB preferentially guarantees uplink throughput of the UE only if this option is selected.
