Display X2 Configuration (DSP X2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the control-plane configuration of X2 interfaces for which the Control Mode parameter in the X2Interface MO is set to AUTO_MODE.

Note

None.

Parameters

ID Name Description
X2Id X2 ID

Meaning: Indicates the X2 MO ID.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the information about the X2 object, run the following command: 
DSP X2:;
The result is shown as follows: 
+++    HUAWEI        2013-08-27 19:55:08
O&M    #159
%%DSP X2:;%%
RETCODE = 0  Operation succeeded.

Display X2 Configuration
------------------------
                       X2 ID  =  1
             X2 Interface ID  =  16
          X2 Interface State  =  Abnormal
   X2 Interface CP Bearer ID  =  0
X2 Interface CP Bearer State  =  Abnormal
(Number of results = 1)


---    END

Output Description

Field Description

X2 ID

Indicates the X2 MO ID.

X2 Interface ID

Indicates the X2 interface ID.

X2 Interface State

Indicates the status of the X2 interface.

X2 Interface CP Bearer ID

Indicates the ID of the CP bearer for the X2 interface.

X2 Interface CP Bearer State

Indicates the status of the CP bearer for the X2 interface.
