Display Cell MBMS Configuration (DSP CELLMBMSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the MBMS information for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the MBMS information for a cell with the local cell ID of 1, run the following command:
DSP CELLMBMSCFG: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:45:02
O&M    #806355015
%%DSP CELLMBMSCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display Cell MBMS Configuration
-------------------------------
    Local cell ID  =  1
    MBSFN Area ID  =  50
MBMS Session TMGI  =  460-98-273,460-98-275
(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

MBSFN Area ID

Indicates the ID of an MBSFN area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.

MBMS Session TMGI

Indicates the TMGI of an MBMS session. The TMGI consists of the MCC, MNC, and ServiceID with each two parts connected by a hyphen (-). TMGIs are separated by comma (,). This parameter applies only to LTE FDD and LTE TDD.
