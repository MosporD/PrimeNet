Start Cell Uplink Synchronization Check (STR CELLHLHCHK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start an uplink synchronization check for a cell.

Note

  • Digital-combination cells do not support this command.

  • When EQUIPMENT.PROTOCOL of an eNodeB is set to TDL_IR and RRUCHAIN.PROTOCOL of the RRU chain containing the RRU used by the cell is set to DEFAULT, Cell.CPRICompression of the cell must be set to NORMAL_COMPRESSION to support uplink cell data synchronization exception detection. In other scenarios, Cell.CPRICompression can be set to NORMAL_COMPRESSION or NO_COMPRESSION.

  • It takes a relatively long time to process this command. It is recommended that you run the query command 5 minutes after this command is executed.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
