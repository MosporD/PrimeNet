Remove eNodeB Function (RMV ENODEBFUNCTION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an eNodeB function.

Note

  • Before removing the eNodeBFunction MO, you need to manually remove the multiple child MOs related to configurations such as local cells, neighboring cells, S1 interfaces, X2 interfaces, and operators. Otherwise, the command execution fails.

  • After this command is executed, the eNodeB function including all radio services and commissioning and maintenance functions become unavailable. In addition, the configuration data related to the eNodeB functions will be deleted. Therefore, exercise caution when deciding to run this command.

Parameters

ID Name Description
eNodeBFunctionName eNodeB Function Name

Meaning: Indicates the name of an eNodeB function, which uniquely identifies the eNodeB function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of eNodeBFunctionName is a string of characters. The string cannot be null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes(\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

-Others:

  • Due to the limitations defined in 3GPP TS 36.413 for the S1 interface, the value of eNodeBFunctionName can contain only the following characters that comply with American Standard Code for Information Interchange (ASCII): upper-case letters (A to Z), lower-case letters (a to z), digits (0 to 9), single blank ( ), left brackets ((), right brackets ()), plus signs (+), hyphens (-), and full stops (.).Messages that an eNodeB sends to an MME contain the IE eNB Name, and the eNodeB uses the value of eNodeBFunctionName to fill the IE. All invalid characters contained in eNodeBFunctionName are replaced with hyphens (-) when an eNodeB sends messages to the MME.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove an eNodeB function named lte, run the following command: 
RMV ENODEBFUNCTION: eNodeBFunctionName="lte";
