Add eNodeB Eutran Special PCI Cell (ADD EUTRANSPEPCICELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a PCI-specific E-UTRAN cell.

Note

A maximum of 16 Eutran Special PCI Cell can be configured for an eNodeB.

Parameters

ID Name Description
DlEarfcn Downlink EARFCN

Meaning: Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) of the E-UTRAN cell with a specified physical cell identifier (PCI). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StaPhyCellId Start Physical Cell ID

Meaning: Indicates the start physical cell identifier (PCI) of E-UTRAN cells with specified PCIs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SpePhyCellIdRange Specified Physical Cell ID Range

Meaning: Indicates the number of physical cell identifiers (PCIs) of E-UTRAN cells with specified PCIs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~504

Unit: None

Actual Value Range: 1~504

MML Default Value: 1

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SpecPciGroupPolicySw Specified PCI Group Policy Switch

Meaning: Indicates the algorithm policy switch of a specified PCI group. This parameter provides the following option:

NO_HO_BASED_X2_AUTO_SETUP_SW: Indicates whether to forbid handover-based X2 self-setup to an eNodeB that serves a cell with a PCI in the specified PCI group. This function is enabled only if this option is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO_HO_BASED_X2_AUTO_SETUP_SW(NO_HO_BASED_X2_AUTO_SETUP_SW)

Unit: None

Actual Value Range: NO_HO_BASED_X2_AUTO_SETUP_SW

MML Default Value: None

Recommended Value: NO_HO_BASED_X2_AUTO_SETUP_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NO_HO_BASED_X2_AUTO_SETUP_SW: If this option is selected, X2-based handovers are affected and the UE handover delay is extended. Deselecting this option has no impact on the network.

Applicable Mode: L-FDD, L-TDD

Example

To add Eutran Specified Physical Cell ID Cell configuration
with the parameters as follows:Downlink EARFCN:3000, Start Physical Cell ID:25, Specified Physical Cell ID Range:10, run the following command:
ADD EUTRANSPEPCICELL: DlEarfcn=3000, StaPhyCellId=25, SpePhyCellIdRange=10;
