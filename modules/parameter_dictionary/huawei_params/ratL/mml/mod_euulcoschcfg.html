Modify Parameters Related to Inter-eNodeB CAMC (MOD EUULCOSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to inter-eNodeB CAMC, such as the delay for coordinated information to take effect.

Note

None.

Parameters

ID Name Description
UlInterEnbCamcSw UL Inter eNodeB Coordinated AMC Switch

Meaning: Indicates whether to enable inter-eNodeB coordinated uplink AMC in the centralized Cloud BB networking. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(off)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to ON, inter-eNodeB coordinated uplink AMC is enabled for uplink MCS index selection. In this way, the eNodeB can estimate the interference and SINR based on the actual scheduling condition of the coordinating cluster, leading to more accurate MCS index selection. In addition, the cell data throughput, UE data throughput, uplink coverage, PUSCH coverage, and user-perceived rate increase in interference fluctuation scenarios. Greater interference fluctuation leads to larger gains. No gains are expected in scenarios with no interference or with steady interference.

If this parameter is set to OFF, inter-eNodeB coordinated uplink AMC is disabled, and the network performance is not affected.

Applicable Mode: L-TDD

Example

Modify Parameters Relationed To Inter-eNodeB CAMC 
MOD EUULCOSCHCFG:UlInterEnbCamcSw=ON;
