Modify Parameter Group for RLF Timer and Constants (MOD RLFTIMERCONSTGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a parameter group related to RLF timer and constants.

Note

None.

T301CE CE Timer 301

Meaning: Indicates the length of the timer 301 in coverage enhancement mode. For details, see 3GPP TS 36.331.

This timer is started when the UE sends the RRCConnectionReestabilshmentRequest message.

Before the timer expires, it is stopped if the UE receives an RRCConnectionReestablishment or RRCConnectionReestablishmentReject message.

After the timer expires, the UE enters the RRC_IDLE state. This option applies only to LTE FDD and LTE TDD.

T310CE Timer 310 in CE Mode

Meaning: Indicates the length of the timer T310 of the cell in coverage enhancement (CE) mode. For details, see 3GPP TS 36.331.

This timer is started for a UE when the UE detects a fault at the physical layer.

The timer is stopped if the UE detects the physical layer fault recovery, triggers a handover procedure, or initiates a reestablishment before the timer expires.

After the timer expires, the UE enters the RRC_IDLE state if the security mode is not activated. Otherwise, an RRC connection reestablishment is initiated. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MS0_T310(0ms), MS50_T310(50ms), MS100_T310(100ms), MS200_T310(200ms), MS500_T310(500ms), MS1000_T310(1000ms), MS2000_T310(2000ms), MS4000_T310(4000ms), MS6000_T310(6000ms)

Unit: None

Actual Value Range: MS0_T310, MS50_T310, MS100_T310, MS200_T310, MS500_T310, MS1000_T310, MS2000_T310, MS4000_T310, MS6000_T310

MML Default Value: None

Recommended Value: MS1000_T310CE(1000ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
T311CE Timer 311 in CE Mode

Meaning: Indicates the length of the timer T311 of the cell in coverage enhancement (CE) mode. For details, see 3GPP TS 36.331.

This timer is started when the UE starts an RRC connection reestablishment.

The timer is stopped if the UE selects an E-UTRAN or inter-RAT cell to camp on before the timer expires.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MS1000_T311(1000ms), MS3000_T311(3000ms), MS5000_T311(5000ms), MS10000_T311(10000ms), MS15000_T311(15000ms), MS20000_T311(20000ms), MS30000_T311(30000ms)

Unit: None

Example

To modify a RLF timer and constants group as follows: Local Cell ID: 0, RLF timer and constants group ID: 0, timer 301: MS200_T301, run the following command:
MOD RLFTIMERCONSTGROUP: LocalCellId=0, RlfTimerConstGroupId=0, T301=MS200_T301;
