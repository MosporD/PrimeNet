List Configurations of Parameters for Neighboring Cell SRS Measurements (LST NCELLSRSMEASPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list settings of parameters related to SRS automatic neighboring cell measurement of specified cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell Id

Meaning: Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of SRS measurements on neighboring cells:
LST NCELLSRSMEASPARA:;
The result is shown as follows:
+++    0        2019-12-05 17:36:01
O&M    #806356111
%%LST NCELLSRSMEASPARA: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local Cell Id

Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

SRS Auto Neighbour Cell Measurement Switch

Indicates whether a cell supports SRS automatic neighboring cell measurements. If this parameter is set to ON(On), the UlHetnetCompOnUlRsrpSw and UlHetnetCompManualNcellCfgSw options of the UplinkCompSwitch parameter do not take effect. This parameter applies only to LTE FDD and LTE TDD.

SRS or DMRS Auto Neighbour Cell Measurement A3 Offset(0.5dB)

Indicates the offset for events related to the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter requires better signal quality of a neighboring cell for sending measurement reports of the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. SRS automatic neighboring cell measurement applies to LTE FDD and LTE TDD. DMRS neighboring cell measurement applies only to LTE FDD.

Neighbouring Cell Measurement Switch

Indicates whether to enable neighboring cell measurement algorithms.

NcellDmrsMeasSwitch: Indicates whether to enable DMRS measurement for neighboring cells. If this option is selected, DMRS measurement is enabled for neighboring cells. If this option is deselected, DMRS measurement is disabled for neighboring cells. When this option is selected, the setting of the SrsAutoNCellMeasSwitch parameter does not take effect. This option applies only to LTE FDD and NB-IoT.

NcellSrsTimeMeasSwitch: Indicates whether to enable time-domain measurement of SRSs from neighboring cells. If this option is selected, the eNodeB supports time-domain measurement of SRSs from neighboring cells. If this option is deselected, the eNodeB does not support time-domain measurement of SRSs from neighboring cells and supports only frequency-domain measurement of the SRSs. This option takes effect only if measurement of SRSs from neighboring cells is triggered. Such measurement can be triggered by UL CoMP or automatic measurement of SRSs from neighboring cells (controlled by the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO). This option applies only to LTE TDD.
