Add S1 Configuration (ADD S1)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an S1 object.

Note

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in S1 or X2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in S1 or X2 MOs cannot overlap.

  • When the eNodeB works in independent mode or in RAN sharing with common carriers mode, IP addresses configured in the SCTPPEER MOs belong to the EPGROUP MOs referenced by the CpEpGroupId parameter in different S1 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the S1 or ECO MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the S1 MOs or the M1EpGroupId parameter in the M1 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the S1 or ECO MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in S1 or EX2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in S1 or EX2 MOs cannot overlap.

  • The EPGROUP MO referenced by CpEpGroupId in an S1 MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an S1 MO and the EPGROUP MO referenced by the IUB, ABIS, or uX2 MO must be different.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the S1 MOs or the M2EpGroupId parameter in the M2 MOs cannot overlap.

  • If the value of the CnOpSharingGroupId parameter in an S1 MO is not set to the invalid value 255, ensure that the associated CnOpSharingGroup MO has been added before adding the S1 MO and the operator to which the S1 MO belongs is in the carrier-sharing operator group. In hybrid RAN sharing mode, the CnOpSharingGroup MO referenced by the S1 MO must be configured and the CnOpSharingGroupId parameter must be set to a valid value.

Meaning: Indicates whether the MME at the other end of the S1 interface supports Huawei-proprietary positioning procedures, which are included in minimization of drive tests (MDT). The value ENABLE(enable) indicates the opposite. For an S1 interface that is automatically set up, the MdtEnable parameter value in the MmefeatureCfg MO is obtained from the MdtEnable parameter in the S1 MO. This parameter applies only to LTE FDD and LTE TDD.

Example

To add an S1 object with the parameters as follows: S1 ID: 0, CN Operator ID: 0, End Point Config Flag: CP_UP_CFG, Control Plane End Point Group ID: 123, User Plane End Point Group ID: 123,and other parameters set to the default values, run the following command:
ADD S1: S1Id=0, CnOperatorId=0, EpGroupCfgFlag=CP_UP_CFG, CpEpGroupId=123, UpEpGroupId=123;
