List External NR Cell (LST NREXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query external NR cells.

Note

This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of the external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Output Description

Field Description

Mobile Country Code

Indicates the mobile country code of the external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile Network Code

Indicates the mobile network code of the external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

gNodeB ID

Indicates the ID of the gNodeB serving the external NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

Cell ID

Indicates the cell ID of an external NR cell served by a gNodeB. It uniquely identifies an NR cell in the gNodeB. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

Downlink ARFCN

Indicates the downlink SSB ARFCN of an external NR cell. For details, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.

Uplink ARFCN Configuration Indicator

Indicates whether to configure the uplink ARFCN. If the uplink ARFCN does not need to be configured, the system calculates the uplink ARFCN based on the default spacing between transmit (TX) and receive (RX) frequencies defined in 3GPP specifications. This parameter applies only to LTE FDD and LTE TDD.

Uplink ARFCN

Indicates the uplink ARFCN of an external NR cell. This parameter applies only to LTE FDD and LTE TDD.

Physical Cell ID

Indicates the physical cell identifier of an external NR cell. For details, see 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD.

Tracking Area Code

Indicates the tracking area code (TAC) of an external NR cell. It is used to form a tracking area identifier (TAI) with the PLMN. The value 4294967295 is an invalid value. This parameter will be set to this invalid value when ANR adds neighboring NR cells that support only the NSA architecture. For details, see 3GPP TS 38.300. This parameter applies only to LTE FDD and LTE TDD.

Aggregation Attribute

Indicates the aggregation attributes of an external NG-RAN cell.

CONTROL_MODE_FLAG: If this option is deselected, this MO can be modified or removed by users but cannot be modified or removed by ANR. A failure message is displayed when a user adds an existing MO (with identical keywords). If this option is selected, this MO can be modified or removed by both ANR and users. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both ANR and users. If an existing MO is added, the MO is actually modified when a user adds this MO. An existing MO cannot be added by ANR. This option is selected by default for objects automatically created by ANR. Users can either select or deselect this option when they create objects. This option applies only to LTE FDD and LTE TDD.

ROAMING_AREA_HANDOVER_FLAG: Indicates whether to allow handover to the neighboring cell during roaming. This option takes effect when the SPID_BASED_HO_BACK_TO_HPLMN_SW option of the EnodebAlgoExtSwitch.NrHandoverAlgoSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.

Master PLMN Reserved Flag

Indicates whether to reserve the master PLMN of an external NR cell. The default value is FALSE.

The value TRUE indicates that the master PLMN of an external NR cell is reserved. UEs of the master PLMN cannot select the cell as the target cell.

The value FALSE indicates that UEs of the master PLMN can select the cell as the target cell. This parameter applies only to LTE FDD and LTE TDD.

NR Networking Option

Indicates the architecture option of an NR cell. The value UNLIMITED indicates that the cell is in its initial state, that is, the cell is in unlimited mode. The value SA indicates that the cell works in SA networking mode. The value NSA indicates that the cell works in NSA networking mode. The value SA_NSA indicates that the cell can work in both SA and NSA networking modes. This parameter applies only to LTE FDD and LTE TDD.

Frequency Band

Indicates the frequency band in which the external NR cell is operating. The parameter value NULL indicates that no frequency band is configured for the external cell. For details about parameter usage, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.

Additional Frequency Band

Indicates an additional frequency band of the external NR cell. If this parameter is set to NULL, no additional frequency band is configured for the external NR cell. For details about parameter usage, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.
