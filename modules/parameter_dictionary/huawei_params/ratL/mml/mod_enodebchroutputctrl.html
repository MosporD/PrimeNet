Modify eNodeB CHR Output Control Settings (MOD ENODEBCHROUTPUTCTRL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the eNodeB call history record (CHR) output control settings.

Note

The value of the SIGOutputMode parameter can be changed only after all related SIG events are unsubscribed.

Parameters

ID Name Description
CHRUpLoadingTimeSwitch CHR UpLoading Time Switch

Meaning: Indicates the time when CHRs are uploaded. If this parameter is set to FIXED_TIME, CHRs are uploaded at a fixed time based on the standard time. If this parameter is set to NON_FIXED_TIME, CHRs are uploaded at a specific interval since system startup.

GUI Value Range: FIXED_TIME(Fixed Time), NON_FIXED_TIME(Non-Fixed Time)

Unit: None

Actual Value Range: FIXED_TIME, NON_FIXED_TIME

MML Default Value: None

Recommended Value: FIXED_TIME

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SIGOutputMode SIG Output Mode

Meaning: Indicates the mode of exporting periodically exported UE-level SIG events. (This parameter does not apply to non-periodically exported UE-level SIG events, periodically exported UE-level SIG events with instantaneous values, or cell-level SIG events.) If this parameter is set to ALL_OUTPUT(ALL_OUTPUT), the eNodeB exports UE-level SIG events periodically and upon bearer or UE release. If this parameter is set to PERIOD_OUTPUT(PERIOD_OUTPUT), the eNodeB exports UE-level SIG events periodically and does not export such events upon bearer or UE release.

GUI Value Range: ALL_OUTPUT(All Output), PERIOD_OUTPUT(Period Output)

Unit: None

Actual Value Range: ALL_OUTPUT, PERIOD_OUTPUT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Compared with the value PERIOD_OUTPUT(PERIOD_OUTPUT), the value ALL_OUTPUT(ALL_OUTPUT) leads to higher CPU usage. High CPU usage causes deterioration of cell and UE throughput and access and packet delays.

Applicable Mode: L
ChrOutputCtrlSwitch CHR Output Control Switch

Meaning: Indicates the switches that control the output of CHR and SIG logs of the eNodeB.

STMSI_MASK_SW: If this option is selected, S-TMSI mask enabled. With this function, all S-TMSIs in internal and external CHRs are replaced by 0. If this option is deselected, this function is disabled.

PUBLIC_TRC_ALIGN_SW: Indicates whether to align the output of the external CHR event PUBLIC INFO with the output of TRC logs. If this option is selected, the alignment is enabled. If this option is deselected, the alignment is disabled.

PUBLIC_SIG_ALIGN_SW: Indicates whether to align the output of the external CHR event PUBLIC INFO with the output of the periodic event of SIG logs. If this option is selected, the alignment is enabled. If this option is deselected, the alignment is disabled.

AOA_REPORT_SW: Indicates whether to enable the reporting of the angle of arrival (AoA) of UE signals received at the eNodeB. If this option is selected, AoA reporting is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE FDD.

GUI Value Range: STMSI_MASK_SW(STMSI_MASK_SW), PUBLIC_TRC_ALIGN_SW(PUBLIC_TRC_ALIGN_SW), PUBLIC_SIG_ALIGN_SW(PUBLIC_SIG_ALIGN_SW), AOA_REPORT_SW(AOA_REPORT_SW)

Unit: None

Actual Value Range: STMSI_MASK_SW, PUBLIC_TRC_ALIGN_SW, PUBLIC_SIG_ALIGN_SW, AOA_REPORT_SW

MML Default Value: None

Recommended Value: STMSI_MASK_SW:Off, PUBLIC_TRC_ALIGN_SW:Off, PUBLIC_SIG_ALIGN_SW:Off, AOA_REPORT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: AOA_REPORT_SW: If this option is selected and the PERIOD_PRIVATE_AOA_MR event is subscribed to on the OSS, the CPU usage of the BBP increases and the random access success rate decreases. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To modify the time when call history record (CHR) uploaded as follows: FIXED_TIME , run the following command:
MOD ENODEBCHROUTPUTCTRL: CHRUpLoadingTimeSwitch=FIXED_TIME;
