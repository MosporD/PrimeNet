Modify UL Guardband Configurations (MOD ULGUARDBANDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify UL guardband configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
HighFreqGuardBand High Frequency Guard Band

Meaning: Indicates the NB-IoT high frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.

GUI Value Range: 0~47

Unit: 3.75kHz

Actual Value Range: 0~176.25

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter leads to less impact caused by non-orthogonal subcarriers and larger impact on the uplink capacity.

A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-NB-IOT
LowFreqGuardBand Low Frequency Guard Band

Meaning: Indicates the NB-IoT low frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.

GUI Value Range: 0~47

Unit: 3.75kHz

Actual Value Range: 0~176.25

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • The value of the LowFreqGuardBand parameter in the UlGuardBandCfg MO must be less than or equal to 12.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter leads to less impact caused by non-orthogonal subcarriers and larger impact on the uplink capacity.

A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-NB-IOT
NprachNpuschGuardBand Guard Band Between NPRACH and NPUSCH

Meaning: Indicates the width of the guard band between the NPRACH and NPUSCH. This parameter applies only to NB-IoT.

GUI Value Range: 0~4

Unit: 3.75kHz

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter leads to a smaller impact caused by non-orthogonal subcarriers and a larger impact on the uplink capacity. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-NB-IOT

Example

To modify the configuration of UlGuardBandCfg, local cell ID is 1, PRB ID is 1, High Frequency Guard Band is 0, Low Frequency Guard Band is 0, run the following command:
MOD ULGUARDBANDCFG: LocalCellId=1, PrbId=1, HighFreqGuardBand=0, LowFreqGuardBand=0;
The result is shown as follows:
