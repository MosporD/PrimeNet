Add Operator Configuration for Serving Cell in UTRAN Frequency (ADD UTRANNFREQSCELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an operator-specific configuration for the UTRAN frequency.

Note

  • Cell reselection priorities based on operators of the local cell (which are specified in the NrNFreqSCellOp, EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, and Cdma2000BcSCellOp MOs) cannot coexist with cell reselection priorities based on operators of neighboring frequencies (which are specified in the EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs).

  • Cell reselection priorities specified in the EutranNFreqSCellOp and UtranNFreqSCellOp MOs for the same operator cannot be the same.

  • Cell reselection priorities specified in the GeranNFGroupSCellOp and UtranNFreqSCellOp MOs for the same operator cannot be the same.

  • Cell reselection priorities specified in the UtranNFreqSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

  • CnOperatorId in a UtranNFreqSCellOp MO must have been set in the associated CnOperator MO.

  • Before running this command, ensure that the associated neighboring UTRAN frequency has been configured.

  • If the operating frequency range of a UTRAN FDD neighboring cell belongs to multiple frequency bands, add the operator sharing information for each UTRAN DL ARFCN corresponding to each frequency band. Other configuration parameters must be the same except for UTRAN DL ARFCN and UTRAN UL ARFCN.

  • Cell reselection priorities specified in the NrNFreqSCellOp and UtranNFreqSCellOp MOs for the same operator cannot be the same.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UtranDlArfcn Downlink UARFCN

Meaning: Indicates the downlink UARFCN of the neighboring UTRAN frequency. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16383

Unit: None

Actual Value Range: 0~16383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOperatorID Cn operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellReselDediPriCfgInd Cell reselection dedicated priority configure indicator

Meaning: Indicates whether to configure a dedicated cell-reselection priority based on the PLMN ID of the local cell for the UTRAN frequency. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: NOT_CFG(Not configure)

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellReselDediPri Cell reselection dedicated priority

Meaning: Indicates the dedicated cell reselection priority for a UTRAN frequency based on the PLMN ID of the local cell. The value 0 indicates the lowest priority. If the related SPID configuration is specified, set this priority to the one specified in the SPID configuration. If no related SPID configuration is specified but this parameter is set, the eNodeB delivers the cell reselection priorities of all PLMNs supported by a UE by using the IE idleModeMobilityControlInfo in an RRC Connection Release message to the UE. If no related SPID configuration is specified and this parameter is not set, a UE uses the cell reselection priority of the neighboring UTRAN frequency, which is broadcast in the system information. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of CellReselDediPriCfgInd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an operator configuration for serving cell in UTRAN frequency with the parameters as follows:Local cell ID:0, Downlink UARFCN:1234, Cn operator ID:3, Cell reselection dedicated priority configure indicator:CFG, Cell reselection dedicated priority:1, run the following command:
ADD UTRANNFREQSCELLOP: LocalCellId=0, UtranDlArfcn=1234, CnOperatorID=3, CellReselDediPriCfgInd=CFG, CellReselDediPri=1;
