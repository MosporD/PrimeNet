Add PCC Frequency Configuration (ADD PCCFREQCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a candidate primary component carrier (PCC).

Note

If the SMART_CARRIER_SELECTION_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is deselected, the number of PCCs cannot exceed nine.

If the SMART_CARRIER_SELECTION_SW option of the MultiCarrierUnifiedSchSw parameter in the MultiCarrUnifiedSch MO is selected, the number of PCCs cannot exceed sixteen.

Parameters

ID Name Description
PccDlEarfcn PCC Downlink EARFCN

Meaning: Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the candidate PCC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PccDlEarfcn in a PccFreqCfg MO must be a valid frequency.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PreferredPccPriority Preferred PCC Priority

Meaning: Indicates the PCC priority of a frequency. A small value of this parameter leads to a low PCC priority of a carrier working on the frequency specified by the PCCDlEarfcn parameter in the PccFreqCfg MO for the carrier to be selected as the PCC for CA UEs. A large value of this parameter leads to a high PCC priority of a carrier working on the frequency specified by the PCCDlEarfcn parameter for the carrier to be selected as the PCC for CA UEs. This parameter takes effect when the IdleModePccAnchorSwitch, PccAnchorSwitch, or EnhancedPccAnchorSwitch option of the CaAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If a CA UE accesses a cell on the frequency specified by the PccDlEarfcn parameter in the PccFreqCfg MO but the PreferredPccPriority parameter specifies a higher priority for another cell, a handover to the other cell will be triggered. This increases the number of handovers.

Applicable Mode: L-FDD, L-TDD
PccA4RsrpThd PCC A4 RSRP Threshold

Meaning: Indicates the reference signal received power (RSRP) threshold for triggering event A4 during higher-priority carrier evaluation for PCC selection. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: -105

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of a CA UE camping on the local cell and less impact on network performance. A smaller value of this parameter results in a higher probability of triggering event A4 and a larger number of handover failures caused by incorrect handover evaluations.

Applicable Mode: L-FDD, L-TDD
PccA4RsrqThd PCC A4 RSRQ Threshold

Meaning: Indicates the reference signal received quality (RSRQ) threshold for triggering event A4 during higher-priority carrier evaluation for PCC selection in scenarios where CA is configured based on frequencies. If the measured RSRQ of an inter-frequency neighboring cell in the CA group is greater than this parameter value, the CA UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -40~-6

Unit: 0.5dB

Actual Value Range: -20~-3

MML Default Value: -20

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of a CA UE camping on the local cell and less impact on network performance. A smaller value of this parameter results in a higher probability of triggering event A4 and a larger number of handover failures caused by incorrect handover evaluations.

Applicable Mode: L-FDD, L-TDD
NsaPccAnchoringPriority NSA PCC Anchoring Priority

Meaning: Indicates the NSA DC PCC anchoring priority. A larger value of this parameter indicates a higher priority. If this parameter is set to 0, this frequency cannot be selected as a target frequency for NSA DC PCC anchoring. The setting of this parameter is valid only if the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcAlgoSwitch parameter in the NsaDcMgmtConfig MO is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: 1

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NsaDcPccA4RsrpThld NSA DC PCC A4 RSRP Threshold

Meaning: Indicates the RSRP threshold for event A4 related to NSA DC PCC anchoring. If the measured RSRP of an inter-frequency neighboring cell is greater than this parameter value, the NSA DC UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: -105

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering PCC anchoring. A smaller value of this parameter results in a higher probability of triggering PCC anchoring and a higher probability of triggering a coverage-based handover for a UE from a cell after the UE is handed over to the cell.

Applicable Mode: L-FDD, L-TDD
NsaDcPccA4RsrqThld NSA DC PCC A4 RSRQ Threshold

Meaning: Indicates the RSRQ threshold for event A4 related to NSA DC PCC anchoring. If the measured RSRQ of an inter-frequency neighboring cell is greater than this parameter value, the NSA DC UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -40~-6

Unit: 0.5dB

Actual Value Range: -20~-3

MML Default Value: -20

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a PCC Downlink EARFCN with the parameters as follows: PCC Downlink EARFCN: 2950, run the following command:
ADD PCCFREQCFG: PccDlEarfcn=2950;
