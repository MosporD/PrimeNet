Remove Previous Registration Parameter with CDMA2000HRPD (RMV CDMA2000HRPDPREREG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the neighboring relation with a CDMA2000 HRPD cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the CDMA2000 high rate packet data (HRPD) pre-registration parameter.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an Cdma2000HrpdPreReg MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the CDMA2000 high rate packet data (HRPD) pre-registration parameter.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in an Cdma2000HrpdPreReg MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the Previous Registration Parameter with CDMA2000 HRPD with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "01", run the following command:
RMV CDMA2000HRPDPREREG: LocalCellId=0, Mcc="460", Mnc="01";
