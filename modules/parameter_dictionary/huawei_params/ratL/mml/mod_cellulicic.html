Modify Cell UL ICIC Algorithm Configuration (MOD CELLULICIC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the cell UL ICIC algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandMode Uplink band division scheme

Meaning: Indicates the band division scheme used in uplink ICIC. The band division in the cell is changed according to the setting of this parameter so that the edge bands do not overlap between neighboring cells. If this parameter is set to INVALID, the cell does not distinguish center and edge bands. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MODE1(UL band division scheme No.1), MODE2(UL band division scheme No.2), MODE3(UL band division scheme No.3), INVALID(Invalid UL band division scheme)

Unit: None

Actual Value Range: MODE1, MODE2, MODE3, INVALID

MML Default Value: None

Recommended Value: If this parameter is not set to INVALID(Invalid UL band division scheme), it is recommended that this parameter be set to different values in neighboring cells. If it is impossible for neighboring cells to use mutually different band modes, it is recommended that this parameter be set to the same value in neighboring cells that has the weakest interference to each other.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of the cell UL ICIC band division with the parameters as follows: Local cell ID: 0, Uplink band division scheme: MODE1, run the following command:
MOD CELLULICIC: LocalCellId=0, BandMode=MODE1;
