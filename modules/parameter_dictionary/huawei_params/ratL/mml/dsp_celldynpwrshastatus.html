Display Cell Dynamic Power Sharing Status (DSP CELLDYNPWRSHASTATUS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of dynamic power sharing in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the operating status of dynamic power sharing of a cell:
DSP CELLDYNPWRSHASTATUS:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sector Equipment Type

Indicates the sector equipment type: sector equipment or sector equipment group. This parameter applies only to LTE FDD and LTE TDD.

Sector Equipment ID

Indicates the ID of sector equipment or a sector equipment group. This parameter applies only to LTE FDD and LTE TDD.

LTE Dynamic Power Sharing Status

Indicates whether dynamic power sharing between LTE carriers has been enabled in the cell. This parameter applies only to LTE FDD and LTE TDD.

LTE Dynamic Power Sharing Remark

Indicates the reason why dynamic power sharing between LTE carriers has not been enabled in the cell. This parameter applies only to LTE FDD and LTE TDD.

LTE Extreme Power Sharing Status

Indicates the status of LTE extreme power sharing. This parameter applies only to LTE FDD.

LTE Extreme Power Sharing Remark

Indicates the reason why LTE extreme power sharing is disabled. This option applies only to LTE FDD.

UMTS LTE Dynamic Power Sharing Status

Indicates whether dynamic power sharing between LTE and UMTS carriers has been enabled in the cell. This parameter applies only to LTE FDD.

UMTS LTE Dynamic Power Sharing Remark

Indicates the reason why dynamic power sharing between LTE and UMTS carriers has not been enabled in the cell. This parameter applies only to LTE FDD.

NR LTE Dynamic Power Sharing Status

Indicates whether dynamic power sharing between LTE and NR has been enabled in the cell. This parameter applies only to LTE TDD.

NR LTE Dynamic Power Sharing Remark

Indicates the reason why dynamic power sharing between LTE and NR has not been enabled in the cell. This parameter applies only to LTE TDD.
