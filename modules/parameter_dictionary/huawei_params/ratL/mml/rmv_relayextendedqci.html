Remove an extended QCI of relay features (RMV RELAYEXTENDEDQCI)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to delete a record of RelayExtendedQci data. The execution of the RMV RELAYEXTENDEDQCI command with the PQ Type parameter set to L2OM takes effect only after the RRN connection is reestablished.

Note

None.

Parameters

ID Name Description
ExtendedQci Extended QoS Class Indication

Meaning: Indicates the extended QCI of an E-RAB on an RRN. After an RRN successfully accesses the network, the eNodeB sets up a bearer with the extended QCI specified by this parameter for the RRN. QCIs 65, 66, 69, 70, 75, and 79 are standardized QCIs, and therefore values 65, 66, 69, 70, 75, and 79 are not recommended for this parameter. Otherwise, services of these QCIs are affected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 10~254

Unit: None

Actual Value Range: 10~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To delete an extended QCI of relay features, Configuration as follows: Extended QoS Class Indication:10, run the following command:
RMV RELAYEXTENDEDQCI: ExtendedQci=10;
