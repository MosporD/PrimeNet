List Configurations of Coverage-Level-Specific Uplink Scheduling for PRBs (LST PRBULSCHCEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list coverage-level-specific parameters related to the uplink scheduling algorithm for PRB carriers of an NB-IoT cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.

Unit: None

MML Default Value: None

Recommended Value: None

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbId PRB ID

Meaning: Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
CoverageLevel Coverage Level

Meaning: Indicates the coverage level of a UE. The value COVERAGE_LEVEL_0 indicates 0 dB coverage enhancement, value COVERAGE_LEVEL_1 indicates 10 dB coverage enhancement, and value COVERAGE_LEVEL_2 indicates 20 dB coverage enhancement. This parameter applies only to NB-IoT.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2)

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.

PRB ID

Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.

Coverage Level

Indicates the coverage level of a UE. The value COVERAGE_LEVEL_0 indicates 0 dB coverage enhancement, value COVERAGE_LEVEL_1 indicates 10 dB coverage enhancement, and value COVERAGE_LEVEL_2 indicates 20 dB coverage enhancement. This parameter applies only to NB-IoT.

Uplink Initial MCS

Indicates the initial uplink MCS index for a UE at a coverage level. For details about MCS indexes, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

UL Initial Transmission Repetition Count

Indicates the number of repeated initial transmissions in the uplink at a coverage level. This parameter applies only to NB-IoT.

ACK/NACK Transmission Repetition Count

Indicates the number of uplink repetitions of ACK/NACK responses to downlink transmissions at a coverage level. This parameter applies only to NB-IoT.

Msg4 ACK/NACK Trans Repetition Count

Indicates the number of ACK/NACK responses to MSG4 at a coverage level. This parameter applies only to NB-IoT.

NB-IoT Logical Channel SR Prohibit Timer

Indicates the logical channel prohibition timer for a UE. This timer starts when the corresponding UE initiates service requests, prohibiting the UE from initiating service requests until it expires. The eNodeB configures this timer for a UE through an RRCConnectionSetup message. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

NB-IoT BSR Retransmission Timer

Indicates the length of the NB-IoT buffer status report (BSR) retransmission timer. This timer is started when an NB-IoT UE sends a BSR. This parameter applies only to NB-IoT.

Initial Msg3 MCS

Indicates the index of the MCS used for the transmission of Msg3 from UEs at a certain coverage level. For details about MCSs, see 3GPP TS 36.213. This parameter applies only to NB-IoT.

Proportion of Uplink Scheduling Duration(%)

Indicates the proportion of uplink scheduling duration for a specific coverage level. This parameter is used to control how frequently uplink scheduling is performed. This parameter applies only to NB-IoT.

Uplink SPS Extended Inactivity Timer

Indicates the length of the extended inactivity timer used in uplink semi-persistent scheduling. After the eNodeB receives an updated BSR from a UE for which semi-persistent scheduling has been activated and the uplink semi-persistent scheduling inactivity timer (specified by UlSpsInactivityTimer in the PrbUlSchCeAlgo MO) has not expired, the eNodeB extends the semi-persistent scheduling inactivity timer for the UE. For example, if this parameter is set to 1, the actual length of the extended inactivity timer for uplink semi-persistent scheduling is 1 multiplied by the value of the UlSpsInterval parameter in the PrbUlSchCeAlgo MO. This parameter applies only to NB-IoT.

Uplink SPS Inactivity Timer

Indicates the length of the inactivity timer used for uplink semi-persistent scheduling. The eNodeB starts this timer after uplink semi-persistent scheduling is activated for a UE. When the timer expires, uplink semi-persistent scheduling is deactivated. If this parameter is set to 0, the timer length is infinite. If this parameter is set to 255, uplink semi-persistent scheduling does not take effect. The effective value range of this parameter is 2 to 160. For example, if this parameter is set to 2, the actual timer length is the result of 2 multiplied by the value of the UlSpsInterval parameter in the PrbUlSchCeAlgo MO. This parameter applies only to NB-IoT.

Uplink SPS Interval

Indicates the interval at which uplink semi-persistent scheduling is performed. This parameter applies only to NB-IoT.

EDT Max TBS(bit)

Indicates the maximum TBS that can be used for the scheduling of Msg3 for EDT initiated by UEs at a specific coverage level. This parameter is valid only for the anchor carrier. For details, see 3GPP TS 36.213. This parameter applies only to NB-IoT.

EDT Msg3 MCS

Indicates the index of the MCS used in the scheduling of Msg3 for EDT initiated by UEs at a specific coverage level. For details, see 3GPP TS 36.213. This parameter applies only to NB-IoT.

EDT UL Transmission Repetition Count

Indicates the number of repetitions of Msg3 for EDT initiated by UEs at a specific coverage level. This parameter applies only to NB-IoT.
