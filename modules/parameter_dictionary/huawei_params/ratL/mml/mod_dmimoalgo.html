Modify D-MIMO Algorithm Configuration (MOD DMIMOALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify D-MIMO algorithm configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
DmimoA3RsrpOffset D-MIMO A3 RSRP Offset

Meaning: Indicates the threshold of the RSRP difference between a neighboring cell and the serving cell to trigger event A3 report for inter-cell D-MIMO when the neighboring cell has better signal quality than the serving cell. A large value of this parameter indicates that neighboring cells must have better signal quality to trigger measurement reporting for inter-cell D-MIMO. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the eNodeB performs UE attribute determination for a large number of UEs, a large number of UEs are identified as joint transmission UEs, and the experience rate of CEUs increases by a large margin, but the signaling overhead used for event A3 report increases. If this parameter is set to a large value, the eNodeB performs UE attribute determination for a small number of UEs, a small number of UEs are identified as joint transmission UEs, and the experience rate of CEUs increases by a small margin. If this parameter is set to a value greater than the RSRP difference threshold used to trigger handovers, the eNodeB performs handovers before UE attribute determination is triggered. In this case, no UEs are identified as joint transmission UEs.

Applicable Mode: L-TDD
DmimoJtCellRsrpDiffThld D-MIMO JT Cell RSRP Difference Threshold

Meaning: Indicates the RSRP difference threshold for D-MIMO joint transmission UEs in selecting coordinating cells. If this parameter is set to a large value, neighboring cells must have better signal quality to be coordinating cells, and a small number of UEs are identified as joint transmission UEs. If this parameter is set to a small value, a large number of UEs are identified as joint transmission UEs. This parameter applies only to LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the eNodeB performs joint transmission for a large number of UEs, and the experience rate of CEUs increase by a large margin. However, an excessively small value may cause deterioration of average user experience in the cell when the multi-user pairing rate is low. If this parameter is set to a large value, the eNodeB performs joint transmission for a small number of UEs, and the experience rate of CEUs increases by a small margin. If this parameter is set to a value greater than the RSRP difference threshold used to trigger handovers, the eNodeB performs handovers without performing joint transmission.

Applicable Mode: L-TDD

Example

To modify D-MIMO algorithm parameters for Cell 0 as follows: 
MOD DMIMOALGO: LocalCellId=0, DmimoA3RsrpOffset=-12;
run the following command:
