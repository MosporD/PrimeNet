Add Band to CA Band Combination (ADD PRIVATEBAND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a band to a private CA band combination.

Note

None.

Parameters

ID Name Description
PrivateCaCombId Private CA Band Combination ID

Meaning: Indicates the ID of a private CA band combination within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CombBandIndex Combination Band Index

Meaning: Indicates the index of a band in the private CA band combination. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CombBandId Combination Band ID

Meaning: Indicates the number of the band. For details about band numbers, see 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CombBandBw Combination Band Bandwidth

Meaning: Indicates the bandwidth set supported in the band. If a bandwidth is selected, any carrier with this bandwidth in the band can be a component of the private CA band combination. Selected bandwidths must be identical to cell bandwidths supported by a UE. Otherwise, the eNodeB may mistakenly determine that a bandwidth that the UE does not support is supported in the private CA band combination, causing CA configuration failures for the UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Bandwidth_1_4M(1.4M), Bandwidth_3M(3M), Bandwidth_5M(5M), Bandwidth_10M(10M), Bandwidth_15M(15M), Bandwidth_20M(20M)

Unit: None

Actual Value Range: Bandwidth_1_4M, Bandwidth_3M, Bandwidth_5M, Bandwidth_10M, Bandwidth_15M, Bandwidth_20M

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When a new PrivateBand MO is to be added for a frequency band, the CombBandBw parameter value cannot be zero.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Add Band to CA Band Combination :
ADD PRIVATEBAND: PrivateCaCombId=0, CombBandIndex=1, CombBandId=3, CombBandBw=Bandwidth_1_4M-1&Bandwidth_3M-1&Bandwidth_5M-1&Bandwidth_10M-1&Bandwidth_15M-1&Bandwidth_20M-1;
