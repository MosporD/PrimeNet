Modify Ul Comp Algo (MOD CELLULCOMPALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the uplink coordinated multi-point (CoMP) algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId LocalCellId

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlCompA3Offset UlCompA3Offset

Meaning: Indicates the offset for UL CoMP event A3. A larger value indicates that a neighboring cell must have better quality for the reporting of the event. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship:

-Others:

  • This parameter takes effects only when the UL CoMP function controlled by the UplinkCompSwitch or SfnUplinkCompSwitch parameter in the CellAlgoSwitch MO for the corresponding cell is enabled.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs selected for UL CoMP and higher average uplink throughput gain of these UEs. A larger value results in the opposite effects. If the value of this parameter is greater than the threshold of event A3 used in handovers, UEs are handed over rather than be selected for UL CoMP.

Applicable Mode: L-FDD, L-TDD
SfnUlCompThd Sfn UL CoMP Threshold

Meaning: Indicates the admission threshold for UL CoMP UEs in an SFN cell.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: FDD or TDD cells: -8

NB-IoT cells: -3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs selected for UL CoMP and higher average uplink throughput gain of these UEs. A larger value results in the opposite effects.

Applicable Mode: L
UlCompA3OffsetForRelaxedBH RelaxedBH UL CoMP A3 Offset

Meaning: Indicates the offset for reporting the UL CoMP event. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better quality for the reporting of the event. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship:

-Others:

  • Due to the restraints on transmission latency and bandwidths, the eNodeB only selects UEs with more potential gains for relaxed-backhaul-based UL CoMP. Therefore, the UlCompA3OffsetForRelaxedBH parameter must be set to a large value, and it is recommended that it be greater than the value of the UlCompA3Offset parameter.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more measurement reports, more relaxed-backhaul-based inter-eNodeB UL-CoMP UEs, smaller uplink QCI-1 packet loss rate for voice UEs, and greater uplink throughput for cell-edge non-voice UEs. A larger value of this parameter results in the opposite effects.

If the value of this parameter is greater than the offset of event A3 used in handovers, UEs are handed over rather than be selected for UL CoMP.

Applicable Mode: L-FDD, L-TDD
UlCompUlRsrpOffset UL RSRP Offset for UL CoMP

Meaning: Indicates the positive offset of the UL RSRP measurement result for a neighboring cell relative to that for the serving cell used in UL CoMP in a wider scope and inter- or intra-eNodeB UL CoMP enhancement. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: -50~30

Unit: 0.5dB

Actual Value Range: -25~15

MML Default Value: None

Recommended Value: FDD cells: -20

NB-IoT cells: -6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of UEs selected for UL CoMP and smaller average uplink throughput of these UEs. A larger value results in the opposite effects.

Applicable Mode: L-FDD, L-NB-IOT

Example

To modify the uplink CoMP algorithm with UlCompA3Offset set to -20 and Sfn UL CoMP Threshold set to -8 for the cell with Local cell identity of 0, run the following command:
MOD CELLULCOMPALGO: LocalCellId=0, UlCompA3Offset=-20, SfnUlCompThd=-8;
