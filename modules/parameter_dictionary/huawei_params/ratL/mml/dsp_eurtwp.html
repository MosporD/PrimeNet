Display RRU RTWP (DSP EURTWP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the received total wideband power (RTWP) of the RRU for a brief analysis on whether the RRU works normally.

Note

None.

Parameters

ID Name Description
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • SECTORID on which SectorEqmId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the received total wideband power (RTWP) of the RRU, run the following command:
DSP EURTWP: SectorEqmId=0;
The result is shown as follows:

Output Description

Field Description

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

RRU Cabinet No.

Indicates the cabinet number of the RRU.

RRU Subrack No.

Indicates the subrack number of the RRU.

RRU Slot No.

Indicates the slot number of the RRU.

RX Channels No.

Indicates the RX channel number of the RRU. An RRU is configured with multiple RX channels.

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the ID of the eNodeB.

Received total wideband power(0.1dBm)

Indicates the RTWP for the carrier. The normal value range is from -130 dBm to -40 dBm. If the value is out of this range, the SINR may be too low, or power saturation occurs (which leads to signal distortion), affecting air interface performance. The value 65535 is invalid, which indicates that the RTWP of the target module cannot be queried.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
