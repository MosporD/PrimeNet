Add Intra-Frequency E-UTRAN Cell to Blacklist (ADD INTRAFREQBLKCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add intra-frequency E-UTRAN cells to the blacklist.

Note

  • A maximum of 32 intra-frequency E-UTRAN cells can be added to the blacklist.

  • The physical cell identifier (PCI) range specified in each IntraFreqBlkCell MO cannot include the PCI of the local cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PhyCellId Start physical cell ID

Meaning: Indicates the starting PCI of the intra-frequency blacklisted cell. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of the value of PhyCellIdRange (n1 is 1, n4 is 4, n8 is 8, and so on) and the value of PhyCellId must be smaller than 504 in the IntraFreqBlkCell MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellName Cell name

Meaning: Indicates the name of the intra-frequency blacklisted cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~99 characters

Unit: None

Actual Value Range: 0~99 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PhyCellIdRange Physical cell ID range

Meaning: Indicates the PCI range of the intra-frequency blacklisted cell. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: n1(n1), n4(n4), n8(n8), n12(n12), n16(n16), n24(n24), n32(n32), n48(n48), n64(n64), n84(n84), n96(n96), n128(n128), n168(n168), n252(n252), n504(n504)

Unit: None

Actual Value Range: n1, n4, n8, n12, n16, n24, n32, n48, n64, n84, n96, n128, n168, n252, n504

MML Default Value: n1(n1)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of the value of PhyCellIdRange (n1 is 1, n4 is 4, n8 is 8, and so on) and the value of PhyCellId must be smaller than 504 in the IntraFreqBlkCell MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ApplicationScope Application Scope

Meaning: Indicates the UEs that the cell blacklist applies to. If this parameter is set to 65535, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through reselection or handover. If this parameter is set to 65534, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through handover. If this parameter is set to a value from 0 to 255, the blacklist applies to UEs with the SPID in an SPID group with the SpidGrpId parameter value the same as the ApplicationScope parameter and such UEs cannot be handed over to the blacklisted cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255,65534~65535

Unit: None

Actual Value Range: 0~255,65534,65535

MML Default Value: 65535

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add an intra-frequency E-UTRAN cell with the following parameters to the blacklist: Local cell ID: 0, Start physical cell ID: 17, run the following command:
ADD INTRAFREQBLKCELL:LocalCellId=0, PhyCellId=17;
Example 2: To add an intra-frequency E-UTRAN cell with the following parameters to the blacklist: Local cell ID: 0, Start physical cell ID: 18, run the following command:
ADD INTRAFREQBLKCELL:LocalCellId=0, PhyCellId=18;
