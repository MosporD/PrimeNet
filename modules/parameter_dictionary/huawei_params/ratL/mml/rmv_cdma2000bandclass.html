Remove Neighboring CDMA2000 Band Class Information (RMV CDMA2000BANDCLASS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the configuration of a CDMA2000 band class.

Note

Before running this command, ensure that all frequencies configured in this band class are removed.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandClass Band class

Meaning: Indicates the neighboring CDMA2000 band class. Signals on a frequency within the band class can be obtained by UEs. For details, see the BandclassCDMA2000 IE defined in 3GPP 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: bc0(bc0), bc1(bc1), bc2(bc2), bc3(bc3), bc4(bc4), bc5(bc5), bc6(bc6), bc7(bc7), bc8(bc8), bc9(bc9), bc10(bc10), bc11(bc11), bc12(bc12), bc13(bc13), bc14(bc14), bc15(bc15), bc16(bc16), bc17(bc17), bc18(bc18), bc19(bc19), bc20(bc20), bc21(bc21)

Unit: None

Actual Value Range: bc0, bc1, bc2, bc3, bc4, bc5, bc6, bc7, bc8, bc9, bc10, bc11, bc12, bc13, bc14, bc15, bc16, bc17, bc18, bc19, bc20, bc21

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the configuration of a CDMA2000 band class with the parameters as follows: Local cell ID: 0, Band class: bc0, run the following command:
RMV CDMA2000BANDCLASS: LocalCellId=0, BandClass=bc0;
