Modify a subscriber template (MOD EUSUBSCRIBERTEMPLATE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a subscriber template.

Note

None.

Parameters

ID Name Description
SubscriberTemplateID Subscriber Template ID

Meaning: Indicates the ID of a subscriber template. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
APNTemplateID APN Template ID

Meaning: Indicates the ID of an APN template. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TemplateName Template Name

Meaning: Indicates the name of a subscriber template. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16 characters

Unit: None

Actual Value Range: 0~16 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SecondaryAPNTemplateCfgInd Secondary APNTemplate Configuration Indicator

Meaning: Indicates whether the second PDN connection configured in the user template takes effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLED(DISABLED), ENABLED(ENABLED)

Unit: None

Actual Value Range: DISABLED, ENABLED

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SecondaryAPNTemplateID Secondary APN Template ID

Meaning: Indicates the ID of the secondary APN template for second PDN connection configuration. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set a subscriber template with the parameters as follows: Subscriber Template ID:4, APN Template ID:5, run the following command:
MOD EUSUBSCRIBERTEMPLATE: SubscriberTemplateID=4, APNTemplateID=5;
