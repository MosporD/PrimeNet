Display BBP Assist Group (DSP BBPASSISTGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of baseband processing units in the baseband equipment associated with the LTE baseband assistance group.

Note

None.

Parameters

ID Name Description
BbpAssistGrpId BBP Assist Group Id

Meaning: Indicates the ID of an LTE BBP assistance group. It uniquely identifies an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the status of baseband processing units in the baseband equipment associated with a baseband assistance group, run the following command: :
DSP BBPASSISTGROUP:;
The result is shown as follows:
+++    0        2018-11-08 21:36:14
O&M    #806355073
%%DSP BBPASSISTGROUP: BbpAssistGrpId=0;%%
RETCODE = 0  Operation succeeded.

Display BbpAssistGroup
----------------------
BBP Assist Group Id  =  0
      Assist Status  =  Not Assisted
      Failed Reason  =  Assist Start Time Not Arrived
(Number of results = 1)


---    END

Output Description

Field Description

BBP Assist Group Id

Indicates the ID of an LTE BBP assistance group. It uniquely identifies an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.

Assist Status

Indicates the status of an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.

Failed Reason

Indicates the cause of the last failure to transfer a cell from the master BBP to the assistant BBP in an LTE BBP assistance group. This parameter applies only to LTE FDD and LTE TDD.
