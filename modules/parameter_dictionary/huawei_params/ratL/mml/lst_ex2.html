List eX2 Configuration (LST EX2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of an eX2 object.

Note

None.

Parameters

ID Name Description
eX2Id eX2 Object ID

Meaning: Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5,10

Unit: None

Actual Value Range: 0~5,10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the information about the eX2 object, run the following command: 
LST EX2:;
The result is shown as follows: 
+++    HUAWEI        2014-04-16 15:17:50
O&M    #806358168
%%LST EX2:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

eX2 Object ID

Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.

End-Point Group Configuration Flag

Indicates whether to configure the control-plane or user-plane end point group. This parameter applies only to LTE FDD and LTE TDD.

Control Plane End-Point Group ID

Indicates the ID of the control-plane end point group used by the eX2 object. This parameter applies only to LTE FDD and LTE TDD.

User Plane End-Point Group ID

Indicates the ID of the user-plane end point group used by the eX2 object. This parameter applies only to LTE FDD and LTE TDD.

eX2 Interface Backhaul Type

Indicates the transport type of the eX2 interface. SRIO- or Ethernet-based transport system connecting through the USU is called ideal backhaul. IPRAN- or PTN-based transport system shared with the S1 or X2 interface is called non-ideal backhaul. The transport type of eX2 interfaces between logical eNodeBs contained in a physical network (for example, a physical eNodeB) is called intra physical network domain ideal backhaul. This parameter applies only to LTE FDD and LTE TDD.

eX2 Object Description

Indicates the description of the eX2 object. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates whether the MO can be automatically modified or removed by the eNodeB. If this parameter is set to MANUAL_MODE(Manual Mode), both operators and the eNodeB can modify or remove this MO. If this parameter is set to AUTO_MODE(Auto Mode), only the eNodeB can modify or remove this MO.
