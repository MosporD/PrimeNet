Modify SPID Configuration (MOD SPIDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the subscriber profile ID (SPID) configuration.

Note

None.

Parameters

When this parameter is set to 0, the eNodeB does not obtain the SPID from the MME or the eNodeB is not configured with an SPID for UEs. This parameter applies only to LTE FDD and LTE TDD.

OffloadSwitch Offload Switch

Meaning: Indicates whether to enable SPID-specific offload.

The eNodeB can transfer UEs with the specific SPID by inter-frequency offload from the local cell to inter-frequency neighboring cells with load information exchange only if this option is selected. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_OFFLOAD_SWITCH: The eNodeB can transfer UEs with the specific SPID by inter-RAT offload from the local cell to UTRAN or GERAN neighboring cells only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SpidSpecificBestEffortGbr SPID-specific Best Effort GBR

Meaning: Indicates the SPID-specific best-effort GBR.

If this parameter is set to 0, the eNodeB does not assure the best-effort GBR for UEs with a specific SPID.

When both the SPID-specific best-effort GBR and QCI-specific best-effort GBR are set to non-zero values and configured for the same UE, the eNodeB performs SPID-specific best-effort GBR for the UE.

SpidUeInactivityTimer SPID-Specific UE Inactivity Timer

Meaning: Indicates the length of the UE inactivity timer for UEs with the SPID. If the eNodeB detects that such a UE has neither received nor sent data for a period exceeding the value of this parameter, the eNodeB releases the RRC connection for the UE. If this parameter is set to 0, the UE inactivity timer is not used. If this parameter is set to 65535, this parameter does not take effect and the UeInactiveTimerForQci parameter in the QciPara MO takes effect. If the parameter setting is changed, the change applies only to UEs that access the network afterwards. This parameter applies only to LTE FDD and LTE TDD.

Unit: s

Actual Value Range: 0~3600,65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in earlier RRC connection releases for UEs without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger value of this parameter results in later RRC connection releases for UEs without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases. If the UE inactivity timer is set to a smaller value, the number of times UEs near the cell center access the cell becomes larger, resulting in smaller values of the L.RRC.ConnSetup.TimeAvg and L.E-RAB.Est.TimeAvg counters.

SpidAlgoSwitch SPID Algorithm Switch

Meaning: Indicates whether to enable SPID-related algorithms.

CA_IDLE_MLB_SWITCH: Assume that the SpidCfg.IdleMlbSwitch parameter is set to TRUE. If this option is selected, idle mode MLB takes effect for CA-capable UEs of the SPID. If this option is deselected, idle mode MLB does not take effect for CA-capable UEs of the SPID. This option does not take effect if the SpidCfg.IdleMlbSwitch parameter is set to FALSE. This parameter applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: If this option is selected, the eNodeB triggers fast-moving-UE smart carrier selection for UEs of this SPID. If this option is deselected, the eNodeB does not trigger fast-moving-UE smart carrier selection for UEs of this SPID. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: CA_IDLE_MLB_SWITCH(CA_IDLE_MLB_SWITCH), SCS_FAST_MOVING_UE_SW(SCS_FAST_MOVING_UE_SW)

Unit: None

Actual Value Range: CA_IDLE_MLB_SWITCH, SCS_FAST_MOVING_UE_SW

MML Default Value: None

Recommended Value: CA_IDLE_MLB_SWITCH:On

SCS_FAST_MOVING_UE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: CA_IDLE_MLB_SWITCH: If this option is selected, during cell reselection for CA-capable UEs of the SPID, the eNodeB considers the load status of neighboring cells based on the load balancing algorithm to prevent the UEs from being reselected to high-load cells. However, if the PccAnchorSwitch or EnhancedPccAnchorSwitch option of the EnodebAlgoSwitch.CaAlgoSwitch parameter is selected, the number of handovers of CA UEs in connected mode increases. If this option is deselected, the eNodeB does not consider the load status of neighboring cells during cell reselection for CA-capable UEs of the SPID. This affects the performance of MLB when the proportion of CA-capable UEs is high. However, if the PccAnchorSwitch or EnhancedPccAnchorSwitch option of the EnodebAlgoSwitch.CaAlgoSwitch parameter is selected, the number of handovers of CA UEs in connected mode does not increase.

SCS_FAST_MOVING_UE_SW: If this option is selected, fast-moving-UE smart carrier selection is adopted for UEs of this SPID. In this case, if the UEs of this SPID are fast-moving UEs, downlink UE throughput can increase. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To modify the SPID configuration with the parameters as follows: Spid: 1, RatFreqPriorityInd: CFG, RatFreqPriorityGroupId: 0, run the following command:
MOD SPIDCFG: Spid=1, RatFreqPriorityInd=CFG, RatFreqPriorityGroupId=0;
