Add Configuration of Cell Reselection to GERAN (ADD CELLRESELGERAN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the configuration related to cell reselection to GERAN.

Note

  • The CELL object must exist when adding the GERAN cell reselection information.

  • If this MO is not configured, cell reselection to GERAN is not allowed.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TReselGeran Cell reselection timer value for GERAN

Meaning: Indicates the evaluation period for a UE to determine whether to reselect a neighboring GERAN cell to camp on. During the evaluation period, if the signal quality in a neighboring GERAN cell is better than that in the serving cell and a UE camps on the serving cell for more than 1s, the UE attempts to reselect the neighboring GERAN cell to camp on. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: s

Actual Value Range: 0~7

MML Default Value: 1

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher probability of initiating cell reselections but a higher probability of ping-pong reselections. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
SpeedStateSfCfgInd Speed state scale factor configure indicator

Meaning: Indicates whether to set the speed-dependent scaling parameters related to cell reselection to GERAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: NOT_CFG(Not configure)

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TReselGeranSfMedium Scaling factor of TReselGeran in medium mobility state

Meaning: Indicates the scaling factor applied to TReselGeran for medium-mobility UEs. The actual duration of cell reselection of medium-mobility UEs to GERAN is equal to TReselGeran multiplied by TReselGeranSfMedium. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: T_RESEL_SF_0DOT25(0.25), T_RESEL_SF_0DOT5(0.5), T_RESEL_SF_0DOT75(0.75), T_RESEL_SF_1DOT0(1.0)

Unit: None

Actual Value Range: T_RESEL_SF_0DOT25, T_RESEL_SF_0DOT5, T_RESEL_SF_0DOT75, T_RESEL_SF_1DOT0

MML Default Value: T_RESEL_SF_1DOT0(1.0)

Recommended Value: T_RESEL_SF_1DOT0(1.0)

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of SpeedStateSfCfgInd.
  • If SpeedStateSfCfgInd is set to CFG, TReselGeranSfMedium must be set.
  • If SpeedStateSfCfgInd is set to NOT_CFG, TReselGeranSfMedium does not need to be set.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A smaller value results in a higher speed of cell reselection for medium-mobility UEs. A larger value leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
TReselGeranSfHigh Scaling factor of TReselGeran in high mobility state

Meaning: Indicates the scaling factor applied to TReselGeran for high-mobility UEs. The actual duration of cell reselection of high-mobility UEs to GERAN is equal to TReselGeran multiplied by TReselGeranSfHigh. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: T_RESEL_SF_0DOT25(0.25), T_RESEL_SF_0DOT5(0.5), T_RESEL_SF_0DOT75(0.75), T_RESEL_SF_1DOT0(1.0)

Unit: None

Actual Value Range: T_RESEL_SF_0DOT25, T_RESEL_SF_0DOT5, T_RESEL_SF_0DOT75, T_RESEL_SF_1DOT0

MML Default Value: T_RESEL_SF_0DOT75(0.75)

Recommended Value: T_RESEL_SF_0DOT75(0.75)

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of SpeedStateSfCfgInd.
  • If SpeedStateSfCfgInd is set to CFG, TReselGeranSfHigh must be set.
  • If SpeedStateSfCfgInd is set to NOT_CFG, TReselGeranSfHigh does not need to be set.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A smaller value results in a higher speed of cell reselection for high-mobility UEs. A larger value leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add the EUTRAN-to-GERAN cell reselection information with the parameters as follows: Local cell ID: 0, Cell reselection timer value for GERAN: 4, Speed state scale factor configure indicator: CFG, Scaling factor of TReselGeran in medium mobility state: T_RESEL_SF_0DOT5, Scaling factor of TReselGeran in high mobility state: T_RESEL_SF_0DOT25, run the following command:
ADD CELLRESELGERAN: LocalCellId=0, TReselGeran=4, SpeedStateSfCfgInd=CFG, TReselGeranSfMedium=T_RESEL_SF_0DOT5, TReselGeranSfHigh=T_RESEL_SF_0DOT25;
Example 2: To add the EUTRAN-to-GERAN cell reselection information with the parameters as follows: Local cell ID: 0, Cell reselection timer value for GERAN: 5, Speed state scale factor configure indicator: NOT_CFG, run the following command:
ADD CELLRESELGERAN: LocalCellId=0, TReselGeran=5, SpeedStateSfCfgInd=NOT_CFG;
