Display Cell LAA Configuration State (DSP CELLLAA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query whether the FCS and coexistence parameters of the LAA cell take effect based on the customer interface configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query whether the FCS and coexistence parameters of the LAA cell take effect based on the customer interface configurations with local cell ID of 1, run the following command:
DSP CELLLAA: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

LAA Configuration Reference Cell ID

Indicates the local cell ID of the reference cell whose FCS and coexistence parameter configurations are referenced by the LAA cell. This parameter applies only to LTE TDD.

Interference Duty Rate(%)

Indicates the interference duty cycle of a cell. The base station detects and samples the RF signal amplitude on an antenna port to obtain a series of interference sampling values. If the value at a sampling point is higher than the interference detection threshold, the sampling point is considered as an interfered sampling point. If the value of a sampling point is lower than or equal to the threshold, the sampling point is considered as a non-interfered sampling point. This parameter value is equal to the total number of interfered sampling points divided by the total number of sampling points multiplied by 100. This parameter applies only to LTE TDD.
