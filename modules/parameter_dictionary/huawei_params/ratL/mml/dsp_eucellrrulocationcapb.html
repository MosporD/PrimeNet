Display Location Capability of Cell-specific Sector Equipment (DSP EUCELLRRULOCATIONCAPB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display the location capability of cell-specific sector equipment. This command applies only to LTE TDD cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • SECTORID on which SectorEqmId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

+++    HUAWEI        2017-06-12 21:08:12
O&M    #123456789
%%DSP EUCELLRRULOCATIONCAPB: LocalCellId=0;%%
RETCODE = 0  Operation succeeded.
Display Location Capability of Cell-specific Sector Equipment
-------------------------------------------------------------
Local cell ID  Sector equipment ID  Location Capability
0              0                   SEND_AND_RECEIVE
0              1                   SEND_OR_RECEIVE
0              2                   NOT_SUPPORT
(Number of results = 3)
---    END

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

Location Capability

Indicates the location capability of the RF module to be located. This parameter applies only to LTE TDD.
