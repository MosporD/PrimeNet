Modify S1 Interface Information (MOD S1INTERFACE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to an S1 interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Changing the MME protocol release may change some functions related to the S1 interface. The MME protocol release configured on the eNodeB must be the same as the MME protocol release configured in the EPC. If the parameter value is different from the MME-complied protocol release, the way in which the MME handles S1 messages is subject to the MME protocol compliance implementation.

  • After an S1 interface is blocked, new admission requests will be rejected over this interface, including normal admission requests, inter-eNodeB incoming handovers, and inter-RAT incoming handovers.

    Normal admissions, inter-eNodeB incoming handovers, and inter-RAT incoming handovers over the blocked S1 interface will fail, affecting the network performance. After an S1 interface is blocked, unblock the interface in a timely manner or remove the interface after all UEs using this interface are released.

  • Before changing the CN operator ID, ensure that the corresponding operator has been added. Before changing the CP bearer ID, ensure that the corresponding CP bearer has been added.

  • After this command is executed to modify the CP bearer ID or CN operator ID, the S1 interface automatically resets. In hybrid RAN sharing mode, after this command is executed to modify the carrier-sharing operator group ID, the eNodeB automatically sets up the S1 interfaces managed by this S1 MO. In other eNodeB sharing modes, the execution of this command has no impact on the radio network.

  • If the value of the CnOpSharingGroupId parameter in an S1Interface MO is not set to the invalid value 255, ensure that the associated CnOpSharingGroup MO has been added before modifying the CnOpSharingGroupId parameter in the S1Interface MO and the operator to which the S1Interface MO belongs is in the carrier-sharing operator group. In hybrid RAN sharing mode, the CnOpSharingGroup MO referenced by the S1Interface MO must be configured and the CnOpSharingGroupId parameter must be set to a valid value.

Parameters

ID Name Description
S1InterfaceId S1 Interface ID

Meaning: Indicates the S1 interface ID. If the S1 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65534. If the S1 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
S1CpBearerId S1 Interface CP Bearer ID

Meaning: Indicates the ID of the control port bearer for the S1 interface.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The S1CpBearerId value in each S1Interface MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator that owns the S1 interface.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
MmeRelease MME Release

Meaning: Indicates the compliance protocol release of the MME to which the eNodeB is connected through the S1 interface. The eNodeB sends S1 messages complying with the protocol release specified by this parameter. The value of this parameter must be the same as the MME-complied protocol release. If the parameter value is different from the MME-complied protocol release, the way in which the MME handles these message is subject to the MME implementation.

GUI Value Range: Release_R8(Release 8), Release_R9(Release 9), Release_R10(Release 10), Release_R11(Release 11), Release_R12(Release 12), Release_R13(Release 13), Release_R14(Release 14), Release_R15(Release 15)

Unit: None

Actual Value Range: Release_R8, Release_R9, Release_R10, Release_R11, Release_R12, Release_R13, Release_R14, Release_R15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
S1InterfaceIsBlock S1 Interface Is Blocked

Meaning: Indicates whether the S1 interface is blocked. An S1 interface is blocked after the execution of BLK S1INTERFACE and is unblocked after the execution of UBL S1INTERFACE.

GUI Value Range: FALSE(FALSE), TRUE(TRUE)

Unit: None

Actual Value Range: FALSE, TRUE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (After an S1 interface is blocked, UEs in idle mode cannot access the network.)

Impact on Radio Network Performance: None

Applicable Mode: L
Priority MME Selection Priority

Meaning: Indicates the priority of an MME to which the eNodeB is connected through the S1 interface. A large parameter value indicates a high priority. After this parameter is set for MMEs, the eNodeB can select a high-priority MME for UEs attempting to access the network.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group that shares the S1Interface MO. If the eNodeB works in hybrid RAN sharing mode, set this parameter to a value within the range from 0 to 5. If the eNodeB works in independent operator mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, retain the default value 255, which is an invalid value.

GUI Value Range: 0~5,255

Unit: None

Actual Value Range: 0~5,255

MML Default Value: None

Recommended Value: If the eNodeB works in hybrid RAN sharing mode, the recommended value is ranging from 0 to 5; otherwise, set this parameter to the invalid value 255.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To change the value of S1 Interface CP Bearer ID to 1 for the S1 interface with S1Interface ID of 2, run the following command:
MOD S1INTERFACE: S1InterfaceId=2, S1CpBearerId=1;
