Modify Inter-RAT Handover Policy Group (MOD INTERRATPOLICYCFGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to inter-RAT handover policies.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the handover policy is set to redirection for QCI-1 services, voice service drops may occur.

Parameters

ID Name Description
InterRatPolicyCfgGroupId InterRAT policy config group ID

Meaning: Indicates the group ID of the parameters related to the inter-RAT handover. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~39

Unit: None

Actual Value Range: 0~39

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UtranHoCfg UTRAN handover policy Configuration

Meaning: Indicates the policy of handovers to UTRAN.

PS_HO: Indicates whether to allow PS handovers to UTRAN.

This option applies only to LTE FDD and LTE TDD.

SRVCC: Indicates whether to allow transfers to UTRAN in SRVCC mode.

This option applies only to LTE FDD and LTE TDD.

REDIRECTION: Indicates whether to allow redirection to UTRAN.

This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PS_HO, SRVCC, REDIRECTION

Unit: None

Actual Value Range: PS_HO, SRVCC, REDIRECTION

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to REDIRECTION for a bearer with a QCI of 1, a call drop occurs during a redirection.

Applicable Mode: L-FDD, L-TDD
GeranGsmHoCfg GERAN GSM handover policy Configuration

Meaning: Indicates the policy of handovers to GERAN GSM networks.

SRVCC: Indicates whether a UE can be handed over to a neighboring GERAN GSM cell through SRVCC.

This option applies only to LTE FDD and LTE TDD.

GUI Value Range: SRVCC

Unit: None

Actual Value Range: SRVCC

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GeranGprsEdgeHoCfg GERAN GPRS EDGE handover policy Configuration

Meaning: Indicates the policy of handovers to GPRS/EDGE networks.

PS_HO:

Indicates whether PS handovers to neighboring GPRS/EDGE cells are allowed. This option applies only to LTE FDD and LTE TDD.

CCO_HO:

Indicates whether CCO to neighboring GPRS/EDGE cells is allowed. This option applies only to LTE FDD and LTE TDD.

SRVCC:

Indicates whether SRVCC to neighboring GPRS/EDGE cells is allowed. This option applies only to LTE FDD and LTE TDD.

REDIRECTION:

Indicates whether redirections to neighboring GPRS/EDGE cells are allowed. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PS_HO, CCO_HO, SRVCC, REDIRECTION

Unit: None

Actual Value Range: PS_HO, CCO_HO, SRVCC, REDIRECTION

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to REDIRECTION for a bearer with a QCI of 1, a call drop occurs during a redirection.

Applicable Mode: L-FDD, L-TDD
CdmaHrpdHoCfg CDMA2000 HRPD handover policy Configuration

Meaning: Indicates the policy of handovers to CDMA2000 HRPD networks.

NON_OPT_HO: Indicates whether to allow non-optimized handovers to neighboring CDMA2000 HRPD cells.

This option applies only to LTE FDD and LTE TDD.

OPT_HO: Indicates whether to allow optimized handovers to neighboring CDMA2000 HRPD cells.

This option applies only to LTE FDD and LTE TDD.

GUI Value Range: OPT_HO, NON_OPT_HO

Unit: None

Actual Value Range: OPT_HO, NON_OPT_HO

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NoHoFlag No handover flag

Meaning: Indicates whether to permit or forbid the inter-RAT handover under the QCI. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PERMIT_HO_ENUM(Permit Ho), FORBID_HO_ENUM(Forbid Ho)

Unit: None

Actual Value Range: PERMIT_HO_ENUM, FORBID_HO_ENUM

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NrHoCfg NR Handover Policy Configuration

Meaning: Indicates the policy for handovers to NG-RAN in the inter-RAT policy configuration group.

PS_HO: Indicates whether to allow PS handovers to NG-RAN. This option applies only to LTE FDD and LTE TDD.

REDIRECTION: Indicates whether to allow redirections to NG-RAN. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PS_HO, REDIRECTION

Unit: None

Actual Value Range: PS_HO, REDIRECTION

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this inter-RAT policy configuration group with this PS_HO option deselected and this REDIRECTION option selected is configured for QCI 1 bearers, call drops occur during inter-RAT redirections.

Applicable Mode: L-FDD, L-TDD

Example

To modify an inter-RAT handover policy group with the parameters as follows: InterRatPolicyCfgGroupId: 9, UtranHoCfg: PS_HO:Off, and UtranHoCfg: SRVCC:Off, run the following command: 

MOD INTERRATPOLICYCFGGROUP: InterRatPolicyCfgGroupId=9, UtranHoCfg=PS_HO-0&SRVCC-0;
