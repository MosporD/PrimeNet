Modify CellCeCfg Configuration (MOD CELLCECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the cell coverage enhancement configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the cell coverage level. A maximum of four levels are supported, corresponding to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancements. When this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, and COVERAGE_LEVEL_3, the maximum coverage level supported by the cell is coverage level 0, coverage level 1, coverage level 2, and coverage level 3, respectively. If the value of this parameter is changed, the value of the SIB1RepNum parameter or SiTransEcr parameter may be changed, which causes eMTC UEs that already accessed the cell to be proactively released. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2), COVERAGE_LEVEL_3(COVERAGE_LEVEL_3)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, COVERAGE_LEVEL_3

MML Default Value: None

Recommended Value: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0)

Parameter Relationship:

-Configuration constraints:

  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_2, the value of the RachRsrpFstThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpSndThd parameter in this MO.
  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_3, the value of the RachRsrpSndThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpTrdThd parameter in this MO. In addition, the value of the RachRsrpFstThd parameter in this MO must be greater than or equal to the RachRsrpSndThd parameter value.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A higher cell coverage level indicates stronger cell coverage enhancement and more consumed cell RB resources. A lower cell coverage level indicates the opposite effects. When this parameter is adjusted dynamically, the eMTC preamble group may change. If the preamble for the UE accessing the network is in the group before the eMTC preamble group change, the preamble demodulation performance is affected, and the RACH success rate decreases temporarily.

Applicable Mode: L-FDD, L-TDD
RachRsrpFstThd RACH RSRP First Threshold

Meaning: Indicates the RSRP level-1 threshold. When the measured RSRP value of a UE is higher than the RSRP level-1 threshold, the UE initiates random access in the cell at coverage level 0. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, or COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -141~-44

Unit: dBm

Actual Value Range: -141~-44

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_2, the value of the RachRsrpFstThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpSndThd parameter in this MO.
  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_3, the value of the RachRsrpSndThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpTrdThd parameter in this MO. In addition, the value of the RachRsrpFstThd parameter in this MO must be greater than or equal to the RachRsrpSndThd parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a too small value, the UE is less likely to access the network with more preamble resources, the probability of preamble demodulation is lower, the number of false preamble detections decreases, and the overhead for preamble demodulation on the eNodeB decreases. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
RachRsrpSndThd RACH RSRP Second Threshold

Meaning: Indicates the RSRP level-2 threshold. When the measured RSRP value of a UE is between the RSRP level-1 threshold and RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 1. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_2 or COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -141~-44

Unit: dBm

Actual Value Range: -141~-44

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_2, the value of the RachRsrpFstThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpSndThd parameter in this MO.
  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_3, the value of the RachRsrpSndThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpTrdThd parameter in this MO. In addition, the value of the RachRsrpFstThd parameter in this MO must be greater than or equal to the RachRsrpSndThd parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a too small value, the UE is less likely to access the network with more preamble resources, the probability of preamble demodulation is lower, the number of false preamble detections decreases, and the overhead for preamble demodulation on the eNodeB decreases. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
RachRsrpTrdThd RACH RSRP Third Threshold

Meaning: Indicates the RSRP level-3 threshold. When the measured RSRP value of a UE is between the RSRP level-2 threshold and RSRP level-3 threshold, the UE initiates random access in the cell at coverage level 2. When the measured RSRP value of a UE is lower than the RSRP level-3 threshold, the UE initiates random access in the cell at coverage level 3. This parameter takes effect only when the CoverageLevel parameter is set to COVERAGE_LEVEL_3. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -141~-44

Unit: dBm

Actual Value Range: -141~-44

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the same cell, when the CoverageLevel parameter in a CellCeCfg MO is set to COVERAGE_LEVEL_3, the value of the RachRsrpSndThd parameter in this CellCeCfg MO must be greater than or equal to the value of the RachRsrpTrdThd parameter in this MO. In addition, the value of the RachRsrpFstThd parameter in this MO must be greater than or equal to the RachRsrpSndThd parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a too small value, the UE is less likely to access the network with more preamble resources, the probability of preamble demodulation is lower, the number of false preamble detections decreases, and the overhead for preamble demodulation on the eNodeB decreases. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify the CellCeCfg Configuration with the parameters as follows: Local cell ID: 0, Coverage Level: COVERAGE_LEVEL_3, run the following command:
MOD CELLCECFG: LocalCellId=0, CoverageLevel=COVERAGE_LEVEL_3;
