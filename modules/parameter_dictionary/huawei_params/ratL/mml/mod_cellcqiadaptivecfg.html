Modify Cell Adaptive CQI Configuration (MOD CELLCQIADAPTIVECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to CQI adaptation.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CqiPeriodAdaptive CQI Period Adaptive Switch

Meaning: Indicates whether to enable CQI reporting period adaptation. If this parameter is set to ON, the CQI reporting period adaptively changes based on the air interface load of the cell. If this parameter is set to OFF, the CQI reporting period is specified by the UserCqiPeriod parameter in the CellCqiAdaptiveCfg MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the eNodeB adaptively configures the period and offset of periodic CQI reporting for UEs. If this parameter is set to OFF, the eNodeB configures the CQI reporting period for UEs based on the setting of the UserCqiPeriod parameter in the CellCqiAdaptiveCfg MO. The CQI offset is mapped to a corresponding reporting period. The setting of this parameter affects the downlink and uplink throughput and the user number specification. For details, see the description of the UserCqiPeriod parameter in the CellCqiAdaptiveCfg MO.

Applicable Mode: L-FDD, L-TDD
UserCqiPeriod User CQI period

Meaning: Indicates the fixed CQI reporting period. This parameter takes effect only if the CqiPeriodAdaptive parameter is set to OFF(Off). If the UserCqiPeriod parameter is set to ms2(2ms), the period is automatically changed to 5ms for the TDD cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: ms2(2ms), ms5(5ms), ms10(10ms), ms20(20ms), ms40(40ms), ms80(80ms), ms160(160ms)

Unit: ms

Actual Value Range: ms2, ms5, ms10, ms20, ms40, ms80, ms160

MML Default Value: None

Recommended Value: ms40(40ms)

Parameter Relationship:

-Others:

  • This parameter is valid only when the CqiPeriodAdaptive parameter is set to OFF(Off).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more frequent periodic CQI reporting, higher downlink throughput, and fewer UEs that can participate in CQI reporting, reducing uplink throughput due to the decrease of the number of available RBs for uplink data transmission. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
SimulAckNackAndCqiSwitch SimulAckNackAndCQI Config Switch

Meaning: Indicates whether CQI and ACK/NACK can be simultaneously sent on the PUCCH. For details about PUCCH formats, see 3GPP TS 36.213.

If this parameter is set to OFF, the value of simultaneousAckNackAndCQI is set to False.

If this parameter is set to ON, the value of simultaneousAckNackAndCQI depends on the DRX status of a UE, the settings of the DrxSimulAckNackAndCqiSwitch and CqiMask parameters.

(1) If the UE is not in the DRX state, the value of simultaneousAckNackAndCQI varies depending on the CA state of the UE. If the UE is not in the CA state, the value is set to True. If the UE is in the CA state, the value depends on the setting of CaCqiAndAckAbnCtrlSwitch for the eNodeB.

(2) If the UE is in the DRX state and:

(i) If CqiMask is set to ON, the value of simultaneousAckNackAndCQI varies depending on the CA state of the UE. If the UE is not in the CA state, the value is set to True. If the UE is in the CA state, the value depends on the setting of CaCqiAndAckAbnCtrlSwitch for the eNodeB.

(ii) If CqiMask is set to OFF, the value of simultaneousAckNackAndCQI varies depending on the setting of DrxSimulAckNackAndCqiSwitch. If DrxSimulAckNackAndCqiSwitch is selected and the number of configured transmit antennas for the cell is greater than two, the value of simultaneousAckNackAndCQI is set to True for the UE not in the CA state or depends on the setting of CaCqiAndAckAbnCtrlSwitch for the UE in the CA state. If DrxSimulAckNackAndCqiSwitch is deselected, the value of simultaneousAckNackAndCQI is set to False.

If the value of simultaneousAckNackAndCQI is set to True, CQI and ACK/NACK can be simultaneously sent on the PUCCH. If the value of simultaneousAckNackAndCQI is set to False, CQI and ACK/NACK cannot be simultaneously sent on the PUCCH.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the PUCCH experiences severe interference or the false detection rate of the PUCCH TPC command is high, the demodulation performance of format 2a and format 2b is poor. In this case, set this parameter to OFF. This ensures that CQI and ACK/NACK cannot be sent simultaneously, and therefore the demodulation performance of feedback from the UE is improved, and downlink throughput increases. When the PUCCH performance is good, set this parameter to ON. In this case, CQI and ACK/NACK can be sent simultaneously, and therefore the CQI discarding rate decreases.

Applicable Mode: L
HoAperiodicCqiCfgSwitch Handover Aperiodic CQI Config Switch

Meaning: Indicates the aperiodic CQI resource configurations and the triggering condition of aperiodic CQI reporting during handovers. If this parameter is set to ON(On), aperiodic CQI resource configurations are included in handover commands. When no periodic CQI resources are configured for a UE, an aperiodic CQI reporting is triggered when the handed-over UE receives data. If this parameter is set to OFF(Off), aperiodic CQI resource configurations are not included in handover commands. The aperiodic CQI resource is configured after the UE is handed over. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Setting this parameter to ON increases the downlink UE throughput but also increases the handover signaling overheads. Setting this parameter to OFF does not affect radio network performance.

Applicable Mode: L-FDD, L-TDD
MinCqiPeriod Minimal CQI Period

Meaning: Indicates the minimum period of periodic CQI reporting. If the CqiPeriodAdaptive parameter is set to ON, the CQI reporting period cannot be less than this parameter value under different PUCCH load conditions. This parameter is valid only if the CqiPeriodAdaptive parameter is set to ON. This parameter applies only to LTE FDD.

GUI Value Range: ms5(5ms), ms20(20ms), ms40(40ms), ms160(160ms)

Unit: ms

Actual Value Range: ms5, ms20, ms40, ms160

MML Default Value: None

Recommended Value: ms5(5ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in fewer PUCCH RBs to be consumed and a possibly higher uplink throughput. In addition, uplink and downlink KPIs change, and the change degree depends on UE types and radio channel conditions.

Applicable Mode: L-FDD
SccCqiRptEnhancedSwitch Enhanced SCC CQI Reporting Switch

Meaning: Indicates whether to enable SCell CQI reporting enhancement. If this parameter is set to ON, SCell periodic CQI reporting is not configured for UEs treating the local cell as their PCell and only SCell aperiodic CQI reporting can be triggered. If this parameter is set to OFF, the UEs send SCell periodic and aperiodic CQI reports following the common process. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, PUCCH RB overhead in the SCells can be reduced, increasing the uplink data transmission rate. However, aperiodic CQI reporting consumes more PDCCH and PUSCH resources. Setting this parameter to OFF has no impact on network performance.

Applicable Mode: L-FDD

Example

To modify parameters related to adaptive CQI for a cell as follows: Local Cell ID: 0, CQI period adaptive switch: OFF, User CQI period config: 10ms, run the following command:
MOD CELLCQIADAPTIVECFG: LocalCellId=0, CqiPeriodAdaptive=OFF, UserCqiPeriod=ms10;
