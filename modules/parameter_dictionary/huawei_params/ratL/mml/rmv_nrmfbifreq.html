Remove NR Multi-Band Frequency (RMV NRMFBIFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an NR multi-band frequency.

Note

None.

Parameters

ID Name Description
DlArfcn Downlink ARFCN

Meaning: Indicates the downlink SSB NR-ARFCN of the NR multi-band frequency. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3279165

Unit: None

Actual Value Range: 0~3279165

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N1 or N66, the DlArfcn parameter value must be within the range of [422000, 434000].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N2 or N25, the DlArfcn parameter value must be within the range of [386000, 398000].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N34 or N70, the DlArfcn parameter value must be within the range of [402000, 404000].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N20 or N28, the DlArfcn parameter value must be within the range of [158200, 160600].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N7, the DlArfcn parameter value must be within the range of [524000, 537999].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N38, the DlArfcn parameter value must be within the range of [514000, 524000].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N41, the DlArfcn parameter value must be within the range of [514000, 537999].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N50 or N75, the DlArfcn parameter value must be within the range of [286400, 303400].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N74, the DlArfcn parameter value must be within the range of [295000, 303400].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N51 or N76, the DlArfcn parameter value must be within the range of [285400, 286400].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N77 or N78, the DlArfcn parameter value must be within the range of [620000, 653333].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N257, the DlArfcn parameter value must be within the range of [2054166, 2084999].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N258, the DlArfcn parameter value must be within the range of [2054166, 2070832].
  • In an NrMfbiFreq MO, if the FrequencyBand parameter is set to N261, the DlArfcn parameter value must be within the range of [2070833, 2084999].

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove an NR multi-band frequency with the parameters as follows: Downlink ARFCN: 633400, run the following command:
RMV NRMFBIFREQ: DlArfcn=633400;
