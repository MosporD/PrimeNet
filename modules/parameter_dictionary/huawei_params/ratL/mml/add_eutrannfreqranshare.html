Add Operator Sharing Information for EUTRAN Frequency (ADD EUTRANNFREQRANSHARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add information about an operator that shares a neighboring E-UTRAN frequency.

Note

  • Before running this command, ensure that the associated neighboring EUTRAN frequency has been configured.

  • A maximum of 6 operators can be configured to share a neighboring EUTRAN frequency.

  • Cell reselection priorities based on operators of the local cell (which are specified in the NrNFreqSCellOp, EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, and Cdma2000BcSCellOp MOs) cannot coexist with cell reselection priorities based on operators of neighboring frequencies (which are specified in the EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs).

  • In a cell, the dedicated cell reselection priority of an EutranNFreqRanShare MO specific to an operator must be different from that of any GeranRanShare MO specific to the same operator.

  • In a cell, the dedicated cell reselection priority of an EutranNFreqRanShare MO specific to an operator must be different from that of any UtranRanShare MO specific to the same operator.

  • If the PLMN ID specified in an EutranExternalCell MO associated with a neighboring E-UTRAN frequency is not specified in EutranNFreqRanShare MOs associated with this frequency, the operator with this PLMN ID cannot use the frequency.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlEarfcn Downlink EARFCN

Meaning: Indicates the DL EARFCN of the operator that shares the neighboring E-UTRAN frequency. For details, see the 3GPP TS 36.104. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the operator that shares the neighboring E-UTRAN frequency.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the operator that shares the neighboring E-UTRAN frequency.

A public land mobile network (PLMN) ID is comprised of a mobile network code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellReselPriorityCfgInd Cell reselection priority configure indicator

Meaning: Indicates whether to configure the cell reselection priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: NOT_CFG(Not configure)

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellReselPriority Cell reselection priority

Meaning: Indicates the cell reselection priority of the operator that shares the neighboring E-UTRAN frequency. The value 0 indicates the lowest priority. If the related SPID configuration is specified, the cell reselection priority specified in the SPID configuration is used. If no related SPID configuration is specified but this parameter is set, the eNodeB delivers the cell reselection priorities of all PLMNs supported by a UE by using the IE idleModeMobilityControlInfo in an RRC Connection Release message to the UE. If no related SPID configuration is specified and this parameter is not set, a UE uses the cell reselection priority of the neighboring E-UTRAN frequency, which is broadcast in the system information. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of CellReselPriorityCfgInd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher probability of starting measurements on neighboring cells on the E-UTRAN frequency and also a higher probability of reselecting to a neighboring cell on the frequency. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To add information about an operator that shares a neighboring EUTRAN frequency with the parameters as follows:Local cell ID:0, Downlink EARFCN:1234, Mobile country code: 460, Mobile network code: 01, Cell reselection priority configure indicator: NOT_CFG, run the following command:
ADD EUTRANNFREQRANSHARE: LocalCellId=0, DlEarfcn=1234, Mcc="460", Mnc="01", CellReselPriorityCfgInd=NOT_CFG;
