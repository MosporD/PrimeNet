Add Debugging Message (ADD ABLMSG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a debugging message. The eNodeB compares messages (either received or to be sent) with the debugging message for UEs of the specified configuration type (all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified UE capability). If the messages meet the specified matching criteria (matching offset, length, and content), the eNodeB discards or modifies the messages.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Running this command disrupts ongoing services. If you indeed need to run this command, run this command under the instruction of a Huawei technical support engineer.

RuleCfgType Rule Configuration Type

Meaning: Indicates whether the rule takes effect on all UEs, UEs with the specified TAC, UEs with the specified TAC and SVN, or UEs with the specified capability.

If this parameter is set to ALL, none of ImeisvTac, ImeisvSvn, and UeCapIndex needs to be configured.

If this parameter is set to IMEISV_TAC, the ImeisvTac parameter must be configured.

If this parameter is set to IMEISV_TAC_SVN, the ImeisvTac and ImeisvSvn parameters must be configured.

If this parameter is set to UE_CAPABILITY, the UeCapIndex parameter must be configured.

Example

To add a debugging message with the parameters as follows: Rule Index : 0, Rule Configuration Type: All, Interface Protocol Name: S1AP, Message Type: 8, Operate Type: DISCARD, Match Count: ZERO, run the following command:
ADD ABLMSG: RuleIndex=0, RuleCfgType=ALL, MsgItfType=S1AP, MsgType=8, MsgOpType=DISCARD, MatchCount=ZERO;
