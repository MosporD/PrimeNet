Stop RTWP Test (STP LRTWPRTTST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to stop RTWP tests in all cells under the eNodeB.

Note

None.

Parameters

None.

Example

To stop an RTWP test for cells, run the following command:
STP LRTWPRTTST:;
The result is shown as follows:
+++    HUAWEI    2014-06-10 17:35:53
O&M    #806355357
%%STP LRTWPRTTST:;%%
RETCODE = 0  Operation succeeded.


---    END
