List Cell Adaptive BFMIMO Configuration (LST CELLBFMIMOPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to adaptive switching between beamforming and MIMO. This command applies only to LTE TDD.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Cell Adaptive BFMIMO Configuration:
LST CELLBFMIMOPARACFG:;
The result is shown as follows:

O&M    #806355219

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

BfMIMO adaptive switch

Indicates the type of adaptive selection between beamforming and MIMO for a multi-antenna eNodeB. The values are described as follows:

NO_ADAPTIVE: A fixed beamforming or MIMO transmission mode is used. That is, transmission mode switching is not supported.

TxD_BF_ADAPTIVE: The transmission mode changes adaptively between TM2 and TM7 or between TM2 and TM8, depending on the 3GPP release with which UEs comply.

MIMO_BF_ADAPTIVE: The transmission mode changes adaptively among TM2, TM3, and TM7, among TM2, TM3, and TM8, or among TM2, TM3, TM8, and TM9, depending on the 3GPP release with which UEs comply. The TM9Switch option must be selected if the TM9 mode is required. This parameter applies only to LTE TDD.

Fixed BfMIMO mode

Indicates the fixed beamforming or MIMO transmission mode configured for a multi-antenna eNodeB. This parameter is valid only when the BfMimoAdaptiveSwitch parameter is set to NO_ADAPTIVE. This parameter applies only to LTE TDD. The values are described as follows:

TM2: Transmission mode 2 is always used for UEs.

TM3: Transmission mode 3 is always used for UEs.

TM7: Transmission mode 7 is always used for UEs.

TM8: Transmission mode 8 is always used for UEs.

TM4: Transmission mode 4 is always used for UEs.

TM9 w/o PMI: Transmission mode 9, which does not require PMI feedback, is always used for UEs.

TM9 w PMI: Transmission mode 9, which requires PMI feedback, is always used for UEs.

Bf Mimo Adaptive Without Tm2

Indicates whether TM2 can be selected during adaptation between beamforming and MIMO when the BfMimoAdaptiveSwitch parameter is set to MIMO_BF_ADAPTIVE. This parameter applies only to LTE TDD.

If this parameter is set to ON and the BfMimoAdaptiveSwitch parameter is set to MIMO_BF_ADAPTIVE:

1. When the BfMimoAdapWithTm4Switch parameter in the CellBfMimoParaCfg MO is set to OFF, TM3 is initially used for handovers in the cell, and then the transmission mode is adaptively selected between TM3

and TM7, between TM3 and TM8, or among TM3, TM8, and TM9 based on the version of 3GPP release that UEs comply with. If TM9 needs to be adaptively selected, the TM9Switch option of the EnhMIMOSwitch parameter must be selected.

2. When the BfMimoAdapWithTm4Switch parameter in the CellBfMimoParaCfg MO is set to ON, TM4 is initially used for handovers in the cell, and then the transmission mode is adaptively selected among TM2, TM4, and TM7, among TM2, TM4, and TM8, or among TM2, TM4, TM7, and TM8 based on the version of 3GPP release that UEs comply with.

If this parameter is set to OFF and the BfMimoAdaptiveSwitch parameter is set to MIMO_BF_ADAPTIVE:

1. When the BfMimoAdapWithTm4Switch parameter in the CellBfMimoParaCfg MO is set to OFF, TM2 is initially used for handovers in the cell, and then the transmission mode is adaptively selected among TM2, TM3, and TM7, among TM2, TM3, and TM8, or among TM2, TM3, TM8, and TM9 based on the version of 3GPP release that UEs comply with. If TM9 needs to be adaptively selected, the TM9Switch option of the EnhMIMOSwitch parameter must be selected.

2. When the BfMimoAdapWithTm4Switch parameter in the CellBfMimoParaCfg MO is set to ON, TM2 is initially used for handovers in the cell, and then the transmission mode is adaptively selected among TM2, TM4, and TM7, among TM2, TM4, and TM8, or among TM2, TM4, TM7, and TM8 based on the version of 3GPP release that UEs comply with.

Single to Dual Streaming Beamforming Threshold Offset(0.01bit/RE)

Indicates the offset to the threshold for switching of the UE transmission mode from single-stream beamforming mode to dual-stream beamforming mode. This parameter applies only to LTE TDD.

TM3 Rank2 To Dual Streaming Beamforming Threshold Offset(0.1bit/RE)

Indicates the offset to the threshold for switching the UE transmission mode from TM3 dual-stream mode to dual-stream beamforming mode. This parameter applies only to LTE TDD.

AS UE Dual BF To TM3 Rank2 Offset(0.1bit/RE)

Indicates the offset to the threshold for triggering switching of the transmission mode of UEs supporting antenna selection from dual-stream beamforming to TM3 rank 2. This parameter applies only to LTE TDD.

AS UE TM3 Rank2 To Dual BF Offset(0.1bit/RE)

Indicates the offset to the threshold for switching the transmission mode of an antenna selection-enabled UE from TM3 dual-stream mode to dual-stream beamforming mode. This parameter applies only to LTE TDD.

AS UE Single to Dual BF Offset(0.1bit/RE)

Indicates the offset to the threshold for switching the transmission mode of an antenna selection-enabled UE from single-stream beamforming mode to dual-stream beamforming mode. This parameter applies only to LTE TDD.

Dual Streaming Beamforming To TM3 Rank2 Offset(0.1bit/RE)

Indicates the offset to the threshold for switching the UE transmission mode from dual-stream beamforming mode to TM3 dual-stream mode. This parameter applies only to LTE TDD.

Offset Of In Statistics(0.1dB)

Indicates whether the measured weight has a gain. When the difference between the measured weight and the instantaneous weight is greater than the offset, the measured weight is used as the beamforming weight. This parameter applies only to LTE TDD.

Offset Of Out Statistics(0.1dB)

Indicates the offset to the difference between the instantaneous weight and the measured weight. This parameter is used to identify whether the instantaneous weight has a gain. If the difference between the instantaneous weight and the measured weight is less than this offset, the instantaneous weight is used for beamforming. This parameter applies only to LTE TDD.

Antenna Type-based BF and MIMO Algo Selection

Indicates the antenna type on which adaptive selection between beamforming and MIMO can be performed. This parameter applies only to LTE TDD.

Value 0(0) indicates 8T8R cross polarization antennas.

Value 1(1) indicates 8T8R omnidirectional circular antennas.

Value 2(2) indicates other antenna types.

Set this parameter based on the antenna type in use.

The Switch of Tm3 Direct to DualBF

Indicates whether to allow transmission mode switching directly from TM3 to dual-stream beamforming when adaptation between MIMO and beamforming is enabled. If this parameter is set to ON, the transmission mode can change directly from TM3 to dual-stream beamforming. If this parameter is set to OFF, TM3 must be changed to single-stream beamforming and then to dual-stream beamforming when the dual-stream beamforming mode is required. This parameter applies only to LTE TDD.

Scc Bf Mimo Adaptive Switch

Indicates whether to enable transmission mode adaptation for the SCC.

If this parameter is set to ON the eNodeB selects a transmission mode for the SCC based on the beamforming and MIMO mode of the SCell.

If this parameter is set to OFF for non-multi-RRU cells, the transmission mode of the SCC is fixed to TM3 in multi-antenna scenarios and TM1 in single-antenna scenarios.

If this parameter is set to OFF for multi-RRU cells, the transmission mode of the SCell is TM1 or TM2 (depending on the number of CRS ports) when all RRUs serving the SCell work in 1T1R mode, and is TM3 in other scenarios. This parameter applies only to LTE TDD.

High and Low Speed UE TM Switch Thld Offset(0.1bit/RE)

Indicates the difference between the threshold for triggering low-speed UE switching between beamforming mode and MIMO mode and that for triggering high-speed UE switching between beamforming mode and MIMO mode. This parameter takes effect only when adaptation between beamforming and MIMO is enabled. This parameter can be used for optimization if low-speed UEs cannot select an optimal transmission mode by using the adaptive selection function. If this parameter is set to 0, the same threshold for switching between beamforming and MIMO modes is adopted for low-speed and high-speed UEs. This parameter applies only to LTE TDD cells using 8T cross polarization antennas.

This parameter applies only to LTE TDD.

Transmission Mode Acceleration Switch

Indicates whether to accelerate the determination of transmission mode switching for UEs when adaptation between beamforming and MIMO is enabled. If this parameter is set to ON, the eNodeB adaptively accelerates the determination of transmission mode switching for all UEs based on their signal quality. In this way, the spectral efficiency improves in scenarios with traffic burst. If it is set to OFF, the acceleration function is disabled. If it is set to INITIAL_ACCESS_TO_BF, the eNodeB accelerates the determination of the switching from MIMO to beamforming during initial network access and accelerates the first update of the working RRU attribute of UEs after initial network access or incoming handovers in D-MIMO or SFN scenarios.

This parameter applies only to LTE TDD.

BfMIMO Adaptive with TM4

Indicates whether TM4 can be selected during the adaptation between beamforming and MIMO when the BfMimoAdaptiveSwitch parameter is set to MIMO_BF_ADAPTIVE. If this parameter is set to ON, TM4 can be selected during the adaptation between beamforming and MIMO. If this parameter is set to OFF, TM4 cannot be selected during the adaptation between beamforming and MIMO. This parameter applies only to LTE TDD.

TM3 and TM9 Switching Threshold Offset(0.1bit/RE)

Indicate the offset to the threshold for switching the UE transmission mode between TM9 with PMI and TM3 when adaptation between TM3, TM8, and TM9 is enabled in a cell. This parameter applies only to LTE TDD.

BF to Two Layer MUBF Threshold Offset(0.01bit/RE)

Indicates the offset to the threshold for triggering UE pairing in dual-stream MU BF mode for beamforming UEs. In omnidirectional antenna-based or directional antenna-based MU BF pairing scenarios, you are advised to set this parameter to the recommended value. A value that is close to the recommended value is also applicable. This parameter applies only to LTE TDD.

BF to Four Layer MUBF Threshold Offset(0.01bit/RE)

Indicates the offset to the threshold for triggering UE pairing in four-stream MU BF mode for beamforming UEs. In omnidirectional antenna-based or directional antenna-based high-order MU BF pairing scenarios, you are advised to set this parameter to the recommended value. A value that is close to the recommended value is also applicable. This parameter applies only to LTE TDD.

TM3 Rank2 To TM9 Rank4 Offset(0.1bit/RE)

Indicates the offset to the threshold for switching from TM3 rank 2 to 4-layer TM9. This parameter controls the probability of switching the UE transmission mode from TM3 rank 2 to 4-layer TM9. This parameter applies only to LTE TDD.

TM9 Rank4 To TM3 Rank2 Offset(0.1bit/RE)

Indicates the offset to the threshold for switching from TM9 quadruple-stream mode to TM3 dual-stream mode. This parameter controls the probability of switching the UE transmission mode from TM9 quadruple-stream mode to TM3 dual-stream mode. This parameter applies only to LTE TDD.

Handover BF Threshold Adjust Switch

If this parameter is set to ON and the source cell and target cell for an intra-frequency handover have the same calculation result of PCI mod 3, the eNodeB increases the probability of the handover UE entering the beamforming mode in the target cell, therefore increasing the downlink throughput. If this parameter is set to OFF, the original mechanism is used. This parameter applies only to LTE TDD.

Volte MIMO Adaptive Switch

Indicates the adaptive MIMO transmission mode of voice UEs. If this parameter is set to ADAPTIVE and the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to NO_ADAPTIVE(NO_ADAPTIVE), a fixed beamforming transmission mode specified by the FixedBfMimoMode parameter in the CellBfMimoParaCfg MO is used for both voice and other UEs. If this parameter is set to ADAPTIVE and the MimoAdaptiveSwitch parameter in the CellMimoParaCfg MO is set to NO_ADAPTIVE(NO_ADAPTIVE), a fixed MIMO transmission mode specified by the FixedMimoMode parameter in the CellMimoParaCfg MO is used for both voice and other UEs. If this parameter is set to FIX_RANK1, voice UEs are scheduled in rank 1 mode. This parameter applies only to LTE TDD.

CA SCC Add Threshold Offset(0.1bit/RE)

Indicates the channel quality threshold for adding an SCC for a CA UE. When the channel quality is good, a quadruple-stream-capable CA UE can achieve a higher peak transmission rate when fewer carriers are aggregated than when more carriers are aggregated. If the channel quality of this UE is lower than this threshold, the SCCs of the UE fail to enter the quadruple stream mode. To improve the transmission rate in this case, the eNodeB triggers addition of an SCC. This parameter applies only to LTE TDD.

CA SCC Delete Threshold Offset(0.1bit/RE)

Indicates the channel quality threshold for removing an SCC for a CA UE. When the channel quality is good, a quadruple-stream-capable CA UE can achieve a higher peak transmission rate when fewer carriers are aggregated than when more carriers are aggregated. If the channel quality is higher than this threshold, the eNodeB triggers removal of an SCC. Then, the remaining SCCs can enter the quadruple stream mode to increase the transmission rate. This parameter applies only to LTE TDD.

BfMimo Algorithm Optimization Switch

BFTOMIMOALGOOPTSWITCH: Indicates whether to optimize switching from beamforming to MIMO and rank detection for MIMO. If this option is selected, switching from beamforming to MIMO and rank detection for MIMO are optimized to increase the rank 2 success rate. If this option is deselected, switching from beamforming to MIMO or rank detection for MIMO is not optimized. This option applies only to LTE TDD.

BFMIMOADAPWITHOUTTM8: Indicates whether TM8 is available during adaptation between beamforming and MIMO or during open-loop beamforming adaptation. If this option is selected and the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE or TxD_BF_ADAPTIVE, the transmission mode cannot be switched to TM8. If this option is deselected and the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE or TxD_BF_ADAPTIVE, the transmission mode can be switched to TM8. This option applies only to LTE TDD.

FIXEDTM9WPMIOPTSWITCH: Indicates whether UEs can enter closed-loop TM9 mode that always requires PMI feedback from UEs, regardless of channel calibration results. If this option is selected, UEs can enter TM9 mode that always requires PMI feedback from UEs even when the channel calibration results do not meet requirements. If this option is deselected, UEs cannot enter this transmission mode when the channel calibration results do not meet requirements. This option applies only to LTE TDD.

BFMIMOADAPTATIONOPTSW: Indicates whether to enabled optimized adaptation between beamforming and MIMO. If this option is selected, optimized adaptation between beamforming and MIMO is enabled. If this option is deselected, optimized adaption between beamforming and MIMO is disabled. This option applies only to LTE TDD.

HEAVYLOADTRANSMODEADAPTBOOSTSW: Indicates whether to enable enhanced transmission mode adaptation in heavy-load scenarios. If this option is selected, enhanced transmission mode adaptation is enabled in heavy-load scenarios. The eNodeB automatically implements transmission mode adaptation or uses the target transmission mode in heavy-load scenarios to achieve optimal spectral efficiency in the cell. If this option is deselected, enhanced transmission mode adaptation is disabled in heavy-load scenarios. This option applies only to LTE TDD.

HISTORICALSPECTRALEFFOPTSW: Indicates whether to enable historical spectral efficiency optimization when enhanced transmission mode adaptation is enabled in heavy-load scenarios. If this option and the HEAVYLOADTRANSMODEADAPTBOOSTSW option are selected, historical spectral efficiency optimization takes effect. The eNodeB automatically learns historical cell spectral efficiency achieved during transmission mode adaptation and when the target transmission mode is used in heavy-load scenarios, and automatically selects a transmission mode to achieve optimal spectral efficiency in the cell. If this option is deselected when the HEAVYLOADTRANSMODEADAPTBOOSTSW option is selected, historical spectral efficiency optimization does not take effect. In this case, the cell always uses the target transmission mode in heavy-load scenarios. This option applies only to LTE TDD.

BF_WEIGHT_GRAN_OPT_SWITCH: Indicates whether to enable massive MIMO beamforming weight granularity optimization. If this option is selected, the weight granularity is selected based on the SRS SINR. If this option is deselected, the weight granularity is selected based on the original policy. This option applies only to LTE TDD.

NON_AS_UE_MAX_BF_RANK_CTRL_SW: Indicates the maximum number of beamforming multiplexing layers for non-antenna selection UEs in massive MIMO cells. If both the FakeAntSelIdentificationSwitch option of the BfAlgoSwitch parameter in the CellAlgoSwitch MO and this option are selected, the maximum number of beamforming multiplexing layers is always rank 1 for non-antenna selection UEs (including fake antenna selection UEs). Otherwise, the maximum number of beamforming multiplexing layers for non-antenna selection UEs (including fake antenna UEs) is specified by the MaxBfRankPara parameter in the CELLBF MO. This option applies only to LTE TDD.

LOAD_BASED_TMA_OPT_SW: Indicates whether to enable load-based adaptive transmission mode optimization. If this option is selected, the transmission mode is selected for UEs based on the cell load during UE access. When the cell load is light, TM3 is preferentially selected. In addition, if the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, 4R UEs and 8R UEs entering PMI feedback-dependent TM9 is accelerated. When the cell load is heavy, beamforming mode is preferentially selected. If this option is deselected, the original transmission mode selection procedure applies. This option applies only to LTE TDD.

INCREASE_SM_LAYER_TMA_OPT_SW: Indicates whether to enable TMA optimization for increasing the number of spatial multiplexing layers in a cell. This function is enabled only if this option is selected. This option applies only to LTE TDD.

Initial BFMIMO Mode

Indicates the beamforming and MIMO mode used during initial network access. This parameter applies only to LTE TDD. When the CrsPortNum parameter in the Cell MO is set to CRS_PORT_4(4 ports) and the BfMimoAdapWithTm4Switch parameter in the CellBfMimoParaCfg MO is set to ON(On), the value TM3(TM3) of this parameter does not take effect. If this value is set in this case, TM2 is used as the beamforming and MIMO mode during initial network access.

Multi-Layer Pairing Isolation Threshold

Indicates the UE isolation threshold for triggering multi-layer pairing. This parameter must be set based on UE conditions in the cell. This parameter applies only to LTE TDD.

UE Access Transmission Mode

Indicates the transmission mode during an E-RAB setup procedure and an incoming handover procedure for a UE in a massive MIMO cell with the BfMimoAdaptiveSwitch parameter of the CellBfMimoParaCfg MO set to MIMO_BF_ADAPTIVE. If this parameter is set to TM7, TM7 is used. If this parameter is set to AUTOMATIC, MIMO is used. This parameter applies only to LTE TDD.

256QAM TM3 to TM9 Switching Spectral Eff Offset(0.1bit/RE)

Indicates the spectral efficiency offset for switching the UE transmission mode from TM3 to TM9 if 256QAM is used. This parameter applies only to LTE TDD.

256QAM TM9 to TM3 Switching Spectral Eff Offset(0.1bit/RE)

Indicates the spectral efficiency offset for switching the UE transmission mode from TM9 to TM3 if 256QAM is used. This parameter applies only to LTE TDD.

Heavy Load Average UE Count Threshold

Indicates the threshold of the number of UEs for identifying heavy-load cells and triggering enhanced transmission mode adaptation in heavy-load scenarios. If the average number of UEs in a cell exceeds this threshold in an evaluation period and the average downlink PRB usage in the cell exceeds the PRB usage threshold, the cell is considered heavily loaded. If the average number of UEs in a cell is smaller than or equal to this threshold, or the average downlink PRB usage in the cell is smaller than or equal to the PRB usage threshold, the cell is considered lightly loaded. This parameter applies only to LTE TDD.

Heavy Load Downlink PRB Usage Threshold(%)

Indicates the PRB usage threshold for identifying heavy-load cells and triggering enhanced transmission mode adaptation in heavy-load scenarios. If the average downlink PRB usage in the cell exceeds this threshold in an evaluation period and the average number of UEs in the cell exceeds the UE quantity threshold, the cell is considered heavily loaded. If the average downlink PRB usage in the cell is less than or equal to this threshold, or the average number of UEs in the cell is less than or equal to the UE quantity threshold, the cell is considered lightly loaded. This parameter applies only to LTE TDD.

Heavy Load Target Trans Mode

Indicates the target transmission mode for enhanced transmission mode adaptation in heavy-load scenarios. If this parameter is set to TM7, the eNodeB automatically implements transmission mode adaptation or uses TM7 mode to achieve optimal spectral efficiency in a heavy-load cell. If this parameter is set to TM8, the eNodeB automatically implements transmission mode adaptation or uses TM8 mode (open-loop TM9 mode is used for UEs supporting TM9 mode) to achieve optimal spectral efficiency in a heavy-load cell. This parameter applies only to LTE TDD.

Heavy Load Trans Mode Evaluation Period(30s)

Indicates the transmission mode evaluation period for enhanced transmission mode adaptation. This period is a multiple of 30s. The eNodeB evaluates the cell load in this period and updates statistics of cell spectral efficiency. This parameter applies only to LTE TDD.

WTTx UE TM3 to TM9 Rank4 Ofs(0.1bit/RE)

Indicates the offset to the threshold for switching the transmission mode of WTTx UEs from TM3 to 4-layer TM9. The value 127 indicates that the function does not take effect. This parameter applies only to LTE TDD.

TM9 DL 4-Layer MIMO Enhancement Switch

Indicates whether to enabled enhanced downlink 4-layer MIMO based on TM9.

TM9_DL_4LAYER_BOOST_SWL Indicates whether to enable enhanced downlink 4-layer TM9. If this option is selected, UEs near the cell center can quickly enter TM9 mode. If this option is deselected, UEs near the cell center cannot quickly enter TM9 mode. This option applies only to LTE TDD.

4R or 8R UE BF MIMO Adaptation Opt Sw

Indicates whether to enable optimization of adaptive switching between beamforming and MIMO for 4R and 8R UEs. This parameter applies only to LTE TDD.
