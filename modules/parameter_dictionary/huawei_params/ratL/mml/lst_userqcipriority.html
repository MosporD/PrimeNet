List User Qci Priority (LST USERQCIPRIORITY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to ARP- and QCI-based scheduling weight factors.

Note

None.

Parameters

ID Name Description
Qci QoS Class Identifier

Meaning: Indicates the QCI of an EPS bearer. Different QCIs represent different QoS specifications such as the packet delay budget, packet error loss rate, and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: QCI6(QCI6), QCI7(QCI7), QCI8(QCI8), QCI9(QCI9)

Unit: None

Actual Value Range: QCI6, QCI7, QCI8, QCI9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List User Qci Priority:
LST USERQCIPRIORITY:;

Output Description

Field Description

QoS Class Identifier

Indicates the QCI of an EPS bearer. Different QCIs represent different QoS specifications such as the packet delay budget, packet error loss rate, and resource type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

Gold Uplink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during uplink scheduling for gold users. This parameter applies only to LTE FDD and LTE TDD.

Gold Downlink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during downlink scheduling for gold users. This parameter applies only to LTE FDD and LTE TDD.

Silver Uplink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during uplink scheduling for silver users. This parameter applies only to LTE FDD and LTE TDD.

Silver Downlink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during downlink scheduling for silver users. This parameter applies only to LTE FDD and LTE TDD.

Bronze Uplink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during uplink scheduling for bronze users. This parameter applies only to LTE FDD and LTE TDD.

Bronze Downlink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during downlink scheduling for bronze users. This parameter applies only to LTE FDD and LTE TDD.

Iron Uplink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during uplink scheduling for iron users. This parameter applies only to LTE FDD and LTE TDD.

Iron Downlink Schedule Priority Factor

Indicates the weight factor used to calculate the connection priorities during downlink scheduling for iron users. This parameter applies only to LTE FDD and LTE TDD.
