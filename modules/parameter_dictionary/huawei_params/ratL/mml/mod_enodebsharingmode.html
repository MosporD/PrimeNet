Modify eNodeB Sharing Mode (MOD ENODEBSHARINGMODE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to change the eNodeB sharing mode.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the eNodeB works in independent mode, only one operator can be added to the eNodeB. This operator must be the primary operator.

  • After this command is executed, run RST APP to reset the application referenced by the eNodeBFunction MO for the application to take effect. You can run LST ENODEBFUNCTION to view the application referenced by the eNodeBFunction MO. If the application referenced by the eNodeBFunction MO is not reset within 10 minutes after the eNodeB sharing mode is changed by running this command, ALM-26245 Configuration Data Inconsistency will be reported.

  • When the ENodeBSharingMode parameter is changed to HYBRID_SHARED, the CnOpSharingGroupId parameter in the associated S1Interface, X2Interface, S1, X2, Cell MOs must be set to a valid value. In different RAN sharing modes, the maximum number of operators that can be added and the restrictions for the relationship between the configurations of these MOs and operators are different. When the eNodeB sharing mode is changed to hybrid RAN sharing from others, the configurations of multiple MOs need to be modified at the same time. You are advised to use MAE to perform the configuration modification in batches. When using the MML command to change the eNodeB sharing mode to hybrid RAN sharing, you are advised to remove these MOs and then set the ENodeBSharingMode to HYBRID_SHARED. After this, re-add the MOs as required.

Parameters

ID Name Description
ENodeBSharingMode eNodeB sharing mode

Meaning: Indicates the eNodeB sharing mode, which can be independent operator mode, RAN sharing with common carrier, RAN sharing with dedicated carrier, hybrid RAN sharing, or RAN sharing with special dedicated carrier.

GUI Value Range: INDEPENDENT(Independent Operator Mode), SHARED_FREQ(Shared Frequency Sharing Mode), SEPARATED_FREQ(Separate Frequency Sharing Mode), HYBRID_SHARED(Hybrid RAN Sharing), SEPARATED_FREQ_SPEC(Special Separate Frequency Sharing Mode)

Unit: None

Actual Value Range: INDEPENDENT, SHARED_FREQ, SEPARATED_FREQ, HYBRID_SHARED, SEPARATED_FREQ_SPEC

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To change the value of eNodeB sharing mode to INDEPENDENT, run the following command:
MOD ENODEBSHARINGMODE: ENodeBSharingMode=INDEPENDENT;
