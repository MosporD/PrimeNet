Modify Cell RF Channel Intelligent Shutdown Configuration (MOD CELLRFSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of RF channel intelligent shutdown in a cell.

Note

  • A cell enters RF channel intelligent shutdown state when all of the following conditions are met: (1) The RF channel intelligent shutdown switch is turned on. (2) The current time is between the start time and end time for RF channel intelligent shutdown. (3) The number of UEs and PRB usage in the cell reach the corresponding thresholds. (4) The number of antennas of the cell meets the criteria. (5) The cell bandwidth meets the criteria. (6) The cell power configuration and aggregation level for common signaling meet the criteria. (7) The current time is not within the last penalty period for exit from RF channel intelligent shutdown state.

  • Cells with only one transmit channel do not support RF channel intelligent shutdown.

  • Cells with a bandwidth of 5 MHz or less do not support RF channel intelligent shutdown.

  • If a cell enters RF channel intelligent shutdown state, carriers are blocked and channels are shut down for the cell.

  • If a cell enters RF channel intelligent shutdown state, UEs can be scheduled in only TM2 mode.

  • If a cell enters RF channel intelligent shutdown state, PDCCH symbol adaptation is not supported.

  • If a cell enters RF channel intelligent shutdown state, the number of available RBs is reduced for the cell.

  • The PRB threshold for exit from RF channel intelligent shutdown state (sum of the corresponding PRB usage threshold and offset) must not be too high. Otherwise, a cell cannot exit from RF channel intelligent shutdown state.

  • LTE TDD cells in cell combination mode do not support RF channel intelligent shutdown.

  • The coverage area of an NB-IoT cell shrinks after it enters the RF channel intelligent shutdown state.

  • If an NB-IoT cell is configured with an LTE in-band carrier, the NB-IoT cell can enter the RF channel intelligent shutdown state only when both the NB-IoT cell and the FDD cell associated with the in-band carrier of the NB-IoT cell meet the conditions for entering the RF channel intelligent shutdown state.

DlPrbThd Downlink PRB threshold

Meaning: Indicates the downlink PRB usage threshold for RF channel intelligent shutdown. For NB-IoT cells, this parameter indicates the downlink subcarrier usage threshold for RF channel intelligent shutdown. A cell enters the RF channel intelligent shutdown mode when the current cell load is less than or equal to both the uplink PRB usage threshold and downlink PRB usage threshold. A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a lower probability that the cell will enter the RF channel intelligent shutdown mode, which does not facilitate eNodeB power saving. A larger value of this parameter leads to a higher probability that the cell will enter the RF channel intelligent shutdown mode, which affects services.

UENumThd UE Number Threshold

Meaning: Indicates the UE number threshold for RF channel intelligent shutdown. The cell enters RF channel intelligent shutdown mode if all of the following conditions are met: (1) the number of RRC_CONNECTED UEs is less than or equal to this threshold; (2) the uplink cell load is lower than or equal to the preset uplink PRB usage; (3) the downlink cell load is lower than or equal to the preset downlink PRB usage. The cell exits RF channel intelligent shutdown mode if any of the following conditions is met: (1) the number of RRC_CONNECTED UEs exceeds this threshold; (2) the uplink cell load is higher than the sum of the uplink PRB usage threshold and the uplink PRB usage offset; (3) the downlink cell load is higher than the sum of the downlink PRB usage threshold and the downlink PRB usage offset. A smaller value of this parameter leads to a lower probability that the cell will enter RF channel intelligent shutdown, which does not facilitate base station power saving. A larger value of this parameter leads to a higher probability that the cell will enter RF channel intelligent shutdown, which affects services. For LTE TDD cells, this parameter takes effect only when the RfShutdownJudgingPolicy parameter in the CellRfShutdown MO is set to PRB_AND_UE_NUMBER.

GUI Value Range: 0~60

Unit: None

Actual Value Range: 0~60

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer time that a cell stays in the RF channel intelligent shutdown mode and a larger impact on average cell throughput in the downlink. A smaller value of this parameter results in the opposite effects. If this parameter is set to 0, a cell enters the RF channel intelligent shutdown mode when no UE in RRC_CONNECTED mode exists in the cell.

Applicable Mode: L
RfShutdownJudgingPolicy RF Intelligent Shutdown Judging Policy

Meaning: Indicates the basis for entering or exiting RF channel intelligent shutdown. If this parameter is set to PRB(PRB), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage of the cell. If this parameter is set to PRB_AND_UE_NUMBER(PRB_AND_UE_NUMBER), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage and the number of online UEs in the cell. This parameter applies only to LTE TDD.

GUI Value Range: PRB(PRB), PRB_AND_UE_NUMBER(PRB_AND_UE_NUMBER)

Unit: None

Actual Value Range: PRB, PRB_AND_UE_NUMBER

MML Default Value: None

Recommended Value: PRB(PRB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to PRB(PRB), the eNodeB determines whether to perform or terminate RF channel intelligent shutdown for the cell based on the uplink and downlink PRB usage of the cell. In this case, RF channel intelligent shutdown can be performed for a cell with a large number of online UEs but a low PRB usage. This affects UE services, but saves power for the eNodeB. If this parameter is set to PRB_AND_UE_NUMBER(PRB_AND_UE_NUMBER), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage and the number of online UEs in the cell. In this case, RF channel intelligent shutdown cannot be performed for a cell with a large number of online UEs but a low PRB usage. This does not affect UE services, but hinder power saving of the eNodeB.

Applicable Mode: L-TDD
RfChnShutdownPwrCheckSw RF Channel Shutdown Power Check Switch

Meaning: Indicates whether to enable power check for RF channel shutdown. SYMBOL_0_POWER_CHECK_OPT_SW: Indicates whether to enable symbol 0 power check optimization for RF channel shutdown. If this option is selected, symbol 0 power check optimization is performed after RF channel shutdown takes effect, preventing continuous PDCCH allocation failures. If this option is deselected, symbol 0 power check optimization is not performed after RF channel shutdown takes effect, which may lead to continuous PDCCH allocation failures. This option applies only to LTE TDD.

GUI Value Range: SYMBOL_0_POWER_CHECK_OPT_SW(SYMBOL_0_POWER_CHECK_OPT_SW)

Unit: None

Actual Value Range: SYMBOL_0_POWER_CHECK_OPT_SW

MML Default Value: None

Recommended Value: SYMBOL_0_POWER_CHECK_OPT_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SYMBOL_0_POWER_CHECK_OPT_SW: If this option is selected, PDCCH allocation for UEs will not continuously fail after RF channel shutdown takes effect. Some performance indicators are improved, including the RRC connection setup success rate, the service drop rate, and the number of successful PDCCH allocations. In addition, the duration for which RF channel shutdown takes effect decreases. If this option is deselected, there is a low probability that PDCCH allocation for UEs continuously fails after RF channel shutdown takes effect and a low probability that some performance indicators deteriorate, such as the RRC connection setup success rate, the service drop rate, and the number of successful PDCCH allocations.

Applicable Mode: L-TDD

Example

To modify the configuration of RF channel intelligent shutdown in the cell with the parameters as follows: Local cell ID: 0, RF intelligent shutdown switch: ON, Start time: 00:00:00, Stop time: 06:00:00, Reference signal power adjust offset: 3, UE Number Threshold: 1, run the following command:
MOD CELLRFSHUTDOWN: LocalCellId=0, RfShutdownSwitch=ON, StartTime=00&00&00, StopTime=06&00&00, RsPwrAdjOffset=3, UENumThd=1;
