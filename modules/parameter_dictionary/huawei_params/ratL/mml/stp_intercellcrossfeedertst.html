Stop Cable Sequence Check Between Cells (STP INTERCELLCROSSFEEDERTST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to stop a cable sequence check between cells.

Note

None.

Parameters

None.

Example

To stop a cable sequence check between cells, run the following command:
STP INTERCELLCROSSFEEDERTST:;
