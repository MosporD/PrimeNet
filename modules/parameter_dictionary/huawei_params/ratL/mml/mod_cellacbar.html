Modify Cell Access Barring Configuration (MOD CELLACBAR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell access barring.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If ac-BarringFactor is set to a value other than P00, this value takes effect only if signaling from UEs of access class 11 to access class 15 is not barred.

  • By setting related parameters to control the access to the cell, operators can effectively avoid channel overload.

AcBarringInfoCfgInd AC barring information configure indicator

Meaning: Indicates the AC barring information configuration mode.

If this parameter is set to NOT_CFG, AC barring information is not configured.

If this parameter is set to CFG, AC barring information is configured.

If this parameter is set to OPERATOR_BASED_CFG, AC barring information is configured based on operator information.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure), OPERATOR_BASED_CFG(Operator-based configuration)

Unit: None

Actual Value Range: NOT_CFG, CFG, OPERATOR_BASED_CFG

MML Default Value: None

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode. This parameter is used with other parameters related to cell access barring to control the UE accesses.)

Impact on Radio Network Performance: If AcBarringForMoDataCfgInd or AcBarringForMoSigCfgInd in SIB2 is set to CFG, the UE generates a random number in the range [0, 1). If the random number is smaller than the value of AcBarringFactorForCall or AcBarringFactorForSig, the UE considers access to the cell as allowed. That is, an RRC connection can be set up for the mobile-originated call or signaling. A larger value of AcBarringFactorForCall or AcBarringFactorForSig leads to a higher probability of granting access to a UE, which may increase cell load. A smaller value of AcBarringFactorForCall or AcBarringFactorForSig leads to a lower probability of granting access to a UE. As a result, a UE may fail to access the cell even when the cell load is relatively light. If this parameter is set to P00, no RRC connection for the mobile-originated call or signaling can be set up.

Applicable Mode: L-FDD, L-TDD
AcBarringForEmergency Emergency call barring state

Meaning: Indicates the barring status of access class 10. This parameter specifies whether UEs are allowed to initiate emergency calls.

If this parameter is set to BOOLEAN_TRUE, UEs of access classes 0 to 9 or UEs without IMSIs are not allowed to initiate emergency calls. If this parameter is set to BOOLEAN_FALSE, UEs of access classes 0 to 9 or UEs without IMSIs are allowed to initiate emergency calls.

A UE of access class 11 to 15 are not allowed to initiate emergency calls only when its access class and access class 10 are both barred. If its access class or access class 10 is not barred, the UE is allowed to initiate emergency calls. This parameter applies only to LTE FDD and LTE TDD.

AcBarringFactorForCall Access probability factor for originating call

Meaning: Indicates the access probability factor for mobile-originated calls. A mobile-originated call is granted access if the random number generated by the UE is less than this access probability factor; otherwise, the access request is rejected. According to 3GPP TS 36.331, if any of the parameters AC11BarforCall, AC12BarforCall, AC13BarforCall, AC14BarforCall, and AC15BarforCall is set to BOOLEAN_TRUE, the eNodeB sends UEs P00 as the access probability factor for mobile-originated calls in the system information block type 2 (SIB2), regardless of the actual setting of the AcBarringFactorForCall parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: P00(0%), P05(5%), P10(10%), P15(15%), P20(20%), P25(25%), P30(30%), P40(40%), P50(50%), P60(60%), P70(70%), P75(75%), P80(80%), P85(85%), P90(90%), P95(95%)

Unit: %

Actual Value Range: P00, P05, P10, P15, P20, P25, P30, P40, P50, P60, P70, P75, P80, P85, P90, P95

MML Default Value: None

Recommended Value: P95(95%)

Parameter Relationship:

-Others:

  • AcBarringFactorForCall is optional, depending on the setting of AcBarringForMoDataCfgInd.

Service Interrupted After Modification: No (For the UE in idle mode, the source call accesses are allowed only when the random number generated by the UE is smaller than the access probability factor.)

Impact on Radio Network Performance: If AcBarringForMoDataCfgInd in SIB2 is set to CFG, the UE generates a random number in the range [0,1). If the random number is smaller than the value of this parameter, the UE considers access to the cell as allowed. That is, an RRC connection can be set up for the mobile-originated call. If this parameter is set to a large value, the probability of allowing access to the cell is high, which may lead to a high cell load. If this parameter is set to a small value, the probability of allowing access to the cell is low. As a result, UEs may fail to access the cell even when the cell load is relatively light. If this parameter is set to P00, an RRC connection is prohibited from being set up for the mobile-originated call.

Applicable Mode: L-FDD, L-TDD
