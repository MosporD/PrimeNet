Add Sector Equipment Id to Group (ADD EUSECTOREQMID2GROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a sector equipment ID to a sector equipment group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The total number of sector equipments configured for a sector equipment group cannot exceed 16.

  • The modifications on the sector equipment group configuration of an active cell would result in the automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmGroupId Sector Equipment Group ID

Meaning: Indicates the group ID of the sector devices that serve the cell, it uniquely identifies a group of sector devices within a cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • CellId on which SectorEqmGroupId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of the sector equipment that serves the cell.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To add a sector equipment to a sector equipment group with the parameters as follows: LocalCellId=0, SectorEqmGroupId=0, SectorEqmId=0, run the following command:
ADD EUSECTOREQMID2GROUP: LocalCellId=0, SectorEqmGroupId=0, SectorEqmId=0;
