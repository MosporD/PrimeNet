List Intelligent Optimization Feature (LST LIOPTFEATURE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list settings of parameters related to intelligent optimization features.

Note

None.

Parameters

ID Name Description
IOptFeatureID Intelligent Optimization Feature ID

Meaning: Indicates the ID of the intelligent optimization feature. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of intelligent optimization features, run the following command: :
LST LIOPTFEATURE:;
The result is shown as follows:
+++    0        2019-12-05 17:34:49
O&M    #806356071
%%LST LIOPTFEATURE: IOptFeatureID=1;%%
RETCODE = 0  Operation succeeded.

List Intelligent Optimization Feature
-------------------------------------
  Intelligent Optimization Feature ID  =  1
Intelligent Optimization Feature Name  =  Automatic Congestion Handling
(Number of results = 1)


---    END

Output Description

Field Description

Intelligent Optimization Feature ID

Indicates the ID of the intelligent optimization feature. This parameter applies only to LTE FDD and LTE TDD.

Intelligent Optimization Feature Name

Indicates the name of the intelligent optimization feature. This parameter applies only to LTE FDD and LTE TDD.
