List CellRachCECfg Configuration in an NB-IoT Cell (LST CELLRACHCECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list coverage-level-specific RACH configurations in an NB-IoT cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
CoverageLevel Coverage Level

Meaning: Indicates the cell coverage level for random access. The value COVERAGE_LEVEL_0 indicates coverage level 0. The value COVERAGE_LEVEL_1 indicates coverage level 1. The value COVERAGE_LEVEL_2 indicates coverage level 2. This parameter applies only to NB-IoT.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

To list the coverage-level-specific RACH configurations of an NB-IoT cell:
LST CELLRACHCECFG: LocalCellId=1;

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

Coverage Level

Indicates the cell coverage level for random access. The value COVERAGE_LEVEL_0 indicates coverage level 0. The value COVERAGE_LEVEL_1 indicates coverage level 1. The value COVERAGE_LEVEL_2 indicates coverage level 2. This parameter applies only to NB-IoT.

Contention Resolution Timer

Indicates the length of the timer that governs the period in which a UE waits for message 4 (Msg4) during a random access (RA) procedure. This timer starts when a UE initially sends or resends message 3 (Msg3). This timer stops when the UE receives Msg4 or NACK to Msg3 within the length of the timer. If the UE does not receive either message until the timer expires, the RA fails, and the UE must reinitiate an RA procedure. It is recommended that this parameter be set to a relatively large value (such as PP_16) when a large number of UEs are initiating random access simultaneously or there is a large number of high-coverage-level UEs (the average number of high-coverage-level UEs performing random access per second is 0.5 or more or the uplink or downlink subcarrier resource usage reaches 65% or more). PP_1 indicates one PDCCH period, PP_2 indicates two PDCCH periods, and so on. This parameter applies only to NB-IoT.

Maximum Number of Preamble Attempt

Indicates the maximum number of preamble transmissions for random access attempts at the corresponding cell coverage level. This parameter applies only to NB-IoT.

EDT Contention Resolution Timer

Indicates the timer governing the period in which a UE waits for Msg4 after sending Msg3 for EDT to the eNodeB during an RA procedure initiated by the UE using contention-based PRACH resources. This timer starts when a UE initially transmits or retransmits Msg3. If the UE receives Msg4 or NACK to Msg3 before the timer expires, the timer stops. If the timer expires, the RA fails. In this case, the UE must reinitiate an RA procedure.

If a large number of UEs initiate access concurrently, a large number of UEs are at high coverage levels, or the EdtDlDataWaitingTimer parameter in the CellEdtConfig MO is set to a large value, you are advised to set the EdtContentionResTimer parameter to a larger value and enable early contention resolution. This parameter applies only to NB-IoT.

RA Response Window Size

Indicates the random access response (RAR) window size. This parameter can be set to different values for different coverage levels of a cell. This parameter applies only to NB-IoT.
