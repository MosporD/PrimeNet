Display Cell Channel Calibration Result (DSP CELLCALIBRATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the channel calibration result of a cell. The command output includes historical data and some details of the calibration results. Pay attention to the calibration time and cell activation time.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Example 1: To list the cell channel calibration result with the local cell ID of 1, run the following command:
DSP CELLCALIBRATION: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Serving Sector Equipment(Group) eNB ID

Indicates the ID of the eNodeB equipped with the serving sector equipment(group).

Serving Sector Equipment Type

Indicates the type of sector equipment in the serving cell.

Serving Sector Equipment(group) ID

Indicates the ID of the serving sector equipment(group).

Calibration Index

Indicates the cell-level channel calibration index. Results of a maximum of 10 channel calibrations can be displayed in the DSP CELLCALIBRATION command output.

Calibration Result

Indicates the cell-level channel calibration result. If channel calibration fails (for example, due to a low SINR) in cells served by combined RRUs, the antenna system must be adjusted.

Calibration Time

Indicates the end time of a cell-level channel calibration.

Calibration Type

Indicates the cell-level channel calibration type.

eNodeB ID

Indicates the ID of the eNodeB.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

TX Channel No.

Indicates information about the TX channel of a cell.

Tx Channel CINR(dB)

Indicates the CINR of a TX channel.

RX Channel No.

Indicates information about the RX channel of a cell.

Rx Channel CINR(dB)

Indicates the CINR of an RX channel.

Calibration Information Code

Indicates the channel calibration information code, which is used to assist channel calibration status analysis. This parameter applies only to LTE FDD and LTE TDD.

Calibration Record Time 1

Indicates calibration recording time 1. This parameter applies only to LTE FDD.

Calibration Record Time 2

Indicates calibration recording time 2. This parameter applies only to LTE FDD.
