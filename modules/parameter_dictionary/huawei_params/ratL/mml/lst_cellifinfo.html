List Cell Intermediate Frequency Information (LST CELLIFINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list cell intermediate frequency information.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the configurations of the intermediate frequency of a cell:
LST CELLIFINFO:;
The result is shown as follows:
+++    0        2018-11-08 21:32:34
O&M    #806355066
%%LST CELLIFINFO: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local cell ID

This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

Intermediate Frequency DL Center Frequency(0.1MHz)

Indicates the downlink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.

Intermediate Frequency Output Power(0.1dBm)

Indicates the output power of the intermediate frequency. This parameter applies only to LTE FDD.

Intermediate Frequency Power Offset(0.1dB)

Indicates the output power offset of the intermediate frequency. This parameter applies only to LTE FDD.

Intermediate Frequency RX Channel Gain(0.1dB)

Indicates the RX channel gains of the intermediate frequency. This parameter applies only to LTE FDD.

Intermediate Frequency UL Center Frequency(0.1MHz)

Indicates the uplink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.
