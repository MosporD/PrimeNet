Modify a cell simulated load control configuration (MOD CELLSIMULOAD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a cell simulated load control configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SimLoadCfgIndex Configure Index

Meaning: Indicates the index of a simulated load configuration. One eNodeB can store a maximum of 10 simulated load configurations. They are identified by indexes ranging from 0 to 9 and correspond to RB usage thresholds (specified by the SimuLoadRbThd parameter) 10% to 100% at a step of 10%. For example, the RB usage thresholds for simulated load configurations 1 and 4 are 20% and 50%, respectively. Alternatively, you can also manually specify the RB usage threshold for a simulated load configuration by setting the SimuLoadRbThd parameter.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SimuLoadTransMode SimuLoad transmission mode

Meaning: Indicates the transmission mode adopted by the simulated load configuration, including:

TM1: indicates transmission mode 1 for the simulated load configuration.

TM2: indicates transmission mode 2 for the simulated load configuration.

TM4: indicates transmission mode 4 for the simulated load configuration.

TM7: indicates transmission mode 7 for the simulated load configuration.

TM8: indicates transmission mode 8 for the simulated load configuration.

TM9: indicates transmission mode 9 for the simulated load configuration.

Load simulation for TM4 and TM9 is used in 4T/8T MIMO cells to simulate interference for 4T/8T transmissions.

GUI Value Range: TM1(TM1), TM2(TM2), TM4(TM4), TM7(TM7), TM8(TM8), TM9(TM9)

Unit: None

Actual Value Range: TM1, TM2, TM4, TM7, TM8, TM9

MML Default Value: None

Recommended Value: TM2(TM2)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
AutoRmvTime Cell Simuload Automatic Remove Time

Meaning: Indicates the period of time exceeding which the cell simulated load is automatically removed. After this parameter value is changed, the time for automatically removing the cell simulated load restarts. If this parameter is changed to a value the same as the previous value of this parameter, the time does not restart. If this parameter is set to 0, the cell simulated load will not be automatically removed.

GUI Value Range: 0~70560

Unit: min

Actual Value Range: 0~70560

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the cell simulated load control configuration with the parameters as follows: Local cell ID: 0, Configure Index: 0, SimuLoad transmission mode: TM2, run the following command:
MOD CELLSIMULOAD: LocalCellId=0, SimLoadCfgIndex=0, SimuLoadTransMode=TM2;
