Modify Cell UL Power Control Configuration (MOD CELLULPCCOMM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of uplink power control for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PassLossCoeff Path loss coefficient

Meaning: Indicates the compensation factor for path loss. It is used in UL power control. For details, see 3GPP TS 36.213.

GUI Value Range: AL0(0), AL04(0.4), AL05(0.5), AL06(0.6), AL07(0.7), AL08(0.8), AL09(0.9), AL1(1)

Unit: None

Actual Value Range: AL0, AL04, AL05, AL06, AL07, AL08, AL09, AL1

MML Default Value: None

Recommended Value: AL07(0.7)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of the PassLossCoeff parameter affects that of the P0NominalPUSCH parameter when the InnerLoopPuschSwitch option of the UlPcAlgoSwitch parameter is cleared. If PassLossCoeff is set to a small value, it is recommended that P0NominalPUSCH be set to a large value to achieve higher sector throughput. If the PassLossCoeff parameter is set to a large value, it is recommended that P0NominalPUSCH be set to a small value to achieve higher data rates for CEUs. When the InnerLoopPuschSwitch option of the UlPcAlgoSwitch parameter is selected, a smaller value of the PassLossCoeff parameter results in lower initial transmit power of the PUSCH and lower interference of the local cell; a larger value of the PassLossCoeff parameter leads to the opposite effects.

Applicable Mode: L
P0NominalPUCCH P0 nominal PUCCH

Meaning: Indicates the target UE transmit power for the PUCCH expected by the eNodeB on condition that normal demodulation can be performed. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -127~-96

Unit: dBm

Actual Value Range: -127~-96

MML Default Value: None

Recommended Value: -115

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter value is too large, the interference to neighboring cells increases and the overall network throughput decreases. If this parameter value is too small, the interference to neighboring cells decreases and the throughput of the local cell also decreases.

Applicable Mode: L-FDD, L-TDD

DeltaPreambleMsg3 Delta preamble value for msg3

Meaning: Indicates the power offset (delta value) of message 3 relative to the preamble. This power offset has a step size of 2. For details, see 3GPP TS 36.213.

GUI Value Range: -1~6

Unit: 2dB

Actual Value Range: -2~12

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A relatively small value of this parameter may result in inadequate transmit power for message 3, leading to a reduced transmit power for the data channel and lower throughput of the cell. A relatively large value of this parameter may result in excessive transmit power for message 3, leading to stronger interference to neighboring cells and lower throughput of the network.

Applicable Mode: L
DeltaMsg2 Delta Message 2

Meaning: Indicates the power offset of Msg3 transmitted during uplink random access. This parameter is also used to set the initial power of the PUSCH or PUCCH for closed-loop power control. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DELTAMsg2_NEG6(-6dB), DELTAMsg2_NEG4(-4dB), DELTAMsg2_NEG2(-2dB), DELTAMsg2_0(0dB), DELTAMsg2_2(2dB), DELTAMsg2_4(4dB), DELTAMsg2_6(6dB), DELTAMsg2_8(8dB)

Unit: dB

Actual Value Range: DELTAMsg2_NEG6, DELTAMsg2_NEG4, DELTAMsg2_NEG2, DELTAMsg2_0, DELTAMsg2_2, DELTAMsg2_4, DELTAMsg2_6, DELTAMsg2_8

MML Default Value: None

Recommended Value: DELTAMsg2_6(6dB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter indicates large power carried in Msg3, increasing the power of the PUSCH or PUCCH after a UE accesses or is handed over to the network.

A small value of this parameter indicates small power carried in Msg3, decreasing the power of the PUSCH or PUCCH after a UE accesses or is handed over to the network.

Applicable Mode: L-FDD, L-TDD
DeltaFPUCCHFormat1bcs PUCCH Format 1bcs Delta

Meaning: Indicates the delta of PUCCH format 1bcs. For details about how to use this parameter, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DELTAF1(1dB), DELTAF2(2dB), INVALID(INVALID)

Unit: dB

Actual Value Range: DELTAF1, DELTAF2, INVALID

MML Default Value: None

Recommended Value: DELTAF2(2dB)

It is recommended that this parameter be set to DELTAF2 to ensure effective demodulation of PUCCH format 1bcs.

Parameter Relationship:

-Configuration constraints:

  • If DeltaFPUCCHFormat3 in the CellUlpcComm MO is set to INVALID, DeltaFPUCCHFormat1bcs in the CellUlpcComm MO must be set to INVALID too.
  • If DeltaFPUCCHFormat3 in the CellUlpcComm MO is set to a value other than INVALID, DeltaFPUCCHFormat1bcs in the CellUlpcComm MO must also be set to a value other than INVALID.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in smaller transmit power of PUCCH format 1bcs and lower interference to neighboring cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the cell UL power control parameter as follows: Local cell ID: 0, Path loss coefficient: AL04, Nominal PUCCH P0: -123, Nominal PUSCH P0: -123, run the following command: 
MOD CELLULPCCOMM: LocalCellId=0, PassLossCoeff=AL04, P0NominalPUCCH=-123, P0NominalPUSCH=-123;
Example 2: To modify the cell UL power control parameter as follows: Local cell ID: 0, Path loss coefficient: AL07, Nominal PUSCH P0: -123, DeltaF for PUCCH format 2a: DELTAF_2, Delta preamble value for msg3: 2, run the following command:
MOD CELLULPCCOMM: LocalCellId=0, PassLossCoeff=AL07, P0NominalPUCCH=-123, DeltaFPUCCHFormat2a=DELTAF_2, DeltaPreambleMsg3=2;
