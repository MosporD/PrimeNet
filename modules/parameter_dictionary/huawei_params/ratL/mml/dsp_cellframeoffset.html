Display Frame Offset Configuration (DSP CELLFRAMEOFFSET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about frame offset that takes effect in the cell. The unit of frame offset is Ts. A Tc is equal to eight times of a Ts. If the DlEarfcn parameter value equals 4294967295, the queried frame offset is invalid.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To Display Frame Offset Configuration Information:
DSP CELLFRAMEOFFSET: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:44:39
O&M    #806355002
%%DSP CELLFRAMEOFFSET: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

display Frame Offset Configuration
----------------------------------
                Local Cell ID  =  1
              Downlink EARFCN  =  1550
Frame Offset Effect Value(Ts)  =  0
    Frame Config Check Result  =  SAME
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

Downlink EARFCN

Indicates the DL EARFCN of a cell. For details about this parameter, see the 3GPP TS 36.104.

The LTE-U function has been removed, and the values in the ranges of 255144 to 256143 and 260894 to 262143 are invalid. Although the configuration interface in this version supports synchronization and delivery of the values in these ranges, the system does not use these values. Therefore, avoid setting this parameter to these values.

Frame Offset Effect Value(Ts)

Indicates the offset of the cell start frame against a reference clock source. If the parameter value is a hyphen (-), the cell has not been activated.

Frame Config Check Result

Indicates the check result of the subframe configuration and frame offset. This parameter applies only to LTE TDD.
