Add an extended QCI for relay features (ADD RELAYEXTENDEDQCI)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a record of RelayExtendedQci data.

Note

None.

Parameters

ID Name Description
ExtendedQci Extended QoS Class Indication

Meaning: Indicates the extended QCI of an E-RAB on an RRN. After an RRN successfully accesses the network, the eNodeB sets up a bearer with the extended QCI specified by this parameter for the RRN. QCIs 65, 66, 69, 70, 75, and 79 are standardized QCIs, and therefore values 65, 66, 69, 70, 75, and 79 are not recommended for this parameter. Otherwise, services of these QCIs are affected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 10~254

Unit: None

Actual Value Range: 10~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DefaultBearerInd Default Bearer Indication

Meaning: Indicates whether a bearer on an RRN is a default bearer. A maximum of one default bearer can be configured for an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(NO)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • One and only one RelayExtendedQci MO in which the DefaultBearerInd parameter is set to YES can be configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RlcPdcpParaGroupId RLC PDCP parameter group ID

Meaning: Indicates the ID of an RLC/PDCP parameter group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~230

Unit: None

Actual Value Range: 0~230

MML Default Value: 5

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SchType Schedule Type

Meaning: Indicates the scheduling type of E-RABs of an RRN. The value PQ indicates that scheduling based on the absolute priority is adopted for a bearer. The value WFQ indicates that fair scheduling based on the value of the UlSchWeight or DlSchWeight parameter in the RelayExtendedQci MO is adopted for a bearer. This scheduling type is used for service data carried on the RRN. The value WFQ_L2OM indicates that fair scheduling based on the value of the UlSchWeight or DlSchWeight parameter in the RelayExtendedQci MO is adopted for a bearer in the L2OM channel. This scheduling type is used for OM data of the RRN. The priority for a PQ bearer is always higher than that for a WFQ bearer. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PQ(PQ), WFQ(WFQ), WFQ_L2OM(WFQ_L2OM)

Unit: None

Actual Value Range: PQ, WFQ, WFQ_L2OM

MML Default Value: PQ(PQ)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of four RelayExtendedQci MOs in which the SchType parameter is set to PQ(PQ) can be configured.
  • A maximum of three RelayExtendedQci MOs in which the SchType parameter is set to WFQ can be configured.
  • At most one RelayExtendedQci MO with SchType set to WFQ_L2OM can be configured.
  • The sum of the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ_L2OM and the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ must be less than or equal to 100.
  • The sum of the DlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ_L2OM and the DlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ must be less than or equal to 100.
  • The RelayExtendedQci MO with the SchType parameter set to WFQ_L2OM and another RelayExtendedQci MO with the SchType parameter set to PQ and the PqType parameter set to L2OM must not be configured at the same time.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: Bearers with this parameter set to PQ can be allocated a greater bandwidth, and therefore have a shorter delay and less jitter. This type of bearers applies to high-priority and small-data-volume services, such as signaling, voice services, and high-priority OM messages. Bearers with this parameter set to WFQ are scheduled in round robin (RR) mode and allocated resources based on the bandwidth allocation weight factor. This type of bearers applies to common services. Bearers with this parameter set to WFQ_L2OM is used for the OM data (including software and logs) of the Relay. The method and effect of the WFQ_L2OM value are the same as those of the WFQ value. Appropriate mapping between a service type and the scheduling type of bearers helps meet the QoS requirement of this type of service. Suppose that the service type does not match the scheduling type of bearers, for example, the common service is configured with bearers with this parameter set to PQ. In this situation, the common service is preferentially scheduled and allocated resources while the bandwidth is restricted for high-priority services, causing the delay and jitter to deteriorate or even packet losses.

Applicable Mode: L-FDD, L-TDD
UlSchWeight Uplink Schedule Weight

Meaning: Indicates the weight factor of uplink scheduling resource allocation for bearers with the scheduling type of WFQ. This parameter is valid when the SchedulingType parameter is set to WFQ or WFQ_L2OM. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: 30

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ_L2OM and the UlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ must be less than or equal to 100.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter affects the RB resource allocation proportion between multiple WFQ bearers on an RRN. When this RRN is scheduled and allocated RB resources and data transmission is required for multiple WFQ bearers on this RRN, the WFQ bearer configured with a larger uplink resource allocation weighting factor can obtain more RB resources, there is a higher probability that data is timely transmitted on this bearer, and service quality on this bearer is better.

Applicable Mode: L-FDD, L-TDD
DlSchWeight Downlink Schedule Weight

Meaning: Indicates the weight factor of downlink scheduling resource allocation for bearers with the scheduling type of WFQ. This parameter is valid when the SchedulingType parameter is set to WFQ or WFQ_L2OM. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: 30

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of the DlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ_L2OM and the DlSchWeight parameter values in all RelayExtendedQci MOs with the SchType parameter set to WFQ must be less than or equal to 100.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter affects the RB resource allocation proportion between multiple WFQ bearers on an RRN. When this RRN is scheduled and allocated RB resources and data transmission is required for multiple WFQ bearers on this RRN, the WFQ bearer configured with a larger downlink resource allocation weighting factor can obtain more RB resources, there is a high probability that data is timely transmitted on this bearer, and service quality on this bearer is better.

Applicable Mode: L-FDD, L-TDD
DscpLower Dscp Lower

Meaning: Indicates the lower limit of the DSCP value contained in the IP packets mapped to a bearer on an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Impact on Radio Network Performance: This parameter determines SDF classifications and mapping between packet types and E-RABs, and therefore determines the QoS for each type of packet.

Applicable Mode: L-FDD, L-TDD
DscpUpper Dscp Upper

Meaning: Indicates the upper limit of the DSCP value contained in the IP packets mapped to a bearer on an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: 63

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter determines SDF classifications and mapping between packet types and E-RABs, and therefore determines the QoS for each type of packet.

Applicable Mode: L-FDD, L-TDD
RrnPreAllocationWeight RRN Pre-allocation Weight

Meaning: Indicates the service preallocation weight of the RRN. If the SchedulingType parameter is set to PQ, the preallocation weight of services corresponding to the priority queuing (PQ) is used. If the SchedulingType parameter is set to WFQ or WFQ_L2OM, the preallocation weight of services corresponding to the largest weighted fair queuing (WFQ) is used. Preallocation possibilities are proportional to preallocation weights. When resources are limited, the preallocation weight affects the preallocation possibilities for an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~1, step: 0.1

MML Default Value: 10

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A large value of this parameter leads to a larger preallocation weight for services with the corresponding extended QCI and shorter preallocation delay. A smaller value of this parameter leads to a smaller preallocation weight for services with the corresponding extended QCI and longer preallocation delay.

Applicable Mode: L-FDD, L-TDD
PqType PQ Type

Meaning: Indicates the PQ bearer type when the SchType parameter is set to PQ(PQ). The value L3PQ indicates the PQ bearer of L3 Relay. The value L2OM indicates the RRN O&M PQ bearer of L2 Relay. The value L2HIGH indicates the high-priority PQ bearer of L2 Relay. The value L2LOW indicates the low-priority PQ bearer of L2 Relay. A maximum of one bearer of each type can be configured. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: L3PQ(L3PQ), L2OM(L2OM), L2HIGH(L2HIGH), L2LOW(L2LOW)

Unit: None

Actual Value Range: L3PQ, L2OM, L2HIGH, L2LOW

MML Default Value: L3PQ(L3PQ)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of one RelayExtendedQci MO can be configured if the PqType parameter is set to L3PQ, L2OM, L2HIGH, or L2LOW.
  • The RelayExtendedQci MO with the SchType parameter set to WFQ_L2OM and another RelayExtendedQci MO with the SchType parameter set to PQ and the PqType parameter set to L2OM must not be configured at the same time.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an extended QCI for relay features with the parameters as follows: Extended QoS Class Indication:11, Schedule Type:PQ, Dscp Lower:31, Dscp Upper:35, run the following command:
ADD RELAYEXTENDEDQCI: ExtendedQci=11, SchType=PQ, DscpLower=31, DscpUpper=35;
