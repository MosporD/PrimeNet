Add GSM Interference ARFCN Configuration (ADD GSMINTERFARFCNCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add ARFCNs of interfering GSM frequencies for GL spectrum cloudification features.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The GSM ARFCNs must be configured within EARFCNs in LTE bandwidths. Otherwise, the configuration does not take effect.

  • When GSM and LTE Spectrum Concurrency is enabled, adding the GSM ARFCN used by the cell will result in automatic reset of the cell.

Parameters

ID Name Description
GsmArfcnGroupId GSM ARFCN Group ID

Meaning: Indicates the GSM ARFCN group ID used in GSM and LTE spectrum concurrency. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of 25 GsmArfcn can be configured for a GsmArfcnGroupId.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
GsmArfcn GSM ARFCN

Meaning: Indicates the GSM ARFCN used in GSM and LTE spectrum concurrency. This parameter applies only to LTE FDD.

GUI Value Range: 0~124,128~251,512~885,975~1023

Unit: None

Actual Value Range: 0~124,128~251,512~885,975~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of 25 GsmArfcn can be configured for a GsmArfcnGroupId.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To add the interference configuration of GsmInterfArfcnCfg with the parameters as follows: GSM ARFCN Group ID: 0, GSM ARFCN: 601, run the following command:
+++    0        2017-03-13 11:58:09
O&M    #806354967
%%ADD GSMINTERFARFCNCFG: GsmArfcnGroupId=0, GsmArfcn=601;%%
RETCODE = 0  Operation succeeded.
