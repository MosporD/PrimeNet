Modify DRX Configuration (MOD DRX)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the DRX configuration.

Note

None.

Parameters

ID Name Description
DrxFlexCtrlSwitch DRX Flexibility Control Switch

Meaning: Indicates whether to enable DRX flexibility. If this parameter is set to OFF, DRX configuration for UEs is restricted based on the UE number. If this parameter is set to ON, DRX configuration for UEs is restricted based on CPU flow control. This parameter does not support LBBPc. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the number of DRX UEs may increase and the uplink BLER, downlink BLER, uplink throughput, downlink throughput, and RRC connection setup success rate may deteriorate.

Applicable Mode: L-FDD, L-TDD

Example

To modify DRX parameter, run the following command:
MOD DRX: DrxFlexCtrlSwitch=ON;
