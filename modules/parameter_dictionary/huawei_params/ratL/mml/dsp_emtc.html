Display eMTC Dynamic Parameters (DSP EMTC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the dynamic attributes of eMTC.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the dynamic attributes of eMTC:
+++    0        2019-07-06 15:31:37
O&M    #806355115
%%DSP EMTC: LocalCellId=0;%%
RETCODE = 0  Operation succeeded.

Display CellEmtcAlgo
--------------------
            Local Cell ID  =  0
Cell eMTC Instance Status  =  EMTC_DISABLED
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Cell eMTC Instance Status

Indicates the eMTC instance state of a cell.

The eMTC instance state of a cell can be EMTC_DISABLED, EMTC_NORMAL, EMTC_DL_RES_ALLOC_FAILURE, BBP_NOT_SUPPORT_EMTC, EMTC_ACCESS_BARRED, EMTC_PUCCH_PRACH_ALLOC_FAILURE, EMTC_CONFIGURATION_CONFLICT, HIGHSPEEDCELL_BBP_NOT_SUPPORT_EMTC, or RES_NOT_READY_FOR_EMTC.

If eMTC is enabled in a cell but fails to take effect due to reasons such as eMTC license insufficiency, the cell is in the EMTC_DISABLED state.

If eMTC is enabled in a cell and eMTC is working properly, the cell is in the EMTC_NORMAL state.

When a cell with eMTC or other functions enabled needs to be re-established, the eNodeB checks whether there are sufficient downlink air interface resources for eMTC control information. If the air interface resources are insufficient, air interface resource allocation will fail for eMTC in the cell (for example, narrowband allocation fails for eMTC system information). In this case, the cell is in the EMTC_DL_RES_ALLOC_FAILURE state.

If eMTC fails to take effect in a cell because the cell is set up on a BBP that does not support eMTC, the cell is in the BBP_NOT_SUPPORT_EMTC state.

If eMTC UEs are barred from accessing a cell, the cell is in the EMTC_ACCESS_BARRED state.

If eMTC PUCCH and PRACH resource allocation fails, the cell is in the EMTC_PUCCH_PRACH_ALLOC_FAILURE state.

If eMTC fails to be initialized because of a conflict between eMTC and other features during the initialization, the cell is in the EMTC_CONFIGURATION_CONFLICT state.

If eMTC fails to take effect in an FDD cell because the BBP serving the cell does not support compatibility between eMTC and high speed mobility, the cell is in the HIGHSPEEDCELL_BBP_NOT_SUPPORT_EMTC state.

If a cell is not reset after its serving BBP is changed from a BBP that does not support eMTC to a BBP that supports eMTC, eMTC fails to take effect in the cell even if the eMTC switch is turned on. In this case, the cell is in the RES_NOT_READY_FOR_EMTC state.

This parameter applies only to LTE FDD and LTE TDD.
