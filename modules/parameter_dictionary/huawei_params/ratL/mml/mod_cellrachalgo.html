Modify Cell RACH Algorithm Configuration (MOD CELLRACHALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the CellRachAlgo.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PrachFalseAlarmDetRadThd PRACH False Alarm Detect Radius Threshold

Meaning: Indicates the threshold of the distance between a UE and the eNodeB for determining whether a contention-based preamble sent by the UE is a PRACH false alarm. If this parameter is set to 0, the eNodeB does not consider a preamble as a false alarm based on the distance. If this parameter is set to a non-zero value and the eNodeB detects that the distance is longer than this parameter value, the preamble is considered as a false alarm. The distance is calculated based on the timing advance (TA) of the contention-based preamble that the eNodeB received for the first time from a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100000

Unit: m

Actual Value Range: 0~100000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If PRACH false alarm detection is disabled or this parameter is set to 0, the network performance is not affected.

If PRACH false alarm detection is enabled, a larger non-zero value of this parameter leads to a lower probability that the eNodeB correctly detects false alarms, and accordingly a lower probability that contention-based preambles are mistakenly considered as false alarms; a smaller non-zero value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
RachThdBoostRatio RACH Threshold Boosting Ratio

Meaning: This parameter indicates the percentage by which the PRACH false alarm detection threshold increases. For example, the value x indicates that the configured PRACH false alarm detection threshold increases by x%, and the value -x indicates that the configured PRACH false alarm detection threshold decreases by x%.

GUI Value Range: -100~1000

Unit: %

Actual Value Range: -100~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to 0, network performance is not affected.

If PRACH false alarm detection is disabled, a larger non-zero value of this parameter leads to a lower probability that preambles are detected, and accordingly a lower probability that preambles are considered as false alarms; a smaller non-zero value of this parameter leads to the opposite effects.

If PRACH false alarm detection is enabled, a larger non-zero value of this parameter leads to a higher probability that preambles are considered as false alarms, a longer delay for UEs to send contention-based preambles, and accordingly a higher probability of contention-based access failures; a smaller non-zero value of this parameter leads to the opposite effects.

Applicable Mode: L
PrachInterfPeriod Prach Interference Period

Meaning: Indicates the period for an eNodeB to avoid PRACH interference. This parameter is used to control the speed of PRACH frequency domain position adjustment to prevent ping-pong adjustments due to interference fluctuation. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 10~600

Unit: s

Actual Value Range: 10~600

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A small value of this parameter increases the speed of PRACH frequency domain position adjustment and the response speed of an eNodeB towards interference. However, it also increases the signaling overheads and number of ping-pong adjustments. A large value of this parameter slows down the speed of PRACH frequency domain position adjustment and the response speed of an eNodeB towards interference. However, it reduces the signaling overheads and number of ping-pong adjustments.

Applicable Mode: L-FDD, L-TDD
PrachInterfThreshold Prach Interference Threshold

Meaning: Indicates the threshold for an eNodeB to determine whether PRACH interference is severe. When the value of PRACH interference (per PRB) is greater than or equal to the value of this parameter, an eNodeB determines that PRACH interference is severe. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -115~-80

Unit: dBm

Actual Value Range: -115~-80

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A large value of this parameter decreases the possibility that PRACH interference avoidance is triggered by the eNodeB for severe PRACH interference. A small value of this parameter increases the possibility that PRACH interference avoidance is triggered by the eNodeB for severe PRACH interference.

Applicable Mode: L-FDD, L-TDD
PrachInterfHysteresis Prach Interference Hysteresis

Meaning: Indicates the hysteresis for an eNodeB to determine PRACH interference. This parameter is used to reduce the number of ping-pong adjustments due to interference fluctuation. This parameter is used with the Prach Interference Threshold parameter to determine weak PRACH interference and moderate PRACH interference. When the value of PRACH interference is less than the value of Prach Interference Threshold minus the value of Prach Interference Hysteresis, the eNodeB determines that PRACH interference is weak. When the value of PRACH interference is greater than or equal to the value of Prach Interference Threshold minus the value of Prach Interference Hysteresis and less than the value of Prach Interference Threshold, the eNodeB determines that PRACH interference is moderate. This parameter applies only to the TDLOFD-081217 Interference Detection and Restraining Enhancement feature. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 5~35

Unit: dB

Actual Value Range: 5~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A large value of this parameter effectively reduces the ping-pong effect due to interference fluctuation and decreases the possibility of state transition between severe and weak PRACH interference. A small value of this parameter increases the possibility of state transition between severe and weak PRACH interference.

Applicable Mode: L-FDD, L-TDD

Example

To modify the cell RACH algorithm configuration with the parameters as follows: Local cell ID: 0, PrachFalseAlarmDetRadThd: 10000, run the following command:
MOD CELLRACHALGO: LocalCellId=0, PrachFalseAlarmDetRadThd=10000;
