List Unified Access Control Parameter Group (LST UACPARAMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configurations of UAC parameter groups.

Note

None.

Parameters

ID Name Description
AccessControlParamGrpId Access Control Parameter Group ID

Meaning: Indicates the ID of an access control parameter group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters of the UAC parameter group with the access control parameter group ID of 1, run the following command:
LST UACPARAMGROUP: AccessControlParamGrpId=1;
The result is shown as follows:

Output Description

Field Description

Access Control Parameter Group ID

Indicates the ID of an access control parameter group. This parameter applies only to LTE FDD and LTE TDD.

Barring State for Specific Access ID

Indicates whether access barring check is required for UEs with a specific access ID. If an option is deselected, UEs with the access ID indicated in this option are allowed to access. If an option is selected, access barring check will be performed for UEs with the access ID indicated in this option when these UEs initiate access. During an access barring check, the UE determines whether it is allowed to access the network based on the uac-BarringFactor and uac-BarringTime IEs in SIB25. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
