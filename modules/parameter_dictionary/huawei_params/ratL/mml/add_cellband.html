Add Cell Slave Band (ADD CELLBAND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a cell slave band.

Note

  • When the operating frequency range of a local cell belongs to multiple frequency bands, as defined in TS 36.101 Table 5.5-1, use the ADD CELL command to configure the frequency band with the highest priority for the local cell, and use the ADD CELLBAND command to configure other frequency bands for the local cell based on the priorities in descending order. The priorities of multiple frequency bands of the local cell are determined by operators. It is recommended that operators comply with the same frequency band priority planning on whole network.

  • Other frequency bands to be configured for the local cell must be different from the frequency band with the highest priority of the local cell.

  • A maximum of two additional frequency bands can be added for the local cell.

  • Use this command to add a secondary frequency band for a cell.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
FreqBand Frequency band

Meaning: Indicates the frequency band in which the cell operates. For details about this parameter, see 3GPP TS 36.104.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To add a cell band with the parameters as follows: Local Cell ID: 0, Frequency band: 38, run the following command:
ADD CELLBAND: LocalCellId=0, FreqBand=38;
