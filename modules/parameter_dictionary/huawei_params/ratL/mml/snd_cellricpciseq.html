Send Cell Remote Interference Data (SND CELLRICPCISEQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to send data about TDD cell remote interference. Dedicated signals (DSs) are generated based on the equivalent PCI of a cell. The equivalent PCI equals the sum of the cell PCI and the PCI offset set in this command. DSs are used to distinguish cells with the same PCI and help identify the cells that cause remote interference.

Note

  • Before running this command, ensure that the related cell has been set up.

  • The time that related commands begin to take effect must be specified according to the Greenwich Mean Time (GMT).

  • Set the start time to a time later than the current eNodeB time. This ensures that the MAE has delivered this command to all eNodeBs before the command execution.

  • FDD cells do not support this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PCIOffset PCI Offset

Meaning: Indicates the PCI offset, which distinguishes cells with the same PCI. The equivalent PCI of a cell equals the sum of the cell PCI and the PCI offset.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
StartTime Start time

Meaning: Indicates the absolute time when the command takes effect. In this way, all eNodeBs can perform the related operation at the same scheduled time.

GUI Value Range: None

Unit: None

Actual Value Range: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To send data about cell remote interference with the parameters as follows: Local cell ID: 0, PCI Offset: 3, Start time: 2011&09&07&10&51&48, run the following command:
SND CELLRICPCISEQ:LocalCellId=0, PCIOffset=3, StartTime=2011&09&07&10&51&48;
