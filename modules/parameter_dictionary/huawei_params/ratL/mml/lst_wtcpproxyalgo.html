List WTCP Proxy Algorithm Configuration (LST WTCPPROXYALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameter settings related to the TCP proxy algorithms.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of the W-TCP proxy algorithm:
LST WTCPPROXYALGO:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

TCP Acceleration Switch

Indicates whether to enable the WTCP proxy function. If an operator's network is an LTE-only network and data forwarding channels have been configured for inter-eNodeB handovers, it is recommended that this parameter be set to ON. When this parameter is set to ON, the eNodeB acts as a proxy in handling TCP packets of HTTP or HTTPS services to increase the download rate of TCP streams. When this parameter is set to OFF, the WTCP proxy function is disabled. This parameter applies only to LTE FDD and LTE TDD.

TCP Statistics Switch

Indicates whether to enable TCP measurements. If this parameter is set to ON(ON), the eNodeB starts TCP measurements regardless of the status of the wireless TCP proxy function. This parameter applies only to LTE FDD and LTE TDD.

Max RTT Statistic Threshold(ms)

Indicates the threshold for measuring the maximum round trip time (RTT) among all TCP-related counters. If the RTT of TCP packets in the access network or ground links is greater than this parameter value, the RTT is not considered during the measurement of counters related to RTT delay. This parameter applies only to LTE FDD and LTE TDD.

Max Number of Proxy Packets

Indicates the maximum number of downlink TCP packets sent by the WTCP proxy. If the number of downlink TCP packets sent by the WTCP proxy reaches the maximum value, the WTCP proxy mode is terminated. This parameter applies only to LTE FDD and LTE TDD.

TPE ACK Split Count

Indicates the number of split ACKs in the TCP Proxy Enhancer (TPE). If this parameter is set to 0, ACK splitting is not performed in the TPE. If this parameter is set to a non-0 value, this parameter specifies the number of ACKs generated each time ACK splitting is performed in the TPE. This parameter applies only to LTE FDD and LTE TDD.

TCP Acceleration Schedule Weight Factor

Indicates the weight factor of the basic scheduling priority for TCP acceleration services. This parameter is used to guarantee such services for acceleration-involved UEs in both the uplink and downlink. If this parameter is set to 0, pre-scheduling of UEs requiring TCP acceleration does not take effect. This parameter applies only to LTE TDD.

TCP Active Ordering Timer(ms)

Indicates the length of the proactive TCP packet ordering timer.

If this parameter is set to 0, proactive TCP packet ordering does not take effect, and TCP packets are transparently transmitted.

If this parameter is set to a value greater than 0: 1. When TCP packets reach the eNodeB in order, the eNodeB directly sends these packets to UEs without buffering the packets; 2. When TCP packet disorder occurs, this timer is started, and the eNodeB resequences the disordered TCP packets before sending them to UEs. If disordered TCP packets have not reached the eNodeB when this timer expires, the eNodeB sends all buffered TCP packets to UEs. The eNodeB does not proactively order non-TCP/IP packets. This parameter applies only to LTE FDD and LTE TDD.

WTCP Enhancement Switch

Indicates whether to enhance WTCP proxy.

WTCP_LOST_PACKET_SWITCH: If this option is selected, the eNodeB checks the size of the UE transmission window to prevent packet loss and does not intercept ACK responses to resent packets when the ACK responses sent by the WTCP proxy are lost. If this option is deselected, the eNodeB does not check the size of the UE transmission window and intercepts ACK responses to resent packets when ACK packets sent by the WTCP proxy are lost. This parameter applies only to LTE FDD and LTE TDD.

WTCP Downlink RTT Timer(10ms)

Indicates the TCP downlink RTT timer. If no ACK message for the corresponding TCP packet is received when this timer expires, scheduling acceleration over the air interface is enabled. If an ACK message for the corresponding TCP packet is received when this timer does not expire, scheduling acceleration over the air interface is disabled. If this parameter is set to 0, WTCP scheduling acceleration over the air interface does not take effect. This parameter applies only to LTE FDD and LTE TDD.

RTO Protection Buffer Threshold

Indicates the threshold of the number of buffered WTCP packets for enabling WTCP proxy RTO protection. This parameter takes effect only if it is set to a value greater than 0. If the number of buffered WTCP packets reaches this threshold, WTCP proxy RTO protection is enabled to avoid RTO. This parameter applies only to LTE FDD and LTE TDD.
