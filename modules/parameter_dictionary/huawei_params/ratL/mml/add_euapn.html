Add an APN (ADD EUAPN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an APN.

Note

None.

Parameters

ID Name Description
APN APN

Meaning: Indicates the network identification code. The value of this parameter can contain a maximum of seven dots (.). Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100 characters

Unit: None

Actual Value Range: 1~100 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PrimaryDNS Primary Domain Name Server

Meaning: This parameter specifies the IP address of the primary DNS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: 0.0.0.0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SecondaryDNS Secondary Domain Name Server

Meaning: This parameter specifies the IP address of the secondary DNS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: 0.0.0.0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IPAddressPoolID Address Pool ID

Meaning: Indicates the ID of the IP address pool corresponding to the APN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an APN with the parameters as follows:APN:huawei.com.APN.EPC.MNC000.MCC460.3GPPNETWORK.ORG, Primary Domain Name Server:192.168.0.1, Secondary Domain Name Server:192.168.255.1, Address Pool ID:1, run the following command:
ADD EUAPN: APN="huawei.com.APN.EPC.MNC000.MCC460.3GPPNETWORK.ORG", PrimaryDNS="192.168.0.1", SecondaryDNS="192.168.255.1", IPAddressPoolID=1;
