Modify Cell MBSFN Subframe Enhancement Configuration (MOD CELLMBSFNSFENHCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the enhanced MBSFN subframe configuration of a cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
SubframeAllocationMode Subframe Allocation Mode

Meaning: Indicates whether one radio frame or four consecutive radio frames contain MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.

GUI Value Range: NOT_CONFIG(NOT_CONFIG), ONE_FRAME(ONE_FRAME), FOUR_FRAME(FOUR_FRAME)

Unit: None

Actual Value Range: NOT_CONFIG, ONE_FRAME, FOUR_FRAME

MML Default Value: None

Recommended Value: NOT_CONFIG(NOT_CONFIG)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
OneFrameAllocation One Frame Allocation

Meaning: Indicates the MBSFN subframes allocated in one radio frame. For an FDD cell, the subframes that can be allocated for MBSFN in a radio frame are SF1, SF2, SF3, SF6, SF7, and SF8. These subframes are represented by bit 5 to bit 0 in sequence. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. When you set this parameter, change the binary value into a decimal value and set this parameter to this decimal value. For details about how to use this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD. This parameter is valid only when the SubframeAllocationMode parameter in the CellMbsfnSfEnhConfig MO is set to ONE_FRAME.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If multiple transmission modes are used by UEs on the network, a larger number of MBSFN subframes leads to better throughput performance for TM9 UEs but poorer throughput performance for non-TM9 UEs, and a smaller number of MBSFN subframes leads to poorer throughput performance for TM9 UEs but better throughput performance for non-TM9 UEs.

Applicable Mode: L-FDD
FourFrameAllocation Four Frame Allocation

Meaning: Indicates the MBSFN subframes allocated in four consecutive radio frames. For an FDD cell, the subframes that can be allocated for MBSFN in each radio frame include SF1, SF2, SF3, SF6, SF7, and SF8. These subframes in the four radio frames are represented by bit 23 to bit 0 in sequence starting from the first radio frame. If a bit is set to 1, the corresponding subframe is allocated for MBSFN. When you set this parameter, change the binary value into a decimal value and set this parameter to this decimal value. For details about how to use this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD. This parameter is valid only when the SubframeAllocationMode parameter in the CellMbsfnSfEnhConfig MO is set to FOUR_FRAME.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If multiple transmission modes are used by UEs on the network, a larger number of MBSFN subframes leads to better throughput performance for TM9 UEs but poorer throughput performance for non-TM9 UEs, and a smaller number of MBSFN subframes leads to poorer throughput performance for TM9 UEs but better throughput performance for non-TM9 UEs.

Applicable Mode: L-FDD
RadioFrameAllocPrd Radio Frame Allocation Period

Meaning: Indicates the allocation period of the radio frames that contain MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.

GUI Value Range: N1(N1), N2(N2), N4(N4), N8(N8), N16(N16), N32(N32)

Unit: frame

Actual Value Range: N1, N2, N4, N8, N16, N32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
RadioFrameAllocOfs Radio Frame Allocation Offset

Meaning: Indicates the frame offset used for MBSFN subframe configuration. This parameter and the RadioFrameAllocPrd parameter together determine the radio frame that contains MBSFN subframes. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To modify the cell Mbsfn subframe enhance configuration with the parameters as follows: Local cell ID: 0, Subframe Allocation Mode: NOT_CONFIG, One Frame Allocation: 0, Four Frame Allocation: 0, Radio Frame Allocation Period(frame): N1, Radio Frame Allocation Offset: 0, run the following command:
MOD CELLMBSFNSFENHCONFIG: LocalCellId=0, SubframeAllocationMode=NOT_CONFIG, OneFrameAllocation=0, FourFrameAllocation=0, RadioFrameAllocPrd=N1, RadioFrameAllocOfs=0;
