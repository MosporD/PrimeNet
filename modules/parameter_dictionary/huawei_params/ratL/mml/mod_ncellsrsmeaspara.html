Modify Neighboring Cell SRS Measurement Parameters (MOD NCELLSRSMEASPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to automatic SRS measurement on neighboring cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell Id

Meaning: Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SrsAutoNCellMeasSwitch SRS Auto Neighbour Cell Measurement Switch

Meaning: Indicates whether a cell supports SRS automatic neighboring cell measurements. If this parameter is set to ON(On), the UlHetnetCompOnUlRsrpSw and UlHetnetCompManualNcellCfgSw options of the UplinkCompSwitch parameter do not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the SrsAutoNCellMeasSwitch parameter in the same MO is set to OFF.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NCellSrsMeasA3Offset SRS or DMRS Auto Neighbour Cell Measurement A3 Offset

Meaning: Indicates the offset for events related to the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter requires better signal quality of a neighboring cell for sending measurement reports of the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement. SRS automatic neighboring cell measurement applies to LTE FDD and LTE TDD. DMRS neighboring cell measurement applies only to LTE FDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value results in more measurement reports for the SRS automatic neighboring cell measurement or DMRS neighboring cell measurement, more Uu interface signaling, and more SRS or DMRS neighboring cells of the serving cell. A larger value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
NCellMeasSwitch Neighbouring Cell Measurement Switch

Meaning: Indicates whether to enable neighboring cell measurement algorithms.

NcellDmrsMeasSwitch: Indicates whether to enable DMRS measurement for neighboring cells. If this option is selected, DMRS measurement is enabled for neighboring cells. If this option is deselected, DMRS measurement is disabled for neighboring cells. When this option is selected, the setting of the SrsAutoNCellMeasSwitch parameter does not take effect. This option applies only to LTE FDD and NB-IoT.

NcellSrsTimeMeasSwitch: Indicates whether to enable time-domain measurement of SRSs from neighboring cells. If this option is selected, the eNodeB supports time-domain measurement of SRSs from neighboring cells. If this option is deselected, the eNodeB does not support time-domain measurement of SRSs from neighboring cells and supports only frequency-domain measurement of the SRSs. This option takes effect only if measurement of SRSs from neighboring cells is triggered. Such measurement can be triggered by UL CoMP or automatic measurement of SRSs from neighboring cells (controlled by the SrsAutoNCellMeasSwitch parameter in the NCellSrsMeasPara MO). This option applies only to LTE TDD.

GUI Value Range: NCellDmrsMeasSwitch(NCellDmrsMeasSwitch), NCellSrsTimeMeasSwitch(NCellSrsTimeMeasSwitch)

Unit: None

Actual Value Range: NCellDmrsMeasSwitch, NCellSrsTimeMeasSwitch

MML Default Value: None

Recommended Value: NCellDmrsMeasSwitch:Off;NCellSrsTimeMeasSwitch:Off

Parameter Relationship:

-Configuration constraints:

  • The NCellDmrsMeasSwitch option of the NCellMeasSwitch parameter in an NCellSrsMeasPara MO can be selected only when the SrsAutoNCellMeasSwitch parameter in the same MO is set to OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To disable SRS automatic neighboring cell measurement for the cell whose local cell ID is 0, run the following command:
MOD NCELLSRSMEASPARA: LocalCellId=0, SrsAutoNCellMeasSwitch=OFF;
