Modify RACH Configuration (MOD RACHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the RACH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • For a cell, modifications on the offset to the starting position of PRACH in the frequency domain of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the indication of PRACH configuration index of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the PRACH configuration index of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the PRACH frequency offset strategy of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the NB-IoT Cyclic Prefix Length of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the PRACH Start Time Config Indication of an active cell would result in the automatic reset of the cell.

  • For a cell, modifications on the Emtc Prach Period of an active cell would result in the release of eMTC users.

PrachStartTimeCfgInd PRACH Start Time Config Indication

Meaning: Indicates whether to allow configuration of the PRACH start time. When this parameter is set to NOT_CFG, the PRACH start time is not configurable. The PRACH start time for coverage level 0 is always 8 ms. The PRACH start time for coverage level 1 is determined based on the following factors: the sum of the PRACH start time and PRACH time length for coverage level 0, and the restriction that the PRACH start time interval between two adjacent coverage levels is not less than 40 ms. The PRACH start time for coverage level 2 is determined in a way similar to that for determining the PRACH start time for coverage level 1. If there are PRACH resources used for early data transmission (EDT), the positions of the EDT PRACH subcarriers and those of the common PRACH subcarriers cannot overlap, and the start time and transmission interval of the EDT PRACH must be the same as those of the common PRACH. When this parameter is set to CFG, the PRACH start time for each coverage level is configurable. The PRACH start time interval between two adjacent coverage levels must not be less than 40 ms. Otherwise, cells cannot be activated. This parameter applies only to NB-IoT.

If this parameter is set to AUTOMATIC(AUTOMATIC) or FULLY_AUTOMATIC(FULLY_AUTOMATIC), the eNodeB determines the PRACH frequency-domain offset. If this parameter is set to MANUAL(MANUAL), the PRACH frequency-domain offset is specified by the PrachFreqOffset parameter.
