List Cell Emergency Area (LST CELLEMERGENCYAREA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of Cell Emergency Area.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local primary cell ID. It uniquely identifies a cell within an eNodeB. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EmergencyAreaId Emergency Area ID

Meaning: Indicates the ID of an emergency area in which an alarm message is to be broadcast. The emergency area ID is defined by the operator. An emergency area consists of one or several cells. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

To list the emergency area ID of a cell:
LST CELLEMERGENCYAREA:;
