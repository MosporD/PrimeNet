List Cell Algorithm Extend Switch Configuration (LST CELLALGOEXTSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of cell-level algorithm extend switches.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of extended cell-level algorithms:
LST CELLALGOEXTSWITCH: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

NB-IoT Cell Algorithm Extended Switch

Indicates the NB-IoT cell-level algorithm switches.

ADAPTIVE_PREAMBLE_INIT_PWR_SW: Indicates whether to enable adaptive adjustment of initial RX power target of preambles. This option applies only to NB-IoT.

DL_AMC_OPT_SWITCH: Indicates whether to enable AMC optimization for downlink NB-IoT scheduling. This option applies only to NB-IoT.

RELEASE_PERFM_IMPROVE_SWITCH: Indicates whether to improve the performance of RRC release signaling demodulation. If this option is selected, the number of RRC release signaling repetitions is adjusted based on signaling transmission status. If this option is deselected, RRC release signaling is transmitted in the same way as data is transmitted This option applies only to NB-IoT.

RECEPTION_FAIL_STATUS_RPT_SW: Indicates whether UEs send status reports when detecting data reception failures. For details, see 3GPP TS 36.322. This option applies only to NB-IoT.

ENODEB_TX_BYTE_POLLING_SW: Indicates whether the eNodeB triggers polling based on the number of transmitted bytes. This option applies only to NB-IoT.

SCH_DURATION_PROP_ADAPT_SWITCH: Indicates whether to adaptively adjust the proportions of scheduling duration for different coverage levels. If this option is selected, the proportions of scheduling duration for different coverage levels are adaptively adjusted based on network loads. If this option is deselected, the proportions of scheduling duration are fixed for different coverage levels. This option applies only to NB-IoT.

HARQ_ACK_WITH_SR_SWITCH: Indicates whether to allow SRs to be sent together with HARQ feedback. If this option is deselected, the function does not take effect. If this option is selected, the function takes effect, which can reduce air interface delay and UE power consumption. This option applies only to NB-IoT.

CFRA_WITH_SR_SWITCH: Indicates whether to allow SRs to be sent during non-contention-based random access. If this option is deselected, the function does not take effect. If this option is selected, the function takes effect, which can reduce air interface delay and UE power consumption. This option applies only to NB-IoT.

SPS_BSR_SWITCH: Indicates whether to allow BSRs to be sent in semi-persistent scheduling. If this option is deselected, the function does not take effect. If this option is selected, the function takes effect, which can reduce air interface delay and UE power consumption. This option applies only to NB-IoT.

PL_DIFF_BASED_DL_AMC_OPT_SW: Indicates whether to enable downlink AMC optimization based on path loss difference. If this option is selected, the eNodeB adjusts the downlink MCS index for a UE based on the difference between the path loss of the UE and the path loss at the edge of the coverage level for the UE. If this option is deselected, the algorithm does not take effect. This option applies only to NB-IoT.

QCI_FREE_DEPLOYMENT_SW: Indicates whether to enable QCI-free deployment of high speed mobility. If this option is selected, high speed mobility deployment does not involve QCI attribute configuration. If this option is deselected, high speed mobility deployment requires that the QciPara.NbUeMobility parameter be set to HIGH_SPEED_MOBILITY. This option takes effect only when the HIGH_SPEED_MOBILITY_SWITCH option of the CellAlgoSwitch.NbCellAlgoSwitch parameter is selected. This option applies only to NB-IoT.

RRC_QUICK_RELEASE_SWITCH: Indicates whether to enable fast RRC connection release in the cell. If this option is selected, the NB-IoT cell instructs UEs not to send status reports when it sends RRC connection release messages to UEs. After receiving an RRC connection release message, UEs will not postpone the release for 10s. If this option is deselected, the function does not take effect. This option applies only to NB-IoT.

Antenna Selection Algorithm Switch

Indicates whether to enable the algorithms related to antenna selection.

ANT_SEL_SCHEDULING_OPT_SWITCH: Indicates whether to enable scheduling optimization for UEs capable of antenna selection in massive MIMO cells. The optimization is enabled only if this option is selected. When this option is selected, the eNodeB optimizes UE pairing for dual-stream beamforming for UEs capable of antenna selection, and allows these UEs to enter dual-stream beamforming when the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter is selected. This option applies only to LTE TDD.

CARRIER_BASED_ANT_SEL_SWITCH: Indicates whether to enable carrier-level antenna selection for UEs capable of antenna selection. If this option is selected, the eNodeB identifies the carrier-level antenna selection capability of UEs capable of antenna selection and enables TDD-carrier antenna selection for UEs capable of carrier-level antenna selection. If this option is deselected, the eNodeB does not identify the carrier-level antenna selection capability of UEs capable of antenna selection. This option applies only to LTE TDD.

Speed Test Switch

Indicates whether to enable identification of UEs that initiate speed-test services. This parameter applies only to LTE FDD and LTE TDD.

Uplink Coverage Enhancement Switch

Indicates whether to enable uplink coverage enhancement for the cell. This parameter applies only to LTE FDD.

WTTx Algorithm Switch

Indicates whether to enable WTTx-specific algorithms.

SPECTRAL_EFF_BASED_GBR_OPT_SW: Indicates whether to enable spectral-efficiency-based scheduling optimization for rate guarantee in WBB scenarios. If this option is selected, the eNodeB lowers scheduling priorities for rate-guaranteed WBB UEs with low spectral efficiency to reduce the radio resource consumption by these UEs and increase the overall cell capacity. If this option is deselected, the eNodeB uses the same scheduling priority for all rate-guaranteed UEs. This option applies only to LTE FDD and LTE TDD.

CELL_CAPB_BASED_GBR_OPT_SW: Indicates whether to enable cell-capability-based scheduling optimization for rate guarantee in WBB CA scenarios. If this option is selected, the eNodeB raises scheduling priorities for rate-guaranteed UEs in SCells with strong capabilities to reduce the impact on other UEs in cells with weak capabilities in CA scenarios. If this option is deselected, the eNodeB uses the same scheduling priority for all rate-guaranteed UEs in CA cells. This option applies only to LTE TDD.

WTTx MU-MIMO Switch

Indicates whether to enable the algorithms related to MU-MIMO in WTTx scenarios.

Tm9FourLayerPairSwitch: Indicates whether to enable four-layer pairing for TM9 MU-MIMO in 4T4R WTTx scenarios. Four-layer pairing for TM9 MU-MIMO is enabled in 4T4R WTTx scenarios only if this option is selected. This option applies only to LTE FDD.

Handover Allowed Switch

Indicates whether to enable cell-level handover functions in the cell.

INTER_RAT_MOBILITY_TO_NR_SW: If this option is selected, cell reselection from E-UTRAN to NG-RAN is enabled and UEs can reselect to NG-RAN cells. In addition, the inter-RAT mobility from E-UTRAN to NG-RAN algorithm is enabled. With this algorithm enabled, handovers or redirections from the E-UTRAN cell back to NG-RAN cells are allowed for UEs in the E-UTRAN cell. If this option is deselected, both cell reselection from E-UTRAN to NG-RAN and the inter-RAT mobility from E-UTRAN to NG-RAN algorithm are disabled. This option applies only to LTE FDD and LTE TDD.

FAST_RETURN_TO_NR_SW: If this option is selected, the fast return from E-UTRAN to NG-RAN algorithm is enabled. With this algorithm enabled, handovers or redirections from the E-UTRAN cell back to NG-RAN cells are allowed for UEs that finish voice services in the E-UTRAN cell. If this option is deselected, this algorithm is disabled. This option applies only to LTE FDD and LTE TDD.

LAI_BASED_CSFB_TO_UTRAN_SW: Indicates whether to enable LAI-based CSFB to UTRAN. LAI-based CSFB to UTRAN is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LAI_BASED_CSFB_TO_GERAN_SW: Indicates whether to enable LAI-based CSFB to GERAN. LAI-based CSFB to GERAN is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SPID_L2N_TARGET_FREQ_CTRL_SW: Indicates whether to restrict the scope of target frequencies of handovers or redirections from LTE to NR for UEs with a specific SPID. If this option is selected and a RatFreqPriorityGroup MO is configured for an SPID, UEs with this SPID can be handed over or redirected only to the NR frequency specified in this RatFreqPriorityGroup MO. If this option is deselected, the scope of target NR frequencies of handovers or redirections from LTE to NR for UEs with this SPID is not restricted. This option applies only to LTE FDD and LTE TDD.

PS_RAT_STEERING_SW: If this option is selected, only the RAT with the highest data service priority for measurements is selected during coverage-based inter-RAT handovers for data services. If this option is deselected, multiple target RATs can be selected for measurements. This option takes effect only if the eNodeB-level option is deselected. This option applies only to LTE FDD and LTE TDD.

Beam Antenna Extension Switch

Indicates whether to enable extended functions that control beam antennas within a cell.

WIDE_BEAM_ANTENNA_4T4R_SW: Indicates whether to enable widebeam antenna 4T4R. If this option is selected, baseband weighting is performed to combine wide beams to common 65° beams. If this option is deselected, default PSD weighting-based 4T4R is used. This parameter applies only to LTE TDD.

Heavy Load Performance Optimization Switch

Indicates whether to optimize performance in LampSite cells in scenarios where the inter-cell distance is small and the load is heavy.

INTRF_BASED_INTER_FREQ_HO_SW: Indicates whether to enable interference-based inter-frequency handover. Interference-based inter-frequency handover is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PUSCH_INTRF_RSRP_HIGH_THLD_SW: Indicates whether to optimize uplink power control. If this option is selected, the RSRP of interference to neighboring cells will be restricted to avoid exceeding the value of the PuschIntrfRsrpHighThld parameter in the CellPcAlgo MO in PUSCH closed-loop power control. If this option is deselected, this restriction does not take effect. This option applies only to LTE FDD and LTE TDD.

UL_RS_PWR_ADAPT_SW: Indicates whether to enable uplink RS power adaptation. If this option is selected, the cell supports uplink RS power adaptation. If this option is deselected, the cell does not support uplink RS power adaptation. This option applies only to LTE FDD and LTE TDD.

DL Scheduling Enhancement Switch

Indicates whether to enable downlink scheduling algorithms in the cell. This parameter includes the following options:

OUTER_LOOP_DSCP_QOS_MGMT_SW: Indicates whether to enable QoS management based on outer-loop DSCP. If this option is selected, QoS management based on outer-loop DSCP takes effect. If this option is deselected, QoS management based on inner-loop DSCP instead of outer-loop DSCP takes effect. This option is valid only when the VideoRateAdaptSwitch option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO is selected. The setting of this option must be consistent with the DSCP policy set in the core network. This option applies only to LTE FDD and LTE TDD.

APERIODIC_CQI_RPT_OPT_SW: Indicates whether to optimize aperiodic CQI reporting. If this option is selected, aperiodic CQI reporting is more timely. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

2D_FSS_SWITCH: Indicates whether to enable two-dimensional frequency selective scheduling. When both the SMART_FSS_SWITCH and 2D_FSS_SWITCH options are selected, two-dimensional frequency selective scheduling takes effect. When either option is deselected, two-dimensional frequency selective scheduling does not take effect. This option applies only to LTE FDD.

SMALL_PKT_MCS_CQI_ADJ_SW: Indicates whether to adjust CQIs for small packets for which the MCS index is reduced. If this option is selected, the CQI will not be adjusted for the scheduling for which a low-index MCS is reselected and the HARQ feedback is ACK. Reselection of a low-index MCS is enabled when the SmallPktMcsSelectAlgoSw option is selected. If this option is deselected, the CQI will be adjusted for the scheduling meeting the preceding conditions. This option applies only to LTE FDD.

MIN_GBR_OPT_SWITCH: Indicates whether to enable downlink minimum GBR guarantee optimization. If this option is selected, downlink minimum GBR guarantee optimization is enabled. If this option is deselected, downlink minimum GBR guarantee optimization is disabled. This option applies only to LTE FDD and LTE TDD.

LNR Intelligent Carrier Shutdown Switch

Indicates whether to enable smart LTE and NR carrier shutdown. If this parameter is set to ON and the LTE cell coverage area is the same as or includes the NR cell coverage area, services in the NR cell will be transferred to the LTE cell in a specific time segment when the overall traffic volume is low and the LTE cell capacity is sufficient. Then the NR carrier can be shut down to reduce the power consumption of the base station. If this parameter is set to OFF, LTE and NR intelligent carrier shutdown is disabled. This parameter applies only to LTE FDD and LTE TDD.

ANR Optimization Switch

Indicates whether to enable ANR algorithm optimization.

NR_NO_HO_SWITCH: If this option is selected, ANR can automatically set a no-handover flag for neighboring NG-RAN cells on condition that the NR_EVENT_ANR_SW option of the AnrFunctionSwitch parameter is selected and the CellAnrOptMode parameter is set to FREE for NG-RAN cells. If this option is deselected, ANR cannot automatically set a no-handover flag for neighboring NG-RAN cells. When this option is selected, pay attention to the neighboring cells set by ANR as cells to which handovers are prohibited so as to prevent any impact on handover performance. This option applies only to LTE FDD and LTE TDD.

LTE In-Band Inter-Freq Deployment Sw

Indicates whether to allow LTE in-band inter-frequency deployment. When this parameter is set to ON and both NB-IoT and eMTC are to be deployed in an LTE cell, inter-frequency NB-IoT deployment is allowed in the LTE cell and the deployment does not affect eMTC. In addition, downlink interference from neighboring NB-IoT carriers deployed in in-band mode to small-packet services in the LTE cell will be avoided. If this parameter is set to OFF and both NB-IoT and eMTC are to be deployed in the LTE cell, inter-frequency NB-IoT deployment is not allowed in the LTE cell. This parameter applies only to LTE FDD.

Uplink Scheduling Enhancement Switch

Indicates whether to enable enhanced uplink scheduling functions in the cell.

UL_SCH_DURATION_OPT_SW: Indicates whether to optimize uplink scheduling duration. If this option is selected, the eNodeB determines whether to optimize uplink scheduling duration based on the CPU load and uplink load. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD.

ABN_UE_SCH_RESTRICTION_SW: Indicates whether to limit the number of RBs allocated to abnormal UEs with a high proportion of padding. If this option is selected, the eNodeB limits the maximum number of RBs that can be allocated to these abnormal UEs. If this option is deselected, this function does not take effect. This option applies only to LTE FDD and LTE TDD.

DSCP_PREALLOCATION_SW: Indicates whether to enable DSCP-based uplink preallocation. If this option is selected, DSCP-based preallocation is enabled. If this option is deselected, DSCP-based preallocation is disabled. This option applies only to LTE FDD and LTE TDD.

LTE Bandwidth Compatibility Opt Sw

Indicates whether to enable optimizations in LTE non-standard bandwidth scenarios.

ABN_RRC_REEST_COMPATIBILITY_SW: Indicates whether to enable compatibility handling when defective UEs experience abnormal RRC connection reestablishments in LTE non-standard bandwidth scenarios. If this option is selected, the eNodeB redirects the defective UEs to other frequencies. If this option is deselected, the eNodeB takes no actions. This option applies only to LTE FDD and LTE TDD.

Meas Opt Algo Ext Sw

Indicates whether to enable measurement-related optimization algorithms.

SPACE_DOMAIN_MEAS_SW: Indicates whether to perform space-domain measurements. If this option is selected, space-domain measurements are enabled. If this option is deselected, space-domain measurements are disabled. This option applies only to LTE TDD.

A6_RPT_TRIG_ECGI_READ_OPT_SW: Indicates whether to optimize the procedure of triggering ECGI reading when the eNodeB receives A6 measurement reports from UEs. If this option is selected, the optimization takes effect. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

Neighboring Cell Algorithm Switch

Indicates whether to enable algorithms related to neighboring cells. This parameter includes the following option:

NR_PCI_CONFUSION_RPT_SW: If this option is selected, the cell reports the detection results of PCI confusion with neighboring NR cells to the OSS. If this option is deselected, the cell does not report the detection results of PCI confusion with neighboring NR cells to the OSS. This option applies only to LTE FDD and LTE TDD.

Operator Function Switch

Indicates whether to enable features based on operators.

FLEXIBLE_SHARING_SWITCH: Indicates whether to enable flexible sharing in the cell. Flexible sharing is enabled in the cell only if this option is selected. This option applies only to LTE FDD and LTE TDD.
