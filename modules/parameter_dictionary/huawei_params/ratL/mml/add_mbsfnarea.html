Add MbsfnArea (ADD MBSFNAREA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add configuration data for an MBSFN area.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Unit: None

Actual Value Range: 0~71

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FddTddInd FDD TDD Indication

Meaning: Indicates the duplex mode of the cells in an MBSFN area. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode. All the cells in an MBSFN area must work in the same duplex mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CELL_FDD(CELL_FDD), CELL_TDD(CELL_TDD)

Unit: None

Actual Value Range: CELL_FDD, CELL_TDD

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlDlSubframeConfig Uplink-Downlink Subframe Configuration

Meaning: Indicates the uplink-downlink subframe configuration for LTE TDD cells in an MBSFN area. For details, see 3GPP TS 36.211. All cells in an MBSFN area must use the same uplink-downlink subframe configuration. This parameter applies only to LTE TDD.

GUI Value Range: SA0(SA0), SA1(SA1), SA2(SA2), SA3(SA3), SA4(SA4), SA5(SA5), SA6(SA6)

Unit: None

Actual Value Range: SA0, SA1, SA2, SA3, SA4, SA5, SA6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
DownlinkBandwidth Downlink Bandwidth

Meaning: Indicates the downlink bandwidth of the cells in an MBSFN area. The bandwidth is represented by the number of RBs. For example, the value CELL_BW_N25 indicates a bandwidth of 25 RBs, and the value CELL_BW_N50 indicates a bandwidth of 50 RBs. For details, see 3GPP TS 36.104. All the cells in an MBSFN area must have the same downlink bandwidth. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CELL_BW_N25(CELL_BW_N25), CELL_BW_N50(CELL_BW_N50), CELL_BW_N75(CELL_BW_N75), CELL_BW_N100(CELL_BW_N100)

Unit: None

Actual Value Range: CELL_BW_N25, CELL_BW_N50, CELL_BW_N75, CELL_BW_N100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CommonSubframeAllocPeriod Common Subframe Allocation Period

Meaning: Indicates the MBSFN subframe allocation period. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF4(RF4), RF8(RF8), RF16(RF16), RF32(RF32), RF64(RF64), RF128(RF128), RF256(RF256)

Unit: None

Actual Value Range: RF4, RF8, RF16, RF32, RF64, RF128, RF256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an MBSFNAREA with the parameters as follows: Local MCE ID:0, MBSFN Area ID:0, FDD TDD Indication:CELL_FDD, Downlink Bandwidth:CELL_BW_N25, Common Subframe Allocation Period: RF4, run the following command:
ADD MBSFNAREA: LocalMceId=0, MbsfnAreaId=0, FddTddInd=CELL_FDD, DownlinkBandwidth=CELL_BW_N25, CommonSubframeAllocPeriod=RF4;
