Modify Cell MLB Configuration (MOD CELLMLB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the cell MLB algorithm.

Note

None.

InterFreqMlbThd Inter-Frequency Mobility Load Balancing Threshold

Meaning: Indicates the PRB usage threshold used to evaluate whether to trigger inter-frequency MLB. Assume that the MlbTriggerMode parameter is set to PRB_ONLY or PRB_OR_UE_NUMBER. Inter-frequency MLB is triggered when the number of UEs meets the minimum UE quantity condition for triggering inter-frequency MLB and the PRB usage is greater than or equal to the sum of this threshold and the load offset. Inter-frequency MLB stops when the PRB usage is less than this threshold or the number of UEs meets the minimum UE quantity condition for terminating inter-frequency MLB. For NB-IoT, inter-frequency MLB is triggered if the downlink resource usage is greater than or equal to the sum of this threshold and the load offset, regardless of the MLB triggering mode.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 60

Parameter Relationship:

-Configuration constraints:

  • In the CellMLB MO, the sum of InterFreqMlbThd and LoadOffset must be smaller than or equal to 100.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering MLB and higher gains to system throughput after UEs are transferred. However, a larger value leads to a longer period during which the throughput is affected because of resource insufficiency before the UEs are transferred. If this parameter is set too small, the MLB algorithm takes effect frequently, which leads to more signaling interaction and handovers. This increases the CPU load and brings little gains to the system throughput.

Applicable Mode: L

Inter-RAT load sharing stops if the number of synchronized UEs in the cell is less than the InterRatMlbUeNumThd parameter value or the PRB usage of the cell is less than the InterRatMlbThd parameter value. This parameter applies only to LTE FDD and LTE TDD.

LoadOffset Load Offset

Meaning: Indicates the offset of the PRB usage for triggering inter-frequency MLB. Inter-frequency MLB is triggered if the minimum number of UEs meets a specified requirement and the PRB usage is greater than or equal to the sum of the inter-frequency MLB threshold and the load offset, or if the minimum number of UEs meets a specified requirement and the PRB evaluation result is greater than or equal to the sum of the PRB-evaluation-based MLB triggering threshold and the load offset. Inter-RAT MLB is triggered if the number of UEs meets the requirement for triggering inter-RAT MLB and the PRB usage is greater than or equal to the sum of the inter-RAT MLB triggering threshold and the load offset. Inter-RAT idle mode MLB is triggered if the number of UEs meets the requirement for triggering inter-RAT idle mode MLB and the PRB usage is greater than or equal to the sum of the inter-RAT MLB triggering threshold and the load offset. For an NB-IoT cell, this parameter indicates the offset of NB-IoT cell load.

A small value of this parameter, however, may result in the frequent triggering or stopping of the load balancing algorithm.

LoadDiffThd Load Difference Threshold

Meaning: Indicates the threshold of PRB usage difference between the serving cell and a neighboring cell. A neighboring cell can be a target cell for intra-RAT MLB only if the result of the PRB usage of the serving cell minus that of the neighboring cell is greater than the value of this parameter. For inter-RAT MLB, the total PRB usage of all UEs to be transferred within an LMB period in the direction where MLB is triggered must be less than half of the sum of the values of CellMLB.LoadDiffThd and CellMLB.LoadDiffThldOffset.

For NB-IoT cells, this parameter indicates the threshold of subcarrier usage difference between the serving cell and a neighboring cell. When the result of the subcarrier usage of the serving cell minus that of an inter-frequency neighboring cell is greater than the value of this parameter, the neighboring cell can be a target cell for MLB.

GUI Value Range: 1~50

Unit: %

Actual Value Range: 1~50

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher requirement on resource sufficiency of neighboring cells. Therefore, it is less likely that neighboring cells meet the requirement, and it is more difficult to trigger MLB. However, more RRC_IDLE UEs can be transferred to the neighboring cells meeting the requirement within an MLB period. A smaller value of this parameter leads to a lower requirement on resource sufficiency of neighboring cells. Therefore, it is more likely that neighboring cells meet the requirement, and it is easier to trigger MLB. However, fewer RRC_IDLE UEs can be transferred within an MLB period.

Applicable Mode: L
InterRatMlbUeNumThd Inter-RAT Mobility Load Balancing UE Number Threshold

Meaning: Indicates the threshold for the number of uplink synchronized UEs in the cell used to trigger PRB-usage-based inter-RAT load sharing. PRB-usage-based inter-RAT load sharing is triggered when the PRB usage condition for triggering the load sharing is met and the number of uplink synchronized UEs in the cell is greater than or equal to the sum of the InterRatMlbUeNumThd and InterRatMlbUeNumOffset parameter values. PRB-usage-based inter-RAT load sharing stops if the number of uplink synchronized UEs in the cell is less than the InterRatMlbUeNumThd parameter value or the PRB usage condition for stopping the load sharing is met. The actual threshold for the number of uplink synchronized UEs equals the percentage value of this parameter multiplied by 1000. For example, the GUI value of 1 indicates that the threshold for the number of uplink synchronized UEs is 10 (1000 x 1%), the GUI value of 2 indicates a threshold of 20, and the GUI value of 10 indicates a threshold of 100. An exception is that if the parameter value is 100 or 99, the threshold for the number of uplink synchronized UEs is 1 or 2, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The value of this parameter has a significant impact on inter-RAT load sharing. A larger value of this parameter results in a higher probability of delayed inter-RAT load sharing when the cell is overloaded. A smaller value, however, causes a higher probability of inter-RAT handovers and network performance deterioration due to low inter-RAT handover success rates.

Applicable Mode: L-FDD, L-TDD

Applicable Mode: L
MlbTriggerMode Mobility Load Balancing Trigger Mode

Meaning: Indicates the trigger of the MLB algorithm. In MLB with load information exchange, if this parameter is set to PRB_ONLY, PRB usage is used as a trigger and the number of UEs is used as a supplementary trigger; PRB usage difference between cells is used as a UE transfer condition; the aim of MLB is to achieve the same number of remaining PRBs between cells. If this parameter is set to UE_NUMBER_ONLY, the number of UEs is used as a trigger; the difference of the number of UEs per unit of bandwidth between cells is used as a UE transfer condition; the aim of MLB is to achieve the same number of UEs per unit of bandwidth between cells. If this parameter is set to PRB_OR_UE_NUMBER, the combination of the triggers, UE transfer conditions, and MLB aims for the values UE_NUMBER_ONLY and PRB_ONLY are used.

In MLB without load information exchange, if this parameter is set to PRB_ONLY, PRB usage is used as a trigger and a UE transfer condition and the number of UEs is used as a supplementary trigger and a supplementary UE transfer condition; the aim of MLB is that the PRB usage is less than the InterFreqMlbThd or InterFreqIdleMlbUeNumThd parameter value. If this parameter is set to UE_NUMBER_ONLY, the number of UEs is used as a trigger and a UE transfer condition; the aim of MLB is that the number of UEs is less than the InterFreqMlbUeNumThd or InterFreqIdleMlbUeNumThd parameter value. If this parameter is set to PRB_OR_UE_NUMBER, the combination of the triggers, UE transfer conditions, and MLB aims for the values UE_NUMBER_ONLY and PRB_ONLY are used. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PRB_ONLY(PrbMode), UE_NUMBER_ONLY(UeNumMode), PRB_OR_UE_NUMBER(PrbOrUeNumMode)

Unit: None

Actual Value Range: PRB_ONLY, UE_NUMBER_ONLY, PRB_OR_UE_NUMBER

MML Default Value: None

Recommended Value: PRB_ONLY(PrbMode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to PRB_ONLY, channel resource allocation among frequencies for transmitting user data is balanced, and the system throughput increases.

If this parameter is set to UE_NUMBER_ONLY, the packet transmission delay reduces, and user experience improves.

Applicable Mode: L-FDD, L-TDD

InterFreqMLBRanShareMode Inter-Frequency MLB RAN Sharing Mode

Meaning: Indicates whether to enable operator-level and operator-group-level inter-frequency MLB. If this parameter is set to NON_SHARING, the eNodeB performs cell-level inter-frequency MLB without distinguishing resources between operators or operator groups. If this parameter is set to SHARING, the eNodeB can perform operator-level inter-frequency MLB based on the resources reserved for each operator in RAN sharing mode. If this parameter is set to OVERSHARING, the eNodeB can perform operator-level inter-frequency MLB based on both the cell load and the operator's load in RAN sharing mode. If this parameter is set to GROUPSHARING, the eNodeB can perform operator-group-level inter-frequency MLB based on the resources reserved for each operator group in RAN sharing mode. If this parameter is set to GROUPOVERSHARING, the eNodeB can perform operator-group-level inter-frequency MLB based on both the overall cell and operator load in RAN sharing mode.

If this parameter is set to OVERSHARING(OVERSHARING), operator-level inter-frequency MLB is performed only if both the cell load and operator-specific load meet the MLB trigger conditions, thereby ensuring system resource usage.

Each operator cannot use resources of other operators in the same operator group, and the load status of one operator group does not affect resources used by other operator groups. However, the system resource usage is lower than that in cell-level inter-frequency MLB.

If this parameter is set to GROUPOVERSHARING(GROUPOVERSHARING), operator-group-level inter-frequency MLB is performed only if both the cell load and operator-group-specific load meet the MLB trigger conditions, thereby ensuring system resource usage.
