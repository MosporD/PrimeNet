Modify an APN template (MOD EUAPNTEMPLATE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify an APN template.

Note

None.

Parameters

ID Name Description
APNTemplateID APN Template ID

Meaning: Indicates the ID of an APN template. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
APN APN

Meaning: Indicates the APN bound to the subscriber template. The value of this parameter can contain a maximum of seven dots (.). Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100 characters

Unit: None

Actual Value Range: 1~100 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
QCI QoS class identifier

Meaning: Indicates a compact EPC QoS attribute that is provided for a service data flow (SDF) as a reference to a specific packet forwarding behavior (such as packet loss rate and delay). The packet forwarding is performed based on the QCI-related parameters that are pre-configured on the access network node (such as the eNodeB). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 5~254

Unit: None

Actual Value Range: 5~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
APNAMBRDL APN Aggregate Maximum Bit Rate Downlink

Meaning: Indicates the downlink aggregate maximum bit rate (AMBR) of the APN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~4294967295

Unit: bit/s

Actual Value Range: 1~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
APNAMBRUL APN Aggregate Maximum Bit Rate Uplink

Meaning: Indicates the uplink aggregate maximum bit rate (AMBR) of the APN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~4294967295

Unit: bit/s

Actual Value Range: 1~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ARP Allocation and Retention Priority

Meaning: Indicates a QoS attribute that specifies the relative importance compared to other bearers for allocation and retention of the bearer. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

PreemptionCapability Preemption Capability

Meaning: Indicates a QoS attribute that specifies whether bearers can occupy resources for lower-priority service data flows. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLED(DISABLED), ENABLED(ENABLED)

Unit: None

Actual Value Range: DISABLED, ENABLED

Applicable Mode: L-FDD, L-TDD
PreemptionVulnerability Preemption Vulnerability

Meaning: Indicates a QoS attribute that controls whether resources for service data flows can be occupied by higher-priority service data flows. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLED(DISABLED), ENABLED(ENABLED)

Unit: None

Actual Value Range: DISABLED, ENABLED

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set an APN template with the parameters as follows: APN Template ID:4, QoS class identifier:7, run the following command:
MOD EUAPNTEMPLATE: APNTemplateID=4, QCI=7;
