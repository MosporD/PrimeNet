List Cell MLB Auto Group Configuration (LST CELLMLBAUTOGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query automatic grouping information for MLB between cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of ANGC for MLB of a cell:
LST CELLMLBAUTOGROUP:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Overlap Indicator Addition Threshold(%)

Indicates the threshold for setting the overlap indicator. The eNodeB compares the measured proportion of coverage overlap between the serving cell and each inter-frequency neighboring cell with this threshold. If the proportion for an inter-frequency neighboring cell exceeds or equals this threshold, the eNodeB sets the overlap indicator for the neighboring cell.

A smaller value of this parameter indicates a lower coverage overlap requirement for setting the overlap indicator. A larger value of this parameter results in the opposite effect. This parameter applies only to LTE FDD and LTE TDD.

Overlap Indicator Deletion Threshold(%)

Indicates the threshold for clearing the overlap indicator. With auto neighbor group configuration (ANGC) for MLB, the eNodeB compares the measured proportion of coverage overlap between the serving cell and an inter-frequency neighboring cell with this threshold. If the overlap indicator has been set for the inter-frequency neighboring cell and the proportion for the neighboring cell is less than the threshold, the eNodeB clears the overlap indicator for the cell.

A smaller value of this parameter results in a lower probability of clearing the overlap indicator. A larger value results in a higher probability. This parameter applies only to LTE FDD and LTE TDD.

Statistic Period(min)

Indicates the measurement period of ANGC for MLB. If the number of samples collected in a period meets the requirement, the eNodeB calculates the coverage overlap proportion and sets or clears overlap indicators within the period. If the number of samples collected in the period does not meet the requirement, the eNodeB automatically extends a second period and performs accumulated statistics collection. To ensure the work efficiency of the algorithm, the eNodeB extends only one period for sample counting.

A shorter measurement period results in faster setting or clearing of overlap indicators. A longer measurement period results in the opposite effect. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Sleep Period(min)

Indicates the sleep period during which ANGC for MLB stops working after one round of statistics collection and configuration. The function resumes after the sleep period if the network topology changed during the sleep period. If this parameter is set to 65535, ANGC for MLB does not enter the sleep period but periodically works. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Additional Measurement Configuration

Indicates whether the eNodeB can instruct UEs to perform additional measurements to provide more samples for collecting statistics. During Auto Neighbor Group Configuration (ANGC) for MLB, if the number of collected samples is insufficient, the eNodeB instructs UEs to perform additional measurements so that the number of samples may reach the preset quantity threshold.

If this parameter is set to ALLOWED, the eNodeB instructs UEs to perform additional measurements in an extension period that automatically starts when the number of samples in a measurement period does not reach the preset target. If this parameter is set to NOT_ALLOWED, the eNodeB does not instruct UEs to perform additional measurements. This parameter applies only to LTE FDD and LTE TDD.

Overlap Indicator Auto Sample Number

Indicates the minimum required number of A4 and A5 measurement report samples for starting coverage evaluation during ANGC for MLB. The eNodeB starts coverage evaluation only if the number of samples reaches or exceeds the value of this parameter. Based on the samples, the eNodeB will calculate the coverage overlap proportion and sets or clears the overlap indicator for the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

Optimization Mode

Indicates the working mode of auto neighbor group configuration (ANGC) for MLB.

If this parameter is set to FREE, the eNodeB automatically sets or clears the overlap indicator. If this parameter is set to CONTROLLED, the eNodeB reports the advice on setting or clearing the overlap indicator to the MAE, and operators determine whether to take the advice. This parameter applies only to LTE FDD and LTE TDD.

Micro Overlap Indicator Addition Threshold (%)

Indicates the threshold for adding an overlap indicator to a micro cell. The automatic overlap indicator configuration function of the micro cell checks the percentage of the overlapping area between the micro cell and inter-frequency macro cell. If the percentage is greater than or equal to this threshold, the micro cell requests the macro cell to add an overlap indicator to the micro cell. This parameter applies only to LTE FDD and LTE TDD.

Micro Overlap Indicator Deletion Threshold (%)

Indicates the threshold for clearing the overlap indicator of a micro cell. The automatic overlap indicator configuration function of the micro cell checks the percentage of the overlapping area between the micro cell and inter-frequency macro cell. If the percentage is smaller than this threshold and the micro cell is labeled an overlap indicator, the micro cell requests the macro cell to clear the overlap indicator of the micro cell. This parameter applies only to LTE FDD and LTE TDD.
