Modify an RRN (MOD EURRN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of an EU RRN.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Meaning: Indicates the policy in which the local WAP of the RRN works.

If this parameter is set to AUTOMATIC, local WAP is disabled after the RRN accesses a cell and local WAP is enabled when the RRN cannot access the cell. If this parameter is set to ALWAYS_ON, local WAP is always enabled. If this parameter is set to ALWAYS_OFF, local WAP is always disabled.

LocalWapRegionCode Local WAP Region Code

Meaning: Indicates the region code of the country where the RRN is located. Different regions support different 2.4 GHz WLAN channels. The RRN supports five types of region codes. REGION_0 indicates North America, where channels 1 to 11 are available. REGION_1 indicates part of Europe, Japan, and China, where channels 1 to 13 are available. REGION_2 indicates France, where channels 1 to 9 are available. REGION_3 indicates Israel, where channels 5 to 13 are available. REGION_USER_DEFINED indicates all areas, where channels 1 to 14 are available. If REGION_0, REGION_1, REGION_2, and REGION_3 do not match the location of the base station, set this parameter to REGION_USER_DEFINED. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: REGION_0(REGION_0), REGION_1(REGION_1), REGION_2(REGION_2), REGION_3(REGION_3), REGION_USER_DEFINED(REGION_USER_DEFINED)

LocalWapChannelNumber Local WAP Channel Number

Meaning: Indicates the channel number used by the local Wireless Access Protocol (WAP) of the RRN. Different countries and regions may use different channel policies. For example, indoor and outdoor WLANs use different channels. When the LocalWapRegionCode parameter is set to REGION_0, REGION_1, REGION_2, or REGION_3, the LocalWapChannelNumber parameter can be set to CHANNEL_AUTOMATIC. In this case, the WLAN module automatically selects the most appropriate channel, that is, the channel with the minimum interference. When the LocalWapRegionCode parameter is set to REGION_USER_DEFINED, the LocalWapChannelNumber parameter cannot be set to CHANNEL_AUTOMATIC, and the WLAN module cannot automatically select the most appropriate channel. The channel number must be set to a specific value. The parameter value must meet the laws, regulations, and industry standard requirements of the country or region where the base station is located. The typical rate is 6 Mbit/s when there is neither obstacle nor obvious interference within a radius of five meters. If the data rate is low, you can modify the value of this parameter to avoid co-channel interference. It is recommended that the parameter value be far away from the current value or you can attempt other channels one by one. In addition, ensure that the terminal is close to the WLAN module and there is no obstacle between them. The weather and strong magnetic field affect the WLAN transmission rate. This parameter applies only to LTE FDD and LTE TDD.

Example

To set an RRN with the parameters as follows: Local Subscriber ID:1, OM IP:172.31.255.6, run the following command:
MOD EURRN: LocalSubscriberId=1, OmIp="172.31.255.6";
