Add Parameter Group for Handover to NR (ADD INTERRATHONRPARAMGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a parameter group related to inter-RAT handovers to NR cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NrHoParamGroupId NR Handover Parameter Group ID

Meaning: Indicates the group ID of parameters for handovers from the E-UTRAN to NR. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NrB1B2Hysteresis NR B1B2 Hysteresis

Meaning: Indicates the hysteresis for events B1 and B2 related to EUTRAN-to-NR handovers. This parameter prevents frequent handover measurement triggering and release caused by radio signal fluctuations and reduces the probability of incorrect handover decisions and ping-pong handovers. The larger the parameter value, the lower this probability. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Entering condition for event B1: Mn + Ofn - Hys > Thresh

Entering condition for event B2: Ms + Hys < Thresh1 and Mn + Ofn - Hys > Thresh2. These conditions must be fulfilled throughout time-to-trigger before the corresponding event can be triggered.

In the formulas, Ms and Mn indicate the measurement results of the serving cell and a neighboring cell, respectively. Ofn indicates the frequency-specific offset for the neighboring cell. Thresh indicates the threshold for event B1, and Thresh1 and Thresh2 indicate thresholds 1 and 2 for event B2. Hys indicates the hysteresis for the individual events.

A larger value of this parameter results in a lower probability of triggering events B1 and B2 and handovers, which affects user experience. A smaller value results in a higher probability of triggering events B1 and B2 and also a higher probability of incorrect handover decisions and ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
NrB1B2TimeToTrigger NR B1B2 Time-to-Trigger

Meaning: Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-NR handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: 320ms(320ms)

Recommended Value: 320ms(320ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handovers to NR cells, and a smaller value results in a higher probability.

Applicable Mode: L-FDD, L-TDD
CovBasedNrB1RsrpThld Coverage-based NR B1 RSRP Threshold

Meaning: Indicates the RSRP threshold for triggering event B1 related to coverage-based EUTRAN-to-NR handovers. If the measured RSRP value of any neighboring cell exceeds this threshold, B1 measurement reports will be sent to the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: -105

Recommended Value: -105

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of handovers to NR cells, and a larger value results in a lower probability.

Applicable Mode: L-FDD, L-TDD
ServBasedNrB1RsrpThld Service-based NR B1 RSRP Threshold

Meaning: Indicates the RSRP threshold for triggering event B1 related to service-based EUTRAN-to-NR handovers. If the measured RSRP value of any neighboring cell exceeds this threshold, B1 measurement reports will be sent to the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: -109

Recommended Value: -109

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher handover probability, and a larger value results in a lower probability. Setting this parameter based on network conditions helps reduce the service drop rate, improve user experience, and optimize network performance.

Applicable Mode: L-FDD, L-TDD
NsaDcSaNrHoNoGapB1Ttt NSA DC SA NR HO No-Gap HO B1 Time-to-Trigger

Meaning: Indicates the time-to-trigger for event B1 reported based on non-gap-assisted measurements for inter-RAT handovers of NSA DC UEs to NG-RAN in SA networking. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0MS(0MS), 40MS(40MS), 64MS(64MS), 80MS(80MS), 100MS(100MS), 128MS(128MS), 160MS(160MS), 256MS(256MS), 320MS(320MS), 480MS(480MS), 512MS(512MS), 640MS(640MS), 1024MS(1024MS), 1280MS(1280MS), 2560MS(2560MS), 5120MS(5120MS)

Unit: None

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: 320MS(320MS)

Recommended Value: 320MS(320MS)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of meeting entering and leaving conditions for the event. A smaller value of this parameter results in the opposite effect.

Applicable Mode: L-FDD, L-TDD

Example

To add a group of parameters related to inter-RAT handovers to NR cells with the parameters as follows: Local cell ID: 0, NR Handover Parameter Group ID: 9, other parameters: default values, run the following command:
ADD INTERRATHONRPARAMGRP: LocalCellId=0, NrHoParamGroupId=9;
