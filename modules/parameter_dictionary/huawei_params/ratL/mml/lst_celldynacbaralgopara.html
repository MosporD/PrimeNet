List Cell Dynamic AC Barring Control Parameter (LST CELLDYNACBARALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of dynamic access barring control in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of dynamic access barring of a cell:
LST CELLDYNACBARALGOPARA:;

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Dynamic AC Barring Control Statistic Period(s)

Indicates the statistic period of dynamic access class (AC) barring in a cell, during which the proportion of time that the cell is in the congestion state is exported. This parameter applies only to LTE FDD and LTE TDD.

Dynamic AC Barring Control Trigger Threshold(%)

Indicates the threshold for triggering dynamic access class (AC) barring in the cell. This threshold specifies the proportion of time that the cell is in the congestion state. If the proportion of time that the cell is in the congestion state is greater than or equal to this parameter value within a statistic period (specified by the DynAcBarStatPeriod parameter), the conditions for triggering dynamic AC barring are met. This parameter applies only to LTE FDD and LTE TDD.

Dynamic AC Barring Control Cancel Threshold(%)

Indicates the threshold for canceling dynamic access class (AC) barring in the cell. This threshold specifies the proportion of time that the cell is in the congestion state. If the proportion of time that the cell is in the congestion state is less than or equal to this parameter value within a statistic period (specified by the DynAcBarStatPeriod parameter), the conditions for canceling dynamic AC barring are met. This parameter applies only to LTE FDD and LTE TDD.

Ssac Trigger Condition Satisfied Periods

Indicates the number of consecutive periods for triggering intelligent access barring on specific services. If related triggering conditions are met for the specified number of consecutive periods, intelligent access barring on specific services is triggered. This parameter applies only to LTE FDD and LTE TDD.

Ssac Cancel Condition Satisfied Periods

Indicates the number of consecutive periods for canceling intelligent access barring on specific services. If related cancellation conditions are met for the specified number of consecutive periods, intelligent access barring on specific services is canceled. This parameter applies only to LTE FDD and LTE TDD.

Disaster Reference Indication

Indicates the disaster reference indications used for determining whether a cell is in the disaster state. If all options included in this parameter are deselected, the disaster state of the cell does not need to be determined.

ETWS_PN: Indicates whether Primary notifications (PNs) in the earthquake and tsunami warning system (ETWS) are used in the disaster state determination. The PNs for ETWS do not include PNs used for ETWS tests.

If this option is selected, PNs in ETWS are used in the disaster state determination.

If this option is deselected, PNs in ETWS are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

ETWS_PN_TEST: Indicates whether PNs for ETWS tests are used in the disaster state determination.

If this option is selected, PNs in ETWS tests are used in the disaster state determination.

If this option is deselected, PNs in ETWS tests are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

CMAS: Indicates whether commercial mobile alert system (CMAS) warning notifications are used in the disaster state determination.

If this option is selected, CMAS warning notifications are used in the disaster state determination.

If this option is deselected, CMAS warning notifications are not used in the disaster state determination. This option applies only to LTE FDD and LTE TDD.

Disaster Duration(min)

Indicates the duration that the cell is in the disaster state. The cell is out of the disaster state after the duration specified by this parameter ends. This parameter applies only to LTE FDD and LTE TDD.

MO Trigger Condition Satisfied Periods

Indicates the number of consecutive periods for triggering intelligent access class control on mobile-originated (MO) calls or signaling if related triggering conditions are met. This parameter applies only to LTE FDD and LTE TDD.

MO Cancel Condition Satisfied Periods

Indicates the number of consecutive periods for canceling intelligent access class control on mobile-originated (MO) calls or signaling if related cancellation conditions are met. This parameter applies only to LTE FDD and LTE TDD.

MO Factor Adjusting Step

Indicates the MO factor adjustment step used after intelligent AC control is triggered. The adjustment target factor is the factor that is ahead of the current factor by the value of this parameter. For example, if this parameter is set to 2 and the current factor is p95, the target factor is p85, which is ahead of p95 by two factors. If the adjustment step required for adjusting the current factor to p05 is less than the value of this parameter, the factor is directly adjusted to p05. This parameter applies only to LTE FDD and LTE TDD.

MO Factor Retreating Step

Indicates the MO factor retreating step used after the conditions for canceling intelligent AC control are met but the number of consecutive periods in which the conditions are met has not reached the value of the MoCancelCondSatiPeriods parameter. The retreating target factor is the factor that is behind the current factor by the value of the MO Factor Retreating Step parameter. For example, if this parameter is set to 2 and the current factor is p85, the target factor is p95, which is behind p85 by two factors. If the step required for retreating the current factor to p95 is less than the value of this parameter, the factor is directly adjusted to p95. This parameter applies only to LTE FDD and LTE TDD.

SSAC Factor Adjusting Step

Indicates the service specific access control (SSAC) factor adjustment step used after SSAC is triggered. The adjustment target factor is the factor that is ahead of the current factor by the value of this parameter. For example, if this parameter is set to 2 and the current factor is p95, the target factor is p85, which is ahead of p95 by two factors. If the adjustment step required for adjusting the current factor to p05 is less than the value of this parameter, the factor is directly adjusted to p05. This parameter applies only to LTE FDD and LTE TDD.

SSAC Factor Retreating Step

Indicates the service specific access control (SSAC) factor retreating step used after the conditions for canceling SSAC are met but the number of consecutive periods in which the conditions are met has not reached the value of the SsacCancelCondSatiPeriods parameter. The retreating target factor is the factor that is behind the current factor by the value of the SSAC Factor Retreating Step parameter. For example, if this parameter is set to 2 and the current factor is p85, the target factor is p95, which is behind p85 by two factors. If the step required for retreating the current factor to p95 is less than the value of this parameter, the factor is directly adjusted to p95. This parameter applies only to LTE FDD and LTE TDD.

MO Factor Initial Value

Indicates the initial value of the probability factor used after dynamic AC barring on mobile-originated calls or signaling is started. This parameter applies only to LTE FDD and LTE TDD.

RRC Reject Rate Congestion Trigger Thld(%)

Indicates the threshold of RRC connection reject rate for triggering access control. If the RRC connection reject rate of a cell is continuously higher than this threshold for N (N = the value of the MoTriggerCondSatiPeriods parameter) consecutive statistic periods specified by the DynAcBarStatPeriod parameter, the cell enters the automatic AC barring control process. This parameter applies only to LTE FDD and LTE TDD.

Ue-Number-based Congestion Clear Thld

Indicates the UE number threshold for relieving the congestion state of a cell. If the number of UEs in a cell in the UE number congestion state becomes less than the value of this parameter, the cell exits this congestion state. If this parameter is set to 0, the function of this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

UE-Number-based Congestion Thld

Indicates the UE number threshold for entering the congestion state of a cell. If the number of UEs in a cell not in the UE number congestion state exceeds the value of this parameter, the cell enters the UE number congestion state. If this parameter is set to 0, the function of this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.
