Modify Neighboring Relation with GERAN Cell (MOD GERANNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the neighboring relation with a GERAN cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

NCellMeasPriority Neighboring Cell Measure Priority

Meaning: Indicates the measurement priority of the neighboring GERAN cell. A larger value indicates a higher priority. The measurement priorities can be periodically and automatically arranged based on the number of times each neighboring GERAN cell is measured. The neighboring GERAN cells for fast blind redirections to GERAN or blind redirections for flash CSFB to GERAN can be selected based on the measurement priorities of neighboring GERAN cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~128

Unit: None

Actual Value Range: 0~128

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter indicates a higher measurement priority of a neighboring GERAN cell, and a higher probability of the neighboring GERAN cell being selected in GERAN flash blind redirections or GERAN flash-CSFB-based blind redirections, thereby increasing the accuracy of GERAN flash blind redirections or GERAN flash-CSFB-based blind redirections and reducing the redirection delay.

Applicable Mode: L-FDD, L-TDD
CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AUTO_MODE(Auto Mode), MANUAL_MODE(Manual Mode)

Unit: None

Actual Value Range: AUTO_MODE, MANUAL_MODE

MML Default Value: None

Recommended Value: AUTO_MODE(Auto Mode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the neighboring relation with the GERAN cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", Location area code: 12, GERAN cell ID: 15, No remove indicator: FORBID_RMV_ENUM, No handover indicator: PERMIT_HO_ENUM, run the following command:
MOD GERANNCELL: LocalCellId=0, Mcc="460", Mnc="20", Lac=12, GeranCellId=15, NoRmvFlag=FORBID_RMV_ENUM, NoHoFlag=PERMIT_HO_ENUM;
Example 2: To modify the neighboring relation with the GERAN cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", Location area code: 12, GERAN cell ID: 15, No handover indicator: FORBID_HO_ENUM, run the following command:
MOD GERANNCELL: LocalCellId=0, Mcc="460", Mnc="20", Lac=12, GeranCellId=15, NoHoFlag=FORBID_HO_ENUM;
