Add Pmch (ADD PMCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add PMCH configuration data.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local MCE ID, which is unique on the local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the MBSFN area ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Recommended Value: None

Meaning: Indicates the PMCH ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~14

AllocationEndSubframe Allocation End Subframe

Meaning: Indicates the end subframe for PMCH allocation. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1535

MchSchedulingPeriod MCH Scheduling Period

Meaning: Indicates the PMCH scheduling period. The PMCH scheduling period must be a multiple of the MBSFN subframe allocation period. The MBSFN subframe allocation period is specified by the CommonSubframeAllocPeriod parameter in the MbsfnArea MO. The PMCH scheduling period must not be greater than the value of the RepetitionPeriod parameter in the Mcch MO. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF8(RF8), RF16(RF16), RF32(RF32), RF64(RF64), RF128(RF128), RF256(RF256), RF512(RF512), RF1024(RF1024)

Unit: None

Qci QoS Class Identifier

Meaning: Indicates the QCI of GBR bearers for MBMS services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Example

To add a PMCH with the parameters as follows: Local MCE ID:0, MBSFN Area ID:0, PMCH ID:0, Allocation End Subframe:1, Data Modulation and Coding Scheme:1, MchSchedulingPeriod:RF8, Qci:2, run the following command:
ADD PMCH: LocalMceId=0, MbsfnAreaId=0, PmchId=0, AllocationEndSubframe=1, DataMcs=1, MchSchedulingPeriod=RF8, Qci=2;
