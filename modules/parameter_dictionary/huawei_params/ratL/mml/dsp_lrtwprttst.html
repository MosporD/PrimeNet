Display RTWP Test (DSP LRTWPRTTST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query results of the latest RTWP tests and the status of the ongoing RTWP tests.

Note

None.

Parameters

None.

Example

To display an RTWP test for cells, run the following command:
DSP LRTWPRTTST:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Test Object

Indicates the type of the tested object.

Test Period(s)

Indicates the interval between tests.

Test Time(min)

Indicates the maximum test duration. If the test interval is 1s, the maximum test duration is 10 days, that is, 14400 minutes. If the test interval is 10s, the maximum test duration is 100 days, that is, 144000 minutes.

Test State

Indicates the test status of the received total wideband power (RTWP) test in the cell.
