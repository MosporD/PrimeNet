Activate Cell (ACT CELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to activate a cell.

Note

  • Only an unblocked cell can be properly set up.

  • Before running this command, ensure that cell operators are configured.

  • Before running this command, ensure that carrier resources are configured.

  • The cell activation failure may be caused by the unavailability of carrier resources. The preparation of carrier resources takes a few seconds. After carrier resources are available, the cell will be automatically activated. You are advised to query the cell status by running the DSP CELL command 10 seconds later. If the cell is still not activated, check whether an alarm is reported. If an alarm is reported, clear the alarm by referring to eNodeB Alarm Reference.

  • When you activate cells with different antenna modes established on the same BBP, check the cell specifications and networking if the following message is displayed: The antenna modes of the cells established on the BBP conflict with each other. If the number of established cells is within the cell specifications, reset the BBP to rectify the problem.

  • If a cell fails to be activated within the internal protection time because a fault occurs in the baseband resources bound to the cell or the baseband resources bound to the cell are occupied by another cell, run the DSP CELL command to query the cell status after the internal protection time ends. If the cell is still unavailable according to the query results, check for related alarms and handle the activation failure based on the alarm handling suggestions. The internal protection time lasts (eNodeBResModeAlgo.BbpResAutoRecfgTimer - 8) minutes. If the eNodeBResModeAlgo.BbpResAutoRecfgTimer parameter value is less than 8, the internal binding algorithm does not take effect.

  • The BBP to which the RF module for a cell is directly connected and the BBP used by this cell cannot be located in different BBUs.

  • Before activating an SFN cell, ensure that the value of the SectorEqmNum parameter in the Cell MO corresponding to this SFN cell is greater than or equal to the number of eUCellSectorEqm MOs for the cell.

  • Before running this command, ensure that the RRU cascading level, cell bandwidth, and CPRI compression configuration meet the CPRI bandwidth and data rate requirements. Otherwise, the command execution fails.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To activate a cell with the local cell ID of 0, run the following command:
ACT CELL:LocalCellId=0;
