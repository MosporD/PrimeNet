List UL CS Algorithm Configuration (LST ULCSALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the settings of parameters related to cell-level UL CS algorithms.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the configurations of the cell-level UL CS algorithm:
LST ULCSALGOPARA:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

UL Coordinated PC IN Threshold(dBm)

Indicates the interference noise threshold for triggering UL coordinated power control (CPC). If the uplink interference noise level in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.

UL Coordinated PC Rollback RSRP Threshold(dBm)

Indicates the RSRP threshold used for UEs involved in UL coordinated power control (CPC) rollback. This parameter applies only to LTE FDD.

UL Coordinated PC User Number Threshold

Indicates the UE number threshold for triggering UL coordinated power control (CPC). If the number of UL-synchronized UEs in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.

UL Coordinated Resource Allocation Band Mode

Indicates the mode of arranging the guard bands of cells for UL coordinated resource allocation. The mode determines the guard band positions. This parameter applies only to LTE FDD.

UL Coordinated Resource Allocation RB Load Thld(%)

Indicates the load threshold for triggering UL coordinated resource allocation. If the PUSCH RB usage in a cell is higher than this threshold, the eNodeB allocates protected UEs only resources in the guard bands. This parameter applies only to LTE FDD.

UL CS A3 Offset(0.5dB)

Indicates the offset for event A3 for UL coordinated scheduling (CS). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.

UL CS Switch

Indicates whether to enable functions of UL coordinated scheduling (CS) for a cell.

UL_COORD_RES_ALLOC_SWITCH: Indicates whether to enable UL coordinated resource allocation. UL coordinated resource allocation is enabled only if this option is selected. This option applies only to LTE FDD.

UL_COORD_PC_SWITCH: Indicates whether to enable UL coordinated power control (CPC). UL CPC is enabled only if this option is selected. This option applies only to LTE FDD.

UL Coordinated Resource Alloc IN Threshold(dBm)

Indicates the interference noise threshold for enabling uplink coordinated resource allocation (UL CRA). If the average interference noise level of the cells in the cluster for UL CRA is greater than this threshold, the interference condition for enabling UL CRA is met. This parameter applies only to LTE FDD.

UL CRA User Number Threshold

Indicates the UE number threshold for enabling uplink coordinated resource allocation (UL CRA). UL CRA takes effect in a cell if the number of served UEs is lower than this threshold. This parameter applies only to LTE FDD.

Uplink CRA Support MOCN Switch

Indicates whether to enable UL CRA in MOCN scenarios where air interface resources and traffic are fully shared. When this parameter is set to ON, UL CRA can be enabled. When this parameter is set to OFF, UL CRA cannot be enabled. This parameter applies only to LTE FDD.
