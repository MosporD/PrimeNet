Add Tracking Area Configuration for CN Operator (ADD CNOPERATORTA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a tracking area for the eNodeB.

Note

An operator can be configured with a maximum of 18 TACs. An eNodeB can be configured with a maximum of 108 tracking areas, which are identified by TACs.

When the TAC is modified, the TAC on the EPC must be modified correspondingly. If the TAC on the EPC is not modified correspondingly, UEs cannot access the network.

Parameters

ID Name Description
TrackingAreaId Local tracking area ID

Meaning: Indicates the tracking area ID, which uniquely identifies an entry of tracking area information. This parameter is used only within the eNodeB and is not used during the information exchange with the EPC. This is different from the TAI configured in the EPC TAL.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The combination of CnOperatorId and Tac in each CnOperatorTa MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
Tac Tracking area code

Meaning: Indicates the tracking area code (TAC), which is used by the EPC to determine the area within which paging messages are sent. One tracking area comprises one or more cells.

GUI Value Range: 1~65533,65535

Unit: None

Actual Value Range: 1~65533,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The combination of CnOperatorId and Tac in each CnOperatorTa MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
NbIotTaFlag NB-IoT TA Flag

Meaning: Indicates whether the current TAI applies only to NB-IoT. If this parameter is set to BOOLEAN_TRUE, the current TAI applies only to NB-IoT. If this parameter is set to BOOLEAN_FALSE, the current TAI does not apply to NB-IoT. In accordance with 3GPP specifications, NB-IoT does not support inter-RAT mobility. Therefore, the TAIs of NB-IoT must be different from those of LTE FDD and LTE TDD. For details, see section 5.3.3 in 3GPP TS 23.401 V13.7.0. This parameter applies only to NB-IoT.

GUI Value Range: BOOLEAN_FALSE(BOOLEAN_FALSE), BOOLEAN_TRUE(BOOLEAN_TRUE)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: BOOLEAN_FALSE(BOOLEAN_FALSE)

Recommended Value: BOOLEAN_FALSE(BOOLEAN_FALSE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To add a tracking area with the parameters as follows: Local tracking area ID: 0, Cn Operator ID: 0, Tracking area code: 33, NB-IoT TA Flag: BOOLEAN_TRUE, run the following command:
ADD CNOPERATORTA: TrackingAreaId=0, CnOperatorId=0, Tac=33, NbIotTaFlag=BOOLEAN_TRUE;
