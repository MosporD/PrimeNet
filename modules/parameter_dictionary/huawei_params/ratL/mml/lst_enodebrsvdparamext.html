List Extended Reserved eNodeB Parameter (LST ENODEBRSVDPARAMEXT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the extended reserved eNodeB-level parameters.

Note

None.

Parameters

None.

Example

List eNodeB Extended Reserved Parameter:
LST ENODEBRSVDPARAMEXT:;
