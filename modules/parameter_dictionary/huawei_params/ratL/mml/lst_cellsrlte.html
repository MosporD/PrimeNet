List Parameters Related to SR LTE-capable UE Scheduling Optimization (LST CELLSRLTE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query configurations about scheduling optimization on single radio LTE-capable UEs in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of SRLTE optimization:
LST CELLSRLTE:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

SRLTE Switch

Indicates whether to enable scheduling optimization on single radio LTE-capable UEs. A single radio LTE-capable UE periodically leaves the LTE system and listens to the paging channel of another RAT during camping or activation, and then returned to the LTE system after listening. If the eNodeB schedules the single radio LTE-capable UE when the UE is absent from the LTE system and listens to the paging channel of another RAT, RB resources are wasted. Based on scheduling optimization on single radio LTE-capable UEs, the eNodeB uses DTX detection to distinguish single radio LTE-capable UEs that leaves the LTE system and listens to the paging channel of another RAT, and then stops scheduling these UEs.

If this parameter is set to ON, scheduling optimization on single radio LTE-capable UEs is enabled.

If this parameter is set to OFF, scheduling optimization on single radio LTE-capable UEs is disabled.

This parameter applies only to LTE FDD and LTE TDD.

SRLTE DTX Threshold

Indicates the threshold of the consecutive number of times DTX from an SRLTE UE is detected in the cell.

If the consecutive number of times the eNodeB detects DTX from an SRLTE UE (including DTXs on the PUSCH and PDSCH) reaches the threshold, the eNodeB considers that the UE has switched from the LTE service state to the state of listening to paging from another RAT. This parameter applies only to LTE FDD.

SRLTE Suspend Time(ms)

Indicates the period of time during which the eNodeB does not schedule a single radio LTE-capable UE because the UE is absent from the LTE mode. This parameter takes effect only when the SrlteSwitch parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.

SRLTE Discard Algorithm Switch

Indicates whether to enable the discarding of PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. When this parameter is set to ON, an eNodeB discards PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. When this parameter is set to OFF, an eNodeB retains PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. This parameter applies only to LTE FDD.
