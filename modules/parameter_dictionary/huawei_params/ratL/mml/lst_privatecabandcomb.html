List Private Carrier Aggregation Combination (LST PRIVATECABANDCOMB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of private CA band combinations for an eNodeB.

Note

None.

Parameters

ID Name Description
PrivateCaCombId Private CA Band Combination ID

Meaning: Indicates the ID of the private CA band combination. It uniquely identifies a private CA band combination in an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List  Private Carrier Aggregation Combination:
LST PRIVATECABANDCOMB:;
The result is shown as follows:

Output Description

Field Description

Private CA Band Combination ID

Indicates the ID of the private CA band combination. It uniquely identifies a private CA band combination in an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Maximum Aggregated Bandwidth(MHz)

Indicates the maximum aggregated bandwidth supported by the CA band combination. This parameter applies only to LTE FDD and LTE TDD.

Bandwidth Combination Set ID

Indicates the protocol-defined ID of a CA bandwidth combination set. As defined in 3GPP TS 36.101, an operating frequency band supports different bandwidth combinations, which are identified by using different set IDs. For details, see section 5.6A.1 in 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 1 Band Identity

Indicates combination band 1. For details, see 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 1 Bandwidth

Indicates the bandwidth set supported in the first band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the first band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 2 Band Identity

Indicates combination band 2. For details, see 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 2 Bandwidth

Indicates the bandwidth set supported in the second band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the second band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 3 Band Identity

Indicates combination band 3. For details, see 3GPP TS 36.101. If the value is 0, combination band 3 is invalid. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 3 Bandwidth

Indicates the bandwidth set supported in the third band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the third band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 4 Band Identity

Indicates combination band 4. For details, see 3GPP TS 36.101. If the value is 0, combination band 4 is invalid. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 4 Bandwidth

Indicates the bandwidth set supported in the fourth band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the fourth band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 5 Band Identity

Indicates combination band 5. For details, see 3GPP TS 36.101. If the value is 0, combination band 5 is invalid. This parameter applies only to LTE FDD and LTE TDD.

Combination Band 5 Bandwidth

Indicates the bandwidth set supported in the fifth band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the fifth band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.
