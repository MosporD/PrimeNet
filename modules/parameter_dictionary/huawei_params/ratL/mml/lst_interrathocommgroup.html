List Common Parameter Group for Inter-RAT Handover (LST INTERRATHOCOMMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list one or all groups of common parameters related to inter-RAT handover.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoCommGroupId InterRAT handover common group ID

Meaning: Indicates the ID of the common parameter group related to inter-RAT handover. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

InterRAT handover common group ID

Indicates the ID of the common parameter group related to inter-RAT handover. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A1A2 hysteresis(0.5dB)

Indicates the hysteresis of events A1/A2 for triggering inter-RAT measurement. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A1A2 time to trigger(ms)

Indicates the time-to-trigger of A1 or A2 for triggering inter-RAT measurement.

When detecting that the signal quality in the serving cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition during the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting, the average number of handovers, and the number of wrong handovers. In summary, it helps prevent unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A1 RSRP trigger threshold(dBm)

Indicates the RSRP threshold for event A1 related to inter-RAT handovers except handovers to NG-RAN.

When the measured RSRP value of the serving cell exceeds this threshold, an event A1 report will be sent. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A1 RSRQ trigger threshold(0.5dB)

Indicates the RSRQ threshold for inter-RAT measurement event A1.

When the measured RSRQ value of the serving cell exceeds this threshold, an event A1 report will be sent. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A2 RSRP trigger threshold(dBm)

Indicates the RSRP threshold for event A2 related to inter-RAT handovers except handovers to NG-RAN.

When the measured RSRP value of the serving cell is below this threshold, an event A2 report will be sent. This parameter applies only to LTE FDD and LTE TDD.

InterRAT A2 RSRQ trigger threshold(0.5dB)

Indicates the RSRQ threshold for inter-RAT measurement event A2.

When the measured RSRQ value of the serving cell is below this threshold, an event A2 report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GERAN B2 RSRP Threshold 1(dBm)

Indicates the RSRP threshold 1 in the serving cell of event B2 for triggering E-UTRAN-to-GERAN handovers.

When the measured RSRP in the serving cell is smaller than the value of this parameter and the signal quality of the neighboring cell is better than the value of InterRatHoGeranB1Thd, the UE reports event B2. This parameter applies only to LTE FDD and LTE TDD.

GERAN B2 RSRQ Threshold 1(0.5dB)

Indicates the RSRQ threshold 1 in the serving cell of event B2 for triggering E-UTRAN-to-GERAN handovers.

When the measured RSRQ in the serving cell is smaller than the value of this parameter and the signal quality of the neighboring cell is better than the value of InterRatHoGeranB1Thd, the UE reports event B2. This parameter applies only to LTE FDD and LTE TDD.

UTRAN B2 RSRP Threshold 1(dBm)

Indicates the RSRP threshold 1 in the serving cell of event B2 for triggering E-UTRAN-to-UTRAN handovers.

When the measured RSRP in the serving cell is smaller than the value of this parameter and the signal quality of the neighboring cell is better than the value of InterRatHoUtranB1ThdRscp or InterRatHoUtranB1ThdEcn0, the UE reports event B2. This parameter applies only to LTE FDD and LTE TDD.

UTRAN B2 RSRQ Threshold 1(0.5dB)

Indicates the RSRQ threshold 1 in the serving cell of event B2 for triggering E-UTRAN-to-UTRAN handovers.

When the measured RSRQ in the serving cell is smaller than the value of this parameter and the signal quality of the neighboring cell is better than the value of InterRatHoUtranB1ThdRscp or InterRatHoUtranB1ThdEcn0, the UE reports event B2. This parameter applies only to LTE FDD and LTE TDD.

Del Inter-Freq Meas A2 Thld RSRP Offset(dB)

Indicates the offset of the RSRP threshold for event A2 to delete inter-frequency measurements relative to the actual RSRP threshold for GERAN event A2. RSRP threshold for event A2 to delete inter-frequency measurements = InterRatHoA2ThdRsrp + GeranA2ThdRsrpOffset (excluding -100) + DelIfMeasA2ThdRsrpOffset.

Del Inter-Freq Meas A2 Thld RSRQ Offset(0.5dB)

Indicates the offset of the RSRQ threshold for event A2 to delete inter-frequency measurements relative to the actual RSRQ threshold for GERAN event A2. RSRQ threshold for event A2 to delete inter-frequency measurements = InterRatHoA2ThdRsrq + DelIfMeasA2ThdRsrqOffset.

A2-based Inter-RAT Handover Trigger Quantity

Indicates the QCI-specific quantity to determine whether to trigger inter-RAT measurements or blind handovers based on inter-RAT event A2. If this parameter is set to BOTH, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on either RSRP or RSRQ. If this parameter is set to RSRP, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on RSRP. If this parameter is set to RSRQ, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on RSRQ. This parameter is valid only if the InterRatHoA1A2TrigQuan parameter is set to BOTH in the InterRatHoComm MO. This parameter applies only to LTE FDD and LTE TDD.

NR B2 RSRP Threshold 1(dBm)

Indicates the RSRP threshold 1 of the serving cell for event B2 related to inter-RAT handovers to NG-RAN. When the measured RSRP value of the serving cell is less than this threshold and the signal quality of the neighboring cell is greater than the threshold specified by the InterRatHoNrParamGrp.CovBasedNrB1RsrpThld parameter, event B2 will be reported. This parameter applies only to LTE FDD and LTE TDD.

Inter-RAT Handover to NR A1 RSRP Thld(dBm)

Indicates the RSRP threshold for event A1 related to handovers to NG-RAN.

When the measured RSRP value of the serving cell exceeds this threshold, event A1 will be reported. This parameter applies only to LTE FDD and LTE TDD.

Inter-RAT Handover to NR A2 RSRP Thld(dBm)

Indicates the RSRP threshold for event A2 related to handovers to NG-RAN.

When the measured RSRP value of the serving cell is less than this threshold, event A2 will be reported. This parameter applies only to LTE FDD and LTE TDD.
