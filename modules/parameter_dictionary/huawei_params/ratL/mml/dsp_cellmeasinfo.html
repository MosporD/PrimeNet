Display interference information (DSP CELLMEASINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

This command applies only to LTE TDD cells. This command can be used to query the signal strength from different directions in a massive MIMO cell and quickly locate strong signal sources, such as interference sources. If there are few UEs in a cell (for example, fewer than 50 UEs), the measurement result is meaningless because there are few or even no samples. For details about data analysis, contact Huawei technical support.

Note

None.

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
