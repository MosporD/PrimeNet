Add License Ratio Share Policy (ADD LICRATIOSHAREPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a license ratio share policy.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
TrfRatio TrfRatio

Meaning: Indicates the proportion of traffic used by the operator when the eNodeB is shared among operators. This parameter must be set based on the contract signed by operators. If this parameter is set to 0, services except emergency calls of this operator are not admitted.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of TrfRatio in all LicRatioSharePolicy MOs cannot exceed 100.
  • In the LicRatioSharePolicy MO, TrfSharingRatio cannot exceed TrfRatio.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
TrfSharingRatio TrfSharingRatio

Meaning: Indicates the proportion of traffic that the operator can share with other operators when the eNodeB is shared among operators.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • In the LicRatioSharePolicy MO, TrfSharingRatio cannot exceed TrfRatio.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates that more resources that can be shared. This increases the traffic license usage and the total traffic on the system. A smaller value of this parameter indicates that fewer resources can be shared. This decreases the traffic license usage and may lead to the condition that one PLMN has remaining resources while another PLMN has insufficient resources. As a result, the total traffic on the system decreases.

Applicable Mode: L

Example

To add a license ratio share policy with the parameters as follows: Cn Operator ID: 0, TrfRatio: 50, run the following command:
ADD LICRATIOSHAREPOLICY: CnOperatorId=0, TrfRatio=50;
