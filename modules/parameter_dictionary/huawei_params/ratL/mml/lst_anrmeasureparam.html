List eNodeB ANR Measurement Parameter (LST ANRMEASUREPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations related to ANR measurements. This command applies only to LTE TDD.

Note

None.

Parameters

None.

Example

List The eNodeb Anr Measure Parameter:
LST ANRMEASUREPARAM:;
The result is shown as follows:
+++    0        2019-12-05 08:56:05
O&M    #806355185
%%LST ANRMEASUREPARAM:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Intrafreq Measure Time to Trigger for ANR(ms)

Indicates the time-to-trigger for the ANR-based intra-frequency measurement event A3.

When a UE detects that the signal quality in the serving cell and that in at least one intra-frequency neighboring cell meets the entering condition, it does not immediately send an ANR-based measurement report to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports and invalid decisions on triggering intra-frequency ANR. This parameter must be set to a value less than or equal to the time-to-trigger for the intra-frequency handover event. This parameter applies only to LTE TDD.

Intrafreq Hysteresis for ANR(0.5dB)

Indicates the hysteresis for the ANR-based intra-frequency measurement event. This parameter is used to decrease the number of invalid decisions on triggering intra-frequency ANR due to radio signal fluctuations. This parameter must be set to a value less than or equal to the hysteresis for intra-frequency handovers. This parameter applies only to LTE TDD.

Intrafreq Measure Offset for ANR(0.5dB)

Indicates the offset for the signal quality in a neighboring cell relative to that in the serving cell in the ANR-based intra-frequency measurement. A large value indicates that a neighboring cell must have a noticeably better quality than the serving cell before ANR measurement reports can be sent. This parameter must be set to a value less than or equal to the offset for intra-frequency handovers. This parameter applies only to LTE TDD.

Interfreq Measure Time to Trigger for ANR(ms)

Indicates the time-to-trigger for the ANR-based inter-frequency measurement event.

When a UE detects that the signal quality in the serving cell and that in at least one inter-frequency neighboring cell meets the entering condition, it does not immediately send an ANR-based measurement report to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting and the number of invalid decisions on triggering inter-frequency ANR. This parameter must be set to a value less than or equal to the time-to-trigger for the inter-frequency handover event. This parameter applies only to LTE TDD.

Interfreq Hysteresis for ANR(0.5dB)

Indicates the hysteresis for the ANR-based inter-frequency measurement event. This parameter is used to decrease the number of invalid decisions on triggering inter-frequency ANR due to radio signal fluctuations. This parameter must be set to a value smaller less than or equal to the InterFreqHoA4Hyst parameter. This parameter applies only to LTE TDD.

Interfreq RSRP Threshold for ANR(dBm)

Indicates the RSRP threshold for triggering the ANR-based inter-frequency measurement event. When the measured RSRP value exceeds this threshold, an ANR-based inter-frequency measurement report is sent. This parameter must be set to a value less than or equal to the RSRP threshold for coverage-based inter-frequency handovers. This parameter applies only to LTE TDD.
