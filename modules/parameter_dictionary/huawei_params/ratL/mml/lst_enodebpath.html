List eNodeB IP Path Application Type (LST ENODEBPATH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the application type of an IP path.

Note

None.

Parameters

ID Name Description
IpPathId IP Path ID

Meaning: Indicates the ID of an IP path.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the application type of an IP path, run the following command: 
LST ENODEBPATH:;
The result is shown as follows:
+++    HUAWEI        2012-10-10 11:20:36
O&M    #131
%%LST ENODEBPATH:;%%
RETCODE = 0  Operation succeeded.

List eNodeB Path
----------------
      IP Path ID  =  0
Application Type  =  X2
 S1 Interface ID  =  NULL
 X2 Interface ID  =  16
(Number of results = 1)


---    END

Output Description

Field Description

IP Path ID

Indicates the ID of an IP path.

Application Type

Indicates the application type of an IP path.

S1 Interface ID

Indicates the S1 interface ID of an IP path. This parameter is not used in this version, and you are advised to set this parameter to 0.

X2 Interface ID

Indicates the X2 interface ID of an IP path.
