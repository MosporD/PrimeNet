Modify NSA DC Algorithm Parameter (MOD NSADCALGOPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify NSA DC algorithm configurations.

Note

None.

Parameters

ID Name Description
DlDataSplitSnOffset DL Data Split SN Offset

Meaning: Indicates the SN offset used when the eNodeB distributes PDCP packets to LTE or NR, whichever provides a lower data rate for UEs, during downlink dynamic data split. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: ms

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a smaller SN offset used by the eNodeB for PDCP packet distribution to the RAT with the lower data rate and leads to higher throughput of the RAT with the lower data rate. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
StopSplitTimeToTrigger Stop Split Time-to-Trigger

Meaning: Indicates the time-to-trigger for stopping data split in downlink dynamic data split. Data split is stopped when the ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate is continuously higher than the value of the NsaDcAlgoParam.StopSplitRateRatioThld parameter within the time-to-trigger. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~200

Unit: 10ms

Actual Value Range: 10~2000

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to sooner data split suspension. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
DlDataSplitPenaltyPeriod DL Data Split Penalty Period

Meaning: Indicates the penalty period for downlink dynamic data split. Dynamic data split is not allowed within the penalty period and is started after the penalty period ends. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a shorter period between data split suspension and the attempt to resume data split. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
StopSplitRateRatioThld Stop Split Rate Ratio Threshold

Meaning: Indicates the threshold for stopping data split in downlink dynamic data split. This threshold is a ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate. Downlink dynamic data split is stopped when the ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate exceeds this threshold for a time-to-trigger specified by the NsaDcAlgoParam.StopSplitTimeToTrig parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, data split is stopped even when the difference between the higher data rate and the lower data rate is small. If this parameter is set to a large value, data split is stopped only when the difference is large.

Applicable Mode: L-FDD, L-TDD
X2TransMaxRate X2 Transmission Max Rate

Meaning: Indicates the maximum PDCP packet transmission rate over the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: 100 Mbps

Actual Value Range: 100~10000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower transmission rate over the X2 interface. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
AbnDlDataSplitPenaltyPrd Abnormal DL Data Split Penalty Period

Meaning: Indicates the penalty period for exceptions in downlink dynamic data split. Dynamic data split is not allowed within the penalty period and is restarted after the penalty period ends. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a shorter period between data split suspension following an exception in data split and the attempt to resume data split. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
HoNsaBandCombSelectPolicy HO NSA Band Combination Selection Policy

Meaning: Indicates the band combination selection policy for handovers with SCG addition. If this parameter is set to LTE_SCC_NR_SCG_FIRST, the eNodeB preferentially delivers the LTE SCC and NR SCG band combination in a handover command message. The eNodeB selects proper LTE SCC bands based on the NR SCG sent from the gNodeB and delivers the band combination of both the LTE SCCs and NR SCG in the handover command message. If this parameter is set to NR_SCG_FIRST, the eNodeB preferentially delivers the NR SCG band combination in the handover command message. When the LTE SCC bands configured by the eNodeB and the NR SCG band combination sent from the gNodeB do not match the UE capability, the eNodeB preferentially assures the configuration of the NR SCG and delivers the band combination of the NR SCG but not the LTE SCCs in the handover command message. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: LTE_SCC_NR_SCG_FIRST(LTE_SCC_NR_SCG_FIRST), NR_SCG_FIRST(NR_SCG_FIRST)

Unit: None

Actual Value Range: LTE_SCC_NR_SCG_FIRST, NR_SCG_FIRST

MML Default Value: None

Recommended Value: LTE_SCC_NR_SCG_FIRST(LTE_SCC_NR_SCG_FIRST)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: During a handover, assume that the NR SCG band combination sent from the gNodeB and the LTE SCC bands configured on the eNodeB do not match the UE capability. If this parameter is set to LTE_SCC_NR_SCG_FIRST, the eNodeB preferentially delivers the LTE SCC and NR SCG band combination in the handover command message, accelerating SCC addition. If this parameter is set to NR_SCG_FIRST, the eNodeB preferentially delivers the NR SCG band combination. The LTE SCC addition can be triggered based on the traffic volume after the handover procedure completes, prolonging the duration of SCG addition.

Applicable Mode: L-FDD, L-TDD
NsaDcAlgoSwitch NSA DC Algorithm Switch

Meaning: Indicates whether to enable the base-station-level LTE-NR NSA DC algorithms.

OVERHEATING_RPOTECTION_SW: Indicates whether the eNodeB preferentially releases SCGs for UEs that have reported overheating information and preferentially adds SCGs for these UEs after overheating ends. If this option is selected, the eNodeB preferentially releases and adds SCGs for UEs that have reported overheating information. If this option is deselected, the eNodeB does not preferentially release or add SCGs for these UEs. This option applies only to LTE FDD and LTE TDD.

PCC_ANCHORING_SMART_DEPLOY_SW: Indicates whether to enable smart deployment of NSA DC PCC anchoring. If this option is selected, the eNodeB automatically identifies whether NSA is deployed in the area where the eNodeB is located. If it is identified that NSA is deployed and the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter is selected, then NSA DC PCC anchoring or NSA DC PCC anchoring for UEs in idle mode is enabled. If it is identified that NSA is not deployed, neither NSA DC PCC anchoring nor NSA DC PCC anchoring for UEs in idle mode is enabled. If this option is deselected, the eNodeB determines whether to enable NSA DC PCC anchoring or NSA DC PCC anchoring for UEs in idle mode based on the setting of the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter, respectively. This option applies only to LTE FDD and LTE TDD.

GAP_OFS_ASSIGNMENT_OPT_SW: Assume that a UE needs to perform gap-assisted measurements of NR frequencies. If this option is selected, the probability of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX decreases. However, the DRX On Duration may be extended. If this option is deselected, the UE may not be able to perform measurements of NR frequencies because of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX. This option applies only to LTE FDD and LTE TDD.

PLMN_BASED_LTE_NR_X2_SEL_SW: Indicates whether the eNodeB selects an LTE-NR X2 interface for an NSA UE based on the PLMN information on both the LTE and NR sides in RAN sharing with dedicated carrier scenarios. If this option is selected, the eNodeB selects an LTE-NR X2 interface for an NSA UE based on the PLMN information on both the LTE and NR sides. If no X2 interface is matched, an LTE-NR X2 self-setup procedure is triggered. If this option is deselected, the eNodeB selects an LTE-NR X2 interface for an NSA UE based on only the PLMN information on the NR side. This option applies only to LTE FDD and LTE TDD.

SRS_CARR_SWITCH_CAPB_QUERY_SW: Indicates whether to enable SRS carrier switching capability query. If this option is selected, the IE "srs-SwitchingTimeRequest" is contained in the UECapabilityEnquiry message to query whether the UE supports this capability. If this option is deselected, the IE is not contained in the message and the eNodeB does not query whether the UE supports the capability. This option applies only to LTE FDD and LTE TDD.

BAND_COMB_SORT_STRATEGY_SW: Indicates the sorting policy of NSA frequency band combinations. If this option is selected, there are the following situations: If the "downlinkSetEUTRA" field corresponding to a frequency band is set to 0, this frequency band is regarded as NSA-capable during sorting and two-layer MIMO is adopted by default. If the "downlinkSetEUTRA" field corresponding to the frequency band is not set to 0 but the number of the "FeatureSetDownlinkPerCC-Id" fields is inconsistent with the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band, this frequency band is regarded as NSA-capable during sorting and the number of consecutive CCs supported by this frequency band is equal to the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band. If this option is deselected, there are the following situations: If the "downlinkSetEUTRA" field corresponding to a frequency band is set to 0, this frequency band is not regarded as NSA-capable during sorting. If the "downlinkSetEUTRA" field corresponding to the frequency band is not set to 0 but the number of the "FeatureSetDownlinkPerCC-Id" fields is inconsistent with the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band, this frequency band is regarded as NSA-capable during sorting and the number of consecutive CCs supported by this frequency band is equal to the number of the "FeatureSetDownlinkPerCC-Id" fields. For details about the IEs, see 3GPP TS 38.331. This option applies only to LTE FDD and LTE TDD.

LAA_MEAS_GAP_PRI_SW: Indicates whether to prioritize the LAA frequencies and NR frequencies to be measured for NSA UEs. If this option is selected, NR frequencies are preferentially selected for gap-assisted measurements, decreasing the priorities for LAA frequencies. If this option is deselected, LAA frequencies are preferentially selected for gap-assisted measurements, increasing the priorities for LAA frequencies. This option applies only to LTE FDD and LTE TDD.

NSA_MEAS_RPT_CHECK_CANCEL_SW: Indicates whether the eNodeB cancels the check on received NSA-related B1 measurement reports. If this option is selected, the eNodeB does not check B1 measurement reports. If this option is deselected, the eNodeB checks B1 measurement reports. If the measured value indicated in a measurement report is less than the B1 measurement threshold configured on the eNodeB, the eNodeB discards the measurement report.

SCC_RMV_AFT_SCG_ADD_OPT_SW: Indicates whether to optimize SCell removal during CA band combination rollback after an SCG is added for an NSA UE. If this option is selected and the configured CA band combination is not supported after an SCG is added for an NSA UE, the base station removes SCells based on the optimal CA band combination in the supported EN-DC band combination. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

MFBI_COMPATIBILITY_HO_SW: Indicates whether the eNodeB applies a compatibility handover solution to UEs that access an MFBI cell. Assume that a UE accesses a band in an MFBI cell but the band does not support the NSA band combination. If this option is selected, the eNodeB initiates an intra-cell handover to transfer the UE to another band that supports the NSA band combination and adds an NR SCG for the UE after the NR SCG addition conditions are met. If this option is deselected, the eNodeB does not add an NR SCG for the UE. This option applies only to LTE FDD and LTE TDD.

DisuseStatement: PLMN_BASED_LTE_NR_X2_SEL_SW: This option will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this option, the system does not use this option. Therefore, avoid using this option.

GUI Value Range: OVERHEATING_RPOTECTION_SW(OVERHEATING_RPOTECTION_SW), PCC_ANCHORING_SMART_DEPLOY_SW(PCC_ANCHORING_SMART_DEPLOY_SW), GAP_OFS_ASSIGNMENT_OPT_SW(GAP_OFS_ASSIGNMENT_OPT_SW), PLMN_BASED_LTE_NR_X2_SEL_SW(PLMN_BASED_LTE_NR_X2_SEL_SW), SRS_CARR_SWITCH_CAPB_QUERY_SW(SRS_CARR_SWITCH_CAPB_QUERY_SW), BAND_COMB_SORT_STRATEGY_SW(BAND_COMB_SORT_STRATEGY_SW), LAA_MEAS_GAP_PRI_SW(LAA_MEAS_GAP_PRI_SW), NSA_MEAS_RPT_CHECK_CANCEL_SW(NSA_MEAS_RPT_CHECK_CANCEL_SW), SCC_RMV_AFT_SCG_ADD_OPT_SW(SCC_RMV_AFT_SCG_ADD_OPT_SW), MFBI_COMPATIBILITY_HO_SW(MFBI_COMPATIBILITY_HO_SW)

Unit: None

Actual Value Range: OVERHEATING_RPOTECTION_SW, PCC_ANCHORING_SMART_DEPLOY_SW, GAP_OFS_ASSIGNMENT_OPT_SW, PLMN_BASED_LTE_NR_X2_SEL_SW, SRS_CARR_SWITCH_CAPB_QUERY_SW, BAND_COMB_SORT_STRATEGY_SW, LAA_MEAS_GAP_PRI_SW, NSA_MEAS_RPT_CHECK_CANCEL_SW, SCC_RMV_AFT_SCG_ADD_OPT_SW, MFBI_COMPATIBILITY_HO_SW

MML Default Value: None

Recommended Value: OVERHEATING_RPOTECTION_SW:Off

PCC_ANCHORING_SMART_DEPLOY_SW: Off

GAP_OFS_ASSIGNMENT_OPT_SW: Off

PLMN_BASED_LTE_NR_X2_SEL_SW: Off

SRS_CARR_SWITCH_CAPB_QUERY_SW: Off

BAND_COMB_SORT_STRATEGY_SW: Off

LAA_MEAS_GAP_PRI_SW: Off

NSA_MEAS_RPT_CHECK_CANCEL_SW: Off

SCC_RMV_AFT_SCG_ADD_OPT_SW:Off

MFBI_COMPATIBILITY_HO_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: OVERHEATING_RPOTECTION_SW: If this option is selected in NSA DC scenarios, the throughput of UEs supporting overheating assistance decreases after these UEs report overheating information. If this option is deselected, network performance is not affected.

PCC_ANCHORING_SMART_DEPLOY_SW: If this option is selected, the eNodeB automatically identifies whether NSA is deployed in the area where the eNodeB is located. In areas where NSA is not deployed and the NSA_PCC_ANCHORING_SWITCH option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter is selected, the number of inter-frequency and inter-RAT measurements decreases. In areas where NSA is not deployed and the IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter is selected, the number of inter-frequency handovers decreases. If this option is deselected, network performance is not affected.

GAP_OFS_ASSIGNMENT_OPT_SW: If this option is selected, the probability of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX decreases. However, the DRX On Duration may be extended. If this option is deselected, UEs may not be able to perform measurements of NR frequencies because of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX.

PLMN_BASED_LTE_NR_X2_SEL_SW: If this option is selected and the eNodeB works in RAN sharing with dedicated carrier, the eNodeB selects an LTE-NR X2 interface for an NSA UE based on the PLMN information on both the LTE and NR sides. If no X2 interface is matched, an LTE-NR X2 self-setup procedure is triggered. In this case, if the gNodeB is shared by multiple operators, the LTE-NR X2 interface overhead increases. If this option is deselected, network performance is not affected.

SRS_CARR_SWITCH_CAPB_QUERY_SW: Network performance is not affected.

BAND_COMB_SORT_STRATEGY_SW: If this option is selected, the gNodeB may select a non-optimal NSA frequency band combination, decreasing UE throughput. If this option is deselected, the gNodeB can select a more suitable NSA frequency band combination, increasing UE throughput.

LAA_MEAS_GAP_PRI_SW: If this option is selected, NR frequencies are preferentially measured, and LAA frequencies can be measured only after NR frequency measurement is complete. In this case, LAA SCell addition is delayed, and LTE throughput decreases.

NSA_MEAS_RPT_CHECK_CANCEL_SW: If this option is selected, the eNodeB does not check measurement reports. As a result, the number of received measurement reports from UEs increases, and the number of NSA UEs may increase. If the measurement report sent by a UE is incorrect, the radio connection on the 5G side may be unstable after an SCG is added. If this option is deselected, the eNodeB checks measurement reports from UEs. If the measured value indicated in a measurement report is incorrectly filled, a valid measurement report may be discarded. The number of NSA UEs may decrease.

SCC_RMV_AFT_SCG_ADD_OPT_SW: If this option is selected, the optimal CA band combination configuration can be selected during SCG addition, improving NSA DC user experience. If this option is deselected, the base station does not consider the optimal CA band combination configuration when adding an SCG. As a result, the total bandwidth after the SCG is added may be less than that of the original CA band combination before the SCG is added, affecting user experience of NSA DC UEs.

MFBI_COMPATIBILITY_HO_SW: If this option is selected, a handover may be triggered when the band that the UE accesses in the MFBI cell does not support the NSA band combination, and then an NR SCG can be added for the UE. If this option is deselected, an NR SCG cannot be added for the UE when the band that the UE accesses in the MFBI cell does not support the NSA band combination.

Applicable Mode: L-FDD, L-TDD

Example

To modify the NSA DC algorithm configurations with the parameters as follows: Stop Split Rate Ratio Threshold: 10,  run the following command:
MOD NSADCALGOPARAM: StopSplitRateRatioThld=10;
