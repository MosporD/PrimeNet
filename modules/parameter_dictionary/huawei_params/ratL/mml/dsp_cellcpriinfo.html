Display Cell CPRI Information (DSP CELLCPRIINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the CPRI information of a cell.

Note

In separate-MPT CPRI MUX scenarios, this command cannot be used to query cell CPRI information of the converged party.

This command is not applicable when an RMU is used. In cascading scenarios, this command is applicable only if the cascaded CPRI ports operate at an identical rate.

This command is applicable only to macro cells but not to any logical cell consisting of both macro and micro cells.

This command is not applicable if the eCPRI or IR protocol is used.

This command is not applicable to cells served by LMPT.

If multiple cells are served by a CPRI link, the total bandwidth required by the CPRI link is equal to the value of "Total Occupied Cell CPRI Link Bandwidth" queried for the local cell plus the sum of the values of "CPRI Bandwidth to be Allocated for the Cell" queried for all cells served by this CPRI link. If the total bandwidth required by the CPRI link is greater than the rate of the optical module for the CPRI link, replace the optical module with another optical module of a higher rate. If the total bandwidth required by the CPRI link is less than or equal to the rate of the optical module for the CPRI link, the optical module meets the CPRI specification requirements of the cells served by the CPRI link, the cells can be activated, and CPRI bandwidth can be automatically allocated to the cells by the system.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Output Description

Field Description

eNodeB ID

Indicates the ID of the eNodeB.

Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB.

Upper Level Optical Module Information

Indicates the cabinet No., subrack No., slot No., and port No. of the upper-level optical module of the RF unit serving the cell.

Upper Level Optical Module Maximum Code Rate(Mbit/s)

Indicates the maximum rate supported by the upper-level optical module of the RF unit serving the cell.

Lower Level Optical Module Information

Indicates the cabinet No., subrack No., slot No., and port No. of the lower-level optical module of the RF unit serving the cell.

Lower Level Optical Module Maximum Code Rate(Mbit/s)

Indicates the maximum rate supported by the lower-level optical module of the RF unit serving the cell.

CPRI Bandwidth to Be Allocated for the Cell(Mbit/s)

Indicates the CPRI bandwidth to be automatically allocated to the cell on the current CPRI link, including the bandwidth required for both payload and overhead transmissions. This parameter is valid when the cell capability is degraded or the cell is not activated.

Total Occupied Cell CPRI Link Bandwidth(Mbit/s)

Indicates the total CPRI bandwidth occupied by all cells on the CPRI link serving the cell, including the bandwidth required for both payload and overhead transmissions.

CPRI Rate(Mbit/s)

Indicates the rate over the CPRI port on the RF unit serving the cell.
