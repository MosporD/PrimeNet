Modify Global Procedure Switch Setting (MOD GLOBALPROCSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to some global functions in the eNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If TargetOpBasedX2Switch is set to ON, run the ADD X2AUTOSETUPOPERATOR command to add an operator that the target eNodeB supporting X2 self-setup belongs to. Otherwise, the self-setup procedure fails.

  • After the X2SctpEstType parameter value is modified, run RST APP to reset the application referenced by the eNodeBFunction MO for the application to take effect. You can run LST ENODEBFUNCTION to view the application referenced by the eNodeBFunction MO. If the application referenced by the eNodeBFunction MO is not reset within 10 minutes, ALM-26245 Configuration Data Inconsistency will be reported.

  • If the value of DiffOpWithSameMmecSwitch is changed from ON(On) to OFF(Off), existing S1 interfaces are not affected but new or reestablished S1 interfaces will be affected.

  • The Prefer Signal Extend Switch parameter applies only to scenarios where a UMPT and an LMPT are installed in the same BBU, with the UMPT working as the main control board and the LMPT working as the extension transmission processing board.

  • When this parameter is set to ON, the function is disabled immediately. In this case, UEs served by the LMPT release the network. When this parameter is set to ON, the function cannot be enabled until the LMPT is reset. After the function is enabled, the LMPT is initialized and serves UEs that were served by the UMPT for load balance.

  • If the Rrc Conn Req Stat Switch is set to OFF(Off), there is low probability that cross-period measurement for the L.RRC.ConnReq.Msg counter is incorrect because a timer is used for periodical measurements for this counter.

    As a result, the L.RRC.ConnReq.Msg counter value is smaller than the L.RRC.ConnReq.Att counter value.

  • If the X2SonSecMode parameter is set to CP_UP, both the IPSECSWITCH parameter in the USERPLANEHOST MO and the SIGIP1SECSWITCH parameter in the SCTPHOST MO must be set to ENABLE. If the X2SonSecMode parameter is set to UP, the IPSECSWITCH parameter in the USERPLANEHOST MO must be set to ENABLE and the SIGIP1SECSWITCH parameter in the SCTPHOST MO must be set to DISABLE. Otherwise, link interruptions may occur after subsequent X2 interface self-updates.

If this parameter is set to a non-zero value, network-requested CA band combination reporting is triggered when the size of the IE "UE-EUTRA-Capability" in UE capability information is greater than the parameter value. If this parameter is set to 0, the threshold is invalid. In this case, network-requested CA band combination reporting is triggered when the number of CA band combinations in the UE capability information reaches 128. For details about the definition of the IE "UE-EUTRA-Capability", see 3GPP TS 36.331. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: 0,500~8000

Unit: None

Actual Value Range: 0,500~8000

MML Default Value: None

Recommended Value: 2000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller non-zero value of this parameter results in a higher probability that network-requested CA band combination reporting takes effect.
