Remove Neighboring GERAN ARFCN (RMV GERANNFREQGROUPARFCN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more records of neighboring ARFCNs of the GERAN BCCHs.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is a risky command and you are advised to run this command during off-peak hours.

    If no parameter is specified, all records of neighboring GERAN BCCH ARFCNs are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If some parameters are specified, records that match the parameter settings are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If all parameters are specified, the record that matches all the parameter settings is removed after the command is executed.

  • Before running this command, remove the neighboring relationship to the GERAN cell at the GERAN ARFCN.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Actual Value Range: 0~255

Applicable Mode: L-FDD, L-TDD
BcchGroupId BCCH group ID

Meaning: Indicates the index of the BCCH carrier frequency group. It identifies a BCCH carrier frequency group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Applicable Mode: L-FDD, L-TDD
GeranArfcn GERAN ARFCN

Meaning: Specifies the ARFCN of the GERAN BCCH. If the GERAN ARFCN value is not between 512 and 810, one ARFCN can only in one frequency band. For details about this parameter, see 3GPP TS 45.005. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

MML Default Value: None

Example

To remove the neighboring GERAN ARFCN with the parameters as follows: Local cell ID: 0, BCCH group ID: 0, GERAN ARFCN: 2, run the following command:
RMV GERANNFREQGROUPARFCN: LocalCellId=0, BcchGroupId=0, GeranArfcn=2;
