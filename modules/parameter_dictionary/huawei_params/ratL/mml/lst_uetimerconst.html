List UE Timer and Constant Configuration (LST UETIMERCONST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of UE timers and constants.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of UE timers and constants:
LST UETIMERCONST:;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Timer 300

Indicates the timer value of Timer 300. For details, see 3GPP TS 36.331.

This timer is started when the UE sends RRCConnectionRequest.

Before the timer expires, it is stopped if the UE receives RRCConnectionSetup or RRCConnectionReject.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.

Timer 301

Indicates the length of timer T301. For details, see 3GPP TS 36.331.

This timer is started when the UE sends an RRC Connection Reestablishment Request message.

This timer is stopped if the UE receives an RRC Connection Reestablishment or RRC Connection Reestablishment Reject message, or the selected cell becomes unsuitable. For details about a suitable cell, see 3GPP TS 36.331.

If the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.

Timer 310

Indicates the length of timer 310. For details, see 3GPP TS 36.331.

This timer is started when the UE detects any fault at the physical layer.

The timer is stopped if the UE detects one of the following before the timer expires: (1) The physical-layer fault is rectified; (2) A handover is triggered; (3) The UE initiates an RRC connection reestablishment procedure.

After the timer expires, the UE enters the RRC_IDLE mode if the security mode is not activated. If the security mode is activated, the UE initiates an RRC connection reestablishment procedure. This parameter applies only to LTE FDD and LTE TDD.

Timer 311

Indicates the length of timer 311. For details, see 3GPP TS 36.331.

This timer is started when the UE starts the RRC connection reestablishment procedure.

The timer is stopped if, before the timer expires, the UE selects an E-UTRAN or inter-RAT cell to camp on.

After the timer expires, the UE enters the RRC_IDLE mode. This parameter applies only to LTE FDD and LTE TDD.

Constant N311

Indicates the maximum number of successive "in sync" indications received from lower layers. For details, see 3GPP TS 36.331.

Constant N310

Indicates the maximum number of successive "out of sync" indications received from lower layers. For details, see 3GPP TS 36.331.

Timer 325

Indicates the length of timer 325. For details, see 3GPP TS 36.331. This timer starts when a UE receives an RRCConnectionReject message containing the deprioritisationReq IE. When the timer expires, the cell reselection priorities that have been reduced using RRCConnectionReject for E-UTRAN frequencies are restored. This parameter applies only to LTE FDD and LTE TDD.

Constant N313

Indicates the maximum number of consecutive "out-of-sync" indications received for a PSCell from lower layers. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Constant N314

Indicates the maximum number of consecutive "in-sync" indications received for a PSCell from lower layers. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Timer 307

Indicates the length of timer 307. For details, see 3GPP TS 36.331. An eNodeB starts this timer when the intended UE receives an RRC Connection Reconfiguration message containing the MobilityControlInfoSCG IE. The eNodeB stops this timer when the UE completes random access to a PSCell. If the timer expires, the UE sends an SCG Failure message to the eNodeB to inform the eNodeB of an SCG update failure. This parameter applies only to LTE FDD and LTE TDD.

Timer 313

Indicates the length of timer 313. For details, see 3GPP TS 36.331. This timer is started for a UE when the UE detects any fault at the physical layer of a PSCell. This timer is stopped when the UE detects that the fault is rectified, the UE initiates a connection reestablishment procedure, the UE receives an SCG Release message, or the UE receives an RRC Connection Reconfiguration message containing the MobilityControlInfoSCG IE. If the timer expires, the UE sends an SCG Failure message to the eNodeB to inform the eNodeB of an SCG radio link failure. This parameter applies only to LTE FDD and LTE TDD.

NB-IoT Timer 300

Indicates the timer value of Timer 300. For details, see 3GPP TS 36.331.

This timer is started when the UE sends RRCConnectionRequest.

Before the timer expires, it is stopped if the UE receives RRCConnectionSetup or RRCConnectionReject.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to NB-IoT.

NB-IoT Timer 310

Indicates the timer value of Timer 310. For details, see 3GPP TS 36.331.

This timer is started when the UE detects any fault at the physical layer. Before the timer expires, it is stopped if the UE detects that the physical-layer fault is rectified. After the timer expires, the UE enters the RRC_IDLE state.

This parameter applies only to NB-IoT.

NB-IoT Timer 301

Indicates the length of the timer T301 in NB-IoT scenarios. For details, see 3GPP TS 36.331.

This timer is started when the UE sends an RRC Connection Reestablishment Request message.

This timer is stopped if the UE receives an RRC Connection Reestablishment or RRC Connection Reestablishment Reject message, or the selected cell becomes unsuitable. For details about an unsuitable cell, see 3GPP TS 36.331.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to NB-IoT.

NB-IoT Timer 311

Indicates the timer value of Timer 311 for NB-IoT. For details, see 3GPP TS 36.331. This timer is started when the UE starts an RRC connection reestablishment. If the UE has selected an NB-IoT cell before the timer expires, the eNodeB stops the timer. After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to NB-IoT.

Timer 300 in CE Mode

Indicates the timer value of Timer 300 in coverage enhancement mode. If this parameter is set to a value indicating a timer length less than or equal to 2000 ms, the value of this parameter is broadcast only in the t300 IE of SIB2 and this value takes effect for UEs in all CE modes. If this parameter is set to a value indicating a timer length greater than 2000 ms, there are two consequences: (a) A fixed value of 2000 ms is broadcast in the t300 IE of SIB2 and this value takes effect for UEs that support only CE mode A. (b) The value of this parameter is broadcast in the t300-v1310 IE of SIB2 and this value takes effect only for UEs that support CE mode B. For details, see 3GPP TS 36.331.

This timer is started when the UE sends RRCConnectionRequest.

Before the timer expires, it is stopped if the UE receives RRCConnectionSetup or RRCConnectionReject.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.

Timer 301 in CE Mode

Indicates the length of timer 301 in coverage enhancement mode. If this parameter is set to a value indicating a timer length less than or equal to 2000 ms, the value of this parameter is broadcast only in the t301 IE of SIB2 and this value takes effect for UEs in all CE modes. If this parameter is set to a value indicating a timer length greater than 2000 ms, there are two consequences: (a) A fixed value of 2000 ms is broadcast in the t301 IE of SIB2 and this value takes effect for UEs that support only CE mode A. (b) The value of this parameter is broadcast in the t301-v1310 IE of SIB2 and this value takes effect only for UEs that support CE mode B. For details, see 3GPP TS 36.331.

This timer is started when the UE sends the RRC Connection Reestablishment Request message.

This timer is stopped if the UE receives an RRC Connection Reestablishment or RRC Connection Reestablishment Reject message before this timer expires.

If the timer expires, the UE enters the RRC_IDLE mode. This parameter applies only to LTE FDD and LTE TDD.

Timer 310 in CE Mode

Indicates the timer value of Timer 310 in cell coverage enhancement mode. If this parameter is set to a value indicating a timer length less than or equal to 2000 ms, the value of this parameter is broadcast only in the t310 IE of SIB2 and this value takes effect for UEs in all CE modes. If this parameter is set to a value indicating a timer length greater than 2000 ms, there are two consequences: (a) A fixed value of 2000 ms is broadcast in the t310 IE of SIB2 and this value takes effect for UEs that support only CE mode A. (b) The value of this parameter is broadcast in the t310-v1330 IE of SIB2 and this value takes effect only for UEs that support CE mode B. For details, see 3GPP TS 36.331.

This timer is started for a UE when the UE detects a fault at the physical layer.

The timer is stopped if the UE detects the physical layer recovery, triggers a handover procedure, or initiates a reestablishment.

After the timer expires, the UE enters idle mode if the security mode is not activated. Otherwise, the UE initiates a reestablishment.

Timer 311 in CE Mode

Indicates the length of timer 311 in coverage enhancement mode. For details, see 3GPP TS 36.331.

This timer is started when the UE starts the RRC connection reestablishment procedure.

The timer is stopped if the UE selects an E-UTRAN cell to camp on before the timer expires.

If the timer expires, the UE enters the RRC_IDLE mode.

NB-IoT Timer T322

Indicates the length of Timer 322. For details, see 3GPP TS 36.331. The UE starts this timer when it detects that the RRC Connection Release message includes the power offset for inter-frequency redirection. If the UE enters the RRC_CONNECTED state before this timer expires, the UE stops this timer. The power offset for inter-frequency redirection does not take effect after this timer expires. This parameter applies only to NB-IoT.

NB-IoT EDT Timer 300

Indicates the length of timer 300 for EDT services. For details, see 3GPP TS 36.331. This timer is started when a UE sends an RRCEarlyDataRequest or RRCConnectionResumeRequest message for an EDT service. If Msg4 is received before the timer expires, the timer is stopped. When the timer expires, the UE returns to the RRC_IDLE state and determines that EDT fails in the uplink. This parameter applies only to NB-IoT.
