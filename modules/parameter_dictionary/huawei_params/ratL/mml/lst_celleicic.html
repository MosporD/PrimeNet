List Enhanced Inter-cell Interference Coordination Information (LST CELLEICIC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of TDM-based eICIC.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of eICIC of a cell:
LST CELLEICIC:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Abs pattern

Indicates the ABS pattern when static TDM-based eICIC is enabled. This parameter is valid only if static TDM-based eICIC is enabled. Different ABS patterns indicate different ABS quantities and ABS numbers in the same period. An ABS pattern is a 40-bit bitmap. For details, see the definition of ABS Pattern Info of X2 signaling in 3GPP TS 36.423. All cells throughout the network must be configured with the same ABS pattern. This parameter is valid only if static TDM-based eICIC is enabled. This parameter applies only to LTE TDD.

Eicic Measure Enable

Indicates whether UEs are allowed to send measurement reports for event A3 during enhanced inter-cell interference coordination (eICIC). The parameter value ENABLE indicates that UEs are allowed to send measurement reports for event A3 during eICIC. The parameter value DISABLE indicates that UEs are not allowed to send measurement reports for event A3 during eICIC, and in this case the eNodeB cannot determine whether to enable eICIC in different scenarios. This parameter applies only to LTE FDD and LTE TDD.

eICIC A3 Offset(0.5dB)

Indicates the offset for event A3 during enhanced inter-cell interference coordination (eICIC). This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality for the reporting of event A3. A smaller value indicates that the requirement on the neighboring cell signal quality for reporting event A3 can be met easier. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Abs Adjustment Period(s)

Indicates the period of adjusting the ABS pattern of a macro cell in dynamic eICIC. This parameter must be configured based on the number of cells and the load of X2 interfaces. It is recommended that the ABS adjustment period (unit: s) be equal to the number of macro cells of the local eNodeB multiplied by the number of micro cells in the local macro cell. This parameter applies only to LTE FDD.

Sample Number Target

Indicates the minimum required number of samples for starting automatic configuration of macro-micro associations. A micro cell collects the sample statistics in a measurement period only when the number of sample macro-cell measurement reports received by the micro cell within the period exceeds or equals the value of this parameter. This parameter takes effect only in micro cells. This parameter applies only to LTE FDD and LTE TDD.

Attach Cell Add Threshold(%)

Indicates the threshold used to trigger automatic configuration of macro-micro associations. The macro-micro association is updated only if the percentage of the strongest macro cell exceeds or equals the threshold. This parameter takes effect only in micro cells. This parameter applies only to LTE FDD and LTE TDD.

Work Mode

Indicates the working mode for automatic configuration of macro-micro associations. If this parameter is set to AUTO, macro-micro associations are automatically configured with no need for manual confirmation. If this parameter is set to CONTROLLED, the strongest macro cell is reported to the MAE for manual confirmation each time before the associations can be configured. This parameter takes effect only in micro cells. This parameter applies only to LTE FDD and LTE TDD.

Statistical Period(min)

Indicates the measurement period for automatic configuration of macro-micro associations. The micro cell counts the number of times each macro cell is included in measurement reports within each period. To prevent network performance deterioration for UEs, the macro-micro associations are not updated immediately when a measurement period approaches its end. Instead, the update is triggered at the specified start time. This parameter takes effect only in micro cells. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

CRE Adjustment Period(min)

Indicates the period of CRE configuration adjustment by a macro cell based on statistics when Adaptive eICIC is enabled. This parameter applies only to FDD.

eICIC Config User Ratio Threshold(%)

Indicates the threshold of the penetration rate of eICIC UEs required for configuring a large CRE offset (6 dB or 9 dB) when eICIC adaptation is enabled. If the penetration rate of eICIC UEs is greater than or equal to this threshold, a large CRE offset can be configured. This parameter applies only to FDD.

eICIC UnConfig User Ratio Threshold(%)

Indicates the threshold of the penetration rate of eICIC UEs required for no longer using a large CRE offset (6 dB or 9 dB) when eICIC adaptation is enabled. If the penetration rate of eICIC UEs is less than this threshold, a large CRE offset cannot be configured. This parameter applies only to FDD.

Large CRE Micro Cell Number Threshold

Indicates the threshold of the number of micro cells homed to a macro cell. This parameter is used to determine whether to configure a large CRE offset (6 dB or 9 dB) when Adaptive eICIC is enabled. If the actual number is greater than or equal to this threshold, a large CRE offset can be set. Otherwise, a large CRE offset cannot be set. This parameter applies only to FDD.

eICIC Adaptive Switch

Indicates whether to allow automatic adjustment of a CRE offset based on statistics. If this switch is on, Adaptive eICIC is enabled. If this switch is off, Adaptive eICIC is disabled. This parameter takes effect only when dynamic eICIC or FeICIC is enabled. This parameter applies only to FDD.

Neighboring Cell Statistic Period for NAIC(min)

Indicates the period for collecting statistics on intra-frequency neighboring cells that cause interference to the local cell after network-assisted interference cancellation is enabled. Assistant information of eight neighboring cells causing the strongest interference is delivered to UEs after the period ends. This parameter applies only to LTE FDD and LTE TDD.

High-Speed ICS CCE Threshold(%)

Indicates the threshold of the equivalent CCE usage for enabling interference coordination for handover zones along high-speed railways. If the equivalent CCE usage exceeds this threshold, interference coordination is enabled for handover zones along high-speed railways. This parameter applies only to LTE TDD.

High-Speed ICS DTX Threshold(%)

Indicates the threshold of the DTX rate for enabling interference coordination for handover zones along high-speed railways. If the DTX rate exceeds this threshold, interference coordination is enabled for handover zones along high-speed railways. This parameter applies only to LTE TDD.

High-Speed Enhanced Optimization Switch

Indicates whether to enable network enhancement and optimization in high-speed railway scenarios. HighSpeedCoorSwitch: Indicates whether to enable interference coordination for UEs in handover zones along high-speed railways. If this option is selected, the eNodeB enables interference coordination for UEs in handover zones along high-speed railways. If this option is deselected, the eNodeB disables interference coordination for UEs in handover zones along high-speed railways. This option applies only to LTE TDD.

High-Speed Incoming Handover Threshold

Indicates the threshold of the number of incoming handovers for enabling interference coordination for handover zones along high-speed railways. If the number of incoming handovers performed in handover zones along high-speed railways is greater than or equal to this threshold, interference coordination is enabled for such handover zones. This parameter applies only to LTE TDD.
