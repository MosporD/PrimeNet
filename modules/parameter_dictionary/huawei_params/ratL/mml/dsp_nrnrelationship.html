Display Dynamic Information About NR Neighbor Relationships (DSP NRNRELATIONSHIP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query dynamic information about neighbor relationships with NR cells.

Note

This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a NrNRelationship MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the mobile network code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in a NrNRelationship MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GnodebId gNodeB ID

Meaning: Indicates the ID of the gNodeB serving the neighboring NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellId Cell ID

Meaning: Indicates the ID of a neighboring NR cell served by a gNodeB. It uniquely identifies an NR cell in the gNodeB. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16383

Unit: None

Actual Value Range: 0~16383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NCellPlmnLabel Neighbor Cell Plmn Label

Meaning: Indicates the PLMN label of the neighboring cell. The parameter value BLACK indicates that the PLMN of the neighboring cell is blacklisted. The parameter value GREY indicates that the PLMN of the neighboring cell is gray-listed. The parameter value WHITE indicates that the PLMN of the neighboring cell is white-listed. The parameter value ALL indicates that the PLMN of the neighboring cell is not distinguished.

GUI Value Range: BLACK(BLACK), GREY(GREY), WHITE(WHITE), ALL(ALL)

Unit: None

Actual Value Range: BLACK, GREY, WHITE, ALL

MML Default Value: WHITE(WHITE)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the dynamic information about the neighbor relationship with an NR cell, run the following command:
DSP NRNRELATIONSHIP:;
The result is shown as follows:
