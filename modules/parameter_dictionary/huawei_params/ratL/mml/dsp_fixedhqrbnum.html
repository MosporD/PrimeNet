Display Fixed High Quality RB Number (DSP FIXEDHQRBNUM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the number of fixed high-quality RBs when the GSM and LTE spectrum concurrency is enabled. For an SFN or adaptive SFN cell, the query result is the number of fixed high-quality RBs shared by all the physical cells that constitute the SFN or adaptive SFN cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of an E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To display the fixed high quality RB number of GL spectrum concurrency with the local cell ID of 1, run the following command:
DSP FIXEDHQRBNUM: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:46:48
O&M    #806355076
%%DSP FIXEDHQRBNUM: LocalCellId=1;%%

Display Fixed High Quality RB Number
------------------------------------
                       Local Cell ID  =  1
Downlink Fixed High Quality RB Count  =  25
  Uplink Fixed High Quality RB Count  =  25
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of an E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.

Downlink Fixed High Quality RB Count

Indicates the number of downlink fixed high-quality RBs for LTE when GSM and LTE Spectrum Concurrency (LTE FDD) is enabled. This parameter applies only to LTE FDD.

Uplink Fixed High Quality RB Count

Indicates the number of uplink fixed high-quality RBs for LTE when GSM and LTE Spectrum Concurrency (LTE FDD) is enabled. This parameter applies only to LTE FDD.
