Display Carrier Aggregation Management Configuration (DSP SMARTCACOMBINATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about the serving cell combination that a cell belongs.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

+++    0        2017-11-17 14:55:06
O&M    #806354963
%%DSP SMARTCACOMBINATION: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Serial Number

Indicates the optimal sorting order of a serving cell (PCell and SCell) combination in intelligent selection of serving cell combinations for CA UEs. This parameter applies only to LTE FDD and LTE TDD.

PCell eNodeB ID

Indicates the eNodeB ID of the PCell. This parameter applies only to LTE FDD and LTE TDD.

PCell Cell ID

Indicates the cell ID of the PCell. This parameter applies only to LTE FDD and LTE TDD.

PCell Downlink EARFCN

Indicates the downlink EARFCN of the PCell. This parameter applies only to LTE FDD and LTE TDD.

PCell Cell Capability

Indicates the cell capability of the PCell in scientific notation. If the cell capability is 7246, this parameter value is displayed as 7246e0. It takes time to update the cell capability when parameter settings or variables related to the cell capability change. In this case, the queried serving cell combination sequence cannot completely match the real-time sequence. This parameter applies only to LTE FDD and LTE TDD.

PCell DL Avg To-Be-Scheduled UE Num

Indicates the average number of UEs to be scheduled in the downlink in the PCell. If the MinDlAvgToBeScheduledUeNum parameter in the CaMgtCfg MO for the cell is set to 0, the displayed value of this parameter is 0. If the average number of UEs to be scheduled in the downlink is less than the value of the MinDlAvgToBeScheduledUeNum parameter in the CaMgtCfg MO, the displayed value of this parameter is the configured value of the MinDlAvgToBeScheduledUeNum parameter in the CaMgtCfg MO. This parameter applies only to LTE FDD and LTE TDD.

First SCell eNodeB ID

First SCell Cell ID
