Set RRN Password (SET EURRNPWD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the password for the RRN.

Note

The password is case sensitive. This command are invalid for the RRN3201 and RRN3901. To restore the password of the admin account, run the RST EURRNPWD command.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PasswordType Password Type

Meaning: Indicates the type of the password. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: ADMIN_ACCOUNT(ADMIN_ACCOUNT), LOCAL_WAP(LOCAL_WAP)

Unit: None

Actual Value Range: ADMIN_ACCOUNT, LOCAL_WAP

MML Default Value: ADMIN_ACCOUNT(ADMIN_ACCOUNT)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NEW New Password

Meaning: Indicates the new password. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 8~64 characters

Unit: None

Actual Value Range: 8~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CFM Confirm Password

Meaning: Indicates the password that is used to confirm the entered password. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 8~64 characters

Unit: None

Actual Value Range: 8~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

+++    LTE_RRN_10.157.112.140        2017-12-20 20:49:44
O&M    #808452710
%%SET EURRNPWD: LocalSubscriberId=2, PasswordType=ADMIN_ACCOUNT, NEW="*****", CFM="*****";%%
RETCODE = 0  Operation succeeded.
