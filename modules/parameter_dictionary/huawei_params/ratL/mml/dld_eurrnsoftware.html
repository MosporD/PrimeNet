Download RRN software (DLD EURRNSOFTWARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to download software from the server to the RRN.

Note

None.

Parameters

Example

To download EURRN software with the parameters as follows:LocalSubscriber ID:10, FTP server IP:"192.168.0.1", USR:"admin", Pass Word:"*****", DIR="D:\stdio" , Software Version="11111", GA=Y;
run the following command:
DLD EURRNSOFTWARE: LocalSubscriberId=10, IP="192.168.0.1", USR="admin", PWD="*****", DIR="D:\stdio" , SV="11111", GA=Y;
