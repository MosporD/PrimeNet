Display eNodeB MBMS Information (DSP MBMSPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query eNodeB MBMS information.

Note

None.

Parameters

None.

Example

DSP MBMSPARA:
+++    HUAWEI        2014-01-06 21:51:55
O&M    #41132
%%DSP MBMSPARA:;%%
RETCODE = 0  Operation succeeded.

Display eNodeB MBMS Information
-------------------------------
                  MBSFN Area ID  =  50
Synchronisation Period(10240ms)  =  58
          Cell Reservation Info  =  NoneReservedCell
                  Local Cell ID  =  34
(Number of results = 1)

Output Description

Field Description

MBSFN Area ID

Indicates the ID of a Multimedia Broadcast Single Frequency Network (MBSFN) area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.

Synchronisation Period(10240ms)

Indicates the synchronization period of the SYNC protocol. This parameter applies only to LTE FDD and LTE TDD.

Cell Reservation Info

Indicates whether the cell is a reserved cell for Multimedia Broadcast Multicast Service (MBMS) services. This parameter applies only to LTE FDD and LTE TDD.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
