List M3 (LST M3)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration data of an M3 object.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M3Id M3 ID

Meaning: Indicates the ID of the M3 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the basic M3 information with the parameters as follows: Local MCE ID: 0, M3 ID:0, run the following command:
LST M3: LocalMceId=0, M3Id=0;
The result is shown as follows:

Output Description

Field Description

Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

M3 ID

Indicates the ID of the M3 MO. This parameter applies only to LTE FDD and LTE TDD.

M3 End Point Group ID

Indicates the ID of the end point resource group used by the M3 MO. This parameter applies only to LTE FDD and LTE TDD.

Interface Setup Initiation Indication

Indicates whether to initiate the M3 interface setup process. Set this parameter to YES for core networks compliant with 3GPP Release 11 or later. Set this parameter to NO for core networks compliant with 3GPP specifications earlier than Release 11. For details, see 3GPP TS 36.444. This parameter applies only to LTE FDD and LTE TDD.

Mobile Country Code

Indicates the MCC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-M3-link scenarios. This parameter applies only to LTE FDD and LTE TDD.

Mobile Network Code

Indicates the MNC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-M3-link scenarios. This parameter applies only to LTE FDD and LTE TDD.
