Add Neighboring Relation with CDMA2000HRPD Cell (ADD CDMA2000HRPDNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the neighboring relation with a CDMA2000 HRPD cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the associated external CDMA2000 HRPD cell has been configured.

  • The band class and frequency information about the CDMA2000 HRPD cell must already be set in the associated neighboring CDMA2000 HRPD frequency.

  • A maximum of 32 neighboring relations with CDMA2000 HRPD cells can be configured for each E-UTRAN cell.

  • The ANR flag parameter specifies whether a neighboring cell is automatically detected by ANR. This parameter cannot be set in the MML command window but can be set by running MML commands in command line or running batch commands. This parameter can be queried by running LST commands.

    The default parameter value BOOLEAN_FALSE(False) is delivered when ADD commands are executed in the MML command window. The value BOOLEAN_FALSE(False) indicates that the neighboring cell is manually configured.

    When a neighbor relationship is automatically added by ANR, this parameter is set to BOOLEAN_TRUE(True), indicating that the neighboring cell is automatically configured.

    You are advised not to set the AnrFlag parameter by running MML commands in command line or running batch commands.

SectorId104 SectorID104

Meaning: Indicates the value for SectorID104 of the neighboring CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 26 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3~28 characters

Unit: None

Actual Value Range: 3~28 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • SectorId104 in the Cdma2000HrpdNCell MO must be set to a hexadecimal number starting with 0x and with a total length not greater than 26 digits. A hexadecimal number is composed of upper-case letters (A to F) and digits (0 to 9). The hexadecimal digit following 0x can be 0 only if the parameter is set to 0x0. That is, the parameter value like 0x00AB is inappropriate but 0x0 is acceptable.

CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AUTO_MODE(Auto Mode), MANUAL_MODE(Manual Mode)

Example

To add a CDMA2000 HRPD neighboring relation with the parameters as follows: Local cell ID: 0, SectorID104: "0x0", SectorID24: "0x0", Band class: bc0, Frequency: 1234, run the following command:
ADD CDMA2000HRPDNCELL: LocalCellId=0, SectorId104="0x0", SectorId24="0x0", BandClass=bc0, Frequency=1234;
