Modify an IP route for an RRN (MOD EURRNRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of an EU RRN route.

Note

None.

Parameters

ID Name Description
RtId Route ID

Meaning: Indicates the ID of an IP route on an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of the EuRrnRt MOs with the LocalSubscriberId parameters set to the same value is less than or equal to 8.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DstIp Destination IP

Meaning: Indicates the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DstMask Destination Mask

Meaning: Indicates the subnet mask of the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NextHop Next Hop

Meaning: Indicates the next-hop IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set an IP route for an RRN with the parameters as follows: Route ID:1, Destination IP:172.31.255.1, Next Hop:172.31.255.2, run the following command:
MOD EURRNRT: RtId=1, DstIp="172.31.255.1", NextHop="172.31.255.2";
