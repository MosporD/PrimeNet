Modify Neighboring Cell Management Parameter Configuration (MOD NCELLPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify settings of parameters related to neighboring cell management.

Note

None.

Parameters

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

NCellOdDisThd Neighboring Cell Distance Threshold

Meaning: Indicates the distance threshold for over-distant neighboring cell detection. If this parameter is set to a value other than 0, the eNodeB detects over-distant neighboring cells based on the distance. If the distance between the serving cell and a neighboring cell is greater than this threshold, the neighboring cell is an over-distant neighboring cell. If this parameter is set to 0, the eNodeB detects over-distant neighboring E-UTRAN cells based on the access radius but does not detect over-distant neighboring UTRAN cells. If the distance between the serving cell and a neighboring E-UTRAN cell is greater than the sum of access radii of both cells, this neighboring cell is an over-distant neighboring cell. This parameter is valid only when RatType is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~500000

Unit: m

Actual Value Range: 0~500000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
HoStatThd Handover Statistic Threshold

Meaning: Indicates the threshold, which is the number of handovers, used for over-distant neighboring cell detection. If the number of handovers to a neighboring cell reaches this threshold and the handover success rate reaches the related threshold within a measurement period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. This parameter is valid only when the RatType parameter is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10000

Unit: None

MML Default Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
HoSuccThd Handover Success Rat Threshold

Meaning: Indicates the threshold, which is a handover success rate, used for over-distant neighboring cell detection. If the number of handovers to a neighboring cell reaches the related threshold and the handover success rate reaches the threshold specified by this parameter within a measurement period, this neighboring cell does not need to be reported to the MAE for over-distant neighboring cell detection. Otherwise, the neighboring cell needs to be reported to the MAE for over-distant neighboring cell detection. This parameter is valid only when the RatType parameter is set to EUTRAN or UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

NcellNumForAnr Neighbouring Cell Number for ANR

Meaning: Indicates the threshold of the number of intra-RAT intra-frequency neighboring cells used in the automatic neighbor relationship removal function of ANR. The value 0 indicates no requirement for the minimum number of neighboring cells on the serving frequency. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: 32

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that an existing neighbor relationship will be replaced by a new neighbor relationship. As a result, a new neighbor relationship cannot be added because no neighbor relationship that can be replaced is found when the number of neighbor relationships reaches its maximum, causing a higher probability that the success rate of handovers to the new neighboring cell or the success rate of configuring the neighboring cell as an SCell decreases.

A smaller value of this parameter results in a higher probability that an existing neighbor relationship will be replaced by a new neighbor relationship. As a result, a new neighbor relationship can be added because a neighbor relationship that can be replaced is found when the number of neighbor relationships reaches its maximum, striking a balance between frequencies in terms of the number of neighbor relationships. However, there is a higher probability that the success rate of handovers to the replaced neighboring cell or the success rate of configuring the replaced neighboring cell as an SCell decreases.

It is recommended that the sum of values of this parameter set for all frequencies be less than the allowed maximum number of neighbor relationships.

Applicable Mode: L-FDD, L-TDD
CellAnrOptMode Cell ANR Optimization Mode

Meaning: Indicates whether to report neighbor relationships of the local cell with cells in different RATs when the OptMode parameter in the ANR MO is set to CONTROLLED. The RAT of a neighboring cell is specified by the RatType parameter in the NCellParaCfg MO. If this parameter is set to CONTROLLED, the eNodeB reports the neighbor relationships with cells in the specified RAT to the MAE. These neighbor relationships will be updated only if they are manually confirmed on the MAE. If this parameter is set to FREE, the eNodeB automatically handles the neighbor relationships with cells in the specified RAT, except the blacklisted neighbor relationships with E-UTRAN and UTRAN cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CONTROLLED(CONTROLLED), FREE(FREE)

Unit: None

Actual Value Range: CONTROLLED, FREE

MML Default Value: None

Recommended Value: CONTROLLED(CONTROLLED)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To configure neighbor cell parameter configuration for local cell id 0, rat type EUTRAN, handover statistic threshold 20, handover success rat threshold 90%, run the following command:
MOD NCELLPARACFG: LocalCellId=0, RatType=EUTRAN, HoStatThd=20, HoSuccThd=90;
