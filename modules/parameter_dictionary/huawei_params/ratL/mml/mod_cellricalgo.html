Modify Cell Remote Interference Cancellation Algorithm Configuration (MOD CELLRICALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the remote interference cancellation algorithm in a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

For a TDD cell, modifications on the number of empty symbols in a UpPTS will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RicAlgoSwitch RIC algorithm switch

Meaning: Indicates the switch for the remote interference cancellation algorithm. If this switch is turned on, the eNodeB performs remote interference detection and records in call history record (CHR) logs if any interference is detected. If this switch is turned off, the eNodeB does not perform remote interference detection. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: The value OFF is recommended if there is no remote interference to the cell.

The value ON is recommended if there is remote interference to the cell.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MuteUpPTSSymNum Mute UpPTS Symbol Number

Meaning: Indicates the number of symbols during which no SRSs are transmitted in an uplink pilot timeslot (UpPTS). If this parameter is set to a non-zero value N, no SRSs are transmitted within N symbols starting from the first symbol during which SRS transmission is allowed in the UpPTS. For any given special subframe configuration, the value of this parameter must not be greater than the total number of symbols during which SRS transmission is allowed in the UpPTS. This parameter applies only to LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: The value 0 is recommended if there is no interference to the cell.

The value 1 or 2 is recommended if there is interference to the cell.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a value other than 0, the amount of resources where SRSs are transmitted and the number of UEs that can access the cell may decrease. If this parameter is set to 0, the network performance is not affected.

Applicable Mode: L-TDD
MuteULSym Whether to mute UL symbol

Meaning: Indicates whether to mute the last symbol in an uplink subframe. If this parameter is set to ON, the last symbol in an uplink subframe is muted. If this parameter is set to OFF, the last symbol in an uplink subframe is not muted. This parameter applies only to LTE TDD cells using uplink-downlink subframe configuration 1. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Recommended Value: OFF(Off)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
UlInterferenceThd UL Interference Threshold

Meaning: Indicates the relative threshold used to determine whether uplink interference occurs in a cell. If the average uplink interference and noise received on each PRB in a cell is at least 15 dBm greater than this threshold or the average UpPTS interference is at least 15 dBm greater than this threshold minus 10, it is considered that severe interference has occurred in the cell. At this point, the eNodeB records an entry of interference-related characteristic (which can be queried by running the DSP INREC command) and collects inverse spectrum data. This parameter applies only to LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -119

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Interference-related characteristic data collection and automatic reverse spectrum data collection are not controlled by any switches and are enabled when uplink interference is determined based on this threshold. An uplink subframe is silent every two minutes during reverse spectrum data collection, causing 1/12000 resources lose. Such losses can be ignored because it has much less impact than uplink interference.

Meaning: Indicates whether to enable adaptive avoidance of remote interference. If this parameter is set to ON(On), characteristic sequences are sent and detected to adaptively avoid remote interference. This parameter applies only to LTE TDD cells.

Parameter Relationship:

-Configuration constraints:

  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo is set to ON, the value of FddTddInd in a CELL MO is only to be set CELL_TDD, and the value of SubframeAssignment in a CELL MO is only to be set SA2, and the value of SpecialSubframePatterns in a CELL MO is only to be set SSP5 or SSP6 or SSP7 or SSP9.
  • When the value of RemoteInfAdpAvoidSwitch in a CellRicAlgo MO is set to ON, the value of MultiRruCellFlag in a CELL MO is only to be set BOOLEAN_FALSE.
  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DuctDLSubfrmShutoffSwitch parameter in the same MO is set to ON(On).
  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DUCT_DL_SUBFRM_SHUTOFF_OPT_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.
  • The DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the CellRicAlgo MO must be deselected when the RemoteInfAdpAvoidSwitch parameter in the same MO is set to ON.

Service Interrupted After Modification: No

Impact on Radio Network Performance: When remote interference is detected, characteristic sequences are sent, reducing the downlink peak throughput by 1/(1024 x 8).

If the difference between the maximum and minimum receive power of uplink symbols exceeds this threshold, the eNodeB determines that abnormal interference occurs. This parameter can be used only to trigger automatic recording of one interference record and reverse spectrum data collection. This parameter applies only to LTE TDD.

DuctDLSubfrmShutoffSwitch Atmospheric Duct DL Subframe Shutdown Switch

Meaning: Indicates whether to enable atmospheric duct DL subframe shutdown. If this parameter is set to ON(On), the eNodeB shuts down downlink subframes. If this parameter is set to OFF(Off), the eNodeB does not shut down downlink subframes. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: If cells do not encounter atmospheric duct interference of remote eNodeBs, set this parameter to OFF(Off). If cells encounter atmospheric duct interference of remote eNodeBs, set this parameter to ON(On).

Parameter Relationship:

-Configuration constraints:

  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DuctDLSubfrmShutoffSwitch parameter in the same MO is set to ON(On).
  • The DuctDLSubfrmShutoffSwitch parameter in the CellRicAlgo MO must be set to OFF when the DUCT_DL_SUBFRM_SHUTOFF_OPT_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.
  • The DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the CellRicAlgo MO must be deselected when the DuctDLSubfrmShutoffSwitch parameter in the same MO is set to ON.

Service Interrupted After Modification: No

Impact on Radio Network Performance: If this parameter is set to ON(On) when atmospheric duct interference occurs, the atmospheric duct interference of the eNodeB to the entire network decreases, increasing the radio connection success rate and handover success rate of the entire network and lowering the radio service drop rate. However, this setting lowers the downlink cell throughput and increases the downlink packet loss rate.

Applicable Mode: L-TDD

For example, if this parameter is set to 12 and the eNodeB detects interference that meets the criteria for 1 minute, the eNodeB records interference for maintenance. This parameter can be used only to trigger automatic recording of one interference record and reverse spectrum data collection. This parameter applies only to LTE TDD.

DuctDLSubfrmShutoffInfThld Duct DL Subframe Shutoff Opt Inf Thld

Meaning: Indicates the absolute interference threshold for determining whether atmospheric duct interference occurs in an uplink subframe. The eNodeB may optimize downlink subframe shutdown due to atmospheric duct interference only when interference occurring in an uplink subframe on the 72 subcarriers in the middle of the frequency domain exceeds this threshold. This parameter applies only to LTE TDD.

GUI Value Range: -150~30

Unit: dBm

Actual Value Range: -150~30

MML Default Value: None

Recommended Value: -95

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value, the eNodeB is more likely to optimize downlink subframe shutdown when atmospheric duct interference occurs and shuts down downlink subframes, reducing atmospheric duct interference of the cell to the entire network. This increases the radio access and handover success rates and decreases the service drop rate on the entire network. However, the cell throughput and number of UEs that can be served in the cell decrease and the packet loss rate increases. If this parameter is set to a larger value, the eNodeB is less likely to optimize downlink subframe shutdown when atmospheric duct interference occurs, bringing no impact on network KPIs.

DuctDLSubfrmShutoffOptSw Duct DL Subframe Shutoff Opt Sw

Meaning: DUCT_DL_SUBFRM_SHUTOFF_OPT_SW: If this option is selected, the eNodeB automatically detects atmospheric duct interference and shuts down downlink subframes when the interference meets the preset condition. If this option is deselected, the eNodeB does not detect atmospheric duct interference or shut down downlink subframes. This option applies only to LTE TDD.

DUCT_DL_SF_SCHED_SHUTOFF_SW: If this option is selected, the eNodeB automatically detects atmospheric duct interference in the cell within the specified detection period, and shuts down downlink subframes when the interference condition is met. If this option is deselected, the eNodeB neither detects atmospheric duct interference nor shuts down downlink subframes. This option applies only to LTE TDD.

GUI Value Range: DUCT_DL_SUBFRM_SHUTOFF_OPT_SW(DUCT_DL_SUBFRM_SHUTOFF_OPT_SW), DUCT_DL_SF_SCHED_SHUTOFF_SW(DUCT_DL_SF_SCHED_SHUTOFF_SW)

Actual Value Range: DUCT_DL_SUBFRM_SHUTOFF_OPT_SW, DUCT_DL_SF_SCHED_SHUTOFF_SW

MML Default Value: None

Recommended Value: DUCT_DL_SUBFRM_SHUTOFF_OPT_SW: It is recommended that this option be selected only when the cell experiences atmospheric duct interference of remote base stations.

DUCT_DL_SF_SCHED_SHUTOFF_SW: It is recommended that this option be deselected when the cell is not under atmospheric duct interference of remote base stations and be selected when the cell experiences atmospheric duct interference of remote base stations and timing control is required.

Parameter Relationship:

-Configuration constraints:

  • The RemoteInfAdpAvoidSwitch parameter in the CellRicAlgo MO must be set to OFF(Off) when the DUCT_DL_SUBFRM_SHUTOFF_OPT_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.
  • The DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the CellRicAlgo MO must be deselected when the RemoteInfAdpAvoidSwitch parameter in the same MO is set to ON.
  • The DuctDLSubfrmShutoffSwitch parameter in the CellRicAlgo MO must be set to OFF when the DUCT_DL_SUBFRM_SHUTOFF_OPT_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.
  • The DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the CellRicAlgo MO must be deselected when the DuctDLSubfrmShutoffSwitch parameter in the same MO is set to ON.
  • The DuctSubfrmShutoffDepth parameter in the CellRicAlgo MO cannot be set to SLOT01_SHUTOFF if the DUCT_DL_SF_SCHED_SHUTOFF_SW option of the DuctDLSubfrmShutoffOptSw parameter in the same MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DUCT_DL_SUBFRM_SHUTOFF_OPT_SW: If atmospheric duct interference meets the condition for triggering downlink subframe shutdown optimization, the eNodeB reduces atmospheric duct interference of the cell to the entire network. This increases the radio connection success rate and handover success rate of the entire network and lowers the radio service drop rate. However, this lowers the cell throughput and number of UEs that can be served and increases the packet loss rate.

DUCT_DL_SF_SCHED_SHUTOFF_SW: If this option is selected and downlink subframe shutdown takes effect when the atmospheric duct interference condition is met within the specified detection period, atmospheric duct interference of the local cell to the entire network is reduced. This increases the radio access and handover success rates and decreases the service drop rate on the entire network. However, this lowers the cell throughput and number of UEs that can be served and increases the packet loss rate. If this option is deselected, there is no impact.

Applicable Mode: L-TDD

Example

To modify the configuration of the remote interference cancellation algorithm in a cell with the parameters as follows: Local cell ID: 0, RIC algorithm switch: ON, Mute UpPTS Symbol Number: 2, run the following command:
MOD CELLRICALGO:LocalCellId=0, RicAlgoSwitch=ON, MuteUpPTSSymNum=2;
