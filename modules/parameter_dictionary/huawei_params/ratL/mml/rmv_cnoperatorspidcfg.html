Remove Cn Operator SPID Configuration (RMV CNOPERATORSPIDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the dedicated subscriber profile ID (SPID) configuration for an operator.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: This parameter indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • CnOperatorId in an CnOperatorSpidCfg MO must be set in the associated CnOperator MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Spid Spid

Meaning: Indicates the dedicated SPID for an operator. According to 3GPP specifications, the SPID can be from 1 to 256. When this parameter is set to 0, the eNodeB does not obtain the SPID from the MME or the eNodeB is not configured with an SPID for UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the dedicated SPID of an operator with the parameters as follows: CN Operator ID: 0, Spid: 1, run the following command:
RMV CNOPERATORSPIDCFG: CnOperatorId=0, Spid=1;
