Remove ULSpectrumShrConfig (RMV ULSPECTRUMSHRCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove spectrum sharing parameter configurations for UMTS and LTE spectrum sharing.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If UMTS and LTE spectrum sharing is enabled, removing the LTE PRB start index or end index when PrbRsvType is set to LTE_DL_AVAILABLE_PRB or LTE_UL_AVAILABLE_PRB will cause cells referencing the ULSpectrumSharingConfigId parameter configurations to reset.

Parameters

ID Name Description
ULSpectrumSharingConfigId UMTS and LTE Spectrum Sharing Config ID

Meaning: Indicates the cell configuration ID of UMTS and LTE spectrum sharing, which is unique within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~25

Unit: None

Actual Value Range: 0~25

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PrbRsvType PRB Reserve Type

Meaning: Indicates the PRB reserving type of UMTS and LTE spectrum sharing. This option applies only to LTE FDD.

GUI Value Range: LTE_DL_AVAILABLE_PRB(LTE_DL_AVAILABLE_PRB), LTE_UL_AVAILABLE_PRB(LTE_UL_AVAILABLE_PRB), LTE_DL_HIGH_PRIORITY_PRB(LTE_DL_HIGH_PRIORITY_PRB), UMTS_CORE_SPECTRUM_1(UMTS_CORE_SPECTRUM_1), UMTS_CORE_SPECTRUM_2(UMTS_CORE_SPECTRUM_2), UMTS_CORE_SPECTRUM_3(UMTS_CORE_SPECTRUM_3), UMTS_CORE_SPECTRUM_4(UMTS_CORE_SPECTRUM_4), UMTS_LTE_SHARED_SPECTRUM(UMTS_LTE_SHARED_SPECTRUM), LTE_PUCCH_AVAILABLE_PRB(LTE_PUCCH_AVAILABLE_PRB)

Unit: None

Actual Value Range: LTE_DL_AVAILABLE_PRB, LTE_UL_AVAILABLE_PRB, LTE_DL_HIGH_PRIORITY_PRB, UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, UMTS_CORE_SPECTRUM_4, UMTS_LTE_SHARED_SPECTRUM, LTE_PUCCH_AVAILABLE_PRB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To remove spectrum sharing parameter configurations for UMTS and LTE spectrum sharing, UMTS and LTE Spectrum Sharing Config ID:0, PRB Reserve Type:LTE_DL_AVAILABLE_PRB:
RMV ULSPECTRUMSHRCONFIG: ULSpectrumSharingConfigId=0, PrbRsvType=LTE_DL_AVAILABLE_PRB;
