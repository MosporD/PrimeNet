QciAlgoSwitch QCI Algorithm Switch

Meaning: Indicates whether to enable QCI-specific algorithms.

INTER_FREQ_MLB_ALLOWED: If this option is selected, inter-frequency mobility load balancing (MLB) can be performed for UEs with bearers of this QCI. You are advised to select this option for the default bearers. Otherwise, the eNodeB may fail to transfer UEs for MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_FREQ_MLB_LOW_PRIO_IND: If this option is selected, the eNodeB does not preferentially select UEs with bearers of this QCI for inter-frequency MLB. If this option is deselected, no policy is applied to selection of such UEs for inter-frequency MLB. You are advised to deselect this option for the default bearers. Otherwise, QCI-based UE selection policies for MLB may not take effect. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_MLB_ALLOWED: If this option is selected, UEs with bearers of this QCI can be selected for inter-RAT MLB. If this option is deselected, UEs with bearers of this QCI cannot be selected for inter-RAT MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

INTER_RAT_MLB_LOW_PRIO_IND: If this option is selected, the eNodeB does not preferentially select UEs with bearers of this QCI for inter-RAT MLB. If this option is deselected, no policy is applied to selection of such UEs for inter-RAT MLB. This option takes effect only on standardized QCIs. This option applies only to LTE FDD and LTE TDD.

HO_USE_VOIP_FREQ_ALLOWED: If this option is selected and inter-frequency directional handovers for VoIP services are enabled, then the eNodeB selects handover target frequencies for UEs with bearers of this QCI based on the value of the VoIPPriority parameter in the EutranInterNFreq MO and frequency-priority-based handovers are disabled for UEs with bearers of this QCI. If this option is deselected, then the eNodeB does not select handover target frequencies for UEs with bearers of this QCI based on the value of the VoIPPriority parameter in the EutranInterNFreq MO and frequency-priority-based handovers are enabled for UEs with bearers of this QCI. This option applies only to LTE FDD and LTE TDD.

SMART_CA_ALLOWED: If this option is selected, the eNodeB triggers a procedure for intelligent selection of serving cell combinations to reselect an optimal serving cell combination after the QCI-specific bearer is set up in the eNodeB. If this option is deselected, the eNodeB does not trigger the procedure in the preceding scenario. This option applies only to LTE FDD and LTE TDD.

ADMISSION_FORBIDDEN: If this option is selected, the eNodeB directly rejects bearers of this QCI during admission upon receiving the E-RAB SETUP REQUEST message from the MME and does not allow preemption. If this option is deselected, the eNodeB admits such bearers. This option applies only to LTE TDD.

SRI_PERIOD_OPT_SW: If this option is selected, the eNodeB preferentially allocates short SRI periods to UEs with bearers of this QCI, improving user experience with delay on UEs with such bearers. In FDD, this option takes effect only when SriPeriodAdaptive is set to QCIADAPTIVE and the SriReCfgInd parameter is set to FALSE. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

DL_SCH_PRIORITY_OPT_SW: If this option is selected, the eNodeB allocates higher scheduling priorities for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

PDCCH_BOUNDARY_PWR_CTRL_OPT_SW: If this option is selected, PDCCH boundary power control optimization is enabled for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

SR_PRIORITY_DATA_OPT_SW: If this option is selected, SR-based scheduling priority and data amount optimization is enabled for bearers of this QCI, improving user experience with delay on UEs with such bearers. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

QCI_TTI_BUNDLING_SWITCH: Indicates whether to enable QCI-specific TTI bundling. If this option is selected, TTI bundling is allowed for UEs with bearers of this QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD.

QCI_ROHC_SWITCH: Indicates whether to enable QCI-specific ROHC. If this option is selected, ROHC is allowed for UEs with bearers of this QCI, thereby improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

LOW_DELAY_UE_UL_SCH_OPT_SW: Indicates whether to enable uplink scheduling optimization for UEs running low-latency services. If this option is selected, uplink scheduling optimization is allowed for UEs with bearers of the specified QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

LOW_DELAY_UE_UL_MCS_IDX_RDC_SW: Indicates whether to enable uplink MCS index reduction for UEs running low-latency services. If this option is selected, uplink MCS index reduction is allowed for UEs with bearers of the specified QCI, improving user experience with service delay. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

SCS_FAST_MOVING_UE_SW: If this option is selected, the base station triggers smart carrier selection for fast-moving UEs after bearers of this QCI are set up in the base station. If this option is deselected, the eNodeB does not trigger smart carrier selection for fast-moving UEs after the bearers are set up. This option applies only to LTE FDD and LTE TDD.

UE_REL_FORBID_IMMCI_FOR_MLB_SW: Indicates whether the eNodeB is prohibited from delivering the IMMCI IE for MLB when the RRC connection of a UE is to be released and the UE is changed from RRC_CONNECTED mode to RRC_IDLE mode. If this option is selected, the IMMCI IE is not allowed to be delivered. If this option is deselected, this IE can be delivered. This option applies only to LTE FDD and LTE TDD.

FORBID_MLB_SWITCH: Indicates whether to prohibit MLB-triggered transfer of RRC_CONNECTED UEs with services of the specified QCI. If this option is selected, MLB-triggered transfer of such UEs is prohibited. If this option is deselected, MLB-triggered transfer of such UEs is not prohibited. This option applies only to LTE FDD and LTE TDD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Operators can configure different MLB policies for different QCIs. For example, if inter-frequency MLB and inter-RAT MLB are disabled for UEs performing QCI 1 services, the number of handovers of such UEs decreases when the network capacity is not restricted for QCI 1 services. However, this may cause overload of QCI 1 services when the number of UEs performing QCI 1 services increases. SMART_CA_ALLOWED: If the eNodeB performs intelligent selection of serving cell combinations based on the QCIs, the number of inter-frequency handovers increases.
