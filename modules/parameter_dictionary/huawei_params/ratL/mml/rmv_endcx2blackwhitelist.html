Remove gNodeB from EN-DC X2 Blacklist or Whitelist (RMV ENDCX2BLACKWHITELIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a peer gNodeB from the EN-DC X2 blacklist or whitelist. If a peer gNodeB is blacklisted, the X2 interface between the local eNodeB and this gNodeB is abnormal and this interface cannot be automatically set up. If a peer gNodeB is whitelisted or blacklisted, the X2 interface between the local eNodeB and this gNodeB cannot be automatically removed.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of three decimal digits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an EnDcX2BlackWhiteList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code of the peer base station in the EN-DC X2 blacklist or whitelist. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in an EnDcX2BlackWhiteList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
gNodeBId gNodeB ID

Meaning: Indicates the ID of the peer base station in the EN-DC X2 blacklist or whitelist. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove a peer gNodeB with the following parameters to the EN-DC X2 blacklist: Mobile country code: 460, Mobile network code: 20, gNodeB ID: 255, run the following command:
RMV ENDCX2BLACKWHITELIST: Mcc="460", Mnc="20", gNodeBId=255;
