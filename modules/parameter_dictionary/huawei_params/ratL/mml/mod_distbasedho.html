Modify Distance based Handover (MOD DISTBASEDHO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of distance-based handovers.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DistBasedMeasObjType Distance-based Measurement Object Type

Meaning: Indicates the measurement object type for distance-based handovers. The measurement object type can be E-UTRAN, UTRAN, or GERAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EUTRAN, GERAN, UTRAN

Unit: None

Actual Value Range: EUTRAN, GERAN, UTRAN

MML Default Value: None

Recommended Value: EUTRAN: Off, GERAN: Off, UTRAN: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DistBasedHOThd Distance-based Handover Threshold

Meaning: Indicates the threshold for distance-based handovers. If the distance between a UE and the cell center is greater than this threshold, a distance-based handover is triggered for this UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: 100m

Actual Value Range: 100~100000

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: An appropriate value of this parameter effectively reduces the possibility of handover attempts between non-neighboring cells and therefore increases handover success rates. A small value of this parameter results in a high probability of distance-based handovers. A large value of this parameter results in a low probability of distance-based handovers.

Applicable Mode: L-FDD, L-TDD

Example

To modify distance based handover settings as follows: Local cell ID: 0, Distance-based Measurement Object Type: UTRAN, Distance-based  Handover Threshold(100m): 1, run the following command:
+++    HUAWEI        2011-12-19 14:57:10
O&M    #1119
%%MOD DISTBASEDHO: LocalCellId=0, DistBasedMeasObjType=UTRAN-1, DistBasedHOThd=1;%%
RETCODE = 0  Operation succeeded.
