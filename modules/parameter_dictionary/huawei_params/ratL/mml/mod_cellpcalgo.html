Modify Cell PC Algorithm Configuration (MOD CELLPCALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters for the cell-level power control algorithm.

Note

  • The IoTCtrlINCorrectSwitch parameter is valid only after the PuschIoTCtrlSwitch(PuschIoTCtrlSwitch) check box is selected under the UlPcAlgoSwitch parameter in the CellAlgoSwitch MO.

  • The IoTNearPointOptSwitch parameter is invalid if the PuschIoTCtrlSwitch(PuschIoTCtrlSwitch) check box is deselected under the UlPcAlgoSwitch parameter in the CellAlgoSwitch MO.

Impact on Radio Network Performance: If SINR-based SRS power control is used, the weight evaluation accuracy of beamforming and DL CoMP UEs can be improved. In this case, there is a high probability that the performance is improved but the number of RRCReconfig messages increases.

If SRS power control based on the converged SINR and RSRP is used, the number of RRCReconfig messages is decreased with the weight evaluation accuracy of beamforming and DL CoMP UEs guaranteed (that is, performance of such UEs is guaranteed).

If SINR-based adaptive SRS power control is used, weight evaluation for beamforming and DL CoMP UEs is more accurate in dense networking mode. In this case, the performance is significantly improved, but the number of RRCReconfig messages may increase.

Meaning: Indicates the offset of signal quality of a neighboring cell to that of the serving cell. This parameter is used to report a measurement event for PUSCH IoT-based power control. A large value of this parameter indicates that the event can be reported only when a UE receives signals of good quality from a neighboring cell. IoTNearPointOptSwitch IoT NearPoint Optimization Switch

Meaning: Indicates whether to enable IoT-based optimization for UEs at the cell center.

If this parameter is set to OFF(Off), the eNodeB does not deliver event A3-based measurement configurations to optimize the uplink throughput of UEs at the cell center when strong interference occurs (the IoT is greater than 7 dB).

If this parameter is set to ON(On), the eNodeB delivers event A3-based measurement configurations to optimize the uplink throughput of UEs at the cell center when strong interference occurs (the IoT is greater than 7 dB).

This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On).

In scenarios where the IoT value is greater than 7 dB, it is recommended that this parameter be set to ON(On) to ensure the average cell throughput after IoT power control is enabled.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the IoT value is greater than 7 dB and the network access success rate of CEUs needs to be ensured, it is recommended that this parameter be set to OFF(Off).

If the IoT value is greater than 7 dB and the average cell throughput needs to be ensured, it is recommended that this parameter be set to ON(On).

If this parameter is set to OFF(Off) when the IoT value is greater than 7 dB, the eNodeB does not deliver event A3 measurement configuration to improve signal quality of CCUs. In this case, the interference suppression effect of IoT-based power control is good, and the network access success rate of CEUs increases, but there is a high probability that the average cell throughput decreases.

If this parameter is set to ON(On) when the IoT value is greater than 7 dB, the eNodeB delivers event A3 measurement configuration to improve signal quality of CCUs. In this case, the interference suppression effect of IoT-based power control is not as good as when this parameter is set to ON(On), and the network access success rate of CEUs slightly decreases, but there is a low probability that the average cell throughput decreases.

Applicable Mode: L-TDD

If this parameter is set to 0, the target SINR of SRS power control for beamforming UEs is not adjusted. If this parameter is set to another value, the target SINR of SRS power control for beamforming UEs equals the configured target SINR plus this offset. This parameter applies only to LTE TDD.

GUI Value Range: 0~10

Unit: dB

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter leads to small SRS transmit power for beamforming UEs and therefore a low probability that UEs' SRS transmit power increases in a competitive way. However, in this case, UEs can measure low SRS SINRs in coordinating cells, causing decreased pairing performance for multi-UE joint transmission. A large value of this parameter leads to great SRS transmit power for beamforming UEs and high SRS SINRs in coordinating cells, improving the pairing performance for multi-UE joint transmission. However, in this case, there is a high probability that UEs' SRS transmit power increases in a competitive way. When this parameter is set to a value greater than 0, the RRC connection reconfiguration message overhead may increase. Since RRC reconfiguration messages are possibly triggered only by switching between the beamforming mode and a common MIMO mode, the probability of the message increase is low. Therefore, this setting has a small impact on the service drop rate.
