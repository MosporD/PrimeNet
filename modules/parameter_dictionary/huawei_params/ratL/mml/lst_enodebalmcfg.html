List eNodeB Alarm Parameter Settings (LST ENODEBALMCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list eNodeB alarm parameter settings.

Note

None.

Parameters

None.

Example

To list the configurations of eNodeB alarm parameters, run the following command: :
LST ENODEBALMCFG:;
The result is shown as follows:
+++    0        2019-12-05 17:31:17
O&M    #806355959
%%LST ENODEBALMCFG: ;%%
RETCODE = 0  Operation succeeded.

List eNodeB Alarm Parameter Settings
------------------------------------
       Traffic Faulty Detect Period(min)  =  1080
Service Interface Alarm Configure Switch  =  S1:Off
                                          =  X2:On
(Number of results = 1)


---    END

Output Description

Field Description

Traffic Faulty Detect Period(min)

Indicates the length for detecting service abnormality when the devices are suspected to experience soft failures. If service abnormality persists within the period of time specified by this parameter while the devices are suspected to experience soft failures, the devices are considered to experience soft failures.

Service Interface Alarm Configure Switch

Indicates whether to mask ALM-25888 SCTP Link Fault, ALM-25952 User Plane Path Fault, and ALM-25886 IP Path Fault. If the options of this parameter are selected, ALM-25888 SCTP Link Fault masking takes effect immediately, and ALM-25952 User Plane Bearer Link Fault (When the User Plane and Control Plane Are the Same Peer End, User Labels on the User Plane and SCTP Peer End Include GlobaleNBId_MCC-MNC-eNodeBId or GlobageNBId_MCC-MNC-gNodeBId) and ALM-25886 IP Path Fault masking takes effect next time the faults occur.

S1(S1): When ALM-29201 S1 Interface Fault and ALM-25888 SCTP Link Fault about an S1 interface are generated at the same time: (1) If this option is selected, ALM-29201 S1 Interface Fault is reported and ALM-25888 SCTP Link Fault is masked. (2) If this option is deselected, ALM-25888 SCTP Link Fault is also reported.

X2: If this option is selected, alarms related to transport links carrying the X2 interface are masked when these alarms are generated together with ALM-29204 X2 Interface Fault. If this option is deselected, alarms related to transport links carrying the X2 interface are not masked when these alarms are generated together with ALM-29204 X2 Interface Fault. Alarms related to transport links carrying the X2 interface include ALM-25888 SCTP Link Fault, ALM-25886 IP Path Fault, and ALM-25952 User Plane Path Fault. For ALM-25952, the user plane and control plane belong to the same peer end if user labels of both the user-plane peer end and SCTP peer end include the same GlobaleNBId_MCC-MNC-eNodeBId or GlobalgNBId_MCC-MNC-gNodeBId and their values are the same.
