Remove Operator Sharing Information for UTRAN Frequency (RMV UTRANRANSHARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove information about an operator that shares a neighboring UTRAN frequency.

Note

  • If a neighboring UTRAN frequency is shared by multiple operators and the sharing information about one operator is removed, this frequency cannot be used by the operator, but can still be used by other operators whose sharing information exists. If a neighboring UTRAN frequency is shared by only one operator and the sharing information about the operator is removed, this frequency can be used by all operators in the current cell.

  • If a neighboring UTRAN frequency is removed, information about operators that share the neighboring UTRAN frequency is automatically removed.

Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the neighboring UTRAN cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Example

To remove information about an operator that shares a neighboring UTRAN frequency with the parameters as follows: Local cell ID: 0, Downlink UARFCN:10800, Mobile country code: "460", Mobile network code: "02", run the following command:
RMV UTRANRANSHARE:LocalCellId=0, UtranDlArfcn=10800, Mcc="460", Mnc="02";
