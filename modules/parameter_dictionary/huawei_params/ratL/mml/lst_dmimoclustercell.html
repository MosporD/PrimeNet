List D-MIMO Cluster Cell (LST DMIMOCLUSTERCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the cells in a D-MIMO cluster.

Note

None.

Parameters

ID Name Description
DMIMOClusterId D-MIMO Cluster Id

Meaning: Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
CellId Cell Id

Meaning: Indicates the unique ID of a cell. The 28-bit E-UTRAN cell identity is comprised of the cell ID (represented by the least significant 8 bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD cells.

Unit: None

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
eNodeBId eNodeB Id

Meaning: Indicates the ID of an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD.

Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

Cell Id

eNodeB Id
