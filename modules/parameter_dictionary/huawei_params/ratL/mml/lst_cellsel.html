List Cell Selection Configuration (LST CELLSEL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters about cell selection.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of cell selection:
LST CELLSEL:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

Minimum required RX level(2dBm)

Indicates the minimum receive level required for a cell to become a candidate for cell selection. The level is included in S criteria and used in the evaluation of cell selection. The value range of this parameter is -70 to -22 for LTE FDD and TDD, and -78 to -22 for LTE NB-IoT. For details, see 3GPP TS 36.304.

Minimum required RX level offset(2dB)

Indicates the offset to the minimum required receive level. This value is included in criteria S and used in the evaluation of cell selection. This parameter is valid only when the cell selection is triggered by periodic searches for higher-priority PLMNs and the UE is served by a Visited Public Land Mobile Network (VPLMN). For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Minimum required RX quality level(dB)

Indicates the minimum required received signal quality, which corresponds to the q-QualMin IE in system information block type 1 (SIB1) and is used to calculate the Squal value for the serving cell involved in cell selection and reselection. If this parameter is set to 0, SIB1 does not contain the q-QualMin IE. If this parameter is set to a value other than 0, SIB1 contains the q-QualMin IE with the same value as the parameter value. For details about this parameter, see 3GPP TS 36.304.

Minimum required RX quality level offset configure indicator

Indicates whether to set the offset to the minimum required receive level for the cell. This parameter applies only to LTE FDD and LTE TDD.

Minimum required RX quality level offset(dB)

Indicates the offset to the minimum required received signal quality for the cell. It is included in criteria S and used in the evaluation of cell selection. This parameter is required only when the cell selection is triggered by periodic searches for higher-priority PLMNs and the UE is served by a Visited Public Land Mobile Network (VPLMN). For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Minimum Required RX Level for CE(2dBm)

Indicates the minimum receive level required for coverage enhancement mode A of a cell. It is included in criterion S for cell selection. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Minimum Required Quality Level for CE(dB)

Indicates the minimum received signal quality used in cell selection criterion S for coverage enhancement mode A. This parameter corresponds to the q-QualMinRSRQ-CE-r13 IE in SIB1-BR. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Min Signal Quality Level for CE Mode B(dB)

Indicates the minimum received signal quality required for coverage enhancement mode B of a cell. It is used as an input parameter for cell selection criterion S. If this parameter is set to 0, SIB1-BR does not contain the q-QualMinRSRQ-CE1-r13 IE. In this case, the value -∞ is used by default and the eNodeB performs cell selection and reselection for UEs based only on the signal level. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Min RX Level for CE Mode B(2dBm)

Indicates the minimum receive level required for coverage enhancement mode B of a cell. It is used as an input parameter for cell selection criterion S. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Power Offset for Selection to NB-IoT Cell(dB)

Indicates the power offset for cell selection of an NB-IoT UE with a power level of 14 dBm. When set to NULL, this parameter will not be delivered in the system information, and the UE takes 0 dB as the power offset by default. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.
