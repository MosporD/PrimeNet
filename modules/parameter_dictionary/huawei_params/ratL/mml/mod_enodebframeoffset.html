Modify eNodeB Frame Offset Configuration (MOD ENODEBFRAMEOFFSET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the offset of the start of LTE TDD cell frames against the reference time.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The frame offset configurations of all cells on the same RRU must be the same. The frame offset setting must be the same for all cells established on a single BBP, including FDD, TDD, and NB-IoT cells.

  • If the value of the TddFrameOffset parameter in the ENodeBFrameOffset MO is changed, all activated TDD cells served by the eNodeB automatically reset. In this case, TDD CSPC or DL CoMP services automatically restart if the eNodeB is equipped with a centralized controller and TDD CSPC or DL CoMP is enabled.

    If the value of the FddFrameOffset parameter in the ENodeBFrameOffset MO is changed, all activated FDD cells served by the eNodeB automatically reset. In this case, FDD CSPC services automatically restart if the eNodeB is equipped with a centralized controller and FDD CSPC is enabled.

Parameters

ID Name Description
TddFrameOffset TDD Frame Offset

Meaning: Indicates the offset of the start time of a cell frame against a reference clock source. This offset applies to all LTE TDD cells served by an eNodeB.

GUI Value Range: 0~261120,275943~307200

Unit: Ts

Actual Value Range: 0~261120,275943~307200

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If LTE TDD coexists with another TDD system (for example, WiMAX, TD-SCDMA, or PHS) and their spectrums are close to each other, inconsistency in uplink and downlink timeslots between systems may lead to high interference between them. This parameter is used to adjust the start time of all LTE TDD cell frames so that the uplink and downlink timeslots of LTE TDD are aligned with those of the other TDD system.

Carrier aggregation (CA) in LTE TDD requires time synchronization between carriers. Therefore, all cells must be configured with the same frame offset to implement CA.

Inconsistent frame offsets between carriers in FDD+TDD CA scenarios may decrease the proportion of UEs on which FDD+TDD CA takes effect.

Applicable Mode: L-TDD
FddFrameOffset FDD Frame Offset

Meaning: Indicates the offset of the start time of a cell frame against a reference clock source. This offset applies to all LTE FDD cells and all NB-IoT cells served by an eNodeB. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: 0~261120,275943~307200

Unit: Ts

Actual Value Range: 0~261120,275943~307200

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Carrier aggregation (CA) in LTE FDD requires time synchronization between carriers. Therefore, all cells must be configured with the same frame offset to implement CA.

Different frame offsets between carriers in FDD+TDD CA scenarios may decrease the proportion of UEs on which FDD+TDD CA takes effect.

Applicable Mode: L-FDD, L-NB-IOT
FrameOffsetAutoCorrectSw Frame Offset Auto Correct Switch

Meaning: Indicates whether to enable automatic frame offset correction. If this option is selected and the frame offset of a cell is different from that of its neighboring cells, the eNodeB automatically changes the frame offset of this cell to that of the neighboring cells. If this option is deselected, the eNodeB cannot automatically change the frame offset of a cell. This parameter applies only to LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

To modify the eNodeB-level frame offsets with the parameters as follows: 
TDD Frame Offset: 0, FDD Frame Offset: 0, 
run the following command: 
MOD ENODEBFRAMEOFFSET: TddFrameOffset=0, FddFrameOffset=0;
