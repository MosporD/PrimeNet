Modify eMTC SIB Configuration (MOD EMTCSIBCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify eMTC SIB configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EmtcSibId eMTC SIB ID

Meaning: Indicates the SIB type of an eMTC cell. SIB types supported by an eMTC cell include SIB2, SIB3, SIB4, SIB5, and SIB14. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SIB2(SIB2), SIB3(SIB3), SIB4(SIB4), SIB5(SIB5), SIB14(SIB14)

Unit: None

Actual Value Range: SIB2, SIB3, SIB4, SIB5, SIB14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The EmtcSibPeriod parameter in the EmtcSibConfig MO can be set to INVALID only if the EmtcSibId in the EmtcSibConfig is set to SIB5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EmtcSibPeriod eMTC SIB Period

Meaning: Indicates the SIB transmission period in an eMTC cell. This parameter is valid only when the EmtcSibId parameter is set. If this parameter is set to RF32 and the EmtcSibId parameter is set to SIB2, the transmission period of SIB2 in an eMTC cell is 320 ms. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF8(RF8), RF16(RF16), RF32(RF32), RF64(RF64), RF128(RF128), RF256(RF256), RF512(RF512), INVALID(INVALID)

Unit: None

Actual Value Range: RF8, RF16, RF32, RF64, RF128, RF256, RF512, INVALID

MML Default Value: None

Recommended Value: RF64(RF64)

Parameter Relationship:

-Configuration constraints:

  • The EmtcSibPeriod parameter in the EmtcSibConfig MO can be set to INVALID only if the EmtcSibId in the EmtcSibConfig is set to SIB5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates fewer SIB transmissions in a unit time and a smaller amount of system resources used for the transmissions. This, however, may result in a longer delay for UEs to receive the SIBs. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify the eMTC SIB Configuration with the parameters as follows: Local cell ID: 0, eMTC SIB ID: SIB2, eMTC SIB Period: RF16, run the following command:
MOD EMTCSIBCONFIG: LocalCellId=0, EmtcSibId=SIB2, EmtcSibPeriod=RF16;
