Modify LAA Cell Coexist Parameters (MOD CELLLAACOEXISTPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the LAA Coexist parameters about a LAA cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be executed only when WorkMode is set to LAA and a CellLaaCoexistPara MO instance has been configured.

  • Cell reestablishment occurs if the value of the CoexistMode parameter is changed from LBT_TYPEA or LBT_TYPEB to ALWAYS_ON or from ALWAYS_ON to LBT_TYPEA or LBT_TYPEB. Perform this operation with caution.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
CoexistMode Coexist Mode

Meaning: Indicates the coexistence mode of an LAA cell. The value ALWAYS_ON indicates that the LAA cell is always enabled and does not share channels with other equipment. The values LBT_TYPEA and LBT_TYPEB indicate two LBT types for coordination between LAA SCells when these cells are served by one RRU. For details, see "Channel access procedures for LAA" in 3GPP 36.213. The value LBT_TYPEA applies only to non-RF combination scenarios or scenarios where the LsbSwitch parameter is set to OFF. This parameter applies only to LTE TDD.

Since the LTE-U function has been removed, the values STATIC_DUTY and DYNAMIC_DUTY are invalid. Although the configuration interface in this version supports synchronization and delivery of these values, the system does not use these values. Therefore, avoid using the value STATIC_DUTY or DYNAMIC_DUTY.

GUI Value Range: ALWAYS_ON(ALWAYS_ON), STATIC_DUTY(STATIC_DUTY), DYNAMIC_DUTY(DYNAMIC_DUTY), LBT_TYPEA(LBT_TYPEA), LBT_TYPEB(LBT_TYPEB)

Unit: None

Actual Value Range: ALWAYS_ON, STATIC_DUTY, DYNAMIC_DUTY, LBT_TYPEA, LBT_TYPEB

MML Default Value: None

Recommended Value: LBT_TYPEB(LBT_TYPEB)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
HighInterfDutyThd High Interference Duty Threshold

Meaning: Indicates the threshold of the severe interference duty ratio in an LAA cell. If the interference duty ratio in an LAA cell exceeds this threshold, the duration of continuous interference to this cell is longer than the value specified by the HighInterfDurationThd parameter in the CellLaaCoexistPara MO, and the FcsMode parameter in the CellAlgoSwitch MO is set to AUTO(AUTO), FCS is automatically triggered once, updating the operating frequency of the LAA cell. This parameter applies only to LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
HighInterfDurationThd High Interference Duration Threshold

Meaning: Indicates the threshold of the duration in which severe continuous interference occurs to an LAA cell. If the interference duty ratio in an LAA cell exceeds the value of the HighInterfDutyThd parameter in the CellLaaCoexistPara MO, the duration of continuous interference to this cell exceeds this threshold, and the FcsMode parameter in the CellAlgoSwitch MO is set to AUTO(AUTO), FCS is automatically triggered once, updating the operating frequency of the LAA cell. This parameter applies only to LTE TDD.

GUI Value Range: 60~3600

Unit: s

Actual Value Range: 60~3600

MML Default Value: None

Recommended Value: 600

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
LbtPriority LBT Priority

Meaning: Indicates the channel access priority class for using the listen before talk (LBT) coexistence technology.

An RRU uses different LBT parameters to implement channel clear access (CCA) based on channel access priority classes. Channel access priority classes 1 to 4 are defined in section 15.1.1 of 3GPP TS 36.213, and channel access priority classes 15 and 16 are extended proprietary classes. This parameter applies only to LTE TDD.

GUI Value Range: 1~4,15~16

Unit: None

Actual Value Range: 1~4,15~16

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
CcaThdOffset CCA Threshold Offset

Meaning: Indicates the offset against the energy detection threshold set for an LAA cell. The listen before talk (LBT) energy detection threshold is the sum of the value of this parameter and the value of the FcsInterfThd parameter in the CellLaaFcsPara MO. For details about the energy detection threshold, see section 15.1.4 of 3GPP TS 36.213. This parameter applies only to LTE TDD.

GUI Value Range: -20~20

Unit: dB

Actual Value Range: -20~20

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, there is a high probability that interference is detected and there is a low probability that the channel is occupied. If this parameter is set to a large value, there is a low probability that interference is detected and there is a high probability that the channel is occupied; however, the interference between difference pieces of unlicensed equipment is high.

Applicable Mode: L-TDD
LsbSwitch LSB Switch

Meaning: Indicates whether to implement the LBT synchronization boundary (LSB) algorithm by using RHUB-based coordination between MPMUs involved in RF combination of an LAA cell. If this parameter is set to ON, the RHUB is used to implement the LSB algorithm to synchronize channel occupation between the MPMUs involved in RF combination. If this parameter is set to OFF, the LBT procedure is independently implemented for each MPMU involved in RF combination and the RHUB is not required for coordination. If RRUs are used, this parameter is invalid. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: If there is no interference between pRRUs or the distance between pRRUs is greater than 50 m, the recommended value is OFF. If there is interference between pRRUs or the distance between pRRUs is less than or equal to 50 m, the recommended value is ON. If RRUs are used, the recommended value is OFF.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the cell performance is better in scenarios where there is interference between pRRUs. If this parameter is set to OFF, the cell performance is better in scenarios where there is no interference between pRRUs.

Applicable Mode: L-TDD
TpcPowerAdjCqiThld TPC Power Adjustment CQI Threshold

Meaning: Indicates the CQI threshold for triggering TPC for the LAA cell in the specified frequency range. This parameter applies only to LTE TDD.

GUI Value Range: 10~15

Unit: None

Actual Value Range: 10~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If TPC is enabled, a large value of this parameter leads to a high CQI threshold for triggering TPC for power reduction and higher average cell power; a small value of this parameter leads to a low CQI threshold for triggering TPC for power reduction and lower average cell power.

Applicable Mode: L-TDD

Example

To modify Coexist parameters as follows: Local cell ID: 1, Coexist Mode is STATIC_DUTY:
MOD CELLLAACOEXISTPARA: LocalCellId=1, CoexistMode=STATIC_DUTY;
