Modify eNodeB Flow Control Parameter (MOD ENODEBFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the eNodeB Flow Control Parameter.

Note

None.

Parameters

ID Name Description
AdaptUnsyncTimerLen Adaptive Unsynchronized Timer Length

Meaning: Indicates whether an adaptive asynchronization UE is selected when the adaptive asynchronization function is enabled. If a UE does not transmit or receive data for a period of time that is longer than the AdaptUnsyncTimerLen parameter value, the UE is a candidate adaptive asynchronization UE. When this parameter value is larger than or equal to the QCIPARA.UeInactiveTimerForQci parameter value, the adaptive asynchronization function does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~20

Unit: s

Actual Value Range: 1~20

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value leads to more candidate adaptive asynchronization UEs. When this parameter is set to an extremely small value, adaptive asynchronization UEs may initiate the uplink synchronization, and therefore signaling overload in the network may increase. A larger value leads to fewer candidate adaptive asynchronization UEs. When this parameter value is equal to the QCIPARA.UeInactiveTimerForQci parameter value, the adaptive asynchronization function does not take effect.

Applicable Mode: L-FDD, L-TDD
AdaptUnsyncUserNumThd Adaptive Unsynchronized User Num Threshold

Meaning: Indicates the threshold of the ratio of uplink-synchronized UEs in a cell or a baseband processing unit. If the ratio of uplink-synchronized UEs in a cell or a baseband processing unit exceeds this threshold, the eNodeB adaptively enables some UEs that do not transmit or receive data for a period of time greater than the AdaptUnsyncTimerLen parameter value to enter the asynchronization state. As a result, PUCCH resources can be released and used by other UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher probability of triggering adaptive asynchronization, and higher access success rate and handover success rate when there are many UEs in the network. If this parameter is set to an extremely small value, too many UEs will enter the adaptive asynchronization mode, and therefore signal overheads in the network increase. A larger value of this parameter leads to lower probability of triggering adaptive asynchronization. When the network is busy and the number of UEs in a cell reaches the maximum number of UEs that can be supported by a cell or a baseband processing unit, new UEs are not allowed to access the network.

Applicable Mode: L-FDD, L-TDD
DynAcBarPolicyMode Dynamic AC Barring Policy Mode

Meaning: Indicates the policy of determining cell congestion for intelligent AC control, dynamic service specific access control (SSAC), and extended access barring (EAB).

When this parameter is set to FLOWCONTROL, an eNodeB determines the congestion state of a cell based on the flow control status.

When this parameter is set to CPULOAD, an eNodeB determines the congestion state of a cell based on the CPU load threshold. When the CPU load of the main control board or baseband processing unit (BBP) serving a cell is greater than or equal to the CPU load threshold, the eNodeB determines that the cell is in a congestion state. The CPU load threshold is specified by the CpuLoadThd parameter.

GUI Value Range: FLOWCONTROL(FLOWCONTROL), CPULOAD(CPULOAD)

Unit: None

Actual Value Range: FLOWCONTROL, CPULOAD

MML Default Value: None

Recommended Value: FLOWCONTROL(FLOWCONTROL)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to FLOWCONTROL, access control is triggered after the cells start flow control, and user experience is affected after the cells start flow control.

If this parameter is set to CPULOAD and the CpuLoadThd parameter is set to a value less than 80%, a large number of UEs are not allowed to access the network, and user experience in cell access is affected, and the busy hour call attempt (BHCA) specifications may not be reached in scenarios where CPU resources are not fully utilized.

Applicable Mode: L
CpuLoadThd CPU Load Threshold

Meaning: Indicates the CPU load threshold of a board. If the CPU load of a main control board or baseband processing unit serving the cells is greater than or equal to this parameter value, the cells are congested. If the CPU load is less than this parameter value, the cells are not congested. This parameter takes effect only when the DynAcBarPolicyMode parameter is set to CPULOAD(CPULOAD).

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability for triggering access control, a greater impact on user experience, and a greater impact for relieving cell congestion. A larger value of this parameter results in the opposite effects.

Applicable Mode: L
McpttMsgCntSwitch MCPTT Message Count Switch

Meaning: Indicates the configuration level switch of the number of access messages for MCPTT services. If this parameter is set to OFF, service access is not affected by the number of access messages. If this parameter is set to HIGH, MEDIUM, or LOW, the service access number differs depending on the configuration level. The values of HIGH, MEDIUM, and LOW indicate the high, medium, and low allowed service access numbers, respectively. This parameter applies only to LTE FDD.

GUI Value Range: OFF, HIGH, MEDIUM, LOW

Unit: None

Actual Value Range: OFF, HIGH, MEDIUM, LOW

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to OFF, network performance is not affected. When this parameter is set to HIGH, the MCPTT service access success rate increases slightly, and the number of RRC_CONNECTED UEs of common services decreases slightly. When this parameter is set to MEDIUM, the MCPTT service access success rate further increases, and the number of RRC_CONNECTED UEs of common services further decreases. When this parameter is set to LOW, the MCPTT service access success rate increases noticeably, and the number of RRC_CONNECTED UEs of common services decreases noticeably.

Applicable Mode: L-FDD
DynAcBarringTrigAllCellSw Dynamic AC Barring Trigger All Cell Switch

Meaning: Indicates whether dynamic access class (AC) control is triggered and takes effect on all cells on a board. If this parameter is set to ON, dynamic AC control is triggered and takes effect on all cells based on the board flow control status. If this parameter is set to OFF, dynamic AC control is triggered and takes effect on heavy-load cells based on flow control. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, experience of UEs at low access levels to access low-load cells deteriorates and system capacity decreases. If this parameter is set to OFF, only experience of UEs at low access levels to access high-load cells deteriorates and system capacity increases compared with that when the parameter is set to ON.

Applicable Mode: L-FDD, L-TDD
NsaFlowCtrlStrategy NSA Flow Control Strategy

Meaning: Indicates the NSA flow control policy. If this parameter is set to USER_CAPACITY_PREFERRED, the policy is UE capacity preferred. In this case, when the CPU usage is high, the eNodeB performs flow control over SCG addition for NSA UEs, to preferentially ensure that more UEs can access the network. If this parameter is set to NSA_SCG_PREFERRED, the policy is SCG addition for NSA UEs preferred. In this case, when the CPU usage is high, the eNodeB still allows SCG addition for NSA UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: USER_CAPACITY_PREFERRED(USER_CAPACITY_PREFERRED), NSA_SCG_PREFERRED(NSA_SCG_PREFERRED)

Unit: None

Actual Value Range: USER_CAPACITY_PREFERRED, NSA_SCG_PREFERRED

MML Default Value: None

Recommended Value: USER_CAPACITY_PREFERRED(USER_CAPACITY_PREFERRED)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to USER_CAPACITY_PREFERRED, NSA flow control is started when the CPU usage is high. In this case, the number of SCG additions decreases, and the eNodeB allows more UEs to access the network. If this parameter is set to NSA_SCG_PREFERRED, SCG addition is allowed even when the CPU usage is high. The SCG procedure consumes CPU resources, and therefore the system can accommodate fewer UEs.

Applicable Mode: L-FDD, L-TDD

Example

To set the Adaptive Unsynchronized Timer Length to 5 seconds, run the following command:
MOD ENODEBFLOWCTRLPARA: AdaptUnsyncTimerLen=5;
