Modify eNodeB US Policy Configuration (MOD ENODEBUSPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of policies applied to UEs running unlimited services in an eNodeB.

Note

  • If whether a UE is a UE running unlimited services is determined based on the SPIDs defined by the operator, operators need to specify the SPID for the service policy applied to UEs running unlimited services.

  • If whether a UE is a UE running unlimited services is determined based on IP address of the server dedicated to UEs running unlimited services, operators need to configure the parameters related to the server dedicated to UEs running unlimited services.

Parameters

ID Name Description
UsStrategy US Ue Strategy Select

Meaning: Indicates the policy based on which the eNodeB identifies UEs running unlimited services.

If the UsBasedSpecificSPID option is selected, the eNodeB identifies UEs running unlimited services based on the SPIDs specified by the operator using the UsUeSpid parameter in the UsUeSpidConfig MO. This option applies only to LTE FDD and LTE TDD.

If the UsBasedSpecificIPAdd option is selected, the eNodeB identifies UEs running unlimited services based on the IP address of the server dedicated to UEs running unlimited services. Operators need to set the parameters in the ServerConfig MO for this server. This option applies only to LTE FDD and LTE TDD.

If the UsBasedSpecificTraceID option is selected, the eNodeB identifies that UEs are running unlimited services if an end-to-end tracing task with a dedicated trace ID starts for the UEs.

If the UsBasedIMEISV option is selected, the eNodeB identifies UEs running unlimited services based on the IMEISVs. Operators need to configure parameters related to the IMEISV information for UEs running unlimited services. This option applies only to LTE TDD.

If the UsBasedSpecificSpidIpAddress option is selected, the eNodeB identifies UEs running unlimited services based on both the SPIDs and server IP address. Operators need to specify the SPIDs and server IP address of UEs running unlimited services. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: UsBasedSpecificSPID(UsBasedSpecificSPID), UsBasedSpecificIPAdd(UsBasedSpecificIPAdd), UsBasedSpecificTraceID(UsBasedSpecificTraceID), UsBasedIMEISV(UsBasedIMEISV), UsBasedSpecificSpidIpAddress(UsBasedSpecificSpidIpAddress)

Unit: None

Actual Value Range: UsBasedSpecificSPID, UsBasedSpecificIPAdd, UsBasedSpecificTraceID, UsBasedIMEISV, UsBasedSpecificSpidIpAddress

MML Default Value: None

Recommended Value: UsBasedSpecificSPID

Parameter Relationship:

-Configuration constraints:

  • The UsBasedSpecificSpidIpAddress option of the UsStrategy parameter in the eNodeBUSParaCfg MO is mutually exclusive with the BigPackageIdentify parameter in this MO and mutually exclusive with all of the following options of the UsStrategy parameter: UsBasedSpecificSPID, UsBasedSpecificIPAdd, UsBasedSpecificTraceID, and UsBasedIMEISV.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If UEs are treated as US UEs (UEs running unlimited services), KPIs of the US UEs related to throughput, latency, and data rate improve. KPIs of common UEs may deteriorate because the resource priorities of the common UEs become relatively lower.

Applicable Mode: L

UsUeInactiveTimer US Ue Inactive Timer

Meaning: Indicates the length of the UE inactivity timer for UEs. If the eNodeB detects that such a UE has neither received nor sent data for a duration exceeding the value of this parameter, the eNodeB releases the RRC connection for the UE. If this parameter is set to 0, the UE inactivity timer is not used. If the parameter setting is changed, the change applies to UEs that newly access the network.

GUI Value Range: 0~3600

Unit: s

Actual Value Range: 0~3600

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in earlier RRC connection releases for UEs without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger value of this parameter results in later RRC connection releases for UEs without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.

Applicable Mode: L
IPDetectInterval US IP Detect Interval

Meaning: Indicates the packet interval at which the eNodeB parses the IP headers of the downlink packets for UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3600

Unit: None

Actual Value Range: 0~3600

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in more frequent downlink packet parsing. Therefore, the eNodeB can detect UEs running unlimited services more quickly. However, a smaller value of this parameter results in a higher load of the baseband processing unit. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
UsUeDlPriorityFactor US Downlink scheduling priority factor

Meaning: Indicates the weight factor used to calculate DL scheduling priorities for UEs running unlimited services. This parameter is used to provide preferential guarantee for UEs running unlimited services. If the parameter is set to a value in the range of 1 to 999, the priority is calculated using the specified weight factor. If this parameter is set to 1000, UEs running unlimited services have the highest priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter is used to adjust the DL scheduling priorities for UEs running unlimited services when service assurance for UEs running unlimited services is enabled. A smaller value of this parameter results in a smaller downlink bandwidth allocated to such UEs. A larger value of this parameter results in the opposite effect.

Applicable Mode: L-FDD, L-TDD

UsUESTMSIKeepAliveTimer US UE S-TMSI Keep Alive Timer

Meaning: Indicates the length of the S-TMSI keep-alive timer for UEs running unlimited services. When the eNodeB detects such a UE based on the IP address of a dedicated server, the eNodeB starts the S-TMSI keep-alive timer for the UE. If the UE initiates an RRC connection setup procedure towards the eNodeB before the timer expires, the eNodeB treats the UE as an unlimited-service UE. If the UE initiates the procedure after the timer expires, the eNodeB treats the UE as a common UE. For details about S-TMSIs, see 3GPP TS 36.331. If this parameter is set to 0, the timer mechanism does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~120

Unit: min

Actual Value Range: 0~120

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter indicates a shorter keep-alive timer and results in a smaller number of unlimited-service UEs on the network and higher throughput and shorter delay for common UEs.

A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
BigPackageIdentify Big Package Identification

Meaning: Indicates whether to use large-packet services as criterion for identifying UEs with unlimited services. If the volume of data to be transmitted for a service in the UE buffer exceeds a specified threshold, this service is a large-packet service. If this parameter is set to ON, a UE is identified based on the buffered data volume and the number of times the UE is scheduled. If certain conditions are met, the UE is identified as a UE running unlimited services. If this parameter is set to OFF, this identification criterion does not work. This parameter applies only to LTE FDD and LTE TDD.

UsNbUeStatusResponseTimer US NB-IoT UE Status Response Timer

Meaning: Indicates the length of the RLC-layer status report response timer for NB-IoT UEs running unlimited services (US NB-IoT UEs). If you need to change the parameter value, contact Huawei technical support. This parameter applies only to NB-IoT.

GUI Value Range: 0~60000

Unit: ms

Actual Value Range: 0~60000

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Others:

  • This timer affects the RLC-layer status report response. A larger value of this parameter results in a lower frequency of status reporting, decreasing the probability of frequent status report scheduling. However, this results in a higher probability that the send window size changes to 0, thereby reducing the transmission rate. A smaller value of this parameter results in a higher frequency of status reporting. This ensures a timely acknowledgment of data in the send window of the transmit end and the transmission rates. However, this increases the probability of frequent status report scheduling and repeated transmissions, thereby wasting resources.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

UsUeExitDetectionTimes US UE Exit Detection Times

Meaning: Indicates the number of times it is detected that a UE running unlimited services (referred to as a US UE) exits a specific SPID and a specific IP address before the UE is finally determined to have exited the US state. This parameter takes effect only if the UsBasedSpecificSpidIpAddress option of the UsStrategy parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

Actual Value Range: 1~600

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a shorter time before a US UE is determined to have exited the US state and a less significant rate guarantee effect for the UE, but a smaller impact on the rates of non-US UEs. A larger value of this parameter results in the opposite effects.

Applicable Mode: L

Example

To modify the configurations of policies applied to UEs running unlimited services in an eNodeB, the US Ue Inactive Timer is 30s, run the following command:
MOD ENODEBUSPARACFG: UsUeInactiveTimer=30;
