List eNodeB MPRU ES Configuration (LST ENODEBMPRUES)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of eNodeB-level MPRU energy saving parameters.

Note

None.

Parameters

None.

Example

To query the settings of MPRU energy saving parameters, run the following command:
LST ENODEBMPRUES:;
The result is shown as follows:
+++    0        2019-12-05 17:31:48

Output Description

Field Description

MPRU Dormancy Downlink EARFCN

Indicates the downlink EARFCN of the basic coverage carrier to be reserved after the MPRU enters dormancy. If this parameter is set to -1, MPRU dormancy is disabled. This parameter applies only to LTE FDD and LTE TDD.

MPRU Dormancy Downlink PRB Usage Threshold(%)

Indicates the downlink PRB usage threshold for MPRU dormancy. If the downlink PRB usage of a carrier is lower than the value of this threshold, the MPRU enters dormancy. If the downlink PRB usage of a carrier is higher than the sum of the value of this threshold and a preset offset (5%), the MPRU exits dormancy. This parameter applies only to LTE FDD and LTE TDD.

MPRU Dormancy Minimum RSRP(dBm)

Indicates the minimum RSRP of the basic coverage carrier to be reserved after the MPRU enters dormancy. This parameter applies only to LTE FDD and LTE TDD.

MPRU Dormancy Start Time

Indicates the start time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.

MPRU Dormancy Stop Time

Indicates the end time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.
