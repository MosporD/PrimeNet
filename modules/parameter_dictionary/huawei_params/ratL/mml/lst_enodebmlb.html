List eNodeB MLB Configuration (LST ENODEBMLB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameter settings for eNodeB-level load balancing.

Note

None.

Parameters

None.

Example

To list the configurations of eNodeB-level parameters for load balancing, run the following command: :
LST ENODEBMLB:;
The result is shown as follows:
+++    0        2019-12-05 17:31:41
O&M    #806355973

Output Description

Field Description

Inter Frequency Idle MLB Mode

Indicates the mode for eNodeB-level inter-frequency MLB for UEs in idle mode. ADAPTIVE_PROPORTION: Indicates whether to enable load balancing in adaptive proportions. If the ADAPTIVE_PROPORTION option of this parameter and the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter are selected, the eNodeB timely adjusts the proportions of UEs to be released among frequencies based on the current proportions of UEs among frequencies and the preset proportions of UEs among frequencies, ensuring that the proportions of UEs in idle mode among frequencies approaches to the preset proportions. This option applies only to LTE FDD and LTE TDD.

Inter Frequency Idle MLB Interval(min)

Indicates the measurement period of eNodeB-level inter-frequency MLB for UEs in idle mode. If the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the eNodeB collects the number of uplink synchronized UEs at a period specified by the InterFreqIdleMlbInterval parameter. At the end of a measurement period, the eNodeB updates the policy for inter-frequency MLB in proportions for UEs in idle mode based on the measurement result. If the INTER_FREQ_IDLE_MLB_SWITCH option is deselected, the eNodeB does not update the policy for inter-frequency MLB in proportions for UEs in idle mode. This parameter applies only to LTE FDD and LTE TDD.

Inter Frequency Idle MLB Statistic Threshold

Indicates the sample threshold of eNodeB-level inter-frequency MLB for UEs in idle mode. This parameter specifies whether to update the load balancing policy based on the statistics of eNodeB-level inter-frequency MLB for UEs in idle mode. If the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the eNodeB periodically measures the average number of uplink synchronized UEs in each cell. If the sum of the average number of uplink synchronized UEs in all cells is greater than or equal to this parameter value, the eNodeB updates the policy of inter-frequency MLB in proportions for UEs in idle mode based on the measurement result. This parameter applies only to LTE FDD and LTE TDD.

DL CA LB Max Component Carrier Number

Indicates the maximum number of CCs aggregated for a CA UE whose load is to be transferred for load balancing in the downlink. If this parameter is set to 2CC(2CC), load of CA UEs using two CCs can be transferred for load balancing in the downlink. If this parameter is set to 3CC(3CC), load of CA UEs using two or three CCs can be transferred for load balancing in the downlink. This parameter applies only to LTE TDD.

CA UE Minimum Data Volume Ratio

Indicates the minimum data volume ratio between two CCs of a CA UE whose load is to be transferred. For example, if this parameter is set to 20, the minimum ratio of the data volume on a heavily loaded CC to that on a lightly loaded CC is 1/5. If this parameter is set to 0, the minimum ratio of the data volume on a heavily loaded CC to that on a lightly loaded CC is 0/1, that is, all data on the heavily loaded CC can be transferred to the lightly loaded CC. This parameter applies only to LTE TDD.
