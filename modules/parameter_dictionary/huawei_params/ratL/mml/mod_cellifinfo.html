Modify Cell Intermediate Frequency Information (MOD CELLIFINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell intermediate frequency information.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
IfDlCenterFreq Intermediate Frequency DL Center Frequency

Meaning: Indicates the downlink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.

GUI Value Range: 1000~1500

Unit: 0.1MHz

Actual Value Range: 100~150

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
IfOutputPower Intermediate Frequency Output Power

Meaning: Indicates the output power of the intermediate frequency. This parameter applies only to LTE FDD.

GUI Value Range: -300~100

Unit: 0.1dBm

Actual Value Range: -30~10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
IfPowerOffset Intermediate Frequency Power Offset

Meaning: Indicates the output power offset of the intermediate frequency. This parameter applies only to LTE FDD.

GUI Value Range: -300~100

Unit: 0.1dB

Actual Value Range: -30~10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
IfRxChannelGain Intermediate Frequency RX Channel Gain

Meaning: Indicates the RX channel gains of the intermediate frequency. This parameter applies only to LTE FDD.

GUI Value Range: -100~1000

Unit: 0.1dB

Actual Value Range: -10~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
IfUlCenterFreq Intermediate Frequency UL Center Frequency

Meaning: Indicates the uplink center frequency of the intermediate frequency. This parameter applies only to LTE FDD.

GUI Value Range: 500~1000

Unit: 0.1MHz

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To modify the settings of cell Intermediate information with the parameters as follows: local cell ID: 100, IfDlCenterFreq=1002, run the following command:
MOD CELLIFINFO: LocalCellId=100, IfDlCenterFreq=1002;
The result is shown as follows:
+++    0        2017-02-23 13:42:55
O&M    #806355072
%%MOD CELLIFINFO: LocalCellId=100, IfDlCenterFreq=1002;%%
RETCODE = 0  Operation succeeded.
