List UL Guardband Configurations (LST ULGUARDBANDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list UL guardband configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

To list the configuration of UlGuardBandCfg, run the following command:
LST ULGUARDBANDCFG: LocalCellId=1;

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within an eNodeB. This parameter applies only to NB-IoT.

High Frequency Guard Band(3.75kHz)

Indicates the NB-IoT high frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.

Low Frequency Guard Band(3.75kHz)

Indicates the NB-IoT low frequency edge guard space size. Subcarriers are divided by 3.75 kHz. The guard space size is represented by the number of subcarriers, which is used to reduce the interference caused by non-orthogonal subcarriers. This parameter applies only to NB-IoT.

Guard Band Between NPRACH and NPUSCH(3.75kHz)

Indicates the width of the guard band between the NPRACH and NPUSCH. This parameter applies only to NB-IoT.
