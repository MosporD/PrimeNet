Display the Dynamic Parameters of CA Group Cell (DSP CAGROUPCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the settings of dynamic parameters for a carrier aggregation (CA) group and the use of licenses in cells of the CA group.

Note

None.

Parameters

ID Name Description
CaGroupId CA Group Identity

Meaning: Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the dynamic information about a CA group, run the following command: :
DSP CAGROUPCELL:;
The result is shown as follows:

Output Description

Field Description

CA Group Identity

Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the ID of the eNodeB serving the cell. This parameter applies only to LTE FDD and LTE TDD.

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Peer eNodeB Id

Indicates the eNodeB ID of a cell that is in the same carrier aggregation (CA) group with the cell specified by the eNodeB ID and Local Cell ID parameters.

Peer Local Cell ID

Indicates the local cell ID of a cell that is in the same carrier aggregation (CA) group with the cell specified by the eNodeB ID and Local Cell ID parameters.

Data Link Status

Indicates the status of the data link between the cell specified by the eNodeB ID and Local Cell ID parameters and the cell specified by the Peer eNodeB Id and Peer Cell Id parameters.

Path RTD Delay(0.1microsecond)

Indicates the inter-cell round-trip delay (RTD). The parameter value is expressed in the unit of 0.1 microsecond. In inter-eNodeB CA in centralized or distributed multi-BBU interconnection scenarios or relaxed backhaul scenarios, the RTD between the inter-eNodeB cells is measured at high precision of 0.1 microsecond and the reported and displayed value is the actual measurement result. The displayed value is 0 if the cells involved are intra-eNodeB intra-BBU cells or eX2 (or X2) interfaces are not required between the cells. The displayed value is NULL in the following situations: (1) A related eX2 or X2 interface is down or a port fault occurs. (2) An eX2 or X2 interface is being set up. (3) The RTD is being measured. In other situations, a number indicating the RTD over the eX2 or X2 interface is displayed.

LTE-A Introduction(per cell)(FDD)

Indicates whether the license "LTE-A Introduction(per Cell)(FDD)" is used in the cell specified by the eNodeB ID and Local Cell ID parameters.

CA for Downlink 2CC in 40MHz(per Cell)(FDD)

Indicates whether the license "Carrier Aggregation for Downlink 2CC in 40MHz(per Cell)(FDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters.

Flexible CA from Multiple Carriers(Per Cell)(FDD)

Indicates whether the license "Flexible CA from Multiple Carriers(Per Cell)(FDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters.

LTE-A Introduction(TDD)

Indicates whether the license "LTE-A Introduction(TDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters.

Carrier Aggregation for Downlink 2CC in 40MHz(TDD)

Indicates whether the license "Carrier Aggregation for Downlink 2CC in 40MHz(TDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters.

Cell CA Config State

Indicates whether there are conflicts in the CA configurations of the cell. For intra-eNodeB CA, a cell can be configured into only one CA group. There will be a configuration conflict if a cell is configured into more than one CA group. For inter-eNodeB CA, there will be a configuration conflict if the cells in a CA group on the eNodeBs involved are not the same. This parameter applies only to LTE FDD and LTE TDD.

Carrier Aggregation for Downlink 3CC in 40MHz(per cell)(FDD)

Indicates whether the license "Carrier Aggregation for Downlink 3CC in 40MHz(per cell)(FDD)" is used in the cell specified by the eNodeB ID and Local Cell ID parameters.

Carrier Aggregation for Downlink 3CC in 60MHz(per cell)(FDD)

Indicates whether the license "Carrier Aggregation for Downlink 3CC in 60MHz(per cell)(FDD)" is used in the cell specified by the eNodeB ID and Local Cell ID parameters.

Carrier Aggregation for Downlink 3CC(TDD)

Indicates whether the license value of the license control item "Carrier Aggregation for Downlink 3CC(TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

Flexible CA from Multiple Carriers(TDD)

Indicates whether the license value of the license control item "Flexible CA from Multiple Carriers(TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

CA for Downlink 4CC and 5CC (TDD)

Indicates whether the license value of the license control item "Carrier Aggregation for Downlink 4CC and 5CC(TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

Carrier Aggregation for Uplink(TDD)

Indicates whether the license value of the license control item "Uplink Carrier Aggregation(TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

Cell FDD TDD indication

Indicates the duplex mode of the cell. If this parameter is set to CELL_FDD(FDD), the cell is an LTE FDD cell. If this parameter is set to CELL_TDD(TDD), the cell is an LTE TDD cell. If this parameter is set to UNKNOWN(UNKNOWN), the duplex mode of the cell is unknown.

FDD+TDD Downlink Carrier Aggregation(LTE TDD)

Indicates whether the license value of the license control item "FDD+TDD Downlink Carrier Aggregation(LTE TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

Carrier Aggregation for Uplink 2CC(FDD)

Indicates whether the license "Carrier Aggregation for Uplink 2CC(FDD)" is used in the cell specified by the eNodeB ID and Local Cell ID parameters.

FDD+TDD Downlink Carrier Aggregation(LTE FDD)

Indicates whether the license "FDD+TDD Downlink Carrier Aggregation(LTE FDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters. This parameter applies only to LTE FDD.

FDD+TDD Uplink Carrier Aggregation(LTE FDD)

Indicates whether the license "FDD+TDD Uplink Carrier Aggregation(LTE FDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters. This parameter applies only to LTE FDD.

FDD+TDD Uplink Carrier Aggregation(LTE TDD)

Indicates whether the license value of the license control item "FDD+TDD Uplink Carrier Aggregation(LTE TDD)" is consumed for a cell specified by the local cell ID and eNodeB ID. This parameter applies only to LTE TDD.

CA for Downlink 4CC and 5CC(FDD)

Indicates whether the license "Carrier Aggregation for Downlink 4CC and 5CC (FDD)" is used by the cell specified by the eNodeB ID and Local Cell ID parameters. This parameter applies only to LTE FDD.
