List CA group SCell configuration (LST CAGROUPSCELLCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list CA group SCell configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SCelleNodeBId SCell eNodeB ID

Meaning: Indicates the ID of the eNodeB serving the candidate SCell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

Unit: None

SCellLocalCellId SCell Local Cell ID

GUI Value Range: 0~255

LST CAGROUPSCELLCFG: LocalCellId=0;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

SCell eNodeB ID

Indicates the ID of the eNodeB serving the candidate SCell. This parameter applies only to LTE FDD and LTE TDD.

SCell Local Cell ID

Indicates the local cell ID of the candidate SCell. This parameter applies only to LTE FDD and LTE TDD.

SCell Blind Configuration Flag

Indicates whether the candidate SCell can be configured as an SCell for CA UEs in a blind manner.

In CA-group-based configuration mode, this parameter takes effect if the SccBlindCfgSwitch option of the CaAlgoSwitch parameter is selected. In adaptive configuration mode, this parameter takes effect regardless of the SccBlindCfgSwitch setting.

If this parameter is set to TRUE, the eNodeB can configure this candidate SCell as an SCell for CA UEs in a blind manner, without delivering A4-related measurement configurations to the CA UEs.

If this parameter is set to FALSE, the eNodeB cannot configure this candidate SCell as an SCell for CA UEs in a blind manner. The eNodeB must deliver the A4 measurement configurations related to the operating frequency of the cell to CA UEs before the eNodeB can configure the cell as an SCell. This parameter applies only to LTE FDD and LTE TDD.

SCell Priority

Indicates the priority of the cell being configured as an SCell. A larger value of this parameter indicates a higher priority level. The value 0 indicates that this cell cannot be configured as an SCell for CA UEs. This parameter applies only to LTE FDD and LTE TDD.

SCell A4 Offset(dB)

Indicates the offset to CarrAggrA4ThdRsrp in CA-group-based configuration mode. When a CA UE treats the cell specified by the LocalCellId parameter in the local eNodeB as its PCell, the UE reports event A4 pertaining to the candidate SCell specified by the SCelleNodeBId and SCellLocalCellId parameters to the eNodeB if the RSRP for the candidate SCell exceeds the sum of the CarrAggrA4ThdRsrp and SCellA4Offset parameter values. If the sum is greater than -43 dBm or less than -140 dBm, the threshold for event A4 takes the value -43 dBm or -140 dBm, respectively. This parameter applies only to LTE FDD and LTE TDD.

SCell A2 Offset(dB)

Indicates the offset to CarrAggrA2ThdRsrp in CA-group-based configuration mode. When a CA UE treats the cell specified by the LocalCellId parameter in the local eNodeB as its PCell, the UE reports event A2 pertaining to the SCell specified by the SCelleNodeBId and SCellLocalCellId parameters to the eNodeB if the RSRP for the SCell falls below the sum of the CarrAggrA2ThdRsrp and SCellA2Offset parameter values. If the sum is greater than -43 dBm or less than -140 dBm, the threshold for event A2 takes the value -43 dBm or -140 dBm, respectively. This parameter applies only to LTE FDD and LTE TDD.

SPID Group ID

Indicates the ID of an SPID group. If this parameter is set to a value ranging from 0 to 255, the candidate SCell cannot be configured as an SCell for UEs in this SPID group. If this parameter is set to 65535, this cell can be configured as an SCell for these UEs. This parameter applies only to LTE FDD and LTE TDD.
