Remove SPID Configuration (RMV SPIDGRPCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an SPID group.

Note

None.

Parameters

ID Name Description
SpidGrpId SPID Group ID

Meaning: Indicates the ID of an SPID group, which identifies a group of UEs whose SPIDs belong to the same group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StartSpid Start SPID

Meaning: Indicates the start SPID value. The value of an SPID defined in 3GPP specifications ranges from 1 to 256. However, this parameter can be set to 0. SPID 0 indicates the UEs that are not configured with SPIDs or whose SPIDs cannot be identified by the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • The value of StartSPID must be less than or equal to EndSPID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EndSpid End SPID

Meaning: Indicates the end SPID value. The value of an SPID defined in 3GPP specifications ranges from 1 to 256. However, this parameter can be set to 0. SPID 0 indicates the UEs that are not configured with SPIDs or whose SPIDs cannot be identified by the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the SPID group configuration with the parameters as follows: SPID Group ID: 1, Start SPID: 1, End SPID: 5, run the following command:
RMV SPIDGRPCFG: SpidGrpId=1, StartSpid=1, EndSpid=5;
