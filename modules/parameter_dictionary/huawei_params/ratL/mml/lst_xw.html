List XW Configuration (LST XW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of an Xw object.

Note

The LMPT board does not support this command.

Parameters

ID Name Description
XwId Xw ID

Meaning: Indicates the ID of the Xw object. This parameter applies only to LTE FDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the configuration of an Xw object, run the following command: 
LST XW:;
The result is shown as follows: 
+++    0        2016-06-16 19:35:11
O&M    #806354962
%%LST XW:;%%
RETCODE = 0  Operation succeeded.

List XW Configuration
---------------------
                           Xw ID  =  1
     End Point Group Config Flag  =  CPUP Config
Control Plane End Point Group ID  =  1
   User Plane End Point Group ID  =  1
                      User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

Xw ID

Indicates the ID of the Xw object. This parameter applies only to LTE FDD.

End Point Group Config Flag

Indicates whether to configure the control-plane endpoint group or user-plane endpoint group for the Xw MO. This parameter applies only to LTE FDD.

Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the Xw object. This parameter applies only to LTE FDD.

User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the Xw object. This parameter applies only to LTE FDD.

User Label

Indicates the user-defined information of the Xw object. This parameter applies only to LTE FDD.
