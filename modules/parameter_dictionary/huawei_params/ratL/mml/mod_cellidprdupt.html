Modify Parameter for Periodic Cell ID Update (MOD CELLIDPRDUPT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the cell ID periodic updating algorithm.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The cell ID broadcast in the system information is updated after the command execution, which may affect the handovers from the local cell to its neighboring cells. Therefore, set the time at which the algorithm for periodically updating cell IDs begins to take effect to the same value for all cells in the E-UTRAN, for example, a low-traffic time point in the next morning of the command execution.In addition, for cells whose adjacent cells are provided by other vendors' equipment, this time also must be the same among all cells to decrease the impact on handovers between cells provided by different vendors' equipment.

  • When prdUptSwitch is ON, the CGI in Uu Interface Trace maybe different with it in NCL recorded in SON log.

Parameters

ID Name Description
PrdUptSwitch Period update switch

Meaning: Indicates the switch for the algorithm for periodically updating cell IDs. If this parameter is set to BOOLEAN_TRUE, cell IDs are periodically updated, inserted into the system information, and broadcast to the associated UEs once the time at which the algorithm begins to take effect is reached. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: None

Recommended Value: BOOLEAN_FALSE(False)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ActionTime Action time

Meaning: Indicates the time at which the algorithm for periodically updating cell IDs begins to take effect. If the switch for the algorithm is turned on, cell IDs are periodically updated, inserted into the system information, and broadcast to the associated UEs once the time specified by this parameter is reached. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2000-01-01T00:00:00+00:00~2099-12-31T23:59:59+00:00

Unit: None

Actual Value Range: 2000-01-01T00:00:00+00:00~2099-12-31T23:59:59+00:00

MML Default Value: None

Recommended Value: 2000-01-01T00:00:00+00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Period Period

Meaning: Indicates the period of updating cell IDs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~365

Unit: day

Actual Value Range: 1~365

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the configuration of the cell ID periodic updating algorithm with the parameters as follows: PrdUptSwitch: BOOLEAN_TRUE, ActionTime: 2011-05-16 16:07:43, run the following command:
MOD CELLIDPRDUPT: PrdUptSwitch=BOOLEAN_TRUE, ActionTime=2011&05&16&16&07&43;
