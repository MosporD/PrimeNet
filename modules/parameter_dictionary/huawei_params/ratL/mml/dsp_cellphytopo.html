Display Cell Physical Topology (DSP CELLPHYTOPO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the physical topology of cells. The physical topology of auxiliary cells on an auxiliary eNodeB for a primary eNodeB can be queried by specifying the primary eNodeB's eNodeBId on the auxiliary eNodeB. On the primary eNodeB, eNodeBId is invalid.

Note

None.

Output Description

Field Description

eNodeB ID

Indicates the ID of the eNodeB.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

Connected BBP Port Information

Indicates the information about the CPRI port on the baseband processing board that is directly connected to the RF unit serving a cell. The information includes the cabinet, subrack, slot, and CPRI port numbers. A hyphen (-) represents an invalid value.

Served BBP Information

Indicates the cabinet, subrack, and slot of the baseband processing unit on which the cell is set up is located.

Served Bbp Primary Secondary Mode

Indicates whether a BBP serving the cell is a primary or secondary BBP. If the value of this parameter is PRIMARY for a slot, the BBP in this slot is the primary BBP, which carries the MAC layer resources of the cell. If the value of this parameter is SECONDARY for a slot, the BBP in this slot is a secondary BBP, which carries the physical layer resources of the cell.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
