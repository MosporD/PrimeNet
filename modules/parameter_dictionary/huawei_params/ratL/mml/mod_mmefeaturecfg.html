Modify MME Feature Configuration (MOD MMEFEATURECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the MME features.

Note

None.

Parameters

ID Name Description
S1InterfaceId S1Interface ID

Meaning: Indicates the ID of an S1 interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MdtEnable MME supporting MDT or not

Meaning: Indicates whether the MME at the other end of the S1 interface supports Huawei-proprietary positioning procedures, which are included in minimization of drive tests (MDT). The value DISABLE indicates that the MME does not support the procedures and therefore the eNodeB cannot obtain UE location information from the MME through the procedures. The value ENABLE indicates the opposite. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

1.Turn On MdtEnable Switch:
MOD MMEFEATURECFG: S1InterfaceId=0, MdtEnable=ENABLE;

2.Turn Off MdtEnable Switch:
MOD MMEFEATURECFG: S1InterfaceId=0, MdtEnable=DISABLE;
