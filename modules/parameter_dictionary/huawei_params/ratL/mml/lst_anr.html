List ANR (LST ANR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the ANR configuration.

Note

None.

Parameters

None.

Example

LST ANR:;

Output Description

Field Description

ANR delete cell threshold(%)

Indicates the threshold for removing a neighbor relationship with a cell by ANR based on the handover success rate. The threshold is the percentage of the number of successful handovers to the total number of handovers from the local cell to the neighboring cell.

For example, an external cell has been configured as a neighboring cell for each cell served by the eNodeB, automatic removal of these neighbor relationships by ANR is allowed, and the control mode is Auto_Mode. If the success rate of handovers from each cell under the eNodeB to this neighboring cell within a measurement period is lower than or equal to this threshold, this external cell and the neighbor relationships with this cell are automatically removed.

This parameter applies only to LTE FDD and LTE TDD.

Least Handover Num for Statistic

Indicates the threshold (expressed as the total number of handover attempts to a neighboring cell) above which ANR determines whether to remove the neighbor relationship with this cell from the NRT or set the NoHoFlag parameter for this cell to FORBID_HO_ENUM on the basis of the handover success rate. This parameter applies only to LTE FDD and LTE TDD.

Statistic cycle(min)

Indicates the length of a measurement period within which the handover success rate is collected for ANR to determine whether to remove neighbor relationships or set NoHoFlag for neighboring cells to FORBID_HO_ENUM. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Specified Service Cell Query Switch

Indicates whether to query specified-service cells for ANR. Set this parameter based on the operator policy.

SPEC_CELL_FLAG_QUERY_SW: Indicates whether the eNodeB checks with the MAE whether a newly added external cell is a specified-service cell. If this option is selected, the eNodeB checks with the MAE whether a newly added external cell is a specified-service cell. If this option is deselected, the eNodeB does not check with the MAE whether a newly added external cell is a specified-service cell. This option applies only to LTE FDD and LTE TDD.

Fast ANR PCI report amount

Indicates the number of periodic measurement reports sent for fast ANR. This parameter applies only to LTE FDD and LTE TDD.

Fast ANR PCI report interval

Indicates the interval at which periodic measurement reports are sent for fast ANR. This parameter applies only to LTE FDD and LTE TDD.

Fast ANR checking period(min)

Indicates the fast ANR checking timer. When the timer is expired, the eNodeB automatically checks whether to disable fast ANR. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Fast ANR measurement RSRP threshold(dBm)

Indicates the RSRP threshold for intra-RAT fast ANR. If the signal quality in a neighboring E-UTRAN cell reported by a UE is lower than this threshold, the cell is not automatically added as an external cell of the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

IntraRat Fast ANR measurement UE number

Indicates the maximum allowed number of UEs performing intra-RAT measurements for fast ANR. After the number of UEs performing intra-RAT measurements for fast ANR reaches the maximum number, no more UEs will perform intra-RAT measurements for fast ANR. This parameter applies only to LTE FDD and LTE TDD.

InterRat Fast ANR measurement UE number

Indicates the maximum allowed number of UEs performing inter-RAT measurements for fast ANR. After the number of UEs performing inter-RAT measurements for fast ANR reaches the maximum number, no more UEs will perform inter-RAT measurements for fast ANR. This parameter applies only to LTE FDD and LTE TDD.

IntraRat Fast ANR valid measurement min UE number

Indicates the threshold above which the eNodeB enters the monitoring state for intra-RAT fast ANR. The threshold is expressed as the number of UEs that have performed measurements for intra-RAT fast ANR. This parameter applies only to LTE FDD and LTE TDD.

InterRat Fast ANR valid measurement min UE number

Indicates the threshold above which the eNodeB enters the monitoring state for inter-RAT fast ANR. The threshold is expressed as the number of UEs that have performed measurements for inter-RAT fast ANR. This parameter applies only to LTE FDD and LTE TDD.

Optimization Mode

Indicates the mode in which the ANR algorithm works. If this parameter is set to FREE, the eNodeB automatically optimizes neighbor relationships using ANR.

If this parameter is set to CONTROLLED, the eNodeB reports the neighbor relationships to be optimized to the MAE and the optimization is subject to manual confirmation. However, whether the eNodeB reports neighbor relationships with E-UTRAN cells, UTRAN cells, and GERAN cells is further controlled by the CellAnrOptMode parameter. No parameter is designed to determine whether to report neighbor relationships with CDMA2000 cells. This parameter applies only to LTE FDD and LTE TDD.

Statistic Cycle For Delete NRT (min)

Indicates the intra-RAT neighbor relationship removal evaluation period during which the eNodeB collects statistics on whether an intra-RAT neighboring cell has been detected by UEs and the number of handovers to the intra-RAT neighboring cell. The eNodeB uses the statistics to determine whether to remove the neighbor relationship when the number of neighbor relationships in the intra-RAT NRT has reached the maximum and a new neighbor relationship needs to be added to the NRT by ANR. This parameter is also used to determine whether to remove an external cell from an intra-RAT NCL. If there are four consecutive periods in which an external cell in the NCL has no corresponding entry in any NRT, and if the local eNodeB is not configured with an X2 interface with the peer eNodeB providing the external cell, the eNodeB removes the external cell from the NCL.

This parameter is also used to determine periodic removal of redundant neighbor relationships from an intra-RAT NRT. The neighbor relationship with the intra-RAT cell to which no UEs are handed over from the local cell within N consecutive periods is removed from the NRT. N is specified by the StatPeriodCoeff parameter. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Statistic Number For Delete NRT

Indicates the threshold of the total number of handovers from the local cell to all intra-RAT neighboring cells, above which the eNodeB determines whether to remove neighbor relationships from a full intra-RAT NRT or whether to periodically remove redundant neighbor relationships from an intra-RAT NRT.

Consider that the number of neighbor relationships in the NRT has reached its maximum and a new neighbor relationship needs to be added by ANR. If the total number of handovers (of all types) from the local cell to its intra-RAT neighboring cells in the previous removal evaluation period reaches this parameter value, removal of a neighbor relationship from the intra-RAT NRT can be triggered.

In periodic redundant neighbor relationship removal, the eNodeB removes redundant neighbor relationships if the total number of handovers (of all types) from the local cell to all intra-RAT neighboring cells reaches this parameter value for N consecutive removal evaluation periods. N is specified by the StatPeriodCoeff parameter. This parameter applies only to LTE FDD and LTE TDD.

ANR Active PCI Conflict Detection Switch

Indicates the switch used to enable or disable proactive PCI conflict detection. Within a specified duration after this switch is turned on, the eNodeB delivers measurement configurations for proactive PCI conflict detection to UEs that meet specific requirements. Then, the eNodeB starts the detection based on the measurement reports from the UEs. This parameter applies only to LTE FDD and LTE TDD.

Start time

Indicates the time the eNodeB starts PCI conflict detection or neighboring cell blacklist management. If the end time is the same as or earlier than the start time, the detection or management ends at the specified end time on the next day. This parameter applies only to LTE FDD and LTE TDD.

Stop time

Indicates the time the eNodeB stops PCI conflict detection or neighboring cell blacklist management. If the end time is the same as or earlier than the start time, the detection or management ends at the specified end time on the next day. This parameter applies only to LTE FDD and LTE TDD.

UTRAN Fast ANR RSCP threshold(dBm)

Indicates the received signal code power (RSCP) threshold for fast ANR with UTRAN. If the signal quality in a neighboring UTRAN cell reported by a UE is lower than this threshold, the cell is not automatically added as an external cell of the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GERAN Fast ANR RSSI threshold(dBm)

Indicates the received signal strength indicator (RSSI) threshold for fast ANR with GERAN. If the signal quality in a neighboring GERAN cell reported by a UE is lower than this threshold, the cell is not automatically added as an external cell of the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Set not handover attribute threshold(%)

Indicates the handover success rate threshold based on which ANR automatically sets NoHoFlag of a neighboring cell to FORBID_HO_ENUM. The threshold is the ratio of the number of successful handovers to the total number of handover attempts from the local cell to the neighboring cell. If the handover success rate within a measurement period is equal to or less than this threshold, ANR automatically sets NoHoFlag of the neighboring cell to FORBID_HO_ENUM. This parameter applies only to LTE FDD and LTE TDD.

Handover threshold for delete NRT

Indicates a threshold for removing a neighbor relationship from an E-UTRAN NRT. When the NRT reaches its capacity and ANR needs to add a new neighbor relationship to the NRT, ANR removes an old neighbor relationship with a cell from the NRT if the number of handovers to this cell is less than the threshold.

If this parameter is set to 0, ANR removes the neighbor relationship with a cell from an NRT not based on the number of handovers to this cell but based on the number of measurement reports on this cell.

If this parameter is set to another value, ANR can remove the neighbor relationship with a cell from an NRT if the number of handovers to this cell is less than the threshold. This parameter applies only to LTE FDD and LTE TDD.

Fast ANR Mode

Indicates the policy based on which fast ANR adds detected cells to NCLs and NRTs.

If this parameter is set to NCL_MODE, fast ANR adds a detected cell that meets certain conditions to an NCL only.

If this parameter is set to NCL_NRT_MODE, fast ANR adds a detected cell that meets certain conditions to an NCL and can add neighbor relationships with cells that meet certain conditions to NRTs based on NCLs.

If this parameter is set to NRT_MODE, fast ANR adds a detected cell that meets certain conditions and with which the neighbor relationship is not in an NRT of the source cell to an NCL and adds the neighbor relationship with the detected cell to an NRT of the source cell based on CGI reading. Neighbor relationships with cells that meet certain conditions cannot be directly added to NRTs based on NCLs. This parameter applies only to LTE FDD and LTE TDD.

Event ANR Mode

Indicates the policy based on which intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs.

If this parameter is set to BASED_NCL, intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs based on NCLs.

If this parameter is set to NOT_BASED_NCL, intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs based on CGIs reported by UEs instead of based on information in NCLs. This parameter applies only to LTE FDD and LTE TDD.

CA UE Chose Mode

Indicates the policy based on which the eNodeB selects CA UEs to perform CGI reading for ANR (excluding event-triggered ANR based on CA measurements or NSA DC measurements).

If this parameter is set to CA_UE_CAP, the eNodeB does not select the CA UEs that support the CA bands in the CA band combinations supported by the eNodeB.

If this parameter is set to CA_UE_CARRIER_NUM, the eNodeB does not select the CA UEs that are each served by more than one carrier.

If this parameter is set to ANR_UE_CAP, the eNodeB does not select the UEs that are incapable of CGI reading for ANR.

Anr Controlled Handover Strategy

Indicates whether the eNodeB can initiate handovers to a newly detected neighboring cell, with which the neighbor relationship is to be processed by the MAE.

When the OptMode parameter in the ANR MO is set to CONTROLLED, the eNodeB reports the newly detected neighboring cell to the MAE for manual confirmation. If this parameter is set to PERMIT_HO, the eNodeB initiates handovers to the newly detected neighboring cell before the corresponding neighbor relationship is manually confirmed. If this parameter is set to FORBID_HO, the eNodeB does not initiate handovers to the newly detected neighboring cell before the corresponding neighbor relationship is manually confirmed. This parameter applies only to LTE FDD and LTE TDD.

Smart Preallocation Mode

Indicates whether smart preallocation takes effect during ANR-triggered CGI reading. When SmartPreAllocationSwitch of the UlSchSwitch parameter is on, setting this parameter to DISABLE indicates that smart preallocation does not take effect, and setting this parameter to ENABLE indicates that smart preallocation takes effect. This parameter applies only to LTE FDD and LTE TDD.

No Handover Set Mode

Indicates whether the eNodeB directly sets NoHoFlag to FORBID_HO_ENUM for an intra-RAT neighboring cell or a neighboring NG-RAN cell if the neighboring cell meets the requirements on the number of handover attempts from the local cell to the neighboring cell and the handover success rate within a specified measurement period. When this parameter is set to NO_CHECK, the eNodeB directly sets NoHoFlag to FORBID_HO_ENUM for this neighboring cell. When this parameter is set to PCI_CHECK, the eNodeB first instructs the UE to read the CGI of the neighboring cell with the aim to detect unknown neighboring cells with the same PCI, and then determines whether to set NoHoFlag to FORBID_HO_ENUM for this neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

Utran Event ANR Mode

Indicates the policy based on which event-triggered ANR with UTRAN adds neighbor relationships to NRTs.

If this parameter is set to BASED_NCL, this type of ANR adds neighbor relationships to NRTs based on NCLs.

If this parameter is set to NOT_BASED_NCL, this type of ANR adds neighbor relationships to NRTs based on CGIs reported by UEs. This parameter applies only to LTE FDD and LTE TDD.

Geran Event ANR Mode

Indicates the policy based on which inter-RAT event-triggered ANR with GERAN adds neighbor relationships to NRTs.

If this parameter is set to BASED_NCL, event-triggered ANR with GERAN adds neighbor relationships to NRTs based on the NCL.

If this parameter is set to NOT_BASED_NCL, event-triggered ANR with GERAN adds neighbor relationships to NRTs based on CGIs reported by UEs rather than based on information in the NCL. This parameter applies only to LTE FDD and LTE TDD.

Event ANR With VoIP Mode

Indicates whether the eNodeB selects VoLTE UEs to perform ANR-related measurements. This parameter includes the following options:

UTRAN_EVENT_ANR_WITH_VOIP_MODE: The eNodeB selects UEs with QCI 1 bearers to perform measurements for event-triggered ANR with UTRAN only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GERAN_EVENT_ANR_WITH_VOIP_MODE: The eNodeB selects UEs with QCI 1 bearers to perform measurements for event-triggered ANR with GERAN only if this option is selected. This option applies only to LTE FDD and LTE TDD.

CDMA_EVENT_ANR_WITH_VOIP_MODE: The eNodeB selects UEs with QCI 1 bearers to perform measurements for event-triggered ANR with CDMA2000 only if this option is selected. This option applies only to LTE FDD and LTE TDD.

LTE_EVENT_ANR_WITH_VOIP_MODE: The eNodeB selects UEs with QCI-1 bearers to perform measurements for event-triggered ANR with E-UTRAN only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UTRAN Event ANR CGI Timer(0.5s)

Indicates the length of the timer of CGI reading for event-triggered ANR with UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GERAN Event ANR CGI Timer(0.5s)

Indicates the length of the timer of CGI reading for event-triggered ANR with GERAN. This parameter applies only to LTE FDD and LTE TDD.

NRT Delete Mode

Indicates the mode of automatically removing neighbor relationships by ANR. If event-triggered ANR and automatic neighbor relationship removal are enabled for an RAT, the following options related to this RAT take effect:

EUTRAN_DELREDUNDANCENCELL: If this option is selected, the eNodeB periodically determines neighboring E-UTRAN cells to which no UEs have been handed over from a local cell and removes the neighbor relationships with these cells from NRTs. This option applies only to LTE FDD and LTE TDD.

UTRAN_DELREDUNDANCENCELL: If this option is selected, the eNodeB periodically determines neighboring UTRAN cells to which no UEs have been handed over from a local cell, and removes the neighbor relationships with these cells from NRTs. This option applies only to LTE FDD and LTE TDD.

GERAN_DELREDUNDANCENCELL: If this option is selected, the eNodeB periodically determines neighboring GERAN cells to which no UEs have been handed over from a local cell, and removes the neighbor relationships with these cells from NRTs. This option applies only to LTE FDD and LTE TDD.

UTRAN_DELERRORNCELL: If this option is selected, the eNodeB periodically determines inappropriate neighboring UTRAN cells to which UEs are handed over with a success rate less than a specified threshold, and removes these UTRAN cells from the NCL and NRT. This option applies only to LTE FDD and LTE TDD.

GERAN_DELERRORNCELL: If this option is selected, the eNodeB periodically determines inappropriate neighboring GERAN cells to which UEs are handed over with a success rate less than a specified threshold, and removes these GERAN cells from the specific NCL and NRT. This option applies only to LTE FDD and LTE TDD.

EUTRAN_DELCELLERRORNCELL: If this option is selected, the eNodeB periodically determines inappropriate neighboring E-UTRAN cells of which the success rate of handovers from a local cell is less than the specified threshold, and removes the E-UTRAN cells from the specific NRT. When event-triggered ANR and automatic neighbor relationship removal for the specific RAT are enabled, NCL/NRT entry removal also takes effect without switch control when the number of NCL or NRT entries reaches its maximum and the NCL or NRT needs to accommodate new entries. This option applies only to LTE FDD and LTE TDD.

MLB_DELNCELCTRL: If this option is selected, during automatic removal of NRT entries, the eNodeB does not remove neighbor relationships with OverlapInd set to YES. If this option is deselected, the eNodeB removes neighbor relationships from NRTs without considering the OverlapInd parameter setting. This option applies only to LTE FDD and LTE TDD.

CA_DELNCELCTRL: If this option is selected, during automatic removal of NRT entries, the eNodeB does not remove the neighbor relationships with the cells that have been configured in CaGroupSCellCfg MOs with SCellBlindCfgFlag set to TRUE. If this option is deselected, the eNodeB removes neighbor relationships from NRTs without considering the SCellBlindCfgFlag parameter setting. This option applies only to LTE FDD and LTE TDD.

BLINDHO_DELNCELCTRL: If this option is selected, during automatic removal of NRT entries, the eNodeB does not remove neighbor relationships with BlindHoPriority set to non-zero values. If this option is deselected, the eNodeB removes neighbor relationships from NRTs without considering the BlindHoPriority parameter setting. This option applies only to LTE FDD and LTE TDD.

NR_DELREDUNDANCENCELL: If this option is selected, the eNodeB periodically determines neighboring NR cells which have not been measured by UEs and removes the neighbor relationships with these cells from NRTs. This option applies only to LTE FDD and LTE TDD.

UTRAN_NCELL_CORRECTION_SW: Indicates whether ANR with UTRAN automatically corrects neighboring cell information in MOCN scenarios. If this option is selected, the eNodeB deletes incorrect external cells and neighbor relationships and adds correct external cells based on the PLMN lists reported by UEs. If this option is deselected, the eNodeB does not perform these operations. This option applies only to LTE FDD and LTE TDD.

Utran Handover Threshold for Delete NRT

Indicates a threshold for removing a neighbor relationship from a UTRAN NRT. When the NRT reaches its capacity and ANR needs to add a new neighbor relationship to the NRT, ANR removes an old neighbor relationship with a cell from the NRT if the number of handovers to this cell is less than the threshold.

If this parameter is set to 0, ANR removes the neighbor relationship with a cell from an NRT not based on the number of handovers to this cell but based on the number of measurement reports on this cell.

If this parameter is set to another value, ANR can remove the neighbor relationship with a cell from an NRT if the number of handovers to this cell is less than the threshold. This parameter applies only to LTE FDD and LTE TDD.

Geran Handover Threshold for Delete NRT

Indicates a threshold for removing a neighbor relationship from a GERAN NRT. When the NRT reaches its capacity and ANR needs to add a new neighbor relationship to the NRT, ANR removes an old neighbor relationship with a cell from the NRT if the number of handovers to this cell is less than the threshold.

If this parameter is set to 0, ANR removes the neighbor relationship with a cell from an NRT not based on the number of handovers to this cell but based on the number of measurement reports on this cell.

If this parameter is set to another value, ANR can remove the neighbor relationship with a cell from an NRT if the number of handovers to this cell is less than the threshold. This parameter applies only to LTE FDD and LTE TDD.

Neighbor Cell Deletion Punish Period(min)

Indicates the penalty evaluation period for removed neighbor relationships with E-UTRAN, NG-RAN, or UTRAN cells. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

EUTRAN Neighbor Cell Deletion Punish Number

Indicates the number of penalties on an E-UTRAN cell after the neighbor relationship with the cell is removed. The cell can be added to the NRT again if the number of attempts to add back the neighbor relationship is greater than or equal to the value of this parameter. This parameter is also valid for the penalty on NG-RAN neighboring cells in inter-RAT ANR. This parameter applies only to LTE FDD and LTE TDD.

UTRAN Neighbor Cell Deletion Punish Number

Indicates the number of times penalty statistics about neighboring UTRAN cell deletion are collected. When a neighbor relationship with a UTRAN cell is deleted, it can be added to the NRT again if the number of times neighboring UTRAN cell addition is triggered is greater than or equal to the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

CA Threshold for NRT Deletion

Indicates the threshold (expressed as a number of times a cell has been configured as an SCell) used for neighbor relationship removal when the number of NRT entries has reached its maximum and a new neighbor relationship needs to be added. The removal is triggered when the number of times a cell has been configured as an SCell is less than this threshold. This parameter applies only to LTE FDD and LTE TDD.

Handover Success Rate for CGI Reading

Indicates the handover success rate threshold for reading the CGI of a neighboring cell. If the handover success rate from the local cell to a neighboring cell is less than or equal to this parameter value, the function of automatically setting the No HO attribute instructs UEs to read the CGI of the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

Stat Period For Inter-RAT Nrt Deletion (min)

Indicates the inter-RAT neighbor relationship removal evaluation period during which the eNodeB collects statistics on whether an inter-RAT neighboring cell has been detected by UEs and the number of handovers to the inter-RAT neighboring cell. The eNodeB uses the statistics to determine whether to remove the neighbor relationship from the inter-RAT NRT when the number of neighbor relationships in the inter-RAT NRT has reached the maximum and a new inter-RAT neighbor relationship needs to be added to the NRT by ANR. This parameter is also used to determine whether to remove an external cell from an inter-RAT NCL. If there are four consecutive periods in which an external cell in the NCL has no corresponding entry in any inter-RAT NRT, the eNodeB removes the external cell from the NCL.

This parameter is also used to determine periodic removal of redundant neighbor relationships from an inter-RAT NRT. The neighbor relationship with the inter-RAT cell to which no UEs are handed over from the local cell within N consecutive periods is removed from the NRT. N is specified by the StatPeriodCoeff parameter. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Stat Number For Inter-RAT Nrt Deletion

Indicates the threshold of the total number of handovers (or measurements for handovers) from the local cell to all inter-RAT neighboring cells, above which the eNodeB determines whether to remove neighbor relationships from an inter-RAT NRT when the number of inter-RAT neighbor relationships has reached the maximum or whether to periodically remove redundant neighbor relationships from the inter-RAT NRT. The number of neighbor relationships in the NRT has reached its maximum, and a new neighbor relationship needs to be added by ANR. In this scenario, if the total number of handovers (of all types) from the local cell to its inter-RAT neighboring cells in the last removal evaluation period reaches the value of this parameter, the eNodeB removes a neighbor relationship from the inter-RAT NRT. If the target RAT is NR, the removal condition is as follows: In the last removal evaluation period, the sum of the number of inter-RAT measurements and the number of times a DC secondary carrier is successfully configured reaches the value of this parameter. In periodic redundant neighbor relationship removal, the eNodeB removes redundant neighbor relationships if the total number of measurements for handovers (of all types) from the local cell to all inter-RAT neighboring cells reaches this parameter value for N consecutive measurement periods specified by the StaPeriodForIRatNRTDel parameter. N is specified by the StatPeriodCoeff parameter. This parameter applies only to LTE FDD and LTE TDD.

Period for Neighboring Cell Ranking(min)

Indicates the period for automatic optimization on neighboring cell measurement priorities. The neighboring cell measurement priorities are determined based on the number of times each neighboring cell is measured within the optimization period. Suggestions on the priorities are provided after the optimization period has elapsed. The period is one week by default. Neighboring cell selection for handovers does not take these priorities into consideration before the suggestions are available. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

Statistic Cycle Coefficient

Indicates the number of consecutive evaluation periods, specified by the StaPeriodForIRatNRTDel or StatisticPeriodForNRTDel parameter, for removal of redundant neighbor relationships. This parameter applies only to LTE FDD and LTE TDD.

Fast ANR Monitoring State Period(min)

Indicates the monitoring state period of fast ANR. During monitoring state periods, the eNodeB does not select new UEs for fast ANR measurements. If a neighboring cell with an unknown PCI is reported for event-triggered ANR during a monitoring state period, fast ANR exits the monitoring state and a new measurement period for fast ANR starts. If this parameter is set to 0, fast ANR does not enter the monitoring state. When the accumulative number of UEs performing fast ANR measurements is cleared, a new measurement period for fast ANR immediately starts. If this parameter is set to 65535, fast ANR does not exit the monitoring state unless a neighboring cell with an unknown PCI is reported for event-triggered ANR. After fast ANR exits the monitoring state, a new measurement period for fast ANR starts. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

NR Fast ANR RSRP Threshold(dBm)

Indicates the RSRP threshold used in fast ANR with NR. If the UE-reported RSRP of an NR cell is lower than this threshold, the eNodeB does not automatically add this NR cell to the NCL or NRT. If this parameter is set to a value other than 0, fast ANR with NR is enabled, and an NR NRT is created and optimized based on the results of periodic NR measurements. If this parameter is set to 0, fast ANR with NR is disabled, and the NR NRT is not created or optimized based on the results of periodic NR measurements. This parameter applies only to LTE FDD and LTE TDD.

NR FR2 CGI Reading Timer(0.5s)

Indicates the length of the timer for ANR-triggered CGI reading of cells on the FR2 frequency of the NR system. This parameter applies only to LTE FDD and LTE TDD.
