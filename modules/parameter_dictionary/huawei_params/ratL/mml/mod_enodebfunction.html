Modify eNodeB Function Configuration (MOD ENODEBFUNCTION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify an eNodeB function.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before changing the ID of an eNodeB under which there are intra-eNodeB neighbor relationships, you need to manually remove all neighbor relationships with cells under this eNodeB.

  • After the eNodeB ID is changed, reset the application referenced by the eNodeBFunction MO by running the RST APP command. If the application referenced by the eNodeBFunction MO is not reset within 10 minutes after the eNodeB ID is changed by running this command, ALM-26245 Configuration Data Inconsistency will be reported.

  • If the MOD_NCELL_CFG_SW option of the X2BasedUptNcellCfgSwitch parameter is selected for a neighboring eNodeB, after the eNodeB ID is changed, the eNodeB notifies the neighboring eNodeB the changes of serving cells of the eNodeB through the X2 interfaces. The neighboring eNodeB then updates the neighbor relationship configurations. The update takes a certain amount of time. If the eNodeB ID is repeatedly changed within a short period, the neighboring eNodeB cannot completely update the neighboring cell configurations. In this case, the configurations must be updated manually or by ANR. It is recommended that the interval between two changes of the eNodeB ID be longer than 60 seconds.

  • If eNodeB is connected with MAE, eNodeB Function Name will be synchronized from MAE to the eNodeB automatically. The modification from the base station does not take effect.

Parameters

ID Name Description
eNodeBFunctionName eNodeB Function Name

Meaning: Indicates the name of an eNodeB function, which uniquely identifies the eNodeB function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of eNodeBFunctionName is a string of characters. The string cannot be null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes(\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

-Others:

  • Due to the limitations defined in 3GPP TS 36.413 for the S1 interface, the value of eNodeBFunctionName can contain only the following characters that comply with American Standard Code for Information Interchange (ASCII): upper-case letters (A to Z), lower-case letters (a to z), digits (0 to 9), single blank ( ), left brackets ((), right brackets ()), plus signs (+), hyphens (-), and full stops (.).Messages that an eNodeB sends to an MME contain the IE eNB Name, and the eNodeB uses the value of eNodeBFunctionName to fill the IE. All invalid characters contained in eNodeBFunctionName are replaced with hyphens (-) when an eNodeB sends messages to the MME.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
eNodeBId eNodeB ID

Meaning: Indicates the eNodeB ID defined in the service protocol interface, which uniquely identifies an eNodeB within a PLMN. For details, see 3GPP TS 36.300.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
UserLabel User Label

Meaning: Indicates user-defined remarks.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify an eNodeB function with the parameters as follows: ENodeBId: 38602, UserLabel: lte-1, run the following command: 
MOD ENODEBFUNCTION: eNodeBId=38602, UserLabel="lte-1";
