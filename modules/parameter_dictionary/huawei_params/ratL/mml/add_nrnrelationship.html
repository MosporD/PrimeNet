Add Neighbor Relationship with NR Cell (ADD NRNRELATIONSHIP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a neighbor relationship with an NR cell.

Note

  • Before running this command, ensure that the associated external NR cell has been configured.

  • If the main control board is UMPTga or UMPTg, neighbor relationships with a maximum of 256 NR cells can be configured for each cell. If the main control board is not UMPTga or UMPTg, the maximum number is 128.

  • This command do not take effect when the LMPT is used as the main control board.

Mcc Mobile Country Code

Meaning: Indicates the mobile country code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

AggregationAttribute Aggregation Attribute

Meaning: Indicates the aggregation attribute of a neighboring NG-RAN cell.

CONTROL_MODE_FLAG: If this option is deselected, users can modify and delete an object, but ANR cannot modify or delete an object. If users add an object whose name is the same as an existing object, the addition fails. If this option is selected, both ANR and users can modify or delete an object (the operation of deleting a non-existing object is also successful), and add an object whose name is not the same as any existing object. Users can add (modify actually) an object whose name is the same as an existing object. ANR cannot add an object whose name is the same as an existing object. This option is selected by default for objects automatically created by ANR. Users can either select or deselect this option for the objects they create. This option applies only to LTE FDD and LTE TDD.

NO_REMOVE_FLAG: If this option is selected, ANR cannot remove a neighbor relationship. If this option is deselected, ANR can remove a neighbor relationship. This option applies only to LTE FDD and LTE TDD.

NO_HO_FLAG: If this option is selected, UEs in the E-UTRAN cell cannot be handed over to the neighboring NG-RAN cell. If this option is deselected, UEs in the E-UTRAN cell can be handed over to the neighboring NG-RAN cell. This option applies only to LTE FDD and LTE TDD.

CO_DEPLOYMENT_NSA_FLAG: If this option is selected, the neighboring NG-RAN cell can be added as a PSCell in the frequency band combination for collocated deployment. If this option is deselected, the neighboring NG-RAN cell cannot be added as a PSCell in the frequency band combination for collocated deployment. This option takes effect when the PCell and PSCell meet the requirements of the frequency band combination for collocated deployment. For details about the configuration of frequency band combinations for collocated deployment, see the AggregationAttribute parameter in the NrScgFreqConfig MO. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: CONTROL_MODE_FLAG(CONTROL_MODE_FLAG), NO_REMOVE_FLAG(NO_REMOVE_FLAG), NO_HO_FLAG(NO_HO_FLAG), CO_DEPLOYMENT_NSA_FLAG(CO_DEPLOYMENT_NSA_FLAG)

Unit: None

Actual Value Range: CONTROL_MODE_FLAG, NO_REMOVE_FLAG, NO_HO_FLAG, CO_DEPLOYMENT_NSA_FLAG

MML Default Value: None

Recommended Value: CONTROL_MODE_FLAG:On, NO_REMOVE_FLAG:Off, NO_HO_FLAG:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add the neighbor relationship with an NR cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", gNodeB ID: 1,  cell ID: 123, run the following command:
ADD NRNRELATIONSHIP: LocalCellId=0, Mcc="460", Mnc="20", GnodebId=1, CellId=123;
Example 2: To add the neighbor relationship with an NR cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", gNodeB ID: 48, cell ID: 12, run the following command:
ADD NRNRELATIONSHIP: LocalCellId=0, Mcc="460", Mnc="20", GnodebId=48, CellId=12;
