Set State (SET ENODEBCHROUTPUTCTRL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set whether to report SIG logs and signaling soft collection results. If the SIGReportSwitch parameter is set to ON, SIG logs and signaling soft collection results subscribed are normally reported. If this parameter is set to OFF, SIG logs and signaling soft collection results subscribed are forcibly terminated and new subscriptions also do not take effect.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the SIGReportSwitch parameter is set to OFF, SIG logs and signaling soft collection results are forcibly stopped being reported without depending on the subscription status. The eNodeB does not record the SIGReportSwitch parameter setting. After the eNodeB is reset, this parameter is set to ON by default.

Parameters

ID Name Description
SIGReportSwitch SIG Report Switch

Meaning: Indicates whether to report SIG logs and signaling soft collection results. If this parameter is set to ON, SIG logs and signaling soft collection results that have been subscribed to are normally reported. If this parameter is set to OFF, reporting of these SIG logs and signaling soft collection results is forcibly terminated and new subscriptions no longer take effect.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Use this command to set the SIGReportSwitch parameter to OFF: 
SET ENODEBCHROUTPUTCTRL: SIGReportSwitch=OFF;
