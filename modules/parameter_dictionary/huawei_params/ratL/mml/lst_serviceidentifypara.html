List Service Identification Parameter (LST SERVICEIDENTIFYPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters related to service identification.

Note

None.

Parameters

None.

Example

To list the parameters related to service identification, run the following command: :
LST SERVICEIDENTIFYPARA:;
The result is shown as follows:
+++    0        2019-12-05 17:38:46
O&M    #806356202
%%LST SERVICEIDENTIFYPARA: ;%%
RETCODE = 0  Operation succeeded.

      Heartbeat Packet Number Threshold  =  4
 Mass Flow Big Packet Rate Threshold(%)  =  80

Output Description

Field Description

Heartbeat Packet Length Threshold(Byte)

Indicates the threshold of the length of an IP packet for identifying heartbeat services. If the length of any IP packet of a service sent in 2s after RRC connection setup exceeds this threshold, the service is not identified as a heartbeat service. This parameter takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected. This parameter applies only to LTE TDD.

Heartbeat Packet Number Threshold

Indicates the threshold of the number of IP packets of a service for identifying heartbeat services. If the number of IP packets of a service sent within 2s after RRC connection setup exceeds this threshold, the service is not identified as a heartbeat service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

Mass Flow Big Packet Rate Threshold(%)

Indicates the threshold of the proportion of large downlink IP packets of a service to all IP packets in a measurement period. This threshold is used together with the MassFlowPacketNumberThld parameter to identify heavy-traffic services. If the proportion of large downlink IP packets of a service exceeds this threshold and the number of downlink IP packets of the service exceeds the MassFlowPacketNumberThld parameter, the service is identified as a heavy-traffic service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

Mass Flow Monitor Duration(s)

Indicates the measurement period for identification of heavy-traffic services. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.

Mass Flow Packet Number Threshold

Indicates the threshold of the number of downlink IP packets of a service, which is used together with the MassFlowBigPacketRateThld parameter to identify heavy-traffic services. If the proportion of large downlink IP packets of a service exceeds the value of the MassFlowBigPacketRateThld parameter and the number of downlink IP packets of the service exceeds the value of the MassflowPacketNumberThd parameter, the service is identified as a heavy-traffic service. This parameter applies only to LTE TDD and takes effect when the SrvBasedSRSAdjAlgo option of the SrsCfgPolicySwitch parameter is selected.
