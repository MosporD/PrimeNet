Modify Cell Dynamic Power Sharing (MOD CELLDYNPOWERSHARING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to cell dynamic power sharing.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DynamicPowerSharingSwitch Dynamic Power Sharing Switch

Meaning: Indicates whether to enable dynamic power sharing. This parameter consists of the following options:

LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers. These LTE carriers can be FDD carriers or TDD carriers, but cannot be any combination of FDD and TDD carriers. When this option is selected, power can be shared between LTE carriers. This option applies only to LTE FDD and LTE TDD.

UMTS_LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and UMTS carriers. When this option is selected, power can be shared between LTE and UMTS carriers. This option applies only to LTE FDD.

LTE_NR_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and NR carriers. When this option is selected, power can be shared between LTE and NR carriers. This option applies only to LTE TDD.

LTE_EXTREME_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers that share the same channel and between split cells. When this option is selected, power can be shared between LTE carriers that share the same channel and between split cells. This option applies only to LTE FDD.

GUI Value Range: LTE_DYN_POWER_SHARING_SW(LTE_DYN_POWER_SHARING_SW), UMTS_LTE_DYN_POWER_SHARING_SW(UMTS_LTE_DYN_POWER_SHARING_SW), LTE_NR_DYN_POWER_SHARING_SW(LTE_NR_DYN_POWER_SHARING_SW), LTE_EXTREME_POWER_SHARING_SW(LTE_EXTREME_POWER_SHARING_SW)

Unit: None

Actual Value Range: LTE_DYN_POWER_SHARING_SW, UMTS_LTE_DYN_POWER_SHARING_SW, LTE_NR_DYN_POWER_SHARING_SW, LTE_EXTREME_POWER_SHARING_SW

MML Default Value: None

Recommended Value: LTE_DYN_POWER_SHARING_SW:Off, UMTS_LTE_DYN_POWER_SHARING_SW:Off, LTE_NR_DYN_POWER_SHARING_SW:Off, LTE_EXTREME_POWER_SHARING_SW:Off

Parameter Relationship:

-Configuration constraints:

  • The UMTS_LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO can be selected only if the LTE_DYN_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the CellDynPowerSharing MO is selected.
  • If the LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in a CellDynPowerSharing MO is selected, the LTE_DYN_POWER_SHARING_SW option of the same parameter must be deselected.
  • The InterferenceControlSwitch parameter in the CellDynPowerSharing MO can be set to ON only if the LTE_DYN_POWER_SHARING_SW, UMTS_LTE_DYN_POWER_SHARING_SW, LTE_NR_DYN_POWER_SHARING_SW, or LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the same MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: LTE_DYN_POWER_SHARING_SW: When this option is selected, user-perceived data rates of all cell-edge UEs and TM7/TM8/TM9 UEs served by the LTE carrier receiving shared power increase. For an FDD cell, services fluctuate within three or four seconds after the setting of this option is changed. For an 8T8R TDD cell or a TDD cell with a lower TX/RX capability, services fluctuate within about one minute after the setting of this option is changed. For a 32T32R or 64T64R TDD cell, services fluctuate within about two minutes after the setting of this option is changed.

UMTS_LTE_DYN_POWER_SHARING_SW: When this option is selected, the impact on LTE carriers varies depending on whether these carriers are benefiting from UMTS carriers or benefiting UMTS carriers. If LTE carriers are benefiting from UMTS carriers, user-perceived data rates of all cell-edge UEs and TM7/TM8/TM9 UEs served by the LTE carriers increase. If LTE carriers are benefiting UMTS carriers, the user-perceived data rates decrease in case of traffic bursts.

LTE_NR_DYN_POWER_SHARING_SW: When this option is selected, the impact on LTE carriers varies depending on whether these carriers are benefiting from NR carriers or benefiting NR carriers. If LTE carriers are benefiting from NR carriers, user-perceived data rates of all cell-edge UEs and TM7/TM8/TM9 UEs served by the LTE carriers increase. If LTE carriers are benefiting NR carriers, the user-perceived data rates decrease in case of traffic bursts.

LTE_EXTREME_POWER_SHARING_SW: When this option is selected, power can be shared between LTE carriers that share the same channel and between split cells. This increases the downlink user-perceived data rates of both cell-center and cell-edge UEs.

Applicable Mode: L-FDD, L-TDD
MaxPowerSharingRate Max Power Sharing Rate

Meaning: Indicates the maximum percentage of power that the LTE carrier can share from other carriers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~50

Unit: %

Actual Value Range: 1~50

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a smaller percentage of power that the LTE carrier can share from other carriers, resulting in lower gains in average downlink user-perceived rate for CEUs and average downlink user-perceived rate in the LTE cell. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
InterferenceControlSwitch Interference Control Switch

Meaning: Indicates whether to enable interference control. If this parameter is set to ON, interference control is enabled. The eNodeB periodically predicts the impact of the local cell's reception of shared power on neighboring cells in terms of interference. If the prediction results indicate that the overall performance of the local and neighboring cells will be better after power sharing, the eNodeB allows the local cell to receive shared power in the next period. If this parameter is set to OFF, interference control is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship:

-Configuration constraints:

  • The InterferenceControlSwitch parameter in the CellDynPowerSharing MO can be set to ON only if the LTE_DYN_POWER_SHARING_SW, UMTS_LTE_DYN_POWER_SHARING_SW, LTE_NR_DYN_POWER_SHARING_SW, or LTE_EXTREME_POWER_SHARING_SW option of the DynamicPowerSharingSwitch parameter in the same MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, power sharing that causes high interference on neighboring cells as a result of power increase for the local cell will not be performed, which prevents the sharing from causing network performance deterioration. If this parameter is set to OFF, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
PowerAdjustmentMode Power Adjustment Mode

Meaning: Indicates the power adjustment mode of the cell that receives shared power. If this parameter is set to PDSCH_ONLY, the eNodeB increases only PDSCH power in the cell. If this parameter is set to CRS_AND_PDSCH, the eNodeB increases both CRS power and PDSCH power in the cell. This option applies only to LTE FDD.

GUI Value Range: PDSCH_ONLY(PDSCH_ONLY), CRS_AND_PDSCH(CRS_AND_PDSCH)

Unit: None

Actual Value Range: PDSCH_ONLY, CRS_AND_PDSCH

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to PDSCH_ONLY, UEs whose data is modulated using QPSK and UEs that support DMRSs will benefit from power sharing. If this parameter is set to CRS_AND_PDSCH, all UEs will benefit from power sharing; however, the measured RSRP values fluctuate more greatly, which causes an increase in the number of handovers.

Applicable Mode: L-FDD
PwrInsuffTimeRateThld Power Insufficiency Time Rate Threshold

Meaning: Indicates the threshold, which is a percentage of the scheduling time with power insufficiency, for LTE extreme power sharing to take effect. The larger the value of this parameter, the longer the allowed duration of power insufficiency and the higher the probability that power sharing takes effect. The smaller the value of this parameter, the shorter the allowed duration of power insufficiency and the lower the probability that power sharing takes effect. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability that ultimate power sharing takes effect. A larger value of this parameter results in a higher probability that ultimate power sharing takes effect.

Applicable Mode: L-FDD

Example

To modify the CellDynPowerSharing Configuration with the parameters as follows: Local cell ID: 0, Dynamic Power Sharing Switch: LTE_DYN_POWER_SHARING_SW-1, Max Power Sharing Rate(%): 30, run the following command:
MOD CELLDYNPOWERSHARING: LocalCellId=0, DynamicPowerSharingSwitch=LTE_DYN_POWER_SHARING_SW-1, MaxPowerSharingRate=30;
