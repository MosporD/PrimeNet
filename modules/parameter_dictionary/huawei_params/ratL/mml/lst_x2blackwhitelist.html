List X2 Blacklist or Whitelist (LST X2BLACKWHITELIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the X2 blacklist or whitelist. If a neighboring eNodeB is in the X2 blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up and the X2 interface manually set up between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is in the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed.

Note

None.

Parameters

ID Name Description
X2ListType X2 Black or White List Type

Meaning: Indicates whether the X2 list is a blacklist or whitelist. If a neighboring eNodeB is added to the X2 blacklist, an X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up or the X2 interface set up between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is added to the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: X2_BLACK_LIST_TYPE, X2_WHITE_LIST_TYPE

Unit: None

Actual Value Range: X2_BLACK_LIST_TYPE, X2_WHITE_LIST_TYPE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list X2 blacklist/whitelist information, run the following command:
LST X2BLACKWHITELIST:;

Output Description

Field Description

Mobile country code

Indicates the mobile country code of the neighboring eNodeB to be added to the list. The value of this parameter is a string of three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code of the neighboring eNodeB to be added to the list. The value of this parameter is a string of two or three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the ID of the neighboring eNodeB to be added to the list. This parameter applies only to LTE FDD and LTE TDD.

X2 Black or White List Type

Indicates whether the X2 list is a blacklist or whitelist. If a neighboring eNodeB is added to the X2 blacklist, an X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically set up or the X2 interface set up between the local eNodeB and this neighboring eNodeB is abnormal. If a neighboring eNodeB is added to the X2 whitelist or blacklist, the X2 interface between the local eNodeB and this neighboring eNodeB cannot be automatically removed. This parameter applies only to LTE FDD and LTE TDD.
