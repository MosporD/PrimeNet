Modify Cell Algorithm Extend Switch Configuration (MOD CELLALGOEXTSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of cell-level algorithm extend switches.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifications on the CFRA_WITH_SR_SWITCH of the NbCellAlgoExtSwitch parameter in an active cell would result in the automatic reset of the cell

If this option is selected, the proportions of scheduling duration for different coverage levels are adaptively adjusted based on network loads. If this option is deselected, the proportions of scheduling duration are fixed for different coverage levels. This option applies only to NB-IoT.

HARQ_ACK_WITH_SR_SWITCH: Indicates whether to allow SRs to be sent together with HARQ feedback. If this option is deselected, the function does not take effect. CFRA_WITH_SR_SWITCH: Indicates whether to allow SRs to be sent during non-contention-based random access. If this option is deselected, the function does not take effect. If this option is selected, the function takes effect, which can reduce air interface delay and UE power consumption. This option applies only to NB-IoT.

SPS_BSR_SWITCH: Indicates whether to allow BSRs to be sent in semi-persistent scheduling. If this option is deselected, the function does not take effect. If this option is selected, the function takes effect, which can reduce air interface delay and UE power consumption. This option applies only to NB-IoT.

PL_DIFF_BASED_DL_AMC_OPT_SW: Indicates whether to enable downlink AMC optimization based on path loss difference. If this option is selected, the eNodeB adjusts the downlink MCS index for a UE based on the difference between the path loss of the UE and the path loss at the edge of the coverage level for the UE. If this option is deselected, the algorithm does not take effect. This option applies only to NB-IoT.

QCI_FREE_DEPLOYMENT_SW: Indicates whether to enable QCI-free deployment of high speed mobility. If this option is selected, high speed mobility deployment does not involve QCI attribute configuration. If this option is deselected, high speed mobility deployment requires that the QciPara.NbUeMobility parameter be set to HIGH_SPEED_MOBILITY. This option takes effect only when the HIGH_SPEED_MOBILITY_SWITCH option of the CellAlgoSwitch.NbCellAlgoSwitch parameter is selected. This option applies only to NB-IoT.

RRC_QUICK_RELEASE_SWITCH: Indicates whether to enable fast RRC connection release in the cell. If this option is selected, the NB-IoT cell instructs UEs not to send status reports when it sends RRC connection release messages to UEs. After receiving an RRC connection release message, UEs will not postpone the release for 10s. If this option is deselected, the function does not take effect. This option applies only to NB-IoT.

Impact on Radio Network Performance: ADAPTIVE_PREAMBLE_INIT_PWR_SW: If this option is selected, the value of the PreambInitRcvTargetPwr parameter in the RACHcfg MO increases with the rise in the minimum value of interference and noise detected on each 15-kHz-based uplink subcarrier. This improves the anti-interference capability of the network and therefore increases the access success rate under interference.

DL_AMC_OPT_SWITCH: If this option is selected, the number of repetitions for UEs at the cell edge or a medium distance from the cell center in the downlink can be more quickly adjusted, increasing the downlink throughput of these UEs.

RELEASE_PERFM_IMPROVE_SWITCH: If this option is selected, the success rate of RRC release signaling transmission increases, reducing the probability of UE state inconsistency caused by delayed RRC release signaling reception. If this option is deselected, the success rate of RRC release signaling transmission decreases.

RECEPTION_FAIL_STATUS_RPT_SW: If this option is selected, a downlink throughput drop to zero due to full buffer can be avoided when the UE experiences data reception failures and data in the buffer cannot be released. If this option is deselected and the eNodeB does not trigger polling, then the downlink throughput drops to zero due to full buffer when the UE experiences data reception failures and data in the buffer cannot be released.

ENODEB_TX_BYTE_POLLING_SW: If this option is selected, the effects vary with the UE's received signal quality. When the UE's received signal quality is good, the downlink peak throughput decreases because the UE sends the status reports. When the UE's received signal quality is poor, a downlink throughput drop to zero due to full buffer can be avoided when the UE experiences data reception failures and data in the buffer cannot be released. If this option is deselected and the UE does not send the status reports, the downlink throughput drops to zero due to full buffer when the UE experiences data reception failures and data in the buffer cannot be released.

SCH_DURATION_PROP_ADAPT_SWITCH: If this option is selected, the resource usage decreases, and the RRC connection setup success rate and throughput in the cell increase. If this option is deselected, UEs at high coverage levels may cause the resource usage to increase. As a result, the RRC connection setup success rate and throughput decrease.

HARQ_ACK_WITH_SR_SWITCH: If this option is selected, the eNodeB allows UEs to transmit SRs together with ACK/NACK to downlink packets. This reduces air interface delay and UE power consumption. If this option is deselected, the function does not take effect, and air interface delay and UE power consumption may increase.

CFRA_WITH_SR_SWITCH: If this option is selected, the eNodeB allows UEs to transmit SRs during non-contention-based random access. This reduces air interface delay and UE power consumption. However, the number of PRACH subcarriers for contention-based random access decreases. If this option is deselected, the function does not take effect, and air interface delay and UE power consumption may increase.

SPS_BSR_SWITCH: If this option is selected, the eNodeB allows UEs to send BSRs to request uplink resources in semi-persistent scheduling. This reduces air interface delay and UE power consumption. If this option is deselected, the function does not take effect, and air interface delay and UE power consumption may increase.

PL_DIFF_BASED_DL_AMC_OPT_SW: If this option is selected, the downlink MCS indexes and repetition counts are adaptively adjusted based on the path loss difference, leading to fast MCS adjustment and therefore increased downlink UE data rates; however, the number of downlink bit errors may increase. If this option is deselected, the algorithm does not take effect and network performance is not affected.

QCI_FREE_DEPLOYMENT_SW: If this option is selected, high speed mobility deployment does not involve QCI attribute configuration, which facilitates the deployment. However, the uplink data transmission performance of motionless UEs may deteriorate. If this option is deselected, high speed mobility deployment requires that the QciPara.NbUeMobility parameter be set to HIGH_SPEED_MOBILITY, which complicates the deployment. However, the performance of UEs with QCIs for which the QciPara.NbUeMobility parameter is set to STATIONARY will not be affected.

APERIODIC_CQI_RPT_OPT_SW: Indicates whether to optimize aperiodic CQI reporting. If this option is selected, aperiodic CQI reporting is more timely. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

2D_FSS_SWITCH: Indicates whether to enable two-dimensional frequency selective scheduling. When both the SMART_FSS_SWITCH and 2D_FSS_SWITCH options are selected, two-dimensional frequency selective scheduling takes effect. When either option is deselected, two-dimensional frequency selective scheduling does not take effect. This option applies only to LTE FDD.

SMALL_PKT_MCS_CQI_ADJ_SW: Indicates whether to adjust CQIs for small packets for which the MCS index is reduced. If this option is selected, the CQI will not be adjusted for the scheduling for which a low-index MCS is reselected and the HARQ feedback is ACK. Reselection of a low-index MCS is enabled when the SmallPktMcsSelectAlgoSw option is selected. If this option is deselected, the CQI will be adjusted for the scheduling meeting the preceding conditions. This option applies only to LTE FDD.

MIN_GBR_OPT_SWITCH: Indicates whether to enable downlink minimum GBR guarantee optimization. If this option is selected, downlink minimum GBR guarantee optimization is enabled. If this option is deselected, downlink minimum GBR guarantee optimization is disabled. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: OUTER_LOOP_DSCP_QOS_MGMT_SW(OUTER_LOOP_DSCP_QOS_MGMT_SW), APERIODIC_CQI_RPT_OPT_SW(APERIODIC_CQI_RPT_OPT_SW), 2D_FSS_SWITCH(2D_FSS_SWITCH), SMALL_PKT_MCS_CQI_ADJ_SW(SMALL_PKT_MCS_CQI_ADJ_SW), MIN_GBR_OPT_SWITCH(MIN_GBR_OPT_SWITCH)

Actual Value Range: OUTER_LOOP_DSCP_QOS_MGMT_SW, APERIODIC_CQI_RPT_OPT_SW, 2D_FSS_SWITCH, SMALL_PKT_MCS_CQI_ADJ_SW, MIN_GBR_OPT_SWITCH

Recommended Value: OUTER_LOOP_DSCP_QOS_MGMT_SW:Off, APERIODIC_CQI_RPT_OPT_SW:Off, 2D_FSS_SWITCH:Off, SMALL_PKT_MCS_CQI_ADJ_SW:Off, MIN_GBR_OPT_SWITCH:Off

-Configuration constraints:

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: OUTER_LOOP_DSCP_QOS_MGMT_SW: If this option is selected in weak coverage scenarios, the service drop rate may increase. If this option is selected in scenarios where the proportion of forwarded packets is high, delays are greatly affected, probably causing the downlink packet loss rate to increase in the cell. When this option is deselected, QoS management based on inner-loop DSCP is used, probably causing the service drop rate to increase in weak coverage scenarios.

APERIODIC_CQI_RPT_OPT_SW: If this option is selected, the number of aperiodic CQI reporting times increases. If downlink frequency selective scheduling is enabled, the number of PRBs that can be used for downlink frequency selective scheduling increases, and therefore downlink UE throughput also increases. If this option is deselected, network performance is not affected.

2D_FSS_SWITCH: When both the SMART_FSS_SWITCH and 2D_FSS_SWITCH options are selected, two-dimensional frequency selective scheduling takes effect. RBGs will be reordered in downlink frequency selective scheduling to produce more frequency selective scheduling gains and increase the downlink UE throughput. However, the number of uplink aperiodic CQI reporting times also increases. When this option is deselected, two-dimensional frequency selective scheduling does not take effect, and network performance is not affected.

SMALL_PKT_MCS_CQI_ADJ_SW: If this option is selected, the IBLER decreases when the small-packet and large-packet hybrid service model is used, and the MCS index may also decrease. If this option is deselected, network performance is not affected.

MIN_GBR_OPT_SWITCH: If this option is selected, downlink minimum GBR guarantee optimization takes effect and the minimum GBRs for non-GBR bearers and the GBRs for GBR bearers can be better guaranteed. If this option is deselected, downlink minimum GBR guarantee optimization does not take effect and network performance is not affected.

Applicable Mode: L-FDD, L-TDD

This parameter applies only to LTE FDD and LTE TDD.
