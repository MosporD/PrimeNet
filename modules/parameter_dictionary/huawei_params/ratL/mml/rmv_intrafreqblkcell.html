Remove Intra-Frequency E-UTRAN Cell from Blacklist (RMV INTRAFREQBLKCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an intra-frequency E-UTRAN cell from the blacklist.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PhyCellId Start physical cell ID

Meaning: Indicates the starting PCI of the intra-frequency blacklisted cell. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The sum of the value of PhyCellIdRange (n1 is 1, n4 is 4, n8 is 8, and so on) and the value of PhyCellId must be smaller than 504 in the IntraFreqBlkCell MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the intra-frequency E-UTRAN cell with the following parameters from the blacklist: Local cell ID: 0, Start physical cell ID: 17, run the following command:
RMV INTRAFREQBLKCELL:LocalCellId=0, PhyCellId=17;
