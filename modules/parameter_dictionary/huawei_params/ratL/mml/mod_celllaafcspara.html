Modify LAA Cell FCS Parameters (MOD CELLLAAFCSPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the FCS parameters about a LAA cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modification of the DfsSwitch::DfsFreqSwitch option to on will enable the DFS function. Execution of this command will result in automatic reset of the pRRU.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FcsStartFreq FCS Start Frequency

Meaning: Indicates the starting frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS. The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.

GUI Value Range: 5150~5925

Unit: MHz

Actual Value Range: 5150~5925

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a CellLaaFcsPara MO, the value of FcsStopFreq cannot be less than the value of FcsStartFreq.
  • The frequency range specified by FcsStartFreq and FcsStopFreq must include at least one of the following values: 5160, 5180, 5200, 5220, 5240, 5260, 5280, 5300, 5320, 5340, 5480, 5500, 5520, 5540, 5560, 5580, 5600, 5620, 5640, 5660, 5680, 5700, 5720, 5745, 5765, 5785, 5805, 5825, 5845, 5865, 5885, and 5905.

-Others:

  • In a CellLaaFcsPara MO, the value of FcsStopFreq cannot be less than the value of FcsStartFreq.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FcsStopFreq FCS Stop Frequency

Meaning: Indicates the cut-off frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.

GUI Value Range: 5150~5925

Unit: MHz

Actual Value Range: 5150~5925

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a CellLaaFcsPara MO, the value of FcsStopFreq cannot be less than the value of FcsStartFreq.
  • The frequency range specified by FcsStartFreq and FcsStopFreq must include at least one of the following values: 5160, 5180, 5200, 5220, 5240, 5260, 5280, 5300, 5320, 5340, 5480, 5500, 5520, 5540, 5560, 5580, 5600, 5620, 5640, 5660, 5680, 5700, 5720, 5745, 5765, 5785, 5805, 5825, 5845, 5865, 5885, and 5905.

-Others:

  • In a CellLaaFcsPara MO, the value of FcsStopFreq cannot be less than the value of FcsStartFreq.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FcsInterfThd FCS Interference Threshold

Meaning: Indicates the threshold of the interference level detected in an LAA cell. If the interference level exceeds this threshold, the channel is considered occupied. Otherwise, the channel is considered available. This parameter applies only to LTE TDD.

GUI Value Range: -100~0

Unit: dBm

Actual Value Range: -100~0

MML Default Value: None

Recommended Value: -80

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
DfsSwitch DFS Switch

Meaning: Indicates whether to enable dynamic frequency selection (DFS). This parameter includes the DfsFreqSwitch option.

DfsFreqSwitch: Indicates whether to enable DFS detection. If this option is selected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are detected for DFS. If this option is deselected, frequencies in the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO are not detected for DFS. This option applies only to LTE TDD.

GUI Value Range: DfsFreqSwitch(DfsFreqSwitch)

Unit: None

Actual Value Range: DfsFreqSwitch

MML Default Value: None

Recommended Value: It is recommended that the DfsFreqSwitch option be selected only if the frequency bands specified by the FcsStartFreq and FcsStopFreq parameters in the CellLaaFcsPara MO match the DFS frequency bands in the country.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: DfsFreqSwitch: If this option is selected, an LAA cell working on a DFS frequency band has lower throughput than on common frequency bands. If this option is deselected, or if this option is selected but the LAA cell works on a non-DFS frequency band, the throughput of the LAA cell is not affected.

Applicable Mode: L-TDD
CellTpcMaxPower Cell TPC Maximum Power

Meaning: Indicates the maximum power during TPC for the LAA cell in the specified frequency range. Set this parameter based on local radio regulations. This parameter applies only to LTE TDD.

GUI Value Range: 20~1000

Unit: 0.1dBm

Actual Value Range: 2~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If TPC is enabled, a small value of this parameter leads to a small maximum cell power, and a large value of this parameter leads to a large maximum cell power.

Applicable Mode: L-TDD
CellTpcPowerAdjRange Cell TPC Power Adjustment Range

Meaning: Indicates the power adjustment range of TPC for the LAA cell in the specified frequency range. Set this parameter based on local radio regulations. This parameter applies only to LTE TDD.

GUI Value Range: 0~6

Unit: dB

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If TPC is enabled, a small value of this parameter leads to a small power decrease for UEs near the cell center, and a large value leads to a large power decrease for such UEs.

Applicable Mode: L-TDD
DlTpcAlgoSwitch Downlink TPC Algorithm Switch

Meaning: Indicates whether to enable TPC for the LAA cell in the specified frequency range.

DL_TPC_SWITCH: Indicates whether to enable downlink TPC for an LAA cell. If this option is selected, downlink TPC is enabled. If this option is deselected, downlink TPC is disabled. This option applies only to LTE TDD.

GUI Value Range: DL_TPC_SWITCH(DL_TPC_SWITCH)

Unit: None

Actual Value Range: DL_TPC_SWITCH

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DL_TPC_SWITCH: If this option is selected, TPC takes effect. After TPC is enabled, the average cell power allowed according to local radio regulations increases. For details, see local radio regulations.

Applicable Mode: L-TDD

Example

To modify the cell FCS parameters as follows:  LocalCellId: 1:Start Frequency is 5150MHz, Stop Frequency is 5250MHz, FCS Interference Threshold is -50dBm:
MOD CELLLAAFCSPARA: LocalCellId=1, FcsStartFreq=5150, FcsStopFreq=5250, FcsInterfThd=-50;
