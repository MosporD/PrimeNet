Remove Cell Emergency Area ID (RMV CELLEMERGENCYAREA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove cell emergency area information.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This command is a risky command and you are advised to run this command during off-peak hours.

If no parameter is specified, all records of emergency area IDs are removed after this command is executed.

If some parameters are specified, records that match the parameter settings are removed after this command is executed.

If all parameters are specified, the record that matches all the parameter settings is removed after the command is executed.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local primary cell ID. It uniquely identifies a cell within an eNodeB. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EmergencyAreaId Emergency Area ID

Meaning: Indicates the ID of an emergency area in which an alarm message is to be broadcast. The emergency area ID is defined by the operator. An emergency area consists of one or several cells. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove an Emergency Area ID with the parameters as follows: LocalCellId: 0, EmergencyAreaId: 0, run the following command:
RMV CELLEMERGENCYAREA: LocalCellId=0, EmergencyAreaId=0;
