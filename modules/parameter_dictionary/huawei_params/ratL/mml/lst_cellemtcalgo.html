List Cell eMTC Algorithm Configuration (LST CELLEMTCALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the cell-level eMTC algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of eMTC algorithm parameters of a cell:
LST CELLEMTCALGO: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

eMTC Target UL RB Usage(%)

Indicates the target uplink RB usage of eMTC UEs in the cell. If the UlLteRsvNbCount parameter in the CellEmtcAlgo MO is set to a large value, the actual RB usage of eMTC UEs may fail to reach the value specified by the EmtcUlRbTargetRatio parameter. Modification of this parameter has no impact on the network if the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

eMTC Aperiodic CQI Trigger Period

Indicates the period of triggering aperiodic CQI reporting by eMTC UEs. The period can be 5 ms, 10 ms, 20 ms, 40 ms, 80 ms, 160 ms, and infinite (that is, no aperiodic CQI reporting is triggered). This parameter applies only to LTE FDD and LTE TDD.

eMTC Target DL RB Usage(%)

Indicates the target downlink RB usage of eMTC UEs in the cell. If the DlLteRsvNbCount parameter in the CellEmtcAlgo MO is set to a large value, the actual RB usage of eMTC UEs may fail to reach the value specified by the EmtcDlRbTargetRatio parameter. Modification of this parameter has no impact on the network if the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

eMTC Algorithm Switch

Indicates whether to enable eMTC-related algorithms.

EMTC_SWITCH: Indicates whether to enable eMTC. If this option is selected, eMTC UEs can access the cell and perform services normally. If this option is deselected, eMTC UEs cannot access the cell to perform services. This option applies only to LTE FDD and LTE TDD.

IDLE_EDRX_SWITCH: Indicates whether to enable eDRX in idle mode. If this option is selected, eDRX takes effect in idle mode. If this option is deselected, eDRX does not take effect in idle mode. This option applies only to LTE FDD and LTE TDD.

G_VALUE_CFG_SWITCH: Indicates value G configured for eMTC UEs. If this option is deselected, the eNodeB adapts value G for eMTC UEs. If this option is selected, value G is fixed to 1 for eMTC UEs. If the value of this parameter is changed, the value of the mpdcch-startSF-CSS-RA-r13 IE is changed, and eMTC UEs that already accessed the cell will be proactively released. This option applies only to LTE TDD.

SI_UPDATE_REL_UE_SWITCH: Indicates whether to proactively release eMTC UEs when system information changes. If this option is selected, when system information changes due to the changes of cell-level SRS resources allocated to eMTC UEs, the eNodeB proactively releases eMTC UEs that accessed the network before the system information change. If this option is deselected, when system information changes due to the changes of cell-level SRS resources allocated to eMTC UEs, the eNodeB does not proactively release eMTC UEs that accessed the network before the system information change. This option applies only to LTE FDD.

EMTC_ONLY_CELL_SWITCH: Indicates whether a cell is an eMTC-only cell. When this option is selected, a cell enters the eMTC-only state, and common UEs cannot access this cell. When this option is deselected, the cell exits the eMTC-only state, and common UEs can access this cell. eMTC-only cells support only 1.4 MHz, 3 MHz, or 5 MHz bandwidth. This option applies only to LTE FDD.

MODE_A_UE_TA_SCHEDULING_SWITCH: Indicates whether the eNodeB proactively allocates PUSCH resources to ModeA UEs for uplink timing measurement. When ModeA UEs do not have sufficient PUSCH resources, the eNodeB proactively allocates PUSCH resources to ModeA UEs for uplink timing measurement only if this option is selected. This option applies only to LTE FDD and LTE TDD.

EMTC_UE_ACK_START_OFFSET_CFG: Indicates whether to enable configuration of UE-level ACK resource start positions for eMTC UEs. If this option is deselected, UE-level ACK resource start positions are not configured. If this option is selected, UE-level ACK resource start positions can be configured for eMTC UEs whose coverage level is 0. This option takes effect only if the cell has a 10 MHz or higher bandwidth and the DeltaShift parameter in the PUCCHCFG MO is set to DS1_DELTA_SHIFT(ds1) or DS2_DELTA_SHIFT(ds2) for the cell. This option applies only to LTE FDD.

DL_PERFORMANCE_ENHANCE_SWITCH: Indicates whether to enable downlink performance enhancement for eMTC UEs. The enhancement is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_PERFORMANCE_ENHANCE_SWITCH: Indicates whether to optimize the uplink and downlink scheduling cooperation and the resource allocation strategy for eMTC UEs so as to improve the uplink link adaptation performance for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

EMTC_CONG_CONTROL_OPT_SWITCH: Indicates whether to enable congestion control based on the eMTC air interface resource load. If this option is selected, access class (AC) control or enhanced AC control for eMTC UEs is triggered based on the load of air interface resources occupied by the signaling of eMTC UEs. If this option is deselected, AC control or enhanced AC control for eMTC UEs is triggered the same way as that for LTE UEs. This option applies only to LTE FDD and LTE TDD.

MPDCCH_MORE_AVAIL_NB_SWITCH: Indicates whether to allow more narrowbands to be allocated to the MPDCCH of the cell. If this option is selected, up to 12 narrowbands can be allocated to the MPDCCH. If this option is deselected, only the default narrowbands are allocated to the MPDCCH. This option takes effect only for cells with the 10 MHz, 15 MHz, or 20 MHz bandwidth. This option applies only to LTE FDD and LTE TDD.

UL_MCS_SCHEDULING_OPT_SWITCH: Indicates whether to enable selection of optimal RBs, MCS, and number of repetitions for uplink scheduling of eMTC UEs at the cell edge. This option applies only to LTE FDD.

EMTC_UL_MCS_SELECT_OPT_SWITCH: Indicates whether to enable eMTC PUSCH MCS selection optimization. This option applies only to LTE FDD and LTE TDD.

EMTC_RATE_ENH_SWITCH: Indicates whether to configure 10 HARQ processes and activate HARQ-ACK bundling for eMTC UEs in CE mode A. For details, see 3GPP TS 36.331 Release 14 and 3GPP TS 36.213 Release 14. If this option is selected, the eNodeB checks whether to configure 10 HARQ processes and activate HARQ-ACK bundling for UEs in CE mode A based on the UE capability reported using the ce-PDSCH-TenProcesses-r14, ce-HARQ-AckBundling-r14, and ce-SchedulingEnhancement-r14 IEs. This option applies only to LTE FDD.

BL_UE_INTER_FREQ_HO_SWITCH: Indicates whether to enable inter-frequency handover and emergency blind inter-frequency redirection for BL UEs. Inter-frequency handover and emergency blind inter-frequency redirection for BL UEs are enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UL_AMC_OPT_SWITCH: Indicates whether to optimize link adaptation performance for eMTC UEs in the uplink, and whether to extend the PUSCH repetition count and restrict PUSCH modulation for CE UEs in mode A as defined by the ce-PDSCH-PUSCH-Enhancement IE. For details, see 3GPP TS 36.213 Release 14. This option applies only to LTE FDD and LTE TDD.

DL_AMC_OPT_SWITCH: Indicates whether to optimize link adaptation performance for eMTC UEs in the downlink, and whether to restrict PDSCH modulation for CE UEs in mode A as defined by the ce-PDSCH-PUSCH-Enhancement IE. For details, see 3GPP TS 36.213 Release 14. This option applies only to LTE FDD and LTE TDD.

EMTC_CSI_RS_OPT_SWITCH: Indicates whether to optimize the cooperation between eMTC and CSI-RS. If this option is selected, the eNodeB uses an MCS with a low index for the scheduling of eMTC UEs so that eMTC UEs can be scheduled in CSI-RS subframes. This reduces the impact of CSI-RS subframe changes on eMTC UEs. If this option is deselected, the eNodeB sets CSI-RS subframes as invalid subframes and informs eMTC UEs of these subframes through system information. This option applies only to LTE FDD and LTE TDD.

EMTC_PRACH_IRC_SWITCH: Indicates whether to enable eMTC PRACH MRC/IRC adaptation. If this option is deselected, MRC is used for the eMTC PRACH. If this option is selected, MRC or IRC is used adaptively for the eMTC PRACH. This option applies only to LTE FDD and LTE TDD.

EMTC_MSG3_RETRANS_OPT_SWITCH: Indicates whether to optimize eMTC Msg3 retransmission. If this option is selected, the eNodeB predicts whether resources can be successfully allocated for eMTC Msg3 retransmission and attempts to allocate resources only if the prediction result indicates successful allocation. This reduces the probability of eMTC Msg3 retransmission failure. If this option is deselected, the eNodeB does not perform the prediction. This option applies only to LTE FDD and LTE TDD.

EMTC_SIG_MCS_ENH_SWITCH: Indicates whether to enable enhanced MCS selection for signaling transmission for eMTC UEs. If this option is selected, enhanced MCS selection for signaling transmission takes effect for eMTC UEs. If this option is deselected, a conservative MCS is used for signaling transmission for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

UL_PERCEIVED_AMC_SWITCH: Indicates whether to enable uplink perception-based AMC. If this option is selected, the eNodeB perceives the scheduling characteristics of eMTC UEs, which helps increase the uplink data rates of eMTC UEs. If this option is deselected, the algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

DL_AGILE_CQI_ADJ_SWITCH: Indicates whether to enable downlink flexible CQI adjustment. If this option is selected, IBLER convergence is accelerated during initial access or incoming handovers, which helps increase the downlink data rates of eMTC UEs. When this option is deselected, a fixed convergence rate is used. This option applies only to LTE FDD and LTE TDD.

PUSCH_DTX_SINR_OPT_SWITCH: Indicates whether to enable SINR processing optimization upon PUSCH DTX detection. If this option is selected, the eNodeB does not process the SINRs measured for UEs in the DTX state when DTX is detected on the PUSCH. If this option is deselected, the eNodeB still processes the SINRs measured for UEs in the DTX state when DTX is detected on the PUSCH. This option applies only to LTE FDD and LTE TDD.

DL LTE Reserved NB Count

Indicates the number of narrowbands reserved for LTE UEs when the eNodeB schedules eMTC UEs in the downlink in the cell. These reserved narrowbands cannot be allocated to the MPDCCH and PDSCH for eMTC services. This parameter must be set to 2 for a 5 MHz cell. The value range is 2 to 5 for a 10 MHz cell, 2 to 9 for a 15 MHz cell, and 2 to 13 for a 20 MHz cell. If the cell uses a non-standard bandwidth, the eNodeB restricts the maximum value on the prerequisite that at least one available narrowband can be allocated to the MPDCCH and PDSCH for eMTC services. If the value of this parameter exceeds the maximum value, the eNodeB uses the maximum value as the number of narrowbands reserved for LTE UEs. This parameter does not take effect when the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

UL LTE Reserved NB Count

Indicates the number of narrowbands reserved for LTE UEs when the eNodeB schedules eMTC UEs in the uplink in the cell. These reserved narrowbands cannot be used for eMTC service data sent on the PUSCH. This parameter must be set to 2 for a 5 MHz cell. The value range is 2 to 5 for a 10 MHz cell, 2 to 9 for a 15 MHz cell, and 2 to 13 for a 20 MHz cell. If the cell uses a non-standard bandwidth, the eNodeB restricts the maximum value on the prerequisite that at least one available narrowband can be allocated to the MPDCCH and PDSCH for eMTC services. If the value of this parameter exceeds the maximum value, the eNodeB uses the maximum value as the number of narrowbands reserved for LTE UEs. This parameter does not take effect when the EMTC_ONLY_CELL_SWITCH option of the EmtcAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

eMTC Cell VoLTE Capability Switch

Indicates whether to enable VoLTE for an eMTC cell. If this parameter is set to ON, VoLTE is enabled for the eMTC cell. If this parameter is set to OFF, VoLTE is disabled for the eMTC cell. This parameter is invalid when the EutranVoipSupportSwitch parameter is set to OFF. This parameter applies only to LTE FDD and LTE TDD.

eMTC No Service Aperiodic CQI Trigger Period

Indicates the triggering period for aperiodic CQI reporting when eMTC UEs are not performing services. The value INF indicates infinite, which means that aperiodic CQI reporting will not be triggered. This parameter applies only to LTE FDD and LTE TDD.

eMTC Downlink Frequency Hopping Interval

Indicates the downlink frequency hopping interval for eMTC in CE mode A or CE mode B. If the MPDCCH_PDSCH_FREQ_HOPPING_SW option is selected, the downlink frequency hopping interval is the value specified by this parameter. If CE mode B is used, the value INTERVAL1 does not take effect. This parameter has different values for FDD and TDD as follows:

For an FDD cell, this parameter can be set to INTERVAL1, INTERVAL2, INTERVAL4, or INTERVAL8.

For a TDD cell, this parameter can be set to INTERVAL1, INTERVAL5, INTERVAL10, or INTERVAL20.

This parameter applies only to LTE FDD and LTE TDD.

eMTC Uplink Frequency Hopping Interval

Indicates the uplink frequency hopping interval for eMTC in CE mode A or CE mode B. If the PUSCH_FREQ_HOPPING_SW option is selected, the uplink frequency hopping interval is the value specified by this parameter. If CE mode B is used, the value INTERVAL1 does not take effect. This parameter has different values for FDD and TDD as follows:

For an FDD cell, this parameter can be set to INTERVAL1, INTERVAL2, INTERVAL4, or INTERVAL8.

For a TDD cell, this parameter can be set to INTERVAL1, INTERVAL5, INTERVAL10, or INTERVAL20.

This parameter applies only to LTE FDD and LTE TDD.

MPDCCH/PDSCH Frequency Hopping Offset

Indicates the MPDCCH/PDSCH frequency hopping offset for eMTC UEs. This parameter can be set to 1 or 2 for 3 MHz cells. The value range is [1, 4] for 5 MHz cells, [1, 8] for 10 MHz cells, [1, 12] for 15 MHz cells, and [1, 16] for 20 MHz cells. This parameter applies only to LTE FDD and LTE TDD.

MPDCCH/PDSCH Frequency Hopping NB Count

Indicates the number of NBs for MPDCCH/PDSCH frequency hopping for eMTC UEs. NB is short for narrowband, and an NB consists of six contiguous RBs. The value NB2 indicates two NBs for frequency hopping, and the value NB4 indicates four NBs for frequency hopping. This parameter can be set only to NB2 for cells with a 3 MHz bandwidth, and can be set to NB2 or NB4 for cells with a 5 MHz or higher bandwidth. This parameter applies only to LTE FDD and LTE TDD.

PUSCH Frequency Hopping Offset

Indicates the PUSCH frequency hopping offset for eMTC UEs. This parameter can be set to 1 or 2 for 3 MHz cells. The value range is [1, 4] for 5 MHz cells, [1, 8] for 10 MHz cells, [1, 12] for 15 MHz cells, and [1, 16] for 20 MHz cells. This parameter applies only to LTE FDD and LTE TDD.

PRACH Frequency Hopping Offset

Indicates the PRACH frequency hopping offset for eMTC UEs. The PRACH frequency hopping offset for eMTC UEs can be manually or automatically configured. If the PRACH frequency hopping offset is automatically configured, the GUI value of this parameter does not take effect. Instead, the eNodeB calculates an optimum PRACH frequency hopping offset for eMTC UEs based on the system bandwidth and resource allocation status. If the PRACH frequency hopping offset is manually configured by setting this parameter, the value range is 0 to 94. If the PRACH frequency hopping position for an eMTC UE conflicts with the positions of PUCCHs for LTE and eMTC, PRACH frequency hopping does not take effect for the eMTC UE. This parameter applies only to LTE FDD and LTE TDD.

eMTC Frequency Hopping Switch

Indicates whether to enable frequency hopping for eMTC UEs.

PRACH_FREQ_HOPPING_SW: Indicates whether to enable PRACH frequency hopping for eMTC UEs. If this option is selected, PRACH frequency hopping is enabled for eMTC UEs, and PRACH is transmitted based on the PRACH frequency-domain offset for eMTC UEs in accordance with a protocol-specified spectrum bitmap. For details, see section 5.7.1 in 3GPP TS 36.211 R14. If this option is deselected, PRACH frequency hopping is disabled for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

PUSCH_FREQ_HOPPING_SW: Indicates whether to enable PUSCH frequency hopping for eMTC UEs. If this option is selected, PUSCH frequency hopping is enabled for eMTC UEs, and PUSCH is transmitted based on the PUSCH frequency-domain offset and uplink time-domain interval for eMTC UEs in accordance with a protocol-specified spectrum bitmap. For details, see section 5.3.4 in 3GPP TS 36.211 R14. If this option is deselected, PUSCH frequency hopping is disabled for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

MPDCCH_PDSCH_FREQ_HOPPING_SW: Indicates whether to enable frequency hopping for downlink channels for eMTC UEs. If this option is selected, the MPDCCH/PDSCH, RAR/Msg4, SI, paging messages, and Msg3 are transmitted in unicast mode, and frequency hopping is enabled. The eNodeB uses System Information Block type 1 to broadcast downlink frequency hopping parameters (for details, see section 6.2.2 in 3GPP TS 36.331 R14), sets frequency hopping parameters in common radio messages, and transmits channels in accordance with protocol-specified spectrum bitmaps (for details, see section 6.4.1 in 3GPP TS 36.211 R14). If this option is deselected, frequency hopping is disabled for downlink channels for eMTC UEs. This option applies only to LTE FDD and LTE TDD.

eMTC PDSCH/PUSCH Enhancement Switch

Indicates whether to enable PDSCH/PUSCH enhancement for eMTC UEs. If this parameter is set to ON, PDSCH/PUSCH enhancement is enabled for eMTC UEs. For UEs in CE mode A, a new set of PUSCH repetition counts (1, 2, 4, 8, 12, 16, 24, and 32) is used and optimization of PDSCH/PUSCH modulation constraints is supported. For details, see 3GPP TS 36.213 Release 14. If this parameter is set to OFF, PDSCH/PUSCH enhancement is disabled for eMTC UEs. This parameter applies only to LTE FDD and LTE TDD.

eMTC Dynamic HARQ-ACK Delay Parameter

Indicates whether to enable dynamic HARQ-ACK delay for eMTC UEs.

If this parameter is set to RANGE1 or RANGE2, dynamic HARQ-ACK delay is enabled for eMTC UEs. For eMTC UEs in CE mode A, the value of HARQ-ACK delay for the PDSCH is one of the values corresponding to RANGE1 or RANGE2, and the DCI is used to inform the eMTC UEs of the delay value. The values corresponding to RANGE1 are 4, 5, 7, 9, 11, 13, 15, and 17, and the values corresponding to RANGE2 are 4, 5, 6, 7, 8, 9, 10, and 11. For details, see 3GPP TS 36.213 R14.

If this parameter is set to OFF, dynamic HARQ-ACK delay is disabled for eMTC UEs. This parameter applies only to LTE FDD.

eMTC DL Schedule Strategy

Indicates the downlink scheduling policy for eMTC UEs. Round robin (RR) ensures scheduling fairness between UEs in a cell. However, it delivers low system throughput. Generally, RR is used to verify a system's best performance in scheduling fairness. Enhanced proportional fair (EPF) considers all of the following factors: QoS, system capacity, and channel frequency selectiveness. Generally, RR is used in performance tests. It is recommended that EPF be used in normal network operations. This parameter applies only to LTE FDD and LTE TDD.

eMTC Enhanced VoLTE Algorithm Switch

Indicates whether to enable the algorithms related to enhanced VoLTE over eMTC.

VOLTE_REPETITION_OPT_SWITCH: Indicates whether to optimize repetitions for VoLTE UEs. If this option is selected, the eNodeB dynamically selects the number of repetitions, MCS indexes, and RBs for the PDSCH and PUSCH based on voice packet sizes and channel conditions. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

VOLTE_CROSS_LAYER_OPT_SWITCH: Indicates whether to enable cross-layer optimization for VoLTE UEs. If this option is selected, the eNodeB optimizes the PDCP-layer discard timer, RLC-layer reordering timer, and maximum number of MAC-layer HARQ retransmissions to increase the tolerable delay over the air interface. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

eMTC Initial Aggregation Level Adj Value

Indicates the initial adjustment value of the MPDCCH aggregation level for eMTC UEs. This parameter applies only to LTE FDD and LTE TDD.

eMTC Initial CQI Adjustment Value

Indicates the initial CQI adjustment value for eMTC UEs. This parameter applies only to LTE FDD and LTE TDD.

eMTC SRI Repetition UE Maximum SRI Usage(%)

Indicates the maximum SRI resource usage allowed for eMTC UEs in the cell to transmit SRIs repeatedly. If this parameter is set to 0, eMTC UEs that need to transmit SRIs repeatedly cannot access the cell. This option applies only to LTE FDD and LTE TDD.

eMTC RACH Algorithm Switch

Indicates whether to enable the algorithms related to eMTC random access.

EXCEED_RADIUS_CRA_DETECTION_SW: Indicates whether to detect contention-based random access by eMTC UEs located beyond the cell radius. If this option is selected, the eNodeB can detect contention-based random access by UEs located beyond the cell radius. If this option is deselected, the eNodeB does not detect contention-based random access by these UEs. This option applies only to LTE FDD and LTE TDD.

EXCEED_RADIUS_CFRA_OPT_SW: Indicates whether to optimize the handling of non-contention-based random access for eMTC UEs located beyond the cell radius. If this option is selected, the eNodeB optimizes the handling of non-contention-based random access for UEs located beyond the cell radius and allows these UEs to access the network. If this option is deselected, the eNodeB does not optimize the handling of non-contention-based random access for these UEs. This option applies only to LTE FDD and LTE TDD.
