Remove PLMN List for External NR Cell (RMV NREXTERNALCELLPLMN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more PLMN IDs of an external NR cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If some of the parameters are specified, running this command deletes records that meet all the specified parameter requirements. A maximum of 640 records can be deleted at a time by running this command.

  • This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of an external NR cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an NrExternalCellPlmn MO consists of digits only.
  • In an NrExternalCellPlmn MO, the combination of Mnc and Mcc must be different from that of SharedMnc and SharedMcc.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the PLMN list for an external NR cell with the parameters as follows: Mobile Country Code: 460, Mobile Network Code: 20, gNodeB ID: 255, Cell ID: 1, Shared Mobile country code: 460, Shared Mobile Network Code: 01, run the following command:
RMV NREXTERNALCELLPLMN: Mcc="460", Mnc="20", GnodebId=255, CellId=1, SharedMcc="460", SharedMnc="01";
