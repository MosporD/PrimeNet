Modify CN Operator (MOD CNOPERATOR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify an operator.

The combination of the mobile country code (MCC) and mobile network code (MNC) uniquely identifies an operator. If the MCC or MNC is changed, the operator identified by the operator ID is changed. After modification, if the eNodeB is configured to work in RAN sharing with common carriers mode, RAN sharing with dedicated carriers mode, hybrid RAN sharing mode, or RAN sharing with special dedicated carriers mode but does not have the required RAN sharing license, configurations of secondary operators do not take effect. A maximum of six operators can be added for an eNodeB. If the license control item RAN Sharing by More Operators is disabled, a maximum of four operators can share the eNodeB, configurations of other operators do not take effect, and other operators cannot use the eNodeB to provide services.

If the license control item RAN Sharing by More Operators is disabled and more than four operators are added for the eNodeB, the following principles apply when the eNodeB decides which four operators to take effect: The configuration of the primary operator takes effect first. The configurations of secondary operators take effect in the same sequence as they are added. After the eNodeB is restarted, the configuration of the primary operator takes effect first and the configurations of secondary operators take effect based on the operator IDs. The configuration of a secondary operator with a smaller operator ID takes effect in prior to that with a larger operator ID. As a result, the following situation is possible: The configurations of secondary operators with larger IDs (for example, 4 and 5) but earlier configuration time take effect while the configurations of secondary operators with smaller IDs (for example, 0 and 1) do not take effect. However, after the eNodeB is restarted, the configurations of secondary operators with the smaller IDs (for example, 0 and 1) take effect while the configurations of secondary operators with the larger IDs (for example, 4 and 5) do not take effect. In either case, two operators cannot provide services normally. In this case, the operators need to purchase the license control item RAN Sharing by More Operators.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If an operator is added on multiple eNodeBs managed by one NMS, the same operator ID must be configured. An operator is uniquely identified by the PLMN ID that is comprised of the MCC and MNC.

  • After this command is executed to change the operator type, MCC, MNC or PlmnMode, run RST APP to reset the application referenced by the eNodeBFunction MO for the application to take effect. You can run LST ENODEBFUNCTION to view the application referenced by the eNodeBFunction MO. If the application referenced by the eNodeBFunction MO is not reset within 10 minutes after the type, mobile country code (MCC), or the mobile network code (MNC) of the operator is changed by running this command, ALM-26245 Configuration Data Inconsistency will be reported.

  • If the eNodeB works in independent mode, there can be only one operator and this operator must be the primary operator.

  • Mobile network code is a string of two or three characters, each of which must be a digit in the range from 0 to 9.

  • If the MOD_NCELL_CFG_SW option of the X2BasedUptNcellCfgSwitch parameter is selected for a neighboring eNodeB, after the operator is changed, the eNodeB notifies the neighboring eNodeB the changes of serving cells of the eNodeB through the X2 interfaces. The neighboring eNodeB then updates the neighbor relationship configurations. The update takes a certain amount of time. If the operator is repeatedly changed within a short period, the neighboring eNodeB cannot completely update the neighboring cell configurations. In this case, the configurations must be updated manually or by ANR. It is recommended that the interval between two changes of the operator be longer than 60 seconds.

  • After the MCC or MNC is changed, the operator identified by the operator ID is also changed. Therefore, modify the CnOperatorTa, S1Interface, and Emc MOs that reference the operator ID.

  • If the eNodeB works in RAN sharing with common carriers mode, RAN sharing with dedicated carriers mode, hybrid RAN sharing mode, or RAN sharing with special dedicated carriers mode, there can be only one primary operator, and other operators, if any, must be secondary operators.

  • Mobile country code is a string of three characters, each of which must be a digit in the range of 0 to 9.

Meaning: Indicates whether the PLMN works in Isolated E-UTRAN Operation for Public Safety (IOPS) mode when the CnOperatorType parameter is set to CNOPERATOR_SECONDARY for the operator.

Only the PLMN of a secondary operator can be configured to work in IOPS mode, and only one PLMN of an eNodeB can be configured to work in IOPS mode. When the active main control board is an LMPT board, the PlmnMode parameter cannot be set to IOPS_PLMN.

OperatorFunSwitch Operator Function Switch

Meaning: Indicates whether to enable features for the operator.

CELL_TRAFFIC_TRACE_MSG_SWITCH: After a cell tracing task is started, the eNodeB can send the CellTrafficTrace message to the MME over the S1 interface only if this option is selected. For details about the mechanism of sending the CellTrafficTrace message, see 3GPP TS 32.422.

DCN_SUPPORT_SWITCH: The operator supports access to the dedicated core network (DCN) and the MME-initiated Reroute NAS Request procedure only if this option is selected. For details about DCN, see 3GPP TS 36.413 and 3GPP TS 23.401.

MME_STRICT_SELECTION_SWITCH: Indicates whether to enable MME selection by exact GUMMEI match for UEs of the operator. A GUMMEI is comprised of a PLMN ID, an MMEGI, and an MMEC. A UE accesses a cell with the IE Registered MME. If this option is selected, the eNodeB selects an MME, whose MMEGI and MMEC totally match those indicated by the IE. If no MME meets the exact match requirement, the eNodeB selects an MME based on priorities, topologies, and loads of MMEs and the NNSFENHANCEMENTSWITCH option does not take effect. If this option is deselected, the eNodeB selects an MME using the original algorithm.

CMAS_BROADCAST_SWITCH: CMAS messages of the PLMN can be broadcast over the air interface only if this option is selected. This option takes effect only in MOCN scenarios. When CMAS is enabled, this option must be selected for at least one PLMN. This option applies only to LTE FDD and LTE TDD.

ARP_QCI_BASED_DIFF_SCH_SW: ARP- and QCI-based differentiated scheduling is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

UPPER_LYR_IND_NO_BROADCAST_SW: If this option is selected, the upperLayerIndication-r15 IE of this PLMN is not included in SIB2. If this option is deselected, this IE of this PLMN is included in SIB2. This option takes effect only if the UpperLayerIndicationSwitch parameter in the NsaDcMgmtConfig MO is not set to OFF. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: CELL_TRAFFIC_TRACE_MSG_SWITCH(CELL_TRAFFIC_TRACE_MSG_SWITCH), DCN_SUPPORT_SWITCH(DCN_SUPPORT_SWITCH), MME_STRICT_SELECTION_SWITCH(MME_STRICT_SELECTION_SWITCH), CMAS_BROADCAST_SWITCH(CMAS_BROADCAST_SWITCH), ARP_QCI_BASED_DIFF_SCH_SW(ARP_QCI_BASED_DIFF_SCH_SW), UPPER_LYR_IND_NO_BROADCAST_SW(UPPER_LYR_IND_NO_BROADCAST_SW)

Unit: None

Actual Value Range: CELL_TRAFFIC_TRACE_MSG_SWITCH, DCN_SUPPORT_SWITCH, MME_STRICT_SELECTION_SWITCH, CMAS_BROADCAST_SWITCH, ARP_QCI_BASED_DIFF_SCH_SW, UPPER_LYR_IND_NO_BROADCAST_SW

MML Default Value: None

Recommended Value: CELL_TRAFFIC_TRACE_MSG_SWITCH:On

DCN_SUPPORT_SWITCH:Off

MME_STRICT_SELECTION_SWITCH:Off

CMAS_BROADCAST_SWITCH:On

ARP_QCI_BASED_DIFF_SCH_SW:Off

UPPER_LYR_IND_NO_BROADCAST_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DCN_SUPPORT_SWITCH: If this option is selected and a UE initiates an Attach Request procedure or a cross-DCN TAU procedure, the MME may trigger a Reroute NAS Request procedure for redirection. In this case, the access delay is extended. Deselecting this option has no impact on network performance.

CMAS_BROADCAST_SWITCH: Assume that this option is selected for an eNodeB in RAN sharing with common carrier or hybrid RAN sharing in MOCN scenarios, and the CBCs are independently deployed and do not work in a coordinating way. When the EPC of multiple PLMNs sends the same CMAS messages to the shared cells, air interface resources are wasted. New messages with different contents will be regarded as duplicate messages and discarded by the eNodeB or UEs. If this option is deselected, fewer air interface resources are wasted.

ARP_QCI_BASED_DIFF_SCH_SW: If this option is selected, services with higher ARPs and QCI priorities have higher scheduling weights and larger throughput and services with lower ARPs and QCI priorities have lower scheduling weights and smaller throughput.

Applicable Mode: L

Example

To change the value of CN Operator name to lte for the operator with CN Operator ID of 0, run the following command:
MOD CNOPERATOR: CnOperatorId=0, CnOperatorName="lte";
