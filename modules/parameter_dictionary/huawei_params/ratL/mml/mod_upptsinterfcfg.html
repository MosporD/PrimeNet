Modify UpPTS Interference Configuration (MOD UPPTSINTERFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the UpPTS interference parameter configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TestPeriod Adjust Period

Meaning: Indicates the interval at which the eNodeB adjusts sounding resources. This parameter applies only to LTE TDD.

GUI Value Range: 50~600

Unit: s

Actual Value Range: 50~600

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to less frequent detection of the UpPTS interference and smaller signaling overheads. A smaller value of this parameter leads to more frequent detection of the UpPTS interference and larger signaling overheads.

Applicable Mode: L-TDD
TestThreshold Test Threshold

Meaning: Indicates the threshold of UpPTS interference for determining whether such interference is severe. If UpPTS interference is greater than or equal to this threshold, the eNodeB determines that such interference is severe. The eNodeB can determine whether such interference is minor or medium based on the values of this parameter and the TestHysteresis parameter in the UpPTSInterfCfg MO. If UpPTS interference is less than this threshold subtracted by the TestHysteresis parameter in the UpPTSInterfCfg MO, the eNodeB determines that such interference is minor. If UpPTS interference is greater than or equal to this threshold subtracted by the TestHysteresis parameter in the UpPTSInterfCfg MO and less than this threshold, the eNodeB determines that such interference is medium. This parameter applies only to LTE TDD.

GUI Value Range: -115~-80

Unit: dBm

Actual Value Range: -115~-80

MML Default Value: None

Recommended Value: -100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter decreases the possibility of SRS-transmission-forbidden in UpPTS due to severe UpPTS interference. A small value of this parameter increases the possibility of SRS-transmission-forbidden in UpPTS due to severe UpPTS interference.

Applicable Mode: L-TDD
TestHysteresis Test Hysteresis

Meaning: Indicates the hysteresis for determining whether UpPTS interference is minor or moderate. This parameter is used to reduce the ping-pong effect caused by interference fluctuation. The eNodeB can determine whether UpPTS interference is minor or moderate based on the values of this parameter and the TestThreshold parameter in the UpPTSInterfCfg MO. If UpPTS interference is less than the value of the TestThreshold parameter in the UpPTSInterfCfg MO subtracted by the value of this parameter, the eNodeB determines that such interference is minor. If UpPTS interference is greater than or equal to the TestThreshold parameter in the UpPTSInterfCfg MO subtracted by this parameter and less than the TestThreshold parameter in the UpPTSInterfCfg MO, the eNodeB determines that such interference is moderate. This parameter applies only to LTE TDD.

GUI Value Range: 5~35

Unit: dB

Actual Value Range: 5~35

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter effectively reduces the ping-pong switchings between the state of SRS-transmission-forbidden in UpPTS and that of SRS-transmission-allowed in UpPTS due to interference fluctuation. A small value of this parameter increases the ping-pong switchings.

Applicable Mode: L-TDD

Example

To modify the configuration of the UpPTS Interference with the parameters as follows: Local cell ID: 0, Test Period: 50, run the following command:
MOD UPPTSINTERFCFG: LocalCellId=0, TestPeriod=50;
