Modify ANR (MOD ANR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the ANR configuration.

Note

None.

Parameters

DelCellThd ANR delete cell threshold

Meaning: Indicates the threshold for removing a neighbor relationship with a cell by ANR based on the handover success rate. The threshold is the percentage of the number of successful handovers to the total number of handovers from the local cell to the neighboring cell.

For example, an external cell has been configured as a neighboring cell for each cell served by the eNodeB, automatic removal of these neighbor relationships by ANR is allowed, and the control mode is Auto_Mode. If the success rate of handovers from each cell under the eNodeB to this neighboring cell within a measurement period is lower than or equal to this threshold, this external cell and the neighbor relationships with this cell are automatically removed.

This parameter applies only to LTE FDD and LTE TDD.

FastAnrMode Fast ANR Mode

Meaning: Indicates the policy based on which fast ANR adds detected cells to NCLs and NRTs.

If this parameter is set to NCL_MODE, fast ANR adds a detected cell that meets certain conditions to an NCL only.

If this parameter is set to NCL_NRT_MODE, fast ANR adds a detected cell that meets certain conditions to an NCL and can add neighbor relationships with cells that meet certain conditions to NRTs based on NCLs.

If this parameter is set to NRT_MODE, fast ANR adds a detected cell that meets certain conditions and with which the neighbor relationship is not in an NRT of the source cell to an NCL and adds the neighbor relationship with the detected cell to an NRT of the source cell based on CGI reading. Neighbor relationships with cells that meet certain conditions cannot be directly added to NRTs based on NCLs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NCL_MODE(NCL Mode), NCL_NRT_MODE(NCL and NRT Mode), NRT_MODE(NRT_MODE)

Unit: None

Actual Value Range: NCL_MODE, NCL_NRT_MODE, NRT_MODE

MML Default Value: None

Recommended Value: NCL_MODE(NCL Mode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Different parameter settings lead to different cells to be added by fast ANR.

If this parameter is set to NCL_MODE, only external cells are added and no new neighbor relationships are added. Therefore, no redundant neighboring cells are added.

When this parameter is set to NCL_NRT_MODE, the NCL is regarded reliable. Compared with the value NCL_MODE, the value NCL_NRT_MODE leads to more neighbor relationships added to the NRT by fast ANR, a larger number of handovers, and a higher handover success rate. However, the value NCL_NRT_MODE also results in a higher probability of adding redundant neighboring cells, which has no negative impacts on KPIs.

When this parameter is set to NRT_MODE, the NCL is regarded less reliable than when this parameter is set to NCL_NRT_MODE, which prevents addition of incorrect neighbor relationships. When neighbor relationships are added for the first time, more signaling messages are transmitted over the Uu interface. However, this ensures the neighbor relationship correctness, decreases the probability of falsely reporting PCI confusion alarms, and increases the intra-RAT intra- and inter-frequency handover success rates.

Applicable Mode: L-FDD, L-TDD
EventAnrMode Event ANR Mode

Meaning: Indicates the policy based on which intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs.

If this parameter is set to BASED_NCL, intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs based on NCLs.

If this parameter is set to NOT_BASED_NCL, intra-RAT event-triggered ANR and event-triggered ANR with NR add neighbor relationships to NRTs based on CGIs reported by UEs instead of based on information in NCLs. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: When PCIs are appropriately planned and the eNodeB or gNodeB capacity is small, you are advised to set this parameter to BASED_NCL. This is because, in such a scenario, the NCL is reliable and will not lead to inappropriate neighbor relationships. Adding neighbor relationships based on the NCL can reduce the number of Uu signaling messages and make neighbor relationship addition more quickly when the neighbor relationships are added for the first time.

When PCIs are not appropriately planned and the eNodeB or gNodeB capacity is large, you are advised to set this parameter to NOT_BASED_NCL. This is because, in such a scenario, the NCL is not reliable and will lead to inappropriate neighbor relationships. If the neighbor relationship is added for the first time, the number of Uu signaling messages increases. This ensures neighbor relationship correctness, decreases the possibility of falsely reporting PCI confusion alarms, increases the intra-RAT intra-frequency and inter-frequency handover success rates, and increases the DC SCell configuration success rate.

CaUeChoseMode CA UE Chose Mode

Meaning: Indicates the policy based on which the eNodeB selects CA UEs to perform CGI reading for ANR (excluding event-triggered ANR based on CA measurements or NSA DC measurements).

If this parameter is set to CA_UE_CAP, the eNodeB does not select the CA UEs that support the CA bands in the CA band combinations supported by the eNodeB.

If this parameter is set to CA_UE_CARRIER_NUM, the eNodeB does not select the CA UEs that are each served by more than one carrier.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to CA_UE_CAP and the neighboring cell is an unknown cell or the PCI confusion occurs, the eNodeB does not select CA UEs to perform CGI reading for ANR. As a result, handovers may not be performed and service drops occur. If this parameter is set to CA_UE_CARRIER_NUM and the neighboring cell is an unknown cell or the PCI confusion occurs, the eNodeB selects CA UEs served by a single carrier to perform CGI reading during ANR. The service drop rate decreases in the preceding scenario but the number of handovers increases. If this parameter is set to ANR_UE_CAP and the neighboring cell is an unknown cell or the PCI confusion occurs, the eNodeB selects all CGI-reading-capable UEs. As a result, new neighboring cells or the correct target cell for handovers can be identified in the preceding scenario and service drops can be avoided.

Meaning: Indicates whether the eNodeB can initiate handovers to a newly detected neighboring cell, with which the neighbor relationship is to be processed by the MAE.

If this parameter is set to FORBID_HO, the eNodeB does not initiate handovers to the newly detected neighboring cell before the corresponding neighbor relationship is manually confirmed. Impact on Radio Network Performance: A smaller value of this parameter leads to a shorter monitoring state period of fast ANR and a longer time in which the throughput of UEs performing measurements for fast ANR is affected but a higher efficiency of detecting unknown neighboring cells by fast ANR. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
NrFastAnrRsrpThld NR Fast ANR RSRP Threshold

Meaning: Indicates the RSRP threshold used in fast ANR with NR. If the UE-reported RSRP of an NR cell is lower than this threshold, the eNodeB does not automatically add this NR cell to the NCL or NRT. If this parameter is set to a value other than 0, fast ANR with NR is enabled, and an NR NRT is created and optimized based on the results of periodic NR measurements. If this parameter is set to 0, fast ANR with NR is disabled, and the NR NRT is not created or optimized based on the results of periodic NR measurements. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -156~-31,0

Unit: dBm

Actual Value Range: -156~-31,0

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NrFr2CgiReadingTimer NR FR2 CGI Reading Timer

Meaning: Indicates the length of the timer for ANR-triggered CGI reading of cells on the FR2 frequency of the NR system. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~32

Unit: 0.5s

Actual Value Range: 1~16

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a shorter duration for UEs to read NR CGIs and a higher probability that the CGI reading success rate will decrease. A larger value of this parameter indicates a longer duration for UEs to read NR CGIs, and a higher probability that NR CGIs will be successfully read.

Applicable Mode: L-FDD, L-TDD
