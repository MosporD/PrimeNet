Add Parameter Group for Handover to CDMA2000 HRPD (ADD INTERRATHOCDMAHRPDGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a parameter group related to inter-RAT handover to CDMA2000 HRPD.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the ID of the QCI-specific parameter group related to inter-RAT handover to CDMA2000 HRPD. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

InterRatHoCdmaB1Hyst CDMA2000HRPD handover hysteresis

Meaning: Indicates the hysteresis for event B1 related to inter-RAT handover to CDMA2000 HRPD. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The entering condition of event B1 is as follows: Mn + Ofn - Hys > Thresh.

Mn is the measurement value of the neighboring cell. Ofn is the frequency-specific offset of the neighboring cell. Thresh is the threshold for this event. Hys is the hysteresis for this event, which is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation or fading.

A larger value of Hys results in a lower probability of triggering event B1 and hence causes a lower probability of handover. A large value may affect user experience. A smaller value of Hys leads to a higher probability of triggering event B1. A small value may cause handover decision errors and ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
InterRatHoCdmaB1ThdPs CoverageBased CDMA2000HRPD trigger threshold

Meaning: Indicates the pilot strength threshold for event B1 related to load- or service-based inter-RAT handover to CDMA2000 HRPD.

When the measurement value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -63~0

Unit: 0.5dB

Actual Value Range: -31.5~0

MML Default Value: -14

Recommended Value: -14

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handover to the CDMA2000 HRPD cell, and a smaller value leads to a higher probability.

Applicable Mode: L-FDD, L-TDD
InterRatHoCdmaB1TimeToTrig CDMA2000HRPD time to trigger

Meaning: Indicates the time-to-trigger for event B1 related to inter-RAT handover to CDMA2000 HRPD.

When detecting that the signal quality in at least one neighboring cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting, the average number of handovers, and the number of wrong handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

MML Default Value: 640ms(640ms)

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handover to the CDMA2000 HRPD cell, and a smaller value results in a higher probability.

Applicable Mode: L-FDD, L-TDD

Example

To add a parameter group related to inter-RAT handover to CDMA2000 HRPD with Local cell identity of 0, InterRATHoCDMAHRPDGroupID of 0, and other parameters retaining their default values, run the following command:
ADD INTERRATHOCDMAHRPDGROUP: LocalCellId=0, InterRatHoCDMAHRPDGroupID=0;
