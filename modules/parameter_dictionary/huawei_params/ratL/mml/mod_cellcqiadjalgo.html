Modify Parameters Related to Cell CQI Adjustment (MOD CELLCQIADJALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-specific CQI adjustment configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InitDlIblerTarget Initial Downlink IBLER Target

Meaning: Indicates the initial value of the downlink target IBLER. For LTE FDD cells, this parameter does not specify the target IBLER when downlink target IBLER adaption and enhanced downlink target IBLER adaption are enabled. For LTE TDD cells, this parameter specifies the target IBLER when downlink target IBLER adaption and enhanced downlink target IBLER adaption are enabled. If this parameter is set to 100, the CQI adjustment amount is not updated. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, the MCS index is high and the retransmission rate is large. In this case, if the spectral efficiency gains brought by the high-index MCS are greater than the loss due to the increased retransmission rate, the downlink throughput increases. Otherwise, the downlink throughput decreases. If this parameter is set to a small value, the MCS index is low and the retransmission rate is small. In this case, if the spectral efficiency loss brought by the low-index MCS is smaller than the gains brought by the decreased retransmission rate, the downlink throughput increases. Otherwise, the downlink throughput decreases.

Applicable Mode: L-FDD, L-TDD
InitDeltaCqi Initial Delta Cqi

Meaning: Indicates the initial CQI adjustment amount. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -10~26

Unit: None

Actual Value Range: -10~26

MML Default Value: None

Recommended Value: -4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, the initial MCS index for a UE is high, which may lead to a high BLER. If this parameter is set to a small value, the initial MCS index for a UE is low.

Applicable Mode: L-FDD, L-TDD
CqiAdjStep CQI Adjust Step

Meaning: Indicates the adjustment efficiency of the baseline step in the CQI adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1000

Unit: None

Actual Value Range: 0~10, step: 0.01

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the CQI is slowly adjusted. In this case, if the signal fluctuates in the channel, the IBLER convergence rate is small. If the channel does not fluctuate, the MCS index fluctuates slightly after the optimal MCS index is achieved.

If this parameter is set to a large value, the CQI is fast adjusted. In this case, if the signal fluctuates in the channel, the IBLER convergence rate is large, which increases the downlink throughput but the MCS index may fluctuate greatly. Therefore, the parameter must be set to a value balancing the CQI adjustment efficiency and accuracy.

Applicable Mode: L-FDD, L-TDD
CqiFilterCoefForMcs CQI Filter Coefficient for MCS

Meaning: Indicates the CQI filtering coefficient in the CQI adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1024

Unit: None

Actual Value Range: 0~1, step: 1/1024

MML Default Value: None

Recommended Value: HighSpeedFlag of cell is set to ULTRA_HIGH_SPEED: 32; HighSpeedFlag of cell is not set to ULTRA_HIGH_SPEED: 256.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the filtering is obvious, but the channel changes are hardly traced. If this parameter is set to a large value, the capability against fast fading is strong, but the MCS index fluctuates greatly.

Applicable Mode: L-FDD, L-TDD
CqiOptSwitch CQI Optimization Algorithm Switch

Meaning: Indicates whether to enable optimization algorithms for CQI transmission on the PUCCH and PUSCH.

PUSCH_CQI_FALSE_DETECTION_SW: Indicates whether to enable the algorithm of counteracting false detection of CQIs on the PUSCH. The algorithm effectively reduces the probability of false CQI detection. False CQI detection occurs if a UE does not report a CQI but the eNodeB detects a CQI from the UE. The algorithm is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PUCCH_CQI_FALSE_DETECTION_SW: Indicates whether to enable the algorithm of counteracting false detection of CQIs on the PUCCH. The algorithm is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PUSCH_CQI_FALSE_DETECTION_SW(PUSCH_CQI_FALSE_DETECTION_SW), PUCCH_CQI_FALSE_DETECTION_SW(PUCCH_CQI_FALSE_DETECTION_SW)

Unit: None

Actual Value Range: PUSCH_CQI_FALSE_DETECTION_SW, PUCCH_CQI_FALSE_DETECTION_SW

MML Default Value: None

Recommended Value: PUSCH_CQI_FALSE_DETECTION_SW:Off,

PUCCH_CQI_FALSE_DETECTION_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: PUSCH_CQI_FALSE_DETECTION_SW: When this option is selected, the probability of falsely detecting CQIs on the PUSCH decreases. When this option is deselected, the probability increases.

PUCCH_CQI_FALSE_DETECTION_SW: When this option is selected, the probability of falsely detecting CQIs on the PUCCH in format 2, 2a, or 2b decreases. When this option is deselected, the probability increases.

Applicable Mode: L-FDD, L-TDD
VolteNackDeltaCqi Volte NACK Delta CQI Adjustment

Meaning: Indicates the decrease in CQI adjustment value when a voice UE returns an NACK message. If the DLDeltaCqiOptSwitch option of the DlVolteCqiAdjOptSw parameter in the CellCqiAdjAlgo MO is selected, the CQI adjustment value decreases by the amount specified by this parameter when a voice UE returns an NACK message. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~330

Unit: None

Actual Value Range: 0~33, step: 0.1

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the CQI adjustment value and the voice packet delay of voice UEs decrease by small amounts, but a small number of RBs are consumed by the PDSCH for voice UEs. If this parameter is set to a large value, the CQI adjustment value and the voice packet delay of voice UEs decrease by large amounts, but a large number of RBs are consumed by the PDSCH for voice UEs.

Applicable Mode: L-FDD, L-TDD
DlVolteCqiAdjOptSw DL Volte CQI Adjust Optimization Switch

Meaning: Indicates whether to optimize downlink CQI adjustment for voice UEs.

DLDeltaCqiOptSwitch: Indicates whether to optimize the downlink CQI adjustment value for voice UEs. If this option is selected, the eNodeB lowers the downlink CQI adjustment value for voice UEs and the MCS index of voice services. If this option is deselected, the downlink CQI adjustment value of voice UEs is processed in the same way as that for other UEs. This option applies only to LTE FDD and LTE TDD.

DlRetxTbsOptSwitch: Indicates whether to optimize the TBS indexes for downlink retransmissions to voice UEs. If this option is selected, the eNodeB decreases the TBS indexes for downlink retransmissions to voice UEs. If this option is deselected, the eNodeB selects TBS indexes for downlink retransmissions to voice UEs in the same way as it selects TBS indexes for downlink retransmissions to other UEs. This option applies only to LTE TDD.

DlPttCqiOptSwitch: Indicates whether to optimize CQIs for downlink PTT services. CQIs for downlink PTT services are optimized only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: DLDeltaCqiOptSwitch(DLDeltaCqiOptSwitch), DlRetxTbsOptSwitch(DlRetxTbsOptSwitch), DlPttCqiOptSwitch(DlPttCqiOptSwitch)

Unit: None

Actual Value Range: DLDeltaCqiOptSwitch, DlRetxTbsOptSwitch, DlPttCqiOptSwitch

MML Default Value: None

Recommended Value: DLDeltaCqiOptSwitch:Off, DlRetxTbsOptSwitch:Off, DlPttCqiOptSwitch:Off

Parameter Relationship:

-Configuration constraints:

  • In a CellCqiAdjAlgo MO, if the DlPttCqiOptSwitch option of the DlVolteCqiAdjOptSw parameter is selected, the DLDeltaCqiOptSwitch option of this parameter must be selected too.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DLDeltaCqiOptSwitch: If this option is selected, the downlink transmission delay of voice UEs decreases, and the voice quality of these UEs is improved. However, the number of RBs consumed by the PDSCH for voice UEs increases, lowering the throughput of data services in the cell. If this option is deselected, the network performance is not affected.

DlRetxTbsOptSwitch: If this option is selected, the downlink transmission delay of voice UEs decreases, and the voice quality of these UEs is improved. However, the number of RBs consumed by the PDSCH for retransmission for voice UEs increases, lowering the throughput of data services in the cell. If this option is deselected, the network performance is not affected.

DlPttCqiOptSwitch: If this option is selected, the transmission delay decreases for UEs running downlink PTT services, improving voice quality; however, these UEs consume more PDSCH RBs, causing a decrease in data service throughput in the cell. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
MuBfPacketThld MU Beamforming Packet Count Threshold

Meaning: Indicates the threshold, which is the number of packets transmitted using MU beamforming, used to trigger MCS index selection optimization for MU beamforming subframes when MU beamforming is enabled. This threshold is used to determine whether the eNodeB performs MCS index selection optimization for MU beamforming based on only out-loop information of MU beamforming. If this parameter is set to 65535, MCS index selection optimization is disabled for MU beamforming subframes. This parameter takes effect only when the massive MIMO feature is enabled. This parameter applies only to LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to 65535 in non-massive-MIMO scenarios. In massive MIMO scenarios, it is recommended that this parameter be set to 20 if three or more layers are paired in a cell and to 65535 if less than three layers are paired in a cell.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter leads to a high probability that the eNodeB selects the MCS index for MU beamforming based on the out-loop information of both MU and SU beamforming, achieving better network performance when the pairing rate is low. A small value of this parameter leads to a high probability that the eNodeB selects the MCS index for MU beamforming based on only the out-loop information of MU beamforming, achieving better network performance when the pairing rate is high.

Applicable Mode: L-TDD
CellDeltaCqiSampSelThd Cell CQI Adjustment Sample Selection Thld

Meaning: Indicates the threshold for selecting samples for the CQI adjustment value for massive MIMO and beamforming in the cell. In massive MIMO scenarios, if the number of times of dynamic initial transmission for a MIMO UE (excluding beamforming UEs) is greater than or equal to this threshold, the UE-specific CQI adjustment value of this UE can be used as a maintenance sample for cell-specific CQI adjustment and provides a reference for selecting an aggregation level for beamforming UEs if the capacity-based aggregation level selection policy is implemented. In non-massive MIMO scenarios, if the number of times of dynamic initial transmission for either a MIMO UE or beamforming UE is greater than or equal to this threshold, the UE-specific CQI adjustment value of this UE can be used as a maintenance sample for cell-specific CQI adjustment and provides a reference for selecting an aggregation level for beamforming UEs if the PDSCH and capacity-based PDCCH aggregation level selection policy is implemented. If this parameter is set to 0, the cell-specific CQI adjustment value for MIMO and beamforming is not used for PDSCH and PDCCH aggregation level selection for beamforming UEs. This parameter applies only to LTE TDD.

GUI Value Range: 0~400

Unit: None

Actual Value Range: 0~400

MML Default Value: None

Recommended Value: In non-massive MIMO scenarios, it is recommended that this parameter be set to 50. In massive MIMO scenarios, it is recommended that this parameter be set to 100 when the number of MIMO UEs and the number of packets are large, and set to 20 when the number of MIMO UEs and the number of packets are small.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, the cell-specific CQI adjustment value for MIMO and beamforming is not used for aggregation level selection for beamforming UEs when PDSCH outer loop adjustment is performed and the capacity-based PDCCH aggregation level selection policy is implemented. If the number of UEs and the number of packets are small, only a few samples for the cell-specific CQI adjustment value are obtained, and the cell-specific CQI adjustment value for MIMO and beamforming is inaccurate. In this case, the DTX proportion and packet error rate of some beamforming UEs may increase. If the number of UEs and the number of packets are large, the UE-specific CQI adjustment amount value converges, and the cell-specific CQI adjustment value is accurate. In this case, the DTX proportion and packet error rate of beamforming UEs decrease.

Applicable Mode: L-TDD
CellCqiAdjSchCntThld Cell CQI Adjustment Schedule Count Thld

Meaning: Indicates the threshold of the number of scheduling times for determining samples used to adaptively set the cell-level CQI adjustment value. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is deselected and the number of dynamic initial scheduling times of a MIMO UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If the MM_DL_SCH_AND_MCS_OPT_SWITCH option of the MMAlgoOptSwitch parameter is selected and the number of dynamic initial scheduling times of either a MIMO UE or beamforming UE is greater than or equal to this threshold, the UE-level CQI adjustment value of this UE can be used as a maintenance sample for cell-level CQI adjustment. If this parameter is set to 0, the algorithm of adaptively setting the initial cell-level CQI adjustment value does not take effect. This parameter applies only to LTE TDD.

GUI Value Range: 0~1000

Unit: None

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, the algorithm of adaptively setting the initial cell-level CQI adjustment value does not take effect. If this parameter is set to a non-0 value, the algorithm of adaptively setting the initial cell-level CQI adjustment value takes effect. A large value of this parameter leads to a small number of samples for the cell-level CQI adjustment value, accurate cell-level CQI adjustment, and large gains of the downlink cell rate and user-perceived rate. A small value of this parameter leads to a large number of samples for the cell-level CQI adjustment value, inaccurate cell-level CQI adjustment, and small gains of the downlink cell rate and user-perceived rate. If the numbers of MIMO UEs and packets are small, the number of the samples for the cell-level CQI adjustment value decreases, and cell-level CQI adjustment value is inaccurate in MIMO mode. In this case, the DTX proportion and packet error rate of beamforming UEs may increase. If the numbers of MIMO UEs and packets are large, the CQI adjustment value for MIMO UEs converges, cell-level CQI adjustment value is accurate, and the DTX proportion and packet error rate for beamforming UEs decrease. If the initial cell-level CQI adjustment value does not match UE channels, the service drop rate and bit error rate may increase.

Applicable Mode: L-TDD
VolteRptCqiDiffLimit VoLTE CQI Report Difference Limit Value

Meaning: Indicates the maximum difference between the CQI reported for the filtering algorithm and the previously reported CQI. The value 0 indicates that no limit is imposed on the maximum difference. A non-0 value indicates the maximum difference. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~26

Unit: dB

Actual Value Range: 0~26

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The value 0 indicates that no limit is imposed on the maximum difference between the CQI reported for the filtering algorithm and the previously reported CQI. A small value of this parameter (other than 0) leads to a slow increase in the selected MCS index, a more reliable control channel over the air interface, and better voice quality. A large value of this parameter leads to a quick increase in the selected MCS index, a less reliable control channel over the air interface, and worse voice quality.

Applicable Mode: L-FDD, L-TDD

Example

Example 1:To modify the cell-specific CQI adjustment configurations with the parameters as follows: Local Cell ID: 0, Initial Downlink IBLER Target: 20,
MOD CELLCQIADJALGO: LocalCellId=0, InitDlIblerTarget=20;
