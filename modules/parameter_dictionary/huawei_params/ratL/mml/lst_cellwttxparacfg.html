List Cell WTTx Configuration (LST CELLWTTXPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list cell-level WTTx parameter settings.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of WTTx parameters of a cell:
LST CELLWTTXPARACFG:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Upper Limit of DL PRB Usage for MBB User(%)

Indicates the upper limit on the proportion of transmission PRB resources allocated for MBB UEs in the PDSCH. This parameter applies only to LTE FDD and LTE TDD.

Upper Limit of UL PRB Usage for MBB User(%)

Indicates the upper limit on the PUSCH PRB usage of MBB UEs. This parameter applies only to LTE FDD and LTE TDD.

PRB Upper Limit Control Mode

Indicates the PRB upper limit control mode, which can be tight control or loose control. When this parameter is set to TIGHT_CONTROL, the PRB resources for WBB and MBB UEs are subject to their respective uplink and downlink PRB resource upper limits. That is, the amounts of PRB resources allocated to WBB and MBB UEs must not exceed the upper limits even if there are remaining PRB resources in the cell. When this parameter is set to MBB_LOOSE_CONTROL: For MBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after WBB UEs are scheduled, the preset upper limit can be exceeded to allow MBB UEs to use the remaining PRB resources; for WBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to WBB_LOOSE_CONTROL: For WBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after MBB UEs are scheduled, the preset upper limit can be exceeded to allow WBB UEs to use the remaining PRB resources; for MBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to LOOSE_CONTROL, if the amount of PRB resources allocated to MBB or WBB UEs has reached the preset upper limit and there are remaining PRB resources, the limit can be exceeded to allow MBB or WBB UEs to use the remaining PRBs. This parameter applies only to LTE FDD and LTE TDD.

WBB or MBB User Definition Mode

Indicates the WBB and MBB UE definition modes. This parameter provides the SPID-based and QCI-based definition modes. When this parameter is set to SPID_BASED, the eNodeB regards UEs configured with SPIDs and whose SpecifiedUserFlag is set to SPECSERUSER as WBB UEs. Other UEs are regarded as MBB UEs. When this parameter is set to QCI_BASED, the eNodeB regards UEs that set up the bearers with QCIs indicating WBB services (ServiceFlag set to WBB_SERVICE) as WBB UEs. Other UEs are regarded as MBB UEs. This parameter applies only to LTE FDD and LTE TDD.

Upper Limit of DL PRB Usage for WBB User(%)

Indicates the upper limit on the proportion of transmission PRB resources allocated for WBB UEs in the PDSCH. This parameter applies only to LTE FDD and LTE TDD.

Upper Limit of UL PRB Usage for WBB User(%)

Indicates the upper limit on the proportion of transmission PRB resources allocated for WBB UEs in the PUSCH. This parameter applies only to LTE FDD and LTE TDD.

Dynamic Control MBB UE PRB Threshold(%)

Indicates the MBB UE PRB usage threshold for triggering PRB restriction for WBB UEs. When the WBB_UE_DL_DYN_PRB_LMT_SWITCH option of the SpecUserAlgoSwitch parameter is selected, if the average PRB usage of MBB UEs is lower than or equal to this threshold, downlink PRB restriction will not be applied to WBB UEs. This parameter applies only to LTE FDD and LTE TDD.

Dynamic Control UE Count High Pct Thld

Indicates the MBB-to-WBB UE number ratio threshold for triggering high restriction on downlink PRBs for WBB UEs. When the WBB_UE_DL_DYN_PRB_LMT_SWITCH option of the SpecUserAlgoSwitch parameter is selected, if the MBB-to-WBB UE number ratio is higher than this threshold and the average PRB usage of MBB UEs is higher than the value of the DynCtrlMbbUePrbThd parameter in the CellWttxParaCfg MO, high restriction on downlink PRBs will be applied to WBB UEs. This parameter applies only to LTE FDD and LTE TDD.

Dynamic Control UE Count Low Pct Thld

Indicates the MBB-to-WBB UE number ratio threshold for triggering low restriction on downlink PRBs for WBB UEs. When the WBB_UE_DL_DYN_PRB_LMT_SWITCH option of the SpecUserAlgoSwitch parameter is selected, if the MBB-to-WBB UE number ratio is higher than this threshold and lower than or equal to the value of the DynCtrlUeCntHighPctThld parameter in the CellWttxParaCfg MO and the average PRB usage of MBB UEs is higher than the value of the DynCtrlMbbUePrbThld parameter in the CellWttxParaCfg MO, low restriction on downlink PRBs will be applied to WBB UEs. This parameter applies only to LTE FDD and LTE TDD.

IPTV Guarantee User Count

Indicates the upper limit on the number of IPTV UEs for which rate acceleration is used for rate guarantee in a cell where IPTV admission control is used. When the number of UEs running IPTV services in the cell exceeds this limit, the eNodeB no longer accelerates rates for newly admitted IPTV UEs. If this parameter is set to 0, the IPTV admission control function does not take effect. That is, the eNodeB accelerates rates for all IPTV UEs in the cell. If multiple bearers have been set up for a UE, the number of identified IPTV UEs equals the number of bearers carrying IPTV data flows. This parameter applies only to LTE FDD and LTE TDD.

WBB Performance Optimization Switch

Indicates whether to enable WBB performance optimization.

DL_CA_SCC_CONFIG_ACT_OPT_SW: Indicates whether to enable the algorithm for optimizing downlink CA SCC configuration and activation. If this option is selected, optimization of downlink CA SCC configuration and activation is enabled. Massive MIMO SCCs can be configured and activated only for UEs supporting uplink CA. If this option is deselected, optimization of downlink CA SCC configuration and activation is disabled. This option applies only to LTE TDD.

WBB_ANT_SELECTION_UE_IDENT_SW: Indicates whether to enable identification of WBB UEs capable of transmit antenna selection. If this option is selected, identification of WBB UEs capable of transmit antenna selection is enabled. Transmit antenna selection is configured for WBB UEs identified using SPIDs based on their capabilities. Transmit antenna selection is disabled for non-WBB UEs. If this option is deselected, the identification is disabled. This option applies only to LTE TDD.

WBB Multi-Carrier Coordination A2 Offset(dB)

Indicates the offset to the threshold for event A2 that triggers handover of CA UEs running WBB services in multi-carrier scenarios from a high-frequency cell to a low-frequency cell.
