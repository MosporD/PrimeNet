Modify Blind Handover Configuration (MOD CSFALLBACKBLINDHOCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration related to inter-RAT blind handover.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHighestPri Highest priority InterRat

Meaning: Indicates the highest-priority RAT for handovers. It is UTRAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the highest-priority RAT is UTRAN, GERAN, or CDMA2000, respectively.

The value CDMA2000 is invalid in the current version. Therefore, avoid setting this parameter to CDMA2000. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: UTRAN, GERAN, CDMA2000

Unit: None

Actual Value Range: UTRAN, GERAN, CDMA2000

MML Default Value: None

Recommended Value: UTRAN

Parameter Relationship:

-Configuration constraints:

  • In the CSFallBackBlindHoCfg MO, InterRatHighestPri must be different from InterRatLowestPri.
  • In the CSFallBackBlindHoCfg MO, InterRatHighestPri must be different from InterRatSecondPri.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatSecondPri Second priority InterRat

Meaning: Indicates the medium-priority RAT for handovers. It is GERAN by default. If this parameter is set to UTRAN, GERAN, or CDMA2000, the medium-priority RAT is UTRAN, GERAN, or CDMA2000, respectively. If this parameter is set to NULL, no medium-priority RAT is specified and only the highest-priority RAT can be selected for handovers.

The value CDMA2000 is invalid in the current version. Therefore, avoid setting this parameter to CDMA2000. This parameter applies only to LTE FDD and LTE TDD.

UtranCsfbBlindRedirRrSw CSFB to UTRAN Blind Redirection RR Switch

Meaning: Indicates whether the eNodeB selects the target frequency in a round robin (RR) manner from frequencies with the same priority in blind redirections for CSFB to UTRAN. If this parameter is set to ON(On), the function of target frequency selection in an RR manner is enabled. If this parameter is set to OFF(Off), this function is disabled. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: The UtranCsfbBlindRedirRrSw parameter will be replaced by the CsfbFlowOptSwitch parameter in the GlobalProcSwitch MO. The configuration interface in the version supports the delivery of the settings of both the UtranCsfbBlindRedirRrSw and CsfbFlowOptSwitch parameters. The UtranCsfbBlindRedirRrSw parameter takes effect if the UtranCsfbBlindRedirRrSw parameter is set to ON. The CsfbFlowOptSwitch parameter takes effect if the UtranCsfbBlindRedirRrSw parameter is set to OFF. Therefore, avoid using this parameter.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the eNodeB selects the target frequency from frequencies with the same priorities in an RR manner and therefore load balancing between different UTRAN cells can be achieved. If this parameter is set to OFF, the load of cells on some UTRA frequencies increases.

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration related to inter-RAT blind handover  with the parameters as follows: CnOperatorId: 0, Highest PRI InterRat: UTRAN, CDMA2000 LCS CAP: OFF, CSFB Highest PRI InterRat for Idle UE: UTRAN, run the following command:
MOD CSFALLBACKBLINDHOCFG: CnOperatorId=0, InterRatHighestPri=UTRAN, CdmaLcsCap=OFF, IdleCsfbHighestPri=UTRAN;
