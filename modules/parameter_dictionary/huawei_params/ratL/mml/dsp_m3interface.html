DSP M3INTERFACE (DSP M3INTERFACE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display M3 interface information.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M3Id M3 ID

Meaning: Indicates the ID of the M3 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the M3 dynamic information with the parameters as follows:Local MCE ID: 0, M3 ID:0, run the following command:
+++    HUAWEI        2018-07-23 11:48:57
O&M    #806354968
%%DSP M3INTERFACE: LocalMceId=3, M3Id=0;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

MCE ID

Indicates the ID of an MCE. It uniquely identifies an MCE within a PLMN. The PLMN ID and the MCE ID together constitute the global MCE ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

M3 ID

Indicates the ID of the M3 MO. This parameter applies only to LTE FDD and LTE TDD.

M3 Interface State

Indicates the M3 interface status. This parameter applies only to LTE FDD and LTE TDD.
