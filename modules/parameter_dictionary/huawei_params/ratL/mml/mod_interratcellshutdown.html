Modify Inter-RAT Cell Shutdown Configuration (MOD INTERRATCELLSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of inter-RAT cell shutdown. A cell requiring inter-RAT cell shutdown must be configured with neighboring UTRAN or GERAN cells corresponding to the shutdown type.

Note

A cell is a basic cell if the CellShutdownSwitch parameter in the CellShutdown MO is set to On, the cell is in active and UlPrbThd or DlPrbThd (specifying the uplink or downlink PRB usage threshold) in the CellShutdown MO is set to 0. Basic cells can never enter inter-RAT cell shutdown mode when the ShutDownType parameter in the InterRatCellShutdown MO is set to BY_UTRAN_WITHOUT_LOAD.

ShutDownType Shut Down Type

Meaning: Indicates the type of the inter-RAT co-coverage cell shutdown.

If this parameter is set to BY_UTRAN_WITHOUT_LOAD, the eNodeB does not obtain the load status of the co-coverage neighboring UTRAN cell, and shuts down the carrier of the E-UTRAN cell based on only the load status of the E-UTRAN cell.

If this parameter is set to BY_UTRAN_WITH_LOAD, the eNodeB obtains the load status of the co-coverage neighboring UTRAN cell, and shuts down the carrier of the E-UTRAN cell based on the load status of both the E-UTRAN cell and the neighboring UTRAN cell.

If this parameter is set to BY_GERAN_WITH_LOAD, the eNodeB obtains the load status of the co-coverage neighboring GERAN cell, and shuts down the carrier of the E-UTRAN cell based on the load status of both the E-UTRAN cell and the neighboring GERAN cell.

If this parameter is set to BY_UTRAN_AND_GERAN_WITH_LOAD, the eNodeB obtains the load status of co-coverage neighboring UTRAN and GERAN cells, and shuts down the carrier of the E-UTRAN cell based on the load status of the E-UTRAN cell, neighboring UTRAN cell, and neighboring GERAN cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BY_UTRAN_WITHOUT_LOAD(By UTRAN without load), BY_UTRAN_WITH_LOAD(By UTRAN with load), BY_GERAN_WITH_LOAD(By GERAN with load), BY_UTRAN_AND_GERAN_WITH_LOAD(By UTRAN and GERAN with load)

Unit: None

BearNumThd UE number threshold

Meaning: Indicates the UE number threshold for the E-UTRAN cell to enter the inter-RAT co-coverage cell shutdown.

In inter-RAT cell shutdown, the eNodeB automatically hands over or redirects the UEs in the E-UTRAN cell to a co-coverage neighboring UTRAN cell when related conditions are met: (1) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITHOUT_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration and uplink and downlink resource block (RB) usages in the E-UTRAN cell are met, and the number of UEs served by the E-UTRAN cell is less than or equal to this parameter value.

(2) The inter-RAT cell shutdown switch is enabled, the ShutDownType parameter is set to BY_UTRAN_WITH_LOAD or BY_UTRAN_AND_GERAN_WITH_LOAD, the shutdown conditions including the specified inter-RAT cell shutdown duration, uplink and downlink RB usages in the E-UTRAN cell, allocation/retention priorities (ARPs) of services in the E-UTRAN cell, and load status of the neighboring UTRAN cell are met, and the number of UEs served by the E-UTRAN cell is less than or equal to this parameter value. After all UEs in the E-UTRAN cell are transferred to the neighboring UTRAN cell, the eNodeB shuts down the carrier of the E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.

Example

To modify the configuration of inter-RAT cell shutdown with the parameters as follows: Local cell ID: 0, Inter-RAT cell shutdown switch: ON, Start time: 03&00&00, Stop time: 05&00&00, Shut down type: BY_UTRAN_AND_GERAN_WITH_LOAD, UE number threshold: 20, High priority ARP threshold: 5, Downlink PRB threshold: 15, Uplink PRB threshold: 15, UTRAN cell downlink load threshold: 30, UTRAN cell downlink load offset: 40, UTRAN cell uplink load threshold: 40, UTRAN cell uplink load offset: 15, GERAN cell load threshold: 25, GERAN cell load offset: 20, run the following command:
MOD INTERRATCELLSHUTDOWN: LocalCellId=0, ForceShutdownSwitch=ON, StartTime=03&00&00, StopTime=05&00&00, ShutDownType=BY_UTRAN_AND_GERAN_WITH_LOAD, BearNumThd=20, HighPriArpThd=5, DlPrbThd=15, UlPrbThd=15, UtranCellDlLoadThd=30, UtranCellDlLoadOffset=40, UtranCellUlLoadThd=40, UtranCellUlLoadOffset=15, GeranCellLoadThd=25, GeranCellLoadOffset=20;
