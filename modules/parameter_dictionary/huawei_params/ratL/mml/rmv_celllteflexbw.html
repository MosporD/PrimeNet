Remove CellLteFlexBw (RMV CELLLTEFLEXBW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the start and end PRB position information and flexible bandwidth switch for Flexible Bandwidth.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This execution of this command will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To remove the configuration of LTE Flexible Bandwidth with the parameters as follows: local cell ID: 0, run the following command:
RMV CELLLTEFLEXBW: LocalCellId=0;
