Add External CDMA20001XRTT Cell (ADD CDMA20001XRTTEXTCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an external CDMA2000 1xRTT cell.

Note

If an LMPT board is installed, a maximum of 576 external CDMA2000 1XRTT cells can be configured for an eNodeB. If a UMPT board is installed, a maximum of 1152 external CDMA2000 1XRTT cells can be configured for an eNodeB.

Meaning: Indicates the cell ID of the external CDMA2000 1xRTT cell. The cell ID and sector ID together uniquely identify a CDMA2000 cell in the mobile switching center (MSC). In the CDMA2000 1xRTT network, a cell ID uniquely identifies a cell within the mobile switching center (MSC). A cell ID consists of 12 bits. This parameter applies only to LTE FDD and LTE TDD.

Nid Network ID

Meaning: Indicates the ID of the network to which the external CDMA2000 1xRTT cell belongs. A base station is a cellular system and a member of the network. A network is a subset of a system that is identified by a system ID. A network in a system is identified by a network ID. A system ID and a network ID together uniquely identify a network. System ID 0 and network ID 0 indicate all base stations outside a specified network and are reserved values. Network ID 65535 is also reserved; this ID indicates that the roaming status of UEs is non-roaming in the whole system no matter what the network ID is. For details, see the description of NID in 3GPP2 C.S0005. This parameter applies only to LTE FDD and LTE TDD.

MscId MSC ID

Meaning: Indicates the ID of the MSC to which the reference CDMA2000 1xRTT cell belongs. The value begins with 0x followed by a maximum of 6 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. An MSC ID uniquely identifies an MSC and is determined by the operator.

MSCID is defined in 6.5.2.82 of TIA/EIA-41.5-D and consists of MarketID (2 bytes) and SwitchNo (1 byte). MarketID is described in TIA/EIA TSB29 and can be defined by the operator. It can be the SID or another ID that can differentiate between operators. SwitchNo consists of a group of cell addresses and circuit resource IDs under MarketID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~8 characters

Unit: None

Actual Value Range: 0~8 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • MscId in the Cdma20001XrttExtCell MO must be set to a hexadecimal number starting with 0x and with a total length not greater than 6 digits. A hexadecimal number is composed of upper-case letters (A to F) and digits (0 to 9). The hexadecimal digit following 0x can be 0 only if the parameter is set to 0x0. That is, the parameter value like 0x00AB is inappropriate but 0x0 is acceptable.

CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

Example

To add an external CDMA2000 1xRTT cell with the parameters as follows: CDMA20001XRTT cell ID: 1, CDMA20001XRTT sector ID: 1, Band class: bc0, Frequency: 1234, System ID: 0, Network ID: 0, Mobile country code: "460", Mobile network code: "01", Physical cell ID: 0, run the following command:
ADD CDMA20001XRTTEXTCELL: Cdma20001XrttCellId=1, Cdma20001XrttSectorId=1, BandClass=bc0, Frequency=1234, Sid=0, Nid=0, Mcc="460", Mnc="01", PnOffset=0;
