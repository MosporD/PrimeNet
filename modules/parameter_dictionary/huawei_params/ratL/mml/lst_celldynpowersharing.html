List Cell Dynamic Power Sharing (LST CELLDYNPOWERSHARING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of dynamic power sharing in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list cell dynamic power sharing with the local cell ID of 1, run the following command:
LST CELLDYNPOWERSHARING: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Dynamic Power Sharing Switch

Indicates whether to enable dynamic power sharing. This parameter consists of the following options:

LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers. These LTE carriers can be FDD carriers or TDD carriers, but cannot be any combination of FDD and TDD carriers. When this option is selected, power can be shared between LTE carriers. This option applies only to LTE FDD and LTE TDD.

UMTS_LTE_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and UMTS carriers. When this option is selected, power can be shared between LTE and UMTS carriers. This option applies only to LTE FDD.

LTE_NR_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE and NR carriers. When this option is selected, power can be shared between LTE and NR carriers. This option applies only to LTE TDD.

LTE_EXTREME_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers that share the same channel and between split cells. When this option is selected, power can be shared between LTE carriers that share the same channel and between split cells. This option applies only to LTE FDD.

Max Power Sharing Rate(%)

Indicates the maximum percentage of power that the LTE carrier can share from other carriers. This parameter applies only to LTE FDD and LTE TDD.

Interference Control Switch

Indicates whether to enable interference control. If this parameter is set to ON, interference control is enabled. The eNodeB periodically predicts the impact of the local cell's reception of shared power on neighboring cells in terms of interference. If the prediction results indicate that the overall performance of the local and neighboring cells will be better after power sharing, the eNodeB allows the local cell to receive shared power in the next period. If this parameter is set to OFF, interference control is disabled. This parameter applies only to LTE FDD and LTE TDD.

Power Adjustment Mode

Indicates the power adjustment mode of the cell that receives shared power. If this parameter is set to PDSCH_ONLY, the eNodeB increases only PDSCH power in the cell. If this parameter is set to CRS_AND_PDSCH, the eNodeB increases both CRS power and PDSCH power in the cell. This option applies only to LTE FDD.

Power Insufficiency Time Rate Threshold(%)

Indicates the threshold, which is a percentage of the scheduling time with power insufficiency, for LTE extreme power sharing to take effect. The larger the value of this parameter, the longer the allowed duration of power insufficiency and the higher the probability that power sharing takes effect. The smaller the value of this parameter, the shorter the allowed duration of power insufficiency and the lower the probability that power sharing takes effect. This parameter applies only to LTE FDD.
