Add Neighboring Relation with UTRAN Cell (ADD UTRANNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the neighboring relation with a UTRAN cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The UtranFddTddType parameter in the UtranExternalCell and UtranNFreq MOs associated with the UtranNCell MO must have the same value.

  • The frequency of the external UTRAN cell associated with a neighboring UTRAN cell must have been configured as a neighboring UTRAN frequency, and the operator for the neighboring UTRAN frequency must be the same as that for the neighboring UTRAN cell.

  • Before running this command, ensure that the associated external UTRAN cell has been configured.

  • A maximum of 128 neighboring relations with UTRAN cells can be configured for each E-UTRAN cell.

  • In all MOs of a local cell, the combination of UtranDlArfcn and PScrambCode must be unique in each UtranNCell MO.

  • The ANR flag parameter specifies whether a neighboring cell is automatically detected by ANR. This parameter cannot be set in the MML command window but can be set by running MML commands in command line or running batch commands. This parameter can be queried by running LST commands.

    The default parameter value BOOLEAN_FALSE(False) is delivered when ADD commands are executed in the MML command window. The value BOOLEAN_FALSE(False) indicates that the neighboring cell is manually configured.

    When a neighbor relationship is automatically added by ANR, this parameter is set to BOOLEAN_TRUE(True), indicating that the neighboring cell is automatically configured.

    You are advised not to set the AnrFlag parameter by running MML commands in command line or running batch commands.

RncId RNC ID

Meaning: Indicates the RNC ID of the external UTRAN cell. There are two RNC ID patterns: RNC-ID and extended RNC-ID. A 28-bit UTRAN cell ID is comprised of an RNC ID and an RNC-wide cell ID. In the RNC-ID pattern, the most significant 12 bits of the UTRAN cell ID represent the RNC ID and the least significant 16 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 65536 + CellId. In the extended RNC-ID pattern, the most significant 16 bits of the UTRAN cell ID represent the RNC ID and the least significant 12 bits represent the RNC-wide cell ID. The UTRAN cell ID is calculated using the following formula: UTRAN Cell Identity = RncId x 4096 + CellId. For details about this parameter, see 3GPP TS 25.401. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

BlindHoPriority Blind handover priority

Meaning: Indicates the priority of the neighboring cell during blind handovers. Blind handover is a process in which the eNodeB instructs a UE to hand over to a specified neighboring cell. There are 32 priorities altogether. The priority has a positive correlation with the value of this parameter. Note that the value 0 indicates that blind handovers to the neighboring cell are not allowed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~32

Actual Value Range: 0~32

Impact on Radio Network Performance: During a blind handover, the eNodeB selects a target cell for the UE based on the blind handover priorities of cells. If a neighboring UTRAN cell assigned a blind handover priority provides weak coverage, a blind handover to this cell may fail, affecting the handover success rate.

NCellMeasPriority Neighboring Cell Measure Priority

Meaning: Indicates the measurement priority of the neighboring UTRAN cell. A larger value indicates a higher priority. The measurement priorities can be periodically and automatically arranged based on the number of times each neighboring UTRAN cell is measured. The neighboring UTRAN cells for UTRAN measurement control, fast blind redirections to UTRAN, and blind redirections for flash CSFB to UTRAN can be selected based on the measurement priorities of neighboring UTRAN cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~128

Unit: None

Actual Value Range: 0~128

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter indicates a higher measurement priority of a neighboring UTRAN cell, and a higher probability of the neighboring UTRAN cell being delivered in UTRAN measurement control. In this case, timely handover to the neighboring UTRAN cell can be ensured when handover conditions are met, thereby decreasing the number of handover attempts and increasing the handover success rate.

In addition, a larger value of this parameter indicates a higher probability of the neighboring UTRAN cell being selected in UTRAN flash blind redirections or UTRAN flash-CSFB-based blind redirections, thereby increasing the accuracy of UTRAN flash blind redirections or UTRAN flash-CSFB-based blind redirections and reducing the redirection delay.

Applicable Mode: L-FDD, L-TDD

CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, the ANR-related MOs can be modified or removed by only the user. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, the ANR-related MOs can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When the ANR-related MOs are automatically added based on the ANR algorithm, this parameter is set to AUTO_MODE by default. When the ANR-related MOs are added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AUTO_MODE(Auto Mode), MANUAL_MODE(Manual Mode)

Unit: None

Actual Value Range: AUTO_MODE, MANUAL_MODE

MML Default Value: AUTO_MODE(Auto Mode)

Recommended Value: AUTO_MODE(Auto Mode)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add the neighboring relation with a UTRAN cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", RNC ID: 1, RNC cell ID: 123, run the following command:
ADD UTRANNCELL: LocalCellId=0, Mcc="460", Mnc="20", RncId=1, CellId=123;
Example 2: To add the neighboring relation with a UTRAN cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", RNC ID: 48, RNC cell ID: 12, run the following command:
ADD UTRANNCELL: LocalCellId=0, Mcc="460", Mnc="20", RncId=48, CellId=12;
