List CellLcsCfg Configuration (LST CELLLCSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the cell LCS.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of LCS parameters of a cell:
LST CELLLCSCFG: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 17:25:29
O&M    #806355769
%%LST CELLLCSCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

                          Local Cell ID  =  1

                        Cell LCS Switch  =  NB_OTDOA_SWITCH:Off
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

NB-IoT E-CID-based Positioning UE Count

Indicates the maximum number of UEs that can simultaneously perform measurements for E-CID-based positioning in a cell. E-CID-based positioning is enabled in a cell only if this parameter is set to a non-zero value. This parameter applies only to NB-IoT.

Cell LCS Switch

Indicates whether to enable location service (LCS) functions in the cell.

NB_OTDOA_SWITCH: Indicates whether to enable OTDOA-based positioning for NB-IoT cells. OTDOA-based positioning is enabled for NB-IoT cells only if this option is selected.

For FDD and TDD cells, OTDOA-based positioning is enabled when either this option or the OtdoaSwitch option of the LcsSwitch parameter in the ENodeBAlgoSwitch MO is selected, and is disabled when both options are deselected.
