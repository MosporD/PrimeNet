List Neighboring CDMA2000 Band Class Information (LST CDMA2000BANDCLASS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the CDMA2000 band class.

Note

None.

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Band class

Indicates the neighboring CDMA2000 band class. Signals on a frequency within the band class can be obtained by UEs. For details, see the BandclassCDMA2000 IE defined in 3GPP 36.331. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT cell reselection indicator

Indicates whether to configure cell reselection priorities for a CDMA2000 1xRTT band class. If this parameter is set to NOT_CFG, the cell reselection priorities are not delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT cell reselection priority

Indicates the absolute priority of the CDMA2000 1xRTT band class to be used during cell reselection. The value 0 indicates the lowest priority. Frequencies used for different RATs must be assigned different cell reselection priorities. The information is contained in SIB8. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT high priority threshold(0.5dB)

Indicates the RX signal level required for a cell on a frequency in the higher-priority CDMA2000 1xRTT band class to become a candidate for cell reselection.

After measurements are started for cells on a frequency in the band class, a cell on the frequency can become a candidate for reselection only if the RX signal level of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see section 5.2.4.5 in 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

CDMA20001XRTT lower priority threshold(0.5dB)

Indicates the RX signal level required for a cell on a frequency in the lower-priority CDMA2000 1xRTT band class to become a candidate for cell reselection.

After measurements are started for cells on a frequency in the band class, a cell on the frequency can become a candidate for reselection only if the RX signal level of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see section 5.2.4.5 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

CDMA2000HRPD cell reselection indicator

Indicates whether to configure cell reselection priorities for a CDMA2000 HRPD band class. If this parameter is set to NOT_CFG, the cell reselection priorities are not delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.

CDMA2000HRPD cell reselection priority

Indicates the absolute priority of the CDMA2000 HRPD band class to be used during cell reselection. The value 0 indicates the lowest priority. Frequencies used for different RATs must be assigned different cell reselection priorities. The information is contained in SIB8. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

CDMA2000HRPD high priority threshold(0.5dB)

Indicates the minimum RX level required for a cell on a target frequency in the CDMA2000 HRPD band class to become a candidate for cell reselection if the cell reselection priority of the target frequency is higher than that of the serving frequency.

After measurements are started for cells on a target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter for a period of time. For details, see section 5.2.4.5 in 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

CDMA2000HRPD lower priority threshold(0.5dB)

Indicates the minimum RX level required for a cell on a target frequency in the CDMA2000 HRPD band class to become a candidate for cell reselection if the cell reselection priority of the target frequency is lower than that of the serving frequency.

After measurements are started for cells on a target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter and that of the serving cell is lower than a specific reselection threshold for a period of time. For details, see section 5.2.4.5 in 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.
