Modify UL CS Algorithm Configuration (MOD ULCSALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to cell-level UL CS algorithms.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
UlCoPcInThd UL Coordinated PC IN Threshold

Meaning: Indicates the interference noise threshold for triggering UL coordinated power control (CPC). If the uplink interference noise level in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.

GUI Value Range: -115~-80

Unit: dBm

Actual Value Range: -115~-80

MML Default Value: None

Recommended Value: -105

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of determining high interference and triggering CPC and a more significant interference suppression effect in high-interference scenarios. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
UlCoPcRbkRsrpThd UL Coordinated PC Rollback RSRP Threshold

Meaning: Indicates the RSRP threshold used for UEs involved in UL coordinated power control (CPC) rollback. This parameter applies only to LTE FDD.

GUI Value Range: -126~24

Unit: dBm

Actual Value Range: -126~24

MML Default Value: None

Recommended Value: -96

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In uplink interference scenarios, a smaller value of this parameter results in a lower probability of uplink power saturation for UEs involved in CPC rollback. As a result, interference between neighboring cells is reduced. However, uplink throughput is also reduced when uplink power is not saturated. In uplink interference scenarios, a larger value of this parameter results in a higher probability of uplink power saturation for UEs involved in CPC rollback and higher uplink throughput when uplink power is not saturated.

Applicable Mode: L-FDD
UlCoPcUserNumThd UL Coordinated PC User Number Threshold

Meaning: Indicates the UE number threshold for triggering UL coordinated power control (CPC). If the number of UL-synchronized UEs in a cell exceeds the threshold, the cell meets the condition for UL CPC. This parameter applies only to LTE FDD.

GUI Value Range: 30~10000

Unit: None

Actual Value Range: 30~10000

MML Default Value: None

Recommended Value: 150

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of determining high load status and triggering CPC and a more significant interference suppression effect in high-load scenarios. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
UlCoResAllocBandMode UL Coordinated Resource Allocation Band Mode

Meaning: Indicates the mode of arranging the guard bands of cells for UL coordinated resource allocation. The mode determines the guard band positions. This parameter applies only to LTE FDD.

GUI Value Range: MODE0(MODE0), MODE1(MODE1), MODE2(MODE2), INVALID(INVALID)

Unit: None

Actual Value Range: MODE0, MODE1, MODE2, INVALID

MML Default Value: None

Recommended Value: INVALID(INVALID)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to different values other than INVALID(INVALID) for neighboring cells, inter-cell interference can be reduced. When this parameter is set to the same value for neighboring cells, UL CS does not take effect.

Applicable Mode: L-FDD
UlCoResAllocRbLoadThld UL Coordinated Resource Allocation RB Load Thld

Meaning: Indicates the load threshold for triggering UL coordinated resource allocation. If the PUSCH RB usage in a cell is higher than this threshold, the eNodeB allocates protected UEs only resources in the guard bands. This parameter applies only to LTE FDD.

GUI Value Range: 40~100

Unit: %

Actual Value Range: 40~100

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in stricter control on interference, and a larger value of this parameter results in the opposite effect.

Applicable Mode: L-FDD
UlCsA3Offset UL CS A3 Offset

Meaning: Indicates the offset for event A3 for UL coordinated scheduling (CS). For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value indicates that a neighboring cell must have better signal quality for the reporting of the event for UL CS. As a result, the number of neighboring cells from which interference is tracked is smaller and interference suppression gains are reduced. A smaller value of this parameter results in a larger number of neighboring cells from which interference is tracked and higher interference suppression gains.

Applicable Mode: L-FDD
UlCsSw UL CS Switch

Meaning: Indicates whether to enable functions of UL coordinated scheduling (CS) for a cell.

UL_COORD_RES_ALLOC_SWITCH: Indicates whether to enable UL coordinated resource allocation. UL coordinated resource allocation is enabled only if this option is selected. This option applies only to LTE FDD.

UL_COORD_PC_SWITCH: Indicates whether to enable UL coordinated power control (CPC). UL CPC is enabled only if this option is selected. This option applies only to LTE FDD.

GUI Value Range: UL_COORD_RES_ALLOC_SWITCH(UL_COORD_RES_ALLOC_SWITCH), UL_COORD_PC_SWITCH(UL_COORD_PC_SWITCH)

Unit: None

Actual Value Range: UL_COORD_RES_ALLOC_SWITCH, UL_COORD_PC_SWITCH

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The UlCraSupportMocnSwitch parameter in the UlCsAlgoPara MO can be set to ON only when the UL_COORD_RES_ALLOC_SWITCH option of the UlCsSw parameter in the UlCsAlgoPara MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_COORD_RES_ALLOC_SWITCH: When this option is selected, average uplink throughput and user-perceived uplink throughput of cell edge UEs increase.

UL_COORD_PC_SWITCH: When this option is selected, average uplink throughput and user-perceived uplink throughput of cell edge UEs increase.

Applicable Mode: L-FDD
UlCraInThld UL Coordinated Resource Alloc IN Threshold

Meaning: Indicates the interference noise threshold for enabling uplink coordinated resource allocation (UL CRA). If the average interference noise level of the cells in the cluster for UL CRA is greater than this threshold, the interference condition for enabling UL CRA is met. This parameter applies only to LTE FDD.

GUI Value Range: -115~80

Unit: dBm

Actual Value Range: -115~80

MML Default Value: None

Recommended Value: -113

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of determining high interference and triggering CRA. As a result, resource allocation is adjusted and the number of times of scheduling UEs running large-packet services may be increased to reduce interference. A larger value of this parameter results in a lower probability of determining high interference and triggering CRA.

Applicable Mode: L-FDD
UlCraUserNumThld UL CRA User Number Threshold

Meaning: Indicates the UE number threshold for enabling uplink coordinated resource allocation (UL CRA). UL CRA takes effect in a cell if the number of served UEs is lower than this threshold. This parameter applies only to LTE FDD.

GUI Value Range: 1~300

Unit: None

Actual Value Range: 1~300

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller number of UEs for which CRA takes effect. A larger value of this parameter results in a greater number of UEs for which CRA takes effect. However, when CRA takes effect for a greater number of UEs, there is a higher probability that the average uplink scheduled users number per TTI (SUNPT) decreases due to interference control.

Applicable Mode: L-FDD
UlCraSupportMocnSwitch Uplink CRA Support MOCN Switch

Meaning: Indicates whether to enable UL CRA in MOCN scenarios where air interface resources and traffic are fully shared. When this parameter is set to ON, UL CRA can be enabled. When this parameter is set to OFF, UL CRA cannot be enabled. This parameter applies only to LTE FDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship:

-Configuration constraints:

  • The UlCraSupportMocnSwitch parameter in the UlCsAlgoPara MO can be set to ON only when the UL_COORD_RES_ALLOC_SWITCH option of the UlCsSw parameter in the UlCsAlgoPara MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, UL CRA can be enabled in MOCN scenarios where air interface resources and traffic are fully shared. If this parameter is set to OFF, UL CRA cannot be enabled in any MOCN scenarios.

Applicable Mode: L-FDD

Example

Example 1: To modify the settings of UL CS algorithm switches with the parameters as follows: Local cell ID: 0, UL_COORD_RES_ALLOC_SWITCH-1, run the following command: 
MOD ULCSALGOPARA: LocalCellId=0, UlCsSw=UL_COORD_RES_ALLOC_SWITCH-1;
Example 2: To modify the settings of UL CS algorithm switches with the parameters as follows: Local cell ID: 0, UL_COORD_PC_SWITCH-1, run the following command: 
MOD ULCSALGOPARA: LocalCellId=0, UlCsSw=UL_COORD_PC_SWITCH-1;
