Modify Clock Detection Parameter (MOD CLKDETECT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify clock detection parameter configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
ClkAsyncDetectSwitch Clock Async Detection Switch

Meaning: Indicates whether to enable clock asynchronization detection. If this parameter is set to ON(On), the eNodeB enables clock asynchronization detection. If this parameter is set to OFF(Off), the eNodeB disables clock asynchronization detection. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to ON(On), clock asynchronization detection is automatically performed to timely identify eNodeBs generating interference due to clock asynchronization and generate alarms for these eNodeBs. This facilitates follow-up interference suppression to reduce network interference, increasing the radio connection rate and lowering the radio service drop rate. If this parameter is set to OFF(Off), clock asynchronization detection is disabled. In this circumstance, eNodeBs with clock asynchronization cannot be automatically identified and related alarms cannot be generated for these eNodeBs, lowering efficiency of resolving clock asynchronization faults. KPI performance cannot be improved in this circumstance.

Applicable Mode: L-TDD
ClkAsyncInterfRptThld Clock Async Interf Report Thld

Meaning: Indicates the interference threshold for interference reporting. This parameter applies only to LTE TDD.

GUI Value Range: -130~-50

Unit: dBm

Actual Value Range: -130~-50

MML Default Value: None

Recommended Value: Set this parameter based on the networking mode and interference intensity recorded during previous clock out-of-synchronization. The recommended value is -95.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
ClkAsyncPrbUsageThld Clock Async PRB Usage Thld

Meaning: Indicates the uplink PRB usage threshold for a cell. This threshold is used to filter out scenarios where interference occurs due to heavy traffic. This parameter applies only to LTE TDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
ClkAsyncSilDetInfDifThld Clock Async Silence Detect Interf Diff Thld

Meaning: Indicates the threshold of interference fluctuations during silence detection for locating eNodeBs with clock asynchronization. This parameter applies only to LTE TDD.

GUI Value Range: -10~30

Unit: dB

Actual Value Range: -10~30

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
ClkAsyncSilDetInfThld Clock Async Silence Detect Interf Thld

Meaning: Indicates the interference detection threshold when interference fluctuates during silence detection. This threshold is used to locate eNodeBs with clock asynchronization. This parameter applies only to LTE TDD.

GUI Value Range: -130~-50

Unit: dBm

Actual Value Range: -130~-50

MML Default Value: None

Recommended Value: Set this parameter based on the networking mode and interference intensity recorded during previous clock out-of-synchronization. The recommended value is -105.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
PostProcessingMeasure Post Processing Measure

Meaning: Indicates the measure to be taken after eNodeB clock out-of-synchronization. If this parameter is set to NO_PROCESSING, the eNodeB does not take any measure after clock out-of-synchronization. If this parameter is set to CLK_ASYNC_ENB_DEACTIVATE, the eNodeB deactivates all LTE TDD cells after clock out-of-synchronization. This parameter applies only to LTE TDD.

GUI Value Range: NO_PROCESSING(NO_PROCESSING), CLK_ASYNC_ENB_DEACTIVATE(CLK_ASYNC_ENB_DEACTIVATE)

Unit: None

Actual Value Range: NO_PROCESSING, CLK_ASYNC_ENB_DEACTIVATE

MML Default Value: None

Recommended Value: NO_PROCESSING(NO_PROCESSING)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to NO_PROCESSING, the eNodeB on which clock out-of-synchronization is detected or that is suspected of being in the clock out-of-synchronization state does not automatically deactivate cells. In this case, the interference generated by this eNodeB cannot be automatically eliminated.

If this parameter is set to CLK_ASYNC_ENB_DEACTIVATE, the eNodeB on which clock out-of-synchronization is detected automatically deactivates cells. If the detection is correct, the interference generated by this eNodeB can be automatically eliminated, increasing the radio connection rate and lowering the service drop rate.

Applicable Mode: L-TDD

Example

To modify the configuration of the clock async detection with the parameters as follows: Clock Async Detection Switch : Off, run the following command:
MOD CLKDETECT: ClkAsyncDetectSwitch=OFF;
