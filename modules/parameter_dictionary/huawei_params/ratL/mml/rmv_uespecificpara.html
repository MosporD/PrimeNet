Remove UE-specific Parameter (RMV UESPECIFICPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a UE-specific configuration.

Note

None.

Parameters

ID Name Description
UeSpecificConfigIndex UE-specific Configuration Index

Meaning: Indicates the index of a UE-specific configuration. If there are two or more UeSpecificPara MOs with the same combination of the MoId, ParaId, and ParaBitId parameter values but different indexes configured for the same type of UE, only the UeSpecificPara MO with the smallest index takes effect.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

+++    0        2017-07-14 10:12:28
O&M    #806354977
%%RMV UESPECIFICPARA: UeSpecificConfigIndex=1;%%
RETCODE = 0  Operation succeeded.
---    END
