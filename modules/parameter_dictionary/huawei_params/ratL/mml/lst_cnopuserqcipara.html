List Operator-specific UE-level QCI Parameter (LST CNOPUSERQCIPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list operator-specific UE-level configurations of a QCI.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Qci QoS Class Indication

Meaning: Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 6~9

Unit: None

Actual Value Range: 6~9

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserPriority User Priority

Meaning: Indicates the user priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: GOLD(Gold), SILVER(Silver), BRONZE(Bronze), IRON(Iron)

Unit: None

Actual Value Range: GOLD, SILVER, BRONZE, IRON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

To list operator-specific UE-level configurations of a QCI, run the following command:
LST CNOPUSERQCIPARA:;

Output Description

Field Description

CN Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

QoS Class Indication

Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

User Priority

Indicates the user priority. This parameter applies only to LTE FDD and LTE TDD.

Downlink Scheduling Priority Weight Factor

Indicates the weight factor used in the calculation of connection priorities during downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.

Uplink Scheduling Priority Weight Factor

Indicates the weight factor used in the calculation of connection priorities during uplink scheduling. This parameter applies only to LTE FDD and LTE TDD.
