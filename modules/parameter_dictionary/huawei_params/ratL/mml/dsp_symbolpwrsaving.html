Display Status of Symbol Power Saving (DSP SYMBOLPWRSAVING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of symbol power saving for energy conservation and emission reduction.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the status of symbol power saving for energy conservation and emission reduction:
DSP SYMBOLPWRSAVING: LocalCellId=1;
The result is shown as follows:
+++    0        2020-01-09 12:16:32
O&M    #806355091
%%DSP SYMBOLPWRSAVING: LocalCellId=80;%%
RETCODE = 0  Operation succeeded.

Multi-RAT Symbol Shutdown Status  =  NOT_STARTED
   LNR Bundled Scheduling Status  =  NOT_STARTED
     Deep Symbol Shutdown Status  =  NOT_STARTED
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB.

Bundled Scheduling Status

Indicates the status of LTE bundled scheduling in a cell. The status can be NOT_STARTED or STARTED. This parameter applies only to LTE FDD and LTE TDD.

Multi-RAT Symbol Shutdown Status

Indicates the multi-RAT symbol power saving status of the cell. The value NOT_STARTED indicates that multi-RAT symbol power saving has not taken effect. The value STARTED indicates that multi-RAT symbol power saving has taken effect. The status can be NOT_STARTED or STARTED.

LNR Bundled Scheduling Status

Indicates the status of LTE and NR bundled scheduling in a cell. The value NOT_STARTED indicates that LTE and NR bundled scheduling has not taken effect. The value STARTED indicates that LTE and NR bundled scheduling has taken effect. This parameter applies only to LTE FDD and LTE TDD.

Deep Symbol Shutdown Status

Indicates the status of deep symbol power saving in the cell.

The value NOT_STARTED indicates that deep symbol power saving has not taken effect. The value STARTED indicates that deep symbol power saving has taken effect. This parameter applies only to LTE FDD and LTE TDD.
