Display Extended Neighboring Relation with E-UTRAN Cell (DSP EUTRANEXTENDEDNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query neighbor relationships with E-UTRAN cells labeled with EXTENDED when intra-RAT neighboring cell classification management is enabled and the IntraRatNcellMgtMode parameter value is INTERNAL_STORAGE_MODE(StorageMode).

Note

None.

Output Description

Field Description

Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB.

Mobile country code

Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

Mobile network code

Indicates the mobile network code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

eNodeB ID

Indicates the eNodeB ID of the intra-frequency neighboring cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Cell ID

Indicates the local ID of the intra-frequency neighboring cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

No handover indicator

Indicates whether handovers of UEs to the neighboring cell are prohibited. This parameter applies only to LTE FDD and LTE TDD.

Physical cell ID

Indicates the physical cell identifier (PCI) of the neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.331.

Downlink EARFCN

Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) of the neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.104.

HO Attempt Number

Indicates the number of handover attempts of an intra-RAT extended neighboring cell. This parameter takes effect only when the INTRA_RAT_NCELL_CLASS_SW option is selected and IntraRatNcellMgtMode is set to INTERNAL_STORAGE_MODE. The statistics of the last statistical period, controlled by StatPeriodForNcellClass, are displayed when this parameter is queried. This parameter does not take effect during the first statistical period of the neighbor relationship classification algorithm when an extended neighboring cell is added or transferred.

HO Success Number

Indicates the number of successful handovers of extended neighboring cells. This parameter takes effect only when the INTRA_RAT_NCELL_CLASS_SW option is selected and IntraRatNcellMgtMode is set to INTERNAL_STORAGE_MODE. The statistics of the last statistical period, controlled by StatPeriodForNcellClass, are displayed when this parameter is queried. This parameter does not take effect during the first statistical period of the neighbor relationship classification algorithm when an extended neighboring cell is added or transferred.

Statistic Valid Indicator

Indicates whether the statistics about handovers of intra-RAT extended neighboring cells take effect.

Overlap Indicator

Indicates whether the neighboring cell is identified as a neighboring cell overlapping the local E-UTRAN cell. The default value is NO. The parameter value YES indicates that the neighboring cell is identified as a neighboring cell overlapping the local E-UTRAN cell. The parameter value NO indicates that the neighboring cell is not identified as a neighboring cell overlapping the local E-UTRAN cell.

Over Distance Flag

Indicates whether a neighboring cell is an over-distant neighboring cell. If this parameter is set to BOOLEAN_TRUE(True), the neighboring cell is a distant neighboring cell. If this parameter is set to BOOLEAN_FALSE(False), the neighboring cell is not a distant neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

Local Cell to NCell MLB PRB Thld(%)

Indicates the PRB usage threshold used to determine whether to trigger MLB from the local cell to the neighboring cell. This parameter does not take effect when it is set to 0. This parameter applies only to LTE FDD and LTE TDD.

Local Cell to NCell MLB UE Number Thld

Indicates the threshold of the number of UEs for triggering MLB from the local cell to the neighboring cell. The value 0 indicates that this parameter is invalid. This parameter applies only to LTE FDD and LTE TDD.

NCell to Local Cell MLB UE Number Thld

Indicates the threshold of the number of UEs for triggering MLB from the neighboring cell to the local cell. The value 0 indicates that this parameter is invalid. This parameter applies only to LTE FDD and LTE TDD.
