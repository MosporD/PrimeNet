Modify eNodeB IP Path Application Type (MOD ENODEBPATH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the application type of an IP path.

Note

An eNodeBPath MO must be configured. If it is not configured, the user-plane alarms and the following eNodeB functions are affected, including basic service functions, transmission QoS, and transmission maintenance.

Parameters

ID Name Description
IpPathId IP Path ID

Meaning: Indicates the ID of an IP path.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
AppType Application Type

Meaning: Indicates the application type of an IP path.

GUI Value Range: S1(S1), X2(X2)

Unit: None

Actual Value Range: S1, X2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
S1InterfaceId S1 Interface ID

Meaning: Indicates the S1 interface ID of an IP path. This parameter is not used in this version, and you are advised to set this parameter to 0.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • When the AppType parameter is set to S1(S1), the S1InterfaceId parameter must be set. When the AppType parameter is set to X2(X2), the S1InterfaceId parameter does not need to be set.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
X2InterfaceId X2 Interface ID

Meaning: Indicates the X2 interface ID of an IP path.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • When the AppType parameter is set to X2(X2), the X2InterfaceId parameter must be set. When the AppType parameter is set to S1(S1), the X2InterfaceId parameter does not need to be set.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the application type of an IP path with the parameters as follows: IP Path ID: 0, Application Type: X2, X2 Interface ID: 16, run the following command: 
MOD ENODEBPATH: IpPathId=0, AppType=X2, X2InterfaceId=16;
