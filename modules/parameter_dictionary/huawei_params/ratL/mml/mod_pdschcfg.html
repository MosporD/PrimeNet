Modify PDSCH Configuration (MOD PDSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PDSCH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If a cell is an air cell, online modifications on the PDSCH configuration will result in automatic reset of the cell.

  • Modification of CrsPowerBoostingAmplitude will cause the cell to automatically reset. After the reset, the cell establishment may fail because the RF module does not support CRS Boosting or the RF module capability to support this function is lower than the setting of this parameter. Therefore, it is recommended that the cell's maximum capability to support this function be queried by running an MML command of DSP CELLCRSBOOSTINGCAPABILITY before this parameter is modified.

  • After the power of a cell is changed, it takes 1 to 3 seconds for the change to take effect on the RRUs serving the cell. If the command used to change the cell power needs to be consecutively executed for a cell, it is recommended that the command be executed at an interval of 3 seconds to prevent command execution failure.

ReferenceSignalPwr Reference signal power

Meaning: Indicates the cell reference signal power of each physical antenna (the precision of converting dBm to mW is 0.01 mW). However, the cell reference signal power delivered in SIB2 is that of each logical antenna. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of this parameter is changed, the eNodeB will proactively release eMTC UEs that have already accessed the cell. For FDD 8T8R and 32T32R cells, this parameter indicates the cell reference signal power of each logical antenna.

GUI Value Range: -600~500

Unit: 0.1dBm

Actual Value Range: -60~50

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: (1) Coverage: If the value of ReferenceSignalPwr is too large, overshoot coverage occurs. This causes interference to other cells. If the value of ReferenceSignalPwr is too small, coverage holes appear.

(2) Interference: The setting of ReferenceSignalPwr varies with the interference from neighboring cells. A large interference margin is required where the interference is strong.

(3) Channel estimation: A larger value of ReferenceSignalPwr leads to higher channel estimation accuracy, a lower demodulation threshold, and higher receiver sensitivity, but it causes stronger interference to neighboring cells.

(4) Capacity: A larger value of ReferenceSignalPwr brings better coverage, but a large value limits the power used for the transmission of data and hence decreases the system capacity.

Set ReferenceSignalPwr appropriately to ensure a reasonable tradeoff between coverage and capacity, effective channel estimation, and appropriate interference control.

Applicable Mode: L

TxChnPowerCfgSw TX Channel Power Config Switch

Meaning: Indicates whether to enable algorithms related to transmit channel power configurations.

SINGLE_CA_PWR_SHARE_SW_FOR_4T: Indicates whether to enable single carrier power sharing for 4T. This option applies only to LTE FDD.

GUI Value Range: SINGLE_CA_PWR_SHARE_SW_FOR_4T(SINGLE_CA_PWR_SHARE_SW_FOR_4T)

Unit: None

Actual Value Range: SINGLE_CA_PWR_SHARE_SW_FOR_4T

MML Default Value: None

Recommended Value: SINGLE_CA_PWR_SHARE_SW_FOR_4T:Off

Parameter Relationship:

-Configuration constraints:

  • If the LogicalPortSwapSwitch parameter in the PDSCHCfg MO is set to SWAP_MODE_1, the SINGLE_CA_PWR_SHARE_SW_FOR_4T option of the TxChnPowerCfgSw parameter in the PDSCHCfg MO must be deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: SINGLE_CA_PWR_SHARE_SW_FOR_4T: If this option is selected, single carrier power sharing for 4T is enabled. In scenarios where the total power remains unchanged after a 2T cell is upgraded to a 4T cell, the reference signal power remains unchanged. This ensures that the coverage of the original 2T cell does not shrink. If this option is deselected, single carrier power sharing for 4T is disabled, which has no impact on the network performance.

Applicable Mode: L-FDD
CellPowerLimit Cell Power Limit

Meaning: Indicates the maximum transmit power of a single channel for a cell. If this parameter is set to 0, the maximum transmit power of a single channel for the cell is not limited. If this parameter is set to a value other than 0, the maximum transmit power of a single channel for the cell is limited. In this case, the eNodeB controls the number of scheduling resources to ensure that the power of a single channel does not exceed the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

CrsPowerBoostingAmplitude CRS Power Boosting Amplitude

Meaning: Indicates the amount of increase in cell-specific reference signal (CRS) power.

If this parameter is set to DB_0, the CRS power will not increase.

If this parameter is set to DB_1DOT77, the CRS power will increase by 1.77 dB.

If this parameter is set to DB_3, the CRS power will increase by 3 dB.

This parameter applies only to LTE FDD.

GUI Value Range: DB_0(0dB), DB_1DOT77(1.77dB), DB_3(3dB)

Unit: None

Actual Value Range: DB_0, DB_1DOT77, DB_3

MML Default Value: None

Recommended Value: If the RF module power is not sufficient and the coverage of the cell needs to be improved, it is recommended that this parameter be set to DB_1DOT77(1.77dB) or DB_3(3dB).

Parameter Relationship:

-Configuration constraints:

  • When the CrsPowerBoostingAmplitude parameter in the PDSCHCfg MO is not set to DB_0, the PdschPowerBoostingSwitch parameter in the PDSCHCfg MO must be set to OFF.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this parameter is set to DB_0, network performance remains unchanged.

When this parameter is set to DB_1DOT77, the CRS coverage is improved, increasing the number of admitted UEs in the cell.

When this parameter is set to DB_3, the CRS coverage is further improved, resulting in a larger number of admitted UEs in the cell.

Applicable Mode: L-FDD
LogicalPortSwapSwitch Logical Port Swap Switch

Meaning: Indicates whether to change the mapping between logical antenna ports and physical channels.

If this parameter is set to OFF, the mapping between logical antenna ports and physical channels, which is specified by the CrsPortMap parameter in the Cell MO, cannot be changed.

If this parameter is set to SWAP_MODE_1, the physical TX channels corresponding to logical antenna ports 0 and 2 are swapped, and the physical TX channels corresponding to logical antenna ports 1 and 3 are swapped.

This parameter applies only to logical cells configured with four logical CRS ports. This parameter applies only to LTE FDD.

GUI Value Range: OFF(OFF), SWAP_MODE_1(SWAP_MODE_1)

Unit: None

Actual Value Range: OFF, SWAP_MODE_1

MML Default Value: None

Recommended Value: OFF

Parameter Relationship:

-Configuration constraints:

  • If the LogicalPortSwapSwitch parameter in the PDSCHCfg MO is set to SWAP_MODE_1, the SINGLE_CA_PWR_SHARE_SW_FOR_4T option of the TxChnPowerCfgSw parameter in the PDSCHCfg MO must be deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PdschPowerBoostingSwitch PDSCH Power Boosting Switch

Meaning: Indicates whether to enable PDSCH power boosting. If this parameter is set to ON, PDSCH power boosting for TM9 UEs will be enabled. If this parameter is set to OFF, PDSCH power boosting will not be enabled. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship:

-Configuration constraints:

  • When the CrsPowerBoostingAmplitude parameter in the PDSCHCfg MO is not set to DB_0, the PdschPowerBoostingSwitch parameter in the PDSCHCfg MO must be set to OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, PDSCH power is increased for TM9 UEs, which helps to increase user-perceived data rates for these UEs. However, downlink interference is generated for neighboring cells. Services fluctuate within three or four seconds after the setting of this parameter is changed.

Applicable Mode: L-FDD

Example

Example 1: To set the PDSCH configuration information with the parameters as follows: Local cell ID: 0, Reference signal power: 160, run the following command:
MOD PDSCHCFG: LocalCellId=0, ReferenceSignalPwr=160;
Example 2: To set the PDSCH configuration information with the parameters as follows: Local cell ID: 0, PB: 2, run the following command:
MOD PDSCHCFG: LocalCellId=0, Pb=2;
