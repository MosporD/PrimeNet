Modify Cell Mlb Hand-over Configuration (MOD CELLMLBHO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the Mlb handover parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IdleUeSelFreqStrategy Idle UE Select Frequency Strategy

Meaning: Indicates the frequency selection policy for UEs in idle mode MLB. The value RESELBASED indicates that the target frequency is selected based on cell-reselection priorities for frequencies. The value MLBPRIOBASED indicates that the target frequency is selected based on MLB priorities for frequencies. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RESELBASED(RESELPRIOBASED), MLBPRIOBASED(MLBPRIOBASED)

Unit: None

Actual Value Range: RESELBASED, MLBPRIOBASED

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to RESELBASED, the number of cell reselections for idle mode MLB decreases and the throughput of cells on frequencies with higher cell-reselection priorities can be maximized. If this parameter is set to MLBPRIOBASED, the number of cell reselections for idle mode MLB increases and the throughput of cells on frequencies with higher MLB priorities can be maximized.

Applicable Mode: L-FDD, L-TDD
MlbHoInProtectMode Mlb Handover-in Protect Mode

Meaning: Indicates the MLB protection mode for UEs that are handed over to the local cell from other cells.

PROTECTTIMERMODE: If this option is selected, the eNodeB imposes a penalty on UEs that are handed over to the local cell through unnecessary incoming handovers. During the penalty, the eNodeB does not perform outgoing handovers for such UEs in the cell for MLB. Unnecessary handovers include intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based handovers, X2-based handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover", and S1-based handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover".

SPECEVENTA1A2MODE: If this option is selected, the eNodeB delivers special A1 and A2 measurement configurations to UEs that are handed over to the local cell through handovers for MLB. If this option is deselected, the eNodeB delivers the same A1 and A2 measurement configurations to all UEs in the local cell. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: PROTECTTIMERMODE(PROTECTTIMER MODE), SPECEVENTA1A2MODE(SPECEVENTA1A2 MODE)

Unit: None

Actual Value Range: PROTECTTIMERMODE, SPECEVENTA1A2MODE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: PROTECTTIMERMODE: If this option is selected, a protection timer is used for UEs that are transferred from other cells to the cell through unnecessary handovers. This prevents MLB-triggered handovers and subsequent ping-pong handovers for these UEs, avoiding UE throughput deterioration. However, other UEs in the cell cannot achieve the maximum throughput. If this option is deselected, the number of MLB-based handovers for UEs in the cell increases, affecting UE throughput. However, other UEs in the cell can achieve the maximum throughput.

SPECEVENTA1A2MODE: If this option is selected, the eNodeB does not immediately perform coverage-based handovers for UEs that were handed over from other cells to the cell for MLB. This prevents ping-pong triggering of MLB-based and coverage-based handovers, decreases the number of handovers, and ensures the handover success rate. However, UE throughput cannot be maximized. If this option is deselected, the number of handovers increases and the handover success rate decreases. However, UE throughput can be maximized.

Applicable Mode: L
MlbHoInProtectTimer Mlb Handover-in Protect Timer

Meaning: Indicates the penalty duration in which UEs that are handed over from other cells to the cell are not allowed to be handed over to other cells for MLB. If this parameter is set to 0, the penalty mechanism does not take effect. The unnecessary handovers include:

- Intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based intra-eNodeB handovers

- X2-based handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover"

- S1-based handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover"

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3600

Unit: s

Actual Value Range: 0~3600

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the UE is selected to perform MLB in an early time, the number of MLB-based handovers is increased, and the UE throughput cannot be maximized. However, other UEs in this cell achieve the maximum throughput. If this parameter is set to a large value, the number of MLB-based handovers is decreased and the UE throughput is maximized. However, other UEs in this cell cannot achieve the maximum throughput.

Applicable Mode: L-FDD, L-TDD
InterFreqMlbHoInA1ThdRsrp InterFreq Mlb Handover-in A1 RSRP Thd

Meaning: Indicates the RSRP threshold for event A1 in measurement configurations delivered to UEs that are handed over to the local cell through handovers for inter-frequency MLB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of entering event A1. This guarantees that UE throughput can be maximized but decreases the handover success rate. A larger value of this parameter results in a lower probability of entering event A1. This guarantees the handover success rate but UE throughput cannot be maximized.

Applicable Mode: L-FDD, L-TDD

InterRatMlbStrategy Inter-RAT MLB Strategy

Meaning: Indicates the policies used in inter-RAT MLB.

If the UtranRedirectIMMCI option is selected, the eNodeB delivers dedicated cell-reselection priorities of frequencies for "MLB to UTRAN by transferring RRC_REL UEs" when redirections for MLB to UTRAN are triggered.

GUI Value Range: UtranRedirectIMMCI(UtranRedirectIMMCI)

Unit: None

Actual Value Range: UtranRedirectIMMCI

MML Default Value: None

Recommended Value: UtranRedirectIMMCI:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Selecting the UtranRedirectIMMCI option maximizes UE throughput in LTE cells but increases Uu signaling overhead. Deselecting the UtranRedirectIMMCI option does not help maximize UE throughput in LTE cells and does not increase Uu signaling overhead.

Applicable Mode: L
MlbMatchOtherFeatureMode MLB Match Other Feature Mode

Meaning: Indicates the coordination mechanism between MLB and other features.

HoAdmitSwitch: Indicates whether the admission of UEs in incoming unnecessary handovers (for example, service-based inter-frequency handovers) is controlled by MLB triggering. The admission is controlled by MLB triggering only if this option is selected.

X2RoHoAdmitSwitch: Indicates whether the admission of UEs in S1- or X2-based incoming handovers with the cause value of "Resource Optimisation Handover" is controlled by MLB triggering. The admission is controlled by MLB triggering only if this option is selected.

NCellSelectSwitch: Indicates whether an intra-eNodeB neighboring cell for which MLB is triggered can be a target cell in a service-based inter-frequency handover or service-request-based inter-frequency handover. Such a neighboring cell can be a target cell only if this option is selected.

IfBackoffHoInRejectSwitch: Indicates whether to reject handovers of UEs from inter-duplex-mode cells in backoff MLB if the cell load has reached the HoInRejectPrbThd or HoInRejectUeNumThd parameter value. Handovers of UEs from inter-duplex-mode cells are rejected for the stated cell load reason only if this option is selected.

CarrierShutdownHoAdmitAllowSw: Indicates whether a local cell accepts incoming handover requests triggered by carrier power-off when MLB is initiated in the local cell. The local cell accepts incoming handover requests triggered by carrier power-off when MLB is initiated in the local cell only if this option is selected. This option applies only to LTE FDD and LTE TDD.

MocnSecOpUeFreqPriInHoEhnSw: Indicates whether neighboring cells in which MLB is triggered allow frequency-priority-based incoming handover requests of UEs served by secondary operators in the local cell when the local cell is a MOCN cell. If this option is selected, such requests are allowed. If this option is deselected, such requests are rejected. This option is valid only if the FLEXIBLE_SHARING_SWITCH option of the CellAlgoExtSwitch.OperatorFunSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: HoAdmitSwitch(HoAdmitSwitch), X2RoHoAdmitSwitch(X2RoHoAdmitSwitch), NCellSelectSwitch(NCellSelectSwitch), IfBackoffHoInRejectSwitch(IfBackoffHoInRejectSwitch), CarrierShutdownHoAdmitAllowSw(CarrierShutdownHoAdmitAllowSw), MocnSecOpUeFreqPriInHoEhnSw(MocnSecOpUeFreqPriInHoEhnSw)

Unit: None

Actual Value Range: HoAdmitSwitch, X2RoHoAdmitSwitch, NCellSelectSwitch, IfBackoffHoInRejectSwitch, CarrierShutdownHoAdmitAllowSw, MocnSecOpUeFreqPriInHoEhnSw

MML Default Value: None

Recommended Value: HoAdmitSwitch:Off, X2RoHoAdmitSwitch:Off, NCellSelectSwitch:Off, IfBackoffHoInRejectSwitch:Off, CarrierShutdownHoAdmitAllowSw:Off, MocnSecOpUeFreqPriInHoEhnSw:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: HoAdmitSwitch: If this option is selected, incoming unnecessary handovers to a cell cannot be admitted when an MLB procedure is triggered in the cell. In this case, the cell loses the performance gains provided by unnecessary handovers. However, this prevents a handover-induced increase in the cell load, which can trigger load balancing. This also decreases the number of load-based handovers. Deselecting the option results in the opposite effects.

X2RoHoAdmitSwitch: If this option is selected, UEs cannot be admitted in S1- or X2-based incoming handovers to a cell with the cause value of "Resource Optimisation Handover" when an MLB procedure is triggered in the cell. In this case, the cell loses the performance gains provided by the handovers. However, this prevents a handover-induced increase in the cell load, which can trigger load balancing. This also decreases the number of load-based handovers. Deselecting the option results in the opposite effects.

NCellSelectSwitch: If this option is selected, UEs can be transferred to high-load intra-eNodeB neighboring cells. However, this affects user experience. If this option is deselected, UEs cannot be transferred to high-load intra-eNodeB neighboring cells. In this case, the service-based and service-request-based inter-frequency handovers cannot be performed if there is no suitable neighboring cell. As a result, network performance gains of service steering cannot be achieved.

IfBackoffHoInRejectSwitch: When this option is selected, the gains of backoff MLB increase and the success rate of handovers from inter-duplex-mode decreases. When this option is deselected, the gains of backoff MLB decrease and the success rate of handovers from inter-duplex-mode cells is not affected.

CarrierShutdownHoAdmitAllowSw: Assume that the local cell serves as a basic cell in a carrier power-off scenario. If this option is selected and a capacity cell transfers UEs to the basic cell for carrier power-off, the local cell accepts incoming handover requests when MLB is initiated in the local cell. This decreases the gains offered by MLB but increases the handover preparation success rate. If this option is deselected and a capacity cell transfers UEs to the basic cell for carrier power-off, the local cell rejects incoming handover requests when MLB is initiated in the local cell. This increases the gains offered by MLB, without changing the handover preparation success rate.

MocnSecOpUeFreqPriInHoEhnSw: Assume that the local cell is a MOCN cell. If this option is selected, neighboring cells in which MLB is triggered allow incoming frequency-priority-based handover requests of UEs served by secondary operators of the MOCN cell. In this case, the MLB gains of these neighboring cells decrease but the handover preparation success rate increases, achieving UE steering in mixed networking of both MOCN and non-MOCN cells. If this option is deselected, these neighboring cells reject such requests. In this case, the MLB gains of these neighboring cells increase and the handover preparation success rate remains unchanged.

Applicable Mode: L

Example

To modify the Mlb handover parameters for a cell, where Local cell ID is 0, Idle UE Select Frequency Strategy is MLBPRIOBASED, run the following command:
MOD CELLMLBHO: LocalCellId=0, IdleUeSelFreqStrategy=MLBPRIOBASED;
