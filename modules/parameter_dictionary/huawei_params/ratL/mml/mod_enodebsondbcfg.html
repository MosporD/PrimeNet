Modify SON DB Configuration (MOD ENODEBSONDBCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the start time to write the changes generated by the automatic grouping configuration function of SON into the database. The changes include overlapping indicator changes of inter-frequency neighboring cells or the switch status changes of the cell to which intra-frequency neighboring cells belong.

Note

None.

Parameters

ID Name Description
StartTime Start Time

Meaning: Indicates the start time to write the changes generated by the ANGC function of SON into the database, including overlapping indicator changes of inter-frequency neighboring cells or the switch status changes of the cell to which intra-frequency neighboring cells belong. The results calculated by the ANGC function are written into the database after the time in the system reaches the start time specified by this parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 2:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

+++    0        2015-04-23 10:46:21
O&M    #806354948
%%MOD ENODEBSONDBCFG: StartTime=12&00&03;%%
RETCODE = 0  Operation succeeded.


---    END
