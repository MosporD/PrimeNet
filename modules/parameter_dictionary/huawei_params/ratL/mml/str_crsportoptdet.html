Start CRS Antenna Port Mapping Optimization Detection (STR CRSPORTOPTDET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start the CRS antenna port mapping optimization detection of the cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When the Automatic Reconfigure Switch is set to OFF, this operation may affect cell KPI badly (result in access rate decreased and drop call rare increased).

When the Automatic Reconfigure Switch is set to ON, this operation may cause cell automatic reset.

Parameters

ID Name Description
AutoRecfgSwitch Automatic Reconfigure Switch

Meaning: Indicates whether to enable either CRS antenna port mapping optimization detection or CRS antenna port mapping reconfiguration. If this parameter is set to OFF, the detection function, rather than the reconfiguration, is executed. If this parameter is set to ON, the configuration function, rather than the detection function, is executed, and the reconfiguration function can be used only after the detection function finishes. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to OFF, only the detection function is executed to detect the optimal CRS antenna port mapping. This does not cause cell reset. If this parameter is set to ON, the CRS antenna port mapping is reconfigured to its optimal setting. This causes cell reset. If the current CRS antenna port mapping is optimal or the optimal setting is unknown, the mapping is not reconfigured and the cell is not reset.

Applicable Mode: L
CrsAntPortOptDetUserNum CRS Ant Port Opt Mapping Detection User Number

Meaning: Indicates the maximum number of UEs that can be used for CRS antenna port mapping optimization detection per hour. This parameter applies only to LTE FDD.

GUI Value Range: 1~12

Unit: None

Actual Value Range: 1~12

MML Default Value: 3

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in smaller inter-cell interference and less impact on the uplink rate and uplink UE-perceived rates. However, the detection efficiency is low. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L

Example

(1)To start the CRS antenna port mapping optimization detection of the cells, run the following command:
STR CRSPORTOPTDET: AutoRecfgSwitch=OFF, CrsAntPortOptDetUserNum=3;
The result is shown as follows:
+++    HUAWEI        2017-03-27 09:31:38
O&M    #807403546
%%STR CRSPORTOPTDET: AutoRecfgSwitch=OFF, CrsAntPortOptDetUserNum=3;%%
RETCODE = 0  Operation succeeded.


---    END

(2)To start the CRS antenna port mapping reconfiguration of the cells, run the following command:
STR CRSPORTOPTDET: AutoRecfgSwitch=ON;
The result is shown as follows:
+++    HUAWEI        2017-03-27 09:31:38
O&M    #807403546
%%STR CRSPORTOPTDET: AutoRecfgSwitch=ON;%%
RETCODE = 0  Operation succeeded.


---    END
