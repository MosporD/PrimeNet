List PIM Cell Group Configuration (LST PIMCELLGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration information about PIM cell group.

Note

None.

Parameters

ID Name Description
PIMCellGroupId PIM Cell Group Identity

Meaning: Indicates the ID of a passive intermodulation (PIM) cell group. It uniquely identifies a PIM cell group within an eNodeB. A PIM cell group consists of two cells sharing an antenna system. This parameter applies only to LTE FDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

Example 1: To query the configuration of all PIM cell groups, run the following command:
LST PIMCELLGROUP:;
The result is as follows:
+++    0        2010-01-05 10:39:09
O&M    HUAWEI
%%LST PIMCELLGROUP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

PIM Cell Group Identity

Indicates the ID of a passive intermodulation (PIM) cell group. It uniquely identifies a PIM cell group within an eNodeB. A PIM cell group consists of two cells sharing an antenna system. This parameter applies only to LTE FDD.

Cell1 Local Cell ID

Indicates the local identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

Cell2 Local Cell ID

Indicates the local identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

Cell1 Sector Equipment Identity

Indicates the sector equipment identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

Cell2 Sector Equipment Identity

Indicates the sector equipment identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

PIM Mitigation Mode

Indicates the PIM mitigation mode. This parameter applies only to FDD.
