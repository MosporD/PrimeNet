Add eNodeBUsTraceId Configurations (ADD ENODEBUSTRACEIDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an eNodeB-level trace ID for UEs running unlimited services.

Note

None.

Parameters

ID Name Description
UsTraceIdIndex US Trace ID Index

Meaning: Indicates the index of the trace ID for UEs running unlimited services (US UEs).

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
UsTraceID US Trace ID

Meaning: Indicates the trace ID for UEs running unlimited services (US UEs). This parameter is valid only if the UsBasedSpecificTraceID option of the UsStrategy parameter is selected. If the UsTraceID parameter is set to 4294967295, the eNodeB identifies UEs with any trace ID as US UEs.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Add eNodeB US Trace ID Configuration
+++    0        2005-01-11 02:23:25
O&M    #806355817
%%ADD ENODEBUSTRACEIDCFG: UsTraceIdIndex=1, UsTraceID=22;%%
RETCODE = 0  Operation succeeded.
