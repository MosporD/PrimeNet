List MbsfnArea (LST MBSFNAREA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration data of an MBSFN area.

Note

None.

Output Description

Field Description

Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

MBSFN Area ID

Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

FDD TDD Indication

Indicates the duplex mode of the cells in an MBSFN area. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode. All the cells in an MBSFN area must work in the same duplex mode. This parameter applies only to LTE FDD and LTE TDD.

Uplink-Downlink Subframe Configuration

Indicates the uplink-downlink subframe configuration for LTE TDD cells in an MBSFN area. For details, see 3GPP TS 36.211. All cells in an MBSFN area must use the same uplink-downlink subframe configuration. This parameter applies only to LTE TDD.

Downlink Bandwidth

Indicates the downlink bandwidth of the cells in an MBSFN area. The bandwidth is represented by the number of RBs. For example, the value CELL_BW_N25 indicates a bandwidth of 25 RBs, and the value CELL_BW_N50 indicates a bandwidth of 50 RBs. For details, see 3GPP TS 36.104. All the cells in an MBSFN area must have the same downlink bandwidth. This parameter applies only to LTE FDD and LTE TDD.

Common Subframe Allocation Period

Indicates the MBSFN subframe allocation period. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
