Start Cable Sequence Check Between Cells (STR INTERCELLCROSSFEEDERTST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start a cable sequence check between cells.

Note

None.

Parameters

None.

Example

To start a cable sequence check between cells, run the following command:
STR INTERCELLCROSSFEEDERTST:;

Output Description

Field Description

Execution Progress(%)

Indicates the cable connection sequence check progress. This parameter applies only to LTE FDD and LTE TDD.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Inter-Cell Test Result

If the check result is CROSSED, cable connection sequences cross between the cells involved.

If the check result is CORRECT, cable connection sequences are correct for the cells involved.

If the check result is ERROR, there is no cable connection sequence check result for the cells involved.

If the check result is ERROR_LOW_CORRELATION, the correlation between channels of the cells involved is too low.

If the check result is CHECKING, cable connection sequences of cells are being checked.

This parameter applies only to LTE FDD and LTE TDD.

Crossed Local Cell ID

Indicates the cell that has a cable connection sequence cross with the cell under a cable connection sequence check.

This parameter applies only to LTE FDD and LTE TDD.
