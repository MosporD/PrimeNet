Add Previous Registration Parameter with CDMA20001XRTT (ADD CDMA20001XRTTPREREG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the pre-registration information about a CDMA2000 1xRTT cell.

Note

A maximum of 1 Cdma20001XrttPreReg can be configured for each cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the CDMA2000 1xRTT cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an Cdma20001XrttPreReg MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the CDMA2000 1xRTT cell.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship:

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Cdma20001XrttCellId CDMA20001XRTT cell ID

Meaning: Indicates the cell ID of the reference CDMA2000 1xRTT cell. The cell ID and sector ID together uniquely identify a CDMA2000 cell in the mobile switching center (MSC). In the CDMA2000 1xRTT network, a cell ID uniquely identifies a cell within the mobile switching center (MSC). A cell ID consists of 12 bits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~4095

Unit: None

Cdma20001XrttSectorId CDMA20001XRTT sector ID

Meaning: Indicates the sector ID of the reference CDMA2000 1xRTT cell. The cell ID and sector ID together uniquely identify a CDMA2000 cell in the mobile switching center (MSC). A sector ID is unique in a CDMA2000 cell and consists of four bits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Sid System ID

Meaning: Indicates the system ID of the reference CDMA2000 1xRTT cell. A system ID is allocated to each local CDMA mobile network and is used to determine whether a UE is in the roaming state. For details about this parameter, see the description of SID in 3GPP2 C.S0005. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~32767

Unit: None

Actual Value Range: 0~32767

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Nid Network ID

Meaning: Indicates the network ID of the reference CDMA2000 1xRTT cell. A base station is a cellular system and a member of the network. A network is a subset of a system identified by a system ID. A network in a system is identified by a network ID. A system ID and a network ID together uniquely identify a network. System ID 0 and network ID 0 indicate all base stations outside a specified network and are reserved values. Network ID 65535 is also reserved; this ID indicates that the roaming status of UEs is non-roaming in the whole system no matter what the network ID is. For details, see the description of NID in 3GPP2 C.S0005. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MscId MSC ID

Meaning: Indicates the ID of the MSC to which the reference CDMA2000 1xRTT cell belongs. The value begins with 0x followed by a maximum of 6 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. An MSC ID uniquely identifies an MSC and is determined by the operator.

MSCID is defined in 6.5.2.82 of TIA/EIA-41.5-D and consists of MarketID (2 bytes) and SwitchNo (1 byte). MarketID is described in TIA/EIA TSB29 and can be defined by the operator. It can be the SID or another ID that can differentiate between operators. SwitchNo consists of a group of cell addresses and circuit resource IDs under MarketID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~8 characters

Unit: None

Actual Value Range: 0~8 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • MscId in the Cdma20001XrttPreReg MO must be set to a hexadecimal number starting with 0x and with a total length not greater than 6 digits. A hexadecimal number is composed of upper-case letters (A to F) and digits (0 to 9). The hexadecimal digit following 0x can be 0 only if the parameter is set to 0x0. That is, the parameter value like 0x00AB is inappropriate but 0x0 is acceptable.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a pre-registration information of CDMA2000 1xRTT cell with the following parameters: Local cell ID: 0, Mobile country code: "460", Mobile network code: "01", CDMA20001XRTT cell ID: 1, CDMA20001XRTT sector ID: 1, System ID: 1, Network ID: 1, MSC ID: "0xAB", run the following command:
ADD CDMA20001XRTTPREREG: LocalCellId=0, Mcc="460", Mnc="01", Cdma20001XrttCellId=1, Cdma20001XrttSectorId=1, Sid=1, Nid=1, MscId="0xAB";
