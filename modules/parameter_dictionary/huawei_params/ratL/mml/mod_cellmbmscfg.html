Modify Cell MBMS Configuration (MOD CELLMBMSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of multimedia broadcast multicast service (MBMS) in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MBSFNSyncAreaId MBSFN synchronization Area ID

Meaning: Indicates the ID of an MBSFN synchronization area to which a cell belongs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MBMSSwitch MBMS switch

Meaning: Indicates whether to enable the MBMS function.

MBMSSwitch: If this option is selected, the MBMS function is enabled, and the cell supports the MBMS service. If this option is deselected, the MBMS function is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MBMSSwitch(MBMSSwitch)

Unit: None

Actual Value Range: MBMSSwitch

MML Default Value: None

Recommended Value: MBMSSwitch:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MBMSServiceSwitch MBMS Service Switch

Meaning: SERVICECONTINUITYSWITCH: Indicates whether MBMS service continuity can be maintained. MBMS service continuity can be maintained in inter-frequency networking by selecting this option.

If this option is selected, MBMS service continuity can be maintained. The eNodeB broadcasts SIB15 and determines whether to perform inter-frequency handovers for MBMS service continuity on an RRC_CONNECTED UE based on the MBMS Interest Indication message sent by the UE. In addition, the eNodeB sends the service area ID (SAI) of the serving cell to neighboring cells over the X2 interface.

If this option is deselected, MBMS service continuity cannot be maintained, the eNodeB does not broadcast SIB15, perform inter-frequency handovers for MBMS service continuity, or send the SAI of the serving cell. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: SERVICECONTINUITYSWITCH

Unit: None

Actual Value Range: SERVICECONTINUITYSWITCH

MML Default Value: None

Recommended Value: SERVICECONTINUITYSWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NCellMbmsCfgSwitch Neighbor Cell MBMS Config Switch

Meaning: NEIGHCELLCONFIGADAPTIVESWITCH: Indicates whether the neighboring cell configurations take effect adaptively. In the eMBMS feature, the MBSFN subframe configuration for a cell dynamically changes based on the MBMS session setups. Neighboring cell configurations can be dynamically updated based on the changes of MBSFN subframe configurations of neighboring cells.

If this option is selected, neighboring cell configurations in the local cell are updated and broadcast according to the MBSFN subframe configurations of the neighboring cells transmitted over X2 interfaces.

If this option is deselected, neighboring cell configurations use static parameter settings. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: NEIGHCELLCONFIGADAPTIVESWITCH

Unit: None

Actual Value Range: NEIGHCELLCONFIGADAPTIVESWITCH

MML Default Value: None

Recommended Value: NEIGHCELLCONFIGADAPTIVESWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of cell MBMS service with the parameters as follows: LocalCellId: 0, MBSFNSyncAreaId: 5, run the following command:
MOD CELLMBMSCFG: LocalCellId=0, MBSFNSyncAreaId=5;
