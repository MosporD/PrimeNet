Modify Scheduling Configurations for eMTC UEs at a Specific Coverage Level (MOD EMTCCESCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify Scheduling Configurations for eMTC UEs at a Specific Coverage Level.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the coverage level for UEs. If this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, or COVERAGE_LEVEL_3, the coverage level for UEs is coverage level 0, coverage level 1, coverage level 2, or coverage level 3, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2), COVERAGE_LEVEL_3(COVERAGE_LEVEL_3)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, COVERAGE_LEVEL_3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MpdcchInitRepNum Initial Number of MPDCCH Repetitions

Meaning: Indicates the initial number of MPDCCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: INVALID(INVALID), MPDCCH_INIT_REP_INDEX_1(MPDCCH_INIT_REP_INDEX_1), MPDCCH_INIT_REP_INDEX_2(MPDCCH_INIT_REP_INDEX_2), MPDCCH_INIT_REP_INDEX_3(MPDCCH_INIT_REP_INDEX_3), MPDCCH_INIT_REP_INDEX_4(MPDCCH_INIT_REP_INDEX_4)

Unit: None

Actual Value Range: INVALID, MPDCCH_INIT_REP_INDEX_1, MPDCCH_INIT_REP_INDEX_2, MPDCCH_INIT_REP_INDEX_3, MPDCCH_INIT_REP_INDEX_4

MML Default Value: None

Recommended Value: INVALID

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to better MPDCCH demodulation performance and higher resource consumption. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
MpdcchInitRepNumType1Css Initial Number of MPDCCH Rep for Type1 CSS

Meaning: Indicates the initial number of repetitions of the type-1 CSS MPDCCH for UEs at the specified coverage level. Given that UE coverage level information is unavailable in type-1 CSS, the number specified by this parameter for the highest coverage level supported by the cell takes effect. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: INVALID(INVALID), MPDCCH_INIT_REP_INDEX_1(MPDCCH_INIT_REP_INDEX_1), MPDCCH_INIT_REP_INDEX_2(MPDCCH_INIT_REP_INDEX_2), MPDCCH_INIT_REP_INDEX_3(MPDCCH_INIT_REP_INDEX_3), MPDCCH_INIT_REP_INDEX_4(MPDCCH_INIT_REP_INDEX_4)

Unit: None

Actual Value Range: INVALID, MPDCCH_INIT_REP_INDEX_1, MPDCCH_INIT_REP_INDEX_2, MPDCCH_INIT_REP_INDEX_3, MPDCCH_INIT_REP_INDEX_4

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

MPDCCH_INIT_REP_INDEX_1 when CoverageLevel is set to COVERAGE_LEVEL_0

MPDCCH_INIT_REP_INDEX_2 when CoverageLevel is set to COVERAGE_LEVEL_1

MPDCCH_INIT_REP_INDEX_3 when CoverageLevel is set to COVERAGE_LEVEL_2

MPDCCH_INIT_REP_INDEX_3 when CoverageLevel is set to COVERAGE_LEVEL_3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to better MPDCCH demodulation performance, higher resource consumption, and a higher probability that UEs cannot access the cell due to failures of RAR resource allocation within the RAR window. A smaller value of this parameter leads to poorer MPDCCH demodulation performance and lower resource consumption.

Applicable Mode: L-FDD, L-TDD
MpdcchMaxRepNum Max Number of MPDCCH Repetitions

Meaning: Indicates the maximum number of MPDCCH repetitions for UEs at the specified coverage level. For details, see 3GPP TS 36.213. To prevent UE access failures as a result of contention resolution timer expiration caused by a large number of repetitions, it is recommended that this parameter be set to a value in which the number does not exceed half of the number included in the value specified by the ContentionResolutionTimer parameter in the CeRachCfg MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MPDCCH_MAX_NUM_R1(MPDCCH_MAX_NUM_R1), MPDCCH_MAX_NUM_R2(MPDCCH_MAX_NUM_R2), MPDCCH_MAX_NUM_R4(MPDCCH_MAX_NUM_R4), MPDCCH_MAX_NUM_R8(MPDCCH_MAX_NUM_R8), MPDCCH_MAX_NUM_R16(MPDCCH_MAX_NUM_R16), MPDCCH_MAX_NUM_R32(MPDCCH_MAX_NUM_R32), MPDCCH_MAX_NUM_R64(MPDCCH_MAX_NUM_R64), MPDCCH_MAX_NUM_R128(MPDCCH_MAX_NUM_R128), MPDCCH_MAX_NUM_R256(MPDCCH_MAX_NUM_R256)

Unit: None

Actual Value Range: MPDCCH_MAX_NUM_R1, MPDCCH_MAX_NUM_R2, MPDCCH_MAX_NUM_R4, MPDCCH_MAX_NUM_R8, MPDCCH_MAX_NUM_R16, MPDCCH_MAX_NUM_R32, MPDCCH_MAX_NUM_R64, MPDCCH_MAX_NUM_R128, MPDCCH_MAX_NUM_R256

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default as follows:

MPDCCH_MAX_NUM_R8 when CoverageLevel is set to COVERAGE_LEVEL_0

MPDCCH_MAX_NUM_R8 when CoverageLevel is set to COVERAGE_LEVEL_1

MPDCCH_MAX_NUM_R64 when CoverageLevel is set to COVERAGE_LEVEL_2

MPDCCH_MAX_NUM_R64 when CoverageLevel is set to COVERAGE_LEVEL_3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to better MPDCCH demodulation performance, higher resource consumption, and a higher probability that UEs cannot access the cell due to contention resolution timer expiration. A smaller value of this parameter leads to poorer MPDCCH demodulation performance and lower resource consumption.

Applicable Mode: L-FDD, L-TDD
PdschInitRepNum Initial Number of PDSCH Repetitions

Meaning: Indicates the initial number of PDSCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: INVALID(INVALID), PDSCH_INIT_REP_INDEX_1(PDSCH_INIT_REP_INDEX_1), PDSCH_INIT_REP_INDEX_2(PDSCH_INIT_REP_INDEX_2), PDSCH_INIT_REP_INDEX_3(PDSCH_INIT_REP_INDEX_3), PDSCH_INIT_REP_INDEX_4(PDSCH_INIT_REP_INDEX_4), PDSCH_INIT_REP_INDEX_5(PDSCH_INIT_REP_INDEX_5), PDSCH_INIT_REP_INDEX_6(PDSCH_INIT_REP_INDEX_6), PDSCH_INIT_REP_INDEX_7(PDSCH_INIT_REP_INDEX_7), PDSCH_INIT_REP_INDEX_8(PDSCH_INIT_REP_INDEX_8)

Unit: None

Actual Value Range: INVALID, PDSCH_INIT_REP_INDEX_1, PDSCH_INIT_REP_INDEX_2, PDSCH_INIT_REP_INDEX_3, PDSCH_INIT_REP_INDEX_4, PDSCH_INIT_REP_INDEX_5, PDSCH_INIT_REP_INDEX_6, PDSCH_INIT_REP_INDEX_7, PDSCH_INIT_REP_INDEX_8

MML Default Value: None

Recommended Value: INVALID

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to better PDSCH demodulation performance and higher resource consumption. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
PdschInitRepNumType1Css Initial Number of PDSCH Rep for Type1 CSS

Meaning: Indicates the initial number of repetitions of the type-1 CSS PDSCH for UEs at the specified coverage level. Given that UE coverage level information is unavailable in type-1 CSS, the number specified by this parameter for the highest coverage level supported by the cell takes effect. For details, see 3GPP TS 36.213. A larger value of this parameter leads to a higher probability that UEs cannot access the cell due to failures of RAR resource allocation within the RAR window. It is recommended that this parameter be set based on the setting of the MpdcchInitRepNumType1Css parameter (in the EmtcCeSchCfg MO) as follows:

If the MpdcchInitRepNumType1Css parameter is set to MPDCCH_INIT_REP_INDEX_3, set the PdschInitRepNumType1Css parameter to PDSCH_INIT_REP_INDEX_5 or a value with a smaller index number.

If the MpdcchInitRepNumType1Css parameter is set to MPDCCH_INIT_REP_INDEX_4, set the PdschInitRepNumType1Css parameter to PDSCH_INIT_REP_INDEX_2 or a value with a smaller index number.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: INVALID(INVALID), PDSCH_INIT_REP_INDEX_1(PDSCH_INIT_REP_INDEX_1), PDSCH_INIT_REP_INDEX_2(PDSCH_INIT_REP_INDEX_2), PDSCH_INIT_REP_INDEX_3(PDSCH_INIT_REP_INDEX_3), PDSCH_INIT_REP_INDEX_4(PDSCH_INIT_REP_INDEX_4), PDSCH_INIT_REP_INDEX_5(PDSCH_INIT_REP_INDEX_5), PDSCH_INIT_REP_INDEX_6(PDSCH_INIT_REP_INDEX_6), PDSCH_INIT_REP_INDEX_7(PDSCH_INIT_REP_INDEX_7), PDSCH_INIT_REP_INDEX_8(PDSCH_INIT_REP_INDEX_8)

Unit: None

Actual Value Range: INVALID, PDSCH_INIT_REP_INDEX_1, PDSCH_INIT_REP_INDEX_2, PDSCH_INIT_REP_INDEX_3, PDSCH_INIT_REP_INDEX_4, PDSCH_INIT_REP_INDEX_5, PDSCH_INIT_REP_INDEX_6, PDSCH_INIT_REP_INDEX_7, PDSCH_INIT_REP_INDEX_8

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

PDSCH_INIT_REP_INDEX_3 when CoverageLevel is set to COVERAGE_LEVEL_0

PDSCH_INIT_REP_INDEX_4 when CoverageLevel is set to COVERAGE_LEVEL_1

PDSCH_INIT_REP_INDEX_2 when CoverageLevel is set to COVERAGE_LEVEL_2

PDSCH_INIT_REP_INDEX_2 when CoverageLevel is set to COVERAGE_LEVEL_3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to better PDSCH demodulation performance, higher resource consumption, and a higher probability that UEs cannot access the cell due to failures of RAR resource allocation within the RAR window. A smaller value of this parameter leads to poorer PDSCH demodulation performance and lower resource consumption.

Applicable Mode: L-FDD, L-TDD
PuschInitRepNum Initial Number of PUSCH Repetitions

Meaning: Indicates the initial number of PUSCH repetitions for UEs at a specified coverage level. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: INVALID(INVALID), PUSCH_INIT_REP_INDEX_1(PUSCH_INIT_REP_INDEX_1), PUSCH_INIT_REP_INDEX_2(PUSCH_INIT_REP_INDEX_2), PUSCH_INIT_REP_INDEX_3(PUSCH_INIT_REP_INDEX_3), PUSCH_INIT_REP_INDEX_4(PUSCH_INIT_REP_INDEX_4), PUSCH_INIT_REP_INDEX_5(PUSCH_INIT_REP_INDEX_5), PUSCH_INIT_REP_INDEX_6(PUSCH_INIT_REP_INDEX_6), PUSCH_INIT_REP_INDEX_7(PUSCH_INIT_REP_INDEX_7), PUSCH_INIT_REP_INDEX_8(PUSCH_INIT_REP_INDEX_8)

Unit: None

Actual Value Range: INVALID, PUSCH_INIT_REP_INDEX_1, PUSCH_INIT_REP_INDEX_2, PUSCH_INIT_REP_INDEX_3, PUSCH_INIT_REP_INDEX_4, PUSCH_INIT_REP_INDEX_5, PUSCH_INIT_REP_INDEX_6, PUSCH_INIT_REP_INDEX_7, PUSCH_INIT_REP_INDEX_8

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Applicable Mode: L-FDD, L-TDD

Example

To modify Scheduling Configurations for eMTC UEs at a Specific Coverage Level with the parameters as follows: Local cell ID: 8, Coverage Level: COVERAGE_LEVEL_0, Initial Number of MPDCCH Repetitions: MPDCCH_INIT_REP_INDEX_1, run the following command:
MOD EMTCCESCHCFG: LocalCellId=8, CoverageLevel=COVERAGE_LEVEL_0, MpdcchInitRepNum=MPDCCH_INIT_REP_INDEX_1;
