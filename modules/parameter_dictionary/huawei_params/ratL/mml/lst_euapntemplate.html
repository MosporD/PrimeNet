Query an APN template (LST EUAPNTEMPLATE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query an APN template.

Note

None.

Parameters

ID Name Description
APNTemplateID APN Template ID

Meaning: Indicates the ID of an APN template. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query an APN template, run the following command:
LST EUAPNTEMPLATE:;
The result is shown as follows:

Output Description

Field Description

APN Template ID

Indicates the ID of an APN template. This parameter applies only to LTE FDD and LTE TDD.

APN

Indicates the APN bound to the subscriber template. The value of this parameter can contain a maximum of seven dots (.). Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

QoS class identifier

Indicates a compact EPC QoS attribute that is provided for a service data flow (SDF) as a reference to a specific packet forwarding behavior (such as packet loss rate and delay). The packet forwarding is performed based on the QCI-related parameters that are pre-configured on the access network node (such as the eNodeB). This parameter applies only to LTE FDD and LTE TDD.

APN Aggregate Maximum Bit Rate Downlink(bit/s)

Indicates the downlink aggregate maximum bit rate (AMBR) of the APN. This parameter applies only to LTE FDD and LTE TDD.

APN Aggregate Maximum Bit Rate Uplink(bit/s)

Indicates the uplink aggregate maximum bit rate (AMBR) of the APN. This parameter applies only to LTE FDD and LTE TDD.

Allocation and Retention Priority

Indicates a QoS attribute that specifies the relative importance compared to other bearers for allocation and retention of the bearer. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Preemption Capability

Indicates a QoS attribute that specifies whether bearers can occupy resources for lower-priority service data flows. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Preemption Vulnerability

Indicates a QoS attribute that controls whether resources for service data flows can be occupied by higher-priority service data flows. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.
