Modify UE Specified DRX Parameter Group (MOD UESPECDRXPARAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of a group of DRX parameters for specific UEs in a cell.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DrxParaGroupIndex DRX Parameter Group Index

Meaning: Indicates the index of a DRX parameter group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~252

Unit: None

Actual Value Range: 1~252

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DrxParaGroupStat DRX Parameter Group Status

Meaning: Indicates whether to enable the DRX parameter group. When a UE requests the DRX parameter group, the eNodeB can deliver the DRX parameter group to the UE only if this parameter is set to ENABLE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default as follows:

DrxParaGroupIndex is set to 1: DISABLE(Disable)

DrxParaGroupIndex is set to 2: DISABLE(Disable)

DrxParaGroupIndex is set to 3: DISABLE(Disable)

DrxParaGroupIndex is set to 4: DISABLE(Disable)

DrxParaGroupIndex is set to 5: ENABLE(Enable)

DrxParaGroupIndex is set to 6: ENABLE(Enable)

DrxParaGroupIndex is set to 7: DISABLE(Disable)

DrxParaGroupIndex is set to 8: DISABLE(Disable)

DrxParaGroupIndex is set to 9: ENABLE(Enable)

DrxParaGroupIndex is set to 10: ENABLE(Enable)

DrxParaGroupIndex is set to 11: ENABLE(Enable)

DrxParaGroupIndex is set to 252: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When a UE requests the DRX parameter group, the eNodeB can deliver the DRX parameter group to the UE if this parameter is set to ENABLE. This reduces the UE power consumption but increases the service delay. In the same scenario, the eNodeB cannot deliver the DRX parameter group to the UE if this parameter is set to DISABLE. This increases UE power consumption but reduces the service delay.

Applicable Mode: L-FDD, L-TDD
OnDurationTimer On Duration Timer

Meaning: Indicates the length of the On Duration Timer. Because of the impact of CQI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

MML Default Value: None

Recommended Value: PSF10(10 PDCCH subframes)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DrxInactivityTimer DRX Inactivity Timer

Meaning: Indicates the length of the DRX Inactivity Timer. This parameter applies only to LTE FDD and LTE TDD.

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default. The default value is as follows:

DrxParaGroupIndex is set to a value from 5 to 8: PSF100(100 PDCCH subframes)

DrxReTxTimer DRX Retransmission Timer

Meaning: Indicates the length of the DRX Retransmission Timer. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PSF1(1 PDCCH subframes), PSF2(2 PDCCH subframes), PSF4(4 PDCCH subframes), PSF6(6 PDCCH subframes), PSF8(8 PDCCH subframes), PSF16(16 PDCCH subframes), PSF24(24 PDCCH subframes), PSF33(33 PDCCH subframes)

Unit: None

Actual Value Range: PSF1, PSF2, PSF4, PSF6, PSF8, PSF16, PSF24, PSF33

MML Default Value: None

Recommended Value: PSF8(8 PDCCH subframes)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongDrxCycle, OnDurationTimer, DrxInactivityTimer, ShortDrxCycle, and DrxShortCycleTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged and this parameter is set to a small value, the UE may enter sleep time before receiving the retransmitted data. In this case, the retransmitted data may not be correctly received. If this parameter is set to a large value and the settings of other DRX parameters remain unchanged, the UE keeps waiting for the retransmitted data when the data is lost. In this case, the UE stays in active time, reducing the battery life.

Applicable Mode: L-FDD, L-TDD
LongDrxCycle Long DRX Cycle

Meaning: Indicates the length of the long DRX cycle. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SF10(10 subframes), SF20(20 subframes), SF32(32 subframes), SF40(40 subframes), SF64(64 subframes), SF80(80 subframes), SF128(128 subframes), SF160(160 subframes), SF256(256 subframes), SF320(320 subframes), SF512(512 subframes), SF640(640 subframes), SF1024(1024 subframes), SF1280(1280 subframes), SF2048(2048 subframes), SF2560(2560 subframes), SF60(60 subframes)

Unit: None

Actual Value Range: SF10, SF20, SF32, SF40, SF64, SF80, SF128, SF160, SF256, SF320, SF512, SF640, SF1024, SF1280, SF2048, SF2560, SF60

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default. The default value is as follows:

DrxParaGroupIndex is set to 1: SF160(160 subframes)

DrxParaGroupIndex is set to 2: SF320(320 subframes)

DrxParaGroupIndex is set to 3: SF640(640 subframes)

DrxParaGroupIndex is set to 4: SF1280(1280 subframes)

DrxParaGroupIndex is set to 5: SF160(160 subframes)

DrxParaGroupIndex is set to 6: SF320(320 subframes)

DrxParaGroupIndex is set to 7: SF640(640 subframes)

DrxParaGroupIndex is set to 8: SF1280(1280 subframes)

DrxParaGroupIndex is set to 9: SF40(40 subframes)

DrxParaGroupIndex is set to 10: SF64(64 subframes)

DrxParaGroupIndex is set to 11: SF80(80 subframes)

DrxParaGroupIndex is set to 252: SF80(80 subframes)

The DRX parameter group of index 10 is used for voice and video services, and therefore the LongDrxCycle parameter needs to be configured to an integer multiple of 20 ms. It is recommended that the LongDrxCycle parameter value in the DRX parameter group of index 10 be changed to SF60(60 subframes).

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the OnDurationTimer, DrxInactivityTimer, ShortDrxCycle, DrxShortCycleTimer, and DrxReTxTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay and better KPIs such as the service drop rate and the handover success rate, and a larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
SupportShortDrx Short-Cycle DRX Supported Indication

Meaning: Indicates whether to enable or disable short DRX cycles. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: UU_DISABLE(Disable), UU_ENABLE(Enable)

Unit: None

Actual Value Range: UU_DISABLE, UU_ENABLE

MML Default Value: None

Recommended Value: UU_DISABLE

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongDrxCycle, OnDurationTimer, DrxInactivityTimer, ShortDrxCycle, DrxShortCycleTimer, and DrxReTxTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged and the SupportShortDrx parameter is set to UU_ENABLE, the short DRX cycle takes effect. As a result, the service delay decreases but the UE power consumption increases. The value UU_DISABLE results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
ShortDrxCycle Short DRX Cycle

Meaning: Indicates the length of the short DRX cycle. According to 3GPP specifications, the length of a long DRX cycle must be an integer multiple of that of a short DRX cycle. In addition, the actual value of LongDrxCycle assigned to a UE may be less than the configured value because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter. Therefore, the actual value of ShortDrxCycle assigned to a UE may be less than the configured value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SF2(2 subframes), SF5(5 subframes), SF8(8 subframes), SF10(10 subframes), SF16(16 subframes), SF20(20 subframes), SF32(32 subframes), SF40(40 subframes), SF64(64 subframes), SF80(80 subframes), SF128(128 subframes), SF160(160 subframes), SF256(256 subframes), SF320(320 subframes), SF512(512 subframes), SF640(640 subframes)

Unit: None

Actual Value Range: SF2, SF5, SF8, SF10, SF16, SF20, SF32, SF40, SF64, SF80, SF128, SF160, SF256, SF320, SF512, SF640

MML Default Value: None

Recommended Value: SF20(20 subframes)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongDrxCycle, OnDurationTimer, DrxInactivityTimer, DrxShortCycleTimer, and DrxReTxTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter system delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DrxShortCycleTimer DRX Short Cycle Timer

Meaning: Indicates the length of the DRX Short Cycle Timer. If this parameter is set to a large value, a UE for which short DRX cycles are enabled stays in short-cycle DRX for a long time. For details, see section 5.7 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~16

Unit: None

Actual Value Range: 1~16

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongDrxCycle, OnDurationTimer, DrxInactivityTimer, ShortDrxCycle, and DrxReTxTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify a specific group of DRX parameters for UEs with Local Cell ID of 0, DRX parameter GroupIndex of 10, DRX parameter GroupStat of Disable, run the following command:
MOD UESPECDRXPARAGROUP: LocalCellId=0, DrxParaGroupIndex=10, DrxParaGroupStat=DISABLE;
