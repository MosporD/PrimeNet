Modify a subscriber (MOD EUSUBSCRIBER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a subscriber.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After an RRN initially accesses the network, the KI parameter must be changed to a user-defined value, and it is recommended that the OP parameter be changed to a user-defined value. These parameters can be changed by running the MOD EUSUBSCRIBER command.

Parameters

Meaning: This parameter specifies the type of a subscriber. The value UE indicates a subscriber using a UE. The value RRN indicates a subscriber using an RRN. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates the number that uniquely identifies a UE. It is stored on the SIM card of the UE and sent to the eNodeB during network access. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Actual Value Range: 000000000000000~999999999999999

MML Default Value: None

Applicable Mode: L-FDD, L-TDD
RrnId RRN ID

Meaning: Indicates the ID that uniquely identifies an RRN. It is equivalent to the IMSI. This ID is stored on the RRN, and sent to the eNodeB when the RRN accesses the network. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 15 characters

Unit: None

Actual Value Range: 000000000000000~999999999999999

MML Default Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of the RrnId parameter in each EuSubscriber MO must be unique.
  • The value of the RrnId parameter in the EuSubscriber MO must consist of digits from 0 to 9 only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set a subscriber with the parameters as follows: Local Subscriber ID:1, Subscriber Type:UE(UE), International Mobile Subscriber ID:460010000000042, run the following command:
MOD EUSUBSCRIBER: LocalSubscriberId=1, SubscriberType=UE, IMSI="460010000000042";
