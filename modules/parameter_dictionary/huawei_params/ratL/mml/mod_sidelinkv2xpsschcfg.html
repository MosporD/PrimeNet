Modify a Sidelink V2X PSSCH Configuration (MOD SIDELINKV2XPSSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a sidelink V2X PSSCH.

Note

None.

Parameters

ID Name Description
SidelinkV2xCarrierId Sidelink V2X Carrier ID

Meaning: Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PsschCfgIndex PSSCH Configuration Index

Meaning: Indicates the PSSCH ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UeSpeedThld UE Speed Threshold

Meaning: Indicates the UE speed threshold for sidelink V2X. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 60_KMPH(60km/h), 80_KMPH(80km/h), 100_KMPH(100km/h), 120_KMPH(120km/h), 140_KMPH(140km/h), 160_KMPH(160km/h), 180_KMPH(180km/h), 200_KMPH(200km/h)

Unit: None

Actual Value Range: 60_KMPH, 80_KMPH, 100_KMPH, 120_KMPH, 140_KMPH, 160_KMPH, 180_KMPH, 200_KMPH

MML Default Value: None

Recommended Value: 140_KMPH(140km/h)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify a sidelink V2X PSSCH configuration with the sidelink V2X carrier ID of 0, PSSCH configuration index of 0, and UE speed threshold of 160, run the following command:
MOD SIDELINKV2XPSSCHCFG: SidelinkV2xCarrierId=0, PsschCfgIndex=0, UeSpeedThld=160_KMPH;
