Display LAA Cell FCS Parameters (DSP CELLLAAFCSPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the results of last FCS implementation for the cells operating on an unlicensed frequency band.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

Unit: None

MML Default Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FcsStartFreq FCS Start Frequency

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

FCS Start Frequency(MHz)

Indicates the starting frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS. The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.

FCS Stop Frequency(MHz)

Indicates the cut-off frequency of spectrum scanning for FCS of LAA cells. The unlicensed spectrum ranging from the starting frequency to the cut-off frequency is scanned for FCS The operating frequency of an LAA cell is selected from this frequency range. This parameter applies only to LTE TDD.

FCS Interference Threshold(dBm)

Indicates the threshold of the interference level detected in an LAA cell. If the interference level exceeds this threshold, the channel is considered occupied. Otherwise, the channel is considered available. This parameter applies only to LTE TDD.

Channel Center Frequency(MHz)

Indicates the central frequency of each channel on 5G unlicensed band. This parameter is used to show the interference detection results of each channel on 5G unlicensed band. This option applies only to LTE TDD.

Interference Duty(%)

Indicates the interference duty ratio detected on each channel on 5G unlicensed band. This parameter is used to show the interference detection results of each channel on 5G unlicensed band. This parameter applies only to LTE TDD.

Interference Duty Rate Timestamp

Indicates a timestamp for calculating the interference duty cycle. This parameter applies only to LTE TDD.
