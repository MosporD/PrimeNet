Start D-MIMO Pre-calibration (STR DMIMOPRECALIBRATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start channel pre-calibration for D-MIMO to obtain RRU channel pre-calibration information for D-MIMO.

Note

The starting time of D-MIMO channel pre-calibration observes standard time.

Parameters

ID Name Description
TxSectorEqmEnodebId TX Sector Equipment eNodeB ID

Meaning: Indicates the ID of the eNodeB to which the sector equipment (or sector equipment group) transmitting signals for channel pre-calibration for D-MIMO belongs. This parameter applies only to LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: N/A

Applicable Mode: L

Example

To start channel pre-calibration for D-MIMO with the ID of the eNodeB to which the sector equipment (or sector equipment group) transmitting signals for channel pre-calibration belongs set to 100, the ID of the sector equipment (or sector equipment group) set to 100, the ID of the local cell served by the sector equipment (or sector equipment group) set to 100, the frequency of the local cell set to 37850, and the startting time of pre-calibration for D-MIMO set to 2018-03-20 15:45:37:
STR DMIMOPRECALIBRATION: TxSectorEqmEnodebId=100, TxSectorEqmId=100, TxSectorEqmLocalCellId=100, PreCalibrationDlEarfcn = 37850, PreCalibrationStartTime = 2018&03&20&15&45&37;
