Add Parameter Group for Intra-Frequency Handover (ADD INTRAFREQHOGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a parameter group related to intra-frequency handover.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntraFreqHoGroupId Intrafreq handover group ID

Meaning: Indicates the ID of the parameter group related to intra-frequency handover. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA3Hyst Intrafreq handover hysteresis

Meaning: Indicates the hysteresis for intra-frequency and inter-frequency handover event A3. This parameter decreases frequent event triggering due to radio signal fluctuations and reduces the probability of handover decision errors and ping-pong handovers. A larger value of this parameter results in a lower probability. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter makes it more difficult to trigger event A3, which delays handovers and affects user experience. A smaller value of this parameter makes it easier to trigger event A3, which increases handover decision errors and ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA3Offset Intrafreq handover offset

Meaning: Indicates the offset for event A3. If the parameter is set to a large value, an intra-frequency handover is performed only when the signal quality of the neighboring cell is significantly better than that of the serving cell and other triggering conditions are met. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A positive value of this parameter results in a relatively low probability of triggering event A3 and therefore a relatively low probability of handover. A negative value of this parameter leads to a relatively high probability of triggering event A3 and therefore a relatively high probability of handover.

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA3TimeToTrig Intrafreq handover time to trigger

Meaning: Indicates the time-to-trigger for intra-frequency and inter-frequency handover event A3.

When the entering condition for intra-frequency or inter-frequency handover event A3 is met, the UE does not immediately report event A3 to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reports, preventing unnecessary handovers. As a result, the average number of handovers and the number of incorrect handovers decrease. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: 320ms(320ms)

Recommended Value: 320ms

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter helps reduce the average number of handovers and the number of unexpected handovers, and hence prevents unnecessary handovers. A larger value of this parameter results in a smaller average number of handovers, but it also leads to a higher risk of call drops.

Applicable Mode: L-FDD, L-TDD
HighSpeedA3TimeToTrig High Speed Intra Frequency A3 Time To Trigger

Meaning: Indicates the time-to-trigger for event A3 related to intra-frequency handovers for high-speed UEs in high-speed cells.

When the entering condition for intra-frequency handover event is met, the UE does not immediately report event A3 to the eNodeB. Instead, the UE sends a report only when the signal quality meets the entering condition throughout the time-to-trigger. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: 64ms

Recommended Value: 64ms(64ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that high-speed UEs report event A3 for triggering intra-frequency handovers and a higher probability of call drops due to untimely handovers. A smaller value of this parameter results in a higher probability that high-speed UEs report event A3 for intra-frequency handovers and a higher probability of inducing ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA2ThldRsrpCE Intra-Freq A2 RSRP Threshold for CE

Meaning: Indicates the RSRP threshold for triggering event A2 related to coverage-based intra-frequency handover for eMTC UEs in coverage enhancement mode. If the measured RSRP value is less than this parameter value, such a UE sends a measurement report. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: -104

Recommended Value: -104

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of triggering event A2 and a higher probability of triggering intra-frequency measurements conducted by eMTC UEs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
ModeAAdjA1RsrpThld Mode A Adjustment A1 RSRP Threshold

Meaning: Indicates the threshold for triggering event A1 based on which UEs switch the coverage mode to coverage enhancement (CE) mode A at coverage level 1. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: -120

Recommended Value: -120

Parameter Relationship:

-Configuration constraints:

  • In an IntraFreqHoGroup MO, the ModeAAdjA1RsrpThld parameter value must be greater than or equal to the ModeBAdjA2RsrpThld parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that UEs switch the coverage mode to CE mode A at coverage level 1 and more air interface resources are used. A smaller value of this parameter results in a higher probability that UEs switch the coverage mode to CE mode A at coverage level 1 and a higher probability of service drops.

Applicable Mode: L-FDD, L-TDD

A smaller value of this parameter results in a lower probability that UEs switch the coverage mode from normal coverage mode to CE mode A or switch the coverage level from coverage level 0 to coverage level 1 and a higher probability of service drops.

EmtcHandoverA3TimeToTrig eMTC Handover A3 Time to Trigger

Example

To add a parameter group related to intra-frequency handover with Local cell identity of 0, IntraFreqHoGroupID of 9, and other parameters retaining their default values, run the following command:
ADD INTRAFREQHOGROUP: LocalCellId=0, IntraFreqHoGroupId=9;
