Add eNodeB CHR Output Mode (ADD CHROUTPUTMODE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a CHR output mode.

Note

If multiple CHR output mode is added with the same cause value, the configuration is the smallest number is applied.

Parameters

ID Name Description
ModeNo Mode Number

Meaning: Indicates the number of a specific call history record (CHR) hierarchical classification output mode.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
ChrDetailCauseVal CHR Detail Cause Value

Meaning: Indicates the call history record (CHR) generating cause value corresponding to a specific CHR hierarchical classification mode.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
ChrHierOutMode CHR Hierarchical Output Mode

Meaning: Indicates the call history record (CHR) hierarchical output mode. If the parameter is set to Level_1_Output, level-1 CHRs, that is, only typical records, are output. If the parameter is set to Level_2_Output, level-2 CHRs, that is, all records, are output. If level-2 CHRs start to be output, the number of output records increases, thereby decreasing the duration when the local logs can be recorded.

GUI Value Range: Level_1_Output(Level_1_Output), Level_2_Output(Level_2_Output)

Unit: None

Actual Value Range: Level_1_Output, Level_2_Output

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SamplingEnable CHR Output Sampling Indicator

Meaning: Indicates whether CHRs are output after being sampled. If this parameter is set to SamplingEnable, specific sampled CHRs are output. If this parameter is set to SamplingUnable, all specific CHRs are output without being sampled. If the value of this parameter is changed from SamplingEnable to SamplingUnable, the number of records increases, thereby decreasing the duration when the local logs can be recorded.

GUI Value Range: SamplingEnable(SamplingEnable), SamplingUnable(SamplingUnable)

Unit: None

Actual Value Range: SamplingEnable, SamplingUnable

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To add a CHR output mode with the parameters as follows: Mode Number: 1, CHR Detail Cause Value: 64531, CHR Hierarchical Output Mode: Level_1_Output, CHR Output Sampling Indicator: SamplingUnable, run the following command:
ADD CHROUTPUTMODE: ModeNo=1, ChrDetailCauseVal=64531, ChrHierOutMode=Level_1_Output, SamplingEnable=SamplingUnable;
