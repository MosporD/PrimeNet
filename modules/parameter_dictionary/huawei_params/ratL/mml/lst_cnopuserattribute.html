List Operator-specific User Attribute (LST CNOPUSERATTRIBUTE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list operator-specific user attributes.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Arp Allocation and Retention Priority

Meaning: Indicates the allocation and retention priority (ARP) of EPS bearers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list operator-specific user attributes, run the following command:
LST CNOPUSERATTRIBUTE:;
The result is shown as follows:
+++    0        2019-12-08 17:21:02
O&M    #806354963
%%LST CNOPUSERATTRIBUTE:;%%
RETCODE = 0  Operation succeeded.

Display CnOpUserAttribute
---------------------
                   CN Operator ID  =  0
Allocation and Retention Priority  =  1
                    User Priority  =  Gold
(Number of results = 1)


---    END

Output Description

Field Description

CN Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

Allocation and Retention Priority

Indicates the allocation and retention priority (ARP) of EPS bearers. This parameter applies only to LTE FDD and LTE TDD.

User Priority

Indicates the user priority. This parameter applies only to LTE FDD and LTE TDD.
