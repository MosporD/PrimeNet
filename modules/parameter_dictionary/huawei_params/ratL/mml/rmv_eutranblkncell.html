Remove Neighboring Relation with EUTRANBLK Cell (RMV EUTRANBLKNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one blacklisted neighbor relationship with an E-UTRAN cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the ID of a local cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the MCC of a neighboring E-UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of the Mcc parameter in the EutranBlkNCell MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the MNC of a neighboring E-UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
eNodeBId eNodeB ID

Meaning: Indicates the eNodeB ID of a blacklisted neighboring E-UTRAN cell, which uniquely identifies an eNodeB within a PLMN. A cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates the cell ID of a blacklisted E-UTRAN cell, which uniquely identifies a cell within an eNodeB. A cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the local cell ID is represented by the 8 least significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

Example

To delete Eutran black neighboring cell, delete the service cell id 0, mobile country code 460, mobile network code 01, eNodeB id 400013, cell id 3, run the following command:
RMV EUTRANBLKNCELL: LocalCellId=0, Mcc="460", Mnc="01", eNodeBId=400013, CellId=3;
The result is shown as following:
