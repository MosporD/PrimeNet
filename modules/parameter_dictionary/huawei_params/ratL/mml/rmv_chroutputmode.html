Remove eNodeB CHR Output Mode (RMV CHROUTPUTMODE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a CHR output mode.

Note

After the CHR output mode is removed, CHRs with the corresponding cause value will be output with the default mode. By default, only level-1 CHRs are output and sampling is started.

Parameters

ID Name Description
ModeNo Mode Number

Meaning: Indicates the number of a specific call history record (CHR) hierarchical classification output mode.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove CHR output mode with the ID of 1, run the following command:
RMV CHROUTPUTMODE: ModeNo=1;
