Remove X2 Configuration (RMV X2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an X2 object.

Note

  • After an X2 object is removed, all X2 links under this object are removed.

  • After an X2 MO is removed, the eNodeB cannot perform self-setup of the X2 interface configured for the operator.

Parameters

ID Name Description
X2Id X2 ID

Meaning: Indicates the X2 MO ID.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove an X2 object whose ID is 0, run the following command:
RMV X2: X2Id=0;
