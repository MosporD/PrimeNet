List eNodeB NB-IoT Configuration (LST ENODEBNBPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of eNodeB-level NB-IoT parameters.

Note

None.

Parameters

None.

Example

List eNodeB NB-IoT Configuration:
LST ENODEBNBPARA:;
The result is shown as follows:
+++    0        2019-12-05 08:43:11
O&M    #806355140
%%LST ENODEBNBPARA:;%%
RETCODE = 0  Operation succeeded.

List eNodeB NB-IoT Configuration
--------------------------------
NB-IoT Reserved Minimum User Number Ratio(%)  =  0
  NB-IoT Extended Paging Optimization Switch  =  Off
(Number of results = 1)


---    END

Output Description

Field Description

NB-IoT Reserved Minimum User Number Ratio(%)

Indicates the minimum proportion of UEs in RRC_CONNECTED mode reserved for NB-IoT. This parameter applies only to LTE FDD and NB-IoT.

NB-IoT Extended Paging Optimization Switch

Indicates whether to enable extended paging optimization for NB-IoT. If this parameter is set to ON, the eNodeB preferentially ensures capacity when adjusting the number of paging message transmission repetitions in the extended paging procedure. If this parameter is set to OFF, the eNodeB preferentially ensures coverage when adjusting the number of paging message transmission repetitions in the extended paging procedure. This parameter applies only to NB-IoT.
