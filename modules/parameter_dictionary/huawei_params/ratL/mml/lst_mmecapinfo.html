List MME Capability Information (LST MMECAPINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of the MME features.

Note

None.

Parameters

ID Name Description
MmeCapCfgId MME Capability Configuration ID

Meaning: Indicates the MME capability configuration index.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list MME capability information, run the following command:

LST MMECAPINFO:;
The result is shown as follows:

Output Description

Field Description

MME Capability Configuration ID

Indicates the MME capability configuration index.

S1 Configuration Type

Indicates the configuration type of the S1 interface. Set this parameter to S1_CFG if operators want to configure the MME capability according to the S1 MO. Set this parameter to S1INTERFACE_CFG if operators want to configure the MME capability according to the S1Interface MO.

S1 ID

Indicates the S1 object ID.

S1 Interface ID

Indicates the S1 interface ID.

NB-IoT CIoT EPS Optimization Capability

Indicates the MME's capability of supporting EPS optimized transmission for NB-IoT CIoT. If this parameter is set to NOT_SUPPORT, the MME does not support EPS optimized transmission for NB-IoT CIoT. If this parameter is set to CP, the MME supports control-plane EPS optimized transmission for NB-IoT CIoT. If this parameter is set to CP_UP, the MME supports control-plane and user-plane EPS optimized transmission for NB-IoT CIoT. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

MME Support LTE Capability

Indicates the MME's capability of supporting LTE FDD and LTE TDD. If this parameter is set to NOT_SUPPORT, the MME does not support LTE FDD or LTE TDD. If this parameter is set to SUPPORT, the MME supports LTE FDD and LTE TDD.

MME Support eMTC-Dedicated EPC Capability

Indicates whether the MME supports eMTC UEs to access a dedicated EPC.

If this parameter is set to NOT_SUPPORT, the MME does not support eMTC UEs to access a dedicated EPC. eMTC UEs access a common EPC if either of the following conditions is met:

- The MmeCapInfo MO is not configured for any MME.

- The MmeCapInfo MOs are configured and the MmeSupportEmtcDedEpcCap parameter in every MmeCapInfo MO is set to NOT_SUPPORT.

If this parameter is set to SUPPORT, the MME supports eMTC UEs to access a dedicated EPC. If the MmeSupportEmtcDedEpcCap parameter in one of the MmeCapInfo MOs is set to SUPPORT, eMTC UEs can only access a dedicated EPC.

MME NSA DC Capability

Indicates whether the MME supports NSA DC. If this parameter is set to NOT_SUPPORT, the MME does not support NSA DC. If this parameter is set to SUPPORT, the MME supports NSA DC. This parameter applies only to LTE FDD and LTE TDD.
