List External E-UTRAN Cell Slave Band (LST EUTRANEXTERNALCELLBAND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the external E-UTRAN cell slave band.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the external E-UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an EutranExternalCell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
Mnc Mobile network code

Meaning: Indicates the mobile network code of the external E-UTRAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in an EutranExternalCell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
eNodeBId eNodeB ID

Meaning: Indicates the eNodeB ID of the external E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

CellId Cell ID

Meaning: Indicates the cell ID of the external E-UTRAN cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details, see 3GPP TS 36.413.
