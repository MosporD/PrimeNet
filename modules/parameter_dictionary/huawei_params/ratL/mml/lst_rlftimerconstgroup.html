List Parameter Group for RLF Timer and Constants (LST RLFTIMERCONSTGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list one or all parameter groups related to RLF timer and constants.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RlfTimerConstGroupId RLF timer and constants group ID

Meaning: Indicates the RLF timer and constants group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

RLF timer and constants group ID

Indicates the RLF timer and constants group ID. This parameter applies only to LTE FDD and LTE TDD.

Timer 301

Indicates the length of the timer T301. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Timer 310

Indicates the length of the timer T310. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Timer 311

Indicates the length of the timer T311. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Constant N310

Indicates the maximum number of successive "out of sync" indications received from L1. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Constant N311

Indicates the maximum number of successive "in sync" indications received from L1. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

CE Timer 301

Indicates the length of the timer 301 in coverage enhancement mode. For details, see 3GPP TS 36.331.

This timer is started when the UE sends the RRCConnectionReestabilshmentRequest message.

Before the timer expires, it is stopped if the UE receives an RRCConnectionReestablishment or RRCConnectionReestablishmentReject message.

After the timer expires, the UE enters the RRC_IDLE state. This option applies only to LTE FDD and LTE TDD.

Timer 310 in CE Mode

Indicates the length of the timer T310 of the cell in coverage enhancement (CE) mode. For details, see 3GPP TS 36.331.

This timer is started for a UE when the UE detects a fault at the physical layer.

The timer is stopped if the UE detects the physical layer fault recovery, triggers a handover procedure, or initiates a reestablishment before the timer expires.

After the timer expires, the UE enters the RRC_IDLE state if the security mode is not activated. Otherwise, an RRC connection reestablishment is initiated. This parameter applies only to LTE FDD and LTE TDD.

Timer 311 in CE Mode

Indicates the length of the timer T311 of the cell in coverage enhancement (CE) mode. For details, see 3GPP TS 36.331.

This timer is started when the UE starts an RRC connection reestablishment.

The timer is stopped if the UE selects an E-UTRAN or inter-RAT cell to camp on before the timer expires.

After the timer expires, the UE enters the RRC_IDLE state. This parameter applies only to LTE FDD and LTE TDD.
