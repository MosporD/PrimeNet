Display Cell CSPC State (DSP CELLCSPCSTATUS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query whether CSPC is enabled in a cell or all cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the activation status of CSPC in a cell:
DSP CELLCSPCSTATUS:;
The result is shown as follows:
+++    0        2019-12-05 21:44:11
O&M    #806354986
%%DSP CELLCSPCSTATUS: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display Cell CSPC State
-----------------------
      Local Cell ID  =  1
   Cell CSPC Status  =  Off
            Remarks  =  The CSPC switch is off
Macro Or Micro Cell  =  Macro
(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Cell CSPC Status

Indicates whether CSPC has been enabled in the cell. This parameter applies only to LTE FDD and LTE TDD.

Remarks

Indicates the reason why CSPC is disabled in a cell. This parameter applies only to LTE FDD and LTE TDD.

Macro Or Micro Cell

Indicates the Cell type is Macro Cell or Micro Cell in CSPC. This parameter applies only to LTE FDD and LTE TDD.
