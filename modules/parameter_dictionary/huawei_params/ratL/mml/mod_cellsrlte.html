Modify Parameters Related to SR LTE-capable UE Scheduling Optimization (MOD CELLSRLTE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify configurations about scheduling optimization on single radio LTE-capable UEs in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SrlteSwitch SRLTE Switch

Meaning: Indicates whether to enable scheduling optimization on single radio LTE-capable UEs. A single radio LTE-capable UE periodically leaves the LTE system and listens to the paging channel of another RAT during camping or activation, and then returned to the LTE system after listening. If the eNodeB schedules the single radio LTE-capable UE when the UE is absent from the LTE system and listens to the paging channel of another RAT, RB resources are wasted. Based on scheduling optimization on single radio LTE-capable UEs, the eNodeB uses DTX detection to distinguish single radio LTE-capable UEs that leaves the LTE system and listens to the paging channel of another RAT, and then stops scheduling these UEs.

If this parameter is set to ON, scheduling optimization on single radio LTE-capable UEs is enabled.

If this parameter is set to OFF, scheduling optimization on single radio LTE-capable UEs is disabled.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If single radio LTE-capable UEs access a cell, setting this parameter to ON increases cell throughput, and setting this parameter to OFF has no impact on network performance. If no single radio LTE-capable UEs access a cell, the parameter setting has no impact on network performance.

Applicable Mode: L-FDD, L-TDD
SrlteDtxThrd SRLTE DTX Threshold

Meaning: Indicates the threshold of the consecutive number of times DTX from an SRLTE UE is detected in the cell.

If the consecutive number of times the eNodeB detects DTX from an SRLTE UE (including DTXs on the PUSCH and PDSCH) reaches the threshold, the eNodeB considers that the UE has switched from the LTE service state to the state of listening to paging from another RAT. This parameter applies only to LTE FDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to an earlier time when the eNodeB detects that an SRLTE UE has left the LTE network to listen to paging from another RAT, but detection accuracy is lower. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
SrlteSuspendTime SRLTE Suspend Time

Meaning: Indicates the period of time during which the eNodeB does not schedule a single radio LTE-capable UE because the UE is absent from the LTE mode. This parameter takes effect only when the SrlteSwitch parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~120

Unit: ms

Actual Value Range: 1~120

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the SrlteSwitch parameter is set to ON, changing the SrlteSuspendTime parameter value affects cell throughput.

A smaller value of the SrlteSuspendTime parameter results in short time that the eNodeB stops scheduling a single radio LTE-capable UE and a lower gain of cell throughput. A larger value of this parameter results in the opposite effects. A too large value of this parameter decreases throughput of the UE.

Applicable Mode: L-FDD, L-TDD
SrlteDiscardAlgoSwitch SRLTE Discard Algorithm Switch

Meaning: Indicates whether to enable the discarding of PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. When this parameter is set to ON, an eNodeB discards PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. When this parameter is set to OFF, an eNodeB retains PUSCH measurement results for single radio LTE-capable UEs when such UEs leave the LTE system and listen to the paging channel of another RAT. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON and there are single radio LTE-capable UEs in the cell, uplink throughput of these UEs increases. When this parameter is set to ON and there are no single radio LTE-capable UEs in the cell or when this parameter is set to OFF, radio network performance is not affected.

Applicable Mode: L-FDD

Example

To modify the configuration related to SR LTE-capable UE scheduling optimization in a cell with the parameters as follows: Local cell ID: 0, SRLTE Switch: ON, SRLTE DTX Threshold: 7, SRLTE Suspend Time: 11, run the following command:
MOD CELLSRLTE: LocalCellId=0, SrlteSwitch=ON, SrlteDtxThrd=7, SrlteSuspendTime=11;
