List Service-based Inter-RAT Handover Policy Group (LST SERVICEIRHOCFGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list one or all service-based inter-RAT handover policy groups.

Note

None.

Output Description

Field Description

CN Operator ID

Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

Service-based inter-RAT handover policy group ID

Indicates the ID of the service-based inter-RAT handover policy group. This parameter applies only to LTE FDD and LTE TDD.

Inter-RAT handover state

Indicates whether the status of service-based inter-RAT handovers for services with a specific QCI. If this parameter is set to NO_HO, service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN, UTRAN, and GERAN are not allowed. If this parameter is set to PERMIT_HO, then service-based inter-RAT handovers of services with the QCI from E-UTRAN to UTRAN and GERAN are allowed but cannot be proactively triggered, and service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN can be triggered. If this parameter is set to MUST_HO, service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN, UTRAN, and GERAN can be triggered. This parameter applies only to LTE FDD and LTE TDD.

Service-based Inter-RAT HO Measure Mode

Indicates the mode of service-based EUTRAN-to-GERAN and EUTRAN-to-UTRAN handover measurements. Assume that conditions for delivering measurement configurations related to both the service-based inter-frequency handovers and service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers are met. If the ServiceIrMeasMode parameter is set to SERVICE_IR_MEAS_ORDER, the eNodeB delivers the measurement configurations for service-based inter-frequency handovers first. After the service-based inter-frequency handover measurement times out, the eNodeB delivers measurement configurations for service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers. If the ServiceIrMeasMode parameter is set to SERVICE_IR_MEAS_NO_ORDER, the eNodeB delivers the measurement configurations for both service-based inter-frequency handovers and service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers. This parameter applies only to LTE TDD.
