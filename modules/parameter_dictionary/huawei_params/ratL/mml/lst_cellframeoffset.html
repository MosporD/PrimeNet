List Frame Offset Configuration (LST CELLFRAMEOFFSET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list frame offset configurations in cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of the frame offset that takes effect in a cell:
LST CELLFRAMEOFFSET: LocalCellId=1;
The result is shown as follows:
+++    0        2019-07-06 15:33:38
O&M    #806355275
%%LST CELLFRAMEOFFSET: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List Frame Offset Configuration
-------------------------------
    Local Cell ID  =  0
Frame Offset Mode  =  User-defined frame offset
 Frame Offset(Ts)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

Frame Offset Mode

Indicates the frame offset configuration mode for the cell.

The value CustomFrameOffset(User-defined frame offset) indicates that the frame offset is user-defined. Only this value applies to FDD cells and NB-IoT cells.

The value TL_FrameOffset(T-L Dual Mode frame offset) indicates that the frame offset is automatically determined based on the subframe configuration in a TD-SCDMA + LTE TDD dual-RAT network.

The value TL_FrameOffset_SA2_SSP5(T-L Dual Mode SA2+SSP5 frame offset) indicates that the frame offset is automatically determined based on uplink-downlink configuration 2 and special subframe configuration 5 in a TD-SCDMA + LTE TDD dual-RAT network.

Frame Offset(Ts)

Indicates the offset of the start time of a cell frame against a reference clock source.
