Add Serving-Cell-Operator-Dedicated Config of Neighboring NR Frequency (ADD NRNFREQSCELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a serving-cell-operator-specific dedicated configuration of a neighboring NR frequency.

Note

  • The CnOperator MO referenced by the CnOperatorId parameter in an NrNFreqSCellOp must be configured.

  • The associated NrNFreq MO must be configured before the configuration of an NrNFreqSCellOp MO.

  • For the same operator in a cell, the dedicated cell-reselection priorities specified in the NrNFreqSCellOp and UtranNFreqSCellOp MOs cannot be the same.

  • For the same operator in a cell, the dedicated cell-reselection priorities specified in the NrNFreqSCellOp and EutranNFreqSCellOp MOs cannot be the same.

  • Serving-cell-operator-specific dedicated cell-reselection priorities based on operators of the local cell (which are specified in the NrNFreqSCellOp, EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, and Cdma2000BcSCellOp MOs) cannot coexist with neighboring-frequency-operator-specific dedicated cell-reselection priorities (which are specified in the EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs).

  • For the same operator in a cell, the dedicated cell-reselection priorities specified in the NrNFreqSCellOp and GeranNFGroupSCellOp MOs cannot be the same.

  • For the same operator in a cell, the dedicated cell-reselection priorities specified in the NrNFreqSCellOp and Cdma2000BcSCellOp MOs cannot be the same.

CellReselPriority Cell Reselection Priority

Meaning: Indicates the serving-cell-PLMN-specific dedicated cell-reselection priority for the NR frequency. The value 0 indicates the lowest priority. If SPIDs are configured, the SPID-specific dedicated cell-reselection priority is used. If SPIDs are not configured but this parameter is configured, the base station includes the cell-reselection priority specific to the PLMN that a UE supports in the IE idleModeMobilityControlInfo in the RRC connection release message. If operator-specific cell-reselection priority for the NR frequency is not configured, the UE uses the common cell-reselection priority for the NR frequency delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.

Example

To add a serving-cell-operator-specific dedicated configuration of a neighboring NR frequency,LocalCellId=0, DlArfcn=620000, CnOperatorId=0, CellReselPriorityConfigInd=NOT_CFG:
ADD NRNFREQSCELLOP: LocalCellId=0, DlArfcn=620000, CnOperatorId=0, CellReselPriorityConfigInd=NOT_CFG;
