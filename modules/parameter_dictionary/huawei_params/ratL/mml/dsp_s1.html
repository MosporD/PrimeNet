Display S1 Configuration (DSP S1)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the control-plane configuration of S1 interfaces for which the Control Mode parameter in the S1Interface MO is set to AUTO_MODE.

Note

None.

Parameters

ID Name Description
S1Id S1 ID

Meaning: Indicates the S1 object ID.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the information about the S1 object, run the following command: 
DSP S1:;
The result is shown as follows: 
+++    HUAWEI        2013-08-27 19:54:08
O&M    #152
%%DSP S1:;%%
RETCODE = 0  Operation succeeded.

Display S1 Configuration
------------------------
                       S1 ID  =  1
             S1 Interface ID  =  0
          S1 Interface State  =  Abnormal
       S1 Interface Is Block  =  FALSE
   S1 Interface CP Bearer ID  =  0
S1 Interface CP Bearer State  =  Abnormal
(Number of results = 1)


---    END

Output Description

Field Description

S1 ID

Indicates the S1 object ID.

S1 Interface ID

Indicates the S1 interface ID.

S1 Interface State

Indicates the status of the S1 interface.

S1 Interface Is Block

Indicates whether the S1 interface is blocked. An S1 interface is blocked after the execution of BLK S1INTERFACE and is unblocked after the execution of UBL S1INTERFACE.

S1 Interface CP Bearer ID

Indicates the ID of the control port bearer for the S1 interface.

S1 Interface CP Bearer State

Indicates the status of the control port (CP) bearer for the S1 interface.
