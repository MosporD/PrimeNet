List Cell Uplink MIMO Parameters Configuration (LST CELLULMIMOPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the UL MIMO configuration in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of uplink MIMO of a cell:
LST CELLULMIMOPARACFG:;
The result is shown as follows:
+++    0        2019-12-05 17:28:55
O&M    #806355883
%%LST CELLULMIMOPARACFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List Cell Uplink MIMO Parameters Configuration
----------------------------------------------
      Local cell ID  =  1
UpLink SU-MIMO Rank  =  RankAdaptive
(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

UpLink SU-MIMO Rank

Indicates the rank selection method when the uplink transmission mode is TM2. If this parameter is set to FixRank1(FixRank1), only rank 1 transmission can be performed for all UEs in the network. If this parameter is set to FixRank2(FixRank2), only rank 2 transmission can be performed for all UEs in the network. If this parameter is set to RankAdaptive(RankAdaptive), the eNodeB adaptively selects a rank based on the UE channel quality. This parameter applies only to LTE FDD and LTE TDD.
