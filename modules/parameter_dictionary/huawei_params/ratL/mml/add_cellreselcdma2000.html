Add Configuration of Cell Reselection to CDMA2000 (ADD CELLRESELCDMA2000)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the configuration related to cell reselection to CDMA2000.

Note

  • The CELL object should exist when adding the CDMA2000 cell reselection information.

  • If this MO is not configured, cell reselection to CDMA2000 is not allowed.

Example

To add the configuration related to cell reselection to a CDMA2000 cell with the parameters as follows: Local cell ID: 0, System time information configure indicator: CFG, CDMA and EUTRA network synchronised indicator: BOOLEAN_TRUE, CDMA search window size configure indicator: CFG, Search window size: 3, HRPD parameters configure indicator: CFG, HRPD cell reselection configure indicator: NOT_CFG, 1XRTT parameters configure indicator: CFG, 1XRTT state of long code generation registers configure indicator: NOT_CFG, 1XRTT cell reselection configure indicator: NOT_CFG, Dual Rx CSFB configure indicator: NOT_CFG, run the following command:
ADD CELLRESELCDMA2000: LocalCellId=0, SysTimeCfgInd=CFG, CdmaEutraSyn=BOOLEAN_TRUE, SearchWndSizeCfgInd=CFG, SearchWndSize=3, HrpdParaCfgInd=CFG, HrpdCellReselectParamCfgInd=NOT_CFG, Cdma1XrttParaCfgInd=CFG, Cdma1XrttCellReselCfgInd=NOT_CFG, SupportDualRxCsfbCfgInd=NOT_CFG;
