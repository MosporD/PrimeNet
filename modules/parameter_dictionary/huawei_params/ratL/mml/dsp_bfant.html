Display Beamforming Antenna (DSP BFANT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the dynamic information about one or all beamforming antennas.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of a beamforming antenna. It uniquely identifies a beamforming antenna within an eNodeB. This parameter is associated with the WeightNO parameter in the eUCellSectorEqm MO. If the WeightNO parameter in the eUCellSectorEqm MO is set to 255, the weight corresponding to the smallest DeviceNo parameter value is used. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

DSP BFANT: DEVICENO=0;

Output Description

Field Description

Device No.

Indicates the device number of a beamforming antenna. It uniquely identifies a beamforming antenna within an eNodeB. This parameter is associated with the WeightNO parameter in the eUCellSectorEqm MO. If the WeightNO parameter in the eUCellSectorEqm MO is set to 255, the weight corresponding to the smallest DeviceNo parameter value is used. This parameter applies only to LTE TDD.

Polar Mode

Indicates the polarization mode of a beamforming antenna. This parameter applies only to LTE TDD.

Element Beamform Width(degree)

Indicates the beamwidth of the antenna element.

Number of Port

Indicates the number of antenna ports to which a beamforming antenna is connected. This parameter applies only to LTE TDD.

CRS Port No.

Indicates the CRS port number. This parameter applies only to LTE TDD.

Channel No.

Indicates the antenna channel information of the cell. This parameter applies only to LTE TDD.

Amplitude Offset for CRS

Indicates the amount of amplitude adjustment for cell-specific reference signals when a beamforming antenna is used. This parameter applies only to LTE TDD.

Phase for CRS(degree)

Indicates the amount of phase adjustment for cell-specific reference signals when a beamforming antenna is used. This parameter applies only to LTE TDD.

Coverage Scenario

Indicates the coverage scenario of a massive MIMO antenna. This parameter is used to adjust the antenna beam pattern. The values EXPANDSCENARIO_1, EXPANDSCENARIO_2, and EXPANDSCENARIO_3 indicate user-defined coverage scenarios. For 64T64R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. For 32T32R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_5, SCENARIO_6, SCENARIO_7, SCENARIO_8, SCENARIO_9, SCENARIO_15, or SCENARIO_17. Due to the limited vertical beamwidth of a single 32T32R channel, it is not recommended that this parameter be set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. This parameter applies only to LTE TDD.
