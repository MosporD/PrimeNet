List Operator-Level Reserved Parameter (LST ENBCNOPRSVDPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list reserved operator-level parameters.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of operator-level reserved parameters, run the following command:
LST ENBCNOPRSVDPARA:;
The result is shown as follows:
+++    0        2019-07-18 20:40:30
O&M    #806355490
%%LST ENBCNOPRSVDPARA:;%%
RETCODE = 0  Operation succeeded.

Indicates reserved 32-bit switch parameter 0 that is reserved for future requirements.

Note on parameter replacement: Reserved parameters are temporarily used in patch versions and will be replaced with new parameters. For example, the ID of a new parameter can signify the parameter function. Therefore, avoid using this parameter.
