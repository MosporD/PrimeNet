Add Configuration of Cell RB Reserve (ADD CELLRBRESERVE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add cell RB reservation configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If too many RBs are blocked, UEs cannot access the network.

  • Adding RB reservation for a cell with the RbRsvMode parameter value being NB_RESERVED, NB_DEPLOYMENT, LNR_SPECTRUM_SHR_RB_RESERVED, or COVERAGE_ENH_RB_RESERVED will cause the cell to automatically restart.

RbRsvMode RB Reserve Mode

Meaning: Indicates the purpose for reserving RBs. The value NB_RESERVED indicates that the specified RBs are reserved not for NB-IoT deployment but as a guard band in the uplink or to reduce the interference between LTE and NB-IoT cells in the downlink. This value applies only to NB-IoT. The value NB_DEPLOYMENT indicates that the specified RBs are used for NB-IoT deployment. This value applies only to NB-IoT. The value RB_MASKING indicates that the specified RBs are used for manual RB masking. This value applies only to LTE FDD and LTE TDD. The value RB_MASKING_WITH_SRS indicates that the specified RBs are used for manual RB and SRS masking. This value applies only to LTE FDD. The value MCPTT_RB_RESERVED indicates that the specified RBs are reserved for MCPTT services. RB reservation for MCPTT services cannot be used in cells with a bandwidth lower than 5 MHz. This value applies only to LTE FDD and LTE TDD. The value LNR_SPECTRUM_SHR_RB_RESERVED indicates that the specified RBs are reserved for LTE and NR spectrum sharing, and RBs are allocated for the LTE PUCCH starting from the start index and end index of the reserved RBs towards the center frequency of the cell. This value applies only to LTE FDD. The value COVERAGE_ENH_RB_RESERVED indicates that the specified RBs are reserved for UEs for which coverage enhancement takes effect. This function does not apply to scenarios where the bandwidth is less than 5 MHz. This value applies only to LTE FDD.

GUI Value Range: NB_RESERVED(NB_RESERVED), NB_DEPLOYMENT(NB_DEPLOYMENT), RB_MASKING(RB_MASKING), RB_MASKING_WITH_SRS(RB_MASKING_WITH_SRS), MCPTT_RB_RESERVED(MCPTT_RB_RESERVED), LNR_SPECTRUM_SHR_RB_RESERVED(LNR_SPECTRUM_SHR_RB_RESERVED), COVERAGE_ENH_RB_RESERVED(COVERAGE_ENH_RB_RESERVED)

Unit: None

Actual Value Range: NB_RESERVED, NB_DEPLOYMENT, RB_MASKING, RB_MASKING_WITH_SRS, MCPTT_RB_RESERVED, LNR_SPECTRUM_SHR_RB_RESERVED, COVERAGE_ENH_RB_RESERVED

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the RbRsvMode parameter in a CellRbReserve MO is set to COVERAGE_ENH_RB_RESERVED, the RbRsvType parameter in this CellRbReserve MO can only be set to UPLINK_MODE.
  • If the RbRsvMode of CellRbReserve is set to MCPTT_RB_RESERVED, the RbRsvType must be UPLINK_MODE.
  • If the RbRsvMode of CellRbReserve is set to LNR_SPECTRUM_SHR_RB_RESERVED, the RbRsvType must be UPLINK_MODE.
  • In a CellRbReserve MO, if the RbRsvMode parameter is set to COVERAGE_ENH_RB_RESERVED, the difference between the values of the RbRsvStartIndex and RbRsvEndIndex parameters must be equal to 1.
  • Under a Cell MO, the number of CellRbReserve MOs in which the RbRsvMode parameter is set to LNR_SPECTRUM_SHR_RB_RESERVED cannot exceed 1.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to RB_MASKING_WITH_SRS, the performance of uplink frequency selective scheduling and uplink link adaptation will be affected. If this parameter is set to MCPTT_RB_RESERVED, the interference on MCPTT services and the packet loss rate of MCPTT services decrease. However, the average rate of non-MCPTT services also decreases. If this parameter is set to COVERAGE_ENH_RB_RESERVED, the uplink coverage enhancement performance improves.

Applicable Mode: L
RbRsvType RB Reserve Type

Meaning: Indicates whether the PRBs to be reserved at the physical layer are uplink or downlink ones.

GUI Value Range: UPLINK_MODE(UPLINK_MODE), DOWNLINK_MODE(DOWNLINK_MODE)

Unit: None

Actual Value Range: UPLINK_MODE, DOWNLINK_MODE

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the RbRsvMode parameter in a CellRbReserve MO is set to COVERAGE_ENH_RB_RESERVED, the RbRsvType parameter in this CellRbReserve MO can only be set to UPLINK_MODE.
  • If the RbRsvMode of CellRbReserve is set to MCPTT_RB_RESERVED, the RbRsvType must be UPLINK_MODE.
  • If the RbRsvMode of CellRbReserve is set to LNR_SPECTRUM_SHR_RB_RESERVED, the RbRsvType must be UPLINK_MODE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
RbRsvStartIndex RB Reserve Start Index

Meaning: Indicates the index of the start PRB of the physical-layer reserved PRBs. The PRBs are numbered starting from 0 in sequence from low to high frequencies. For details, see 3GPP TS 36.211.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: When the cell bandwidth is 1.4 MHz, the parameter value range is 0 to 5.

When the cell bandwidth is 3 MHz, the parameter value range is 0 to 14. When the RbRsvMode parameter is set to NB_DEPLOYMENT, the RbRsvType parameter is set to DOWNLINK_MODE, and the Prb.AnchorCarrierFlag parameter of an NB-IoT carrier is set to TRUE, this parameter must be set to 2 or 12.

When the cell bandwidth is 5 MHz, the parameter value range is 0 to 24. When the RbRsvMode parameter is set to NB_DEPLOYMENT, the RbRsvType parameter is set to DOWNLINK_MODE, and the Prb.AnchorCarrierFlag parameter of an NB-IoT carrier is set to TRUE, this parameter must be set to 2, 7, 17, or 22.

When the cell bandwidth is 10 MHz, the parameter value range is 0 to 49. When the RbRsvMode parameter is set to NB_DEPLOYMENT, the RbRsvType parameter is set to DOWNLINK_MODE, and the Prb.AnchorCarrierFlag parameter of an NB-IoT carrier is set to TRUE, this parameter must be set to 4, 9, 14, 19, 30, 35, 40, or 45.

When the cell bandwidth is 15 MHz, the parameter value range is 0 to 74. When the RbRsvMode parameter is set to NB_DEPLOYMENT, the RbRsvType parameter is set to DOWNLINK_MODE, and the Prb.AnchorCarrierFlag parameter of an NB-IoT carrier is set to TRUE, this parameter must be set to 2, 7, 12, 17, 22, 27, 32, 42, 47, 52, 57, 62, 67, or 72.

When the cell bandwidth is 20 MHz, the parameter value range is 0 to 99. When the RbRsvMode parameter is set to NB_DEPLOYMENT, the RbRsvType parameter is set to DOWNLINK_MODE, and the Prb.AnchorCarrierFlag parameter of an NB-IoT carrier is set to TRUE, this parameter must be set to 4, 9, 14, 19, 24, 29, 34, 39, 44, 55, 60, 65, 70, 75, 80, 85, 90, or 95.

When the RbRsvMode parameter is set to NB_DEPLOYMENT or NB_RESERVED, the values of the RbRsvEndIndex and RbRsvStartIndex parameters must be the same. The two parameters can be set to different values if continuous RB blocking is supported.

When the RbRsvMode parameter is set to COVERAGE_ENH_RB_RESERVED, the difference between the values of the RbRsvEndIndex and RbRsvStartIndex parameters must be equal to 1.

Parameter Relationship:

-Configuration constraints:

  • In a CellRbReserve MO, the value of RbRsvStartIndex must be less than or equal to that of RbRsvEndIndex.
  • In a CellRbReserve MO, if the RbRsvMode parameter is set to COVERAGE_ENH_RB_RESERVED, the difference between the values of the RbRsvStartIndex and RbRsvEndIndex parameters must be equal to 1.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Use this command to add a cell RB Reserve configuration, with LocalCellId=10, Index=1, RbRsvMode=RB_MASKING, RbRsvType=UPLINK_MODE, RbRsvStartIndex=0, and RbRsvEndIndex=1:
ADD CELLRBRESERVE: LocalCellId=10, Index=1, RbRsvMode=RB_MASKING, RbRsvType=UPLINK_MODE, RbRsvStartIndex=0, RbRsvEndIndex=1;
