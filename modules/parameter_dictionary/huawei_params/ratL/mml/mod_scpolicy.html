Modify SC Policy (MOD SCPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the SC policy.

Note

None.

Parameters

ID Name Description
ScAlgoSwitch SC Algorithm Switch

Meaning: Indicates the general switch of the service classification (SC) algorithm. This parameter provides the following options:

SC_SERVICE_IDENTITY_SW: The eNodeB identifies services based on service characteristics only if this option is selected. This option applies only to LTE FDD and LTE TDD.

SC_MODULE_LOAD_SW: The eNodeB identifies and measures services of specified UEs when operators use end-to-end UE tracing only if this option is selected.

SC_DEFAULT_DNS_DISABLE_SW: If this option is selected, the default DNS does not take effect. If this option is deselected, the default DNS takes effect.

This option applies only to LTE FDD and LTE TDD.

SC_SUPPORT_IPV6_SW: If this option is selected, the SC module supports both the IPv6 and IPv4 protocols. Otherwise, the SC module supports only the IPv4 protocol. This option applies only to LTE FDD and LTE TDD.

LOW_LATENCY_QCI_SC_LOAD_SW: If this option is selected, the eNodeB loads service identification based on service characteristics for services of bearers with QCIs for which the LowLatencyFlag parameter in the CellQciPara is set to TRUE. In this case, the eNodeB identifies and measures these services. If this option is deselected, this function is disabled. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: SC_SERVICE_IDENTITY_SW(SC Service Identify Switch), SC_MODULE_LOAD_SW(SC Module Load Switch), SC_DEFAULT_DNS_DISABLE_SW(SC Default DNS Disable Switch), SC_SUPPORT_IPV6_SW(SC Support IPV6 Switch), LOW_LATENCY_QCI_SC_LOAD_SW(LOW Latency Qci Sc Load Switch)

Unit: None

Actual Value Range: SC_SERVICE_IDENTITY_SW, SC_MODULE_LOAD_SW, SC_DEFAULT_DNS_DISABLE_SW, SC_SUPPORT_IPV6_SW, LOW_LATENCY_QCI_SC_LOAD_SW

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VideoInitBufTime Video Initial Buffer Time

Meaning: Indicates the evaluation time of video initial caching. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 5s(5s), 10s(10s), 15s(15s), 20s(20s), 30s(30s), 2s(2s)

Unit: None

Actual Value Range: 5s, 10s, 15s, 20s, 30s, 2s

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VideoSynackToAckDelayThld Video SYN-ACK to ACK Delay Threshold

Meaning: Indicates the threshold of delays between SYN-ACK packets and ACK packets in the three-way handshake processes of video services. If the delay between a SYN-ACK packet and an ACK packet in the three-way handshake process of a video service in a cell exceeds the threshold, the L.Exp.Video.Time.SynackToAck.OverThld.Num counter is incremented by 1. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: ms

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of Service Classification policy with the parameters as follows: ScAlgoSwitch: SC_SERVICE_IDENTITY_SW-1, VideoInitBufTime: 10s, Video SYN-ACK to ACK Delay Threshold: 60ms, run the following command:
MOD SCPOLICY: ScAlgoSwitch=SC_SERVICE_IDENTITY_SW-1, VideoInitBufTime=10s, VideoSynackToAckDelayThld=60;
