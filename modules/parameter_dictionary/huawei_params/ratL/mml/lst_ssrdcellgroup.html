List Soft Split Cell Group Configuration (LST SSRDCELLGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of a specific or all soft split cell groups.

Note

None.

Parameters

ID Name Description
PrimaryLocalCellID Primary Local Cell ID

Meaning: Indicates the local cell ID of a primary cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under all SsrdCellGroup MOs, the PrimaryLocalCellID parameter and the SsrdLocalCellID parameter must be set to unique values.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SsrdLocalCellID Ssrd Local Cell ID

Meaning: Indicates the local cell ID of a split cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under all SsrdCellGroup MOs, the PrimaryLocalCellID parameter and the SsrdLocalCellID parameter must be set to unique values.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configuration of soft split cell groups, run the following command:
LST SSRDCELLGROUP:;
The result is shown as follows:
+++    HUAWEI        2015-07-21 16:34:11
O&M    #806355005
%%LST SSRDCELLGROUP:;%%
RETCODE = 0  Operation succeeded.

List Soft Split Cell Group Configuration
-------------------
Primary Local Cell ID  =  0
   Ssrd Local Cell ID  =  1
(Number of results = 1)


---    END

Output Description

Field Description

Primary Local Cell ID

Indicates the local cell ID of a primary cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Ssrd Local Cell ID

Indicates the local cell ID of a split cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.
