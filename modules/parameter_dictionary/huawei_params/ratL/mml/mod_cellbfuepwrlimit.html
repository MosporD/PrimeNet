Modify BF UE Power Limit Switch (MOD CELLBFUEPWRLIMIT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

This command is only used to modify the BfUePowerLimitSwitch parameter in MAE.

Note

Executing this command may cause the BF user power to be restricted.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BfUePowerLimitSwitch BF UE Power Limit Switch

Meaning: Indicates whether to enable power limit for beamforming UEs in a massive MIMO cell. If this parameter is set to ON, power limit for beamforming UEs in the massive MIMO cell is enabled. The eNodeB limits the power of beamforming UEs that participate in less-than-four-layer pairing or do not participate in pairing, and does not limit the power of beamforming UEs that participate in four-layer or more-than-four-layer pairing. If this parameter is set to OFF, power limit for beamforming UEs in the massive MIMO cell is disabled. This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON: (1) When there are less than four pairing layers or SU scheduling is performed in the massive MIMO cell, the power of beamforming UEs and downlink throughput decrease. (2) When there are four or more pairing layers in the massive MIMO cell, network performance is not affected. If this parameter is set to OFF, network performance is not affected.

Applicable Mode: L-TDD

Example

To modify the BF UE Power Limit Switch for the cell with an ID of 0, run the following commad:
MOD CELLBFUEPWRLIMIT: LocalCellId=0, BfUePowerLimitSwitch=ON;
