Modify X2 Configuration (MOD X2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters in an X2 MO.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Changing the control-plane end point group ID may lead to automatic X2 link reestablishment.

  • Changing the value of User Plane End Point Group ID for an X2 object may lead to service interruption.

  • Before changing the CN operator ID, ensure that the corresponding operator has been added.

  • Before changing the control-plane end point group ID, ensure that the corresponding end point group has been added.

  • Before changing the user-plane end point group ID, ensure that the corresponding end point group has been added.

  • The X2 self-setup is supported for the operator only after the CpEpGroupId parameter under the X2 MO for this operator is added.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in X2 or S1 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in X2 or S1 MOs cannot overlap.

  • If a local control-plane IP address is configured in an X2 MO of a specific operator (that is, the CpEpGroupId parameter in the X2 MO is configured), X2 self-setup in X2 over S1 or X2 over OSS mode can be triggered only during handovers of UEs served by the operator.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the X2 or ECO MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the X2 or ECO MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in X2 or EX2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in X2 or EX2 MOs cannot overlap.

  • The EPGROUP MO referenced by CpEpGroupId in an X2 MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an X2 MO and the EPGROUP MO referenced by the IUB or ABIS MO must be different.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the X2 MOs or the M2EpGroupId parameter in the M2 MOs cannot overlap.

  • If the value of the CnOpSharingGroupId parameter in an X2 MO is not set to the invalid value 255, ensure that the associated CnOpSharingGroup MO has been added before modifying the CnOpSharingGroupId parameter in the X2 MO and the operator to which the X2 MO belongs is in the carrier-sharing operator group. In hybrid RAN sharing mode, the CnOpSharingGroup MO referenced by the X2 MO must be configured and the CnOpSharingGroupId parameter must be set to a valid value.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the X2 MOs or the M1EpGroupId parameter in the M1 MOs cannot overlap.

  • In hybrid RAN sharing mode, after this command is executed to modify the carrier-sharing operator group ID, the eNodeB automatically sets up the X2 interfaces managed by this X2 MO. In other eNodeB sharing modes, the execution of this command has no impact on the radio network.

Example

To modify the configuration of an X2 MO with the parameters as follows: X2 ID: 0, End Point Config Flag: CP_CFG, Control Plane End Point Group ID: 124, run the following command:
MOD X2: X2Id=0, EpGroupCfgFlag=CP_CFG, CpEpGroupId=124;
