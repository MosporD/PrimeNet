List External CDMA2000HRPD Cell (LST CDMA2000HRPDEXTCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to the external CDMA2000 HRPD cell.

Note

None.

Parameters

ID Name Description
SectorId104 SectorID104

Meaning: Indicates the value for SectorID104 of the external CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 26 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3~28 characters

Unit: None

Actual Value Range: 3~28 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • SectorId104 in the Cdma2000HrpdExtCell MO must be set to a hexadecimal number starting with 0x and with a total length not greater than 26 digits. A hexadecimal number is composed of upper-case letters (A to F) and digits (0 to 9). The hexadecimal digit following 0x can be 0 only if the parameter is set to 0x0. That is, the parameter value like 0x00AB is inappropriate but 0x0 is acceptable.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

SectorID104

Indicates the value for SectorID104 of the external CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 26 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.

SectorID24

Indicates the value for SectorID24 of the external CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of six hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.

Band class

Indicates the band class on which the external CDMA2000 high rate packet data (HRPD) cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Frequency

Indicates the frequency on which the external CDMA2000 high rate packet data (HRPD) cell operates. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Mobile country code

Indicates the mobile country code (MCC) of the external CDMA2000 high rate packet data (HRPD) cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code (MNC) of the external CDMA2000 high rate packet data (HRPD) cell.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Physical cell ID

Indicates the pseudo noise (PN) sequence number of the external CDMA2000 high rate packet data (HRPD) cell. This number is used as the physical cell ID of the cell. For details, see C.S0005 PILOT_PN. This parameter applies only to LTE FDD and LTE TDD.

Cell name

Indicates the name of the external CDMA2000 HRPD cell. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.
