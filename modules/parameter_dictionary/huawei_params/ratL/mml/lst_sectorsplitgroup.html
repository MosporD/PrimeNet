List Configurations of Sector Splitting Groups (LST SECTORSPLITGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters for a sector splitting group.

Note

None.

Parameters

ID Name Description
SectorSplitGroupId Sector Split Group ID

Meaning: Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of a sector splitting group:
LST SECTORSPLITGROUP:;
The result is shown as follows:

Output Description

Field Description

Sector Split Group ID

Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

Beam Template ID

Indicates the beam template ID. This parameter needs to be set to 0 for 8T cells. This parameter applies only to LTE FDD and LTE TDD.

Beam Deployment Mode

Indicates the beam deployment mode for a multi-antenna cell. MODE_0 indicates that the number of outer-cell beams is the same as or one more than that of inner-cell beams. MODE_1 indicates that the number of outer-cell beams is two or three more than that of inner-cell beams. MODE_2 indicates that the number of outer-cell beams is four or five more than that of inner-cell beams. MODE_3 indicates smart 8T8R. NOT_CFG indicates that beams are not deployed. The difference between the numbers of outer-cell and inner-cell beams depends on the AAU type and the total number of selected beams. For details, see the related feature parameter description. The beam deployment mode can be set based on the distribution of UEs on the network to achieve even UE distribution in each beam. This helps increase the capacity and UE-perceived rates. This parameter applies to LTE FDD and LTE TDD.

Sector Split Switch

Indicates whether to enable functions related to sector split in massive MIMO scenarios.

MM_INTELLIGENT_BEAM_SHAPING_SW: Indicates whether to enable intelligent beam shaping in massive MIMO scenarios. Intelligent beam shaping in massive MIMO scenarios is enabled only if this option is selected. The PATTERN_ADJ_SWITCH and POWER_ADJ_SWITCH options are valid only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected. This option applies only to LTE FDD and LTE TDD.

PATTERN_ADJ_SWITCH: Indicates whether to adjust the pattern for intelligent beam shaping in massive MIMO scenarios. If UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the eNodeBResModeAlgo.ServiceMode parameter must also be selected for the pattern adjustment function to take effect. If this option is selected, the CellBeamAzimuth and CellBeamwidth parameters do not take effect, and the beam azimuth and beamwidth are adaptively adjusted based on UE distribution. If this option is deselected, the beam azimuth and horizontal 3 dB beamwidth are determined by the CellBeamAzimuth and CellBeamwidth parameters, respectively. This option applies only to LTE FDD.

POWER_ADJ_SWITCH: Indicates whether to enable power adjustment for intelligent beam shaping in massive MIMO scenarios. This option takes effect only when the TM4WeightScheme parameter is set to DEFAULT_MODE. If this option is selected, the traffic channel power is adjusted based on the principle of power usage maximization. If this option is deselected, the traffic channel power is not adjusted based on the principle of power usage maximization. This option applies only to LTE FDD.

PATTERN_ADJ_ENH_SWITCH: Indicates whether to enable enhanced pattern adjustment. If this option is selected, the pattern adjustment enhancement function is enabled. If this option is deselected, the pattern adjustment enhancement function is disabled. The PATTERN_ADJ_ENH_SWITCH option is valid only when both the MM_INTELLIGENT_BEAM_SHAPING_SW and PATTERN_ADJ_SWITCH options of this parameter are selected. This option applies only to LTE FDD.

POWER_ALLOCATION_SWITCH: Indicates whether to enable power allocation. If this option is selected, the PDSCHCfg.ReferenceSignalPwr parameter becomes invalid. Instead, the reference signal power is determined based on the cell power, which is specified by the SectorSplitCell.CellBeamPower parameter. The reference signal power can be queried by running the DSP MASSIVEMIMOPOWER command. If this option is deselected, power allocation is disabled. The POWER_ALLOCATION_SWITCH option takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter is selected. This option applies only to LTE FDD.

Massive MIMO Beam Azimuth Adjustment Step(degree)

Indicates the beam azimuth adjustment step used for smart beam adjustment in massive MIMO scenarios.

If this parameter is set to 0, only the beam width can be adjusted in smart beam adjustment in massive MIMO scenarios, and the beam azimuth cannot be adjusted. If this parameter is set to 60, the beam azimuth is adjusted based on the clustering result instead of being restricted by the adjustment step.

This parameter applies only to LTE FDD.

TM4 Weight Scheme

Indicates the scheme for setting the weight of TM4 in massive MIMO. The eNodeB sets the weight of TM4 based on the AAU type and coverage requirements. The value DEFAULT_MODE is applicable to common scenarios. When this parameter is set to DEFAULT_MODE, the CellBeamTilt parameter is valid. The value COVERAGE_MODE_1 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_1, the CellBeamTilt parameter is invalid if the CrsPortNum parameter is set to CRS_PORT_4 or is valid if CrsPortNum parameter is set to CRS_PORT_2. The value COVERAGE_MODE_2 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_2, the CellBeamTilt parameter is valid. This parameter applies only to LTE FDD.

Intelligent Beam Scheduling Switch

Indicates whether to enable algorithms related to intelligent beam scheduling.

JOINT_SCHEDULING_SWITCH: Indicates whether to enable joint scheduling for intelligent beam scheduling in massive MIMO scenarios. Joint scheduling is enabled for intelligent beam scheduling in massive MIMO scenarios only if this option is selected. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.

ENH_JOINT_SCHEDULING_SWITCH: Indicates whether to enable enhanced joint scheduling for intelligent beam scheduling in massive MIMO scenarios. When this option is selected, the enhanced joint scheduling is enabled. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.

Massive MIMO EMF Power Limit(0.01W)

Indicates the maximum transmit power that can be used by UEs in massive MIMO cells. This parameter is used to prevent UE transmit power from exceeding the EMF limit. If this parameter is set to 0, the maximum transmit power of UEs in massive MIMO cells is not restricted. If this parameter is set to a non-zero value, the maximum transmit power of UEs in massive MIMO cells cannot exceed the power value specified by this parameter. This parameter applies only to LTE FDD.

Massive MIMO Beam Scheme

Indicates the massive MIMO beam scheme. This parameter applies only to LTE FDD.

Power Sharing TM9 UE Max Pa Offset(0.1dB)

Indicates the offset relative to the maximum PA for the shared power received by TM9 UEs when intelligent beam scheduling is enabled. The actual maximum PA for the shared power received by TM9 UEs is the result of 90 minus the configured value. This parameter applies only to LTE FDD.

Beam Optimization PRB Usage Threshold(%)

Indicates the PRB usage threshold for triggering TM9 beam optimization. When the average PRB usage of the split sector group is higher than the threshold, TM9 beam optimization is enabled to reduce interference from TM9 beams to UEs using other beams and increase the average downlink UE throughput. This parameter applies only to LTE FDD.

Power Sharing High Load Threshold(%)

Indicates the load threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the PRB usage of a high-load cell exceeds this threshold, the condition for the sharing to take effect is met. If this parameter is set to 100, this power sharing algorithm does not take effect. This parameter applies only to LTE FDD.

Power Sharing Load Multiple Threshold

Indicates the load ratio threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the ratio of the load of a high-load cell to that of a low-load cell exceeds this threshold, the condition for the sharing to take effect is met. This parameter applies only to LTE FDD.
