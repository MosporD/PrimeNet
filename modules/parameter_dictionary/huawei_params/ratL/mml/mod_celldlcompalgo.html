Modify Dl Comp Algo (MOD CELLDLCOMPALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of downlink coordinated multi-point (CoMP).

Note

None.

Parameters

ID Name Description
LocalCellId LocalCellId

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlCompA3Offset DlCompA3Offset

Meaning: Indicates the offset for reporting the DL CoMP measurement event. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better quality for reporting the event. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship:

-Others:

  • This parameter is valid only when the DlCompSwitch parameter in the CellAlgoSwitch MO of the corresponding cell is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more UEs entering DL CoMP and smaller average DL throughput of DL CoMP UEs. If the value of this parameter is set to an excessively small value, the average DL throughput of the cell may experience negative gains. A larger value of this parameter results in less UEs entering DL CoMP and larger average DL throughput of DL CoMP UEs. If the value of this parameter is set to a value greater than the offset of event A3 used in handovers, UEs may be handed over rather than enter DL CoMP.

Applicable Mode: L-TDD
DpsCoCellUserRatioThd DPS Coordinating Cell User Ratio Threshold

Meaning: Indicates the threshold for the ratio of the number of uplink synchronized UEs in a dynamic point selection (DPS) serving cell to a DPS coordinating cell when DL CoMP is enabled. When the ratio of the number of uplink synchronized UEs in the coordinating cell (including those transferred to the coordinating cell) to that in the serving cell is smaller than this threshold, the coordinating cell can function as the target cell of DPS UEs. This parameter applies only to LTE FDD cells.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to more UEs in coordinating cells and smaller offload gains to the serving cell. A smaller value of this parameter leads to fewer UEs in coordinating cells and larger offload gains to the serving cell.

Applicable Mode: L-FDD
DpsLoadDiffThd DPS Load Difference Threshold

Meaning: Indicates the threshold of the difference between the PRB usage of a DPS serving cell and that of a DPS coordinating cell when DL CoMP is enabled. When the difference between the PRB usage of the serving cell and the coordinating cell exceeds this threshold, the coordinating cell can function as the target cell of DPS UEs. This parameter applies only to LTE FDD cells.

GUI Value Range: 0~50

Unit: %

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: 20

Parameter Relationship:

-Configuration constraints:

  • DpsServingCellDlPrbThd must be set to a value greater than or equal to the value of DpsLoadDiffThd in a CellDlCompAlgo MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter indicates that a large number of UEs can be transferred to the coordinating cell in a coordinating cell update period, significantly improving the system throughput. However, it is possible that the eNodeB cannot select a proper neighboring cell if the value is too large. A small value of this parameter indicates that a small number of UEs can be transferred to the coordinating cell in an update interval, and the system throughput does not improve significantly.

Applicable Mode: L-FDD
DpsServingCellDlPrbThd DPS Serving cell download PRB Threshold

Meaning: Indicates the threshold of the downlink PRB usage for a DPS serving cell when DL CoMP is enabled. When the PRB usage of a candidate cell exceeds this threshold, the cell can be selected as a DPS serving cell. This parameter applies only to LTE FDD cells.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 40

Parameter Relationship:

-Configuration constraints:

  • DpsServingCellDlPrbThd must be set to a value greater than or equal to the value of DpsLoadDiffThd in a CellDlCompAlgo MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter indicates that the threshold for selecting a DPS serving cell is low, increasing the probability of negative DPS gains. A large value of this parameter indicates that the threshold for selecting a DPS serving cell is high. If the parameter value is too large, DPS gains cannot be maximized.

Applicable Mode: L-FDD
HetnetDpsCoCellRsrpThd HetNet DPS Coordinating Cell RSRP Threshold

Meaning: Indicates the RSRP offset threshold for DPS UEs in selecting a coordinating cell in a HetNet. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of DPS UEs selecting a coordinating cell in a HetNet. A small value of this parameter indicates a large number of DPS UEs selecting a coordinating cell in a HetNet. This parameter applies only to LTE FDD cells.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter indicates that a large number of DPS UEs are transferred from the serving cell to a coordinating cell in a HetNet, lowering the average downlink throughput of such UEs. A large value of this parameter indicates that a small number of DPS UEs are transferred from the serving cell to a coordinating cell in a HetNet.

Applicable Mode: L-FDD
HomnetDpsCoCellRsrpThd HomNet DPS Coordinating Cell RSRP Threshold

Meaning: Indicates the RSRP offset threshold for DPS UEs in selecting a coordinating cell in a HomNet. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of DPS UEs selecting a coordinating cell in a HomNet. A small value of this parameter indicates a large number of DPS UEs selecting a coordinating cell in a HomNet. This parameter applies only to LTE FDD cells.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter indicates that a large number of DPS UEs are transferred from the serving cell to a coordinating cell in a HomNet, lowering the average downlink throughput of such UEs. A large value of this parameter indicates that a small number of DPS UEs are transferred from the serving cell to a coordinating cell in a HomNet.

Applicable Mode: L-FDD
JtCoCellDlPrbThd JT Coordinating Cell DL PRB Threshold

Meaning: Indicates the threshold of the downlink PRB usage for selecting a candidate cell as a coordinating cell when DL CoMP is enabled. When the PRB usage of a candidate cell is lower than this threshold, the cell can be selected as a coordinating cell for joint transmission. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 20

Parameter Relationship:

-Configuration constraints:

  • JtServingCellDlPrbThd must be set to a value greater than or equal to the value of JtCoCellDlPrbThd in a CellDlCompAlgo MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter indicates a high threshold for a cell to be selected as a coordinating cell for JT. In this case, JT gains cannot be maximized. A large value of this parameter indicates a low threshold for a cell to be selected as a coordinating cell for JT. In this case, the probability of negative JT impacts is high.

Applicable Mode: L-FDD
JtCoCellRsrpThd JT Coordinating Cell RSRP Threshold

Meaning: Indicates the RSRP offset threshold for joint transmission UEs in selecting a coordinating cell. A large value of this parameter indicates a high requirement on neighboring cell quality for reporting measurement events and a small number of joint transmission UEs. A small value of this parameter indicates a large number of joint transmission UEs. This parameter applies only to LTE FDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more UEs to perform joint transmission and smaller average downlink throughput of joint transmission UEs. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
JtServingCellDlPrbThd JT Serving Cell DL PRB Threshold

Meaning: Indicates the threshold of the downlink PRB usage for a serving cell for joint transmission when DL CoMP is enabled. When the PRB usage of a candidate cell is smaller than this threshold, the cell can be selected as a serving cell for joint transmission. This parameter applies only to LTE FDD cells.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship:

-Configuration constraints:

  • JtServingCellDlPrbThd must be set to a value greater than or equal to the value of JtCoCellDlPrbThd in a CellDlCompAlgo MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A small value of this parameter indicates that the threshold for selecting a serving cell for joint transmission is low, reducing the number of cells for joint transmission. In this case, joint transmission gains decrease. A large value of this parameter indicates that the threshold for selecting a serving cell for joint transmission is high, increasing joint transmission interference and interference to neighboring cells. In this case, the system throughput is affected.

Applicable Mode: L-FDD
DlCompSchPriFactor DL CoMP Scheduling Priority Factor

Meaning: Indicates the scheduling priority for DL CoMP UEs. This parameter takes effect only for downlink non-GBR services of DL CoMP UEs. This parameter applies only to LTE FDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more scheduling opportunities for DL CoMP UEs and a larger increase in the downlink rates of DL CoMP UEs. However, this results in fewer scheduling opportunities for common UEs and lower downlink rates of common UEs. If this parameter is set to 1, the service rates of DL CoMP UEs are not preferentially guaranteed.

Applicable Mode: L-FDD
DlCompReportInterval DL CoMP Report Interval

Meaning: Indicates the interval at which TM9- or TM10-capable UEs periodically send A3 or A6 measurement reports when at least one of DL CoMP with TM 10 and joint transmission with TM9 takes effect. For details about the reporting interval, see 3GPP TS 36.331. If this parameter is set to OFF, the A3 or A6 reporting interval is the same as the reporting interval (specified by the ReportInterval parameter in the CellMcPara MO) of common event A3 or A6. This parameter applies only to LTE FDD.

GUI Value Range: 120MS(120MS), 240MS(240MS), 480MS(480MS), 640MS(640MS), 1024MS(1024MS), 2048MS(2048MS), 5120MS(5120MS), 10240MS(10240MS), 1MIN(1MIN), 6MIN(6MIN), 12MIN(12MIN), 30MIN(30MIN), 60MIN(60MIN), OFF(OFF)

Unit: None

Actual Value Range: 120MS, 240MS, 480MS, 640MS, 1024MS, 2048MS, 5120MS, 10240MS, 1MIN, 6MIN, 12MIN, 30MIN, 60MIN, OFF

MML Default Value: None

Recommended Value: 1024ms

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in less frequent DL CoMP UE measurement reporting and a lower capability of tracking the changes in the geographic positions of DL CoMP UEs, decreasing the average throughput of cell edge UEs. A smaller value of this parameter results in more frequent DL CoMP UE measurement reporting and a higher capability of tracking the changes in the geographic positions of DL CoMP UEs, increasing the average throughput of cell edge UEs but increasing the UE power consumption.

Applicable Mode: L-FDD

Example

To modify the downlink CoMP algorithm with DlCompA3Offset set to -12 for the cell with Local cell identity of 0, run the following command:
MOD CELLDLCOMPALGO: LocalCellId=0, DlCompA3Offset=-12;
