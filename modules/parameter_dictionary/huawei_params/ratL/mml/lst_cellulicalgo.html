List Uplink IC Algorithm (LST CELLULICALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the uplink interference cancellation (IC) algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Uplink IC Algorithm:
LST CELLULICALGO:;
The result is shown as follows:
+++    0        2019-12-05 15:43:33
O&M    #806355237
%%LST CELLULICALGO: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List Ul IC Algo
---------------
         Local Cell ID  =  1
UL IC A3 Offset(0.5dB)  =  -20
         SRS IC Switch  =  MASSIVE_MIMO_SRS_IC_SW:Off
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

UL IC A3 Offset(0.5dB)

Indicates the A3 offset for interference cancellation (IC) event A3, that is, the A3 offset of the neighboring cell's signal quality to the serving cell. A larger value indicates that a neighboring cell must have better signal quality for reporting the event. This parameter applies only to LTE FDD.

SRS IC Switch

Indicates whether to enable the SRS IC algorithm for a cell.

MASSIVE_MIMO_SRS_IC_SW: If this option is selected, the SRS IC algorithm for massive MIMO is enabled. If this option is deselected, the SRS IC algorithm for massive MIMO is disabled. This option applies only to LTE TDD.
