Display RRN software (DSP EURRNSOFTWARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list an RRN.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list an EURRN  with the parameters as follows :LocalSubscriberId:10;
run the following command:
DSP EURRNSOFTWARE: LocalSubscriberId=10;
The result is shown as follows:

Output Description

Field Description

Storage Area

Indicates the area where the software is stored. This parameter applies only to LTE FDD and LTE TDD.

Software Version

Indicates the RRN software version. This parameter applies only to LTE FDD and LTE TDD.

Software Status

Indicates the software status, which can be available or unavailable. This parameter applies only to LTE FDD and LTE TDD.

Active Time

Indicates the time when the software is activated. This parameter applies only to LTE FDD and LTE TDD.
