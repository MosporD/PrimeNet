Display Cell Uplink Synchronization Check Result (DSP CELLHLHCHK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the uplink synchronization check results of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the uplink synchronization check results of a cell, run the following command:
DSP CELLHLHCHK: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Cell Check Time

Indicates the health check time of the cell. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the ID of the eNodeB.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

RX Channel No.

Indicates information about the RX channel of a cell.

Fault Unit Type

Indicates the type of the faulty unit. This parameter applies only to LTE FDD and LTE TDD.

Fault Unit Info

Indicates the cabinet, subrack, slot, and port of the faulty unit. This parameter applies only to LTE FDD and LTE TDD.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
