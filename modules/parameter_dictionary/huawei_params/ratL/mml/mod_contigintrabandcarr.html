Modify Parameters for Zero Guard Band Between Contiguous Intra-Band Carriers (MOD CONTIGINTRABANDCARR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-level parameters related to the Zero Guard Band Between Contiguous Intra-Band Carriers feature.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ContigIntraBandCarrSw Contiguous Intra-Band Carriers Switch

Meaning: Indicates whether to enable the algorithms related to the Zero Guard Band Between Contiguous Intra-Band Carriers feature.

CONTIG_INTRA_BAND_CARR_SW: If this option is selected, Zero Guard Band Between Contiguous Intra-Band Carriers is enabled. Multiple LTE carriers can be deployed in such a way that these carriers overlap. When the spectrum resources of two cells overlap, the overlapping spectrum resources can be used by both cells. If this option is deselected, Zero Guard Band Between Contiguous Intra-Band Carriers is disabled. This option applies only to LTE FDD and LTE TDD.

GUARDBAND_COMPACT_SW: If this option is selected, the guard band compression function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is enabled, allowing guard bands that do not overlap with other spectrum resources to be compressed. The center frequency of the cell can be re-configured to obtain more RBs. If this option is deselected, the guard band compression function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is disabled. This option applies only to LTE FDD.

POWER_RAISE_SW: If this option is selected, the power increase function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is enabled, allowing UEs to increase power. If this option is deselected, the power increase function of the Zero Guard Band Between Contiguous Intra-Band Carriers feature is disabled. This option applies only to LTE FDD.

LOW_QUALITY_RB_SCH_SW: If this option is selected, low-quality RBs cannot be allocated. If this option is deselected, low-quality RBs can be allocated. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: CONTIG_INTRA_BAND_CARR_SW(CONTIG_INTRA_BAND_CARR_SW), GUARDBAND_COMPACT_SW(GUARDBAND_COMPACT_SW), POWER_RAISE_SW(POWER_RAISE_SW), LOW_QUALITY_RB_SCH_SW(LOW_QUALITY_RB_SCH_SW)

Unit: None

Actual Value Range: CONTIG_INTRA_BAND_CARR_SW, GUARDBAND_COMPACT_SW, POWER_RAISE_SW, LOW_QUALITY_RB_SCH_SW

MML Default Value: None

Recommended Value: CONTIG_INTRA_BAND_CARR_SW: Off

GUARDBAND_COMPACT_SW: Off

POWER_RAISE_SW: Off

LOW_QUALITY_RB_SCH_SW: Off

Parameter Relationship:

-Configuration constraints:

  • The GUARDBAND_COMPACT_SW option of the ContigIntraBandCarrSw parameter in a ContigIntraBandCarr MO can be selected only if the CONTIG_INTRA_BAND_CARR_SW option of the same parameter is selected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: CONTIG_INTRA_BAND_CARR_SW: If this option is selected, the network capacity and average UE throughput increase. If this option is deselected, the network capacity and average UE throughput are not affected.

GUARDBAND_COMPACT_SW: If this option is selected, the network capacity and average UE throughput increase. If this option is deselected, there is no increase in the network capacity and average UE throughput.

POWER_RAISE_SW: If this option is selected, UE throughput increases. If this option is deselected, UE throughput is not affected.

LOW_QUALITY_RB_SCH_SW: If this option is selected, the BLER decreases in the cell where there are low-quality RBs, but the number of available RBs decreases. If this option is deselected, there is no impact on the BLER and the number of available RBs.

Applicable Mode: L-FDD, L-TDD
FixedExclusiveResRate Fixed Exclusive Resource Rate

Meaning: Indicates the proportion of resources that are always exclusively used in a cell to the total resources in the cell. If this parameter is set to 80, 80% of the resources in the cell are always exclusively used. If this parameter is set to 100, all resources in the cell are always exclusively used, that is, resources in the cell are not shared. If this parameter is set to 255, the proportion does not take effect. This parameter applies only to LTE FDD.

GUI Value Range: 80~100,255

Unit: %

Actual Value Range: 80~100,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller network capacity and lower average UE throughput. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD

Example

To modify configurations for contiguous intra-Band carriers, Local Cell ID is 0: CONTIG_INTRA_BAND_CARR_SW of Contiguous Intra-Band Carriers Switch to ON, run the following command:
MOD CONTIGINTRABANDCARR: LocalCellId=0, ContigIntraBandCarrSw=CONTIG_INTRA_BAND_CARR_SW-1;
