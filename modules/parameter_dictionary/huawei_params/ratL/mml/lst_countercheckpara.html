List Counter Check Configuration (LST COUNTERCHECKPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to counter check.

Note

None.

Parameters

None.

Example

List Counter Check Configuration:
LST COUNTERCHECKPARA:;
The result is shown as follows:
+++    0        2019-12-05 08:55:07
O&M    #806355182
%%LST COUNTERCHECKPARA:;%%
RETCODE = 0  Operation succeeded.

List Counter Check Configuration
--------------------------------
           Counter check timer(s)  =  0
       Counter check count number  =  0
Counter check user Release switch  =  Off
(Number of results = 1)


---    END

Output Description

Field Description

Counter check timer(s)

Indicates the length of the counter check timer. When the timer expires, a counter check procedure is initiated. After the procedure is complete, the timer is restarted. A length of 0 indicates that the timer is invalid. In this case, the eNodeB cannot initiate periodic counter check procedures. This parameter applies only to LTE FDD and LTE TDD.

Counter check count number

Indicates the COUNT value for initiating counter check procedures. When the COUNT value (used at the PDCP layer) of any DRB for a UE is a multiple of the value of this parameter, the eNodeB initiates a counter check procedure. The value 0 indicates that the eNodeB does not initiate a counter check procedure based on the COUNT value. This parameter applies only to LTE FDD and LTE TDD.

Counter check user Release switch

Indicates whether to release a DRB when the counter check detects an unexpected result in the DRB. This parameter applies only to LTE FDD and LTE TDD.
