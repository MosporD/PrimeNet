Modify Neighboring Cell Optimization Parameters for Blind Handovers (MOD BLINDNCELLOPT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to neighbor cell optimization for blind handovers.

Note

None.

Parameters

ID Name Description
StatisticPeriod Statistic Period

Meaning: Indicates the statistic period for blind neighboring cell optimization. Information about CSFB-triggered measurement-based handovers or CSFB-triggered blind handovers is collected within the statistic period, and suggestions on blind neighboring cell optimization are exported or automatically executed after the statistic period. The statistic period is seven days by default. It is recommended that this parameter be set to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~50400

Unit: min

Actual Value Range: 1~50400

MML Default Value: None

Recommended Value: 10080

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SampleNumThd Sample Number Threshold

Meaning: Indicates the sampling number threshold of handovers from an E-UTRAN cell to neighboring cells. During the planning of neighboring cells for blind handovers, if the number of CSFB-triggered measurement-based handover attempts from the E-UTRAN cell to neighboring cells working at a frequency (or frequency group) within a measurement period is greater than this parameter value, neighboring cells working at the frequency (or frequency group) can be selected as candidate cells in blind handovers. In blind neighboring cell optimization, if the number of blind handover attempts from the E-UTRAN cell to a neighboring cell that has been selected as a candidate cell in blind handovers within a measurement period is greater than this parameter value, this neighboring cell can remain as a candidate cell in blind handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000000

Unit: None

Actual Value Range: 1~1000000

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
HoSuccRateThd Handover Success Ratio Threshold

Meaning: Indicates the outgoing handover success rate threshold for determining whether a neighboring cell can be selected as a candidate cell in blind handovers. If the success rate of measurement-based handovers for a UE from an E-UTRAN cell to a neighboring cell is greater than or equal to this parameter value within a measurement period, the neighboring cell can be selected as a candidate cell in blind handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 98

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CsfbHoAttempRatioThd CSFB Handover Attemption Ratio Threshold

Meaning: Indicates the CSFB-triggered measurement-based handover attempt ratio threshold for determining whether a neighboring cell can be selected as a candidate cell in blind handovers. In a measurement period, the ratio of the CSFB-triggered measurement-based handover attempts from an E-UTRAN cell to a neighboring cell to all CSFB-triggered measurement-based handover attempts from the E-UTRAN cell to all neighboring cells working on the corresponding frequency (or frequency group) is measured. If the ratio is greater than or equal to this threshold, the neighboring cell can be selected as a candidate cell in blind handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 98

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BlindHoSuccRateThd Blind Handover Success Ratio Threshold

Meaning: Indicates the blind handover success rate threshold for determining whether a neighboring cell selected as a candidate cell in blind handovers can remain as a candidate cell in blind handovers. If the blind handover success rate of handing over a UE from an E-UTRAN cell to the neighboring cell that has been selected as a candidate cell in blind handovers is less than or equal to this parameter value within a measurement period, the neighboring cell cannot remain as a candidate cell in blind handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 98

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
OptMode Optimization Mode

Meaning: Indicates the mode of blind-handover priority optimization. If this parameter is set to FREE, the eNodeB automatically changes the blind-handover priorities for neighboring cells. If this parameter is set to CONTROLLED, the eNodeB does not automatically change the blind-handover priorities for neighboring cells but reports the optimization suggestions on blind-handover priorities for neighboring cells to the MAE for user confirmation. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: FREE(FREE), CONTROLLED(CONTROLLED)

Unit: None

Actual Value Range: FREE, CONTROLLED

MML Default Value: None

Recommended Value: CONTROLLED(CONTROLLED)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set the Statistic Period to 1 minutes, run the following command:
MOD BLINDNCELLOPT: StatisticPeriod=1;
