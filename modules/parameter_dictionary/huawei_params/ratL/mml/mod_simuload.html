Modify configuration of eNodeB simulated load configuration (MOD SIMULOAD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the simulated load configuration.

Note

None.

Parameters

ID Name Description
SimuLoadCfgIndex configuration index

Meaning: Indicates the index of a simulated load configuration. One BS can store 10 simulated load configurations, which are identified by the indexes.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SimuLoadRbThd RB usage threshold

Meaning: Indicates the RB usage threshold of a simulated load configuration. If the RB usage of a cell is below this threshold, the simulated load scheduling is performed.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

SimuLoadCfgIndex 0: SimuLoadRbThd 10

SimuLoadCfgIndex 1: SimuLoadRbThd 20

SimuLoadCfgIndex 2: SimuLoadRbThd 30

SimuLoadCfgIndex 3: SimuLoadRbThd 40

SimuLoadCfgIndex 4: SimuLoadRbThd 50

SimuLoadCfgIndex 5: SimuLoadRbThd 60

SimuLoadCfgIndex 6: SimuLoadRbThd 70

SimuLoadCfgIndex 7: SimuLoadRbThd 80

SimuLoadCfgIndex 8: SimuLoadRbThd 90

SimuLoadCfgIndex 9: SimuLoadRbThd 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SimuLoadPwrThd Power usage threshold

Meaning: Indicates the power usage threshold of a simulated load configuration. If the power usage of a cell is below this threshold, the simulated load scheduling is performed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

SimuLoadCfgIndex 0: SimuLoadPwrThd 10

SimuLoadCfgIndex 1: SimuLoadPwrThd 20

SimuLoadCfgIndex 2: SimuLoadPwrThd 30

SimuLoadCfgIndex 3: SimuLoadPwrThd 40

SimuLoadCfgIndex 4: SimuLoadPwrThd 50

SimuLoadCfgIndex 5: SimuLoadPwrThd 60

SimuLoadCfgIndex 6: SimuLoadPwrThd 70

SimuLoadCfgIndex 7: SimuLoadPwrThd 80

SimuLoadCfgIndex 8: SimuLoadPwrThd 90

SimuLoadCfgIndex 9: SimuLoadPwrThd 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SimuLoadReportPeriod Report period

Meaning: Indicates the reporting period for simulated load. The value 0 indicates that simulated load is not reported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50000

Unit: ms

Actual Value Range: 0~50000

MML Default Value: None

Recommended Value: 500

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SimuLoadStatPeriod Statistic period

Meaning: Indicates the measurement period for simulated load. The value 0 indicates that simulated load is not measured. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50000

Unit: ms

Actual Value Range: 0~50000

MML Default Value: None

Recommended Value: 5000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FreqSelSwitch Frequency selective switch

Meaning: Indicates the switch that is used to determine whether to enable and disable the frequency-selective scheduling in simulated load configuration. If the switch is set to ON, the frequency-selective scheduling is enabled. If the switch is set to OFF, the frequency-diversity scheduling is used. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the load simulation configuration with the parameters as follows: configuration index: 0, RB usage threshold: 11, Power usage threshold: 11, run the following command:
MOD SIMULOAD: SimuLoadCfgIndex=0, SimuLoadRbThd=11, SimuLoadPwrThd=11;
