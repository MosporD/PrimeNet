List TCP MSS Control Algorithm Parameter (LST TCPMSSCTRL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the TCP MSS control algorithm.

Note

None.

Parameters

None.

Example

To list the configuration of the TCP MSS control algorithm, run the following command: :
LST TCPMSSCTRL:;
The result is shown as follows:
+++    0        2019-12-05 17:39:35
O&M    #806356230
%%LST TCPMSSCTRL: ;%%
RETCODE = 0  Operation succeeded.

List TCP MSS Control Algorithm Parameter
----------------------------------------
 TCP MSS Control Switch  =  Off
TCP MSS Threshold(byte)  =  1460
(Number of results = 1)


---    END

Output Description

Field Description

TCP MSS Control Switch

Indicates the switch used to enable or disable the TCP MSS function. If this switch is turned off, TCP packets are transparently transmitted without being processed. If this switch is turned on, the value of the MSS field in each packet for TCP link setups can be modified. This parameter applies only to LTE FDD and LTE TDD.

TCP MSS Threshold(byte)

Indicates the threshold for the value of the MSS field in packets for TCP link setups. If the TCP MSS function is enabled, the eNodeB first checks the MSS field in each packet for TCP link setups. If the value of the MSS field is greater than the predefined threshold, the eNodeB changes the value of the MSS field to the predefined threshold. Then, the eNodeB recalculates the TCP checksum and retransmits the packet with modified fields. For other packets, the eNodeB transparently transmits them.
