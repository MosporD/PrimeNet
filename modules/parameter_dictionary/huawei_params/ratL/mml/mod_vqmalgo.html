Modify Voice Quality Monitoring Algorithm Parameter (MOD VQMALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify voice quality monitoring (VQM) algorithm parameters.

Note

Before parameters related to the VQM algorithm are modified by running this command, ensure that the VQM switch has been turned on.

Parameters

ID Name Description
ULDelayJitter UL Delay Jitter

Meaning: Indicates the maximum UL voice packet delay variation allowed on the Uu interface. If the actual delay variation of a UL voice packet exceeds this limit, this packet is regarded as lost during the evaluation of voice quality indicator (VQI). The delay variation is measured at the eNodeB PDCP layer. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~255

Unit: ms

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The validity of this parameter depends on the setting of the VQMAlgoSwitch parameter, the default value of which is VQM_ALGO_SWITCH_OFF. The parameter setting takes effect only when the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON or VQM_ALGO_SWITCH_ADAPTIVE_ON. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON or VQM_ALGO_SWITCH_ADAPTIVE_ON, a larger value of the ULDelayJitter parameter increases the proportion of uplink voice services with good voice quality and decreases the proportion of uplink voice services with poor voice quality. The ULDelayJitter parameter does not apply to UEs not running voice services and has no impact on such UEs.

Applicable Mode: L-FDD, L-TDD
VqiGoodThd VQI Good Threshold

Meaning: Indicates the voice quality indicator (VQI) threshold for determining the voice quality is good. If the VQI evaluation value is greater than the VqiGoodThd parameter value and less than or equal to the VqiExcellentThd parameter value, the voice quality is considered as good. If the VQI evaluation value is less than or equal to the VqiGoodThd parameter value and greater than the VqiPoorThd parameter value, the voice quality is considered as accepted. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~500

Unit: None

Actual Value Range: 0~5, step: 0.01

MML Default Value: None

Recommended Value: 300

Parameter Relationship:

-Configuration constraints:

  • In the VQMAlgo MO, VqiExcellentThd must be larger than VqiGoodThd.
  • In the VQMAlgo MO, VqiGoodThd must be larger than VqiPoorThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VqiPoorThd VQI Poor Threshold

Meaning: Indicates the voice quality indicator (VQI) threshold for determining the voice quality is poor. If the VQI evaluation value is greater than the VqiBadThd parameter value and less than or equal to the VqiPoorThd parameter value, the voice quality is considered as poor. If the VQI evaluation value is less than or equal to the VqiGoodThd parameter value and greater than the VqiPoorThd parameter value, the voice quality is considered as accepted. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~500

Unit: None

Actual Value Range: 0~5, step: 0.01

MML Default Value: None

Recommended Value: 200

Parameter Relationship:

-Configuration constraints:

  • In the VQMAlgo MO, VqiGoodThd must be larger than VqiPoorThd.
  • In the VQMAlgo MO, VqiPoorThd must be larger than VqiBadThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VqiBadThd VQI Bad Threshold

Meaning: Indicates the voice quality indicator (VQI) threshold equal to or below which the voice quality is considered as bad. This parameter applies only to LTE FDD and LTE TDD.

AmrWbRadioLowQualRelThd Release Threshold of Radio Low Quality for Amr Wideband

Meaning: Indicates the threshold of the packet loss rate over the air interface for normally releasing AMR-WB and EVS voice services. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_AMR_ON and the uplink or downlink packet loss rate of AMR-WB UEs over the air interface exceeds this threshold, the eNodeB considers that AMR-WB UEs release calls due to poor voice quality. If the VQMAlgoSwitch parameter in the ENodeBAlgoSwitch MO is set to VQM_ALGO_SWITCH_ADAPTIVE_ON and the uplink or downlink packet loss rate of AMR-WB and EVS UEs over the air interface exceeds this threshold, the eNodeB considers that AMR-WB and EVS UEs release calls due to poor voice quality. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The validity of this parameter depends on the setting of the VQMAlgoSwitch parameter, the default value of which is VQM_ALGO_SWITCH_OFF.

If the VQMAlgoSwitch parameter is set to VQM_ALGO_SWITCH_AMR_ON, a larger value of the AmrWbRadioLowQualRelThd parameter decreases the number of times that AMR-WB voice services are released by UEs due to poor voice quality over the air interface. A smaller value of the AmrWbRadioLowQualRelThd parameter results in the opposite effects.

If the VQMAlgoSwitch parameter is set to VQM_ALGO_SWITCH_ADAPTIVE_ON, a larger value of the AmrWbRadioLowQualRelThd parameter decreases the number of times that AMR-WB and EVS voice services are released by UEs due to poor voice quality over the air interface. A smaller value of the AmrWbRadioLowQualRelThd parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

AmrSilentPeriodNum Period Number of Silent for Amr

Meaning: Indicates the number of periods that is used to evaluate whether a voice service is muted due to poor voice quality. If an AMR or EVS voice service performed by a UE is muted in consecutive periods specified by this parameter, voice mute is regarded to occur during communication. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 2

A smaller value of the AmrSilentPeriodNum parameter results in the opposite effects.

Meaning: Indicates the VQM evaluation period. During VQM-based voice quality evaluation, voice quality is evaluated and a score is exported periodically. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2DOT5(2.5), 5(5), 10(10)

Actual Value Range: 2DOT5, 5, 10

MML Default Value: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VoiceCallSetupDelayThld Voice Call Setup Delay Threshold

Meaning: Indicates the threshold for determining abnormal voice call setup delay. If the voice call setup delay (the duration between the INVITE message and the 180RINGING message) is greater than this threshold, an SIP exception event will be recorded in the internal CHR. If the voice call setup delay is less than or equal to this threshold, no SIP exception event will be recorded in the internal CHR. If this parameter is set to 0, the eNodeB does not check whether there are delay exceptions or record SIP exception events in the internal CHR. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30000

Unit: ms

Actual Value Range: 0~30000

MML Default Value: None

Recommended Value: When the resource reservation procedure is enabled on the IMS side, the recommended value is 5000. When the resource reservation procedure is disabled on the IMS side, the recommended value is 3000.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To change the value of UL Delay Jitter to 50, run the following command:
MOD VQMALGO: ULDelayJitter=50;
