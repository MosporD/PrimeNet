Modify eNodeB MBMS Parameter (MOD MBMSPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify eNodeB MBMS parameter.

Note

None.

Parameters

ID Name Description
SyncPeriod Synchronisation Period

Meaning: Indicates the synchronization period of the SYNC protocol. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~58

Unit: 10240ms

Actual Value Range: 10240~593920

MML Default Value: None

Recommended Value: 58

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbmsCtrlSwitch MBMS Control Switch

Meaning: Indicates the switches to control eNodeB-level MBMS services. This parameter provides the following options:

SessionForMultiMASwitch: A single MBMS session can be broadcasted in multiple MBSFN areas in an eNodeB only if this option is selected. This option applies only to LTE FDD and LTE TDD.

M2DisconnProtectSwitch: Indicates whether to delete eMBMS sessions on the eNodeB with time delays after the M2 interface is interrupted. If this option is selected, eMBMS sessions on the eNodeB are deleted with a time delay after the M2 interface is interrupted. Otherwise, eMBMS sessions are immediately deleted in this situation. This option applies only to LTE FDD and LTE TDD.

SyncPduCompatibilitySwitch: Indicates whether the M1 interface complies with the R13 SYNC protocol. The switch setting must be consistent with that in the SYNC protocol version of the BMSC. If this option is selected, SYNC PDU counting does not include SYNC PDU headers. If this option is deselected, SYNC PDU counting includes SYNC PDU headers. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: SessionForMultiMASwitch(Session For Multi MA Switch), M2DisconnProtectSwitch(M2 Disconnect Protect Switch), SyncPduCompatibilitySwitch(SyncPduCompatibilitySwitch)

Unit: None

Actual Value Range: SessionForMultiMASwitch, M2DisconnProtectSwitch, SyncPduCompatibilitySwitch

MML Default Value: None

Recommended Value: SessionForMultiMASwitch:Off, M2DisconnProtectSwitch:Off, SyncPduCompatibilitySwitch:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the SessionForMultiMASwitch option is selected, a single MBMS session can be broadcasted in multiple MBSFN areas, which increases the system processing load and degrades the maximum BBP throughput.

Applicable Mode: L-FDD, L-TDD
M2DisconnProtectTime M2 Interface Disconnect Protect Time

Meaning: Indicates the delay after which the eNodeB deletes MBMS sessions if the M2 interface is interrupted. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1440

Unit: min

Actual Value Range: 1~1440

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: The parameter value must approach the duration in which MBMS services are not affected after the M2 interface is interrupted. If the value is too large, MBMS sessions may not be deleted in a timely manner, wasting system resources. If the value is too small, MBMS sessions may be deleted when the MBMS services are still normal. This affects user experience.

Applicable Mode: L-FDD, L-TDD

Example

To change the synchronization period to 20, run the following command:
MOD MBMSPARA: SyncPeriod=20;
