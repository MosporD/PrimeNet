List eNodeB Algorithm Extend Switch Settings (LST ENODEBALGOEXTSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of eNodeB-level algorithm extend switches.

Note

None.

Parameters

None.

Example

List eNodeB Algorithm Extend Switch Settings:
LST ENODEBALGOEXTSWITCH:;

Output Description

Field Description

Extended QCI Mapping Index

Indicates the standardized QCI that maps the extended-QCI bearers set up by the EPC without the QCIs configured on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

X2 SON Delete gNodeB Addition Count Threshold

Indicates the threshold of the number of SgNB additions for automatically removing X2 interfaces based on NSA X2 usage. If the measured number of successful SgNB additions corresponding to an X2 interface within a timer length is less than or equal to this threshold and no NSA UEs use the X2 interface, automatic removal of this X2 interface is triggered. This parameter applies only to LTE FDD and LTE TDD.

X2 SON Delete Timer for LTE-NR X2 Fault(min)

Indicates the length of the timer for automatically removing LTE-NR X2 interfaces based on X2 faults.

When this timer is set to 0, the function of automatically removing of LTE-NR X2 interfaces based on X2 faults does not take effect.

When this timer is set to another value, this function takes effect. If an X2 interface is faulty throughout the period specified by this timer, the eNodeB automatically removes the X2 interface.

This parameter applies only to LTE FDD and LTE TDD.

X2 SON Delete Timer for LTE-NR X2 Usage(min)

Indicates the length of the timer for automatically removing LTE-NR X2 interfaces based on X2 usage.

When this timer is set to 0, the function of automatically removing of LTE-NR X2 interfaces based on X2 usage does not take effect.

When this timer is set to another value, this function takes effect. If the measured number of successful SgNB additions corresponding to an LTE-NR X2 interface within the timer length is less than or equal to a specified threshold and no NSA UEs perform services over the X2 interface, automatic removal of this LTE-NR X2 interface is triggered.

This parameter applies only to LTE FDD and LTE TDD.

IP Entry Detection Interval

Indicates the interval at which the eNodeB checks whether a UE is accessing a specified IP address. The eNodeB parses the IP header of a downlink packet of the UE every N packets (N is the value of this parameter). If the specified IP address is detected in the IP header, the eNodeB considers that the UE is accessing the IP address. This parameter applies only to LTE FDD and LTE TDD.

IP Exit Detection Times

Indicates the number of times the eNodeB fails to detect a specified IP address for a UE before the eNodeB can determine that the UE has stopped accessing the IP address. If the eNodeB fails to detect the specified IP address in the IP headers of downlink packets of the UE for N consecutive times (N is the value of this parameter), the eNodeB considers that the UE has stopped accessing the IP address. This parameter applies only to LTE FDD and LTE TDD.

Protocol Compatibility Extended Switch

Indicates whether the eNodeB applies compatibility handling to the protocol-defined procedures. This parameter provides the following options:

S1_HO_REQ_UE_CONFIG_REL_OPT_SW: Indicates whether to apply compatibility handling to the IE ue-ConfigRelease-r9 contained in an eNodeB-initiated S1-based handover request message. If this option is selected, the IE ue-ConfigRelease-r9 is contained in the message based on the actual configuration. If this option is deselected, the maximum value of the IE cannot exceed Rel13. This option applies only to LTE FDD and LTE TDD.

RRC_REEST_FULL_CONFIG_SW: Indicates whether to enable full configuration for RRC connection reconfiguration. If this option is selected, the eNodeB can configure the IE fullconfig-r9 in the first RRC reconfiguration message after RRC connection reestablishment. If this option is deselected, the eNodeB does not configure the IE fullconfig-r9 in the first RRC reconfiguration message after RRC connection reestablishment. This option applies only to LTE FDD and LTE TDD.

Connection to 5G CN Configuration

Indicates switches that control the function of LTE connecting to the 5G Core Network (5GC). CONNECTION_TO_5G_CN_SWITCH: If this option is selected, the eNodeB supports a connection to the 5GC and allows UEs to access the 5GC and perform basic calling procedures. If this option is deselected, the eNodeB does not support the connection to 5GC or allow UEs to access the 5GC. This option applies only to LTE FDD and LTE TDD.

NSA DC Algorithm Switch

Indicates whether to enable eNodeB-level NSA DC algorithms.

EUTRA_PDCP_CONFIG_OPT_SW: Indicates whether an NSA DC UE is configured with an RLC/PDCP parameter group that is used for NSA DC services (specified by the NsaDcRlcPdcpParamGroupId parameter in a QciPara MO) or an RLC/PDCP parameter group that is used for LTE services (specified by the RlcPdcpParaGroupId parameter in a QciPara MO) when the eNodeB configures the E-UTRA PDCP for the NSA DC UE. If this option is selected, the NSA DC UE is configured with an LTE RLC/PDCP parameter group. If this option is deselected, the NSA DC UE is configured with an NSA DC RLC/PDCP parameter group. This option applies only to LTE FDD and LTE TDD.

RELEASE_NR_WITH_LTE_SW: Indicates whether to enable simultaneous release of LTE and NR bearers. If this option is selected, the eNodeB releases both the LTE and NR bearers for a UE when receiving an SGNB RELEASE REQUIRED message with the cause value "Improve user bit rate". If this option is deselected, the eNodeB releases only the NR bearers for the UE when receiving an SGNB RELEASE REQUIRED message. This option applies only to LTE FDD and LTE TDD.

UM_DRB_INTRA_CELL_HO_SW: Indicates whether to trigger an intra-cell handover procedure in specific scenarios. Assume that a UE is moving, its connection mode is changed from NSA Option 3x or SCG-terminated MCG bearer to LTE only, and the UE has split service bearers in UM. If this option is selected, an intra-cell handover procedure is triggered after the connection mode is changed to LTE only. If this option is deselected, an intra-cell handover procedure does not need to be triggered after the connection mode is changed to LTE only. This option applies only to LTE FDD and LTE TDD.

UE_ENDC_CAPB_ENQUIRY_OPT_SW: Indicates whether to optimize the UE E-UTRA-NR DC capability query. If this option is deselected, the eNodeB queries the E-UTRA-NR DC capability of a UE when the UE accesses a cell served by the eNodeB as long as the NSA_DC_CAPABILITY_SWITCH or NSA_PCC_ANCHORING_SWITCH option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter is selected for any one cell served by the eNodeB. If this option is selected, the eNodeB queries the E-UTRA-NR DC capability of the UE only in case that either of the preceding options is selected for the cell that the UE accesses. This option applies only to LTE FDD and LTE TDD.

NSA Protocol Compatibility Switch

Indicates whether to apply compatibility solutions to protocol-defined NSA-DC-related procedures. This parameter provides the following options:

X2_HO_COMPATIBILITY_SW: Indicates whether to apply a compatibility solution to NSA-DC-capable UEs during X2-based handovers. If this option is selected, the compatibility solution takes effect for NSA-DC-capable UEs during X2-based handovers. The eNodeB removes the NSA-related IEs from messages sent to Huawei early-version eNodeBs that do not support protocol-defined NSA-related IEs. If this option is deselected, the compatibility solution does not take effect for NSA-DC-capable UEs during X2-based handovers. This option applies only to LTE FDD and LTE TDD.

S1_HO_COMPATIBILITY_SW: Indicates whether to apply a compatibility solution to NSA-DC-capable UEs during S1-based handovers. If this option is selected, the compatibility solution takes effect for NSA-DC-capable UEs during S1-based handovers. Local NSA configurations are forcibly removed through intra-cell handovers during outgoing handovers of these UEs. If this option is deselected, the compatibility solution does not take effect. This option applies only to LTE FDD and LTE TDD.

NR_EN_DC_CAPB_FILTERING_RPT_SW: Indicates whether the eNodeB filters out the NR and EN-DC capabilities of UEs when reporting UE capabilities. If this option is selected, the eNodeB reports the NR and EN-DC capabilities of UEs to the core network. If this option is deselected, the eNodeB does not report these capabilities. This option applies only to LTE FDD and LTE TDD.

MR_MDT_MC_UNIFIED_SCH_MEAS_SW: Indicates whether to deliver measurement configurations related to inter-frequency/inter-RAT MR/MDT and periodic measurement configurations related to multi-carrier unified scheduling for NSA DC UEs. If this option is selected, these measurement configurations can be delivered to NSA DC UEs. If this option is deselected, these measurement configurations cannot be delivered to NSA DC UEs. This option applies only to LTE FDD and LTE TDD.

X2_HO_ENH_COMPATIBILITY_SW: Indicates whether to apply an enhanced compatibility solution to NSA-DC-capable UEs during X2-based handovers. If this option is selected, the enhanced compatibility solution takes effect for NSA-DC-capable UEs during X2-based handovers. The eNodeB proactively removes NSA-related IEs during handovers involving non-Huawei eNodeBs. If this option is deselected, this solution does not take effect. This option applies only to LTE FDD and LTE TDD.

SMTC_CONFIG_SW: Indicates whether the eNodeB includes the SMTC configurations of NR carriers in reconfiguration messages used for NR SCC addition. If this option is selected, the eNodeB includes the SMTC configurations in the messages. If option is deselected, the eNodeB does not include the SMTC configurations in the messages. This option applies only to LTE FDD and LTE TDD.

NR_SCG_FAST_ADDITION_SW: Indicates whether to initiate a fast NR SCG addition procedure after an SCG failure. If this option is selected, the eNodeB initiates a fast NR SCG addition procedure after receiving an SCGFailureInformationNR message from an NSA UE. It directly sends an RRC connection reconfiguration message that contains a new SCC addition IE (nr-Config-r15) or NR carrier measurement configurations. If this option is deselected, the eNodeB only releases the NR SCG after receiving the SCGFailureInformationNR message from the NSA UE. This option applies only to LTE FDD and LTE TDD.

HO_WITH_SCG_RENEGOTIATION_SW: Indicates whether to support LTE SCC renegotiation during handovers with SCG addition. If this option is selected, renegotiation is supported. When the LTE band combinations configured on the eNodeB are inconsistent with the band combinations returned by the gNodeB, the eNodeB can reselect LTE SCCs based on the band combinations returned by the gNodeB and deliver the configurations in handover commands. If this option is deselected, the eNodeB proactively removes all LTE SCCs during handovers when the LTE band combinations configured on the eNodeB are inconsistent with the band combinations returned by the gNodeB. After handovers, SCC reselection can be triggered based on the traffic volume. This option applies only to LTE FDD and LTE TDD.

HO_WITH_SCG_CONFIG_IND_SW: Indicates whether to carry an SCG configuration indication during an outgoing handover. Assume that an SCG is configured on the source side. If this option is selected, the as-ConfigNR-v1570 IE is carried during an X2- or S1-based outgoing handover; if this option is deselected, the as-ConfigNR-v1570 IE is not carried. This option applies only to LTE FDD and LTE TDD.

PCC_ANCHORING_HO_OPT_SW: Indicates whether to optimize the handover policy for NSA DC PCC anchoring. Assume that handovers triggered for NSA DC PCC anchoring are enabled. If this option is deselected and an X2 interface is configured between the source and target base stations, the source base station checks whether the target base station supports NSA through the X2 interface. If the target base station does not support NSA, handovers triggered for NSA DC PCC anchoring are not executed. Otherwise, such handovers are executed. If this option is selected, handovers triggered for NSA DC PCC anchoring are executed unconditionally. This option applies only to LTE FDD and LTE TDD.

NR_NB_INFO_BASED_NSA_CAPB_SW: Indicates whether the local eNodeB determines the NSA capability of the peer eNodeB based on the IE "NR Neighbour Information" carried in an X2 message. Assume that the peer eNodeB is an intra-vendor eNodeB. If this option is selected, there are the following situations: The local eNodeB determines that the peer eNodeB supports NSA if the X2 message contains the "NR Neighbour Information" IE; otherwise, the local eNodeB determines that the peer eNodeB does not support NSA. If this option is deselected, the local eNodeB determines that the peer eNodeB supports NSA. This option is valid only if the PCC_ANCHORING_SMART_DEPLOY_SW option of the NsaDcAlgoParam.NsaDcAlgoSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.

NR_GAP_S1_HO_COMPATIBILITY_SW: Indicates whether to apply the compatibility solution to NSA-capable or SA-capable UEs performing gap-assisted measurements during S1-based handovers. If this option is selected, the S1-based handover compatibility solution takes effect for UEs that have started gap-assisted measurements and are configured with the IE "measGapSharingConfig-r14", "fr1-Gap-r15", or "mgta-r15". Gap-related configurations are forcibly removed through intra-cell handovers during outgoing handovers of these UEs. If this option is deselected, the S1-based handover compatibility solution does not take effect. This option applies only to LTE FDD and LTE TDD.

NR SCG Release Protection Timer(ms)

Indicates the length of the protection timer for NR SCG release. This timer controls a duration from the time proactive NR SCG release is triggered for a UE upon VoLTE service setup to the time the eNodeB executes the release. The eNodeB can initiate the NR SCG release procedure only after the timer expires. This parameter applies only to LTE FDD and LTE TDD.

NR SCG Blind Config Protection Timer(ms)

Indicates the length of the protection timer for blind NR SCG configuration. This timer controls the wait time after which blind NR SCG configuration can be initiated for UEs that have accessed or been handed over to any cell served by the eNodeB. The eNodeB can initiate the blind NR SCG configuration procedure only after the timer expires. This parameter applies only to LTE FDD and LTE TDD.

X2 NSA Counter Period

Indicates the length of an X2-based NSA service performance measurement period. You can run the DSP X2INTERFACE command to query the measurement results.

NR SCG Inactivity Release Strategy

Indicates the policy for the eNodeB to release an NR SCG after receiving an SgNB Activity Notification message that indicates the inactive state from a gNodeB.

If this parameter is set to REL_UPON_LTE_INACTVTY_TMR_EXPN, the eNodeB releases both the UE and NR SCG after it receives the message and the UE inactivity timer on the LTE side expires.

If this parameter is set to INSTANT_RELEASE, the eNodeB releases the NR SCG immediately after receiving the message.

If this parameter is set to NO_ACTIVITY_NOTIFICATION_REQ, the eNodeB does not require the gNodeB to send the SgNB Activity Notification message to it. The eNodeB does not determine whether to release the NR SCG based on the SgNB Activity Notification message, but proactively request the NR SCG release based on the service status of the NR SCG.

This parameter applies only to LTE FDD and LTE TDD.

Waiting NSA DC UE PDCP Status Report Timer(ms)

Indicates the length of the timer that governs the period in which the base station waits for a PDCP status report from an NSA-DC-capable UE. This parameter applies only to LTE FDD and LTE TDD.

Multi Networking Option Opt Switch

Indicates whether to enable optimizations in scenarios with multiple networking options.

NSA_DC_SA_NR_HO_B1_NO_GAP_SW: Indicates whether to enable non-gap-assisted B1 measurement related to inter-RAT handovers to NG RAN in SA networking for NSA DC UEs. This function is enabled only if this option is selected. This option applies only to LTE FDD and LTE TDD.

NR_CALIB_AVOIDANCE_SW: Indicates whether to enable avoidance of services during NR channel calibration in non-gap positions. If this option is selected, services are not allowed to be performed during NR channel calibration in non-gap positions. If this option is deselected, services are allowed to be performed during NR channel calibration in non-gap positions. This option applies only to LTE TDD.

Manual Cell Deactivation Counter Rsv Sw

Indicates whether to retain the measurement set for a cell after the cell is manually deactivated. If this parameter is set to OFF, the measurement set for a cell will be removed after the cell is manually deactivated. If this parameter is set to ON, the measurement set for a cell will be retained after the cell is manually deactivated. In addition, the duration of cell unavailability due to manual deactivation will be measured in the L.Cell.Unavail.Dur.Manual or L.NB.Cell.Unavail.Dur.Manual counter and subtracted from the value of the L.Cell.Avail.Dur or L.NB.Cell.Avail.Dur counter.

gNodeB X2 Initial Fail Delete Switch

Indicates whether LTE-NR X2 automatic removal takes effect when an initial X2 self-setup procedure fails. If this parameter is set to ON, LTE-NR X2 automatic removal takes effect when an initial X2 self-setup procedure fails. If this parameter is set to OFF, LTE-NR X2 automatic removal does not take effect when an initial X2 self-setup procedure fails.

If this parameter is set to ON, an eNodeB automatically removes an LTE-NR X2 interface when detecting a consistently faulty SCTP link referenced by an initial self-setup X2 interface. Then, the eNodeB adds information of the local and peer base stations of the X2 interface to the dynamic X2 blacklist. When a new base station is deployed or the network is tuned, the transport network may not be stable. It is recommended that this parameter be set to ON in this situation. When the transport network becomes stable, it is recommended that this parameter be set to OFF. This parameter applies only to LTE FDD and LTE TDD.

gNodeB X2 Dynamic Blacklist Aging Timer(min)

Indicates the aging time of dynamic LTE-NR X2 blacklists that are automatically generated. When the aging time is reached, dynamic X2 blacklists automatically become invalid. This parameter applies only to LTE FDD and LTE TDD.

Handover to NR Algo Switch

Indicates the eNodeB-level switches for algorithms of interoperability with NR.

SPID_BASED_HO_BACK_TO_HPLMN_SW: Indicates whether to allow SPID-based handovers back to HPLMN NG-RAN. If this option is selected, a roaming UE can be handed over back to its HPLMN NG-RAN based on its SPID when the UE moves back to the coverage of the NG-RAN. If this option is deselected, this function does not take effect. This option applies only to LTE FDD and LTE TDD.

Network Performance Optimization Switch

Indicates whether to enable network performance optimization functions.

EX2_AUTO_SETUP_FC_OPT_SW: Indicates whether to enable eX2 self-setup flow control optimization. If this option is selected, the peer eNodeB uses a new message code to send an eX2 self-setup response message during an eX2 self-setup procedure, and the OSS does not perform flow control over the eX2 self-setup response message. If this option is deselected, the peer eNodeB uses the original message code to send an eX2 self-setup response message, and the OSS performs flow control over the eX2 self-setup response message when the OSS is overloaded. This option applies only to LTE FDD and LTE TDD.

Max Rate of PDCP HO Trans(100Mbps)

Indicates the maximum rate at which PDCP data is forwarded during inter-eNodeB handovers. If this parameter is set to 65535, it does not take effect and PDCP data is forwarded at the default rate. It is recommended that this parameter be set to a value less than or equal to the maximum rate allowed by the physical transmission bandwidth of the link. Otherwise, packet loss may occur in the forwarded data during handovers. This parameter applies only to LTE FDD and LTE TDD.

LTE to NR PLMN Selection Mode

Indicates the PLMN filling mode in LTE-to-NR procedures, including LTE-to-NR handovers and EN-DC X2 self-setup in NSA networking.

If this parameter is set to PRIMARY_PLMN_ID, the primary PLMN of the target NR cell is filled in. If this parameter is set to SELECTED_PLMN_ID, the PLMN selected by the UE in the target NR cell is filled in. If this parameter is set to HYBRID_PLMN_ID, the PLMN to be filled in depends on the cell identities corresponding to different PLMNs for the same NR cell. If different PLMNs correspond to different cell identifies, the PLMN selected by the UE is filled in. If different PLMNs correspond to the same cell identify, the primary PLMN of the cell is filled in. If a neighboring gNodeB's PLMN selection policy (specified by the NbrGnodeBPolicy.LteToNrPlmnSelectionMode parameter) has been configured, the configuration prevails. This parameter applies only to LTE FDD and LTE TDD.
