List Cell CSI-RS Configuration (LST CELLCSIRSPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query parameters related to CSI-RS configuration in the cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query parameters related to CSI-RS configuration with the local cell ID of 1, run the following command:
LST CELLCSIRSPARACFG: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Switch

Indicates whether to configure CSI-RSs for UEs. If this parameter is set to NOT_CFG(Not configure), the eNodeB does not configure CSI-RSs for UEs. If this parameter is set to FIXED_CFG(Fixed configure), the eNodeB configures CSI-RSs for UEs that support CSI-RSs. If this parameter is set to ADAPTIVE_CFG(ADAPTIVE_CFG), the eNodeB determines whether to configure CSI-RSs for UEs that support CSI-RSs based on the proportion of TM9 UEs. When SfnLoadBasedAdptSwitch is deselected in a TDD cell with adaptive SFN enabled, neither FIXED_CFG nor ADAPTIVE_CFG takes effect. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Period

Indicates the channel state information (CSI) reference signal (RS) measurement period. This parameter does not take effect if the FddTddInd parameter in the Cell MO is set to CELL_TDD, the TM9HybridPrecodingSwitch option of the EnhMIMOSwitch parameter in the CellAlgoSwitch MO is selected, and the CsiRsPortNum parameter in the CellCsiRsParaCfg MO is set to CSI_RS_PORT_8. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Config User Number Threshold

Indicates the threshold, which is the number of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state when adaptive CSI-RS configuration is used. The number must be equal to or larger than this threshold for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Unconfig User Number Threshold

Indicates the threshold, which is the number of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state when adaptive CSI-RS configuration is adopted. The number must be smaller than this threshold for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Config User Ratio Threshold(%)

Indicates the threshold, which is the proportion of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state when adaptive CSI-RS configuration is adopted. The proportion must be equal to or larger than this threshold for determining a change from the CSI-RS unconfigured state to the CSI-RS configured state. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Unconfig User Ratio Threshold(%)

Indicates the threshold, which is the proportion of RRC_CONNECTED UEs supporting CSI-RSs, for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state when adaptive CSI-RS configuration is adopted. The proportion must be equal to or smaller than this threshold for determining a change from the CSI-RS configured state to the CSI-RS unconfigured state. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Set Judge Hysteresis Timer(s)

Indicates whether to trigger the hysteresis timer for a switch to the CSI-RS unconfigured state for UEs in the CSI-RS state when adaptive CSI-RS configuration is adopted. The timer is triggered when a UE enters the CSI-RS configured state and the decision mechanism for a switch to the CSI-RS unconfigured state is triggered after the timer expires. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Set Judge Timer(s)

Indicates the length of the timer for determining a switch between the CSI-RS unconfigured state and the CSI-RS configured state when adaptive CSI-RS configuration is adopted. This parameter applies only to LTE FDD and LTE TDD.

CsiRs Port Number

Indicates the number of CSI-RS ports. This parameter applies only to LTE TDD.

CSI-RS Adaptive Beam Count

Indicates the number of CSI-RS beams during CSI-RS beam adaptation. If this parameter is set to ADAPTIVE_BEAM_DISABLED, CSI-RS beam adaptation is disabled. If this parameter is set to a value other than ADAPTIVE_BEAM_DISABLED, the number in the value indicates the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation. For example, if this parameter is set to CSI_RS_BEAM_5, the maximum number of CSI-RS beams that can be configured during CSI-RS beam adaptation is 5. This parameter applies only to LTE FDD.
