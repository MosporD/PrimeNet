Display Neighboring Cells in a UL CS Coordination Set (DSP ULCSNCELLINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about the neighboring UL CS cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To query information about neighboring cells in the UL CS coordination set:
DSP ULCSNCELLINFO:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

SFN Cell Indicator

Indicates whether a local cell is an SFN cell. This parameter applies only to LTE FDD.

Macro Cell Indicator

Indicates whether the local cell involved in uplink coordinated scheduling (CS) is a macro cell. This parameter applies only to LTE FDD.

Neighbour Cell eNodeB ID

Indicates the ID of the eNodeB serving a neighboring cell in the UL CS coordination set. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD.

Neighbour Cell ID

Indicates the local ID of a neighboring cell in the UL CS coordination set, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD.

Neighbour Cell SFN Cell Indicator

Indicates whether a neighboring cell in the UL CS coordination set is an SFN cell. This parameter applies only to LTE FDD.

Neighbour Cell Macro Cell Indicator

Indicates whether a neighboring cell in the UL CS coordination set is a macro cell. This parameter applies only to LTE FDD.

Round Trip Transmission Delay(0.1us)

Indicates the average round trip time of a link. This parameter applies only to LTE FDD.

Neighbour Cell UL CS Relation Indicator

Indicates the specific UL CS function for which neighboring cells are grouped into a UL CS coordination set. This parameter applies only to LTE FDD.
