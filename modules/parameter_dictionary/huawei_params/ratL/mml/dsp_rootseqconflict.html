Display eNodeB Sequence Conflict Information (DSP ROOTSEQCONFLICT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about the PRACH root sequence conflict between neighboring cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query information about eNodeB root sequence conflicts:
DSP ROOTSEQCONFLICT:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

Conflict Cell Mobile Country Code

Indicates the MCC of a conflict cell. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two to three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Conflict Cell Mobile Network Code

Indicates the MNC of a conflict cell. A PLMN ID is composed of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two to three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Conflict eNodeB ID

Indicates the eNodeB ID of a conflict cell located in the same PLMN as the local cell. A local cell ID and an eNodeB ID compose a 28-bit E-UTRAN cell ID, where the eNodeB ID is represented by the 20 most significant bits. An E-UTRAN cell ID and a PLMN ID compose an E-UTRAN CGI (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

Conflict Cell ID

Indicates the ID of the cell that conflicts with the local cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell identity is comprised of the cell ID in the most significant eight bits and the eNodeB ID. The E-UTRAN cell identity and the PLMN ID form the E-UTRAN cell global identifier (ECGI). For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
