Download external device software (DLD EXTSOFTWARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to download external device software to the NE from the server.

Note

None.

Example

To download external device software with the parameters as follows: LocalSubscriber ID:10, FTP server IP:"192.168.0.1", USR:"admin", Pass Word:"*****", DIR:"D:\stdio", EXTDEVTYPE:RRN3901, Software Version="V100R010C00B043";
DLD EXTSOFTWARE: LocalSubscriberId=10, IP="192.168.0.1", USR="admin", PWD="*****", DIR="D:\stdio", EXTDEVTYPE=RRN3901, SV="V100R010C00B043";
