List RbcaFwdCount Parameters (LST RBCAFWDCOUNTPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of a set of parameters related to the index of performance counters measuring the amount of data forwarded in relaxed-backhaul-based CA.

Note

None.

Parameters

ID Name Description
FwdCounterIndex Forward Counter Index

Meaning: Indicates the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List RbcaFwdCountPara:
LST RBCAFWDCOUNTPARA:;
The result is shown as follows:
+++    0        2015-11-05 16:38:27
O&M    #806354989
%%LST RBCAFWDCOUNTPARA:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Forward Counter Index

Indicates the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

PCC Mobile Country Code

Indicates the mobile country code of the PCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

PCC Mobile Network Code

Indicates the mobile network code of the PCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

SCC Mobile Country Code

Indicates the mobile country code of the SCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

SCC Mobile Network Code

Indicates the mobile network code of the SCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.
