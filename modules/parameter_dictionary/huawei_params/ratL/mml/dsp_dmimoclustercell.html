Display D-MIMO Cluster Cell (DSP DMIMOCLUSTERCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the status of cells in D-MIMO clusters.

Note

None.

Parameters

ID Name Description
DMIMOClusterId D-MIMO Cluster Id

Meaning: Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

To query the status of cells in a D-MIMO cluster, run the following command: :
DSP DMIMOCLUSTERCELL:;
The result is shown as follows:
+++    0        2018-11-06 10:17:38
O&M    #806354968

       Mobile Network Code  =  610
                   Cell Id  =  120
D-MIMO Cluster Cell Status  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

D-MIMO Cluster Id

Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

Cell Id

Indicates the unique ID of a cell. The 28-bit E-UTRAN cell identity is comprised of the cell ID (represented by the least significant 8 bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD cells.

eNodeB Id

Indicates the ID of an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD.

Mobile Country Code

Indicates the MCC of a D-MIMO cluster cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE TDD.

Mobile Network Code

Indicates the MNC of a D-MIMO cluster cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE TDD.

D-MIMO Cluster Cell Status

Indicates the status of a D-MIMO cluster and the reason why a D-MIMO cluster fails to take effect. This parameter applies only to LTE TDD.
