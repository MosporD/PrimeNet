List Cell DACQ Parameter Configuration (LST CELLDACQPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the DACQ parameter configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of DACQ of a cell:
LST CELLDACQPARACFG:;

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

Downlink AMBR Limit First Rank(bps)

Indicates the level-1 threshold of the downlink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Downlink AMBR Limit Second Rank(bps)

Indicates the level-2 threshold of the downlink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Uplink AMBR Limit First Rank(bps)

Indicates the level-1 threshold of the uplink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Uplink AMBR Limit Second Rank(bps)

Indicates the level-2 threshold of the uplink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Downlink PRB Usage First Rank(%)

Indicates the level-1 threshold of the downlink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Downlink PRB Usage Second Rank(%)

Indicates the level-2 threshold of the downlink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Uplink PRB Usage First Rank(%)

Indicates the level-1 threshold of the uplink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Uplink PRB Usage Second Rank(%)

Indicates the level-2 threshold of the uplink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

DACQ Execution Duration(s)

Indicates the duration of performing dynamic AMBR control by QCI (DACQ) after congestion is detected. This parameter applies only to LTE FDD and LTE TDD.

DACQ Congestion Monitor Duration(s)

Indicates the duration of monitoring the number of UEs in the cell and RB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

AMBR Limited User Number Threshold

Indicates the threshold of the number of AMBR-limited UEs in the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

AMBR Protected User Number Threshold

Indicates the threshold of the number of AMBR-protected UEs in the cell for performing dynamic AMBR control by QCI (DACQ). This parameter applies only to LTE FDD and LTE TDD.

Downlink AMBR Limit Third Rank(bps)

Indicates the level-3 threshold of the downlink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter takes effect only when enhanced DACQ is enabled. This parameter applies only to LTE FDD and LTE TDD.

Downlink PRB Usage Third Rank(%)

Indicates the level-3 threshold of the downlink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter takes effect only when enhanced DACQ is enabled. This parameter applies only to LTE FDD and LTE TDD.

Uplink AMBR Limit Third Rank(bps)

Indicates the level-3 threshold of the uplink AMBR used for dynamic AMBR control by QCI (DACQ). This parameter takes effect only when enhanced DACQ is enabled. This parameter applies only to LTE FDD and LTE TDD.

Uplink PRB Usage Third Rank(%)

Indicates the level-3 threshold of the uplink PRB usage of the cell for performing dynamic AMBR control by QCI (DACQ). This parameter takes effect only when enhanced DACQ is enabled. This parameter applies only to LTE FDD and LTE TDD.

MBB UE Experienced Rate Percentage Target Thld(%)

Indicates the threshold used to determine whether to perform MBB-user-experience-based DACQ. This threshold is the minimum target percentage of the MBB-user-perceived rates that reach a satisfactory level over a period. This parameter applies only to LTE FDD and LTE TDD.

If this parameter is set to 100, MBB-user-experience-based DACQ does not take effect, and the eNodeB uses the original DACQ feature to determine whether to restrict the rates of WBB UEs. If this parameter is set to 0, the eNodeB restricts the rates of WBB UEs only when no MBB-user-perceived rate reaches the target threshold of MBB-user-perceived rates in a monitoring period.

MBB UE Experienced Rate Target Threshold(Mbps)

Indicates the target threshold of MBB-user-experienced rates. This threshold is the minimum MBB-user-perceived rate that reaches a satisfactory level. This parameter applies only to LTE FDD and LTE TDD.
