List MME Domain Name (LST MMEDOMAINNAME)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of an MME domain name.

Note

None.

Parameters

ID Name Description
MMEDomNameId MME Domain Name ID

Meaning: Indicates the index of the MME domain name.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

%%LST MMEDOMAINNAME:;%%
RETCODE = 0  Operation succeeded.

List MME Domain Name
--------------------
MME Domain Name ID  =  0
    CN Operator ID  =  0
   MME Domain Name  =  test.3gpp.org
(Number of results = 1)


---    END

Output Description

Field Description

MME Domain Name ID

Indicates the index of the MME domain name.

CN Operator ID

Indicates the ID of the operator.

MME Domain Name

Indicates the domain name of an MME or an MME pool. If MMEs are configured as an MME pool, you are advised to specify the domain name of the MME pool to simplify the configuration.
