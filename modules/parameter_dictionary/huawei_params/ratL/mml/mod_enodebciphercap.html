Modify eNodeB Ciphering Algorithm Priority (MOD ENODEBCIPHERCAP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the priorities of the eNodeB ciphering algorithms.

Note

None.

Parameters

ID Name Description
PrimaryCipherAlgo Primary cipher algorithm

Meaning: Indicates the highest-priority ciphering algorithm for the eNodeB. If this parameter is set to NULL, ciphering is not used. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm.

GUI Value Range: NULL(NULL Algorithm), Snow3G(SNOW 3G Algorithm), AES(AES Algorithm), ZUC(ZUC Algorithm), NOT_CFG(NOT_CFG)

Unit: None

Actual Value Range: NULL, Snow3G, AES, ZUC, NOT_CFG

MML Default Value: None

Recommended Value: AES(AES Algorithm)

Parameter Relationship:

-Configuration constraints:

  • In the ENodeBCipherCap MO, the PrimaryCipherAlgo, SecondCipherAlgo, ThirdCipherAlgo, and FourthCipherAlgo parameters must be set to different values except NOT_CFG.
  • Not all the PrimaryCipherAlgo, SecondCipherAlgo, ThirdCipherAlgo, and FourthCipherAlgo parameters in the ENodeBCipherCap MO are set to NOT_CFG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm. If the ciphering algorithm list that the eNodeB supports and ciphering algorithms that the UE supports have no intersection, the security mode configuration fails for the UE, resulting in an E-RAB setup failure or handover failure.

Applicable Mode: L

Example

To modify the priorities of the eNodeB ciphering algorithms with the parameters as follows: PrimaryCipherAlg: AES, SecondCipherAlg: ZUC, ThirdCipherAlg: Snow3G, FourthCipherAlg: NULL, run the following command:
MOD ENODEBCIPHERCAP: PrimaryCipherAlgo=AES, SecondCipherAlgo=ZUC, ThirdCipherAlgo=Snow3G, FourthCipherAlgo=NULL;
