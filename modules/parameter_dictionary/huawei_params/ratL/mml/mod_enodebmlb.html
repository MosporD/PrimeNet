Modify eNodeB MLB Configuration (MOD ENODEBMLB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameter settings for eNodeB-level load balancing.

Note

None.

Parameters

ID Name Description
InterFreqIdleMlbMode Inter Frequency Idle MLB Mode

Meaning: Indicates the mode for eNodeB-level inter-frequency MLB for UEs in idle mode. ADAPTIVE_PROPORTION: Indicates whether to enable load balancing in adaptive proportions. If the ADAPTIVE_PROPORTION option of this parameter and the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter are selected, the eNodeB timely adjusts the proportions of UEs to be released among frequencies based on the current proportions of UEs among frequencies and the preset proportions of UEs among frequencies, ensuring that the proportions of UEs in idle mode among frequencies approaches to the preset proportions. This option applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: ADAPTIVE_PROPORTION(ADAPTIVE_PROPORTION)

Unit: None

Actual Value Range: ADAPTIVE_PROPORTION

MML Default Value: None

Recommended Value: ADAPTIVE_PROPORTION:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the ADAPTIVE_PROPORTION option of this parameter is not selected, eNodeB-level load balancing in adaptive proportions is disabled. The proportions of UEs in idle mode among frequencies may not comply with the preset proportions. If the ADAPTIVE_PROPORTION option of this parameter and the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter are selected, the eNodeB adjusts the proportions of UEs in idle mode among frequencies, ensuring that the proportions comply with the preset proportions.

Applicable Mode: L-FDD, L-TDD
InterFreqIdleMlbInterval Inter Frequency Idle MLB Interval

Meaning: Indicates the measurement period of eNodeB-level inter-frequency MLB for UEs in idle mode. If the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the eNodeB collects the number of uplink synchronized UEs at a period specified by the InterFreqIdleMlbInterval parameter. At the end of a measurement period, the eNodeB updates the policy for inter-frequency MLB in proportions for UEs in idle mode based on the measurement result. If the INTER_FREQ_IDLE_MLB_SWITCH option is deselected, the eNodeB does not update the policy for inter-frequency MLB in proportions for UEs in idle mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10080

Unit: min

Actual Value Range: 0~10080

MML Default Value: None

Recommended Value: 1440

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more timely adjustment of the proportions of UEs in idle mode among frequencies based on real-time network conditions during eNodeB-level inter-frequency MLB for UEs in idle mode. However, if this parameter value is too small, the performance of eNodeB-level inter-frequency MLB for UEs in idle mode is affected by traffic fluctuation. If this parameter is set to a larger value, the eNodeB determines the proportions based on stable traffic model. However, if this parameter value is too large, the eNodeB cannot timely adjust the proportions.

Applicable Mode: L-FDD, L-TDD
InterFreqIdleMlbStaThd Inter Frequency Idle MLB Statistic Threshold

Meaning: Indicates the sample threshold of eNodeB-level inter-frequency MLB for UEs in idle mode. This parameter specifies whether to update the load balancing policy based on the statistics of eNodeB-level inter-frequency MLB for UEs in idle mode. If the INTER_FREQ_IDLE_MLB_SWITCH option of the MlbAlgoSwitch parameter in the ENodeBAlgoSwitch MO is selected, the eNodeB periodically measures the average number of uplink synchronized UEs in each cell. If the sum of the average number of uplink synchronized UEs in all cells is greater than or equal to this parameter value, the eNodeB updates the policy of inter-frequency MLB in proportions for UEs in idle mode based on the measurement result. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~10000

Unit: None

Actual Value Range: 1~10000

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of the eNodeB adjusting the proportions in which to-be-released UEs camp on cells operating in different frequencies during eNodeB-level inter-frequency load balancing in adaptive proportions. If the parameter value is too small, the eNodeB may improperly adjust the proportions based on incredible statistic results. A larger value of this parameter results in a higher probability of the eNodeB performing proper proportion adjustments. If this parameter value is too large, there is a low probability that the eNodeB adjusts the proportions.

Applicable Mode: L-FDD, L-TDD
DlCaLbMaxCCNum DL CA LB Max Component Carrier Number

Meaning: Indicates the maximum number of CCs aggregated for a CA UE whose load is to be transferred for load balancing in the downlink. If this parameter is set to 2CC(2CC), load of CA UEs using two CCs can be transferred for load balancing in the downlink. If this parameter is set to 3CC(3CC), load of CA UEs using two or three CCs can be transferred for load balancing in the downlink. This parameter applies only to LTE TDD.

GUI Value Range: 3CC(3CC), 2CC(2CC)

Unit: None

Actual Value Range: 3CC, 2CC

MML Default Value: None

Recommended Value: 3CC(3CC)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 2CC, only the load of CA UEs using two CCs can be transferred for load balancing. As a result, the average throughput cannot reach the maximum.

If this parameter is set to 3CC, load of CA UEs using two CCs and three CCs can be transferred for load balancing, increasing the average cell throughput.

Applicable Mode: L-TDD
CaUeMinDataVolRatio CA UE Minimum Data Volume Ratio

Meaning: Indicates the minimum data volume ratio between two CCs of a CA UE whose load is to be transferred. For example, if this parameter is set to 20, the minimum ratio of the data volume on a heavily loaded CC to that on a lightly loaded CC is 1/5. If this parameter is set to 0, the minimum ratio of the data volume on a heavily loaded CC to that on a lightly loaded CC is 0/1, that is, all data on the heavily loaded CC can be transferred to the lightly loaded CC. This parameter applies only to LTE TDD.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the average cell throughput can reach the maximum but the average throughput of CA UEs cannot reach the maximum.

If this parameter is set to a large value, the average throughput of CA UEs cannot reach the maximum but the average cell throughput cannot reach the maximum.

Applicable Mode: L-TDD

Example

To modify eNodeB MLB configuration with the parameters as follows: Inter Frequency Idle MLB Mode: ADAPTIVE_PROPORTION-1, Inter Frequency Idle MLB Interval: 1440, Inter Frequency Idle MLB Statistic Threshold: 3, run the following command:
MOD ENODEBMLB: InterFreqIdleMlbMode=ADAPTIVE_PROPORTION-1, InterFreqIdleMlbInterval=1440, InterFreqIdleMlbStaThd=3;
