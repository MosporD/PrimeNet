Modify PCCH Configuration (MOD PCCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PCCH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The product of ModifyPeriodCoeff in BcchCfg and DefaultPagingCycle in PCCHCfg is the actual modification period of the BCCH, which cannot exceed 1,024 radio frames.

  • The modifications on the PCCH configuration of an active cell would result in the automatic reset of the cell.

Parameters

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L
DefaultPagingCycle Default paging cycle

Meaning: Indicates the default paging period for the cell. It is also called the default discontinuous reception (DRX) period. If the EPC specifies a DRX period for a UE, the UE compares this period with the value of this parameter and uses the smaller one as its DRX period. If the EPC does not specify a DRX period, the UE uses the value of this parameter, which is delivered in the system information, as its DRX period. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: rf32(32 radio frames), rf64(64 radio frames), rf128(128 radio frames), rf256(256 radio frames)

Unit: None

Actual Value Range: rf32, rf64, rf128, rf256

MML Default Value: None

Recommended Value: rf128(128 radio frames)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: The values of this parameter and the NB parameter determine the number of paging occasions, that is, the number of paging groups. A larger value of this parameter may lead to a longer delay in paging a UE but help reduce the power consumption of the UE. A smaller value of this parameter may lead to a shorter delay in paging a UE but cause more power consumption of the UE. If the EPC specifies a DRX period for a UE, the UE uses the smaller value between the period and the parameter value as its DRX period.

Applicable Mode: L-FDD, L-TDD
Nb NB

Meaning: Indicates the number of paging occasions (a type of subframe) within a paging period. This parameter value also indicates the number of paging groups within a paging period. For details, see 3GPP TS 36.304.

GUI Value Range: FOURT, TWOT, ONET, HALFT, QUARTERT, ONE_EIGHTT, ONE_SIXTEENTHT, ONE_THIRTY_SECONDT

Unit: None

Actual Value Range: FOURT, TWOT, ONET, HALFT, QUARTERT, ONE_EIGHTT, ONE_SIXTEENTHT, ONE_THIRTY_SECONDT

MML Default Value: None

Recommended Value: ONET

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: For a certain paging load, a larger value of this parameter indicates a larger paging capacity during a specific period, and a smaller value of this parameter indicates a smaller paging capacity during a specific period.

Applicable Mode: L
PagingSentNum Paging Sent Number

Meaning: Indicates the number of paging messages transmitted to UEs over the air interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~3

Unit: None

Actual Value Range: 1~3

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a value greater than 1, paging messages are transmitted more than once to UEs over the air interface as configured. This increases the probability that UEs receive the paging messages and assists the EPC in ensuring delivery reliability. However, resource consumption on the air interface also increases. If a great number of paging messages are transmitted, the probability of congestion increases.

Applicable Mode: L-FDD, L-TDD
MaxPagingRecordsNum Maximum Number of Paging Records

Meaning: Indicates the maximum number of UEs that can be included in a paging message on each paging occasion. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~16

Unit: None

Actual Value Range: 1~16

MML Default Value: None

Recommended Value: 1. 16 for cells with a bandwidth of 20 MHz or 15 MHz;

2. 8 for cells with a bandwidth of 10 MHz or 5 MHz;

3. 4 for cells with a bandwidth of 3.3 MHz or 1.4 MHz.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If a large number of paging messages are to be sent in a cell, a smaller value of this parameter results in a higher probability of paging message discard or delayed paging message delivery due to paging message overload and therefore a lower paging success rate or worse user experience. If this parameter is set to a large value and there are many paging messages, one paging message may occupy too many resource blocks (RBs), which may result in an increased coding rate for paging messages due to insufficient system power or resources. As a result, the success rate of paging message reception decreases.

Applicable Mode: L-FDD, L-TDD
PagingStrategy Paging Message Sending Strategy

Meaning: Indicates the policy of sending paging messages. There are three policies: first in first out (FIFO), priority-based, and coverage-level-based.

If the FIFO policy is used, paging messages that arrive earlier are preferentially transmitted on a paging occasion.

If the priority-based policy is used, high-priority paging messages are preferentially transmitted on a paging occasion.

If the coverage-level-based policy is used, different priorities are assigned to NB-IoT paging messages intended for UEs at different coverage levels and paging messages are transmitted based on the assigned priorities on a paging occasion. The coverage-level-based policy applies only to NB-IoT.

GUI Value Range: PAGING_STRATEGY_FIFO(First-in First-out Strategy), PAGING_STRATEGY_DIFFPRI(Priority Differentiation Strategy), DIFFERENTIATION_BY_NB_COV_LVL(DIFFERENTIATION_BY_NB_COV_LVL)

Unit: None

Actual Value Range: PAGING_STRATEGY_FIFO, PAGING_STRATEGY_DIFFPRI, DIFFERENTIATION_BY_NB_COV_LVL

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

FDD/TDD: PAGING_STRATEGY_FIFO

NB-IoT: PAGING_STRATEGY_DIFFPRI

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the FIFO policy is used, paging messages that arrive earlier are preferentially transmitted on a paging occasion. When a large number of paging messages need to be transmitted, high-priority paging messages may not be transmitted promptly.

If the priority-based policy is used, high-priority paging messages are preferentially transmitted on a paging occasion. When a large number of paging messages need to be transmitted, this policy reduces the waiting time of high-priority paging messages on the air interface and therefore enables faster response to higher-priority paging messages.

If the coverage-level-based policy is used, paging messages are scheduled based on coverage levels to maximize the paging capacity. When there are a large number of paging messages, the paging capacity can be increased.

Applicable Mode: L
EnhPagingCR Enhanced Paging Code Rate

Meaning: Indicates the code rate used for paging messages when enhanced paging is enabled. An eNodeB identifies high-priority paging and CSFB-triggered paging and uses the code rate specified by this parameter to send high-priority paging messages and CSFB-triggered paging messages. If a paging message sent from the EPC contains the Paging Priority field, the paging is high-priority paging. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 10~930

Unit: None

Actual Value Range: 0.010~0.930

MML Default Value: None

Recommended Value: 35

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that paging messages will be successfully received and a greater number of RBs used for paging messages. When a large number of paging messages are transmitted, system throughput decreases. A larger value of this parameter results in a lower probability that paging messages will be successfully received and a smaller number of RBs used for paging messages. Consequently, the access success rate and paging success rate decrease.

Applicable Mode: L-FDD, L-TDD
EnhPagingSwitch Enhanced Paging Switch

Meaning: Indicates whether to enable enhanced paging. This parameter applies only to cells with a 10 MHz bandwidth or higher.

ENHNCD_HIGH_PRI_PAGING_SWITCH: If this option is selected, enhanced paging is enabled for high-priority paging and high-priority paging messages are transmitted at the code rate specified by the EnhPagingCR parameter in the PCCHCfg MO. If this option is deselected, high-priority paging messages are transmitted at the code rate specified by the RarAndPagingCR parameter in the CellDlschAlgo MO. This option applies only to LTE FDD and LTE TDD.

ENHNCD_CSFB_PAGING_SWITCH: If this option is selected, enhanced paging is enabled for CSFB-triggered paging and CSFB-triggered paging messages are transmitted at the code rate specified by the EnhPagingCR parameter in the PCCHCfg MO. If this option is deselected, CSFB-triggered paging messages are transmitted at the code rate specified by the RarAndPagingCR parameter in the CellDlschAlgo MO. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: ENHNCD_HIGH_PRI_PAGING_SWITCH(ENHNCD_HIGH_PRI_PAGING_SWITCH), ENHNCD_CSFB_PAGING_SWITCH(ENHNCD_CSFB_PAGING_SWITCH)

Unit: None

Actual Value Range: ENHNCD_HIGH_PRI_PAGING_SWITCH, ENHNCD_CSFB_PAGING_SWITCH

MML Default Value: None

Recommended Value: ENHNCD_HIGH_PRI_PAGING_SWITCH:Off, ENHNCD_CSFB_PAGING_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: ENHNCD_HIGH_PRI_PAGING_SWITCH: When this option is selected, the code rate for paging message transmission is reduced to increase the success rate of high-priority paging. When this option is deselected, the success rate of high-priority paging is not affected. ENHNCD_CSFB_PAGING_SWITCH: When this option is selected, the code rate for paging message transmission is reduced to increase the success rate of CSFB-triggered paging. When this option is deselected, the success rate of CSFB-triggered paging is not affected.

Applicable Mode: L-FDD, L-TDD
DefaultPagingCycleForNb NB-IoT Default Paging Cycle

Meaning: Indicates the default paging period for the cell. It is also called the default discontinuous reception (DRX) period. For details, see 3GPP TS 36.304. This parameter applies only to NB-IoT.

GUI Value Range: rf128(rf128), rf256(rf256), rf512(rf512), rf1024(rf1024)

A smaller value of this parameter may lead to a shorter delay in paging a UE but cause more power consumption of the UE.

NbForNbIoT NB-IoT nB

Meaning: Indicates the number of paging occasions (a type of subframe) of an NB-IoT cell within a paging period. This parameter is correlated with the repetition count of initial PDCCH transmission and the repetition count needs to be considered when this parameter is set. This parameter applies only to NB-IoT.

GUI Value Range: FOUR_T(FOUR_T), TWO_T(TWO_T), ONE_T(ONE_T), HALF_T(HALF_T), QUARTER_T(QUARTER_T), ONE_8TH_T(ONE_8TH_T), ONE_16TH_T(ONE_16TH_T), ONE_32TH_T(ONE_32TH_T), ONE_64TH_T(ONE_64TH_T), ONE_128TH_T(ONE_128TH_T), ONE_256TH_T(ONE_256TH_T), ONE_512TH_T(ONE_512TH_T), ONE_1024TH_T(ONE_1024TH_T)

Applicable Mode: L-NB-IOT
PagingTimeoutDiscardTimer Paging Timeout Discard Timer

Meaning: Indicates the length of the paging message discarding timer. If this parameter is set to 0, the timer does not take effect. If this parameter is set to a non-zero value, the timer takes effect. The eNodeB discards paging messages not yet sent and measures the number of discarded paging messages when this timer expires. If this timer is required, it is recommended that this parameter be set to a value at least greater than a paging cycle but less than the MME paging retransmission interval. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: s

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a non-zero value, this timer takes effect. A smaller value of this parameter leads to a lower probability of sending paging messages and more paging messages discarded when this timer expires. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
NbDefaultPagingCovLevel Default Coverage Level of NB-IoT Paging

Meaning: Indicates the default coverage level for paging messages. Paging messages in which coverage level information is not included by the core network are scheduled based on the coverage level specified by this parameter. This parameter applies only to NB-IoT.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2

Recommended Value: COVERAGE_LEVEL_2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In scenarios where the core network does not include coverage level information in paging messages, a larger value of this parameter leads to a higher paging success rate, higher paging resource usage, but a smaller paging capacity, and a smaller value of this parameter leads to lower paging resource usage, a higher paging capacity, but a probably lower paging success rate.

Applicable Mode: L-NB-IOT
DefaultPagingCycleForEmtc eMTC Default Paging Cycle

Meaning: Indicates the default paging cycle for eMTC. It is also called the DRX cycle. If the EPC delivers a DRX cycle, the eNodeB compares the cycle specified by this parameter with that delivered by the EPC and uses the smaller cycle for eMTC UEs. If the EPC does not deliver a DRX cycle, the eNodeB sends the cycle specified by this parameter to eMTC UEs through system information.

Note: In accordance with 3GPP specifications, the product of the value of this parameter and that of the PagingGroupNum parameter must be greater than or equal to 1. Otherwise, the network cannot perform paging normally. As a result, UEs cannot receive paging messages. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF32(RF32), RF64(RF64), RF128(RF128), RF256(RF256)

Unit: None

Actual Value Range: RF32, RF64, RF128, RF256

MML Default Value: None

Recommended Value: RF128

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: This parameter and the number of eMTC paging groups determine the number of paging occasions, that is, the number of paging groups. A larger value of this parameter may lead to a longer paging delay but helps reduce UE power consumption. A smaller value of this parameter may lead to a shorter paging delay but increases UE power consumption.

Applicable Mode: L-FDD, L-TDD
MaxPagingQueueBufferLength Max Paging Queue Buffer Length

Meaning: Indicates the maximum buffer length of a single paging queue.

If this parameter is set to a value in the range of 0 to 299, the maximum buffer length of a single paging queue is not controlled. If this parameter is set to another value, the maximum buffer length of a single paging queue is controlled. When the number of buffered paging messages in a paging queue reaches this value, subsequent paging messages that need to enter this paging queue will be discarded. To prevent paging message congestion in a single paging queue from occupying excessive paging buffer resources and affecting the paging success rates of other paging queues, you are advised to set this parameter to 1000. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4000

Unit: None

Actual Value Range: 0~4000

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value indicating that the control takes effect, a larger value leads to a lower probability of discarding paging messages and therefore a lower probability of relieving paging message congestion, and a smaller value leads to a higher probability of discarding paging messages and therefore a lower paging success rate.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: In a deactivated cell, to modify the PCCH configuration with the parameters as follows: Local cell ID: 0, Default paging cycle: rf32, run the following command:
MOD PCCHCFG: LocalCellId=0, DefaultPagingCycle=rf32;
Example 2: In a deactivated cell, to modify the PCCH configuration with the parameters as follows: Local cell ID: 0, Nb: HALFT, run the following command:
MOD PCCHCFG: LocalCellId=0, Nb=HALFT;
