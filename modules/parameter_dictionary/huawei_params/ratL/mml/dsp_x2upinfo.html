Display X2 User Plane Information (DSP X2UPINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query X2 user plane information.

Note

None.

Parameters

ID Name Description
X2InterfaceId X2Interface ID

Meaning: Indicates the X2 interface ID. If the X2 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65535. If the X2 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Display X2 User Plane Information: 
DSP X2UPINFO:;

Output Description

Field Description

X2Interface ID

Indicates the X2 interface ID. If the X2 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65535. If the X2 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.

X2 User Plane Host IPv4 Address

Indicates the IPv4 address of the user-plane host of the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Host IPv6 Address

Indicates the IPv6 address of the user-plane host of the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Peer IPv4 Address

Indicates the IPv4 address of the user-plane peer of the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Peer IPv6 Address

Indicates the IPv6 address of the user-plane peer of the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Link State

Indicates the user-plane link status of the X2 interface. The value Abnormal indicates that the user-plane link is disconnected. The value Normal indicates that the user-plane link is connected. The value Unknown indicates that the status or the IP PM delay of the link cannot be obtained. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Link Maximum One-Way Delay(0.1microsecond)

Indicates maximum one-way link delay of the X2 user-plane. This parameter applies only to LTE FDD and LTE TDD.

X2 User Plane Link Two-Way Delay(0.1microsecond)

Indicates the two-way link delay of the X2 user-plane. This parameter applies only to LTE FDD and LTE TDD.

Transmit Available Bandwidth(kbps)

Indicates the available bandwidth in the sending direction detected by the function of transmission congestion detection. If the TransmitCongDelay and TransmitAvailableBw parameter values are NULL and congestion detection in X2/eX2 links in non-ideal backhaul mode for bearer coordination services is enabled, the transmission congestion detection procedure fails. The failure cause can be one of the following: 1. The IPPM session that transmission congestion detection depends on is not activated. 2. The version or boards of the peer end do not support transmission congestion detection. 3. The boards of the local end do not support transmission congestion detection. This parameter applies only to LTE FDD and LTE TDD.

Transmit Congestion Delay(ms)

Indicates the single-way transmission congestion delay detected by the function of transmission congestion detection. If the TransmitCongDelay and TransmitAvailableBw parameter values are NULL and congestion detection in X2/eX2 links in non-ideal backhaul mode for bearer coordination services is enabled, the transmission congestion detection procedure fails. The failure cause can be one of the following:

- The IPPM session that transmission congestion detection depends on is not activated.

- The version or boards of the peer end do not support transmission congestion detection.

- The boards of the local end do not support transmission congestion detection.
