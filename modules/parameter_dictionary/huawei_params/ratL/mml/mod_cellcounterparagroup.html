Modify Cell Counter Parameter Group (MOD CELLCOUNTERPARAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify settings of parameters related to cell-level performance counter measurement.

Note

  • In heavy-traffic scenarios (for example, when the number of UEs in a cell exceeds 200), it is recommended that this function be disabled. This reduces the increase in uplink interference caused by uplink PRB usage increase in heavy-traffic scenarios.

  • When this function is used in non-heavy-traffic scenarios, if features related to common A3 measurement reports are disabled (an example feature is UL CoMP), it is recommended that the period of reporting common event A3 be changed from the default value 5120 ms to 60 minutes.

CellUserNumPdfThd Cell User Number PDF Counter Threshold

Meaning: Indicates the interval in which the statistics on the number of UEs in RRC_CONNECTED mode are collected. Eleven ranges are divided into based on this parameter value (referred as "N"): [0, N/10), [N/10, 2N/10), [2N/10, 3N/10), [3N/10, 4N/10), [4N/10, 5N/10), [5N/10, 6N/10), [6N/10, 7N/10), [7N/10, 8N/10), [8N/10, 9N/10), [9N/10, N), and [N, infinity). Each range corresponds to a performance counter. The number of UEs in RRC_CONNECTED mode is periodically sampled. A counter is incremented by one each time a sampled value falls into the corresponding range. For detailed descriptions of the performance counters affected by this parameter, see "Description" of counters related to UE distribution in the performance counter reference. To ensure that all sampled values fall into proper ranges, set this parameter based on the number of UEs in the cell. For example, if the average number of UEs in the cell is large, set this parameter to a large value; otherwise, set this parameter to a small value. This parameter applies only to LTE FDD and LTE TDD.

UlIblerOptSwitch Uplink Ibler Optimization Switch

Meaning: Indicates whether to enable uplink IBLER optimization. If this parameter is set to ON, for LTE TDD cells, the TBs not received are not taken into account for the IBLER calculation if DTX is detected based on the PUSCH. This function applies only to subframe configurations 2 and 5. If LTE TDD cells are established on the LBBPc, PUSCH DTX detection is not supported. If the PuschDtxSchOptSwitch option is deselected, the uplink IBLER is not affected even if this parameter is set to ON. For NB-IoT cells, uplink IBLER measurement is optimized. false PRACH detection due to interference is not considered during IBLER and RBLER measurement. The counters related to the number of TBs involved in uplink BPSK and QPSK modulation schemes are not taken into account. If this parameter is set to OFF, uplink IBLER measurement is not optimized for LTE TDD cells, and uplink IBLER and RBLER measurement is not optimized for NB-IoT cells. This parameter applies only to LTE TDD and NB-IoT.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the Uplink Ibler Optimization Switch parameter is set to ON, the TBs not received are not taken into account for the IBLER when DTX is detected on the PUSCH and therefore the IBLER decreases.

If the Uplink Ibler Optimization Switch parameter is set to OFF, the IBLER is not affected.

Applicable Mode: L-TDD, L-NB-IOT
CellCounterAlgoSwitch Cell Counter Algorithm Switch

Meaning: Indicates whether to enable cell-level algorithms related to performance counters. This parameter includes the following options: BasedA3EdgeUserSwitch: Indicates whether to enable A3-based cell edge user (CEU) identification. If this option is selected, the eNodeB starts to identify CEUs based on A3-related measurement reports and collects related performance counters based on the identified CEUs. This option applies only to LTE FDD and LTE TDD.

UlStatOptmizeSwitch: Indicates whether to optimize measurement of uplink interference. If this option is selected, the eNodeB optimizes measurement of uplink interference, and interference noise caused by RRUs is not measured. If this option is deselected, the eNodeB does not optimize measurement of uplink interference, and interference noise caused by RRUs is measured. This option applies only to LTE FDD and LTE TDD.

InSessionUeQtyUlDlAccSwitch: Indicates the method of collecting statistics about Number of UEs with Service Data to Be Transmitted in a Cell. When this option is deselected, the eNodeB samples the number of UEs in RRC_CONNECTED mode with data in the buffer every 100 ms in a cell, regardless of whether the data is in the uplink or downlink. When this option is selected, the eNodeB samples the number of UEs with uplink data in the buffer and the number of UEs with downlink data in the buffer every 100 ms in a cell. The numbers sampled in the uplink and the numbers sampled in the downlink are then separately added up. When a single UE performs services with multiple QCIs in the uplink or downlink, the number is then incremented on a per QCI basis. This option applies only to LTE FDD and LTE TDD.

RrcConnectedUserCountOptSwitch: Indicates the method of calculating the average number of users in a cell (L.Traffic.User.Avg) and maximum number of users in a cell (L.Traffic.User.Max). If this option is selected, downlink CA UEs that treat the cell as their SCell are counted while calculating the preceding counters. This option applies only to LTE FDD and LTE TDD.

RrcSetupSuccRateByRadiusOptSw: Indicates the method of measuring the RRC connection setup success rate when the ForbidAcByRadiusSwitch option of the RachAlgoSwitch parameter in the CellAlgoSwitch MO is selected. If this option is selected, the number of rejected RRC connection setup requests of UEs initiating access beyond the cell radius is not taken into account for RRC connection setup success rate measurements. If this option is deselected, the number is taken into account for the measurements. This option applies only to LTE FDD and LTE TDD.

UlIntrfMeasOptSw: Indicates whether to change the interference value for protection. When this option is selected, measurements are optimized in low-interference scenarios. If this option is deselected, the function does not take effect. This option applies only to LTE FDD and LTE TDD.

TaDistanceMappingSwitch: Indicates whether to exclude the impact of UL CoMP when TA-related statistics are collected in the cell. If this option is selected, the impact of UL CoMP will be excluded when TA-related statistics are collected. If this option is deselected, the impact of UL CoMP will not be excluded when TA-related statistics are collected. This option applies only to LTE FDD and LTE TDD.

VolteE2eVqiMeasOptSw: Indicates whether to optimize E2E VQI measurement. If this option is selected, packets received within a 2.5s period are measured with delay considered during the measurement of E2E VQI counters for calculating the MOS. If this option is deselected, measurement of E2E VQI counters is not optimized. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: BasedA3EdgeUserSwitch(BasedA3EdgeUserSwitch), UlStatOptmizeSwitch(UlStatOptmizeSwitch), InSessionUeQtyUlDlAccSwitch(InSessionUeQtyUlDlAccSwitch), RrcConnectedUserCountOptSwitch(RrcConnectedUserCountOptSwitch), RrcSetupSuccRateByRadiusOptSw(RrcSetupSuccRateByRadiusOptSw), UlIntrfMeasOptSw(UlIntrfMeasOptSw), TaDistanceMappingSwitch(TaDistanceMappingSwitch), VolteE2eVqiMeasOptSw(VolteE2eVqiMeasOptSw)

Unit: None

Actual Value Range: BasedA3EdgeUserSwitch, UlStatOptmizeSwitch, InSessionUeQtyUlDlAccSwitch, RrcConnectedUserCountOptSwitch, RrcSetupSuccRateByRadiusOptSw, UlIntrfMeasOptSw, TaDistanceMappingSwitch, VolteE2eVqiMeasOptSw

MML Default Value: None

Recommended Value: BasedA3EdgeUserSwitch:Off, UlStatOptmizeSwitch:Off, InSessionUeQtyUlDlAccSwitch:Off, RrcConnectedUserCountOptSwitch:Off, UlIntrfMeasOptSw:Off, TaDistanceMappingSwitch:Off, VolteE2eVqiMeasOptSw:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: BasedA3EdgeUserSwitch: If this option is selected, a UE that meets event A3 reporting conditions sends a measurement report to the eNodeB. The eNodeB determines whether the UE is a cell edge UE based on the report. Because the sending of A3 measurement reports occupies some uplink PRBs, uplink interference increases to some extent. If this option is deselected, network performance is not affected.

UlStatOptmizeSwitch: If this option is selected, the eNodeB optimizes measurement of uplink interference, and interference noise caused by RRUs is not measured. If this option is deselected, the eNodeB does not optimize measurement of uplink interference, and interference noise caused by RRUs is measured. This option has no impact on network performance.

RrcConnectedUserCountOptSwitch: If this option is selected, the values of the L.Traffic.User.Avg and L.Traffic.User.Max counters increase. If this option is deselected, network performance is not affected.

TaDistanceMappingSwitch: If this option is selected, the distance determined based on TA-related statistics is more accurate. If this option is deselected, the distance determined based on TA-related statistics in a micro cell or a cell served by a low-power RRU is longer than the actual distance in UL CoMP scenarios.

VolteE2eVqiMeasOptSw: If this option is selected, E2E VQI measurement values will decrease. If this option is deselected, E2E VQI measurement is not affected.

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the offset for cell edge user (CEU) identification event A3. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value of this parameter results that better signal quality of the neighboring cell is required for the reporting of CEU identification event A3 and the eNodeB has a lower probability of identifying a UE as a CEU. A smaller value of this parameter results in a higher probability that a UE is identified as a CEU. This parameter applies only to LTE FDD and LTE TDD.

UeAbnormalJudgeThd Ue Abnormal Judge Thd

Meaning: Indicates the uplink reception error rate threshold for identifying abnormal UEs. If this parameter is set to 0, abnormal UE identification based on the service drop rate is disabled. If this parameter is set to a non-zero value, an eNodeB identifies UEs with an uplink reception error rate greater than or equal to the specified threshold as abnormal UEs and counts the releases of such UEs as normal releases in context- and E-RAB-related statistics collection. In FDD networks, if this parameter is set to a non-zero value and the UELinkAbnormalDetectSwitch parameter is set to ON, the setting of the UELinkAbnormalDetectSwitch parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, an eNodeB does not identify abnormal UEs based on service drops. If this parameter is set to any value from 1 to 100, an eNodeB identifies abnormal UEs based on service drops. A smaller value of this parameter indicates that an eNodeB is less likely to identify abnormal UEs based on service drops and the decrease in the call drop rate is greater. A larger value of this parameter indicates that an eNodeB is more likely to identify abnormal UEs based on service drops and the decrease in the call drop rate is smaller.

ThrPdfPolicy Statistical Policy for Throughput PDF

Meaning: Indicates the policy of collecting statistics on throughput distribution. When this parameter is set to NORMAL, statistics about the downlink PDCP SDU throughput are collected based on the following formula: (L.Thrp.bits.DL - L.Thrp.bits.DL.LastTTI)/L.Thrp.Time.DL.RmvLastTTI. The statistics are collected in the corresponding throughput distribution ranges.
