Add eNodeB US Server Parameters Configuration (ADD ENODEBUSSERVERCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add configurations to the server which allows UEs who gain access to then be determined as UEs running unlimited services.

Note

None.

Parameters

ID Name Description
UsServerIndex US Server Index

Meaning: Indicates the index of the server which allows UEs who gain access to then be determined as UEs running unlimited services. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter is replaced by the ServerConfig.ServerIndex and will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: 0~49

Unit: None

Actual Value Range: 0~49

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UsServerIP US Server IP

Meaning: Indicates the IP address of the server which allows UEs who gain access to then be determined as UEs running unlimited services. Server-IP-address-based unlimited-service-supported UE identification can be performed based on any of the following methods: (1) Server IP address; (2) Server IP address + server protocol type; (3) Server IP address + server protocol type + server port number. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter is replaced by the ServerConfig.ServerIpAddress and will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UsServerPort US Server Port

Meaning: Indicates whether to check the port number of the server which allows UEs who gain access to then be determined as UEs running unlimited services. The value 0 indicates that the port number of the server that a UE running unlimited services accesses does not need to be checked. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter is replaced by the ServerConfig.ServerPortNumber and will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UsProtocolType US Protocol Type

Meaning: Indicates whether to check the protocol type of the server which allows UEs who gain access to then be determined as UEs running unlimited services. If this parameter is set to None, the eNodeB does not check the protocol type of downlink packets. If this parameter is set to UDP, the eNodeB checks whether the protocol type of downlink packets is UDP. If this parameter is set to TCP, the eNodeB checks whether the protocol type of downlink packets is TCP. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter is replaced by the ServerConfig.ProtocolType and will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: NONE(Not_Check), UDP(Check_Whether_UDP), TCP(Check_Whether_TCP)

Unit: None

Actual Value Range: NONE, UDP, TCP

MML Default Value: NONE(Not_Check)

Recommended Value: None(Not_Check)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add eNodeB US server configuration with the parameters as follows:Us Server Index:0, Us Server IP:192.168.1.1, Us Server Port:0, Us Protocol Type:NONE(The eNodeB does not check the protocol type of downlink packets), run the following command:
ADD ENODEBUSSERVERCFG: UsServerIndex=0, UsServerIP="192.168.1.1", UsServerPort=0, UsProtocolType=NONE;
