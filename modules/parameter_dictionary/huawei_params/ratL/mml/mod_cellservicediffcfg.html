Modify Cell Service Differentiation Configuration (MOD CELLSERVICEDIFFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell service differentiation.

Note

If the FPIGTPUSwitch or DSCPRemarkSwitch option of the ServiceDiffSwitch parameter in the CellServiceDiffCfg MO is selected, the VideoRateAdaptSwitch and DownLoadRateLimitSwitch options of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO cannot be selected. Alternatively, if the VideoRateAdaptSwitch or DownLoadRateLimitSwitch option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO is selected, the FPIGTPUSwitch and DSCPRemarkSwitch options of the ServiceDiffSwitch parameter in the CellServiceDiffCfg MO cannot be selected.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServiceDiffSwitch Service differentiation switch

Meaning: Indicates the switches related to service differentiation in a cell.

CellConStaReportSwitch: Indicates the switch used to control whether the RLC-buffered-based cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. This option applies only to LTE FDD and LTE TDD.

FPIGTPUSwitch: Indicates whether to enable the service differentiation feature using the extended GTP-U header containing the FPI value. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority.

DSCPRemarkSwitch: Indicates whether to enable the DSCP Remark-based service differentiation feature. If this option is selected, the eNodeB guarantees differentiated quality of service (QoS) based on the service type specified by the DSCP field in the IP packet sent by the PDN gateway to the eNodeB. This option applies only to LTE FDD.

CellUuConStaReportSwitch: Indicates the switch used to control whether the PRB-based and UL-sync UE cell congestion information is reported using the extended GTP-U headers to the EPC. The guideline can be found in documents related to the EPC feature, which is Wireless Optimization Based on Flow Priority. When both the CellConStaReportSwitch and CellUuConStaReportSwitch options are selected, the CellConStaReportSwitch option takes effect but the CellUuConStaReportSwitch option does not take effect. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: CellConStaReportSwitch(CellConStaReportSwitch), FPIGTPUSwitch(FPIGTPUSwitch), DSCPRemarkSwitch(DSCPRemarkSwitch), CellUuConStaReportSwitch(CellUuConStaReportSwitch)

Unit: None

Actual Value Range: CellConStaReportSwitch, FPIGTPUSwitch, DSCPRemarkSwitch, CellUuConStaReportSwitch

MML Default Value: None

Recommended Value: CellConStaReportSwitch:Off, FPIGTPUSwitch:Off, DSCPRemarkSwitch:Off, CellUuConStaReportSwitch:Off

Parameter Relationship:

-Others:

  • When both of DSCPRemarkSwitch(DSCPRemarkSwitch) and FPIGTPUSwitch(FPIGTPUSwitch) are turned on, only the former related feature is enabled actually, but not the later.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
CellConStatePrbThd Cell Congestion State PRB Threshold

Meaning: Indicates the threshold for determining the cell congestion status based on the physical resource block (PRB) usage. The eNodeB generates a cell congestion indicator based on this parameter and the CellConStateUeNumThd parameter and then sends the indicator to the EPC. If both the downlink PRB usage and the number of UL-sync UEs are greater than or equal to their respective congestion thresholds but do not exceed their respective overload thresholds, the eNodeB sends a cell congestion indicator to the EPC. If either the downlink PRB usage or the number of UL-sync UEs is less than the corresponding congestion threshold, the eNodeB sends a congestion indicator indicating that the cell is in the normal state to the EPC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 75

Parameter Relationship:

-Configuration constraints:

  • In the CellServiceDiffCfg MO, the CellConStatePrbThd parameter must be set to a value smaller than that of the CellOverloadStatePrbThd parameter.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value, the EPC performs differentiated control on UEs and services in a more timely manner, which ensures experience of high-priority UEs and services. However, the air interface resource utilization rate decreases when the number of UEs or traffic volume is insufficient. If this parameter is set to a larger value, the EPC performs differentiated control on UEs and services in a less timely manner and UEs have a higher resource utilization rate. However, timely differentiated service assurance for high-priority UEs and services cannot be ensured.

Applicable Mode: L-FDD, L-TDD

QueueServiceWeight0 Weight of queue 0

Meaning: Indicates the weight of the queue, which is used in service differentiation scheduling. The value of this parameter is used in calculating the priority of a UE during scheduling and therefore determines the scheduling probability of this UE. The scheduling probability and priority of services in a queue has a positive correlation with the value of this parameter. This parameter is valid only if FPIGTPUSwitch(FPIGTPUSwitch) or DSCPRemarkSwitch(DSCPRemarkSwitch) is turned on. When DSCPRemarkSwitch is turned on, this parameter indicates the weight of non-P2P service queue. This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates the maximum number of times that the eNodeB sends a proprietary GTP-U extension header during a negotiation process. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter waiting time for a roaming UE to roam to the home core network but a higher probability that negotiation cannot be completed for local UEs, affecting the performance of the Wireless Optimization Based on Flow Priority feature. A larger value of this parameter results in less impact on successful negotiation for local UEs but a longer waiting time for a roaming UE to roam to the home core network.

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of service differentiation in the cell with the parameters as follows: Local cell ID: 0, Service differentiation switch: CellConStaReportSwitch-1, QueueServiceWeight0: 20, run the following command:
MOD CELLSERVICEDIFFCFG: LocalCellId=0, ServiceDiffSwitch=CellConStaReportSwitch-1, QueueServiceWeight0=20;
