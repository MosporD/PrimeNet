Add IP Address Pool (ADD EUIPADDRESSPOOL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an IP address pool of the compact EPC.

Note

None.

Parameters

ID Name Description
IPAddressPoolID IP Address Pool ID

Meaning: This parameter specifies the ID of an IP address pool. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StartIPAddress Start IP Address

Meaning: Indicates the start IP address. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EndIPAddress End IP Address

Meaning: Indicates the end IP address. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mask Mask

Meaning: Indicates the mask of an IP address pool. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an IP address pool with the parameters as follows: IP Address Pool ID:4, Start IP Address:172.31.255.4, End IP Address:172.31.255.5, Mask255.255.255.128, run the following command:
ADD EUIPADDRESSPOOL: IPAddressPoolID=4, StartIPAddress="172.31.255.4", EndIPAddress="172.31.255.5", Mask="255.255.255.128";
