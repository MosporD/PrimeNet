List CN Operator Handover Configuration (LST CNOPERATORHOCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list operator-specific handover configurations.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List CN Operator Handover Configuration:
LST CNOPERATORHOCFG:;
The result is shown as follows:
+++    BHCA_10.21        2019-12-18 10:10:23
O&M    #806355566
%%LST CNOPERATORHOCFG:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

CN Operator ID

Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

First RAT Priority

Indicates the priority of E-UTRAN TDD or E-UTRAN FDD in inter-frequency blind handover or blind redirection scenarios. To prioritize E-UTRAN TDD or E-UTRAN FDD, set this parameter to EUTRAN_TDD or EUTRAN_FDD, respectively. To treat E-UTRAN TDD and E-UTRAN FDD equally, set this parameter to EUTRAN. This parameter applies only to LTE FDD and LTE TDD.

Second RAT Priority

Indicates the priority of E-UTRAN TDD or E-UTRAN FDD in inter-frequency blind handover or blind redirection scenarios. To prioritize E-UTRAN TDD or E-UTRAN FDD, set this parameter to EUTRAN_TDD or EUTRAN_FDD, respectively. If the FirstRatPri parameter is set to EUTRAN, the SecondRatPri parameter must be set to NULL, indicating that E-UTRAN TDD and E-UTRAN FDD are not differentiated. This parameter applies only to LTE FDD and LTE TDD.

LTE TDD inter-freq A2 Threshold RSRP Offset(dB)

Indicates the offset for LTE TDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE TDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE TDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter or the FddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the TddIfHoA2ThdRsrpOffset parameter is set to -100 and the FddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE TDD measurement is not triggered, and the eNodeB delivers only LTE FDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE FDD inter-frequency measurement. The RSRP threshold for LTE FDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

LTE FDD inter-freq A2 Threshold RSRP Offset(dB)

Indicates the offset for LTE FDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE FDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE FDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter or the TddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the FddIfHoA2ThdRsrpOffset parameter is set to -100 and the TddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE FDD measurement is not triggered, and the eNodeB delivers only LTE TDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE TDD inter-frequency measurement. The RSRP threshold for LTE TDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

UTRAN A2 Threshold RSRP Offset(dB)

Indicates the offset for UTRAN event A2 relative to the RSRP threshold for inter-RAT event A2 (specified by the InterRatHoA2ThdRsrp parameter). The sum of the value of this parameter, the value of the InterRatHoA2ThdRsrp parameter in the InterRatHoCommGroup MO, and the value of the InterRatA2RsrpThldOffset parameter in the CnOperatorQciPara MO is taken as the RSRP threshold for inter-RAT event A2. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-RAT A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the UtranA2ThdRsrpOffset or GeranA2ThdRsrpOffset parameter value, and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If both the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-RAT event A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the UtranA2ThdRsrpOffset parameter is set to -100 and the GeranA2ThdRsrpOffset parameter is not set to -100, coverage-based UTRAN measurement is not triggered, and the eNodeB delivers only the GERAN event A2 measurement configurations, which are used to trigger coverage-based GERAN measurement. The RSRP threshold for GERAN event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the InterRatA2RsrpThldOffset parameter value, and the GeranA2ThdRsrpOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. This parameter applies only to LTE FDD and LTE TDD.

GERAN A2 Threshold RSRP Offset(dB)

Indicates the offset for GERAN event A2 relative to the RSRP threshold for inter-RAT event A2 (specified by the InterRatHoA2ThdRsrp parameter). The sum of the value of this parameter, the value of the InterRatHoA2ThdRsrp parameter in the InterRatHoCommGroup MO, and the value of the InterRatA2RsrpThldOffset parameter in the CnOperatorQciPara MO is taken as the RSRP threshold for inter-RAT event A2. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-RAT A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the UtranA2ThdRsrpOffset or GeranA2ThdRsrpOffset parameter value, and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If both the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-RAT event A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the GeranA2ThdRsrpOffset parameter is set to -100 and the UtranA2ThdRsrpOffset parameter is not set to -100, coverage-based GERAN measurement is not triggered, and the eNodeB delivers only the UTRAN event A2 measurement configurations, which are used to trigger coverage-based UTRAN measurement. The RSRP threshold for UTRAN event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the InterRatA2RsrpThldOffset parameter value, and the UtranA2ThdRsrpOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. This parameter applies only to LTE FDD and LTE TDD.

SRVCC with PSHO Based UTRAN Cell Capb Switch

Indicates whether the eNodeB checks the CS+PS handover capability of external UTRAN cells when initiating SRVCC for concurrent CS and PS services. If this parameter is set to ON(On), the eNodeB does not check the capability indicated by the setting of the CsPsHOInd parameter in the UtranExternalCell MOs. If this parameter is set to OFF(Off), the eNodeB needs to check this capability. This parameter applies only to LTE FDD and LTE TDD.

PS Inter-RAT Highest Priority

Indicates the highest-priority RAT for data services. If this parameter is set to UTRAN, GERAN, or CDMA2000, the highest-priority RAT for inter-RAT handovers of data services is UTRAN, GERAN, or CDMA2000, respectively.

The value CDMA2000 is invalid in the current version. Therefore, avoid setting this parameter to CDMA2000. This parameter applies only to LTE FDD and LTE TDD.

PS Inter-RAT Second Priority

Indicates the medium-priority RAT for data services. If this parameter is set to UTRAN, GERAN, or CDMA2000, the medium-priority RAT for inter-RAT handovers of data services is UTRAN, GERAN, or CDMA2000, respectively.

The value CDMA2000 is invalid in the current version. Therefore, avoid setting this parameter to CDMA2000. This parameter applies only to LTE FDD and LTE TDD.

PS Inter-RAT Lowest Priority

Indicates the lowest-priority RAT for data services. If this parameter is set to UTRAN, GERAN, or CDMA2000, the lowest-priority RAT for inter-RAT handovers of data services is UTRAN, GERAN, or CDMA2000, respectively.

The value CDMA2000 is invalid in the current version. Therefore, avoid setting this parameter to CDMA2000. This parameter applies only to LTE FDD and LTE TDD.

NR A2 Threshold RSRP Offset(dB)

Indicates the offset for NG-RAN event A2 relative to the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO. The sum of this offset, the value of the InterRatHoNrA2ThldRsrp parameter in the InterRatHoCommGroup MO, and the value of the NrA2RsrpThldOffset parameter in the CnOperatorQciPara MO is taken as the RSRP threshold for NG-RAN event A2. This parameter applies only to LTE FDD and LTE TDD.
