Modify MRO Algorithm (MOD MRO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the MRO configuration.

Note

None.

Parameters

ID Name Description
OptPeriod MRO optimization period

Meaning: Indicates the period of measurement for MRO. During the period, the number of handovers is measured and abnormal scenarios (including premature handover, delayed handover, and ping-pong handover) are identified. After the period elapses, the eNodeB makes a decision on parameter adjustment. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~70000

Unit: min

Actual Value Range: 1~70000

MML Default Value: None

Recommended Value: 1440

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NcellOptThd Ncell optimization threshold

Meaning: Indicates the handover success rate threshold for enabling mobility-related parameter optimization. If the handover success rate is greater than this parameter value, mobility-related parameters are optimized to reduce the number of ping-pong handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 99

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StatNumThd MRO statistics number threshold

Meaning: Indicates the threshold of the number of handovers (including outgoing handover attempts and delayed handovers) required for enabling optimization of intra-RAT mobility-related parameters. Optimization of intra-RAT mobility-related parameters is started when the number of handovers from the local cell to an intra-RAT neighboring cell reaches this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10000

Unit: None

Actual Value Range: 0~10000

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PingpongTimeThd Pingpong handover threshold

Meaning: Indicates the threshold of the duration during which a UE stays in the target cell to determine whether the handover is a ping-pong handover. If a UE is handed over back to the source cell after staying in the target cell for a period shorter than this threshold, the eNodeB decides that a ping-pong handover occurs based on the history information about this UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller number of ping-pong handovers indicated by counters. A larger value of this parameter leads to a larger number of ping-pong handovers indicated by counters.

Applicable Mode: L-FDD, L-TDD
PingpongRatioThd Pingpong ratio threshold

Meaning: Indicates the threshold for the percentage of intra-RAT ping-pong handovers. If the percentage of intra-RAT ping-pong handovers is greater than this parameter value, parameters are adjusted to reduce the number of ping-pong handovers. If the percentage is less than or equal to this parameter value, parameters are not adjusted to reduce the number of ping-pong handovers. This parameter applies only to LTE FDD and LTE TDD.

Applicable Mode: L-FDD, L-TDD
CoverAbnormalThd Abnormal coverage threshold

Meaning: Indicates the threshold for the percentage of coverage-induced abnormal handovers to all abnormal handovers from the serving cell to a neighboring cell. If the percentage is greater than or equal to this threshold when a mobility robustness optimization (MRO) period approaches its end, the eNodeB does not adjust MRO-related parameters of the neighboring cell within this period. This parameter applies only to LTE FDD and LTE TDD.

MML Default Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServingRsrpThd Serving cell RSRP threshold

Meaning: Indicates the reference signal received power (RSRP) threshold for the serving cell. The threshold is used to identify abnormal coverage in a serving cell. If a UE successfully reestablishes an RRC connection or reaccess the serving cell after a radio link failure (RLF) or a handover failure, the UE sends the eNodeB an RLF report, which includes the RSRP values of the serving cell and neighboring cell. If the RSRP value of the serving cell is less than this parameter value and the RSRP value of the neighboring cell is less than the NeighborRsrpThd parameter value, this RLF or handover failure is induced by abnormal coverage rather than inappropriate MRO configurations. This parameter applies only to LTE FDD and LTE TDD.

NeighborRsrpThd Neighbour cell RSRP threshold

Meaning: Indicates the reference signal received power (RSRP) threshold for neighboring cells. The threshold is used to identify coverage-induced abnormal handovers from the serving cell to the neighboring cell. If a UE successfully reestablishes an RRC connection or reaccess the serving cell after a radio link failure (RLF) or a handover failure, the UE sends the eNodeB an RLF report, which includes the RSRP values of the serving cell and neighboring cell. If the RSRP value of the serving cell is less than the ServingRsrpThd parameter value and the RSRP value of the neighboring cell is less than this parameter value, this RLF is induced by abnormal coverage rather than inappropriate MRO configurations. This parameter applies only to LTE FDD and LTE TDD.

UePingPongNumThd UE PingPong Number Threshold

Meaning: Indicates the threshold for the number of ping-pong handovers of a UE. If the number of consecutive ping-pong handovers reaches the threshold, the UE is a ping-pong UE. This parameter applies only to LTE FDD and LTE TDD.

InterFreqMeasTooLateHoThd Inter frequency measurement too late handover threshold

Meaning: Indicates the threshold of the percentage of delayed handovers caused by a low event A2 threshold and delayed inter-frequency measurements to the sum of premature handovers and delayed handovers. If the actual percentage is greater than this parameter value, the threshold for triggering inter-frequency event A2 is adjusted by the inter-frequency MRO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 20 for newly deployed networks with inter-frequency MRO deployed for the first time

Parameter Relationship:

-Configuration constraints:

  • In the MRO MO, InterFreqA2RollBackThd must be smaller than InterFreqMeasTooLateHoThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter specifies the probability that the event A2 threshold adjustment is triggered by the inter-frequency MRO. A smaller value of this parameter results in easier event A2 threshold adjustments, higher probability of inter-frequency measurements, a lower service drop rate and a smaller number of RRC reestablishments caused by delayed inter-frequency measurements due to improper event A2 thresholds, and a higher handover success rate, but lower user and cell throughput due to frequent inter-frequency GAP measurements. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
InterFreqA2RollBackThd Inter frequency A2 rollback threshold

Meaning: Indicates the threshold of event A2 rollback triggered by inter-frequency MRO. If the percentage of delayed handovers caused by late inter-frequency measurement to the sum of premature handovers and delayed handovers is less than the threshold, the event A2 rollback is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 2

Parameter Relationship:

-Configuration constraints:

  • In the MRO MO, InterFreqA2RollBackThd must be smaller than InterFreqMeasTooLateHoThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value leads to higher probability of event A2 rollback and lower probability of inter-frequency measurement. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
MroOptMode MRO Optimization Mode

Meaning: Indicates the mode in which MRO takes effect. If this parameter is set to FREE, the eNodeB automatically optimizes handover and cell reselection parameter settings. If this parameter is set to CONTROLLED, the eNodeB only reports the handover or cell reselection parameter settings to be optimized to the MAE, and the MAE delivers the optimization on handover or cell reselection parameter settings after users confirm the optimization. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: FREE(FREE), CONTROLLED(CONTROLLED)

Unit: None

Actual Value Range: FREE, CONTROLLED

MML Default Value: None

Recommended Value: FREE(FREE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UnnecInterRatHoOptThd Unnecessary IRAT Ho Optimize Threshold

Meaning: Indicates the threshold for the inter-RAT handover success rate used to evaluate MRO against unnecessary inter-RAT handovers. If the inter-RAT handover success rate is greater than or equal to this parameter value, this type of MRO is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 95

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering MRO against unnecessary inter-RAT handovers, which has no negative impact on KPIs. A smaller value of this parameter results in a higher probability of triggering MRO against unnecessary inter-RAT handovers and a higher probability that UEs camp on the LTE network. However, the inter-RAT handover success rate and service drop rate may be affected.

Applicable Mode: L-FDD, L-TDD
UnnecInterRatHoRsrpThd Unnecessary InterRAT Ho RSRP Threshold

Meaning: Indicates the reference signal received power (RSRP) threshold used to determine whether an inter-RAT handover is an unnecessary handover. After an inter-RAT handover, if the RSRP value of the source E-UTRAN cell measured by the UE in the target cell is consecutively greater than or equal to this parameter value within the specified period of time, the eNodeB considers that the inter-RAT handover is an unnecessary handover. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-44

Unit: dBm

Actual Value Range: -140~-44

MML Default Value: None

Recommended Value: -115

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that inter-RAT handovers are considered as unnecessary handovers. This has no negative impact on KPIs. A smaller value of this parameter results in a higher probability that inter-RAT handovers are considered as unnecessary handovers, including incorrect evaluation. As a result, the inter-RAT handover success rate may decrease and the service drop rate may increase.

Applicable Mode: L-FDD, L-TDD
InterRatA2RsrpMinThd InterRAT A2 RSRP Adjustment Lower Limit

Meaning: Indicates the minimum value within the range for inter-RAT A2 event threshold adjustment. This parameter applies only to LTE TDD.

GUI Value Range: -141~-43

Unit: dBm

Actual Value Range: -141~-43

MML Default Value: None

Recommended Value: -118

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, MRO against unnecessary inter-RAT handovers adjusts the lower limit of the inter-RAT A2 event to a large value. In this case, the inter-RAT measurement is difficult to be triggered, and inter-RAT handover failures and call drops may occur. If this parameter is set to a small value, MRO against unnecessary inter-RAT handovers adjusts the lower limit of the inter-RAT A2 event to a small value. In this case, the MRO against unnecessary inter-RAT handovers is affected, while the KPIs are not affected.

Applicable Mode: L-TDD

Meaning: Indicates the threshold of the number of handovers (including outgoing handover attempts and delayed handovers) required for enabling optimization of inter-RAT mobility-related parameters. Optimization of inter-RAT mobility-related parameters is started when the number of handovers from the local cell to inter-RAT neighboring cells reaches this threshold. This parameter applies only to LTE FDD and LTE TDD.

Applicable Mode: L-FDD, L-TDD
IntraRatTooEarlyHoRatioThd IntraRat Too Early HO Ratio Threshold

Meaning: Indicates the threshold of the proportion of premature intra-RAT handovers. If the proportion of the premature intra-RAT handovers is higher than this threshold and the current cell individual offset (CIO) is greater than the CIO adjustment threshold, mobility parameters need to be adjusted. If the proportion of the premature intra-RAT handovers is less than or equal to this parameter value, mobility parameters do not need to be adjusted. If both this parameter and the IntraRatTooLateHoRatioThd parameter are set to 50% or smaller values, the conditions for optimizing both premature and delayed intra-RAT handovers may be met. In this case, delayed intra-RAT handovers, which increase the service drop rate at a higher probability than premature intra-RAT handovers, are optimized by preference. This parameter applies only to LTE FDD and LTE TDD.

Applicable Mode: L-FDD, L-TDD
IntraRatTooLateHoRatioThd IntraRat Too Late HO Ratio Threshold

Meaning: Indicates the threshold of the proportion of delayed intra-RAT handovers. If the proportion of the delayed intra-RAT handovers is higher than this threshold and the current cell individual offset (CIO) is less than the CIO adjustment threshold, mobility parameters need to be adjusted. If the proportion of delayed intra-RAT handovers is less than or equal to this parameter value, mobility parameters do not need to be adjusted. In this case, delayed intra-RAT handovers, which increase the service drop rate at a higher probability than premature intra-RAT handovers, are optimized by preference. This parameter applies only to LTE FDD and LTE TDD.

InterFreqA2RollBackPeriod Inter Frequency A2 Rollback Period

If the conditions for lowering the RSRP threshold in inter-frequency A2-related delayed handovers are met for the consecutive number of MRO periods specified by this parameter, the RSRP threshold for triggering inter-frequency event A2 is lowered. IntraRatHoTooEarlyTimeThd IntraRat HO Too Early Time Threshold

Meaning: Indicates the duration threshold for determining whether an abnormal intra-RAT handover due to an unstable target cell. If the time during which a UE camps on a cell after an intra-RAT handover is less than or equal to this parameter value, the eNodeB considers that the cell is unstable.

A larger value of this parameter results in a higher probability that intra-RAT MRO determines intra-RAT handovers as premature handovers and adjusts parameters to reduce the number of premature handovers. This decreases the number of handovers and increases the probability of delayed handovers.

A smaller value of this parameter results in a higher probability that intra-RAT MRO determines intra-RAT handovers as delayed handovers and adjusts parameters to reduce the number of delayed handovers. This increases the number of handovers.

For details, see descriptions of "short time" in "Intra-RAT MRO use case" in 3GPP TS 36.300. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of parameter results in a higher probability that intra-RAT handovers are determined as premature handovers based on MRO, and a higher probability that optimization on premature handovers is triggered, which in turn decreases the number of handover attempts and increases the probability of delayed handovers.

A smaller value of this parameter results in a higher probability that intra-RAT handovers are determined as delayed handovers based on MRO and a higher probability that optimization on delayed handovers is triggered, which in turn increases the number of handover attempts.

Applicable Mode: L-FDD, L-TDD
InterRatAbnormalHoRatioThd InterRat Abnormal HO Ratio Threshold

Meaning: Indicates the threshold for triggering optimization against abnormal inter-RAT handovers. If the ratio of abnormal inter-RAT handovers is greater than or equal to this threshold, the eNodeB determines whether to adjust mobility parameters. If the ratio of abnormal inter-RAT handovers is less than this threshold, the eNodeB does not determine whether to adjust mobility parameters. Abnormal handovers include delayed handovers and premature handovers. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value: 10

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering parameter adjustments against abnormal inter-RAT handovers and a lower probability of reducing the rate of inter-RAT handover failures or service drops caused by inappropriate inter-RAT handover parameter settings. A smaller value of this parameter results in a higher probability of triggering parameter adjustments against abnormal inter-RAT handovers, but also a higher probability of triggering unnecessary parameter adjustments due to some abnormal inter-RAT handovers.

Applicable Mode: L-FDD, L-TDD
InterRatMeasTooLateHoThd InterRat Measurement Too Late Ratio Threshold

Meaning: Indicates the percentage threshold of delayed inter-RAT handovers caused by delayed inter-RAT measurements to the sum of abnormal inter-RAT handovers (including premature handovers and delayed handovers). If the actual percentage of delayed A2-related inter-RAT handovers is greater than this parameter value, optimization on the threshold for inter-RAT event A2 is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of increasing the threshold for inter-RAT event A2. A higher threshold leads to a higher probability of inter-RAT measurements and a smaller number of A2-related delayed handovers. This parameter adjustment reduces the service drop rate and the number of RRC connection reestablishments caused by delayed inter-RAT measurements due to an inappropriate threshold for inter-RAT event A2, and it also increases the inter-RAT handover success rate. However, frequent gap-assisted inter-RAT measurements cause a decrease in UE throughput and cell throughput.

A larger value of this parameter results in a lower probability of increasing the threshold for inter-RAT event A2.

Applicable Mode: L-FDD, L-TDD

If the percentage of unnecessary inter-RAT handovers is greater than this parameter value, this type of MRO is triggered. This parameter applies only to LTE FDD and LTE TDD.

After an inter-RAT handover, if the reference signal received power (RSRP) value of the source E-UTRAN cell measured by the UE in the target cell is consecutively greater than a preset threshold within the period of time specified by this parameter, the eNodeB considers that the inter-RAT handover is an unnecessary handover. This parameter applies only to LTE FDD and LTE TDD.

Unit: s

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 2

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

A smaller value of this parameter results in a higher probability that inter-RAT handovers are considered as unnecessary handovers, including incorrect evaluation. As a result, the inter-RAT handover success rate may decrease and the service drop rate may increase.

Example

Example 1: To modify the MRO configuration with the parameters as follows: MRO optimization period: 10, Ncell optimization threshold: 100, MRO statistics number threshold: 10, Pingpong handover threshold: 1, Pingpong ratio threshold: 1, run the following command:
MOD MRO: OptPeriod=10, NcellOptThd=100, StatNumThd=10, PingpongTimeThd=1, PingpongRatioThd=1;
Example 2: To modify the MRO configuration with the parameters as follows: MRO optimization period: 1, Ncell optimization threshold: 100, MRO statistics number threshold: 1, Pingpong handover threshold: 2, Pingpong ratio threshold: 2, run the following command:
MOD MRO: OptPeriod=1, NcellOptThd=100, StatNumThd=1, PingpongTimeThd=2, PingpongRatioThd=2;
