Modify PRB Sector Equipment Group (MOD EUPRBSECTOREQMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a sector equipment group of a PRB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During the modification of the BasebandEqmId parameter associated with an activated cell, the cell automatically resets if the BasebandEqmId parameter value is changed to an ID representing a baseband equipment on which the cell is not established.

  • The baseband resource allocation mode is changed after the modification of the AutoConfigFlag parameter.

BasebandEqmId Baseband Equipment ID

Meaning: Indicates the ID of the baseband equipment that serves the PRB.

When this parameter is set to 255, the baseband equipment is not specified for the PRB. In this scenario, any BBP in the base station can be selected to serve the PRB, and the BBP to which the RRU for the PRB is directly connected is preferentially selected.

When this parameter is set to a value other than 255, the PRB can be served only by a BBP included in the specified baseband equipment, and the BBP to which the RRU for the PRB is directly connected is preferentially selected. This parameter applies only to NB-IoT.

Recommended Value: None

AutoConfigFlag Auto Config Flag

Meaning: Indicates whether to automatically or manually control the setting of baseband equipment ID. To allow for automatic binding, set this parameter to AUTO_MODE. To allow for manual binding, set this parameter to MANUAL_MODE or AUTO_MODE. This parameter applies only to NB-IoT.

This parameter is valid only if the MultiRruCellFlag parameter is set to BOOLEAN_TRUE and the MultiRruCellMode parameter is set to MPRU_AGGREGATION or SFN, respectively. Example

To modify prb sector equipment group with the parameters as follows: LocalCellId: 0, PrbId: 0, SectorEqmGroupId: 0, AutoConfigFlag: MANUAL_MODE, run the following command:
+++    0        2017-10-20 16:14:49
O&M    #806354955
%%MOD EUPRBSECTOREQMGROUP: LocalCellId=0, PrbId=0, SectorEqmGroupId=0, AutoConfigFlag=MANUAL_MODE;%%
RETCODE = 0  Operation succeeded.


---    END
