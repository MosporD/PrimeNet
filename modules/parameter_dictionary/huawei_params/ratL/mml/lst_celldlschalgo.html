List Cell DL Scheduling Algorithm Configuration (LST CELLDLSCHALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the cell DL scheduling algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the parameters of the Cell Downlink Schedule Parameters with the local cell ID of 1, run the following command:
LST CELLDLSCHALGO: LocalCellId=1;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Downlink scheduling Strategy

Indicates the DL scheduling policy. According to the Max C/I scheduling policy, the UE with good channel quality is scheduled and hence the spectral efficiency is very high. The QoS and fairness among users, however, cannot be ensured. The Max C/I scheduling policy can be used to verify the maximum capacity of the system. The RR scheduling policy is the fairest scheduling policy. When RR is adopted, the system capacity is the smallest. Therefore, RR is used only to verify the upper bound of the scheduling fairness in the system. In terms of the scheduling effect, the PF scheduling policy is between the previous two policies. Therefore, PF can be used to verify the capacity, coverage, and fairness of the system. The EPF scheduling policy supports the features such as user QoS, system capacity, and channel frequency selection. The basic scheduling policy is mainly used for the performance test purpose. During common operation, the EPF scheduling policy is recommended. This parameter applies only to LTE FDD and LTE TDD.

Free Users Downlink RB Ratio(%)

Indicates the percentage of PDSCH RBs shared by free UEs when both free and paying UEs are scheduled. The rest of RBs used as the PDSCH are allocated to paying UEs. When UEs have a large amount of data to be sent, the percentage of RBs allocated to free UEs and that allocated to paying UEs will reach the preset values. Changing this parameter affects the percentage of RBs allocated to free UEs and that to paying UEs. Modifying this parameter for an active cell will lead to cell re-setup. This parameter applies only to LTE TDD.

Maximum Number of MIMO Layers

Indicates the maximum number of layers (the rank) in the implementation of multiple-input multiple-output (MIMO) in DL scheduling. This parameter applies only to LTE FDD and LTE TDD.

Downlink CA Schedule Strategy

Indicates the downlink scheduling policy used when CA is applied, which can be basic scheduling or differentiated scheduling. (If CA is applied in the uplink, this parameter also indicates the uplink scheduling policy.) If the CA basic scheduling policy is adopted, the eNodeB calculates the proportional fair (PF) scheduling priority of each component carrier (CC) for a CA UE using the total data rates on both CCs of this CA UE. In this way, CA UEs and non-CA UEs can be allocated similar number of RBs. If the CA differentiated scheduling policy is adopted, the eNodeB calculates the PF scheduling priority of each CC for a CA UE using the data rate only on the primary component carrier (PCC) or secondary component carrier (SCC) of this CA UE. In this way, CA UEs can achieve better performance than non-CA UEs. This parameter applies only to LTE FDD and LTE TDD.

Reserved resource ratio for non-GBR services(%)

Indicates the proportion of resources reserved for non-GBR services. A proportion of resources is reserved periodically to prevent non-GBR services from failing to be allocated resources. During the periods when resources are reserved, resources are scheduled preferentially for non-GBR services. If this parameter is set to 0, resources are not reserved for non-GBR services. This parameter applies only to LTE FDD and LTE TDD.

Intra-Pole RRU Identification Period(day)

Indicates the interval at which intra-pole RRU identification is triggered for downlink offset pre-correction. When this parameter is set to 0, intra-pole RRU identification is not triggered periodically. This parameter applies only to LTE FDD and LTE TDD.

Downlink EPF capacity factor

Indicates the capacity factor for downlink enhanced proportional fair (EPF) scheduling. This factor affects the scheduling priorities of UEs running services with the QCI of 6, 7, 8, or 9, and accordingly can be used to adjust the cell capacity and fairness among users. This parameter applies only to LTE FDD and LTE TDD.

RB Priority MCS Select Ratio Threshold(%)

Indicates the selection ratio threshold for the function of lowering the modulation and coding scheme (MCS) index to increase the number of resource blocks (RBs) with priority for UEs running small-packet services. If the threshold of TTIs within which downlink scheduling is performed and RBs are surplus is less than this parameter value, the function is enabled. The value 0 indicates that the function is disabled. The value 100 indicates that the function is always enabled. This parameter applies only to LTE FDD and LTE TDD.

Cell Edge User RB Allocation Mode

Indicates the resource block (RB) allocation mode for cell edge users (CEUs) when downlink ICIC is enabled. If this parameter is set to ALL_EDGE_USER, RBs in the current transmission time interval (TTI) are first allocated to cell center users (CCUs) and then allocated to all CEUs. If this parameter is set to PART_EDGE_USER, RBs in the current TTI are first allocated to CCUs and then allocated to the CEUs to which RBs have not been allocated within this TTI. This parameter applies only to LTE FDD and LTE TDD.

Downlink ICIC Schedule Mode

Indicates the scheduling policy used when downlink ICIC is enabled. If this parameter is set to EDGE_USER_NO_PRIO, both cell center users (CCUs) and cell edge users (CEUs) can preempt edge bands, thereby improving CCUs' performance. If this parameter is set to EDGE_USER_PRIO, CCUs are scheduled at both the center band and the edge band only after CEUs have been scheduled at the edge band, and therefore CEUs' performance improves. This parameter applies only to LTE FDD and LTE TDD.

RBG Resource Allocation Strategy

For services whose QoS class identifier (QCI) is not 1:

When this parameter is set to ROUND_DOWN: (1) If the number of required resource block groups (RBGs) is less than 1, the actual required number of RBs are allocated to UEs in the current transmission time interval (TTI); (2) If the number of required RBGs is greater than N but less than N+1 (N is an integer greater than or equal to 1), N RBGs are allocated to UEs in the current TTI and the other required RBs are allocated to UEs in subsequent TTIs. Setting this parameter to ROUND_DOWN ensures full utilization of RBs, but increases scheduling times and decreases the downlink UE data rate.

When this parameter is set to ROUND_UP and the number of required RBGs is greater than N but less than N+1 (N is an integer greater than or equal to 0), N+1 RBGs are allocated to UEs in the current TTI. Setting this parameter to ROUND_UP wastes a few RBs, but decreases scheduling times and increases the downlink UE data rate.

When this parameter is set to ADAPTIVE: (1) If the number of required RBGs is less than 1, the actual required number of RBs are allocated to UEs in the current TTI; (2) If the number of required RBGs is greater than N but less than N+1 (N is an integer greater than or equal to 1), N+1 RBGs are allocated to UEs in the current TTI. Compared with setting this parameter to ROUND_UP, setting this parameter to ADAPTIVE avoids wasting RBs when the number of required RBGs is less than 1.

When this parameter is set to TYPE1_FIRST and the number of required RBs is less than or equal to the maximum number of RBs that can be allocated using resource allocation type 1, resource allocation type 1 is preferentially used to allocate RBs. If the conditions for using resource allocation type 1 are not met, the parameter value ADAPTIVE takes effect. This value applies only to LTE TDD.

For services whose QCI is 1 (such as VoIP services):

When this parameter is set to ROUND_DOWN: (1) If the number of required RBGs is less than 1, the actual required number of RBs are allocated to UEs in the current TTI; (2) If the number of required RBGs is greater than N but less than N+1 (N is an integer greater than or equal to 1), N+1 RBGs are allocated to UEs in the current TTI.

If this parameter is set to ROUND_UP or ADAPTIVE, RBs are allocated to UEs in the same way as they are allocated when this parameter is set to ROUND_UP or ADAPTIVE for non-QCI-1 services, respectively.

If this parameter is set to TYPE1_FIRST, RBs are allocated to UEs in the same way as they are allocated when this parameter is set to ADAPTIVE.

For ping services:

If this parameter is set to ROUND_DOWN, ROUND_UP, or ADAPTIVE and the number of required RBs is greater than N but less than N+1 RBGs (N is an integer greater than or equal to 0), N+1 RBGs are allocated to UEs in the current TTI.

If this parameter is set to TYPE1_FIRST, RBs are allocated to UEs in the same way as they are allocated when this parameter is set to TYPE1_FIRST for non-QCI-1 services.

This parameter applies only to LTE FDD and LTE TDD.

Intra-Pole RRU Identification Duration(h)

Indicates the maximum sampling duration in which intra-pole RRU identification is performed for downlink offset pre-correction. When this parameter is set to 0, intra-pole RRU identification is disabled. This parameter applies only to LTE FDD and LTE TDD.

Middle User Mcs Threshold

Indicates the MCS index threshold for determining UEs of medium distances from the cell center. The DL target IBLER for the determined UEs can be set by specifying a parameter. For a TDD cell, when the DlVarIBLERtargetSwitch option of the CqiAdjAlgoSwitch parameter is selected, the InitDlIblerTarget parameter in the CellCqiAdjAlgo MO can be used to specify the DL target IBLER only for UEs whose MCS index is less than or equal to this threshold. For an FDD or TDD cell, when the PreciseAmcSwitch option of the EmimoSwitch parameter is selected, the target IBLER is a fixed value (10%) for UEs whose MCS index is greater than this threshold. This parameter applies only to LTE FDD and LTE TDD.

Downlink Low Load SDMA Threshold Offset(dB)

Indicates the offset to the low load isolation threshold in the downlink of an adaptive SFN cell. The isolation is the ratio of the RSRP sum of working RRUs to the RSRP sum of non-working RRUs in an adaptive SFN cell. This parameter applies only to LTE FDD and LTE TDD.

Neighbor RRU Identification Threshold(%)

Indicates the threshold for determining that two RRUs are neighboring RRUs. The threshold is the ratio (expressed as a percentage) of the number of times that the target RRU changes between an RRU (for example, RRU A) and another specified RRU (for example, RRU B) in the uplink to the total number of times that the target RRU changes between RRU A and all other RRUs in the uplink. This parameter applies only to LTE FDD and LTE TDD.

Downlink HARQ Maximum Transmission Number

Indicates the maximum number of downlink hybrid automatic repeat request (HARQ) transmissions. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

NonGBR Traffic Delay Weight

Indicates the weight for scheduling non-GBR services with long scheduling delay. This parameter applies only to LTE FDD and LTE TDD.

Inter-Pole RRU Identification Threshold(%)

Indicates the threshold for determining that two RRUs are inter-pole RRUs. The eNodeB first obtains the percentage of times that the difference between the frequency offsets before and after a target RRU change from one RRU to the other RRU in the uplink is greater than a specified value and then compares this percentage with the threshold specified by this parameter. If the percentage is higher than this threshold, the two RRUs are determined as inter-pole RRUs. This parameter applies only to LTE FDD and LTE TDD.

RB Damage Cell Near Point User IBLER Thd

Indicates the IBLER threshold for determining cell-center UEs when certain RBs are unavailable, or the IBLER threshold for 4R UEs to perform rank 3 or 4 measurement when CA and MIMO cooperation, the algorithm of 4x4 MIMO in the overlapping areas of an SFN cell, or the algorithm of adaptively entering TM4 and TM9 modes is used. This parameter applies only to LTE FDD and LTE TDD.

Breathing Pilot Switch

BreathingPilotSwitch: Indicates whether to enable the Breathing Pilot function. This function is enabled only if this option is selected. This parameter applies only to LTE FDD and LTE TDD.

Handover UE Static MCS Scheduling Timer(ms)

Indicates the duration within which the eNodeB performs downlink scheduling based on a low modulation and coding scheme (MCS) order in handovers. The eNodeB starts this timer after determining that a UE has entered the handover area or has been handed over to the target cell. The eNodeB performs downlink scheduling based on a low MCS index during the running of this timer. After the timer expires, the eNodeB performs downlink scheduling based on a new MCS index after CQI adjustment. This parameter applies only to LTE FDD and LTE TDD.

Downlink Rank Optimize Switch

Indicates whether to perform downlink rank optimization. If this parameter is set to OFF, the eNodeB uses the rank received from a UE to schedule the UE. If the baseband processing unit determines that the received rank is unsuitable for UE scheduling, the eNodeB schedules the UE based on rank 1. If this parameter is set to ON, the eNodeB optimizes the received rank and schedules the UE based on the optimized rank. If the baseband processing unit determines that the received rank is unsuitable for UE scheduling, the eNodeB does not optimize the received rank and schedules the UE based on the rank used last time. This parameter applies only to LTE FDD and LTE TDD.

Ca Scc Doppler Measurement

Indicates the method for measuring the Doppler frequency offset that is applied to frequency selective scheduling on the secondary component carrier (SCC) in carrier aggregation (CA). If this parameter is set to FROMSCC, the Doppler frequency offset is measured on the SCC. If this parameter is set to FROMPCC, the Doppler frequency offset is measured on the primary component carrier (PCC) no matter whether the SCC is configured with an uplink carrier, and then Doppler frequency offset on the SCC is determined based on the Doppler frequency offset measured on the PCC and downlink frequencies of the PCC and SCC. This parameter applies only to LTE FDD and LTE TDD.

Downlink Semi-persistent Scheduling Interval

Indicates the downlink semi-persistent scheduling interval. If this parameter is set to ms20(20ms) or ms40(40ms), a fixed interval of 20 ms or 40 ms is used. If this parameter is set to ADAPTIVE, the eNodeB adaptively uses the interval of 20 or 40 ms. The value ADAPTIVE takes effect only for TDD eNodeBs.

FDD eNodeBs support a fixed interval of 20 ms or 40 ms. If this parameter is set to ADAPTIVE for FDD eNodeBs, the actually effective value is ms20(20ms). This parameter applies only to LTE FDD and LTE TDD.

RB Priority MCS Select Strategy

Indicates how to apply the policy of increasing the number of resource blocks (RBs) to lower the modulation and coding scheme (MCS) index. If this parameter is set to SINGLEUSER_STRATEGY, the policy is applied to a single RRC_CONNECTED UE whose capability is limited (Maximum number of DL-SCH transport block bits received within a TTI of the UE is less than the maximum TBS with the total number of PRBs). The policy is applied to a single service when the following conditions are met within a measurement period: (1) This parameter is set to SINGLEUSER_STRATEGY; (2) The service is the only service to be scheduled in the cell; (3) The proportion of the transmission time intervals (TTIs) in which RBs are expected to be surplus is less than a specified threshold. If this parameter is set to MULTIUSER_STRATEGY, the policy is applied to the last capability-limited UE to be scheduled. If this parameter is set to MULTIUSER_STRATEGY and the proportion of TTIs in which RBs are expected to be surplus is less than a specified threshold within a measurement period, the policy is applied to the last UE to be scheduled. If this parameter is set to MULTIUSR_LOWMCSLIMIT_STRATEGY, the policy is applied to the last capability-limited UE to be scheduled. If this parameter is set to MULTIUSR_LOWMCSLIMIT_STRATEGY and the proportion of TTIs in which RBs are expected to be surplus is less than a specified threshold within a measurement period, the policy is applied to the last UE to be scheduled, and the MCS index decreases by a maximum of 3. This parameter applies only to LTE FDD and LTE TDD.

Downlink Rank Detect Switch

Indicates whether to perform rank detection.

DetectRank2AdjSwitch: If this option is deselected, the eNodeB does not perform rank 2 detection for UEs reporting rank 1. In this case, the eNodeB performs single-codeword scheduling. If this option is selected: (1) The eNodeB performs rank 2 detection upon reception of rank 1 reported by any UEs if the UE whitelist has not been configured. (2) The eNodeB performs rank 2 detection only upon reception of rank 1 reported by whitelisted UEs if configured. The StartRankDetectEffThd parameter in the CellDlschAlgo MO, the StartRankDetectCntThd parameter in the CellDlschAlgo MO, the RankDetectSuccessCntThd parameter in the CellDlschAlgo MO, and the RankReverseDetectCntThd parameter in the CellDlschAlgo MO take effect only when the DetectRank2AdjSwitch option is selected.

DetectRank1AdjSwitch: If this option is deselected, the eNodeB does not perform rank 1 detection for UEs reporting rank 2. In this case, the eNodeB performs dual-codeword scheduling. If this option is selected, the eNodeB performs rank 1 detection for UEs reporting rank 2. This option applies only to LTE TDD. The setting of this option does not take effect for LTE FDD but takes effect for LTE TDD.

BfDetectRank1AdjSwitch: If this option is deselected, the eNodeB switches between the single-stream beamforming and dual-stream beamforming modes based on the spectral efficiency. If this option is selected, the eNodeB attempts to switch to the single-stream beamforming mode when it is in dual-stream beamforming mode. This option applies only to LTE TDD.

MBSFN Subframe Configuration

Indicates whether to configure Multimedia Broadcast multicast service Single Frequency Network (MBSFN) subframes. The ten options of this parameter map to the ten MBSFN subframes. If an option is selected, the corresponding subframe is configured. If an option is not selected, the corresponding subframe is not configured. PDSCH services with enhanced MIMO applied can be scheduled on configured MBSFN subframes. This parameter applies only to LTE FDD and LTE TDD.

Data Threshold In Pdcch And Pdsch Balance(bit)

Indicates the traffic volume threshold for determining a bearer as one with large packets in the PDCCH and PDSCH resource allocation optimization mechanism. If this parameter is set to 0, the optimization mechanism does not take effect. If this parameter is set to a non-zero value, a bearer is determined as one with large packets when the amount of to-be-scheduled data for the bearer is greater than or equal to this value. If the amounts of to-be-scheduled data for all bearers are less than the value of this parameter, the bearer with the largest amount of to-be-scheduled data among all bearers is selected as the one with large packets. This parameter applies only to LTE FDD and LTE TDD.

Ue Num Threshold In Pdcch And Pdsch Balance

Indicates the threshold of the number of synchronized UEs in a cell for activating the PDCCH and PDSCH resource allocation optimization mechanism in large traffic volume scenarios. If this parameter is set to a value ranging from 0 to 10000 (indicating a threshold from 0 UEs to 10000 UEs), the mechanism is activated when the number of synchronized UEs in the cell is greater than or equal to this parameter value. This parameter applies only to LTE FDD and LTE TDD.

eNodeB Interference Randomize Modular

Indicates the modulus for calculating the first resource block (RB) to be scheduled based on interference randomization. This parameter applies only to LTE FDD and LTE TDD.

TxD DCI1A Scheduling Switch

Indicates whether the DCI1A format is used for downlink grant scheduling for UEs in transmit diversity mode. If this parameter is set to ON(On) and the UE in transmit diversity mode requires single-codeword scheduling, the DCI1A format can be used for downlink grant scheduling, which increases the DCI1A coverage area. If this parameter is set to OFF(Off), the downlink grant scheduling is performed in default mode. This parameter applies only to LTE FDD and LTE TDD.

Downlink Schedule Abnormal Ue Threshold

Indicates the threshold for the number of consecutive discontinuous transmissions (DTXs) in the downlink above which the eNodeB stops scheduling the abnormal UE. The parameter value range is from 6 to 120. This parameter applies only to LTE FDD and LTE TDD.

Code Rate for Random Access Response and Paging Message

Indicates the code rate for Random Access Response messages and paging messages. This parameter applies only to LTE FDD and LTE TDD.

CQI Adjustment Initial Step

Indicates the initial step in which channel quality indicators (CQIs) are adjusted for UEs that initially access or are handed over to the network through an incoming handover. If the periodically measured initial block error rate (IBLER) exceeds the IBLER threshold, the CQI adjustment step is changed to its default value 0.1. This parameter applies only to LTE FDD and LTE TDD.

CSI-RS Subframe Scheduling Strategy Switch

Indicates the scheduling policy of CSI-RS subframes.

UnCfgCsiRsUESchSwitch: Indicates whether UEs for which CSI-RSs are not configured can be scheduled in CSI-RS subframes. These UEs can be scheduled in these subframes only when this option is selected. UEs for which CSI-RSs are not configured refer to the CSI-RSs that cannot identify CSI-RSs transmitted in the CSI-RS subframes. This option applies only to LTE TDD.

UnCfgCsiRsUEDeOrderSchSwitch: Indicates whether UEs for which CSI-RSs are not configured can be scheduled in CSI-RS subframes using the MCS index decreasing policy. SRB1 Scheduling Enhancement Switch

Indicates whether to continue delivering RRC Connection Release signaling carried by SRB1 when the number of SRB1 retransmissions has reached the maximum at the RLC layer. If this parameter is set to OFF, the eNodeB stops SRB1 scheduling and no longer delivers the RRC Connection Release signaling when the number of SRB1 retransmissions has reached the maximum at the RLC layer. If this parameter is set to ON, the eNodeB continues SRB1 scheduling and delivers RRC Connection Release signaling when the number of SRB1 retransmissions has reached the maximum at the RLC layer. This parameter applies only to LTE FDD and LTE TDD.

Max Number of Aperiodic CSI Reporting

Indicates the allowed maximum number of aperiodic CSI reporting times per second when the CSI feedback enhancement function is used. This parameter applies only to LTE FDD.

UE Proportion with Increased DL SCH Priority(%)

Indicates the proportion of UEs (running small-packet services) for which the downlink scheduling priority is raised during inter-cell D-MIMO and massive MIMO. The value 0 indicates that the eNodeB does not raise the downlink scheduling priority for any UEs. This parameter applies only to LTE TDD.

MCG High Load Threshold(%)

Indicates the high-load threshold of MCG cells. If the load of an MCG cell is higher than this threshold, the eNodeB takes a downlink scheduling protection measure for NSA UEs in this MCG cell by decreasing the scheduling priority of non-GBR services to the lowest level for these UEs. This parameter applies only to LTE FDD and LTE TDD.

EPF Enhanced Scheduling Optimization Switch

Indicates whether to optimize EPF enhanced scheduling. If this parameter is set to ON, the eNodeB optimizes the scheduling to promptly update the scheduling priorities of UEs that treat the cell as an SCell in inter-BBP CA. If this parameter is set to OFF, the eNodeB does not optimize the scheduling. This parameter applies only to LTE FDD and LTE TDD.

Downlink Joint AMC Algorithm Switch

Indicates whether to enable downlink joint AMC.

DL_INTRA_JAMC_ALGO_SW: Indicates whether to enable intra-board downlink joint AMC. If this option is selected, intra-board downlink joint AMC is enabled. If this option is deselected, intra-board downlink joint AMC is disabled. This option applies only to LTE TDD.

DL 2D FSS User Data Volume Thld(kbit)

Indicates the downlink data volume threshold for identifying large-packet UEs for two-dimensional frequency selective scheduling. If the to-be-scheduled downlink data volume of a UE is greater than or equal to this threshold, the UE will be identified as a large-packet UE for two-dimensional frequency selective scheduling. This parameter applies only to LTE FDD.

Upper Limit on PDSCH Code Rate

Indicates the upper limit on the PDSCH code rate for special UEs. If the CODE_RATE_RISE_SWITCH_ON option of the WhiteLstCtrlSwitch parameter in the UeCompat MO is selected, the maximum code rate specified by the PdschCodeRateUpperLimit parameter is used for special UEs. If this option is deselected, the rate specified by the PdschMaxCodeRate parameter in the CellDlschAlgo MO is used for special UEs. This parameter applies only to LTE FDD and LTE TDD.

RB Priority MCS Select Max Decrease in TBS Index

Indicates the maximum decrease in the TBS index when the policy of MCS selection with prioritized RBs is single-user policy or multi-user policy. If this parameter is set to 255, the optimized algorithm for MCS selection with prioritized RBs does not take effect. If this parameter is set to a value other than 255, the value indicates the maximum decrease in the TBS index when the single-user policy or multi-user policy is used. If the InterfRandSwitch parameter in the CellAlgoSwitch MO is set to ENB_BASED, the range of RBs for which the index can be reduced will be restricted under the three policies of MCS selection with prioritized RBs. If the InterfRandSwitch parameter in the CellAlgoSwitch MO is set to OFF, the range of RBs for which the index can be reduced will not be restricted. This parameter applies only to LTE FDD and LTE TDD.

Edge Beam Threshold

Indicates the edge beam range threshold for a massive MIMO cell. The range of horizontal beams approaching the edge of a massive MIMO cell that is smaller than this threshold indicates the range of edge beams. The value 255 indicates that this parameter does not take effect. This parameter applies only to LTE TDD.

Downlink Min Expected Bit Rate(kbps)

Indicates the expected minimum downlink rate when equivalent Max C/I is used as the scheduling policy. If this parameter is set to 65535, equivalent Max C/I cannot be used as the scheduling policy.

This parameter applies only to LTE FDD and LTE TDD.

Adaptive Pilot Off PRB Thld(%)

Indicates the downlink PRB usage threshold for dynamically adjusting the CRS transmission disabling policy. If the downlink PRB usage of the cell is less than or equal to this threshold, the CRS transmission disabling policy can be dynamically adjusted. If the downlink PRB usage of the cell is greater than the sum of this threshold and the corresponding offset, the CRS transmission disabling policy cannot be dynamically adjusted. When this parameter is set to 0, the function does not take effect. This parameter applies only to LTE FDD.
