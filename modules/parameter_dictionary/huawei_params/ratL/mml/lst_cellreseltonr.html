List Configuration of Cell Reselection to NR (LST CELLRESELTONR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters about cell reselection to NR.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters of the NR cell reselection with the local cell ID of 1, run the following command:
LST CELLRESELTONR: LocalCellId=1;
The result is shown as follows:
+++    HUAWEI        2018-06-08 12:37:15
O&M    #12239
%%LST CELLRESELTONR: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List Cell lInterfSuppressCfg Configuration
----------------------
               Local cell ID  =  0
NR Cell Reselection Timer(s)  =  2

(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

NR Cell Reselection Timer(s)

Indicates the timer used for NR cell reselection. A UE initiates NR cell reselection if the signal quality of the serving cell and that of the NR cell constantly meet reselection threshold requirements before the timer expires and the UE has stayed in the serving cell for more than one second. This parameter applies only to LTE FDD and LTE TDD.
