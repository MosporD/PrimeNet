List Cell Interference Control Parameter (LST CELLINTRFCTRLPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of interference control parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the interference control parameter of the cell with Local cell ID of 1, run the following command:
LST CELLINTRFCTRLPARAM: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.

Downlink RB Allocation Direction

Indicates the RB allocation direction. If this parameter is set to HIGH_TO_LOW, RB allocation starts from the high end of the frequency band. If this parameter is set to LOW_TO_HIGH, RB allocation starts from the low end of the frequency band. This parameter applies only to LTE FDD.

High Intrf State Duration(s)

Indicates the duration in which the cell is in the high interference state. This parameter applies only to LTE FDD.

High Intrf State DL RB Usage Threshold(%)

Indicates the upper limit to the downlink wideband RB usage when the cell is in the high interference state. In this cell, the downlink RB usage in each TTI cannot exceed this limit. This parameter applies only to LTE FDD.

Low Intrf State Duration(s)

Indicates the duration in which the cell is in the low interference state. This parameter applies only to LTE FDD.

Low Intrf State DL RB Usage Threshold(%)

Indicates the upper limit to the downlink wideband RB usage when the cell is in the low interference state. In this cell, the downlink RB usage in each TTI cannot exceed this limit. This parameter applies only to LTE FDD.
