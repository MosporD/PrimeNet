Add PIM Frequency Group (ADD PIMFREQGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a PIM frequency group.

Note

PIM may not work under the configuration of PIMFreqGroup when MML Command "STR VSWRTEST", "STR RFTEST", or "ADD CELLSIMULOAD" was executed before. When RF Unit VSWR Threshold Crossed (ALM-26529) caution exists, PIM function will be delayed under the configuration of PIMFreqGroup. Please Check RF Unit VSWR Threshold Crossed caution before executing this command.

Parameters

ID Name Description
PimFreqGroupId PIM Frequency Group ID

Meaning: Indicates the ID of a passive intermodulation (PIM) frequency group. It uniquely identifies a PIM frequency group within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PimMitigationMode PIM Mitigation Mode

Meaning: Indicates the PIM mitigation mode. This parameter applies only to LTE FDD.

GUI Value Range: BASED_ON_PHY_ALGO(BASED_ON_PHY_ALGO), BASED_ON_JOINT_SCH(BASED_ON_JOINT_SCH)

Unit: None

Actual Value Range: BASED_ON_PHY_ALGO, BASED_ON_JOINT_SCH

MML Default Value: BASED_ON_PHY_ALGO(BASED_ON_PHY_ALGO)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To add a PIM frequency point group with the parameters as follows: PimFreqGroupId: 0, run the following command:
ADD PIMFREQGROUP: PimFreqGroupId=0;
