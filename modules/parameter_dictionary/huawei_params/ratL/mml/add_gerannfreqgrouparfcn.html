Add Neighboring GERAN ARFCN (ADD GERANNFREQGROUPARFCN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a GERAN ARFCN to a neighboring GERAN carrier frequency group.

Note

  • A maximum of 31 neighboring GERAN ARFCNs can be configured under each neighboring GERAN carrier frequency group of an E-UTRAN cell. A maximum of 64 neighboring GERAN ARFCNs can be configured for each E-UTRAN cell, including the first GERAN ARFCNs and other GERAN ARFCNs in the neighboring GERAN carrier frequency groups.

  • Before running this command, ensure that the associated neighboring GERAN carrier frequency group has been configured.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BcchGroupId BCCH group ID

Meaning: Indicates the index of the BCCH carrier frequency group. It identifies a BCCH carrier frequency group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GeranArfcn GERAN ARFCN

Meaning: Specifies the ARFCN of the GERAN BCCH. If the GERAN ARFCN value is not between 512 and 810, one ARFCN can only in one frequency band. For details about this parameter, see 3GPP TS 45.005. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add a GERAN ARFCN with the parameters as follows: Local cell ID: 0, BCCH group ID: 0, GERAN ARFCN: 1, run the following command:
ADD GERANNFREQGROUPARFCN: LocalCellId=0, BcchGroupId=0, GeranArfcn=1;
Example 2: To add a GERAN ARFCN with the parameters as follows: Local cell ID: 0, BCCH group ID: 0, GERAN ARFCN: 2, run the following command:
ADD GERANNFREQGROUPARFCN: LocalCellId=0, BcchGroupId=0, GeranArfcn=2;
