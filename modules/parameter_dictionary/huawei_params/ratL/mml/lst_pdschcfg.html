List PDSCH Configuration (LST PDSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the PDSCH configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the PDSCH configurations:
LST PDSCHCFG: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Reference signal power(0.1dBm)

Indicates the cell reference signal power of each physical antenna (the precision of converting dBm to mW is 0.01 mW). However, the cell reference signal power delivered in SIB2 is that of each logical antenna. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of this parameter is changed, the eNodeB will proactively release eMTC UEs that have already accessed the cell. For FDD 8T8R and 32T32R cells, this parameter indicates the cell reference signal power of each logical antenna.

PB

Indicates the scaling factor index of the Energy Per Resource Element (EPRE) on the PDSCH. This scaling factor is determined by the value of this parameter and the antenna port. For details, see 3GPP TS 36.213. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of this parameter is changed, eMTC UEs that already accessed the cell will be proactively released.

Reference Signal Power Margin(0.1dB)

Indicates the cell reference signal power headroom of each physical antenna. This parameter applies only to LTE TDD.

Offset of Ant0 to Tx Power(0.1dB)

Indicates the offset of the TX power of physical channel 0 relative to the baseline TX power. The baseline TX power is determined by the system bandwidth, cell reference signal power, Pa, and Pb. If the TX power configurations should be the same between physical channels, set this parameter to 255. If the TX power configurations should be different between physical channels, set this parameter to a proper value based on the actual situation. This parameter applies only to FDD.

Offset of Ant1 to Tx Power(0.1dB)

Indicates the offset of the TX power of physical channel 1 relative to the baseline TX power. The baseline TX power is determined by the system bandwidth, cell reference signal power, Pa, and Pb. If the TX power configurations should be the same between physical channels, set this parameter to 255. If the TX power configurations should be different between physical channels, set this parameter to a proper value based on the actual situation. This parameter applies only to FDD.

Offset of Ant2 to Tx Power(0.1dB)

Indicates the offset of the TX power of physical channel 2 relative to the baseline TX power. The baseline TX power is determined by the system bandwidth, cell reference signal power, Pa, and Pb. If the TX power configurations should be the same between physical channels, set this parameter to 255. If the TX power configurations should be different between physical channels, set this parameter to a proper value based on the actual situation. This parameter applies only to FDD.

Offset of Ant3 to Tx Power(0.1dB)

Indicates the offset of the TX power of physical channel 3 relative to the baseline TX power. The baseline TX power is determined by the system bandwidth, cell reference signal power, Pa, and Pb. If the TX power configurations should be the same between physical channels, set this parameter to 255. If the TX power configurations should be different between physical channels, set this parameter to a proper value based on the actual situation. This parameter applies only to FDD.

TX Channel Power Config Switch

Indicates whether to enable algorithms related to transmit channel power configurations.

SINGLE_CA_PWR_SHARE_SW_FOR_4T: Indicates whether to enable single carrier power sharing for 4T. This option applies only to LTE FDD.

Cell Power Limit(0.01W)

Indicates the maximum transmit power of a single channel for a cell. If this parameter is set to 0, the maximum transmit power of a single channel for the cell is not limited. If this parameter is set to a value other than 0, the maximum transmit power of a single channel for the cell is limited. In this case, the eNodeB controls the number of scheduling resources to ensure that the power of a single channel does not exceed the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

EMF Power Limit Switch

Indicates whether to enable the on-demand TX power allocation under EME. If this parameter is set to ON, the maximum transmit power of a cell is limited by an EME policy. In this case, the eNodeB controls scheduling resources to ensure that the cell power does not exceed the preset limit. This parameter applies only to LTE FDD and LTE TDD.

CRS Power Boosting Amplitude

Indicates the amount of increase in cell-specific reference signal (CRS) power.

If this parameter is set to DB_0, the CRS power will not increase.

If this parameter is set to DB_1DOT77, the CRS power will increase by 1.77 dB.

If this parameter is set to DB_3, the CRS power will increase by 3 dB.

This parameter applies only to LTE FDD.

Logical Port Swap Switch

Indicates whether to change the mapping between logical antenna ports and physical channels.

If this parameter is set to OFF, the mapping between logical antenna ports and physical channels, which is specified by the CrsPortMap parameter in the Cell MO, cannot be changed.

If this parameter is set to SWAP_MODE_1, the physical TX channels corresponding to logical antenna ports 0 and 2 are swapped, and the physical TX channels corresponding to logical antenna ports 1 and 3 are swapped.

This parameter applies only to logical cells configured with four logical CRS ports. This parameter applies only to LTE FDD.

PDSCH Power Boosting Switch

Indicates whether to enable PDSCH power boosting. If this parameter is set to ON, PDSCH power boosting for TM9 UEs will be enabled. If this parameter is set to OFF, PDSCH power boosting will not be enabled. This parameter applies only to LTE FDD.
