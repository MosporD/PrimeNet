Modify Ue Cooperation Para (MOD UECOOPERATIONPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-level parameters related to UE cooperation.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

A modification to the MacCeMsgLCID parameter will result in automatic reset of the cell.

MacCeMsgLCID LCID of MAC CE Message

Meaning: Indicates the reserved LCID used by a Media Access Control control element (MAC CE) message. An eNodeB converts the specified value of this parameter to an enumerated value and then sends the enumerated value to the UE. The UE converts the received enumerated value back to the specified value of this parameter (that is, the actual reserved LCID). If this parameter is set to 17, 18, or 19, an eNodeB coverts the value to 1, 2, or 3, respectively. This parameter applies only to LTE FDD and LTE TDD.

This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates whether to allow UE-triggered power saving. If this parameter is set to ON, functions such as UE-triggered DRX parameter configuration and fast entering into the idle state are supported to save UE power. If this parameter is set to OFF, UE-triggered power saving functions are not supported. This parameter takes effect only on UEs that support UE-triggered power saving functions. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON and there are UEs supporting UE-triggered power saving on the network, power of such UEs is saved, but service delay is increased if the long DRX cycle is long. Setting this parameter to OFF does not affect network performance.

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the threshold for disabling power saving coordination for a UE. If the number of MAC CE messages sent by a UE within 10s exceeds this threshold, power saving coordination will be disabled for the current connection of the UE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~50

Actual Value Range: 2~50

Recommended Value: 6

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, there is a high probability that UE-triggered power saving functions will become invalid, but the impact on system signaling decreases. If this parameter is set to a large value, the impact on system signaling may increase.

Applicable Mode: L-FDD, L-TDD
SpecUserCooperationSwitch Specified User Cooperation Switch

Meaning: Indicates whether to enable device-pipe synergy functions for specific UEs and support for high-power UEs.

SpecUeIdentifySwitch: Indicates whether to identify specific UEs. If this option is selected, specific UEs can be identified in the cell. If this option is deselected, specific UEs cannot be identified in the cell.

HighPowerUeSupportSwitch: Indicates whether the cell can serve high-power UEs. If this option is selected, the cell can serve high-power UEs. If this option is deselected, the cell cannot serve high-power UEs.

UlAntennaSmartSelectSwitch: Indicates whether to enable intelligent selection of antennas for the uplink. If this option is selected, intelligent selection of antennas for the uplink is enabled in the cell. If this option is deselected, intelligent selection of antennas for the uplink is disabled in the cell. This option applies only to LTE TDD.

UlQosEnhancementSwitch: Indicates whether to enable uplink QoS enhancement. If this option is selected, uplink QoS enhancement is enabled in the cell. If this option is deselected, uplink QoS enhancement is disabled in the cell. This option applies only to LTE FDD and LTE TDD.

UlClosedloopIntelAntSelSwitch: Indicates whether to enable intelligent uplink closed-loop antenna selection. If this option is selected, intelligent uplink closed-loop antenna selection is supported in the cell. If this option is deselected, intelligent uplink closed-loop antenna selection is not supported in the cell. This option applies only to LTE TDD.

Tm9Port5Switch: Indicates whether to allow the use of port 5 for data transmission in TM9. If this option is selected, antenna port 5 can be allocated for data transmission in TM9. If this option is deselected, antenna port 5 cannot be allocated for data transmission in TM9. This option applies only to LTE TDD.

GUI Value Range: SpecUeIdentifySwitch(SpecUeIdentifySwitch), HighPowerUeSupportSwitch(HighPowerUeSupportSwitch), UlAntennaSmartSelectSwitch(UlAntennaSmartSelectSwitch), UlQosEnhancementSwitch(UlQosEnhancementSwitch), UlClosedloopIntelAntSelSwitch(UlClosedloopIntelAntSelSwitch), Tm9Port5Switch(Tm9Port5Switch)

Unit: None

Actual Value Range: SpecUeIdentifySwitch, HighPowerUeSupportSwitch, UlAntennaSmartSelectSwitch, UlQosEnhancementSwitch, UlClosedloopIntelAntSelSwitch, Tm9Port5Switch

MML Default Value: None

Recommended Value: SpecUeIdentifySwitch:Off, HighPowerUeSupportSwitch:Off, UlAntennaSmartSelectSwitch:Off, UlQosEnhancementSwitch:Off, UlClosedloopIntelAntSelSwitch:Off, Tm9Port5Switch:Off

Parameter Relationship:

-Configuration constraints:

  • HighPowerUESupportSwitch option of SpecUserCooperationSwitch parameter in a UeCooperationPara MO can be selected only if the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch in the UeCooperationPara MO is selected.
  • The UlAntennaSmartSelectSwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO can be selected only when the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.
  • When the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in a UeCooperationPara MO is selected, the VoltePagingPriority parameter in the UeCooperationPara MO can be set to a value other than OFF.
  • The SpecUserSmartDrxSwitch parameter in the UeCooperationPara MO can be set to ON only when the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SpecUeIdentifySwitch: This option controls the basic function for enhanced device-pipe synergy functions. If this option is selected, the eNodeB broadcasts UE-specific identification information through system information, slightly increasing the downlink RB usage. If this option is deselected, enhanced device-pipe functions are disabled, and network performance is not affected.

HighPowerUeSupportSwitch: If this option is selected, the maximum transmit power of specific UEs increases. As a result, the uplink throughput of these specific UEs increases, but the uplink IoT also slightly increases. If this option is deselected, support for high-power UEs is disabled, and the uplink throughput of such UEs cannot be improved.

UlAntennaSmartSelectSwitch: If this option is selected, the uplink signal quality of specific UEs can be improved, and the uplink throughput of such specific UEs can be improved. If this option is deselected, intelligent selection of transmit antennas is disabled, and the uplink signal quality cannot be improved for specific UEs.

UlQosEnhancementSwitch: If this option is selected, VoLTE quality can be improved for indoor UEs in LampSite Libero scenarios. If this option is deselected, uplink QoS enhancement is disabled in LampSite Libero scenarios, and VoLTE quality cannot be improved for indoor UEs in such scenarios.

UlClosedloopIntelAntSelSwitch: If this option is selected, the eNodeB selects the antenna with the best signal quality as the uplink transmit antenna based on the uplink signal quality of each antenna of a specific UE, improving the uplink throughput of this UE. If this option is deselected, intelligent uplink closed-loop antenna selection does not take effect, affecting uplink signal quality improvement for specific UEs.

Tm9Port5Switch: If this option is selected, antenna port 5 can be used for data transmission in TM9 for specific UEs, increasing the throughput of these UEs. If this option is deselected, antenna port 5 cannot be used for data transmission in TM9 for specific UEs, preventing throughput increase for these UEs.

Applicable Mode: L
DsdsCooperationRptSwitch DSDS Cooperation Reporting Switch

Meaning: Indicates whether to enable algorithms of the coordinated control feature for dual-SIM dual-standby (DSDS) single-pass UEs. DSDS_STATUS_RPT_SWITCH: Indicates whether to allow DSDS UEs to timely report information about leaving and returning to the LTE network. If this option is selected, such UEs can report MCEs containing information about leaving and returning to the LTE network. If this option is deselected, such UEs cannot report MCEs containing information about leaving and returning to the LTE network. This option applies to LTE FDD and LTE TDD.

SCELL_ABNORMAL_RPT_SWITCH: Indicates whether to allow UEs to report abnormal SCCs. If this option is selected, the eNodeB allows UEs to report abnormal SCC status and sends an MCE for SCell deactivation to UEs to synchronize the SCC status between the eNodeB and UEs. If this option is deselected, the eNodeB does not allow UEs to report abnormal SCC status. This option applies to LTE FDD and LTE TDD.

TA_ABNORMAL_RPT_SWITCH: Indicates whether to allow UEs to report abnormal TAs. If this option is selected, the eNodeB allows UEs to report abnormal TAs and triggers the resynchronization process. If this option is deselected, the eNodeB does not allow UEs to report abnormal TAs. This option applies to LTE FDD and LTE TDD.

GUI Value Range: DSDS_STATUS_RPT_SWITCH(DSDS_STATUS_RPT_SWITCH), SCELL_ABNORMAL_RPT_SWITCH(SCELL_ABNORMAL_RPT_SWITCH), TA_ABNORMAL_RPT_SWITCH(TA_ABNORMAL_RPT_SWITCH)

Unit: None

Actual Value Range: DSDS_STATUS_RPT_SWITCH, SCELL_ABNORMAL_RPT_SWITCH, TA_ABNORMAL_RPT_SWITCH

MML Default Value: None

Recommended Value: DSDS_STATUS_RPT_SWITCH: Off, SCELL_ABNORMAL_RPT_SWITCH: Off, TA_ABNORMAL_RPT_SWITCH: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DSDS_STATUS_RPT_SWITCH: If this option is selected, the eNodeB uses more RBs to transmit SIB1, reducing the number of available RBs in the cell. This may lower the downlink cell throughput. However, the eNodeB can be promptly informed of the time a UE leaves and returns to the LTE network, facilitating the stop and recovery of scheduling and measurement. This increases the CQI, RI, and DMRS measurement accuracy and the downlink throughput of DSDS UEs. If this option is deselected, UEs cannot send information about leaving and returning to the LTE network to the eNodeB, hindering the stop and recovery of scheduling and measurement. In this case, both the cell throughput and CQI, RI, and DMRS measurement accuracy decrease.

SCELL_ABNORMAL_RPT_SWITCH: If this option is selected, the eNodeB can resend an MCE for SCell deactivation to the UE when the SCC status on the UE side is inconsistent with that on the eNodeB side, ensuring SCC status consistency between the two sides and lowering the bit error rate on the SCC. If this option is deselected, the eNodeB cannot recover the SCC status when it is inconsistent between the eNodeB and UEs, increasing the bit error rate on the SCC.

TA_ABNORMAL_RPT_SWITCH: If this option is selected, the eNodeB allows UEs to report abnormal TAs and triggers the resynchronization process, avoiding deterioration in demodulation performance. If this option is deselected, UEs cannot report abnormal TAs, which causes deterioration in demodulation performance.

Applicable Mode: L-FDD, L-TDD

SpecUserSmartDrxSwitch Special User Smart DRX Switch

Meaning: Indicates whether to enable the power-saving function for specific UEs capable of device-pipe synergy. When this parameter is set to ON, smart DRX for such UEs is supported, reducing power consumption of these UEs. When this parameter is set to OFF, smart DRX is not supported for these UEs. This function requires support from specific UEs capable of device-pipe synergy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

-Configuration constraints:

  • The SpecUserSmartDrxSwitch parameter in the UeCooperationPara MO can be set to ON only when the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in the UeCooperationPara MO is selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, specific UEs capable of smart DRX on the network can save power, but the service delay extends when the long DRX cycle is set to a large value. If this parameter is set to OFF, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
VoltePagingPriority VoLTE Paging Priority

Meaning: Indicates whether to enable VoLTE marking in PS paging and the paging priority for VoLTE UEs. If this parameter is set to OFF, PS paging call flag addition is disabled. If this parameter is set to a value other than OFF, PS paging call flag addition is enabled. For the value range, see the definition of the paging priority IE in 3GPP TS 36.413. If PS paging call flag addition is enabled, the eNodeB identifies the paging priority of VoLTE services in S1 paging messages, and uses an extended bit in paging messages sent over the air interface to inform UEs of VoLTE paging. Then, UEs send the mo-VoiceCall-v1280 IE during network access. The eNodeB interprets this IE and handles these services by following the procedure for preferential access of mobile-originated VoLTE services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PRIORITY_LEVEL_1(PRIORITY_LEVEL_1), PRIORITY_LEVEL_2(PRIORITY_LEVEL_2), PRIORITY_LEVEL_3(PRIORITY_LEVEL_3), PRIORITY_LEVEL_4(PRIORITY_LEVEL_4), PRIORITY_LEVEL_5(PRIORITY_LEVEL_5), PRIORITY_LEVEL_6(PRIORITY_LEVEL_6), PRIORITY_LEVEL_7(PRIORITY_LEVEL_7), PRIORITY_LEVEL_8(PRIORITY_LEVEL_8), OFF(OFF)

Unit: None

Actual Value Range: PRIORITY_LEVEL_1, PRIORITY_LEVEL_2, PRIORITY_LEVEL_3, PRIORITY_LEVEL_4, PRIORITY_LEVEL_5, PRIORITY_LEVEL_6, PRIORITY_LEVEL_7, PRIORITY_LEVEL_8, OFF

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship:

-Configuration constraints:

  • When the SpecUeIdentifySwitch option of the SpecUserCooperationSwitch parameter in a UeCooperationPara MO is selected, the VoltePagingPriority parameter in the UeCooperationPara MO can be set to a value other than OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value other than OFF and the UE supports PS paging call flag addition, the eNodeB optimizes procedures such as admission, scheduling, and flow control for identified VoLTE paging. This increases the VoLTE call success rate but also the service drop rate of UEs running data services. If the UE is experiencing weak coverage, the VoLTE quality is poor, and the voice packet loss rate increases. The UE includes mo-VoiceCall-v1280, instead of mt-Access, as the establishment cause in the RRC Connection Request message. The values of the L.Paging.UU.Succ and L.RRC.ConnReq.Msg.Mt counters decrease, and that of the L.RRC.ConnReq.Msg.MoVoiceCall counter increases. Since the eNodeB uses an extended bit during paging, the paging overhead increases, and the downlink cell throughput slightly decreases.

Applicable Mode: L-FDD, L-TDD

Example

To modify the UE CooperationPara with the parameters as follows: Local cell ID: 0:the event A2 threshold offset :dB6, the event A3 threshold offset:dB5, run the following command:
MOD UECOOPERATIONPARA: LocalCellId=0, A2Offset=dB6, A3Offset=dB5;
