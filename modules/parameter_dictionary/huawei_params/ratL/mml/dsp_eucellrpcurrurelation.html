Display Relationship Between RPCU and RRU (DSP EUCELLRPCURRURELATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the pairing relationship between radio phase calibration unit (RPCU) and RRU.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To display the pairing relationship between RPCU and RRU, run the following command:
DSP EUCELLRPCURRURELATION: LocalCellId=1;
The result is shown as follows:
+++    0        2020-05-06 09:46:07
O&M    #806355192
%%DSP EUCELLRPCURRURELATION: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display Relationship Between RPCU and RRU
-----------------------------------------
   Local Cell ID  =  1
RPCU Information  =  0-73-0
 RRU Information  =  0-70-0,0-71-0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

RPCU Information

Indicates information about the cabinet, subrack, and slot of the radio phase calibration unit (RPCU) used by the cell.

RRU Information

Indicates information about cabinet, subrack, and slot of the RF module serving the cell.

Probe Index

Indicates the index for detection of the pairing relationship between RRU and radio phase calibration unit (RPCU). The DSP EUCELLRPCURRURELATION command output includes a maximum of 10 latest detection results.

Probe Result

Indicates the detection result of the pairing relationship between RRU and radio phase calibration unit (RPCU).

Probe End Time

Indicates the end time of detecting the pairing relationship between RRU and radio phase calibration unit (RPCU).
