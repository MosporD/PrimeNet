LST TDDRESMODESW (LST TDDRESMODESW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the TDD cell resource mode.

Note

None.

Parameters

None.

Example

To list the switch settings for TDD cell resource modes, run the following command: :
LST TDDRESMODESW:;
The result is shown as follows:
+++    0        2019-12-05 17:39:40
O&M    #806356233
%%LST TDDRESMODESW: ;%%
RETCODE = 0  Operation succeeded.

LST TDDRESMODESW
----------------
Clock-Unavailable Cell Activation Switch  =  Off
     Baseband Equipment Exclusive Switch  =  Off
   No Clock Cell Activate Sw Expiry Time  =  2000-01-01 00:00:00
(Number of results = 1)


---    END

Output Description

Field Description

Clock-Unavailable Cell Activation Switch

Indicates whether to forcibly activate an LTE TDD cell. If this parameter is set to ON(On), an LTE TDD cell can be activated even when no clock resource is available. If this parameter is set to OFF(Off), an LTE TDD cell cannot be activated when no clock resource is available. This parameter cannot be set to ON(On) when inter-BBU services are ongoing. Otherwise, the services will be affected. This parameter applies only to LTE TDD.

Baseband Equipment Exclusive Switch

Indicates whether cells can be set up a piece of baseband equipment to which these cells have not been bound but other cells have been bound. If this parameter is set to OFF and cells have been bound to a piece of baseband equipment, both these cells and cells that have not been bound to this piece of baseband equipment can be set up on this piece of baseband equipment. If this parameter is set to ON and cells have been bound to a piece of baseband equipment, cells that have not been bound to this piece of baseband equipment cannot be set up on this piece of baseband equipment. If this parameter is set to ON_WITH_BIND and cells have been bound to a piece of baseband equipment, then: (a) cells that have been bound to this baseband equipment can be set up on other baseband equipment to which other cells have been bound, on condition that this baseband equipment is faulty, and all cells not bound to this baseband equipment have been activated; (b) cells that have not been bound to this baseband equipment cannot be set up on this baseband equipment. This parameter applies only to LTE TDD.

No Clock Cell Activate Sw Expiry Time

Indicates the time after which the no-clock cell activation switch does not take effect for LTE TDD cells. If the system time is later than the parameter value, the no-clock cell activation switch becomes invalid. This parameter is precise to minutes, not seconds. The time is the local time of the NE (including the DST). If no value is set for this parameter, this parameter is automatically set to the system time, indicating that the no-clock cell activation switch does not take effect. This parameter applies only to LTE TDD.
