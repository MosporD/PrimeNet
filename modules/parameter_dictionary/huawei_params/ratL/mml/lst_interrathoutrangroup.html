List Parameter Group for Handover to UTRAN (LST INTERRATHOUTRANGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list one or all parameter groups related to inter-RAT handover to UTRAN.

Note

None.

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

InterRAT handover to UTRAN Group ID

Indicates the ID of the parameter group related to inter-RAT handover to UTRAN. This parameter applies only to LTE FDD and LTE TDD.

CoverageBased UTRAN ECN0 trigger threshold(0.5dB)

Indicates the Ec/N0 threshold for event B1 related to coverage-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for Ec/N0 of the target UTRAN cell. For a cell with large signal fading variance, set this parameter to a large value to prevent unnecessary handovers. For a cell with small signal fading variance, set this parameter to a small value to ensure timely handovers. A large value of this parameter results in a low probability of handover to the UTRAN cell, and a small value leads to a high probability.

When the measured value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

CoverageBased UTRAN RSCP trigger threshold(dBm)

Indicates the RSCP threshold for event B1 related to coverage-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for RSCP of the target UTRAN cell.

When the measurement value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

UTRAN handover hysteresis(0.5dB)

Indicates the hysteresis for event B1 related to inter-RAT handover to UTRAN. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers or handover decision errors. This parameter applies only to LTE FDD and LTE TDD.

UTRAN time to trigger(ms)

Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-UTRAN handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

Load Service Based UTRANB1 ECN0 threshold(0.5dB)

Indicates the Ec/N0 threshold for event B1 related to load- or service-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for Ec/N0 of the target UTRAN cell. When the measurement value exceeds this threshold, a measurement report may be sent. For a cell with large signal fading variance, set this parameter to a large value to prevent unnecessary handovers. For a cell with small signal fading variance, set this parameter to a small value to ensure timely handovers. This parameter applies only to LTE FDD and LTE TDD.

Load Service Based UTRAN EventB1 RSCP trigger threshold(dBm)

Indicates the RSCP threshold for event B1 related to load- or service-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for RSCP of the target UTRAN cell.

When the measurement value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

High Speed Inter RAT HO UTRAN B1 Time To Trigger(ms)

Indicates the time-to-trigger for event B1 or B2 related to handovers to UTRAN for high-speed UEs in high-speed cells. When detecting that the signal quality in at least one neighboring cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition during the time-to-trigger. This option applies only to LTE FDD and LTE TDD.
