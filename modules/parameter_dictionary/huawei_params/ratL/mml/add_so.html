Add SO Configuration (ADD SO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an SO MO.

Note

  • The EPGROUP MO referenced by CpEpGroupId in an SO MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an SO MO and the EPGROUP MO referenced by the IUB, ABIS, or uX2 MO must be different.

Example

To add an SO MO with the parameters as follows: SO ID: 0,End Point Group Config Flag: CP_UP_CFG, Control Plane End Point Group ID: 457, User Plane End Point Group ID: 457, and other parameters set to the default value, run the following command: 
ADD SO: SoId=0, EpGroupCfgFlag=CP_UP_CFG, CpEpGroupId=457, UpEpGroupId=457;
