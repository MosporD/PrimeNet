List Service Differentiation Configuration (LST SERVICEDIFFSETTING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters related to differentiated service settings.

Note

None.

Parameters

None.

Example

To list the configurations of service differentiation, run the following command: :
LST SERVICEDIFFSETTING:;
The result is shown as follows:
+++    0        2019-12-05 17:38:40
O&M    #806356199
%%LST SERVICEDIFFSETTING: ;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Queue0 Weight

Indicates the scheduling weight of queue 0. A larger parameter value indicates a higher priority. If the value is 0, queue 0 is not scheduled. The sum of scheduling weight values of all queues must not exceed 100. This parameter applies only to LTE FDD and LTE TDD.
