List IP Address Pool (LST EUIPADDRESSPOOL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query an IP address pool of the compact EPC.

Note

None.

Parameters

ID Name Description
IPAddressPoolID IP Address Pool ID

Meaning: This parameter specifies the ID of an IP address pool. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query an IP address pool, run the following command:
LST EUIPADDRESSPOOL:;
The result is shown as follows:
+++    0        2014-06-05 16:51:01
O&M    #806354947
%%LST EUIPADDRESSPOOL:;%%
RETCODE = 0  Operation succeeded.

Inquire IP Address Pool
-----------------------
IP Address Pool ID  =  4
  Start IP Address  =  172.31.255.4
    End IP Address  =  172.31.255.5
              Mask  =  255.255.255.128
(Number of results = 1)


---    END

Output Description

Field Description

IP Address Pool ID

This parameter specifies the ID of an IP address pool. This parameter applies only to LTE FDD and LTE TDD.

Start IP Address

Indicates the start IP address. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

End IP Address

Indicates the end IP address. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Mask

Indicates the mask of an IP address pool. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.
