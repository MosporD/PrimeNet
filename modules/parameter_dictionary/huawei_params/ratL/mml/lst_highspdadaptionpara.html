List Configuration of High Speed Adaption (LST HIGHSPDADAPTIONPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters related to high-speed mobility.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configuration of the High Speed Adaption Para with the local cell ID of 1, run the following command:
LST HIGHSPDADAPTIONPARA: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Low Speed Judge Number

Indicates the threshold of the number of consecutive low-speed judgments required for an initially admitted UE or a high-speed UE to be identified as a low-speed UE in a high-speed or ultra-high-speed cell. This parameter applies only to LTE FDD and LTE TDD.

Doppler Factor(%)

Indicates the impact of the Doppler effect on UE speed estimation in high-speed or ultra-high speed scenarios. The change in frequency for a UE moving relative to an eNodeB (that is, the Doppler shift) is equal to the Doppler frequency multiplied by cosθ, where θ is the angle between the UE movement direction and the signal emission direction. The angle is highly correlated with the UE location and the distance between the eNodeB and the track. When the distance is large, the UE speed cannot be well estimated. This parameter is used to address this issue. The parameter is defined as a percentage of the Doppler frequency multiplied by cosθ', where θ' is the smallest refraction angle within the eNodeB coverage. When the distance is less than or equal to 200 m, you can retain the default parameter value. When the distance is greater than 200 m, set the parameter according to instructions in High Speed Mobility Feature Parameter Description. This parameter applies only to LTE FDD and LTE TDD.

High Speed User Number Threshold

Indicates the minimum number of high-speed UEs required to determine that high-speed trains are passing by. It is recommended that this parameter be set, based on the operators' levels of traffic volume at high-speed railways, to the maximum appropriate value that can be used to identify high-speed trains in off-peak hours to minimize the impact on low-speed UEs. This parameter applies only to LTE FDD and LTE TDD.

Handover History Judge High Threshold(s)

Indicates the maximum duration of stay in the previous cell for a UE to be identified as a high-speed UE. This parameter applies only to LTE FDD and LTE TDD.

Interference Avoid Cell Number

Indicates the maximum number of a high-speed cell's neighboring low-speed cells that perform interference avoidance when high-speed trains pass by. This parameter applies only to LTE FDD.

Interference Avoid Mode

RbBasedInterfAvoid: Indicates whether to enable downlink RB-based interference avoidance. When this option is selected, the proportion of available downlink PRBs is reduced in low-speed cells to reduce the downlink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

PowerBasedInterfAvoid: Indicates whether to enable downlink power-based interference avoidance. When this option is selected, the downlink transmit power is reduced in low-speed cells to reduce the downlink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

UlRbBasedInterfAvoid: Indicates whether to enable uplink PRB-based interference avoidance. When this option is selected, the proportion of available uplink PRBs is reduced in low-speed cells to reduce the interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

UlPowerBasedInterfAvoid: Indicates whether to enable uplink power-based interference avoidance. When this option is selected, the uplink UE transmit power is reduced in low-speed cells to reduce the uplink interference to high-speed UEs when high-speed trains pass by. This option applies only to LTE FDD and LTE TDD.

RbBasedAbsoluteAvoidInd: Indicates whether to disable scheduling of high-priority services, such as signaling, in the HighSpeedOverlapBandInd-specified range of overlapping frequency bands between public cells and high-speed railway dedicated cells. This option requires that RbBasedInterfAvoid or UlRbBasedInterfAvoid has been selected. This option applies only to LTE FDD and LTE TDD.

HSCellSleepInterfAvoidSwitch: Indicates whether to allow high-speed cells to enter sleep mode. If this option is selected, the eNodeB allows high-speed cells to adaptively enter sleep mode. When a high-speed train arrives at a high-speed cell, the cell exits from sleep mode. After the high-speed rain has left the high-speed cell for a specified period of time, the high-speed cell enters sleep mode. This option applies only to LTE FDD and LTE TDD.

Interference Based Power Offset(0.5dB)

Indicates the offset to the downlink transmit power or the offset used with the uplink high-SINR threshold in the low-speed cell adjacent to a high-speed cell. When high-speed trains pass by, the downlink transmit power of the low-speed cell or the uplink transmit power for low-priority services in this cell is decreased to reduce the downlink or uplink interference to high-speed UEs. This parameter applies only to LTE FDD and LTE TDD.

Interference Based RB Ratio(%)

Indicates the maximum percentage of RBs that can be used in the low-speed cell, for which the RbBasedInterfAvoid or UlRbBasedInterfAvoid option of the InterfAvoidMode parameter is selected. When high-speed trains travel through a high-speed cell, the eNodeB stops scheduling non-GBR bearers for non-emergency calls in the low-speed cell to reduce interference to high-speed UEs if the number of downlink or uplink RBs used per TTI in the low-speed cell is greater than a specified threshold. (This threshold is the result of the number of RBs of the bandwidth multiplied by the value of this parameter.) This parameter applies only to LTE FDD.

Period of Updating Vector Cell Flag(h)

Indicates the interval at which an eNodeB updates and collects statistics about high-speed vector cell flags. This parameter applies only to LTE FDD.

Switch for Updating Vector Cell Flag

Indicates whether to automatically update soft vector flags. If this parameter is set to ON, soft vector flags can be automatically updated based on statistics on the eNodeB. If this parameter is set to OFF, soft vector flags are manually updated. This parameter applies only to LTE FDD.

High-Speed Overlapping Band Indicator

Indicates the range of overlapping frequency bands between public cells and high-speed dedicated cells. The eNodeB cannot schedule PRBs within this range for public cells. This parameter takes effect only when the HighSpeedFlag parameter in the Cell MO is set to LOW_SPEED for public cells and the RbBasedInterfAvoid or UlRbBasedInterfAvoid option of the InterfAvoidMode parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

High Speed Cell Sleep Mode

Indicates whether to allow high-speed cells to enter different sleep modes.

HS_CARR_POWER_DECREASE_MODE: If this option is selected, the eNodeB disables power decrease in the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells. After the train has left the local high-speed cell for a period, the eNodeB enables power decrease in this cell to conserve energy and reduce interference to adjacent cells. This option applies only to LTE FDD and LTE TDD.

HS_CARR_INTEL_SHUTDOWN_MODE: If this option is selected, the eNodeB disables intelligent carrier shutdown in the local high-speed cell and its adjacent high-speed cells when a high-speed train passes these cells. After the train has left the local high-speed cell for a period, the eNodeB enables intelligent carrier shutdown in this cell to conserve energy and reduce interference to adjacent cells. This option applies only to LTE FDD and LTE TDD.

High Speed Optimization Switch

Indicates whether to enable optimization algorithms in high speed mobility scenarios.

DL_AFC_OPT_SW: Indicates whether to enable the downlink AFC optimization algorithm. If this option is selected, this algorithm takes effect. If this option is deselected, the algorithm does not take effect. This option applies only to LTE FDD and LTE TDD.

LOW_SPEED_VOLTE_HO_SW: Indicates whether to hand over low-speed VoLTE UEs to low-speed frequencies. Select this option only for high-speed cells in high-speed railway scenarios. This option applies only to LTE FDD and LTE TDD.

HIGH_SPEED_INTRF_COORD_OPT_SW: Indicates whether to enable coordinated scheduling and interference suppression between public and dedicated networks in high-speed railway scenarios. If this option is selected, coordinated scheduling and interference suppression between public and dedicated networks are supported in high-speed railway scenarios. If this option is deselected, only public network interference avoidance is supported in high-speed railway scenarios. This option applies only to LTE FDD.
