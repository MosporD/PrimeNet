Modify Abnormal RRC Connection Setup Detection Configuration (MOD ABNRRCACCESSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters for the detection of abnormal RRC connection setups.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After parameters for the detection of abnormal RRC connection setups are modified, RRC connection setups meeting specified conditions will not be measured by performance counters related to normal RRC connection setups.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within the local or peer base station. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
AccessPeriod Access Period

Meaning: Indicates the period of abnormal RRC connection setup. This parameter applies only to NB-IoT.

GUI Value Range: 1~255

Unit: s

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
AccessPeriodOffset Access Period Offset

Meaning: Indicates the offset to the period of abnormal RRC connection setup. This parameter applies only to NB-IoT.

GUI Value Range: 0~5000

Actual Value Range: 0~5000

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Applicable Mode: L-NB-IOT

Example

To modify abnormal rrc access configuration with the parameters as follows: Local Cell ID: 0, Access Period(s): 200, Access Period Offset(ms): 10, TA: 35, TA Offset: 2, run the following command:, run the following command:
MOD ABNRRCACCESSCFG: LocalCellId=0, AccessPeriod=200, AccessPeriodOffset=10, Ta=35, TaOffset=2;
