Display MDT UE-based RRU Locating Task (DSP EUCELLRRULOCATIONVIAUE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display an MDT UE-based RRU locating task.

Note

None.

Example

To display an RRU locating task based on MDT UEs, run the following command:
DSP EUCELLRRULOCATIONVIAUE:;

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

eNodeB ID

Indicates the ID of the eNodeB.

Maximum Sample Number for Location

Indicates the maximum number of samples that need to be collected during RRU locating. This parameter applies only to LTE FDD and LTE TDD.

Maximum User Number for Location per Minute

Indicates the maximum number of UEs involved within one minute during RRU locating. This parameter applies only to LTE FDD and LTE TDD.

RB Number for Location

Indicates the number of RBs used for RRU locating. If this parameter is set to 255:

For 5 MHz LTE bandwidth, 6 RBs are used for RRU locating.

For 10 MHz LTE bandwidth, 10 RBs are used for RRU locating.

For 15 MHz or 20 MHz LTE bandwidth, 15 RBs are used for RRU locating.

If this parameter is not set to 255:

For 5 MHz LTE bandwidth, set this parameter to a value less than or equal to 12.

For 10 MHz LTE bandwidth, set this parameter to a value less than or equal to 30. This parameter applies only to LTE FDD and LTE TDD.

Location Progress(%)

Indicates the RRU locating progress. This parameter applies only to LTE FDD and LTE TDD.
