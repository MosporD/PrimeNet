Start Intelligent Beam Shaping Task (STR INTELLIGENTBEAMSHAPING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start an intelligent beam shaping task and to evaluate whether the corresponding sub-switches provide gains. After the task ends normally, if the gain threshold is met, the corresponding sub-switches have taken effect, otherwise the corresponding sub-switches have not taken effect. This command applies only to LTE FDD.

Note

  • The intelligent beam shaping switch(MM_INTELLIGENT_BEAM_SHAPING_SW) must be selected.

  • The task will be stopped if any of the following conditions is met: (1) The setting of the sector splitting switch is changed. (2) The cell beam azimuth, cell beam azimuth offset, or cell beam width of the sector split cell is changed. (3) The base station is reset. (4) The main control board is reset. (5) The APP is reset. (6) The STP INTELLIGENTBEAMSHAPING command is executed.

  • After a task is started, the sub-switch (PATTERN_ADJ_SWITCH or POWER_ADJ_SWITCH or PATTERN_ADJ_ENH_SWITCH) set in the task takes effect one week later.

  • One of the following conditions must be met for setting PATTERN_ADJ_ENH_SWITCH in a task: (1) the PATTERN_ADJ_SWITCH has set in the SectorSplitGroup MO; (2) the PATTERN_ADJ_SWITCH is set in the same task.

  • After the task ends normally, if the gain threshold is met, the corresponding sub-switch takes effect, otherwise the corresponding sub-switch does not take effect.

IntelliBeamShapingTask Intelligent Beam Shaping Task

Meaning: Indicates whether to enable functions related to intelligent beam shaping tasks.

PATTERN_ADJ_SWITCH: Indicates whether to enable pattern adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

POWER_ADJ_SWITCH: Indicates whether to enable power adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

PATTERN_ADJ_ENH_SWITCH: Indicates whether to enable enhanced pattern adjustment in an intelligent beam shaping task. This option applies only to LTE FDD.

GUI Value Range: PATTERN_ADJ_SWITCH(PATTERN_ADJ_SWITCH), POWER_ADJ_SWITCH(POWER_ADJ_SWITCH), PATTERN_ADJ_ENH_SWITCH(PATTERN_ADJ_ENH_SWITCH)

Unit: None

Actual Value Range: PATTERN_ADJ_SWITCH, POWER_ADJ_SWITCH, PATTERN_ADJ_ENH_SWITCH

MML Default Value: None

Recommended Value: PATTERN_ADJ_SWITCH:Off, POWER_ADJ_SWITCH:Off, PATTERN_ADJ_ENH_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: PATTERN_ADJ_SWITCH: If this option is selected, the pattern adjustment function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the pattern adjustment function will take effect for one week. This function enables main lobe directions of the antennas for the split cells to adaptively change with UE distribution, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.

POWER_ADJ_SWITCH: If this option is selected, the power adjustment function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the power adjustment function will take effect for one week. This function enables the downlink transmit power of the split cell to be adjusted to maximize power usage, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.

PATTERN_ADJ_ENH_SWITCH: If this option is selected, the pattern adjustment enhancement function of intelligent beam shaping starts to take effect when an intelligent beam shaping task has been started for one week, and the pattern adjustment enhancement function will take effect for one week. This function enhances the UE-distribution-based adjustment of main lobe directions of the antennas for the split cells, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD

User experience gain is measured by scatter chart of the DL User Throughput and DL Traffic before and after the feature takes effect.

This parameter applies only to LTE FDD.
