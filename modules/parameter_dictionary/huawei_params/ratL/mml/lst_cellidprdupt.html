List Parameter for Periodic Cell ID Update (LST CELLIDPRDUPT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the cell ID periodic updating algorithm.

Note

None.

Parameters

None.

Example

To list the configuration of the periodic cell ID updating algorithm, run the following command: :
LST CELLIDPRDUPT:;
The result is shown as follows:
+++    0        2019-12-05 17:25:06
O&M    #806355757
%%LST CELLIDPRDUPT: ;%%
RETCODE = 0  Operation succeeded.

List Parameter for Periodic Cell ID Update
------------------------------------------
Period update switch  =  False
         Action time  =  2000-01-01 00:00:00
         Period(day)  =  1
(Number of results = 1)


---    END

Output Description

Field Description

Period update switch

Indicates the switch for the algorithm for periodically updating cell IDs. If this parameter is set to BOOLEAN_TRUE, cell IDs are periodically updated, inserted into the system information, and broadcast to the associated UEs once the time at which the algorithm begins to take effect is reached. This parameter applies only to LTE FDD and LTE TDD.

Action time

Indicates the time at which the algorithm for periodically updating cell IDs begins to take effect. If the switch for the algorithm is turned on, cell IDs are periodically updated, inserted into the system information, and broadcast to the associated UEs once the time specified by this parameter is reached. This parameter applies only to LTE FDD and LTE TDD.

Period(day)

Indicates the period of updating cell IDs. This parameter applies only to LTE FDD and LTE TDD.
