List UL Time Alignment Timer Configuration (LST TATIMER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters of the uplink time alignment timer for UEs in a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of the uplink time alignment timer:
LST TATIMER:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Uplink time alignment timer

Indicates the length of the uplink time alignment timer for UEs in the cell. A UE is considered not time-aligned in the uplink if the timer expires. This parameter applies only to LTE FDD and LTE TDD.

Uplink timing advance command optimization switch

Indicates whether optimization of the mechanism for delivering the uplink time alignment command takes effect. If the optimization takes effect, the number of unnecessary uplink time alignment commands delivered to motionless or low-mobility UEs can be reduced to save air interface resources and reduce power consumption of UEs in DRX mode. This ensures the uplink time alignment performance if the length of the uplink time alignment timer is set to a large value.

If this parameter is set to ON, it is recommended that the TimeAlignmentTimer parameter be set to SF10240. A smaller value of the TimeAlignmentTimer parameter, such as SF5120, leads to a higher probability of becoming out-of-synchronization in the uplink for UEs in DRX mode.

If this parameter is set to ON, it is recommended that the LongDrxCycle parameter be smaller than or equal to SF320. Otherwise, the uplink time alignment performance of UEs in DRX mode is affected. This parameter applies only to LTE FDD and LTE TDD.

Timing Measurement Mode

Indicates the method of measuring uplink timing offsets. If this parameter is set to INVALID, uplink timing offsets are measured based on the demodulation reference signal (DMRS) for PUSCH or sounding reference signal (SRS). If this parameter is set to ALLMEASMODE, uplink timing offsets are measured based on the DMRS for PUSCH and SRS or based on the DMRS for PUSCH and channel quality indicator (CQI) reported over PUCCH. In addition, the value ON of the TimingAdvCmdOptSwitch parameter takes effect regardless of the actual parameter setting. That is, the eNodeB always sends the Timing Advance Command to UEs. In this case, it is recommended that the TimeAlignmentTimer parameter be set to SF10240. The value ALLMEASMODE applies only to LTE FDD cells. The parameter value INVALID takes effect in a cell regardless of the actual parameter setting in any of the following scenarios: (1) The cell is established on an LBBPc. (2) The UlCyclicPrefix parameter is set to EXTENDED_CP. (3) The HighSpeedFlag parameter is set to HIGH_SPEED, ULTRA_HIGH_SPEED, or EXTRA_HIGH_SPEED. (4) The TX/RX mode of the cell is 2T8R. This parameter applies only to LTE FDD and LTE TDD.

TA Command Sending Period

Indicates the interval for sending Timing Advance Commands to UEs. This parameter must be set only when the TimingAdvCmdOptSwitch parameter is set to ON. If this parameter is set to INVALID, none of the parameter settings in the MML Command window takes effect. This parameter applies only to LTE FDD.

Timing Resource Optimization Switch

Indicates whether to enable the mechanism of optimized resource scheduling for uplink timing. If this parameter is set to OFF, the eNodeB adopts the existing resource scheduling policy for uplink timing, which consumes a large amount of resources used for delivering Timing Advance Commands in large traffic scenarios. If this parameter is set to ON, the eNodeB adopts the mechanism of optimized resource scheduling for uplink timing, which reduces the number of unnecessary Timing Advance Commands to be delivered and reduces resources allocated for uplink timing in large traffic scenarios. The parameter value ON is recommended in heavily loaded cells where there is a large number of UEs. This parameter applies only to LTE FDD.

Pucch Timing Offset Compensation Value(Ts)

Indicates the offset compensation of the timing advance on the PUCCH. This parameter does not take effect on cells established on an LBBPc. This parameter applies only to LTE FDD and LTE TDD.

High Speed TA Command Sending Period

Indicates the TA command sending period for high-speed UEs in a high-speed railway cell. This parameter takes effect only when the ProcSwitchBasedOnUserSpeed option is selected. This parameter applies only to LTE FDD.

TA Enhancement

TaEnhancePuschDmrs: Indicates whether to enable enhanced TA. If this option is selected, enhanced TA is enabled, and uplink-synchronization-induced overloads over the air interface decrease. If this option is deselected, enhanced TA is disabled. This option applies only to LTE FDD. This option does not take effect in the following scenarios:

1. The FddTddInd parameter in the Cell MO is set to CELL_TDD(TDD).

2. The baseband processing unit type is the LBBPc.

3. The HoppingMode parameter in the PUSCHCfg MO is set to INTRA_AND_INTER_SUB_FRAME(Inter And Intra).

4. The HighSpeedFlag parameter in the Cell MO is set to HIGH_SPEED(High speed cell flag), ULTRA_HIGH_SPEED(Ultra high speed cell flag), or EXTRA_HIGH_SPEED(Extra high speed cell flag).

5. The TimingResOptSwitch parameter in the TimeAlignmentTimer MO is set to OFF.

TaEnhancePucch: Indicates whether to enable enhanced PUCCH TA. Enhanced PUCCH TA is enabled only after this option is selected. The enhancement helps improve the PUCCH TA measurement accuracy. This option does not take effect in the following scenarios:

1. The FddTddInd parameter in the Cell MO is set to CELL_TDD(TDD).

2. The baseband processing unit type is the LBBPc.

3. The HighSpeedFlag parameter in the Cell MO is set to HIGH_SPEED(High speed cell flag), ULTRA_HIGH_SPEED(Ultra high speed cell flag), or EXTRA_HIGH_SPEED(Extra high speed cell flag).

TA Measurement Opt Switch

Indicates whether to enable functions related to TA measurement optimization.

TA_SEARCH_WINDOW_SIZE_OPT_SW: Indicates whether to optimize the TA search window size. If this option is deselected, the default TA search window size is used. If this option is selected, the TA search window size is extended, which reduces the probability of inaccurate TA measurement due to a large multipath delay difference. This option applies only to LTE FDD.

TA_DETECT_OPT_SW: Indicates whether to optimize TA detection. If this option is deselected, the default TA detection algorithm is used. If this option is selected, the TA detection optimization algorithm is used to increase the TA detection accuracy in multipath scenarios. This option applies only to LTE FDD.

TA Adjustment Max Step

Indicates the maximum TA adjustment step. This parameter applies only to LTE FDD.
