List configurations of an LTE and NR spectrum sharing cell group (LST LTENRSPCTSHRCELLGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list configurations of an LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
LteNrSpectrumShrCellGrpId LTE and NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query spectrum sharing cell group configurations:
LST LTENRSPCTSHRCELLGRP:;
+++    0        2019-07-06 15:32:33
O&M    #806355189
%%LST LTENRSPCTSHRCELLGRP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

LTE and NR Spectrum Sharing Cell Group ID

Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

LTE Prior Res Ratio in LTE and NR Spectrum Shr(%)

Indicates the total percentage of uplink and downlink spectrum resources to be preferentially allocated to LTE for MBB services in LTE FDD and NR spectrum sharing scenarios. The total percentage of uplink and downlink spectrum resources to be preferentially allocated to NR is equal to the result of 100% minus the value of this parameter. If this parameter is set to X%, X% of the uplink and downlink spectrum resources are preferentially allocated to LTE within a measurement period (for example, 100 ms). If the X% spectrum resources are not used up by LTE, the remaining resources can be dynamically allocated to NR when NR services require more than (100% - X%) spectrum resources. This parameter applies only to LTE FDD.

LTE and NR Co Carrier Co CPRI Data Switch

Indicates whether LTE and NR share RRU carrier and CPRI data resources. If LTE and NR share optical fibers, they will share RRU carrier and CPRI data resources when this parameter is set ON. They will use their respective RRU carrier and CPRI data resources when this parameter is set to OFF. This parameter applies only to LTE FDD.

LTE and NR Uplink Spectrum Sharing Mode

Indicates the mode of uplink spectrum sharing between LTE FDD and NR. This parameter applies only to LTE FDD.

Rate of Uplink Spectrum Allocated to NR(%)

Indicates the rate of uplink spectrum to be allocated to NR. This parameter applies only to LTE FDD.

LTE Guarantee PUSCH RB Number

Indicates the PUSCH RB quantity guaranteed for LTE when LTE FDD and NR Uplink Spectrum Sharing is used. If this parameter is set to a value less than the minimum number of PUSCH RBs required by LTE, the number of PUSCH RBs actually allocated to LTE is at least this minimum number. If this parameter is set to a value greater than the maximum number of PUSCH RBs that can be allocated to LTE, the number of PUSCH RBs actually allocated to LTE may be less than the value of this parameter. If the sum of the PUSCH RB quantity guaranteed for LTE and PUSCH RB quantity guaranteed for NR is greater than the total number of PUSCH RBs that can be shared between LTE and NR, the number of PUSCH RBs actually allocated to LTE may be different from the value of this parameter. This parameter applies only to LTE FDD.

NR Guarantee PUSCH RB Number

Indicates the PUSCH RB quantity guaranteed for NR when LTE FDD and NR Uplink Spectrum Sharing is used. If this parameter is set to a value less than the minimum number of PUSCH RBs required by NR, the number of PUSCH RBs actually allocated to NR is at least this minimum number. If this parameter is set to a value greater than the maximum number of PUSCH RBs that can be allocated to NR, the number of PUSCH RBs actually allocated to NR may be less than the value of this parameter. If the sum of the PUSCH RB quantity guaranteed for LTE and PUSCH RB quantity guaranteed for NR is greater than the total number of PUSCH RBs that can be shared between LTE and NR, the number of PUSCH RBs actually allocated to NR may be different from the value of this parameter. This parameter applies only to LTE FDD.

LTE and NR Spectrum Sharing Priority

Indicates the RAT priority in spectrum sharing between LTE and NR. This parameter is valid only when the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_UPLINK_SPECTRUM_SHR and the LteNrUlSpectrumShrMode parameter in the LteNrSpctShrCellGrp MO is set to DYNAMIC_SHARING, or when the FddTddInd parameter in the Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR. This parameter applies only to LTE FDD and LTE TDD.

PRB Usage Threshold(%)

Indicates the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. When the LTE PRB usage is greater than the PRB usage threshold plus the threshold offset, the LTE cells require the spectrum shared with the NR cells. When the LTE PRB usage is less than or equal to the PRB usage threshold minus the threshold offset, the LTE cells do not require the spectrum shared with the NR cells. This parameter applies only to LTE TDD.

PRB Usage Threshold Offset(%)

Indicates the offset relative to the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. When the PRB usage is greater than the PRB usage threshold plus the threshold offset, the LTE network requires the spectrum shared with the NR network. When the PRB usage is less than or equal to the PRB usage threshold minus the threshold offset, the LTE network does not require the spectrum shared with the NR network. This parameter applies only to LTE TDD.

RRC Connected UE Number Threshold

Indicates the RRC_CONNECTED UE number threshold for triggering LTE TDD and NR spectrum sharing. When the number of LTE RRC_CONNECTED UEs is greater than the RRC_CONNECTED UE number threshold plus the threshold offset, the LTE cells require the spectrum shared with the NR cells. When the number of RRC_CONNECTED UEs is less than or equal to the RRC_CONNECTED UE number threshold minus the threshold offset, the LTE cells do not require the spectrum shared with the NR cells. This parameter applies only to LTE TDD.

RRC Connected UE Number Threshold Offset

Indicates the offset relative to the RRC_CONNECTED UE number threshold for triggering LTE TDD and NR spectrum sharing. When the number of RRC_CONNECTED UEs is greater than the RRC_CONNECTED UE number threshold plus the threshold offset, the LTE network requires the spectrum shared with the NR network. When the number of RRC_CONNECTED UEs is less than or equal to the RRC_CONNECTED UE number threshold minus the threshold offset, the LTE network does not require the spectrum shared with the NR network. This parameter applies only to LTE TDD.

LTE and NR Spectrum Handover Protect Duration(min)

Indicates the handover protection duration for LTE and NR spectrum sharing. This parameter applies only to LTE TDD.

LNR Spectrum Sharing Switch

Indicates whether to enable LTE and NR spectrum sharing functions.

LTE_SHR_SPCT_ACT_SILENCE_SW: Indicates whether to enable active silence for LTE carriers involved in spectrum sharing. If this option is selected, the light-load and extremely-light-load LTE cells involved in spectrum sharing will actively enter the silent state. If this option is deselected, LTE cells involved in spectrum sharing will not actively enter the silent state. This option applies only to LTE TDD.
