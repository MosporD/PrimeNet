Modify PrbPdcchCeConfig Configuration in an NB-IoT Cell (MOD PRBPDCCHCECONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the coverage-level-specific PDCCH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • For a cell, modifications on the PdcchOffset of an active cell would result in the automatic reset of the cell.

  • If the PdcchMaxRepetitionCnt is modified, the cell will be automatically reset and PDCCH resources may fail to be allocated.

  • It is recommended that this parameter be set to different values for the three coverage levels when the percentages of UEs with each coverage level are basically the same.

  • If the PdcchPeriodFactor is modified, the cell will be automatically reset and PDCCH resources may fail to be allocated.

PdcchMaxRepetitionCnt PDCCH Maximum Repetition Count

Meaning: Indicates the maximum number of PDCCH repetitions. The PDCCH period factor multiplied by the maximum number of PDCCH repetitions is a PDCCH period (unit: ms).

Multiple PDCCH periods without PDCCH resources are generated when this parameter is set to REP_1(REP_1) and the PdcchPeriodFactor parameter is set to G_4(G_4) or when this parameter is set to REP_4(REP_4) and the PdcchPeriodFactor parameter is set to G_2(G_2).

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is one of the preceding configurations, it is recommended that the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO be set to REP_1(REP_1) and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO be set to a value greater than or equal to MCS_2(MCS2). This is to avoid UE access failures caused by RAR resource allocation failures within the RAR window.

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is not one of the preceding combinations and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value less than MCS_2(MCS2), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.74. This is to avoid UE access failures caused by RAR resource allocation failures within the RAR window.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_2(MCS2) and less than MCS_5(MCS5), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.3.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_5(MCS5) and less than MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.87.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.43.

When the PdcchMaxRepetitionCnt parameter is set to REP_1(REP_1) or REP_2(REP_2), the product of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameter values must be greater than or equal to 1/2. When the PdcchMaxRepetitionCnt parameter is set to REP_4(REP_4), the product of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameter values must be greater than or equal to 1. This parameter applies only to NB-IoT.

GUI Value Range: REP_1(REP_1), REP_2(REP_2), REP_4(REP_4), REP_8(REP_8), REP_16(REP_16), REP_32(REP_32), REP_64(REP_64), REP_128(REP_128), REP_256(REP_256), REP_512(REP_512), REP_1024(REP_1024), REP_2048(REP_2048)

Unit: None

Actual Value Range: REP_1, REP_2, REP_4, REP_8, REP_16, REP_32, REP_64, REP_128, REP_256, REP_512, REP_1024, REP_2048

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default as follows:

REP_8 when the CoverageLevel parameter is set to COVERAGE_LEVEL_0

REP_16 when the CoverageLevel parameter is set to COVERAGE_LEVEL_1

REP_32 when the CoverageLevel parameter is set to COVERAGE_LEVEL_2

Parameter Relationship:

-Configuration constraints:

  • The PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO must not be set to G_1DOT5(G_1DOT5) or G_48(G_48). The product of the values of the PdcchPeriodFactor and PdcchMaxRepetitionCnt parameters in the PrbPdcchCeConfig MO must be within the range of 8 to 2048.
  • When the PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO is set to G_2(G_2), the PdcchMaxRepetitionCnt parameter in this PrbPdcchCeConfig MO must not be set to REP_2(REP_2).
  • The PdcchMaxRepetitionCnt parameter in the PrbPdcchCeConfig MO must not be set to REP_2048(REP_2048).
  • When the PdcchMaxRepetitionCnt parameter in a PrbPdcchCeConfig MO is set to REP_1(REP_1) or REP_2(REP_2), the product of the values of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameters in a PrbPdcchCeConfig MO must be greater than or equal to 1/2.
  • When the PdcchMaxRepetitionCnt parameter in a PrbPdcchCeConfig MO is set to REP_4(REP_4), the product of the values of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameters in a PrbPdcchCeConfig MO must be greater than or equal to 1.

PdcchPeriodFactor PDCCH Period Factor

Meaning: Indicates the PDCCH period factor. The PDCCH period factor multiplied by the maximum number of PDCCH repetitions is the PDCCH period.

Multiple PDCCH periods without PDCCH resources are generated when this parameter is set to G_4(G_4) and the PdcchMaxRepetitionCnt parameter is set to REP_1(REP_1) or when this parameter is set to G_2(G_2) and the PdcchMaxRepetitionCnt parameter is set to REP_4(REP_4).

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is one of the preceding configurations, it is recommended that the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO be set to REP_1(REP_1) and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO be set to a value greater than or equal to MCS_2(MCS2). This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is not one of the preceding combinations and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value less than MCS_2(MCS2), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.74. This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_2(MCS2) and less than MCS_5(MCS5), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.3.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_5(MCS5) and less than MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.87.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.43.

This parameter applies only to NB-IoT.

GUI Value Range: G_1DOT5(G_1DOT5), G_2(G_2), G_4(G_4), G_8(G_8), G_16(G_16), G_32(G_32), G_48(G_48), G_64(G_64)

Unit: None

Recommended Value: G_2(G_2)

-Configuration constraints:

  • The PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO must not be set to G_1DOT5(G_1DOT5) or G_48(G_48). The product of the values of the PdcchPeriodFactor and PdcchMaxRepetitionCnt parameters in the PrbPdcchCeConfig MO must be within the range of 8 to 2048.
  • When the PdcchPeriodFactor parameter in the PrbPdcchCeConfig MO is set to G_2(G_2), the PdcchMaxRepetitionCnt parameter in this PrbPdcchCeConfig MO must not be set to REP_2(REP_2).

Service Interrupted After Modification: Yes

PdcchTransRptCntFactor PDCCH Initial Trans Rept Count Factor

Meaning: Indicates the factor of the number of repeated PDCCH initial transmissions. The number of repeated PDCCH initial transmissions equals this parameter multiplied by the maximum number of PDCCH repetitions. This parameter applies only to NB-IoT.

GUI Value Range: ONER_EIGHTR(ONER_EIGHTR), QUARTERR(QUARTERR), HALFR(HALFR), ONER(ONER)

Unit: None

Actual Value Range: ONER_EIGHTR, QUARTERR, HALFR, ONER

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default as follows:

ONER_EIGHTR(ONE_EIGHTR) when the CoverageLevel parameter is set to COVERAGE_LEVEL_0

ONER_EIGHTR(ONE_EIGHTR) when the CoverageLevel parameter is set to COVERAGE_LEVEL_1

QUARTERR(QUARTERR) when the CoverageLevel parameter is set to COVERAGE_LEVEL_2

Parameter Relationship:

-Configuration constraints:

  • When the PdcchMaxRepetitionCnt parameter in a PrbPdcchCeConfig MO is set to REP_1(REP_1) or REP_2(REP_2), the product of the values of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameters in a PrbPdcchCeConfig MO must be greater than or equal to 1/2.
  • When the PdcchMaxRepetitionCnt parameter in a PrbPdcchCeConfig MO is set to REP_4(REP_4), the product of the values of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameters in a PrbPdcchCeConfig MO must be greater than or equal to 1.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter is specific to the coverage value. For an identical maximum number of PDCCH repetitions, a larger value of this parameter leads to more repeated PDCCH initial transmissions at the corresponding coverage level and good PDCCH transmission robustness but consumption of more resources and less PDCCH capacity; a smaller value of this parameter leads to fewer repeated PDCCH initial transmissions at the corresponding coverage level and poor PDCCH transmission robustness but consumption of fewer resources and more PDCCH capacity.

Applicable Mode: L-NB-IOT
PdcchOffset PDCCH Offset

Meaning: Indicates the start position offset for the NPDCCH search space. It is recommended that this parameter be set to different values for the three coverage levels when the percentages of UEs at each coverage level are basically the same. This parameter applies only to NB-IoT.

GUI Value Range: ZERO(ZERO), ONEEIGHTH(ONEEIGHTH), ONEFOURTH(ONEFOURTH), THREEEIGHTH(THREEEIGHTH)

Unit: None

Actual Value Range: ZERO, ONEEIGHTH, ONEFOURTH, THREEEIGHTH

MML Default Value: None

Recommended Value: A default value is set for this parameter. The default value is as follows:

ONEEIGHTH(1/8) for coverage level 0

ZERO(0) for coverage level 1

ZERO(0) for coverage level 2

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To modify PrbPdcchCeConfig PdcchMaxRepetitionCnt to REP_4:
MOD PRBPDCCHCECONFIG: LocalCellId=2, PrbId=2, CoverageLevel=COVERAGE_LEVEL_0, PdcchMaxRepetitionCnt=REP_4;
