Modify Cell PUSCH Parameter (MOD CELLUCIONPUSCHPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the modulation and coding scheme (MCS) offset values for signaling transmission with data on PUSCH.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DeltaOffsetCqiIndex Delta Offset CQI Index

Meaning: Indicates the index mapped to the MCS offset for CQIs transmitted with data on PUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, values 0 and 1 are reserved in 3GPP TS 36.213 Release 9. If this parameter is set to a reserved value, access failure or RRC connection reestablishment will occur. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 12

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value leads to better detection performance of CQIs transmitted with data on PUSCH and higher downlink throughput, but more occupied uplink resources and lower uplink throughput. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
DeltaOffsetRiIndex Delta Offset RI Index

Meaning: Indicates the index mapped to the MCS offset for RIs transmitted with data on PUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, values 13, 14, and 15 are reserved in 3GPP TS 36.213 Release 9. If this parameter is set to a reserved value, access failure or RRC connection reestablishment will occur. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value leads to better detection performance of RIs transmitted with data on PUSCH and higher downlink throughput, but more occupied uplink resources and lower uplink throughput. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
DeltaOffsetAckIndex Delta Offset Acknowledge Index

Meaning: Indicates the index mapped to the MCS offset for acknowledgments (ACKs) transmitted with data on PUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, value 15 is reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to UEs that are not in the TTI bundling state. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 9

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value leads to better detection performance of ACKs transmitted with data on PUSCH and higher downlink throughput, but more occupied uplink resources and lower uplink throughput. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
DeltaOffsetAckIndexForTtiB Delta Offset Acknowledge Index for TTI Bundling

Meaning: Indicates the index mapped to the MCS offset for acknowledgments (ACKs) transmitted with data on PUSCH. For details, see 3GPP TS 36.213. Some values are reserved, for example, value 15 is reserved in 3GPP TS 36.213 Release 9. When this parameter is set to a reserved value, a UE initiates an RRC connection reestablishment or fails to access the network. This parameter applies only to UEs that are in the TTI bundling state. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: The recommended value is 11 in TTI bundling scenarios. This can reduce the impact on the detection of ACKs transmitted with data on the PUSCH when UEs enter the TTI bundling state from the non-TTI bundling state.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value results in better detection performance of ACKs transmitted with data on PUSCH and greater downlink throughput, but more occupied uplink resources and lower uplink throughput. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify the cell pusch para, Local cell ID: 0, Delta Offset CQI Index: 12, run the following command:
MOD CELLUCIONPUSCHPARA: LocalCellId=0, DeltaOffsetCqiIndex=12;
