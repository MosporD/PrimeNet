Modify eNodeB-level Counter-related Parameter Group Configuration (MOD ENODEBCOUNTERPARAGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of eNodeB-level counter-related parameters.

Note

None.

Parameters

ID Name Description
VolteCounterAlgoSwitch VoLTE Counter Algorithm Switch

Meaning: Indicates whether to enable algorithms related to VoLTE counters. This parameter provides the following option:

VOLTE_LINK_ABN_DETECTION_SW: If this option is selected, the eNodeB performs link abnormality detection for VoLTE UEs and counts the E-RAB releases due to link abnormality as abnormal E-RAB releases in E-RAB-related counter measurements. If this option is deselected, the eNodeB does not perform link abnormality detection for VoLTE UEs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: VOLTE_LINK_ABN_DETECTION_SW(VOLTE_LINK_ABN_DETECTION_SW)

Unit: None

Actual Value Range: VOLTE_LINK_ABN_DETECTION_SW

MML Default Value: None

Recommended Value: VOLTE_LINK_ABN_DETECTION_SW: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: VOLTE_LINK_ABN_DETECTION_SW: If this option is selected, the number of abnormal releases of VoLTE UEs recorded by the eNodeB increases and the service drop rate increases. Deselecting this option has no impact on the eNodeB.

Applicable Mode: L-FDD, L-TDD
EnodebCounterAlgoSwitch eNodeB Counter Algorithm Switch

Meaning: Indicates whether to enable algorithms related to eNodeB-level counters. This parameter provides the following options:

MME_ABN_REL_SAME_TMSI_CHECK_SW: If this option is selected, the eNodeB checks accesses of other calls with the same TMSI in MME-triggered abnormal release scenarios. In MME-triggered abnormal release scenarios, if the eNodeB determines that the abnormal release is caused by the access of another call with the same TMSI, the eNodeB does not count this service drop. If this option is deselected, the eNodeB does not check the accesses of other calls with the same TMSI in MME-triggered abnormal release scenarios. This parameter applies only to LTE FDD and LTE TDD.

LTE_RSRP_CALCULATION_OFFSET_SW: If this option is deselected, UE-reported RSRP values are reduced by 140 before the RSRP segment statistics. If this option is selected, UE-reported RSRP values are reduced by 141 before the RSRP segment statistics. The setting of this option affects the measurement of downlink RSRP distribution of a cell. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: MME_ABN_REL_SAME_TMSI_CHECK_SW(MME_ABN_REL_SAME_TMSI_CHECK_SW), LTE_RSRP_CALCULATION_OFFSET_SW(LTE_RSRP_CALCULATION_OFFSET_SW)

Unit: None

Actual Value Range: MME_ABN_REL_SAME_TMSI_CHECK_SW, LTE_RSRP_CALCULATION_OFFSET_SW

MML Default Value: None

Recommended Value: MME_ABN_REL_SAME_TMSI_CHECK_SW:Off

LTE_RSRP_CALCULATION_OFFSET_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: MME_ABN_REL_SAME_TMSI_CHECK_SW: If this option is selected and accesses of other calls with the same TMSI are detected in MME-triggered abnormal release scenarios, the service drop rate decreases.

Applicable Mode: L-FDD, L-TDD

Example

To modify the eNodeB-level counter-related parameter configurations with the VOLTE_LINK_ABN_DETECTION_SW option of the VoLTE Counter Algorithm Switch parameter and the ENB_COUNTER_ALGO_SW option of the eNodeB Counter Algorithm Switch parameter selected, run the following command:
MOD ENODEBCOUNTERPARAGRP: VolteCounterAlgoSwitch=VOLTE_LINK_ABN_DETECTION_SW-1, EnodebCounterAlgoSwitch=MME_ABN_REL_SAME_TMSI_CHECK_SW-1&LTE_RSRP_CALCULATION_OFFSET_SW-1;
