CellReselPriority Inter frequency cell resel priority

Meaning: Indicates the cell reselection priority of the neighboring E-UTRAN frequency. The value 0 indicates the lowest priority. It is contained in SIB5. A UE determines whether to reselect to a neighboring cell on the frequency based on the value of this parameter and the absolute priority of the serving cell.

If the priority specified by this parameter is higher than the priority of the serving cell, the UE starts measuring neighboring cells on the frequency. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection.

If the priority specified by this parameter is lower than or equal to the priority of the serving cell, the UE starts the measurements only when the signal quality of the serving cell is poor. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection. Cell reselection priorities in different RATs cannot be the same. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
