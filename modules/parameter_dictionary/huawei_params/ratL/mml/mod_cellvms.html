Modify Cell VMS Configuration (MOD CELLVMS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the cell VMS.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
VmsHoUeNumTh Max UE Number for Handover Out

Meaning: Indicates the maximum number of UEs that can be transferred within 10s. This parameter is used to prevent too many UEs from being transferred at a time to neighboring cells to cause significant impact on neighboring cells. This parameter applies only to LTE FDD.

GUI Value Range: 1~10

Unit: None

Actual Value Range: 1~10

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, a large number of UEs can be transferred to neighboring cells at a time, leading to a significant UE number decrease in the serving cell but a quick UE number increase and a load increase in neighboring cells. If this parameter is set to a small value, the number of UEs in the serving cell decreases slowly.

Applicable Mode: L-FDD
VmsPrbDiffTh Load Difference Threshold

Meaning: Indicates the threshold of PRB usage difference between the serving cell and a neighboring cell. When the result of the PRB usage of the serving cell minus that of a neighboring cell in a cluster is greater than the parameter value, this neighboring cell can be a target cell for MLB. This parameter applies only to LTE FDD.

GUI Value Range: 1~99

Unit: %

Actual Value Range: 1~99

MML Default Value: None

Recommended Value: 40

Parameter Relationship:

-Configuration constraints:

  • In the CellVMS MO, the value of VmsPrbDiffTh must be less than the value of VmsPrbLoadTh.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a larger amount of load that can be transferred within an MLB period. As a result, system throughput can be improved significantly. However, there is a higher risk that appropriate neighboring cells cannot be selected. A smaller value of this parameter results in a smaller amount of load that can be transferred within an MLB period. As a result, system throughput cannot be improved significantly.

Applicable Mode: L-FDD
VmsPrbLoadTh Load Balancing Threshold

Meaning: Indicates the PRB usage threshold for triggering MLB. MLB is triggered if the PRB usage of the serving cell is higher than this parameter value. This parameter applies only to LTE FDD.

GUI Value Range: 1~99

Unit: %

Actual Value Range: 1~99

MML Default Value: None

Recommended Value: 80

Parameter Relationship:

-Configuration constraints:

  • In the CellVMS MO, the value of VmsPrbDiffTh must be less than the value of VmsPrbLoadTh.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to a larger value, MLB is less prone to be triggered. Therefore, the system throughput is affected for a longer time before UE transfer because of limited resources in the serving cell. However, more gains on the system throughput can be obtained after UEs are transferred. When this parameter is set to a smaller value, MLB is more prone to be triggered. Frequent MLB triggering leads to more signaling exchanges and handovers, which increases the CPU load. In addition, limited gains on the system throughput can be obtained by UE transfer.

Applicable Mode: L-FDD
VmsA3Offset VMS A3 Offset

Meaning: Indicates the offset for intra-frequency handovers between the inner and outer cells in VMS scenarios. This parameter also indicates the intra-frequency handover offset between cells served by the same AAU in massive MIMO (32T32R) scenarios. This parameter applies only to LTE FDD.

GUI Value Range: 0~20

Unit: dB

Actual Value Range: 0~20

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a larger amount of load that can be transferred within an MLB period. As a result, system throughput can be improved significantly. However, there is a higher risk of deterioration in the performance of transferred UEs. A smaller value of this parameter results in a smaller amount of load that can be transferred within an MLB period. As a result, system throughput cannot be improved significantly.

Applicable Mode: L-FDD

Example

To modify the configuration of the cell VMS, local cell ID is 0, VmsHoUeNumThd is 2, run the following command:
MOD CELLVMS: LocalCellId=0, VmsHoUeNumTh=2;
The result is shown as follows:
