Modify Configuration of Cell EAB Algorithm Parameter (MOD CELLEABALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to cell EAB algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
EABTriggerThd EAB Control Trigger Threshold

Meaning: Indicates the threshold for triggering extended access barring (EAB). The threshold is denoted by a percentage of cell congestion duration. If the percentage of time when the cell is in a congestion state is greater than or equal to the value of this parameter within a statistics collection period (specified by the EABStatPeriod parameter), the conditions for triggering EAB are met.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 90

Parameter Relationship:

-Configuration constraints:

  • In the CellEABAlgoPara MO, EABTriggerThd must be greater than EABCancelThd.

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: A larger parameter value leads to a lower probability of triggering EAB and reducing cell load, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L
EABStatPeriod EAB Control Statistic Periods

Meaning: Indicates the period for measuring the percentage of cell congestion duration for extended access barring (EAB). An eNodeB periodically determines the cell status based on the setting of this parameter.

GUI Value Range: 10~60

Unit: s

Actual Value Range: 10~60

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: A larger parameter value leads to a lower frequency of exporting the percentage of time during which the cell is in the congestion state and a longer time to reduce cell load, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L
EABCategory EAB Category

Meaning: Indicates the category of UEs to which EAB information is applied. If this parameter is set to CATEGORY_A, EAB information is applied to all EAB-applicable UEs. If this parameter to CATEGORY_B, EAB information is applied to EAB-applicable UEs that are not in the HPLMN and EHPLMN. If this parameter is set to CATEGORY_C, EAB information is applied to EAB-applicable UEs that are not in the HPLMN, EHPLMN, and preferred PLMN.

GUI Value Range: CATEGORY_A(Category_a), CATEGORY_B(Category_b), CATEGORY_C(Category_c)

Unit: None

Actual Value Range: CATEGORY_A, CATEGORY_B, CATEGORY_C

MML Default Value: None

Recommended Value: CATEGORY_A(Category_a)

Parameter Relationship: None

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: If this parameter is set to CATEGORY_A, EAB information is applied to all EAB-applicable UEs. If this parameter to CATEGORY_B, EAB information is applied to EAB-applicable UEs that are not in the HPLMN and EHPLMN. If this parameter is set to CATEGORY_C, EAB information is applied to EAB-applicable UEs that are not in the HPLMN, EHPLMN, and preferred PLMN.

Applicable Mode: L
EABCancelThd EAB Control Cancel Threshold

Meaning: Indicates the threshold for canceling extended access barring (EAB). The threshold is denoted by a percentage of cell congestion duration. If the percentage of time when the cell is in a congestion state is less than or equal to the value of this parameter within a statistics collection period (specified by the EABStatPeriod parameter), the conditions for canceling EAB are met.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 70

Parameter Relationship:

-Configuration constraints:

  • In the CellEABAlgoPara MO, EABTriggerThd must be greater than EABCancelThd.

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: A larger parameter value leads to a lower probability of triggering EAB and reducing cell load, but a smaller impact on user experience. A smaller parameter value leads to the opposite effects.

Applicable Mode: L
EABCancelCondSatiPeriod EAB Cancel Condition Satisfied Period

Meaning: Indicates the number of consecutive periods in which the conditions for canceling extended access barring (EAB) are met. EAB can be canceled only when the number of consecutive periods in which the conditions for canceling EAB are met reaches the value of this parameter.

GUI Value Range: 1~9

Unit: None

Actual Value Range: 1~9

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (The parameter modification has no impact on the equipment.)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that EAB will be canceled, access barring of fewer EAB-applicable UEs (that is, access experience of fewer UEs is affected), and less improvement in eNodeB stability. A larger value of this parameter results in the opposite effects.

Applicable Mode: L
ABForExceptionData NB-IoT Access Barring For Exception Data

Meaning: Indicates the access barring status of abnormal data. This parameter specifies whether NB-IoT UEs can initiate access with the cause value being mo-ExceptionData. When this parameter is set to BOOLEAN_TRUE, NB-IoT UEs are not allowed to initiate access with the cause value being mo-ExceptionData. When this parameter is set to BOOLEAN_FALSE, NB-IoT UEs can initiate access with the cause value being mo-ExceptionData. This parameter applies only to NB-IoT.

GUI Value Range: BOOLEAN_FALSE(BOOLEAN_FALSE), BOOLEAN_TRUE(BOOLEAN_TRUE)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: None

Recommended Value: BOOLEAN_FALSE(BOOLEAN_FALSE)

Parameter Relationship: None

Service Interrupted After Modification: No (And UEs in idle mode are not allowed to initiate ExceptionData access if this parameter is set to BOOLEAN_TRUE.)

Impact on Radio Network Performance: When this parameter is set to BOOLEAN_TRUE, UEs are not allowed to initiate ExceptionData access, which alleviates the impact on the eNodeB. When this parameter is set to BOOLEAN_FALSE, UEs are allowed to initiate ExceptionData access, avoiding the impact on UEs reporting emergency events.

Applicable Mode: L-NB-IOT
ABForSpecialAC NB-IoT Access Barring For AC11-15

Meaning: Indicates the access barring status of UEs with access classes 11 to 15. This parameter specifies whether NB-IoT UEs with access classes 11 to 15 can initiate access.

AC11BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 11 in idle mode is barred. This option applies only to NB-IoT.

AC12BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 12 in idle mode is barred. This option applies only to NB-IoT.

AC13BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 13 in idle mode is barred. This option applies only to NB-IoT.

AC14BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 14 in idle mode is barred. This option applies only to NB-IoT.

AC15BARSTATE: If this option is selected, access initiated by NB-IoT UEs of AC 15 in idle mode is barred. This option applies only to NB-IoT.

GUI Value Range: AC11BARSTATE(AC11BARSTATE), AC12BARSTATE(AC12BARSTATE), AC13BARSTATE(AC13BARSTATE), AC14BARSTATE(AC14BARSTATE), AC15BARSTATE(AC15BARSTATE)

Unit: None

Actual Value Range: AC11BARSTATE, AC12BARSTATE, AC13BARSTATE, AC14BARSTATE, AC15BARSTATE

MML Default Value: None

Recommended Value: AC11BARSTATE:Permit, AC12BARSTATE:Permit, AC13BARSTATE:Permit, AC14BARSTATE:Permit, AC15BARSTATE:Permit

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, the barring indication of each access class controls the access of the corresponding access class.)

Impact on Radio Network Performance: When the access initiated by UEs of an access class is barred, UEs of the access class are not allowed to initiate access. This alleviates the impact on the eNodeB. When the access initiated by UEs of an access class is allowed, UEs of the access class are allowed to initiate access, avoiding the impact on data reporting of UEs.

Applicable Mode: L-NB-IOT
ACCountForManualBarring Access Class Count for Manual Access Barring

Meaning: Indicates the number of barred access classes for AC0-AC9 UEs indicated in SIB14. When this parameter is set to the invalid value 255, the number of barred access classes in SIB14 is dynamically controlled by the access barring algorithm.

GUI Value Range: 1~10,255

Unit: None

Actual Value Range: 1~10,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on equipment)

Impact on Radio Network Performance: A smaller value of this parameter indicates a greater number of allowed access classes, and a greater impact on the eNodeB upon congestion. A larger value of this parameter (except the invalid value) results in the opposite effects.

Applicable Mode: L

Example

To modify the parameter of cell Extended AC Barring control with the parameters as follows: Local Cell ID: 0, Extended AC Barring Control Statistic Period: 30, Extended AC Barring Control Trigger Threshold: 80, Extended AC Barring Control Cancel Threshold: 50, run the following command:
MOD CELLEABALGOPARA: LocalCellId=0, EABTriggerThd=80, EABStatPeriod=30, EABCancelThd=50;
