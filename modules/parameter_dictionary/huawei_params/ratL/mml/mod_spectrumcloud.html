Modify Spectrum Cloud (MOD SPECTRUMCLOUD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of spectrum cloudification.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The cell will reset, when turning on(off) the SpectrumCloud feature, expect for the LTE and NR spectrum sharing coordinate cell.

  • When GSM and LTE Spectrum Concurrency is enabled, modifying the GSM ARFCN group ID of the cell will result in automatic reset of the cell.

  • When UMTS and LTE Spectrum Sharing is enabled, modifying the UMTS and LTE Spectrum Sharing Config ID of the cell will result in automatic reset of the cell.

  • The cell will reset if the GL_SPCT_CONCURRENCY_PH2_SW option setting is changed.

  • The cell will reset if the UL_SPECTRUM_SHR_PH2_SW option setting is changed.

  • When LTE and NR Uplink Spectrum Sharing is enabled, modifying the LTE and NR Spectrum Sharing Group ID of the cell will result in automatic reset of the cell.

  • When UMTS and LTE Spectrum Sharing based on DC-HSDPA is enabled, modifying the UMTS and LTE Spectrum Sharing Config ID of the cell will result in automatic reset of the cell.

  • When UMTS and LTE Spectrum Sharing Phase 2 with GSM is enabled, modifying the UMTS and LTE Spectrum Sharing Config ID or GSM ARFCN group ID of the cell will result in automatic reset of the cell.

  • When LTE and NR Spectrum Sharing is enabled, modifying the LTE and NR Spectrum Sharing Group ID of the cell will result in automatic reset of the cell.

  • When LTE and NR Spectrum Sharing is enabled, modifying the LTE and NR Spectrum Sharing Mode of the cell will result in automatic reset of the cell.

  • Under the LTE and NR uplink spectrum sharing mode, modifying the LNR_SPECTRUM_SHR_SUPERUL_SW option will result in LTE and NR cell reset.

-Configuration constraints:

  • If SpectrumCloudSwitch in the SpectrumCloud MO is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, the GL_SPCT_CONCURRENCY_PH2_SW and UL_SPECTRUM_SHR_PH2_SW options of the SpectrumCloudEnhSwitch parameter in the SpectrumCloud MO must be deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to GL_SPECTRUM_CONCURRENCY, the impact varies depending on the BE interface. If a BE interface is not set up between the BSC and eNodeB, E-UTRAN cells use the spectrum not overlapping with GSM. Therefore, resource utilization is inefficient but the interference between LTE and GSM is light. If a BE interface is set up between the BSC and eNodeB, E-UTRAN cells dynamically use the spectrum overlapping with GSM. Therefore, resource utilization is efficient but the interference between LTE and GSM increases.

If this parameter is set to UL_SPECTRUM_SHARING, spectrum resource usage increases and more RBs are available than when the standard bandwidth is used, which increases the system capacity. However, UMTS and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to LTE_NR_UPLINK_SPECTRUM_SHR, LTE and NR share uplink spectrum resources, decreasing uplink LTE throughput.

If this parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, spectrum resource usage increases; however, GSM, UMTS, and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to DC_HSDPA_BASED_UL_SPECTRUM_SHR, spectrum resource usage increases; however, UMTS and LTE UEs experience stronger inter-RAT interference than when the standard bandwidth is used. Therefore the uplink throughput and downlink throughput of these UEs are lower than those of UEs in the standard bandwidth when they are allocated an identical number of RBs.

If this parameter is set to LTE_NR_SPECTRUM_SHR to enable LTE FDD and NR flash dynamic spectrum sharing, uplink and downlink spectrum resources available to LTE decrease, and uplink and downlink LTE throughput decreases. If this parameter is set to LTE_NR_SPECTRUM_SHR to enable LTE TDD and NR dynamic spectrum sharing, the LTE handover success rate fluctuates during traffic migration and the fluctuation is within the normal range.

DlCchSendStrategy Downlink CCH Send Strategy

Meaning: Indicates the CRS and PDCCH transmission policy used in the LTE cell.

When GSM and LTE spectrum concurrency is enabled:

If this parameter is set to ADAPTIVE, CRSs and PDCCHs are transmitted adaptively based on the GSM and LTE interference coordination result.

If this parameter is set to CRS_AND_PDCCH_AVOIDED, CRSs and PDCCHs are not transmitted on the REs exposed to strong GSM interference.

If this parameter is set to CRS_AVOIDED_PDCCH_ADAPTIVE, CRSs are not transmitted on the REs exposed to strong GSM interference, and PDCCHs are transmitted adaptively based on the GSM and LTE interference coordination result.

If this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, CRSs are transmitted across the entire bandwidth, and PDCCHs are transmitted based on the GSM and LTE interference coordination result.

When UMTS and LTE spectrum sharing is enabled:

If this parameter is set to ADAPTIVE, CRSs and PDCCHs of the LTE cell are transmitted only within the available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_ALL, CRSs and PDCCHs of the LTE cell are transmitted across the entire LTE bandwidth.

If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, CRSs of the LTE cell are transmitted across the entire LTE bandwidth, and PDCCHs of the LTE cell are transmitted within the available LTE bandwidth.

When UMTS and LTE spectrum sharing phase 2 is enabled, DC-HSDPA-based UMTS and LTE spectrum sharing is enabled, or both UMTS and LTE spectrum sharing phase 2 and GSM and LTE spectrum concurrency are enabled (the SpectrumCloudSwitch parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM):

If this parameter is set to ADAPTIVE, CRSs and PDCCHs of the LTE cell are dynamically transmitted only within the maximum available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_ALL, CRSs and PDCCHs of the LTE cell are statically transmitted on the maximum available LTE bandwidth.

If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, CRSs of the LTE cell are statically transmitted on the maximum available LTE bandwidth, and PDCCHs of the LTE cell are dynamically transmitted on the available LTE bandwidth.

If this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, CRSs of the LTE cell are transmitted within the LTE standard bandwidth, and PDCCHs of the LTE cell are dynamically transmitted only within the maximum available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_STANDARD_BW, CRSs and PDCCHs are transmitted within the LTE standard bandwidth. In addition, if the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter is selected, RB allocation optimization is enabled. This parameter applies only to LTE FDD.

GUI Value Range: ADAPTIVE(ADAPTIVE), CRS_AND_PDCCH_AVOIDED(CRS_AND_PDCCH_AVOIDED), CRS_AVOIDED_PDCCH_ADAPTIVE(CRS_AVOIDED_PDCCH_ADAPTIVE), CRS_ALL_PDCCH_ADAPTIVE(CRS_ALL_PDCCH_ADAPTIVE), CRS_AND_PDCCH_ALL(CRS_AND_PDCCH_ALL), CRS_ALL_AND_PDCCH_AVOIDED(CRS_ALL_AND_PDCCH_AVOIDED), CRS_AND_PDCCH_STANDARD_BW(CRS_AND_PDCCH_STANDARD_BW)

Unit: None

Actual Value Range: ADAPTIVE, CRS_AND_PDCCH_AVOIDED, CRS_AVOIDED_PDCCH_ADAPTIVE, CRS_ALL_PDCCH_ADAPTIVE, CRS_AND_PDCCH_ALL, CRS_ALL_AND_PDCCH_AVOIDED, CRS_AND_PDCCH_STANDARD_BW

MML Default Value: None

Recommended Value: ADAPTIVE(ADAPTIVE)

Parameter Relationship:

-Others:

  • The DlCchSendStrategy parameter is valid when the SpectrumCloudSwitch parameter is set to GL_SPECTRUM_CONCURRENCY, UL_SPECTRUM_SHARING, DC_HSDPA_BASED_UL_SPECTRUM_SHR, or UL_SPECTRUM_SHR_PH2_WITH_GSM.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When GSM and LTE spectrum concurrency is enabled:

If the parameter is set to ADAPTIVE, the interference from LTE to GSM is the least, but LTE performance is the poorest.

If this parameter is set to CRS_AVOIDED_PDCCH_ADAPTIVE, interference from LTE to GSM is greater but LTE performance is better compared with when this parameter is set to ADAPTIVE. It is recommended that this parameter be set to CRS_AVOIDED_PDCCH_ADAPTIVE to improve the LTE performance when frequency hopping is not used in GSM.

If this parameter is set to CRS_AND_PDCCH_AVOIDED, interference from LTE to GSM is greater but LTE performance is better compared with when this parameter is set to CRS_AVOIDED_PDCCH_ADAPTIVE. It is recommended that this parameter be set to CRS_AND_PDCCH_AVOIDED to improve the LTE performance when frequency hopping is not used in GSM and LTE traffic is heavy.

When this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, interference from LTE to GSM is greater but LTE performance is better compared with when this parameter is set to ADAPTIVE or CRS_AVOIDED_PDCCH_ADAPTIVE. It is recommended that this parameter be set to CRS_ALL_PDCCH_ADAPTIVE to improve the LTE performance when frequency hopping is used in GSM.

When UMTS and LTE spectrum sharing is enabled:

If this parameter is set to ADAPTIVE, the interference from LTE to UMTS is the least, but LTE downlink performance is the poorest.

If this parameter is set to CRS_AND_PDCCH_ALL, the interference from LTE to UMTS is the greatest, but LTE downlink performance is optimal. If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, LTE downlink performance is better compared with when this parameter is set to ADAPTIVE, and interference to UMTS is smaller compared with when this parameter is set to CRS_AND_PDCCH_ALL.

When UMTS and LTE spectrum sharing phase 2 is enabled, DC-HSDPA-based UMTS and LTE spectrum sharing is enabled, or both UMTS and LTE spectrum sharing phase 2 and GSM and LTE spectrum concurrency are enabled (the SpectrumCloudSwitch parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM):

If this parameter is set to ADAPTIVE, the interference from LTE to UMTS is the least, but LTE downlink performance is the poorest.

If this parameter is set to CRS_AND_PDCCH_ALL, the interference from LTE to UMTS is greater but LTE downlink performance is better compared with when this parameter is set to ADAPTIVE. If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, LTE downlink performance is better compared with when this parameter is set to ADAPTIVE, and interference to UMTS is smaller compared with when this parameter is set to CRS_AND_PDCCH_ALL.

If this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, UE compatibility issues on the network can be resolved. In addition, LTE downlink performance is better but interference to UMTS is greater than when this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED.

If this parameter is set to CRS_AND_PDCCH_STANDARD_BW, the interference from LTE to UMTS is the greatest, but LTE downlink performance is optimal.

Applicable Mode: L-FDD

SpctShrMode Spectrum Sharing Mode

Meaning: Indicates the spectrum sharing mode. If this parameter is set to LTE_NR_PWR_DYN_SHR_WITH_SPCT, LTE and NR share spectrum power when they share the spectrum. If this parameter is set to LTE_NR_PWR_INDEPENDENT, LTE and NR use separate spectrum power when they share the spectrum. This parameter applies only to LTE FDD.

GUI Value Range: LTE_NR_PWR_DYN_SHR_WITH_SPCT(LTE_NR_PWR_DYN_SHR_WITH_SPCT), LTE_NR_PWR_INDEPENDENT(LTE_NR_PWR_INDEPENDENT)

Unit: None

Actual Value Range: LTE_NR_PWR_DYN_SHR_WITH_SPCT, LTE_NR_PWR_INDEPENDENT

MML Default Value: None

Recommended Value: LTE_NR_PWR_DYN_SHR_WITH_SPCT

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to LTE_NR_PWR_DYN_SHR_WITH_SPCT, the total power consumption is lower than when this parameter is set to LTE_NR_PWR_INDEPENDENT. To ensure that the power used when LTE and NR share spectrum does not exceed the power that can be shared between LTE and NR, spectrum resources that can be scheduled are restricted, resulting in a throughput decrease.

If this parameter is set to LTE_NR_PWR_INDEPENDENT, the total power consumption is higher than when this parameter is set to LTE_NR_PWR_DYN_SHR_WITH_SPCT. With this parameter setting, spectrum resources that can be scheduled in spectrum sharing are not restricted by power, and therefore throughput is not affected.
