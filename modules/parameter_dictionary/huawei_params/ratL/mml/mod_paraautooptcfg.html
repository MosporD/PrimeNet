Modify Automatic Congestion Handling Parameters (MOD PARAAUTOOPTCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of Automatic Congestion Handling.

Note

None.

Parameters

ID Name Description
PUSCHRsrpHighThd4AutoOpt PUSCH RSRP High Threshold for Auto Optimization

Meaning: Indicates the target upper limit of RSRP used in automatic optimization for PUSCH closed-loop power control. This parameter takes effect only when PuschRsrpHighThdSwitch is on. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -126~24

Unit: dBm

Actual Value Range: -126~24

MML Default Value: None

Recommended Value: -96

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a lower probability that the uplink received power is saturated in the presence of uplink interference, lower inter-cell interference, but also lower uplink throughput when the uplink received power is not saturated. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
PUCCHPcSINROffset4AutoOpt PUCCH PC SINR Offset for Auto Optimization

Meaning: Indicates the target offset to the target SINR used in automatic optimization for PUCCH power control. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in lower PUCCH power transmitted by UEs in the local cell, weaker PUCCH interference on other UEs in the local cell and UEs in neighboring cells, but a lower anti-interference capability. A larger parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
P0NominalPUCCH4AutoOpt P0 Nominal PUCCH for Auto Opt

Meaning: Indicates the target eNodeB-expected PUCCH transmit power used in automatic optimization for correct PUCCH demodulation. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -127~-96

Unit: dBm

Actual Value Range: -127~-96

MML Default Value: None

Recommended Value: -105

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger parameter value results in better PUCCH performance in the local cell, higher anti-interference capability, higher downlink throughput, but stronger uplink interference for neighboring cells. A smaller parameter value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
HOTimesThd Handover Times Threshold

Meaning: Indicates the threshold of the number of handovers required for selecting a neighboring cell as a coordinated neighboring cell in automatic congestion handling. If the number of handovers from a serving cell to a neighboring cell exceeds the threshold in the last 5-minute period and the neighboring cell is ranked at the top according to the number of handovers, the neighboring cell is selected as a coordinated neighboring cell. Then, the serving cell will send a parameter adjustment request to the neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a larger number of neighboring cells selected as coordinated cells for automatic congestion handling. A larger parameter value results in the opposite effect.

Applicable Mode: L-FDD, L-TDD
AchEffectiveType ACH Effective Type

Meaning: Indicates the ACH effective type.

TDD_ACH_SWITCH: If this option is selected, the ACH feature takes effect for LTE TDD cells. If both this option and the ACHSwitch option of the IOptAlgoSwitch parameter in the ENodeBAlgoSwitch MO are deselected, the ACH feature does not take effect for LTE TDD cells. This option applies only to LTE TDD.

FDD_ACH_SWITCH: If this option is selected, the ACH feature takes effect for LTE FDD cells. If both this option and the ACHSwitch option of the IOptAlgoSwitch parameter in the ENodeBAlgoSwitch MO are deselected, the ACH feature does not take effect for LTE FDD cells. This option applies only to LTE FDD.

GUI Value Range: TDD_ACH_SWITCH(TDD_ACH_SWITCH), FDD_ACH_SWITCH(FDD_ACH_SWITCH)

Unit: None

Actual Value Range: TDD_ACH_SWITCH, FDD_ACH_SWITCH

MML Default Value: None

Recommended Value: TDD_ACH_SWITCH:Off, FDD_ACH_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: TDD_ACH_SWITCH: If this option is selected, ACH takes effect in LTE TDD cells. ACH adjusts related parameters based on conditions in heavy-load networks to increase the RRC connection setup success rate and uplink and downlink UE and cell throughput. If this option is deselected, ACH does not take effect in LTE TDD cells, and network performance is not affected.

FDD_ACH_SWITCH: If this option is selected, ACH takes effect in LTE FDD cells. ACH adjusts related parameters based on conditions in heavy-load networks to increase the RRC connection setup success rate and uplink and downlink UE and cell throughput. If this option is deselected, ACH does not take effect in LTE FDD cells, and network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To modify the PARAAUTOOPTCFG with the parameters as follows: PUSCH RSRP High Threshold for Auto Optimization: -90, Handover Times Threshold: 20, run the following command:
MOD PARAAUTOOPTCFG: PUSCHRsrpHighThd4AutoOpt=-90, HOTimesThd=20;
