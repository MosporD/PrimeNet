List Coverage Pucch Configuration (LST CEPUCCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the PUCCH coverage enhancement configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the UE's coverage level.

COVERAGE_LEVEL0: Indicates the UE's coverage level is 0.

COVERAGE_LEVEL1: Indicates the UE's coverage level is 1.

COVERAGE_LEVEL2: Indicates the UE's coverage level is 2.

COVERAGE_LEVEL3: Indicates the UE's coverage level is 3.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL0(COVERAGE_LEVEL0), COVERAGE_LEVEL1(COVERAGE_LEVEL1), COVERAGE_LEVEL2(COVERAGE_LEVEL2), COVERAGE_LEVEL3(COVERAGE_LEVEL3)

Unit: None

Actual Value Range: COVERAGE_LEVEL0, COVERAGE_LEVEL1, COVERAGE_LEVEL2, COVERAGE_LEVEL3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Coverage Level

Indicates the UE's coverage level.

COVERAGE_LEVEL0: Indicates the UE's coverage level is 0.

COVERAGE_LEVEL1: Indicates the UE's coverage level is 1.

COVERAGE_LEVEL2: Indicates the UE's coverage level is 2.

COVERAGE_LEVEL3: Indicates the UE's coverage level is 3.

This parameter applies only to LTE FDD and LTE TDD.

PUCCH Repetition Number

Indicates the number of PUCCH transmission repetitions for UEs at a specific coverage level in the cell. This parameter takes effect only for UEs that will access the network after the parameter is set. If the CoverageLevel parameter in the CePucchCfg MO is set to COVERAGE_LEVEL0 or COVERAGE_LEVEL1, the following values of the PucchRepNum parameter are valid: - PUCCH_REP_NUM_R1 - PUCCH_REP_NUM_R2 - PUCCH_REP_NUM_R4 - PUCCH_REP_NUM_R8 If the CoverageLevel parameter in the CePucchCfg MO is set to COVERAGE_LEVEL2 or COVERAGE_LEVEL3, the following values of the PucchRepNum parameter are valid: - PUCCH_REP_NUM_R4 - PUCCH_REP_NUM_R8 - PUCCH_REP_NUM_R16 - PUCCH_REP_NUM_R32 This parameter applies only to LTE FDD and LTE TDD.

eMTC SRI Period Adaptation Switch

Indicates whether to enable SRI period adaptation for eMTC UEs. If this parameter is set to QCI_ADAPTIVE, the SRI period adaptively changes for eMTC UEs based on the cell load and bearers with different QCIs. If this parameter is set to NON_QCI_ADAPTIVE, the SRI period adaptively changes for eMTC UEs based on only the cell load. If the parameter is set to OFF, the SRI period for eMTC UEs is the value of the EmtcSriPeriod parameter in the CellQciPara MO. This parameter applies only to LTE FDD and LTE TDD.

Full Duplex VoLTE PUCCH Repetition Number

Indicates the number of PUCCH repetitions used by eMTC full-duplex VoLTE UEs. This parameter is valid only if the VOLTE_REPETITION_OPT_SWITCH option of the EmtcEnhancedVolteAlgoSw parameter in the CellEmtcAlgo MO is selected. TDD does not distinguish between full duplex and half duplex. For eMTC VoLTE UEs in LTE TDD, the PUCCH repetition count is determined by the HalfDuplexVoltePucchRepNum parameter in the CePucchCfg MO. This parameter applies only to LTE FDD.

Half Duplex VoLTE PUCCH Repetition Number

Indicates the number of PUCCH repetitions used by eMTC half-duplex VoLTE UEs. This parameter is valid only if the VOLTE_REPETITION_OPT_SWITCH option of the EmtcEnhancedVolteAlgoSw parameter in the CellEmtcAlgo MO is selected. TDD does not distinguish between full duplex and half duplex. For eMTC VoLTE UEs in LTE TDD, the PUCCH repetition count is determined by the HalfDuplexVoltePucchRepNum parameter in the CePucchCfg MO. This parameter applies only to LTE FDD and LTE TDD.
