Display pRRU Uplink Interference Suppression Results (DSP ULINTERFSUPPRESSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the uplink interference suppression results of pRRUs.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the uplink interference suppression results of pRRUs:
DSP ULINTERFSUPPRESSCFG: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:50:13
O&M    #806355144
%%DSP ULINTERFSUPPRESSCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display UlInterfSuppressCfg
---------------------------
                         Local cell ID  =  1
Uplink Interference Suppression Status  =  FAILURE_DUE_TO_INABILITY
(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Uplink Interference Suppression Status

Indicates the uplink interference suppression status of a pRRU. The value of this parameter can be SUCCESS, FAILURE_DUE_TO_INABILITY, or FAILURE_DUE_TO_OTHER_CAUSE. The value SUCCESS indicates that the feature has been successfully activated. The value FAILURE_DUE_TO_INABILITY indicates that the feature fails to be activated because hardware in the sector equipment group for the cell does not support this feature. The value FAILURE_DUE_TO_OTHER_CAUSE indicates that the feature fails to be activated for other reasons. This parameter applies only to LTE FDD and LTE TDD.
