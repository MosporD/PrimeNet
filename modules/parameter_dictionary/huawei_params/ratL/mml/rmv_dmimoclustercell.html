Remove D-MIMO Cluster Cell (RMV DMIMOCLUSTERCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove cells from a D-MIMO cluster.

Note

None.

Parameters

ID Name Description
DMIMOClusterId D-MIMO Cluster Id

Meaning: Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
CellId Cell Id

Meaning: Indicates the unique ID of a cell. The 28-bit E-UTRAN cell identity is comprised of the cell ID (represented by the least significant 8 bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD cells.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
eNodeBId eNodeB Id

Meaning: Indicates the ID of an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
Mcc Mobile Country Code

Meaning: Indicates the MCC of a D-MIMO cluster cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
Mnc Mobile Network Code

Meaning: Indicates the MNC of a D-MIMO cluster cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

To delete a D-MIMO cluster with the parameters as follows: D-MIMO Cluster Id: 0, Cell ID: 0, eNodeB ID: 0, Mobile country code: 100, Mobile network code: 01, run the following command:
RMV DMIMOCLUSTERCELL: DMIMOClusterId=0, CellId=0, eNodeBId=0, Mcc="100", Mnc="01";
