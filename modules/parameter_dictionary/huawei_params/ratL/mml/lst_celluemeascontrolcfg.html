List UE Measurement Control Configuration for a Cell (LST CELLUEMEASCONTROLCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the UE measurement configurations for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List UE Measurement Control Configuration for a Cell:
LST CELLUEMEASCONTROLCFG:;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Max Non-Intra Freq Measurement Object Number

Indicates the maximum number of inter-frequency and inter-RAT measurement objects that can be contained in the measurement configurations delivered to UEs in RRC_CONNECTED mode. This parameter takes effect only on LTE-only UEs, that is, UEs that do not support NSA DC. The total number of measurement objects that can be delivered on the LTE side to NSA-DC-capable UEs is specified by the CellUeMeasControlCfg.NsaMaxLteInterFMeasObjNum parameter. This parameter applies only to LTE FDD and LTE TDD.

Max EUTRAN FDD Measure Freq Number

Indicates the maximum number of E-UTRAN FDD frequencies (excluding the frequency on which the serving cell operates) that can be contained in the measurement control messages delivered to UEs in the RRC_CONNECTED state. This parameter applies only to LTE FDD and LTE TDD.

Max EUTRAN TDD Measure Freq Number

Indicates the maximum number of E-UTRAN TDD frequencies (excluding the frequency on which the serving cell works) that can be contained in the measurement control messages delivered to UEs in RRC_CONNECTED state. This parameter applies only to LTE FDD and LTE TDD.

Max UTRAN FDD Measure Freq Number

Indicates the maximum number of UTRAN FDD frequencies that can be contained in the measurement control messages delivered for UEs in the RRC_CONNECTED state. This parameter applies only to LTE FDD and LTE TDD.

Max UTRAN TDD Measure Freq Number

Indicates the maximum number of UTRAN TDD frequencies that can be contained in the measurement control messages delivered for UEs in the RRC_CONNECTED state. This parameter applies only to LTE TDD.

Max GERAN Measure Freq Number

Indicates the maximum number of GERAN frequencies that can be contained in the measurement control messages delivered for UEs in RRC_CONNECTED state. This parameter applies only to LTE FDD and LTE TDD.

Max UE TDD Measurement Freq Number

Indicates the maximum number of TDD frequencies that are supported when a UE is performing measurements. This parameter takes effect only on R13 LAA UEs. This option applies only to LTE FDD and LTE TDD.

Max Periodic Inter-Freq Measurement Freq Num

Indicates the maximum number of non-serving E-UTRA frequencies for periodic measurements that the eNodeB delivers to each UE in connected mode. If this parameter is set to N (N is not equal to 0), the eNodeB can deliver both N non-serving FDD E-UTRA frequencies and N non-serving TDD E-UTRA frequencies to a single UE in connected mode for periodic measurements. If this parameter is set to 0, the number of non-serving E-UTRA frequencies and the number of inter-RAT frequencies delivered for periodic measurements are not under control. This parameter applies only to LTE FDD and LTE TDD.

Inter-Frequency Periodic MR Control Switch

Indicates whether to enable periodic MR reporting of non-serving E-UTRA frequencies in different inter-frequency periodic MR frequency groups. Each option specifies whether inter-frequency periodic MR reporting of frequencies in the corresponding group is enabled. An inter-frequency group can be specified by the InterFreqPrdcMrFreqGrpId parameter in the EutranInterNFreq MO. This parameter applies only to LTE FDD and LTE TDD.

Max NR Measure Freq Number

Indicates the maximum number of NG-RAN frequencies that can be contained in a measurement configuration delivered to a UE in RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.

Measurement Optimization Algorithm Switch

Indicates whether to enable measurement-related optimization algorithms.

NSA_SA_MEAS_OBJ_PREEMPTION_SW: Indicates whether to enable preemption during measurement configuration when the number of measurement objects for an SA or NSA UE reaches the maximum. If this option is selected, preemption is enabled so that measurement configurations related to high-priority algorithms are preferentially delivered. If this option is deselected, preemption is disabled and the measurement configurations related to algorithms that are subsequently initiated are not delivered. This option applies only to LTE FDD and LTE TDD.

NSA DC Max Inter-Freq Measurement Object Num

Indicates the maximum total number of inter-frequency measurement objects that can be contained in the inter-frequency measurement configurations delivered to NSA UEs in the DC state in both the LTE PCell and NR PSCell. This parameter applies only to LTE FDD and LTE TDD.

NSA Max LTE Inter-Freq Measurement Object Num

Indicates the maximum total number of inter-frequency measurement objects that can be contained in the inter-frequency measurement configurations delivered to NSA UEs in the LTE PCell. This parameter applies only to LTE FDD and LTE TDD.
