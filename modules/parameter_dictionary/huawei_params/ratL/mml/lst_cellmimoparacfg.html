List Cell Mimo Configuration (LST CELLMIMOPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of cell MIMO.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Cell Mimo Configuration:
LST CELLMIMOPARACFG:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

MIMO Adaptive Switch

Indicates the type of adaptive MIMO for a multi-antenna eNodeB. The values are described as follows:

NO_ADAPTIVE: A fixed MIMO transmission mode is used. That is, transition between MIMO transmission modes is not supported.

OL_ADAPTIVE: Open-loop transmission modes are adaptively selected. UEs report rank and CQI values but do not report PMI values.

CL_ADAPTIVE: Closed-loop transmission modes are adaptively selected. UEs report rank, CQI, and PMI values.

OC_ADAPTIVE: Open- or closed-loop transmission modes are adaptively selected. This parameter applies only to LTE FDD and LTE TDD.

Fixed MIMO Mode

Indicates the fixed MIMO mode for a multi-antenna eNodeB. This parameter is valid only when MimoAdaptiveSwitch is set to NO_ADAPTIVE. There are four values.

TM2: Transmission mode 2 is always used for UEs.

TM3: Transmission mode 3 is always used for UEs.

TM4: Transmission mode 4 is always used for UEs.

TM6: Transmission mode 6 is always used for UEs. This parameter applies only to LTE FDD and LTE TDD.

Initial Mimo Type

Indicates the MIMO transmission mode used during initial network access.

If this parameter is set to TM2, the MIMO transmission mode used during initial network access is TM2.

If this parameter is set to ADAPTIVE, the MIMO transmission mode used during initial network access is determined by the settings of the MimoAdaptiveSwitch and FixedMimoMode parameters. If the MimoAdaptiveSwitch parameter is set to NO_ADAPTIVE, the initial MIMO transmission mode is determined by the setting of the FixedMimoMode parameter. If the MimoAdaptiveSwitch parameter is set to OL_ADAPTIVE or OC_ADAPTIVE, the initial MIMO transmission mode is TM3. If the MimoAdaptiveSwitch parameter is set to CL_ADAPTIVE, the initial MIMO transmission mode is TM4. This parameter applies only to LTE FDD and LTE TDD.

MIMO Switch

Indicates MIMO algorithm switches.

8T_TM9_MU-MIMO_SW: Indicates whether to enable 8T TM9 MU-MIMO. The function is enabled only if this option is selected. This option applies only to LTE FDD.

MM_SCC_TM9_MU_MIMO_SW: Indicates whether to enable TM9 MU-MIMO in a massive MIMO SCell. If this option is selected, then TM9 MU-MIMO is enabled and the massive MIMO SCell adaptively selects an MIMO mode and determines whether to perform multiple UE pairing based on the TM9 UE penetration rate and load. If this option is deselected, then TM9 MU-MIMO is disabled and the massive MIMO SCell only uses SU-MIMO. This option applies only to LTE FDD.

TM9_RANK8_SCH_OPT_SW: Indicates whether to enable TM9 rank 8 UE scheduling optimization. If this option is selected, TM9 rank 8 UE scheduling optimization is enabled. If this option is deselected, the optimization does not take effect. This option applies only to LTE TDD.

FREQ_DIFF_AMEND_SW: Indicates whether to enable frequency difference amendment in the cell. If this option is selected, frequency difference amendment is enabled. This function reduces the impact of excessive spacing between uplink and downlink center frequencies for FDD cells. This option applies only to massive MIMO cells. This option applies only to LTE FDD.

PRECISE_DL_CSI_SW: Indicates whether to enable high-precision downlink CSI in the cell. If this option is selected, this function is enabled. This option applies only to LTE FDD.

MASSIVE_MIMO_SUBBAND_BF_SW: Indicates whether to enable subband beamforming in the cell. If this option is selected, aperiodic subband feedback mode can be configured for UEs to trigger feedback and subband beamforming is enabled. This option applies only to LTE FDD.

MASSIVE_MIMO_MU_RANK_OPT_SW: Indicates whether to enable MU-MIMO rank optimization in the cell. If this option is selected, the maximum rank values that UEs can report are adaptively tuned in the cell. This option applies only to LTE FDD.

4T_TM9_ADAPTATION_SW: Indicates whether to enable TM9 adaptation in 4T cells. If this option is selected, some TM9-capable UEs are allowed to enter TM9 in 4T cells. If this option is deselected, the function does not take effect. This option applies only to LTE FDD.

MU Pairing Gain Threshold For TM9(%)

Indicates the gain threshold related to UE pairing in MU-MIMO in TM9. If the gain from UE pairing exceeds the threshold, UE pairing is allowed. This parameter applies only to LTE FDD.

MU Pairing TBS Index Threshold

Indicates the TBS index threshold for downlink multi-user pairing. For LTE FDD, this parameter specifies the TBS index threshold for TM9 MU-MIMO pairing. If the TBS index of a UE exceeds the threshold, the UE can participate in multi-user pairing. For LTE TDD, this parameter specifies the TBS index threshold for MU beamforming pairing. If the TBS index of a UE exceeds the threshold, the UE can participate in multi-user pairing. This parameter applies only to LTE FDD and LTE TDD.

PRB Ratio Threshold For TM9 SU-MIMO(%)

Indicates the PRB ratio threshold related to SU-MIMO in TM9. If the ratio of the number of PRBs scheduled for TM9-capable UEs in the cell to the total number of PRBs scheduled in the cell exceeds the threshold, SU-MIMO in TM9 takes effect. This parameter applies only to LTE FDD.

MU-MIMO Max Pair Layer

Indicates the maximum number of layers that can be paired for MU-MIMO in an FDD massive MIMO cell. This parameter applies only to LTE FDD.

MU-MIMO Weight Adjustment Strategy

Indicates the strategy for adjusting data transmission weight values for MU-MIMO. This parameter applies only to LTE FDD.

MCS Index Thld for Adaptive TM9

Indicates the MCS index threshold for TM9 adaptation. If this parameter is set to 255, the adaptation does not take effect. A UE can exit TM9 only if the MCS index of the UE exceeds this threshold. This parameter applies only to LTE FDD.

Pairing Probability Thld for Adaptive TM9(%)

Indicates the UE pairing (for MU-MIMO) probability threshold for TM9 adaptation. A UE can exit TM9 only if the pairing probability for the UE is lower than this threshold. This parameter applies only to LTE FDD.

High Order MIMO Pairing Strategy

Indicates the UE pairing policy for high-order MIMO. If this parameter is set to DEFAULT, UEs using rank 3 or rank 4 can be directly paired. If this parameter is set to FALLBACK_SU, UEs using rank 3 or rank 4 cannot be paired and therefore can perform only SU-MIMO. If this parameter is set to FALLBACK_RANK, UEs using rank 3 or rank 4 can be paired on condition that their current rank is reduced to rank 2. If this parameter is set to ADAPTIVE, the eNodeB determines whether to restrict codebook subsets for UEs using rank 3 or rank 4 or reduce the current rank of these UEs to rank 2 for pairing based on UE-level characteristics. This parameter applies only to LTE FDD.

RAN Sharing Sch Opt Switch

Indicates the algorithm for allocating RB resources for different operators proportionally in multi-user pairing scenarios. If this parameter is set to OFF, the eNodeB does not allocate RB resources for different operators proportionally in multi-user pairing scenarios. If this parameter is set to MU_PAIRING_RB_ALLOC, the operator-specific scheduling priority takes effect for all UEs. If this parameter is set to MU_PAIRING_RB_ALLOC_ENH, the operator-specific scheduling priority takes effect for paired UEs only. This parameter applies only to LTE TDD.

MU-MIMO Pairing Strategy

Indicates the UE pairing policy for MU-MIMO.

If this parameter is set to DEFAULT, the eNodeB uses the correlation policy for UE pairing.

If this parameter is set to EPF_FIRST, the eNodeB selects UEs to be paired based on the pairing efficiency maximization policy and preferentially considers scheduling fairness.

If this parameter is set to PAIRING_EFF_FIRST, the eNodeB selects UEs to be paired based on the pairing efficiency maximization policy and preferentially considers spectral efficiency.

If this parameter is set to EPF_PAIRING_EFF_BALANCING, the eNodeB selects UEs to be paired based on the pairing efficiency maximization policy and balances the spectral efficiency and scheduling fairness.

This parameter applies only to LTE FDD.
