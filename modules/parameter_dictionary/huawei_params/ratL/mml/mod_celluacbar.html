Modify Cell UAC Barring Information (MOD CELLUACBAR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify UAC barring configurations for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AccessCategory Access Category

Meaning: Indicates the access category of services in a cell. For details, see 3GPP TS 22.261. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AccessControlParamGrpId Access Control Parameter Group ID

Meaning: Indicates the access control parameter group ID mapping to an access category. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, the access control parameters for UE access are changed after this parameter is modified.)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the cell uac barring configuration parameters as follows: Local Cell Id: 0, Access Category: 1, Access Control Parameter Group ID: 2, run the following command:
MOD CELLUACBAR: LocalCellId=0, AccessCategory=1, AccessControlParamGrpId=2;
