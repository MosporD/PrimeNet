Modify BSR Parameter (MOD TYPDRBBSR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify timer settings related to buffer status reports (BSRs) for one or all QoS class identifiers (QCIs).

Note

None.

Parameters

ID Name Description
Qci QoS Class Identifier

Meaning: Indicates the QoS class identifier (QCI).

QCI 1 indicates the requirements for traditional voice services.

QCI 2 indicates the requirements for traditional video (live streaming) services.

QCI 3 indicates the requirements for traditional real-time gaming services and Internet of Vehicles (IoV) services.

QCI 4 indicates the requirements for traditional video (buffered streaming) services.

QCI 5 indicates the requirements for traditional IP multimedia subsystem (IMS) signaling.

QCI 7 indicates the requirements for traditional voice, video, and interactive gaming services.

QCIs 6, 8, and 9 indicate the requirements for video services and TCP-based services.

QCI 65 indicates the requirements for mission-critical push-to-talk (MCPTT) voice services.

QCI 66 indicates the requirements for non-mission-critical PTT voice services.

QCI 69 indicates the requirements for mission-critical PTT signaling.

QCI 70 indicates the requirements for mission-critical data services.

QCIs 75 and 79 indicate the requirements for IoV services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: QCI_1(QCI 1), QCI_2(QCI 2), QCI_3(QCI 3), QCI_4(QCI 4), QCI_5(QCI 5), QCI_6(QCI 6), QCI_7(QCI 7), QCI_8(QCI 8), QCI_9(QCI 9), QCI_65(QCI 65), QCI_66(QCI 66), QCI_69(QCI 69), QCI_70(QCI 70), QCI_75(QCI 75), QCI_79(QCI 79)

Unit: None

Actual Value Range: QCI_1, QCI_2, QCI_3, QCI_4, QCI_5, QCI_6, QCI_7, QCI_8, QCI_9, QCI_65, QCI_66, QCI_69, QCI_70, QCI_75, QCI_79

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
TPerodicBSRTimer Periodic BSR Timer

Meaning: Indicates the length of the timer for periodic transmission of buffer status reports (BSRs).

BSRs are sent periodically or as triggered by events.

Periodic transmission of BSRs uses the timer specified by this parameter.

When the timer expires, a BSR is sent.

After the BSR is sent, the timer is restarted. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: TPeriodBSRTimer_sf5(5 subframes), TPeriodBSRTimer_sf10(10 subframes), TPeriodBSRTimer_sf16(16 subframes), TPeriodBSRTimer_sf20(20 subframes), TPeriodBSRTimer_sf32(32 subframes), TPeriodBSRTimer_sf40(40 subframes), TPeriodBSRTimer_sf64(64 subframes), TPeriodBSRTimer_sf80(80 subframes), TPeriodBSRTimer_sf128(128 subframes), TPeriodBSRTimer_sf160(160 subframes), TPeriodBSRTimer_sf320(320 subframes), TPeriodBSRTimer_sf640(640 subframes), TPeriodBSRTimer_sf1280(1280 subframes), TPeriodBSRTimer_sf2560(2560 subframes), TPeriodBSRTimer_infinity(infinity subframes)

Unit: subframe

Actual Value Range: TPeriodBSRTimer_sf5, TPeriodBSRTimer_sf10, TPeriodBSRTimer_sf16, TPeriodBSRTimer_sf20, TPeriodBSRTimer_sf32, TPeriodBSRTimer_sf40, TPeriodBSRTimer_sf64, TPeriodBSRTimer_sf80, TPeriodBSRTimer_sf128, TPeriodBSRTimer_sf160, TPeriodBSRTimer_sf320, TPeriodBSRTimer_sf640, TPeriodBSRTimer_sf1280, TPeriodBSRTimer_sf2560, TPeriodBSRTimer_infinity

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RetxBsrTimer BSR Retransmission Timer

Meaning: Indicates the length of the buffer status report (BSR) retransmission timer. This timer is started after a BSR is sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: sf320(sf320), sf640(sf640), sf1280(sf1280), sf2560(sf2560), sf5120(sf5120), sf10240(sf10240)

Unit: subframe

Actual Value Range: sf320, sf640, sf1280, sf2560, sf5120, sf10240

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify parameters related to buffer status reports (BSRs): QoS class identifier: QCI_1, Periodic BSR Timer: 5 subframes, BSR Retransmission Timer: sf320, run the following command:
MOD TYPDRBBSR: Qci=QCI_1, TPerodicBSRTimer=TPeriodBSRTimer_sf5, RetxBsrTimer=sf320;
