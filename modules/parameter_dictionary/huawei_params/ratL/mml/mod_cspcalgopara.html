Modify CSPC Algorithm Parameter (MOD CSPCALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to the CSPC algorithm. This command takes effect only on the centralized control node.

Note

None.

Parameters

ID Name Description
CspcAlgoSwitch CSPC Algorithm Switch

Meaning: Indicates whether to enable CSPC in cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship:

-Configuration constraints:

  • In the CspcAlgoPara MO, TddCspcAlgoSwitch and CspcAlgoSwitch are mutually exclusive.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
CspcRsrpMeasMode CSPC RSRP Measurement Mode

Meaning: Indicates the measurement mode of the reference signal received power (RSRP) used in CSPC. The uplink RSRP is measured based on the uplink sounding reference signal (SRS) measurement. This parameter applies only to LTE FDD.

GUI Value Range: RSRP_UL(Uplink RSRP)

Unit: None

Actual Value Range: RSRP_UL

MML Default Value: None

Recommended Value: RSRP_UL(Uplink RSRP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
CspcClusterMode CSPC Cluster Mode

Meaning: Indicates the mode of grouping cells into clusters for CSPC. If this parameter is set to STATIC_CONFIG, cells must be manually grouped into clusters for CSPC based on site scenarios. If this parameter is set to DYNAMIC_PARTITION_CONFIG, the centralized control node periodically groups cells into clusters for CSPC based on site scenarios. The DYNAMIC_PARTITION_CONFIG value does not take effect currently. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: STATIC_CONFIG(Static Config), DYNAMIC_PARTITION_CONFIG(Dynamic Partition Config)

Unit: None

Actual Value Range: STATIC_CONFIG, DYNAMIC_PARTITION_CONFIG

MML Default Value: None

Recommended Value: STATIC_CONFIG(Static Config)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CspcClusterPartPeriod CSPC Cluster Partition Period

Meaning: Indicates the interval at which cells are grouped into clusters for CSPC. The interval can be configured based on site scenarios. This parameter currently does not take effect because dynamic clustering is not supported. This parameter applies only to LTE FDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: 1~20

Unit: s

Actual Value Range: 1~20

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that dynamic cell clustering adapts to UE movements and network services in a timely manner, and accordingly lower CSPC performance gains. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
CspcPowerConfigDelay CSPC Power Config Delay

Meaning: Indicates the interval between the time that an eNodeB reports measurement information to the centralized control node and the time that the power configuration delivered by the centralized control node takes effect on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~10

Unit: ms

Actual Value Range: 2~10

MML Default Value: None

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that power optimization adapts to UE movements and network services in a timely manner, and accordingly lower CSPC performance gains. A smaller value of this parameter results in a higher probability that power optimization adapts to UE movements and network services in a timely manner, and accordingly higher CSPC performance gains, but a heavier system load.

Applicable Mode: L-FDD, L-TDD
CspcScheduleUeSpec CSPC Schedule UE Specification

Meaning: Indicates the maximum number of UEs that can be selected for CSPC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~25

Unit: None

Actual Value Range: 1~25

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to higher complexity of the CSPC algorithm, higher CSPC performance gains, but heavier load on the centralized control node. A smaller value of this parameter leads to lower complexity of the CSPC algorithm and lower CSPC performance gains.

Applicable Mode: L-FDD, L-TDD
CspcEnableDlPrbRatioThd CSPC Enable Downlink PRB Ratio Threshold

Meaning: Indicates the physical resource block (PRB) usage threshold for enabling coordinated scheduling-based power control (CSPC). CSPC is enabled when the highest PRB usage among all cells in a CSPC cluster is greater than this parameter value. To prevent CSPC from being enabled and disabled frequently in the cluster, the PRB usage threshold for disabling CSPC is lower than this parameter value. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of starting the coordinated scheduling function of CSPC in the cluster and therefore a lower probability of increasing downlink throughput by coordinated scheduling. A smaller parameter value results in the opposite effects.

Applicable Mode: L-FDD
TddCspcAlgoSwitch TDD Cspc Algorithm Switch

Meaning: Indicates whether to enable CSPC for cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE TDD.

GUI Value Range: TddCspcMacroMicroSwitch(TddCspcMacroMicroSwitch)

Unit: None

Actual Value Range: TddCspcMacroMicroSwitch

MML Default Value: None

Recommended Value: TddCspcMacroMicroSwitch:Off

Parameter Relationship:

-Configuration constraints:

  • In the CspcAlgoPara MO, TddCspcAlgoSwitch and CspcAlgoSwitch are mutually exclusive.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
CspcCapacityFactor CSPC Capacity Factor

Meaning: Indicates the acceptable capacity loss proportion in a network with CSPC enabled. This parameter affects the gain for cell edge UEs. Set this parameter in heavily-loaded networks to adjust cell downlink throughput and the downlink throughput gain of cell edge UEs. If this parameter is set to 100, network capacity loss is not considered, and the downlink throughput gain of cell edge UEs reaches the maximum. If this parameter is set to 0, it is preferential to guarantee that capacity loss does not occur in heavily-loaded networks. However, the downlink throughput gain of cell edge UEs decreases. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that cell downlink throughput experiences negative gain and a larger downlink throughput gain for cell edge UEs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD

Example

To enable the CSPC algorithm, run the following command:
MOD CSPCALGOPARA: CspcAlgoSwitch=ON;
