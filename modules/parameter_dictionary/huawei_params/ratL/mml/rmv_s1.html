Remove S1 Configuration (RMV S1)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an S1 object.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After an S1 object is removed, all S1 links under this object are removed. This may lead to unavailability of the cells under the operator.

Parameters

ID Name Description
S1Id S1 ID

Meaning: Indicates the S1 object ID.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove an S1 object whose ID is 0, run the following command:
RMV S1: S1Id=0;
