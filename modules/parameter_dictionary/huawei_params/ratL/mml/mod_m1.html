Modify M1 Configuration (MOD M1)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters of an M1 MO.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Modifying the setting of the M1EpGroupId parameter in the M1 MO may interrupt ongoing eMBMS services.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the M1EpGroupId parameter in the M1 MOs or the UpEpGroupId parameter in the S1 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the M1EpGroupId parameter in the M1 MOs or the UpEpGroupId parameter in the X2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the M1EpGroupId parameter in the M1 MOs or the UpEpGroupId parameter in the ECO MOs cannot overlap.

  • The EPGROUP MO referenced by M1EpGroupId in an M1 MO and the EPGROUP MO referenced by the IUB, ABIS, or uX2 MO must be different.

Parameters

ID Name Description
M1Id M1 ID

Meaning: Indicates the M1 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M1NetworkType M1 Network Type

Meaning: Indicates the type of network served by the M1 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MACRO_NETWORK(MACRO_NETWORK), IOPS_NETWORK(IOPS_NETWORK)

Unit: None

Actual Value Range: MACRO_NETWORK, IOPS_NETWORK

MML Default Value: None

Recommended Value: MACRO_NETWORK(MACRO_NETWORK)

Parameter Relationship:

-Configuration constraints:

  • The M1NetworkType value in each M1 MO must be unique.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M1EpGroupId M1 End Point Group ID

Meaning: Indicates the ID of the endpoint group used by the M1 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The M1EpGroupId value in each M1 MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserLabel User Label

Meaning: Indicates the descriptions of the M1 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of an M1 MO with the parameters as follows: M1 ID: 0, Control Plane End Point Group ID: 457, run the following command:
MOD M1: M1Id=0, M1EpGroupId=457;
