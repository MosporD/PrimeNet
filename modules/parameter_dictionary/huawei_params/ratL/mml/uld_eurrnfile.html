Upload RRN Inventory Information File (ULD EURRNFILE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to upload the RRN inventory information file to an FTP server.

Note

The execution of this command does not affect operation of the eNodeB. The RRN supports inventory information reporting. Before running this command, ensure that the following conditions are met: The FTP server is running properly and the IP address of the FTP server is an IPv4 address. The FTP server has been configured in the same Intranet as the eNodeB. No firewall has been configured between the FTP server and the eNodeB. The FTP user can access a specified directory.

Example

To upload RRN inventory information file with the parameters as follows:LocalSubscriber ID:12, FTP server IP:"192.168.0.1", USR:"admin", Pass Word:"*****", FileType:"INVENTORY";
run the following command:
ULD EURRNFILE: LocalSubscriberId=12, IP="192.168.0.1", USR="admin", PWD="*****", FileType=INVENTORY;
