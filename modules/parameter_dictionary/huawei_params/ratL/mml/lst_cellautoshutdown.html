List Cell Automatic Shutdown Parameters (LST CELLAUTOSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of automatic cell shutdown.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list Cell Auto Shutdown Configuration, run the following command:
LST CELLAUTOSHUTDOWN:;
The result is shown as follows:
+++    0        2019-12-05 17:22:46
O&M    #806355680
%%LST CELLAUTOSHUTDOWN: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List Cell Automatic Shutdown Parameters
---------------------------------------
            Local Cell ID  =  1
Cell Auto Shutdown Switch  =  OFF
               Start Time  =  00:00:00
                Stop Time  =  06:00:00
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Cell Auto Shutdown Switch

Indicates whether to enable automatic cell shutdown.

Start Time

Indicates the start time of automatic cell shutdown.

Stop Time

Indicates the end time of automatic cell shutdown.
