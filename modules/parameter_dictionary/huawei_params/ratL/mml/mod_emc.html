Modify EMC Configuration (MOD EMC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the emergency call configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

EmcEnable is recommended that this parameter be set to a value in accordance with the actual emergency call capability of the operator.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: This parameter has been set in the network planning, and no optimization is required. It is recommended that this parameter be set to a value in accordance with the actual emergency call capability of the operator.

Applicable Mode: L-FDD, L-TDD
EmcEnable Emergency call enabled switch

Meaning: Indicates whether the operator supports emergency calls. It is recommended that this parameter be set to a value in accordance with the actual emergency call capability of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the eNodeB identifies emergency UEs and gives them preferential treatment in admission and congestion control. The eNodeB can hand over emergency UEs to a neighboring cell even though the neighboring cell is configured with the handover prohibition flag, is blacklisted, in the handover restriction list, or belongs to a PLMN to which a handover is not allowed. When this parameter is set to OFF, the eNodeB does not identify emergency UEs, and provides the same services for emergency UEs as common UEs.

Applicable Mode: L-FDD, L-TDD
EmcEnableInLimitedMode Emergency call enabled switch in limited mode

Meaning: Indicates whether the operator supports emergency calls initiated by UEs in the limited service state. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the eNodeB supports emergency calls initiated by UEs in the limited service state and will notify UEs of this fact using the IE ims-EmergencySupport-r9 with the value true in SIB1 delivered by the eNodeB. When this parameter is set to OFF, the eNodeB does not support such emergency calls and does not deliver the SIB1 containing the IE ims-EmergencySupport-r9. In this case, UEs select or reselect a cell in any RAT that supports such emergency calls and then camp on the cell.

Applicable Mode: L-FDD, L-TDD
EmcDedicatedBearerARP The ARP of EMC dedicated bearer

Meaning: Indicates the Allocation and Retention Priority (ARP) value of the dedicated bearer for an emergency call. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In the initial stage of the network planning, the setting of this parameter is consistent with the configurations in the evolved packet core (EPC).

If the EmcEnable parameter is set to ON and the ARP of a bearer set up by a UE is the same as the EmcDedicatedBearerARP parameter, the eNodeB identifies the UE as an emergency UE. In this case, UE throughput cannot exceed the upper limit that is configured in the EPC, except in admission control, congestion control, and mobility management procedures.

Applicable Mode: L-FDD, L-TDD
EmcDefaultBearerARP The ARP of EMC default bearer

Meaning: Indicates the Allocation and Retention Priority (ARP) value of the default bearer for an emergency call. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In the initial stage of the network planning, the setting of this parameter is consistent with the configurations in the evolved packet core (EPC).

If the EmcEnable parameter is set to ON and the ARP of a bearer set up by a UE is the same as the EmcDefaultBearerARP parameter, the eNodeB identifies the UE as an emergency UE. In this case, UE throughput cannot exceed the upper limit that is configured in the EPC, except in admission control, congestion control, and mobility management procedures.

Applicable Mode: L-FDD, L-TDD
EmergCallOptimizationSw Emergency Call Optimization Switch

Meaning: Indicates whether to enable optimization functions of emergency calls.

TM_RESTRICTION_DISABLE_SW: Indicates whether to cancel TM mode selection restriction for emergency calls. If this option is selected, emergency calls do not always use TM2 but use the same TM mode as common calls. If this option is deselected, emergency calls always use TM2 in non-single-port scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: TM_RESTRICTION_DISABLE_SW(TM_RESTRICTION_DISABLE_SW)

Unit: None

Actual Value Range: TM_RESTRICTION_DISABLE_SW

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: TM_RESTRICTION_DISABLE_SW: If this option is selected, TM mode selection for emergency calls is the same as that of common calls. As a result, the proportion of rank 2 may increase on the network, and the access success rate of emergency UEs may decrease. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To change the value of Emergency call enabled switch to OFF for the operator with CN Operator ID of 0, run the following command:
MOD EMC: CnOperatorId=0, EmcEnable=OFF;
