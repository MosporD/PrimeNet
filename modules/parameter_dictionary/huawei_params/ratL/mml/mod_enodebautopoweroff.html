Modify RF Module Regular Time Sleep Configuration (MOD ENODEBAUTOPOWEROFF)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the RF module regular time sleep configurations about the eNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When conditions for RF modules entering the regular sleep time are met and the AutoPowerOffSwitch parameter setting is changed to ON(On) on an eNodeB, the eNodeB shuts down all cells.

Parameters

ID Name Description
AutoPowerOffSwitch RF module sleep switch

Meaning: Indicates the switch for RF module regular time sleep. Cells are unavailable after the eNodeB enters RF module regular time sleep. After the eNodeB exits RF module regular time sleep, it is in the normal state. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Cells are unavailable after the eNodeB enters RF module regular time sleep and UEs cannot access these cells.

Applicable Mode: L-FDD, L-NB-IOT
PowerOffTime RF module sleep start time

Meaning: Indicates the time for entering RF module regular time sleep. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: 22:00:00~05:00:00

Unit: None

Actual Value Range: 22:00:00~05:00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the eNodeBAutoPowerOff MO, PowerOffTime must be set to a time in the range of 22:00:00 to 05:00:00 of the next day.
  • In the eNodeBAutoPowerOff MO, the value of PowerOnTime must be one hour later than that of PowerOffTime.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-NB-IOT
PowerOnTime RF module sleep stop time

Meaning: Indicates the time for exiting RF module regular time sleep. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: 23:00:00~06:00:00

Unit: None

Actual Value Range: 23:00:00~06:00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the eNodeBAutoPowerOff MO, PowerOnTime must be set to a time in the range of 23:00:00 to 06:00:00 of the next day.
  • In the eNodeBAutoPowerOff MO, the value of PowerOnTime must be one hour later than that of PowerOffTime.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-NB-IOT

Example

To modify the parameters of the RF module regular time sleep as follows: RF module sleep switch: ON, RF module sleep start time: 22:00:00, RF module sleep stop time: 23:00:00:
MOD ENODEBAUTOPOWEROFF: AutoPowerOffSwitch=ON, PowerOffTime=22&00&00, PowerOnTime=23&00&00;
