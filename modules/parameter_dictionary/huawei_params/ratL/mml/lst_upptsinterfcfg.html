List UpPTS Interference Configuration (LST UPPTSINTERFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the UpPTS interference parameter configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of parameters related to UpPTS interference:
LST UPPTSINTERFCFG:;
The result is shown as follows:
+++    0        2019-12-05 17:40:28
O&M    #806356260
%%LST UPPTSINTERFCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Adjust Period(s)

Indicates the interval at which the eNodeB adjusts sounding resources. This parameter applies only to LTE TDD.

Test Threshold(dBm)

Indicates the threshold of UpPTS interference for determining whether such interference is severe. If UpPTS interference is greater than or equal to this threshold, the eNodeB determines that such interference is severe. The eNodeB can determine whether such interference is minor or medium based on the values of this parameter and the TestHysteresis parameter in the UpPTSInterfCfg MO. If UpPTS interference is less than this threshold subtracted by the TestHysteresis parameter in the UpPTSInterfCfg MO, the eNodeB determines that such interference is minor. If UpPTS interference is greater than or equal to this threshold subtracted by the TestHysteresis parameter in the UpPTSInterfCfg MO and less than this threshold, the eNodeB determines that such interference is medium. This parameter applies only to LTE TDD.

Test Hysteresis(dB)

Indicates the hysteresis for determining whether UpPTS interference is minor or moderate. This parameter is used to reduce the ping-pong effect caused by interference fluctuation. The eNodeB can determine whether UpPTS interference is minor or moderate based on the values of this parameter and the TestThreshold parameter in the UpPTSInterfCfg MO. If UpPTS interference is less than the value of the TestThreshold parameter in the UpPTSInterfCfg MO subtracted by the value of this parameter, the eNodeB determines that such interference is minor. If UpPTS interference is greater than or equal to the TestThreshold parameter in the UpPTSInterfCfg MO subtracted by this parameter and less than the TestThreshold parameter in the UpPTSInterfCfg MO, the eNodeB determines that such interference is moderate. This parameter applies only to LTE TDD.
