Add a Sidelink V2X Carrier (ADD SIDELINKV2XCARRIER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add static attributes for sidelink V2X carriers.

Note

None.

Parameters

ID Name Description
SidelinkV2xCarrierId Sidelink V2X Carrier ID

Meaning: Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SidelinkV2xEarfcn Sidelink V2X EARFCN

Meaning: Indicates the sidelink V2X EARFCN. This parameter can be set to a value ranging from 46790 to 55239. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 46790~55239

Unit: None

Actual Value Range: 46790~55239

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MaxSidelinkV2xTransmitPwr Maximum Sidelink V2X Transmit Power

Meaning: Indicates the maximum transmit power of a UE for V2X sidelink transmission. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~33

Unit: dBm

Actual Value Range: -30~33

MML Default Value: 23

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SidelinkV2xBandwidth Sidelink V2X Bandwidth

Meaning: Indicates the operating carrier bandwidth for sidelink V2X. Sidelink adopts the same RX and TX bandwidths. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SIDELINK_BW_N6(1.4M), SIDELINK_BW_N15(3M), SIDELINK_BW_N25(5M), SIDELINK_BW_N50(10M), SIDELINK_BW_N75(15M), SIDELINK_BW_N100(20M)

Unit: None

Actual Value Range: SIDELINK_BW_N6, SIDELINK_BW_N15, SIDELINK_BW_N25, SIDELINK_BW_N50, SIDELINK_BW_N75, SIDELINK_BW_N100

MML Default Value: SIDELINK_BW_N50(10M)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a sidelink V2X carrier with the sidelink V2X carrier ID of 0 and sidelink V2X EARFCN of 51000, run the following command:
ADD SIDELINKV2XCARRIER: SidelinkV2xCarrierId=0, SidelinkV2xEarfcn=51000;
