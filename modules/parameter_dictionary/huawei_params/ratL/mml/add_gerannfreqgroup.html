Add Neighboring GERAN Frequency Group (ADD GERANNFREQGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a neighboring GERAN carrier frequency group.

Note

  • A maximum of 16 neighboring GERAN carrier frequency groups can be configured for each E-UTRAN cell.

  • A GeranNfreqGroup MO consists of the parameters related to a neighboring GERAN frequency group. The configuration of this MO is shared by all frequencies in the group, and is used in measurement control for inter-RAT handovers to GERAN and also used for inter-RAT cell reselections to GERAN. If no operator is configured to share the added neighboring GERAN frequency group, frequencies in this group can be used by all operators of the cell. If operators are configured to share the added neighboring GERAN frequency group, frequencies in this group can be used only by the configured operators of the cell.

  • A maximum of 64 neighboring GERAN ARFCNs can be configured for each E-UTRAN cell, including the first GERAN ARFCNs and other GERAN ARFCNs in the neighboring GERAN carrier frequency groups.

CellReselPriority Cell reselection priority

Meaning: Indicates the cell reselection priority of the GERAN carrier frequency group. The value 0 indicates the lowest priority. It is contained in SIB7. A UE determines whether to reselect to a neighboring cell on a frequency in the GERAN carrier frequency group based on the value of this parameter and the absolute priority of the serving cell.

If the priority specified by this parameter is higher than the priority of the serving cell, a UE starts measuring neighboring cells on the frequencies in the GERAN carrier frequency group. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection. If the priority specified by this parameter is lower than the priority of the serving cell, the UE starts the measurements only when the signal quality of the serving cell is poor. Then, if the signal quality of any neighboring cell meets requirements, the UE starts cell reselection. Cell reselection priorities in different RATs cannot be the same. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GeranRanSharingInd GERAN Freq Group RAN Sharing Indication

Meaning: Indicates whether a neighboring GERAN cell on the GERAN frequency is a shared neighboring GERAN cell. If this parameter is set to BOOLEAN_TRUE, the GERAN frequency is a shared frequency, and the frequency-sharing operator information must be checked on the OSS before all neighboring GERAN cells are added. If this parameter is set to BOOLEAN_FALSE, the GERAN frequency is not a shared frequency, and the frequency-sharing operator information does not need to be checked on the OSS before all neighboring GERAN cells are added. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: BOOLEAN_TRUE(True)

Recommended Value: BOOLEAN_TRUE(True)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to BOOLEAN_TRUE, the GERAN frequency is a shared frequency, and operator information of neighboring GERAN cells on the shared frequency must be checked on the OSS before the neighboring GERAN cells are added.

If this parameter is set to BOOLEAN_FALSE, the GERAN frequency is a non-shared frequency, and operator information of neighboring GERAN cells on the non-shared frequency does not need to be checked on the OSS before the neighboring GERAN cells are added, which avoids OSS congestion. Neighboring GERAN cells on the non-shared GERAN frequency can be added directly without the frequency-sharing operator information delivered from the OSS, thereby accelerating neighboring cell addition and avoiding neighboring cell loss caused by OM channel exceptions.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add a neighboring GERAN carrier frequency group with the parameters as follows: Local cell ID: 0, BCCH group ID: 0, GERAN version: GSM, Starting ARFCN: 0, Band indicator: GSM_dcs1800, Cell reselection priority indicator: CFG, Cell reselection priority: 2, PMAX configure indicator: CFG, PMAX: 1, Minimum required RX level: 6, High priority threshold: 6, Lower priority threshold: 16, Frequency offset: -1, NCC monitoring permitted: 255, run the following command:
ADD GERANNFREQGROUP:LocalCellId=0, BcchGroupId=0, GeranVersion=GSM, StartingArfcn=0, BandIndicator=GSM_dcs1800, CellReselPriorityCfgInd=CFG, CellReselPriority=2, PmaxGeranCfgInd=CFG, PmaxGeran=1, QRxlevmin=6, ThreshXHigh=6, ThreshXLow=16, OffsetFreq=-1, NccPermitted=255;
Example 2: To add a neighboring GERAN carrier frequency group with the parameters as follows: Local cell ID: 0, BCCH group ID: 1, GERAN version: GSM, Starting ARFCN: 0, Band indicator: GSM_pcs1900,  Cell reselection priority indicator: CFG, Cell reselection priority: 3, PMAX configure indicator: CFG, PMAX: 3, Minimum required RX level: 5, High priority threshold: 5, Lower priority threshold: 6, Frequency offset: 0, NCC monitoring permitted: 254, run the following command:
ADD GERANNFREQGROUP:LocalCellId=0, BcchGroupId=1, GeranVersion=GSM, StartingArfcn=0, BandIndicator=GSM_pcs1900, CellReselPriorityCfgInd=CFG, CellReselPriority=3, PmaxGeranCfgInd=CFG, PmaxGeran=3, QRxlevmin=5, ThreshXHigh=5, ThreshXLow=6, OffsetFreq=0, NccPermitted=254;
