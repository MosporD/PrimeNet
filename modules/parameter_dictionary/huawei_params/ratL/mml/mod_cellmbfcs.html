Modify Cell Multi-band Fast Carrier Selection (MOD CELLMBFCS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameter configuration of multi-band fast carrier selection.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellSyntheticalRateHoHyst Cell Synthetical Rate Handover Hysteresis

Meaning: Indicates the hysteresis for the overall cell data rate gain that must be met to trigger an outgoing inter-carrier handover for a non-CA UE or serving cell combination change for a CA UE. If the estimated overall cell data rate gain brought by the handover or combination change is greater than the hysteresis, the eNodeB triggers the handover or combination change. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a lower probability of triggering optimal carrier selection. Therefore, the system throughput improvement is significant each time a handover is triggered. However, the less frequent triggering of carrier selection still affects the system throughput improvement. A smaller value of this parameter indicates a higher probability of triggering optimal carrier selection. As a result, the number of handovers increases. The system throughput improvement is slight each time a handover is triggered. The probability of ping-pong handovers increases.

Applicable Mode: L-FDD, L-TDD
CellTrafficLoadThd Cell Traffic Load Threshold

Meaning: Indicates the service load threshold of the cell for triggering optimal carrier selection. If the estimated service data transmission duration of the cell is greater than or equal to this threshold, the eNodeB triggers optimal carrier selection. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1000

Unit: ms

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a lower probability of triggering optimal carrier selection. Therefore, the system throughput improvement is significant each time a handover is triggered. However, the less frequent triggering of carrier selection still affects the system throughput improvement. A smaller value of this parameter indicates a higher probability of triggering optimal carrier selection. As a result, the number of handovers increases. The system throughput improvement is slight each time a handover is triggered.

Applicable Mode: L-FDD, L-TDD
InterFreqMeasLoadRatioThd Inter-Freq Measurement Load Ratio Threshold

Meaning: Indicates the UE load ratio threshold for triggering inter-frequency measurement. A UE is allowed to perform inter-frequency measurement when the ratio of the service load of the UE to the total service load of the cell is less than or equal to this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates more UEs that can perform inter-frequency measurement and more UEs that are affected by inter-frequency measurement. A smaller value of this parameter leads to the opposite effects but also indicates fewer UEs that can be handed over for optimal carrier selection.

Applicable Mode: L-FDD, L-TDD
InterFreqMeasMcsThd Inter-Freq Measurement MCS Threshold

Meaning: Indicates the MCS threshold for triggering inter-frequency measurement. A UE is allowed to perform inter-frequency measurement when the average MCS used for single-codeword transmission of a UE is less than this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~28

Unit: None

Actual Value Range: 0~28

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates more UEs that can perform inter-frequency measurement and more UEs that can be handed over for fast carrier selection. A smaller value of this parameter indicates a requirement of poorer air interface quality for triggering inter-frequency measurement, fewer UEs that perform measurement, and fewer UEs that are affected by inter-frequency measurement.

Applicable Mode: L-FDD, L-TDD
InterFreqMeasServiceThd Inter-Freq Measurement Service Threshold

Meaning: Indicates the UE traffic volume threshold for triggering inter-frequency measurement. A UE is allowed to trigger inter-frequency measurement when the traffic volume of the UE is greater than this threshold. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: byte

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates fewer UEs that can perform inter-frequency measurement. Only the UEs with high data transmission requirements can be handed over for optimal carrier selection. A smaller value of this parameter indicates more candidate UEs that can perform inter-frequency measurement. This means that more UEs are affected by inter-frequency measurement.

Applicable Mode: L-FDD, L-TDD
MeasInfoUpdInterval Measurement Information Update Interval

Meaning: Indicates the interval for updating UE measurement information. UEs periodically report intra-frequency measurement information at this interval. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 120ms(120ms), 240ms(240ms), 480ms(480ms), 640ms(640ms), 1024ms(1024ms), 2048ms(2048ms), 5120ms(5120ms), 10240ms(10240ms), 1min(1min), 6min(6min), 12min(12min), 30min(30min), 60min(60min)

Unit: None

Actual Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

MML Default Value: None

Recommended Value: 5120ms(5120ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in less frequent UE measurement reporting and a lower capability of tracking the changes in radio conditions, affecting the handover success rate. A smaller value of this parameter results in more frequent UE measurement reporting and a higher capability of tracking the changes in radio conditions, affecting UE throughput.

Applicable Mode: L-FDD, L-TDD
UeSpectralEffHoHyst UE Spectral Efficiency Handover Hysteresis

Meaning: Indicates the hysteresis for the spectral efficiency gain that must be met to trigger an outgoing inter-carrier handover for a non-CA UE or serving cell combination change for a CA UE. If the estimated spectral efficiency gain brought by the handover or combination change is greater than the hysteresis, the eNodeB triggers the handover or combination change. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a lower probability of triggering optimal carrier selection based on the improvement on UE spectral efficiency. Therefore, the system throughput improvement is significant each time optimal carrier selection is triggered. However, the less frequent triggering of carrier selection still affects the system throughput improvement. A smaller value of this parameter indicates a higher probability of triggering optimal carrier selection based on the improvement on UE spectral efficiency. As a result, the number of handovers increases. The system throughput improvement is slight each time a handover is triggered. The probability of ping-pong handovers increases.

Applicable Mode: L-FDD, L-TDD
LoadDiffRatioThld Load Difference Ratio Threshold

Meaning: Indicates the ratio threshold of the load difference between the serving cell and an inter-frequency neighboring cell. A neighboring cell can be a target cell for optimal carrier selection when the following condition is met: (Serving cell load - Neighboring cell load)/Serving cell load >= LoadDiffRatioThld. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -100~100

Unit: %

Actual Value Range: -100~100

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher requirement on resource sufficiency of neighboring cells. Therefore, it is less likely that neighboring cells meet the requirement. However, there is a higher probability of triggering handovers for optimal carrier selection to neighboring cells meeting the requirement. A smaller value of this parameter leads to a lower requirement on resource sufficiency of neighboring cells. Therefore, it is more likely that neighboring cells meet the requirement. However, there is a lower probability of triggering handovers for optimal carrier selection to neighboring cells whose load difference from the serving cell is small.

Applicable Mode: L-FDD, L-TDD
MbocsAlgorithmSwitch MBOCS Algorithm Switch

Meaning: Indicates whether to enable multi-band optimal carrier selection (MBOCS).

DL_CA_UE_ENH_SWITCH: Indicates whether to allow MBOCS between FDD and TDD and controls the scope of downlink CA UEs that can be selected for MBOCS. If this option is deselected, the eNodeB can select only non-CA UEs and UEs with two downlink CCs aggregated. If this option is selected, the eNodeB can also select UEs with three to five downlink CCs aggregated. These carriers can be FDD-only, TDD-only, or FDD+TDD carriers. In addition, MBOCS between FDD and TDD is allowed only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PROHIBIT_PCC_HANDOVER_SWITCH: Indicates whether to prohibit PCC change for CA UEs during MBOCS. If this option is selected, PCC change for CA UEs is prohibited during MBOCS. If this option is deselected, PCC change for CA UEs is allowed during MBOCS. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: DL_CA_UE_ENH_SWITCH(DL_CA_UE_ENH_SWITCH), PROHIBIT_PCC_HANDOVER_SWITCH(PROHIBIT_PCC_HANDOVER_SWITCH)

Unit: None

Actual Value Range: DL_CA_UE_ENH_SWITCH, PROHIBIT_PCC_HANDOVER_SWITCH

MML Default Value: None

Recommended Value: DL_CA_UE_ENH_SWITCH:On, PROHIBIT_PCC_HANDOVER_SWITCH:Off

Parameter Relationship:

-Configuration constraints:

  • When the PROHIBIT_PCC_HANDOVER_SWITCH option of the MbocsAlgorithmSwitch parameter in a CellMbfcs MO is selected, the DL_CA_UE_ENH_SWITCH option of the MbocsAlgorithmSwitch parameter in the same MO must be selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DL_CA_UE_ENH_SWITCH: Selecting this option increases the number of inter-frequency measurements, the number of inter-frequency handovers, and the average downlink throughput of CA UEs on the network.

PROHIBIT_PCC_HANDOVER_SWITCH: Selecting this option decreases the number of inter-frequency handovers and the average downlink throughput of CA UEs on the network. If this option is deselected, there is no impact on network performance.

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameters  of multi-band fast carrier selection configuration as follows: Local cell ID: 0, measurement information update interval is 1024ms, run the following command:
MOD CELLMBFCS: LocalCellId=0, MeasInfoUpdInterval=1024ms;
