Remove Inter-Frequency Neighboring Relation with E-UTRAN Cell (RMV EUTRANINTERFREQNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more neighbor relationships with inter-frequency E-UTRAN cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If all parameters are specified, only the configuration of the one inter-frequency neighboring cell with the same parameter settings is removed after the command is executed.

  • If some parameters are specified, configurations of the inter-frequency neighboring cells with the same parameter settings are removed after this command is executed, and a maximum of 640 inter-frequency neighboring cell configurations can be removed at a time.

  • If no parameter is specified, configurations of all inter-frequency neighboring cells are removed after this command is executed, and a maximum of 640 inter-frequency neighboring cell configurations can be removed at a time.

Mcc Mobile country code

Meaning: Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

Unit: None

Actual Value Range: 000~999

Meaning: Indicates the mobile network code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

eNodeBId eNodeB ID

Meaning: Indicates the eNodeB ID of the inter-frequency neighboring cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Example

To remove the inter-frequency neighboring relation with the following parameters: Local cell ID: 0, Mobile country code: 460, Mobile network code: 20, eNodeB ID: 2, Cell ID: 1, run the following command:
RMV EUTRANINTERFREQNCELL: LocalCellId=0, Mcc="460", Mnc="20", eNodeBId=2, CellId=1;
To remove the inter-frequency neighboring relations with the following parameters: Mobile country code: 460, Mobile network code: 20, run the following command:
RMV EUTRANINTERFREQNCELL: Mcc="460", Mnc="20";
