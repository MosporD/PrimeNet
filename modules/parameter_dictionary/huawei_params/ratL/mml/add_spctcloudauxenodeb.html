Add Auxiliary Base Station Configuration for Spectrum Cloudification (ADD SPCTCLOUDAUXENODEB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add auxiliary base station configuration for spectrum cloudification.

Note

None.

Parameters

ID Name Description
LteNrSpectrumShrCellGrpId LTE and NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the MCC of a cell served by an auxiliary base station involved in spectrum sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the MNC of a cell served by an auxiliary base station involved in spectrum sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EnodebId eNodeB ID

Meaning: Indicates the ID of an eNodeB serving as an auxiliary eNodeB in spectrum sharing. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CellId Cell ID

Meaning: Indicates the ID of a cell served by an auxiliary base station involved in spectrum sharing. It uniquely identifies a cell within a base station. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Example

To add the auxiliary base station configuration for spectrum cloudification with the parameters as follows: Cell ID: 1, eNodeB ID: 10, LTE and NR Spectrum Sharing Cell Group ID: 2, Mobile Country Code: 460, Mobile Network Code: 01, run the following command:
ADD SPCTCLOUDAUXENODEB: CellId=1, EnodebId=10, LteNrSpectrumShrCellGrpId=2, Mcc="460", Mnc="01";
