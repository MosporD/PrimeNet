Modify Cell PDCCH Algorithm Configuration (MOD CELLPDCCHALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the PDCCH resource allocation algorithm.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Ensure that the antenna weight is valid. Otherwise, it will cause a cell activation failure during the modification of the SplitBeamPdcchSdmaSw::MASSIVE_MIMO_PDCCH_SDMA_SW option.
