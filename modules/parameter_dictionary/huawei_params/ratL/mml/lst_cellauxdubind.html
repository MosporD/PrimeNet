List Auxiliary eNodeB Cell Distributed Unit Binding Relationship (LST CELLAUXDUBIND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the binding relationship between a distributed unit and an auxiliary eNodeB for a cell.

Note

None.

Parameters

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Example

To list the auxiliary eNodeBs bound to a DU of an SFN cell:
LST CELLAUXDUBIND:;

eNodeB ID

Mobile Network Code

Auxiliary eNodeB Distributed Unit ID

Indicates the ID of the DU of an auxiliary eNodeB that serves an SFN cell. This parameter applies only to LTE FDD and LTE TDD.
