Modify Frame Offset Configuration (MOD CELLFRAMEOFFSET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify frame offset configurations of a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The frame offset configurations of all cells on the same BBP must be the same.

  • When a cell is active, modifications on the configuration of CELLFRAMEOFFSET will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
FrameOffsetMode Frame Offset Mode

Meaning: Indicates the frame offset configuration mode for the cell.

The value CustomFrameOffset(User-defined frame offset) indicates that the frame offset is user-defined. Only this value applies to FDD cells and NB-IoT cells.

The value TL_FrameOffset(T-L Dual Mode frame offset) indicates that the frame offset is automatically determined based on the subframe configuration in a TD-SCDMA + LTE TDD dual-RAT network.

The value TL_FrameOffset_SA2_SSP5(T-L Dual Mode SA2+SSP5 frame offset) indicates that the frame offset is automatically determined based on uplink-downlink configuration 2 and special subframe configuration 5 in a TD-SCDMA + LTE TDD dual-RAT network.

GUI Value Range: CustomFrameOffset(User-defined frame offset), TL_FrameOffset(T-L Dual Mode frame offset), TL_FrameOffset_SA2_SSP5(T-L Dual Mode SA2+SSP5 frame offset)

Unit: None

Actual Value Range: CustomFrameOffset, TL_FrameOffset, TL_FrameOffset_SA2_SSP5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
FrameOffset Frame Offset

Meaning: Indicates the offset of the start time of a cell frame against a reference clock source.

GUI Value Range: 0~261120,275943~307200

Unit: Ts

Actual Value Range: 0~261120,275943~307200

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • This parameter is valid only if the FrameOffsetMode parameter is set to CustomFrameOffset.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Different frame offsets between carriers in FDD+TDD CA scenarios may decrease the proportion of UEs on which FDD+TDD CA takes effect.

Applicable Mode: L

Example

Example 1: To modify the Frame Offset Mode Configuration with the parameters as follows: Local cell ID: 0, Frame Offset Mode: User-defined Frame Offset, Frame Offset(Ts): 0:
MOD CELLFRAMEOFFSET: LocalCellId=0, FrameOffsetMode=CustomFrameOffset, FrameOffset=0;
Example 2: To modify the Frame Offset Mode Configuration with the parameters as follows: Local cell ID: 0, Frame Offset Mode: T-L Dual Mode:
MOD CELLFRAMEOFFSET: LocalCellId=0, FrameOffsetMode=TL_FrameOffset;
