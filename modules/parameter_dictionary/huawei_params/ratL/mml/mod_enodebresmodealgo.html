Modify eNodeBResModeAlgo (MOD ENODEBRESMODEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to specify the eNodeBResModeAlgo.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the BbpResAutoConfigSw parameter setting is changed to ON(On) on an eNodeB and all cells are successfully activated, the BasebandEqmId parameter setting will be automatically changed to bind cells with baseband resources.

  • When the BbResExclusiveSwitch parameter is set to ON(On), BBPs cannot be shared among cells if the baseband resources and cells are automatically bound.

  • Before changing the setting of CPRI Sharing Switch from ON to OFF, deactivate all the cells using CPRI sharing. Otherwise, the cells will be deactivated after the setting of CPRI Sharing Switch is changed from ON to OFF, and each of the cells will be reestablished on the BBP where the CPRI port of the cell is located.

  • Changing the values of EnbCellDstDeploySw parameter and eNBCellNumCapabilityMode parameter affects the maximum number of cells supported by the eNodeB. You must reset the main control board to make the settings to take effect. If the main control board is not reset 10 minutes after the parameter setting is changed, ALM-26245 Configuration Data Inconsistency is reported.

  • The eNBCellNumCapabilityMode parameter cannot be set to ENHANCED_MODE in BBU interconnection scenarios.

  • Changing the value of AI_ENHANCEMENT_SWITCH switch or UMPTB_ENHANCEMENT_SWITCH switch of ServiceMode parameter. You must reset APP to make the settings to take effect. If the APP is not reset 10 minutes after the parameter setting is changed, ALM-26245 Configuration Data Inconsistency is reported.

Parameters

ID Name Description
BbpResAutoConfigSw BBP Resource Auto Config Switch

Meaning: Indicates whether to automatically or manually bind a baseband equipment ID to a cell. If this parameter is set to ON, the eNodeB automatically changes the BaseBandEqmId parameter value within 5 minutes after all cells are successfully activated, to bind the cells to baseband resources. If this parameter is set to ON_BIND, the eNodeB periodically changes the BaseBandEqmId parameter value for all activated cells to bind the cells to baseband resources. If a BASEBANDEQM MO has been configured for each BBP, the automatic baseband allocation algorithm can take effect. If a BASEBANDEQM MO is not configured for each BBP, the eNodeB automatically configures a BASEBANDEQM MO for each BBP. The MO contains information about only the corresponding BBP. If the automatic configuration fails due to causes such as a specification limit of the baseband equipment, the automatic baseband allocation algorithm does not take effect.

GUI Value Range: OFF(OFF), ON(ON), ON_BIND(ON_BIND)

Unit: None

Actual Value Range: OFF, ON, ON_BIND

MML Default Value: None

Recommended Value: OFF(OFF)

When the BbResExclusiveSwitch parameter is set to ON(ON), BBPs cannot be shared among cells if the baseband resources and cells are automatically bound. Therefore, it is recommended that this parameter be set to OFF(Off) if the BbpResAutoConfigSw parameter is set to ON(ON).

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
TddBbpResDeployAlgo TDD BBP Resource Auto Deploy Algorithm

Meaning: Indicates the baseband resource allocation policy for LTE TDD cells. If this parameter is set to RESOURCE_PRIMARY, baseband resources are preferentially allocated based on the minimum resource allocation policy, ensuring that baseband resources can be allocated to as many cells as possible. If this parameter is set to LOAD_BALANCE, the eNodeB allocates baseband resources to cells based on the principle of load balancing to ensure that a cell obtains as many baseband resources as possible. If this parameter is set to ADAPTIVE, the eNodeB automatically allocates baseband resources to cells based on the number of cells. This parameter applies only to LTE TDD.

GUI Value Range: ADAPTIVE(ADAPTIVE), RESOURCE_PRIMARY(RESOURCE_PRIMARY), LOAD_BALANCE(LOAD_BALANCE)

Unit: None

Actual Value Range: ADAPTIVE, RESOURCE_PRIMARY, LOAD_BALANCE

MML Default Value: None

Recommended Value: ADAPTIVE(ADAPTIVE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD
FddBbpResDeployAlgo FDD BBP Resource Auto Deploy Algorithm

Meaning: Indicates the baseband resource allocation policy for FDD cells. If this parameter is set to RESOURCE_PRIMARY, baseband resources are allocated preferentially based on the minimum resource allocation policy, ensuring that baseband resources can be allocated to as many cells as possible. If this parameter is set to LOAD_BALANCE, baseband resources are allocated to cells preferentially based on the principle of load balancing, ensuring that cells obtain as many baseband resources as possible. If this parameter is set to ADAPTIVE, baseband resources are automatically allocated to cells based on the number of cells. If this parameter is set to ADAPTIVE_POLICY1, baseband resources are automatically allocated to cells based on the number of cells. In addition, resources are allocated preferentially in load balancing mode to both common cells and physical cells in SFN cells if these cells are established on UBBP boards. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: ADAPTIVE(ADAPTIVE), RESOURCE_PRIMARY(RESOURCE_PRIMARY), LOAD_BALANCE(LOAD_BALANCE), ADAPTIVE_POLICY1(ADAPTIVE_POLICY1)

Unit: None

Actual Value Range: ADAPTIVE, RESOURCE_PRIMARY, LOAD_BALANCE, ADAPTIVE_POLICY1

MML Default Value: None

Recommended Value: ADAPTIVE(ADAPTIVE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-NB-IOT
BbpResAutoRecfgTimer BBP Resource Auto Reconfig Timer

Meaning: Indicates the maximum period of time available for cell activation on the bound BBP. When a cell fails to be activated within this period and the BbpResAutoConfigSw parameter is set to ON(On), the eNodeB automatically allocates available baseband resources to the cell until the cell is successfully activated. This parameter is also used to specify the internal protection time length, which is the value of this parameter minus 8 minutes. During the internal protection time, a cell fails to be activated if a fault occurs in the baseband resources bound to the cell or the baseband resources bound to the cell are occupied by another cell.

GUI Value Range: 0~65535

Unit: min

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
eNBCellNumCapabilityMode eNodeB Cell Number Capability Mode

Meaning: Indicates how to define the maximum number of cells on a single base station. If this parameter is set to NORMAL_MODE, a single UMPTa or UMPTb supports a maximum of 36 cells, a single UMPTga supports a maximum of 72 cells, and a single UMPTg supports a maximum of 144 cells. If this parameter is set to ENHANCED_MODE, two UMPTa or UMPTb boards in a single base station support a maximum of 48 cells, two UMPTga boards in a single base station support a maximum of 144 cells, and two UMPTg boards in a single base station support a maximum of 216 cells. This parameter is a base-station-level parameter and applies only to UMPTa, UMPTb, UMPTga, and UMPTg boards.

GUI Value Range: NORMAL_MODE(NORMAL_MODE), ENHANCED_MODE(ENHANCED_MODE)

Unit: None

Actual Value Range: NORMAL_MODE, ENHANCED_MODE

MML Default Value: None

Recommended Value: NORMAL_MODE(NORMAL_MODE)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
BbpCpriSharingSwitch CPRI Sharing Switch

Meaning: Indicates whether to support CPRI sharing between baseband processing units (BBPs). When this parameter is set to ON, CPRI sharing is supported and CPRI ports of a BBP or CPRI interface board are shared between specified BBPs to enable baseband processing to be independent of CPRI ports. When this parameter is set to OFF, CPRI sharing is not supported.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this parameter is set to ON, there is no impact on the cells that have already been established. When this parameter is set to OFF, all cells using CPRI sharing are deactivated and each of them is reestablished on the BBP where the CPRI port for the cell is located.

Applicable Mode: L
EnbCellDstDeploySw eNodeB Cell Distributed Deployment Switch

Meaning: Indicates whether to enable distributed cell deployment. This parameter takes effect only when a base station is equipped with two main control boards. If this parameter is set to ON, the cell management function can be deployed on two UMPT boards or UMPT+LMPT boards to increase the cell number capacity. If this parameter is set to OFF, the cell management function is deployed only on the primary UMPT.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: N/A

Applicable Mode: L
BackplaneBwLackProtectSw Backplane Bandwidth Lack Protection Switch

Meaning: Indicate whether to establish cells with reduced capacity if the backplane bandwidth is insufficient. If this parameter is set to ON(On) and the backplane bandwidth is insufficient, cells are not established with reduced capacity. If this parameter is set to OFF(Off) and the backplane bandwidth is insufficient, cells are established with reduced capacity. It is recommended that this parameter be set to ON(On) if the IR protocol is used. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(ON)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServiceMode Service Mode

Meaning: Indicates the service running mode of the eNodeB. The product specifications vary according to the serving running mode.

AI_ENHANCEMENT_SWITCH: If this option is selected and the UMPTe or UMPTga board is used, the eNodeB works under the enhanced product specifications applicable when smart features are activated. If this option is deselected, the eNodeB works under the normal product specifications applicable when smart features are deactivated.

UMPTB_ENHANCEMENT_SWITCH: If this option is selected and UMPTb is used, the eNodeB works under the enhanced product specifications applicable when intelligent features are activated. If this option is deselected, the eNodeB works under the normal product specifications applicable when intelligent features are deactivated.

GUI Value Range: AI_ENHANCEMENT_SWITCH(AI_ENHANCEMENT_SWITCH), UMPTB_ENHANCEMENT_SWITCH(UMPTB_ENHANCEMENT_SWITCH)

Unit: None

Actual Value Range: AI_ENHANCEMENT_SWITCH, UMPTB_ENHANCEMENT_SWITCH

MML Default Value: None

Recommended Value: AI_ENHANCEMENT_SWITCH:Off, UMPTB_ENHANCEMENT_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: The UE number and signaling specifications of the main control board may change when the parameter setting is changed.

AI_ENHANCEMENT_SWITCH: If this option is deselected, the default UE number and signaling specifications are used. If this option is selected, the UE number and signaling specifications used are those available when intelligent features are activated.

UMPTB_ENHANCEMENT_SWITCH: If this option is deselected, the default UE number and signaling specifications are used. If this option is selected, the UE number and signaling specifications used are those available when intelligent features are activated.

Applicable Mode: L-FDD, L-TDD

Example

To modify ENODEBRESMODEALGO as follows: BbpResAutoRecfgTimer: 9, run the following command:
MOD ENODEBRESMODEALGO: BbpResAutoRecfgTimer=9;
