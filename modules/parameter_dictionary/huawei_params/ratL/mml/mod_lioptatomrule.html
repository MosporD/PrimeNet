Modify Intelligent Optimization Atom Rule (MOD LIOPTATOMRULE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify settings of parameters related to intelligent optimization atom rules.

Note

None.

Parameters

ID Name Description
AtomRuleID Atom Rule ID

Meaning: Indicates the ID of an intelligent optimization atom rule. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ThresholdforNumPara Threshold for Numerical Parameter

Meaning: Indicates the threshold for selecting measurement objects with numerical values in intelligent optimization atom rules. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -2147483647~2147483647
