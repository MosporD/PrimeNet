Modify Beamforming Antenna (MOD BFANT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a beamforming antenna.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may disrupt cell services.

Meaning: Indicates the device number of a beamforming antenna. It uniquely identifies a beamforming antenna within an eNodeB. This parameter is associated with the WeightNO parameter in the eUCellSectorEqm MO. If the WeightNO parameter in the eUCellSectorEqm MO is set to 255, the weight corresponding to the smallest DeviceNo parameter value is used. This parameter applies only to LTE TDD.

CrsSplitBeamIndicator CRS Split Beam Indicator

Meaning: Indicates a split beam for the CRS of a cell from a split. If this parameter is set to a value ranging from 0 to 7, the eNodeB uses the split beam specified by this parameter to transmit the CRS of the soft split cell. The values 0 to 7 are divided into four groups: (0, 1), (2, 3), (4, 5), and (6, 7). This parameter must be set to different values in any of these groups for two split cells in a SSRDCellGroup MO. For example, if this parameter is set to 0 for the primary cell in a SSRDCellGroup MO, this parameter must be set to 1 for the split cell in the same MO. If this parameter is set to 255, the eNodeB uses the default split beam to transmit the CRS of the soft split cell. This parameter applies only to LTE TDD.

GUI Value Range: 0~7,255

Unit: None

Actual Value Range: 0~7,255

MML Default Value: None

Recommended Value: 255

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The eNodeB uses the split beam specified by this parameter to transmit the CRS of a soft split cell. Changing the split beam used for CRS transmission affects cell coverage and causes changes in network KPIs. Set this parameter based on cell coverage.

BFANTBEARING BFANTBEARING

Meaning: Indicates angle at which an antenna deflects the horizontal azimuth of the beam (weight-based deflection relative to the mechanical azimuth). In non-massive MIMO scenarios, this parameter indicates only the degree at which a smart antenna deflects. In massive MIMO scenarios, this parameter indicates the degree at which an antenna deflects. With the mechanical azimuth of the antenna as the normal line, a clockwise deflection requires a positive value and a counterclockwise deflection requires a negative value. This parameter applies only to broadcast beams, but not to traffic beams. This parameter applies only to LTE TDD.

GUI Value Range: -90~90

Unit: degree

Actual Value Range: -90~90

MML Default Value: None

Recommended Value: 0 when CoverageScenario is set to SCENARIO_1 or SCENARIO_5

A value in the range of -10 to 10 when CoverageScenario is set to SCENARIO_2, SCENARIO_6, or SCENARIO_10

A value in the range of -20 to 20 when CoverageScenario is set to SCENARIO_3, SCENARIO_7, or SCENARIO_11

A value in the range of -30 to 30 when CoverageScenario is set to SCENARIO_4, SCENARIO_8, SCENARIO_9, SCENARIO_12, or SCENARIO_13

CoverageScenario Coverage Scenario

Meaning: Indicates the coverage scenario of a massive MIMO antenna. This parameter is used to adjust the antenna beam pattern. The values EXPANDSCENARIO_1, EXPANDSCENARIO_2, and EXPANDSCENARIO_3 indicate user-defined coverage scenarios. For 64T64R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. For 32T32R cells: The vertical beamwidth of a massive MIMO antenna is equivalent to the vertical beamwidth of a single channel, and adjusting the TILT parameter in the BfAnt MO has no effect if this parameter is set to SCENARIO_5, SCENARIO_6, SCENARIO_7, SCENARIO_8, SCENARIO_9, SCENARIO_15, or SCENARIO_17. Due to the limited vertical beamwidth of a single 32T32R channel, it is not recommended that this parameter be set to SCENARIO_10, SCENARIO_11, SCENARIO_12, or SCENARIO_13. This parameter applies only to LTE TDD.

Example

To modify the configuration of a beamforming antenna with the parameters as follows: Device No.: 0, Connect RRU subrack No.: 61, Antenna model number: TYDA-2015D4T0, Band: 34, run the following command:
MOD BFANT: DEVICENO=0, CONNSRN=61, MODELNO="TYDA-2015D4T0", Band=34;
