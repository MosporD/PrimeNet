Modify Co-Processing Resources (MOD COPROCRES)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify information about co-processing resources.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Running this command will disrupt services carried by the board specified by the BASEBANDEQMID parameter in the associated BASEBANDEQM MO.

Parameters

ID Name Description
CoProcResId Coordinate Process Resource ID

Meaning: Indicates a co-processing resource index. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~12

Unit: None

Actual Value Range: 0~12

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BaseBandEqmId BaseBand Equipment ID

Meaning: Indicates the ID of the baseband equipment providing co-processing resources. When this parameter is set to 255, no baseband equipment is specified. In this scenario, the eNodeB selects baseband processing units (BBPs) for providing co-processing resources among all BBPs in the eNodeB. When this parameter is set to a value other than 255, the eNodeB selects BBPs contained in the specified baseband equipment for providing co-processing resources. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~23,255

Unit: None

Actual Value Range: 0~23,255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BundlingClusterType Bundling Cluster Type

Meaning: Indicates the type of the cluster bound to co-processing resources. If this parameter is set to ADAPTIVE, no cluster type is specified and the eNodeB adaptively specifies a cluster type based on the coordination processing requirements of coordination features. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: ADAPTIVE(ADAPTIVE), CSPC(CSPC), DL_COMP(DL_COMP), UL_ICS(UL_ICS), DMIMO(DMIMO)

Unit: None

Actual Value Range: ADAPTIVE, CSPC, DL_COMP, UL_ICS, DMIMO

MML Default Value: None

Recommended Value: ADAPTIVE(ADAPTIVE)

Parameter Relationship:

-Configuration constraints:

  • If both the COORDINATING_PROCESSING and BASEBAND_PROCESSING options of the WorkMode parameter in the CoProcRes MO are selected, the BundlingClusterType parameter in the CoProcRes MO must not be set to DMIMO or CSPC.
  • If only the BASEBAND_PROCESSING option among all options of the WorkMode parameter in the CoProcRes MO is selected, the BundlingClusterType parameter in the CoProcRes MO must not be set to CSPC, DL_COMP, or UL_ICS.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
WorkMode Work Mode

Meaning: Indicates the working mode of co-processing resources. This parameter includes the following options:

BASEBAND_PROCESSING: Indicates that the baseband equipment performs general baseband processing.

COORDINATING_PROCESSING: Indicates that the baseband equipment performs coordination processing.

CLUSTER_MANAGEMENT: Indicates that the baseband equipment performs cluster management. Only one piece of baseband equipment can be configured in an eNodeB for cluster management.

This option applies only to LTE FDD and LTE TDD.

GUI Value Range: BASEBAND_PROCESSING(BASEBAND_PROCESSING), COORDINATING_PROCESSING(COORDINATING_PROCESSING), CLUSTER_MANAGEMENT(CLUSTER_MANAGEMENT)

Unit: None

Actual Value Range: BASEBAND_PROCESSING, COORDINATING_PROCESSING, CLUSTER_MANAGEMENT

MML Default Value: None

Recommended Value: BASEBAND_PROCESSING:Off

COORDINATING_PROCESSING:Off

CLUSTER_MANAGEMENT:Off

Parameter Relationship:

-Configuration constraints:

  • The COORDINATING_PROCESSING option of the WorkMode parameter in the CoProcRes MO must be selected if the CLUSTER_MANAGEMENT option of this parameter is selected.
  • There must not be more than one CoProcRes MO in which the CLUSTER_MANAGEMENT or COORDINATING_PROCESSING option of the WorkMode parameter is selected.
  • If both the COORDINATING_PROCESSING and BASEBAND_PROCESSING options of the WorkMode parameter in the CoProcRes MO are selected, the BundlingClusterType parameter in the CoProcRes MO must not be set to DMIMO or CSPC.
  • If only the BASEBAND_PROCESSING option among all options of the WorkMode parameter in the CoProcRes MO is selected, the BundlingClusterType parameter in the CoProcRes MO must not be set to CSPC, DL_COMP, or UL_ICS.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the setting of the BASEBAND_PROCESSING option is changed from On to Off, services in cells established on common baseband equipment are interrupted.

Applicable Mode: L-FDD, L-TDD

Example

To modify the co-processing resources with the parameters as follows:Coordinate Process Resource ID: 0, BaseBand Equipment ID : 1, run the following command:
MOD COPROCRES: CoProcResId=0, BaseBandEqmId=1;
