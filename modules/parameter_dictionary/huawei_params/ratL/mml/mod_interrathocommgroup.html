Modify Common Parameter Group for Inter-RAT Handover (MOD INTERRATHOCOMMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a group of common parameters related to inter-RAT handover.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

InterRatHoA1A2Hyst InterRAT A1A2 hysteresis

Meaning: Indicates the hysteresis of events A1/A2 for triggering inter-RAT measurement. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The entering condition of event A1 is as follows: Ms - Hys > Thresh, and the entering condition of event A2 is as follows: Ms + Hys < Thresh. Where, Ms is the measurement value of the serving cell, Hys is the hysteresis for the corresponding event in the measurement configuration, and Thresh is the threshold for entering the corresponding event. A larger value of Hys causes a lower probability of entering the corresponding event, and a smaller value of Hys causes a higher probability of entering the corresponding event.

Applicable Mode: L-FDD, L-TDD
InterRatHoA1A2TimeToTrig InterRAT A1A2 time to trigger

Meaning: Indicates the time-to-trigger of A1 or A2 for triggering inter-RAT measurement.

When detecting that the signal quality in the serving cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition during the time-to-trigger.

This parameter helps decrease the number of occasionally triggered event reporting, the average number of handovers, and the number of wrong handovers. In summary, it helps prevent unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: 640ms

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: An appropriate setting of this parameter can effectively prevent unnecessary inter-RAT measurements and reduce the number of inter-RAT measurements. A larger value results in a smaller average number of inter-RAT measurements but a higher probability of service drops.

Applicable Mode: L-FDD, L-TDD
InterRatHoA1ThdRsrp InterRAT A1 RSRP trigger threshold

Meaning: Indicates the RSRP threshold for event A1 related to inter-RAT handovers except handovers to NG-RAN.

When the measured RSRP value of the serving cell exceeds this threshold, an event A1 report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -111

Parameter Relationship:

-Configuration constraints:

  • In an InterRatHoCommGroup MO, the value of InterRatHoA1ThdRsrp must be greater than or equal to the value of InterRatHoA2ThdRsrp.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The entering condition of event A1 is as follows: Ms - Hys > Thresh, where Thresh is the threshold for this event. A higher threshold makes it more difficult to trigger event A1 and stop inter-RAT measurement. A lower threshold makes it easier to trigger event A1 and stop inter-RAT measurement.

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the QCI-specific quantity to determine whether to trigger inter-RAT measurements or blind handovers based on inter-RAT event A2. If this parameter is set to BOTH, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on either RSRP or RSRQ. If this parameter is set to RSRP, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on RSRP. If this parameter is set to RSRQ, the eNodeB determines whether to trigger inter-RAT measurements or blind handovers based on RSRQ. This parameter is valid only if the InterRatHoA1A2TrigQuan parameter is set to BOTH in the InterRatHoComm MO. This parameter applies only to LTE FDD and LTE TDD.

Example

To modify a group of common parameters related to inter-RAT handover as follows: Local cell identity: 0, InterRatHoCommGroupId: 9, InterRAT A1A2 time to trigger: 640ms, run the following command:
MOD INTERRATHOCOMMGROUP: LocalCellId=0, InterRatHoCommGroupId=9, InterRatHoA1A2TimeToTrig=640ms;
