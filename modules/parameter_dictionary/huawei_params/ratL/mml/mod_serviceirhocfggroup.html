Modify Service-based Inter-RAT Handover Policy Group (MOD SERVICEIRHOCFGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a service-based inter-RAT handover policy group.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServiceIrHoCfgGroupId Service-based inter-RAT handover policy group ID

Meaning: Indicates the ID of the service-based inter-RAT handover policy group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoState Inter-RAT handover state

Meaning: Indicates whether the status of service-based inter-RAT handovers for services with a specific QCI. If this parameter is set to NO_HO, service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN, UTRAN, and GERAN are not allowed. If this parameter is set to PERMIT_HO, then service-based inter-RAT handovers of services with the QCI from E-UTRAN to UTRAN and GERAN are allowed but cannot be proactively triggered, and service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN can be triggered. If this parameter is set to MUST_HO, service-based inter-RAT handovers of services with the QCI from E-UTRAN to NG-RAN, UTRAN, and GERAN can be triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO_HO, PERMIT_HO, MUST_HO

Unit: None

Actual Value Range: NO_HO, PERMIT_HO, MUST_HO

MML Default Value: None

Recommended Value: This parameter can be set by the eNodeB by default. The default value is as follows:

ServiceIrHoCfgGroupId is set to 0: NO_HO

ServiceIrHoCfgGroupId is set to 1: PERMIT_HO

ServiceIrHoCfgGroupId is set to 2: MUST_HO

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ServiceIrMeasMode Service-based Inter-RAT HO Measure Mode

Meaning: Indicates the mode of service-based EUTRAN-to-GERAN and EUTRAN-to-UTRAN handover measurements. Assume that conditions for delivering measurement configurations related to both the service-based inter-frequency handovers and service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers are met. If the ServiceIrMeasMode parameter is set to SERVICE_IR_MEAS_ORDER, the eNodeB delivers the measurement configurations for service-based inter-frequency handovers first. After the service-based inter-frequency handover measurement times out, the eNodeB delivers measurement configurations for service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers. If the ServiceIrMeasMode parameter is set to SERVICE_IR_MEAS_NO_ORDER, the eNodeB delivers the measurement configurations for both service-based inter-frequency handovers and service-based EUTRAN-to-GERAN or EUTRAN-to-UTRAN handovers. This parameter applies only to LTE TDD.

GUI Value Range: SERVICE_IR_MEAS_NO_ORDER, SERVICE_IR_MEAS_ORDER

Unit: None

Actual Value Range: SERVICE_IR_MEAS_NO_ORDER, SERVICE_IR_MEAS_ORDER

MML Default Value: None

Recommended Value: SERVICE_IR_MEAS_NO_ORDER

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to SERVICE_IR_MEAS_NO_ORDER, during UE bearer changes, and the priority of the UE being handed over to an inter-frequency network is the same as that of the UE being handed over to an inter-RAT network.

If this parameter is set to SERVICE_IR_MEAS_ORDER, during UE bearer changes, and the UE is handed over to an inter-frequency network preferentially.

Applicable Mode: L-TDD

Example

To modify a service-based inter-RAT handover policy group with the parameters as follows: Cn Operator ID: 0, ServiceIrHoCfgGroupId: 9, InterRatHoState: NO_HO, run the following command:
MOD SERVICEIRHOCFGGROUP: CnOperatorId=0, ServiceIrHoCfgGroupId=9, InterRatHoState=NO_HO;
