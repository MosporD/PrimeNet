Modify Cell MLB Ue Select Parameter (MOD CELLMLBUESEL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-specific parameters related to UE selection for MLB.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UeSelectPrbPrio UE Select PRB Priority

Meaning: Indicates the priority of the UEs' PRB usage used as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the PRB usage is not regarded as a criterion for MLB-oriented UE selection. The parameter value 255 indicates that the PRB usage is regarded as a mandatory criterion for MLB-oriented UE selection. The parameter value ranging from 1 through 254 indicates that the PRB usage is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and this UE selection criterion has a higher priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UeSelectQciPrio UE Select QCI Priority

Meaning: Indicates the priority of the UEs' QCI as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the QCI is not regarded as a criterion for MLB-oriented UE selection, the parameter value 255 indicates that the QCI is regarded as a mandatory criterion for MLB-oriented UE selection, and the parameter value ranging from 1 to 254 indicates that the QCI is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

UeSelectArpPrio UE Select ARP Priority

Meaning: Indicates the priority of the UEs' ARP as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the ARP is not regarded as a criterion for MLB-oriented UE selection, the parameter value 255 indicates that the ARP is regarded as a mandatory criterion for MLB-oriented UE selection, and the parameter value ranging from 1 to 254 indicates that the ARP is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.

UeSelectDlMcsPrio UE Select DL MCS Priority

Meaning: Indicates the priority of the UEs' downlink MCS as a criterion for MLB-oriented UE selection. The parameter value 0 indicates that the downlink MCS is not regarded as a criterion for MLB-oriented UE selection. The parameter value 255 indicates that the downlink MCS is regarded as a mandatory criterion for MLB-oriented UE selection. The parameter value ranging from 1 to 254 indicates that the downlink MCS is regarded as a preferential criterion for MLB-oriented UE selection. A larger value indicates a higher priority, and UEs meeting the criterion have a higher priority to be selected for MLB. This parameter applies only to LTE FDD and LTE TDD.

InterFreqMlbUeArpThd Inter-Freq MLB UE Select ARP Threshold

Meaning: Indicates the ARP threshold for selecting UEs to be transferred for MLB. A UE is selected only if the ARPs of all the UE's services is higher than or equal to this threshold. The parameter value 1 indicates the highest priority and the parameter value 15 indicates the lowest priority. If this parameter is set to a large value, UEs with low service priorities are selected to perform MLB. This parameter applies only to LTE FDD and LTE TDD.

InterFreqMlbUeDlMcsThd Inter-Freq MLB UE Select DL MCS Threshold

Meaning: Indicates the downlink MCS index threshold for selecting UEs to be transferred for MLB. A UE is selected only if the downlink MCS index of the UE is greater than or equal to this threshold. If this parameter is set to a large value, UEs with favorable downlink channel quality are selected for MLB. This parameter applies only to LTE FDD and LTE TDD.

MmLoadSteeringUePrbThld MM Load Steering UE PRB Thld

Meaning: Indicates the PRB usage threshold for selecting UEs to be transferred after massive MIMO load transfer is triggered for non-massive MIMO cells. If the downlink PRB usage of a UE is greater than or equal to this threshold, the UE can be selected for load steering. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter leads to a small number of UEs that can be selected for load transfer in massive MIMO cells and a small number of UEs that can be paired in massive MIMO cells. However, multi-user pairing performance is good for UEs transferred to massive MIMO cells.

A small value of this parameter leads to a large number of UEs that can be selected for load transfer in massive MIMO cells and a large number of UEs that can be paired in massive MIMO cells. However, multi-user pairing performance is poor for UEs transferred to massive MIMO cells.

Applicable Mode: L-FDD, L-TDD
UlExpServSteerUeSelMcsThld UL-Exp-oriented Serv Steering UE Sel MCS Thld

Meaning: Indicates the uplink MCS index threshold for UE selection in uplink-experience-oriented service steering. If this parameter is set to 0, the eNodeB does not consider the uplink MCS index when selecting a UE. If this parameter is set to a value other than 0 and the uplink MCS index of a UE is less than this threshold, the UE is selected as a target UE to be transferred. This parameter applies only to LTE TDD.

GUI Value Range: 0~28

Unit: None

Actual Value Range: 0~28

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter (non-zero value) leads to a higher probability of UEs being selected as target UEs to be transferred and higher average uplink cell throughput. A smaller value of this parameter leads to a lower probability of UEs being selected as targeted UEs to be transferred, affecting the maximization of the average uplink cell throughput. If this parameter is set to 0, network performance is not affected.

Applicable Mode: L-TDD
NsaDcUeSelectionStrategy NSA DC UE Selection Strategy

Meaning: Indicates the policy of selecting NSA DC UEs for user-number-based connected mode load equalization and PRB-usage-based connected mode load equalization. If this parameter is set to LTE_NSA_DC_FAIR, NSA DC UEs and LTE UEs are selected at random for load equalization. If this parameter is set to LTE_UE_PREFERRED, UEs not supporting NSA DC and NSA DC UEs are selected for load equalization in descending order of preference. If this parameter is set to NSA_DC_UE_PREFERRED, UEs supporting NSA DC and UEs not supporting NSA DC are selected for load equalization in descending order of preference. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: LTE_NSA_DC_FAIR(LTE_NSA_DC_FAIR), LTE_UE_PREFERRED(LTE_UE_PREFERRED), NSA_DC_UE_PREFERRED(NSA_DC_UE_PREFERRED)

Unit: None

Actual Value Range: LTE_NSA_DC_FAIR, LTE_UE_PREFERRED, NSA_DC_UE_PREFERRED

MML Default Value: None

Recommended Value: LTE_UE_PREFERRED

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to LTE_NSA_DC_FAIR, network performance is not affected. If this parameter is set to LTE_UE_PREFERRED, LTE UEs are preferentially transferred, which helps guarantee user experience of NSA DC UEs. If this parameter is set to NSA_DC_UE_PREFERRED, NSA DC UEs are preferentially transferred, which helps guarantee user experience of LTE UEs.

Applicable Mode: L-FDD, L-TDD

Example

To modify the cell MLB Ue select parameter with the parameters as follows: Local cell ID: 0, UE Select PRB Priority: 255, UE Select QCI Priority: 0, run the following command:
MOD CELLMLBUESEL: LocalCellId=0, UeSelectPrbPrio=255, UeSelectQciPrio=0;
