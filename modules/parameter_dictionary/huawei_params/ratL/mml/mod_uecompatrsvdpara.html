Modify UeCompatRsvdPara (MOD UECOMPATRSVDPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of UE compatibility reserved parameters.

Note

  • Do not modify a not-in-use reserved parameter.

  • If an in-use reserved parameter that has been configured is set to a value not in the value range, the default parameter value will be used.

  • Modify in-use reserved parameters according to the descriptions in (eNodeB) Used Reserved Parameter List in the 03-Reserved List folder that is delivered with Release Documents-EN of the corresponding version.

Example

To modify the reserved UE compatibility parameters with an index of 1 and change the values of Reserved Switch Parameter 0 and Reserved Switch Parameter 1 to RsvdSwPara0_bit1 and RsvdSwPara1_bit2, respectively, run the following command:
MOD UECOMPATRSVDPARA: Index=1, RsvdSwPara0=RsvdSwPara0_bit1-1, RsvdSwPara1=RsvdSwPara1_bit2-1;
