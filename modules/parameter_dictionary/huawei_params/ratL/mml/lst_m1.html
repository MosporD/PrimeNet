List M1 Configuration (LST M1)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of an M1 object.

Note

None.

Parameters

ID Name Description
M1Id M1 ID

Meaning: Indicates the M1 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the M1 object information, run the following command:
+++    HUAWEI        2013-04-25 10:49:41
O&M    #2422
%%LST M1:;%%
RETCODE = 0  Operation succeeded.
List M1 Configuration
---------------------
                M1 ID  =  0
M1 End Point Group ID  =  456
           User Label  =  M1
(Number of results = 1)
---    END

Output Description

Field Description

M1 ID

Indicates the M1 object ID. This parameter applies only to LTE FDD and LTE TDD.

M1 Network Type

Indicates the type of network served by the M1 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.

M1 End Point Group ID

Indicates the ID of the endpoint group used by the M1 MO. This parameter applies only to LTE FDD and LTE TDD.

User Label

Indicates the descriptions of the M1 MO. This parameter applies only to LTE FDD and LTE TDD.
