Modify Common Parameters for Inter-RAT Handover (MOD INTERRATHOCOMM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the common parameters about inter-RAT handovers.

Note

None.

Parameters

ID Name Description
InterRatHoMaxRprtCell Max report cell number

Meaning: Indicates the maximum number of cells to be included in the measurement report after an inter-RAT handover event or a periodic inter-RAT measurement for ANR purposes is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A decrease in the value of this parameter indicates a decrease in the number of candidate cells for each handover. In this case, the success rate of the handover triggered by each measurement report is decreased, but the required amount of radio interface resource is reduced.

Applicable Mode: L-FDD, L-TDD
InterRatHoRprtAmount Measurement report amount

Meaning: Indicates the number of periodic measurement reports to be sent after an inter-RAT handover event is triggered. It is used to prevent the impact of measurement report loss and internal processing failure on the handover. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: r1(1), r2(2), r4(4), r8(8), r16(16), r32(32), r64(64), Infinity(Infinity)

Unit: None

Actual Value Range: r1, r2, r4, r8, r16, r32, r64, Infinity

MML Default Value: None

Recommended Value: infinity(Infinity)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the value is increased, the number of reports increases and the handover success rate rises to a certain extent. An excessively large number of reports, however, results in excessive signaling and hence causes a waste of radio interface resources.

Applicable Mode: L-FDD, L-TDD
InterRatHoGeranRprtInterval Geran measurement report interval

Meaning: Indicates the interval at which periodic measurement reports are sent to the eNodeB after the event for inter-RAT handover to GERAN is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 120ms(120ms), 240ms(240ms), 480ms(480ms), 640ms(640ms), 1024ms(1024ms), 2048ms(2048ms), 5120ms(5120ms), 10240ms(10240ms), 1min(1min), 6min(6min), 12min(12min), 30min(30min), 60min(60min)

Unit: None

Actual Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

MML Default Value: None

Recommended Value: 480ms(480ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to more measurement reports over the air interface and therefore more air interface resources are consumed. A larger value of this parameter results in a larger handover retry delay, which lowers the handover success rate. Therefore, a smaller value is recommended to ensure timely handovers in the initial phase of LTE network deployment.

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranB1MeasQuan Utran measurement trigger quantity

Meaning: Indicates the quantity to be measured for handovers to UTRAN FDD cells. RSCP values are relatively stable while Ec/N0 values fluctuate with the network load. The value BOTH applies only to UEs complying with 3GPP Release 10 or later. UEs complying with 3GPP Release 10 or later include both RSCP and Ec/N0 values in measurement reports. When both RSCP- and Ec/N0-based trigger conditions are met, handovers can be triggered. For UEs complying with 3GPP Release 8 or 9, the value BOTH produces the same effect as the value RSCP. QoE-based handover algorithms do not apply to UEs complying with 3GPP Release 8 and Release 9, and the applicable quantity is always Ec/N0. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RSCP, ECN0, BOTH

Unit: None

Actual Value Range: RSCP, ECN0, BOTH

MML Default Value: None

Recommended Value: ECN0(ECN0)

Parameter Relationship: None

Impact on Radio Network Performance: None

InterRatHoA1A2TrigQuan InterRat A1A2 measurement trigger quantity

Meaning: Indicates the triggering quantity of inter-RAT events A1 and A2. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RSRP(RSRP), RSRQ(RSRQ), BOTH(BOTH)

CdmaHrpdSectorIdSelMode CDMA2000 eHRPD SectorID Select Mode

Meaning: Indicates the method of selecting reference cells during an optimized handover from E-UTRAN to CDMA2000 eHRPD. One method is selecting reference cells configured on the eNodeB. The other method is selecting neighboring CDMA2000 eHRPD cells with the best signal quality indicated by measurement reports. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BY_RATIO(BY_RATIO), BY_MEAS_RESULT(BY_MEAS_RESULT)

Unit: None

Actual Value Range: BY_RATIO, BY_MEAS_RESULT

MML Default Value: None

Recommended Value: BY_MEAS_RESULT

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to BY_MEAS_RESULT, the probability that CDMA2000 network cell pseudo noises (PNs) are correctly identified increases, leading to higher success rate of optimized handovers from E-UTRAN to CDMA2000 network.

The value BY_RATIO is applicable when only a few reference cells are configured for LTE cells. If multiple CDMA reference cells are configured for an LTE cell, the value BY_MEAS_RESULT is recommended.

Applicable Mode: L-FDD, L-TDD

Example

To modify the common parameters related to the inter-RAT handover measurement as follows: Max report cell number: 8, Measurement report amount: r2, Geran measurement report interval: 480ms, Utran measurement trigger quantity: RSCP, UTRAN FDD measurement report interval: 640ms, CDMA20001XRTT measurement trigger quantity: PILOT_STRENGTH, CDMA20001XRTT measurement report interval: 480ms, CDMA2000HRPD measurement trigger quantity: PILOT_STRENGTH, CDMA2000HRPD measurement report interval: 240ms, InterRat A1A2 measurement trigger quantity: RSRP, Max Utran cell num in redirection: 8, Max Geran cell num in redirection: 8, run the following command:
MOD INTERRATHOCOMM: InterRatHoMaxRprtCell=8, InterRatHoRprtAmount=r2, InterRatHoGeranRprtInterval=480ms, InterRatHoUtranB1MeasQuan=RSCP, InterRatHoUtranRprtInterval=640ms, InterRatHoCdma1xRttB1MeasQuan=PILOT_STRENGTH, InterRatCdma1xRttRprtInterval=480ms, InterRatHoCdmaHrpdB1MeasQuan=PILOT_STRENGTH, InterRatCdmaHrpdRprtInterval=240ms, InterRatHoA1A2TrigQuan=RSRP, CellInfoMaxUtranCellNum=8, CellInfoMaxGeranCellNum=8;
