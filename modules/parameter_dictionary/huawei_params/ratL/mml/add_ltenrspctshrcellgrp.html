Add configurations of an LTE and NR spectrum sharing cell group (ADD LTENRSPCTSHRCELLGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add configurations of an LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
LteNrSpectrumShrCellGrpId LTE and NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LteNrSpctShrLtePriResRatio LTE Prior Res Ratio in LTE and NR Spectrum Shr

Meaning: Indicates the total percentage of uplink and downlink spectrum resources to be preferentially allocated to LTE for MBB services in LTE FDD and NR spectrum sharing scenarios. The total percentage of uplink and downlink spectrum resources to be preferentially allocated to NR is equal to the result of 100% minus the value of this parameter. If this parameter is set to X%, X% of the uplink and downlink spectrum resources are preferentially allocated to LTE within a measurement period (for example, 100 ms). If the X% spectrum resources are not used up by LTE, the remaining resources can be dynamically allocated to NR when NR services require more than (100% - X%) spectrum resources. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 100

Recommended Value: In LTE precedence scenarios, the value 80 is recommended.

In NR precedence scenarios, the value 20 is recommended.

In scenarios where even spectrum resource allocation between LTE and NR is required, the value 50 is recommended.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower percentage of spectrum resources preferentially allocated to LTE and lower average LTE UE throughput. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
LteNrCoCarrCoCpriDataSw LTE and NR Co Carrier Co CPRI Data Switch

Meaning: Indicates whether LTE and NR share RRU carrier and CPRI data resources. If LTE and NR share optical fibers, they will share RRU carrier and CPRI data resources when this parameter is set ON. They will use their respective RRU carrier and CPRI data resources when this parameter is set to OFF. This parameter applies only to LTE FDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(OFF)

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this parameter is set to ON, LTE and NR consume one set of carrier resources and CPRI bandwidth. When this parameter is set to OFF, LTE and NR consume two sets of carrier resources and CPRI bandwidth.

Applicable Mode: L-FDD
LteNrUlSpectrumShrMode LTE and NR Uplink Spectrum Sharing Mode

Meaning: Indicates the mode of uplink spectrum sharing between LTE FDD and NR. This parameter applies only to LTE FDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB. Therefore, avoid using this parameter.

GUI Value Range: STATIC_SHARING(STATIC_SHARING), DYNAMIC_SHARING(DYNAMIC_SHARING)

Unit: None

Actual Value Range: STATIC_SHARING, DYNAMIC_SHARING

MML Default Value: DYNAMIC_SHARING(DYNAMIC_SHARING)

Recommended Value: DYNAMIC_SHARING(DYNAMIC_SHARING)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to STATIC_SHARING, uplink spectrum is statically shared between LTE and NR. If this parameter is set to DYNAMIC_SHARING, uplink spectrum is dynamically shared between LTE and NR.

Applicable Mode: L-FDD
RateOfUlSpectrumAllocToNr Rate of Uplink Spectrum Allocated to NR

Meaning: Indicates the rate of uplink spectrum to be allocated to NR. This parameter applies only to LTE FDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB. Therefore, avoid using this parameter.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 50

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer RB resources that can be allocated to NR and a smaller decrease in the uplink LTE throughput. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
LteGuaranteePuschRbNum LTE Guarantee PUSCH RB Number

Meaning: Indicates the PUSCH RB quantity guaranteed for LTE when LTE FDD and NR Uplink Spectrum Sharing is used. If this parameter is set to a value less than the minimum number of PUSCH RBs required by LTE, the number of PUSCH RBs actually allocated to LTE is at least this minimum number. If this parameter is set to a value greater than the maximum number of PUSCH RBs that can be allocated to LTE, the number of PUSCH RBs actually allocated to LTE may be less than the value of this parameter. If the sum of the PUSCH RB quantity guaranteed for LTE and PUSCH RB quantity guaranteed for NR is greater than the total number of PUSCH RBs that can be shared between LTE and NR, the number of PUSCH RBs actually allocated to LTE may be different from the value of this parameter. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~100

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer PUSCH RB resources that can be guaranteed for LTE and lower uplink LTE throughput. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
NrGuaranteePuschRbNum NR Guarantee PUSCH RB Number

LteNrUlSpectrumShrPriority LTE and NR Spectrum Sharing Priority

Meaning: Indicates the RAT priority in spectrum sharing between LTE and NR. This parameter is valid only when the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_UPLINK_SPECTRUM_SHR and the LteNrUlSpectrumShrMode parameter in the LteNrSpctShrCellGrp MO is set to DYNAMIC_SHARING, or when the FddTddInd parameter in the Cell MO is set to CELL_TDD and the SpectrumCloudSwitch parameter in the SpectrumCloud MO is set to LTE_NR_SPECTRUM_SHR. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: LTE_PRI(LTE_PRI), NR_PRI(NR_PRI), LTE_NR_FAIR(LTE_NR_FAIR)

Unit: None

Actual Value Range: LTE_PRI, NR_PRI, LTE_NR_FAIR

MML Default Value: LTE_NR_FAIR(LTE_NR_FAIR)

Recommended Value: LTE_NR_FAIR(LTE_NR_FAIR)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to LTE_PRI, LTE takes precedence over NR in dynamic spectrum sharing between LTE and NR. If this parameter is set to NR_PRI, NR takes precedence over LTE in the sharing. If this parameter is set to LTE_NR_FAIR, spectrum is fairly shared between LTE and NR in the sharing.

Applicable Mode: L-FDD, L-TDD
PrbUsageThld PRB Usage Threshold

Meaning: Indicates the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. When the LTE PRB usage is greater than the PRB usage threshold plus the threshold offset, the LTE cells require the spectrum shared with the NR cells. When the LTE PRB usage is less than or equal to the PRB usage threshold minus the threshold offset, the LTE cells do not require the spectrum shared with the NR cells. This parameter applies only to LTE TDD.

GUI Value Range: 20~80

Unit: %

Actual Value Range: 20~80

MML Default Value: 40

Recommended Value: 40

Parameter Relationship:

-Configuration constraints:

  • In an LteNrSpctShrCellGrp MO, the value of the PrbUsageThldOffset parameter must be less than or equal to that of the PrbUsageThld parameter.
  • In an LteNrSpctShrCellGrp MO, the sum of the PrbUsageThldOffset and PrbUsageThld parameter values must be less than or equal to 100.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Set this parameter based on the load on the live network to allocate LTE spectrum suitably and maximize spectral efficiency. A too large value of this parameter leads to a low probability that LTE is allocated shared spectrum. A too small value of this parameter leads to a long duration in which LTE occupies shared spectrum.

Applicable Mode: L-TDD
PrbUsageThldOffset PRB Usage Threshold Offset

Meaning: Indicates the offset relative to the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. When the PRB usage is greater than the PRB usage threshold plus the threshold offset, the LTE network requires the spectrum shared with the NR network. When the PRB usage is less than or equal to the PRB usage threshold minus the threshold offset, the LTE network does not require the spectrum shared with the NR network. This parameter applies only to LTE TDD.

GUI Value Range: 0~30

Unit: %

Actual Value Range: 0~30

MML Default Value: 10

Recommended Value: 10

Parameter Relationship:

-Configuration constraints:

  • In an LteNrSpctShrCellGrp MO, the value of the PrbUsageThldOffset parameter must be less than or equal to that of the PrbUsageThld parameter.
  • In an LteNrSpctShrCellGrp MO, the sum of the PrbUsageThldOffset and PrbUsageThld parameter values must be less than or equal to 100.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Set this parameter based on the load on the live network to allocate LTE spectrum suitably and maximize spectral efficiency. An excessively large value of this parameter may cause the LTE cell to retain its current spectrum usage and a low probability that the LTE cell shares spectrum or receives shared spectrum. An excessively small value of this parameter may lead to ping-pong handovers and cause the LTE cell to frequently share spectrum or receive shared spectrum.

Applicable Mode: L-TDD

When the number of RRC_CONNECTED UEs is less than or equal to the RRC_CONNECTED UE number threshold minus the threshold offset, the LTE cells do not require the spectrum shared with the NR cells. This parameter applies only to LTE TDD.

LteNrSpctShrSwitch LNR Spectrum Sharing Switch

Meaning: Indicates whether to enable LTE and NR spectrum sharing functions.

LTE_SHR_SPCT_ACT_SILENCE_SW: Indicates whether to enable active silence for LTE carriers involved in spectrum sharing. If this option is selected, the light-load and extremely-light-load LTE cells involved in spectrum sharing will actively enter the silent state. If this option is deselected, LTE cells involved in spectrum sharing will not actively enter the silent state. This option applies only to LTE TDD.

GUI Value Range: LTE_SHR_SPCT_ACT_SILENCE_SW(LTE_SHR_SPCT_ACT_SILENCE_SW)

Unit: None

Actual Value Range: LTE_SHR_SPCT_ACT_SILENCE_SW

MML Default Value: None

Recommended Value: LTE_SHR_SPCT_ACT_SILENCE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: LTE_SHR_SPCT_ACT_SILENCE_SW: If this option is selected, the number of intra-LTE handovers increases and the handover-related KPIs are expected to remain stable when the LTE cells involved in spectrum sharing enter the silent state. If burst services occur on the LTE network, the LTE cells in the silent state cannot be activated in a timely manner. This degrades user experience of burst services. If this option is deselected, network performance is not affected.

Applicable Mode: L-TDD

Example

To add spectrum sharing cell group configurations with the parameters as follows: LTE and NR Spectrum Sharing Cell Group ID: 0, Rate of Uplink Spectrum Allocated to NR: 25, LTE and NR Co Carrier Co CPRI Data Switch: OFF, LTE and NR Uplink Spectrum Sharing Mode:STATIC_SHARING, run the following command:
+++    0        2019-01-10 15:41:17
O&M    #806354978
%%ADD LTENRSPCTSHRCELLGRP: LteNrSpectrumShrCellGrpId=0, RateOfUlSpectrumAllocToNr=25, LteNrCoCarrCoCpriDataSw=OFF, LteNrUlSpectrumShrMode=STATIC_SHARING;%%
RETCODE = 0  Operation succeeded.
