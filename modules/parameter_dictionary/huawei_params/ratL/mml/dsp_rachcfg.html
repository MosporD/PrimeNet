Display RACH Configuration (DSP RACHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query parameters related to the RACH.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query dynamic information about RACH:
DSP RACHCFG: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:49:45
O&M    #806355128
%%DSP RACHCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display RACH Configuration
--------------------------
               Local cell ID  =  1
Zero correlation zone config  =  11
(Number of results = 1)


---    END

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Zero correlation zone config

Indicates the length index for the Zadoff-Chu sequence that generates random access preambles. When this parameter is set to 0, the number of preambles generated by a root sequence is 1. For details about this parameter, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.
