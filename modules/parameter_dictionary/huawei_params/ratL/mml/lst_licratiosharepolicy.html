List License Ratio Share Policy (LST LICRATIOSHAREPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list a license ratio share policy.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the license ratio share policy with Cn Operator ID of 0, run the following command:
LST LICRATIOSHAREPOLICY: CnOperatorId=0;
The result is shown as follows:
+++    HUAWEI        2010-06-11 17:25:34
O&M    #1599
%%LST LICRATIOSHAREPOLICY: CnOperatorId=0;%%
RETCODE = 0  Operation succeeded.

List License Ratio Share Policy
-----------------------------
    Cn Operator ID  =  0
       TrfRatio(%)  =  75
TrfSharingRatio(%)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

CN Operator ID

Indicates the ID of the operator.

TrfRatio(%)

Indicates the proportion of traffic used by the operator when the eNodeB is shared among operators. This parameter must be set based on the contract signed by operators. If this parameter is set to 0, services except emergency calls of this operator are not admitted.

TrfSharingRatio(%)

Indicates the proportion of traffic that the operator can share with other operators when the eNodeB is shared among operators.
