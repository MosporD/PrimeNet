Display D-MIMO Channel Calibration (DSP DMIMOCALIBRATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display the status of channel calibration of the D-MIMO cluster. This command applies only to LTE TDD.

Note

None.

Parameters

ID Name Description
DMIMOClusterId D-MIMO Cluster ID

Meaning: Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

Display D-MIMO Channel Calibration:
DSP DMIMOCALIBRATION:;
The result is shown as follows:
+++    0        2016-01-29 16:00:41
O&M    #806354990
%%DSP DMIMOCALIBRATION: DMIMOClusterId=123;%%
RETCODE = 0  Operation succeeded.

Display D-MIMO Channel Calibration
---------------------------------
D-MIMO Cluster ID  Calibration Record Time  D-MIMO Calibration Result 

123                2016-01-29 15:39:52      Succeeded                  
(Number of results = 3)


---    END

Output Description

Field Description

D-MIMO Cluster ID

Indicates the D-MIMO static cluster index. This parameter applies only to LTE TDD.

Calibration Record Time

Indicates the time when the status of D-MIMO channel calibration results changes. This parameter applies only to LTE TDD.

D-MIMO Calibration Result

Indicates the result of channel calibration of the D-MIMO cluster. This parameter applies only to LTE TDD.

eNodeB ID of First Calibration Unit

Indicates the eNodeB ID of the first channel calibration unit (sector equipment or sector equipment group). This parameter applies only to LTE TDD.

Local Cell ID of First Calibration Unit

Indicates the local cell ID of the first channel calibration unit (sector equipment or sector equipment group). This parameter applies only to LTE TDD.

Sector Flag of First Calibration Unit

Indicates whether the first channel calibration unit is sector equipment or sector equipment group. The value SectorEqm(SectorEqm) indicates sector equipment. The value SectorEqmGrp(SectorEqmGrp) indicates sector equipment group. This parameter applies only to LTE TDD.

SectorEqm ID of First Calibration Unit

Indicates the sector equipment ID or the sector equipment group ID of the first channel calibration unit. This parameter applies only to LTE TDD.

eNodeB ID of Second Calibration Unit

Indicates the eNodeB ID of the second channel calibration unit (sector equipment or sector equipment group). This parameter applies only to LTE TDD.

Local Cell ID of Second Calibration Unit

Indicates the local cell ID of the second channel calibration unit (sector equipment or sector equipment group). This parameter applies only to LTE TDD.

Sector Flag of Second Calibration Unit

Indicates whether the second channel calibration unit is sector equipment or sector equipment group. The value SectorEqm(SectorEqm) indicates sector equipment. The value SectorEqmGrp(SectorEqmGrp) indicates sector equipment group. This parameter applies only to LTE TDD.

SectorEqm ID of Second Calibration Unit

Indicates the sector equipment ID or the sector equipment group ID of the second channel calibration unit. This parameter applies only to LTE TDD.

Calibration Signal CINR(dB)

Indicates the carrier-to-interference-and-noise ratio (CINR) of calibrated signals between two RRUs. This parameter applies only to LTE TDD cells.

Calibration Signal RSSI(dBm)

Indicates the received signal strength indicator (RSSI) of channel calibration signals between two RRUs. This parameter applies only to LTE TDD.
