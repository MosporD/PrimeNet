List Cell Sector Equipment (LST EUCELLSECTOREQM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the sector equipment configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • SECTORID on which SectorEqmId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

To list the configurations of a set of cell sector equipment:
LST EUCELLSECTOREQM:;

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

Reference signal power(0.1dBm)

Indicates the reference signal power of cell-specific sector equipment. If this parameter is set to 32767, it is invalid, and the cell uses the reference signal power specified in the PDSCHCfg MO to transmit reference signals. For details, see 3GPP TS 36.213. This parameter is valid only when the MultiRruCellFlag parameter in the Cell MO is set to BOOLEAN_TRUE and the MultiRruCellMode parameter in the Cell MO is set to SFN, CELL_COMBINATION, or MPRU_AGGREGATION. This parameter applies only to LTE FDD and LTE TDD.

Baseband equipment ID

Indicates the ID of a piece of baseband equipment that serves the cell.

If this parameter is set to 255 for a cell, baseband equipment is not specified for the cell. In this case, the eNodeB selects BBPs for a cell among all the local available BBPs. The BBP directly connected to the RRU serving the cell is preferentially selected.

If this parameter is set to another value, baseband equipment is specified for the cell. In this case, the cell can use only the BBPs included in the baseband equipment, and the BBP directly connected to the RRU is preferentially selected. This parameter applies only to LTE FDD and LTE TDD.

Reference Signal Power Margin(0.1dB)

Indicates the reference signal power headroom of each physical antenna. This parameter is valid only when the MultiRruCellFlag parameter of the Cell MO is set to BOOLEAN_TRUE(True) and the MultiRruCellMode parameter in the Cell MO is set to SFN(SFN) or CELL_COMBINATION(Cell Combination). This parameter applies only to LTE TDD.

If this parameter is set to 0, the parameter does not take effect. That is, the reference signal power headroom of the cell equals the value of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO. If this parameter is set to a non-zero value, the reference signal power headroom of the cell equals this value regardless of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO set for the sector equipment of the cell.

Sector CPRI Compression

Indicates the CPRI compression type of the sector equipment. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, or NULL. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, and this parameter value is applicable only to LTE FDD. The value 3_2_COMPRESSION indicates that the compression ratio of 3.2:1 is used, and this value is applicable only to TDD. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than that of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cell served by the sector equipment automatically restarts. This parameter is used only when MultiRruCellMode is set to SFN or CELL_COMBINATION. This parameter can be set based on the sector equipment. When this parameter is set to NULL, the CPRI compression type of the carrier of the cell depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the sector equipment CPRI compression type of carriers depends on the value of the SectorCpriCompression parameter in the eUCellSectorEqm MO. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by RRUs in the RRU chain or ring are deactivated. Activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.

Auto Config Flag

Indicates whether to automatically or manually bind a baseband equipment ID to a cell. To enable automatic binding, set this parameter to AUTO_MODE_CFG. To enable manual binding, set this parameter to MANUAL_MODE_CFG. This parameter applies only to LTE FDD and LTE TDD.

Weight Number

Indicates the weight number configured for cell-specific sector equipment. If this parameter is not set to 255, the value of this parameter has a mapping relationship with the DEVICENO parameter in the BFANT MO. If this parameter is set to 255, the smallest weight number specified by the DEVICENO parameter in the BFANT is used. If the value of DEVICENO in the DSP BFANT command output is not equal to the value of this parameter, the default weight is used. This parameter applies only to LTE TDD.

Virtual Cell ID

Indicates a virtual cell ID used for DMRS and CSI-RS scrambling when adaptive SFN and TM10 are enabled. This parameter should be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to FDD.

Sector Equipment Combine Group ID

Indicates the ID of a sector equipment combination group, which contains multiple sets of sector equipment. The value 255 indicates that the sector equipment is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.

Cell Beam Mode

Indicates the beam mode of the cell. This parameter has four values: NORMAL, ADVANCED_BEAMFORMING, MASSIVE_MIMO_Ph1, and MASSIVE_MIMO_Ph2. The value NORMAL indicates that the cell is a normal cell. The value ADVANCED_BEAMFORMING indicates that the cell uses AAU-based advanced beamforming. The value MASSIVE_MIMO_Ph1 indicates that the cell uses phase-1 massive MIMO. The value MASSIVE_MIMO_Ph2 indicates that the cell uses phase-2 massive MIMO. This parameter applies only to LTE FDD.
