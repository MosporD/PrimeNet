Remove Operator Sharing Information for GERAN Carrier Frequency Group (RMV GERANRANSHARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove information about an operator that shares a neighboring GERAN carrier frequency group.

Note

  • If a neighboring GERAN carrier frequency group is shared by multiple operators and the sharing information about one operator is removed, this group cannot be used by the operator, but can still be used by other operators whose sharing information exists. If a neighboring GERAN carrier frequency group is shared by only one operator and the sharing information about the operator is removed, this group can be used by all operators in the current cell.

  • If a neighboring GERAN carrier frequency group is removed, information about operators that share the neighboring GERAN carrier frequency group is automatically removed.

Meaning: Indicates the cell identity of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the operator that shares the neighboring GERAN carrier frequency group.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the operator that shares the neighboring GERAN carrier frequency group.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Example

To remove an operator sharing information for GERAN carrier frequency group with the parameters as follows: Local cell ID: 0, BCCH group ID: 0, Mobile country code: "460", Mobile network code: "02", run the following command:
RMV GERANRANSHARE: LocalCellId=0, BcchGroupId=0, Mcc="460", Mnc="02";
