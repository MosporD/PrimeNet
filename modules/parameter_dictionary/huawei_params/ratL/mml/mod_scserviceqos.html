Modify SC Service Qos (MOD SCSERVICEQOS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify SC-based service QoS.

Note

None.

Parameters

ID Name Description
ScQosId Sc Qos ID

Meaning: Indicates a QoS ID. An ID is allocated to each service (video) to be optimized. The value range is from 0 to 49. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~49

Unit: None

Actual Value Range: 0~49

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppIdentType Application Identification Type

Meaning: Indicates the application identification type. If the AppIdentType parameter is set to DNS, the AppDns parameter must be set. If the AppIdentType parameter is set to IPv4, the AppIpv4 parameter must be set. If the AppIdentType parameter is set to IPv6, the AppIpv6 parameter must be set. Currently, IPv6 is not supported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DNS(DNS), IPV4(IPv4), IPV6(IPv6)

Unit: None

Actual Value Range: DNS, IPV4, IPV6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppDns Application Dns

Meaning: Indicates the domain name of the to-be-identified application or website. This parameter must be set only if the AppIdentType parameter is set to DNS. "NULL" is an invalid value and cannot be entered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~49 characters

Unit: None

Actual Value Range: 1~49 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of AppDns in the ScServiceQos MO can contain only the following characters:lower-case letters (a to z), upper-case letters (A to Z), digits (0 to 9), wildcard character (*), hyphens (-), full stops (.), and at-signs (@).
  • The values of AppDns in the ScServiceQos MOs must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppIpv4 Application IPv4

Meaning: Indicates the IPv4 address of a service, which is used for service identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv4. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The values of AppIpv4 in the ScServiceQos MOs must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppIpv6 Application IPv6

Meaning: Indicates the IPv6 address of a service, which is used for service identification based on IP addresses. This parameter must be set only if the AppIdentType parameter is set to IPv6. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The values of AppIpv6 in the ScServiceQos MOs must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlSgbr Downlink Service Grant Bit Rate

Meaning: Indicates the guaranteed bit rate (GBR) for downlink services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: Kbit/s

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the service QOS of Service Classification with the parameters as follows: Sc Qos ID: 10, Application Dns: "www.sina.com", Downlink Service Grant Bit Rate(Kbit/s): 200, run the following command:
MOD SCSERVICEQOS: ScQosId=10, AppIdentType=DNS, AppDns="www.sina.com", DlSgbr=200;
