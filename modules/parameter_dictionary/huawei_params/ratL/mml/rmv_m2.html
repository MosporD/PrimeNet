Remove M2 Configuration (RMV M2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an M2 MO.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Deleting the M2 MO interrupts ongoing eMBMS services.

Parameters

ID Name Description
M2Id M2 ID

Meaning: Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove an M2 MO whose ID is 0, run the following command:
RMV M2: M2Id=0;
