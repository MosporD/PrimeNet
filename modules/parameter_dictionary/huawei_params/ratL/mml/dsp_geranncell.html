Display Neighboring Relation with GERAN Cell (DSP GERANNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to dynamically query GERAN neighbor relationship records.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code of the neighboring GERAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a GeranNcell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code of the neighboring GERAN cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in a GeranNcell MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Lac Location area code

Meaning: Indicates the LAC of the GERAN neighboring cell. It uniquely identifies a location within a PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65533,65535

Unit: None

Actual Value Range: 1~65533,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GeranCellId GERAN cell ID

Meaning: Indicates the cell ID of the GERAN neighboring cell. It uniquely identifies a GERAN cell within the area specified by the location area identity (LAI). An LAI consists of the MCC, MNC, and LAC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NCellPlmnLabel Neighbor Cell Plmn Label

Meaning: Indicates the PLMN list label of the neighboring cell. The parameter value BLACK(BLACK) indicates that the PLMN of the neighboring cell is blacklisted. The parameter value GREY(GREY) indicates that the PLMN of the neighboring cell is gray-listed. The parameter value WHITE(WHITE) indicates that the PLMN of the neighboring cell is white-listed. The parameter value ALL(ALL) indicates that all neighboring cells that their PLMNs are blacklisted, gray-listed, and white-listed.

GUI Value Range: BLACK(BLACK), GREY(GREY), WHITE(WHITE), ALL(ALL)

Unit: None

Actual Value Range: BLACK, GREY, WHITE, ALL

MML Default Value: WHITE(WHITE)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the dynamic information about the neighbor relationship with a GERAN cell, run the following command: :
DSP GERANNCELL:;
The result is shown as follows:
