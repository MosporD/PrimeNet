Stop CRS Antenna Port Mapping Optimization Detection (STP CRSPORTOPTDET)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to stop the CRS antenna port mapping optimization detection of the cell.

Note

None.

Parameters

None.

Example

To stop the CRS antenna port mapping optimization detection of the cells, run the following command:
STP CRSPORTOPTDET;
The result is shown as follows:
+++    HUAWEI        2017-03-27 09:32:33
O&M    #807403548
%%STP CRSPORTOPTDET:;%%
RETCODE = 0  Operation succeeded.
