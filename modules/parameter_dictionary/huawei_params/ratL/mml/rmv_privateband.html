Remove Band from CA Band Combination (RMV PRIVATEBAND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a band from a private CA band combination.

Note

None.

Parameters

ID Name Description
PrivateCaCombId Private CA Band Combination ID

Meaning: Indicates the ID of a private CA band combination within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CombBandIndex Combination Band Index

Meaning: Indicates the index of a band in the private CA band combination. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Remove Band from CA Band Combination:
RMV PRIVATEBAND: PrivateCaCombId=0, CombBandIndex=3;
