Add Ncell Plmn List (ADD NCELLPLMNLIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a neighboring cell PLMN list.

Note

A maximum of 32 Ncell Plmn List can be configured for an eNodeB.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code (MCC) of the listed PLMN of neighboring cells. An MCC is a string of three decimal digits, each of which must be a digit ranging from 0 to 9. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a NCellPlmnList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the mobile network code (MNC) of the listed PLMN of neighboring cells. An MNC is a string of two or three decimal digits, each of which must be a digit ranging from 0 to 9. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in a NCellPlmnList MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RatType Rat Type

Meaning: Indicates the RAT of a listed PLMN of neighboring cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EUTRAN(EUTRAN), UTRAN(UTRAN), GERAN(GERAN), NR(NR)

Unit: None

Actual Value Range: EUTRAN, UTRAN, GERAN, NR

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a NCellPlmnList MO, PlmnListType can be set to a maximum of two values for PLMNs with the same value of RatType.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PlmnListType Plmn List Type

Meaning: Indicates the type of a PLMN list. If this parameter is set to BLACK_LIST, the cell of the blacklisted PLMN cannot be configured as a neighboring cell or an external cell by ANR. If this parameter is set to GREY_LIST, the cell of the graylisted PLMN can be added as a neighboring cell and an external cell by ANR, and the ANR marks a PLMN graylist label on the neighboring cell. If this parameter is set to WHITE_LIST, the cell of the whitelisted PLMN can be added as a neighboring cell and an external cell by ANR, and the ANR marks a PLMN whitelist label on the neighboring cell. This parameter can be set to only two of the three values for all PLMNs in an E-UTRAN, UTRAN, GERAN, or NG-RAN. The type of PLMNs for which this parameter is not configured is considered the third type by default. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BLACK_LIST(BLACK_LIST), GREY_LIST(GREY_LIST), WHITE_LIST(WHITE_LIST)

Unit: None

Actual Value Range: BLACK_LIST, GREY_LIST, WHITE_LIST

MML Default Value: WHITE_LIST(WHITE_LIST)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a NCellPlmnList MO, PlmnListType can be set to a maximum of two values for PLMNs with the same value of RatType.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to BLACK_LIST, the source eNodeB does not add a detected neighboring cell to the corresponding NRT and NCL after obtaining information about the cell corresponding to the blacklisted PLMN. You are advised to set this parameter to BLACK_LIST when abnormal UEs report incorrect CGIs. If this parameter is set to WHITE_LIST or GREY_LIST, the source eNodeB adds a detected neighboring cell to the corresponding NRT and NCL after obtaining information about the cell corresponding to the whitelisted PLMN or graylisted PLMN. This has no impact on network performance.

Applicable Mode: L-FDD, L-TDD
gNBIdLength gNodeB ID Length

Meaning: Indicates the length of a gNodeB ID. This parameter specifies the number of bits of the gNodeB ID in the NCI to uniquely identify an NCI. For details, see 3GPP TS 38.423. This parameter is valid only when the RatType parameter in the NCellPlmnList MO is set to NR. This parameter must be set to the gNodeB ID length of the gNodeB in the specified PLMN on the 5G network. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 22~32

Unit: bit

Actual Value Range: 22~32

MML Default Value: 22

Recommended Value: 22

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Add Ncell Plmn List, Mobile Country Code is 460, Mobile Network Code is 01, Plmn List Type is GREY_LIST, RatType is EUTRAN:
ADD NCELLPLMNLIST: Mcc="460", Mnc="01", RatType=EUTRAN, PlmnListType=GREY_LIST;
