Modify Cell Selection Configuration (MOD CELLSEL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters about cell selection.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
QRxLevMin Minimum required RX level

Meaning: Indicates the minimum receive level required for a cell to become a candidate for cell selection. The level is included in S criteria and used in the evaluation of cell selection. The value range of this parameter is -70 to -22 for LTE FDD and TDD, and -78 to -22 for LTE NB-IoT. For details, see 3GPP TS 36.304.

GUI Value Range: -78~-22

Unit: 2dBm

Actual Value Range: -156~-44

MML Default Value: None

Recommended Value: -64

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability of the cell meeting criteria S and becoming a suitable cell for cell selection. A smaller value of this parameter results in a higher probability. Set this parameter properly so that the selected cells can provide signals that meet the quality requirement of basic services.

Applicable Mode: L
QRxLevMinOffset Minimum required RX level offset

Meaning: Indicates the offset to the minimum required receive level. This value is included in criteria S and used in the evaluation of cell selection. This parameter is valid only when the cell selection is triggered by periodic searches for higher-priority PLMNs and the UE is served by a Visited Public Land Mobile Network (VPLMN). For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~8

Unit: 2dB

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher probability of the cell meeting criteria S and becoming a suitable cell for cell selection. A smaller value of this parameter results in a lower probability.

Applicable Mode: L-FDD, L-TDD
QQualMin Minimum required RX quality level

Meaning: Indicates the minimum required received signal quality, which corresponds to the q-QualMin IE in system information block type 1 (SIB1) and is used to calculate the Squal value for the serving cell involved in cell selection and reselection. If this parameter is set to 0, SIB1 does not contain the q-QualMin IE. If this parameter is set to a value other than 0, SIB1 contains the q-QualMin IE with the same value as the parameter value. For details about this parameter, see 3GPP TS 36.304.

GUI Value Range: -34~-3,0

Unit: dB

Actual Value Range: -34~-3,0

MML Default Value: None

Recommended Value: For LTE FDD or LTE TDD cells: -18 if the RSRQ is used for cell selection and reselection.

For NB-IoT cells: The default value is -23 and this parameter must not be set to 0.

Parameter Relationship:

-Configuration constraints:

  • In the CellSel MO, when QQualMin is set 0, ThrshServLowQCfgInd in the CellResel MO cannot be set to CFG.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell selection of the UE in idle mode.)

Impact on Radio Network Performance: If this parameter is set to a value other than 0, a larger value indicates that cell reselection is easier to trigger and it is more difficult for the related cell to meet the criteria for UEs to camp on. A smaller value results in the opposite effects. If this parameter is set to 0, SIB1 does not contain the q-QualMin IE, and UEs use the default value (negative infinity) of the IE. In this case, only the signal level is used for UEs to select and reselect cells.

Applicable Mode: L
QQualMinOffsetCfgInd Minimum required RX quality level offset configure indicator

Meaning: Indicates whether to set the offset to the minimum required receive level for the cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: None

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell selection of the UE in idle mode.)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
QQualMinOffset Minimum required RX quality level offset

Meaning: Indicates the offset to the minimum required received signal quality for the cell. It is included in criteria S and used in the evaluation of cell selection. This parameter is required only when the cell selection is triggered by periodic searches for higher-priority PLMNs and the UE is served by a Visited Public Land Mobile Network (VPLMN). For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: dB

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of QQualMinOffsetCfgInd.
  • If QQualMinOffsetCfgInd is set to CFG, this parameter must be set.
  • If QQualMinOffsetCfgInd is set to NOT_CFG, this parameter does not need to be set.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell selection of the UE in idle mode.)

Impact on Radio Network Performance: A larger value of this parameter leads to higher probabilities of the cell meeting criteria S and becoming a suitable cell for cell selection. A smaller value of this parameter results in lower probabilities. If this parameter is not set, that is, the value of this parameter is not sent to the UE over the air interface, the UE uses the value 0 by default.

Applicable Mode: L-FDD, L-TDD
QRxLevMinCE Minimum Required RX Level for CE

Meaning: Indicates the minimum receive level required for coverage enhancement mode A of a cell. It is included in criterion S for cell selection. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -70~-22

Unit: 2dBm

Actual Value Range: -140~-44

MML Default Value: None

Recommended Value: -66

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell selection of the UE in idle mode.)

Impact on Radio Network Performance: If this parameter is set to a large value, the cell is less likely to meet UE camping conditions. If this parameter is set to a small value, the cell is more likely to meet UE camping conditions. Set this parameter to an appropriate value so that the selected cell can provide signals that meet the requirements of basic services.

Applicable Mode: L-FDD, L-TDD
QQualMinCE Minimum Required Quality Level for CE

Meaning: Indicates the minimum received signal quality used in cell selection criterion S for coverage enhancement mode A. This parameter corresponds to the q-QualMinRSRQ-CE-r13 IE in SIB1-BR. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -34~-3,0

Unit: dB

Actual Value Range: -34~-3,0

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to -18 when cell selection and reselection are performed based on the RSRQ.

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell selection of the UE in idle mode.)

Impact on Radio Network Performance: If this parameter is set to a larger non-zero value, the cell is less likely to meet UE camping conditions, increasing the probability of triggering cell reselection. If this parameter is set to a smaller value other than 0, the cell is more likely to meet UE camping conditions, lowering the probability of triggering cell reselection. If this parameter is set to 0, SIB1-BR does not contain the q-QualMinRSRQ-CE-r13 IE, and UEs use the default value (negative infinity) of the IE. In this case, only the signal level is used for UEs to select and reselect cells.

Applicable Mode: L-FDD, L-TDD
QQualMinForCeModeB Min Signal Quality Level for CE Mode B

Meaning: Indicates the minimum received signal quality required for coverage enhancement mode B of a cell. It is used as an input parameter for cell selection criterion S. If this parameter is set to 0, SIB1-BR does not contain the q-QualMinRSRQ-CE1-r13 IE. In this case, the value -∞ is used by default and the eNodeB performs cell selection and reselection for UEs based only on the signal level. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -34~-3,0

Unit: dB

Actual Value Range: -34~-3,0

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to -18 when cell selection and reselection is performed based on the RSRQ.

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell selection for UEs in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value other than 0, a larger value indicates that it is less likely for the cell to meet the criteria for UEs to camp on and therefore cell reselection is more likely to occur. A smaller value results in the opposite effects. If this parameter is set to 0, SIB1-BR does not contain the q-QualMinRSRQ-CE1-r13 IE. In this case, the value -∞ is used by default and the eNodeB performs cell selection and reselection for UEs based only on the minimum receive level.

Applicable Mode: L-FDD, L-TDD
QRxLevMinForCeModeB Min RX Level for CE Mode B

Meaning: Indicates the minimum receive level required for coverage enhancement mode B of a cell. It is used as an input parameter for cell selection criterion S. For details, see 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -78~-22

Unit: 2dBm

Actual Value Range: -156~-44

MML Default Value: None

Recommended Value: -70

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell selection for UEs in idle mode)

Impact on Radio Network Performance: A larger value indicates that it is less likely for the cell to meet the criteria for UEs to camp on. A smaller value results in the opposite effects. Set this parameter to an appropriate value so that the signal quality of the affected cell is adequate for performing basic services.

Applicable Mode: L-FDD, L-TDD
PwrOffsetForSelectionToNb Power Offset for Selection to NB-IoT Cell

Meaning: Indicates the power offset for cell selection of an NB-IoT UE with a power level of 14 dBm. When set to NULL, this parameter will not be delivered in the system information, and the UE takes 0 dB as the power offset by default. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: dB-6(dB-6), dB-3(dB-3), dB3(dB3), dB6(dB6), dB9(dB9), dB12(dB12), NULL(NULL)

Unit: dB

Actual Value Range: dB-6, dB-3, dB3, dB6, dB9, dB12, NULL

MML Default Value: None

Recommended Value: NULL

Parameter Relationship: None

Service Interrupted After Modification: No (And affects the cell selection for UEs in idle mode)

Impact on Radio Network Performance: A larger value (excluding NULL) of this parameter results in a higher probability for an NB-IoT UE with a power level of 14 dBm to select a cell with good signal quality. A smaller value of this parameter leads to the opposite effect.

Applicable Mode: L-NB-IOT

Example

Example 1: To modify the cell selection information parameters as follows: Local cell ID: 0, Minimum required RX level: -70, Minimum required RX level offset: 4, run the following command:
MOD CELLSEL: LocalCellId=0, QRxLevMin=-70, QRxLevMinOffset=4;
Example 2: To modify the cell selection information parameters as follows: Local cell ID: 0, Minimum required RX level: -67, Minimum required RX level offset: 4, run the following command:
MOD CELLSEL: LocalCellId=0, QRxLevMin=-67, QRxLevMinOffset=4;
