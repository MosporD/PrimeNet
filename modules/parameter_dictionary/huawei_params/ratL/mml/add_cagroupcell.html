Add CA Group Cell (ADD CAGROUPCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a cell to a CA group.

Note

  • Before running this command, ensure that the cell to be added has already been configured.

  • One cell can be configured only into one CA group.

  • For two inter-frequency CaGroupCell MOs associated with a CaGroup MO, excluding the two cells that both are added to a double deck cell group or are configured as superband cells, if the spacing between their downlink center frequencies is less than their average downlink bandwidth, the spacing must be the nominal channel spacing between contiguously aggregated component carriers.

  • The frequencies of two cells in a CA group must have inter-frequency neighbor relationships with each other. Otherwise, CA cannot be performed.

  • Among cells that are added into the same CA group, CA services cannot be performed between any two cells that are established on intra-eNodeB inter-BBU BBPs.

Meaning: Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

PreferredPCellPriority Preferred PCell Priority

Meaning: Indicates the priority of the cell being treated as a primary serving cell (PCell). A larger parameter value represents a higher priority level. This parameter is valid only if the IdleModePccAnchorSwitch(IdleModePccAnchorSwitch), PccAnchorSwitch(PccAnchorSwitch), or EnhancedPccAnchorSwitch(EnhancedPccAnchorSwitch) option of the CaAlgoSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value indicates a lower PCell priority of a cell, which results in a higher probability that CA UEs select other higher-priority cells as PCells based on inter-frequency handovers and also a longer delay for CA UEs to reach peak data rates on the aggregated carriers. A larger parameter value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
PCellA4RsrpThd PCell A4 RSRP Threshold

Meaning: Indicates the reference signal received power (RSRP) threshold for triggering event A4 during higher-priority cell evaluation for PCell selection in scenarios where CA is configured based on CA groups. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: -105

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of a CA UE camping on the local cell and less impact on network performance. A smaller value of this parameter results in a higher probability of triggering event A4 and a larger number of handover failures caused by incorrect handover evaluations.

Applicable Mode: L-FDD, L-TDD
PCellA4RsrqThd PCell A4 RSRQ Threshold

Meaning: Indicates the reference signal received quality (RSRQ) threshold for triggering event A4 during higher-priority cell evaluation for PCell selection in scenarios where CA is configured based on CA groups. If the measured RSRQ of an inter-frequency neighboring cell in the CA group is greater than this parameter value, the CA UE reports event A4. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -40~-6

Unit: 0.5dB

Actual Value Range: -20~-3

MML Default Value: -20

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of a CA UE camping on the local cell and less impact on network performance. A smaller value of this parameter results in a higher probability of triggering event A4 and a larger number of handover failures caused by incorrect handover evaluations.

Applicable Mode: L-FDD, L-TDD

Example

To add a cell to a CA group with the parameters as follows: CA Group Identity: 0, Local cell ID: 0, eNodeB ID: 0, run the following command:
ADD CAGROUPCELL: CaGroupId=0, LocalCellId=0, eNodeBId=0;
