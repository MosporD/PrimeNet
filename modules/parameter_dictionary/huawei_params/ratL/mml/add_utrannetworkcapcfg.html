Add Utran Network Capability Configuration (ADD UTRANNETWORKCAPCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a UTRAN capability configuration.

Note

A maximum of 32 UTRAN capability configurations can be configured.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of a target radio network controller (RNC).

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of a target radio network controller (RNC).

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RncId RNC ID

Meaning: Indicates the RNC ID of external UTRAN cells. The RNC ID has two modes: RNC-ID and extended RNC-ID. The 28-bit UTRAN cell ID comprises the RNC ID and the RNC cell ID. If the RNC ID is represented in the RNC-ID mode, the UTRAN cell ID comprises the RNC ID and the RNC cell ID that are represented by the leftmost 12 bits and the rightmost 16 bits, respectively. In this case, the formula for calculating the UTRAN cell ID is as follows: UTRAN cell ID = RNC ID x 65536 + RNC cell ID. If the RNC ID is represented in the extended RNC-ID mode, the UTRAN cell ID comprises the RNC ID and the RNC cell ID that are represented by the leftmost 16 bits and the rightmost 12 bits, respectively. In this case, the formula for calculating the UTRAN cell ID is as follows: UTRAN cell ID = RNC ID x 4096 + RNC cell ID. The value range of an RNC ID is (0-65535, 4294967295). A value in the range of 0-65535 indicates the actual RNC ID on the network, and the value 4294967295 indicates all RNC IDs in the PLMN. That is, the policy applies to all RNCs in the PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535,4294967295

Unit: None

Actual Value Range: 0~65535,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When more than one UtranNetworkCapCfg is configured with the same Mcc and Mnc, RncId 4294967295 cannot be co-exist with other RncId values.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NetworkCapCfg Network Capability Configuration

Meaning: Indicates the UTRAN capabilities for an operator including the PS handover capability, capability of obtaining system information (SI) of the UTRAN through RAN information management (RIM) procedures, VoIP capability, ultra-flash CSFB capability, and SRVCC capability. If the MME, SGSN, MSC, or RNC of the operator does not support PS handover, RIM procedures, VoIP, ultra-flash CSFB, or SRVCC, set this parameter to indicate the incapabilities. If this parameter is not set, the capabilities are supported by default. This parameter provides the following options:

PsHoCapCfg: Indicates whether PS handover is supported by the operator in the UTRAN. This capability is supported only if this option is selected. This option applies only to LTE FDD.

SiByRimCapCfg: Indicates whether SI of the UTRAN can be obtained through RIM procedures. This capability is supported only if this option is selected. This option applies only to LTE FDD.

VoipCapCfg: Indicates whether VoIP is supported by the operator in the UTRAN. Only if this option is selected, this capability is supported and the eNodeB can transfer voice services to the UTRAN through PS handover to establish VoIP services. This option applies only to LTE FDD.

UltraFlashCsfbCapCfg: Indicates whether SRVCC-based CSFB is supported by the operator in the UTRAN. This capability is supported only if this option is selected. This option applies only to LTE FDD.

SrvccCapCfg: Indicates whether SRVCC is supported by the operator in the UTRAN. This capability is supported and UEs running voice services can be handed over to the UTRAN through SRVCC only if this option is selected. This option applies only to LTE FDD.

GUI Value Range: PsHoCapCfg(PsHoCapCfg), SiByRimCapCfg(SiByRimCapCfg), VoipCapCfg(VoipCapCfg), UltraFlashCsfbCapCfg(UltraFlashCsfbCapCfg), SrvccCapCfg(SrvccCapCfg)

Unit: None

Actual Value Range: PsHoCapCfg, SiByRimCapCfg, VoipCapCfg, UltraFlashCsfbCapCfg, SrvccCapCfg

MML Default Value: None

Recommended Value: PsHoCapCfg:Off, SiByRimCapCfg:Off, VoipCapCfg:On, UltraFlashCsfbCapCfg:Off, SrvccCapCfg:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: By setting the options of this parameter, operators adopt different policies per RNC to ensure their optimum network performance. If the PsHoCapCfg option is deselected, PS handovers are not supported and therefore another policy is required. This policy can reduce delayed-handover-induced service drops that occur when the operator uses PS handovers but the UTRAN does not support PS handovers. If the SiByRimCapCfg option is deselected, the eNodeB cannot use RIM to obtain the system information of neighboring cells and therefore cannot perform fast redirection. If the VoipCapCfg option is selected, VoIP is supported in the UTRAN cell. Voice services established in the LTE network can be transferred to the UTRAN using PS handovers for UEs to perform voice services in the UTRAN cell. If the VoipCapCfg option is deselected, VoIP is not supported in the UTRAN cell. VoIP services established in the LTE network cannot be transferred to the UTRAN using PS handovers but can be transferred to the CS domain of the UTRAN using SRVCC. If the UltraFlashCsfbCapCfg option is selected, SRVCC-based CSFB is supported in the UTRAN cell. Voice services can be transferred to a UTRAN cell by SRVCC-based CSFB. The SRVCC-based CSFB procedure has a shorter voice service establishment delay than the standard CSFB procedure. If the UltraFlashCsfbCapCfg option is deselected, SRVCC-based CSFB is not supported in the UTRAN cell. Voice services can be transferred to a UTRAN cell only by the standard CSFB procedure, which has a longer delay than SRVCC-based CSFB. If the SrvccCapCfg option is selected, SRVCC is supported in the UTRAN cell. The eNodeB can transfer voice services to the CS domain of a UTRAN cell through SRVCC to ensure continuity of voice services. If the SrvccCapCfg option is deselected, SRVCC is not supported in the UTRAN cell. The eNodeB cannot transfer voice services to the CS domain of a UTRAN cell through SRVCC and service drops may occur.

Applicable Mode: L-FDD

Example

To add a UTRAN capability configuration with the following parameters: Mobile country code: 460, Mobile network code: 32, Rnc Id: 0, Network Capability Configuration: PsHoCapCfg-0 & SiByRimCapCfg-0, run the following command:
ADD UTRANNETWORKCAPCFG: Mcc="460", Mnc="32", RncId=0, NetworkCapCfg=PsHoCapCfg-0&SiByRimCapCfg-0;
