Modify Cell WTTx Configuration (MOD CELLWTTXPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify cell-level WTTx parameter settings.

Note

None.

Parameters

PrbUpLimitCtrlMode PRB Upper Limit Control Mode

Meaning: Indicates the PRB upper limit control mode, which can be tight control or loose control. When this parameter is set to TIGHT_CONTROL, the PRB resources for WBB and MBB UEs are subject to their respective uplink and downlink PRB resource upper limits. That is, the amounts of PRB resources allocated to WBB and MBB UEs must not exceed the upper limits even if there are remaining PRB resources in the cell. When this parameter is set to MBB_LOOSE_CONTROL: For MBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after WBB UEs are scheduled, the preset upper limit can be exceeded to allow MBB UEs to use the remaining PRB resources; for WBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to WBB_LOOSE_CONTROL: For WBB UEs, if the amount of PRB resources allocated to them has reached the preset upper limit and there are remaining PRB resources after MBB UEs are scheduled, the preset upper limit can be exceeded to allow WBB UEs to use the remaining PRB resources; for MBB UEs, the TIGHT_CONTROL policy is still used. When this parameter is set to LOOSE_CONTROL, if the amount of PRB resources allocated to MBB or WBB UEs has reached the preset upper limit and there are remaining PRB resources, the limit can be exceeded to allow MBB or WBB UEs to use the remaining PRBs. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: TIGHT_CONTROL(Tight control), MBB_LOOSE_CONTROL(MBB loose control), WBB_LOOSE_CONTROL(WBB loose control), LOOSE_CONTROL(Loose control)

Unit: None

Actual Value Range: TIGHT_CONTROL, MBB_LOOSE_CONTROL, WBB_LOOSE_CONTROL, LOOSE_CONTROL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to TIGHT_CONTROL, the upper limits of PRB resources for both WBB and MBB UEs can be accurately controlled. This leads to a smaller increase in the interference to neighboring cells than when loose control mode is used. If this parameter is set to MBB_LOOSE_CONTROL, WBB_LOOSE_CONTROL, or LOOSE_CONTROL, UEs can use spare PRBs in the cell more flexibly. In this case, the increase in the interference to neighboring cell is greater than when tight control mode is used.

Applicable Mode: L-FDD, L-TDD
WbbOrMbbUserDefMode WBB or MBB User Definition Mode

Meaning: Indicates the WBB and MBB UE definition modes. This parameter provides the SPID-based and QCI-based definition modes. When this parameter is set to SPID_BASED, the eNodeB regards UEs configured with SPIDs and whose SpecifiedUserFlag is set to SPECSERUSER as WBB UEs. Other UEs are regarded as MBB UEs. When this parameter is set to QCI_BASED, the eNodeB regards UEs that set up the bearers with QCIs indicating WBB services (ServiceFlag set to WBB_SERVICE) as WBB UEs. Other UEs are regarded as MBB UEs. This parameter applies only to LTE FDD and LTE TDD.

IptvGuaranteeUserCount IPTV Guarantee User Count

Meaning: Indicates the upper limit on the number of IPTV UEs for which rate acceleration is used for rate guarantee in a cell where IPTV admission control is used. When the number of UEs running IPTV services in the cell exceeds this limit, the eNodeB no longer accelerates rates for newly admitted IPTV UEs. If this parameter is set to 0, the IPTV admission control function does not take effect. That is, the eNodeB accelerates rates for all IPTV UEs in the cell. If multiple bearers have been set up for a UE, the number of identified IPTV UEs equals the number of bearers carrying IPTV data flows. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50

Unit: None

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller number of IPTV UEs which are preferentially scheduled for rate guarantee and better experience of IPTV UEs preferentially scheduled during busy hours. A larger value of this parameter leads to a larger number of IPTV UEs which are preferentially scheduled for rate guarantee and experience deterioration of IPTV UEs after the cell capacity is exceeded.

Applicable Mode: L-FDD, L-TDD
WbbPerformanceOptSwitch WBB Performance Optimization Switch

Meaning: Indicates whether to enable WBB performance optimization.

DL_CA_SCC_CONFIG_ACT_OPT_SW: Indicates whether to enable the algorithm for optimizing downlink CA SCC configuration and activation. If this option is selected, optimization of downlink CA SCC configuration and activation is enabled. Massive MIMO SCCs can be configured and activated only for UEs supporting uplink CA. If this option is deselected, optimization of downlink CA SCC configuration and activation is disabled. This option applies only to LTE TDD.

WBB_ANT_SELECTION_UE_IDENT_SW: Indicates whether to enable identification of WBB UEs capable of transmit antenna selection. If this option is selected, identification of WBB UEs capable of transmit antenna selection is enabled. Transmit antenna selection is configured for WBB UEs identified using SPIDs based on their capabilities. Transmit antenna selection is disabled for non-WBB UEs. If this option is deselected, the identification is disabled. This option applies only to LTE TDD.

GUI Value Range: DL_CA_SCC_CONFIG_ACT_OPT_SW(DL_CA_SCC_CONFIG_ACT_OPT_SW), WBB_ANT_SELECTION_UE_IDENT_SW(WBB_ANT_SELECTION_UE_IDENT_SW)

Unit: None

Actual Value Range: DL_CA_SCC_CONFIG_ACT_OPT_SW, WBB_ANT_SELECTION_UE_IDENT_SW

MML Default Value: None

Recommended Value: DL_CA_SCC_CONFIG_ACT_OPT_SW:Off, WBB_ANT_SELECTION_UE_IDENT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DL_CA_SCC_CONFIG_ACT_OPT_SW: If this option is selected, massive MIMO SCCs can be configured and activated only for UEs supporting uplink CA. This improves the capacity of massive MIMO SCCs, but the experience of UEs not supporting uplink CA may deteriorate. If this option is deselected, network performance is not affected.

DL_CA_SCC_CONFIG_ACT_OPT_SW: If this option is selected, transmit antenna selection is configured only for WBB UEs identified using SPIDs based on their capabilities to produce antenna selection gains and improve the experience of WBB UEs. Transmit antenna selection is disabled for non-WBB UEs. MBB UEs supporting transmit antenna selection cannot obtain the gains from transmit antenna selection. If this option is deselected, the identification does not take effect, and network performance is not affected.

Applicable Mode: L-TDD
WbbMultiCarrierCoordA2Ofs WBB Multi-Carrier Coordination A2 Offset

Meaning: Indicates the offset to the threshold for event A2 that triggers handover of CA UEs running WBB services in multi-carrier scenarios from a high-frequency cell to a low-frequency cell.

GUI Value Range: 0~10

Unit: dB

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower probability of triggering multi-carrier coordination for CA UEs running WBB services. A larger value of this parameter leads to the opposite effect.

Applicable Mode: L

Example

To modify the cell-level WTTx parameter with MbbUserDlPrbUpLimit set to 20 for the cell with Local cell identity 0, run the following command:
MOD CELLWTTXPARACFG: LocalCellId=0, MbbUserDlPrbUpLimit=20;
