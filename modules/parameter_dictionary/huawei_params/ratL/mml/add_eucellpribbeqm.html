Add Primary Baseband Equipment Binding to a Cell (ADD EUCELLPRIBBEQM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add primary baseband equipment configuration to a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If certain cells have been established on a BBP board, a cell not bound to primary baseband equipment cannot be established on this BBP board.

Only cells already bound to primary baseband equipment can be established on this BBP board.

If the command is executed for an activated cell and its primary baseband equipment unit is not included in the baseband equipment, the cell is automatically reestablished.

If the cell is bound to a piece of primary baseband equipment, the cell must be bound to the serving baseband equipment based on the network plan.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PriBaseBandEqmId Primary Baseband Equipment ID

Meaning: Indicates the ID of the primary baseband equipment that serves a cell.

If the primary baseband equipment is not configured for a cell, the eNodeB selects baseband processing units for the cell among all baseband processing units that have not been bound to cells.

If this parameter is configured, the cell uses specified primary baseband equipment. In this case, the cell can use only the baseband processing units included in the primary baseband equipment.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To add primary baseband equipment configuration to a cell with the parameters as follows:  LocalCellId: 0, PriBaseBandEqmId: 0, run the following command:
ADD EUCELLPRIBBEQM: LocalCellId=0, PriBaseBandEqmId=0;
