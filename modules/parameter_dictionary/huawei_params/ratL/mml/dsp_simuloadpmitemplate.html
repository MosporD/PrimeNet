Display Information of Simuload Pmi Template (DSP SIMULOADPMITEMPLATE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about simuload PMI templates.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If values of LocalCellId in SimuloadPmiTemplate MOs are the same, PmiType in these SimuloadPmiTemplate MOs must be the same.
  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is selected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, all values of CellSimuloadRank, CellSimuloadPmiExtend0 and CellSimuloadPmiExtend1 cannot be the same simultaneously.
  • If the Virtual4T4RSwitch option of EmimoSwitch in the CellAlgoSwitch MO is deselected, values of LocalCellId in related SimuloadPmiTemplate MOs are the same, and values of SimuloadPmiTemplateId in these SimuloadPmiTemplate MOs are different, values of CellSimuloadRank and CellSimuloadPmi cannot be the same simultaneously.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the dynamic information about the simuload pmi template with the Local cell ID of 1, run the following command:
DSP SIMULOADPMITEMPLATE: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Simuload PMI Template ID

Indicates the number of a PMI template used in interference simulation. This parameter applies only to FDD.

PMI Type

Indicates the cell type for load simulation. If the cell is a normal cell, set this parameter to Normal. If the cell is an eMIMO cell, set this parameter to Virtual4T4R. This parameter applies only to LTE FDD and LTE TDD.

Cell Simuload Rank

Indicates the rank for the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. This parameter applies only to FDD.

Cell Simuload PMI

Indicates the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. This parameter applies only to FDD.

Cell Simuload PMI Extend 0

Indicates the PMI for TM4 during virtual 4T4R feature load simulation. This parameter indicates the PMI for beam 0 (the left beam serving the virtual 4T4R cell) during load simulation. PMI values used for load simulation in a cell must be unique. This parameter applies only to LTE FDD and LTE TDD.

Cell Simuload PMI Extend 1

Indicates the PMI for TM4 during virtual 4T4R feature load simulation. This parameter indicates the PMI for beam 1 (the left beam serving the virtual 4T4R cell) during load simulation. PMI values used for load simulation in a cell must be unique. This parameter applies only to LTE FDD and LTE TDD.

Cell Simuload PMI Period(ms)

Indicates the PMI polling cycle used in load simulation with the SimuLoadTransMode parameter is set to TM4 or TM9. This parameter applies only to FDD.

Cell Simuload PMI Schedule Duration(ms)

Indicates the scheduling duration for the PMI used in interference simulation with the SimuLoadTransMode parameter set to TM4 or TM9. The total configured duration of interference simulation using the PMIs in all PMI templates configured for a cell is the PMI polling cycle. The actual probability of scheduling a PMI is equal to the scheduling duration for this PMI divided by the PMI polling cycle. This parameter applies only to FDD.
