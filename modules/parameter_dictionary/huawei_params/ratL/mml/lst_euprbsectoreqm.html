List PRB Sector Equipment (LST EUPRBSECTOREQM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the PRB sector equipment configuration.

Note

None.

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

Sector Equipment ID

Indicates the ID of the sector equipment that serves the cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to NB-IoT.

Reference Signal Power(0.1dBm)

Indicates the reference signal power of the sector equipment for the PRB (the precision of converting dBm to mW is 0.01 mW). If this parameter is set to 32767, this value is invalid for reference signal power. In this case, the reference signal power defined in the PDSCHCFG MO takes effect. For details, see 3GPP TS 36.213. In accordance with 3GPP specifications, the difference in reference signal power between the non-anchor carrier and the anchor carrier of a multi-carrier NB-IoT cell can be -12 dB, -10 dB, -8 dB, -6 dB, -4 dB, -2 dB, 0 dB, or 3 dB. If the configured reference signal power difference value is different from the protocol-specified values, the protocol-specified value closest to and greater than the configured difference value is delivered in a Uu message. If the configured difference value is greater than 3 dB, the value 3 dB is delivered in a Uu message. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

Baseband Equipment ID

Indicates the ID of the baseband equipment that serves the cell.

The value 255 indicates that no baseband equipment is specified for the cell. In this scenario, any of the BBPs in the eNodeB can be selected to serve the cell. The BBP to which the cell's serving RRU is directly connected is preferentially selected.

When this parameter is set to a value other than 255, the cell can be served only by the BBPs included in the specified baseband equipment, and the BBP to which the cell's serving RRU is directly connected is preferentially selected. This parameter applies only to NB-IoT.

Auto Config Flag

Indicates whether to automatically or manually control the setting of baseband equipment ID. To allow for automatic setting, set this parameter to AUTO_MODE. To allow for manual object creation, set this parameter to MANUAL_MODE or AUTO_MODE. This parameter applies only to NB-IoT.

NPRS ID

Indicates the narrowband positioning reference signal (NPRS) ID of an NB-IoT cell. If this parameter is set to 65535, the specified NPRS ID is invalid. In this case, the NPRS ID is the same as the PCI. For details about the parameter, see 3GPP TS 36.455. This parameter applies only to NB-IoT.
