List Cell Beamforming Configuration (LST CELLBF)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the information used to control the single-stream or dual-stream beamforming.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of single-stream and dual-stream beamforming:
LST CELLBF: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Beamforming maximum number of layers

Indicates the maximum number of beamforming layers, that is, the rank of beamforming. The value SINGLE_LAYER_BF indicates single-layer beamforming (that is, beamforming with the rank of 1). The value DUAL_LAYER_BF indicates dual-layer beamforming (that is, beamforming with the rank of 2). The value FOUR_LAYER_BF indicates three- or four-layer beamforming (that is, beamforming with the rank of 3 or 4). This parameter applies only to LTE TDD.

Antenna Selection UE MUBF Pair Mode

Indicates the MU beamforming pairing policy for UEs that support transmit antenna selection during SRS transmission. This parameter takes effect only in massive MIMO scenarios. If this parameter is set to SINGLE_STREAM_PAIR, such UEs in single-stream beamforming mode are paired for MU beamforming. If this parameter is set to DUAL_STREAM_PAIR, such UEs in dual-stream beamforming mode are paired for MU beamforming. This parameter applies only to LTE TDD.

Non Antenna Selection UE MUBF Pair Mode

Indicates the policy of pairing UEs that do not support transmit antenna selection during SRS transmission for MU beamforming. This parameter applies only to massive MIMO cells. If this parameter is set to SINGLE_STREAM_PAIR(SINGLE_STREAM_PAIR), such UEs in single-stream beamforming mode are paired for MU beamforming. If this parameter is set to DUAL_STREAM_PAIR(DUAL_STREAM_PAIR), such UEs in dual-stream beamforming mode are paired for MU beamforming. This parameter applies only to LTE TDD.

PDSCH Split Beam Config Index

Indicates the PDSCH split beam weight index in massive MIMO scenarios. This parameter is used to select a transmit weight coefficient for the transmission modes (TM7, TM8, and TM9) used to demodulate downlink UE-specific reference signals. This parameter applies only to massive MIMO LTE TDD cells.

1. If this parameter is set to CONFIG_DEFAULT, the default beam configuration template is used, and 15 beams are configured.

2. If this parameter is set to CONFIG_INDEX1, the first set of beam configuration templates is used, and 11 beams are configured.

3. If this parameter is set to CONFIG_INDEX2, the second set of beam configuration templates is used, and 9 beams are configured.

4. If this parameter is set to CONFIG_INDEX3, the third set of beam configuration templates is used, and 7 beams are configured.

5. If this parameter is set to CONFIG_INDEX4, the fourth set of beam configuration templates is used. For 64T64R cells, 15 beams using 4-port TM9 hybrid precoding and 14 beams using 8-port TM9 hybrid precoding are configured. For 32T32R cells, 15 beams using 4-port TM9 hybrid precoding and 6 beams using 8-port TM9 hybrid precoding are configured. This parameter applies only to LTE TDD.

Split SDMA Adaption Period

Indicates the adjustment period for adaptation between entry to and exit from split SDMA in massive MIMO scenarios. This parameter applies only to LTE TDD.

Max Number of MUBF Layers

Indicates the maximum number of layers that can be paired for MU beamforming. This parameter takes effect only when the MuBfSwitch option of the MuBfAlgoSwitch parameter is selected. This parameter applies only to LTE TDD.

MUBF Pairing Rule

Indicates the rule of high-order MU beamforming pairing. This parameter takes effect only when the MuBfSwitch option of the MuBfAlgoSwitch parameter is selected in non-massive MIMO scenarios. There are two pairing rules. PRE_MU_PRI_PAIR_RULE: Indicates that UEs are paired based on the UE scheduling priority used before they are paired. The impact on the network performance of this rule is similar to the impact of the scheduling algorithm used before UE pairing for MU beamforming. POST_MU_PF_PRI_PAIR_RULE: Indicates that UEs are paired based on the evaluated UE scheduling priorities and channel quality difference after UEs are paired for MU beamforming. This rule increases the system capacity after pairing for MU beamforming. This parameter applies only to LTE TDD.

Moving Ue MUBF Scheme

Indicates the MU beamforming scheme selected for moving UEs when massive MIMO is enabled. An appropriate MU beamforming scheme increases the throughput of MU beamforming UEs. This parameter applies only to LTE TDD.

If this parameter is set to MOVING_MUBF_SCHEME_OFF, the eNodeB disables the MU beamforming scheme for moving UEs.

If this parameter is set to HEAVY_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in heavy-load scenarios.

If this parameter is set to LIGHT_LOAD_SCHEME, the eNodeB selects an MU beamforming scheme that applies to moving UEs in light-load scenarios.

If this parameter is set to SPLIT_SDMA_SCHEME, the eNodeB enables split SDMA for moving UEs. This value takes effect after split SDMA is enabled.

If this parameter is set to BIG_EVENT_PROTECT_SCHEME, the eNodeB optimizes MU beamforming pairing for coverage areas with a large number of UEs in mobility state during major events.

If this parameter is set to HIGH_SPEED_OPT_SCHEME, the eNodeB enables MU beamforming pairing optimization in high-speed scenarios.

Port Allocation Avoid for Continuous NACK UEs

Indicates whether to identify UEs with consecutive bit errors and whether to implement the port allocation policy. If this parameter is set to OFF, the eNodeB does not identify and protect UEs with consecutive bit errors. If this parameter is set to USERIDENTIFY, the eNodeB protects only UEs with consecutive bit errors. If this parameter is set to ALLUSERPROTECT, the eNodeB protects all UEs. If this parameter is set to USERIDENTIFYRANK2PAIRING, the eNodeB protects only UEs with consecutive bit errors, and dual-stream beamforming UEs with consecutive bit errors can be paired for MU beamforming and D-MIMO. This parameter applies only to LTE TDD.

Wait Pairing Layer Number Threshold

Indicates the threshold of the number of pairing layers. This parameter is used to identify heavy-load and multi-layer pairing scenarios and adapt the transmission mode for each cell, facilitating multi-user pairing and improving system capacity. If this parameter is set to 0, heavy-load scenarios are not identified and the transmission mode is not adapted for each cell. This parameter applies only to LTE TDD.

Massive MIMO MUBF Pairing Rule

Indicates the rule of UE pairing for MU beamforming in massive MIMO scenarios. For LTE TDD cells, this parameter takes effect only when the MuBfSwitch option of the MuBfAlgoSwitch parameter is selected in massive MIMO scenarios. For LTE FDD cells, this parameter takes effect only when the dynamic dedicated beam (DDB) function is enabled in 32T32R massive MIMO scenarios. If this parameter is set to MU_CORR_PAIR_RULE, the eNodeB selects only UEs of low correlation for pairing. If this parameter is set to MU_WITHOUT_CORR_PAIR_RULE, the eNodeB does not consider UE correlation when selecting UEs for pairing. This parameter applies only to LTE FDD and LTE TDD.

Cell Highload Thd for Switch to BF

Indicates the threshold of the number of pairing layers for switching the UE transmission mode to TM7. If the number of layers of UEs to be paired in the cell reaches this threshold, the eNodeB switches the transmission mode of TM8, open-loop TM9, and MIMO UEs to TM7 to achieve more pairing gains. Set this parameter based on network conditions such as the downlink cell load. The value 0 indicates that this function does not take effect. This parameter indicates the threshold of the number of UEs to be scheduled in the downlink when the DmimoJTSwitch option of the DMIMOAlgoSwitch parameter in the CellAlgoSwitch MO is selected and downlink D-MIMO takes effect. If the number of UEs to be scheduled in the downlink reaches this threshold, the transmission mode of UEs that newly access the network and UEs newly handed over to the cell quickly switches to TM7, TM8, or open-loop TM9. The value 0 indicates the function does not take effect. This parameter applies only to LTE TDD.

BF Weight Optimization Degree Factor

Indicates the beamforming weight optimization degree factor. If this parameter is set to 0, beamforming weight optimization is disabled. If this parameter is set to 1 or a larger value, beamforming weight optimization takes effect. Set this parameter based on time-variant characteristics of channels. This parameter applies only to LTE TDD.

BF Weight Opt Chn Quality Thld Offset(0.1dB)

Indicates the offset to the channel quality threshold for weight optimization. Weight optimization is performed only if the radio channel quality of a UE is lower than the sum of the channel quality threshold and this offset. The channel quality threshold is 0 dB. This parameter applies only to LTE TDD.

BF UE Power Limit Switch

Indicates whether to enable power limit for beamforming UEs in a massive MIMO cell. If this parameter is set to ON, power limit for beamforming UEs in the massive MIMO cell is enabled. The eNodeB limits the power of beamforming UEs that participate in less-than-four-layer pairing or do not participate in pairing, and does not limit the power of beamforming UEs that participate in four-layer or more-than-four-layer pairing. If this parameter is set to OFF, power limit for beamforming UEs in the massive MIMO cell is disabled. This parameter applies only to LTE TDD.

TM8 Pairing Optimization Switch

Indicates whether to enable TM8 pairing optimization. If this parameter is set to ON, TM8 pairing optimization is enabled. If this parameter is set to OFF, TM8 pairing optimization is disabled. This parameter applies only to LTE TDD.

Turbo BF WBB Average UE Count Threshold

Indicates the threshold of the average number of WBB UEs for turbo beamforming. If the average number of WBB UEs in a cell is greater than this threshold within a measurement period, turbo beamforming takes effect. If the average number of WBB UEs in a cell is less than or equal to this threshold, turbo beamforming does not take effect. This parameter applies only to LTE TDD.

MUBF Power Normalization Adaptive Factor

Indicates the control factor of the switching threshold for adaptive MU beamforming power normalization. This parameter is used to calculate the SNR threshold for switching between NEBF and PEBF for pairing UEs. If this parameter is set to 0, PEBF power normalization is always implemented for MU beamforming. If this parameter is set to 10, NEBF is always implemented for MU beamforming. If this parameter is set to a value ranging from 0 to 10, the eNodeB adjusts the SNR threshold for switching between NEBF and PEBF in MU beamforming scenarios. This parameter applies only to LTE TDD.

Adaptive MUBF Start Threshold(%)

Indicates the threshold of the downlink PRB usage in a cell for adaptive entry to or exit from space-domain-preferred MU beamforming. If this parameter is set to 255, adaptive MU beamforming does not take effect. If this parameter is set to a value other than 255, space-domain-preferred MU beamforming takes effect when the downlink PRB usage of a cell is higher than this threshold and does not take effect when the downlink PRB usage of a cell is lower than this threshold (within a certain range). This parameter applies only to 8T8R cells. This parameter applies only to LTE TDD.

Dual-Stream BF Algorithm Switch

Indicates whether to enable dual-stream beamforming.

ACK_FEEDBACK_IN_MUX_MODE_SW: Indicates whether to support the multiplexing mode for ACK feedback during dual-stream beamforming. If this option is selected, the multiplexing mode is supported by ACK feedback during dual-stream beamforming. If this option is deselected, the multiplexing mode is not supported by ACK feedback during dual-stream beamforming. This option applies only to LTE TDD.

Heavy-Load Switch to BF Optimization

Indicates whether to enable the optimization of switching to beamforming in heavy-load scenarios.

If this parameter is set to 255, the optimization does not take effect.

For massive MIMO cells, if this parameter is set to a value other than 255 and the MultiLayerThdSwitchToTM7 or WaitPairingLayerThd parameter in the CellBf MO is set to a value other than 0, online WBB UEs are allowed to be switched to beamforming in heavy-load scenarios. If the HEAVYLOADTRANSMODEADAPTBOOSTSW and HISTORICALSPECTRALEFFOPTSW options of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO are both selected, adaptive switching between cell-level transmission mode adaptation and cell-level target transmission mode is enabled only when the average number of downlink pairing layers is less than or equal to the value of this parameter.

For non-massive MIMO cells, if this parameter is set to a value other than 255, the HEAVYLOADTRANSMODEADAPTBOOSTSW option of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO is selected, and a UE supporting three or more layers in TM9 uses TM9 with PMI in 5 seconds after accessing a cell using the target transmission mode, then it will not be forcibly switched to beamforming.

This parameter applies only to LTE TDD.

UE Identification Switch

Indicates whether to enable status identification for different types of UEs.

SRS_LMT_AND_ABN_UE_IDENT_SW: Indicates whether to enable identification of SRS-restricted UEs and UEs suffering from abnormal downlink scheduling. If this option is selected, the eNodeB identifies UEs with poor downlink performance or suffering from abnormal downlink scheduling due to delayed SRS updates. If this option is deselected, the algorithm does not take effect. This option applies only to LTE TDD.

LARGE_DELAY_SPREAD_UE_IDENT_SW: Indicates whether to enable identification of UEs with a long delay spread. If this option is selected, the identification takes effect. If this option is deselected, the identification does not take effect. This option applies only to LTE TDD.

MUBF Algorithm Optimization Switch

Indicates whether to enable MU beamforming optimization algorithms.

ABN_UE_PRI_SUPPRESSION_SW: Indicates whether to restrict the priorities of abnormal UEs. If this option is selected, the function takes effect. If this option is deselected, the function does not take effect. This option applies only to 8T8R cells. This option applies only to LTE TDD.
