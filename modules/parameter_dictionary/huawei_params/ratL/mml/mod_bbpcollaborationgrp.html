Modify Bbp Collaboration Group status (MOD BBPCOLLABORATIONGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a BBP collaboration group.

Note

None.

Parameters

ID Name Description
BbCoGroupId BBP Collaboration Group ID

Meaning: Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InventoryBaseBandEqmId Inventory Baseband Equipment ID

Meaning: Indicates the ID of the inventory baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, an inventory BBP in a BBU is added to the inventory baseband equipment and the ID of the inventory baseband equipment is associated with the ID of the BBP collaboration group. In this way, an inventory BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoBaseBandEqmId Collaborating Baseband Equipment ID

Meaning: Indicates the ID of the collaborating baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, a collaborating BBP in a BBU is added to the collaborating baseband equipment and the ID of the collaborating baseband equipment is associated with the ID of the BBP collaboration group. In this way, a collaborating BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CollaboratingFeatureList Collaborating Features

Meaning: Indicates the feature that a BBP collaboration group supports. The feature is specified when the group is created. Currently, only the Turbo Receiver feature is supported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: TURBO_RECEIVER(TURBO_RECEIVER)

Unit: None

Actual Value Range: TURBO_RECEIVER

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Modify Bbp Collaboration Group :

+++    0        2016-04-21 18:59:45
O&M    #806355043
%%MOD BBPCOLLABORATIONGRP: BbCoGroupId=2, InventoryBaseBandEqmId=3, CoBaseBandEqmId=2;%%
RETCODE = 0  Operation succeeded.
