Modify CellLcsCfg Configuration (MOD CELLLCSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to the cell LCS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

A modification to the NB_OTDOA_SWITCH option of the CellLcsSwitch parameter will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
NbEcidPositioningUeCount NB-IoT E-CID-based Positioning UE Count

Meaning: Indicates the maximum number of UEs that can simultaneously perform measurements for E-CID-based positioning in a cell. E-CID-based positioning is enabled in a cell only if this parameter is set to a non-zero value. This parameter applies only to NB-IoT.

GUI Value Range: 0~12

Unit: None

Actual Value Range: 0~12

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer UEs that can simultaneously perform E-CID-based positioning in a cell, which means less impact on other UEs in the cell and shorter positioning time. A larger value of this parameter leads to more UEs that can simultaneously perform E-CID-based positioning in a cell, which means that more RACH resources are consumed.

Applicable Mode: L-NB-IOT
CellLcsSwitch Cell LCS Switch

Meaning: Indicates whether to enable location service (LCS) functions in the cell.

NB_OTDOA_SWITCH: Indicates whether to enable OTDOA-based positioning for NB-IoT cells. OTDOA-based positioning is enabled for NB-IoT cells only if this option is selected.

For FDD and TDD cells, OTDOA-based positioning is enabled when either this option or the OtdoaSwitch option of the LcsSwitch parameter in the ENodeBAlgoSwitch MO is selected, and is disabled when both options are deselected.

GUI Value Range: NB_OTDOA_SWITCH(NB_OTDOA_SWITCH)

Unit: None

Actual Value Range: NB_OTDOA_SWITCH

MML Default Value: None

Recommended Value: NB_OTDOA_SWITCH:Off

Parameter Relationship:

-Configuration constraints:

  • If the DeployMode parameter in the Prb MO is set to IN_BAND and the OtdoaSwitch option of the LcsSwitch parameter in the ENodeBAlgoSwitch MO and the NB_OTDOA_SWITCH option of the CellLcsSwitch parameter in the CellLcsCfg MO are selected, the NprsId parameter (if not set to 65535) in the EuPrbSectorEqm MO must be set to the same value as the PhyCellId parameter in the Cell MO for the LTE cell associated with the NB-IoT cell, or has a different mod 6 value from the PhyCellId parameter.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: NB_OTDOA_SWITCH: For NB-IoT cells: If this option is selected, OTDOA-based positioning is supported. NPRSs occupy downlink air interface resources, causing downlink performance to deteriorate. If this option is deselected, OTDOA-based positioning is not supported. For FDD and TDD cells: If this option is selected, OTDOA-based positioning is supported. PRS transmission occupies air interface resources. A shorter PRS period leads to a larger number of consecutive subframes in which PRSs are sent, and therefore more resources are occupied. If this option is deselected, air interface resources will not be occupied by PRSs.

Applicable Mode: L

Example

To modify the CellLcsCfg Configuration with the parameters as follows: Local cell ID: 0, NB-IoT E-CID-based Positioning UE Count: 1, run the following command:
MOD CELLLCSCFG: LocalCellId=0, NbEcidPositioningUeCount=1;
