Modify Cell Uplink MIMO Parameters Configuration (MOD CELLULMIMOPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the UL MIMO parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlSuMimoRankPara UpLink SU-MIMO Rank

Meaning: Indicates the rank selection method when the uplink transmission mode is TM2. If this parameter is set to FixRank1(FixRank1), only rank 1 transmission can be performed for all UEs in the network. If this parameter is set to FixRank2(FixRank2), only rank 2 transmission can be performed for all UEs in the network. If this parameter is set to RankAdaptive(RankAdaptive), the eNodeB adaptively selects a rank based on the UE channel quality. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RankAdaptive(RankAdaptive), FixRank1(FixRank1), FixRank2(FixRank2)

Unit: None

Actual Value Range: RankAdaptive, FixRank1, FixRank2

MML Default Value: None

Recommended Value: RankAdaptive

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to FixRank1(FixRank1), only single-stream transmission can be performed for UEs. In this case, the CEU performance is good, but dual-stream transmission cannot be performed for UEs in and near the cell center, affecting the performance of such UEs. If this parameter is set to FixRank2(FixRank2), dual-stream transmission can be performed for UEs in and near the cell center, increasing the throughput of such UEs. However, the CEU performance deteriorates. If this parameter is set to RankAdaptive(RankAdaptive), the eNodeB adaptively selects an optimal rank based on the UE channel quality.

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of CellUlMimoParaCfg with the parameters as follows: Local cell ID: 0, UpLink SU-MIMO Rank=RankAdaptive, run the following command:
MOD CELLULMIMOPARACFG: LocalCellId=0, UlSuMimoRankPara=RankAdaptive;
