Display RRU Location Sequence Sending and Receiving (DSP EUCELLRRULOCATIONTASK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display a task of sending and receiving RRU location sequences. This command applies only to LTE TDD cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorEqmId Sector equipment ID

Meaning: Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • SECTORID on which SectorEqmId depends must have been configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
TaskId Task ID

Meaning: Indicates the ID that uniquely identifies a location sequence sending and receiving task. This parameter applies only to LTE TDD.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Output Description

Field Description

Local cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

Task ID

Indicates the ID that uniquely identifies a location sequence sending and receiving task. This parameter applies only to LTE TDD.

Task Status

Indicates the status of a location sequence sending and receiving task. This parameter applies only to LTE TDD.

Start Time

Indicates the time when location sequence sending or receiving starts. This parameter applies only to LTE TDD.

Duration(1024frame)

Indicates the duration of sending and receiving location sequences. This parameter applies only to LTE TDD.

Start Frame

Indicates the first radio frame used to send and receive location sequences. This parameter applies only to LTE TDD.

Frame Number

Indicates the number of radio frames used to send and receive location sequences. This parameter applies only to LTE TDD.

Send and Receive Mode

Indicates the mode of sending and receiving location sequences. This parameter applies only to LTE TDD.

Target eNodeB ID

Indicates the ID of the eNodeB to be located. This parameter applies only to LTE TDD.

Target Sector Equipment ID

Indicates the ID of the sector equipment to be located. This parameter applies only to LTE TDD.

Task Type

Indicates the type of a location sequence sending and receiving task. This parameter applies only to LTE TDD.
