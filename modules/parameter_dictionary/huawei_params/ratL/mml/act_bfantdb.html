Activate Beamforming Antenna Weight Database (ACT BFANTDB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to activate the weight database file for a beamforming antenna. This command applies only to LTE TDD non-massive MIMO scenarios.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • An activated weight database file can be uploaded by running the ULD FILE command. For details, see the ULD FILE command.

  • This operation may affect cell services.

Parameters

ID Name Description
OPMODE Device type

Meaning: Indicates the mode for activating the weight database file.

GUI Value Range: SWFILE, DLDFILE

Unit: None

Actual Value Range: SWFILE, DLDFILE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To activate a weight database file with the operation mode set to SWFILE, run the following command:
ACT BFANTDB: OPMODE=SWFILE;
