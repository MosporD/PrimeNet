Modify PUSCH Configuration (MOD PUSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PUSCH configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When a cell is active, modifications on the following parameters do not affect the services in the cell: GroupAssignPUSCH, CyclicShift. Modifications on other parameters of an active cell will result in the automatic reset of the cell.

GroupHoppingEnabled Group hopping enabled

Meaning: Indicates whether group hopping of the PUSCH is enabled.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: None

Recommended Value: BOOLEAN_FALSE(False)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: As a supplement to planning of base sequence groups for UL RS generation, group hopping simplifies the planning and randomizes UL RS correlation interference. Though the current group hopping can significantly reduce the probability of collisions that neighboring cells use the same base sequence group in a TTI, it cannot completely prevent such collisions.

(a) When the number of cells is less than 30, the reuse of base sequence groups does not occur. In this case, group hopping is not required. Therefore, it is recommended that group hopping be disabled.

(b) When the number of cells exceeds 30, the reuse of base sequence groups might occur. Though planning can be performed to prevent neighboring cells from using the same base sequence group, the planning is complicated when there are a large number of cells. In this case, it is recommended that group hopping be enabled to randomize UL RS interference and prevent complicated planning.

Applicable Mode: L-FDD, L-TDD
GroupAssignPUSCH Group assignment PUSCH

Meaning: Indicates the group assignment of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~29

Unit: None

Actual Value Range: 0~29

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When GroupAssignPUSCH of all cells under one eNodeB is set to 0, the UL RSs on the PUSCHs are generated on the basis of different base sequence groups. In this case, each cell can use any Cyclic Shift (CS) value during the generation of the UL RS. The more the available CS values, the more the V-MIMO users that can be matched.

When GroupAssignPUSCH of cells under one eNodeB is set to different values, the UL RSs on the PUSCHs can be generated on the basis of the same base sequence. Thus, the orthogonality of UL RSs between neighboring cells can be slightly improved. In addition, to ensure orthogonality of UL RSs between cells, only part of the CS values are available for each cell. Thus, the number of available CS values decreases and the number of V-MIMO users that can be matched also decreases.

Applicable Mode: L-FDD, L-TDD
SeqHoppingEnabled Sequence hopping enabled

Meaning: Indicates whether sequence hopping of the PUSCH is enabled.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: None

Recommended Value: BOOLEAN_FALSE(False)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When group hopping is not performed, sequence hopping can be supported. After base sequences are divided into groups, the base sequences within each group have great correlations (the base sequences are almost regarded as identical). The correlations between a base sequence in group A and the base sequences in group B are similar to those between any other base sequence in group A and the base sequences in group B. Thus, sequence hopping is equivalent to the use of an identical base sequence in each TTI, which does not result in an obvious difference from that when sequence hopping is not performed. Therefore, it is recommended that sequence hopping be disabled.

Applicable Mode: L-FDD, L-TDD
CyclicShift Cyclic shift

Meaning: Indicates the cyclic shift of the PUSCH.

For details, see 3GPP TS 36.211. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When all cells under one eNodeB use the same base sequence group to generate UL RSs on PUSCHs, different CyclicShift values need to be set for these cells so that the cells use different cyclic shifts during semi-persistent scheduling.

When the cells under one eNodeB use different base sequence groups to generate UL RSs on PUSCHs, set CyclicShift to 0.

Applicable Mode: L-FDD, L-TDD

R12Qam64Enabled R12 UL 64QAM Enabled

Meaning: Indicates whether the eNodeB supports UL 64QAM for UEs compliant with 3GPP Release 12 and later. This parameter is valid only when the Qam64Enabled parameter in the PUSCHCfg MO is set to BOOLEAN_TRUE. When R12Qam64Enabled is set to BOOLEAN_TRUE, the eNodeB supports UL 64QAM for UEs compliant with 3GPP TS 36.331 V12.7.0 or later as well as for UEs compliant with versions earlier than 3GPP TS 36.331 V12.7.0. When R12Qam64Enabled is set to BOOLEAN_FALSE, the eNodeB does not support UL 64QAM for certain UEs, except CAT5 and CAT8 UEs, that comply with versions later than 3GPP TS 36.331 V12.7.0.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: None

Recommended Value: BOOLEAN_TRUE(True)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Setting this parameter to BOOLEAN_TRUE has no impact on network performance. If this parameter is set to BOOLEAN_FALSE, serious bit errors will occur in the demodulation of UL data modulated using MCSs of indexes 21 to 24, affecting network performance.

Applicable Mode: L-FDD, L-TDD
Ul256QamAlgoSwitch UL 256QAM Algorithm Switch

Meaning: Indicates whether to enable uplink 256QAM.

UL_256QAM_SWITCH: If this option is selected, uplink 256QAM is enabled. The maximum uplink modulation scheme can be 256QAM for UEs supporting uplink 256QAM. If this option is deselected, uplink 256QAM is disabled. The maximum uplink modulation scheme is 64QAM. This option applies only to LTE TDD.

GUI Value Range: UL_256QAM_SWITCH(UL_256QAM_SWITCH)

Unit: None

Actual Value Range: UL_256QAM_SWITCH

MML Default Value: None

Recommended Value: UL_256QAM_SWITCH: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_256QAM_SWITCH: If this option is selected, the throughput and spectral efficiency of UEs supporting uplink 256QAM and residing near the cell center increase, and the data transmission delay decreases. If this option is deselected, network performance is not affected.

Applicable Mode: L-TDD
Ul256QamMcsTblAdpPeriod UL 256QAM MCS Table Adaptive Period

Meaning: Indicates the period for adaptation of the MCS table for uplink 256QAM. This parameter is valid only if the adaptive MCS table configuration policy is used. This parameter applies only to LTE TDD.

GUI Value Range: 1~1000

Unit: s

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to more adaptive switching of the MCS table based on channel quality and higher uplink rates but more frequent signaling reconfiguration. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-TDD
Ul256QamMcsTblCfgStrategy UL 256QAM MCS Table Configuration Strategy

Meaning: Indicates the MCS table configuration policy for uplink 256QAM. The policy can be fixed or adaptive.

If this parameter is set to FIXED_CONFIGURATION, the MCS table supporting 256QAM is always used for uplink scheduling of UEs supporting 256QAM. If this parameter is set to ADAPTIVE_CONFIGURATION, the eNodeB adaptively selects the MCS table supporting or not supporting 256QAM based on channel quality for UEs supporting uplink 256QAM. This parameter is valid only if the UL_256QAM_SWITCH option is selected. This parameter applies only to LTE TDD.

GUI Value Range: FIXED_CONFIGURATION(FIXED_CONFIGURATION), ADAPTIVE_CONFIGURATION(ADAPTIVE_CONFIGURATION)

Unit: None

Actual Value Range: FIXED_CONFIGURATION, ADAPTIVE_CONFIGURATION

MML Default Value: None

Recommended Value: ADAPTIVE_CONFIGURATION(ADAPTIVE_CONFIGURATION)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to FIXED_CONFIGURATION, the uplink rate of QPSK-modulated UEs supporting 256QAM decreases, but the signaling overhead also decreases. If this parameter is set to ADAPTIVE_CONFIGURATION, the uplink rate of QPSK-modulated UEs supporting 256QAM increases, but the signaling overhead also increases and the uplink throughput during handovers may decrease.

Applicable Mode: L-TDD

Example

Example 1: To modify the PUSCH configuration with the parameters as follows: Local cell ID: 0, Group assignment PUSCH: 10, run the following command:
MOD PUSCHCFG: LocalCellId=0, GroupAssignPUSCH=10;
Example 2: To modify the PUSCH configuration with the parameters as follows: Local cell ID: 0, Cyclic shift: 2, run the following command:
MOD PUSCHCFG: LocalCellId=0, CyclicShift=2;
