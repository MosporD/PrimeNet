Add Operator (ADD X2AUTOSETUPOPERATOR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an operator that the target eNodeB supporting X2 self-setup belongs to.

Note

An eNodeB can be configured with a maximum of 10 operators that target eNodeBs supporting X2 self-setup belong to

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of an operator that the target eNodeB supporting X2 self-setup belongs to. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in each X2AutoSetupOperator MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of an operator that the target eNodeB supporting X2 self-setup belongs to. The value of this parameter is a string of two or three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in each X2AutoSetupOperator MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add the operator information about the target eNodeB supporting X2 self-setup, Mobile country code is 460, Mobile network code is 01, run the following command:
ADD X2AUTOSETUPOPERATOR: Mcc="460", Mnc="01";
