List Bbp Collaboration Group Configurations (LST BBPCOLLABORATIONGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the BBP collaboration group configurations.

Note

None.

Parameters

ID Name Description
BbCoGroupId BBP Collaboration Group ID

Meaning: Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Bbp Collaboration Group Configurations:

+++    0        2016-04-21 18:48:07
O&M    #806355037
%%LST BBPCOLLABORATIONGRP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

BBP Collaboration Group ID

Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

Inventory Baseband Equipment ID

Indicates the ID of the inventory baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, an inventory BBP in a BBU is added to the inventory baseband equipment and the ID of the inventory baseband equipment is associated with the ID of the BBP collaboration group. In this way, an inventory BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.

Collaborating Baseband Equipment ID

Indicates the ID of the collaborating baseband equipment associated with a BBP collaboration group. When a BBP collaboration group is created, a collaborating BBP in a BBU is added to the collaborating baseband equipment and the ID of the collaborating baseband equipment is associated with the ID of the BBP collaboration group. In this way, a collaborating BBP is added to the BBP collaboration group. This parameter applies only to LTE FDD and LTE TDD.

Collaborating Features

Indicates the feature that a BBP collaboration group supports. The feature is specified when the group is created. Currently, only the Turbo Receiver feature is supported. This parameter applies only to LTE FDD and LTE TDD.

Collaboration Group Block Indication

Indicates the blocking method of a baseband processing unit (BBP) collaboration group. If this parameter is set to HIGH_PRIORITY_BLOCK(HIGH_PRIORITY_BLOCK), the UEs transferred from inventory BBPs to collaborating BBPs for assistance are immediately released. If this parameter is set to LOW_PRIORITY_BLOCK(LOW_PRIORITY_BLOCK), a BBP collaboration group is blocked when there are no UEs transferred from inventory BBPs to collaborating BBPs for assistance. If this parameter is set to UNBLOCK(Unblock), a BBP collaboration group is unblocked. This parameter applies only to LTE FDD and LTE TDD.
