List Physical Resource Block (LST PRB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of a physical carrier for an NB-IoT cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

List Physical Resource Block in one NB-IOT cell:
LST PRB: LocalCellId=1;

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

Deployment Mode

Indicates the NB-IoT PRB deployment mode. STAND_ALONE indicates that out-of-band LTE spectrum resources are used to deploy NB-IoT PRB. GUARD_BAND indicates that NB-IoT PRB is deployed on the LTE guardband. IN_BAND indicates that PRB is deployed on the LTE RB resources, which means that fewer RBs are available for LTE. This parameter applies only to NB-IoT.

Work Mode

Indicates the working mode of the carrier for an NB-IoT cell. This parameter must be set to UL_DL for the anchor carrier. This parameter applies only to NB-IoT.

Anchor Carrier Flag

Indicates whether the PRB is an anchor carrier. This parameter applies only to NB-IoT.

Frequency Band

Indicates the frequency band to which the PRB belongs. For details, see 3GPP TS 36.104. This parameter applies only to NB-IoT.

Uplink EARFCN Configuration Indicator

Indicates whether to configure information about the PRB uplink EARFCN. This parameter applies only to NB-IoT.

LTE Uplink RB Index

Indicates the index of a physical layer RB. This parameter is valid only when the DeployMode parameter is set to IN_BAND and the UlEarfcnCfgInd parameter is set to CFG. For details, see 3GPP TS 36.211. The value 255 indicates an invalid RB index. The UlEarfcn and UlFreqOffset parameters can be set only when this parameter is set to 255. This parameter applies only to NB-IoT.

Uplink EARFCN

Indicates the PRB uplink EARFCN, which is optional. This parameter takes effect only when UlEarfcnCfgInd is set to CFG(Configure). Otherwise, the eNodeB calculates this parameter value based on the rule that RB positions in the uplink and downlink are consistent. This parameter applies only to NB-IoT.

Uplink Frequency Offset

Indicates the frequency offset of the PRB uplink central frequency to the uplink frequency. This parameter takes effect only when UlEarfcnCfgInd is set to CFG(Configure). Otherwise, the eNodeB calculates this parameter value based on the rule that RB positions in the uplink and downlink are consistent. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.

LTE Downlink RB Index

Indicates the index of a physical layer RB. This parameter is valid only when the DeployMode parameter is set to IN_BAND. For details, see 3GPP TS 36.211. The value 255 indicates an invalid RB index. The DlEarfcn and DlFreqOffset parameters can be set only when this parameter is set to 255. This parameter applies only to NB-IoT.

Downlink EARFCN

Indicates the PRB DL EARFCN. For details, see 3GPP TS 36.104. This parameter applies only to NB-IoT.

Downlink Frequency Offset

Indicates the frequency offset of the PRB downlink central frequency to the downlink frequency. For details, see 3GPP TS 36.101. This parameter applies only to NB-IoT.

LTE Bandwidth

Indicates the LTE cell bandwidth. This parameter takes effect only when DeployMode is set to GUARD_BAND. This parameter applies only to NB-IoT.

LTE Downlink EARFCN

Indicates the downlink EARFCN of an LTE cell. This parameter takes effect only when DeployMode is set to GUARD_BAND. This parameter applies only to NB-IoT.

LTE Cell ID

Indicates the LTE cell ID. This parameter takes effect only when DeployMode is set to IN_BAND. This parameter applies only to NB-IoT.

Uplink All Symbol Send Flag

Indicates whether all PRB uplink symbols are used for sending. When this parameter is set to TRUE, all NB-IoT PRB uplink symbols are sent. When this parameter is set to FALSE, not all NB-IoT PRB uplink symbols are sent. In in-band scenarios, NB-IoT PRB symbols and LTE SRS symbols must be staggered to avoid interference. This parameter applies only to NB-IoT.

PRB Block Priority

Indicates the block priority of the PRB when it is a non-anchor carrier. If this parameter is set to HIGH_PRIORITY_BLOCK, the PRB is deactivated immediately. If this parameter is set to MEDIUM_PRIORITY_BLOCK, the access of new UEs is not allowed within 5 minutes and the PRB is deactivated immediately in the case of no existing UEs. Otherwise, the PRB is deactivated after 5 minutes irrespective of whether any UE exists. If this parameter is set to LOW_PRIORITY_BLOCK, the access of new UEs is not allowed and the PRB is deactivated only when no UE occupies the PRBs. This parameter applies only to NB-IoT.

NPRS Parameter Group ID

Indicates an NPRS parameter group ID. The value 255 indicates an invalid ID. This parameter applies only to NB-IoT.

PRACH Coverage Level Type

Indicates the PRACH coverage level supported by the PRB when it is a non-anchor carrier. A maximum of three coverage levels of PRACH resources are supported.

COVERAGE_LEVEL_0: When this option is selected, the PRACH configuration of coverage level 0 in the PrbRachCeConfig MO is supported on the PRB. If this option is deselected, the configuration is not supported.

COVERAGE_LEVEL_1: When this option is selected, the PRACH configuration of coverage level 1 in the PrbRachCeConfig MO is supported on the PRB. If this option is deselected, the configuration is not supported.

COVERAGE_LEVEL_2: When this option is selected, the PRACH configuration of coverage level 2 in the PrbRachCeConfig MO is supported on the PRB. If this option is deselected, the configuration is not supported.

If all options are deselected, PRACH is not supported on the PRB.

This parameter applies only to NB-IoT.
