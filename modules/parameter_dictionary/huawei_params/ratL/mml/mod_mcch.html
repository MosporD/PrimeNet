Modify Mcch (MOD MCCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify MCCH configuration data.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Unit: None

Actual Value Range: 0~71

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcs Modulation and Coding Scheme

Meaning: Indicates the MCS for information transmitted over the MCCH. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: N2(N2), N7(N7), N13(N13), N19(N19)

Unit: None

Actual Value Range: N2, N7, N13, N19

MML Default Value: None

Recommended Value: N2(N2)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ModificationPeriod Modification Period

Meaning: Indicates the interval between MCCH updates. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF512(RF512), RF1024(RF1024)

Unit: None

Actual Value Range: RF512, RF1024

MML Default Value: None

Recommended Value: RF512(RF512)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PdcchLength PDCCH Length

Meaning: Indicates the number of OFDM symbols (in an MBSFN subframe) used for the PDCCH. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: S1(S1), S2(S2)

Unit: None

Actual Value Range: S1, S2

MML Default Value: None

Recommended Value: S1(S1)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RepetitionPeriod Repetition Period

Meaning: Indicates the interval between transmissions of MCCH information. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RF32(RF32), RF64(RF64), RF128(RF128), RF256(RF256)

Unit: None

Actual Value Range: RF32, RF64, RF128, RF256

MML Default Value: None

Recommended Value: RF32(RF32)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RepetitionPeriodOffset Repetition Period Offset

Meaning: Indicates the repetition period offset, which is used together with the RepetitionPeriod parameter in the Mcch MO to specify the radio frames in which MCCH information is transmitted. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SubframeAllocationInfo Subframe Allocation Information

Meaning: Indicates the subframes in a radio frame in which MCCH information can be sent. If the cells in an MBSFN area work in TDD mode, SF3, SF4, SF7, SF8, and SF9 (represented by bit 5 to bit 1 in sequence) can be configured as MBSFN subframes. If a bit is set to 1, the corresponding subframe can be used for MCCH information transmission. If the cells in an MBSFN area work in FDD mode, SF1, SF2, SF3, SF6, SF7, and SF8 (represented by bit 5 to bit 0 in sequence) can be configured as MBSFN subframes. If a bit is set to 1, the corresponding subframe can be used for MCCH information transmission. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 32

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the following MCCH parameters, Local MCE ID:0, MBSFN Area ID:0, Modulation and Coding Scheme:N2, Modification Period:RF512, PDCCH Length:S1, Repetition Period:RF32, Repetition Period Offset:1, Subframe Allocation Information:0, run the following command:
MOD MCCH: LocalMceId=0, MbsfnAreaId=0, Mcs=N2, ModificationPeriod=RF512, PdcchLength=S1, RepetitionPeriod=RF32, RepetitionPeriodOffset=1, SubframeAllocationInfo=0;
