List eNodeB Function Configuration (LST ENODEBFUNCTION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list eNodeB function configuration information.

Note

If eNodeB is connected with MAE, eNodeB Function Name will be synchronized from MAE to the eNodeB automatically.

Parameters

None.

Example

To list eNodeB function configurations, run the following command:
LST ENODEBFUNCTION:;
The result is shown as follows:
+++    0        2018-11-23 15:56:32
O&M    #806355229
%%LST ENODEBFUNCTION:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

eNodeB Function Name

Indicates the name of an eNodeB function, which uniquely identifies the eNodeB function.

Application Reference

Indicates the ID of the application referenced by an eNodeB function. The application provides an operating environment for the eNodeB function.

eNodeB ID

Indicates the eNodeB ID defined in the service protocol interface, which uniquely identifies an eNodeB within a PLMN. For details, see 3GPP TS 36.300.

User Label

Indicates user-defined remarks.

NeRM Version

Indicates model definition version of eNodeB resources, including the management object (MO) definition, attribute definition, and configuration rules.

Product Version

Indicates the version of the product. This parameter is valid for version query.
