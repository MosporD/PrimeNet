Add Inter-PLMN Handover List (ADD INTERPLMNHOLIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add InterPlmnHo information.

Note

A maximum of eight MOs can be configured for each CnOperator.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TarMcc Target Mobile country code

Meaning: Indicates the mobile country code of the target PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TarMnc Target Mobile network code

Meaning: Indicates the mobile network code of the target PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a InterPlmnHo information with the parameters follows: CnOperatorId: 0, TarMcc: "460", TarMnc: "01", run the following command:
ADD INTERPLMNHOLIST: CnOperatorId=0, TarMcc="460", TarMnc="01";
