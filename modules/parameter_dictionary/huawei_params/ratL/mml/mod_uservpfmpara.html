Modify User Experience Parameter (MOD USERVPFMPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters used to evaluate user experience.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify configurations related to user experience evaluation with the parameters as follows: Local cell ID: 0, Downlink User Throughput Threshold 0: 100, run the following command:
MOD USERVPFMPARA: LocalCellId=0, DlUserThruputThd0=100;
