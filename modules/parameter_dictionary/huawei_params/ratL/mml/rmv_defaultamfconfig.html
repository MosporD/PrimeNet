Remove Default AMF Configuration (RMV DEFAULTAMFCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the configuration of a default AMF.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator that owns the NG object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DefaultAmfRegionId Default AMF Region ID

Meaning: Indicates the default AMF region ID. For details, see 3GPP TS 23.501.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DefaultAmfSetId Default AMF Set ID

Meaning: Indicates the default AMF set ID. For details, see 3GPP TS 23.501.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DefaultAmfPointer Default AMF Pointer

Meaning: Indicates the default AMF pointer. For details, see 3GPP TS 23.501.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove  a default AMF configuration with the parameters as follows:CN Operator ID: 0, Default AMF Region ID: 0, Default AMF Set ID:0, Default AMF Pointer:0, run the following command:
RMV DEFAULTAMFCONFIG: CnOperatorId=0, DefaultAmfRegionId=0, DefaultAmfSetId=0, DefaultAmfPointer=0;
