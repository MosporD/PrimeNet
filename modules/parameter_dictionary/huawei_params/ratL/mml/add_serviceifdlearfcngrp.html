Add Configuration group of Service InterFreq DLEARFCN group (ADD SERVICEIFDLEARFCNGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a group of DL EARFCNs to service-based inter-frequency handover policy group.

Note

  • DlEarfcn must have been set in the associated EutranInterNFreq when the value of the InterFreqHoState in the associated ServiceIfHoCfgGroup is set to PERMIT_HO.

  • A maximum of 16 DL EARFCN can be added for a service-based inter-frequency handover policy group.

Example

To add a service-based inter-Freq handover DL Earfcn group with the parameters as follows: Cn Operator ID: 0, ServiceIfHoCfgGroupId: 9, DlEarfcnIndex: 0, DlEarfcn: 38100, run the following command:
ADD SERVICEIFDLEARFCNGRP: CnOperatorId=0, ServiceIfHoCfgGroupId=9, DlEarfcnIndex=0, DlEarfcn=38100;
