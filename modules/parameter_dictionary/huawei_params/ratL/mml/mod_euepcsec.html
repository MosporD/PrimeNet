Modify Security Policy and Algorithm in EPC (MOD EUEPCSEC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the security policies and algorithms of the compact EPC.

Note

None.

Parameters

ID Name Description
CiphAlgo Cipher Algorithm

Meaning: Indicates the algorithm that the compact EPC preferentially selects to encrypt NAS messages. For example, if this parameter is set to EEA2, the EEA2 algorithm is preferentially selected to encrypt NAS messages. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EEA0(NULL), EEA1(SNOW 3G), EEA2(AES)

Unit: None

Actual Value Range: EEA0, EEA1, EEA2

MML Default Value: None

Recommended Value: EEA0:Off, EEA1:Off, EEA2:On

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntAlgo Integrity Algorithm

Meaning: Indicates the algorithm that the compact EPC preferentially selects to ensure NAS message integrity. If this parameter is set to EIA2, the EIA2 algorithm is preferentially selected to ensure NAS message integrity. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EIA1(SNOW 3G), EIA2(AES)

Unit: None

Actual Value Range: EIA1, EIA2

MML Default Value: None

Recommended Value: EIA1:Off, EIA2:On

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set a security policy and algorithm for the EPC-inside with the parameters as follows: Cipher Algorithm:NULL:On, Snow3G:On, AES:On, run the following command:
MOD EUEPCSEC: CiphAlgo=EEA0-1&EEA1-1&EEA2-1;
