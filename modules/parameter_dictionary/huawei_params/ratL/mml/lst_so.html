List SO Configuration (LST SO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the SO MO, including the SO MO ID, end point

Note

None.

Parameters

ID Name Description
SoId SO ID

Meaning: Indicates the ID of the SO MO. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: Currently, customers have no requirements for the SO interface. This parameter will be deleted in later versions. Although the configuration interface in this version still supports synchronization and delivery of the setting of this parameter, the system no longer uses this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the SO MO information, run the following command:
+++    HUAWEI 
   2014-11-10 10:52:05
O&M    #24264
%%LST SO:;%%
RETCODE = 0  Operation succeeded.

List SO Configuration
----------------------
                          SO ID  =  0
     End Point Group Config Flag  =  CPUP Config
Control Plane End Point Group ID  =  0
   User Plane End Point Group ID  =  0
                      User Label  =  123
(Number of results = 1)


---    END

Output Description

Field Description

SO ID

Indicates the ID of the SO MO. This parameter applies only to LTE FDD and LTE TDD.

End Point Group Config Flag

Indicates whether to configure the control-plane endpoint group, user-plane end point group, or both end point groups for the SO MO. This parameter applies only to LTE FDD and LTE TDD.

Control Plane End Point Group ID

Indicates the ID of the control-plane endpoint group used by the SO MO. This parameter applies only to LTE FDD and LTE TDD.

User Plane End Point Group ID

Indicates the ID of the user-plane endpoint group used by the SO MO. This parameter applies only to LTE FDD and LTE TDD.

User Label

Indicates the description of the SO MO. This parameter applies only to LTE FDD and LTE TDD.
