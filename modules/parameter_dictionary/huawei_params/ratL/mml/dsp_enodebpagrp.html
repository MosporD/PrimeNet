Display Power Sharing Group Status (DSP ENODEBPAGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the dynamic power sharing group.

Note

None.

Parameters

None.

Example

To display the status of the dynamic power sharing group of the eNodeB, run the following command:
DSP ENODEBPAGRP:;
The result is shown as follows:
+++    0        2017-09-25 09:46:07
O&M    #806355192
%%DSP ENODEBPAGRP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Power Sharing Group ID

Indicates the ID of a power sharing group. This parameter applies only to LTE FDD and LTE TDD.

Power Sharing Group Local Cell ID

Indicates the local ID of a cell in a power sharing group. This parameter applies only to LTE FDD and LTE TDD.

Power Sharing Group Sector Equipment List

Indicates the list of sector equipment for a cell in a power sharing group. This parameter applies only to LTE FDD and LTE TDD.

Power Sharing Group Type

Indicates the type of the power sharing group. This parameter applies only to LTE FDD and LTE TDD.
