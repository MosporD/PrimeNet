List Cell CE Scheduling Configuration (LST CELLCESCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list coverage-level-specific cell scheduling configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the cell coverage level, which corresponds to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancements.

When this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, and COVERAGE_LEVEL_3, the maximum coverage level supported by the cell is coverage level 0, coverage level 1, coverage level 2, and coverage level 3, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2), COVERAGE_LEVEL_3(COVERAGE_LEVEL_3)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, COVERAGE_LEVEL_3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Coverage Level

Indicates the cell coverage level, which corresponds to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancements.

When this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, and COVERAGE_LEVEL_3, the maximum coverage level supported by the cell is coverage level 0, coverage level 1, coverage level 2, and coverage level 3, respectively. This parameter applies only to LTE FDD and LTE TDD.

CE SIB1 Repetition Number

Indicates the number of times the eNodeB repeatedly sends the SIB-BR message in a period in the current coverage enhancement mode of a cell. If this parameter corresponding to the maximum coverage level supported by the cell is modified, eMTC UEs that already accessed the cell will be proactively released. This parameter applies only to LTE FDD and LTE TDD.

Max Number of PDSCH Repetitions in Mode A

Indicates the maximum number of times the eNodeB repeatedly uses a PDSCH for a UE in coverage enhancement mode A. This parameter applies only to LTE FDD and LTE TDD.

Max Number of PDSCH Repetitions in Mode B

Indicates the maximum number of times the eNodeB repeatedly uses a PDSCH for a UE in coverage enhancement mode B. This parameter applies only to LTE FDD and LTE TDD.

Max Number of PUSCH Repetitions in Mode A

Indicates the maximum number of times the eNodeB repeatedly uses a PUSCH for a UE in coverage enhancement mode A. This parameter applies only to LTE FDD and LTE TDD.

Max Number of PUSCH Repetitions in Mode B

Indicates the maximum number of times the eNodeB repeatedly uses a PUSCH for a UE in coverage enhancement mode B. This parameter applies only to LTE FDD and LTE TDD.

Max Number of MPDCCH Repetitions for Paging

Indicates the maximum number of repetitions of the type-1 CSS MPDCCH for scheduling in the cell.. When LTE Flexible Bandwidth or GSM and LTE Spectrum Concurrency feature is activated in the cell, the eNodeB increases the number of repetitions based on the SIB1 interruption state. This parameter applies only to LTE FDD and LTE TDD.

Max Number of MPDCCH Repetitions in Mode A

Indicates the maximum number of times the eNodeB repeatedly uses the MTC physical downlink control channel (MPDCCH) for a UE in mode A. This parameter applies only to LTE FDD and LTE TDD.

Max Number of MPDCCH Repetitions in Mode B

Indicates the maximum number of times the eNodeB repeatedly uses the MTC physical downlink control channel (MPDCCH) for a UE in mode B. This parameter applies only to LTE FDD and LTE TDD.

Effective Code Rate for SI Transmission

Indicates the target code rate of system information transmission. If this parameter corresponding to the maximum coverage level supported by the cell is modified, eMTC UEs that already accessed the cell will be proactively released. This parameter applies only to LTE FDD and LTE TDD.

Paging Group Number

Indicates the number of paging occasions (a type of subframe) within a paging cycle, that is, the number of paging groups. According to 3GPP specifications, the value of nB must be a positive integer. Therefore, the result obtained by multiplying the DefaultPagingCycle parameter value by the PagingGroupNum parameter value must be greater than or equal to 1. Otherwise, the network cannot perform paging normally and UEs cannot receive paging messages. For details, see 3GPP TS 36.304.

This parameter applies only to LTE FDD and LTE TDD.
