Modify Cell Adaptive SRS Configuration (MOD CELLSRSADAPTIVECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to SRS adaptation.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SrsPeriodAdaptive SRS Period Adaptive Switch

Meaning: Indicates whether to enable SRS reporting period adaptation. If this parameter is set to ON(On), the SRS reporting period adaptively changes based on the SRS algorithm. If this parameter is set to OFF(Off), the SRS reporting period is specified by the UserSrsPeriod parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the SrsPeriodAdaptive parameter is set to ON, the eNodeB adaptively adjusts the SRS reporting period for UEs that will access the network after the parameter is set. The adjustment is based on the load of SRS resources and achieves a tradeoff between the number of UEs served and network performance. If this parameter is set to OFF, the eNodeB uses a fixed SRS reporting period for UEs that will access the network after the parameter is set.

Applicable Mode: L-FDD, L-TDD
UserSrsPeriod User SRS Period

Meaning: Indicates the fixed SRS reporting period. This parameter takes effect only when the SrsPeriodAdaptive parameter is set to OFF(Off). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: ms5(5ms), ms10(10ms), ms20(20ms), ms40(40ms), ms80(80ms), ms160(160ms), ms320(320ms)

Unit: ms

Actual Value Range: ms5, ms10, ms20, ms40, ms80, ms160, ms320

MML Default Value: None

Recommended Value: ms40(40ms)

Parameter Relationship:

-Others:

  • This parameter is valid only when the SrsPeriodAdaptive parameter is set to OFF(Off).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of this parameter applies to all UEs in the cell. Set this parameter to achieve a tradeoff between the number of UEs served and network performance. A shorter SRS reporting period results in a shorter interval of SRS measurements, better user experience, and a lower SRS capacity in the cell. A longer SRS period results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify parameters related to adaptive SRS for a cell as follows: Local cell ID: 0, SRS period adaptive switch: OFF, User SRS period config: 10ms, run the following command:
MOD CELLSRSADAPTIVECFG: LocalCellId=0, SrsPeriodAdaptive=OFF, UserSrsPeriod=ms10;
