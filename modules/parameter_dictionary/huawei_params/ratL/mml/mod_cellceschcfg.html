Modify Cell CE Scheduling Configuration (MOD CELLCESCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify coverage-level-specific cell scheduling configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CoverageLevel Coverage Level

Meaning: Indicates the cell coverage level, which corresponds to 0 dB, 5 dB, 10 dB, and 15 dB coverage enhancements.

When this parameter is set to COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, and COVERAGE_LEVEL_3, the maximum coverage level supported by the cell is coverage level 0, coverage level 1, coverage level 2, and coverage level 3, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: COVERAGE_LEVEL_0(COVERAGE_LEVEL_0), COVERAGE_LEVEL_1(COVERAGE_LEVEL_1), COVERAGE_LEVEL_2(COVERAGE_LEVEL_2), COVERAGE_LEVEL_3(COVERAGE_LEVEL_3)

Unit: None

Actual Value Range: COVERAGE_LEVEL_0, COVERAGE_LEVEL_1, COVERAGE_LEVEL_2, COVERAGE_LEVEL_3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the number of times the eNodeB repeatedly sends the SIB-BR message in a period in the current coverage enhancement mode of a cell. PagingGroupNum Paging Group Number

Meaning: Indicates the number of paging occasions (a type of subframe) within a paging cycle, that is, the number of paging groups. According to 3GPP specifications, the value of nB must be a positive integer. Therefore, the result obtained by multiplying the DefaultPagingCycle parameter value by the PagingGroupNum parameter value must be greater than or equal to 1. Otherwise, the network cannot perform paging normally and UEs cannot receive paging messages. For details, see 3GPP TS 36.304.

This parameter applies only to LTE FDD and LTE TDD.

Example

To modify the CellCeSchCfg Configuration with the parameters as follows: Local cell ID: 0, Coverage Level: COVERAGE_LEVEL_3, CE SIB1 Repetition Number: SIB1_NUM_R4, run the following command:
MOD CELLCESCHCFG: LocalCellId=0, CoverageLevel=COVERAGE_LEVEL_3, SIB1RepNum=SIB1_NUM_R4;
