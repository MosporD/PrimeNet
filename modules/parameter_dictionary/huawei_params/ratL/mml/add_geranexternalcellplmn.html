Add PLMN List for External GERAN Cell (ADD GERANEXTERNALCELLPLMN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an additional PLMN ID for an external GERAN cell.

Note

  • Before running this command, ensure that the associated external GERAN cell has been configured.

  • A maximum of three additional PLMN IDs can be added for each external GERAN cell.

Parameters

ID Name Description
GeranCellId GERAN cell ID

Meaning: Indicates the identity of the external GERAN cell. It uniquely identifies a GERAN cell within a PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Lac Location area code

Meaning: Indicates the LAC of the external GERAN cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65533,65535

Unit: None

Actual Value Range: 1~65533,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code of the external cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a GeranExternalCellPlmn MO, the combination of Mnc and Mcc must be different from that of ShareMnc and ShareMcc.
  • Mcc in a GeranExternalCellPlmn MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

The MCC consists of three digits.

Unit: None

MML Default Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Service Interrupted After Modification: N/A

Example

To add an additional PLMN ID for an external GERAN cell with the parameters as follows: GERAN cell ID: 15, Location area code: 12, Mobile country code: "460", Mobile network code: "20", Share mobile country code: "460", Share mobile network code: "01", run the following command:
ADD GERANEXTERNALCELLPLMN: GeranCellId=15, Lac=12, Mcc="460", Mnc="20", ShareMcc="460", ShareMnc="01";
