Display interference record (DSP INREC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query historical interference data. This command applies only to LTE TDD.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
eNodeBId Main eNodeB ID

Meaning: Indicates the main eNodeB ID.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Output Description

Field Description

Sector equipment ID

Indicates the ID of a piece of sector equipment that serves a cell. It uniquely identifies the sector equipment within an eNodeB.

UL Average Interference Power

Indicates the average uplink interference power when interference is generated. This parameter applies only to LTE TDD networks.

UpPTS Average Interference Power

Indicates the average uplink interference power on the UpPTS when interference is generated. This parameter applies only to LTE TDD networks.

First UL Frame First Symbol Power

Indicates the power of the first symbol in the first UL subframe when interference is generated. This parameter applies only to LTE TDD cells.

First UL Seventh (or Fifth) Symbol Power

Indicates the receive power of the seventh (or fifth when extended CP is used) symbol in the first UL subframe when interference is generated. This parameter applies only to LTE TDD cells.

Last UL Frame First Symbol Power

Indicates the power of the first symbol in the last UL subframe when interference is generated. This parameter applies only to LTE TDD cells.

Last UL Twelfth (or Tenth) Symbol Power

Indicates the receive power of the twelfth (or tenth when extended CP is used) symbol in the last UL subframe when interference is generated. This parameter applies only to LTE TDD cells.

Time

Indicates the time when interference is generated. This parameter applies only to LTE TDD networks.

Idle GP Interference Power(dBm)

Indicates the interference power in an idle GP. This parameter applies only to LTE TDD.

Inter-RRU Channel Calibration Interf Power(dBm)

Indicates the interference power in a GP during inter-RRU channel calibration. This parameter applies only to LTE TDD.

Intra-RRU Channel Calibration Interf Power(dBm)

Indicates the interference power in a GP during intra-RRU channel calibration. This parameter applies only to LTE TDD.
