Display Cell By Location (DSP CELLBYLOCATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query a cell by its location.

Note

None.

Parameters

ID Name Description
LocationName Location Name

Meaning: Indicates the location name.

GUI Value Range: 0~65 characters

Unit: None

Actual Value Range: 0~65

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query cells by the location which the locationname is "huawei":
DSP CELLBYLOCATION: LOCATIONNAME=huawei;
The result is shown as follows:
+++    0        2019-12-05 21:43:43
O&M    #806354970

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Cell ID

Indicates the ID of the E-UTRAN cell. The combination of this parameter and the eNodeB ID forms the E-UTRAN cell identity. The combination of the E-UTRAN cell identity and the PLMN identity forms the ECGI. For details, see 3GPP TS 36.413.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
