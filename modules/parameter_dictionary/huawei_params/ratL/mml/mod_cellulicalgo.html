Modify Uplink IC Algorithm (MOD CELLULICALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of the uplink interference cancellation (IC) algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlIcA3Offset UL IC A3 Offset

Meaning: Indicates the A3 offset for interference cancellation (IC) event A3, that is, the A3 offset of the neighboring cell's signal quality to the serving cell. A larger value indicates that a neighboring cell must have better signal quality for reporting the event. This parameter applies only to LTE FDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship:

-Others:

  • This parameter is valid only when uplink IC controlled by the UplinkIcSwitch parameter in the CellAlgoSwitch MO is enabled for the cell.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more interfering UEs that meet the IC conditions, more IC-beneficiary UEs, and higher average uplink throughput of IC-beneficiary UEs. A larger value of this parameter results in the opposite effects. If this parameter is set to a value greater than the offset of event A3 used in handovers, UEs may be handed over and cannot meet the conditions of interfering UEs in IC.

Applicable Mode: L-FDD
SrsIcSwitch SRS IC Switch

Meaning: Indicates whether to enable the SRS IC algorithm for a cell.

MASSIVE_MIMO_SRS_IC_SW: If this option is selected, the SRS IC algorithm for massive MIMO is enabled. If this option is deselected, the SRS IC algorithm for massive MIMO is disabled. This option applies only to LTE TDD.

GUI Value Range: MASSIVE_MIMO_SRS_IC_SW(MASSIVE_MIMO_SRS_IC_SW)

Unit: None

Actual Value Range: MASSIVE_MIMO_SRS_IC_SW

MML Default Value: None

Recommended Value: MASSIVE_MIMO_SRS_IC_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: MASSIVE_MIMO_SRS_IC_SW: If this option is selected, the SRS IC algorithm is enabled to improve beamforming performance of CEUs. If this option is deselected, the SRS IC is disabled, and network performance is not affected.

Applicable Mode: L-TDD

Example

To modify the configuration of cell-level uplink IC with the parameters as follows: Local Cell ID: 0, UL IC A3 Offset: -10, run the following command:
MOD CELLULICALGO: LocalCellId=0, UlIcA3Offset=-10;
