Remove Configuration of Cell RB Reserve (RMV CELLRBRESERVE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove cell RB reservation configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Removing RB reservation for a cell with the RbRsvMode parameter value being NB_RESERVED, NB_DEPLOYMENT, LNR_SPECTRUM_SHR_RB_RESERVED, or COVERAGE_ENH_RB_RESERVED will cause the cell to automatically restart.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
Index Index

Meaning: Indicates the index of a reserved RB configuration for the cell.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on equipment)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Remove Cell RB Reserve configuration, with LocalCellId=10, Index=1:


+++    0        2016-07-21 09:28:47
O&M    #806354970
%%RMV CELLRBRESERVE: LocalCellId=10, Index=1;%%
RETCODE = 0  Operation succeeded.
