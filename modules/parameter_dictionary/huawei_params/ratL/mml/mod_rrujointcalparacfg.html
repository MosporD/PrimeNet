Modify RRU-Combined TX Channel Calibration Configuration (MOD RRUJOINTCALPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify TX channel calibration configuration in a cell with combined RRUs.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TxChnCalSwitch Joint Channel Calibration Switch

Meaning: Indicates whether to enable joint TX channel calibration for a 4T4R or 4T8R cell served by a combined RRU. If this parameter is set to ON for a cell, initial channel calibration is started after the cell is activated and then channel calibration is performed periodically for the cell. If this parameter is set to OFF for a cell, channel calibration is disabled for the cell. If the setting of this parameter is changed from ON to OFF during normal operating of a cell, channel calibration is stopped. If the setting of this parameter is changed from OFF to ON during normal operating of a cell, initial channel calibration is started and then channel calibration is performed periodically for the cell. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On) for 4T4R and 4T8R cells

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to OFF, throughput of downlink 4x2 MIMO or 4x4 MIMO in closed-loop mode cannot reach the maximum due to delay difference between channels. If this parameter is set to ON, throughput of downlink 4x2 MIMO or 4x4 MIMO in closed-loop mode can increase by up to 30% or even higher; however, during each joint channel calibration attempt which lasts for about 2 minutes, uplink throughput and downlink throughput degrade periodically. In the case of CA, when joint channel calibration is performed in the PCell, uplink throughput and downlink throughput in the SCells degrade periodically.

Applicable Mode: L-FDD
TxChnCalTime Joint Channel Periodic Calibration Time

Meaning: Indicates the local time to perform periodic TX channel calibration in a cell with combined RRUs and four TX antennas. This parameter works together with the TxChnCalPeriod parameter to determine the time to perform periodic TX channel calibration. For details, see descriptions of the TxChnCalPeriod parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 03:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Because only two RX antennas are available during TX channel calibration (less than 1s), uplink throughput of cell edge users (CEUs) decreases during TX channel calibration. Setting this parameter to a busy time has a greater impact on uplink throughput of CEUs, and setting this parameter to an idle time has a smaller impact on uplink throughput of CEUs.

Applicable Mode: L-FDD, L-TDD
TxChnCalPeriod Joint Channel Calibration Period

Meaning: Indicates the interval at which periodic TX channel calibration is performed in a cell with combined RRUs and four TX antennas. This parameter works together with the TxChnCalTime parameter to determine the time to perform periodic TX channel calibration. The following examples clarify the criteria:

(1) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 48 (indicating that the TX channel calibration period is 24 hours), periodic TX channel calibration is performed at 03:00:00 every day.

(2) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 24 (indicating that the TX channel calibration period is 12 hours), periodic TX channel calibration is performed at 03:00:00 and 15:00:00 every day.

(3) If the TxChnCalTime parameter is set to 03:00:00 and the TxChnCalPeriod parameter is set to 96 (indicating that the TX channel calibration period is 48 hours), periodic TX channel calibration is performed at 03:00:00 every other day. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1440

Unit: 0.5h

Actual Value Range: 0.5~720

MML Default Value: None

Recommended Value: 48

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: Throughput of downlink 4x2 or 4x4 MIMO in closed-loop mode increases after TX channel calibration, but uplink throughput of cell edge users (CEUs) decreases during TX channel calibration because only two RX channels can be used during TX channel calibration. The TX channel calibration duration is less than 1s. A smaller value of this parameter leads to more frequent periodic TX channel calibration, higher throughput of downlink 4x2 or 4x4 MIMO in closed-loop mode after TX channel calibration, but lower uplink throughput of CEUs during TX channel calibration. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
AauPassivePortCalibPeriod Aau Passive Port Calibration Period

Meaning: Indicates whether to enable AAU passive port channel calibration in 3D beamforming, RPCU-based SDA antenna channel calibration, and channel calibration for SDL cells, and also indicates the period for periodic calibration when calibration is enabled. The calibration is enabled only when this parameter is set to a non-zero value. If this parameter is set to 65535, the eNodeB performs periodic calibration using a short period, which is longer than or equal to 1 minute and shorter than 5 minutes. If this parameter is set to a non-zero value other than 65535, the eNodeB performs periodic calibration using the period specified by the parameter value. This parameter applies only to LTE FDD. RPCU-based SDA antenna channel calibration cycle is not recommended for 65535.

GUI Value Range: 0~60,65535

Unit: 5min

Actual Value Range: 0~300,65535

MML Default Value: None

Recommended Value: 6 (indicating 30 minutes)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to 0, channel calibration does not take effect, preventing downlink throughput from reaching the optimal value. If this parameter is set to a value other than 0 and 65535, channel calibration takes effect, increasing downlink throughput. A smaller non-zero value of this parameter leads to more frequent channel calibration, a higher probability that downlink throughput reaches the optimal value after channel calibration, but a greater impact on network KPIs during the calibration period. A larger non-zero value of this parameter leads to the opposite effects. If this parameter is set to 65535 and the number of cells is greater than 3, the calibration delay of some cells will be longer than the configured period.

Applicable Mode: L-FDD

Example

1. To modify the joint channel calibration configuration in a cell with combined RRUs with the parameters as follows: LocalCellId: 0, TxChnCalSwitch: ON, TxChnCalTime: 03:00:00, TxChnCalPeriod: 48, run the following command:
MOD RRUJOINTCALPARACFG: LocalCellId=0, TxChnCalSwitch=ON, TxChnCalTime=03&00&00, TxChnCalPeriod=48;
2. To modify the joint channel calibration configuration in a cell with combined RRUs with the parameters as follows: LocalCellId: 0, TxChnCalSwitch: OFF, run the following command:
MOD RRUJOINTCALPARACFG: LocalCellId=0, TxChnCalSwitch=OFF;
