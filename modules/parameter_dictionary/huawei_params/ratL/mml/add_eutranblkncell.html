Add Neighboring Relation with EUTRANBLK Cell (ADD EUTRANBLKNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add one blacklisted neighbor relationship with an E-UTRAN cell.

Note

  • The maximum number of E-UTRAN blacklist neighbor relationships configured for each cell must not exceed 16.

  • If the E-UTRAN blacklist neighboring cells and serving cell are served by different eNodeBs, the corresponding E-UTRAN external cells must be configured in advance.

Mcc Mobile country code

Meaning: Indicates the MCC of a neighboring E-UTRAN cell.

A PLMN ID is composed of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

CtrlMode Control Mode

Meaning: Indicates the control mode of a blacklisted neighboring E-UTRAN cell, which determines the control policies of operators and the SON functions on this MO. If this parameter is set to MANUAL_MODE(Manual Mode), users can modify or delete this MO but the SON cannot automatically modify or delete this MO. If this parameter is set to AUTO_MODE(Auto Mode), both users and the SON can modify or delete this MO. If this MO is created by SON, this parameter is set to AUTO_MODE(Auto Mode). Example

To add Eutran black neighboring cell, add the cell id 3 to service cell id 0 as its Eutran black neighboring cell in the same eNodeB, run the following command:
ADD EUTRANBLKNCELL: LocalCellId=0, Mcc="460", Mnc="01", eNodeBId=400013, CellId=3;
