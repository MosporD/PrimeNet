Modify Cell Adaptive BFMIMO Configuration (MOD CELLBFMIMOPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of adaptive

selection between beamforming and MIMO. This command applies only

to LTE TDD networks.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BfMimoAdaptiveSwitch BfMIMO adaptive switch

Meaning: Indicates the type of adaptive selection between beamforming and MIMO for a multi-antenna eNodeB. The values are described as follows:

NO_ADAPTIVE: A fixed beamforming or MIMO transmission mode is used. That is, transmission mode switching is not supported.

TxD_BF_ADAPTIVE: The transmission mode changes adaptively between TM2 and TM7 or between TM2 and TM8, depending on the 3GPP release with which UEs comply.

MIMO_BF_ADAPTIVE: The transmission mode changes adaptively among TM2, TM3, and TM7, among TM2, TM3, and TM8, or among TM2, TM3, TM8, and TM9, depending on the 3GPP release with which UEs comply. The TM9Switch option must be selected if the TM9 mode is required. This parameter applies only to LTE TDD.

GUI Value Range: NO_ADAPTIVE(NO_ADAPTIVE), TxD_BF_ADAPTIVE(TxD_BF_ADAPTIVE), MIMO_BF_ADAPTIVE(MIMO_BF_ADAPTIVE)

Unit: None

Actual Value Range: NO_ADAPTIVE, TxD_BF_ADAPTIVE, MIMO_BF_ADAPTIVE

MML Default Value: None

Recommended Value: MIMO_BF_ADAPTIVE(MIMO_BF_ADAPTIVE)

Parameter Relationship:

-Others:

  • This parameter is valid only when the BfSwitch check box is selected in the BfAlgoSwitch parameter under the CellAlgoSwitch MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter is valid only when the BfSwitch option under the BfAlgoSwitch parameter is selected. The setting of this parameter determines the transmission modes that apply to UEs served by a multi-antenna eNodeB and therefore affects performance such as the throughput and coverage.

If this parameter is set to NO_ADAPTIVE, the transmission mode that applies to UEs in a cell is determined by the setting of the FixedBfMimoMode parameter. For details, see the description of impact on radio network performance of the FixedBfMimoMode parameter.

If this parameter is set to TxD_BF_ADAPTIVE, the transmission mode that applies to UEs in a cell can be TM2 or beamforming and the peak transmission rates of MIMO UEs are affected. This parameter can be set to TxD_BF_ADAPTIVE in scenarios without requiring TM3 transmission mode.

If this parameter is set to MIMO_BF_ADAPTIVE, the eNodeB adaptively uses beamforming or open-loop MIMO mode to transmit data in scenarios where the eNodeB is equipped with 4T or 8T antennas to serve UEs that move at different speeds and have different channel correlation and signal quality.

The best performance can be achieved only when the setting of this parameter matches the SINR and speed mobility of UEs. Otherwise, the performance such as the throughput and coverage is worse than that with the optimal transmission mode.

Applicable Mode: L-TDD
FixedBfMimoMode Fixed BfMIMO mode

Meaning: Indicates the fixed beamforming or MIMO transmission mode configured for a multi-antenna eNodeB. This parameter is valid only when the BfMimoAdaptiveSwitch parameter is set to NO_ADAPTIVE. This parameter applies only to LTE TDD. The values are described as follows:

TM2: Transmission mode 2 is always used for UEs.

TM3: Transmission mode 3 is always used for UEs.

TM7: Transmission mode 7 is always used for UEs.

TM8: Transmission mode 8 is always used for UEs.

TM4: Transmission mode 4 is always used for UEs.

TM9 w/o PMI: Transmission mode 9, which does not require PMI feedback, is always used for UEs.

TM9 w PMI: Transmission mode 9, which requires PMI feedback, is always used for UEs.

  • This parameter is valid only when the BfMimoAdaptiveSwitch parameter is set to NO_ADAPTIVE.
  • The setting of this parameter determines the transmission mode that applies to UEs served by a multi-antenna eNodeB. The transmission modes vary with the application scenarios:
  • 1. TM2 applies to UEs with low SINR and a high speed.
  • 2. TM3 applies to UEs with high SINR and a high speed.
  • 3. TM4 applies to UEs with high SINR and a low speed.

However, the UE transmits only a single data stream, and therefore the downlink throughput decreases.

Meaning: Indicates whether to accelerate the determination of transmission mode switching for UEs when adaptation between beamforming and MIMO is enabled. If this parameter is set to ON, the eNodeB reduces the time for determining transmission mode switching for UEs based on their signal quality.
