Remove Auxiliary eNodeB SFN Cell Binding Relationship (RMV CELLAUXENBBIND)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a single frequency network (SFN) cell binding relationship to an auxiliary eNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The cell may be reestablished after the execution of this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EnodebId Slave site eNodeB ID

Meaning: Indicates the ID of the auxiliary eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the mobile country code (MCC) of the operator that operates an auxiliary eNodeB. This parameter applies only to LTE FDD and LTE TDD. This parameter is valid only when the USU3910 is used.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of the Mcc parameter in the CellAuxEnbBind MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the mobile network code (MNC) of the operator that operates an auxiliary eNodeB. The value of this parameter is a string of two or three decimal digits. This parameter applies only to LTE FDD and LTE TDD. This parameter is valid only when the USU3910 is used.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of the Mnc parameter in the CellAuxEnbBind MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove cell binding relationship to an auxiliary eNodeB (Local cell ID: 0; Auxiliary eNodeB ID: 101; Mcc: "460"; Mnc: "10"), run the following command: 
RMV CELLAUXENBBIND: LocalCellId=0, EnodebId=101, Mcc="460", Mnc="10";
