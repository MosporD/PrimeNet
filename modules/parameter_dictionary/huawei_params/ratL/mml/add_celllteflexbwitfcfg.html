Add CellLteFlexBwItfCfg (ADD CELLLTEFLEXBWITFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add GSM interference ARFCN information for Flexible Bandwidth.

Note

  • LTE_FB_CFG_SWITCH of LteFlexBwSwitch in a CellLteFlexBw MO must be set on before you run this command. In addition, the to-be-added frequency of a high-interference GSM cell must be an intra-eNodeB co-coverage frequency with the LTE cell.

  • A maximum of six CellLteFlexBwItfCfg MO instances can be configured for a cell.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
HighItfGsmArfcn High Interference GSM ARFCN

Meaning: Indicates the ARFCN of a high-interference GSM cell adjacent to the LTE cell. This parameter applies only to LTE FDD.

GUI Value Range: 0~124,128~251,512~885,975~1023

Unit: None

Actual Value Range: 0~124,128~251,512~885,975~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 850MHz, the value range of the HighItfGsmArfcn parameter must be [128,251].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 900MHz, the value range of the HighItfGsmArfcn parameter must be [0,124] or [975,1023].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 1800MHz, the value range of the HighItfGsmArfcn parameter must be [512,885].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 1900MHz, the value range of the HighItfGsmArfcn parameter must be [512,810].

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
GsmCarrierFreq GSM Carrier Frequency

Meaning: Indicates the carrier bearing GSM signals of a cell adjacent to the LTE cell. This parameter applies only to LTE FDD.

GUI Value Range: 850MHz(850MHz), 900MHz(900MHz), 1800MHz(1800MHz), 1900MHz(1900MHz)

Unit: None

Actual Value Range: 850MHz, 900MHz, 1800MHz, 1900MHz

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 850MHz, the value range of the HighItfGsmArfcn parameter must be [128,251].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 900MHz, the value range of the HighItfGsmArfcn parameter must be [0,124] or [975,1023].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 1800MHz, the value range of the HighItfGsmArfcn parameter must be [512,885].
  • When the GsmCarrierFreq parameter in a CellLteFlexBwItfCfg MO is set to 1900MHz, the value range of the HighItfGsmArfcn parameter must be [512,810].

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To add the interference configuration of LTE Flexible Bandwidth with the parameters as follows: local cell ID: 0, High Interference GSM ARFCN: 512, GSM Carrier Frequency: 1800MHz, run the following command:
ADD CELLLTEFLEXBWITFCFG: LocalCellId=0, HighItfGsmArfcn=512, GsmCarrierFreq=1800MHz;
