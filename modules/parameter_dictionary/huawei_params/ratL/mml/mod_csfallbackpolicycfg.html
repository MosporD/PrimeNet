Modify CS FallBack Policy Configuration (MOD CSFALLBACKPOLICYCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the CSFB policy configuration.

Note

None.

Parameters

ID Name Description
CsfbHoPolicyCfg CSFB handover policy Configuration

Meaning: Indicates the CSFB policy for a UE in connected mode. If the CSFB steering function is disabled, this parameter also applies to UEs in idle mode. The policy can be PS handover, CCO, or redirection.

GUI Value Range: REDIRECTION, CCO_HO, PS_HO

Unit: None

Actual Value Range: REDIRECTION, CCO_HO, PS_HO

MML Default Value: None

Recommended Value: REDIRECTION:On, CCO_HO:On, PS_HO:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
IdleModeCsfbHoPolicyCfg CSFB handover policy Configuration for idle ue

Meaning: Indicates the CSFB policy for a UE in idle mode. The policy can be PS handover, CCO, or redirection. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: REDIRECTION, CCO_HO, PS_HO

Unit: None

Actual Value Range: REDIRECTION, CCO_HO, PS_HO

MML Default Value: None

Recommended Value: REDIRECTION:On, CCO_HO:On, PS_HO:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CsfbUserArpCfgSwitch Csfb User Arp Configuration Switch

Meaning: Indicates whether to allow the eNodeB to change the ARPs for CSFB UEs. If this parameter is set to ON, the ARPs for CSFB UEs in common calls are specified by the NormalCsfbUserArp parameter in the CsFallbackPolicyCfg MO, and the ARPs for CSFB UEs in emergency calls are always 1. If this parameter is set to OFF, admission of CSFB UEs is performed based on the ARPs delivered from the EPC. For details about ARP, see 3GPP TS 23.401. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to OFF, admission of CSFB UEs is performed based on the ARPs delivered from the EPC and network performance is not affected. If this parameter is set to ON, ARPs for CSFB UEs configured on the eNodeB take effect, preemption is performed based on the configured ARPs during admission, and a higher ARP priority leads to a higher admission success rate.

Applicable Mode: L-FDD, L-TDD
NormalCsfbUserArp Normal Csfb User Arp

Meaning: Indicates the allocation/retention priority (ARP) of a CSFB service triggered by a common call. When this parameter is set to 1, the service priority is the same as that of an emergency call. For details about the ARP, see 3GPP TS 23.401. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~15

Unit: None

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher ARP for CSFB users with common calls and therefore a higher admission success rate for these users. This, however, may lead to call drops of other low-priority users. A greater value leads to the opposite affects and has fewer affects on other low-priority users.

Applicable Mode: L-FDD, L-TDD

Example

To modify the CSFB policy configuration with the parameters as follows: CSFB handover policy Configuration: REDIRECTION and PS_HO, CSFB handover policy Configuration for idle ue: REDIRECTION, run the following command:
MOD CSFALLBACKPOLICYCFG: CsfbHoPolicyCfg=REDIRECTION-1&CCO_HO-0&PS_HO-1, IdleModeCsfbHoPolicyCfg=REDIRECTION-1&CCO_HO-0&PS_HO-0;
