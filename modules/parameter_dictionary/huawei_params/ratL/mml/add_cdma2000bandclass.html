Add Neighboring CDMA2000 Band Class Information (ADD CDMA2000BANDCLASS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the information about a CDMA2000 band class.

Note

A maximum of 16 CDMA2000 band classes can be configured for an E-UTRAN cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandClass Band class

Meaning: Indicates the neighboring CDMA2000 band class. Signals on a frequency within the band class can be obtained by UEs. For details, see the BandclassCDMA2000 IE defined in 3GPP 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: bc0(bc0), bc1(bc1), bc2(bc2), bc3(bc3), bc4(bc4), bc5(bc5), bc6(bc6), bc7(bc7), bc8(bc8), bc9(bc9), bc10(bc10), bc11(bc11), bc12(bc12), bc13(bc13), bc14(bc14), bc15(bc15), bc16(bc16), bc17(bc17), bc18(bc18), bc19(bc19), bc20(bc20), bc21(bc21)

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Cdma20001XrttCellReselInd CDMA20001XRTT cell reselection indicator

Meaning: Indicates whether to configure cell reselection priorities for a CDMA2000 1xRTT band class. If this parameter is set to NOT_CFG, the cell reselection priorities are not delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Cdma20001XrttCellReselPri CDMA20001XRTT cell reselection priority

Meaning: Indicates the absolute priority of the CDMA2000 1xRTT band class to be used during cell reselection. The value 0 indicates the lowest priority. Frequencies used for different RATs must be assigned different cell reselection priorities. The information is contained in SIB8. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

GUI Value Range: 0~7

Actual Value Range: 0~7

Recommended Value: 2

Parameter Relationship:

-Others:

  • If Cdma20001XrttCellReselInd is set to NOT_CFG, Cdma20001XrttCellReselPri does not need to be set.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a higher probability of a UE camping on the cell in the band class, and a smaller value indicates a lower probability.

Applicable Mode: L-FDD, L-TDD
Cdma20001XrttThreshXHigh CDMA20001XRTT high priority threshold

Meaning: Indicates the RX signal level required for a cell on a frequency in the higher-priority CDMA2000 1xRTT band class to become a candidate for cell reselection.

After measurements are started for cells on a frequency in the band class, a cell on the frequency can become a candidate for reselection only if the RX signal level of the cell is higher than the value specified by this parameter for a time-to-trigger. For details, see section 5.2.4.5 in 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Cdma2000HrpdThreshXHigh CDMA2000HRPD high priority threshold

Meaning: Indicates the minimum RX level required for a cell on a target frequency in the CDMA2000 HRPD band class to become a candidate for cell reselection if the cell reselection priority of the target frequency is higher than that of the serving frequency.

After measurements are started for cells on a target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter for a period of time. For details, see section 5.2.4.5 in 3GPP TS 36.304. This parameter applies only to LTE FDD and LTE TDD.

Example

Example 1: To add a CDMA2000 band class with the parameters as follows: Local cell ID: 0, Band class: bc0, CDMA20001XRTT cell reselection indicator: CFG, CDMA20001XRTT cell reselection priority: 1, CDMA20001XRTT high priority threshold: -34, CDMA20001XRTT lower priority threshold: -34, CDMA2000HRPD cell reselection indicator: CFG, CDMA2000HRPD cell reselection priority: 1, CDMA2000HRPD high priority threshold: -26, CDMA2000HRPD lower priority threshold: -26, run the following command:
ADD CDMA2000BANDCLASS: LocalCellId=0, BandClass=bc0, Cdma20001XrttCellReselInd=CFG, Cdma20001XrttCellReselPri=1, Cdma20001XrttThreshXHigh=-34, Cdma20001XrttThreshXLow=-34, Cdma2000HrpdCellReselInd=CFG, Cdma2000HrpdCellReselPri=1, Cdma2000HrpdThreshXHigh=-26, Cdma2000HrpdThreshXLow=-26;
Example 2: To add a CDMA2000 band class with the parameters as follows: Local cell ID: 0, Band class: bc1, CDMA20001XRTT cell reselection indicator: NOT_CFG, CDMA20001XRTT high priority threshold: -34, CDMA20001XRTT lower priority threshold: -34, CDMA2000HRPD cell reselection indicator: NOT_CFG, CDMA2000HRPD high priority threshold: -26, CDMA2000HRPD lower priority threshold: -26, run the following command:
ADD CDMA2000BANDCLASS: LocalCellId=0, BandClass=bc1, Cdma20001XrttCellReselInd=NOT_CFG, Cdma20001XrttThreshXHigh=-34, Cdma20001XrttThreshXLow=-34, Cdma2000HrpdCellReselInd=NOT_CFG, Cdma2000HrpdThreshXHigh=-26, Cdma2000HrpdThreshXLow=-26;
