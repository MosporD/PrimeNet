List LAA Cell Coexist Parameters (LST CELLLAACOEXISTPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the LAA Coexist parameters about a LAA cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

To list the cell Coexist parameters:
LST CELLLAACOEXISTPARA:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

This parameter has been added to specify the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

Coexist Mode

Indicates the coexistence mode of an LAA cell. The value ALWAYS_ON indicates that the LAA cell is always enabled and does not share channels with other equipment. The values LBT_TYPEA and LBT_TYPEB indicate two LBT types for coordination between LAA SCells when these cells are served by one RRU. For details, see "Channel access procedures for LAA" in 3GPP 36.213. The value LBT_TYPEA applies only to non-RF combination scenarios or scenarios where the LsbSwitch parameter is set to OFF. This parameter applies only to LTE TDD.

Since the LTE-U function has been removed, the values STATIC_DUTY and DYNAMIC_DUTY are invalid. Although the configuration interface in this version supports synchronization and delivery of these values, the system does not use these values. Therefore, avoid using the value STATIC_DUTY or DYNAMIC_DUTY.

High Interference Duty Threshold(%)

Indicates the threshold of the severe interference duty ratio in an LAA cell. If the interference duty ratio in an LAA cell exceeds this threshold, the duration of continuous interference to this cell is longer than the value specified by the HighInterfDurationThd parameter in the CellLaaCoexistPara MO, and the FcsMode parameter in the CellAlgoSwitch MO is set to AUTO(AUTO), FCS is automatically triggered once, updating the operating frequency of the LAA cell. This parameter applies only to LTE TDD.

High Interference Duration Threshold(s)

Indicates the threshold of the duration in which severe continuous interference occurs to an LAA cell. If the interference duty ratio in an LAA cell exceeds the value of the HighInterfDutyThd parameter in the CellLaaCoexistPara MO, the duration of continuous interference to this cell exceeds this threshold, and the FcsMode parameter in the CellAlgoSwitch MO is set to AUTO(AUTO), FCS is automatically triggered once, updating the operating frequency of the LAA cell. This parameter applies only to LTE TDD.

LBT Priority

Indicates the channel access priority class for using the listen before talk (LBT) coexistence technology.

An RRU uses different LBT parameters to implement channel clear access (CCA) based on channel access priority classes. Channel access priority classes 1 to 4 are defined in section 15.1.1 of 3GPP TS 36.213, and channel access priority classes 15 and 16 are extended proprietary classes. This parameter applies only to LTE TDD.

CCA Threshold Offset(dB)

Indicates the offset against the energy detection threshold set for an LAA cell. The listen before talk (LBT) energy detection threshold is the sum of the value of this parameter and the value of the FcsInterfThd parameter in the CellLaaFcsPara MO. For details about the energy detection threshold, see section 15.1.4 of 3GPP TS 36.213. This parameter applies only to LTE TDD.

LSB Switch

Indicates whether to implement the LBT synchronization boundary (LSB) algorithm by using RHUB-based coordination between MPMUs involved in RF combination of an LAA cell. If this parameter is set to ON, the RHUB is used to implement the LSB algorithm to synchronize channel occupation between the MPMUs involved in RF combination. If this parameter is set to OFF, the LBT procedure is independently implemented for each MPMU involved in RF combination and the RHUB is not required for coordination. If RRUs are used, this parameter is invalid. This parameter applies only to LTE TDD.

TPC Power Adjustment CQI Threshold

Indicates the CQI threshold for triggering TPC for the LAA cell in the specified frequency range. This parameter applies only to LTE TDD.
