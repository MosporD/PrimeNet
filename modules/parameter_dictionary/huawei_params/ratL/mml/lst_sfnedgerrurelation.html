List SFN Edge RRU Relation (LST SFNEDGERRURELATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters related to relationship between RRUs in edges of neighboring SFN cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of an edge physical cell's sector equipment used by an SFN cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To list the SFN edge RRU relation information with the local cell ID of 1, run the following command:
LST SFNEDGERRURELATION: LocalCellId=1;

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment used by an SFN cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to LTE FDD.

Mobile Country Code

Indicates the MCC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD.

Mobile Network Code

Indicates the MNC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD.

eNodeB ID

Indicates the eNodeB ID of a neighboring SFN cell. This parameter applies only to LTE FDD.

Neighbor Cell ID

Indicates the ID of a neighboring SFN cell. This parameter applies only to LTE FDD.

Neighbor Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment of a neighboring SFN cell. This parameter applies only to LTE FDD.
