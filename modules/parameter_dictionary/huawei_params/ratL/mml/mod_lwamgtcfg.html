Modify LWA Management Configuration (MOD LWAMGTCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to LWA carrier management.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LteWlanAggrW1ThdRssi LWA W1 Threshold

Meaning: Indicates the threshold for LWA measurement events W1 and W2. When the RSSI value of a WLAN AP measured by a UE is greater than this threshold, an event W1 measurement report is triggered. This parameter can also be taken as the threshold 2 for event W2. This parameter applies only to LTE FDD.

GUI Value Range: -100~39

Unit: dBm

Actual Value Range: -100~39

MML Default Value: None

Recommended Value: -70

Parameter Relationship:

-Configuration constraints:

  • LteWlanAggrW3ThdRssi in the LwaMgtCfg MO must be less than LteWlanAggrW1ThdRssi in the same MO.
  • In an LwaMgtCfg MO, the value of LteWlanAggrW1ThdRssi must be greater than or equal to the value of LteWlanAggrW2Thd1Rssi.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering event W1 and configuring an LWA offloading carrier, affecting experience of LWA UEs. A smaller value of this parameter results in a higher probability of triggering event W1 and a higher probability of incorrect decision and ping-pong configuration of LWA offloading carriers.

A larger value of this parameter results in a lower probability of triggering event W2 and changing the LWA offloading carrier, affecting experience of LWA UEs. A smaller value of this parameter results in a higher probability of triggering event W2 and a higher probability of incorrect decision and ping-pong configuration of LWA offloading carriers.

Applicable Mode: L-FDD
LteWlanAggrW2Thd1Rssi LWA W2 Threshold 1

Meaning: Indicates the threshold 1 for LWA measurement event W2. When the RSSI values of all WLAN APs in the mobility set of a UE are less than the threshold 1 of event W2 and the RSSI values of WLAN APs that are not in the mobility set are greater than threshold 2 of event W2, an event W2 measurement report is sent. This parameter applies only to LTE FDD.

GUI Value Range: -100~39

Unit: dBm

Actual Value Range: -100~39

MML Default Value: None

Recommended Value: -80

Parameter Relationship:

-Configuration constraints:

  • In an LwaMgtCfg MO, the value of LteWlanAggrW1ThdRssi must be greater than or equal to the value of LteWlanAggrW2Thd1Rssi.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering event W2 and changing the LWA offloading carrier, affecting experience of LWA UEs. A larger value of this parameter results in a higher probability of triggering event W2 and a higher probability of incorrect decision and ping-pong configuration of LWA offloading carriers.

Applicable Mode: L-FDD
LteWlanAggrW3ThdRssi LWA W3 Threshold

Meaning: Indicates the triggering threshold for LWA measurement event W3. When the RSSI values of all WLAN APs in a mobility set measured by a UE are less than the threshold, an event W3 measurement report is sent. This parameter applies only to LTE FDD.

GUI Value Range: -100~39

Unit: dBm

Actual Value Range: -100~39

MML Default Value: None

Recommended Value: -80

Parameter Relationship:

-Configuration constraints:

  • LteWlanAggrW3ThdRssi in the LwaMgtCfg MO must be less than LteWlanAggrW1ThdRssi in the same MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering event W3 and a higher probability that a serving LWA offloading carrier cannot be promptly removed, affecting offloading performance. A larger value of this parameter results in a higher probability of triggering event W3, a higher probability that the serving LWA offloading carrier can be removed, and a higher probability that the serving LWA offloading carrier is mistakenly removed.

Applicable Mode: L-FDD
LwaW1TimeToTrigger LWA W1 Time To Trigger

Meaning: Indicates the time-to-trigger for LWA event W1. This parameter applies only to LTE FDD.

GUI Value Range: 0ms(0), 40ms(40), 64ms(64), 80ms(80), 100ms(100), 128ms(128), 160ms(160), 256ms(256), 320ms(320), 480ms(480), 512ms(512), 640ms(640), 1024ms(1024), 1280ms(1280), 2560ms(2560), 5120ms(5120)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of reporting LWA event W1. A larger value of this parameter results in the opposite effect. If this parameter is set to a small value, there is a high probability of triggering event W1 too early, and therefore the LWA offloading carrier is mistakenly configured, affecting user experience. If this parameter is set to a large value, there is a high probability that event W1 cannot be triggered, and therefore the LWA offloading carrier cannot not be configured.

Applicable Mode: L-FDD
LwaW2TimeToTrigger LWA W2 Time To Trigger

Meaning: Indicates the time-to-trigger for LWA event W2. This parameter applies only to LTE FDD.

GUI Value Range: 0ms(0), 40ms(40), 64ms(64), 80ms(80), 100ms(100), 128ms(128), 160ms(160), 256ms(256), 320ms(320), 480ms(480), 512ms(512), 640ms(640), 1024ms(1024), 1280ms(1280), 2560ms(2560), 5120ms(5120)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of reporting LWA event W2. A larger value of this parameter results in the opposite effect. If this parameter is set to a small value, there is a high probability of premature event A2 triggering, and therefore the LWA offloading carrier is mistakenly configured, affecting user experience. If this parameter is set to a large value, there is a high probability that event W2 cannot be triggered, and therefore the LWA offloading carrier cannot not be changed.

Applicable Mode: L-FDD
LwaW3TimeToTrigger LWA W3 Time To Trigger

Meaning: Indicates the time-to-trigger for LWA event W3. This parameter applies only to LTE FDD.

GUI Value Range: 0ms(0), 40ms(40), 64ms(64), 80ms(80), 100ms(100), 128ms(128), 160ms(160), 256ms(256), 320ms(320), 480ms(480), 512ms(512), 640ms(640), 1024ms(1024), 1280ms(1280), 2560ms(2560), 5120ms(5120)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of reporting LWA event W3. A larger value of this parameter results in the opposite effect. If this parameter is set to a small value, there is a high probability of triggering event W3 too early, and therefore the LWA offloading carrier is mistakenly removed. If this parameter is set to a large value, there is a high probability of triggering event W3 too late, and therefore the LWA offloading carrier is not promptly removed, affecting user experience.

Applicable Mode: L-FDD
WlanMeasHyst WLAN Measurement Hysteresis

Meaning: Indicates the hysteresis for LWA measurement events. This parameter decreases the number of LWA measurement event triggering times due to radio signal fluctuations and reduces the probability of LWA offloading configuration decision errors and ping-pong configurations. A larger value of this parameter results in a lower probability. This parameter applies to W1, W2, and W3 measurements. This parameter applies only to LTE FDD.

GUI Value Range: 0~30

Unit: 0.5db

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter makes it more difficult to trigger event W1, W2, or W3, which delays related WLAN measurement event triggering. A smaller value of this parameter makes it easier to trigger event W1, W2, or W3, which increases the probability of WLAN offloading configuration decision errors and ping-pong configurations.

Applicable Mode: L-FDD
CellLwaAlgoSwitch Cell LWA Algorithm Switch

Meaning: Indicates whether to enable cell-level LTE WLAN Aggregation (LWA). This parameter provides the following option:

LWA_DL_3C_SWITCH: Indicates whether to enable downlink 3C offloading in LWA. This function is enabled only if this option is selected. This option applies only to LTE FDD.

GUI Value Range: LWA_DL_3C_SWITCH(LWA DL 3C Switch)

Unit: None

Actual Value Range: LWA_DL_3C_SWITCH

MML Default Value: None

Recommended Value: LWA_DL_3C_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: LWA_DL_3C_SWITCH: UEs that support LWA 3C offloading can reach a higher peak data rate only if this option is selected.

Applicable Mode: L-FDD

Example

To modify LTE WLAN Aggregation Management Configuration as follows: Local cell ID: 2, Coverage-Based WLAN RSSI Threshold: -60, run the following command:
MOD LWAMGTCFG: LocalCellId=2, LteWlanAggrW1ThdRssi=-60;
