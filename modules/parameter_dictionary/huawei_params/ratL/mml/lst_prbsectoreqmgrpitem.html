List PRB Sector Equipment Group Item (LST PRBSECTOREQMGRPITEM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the sector equipment group item configuration of a PRB.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of the sector equipment that serves the PRB. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB ID. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

MML Default Value: None

Recommended Value: None

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.

Sector Equipment ID

Indicates the ID of the sector equipment that serves the PRB. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to NB-IoT.

PRB ID

Indicates the NB-IoT PRB ID. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

Sector Equipment Group ID

Indicates the ID of the sector equipment group that serves the PRB. It uniquely identifies a sector equipment group within an eNodeB. This parameter applies only to NB-IoT.
