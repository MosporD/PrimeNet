Display RRN Uplink Data Test (DSP EURRNULDATATST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information about the uplink data test of the RRN.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

+++    ycj_3.5        2017-12-20 20:26:25
O&M    #806354984
%%DSP EURRNULDATATST: LocalSubscriberId=65535;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

E-RAB ID

Indicates the ID of the E-RAB that carries the data test. This parameter applies only to LTE FDD and LTE TDD.

Source IP Address

Indicates the source IP address of the data test packets. This parameter applies only to LTE FDD and LTE TDD.

Source Port Number

Indicates the number of the source port of the data test packets. This parameter applies only to LTE FDD and LTE TDD.

Destination IP Address

Indicates the destination IP address of the data test packets. This parameter applies only to LTE FDD and LTE TDD.

Destination Port Number

Indicates the number of the destination port of the data test packets. This parameter applies only to LTE FDD and LTE TDD.

Packet Size(byte)

Indicates the packet size in a data test. This parameter applies only to LTE FDD and LTE TDD.

Rate(kbit/s)

Indicates the rate of the data test. The rate cannot exceed the maximum data rate supported by the BBP where the cell serving the RRN is set up. The recommended packet size is 1400 bytes or more in peak rate tests. This parameter applies only to LTE FDD and LTE TDD.

Test Time(s)

Indicates the total duration of the data test.

Test Time Left(s)

Indicate the remaining time for testing the uplink peak rate.
