Modify eNodeB Algorithm Switch Settings (MOD ENODEBALGOSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of eNodeB-level algorithm switches.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The ANR function is controlled by both the AnrSwitch parameter in the ENodeBAlgoSwitch MO and the AnrFunctionSwitch parameter in the CellAlgoSwitch MO. A specific ANR function is enabled in a cell only if the options corresponding to the specific ANR function are selected under both the AnrSwitch and AnrFunctionSwitch parameters. An ANR function is disabled in a cell if any option corresponding to the ANR function is deselected under the AnrSwitch or AnrFunctionSwitch parameter and is disabled on the entire eNodeB if the option corresponding to the ANR function is deselected under the AnrSwitch parameter.

  • If the Ue CsiRsCfigCtrlSwitch option is selected, service drops can occur for UEs that are incompatible with the function controlled by this option. Before selecting this option, check that all UEs on the network are compatible with the function controlled by this option.

  • The ENodeBAlgoSwitch MO consists of the switches related to eNodeB-level algorithms, which are applicable to all the cells and admitted UEs of the eNodeB.

  • If BBPs in a baseband collaboration group work as primary and secondary BBPs, disabling baseband collaboration may cause service drops at the UEs transferred from the primary BBPs to the secondary BBP for load sharing.

  • Running this command will reset a cell served by a single-mode RRU that connects to the BBU over the IR interface and works on band F or band A or a cell that is not configured with a cell-specific frame offset.

  • Turn on RimOnEcoSwitch when all the following conditions are met: (1) all NEs in the co-coverage GERAN, UTRAN, and E-UTRAN networks are provided by Huawei so that the networks comprise a Huawei SingleRAN network; (2) an eCoordinator is deployed and all NEs in the network are connected to the eCoordinator; (3) the RAN information management (RIM) procedure is disabled or not supported in all the core networks connected to the GERAN, UTRAN, and E-UTRAN networks.

    If the RIM procedure needs to be performed by the eCoordinator, turn on RimOnEcoSwitch on all Huawei NEs in GERAN, UTRAN, and E-UTRAN networks. In this case, these NEs do not send RIM messages to the core networks or respond to RIM messages sent from the core networks.

  • If the cell bandwidth is 1.4 MHz or 3 MHz, downlink inter-cell interference coordination (ICIC) and uplink ICIC are not supported.

  • When the eNodeB is in service, all cells under the eNodeB are automatically reset if the setting of OtdoaSwitch under LcsSwitch is changed.

  • If the parameter AntCalibrationTimeSwitch is modified, it will reset a cell served by a TDL(LTE_TDD) RRU that connects to the BBU over the IR interface and works on band F or band A and a cell that is configured with subframe patterns of SA2+SSP6 or SA2+SSP7.

MML Default Value: None

Parameter Relationship:

-Others:

  • Cells with customized bandwidths support only static ICIC. The DlIcicDynamicSwitch_ON_ENUM and DlIcicReuse3Switch_ON_ENUM values do not take effect for these cells.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to DlIcicDynamicSwitch_ON_ENUM or DlIcicStaticSwitch_ON_ENUM, the DL ICIC feature is enabled. Cell edge users (CEUs) will transmit signals using high transmit power in edge frequency bands, and cell center users (CCUs) will transmit signals using low transmit power in center frequency band. In this situation, the average cell throughput decreases, and downlink throughput of CEUs increases.

When this parameter is set to DlIcicSwitch_OFF_ENUM, the DL ICIC feature is disabled, and the throughput of CEUs will not increase.

AnrSwitch ANR algorithm switch

Meaning: Indicates whether to enable automatic neighbor relation (ANR). This parameter provides the following options:

IntraRatEventAnrSwitch: If this option is selected, intra-RAT event-triggered ANR is enabled. This type of ANR sets up and optimizes intra-RAT neighbor relationships based on intra-RAT handover events. This option applies only to LTE FDD and LTE TDD.

IntraRatFastAnrSwitch: If this option is selected, intra-RAT fast ANR is enabled. This type of ANR sets up and optimizes intra-RAT neighbor relationships based on periodic intra-RAT measurement. This option applies only to LTE FDD and LTE TDD.

IntraRatAnrAutoDelSwitch: If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can automatically remove intra-RAT neighbor relationships with cells for which NoRmvFlag is set to PERMIT_RMV_ENUM. If the IntraRatAnrAutoDelSwitch option is deselected, the eNodeB cannot automatically remove intra-RAT neighbor relationships. This option applies only to LTE FDD and LTE TDD.

UtranEventAnrSwitch: If this option is selected, event-triggered ANR with UTRAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with UTRAN cells based on events for coverage-based handovers to UTRAN. This option applies only to LTE FDD and LTE TDD.

GeranEventAnrSwitch: If this option is selected, event-triggered ANR with GERAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with GERAN cells based on events for coverage-based handovers to GERAN. This option applies only to LTE FDD and LTE TDD.

UtranFastAnrSwitch: If this option is selected, fast ANR with UTRAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with UTRAN cells based on periodic UTRAN measurement. UEs measure only neighboring cells contained in measurement configurations, in which the eNodeB does not include external UTRAN cells. To enable external UTRAN cells added by fast ANR as neighboring cells to be measured for handovers, you are advised to also select the UtranEventAnrSwitch option. This option applies only to LTE FDD and LTE TDD.

GeranFastAnrSwitch: If this option is selected, fast ANR with GERAN is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with GERAN cells based on periodic GERAN measurement. This option applies only to LTE FDD and LTE TDD.

UtranAutoNrtDeleteSwitch: If both this option and the UtranEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with UTRAN cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with UTRAN cells. This option applies only to LTE FDD and LTE TDD.

GeranAutoNrtDeleteSwitch: If both this option and the GeranEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with GERAN cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with GERAN cells. This option applies only to LTE FDD and LTE TDD.

CdmaAutoNrtDeleteSwitch: If both this option and the CdmaEventAnrSwitch option are selected, the eNodeB can automatically remove inter-RAT neighbor relationships with CDMA2000 cells for which the NoRmvFlag parameter is set to PERMIT_RMV_ENUM. If this option is deselected, the eNodeB cannot automatically remove neighbor relationships with CDMA2000 cells. This option applies only to LTE FDD and LTE TDD.

CdmaEventAnrSwitch: If this option is selected, event-triggered ANR with CDMA is enabled. This type of ANR sets up and optimizes inter-RAT neighbor relationships with CDMA2000 cells based on events for handovers to CDMA2000 cells. This option applies only to LTE FDD and LTE TDD.

MlbBasedEventAnrSwitch: Indicates whether to enable MLB-based event-triggered ANR. If both this option and the IntraRatEventAnrSwitch option are selected, the eNodeB can automatically set up and optimize inter-frequency neighbor relationships based on inter-frequency MLB measurement. If both this option and the option for event-triggered inter-RAT ANR (UtranEventAnrSwitch or GeranEventAnrSwitch) are selected, the eNodeB can automatically set up and optimize neighbor relationships with cells of that RAT based on measurement for MLB to that RAT.
