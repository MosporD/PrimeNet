Display Cell Information (DSP CELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the dynamic information about a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the dynamic information of a cell:
DSP CELL: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Cell Name

Indicates the name of the cell.

Cell instance state

Indicates the state of the cell instance.

In the case of access barring, the state can be CELL_INST_BARRED(Barred), CELL_INST_EMTC_BARRED(eMTC Barred), or CELL_INST_LTE_EMTC_BARRED(LTE and eMTC Barred). If NB-IoT or LTE UEs are barred from accessing the cell, CELL_INST_BARRED(Barred) is displayed as the state of the cell instance. If eMTC UEs are barred from accessing the cell, CELL_INST_EMTC_BARRED(eMTC Barred) is displayed as the state of the cell instance. If both LTE and eMTC UEs are barred from accessing the cell, CELL_INST_LTE_EMTC_BARRED(LTE and eMTC Barred) is displayed as the state of the cell instance.

Reason for latest state change

Indicates the reason for the latest state change of the cell, which can be a cell activation success or a cell setup failure.

Cell latest setup time

Indicates the latest setup time of the cell.

Cell latest setup operate type

Indicates the latest setup type of the cell.

Cell latest remove time

Indicates the latest removal time of the cell.

Cell latest remove operate type

Indicates the latest removal type of the cell.

Cell power save state

Indicates the energy saving status of the cell.

Symbol shutdown state

Indicates whether the cell is in the symbol power saving state.

Anti Interfere Status in High Speed Scenario

Indicates the status of interference coordination in high-speed railway scenarios. The value of this parameter can be InterfHighSpeedStatus_NO_OP~0(Disable), InterfHighSpeedStatus_ACT~1(Run), or InterfHighSpeedStatus_RENEW~2(Restore).

When interference coordination in high-speed railway scenarios is disabled for a cell, the value of this parameter is InterfHighSpeedStatus_NO_OP~0(Disable) in the command output. When this function is being performed in the cell, the value of this parameter is InterfHighSpeedStatus_ACT~1(Run). When resources are restored to normal status, the value of this parameter is InterfHighSpeedStatus_RENEW~2(Restore). This parameter applies only to LTE FDD and LTE TDD.

Primary BBP information

Indicates the cabinet number, subrack number, and slot number of the primary BBP that serves the cell.

Cell topology type

Indicates the topology of the cell.

Maximum transmit power(0.1dBm)

Indicates the theoretical maximum transmit power of a single antenna channel of the cell. The value 65535 indicates that this parameter is invalid, and the maximum transmit power can be adjusted by modifying the PDSCH configuration or the PA-related parameters for PDSCH power control. The maximum transmit power of LTE and NB-IoT physical cells in the extension information is the same as that in the basic information. The maximum transmit power of LampSite and 32T32R cells is not calculated, and the invalid value 65535 is used for these cells. The maximum transmit power of auxiliary eNodeBs for SFN cells may be different from that in the basic information. For FDD 8T8R cells, this parameter indicates the cell max power of each logical ant.

eNodeB ID

Indicates the ID of the eNodeB.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

TX Channel No.

Indicates information about the TX channel of a cell.

RX Channel No.

Indicates information about the RX channel of a cell.

Served BBP Information

Indicates the cabinet, subrack, and slot of the baseband processing unit on which the cell is set up is located.

Work Status

Indicates the work status of the RF module and BBP that serves the cell.

MPT information

Indicates the location information of the MPT used by a cell. The value of this parameter is expressed as cabinet number - subrack number - slot number. The value "-" (hyphen) indicates an invalid value.

Anchor Carrier Flag

Indicates whether the PRB is an anchor carrier. This parameter applies only to NB-IoT.

PRB ID

Indicates the NB-IoT PRB identity. It uniquely identifies a PRB within a cell. This parameter applies only to NB-IoT.

Cell Tx Power Offset(0.1dBm)

Indicates the offset to the maximum transmit power of a single antenna channel of the cell. This parameter is related to the power allocation algorithm for each control channel and traffic channel of the eNodeB. The value 65535 indicates that this parameter is invalid. When the actually used power is less than or equal to the configured power, the value 65535 is used. If the cell is a LampSite cell, the value 65535 is used.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
