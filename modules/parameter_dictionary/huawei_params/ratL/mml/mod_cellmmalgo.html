Modify Massive MIMO Algorithm (MOD CELLMMALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters for the Massive MIMO algorithm.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
BeamGainLimitSwitch Beam Gain Limit Switch

Meaning: Indicates the beam gains of massive MIMO. If this parameter is set to ON(On) and the number of admitted UEs is smaller than or equal to three, the eNodeB forcibly performs MIMO for these UEs. If this parameter is set to ON(On) and the number of admitted UEs is greater than three, the eNodeB adaptively changes the transmission mode for these UEs. If this parameter is set to OFF(Off), the eNodeB adaptively performs beamforming or MIMO for UEs. This parameter takes effect only when the BfMimoAdaptiveSwitch parameter in the CellBfMimoParaCfg MO is set to MIMO_BF_ADAPTIVE(MIMO_BF_ADAPTIVE) or TxD_BF_ADAPTIVE(TxD_BF_ADAPTIVE). This parameter applies only to LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to ON(On) and the number of admitted UEs is smaller than or equal to three, the eNodeB forcibly performs MIMO for these UEs, restricting beam gains but lowering downlink spectral efficiency. If this parameter is set to OFF(Off), the eNodeB adaptively performs beamforming or MIMO for UEs, achieving optimal downlink spectral efficiency.

MMAlgoOptSwitch Massive MIMO Algorithm Optimization Switch

Meaning: Indicates whether to enable massive MIMO optimization algorithms.

MUBF_UE_POWER_FIXED_SWITCH: Indicates whether to assign fixed power to paired UEs. This option takes effect only in massive MIMO scenarios. If this option is selected, the base station assigns fixed power to paired UEs. If this option is deselected, the base station does not assign fixed power to paired UEs. This option applies only to LTE TDD.

PUSCH_RECEIVE_ENH_SWITCH: Indicates whether to enable enhanced PUSCH reception. If this option is selected, enhanced PUSCH reception is enabled. If this option is deselected, enhanced PUSCH reception is disabled. This option takes effect only in massive MIMO scenarios. It is recommended that this option be selected in massive MIMO scenarios. This option applies only to LTE TDD.

MU_PAIRING_MCS_EXACT_SWITCH: Indicates whether to enable optimized MCS index selection for UE pairing. If this option is selected, optimized MCS index selection for UE pairing is enabled. If this option is deselected, the baseline MCS index selection algorithm is used. This option takes effect only in massive MIMO scenarios. It is recommended that this option be selected in massive MIMO scenarios. This option applies only to LTE TDD.

MUBF_ABNORMAL_UE_OPT_SWITCH: Indicates whether to enable optimization for UEs of extremely low efficiency. If this option is selected, the base station identifies UEs of extremely low efficiency and transfers such UEs to inter-frequency cells. If this option is deselected, the optimization is disabled. This option applies only to LTE TDD.

DL_RB_ASSIGN_OPT_SWITCH: Indicates whether to enable optimized downlink RB allocation. If this option is selected, optimized downlink RB allocation is enabled. If this option is deselected, optimized downlink RB allocation is disabled. This option takes effect only in massive MIMO scenarios. This option applies only to LTE TDD.

MU_PAIRING_VOLTE_SWITCH: Indicates whether VoLTE UEs can be paired for MU beamforming. If this option is selected, VoLTE UEs can be paired for MU beamforming. If this option is deselected, VoLTE UEs cannot be paired for MU beamforming. This option applies only to LTE TDD.

MM_DL_SCH_AND_MCS_OPT_SWITCH: Indicates whether to enable downlink scheduling and MCS optimization in massive MIMO scenarios. If this option is selected, the optimization is enabled. If this option is deselected, the optimization is disabled. This option applies only to LTE TDD.

SRS_SDNR_SWITCH: Indicates whether to enable the SRS space-domain noise reduction (SDNR) function. If this option is selected, the SRS SDNR function is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

MM_ANT_SEL_ENH_SWITCH: Indicates whether to enable SRS transmission by four antennas in turn. If this option is selected, this function is enabled. If this option is deselected, this function is disabled. This option takes effect only in massive MIMO scenarios. This option applies only to LTE TDD.

MM_ACCESS_CONTROL_OPT_SWITCH: Indicates whether to enable access control optimization to ensure that the user-experienced rate reaches the target value during major events in massive MIMO scenarios. If this option is selected, access control optimization takes effect. If this option is deselected, access control optimization does not take effect. This option applies only to LTE TDD.

TM9_HIGH_ORDER_PAIRING_SWITCH: Indicates whether to enable downlink TM9 high-order pairing for massive MIMO. If this option is selected, TM9 high-order pairing is enabled. If this option is deselected, TM9 high-order pairing is disabled. This option applies only to LTE TDD.

DL_CORR_UE_PAIRING_OPT_SWITCH: Indicates whether to enable UE pairing optimization based on downlink correlation in MU beamforming scenarios. If this option is selected, this function takes effect. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

UE_STATUS_BASED_MLB_SWITCH: Indicates whether to enable MLB between massive MIMO common cells and non-massive MIMO cells or between massive MIMO common cells and massive MIMO split cells based on UE status identification results. If this option is selected, this type of MLB takes effect. If this option is deselected, this type of MLB does not take effect. This option applies only to LTE TDD.

TM8_PORT_ALLOC_OPT_SWITCH: Indicates whether to enable port allocation optimization for massive MIMO TM8 pairing. If this option is selected, port allocation optimization for massive MIMO TM8 pairing is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

ABN_UE_PAIRING_PROT_SWITCH: Indicates whether to enable multi-UE pairing protection for defective UEs. If this option is selected, this function is enabled. If this option is deselected, this function does not take effect. This option applies only to LTE TDD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: MUBF_UE_POWER_FIXED_SWITCH: This option can be selected only if the MuBfSwitch option of the MuBfAlgoSwitch parameter is selected. If this option is selected, the eNodeB assigns a fixed amount of power to UEs in a cell. This reduces interference, improves MU beamforming performance in massive MIMO cells, and increases the throughput. If this option is deselected, the eNodeB does not assign a fixed amount of power to UEs in a cell, and network performance is not affected.

PUSCH_RECEIVE_ENH_SWITCH: If this option is selected, the average uplink cell throughput increases. If this option is deselected, the average uplink cell throughput does not increase.

MU_PAIRING_MCS_EXACT_SWITCH: If this option is selected, the eNodeB selects the MCS index more accurately, increasing the average downlink cell throughput when UEs are moving at speeds ranging from 3 km/h to 5 km/h. If this option is deselected, the average downlink cell throughput does not increase.

MUBF_ABNORMAL_UE_OPT_SWITCH: If this option is selected, the eNodeB identifies UEs of extremely low efficiency and performs optimization for such UEs, increasing the resource efficiency and the number of inter-frequency handovers. However, the inter-frequency handover success rate is more likely to fluctuate. If this option is deselected, the eNodeB does not identify UEs of extremely low efficiency or perform optimization for such UEs. In this case, resource efficiency does not increase, and the number of inter-frequency handovers is not affected.

DL_RB_ASSIGN_OPT_SWITCH: If this option is selected, the downlink packet error rate in massive MIMO cells decreases, and the downlink spectral efficiency increases. However, RBs may be fragmented. If this option is deselected, network performance is not affected.

MU_PAIRING_VOLTE_SWITCH: If this option is selected, the downlink packet loss rate of VoLTE UEs, spectral efficiency, capacity, and cell throughput increase, and the scheduling delay in heavy-load scenarios decreases. Deselecting this option leads to the opposite effects.

MM_DL_SCH_AND_MCS_OPT_SWITCH: If this option is selected, the downlink spectral efficiency improves, and the average expected downlink MCS index of paired UEs decreases. If this option is deselected, network performance is not affected.

SRS_SDNR_SWITCH: If this option is selected, SRS resource estimation is more accurate, and the downlink cell throughput increases. If this option is deselected, network performance is not affected.

MM_ANT_SEL_ENH_SWITCH: If this option is selected, SRS transmission by four antennas in turn is enabled. Channel information of four UE antennas can be obtained. The downlink beamforming performance is improved. If this option is deselected, network performance is not affected.

MM_ACCESS_CONTROL_OPT_SWITCH: If this option is selected, the user-experienced rate can reach the target value. However, if the uplink and downlink PRB resources on the air interface are not limited, the uplink and downlink cell traffic decreases. If the uplink and downlink PRB resources on the air interface are limited, the uplink or downlink cell traffic does not decrease. If this option is deselected, the user-experienced rate is not considered when UEs access massive MIMO networks. In this case, the user-experienced rate drops to zero if the number of UEs is greater than a certain value.

TM9_HIGH_ORDER_PAIRING_SWITCH: If this option is selected, the number of TM9 pairing layers increases. However, the BLER may increase after pairing, and system capacity may decrease. If this option is deselected, network performance is not affected.

DL_CORR_UE_PAIRING_OPT_SWITCH: If this option is selected, fewer high-correlation UEs are paired, improving MU beamforming pairing performance but slightly reducing downlink pairing layers. If this option is deselected, network performance is not affected.

UE_STATUS_BASED_MLB_SWITCH: If this option is selected, system capacity increases. If this option is deselected, network performance is not affected.

TM8_PORT_ALLOC_OPT_SWITCH: If this option is selected, the port multiplexing performance is improved for TM8 pairing when there are many pairing layers in the cell, improving user experience. If this option is deselected, network performance is not affected.

ABN_UE_PAIRING_PROT_SWITCH: If this option is selected, the number of paired layers decreases. If this option is deselected, network performance is not affected.

Applicable Mode: L-TDD
