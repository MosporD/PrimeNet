Modify Operator-specific UE-level QCI Parameter (MOD CNOPUSERQCIPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify operator-specific UE-level configurations of a QCI.

Note

None.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Qci QoS Class Indication

Meaning: Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 6~9

Unit: None

Actual Value Range: 6~9

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserPriority User Priority

Meaning: Indicates the user priority. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: GOLD(Gold), SILVER(Silver), BRONZE(Bronze), IRON(Iron)

Unit: None

Actual Value Range: GOLD, SILVER, BRONZE, IRON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.
  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlschPriorityWeightFactor Downlink Scheduling Priority Weight Factor

Meaning: Indicates the weight factor used in the calculation of connection priorities during downlink scheduling. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 0.001~1, step: 0.001

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Gold users:

QCI 6: 1000, QCI 7: 950, QCI 8: 900, QCI 9: 850

Silver users:

QCI 6: 800, QCI 7: 750, QCI 8: 700, QCI 9: 650

Bronze users:

QCI 6: 600, QCI 7: 550, QCI 8: 500, QCI 9: 450

Iron users:

QCI 6: 400, QCI 7: 350, QCI 8: 300, QCI 9: 250

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the DlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher downlink scheduling priority for services with the QCI and also a higher priority with which the data rates for these services are guaranteed. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
UlschPriorityWeightFactor Uplink Scheduling Priority Weight Factor

Meaning: Indicates the weight factor used in the calculation of connection priorities during uplink scheduling. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 0.001~1, step: 0.001

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Gold users:

QCI 6: 1000, QCI 7: 950, QCI 8: 900, QCI 9: 850

Silver users:

QCI 6: 800, QCI 7: 750, QCI 8: 700, QCI 9: 650

Bronze users:

QCI 6: 600, QCI 7: 550, QCI 8: 500, QCI 9: 450

Iron users:

QCI 6: 400, QCI 7: 350, QCI 8: 300, QCI 9: 250

Parameter Relationship:

-Configuration constraints:

  • In CnOpUserQciPara MOs with the same values of both the CnOperatorId and Qci parameters, the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value GOLD, SILVER, or BRONZE must be greater than or equal to the value of the UlSchPriorityWeightFactor parameter corresponding to the UserPriority parameter with the value SILVER, BRONZE, or IRON, respectively.

Service Interrupted After Modification: No (No impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller uplink bandwidth to be allocated to services with the QCI when the uplink transmission bandwidth or uplink licensed traffic volume is limited. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify operator-specific UE-level configurations of a QCI with the parameters as follows: CN Operator ID: 0, QoS Class Indication: 6, User Priority: GOLD, Downlink Scheduling Priority Weight Factor: 950, Uplink Scheduling Priority Weight Factor: 950, run the following command:
MOD CNOPUSERQCIPARA: CnOperatorId=0, Qci=6, UserPriority=GOLD, DlschPriorityWeightFactor=950, UlschPriorityWeightFactor=950;
