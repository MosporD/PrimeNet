Modify Cell Coverage Enhancement Configuration (MOD CELLENHCOVERAGE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters related to cell coverage enhancement.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
EnhChCoverageSw Channel Coverage Enhancement Switch

Meaning: Indicates whether to enable channel coverage enhancement.

PRACH_PUCCH_COVERAGE_ENH_SW: Indicates whether to enable coverage enhancement for the PRACH and PUCCH. This option is valid when the UlCoverageEnhancementSw parameter is set to ON. This option applies only to LTE FDD.

PUSCH_JR_COVERAGE_ENH_SW: Indicates whether to enable UL CoMP for UEs for which coverage is enhanced. This option is valid when the UlCoverageEnhancementSw parameter is set to ON and the UlJointReceptionSwitch option of the UplinkCompSwitch parameter is selected. UL CoMP is supported for UEs for which coverage is enhanced only if the PUSCH_JR_COVERAGE_ENH_SW option is selected. This option applies only to LTE FDD.

TTIB_SMART_RETRANS_SW: Indicates whether to enable intelligent retransmission for UEs in the TTI bundling state. This option is valid when the UlCoverageEnhancementSw parameter is set to ON. This option applies only to LTE FDD.

GUI Value Range: PRACH_PUCCH_COVERAGE_ENH_SW(PRACH_PUCCH_COVERAGE_ENH_SW), PUSCH_JR_COVERAGE_ENH_SW(PUSCH_JR_COVERAGE_ENH_SW), TTIB_SMART_RETRANS_SW(TTIB_SMART_RETRANS_SW)

Unit: None

Actual Value Range: PRACH_PUCCH_COVERAGE_ENH_SW, PUSCH_JR_COVERAGE_ENH_SW, TTIB_SMART_RETRANS_SW

MML Default Value: None

Recommended Value: PRACH_PUCCH_COVERAGE_ENH_SW: In common scenarios, it is recommended that this option be selected, indicating that the PRACH coverage and PUCCH coverage are kept unchanged. In scenarios where there is definite requirement for cell coverage improvement, whether to deselect this option depends on live network configurations.

PUSCH_JR_COVERAGE_ENH_SW: It is recommended that this option be selected for target weak-coverage cells for which intra-eNodeB UL CoMP has been enabled.

TTIB_SMART_RETRANS_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: PRACH_PUCCH_COVERAGE_ENH_SW: If this option is deselected for a 2R or 4R cell where PRACH format 0 or 1 is used, the PRACH coverage and PUCCH coverage will be expanded. As a result of PRACH coverage expansion, the number of UEs admitted to the cell increases and KPIs such as the access success rate, service drop rate, and throughput deteriorate in case of uplink limitation. As a result of the PUCCH coverage expansion, the false PUCCH detection rate increases and KPIs such as the false detection rate and throughput deteriorate. If this option is selected, the PRACH and PUCCH coverage remains unchanged.

PUSCH_JR_COVERAGE_ENH_SW: If this option is selected, the uplink performance improves and user-perceived uplink rates increase. If this option is deselected, user-perceived uplink rates are not affected.

TTIB_SMART_RETRANS_SW: If this option is selected, user-perceived uplink rates increase for UEs for which the function takes effect. If this option is deselected, there is no impact.

Applicable Mode: L-FDD

Example

To modify the cell coverage enhancement with the parameters as follows:Local cell ID:0, Channel Coverage Enhancement Switch:PRACH_PUCCH_COVERAGE_ENH_SW-1, run the following command:
MOD CELLENHCOVERAGE: LocalCellId=0, EnhChCoverageSw=PRACH_PUCCH_COVERAGE_ENH_SW-1;
