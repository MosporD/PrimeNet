Add a Sidelink V2X Resource Pool Configuration (ADD SIDELINKV2XRESPLCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to configure a sidelink V2X resource pool.

Note

None.

Parameters

ID Name Description
SidelinkV2xCarrierId Sidelink V2X Carrier ID

Meaning: Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PoolId Pool ID

Meaning: Indicates the resource pool ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PoolType Pool Type

Meaning: Indicates the resource pool type. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: TX_POOL(TX_POOL), RX_POOL(RX_POOL)

Unit: None

Actual Value Range: TX_POOL, RX_POOL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PoolSubframeBitmap Pool Subframe Bitmap

Meaning: Indicates the bitmap of the subframe used for the resource pool. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: 1048575

Recommended Value: 1048575

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PscchPsschAdjacency PSCCH PSSCH Adjacency

Meaning: Indicates whether adjacent RBs in the same subframe are used to transmit the PSSCH and PSCCH. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: BOOLEAN_FALSE(False), BOOLEAN_TRUE(True)

Unit: None

Actual Value Range: BOOLEAN_FALSE, BOOLEAN_TRUE

MML Default Value: BOOLEAN_FALSE(False)

Recommended Value: BOOLEAN_FALSE(False)

Parameter Relationship:

-Configuration constraints:

  • When the PscchPsschAdjacency parameter in a SidelinkV2xResPlCfg MO is set to BOOLEAN_FALSE, the product of the SubchannelCount parameter value and 2 plus the PscchPoolStartRbIndex parameter value must not exceed the SubchannelStartRbIndex parameter value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SubchannelCount Subchannel Count

GUI Value Range: COUNT_1(COUNT_1), COUNT_3(COUNT_3), COUNT_5(COUNT_5), COUNT_8(COUNT_8), COUNT_10(COUNT_10), COUNT_15(COUNT_15), COUNT_20(COUNT_20)

Unit: None

MML Default Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

SubchannelStartRbIndex Subchannel Start RB Index

Meaning: Indicates the index of the starting RB of the subchannel. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

PscchPoolStartRbIndex PSCCH Pool Start RB Index

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Example

To add a sidelink V2X resource pool configuration with the sidelink V2X carrier ID of 0, resource pool ID of 0, resource pool type of TX_POOL, subchannel count of COUNT_1, subchannel PRB count of COUNT_5, and PSCCH pool start RB index of 0, run the following command:
ADD SIDELINKV2XRESPLCFG: SidelinkV2xCarrierId=0, PoolId=0, PoolType=TX_POOL, SubchannelCount=COUNT_1, SubchannelPrbCount=COUNT_5, PscchPoolStartRbIndex=0;
