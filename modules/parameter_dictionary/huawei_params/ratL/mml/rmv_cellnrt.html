Remove Cell Nrt (RMV CELLNRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove all data related to neighboring cells of the local cell, including blacklisted intra-frequency neighboring cells, blacklisted inter-frequency neighboring cells, inter-frequency neighbor relationships, neighboring E-UTRAN frequencies, intra-frequency neighbor relationships, neighbor relationships with UTRAN cells, neighboring UTRAN frequencies, neighbor relationships with GERAN cells, neighbor GERAN frequency group, neighbor GERAN BCCH frequencies, neighbor relationships with CDMA2000 HRPD cells, neighbor relationships with CDMA2000 1xRTT cells, neighboring CDMA2000 frequencies, neighboring CDMA2000 frequency bands, blacklisted neighboring E-UTRAN cells, blacklisted neighboring UTRAN cells, neighbor relationships with NR cells, neighboring NR frequencies, EutranNFreqSCellOp, EutranNFreqRanShare, QciEutranRelation, QciUtranRelation, UtranNFreqSCellOp, UtranRanShare, QciGeranRelation, GeranNFGroupSCellOp, GeranRanShare, Cdma2000BcSCellOp and NrNFreqSCellOp.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This operation is a high-risk operation and you are advised to perform this operation with caution. This operation will remove data of all neighboring cells of the local cell. Perform this operation after the cell is deactivated. Do not perform other configuration operations before this operation is complete.

  • Before using the RMV CELLNRT command to delete neighboring cell data, delete the configurations that depend on the neighboring cell data. Otherwise, the neighboring cell data will fail to be deleted.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove all neighboring cells data of the local cell ID of 0, run the following command:
RMV CELLNRT: LocalCellId=0;
