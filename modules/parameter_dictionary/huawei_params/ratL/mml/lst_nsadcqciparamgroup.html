List QCI-specific NSA DC Parameter Group (LST NSADCQCIPARAMGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list QCI-specific NSA DC parameter groups.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
NsaDcQciParamGroupId NSA DC QCI Parameter Group ID

Meaning: Indicates the ID of the QCI-specific NSA DC parameter group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

NSA DC QCI Parameter Group ID

Indicates the ID of the QCI-specific NSA DC parameter group. This parameter applies only to LTE FDD and LTE TDD.

Uplink Data Split Threshold(Byte)

Indicates the uplink data split threshold when the UE performs LTE-NR NSA DC. If the UE PDCP buffer data size is greater than the threshold, the UE transfers data to the master and secondary base stations at the same time. For details, see 3GPP TS 38.323 and 3GPP TS 38.331. This parameter applies only to LTE FDD and LTE TDD.

Uplink Data Split Primary Path

Indicates the primary path for uplink data split. If this parameter is set to MCG, the primary path for uplink data split is the path towards the MCG. If this parameter is set to SCG, the primary path for uplink data split is the path towards the SCG. For details, see 3GPP TS 38.323. This parameter applies only to LTE FDD and LTE TDD.

Downlink Data PDCP Split Mode

Indicates the downlink PDCP-layer data split mode. If this parameter is set to SCG_AND_MCG, dynamic data split is adopted and data is dynamically transferred to the eNodeB and gNodeB based on the split algorithm. If this parameter is set to MCG_ONLY, data is transferred only to the eNodeB. If this parameter is set to SCG_ONLY, data is transferred only to the gNodeB. This parameter applies only to LTE FDD and LTE TDD.

NSA DC B1 RSRP Threshold Offset(dB)

Indicates the offset relative to the RSRP threshold for event B1 related to SCG addition by the eNodeB for UEs. The sum of this offset and the value of the NsaDcB1ThldRsrp parameter in the NrScgFreqConfig MO is taken as the RSRP threshold for event B1 related to SCG addition. This parameter applies only to LTE FDD and LTE TDD.
