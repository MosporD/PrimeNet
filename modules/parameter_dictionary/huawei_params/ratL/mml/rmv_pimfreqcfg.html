Remove PIM Downlink EARFCN (RMV PIMFREQCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a PIM Downlink EARFCN.

Note

None.

Parameters

ID Name Description
PimFreqGroupId PIM Frequency Group ID

Meaning: Indicates the ID of a passive intermodulation (PIM) frequency group. It uniquely identifies a PIM frequency group within an eNodeB. This parameter applies only to FDD macro eNodeBs. This parameter applies only to LTE FDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PimDlEarfcn must be set to different values in different PIMFreqCfg MOs.
  • A maximum of two PIMFreqCfg MOs can be configured under a PIMFreqGroup MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PimDlEarfcn PIM Downlink EARFCN

Meaning: Indicates the downlink EARFCN of a carrier involved in passive intermodulation (PIM) mitigation. This parameter applies only to FDD macro eNodeBs. This parameter applies only to LTE FDD.

GUI Value Range: 0~70545,255144~256143,260894~262143

Unit: None

Actual Value Range: 0~70545,255144~256143,260894~262143

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PimDlEarfcn must be set to different values in different PIMFreqCfg MOs.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To remove a PIM Downlink EARFCN with the parameters as follows: PimFreqGroupId:0, PimDlEarfcn:1500, run the following command:
RMV PIMFREQCFG: PimFreqGroupId=0, PimDlEarfcn=1500;
