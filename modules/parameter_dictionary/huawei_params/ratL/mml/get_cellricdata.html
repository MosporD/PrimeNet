Get Cell Remote Interference Data (GET CELLRICDATA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to collect the interference data about a cell for identifying interference sources.

Note

  • Start an CHR collection task on the NIC before running this command.

  • The time that related commands begin to take effect must be specified according to the Greenwich Mean Time (GMT).

  • Only one data collection task can be started on one BBP. This command can be successfully executed only when the previous task is complete.

  • Before running this command, ensure that the cell has been set up.

  • Set the start time to a time later than the current eNodeB time. This ensures that the MAE has delivered this command to all eNodeBs before the command execution.

Example

To collect data about cell remote interference with the parameters as follows: Main eNodeB ID: 74, Main eNodeB Local cell ID: 0, Start time: 2012&07&19&09&41&57, Cabinet No.: 0, Subrack No.: 62, Slot No.: 0, RX Channel No.: 1, Silence Flag: OFF, run the following command:
GET CELLRICDATA: eNodeBId=74, LocalCellId=0, StartTime=2012&07&19&09&41&57, CabinetNo=0, SRN=62, SN=0, RXNO=1, SilenceFlag=OFF;

Output Description

Field Description

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
