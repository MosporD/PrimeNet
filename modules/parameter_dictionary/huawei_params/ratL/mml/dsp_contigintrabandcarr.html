Display Parameters for Zero Guard Band Between Contiguous Intra-Band Carriers (DSP CONTIGINTRABANDCARR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query cell-level dynamic parameters related to the Zero Guard Band Between Contiguous Intra-Band Carriers feature.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the dynamic information of contiguous intra-Band carriers:
DSP CONTIGINTRABANDCARR: LocalCellId=0;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Neighboring Cell Local Cell ID

Indicates the local cell ID of the neighboring cell associated with the current cell in the Zero Guard Band Between Contiguous Intra-Band Carriers feature. This parameter applies only to LTE FDD and LTE TDD.

Downlink Exclusive RB Start Index

Indicates the index of the start downlink RB that is exclusively used after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Downlink Exclusive RB End Index

Indicates the index of the end downlink RB that is exclusively used after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Downlink Shared RB Start Index

Indicates the index of the start downlink RB that is shared after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Downlink Shared RB End Index

Indicates the index of the end downlink RB that is shared after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Uplink RB Start Index

Indicates the index of the start uplink RB after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Uplink RB End Index

Indicates the index of the end uplink RB after the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Downlink RB Start Index

Indicates the index of the start RB that is an initially static downlink RB when the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

Downlink RB End Index

Indicates the index of the end RB that is an initially static downlink RB when the Zero Guard Band Between Contiguous Intra-Band Carriers feature is deployed. This parameter applies only to LTE FDD and LTE TDD.

EVM Optimization Status

Indicates the status of the EVM optimization function for the Zero Guard Band Between Contiguous Intra-Band Carriers feature. The value NOT_ACTIVE indicates that EVM optimization has not taken effect in the overlapping spectrum range after this feature is deployed. The value ACTIVE indicates that EVM optimization has taken effect in the overlapping spectrum range after this feature is deployed. This parameter applies only to LTE FDD and LTE TDD.
