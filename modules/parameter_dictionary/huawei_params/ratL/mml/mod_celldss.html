Modify Cell DSS Configuration (MOD CELLDSS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of Cell Dynamic Spectrum Sharing Parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modification on the HighFreqShareRbNum and LowFreqShareRbNum parameters causes cell resetting and affects services.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
HighFreqShareRbNum Shared RB Number in High Frequency

Meaning: Indicates the number of high-band RBs that the E-UTRAN cell can share with GERAN cells when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. A larger number of shared RBs results in a higher gain that an LTE cell can achieve. For GSM and LTE FDD Dynamic Spectrum Sharing, however, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/5. For GSM and LTE Zero BufferZone, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/2. This parameter applies only to FDD.

GUI Value Range: 0~20

Unit: None

Actual Value Range: 0~20

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter leads to more spectrum resources that can be used by the eNodeB and larger downlink capacity of the E-UTRAN cell. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD

A larger number of shared RBs results in a higher gain that an LTE cell can achieve. For GSM and LTE FDD Dynamic Spectrum Sharing, however, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/5. For GSM and LTE Zero BufferZone, it is recommended that the ratio of the shared bandwidth to the cell bandwidth be less than or equal to 1/2. This parameter applies only to FDD.

ReMuteSwitch Mute RE Switch

Meaning: Indicates whether to send REs if the corresponding REs in the shared spectrum are being used by GSM when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If this switch is on, the eNodeB cannot send these REs. If this switch is off, the eNodeB can send these REs. This parameter applies only to FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, interference from the E-UTRAN cell to GERAN cells decreases, improving the GERAN cell performance. If this parameter is set to OFF, interference from the E-UTRAN cell to GERAN cells increases, increasing GSM transmit power and deteriorating the E-UTRAN cell performance.

Applicable Mode: L-FDD
UlInterfRestrictionMode UL Narrowband Interference Restriction Mode

Meaning: Indicates the UL narrowband interference restriction mode used in the GSM and LTE FDD Dynamic Spectrum Sharing(LTE FDD) feature and GSM and LTE Zero Bufferzone feature. The value NONE indicates that UL narrowband interference restriction is not enabled. The value BASEBANDPROCESS indicates that UL narrowband interference is restricted through baseband processing. The interference scope of GSM is reduced and only RBs close to the GSM spectrum are affected. As a result, RBs far away from the GSM spectrum and the LTE spectrum can work properly and LTE performance improves. The value ADAPTIVEPROCESS indicates that UL narrowband interference is restricted through adaptive processing. This algorithm further enhances the interference restriction capability and improves LTE performance. The value INFERIORINTERFPROCESS indicates that only interference from GSM in a neighboring cell is handled through baseband processing. When the setting of the UlInterfRestrictionMode parameter is changed from INFERIORINTERFPROCESS to another value or from another value to INFERIORINTERFPROCESS, the cell must be restarted for the setting change to take effect. This parameter applies only to LTE FDD.

GUI Value Range: NONE(NONE), BASEBANDPROCESS(BASEBANDPROCESS), ADAPTIVEPROCESS(ADAPTIVEPROCESS), INFERIORINTERFPROCESS(INFERIORINTERFPROCESS)

Unit: None

Actual Value Range: NONE, BASEBANDPROCESS, ADAPTIVEPROCESS, INFERIORINTERFPROCESS

MML Default Value: None

Recommended Value: ADAPTIVEPROCESS

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NONE, interference from GSM is not restricted and therefore may affect the full band of LTE and decrease the UL throughput of LTE.

If this parameter is set to BASEBANDPROCESS, the interference scope of GSM is compressed and only RBs close to the GSM spectrum are affected. As a result, RBs far away from the GSM spectrum and RBs in the LTE spectrum can work properly and the UL throughput of LTE improves.

If this parameter is set to ADAPTIVEPROCESS, UL interference from GSM to LTE further decreases and the UL throughput of LTE further increases.

If this parameter is set to INFERIORINTERFPROCESS, only UL interference from GSM in a neighboring cell or weak interference from GSM is handled.

Applicable Mode: L-FDD
A3Offset A3 Offset

Meaning: Indicates the offset of a neighboring cell's signal level that triggers event A3 used after the GSM and LTE FDD Dynamic Spectrum Sharing feature or the GSM and LTE Zero Bufferzone feature is enabled. Measurement reports for this event A3 are reported only when the signal quality of at least one neighboring cell is better than that of the local cell by this offset. If this parameter is set to a larger value, the probability of UEs reporting this event A3 is lower. This parameter applies only to FDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability of UEs reporting event A3 used in GSM and LTE dynamic spectrum sharing, thereby decreasing downlink throughput of cell edge users (CEUs) and downlink capacity of the E-UTRAN cell.

A smaller value of this parameter leads to a higher probability of UEs reporting event A3 used in GSM and LTE dynamic spectrum sharing. In this case, more UEs report A3 measurements, thereby increasing overheads in the physical uplink shared channel (PUSCH) and decreasing uplink capacity of the E-UTRAN cell.

Applicable Mode: L-FDD

If this parameter is set to a larger value, the probability of UEs reporting this event A6 is lower. This parameter applies only to FDD.

Applicable Mode: L-FDD
NearAreaSinrThd Near Area Sinr Threshold

Meaning: Indicates the SINR threshold used to determine whether RBs in the shared spectrum can be allocated to UEs that are located in the cell center when the GSM and LTE FDD Dynamic Spectrum Sharing feature and the GSM and LTE Zero Bufferzone feature are enabled. If the actual SINR of RBs is greater than or equal to this threshold, these RBs can be allocated to these UEs. This parameter applies only to FDD.

GUI Value Range: 0~15

Unit: dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to fewer RBs in the shared spectrum that can be used by UEs that are located at short distances away from the center of the E-UTRAN cell, decreasing the RB usage in the shared spectrum and downlink capacity when GSM and LTE dynamic spectrum sharing is enabled. A smaller value of this parameter leads to the opposite effects. However, the block error rate (BLER) of RBs in the shared spectrum increases, thereby raising interference to the GERAN cell.

Applicable Mode: L-FDD

If the SINR of shared RBs is greater than or equal to this threshold, these RBs can be allocated to these UEs. This parameter applies only to FDD.

SpecShrPfmOptSwitch Spectrum Sharing Performance Opt Switch

Meaning: Indicates whether to enable spectrum sharing optimization. This parameter provides four options: FlexSpecSchSwitch, UlSchInterfAvdSwitch, HoZoneUserSchSwitch, and UlShrSpecSchSwitch. HoZoneUserSchSwitch and UlShrSpecSchSwitch apply only when GSM and LTE (GL) zero bufferzone is used. This option applies only to LTE FDD.

FlexSpecSchSwitch: Indicates whether to enable flexible exclusive scheduling of shared RBs in GL dynamic spectrum sharing and GL zero bufferzone. This option applies only to LTE FDD.

UlSchInterfAvdSwitch: Indicates whether to enable avoidance of GSM interference when uplink exclusive scheduling of shared RBs is enabled in GL dynamic spectrum sharing and GL zero bufferzone. This option applies only to LTE FDD.

HoZoneUserSchSwitch: Indicates whether to enable scheduling of UEs in handover zones when GL zero bufferzone is used. This option applies only to LTE FDD.

UlShrSpecSchSwitch: Indicates whether to enable scheduling of uplink shared spectrum resources when GL zero bufferzone is used. This option applies only to LTE FDD.

GUI Value Range: FlexSpecSchSwitch(FlexSpecSchSwitch), UlSchInterfAvdSwitch(UlSchInterfAvdSwitch), HoZoneUserSchSwitch(HoZoneUserSchSwitch), UlShrSpecSchSwitch(UlShrSpecSchSwitch)

Unit: None

Actual Value Range: FlexSpecSchSwitch, UlSchInterfAvdSwitch, HoZoneUserSchSwitch, UlShrSpecSchSwitch

MML Default Value: None

Recommended Value: FlexSpecSchSwitch:Off, UlSchInterfAvdSwitch:Off, HoZoneUserSchSwitch:Off, UlShrSpecSchSwitch:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: FlexSpecSchSwitch: When this option is selected, user experience improves if the shared spectrum is not fully occupied by GSM users in scenarios where GL dynamic spectrum sharing and GL zero bufferzone are used.

UlSchInterfAvdSwitch: When this option is selected, the eNodeB avoids strong GSM interference in scenarios where GL dynamic spectrum sharing and GL zero bufferzone are used, improving E-UTRAN uplink performance.

HoZoneUserSchSwitch: When this option is selected, all UEs in the buffer zone can use the shared spectrum when GL zero bufferzone is used, improving spectrum utilization.

UlShrSpecSchSwitch: When this option is selected, UEs can use the shared spectrum when GL zero bufferzone is used, improving spectrum utilization and increasing uplink capacity.

Applicable Mode: L-FDD
SinrThdWithoutGsmInterf SINR Threshold Without GSM Interference

Meaning: Indicates the threshold for determining no GSM interference to shared RBs when exclusive scheduling of shared RBs is to be enabled in GSM and LTE (GL) dynamic spectrum sharing and GL zero bufferzone. If the estimated SINR of shared RBs is greater than the threshold, shared RBs are free of GSM interference and can be exclusively scheduled for LTE. This parameter applies only to LTE FDD.

GUI Value Range: 0~80

Unit: dB

Actual Value Range: 0~80

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a low probability that shared RBs will be determined to be free of GSM interference and therefore a low probability that shared RBs can be exclusively scheduled, which further results in small improvement in user experience. A smaller value results in the opposite effects. However, if this parameter is set to an extremely small value, for example 5, shared RBs suffering interference may be incorrectly determined to be free of interference and therefore are exclusively scheduled, causing UE throughput to decrease.

Applicable Mode: L-FDD
GsmInterfINThd GSM Interference Noise Threshold

Meaning: Indicates the threshold for determining strong GSM interference in the high frequency band or low frequency band when uplink scheduling in dedicated spectrum is enabled in GSM and LTE (GL) dynamic spectrum sharing or GL zero bufferzone. When the difference between the IN values of the high and low frequency bands is greater than the value of this parameter, there is strong GSM interference to the frequency band with the higher IN value. This parameter applies only to LTE FDD cells.

GUI Value Range: 0~50

Unit: dB

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a low probability that strong GSM interference to uplink dedicated spectrum will be determined and therefore a low probability of replacing interference randomization. A smaller value of this parameter results in the opposite effects, improving uplink performance.

Applicable Mode: L-FDD
NearPtUserRsrpThd Near Point User Rsrp Threshold

Meaning: Indicates the threshold for scheduling uplink shared spectrum resources for UEs located near the center of the E-UTRAN cell when the GL zero bufferzone feature is used. If the downlink RSRP reported by a UE is greater than the threshold, the UE is located near the center of the E-UTRAN cell. This parameter applies only to LTE FDD cells.

GUI Value Range: -120~-40

Unit: dBm

Actual Value Range: -120~-40

MML Default Value: None

Recommended Value: -75

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a low probability that a UE will be determined as a UE located near the cell center and a small average number of uplink RBs to be shared. A smaller value of this parameter results in the opposite effects. However, if this parameter is set to an extremely small value and neighboring GERAN cells using the shared spectrum causes strong interference to the local cell, UEs located near the cell center may not have sufficient power to resist GSM interference, causing uplink performance to deteriorate.

Applicable Mode: L-FDD

Example

To modify the configuration of the Cell Dynamic Spectrum Sharing Parameters with the parameters as follows: Local cell ID: 0, Mute RE Switch: OFF, run the following command:
MOD CELLDSS: LocalCellId=0, ReMuteSwitch=OFF;
