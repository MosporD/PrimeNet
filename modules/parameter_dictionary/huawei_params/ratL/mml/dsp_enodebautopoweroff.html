Display RF Module Regular Time Sleep Information (DSP ENODEBAUTOPOWEROFF)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the RF module regular time sleep information about the eNodeB.

Note

None.

Parameters

None.

Example

To query the dynamic RF module sleep information, run the following command: :
DSP ENODEBAUTOPOWEROFF:;
The result is shown as follows:
+++    0        2019-12-05 21:46:16
O&M    #806355060
%%DSP ENODEBAUTOPOWEROFF: ;%%
RETCODE = 0  Operation succeeded.

Display RF Module Regular Time Sleep Information
------------------------------------------------
RF module sleep status  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

RF module sleep status

Indicates the sleep status of the RF modules of the eNodeB. The value POWER_OFF indicates that cells on the eNodeB are unavailable. The value NORMAL indicates that the eNodeB is working normally. This parameter applies only to LTE FDD and NB-IoT.
