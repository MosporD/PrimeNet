Display Cell eCSPC status (DSP CELLECSPCSTATUS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about the coordinating neighboring cells after eCSPC is activated.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

query information about the coordinating neighboring cells after eCSPC is activated with local cell ID of 1, run the following command:
DSP CELLECSPCSTATUS: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:44:32
O&M    #806354998
%%DSP CELLECSPCSTATUS: LocalCellId=1;%%

              eCspc Coordinate eNodeB ID  =  400021
              eCspc Coordinate Cell Type  =  Macro
(Number of results = 1)


---    END

Output Description

Field Description

eCspc Coordinate Cell Link Delay Status

Indicates whether the delay on links between the coordinating cells in eCSPC exceeds the delay threshold. This parameter applies only to LTE FDD and LTE TDD.

eCspc Coordinate Cell Type

Indicates the type (macro or micro) of the cooperating cell in eCSPC. This parameter applies only to LTE FDD and LTE TDD.

eCspc Coordinate eNodeB ID

Indicates the ID of the eNodeB that serves a cooperating cell in eCSPC. This parameter applies only to LTE FDD and LTE TDD.

eCspc Coordinate Local Cell ID

Indicates the ID of the local cell that functions as a cooperating cell in eCSPC. This parameter applies only to LTE FDD and LTE TDD.

eCspc Data Link Status

Indicates the status of the data link to a cooperating cell in eCSPC. This parameter applies only to LTE FDD and LTE TDD.
