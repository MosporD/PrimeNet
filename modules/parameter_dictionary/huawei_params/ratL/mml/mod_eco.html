Modify ECO Configuration (MOD ECO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify parameters of an ECO MO.

Note

  • Modifying the EPGROUP MO referenced by the ECO MO may lead to the ongoing service interruption.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the ECO or S1 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the ECO or X2 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the CpEpGroupId parameter in the ECO MOs or the M2EpGroupId parameter in the M2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the ECO or S1 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the ECO or X2 MOs cannot overlap.

  • IP addresses configured in the USERPLANEPEER MOs belonging to the EPGROUP MOs referenced by the UpEpGroupId parameter in the ECO MOs or the M1EpGroupId parameter in the M1 MOs cannot overlap.

  • The EPGROUP MO referenced by CpEpGroupId in an ECO MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an ECO MO and the EPGROUP MO referenced by the IUB, ABIS, or uX2 MO must be different.

Parameters

ID Name Description
EcoId ECO ID

Meaning: Indicates the ID of the ECO MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EpGroupCfgFlag End Point Group Config Flag

Meaning: Indicates whether to configure the control-plane endpoint group, user-plane endpoint group, or both endpoint groups for the ECO MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: CP_CFG(CP Config), UP_CFG(UP Config), CP_UP_CFG(CPUP Config)

Unit: None

Actual Value Range: CP_CFG, UP_CFG, CP_UP_CFG

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of an ECO MO with the parameters as follows: ECO ID: 0, End Point Group Config Flag: CP_CFG, Control Plane End Point Group ID: 124, run the following command:
MOD ECO: EcoId=0, EpGroupCfgFlag=CP_CFG, CpEpGroupId=124;
