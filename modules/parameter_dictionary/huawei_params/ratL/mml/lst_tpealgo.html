List TPE Algorithm Parameter (LST TPEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the TPE algorithm. The ports with enabled TPE are listed starting from TPE Port 1 in the command output, with the number of ports equal the value of TPE Port Num.

Note

None.

Parameters

None.

Example

To list the configurations of the TPE algorithm, run the following command: :
LST TPEALGO:;
The result is shown as follows:
+++    0        2019-12-05 17:39:47
O&M    #806356237
%%LST TPEALGO: ;%%
RETCODE = 0  Operation succeeded.

List TPE Algorithm Parameter
----------------------------
TCP Port Number  =  3
     TCP Port 1  =  20
     TCP Port 2  =  80
     TCP Port 3  =  8080
     TCP Port 4  =  0
     TCP Port 5  =  0
(Number of results = 1)


---    END

Output Description

Field Description

TCP Port Number

Indicates the number of ports to which TCP acceleration is to be applied. This parameter applies only to LTE FDD and LTE TDD.

TCP Port 1

Indicates port 1 to which TPE is to be applied. This parameter applies only to LTE FDD and LTE TDD.

TCP Port 2

Indicates port 2 to which TPE is to be applied. This parameter applies only to LTE FDD and LTE TDD.

TCP Port 3

Indicates port 3 to which TPE is to be applied. This parameter applies only to LTE FDD and LTE TDD.

TCP Port 4

Indicates port 4 to which TPE is to be applied. This parameter applies only to LTE FDD and LTE TDD.

TCP Port 5

Indicates port 5 to which TPE is to be applied. This parameter applies only to LTE FDD and LTE TDD.
