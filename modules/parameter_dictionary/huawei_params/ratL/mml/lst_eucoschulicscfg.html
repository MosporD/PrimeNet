List Parameters Set for UL ICS (LST EUCOSCHULICSCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters related to UL ICS.

Note

None.

Parameters

None.

Example

To list the configurations of UL ICS, run the following command: :
LST EUCOSCHULICSCFG:;
The result is shown as follows:
+++    0        2019-12-05 17:32:29
O&M    #806355999
%%LST EUCOSCHULICSCFG: ;%%
RETCODE = 0  Operation succeeded.

List Parameters Set for UL ICS
------------------------------
UL ICS Algorithm Switch  =  Off
(Number of results = 1)


---    END

Output Description

Field Description

UL ICS Algorithm Switch

Indicates whether to enable UL ICS for a centralized control node. This parameter applies only to LTE TDD networks.
