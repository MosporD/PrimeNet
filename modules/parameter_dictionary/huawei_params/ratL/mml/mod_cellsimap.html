Modify Cell SIB-to-SI Mapping (MOD CELLSIMAP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the SIB-to-SI mapping.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Sib6Switch and Sib7Switch are set to On by default. Set Sib6Switch (or Sib7Switch) to Off only when it is desired that UEs in E-UTRAN cells do not reselect UTRAN (or GERAN) cells, for example, during UTRAN (or GERAN) reconstruction.

  • The LTE cell resets when the DlOnlyCellSiSwitch parameter or ForbidCellSiSwitch parameter is modified.

SiSchResRatio System Information Scheduling Resource Ratio

Meaning: Indicates the resource proportion in SI scheduling and controls whether SI-based gap-assisted measurement optimization takes effect. If this parameter is set to 0 (corresponding to the actual value 0), the specified resource proportion in SI scheduling does not take effect and SI-based gap-assisted measurement optimization does not take effect. If this parameter is set to a value within the range of 40 to 100 (corresponding to the actual value within the range of 0.4 to 1.0), the specified resource proportion in SI scheduling and SI-based gap-assisted measurement optimization takes effect to guarantee SI demodulation performance. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0,40~100

Unit: None

Actual Value Range: 0,0.4~1, step: 0.01

MML Default Value: None

Recommended Value: 100(Weak SI Demodulation Performance)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more SI scheduling times, higher bit rate for SI transmissions at a single time, and weaker SI demodulation performance of UEs at a single time.

A larger value of this parameter results in the opposite effects.

If this parameter is set to 0, SI-based gap-assisted measurement optimization is disabled, and the impact of gap-assisted measurements on SI is relatively small due to possible multiple SI transmissions.

If this parameter is set to a value within the range of 40 to 100, SI-based gap-assisted measurement optimization is enabled so that each UE performs gap-assisted measurements and demodulates SI at different times. The impact of gap-assisted measurements on SI decreases and SI demodulation performance of UEs increases. However, the transmission times of SRI/SRS/CQI may be affected, and related network performance (including uplink throughput, downlink throughput, and MOS) deteriorates.

Applicable Mode: L-FDD, L-TDD

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SibPagingOptCtrlSwitch:

If this option is selected, the success rate of system information update increases in the scenario where both LTE cells and CDMA cells are deployed. As a result, the RRC connection setup success rate increases. However, if the LBBPc is used, it is more likely that RRC connection setup success rate decreases in large traffic scenarios.

If this option is deselected, there is a possibility that system information update fails in the scenario where both LTE cells and CDMA cells are deployed, which leads to a decrease in the RRC connection setup success rate.

Sib12BroadcastOptSwitch:

When this option is selected, UEs that receive CMAS paging messages earlier than other UEs receive CMAS messages earlier. The reception delay of the UEs is shorter. However, the number of SIB12 messages broadcast by the eNodeB is large, and therefore a large amount of air interface resources are occupied.

When this option is deselected, all UEs receive CMAS messages after CMAS paging is complete. The reception delay of UEs is long, but the number of SIB12 messages broadcast by the eNodeB is small, and therefore a small amount of air interface resources are occupied.

MibRepetitionCtrlOptSwitch MIB Repetition Control Opt Switch

Meaning: Indicates whether to enable optimization of repeated MIB transmission. If this parameter is set to OFF, the optimization is disabled. For LTE FDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 9. For LTE TDD cells, the eNodeB repeatedly transmits MIBs in subframes 0 and 5. If this parameter is set to ON, the optimization is enabled, and the eNodeB transmits MIBs only in subframe 0. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to OFF, the eNodeB repeatedly transmits MIBs in subframes 0 and 9 for LTE FDD cells, and in subframes 0 and 5 for LTE TDD cells. In this case, eMTC coverage enhancement is supported. However, repeated MIB transmission consumes extra downlink PRB resources, lowering the peak LTE cell throughput and user-perceived throughput. If this parameter is set to ON, optimization of repeated MIB transmission is enabled, and the eNodeB transmits MIBs only in subframe 0. In this case, eMTC coverage gains are limited, and the peak LTE cell throughput and user-perceived throughput are not affected.
