List PrbPdcchCeConfig Configuration in an NB-IoT Cell (LST PRBPDCCHCECONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the coverage-level-specific PDCCH configuration.

Note

None.

Meaning: Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

MML Default Value: None

CoverageLevel Coverage Level

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to NB-IoT.

PRB ID

Indicates the ID that uniquely specifies a PRB in an NB-IoT cell. This parameter applies only to NB-IoT.

Coverage Level

Indicates the UE's coverage level. The value 0 indicates 0 dB coverage enhancement; the value 1 indicates 10 dB coverage enhancement; and the value 2 indicates 20 dB coverage enhancement. This parameter applies only to NB-IoT.

PDCCH Maximum Repetition Count

Indicates the maximum number of PDCCH repetitions. The PDCCH period factor multiplied by the maximum number of PDCCH repetitions is a PDCCH period (unit: ms).

Multiple PDCCH periods without PDCCH resources are generated when this parameter is set to REP_1(REP_1) and the PdcchPeriodFactor parameter is set to G_4(G_4) or when this parameter is set to REP_4(REP_4) and the PdcchPeriodFactor parameter is set to G_2(G_2).

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is one of the preceding configurations, it is recommended that the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO be set to REP_1(REP_1) and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO be set to a value greater than or equal to MCS_2(MCS2). This is to avoid UE access failures caused by RAR resource allocation failures within the RAR window.

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is not one of the preceding combinations and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value less than MCS_2(MCS2), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.74. This is to avoid UE access failures caused by RAR resource allocation failures within the RAR window.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_2(MCS2) and less than MCS_5(MCS5), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.3.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_5(MCS5) and less than MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.87.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.43.

When the PdcchMaxRepetitionCnt parameter is set to REP_1(REP_1) or REP_2(REP_2), the product of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameter values must be greater than or equal to 1/2. When the PdcchMaxRepetitionCnt parameter is set to REP_4(REP_4), the product of the PdcchMaxRepetitionCnt and PdcchTransRptCntFactor parameter values must be greater than or equal to 1. This parameter applies only to NB-IoT.

PDCCH Period Factor

Indicates the PDCCH period factor. The PDCCH period factor multiplied by the maximum number of PDCCH repetitions is the PDCCH period.

Multiple PDCCH periods without PDCCH resources are generated when this parameter is set to G_4(G_4) and the PdcchMaxRepetitionCnt parameter is set to REP_1(REP_1) or when this parameter is set to G_2(G_2) and the PdcchMaxRepetitionCnt parameter is set to REP_4(REP_4).

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is one of the preceding configurations, it is recommended that the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO be set to REP_1(REP_1) and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO be set to a value greater than or equal to MCS_2(MCS2). This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

If the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter configuration is not one of the preceding combinations and the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value less than MCS_2(MCS2), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.74. This is to avoid UE access failures caused by RAR resource allocation failure within the RAR window.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_2(MCS2) and less than MCS_5(MCS5), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 1.3.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_5(MCS5) and less than MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.87.

When the DlInitialMcs parameter in the PrbDlSchCeAlgo MO is set to a value greater than or equal to MCS_9(MCS9), it is recommended that the product of the PdcchMaxRepetitionCnt and PdcchPeriodFactor parameter values be greater than the value of the DlInitialTransRptCount parameter in the PrbDlSchCeAlgo MO multiplied by 0.43.

This parameter applies only to NB-IoT.

PDCCH Initial Trans Rept Count Factor

Indicates the factor of the number of repeated PDCCH initial transmissions. The number of repeated PDCCH initial transmissions equals this parameter multiplied by the maximum number of PDCCH repetitions. This parameter applies only to NB-IoT.

PDCCH Offset

Indicates the start position offset for the NPDCCH search space. It is recommended that this parameter be set to different values for the three coverage levels when the percentages of UEs at each coverage level are basically the same. This parameter applies only to NB-IoT.
