List HeNbTacRangeGroup (LST HENBTACRANGEGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the HeNB TAC range group.

Note

None.

Parameters

ID Name Description
HeNbTacRaGId HeNB TAC Range Group ID

Meaning: Indicates the ID of the TAC range group of HeNBs in macro-micro handover scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list a HeNbTacRangeGroup, HeNbTacRaGId is 0.
The result is shown as follows:
+++    HUAWEI         2016-08-15 17:30:59
O&M    #806355154
%%LST HENBTACRANGEGROUP: HeNbTacRaGId=0;%%
RETCODE = 0  Operation succeeded.

List HeNbTacRangeGroup
----------------------
HeNB TAC Range Group ID  =  0
         TAC Start Mark  =  50
           TAC End Mark  =  100
(Number of results = 1)


---    EN

Output Description

Field Description

HeNB TAC Range Group ID

Indicates the ID of the TAC range group of HeNBs in macro-micro handover scenarios. This parameter applies only to LTE FDD and LTE TDD.

TAC Start Mark

Indicates the start TAC of the special TAC range group of HeNBs. This parameter value must be less than or equal to the TacEnd parameter value. 3GPP specifications define that the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration. This parameter applies only to LTE FDD and LTE TDD.

TAC End Mark

Indicates the end TAC of the special TAC range group of HeNBs. This parameter value must be greater than or equal to the TacStart parameter value. 3GPP specifications define that the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration. This parameter applies only to LTE FDD and LTE TDD.
