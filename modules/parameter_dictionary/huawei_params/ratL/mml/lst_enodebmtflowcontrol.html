List Enodeb Mt Flow Control (LST ENODEBMTFLOWCONTROL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list eNodeB MT flow control parameter configurations.

Note

None.

Parameters

None.

Example

To list the configurations of eNodeB maintenance and test flow control:
LST ENODEBMTFLOWCONTROL:;
The result is shown as follows:
+++    0        2019-12-05 17:31:53
O&M    #806355979
%%LST ENODEBMTFLOWCONTROL: ;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

High-Priority UE MT Flow Control Level

Indicates the MT flow control level for the cell DT and internal CHRs of high-priority UEs. A larger value (non-zero) of this parameter leads to a higher flow control threshold for the cell DT and internal CHRs of high-priority UEs. If this parameter is set to 0, the flow control level is not configurable. For the definition of high-priority UEs, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

CHR Flow Control Switch

Indicates whether to enable flow control on external CHRs. ChrFlowControlSwitch: Indicates whether to enable enhanced flow control on external CHRs. If this option is selected, the number of external CHR sampling points is reduced to decrease the system load and improve user experience. If this option is deselected, the number of external CHR sampling points is not reduced, and the system load is not affected. This option applies only to LTE FDD and LTE TDD.

ChrUeFlowControlOptSwitch: Indicates whether to optimize UE-specific flow control on external CHRs. If this option is selected, the period of UE-specific flow control on external CHRs is shortened to improve the flow control effect. If this option is deselected, flow control on external CHRs is not affected. This option applies only to LTE FDD and LTE TDD.

ChrCceFlowControlOptSwitch: Indicates whether to optimize CCE-usage-based flow control on external CHRs. If this option is selected, the formula for calculating the CCE usage is optimized to increase the CHRs reported in light-load scenarios with poor signal quality. If this option is deselected, flow control on external CHRs is not affected. This option applies only to LTE TDD.

ChrQueueFlowControlOptSwitch: Indicates whether to optimize UE-specific flow control based on queue congestion for external CHRs. If this option is selected, the system monitors the congestion state of message queues and improves flow control for external CHRs. If this option is deselected, flow control for external CHRs remains unchanged. This option applies only to LTE FDD and LTE TDD.

SIG Log MT Flow Control Level

Indicates the CPU flow control level of SIG logs on the main control board. A larger value of this parameter indicates a higher CPU threshold for triggering the main control board to discard SIG data and a lower probability of discarding SIG logs due to flow control. 0 indicates that SIG log reporting is disabled on the main control board. This parameter applies only to LTE FDD and LTE TDD.

TRC Log MT Flow Control Level

Indicates the CPU flow control level of TRC logs on the main control board. A larger value of this parameter indicates a higher CPU threshold for triggering the main control board to discard TRC data and a lower probability of discarding TRC logs due to flow control. 0 indicates that TRC log reporting is disabled on the main control board. This parameter applies only to LTE FDD and LTE TDD.
