Modify User Priority (MOD USERPRIORITY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of policies applied to UEs running unlimited services in an eNodeB.

Note

None.

Parameters

ID Name Description
ArpSchSwitch ARP Schedule Switch

Meaning: Indicates whether to enable ARP- and QCI-based user-differentiated scheduling. If the ArpPrioritySchSwitch option is selected, ARP- and QCI-based user-differentiated scheduling is enabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 do not take effect. If the ArpPrioritySchSwitch option is deselected, ARP- and QCI-based user-differentiated scheduling is disabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 take effect. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: ArpPrioritySchSwitch(ArpPrioritySchSwitch)

Unit: None

Actual Value Range: ArpPrioritySchSwitch

MML Default Value: None

Recommended Value: ArpPrioritySchSwitch:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If the ArpPrioritySchSwitch option is selected, services with higher ARP and QCI priorities have a heavier scheduling weight and larger throughput.

If the ArpPrioritySchSwitch option is deselected, the network performance is not affected.

Applicable Mode: L-FDD, L-TDD

Example

To modify parameters related to user priority as follows: ARP Schedule Switch: ArpPrioritySchSwitch-1, ARP1 Priority: SILVER, run the following command:
MOD USERPRIORITY: ArpSchSwitch=ArpPrioritySchSwitch-1, Arp1Priority=SILVER;
