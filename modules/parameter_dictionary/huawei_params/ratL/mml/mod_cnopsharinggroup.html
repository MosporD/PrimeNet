Modify CN Operator Sharing Group Configuration (MOD CNOPSHARINGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a carrier-sharing operator group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The primary operators of different carrier-sharing operator groups cannot be the same. In a carrier-sharing operator group, the primary operator and secondary operators cannot be the same.

  • If the CnOpSharingGroup MO is referenced by the following associated MOs such as, S1Interface, S1, X2Interface, X2, Cell, operators to which these MOs belong must be in the carrier-sharing operator group. In this case, when running this command, ensure that the operator to which these MOs belong must be in the carrier-sharing operator group after the command execution. Otherwise, the execution of this command fails

  • When the eNodeB works in hybrid RAN sharing mode, if the primary operator is changed, the eNodeB automatically resets up S1 interfaces, X2 interfaces, and cells in the RAN sharing group to make the modifications to this parameter take effects. In this case, services are interrupted.

Parameters

ID Name Description
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group. This parameter uniquely specifies a carrier-sharing operator group.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
PrimaryOperatorId Primary Operator ID

Meaning: Indicates the ID of the primary operator in a carrier-sharing operator group.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PrimaryOperatorId and SecondaryOperatorId referenced by SecondaryOperatorList in the same CnOpSharingGroup MO must be set to different values.
  • The value of PrimaryOperatorId in each CnOpSharingGroup MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the configuration of a carrier-sharing operator group with the parameters as follows: CN Operator Sharing Group ID: 0, Primary Operator ID: 1, run the following command:
MOD CNOPSHARINGGROUP: CnOpSharingGroupId=0, PrimaryOperatorId=1;
