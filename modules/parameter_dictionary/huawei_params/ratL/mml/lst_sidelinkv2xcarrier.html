List a Sidelink V2X Carrier (LST SIDELINKV2XCARRIER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query static attributes for sidelink V2X carriers.

Note

None.

Parameters

ID Name Description
SidelinkV2xCarrierId Sidelink V2X Carrier ID

Meaning: Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list a sidelink V2X carrier with the sidelink V2X carrier ID of 0, run the following command:
LST SIDELINKV2XCARRIER: SidelinkV2xCarrierId=0;
The result is shown as follows:

Output Description

Field Description

Sidelink V2X Carrier ID

Indicates the sidelink V2X carrier ID. It uniquely identifies a sidelink V2X carrier within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Sidelink V2X EARFCN

Indicates the sidelink V2X EARFCN. This parameter can be set to a value ranging from 46790 to 55239. This parameter applies only to LTE FDD and LTE TDD.

Maximum Sidelink V2X Transmit Power(dBm)

Indicates the maximum transmit power of a UE for V2X sidelink transmission. This parameter applies only to LTE FDD and LTE TDD.

Sidelink V2X Bandwidth

Indicates the operating carrier bandwidth for sidelink V2X. Sidelink adopts the same RX and TX bandwidths. This parameter applies only to LTE FDD and LTE TDD.
