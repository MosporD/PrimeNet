Modify Cell Interference Control Parameter (MOD CELLINTRFCTRLPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to change the settings of interference control parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlRbAllocationDirection Downlink RB Allocation Direction

Meaning: Indicates the RB allocation direction. If this parameter is set to HIGH_TO_LOW, RB allocation starts from the high end of the frequency band. If this parameter is set to LOW_TO_HIGH, RB allocation starts from the low end of the frequency band. This parameter applies only to LTE FDD.

GUI Value Range: LOW_TO_HIGH(LOW_TO_HIGH), HIGH_TO_LOW(HIGH_TO_LOW)

Unit: None

Actual Value Range: LOW_TO_HIGH, HIGH_TO_LOW

MML Default Value: None

Recommended Value: LOW_TO_HIGH

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to HIGH_TO_LOW, the low end of the frequency band causes less interference to neighboring frequency bands. When this parameter is set to LOW_TO_HIGH, there is no impact.

Applicable Mode: L-FDD
HighIntrfStateDuration High Intrf State Duration

Meaning: Indicates the duration in which the cell is in the high interference state. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: s

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value other than 0 and the RB usage limit for the high interference state is set to a value less than 100, the eNodeB proactively restricts the number of downlink RBs for allocation when the cell is in the high interference state. As a result, the perceived data rates of UEs decrease and delays increase. However, downlink interference to neighboring frequency bands can be mitigated.

Applicable Mode: L-FDD
HighIntrfStateRbUsageThld High Intrf State DL RB Usage Threshold

Meaning: Indicates the upper limit to the downlink wideband RB usage when the cell is in the high interference state. In this cell, the downlink RB usage in each TTI cannot exceed this limit. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value less than 100 and the high interference duration is set to a value other than 0, the eNodeB proactively restricts the number of downlink RBs for allocation when the cell is in the high interference state. As a result, the perceived data rates of UEs decrease and delays increase. However, downlink interference to neighboring frequency bands can be mitigated.

Applicable Mode: L-FDD
LowIntrfStateDuration Low Intrf State Duration

Meaning: Indicates the duration in which the cell is in the low interference state. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: s

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value other than 0 and the RB usage limit for the low interference state is set to a value less than 100, the eNodeB proactively restricts the number of downlink RBs for allocation when the cell is in the low interference state. As a result, the perceived data rates of UEs decrease and delays increase. However, downlink interference to neighboring frequency bands can be mitigated.

Applicable Mode: L-FDD
LowIntrfStateRbUsageThld Low Intrf State DL RB Usage Threshold

Meaning: Indicates the upper limit to the downlink wideband RB usage when the cell is in the low interference state. In this cell, the downlink RB usage in each TTI cannot exceed this limit. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value less than 100 and the low interference duration is set to a value other than 0, the eNodeB proactively restricts the number of downlink RBs for allocation when the cell is in the low interference state. As a result, the perceived data rates of UEs decrease and delays increase. However, downlink interference to neighboring frequency bands can be mitigated.

Applicable Mode: L-FDD

Example

To modify the cell interference control parameter as follows: Local cell ID: 0, Downlink RB Allocation Direction: LOW_TO_HIGH, run the following command: 
MOD CELLINTRFCTRLPARAM: LocalCellId=0, DlRbAllocationDirection=LOW_TO_HIGH;
