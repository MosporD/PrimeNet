Remove Neighboring NR Frequency (RMV NRNFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more records of neighboring NR frequencies.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is a risky command and you are advised to run this command during off-peak hours.

    If no parameter is specified, all records of neighboring NR frequencies are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If some parameters are specified, records that match the parameter settings are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If all parameters are specified, the record that matches all the parameter settings is removed after the command is executed.

  • Before running this command, ensure that no neighboring NR cell is configured with this neighboring NR frequency.

  • This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Meaning: Indicates the downlink SSB ARFCN of the neighboring NR cell. This parameter applies only to LTE FDD and LTE TDD.

Example

To remove a neighboring NR frequency with the parameters as follows: Local cell ID: 0, Downlink ARFCN: 151600, run the following command:
RMV NRNFREQ: LocalCellId=0, DlArfcn=151600;
