Modify Cell PRB Valuation MLB Parameter (MOD CELLPRBVALMLB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of PRB-evaluation-based MLB.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PrbValMlbTrigThd PRB Valuation MLB Trigger Threshold

Meaning: Indicates the threshold of the PRB evaluation value for triggering MLB based on the PRB evaluation value. This parameter takes effect only when the MlbTriggerMode parameter in the CellMLB MO is set to PRB_ONLY or PRB_OR_UE_NUMBER and the PrbLoadCalcMethod parameter in the CellMLB MO is set to PRB_VALUATION_WITH_CTRL or PRB_VALUATION_NO_CTRL. If the number of UEs meets the minimum UE quantity condition for triggering MLB and the PRB evaluation value is greater than or equal to the sum of this threshold and the load offset, MLB is triggered. If the number of UEs meets the minimum UE quantity condition for terminating MLB or the PRB evaluation value is less than this threshold, MLB is terminated. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, load balancing cannot be triggered when the load is high. If this parameter is set to a small value, excessive signaling interactions and handovers are caused due to premature triggering of load balancing based on the PRB evaluation value.

Applicable Mode: L-FDD, L-TDD
PrbValMlbAdmitThd PRB Valuation MLB Admit Threshold

Meaning: Indicates the threshold of the PRB evaluation value for determining a target neighboring cell for inter-frequency MLB. This parameter takes effect only when the MlbTriggerMode parameter in the CellMLB MO is set to PRB_ONLY or PRB_OR_UE_NUMBER and the PrbLoadCalcMethod parameter in the CellMLB MO is set to PRB_VALUATION_WITH_CTRL or PRB_VALUATION_NO_CTRL. If the PRB evaluation value of a neighboring cell is less than this threshold, this neighboring cell can be selected as a target cell for MLB. If the PRB evaluation value of a neighboring cell is greater than or equal to this threshold, this neighboring cell cannot be selected as a target cell for MLB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, the target cell allows MLB-based incoming UEs even when the load of the target cell is high. If this parameter is set to a small value, the target cell rejects MLB-based incoming UEs even when the load of the target cell is low.

Applicable Mode: L-FDD, L-TDD
MlbUeSelectPrbValThd Mlb UE Selection PRB Valuation Threshold

Meaning: Indicates the threshold of the UE-specific PRB evaluation value for selecting UEs for MLB. A UE is transferred for MLB based on PRB evaluation only when the downlink or uplink PRB evaluation value of the UE is higher than the value of this parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50

Unit: %

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a larger value, a smaller number of UEs are selected for MLB, and the MLB is more difficult to be triggered, which cannot help maximize the cell throughput. If this parameter is set to a smaller value, a larger number of UEs are selected for MLB, and the MLB is easier to be triggered, which helps maximize the cell throughput.

Applicable Mode: L-FDD, L-TDD
PrbValFilterFactor PRB Valuation Filter Factor

Meaning: Indicates the filtering coefficient used to calculate the PRB evaluation value. The filtering value is calculated by weighting the measured PRB evaluation value and historical filtering value based on the filtering coefficient. If this parameter is set to a smaller value, the filtering value is more close to the historical filtering value. If this parameter is set to a larger value, the filtering value is more close to the measured value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the MLB algorithm based on the PRB evaluation with the parameters as follows: Local Cell ID: 0, PRB Valuation MLB Trigger Threshold(%): 79, PRB Valuation MLB Admit Threshold(%): 70, Mlb UE Selection PRB Valuation Threshold: 20, run the following command:
MOD CELLPRBVALMLB: LocalCellId=0, PrbValMlbTrigThd=79, PrbValMlbAdmitThd=70, MlbUeSelectPrbValThd=20;
