Modify Enhanced Inter-cell Interference Coordination Information (MOD CELLEICIC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of TDM-based eICIC.

Note

In a Cell, if FddTddInd is set to CELL_TDD, and SubframeAssignment is set to SA1, then the AbsPattern in CellEicic could not have subframe 3 and subframe 8.

Parameters

AbsPattern Abs pattern

Meaning: Indicates the ABS pattern when static TDM-based eICIC is enabled. This parameter is valid only if static TDM-based eICIC is enabled. Different ABS patterns indicate different ABS quantities and ABS numbers in the same period. An ABS pattern is a 40-bit bitmap. For details, see the definition of ABS Pattern Info of X2 signaling in 3GPP TS 36.423. All cells throughout the network must be configured with the same ABS pattern. This parameter is valid only if static TDM-based eICIC is enabled. This parameter applies only to LTE TDD.

GUI Value Range: SUBFRAME_0_TWO_PER_20(Two ABS with 0 per 20 ms), SUBFRAME_3_TWO_PER_20(Two ABS with 3 per 20 ms), SUBFRAME_4_TWO_PER_20(Two ABS with 4 per 20 ms), SUBFRAME_5_TWO_PER_20(Two ABS with 5 per 20 ms), SUBFRAME_8_TWO_PER_20(Two ABS with 8 per 20 ms), SUBFRAME_9_TWO_PER_20(Two ABS with 9 per 20 ms), SUBFRAME_4_9_THREE_PER_20(Three ABS with 4/9 per 20 ms), SUBFRAME_0_5_THREE_PER_20(Three ABS with 0/5 per 20 ms), SUBFRAME_3_8_THREE_PER_20(Three ABS with 3/8 per 20 ms), SUBFRAME_3_4_9_THREE_PER_20(Three ABS with 3/4/9 per 20 ms), SUBFRAME_0_5_FOUR_PER_20(Four ABS with 0/5 per 20 ms), SUBFRAME_4_9_FOUR_PER_20(Four ABS with 4/9 per 20 ms), SUBFRAME_3_8_FOUR_PER_20(Four ABS with 3/8 per 20 ms), SUBFRAME_0_4_9_FIVE_PER_20(Five ABS with 0/4/9 per 20 ms), SUBFRAME_0_5_9_FIVE_PER_20(Five ABS with 0/5/9 per 20 ms), SUBFRAME_3_4_8_9_FIVE_PER_20(Five ABS with 3/4/8/9 per 20 ms), SUBFRAME_0_4_8_SIX_PER_20(Six ABS with 0/4/8 per 20 ms), SUBFRAME_0_3_5_8_EIGHT_PER_20(Eight ABS with 0/3/5/8 per 20 ms), SUBFRAME_INVALID(Invalid SubFrame)

Unit: None

Actual Value Range: SUBFRAME_0_TWO_PER_20, SUBFRAME_3_TWO_PER_20, SUBFRAME_4_TWO_PER_20, SUBFRAME_5_TWO_PER_20, SUBFRAME_8_TWO_PER_20, SUBFRAME_9_TWO_PER_20, SUBFRAME_4_9_THREE_PER_20, SUBFRAME_0_5_THREE_PER_20, SUBFRAME_3_8_THREE_PER_20, SUBFRAME_3_4_9_THREE_PER_20, SUBFRAME_0_5_FOUR_PER_20, SUBFRAME_4_9_FOUR_PER_20, SUBFRAME_3_8_FOUR_PER_20, SUBFRAME_0_4_9_FIVE_PER_20, SUBFRAME_0_5_9_FIVE_PER_20, SUBFRAME_3_4_8_9_FIVE_PER_20, SUBFRAME_0_4_8_SIX_PER_20, SUBFRAME_0_3_5_8_EIGHT_PER_20, SUBFRAME_INVALID

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In a HetNet with static TDM eICIC enabled, an appropriate ABS pattern set based on REs configured for micro base stations increases the downlink cell edge throughput, while ensuring that the average downlink throughput on the entire network does not decrease. An inappropriate ABS pattern lowers the downlink throughput on the entire network.

Applicable Mode: L-TDD
EicicMeasureEnable Eicic Measure Enable

Meaning: Indicates whether UEs are allowed to send measurement reports for event A3 during enhanced inter-cell interference coordination (eICIC). The parameter value ENABLE indicates that UEs are allowed to send measurement reports for event A3 during eICIC. The parameter value DISABLE indicates that UEs are not allowed to send measurement reports for event A3 during eICIC, and in this case the eNodeB cannot determine whether to enable eICIC in different scenarios. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE, UEs are allowed to send measurement reports for event A3 during eICIC, increasing overheads in the PUSCH and decreasing uplink capacity of the cell.

Applicable Mode: L-FDD, L-TDD
A3Offset eICIC A3 Offset

Meaning: Indicates the offset for event A3 during enhanced inter-cell interference coordination (eICIC). This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates that a neighboring cell must have better signal quality for the reporting of event A3. A smaller value indicates that the requirement on the neighboring cell signal quality for reporting event A3 can be met easier. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of reporting event A3 during eICIC and accordingly a smaller number of UEs that report the related measurements. As a result, service quality is not guaranteed for cell edge users (CEUs), causing drops in CEU throughput and cell capacity. A smaller value of this parameter results in a higher probability of reporting event A3 during eICIC and accordingly a larger number of UEs that report the related measurements, increasing overheads in the PUSCH and decreasing uplink capacity of the cell.

Applicable Mode: L-FDD, L-TDD

It is recommended that the ABS adjustment period (unit: s) be equal to the number of macro cells of the local eNodeB multiplied by the number of micro cells in the local macro cell. This parameter applies only to LTE FDD.

Impact on Radio Network Performance: A larger parameter value results in a lower frequency of adjusting the ABS patterns of macro and micro cells and therefore a lower system load. A smaller parameter value results in the opposite effects.

Applicable Mode: L-FDD

StatPeriod Statistical Period

Meaning: Indicates the measurement period for automatic configuration of macro-micro associations. The micro cell counts the number of times each macro cell is included in measurement reports within each period. To prevent network performance deterioration for UEs, the macro-micro associations are not updated immediately when a measurement period approaches its end. Instead, the update is triggered at the specified start time. This parameter takes effect only in micro cells. You are advised to set this parameter to a multiple of 5. If this parameter is not set to a multiple of 5, the actually effective parameter value is extended to a multiple of 5. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~43200

Unit: min

Actual Value Range: 1~43200

MML Default Value: None

Recommended Value: 10080

Parameter Relationship:

-Others:

A larger value of this parameter results in a lower probability of reflecting the actual network condition changes and achieving the optimal effect of TDM eICIC.

Meaning: Indicates the threshold of the equivalent CCE usage for enabling interference coordination for handover zones along high-speed railways.
