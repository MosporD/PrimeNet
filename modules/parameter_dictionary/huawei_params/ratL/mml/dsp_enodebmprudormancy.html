Display eNodeB MPRU Dormancy Status (DSP ENODEBMPRUDORMANCY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to display the MPRU dormancy state of an eNodeB. When the time and load conditions are met, the MPRUs available for dormancy are displayed in the command output.

Note

None.

Parameters

None.

Example

To query the MPRU dormancy state of an eNodeB, run the following command:
DSP ENODEBMPRUDORMANCY:;

The result is shown as follows:

+++    HUAWEI        2018-11-28 19:37:46
O&M    #806354959
%%DSP ENODEBMPRUDORMANCY:;%%
RETCODE = 0  Operation succeeded.

Display eNodeB MPRU Dormancy Status
-----------------------------------
MPRU Cabinet Number  MPRU Subrack Number  MPRU Slot Number  Dormancy State

0                    61                   0                 DISABLED       
0                    62                   0                 DISABLED       
0                    63                   0                 ENABLED       
     
(Number of results = 3)


---    END

Output Description

Field Description

MPRU Cabinet Number

Indicates the cabinet number of the MPRU. This parameter applies only to LTE FDD and LTE TDD.

MPRU Subrack Number

Indicates the subrack number of the MPRU. This parameter applies only to LTE FDD and LTE TDD.

MPRU Slot Number

Indicates the slot number of the MPRU. This parameter applies only to LTE FDD and LTE TDD.

Dormancy State

Indicates the MPRU dormancy state determined based on LTE coverage analysis results. The actual dormancy state depends on whether conditions, such as the RRU dormancy switch setting and service load, are met. If this parameter is set to ENABLED, the MPRU enters dormancy when the RRU dormancy switch setting, time, and load conditions are met. If this parameter is set to DISABLED, MPRU does not enter dormancy. This parameter applies only to LTE FDD and LTE TDD.
