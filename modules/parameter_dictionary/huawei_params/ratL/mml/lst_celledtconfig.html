List Cell EDT Configuration (LST CELLEDTCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list EDT parameter settings of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To list the cell edt configurations of a cell:
LST CELLEDTCONFIG: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to NB-IoT.

EDT DL Data Waiting Timer(100ms)

Indicates the length of the timer governing the period during which the eNodeB waits for downlink data from the core network when a UE initiates an EDT service. The timer length specified by this parameter must be less than the timer length specified by the CellRachCECfg.EdtContentionResTimer parameter when the EDT service does not use early contention resolution. Otherwise, the UE EDT service cannot be normally performed.

The eNodeB starts this timer when it receives an RRCConnectionResume message carrying data or an RRCEarlyDataRequest message.

If downlink data indication is received from the core network before the timer expires or the volume of downlink data that arrives before the timer expires is larger than the maximum data volume allowed for an EDT service, the timer will be stopped.

After the timer expires, the eNodeB starts EDT in the downlink. This parameter applies only to NB-IoT.

EDT Early Contention Resolution Mode

Indicates the early contention resolution mode used for EDT in a cell. If this parameter is set to OFF, early contention resolution is not supported. In this case, SRB0 and the contention resolution MCE must be delivered at the same time. If this parameter is set to SRB0_CONTENTION_RES_SPLIT_SCH, SRB0 and the contention resolution MCE are separately scheduled. If this parameter is set to ADAPTIVE, the cell adaptively determines whether to use early contention resolution based on the value of the contention resolution timer. This parameter applies only to NB-IoT.

Preferential Tone Num for EDT Multi-tone Sch

Indicates the number of tones preferentially used when multi-tone scheduling is used for EDT services. This parameter takes effect only for UEs at coverage level 0. Single-tone scheduling is used for UEs at coverage levels 1 and 2. This parameter applies only to NB-IoT.

EDT Sch Strategy

Indicates the scheduling policy used when there are EDT services in a cell. If this parameter is set to NON_EDT_PRIORITY, scheduling of non-EDT services is preferentially guaranteed. If this parameter is set to DEFAULT, scheduling is based on fairness without differentiating between service types. If this parameter is set to EDT_PREFERRED, scheduling of EDT services is preferentially guaranteed. This parameter applies only to NB-IoT.

Number of EDT TBS Type

Indicates the number of different TBSs that can be used for the transmission of Msg3 for EDT. If this parameter is set to ONE, the TBS used for the transmission of Msg3 for EDT initiated by a UE must be the same as that used for the transmission of system information. If this parameter is set to TWO, a maximum of two different TBSs can be used for the transmission of Msg3 for EDT. If this parameter is set to FOUR, a maximum of four different TBSs can be used for the transmission of Msg3 for EDT. For details, see 3GPP TS 36.213. This parameter applies only to NB-IoT.

EDT Algorithm Switch

Indicates whether to enable EDT.

EDT_SWITCH: Indicates whether to enable EDT in the cell. If this option is selected, the cell supports EDT and UEs can perform EDT services in the cell. If this option is deselected, the cell does not support EDT. This option applies only to NB-IoT.

EDT_L_VALUE_COMPAT_SWITCH: Indicates whether to determine the value of L based on Msg3 for EDT. If this option is selected, the value of L for NB-IoT UEs involved in single-tone transmission is determined based on the repetition count of Msg3 on the NPUSCH. If this option is deselected, the value of L is fixed at 1 for NB-IoT UEs involved in single-tone transmission. This option applies only to NB-IoT.
