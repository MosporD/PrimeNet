List RACH Configuration (LST RACHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration information of the Random Access Channel (RACH).

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the RACH configuration with Local cell ID of 1, run the following command:
LST RACHCFG: LocalCellId=1;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

PRACH Start Time Config Indication

Indicates whether to allow configuration of the PRACH start time. When this parameter is set to NOT_CFG, the PRACH start time is not configurable. The PRACH start time for coverage level 0 is always 8 ms. The PRACH start time for coverage level 1 is determined based on the following factors: the sum of the PRACH start time and PRACH time length for coverage level 0, and the restriction that the PRACH start time interval between two adjacent coverage levels is not less than 40 ms. The PRACH start time for coverage level 2 is determined in a way similar to that for determining the PRACH start time for coverage level 1. If there are PRACH resources used for early data transmission (EDT), the positions of the EDT PRACH subcarriers and those of the common PRACH subcarriers cannot overlap, and the start time and transmission interval of the EDT PRACH must be the same as those of the common PRACH. When this parameter is set to CFG, the PRACH start time for each coverage level is configurable. The PRACH start time interval between two adjacent coverage levels must not be less than 40 ms. Otherwise, cells cannot be activated. This parameter applies only to NB-IoT.

Power Ramping Step CE1(dB)

Indicates the ramping step of preamble power at coverage level 1. If multiple access attempts over the NPRACH fail, the UE increases the TX power for random access preambles by a step specified by this parameter to ensure successful access.

For details about this parameter, see 3GPP TS 36.321. This parameter is optional. The value NOT_CFG indicates that this parameter is not configured. This parameter applies only to NB-IoT.

Preamble Initial Received Target Power CE1(dBm)

Indicates the eNodeB-expected target receive power level of the NPRACH preambles sent from NB-IoT UEs at coverage level 1.

For details about this parameter, see 3GPP TS 36.321. This parameter is optional. The value NOT_CFG indicates that this parameter is not configured. This parameter applies only to NB-IoT.

Power ramping step(dB)

Indicates the step by which the TX power for random access preambles is increased each time after a RACH access failure. If multiple access attempts over the PRACH fail, the UE increases the TX power for random access preambles by a step specified by this parameter each time after an access failure to ensure successful access.

For details, see 3GPP TS 36.321.

Preamble Initial Received Target Power(dBm)

Indicates the eNodeB-expected target receive power of PRACH preambles when PRACH preamble format 0 is used and the requirements for preamble detection performance are met. For NB-IoT cells, the values DBM_130(-130dBm), DBM_128(-128dBm), DBM_126(-126dBm), DBM_124(-124dBm), and DBM_122(-122dBm) are added to extend the lower power limit, and the values DBM_88(-88dBm), DBM_86(-86dBm), DBM_84(-84dBm), DBM_82(-82dBm), and DBM_80(-80dBm) are added to extend the upper power limit. These added values can be configured only for NB-IoT cells.

For details about this parameter, see 3GPP TS 36.321.

Message size of select group A(bit)

Indicates the threshold for determining the size of Msg3 when a UE selects a preamble from random access preamble group A during a random access procedure.

For details, see 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

PRACH Frequency Offset

Indicates the offset for the starting frequency-domain position of PRACH RBs. The PrachFreqOffset parameter takes effect only when the PrachFreqOffsetStrategy parameter is set to MANUAL or the PucchSwitch option of the PucchAlgoSwitch parameter is deselected for an LTE FDD cell whose PrachFreqOffsetStrategy is not set to FULLY_AUTOMATIC. This parameter applies only to LTE FDD and LTE TDD.

Indication of PRACH Configuration Index

Indicates whether to configure a PRACH configuration index for a cell. If an LTE TDD cell is established on an LBBPc, the PRACH configuration index configured for the cell does not take effect. When the eMTC function takes effect, this parameter does not take effect. In this case, LTE PRACH configurations will be reconfigured, and the PRACH configuration index is determined by eNodeB based on the corresponding the algorithm. This parameter applies only to LTE FDD and LTE TDD.

PRACH Configuration Index

Indicates the PRACH configuration index of a cell. If cells are established on an LBBPc in a 4T4R scenario, the PRACH configuration indexes of these cells must be staggered in the time domain.

If a cell is an ultra-high-speed cell and HighSpeedR14Switch is set to ON, the value of this parameter takes effect only for the 3GPP-defined IE prach-ConfigIndex, but not for the 3GPP-defined IE prach-ConfigIndexHighSpeed-r14. For LTE FDD cells: If PreambleFmt is 0, prach-ConfigIndex is 3 and prach-ConfigIndexHighSpeed-r14 is 5. If PreambleFmt is 1, prach-ConfigIndex is 19 and prach-ConfigIndexHighSpeed-r14 is 21. If PreambleFmt is 2, prach-ConfigIndex is 35 and prach-ConfigIndexHighSpeed-r14 is 37. If PreambleFmt is 3, prach-ConfigIndex is 51 and prach-ConfigIndexHighSpeed-r14 is 53. For LTE TDD cells: If PreambleFmt is 0, prach-ConfigIndex is 3 and prach-ConfigIndexHighSpeed-r14 is 4. If PreambleFmt is 1, prach-ConfigIndex is 23 and prach-ConfigIndexHighSpeed-r14 is 24. If PreambleFmt is 2, prach-ConfigIndex is 33 and prach-ConfigIndexHighSpeed-r14 is 34. If PreambleFmt is 3, prach-ConfigIndex is 43 and prach-ConfigIndexHighSpeed-r14 is 44. This parameter applies only to LTE FDD and LTE TDD.

Maximum number of preamble transmission

Indicates the maximum number of preamble transmission times. For details about this parameter, see 3GPP TS 36.321.

Timer for contention resolution(subframe)

Indicates the period that a UE waits for message 4 (Msg4) during a random access (RA) procedure. This timer starts when a UE initially sends or resends message 3 (Msg3). If the UE receives Msg4 or the NACK to Msg3 before the timer expires, the timer stops. If the UE does not receive either message until the timer expires, the RA fails, and the UE must reinitiate an RA procedure. For details about this parameter, see 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

Maximum number of Msg3 HARQ transmissions

Indicates the maximum number of HARQ retransmissions of the message 3. For details about this parameter, see 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

Random Preamble Ratio

Indicates the proportion of the number of random preambles in a cell to the number of preambles in the cell. The number of random preambles in a cell is calculated by this parameter value multiplied by the number of preambles in the cell. Preambles in a cell can be classified as random preambles and dedicated preambles, which are used for contention-based random access and non-contention-based random access, respectively. For details, see section 5.1.1 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

Random Access preamble Group A Ratio(%)

Indicates the proportion of the number of group A random preambles in a cell to the number of random preambles in the cell. The number of group A random preambles in a cell is calculated by this parameter value multiplied by the number of random preambles in the cell. Preambles in a cell can be classified as random preambles and dedicated preambles, and random preambles are classified into group A random preambles and group B random preambles. For details, see section 5.1.1 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

PRACH Frequency Offset Strategy

Indicates the policy of determining the PRACH frequency-domain offset. If this parameter is set to AUTOMATIC(AUTOMATIC) or FULLY_AUTOMATIC(FULLY_AUTOMATIC), the eNodeB determines the PRACH frequency-domain offset. If this parameter is set to MANUAL(MANUAL), the PRACH frequency-domain offset is specified by the PrachFreqOffset parameter. In an LTE FDD cell, the eNodeB determines the PRACH frequency-domain offset only if this parameter is set to FULLY_AUTOMATIC(FULLY_AUTOMATIC) when the PucchSwitch option of the PucchAlgoSwitch parameter is deselected. In an LTE TDD cell, the parameter value MANUAL(MANUAL) does not take effect when preamble format 4 is used. This parameter applies only to LTE FDD and LTE TDD.

NB-IoT Cyclic Prefix Length

Indicates the PRACH cyclic prefix length, which supports 66.7 us and 266.7 us. This parameter applies only to NB-IoT.

NB-IoT RSRP First Threshold(dBm)

Indicates the RSRP level-1 threshold. When the measured RSRP value of a UE is higher than the RSRP level-1 threshold, the UE initiates random access in the cell at coverage level 0. When the measured RSRP value of a UE is between the RSRP level-1 threshold and RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 1. When the measured RSRP value of a UE is lower than the RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 2. This parameter applies only to NB-IoT.

NB-IoT RSRP Second Threshold(dBm)

Indicates the RSRP level-2 threshold. When the measured RSRP value of a UE is higher than the RSRP level-1 threshold, the UE initiates random access in the cell at coverage level 0. When the measured RSRP value of a UE is between the RSRP level-1 threshold and RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 1. When the measured RSRP value of a UE is lower than the RSRP level-2 threshold, the UE initiates random access in the cell at coverage level 2. This parameter applies only to NB-IoT.

UE RACH Information Report Ratio Threshold(%)

Indicates the threshold of the proportion of the number of random access messages reported by the UE to the number of successful UE access attempts. RACH resource adjustment is not triggered when the proportion is smaller than the threshold.

VoLTE Handover Random Preamble Power Offset(2dB)

Indicates the offset of the target power of preambles sent by VoLTE UEs to be handed over and initially received by the eNodeB to the target power of preambles sent by non-VoLTE UEs and initially received by the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

eMTC PRACH Period

Indicates the eMTC PRACH period. This parameter applies only to LTE FDD and LTE TDD.

NB-IoT Path Loss Coefficient

Indicates the path loss coefficient, which is used in the uplink power control for SR transmission during non-contention-based random access. For details, see 3GPP TS 36.213. This parameter applies only to NB-IoT.

NB-IoT SR P0(dBm)

Indicates the eNodeB-expected target transmit power for SR transmission during non-contention-based random access. The expected transmit power is for normal PRACH demodulation. For details, see 3GPP TS 36.213. This parameter applies only to NB-IoT.
