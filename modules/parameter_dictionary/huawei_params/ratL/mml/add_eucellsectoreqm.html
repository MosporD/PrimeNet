Add Cell Sector Equipment (ADD EUCELLSECTOREQM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to configure sector equipment for a cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

During the modification of the BaseBandEqmId parameter associated with an activated cell, the cell automatically resets if the BaseBandEqmId parameter value is changed to an ID representing a baseband equipment on which the cell is not established.

A cell automatically resets during the modification of the SectorCpriCompression parameter.

The baseband resource allocation mode is changed after the modification of the AutoCfgFlag parameter.

When cell mode is 2RRU, if you want to specify baseband, it is recommended to set same BaseBandEqmId for two EUCELLSECTOREQMs, else baseband will be selected in two BaseBandEqmIds.

BaseBandEqmId Baseband equipment ID

Meaning: Indicates the ID of a piece of baseband equipment that serves the cell.

If this parameter is set to 255 for a cell, baseband equipment is not specified for the cell. In this case, the eNodeB selects BBPs for a cell among all the local available BBPs. The BBP directly connected to the RRU serving the cell is preferentially selected.

If this parameter is set to another value, baseband equipment is specified for the cell. In this case, the cell can use only the BBPs included in the baseband equipment, and the BBP directly connected to the RRU is preferentially selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~23,255

Unit: None

Actual Value Range: 0~23,255

Recommended Value: None

ReferenceSignalPwrMargin Reference Signal Power Margin

Meaning: Indicates the reference signal power headroom of each physical antenna. This parameter is valid only when the MultiRruCellFlag parameter of the Cell MO is set to BOOLEAN_TRUE(True) and the MultiRruCellMode parameter in the Cell MO is set to SFN(SFN) or CELL_COMBINATION(Cell Combination). This parameter applies only to LTE TDD.

If this parameter is set to 0, the parameter does not take effect. That is, the reference signal power headroom of the cell equals the value of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO. If this parameter is set to a non-zero value, the reference signal power headroom of the cell equals this value regardless of the ReferenceSignalPwrMargin parameter in the PDSCHCfg MO set for the sector equipment of the cell.

Unit: 0.1dB

SectorCpriCompression Sector CPRI Compression

Meaning: Indicates the CPRI compression type of the sector equipment. CPRI compression is used in RRU cascading scenarios to enable more RRUs to be cascaded without changing the CPRI data rate. The parameter can be set to NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, or NULL. The parameter value NO_COMPRESSION indicates that CPRI compression is not used. The parameter value NORMAL_COMPRESSION indicates that CPRI compression is used. The parameter value ENHANCED_COMPRESSION indicates that enhanced CPRI compression is used. The parameter value TRIPLEX_COMPRESSION_10M indicates triple CPRI compression for a 10 MHz cell, and this parameter value is applicable only to LTE FDD. The value 3_2_COMPRESSION indicates that the compression ratio of 3.2:1 is used, and this value is applicable only to TDD. The parameter value NULL indicates that this parameter is invalid. The performance of enhanced CPRI compression is better than that of normal CPRI compression. If the eNodeB is equipped with LBBPd boards and the CPRI data rate is 9.8 Gbit/s for LTE FDD cells or the CPRI data rate is greater than 4.9 Gbit/s for LTE TDD cells, the CPRI compression type of cells served by RRUs in the same RRU chain or ring must be the same. If the value of this parameter is changed, the cell served by the sector equipment automatically restarts. This parameter is used only when MultiRruCellMode is set to SFN or CELL_COMBINATION. This parameter can be set based on the sector equipment. When this parameter is set to NULL, the CPRI compression type of the carrier of the cell depends on the value of the CPRICompression parameter in the Cell MO. When this parameter is set to any other value, the sector equipment CPRI compression type of carriers depends on the value of the SectorCpriCompression parameter in the eUCellSectorEqm MO. Before changing the value of this parameter for a cell served by an RRU in an RRU chain or ring, ensure that all cells served by RRUs in the RRU chain or ring are deactivated. Activate the cells after you change the parameter value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NO_COMPRESSION(No Compression), NORMAL_COMPRESSION(Normal Compression), ENHANCED_COMPRESSION(Enhanced Compression), TRIPLEX_COMPRESSION_10M(Triplex Compression for 10M), 3_2_COMPRESSION(3.2 times Compression), NULL(Invalid)

Unit: None

Actual Value Range: NO_COMPRESSION, NORMAL_COMPRESSION, ENHANCED_COMPRESSION, TRIPLEX_COMPRESSION_10M, 3_2_COMPRESSION, NULL

MML Default Value: NULL(Invalid)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

WeightNO Weight Number

Meaning: Indicates the weight number configured for cell-specific sector equipment. If this parameter is not set to 255, the value of this parameter has a mapping relationship with the DEVICENO parameter in the BFANT MO. If this parameter is set to 255, the smallest weight number specified by the DEVICENO parameter in the BFANT is used. If the value of DEVICENO in the DSP BFANT command output is not equal to the value of this parameter, the default weight is used. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to a value that is different from that configured for sector equipment of other cells, the sector equipment of the cell uses the value of the DEVICENO parameter in the BfAnt MO for the weighting for beamforming transmission.

Applicable Mode: L-TDD
VisualCellId Virtual Cell ID

Meaning: Indicates a virtual cell ID used for DMRS and CSI-RS scrambling when adaptive SFN and TM10 are enabled. This parameter should be manually set to a planned value as required when adaptive SFN and TM10 are enabled. This parameter applies only to FDD.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: 1. If VisualCellId is set to an improper value, the performance of CSI-RS measurement and the performance of DMRS-based channel estimation will both deteriorate.

2. If the VisualCellId parameter value is changed while a UE is running services, the UE performance deteriorates. If a UE initiates services after the VisualCellId parameter value is changed, the UE performance is not affected.

Applicable Mode: L-FDD
SectorEqmCombineGrpId Sector Equipment Combine Group ID

Meaning: Indicates the ID of a sector equipment combination group, which contains multiple sets of sector equipment. The value 255 indicates that the sector equipment is not to be included in a combination. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1,255

Unit: None

Actual Value Range: 0~1,255

MML Default Value: 255

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the Virtual4T4RSwitch option is selected and the TX/RX mode is 2T2R or 2T4R, the SectorEqmCombineGrpId parameter must be set to 0 for some pieces of sector equipment of the cell and to 1 for the other pieces of sector equipment of the cell. If the SectorEqmCombineGrpId parameter is set to 0 or 1 for all pieces of sector equipment of the cell, the cell does not support Rank 3 or Rank 4 4x4 MIMO, and the throughput decreases.

Applicable Mode: L-FDD, L-TDD
CellBeamMode Cell Beam Mode

Meaning: Indicates the beam mode of the cell. This parameter has four values: NORMAL, ADVANCED_BEAMFORMING, MASSIVE_MIMO_Ph1, and MASSIVE_MIMO_Ph2. The value NORMAL indicates that the cell is a normal cell. The value ADVANCED_BEAMFORMING indicates that the cell uses AAU-based advanced beamforming. The value MASSIVE_MIMO_Ph1 indicates that the cell uses phase-1 massive MIMO. The value MASSIVE_MIMO_Ph2 indicates that the cell uses phase-2 massive MIMO. This parameter applies only to LTE FDD.

GUI Value Range: NORMAL(NORMAL), ADVANCED_BEAMFORMING(ADVANCED_BEAMFORMING), MASSIVE_MIMO_Ph1(MASSIVE_MIMO_Ph1), MASSIVE_MIMO_Ph2(MASSIVE_MIMO_Ph2)

Unit: None

Actual Value Range: NORMAL, ADVANCED_BEAMFORMING, MASSIVE_MIMO_Ph1, MASSIVE_MIMO_Ph2

MML Default Value: NORMAL(NORMAL)

Recommended Value: NORMAL(NORMAL)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To add cell sector equipment with the parameters as follows: LocalCellId: 0, SectorEqmId: 0, run the following command:
ADD EUCELLSECTOREQM: LocalCellId=0, SectorEqmId=0;
