List Cell Mlb Hand-over Configuration (LST CELLMLBHO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the Mlb handover parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Cell Mlb Hand-over Configuration:
LST CELLMLBHO:;

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Idle UE Select Frequency Strategy

Indicates the frequency selection policy for UEs in idle mode MLB. The value RESELBASED indicates that the target frequency is selected based on cell-reselection priorities for frequencies. The value MLBPRIOBASED indicates that the target frequency is selected based on MLB priorities for frequencies. This parameter applies only to LTE FDD and LTE TDD.

Mlb Handover-in Protect Mode

Indicates the MLB protection mode for UEs that are handed over to the local cell from other cells.

PROTECTTIMERMODE: If this option is selected, the eNodeB imposes a penalty on UEs that are handed over to the local cell through unnecessary incoming handovers. During the penalty, the eNodeB does not perform outgoing handovers for such UEs in the cell for MLB. Unnecessary handovers include intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based handovers, X2-based handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover", and S1-based handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover".

SPECEVENTA1A2MODE: If this option is selected, the eNodeB delivers special A1 and A2 measurement configurations to UEs that are handed over to the local cell through handovers for MLB. If this option is deselected, the eNodeB delivers the same A1 and A2 measurement configurations to all UEs in the local cell. This option applies only to LTE FDD and LTE TDD.

Mlb Handover-in Protect Timer(s)

Indicates the penalty duration in which UEs that are handed over from other cells to the cell are not allowed to be handed over to other cells for MLB. If this parameter is set to 0, the penalty mechanism does not take effect. The unnecessary handovers include:

- Intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based intra-eNodeB handovers

- X2-based handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover"

- S1-based handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover"

This parameter applies only to LTE FDD and LTE TDD.

InterFreq Mlb Handover-in A1 RSRP Thd(dBm)

Indicates the RSRP threshold for event A1 in measurement configurations delivered to UEs that are handed over to the local cell through handovers for inter-frequency MLB. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Mlb Handover-in A1 RSRQ Thd(0.5dB)

Indicates the RSRQ threshold for event A1 in measurement configurations delivered to UEs that are handed over to the local cell through handovers for inter-frequency MLB. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Mlb Handover-in A2 RSRP Thd(dBm)

Indicates the RSRP threshold for event A2 in measurement configurations delivered to UEs that are handed over to the local cell through handovers for inter-frequency MLB. This parameter applies only to LTE FDD and LTE TDD.

InterFreq Mlb Handover-in A2 RSRQ Thd(0.5dB)

Indicates the RSRQ threshold for event A2 in measurement configurations delivered to UEs that are handed over to the local cell through handovers for inter-frequency MLB. This parameter applies only to LTE FDD and LTE TDD.

Inter-RAT MLB Strategy

Indicates the policies used in inter-RAT MLB.

If the UtranRedirectIMMCI option is selected, the eNodeB delivers dedicated cell-reselection priorities of frequencies for "MLB to UTRAN by transferring RRC_REL UEs" when redirections for MLB to UTRAN are triggered.

MLB Match Other Feature Mode

Indicates the coordination mechanism between MLB and other features.

HoAdmitSwitch: Indicates whether the admission of UEs in incoming unnecessary handovers (for example, service-based inter-frequency handovers) is controlled by MLB triggering. The admission is controlled by MLB triggering only if this option is selected.

X2RoHoAdmitSwitch: Indicates whether the admission of UEs in S1- or X2-based incoming handovers with the cause value of "Resource Optimisation Handover" is controlled by MLB triggering. The admission is controlled by MLB triggering only if this option is selected.

NCellSelectSwitch: Indicates whether an intra-eNodeB neighboring cell for which MLB is triggered can be a target cell in a service-based inter-frequency handover or service-request-based inter-frequency handover. Such a neighboring cell can be a target cell only if this option is selected.

IfBackoffHoInRejectSwitch: Indicates whether to reject handovers of UEs from inter-duplex-mode cells in backoff MLB if the cell load has reached the HoInRejectPrbThd or HoInRejectUeNumThd parameter value. Handovers of UEs from inter-duplex-mode cells are rejected for the stated cell load reason only if this option is selected.

CarrierShutdownHoAdmitAllowSw: Indicates whether a local cell accepts incoming handover requests triggered by carrier power-off when MLB is initiated in the local cell. The local cell accepts incoming handover requests triggered by carrier power-off when MLB is initiated in the local cell only if this option is selected. This option applies only to LTE FDD and LTE TDD.

MocnSecOpUeFreqPriInHoEhnSw: Indicates whether neighboring cells in which MLB is triggered allow frequency-priority-based incoming handover requests of UEs served by secondary operators in the local cell when the local cell is a MOCN cell. If this option is selected, such requests are allowed. If this option is deselected, such requests are rejected. This option is valid only if the FLEXIBLE_SHARING_SWITCH option of the CellAlgoExtSwitch.OperatorFunSwitch parameter is selected. This option applies only to LTE FDD and LTE TDD.
