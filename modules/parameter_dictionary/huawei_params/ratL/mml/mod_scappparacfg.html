Modify SC Application Parameter Configuration (MOD SCAPPPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of an SC application.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the index of an application. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~301

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppIdentType Application Identification Type

Meaning: Indicates the application identification method. If the AppIdentType parameter is set to DNS, the AppDns parameter must be set. If the AppIdentType parameter is set to IPv4, the AppIpv4 parameter must be set. If the AppIdentType parameter is set to IPv6, the AppIpv6 parameter must be set. You are advised to set the IP address for an application when the application is not configured with a domain name. You must not set both an IP address and a domain name for an application at the same time. If the AppIdentType parameter is set to TCPPORT, the TCP port number does not need to be configured and port 80, 8080, or 443 takes effect by default. The value 100 of the AppDnsId parameter is reserved for TCP link setup acceleration. That is, when the AppDnsId parameter is set to 100, the AppIdentType parameter can be set to only TCPPORT. If the AppIdentType parameter is set to WTCP, the WTCP service identification does not need to be configured but the AppDnsId parameter must be set to 101. The value 101 of the AppDnsId parameter is reserved for WTCP. That is, when the AppDnsId parameter is set to 101, the AppIdentType parameter can be set to only WTCP. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DNS(DNS), IPV4(IPv4), IPV6(IPv6), TCPPORT(TCPPORT), WTCP(WTCP)

Unit: None

Actual Value Range: DNS, IPV4, IPV6, TCPPORT, WTCP

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Only one group of ScAppParaCfg MO instances where the AppIdentType parameter is set to TCPPORT is allowed.
  • Only one group of ScAppParaCfg MO instances where the AppIdentType parameter is set to WTCP is allowed.
  • If the AppIdentType parameter in an ScAppParaCfg MO is set to TCPPORT or WTCP, the VideoIdentInd option of the AppCfgTargetInd parameter in the same MO must be deselected, the AccelerateInd option of the AppCfgTargetInd parameter in the same MO must be selected and the ServiceTraceInd option of the AppCfgTargetInd parameter in the same MO must be deselected.
  • If the UeMatchInd option of the AppCfgTargetInd parameter in an ScAppParaCfg is selected, then the AppIdentType parameter must be set to DNS and only one ScAppParaCfg MO instance with the UeMatchInd option selected can be configured.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppDns Application DNS

Meaning: Indicates the domain name of the to-be-identified application or website. This parameter must be set only if the AppIdentType parameter is set to DNS. A single domain name specified by the AppDns parameter can be repeatedly configured for auxiliary application domain names associated with different main domain names. In other cases, it is not recommended that a single domain name be repeatedly configured for different application domain names. This parameter must be set to specific application domain names. It is not recommended that this parameter be set to domain names without specific meanings, such as *, *.*, *.com, or a*.c*. If such domain names are configured, the identification of application (such as video) domain names with specific meanings is affected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~49 characters

Unit: None

Actual Value Range: 1~49 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of AppDns in the ScAppParaCfg MO can contain only the following characters:lower-case letters (a to z), upper-case letters (A to Z), digits (0 to 9), wildcard character (*), hyphens (-), full stops (.), and at-signs (@). The parameter cannot be set to * or *.*.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

MatchRule Match Rule

Meaning: Indicates the rule for matching a to-be-identified application (for example, a video) with the domain name. The service classification (SC) function uses the domain name to identify an application in two methods. If this parameter is set to Query, the query method is applied. If the IP address that a UE attempts to visit and a configured domain name match, the UE can obtain the service type (video service) through a reverse query of the domain name by using the IP address.

If this parameter is set to Relevancy, the relevancy method is applied. Assume that a UE accesses a video service and the IP address of the video does not match any configured domain name. After an initial identification of the video service, SC checks the domain names that the UE visited to find out whether there are domain names related to the video service. If yes, SC concludes the service as a video service. This parameter must be set under the consideration of the video service access characteristics in the place where the network locates.

This parameter must be set to Query when the domain name or IP address is configured for air interface acceleration guarantee for network services or simplified KQI tracing, or the TCP port is configured for TCP link setup acceleration. Otherwise, the configured domain name, IP address, or TCP port does not take effect.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Relevancy(Relevancy), Query(Query)

Unit: None

Actual Value Range: Relevancy, Query

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the AccelerateInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the ServiceTraceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the LowDelayServiceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the PortNumber parameter is set to a value other than 0 and the ProtocolType parameter is set to BOTH or UDP, the MatchRule parameter must be set to Query.
  • If the VideoIdentInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 443 or 0.
  • If the AccelerateInd or ServiceTraceInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AppCfgTargetInd Application Config Target Indicator

Meaning: Indicates whether the configured DNS or IP address can be used for video service identification, air interface acceleration guarantee for network services, service tracing, or low-delay service identification.

VideoIdentInd: The configured DNS or IP address is used for video service identification only when this option is selected.

AccelerateInd: The configured DNS, IP address, or TCP port is used for air interface acceleration guarantee for network services, TCP link setup acceleration guarantee, and WTCP air interface acceleration only when this option is selected. When a UE accesses a configured DNS, IP address, or TCP port, the eNodeB performs air interface acceleration guarantee for network services, TCP link setup acceleration guarantee, and WTCP air interface acceleration for the UE if any of the following conditions is met: (1) The AsAlgoSwitch parameter is set to ON. (2) The AsForTcpSw option of the ServiceDiffSwitch parameter in the CellAlgoSwitch MO is selected. (3) The WtcpDlRttTimer parameter in the WtcpProxyAlgo MO is set to ON.

ServiceTraceInd: Service-related external CHRs are recorded for a UE visiting the configured DNS or IP address only when this option is selected.

LowDelayServiceInd: External CHRs related to low-delay services are recorded for a UE visiting the configured DNS or IP address only when this option is selected.

UeMatchInd: If this option is selected, the configured DNS is used for UE identification. If this option is deselected, the configured DNS is not used for UE identification.

If all of the VideoIdentInd, AccelerateInd, ServiceTraceInd, LowDelayServiceInd, and UeMatchInd options are deselected, this parameter is invalid. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: VideoIdentInd(VideoIdentInd), AccelerateInd(AccelerateInd), ServiceTraceInd(ServiceTraceInd), LowDelayServiceInd(LowDelayServiceInd), UeMatchInd(UeMatchInd)

Unit: None

Actual Value Range: VideoIdentInd, AccelerateInd, ServiceTraceInd, LowDelayServiceInd, UeMatchInd

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the AppIdentType parameter in an ScAppParaCfg MO is set to TCPPORT or WTCP, the VideoIdentInd option of the AppCfgTargetInd parameter in the same MO must be deselected, the AccelerateInd option of the AppCfgTargetInd parameter in the same MO must be selected and the ServiceTraceInd option of the AppCfgTargetInd parameter in the same MO must be deselected.
  • If the UeMatchInd option of the AppCfgTargetInd parameter in an ScAppParaCfg is selected, then the AppIdentType parameter must be set to DNS and only one ScAppParaCfg MO instance with the UeMatchInd option selected can be configured.
  • If the AccelerateInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the ServiceTraceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg MO is selected, the MatchRule parameter in the same MO must be set to Query.
  • If the LowDelayServiceInd option of the AppCfgTargetInd parameter in an ScAppParaCfg is selected, the MatchRule parameter in the same MO must be set to Query.
  • In an ScAppParaCfg MO, only one option among VideoIdentInd, ServiceTraceInd, and LowDelayServiceInd of the AppCfgTargetInd parameter can be selected.
  • If the VideoIdentInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 443 or 0.
  • If the AccelerateInd or ServiceTraceInd option of the AppCfgTargetInd parameter is selected, the ProtocolType parameter is set to BOTH or UDP, and the MatchRule parameter is set to Query in an ScAppParaCfg MO, the PortNumber parameter in the same MO must be set to 0.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

ServiceEndTimeThd Service End Time Threshold

Meaning: Indicates the service end time threshold used in service tracing. If this parameter is set to a value in the range from 1 to 255, the configured value takes effect. If this parameter is set to 0, the value 255 takes effect. This parameter takes effect only when the ServiceTraceInd or AccelerateInd option of the AppCfgTargetInd parameter in the ScAppParaCfg MO is selected. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: In the current version, the value range of this parameter is 0 to 255. In later versions, the value range will be changed to 1 to 255. In the current version, if this parameter is set to 0, the parameter setting can be synchronized and delivered, and the value 255 takes effect automatically in the system. Therefore, avoid setting this parameter to 0.

Example

To modify an SC application with the parameters follows: Application Index: 10, AppIdentType: DNS, Application DNS: "www.example1.com", Match Rule: Query, Application Config Target Indicator: VideoIdentInd-0&AccelerateInd-1&ServiceTraceInd-0, Main Application DNS Flag: Main, Accelerate Service Para Group ID: 0, Application Name: "example1", Protocol Type: TCP, Port Number: 666, run the following command:
MOD SCAPPPARACFG: AppDnsId=10, AppIdentType=DNS, AppDns="www.example1.com", MatchRule=Query, AppCfgTargetInd=VideoIdentInd-0&AccelerateInd-1&ServiceTraceInd-0, MainAppDnsFlag=Main, AsParaGroupID=0, AppName="example1", ProtocolType=TCP, PortNumber=666;
