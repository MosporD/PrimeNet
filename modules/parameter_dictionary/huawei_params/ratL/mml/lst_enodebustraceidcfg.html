List eNodeBUsTraceId Configurations (LST ENODEBUSTRACEIDCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of an eNodeB-level trace ID for UEs running unlimited services.

Note

None.

Parameters

ID Name Description
UsTraceIdIndex US Trace ID Index

Meaning: Indicates the index of the trace ID for UEs running unlimited services (US UEs).

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

List eNodeB US Trace ID Configuration
+++    0        2005-01-11 02:24:07
O&M    #806355821
%%LST ENODEBUSTRACEIDCFG:;%%
RETCODE = 0  Operation succeeded.

List eNodeBUsTraceIdCfg
-----------------------
Us Trace ID Index  US Trace ID

0                 1          
1                 100        
23                4294967295 
(Number of results = 3)

Output Description

Field Description

US Trace ID Index

Indicates the index of the trace ID for UEs running unlimited services (US UEs).

US Trace ID

Indicates the trace ID for UEs running unlimited services (US UEs). This parameter is valid only if the UsBasedSpecificTraceID option of the UsStrategy parameter is selected. If the UsTraceID parameter is set to 4294967295, the eNodeB identifies UEs with any trace ID as US UEs.
