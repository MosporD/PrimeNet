List Session (LST SESSION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration data of a session.

Note

None.

Parameters

ID Name Description
LocalMceId Local MCE ID

Meaning: Indicates the local MCE ID, which is unique on the local NE. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MbsfnAreaId MBSFN Area ID

Meaning: Indicates the MBSFN area ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~71

Unit: None

Actual Value Range: 0~71

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PmchId PMCH ID

Meaning: Indicates the PMCH ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~14

Example

To list the basic SESSION information with the parameters as follows: LocalMceId:0, MbsfnAreaId:0, PMCH ID:0, Service ID:"101", run the following command:
LST SESSION: LocalMceId=0, MbsfnAreaId=0, PmchId=0, ServiceId="101"
The result is shown as follows:
