List License Sharing Policy (LST LICENSESHARINGPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters related to license sharing policy.

Note

If a LicenseSharingPolicy MO is not configured for an operator, the proportion of the maximum number of users for this operator is 0 by default. Users of this operator cannot access the shared eNodeB.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters related to license sharing policies, run the following command:

LST LICENSESHARINGPOLICY:;

The result is shown as follows:

Output Description

Field Description

CN Operator ID

Indicates the index of the operator. This parameter applies only to LTE FDD and LTE TDD.

The proportion of the maximum number of users(%)

Indicates the proportion of the number of UEs in RRC_CONNECTED mode of the operator when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD and LTE TDD.

The proportion of the sharing number of users(%)

Indicates the proportion of users that the operator can share with other operators when the eNodeB is shared among operators. This parameter must be set based on the contract signed with operators. This parameter applies only to LTE FDD.

User Number Sharing Group ID

Indicates the ID of the sharing group of UEs in RRC_CONNECTED mode. Operators with the same UserNumSharingGroupId parameter value share the sum of the proportions of UEs in RRC_CONNECTED mode of each operator and the sum of the penetration rates of UEs in RRC_CONNECTED mode of each operator. The value 255 is an invalid ID, indicating that the operator is not configured with a sharing group of UEs in RRC_CONNETED mode. This parameter applies only to LTE FDD and LTE TDD.
