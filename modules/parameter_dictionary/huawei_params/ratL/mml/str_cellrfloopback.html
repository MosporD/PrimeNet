Start Cell RF LoopBack (STR CELLRFLOOPBACK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start a cell RF loopback test to check whether the connection from the BBP to the RRU works properly.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • RF loopback is available only after a cell is activated.

  • RF loopback is available only in cells that do not support CPRI compression.

  • When the system is in the reconfiguration status, the RF loopback function fails to be started. You can run this command again to resolve this problem.

  • RF loopback is unavailable in a cell with the bandwidth of 1.4 or 3 MHz.

  • RF loopback is unavailable in cells whose values of the Downlink cyclic prefix length parameter and the Uplink cyclic prefix length parameter are different.

  • In an LTE TDD cell, an RF loopback test can be started only after the preceding RF loopback test completes.

  • RF loopback is available only in single-RRU cells and the SFN primary cell whose primary eNodeB is equipped with only one RRU.

  • RF loopback is unavailable in cells configured with an LBBPc, RRU in version 1, or RRU in version 2.

  • NB-IoT cell does not support RF loopback.

  • The cell configured with MRIU does not support RF loopback.

  • The LTE TDD RF loopback feature needs to be not executed after the clock step-out detection is started.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To start an RF loopback test for a cell with the local cell ID of 0, run the following command:
STR CELLRFLOOPBACK: LocalCellId=0;

Output Description

Field Description

RF module cabinet number

Indicates the cabinet number of the RF module that serves the cell.

RF module subrack number

Indicates the subrack number of the RF module that serves the cell.

RF module slot number

Indicates the slot number of the RF module that serves the cell.

TX Channel No.

Indicates information about the TX channel of a cell.

RX Channel No.

Indicates information about the RX channel of a cell.

RF Loop Result

Indicates the RF loopback verification result of each channel of the cell.
