Modify a Cell Sidelink V2X Configuration (MOD CELLSIDELINKV2XCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the sidelink V2X configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SidelinkV2xCfgSwitch Sidelink V2X Configuration Switch

Meaning: Indicates whether to enable sidelink V2X functions for the cell. This parameter applies only to LTE FDD and LTE TDD. If the LBBPc is used, all functions controlled by this parameter do not take effect.

SIDELINK_V2X_SWITCH: If this option is selected, the eNodeB can broadcast SIB21 in the cell and support mode 4 communication used by UEs.

GUI Value Range: SIDELINK_V2X_SWITCH(SIDELINK_V2X_SWITCH)

Unit: None

Actual Value Range: SIDELINK_V2X_SWITCH

MML Default Value: None

Recommended Value: SIDELINK_V2X_SWITCH: Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: When the SIDELINK_V2X_SWITCH option of the SidelinkV2xCfgSwitch parameter is selected, the load of transmitting SI increases. Service interruption may occur in cells with a bandwidth of 1.4 MHz or 3 MHz due to an SI transmission failure. This issue can be resolved by increasing the value of the SiTransEcr parameter.

Applicable Mode: L-FDD, L-TDD

Example

To modify a cell sidelink V2X parameter configuration with the local cell ID of 0 and sidelink V2X enabled, run the following command:
MOD CELLSIDELINKV2XCFG: LocalCellId=0, SidelinkV2xCfgSwitch=SIDELINK_V2X_SWITCH-1;
