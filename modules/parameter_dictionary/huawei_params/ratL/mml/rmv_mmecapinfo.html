Remove MME Capability Information (RMV MMECAPINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to delete the configuration of the MME features.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may result in an inconsistency between the S1 interface settings and the S1 object settings in the MmeCapInfo MO. The eNodeB determines the MME capability information preferentially based on the setting of the S1 interface.

Parameters

ID Name Description
MmeCapCfgId MME Capability Configuration ID

Meaning: Indicates the MME capability configuration index.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove the MME capability information with MME Capability Configuration ID of 0, run the following command:
RMV MMECAPINFO: MmeCapCfgId=0;
