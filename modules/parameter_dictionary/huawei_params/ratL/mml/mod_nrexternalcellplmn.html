Modify PLMN List for External NR Cell (MOD NREXTERNALCELLPLMN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PLMN list of an external NR cell.

Note

This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of an external NR cell.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an NrExternalCellPlmn MO consists of digits only.
  • In an NrExternalCellPlmn MO, the combination of Mnc and Mcc must be different from that of SharedMnc and SharedMcc.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

NrNetworkingOption NR Networking Option

Meaning: Indicates the PLMN-specific architecture option of an NR cell that is shared between operators. The value UNLIMITED indicates that the architecture option of the NR cell is not yet determined and is in its initial state in the PLMN. The value SA indicates that the PLMN-specific architecture option of the NR cell is SA. The value NSA indicates that the PLMN-specific architecture option of the NR cell is NSA. The value SA_NSA indicates that the PLMN-specific architecture options of the cell include both SA and NSA. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: UNLIMITED(UNLIMITED), SA(SA), NSA(NSA), SA_NSA(SA_NSA)

Unit: None

Actual Value Range: UNLIMITED, SA, NSA, SA_NSA

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to the same value as the NrNetworkingOption parameter set for the RAN sharing operator of the peer gNodeB.

The recommended value is SA if NrNetworkingOption is set to SA for the RAN sharing operator of the peer gNodeB.

The recommended value is NSA if NrNetworkingOption is set to NSA for the RAN sharing operator of the peer gNodeB.

The recommended value is SA_NSA if NrNetworkingOption is set to SA_NSA for the RAN sharing operator of the peer gNodeB.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Tac Tracking Area Code

Meaning: Indicates the tracking area code (TAC) of a secondary operator of the external NG-RAN cell. The TAC and the PLMN ID together form a tracking area identifier (TAI). If this parameter is set to the invalid value 4294967295, no operator-specific TAC is configured, and the TAC specified by the NrExternalCell.Tac parameter is used when handovers to the NG-RAN cell are triggered. This parameter is mandatory when operator-specific TACs are planned for the NG-RAN cell. For details, see 3GPP TS 38.300. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16777215,4294967295

Unit: None

Actual Value Range: 0~16777215,4294967295

MML Default Value: None

Recommended Value: 4294967295

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If the external NG-RAN cell is an MOCN cell, a TAC is planned for each operator, but this parameter is not set, then UEs whose target PLMN is a secondary operator's PLMN will experience handover preparation failures due to core network routing failures. As a result, the number of handover preparation failures increases.

Applicable Mode: L-FDD, L-TDD
SharedPlmnGnodebId Shared PLMN gNodeB ID

Meaning: Indicates the ID of base station serving the external NR cell for a RAN sharing operator. The ID uniquely identifies the base station for the operator. The setting of this parameter does not take effect if the NrExternalCellPlmn.SharedPlmnCellId parameter is set to 65535. In this case, the operator does not have an independent gNodeB ID and the NrExternalCellPlmn.GnodebId parameter value is used for the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: If the multi-cell-identity function is not enabled on the neighboring gNodeB, no recommended value is provided. If the multi-cell-identity function is enabled on the neighboring gNodeB, set this parameter to the planned value.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SharedPlmnCellId Shared PLMN Cell ID

Meaning: Indicates the ID of the external NR cell for a RAN sharing operator. The ID uniquely identifies the cell for the operator within the base station of the external NR cell. The parameter value 65535 indicates that the operator does not have an independent cell ID. In this case, the NrExternalCellPlmn.CellId parameter value is used for the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16383,65535

Unit: None

Actual Value Range: 0~16383,65535

MML Default Value: None

Recommended Value: If the multi-cell-identity function is not enabled on the neighboring gNodeB, the recommended value is 65535. If the multi-cell-identity function is enabled on the neighboring gNodeB, set this parameter to the planned value.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To set an additional PLMN ID for an external Nr cell with the parameters as follows: Mobile Country Code: 460, Mobile Network Code: 20, gNodeB ID: 255, Cell ID: 1, Shared Mobile Country Code: 460, Shared Mobile Network Code: 01, NR Networking Option: SA, run the following command:
MOD NREXTERNALCELLPLMN: Mcc="460", Mnc="20", GnodebId=255, CellId=1, SharedMcc="460", SharedMnc="01", NrNetworkingOption=SA;
