Display Intelligent Beam Shaping Task Status (DSP INTELLIGENTBEAMSHAPING)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

When the intelligent beam shaping feature is enabled, use this command to display the execution status of an intelligent beam shaping task. This command applies only to LTE FDD.

Note

None.

Parameters

ID Name Description
SectorSplitGroupId Sector Split Group ID

Meaning: Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

+++    ss        2019-08-21 08:56:40
O&M    #806354954
%%DSP INTELLIGENTBEAMSHAPING: SectorSplitGroupId=2;%%
RETCODE = 0  Operation succeeded.

Display Intelligent Beam Shaping Task Status
--------------------------------------------
          Sector Split Group ID  =  2
Intelligent Beam Shaping Result  =  TASK_PROCESSING
(Number of results = 1)


---    END

Output Description

Field Description

Sector Split Group ID

Indicates the ID of a sector split group. This parameter applies only to LTE FDD and LTE TDD.

Intelligent Beam Shaping Result

Indicates the execution result of an intelligent beam shaping task. This parameter applies only to LTE FDD.
