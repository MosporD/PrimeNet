List Voice Rate Control setting (LST VOICEAMRCONTROL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list voice rate control records.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the AMR voice configuration, run the following command:
LST VOICEAMRCONTROL:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Voice Rate Control Parameter Group ID

Indicates the ID of a parameter group for rate control over voice services. This parameter applies only to LTE FDD and LTE TDD.

High Rate Coding Mode

Indicates the high rate coding mode for the corresponding parameter group ID. This parameter is used to configure the high rate coding mode for the corresponding parameter group ID. This parameter applies only to LTE FDD and LTE TDD.

Low Rate Coding Mode

Indicates the low rate coding mode for the corresponding parameter group ID. This parameter is used to configure the low rate coding mode for the corresponding parameter group ID. This parameter applies only to LTE FDD and LTE TDD.

Packet Loss Rate Thd for Decreasing

Indicates the packet loss rate threshold (in a parameter group with a specific ID) for reducing the data rates of uplink voice services. If the packet loss rate of uplink QCI 1 services is greater than the threshold and the TBS meets the rate reduction conditions, rate reduction is triggered. This parameter applies only to LTE FDD and LTE TDD.

Packet Loss Rate Threshold for Increasing

Indicates the packet loss rate threshold (in a parameter group with a specific ID) for increasing the data rates of uplink voice services. If the packet loss rate of uplink QCI 1 services is less than the threshold and the TBS meets the rate increase conditions, the rate is increased. This parameter applies only to LTE FDD and LTE TDD.

RLC Segment Num Thd for Decreasing

Indicates the RLC segment number threshold (in a parameter group with a specific ID) for reducing the data rates of uplink voice services. This parameter is used to calculate the TBS threshold for rate reduction. If this parameter is set to 0, only the uplink QCI 1 packet loss rate (not the number of RLC segments) is used to determine whether to reduce rates. This parameter applies only to LTE FDD and LTE TDD.

RLC Segment Num Thd for Increasing

Indicates the RLC segment number threshold (in a parameter group with a specific ID) for increasing the data rates of uplink voice services. This parameter is used to calculate the TBS threshold for rate increases. This parameter applies only to LTE FDD and LTE TDD.
