List Intra-Frequency Neighboring Relation with E-UTRAN Cell (LST EUTRANINTRAFREQNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameters of the neighboring relations with intra-frequency E-UTRAN cell.

Note

None.

Output Description

Field Description

Local cell ID

Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB.

Mobile country code

Indicates the mobile country code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

Mobile network code

Indicates the mobile network code of the E-UTRAN neighboring cell.

The PLMN consists of the MCC and the MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345.

eNodeB ID

Indicates the eNodeB ID of the intra-frequency neighboring cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Cell ID

Indicates the local ID of the intra-frequency neighboring cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Cell individual offset(dB)

Indicates the cell individual offset for the intra-frequency neighboring cell. It affects the probability of triggering intra-frequency measurement reports. A larger value of this parameter indicates a higher probability. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Cell offset(dB)

Indicates the offset for the intra-frequency neighboring cell, which is used in evaluation for cell reselections. A larger value of this parameter results in a lower probability of cell reselections to this neighboring cell. If this parameter is not set to dB0, it is delivered in SIB4. For details, see 3GPP TS 36.331. If this parameter is set to dB0, it is not delivered in SIB4. In this situation, UEs use 0 dB as the offset for cell reselections. For details, see 3GPP TS 36.304.

No handover indicator

Indicates whether handovers of UEs to the neighboring cell are prohibited. This parameter applies only to LTE FDD and LTE TDD.

No remove indicator

Indicates whether to permit or prohibit removal of the neighbor relationship by ANR. This parameter applies only to LTE FDD and LTE TDD.

ANR flag

Indicates whether this neighboring cell is automatically discovered by the ANR algorithm. This parameter applies only to LTE FDD and LTE TDD.

Local cell name

Indicates the name of the local cell.

Neighbour cell name

Indicates the name of the intra-frequency neighboring E-UTRAN cell.

Cell Measure Priority

Indicates the priority of measurement on the intra-frequency neighboring cell. The eNodeB preferentially contains the information about a neighboring cell with this priority set to HIGH_PRIORITY while delivering a measurement configuration. This parameter applies only to LTE FDD and LTE TDD.

Cell Range Expansion(dB)

Indicates the maximum cell coverage offset. This parameter is specified to achieve coverage expansion of micro base stations. The offset that actually takes effect depends on UE capabilities. The parameter value is added to or subtracted from the handover parameter cell individual offset (CIO) to obtain a new CIO, which must meet protocol-defined constraints. The updated CIO is delivered to UEs so that handovers from an eNodeB to a micro base station can be triggered more easily or handovers from a micro base station to an eNodeB can be triggered less easily. In this manner, the cell coverage of a micro base station is expanded. This parameter applies only to LTE FDD and LTE TDD.

Neighbor Cell Classification Label

Indicates the neighboring cell classification label. The parameter values FORMAL and EXTENDED represent different neighboring cell management policies. If the number of handovers to a neighboring cell reaches a predefined threshold, the parameter is set to FORMAL for this neighboring cell; otherwise, the parameter is set to EXTENDED for this neighboring cell. This parameter applies only to LTE FDD and LTE TDD.

Control Mode

Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

Attach Cell Switch

Indicates whether to enable the macro-micro homing relationship of the intra-frequency neighboring cell. In HetNet networking, the macro cell and micro cell that greatly interfere each other are added to one cluster, and homing relationships are configured between the macro and micro cells in each cluster. A cluster consists of one macro cell and a maximum of eight homed micro cells.

If this parameter is set to ON(On), the neighboring cell is the homed cell of the local cell.

If this parameter is set to OFF(Off), the neighboring cell is not the homed cell of the local cell.

The homing relationship between a macro cell and a micro cell takes effect only when the parameter settings are the same in the two cells. This parameter applies only to LTE FDD and LTE TDD.

High Speed Cell Individual Offset(dB)

Indicates the individual cell offset for event A3 related to intra-frequency handovers for high-speed UEs in high-speed cells. This parameter applies only to LTE FDD and LTE TDD.

Vector Cell Flag

Indicates whether an intra-frequency neighboring cell is a vector cell. A vector cell is a neighboring cell with coverage adjacent to that of the serving cell along a high-speed railway. This type of cell requires planning during network construction. This parameter applies only to LTE FDD and LTE TDD.

Neighboring Cell Addition Time

Indicates the time the neighboring cell was added by ANR for the first time. In free mode, this time is the local time of the NE. In control mode, this time is the local time of the OSS when optimization suggestions are delivered. The format is YYYY-MM-DD. For example, the value 2018-01-01 indicates January 1, 2018. The value 2001-01-01 indicates that the neighboring cell was manually added. This parameter applies only to LTE FDD and LTE TDD.

Aggregation Attribute

Indicates the aggregation attribute of an intra-frequency neighboring E-UTRAN cell. UL_INTRF_DET_COORD_NCELL_FLAG: If this option is selected, the neighboring cell is a coordinating cell for uplink interference detection of the serving cell. If this option is deselected, the neighboring cell is not a coordinating cell for uplink interference detection of the serving cell. This option applies only to LTE FDD.
