List Cell Multi-band Fast Carrier Selection (LST CELLMBFCS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the parameter configuration of multi-band fast carrier selection.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters of the cell multi-band fast carrier selection configuration with the local cell ID of 1, run the following command:
LST CELLMBFCS: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Cell Synthetical Rate Handover Hysteresis(%)

Indicates the hysteresis for the overall cell data rate gain that must be met to trigger an outgoing inter-carrier handover for a non-CA UE or serving cell combination change for a CA UE. If the estimated overall cell data rate gain brought by the handover or combination change is greater than the hysteresis, the eNodeB triggers the handover or combination change. This parameter applies only to LTE FDD and LTE TDD.

Cell Traffic Load Threshold(ms)

Indicates the service load threshold of the cell for triggering optimal carrier selection. If the estimated service data transmission duration of the cell is greater than or equal to this threshold, the eNodeB triggers optimal carrier selection. This parameter applies only to LTE FDD and LTE TDD.

Inter-Freq Measurement Load Ratio Threshold(%)

Indicates the UE load ratio threshold for triggering inter-frequency measurement. A UE is allowed to perform inter-frequency measurement when the ratio of the service load of the UE to the total service load of the cell is less than or equal to this threshold. This parameter applies only to LTE FDD and LTE TDD.

Inter-Freq Measurement MCS Threshold

Indicates the MCS threshold for triggering inter-frequency measurement. A UE is allowed to perform inter-frequency measurement when the average MCS used for single-codeword transmission of a UE is less than this threshold. This parameter applies only to LTE FDD and LTE TDD.

Inter-Freq Measurement Service Threshold(byte)

Indicates the UE traffic volume threshold for triggering inter-frequency measurement. A UE is allowed to trigger inter-frequency measurement when the traffic volume of the UE is greater than this threshold. This parameter applies only to LTE FDD and LTE TDD.

Measurement Information Update Interval

Indicates the interval for updating UE measurement information. UEs periodically report intra-frequency measurement information at this interval. This parameter applies only to LTE FDD and LTE TDD.

UE Spectral Efficiency Handover Hysteresis(%)

Indicates the hysteresis for the spectral efficiency gain that must be met to trigger an outgoing inter-carrier handover for a non-CA UE or serving cell combination change for a CA UE. If the estimated spectral efficiency gain brought by the handover or combination change is greater than the hysteresis, the eNodeB triggers the handover or combination change. This parameter applies only to LTE FDD and LTE TDD.

Load Difference Ratio Threshold(%)

Indicates the ratio threshold of the load difference between the serving cell and an inter-frequency neighboring cell. A neighboring cell can be a target cell for optimal carrier selection when the following condition is met: (Serving cell load - Neighboring cell load)/Serving cell load >= LoadDiffRatioThld. This parameter applies only to LTE FDD and LTE TDD.

MBOCS Algorithm Switch

Indicates whether to enable multi-band optimal carrier selection (MBOCS).

DL_CA_UE_ENH_SWITCH: Indicates whether to allow MBOCS between FDD and TDD and controls the scope of downlink CA UEs that can be selected for MBOCS. If this option is deselected, the eNodeB can select only non-CA UEs and UEs with two downlink CCs aggregated. If this option is selected, the eNodeB can also select UEs with three to five downlink CCs aggregated. These carriers can be FDD-only, TDD-only, or FDD+TDD carriers. In addition, MBOCS between FDD and TDD is allowed only if this option is selected. This option applies only to LTE FDD and LTE TDD.

PROHIBIT_PCC_HANDOVER_SWITCH: Indicates whether to prohibit PCC change for CA UEs during MBOCS. If this option is selected, PCC change for CA UEs is prohibited during MBOCS. If this option is deselected, PCC change for CA UEs is allowed during MBOCS. This option applies only to LTE FDD and LTE TDD.
