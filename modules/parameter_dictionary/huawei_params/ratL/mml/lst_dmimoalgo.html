List D-MIMO Algorithm Configuration (LST DMIMOALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list D-MIMO algorithm configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-TDD

Example

To list the configurations of D-MIMO algorithm parameters:
LST DMIMOALGO:;
The result is shown as follows:
+++    0        2019-12-05 17:30:24
O&M    #806355933
%%LST DMIMOALGO: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List D-MIMO Algorithm Configuration

                                  Local Cell ID  =  1
                   D-MIMO A3 RSRP Offset(0.5dB)  =  -12
D-MIMO JT Cell RSRP Difference Threshold(0.5dB)  =  -20
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE TDD.

D-MIMO A3 RSRP Offset(0.5dB)

Indicates the threshold of the RSRP difference between a neighboring cell and the serving cell to trigger event A3 report for inter-cell D-MIMO when the neighboring cell has better signal quality than the serving cell. A large value of this parameter indicates that neighboring cells must have better signal quality to trigger measurement reporting for inter-cell D-MIMO. For details, see 3GPP TS 36.331. This parameter applies only to LTE TDD.

D-MIMO JT Cell RSRP Difference Threshold(0.5dB)

Indicates the RSRP difference threshold for D-MIMO joint transmission UEs in selecting coordinating cells. If this parameter is set to a large value, neighboring cells must have better signal quality to be coordinating cells, and a small number of UEs are identified as joint transmission UEs. If this parameter is set to a small value, a large number of UEs are identified as joint transmission UEs. This parameter applies only to LTE TDD.
