List an IP route of an RRN (LST EURRNRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters in the EuRrnRt MO.

Note

None.

Parameters

ID Name Description
RtId Route ID

Meaning: Indicates the ID of an IP route on an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query an IP route of an RRN, run the following command:
LST EURRNRT:;
The result is shown as follows:
+++    0        2014-06-06 10:13:23
O&M    #806354962
%%LST EURRNRT:;%%
RETCODE = 0  Operation succeeded.

Inquire RRN Router
------------------
           Route ID  =  1
Local Subscriber ID  =  1
     Destination IP  =  172.31.255.1
   Destination Mask  =  255.255.255.100
           Next Hop  =  172.31.255.2
(Number of results = 1)


---    END

Output Description

Field Description

Route ID

Indicates the ID of an IP route on an RRN. This parameter applies only to LTE FDD and LTE TDD.

Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Destination IP

Indicates the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.

Destination Mask

Indicates the subnet mask of the destination IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.

Next Hop

Indicates the next-hop IP address of the route from an RRN to the downstream base station. This parameter applies only to LTE FDD and LTE TDD.
