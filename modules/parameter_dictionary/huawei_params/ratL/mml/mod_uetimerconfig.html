Modify UE Timer Configuration (MOD UETIMERCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify UE timer configurations.

Note

None.

Parameters

ID Name Description
TimerType Timer Type

Meaning: Indicates the timer type. This parameter applies only to NB-IoT.

GUI Value Range: NB_CL0_UE_INACTIVITY_TIMER(NB_CL0_UE_INACTIVITY_TIMER), NB_CL1_UE_INACTIVITY_TIMER(NB_CL1_UE_INACTIVITY_TIMER), NB_CL2_UE_INACTIVITY_TIMER(NB_CL2_UE_INACTIVITY_TIMER), NB_CL0_T310(NB_CL0_T310), NB_CL1_T310(NB_CL1_T310), NB_CL2_T310(NB_CL2_T310), NB_CL0_N310(NB_CL0_N310), NB_CL1_N310(NB_CL1_N310), NB_CL2_N310(NB_CL2_N310), NB_CL0_T311(NB_CL0_T311), NB_CL1_T311(NB_CL1_T311), NB_CL2_T311(NB_CL2_T311), NB_CL0_N311(NB_CL0_N311), NB_CL1_N311(NB_CL1_N311), NB_CL2_N311(NB_CL2_N311)

Unit: None

Actual Value Range: NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, NB_CL2_UE_INACTIVITY_TIMER, NB_CL0_T310, NB_CL1_T310, NB_CL2_T310, NB_CL0_N310, NB_CL1_N310, NB_CL2_N310, NB_CL0_T311, NB_CL1_T311, NB_CL2_T311, NB_CL0_N311, NB_CL1_N311, NB_CL2_N311

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
TimerDuration Timer Duration

Meaning: Indicates the duration of the timer. If the parameter setting is changed, the change applies only to UEs that access the network afterwards.

GUI Value Range: 1~3600

Unit: s

Actual Value Range: 1~3600

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

If TimerType is set to NB_CL0_UE_INACTIVITY_TIMER, then: 20

If TimerType is set to NB_CL1_UE_INACTIVITY_TIMER, then: 20

If TimerType is set to NB_CL2_UE_INACTIVITY_TIMER, then: 20

The recommended value of this parameter varies with the NB-IoT cell deployment mode when the TimerType parameter is set to NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, or NB_CL2_UE_INACTIVITY_TIMER. The recommended value is as follows:

20 for standalone or LTE guard band deployment scenarios; 30 for LTE in-band deployment scenarios

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NB_CL0_UE_INACTIVITY_TIMER: A smaller timer length results in earlier RRC connection releases for NB-IoT UEs at coverage level 0 without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger timer length results in later RRC connection releases for NB-IoT UEs at coverage level 0 without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.

NB_CL1_UE_INACTIVITY_TIMER: A smaller timer length results in earlier RRC connection releases for NB-IoT UEs at coverage level 1 without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger timer length results in later RRC connection releases for NB-IoT UEs at coverage level 1 without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.

NB_CL2_UE_INACTIVITY_TIMER: A smaller timer length results in earlier RRC connection releases for NB-IoT UEs at coverage level 2 without performing services, more frequent RRC connection setup requests, and better KPIs such as the service drop rate due to more normal RRC connection releases. A larger timer length results in later RRC connection releases for NB-IoT UEs at coverage level 2 without performing services, longer online duration in which radio resources are occupied, and worse KPIs such as the service drop rate due to fewer normal RRC connection releases.

Applicable Mode: L-NB-IOT
TimerDurationMillisecond Millisecond-level Timer Duration

Meaning: Indicates the length of the UE timer.

If the TimerType parameter is set to NB_CL0_T310, NB_CL1_T310, or NB_CL2_T310, this parameter can be set to 0, 200, 500, 1000, 2000, 4000, or 8000.

If the TimerType parameter is set to NB_CL0_T311, NB_CL1_T311, or NB_CL2_T311, this parameter can be set to 1000, 3000, 5000, 10000, 15000, 20000, 30000, 40000, 60000, 90000, or 120000.

If this parameter is set to 4294967295, the corresponding T310 and T311 timers do not take effect. If the parameter setting is changed, the change applies only to UEs that access the network afterwards. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: 0,200,500,1000,2000,3000,4000,5000,8000,10000,15000,20000,30000,40000,60000,90000,120000,4294967295

Unit: ms

Actual Value Range: 0~240000,4294967295

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is 4294967295.

The recommended value is as follows:

If TimerType is set to NB_CL0_T310, then: 500

If TimerType is set to NB_CL1_T310, then: 2000

If TimerType is set to NB_CL2_T310, then: 8000

If TimerType is set to NB_CL0_T311, NB_CL1_T311, or NB_CL2_T311, then: 30000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
MaxNumUeSyncOrOutOfSyncInd Max Num of UE Sync or Out-of-Sync Indication

Meaning: Indicates the maximum number of consecutive synchronization or out-of-synchronization indications that a UE receives from lower layers. If the TimerType parameter is set to NB_CL0_N310, NB_CL1_N310, or NB_CL2_N310, this parameter can be set to 1, 2, 3, 4, 6, 8, 10, or 20. If the TimerType parameter is set to NB_CL0_N311, NB_CL1_N311, or NB_CL2_N311, this parameter can be set to 1, 2, 3, 4, 5, 6, 8, or 10. If this parameter is set to 0, this parameter does not take effect. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: 0~6,8,10,20

Unit: None

Actual Value Range: 0~200

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is 0.

The recommended value is as follows:

If TimerType is set to NB_CL0_N310, then: 3

If TimerType is set to NB_CL1_N310, then: 6

If TimerType is set to NB_CL2_N310, then: 10

If TimerType is set to NB_CL0_N311, then: 3

If TimerType is set to NB_CL1_N311, then: 3

If TimerType is set to NB_CL2_N311, then: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To modify UeTimerConfig with the parameters as follows: Timer Type: NB_CL0_UE_INACTIVITY_TIMER, Timer Duration: 10, run the following command:
MOD UETIMERCONFIG: TimerType=NB_CL0_UE_INACTIVITY_TIMER, TimerDuration=10;
