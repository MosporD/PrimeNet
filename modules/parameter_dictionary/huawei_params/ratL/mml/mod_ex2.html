Modify eX2 Configuration (MOD EX2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of an eX2 object.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The modification of the control-plane end point group ID may lead to automatic eX2 interface reestablishment.

  • The modification of the user-plane end point group ID may lead to the inter-site coordinated service interruption.

  • The value of the BackhaulType parameter must comply with the transmission interface used by the eX2 interface. Otherwise, the eX2 interface cannot be established or work properly.

  • The EPGROUP MO referenced by CpEpGroupId in an eX2 MO and the EPGROUP MO referenced by the uX2 MO must be different.

  • The EPGROUP MO referenced by UpEpGroupId in an eX2 MO and the EPGROUP MO referenced by the IUB or ABIS MO must be different.

  • The EPGROUP MO referenced by CpEpGroupId in an eX2 MO and the EPGROUP MO referenced by the X2 MO must be different.

BackhaulType eX2 Interface Backhaul Type

Meaning: Indicates the transport type of the eX2 interface. SRIO- or Ethernet-based transport system connecting through the USU is called ideal backhaul. IPRAN- or PTN-based transport system shared with the S1 or X2 interface is called non-ideal backhaul. The transport type of eX2 interfaces between logical eNodeBs contained in a physical network (for example, a physical eNodeB) is called intra physical network domain ideal backhaul. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: IDEAL(Ideal Backhaul), NON_IDEAL(Non-Ideal Backhaul), INTRA_PHYNET_IDEAL(Intra-PhyNet-Ideal Backhaul)

Unit: None

Actual Value Range: IDEAL, NON_IDEAL, INTRA_PHYNET_IDEAL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of an eX2 object with the parameters as follows: eX2 Object ID: 1, eX2 Interface Backhaul Type: NON_IDEAL, run the following command: 
MOD EX2: eX2Id=1, BackhaulType=NON_IDEAL;
