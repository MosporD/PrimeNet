Modify Inter-Frequency Neighboring Relation with E-UTRAN Cell (MOD EUTRANINTERFREQNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the neighboring relation with an inter-frequency E-UTRAN cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

BlindHoPriority Blind handover Priority

Meaning: Indicates the priority of the neighboring cell during handovers. The parameter values are divided into three segments, indicating the blind-handover priority, frequency-based-handover priority, and 0. A larger value indicates a higher priority within the same segment. The parameter values 1 to 16 indicate the blind-handover priorities used only in non-frequency-priority-based blind handovers. A blind handover is a process in which the eNodeB hands over a UE to a specified neighboring cell without measurements. If this parameter is set to 0 for blind handovers, this neighboring cell cannot be selected as a target cell for blind handovers. The parameter values 17 to 32 indicate the handover priorities used when the eNodeB selects the frequencies to be delivered for measurements based on the blind handover cell configurations. These values are applicable to frequency-priority-based blind handovers and measurement-based handovers. If this parameter is set to 0, this neighboring cell cannot be selected as a target cell for frequency-priority-based handovers. This parameter applies only to LTE FDD and LTE TDD.

CellMeasPriority Cell Measure Priority

Meaning: Indicates the priority of measurement on the inter-frequency neighboring cell. The eNodeB preferentially contains the information about a neighboring cell with this priority set to HIGH_PRIORITY while delivering a measurement configuration. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: LOW_PRIORITY(Low Priority), HIGH_PRIORITY(High Priority)

Unit: None

Actual Value Range: LOW_PRIORITY, HIGH_PRIORITY

MML Default Value: None

Recommended Value: LOW_PRIORITY(Low Priority)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In the measurement configuration for an inter-frequency handover, the eNodeB includes information about a limited number of inter-frequency neighboring cells whose cell individual offsets (CIOs) are not zero. If this parameter is set to HIGH_PRIORITY and this neighboring cell has a non-zero CIO, it is more likely that this neighboring cell is included in the measurement configuration, thereby increasing the probability of a timely handover to this inter-frequency neighboring cell. If this neighboring cell is eventually not included in the measurement configuration, the UE uses zero as the CIO for this neighboring cell during handover evaluation. In this case, if the actual CIO for the neighboring cell is not 0, this results in a delayed or premature handover to this neighboring cell.

Applicable Mode: L-FDD, L-TDD

Impact on Radio Network Performance: If this parameter is set to BOOLEAN_TRUE, a high-speed cell sends an X2 message to inform adjacent low-speed neighboring cells of high-speed train passing and request adjacent low-speed neighboring cells to perform interference avoidance and reduce interference to high-speed UEs. CtrlMode Control Mode

Meaning: Indicates the control policy on ANR-related MOs, which can be defined by the user or be based on the automatic neighbor relation (ANR) algorithm. When this parameter is set to MANUAL_MODE, this MO can be modified or removed only by users. A failure message is displayed when a user adds an existing MO (with identical keywords). When this parameter is set to AUTO_MODE, this MO can be modified or removed by users or the ANR algorithm. The MO removal is successful even if the MO does not exist. If an MO does not exist, it can be added by both users and the ANR algorithm. If an existing MO is to be added, the MO is modified when a user performs the addition, but it cannot be added by the ANR algorithm. When this MO is automatically added by the ANR algorithm, this parameter is set to AUTO_MODE by default. When this MO is added by a user, this parameter can be set to either AUTO_MODE or MANUAL_MODE. This parameter applies only to LTE FDD and LTE TDD.

Example

Example 1: To modify the neighboring relation with an inter-frequency EUTRAN cell with the parameters as follows: Local cell ID: 0, Mobile country code:" 460", Mobile network code:" 20", eNodeB ID: 255, Cell ID: 1, Cell individual offset: dB-10, Cell offset: dB-20, No handover indicator: PERMIT_HO_ENUM, No remove indicator: FORBID_RMV_ENUM, run the following command:
MOD EUTRANINTERFREQNCELL: LocalCellId=0, Mcc="460", Mnc="20", eNodeBId=255, CellId=1, CellIndividualOffset=dB-10, CellQoffset=dB-20, NoHoFlag=PERMIT_HO_ENUM, NoRmvFlag=FORBID_RMV_ENUM;
Example 2: To modify the neighboring relation with an inter-frequency EUTRAN cell with the parameters as follows: Local cell ID: 0, Mobile country code:"460", Mobile network code:" 20", eNodeB ID: 255, Cell ID: 2, Cell individual offset: dB-11, Cell offset: dB-22, No handover indicator: PERMIT_HO_ENUM, No remove indicator: FORBID_RMV_ENUM, run the following command:
MOD EUTRANINTERFREQNCELL: LocalCellId=0, Mcc="460", Mnc="20", eNodeBId=255, CellId=2, CellIndividualOffset=dB-11, CellQoffset=dB-22, NoHoFlag=PERMIT_HO_ENUM, NoRmvFlag=FORBID_RMV_ENUM;
