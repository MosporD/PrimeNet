Add Inter-Frequency E-UTRAN Cell to Blacklist (ADD INTERFREQBLKCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an inter-frequency E-UTRAN cell to the blacklist.

Note

  • A single cell can be configured with a maximum of 32 InterFreqBlkCell MO instances.

  • Before running this command, ensure that the DL EARFCN of the inter-frequency E-UTRAN cell to be blacklisted is included in the information about a neighboring E-UTRAN frequency. If other DL EARFCNs are included in the information about the neighboring EUTRAN frequency and correspond to the same frequency as that of the inter-frequency EUTRAN cell to be blacklisted, those DL EARFCNs must be added to the blacklist too. Other configuration parameters must be the same except for the DL EARFCN.

ApplicationScope Application Scope

Meaning: Indicates the UEs that the cell blacklist applies to. If this parameter is set to 65535, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through reselection or handover. If this parameter is set to 65534, the blacklist applies to all UEs and all UEs cannot be transferred to the blacklisted cell through handover. If this parameter is set to a value from 0 to 255, the blacklist applies to UEs with the SPID in an SPID group with the SpidGrpId parameter value the same as the ApplicationScope parameter and such UEs cannot be handed over to the blacklisted cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255,65534~65535

Recommended Value: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add an inter-frequency blacklisted E-UTRAN cell with the following parameters to the blacklist: Local cell ID: 0, Downlink EARFCN: 3000, Start physical cell ID: 19, run the following command:
ADD INTERFREQBLKCELL: LocalCellId=0, DlEarfcn=3000, PhyCellId=19;
Example 2: To add an inter-frequency blacklisted E-UTRAN cell with the following parameters to the blacklist: Local cell ID: 0, Downlink EARFCN: 2950, Start physical cell ID: 20, run the following command:
ADD INTERFREQBLKCELL: LocalCellId=0, DlEarfcn=2950, PhyCellId=20;
