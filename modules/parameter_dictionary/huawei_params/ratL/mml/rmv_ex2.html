Remove eX2 Configuration (RMV EX2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an eX2 object.

Note

After an eX2 MO is removed, all configurations of the eX2 interface defined by this MO are removed and related inter-site coordinated services are interrupted.

Parameters

ID Name Description
eX2Id eX2 Object ID

Meaning: Indicates the eX2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5,10

Unit: None

Actual Value Range: 0~5,10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove an eX2 object whose ID is 1, run the following command:
RMV EX2: eX2Id=1;
