Modify Cell Data Compression Configuration (MOD CELLDATACOMPRCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the data compression configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StandardUdcSwitch Standard UDC Switch

Meaning: Indicates standardized uplink data compression (UDC) switches. For details about the descriptions of functions controlled by this parameter, see 3GPP TS 36.323.

UL_DEFLATE_DATA_COMPRESSION_SW: Indicates whether to enable the DEFLATE-based uplink data compression. If this option is selected, DEFLATE-based uplink data compression is initiated for DEFLATE-capable UEs. If this option is deselected, DEFLATE-based uplink data compression is disabled. This option applies only to LTE FDD and LTE TDD.

UL_DEFLATE_SIP_COMPRESSION_SW: Indicates whether to enable the DEFLATE-based uplink SIP signaling compression. If this option is selected, DEFLATE-based uplink voice SIP signaling compression is initiated for DEFLATE-capable UEs. If this option is deselected, DEFLATE-based uplink voice SIP signaling compression is disabled. This option applies only to LTE FDD and LTE TDD.

SIP_DICTIONARY_SW: Indicates whether to enable the standard dictionary for SIP signaling. VoLTE QCI-5 SIP signaling is configured with the standard dictionary only if this option is selected. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: UL_DEFLATE_DATA_COMPRESSION_SW, UL_DEFLATE_SIP_COMPRESSION_SW(UL_DEFLATE_SIP_COMPRESSION_SW), SIP_DICTIONARY_SW(SIP_DICTIONARY_SW)

Unit: None

Actual Value Range: UL_DEFLATE_DATA_COMPRESSION_SW, UL_DEFLATE_SIP_COMPRESSION_SW, SIP_DICTIONARY_SW

MML Default Value: None

Recommended Value: UL_DEFLATE_DATA_COMPRESSION_SW:Off, UL_DEFLATE_SIP_COMPRESSION_SW:Off, SIP_DICTIONARY_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
StandardUdcBufferSize Standard UDC Buffer Size

Meaning: Indicates the size of the standard uplink data compression (UDC) buffer. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: KBYTE2(2K Byte), KBYTE4(4K Byte), KBYTE8(8K Byte)

Unit: None

Actual Value Range: KBYTE2, KBYTE4, KBYTE8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Set Cell Data Compr Config, Local Cell ID: 33, UL_DEFLATE_DATA_COMPRESSION_SW  off:
MOD CELLDATACOMPRCONFIG: LocalCellId=33, StandardUdcSwitch=UL_DEFLATE_DATA_COMPRESSION_SW-0;
