Modify eNodeB Cell Alarm Configuration (MOD EUCELLALMCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the data record of eNodeB cell alarm configurations.

Note

Actual value range of parameter RxNoisePwrThd is 0~32. When actual value is smaller than 12, 12 will be used by eNodeB.

Parameters

ID Name Description
LocalCellId LocalCellId

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L
RxNoisePwrThd Rx Noise Power Threshold

Meaning: Indicates the threshold for reporting an alarm indicating interference noise power imbalance between receive (RX) channels of the cell. The threshold is an average interference noise power difference between two RX channels of the cell. This parameter applies only to LTE FDD cells and NB-IoT cells deployed in a mode other than LTE in-band mode.

GUI Value Range: 0~320

Unit: 0.1dBm

Actual Value Range: 0~32

MML Default Value: None

Recommended Value: 120

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that an alarm indicating interference noise power imbalance between RX channels will be reported for the cell. Therefore, there is a possibility that no alarms are reported when related KPIs deteriorate due to RF module or antenna issues. A smaller value of this parameter results in a higher probability that such an alarm will be reported for the cell.

Applicable Mode: L-FDD, L-NB-IOT
RxChannelNoiseDetectMode RX Channel Noise Detection Mode

Meaning: Indicates the method of checking the alarm of interference noise power imbalance between receive channels in a cell.

ALL_CHANNELS: Indicates that the eNodeB checks whether the interference power of all channels in a cell is balanced. If the interference power is unbalanced and exceeds the RxNoisePwrThd parameter value, ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is generated. If this parameter is changed from another value to this value, the modification takes effect at the next check period.

RRU_CHANNELS: Indicates that the eNodeB checks whether the interference noise power is balanced between RRU channels. This value applies only to physical cells served by two combined RRUs. If interference noise power is unbalanced, ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is generated. If this parameter is changed from another value to this value, the modification takes effect at the next check period.

NONE: Indicates that ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is not generated. If this alarm has been reported, the eNodeB clears the alarm.

This parameter applies only to LTE FDD cells and NB-IoT cells deployed in a mode other than LTE in-band mode.

GUI Value Range: ALL_CHANNELS(ALL_CHANNELS), RRU_CHANNELS(RRU_CHANNELS), NONE(NONE)

Unit: None

Actual Value Range: ALL_CHANNELS, RRU_CHANNELS, NONE

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to RRU_CHANNELS when a physical cell is served by two combined RRUs. Otherwise, you are advised to set this parameter to ALL_CHANNELS.

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-NB-IOT

Example

To modify the configuration of the eNodeB cell alarm as follows: Local cell ID: 0: Rx Noise Power Threshold: 123, run the following command:
MOD EUCELLALMCFG: LocalCellId=0, RxNoisePwrThd=123;
