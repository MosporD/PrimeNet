Modify Private Carrier Aggregation Combination (MOD PRIVATECABANDCOMB)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a private CA band combination for an eNodeB.

Note

None.

Parameters

ID Name Description
PrivateCaCombId Private CA Band Combination ID

Meaning: Indicates the ID of the private CA band combination. It uniquely identifies a private CA band combination in an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MaxAggregatedBw Maximum Aggregated Bandwidth

Meaning: Indicates the maximum aggregated bandwidth supported by the CA band combination. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 20~300

Unit: MHz

MML Default Value: None

BwCombSetId Bandwidth Combination Set ID

Meaning: Indicates the protocol-defined ID of a CA bandwidth combination set. As defined in 3GPP TS 36.101, an operating frequency band supports different bandwidth combinations, which are identified by using different set IDs. For details, see section 5.6A.1 in 3GPP TS 36.101. This parameter applies only to LTE FDD and LTE TDD.

CombBand1Bw Combination Band 1 Bandwidth

Meaning: Indicates the bandwidth set supported in the first band in the band combination. If a bandwidth is selected, the carrier with this bandwidth in the first band is supported in the private CA band combination. Selected bandwidths must be identical to configured cell bandwidths. Otherwise, the eNodeB may mistakenly determine that a bandwidth that a UE does not support is supported in the private CA band combination, causing CA configuration failures. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter has been replaced by the CombBandBw parameter in the PrivateBand MO and will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.
