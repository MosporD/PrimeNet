Remove Neighbor Relationship with NR Cell (RMV NRNRELATIONSHIP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more neighbor relationships with NR cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If all parameters are specified, only the configuration of the one neighboring NR cell with the same parameter settings is removed after the command is executed.

  • If some parameters are specified, configurations of the neighboring NR cells with the same parameter settings are removed after this command is executed, and a maximum of 640 neighboring NR cell configurations can be removed at a time.

    If no parameter is specified, configurations of all neighboring UTRAN cells are removed after this command is executed, and a maximum of 640 neighboring UTRAN cell configurations can be removed at a time.

  • If no parameter is specified, configurations of all neighboring NR cells are removed after this command is executed, and a maximum of 640 neighboring NR cell configurations can be removed at a time.

  • This command do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in a NrNRelationship MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Meaning: Indicates the mobile network code of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

Example

Example 1:To remove a neighbor relationship with the NR cell with the parameters as follows: Local cell ID: 0, Mobile country code: "460", Mobile network code: "20", gNodeB ID: 48, NR cell ID: 12, run the following command:
RMV NRNRELATIONSHIP: LocalCellId=0, Mcc="460", Mnc="20", GnodebId=48, CellId=12;
Example 2:To remove the neighbor relationships with the NR cell with the parameters as follows: Mobile country code: "460", Mobile network code: "20", run the following command:
RMV NRNRELATIONSHIP: Mcc="460", Mnc="20";
