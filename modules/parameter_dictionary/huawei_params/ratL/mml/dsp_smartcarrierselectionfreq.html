Display Frequencies for Smart CA (DSP SMARTCARRIERSELECTIONFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the frequency sequence arranged after smart carrier selection is enabled.

Note

None.

Parameters

None.

Example

Display the freq list of SmartCA:
DSP SMARTCARRIERSELECTIONFREQ:;
The result is shown as follows:
+++    0        2018-10-25 12:17:58
O&M    #806355075
%%DSP SMARTCARRIERSELECTIONFREQ:;%%

Output Description

Field Description

Downlink EARFCN

Indicates the downlink EARFCN of the to-be-measured frequency selected by smart carrier selection. This parameter applies only to LTE FDD and LTE TDD.
