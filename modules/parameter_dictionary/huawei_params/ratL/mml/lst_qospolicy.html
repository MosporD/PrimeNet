List QoS Policy (LST QOSPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query QoS policies.

Note

None.

Parameters

ID Name Description
QosPolicyId QoS Policy Identity

Meaning: Indicates the ID of a user-defined QoS policy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the QoS policy, run the following command: :
LST QOSPOLICY:;
The result is shown as follows:

Output Description

Field Description

QoS Policy Identity

Indicates the ID of a user-defined QoS policy. This parameter applies only to LTE FDD and LTE TDD.

Traffic Type

Indicates a traffic type for service differentiation. Currently, there are three types of traffic: VIDEO, DOWNLOAD, and OTHER. This parameter applies only to LTE FDD and LTE TDD.

Priority Queue Identity

Indicates the ID of a prioritized queue. The eNodeB can provide differentiated services for a maximum of eight prioritized queues. Multiple DSCPs can be mapped to one queue, but one DSCP cannot be mapped to multiple queues. This parameter applies only to LTE FDD and LTE TDD.

Downlink Service Grant Bit Rate(Kbit/s)

Indicates the guaranteed bit rate of downlink services. This parameter must be set to a value greater than 0 if the TrafficType parameter value is VIDEO. Otherwise, commands containing this parameter fail to be executed. This parameter applies only to LTE FDD and LTE TDD.

Downlink Service Maximum Bit Rate(Kbit/s)

Indicates the maximum bit rate for downlink services. If the downlink data rate of a UE exceeds the value of this parameter, rate control will be triggered for the UE. This parameter must be set to a value greater than 0 if the TrafficType parameter is set to DOWNLOAD. Otherwise, the command for QoS policy addition or modification cannot be successfully executed. This parameter applies only to LTE FDD and LTE TDD.

Rate Control Switch

Indicates whether to limit the UE rate based on the UE-AMBR.

When the eNodeB detects that the UE has sufficient traffic in the queue:

If this parameter is set to ON, the eNodeB limits the UE rate based on the UE-AMBR.

If this parameter is set to OFF, the eNodeB does not limit the UE rate based on the UE-AMBR.

This parameter applies only to LTE FDD and LTE TDD.
