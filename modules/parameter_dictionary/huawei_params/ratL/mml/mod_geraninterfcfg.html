Modify GL Bufferzone Optimization Configuration (MOD GERANINTERFCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the GSM and LTE Buffer Zone Optimization configuration.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local identity of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlGeranIntefRbNum Number of DL RBs interfered by GERAN

Meaning: Indicates the number of RBs that are interfered by GERAN at each end of the LTE DL frequency band. If the numbers of such RBs are different at both ends, the larger number is used as the value of this parameter.

If this parameter is set to 3, three RBs are interfered by GERAN at each end of the LTE DL frequency band and altogether six RBs are interfered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~10

Unit: 2RB

Actual Value Range: 2~20

MML Default Value: None

Recommended Value: Set this parameter based on the number of RBs interfered by the GERAN cell.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a too small value, RBs that under strong GERAN interference are used by UEs. This decreases the throughput of UEs. If this parameter is set to a too large value, some UEs that can resist GERAN interference cannot use GERAN interfered RBs and therefore the average cell throughput is not increased.

Applicable Mode: L-FDD, L-TDD
DlRbAvailSinrThd SINR threshold for available DL RBs

Meaning: Indicates the SINR threshold for determining whether DL RB resources of an E-UTRAN cell using the LTE frequency spectrum that overlaps the GSM frequency spectrum are available. If the result of the local cell RSRP plus 11.2 and minus the RSSI of the GERAN cell that brings the severest interference is greater than the value of this parameter, UEs can use these RB resources. Otherwise, UEs cannot use these RB resources. UEs measure the local cell RSRP and the RSSI of the GERAN cell that brings the severest interference and report the measurement results to the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -6~12

Unit: dB

Actual Value Range: -6~12

MML Default Value: None

Recommended Value: -3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a larger number of available RBs but stronger interference on RBs. This decreases the throughput of UEs. A larger value of this parameter leads to a smaller number of available RBs, but the gain on the average cell throughput is not significant.

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameters related to GL Bufferzone optimization configuration with the parameters as follows: Local cell ID: 0, Number of DL RBs interfered by GERAN(2RB): 5, SINR threshold for available DL RBs(dB): 2, run the following command:
MOD GERANINTERFCFG: LocalCellId=0, DlGeranIntefRbNum=5, DlRbAvailSinrThd=2;
