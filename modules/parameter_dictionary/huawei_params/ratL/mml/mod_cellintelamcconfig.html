Modify Cell Intelligent AMC Configuration (MOD CELLINTELAMCCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to intelligent AMC for a cell.

Note

When the option of the IntelligentAmcSwitch parameter is selected, intelligent MCS selection requires that the corresponding option of the ServiceMode parameter in the eNodeBResModeAlgo MO be selected in some scenarios. For details, see the feature documentation.

Parameters

ID Name Description
LocalCellId Local Cell Id

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntelligentAmcSwitch Intelligent AMC Switch

Meaning: Indicates whether to enable intelligent MCS selection. DL_INTEL_AMC_SELECTION_SW: Indicates whether to enable downlink intelligent selection. Downlink intelligent selection is enabled only if this option is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DL_INTEL_AMC_SELECTION_SW(DL_INTEL_AMC_SELECTION_SW)

Unit: None

Actual Value Range: DL_INTEL_AMC_SELECTION_SW

MML Default Value: None

Recommended Value: DL_INTEL_AMC_SELECTION_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: DL_INTEL_AMC_SELECTION_SW: If this option is selected, optimal MCSs for downlink transmissions are determined based on big data analysis. When the downlink intelligent AMC model converges, the average user-perceived downlink rate increases in the cell. If this option is deselected, network performance is not affected.

Applicable Mode: L-FDD, L-TDD
DlPredErrorUpperLimit Downlink Prediction Error Upper Limit

Meaning: Indicates the upper limit on the error of the IBLER predicted for downlink scheduling. When the error of the predicted IBLER exceeds the upper limit, the prediction is recorded as incorrect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~20

Unit: %

Actual Value Range: 0~20

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a higher requirement for downlink intelligent AMC model convergence, a smaller difference between the predicted value and the actual value, more accurate selection of an optimal MCS for downlink transmission, and a higher gain in the average user-perceived downlink rate in the cell. However, the probability of downlink intelligent AMC model retraining increases, and the training process may affect user-perceived downlink rates in the cell.

A larger value of this parameter results in a lower requirement for downlink intelligent AMC model convergence, a larger difference between the predicted value and the actual value, and less accurate selection of an optimal MCS for downlink transmission. However, the probability of downlink intelligent AMC model retraining is lower.

Applicable Mode: L-FDD, L-TDD
DlDataCollectionInterval Downlink Data Collection Interval

Meaning: Indicates the interval at which data is collected for downlink intelligent AMC model training. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SHORT(SHORT), LONG(LONG)

Unit: None

Actual Value Range: SHORT, LONG

MML Default Value: None

Recommended Value: SHORT(SHORT)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to SHORT, training data is collected at a short interval in the downlink, and therefore the downlink intelligent AMC model is updated quickly. The value SHORT has a greater impact on the CPU than the value LONG.

If this parameter is set to LONG, training data is collected at a long interval in the downlink, and therefore the downlink intelligent AMC model is updated slowly. The value LONG has a smaller impact on the CPU than the value SHORT.

Applicable Mode: L-FDD, L-TDD
DlModelMinUpdatePeriod Downlink Model Min Update Period

Meaning: Indicates the minimum period of updating the downlink intelligent AMC model. The value 0MIN indicates that the model is updated continuously. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0MIN(0MIN), 10MIN(10MIN), 20MIN(20MIN), 30MIN(30MIN), 40MIN(40MIN), 50MIN(50MIN), 60MIN(60MIN), 80MIN(80MIN), 100MIN(100MIN), 120MIN(120MIN)

Unit: None

Actual Value Range: 0MIN, 10MIN, 20MIN, 30MIN, 40MIN, 50MIN, 60MIN, 80MIN, 100MIN, 120MIN

MML Default Value: None

Recommended Value: 0MIN(0MIN)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter indicates a shorter minimum period of starting downlink intelligent AMC model training, which leads to quicker updating of the model and therefore a closer matching between downlink MCS selection and instantaneous channel quality fluctuation on the live network. A larger value of this parameter indicates a longer minimum period of starting downlink intelligent AMC model training, which leads to slower updating of the model and a closer matching between downlink MCS selection and average channel quality fluctuation on the live network.

Applicable Mode: L-FDD, L-TDD

Example

To modify the settings of intelligent AMC with the parameters as follows: LocalCellId=131, IntelligentAmcSwitch=DL_INTEL_AMC_SELECTION_SW-1, run the following command:
+++    0        2019-11-12 22:04:56
O&M    #806354951
%%MOD CELLINTELAMCCONFIG: LocalCellId=131, IntelligentAmcSwitch=DL_INTEL_AMC_SELECTION_SW-1;%%
RETCODE = 0  Operation succeeded.


---    END
