Modify Parameter Group for Handover to UTRAN (MOD INTERRATHOUTRANGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a parameter group related to inter-RAT handover to UTRAN.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranGroupId InterRAT handover to UTRAN Group ID

Meaning: Indicates the ID of the parameter group related to inter-RAT handover to UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranB1ThdEcn0 CoverageBased UTRAN ECN0 trigger threshold

Meaning: Indicates the Ec/N0 threshold for event B1 related to coverage-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for Ec/N0 of the target UTRAN cell. For a cell with large signal fading variance, set this parameter to a large value to prevent unnecessary handovers. For a cell with small signal fading variance, set this parameter to a small value to ensure timely handovers. A large value of this parameter results in a low probability of handover to the UTRAN cell, and a small value leads to a high probability.

When the measured value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -48~0

Unit: 0.5dB

Actual Value Range: -24~0

MML Default Value: None

Recommended Value: -24

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handovers to UTRAN, and a smaller value results in a higher probability.

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranB1ThdRscp CoverageBased UTRAN RSCP trigger threshold

Meaning: Indicates the RSCP threshold for event B1 related to coverage-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for RSCP of the target UTRAN cell.

When the measurement value exceeds this threshold, a measurement report will be sent. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -120~-25

Unit: dBm

Actual Value Range: -120~-25

MML Default Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranB1Hyst UTRAN handover hysteresis

Meaning: Indicates the hysteresis for event B1 related to inter-RAT handover to UTRAN. This parameter is used to prevent frequent triggering of event evaluation caused by radio signal fluctuation. In this way, the probability of ping-pong handovers or handover decision errors is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers or handover decision errors. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The entering condition of event B1 is as follows: Mn + Ofn - Hys > Thresh.

Mn is the measurement value of the neighboring cell. Ofn is the frequency-specific offset of the neighboring cell. Thresh is the threshold for event B1. Hys is the hysteresis for event B1.

A larger value of Hys results in a lower probability of triggering event B1 and therefore a lower probability of handover. A large value may affect user experience. A smaller value of Hys leads to a higher probability of triggering event B1. A small value may cause handover decision errors and ping-pong handovers.

Applicable Mode: L-FDD, L-TDD
InterRatHoUtranB1TimeToTrig UTRAN time to trigger

Meaning: Indicates the time-to-trigger for events B1 and B2 related to EUTRAN-to-UTRAN handovers. When detecting that the entering condition for the corresponding event is fulfilled, the UE does not immediately send a measurement report to the eNodeB. Instead, the UE sends a report only when the entering condition is fulfilled throughout the time-to-trigger. This parameter helps decrease the number of occasionally triggered event reports, the average number of handovers, and the number of incorrect handovers, preventing unnecessary handovers. This parameter applies only to LTE FDD and LTE TDD.

Unit: ms

Recommended Value: 320ms(320ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

LdSvBasedHoUtranB1ThdEcn0 Load Service Based UTRANB1 ECN0 threshold

Meaning: Indicates the Ec/N0 threshold for event B1 related to load- or service-based inter-RAT handover to UTRAN.

This parameter specifies the requirement for Ec/N0 of the target UTRAN cell. When the measurement value exceeds this threshold, a measurement report may be sent. For a cell with large signal fading variance, set this parameter to a large value to prevent unnecessary handovers. For a cell with small signal fading variance, set this parameter to a small value to ensure timely handovers. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -48~0

Unit: 0.5dB

Actual Value Range: -24~0

MML Default Value: None

Recommended Value: -18

Parameter Relationship:

-Others:

  • If coverage-based handover is enabled and the threshold specified by this parameter is higher than the associated threshold for coverage-based inter-RAT handover, coverage-based handover takes precedence over both load- and service-based handovers. In this case, load- and service-based handovers will not occur.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of handover to the UTRAN cell, and a smaller value leads to a higher probability.

This parameter specifies the requirement for RSCP of the target UTRAN cell.

HSInterRatHoUtranB1TimeTrig High Speed Inter RAT HO UTRAN B1 Time To Trigger

Meaning: Indicates the time-to-trigger for event B1 or B2 related to handovers to UTRAN for high-speed UEs in high-speed cells. When detecting that the signal quality in at least one neighboring cell meets the entering condition, the UE does not send a measurement report to the eNodeB immediately. Instead, the UE sends a report only when the signal quality continuously meets the entering condition during the time-to-trigger. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: 64ms(64ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that high-speed UEs report event B1 or B2 for triggering inter-RAT handovers and a higher probability of service drops due to untimely handovers. A smaller value of this parameter results in a higher probability that high-speed UEs report event B1 or B2 for inter-RAT handovers and a higher probability of triggering handovers.

Applicable Mode: L-FDD, L-TDD

Example

To modify a parameter group related to inter-RAT handover to UTRAN as follows: Local cell identity: 0, InterRatHoUtranGroupId: 0, CoverageBased UTRAN ECN0 trigger threshold: -20, run the following command:
MOD INTERRATHOUTRANGROUP: LocalCellId=0, InterRatHoUtranGroupId=0, InterRatHoUtranB1ThdEcn0=-20;
