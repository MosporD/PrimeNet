List Cell RF Channel Intelligent Shutdown Configuration (LST CELLRFSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of RF channel intelligent shutdown for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configuration of cell RF channel intelligent shutdown with Local cell ID of 1, run the following command:
LST CELLRFSHUTDOWN: LocalCellId=1;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

RF intelligent shutdown switch

Indicates whether to enable intelligent RF channel shutdown. The eNodeB can perform intelligent RF channel shutdown when specific criterion is met only if this parameter is set to ON. If this parameter is set to DETECTION, the eNodeB only detects and measures the duration when intelligent RF channel shutdown can be triggered, but does not perform intelligent RF channel shutdown.

Start time

Indicates the start time of RF channel intelligent shutdown for the cell.

Stop time

Indicates the stop time of RF channel intelligent shutdown for the cell. If the stop time is earlier than or the same as the start time, the stop time is assumed to be a time of the next day.

Reference signal power adjust offset(dB)

Indicates the value by which the reference signal power is increased during the RF channel intelligent shutdown period. The reference signal power increases by the value specified by this parameter to ensure coverage of the cell. If this parameter is set to a value greater than 3, the value 3 is used. Otherwise, the configuration value is used. This parameter applies only to LTE FDD and LTE TDD.

Downlink PRB threshold(%)

Indicates the downlink PRB usage threshold for RF channel intelligent shutdown. For NB-IoT cells, this parameter indicates the downlink subcarrier usage threshold for RF channel intelligent shutdown. A cell enters the RF channel intelligent shutdown mode when the current cell load is less than or equal to both the uplink PRB usage threshold and downlink PRB usage threshold. A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a lower probability that the cell will enter the RF channel intelligent shutdown mode, which does not facilitate eNodeB power saving. A larger value of this parameter leads to a higher probability that the cell will enter the RF channel intelligent shutdown mode, which affects services.

Uplink PRB threshold(%)

Indicates the uplink PRB usage threshold for RF channel intelligent shutdown. For NB-IoT cells, this parameter indicates the uplink subcarrier usage threshold for RF channel intelligent shutdown. A cell enters the RF channel intelligent shutdown mode when the current cell load is less than or equal to both the uplink PRB usage threshold and downlink PRB usage threshold. A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a lower probability that the cell will enter the RF channel intelligent shutdown mode, which does not facilitate eNodeB power saving. A larger value of this parameter leads to a higher probability that the cell will enter the RF channel intelligent shutdown mode, which affects services.

Downlink PRB offset(%)

Indicates the offset to the downlink PRB usage for RF channel intelligent shutdown.

For NB-IoT cells, this parameter indicates the offset to the downlink subcarrier usage for RF channel intelligent shutdown.

A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a higher probability that the cell will exit the RF channel intelligent shutdown mode and also a higher probability of ping-pong switchover between entry into and exit from the RF channel shutdown mode. A larger value of this parameter leads to a lower probability that the cell will exit the RF channel intelligent shutdown mode, which affects services.

Uplink PRB offset(%)

Indicates the offset to the uplink PRB usage for RF channel intelligent shutdown.

For NB-IoT cells, this parameter indicates the offset to the uplink subcarrier usage for RF channel intelligent shutdown.

A cell exits the RF channel intelligent shutdown mode when the cell load reaches 100%, or when the cell load is greater than the sum of the uplink PRB usage threshold and the offset to the uplink PRB usage or the sum of the downlink PRB usage threshold and the offset to the downlink PRB usage.

A smaller value of this parameter leads to a higher probability that the cell will exit the RF channel intelligent shutdown mode and also a higher probability of ping-pong switchover between entry into and exit from the RF channel shutdown mode. A larger value of this parameter leads to a lower probability that the cell will exit the RF channel intelligent shutdown mode, which affects services.

UE Number Threshold

Indicates the UE number threshold for RF channel intelligent shutdown. The cell enters RF channel intelligent shutdown mode if all of the following conditions are met: (1) the number of RRC_CONNECTED UEs is less than or equal to this threshold; (2) the uplink cell load is lower than or equal to the preset uplink PRB usage; (3) the downlink cell load is lower than or equal to the preset downlink PRB usage. The cell exits RF channel intelligent shutdown mode if any of the following conditions is met: (1) the number of RRC_CONNECTED UEs exceeds this threshold; (2) the uplink cell load is higher than the sum of the uplink PRB usage threshold and the uplink PRB usage offset; (3) the downlink cell load is higher than the sum of the downlink PRB usage threshold and the downlink PRB usage offset. A smaller value of this parameter leads to a lower probability that the cell will enter RF channel intelligent shutdown, which does not facilitate base station power saving. A larger value of this parameter leads to a higher probability that the cell will enter RF channel intelligent shutdown, which affects services. For LTE TDD cells, this parameter takes effect only when the RfShutdownJudgingPolicy parameter in the CellRfShutdown MO is set to PRB_AND_UE_NUMBER.

RF Intelligent Shutdown Judging Policy

Indicates the basis for entering or exiting RF channel intelligent shutdown. If this parameter is set to PRB(PRB), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage of the cell. If this parameter is set to PRB_AND_UE_NUMBER(PRB_AND_UE_NUMBER), the eNodeB determines whether to enter or exit RF channel intelligent shutdown for the cell, based on the uplink and downlink PRB usage and the number of online UEs in the cell. This parameter applies only to LTE TDD.

RF Channel Shutdown Power Check Switch

Indicates whether to enable power check for RF channel shutdown. SYMBOL_0_POWER_CHECK_OPT_SW: Indicates whether to enable symbol 0 power check optimization for RF channel shutdown. If this option is selected, symbol 0 power check optimization is performed after RF channel shutdown takes effect, preventing continuous PDCCH allocation failures. If this option is deselected, symbol 0 power check optimization is not performed after RF channel shutdown takes effect, which may lead to continuous PDCCH allocation failures. This option applies only to LTE TDD.

Multi-RAT Joint Channel Shutdown Switch

Indicates whether to enable multi-RAT joint channel shutdown. If this parameter is set to ON for a cell, multi-RAT joint channel shutdown takes effect in the cell under certain conditions. If this parameter is set to OFF, the function does not take effect. This parameter applies only to LTE FDD.

Penalty Duration(min)

Indicates the duration of penalty imposed on a cell that has exited RF channel intelligent shutdown and meets the penalty condition. In the penalty period, the conditions for triggering RF channel intelligent shutdown will not be checked for the cell.
