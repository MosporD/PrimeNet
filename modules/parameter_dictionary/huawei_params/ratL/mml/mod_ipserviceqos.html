Modify Mappings between DSCPs and QoS Policies of IP Packets (MOD IPSERVICEQOS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify mappings between DSCPs and QoS policies of IP packets.

Note

None.

Parameters

ID Name Description
Dscp Differentiated Services Code Point

Meaning: Indicates a differentiated services code point (DSCP) for IP packets. Different types of traffic can be assigned different DSCPs within the range of 1 to 63. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~63

Unit: None

Actual Value Range: 1~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Description Traffic Description

Meaning: Indicates a service description. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
QosPolicyTimeSwitch QoS Policy Time Switch

Meaning: Indicates whether to use different rate measures in two phases for QoS purposes. This switch is required only for video services, not for other services. If this switch is turned on for video services, the eNodeB provides an initial acceleration in the first phase and a normal rate guarantee in the second phase. If this switch is turned off, the eNodeB provides a normal rate guarantee from the start. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FirQosPolicyId First QoS Policy Identity

Meaning: Indicates the ID of the QoS policy used in the first phase of a video service. If the QosPolicyTimeSwitch parameter is set to ON, the QoS policy is used in the initial phase of the service; if this parameter is set to OFF, the QoS policy is used across the entire process of the service. The FirQosPolicyId parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). In this case, the system sets FirQosPolicyId to 255 by default, which is an invalid value. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127,255

Unit: None

Actual Value Range: 0~127,255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The FirQosPolicyId parameter in an IpServiceQos MO can be set to 255 only when the PREALLOCATION_SW option of the ApplicationRange parameter in this IpServiceQos MO is selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of the same parameter is deselected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FirQosPolicyTimeLength First QoS Policy Time Length

Meaning: Indicates the time length of the first phase in which the eNodeB provides initial acceleration for video services. When the QosPolicyTimeSwitch parameter is set to ON, the FirQosPolicyTimeLength parameter must be set to a value greater than 0. A larger value indicates longer acceleration time. When the QosPolicyTimeSwitch parameter is set to OFF, the FirQosPolicyTimeLength parameter does not need to be set, and the default value 0 is used. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: s

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SecQosPolicyId Second QoS Policy Identity

Meaning: Indicates the QoS policy to be used after initial acceleration is complete for a video service. If the QosPolicyTimeSwitch parameter is set to ON, set the SecQosPolicyId parameter to an existing QosPolicyId value in the range of 0 to 127. If the QosPolicyTimeSwitch parameter is set to OFF, the SecQosPolicyId parameter does not need to be set. In this case, the system sets SecQosPolicyId to 255 by default, which is an invalid value. This parameter does not take effect if the QoS policy applies only to DSCP-based preallocation (with the PREALLOCATION_SW option of the ApplicationRange parameter selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of this parameter deselected). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~127,255

Unit: None

Actual Value Range: 0~127,255

MML Default Value: None

Recommended Value: 0~127

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ApplicationRange Application Range

Meaning: Indicates the scope of functions to which a QoS policy is applicable.

VIDEO_AND_DWNLD_RATE_CTRL_SW: If this option is selected, the QoS policy is applicable to DSCP-based video service rate adaptation and busy-hour download rate control. If this option is deselected, the QoS policy is not applicable to DSCP-based video service rate adaptation and busy-hour download rate control. This option applies only to LTE FDD and LTE TDD.

PREALLOCATION_SW: If this option is selected, the QoS policy is applicable to DSCP-based preallocation. If this option is deselected, the QoS policy is not applicable to DSCP-based preallocation. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: VIDEO_AND_DWNLD_RATE_CTRL_SW(VIDEO_AND_DWNLD_RATE_CTRL_SW), PREALLOCATION_SW(PREALLOCATION_SW)

Unit: None

Actual Value Range: VIDEO_AND_DWNLD_RATE_CTRL_SW, PREALLOCATION_SW

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • One of the VIDEO_AND_DWNLD_RATE_CTRL_SW and PREALLOCATION_SW options of the ApplicationRange parameter in the IpServiceQos MO must be selected.
  • The FirQosPolicyId parameter in an IpServiceQos MO can be set to 255 only when the PREALLOCATION_SW option of the ApplicationRange parameter in this IpServiceQos MO is selected and the VIDEO_AND_DWNLD_RATE_CTRL_SW option of the same parameter is deselected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration of IpServiceQos with the parameters as follows: Dscp:10, QosPolicyTimeSwitch: ON, First QoS Policy Identity:20, run the following command:
MOD IPSERVICEQOS: Dscp=10, QosPolicyTimeSwitch=OFF, FirQosPolicyId=20;
