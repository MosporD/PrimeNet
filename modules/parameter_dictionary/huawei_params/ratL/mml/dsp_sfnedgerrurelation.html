Display Super Combined Cell Status (DSP SFNEDGERRURELATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration status and reasons for abnormal configurations of neighboring SFN cells in a super combined cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To Display the SFN edge RRU relation dynamic information with the local cell ID of 0, run the following command:
DSP CELL: LocalCellId=0;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD.

Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment used by an SFN cell. It uniquely identifies a set of sector equipment within an eNodeB. This parameter applies only to LTE FDD.

Mobile Country Code

Indicates the MCC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345. This parameter applies only to LTE FDD.

Mobile Network Code

Indicates the MNC of a neighboring SFN cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD.

eNodeB ID

Indicates the eNodeB ID of a neighboring SFN cell. This parameter applies only to LTE FDD.

Neighbor Cell ID

Indicates the ID of a neighboring SFN cell. This parameter applies only to LTE FDD.

Neighbor Sector Equipment ID

Indicates the ID of an edge physical cell's sector equipment of a neighboring SFN cell. This parameter applies only to LTE FDD.

Super Combined Cell Status

Indicates the status of the super combined cell. This parameter applies only to FDD cells.

Effect Failure Reason

Indicates the reason of the Super Combined Cell feature activation failure. This parameter applies only to FDD cells.

Data Configuration Status

Indicates the parameter setting status of SFN cells in a super combined cell. The status is used to determine whether parameter settings for neighboring SFN cells are appropriate. This parameter applies only to FDD cells.

Data Configuration Failure Reason

Indicates the reason of abnormal parameter settings in neighboring SFN cells in a super combined cell. This parameter applies only to FDD cells.
