Add RbcaFwdCount Parameters (ADD RBCAFWDCOUNTPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a set of parameters related to the index of performance counter measuring data forwarded in relaxed-backhaul-based CA.

Note

None.

Parameters

ID Name Description
FwdCounterIndex Forward Counter Index

Meaning: Indicates the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PccMcc PCC Mobile Country Code

Meaning: Indicates the mobile country code of the PCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PccMnc PCC Mobile Network Code

Meaning: Indicates the mobile network code of the PCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SccMcc SCC Mobile Country Code

Meaning: Indicates the mobile country code of the SCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Applicable Mode: L-FDD, L-TDD
SccMnc SCC Mobile Network Code

Meaning: Indicates the mobile network code of the SCC mapped to the counter index related to the data forwarded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

MML Default Value: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a set of parameters related to the index of performance counters measuring the amount of data forwarded in relaxed-backhaul-based CA with the parameters as follows: Forward Counter Index: 1, PCC Mobile Country Code: 460, PCC Mobile Network Code: 300, SCC Mobile Country Code: 460, SCC Mobile Network Code: 200:

O&M    #806354986
%%ADD RBCAFWDCOUNTPARA: FwdCounterIndex=1, PccMcc="460", PccMnc="300", SccMcc="460", SccMnc="200";%%
