List Cell TTI Bundling Algorithm Configuration (LST CELLTTIBUNDLINGALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters related to the TTI bundling algorithm of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of TTI bundling of a cell:
LST CELLTTIBUNDLINGALGO:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

SINR Threshold To Trigger TTI Bundling

Indicates the configuration policy and value of the SINR threshold when TTI bundling is enabled for a UE. If this parameter is set to 255, the SINR threshold configuration policy is "dynamic calculation", indicating that the SINR threshold is dynamically calculated based on the voice packet size and channel quality. If this parameter is set to a value other than 255, the SINR threshold configuration policy is "manual configuration", indicating that the SINR threshold is manually configured on the GUI. This parameter applies only to LTE FDD.

SINR Threshold To Trigger Video TTI Bundling

Indicates the SINR threshold for triggering TTI Bundling for video services of UEs. This parameter applies only to LTE FDD.

TTI Bundling Algorithm Switch

Indicates whether to enable TTI bundling optimization.

TTIB_EXIT_BASED_ON_QCI_SW: Indicates whether to enable exit from TTI bundling for specific QCIs. If this option is selected, UEs exit TTI bundling after beneficiary bearers (applicable to VoLTE, PTT, and video services) are removed. If this option is deselected, the exit is not supported. This option applies only to LTE FDD.

TTIBUNDLING_ALGO_ENHANCE_SW: Indicates whether to enable TTI bundling during handovers or RRC connection reestablishments and use high-index MCSs for TTI bundling. TTI bundling is enabled during handovers and RRC connection reestablishments (applicable to VoLTE and PTT) and high-index MCSs are used for TTI bundling (applicable to VoLTE, PTT, and video services) only when this option is selected. This option applies only to LTE FDD.

R12 TTI Bundling HARQ Max Trans Num

Indicates the maximum number of uplink HARQ transmissions in TTI bundling mode from a UE capable of R12 TTI bundling. For details, see 3GPP TS 36.331. This parameter applies only to FDD.

R12 TTI Bundling Switch

Indicates whether to enable R12 TTI bundling.

If this parameter is set to ON, R12 TTI bundling works for UEs that support this function. If this parameter is set to OFF, R12 TTI bundling cannot take effect on these UEs. This parameter applies only to FDD.

SINR Threshold To Trigger R12 TTI Bundling(dB)

Indicates the SINR threshold used to trigger TTI bundling for UEs capable of R12 TTI bundling. This parameter applies only to FDD.
