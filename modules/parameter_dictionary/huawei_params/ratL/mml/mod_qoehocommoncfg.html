Modify QoE-Based Handover Common Parameters (MOD QOEHOCOMMONCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify common parameters related to QoE-based handovers.

Note

None.

Parameters

ID Name Description
QoEBasedHandoverStat QoE-Based Handover Stat

Meaning: Indicates the value N in the P/N rule for QoE-based handover decision. If the throughput is unsatisfactory for P consecutive times during the measurement period N, QoE-based handover is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~60

Unit: s

Actual Value Range: 0~60

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability of triggering a QoE-based handover and therefore a larger number of handovers. A larger parameter value results in a lower probability of triggering a QoE-based handover and a lower throughput of video service.

Applicable Mode: L-FDD, L-TDD
QoEBasedHandoverLast QoE-Based Handover Last

Meaning: Indicates the value P in the P/N rule for QoE-based handover decision. If the throughput is unsatisfactory for P consecutive times during the measurement period N, QoE-based handover is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~60

Unit: s

Actual Value Range: 0~60

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability of triggering a QoE-based handover and therefore a larger number of handovers. A larger parameter value results in a lower probability of triggering a QoE-based handover and a lower throughput of video service.

Applicable Mode: L-FDD, L-TDD

Example

To modify the configuration QoE Handover Common Configuration with the parameters as follows: QoE-Based Handover Stat: 6, run the following command:
MOD QOEHOCOMMONCFG: QoEBasedHandoverStat=6;
