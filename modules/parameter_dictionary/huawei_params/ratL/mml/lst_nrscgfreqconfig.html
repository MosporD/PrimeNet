List NR SCG Frequency Configuration (LST NRSCGFREQCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of a candidate SCC in an NR SCG.

Note

None.

Parameters

Meaning: Indicates the downlink EARFCN of the PCC. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

Actual Value Range: 0~70545,229376~229575

  • The PccDlEarfcn parameter value in an NrScgFreqConfig MO must be a valid frequency number.

Output Description

Field Description

PCC DL EARFCN

Indicates the downlink EARFCN of the PCC. This parameter applies only to LTE FDD and LTE TDD.

SCG DL ARFCN

Indicates the downlink SSB ARFCN of a candidate SCC in the NR SCG. For details about this parameter, see 3GPP TS 38.104. This parameter applies only to LTE FDD and LTE TDD.

SCG DL ARFCN Priority

Indicates the downlink frequency priority for a candidate SCC in the NR SCG. This parameter applies only to LTE FDD and LTE TDD.

NSA DC B1 Event RSRP Threshold(dBm)

Indicates the RSRP threshold for event B1 during NR SCG configuration by the eNodeB. When the measured RSRP exceeds this threshold, event B1 is reported. This parameter applies only to LTE FDD and LTE TDD.

NR B1 Time To Trigger

Indicates the time-to-trigger for NR frequency measurement event B1. Event B1 is not immediately reported at the moment that the signal quality of an NR cell meets the condition for triggering measurement reports for event B1. Instead, it is reported if the signal quality always meets the condition within the period specified by this parameter. This parameter reduces accidentally reported event B1. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

NSA DC SUL B1 Event RSRP Threshold(dBm)

Indicates the RSRP threshold for reporting event B1, based on which the eNodeB configures NR SCGs for SUL-capable UEs. If the measured RSRP value exceeds this threshold, an event B1 measurement report will be reported. This parameter applies only to LTE FDD.

NR Frequency Band

Indicates the NR SUL frequency bands. If the option corresponding to a frequency band is selected, the SCG supports this frequency band. In this case, the ScgDlArfcnPriority, NsaDcB1ThldRsrp, and NrB1TimeToTrigger parameters for the frequency band become invalid. This parameter applies only to LTE FDD and LTE TDD.

Aggregation Attribute

Indicates the aggregation attributes of the combination of the PCC frequency band and the corresponding NR SCG frequency band.

CO_DEPLOYMENT_NSA_FLAG: If this option is selected, mobility management procedures specific to co-site deployment are allowed in the frequency band combination. If this option is deselected, mobility management procedures specific to co-site deployment are not allowed in the frequency band combination. This option applies only to LTE FDD and LTE TDD.

SINGLE_UL_NSA_FLAG: If this option is selected, the support of only uplink single-side transmission is allowed in the frequency band combination in NSA DC scenarios. If this option is deselected, the support of only uplink single-side transmission is not allowed in the frequency band combination in NSA DC scenarios. This option applies only to LTE FDD.
