List Parameters Related to Inter-eNodeB CAMC (LST EUULCOSCHCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of parameters related to inter-eNodeB CAMC, such as the delay for coordinated information to take effect.

Note

None.

Parameters

None.

Example

To list the configurations of inter-eNodeB CAMC, run the following command: :
LST EUULCOSCHCFG:;
The result is shown as follows:
+++    0        2019-12-05 17:33:10
O&M    #806356022
%%LST EUULCOSCHCFG: ;%%
RETCODE = 0  Operation succeeded.

List Parameters Relationed To Inter-eNodeB CAMC
-----------------------------------------------
UL Inter eNodeB Coordinated AMC Switch  =  Off
(Number of results = 1)


---    END

Output Description

Field Description

UL Inter eNodeB Coordinated AMC Switch

Indicates whether to enable inter-eNodeB coordinated uplink AMC in the centralized Cloud BB networking. This parameter applies only to LTE TDD.
