Display Primary Baseband Processing Board Information (DSP PRIBBPRESINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the used and remaining resources on the primary baseband processing board.

Note

  • Use this command to query information about the remaining capability of a master BBP, which must be an LBBPc, LBBPd, or UBBPd. UBBPd supports the query only when its working mode is set to LTE_FDD, LTE_TDD, or LTE_FDD&LTE_TDD. A BBP does not support the query if its working mode is set to TDD_ENHANCE.

  • Multi-PRB cell with SectorEqmNum more than 3 does not support querying information about the remaining capability.

Output Description

Field Description

1 RRU Cell Number

Indicates the number of cells (each cell is served by one RRU) supported by the remaining resources on the primary baseband processing board.

2 RRU Cell Number

Indicates the number of cells (each cell is served by two RRUs) supported by the remaining resources on the primary baseband processing board.

3 RRU Cell Number

Indicates the number of cells (each cell is served by three RRUs) supported by the remaining resources on the primary baseband processing board.

4 RRU Cell Number

Indicates the number of cells (each cell is served by four RRUs) supported by the remaining resources on the primary baseband processing board.

5 RRU Cell Number

Indicates the number of cells (each cell is served by five RRUs) supported by the remaining resources on the primary baseband processing board.

6 RRU Cell Number

Indicates the number of cells (each cell is served by six RRUs) supported by the remaining resources on the primary baseband processing board.

7 RRU Cell Number

Indicates the number of cells (each cell is served by seven RRUs) supported by the remaining resources on the primary baseband processing board.

SectorEqm(SectorEqmGroup) Number

Indicates the quantity of resources occupied by the cell on the primary baseband processing board. The resource quantity is indicated by the number of RRUs.

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

eNodeB Du ID

Indicates the ID of the eNodeB DU. A hyphen (-) indicates an invalid value.
