Remove QCI-specific UE Timer (RMV QCIUETIMERCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a QCI-specific UE timer.

Note

None.

Parameters

ID Name Description
TimerType Timer Type

Meaning: Indicates the timer type. This parameter applies only to NB-IoT.

GUI Value Range: NB_CL0_UE_INACTIVITY_TIMER(NB_CL0_UE_INACTIVITY_TIMER), NB_CL1_UE_INACTIVITY_TIMER(NB_CL1_UE_INACTIVITY_TIMER), NB_CL2_UE_INACTIVITY_TIMER(NB_CL2_UE_INACTIVITY_TIMER), NB_T310(NB_T310), NB_N310(NB_N310), NB_T311(NB_T311), NB_N311(NB_N311)

Unit: None

Actual Value Range: NB_CL0_UE_INACTIVITY_TIMER, NB_CL1_UE_INACTIVITY_TIMER, NB_CL2_UE_INACTIVITY_TIMER, NB_T310, NB_N310, NB_T311, NB_N311

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
Qci QoS Class Identifier

Meaning: Indicates the QoS class identifier (QCI), which is an attribute of EPS bearers. Different QCIs represent different QoS specifications, such as packet delay, packet loss rate, packet error rate, and service type (whether the service is a GBR service or not). For details, see Table 6.1.7 in 3GPP TS 23.203.

GUI Value Range: 1~254

Unit: None

Actual Value Range: 1~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove QciUeTimerConfig with the parameters as follows: Timer Type: NB_CL1_UE_INACTIVITY_TIMER, QoS Class Identifier: 15, run the following command:
RMV QCIUETIMERCONFIG: TimerType=NB_CL1_UE_INACTIVITY_TIMER, Qci=15;
