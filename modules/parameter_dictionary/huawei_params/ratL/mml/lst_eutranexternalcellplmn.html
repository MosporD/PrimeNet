List PLMN List for External E-UTRAN Cell (LST EUTRANEXTERNALCELLPLMN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list an additional PLMN ID for an external E-UTRAN cell.

Note

None.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code of the external cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, if the MCC is 123 and the MNC is 45, then the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an EutranExternalCellPlmn MO consists of digits only.
  • In an EutranExternalCellPlmn MO, the combination of Mnc and Mcc must be different from that of ShareMnc and ShareMcc.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
