Modify Cell Beamforming Configuration (MOD CELLBF)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the information used to control the single-stream or dual-stream beamforming.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Modifying the PdschSplitBeamConfigIndex parameter will result in automatic reset of the cell.

  • If a TDD cell is activated, the TM9HybridPrecodingSwitch option of the CellAlgoSwitch.EnhMIMOSwitch parameter must be deselected before setting the CellCsiRsParaCfg.CsiRsPortNum parameter and the CellBf.PdschSplitBeamConfigIndex parameter to CSI_RS_PORT_8 and CONFIG_INDEX4, respectively.

HeavyLoadSwitchToBfOpt Heavy-Load Switch to BF Optimization

Meaning: Indicates whether to enable the optimization of switching to beamforming in heavy-load scenarios.

If this parameter is set to 255, the optimization does not take effect.

For massive MIMO cells, if this parameter is set to a value other than 255 and the MultiLayerThdSwitchToTM7 or WaitPairingLayerThd parameter in the CellBf MO is set to a value other than 0, online WBB UEs are allowed to be switched to beamforming in heavy-load scenarios. If the HEAVYLOADTRANSMODEADAPTBOOSTSW and HISTORICALSPECTRALEFFOPTSW options of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO are both selected, adaptive switching between cell-level transmission mode adaptation and cell-level target transmission mode is enabled only when the average number of downlink pairing layers is less than or equal to the value of this parameter.

For non-massive MIMO cells, if this parameter is set to a value other than 255, the HEAVYLOADTRANSMODEADAPTBOOSTSW option of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO is selected, and a UE supporting three or more layers in TM9 uses TM9 with PMI in 5 seconds after accessing a cell using the target transmission mode, then it will not be forcibly switched to beamforming.

Unit: None

Actual Value Range: 0~24,25.5, step: 0.1

MML Default Value: None

Recommended Value: 13

Impact on Radio Network Performance: For massive MIMO cells, if this parameter is set to a value other than 255 and the MultiLayerThdSwitchToTM7 or WaitPairingLayerThd parameter in the CellBf MO is set to a value other than 0, the more WBB UEs, the higher the proportion of beamforming UEs in heavy-load scenarios. This increases the number of downlink pairing layers and may increase the downlink spectral efficiency and downlink user-perceived rate. However, when UE pairing is inapplicable, the downlink spectral efficiency and downlink user-perceived rate decrease. If the HEAVYLOADTRANSMODEADAPTBOOSTSW and HISTORICALSPECTRALEFFOPTSW options of the BfMimoAlgoOptSwitch parameter in the CellBfMimoParaCfg MO are both selected, a smaller value of this parameter results in a lower probability of adaptive switching to cell-level transmission mode adaptation and a higher proportion of beamforming UEs in heavy-load scenarios. The downlink spectral efficiency increases when UE pairing is applicable, but decreases when UE pairing is inapplicable.

For non-massive MIMO cells, the more UEs supporting three or more layers in TM9, the lower the proportion of beamforming UEs in heavy-load scenarios. If all UEs supporting three or more layers in TM9 are located at the cell center, single-UE multi-layer gains can be obtained and downlink spectral efficiency increases. If all UEs supporting three or more layers in TM9 are located away from the cell center, single-UE multi-layer gains cannot be obtained. In addition, the number of pairing layers in a cell and the downlink spectral efficiency decrease.
