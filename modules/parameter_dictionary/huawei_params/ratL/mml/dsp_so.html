Display SO Configuration (DSP SO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the control-plane information about the SO interface.

Note

None.

Parameters

ID Name Description
SoId SO ID

Meaning: Indicates the ID of the SO MO. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: Currently, customers have no requirements for the SO interface. This parameter will be deleted in later versions. Although the configuration interface in this version still supports synchronization and delivery of the setting of this parameter, the system no longer uses this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

DSP SO:
+++    HUAWEI        2014-11-19 15:47:21
O&M    #24263
%%DSP SO:;%%
RETCODE = 0  Operation succeeded.

Display SO Configuration
-------------------------
                       SO ID  =  0
   SO Interface CP Bearer ID  =  0
SO Interface CP Bearer State  =  Abnormal
(Number of results = 1)


---    END

Output Description

Field Description

SO ID

Indicates the ID of the SO MO. This parameter applies only to LTE FDD and LTE TDD.

SO Interface CP Bearer ID

Indicates the ID of the control port (CP) bearer for the SO interface. This parameter applies only to LTE FDD and LTE TDD.

SO Interface CP Bearer State

Indicates the status of the CP bearer for the SO interface. This parameter applies only to LTE FDD and LTE TDD.
