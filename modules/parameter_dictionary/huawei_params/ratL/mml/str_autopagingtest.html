Start Fault Recovery Detection on NB-IoT or eMTC Cell (STR AUTOPAGINGTEST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to start fault recovery detection on an NB-IoT or eMTC cell to obtain the state information after a cell recovers.

Note

This command generates a temporary TAC in the eNodeB. The temporary TAC is not equal to the value allocated by the core network. The TAC is then sent to NB-IoT or eMTC UEs through system information. If there are a large number of UEs in the target cell, paging all these UEs may cause these UEs to access the target cell simultaneously, resulting in signaling congestion. Before delivering the command for detection, evaluate the number of UEs and select a proper paging proportion. If the number of UEs is large, set a small paging proportion. If the number of UEs is small, set a large paging proportion.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
PagingRatio Paging Ratio

Meaning: Indicate the paging ratio of a cell. This parameter controls whether paging is initiated for some or all of the UEs in a cell. The value ALL indicates that paging is initiated for all UEs in a cell. The value HALF indicates that paging is initiated for only 1/2 of the UEs in a cell. The value QUARTER indicates that paging is initiated for only 1/4 of the UEs in a cell. The value ONE_8TH indicates that paging is initiated for only 1/8 of the UEs in a cell. The value ONE_16TH indicates that paging is initiated for only 1/16 of the UEs in a cell. The value ONE_32TH indicates that paging is initiated for only 1/32 of the UEs in a cell. The value ONE_64TH indicates that paging is initiated for only 1/64 UEs in a cell. The value ONE_128TH indicates that paging is initiated for only 1/128 of the UEs in a cell.

Note: According to the descriptions of paging in 3GPP TS36.304, the paging ratio of a cell is related to the number of paging groups set for the cell. The minimum allowed paging ratio is the reciprocal of the number of radio frames in a paging cycle or the number of paging groups, whichever number is smaller. The number of radio frames in a paging cycle for NB-IoT is specified by the DefaultPagingCycleForNb parameter in the PcchCfg MO, and the number of radio frames in a paging cycle for eMTC is specified by the DefaultPagingCycle parameter in the PcchCfg MO. The number of paging groups for NB-IoT is specified by the NbForNbIoT parameter in the PcchCfg MO, and the number of paging groups for eMTC is specified by the PagingGroupNum parameter in the CellCeSchCfg MO. For example, if the paging cycle is 128 radio frames and the number of paging groups equals 1/32 of the number of radio frames in a paging cycle, the minimum allowed paging ratio is 1/4, which is the result of 1/MIN[128, (1/32) x 128]. If the paging ratio specified by this parameter is less than or equal to the minimum allowed value, the minimum allowed value takes effect.

GUI Value Range: ALL(ALL), HALF(HALF), QUARTER(QUARTER), ONE_8TH(ONE_8TH), ONE_16TH(ONE_16TH), ONE_32TH(ONE_32TH), ONE_64TH(ONE_64TH), ONE_128TH(ONE_128TH)

Unit: None

Actual Value Range: ALL, HALF, QUARTER, ONE_8TH, ONE_16TH, ONE_32TH, ONE_64TH, ONE_128TH

MML Default Value: QUARTER(QUARTER)

Recommended Value: QUARTER(QUARTER)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
