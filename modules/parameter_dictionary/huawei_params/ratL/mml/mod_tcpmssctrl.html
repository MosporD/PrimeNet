Modify TCP MSS Control Algorithm Parameter (MOD TCPMSSCTRL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the TCP MSS control algorithm.

Note

None.

Parameters

ID Name Description
TcpMssCtrlSwitch TCP MSS Control Switch

Meaning: Indicates the switch used to enable or disable the TCP MSS function. If this switch is turned off, TCP packets are transparently transmitted without being processed. If this switch is turned on, the value of the MSS field in each packet for TCP link setups can be modified. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is turned on, the TCP MSS function is enabled, which means users can specify MSS parameters for TCP services. In scenarios where packet loss occurs when fragmentation is performed, turning on this switch avoids packet fragmentation and decreases the number of lost packets. When this switch is turned off, there is no impact on radio network performance.

Applicable Mode: L-FDD, L-TDD
TcpMssThd TCP MSS Threshold

Meaning: Indicates the threshold for the value of the MSS field in packets for TCP link setups. If the TCP MSS function is enabled, the eNodeB first checks the MSS field in each packet for TCP link setups. If the value of the MSS field is greater than the predefined threshold, the eNodeB changes the value of the MSS field to the predefined threshold. Then, the eNodeB recalculates the TCP checksum and retransmits the packet with modified fields. For other packets, the eNodeB transparently transmits them.

DisuseStatement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 1~1460

Unit: byte

Actual Value Range: 1~1460

MML Default Value: None

Recommended Value: When MTU is set to 1500 and no security tunnel is set up, the recommended value is 1420.

When MTU is set to 1500 and a security tunnel is set up, the recommended value is 1342, where 78 bytes are used by security tunnel header by default. In other scenarios, set the recommended value based on the description in Caution.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a smaller MSS field value in packets for TCP link setups. If this parameter value is too small, transmission efficiency decreases and the throughput is reduced. If this parameter value is too large, the MSS control function does not take effect.

Applicable Mode: L

Example

To modify the configuration of TCP MSS control algorithm with the parameters as follows:TCP MSS Control Switch:ON, TCP MSS Threshold:1230, run the following command:
MOD TCPMSSCTRL: TcpMssCtrlSwitch=ON, TcpMssThd=1230;
