Modify Cell CSPC Parameter (MOD CELLCSPCPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the CSPC configuration in a cell.

Note

Before enabling this function, change the MeasBandWidth parameter value. You are advised to change the MeasBandWidth parameter value to MBW6(1.4M).

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
eCspcPCAdjUeNumTh eCSPC PC Adjustment UE Number Threshold

Meaning: Indicates the UE number threshold for power coordination to take effect. The eNodeB samples the number of activated UEs in the downlink in a cell multiple times and calculates the average number. If the average number is not 0 and greater than or equal to the threshold, power coordination takes effect. If the average number is 0 or less than the threshold, power coordination does not take effect. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~10, step: 0.1

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability for eCSPC-based power coordination to take effect, higher gains in scenarios where the network load is medium or high and load is unbalanced between cells, and sustained performance or slight performance degradation in light-load scenarios. A larger value of this parameter results in lower gains in scenarios where the network load is medium or high and load is unbalanced between cells, and sustained performance in light-load scenarios.

Applicable Mode: L-FDD, L-TDD
CellCspcSwitch Cell CSPC Switch

Meaning: Indicates whether to enable CSPC in the cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship:

-Configuration constraints:

  • If the CelleCspcSwitch in the CellCspcPara MO is ON, CellCspcSwitch in the CellCspcPara MO must be set to OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CspcRapidRptSwitch CSPC UE SRS Config Rapid Report Switch

Meaning: Indicates whether to report the changed sounding reference signal (SRS) configurations of UEs with CSPC applied in the serving cell to the centralized control node immediately after the configurations are changed. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
CspcUeSrsCfgRptPeriod CSPC UE SRS Config Report Period

Meaning: Indicates the interval at which the local cell reports its UE-specific SRS configurations to the centralized control node. This parameter applies only to LTE FDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: It is recommended that this parameter be set to 30 when the CspcRapidRptSwitch is set to ON. Otherwise, you are advised to set this parameter to 1.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a larger value, neighboring cells perform SRS measurements on UEs in the serving cell at a lower frequency, and the system load decreases. However, neighboring cells perform delayed SRS measurements on UEs that newly access the serving cell and more unnecessary SRS measurements on UEs that already exit the serving cell. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
UlRsrpRptPeriod Uplink RSRP Measurement Report Period

Meaning: Indicates the interval at which neighboring cells report their uplink reference signal received power (RSRP) measurement results to the local cell. This parameter applies only to LTE FDD.

GUI Value Range: 1~50

Unit: 100ms

Actual Value Range: 100~5000

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower frequency that a neighboring cell reports the uplink RSRP measurements to the serving cell and a lighter system load, but untimely updates of user information. A smaller value leads to the opposite effects.

Applicable Mode: L-FDD
CspcCqiFilterCoeff CSPC CQI Filter Coefficient

Meaning: Indicates the filtering coefficient for channel quality indicators (CQIs) in CSPC-based power optimization. This filtering makes the reported CQIs more stable. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~1, step: 0.01

MML Default Value: None

Recommended Value: FDD: 0; TDD: 25

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a smaller impact of the previous CQI value but a greater impact of the CQI value reported this time on the filtering result. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
eCspcA3Offset eCSPC A3 Offset

Meaning: Indicates the A3 offset for eCSPC. If the parameter value is increased, the probability of UEs reporting event A3 is reduced. A larger value of this parameter indicates a smaller number of cell edge users, and a smaller value of this parameter indicates a larger number of cell edge users. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value, eCSPC takes effect for a larger number of cell edge users in the downlink and a larger increase in the downlink cell edge data rate. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
CelleCspcSwitch Cell eCSPC Switch

Meaning: Indicates whether to enable cell-level enhanced CSPC (eCSPC). eCSPC is enabled only when this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship:

-Configuration constraints:

  • If the CelleCspcSwitch in the CellCspcPara MO is ON, CellCspcSwitch in the CellCspcPara MO must be set to OFF.
  • If the CelleCspcSwitch in the CellCspcPara MO is ON, eCspcPCAdjRange in the CellCspcPara MO must be configured first.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Setting this parameter to ON increases the downlink cell-edge rate and the number of RRC messages. Setting this parameter to OFF has no impact on network performance.

Applicable Mode: L-FDD, L-TDD
eCspcPCAdjRange eCSPC Power Control Adjustment Range

Meaning: Indicates the cell power adjustment range for eCSPC. This parameter must be set to a PDSCH PA value less than the value of the PaPcOff parameter. At most two values can be selected for the eCspcPCAdjRange parameter. If one value is selected for the eCspcPCAdjRange parameter, only one-level adjustment is applicable. If two values are selected for this parameter, two-level adjustment is supported. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DB_6_P_A(-6 dB), DB_4DOT77_P_A(-4.77 dB), DB_3_P_A(-3 dB), DB_1DOT77_P_A(-1.77 dB), DB0_P_A(0 dB), DB1_P_A(1 dB), DB2_P_A(2 dB), DB3_P_A(3 dB)

Unit: None

Actual Value Range: DB_6_P_A, DB_4DOT77_P_A, DB_3_P_A, DB_1DOT77_P_A, DB0_P_A, DB1_P_A, DB2_P_A, DB3_P_A

MML Default Value: None

Recommended Value: When the PaPcOff parameter is set to DB_4DOT77_P_A, the recommended setting is as follows: DB_6_P_A:ON, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB_3_P_A, the recommended setting is as follows: DB_6_P_A:ON, DB_4DOT77_P_A~1:ON, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB_1DOT77_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:ON, DB_3_P_A~2:ON, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB0_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:ON, DB_1DOT77_P_A~3:ON, DB0_P_A~4:OFF, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB1_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:ON, DB0_P_A~4:ON, DB1_P_A~5:OFF, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB2_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:ON, DB1_P_A~5:ON, DB2_P_A~6:OFF, DB3_P_A~7:OFF.

When the PaPcOff parameter is set to DB3_P_A, the recommended setting is as follows: DB_6_P_A:OFF, DB_4DOT77_P_A~1:OFF, DB_3_P_A~2:OFF, DB_1DOT77_P_A~3:OFF, DB0_P_A~4:OFF, DB1_P_A~5:ON, DB2_P_A~6:ON, DB3_P_A~7:OFF.

Parameter Relationship:

-Configuration constraints:

  • A maximum of two options of eCspcPCAdjRange in the CellCspcPara MO can be selected.
  • If the CelleCspcSwitch in the CellCspcPara MO is ON, eCspcPCAdjRange in the CellCspcPara MO must be configured first.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If two values are selected for this parameter, cell power adjustment is frequent, the gains for hotspot cells are large, but radio signaling increases. If one value is selected for this parameter, cell power adjustment is less frequent, the gains for hotspot cells are reduced, but radio signaling decreases.

Applicable Mode: L-FDD, L-TDD
IntraEnbCspcSw Intra Enodeb Cspc Switch

Meaning: Indicates whether to enable intra-eNodeB CSPC. Intra-eNodeB CSPC is enabled only when this parameter is set to ON(On). This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To modify the CSPC configuration in a cell with the parameters as follows: Local cell ID: 0, Cell CSPC Switch: OFF, run the following command:
MOD CELLCSPCPARA: LocalCellId=0, CellCspcSwitch=OFF;
