List Serving-Cell-Operator-Dedicated Config of Neighboring NR Frequency (LST NRNFREQSCELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list serving-cell-operator-specific dedicated configurations of a neighboring NR frequency.

Note

None.

Parameters

LocalCellId Local Cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

Recommended Value: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

Local Cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within a base station. This parameter applies only to LTE FDD and LTE TDD.

Downlink ARFCN

Indicates the downlink SSB ARFCN of neighboring NR frequency dedicated to the operator of the serving cell. This parameter applies only to LTE FDD and LTE TDD.

Cn Operator ID

Indicates the ID of an operator. This parameter applies only to LTE FDD and LTE TDD.

Cell Reselection Priority Config Indicator

Indicates whether to configure the serving-cell-PLMN-specific cell-reselection priority for the NR frequency. This parameter applies only to LTE FDD and LTE TDD.

Cell Reselection Priority

Indicates the serving-cell-PLMN-specific dedicated cell-reselection priority for the NR frequency. The value 0 indicates the lowest priority. If SPIDs are configured, the SPID-specific dedicated cell-reselection priority is used. If SPIDs are not configured but this parameter is configured, the base station includes the cell-reselection priority specific to the PLMN that a UE supports in the IE idleModeMobilityControlInfo in the RRC connection release message. If operator-specific cell-reselection priority for the NR frequency is not configured, the UE uses the common cell-reselection priority for the NR frequency delivered in the system information. This parameter applies only to LTE FDD and LTE TDD.
