Start Cell Baseband Resource Defragmentation (STR CELLFRAGPREADJUST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to:

(1) Adjust the cells indicated by baseband resource pre-adjustment information to eliminate baseband resource fragments, and then reestablish the target cell, if the target cell is specified. (The target cell establishment previously failed due to baseband resource fragmentation.)

(2) Eliminate baseband resource fragments on the eNodeB if no target cell is specified.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If a target cell is specified, the specified cell must be an 8T8R FDD or Static Shared Beam Mode for which the MultiRruCellFlag parameter is set to BOOLEAN_FALSE and that has failed to be established, or the specified cell must be a cell whose baseband equipment allows hybrid configuration of massive MIMO and common cells and that has failed to be established.

  • The DSP CELLFRAGPREADJUST command must be executed first to display cell baseband resource pre-adjustment information, and the STR CELLFRAGPREADJUST command must be executed within 10 minutes after the query result is displayed.

  • Cell baseband resource defragmentation is only applicable to scenarios where cell setup fails due to baseband resource fragments. If a cell fails to be set up due to other causes, cell pre-adjustment information may be obtained. However, the cell may still fail to be set up after this command is executed.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To  start cell baseband resource defragmentation, no target cell is specified, run the following command:
STR CELLFRAGPREADJUST:;
