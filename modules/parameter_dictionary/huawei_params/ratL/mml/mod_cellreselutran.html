Modify Configuration of Cell Reselection to UTRAN (MOD CELLRESELUTRAN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters about cell reselection to UTRAN.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TReselUtran Cell reselection timer value for UTRAN

Meaning: Indicates the evaluation period for a UE to determine whether to reselect a neighboring UTRAN cell to camp on. During the evaluation period, if the signal quality in a neighboring UTRAN cell is better than that in the serving cell and a UE camps on the serving cell for more than 1s, the UE attempts to reselect the neighboring UTRAN cell to camp on. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: s

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A larger value results in a lower probability that the cell is selected when other conditions remain unchanged. A smaller value leads to the opposite effect.

Applicable Mode: L-FDD, L-TDD
SpeedStateSfCfgInd Speed state scale factor configure indicator

Meaning: Indicates whether to set the speed-dependent scaling parameters related to cell reselection to UTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(Not configure), CFG(Configure)

Unit: None

Actual Value Range: NOT_CFG, CFG

MML Default Value: None

Recommended Value: NOT_CFG(Not configure)

Parameter Relationship: None

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
TReselUtranSfMedium Scaling factor of TReselUtran in medium mobility state

Meaning: Indicates the scaling factor applied to TReselUtran for medium-mobility UEs. The actual duration of cell reselection of medium-mobility UEs to UTRAN is equal to TReselUtran multiplied by TReselUtranSfMedium.

The value T_RESEL_SF_0DOT25 means a scaling factor of 0.25, the value T_RESEL_SF_0DOT5 means a scaling factor of 0.5, and other values also follow this rule in their meanings. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: T_RESEL_SF_0DOT25(0.25), T_RESEL_SF_0DOT5(0.5), T_RESEL_SF_0DOT75(0.75), T_RESEL_SF_1DOT0(1.0)

Unit: None

Actual Value Range: T_RESEL_SF_0DOT25, T_RESEL_SF_0DOT5, T_RESEL_SF_0DOT75, T_RESEL_SF_1DOT0

MML Default Value: None

Recommended Value: T_RESEL_SF_1DOT0(1.0)

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of the SpeedStateSfCfgInd parameter.
  • If SpeedStateSfCfgInd is set to CFG, TReselUtranSfMedium must be set.
  • If SpeedStateSfCfgInd is set to NOT_CFG, TReselUtranSfMedium does not need to be set.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A smaller value of this parameter results in a greater impact of the UE mobility state on the duration of cell reselection to UTRAN, that is, a shorter duration. A larger value leads to a smaller impact.

Applicable Mode: L-FDD, L-TDD
TReselUtranSfHigh Scaling factor of TReselUtran in high mobility state

Meaning: Indicates the scaling factor applied to TReselUtran for high-mobility UEs. The actual duration of cell reselection of high-mobility UEs to UTRAN is equal to TReselUtran multiplied by TReselUtranSfHigh.

The value T_RESEL_SF_0DOT25 means a scaling factor of 0.25, the value T_RESEL_SF_0DOT5 means a scaling factor of 0.5, and other values also follow this rule in their meanings. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: T_RESEL_SF_0DOT25(0.25), T_RESEL_SF_0DOT5(0.5), T_RESEL_SF_0DOT75(0.75), T_RESEL_SF_1DOT0(1.0)

Unit: None

Actual Value Range: T_RESEL_SF_0DOT25, T_RESEL_SF_0DOT5, T_RESEL_SF_0DOT75, T_RESEL_SF_1DOT0

MML Default Value: None

Recommended Value: T_RESEL_SF_0DOT75(0.75)

Parameter Relationship:

-Others:

  • This parameter is optional, depending on the setting of the SpeedStateSfCfgInd parameter.
  • If SpeedStateSfCfgInd is set to CFG, TReselUtranSfHigh must be set.
  • If SpeedStateSfCfgInd is set to NOT_CFG, TReselUtranSfHigh does not need to be set.

Service Interrupted After Modification: No (Modifications on this parameter would affect cell reselection of the UE in idle mode.)

Impact on Radio Network Performance: A smaller value of this parameter results in a greater impact of the UE mobility state on the duration of cell reselection to UTRAN, that is, a shorter duration. A larger value leads to a smaller impact.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the UTRAN cell reselection configuration parameters as follows: Local cell ID: 0, GERAN cell reselection duration: 1, Speed state scale factor configure indicator: NOT_CFG, run the following command:
MOD CELLRESELUTRAN: LocalCellId=0, TReselUtran=1, SpeedStateSfCfgInd=NOT_CFG;
Example 2: To modify the UTRAN cell reselection configuration parameters as follows: Local cell ID: 0, UTRAN cell reselection duration: 5, Speed state scale factor configure indicator: CFG, UTRAN cell reselection ratio factor of the medium-mobility UE: T_RESEL_SF_1DOT0, UTRAN cell reselection ratio factor of the high-mobility UE: T_RESEL_SF_0DOT25, run the following command:
MOD CELLRESELUTRAN: LocalCellId=0, TReselUtran=5, SpeedStateSfCfgInd=CFG, TReselUtranSfMedium=T_RESEL_SF_1DOT0, TReselUtranSfHigh=T_RESEL_SF_0DOT25;
