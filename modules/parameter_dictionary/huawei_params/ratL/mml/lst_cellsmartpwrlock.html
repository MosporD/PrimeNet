List Cell Smart Power Lock Configuration (LST CELLSMARTPWRLOCK)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the smart power lock configuration of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configuration about cell smart power lock, run the following command:
LST CELLSMARTPWRLOCK: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 17:28:26

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Smart Power Lock Mode

Indicates the control mode of smart power lock. The value OFF indicates that the smart power lock feature is disabled. The value AVERAGE_POWER_CONTROL indicates that the average power control function of the smart power lock feature is enabled. This parameter applies only to LTE FDD and LTE TDD.

Power Control Threshold(0.01W)

Indicates the power control threshold for the smart power lock feature. The average transmit power of the cell within the average power measurement period for the smart power lock feature must be lower than this threshold. This parameter applies only to LTE FDD and LTE TDD.

Average Power Measurement Period(s)

Indicates the average power measurement period for the smart power lock feature. This parameter applies only to LTE FDD and LTE TDD.
