List eNodeB CHR Output Mode (LST CHROUTPUTMODE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of a CHR output mode.

Note

None.

Parameters

ID Name Description
ModeNo Mode Number

Meaning: Indicates the number of a specific call history record (CHR) hierarchical classification output mode.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configuration of a CHR output mode, run the following command:
LST CHROUTPUTMODE:;

The result is shown as follows:

Output Description

Field Description

Mode Number

Indicates the number of a specific call history record (CHR) hierarchical classification output mode.

CHR Detail Cause Value

Indicates the call history record (CHR) generating cause value corresponding to a specific CHR hierarchical classification mode.

CHR Hierarchical Output Mode

Indicates the call history record (CHR) hierarchical output mode. If the parameter is set to Level_1_Output, level-1 CHRs, that is, only typical records, are output. If the parameter is set to Level_2_Output, level-2 CHRs, that is, all records, are output. If level-2 CHRs start to be output, the number of output records increases, thereby decreasing the duration when the local logs can be recorded.

CHR Output Sampling Indicator

Indicates whether CHRs are output after being sampled. If this parameter is set to SamplingEnable, specific sampled CHRs are output. If this parameter is set to SamplingUnable, all specific CHRs are output without being sampled. If the value of this parameter is changed from SamplingEnable to SamplingUnable, the number of records increases, thereby decreasing the duration when the local logs can be recorded.
