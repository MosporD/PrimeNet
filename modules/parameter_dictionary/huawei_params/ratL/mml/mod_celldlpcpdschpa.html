Modify PA Configuration for PDSCH Power Control (MOD CELLDLPCPDSCHPA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the PA parameters related to power control for the PDSCH.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If a cell is an air cell, online modifications on the PaPcOff parameter will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PaPcOff PA for even power distribution

Meaning: Indicates the PA to be used when PA adjustment for PDSCH power control is disabled, DL ICIC is disabled, and the even power distribution is used for the PDSCH. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: DB_6_P_A(-6 dB), DB_4DOT77_P_A(-4.77 dB), DB_3_P_A(-3 dB), DB_1DOT77_P_A(-1.77 dB), DB0_P_A(0 dB), DB1_P_A(1 dB), DB2_P_A(2 dB), DB3_P_A(3 dB)

Unit: dB

Actual Value Range: DB_6_P_A, DB_4DOT77_P_A, DB_3_P_A, DB_1DOT77_P_A, DB0_P_A, DB1_P_A, DB2_P_A, DB3_P_A

MML Default Value: None

Recommended Value: Dual-antenna or four-antenna: DB_3_P_A(-3 dB)

Single-antenna: DB0_P_A(0 dB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the RS power is fixed, setting this parameter to a large value increases the transmit power and MCS for all UEs in the cell, which results in power limitation and affects throughput. Setting this parameter to a small value decreases the transmit power and MCS for all UEs in the cell but reduces cell throughput. When you modify the PaPcOff parameter, modify the following parameters accordingly: Pb, PcfichPwr, PbchPwr, SchPwr, DbchPwr, PchPwr, RaRspPwr, PrsPwr, DediDciPwrOffset, PwrOffset, CcuPa, and CeuPa.

Applicable Mode: L-FDD, L-TDD
NomPdschRsEpreOffset Nominal PDSCH-to-RS-EPRE Offset

Meaning: Indicates the power offset of the PDSCH EPRE relative to the reference signal (RS) EPRE. If this parameter is set to -1 to 6, nomPDSCH-RS-EPRE-Offset is set to -1 to 6. The parameter is set to 0 by default. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -1~6

Unit: dB

Actual Value Range: -1~6

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in larger single-codeword or dual-codeword CQI values reported by some UEs and a higher proportion of rank 2. A smaller value of this parameter results in the opposite effects. (If the CQIs are measured without distinguishing between the single codeword and dual codewords, the CQI measurement result may not change because the rank ratio is changed.)

If this parameter is set to a non-zero value, the reported CQI value and rank value are not consistent with the actual channel quality in the downlink. As a result, downlink MCS indexes and BERs are changed, affecting the user-perceived data rate and cell throughput in the downlink.

If the UeSigMcsEnhanceSwitch option of the DlSchSwitch parameter is deselected and this parameter is set to a non-zero value, the service drop rate, access success rate, and handover success rate are not affected. If the UeSigMcsEnhanceSwitch option is selected and this parameter is set to an actual value greater than 0, control-plane KPIs may deteriorate.

Applicable Mode: L-FDD, L-TDD
EpreOffsetAdjustmentThld EPRE Offset Adjustment Threshold

Meaning: Indicates the threshold for triggering the adjustment of the PDSCH power offset relative to the reference signal power. If this parameter is set to a value within the range of 0 to 26, the PDSCH power offset adjustment is triggered when the absolute value of the CQI adjustment is greater than this threshold. If this parameter is set to 255, the power offset adjustment does not take effect. The default value is 255. This parameter applies only to LTE FDD.

GUI Value Range: 0~26,255

Unit: None

Actual Value Range: 0~26,255

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering the adjustment of the PDSCH power offset relative to the reference signal power. However, once the power offset adjustment is triggered, CSI feedback better matches downlink channel quality and throughput gains are more noticeable. A smaller value of this parameter results in a higher probability of triggering the adjustment. However, frequent triggering may cause inappropriate CSI feedback on downlink channel quality, affecting user throughput.

Applicable Mode: L-FDD
TM9RankCorrectThld TM9 Rank Correct Threshold

Meaning: Indicates the threshold for triggering rank correction for 4R TM9 UEs. If this parameter is set to a value within the range of 0 to 28, a codebook subset constraint is activated so that high-rank UEs report a maximum of rank 2 when their MCS indexes are lower than this threshold. If this parameter is set to 255, the constraint does not take effect. The default value is 255. This parameter applies only to LTE FDD.

GUI Value Range: 0~28,255

Unit: None

Actual Value Range: 0~28,255

MML Default Value: None

Recommended Value: 9

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This constraint is used to lower ranks reported by 4R TM9 UEs. A larger value of this parameter results in a higher probability of activating the constraint that UEs can report ranks of no greater than 2. Throughput may decrease. A smaller value results in a lower probability of activating this constraint. However, throughput gains can be ensured for UEs with this constraint activated.

Applicable Mode: L-FDD
CellNpreoAdjThreshold Cell-Level NPREO Adjustment Threshold

Meaning: Indicates the threshold used for starting the cell-level NPREO (the IE nomPDSCH-RS-EPRE-Offset) adjustment algorithm. If this parameter is set to 255, this algorithm does not take effect. If this parameter is not set to 255, the parameter value indicates the predicted gain threshold for searching for the optimal cell-level NPREO. When the algorithm searches for the optimal cell-level NPREO, if the predicted UE throughput gain yielded by changing the NPREO from B to A is greater than the threshold, A is regarded as better than B. This parameter applies only to LTE FDD.

GUI Value Range: 0~50,255

Unit: None

Actual Value Range: 0~0.5,255, step: 0.01

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 255, network performance is not affected.

If this parameter is not set to 255, a smaller value of this parameter results in a higher probability that an optimal NPREO can be found. However, in this case, the probability of incorrect decision of the optimal NPREO also increases, decreasing UE throughput. If this parameter is not set to 255, a larger value of this parameter results in a lower probability of finding an optimal NPREO and a smaller number of cells for which NPREO adjustment takes effect.

Applicable Mode: L-FDD
UeNpreoAdjThreshold UE-Level NPREO Adjustment Threshold

Meaning: Indicates the threshold used for starting the UE-level NPREO (the IE nomPDSCH-RS-EPRE-Offset) adjustment algorithm. If this parameter is set to 127, this algorithm does not take effect. If this parameter is not set to 127, the parameter value indicates the compensation value used in the UE-level NPREO adjustment algorithm. This parameter applies only to LTE FDD.

GUI Value Range: -2~20,127

Unit: None

Actual Value Range: -2~20,127

MML Default Value: None

Recommended Value: The recommended value is 1 when the values of PCI modulo 3 of the local cell and its neighboring cells are different on the network. The recommended value is 10 when the values are identical on the network.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 127, network performance is not affected.

If this parameter is not set to 127, a smaller value of this parameter results in a more radical adjustment of the UE-level NPREO, decreasing UE throughput. If this parameter is not set to 127, a larger value of this parameter results in a less radical adjustment of the UE-level NPREO, decreasing the proportion of high ranks.

Applicable Mode: L-FDD

Example

To modify PA parameters related to PDSCH power control as follows: Local cell identity: 0, PA adjusting switch: OFF, PA for even power distribution: DB_3_P_A, run the following command:
MOD CELLDLPCPDSCHPA: LocalCellId=0, PaPcOff=DB_3_P_A;
