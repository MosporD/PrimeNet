List eNodeB Ciphering Algorithm Priority (LST ENODEBCIPHERCAP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the priorities of the eNodeB ciphering algorithms.

Note

None.

Parameters

None.

Example

List eNodeB Ciphering Algorithm Priority:
LST ENODEBCIPHERCAP:;
The result is shown as follows:
+++    0        2019-12-05 08:55:06
O&M    #806355180
%%LST ENODEBCIPHERCAP:;%%
RETCODE = 0  Operation succeeded.

List eNodeB Ciphering Algorithm Priority
----------------------------------------
Primary cipher algorithm  =  AES Algorithm
 Second cipher algorithm  =  SNOW 3G Algorithm
  Third cipher algorithm  =  ZUC Algorithm
 Fourth cipher algorithm  =  NULL Algorithm
(Number of results = 1)


---    END

Output Description

Field Description

Primary cipher algorithm

Indicates the highest-priority ciphering algorithm for the eNodeB. If this parameter is set to NULL, ciphering is not used. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm.

Second cipher algorithm

Indicates the second-priority ciphering algorithm for the eNodeB. If this parameter is set to NULL, ciphering is not used. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm.

Third cipher algorithm

Indicates the third-priority ciphering algorithm for the eNodeB. If this parameter is set to NULL, ciphering is not used. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm.

Fourth cipher algorithm

Indicates the fourth-priority ciphering algorithm for the eNodeB. If this parameter is set to NULL, ciphering is not used. If this parameter is set to NOT_CFG, the eNodeB skips the algorithm of this priority when selecting the ciphering algorithm.
