List Operator (LST X2AUTOSETUPOPERATOR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list operator information that the target eNodeB supporting X2 self-setup belongs to.

Note

None.

Parameters

None.

Example

To list the operator information about the target eNodeB supporting X2 self-setup, run the following command:
LST X2AUTOSETUPOPERATOR:;
The result is shown as follows:
+++    HUAWEI        2012-07-31 15:19:32
O&M    #12877
%%LST X2AUTOSETUPOPERATOR:;%%
RETCODE = 0  Operation succeeded.

List Operator
-------------
Mobile country code  =  460
Mobile network code  =  01
(Number of results = 1)


---    END

Output Description

Field Description

Mobile country code

Indicates the mobile country code (MCC) of an operator that the target eNodeB supporting X2 self-setup belongs to. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code (MNC) of an operator that the target eNodeB supporting X2 self-setup belongs to. The value of this parameter is a string of two or three characters, each of which must be a digit in the range of 0 to 9. This parameter applies only to LTE FDD and LTE TDD.
