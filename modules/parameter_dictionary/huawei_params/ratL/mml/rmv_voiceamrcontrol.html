Remove Voice RateControl setting (RMV VOICEAMRCONTROL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove voice rate control records.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VoiceAmrCtrlParaGroupId Voice Rate Control Parameter Group ID

Meaning: Indicates the ID of a parameter group for rate control over voice services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the user-defined configuration of VoiceAmrControl with the parameters as follows: Local Cell ID: 0, Voice AMR Control Parameter Group ID: 0, run the following command:
RMV VOICEAMRCONTROL: LocalCellId=0, VoiceAmrCtrlParaGroupId=0;
