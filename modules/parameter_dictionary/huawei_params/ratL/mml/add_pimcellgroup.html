Add PIM Cell Group (ADD PIMCELLGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a PIM cell group.

Note

None.

Parameters

ID Name Description
PIMCellGroupId PIM Cell Group Identity

Meaning: Indicates the ID of a passive intermodulation (PIM) cell group. It uniquely identifies a PIM cell group within an eNodeB. A PIM cell group consists of two cells sharing an antenna system. This parameter applies only to LTE FDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
Cell1Id Cell1 Local Cell ID

Meaning: Indicates the local identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
Cell2Id Cell2 Local Cell ID

Meaning: Indicates the local identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
Cell1SectorEqmId Cell1 Sector Equipment Identity

Meaning: Indicates the sector equipment identity of cell 1 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
Cell2SectorEqmId Cell2 Sector Equipment Identity

Meaning: Indicates the sector equipment identity of cell 2 in the passive intermodulation (PIM) cell group. This parameter applies only to LTE FDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PimMitigationMode PIM Mitigation Mode

Meaning: Indicates the PIM mitigation mode. This parameter applies only to FDD.

GUI Value Range: BASED_ON_PHY_ALGO(BASED_ON_PHY_ALGO), BASED_ON_JOINT_SCH(BASED_ON_JOINT_SCH)

Unit: None

Actual Value Range: BASED_ON_PHY_ALGO, BASED_ON_JOINT_SCH

MML Default Value: BASED_ON_PHY_ALGO(BASED_ON_PHY_ALGO)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To add a passive intermodulation cell group with the parameters as follows: PIMCellGroupId: 0, Cell1Id: 1, Cell2Id: 2, Cell1SectorEqmId: 1, Cell2SectorEqmId: 2, run the following command:
ADD PIMCELLGROUP: PIMCellGroupId=0, Cell1Id=1, Cell2Id=2, Cell1SectorEqmId=1, Cell2SectorEqmId=2;
