Download RRN File (DLD EURRNFILE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to download files from the FTP server to the RRN.

Note

  • When the RRN executes this command, the RRN directly replaces duplicate files in the storing directory.

  • If the DownloadFileType parameter is set to SWSCRL, the name of the file to be downloaded must be SWSCRL.crl.

Parameters

SourceFileName Source File Name

Meaning: Indicates the name of the source file in an FTP server. (The name does not support wildcard characters.) The file name can include the file path. With the file path, the maximum size of the file name depends on the maximum size of a file name that the FTP server supports. The maximum size cannot exceed 230 bytes. (Some FTP servers do not support 230-byte full-path file names. For details, see the corresponding user manual of the FTP server.)

This parameter applies only to LTE FDD and LTE TDD.
