Remove eNodeBUSImeisvCfg (RMV ENODEBUSIMEISVCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove information about a configured IMEISV.

Note

None.

Parameters

ID Name Description
ImeisvTac IMEISV TAC

Meaning: Indicates the type allocation code (TAC) in the IMEISV of UEs. The TAC identifies the UE model. For details about the definition of IMEISV, see section 6.2.2 in 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~99999999

Unit: None

Actual Value Range: 0~99999999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
ImeisvSvn IMEISV SVN

Meaning: Indicates the software version number (SVN) which is an element of the international mobile station equipment identity and software version (IMEISV) and specifies the software version of UEs. For details about the definition of IMEISV, see section 6.2.2 in 3GPP TS 23.003. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~99,255

Unit: None

Actual Value Range: 0~99,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To remove the configurations of IMEISV in an eNodeB, run the following command:
RMV ENODEBUSIMEISVCFG:;
+++    172.16.15.27        2014-12-24 17:46:31
O&M    #806355193
%%RMV ENODEBUSIMEISVCFG: ImeisvTac=1, ImeisvSvn=255;%%
RETCODE = 0  Operation succeeded.
