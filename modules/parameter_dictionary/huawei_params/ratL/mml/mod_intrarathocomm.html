Modify Common Parameters for Intra-RAT Handover (MOD INTRARATHOCOMM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the common parameters for intra-RAT handover.

Note

None.

Parameters

ID Name Description
IntraRatHoMaxRprtCell Max report cell number

Meaning: Indicates the maximum number of cells to be included in the measurement report after an intra-RAT inter-frequency or intra-RAT intra-frequency measurement event for handover purposes or a periodic intra-RAT measurement for ANR purposes is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer candidate target cells for handovers, which lowers the handover success rate but saves the air interface resources. A larger value leads to opposite effect.

Applicable Mode: L-FDD, L-TDD
IntraRatHoRprtAmount Measurement report amount

Meaning: Indicates the number of periodic measurement reports to be sent after an event for the intra- or inter-frequency handover within the E-UTRAN is triggered.

It is used to prevent the impact of measurement report loss and internal processing failure on the handover. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: r1(1), r2(2), r4(4), r8(8), r16(16), r32(32), r64(64), Infinity(Infinity)

Unit: None

Actual Value Range: r1, r2, r4, r8, r16, r32, r64, Infinity

MML Default Value: None

Recommended Value: infinity(Infinity)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the value is increased, the number of reports increases and the handover success rate rises to a certain extent. An excessively large number of reports, however, results in excessive signaling and hence causes a waste of radio interface resources.

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA3TrigQuan A3 measurement trigger quantity

Meaning: Indicates the triggering quantity used to evaluate the triggering condition for intra-frequency handovers. The quantity can be RSRP or RSRQ.

The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal quality fluctuation. The measured RSRQ values vary greatly with the load and better reflect the signal quality of the cell in real time.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RSRP(RSRP), RSRQ(RSRQ)

Unit: None

Actual Value Range: RSRP, RSRQ

MML Default Value: None

Recommended Value: RSRP(RSRP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
IntraFreqHoA3RprtQuan A3 measurement report quantity

Meaning: Indicates the quantity to be included in the measurement report after an event for intra-frequency handover is triggered. The quantity can be RSRP, RSRQ, or both.

The measured RSRP values are stable, varying little with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and better reflect the signal quality of the cell in real time. Even when this parameter is set to BOTH, the eNodeB triggers handovers based on the setting of the IntraFreqHoA3TrigQuan parameter. The value of this parameter is also used as the quantity to be included in inter-frequency event A3 measurement reports. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SAME_AS_TRIG_QUAN(Same as Trig Quan), BOTH

Unit: None

Actual Value Range: SAME_AS_TRIG_QUAN, BOTH

MML Default Value: None

Recommended Value: SAME_AS_TRIG_QUAN(Same as Trig Quan)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to RSRP, the number of handovers is less and cell throughput is not optimal compared with setting this parameter to RSRQ or BOTH. This is because RSRP measurement results are stable but cannot completely represent the signal quality. If this parameter is set to RSRQ, the number of handovers is more but cell throughput is optimized when the network load is high compared with setting this parameter to RSRP. This is because load-related RSRQ fluctuates dramatically. If this parameter is set to BOTH, the number of handovers is much more but cell throughput is further optimized compared with setting this parameter to RSRQ.

Applicable Mode: L-FDD, L-TDD
IntraFreqHoRprtInterval A3 measurement report interval

Meaning: Indicates the interval between periodic measurement reports that are sent after an intra-frequency handover is triggered. The value of this parameter is also used as the interval between A3-related inter-frequency measurement reports.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 120ms(120ms), 240ms(240ms), 480ms(480ms), 640ms(640ms), 1024ms(1024ms), 2048ms(2048ms), 5120ms(5120ms), 10240ms(10240ms), 1min(1min), 6min(6min), 12min(12min), 30min(30min), 60min(60min)

Unit: None

Actual Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

MML Default Value: None

Recommended Value: 240ms(240ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to more measurement reports, a higher handover probability, and consumption of more air interface resources. A larger value of this parameter leads to a longer handover retry delay and a lower handover success rate.

Applicable Mode: L-FDD, L-TDD
InterFreqHoA4RprtQuan Measurement A4 report quantity

Meaning: Indicates the quantity to be included in the measurement reports for inter-frequency handovers. The quantity can be RSRP, RSRQ, or both.

The measured RSRP values are stable, varying little with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and better reflect the signal quality of the cell in real time. This parameter applies to measurements for events A4 and A5. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SAME_AS_TRIG_QUAN(Same as Trig Quan), BOTH

Unit: None

Actual Value Range: SAME_AS_TRIG_QUAN, BOTH

MML Default Value: None

Recommended Value: SAME_AS_TRIG_QUAN(Same as Trig Quan)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to BOTH, both measured RSRP and RSRQ values are reported for event A4/A5. In this situation, a handover is triggered only when both the measured RSRP and RSRQ values meet the corresponding conditions, preventing unnecessary handovers.

If this parameter is set to SAME_AS_TRIG_QUAN, the measurement quantity included in the measurement report for event A4/A5 is the same as the quantity used to trigger event A4/A5.

Applicable Mode: L-FDD, L-TDD
InterFreqHoRprtInterval Interfreq measurement report interval

Meaning: Indicates the interval at which periodic measurement reports are sent after an inter-frequency handover event is triggered.

For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 120ms(120ms), 240ms(240ms), 480ms(480ms), 640ms(640ms), 1024ms(1024ms), 2048ms(2048ms), 5120ms(5120ms), 10240ms(10240ms), 1min(1min), 6min(6min), 12min(12min), 30min(30min), 60min(60min)

Unit: None

Actual Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

MML Default Value: None

Recommended Value: 240ms(240ms)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to more measurement reports, a higher handover probability, and consumption of more air interface resources. A larger value of this parameter leads to a longer handover retry delay and a lower handover success rate.

Applicable Mode: L-FDD, L-TDD
InterFreqHoA1A2TrigQuan InterFreq A1A2 Measurement trigger quantity

Meaning: Indicates the triggering quantity for events A1 and A2 related to A4- or A5-based inter-frequency handovers. RSRP measurements slightly vary with the load, and there is little signal quality fluctuation. By contrast, RSRQ measurements greatly vary with the load and are likely to reflect the signal quality of the cell in real time. If this parameter is set to BOTH, both RSRP- and RSRQ-based measurement configurations are delivered. When either the RSRP-based or RSRQ-based entering condition of event A1 or A2 is met, the UE reports event A1 or A2. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RSRP(RSRP), RSRQ(RSRQ), BOTH(BOTH)

Unit: None

Actual Value Range: RSRP, RSRQ, BOTH

MML Default Value: None

Recommended Value: RSRP(RSRP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to RSRP, the number of handovers is less and cell throughput is not optimal compared with when this parameter is set to RSRQ or BOTH. This is because RSRP measurement results are stable but cannot completely represent the signal quality. If this parameter is set to RSRQ, the number of handovers is more but cell throughput is optimal when the network load is high compared with when this parameter is set to RSRP. This is because load-related RSRQ fluctuates dramatically. If this parameter is set to BOTH, the number of handovers is much more but cell throughput is further optimized compared with when this parameter is set to RSRQ.

Applicable Mode: L-FDD, L-TDD

CovBasedIfHoWaitingTimer Coverage Based Inter Frequency HO Waiting Timer

Meaning: Indicates the timer governing the period of time that the eNodeB waits for more measurement reports to evaluate whether to perform a coverage-based inter-frequency handover after it receives a measurement report. This parameter takes effect only when the CovBasedInterFreqHoMode parameter is set to BASEDONSIGNALSTRENGTH or BASEDONFREQPRIORITY. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5000

Unit: ms

Actual Value Range: 0~5000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 0, the eNodeB immediately processes a measurement report when receiving it and does not wait for more measurement reports. A larger value of this parameter indicates a longer timer for the eNodeB to wait for new measurement reports, resulting longer handover delay and a higher probability of service drops due to handover failures.

Applicable Mode: L-FDD, L-TDD

FreqPriHoCandidateUeSelPer Freq Pri Ho Candidate UE Select Period

Meaning: Indicates the interval at which the eNodeB selects candidate UEs in the cell to perform frequency-priority-based inter-frequency measurement. If this parameter is set to 0, the eNodeB does not periodically select candidate UEs in the cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~500

Unit: s

Actual Value Range: 0~500

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value, the eNodeB is more likely to trigger frequency-priority-based inter-frequency handovers. In this case, the UE throughput decreases when the target LTE frequency band provides poor coverage, and increases when the target LTE frequency band provides good coverage. If this parameter is set to a larger value, the eNodeB is less likely to trigger frequency-priority-based inter-frequency handovers.

Applicable Mode: L-FDD, L-TDD
FreqPriIFHoWaitingTimer Freq-Pri-based Inter-Freq HO Waiting Timer

Meaning: Indicates the time within which the eNodeB waits for measurement reports for frequency-priority-based inter-frequency handovers. The value 0 indicates that the eNodeB handles a measurement report upon receiving it. If this parameter is set to a value greater than 0, the eNodeB waits for other measurement reports after receiving any measurement report for a frequency-priority-based inter-frequency handover. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 100ms

Actual Value Range: 0~30

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The value 0 results in a short handover delay. The larger the value of this parameter, the longer the time of waiting for new measurement reports and the longer the handover delay.

Applicable Mode: L-FDD, L-TDD
IntraRatHoA1A2TrigQuanCe Intra-RAT HO A1 A2 Meas Trigger Quantity for CE

Meaning: Indicates the triggering type of A1/A2 event measurement for coverage-based intra-RAT handovers of UEs in coverage enhancement mode. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: RSRP(RSRP), RSRQ(RSRQ)

Unit: None

Actual Value Range: RSRP, RSRQ

MML Default Value: None

Recommended Value: RSRP(RSRP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to RSRP, the number of handovers is smaller than when this parameter is set to RSRQ, but the cell throughput cannot reach the optimum value. This is because RSRP values, although stable, cannot accurately indicate signal quality. If this parameter is set to RSRQ, the number of handovers is larger than when this parameter is set to RSRP, but the cell throughput can be further increased under heavy network load conditions. This is because RSRQ values fluctuate obviously with network load.

Applicable Mode: L-FDD, L-TDD
FreqPriInHoProtectionTimer Freq-Pri-based Incoming HO Protection Timer

Meaning: Indicates the length of the timer that governs the period in which UEs handed over from other cells to the local cell through unnecessary handovers are not allowed to be handed over to other cells through frequency-priority-based handovers. If this parameter is set to 0, the protection mechanism does not take effect. The unnecessary handovers include intra-eNodeB handovers except coverage-, uplink-quality-, and distance-based handovers, X2-based inter-eNodeB handovers with the cause value "Reduce Load in Serving Cell", "Handover Optimization", or "Resource optimization handover", and S1-based inter-eNodeB handovers with the cause value "Reduce Load in Serving Cell" or "Resource optimization handover". This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: s

Actual Value Range: 0~30

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of frequency-priority-based handovers for UEs, increasing the number of such handovers. A larger value of this parameter results in a smaller number of times frequency-priority-based handovers are triggered for UEs, decreasing the probability of data service transfer to high frequencies.

Applicable Mode: L-FDD, L-TDD
MaxNumHoFwdPdcpPktWithSn Max Num of HO Fwd PDCP Pkt with SN

Meaning: Indicates the maximum number of PDCP packets that can be forwarded with SNs during handovers when the actually effective PdcpSnSize value is less than 18 bits. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~2000

Unit: None

Actual Value Range: 1~2000

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the data rates of UEs may decrease during handovers, resulting in repeated packet delivery. If this parameter is set to a large value, HFN rollover may occur for UEs during handovers when the transmission link is unstable, resulting in user-plane service failures.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the eNodeB-level parameters that are related to intra-RAT handovers as follows: Max report cell number: 6, Measurement report amount: r4, A3 measurement trigger quantity: RSRP, A3 measurement report quantity: SAME_AS_TRIG_QUAN, Intrafreq measurement report interval: 480ms, Measurement A4 report quantity: SAME_AS_TRIG_QUAN, Interfreq measurement report interval: 640ms, A1A2 Measurement trigger quantity: RSRP, run the following command:
MOD INTRARATHOCOMM: IntraRatHoMaxRprtCell=6, IntraRatHoRprtAmount=r4, IntraFreqHoA3TrigQuan=RSRP, IntraFreqHoA3RprtQuan=SAME_AS_TRIG_QUAN, IntraFreqHoRprtInterval=480ms, InterFreqHoA4RprtQuan=SAME_AS_TRIG_QUAN, InterFreqHoRprtInterval=640ms, InterFreqHoA1A2TrigQuan=BOTH;
Example 2: To modify the eNodeB-level parameters that are related to intra-RAT handovers as follows: Max report cell number: 6, Measurement report amount: r8, A3 measurement trigger quantity: RSRQ, A3 measurement report quantity: BOTH, Intrafreq measurement report interval: 480ms, Measurement A4 report quantity: BOTH, Interfreq measurement report interval: 640ms, A1A2 Measurement trigger quantity: BOTH, run the following command:
MOD INTRARATHOCOMM: IntraRatHoMaxRprtCell=6, IntraRatHoRprtAmount=r8, IntraFreqHoA3TrigQuan=RSRQ, IntraFreqHoA3RprtQuan=BOTH, IntraFreqHoRprtInterval=480ms, InterFreqHoA4RprtQuan=BOTH, InterFreqHoRprtInterval=640ms, InterFreqHoA1A2TrigQuan=BOTH;
