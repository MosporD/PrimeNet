Remove TM9 Dedicated Carrier Config (RMV TM9DEDICATEDCARRIER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove the configuration of a TM9-dedicated carrier.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the CrsTransmissionStrategy parameter is set to CENTRAL_RB_ON, removing the MO will cause the cell to reset.

  • Configurations related to dedicated carrier for TM9 do not take effect when the LMPT is used as the main control board.

Parameters

ID Name Description
Tm9CcDlEarfcn TM9 CC Downlink EARFCN

Meaning: Indicates the downlink EARFCN of a TM9-dedicated carrier. This parameter applies only to LTE FDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When there is a low TM9 penetration rate, the setting of TM9-dedicated carriers may result in a decrease in UE throughput due to UE capabilities of CA combinations. However, on these carriers, TM9 delivers performance that is not worse than TM4 performance.

Applicable Mode: L-FDD

Example

To remove the configuration of TM9DEDICATEDCARRIER with the parameters as follows: TM9 CC Downlink EARFCN: 1800, run the following command:
RMV TM9DEDICATEDCARRIER: Tm9CcDlEarfcn=1800;
