List NSA DC Algorithm Parameter (LST NSADCALGOPARAM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query NSA DC algorithm configurations.

Note

None.

Parameters

None.

Example

To query NSA DC algorithm configurations, run the following command: :
LST NSADCALGOPARAM:;
The result is shown as follows:

Output Description

Field Description

DL Data Split SN Offset(ms)

Indicates the SN offset used when the eNodeB distributes PDCP packets to LTE or NR, whichever provides a lower data rate for UEs, during downlink dynamic data split. This parameter applies only to LTE FDD and LTE TDD.

Stop Split Time-to-Trigger(10ms)

Indicates the time-to-trigger for stopping data split in downlink dynamic data split. Data split is stopped when the ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate is continuously higher than the value of the NsaDcAlgoParam.StopSplitRateRatioThld parameter within the time-to-trigger. This parameter applies only to LTE FDD and LTE TDD.

DL Data Split Penalty Period(s)

Indicates the penalty period for downlink dynamic data split. Dynamic data split is not allowed within the penalty period and is started after the penalty period ends. This parameter applies only to LTE FDD and LTE TDD.

Stop Split Rate Ratio Threshold

Indicates the threshold for stopping data split in downlink dynamic data split. This threshold is a ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate. Downlink dynamic data split is stopped when the ratio of the data rate of the RAT with the higher data rate to that of the RAT with the lower data rate exceeds this threshold for a time-to-trigger specified by the NsaDcAlgoParam.StopSplitTimeToTrig parameter. This parameter applies only to LTE FDD and LTE TDD.

X2 Transmission Max Rate(100 Mbps)

Indicates the maximum PDCP packet transmission rate over the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

Abnormal DL Data Split Penalty Period(s)

Indicates the penalty period for exceptions in downlink dynamic data split. Dynamic data split is not allowed within the penalty period and is restarted after the penalty period ends. This parameter applies only to LTE FDD and LTE TDD.

HO NSA Band Combination Selection Policy

Indicates the band combination selection policy for handovers with SCG addition. If this parameter is set to LTE_SCC_NR_SCG_FIRST, the eNodeB preferentially delivers the LTE SCC and NR SCG band combination in a handover command message. The eNodeB selects proper LTE SCC bands based on the NR SCG sent from the gNodeB and delivers the band combination of both the LTE SCCs and NR SCG in the handover command message. If this parameter is set to NR_SCG_FIRST, the eNodeB preferentially delivers the NR SCG band combination in the handover command message. When the LTE SCC bands configured by the eNodeB and the NR SCG band combination sent from the gNodeB do not match the UE capability, the eNodeB preferentially assures the configuration of the NR SCG and delivers the band combination of the NR SCG but not the LTE SCCs in the handover command message. This parameter applies only to LTE FDD and LTE TDD.

NSA DC Algorithm Switch

Indicates whether to enable the base-station-level LTE-NR NSA DC algorithms.

OVERHEATING_RPOTECTION_SW: Indicates whether the eNodeB preferentially releases SCGs for UEs that have reported overheating information and preferentially adds SCGs for these UEs after overheating ends. If this option is selected, the eNodeB preferentially releases and adds SCGs for UEs that have reported overheating information. If this option is deselected, the eNodeB does not preferentially release or add SCGs for these UEs. This option applies only to LTE FDD and LTE TDD.

PCC_ANCHORING_SMART_DEPLOY_SW: Indicates whether to enable smart deployment of NSA DC PCC anchoring. If this option is selected, the eNodeB automatically identifies whether NSA is deployed in the area where the eNodeB is located. If it is identified that NSA is deployed and the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter is selected, then NSA DC PCC anchoring or NSA DC PCC anchoring for UEs in idle mode is enabled. If it is identified that NSA is not deployed, neither NSA DC PCC anchoring nor NSA DC PCC anchoring for UEs in idle mode is enabled. If this option is deselected, the eNodeB determines whether to enable NSA DC PCC anchoring or NSA DC PCC anchoring for UEs in idle mode based on the setting of the NSA_PCC_ANCHORING_SWITCH or IDLE_MODE_NSA_PCC_ANCHORING_SW option of the NsaDcMgmtConfig.NsaDcAlgoSwitch parameter, respectively. This option applies only to LTE FDD and LTE TDD.

GAP_OFS_ASSIGNMENT_OPT_SW: Assume that a UE needs to perform gap-assisted measurements of NR frequencies. If this option is selected, the probability of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX decreases. However, the DRX On Duration may be extended. If this option is deselected, the UE may not be able to perform measurements of NR frequencies because of conflicts between the gap assignment and the configurations of PUCCH and SRS resources and DRX. This option applies only to LTE FDD and LTE TDD.

PLMN_BASED_LTE_NR_X2_SEL_SW: Indicates whether the eNodeB selects an LTE-NR X2 interface for an NSA UE based on the PLMN information on both the LTE and NR sides in RAN sharing with dedicated carrier scenarios. If this option is selected, the eNodeB selects an LTE-NR X2 interface for an NSA UE based on the PLMN information on both the LTE and NR sides. If no X2 interface is matched, an LTE-NR X2 self-setup procedure is triggered. If this option is deselected, the eNodeB selects an LTE-NR X2 interface for an NSA UE based on only the PLMN information on the NR side. This option applies only to LTE FDD and LTE TDD.

SRS_CARR_SWITCH_CAPB_QUERY_SW: Indicates whether to enable SRS carrier switching capability query. If this option is selected, the IE "srs-SwitchingTimeRequest" is contained in the UECapabilityEnquiry message to query whether the UE supports this capability. If this option is deselected, the IE is not contained in the message and the eNodeB does not query whether the UE supports the capability. This option applies only to LTE FDD and LTE TDD.

BAND_COMB_SORT_STRATEGY_SW: Indicates the sorting policy of NSA frequency band combinations. If this option is selected, there are the following situations: If the "downlinkSetEUTRA" field corresponding to a frequency band is set to 0, this frequency band is regarded as NSA-capable during sorting and two-layer MIMO is adopted by default. If the "downlinkSetEUTRA" field corresponding to the frequency band is not set to 0 but the number of the "FeatureSetDownlinkPerCC-Id" fields is inconsistent with the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band, this frequency band is regarded as NSA-capable during sorting and the number of consecutive CCs supported by this frequency band is equal to the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band. If this option is deselected, there are the following situations: If the "downlinkSetEUTRA" field corresponding to a frequency band is set to 0, this frequency band is not regarded as NSA-capable during sorting. If the "downlinkSetEUTRA" field corresponding to the frequency band is not set to 0 but the number of the "FeatureSetDownlinkPerCC-Id" fields is inconsistent with the number of consecutive CCs indicated by the "ca-BandwidthClassDL" field corresponding to the frequency band, this frequency band is regarded as NSA-capable during sorting and the number of consecutive CCs supported by this frequency band is equal to the number of the "FeatureSetDownlinkPerCC-Id" fields. For details about the IEs, see 3GPP TS 38.331. This option applies only to LTE FDD and LTE TDD.

LAA_MEAS_GAP_PRI_SW: Indicates whether to prioritize the LAA frequencies and NR frequencies to be measured for NSA UEs. If this option is selected, NR frequencies are preferentially selected for gap-assisted measurements, decreasing the priorities for LAA frequencies. If this option is deselected, LAA frequencies are preferentially selected for gap-assisted measurements, increasing the priorities for LAA frequencies. This option applies only to LTE FDD and LTE TDD.

NSA_MEAS_RPT_CHECK_CANCEL_SW: Indicates whether the eNodeB cancels the check on received NSA-related B1 measurement reports. If this option is selected, the eNodeB does not check B1 measurement reports. If this option is deselected, the eNodeB checks B1 measurement reports. If the measured value indicated in a measurement report is less than the B1 measurement threshold configured on the eNodeB, the eNodeB discards the measurement report.

SCC_RMV_AFT_SCG_ADD_OPT_SW: Indicates whether to optimize SCell removal during CA band combination rollback after an SCG is added for an NSA UE. If this option is selected and the configured CA band combination is not supported after an SCG is added for an NSA UE, the base station removes SCells based on the optimal CA band combination in the supported EN-DC band combination. If this option is deselected, the optimization does not take effect. This option applies only to LTE FDD and LTE TDD.

MFBI_COMPATIBILITY_HO_SW: Indicates whether the eNodeB applies a compatibility handover solution to UEs that access an MFBI cell. Assume that a UE accesses a band in an MFBI cell but the band does not support the NSA band combination. If this option is selected, the eNodeB initiates an intra-cell handover to transfer the UE to another band that supports the NSA band combination and adds an NR SCG for the UE after the NR SCG addition conditions are met. If this option is deselected, the eNodeB does not add an NR SCG for the UE. This option applies only to LTE FDD and LTE TDD.
