Block Bbp Collaboration Group (BLK BBPCOLLABORATIONGRP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to block a specified BBP collaboration group.

Note

None.

Parameters

ID Name Description
BbCoGroupId BBP Collaboration Group ID

Meaning: Indicates the BBP collaboration group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BlockState Collaboration Group Block Indication

Meaning: Indicates the blocking method of a baseband processing unit (BBP) collaboration group. If this parameter is set to HIGH_PRIORITY_BLOCK(HIGH_PRIORITY_BLOCK), the UEs transferred from inventory BBPs to collaborating BBPs for assistance are immediately released. If this parameter is set to LOW_PRIORITY_BLOCK(LOW_PRIORITY_BLOCK), a BBP collaboration group is blocked when there are no UEs transferred from inventory BBPs to collaborating BBPs for assistance. If this parameter is set to UNBLOCK(Unblock), a BBP collaboration group is unblocked. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: HIGH_PRIORITY_BLOCK(HIGH_PRIORITY_BLOCK), LOW_PRIORITY_BLOCK(LOW_PRIORITY_BLOCK)

Unit: None

Actual Value Range: HIGH_PRIORITY_BLOCK, LOW_PRIORITY_BLOCK

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Block Bbp Collaboration Group:

+++    0        2016-04-21 18:50:17
O&M    #806355041
%%BLK BBPCOLLABORATIONGRP: BbCoGroupId=2, BlockState=LOW_PRIORITY_BLOCK;%%
RETCODE = 0  Operation succeeded.
