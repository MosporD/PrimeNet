Add Neighboring gNodeB Policy (ADD NBRGNODEBPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a neighboring gNodeB policy.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of an external NR cell. A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in each NbrGnodebPolicy MO consists of digits only.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile Network Code

Meaning: Indicates the MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mnc in each NbrGnodebPolicy MO consists of digits only.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
GnodebId gNodeB ID

Meaning: Indicates the gNodeB ID of an external NR cell. It uniquely identifies a gNodeB within a PLMN. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LteToNrPlmnSelectionMode LTE to NR PLMN Selection Mode

Meaning: Indicates the PLMN filling mode in LTE-to-NR procedures, including LTE-to-NR handovers and EN-DC X2 self-setup in NSA networking.

If this parameter is set to NOT_CFG, the PLMN filling mode is dependent on the EnodebAlgoExtSwitch.LteToNrPlmnSelectionMode parameter value. If this parameter is set to PRIMARY_PLMN_ID, the primary PLMN of the cell served by the gNodeB is filled in. If this parameter is set to SELECTED_PLMN_ID, the PLMN selected by the UE in the cell served by the gNodeB is filled in. If this parameter is set to HYBRID_PLMN_ID, the PLMN to be filled in depends on the cell identities corresponding to different PLMNs for the same NR cell served by the gNodeB. If different PLMNs correspond to different cell identifies, the PLMN selected by the UE is filled in. If different PLMNs correspond to the same cell identify, the primary PLMN of the cell served by the gNodeB is filled in. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: NOT_CFG(NOT_CFG), PRIMARY_PLMN_ID(PRIMARY_PLMN_ID), SELECTED_PLMN_ID(SELECTED_PLMN_ID), HYBRID_PLMN_ID(HYBRID_PLMN_ID)

Unit: None

Actual Value Range: NOT_CFG, PRIMARY_PLMN_ID, SELECTED_PLMN_ID, HYBRID_PLMN_ID

MML Default Value: NOT_CFG(NOT_CFG)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a neighboring gNodeB policy with the parameters as follows: Mobile Country Code: 111, Mobile Network Code: 111, gNodeB ID: 0, LTE to NR PLMN Selection Mode is not configure. 
ADD NBRGNODEBPOLICY: Mcc="111", Mnc="111", GnodebId=0, LteToNrPlmnSelectionMode=NOT_CFG;
