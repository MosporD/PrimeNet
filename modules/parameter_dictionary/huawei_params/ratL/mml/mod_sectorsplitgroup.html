Modify Sector Split Group (MOD SECTORSPLITGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters for a sector splitting group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The change of the MM_INTELLIGENT_BEAM_SHAPING_SW option setting will cause all cells in the sector splitting group to reset.

  • The change of the PATTERN_ADJ_SWITCH option setting requires the SRS subframes and SRS period to be set. In addition, the change will cause the cell to restart.

  • Modification of BeamTemplateId parameter will cause all cells in the sector splitting group to reset.

    Modification of BeamDeploymentMode parameter will cause all cells in the sector splitting group to reset.

    Modification of TM4WeightScheme parameter will cause all cells in the sector splitting group to reset.

    Modification of MassiveMimoBeamScheme parameter will cause all cells in the sector splitting group to reset.

  • The change of the POWER_ALLOCATION_SWITCH option setting will cause all cells in the sector splitting group to reset.

BeamDeploymentMode Beam Deployment Mode

Meaning: Indicates the beam deployment mode for a multi-antenna cell. MODE_0 indicates that the number of outer-cell beams is the same as or one more than that of inner-cell beams. MODE_1 indicates that the number of outer-cell beams is two or three more than that of inner-cell beams. MODE_2 indicates that the number of outer-cell beams is four or five more than that of inner-cell beams. MODE_3 indicates smart 8T8R. NOT_CFG indicates that beams are not deployed. The difference between the numbers of outer-cell and inner-cell beams depends on the AAU type and the total number of selected beams. For details, see the related feature parameter description. The beam deployment mode can be set based on the distribution of UEs on the network to achieve even UE distribution in each beam. This helps increase the capacity and UE-perceived rates. This parameter applies to LTE FDD and LTE TDD.

GUI Value Range: MODE_0(MODE_0), MODE_1(MODE_1), MODE_2(MODE_2), MODE_3(MODE_3), NOT_CFG(NOT_CFG)

Unit: None

Actual Value Range: MODE_0, MODE_1, MODE_2, MODE_3, NOT_CFG

MML Default Value: None

Recommended Value: For TDD cells, the recommended value is NOT_CFG. For FDD cells, set this parameter based on site requirements.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorSplitSwitch Sector Split Switch

Meaning: Indicates whether to enable functions related to sector split in massive MIMO scenarios.

MM_INTELLIGENT_BEAM_SHAPING_SW: Indicates whether to enable intelligent beam shaping in massive MIMO scenarios. Intelligent beam shaping in massive MIMO scenarios is enabled only if this option is selected. The PATTERN_ADJ_SWITCH and POWER_ADJ_SWITCH options are valid only when the MM_INTELLIGENT_BEAM_SHAPING_SW option is selected. This option applies only to LTE FDD and LTE TDD.

PATTERN_ADJ_SWITCH: Indicates whether to adjust the pattern for intelligent beam shaping in massive MIMO scenarios. If UMPTe or UMPTga is used, the AI_ENHANCEMENT_SWITCH option of the eNodeBResModeAlgo.ServiceMode parameter must also be selected for the pattern adjustment function to take effect. If this option is selected, the CellBeamAzimuth and CellBeamwidth parameters do not take effect, and the beam azimuth and beamwidth are adaptively adjusted based on UE distribution. If this option is deselected, the beam azimuth and horizontal 3 dB beamwidth are determined by the CellBeamAzimuth and CellBeamwidth parameters, respectively. This option applies only to LTE FDD.

POWER_ADJ_SWITCH: Indicates whether to enable power adjustment for intelligent beam shaping in massive MIMO scenarios. This option takes effect only when the TM4WeightScheme parameter is set to DEFAULT_MODE. If this option is selected, the traffic channel power is adjusted based on the principle of power usage maximization. If this option is deselected, the traffic channel power is not adjusted based on the principle of power usage maximization. This option applies only to LTE FDD.

PATTERN_ADJ_ENH_SWITCH: Indicates whether to enable enhanced pattern adjustment. If this option is selected, the pattern adjustment enhancement function is enabled. If this option is deselected, the pattern adjustment enhancement function is disabled. The PATTERN_ADJ_ENH_SWITCH option is valid only when both the MM_INTELLIGENT_BEAM_SHAPING_SW and PATTERN_ADJ_SWITCH options of this parameter are selected. This option applies only to LTE FDD.

POWER_ALLOCATION_SWITCH: Indicates whether to enable power allocation. If this option is selected, the PDSCHCfg.ReferenceSignalPwr parameter becomes invalid. Instead, the reference signal power is determined based on the cell power, which is specified by the SectorSplitCell.CellBeamPower parameter. The reference signal power can be queried by running the DSP MASSIVEMIMOPOWER command. If this option is deselected, power allocation is disabled. The POWER_ALLOCATION_SWITCH option takes effect only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of the SectorSplitSwitch parameter is selected. This option applies only to LTE FDD.

GUI Value Range: MM_INTELLIGENT_BEAM_SHAPING_SW(MM_INTELLIGENT_BEAM_SHAPING_SW), PATTERN_ADJ_SWITCH(PatternAdjSwitch), POWER_ADJ_SWITCH(POWER_ADJ_SWITCH), PATTERN_ADJ_ENH_SWITCH(PATTERN_ADJ_ENH_SWITCH), POWER_ALLOCATION_SWITCH(POWER_ALLOCATION_SWITCH)

Unit: None

Actual Value Range: MM_INTELLIGENT_BEAM_SHAPING_SW, PATTERN_ADJ_SWITCH, POWER_ADJ_SWITCH, PATTERN_ADJ_ENH_SWITCH, POWER_ALLOCATION_SWITCH

MML Default Value: None

Recommended Value: MM_INTELLIGENT_BEAM_SHAPING_SW:Off, PATTERN_ADJ_SWITCH:Off, POWER_ADJ_SWITCH:Off, PATTERN_ADJ_ENH_SWITCH:Off, POWER_ALLOCATION_SWITCH:Off

Parameter Relationship:

-Configuration constraints:

  • The PATTERN_ADJ_SWITCH option of the SectorSplitSwitch parameter can be selected in a maximum of six SectorSplitGroup MOs configured on an eNodeB, and the MM_INTELLIGENT_BEAM_SHAPING_SW option of the same parameter can be selected in a maximum of 12 SectorSplitGroup MOs configured on an eNodeB.
  • The PATTERN_ADJ_SWITCH and POWER_ADJ_SWITCH options of the SectorSplitSwitch parameter in the SectorSplitGroup MO can be selected only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of this parameter is selected.
  • The POWER_ALLOCATION_SWITCH options of the SectorSplitSwitch parameter in the SectorSplitGroup MO can be selected only when the MM_INTELLIGENT_BEAM_SHAPING_SW option of this parameter is selected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: MM_INTELLIGENT_BEAM_SHAPING_SW: If this option is selected, the main lobe direction of the antenna for the split cell adaptively changes with UE distribution, increasing user-perceived data rates of UEs in the massive MIMO cell. If this option is deselected, the main lobe direction of the antenna for the split cell is fixed, preventing data rates of UEs in the massive MIMO cell from reaching the optimal level.

POWER_ADJ_SWITCH: If this option is selected, the downlink transmit power of the split cell is adjusted based on the principle of power usage maximization, increasing the user-perceived rates of UEs in the massive MIMO cell. If this option is deselected, the downlink transmit power of the split cell is not adjusted based on the principle of power usage maximization, preventing the rates of UEs in the massive MIMO cell from reaching the optimal level.

PATTERN_ADJ_SWITCH: If this option is selected, the main lobe direction of the antenna for the split cell is adaptively adjusted based on with UE distribution, increasing user-perceived data rates of UEs in the massive MIMO cell. If this option is deselected, the main lobe direction of the antenna for the split cell is fixed, preventing data rates of UEs in the massive MIMO cell from reaching the optimal level.

PATTERN_ADJ_ENHANCE_SWITCH: If this option is selected, the UE-distribution-based adjustment of the main lobe direction of the antenna for the split cell is enhanced, increasing user-perceived data rates of UEs in the massive MIMO cell. If this option is deselected, the adjustment is not enhanced, preventing data rates of UEs in the massive MIMO cell from reaching the optimal level.

POWER_ALLOCATION_SWITCH: If this option is selected, the beam power of a split cell is specified by the SectorSplitCell.CellBeamPower parameter. Lower beam power results in smaller cell coverage or lower user-perceived rates. Higher cell beam power results in larger cell coverage or higher user-perceived rates. If this option is deselected, the cell beam power is not determined by the SectorSplitCell.CellBeamPower parameter and the network performance is not affected.

Applicable Mode: L-FDD, L-TDD
MmBeamAzimuthAdjStep Massive MIMO Beam Azimuth Adjustment Step

Meaning: Indicates the beam azimuth adjustment step used for smart beam adjustment in massive MIMO scenarios.

If this parameter is set to 0, only the beam width can be adjusted in smart beam adjustment in massive MIMO scenarios, and the beam azimuth cannot be adjusted. If this parameter is set to 60, the beam azimuth is adjusted based on the clustering result instead of being restricted by the adjustment step.

This parameter applies only to LTE FDD.

GUI Value Range: 0~60

Unit: degree

Actual Value Range: 0~60

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller adjustment step for smart beam adjustment in massive MIMO scenarios. A larger value of this parameter leads to a larger adjustment step for smart beam adjustment in massive MIMO scenarios.

Applicable Mode: L-FDD
TM4WeightScheme TM4 Weight Scheme

Meaning: Indicates the scheme for setting the weight of TM4 in massive MIMO. The eNodeB sets the weight of TM4 based on the AAU type and coverage requirements. The value DEFAULT_MODE is applicable to common scenarios. When this parameter is set to DEFAULT_MODE, the CellBeamTilt parameter is valid. The value COVERAGE_MODE_1 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_1, the CellBeamTilt parameter is invalid if the CrsPortNum parameter is set to CRS_PORT_4 or is valid if CrsPortNum parameter is set to CRS_PORT_2. The value COVERAGE_MODE_2 is applicable to coverage enhancement scenarios. When this parameter is set to COVERAGE_MODE_2, the CellBeamTilt parameter is valid. This parameter applies only to LTE FDD.

GUI Value Range: DEFAULT_MODE(DEFAULT_MODE), COVERAGE_MODE_1(COVERAGE_MODE_1), COVERAGE_MODE_2(COVERAGE_MODE_2)

Unit: None

Actual Value Range: DEFAULT_MODE, COVERAGE_MODE_1, COVERAGE_MODE_2

MML Default Value: None

Recommended Value: DEFAULT_MODE

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to DEFAULT_MODE, there is no impact on network performance. If this parameter is set to COVERAGE_MODE_1 or COVERAGE_MODE_2, the RS coverage of cells in the sector splitting group improves.

Applicable Mode: L-FDD
IntelligentBeamSchSwitch Intelligent Beam Scheduling Switch

Meaning: Indicates whether to enable algorithms related to intelligent beam scheduling.

JOINT_SCHEDULING_SWITCH: Indicates whether to enable joint scheduling for intelligent beam scheduling in massive MIMO scenarios. Joint scheduling is enabled for intelligent beam scheduling in massive MIMO scenarios only if this option is selected. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.

ENH_JOINT_SCHEDULING_SWITCH: Indicates whether to enable enhanced joint scheduling for intelligent beam scheduling in massive MIMO scenarios. When this option is selected, the enhanced joint scheduling is enabled. This option takes effect only for split cells in the same sector split group. This option applies only to LTE FDD.

GUI Value Range: JOINT_SCHEDULING_SWITCH(JOINT_SCHEDULING_SWITCH), ENH_JOINT_SCHEDULING_SWITCH(ENH_JOINT_SCHEDULING_SWITCH)

Unit: None

Actual Value Range: JOINT_SCHEDULING_SWITCH, ENH_JOINT_SCHEDULING_SWITCH

MML Default Value: None

Recommended Value: JOINT_SCHEDULING_SWITCH:Off, ENH_JOINT_SCHEDULING_SWITCH:Off

Parameter Relationship:

-Configuration constraints:

  • If the ENH_JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in a SectorSplitGroup MO is selected, the JOINT_SCHEDULING_SWITCH option of the IntelligentBeamSchSwitch parameter in the SectorSplitGroup MO must be selected.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: JOINT_SCHEDULING_SWITCH: If this option is selected, user-perceived downlink data rates increase. If this option is deselected, radio network performance is not affected.

ENH_JOINT_SCHEDULING_SWITCH: If this option is selected and joint scheduling is enabled for intelligent beam scheduling in massive MIMO scenarios, the power usage and user-perceived downlink data rate increase. If this option is deselected, there is no impact on radio network performance.

Applicable Mode: L-FDD
MassiveMimoEmfPowerLimit Massive MIMO EMF Power Limit

Meaning: Indicates the maximum transmit power that can be used by UEs in massive MIMO cells. This parameter is used to prevent UE transmit power from exceeding the EMF limit. If this parameter is set to 0, the maximum transmit power of UEs in massive MIMO cells is not restricted. If this parameter is set to a non-zero value, the maximum transmit power of UEs in massive MIMO cells cannot exceed the power value specified by this parameter. This parameter applies only to LTE FDD.

GUI Value Range: 0~65500

Unit: 0.01W

Actual Value Range: 0~655

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability that the transmit power of TM9 UEs in massive MIMO cells will be restricted and less degradation in the performance of these UEs. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD

Meaning: Indicates the offset relative to the maximum PA for the shared power received by TM9 UEs when intelligent beam scheduling is enabled. The actual maximum PA for the shared power received by TM9 UEs is the result of 90 minus the configured value. This parameter applies only to LTE FDD.

GUI Value Range: 0~90

Unit: 0.1dB

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in higher downlink UE throughput gains but stronger interference for neighboring cell RSRP measurements by UEs, which may increase the number of handovers. A larger value of this parameter results in lower downlink UE throughput gains and weaker interference for neighboring cell RSRP measurements by UEs, which has a small impact on the number of handovers.

Applicable Mode: L-FDD
BeamOptPrbUsageThld Beam Optimization PRB Usage Threshold

Meaning: Indicates the PRB usage threshold for triggering TM9 beam optimization. When the average PRB usage of the split sector group is higher than the threshold, TM9 beam optimization is enabled to reduce interference from TM9 beams to UEs using other beams and increase the average downlink UE throughput. This parameter applies only to LTE FDD.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 45

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that TM9 beam optimization takes effect but a larger throughput gain after TM9 beam optimization takes effect. A smaller value of this parameter results in a higher probability that TM9 beam optimization takes effect; however, the throughput may slightly decrease when the load is light.

Applicable Mode: L-FDD
PwrSharingHighLoadThld Power Sharing High Load Threshold

Meaning: Indicates the load threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the PRB usage of a high-load cell exceeds this threshold, the condition for the sharing to take effect is met. If this parameter is set to 100, this power sharing algorithm does not take effect. This parameter applies only to LTE FDD.

GUI Value Range: 50~100

Unit: %

Actual Value Range: 50~100

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of power increase in high-load cells, a higher gain in the downlink user-perceived rate in these cells, but a larger negative impact for low-load cells. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
PwrSharingLoadMultipleThld Power Sharing Load Multiple Threshold

Meaning: Indicates the load ratio threshold for power sharing to take effect for high-load cells in sector split scenarios where LTE extreme power sharing is enabled. When the ratio of the load of a high-load cell to that of a low-load cell exceeds this threshold, the condition for the sharing to take effect is met. This parameter applies only to LTE FDD.

GUI Value Range: 20~100

Unit: None

Actual Value Range: 2~10, step: 0.1

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of power increase in high-load cells, a higher gain in the downlink user-perceived rate in these cells, but a larger negative impact for low-load cells. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD
