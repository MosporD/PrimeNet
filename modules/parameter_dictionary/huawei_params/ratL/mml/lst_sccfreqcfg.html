List SCC Frequency Configuration (LST SCCFREQCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the secondary component carrier (SCC) configurations.

Note

None.

Parameters

ID Name Description
PccDlEarfcn PCC Downlink EARFCN

Meaning: Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the PCC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PccDlEarfcn in an SccFreqCfg MO must be a valid frequency.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SccDlEarfcn SCC Downlink EARFCN

Meaning: Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of a frequency to be acting as an SCC. This parameter applies only to LTE FDD and LTE TDD. Always set this parameter to 46790 for an LAA SCell. Since the LTE-U function has been removed, the values 255144 and 260894 are invalid. Although the configuration interface in this version supports synchronization and delivery of the two values, the system no longer uses these values. Therefore, avoid using the parameter values 255144 and 260894.

Service Interrupted After Modification: N/A

Applicable Mode: L-FDD, L-TDD

Output Description

Field Description

PCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the PCC. This parameter applies only to LTE FDD and LTE TDD.

SCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of a frequency to be acting as an SCC. This parameter applies only to LTE FDD and LTE TDD. Always set this parameter to 46790 for an LAA SCell. Since the LTE-U function has been removed, the values 255144 and 260894 are invalid. Although the configuration interface in this version supports synchronization and delivery of the two values, the system no longer uses these values. Therefore, avoid using the parameter values 255144 and 260894.

SCC Priority

Indicates the priority with which the candidate SCC works as an SCC for that PCC. A smaller value of this parameter indicates a lower priority, and a larger value indicates a higher priority. This parameter applies only to LTE FDD and LTE TDD.

SCC A2 Offset(dB)

Indicates the offset of the actual threshold for CA event A2 relative to the value of the CarrAggrA2ThdRsrp parameter in the CaMgtCfg MO. If the actual threshold is greater than -43 dBm, the value of -43 dBm takes effect. If the actual threshold is less than -140 dBm, the value of -140 dBm takes effect. This parameter applies only to LTE FDD and LTE TDD.

SCC A4 Offset(dB)

Indicates the offset of the actual threshold for CA event A4 relative to the value of the CarrAggrA4ThdRsrp parameter in the CaMgtCfg MO. If the actual threshold is greater than -43 dBm, the value of -43 dBm takes effect. If the actual threshold is less than -140 dBm, the value of -140 dBm takes effect. This parameter applies only to LTE FDD and LTE TDD.

SCell Blind Configuration Flag Addition Threshold(%)

Indicates the threshold for adding the setting of the flag used to identify whether a cell can be configured as an SCell in a blind manner. ANGC for CA compares the measured coverage overlap proportion of an inter-frequency neighboring cell and the serving cell with this parameter value. If the coverage overlap proportion is greater than or equal to this parameter value, the inter-frequency neighboring cell can be configured as an SCell in a blind manner for CA UEs in the serving cell and the flag setting is added or modified for the inter-frequency neighboring cell.

A smaller value of this parameter indicates a looser coverage overlap requirement for adding the flag setting. A larger value of this parameter results in the opposite effect. This parameter applies only to LTE FDD and LTE TDD.

SCell Blind Configuration Flag Deletion Threshold(%)

Indicates the threshold for removing the setting of the flag used to identify whether a cell can be configured as an SCell in a blind manner. ANGC for CA compares the measured coverage overlap proportion of an inter-frequency neighboring cell and the serving cell with this parameter value. If this flag setting has been added for the inter-frequency neighboring cell and the coverage overlap proportion is less than this parameter value, the flag setting can be removed.

A smaller value of this parameter results in a lower probability of removing the flag setting. A larger value results in a higher probability. This parameter applies only to LTE FDD and LTE TDD.

SCell Blind Configuration Flag Control Mode

Indicates the control policy for the flag used to identify whether a cell can be configured as an SCell in a blind manner.

If this parameter is set to AUTO, ANGC for CA can add, modify, or remove the flag settings for cells on this frequency.

If this parameter is set to MANUAL, the flag settings for cells on this frequency can only be manually added, modified, or removed. This parameter applies only to LTE FDD and LTE TDD.

SPID Group ID

Indicates the SPID group ID, which identifies a group of UEs whose SPIDs belong to the same group. If this parameter is set to a value ranging from 0 to 255, the eNodeB cannot configure candidate SCCs of UEs that belong to the SPID group specified by this parameter as SCCs for CA. If this parameter is set to 65535, candidate SCCs of such UEs can be configured as SCCs for CA. This parameter applies only to LTE FDD and LTE TDD.

SCC A2/A4 RSRP Threshold Extended Offset(dB)

Indicates the extended offset to the RSRP threshold for SCell-related event A2 or A4.

If this parameter is set to a non-0 value, the extended threshold for SCell-related event A2 or A4 is equal to the normal threshold for the event plus this offset. The normal threshold for event A2 is equal to the sum of the CarrAggrA2ThdRsrp parameter in the CaMgtCfg MO and the SccA2Offset parameter in the SccFreqCfg MO. The normal threshold for event A4 is equal to the sum of the CarrAggrA4ThdRsrp parameter in the CaMgtCfg MO and the SccA4Offset parameter in the SccFreqCfg MO. If the RSRP of an SCell is between the extended and normal thresholds for event A2, the eNodeB does not remove this SCell, which is considered to be in extended coverage state. For CA UEs at initial access, an incoming handover, or an RRC connection reestablishment, if the RSRP of a cell is greater than the extended threshold for event A4, the eNodeB can configure this cell, which is considered to be in extended coverage state, as an SCell. If the sum of this parameter, the CarrAggrA2ThdRsrp/CarrAggrA4ThdRsrp parameter in the CaMgtCfg MO, and the SccA2Offset/SccA4Offset parameter in the SccFreqCfg MO exceeds -43 dBm, -43 dBm is used as the normal threshold for event A2 or A4. If the sum is less than -140 dBm, -140 dBm is used as the normal threshold for event A2 or A4. The value 0 indicates that this parameter does not take effect. This parameter applies only to LTE FDD and LTE TDD.

CN Operator List

Indicates the operators corresponding to an SCC. The characters from the left to the right in the parameter value correspond to the operator indexes of the local eNodeB. The character can be assigned with a value either 0 or 1. If the character is assigned with a value 1, the SCC can be used by the corresponding operator. If the character is assigned with a value 0, the SCC cannot be used by the corresponding operator. The eNodeB filters the SCCs based on the operators which a CA UE accesses. If the corresponding operator index is invalid, the eNodeB ignores it. For example: 100100 indicates that the SCC belongs to the operators whose operator indexes are 0 and 3. This parameter does not take effect on the LMPT, and if the LMPT is used, the SCC can be used by all operators. This parameter applies only to LTE FDD and LTE TDD.
