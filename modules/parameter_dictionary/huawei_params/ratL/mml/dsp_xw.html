Display XW Information (DSP XW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information of an Xw object.

Note

None.

Parameters

ID Name Description
XwId Xw ID

Meaning: Indicates the ID of the Xw object. This parameter applies only to LTE FDD.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD

Example

To query information about an Xw object, run the following command: 
DSP XW:;
The result is shown as follows: 
+++    0        2016-06-16 19:41:27
O&M    #806354964
%%DSP XW:;%%
RETCODE = 0  Operation succeeded.

Display XW interface information
--------------------------------
                       Xw ID  =  1
             Xw Interface ID  =  0
          Xw Interface State  =  Abnormal
   Xw Interface CP Bearer ID  =  70000
Xw Interface CP Bearer State  =  Abnormal
(Number of results = 1)


---    END

Output Description

Field Description

Xw ID

Indicates the ID of the Xw object. This parameter applies only to LTE FDD.

Xw Interface ID

Indicates the Xw interface ID. This parameter applies only to LTE FDD.

Xw Interface State

Indicates the Xw interface status. This parameter applies only to LTE FDD.

Xw Interface CP Bearer ID

Indicates the ID of the CP bearer for the Xw interface. This parameter applies only to LTE FDD.

Xw Interface CP Bearer State

Indicates the status of the CP bearer for the Xw interface. This parameter applies only to LTE FDD.
