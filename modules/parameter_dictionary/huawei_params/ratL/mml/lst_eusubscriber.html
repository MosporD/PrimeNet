List a subscriber (LST EUSUBSCRIBER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters in the EuSubscriber MO.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query a subscriber, run the following command:
LST EUSUBSCRIBER:;
The result is shown as follows:

Output Description

Field Description

Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Subscriber Type

This parameter specifies the type of a subscriber. The value UE indicates a subscriber using a UE. The value RRN indicates a subscriber using an RRN. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

International Mobile Subscriber ID

Indicates the number that uniquely identifies a UE. It is stored on the SIM card of the UE and sent to the eNodeB during network access. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

RRN ID

Indicates the ID that uniquely identifies an RRN. It is equivalent to the IMSI. This ID is stored on the RRN, and sent to the eNodeB when the RRN accesses the network. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Cell ID

Indicates the ID of the cell serving an RRN. The combination of this parameter and the eNodeB ID forms the E-UTRAN cell identifier. The combination of the E-UTRAN cell identifier and the PLMN ID forms the E-UTRAN cell global identifier (ECGI). For details, see 3GPP TS 36.413. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Individual Subscriber Authentication Key

Indicates a key for subscriber authentication during network access. Modification to this parameter takes effect at the next network access of the subscriber. This parameter applies only to LTE FDD and LTE TDD.

Operator Variant Algorithm Configuration Field

Indicates an input parameter involved in calculation for subscriber authentication. Modification to this parameter takes effect at the next network access of the subscriber. This parameter applies only to LTE FDD and LTE TDD.

Uplink Aggregate Maximum Bit Rate(bit/s)

Indicates the uplink AMBR available for all the non-GBR bearers of a subscriber. This parameter applies only to LTE FDD and LTE TDD.

Downlink Aggregate Maximum Bit Rate(bit/s)

Indicates the downlink AMBR available for all the non-GBR bearers of a subscriber. This parameter applies only to LTE FDD and LTE TDD.

Subscriber Template ID

Indicates the ID of the subscriber template bound to a subscriber. Modification to this parameter takes effect at the next network access of a UE. This parameter applies only to LTE FDD and LTE TDD.

Subscriber Description

This parameter provides the description about a subscriber, including the functions and location. This parameter needs to be displayed and configured only if the SubscriberType parameter is set to RRN. This parameter applies only to LTE FDD and LTE TDD.
