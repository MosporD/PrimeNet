List Configuration of Cell RB Reserve (LST CELLRBRESERVE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query cell RB reservation configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

Display Cell RB Reserve Configuration:
LST CELLRBRESERVE: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 17:27:21
O&M    #806355830
%%LST CELLRBRESERVE: LocalCellId=1;%%

Output Description

Field Description

Local cell ID

Indicates the local cell ID, which uniquely identifies a cell within an eNodeB.

Index

Indicates the index of a reserved RB configuration for the cell.

RB Reserve Mode

Indicates the purpose for reserving RBs. The value NB_RESERVED indicates that the specified RBs are reserved not for NB-IoT deployment but as a guard band in the uplink or to reduce the interference between LTE and NB-IoT cells in the downlink. This value applies only to NB-IoT. The value NB_DEPLOYMENT indicates that the specified RBs are used for NB-IoT deployment. This value applies only to NB-IoT. The value RB_MASKING indicates that the specified RBs are used for manual RB masking. This value applies only to LTE FDD and LTE TDD. The value RB_MASKING_WITH_SRS indicates that the specified RBs are used for manual RB and SRS masking. This value applies only to LTE FDD. The value MCPTT_RB_RESERVED indicates that the specified RBs are reserved for MCPTT services. RB reservation for MCPTT services cannot be used in cells with a bandwidth lower than 5 MHz. This value applies only to LTE FDD and LTE TDD. The value LNR_SPECTRUM_SHR_RB_RESERVED indicates that the specified RBs are reserved for LTE and NR spectrum sharing, and RBs are allocated for the LTE PUCCH starting from the start index and end index of the reserved RBs towards the center frequency of the cell. This value applies only to LTE FDD. The value COVERAGE_ENH_RB_RESERVED indicates that the specified RBs are reserved for UEs for which coverage enhancement takes effect. This function does not apply to scenarios where the bandwidth is less than 5 MHz. This value applies only to LTE FDD.

RB Reserve Type

Indicates whether the PRBs to be reserved at the physical layer are uplink or downlink ones.

RB Reserve Start Index

Indicates the index of the start PRB of the physical-layer reserved PRBs. The PRBs are numbered starting from 0 in sequence from low to high frequencies. For details, see 3GPP TS 36.211.

RB Reserve End Index

Indicates the index of the end PRB of the physical-layer reserved PRBs.
