List External LAA Cell (LST LAAEXTERNALCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query external LAA cells.

Note

None.

Parameters

ID Name Description
EnodebId eNodeB ID

Meaning: Indicates the ID of the eNodeB serving the external LAA cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID. The eNodeB ID is the most significant 20 bits of the E-UTRAN cell ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The total number of different eNodeB IDs specified by the EnodebId parameter in LaaExternalCell MOs cannot exceed 18.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configuration of the LAA external cell, run the following command:
LST LAAEXTERNALCELL:;

Output Description

Field Description

Mobile Country Code

Indicates the MCC of the external LAA cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Mobile Network Code

Indicates the MNC of a neighboring LAA cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

eNodeB ID

Indicates the ID of the eNodeB serving the external LAA cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID. The eNodeB ID is the most significant 20 bits of the E-UTRAN cell ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Cell ID

Indicates the cell ID of an external LAA cell. It uniquely identifies an LAA cell in the eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID. The cell ID is the least significant eight bits of the E-UTRAN cell ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Tracking Area Code

Indicates the TAC of the external LAA cell. 3GPP specifications stipulate that the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration.
