Modify Cell Measurement Control Parameters (MOD CELLMCPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of the measurement control parameters.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
A3Offset A3 Offset

Meaning: Indicates the offset for event A3. This offset is the difference between the signal quality of a neighboring cell and that of the serving cell. A larger value indicates a higher requirement on neighboring cell quality for reporting event A3. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -13

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of reporting event A3 and accordingly a smaller number of UEs that report the related measurement results. In this case, the algorithm performance is poorer but signaling overheads are less. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
Hysteresis Hysteresis

Meaning: Indicates the hysteresis for reporting event A3 or A6. This parameter is used to prevent frequent entering or leaving of event A3 or A6 and decision errors due to radio signal fluctuation. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of meeting entering and leaving conditions for event A3 or A6. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
TimetoTrigger Time to Trigger

Meaning: Indicates the time-to-trigger for reporting event A3 or A6. When the entering condition of the event is met, the UE does not report the event to the eNodeB immediately. Instead, the UE reports the event only when the entering condition is continuously met throughout the time-to-trigger. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0ms(0ms), 40ms(40ms), 64ms(64ms), 80ms(80ms), 100ms(100ms), 128ms(128ms), 160ms(160ms), 256ms(256ms), 320ms(320ms), 480ms(480ms), 512ms(512ms), 640ms(640ms), 1024ms(1024ms), 1280ms(1280ms), 2560ms(2560ms), 5120ms(5120ms)

Unit: ms

Actual Value Range: 0ms, 40ms, 64ms, 80ms, 100ms, 128ms, 160ms, 256ms, 320ms, 480ms, 512ms, 640ms, 1024ms, 1280ms, 2560ms, 5120ms

MML Default Value: None

Recommended Value: 640ms

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of meeting entering and leaving conditions for event A3 or A6. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
MaxReportCells Max Report Cell Number

Meaning: Indicates the maximum number of cells to be included in each measurement report after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a larger number of cells to be included in a measurement report, which facilitates more accurate evaluation on interferences from neighboring cells, improves the performance of CEUs, and increases the average throughput of CEUs. However, the power consumption of UEs due to measurements and the overheads for measurement reporting are increased. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
ReportAmount Report Amount

Meaning: Indicates the number of periodic measurement reports that are sent after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: r1(1), r2(2), r4(4), r8(8), r16(16), r32(32), r64(64), Infinity(Infinity)

Unit: None

Actual Value Range: r1, r2, r4, r8, r16, r32, r64, Infinity

MML Default Value: None

Recommended Value: Infinity(Infinity)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more power consumption of UEs but more timely reflection of the interference from neighboring cells on CEUs. A smaller value of this parameter results in opposite effects.

Applicable Mode: L-FDD, L-TDD
ReportInterval Report Interval

Meaning: Indicates the interval between periodic measurement reports that are sent after event A3 or A6 is triggered. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

Unit: None

Actual Value Range: 120ms, 240ms, 480ms, 640ms, 1024ms, 2048ms, 5120ms, 10240ms, 1min, 6min, 12min, 30min, 60min

MML Default Value: None

Recommended Value: 5120ms

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer interval between periodic measurement reports and accordingly a lower frequency that UEs report the related measurement results. In this case, the capability of UE location tracing and the average throughput of CEUs decrease. A smaller value of this parameter results in the opposite effects, but frequent reporting of measurement results increases the power consumption of UEs.

Applicable Mode: L-FDD, L-TDD
ReportQuantity Report Quantity

Meaning: Indicates the type of the value to be included in the measurement report after event A3 or A6 is triggered, which can be set to SAME_AS_TRIG_QUAN or BOTH. The value SAME_AS_TRIG_QUAN indicates that the type of the value to be included in the measurement report is the same as that specified by the TriggerQuantity parameter. The value BOTH indicates that both RSRP and RSRQ values are to be included in the measurement report. The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. The measured RSRQ values vary with the load and are likely to reflect the signal quality of the cell in real time. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SAME_AS_TRIG_QUAN(Same as Trig Quan), BOTH

Unit: None

Actual Value Range: SAME_AS_TRIG_QUAN, BOTH

MML Default Value: None

Recommended Value: BOTH

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

The measured RSRP values are stable, slightly varying with the load, and therefore there is little signal fluctuation. IntraFreqReportQuantity IntraFreq Period MR Report Quantity

A3MCAdaptiveSwitch A3 Measurement Control Adaptive Switch

Meaning: Indicates whether parameter configurations related to A3 measurement report can be adaptively modified. This parameter provides the following options:

UlCoMPA3RptIntervalAdapt: If this option is selected, parameter configurations related to A3 measurement report can be adaptively modified. If this option is deselected, parameter configurations related to A3 measurement report cannot be adaptively modified. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: UlCoMPA3RptIntervalAdapt

Unit: None

Actual Value Range: UlCoMPA3RptIntervalAdapt

MML Default Value: None

Recommended Value: UlCoMPA3RptIntervalAdapt:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UlCoMPA3RptIntervalAdapt: When this option is selected, the eNodeB determines the cell UE number load conditions and adaptively adjusts the interval at which periodic measurement reports are sent. In multi-UE scenarios, the eNodeB extends the interval for UEs that newly access the cell. This reduces the amount of signaling but also slightly decreases the accuracy of coordinating cell selection. When this option is deselected, the interval is fixed for newly accessed UEs. This increases the accuracy of coordinating cell selection but also increases signaling overhead.

Applicable Mode: L-FDD, L-TDD
AoaDetectThd AoA Detect Threshold

Meaning: Indicates the channel quality threshold for measuring the angle of arrival (AOA) of UE signals to the eNodeB. When the channel quality of a UE reaches this threshold, the AOA is measured and the measurement results are reported periodically. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -10000~2000

Unit: 0.01dB

Actual Value Range: -100~20

MML Default Value: None

Recommended Value: -800

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a decrease in the number of UEs for which the AOA is measured, but also a decrease in the number of UEs with inaccurate AOA measurement results. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify the measurement control parameters with the parameters as follows: Local cell ID: 0, A3 Offset: -15dB, run the following command:
MOD CELLMCPARA: LocalCellId=0, A3Offset=-15;
