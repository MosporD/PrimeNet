Display Cell Camc Status (DSP CELLCAMCSTATUS)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the UL CAMC enablement status of UL CAMC-enabled cells. In the Dsp Local Cluster Cell Info area, information about intra-eNodeB CAMC cluster cells is displayed. In the Dsp Cluster Cell Info area, information about inter-eNodeB CAMC cluster cells in centralized Cloud BB is displayed. This command applies only to LTE TDD networks.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the cell Camc status with local cell ID of 0, run the following command:
DSP CELLCAMCSTATUS: LocalCellId=0;
The result is shown as follows:

Output Description

Field Description

Cell ID

Indicates the ID of the E-UTRAN cell. The combination of this parameter and the eNodeB ID forms the E-UTRAN cell identity. The combination of the E-UTRAN cell identity and the PLMN identity forms the ECGI. For details, see 3GPP TS 36.413.

Cluster ID

Indicates the ID of a cluster in Cloud BB scenarios. When static clusters are configured, the value of this parameter ranges from 0 to 999. This parameter applies only to LTE FDD and LTE TDD.

Cell UL CAMC Status

Indicates the status of uplink inter-eNodeB CAMC in a cell. This parameter applies only to LTE TDD cells.

Mobile country code

Indicates the mobile country code (MCC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code (MNC) of a cell in the cluster.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the eNodeB identity of the cluster cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell identity is comprised of the cell identity and the eNodeB identity (represented by the most significant 20 bits). The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell identity and the PLMN ID. For details about this parameter, see 3GPP TS 36.413. This parameter applies only to LTE FDD and LTE TDD.
