Display Information about Neighboring Cells for Uplink Interference Detection (DSP ULINTRFDETECTNCELLINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about neighboring cells involved in uplink interference detection for a cell. This command applies only to LTE FDD.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query information about neighboring cells involved in uplink interference detection for a cell:
+++    nq131        2019-07-11 16:33:59
O&M    #806355268
%%DSP ULINTRFDETECTNCELLINFO: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

Serving Sector Equipment Type

Indicates the type of sector equipment in the serving cell.

Serving Sector Equipment(group) ID

Indicates the ID of the serving sector equipment(group).

Serving Sector Equipment(Group) eNB ID

Indicates the ID of the eNodeB equipped with the serving sector equipment(group).

Coordinating Cell eNodeB ID

Indicates the ID of the eNodeB serving the coordinating cell.

Coordinating Sector Equipment Type

Indicates the type of sector equipment in the coordinating cell.

Coordinating Sector Equipment(group) ID

Indicates the ID of the coordinating sector equipment (group).

Coordinating Sector Equipment(group) eNB ID

Indicates the ID of the eNodeB equipped with the coordinating sector equipment (group).

Coordinating Local Cell ID

Indicates the local cell ID of the cell that functions as a cooperating cell in UL CoMP (DSP CELLULCOMPCLUSTER is used to query the ID), the local cell ID of the cell that functions as a cooperating cell in uplink IC (DSP CELLULICCLUSTER is used to query the ID), or the local cell ID of the cell that functions as a cooperating cell in uplink interference detection (DSP ULINTRFDETECTNCELLINFO is used to query the ID).

Coordinating Cell Route Type

Indicates the type of route between the serving BBPs of the serving and cooperating cells in UL CoMP (DSP CELLULCOMPCLUSTER is used to query the type), the type of route between the primary BBPs of the benefited and interfering cells in uplink IC (DSP CELLULICCLUSTER is used to query the type), the type of route between the serving and cooperating cells in uplink interference detection (DSP ULINTRFDETECTNCELLINFO is used to query the type).
