List Spectrum Cloud (LST SPECTRUMCLOUD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the configuration of spectrum cloudification.

Note

LocalCellId must be manually set. If LocalCellId is not specified, the eNodeB queries the parameter settings related to spectrum cloudification features of all local cells. If LocalCellId is specified, the eNodeB queries the parameter settings related to spectrum cloudification features of the local cell specified by LocalCellId.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of an E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of spectrum cloudification:
LST SPECTRUMCLOUD:;

Output Description

Field Description

Local Cell ID

Indicates the local ID of an E-UTRAN cell. This parameter applies only to LTE FDD and LTE TDD.

Spectrum Cloud Switch

Indicates whether to enable spectrum cloudification. If this parameter is set to OFF, spectrum cloudification is disabled. If this parameter is set to GL_SPECTRUM_CONCURRENCY, GSM and LTE spectrum concurrency is enabled. If this parameter is set to UL_SPECTRUM_SHARING, UMTS and LTE spectrum sharing is enabled. If this parameter is set to LTE_NR_UPLINK_SPECTRUM_SHR, LTE and NR uplink spectrum sharing is enabled. If this parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM, LTE, UMTS, and GSM spectrum sharing is enabled with GSM statically deployed on the LTE guard band. If this parameter is set to DC_HSDPA_BASED_UL_SPECTRUM_SHR, DC-HSDPA-based UMTS and LTE spectrum sharing is enabled. If this parameter is set to LTE_NR_SPECTRUM_SHR, LTE FDD and NR flash dynamic spectrum sharing or LTE TDD and NR dynamic spectrum sharing is enabled. If this parameter is set to LTE_NR_COORD_SPECTRUM_SHR, LTE and NR spectrum sharing coordination is enabled. This function determines the spectrum requirement status of an LTE cell based on the shared spectrum and supports incoming UE handovers when the LTE cell is in the power silence state. The LTE_NR_COORD_SPECTRUM_SHR value applies only to LTE FDD and LTE TDD.

GSM ARFCN Group ID

Indicates the GSM ARFCN group ID used by GSM in standard LTE bandwidths. This parameter references the frequency configuration in the GsmInterfArfcnCfg MO. This parameter applies only to LTE FDD.

LTE Interference Performance Optimize Switch

Indicates whether to optimize LTE interference performance in the GSM and LTE spectrum concurrency feature or UMTS and LTE spectrum sharing feature.

DL_PFM_PRF_PDCCH_SWITCH: Indicates whether to enable PDCCH optimization to preferentially guarantee downlink performance. If this option is selected, PDCCH resource allocation preferentially guarantees the downlink performance.

QPSK_RAISE_PWR_SWITCH: Indicates whether to raise power for the transmission of QPSK-modulated data. If this option is selected, in the downlink, the eNodeB uses the power of unavailable RBs to increase the power for the transmission of QPSK-modulated data to cell-edge UEs. This increases the demodulation performance of cell-edge UEs.

UNCOSITE_UL_SCH_OPT_SWITCH: Indicates whether to optimize inter-site uplink scheduling. If this option is selected, the usage of spectrum overlap between GSM and LTE increases in the uplink. This parameter applies only to LTE FDD.

Near Point User Path Loss Threshold(dB)

Indicates the threshold for determining whether a UE is located near the cell center for uplink shared spectrum resource scheduling when the GSM and LTE Spectrum Concurrency (LTE FDD) feature is used. If the path loss reported by a UE is lower than the threshold, the UE is determined as a UE located near the center of the E-UTRAN cell. This parameter applies only to LTE FDD.

Downlink CCH Send Strategy

Indicates the CRS and PDCCH transmission policy used in the LTE cell.

When GSM and LTE spectrum concurrency is enabled:

If this parameter is set to ADAPTIVE, CRSs and PDCCHs are transmitted adaptively based on the GSM and LTE interference coordination result.

If this parameter is set to CRS_AND_PDCCH_AVOIDED, CRSs and PDCCHs are not transmitted on the REs exposed to strong GSM interference.

If this parameter is set to CRS_AVOIDED_PDCCH_ADAPTIVE, CRSs are not transmitted on the REs exposed to strong GSM interference, and PDCCHs are transmitted adaptively based on the GSM and LTE interference coordination result.

If this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, CRSs are transmitted across the entire bandwidth, and PDCCHs are transmitted based on the GSM and LTE interference coordination result.

When UMTS and LTE spectrum sharing is enabled:

If this parameter is set to ADAPTIVE, CRSs and PDCCHs of the LTE cell are transmitted only within the available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_ALL, CRSs and PDCCHs of the LTE cell are transmitted across the entire LTE bandwidth.

If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, CRSs of the LTE cell are transmitted across the entire LTE bandwidth, and PDCCHs of the LTE cell are transmitted within the available LTE bandwidth.

When UMTS and LTE spectrum sharing phase 2 is enabled, DC-HSDPA-based UMTS and LTE spectrum sharing is enabled, or both UMTS and LTE spectrum sharing phase 2 and GSM and LTE spectrum concurrency are enabled (the SpectrumCloudSwitch parameter is set to UL_SPECTRUM_SHR_PH2_WITH_GSM):

If this parameter is set to ADAPTIVE, CRSs and PDCCHs of the LTE cell are dynamically transmitted only within the maximum available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_ALL, CRSs and PDCCHs of the LTE cell are statically transmitted on the maximum available LTE bandwidth.

If this parameter is set to CRS_ALL_AND_PDCCH_AVOIDED, CRSs of the LTE cell are statically transmitted on the maximum available LTE bandwidth, and PDCCHs of the LTE cell are dynamically transmitted on the available LTE bandwidth.

If this parameter is set to CRS_ALL_PDCCH_ADAPTIVE, CRSs of the LTE cell are transmitted within the LTE standard bandwidth, and PDCCHs of the LTE cell are dynamically transmitted only within the maximum available LTE bandwidth.

If this parameter is set to CRS_AND_PDCCH_STANDARD_BW, CRSs and PDCCHs are transmitted within the LTE standard bandwidth. In addition, if the SchedulerCtrlPowerSwitch option of the UlSchSwitch parameter is selected, RB allocation optimization is enabled. This parameter applies only to LTE FDD.

PDCCH Interferenced RE Compensation Rate(%)

Indicates the compensation rate of REs in the case of GSM interference. This parameter applies only to LTE FDD.

UMTS and LTE Spectrum Sharing Config ID

Indicates the cell configuration ID of UMTS and LTE spectrum sharing, which is unique within an eNodeB. This parameter applies only to LTE FDD.

Co-coverage GSM Sharing Carrier Power(0.1W)

Indicates the power of GSM shared carrier in the GSM and LTE co-coverage area. The power value is used to calculate the difference in power spectrum density (PSD) between GSM and LTE, which can be used for selecting an appropriate GL guardband. This parameter is invalid when it is set to 65535. This parameter applies only to LTE FDD.

LTE and NR UL Static Spct Shr Switch

Indicates whether to enable uplink static spectrum sharing between LTE and NR. This parameter applies only to LTE FDD.

Spectrum Cloud Enhancement Switch

Indicates whether to enable spectrum cloudification enhancement.

GL_SPCT_CONCURRENCY_PH2_SW: Indicates whether to enable enhanced GL spectrum concurrency phase 2. When this option is selected, the maximum number of ARFCNs of interfering GSM frequencies that can be configured in LTE in-band increases.

UL_SPECTRUM_SHR_PH2_SW: Indicates whether to enable enhanced UL spectrum sharing phase 2. When this option is selected, spectrum can be dynamically shared between LTE and UMTS. This option applies only to LTE FDD.

LNR_SPECTRUM_SHR_SUPERUL_SW: Indicates whether to enable superior uplink spectrum sharing. When this option is selected, superior uplink spectrum sharing is enabled between LTE and NR. This option applies only to LTE FDD.

LTE and NR Spectrum Sharing Cell Group ID

Indicates the ID of an LTE and NR spectrum sharing cell group. This ID uniquely identifies such a group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Decrease CFI Rate(%)

Indicates the threshold, expressed as a percentage of CFIs, for triggering reduction of the CFI configured for UMTS. The actual CFI may be different from the CFI configured for UMTS. There are two scenarios: (1) The actual CFI is smaller than the CFI configured for UMTS. (2) The actual CFI is greater than or equal to the CFI configured for UMTS. The percentage of the actual CFIs smaller than the CFI configured for UMTS is recorded as A, and the percentage of the actual CFIs greater than or equal to the CFI configured for the UMTS is recorded as 1-A. When A is greater than the value of DecreaseCfiRate and 1-A is smaller than the value of IncreaseCfiRate, the CFI configured for UMTS will be reduced. This parameter applies only to LTE FDD.

Increase CFI Rate(%)

Indicates the threshold, expressed as a percentage of CFIs, for triggering increase of the CFI configured for UMTS. If the percentage of actual CFIs greater than the CFI configured for UMTS is greater than the value of this parameter, the CFI configured for UMTS will be increased. This parameter applies only to LTE FDD.

Spectrum Sharing Mode

Indicates the spectrum sharing mode. If this parameter is set to LTE_NR_PWR_DYN_SHR_WITH_SPCT, LTE and NR share spectrum power when they share the spectrum. If this parameter is set to LTE_NR_PWR_INDEPENDENT, LTE and NR use separate spectrum power when they share the spectrum. This parameter applies only to LTE FDD.
