Modify PrbDlGapConfig (MOD PRBDLGAPCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of PRB-level parameters related to the downlink gap function.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB ID, which uniquely identifies a PRB within an NB-IoT cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
DlGapDurationCoeff Downlink Gap Duration Coefficient

Meaning: Indicates the coefficient for the duration of a downlink gap for NB-IoT. The duration of a downlink gap is equal to the interval between downlink gaps multiplied by this coefficient. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

GUI Value Range: ONE_EIGHTH(ONE_EIGHTH), ONE_FOURTH(ONE_FOURTH), THREE_EIGHTH(THREE_EIGHTH), ONE_HALF(ONE_HALF)

Unit: None

Actual Value Range: ONE_EIGHTH, ONE_FOURTH, THREE_EIGHTH, ONE_HALF

MML Default Value: None

Recommended Value: ONE_EIGHTH(1/8)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter duration for NPDSCH/NPDCCH gaps. A larger value leads to a longer duration.

Applicable Mode: L-NB-IOT
DlGapPeriod Downlink Gap Period

Meaning: Indicates the interval between downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

GUI Value Range: SF64(SF64), SF128(SF128), SF256(SF256), SF512(SF512)

Unit: None

Actual Value Range: SF64, SF128, SF256, SF512

MML Default Value: None

Recommended Value: SF256(SF256)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter interval between NPDSCH/NPDCCH gaps. A larger value leads to a longer interval.

Applicable Mode: L-NB-IOT
DlGapThreshold Downlink Gap Threshold

Meaning: Indicates the threshold for applying downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

GUI Value Range: N_32(N_32), N_64(N_64), N_128(N_128), N_256(N_256)

Unit: None

Actual Value Range: N_32, N_64, N_128, N_256

MML Default Value: None

Recommended Value: N_32(N_32)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of applying NPDSCH/NPDCCH gaps. A larger value leads to a lower probability.

Applicable Mode: L-NB-IOT

Example

To modify PRB downlink gap config in the cell with the parameters as follows: Local cell ID: 0, PRB ID : 0, Downlink Gap Duration Coefficient: ONE_EIGHTH, run the following command:
MOD PRBDLGAPCONFIG: LocalCellId=0, PrbId=0, DlGapDurationCoeff=ONE_EIGHTH;
