Add Intra-Frequency Neighboring Relation with E-UTRAN Cell (ADD EUTRANINTRAFREQNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the neighboring relation with an intra-frequency E-UTRAN cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the current cell and the intra-frequency E-UTRAN cell are controlled by different eNodeBs, ensure that the associated external E-UTRAN cell has been configured.

  • The uplink and downlink frequencies of an intra-frequency neighboring cell must be the same as the uplink and downlink frequencies of the local LTE FDD cell, respectively.

  • In non-super-combined cells, the physical cell ID of an intra-frequency neighboring cell must be different from that of the serving cell. In super-combined cells, the physical cell ID of an intra-frequency neighboring cell can be the same as that of the serving cell.

  • The total number of intra- and inter-frequency neighboring cells configured for an E-UTRAN cell cannot exceed 256 for LMPT board and 384 for UMPT board.

  • For TDD cells, if the Cell Range Expansion parameter is set to a non-zero value and a neighboring relationship exists between a macro cell and a micro cell, the MRO algorithm does not change the value of the Cell individual offset parameter.

  • The ANR flag parameter specifies whether a neighboring cell is automatically detected by ANR. This parameter cannot be set in the MML command window but can be set by running MML commands in command line or running batch commands. This parameter can be queried by running LST commands.

    The default parameter value BOOLEAN_FALSE(False) is delivered when ADD commands are executed in the MML command window. The value BOOLEAN_FALSE(False) indicates that the neighboring cell is manually configured.

    When a neighbor relationship is automatically added by ANR, this parameter is set to BOOLEAN_TRUE(True), indicating that the neighboring cell is automatically configured.

    You are advised not to set the AnrFlag parameter by running MML commands in command line or running batch commands.

CellMeasPriority Cell Measure Priority

Meaning: Indicates the priority of measurement on the intra-frequency neighboring cell. The eNodeB preferentially contains the information about a neighboring cell with this priority set to HIGH_PRIORITY while delivering a measurement configuration. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: LOW_PRIORITY(Low Priority), HIGH_PRIORITY(High Priority)

Unit: None

Actual Value Range: LOW_PRIORITY, HIGH_PRIORITY

MML Default Value: LOW_PRIORITY(Low Priority)

Recommended Value: LOW_PRIORITY(Low Priority)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In the measurement configuration for an intra-frequency handover, the eNodeB includes information about a limited number of intra-frequency neighboring cells whose cell individual offsets (CIOs) are not zero. If this parameter is set to HIGH_PRIORITY and this neighboring cell has a non-zero CIO, it is more likely that this neighboring cell is included in the measurement configuration, thereby increasing the probability of a timely handover to this intra-frequency neighboring cell. If this neighboring cell is eventually not included in the measurement configuration, the UE uses zero as the CIO for this neighboring cell during handover evaluation. In this case, if the actual CIO for the neighboring cell is not 0, this results in a delayed or premature handover to this neighboring cell.

Applicable Mode: L-FDD, L-TDD
CellRangeExpansion Cell Range Expansion

Meaning: Indicates the maximum cell coverage offset. This parameter is specified to achieve coverage expansion of micro base stations. The offset that actually takes effect depends on UE capabilities. The parameter value is added to or subtracted from the handover parameter cell individual offset (CIO) to obtain a new CIO, which must meet protocol-defined constraints. The updated CIO is delivered to UEs so that handovers from an eNodeB to a micro base station can be triggered more easily or handovers from a micro base station to an eNodeB can be triggered less easily. In this manner, the cell coverage of a micro base station is expanded. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: dB

Actual Value Range: 0~15

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a larger cell coverage of micro cells and allows a micro cell to serve more UEs. However, an extremely large value of this parameter may decrease network capacity or throughput of cell edge UEs and deteriorate KPIs related to handovers, such as the handover success rate. A smaller value of this parameter leads to the opposite effects, and an extremely small value of this parameter may decrease network capacity or throughput of cell edge UEs. Therefore, you are advised to set this parameter properly to balance the load between macro and micro cells and increase throughput of cell edge UEs to improve the network coverage.

AttachCellSwitch Attach Cell Switch

Meaning: Indicates whether to enable the macro-micro homing relationship of the intra-frequency neighboring cell. In HetNet networking, the macro cell and micro cell that greatly interfere each other are added to one cluster, and homing relationships are configured between the macro and micro cells in each cluster. A cluster consists of one macro cell and a maximum of eight homed micro cells.

If this parameter is set to ON(On), the neighboring cell is the homed cell of the local cell.

If this parameter is set to OFF(Off), the neighboring cell is not the homed cell of the local cell.

The homing relationship between a macro cell and a micro cell takes effect only when the parameter settings are the same in the two cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF(Off)

Parameter Relationship:

-Others:

  • In HetNet networking, dynamic enhanced inter-cell interference coordination (eICIC) takes effect only when homing relationships between macro and micro cells are configured. After dynamic eICIC is enabled and homing relationships between macro and micro cells are modified, the almost-blank subframe (ABS) of the new homing macro cell may differ from that of the original homing macro cell. However, to decrease signaling overheads in the RRC layer, the micro cells whose homing relationships are modified do not initiate CRE and measurement subset reconfiguration for UEs that have already accessed the cells. As a result, these UEs may suffer stronger interference from the original homing macro cell and their performance deteriorates.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To add an intra-frequency neighboring relation with the parameters as follows: Local cell ID: 0, Mobile country code: 460, Mobile network code: 20, eNodeB ID: 255, Cell ID: 1, Cell individual offset: dB1, Cell offset: dB1, No handover indicator: PERMIT_HO_ENUM, run the following command:
ADD EUTRANINTRAFREQNCELL: LocalCellId=0, Mcc="460", Mnc="20", eNodeBId=255, CellId=1, CellIndividualOffset=dB1, CellQoffset=dB1, NoHoFlag=PERMIT_HO_ENUM;
Example 2: To add an intra-frequency neighboring relation with the parameters as follows: Local cell ID: 0, Mobile country code: 460, Mobile network code: 20, eNodeB ID: 255, Cell ID: 2, Cell individual offset: dB2, Cell offset: dB2, No handover indicator: PERMIT_HO_ENUM, No remove indicator: FORBID_RMV_ENUM, run the following command:
ADD EUTRANINTRAFREQNCELL: LocalCellId=0, Mcc="460", Mnc="20", eNodeBId=255, CellId=2, CellIndividualOffset=dB2, CellQoffset=dB2, NoHoFlag=PERMIT_HO_ENUM, NoRmvFlag=FORBID_RMV_ENUM;
