Display NG Interface Information (DSP NGINTERFACE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the information about an NG interface, such as the information about the CP bearer used by the NG interface, NG interface status, and peer AMF status. If the status of an NG interface is abnormal, the command output displays the information of the peer AMF in the last normal connection.

Note

None.

Parameters

ID Name Description
NgInterfaceId NG Interface ID

Meaning: Indicates the ID of the NG interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

O&M    #806354947

RETCODE = 0  Operation succeeded.

Output Description

Field Description

NG Interface ID

Indicates the ID of the NG interface. This parameter applies only to LTE FDD and LTE TDD.

CN Operator ID

Indicates the ID of the operator that owns the NG interface. This parameter applies only to LTE FDD and LTE TDD.

CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group that owns the NG interface. If the eNodeB works in hybrid RAN sharing mode, you can set this parameter to a value within the range of 0-5. These IDs are valid. If the eNodeB works in independent mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, this parameter does not take effect. In this case, you can set this parameter to its default value 255. The value 255 is invalid. This parameter applies only to LTE FDD and LTE TDD.

NG Interface CP Bearer ID

Indicates the ID of the control port (CP) bearer used by the NG interface. This parameter applies only to LTE FDD and LTE TDD.

NG Interface CP Bearer Status

Indicates the status of the control port (CP) bearer used by the NG interface. This parameter applies only to LTE FDD and LTE TDD.

NG Interface Blocking Status

Indicates whether the NG interface is blocked. If this parameter is set to TRUE, the NG interface is blocked. If this parameter is set to FALSE, the NG interface is not blocked. This parameter applies only to LTE FDD and LTE TDD.

NG Interface Status

Indicates the status of the NG interface. This parameter applies only to LTE FDD and LTE TDD.

NG Interface User Number

Indicates the number of UEs accessed over the NG interface. This parameter applies only to LTE FDD and LTE TDD.

AMF Name

Indicates the name of the access and mobility management function (AMF) connected over the NG interface. This parameter is valid after the NG interface is set up and the AMF name is contained in the NG interface setup response message or the AMF configuration update message. In other conditions, NULL is displayed. For details, see 3GPP TS 38.413. This parameter applies only to LTE FDD and LTE TDD.

Served GUAMIs

Indicates all of the globally unique AMF identifiers (GUAMIs) of the AMFs connected over the NG interface. Each GUAMI is represented by MCC-MNC-AMF Region ID-AMF Set ID-AMF Pointer. The GUAMIs of serving core networks are separated by commas (,). This parameter applies only to LTE FDD and LTE TDD.

NG Interface Fault Reason

Indicates the reason why the NG interface is faulty. This parameter applies only to LTE FDD and LTE TDD.
