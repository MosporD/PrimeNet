Modify MME Domain Name (MOD MMEDOMAINNAME)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of an MME domain name.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifying the setting of this MO may trigger automatic S1 removal, causing service interruptions.

Parameters

ID Name Description
MMEDomNameId MME Domain Name ID

Meaning: Indicates the index of the MME domain name.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
MMEDomName MME Domain Name

Meaning: Indicates the domain name of an MME or an MME pool. If MMEs are configured as an MME pool, you are advised to specify the domain name of the MME pool to simplify the configuration.

GUI Value Range: 1~127 characters

Unit: None

Actual Value Range: 1~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of MMEDomName in the MMEDomainName MO can contain only the following characters: lower-case letters (a to z), upper-case letters (A to Z), digits (0 to 9), hyphens (-), and full stops (.).
  • The values of MMEDomName in MMEDomainName MOs must be different.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the configurations of an MME domain name with the parameters as follows: MME Domain Name ID: 0, CN Operator ID: 0, MME Domain Name: "template.3gppnetwork.org", run the following command:
MOD MMEDOMAINNAME: MMEDomNameId=0, CnOperatorId=0, MMEDomName="template.3gppnetwork.org";
