Add 5QI Configuration (ADD QCI5QICONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add 5QI configurations on the eNodeB, which is connected to the 5GC.

Note

None.

Parameters

ID Name Description
Nr5qi NR 5G QoS Identifier

Meaning: Indicates the 5G QoS Identifier (5QI) of a QoS flow that needs to be mapped to a QCI. Different 5QIs represent different QoS specifications such as the packet delay budget, packet loss rate, average window, and service type (whether the service is a GBR service or not). For details, see 3GPP TS 23.501.

When a new 5QI is configured on the core network:

1. If no Qci5qiConfig MO is added for this 5QI, this 5QI is mapped to QCI 9 by default.

2. If a Qci5qiConfig MO is added for this 5QI but the QCI mapped to this 5QI is not configured on the base station side, the base station processes this 5QI as if the mapping between the 5QI and QCI is not configured.

This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~254

Unit: None

Actual Value Range: 1~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When the Nr5qi parameter in the Qci5qiConfig MO is set to 1-5,65,66,69,75, the default Qci mapping relationship cannot be modified or deleted.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AsReflectiveQosSwitch Access Service Reflective QoS Switch

Meaning: Indicates whether to enable the AS reflective QoS function. For details about reflective QoS, see 3GPP TS 23.501. If the parameter is set to ON, the UE can obtain the mapping between QoS flows and the DRBs by monitoring the QoS flow identity (QFI) of the data packet transmitted on each DRB. If this parameter is set to OFF, this function is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON and multiple QoS flows are mapped to the same DRB, the RRC signaling overhead can be reduced. If this parameter is set to OFF, the mapping between all QoS flows and DRBs needs to be sent to UEs through RRC signaling. When multiple QoS flows are mapped to the same DRB, extra RRC signaling overhead is generated.

Applicable Mode: L-FDD, L-TDD
Qci QoS Class Identifier

Meaning: Indicates the QCI that is mapped to the 5QI. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~254

Unit: None

Actual Value Range: 1~254

MML Default Value: 9

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Nr5qi 1: 1

Nr5qi 2: 2

Nr5qi 3: 3

Nr5qi 4: 4

Nr5qi 5: 5

Nr5qi 6: 6

Nr5qi 7: 7

Nr5qi 8: 8

Nr5qi 9: 9

Nr5qi 65: 65

Nr5qi 66: 66

Nr5qi 69: 69

Nr5qi 70: 70

Nr5qi 75: 75

Nr5qi 79: 79

Parameter Relationship:

-Configuration constraints:

  • When the Nr5qi parameter in the Qci5qiConfig MO is set to 1-5,65,66,69,75, the default Qci mapping relationship cannot be modified or deleted.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add 5QI configurations on the eNodeB with the parameters as follows: NR 5G QoS Identifier: 254, QoS Class Identifier: 9, run the following command:
ADD QCI5QICONFIG: Nr5qi=254, Qci=9;
