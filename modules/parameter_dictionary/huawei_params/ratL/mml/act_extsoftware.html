Activate external device software (ACT EXTSOFTWARE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to activate the software of an external device.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When operators activate the software of an RRN, the RRN will be reset. As a result, services provided by base stations connected to the RRN will be interrupted.

Parameters

Example

Activate the software of an external device with the parameters as follows: Local Subscriber ID:10, EXTDEVTYPE:RRN3901, Software Version:" V100R010C00B043";
run the following command:
ACT EXTSOFTWARE: LocalSubscriberId=10, EXTDEVTYPE=RRN3901, SV="V100R010C00B043";

Output Description

Indicates the session ID of the operation feedback. This parameter applies only to LTE FDD and LTE TDD.
