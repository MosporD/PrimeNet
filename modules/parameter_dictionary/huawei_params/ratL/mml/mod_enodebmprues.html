Modify eNodeB MPRU ES Configuration (MOD ENODEBMPRUES)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of eNodeB-level MPRU energy saving parameters.

Note

The value of the MpruDormancyDlEarfcn parameter must equal a downlink EARFCN on which a cell served by the eNodeB works, and the bandwidth of this cell must be greater than 10 MHz.

Parameters

ID Name Description
MpruDormancyDlEarfcn MPRU Dormancy Downlink EARFCN

Meaning: Indicates the downlink EARFCN of the basic coverage carrier to be reserved after the MPRU enters dormancy. If this parameter is set to -1, MPRU dormancy is disabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -1~70545,229376~229575

Unit: None

Actual Value Range: -1,0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MpruDormancyDlPrbUsageThld MPRU Dormancy Downlink PRB Usage Threshold

Meaning: Indicates the downlink PRB usage threshold for MPRU dormancy. If the downlink PRB usage of a carrier is lower than the value of this threshold, the MPRU enters dormancy. If the downlink PRB usage of a carrier is higher than the sum of the value of this threshold and a preset offset (5%), the MPRU exits dormancy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~15

Unit: %

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower probability for the MPRU to enter dormancy and therefore a smaller impact on UE throughput. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
MpruDormancyMinimumRsrp MPRU Dormancy Minimum RSRP

Meaning: Indicates the minimum RSRP of the basic coverage carrier to be reserved after the MPRU enters dormancy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -115~-105

Unit: dBm

Actual Value Range: -115~-105

MML Default Value: None

Recommended Value: -115

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower level value for basic coverage after the MPRU enters dormancy and a larger impact on UE throughput. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
MpruDormancyStartTime MPRU Dormancy Start Time

Meaning: Indicates the start time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 00:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MpruDormancyStopTime MPRU Dormancy Stop Time

Meaning: Indicates the end time of MPRU dormancy. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 06:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the eNodeB-level MPRU energy saving configurations, run the following command:
MOD ENODEBMPRUES: MpruDormancyDlEarfcn = 1500;
