Modify Cell DL PDSCH Power Control Configuration (MOD CELLDLPCPDSCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of cell PDSCH downlink power control.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CcuPa Center UE PA

Meaning: Indicates the PA value of cell center UEs when DL ICIC is enabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PA_NEG6(-6dB), PA_NEG4DOT77(-4.77dB), PA_NEG3(-3dB), PA_NEG1DOT77(-1.77dB), PA_0(0dB), PA_1(1dB), PA_2(2dB), PA_3(3dB)

Unit: dB

Actual Value Range: PA_NEG6, PA_NEG4DOT77, PA_NEG3, PA_NEG1DOT77, PA_0, PA_1, PA_2, PA_3

MML Default Value: None

Recommended Value: When PaPcOff is set to -6, you are not advised to enable the ICIC function.

When PaPcOff is set to -4.77, you are advised to set CcuPa to -6 dB.

When PaPcOff is set to -3, you are advised to set CcuPa to -6 dB.

When PaPcOff is set to -1.77, you are advised to set CcuPa to -4.77 dB.

When PaPcOff is set to 0, you are advised to set CcuPa to -3 dB.

When PaPcOff is set to 1, you are advised to set CcuPa to -1.77 dB.

When PaPcOff is set to 2, you are advised to set CcuPa to 0 dB.

When PaPcOff is set to 3, you are not advised to enable the ICIC function.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When downlink static or dynamic ICIC is enabled in the cell, a larger value results in higher transmit power for cell center UEs (CCUs) in the cell and also higher interference to cell edge UEs (CEUs) in neighboring cells. This results in higher average throughput for UEs and lower throughput for CEUs in the local cell. When downlink static or dynamic ICIC is enabled in the cell, a smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
CeuPa Edge UE PA

Meaning: Indicates the PA value of cell edge UEs when DL ICIC is enabled. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: PA_NEG6(-6dB), PA_NEG4DOT77(-4.77dB), PA_NEG3(-3dB), PA_NEG1DOT77(-1.77dB), PA_0(0dB), PA_1(1dB), PA_2(2dB), PA_3(3dB)

Unit: dB

Actual Value Range: PA_NEG6, PA_NEG4DOT77, PA_NEG3, PA_NEG1DOT77, PA_0, PA_1, PA_2, PA_3

MML Default Value: None

Recommended Value: When PaPcOff is set to -6, you are not advised to enable the ICIC function.

When PaPcOff is set to -4.77, you are advised to set CeuPa to -3 dB.

When PaPcOff is set to -3, you are advised to set CeuPa to -1.77 dB.

When PaPcOff is set to -1.77, you are advised to set CeuPa to 0 dB.

When PaPcOff is set to 0, you are advised to set CeuPa to 1 dB.

When PaPcOff is set to 1, you are advised to set CeuPa to 2 dB.

When PaPcOff is set to 2, you are advised to set CeuPa to 3 dB.

When PaPcOff is set to 3, you are not advised to enable the ICIC function.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When downlink static or dynamic ICIC is enabled in the cell, a larger value results in higher transmit power for CEUs in the cell and also higher interference to CCUs in neighboring cells. This results in lower average throughput for UEs and higher throughput for CEUs in the local cell. When downlink static or dynamic ICIC is enabled in the cell, a smaller value leads to the opposite effects.

Applicable Mode: L-FDD, L-TDD
CellEdgLoadEvalPrd Cell Edge Load Evaluation Period

Meaning: Indicates the interval for evaluating the cell edge load when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This parameter applies only to LTE TDD networks.

GUI Value Range: 900~3600

Unit: s

Actual Value Range: 900~3600

MML Default Value: None

Recommended Value: 1800

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to minor impact of the cell edge load fluctuation on the evaluation result. However, the eNodeB cannot obtain the real-time cell edge load.

A smaller value of this parameter enables the eNodeB to obtain the real-time cell edge load but leads to greater impact of the cell edge load fluctuation on the evaluation result.

Applicable Mode: L-TDD
NeighCellEdgLoadThd Neighboring Cell Edge Load Threshold

Meaning: Indicates the threshold of the neighboring cell edge load for determining whether to increase the power of beamforming UEs at the edge of the local cell when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. If the neighboring cell edge load is greater than the threshold specified by this parameter, the power of corresponding beamforming UEs in the local cell edge is not increased. If the neighboring cell edge load is less than or equal to the specified threshold and the number of neighboring cells meeting this condition is less than or equal to a specified percentage, the power of corresponding beamforming UEs in the local cell edge is increased. This parameter applies only to LTE TDD networks.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to power increase for a smaller number of beamforming UEs in the cell edge and less increase in the average cell throughput. However, the interference to neighboring cells is smaller.

A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-TDD
ExceedNCellEdgLoadThdRatio Ratio of Cells Exceeding Neighboring Cell Edge Load Threshold

Meaning: Indicates the percentage of the number of neighboring cells whose cell edge load meets the specified threshold. This percentage is used to determine whether to increase the power of beamforming UEs when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. If the percentage of the number of neighboring cells meeting the cell edge load threshold is greater than the value of this parameter, the power of all beamforming UEs in the local cell is not increased. If the percentage of the number of neighboring cells meeting the cell edge load threshold is less than or equal to the value of this parameter, the power of beamforming UEs in the local cell is increased. This parameter applies only to LTE TDD networks.

GUI Value Range: 1~100

Unit: %

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller probability of increasing the power of beamforming UEs and less increase in the average cell throughput. However, the interference to neighboring cells is smaller.

A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-TDD
BFUserPwrBoostPrd BF User Power Boost Period

Meaning: Indicates the period during which the increased value of the beamforming UE power remains unchanged when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This parameter applies only to LTE TDD cells.

GUI Value Range: 5~3600

Unit: s

Actual Value Range: 5~3600

MML Default Value: None

Recommended Value: 1800

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to less frequent adjustments in the adaptive increase of beamforming UE power, minor impact of the RRU power fluctuation on the adaptive power increase, and therefore more stable increase of beamforming UE power. However, the real-time RRU power cannot be used for the adaptation.

A smaller value of this parameter leads to more frequent adjustments in the adaptive increase of beamforming UE power and therefore more frequent increases of the beamforming UE power. However, the real-time RRU power can be used.

Applicable Mode: L-TDD
BFUserAdptPwrA3Offset BF Mode User Adaptive Power A3 offset

Meaning: Indicates the offset for event A3 reporting when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This offset is the difference between the quality of a neighboring cell and that of the serving cell. If this parameter is set to a large value, event A3 is reported only if the signal quality of the neighboring cell is significantly better than that of the serving cell. This parameter applies only to LTE TDD networks.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -13

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter, a smaller value of this parameter leads to a larger number of UEs being considered as CEUs, a smaller probability that the power of beamforming UEs in the neighboring cells is increased, and smaller interference in the local cell edge. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-TDD
BFUserAdptPwrA6Offset BF Mode User Adaptive Power A6 offset

Meaning: Indicates the offset for event A6 reporting in CA scenarios when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This offset is the difference between the quality of a neighboring cell and that of the serving cell. If this parameter is set to a large value, event A6 is reported only if the signal quality of the neighboring cell is significantly better than that of the serving cell. This parameter applies only to LTE TDD networks.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -13

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter, a smaller value of this parameter leads to a larger number of UEs being considered as CEUs in CA scenarios, a smaller probability that the power of beamforming UEs in the neighboring cells is increased, and smaller interference in the local cell edge. A larger value of this parameter leads to the opposite effects.

Applicable Mode: L-TDD
RemainingPwrUseStrategy Remaining Power Use Strategy

Meaning: Indicates whether to use the remaining power. If this parameter is set to OFF, the remaining power is not used. If this parameter is set to PORT_PWR_BALANCING and the CrsPortNum parameter is set to CRS_PORT_4, power is balanced among the ports. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), PORT_PWR_BALANCING(Port power balancing)

Unit: None

Actual Value Range: OFF, PORT_PWR_BALANCING

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to OFF, network performance is not affected. If this parameter is set to PORT_PWR_BALANCING, the downlink UE throughput in the cell increases when the value of Pb decreases and the power for data transmission in the symbols with reference signals increases.

Applicable Mode: L-FDD

Example

Example 1: To modify the DL power control PDSCH configuration information with the parameters as follows: Local cell ID: 0, PaEdgeUe: PA_0, run the following command:
MOD CELLDLPCPDSCH: LocalCellId=0, CeuPa=PA_0;
Example 2: To modify the DL power control PDSCH configuration information with the parameters as follows: Local cell ID: 0, PaCenterUe: PA_0, run the following command:
MOD CELLDLPCPDSCH: LocalCellId=0, CcuPa=PA_0;
