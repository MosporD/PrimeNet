Modify Cell Drx Special Para (MOD CELLDRXSPECIALPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of special DRX parameters for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LongDrxCycleSpecial Long DRX Cycle for Special UE

Meaning: Indicates the length of the SPID-specific long DRX cycle. This long DRX cycle takes effect only on non-power-saving UEs configured with a specific SPID or UEs whose capability information indicates that they do not support power saving. Because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter, the actual value of the LongDrxCycleSpecial parameter assigned to a UE may be less than the configured value. In addition, the configured value will be rounded down to an integral multiple of 10. Therefore, you are advised to configure the LongDrxCycleSpecial parameter to a value that is an integral multiple of 10. If users hope that the value actually assigned to a UE is greater than or equal to 80 ms, set the TimeAlignmentTimer parameter to a value greater than or equal to 10240 ms. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the LongDrxCycleSpecial parameter be set to less than or equal to 320 ms. Otherwise, the uplink time alignment performance of UEs is affected. If the TimingAdvCmdOptSwitch parameter is set to ON, it is recommended that the TimeAlignmentTimer parameter be set to sf10240. A smaller value of the TimeAlignmentTimer parameter, such as sf5120, indicates a higher probability that UEs in DRX mode are out of synchronization in the uplink. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SF10(10 subframes), SF20(20 subframes), SF32(32 subframes), SF40(40 subframes), SF64(64 subframes), SF80(80 subframes), SF128(128 subframes), SF160(160 subframes), SF256(256 subframes), SF320(320 subframes), SF512(512 subframes), SF640(640 subframes), SF1024(1024 subframes), SF1280(1280 subframes), SF2048(2048 subframes), SF2560(2560 subframes)

Unit: subframe

Parameter Relationship:

-Others:

  • In the CellDrxSpecialPara MO, the value of OnDurationTimerSpecial must not be greater than the value of LongDrxCycleSpecial. For LTE TDD cells, the unit for the value of the OnDurationTimerSpecial parameter is PSF while that for the value of the LongDrxCycleSpecial parameter is SF. Before comparing the periods specified by these parameters and whether these parameters are effective, unify the value units. For details, see "Parameter Relationship" about OnDurationTimerSpecial.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the OnDurationTimerSpecial, DrxInactivityTimerSpecial, ShortDrxCycleSpecial, and DrxShortCycleTimerSpecial parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay and better KPIs such as the service drop rate and the handover success rate, and a larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

This parameter applies only to LTE FDD and LTE TDD.

  • If SA2 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*8 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 3; y = 5, temp = 4; y = 6, temp = 5; y = 8, temp = 6.

  • If SA4 is used, the value of LongDrxCycleSpecial or ShortDrxCycleSpecial equals to x*8 + temp (y) where: if y = 0, temp = 0; y = 2, temp = 2; y = 4, temp = 2; y = 5, temp = 3; y = 6, temp = 4; y = 8, temp = 6.

If the value of ShortDrxCycleSwitchSpecial is UU_ENABLE, the value of the ShortDrxCycleSpecial calculated based on the preceding formula must be greater than or equal to the value of OnDurationTimerSpecial.

ShortDrxCycleSpecial Short DRX Cycle for Special UE

Meaning: Indicates the length of the SPID-specific short DRX cycle. The short DRX cycle takes effect only on non-power-saving UEs configured with a specific SPID or UEs whose capability information indicates that they do not support power saving. According to 3GPP specifications, the length of a long DRX cycle must be an integer multiple of that of a short DRX cycle. In addition, the actual value of LongDrxCycleSpecial assigned to a UE may be less than the configured value because of the impact of the SRS bandwidth and TA period specified by the TimeAlignmentTimer parameter. Therefore, the actual value of ShortDrxCycleSpecial assigned to a UE may be less than the configured value. This parameter applies only to LTE FDD and LTE TDD.

DrxShortCycleTimerSpecial DRX Short Cycle Timer for Special UE

Meaning: Indicates the length of the SPID-specific DRX Short Cycle Timer. This timer takes effect only on non-power-saving UEs configured with a specific SPID or UEs whose capability information indicates that they do not support power saving. The length of this timer is expressed in the number of short DRX cycles. If this parameter is set to 1, the length of this timer is one short DRX cycle. If this parameter is set to 2, the length of this timer is two short DRX cycles. For details, see section 5.7 in 3GPP TS 36.321. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the DRX cycle of TM7, TM8, and TM9 w/o PMI UEs shortens, and the overall performance of such UEs improves, but the power-saving performance of such UEs deteriorates. Applicable Mode: L-TDD

Example

To modify DRX parameter as follows: Local cell ID: 0, Cell DRX Special Parameter Valid Flag: TRUE, Long DRX Cycle for Special UE: SF40, run the following command:
MOD CELLDRXSPECIALPARA: LocalCellId=0, LongDrxCycleSpecial=SF40;
