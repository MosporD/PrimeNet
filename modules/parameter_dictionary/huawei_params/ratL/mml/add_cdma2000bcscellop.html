Add Operator Configuration for Serving Cell in CDMA2000 Band Class (ADD CDMA2000BCSCELLOP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an operator-specific configuration for the CDMA2000 band class.

Note

  • Cell reselection priorities based on operators of the local cell (which are specified in the NrNFreqSCellOp, EutranNFreqSCellOp, UtranNFreqSCellOp, GeranNFGroupSCellOp, and Cdma2000BcSCellOp MOs) cannot coexist with cell reselection priorities based on operators of neighboring frequencies (which are specified in the EutranNFreqRanShare, UtranRanShare, and GeranRanShare MOs).

  • Cell reselection priorities specified in the UtranNFreqSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

  • Cell reselection priorities specified in the EutranNFreqSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

  • Cell reselection priorities specified in the GeranNFGroupSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

  • CnOperatorId in a Cdma2000BcSCellOp MO must have been set in the associated CnOperator MO.

  • Before running this command, ensure that the associated CDMA2000 band class has been configured.

  • Cell reselection priorities specified in the NrNFreqSCellOp and Cdma2000BcSCellOp MOs for the same operator cannot be the same.

Cdma1XrttCellReselPriInd CDMA2000 1xRTT dedicated priority configure indicator

Meaning: Indicates whether to configure a dedicated cell-reselection priority based on the PLMN ID of the local cell for the CDMA2000 1xRTT band class. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Cdma1XrttCellReselDediPri CDMA2000 1xRTT Cell Reselection Dedicated Priority

Meaning: Indicates the dedicated cell reselection priority for a CDMA2000 1xRTT band class based on the PLMN ID of the local cell. The value 0 indicates the lowest priority. If the related SPID configuration is specified, set this priority to the one specified in the SPID configuration. If no related SPID configuration is specified but this parameter is set, the eNodeB delivers the cell reselection priorities of all PLMNs supported by a UE by using the IE idleModeMobilityControlInfo in an RRC Connection Release message to the UE. If no related SPID configuration is specified and this parameter is not set, a UE uses the cell reselection priority of the CDMA2000 band class, which is broadcast in the system information. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: This parameter will be removed in later versions. In this version, the setting of this parameter is still synchronized between the MAE and the eNodeB and can be delivered to the eNodeB, but it is no longer used internally. Therefore, avoid using this parameter.

Example

To add an operator configuration for serving cell in CDMA Band Class with the parameters as follows: Local cell ID: 0, Band class: bc0, Cn operator ID: 3, CDMA2000 1xRTT dedicated priority configure indicator:NOT_CFG, CDMA2000 HRPD dedicated priority configure indicator:NOT_CFG, run the following command:
ADD CDMA2000BCSCELLOP: LocalCellId=0, BandClass=bc0, CnOperatorID=3, Cdma1XrttCellReselPriInd=NOT_CFG, HrpdCellReselDediPriCfgInd=NOT_CFG;
