Remove Neighboring CDMA2000 Frequency (RMV CDMA2000NFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more records of neighboring CDMA2000 frequencies.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is a risky command and you are advised to run this command during off-peak hours.

    If no parameter is specified, all records of neighboring CDMA2000 frequencies are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If some parameters are specified, records that match the parameter settings are removed after this command is executed, and a maximum of 640 records can be removed at a time.

    If all parameters are specified, the record that matches all the parameter settings is removed after the command is executed.

  • Before running this command, ensure that all neighboring relations with the cells on the frequency are removed.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandClass Band class

Meaning: Indicates the band class on which the neighboring CDMA2000 cell of the serving cell operates. Signals on a frequency within the band class can be obtained by UEs. For details, see the BandclassCDMA2000 IE defined in 3GPP 36.331 6.3.4. This parameter applies only to LTE FDD and LTE TDD.

Unit: None

MML Default Value: None

Frequency Frequency

Meaning: Indicates the frequency on which the neighboring CDMA2000 cell of the serving cell operates. For details, see the CDMA2000-CarrierInfo IE defined in section 6.3.4 in 3GPP 36.331. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~2047

Unit: None

MML Default Value: None

Example

To remove a neighboring CDMA2000 frequency with the parameter as follows: Local cell ID: 0, Band class: bc0, Frequency: 10, run the following command:
RMV CDMA2000NFREQ: LocalCellId=0, BandClass=bc0, Frequency=10;
