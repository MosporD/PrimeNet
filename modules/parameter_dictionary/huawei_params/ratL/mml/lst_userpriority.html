List User Priority (LST USERPRIORITY)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of policies applied to UEs running unlimited services in an eNodeB.

Note

None.

Parameters

None.

Example

List User Priority:
LST USERPRIORITY:;
The result is shown as follows:

Output Description

Field Description

ARP Schedule Switch

Indicates whether to enable ARP- and QCI-based user-differentiated scheduling. If the ArpPrioritySchSwitch option is selected, ARP- and QCI-based user-differentiated scheduling is enabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 do not take effect. If the ArpPrioritySchSwitch option is deselected, ARP- and QCI-based user-differentiated scheduling is disabled and the UlschPriorityFactor and DlschPriorityFactor parameters for QCIs 6 to 9 take effect. This option applies only to LTE FDD and LTE TDD.

ARP1 Priority
