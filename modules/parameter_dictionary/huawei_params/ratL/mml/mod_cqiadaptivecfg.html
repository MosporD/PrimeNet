Modify Adaptive CQI Configuration (MOD CQIADAPTIVECFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the parameters related to CQI adaptation.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Changing the PucchPeriodicCqiOptSwitch parameter value will result in automatic cell reset.

Parameters

ID Name Description
PucchPeriodicCqiOptSwitch PUCCH Periodic CQI Optimize Switch

Meaning: Indicates whether to enable the optimization on CQI reporting periods and RB resources for CQI reporting on the PUCCH. If this parameter is set to ON, the eNodeB configures fewer UEs with a short CQI reporting period, decreasing PUCCH resources to be used and increasing available PUSCH resources. If this parameter is set to OFF, the eNodeB configures more UEs with a short CQI reporting period, increasing PUCCH resources to be used and decreasing available PUSCH resources. This parameter applies only to LTE FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to ON, the eNodeB configures fewer UEs with a short CQI reporting period. This decreases PUCCH resources to be used and increases available PUSCH resources, and therefore leads to a higher uplink peak rate. In addition, the downlink performance decreases because the number of UEs using a long CQI reporting period increases and such UEs cannot promptly feed back the channel quality.

If this parameter is set to OFF, the eNodeB configures more UEs with a short CQI reporting period. This increases PUCCH resources to be used and decreases available PUSCH resources, and therefore leads to a lower uplink peak rate. In addition, the downlink performance improves because the number of UEs with a short CQI reporting period increases and such UEs can promptly feed back the channel quality.

Applicable Mode: L-FDD
SimulAckNackAndCqiFmt3Sw PUCCH Format 3 CQI Reporting Switch

Meaning: Indicates whether CQI and ACK/NACK can be simultaneously transmitted over the PUCCH of format 3. For details about PUCCH format 3, see 3GPP TS 36.213. When this parameter is set to OFF, simultaneous transmission is not allowed. When this parameter is set to ON, the IE simultaneousAckNackAndCQI-Format3-r11 takes the value "Setup", meaning that simultaneous transmission is allowed. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the CQI discard rate decreases but, upon insufficient PUCCH power, the format-3 PUCCH demodulation performance deteriorates. When this parameter is set to OFF, CQI cannot be transmitted together with ACK/NACK.

Applicable Mode: L-FDD, L-TDD

Example

To modify parameters related to adaptive CQI as follows: Pucch Periodic Cqi Opt Switch: OFF, run the following command:
MOD CQIADAPTIVECFG: PucchPeriodicCqiOptSwitch=OFF;
