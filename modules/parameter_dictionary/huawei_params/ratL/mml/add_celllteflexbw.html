Add CellLteFlexBw (ADD CELLLTEFLEXBW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the start and end PRB position information and flexible bandwidth switch for Flexible Bandwidth.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This execution of this command will result in automatic reset of the cell.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell ID. This parameter applies only to LTE FDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
LteFlexBwSwitch Flexible Bandwidth Optimization Switch

Meaning: Indicates whether to enable flexible bandwidth optimization.

LTE_FB_CFG_SWITCH: Indicates whether to enable the LTE flexible bandwidth algorithm. This option applies only to LTE FDD.

PDCCH_CAPACITY_OPT_SWITCH: Indicates whether to enable the PDCCH capacity improvement algorithm. This option applies only to LTE FDD.

UL_WEAK_GSM_ITF_PROCESS_SW: Indicates the uplink weak GSM interference processing switch. This option applies only to LTE FDD.

UL_STRONG_GSM_ITF_PROCESS_SW: Indicates the uplink strong GSM interference processing switch. This option applies only to LTE FDD.

The PDCCH_CAPACITY_OPT_SWITCH, UL_WEAK_GSM_ITF_PROCESS_SW, and UL_STRONG_GSM_ITF_PROCESS_SW options take effect only when the LTE_FB_CFG_SWITCH option is selected.

GUI Value Range: LTE_FB_CFG_SWITCH(LTE_FB_CFG_SWITCH), PDCCH_CAPACITY_OPT_SWITCH(PDCCH_CAPACITY_OPT_SWITCH), UL_WEAK_GSM_ITF_PROCESS_SW(UL_WEAK_GSM_ITF_PROCESS_SW), UL_STRONG_GSM_ITF_PROCESS_SW(UL_STRONG_GSM_ITF_PROCESS_SW)

Unit: None

Actual Value Range: LTE_FB_CFG_SWITCH, PDCCH_CAPACITY_OPT_SWITCH, UL_WEAK_GSM_ITF_PROCESS_SW, UL_STRONG_GSM_ITF_PROCESS_SW

MML Default Value: None

Recommended Value: LTE_FB_CFG_SWITCH:Off, PDCCH_CAPACITY_OPT_SWITCH:Off, UL_WEAK_GSM_ITF_PROCESS_SW:Off, UL_STRONG_GSM_ITF_PROCESS_SW:Off

Parameter Relationship:

-Configuration constraints:

  • The PDCCH_CAPACITY_OPT_SWITCH, UL_WEAK_GSM_ITF_PROCESS_SW or UL_STRONG_GSM_ITF_PROCESS_SW option of the LteFlexBwSwitch parameter in a CellLteFlexBw MO can be selected only if the LTE_FB_CFG_SWITCH option of the LteFlexBwSwitch parameter in the same MO is selected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: LTE_FB_CFG_SWITCH: When this option is selected, spectral efficiency improves, and the number of available RBs increases, comparing with that when standardized bandwidth is used. The system capacity improves. However, UEs using RBs in the flexible bandwidth are more prone to inter-RAT interference than UEs using RBs in the standard bandwidth. When the RBs at the start and end positions are used under flexible bandwidth, the uplink and downlink throughput decreases, comparing with that when the same number of RBs is used under standardized bandwidth.

PDCCH_CAPACITY_OPT_SWITCH: When this option is selected, the PDCCH does not have power output in frequencies with strong GSM interference. The PDCCH capacity decreases but interference to the GERAN decreases when compared with that when the option is deselected. When this option is deselected, the PDCCH has power output over the full bandwidth. The PDCCH capacity increases but interference to the GERAN increases when compared with that when the option is selected.

UL_WEAK_GSM_ITF_PROCESS_SW: When this option is selected, uplink interference is regarded as GSM weak interference. In this case, the interference is processed according to the GSM weak interference algorithm.

UL_STRONG_GSM_ITF_PROCESS_SW: When this option is selected, uplink interference is regarded as GSM strong interference. In this case, the interference is processed according to the GSM strong interference algorithm.

Applicable Mode: L-FDD
DlCustStartPrbIndex Downlink Customized Starting PRB Index

Meaning: Indicates the downlink customized start PRB number. The parameter value of 255 indicates an invalid value. This parameter applies only to LTE FDD.

GUI Value Range: 0~99,255

Unit: None

Actual Value Range: 0~99,255

MML Default Value: 255

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If the DlCustStartPrbIndex parameter in a CellLteFlexBw MO is set to 255, the DlCustEndPrbIndex parameter in the same MO must be set to 255.
  • If the DlCustStartPrbIndex parameter in a CellLteFlexBw MO is not set to 255, the DlCustEndPrbIndex parameter in the same MO must not be set to 255, and the DlCustStartPrbIndex and DlCustEndPrbIndex parameter values must be different.

Service Interrupted After Modification: Yes

Example

To add the configuration of LTE Flexible Bandwidth with the parameters as follows:
LocalCellId: 0, LteFlexBwSwitch. LTE_FB_CFG_SWITCH: On, DlCustStartPrbIndex: 255, DlCustEndPrbIndex: 255, UlCustStartPrbIndex: 255, UlCustEndPrbIndex: 255, run the following command:
+++    0        2016-11-05 19:48:01
O&amp;M    #807403522
%%ADD CELLLTEFLEXBW: LocalCellId=0, LteFlexBwSwitch=LTE_FB_CFG_SWITCH-1, DlCustStartPrbIndex=255, DlCustEndPrbIndex=255, UlCustStartPrbIndex=255, UlCustEndPrbIndex=255;%%
RETCODE = 0  Operation succeeded.
