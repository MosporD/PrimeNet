Add TM9 Dedicated Carrier Config (ADD TM9DEDICATEDCARRIER)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add the configuration of a TM9-dedicated carrier.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the CrsTransmissionStrategy parameter is set to CENTRAL_RB_ON, adding the MO will cause the cell to reset.

  • Configurations related to dedicated carrier for TM9 do not take effect when the LMPT is used as the main control board.

  • If the main control board is not an LMPT, a maximum of 16 downlink EARFCNs of TM9-dedicated carriers can be configured.

Parameters

ID Name Description
Tm9CcDlEarfcn TM9 CC Downlink EARFCN

Meaning: Indicates the downlink EARFCN of a TM9-dedicated carrier. This parameter applies only to LTE FDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When there is a low TM9 penetration rate, the setting of TM9-dedicated carriers may result in a decrease in UE throughput due to UE capabilities of CA combinations. However, on these carriers, TM9 delivers performance that is not worse than TM4 performance.

Applicable Mode: L-FDD
CrsTransmissionStrategy CRS Transmission Strategy

Meaning: Indicates whether to transmit PDSCH CRSs across the entire channel bandwidth or using only central RBs on the TM9-dedicated carrier. If this parameter is set to ALL_RB_ON, the CRSs are transmitted across the entire channel bandwidth. If this parameter is set to CENTRAL_RB_ON, the CRSs are transmitted using only the six RBs in the center of the channel bandwidth. This parameter applies only to LTE FDD.

GUI Value Range: ALL_RB_ON(ALL_RB_ON), CENTRAL_RB_ON(CENTRAL_RB_ON)

Unit: None

Actual Value Range: ALL_RB_ON, CENTRAL_RB_ON

MML Default Value: ALL_RB_ON(ALL_RB_ON)

Recommended Value: ALL_RB_ON(ALL_RB_ON)

Parameter Relationship:

-Configuration constraints:

  • If the CrsTransmissionStrategy parameter in a Tm9DedicatedCarrier MO is set to CENTRAL_RB_ON, the WorkMode parameter in the Tm9DedicatedCarrier MO must be set to TM9_DEDICATED_SCC.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Setting this parameter to ALL_RB_ON helps prevent inaccurate RSRP measurements caused by UE incompatibility but causes a decrease in throughput gains. Setting this parameter to CENTRAL_RB_ON helps increase throughput gains but may cause inaccurate RSRP measurements due to UE incompatibility. The inaccurate RSRP measurements affect the handover success rate and service drop rate.

Applicable Mode: L-FDD
WorkMode Work Mode

Meaning: Indicates the working mode of the TM9-dedicated carrier. When this parameter is set to TM9_DEDICATED_SCC, the TM9-dedicated carrier can be configured only as an SCC. When this parameter is set to TM9_DEDICATED_CC, the TM9-dedicated carrier can be configured as a PCC or an SCC. When this parameter is set to R10PLUS_DEDICATED_CC, the TM9-dedicated carrier can only be used by UEs complying with 3GPP Release 10 or later. If this parameter is set to NON_TM9_SCC, the TM9-dedicated carrier can be configured as an SCC for TM9-incapable UEs and as a PCC or SCC for TM9-capable UEs. This parameter applies only to LTE FDD.

GUI Value Range: TM9_DEDICATED_SCC(TM9_DEDICATED_SCC), TM9_DEDICATED_CC(TM9_DEDICATED_CC), R10PLUS_DEDICATED_CC(R10PLUS_DEDICATED_CC), NON_TM9_SCC(NON_TM9_SCC)

Unit: None

Actual Value Range: TM9_DEDICATED_SCC, TM9_DEDICATED_CC, R10PLUS_DEDICATED_CC, NON_TM9_SCC

MML Default Value: TM9_DEDICATED_SCC(TM9_DEDICATED_SCC)

Recommended Value: TM9_DEDICATED_SCC(TM9_DEDICATED_SCC)

Parameter Relationship:

-Configuration constraints:

  • If the CrsTransmissionStrategy parameter in a Tm9DedicatedCarrier MO is set to CENTRAL_RB_ON, the WorkMode parameter in the Tm9DedicatedCarrier MO must be set to TM9_DEDICATED_SCC.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to TM9_DEDICATED_SCC, the TM9-dedicated carrier can be configured with one CRS port, reducing the CRS overhead and interference and yielding large throughput gains. When this parameter is set to TM9_DEDICATED_CC, the TM9-dedicated carrier can be configured as a PCC or SCC for TM9 UEs. In this case, the configuration of two CRS ports is recommended. This yields smaller UE throughput gains than the dedicated TM9 carrier configured as an SCC, but assures the handover success rate and the service drop rate. Setting this parameter to R10PLUS_DEDICATED_CC has no impact on network performance. When this parameter is set to NON_TM9_SCC, the proportion of traffic volume absorbed by the TM9-dedicated carrier increases. Therefore, the value NON_TM9_SCC is favourable to scenarios with a low penetration rate of TM9-capable UEs.

Applicable Mode: L-FDD

Example

To add the interference configuration of Tm9DedicatedCarrier with the parameters as follows: TM9 CC Downlink EARFCN: 1800, run the following command:
+++    0        2017-11-23 09:41:11
O&M    #806354967
%%ADD TM9DEDICATEDCARRIER: Tm9CcDlEarfcn=1800;%%
RETCODE = 0  Operation succeeded.
