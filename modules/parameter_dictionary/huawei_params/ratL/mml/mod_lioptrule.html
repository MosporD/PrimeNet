Modify Intelligent Optimization Rule Parameter (MOD LIOPTRULE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify settings of parameters related to intelligent optimization rules.

Note

None.

PenaltyTime Penalty Time

Meaning: Indicates the penalty duration of intelligent optimization rules under an intelligent optimization function. If related conditions for an intelligent optimization rule under an intelligent optimization function are met and related adjustment measures are taken, the penalty duration starts. During the penalty duration, parameter adjustment cannot be triggered even if conditions for an intelligent optimization rule under this intelligent optimization function are met. If this parameter is set to 0, no penalty is imposed on intelligent optimization rules under an intelligent optimization function. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: In an eNodeB, the value of this parameter is set for each pre-defined intelligent optimization rule. If this parameter is set to BOTH(BOTH) for an intelligent optimization rule and the rule needs to be applied only to LTE FDD or LTE TDD, the parameter value can be changed to FDD(FDD) or TDD(TDD). If this parameter is set to FDD(FDD) or TDD(TDD) for an intelligent optimization rule, the intelligent optimization rule may not take effect or negative impacts may occur after this parameter value is changed, and therefore do not change the parameter value in this case.

Applicable Mode: L-FDD, L-TDD

Example

To modify information about LIOPTRULE as follows:RuleID is 3, Period is 200, PenaltyTime is 100, AdaptiveRAT is FDD.
MOD LIOPTRULE: RuleID=3, Period=200, PenaltyTime=100, AdaptiveRAT=FDD;
