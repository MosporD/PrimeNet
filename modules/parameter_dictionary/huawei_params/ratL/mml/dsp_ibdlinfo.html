Display Internal Baseband Data Link Information (DSP IBDLINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query information about the BBP data link.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local cell identity of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query the internal baseband data link information:
DSP IBDLINFO:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local cell identity of the cell. It uniquely identifies a cell within an eNodeB.

Connect eNodeB ID

Indicates the ID of the eNodeB to which the RRU/RFU is connected.

RRU/RFU Cabinet No.

Indicates the cabinet number of the RRU/RFU.

RRU/RFU Subrack No.

Indicates the subrack number of the RRU/RFU.

RRU/RFU Slot No.

Indicates the slot number of the RRU/RFU.

Number of BBP Data Links

Indicates the number of BBP data links.

BBP Data Link ID

Indicates the BBP data link ID.

BBP Data Link Status

Indicates the status of the BBP data link.

ODI ID

Indicates the open DU interface (ODI) ID.

BBP Data Link Input Port No.

Indicates the input port number of the BBP data link.

BBP Data Link Output Port No.

Indicates the output port number of the BBP data link.

BBP Data Link Loopback Delay(microsecond)

Indicates the loopback delay on the BBP data link.

BBP Data Link Loopback Timeout Counter

Indicates the number of loopback timeouts on the BBP data link.

Board Cabinet No.

Indicates the cabinet number of the board involved in data link transmission.

Board Subrack No.

Indicates the subrack number of the board involved in data link transmission.

Board Slot No.

Indicates the slot number of the board involved in data link transmission.
