Modify Configurations of Coverage-Level-Specific Uplink Scheduling for PRBs (MOD PRBULSCHCEALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify coverage-level-specific parameters related to the uplink scheduling algorithm for PRB carriers of an NB-IoT cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

For a cell, modifications on the EdtMaxTbs parameter of an active cell would result in the automatic reset of the cell or prb.

NbLogicChSrProhibitTimer NB-IoT Logical Channel SR Prohibit Timer

Meaning: Indicates the logical channel prohibition timer for a UE. This timer starts when the corresponding UE initiates service requests, prohibiting the UE from initiating service requests until it expires. The eNodeB configures this timer for a UE through an RRCConnectionSetup message. For details, see 3GPP TS 36.331. This parameter applies only to NB-IoT.

GUI Value Range: NOT_CFG(NOT_CFG), PP2(PP2), PP8(PP8), PP32(PP32), PP128(PP128), PP512(PP512), PP1024(PP1024), PP2048(PP2048)

Unit: None

Actual Value Range: NOT_CFG, PP2, PP8, PP32, PP128, PP512, PP1024, PP2048

MML Default Value: None

Recommended Value: NOT_CFG(NOT_CFG)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_CFG, the uplink pre-allocation success rate decreases, and the UE transmission delay increases. If this parameter is set to PP2, uplink pre-allocation is more effective, and the number of random access requests initiated by a UE using the SR process decreases. This lowers the UE transmission delay but increases the UE access delay. If this parameter is set to PP8 or larger, effectiveness of uplink pre-allocation is further improved, but the UE access delay further increases.

Applicable Mode: L-NB-IOT

Meaning: Indicates the length of the extended inactivity timer used in uplink semi-persistent scheduling. For example, if this parameter is set to 1, the actual length of the extended inactivity timer for uplink semi-persistent scheduling is 1 multiplied by the value of the UlSpsInterval parameter in the PrbUlSchCeAlgo MO. This parameter applies only to NB-IoT.

UlSpsInactivityTimer Uplink SPS Inactivity Timer

Meaning: Indicates the length of the inactivity timer used for uplink semi-persistent scheduling. The eNodeB starts this timer after uplink semi-persistent scheduling is activated for a UE. When the timer expires, uplink semi-persistent scheduling is deactivated. If this parameter is set to 0, the timer length is infinite. If this parameter is set to 255, uplink semi-persistent scheduling does not take effect. The effective value range of this parameter is 2 to 160. For example, if this parameter is set to 2, the actual timer length is the result of 2 multiplied by the value of the UlSpsInterval parameter in the PrbUlSchCeAlgo MO. This parameter applies only to NB-IoT.
