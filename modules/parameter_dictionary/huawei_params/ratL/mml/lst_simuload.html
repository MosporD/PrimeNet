List configuration of eNodeB simulated load configuration (LST SIMULOAD)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the simulated load configuration.

Note

None.

Parameters

ID Name Description
SimuLoadCfgIndex configuration index

Meaning: Indicates the index of a simulated load configuration. One BS can store 10 simulated load configurations, which are identified by the indexes.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of PMI templates used in interference simulation, run the following command: :
LST SIMULOAD:;
The result is shown as follows:

Output Description

Field Description

configuration index

Indicates the index of a simulated load configuration. One BS can store 10 simulated load configurations, which are identified by the indexes.

RB usage threshold(%)

Indicates the RB usage threshold of a simulated load configuration. If the RB usage of a cell is below this threshold, the simulated load scheduling is performed.

Power usage threshold(%)

Indicates the power usage threshold of a simulated load configuration. If the power usage of a cell is below this threshold, the simulated load scheduling is performed. This parameter applies only to LTE FDD and LTE TDD.

Report period(ms)

Indicates the reporting period for simulated load. The value 0 indicates that simulated load is not reported. This parameter applies only to LTE FDD and LTE TDD.

Statistic period(ms)

Indicates the measurement period for simulated load. The value 0 indicates that simulated load is not measured. This parameter applies only to LTE FDD and LTE TDD.

Frequency selective switch

Indicates the switch that is used to determine whether to enable and disable the frequency-selective scheduling in simulated load configuration. If the switch is set to ON, the frequency-selective scheduling is enabled. If the switch is set to OFF, the frequency-diversity scheduling is used. This parameter applies only to LTE FDD and LTE TDD.
