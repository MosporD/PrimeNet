Modify Cell TTI Bundling Algorithm Configuration (MOD CELLTTIBUNDLINGALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the settings of parameters related to the TTI bundling algorithm of a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SinrThdToTrigTtib SINR Threshold To Trigger TTI Bundling

Meaning: Indicates the configuration policy and value of the SINR threshold when TTI bundling is enabled for a UE. If this parameter is set to 255, the SINR threshold configuration policy is "dynamic calculation", indicating that the SINR threshold is dynamically calculated based on the voice packet size and channel quality. If this parameter is set to a value other than 255, the SINR threshold configuration policy is "manual configuration", indicating that the SINR threshold is manually configured on the GUI. This parameter applies only to LTE FDD.

GUI Value Range: -5~10,255

Unit: None

Actual Value Range: -5~10,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the parameter value is from -5 to 10:

A smaller value results in a lower probability of triggering TTI bundling and worse channel quality of the UE upon entry into TTI bundling, increasing the risk of voice quality deterioration, consuming more CCEs, and decreasing the MOS.

A larger value results in a higher probability of triggering TTI bundling and better channel quality of the UE upon entry into TTI bundling, but higher RB usage and lower throughput.

Applicable Mode: L-FDD
SinrThdToTrigVideoTtib SINR Threshold To Trigger Video TTI Bundling

Meaning: Indicates the SINR threshold for triggering TTI Bundling for video services of UEs. This parameter applies only to LTE FDD.

GUI Value Range: -5~10

Unit: None

Actual Value Range: -5~10

MML Default Value: None

Recommended Value: -3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering TTI bundling for video services, poorer channel quality at the time when video service UEs enter the TTI bundling, and a higher risk of cell-edge video user experience deterioration. It causes more CCE consumption and lower cell-edge UE throughput.

A larger value of this parameter results in a higher probability of triggering TTI bundling for video services and better channel quality at the time when video service UEs enter the TTI bundling. It causes more RB consumption and lower throughput.

Applicable Mode: L-FDD
TtiBundlingAlgoSw TTI Bundling Algorithm Switch

Meaning: Indicates whether to enable TTI bundling optimization.

TTIB_EXIT_BASED_ON_QCI_SW: Indicates whether to enable exit from TTI bundling for specific QCIs. If this option is selected, UEs exit TTI bundling after beneficiary bearers (applicable to VoLTE, PTT, and video services) are removed. If this option is deselected, the exit is not supported. This option applies only to LTE FDD.

TTIBUNDLING_ALGO_ENHANCE_SW: Indicates whether to enable TTI bundling during handovers or RRC connection reestablishments and use high-index MCSs for TTI bundling. TTI bundling is enabled during handovers and RRC connection reestablishments (applicable to VoLTE and PTT) and high-index MCSs are used for TTI bundling (applicable to VoLTE, PTT, and video services) only when this option is selected. This option applies only to LTE FDD.

GUI Value Range: TTIB_EXIT_BASED_ON_QCI_SW(TTIB_EXIT_BASED_ON_QCI_SW), TTIBUNDLING_ALGO_ENHANCE_SW(TTIBUNDLING_ALGO_ENHANCE_SW)

Unit: None

Actual Value Range: TTIB_EXIT_BASED_ON_QCI_SW, TTIBUNDLING_ALGO_ENHANCE_SW

MML Default Value: None

Recommended Value: TTIB_EXIT_BASED_ON_QCI_SW: Off, TTIBUNDLING_ALGO_ENHANCE_SW: Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: TTIB_EXIT_BASED_ON_QCI_SW: If this option is selected and a UE exits TTI bundling at removal of bearers that benefit from TTI bundling in a weak coverage area, there is a risk of deterioration in the RRC connection reestablishment success rate and the service drop rate. If this option is deselected and a UE initiates an uplink data service after the bearer removal, the uplink service throughput of this UE, which is in the TTI bundling state, is limited.

TTIBUNDLING_ALGO_ENHANCE_SW: If this option is selected, TTI bundling is enabled in handover and reestablishment scenarios. TTI bundling uses a high-order MCS, which allows more UEs to enter TTI bundling, increases the uplink average MCS index, decreases the number of scheduling times, and saves PDCCH CCE resources. If this option is deselected, there is no impact on radio network performance.

Applicable Mode: L-FDD
R12TtiBHarqMaxTxNum R12 TTI Bundling HARQ Max Trans Num

Meaning: Indicates the maximum number of uplink HARQ transmissions in TTI bundling mode from a UE capable of R12 TTI bundling. For details, see 3GPP TS 36.331. This parameter applies only to FDD.

GUI Value Range: n4(4), n8(8), n12(12), n16(16), n20(20), n24(24), n28(28)

Unit: None

Actual Value Range: n4, n8, n12, n16, n20, n24, n28

MML Default Value: None

Recommended Value: n20(20)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller amount of radio resources consumed by HARQ retransmissions but lower reliability of radio links.

A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD
R12TtiBundlingSwitch R12 TTI Bundling Switch

Meaning: Indicates whether to enable R12 TTI bundling.

If this parameter is set to ON, R12 TTI bundling works for UEs that support this function. If this parameter is set to OFF, R12 TTI bundling cannot take effect on these UEs. This parameter applies only to FDD.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
SinrThdToTrigR12TtiB SINR Threshold To Trigger R12 TTI Bundling

Meaning: Indicates the SINR threshold used to trigger TTI bundling for UEs capable of R12 TTI bundling. This parameter applies only to FDD.

GUI Value Range: -10~20

Unit: dB

Actual Value Range: -10~20

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering TTI bundling, poorer channel quality at the time when UEs enter TTI bundling, a higher risk of voice quality deterioration or cell-edge video user experience deterioration, higher CCE consumption, and lower voice MOSs or lower cell-edge video throughput.

A larger value of this parameter results in a higher probability of triggering TTI bundling, better channel quality at the time when UEs enter TTI bundling, higher RB consumption, and lower throughput.

Applicable Mode: L-FDD

Example

To modify the configuration of CellTtiBundlingAlgo with the parameters as follows: LocalCellId=0, SinrThdToTrigTtib=1, run the following command:
MOD CELLTTIBUNDLINGALGO: LocalCellId=0, SinrThdToTrigTtib=1;
