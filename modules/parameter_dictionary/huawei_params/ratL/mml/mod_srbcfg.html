Modify SrbCfg (MOD SRBCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the SRB configurations.

Note

None.

Parameters

ID Name Description
SrbRlcParaAdaptSwitch SRB RLC Parameter Adaptive Switch

Meaning: Indicates whether to enable adaptive configuration of parameters related to Radio Link Control (RLC) on SRBs. If this parameter is set to ON, the eNodeB adaptively adjusts the SRB polling PDU retransmission timer for the eNodeB based on the timer expiration information and the number of scheduled UEs in the uplink. This aims to match the timer length and the interval at which UEs send the status report and reduces the number of invalid retransmissions due to the timer expiration. If the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected, for a small-bandwidth cell (cell with a bandwidth of 5 MHz, 3 MHz, or 1.4 MHz), the eNodeB proceeds as the SrbRlcParaAdaptSwitch parameter is set to ON regardless of the SrbRlcParaAdaptSwitch parameter setting. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the SRB polling PDU retransmission timer for the eNodeB can be adaptively adjusted, decreasing the number of retransmissions and saving the air interface resources.

If this parameter is set to OFF, the timer cannot be adaptively adjusted. In this case, when the number of UEs is growing, the UE scheduling interval in the uplink increases, causing excessive invalid downlink RLC retransmissions. When the number of RLC retransmissions reaches its maximum value, the probability of RRC connection reestablishment increases.

Applicable Mode: L-FDD, L-TDD
SrbPollTimerAdjustStep SRB Polling Timer Adjust Step

Meaning: Indicates the adjustment step of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~49

Unit: None

Actual Value Range: 1~49

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller adjustment step and less frequent adaptation of uplink scheduling interval.

A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
SrbPollTimerPreset Preset eNodeB SRB Poll Retransmit Timer

Meaning: Indicates the initial value of the SRB polling PDU retransmission timer for the eNodeB when the SrbRlcParaAdaptSwitch parameter is set to ON or the SMALL_BAND_RLC_OPT_SWITCH option of the SmallBandOptSwitch parameter is selected. If the SrbPollTimerPreset parameter value is greater than the SrbPollTimerMaxAdjustValue parameter value, the SrbPollTimerMaxAdjustValue parameter value is taken as the initial value. It is recommended that the SrbPollTimerPreset parameter value be greater than or equal to the ENodeBPollRetransmitTimer parameter value. This parameter applies only to LTE FDD and LTE TDD.

SrbPollTimerAdjUserNumThd SRB Polling Timer Adjust User Threshold

Meaning: Indicates the UE number threshold for triggering the SRB RLC parameter adaptation. If the SrbRlcParaAdaptSwitch parameter is set to ON(On) and the number of UEs in a cell is greater than the SrbPollTimerAdjUserNumThd parameter value, the adaptive adjustment of the SRB polling PDU retransmission timer for the eNodeB is triggered. If the SMALL_BAND_RLC_OPT_SWITCH(SMALL_BAND_RLC_OPT_SWITCH) option of the SmallBandOptSwitch parameter is selected, this parameter does not take effect and the UE number threshold specified by the system is used. The threshold value is 75 for a 5 MHz bandwidth, 45 for a 3 MHz bandwidth, and 20 for a 1.4 MHz bandwidth. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5000

Unit: None

Actual Value Range: 0~5000

MML Default Value: None

Recommended Value: 150

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering the adaptive adjustment of the SRB polling PDU retransmission timer for the eNodeB when the number of UEs in the cell is growing. In this case, the timer length applied to UEs may be shorter than the actual UE scheduling interval, and the decrease in the number of SRB RLC retransmissions becomes slower.

If this parameter is set to a too small value, there is a high probability of triggering the adaptive adjustment of the SRB polling PDU retransmission timer for the eNodeB when the number of UEs in the cell is growing. In this case, when UE packets are lost due to poor channel quality, RLC retransmissions are not promptly performed in the downlink.

Applicable Mode: L-FDD, L-TDD
RrcConnRelMaxRetxThd RRCConnRel Maximum Retransmit Times

Meaning: Indicates the maximum number of RRC Connection Release message retransmissions. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: 32

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that a UE will successfully receive the RRC Connection Release message and a smaller number of RRC connection reestablishment attempts. However, the RBLER and number of retransmission packets increase for RRC Connection Release messages. A smaller value of this parameter results in a higher probability that the UE cannot receive the RRC Connection Release message and a larger number of RRC connection reestablishment attempts.

Applicable Mode: L-FDD, L-TDD

This parameter applies only to LTE FDD and LTE TDD.

HOCmdRRCRlsMsgRetxAdpSw HO Command RRC Release Msg Retran Adp Sw

Meaning: Indicates whether to optimize invalid retransmission of handover signaling and RRC release messages. The eNodeB optimizes invalid retransmission of handover signaling and RRC release messages only if this parameter is set to ON(On).

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON(On), the source eNodeB extends the SRB Polling PDU retransmission timer at the RLC layer after receiving the ACK to unfragmented handover signaling and RRC Connection Release messages at the MAC layer. As a result, invalid retransmission of handover signaling and RRC Connection Release messages decreases, thereby saving CCE resources and scheduled RB resources and increasing downlink user-perceived data rates. If this parameter is set to OFF(Off), the network performance is not affected.

Applicable Mode: L
