Modify CA Group (MOD CAGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a CA group.

Note

None.

Parameters

ID Name Description
CaGroupId CA Group Identity

Meaning: Indicates the identity of the CA group. It uniquely identifies a CA group within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CaGroupTypeInd CA Group Type Indication

Meaning: Indicates the type of the CA group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: FDD(FDD), TDD(TDD), FDDTDD(FDDTDD)

Unit: None

Actual Value Range: FDD, TDD, FDDTDD

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOperatorList Operator List

Meaning: Indicates the operators of which CA is allowed in cells of the group specified by the CaGroup.CaGroupId parameter. The characters in sequence in the parameter value correspond to the operator indexes of the local eNodeB. A character can be either 0 or 1. If a character is 1, CA is allowed for UEs served by the corresponding operator in the cells. If the character is 0, CA is not allowed for UEs served by the corresponding operator in the cells. The eNodeB filters the CA cell groups based on the operator which a CA UE accesses. If the corresponding operator index is invalid, the eNodeB ignores it. For example, 100100 indicates that the CA cell group belongs to the operators whose operator indexes are 0 and 3. This parameter does not take effect on the LMPT, and if the LMPT is used, the CA cell group can be used by all operators. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 6 characters

Unit: None

Actual Value Range: 6~6

MML Default Value: None

Recommended Value: 111111

Parameter Relationship:

-Configuration constraints:

  • Characters in the CnOperatorList parameter value in a CaGroup can be 0 or 1.
  • The value of the CnOperatorList parameter in a CaGroup MO cannot be 000000.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To modify the parameters of the CA group information as follows: CA Group Identity: 1, Ca Group Type Index: FDD, run the following command:
MOD CAGROUP: CaGroupId=1, CaGroupTypeInd=FDD;
