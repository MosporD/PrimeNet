List CSPC Algorithm Parameter (LST CSPCALGOPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list parameters related to the CSPC algorithm. This command takes effect only on the centralized control node.

Note

None.

Parameters

None.

Example

To list the configurations of the CSPC algorithm, run the following command: :
LST CSPCALGOPARA:;
The result is shown as follows:

Output Description

Field Description

CSPC Algorithm Switch

Indicates whether to enable CSPC in cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE FDD.

CSPC RSRP Measurement Mode

Indicates the measurement mode of the reference signal received power (RSRP) used in CSPC. The uplink RSRP is measured based on the uplink sounding reference signal (SRS) measurement. This parameter applies only to LTE FDD.

CSPC Cluster Mode

Indicates the mode of grouping cells into clusters for CSPC. If this parameter is set to STATIC_CONFIG, cells must be manually grouped into clusters for CSPC based on site scenarios. If this parameter is set to DYNAMIC_PARTITION_CONFIG, the centralized control node periodically groups cells into clusters for CSPC based on site scenarios. The DYNAMIC_PARTITION_CONFIG value does not take effect currently. This parameter applies only to LTE FDD and LTE TDD.

CSPC Cluster Partition Period(s)

Indicates the interval at which cells are grouped into clusters for CSPC. The interval can be configured based on site scenarios. This parameter currently does not take effect because dynamic clustering is not supported. This parameter applies only to LTE FDD.

CSPC Power Config Delay(ms)

Indicates the interval between the time that an eNodeB reports measurement information to the centralized control node and the time that the power configuration delivered by the centralized control node takes effect on the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

CSPC Schedule UE Specification

Indicates the maximum number of UEs that can be selected for CSPC. This parameter applies only to LTE FDD and LTE TDD.

CSPC Enable Downlink PRB Ratio Threshold(%)

Indicates the physical resource block (PRB) usage threshold for enabling coordinated scheduling-based power control (CSPC). CSPC is enabled when the highest PRB usage among all cells in a CSPC cluster is greater than this parameter value. To prevent CSPC from being enabled and disabled frequently in the cluster, the PRB usage threshold for disabling CSPC is lower than this parameter value. This parameter applies only to LTE FDD.

TDD Cspc Algorithm Switch

Indicates whether to enable CSPC for cells under the centralized control node in Cloud BB scenarios. This parameter applies only to LTE TDD.

CSPC Capacity Factor(%)

Indicates the acceptable capacity loss proportion in a network with CSPC enabled. This parameter affects the gain for cell edge UEs. Set this parameter in heavily-loaded networks to adjust cell downlink throughput and the downlink throughput gain of cell edge UEs. If this parameter is set to 100, network capacity loss is not considered, and the downlink throughput gain of cell edge UEs reaches the maximum. If this parameter is set to 0, it is preferential to guarantee that capacity loss does not occur in heavily-loaded networks. However, the downlink throughput gain of cell edge UEs decreases. This parameter applies only to LTE FDD.
