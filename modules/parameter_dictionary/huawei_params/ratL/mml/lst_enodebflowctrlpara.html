List eNodeB Flow Control Parameter (LST ENODEBFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the eNodeB Flow Control Parameter.

Note

None.

Parameters

None.

Example

To list the configurations of eNodeB flow control parameters, run the following command: :
LST ENODEBFLOWCTRLPARA:;
The result is shown as follows:

Output Description

Field Description

Adaptive Unsynchronized Timer Length(s)

Indicates whether an adaptive asynchronization UE is selected when the adaptive asynchronization function is enabled. If a UE does not transmit or receive data for a period of time that is longer than the AdaptUnsyncTimerLen parameter value, the UE is a candidate adaptive asynchronization UE. When this parameter value is larger than or equal to the QCIPARA.UeInactiveTimerForQci parameter value, the adaptive asynchronization function does not take effect. This parameter applies only to LTE FDD and LTE TDD.

Adaptive Unsynchronized User Num Threshold(%)

Indicates the threshold of the ratio of uplink-synchronized UEs in a cell or a baseband processing unit. If the ratio of uplink-synchronized UEs in a cell or a baseband processing unit exceeds this threshold, the eNodeB adaptively enables some UEs that do not transmit or receive data for a period of time greater than the AdaptUnsyncTimerLen parameter value to enter the asynchronization state. As a result, PUCCH resources can be released and used by other UEs. This parameter applies only to LTE FDD and LTE TDD.

Dynamic AC Barring Policy Mode

Indicates the policy of determining cell congestion for intelligent AC control, dynamic service specific access control (SSAC), and extended access barring (EAB).

When this parameter is set to FLOWCONTROL, an eNodeB determines the congestion state of a cell based on the flow control status.

When this parameter is set to CPULOAD, an eNodeB determines the congestion state of a cell based on the CPU load threshold. When the CPU load of the main control board or baseband processing unit (BBP) serving a cell is greater than or equal to the CPU load threshold, the eNodeB determines that the cell is in a congestion state. The CPU load threshold is specified by the CpuLoadThd parameter.

CPU Load Threshold(%)

Indicates the CPU load threshold of a board. If the CPU load of a main control board or baseband processing unit serving the cells is greater than or equal to this parameter value, the cells are congested. If the CPU load is less than this parameter value, the cells are not congested. This parameter takes effect only when the DynAcBarPolicyMode parameter is set to CPULOAD(CPULOAD).

MCPTT Message Count Switch

Indicates the configuration level switch of the number of access messages for MCPTT services. If this parameter is set to OFF, service access is not affected by the number of access messages. If this parameter is set to HIGH, MEDIUM, or LOW, the service access number differs depending on the configuration level. The values of HIGH, MEDIUM, and LOW indicate the high, medium, and low allowed service access numbers, respectively. This parameter applies only to LTE FDD.

Dynamic AC Barring Trigger All Cell Switch

Indicates whether dynamic access class (AC) control is triggered and takes effect on all cells on a board. If this parameter is set to ON, dynamic AC control is triggered and takes effect on all cells based on the board flow control status. If this parameter is set to OFF, dynamic AC control is triggered and takes effect on heavy-load cells based on flow control. This parameter applies only to LTE FDD and LTE TDD.

NSA Flow Control Strategy

Indicates the NSA flow control policy. If this parameter is set to USER_CAPACITY_PREFERRED, the policy is UE capacity preferred. In this case, when the CPU usage is high, the eNodeB performs flow control over SCG addition for NSA UEs, to preferentially ensure that more UEs can access the network. If this parameter is set to NSA_SCG_PREFERRED, the policy is SCG addition for NSA UEs preferred. In this case, when the CPU usage is high, the eNodeB still allows SCG addition for NSA UEs. This parameter applies only to LTE FDD and LTE TDD.
