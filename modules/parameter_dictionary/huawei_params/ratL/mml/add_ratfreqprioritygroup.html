Add RAT/Freq Priority Group (ADD RATFREQPRIORITYGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a RAT/frequency priority group configuration.

Note

None.

Parameters

ID Name Description
RatFreqPriorityGroupId RAT frequency priority group ID

Meaning: Indicates the ID of the RAT/frequency priority group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
RatType RAT Type

Meaning: Indicates the Radio Access Technology (RAT). This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EUTRAN, UTRAN, GERAN, CDMA20001XRTT, CDMA2000HRPD, NR(NR)

Unit: None

Actual Value Range: EUTRAN, UTRAN, GERAN, CDMA20001XRTT, CDMA2000HRPD, NR

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlEarfcn DL Earfcn or Bandclass

Meaning: Indicates the downlink frequency. In CDMA2000, this parameter indicates the bandclass. Before configuring a priority for a frequency specified by this parameter, ensure that an external or local cell operating on this frequency has been configured. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~3279165

Unit: None

Actual Value Range: 0~3279165

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Priority Priority

Meaning: Indicates the priority of the intra-RAT frequency band or frequency. The value 0 indicates the lowest priority. The value of this parameter must be determined together with the priorities of other frequencies during the network planning. Cell reselection priorities in different RATs cannot be the same. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the same RAT/frequency priority group specified by RatFreqPriorityGroupId, frequencies used for different RATs must be assigned different priorities.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
BandIndicator GERAN Frequency Indicator

Meaning: Indicates the GERAN frequency band. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: GSM_dcs1800, GSM_pcs1900

Unit: None

Actual Value Range: GSM_dcs1800, GSM_pcs1900

MML Default Value: GSM_dcs1800

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
InterFreqUeNumOffloadThd Inter-Frequency Offload UE Number Threshold

Meaning: Indicates the UE number threshold used for SPID-specific inter-frequency offload. When user-number-based MLB is triggered in a cell operating on a specified frequency and the number of UEs in the cell is greater than this parameter value, the eNodeB attempts to transfer UEs with the specific SPID from the local cell to inter-frequency neighboring cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 65535

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of InterFreqUeNumOffloadThd must be greater than or equal to the value of UeNumOffloadProhibitThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in higher average UE throughput in the cells on the specified frequency but lower average UE throughput in inter-frequency neighboring cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
UeNumOffloadProhibitThd UE Number Offload Prohibition Threshold

Meaning: Indicates the UE number threshold for prohibiting admission of UEs with the specified SPID. If the number of UEs in a cell on a specified frequency is greater than or equal to this parameter value, the eNodeB prohibits the transfer of UEs with the specific SPID to the local cell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 65535

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of InterFreqUeNumOffloadThd must be greater than or equal to the value of UeNumOffloadProhibitThd.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in higher average UE throughput in the cells on the specified frequency but lower average UE throughput in other cells in which the SPID-based inter-frequency offload function is enabled. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
InterRatUeNumOffloadThd Inter-RAT Offload UE Number Threshold

Meaning: Indicates the user number threshold used for SPID-specific inter-RAT offload. When the number of uplink-synchronized (UL-sync) UEs in a local cell is greater than or equal to this threshold, the eNodeB attempts to transfer UEs with the specific SPID to inter-RAT neighboring cells. When the number of UL-sync UEs in the local cell is greater than or equal to the sum of the cell-level user number threshold and the related offset, the eNodeB attempts to transfer UEs without the specific SPID or UEs whose SPIDs are not obtained to inter-RAT neighboring cells. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~65535

Unit: None

Actual Value Range: 1~65535

MML Default Value: 150

Recommended Value: 150

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering inter-RAT offload and a higher probability that UEs with the specific SPID are transferred to a UTRAN or GERAN. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
ConnFreqPriority Frequency Priority for Connected Mode

Meaning: Indicates the frequency priority for the connected mode. Operators can configure different frequency priorities for the connected mode by PLMN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add a RAT/frequency priority group configuration with the parameters follows: RatFreqPriorityGroupId: 0, RatType: EUTRAN, Downlink Earfcn: 3000, run the following command:
ADD RATFREQPRIORITYGROUP: RatFreqPriorityGroupId=0, RatType=EUTRAN, DlEarfcn=3000;
