List eNodeB Cell Alarm Configuration (LST EUCELLALMCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration information of the eNodeB cell alarm.

Note

None.

Parameters

ID Name Description
LocalCellId LocalCellId

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of eNodeB alarms of a cell:
LST EUCELLALMCFG:;
The result is shown as follows:
+++    0        2019-12-05 17:32:11
O&M    #806355989
%%LST EUCELLALMCFG: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List EuCellAlmCfg
-----------------
                     LocalCellId  =  1
Rx Noise Power Threshold(0.1dBm)  =  120
 RX Channel Noise Detection Mode  =  ALL_CHANNELS
(Number of results = 1)


---    END

Output Description

Field Description

LocalCellId

Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB.

Rx Noise Power Threshold(0.1dBm)

Indicates the threshold for reporting an alarm indicating interference noise power imbalance between receive (RX) channels of the cell. The threshold is an average interference noise power difference between two RX channels of the cell. This parameter applies only to LTE FDD cells and NB-IoT cells deployed in a mode other than LTE in-band mode.

RX Channel Noise Detection Mode

Indicates the method of checking the alarm of interference noise power imbalance between receive channels in a cell.

ALL_CHANNELS: Indicates that the eNodeB checks whether the interference power of all channels in a cell is balanced. If the interference power is unbalanced and exceeds the RxNoisePwrThd parameter value, ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is generated. If this parameter is changed from another value to this value, the modification takes effect at the next check period.

RRU_CHANNELS: Indicates that the eNodeB checks whether the interference noise power is balanced between RRU channels. This value applies only to physical cells served by two combined RRUs. If interference noise power is unbalanced, ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is generated. If this parameter is changed from another value to this value, the modification takes effect at the next check period.

NONE: Indicates that ALM-29250 Cell RX Channel Interference Noise Power Unbalanced is not generated. If this alarm has been reported, the eNodeB clears the alarm.

This parameter applies only to LTE FDD cells and NB-IoT cells deployed in a mode other than LTE in-band mode.
