List RRN LAN IP (LST EURRNLANIP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the IP address of the LAN port on an RRN.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of the EuRrnLanIp MOs with the LocalSubscriberId parameters set to the same value is less than or equal to 16.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LanIp LAN IP

Meaning: Indicates the IP address of the LAN port on an RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the IP address of the LAN port on an RRN, run the following command: 
+++    0        2014-09-15 18:59:37
O&M    #806355076
%%LST EURRNLANIP:;%%
RETCODE = 0  Operation succeeded.

Query an Lan IP  of an RRN
--------------------------
Local Subscriber ID  =  12
             LAN IP  =  192.168.10.1
           LAN Mask  =  255.255.255.0
(Number of results = 1)


---    END

Output Description

Field Description

Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

LAN IP

Indicates the IP address of the LAN port on an RRN. This parameter applies only to LTE FDD and LTE TDD.

LAN Mask

Indicates the subnet mask of the IP address of the LAN port on an RRN. This parameter applies only to LTE FDD and LTE TDD.
