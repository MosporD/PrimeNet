Modify Multi-Prb Configuration of NB-IoT Cell (MOD NBCELLMULTIPRBCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify Multi-PRB configuration parameter of NB-IoT cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbDlScUsageDiffThld PRB DL Subcarrier Usage Difference Threshold

Meaning: Indicates the threshold used to determine whether to trigger load balancing between carriers of a multi-carrier NB-IoT cell. This threshold is a difference in downlink subcarrier resource usage between the serving carrier and the candidate carrier. If the difference in downlink subcarrier resource usage between the carriers is greater than or equal to the sum of the values of this parameter and the DlSubcarrierUsageOffset parameter in the PrbSchConfig MO, load balancing will be triggered between the carriers. This parameter applies only to NB-IoT.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to an extremely large value, it is difficult to trigger load balancing between carriers, causing user experience to deteriorate for UEs served by the heavily loaded carrier. If this parameter is set to an extremely small value, load balancing will be triggered too frequently.

Applicable Mode: L-NB-IOT
PrbDlSubcarrierUsageThld PRB DL Subcarrier Usage Threshold

Meaning: Indicates the threshold used to determine whether to trigger load balancing between NB-IoT carriers. This threshold is represented by downlink subcarrier resource usage. If the downlink subcarrier resource usage of a carrier is higher than or equal to the value of this parameter, load balancing is triggered between this carrier and other carriers. If the downlink subcarrier resource usage of a carrier is lower than the value of this parameter, the eNodeB evaluates whether to trigger load balancing between this carrier and other carriers based on the difference in downlink subcarrier resource usage between carriers. If the difference condition is not met either, load balancing will not be triggered between the carriers. This parameter applies only to NB-IoT.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

If this parameter is set to an extremely small value, load balancing will be triggered too frequently.

Applicable Mode: L-NB-IOT
PrbUeNumberOffset PRB UE Number Offset

Meaning: Indicates the offset to the difference in the number of UEs between the NB-IoT carriers. This offset is used for load balancing between the NB-IoT carriers. This parameter applies only to NB-IoT.

GUI Value Range: 0~10000

Unit: None

Actual Value Range: 0~10000

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to an extremely large value, there will be a UE number imbalance between carriers. This can cause congestion when there are burst services, resulting in user experience deterioration. If this parameter is set to an extremely small value, the load difference between carriers will be large, causing user experience to deteriorate for UEs served by the heavily loaded carrier.

NbRfCarrierStrategy NB-IoT RF Carrier Strategy

Meaning: Indicates the RF carrier policy for an NB-IoT cell. If this parameter is set to SEPARATE_PRECEDENCE, the RF carrier separation policy is preferentially used to set up the cell. If the RRU or BBP does not support RF carrier separation, the RF carrier sharing policy is then used. If this parameter is set to SHARE, the RF carrier sharing policy is used to set up the cell. This policy requires that the RRU and BBP support RF carrier sharing. If this parameter is set to SEPARATE, the RF carrier separation policy is used to set up the cell. This policy requires that the RRU and BBP support RF carrier separation. This parameter applies only to the LTE in-band and standalone deployment modes. In other deployment modes, the RF carrier separation policy is used by default. This parameter applies only to macro and micro base stations but does not apply to LampSite base stations. This parameter applies only to NB-IoT.

GUI Value Range: SEPARATE_PRECEDENCE(SEPARATE_PRECEDENCE), SHARE(SHARE), SEPARATE(SEPARATE)

Unit: None

Actual Value Range: SEPARATE_PRECEDENCE, SHARE, SEPARATE

MML Default Value: None

Recommended Value: SEPARATE_PRECEDENCE(SEPARATE_PRECEDENCE)

Parameter Relationship: None

MultiCarrierOptSwitch Multi-Carrier Optimization Switch

Meaning: Indicates whether to enable NB-IoT multi-carrier functions.

PAGING_PRB_SELECTION_SW: Indicates the carrier range for NB-IoT UEs that support R15-defined mixed operation modes to monitor paging messages. If this option is deselected, the UEs monitor paging messages on all carriers that support paging. If this option is selected, the UEs monitor paging messages on non-anchor carriers that support paging and are deployed in multi-carrier mode in compliance with 3GPP Release 15. This option is valid only when both paging on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 14 and paging on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 15 are enabled. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

NPRACH_PRB_SELECTION_SW: Indicates the carrier range for NB-IoT UEs that support R15-defined mixed operation modes to access the cell. If this option is deselected, the UEs can initiate random access on all carriers that support random access. If this option is selected, the UEs can initiate random access on non-anchor carriers that support random access and are deployed in multi-carrier mode in compliance with 3GPP Release 15. This option is valid only when both access on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 14 and access on non-anchor carriers deployed in multi-carrier mode in compliance with 3GPP Release 15 are enabled. For details, see 3GPP TS 36.331. This option applies only to NB-IoT.

PWR_DIFF_BASED_PRB_LB_SW: Indicates whether an NB-IoT cell supports load sharing based on the power difference between carriers. If this option is selected, the cell supports load sharing based on the power difference between carriers. If this option is deselected, whether loads can be shared between carriers varies as follows: If the NB-IoT cell has two carriers, UEs at coverage level 2 can perform services only on the anchor carrier; if the NB-IoT cell has more than two carriers, UEs at coverage level 2 can be assigned to non-anchor carriers whose power difference from the anchor carrier is at least -4 dB. This option applies only to NB-IoT.

GUI Value Range: PAGING_PRB_SELECTION_SW(PAGING_PRB_SELECTION_SW), NPRACH_PRB_SELECTION_SW(NPRACH_PRB_SELECTION_SW), PWR_DIFF_BASED_PRB_LB_SW(PWR_DIFF_BASED_PRB_LB_SW)

Unit: None

Actual Value Range: PAGING_PRB_SELECTION_SW, NPRACH_PRB_SELECTION_SW, PWR_DIFF_BASED_PRB_LB_SW

MML Default Value: None

Recommended Value: PAGING_PRB_SELECTION_SW:Off, NPRACH_PRB_SELECTION_SW:Off, PWR_DIFF_BASED_PRB_LB_SW:Off

Parameter Relationship: None

NbMpruRfCarrierStrategy NB-IoT MPRU RF Carrier Strategy

Meaning: Indicates the MPRU RF carrier policy for an NB-IoT cell. If this parameter is set to SHARE, the RF carrier sharing policy is used to set up the cell. This policy requires that the BBP and RRU support RF carrier sharing. If this parameter is set to SEPARATE, the RF carrier separation policy is used to set up the cell. This policy requires that the BBP and RRU support RF carrier separation. This parameter applies only to the LTE in-band deployment mode. In other deployment modes, the RF carrier separation policy is used by default. This parameter applies only to LampSite base stations. This parameter applies only to NB-IoT.

GUI Value Range: SHARE(SHARE), SEPARATE(SEPARATE)

Unit: None

Actual Value Range: SHARE, SEPARATE

MML Default Value: None

Recommended Value: SHARE(SHARE)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

Example 1: To modify the Multi-Prb configuration of NB-IoT cell with the parameters as follows: Local cell ID: 0, PRB DL Subcarrier Usage Difference Threshold(%): 25, run the following command:
MOD NBCELLMULTIPRBCONFIG: LocalCellId=0, PrbDlScUsageDiffThld=25;
