Add Qci Eutran Relation (ADD QCIEUTRANRELATION)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add a relationship between a QCI and an E-UTRAN frequency.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
DlEarfcn Downlink EARFCN

Meaning: Indicates the downlink (DL) E-UTRA absolute radio frequency channel number (EARFCN) associated with the QCI. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
QciEutranFreqRelationId QCI Eutran Frequency Relation ID

Meaning: Indicates the ID of the QCI and E-UTRAN frequency relationship group. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MobilityTargetInd Mobility Target Indicator

Meaning: Indicates whether the neighboring E-UTRAN frequency can be a target frequency in QCI-specific mobility management.

MlbTargetInd(MlbTargetInd): The neighboring E-UTRAN frequency can be a target frequency in QCI-specific MLB only if this option is selected. You are advised to select this option for the default bearer. Otherwise, MLB may not transfer UEs. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: MlbTargetInd(MlbTargetInd)

Unit: None

Actual Value Range: MlbTargetInd

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
