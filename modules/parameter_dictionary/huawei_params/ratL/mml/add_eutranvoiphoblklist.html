Add EUTRAN VoIP Handover Blacklist (ADD EUTRANVOIPHOBLKLIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an intra-RAT VoIP service handover blacklist.

Note

A maximum of 32 intra-RAT VoIP service handover blacklists can be configured.

Parameters

ID Name Description
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of a target eNodeB.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of a target eNodeB.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Tac Tac

Meaning: Indicates the tracking area code (TAC), which is used by the EPC to determine the area within which paging messages are sent. One tracking area is comprised of one or more cells. Two TAC values 0x0000(0) and 0xFFFE(65534) are reserved according to the protocol and will not be used in future versions. Therefore, do not use 0 or 65534 as a TAC value in TAC planning or configuration. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an EUTRAN VoIP service handover blacklist, Configuration as follows: Mobile country code: "460", Mobile network code: "20", Tac: 100, run the following command:
ADD EUTRANVOIPHOBLKLIST: Mcc="460", Mnc="20", Tac=100;
