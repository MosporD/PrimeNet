List Dedicated RRC Parameter for PUSCH Power Control (LST CELLULPCDEDIC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the dedicated RRC parameters related to power control for the PUSCH.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

List Dedicated RRC Parameter for PUSCH Power Control:
LST CELLULPCDEDIC:;
The result is shown as follows:
+++    0        2019-12-05 09:00:53
O&M    #806355203
%%LST CELLULPCDEDIC: LocalCellId=1;%%

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

Delta-MCS enable or disable indication

Indicates whether a UE needs to adjust the transmit power based on the MCS. The indication is sent to the UE through an RRC message. The indication is denoted by a bit. Bit 0 indicates that both Ks and ΔTF are equal to 0. Bit 1 indicates that Ks is equal to 1.25 and ΔTF is calculated. UU_DISABLE and UU_ENABLE indicate bits 0 and 1, respectively. For details, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.

Power Offset of SRS When DeltaMcsEnabled Off(0.1dB)

Indicates the power offset of the sounding reference signal to the PUSCH when DeltaMcsEnabled is set to UU_DISABLE. This parameter applies only to LTE FDD and LTE TDD.

Power Offset of SRS When DeltaMcsEnabled On(0.1dB)

Indicates the power offset of the sounding reference signal to the PUSCH when DeltaMcsEnabled is set to UU_ENABLE. This parameter applies only to LTE FDD and LTE TDD.

RSRP filtering coefficient

Indicates the alpha filtering coefficient used by the UE during RSRP measurement for path loss estimation. This parameter applies only to LTE FDD and LTE TDD.

Pathloss Reference Link

Indicates whether to use the radio link in the PCell or SCell for evaluation of downlink path loss in the cell. For details about how to use this parameter, see 3GPP TS 36.213. This parameter applies only to LTE FDD and LTE TDD.
