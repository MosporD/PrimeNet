List Tracking Area Configuration for CN Operator (LST CNOPERATORTA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list tracking area settings of the eNodeB.

Note

None.

Parameters

ID Name Description
TrackingAreaId Local tracking area ID

Meaning: Indicates the tracking area ID, which uniquely identifies an entry of tracking area information. This parameter is used only within the eNodeB and is not used during the information exchange with the EPC. This is different from the TAI configured in the EPC TAL.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

List Tracking Area Configuration for CN Operator:
LST CNOPERATORTA:;
The result is shown as follows:

Output Description

Field Description

Local tracking area ID

Indicates the tracking area ID, which uniquely identifies an entry of tracking area information. This parameter is used only within the eNodeB and is not used during the information exchange with the EPC. This is different from the TAI configured in the EPC TAL.

CN Operator ID

Indicates the ID of the operator.

Tracking area code

Indicates the tracking area code (TAC), which is used by the EPC to determine the area within which paging messages are sent. One tracking area comprises one or more cells.

NB-IoT TA Flag

Indicates whether the current TAI applies only to NB-IoT. If this parameter is set to BOOLEAN_TRUE, the current TAI applies only to NB-IoT. If this parameter is set to BOOLEAN_FALSE, the current TAI does not apply to NB-IoT. In accordance with 3GPP specifications, NB-IoT does not support inter-RAT mobility. Therefore, the TAIs of NB-IoT must be different from those of LTE FDD and LTE TDD. For details, see section 5.3.3 in 3GPP TS 23.401 V13.7.0. This parameter applies only to NB-IoT.
