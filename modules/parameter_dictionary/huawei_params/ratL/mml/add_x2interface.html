Add X2 Interface (ADD X2INTERFACE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an X2 interface.

Note

Before running this command, ensure that the associated CP bearer and the operator have been configured.

If the value of the CnOpSharingGroupId parameter in an X2Interface MO is not set to the invalid value 255, ensure that the associated CnOpSharingGroup MO has been added before adding the X2Interface MO and the operator to which the X2Interface MO belongs is in the carrier-sharing operator group. In hybrid RAN sharing mode, the CnOpSharingGroup MO referenced by the X2Interface MO must be configured and the CnOpSharingGroupId parameter must be set to a valid value.

Parameters

ID Name Description
X2InterfaceId X2Interface ID

Meaning: Indicates the X2 interface ID. If the X2 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65535. If the X2 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
X2CpBearerId X2 Interface CP Bearer ID

Meaning: Indicates the ID of the control port bearer for the X2 interface.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The X2CpBearerId value in each X2Interface MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator that owns the X2 interface.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
TargetENodeBRelease Peer Base Station Release

Meaning: Indicates the protocol release with which the peer base station connected to the local base station through the X2 interface complies. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: Release_R8(Release 8), Release_R9(Release 9), Release_R10(Release 10), Release_R11(Release 11), Release_R12(Release 12), Release_R13(Release 13), Release_R14(Release 14), Release_R15(Release 15)

Unit: None

Actual Value Range: Release_R8, Release_R9, Release_R10, Release_R11, Release_R12, Release_R13, Release_R14, Release_R15

MML Default Value: Release_R10(Release 10)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group that shares the X2 Interface MO. If the eNodeB works in hybrid RAN sharing mode, set this parameter to a value within the range from 0 to 5. If the eNodeB works in independent mode, RAN sharing with common carriers mode, or RAN sharing with dedicated carriers mode, retain the default value 255, which is an invalid value.

GUI Value Range: 0~5,255

Unit: None

Actual Value Range: 0~5,255

MML Default Value: 255

Recommended Value: If the eNodeB works in hybrid RAN sharing mode, the recommended value is ranging from 0 to 5; otherwise, set this parameter to the invalid value 255.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L
NeighboringBaseStationType Neighboring Base Station Type

Meaning: Indicates the type of the neighboring base station to which the local base station is connected through the X2 interface. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: ENODEB(ENODEB), GNODEB(GNODEB)

Unit: None

Actual Value Range: ENODEB, GNODEB

MML Default Value: ENODEB(ENODEB)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When the CtrlMode parameter is set to MANUAL_MODE, the NeighboringBaseStationType parameter must be set to ENODEB.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an X2 interface with the parameters as follows: X2InterfaceId: 16, X2CpBearerId: 16, CnOperatorId: 0, run the following command:
ADD X2INTERFACE: X2InterfaceId=16, X2CpBearerId=16, CnOperatorId=0;
