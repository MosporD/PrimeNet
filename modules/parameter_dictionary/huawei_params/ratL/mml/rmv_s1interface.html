Remove S1 Interface (RMV S1INTERFACE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an S1 interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the operator that owns the S1 interface to be removed does not have another available S1 interface, removing the S1 interface may result in unavailability of this operator's cells.

Parameters

ID Name Description
S1InterfaceId S1 Interface ID

Meaning: Indicates the S1 interface ID. If the S1 interface is set up based on the endpoint configuration mode, the value range is 40000 to 65534. If the S1 interface is set up based on the link configuration mode using the MAE or MML commands, the recommended value range is 0 to 39999.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove an S1 interface whose ID is 2, run the following command:
RMV S1INTERFACE: S1InterfaceId=2;
