Modify Cell Reserved Parameter (MOD ENBCELLRSVDPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify reserved cell-level parameters.

Note

  • Do not modify a not-in-use reserved parameter.

  • If an in-use reserved parameter that has been configured is set to a value not in the value range, the default parameter value will be used.

  • Modify in-use reserved parameters according to the descriptions in (eNodeB) Used Reserved Parameter List in the 03-Reserved List folder that is delivered with Release Documents-EN of the corresponding version.
