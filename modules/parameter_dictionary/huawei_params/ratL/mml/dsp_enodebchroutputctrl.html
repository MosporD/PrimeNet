Display State (DSP ENODEBCHROUTPUTCTRL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the dynamic information about the output control of eNodeB CHRs.

Note

In the command output of the EventSubscriptionInfo parameter, the field "Number of Results" indicates the number of lines of the output result rather than the number of event IDs.

Parameters

None.

Example

To query the dynamic information about the output control of eNodeB CHRs, run the following command:
DSP ENODEBCHROUTPUTCTRL:;
The result is shown as follows:
+++    0        2019-12-05 19:16:00
O&M    #806355314
%%DSP ENODEBCHROUTPUTCTRL:;%%
RETCODE = 0  Operation succeeded.

Display ENODEBCHROUTPUTCTRL State
---------------------------------
SIG Report Switch  =  On
(Number of results = 1)

Display ENODEBCHROUTPUTCTRL State
---------------------------------
Event Subscription Info

Local Cell ID:None     
Event ID:  None        
(Number of results = 2)


---    END

Output Description

Field Description

SIG Report Switch

Indicates whether to report SIG logs and signaling soft collection results. If this parameter is set to ON, SIG logs and signaling soft collection results that have been subscribed to are normally reported. If this parameter is set to OFF, reporting of these SIG logs and signaling soft collection results is forcibly terminated and new subscriptions no longer take effect.

Event Subscription Info

Indicates the IDs of successfully subscribed events displayed in the result of the DSP ENODEBCHROUTPUTCTRL command.
