Add EPC information (ADD EUEPCINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add compact EPC information.

Note

In the current version, only one EUEPCINFO MO can be configured for an eNodeB.

Parameters

ID Name Description
LocalEpcId Local EPC ID

Meaning: Indicates the local ID of the compact EPC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MmeGroupId MME Group ID

Meaning: Indicates the ID of the MME group in the compact EPC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 32768~65535

Unit: None

Actual Value Range: 32768~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MMECode MME Code

Meaning: Indicates the code of the MME in the compact EPC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FullNameForNetwork Full Name for Network

Meaning: This parameter specifies the full name of a network service provider. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Meaning: This parameter specifies the abbreviation for the name of a network service provider. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add EPC-inside information with the parameters as follows: Local EPC ID:1, MME Group ID:40625, MME Code:1, run the following command:
ADD EUEPCINFO: LocalEpcId=1, MmeGroupId=40625, MMECode=1;
