Modify CN Operator Handover Configuration (MOD CNOPERATORHOCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify operator-specific handover configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If this MO is modified, the eNodeB may fail to start FDD/TDD or UTRAN/GERAN measurements.

Parameters

ID Name Description
CnOperatorId CN Operator ID

Meaning: Indicates the ID of the operator. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
FirstRatPri First RAT Priority

Meaning: Indicates the priority of E-UTRAN TDD or E-UTRAN FDD in inter-frequency blind handover or blind redirection scenarios. To prioritize E-UTRAN TDD or E-UTRAN FDD, set this parameter to EUTRAN_TDD or EUTRAN_FDD, respectively. To treat E-UTRAN TDD and E-UTRAN FDD equally, set this parameter to EUTRAN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EUTRAN_TDD, EUTRAN_FDD, EUTRAN

Unit: None

Actual Value Range: EUTRAN_TDD, EUTRAN_FDD, EUTRAN

MML Default Value: None

Recommended Value: EUTRAN

Parameter Relationship:

-Configuration constraints:

  • In the CnOperatorHoCfg MO, SecondRatPri must be set to NULL if FirstRatPri is set to EUTRAN.
  • In the CnOperatorHoCfg MO, SecondRatPri must be set to EUTRAN_TDD if FirstRatPri is set to EUTRAN_FDD.
  • In the CnOperatorHoCfg MO, SecondRatPri must be set to EUTRAN_FDD if FirstRatPri is set to EUTRAN_TDD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SecondRatPri Second RAT Priority

Meaning: Indicates the priority of E-UTRAN TDD or E-UTRAN FDD in inter-frequency blind handover or blind redirection scenarios. To prioritize E-UTRAN TDD or E-UTRAN FDD, set this parameter to EUTRAN_TDD or EUTRAN_FDD, respectively. If the FirstRatPri parameter is set to EUTRAN, the SecondRatPri parameter must be set to NULL, indicating that E-UTRAN TDD and E-UTRAN FDD are not differentiated. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: EUTRAN_TDD, EUTRAN_FDD, NULL

Unit: None

MML Default Value: None

Recommended Value: NULL

Parameter Relationship:

-Configuration constraints:

  • In the CnOperatorHoCfg MO, SecondRatPri must be set to EUTRAN_TDD if FirstRatPri is set to EUTRAN_FDD.
  • In the CnOperatorHoCfg MO, SecondRatPri must be set to EUTRAN_FDD if FirstRatPri is set to EUTRAN_TDD.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

TddIfHoA2ThdRsrpOffset LTE TDD inter-freq A2 Threshold RSRP Offset

Meaning: Indicates the offset for LTE TDD inter-frequency event A2 relative to the RSRP threshold for A3-based inter-frequency event A2 (specified by the A3InterFreqHoA2ThdRsrp parameter) and the RSRP threshold for A4/A5-based inter-frequency event A2 (specified by the InterFreqHoA2ThdRsrp parameter). The value of this parameter plus the value of the A3InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A3-based LTE TDD inter-frequency event A2. The value of this parameter plus the value of the InterFreqHoA2ThdRsrp parameter is taken as the RSRP threshold for A4/A5-based LTE TDD inter-frequency event A2. If the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold for inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the TddIfHoA2ThdRsrpOffset parameter or the FddIfHoA2ThdRsrpOffset parameter. If both the TddIfHoA2ThdRsrpOffset and FddIfHoA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-frequency A2 measurement configurations without considering LTE TDD and LTE FDD measurement priorities in coverage-based inter-frequency measurement scenarios, and the RSRP threshold is the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter. If the TddIfHoA2ThdRsrpOffset parameter is set to -100 and the FddIfHoA2ThdRsrpOffset parameter is not set to -100, coverage-based LTE TDD measurement is not triggered, and the eNodeB delivers only LTE FDD inter-frequency A2 measurement configurations, which are used to trigger coverage-based LTE FDD inter-frequency measurement. The RSRP threshold for LTE FDD inter-frequency event A2 equals the value of the A3InterFreqHoA2ThdRsrp parameter or the InterFreqHoA2ThdRsrp parameter plus the value of the FddIfHoA2ThdRsrpOffset parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: -100,-20~20

Unit: dB

Actual Value Range: -100,-20~20

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

UtranA2ThdRsrpOffset UTRAN A2 Threshold RSRP Offset

Meaning: Indicates the offset for UTRAN event A2 relative to the RSRP threshold for inter-RAT event A2 (specified by the InterRatHoA2ThdRsrp parameter). The sum of the value of this parameter, the value of the InterRatHoA2ThdRsrp parameter in the InterRatHoCommGroup MO, and the value of the InterRatA2RsrpThldOffset parameter in the CnOperatorQciPara MO is taken as the RSRP threshold for inter-RAT event A2. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to the same value excluding the value -100, the eNodeB delivers inter-RAT A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the UtranA2ThdRsrpOffset or GeranA2ThdRsrpOffset parameter value, and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If both the UtranA2ThdRsrpOffset and GeranA2ThdRsrpOffset parameters are set to -100, the eNodeB delivers inter-RAT event A2 measurement configurations without considering UTRAN and GERAN measurement priorities in coverage-based inter-RAT measurement scenarios, and the RSRP threshold for inter-RAT event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value and the InterRatA2RsrpThldOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. If the UtranA2ThdRsrpOffset parameter is set to -100 and the GeranA2ThdRsrpOffset parameter is not set to -100, coverage-based UTRAN measurement is not triggered, and the eNodeB delivers only the GERAN event A2 measurement configurations, which are used to trigger coverage-based GERAN measurement. The RSRP threshold for GERAN event A2 equals the sum of the InterRatHoA2ThdRsrp parameter value, the InterRatA2RsrpThldOffset parameter value, and the GeranA2ThdRsrpOffset parameter value. If an SpidCfg MO is configured, the InterRatA2RsrpThldOffset parameter value in the SpidCfg MO must also be added to the sum. This parameter applies only to LTE FDD and LTE TDD.

Example

To modify the CN operator parameters that are related to handovers as follows: CN Operator ID:0, FirstRatPri: EUTRAN_TDD, SecondRatPri:EUTRAN_FDD:
MOD CNOPERATORHOCFG: CnOperatorId=0, FirstRatPri=EUTRAN_TDD, SecondRatPri=EUTRAN_FDD;
