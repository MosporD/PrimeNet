List Previous Registration Parameter with CDMA2000HRPD (LST CDMA2000HRPDPREREG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the neighboring relation with the CDMA2000 HRPD cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the CDMA2000 high rate packet data (HRPD) pre-registration parameter.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Mcc in an Cdma2000HrpdPreReg MO consists of digits only.

Output Description

Field Description

Local cell ID

Indicates the ID of the local cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Mobile country code

Indicates the mobile country code (MCC) of the CDMA2000 high rate packet data (HRPD) pre-registration parameter.

A public land mobile network (PLMN) ID is comprised of an MCC and a mobile network code (MNC).

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

Mobile network code

Indicates the mobile network code (MNC) of the CDMA2000 high rate packet data (HRPD) pre-registration parameter.

A public land mobile network (PLMN) ID is comprised of a mobile country code (MCC) and an MNC.

The MCC consists of three digits.

The MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345. This parameter applies only to LTE FDD and LTE TDD.

SIB8 Pre-registration allowed indicator

Indicates whether a UE without valid pre-registration is allowed to initiate high rate packet data (HRPD) pre-registration. If this parameter is set to BOOLEAN_TRUE, the UE is allowed to initiate the pre-registration. If this parameter is set to BOOLEAN_FALSE, the UE is not allowed to initiate the pre-registration. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

PreRegistrationInfoHRPD configure indicator in MeasConfig

Indicates whether the measurement configuration pre-registration parameter is configured. This parameter applies only to LTE FDD and LTE TDD.

Pre-registration allowed indicator in MeasConfig

Indicates whether measurement configuration pre-registration is allowed. This parameter applies only to LTE FDD and LTE TDD.

Pre-registration zone ID

Indicates the ID of the pre-registration CDMA2000 HRPD zone. This parameter is used to control the re-registration of the UE and is valid only when pre-registration is allowed. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Secondary pre-registration zone ID 0 configure indicator

Indicates whether the secondary pre-registration zone ID 0 is configured. If this parameter is set to CFG, the secondary pre-registration zone ID 0 exists. If this parameter is set to NOT_CFG, the secondary pre-registration zone ID 0 does not exist. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Secondary pre-registration zone ID 0

Indicates the secondary pre-registration zone ID 0. This parameter is used to control the re-registration of the UE. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Secondary pre-registration zone ID 1 configure indicator

Indicates whether the secondary pre-registration zone ID 1 is configured. If this parameter is set to CFG, the secondary pre-registration zone ID 1 exists. If this parameter is set to NOT_CFG, the secondary pre-registration zone ID 1 does not exist. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Secondary pre-registration zone ID 1

Indicates the secondary pre-registration zone ID 1. This parameter is used to control the re-registration of the UE. For details about this parameter, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.
