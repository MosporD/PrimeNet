Modify NbCellDynPwrShrPara Configuration in an NB-IoT Cell (MOD NBCELLDYNPWRSHRPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify NbCellDynPwrShrPara Configuration in an NB-IoT Cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: This parameter specifies the local ID of a cell. It uniquely identifies a cell within a eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
DlPrbUsageThld Downlink PRB Usage Threshold

Meaning: Indicates the LTE cell downlink PRB usage threshold for sharing power with NB-IoT cells in in-band deployment scenarios where NB-IoT dynamic power sharing is used. When this parameter is set to 0, NB-IoT dynamic power sharing does not take effect. When this parameter is set to a non-zero value, the eNodeB checks the downlink PRB usage of the LTE cell at intervals of 10s. If the downlink PRB usage is lower than or equal to this value for six consecutive times, the LTE cell can share its power with NB-IoT cells during the time when NB-IoT dynamic power sharing is effective. If the PRB usage of the LTE cell is greater than the threshold by 10% or more, or if the condition that the PRB usage of the LTE cell is greater than the threshold by 5% or more is satisfied for 20 times or more within 10 minutes, the LTE cell stops sharing its power with the NB-IoT cells.

This parameter applies only to NB-IoT.

GUI Value Range: 0~30

Unit: %

Actual Value Range: 0~30

MML Default Value: None

Recommended Value: 0 when NB-IoT dynamic power sharing is not required in in-band deployment scenarios, and 10 when NB-IoT dynamic power sharing is required in in-band deployment scenarios

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability that NB-IoT dynamic power sharing will be triggered to increase the downlink cell throughput and UE throughput of NB-IoT cells. However, the probability of affecting and the impact on the average downlink throughput and user-perceived throughput of the LTE FDD cell are small. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-NB-IOT
StartTime Start Time

Meaning: Indicates the time when NB-IoT dynamic power sharing starts to take effect. This parameter and the EndTime parameter define the time segment in which NB-IoT dynamic power sharing takes effect. This parameter applies only to NB-IoT.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 00:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
EndTime End Time

Meaning: Indicates the time when NB-IoT dynamic power sharing stops taking effect. This parameter and the StartTime parameter define the time segment in which NB-IoT dynamic power sharing takes effect. This parameter applies only to NB-IoT.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: 07:00:00

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To modify the NbCellDynPwrShrPara Configuration in an NB-IoT Cell with the parameters as follows: Local cell ID: 10, Downlink PRB Usage Threshold: 10, run the following command:
MOD NBCELLDYNPWRSHRPARA: LocalCellId=10, DlPrbUsageThld=10;
