Remove Neighboring Relation with CDMA2000HRPD Cell (RMV CDMA2000HRPDNCELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove one or more neighbor relationships with CDMA2000 HRPD cells.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If all parameters are specified, only the configuration of the one neighboring CDMA2000 HRPD cell with the same parameter settings is removed after the command is executed.

  • If some parameters are specified, configurations of the neighboring CDMA2000 HRPD cells with the same parameter settings are removed after this command is executed, and a maximum of 640 neighboring CDMA2000 HRPD cell configurations can be removed at a time.

  • If no parameter is specified, configurations of all neighboring CDMA2000 HRPD cells are removed after this command is executed, and a maximum of 640 neighboring CDMA2000 HRPD cell configurations can be removed at a time.

Parameters

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

MML Default Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
SectorId104 SectorID104

Meaning: Indicates the value for SectorID104 of the neighboring CDMA2000 high rate packet data (HRPD) cell. The value begins with 0x followed by a maximum of 26 hexadecimal characters (0 to 9, and A to F), for example, 0x123A. The hexadecimal character string cannot begin with 0, for example, the value cannot be 0x0123A. SECTORID128 uniquely identifies an EV-DO sector in the global scope and is comprised of SECTORID104 and SECTORID24. SECTORID104 uniquely identifies a subnetwork in the global scope and SECTORID24 uniquely identifies an EV-DO sector in the subnetwork. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 3~28 characters

Unit: None

Actual Value Range: 3~28 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • SectorId104 in the Cdma2000HrpdNCell MO must be set to a hexadecimal number starting with 0x and with a total length not greater than 26 digits. A hexadecimal number is composed of upper-case letters (A to F) and digits (0 to 9). The hexadecimal digit following 0x can be 0 only if the parameter is set to 0x0. That is, the parameter value like 0x00AB is inappropriate but 0x0 is acceptable.

Service Interrupted After Modification: N/A

Example

To remove the CDMA2000 HRPD neighboring relation with the parameters as follows: Local cell ID: 0, SectorID104: "0x0", SectorID24: "0x0", Band class: bc0, Frequency: 1234, run the following command:
RMV CDMA2000HRPDNCELL: LocalCellId=0, SectorId104="0x0", SectorId24="0x0", BandClass=bc0, Frequency=1234;
To remove the CDMA2000 HRPD neighboring relations with the parameters as follows: SectorID104: "0x0", SectorID24: "0x0", run the following command:
RMV CDMA2000HRPDNCELL: SectorId104="0x0", SectorId24="0x0";
