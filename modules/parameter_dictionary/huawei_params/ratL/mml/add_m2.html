Add M2 Configuration (ADD M2)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an M2 MO.

Note

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the M2EpGroupId parameter in the M2 MOs or the CpEpGroupId parameter in the S1 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the M2EpGroupId parameter in the M2 MOs or the CpEpGroupId parameter in the X2 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the M2EpGroupId parameter in the M2 MOs or the CpEpGroupId parameter in the EX2 MOs cannot overlap.

  • IP addresses configured in the SCTPPEER MOs belonging to the EPGROUP MOs referenced by the M2EpGroupId parameter in the M2 MOs or the CpEpGroupId parameter in the ECO MOs cannot overlap.

  • The EPGROUP MO referenced by M2EpGroupId in an M2 MO and the EPGROUP MO referenced by the uX2 MO must be different.

Parameters

ID Name Description
M2Id M2 ID

Meaning: Indicates the M2 object ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M2NetworkType M2 Network Type

Meaning: Indicates the type of network served by the M2 interface. If this parameter is set to MACRO_NETWORK, the type is macro network. If this parameter is set to IOPS_NETWORK, the network type is IOPS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: MACRO_NETWORK(MACRO_NETWORK), IOPS_NETWORK(IOPS_NETWORK)

Unit: None

Actual Value Range: MACRO_NETWORK, IOPS_NETWORK

MML Default Value: MACRO_NETWORK(MACRO_NETWORK)

Recommended Value: MACRO_NETWORK(MACRO_NETWORK)

Parameter Relationship:

-Configuration constraints:

  • The M2NetworkType value in each M2 MO must be unique.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
M2EpGroupId M2 End Point Group ID

Meaning: Indicates the ID of the endpoint group used by the M2 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The M2EpGroupId value in each M2 MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UserLabel User Label

Meaning: Indicates the descriptions of the M2 MO. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To add an M2 MO with the parameters as follows: M2 ID: 0, M2 End Point Group ID: 456, User Label: M2, run the following command:
ADD M2: M2Id=0, M2EpGroupId=456, UserLabel="M2";
