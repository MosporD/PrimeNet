List MbsfnAreaCell (LST MBSFNAREACELL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration data of the cells in an MBSFN area.

Note

None.

Output Description

Field Description

Local MCE ID

Indicates the local ID of an MCE. It uniquely identifies an MCE within a local NE. This parameter applies only to LTE FDD and LTE TDD.

MBSFN Area ID

Indicates the ID of an MBSFN area. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Cell ID

Indicates the cell identity of an E-UTRAN cell. The cell identity is a string of 28 bits, of which the 20 leftmost bits represent the eNodeB ID and the 8 rightmost bits represent the cell ID. The PLMN ID and the cell identity constitute the ECGI. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

eNodeB ID

Indicates the eNodeB ID, which is a string of at most 20 bits. The ID is unique within a PLMN. The PLMN ID and the eNodeB ID together constitute the global eNodeB ID. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Reserved Cell Indication

Indicates whether an E-UTRAN cell is a reserved cell for MBSFN. If the E-UTRAN cell is a reserved cell, multicast transmission is not performed in the cell. For details, see 3GPP TS 36.443. This parameter applies only to LTE FDD and LTE TDD.

Mobile Country Code

Indicates the MCC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-PLMN and multi-operator scenarios. This parameter applies only to LTE FDD and LTE TDD.

Mobile Network Code

Indicates the MNC of the MCE. An MCC and an MNC constitute a PLMN ID. PLMN IDs are used to support multi-PLMN and multi-operator scenarios. This parameter applies only to LTE FDD and LTE TDD.
