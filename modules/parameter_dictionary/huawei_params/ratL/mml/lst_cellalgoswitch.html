List Cell Algorithm Switch Configuration (LST CELLALGOSWITCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of cell-level algorithm switches.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the settings of cell-level algorithm switches, run the following command:
LST CELLALGOSWITCH:;
The result is shown as follows:
+++    0        2019-12-05 17:22:40
O&M    #806355677
%%LST CELLALGOSWITCH: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

If this option is selected, the eNodeB ensures the best-effort GBR for UEs with a specific QCI or SPID. If this option is deselected, the eNodeB does not ensure the best-effort GBR for UEs with a specific QCI or SPID. This option applies only to LTE FDD and LTE TDD.

SMART_FSS_SWITCH: Indicates whether to enable smart frequency selective scheduling. If the FreqSelSwitch option of the DlSchSwitch parameter and the SMART_FSS_SWITCH option are both selected, smart frequency selective scheduling takes effect. The eNodeB dynamically adjusts the period of triggering aperiodic CQI reporting from UEs involved in frequency selective scheduling and also adjusts the validity period of aperiodically reported CQIs. Therefore, the settings of the FSUEAperCQITrigPeriod and FSUESbCQIValidityPeriod parameters are invalid in smart frequency selective scheduling. If the SMART_FSS_SWITCH option is deselected, the settings of the FSUEAperCQITrigPeriod and FSUESbCQIValidityPeriod parameters still take effect. This option applies only to LTE FDD and LTE TDD.

PUSCH_1X_SWITCH: Indicates whether to enable the PUSCH 1-0 and PUSCH 1-1 feedback modes. These modes can be used only for short-TTI UEs. If this option is selected, UEs that support reporting on PUSCH 1-0 or PUSCH 1-1 use the corresponding mode to aperiodically report CSI. If this option is deselected, the PUSCH 1-0 and PUSCH 1-1 feedback modes cannot be used. This option applies only to LTE FDD.

MPMU Fault Detection Switch

Indicates whether to enable MPMU-level fault detection.

PRRUDETECT_SWITCH: If this option is selected, the system starts to record the positions of the UE and MPMU and saves the positions in the maintenance CHR log. If this option is deselected, the system stops recording such information.

Vertical Multiple Sectors Algorithm Switch

Indicates whether to enable algorithms related to vertical multiple sectors (VMS) or massive MIMO (32T32R) cell split.

PrbBalanceSw: If this option is selected in VMS scenarios, load balancing between inner and outer cells is enabled. If this option is deselected in VMS scenarios, load balancing between inner and outer cells is disabled. If this option is selected in massive MIMO (32T32R) scenarios, load balancing between cells served by the same AAU is enabled. If this option is deselected in massive MIMO (32T32R) scenarios, load balancing between cells served by the same AAU is disabled. This option applies only to LTE FDD.

RRC Reestablishment Data Forwarding Switch

Indicates whether the eNodeB serving the cell forwards data that has not been sent to a UE in the cell (as the source cell) to the target cell when the UE experiences an RRC connection reestablishment so that the target cell can send the data to the UE. If this parameter is set to ON(On), the eNodeB forwards the data to the target cell and the target cell sends the data to the UE after the RRC connection is reestablished in the target cell. If this parameter is set to OFF(Off), the eNodeB discards the data in the preceding scenario. This parameter applies only to LTE FDD and LTE TDD.

Small Bandwidth Optimization Switch

Indicates the small bandwidth optimization switch, which is used to control the optimization features of small-bandwidth cells, such as 1.4 MHz, 3 MHz, and 5 MHz cell.

SMALL_BAND_RLC_OPT_SWITCH: If this option is selected, the eNodeB configures different heavy-UE number thresholds depending on the cell bandwidth configuration and performs optimization according to the settings of RlcParaAdaptSwitch and SrbRlcParaAdaptSwitch. Timer parameters related to the RlcParaAdaptSwitch optimization are set to the fixed value of 200 ms. Timer parameters related to the SrbRlcParaAdaptSwitch optimization are dependent on the GUI values. If this option is deselected, the eNodeB performs RLC optimization depending on the GUI values of the RlcParaAdaptSwitch and SrbRlcParaAdaptSwitch parameters. This option applies only to LTE FDD.

Idle Mode Extended DRX Switch

Indicates whether to enable idle mode eDRX for LTE UEs. For details about idle mode eDRX, see 3GPP TS 23.682. This parameter applies only to LTE FDD and LTE TDD.
