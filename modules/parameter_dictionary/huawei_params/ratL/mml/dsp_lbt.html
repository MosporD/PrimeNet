Display Cell LBT Status (DSP LBT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to view the status of LBT. This command applies only to LTE TDD cells.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query status of LBT with Local cell ID of 1, run the following command:
%DSP LBT: LocalCellId=1;
The result is shown as follows:
+++    0        2019-12-05 21:48:46
O&M    #806355094
%%DSP LBT: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

Display Cell LBT Status
-----------------------
                      Listen Before Talk Detect Time  =  2019-12-05 10:33:17
                  Listen Before Talk Transmit Status  =  On
Listen Before Talk Noise Interfere Power(0.1dBm/MHz)  =  -1200
(Number of results = 1)


---    END

Output Description

Field Description

Listen Before Talk Detect Time

Indicates the duration of listen before talk (LBT) for detecting interference and noise. This parameter applies only to LTE TDD.

Listen Before Talk Transmit Status

Indicates whether downlink transmission is enabled. This parameter applies only to LTE TDD.

Listen Before Talk Noise Interfere Power(0.1dBm/MHz)

Indicates the noise interference power detected by LBT. This parameter applies only to LTE TDD.
