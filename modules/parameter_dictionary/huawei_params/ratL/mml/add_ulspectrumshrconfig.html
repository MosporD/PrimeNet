Add ULSpectrumShrConfig (ADD ULSPECTRUMSHRCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to configure spectrum sharing parameters for UMTS and LTE spectrum sharing.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
ULSpectrumSharingConfigId UMTS and LTE Spectrum Sharing Config ID

Meaning: Indicates the cell configuration ID of UMTS and LTE spectrum sharing, which is unique within an eNodeB. This parameter applies only to LTE FDD.

GUI Value Range: 0~25

Unit: None

Actual Value Range: 0~25

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
PrbRsvType PRB Reserve Type

Meaning: Indicates the PRB reserving type of UMTS and LTE spectrum sharing. This option applies only to LTE FDD.

GUI Value Range: LTE_DL_AVAILABLE_PRB(LTE_DL_AVAILABLE_PRB), LTE_UL_AVAILABLE_PRB(LTE_UL_AVAILABLE_PRB), LTE_DL_HIGH_PRIORITY_PRB(LTE_DL_HIGH_PRIORITY_PRB), UMTS_CORE_SPECTRUM_1(UMTS_CORE_SPECTRUM_1), UMTS_CORE_SPECTRUM_2(UMTS_CORE_SPECTRUM_2), UMTS_CORE_SPECTRUM_3(UMTS_CORE_SPECTRUM_3), UMTS_CORE_SPECTRUM_4(UMTS_CORE_SPECTRUM_4), UMTS_LTE_SHARED_SPECTRUM(UMTS_LTE_SHARED_SPECTRUM), LTE_PUCCH_AVAILABLE_PRB(LTE_PUCCH_AVAILABLE_PRB)

Unit: None

Actual Value Range: LTE_DL_AVAILABLE_PRB, LTE_UL_AVAILABLE_PRB, LTE_DL_HIGH_PRIORITY_PRB, UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, UMTS_CORE_SPECTRUM_4, UMTS_LTE_SHARED_SPECTRUM, LTE_PUCCH_AVAILABLE_PRB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD
LtePrbStartIndex LTE PRB Start Index

Meaning: Indicates the start index of the PRB reserving. This option applies only to LTE FDD.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of LtePrbEndIndex must be greater than the value of LtePrbStartIndex in the ULSpectrumShrConfig MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When the PrbRsvType parameter is set to LTE_DL_AVAILABLE_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more available PRBs in the downlink of LTE, higher throughput, but fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_UL_AVAILABLE_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more available PRBs in the uplink of LTE, higher throughput, but fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_HIGH_PRIORITY_PRB: A greater difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more high-priority LTE PRBs and less impact on UMTS performance; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to UMTS_CORE_SPECTRUM_1, UMTS_CORE_SPECTRUM_2, UMTS_CORE_SPECTRUM_3, or UMTS_CORE_SPECTRUM_4, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more UMTS preferential spectrum resources, higher UMTS cell capacity in the uplink, fewer spectrum resources available to LTE CEUs in the uplink, and lower LTE cell capacity in the uplink; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to UMTS_LTE_SHARED_SPECTRUM, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that can be shared by UMTS and LTE and lower uplink capacity of LTE cells in the bufferzone; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to the opposite effects.

When the PrbRsvType parameter is set to LTE_PUCCH_AVAILABLE_PRB, a larger difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that can be used for LTE PUCCH, and fewer spectrum resources that UMTS can share with LTE; a smaller difference between the LtePrbStartIndex and LtePrbEndIndex parameter values leads to more spectrum resources that UMTS can share with LTE, but fewer spectrum resources for LTE PUCCH, which may lead to cell activation failure.

Applicable Mode: L-FDD
LtePrbEndIndex LTE PRB End Index

Meaning: Indicates the end index of the PRB reserving. This option applies only to LTE FDD.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Example

Configure spectrum sharing parameters for UMTS and LTE spectrum sharing as follows: UMTS and LTE Spectrum Sharing Config ID: 0, PRB Reserve Type: LTE_DL_AVAILABLE_PRB, LTE PRB Start Index: 0 LTE PRB End Index: 99, run the following command:
+++    0        2017-08-27 16:21:48
O&M    #806355002
%%ADD ULSPECTRUMSHRCONFIG: ULSpectrumSharingConfigId=0, PrbRsvType=LTE_DL_AVAILABLE_PRB, LtePrbStartIndex=0, LtePrbEndIndex=99;%%
RETCODE = 0  Operation succeeded.
