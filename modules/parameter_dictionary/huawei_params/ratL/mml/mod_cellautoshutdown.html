Modify Cell Automatic Shutdown Parameters (MOD CELLAUTOSHUTDOWN)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of automatic cell shutdown.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
CellAutoShutdownSwitch Cell Auto Shutdown Switch

Meaning: Indicates whether to enable automatic cell shutdown.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When the function takes effect, the cell does not provide services.

Applicable Mode: L
StartTime Start Time

Meaning: Indicates the start time of automatic cell shutdown.

GUI Value Range: 22:00:00~05:00:00

Unit: None

Actual Value Range: 22:00:00~05:00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the CellAutoShutdown MO, StartTime must be set to a time in the range of 22:00:00 to 05:00:00 of the next day.
  • The time specified by the StopTime parameter in a CellAutoShutdown MO must be at least one hour later than the time specified by the StartTime parameter in this MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this function takes effect, the cell does not provide services.

Applicable Mode: L
StopTime Stop Time

Meaning: Indicates the end time of automatic cell shutdown.

GUI Value Range: 23:00:00~06:00:00

Unit: None

Actual Value Range: 23:00:00~06:00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the CellAutoShutdown MO, StopTime must be set to a time in the range of 23:00:00 to 06:00:00 of the next day.
  • The time specified by the StopTime parameter in a CellAutoShutdown MO must be at least one hour later than the time specified by the StartTime parameter in this MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this function takes effect, the cell does not provide services.

Applicable Mode: L

Example

To modify Cell Auto Shutdown Configuration with the parameters as follows: Local Cell ID: 0, Cell Auto Shutdown Switch: ON, Start Time: 00:00:00, Stop Time: 06:00:00, run the following command:
MOD CELLAUTOSHUTDOWN: LocalCellId=0, CellAutoShutdownSwitch=ON, StartTime=00&00&00, StopTime=06&00&00;
