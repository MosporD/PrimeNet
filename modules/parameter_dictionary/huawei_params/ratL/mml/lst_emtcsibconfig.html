List eMTC SIB Configuration (LST EMTCSIBCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list eMTC SIB configurations.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local cell ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
EmtcSibId eMTC SIB ID

Meaning: Indicates the SIB type of an eMTC cell. SIB types supported by an eMTC cell include SIB2, SIB3, SIB4, SIB5, and SIB14. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: SIB2(SIB2), SIB3(SIB3), SIB4(SIB4), SIB5(SIB5), SIB14(SIB14)

Unit: None

Actual Value Range: SIB2, SIB3, SIB4, SIB5, SIB14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The EmtcSibPeriod parameter in the EmtcSibConfig MO can be set to INVALID only if the EmtcSibId in the EmtcSibConfig is set to SIB5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of eMTC SIB:
LST EMTCSIBCONFIG:;
The result is shown as follows:

Output Description

Field Description

Local Cell ID

Indicates the local cell ID. This parameter applies only to LTE FDD and LTE TDD.

eMTC SIB ID

Indicates the SIB type of an eMTC cell. SIB types supported by an eMTC cell include SIB2, SIB3, SIB4, SIB5, and SIB14. This parameter applies only to LTE FDD and LTE TDD.

eMTC SIB Period

Indicates the SIB transmission period in an eMTC cell. This parameter is valid only when the EmtcSibId parameter is set. If this parameter is set to RF32 and the EmtcSibId parameter is set to SIB2, the transmission period of SIB2 in an eMTC cell is 320 ms. This parameter applies only to LTE FDD and LTE TDD.
