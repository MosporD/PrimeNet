Display the dynamic SCC cell list of PCC (DSP PCCSCELLLIST)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the secondary serving cells (SCells) that are dynamically configured for the primary serving cells (PCells) on one primary component carrier (PCC) or all PCCs under the eNodeB. If the PccDlEarfcn parameter is set, SCells for PCells on the frequency specified by the PccDlEarfcn parameter are queried. If the PccDlEarfcn parameter is not set, SCells for PCells on all candidate PCCs in the eNodeB are queried. When the operating frequencies of the queried PCells or the SCells dynamically configured for the PCells belong to multiple bands, multiple downlink ARFCNs corresponding to the cell are displayed.

Note

Use this command to query the routes that are established in static mode for adaptive FCA under the eNodeB.

Parameters

ID Name Description
PccDlEarfcn PCC Downlink EARFCN

Meaning: Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the candidate PCC. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • PccDlEarfcn in a PccFreqCfg MO must be a valid frequency.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To query the dynamically configured SCells, run the following command: :
DSP PCCSCELLLIST:;
The result is shown as follows:

Output Description

Field Description

PCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of the PCell. This parameter applies only to LTE FDD and LTE TDD.

SCC Downlink EARFCN

Indicates the downlink E-UTRA absolute radio frequency channel number (EARFCN) of an SCell. This parameter applies only to LTE FDD and LTE TDD.

PCC eNodeB ID

Indicates the ID of the eNodeB that provides the primary component carrier (PCC).

PCC Local Cell ID

Indicates the local ID of the primary serving cell (PCell).

SCC eNodeB ID

Indicates the ID of the eNodeB that serves the secondary serving cell (SCell).

SCC Local Cell ID

Indicates the local ID of the SCell.

Path RTD Delay(0.1microsecond)

Indicates the inter-cell round-trip delay. The parameter value is expressed in the unit of 0.1 microsecond. In inter-eNodeB CA in centralized or distributed multi-BBU interconnection scenarios or relaxed backhaul scenarios, the RTD between the inter-eNodeB cells is measured at high precision of 0.1 microsecond and the reported and displayed value is the actual measurement result. The displayed value is 0 if the cells involved are intra-eNodeB intra-BBU cells or eX2 (or X2) interfaces are not required between the cells. The displayed value is NULL in the following situations: (1) A related eX2 or X2 interface is down or a port fault occurs. (2) An eX2 or X2 interface is being set up. (3) The RTD is being measured. In other situations, a number indicating the RTD over the eX2 or X2 interface is displayed.

PCC Cell FDD TDD Indication

Indicates the duplex mode of a primary serving cell (PCell). The value FDD indicates an FDD cell, the value TDD indicates a TDD cell, and the value UNKNOWN indicates an unknown cell.

SCC Cell FDD TDD Indication

Indicates the duplex mode of a secondary serving cell (SCell). The value FDD indicates an FDD cell, the value TDD indicates a TDD cell, and the value UNKNOWN indicates an unknown cell.
