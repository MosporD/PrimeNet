List Cell DL PDSCH Power Control Configuration (LST CELLDLPCPDSCH)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of cell PDSCH downlink power control.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of downlink power control on the PDSCH of a cell:
LST CELLDLPCPDSCH:;
The result is shown as follows:

Output Description

Field Description

Local cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

Center UE PA(dB)

Indicates the PA value of cell center UEs when DL ICIC is enabled. This parameter applies only to LTE FDD and LTE TDD.

Edge UE PA(dB)

Indicates the PA value of cell edge UEs when DL ICIC is enabled. This parameter applies only to LTE FDD and LTE TDD.

Cell Edge Load Evaluation Period(s)

Indicates the interval for evaluating the cell edge load when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This parameter applies only to LTE TDD networks.

Neighboring Cell Edge Load Threshold(%)

Indicates the threshold of the neighboring cell edge load for determining whether to increase the power of beamforming UEs at the edge of the local cell when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. If the neighboring cell edge load is greater than the threshold specified by this parameter, the power of corresponding beamforming UEs in the local cell edge is not increased. If the neighboring cell edge load is less than or equal to the specified threshold and the number of neighboring cells meeting this condition is less than or equal to a specified percentage, the power of corresponding beamforming UEs in the local cell edge is increased. This parameter applies only to LTE TDD networks.

Ratio of Cells Exceeding Neighboring Cell Edge Load Threshold(%)

Indicates the percentage of the number of neighboring cells whose cell edge load meets the specified threshold. This percentage is used to determine whether to increase the power of beamforming UEs when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. If the percentage of the number of neighboring cells meeting the cell edge load threshold is greater than the value of this parameter, the power of all beamforming UEs in the local cell is not increased. If the percentage of the number of neighboring cells meeting the cell edge load threshold is less than or equal to the value of this parameter, the power of beamforming UEs in the local cell is increased. This parameter applies only to LTE TDD networks.

BF User Power Boost Period(s)

Indicates the period during which the increased value of the beamforming UE power remains unchanged when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This parameter applies only to LTE TDD cells.

BF Mode User Adaptive Power A3 offset(0.5dB)

Indicates the offset for event A3 reporting when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This offset is the difference between the quality of a neighboring cell and that of the serving cell. If this parameter is set to a large value, event A3 is reported only if the signal quality of the neighboring cell is significantly better than that of the serving cell. This parameter applies only to LTE TDD networks.

BF Mode User Adaptive Power A6 offset(0.5dB)

Indicates the offset for event A6 reporting in CA scenarios when the BFModeUserAdptPwrSwitch check box is selected under the DlPcAlgoSwitch parameter. This offset is the difference between the quality of a neighboring cell and that of the serving cell. If this parameter is set to a large value, event A6 is reported only if the signal quality of the neighboring cell is significantly better than that of the serving cell. This parameter applies only to LTE TDD networks.

Remaining Power Use Strategy

Indicates whether to use the remaining power. If this parameter is set to OFF, the remaining power is not used. If this parameter is set to PORT_PWR_BALANCING and the CrsPortNum parameter is set to CRS_PORT_4, power is balanced among the ports. This parameter applies only to LTE FDD.
