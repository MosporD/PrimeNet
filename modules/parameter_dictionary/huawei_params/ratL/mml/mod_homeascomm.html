Modify Common Measurement Parameters for Handover (MOD HOMEASCOMM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the common measurement parameters for handover.

Note

None.

Parameters

ID Name Description
GapPatternType GAP measurement pattern

Meaning: Indicates the measurement gap pattern.

With gap-assisted measurement, the eNodeB configures periodic idle time for UEs in RRC_CONNECTED mode to measure cell signal quality on specified frequencies.

There are two gap patterns: pattern 0 and pattern 1. In pattern 0, the gap width is 6 ms and the repetition period is 40 ms. In pattern 1, the gap width is 6 ms and the repetition period is 80 ms. For details, see 3GPP TS 36.331. Pattern 0 and pattern 1 correspond to Gap Pattern Id "0" and Gap Pattern Id "1" in 3GPP TS 36.331, respectively. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: GAP_PATTERN_TYPE_0(GAP_PATTERN_TYPE_0), GAP_PATTERN_TYPE_1(GAP_PATTERN_TYPE_1)

Unit: None

Actual Value Range: GAP_PATTERN_TYPE_0, GAP_PATTERN_TYPE_1

MML Default Value: None

Recommended Value: GAP_PATTERN_TYPE_0(GAP_PATTERN_TYPE_0)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A shorter repetition period of measurement gaps results in a shorter time it takes to identify intra-RAT and inter-RAT neighboring frequencies, more samples per unit time, and a larger decrease in the maximum throughput of UEs performing gap-assisted measurements. A longer repetition period results in a longer time it takes to identify intra-RAT and inter-RAT neighboring frequencies, fewer samples per unit time, and a higher probability of handover failures and service drops.

Applicable Mode: L-FDD, L-TDD
EutranFilterCoeffRsrp EUTRAN RSRP filter coefficient

Meaning: Indicates the upper-layer filtering coefficient for RSRP measurements on E-UTRAN.

A larger value of this parameter indicates a stronger smoothing effect and higher resistance to fast fading, but it may weaken the tracing capability towards varying signals. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

DisuseStatement: In later versions, this eNodeB-level parameter will be replaced by the cell-level parameter, the EutranFilterCoeffRsrp parameter in the CellHoParaCfg MO. The configuration interface in this version supports synchronization and delivery of the settings of both the eNodeB-level and cell-level parameters. When operators deliver the settings, the cell-level parameter takes effect. Therefore, operators should use the cell-level parameter and avoid using the eNodeB-level parameter from then on.

DedicatedGapPatternType Dedicated Gap Pattern Type

Meaning: Indicates the CSFB gap-assisted measurement mode.

With gap-assisted measurement, the eNodeB configures periodic idle time for UEs in RRC_CONNECTED mode to measure cell signal quality on specified frequencies.

If the parameter is set to GAP_PATTERN_TYPE_0, the gap width is 6 ms and the repetition period is 40 ms. If the parameter is set to GAP_PATTERN_TYPE_1, the gap width is 6 ms and the repetition period is 80 ms. GAP_PATTERN_TYPE_0 maps to Gap Pattern Id "0" and GAP_PATTERN_TYPE_1 maps to Gap Pattern Id "1" in 3GPP specifications. For details, see 3GPP TS 36.331. This parameter applies only to LTE FDD and LTE TDD.

Impact on Radio Network Performance: If this parameter is set to GAP_PATTERN_TYPE_0, it takes a shorter time to identify neighboring frequencies for CSFB, more samples exist per unit time, and a larger decrease is caused in the maximum throughput of UEs performing gap-assisted measurements. If this parameter is set to GAP_PATTERN_TYPE_1, it takes a longer time to identify neighboring frequencies for CSFB, fewer samples exist per unit time, and there is a higher probability of handover failures and service drops.

Applicable Mode: L-FDD, L-TDD

Example

Example 1: To modify the common parameters related to the handover measurement as follows: GAP measurement pattern: GAP_PATTERN_TYPE_1, EUTRAN RSRP filter coefficient: FC0, EUTRAN RSRQ filter coefficient: FC0, GERAN filter coefficient: FC0, run the following command:
MOD HOMEASCOMM: GapPatternType=GAP_PATTERN_TYPE_1, EutranFilterCoeffRsrp=FC0, EutranFilterCoeffRsrq=FC0, GeranFilterCoeff=FC0;
Example 2: To modify the common parameters related to the handover measurement as follows: EUTRAN RSRP filter coefficient: FC2, GERAN filter coefficient: FC1, run the following command:
MOD HOMEASCOMM: EutranFilterCoeffRSRQ=FC2, GeranFilterCoeff=FC1;
