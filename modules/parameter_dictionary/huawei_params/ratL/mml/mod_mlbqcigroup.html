Modify Mlb Qci Group (MOD MLBQCIGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify a QCI-specific mobility load balancing (MLB) parameter group.

Note

None.

Parameters

ID Name Description
MlbQciGroupId Mlb Qci Group ID

Meaning: Indicates the ID of a mobility load balancing (MLB) parameter group for a QCI. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~9

Unit: None

Actual Value Range: 0~9

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
UlMinQoSBitRate Uplink Minimum Qos Bit Rate

Meaning: Indicates the uplink minimum guaranteed bit rate. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50000

Unit: kbit/s

Actual Value Range: 0~50000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: The setting of this parameter affects the results of load evaluation. A larger value of this parameter results in a larger evaluation value of the QCI-specific PRB usage of uplink services. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
DlMinQoSBitRate Downlink Minimum Qos Bit Rate

Meaning: Indicates the downlink minimum guaranteed bit rate. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~50000

Unit: kbit/s

Actual Value Range: 0~50000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: The setting of this parameter affects the results of load evaluation. A larger value of this parameter results in a larger evaluation value of the QCI-specific PRB usage of downlink services. A smaller value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To modify a QCI-specific MLB parameter group with MLB QCI identity of 0, UlMinQoSBitRate of 1000Kbps, and DlMinQoSBitRate of 2000Kbps, run the following command:
MOD MLBQCIGROUP: MlbQciGroupId=0, UlMinQoSBitRate=1000, DlMinQoSBitRate=2000;
