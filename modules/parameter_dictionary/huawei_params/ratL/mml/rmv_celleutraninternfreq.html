Remove Neighboring E-UTRAN Frequency of Cell (RMV CELLEUTRANINTERNFREQ)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove a cell-specific neighboring E-UTRA frequency and its related configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The specified neighboring E-UTRA frequency and its related configuration data are removed after the command is executed successfully. Do not run other configuration commands before the command execution is complete. The command execution occupies CPU resources. Therefore, it is recommended that you run this command when traffic is very light, for example, in the early morning.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the cell ID of a local cell. It uniquely identifies a cell within an eNodeB.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
DlEarfcn Downlink EARFCN

Meaning: Indicates the DL EARFCN of the neighboring cell on the neighboring E-UTRAN frequency. For details, see the 3GPP TS 36.104.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • DlEarfcn in an EutranInterNFreq MO must be a valid frequency.
  • In an EutranInterNFreq MO, if DlEarfcn is specific to band 29, 32, 67, 69, 75, 76, UlEarfcnCfgInd must be set to NOT_CFG.
  • If the value of the DlEarfcn parameter in an EutranInterNFreq MO is specific to Band 111 or Band 222, the UlEarfcnCfgInd parameter must be set to CFG.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To remove a cell-specific neighboring E-UTRAN frequency with the parameters as follows: Local cell ID: 0, Downlink EARFCN: 3000, run the following command:
RMV CELLEUTRANINTERNFREQ: LocalCellId=0, DlEarfcn=3000;
