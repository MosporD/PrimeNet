List RRN Port (LST EURRNPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the RRN port configuration.

Note

None.

Parameters

ID Name Description
LocalSubscriberId Local Subscriber ID

Meaning: Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PN Port No.

Meaning: Indicates the transmission port number on the RRN. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the RRN port configuration information, run the following command: 
LST EURRNPORT:;
The result is shown as follows:
+++    613011        2014-07-19 18:10:19
O&M    #806354965
%%LST EURRNPORT:;%%
RETCODE = 0  Operation succeeded.

Query RRN Port
--------------
Local Subscriber ID  Port No.  Port Switch

10                   0         On         
10                   1         Off        
(Number of results = 2)


---    END

Output Description

Field Description

Local Subscriber ID

Indicates the local ID of a subscriber. It uniquely identifies a subscriber within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Port No.

Indicates the transmission port number on the RRN. This parameter applies only to LTE FDD and LTE TDD.

Port Switch

Indicates the switch controlling the transmission port on the RRN. This parameter applies only to LTE FDD and LTE TDD.
