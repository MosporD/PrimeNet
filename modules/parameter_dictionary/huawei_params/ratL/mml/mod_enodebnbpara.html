Modify eNodeB NB-IoT Configuration (MOD ENODEBNBPARA)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configurations of eNodeB-level NB-IoT parameters.

Note

None.

Parameters

ID Name Description
NbRsvMinUserNumRatio NB-IoT Reserved Minimum User Number Ratio

Meaning: Indicates the minimum proportion of UEs in RRC_CONNECTED mode reserved for NB-IoT. This parameter applies only to LTE FDD and NB-IoT.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates fewer UEs in RRC_CONNECTED mode reserved for NB-IoT and less impact on the specification of UEs in RRC_CONNECTED mode in LTE. A larger value of this parameter results in the opposite effects.

Applicable Mode: L-FDD, L-NB-IOT
NbExtendedPagingOptSwitch NB-IoT Extended Paging Optimization Switch

Meaning: Indicates whether to enable extended paging optimization for NB-IoT. If this parameter is set to ON, the eNodeB preferentially ensures capacity when adjusting the number of paging message transmission repetitions in the extended paging procedure. If this parameter is set to OFF, the eNodeB preferentially ensures coverage when adjusting the number of paging message transmission repetitions in the extended paging procedure. This parameter applies only to NB-IoT.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the paging capacity for NB-IoT increases but the paging success rate may decrease. If this parameter is set to OFF, the paging capacity for NB-IoT decreases but the paging success rate increases.

Applicable Mode: L-NB-IOT

Example

To modify the eNodeB NB-IoT Configuration with the parameters as follows: NB-IoT Reserved Minimum User Number Ratio: 10, run the following command:
MOD ENODEBNBPARA: NbRsvMinUserNumRatio=10;
