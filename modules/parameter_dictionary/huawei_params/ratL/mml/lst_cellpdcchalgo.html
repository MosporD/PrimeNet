List Cell PDCCH Algorithm Configuration (LST CELLPDCCHALGO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of the PDCCH resource allocation algorithm.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the Local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the configurations of the PDCCH algorithm:
LST CELLPDCCHALGO: LocalCellId=1;

Output Description

Field Description

Local cell ID

Indicates the Local ID of the cell. It uniquely identifies a cell within a BS. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Power Boost Upper Limit

Indicates the upper limit for the power increase during enhanced PDCCH power control, which is determined by the PdcchPowerEnhancedSwitch parameter. When the PdcchPowerBoostUpperLimit parameter is set to NULL, the default power increase upper limit of enhanced PDCCH power control is used. When the PdcchPowerBoostUpperLimit parameter is set to another value, the parameter value is used as the upper limit for the power increase. This parameter applies only to LTE FDD.

SignalCongregateLevel

Indicates the CCE aggregation level for common control signaling. If the HOSuccRateBoostOptSwitch option of the HoSignalingOptSwitch parameter is selected, the PDCCH CCE aggregation level is changed to level 8 when an RAR message for a handover is retransmitted. This parameter applies only to LTE FDD and LTE TDD.

Cce Ratio Adjust Switch

Indicates the CCE ratio adjustment switch for the PDCCH. If this parameter is set to ENHANCED_CCE_RATIO_ADJUSTMENT, the uplink-downlink CCE ratio is not dynamically adjusted in the event of uplink CCE allocation failure not caused by CCE resource insufficiency. If this parameter is set to ON, the PDCCH resource allocation algorithm dynamically adjusts the uplink-downlink CCE ratio in each TTI based on uplink and downlink CCE usages. If this parameter is set to OFF, the uplink-downlink CCE ratio is not dynamically adjusted. This parameter applies only to LTE FDD and LTE TDD.

SFN Pdcch DCS Threshold(0.5dB)

Indicates the threshold of isolation for determining whether to enable PDCCH selective transmission in adaptive SFN/SDMA scenarios. For a UE, if the ratio of the total RSRP of the RRUs providing strong signals to that of the RRUs providing weak signals is greater than or equal to this threshold, the eNodeB does not allocate power to the RRUs providing weak signals. This parameter applies only to LTE TDD.

PDCCH Initial Symbol Number

Indicates the number of OFDM symbols initially occupied by the PDCCH. If the switch for dynamic adjustment of the number of OFDM symbols occupied by the PDCCH is turned off, this parameter indicates the fixed number of OFDM symbols occupied by the PDCCH. For LTE TDD cells, this parameter indicates the number of OFDM symbols initially occupied by the PDCCH in the downlink subframes in which only downlink scheduling control information is transmitted. If the switch for dynamic adjustment of the number of OFDM symbols occupied by the PDCCH is turned on and the bandwidth is 1.4 MHz or 3 MHz, the PDCCH occupies 4 or 3 OFDM symbols, respectively, and this parameter is invalid. If the switch is turned on and the bandwidth is 5 MHz, 10 MHz, 15 MHz, or 20 MHz, the eNodeB adjusts the number of OFDM symbols in the range of 1, 2, and 3 when this parameter is set to the default value 1, or in the range of 2 and 3 when this parameter is set to 2 or 3. For LTE TDD cells, if the switch is turned on and the bandwidth is 5 MHz, the eNodeB adjusts the number of OFDM symbols in the range of 2 and 3 by default, and this parameter is invalid. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of the startSymbolBR-r13 IE is changed due to modification of this parameter, eMTC UEs that already accessed the cell will be proactively released. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Virtual Loading Proportion(%)

Indicates the percentage of the number of virtually loaded PDCCH CCEs when the PDCCH power control switch is turned off, or indicates the percentage of the power of virtually loaded PDCCH CCEs when the PDCCH power control switch is turned on. This parameter is used to analyze the impact of the parameter values on PDCCH demodulation performance and provide reference to intra-frequency networking in LTE. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Initial Cce Adjustment Value

Indicates the PDCCH initial aggregation level adjustment. This parameter applies only to LTE FDD.

PDCCH Symbol Number Adjust Switch

Indicates whether to enable dynamic adjustment on the number of OFDM symbols occupied by the PDCCH.

If this parameter is set to OFF, the number of OFDM symbols occupied by the PDCCH is fixed.

If this parameter is set to ON, the number of OFDM symbols occupied by the PDCCH is dynamically adjusted based on the required number of control channel elements (CCEs). The OFDM symbol number adjustment range can be determined by referring to the MML reference of the InitPdcchSymNum parameter.

If this parameter is set to ECFIADAPTIONON, the number of OFDM symbols occupied by the PDCCH is dynamically adjusted with the aim of achieving optimal downlink throughput. The OFDM symbol number adjustment range can be determined by referring to the MML reference of the InitPdcchSymNum parameter.

If this parameter is set to MM_HEAVY_LOAD_ECFI_ADAPT_ON: (1) When the control channel capacity is limited, the number of CCEs required by the massive MIMO cell in the current TTI is estimated to determine the CFI for the current TTI. (2) When the control channel capacity is not limited, the CFI for the current TTI is determined in the same way as when this parameter is set to ECFIADAPTIONON. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in the CellEmtcAlgo MO is selected and the startSymbolBR-r13 IE value changes due to modification to this parameter, the eNodeB releases eMTC UEs in the cell.

This parameter applies only to LTE FDD and LTE TDD.

CCE use ratio(%)

Indicates the upper limit of the CCE usage within each transmission time interval (TTI). When the PdcchSymNumSwitch parameter in the CellPdcchAlgo MO is set to ON(On), the parameter setting is invalid, that is, the CCE usage cannot be limited within each TTI. This parameter applies only to LTE TDD.

PDCCH Aggregation Level CL Switch

Indicates the switch used to enable or disable closed-loop adjustment to the PDCCH aggregation level. If this switch is turned on, PDCCH aggregation level is adjusted based on the block error rate (BLER) of the PDCCH. If this switch is turned off, PDCCH aggregation level is not adjusted based on the BLER of the PDCCH. This parameter applies only to LTE FDD and LTE TDD.

DPD Virtual Load Switch

Indicates whether to enable virtual loading for digital predistortion (DPD). This parameter applies only to LTE TDD.

DPD Virtual Load Type

Indicates the virtual loading type for digital predistortion (DPD). This parameter applies only to LTE TDD.

Aggregation Level Strategy for Dual Codewords

For FDD, this parameter indicates the PDCCH CCE aggregation level selection policy used in dual-codeword transmission scenarios. The capacity-based selection policy is the default policy. If this policy is used, a low CCE aggregation level is selected in dual-codeword transmission scenarios, allowing PDCCH resources to be allocated to more UEs. If the coverage-based selection policy is used, a high CCE aggregation level is selected in dual-codeword transmission scenarios, improving cell coverage performance. For TDD, this parameter indicates the PDCCH CCE aggregation level selection policy used in dual-codeword transmission scenarios, when the PDCCH CCE aggregation level adaptation policy is coverage-oriented. The capacity-based selection policy is the default policy. If this policy is used, a low CCE aggregation level is selected in dual-codeword transmission scenarios, allowing PDCCH resources to be allocated to more UEs. If the coverage-based selection policy is used, a high CCE aggregation level is selected in dual-codeword transmission scenarios, improving cell coverage performance. This parameter does not take effect when the PDCCH aggregation level adaptation policy is capacity-oriented. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Capacity Improve Switch

Indicates whether to enable optimization on PDCCH capacity expansion. For LTE FDD networks, if this parameter is set to ON(On), (1) the initial value for closed-loop adjustment on PDCCH aggregation level applies only to SRBs; (2) if a UE fails to be allocated CCEs, the eNodeB reallocates CCEs to the UE by increasing the PDCCH power and decreasing the PDCCH aggregation level for the UE. If this parameter is set to OFF(Off), (1) the initial value for closed-loop adjustment on PDCCH aggregation level applies to both SRBs and DRBs; (2) if a UE fails to be allocated CCEs, the eNodeB does not reallocate CCEs to the UE by increasing the PDCCH power and decreasing the PDCCH aggregation level for the UE. For LTE TDD networks, if this parameter is set to ON(On), the eNodeB reallocates CCEs to a UE, if the UE fails to be allocated CCEs, by increasing the PDCCH power and decreasing the PDCCH aggregation level for the UE. If this parameter is set to OFF(Off), the eNodeB does not reallocate CCEs to a UE, if the UE fails to be allocated CCEs, by increasing the PDCCH power and decreasing the PDCCH aggregation level for the UE. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Max Code Rate

Indicates the maximum coding rate on the PDCCH. The coding rate on the PDCCH cannot exceed this parameter value. Otherwise, the PDCCH aggregation level must be increased. This parameter applies only to LTE FDD and LTE TDD.

Uplink and Downlink PDCCH Symbols Configuration

Indicates the number of OFDM symbols initially occupied by the PDCCH in the downlink subframe in which uplink and downlink scheduling control information is transmitted. If the PDCCH Symbol Number Adjust Switch parameter is set to OFF, this parameter indicates the fixed number of OFDM symbols occupied by the PDCCH in the downlink subframe in which uplink and downlink scheduling control information is transmitted. For downlink subframes in which both uplink and downlink scheduling control information is transmitted, if the PDCCH Symbol Number Adjust Switch parameter is set to ON, the number of OFDM symbols occupied by the PDCCH is as follows: On the bandwidth of 5 MHz, the PDCCH occupies 2 or 3 OFDM symbols. (In this case, the configuration of this parameter is invalid.) On the bandwidth of 10 MHz, 15 MHz, or 20 MHz, the PDCCH occupies 1, 2, or 3 OFDM symbols when this parameter is set to 1, and the PDCCH occupies 2 or 3 OFDM symbols when this parameter is set to 2 or 3. If the EMTC_SWITCH option of the EmtcAlgoSwitch parameter in a CellEmtcAlgo MO is selected and the value of the startSymbolBR-r13 IE is changed due to modification of this parameter, eMTC UEs that already accessed the cell will be proactively released. This parameter applies only to LTE TDD. When the PhichDuration parameter in the PHICHCfg MO is set to EXTENDED and the cell bandwidth is 1.4 MHz, this parameter must be set to 3(3) according to 3GPP specifications. Therefore, value 3(3) takes effect automatically even if this parameter is set to another value.

The Strategy Of PDCCH Aggregation Level Adaptation

Indicates the adaptation strategy of the CCE aggregation level for the PDCCH. For LTE TDD cells, the coverage-based PDCCH aggregation level adaptation strategy is used by default. This strategy leads to a higher PDCCH aggregation level and better cell coverage provided by the PDCCH but fewer UEs scheduled on the PDCCH. The capacity-based PDCCH aggregation level adaptation strategy leads to a lower PDCCH aggregation level but more UEs scheduled on the PDCCH.

For NB-IoT cells, the coverage-based PDCCH aggregation level adaptation strategy is used by default. This strategy slows down the adjustment of the NPDCCH aggregation level and the number of repetitions to guarantee cell-edge coverage. The capacity-based PDCCH aggregation level adaptation strategy speeds up the adjustment of the NPDCCH aggregation level and the number of repetitions based on channel quality.

This parameter applies only to LTE TDD and NB-IoT.

Hysteresis for CFI increase based on PreSch

Indicates whether to increase the number of PDCCH symbols in case of uplink preallocation failure when PdcchSymNumSwitch is set to ECFIADAPTIONON. If this parameter is set to 0, the eNodeB does not increase the number of PDCCH symbols in case of preallocation failure. If this parameter is set to 1, the eNodeB increases the number of PDCCH symbols in case of preallocation failure. This parameter applies only to LTE FDD and LTE TDD.

SFN PDCCH SDMA Threshold(0.5dB)

Indicates the threshold of isolation for determining whether to enable PDCCH SDMA in adaptive SFN/SDMA scenarios. For a UE, if the ratio of the total RSRP of signals collaboratively received from RRUs providing strong signals to that from RRUs providing weak signals is greater than or equal to this threshold, the UE uses only the RRUs providing strong signals, and the RRUs providing weak signals serve other UEs. This parameter applies only to LTE TDD.

UL PDCCH Alloc Improve Switch

Indicates whether to enable the mechanism of increasing the control channel element (CCE) resource allocation success rate in the uplink. ReserveCommonCCESwitch: Indicates whether to reserve CCE resources in the common search space for the uplink. CCE resources in the common search space are reserved for the uplink only when this switch is on. This parameter applies only to LTE FDD and LTE TDD.

CCE Max Initial Ratio

Indicates the maximum ratio of uplink to downlink initial CCEs on the PDCCH. If this parameter is set to 1_2, the maximum uplink-downlink initial CCE ratio is 1:2. If this parameter is set to a value greater than 1_2, the maximum uplink-downlink initial CCE ratio can be dynamically changed to any value ranging from 1_2 to the configured value based on the load in the uplink and downlink. If subframe configuration 2 is adopted for an LTE TDD cell, it is recommended that the SubframeSchDiffSwitch option be selected to ensure the PRB usage on subframes 3 and 8. This parameter applies only to LTE TDD.

PDCCH Power Enhanced Switch

Indicates whether to enable PDCCH power control enhancement and specifies the enhancement scope. If this parameter is set to ON_ALL, ON_EXPANDED_RANGE, or ON_BASIC_RANGE, the eNodeB selects an appropriate power value based on the PDCCH quality to increase the PDCCH capacity. The value ON_ALL indicates that the enhancement takes effect in all scenarios. The value ON_BASIC_RANGE indicates that the enhancement takes effect only in basic scenarios. The value ON_EXPANDED_RANGE indicates that the enhancement takes effect in more scenarios than when this parameter is set to ON_BASIC_RANGE.

For FDD, this parameter can be configured in all scenarios.

For TDD, this parameter applies only to massive MIMO cells where the aggregation level is selected based on capacity and cannot be set to ON_EXPANDED_RANGE or ON_BASIC_RANGE.

PDCCH BLER Target

Indicates the target BLER in PDCCH link adaptation. The PDCCH BLER must converge on this target BLER. This parameter applies only to LTE FDD and LTE TDD.

HL Net Access Signal Aggregation Lvl Select Enhance Switch

Indicates whether to enable enhanced aggregation level selection for access signaling on high load networks. If this parameter is set to ON(On), the eNodeB accurately estimates the channel conditions when a UE accesses a high load network where PDCCH resources are insufficient, and selects a PDCCH aggregation level for the UE that better matches the UE's actual signal quality. It is recommended that this parameter be set to ON(On) and the PuschDtxSchOptSwitch option of the UlSchSwitch parameter in the CellAlgoSwitch MO be selected. If this parameter is set to OFF(Off), the eNodeB selects a high aggregation level for all access signaling to ensure the PDCCH reliability. This parameter applies only to LTE FDD and LTE TDD.

EPDCCH Algorithm Switch

Indicates whether to enable algorithms related to the EPDCCH. EpdcchFunctionSwitch: Indicates whether to support EPDCCH. If this option is selected, EPDCCH is supported. This option applies only to LTE FDD and LTE TDD.

CCE Usage Threshold To Enable EPDCCH

Indicates the CCE usage threshold for configuring the EPDCCH. If the CCE usage is greater than this parameter value, the eNodeB configures EPDCCH resources for newly accessed UEs. This parameter applies only to LTE FDD and LTE TDD.

RB Usage Threshold To Enable EPDCCH

Indicates the downlink RB usage threshold for configuring EPDCCH. If the downlink RB usage is less than this parameter value, the eNodeB configures EPDCCH resources for newly accessed UEs. This parameter applies only to LTE FDD and LTE TDD.

CCE Usage Threshold To Disable EPDCCH

Indicates the CCE usage threshold for disabling EPDCCH. If the CCE usage is lower than this parameter value, the eNodeB disables the EPDCCH. This parameter applies only to LTE FDD and LTE TDD.

ECCE Usage Threshold To Disable EPDCCH

Indicates the ECCE usage threshold for disabling EPDCCH. If the ECCE usage is lower than this parameter value, the eNodeB disables the EPDCCH. This parameter applies only to LTE FDD and LTE TDD.

RB Usage Threshold To Disable EPDCCH

Indicates the downlink RB usage threshold for disabling EPDCCH. If the downlink RB usage is greater than this parameter value, the eNodeB disables the EPDCCH. This parameter applies only to LTE FDD and LTE TDD.

High Load Net Access Signal Attempt

Indicates whether to enable functions related to enhanced aggregation level selection for access signaling on high load networks. MSG5Attempt: Indicates whether to enable enhanced aggregation level selection for MSG5. If this option is selected, enhanced aggregation level selection is enabled for MSG5. If this option is deselected, enhanced aggregation level selection is disabled for MSG5. This option applies only to LTE TDD.

EPDCCH Subframe Configuration

Indicates whether the enhanced physical downlink control channel (EPDCCH) is configured only on downlink subframes that carry the uplink and downlink scheduling control information or in all downlink subframes after the EPDCCH is started. This parameter takes effect only in LTE TDD cells that use uplink-downlink subframe configuration 2. This parameter applies only to LTE TDD.

UL DL ECCE Initial Ratio Adjustment Switch

Indicates whether to enable adaptive adjustment of the initial ratios of the uplink and downlink enhanced control channel elements (eCCEs). If this parameter is set to ON(On), the initial ratios of uplink and downlink eCCEs can be dynamically adjusted in the range from 1 to Max(CceMaxInitialRatio, 1) based on the uplink and downlink loads. If this parameter is set to OFF(Off), the initial ratios of uplink and downlink eCCEs are fixed to be Max(CceMaxInitialRatio, 1). This parameter applies only to LTE TDD cells.

BF Opt for Capacity-based PDCCH Aggregation

Indicates whether to optimize the calculation of the beamforming gain for capacity-based PDCCH aggregation level adaptation. This parameter applies only to LTE TDD cells.

Flow Control Enable CCE Threshold(%)

Indicates the upper threshold of CCE usage. If the percentage of CCEs consumed by SRBs is larger than this threshold, the eNodeB triggers MSG3 flow control. This parameter applies only to LTE FDD and LTE TDD.

Flow Control Disable CCE Threshold(%)

Indicates the lower threshold of CCE usage. If the percentage of CCEs consumed by SRBs is smaller than this threshold, the eNodeB cancels MSG3 flow control, or does not trigger MSG3 flow control. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Power Upper Limit Optimization Switch

Indicates whether to raise the PDCCH power increase limit. If this parameter is set to ON(On), the eNodeB raises the PDCCH power increase limit in the subframes allocated uplink and downlink CCEs when the CceMaxInitialRatio parameter in the CellPdcchAlgo is set to a large value. If this parameter is set to OFF(Off), the eNodeB does not raise the PDCCH power increase limit in the subframes allocated uplink and downlink CCEs when the CceMaxInitialRatio parameter in the CellPdcchAlgo MO is set to a large value. This parameter applies only to LTE TDD.

PDCCH Spare Power Allocation Strategy

Indicates the spare PDCCH power allocation strategy. When this parameter is set to NONE, spare PDCCH power is not allocated. When this parameter is set to WEAKCOVERAGEUSER, spare power of the PDCCH with the current CFI is allocated to UEs with weak coverage. When this parameter is set to BIGPKTUSER, spare power of the PDCCH with the current CFI is allocated to UEs with large-packet transmission. This parameter applies only to LTE FDD and LTE TDD.

Volte PDCCH SINR Offset(0.1dB)

Indicates the PDCCH SINR offset of voice UEs. This parameter is used to adjust the PDCCH aggregation level and PDCCH power for such UEs. If this parameter is set to 0, adjustment of the PDCCH aggregation level and PDCCH power does not take effect. It is recommended that this parameter be set to 30 for cells with few voice UEs. This helps improve the transmission reliability of the control channel occupied by voice UEs. This parameter applies only to LTE FDD and LTE TDD.

Enhanced PDCCH DL Agg Lev Selection

Indicates whether to optimize PDCCH aggregation level selection. The PDCCH BLER caused due to no responses from the UE is used as a reference for PDCCH aggregation level selection only when this parameter is set to ON. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Out Loop Adjustment Baseline Step(0.1dB)

Indicates the baseline step used for outer-loop adjustment of the PDCCH. The selection of an appropriate step for the adjustment is dependent on this baseline step. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Out Loop Adjustment Value Lower Thld(dB)

For FDD: indicates the lower limit of the adjustment amount for outer-loop adjustment of the PDCCH.

For TDD: indicates the lower limit of the initial adjustment amount for outer-loop adjustment of the PDCCH. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Adjust Algorithm Switch

Indicates whether to enable optimization functions related to the PDCCH adjustment algorithm. This parameter applies only to LTE FDD and LTE TDD.

CCE8PcOptSwitch: Indicates the basis of performing dynamic power control for UEs with a CCE aggregation level of 8 when the CCE aggregation level is adjusted based on capacity. If this option is selected, the PDCCH power for UEs with a CCE aggregation level of 8 is dynamically adjusted based on PDCCH quality. This option applies only to LTE TDD.

AggLvl8PwrIncreaseUpperLimitSw: Indicates whether to enable power increase limiting for the PDCCH aggregation level 8. If this option is selected, the PDCCH aggregation level of downlink retransmission UEs is 8, and the number of RRC_CONNECTED UEs is greater than the value of the PdcchPwrCtrlUserNumThd parameter in the CellPdcchAlgo MO, an upper power increase limit is set for this aggregation level. If this option is deselected, no upper power increase limit is set for downlink retransmission UEs with the PDCCH aggregation level 8. This option applies only to LTE TDD.

EnhCfiAdptOptSwitch: Indicates whether to enable enhanced CFI adaptation optimization for 8T8R. This option is valid only when the PdcchSymNumSwitch parameter is set to ECFIADAPTIONON. If this option is selected, CCE resources increase in 8T8R heavy-load scenarios and therefore the number of scheduled UEs also increases in these scenarios. When this option is deselected, the optimization does not take effect and the enhanced CFI adaptation function is used. This option applies only to LTE TDD.

PdcchRobustnessEnhSw: Indicates whether to enable the PDCCH robustness enhancement algorithm. If this option is selected, the PDCCH robustness enhancement algorithm is enabled. If this option is deselected, the PDCCH robustness enhancement algorithm is disabled. This option applies only to LTE FDD.

PDCCH Split Beam SDMA Threshold(0.5dB)

Indicates the threshold of isolation for deciding whether to perform SDMA for PDCCH transmission in beam splitting scenarios. For a UE, if the ratio of the RSRP of combined beams providing strong signals to that of providing weak signals in a cell is greater than or equal to this threshold during PDCCH transmission in beam splitting scenarios, the UE uses the resources allocated to beams providing strong signals, and resources allocated to beams providing weak signals can be used by other UEs. This parameter applies only to TDD massive MIMO cells.

NACK and DTX Ratio Threshold(%)

Indicates the threshold, which is the proportion of the sum of NACKs and DTXs to the sum of ACKs, NACKs, and DTXs of uplink HARQ feedback for downlink scheduling, for stopping scheduling a UE. If the proportion of the sum of NACKs and DTXs to the sum of ACKs, NACKs, and DTXs for downlink scheduling of a UE is higher than this threshold, the eNodeB stops initial transmission and retransmission of DRBs for the UE in a certain period. If this parameter is set to 0, the eNodeB does not stop initial transmission and retransmission of DRBs for UEs based on the proportion of the sum of NACKs and DTXs to the sum of ACKs, NACKs, and DTXs. This parameter applies only to LTE TDD.

PDCCH Split Beam SDMA Switch

Indicates whether to perform SDMA for PDCCH split beams.

MASSIVE_MIMO_PDCCH_SDMA_SW: If this option is selected, SDMA is performed for PDCCH split beams. If this option is deselected, joint transmission is always performed for PDCCH split beams. This option applies only to LTE TDD.

MASSIVE_MIMO_PDCCH_MEAS_SW: If this option is selected, PDCCH beam association measurement is performed for UEs in massive MIMO scenarios. If this option is deselected, PDCCH beam association measurement is disabled for UEs in massive MIMO scenarios. This option applies only to LTE TDD.

PDCCH Power Control User Num Threshold

Indicates whether to perform PDCCH power optimization for heavy-load networks, and specifies the threshold of the number of UEs for triggering the optimization. If this parameter is set to 65535, PDCCH power optimization is disabled for heavy-load networks. If this parameter is set to a value ranging from 0 to 1050, PDCCH power optimization is enabled for heavy-load networks, and the eNodeB uses this threshold to determine whether to perform the optimization. This parameter applies only to LTE TDD.

PDCCH Beamforming Gain Offset

Indicates the PDCCH beamforming gain offset for D-MIMO cells when the PDCCH aggregation level is selected based on coverage. If this parameter is set to -127, optimization of PDCCH beamforming gain offset is disabled. If this parameter is set to a value ranging from -10 to 10, optimization of PDCCH beamforming gain offset is enabled, and the offset is specified by this parameter. This parameter applies only to LTE TDD.

VoLTE PDCCH Optimize Switch

Indicates whether to optimize the PDCCH for VoLTE UEs.

VOLTE_PDCCH_CCE_SELECT_SWITCH: Indicates whether to optimize the selection of PDCCH CCE aggregation levels. If this option is deselected, the eNodeB does not optimize selection of the PDCCH CCE aggregation levels for VoLTE UEs. If this option is selected, the eNodeB optimizes the selection of PDCCH CCE aggregation levels for VoLTE UEs. This parameter applies only to LTE FDD and LTE TDD.

CFI Adjustment CCE Threshold

Indicates the CCE threshold of enhanced CFI adaptation.

This parameter is valid only when the PdcchSymNumSwitch parameter is set to ECFIADAPTIONON.

This parameter applies only to LTE FDD.

Voice UE PDCCH Outer-Loop Adj Lower Limit(dB)

Indicates the lower limit of outer-loop adjustment to the PDCCH aggregation level and whether to enable optimized CCE aggregation level selection for PDCCH for voice and air interface acceleration UEs. For FDD, if this parameter is set to 255, the value of the PdcchOutLoopAdjLowerLimit parameter in the CellPdcchAlgo MO is used as the lower limit of outer-loop adjustment to the PDCCH aggregation level for voice and air interface acceleration UEs. In addition, optimized CCE aggregation level selection for PDCCH for air interface acceleration UEs is disabled. If this parameter is set to a value other than 255, the VoicePdcchOtLpAdjLowerLmt parameter value is used as the lower limit of outer-loop adjustment to the PDCCH aggregation level for voice and air interface acceleration UEs. In addition, optimized CCE aggregation level selection for PDCCH for air interface acceleration UEs is enabled. For TDD, if this parameter is set to 255, optimized CCE aggregation level selection for PDCCH for air interface acceleration UEs is disabled. If this parameter is set to a value other than 255, optimized CCE aggregation level selection for PDCCH for air interface acceleration UEs is enabled. This parameter applies only to LTE FDD and LTE TDD.

PDCCH Optimization Switch

Indicates whether to enable PDCCH optimization for TDD macro cells.

LOW_AGG_PREFERENTIAL_SCH_SW: If this option is selected, preferential scheduling for UEs with a low aggregation level is enabled. If this option is deselected, preferential scheduling for UEs with a low aggregation level is disabled. This option applies only to LTE TDD.

HEAVY_LOAD_BIG_PKT_SCH_OPT_SW: Indicates whether to enable the following two functions in heavy-load scenarios: large-packet scheduling optimization, and CCE selection optimization for cell-center UEs or UEs at a medium distance from the cell center. The two functions are enabled only if this option is selected. This option applies only to LTE TDD.

SF_3_8_HARQ_SELECTIVE_SCH_SW: Indicates whether to enable selective HARQ scheduling in subframe 3 or 8. If this option is selected, selective HARQ scheduling in subframe 3 or 8 is enabled. If this option is deselected, selective HARQ scheduling in subframe 3 or 8 is disabled. This option applies only to LTE TDD.

Split Beam PDCCH SDMA Threshold Offset

Indicates the offset to the isolation threshold for UEs with PDCCH aggregation levels of 4 and 8 when SDMA is performed for PDCCH transmission in beam splitting scenarios. The actual isolation threshold for UEs with PDCCH aggregation levels of 4 and 8 is the sum of this offset and the SplitBeamPdcchSdmaThd parameter. The value THRESHOLD_OFFSET_0 indicates that the offset is 0 dB. The value THRESHOLD_OFFSET_1 indicates that the offset is -1 dB for UEs with the PDCCH aggregation level of 4 and -2 dB for UEs with the PDCCH aggregation level of 8. The value THRESHOLD_OFFSET_2 indicates that the offset is -2 dB for UEs with the PDCCH aggregation level of 4 and -4 dB for UEs with the PDCCH aggregation level of 8. The value THRESHOLD_OFFSET_3 indicates that the offset is -3 dB for UEs with the PDCCH aggregation level of 4 and -6 dB for UEs with the PDCCH aggregation level of 8. This parameter applies only to LTE TDD.

PDCCH SDMA Weight Type

Indicates the weight type for PDCCH SDMA in massive MIMO scenarios. If this parameter is set to PREFERENTIAL_COV_GUARANTEE, a weight type guaranteeing coverage is preferred. If this parameter is set to PREFERENTIAL_ENHANCED_SDMA, a weight type guaranteeing space division gains is preferred. This parameter value is valid only when the CoverageScenario parameter is set to SCENARIO_2(HBW 65 Degree, VBW 8 Degree) or SCENARIO_6(HBW 65 Degree, VBW 17 Degree). If this parameter is set to POWER_SHARING_AMONG_3_BEAMS, power sharing among three beams is enabled. If this parameter is set to POWER_SHARING_AMONG_4_BEAMS, power sharing among four beams is enabled. If this parameter is set to POWER_SHARING_AMONG_5_BEAMS, power sharing among five beams is enabled. This parameter applies only to LTE TDD.

PDCCH Power Check Switch

Indicates whether to enable PDCCH symbol power check. If this parameter is set to OFF, the eNodeB does not check the PDCCH symbol power. If this parameter is set to SYMBOL_0_POWER_CHECK, the eNodeB checks the power of PDCCH symbol 0 to ensure that the power of this symbol does not exceed the RRU single-channel power. If the power of this symbol exceeds the RRU single-channel power, CCE allocation fails. This parameter applies only to LTE FDD and LTE TDD.

HARQ-ACK Feedback Mode Optimization Thld(%)

Indicates the threshold for optimizing the HARQ-ACK feedback mode. If HARQ-ACK feedback mode optimization is enabled, the PDCCH load in the cell is greater than this threshold, and the single-frame scheduling mode is used for the UEs, the HARQ-ACK feedback mode of the UEs is reconfigured to the multiplexing mode. This parameter applies only to LTE TDD.

PDCCH Beamforming Switch

Indicates whether to enable PDCCH beamforming.

MASSIVE_MIMO_PDCCH_BF_SW: If this option is selected, UE-specific beam weighting is performed to transmit the PDCCH data in massive MIMO scenarios. If this option is deselected, broadcast beam is performed to transmit the PDCCH data in massive MIMO scenarios. This option applies only to LTE TDD.

Abnormal UE PDCCH Opt CCE Usage Thld(%)

Indicates the equivalent CCE usage threshold used for evaluating whether to enable the function of PDCCH optimization for defective UEs. If this parameter is set to a non-zero value, the function is enabled. If this parameter is set to 0, the function is disabled. This parameter applies only to LTE TDD.

Abnormal UE PDCCH Opt CQI Thld

Indicates the CQI threshold of UEs used for evaluating whether to enable the function of PDCCH optimization for defective UEs. This parameter applies only to LTE TDD.
