List CN Operator Sharing Group Configuration (LST CNOPSHARINGGROUP)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of a carrier-sharing operator group.

Note

None.

Parameters

ID Name Description
CnOpSharingGroupId CN Operator Sharing Group ID

Meaning: Indicates the ID of a carrier-sharing operator group. This parameter uniquely specifies a carrier-sharing operator group.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To list the configurations of a carrier-sharing operator groups with the following parameter: CN Operator Sharing Group ID: 0, run the following command:
LST CNOPSHARINGGROUP: CnOpSharingGroupId=0;
The result is shown as follows:
+++    HUAWEI        2014-06-18 11:03:29
O&M    #808452138
%%LST CNOPSHARINGGROUP: CnOpSharingGroupId=0;%%
RETCODE = 0  Operation succeeded.

List CN Operator Sharing Group Configuration
--------------------------------------------
CN Operator Sharing Group ID  =  0
         Primary Operator ID  =  0
(Number of results = 1)


---    END

Output Description

Field Description

CN Operator Sharing Group ID

Indicates the ID of a carrier-sharing operator group. This parameter uniquely specifies a carrier-sharing operator group.

Primary Operator ID

Indicates the ID of the primary operator in a carrier-sharing operator group.

Secondary Operator List

Indicates the list of secondary operators in a carrier-sharing operator group.
