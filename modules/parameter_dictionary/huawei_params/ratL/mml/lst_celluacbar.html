List Cell UAC Barring Information (LST CELLUACBAR)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query UAC barring configurations for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
AccessCategory Access Category

Meaning: Indicates the access category of services in a cell. For details, see 3GPP TS 22.261. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD

Example

To list the parameters of the cell uac barring information with the local cell ID of 1 and access category of 1, run the following command:
LST CELLUACBAR: LocalCellId=1, AccessCategory=1;
The result is shown as follows:
+++    0        2019-05-21 15:56:28
O&M    #806355441

                    Local Cell ID  =  1
                  Access Category  =  1

---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within the eNodeB. This parameter applies only to LTE FDD and LTE TDD.

Access Category

Indicates the access category of services in a cell. For details, see 3GPP TS 22.261. This parameter applies only to LTE FDD and LTE TDD.

Access Control Parameter Group ID

Indicates the access control parameter group ID mapping to an access category. This parameter applies only to LTE FDD and LTE TDD.
