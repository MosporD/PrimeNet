Modify Cell DACQ Parameter Configuration (MOD CELLDACQPARACFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the DACQ parameter configuration of a cell.

Note

Do not set the DlAmbrLimitFirstRank, DlAmbrLimitSecRank, UlAmbrLimitFirstRank, and UlAmbrLimitSecRank parameters to a value greater than the subscribed rate of UEs.

MbbUeExpRatePctTargetThld MBB UE Experienced Rate Percentage Target Thld

Meaning: Indicates the threshold used to determine whether to perform MBB-user-experience-based DACQ. This threshold is the minimum target percentage of the MBB-user-perceived rates that reach a satisfactory level over a period. This parameter applies only to LTE FDD and LTE TDD.

If this parameter is set to 100, MBB-user-experience-based DACQ does not take effect, and the eNodeB uses the original DACQ feature to determine whether to restrict the rates of WBB UEs. If this parameter is set to 0, the eNodeB restricts the rates of WBB UEs only when no MBB-user-perceived rate reaches the target threshold of MBB-user-perceived rates in a monitoring period.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 80

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a smaller value, DACQ is less likely to take effect, leading to a smaller number of times the rates of WBB UEs are restricted. If this parameter is set to a larger value, DACQ is more likely to take effect, leading to a larger number of times the rates of WBB UEs are restricted.

Applicable Mode: L-FDD, L-TDD
MbbUeExpRateTargetThld MBB UE Experienced Rate Target Threshold

Meaning: Indicates the target threshold of MBB-user-experienced rates. This threshold is the minimum MBB-user-perceived rate that reaches a satisfactory level. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~20

Actual Value Range: 1~20

If this parameter is set to a larger value, DACQ is more likely to take effect, leading to a larger number of times the rates of WBB UEs are restricted.

Applicable Mode: L-FDD, L-TDD

Example

To modify the DACQ configuration in a cell with the parameters as follows: Local cell ID: 0, DlAmbrLimitFirstRank: 2000000, DlAmbrLimitSecRank:100000, run the following command:
MOD CELLDACQPARACFG: LocalCellId=0, DlAmbrLimitFirstRank=2000000, DlAmbrLimitSecRank=100000;
