Modify UE Measurement Control Configuration for a Cell (MOD CELLUEMEASCONTROLCFG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the UE measurement configurations for a cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
MaxNonIntraMeasObjNum Max Non-Intra Freq Measurement Object Number

Meaning: Indicates the maximum number of inter-frequency and inter-RAT measurement objects that can be contained in the measurement configurations delivered to UEs in RRC_CONNECTED mode. This parameter takes effect only on LTE-only UEs, that is, UEs that do not support NSA DC. The total number of measurement objects that can be delivered on the LTE side to NSA-DC-capable UEs is specified by the CellUeMeasControlCfg.NsaMaxLteInterFMeasObjNum parameter. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to more inter-frequency and inter-RAT measurement objects that can be delivered over the Uu interface. The number of inter-frequency and inter-RAT measurement objects that a UE can measure also depends on the UE capability. According to 3GPP specifications, a UE can measure at least 7 inter-frequency and inter-RAT measurement objects. If this parameter is set to a value larger than 7, compatibility problems may occur and UEs may become abnormal.

A smaller value of this parameter leads to fewer inter-frequency and inter-RAT measurement objects that can be delivered over the Uu interface. If the measurement configurations of some inter-frequency and inter-RAT measurement objects are not delivered, necessary frequency measurement information cannot be obtained and then measurement-related algorithms are affected. For example, the handover algorithm and related inter-frequency or inter-RAT handover success rate are affected.

Applicable Mode: L-FDD, L-TDD

If the measurement configurations of some neighboring E-UTRAN FDD frequencies are not delivered, necessary frequency measurement information cannot be obtained and then measurement-related algorithms are affected. For example, the handover algorithm and related inter-frequency handover success rate are affected.

Applicable Mode: L-FDD, L-TDD

MaxPrdcInterFMeasFreqNum Max Periodic Inter-Freq Measurement Freq Num

Meaning: Indicates the maximum number of non-serving E-UTRA frequencies for periodic measurements that the eNodeB delivers to each UE in connected mode. If this parameter is set to N (N is not equal to 0), the eNodeB can deliver both N non-serving FDD E-UTRA frequencies and N non-serving TDD E-UTRA frequencies to a single UE in connected mode for periodic measurements. If this parameter is set to 0, the number of non-serving E-UTRA frequencies and the number of inter-RAT frequencies delivered for periodic measurements are not under control. This parameter applies only to LTE FDD and LTE TDD.

MaxNrMeasFreqNum Max NR Measure Freq Number

Meaning: Indicates the maximum number of NG-RAN frequencies that can be contained in a measurement configuration delivered to a UE in RRC_CONNECTED mode. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~16

Unit: None

Actual Value Range: 1~16

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more NG-RAN frequencies that can be delivered over the Uu interface. The number of NG-RAN frequencies that a UE can measure depends on the UE capability and the maximum number of inter-frequency and inter-RAT measurement objects for the UE to measure. According to 3GPP specifications, a UE can measure at least seven NG-RAN frequencies. If this parameter is set to a value larger than 7, compatibility problems may occur and UEs may become abnormal. A smaller value of this parameter results in fewer NG-RAN frequencies that can be delivered over the Uu interface. If some NG-RAN frequencies are not delivered, measurement-related algorithms may be affected. For example, handover algorithms may be affected, and accordingly the success rate of handovers to NG-RAN may be affected. Other measurement-related algorithms cannot obtain necessary frequency measurement information.

Applicable Mode: L-FDD, L-TDD
MeasOptAlgoSwitch Measurement Optimization Algorithm Switch

Meaning: Indicates whether to enable measurement-related optimization algorithms.

NSA_SA_MEAS_OBJ_PREEMPTION_SW: Indicates whether to enable preemption during measurement configuration when the number of measurement objects for an SA or NSA UE reaches the maximum. If this option is selected, preemption is enabled so that measurement configurations related to high-priority algorithms are preferentially delivered. If this option is deselected, preemption is disabled and the measurement configurations related to algorithms that are subsequently initiated are not delivered. This option applies only to LTE FDD and LTE TDD.

GUI Value Range: NSA_SA_MEAS_OBJ_PREEMPTION_SW(NSA_SA_MEAS_OBJ_PREEMPTION_SW)

Unit: None

Actual Value Range: NSA_SA_MEAS_OBJ_PREEMPTION_SW

MML Default Value: None

Recommended Value: NSA_SA_MEAS_OBJ_PREEMPTION_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this option is selected and the number of measurement objects for a UE reaches the maximum, high-priority features or algorithms that are subsequently initiated can start up, improving user experience with critical KPIs (for example, reducing the service drop rate). If this option is deselected and the number of measurement objects for a UE reaches the maximum, high-priority features or algorithms that are subsequently initiated cannot start up. User experience with critical KPIs deteriorates. For example, coverage-based handovers cannot be performed. Only blind redirections can be used. As a result, the service interruption time increases, and service drops may occur.

Applicable Mode: L-FDD, L-TDD
NsaDcMaxInterFMeasObjNum NSA DC Max Inter-Freq Measurement Object Num

Meaning: Indicates the maximum total number of inter-frequency measurement objects that can be contained in the inter-frequency measurement configurations delivered to NSA UEs in the DC state in both the LTE PCell and NR PSCell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 2~32

Unit: None

Actual Value Range: 2~32

MML Default Value: None

Recommended Value: 13

Parameter Relationship:

-Configuration constraints:

  • In a CellUeMeasControlCfg MO, the value of NsaMaxLteInterFMeasObjNum must not be greater than the value of NsaDcMaxInterFMeasObjNum.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more inter-frequency measurement objects that can be delivered over the Uu interface. The number of inter-frequency measurement objects that a UE can measure also depends on the UE capability. According to 3GPP specifications, an NSA UE in the DC state can measure at least a total of 13 inter-frequency measurement objects. If this parameter is set to a value larger than 13, compatibility problems may occur and UEs may become abnormal. A smaller value of this parameter results in fewer inter-frequency measurement objects that can be delivered over the Uu interface. If some inter-frequency and inter-RAT measurement objects are not delivered, measurement-related algorithms may be affected. For example, handover algorithms may be affected, and accordingly the inter-frequency and inter-RAT handover success rates may be affected. Other measurement-related algorithms cannot obtain necessary frequency measurement information.

Applicable Mode: L-FDD, L-TDD
NsaMaxLteInterFMeasObjNum NSA Max LTE Inter-Freq Measurement Object Num

Meaning: Indicates the maximum total number of inter-frequency measurement objects that can be contained in the inter-frequency measurement configurations delivered to NSA UEs in the LTE PCell. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: 7

Parameter Relationship:

-Configuration constraints:

  • In a CellUeMeasControlCfg MO, the value of NsaMaxLteInterFMeasObjNum must not be greater than the value of NsaDcMaxInterFMeasObjNum.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more inter-frequency measurement objects that can be delivered over the Uu interface. The number of inter-frequency measurement objects that a UE can measure also depends on the UE capability. According to 3GPP specifications, an NSA UE can measure at least a total of 7 LTE inter-frequency measurement objects. If this parameter is set to a value larger than 7, compatibility problems may occur and UEs may become abnormal. In addition, a larger value of this parameter results in a smaller number of NR inter-frequency measurement objects that can be delivered in the NR PSCell when the NSA UE is in the DC state, affecting NR inter-frequency measurements. (This number is equal to the CellUeMeasControlCfg.NsaDcMaxInterFMeasObjNum parameter value minus the CellUeMeasControlCfg.NsaMaxLteInterFMeasObjNum parameter value.) A smaller value of this parameter results in fewer LTE inter-frequency measurement objects that can be delivered over the Uu interface. If some inter-frequency and inter-RAT measurement objects are not delivered, measurement-related algorithms may be affected. For example, handover algorithms may be affected, and accordingly the inter-frequency and inter-RAT handover success rates may be affected. Other measurement-related algorithms cannot obtain necessary frequency measurement information.

Applicable Mode: L-FDD, L-TDD

MOD CELLUEMEASCONTROLCFG: LocalCellId=0, MaxNonIntraMeasObjNum=7, MaxEutranFddMeasFreqNum=3, MaxEutranTddMeasFreqNum=3, MaxUtranFddMeasFreqNum=3, MaxUtranTddMeasFreqNum=3, MaxGeranMeasFreqNum=32;
