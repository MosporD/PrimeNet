Add Voice Rate Control setting (ADD VOICEAMRCONTROL)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add voice rate control records.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies a cell within an eNodeB. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
VoiceAmrCtrlParaGroupId Voice Rate Control Parameter Group ID

Meaning: Indicates the ID of a parameter group for rate control over voice services. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
HighAmrCodingMode High Rate Coding Mode

Meaning: Indicates the high rate coding mode for the corresponding parameter group ID. This parameter is used to configure the high rate coding mode for the corresponding parameter group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AMR_WB_23_85kbps(AMR_WB_23_85kbps), AMR_WB_12_65kbps(AMR_WB_12_65kbps), AMR_NB_12_2kbps(AMR_NB_12_2kbps), AMR_NB_7_4kbps(AMR_NB_7_4kbps), EVS_SWB_24_4kbps(EVS_SWB_24_4kbps), EVS_SWB_13_2kbps(EVS_SWB_13_2kbps)

Unit: None

Actual Value Range: AMR_WB_23_85kbps, AMR_WB_12_65kbps, AMR_NB_12_2kbps, AMR_NB_7_4kbps, EVS_SWB_24_4kbps, EVS_SWB_13_2kbps

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, the value of HighAmrCodingMode must be greater than the value of LowAmrCodingMode. In addition, HighAmrCodingMode and LowAmrCodingMode must be set to AMR-WB or AMR-NB or EVS-SWB at the same time. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of HighAmrCodingMode in those VoiceAmrControl MOs must be different. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of LowAmrCodingMode in those VoiceAmrControl MOs must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
LowAmrCodingMode Low Rate Coding Mode

Meaning: Indicates the low rate coding mode for the corresponding parameter group ID. This parameter is used to configure the low rate coding mode for the corresponding parameter group ID. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: AMR_WB_12_65kbps(AMR_WB_12_65kbps), AMR_WB_6_6kbps(AMR_WB_6_6kbps), AMR_NB_7_4kbps(AMR_NB_7_4kbps), AMR_NB_4_75kbps(AMR_NB_4_75kbps), EVS_SWB_13_2kbps(EVS_SWB_13_2kbps), EVS_SWB_9_6kbps(EVS_SWB_9_6kbps)

Unit: None

Actual Value Range: AMR_WB_12_65kbps, AMR_WB_6_6kbps, AMR_NB_7_4kbps, AMR_NB_4_75kbps, EVS_SWB_13_2kbps, EVS_SWB_9_6kbps

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, the value of HighAmrCodingMode must be greater than the value of LowAmrCodingMode. In addition, HighAmrCodingMode and LowAmrCodingMode must be set to AMR-WB or AMR-NB or EVS-SWB at the same time. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of HighAmrCodingMode in those VoiceAmrControl MOs must be different. If values of VoiceAmrCtrlParaGroupId in VoiceAmrControl MOs configured for a cell are different, values of LowAmrCodingMode in those VoiceAmrControl MOs must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L-FDD, L-TDD
PlrThdForDecreasingAmr Packet Loss Rate Thd for Decreasing

Meaning: Indicates the packet loss rate threshold (in a parameter group with a specific ID) for reducing the data rates of uplink voice services. If the packet loss rate of uplink QCI 1 services is greater than the threshold and the TBS meets the rate reduction conditions, rate reduction is triggered. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 0.005~0.5, step: 0.005

MML Default Value: None

Recommended Value: AMR_WB_23_85kbps to AMR_WB_12_65kbps: 6

AMR_WB_12_65kbps to AMR_WB_6_6kbps: 16

AMR_WB_23_85kbps to AMR_WB_6_6kbps: 24

AMR_NB_12_2kbps to AMR_NB_7_4kbps: 6

AMR_NB_7_4kbps to AMR_NB_4_75kbps: 10

AMR_NB_12_2kbps to AMR_NB_4_75kbps: 20

EVS_SWB_24_4KBPS to EVS_SWB_13_2KBPS: 6

EVS_SWB_13_2KBPS and EVS_SWB_9_6KBPS: 16

EVS_SWB_24_4KBPS and EVS_SWB_9_6KBPS: 24

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, if the value of PlrThdForDecreasingAmr is greater than 1, the value of PlrThdForDecreasingAmr must be greater than the value of PlrThdForIncreasingAmr. If the value of PlrThdForDecreasingAmr is 1, the value of PlrThdForIncreasingAmr must be 1.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability of reducing the data rates of uplink voice services and therefore a larger decrease in the PDCCH and RB resources consumed by these services and in the uplink QCI 1 packet loss rate.

A larger value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
PlrThdForIncreasingAmr Packet Loss Rate Threshold for Increasing

Meaning: Indicates the packet loss rate threshold (in a parameter group with a specific ID) for increasing the data rates of uplink voice services. If the packet loss rate of uplink QCI 1 services is less than the threshold and the TBS meets the rate increase conditions, the rate is increased. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 0.005~0.5, step: 0.005

MML Default Value: None

Recommended Value: 2

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, if the value of PlrThdForDecreasingAmr is greater than 1, the value of PlrThdForDecreasingAmr must be greater than the value of PlrThdForIncreasingAmr. If the value of PlrThdForDecreasingAmr is 1, the value of PlrThdForIncreasingAmr must be 1.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a lower probability of increasing the data rates of uplink voice services and therefore a smaller increase in the PDCCH and RB resources consumed by these services and in the uplink QCI 1 packet loss rate.

A larger value results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
RsnThdForDecreasingAmr RLC Segment Num Thd for Decreasing

Meaning: Indicates the RLC segment number threshold (in a parameter group with a specific ID) for reducing the data rates of uplink voice services. This parameter is used to calculate the TBS threshold for rate reduction. If this parameter is set to 0, only the uplink QCI 1 packet loss rate (not the number of RLC segments) is used to determine whether to reduce rates. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 0~40

Unit: None

Actual Value Range: 0~40

MML Default Value: None

Recommended Value: Set this parameter to 14 for LTE FDD cells.

The value of this parameter for LTE TDD cells depends on the uplink-downlink subframe configuration:

For SA0, set this parameter to 8.

For SA1, set this parameter to 6.

For SA2, set this parameter to 3.

For SA3, set this parameter to 4.

For SA4, set this parameter to 3.

For SA5, set this parameter to 1.

For SA6, set this parameter to 7.

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, if the value of RsnThdForDecreasingAmr is greater than or equal to 2, the value of RsnThdForDecreasingAmr must be greater than the value of RsnThdForIncreasingAmr. If the value of RsnThdForDecreasingAmr is 1, RsnThdForIncreasingAmr must be set to 1.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value (the smallest value is 1) results in a higher probability of reducing the data rates of uplink voice services and therefore a larger decrease in the PDCCH and RB resources consumed by these services and in the uplink QCI 1 packet loss rate.

A larger parameter value (the largest value is 40) results in the opposite effects.

Applicable Mode: L-FDD, L-TDD
RsnThdForIncreasingAmr RLC Segment Num Thd for Increasing

Meaning: Indicates the RLC segment number threshold (in a parameter group with a specific ID) for increasing the data rates of uplink voice services. This parameter is used to calculate the TBS threshold for rate increases. This parameter applies only to LTE FDD and LTE TDD.

GUI Value Range: 1~40

Unit: None

Actual Value Range: 1~40

MML Default Value: None

Recommended Value: Set this parameter to 5 for LTE FDD cells.

The value of this parameter for LTE TDD cells depends on the uplink-downlink subframe configuration:

For SA0, set this parameter to 3.

For SA1, set this parameter to 2.

For SA2, set this parameter to 1.

For SA3, set this parameter to 1.

For SA4, set this parameter to 1.

For SA5, set this parameter to 1.

For SA6, set this parameter to 3.

Parameter Relationship:

-Configuration constraints:

  • In a VoiceAmrControl MO, if the value of RsnThdForDecreasingAmr is greater than or equal to 2, the value of RsnThdForDecreasingAmr must be greater than the value of RsnThdForIncreasingAmr. If the value of RsnThdForDecreasingAmr is 1, RsnThdForIncreasingAmr must be set to 1.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value (the smallest value is 1) results in a lower probability of increasing the data rates of uplink voice services and therefore a smaller increase in the PDCCH and RB resources consumed by these services and in the uplink QCI 1 packet loss rate.

A larger parameter value (the largest value is 40) results in the opposite effects.

Applicable Mode: L-FDD, L-TDD

Example

To add a configuration of VoiceAmrControl with the parameters as follows: Local Cell ID: 0, Voice AMR Control Parameter Group ID: 0, High AMR Coding Mode:AMR_WB_23_85kbps, Low AMR Coding Mode:AMR_WB_6_6kbps, Packet Loss Rate Thd for Decreasing AMR:1, Packet Loss Rate Thd for Increasing AMR:1, RLC Segment Num Thd for Decreasing AMR:14, RLC Segment Num Thd for Increasing AMR:5, run the following command:
ADD VOICEAMRCONTROL: LocalCellId=0, VoiceAmrCtrlParaGroupId=0, HighAmrCodingMode=AMR_WB_23_85kbps, LowAmrCodingMode=AMR_WB_6_6kbps, PlrThdForDecreasingAmr=1, PlrThdForIncreasingAmr=1, RsnThdForDecreasingAmr=14, RsnThdForIncreasingAmr=5;
