List PrbDlGapConfig (LST PRBDLGAPCONFIG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the settings of PRB-level parameters related to the downlink gap function.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT
PrbId PRB ID

Meaning: Indicates the NB-IoT PRB ID, which uniquely identifies a PRB within an NB-IoT cell. This parameter applies only to NB-IoT.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L-NB-IOT

Example

To list the settings of PRB-level parameters related to the downlink gap function, run the following command:
LST PRBDLGAPCONFIG: LocalCellId=1;

Output Description

Field Description

Local Cell ID

Indicates the local ID of a cell, which uniquely identifies the cell within an eNodeB. This parameter applies only to NB-IoT.

PRB ID

Indicates the NB-IoT PRB ID, which uniquely identifies a PRB within an NB-IoT cell. This parameter applies only to NB-IoT.

Downlink Gap Duration Coefficient

Indicates the coefficient for the duration of a downlink gap for NB-IoT. The duration of a downlink gap is equal to the interval between downlink gaps multiplied by this coefficient. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

Downlink Gap Period

Indicates the interval between downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.

Downlink Gap Threshold

Indicates the threshold for applying downlink gaps for NB-IoT. For details, see 3GPP TS 36.211. This parameter applies only to NB-IoT.
