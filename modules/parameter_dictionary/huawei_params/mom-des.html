MOM Description

This chapter describes the MOMs of the 3900 series and 5900 series base stations.

  • MOM User Guide
    MOM user guide describes managed object models (MOMs) and provides MO configuration methods.
  • NE MOM Description
    This section describes the functions and concepts of NEs. It also illustrates managed object models (MOMs) and describes the corresponding managed objects (MOs).
  • Node MOM Description
    This section describes the functions and concepts of Nodes. It also illustrates managed object models (MOMs) and describes the corresponding managed objects (MOs).
  • GBTSFunction MOM Description
    This section describes the functions and concepts of GBTSFunction and also provides the managed object model (MOM) view and MOs related to GBTSFunction.
  • NodeBFunction MOM Description
    This section describes the functions and concepts of NodeBFunction and also provides the managed object model (MOM) view and MOs related to NodeBFunction.
  • eNodeBFunction MOM Description
    This chapter describes the functions, concepts, and child MOMs of the eNodeBFunction MOM. MOM is short for managed object models.
  • gNodeBFunction MOM Description
    This section describes the functions and concepts of the gNodeBFunction. It also provides the classification of the gNodeBFunction.
  • RFAFunction MOM Description
    This section describes the functions and concepts of RFAFunction and also provides the managed object model (MOM) view and MOs related to RFAFunction.
