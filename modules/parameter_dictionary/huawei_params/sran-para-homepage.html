3900 & 5900 Series Base Station MO and Parameter Reference

Purpose

This document describes all the managed objects (MOs) and parameters of 3900 and 5900 series base stations.

The MDU board provides the functions of main control, transmission, and baseband processing. Unless otherwise specified, all descriptions about the main control board and baseband processing board apply to the MDU board.
