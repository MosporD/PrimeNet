Modify GBTS TRX Group (MOD GTRXGROUP)

Network Element: BTS3900, BTS5900

Function

Use this command to modify the attributes of the TRX group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

The TRX group to be modified must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
GTRXGROUPID TRX Group ID

Meaning: Indicates the identity of a TRX group. It uniquely identifies a TRX group for a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
SNDMD Sending Mode

Meaning: Indicates the sending mode of the TRX in the TRX group.

GUI Value Range: SINGLESND(Single Transmitter), DIVERSITY(Transmit Diversity)

Unit: None

Actual Value Range: SINGLESND, DIVERSITY

MML Default Value: None

Recommended Value: SINGLESND(Single Transmitter)

Parameter Relationship:

-Configuration constraints:

  • If SNDMD under GTRXGROUP is set to DIVERSITY, WORKMODE must be set to INDEPENDENT.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
RCVMD Receiving Mode

Meaning: Indicates the receiving mode of the TRX group.

GUI Value Range: SINGLERECV(Single Receiver), MAINDIVERSITY(Main Diversity), FOURDIVERSITY(Four Diversity)

Unit: None

Actual Value Range: SINGLERECV, MAINDIVERSITY, FOURDIVERSITY

MML Default Value: None

Recommended Value: MAINDIVERSITY(MainDiversity)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
WORKMODE Working Mode

Meaning: Indicates the working mode of a TRX group. If each sector equipment serving the TRX group meets the requirements for the frequency and power of TRXs in the TRX group, this parameter is set to INDEPENDENT. If the bandwidth of the frequency set in the TRX group exceeds the maximum transmitting bandwidth of its serving sector equipment and all sector equipment serving the TRX group need to cooperate with each other, this parameter is set to INTERPARFFH. If the power of the TRXs in the TRX group exceeds the power specification for single sector equipment and all sector equipment serving the TRX group need to cooperate with each other, this parameter is set to INTERPAPS.

GUI Value Range: INDEPENDENT(Independent), INTERPARFFH(Inter-PA RF Frequency Hopping), INTERPAPS(Inter-PA Power Sharing)

Unit: None

Actual Value Range: INDEPENDENT, INTERPARFFH, INTERPAPS

MML Default Value: None

Recommended Value: INDEPENDENT(Independent)

Parameter Relationship:

-Configuration constraints:

  • If SNDMD under GTRXGROUP is set to DIVERSITY, WORKMODE must be set to INDEPENDENT.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
USERLABEL User Label

Meaning: Indicates a user-defined message. Users can add remarks for the TRX group using this parameter.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To modify the TRX group with the parameters as follows: TRX Group ID: 0, Receiving Mode: SINGLERECV, User Label: "test", run the following command: 
MOD GTRXGROUP: GTRXGROUPID=0, RCVMD=SINGLERECV, USERLABEL="test";
