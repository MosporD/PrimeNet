Set GBTS Local Cell Energy Management Parameter (SET GLOCELLENERGYMGTPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set energy saving parameters of local cells. The configured energy saving parameter includes the BCCH intelligent energy saving related parameters.

Note

The local cell for which energy saving parameters are configured must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
MAINBCCHPWRDTEN Power Derating for BCCH TRX Non-BCCH TS Allowed

Meaning: Indicates whether the logical cell bound to the local cell enables the Enhanced BCCH Power Consumption Optimization feature. If this parameter is set to YES, the GBTS function is allowed to decrease the transmitting power of the idle non-BCCH timeslots on the BCCH TRX in the logical cell and to perform power control on occupied non-BCCH timeslots on the BCCH TRX. Consequently, the power of the BCCH TRX also decreases, achieving power consumption optimization.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: None

Recommended Value: NO(NO)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to YES, the power of the BCCH TRX decreases with the impacts as follows:

(1) The MS startup duration prolongs.

(2) The MS may fail to hand over to or reselect this cell.

Applicable Mode: G
MAINBCCHPWRDTSTIME Power Derating Start Time for BCCH TRX Non-BCCH TS

Meaning: Indicates the start time of the transmitting power derating for non-BCCH timeslots on the BCCH TRX.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G
MAINBCCHPWRDTETIME Power Derating Terminal Time for BCCH TRX Non-BCCH TS

Meaning: Indicates the end time of the transmitting power derating for non-BCCH timeslots on the BCCH TRX.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • The terminal time needs to be larger than the start time. If MAINBCCHPWRDTETIME is smaller than MAINBCCHPWRDTSTIME, the power derating terminates the next day.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G
MAINBCCHPWRDTRANGE Power Derating Range for BCCH TRX Non-BCCH TS

Meaning: Indicates the derating range of transmitting power for non-BCCH timeslots on the BCCH TRX.

GUI Value Range: 0~40

Unit: 0.2 dB

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To set energy saving parameters for a local cell with the parameters as follows: Local Cell ID: 0, Power Derating for BCCH TRX Non-BCCH TS Allowed: YES, Power Derating Range for BCCH TRX Non-BCCH TS: 5, run the following command:
SET GLOCELLENERGYMGTPARA: GLOCELLID=0, MAINBCCHPWRDTEN=YES, MAINBCCHPWRDTRANGE=5;
