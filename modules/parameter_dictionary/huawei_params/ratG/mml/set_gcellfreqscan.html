Set GBTS Local Cell Frequency Scan (SET GCELLFREQSCAN)

Network Element: BTS3900, BTS5900

Function

Use this command to start the uplink frequency scan test in a specified local cell. In the uplink frequency scan test, the uplink receive levels of specified frequencies are scanned when the TCH/F is idle. The interference of uplink frequencies can be obtained from this test. Therefore, the test provides a reference for selecting appropriate working frequencies in network optimization.

Note

  • The local cell where an uplink frequency scan is to be started must have been configured. Otherwise, the command execution fails.
  • The logical cell bound to the local cell where an uplink frequency scan is to be started must have been configured and activated.
  • After the uplink frequency scan test is started in the cell, the TRX involved in the scan test automatically exits from the power reduction mode if the GBTS function enables the backup power saving function.
  • The uplink frequency scan test cannot be performed together with the BTS deployment call tests.
  • The uplink frequency scan test and the CDMA network interference test cannot be simultaneously conducted under the same logical cell.
  • ALLSECTOR and SECTORID are valid only in multi-site cells.
  • In a multi-site cell, if ALLSECTOR is not specified, start an uplink frequency scan for the sector with the minimum sector number under a local cell.
  • In a multi-site cell, the uplink frequency scan occupies a TCH/F. The occupied TCH/F cannot be used for services, and the channel status is displayed as Faulty.

Example

To start an uplink frequency scan test with the parameters as follows: Local Cell ID: 88, Duration(min): 60, Frequency List: 51&72, run the following command:
SET GCELLFREQSCAN: GLOCELLID=88, DURATION=60, FREQLIST=51&72;

To start an uplink frequency scan test with the parameters as follows: Local Cell ID: 88, Duration(min): 60, Frequency List: 51&72, Whether all sector or Not: NO, Sector ID: 12, run the following command:
SET GCELLFREQSCAN: GLOCELLID=88, DURATION=60, FREQLIST=51&72, ALLSECTOR=NO, SECTORID=12;
