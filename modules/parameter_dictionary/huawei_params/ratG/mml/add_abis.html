Add Abis (ADD ABIS)

Network Element: BTS3900, BTS5900

Function

Use this command to add transmission resources over the Abis interface.

Note

  • Before running this command, ensure that UPEPGRPID to be used has been added successfully by running the ADD EPGROUP command.
  • The Abis interface supports only one transmission resource.
  • For a co-MPT multimode base station that includes GSM and UMTS, the end point group used by the Abis object based on UPEPGROUPID must differ from that used by the uX2 interface on the UMTS side.
  • For a co-MPT multimode base station that includes GSM and LTE, the end point group used by the Abis object based on UPEPGROUPID must differ from that used by interfaces on LTE side.

Parameters

ID Name Description
ABISID Transmission Resource ID

Meaning: Indicates the identity of the transmission resource over the Abis interface.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
UPEPGRPID End Node Object Homing Group ID

Meaning: Indicates the identity of an end node object homing group used over the Abis interface. The end node object homing group can be configured by running the ADD EPGROUP command.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
USERLABEL User Label

Meaning: Indicates a user-defined message. Users can add remarks for the Abis interface using this parameter.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To add transmission resources over the Abis interface with the parameters as follows: Transmission Resource ID: 0, End Node Object Homing Group ID: 0, User Label: test, run the following command: 
ADD ABIS: ABISID=0, UPEPGRPID=0, USERLABEL="test";
