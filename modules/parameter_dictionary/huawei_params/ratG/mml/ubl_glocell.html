Unblock GBTS Local Cell (UBL GLOCELL)

Network Element: BTS3900, BTS5900

Function

Use this command to unblock a local cell.

Note

  • If the local cell ID is not specified, the system unblocks all local cells served by the GBTS function by default.
  • The local cell to be unblocked must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To unblock a local cell with the parameter as follows: Local Cell ID: 0, run the following command:
UBL GLOCELL: GLOCELLID=0;
