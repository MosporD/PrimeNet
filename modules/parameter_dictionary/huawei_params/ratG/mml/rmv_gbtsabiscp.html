Remove GBTS Abis Control Port (RMV GBTSABISCP)

Network Element: BTS3900, BTS5900

Function

Use this command to remove the Abis control port for a GBTS function.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Removing the in-use Abis control port may interrupt services carried on the logical TRX on the control plane.
  • The Abis control port to be removed must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
ABISCPID Control Port ID

Meaning: Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
CPBEARID CP Bear No.

Meaning: Indicates the control port bearing ID used by the GBTS function.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To remove the Abis control port with the parameters as follows: Control Port ID: 0, CP Bear No.: 0, run the following command: 
RMV GBTSABISCP: ABISCPID=0, CPBEARID=0;
