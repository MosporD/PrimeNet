List GBTS Function (LST GBTSFUNCTION)

Network Element: BTS3900, BTS5900

Function

Use this command to query the basic information about the GBTS function.

Note

None.

Parameters

None.

Example

To query the basic information about the GBTS function, run the following command:
LST GBTSFUNCTION:;
The result is as follows:
+++    0        2014-01-15 18:35:16
O&M    #269484174
%%LST GBTSFUNCTION:;%%
RETCODE = 0  Operation succeeded.

List GBTS Function
------------------
   GBTS Function Name  =  LCM_32_BTS_1150
Application Reference  =  1
           User Label  =  GBTS
         NeRM Version  =  GSMDATAV100R016C00SPC001
      Product Version  =  BTS3900 V100R009C00SPC001
(Number of results = 1)


---    END

Output Description

Field Description

GBTS Function Name

Indicates the GBTS function name. This parameter uniquely identifies an instance of a GBTS function.

Application Reference

Indicates the ID referenced by an application object for the GBTS function. This parameter must be consistent with AID in the ADD APP command.

User Label

Indicates a user-defined message. Users can add remarks for the GBTS function using this parameter.

NeRM Version

Indicates the model version of the NE software. For different NE software, if their model definitions are the same, their model versions are also the same.

In most cases, a software version uniquely corresponds to a model version. That is, the mapping between a software version and a model version is one-to-one. In few cases, their mapping is many-to-many. For example, the software version has been upgraded but the model version is not, or a software version may be compatible with multiple model versions.

Product Version

Indicates the product version.
