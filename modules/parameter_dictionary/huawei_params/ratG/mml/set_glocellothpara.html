Set GBTS Local Cell Other Parameter (SET GLOCELLOTHPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set other parameters for a local cell.

Note

The local cell for which other parameters are configured must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G
MULTRXBRDSTABMONITUNNSW MultiTRX Brd Stable Channel Monitor Switch

Meaning: Indicates whether a multi-carrier board performs a channel self-check when the board operates in the steady state.

When this parameter is set to ON, the board performs a channel self-check. When this parameter is set to OFF, the board does not perform a channel self-check.

This parameter is an advanced parameter. To change the parameter settings, ask Huawei Customer Center for help.

IMMOCCUPYPCHOPTSW Immediate Assign Message Occupy PCH Opt Switch

Meaning: Indicates whether to enable the optimization of PCH preemption by immediate assignment messages. When this parameter is set to ON, immediate assignment messages can preempt PCHs occupied by paging messages only after the cache time of the immediate assignment messages is longer than or equal to the specified delay. When this parameter is set to OFF, immediate assignment messages can preempt PCHs occupied by paging messages if required.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the probability of immediate assignment messages preempting PCHs decreases, paging overloads decrease, the BSC decreases the flow control on paging, and the downlink TBF establishment success rate increases. However, this prolongs the immediate assignment delay and decreases the immediate assignment success rate. When this parameter is set to OFF, the probability of immediate assignment messages preempting PCHs increases, paging overloads increase, the BSC enhances the flow control on paging, and the downlink TBF establishment success rate decreases. However, this shortens the immediate assignment delay and increases the immediate assignment success rate.

Applicable Mode: G
IMMOCCUPYPCHDELAY Immediate Assignment Message Occupy PCH Delay

Meaning: Indicates the delay used for protecting PCHs occupied by paging messages from being preempted by immediate assignment messages. When the cache time of immediate assignment messages is greater than or equal to the value of this parameter, the immediate assignment messages can preempt PCHs occupied by paging messages.

GUI Value Range: 0~7

Unit: 46 ms

Actual Value Range: 0~322

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to a large value, the immediate assignment delay and call continuity delay are long, but the probability of immediate assignment messages preempting PCHs is small. When this parameter is set to a small value, the immediate assignment delay and call continuity delay are short, but the probability of immediate assignment messages preempting PCHs is large.

Applicable Mode: G
PCHFORBIDRPTLOADSW Paging Expire Report Overload Prohibit Switch

Meaning: Indicates whether the BTS sends paging overload messages to the BSC when the paging timer expires. When this parameter is set to ON, the BTS does not send paging overload messages to the BSC upon detecting that the paging timer expires. When this parameter is set to OFF, the BTS sends paging overload messages to the BSC upon detecting that the paging timer expires.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the BTS does not send paging overload messages to the BSC upon detecting that the paging timer expires. As a result, the BSC flow control over paging is reduced. When this parameter is set to OFF, the BTS sends paging overload messages to the BSC upon detecting that the paging timer expires. As a result, the BSC flow control over paging is enhanced.

Applicable Mode: G
PTCCHPOWEROPTSW PTCCH Power Optimization Switch

Meaning: Indicates whether to enable the PTCCH power optimization function. When this parameter is set to ON, no signals are transmitted or received on downlink PTCCHs on non-BCCH TRXs when no services are ongoing. When this parameter is set to OFF, signals are transmitted or received on downlink PTCCHs on non-BCCH TRXs even when no services are ongoing.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Meaning: Indicates whether to enable the first MR optimization function. When this parameter is set to ON, the BSC optimizes the first MR to ensure that the MR reflects the actual measurement result. When this parameter is set to OFF, the BSC does not optimize the first MR.

This parameter is an advanced parameter. To change the parameter settings, ask Huawei Customer Center for help.

SPEECHDELAYOPTSW Speech Delay Optimize Switch

Meaning: Indicates whether to enable the speech delay optimization function. When this parameter is set to ON, the speech delay optimization function is enabled. In this case, the BTS decreases the size of downlink receive jitter buffer to decrease the E2E delay. When this parameter is set to OFF, the speech delay optimization function is disabled.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the E2E speech delay is decreased.

Applicable Mode: G
SPEECHBADFRAMEOPTSW Speech Bad Frame Optimize Switch

Meaning: Indicates whether to enable the speech bad frame optimization function. When this parameter is set to ON, the speech bad frame optimization function is enabled. In this case, the BTS optimizes the method for sending frames on the Um interface when receiving downlink speech bad frames, resolving the noise problem that occurs with a low probability during AMR-WB services. When this parameter is set to OFF, the speech bad frame optimization function is disabled.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the cell downlink DTX is disabled, setting this parameter to ON leads to voice quality fluctuation.

Applicable Mode: G
PAGINGOVLDPROCOPTSW Paging Overload Optimization Switch

Meaning: Indicates whether to enable the paging overload optimization function. When this parameter is set to ON, the paging overload optimization function is enabled. If the congestion is caused by paging for PS services, the BTS only reports PS congestion and does not perform flow control on CS services. When this parameter is set to OFF, the paging overload optimization function is disabled.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(OFF)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, Delivered Paging Messages for CS service increases, MSG CCCH LOAD IND (PCH) Messages Sent on Abis Interface (CS Service) decreases, Number of Expired of the Paging for PS Services on the PCH or Number of Deletions of the Paging for PS Services on the PCH increases, and the downlink TBF setup success rate decreases due to no response.

Applicable Mode: G
RFMODULESTDETECTSW RF Module State Detect Switch

Meaning: Indicates whether the BTS checks the status of RF module components. If this parameter is set to ON, the BTS checks the status of RF module components. If this parameter is set to OFF, the BTS does not check the status of RF module components. This parameter is valid only for MRFU V2 and GRFU V2.

RFMODULESTDETECTPNTHRD RF Module State Detect PN Threshold

Meaning: Indicates the phase noise variance threshold for reporting an RF module state detection alarm. If RFMODULESTDETECTSW is set to ON and the phase noise variance is greater than or equal to the value of this parameter, the ALM-26532 RF Unit Hardware Fault alarm is reported.

This parameter is valid only when RFMODULESTDETECTSW is set to ON.

NOTRAFFICSELFHEALSW No Traffic Self-Healing Switch

Meaning: Indicates whether the BTS performs self-healing when a no-traffic fault occurs. If this parameter is set to ON, the BTS performs self-healing upon a no-traffic fault in the sequence of TRX reconfiguration, RF unit level-2 reset, and RF unit warm reset based on the historical maximum no-traffic duration. If this parameter is set to OFF, the BTS does not perform level-by-level self-healing.

Example

To set the GBTS Local Cell Other Parameter as follows:Local Cell ID:0,MultiTRX Brd Stable Channel Monitor Switch:OFF,MultiTRX Brd Unstable Channel Monitor Switch:OFF,Immediate Assign Message Occupy PCH Opt Switch:ON,Immediate Assignment Message Occupy PCH Delay:5,Paging Expire Report Overload Prohibit Switch:OFF,PTCCH Power Optimization Switch:OFF,First MR Optimization Switch:OFF,Speech Delay Optimize Switch:OFF,Speech Bad Frame Optimize Switch:OFF,Paging Overload Optimization Switch:OFF,RF Module State Detect Switch:ON,RF Module State Detect PN Threshold:8,No Traffic Self-Healing Switch:ON:
SET GLOCELLOTHPARA: GLOCELLID=0, MULTRXBRDSTABMONITUNNSW=OFF, MULTRXBRDUNSTABMONITUNNSW=OFF, IMMOCCUPYPCHOPTSW=ON, IMMOCCUPYPCHDELAY=5, PCHFORBIDRPTLOADSW=OFF, PTCCHPOWEROPTSW=OFF, FIRSTMROPTSW=OFF, SPEECHDELAYOPTSW=OFF, SPEECHBADFRAMEOPTSW=OFF, PAGINGOVLDPROCOPTSW=OFF, RFMODULESTDETECTSW=ON, RFMODULESTDETECTPNTHRD=8, NOTRAFFICSELFHEALSW=ON;
