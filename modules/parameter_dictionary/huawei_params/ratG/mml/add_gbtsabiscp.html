Add GBTS Abis Control Port (ADD GBTSABISCP)

Network Element: BTS3900, BTS5900

Function

Use this command to add an Abis control port for the GBTS function. This port is used to carry the control plane data for a GBTS function. One Abis control port corresponds to one CP bearer.

A control port is a set of CP bearers between the GBTS function and a BSC, that is, a set of Abis control ports.

An Abis control port is uniquely identified by the control port ID and the CP bearer ID.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that CPBEARID in the ADD CPBEARER command is specified and BEARTYPE is set to SCTP.
  • If the BSC Node Redundancy feature is not used, only one control port is required. If the BSC Node Redundancy feature is used, two control ports must be configured, which maps to the active and standby BSCs. At present, a GBTS function can be configured with a maximum of two control ports.
  • If the main control board is the GTMUb or the GTMUc, only one CP bearer can be bound to a control port. If the main control board is neither the GTMUb nor the GTMUc, a maximum of 12 CP bearers can be bound to a control port.
  • Different control ports must use different CP bearers.
  • If RSL Bearer Type is set to SCTP for sites on the BSC side, it is recommended that every 12 TRXs are bound to one CP bearer. For example, if the number of TRXs is less than or equal to 12, one CP bearer is required. If the number of TRXs is greater than 12 and less than or equal to 24, two CP bearers are required. This rule applies to other numbers. One CP bearer can be bound to a maximum of 18 TRXs. If RSL Bearer Type is set to LAPD for sites on the BSC side, there is no relationship between the number of TRXs and the number of required CP bearers.

Parameters

ID Name Description
ABISCPID Control Port ID

Meaning: Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
CPBEARID CP Bear No.

Meaning: Indicates the control port bearing ID used by the GBTS function.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To add an Abis control port with the parameters as follows: Control Port ID: 0, CP Bear No.: 0, run the following command: 
ADD GBTSABISCP: ABISCPID=0, CPBEARID=0;
