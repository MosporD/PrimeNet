List GBTS Abis Control Port (LST GBTSABISCP)

Network Element: BTS3900, BTS5900

Function

Use this command to query the configuration information about an Abis control port for a GBTS function.

Note

If ABISCPID and CPBEARID are not specified, the system queries the configuration information about all Abis control ports for the GBTS function by default.

Parameters

ID Name Description
ABISCPID Control Port ID

Meaning: Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
CPBEARID CP Bear No.

Meaning: Indicates the control port bearing ID used by the GBTS function.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query the information about an Abis control port with the parameter as follows: Control Port ID: 0, run the following command:
LST GBTSABISCP: ABISCPID=0;
The result is as follows:
+++    0        2012-10-08 19:09:02
O&M    #118
%%LST GBTSABISCP: ABISCPID=0;%%
RETCODE = 0  Operation succeeded.

List GBTS Abis Control Port
---------------------------
Control Port ID  CP Bear No.

0                0                      
0                1                      
(Number of results = 2)


---    END

Output Description

Field Description

Control Port ID

Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

CP Bear No.

Indicates the control port bearing ID used by the GBTS function.
