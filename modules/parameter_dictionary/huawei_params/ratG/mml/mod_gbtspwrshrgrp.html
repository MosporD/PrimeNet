Modify GBTS Power Sharing Group (MOD GBTSPWRSHRGRP)

Network Element: BTS3900, BTS5900

Function

Use this command to modify the attribute of a multi-mode dynamic power sharing group.

Note

The multi-mode dynamic power sharing group whose attribute is to be modified must have been configured. Otherwise, the command execution fails.

Parameters

ID Name Description
PWRSHRGRPID Power Sharing Group ID

Meaning: Indicates the identity of a power sharing group. It uniquely identifies a power sharing group in a GBTS function.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
PWRSHRTYPE Power Sharing Type

Meaning: Indicates the GX power sharing type. The values of this parameter are OFF(Off), GUPWRSHR(GU Power Sharing), and GLPWRSHR(GL Power Sharing). OFF indicates that the multi-mode dynamic power sharing algorithm is disabled. GUPWRSHR indicates that GSM and UMTS dynamic power sharing algorithm is enabled. GLPWRSHR indicates that GSM and LTE dynamic power sharing algorithm is enabled. GX dynamic power sharing algorithm means that the GSM network shares power with the UMTS or LTE network when the TRXs of both networks in GX mode use the same power amplifier. This algorithm aims to improve the power usage and the quality of the UMTS or LTE network when the peak hours for the two networks are different or their traffic is unbalanced.

GUI Value Range: OFF(Off), GUPWRSHR(GU Power Sharing), GLPWRSHR(GL Power Sharing)

Unit: None

Actual Value Range: OFF, GUPWRSHR, GLPWRSHR

MML Default Value: None

Recommended Value: None

Parameter Relationship:

Service Interrupted After Modification: Yes

PWRSHARETRXNUM Min. Number of GSM Non-BCCH TRXs

Meaning: Indicates the minimum number of GSM non-BCCH TRXs configured on the sector equipment of the power sharing group during power sharing between GSM and another RAT (UMTS or LTE). Power sharing between GSM and another RAT is allowed only when the number of GSM non-BCCH TRXs on the sector equipment bound to the power sharing group is greater than or equal to the value of this parameter.

PWRSHAREPWRLOAD GSM Single PA Power Threshold for GX Power Sharing

Meaning: Indicates the allowed maximum power of single RF channel in GSM and UMTS or GSM and LTE power sharing mode. GX power sharing is supported only when the power of single RF channel is lower than the value of this parameter. This ensures that the GSM network quality is not affected.

PWRSHAREGSMIDLERSVPWR GSM Idle Power Reserve for GX Power Sharing

Meaning: Indicates the GSM power reserve when the GX power sharing mode is used during off-peak hours. If the number of current idle channels is greater than or equal to the sum of PWRSHAREGSMIDLETH and PWRSHAREGSMIDLEHS, the GSM network has a low traffic load. This parameter can be used to reduce the power reserve and increase the power sharing range. 65535 indicates that no power is reserved.

PWRSHAREGSMBUSYRSVPWR GSM Busy Power Reserve for GX Power Sharing

Meaning: Indicates the GSM power reserve when the GX power sharing mode is used during peak hours. If the number of current idle channels is less than the difference between PWRSHAREGSMIDLETH and PWRSHAREGSMIDLEHS, the GSM network has a high traffic load. This parameter can be used to increase the power reserve and avoid GSM peak clipping. 65535 indicates that no power is reserved.

PWRSHARERCVPWR Max. Shared Power Accepted by Target Network

Meaning: Indicates the maximum shared power that the target network can accept according to the RF channel power configuration of the target network. The GSM network power shared with the target network cannot exceed the value of this parameter. 65535 indicates that the target network does not support power sharing.

GUI Value Range: 0~500,65535

Unit: 0.1 dBm

Actual Value Range: 0~50,65535

MML Default Value: None

Recommended Value: 400

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G
PWRSHARERCVPWRPD Max. Power Shared by GSM in a Period

Meaning: Indicates the maximum power shared by the GSM network in each period. This prevents the power of the target network from being increased overly fast, which results in a sharp decrease in network coverage. In each GX power sharing period, the power shared by the GSM network must be less than or equal to PWRSHARERCVPWRPD. 65535 indicates that the target network does not support power sharing.

GUI Value Range: 0~420,65535

Unit: 0.1 dBm

Actual Value Range: 0~42,65535

MML Default Value: None

Recommended Value: 370(GU power sharing);400(GL power sharing)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the value of this parameter is overly large and the data channel power increases overly fast during GU power sharing mode, the cell coverage shrinks. This causes users at the cell edge to fail to be handed over to a proper target neighboring cell timely and therefore call drops occur.

Applicable Mode: G

Example

1. To modify a power sharing group with the parameters as follows: Power Sharing Group ID: 0, Power Sharing Type: OFF, run the following command:
MOD GBTSPWRSHRGRP: PWRSHRGRPID=0, PWRSHRTYPE=OFF;
2. To modify a power sharing group with the parameters as follows: Power Sharing Group ID: 1, Power Sharing Type: GLPWRSHR, Sector Equipment ID 1: 2, Sector Equipment ID 2: 3, run the following command:
MOD GBTSPWRSHRGRP: PWRSHRGRPID=1, PWRSHRTYPE=GLPWRSHR, SECTOREQMID1=2, SECTOREQMID2=3;
3. To modify a power sharing group with the parameters as follows: Power Sharing Group ID: 1, Power Sharing Type: GUPWRSHR, Sector Equipment ID 1: 3, Min. Number of GSM Non-BCCH TRXs: 10, GSM Single PA Power Thld for GX Power Sharing: 50%, GSM Idle Channel Threshold for GX Power Sharing: 10, GSM Idle Channel Hysteresis for GX Power Sharing: 5, GSM Idle Power Reserve for GX Power Sharing: 38dBm, GSM Busy Power Reserve for GX Power Sharing: 42dBm, Max. Shared Power Accepted by Target Network: 39dBm, run the following command:
MOD GBTSPWRSHRGRP: PWRSHRGRPID=1, PWRSHRTYPE=GUPWRSHR, SECTOREQMID1=3, PWRSHARETRXNUM=10, PWRSHAREPWRLOAD=50, PWRSHAREGSMIDLETH=10, PWRSHAREGSMIDLEHS=5, PWRSHAREGSMIDLERSVPWR=380, PWRSHAREGSMBUSYRSVPWR=420, PWRSHARERCVPWR=390;
