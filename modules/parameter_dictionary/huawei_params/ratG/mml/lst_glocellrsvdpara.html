List GBTS Local Cell Reserved Parameter (LST GLOCELLRSVDPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to query reserved parameters of local cells.

Note

If GLOCELLID is not specified, the system queries reserved parameters for all local cells served by the GBTS function by default.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query reserved parameters for a local cell with the parameter as follows: Local Cell ID: 0, run the following command:
LST GLOCELLRSVDPARA: GLOCELLID=0;
The result is as follows:

Indicates reserved parameter 1 that is reserved for future requirements. Note on parameter replacement: Reserved parameters are temporarily used in patch versions and will be replaced with new parameters. For example, the ID of a new parameter can signify the parameter function. Therefore, avoid using this parameter.
