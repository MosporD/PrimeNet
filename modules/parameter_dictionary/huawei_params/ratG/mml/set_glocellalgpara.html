Set GBTS Local Cell Algorithm Parameter (SET GLOCELLALGPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set algorithm-related parameters for a local cell.

Note

  • The local cell for which algorithm-related parameters are to be set must have been configured. Otherwise, the command execution fails.
  • The local cell supports a maximum of one UMTS frequency with 2.0 MHz spacing and one UMTS frequency with 2.2 MHz spacing.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
GUDEGRATEPWRCTRL Frequency-based Power Control

Meaning: Indicates whether to enable the frequency-based power control algorithm. If the frequency spacing between the GSM and UMTS networks is less than or equal to 2.2 MHz, the frequency-based power control algorithm can be enabled to reduce the power on GSM interfering frequencies and therefore reduce the interference on the UMTS network.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If there is a frequency spacing less than or equal to 2.2 MHz between the GSM and UMTS networks, enabling the frequency-based power control algorithm deteriorates the GSM network quality but brings positive gains for HSDPA services on the UMTS network.

Applicable Mode: G
GUDEGRATEPWRPRI Interference Coordination Policy

Meaning: Indicates the frequency-based power control policy. If this parameter is set to GSM(GSM), the policy preferentially ensures the GSM network quality when minimizing the interference on the UMTS network. If this parameter is set to UMTS(UMTS), the policy preferentially ensures the UMTS network quality.

GUI Value Range: GSM(GSM), UMTS(UMTS)

Unit: None

Actual Value Range: GSM, UMTS

MML Default Value: None

Recommended Value: GSM(GSM)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to GSM(GSM), there is hardly any impact on the GSM downlink channel receive quality but the HSDPA gain on the UMTS network is small.

When this parameter is set to UMTS(UMTS), the GSM downlink channel receive quality deteriorates but an obvious HSDPA gain is obtained on the UMTS network.

Applicable Mode: G

Meaning: Indicates the maximum power decrease for the GSM interfering frequencies when there is a 2.0 MHz frequency spacing between the GSM and UMTS networks. The related formula is as follows: Expected transmit power of the interfering frequency on the GSM side = Maximum TRX transmit power - GU2000KHZMAXVAL.

Therefore, the delay of transmit diversity must be configurable and can be separately set for GMSK and 8PSK.

Example

To set the algorithm-related parameters for a local cell with the parameters as follows: Local Cell ID: 0, Frequency-based Power Control: ON, Interference Coordination Policy: GSM, UMTS Center Frequency 1: 5, run the following command:
SET GLOCELLALGPARA: GLOCELLID=0, GUDEGRATEPWRCTRL=ON, GUDEGRATEPWRPRI=GSM, UMTSFREQNUM1=5;
