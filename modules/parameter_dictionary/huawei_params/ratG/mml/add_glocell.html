Add GBTS Local Cell (ADD GLOCELL)

Network Element: BTS3900, BTS5900

Function

Use this command to add a local cell for a GBTS function.

Note

  • The baseband equipment corresponding to the baseband equipment ID must have been configured.
  • A GBTS function can be configured with a maximum of 12 local cells.
  • If there are multi-site cells under an eGBTS, Baseband Policy for all local cells must be the same, and Baseband Equipment Policy must be set to a value other than LOWFREQBBEQMONLY and HIGHFREQBBEQMONLY.
  • If Local Cell Type is set to MULTISITE_CELL(Multisite Cell), the BTSLOCGRPE needs to be added for the corresponding logical cell on the BSC side.
  • If Local Cell Type is set to NORMAL_CELL(Normal Cell), the BTSLOCGRPE cannot be added for the corresponding to the logical cell on the BSC side.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
LOCELLTYPE Local Cell Type

Meaning: Indicates the local cell type. NORMAL_CELL indicates a common cell, and MULTISITE_CELL indicates a multi-site cell.

GUI Value Range: NORMAL_CELL(Normal Cell), MULTISITE_CELL(Multisite Cell)

Unit: None

Actual Value Range: NORMAL_CELL, MULTISITE_CELL

MML Default Value: NORMAL_CELL(Normal Cell)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
BASEBANDPOLICY Baseband Policy

Meaning: Indicates the policy used by a baseband processing unit serving the local cell. When this parameter is set to EMBEDBBONLY, the local cell can use only the baseband processing unit (BPU) in an RF module. When this parameter is set to BBEQMFST, the local cell preferentially uses the baseband processing unit in the baseband equipment

GUI Value Range: EMBEDBBONLY(Embedded Baseband Only), BBEQMFST(Baseband Equipment Preferentially)

Unit: None

Actual Value Range: EMBEDBBONLY, BBEQMFST

MML Default Value: EMBEDBBONLY(Embedded Baseband Only)

Recommended Value: EMBEDBBONLY(Embedded Baseband Only)

Parameter Relationship:

-Configuration constraints:

  • If BASEBANDPOLICY for GLOCELL is set to BBEQMFST, BASEBANDEQMID cannot be 255.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
BBEQMPOLICY Baseband Equipment Policy

Meaning: Indicates the policy used by the baseband equipment serving the local cell. When this parameter is set to ALLBBEQM, the local cell can use only the baseband processing unit in the baseband equipment. When this parameter is set to LOWFREQBBEQMONLY, only low-frequency TRXs (PGSM, EGSM, RGSM, GSM850, and GT810) of the local cell can use the baseband processing unit in the baseband equipment. TRXs at other frequency bands use the baseband processing unit in the RF module. When this parameter is set to HIGHFREQBBEMONLY, only high-frequency TRXs (DSC1800 and PSC1900) of the local cell can use the baseband processing unit in the baseband equipment. TRXs at other frequency bands use the baseband processing unit in the RF module.

GUI Value Range: ALLBBEQM(All Baseband Equipment), LOWFREQBBEQMONLY(Low Frequency Baseband Equipment Only), HIGHFREQBBEQMONLY(High Frequency Baseband Equipment Only)

Unit: None

Actual Value Range: ALLBBEQM, LOWFREQBBEQMONLY, HIGHFREQBBEQMONLY

MML Default Value: ALLBBEQM(All Baseband Equipment)

Recommended Value: ALLBBEQM(All Baseband Equipment)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
BASEBANDEQMID Baseband Equipment ID

Meaning: Indicates the ID of the baseband equipment deployed in the local cell. This parameter identifies the physical deployment for the baseband processing unit (BPU) in the local cell. 255 is an invalid value, indicating that the BPU is deployed on the RF module.

GUI Value Range: 0~23,255

Unit: None

Actual Value Range: 0~23,255

MML Default Value: 255

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • If BASEBANDPOLICY for GLOCELL is set to BBEQMFST, BASEBANDEQMID cannot be 255.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G
USERLABEL User Label

Meaning: Indicates a user-defined message. Users can add remarks for the local cell using this parameter.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To add a local cell with the parameters as follows: Local Cell ID: 0, Local Cell Type: NORMAL_CELL, Baseband Policy: EMBEDBBONLY, Baseband Equipment ID: 255, User Label: "test", run the following command: 
ADD GLOCELL: GLOCELLID=0, LOCELLTYPE=NORMAL_CELL, BASEBANDPOLICY=EMBEDBBONLY, BASEBANDEQMID=255, USERLABEL="test";
