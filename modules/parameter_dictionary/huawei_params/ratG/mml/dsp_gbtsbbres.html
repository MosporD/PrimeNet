Display GBTS Baseband Resource Status (DSP GBTSBBRES)

Network Element: BTS3900, BTS5900

Function

Use this command to query the attributes of GBTS baseband resources.

Note

  • If GBTS Baseband Resource Identifier is not specified, the system queries all GBTS baseband resources by default.
  • The GBTSBBRES MO is automatically created based on parameter values in the MO of the baseband processing unit.

Parameters

ID Name Description
GBTSBBRESID GBTS Baseband Resource Identifier

Meaning: Indicates the identity of a GBTS baseband resource. If the BBWS parameter in the MO of the baseband processing unit is set to GSM, the GBTS automatically creates a GBTSBBRES MO on the board and allocates a unique identity to the MO.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query the attributes of a GBTS baseband resource with the parameter as follows: GBTS Baseband Resource Identifier: 0, run the following command:
DSP GBTSBBRES: GBTSBBRESID=0;
The result is as follows:

Output Description

Field Description

GBTS Baseband Resource Identifier

Indicates the identity of a GBTS baseband resource. If the BBWS parameter in the MO of the baseband processing unit is set to GSM, the GBTS automatically creates a GBTSBBRES MO on the board and allocates a unique identity to the MO.

Cabinet Number

Indicates the No. of the cabinet accommodating the baseband processing unit associated to the GBTS baseband resources. The GBTS assigns a value to a GBTSBBRES MO created automatically based on the cabinet number in the MO of the baseband processing unit.

Subrack Number

Indicates the No. of the subrack accommodating the baseband processing unit associated to the GBTS baseband resources. The GBTS assigns a value to a GBTSBBRES MO created automatically based on the subrack number in the MO of the baseband processing unit.

Slot Number

Indicates the No. of the slot accommodating the baseband processing unit associated to the GBTS baseband resources. The GBTS assigns a value to a GBTSBBRES MO created automatically based on the slot number in the MO of the baseband processing unit.

Administrative State

Indicates the administration state of GBTS baseband resources: BLOCKED and UNBLOCKED. If this parameter is set to BLOCKED, GSM services cannot be established on the baseband resources. If this parameter is set to UNBLOCKED, GSM services can be established on the baseband resources.

Operational State

Indicates the operating status of GBTS baseband resources: ENABLED and DISABLED. If the BBWS parameter value on a board does not match the board capability, the operating status will be unavailable.
