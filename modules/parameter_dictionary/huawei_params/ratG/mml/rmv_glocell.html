Remove GBTS Local Cell (RMV GLOCELL)

Network Element: BTS3900, BTS5900

Function

Use this command to remove a specified local cell.

Note

  • The local cell to be removed must have been configured. Otherwise, the command execution fails.
  • Removing the local cell interrupts all services in the logical cell bound to the local cell. Therefore, if a logical cell is bound to the local cell, deactivate the logical cell on the BSC side, and then run this command.
  • If the local cell is configured with a TRX group, remove the TRX group first and then run this command. Otherwise, the command execution fails.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To remove the local cell with the parameter as follows: Local Cell ID: 0, run the following command: 
RMV GLOCELL: GLOCELLID=0;
