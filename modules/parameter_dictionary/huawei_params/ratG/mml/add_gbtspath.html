Add GBTS IP Path (ADD GBTSPATH)

Network Element: BTS3900, BTS5900

Function

Use this command to add an IP path used by a GBTS function. An IP path is used to transfer user-plane data between the BTS and the BSC. In the scenario where the GSM and UMTS networks share a main control board, if PEERIPADDR and DSCP for the IP path used by the GSM network are the same as those used by the UMTS network, but the IPADDR for the IP path used by the two networks is different, run this command to configure the IP path used by the current network.

Note

  • Before running this command, ensure that the IP path to be used has been added successfully by running the ADD IPPATH.
  • The number of IP paths used by a GBTS function must be equal to or less than 128.
  • If the main control board is the GTMUb or the GTMUc, GBTSPATH cannot be configured.

Parameters

ID Name Description
PATHID Path ID

Meaning: Indicates the ID of the IP path used by the GBTS function. This parameter uniquely identifies an IP path.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To add an IP path used by a GBTS function with the parameter as follows: Path ID: 0, run the following command: 
ADD GBTSPATH: PATHID=0;
