List GBTS Local Cell Frequency Scan (LST GCELLFREQSCAN)

Network Element: BTS3900, BTS5900

Function

Use this command to query the configuration information about the frequency scan in the specified or all local cells.

Note

If the Whether all sectors or Not parameter is set to YES in the SET GCELLFREQSCAN command, that is, all sectors are scanned one by one, the Sector ID parameter queried in the LST GCELLFREQSCAN command is NULL, indicating that the sector ID is meaningless.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query the configuration information about the frequency scan with the parameters as follows: Local Cell ID: 88, run the following command:
LST GCELLFREQSCAN: GLOCELLID=88;
The result is as follows:
+++    0        2012-12-01 09:33:49

Output Description

Field Description

Local Cell ID

Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

Start Time

Indicates the start time of the frequency scan. If the start time is not specified, the frequency scan is started immediately.

Duration(min)

Indicates the duration of the frequency scan.

Frequency List

Indicates the list of frequencies on which the scan test is started.

Whether all sectors or Not

Indicates whether all sectors under the local cell are scanned during the uplink frequency scan. The values of this parameter are YES and NO.

Sector ID

Indicates the No. of a sector.
