Remove GBTS TRX Group (RMV GTRXGROUP)

Network Element: BTS3900, BTS5900

Function

Use this command to remove a TRX group.

Note

  • The TRX group to be removed must have been configured. Otherwise, the command execution fails.
  • Removing a TRX group interrupts services carried on the logical TRX on the TRX group. Therefore, if logical TRXs are configured for the TRX group, deactivate the TRXs on the BSC side and then run this command.
  • If sector equipment is bound to the TRX group, remove the sector equipment from the TRX group first and then run this command. Otherwise, the command execution fails.

Parameters

ID Name Description
GTRXGROUPID TRX Group ID

Meaning: Indicates the identity of a TRX group. It uniquely identifies a TRX group for a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To remove the TRX group with the parameter as follows: TRX Group ID: 0, run the following command: 
RMV GTRXGROUP: GTRXGROUPID=0;
