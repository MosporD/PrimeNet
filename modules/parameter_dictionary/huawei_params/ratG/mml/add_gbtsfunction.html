Add GBTS Function (ADD GBTSFUNCTION)

Network Element: BTS3900, BTS5900

Function

Use this command to add a root node of the GBTS function.

Note

  • Before adding a GBTS function, ensure that application objects associated with APPLICATIONREF have been created, and the application type must be GBTS. Otherwise, the command execution fails.
  • Only one GBTS function can be added for a BTS.
  • The GBTS function name must be the same as the logical BTS name on the BSC side. Otherwise, the MAE cannot associate the GBTS function with the logical BTS on the BSC side, and services of the GBTS are unavailable when the Abis Self-planning function is enabled.
  • The name of the GBTS must be unique in the GSM network. Otherwise, services of the GBTSs with the same name are unavailable when the Abis Self-planning function is enabled.

Parameters

ID Name Description
GBTSFUNCTIONNAME GBTS Function Name

Meaning: Indicates the GBTS function name. This parameter uniquely identifies an instance of a GBTS function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of GBTSFUNCTIONNAME is a string of characters. The string cannot be null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes (\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three plus signs (+++), two or more consecutive spaces, and two or more consecutive percentage signs (%).

-Others:

  • BTSNAME (MO: BTS) for a logical BTS, corresponding to the GBTSFunction MO on the BSC, must be consistent with this parameter.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
APPLICATIONREF Application Reference

Meaning: Indicates the ID referenced by an application object for the GBTS function. This parameter must be consistent with AID in the ADD APP command.

GUI Value Range: 1~255

Unit: None

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G
USERLABEL User Label

Meaning: Indicates a user-defined message. Users can add remarks for the GBTS function using this parameter.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To add a GBTS function with the parameters as follows: GBTS Name: "GRAT", Referenced Application ID: 1, User Label: "test", run the following command:
ADD GBTSFUNCTION: GBTSFUNCTIONNAME="GRAT", APPLICATIONREF=1, USERLABEL="test";
