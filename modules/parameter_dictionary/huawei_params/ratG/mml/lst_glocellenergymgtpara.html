List GBTS Local Cell Energy Management Parameter (LST GLOCELLENERGYMGTPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to query the energy management parameters for a local cell.

Note

If GLOCELLID is not specified, the system queries the energy management parameters for all local cells served by the GBTS function by default.

Parameters

ID Name Description
GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query the energy management parameters for a local cell with the parameter as follows: Local Cell ID: 0, run the following command:
LST GLOCELLENERGYMGTPARA: GLOCELLID=0;
The result is as follows:

Output Description

Field Description

Local Cell ID

Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

Power Derating for BCCH TRX Non-BCCH TS Allowed

Indicates whether the logical cell bound to the local cell enables the Enhanced BCCH Power Consumption Optimization feature. If this parameter is set to YES, the GBTS function is allowed to decrease the transmitting power of the idle non-BCCH timeslots on the BCCH TRX in the logical cell and to perform power control on occupied non-BCCH timeslots on the BCCH TRX. Consequently, the power of the BCCH TRX also decreases, achieving power consumption optimization.

Power Derating Start Time for BCCH TRX Non-BCCH TS

Indicates the start time of the transmitting power derating for non-BCCH timeslots on the BCCH TRX.

Power Derating Terminal Time for BCCH TRX Non-BCCH TS

Indicates the end time of the transmitting power derating for non-BCCH timeslots on the BCCH TRX.

Power Derating Range for BCCH TRX Non-BCCH TS(0.2 dB)

Indicates the derating range of transmitting power for non-BCCH timeslots on the BCCH TRX.
