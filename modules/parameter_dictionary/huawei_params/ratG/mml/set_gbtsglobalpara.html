Set GBTS Global Parameter (SET GBTSGLOBALPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set the global parameters for a GBTS function.

Note

None.

Parameters

ID Name Description
MCSTANDARD GSM Multi-Carrier BTS Standards

Meaning: Indicates the GSM multi-carrier BTS standards.

GUI Value Range: CLASS0(Class0), CLASS1(Class1), CLASS2(MCBTS), MSR(MSR)

Unit: None

Actual Value Range: CLASS0, CLASS1, CLASS2, MSR

MML Default Value: None

Recommended Value: CLASS2(MCBTS)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To set the global parameters for a GBTS with the parameter as follows: GSM Multi-Carrier BTS Standards: MSR, run the following command:
SET GBTSGLOBALPARA:MCSTANDARD=MSR;
