Remove GBTS Function (RMV GBTSFUNCTION)

Network Element: BTS3900, BTS5900

Function

Use this command to remove the GBTS function.

Note

If the GBTS function has any of the following objects: Abis control port, GBTS path, power sharing group, local cell, TRX group, TRX group sector equipment, remove all these objects and then remove the GBTS function. Otherwise, the command execution fails.

Parameters

ID Name Description
GBTSFUNCTIONNAME GBTS Function Name

Meaning: Indicates the GBTS function name. This parameter uniquely identifies an instance of a GBTS function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of GBTSFUNCTIONNAME is a string of characters. The string cannot be null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes (\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three plus signs (+++), two or more consecutive spaces, and two or more consecutive percentage signs (%).

-Others:

  • BTSNAME (MO: BTS) for a logical BTS, corresponding to the GBTSFunction MO on the BSC, must be consistent with this parameter.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To remove the GBTS function with the parameter as follows: GBTS Name: GRAT, run following command: 
RMV GBTSFUNCTION: GBTSFUNCTIONNAME="GRAT";
