List Abis (LST ABIS)

Network Element: BTS3900, BTS5900

Function

Use this command to query the transmission resources over the Abis interface.

Note

If ABISID is not specified, the system queries the configuration information about Abis transmission resources over all of the Abis interfaces by default.

Parameters

ID Name Description
ABISID Transmission Resource ID

Meaning: Indicates the identity of the transmission resource over the Abis interface.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G

Example

To query the transmission resources over the Abis interface with the parameter as follows: Transmission Resource ID: 0, run the following command:
LST ABIS: ABISID=0;
The result is as follows:
+++    0        2012-10-08 19:09:56
O&M   #123
%%LST ABIS: ABISID=0;%%
RETCODE = 0  Operation succeeded.

List Abis
---------
       Transmission Resource ID  =  0
End Node Object Homing Group ID  =  1
                     User Label  =  test
(Number of results = 1)


---    END

Output Description

Field Description

Transmission Resource ID

Indicates the identity of the transmission resource over the Abis interface.

End Node Object Homing Group ID

Indicates the identity of an end node object homing group used over the Abis interface. The end node object homing group can be configured by running the ADD EPGROUP command.

User Label

Indicates a user-defined message. Users can add remarks for the Abis interface using this parameter.
