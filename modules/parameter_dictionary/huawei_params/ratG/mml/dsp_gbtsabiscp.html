Display GBTS Abis Control Port (DSP GBTSABISCP)

Network Element: BTS3900, BTS5900

Function

Use this command to query the transmission bearing status of the Abis control port: AVAILABLE and UNAVAILABLE.

Note

  • If CPBEARID is not specified, the system queries all available transmission bearing corresponding to ABISCPID by default.
  • If CPBEARID is specified, the system queries the available transmission bearing corresponding to the specified ID by default.

Parameters

ID Name Description
ABISCPID Control Port ID

Meaning: Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

GUI Value Range: 0~65534

CPBEARID CP Bear No.

Meaning: Indicates the control port bearing ID used by the GBTS function.

Example

To query the status of an Abis control port with the parameter as follows: Control Port ID: 0, run the following command:
DSP GBTSABISCP: ABISCPID=0;
The result is as follows:

Output Description

Field Description

Control Port ID

Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.

CP Bear No.

Indicates the control port bearing ID used by the GBTS function.

Control Port Bearing Status

Indicates the transmission bearing status of the control port: AVAILABLE and UNAVAILABLE. When this parameter is set to AVAILABLE, the control port can bear control data transmission. When this parameter is set to UNAVAILABLE, the control port cannot bear control data transmission.
