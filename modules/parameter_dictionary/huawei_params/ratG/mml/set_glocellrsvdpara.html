Set GBTS Local Cell Reserved Parameter (SET GLOCELLRSVDPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set reserved parameters for local cells. These reserved parameters are used to set the switch attribute of new features. The implementation of this command needs support from patch versions.

If a new feature is introduced in a patch version, determine whether to enable this feature by setting a reserved parameter.

Note

  • To avoid impacts on future upgrade, run this command following the instructions of Huawei engineers.
  • The local cell for which reserved parameters are configured must have been configured. Otherwise, the command execution fails.

Parameters

GLOCELLID Local Cell ID

Meaning: Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.

Example

To set reserved parameters for a local cell with the parameters as follows: Local Cell ID: 0, Reserved Parameter 1: 0, run the following command: 
SET GLOCELLRSVDPARA: GLOCELLID=0, GLOCELLRSVDPARA1=0;
