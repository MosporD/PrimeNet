Set GBTS Local Cell Radio Link Alarm Parameter (SET GLOCELLRLALMPARA)

Network Element: BTS3900, BTS5900

Function

Use this command to set the radio link alarm parameters for a local cell and to define the radio link alarm switch, detection period, and threshold.

Note

The local cell for which radio link alarm parameters are configured must have been configured. Otherwise, the command execution fails.

GUNFAULTDECTSW Service Failure Detect Switch

Meaning: Indicates the switch for detecting a service failure by the GBTS. The causes of service failures include high call drop rate, bad uplink/downlink quality, abnormal activation, and abnormal release. When this switch is set to ON, the service failure detection is enabled on the GBTS. When detecting a service failure caused by high call drop rate or bad uplink/downlink quality, the GBTS reports an alarm indicating a radio link exception. Checks on service failures caused by abnormal activation and release are performed on a per-TRX basis. When this switch is set to OFF, checks on service failures caused by high call drop rate or bad uplink/downlink quality are disabled. Checks on service failures caused by abnormal activation and release are performed on a per-channel basis.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G

Meaning: Indicates the threshold for triggering ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced. The value of this parameter is the difference between the receive main and diversity RSSI values for a GSM TRX. If 80% of the difference for GSM TRXs in the uplink occupation state is greater than the value of this parameter, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is reported. If 80% of the difference for GSM TRXs in uplink occupation state is less than the value of this parameter, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is cleared.

Example

To set the radio link alarm parameters for a local cell with the parameters as follows: Local Cell ID: 0, Abnormal Release Alarm Threshold: 80%, Abnormal Release Alarm Clearing Threshold: 20%, No-traffic Measurement Period: 200, Service Failure Detect Switch: ON, High Call Drop Rate Fault Detect Thres: 50%, High Call Drop Rate Fault Clear Thres: 20%, Bad Quality Failure Check Threshold: 50%, Bad Quality Failure Clear Threshold: 20%, RSSI Unbalanced Alarm Threshold(0.1dB): 150, run the following command:
SET GLOCELLRLALMPARA: GLOCELLID=0, ARELWTHD=80, AREDISTHD=20, NOTRASP=40, GUNFAULTDECTSW=ON, GUNCHDROPDECTTHRD=5, GUNCHDROPCLRTHRD=2, GUNBADQUALDETCTTHRD=5, GUNBADQUALCLRTHRD=2, RSSIUNBALANCEDTHRD=150;
