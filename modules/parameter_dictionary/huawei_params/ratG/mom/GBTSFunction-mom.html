GBTSFunction MOM Description

This section describes the functions and concepts of GBTSFunction and also provides the managed object model (MOM) view and MOs related to GBTSFunction.

Functions and Concepts

GBTSFunction

GBTSFunction is the root node of a GBTS function and is used to perform GSM radio access functions, including air interface management, access control, resource allocation.

MOM View

Figure 1 is a subset of the eGBTS MOM and provides MOs related to GBTSFunction.

Figure 1 GBTSFunction MOM view

In the GBTSFunction MOM view, the GBTSFUNCTION MO is attributed to the NE MO which is the root node of NEs. GBTSFUNCTION is the root node of a GBTS function. Before creating a GBTSFUNCTION MO, the Application ID (under the APPLICATION MO) referenced by the GBTSFUNCTION MO must be available and the application object type must be GBTS.

One GBTSFUNCTION MO corresponds to one GBTS instance, and an eGBTS has only one GBTSFUNCTION MO.

The GBTSFunction MOM is divided into GBTS MOM, local cell MOM, and Abis MOM.

  • For detailed descriptions about the GBTS MOM, see GBTS MOM Description.
  • Local cell MOM: For details about MOs related to a local cell, see Local Cell MOM Description.
    • eGBTS with the UMPT/UMDU functioning as the main control board: One GBTSFUNCTION MO can be configured with a maximum of 12 GLOCELL MOs and 72 GTRXGROUP MOs.
    • eGBTS with the GTMUb functioning as the main control board: One GBTSFUNCTION MO can be configured with a maximum of 12 GLOCELL MOs and 24 GTRXGROUP MOs.
  • Abis MOM: For Abis interface-related MOs, see Abis MOM Description.
    • eGBTS with the UMPT/UMDU functioning as the main control board: The Abis control plane of a GBTSFUNCTION MO can be configured with a maximum of 24 GBTSABISCP Mos (24 = 2 (number of ports) x 12 (number of CPs)). The Abis user plane can be configured with a maximum of 128 GBTSPATH MOs in Link mode and one ABIS MO in End-Point mode.
    • eGBTS with the GTMUb functioning as the main control board: The Abis control plane of a GBTSFUNCTION MO can be configured with a maximum of 2 GBTSABISCP MOs (2 = 2 (number of ports) x 1 (number of CPs)). The Abis user plane can be configured with 0 GBTSPATH MO in Link mode and one ABIS MO in End-Point mode.
NOTE:

For details about NE and APPLICATION MOs, see NE MOM Description and Application Management MOM Description, respectively.
