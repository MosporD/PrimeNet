Local Cell MOM Description

This section describes the functions and concepts of local cells and TRX groups and also provides the managed object model (MOM) view and related managed objects (MOs).

Functions and Concepts

Local cell (GLOCELL)

A GSM cell is a wireless coverage area identified using a base transceiver station identity code (BSIC) or a cell global identification (CGI) and is the minimum service unit that allows an MS to access a network. GSM cell functions are implemented by the BSC and eGBTS. A local cell is the functional set of a GSM cell on the eGBTS.

TRX group (GTRXGROUP)

A TRX group is a group of TRX resources that comply with the same deployment restrictions. A TRX group only belongs to a local cell, and a local cell can be served by one or more TRX groups. A TRX group can be bound to multiple TRXs.

MOM

Figure 1 is a subset of the eGBTS MOM and provides the MOs related to a local cell.

Figure 1 Local cell MOM view

The MOs related to a local cell are described as follows:

  • GLOCELL defines basic information about a local cell, including local cell type, baseband resource utilization policy, and BASEBANDEQM ID deployed for a local cell.
  • GLOCELLALGPARA defines parameters related to algorithms for a local cell, including frequency-level power control algorithms.
  • GLOCELLENERGYMGTPARA defines parameters related to energy saving for a local cell, including BCCH intelligent energy saving-related parameters.
  • GLOCELLRLALMPARA defines parameters related to radio link alarms for a local cell, including radio link alarm switch, detection period, and thresholds.
  • GLOCELLRSVDPARA defines reserved parameters for a local cell. Reserved parameters are used by new features in a patch version.
  • GLOCELLOTHPARA defines other parameters for a local cell.
  • GTRXGROUP defines basic information about a TRX group which is a set of sector equipment serving a group of TRXs. The basic information about a TRX group includes the homing cell of TRXs, TX/RX mode, and working mode. A maximum of 24 TRX groups can be configured for a local cell.
  • GTRXGROUPSECTOREQM defines the relationship between TRX groups and sector equipment. This relationship indicates that the sector equipment can provide radio frequency (RF) resources for the TRXs in a TRX group.
NOTE:

For details about BASEBANDEQM and SECTOREQM MOs, see Baseband Equipment MOM Description and Sector MOM Description, respectively.
