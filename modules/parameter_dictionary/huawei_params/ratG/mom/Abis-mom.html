Abis MOM Description

This section describes the functions and concepts of the Abis MOM and provides the managed object model (MOM) view and MOs related to the Abis interface.

Functions and Concepts

The GSM Abis interface works between a BTS and a BSC and complies with the protocol stacks shown in Figure 1. By data to be transmitted, the Abis interface can be divided into the control plane and user plane.

Figure 1 Abis protocol stack
  • The protocol stacks at the physical layer, data link layer, and network transport layer are the same for the control plane and user plane over the Abis interface of GBTSFunction. The physical layer uses FE/GE and E1/T1 protocols. The data link layer uses Ethernet, virtual local area network (VLAN), Point-to-Point Protocol (PPP), and Multi-Link Point-to-Point Protocol (MLPPP) protocols. The network transport layer uses Internet Protocol (IP).
  • On the control plane over the Abis interface of GBTSFunction, the transport layer is borne by the SCTP protocol and the radio network layer has RSLs and CSLs. On the user plane over the Abis interface of GBTSFunction, the transport layer is borne by the UDP protocol and the radio network layer has TCHpTrau and PDCH pTrau.

Figure 2 shows the relationship between MOs over the GSM Abis interface.

Figure 2 Relationship between MOs over the Abis interface

The Abis data can be configured in Link or End-Point mode. In Link mode, both local and peer parameters, such as source and destination IP addresses, are manually configured. In End-Point mode, local parameters can only be manually configured and peer parameters can be automatically obtained by the GBTSFunction from signaling or manually configured.

  • The control-plane data over the Abis interface can be configured only in Link mode. The related MOs are SCTPLNK, CPBEARER, and GBTSABISCP.
  • The user-plane data over the Abis interface can be configured in either Link or End-Point mode. In Link mode, the related MOs are IPPATH and GBTSPATH (optional). In End-Point mode, the related MOs are USERPLANEHOST, USERPLANEPEER, EPGROUP, and ABIS.
    NOTE:
    1. The user-plane data over the Abis interface can be configured in only one mode (Link mode or End-Point mode) at a time. The Link mode is recommended.
    2. When the user-plane data over the Abis interface is configured in Link mode, the GBTSPATH MO is optional. For a co-MPT GSM/UMTS base station, if the GSM and UMTS modes use the same peer IP address and differentiated services code point (DSCP) but different local IP addresses under the IPPATH MO, the GBTSPATH MO must be configured.
    3. When the user-plane data over the Abis interface is configured in End-Point mode, it is recommended that local parameters be manually configured and peer parameters be automatically obtained by the GBTSFunction from signaling.

MOM

Abis Control-Plane MOM

Figure 3 is a subset of the eGBTS MOM and provides MOs related to the Abis control plane.

Figure 3 MOM view for Abis control plane
  • SCTPLNK defines an SCTP link over the Abis interface of the GBTSFunction and is used to configure SCTP-related parameters.
  • CPBEARER is the encapsulation and abstraction of the control port bearer and is used to shield lower-layer protocol information from the upper-layers and to provide transmission bearer for the control plane at the application layer. One CPBEARER MO corresponds to one SCTPLNK MO.
  • GBTSABISCP defines the control port that carries the Abis control-plane data for a GBTSFunction. One GBTSABISCP MO corresponds to one CPBEARER MO.

Abis User-Plane MOM

Figure 4 and Figure 5 are subsets of the eGBTS MOM and provide MOs related to the Abis user plane.

Figure 4 MOM diagram for Abis user plane (in Link mode)
  • IPPATH defines a path for transmitting user-plane data over the Abis interface of a GBTSFunction.
  • GBTSPATH, which is optional, defines the IPPATH MO that can be bound to the GBTSFunction. One GBTSPATH MO corresponds to one IPPATH MO.
Figure 5 MOM view for Abis user plane (in End-Point mode)
  • USERPLANEHOST defines local transmission parameters for the user-plane data. USERPLANEPEER defines peer transmission parameters for the user-plane data.
  • EPGROUP defines a set of transmission end point resources, including a set of control-plane end points, user-plane end points, or a combined set of both. The GBTSFunction can only use the set of user-plane end points. One EPGROUP MO can be configured with a maximum of 12 USERPLANEHOST MOs.
  • ABIS defines a set of transmission resources bound to the Abis interface of a GBTSFunction. One ABIS MO corresponds to one EPGROUP MO.
