GLOCELLRLALMPARA

+-NE
  +-GBTSFUNCTION
    +-GLOCELL
      +-GLOCELLRLALMPARA

Description

The GLOCELLRLALMPARA MO manages radio link alarm parameters for a local cell, including parameters related to the radio link alarm detection and report.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GLOCELL

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GLOCELLRLALMPARA

Use this command to query the radio link alarm parameters for a local cell.
SET GLOCELLRLALMPARA

Use this command to set the radio link alarm parameters for a local cell and to define the radio link alarm switch, detection period, and threshold.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.
Abnormal Release Alarm Threshold

Indicates the threshold for reporting an abnormal channel release alarm. If the percentage of the abnormal channel releases exceeds this threshold, the GBTS function reports a radio link failure alarm.
Abnormal Release Alarm Clearing Threshold

Indicates the threshold for clearing the abnormal channel release alarm. If the percentage of the abnormal channel releases is equal to or less than this threshold, the corresponding radio link failure alarm is cleared.
No-traffic Measurement Period

Indicates the measurement period when there is no traffic for TRXs. When the no-traffic measurement period is greater than or equal to the value of this parameter, the GBTS function reports a radio link failure alarm.
Start Time of Alarm Detection

Indicates the time when the GBTS function starts detecting the abnormal channel release and TRX no-traffic duration.
End Time of Alarm Detection

Indicates the time when the GBTS function stops detecting the abnormal channel release and TRX no-traffic duration.
Up Down Balance Threshold

Indicates a proportion of measurement reports for imbalanced uplink and downlink receive levels to the total valid measurement reports. If the actual proportion is greater than or equal to this threshold, the GBTS function reports a radio link failure alarm.
Service Failure Detect Switch

Indicates the switch for detecting a service failure by the GBTS. The causes of service failures include high call drop rate, bad uplink/downlink quality, abnormal activation, and abnormal release. When this switch is set to ON, the service failure detection is enabled on the GBTS. When detecting a service failure caused by high call drop rate or bad uplink/downlink quality, the GBTS reports an alarm indicating a radio link exception. Checks on service failures caused by abnormal activation and release are performed on a per-TRX basis. When this switch is set to OFF, checks on service failures caused by high call drop rate or bad uplink/downlink quality are disabled. Checks on service failures caused by abnormal activation and release are performed on a per-channel basis.
High Call Drop Rate Fault Detect Threshold

Indicates the threshold for detecting a fault alarm due to a high call drop rate. When the call drop rate is greater than this threshold, the GBTS function reports a corresponding radio link failure alarm.
High Call Drop Rate Fault Clear Threshold

Indicates the threshold for clearing a high call drop rate alarm. When the call drop rate is smaller than this threshold, the corresponding radio link failure alarm is cleared.
Bad Quality Failure Check Threshold

Indicates the threshold for checking a failure due to bad channel receive quality. When the proportion of bad channel receive quality exceeds this threshold, the GBTS function reports a corresponding radio link failure alarm.
Bad Quality Failure Clear Threshold

Indicates the threshold for clearing the failure alarm due to bad channel receive quality. When the proportion of the number of times when the channel receive quality is poor is smaller than this threshold, the corresponding radio link failure alarm is cleared.
RSSI Unbalanced Alarm Threshold

Indicates the threshold for triggering ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced. The value of this parameter is the difference between the receive main and diversity RSSI values for a GSM TRX. If 80% of the difference for GSM TRXs in the uplink occupation state is greater than the value of this parameter, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is reported. If 80% of the difference for GSM TRXs in uplink occupation state is less than the value of this parameter, ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced is cleared.
