ABIS

+-NE
  +-GBTSFUNCTION
    +-ABIS

Description

The ABIS MO manages transmission resources used by the GBTS function over the Abis interface, including user plane end point group (EPGROUP).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GBTSFUNCTION
  • Relation with the ABIS MO:
    • EPGROUP used by ABIS must have been configured.
  • Relation with the EPGROUP MO:
    • EPGROUP used by ABIS needs to be configured with at least one and a maximum of four USERPLANEHOSTs.
    • EPGROUP used by ABIS can be configured with a maximum of 24 USERPLANEPEERs.
    • USERPLANEHOST in the EPGROUP used by ABIS must be IPv4 type.
    • USERPLANEPEER in the EPGROUP used by ABIS must be IPv4 type.
    • APPTYPE for EPGROUP referenced by ABIS must be set to NULL.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD ABIS

Use this command to add transmission resources over the Abis interface.
LST ABIS

Use this command to query the transmission resources over the Abis interface.
MOD ABIS

Use this command to modify the transmission resources over the Abis interface.
RMV ABIS

Use this command to remove transmission resources over the Abis interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Transmission Resource ID

Indicates the identity of the transmission resource over the Abis interface.
End Node Object Homing Group ID

Indicates the identity of an end node object homing group used over the Abis interface. The end node object homing group can be configured by running the ADD EPGROUP command.
User Label

Indicates a user-defined message. Users can add remarks for the Abis interface using this parameter.
