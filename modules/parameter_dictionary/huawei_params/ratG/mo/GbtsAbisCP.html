GBTSABISCP

+-NE
  +-GBTSFUNCTION
    +-GBTSABISCP

Description

The GBTSABISCP MO manages the Abis control port that carries the control plane data for the GBTS function.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GBTSFUNCTION
  • Relation with the GBTSABISCP MO:
    • A maximum of 12 CP bearers can be bound to one ABISCPID.
    • BEARTYPE for CPBEARER used by GBTSABISCP must be set to SCTP.
    • Different ABISCPID cannot use same CPBEARID.
    • The number of different ABISCPID must be equal to or less than 2.
  • Relation with the CPBEARER MO:
    • CPBEARER used by GBTSABISCP must have been configured.
  • Relation with the MPT and GTMU MOs:
    • Only one CPBEARER can be configured for the ABISCPID when GTMU with TYPE set to GTMU is configured, and MPT with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GBTSABISCP

Use this command to add an Abis control port for the GBTS function. This port is used to carry the control plane data for a GBTS function. One Abis control port corresponds to one CP bearer.

A control port is a set of CP bearers between the GBTS function and a BSC, that is, a set of Abis control ports.

An Abis control port is uniquely identified by the control port ID and the CP bearer ID.
DSP GBTSABISCP

Use this command to query the transmission bearing status of the Abis control port: AVAILABLE and UNAVAILABLE.
LST GBTSABISCP

Use this command to query the configuration information about an Abis control port for a GBTS function.
RMV GBTSABISCP

Use this command to remove the Abis control port for a GBTS function.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Control Port ID

Indicates the ID of a control port for a GBTS function. It is used together with CPBEARID to uniquely identify an Abis control port.
CP Bear No.

Indicates the control port bearing ID used by the GBTS function.
Table 3 Dynamic parameters

Parameter

Description
Control Port Bearing Status

Indicates the transmission bearing status of the control port: AVAILABLE and UNAVAILABLE. When this parameter is set to AVAILABLE, the control port can bear control data transmission. When this parameter is set to UNAVAILABLE, the control port cannot bear control data transmission.
