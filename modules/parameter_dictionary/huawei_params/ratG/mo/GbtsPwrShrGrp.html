GBTSPWRSHRGRP

+-NE
  +-GBTSFUNCTION
    +-GBTSPWRSHRGRP

Description

The GBTSPWRSHRGRP MO manages the multi-mode dynamic power sharing group served by the GBTS function and enable the multi-mode dynamic power sharing function. The multi-mode dynamic power sharing function involves GU dynamic power sharing and GL dynamic power sharing. In a GU refarming scenario, if the GSM and UMTS networks share the same RF module, the GU dynamic power sharing function can be enabled.In a GL refarming scenario, if the GSM and LTE networks share the same RF module, the GL dynamic power sharing function can be enabled.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GBTSFUNCTION
  • Relation with the GTRXGROUPSECTOREQM MO:
    • The sector equipment used by GBTSPWRSHRGRP must have been bound to GTRXGROUPSECTOREQM.
  • Relation with the GBTSPWRSHRGRP MO:
    • Different GBTSPWRSHRGRPs must use different sector equipment.
    • If SECTOREQMID for GTRXGROUPSECTOREQM is used by SECTOREQMID1 or SECTOREQMID2 for GBTSPWRSHRGRP, WORKMODE for GTRXGROUP bound to GTRXGROUPSECTOREQM must be set to INDEPENDENT.
    • If the PWRSHRTYPE for GBTSPWRSHRGRP is set to GLPWRSHR, the SECTOREQMID1 and SECTOREQMID2 must serve the same sector.
    • If LOCELLTYPE for GLOCELL is set to MULTISITE_CELL, sector equipment bound to all GTRXGROUPs under GLOCELL cannot be used by GBTSPWRSHRGRP.
  • Relation with the GTRXGROUP MO:
    • If SECTOREQMID under GTRXGROUPSECTOREQM is referenced by SECTOREQMID1 or SECTOREQMID2 under GBTSPWRSHRGRP, SNDMD under GTRXGROUP bound to GTRXGROUPSECTOREQM must be set to SINGLESND.
  • Relation with the GTRXGROUP, GTRXGROUPSECTOREQM, and SECTOREQM MOs:
    • The transmit antennas for SECTOREQM referenced by GBTSPWRSHRGRP, and those referenced by GTRXGROUP for which SNDMD is set to DIVERSITY cannot be located on the same virtual antenna.
  • Relation with the SECTOREQM MO:
    • When PWRSHRTYPE in GBTSPWRSHRGRP is set to GUPWRSHR or GLPWRSHR, transmit antennas of SECTOREQMs in GBTSPWRSHRGRPs cannot be located on the same virtual antenna.
  • Relation with the GTRXGROUPSECTOREQM and SECTOREQM MOs:
    • PWRSHRTYPE in GBTSPWRSHRGRP is set to GLPWRSHR, and transmit antennas of two SECTOREQMs that bound to the GBTSPWRSHRGRP are configured on different RF modules. If among the different RF modules, transmit antennas of an RF module are configured on the SECTOREQM that bound to a GTRXGROUP, transmit antennas bound to the GTRXGROUP and those bound to the GBTSPWRSHRGRP must be located on the same virtual antenna.
    • When GTRXGROUP is bound to GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX, the TX antenna referenced by GTRXGROUP must differ from that referenced by GBTSPWRSHRGRP, and the antennas cannot belong to the same virtual antenna.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GBTSPWRSHRGRP

Use this command to add a multi-mode dynamic power sharing group served by the GBTS function and enable the multi-mode dynamic power sharing function.

The multi-mode dynamic power sharing function involves GU dynamic power sharing and GL dynamic power sharing. In a GU refarming scenario, if the GSM and UMTS networks share the same RF module, the GU dynamic power sharing function can be enabled. In a GL refarming scenario, if the GSM and LTE networks share the same RF module, the GL dynamic power sharing function can be enabled.
DSP GBTSPWRSHRGRP

Use this command to query the status of the multi-mode dynamic power sharing group, including PWRSHRTYPE, SECTOREQMID1, SECTOREQMID2, and PWRSHRGRPSTATUS.
LST GBTSPWRSHRGRP

Use this command to query the configuration information about a multi-mode dynamic power sharing group.
MOD GBTSPWRSHRGRP

Use this command to modify the attribute of a multi-mode dynamic power sharing group.
RMV GBTSPWRSHRGRP

Use this command to remove a multi-mode dynamic power sharing group.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Power Sharing Group ID

Indicates the identity of a power sharing group. It uniquely identifies a power sharing group in a GBTS function.
Power Sharing Type

Indicates the GX power sharing type. The values of this parameter are OFF(Off), GUPWRSHR(GU Power Sharing), and GLPWRSHR(GL Power Sharing). OFF indicates that the multi-mode dynamic power sharing algorithm is disabled. GUPWRSHR indicates that GSM and UMTS dynamic power sharing algorithm is enabled. GLPWRSHR indicates that GSM and LTE dynamic power sharing algorithm is enabled. GX dynamic power sharing algorithm means that the GSM network shares power with the UMTS or LTE network when the TRXs of both networks in GX mode use the same power amplifier. This algorithm aims to improve the power usage and the quality of the UMTS or LTE network when the peak hours for the two networks are different or their traffic is unbalanced.
Sector Equipment ID 1

Indicates the sector equipment identity 1 for a power sharing group.
Sector Equipment ID 2

Indicates the sector equipment identity 2 for a power sharing group.
Min. Number of GSM Non-BCCH TRXs

Indicates the minimum number of GSM non-BCCH TRXs configured on the sector equipment of the power sharing group during power sharing between GSM and another RAT (UMTS or LTE). Power sharing between GSM and another RAT is allowed only when the number of GSM non-BCCH TRXs on the sector equipment bound to the power sharing group is greater than or equal to the value of this parameter.
GSM Single PA Power Threshold for GX Power Sharing

Indicates the allowed maximum power of single RF channel in GSM and UMTS or GSM and LTE power sharing mode. GX power sharing is supported only when the power of single RF channel is lower than the value of this parameter. This ensures that the GSM network quality is not affected.
Power Reserve Coef. Claiming GSM Single PA Power

Indicates the threshold that the GSM network decides to reduce the shared power. When the residual power of the current timeslot of the GSM network is less than the product of PWRSHAREGSMIDLERSVPWR and PWRSHARERSVFACTOR, the GSM network reduces the shared power.
GSM Idle Channel Threshold for GX Power Sharing

Determines the number of idle channels for PWRSHAREGSMIDLERSVPWR or PWRSHAREGSMBUSYRSVPWR.
GSM Idle Channel Hysteresis for GX Power Sharing

Indicates the number of protection idle channels. It is used in parallel with PWRSHAREGSMIDLETH to prevent the system from being handed over frequently between busy and idle status.
GSM Idle Power Reserve for GX Power Sharing

Indicates the GSM power reserve when the GX power sharing mode is used during off-peak hours. If the number of current idle channels is greater than or equal to the sum of PWRSHAREGSMIDLETH and PWRSHAREGSMIDLEHS, the GSM network has a low traffic load. This parameter can be used to reduce the power reserve and increase the power sharing range. 65535 indicates that no power is reserved.
GSM Busy Power Reserve for GX Power Sharing

Indicates the GSM power reserve when the GX power sharing mode is used during peak hours. If the number of current idle channels is less than the difference between PWRSHAREGSMIDLETH and PWRSHAREGSMIDLEHS, the GSM network has a high traffic load. This parameter can be used to increase the power reserve and avoid GSM peak clipping. 65535 indicates that no power is reserved.
Max. Shared Power Accepted by Target Network

Indicates the maximum shared power that the target network can accept according to the RF channel power configuration of the target network. The GSM network power shared with the target network cannot exceed the value of this parameter. 65535 indicates that the target network does not support power sharing.
Max. Power Shared by GSM in a Period

Indicates the maximum power shared by the GSM network in each period. This prevents the power of the target network from being increased overly fast, which results in a sharp decrease in network coverage. In each GX power sharing period, the power shared by the GSM network must be less than or equal to PWRSHARERCVPWRPD. 65535 indicates that the target network does not support power sharing.
Time for Enabling GX Power Sharing

Indicates the time when the GU or GL power sharing function needs to be enabled according to the GX traffic distribution on the live network.
Table 3 Dynamic parameters

Parameter

Description
Power Sharing Group Status

Indicates the actual status of a power sharing group: UNEFFECTIVE, START, and STOP. UNEFFECTIVE indicates that the current configuration data of the power sharing group does not meet requirements and therefore the power sharing function cannot be performed. START indicates that the power sharing function is being performed. STOP indicates that the power sharing function is disabled or it is not time for starting the power sharing function although the current configuration data of the power sharing group meets requirements.
