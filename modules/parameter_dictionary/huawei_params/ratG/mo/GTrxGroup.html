GTRXGROUP

+-NE
  +-GBTSFUNCTION
    +-GTRXGROUP
      +-GTRXGROUPSECTOREQM[0~2]

Description

The GTRXGROUP MO manages a TRX group which is served by a set of sector equipment.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GBTSFUNCTION

  • Possible children:

    GTRXGROUPSECTOREQM[0~2]
  • Relation with the GTRXGROUP MO:
    • A GLOCELL can be configured with a maximum of 24 GTRXGROUPs.
    • GLOCELL served by GTRXGROUP must have been configured.
    • The GLOCELL served by the GTRXGROUP for which WORKMODE is set to INTERPARFFH can be configured with only one GTRXGROUP.
    • When LOCELLTYPE in GLOCELL is set to NORMAL_CELL, the sector equipment cannot be bound to different GTRXGROUP MOs bound to GLOCELL using GTRXGROUPSECTOREQM under which SERVETYPE is set to NORMAL.
    • If SECTOREQMID for GTRXGROUPSECTOREQM is used by SECTOREQMID1 or SECTOREQMID2 for GBTSPWRSHRGRP, WORKMODE for GTRXGROUP bound to GTRXGROUPSECTOREQM must be set to INDEPENDENT.
    • If LOCELLTYPE for GLOCELL is set to MULTISITE_CELL, WORKMODE for GTRXGROUP under GLOCELL must be set to INDEPENDENT.
    • If LOCELLTYPE for GLOCELL is set to MULTISITE_CELL, MAXPOWER for GTRXGROUPSECTOREQM bound to GTRXGROUP must be set to 65535.
    • If LOCELLTYPE for GLOCELL is set to MULTISITE_CELL, sector equipment bound to all GTRXGROUPs under GLOCELL cannot be used by GBTSPWRSHRGRP.
    • If LOCELLTYPE for GLOCELL is set to MULTISITE_CELL, RCVMD for GTRXGROUP under GLOCELL cannot be set to FOURDIVERSITY.
  • Relation with the GTRXGROUPSECTOREQM MO:
    • If WORKMODE for GTRXGROUP is set to INTERPARFFH, a maximum of two pieces of sector equipment can be bound to the GTRXGROUP.
    • If WORKMODE for GTRXGROUP is set to INTERPAPS, a maximum of two pieces of sector equipment can be bound to the GTRXGROUP.
    • When RCVMD in GTRXGROUP is set to MAINDIVERSITY, the sector equipment referenced by GTRXGROUP using GTRXGROUPSECTOREQM under which SERVETYPE is set to NORMAL must be configured with at least two RX antennas.
    • When RCVMD in GTRXGROUP is set to FOURDIVERSITY, the sector equipment referenced by GTRXGROUP using GTRXGROUPSECTOREQM under which SERVETYPE is set to NORMAL must be configured with at least two RX antennas.
    • If LOCELLTYPE under GLOCELL is set to MULTISITE_CELL, the sector equipment bound to GTRXGROUP under GLOCELL cannot be used by other GLOCELL.
    • One GLOCELL allows only one GTRXGROUP to be bound to GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX.
    • If SNDMD under GTRXGROUP is set to DIVERSITY, GTRXGROUP cannot be bound to GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX.
    • When WORKMODE in GTRXGROUP is set to INTERPARFFH or INTERPAPS, GTRXGROUP cannot be bound to GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX.
  • Relation with the GLOCELL and GTRXGROUPSECTOREQM MOs:
    • No more than two pieces of sector equipment can be bound to the GTRXGROUP MO using the GTRXGROUPSECTOREQM MO under which SERVETYPE is set to NORMAL if both the following conditions are met:
    • LOCELLTYPE in GLOCELL is set to NORMAL_CELL.
    • WORKMODE in GTRXGROUP bound to GLOCELL is set to INDEPENDENT.
    • When LOCELLTYPE in the GLOCELL MO is set to NORMAL_CELL, if WORKMODE in the GTRXGROUP MO referenced by the GLOCELL MO is set to INDEPENDENT and the GTRXGROUPSECTOREQM MO with SERVETYPE set to NORMAL is bound to two sets of sector equipment, SNDMD must be set to DIVERSITY and RCVMD must be set to FOURDIVERSITY in the GTRXGROUP MO.
  • Relation with the GTRXGROUPSECTOREQM and SECTOREQM MOs:
    • If WORKMODE for GTRXGROUP is set to INTERPAPS or INTERPARFFH, the RF modules where the transmit antennas for the GTRXGROUPSECTOREQMs bound to the GTRXGROUP are configured cannot be used by other GTRXGROUPSECTOREQMs.
    • When SNDMD under GTRXGROUP is set to DIVERSITY, transmit antennas configured for the sector equipment referenced by GTRXGROUP must be configured on the same RF module.
    • When SNDMD under GTRXGROUP is set to DIVERSITY, transmit antennas configured for the sector equipment referenced by GTRXGROUP cannot be located on the same virtual antenna.
    • When an RF module is used by GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX, GTRXGROUP of all TX antennas on the RF module must belong the one GLOCELL.
    • If one transmit antenna is bound to two SECTOREQM MOs, and the SECTOREQM MO is referenced by the GTRXGROUPSECTOREQM MO under which SERVETYPE is set to NORMAL, RCVMD under the two GTRXGROUP MOs referencing the SECTOREQM MO must be set to MAINDIVERSITY and FOURDIVERSITY, respectively.
  • Relation with the GBTSPWRSHRGRP MO:
    • If SECTOREQMID under GTRXGROUPSECTOREQM is referenced by SECTOREQMID1 or SECTOREQMID2 under GBTSPWRSHRGRP, SNDMD under GTRXGROUP bound to GTRXGROUPSECTOREQM must be set to SINGLESND.
  • Relation with the GLOCELL MO:
    • If LOCELLTYPE under GLOCELL is set to MULTISITE_CELL, SNDMD of GTRXGROUP under GLOCELL must be set to SINGLESND.
  • Relation with the GBTSPWRSHRGRP, GTRXGROUPSECTOREQM, and SECTOREQM MOs:
    • The transmit antennas for SECTOREQM referenced by GBTSPWRSHRGRP, and those referenced by GTRXGROUP for which SNDMD is set to DIVERSITY cannot be located on the same virtual antenna.
  • Relation with the GTRXGROUPSECTOREQM, SECTOREQM, and GLOCELL MOs:
    • The four RX antennas must be configured on the same RF module if all of the following conditions are met:
    • BASEBANDPOLICY in GLOCELL is set to EMBEDBBONLY.
    • RCVMD in GTRXGROUP bound to GLOCELL is set to FOURDIVERSITY.
    • Four RX antennas are configured on SECTOREQM referenced by GTRXGROUP using GTRXGROUPSECTOREQM under which SERVETYPE is set to NORMAL.
    • The four RX antennas must be configured on the same RF module, or two RX antennas are configured on one RF module and the other two are configured on another RF module if all of the following conditions are met:
    • BASEBANDPOLICY in GLOCELL is set to BBEQMFST.
    • RCVMD in GTRXGROUP bound to GLOCELL is set to FOURDIVERSITY.
    • Four RX antennas are configured on SECTOREQM referenced by GTRXGROUP using GTRXGROUPSECTOREQM under which SERVETYPE is set to NORMAL.
    • If one transmit antenna is bound to two SECTOREQM MOs, and the SECTOREQM MO is referenced by the GTRXGROUPSECTOREQM MO under which SERVETYPE is set to NORMAL, LOCELLTYPE under the GLOCELL MO referencing the SECTOREQM MO must be set to NORMAL_CELL.
  • Relation with the MPT and GTMU MOs:
    • A maximum of 24 GTRXGROUPs can be configured for a GBTS function when GTMU with TYPE set to GTMU and BRDSPEC set
    • to GTMUb is configured, and MPT with TYPE set to UMPT is not configured.
  • Relation with the GTRXGROUPSECTOREQM and GLOCELL MOs:
    • When LOCELLTYPE in GLOCELL is set to MULTISITE_CELL, GTRXGROUP bound to GLOCELL cannot be bound to GTRXGROUPSECTOREQM under which SERVETYPE is set to AUX.
  • Relation with the GLOCELL, GTRXGROUPSECTOREQM, and SECTOREQM MOs:
    • When LOCELLTYPE in the GLOCELL MO is set to NORMAL_CELL, if WORKMODE in the GTRXGROUP MO referenced by the GLOCELL MO is set to INDEPENDENT and the GTRXGROUPSECTOREQM MO with SERVETYPE set to NORMAL is bound to two sets of sector equipment, all antennas bound to GTRXGROUP must belong to the same RF module.
    • When LOCELLTYPE in the GLOCELL MO is set to NORMAL_CELL, if WORKMODE in the GTRXGROUP MO referenced by the GLOCELL MO is set to INDEPENDENT and the GTRXGROUPSECTOREQM MO with SERVETYPE set to NORMAL is bound to two sets of sector equipment, the sector equipment bound to GTRXGROUP must be configured with two TX antennas.
    • When LOCELLTYPE in the GLOCELL MO is set to NORMAL_CELL, if WORKMODE in the GTRXGROUP MO referenced by the GLOCELL MO is set to INDEPENDENT and the GTRXGROUPSECTOREQM MO with SERVETYPE set to NORMAL is bound to two sets of sector equipment, the sector equipment bound to GTRXGROUP must be configured with four RX antennas.
    • When LOCELLTYPE in the GLOCELL MO is set to NORMAL_CELL, if WORKMODE in the GTRXGROUP MO referenced by the GLOCELL MO is set to INDEPENDENT and the GTRXGROUPSECTOREQM MO with SERVETYPE set to NORMAL is bound to two sets of sector equipment, the two sets of sector equipment bound to GTRXGROUP must belong to different sectors.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GTRXGROUP

Use this command to add a TRX group which is served by a set of sector equipment.
LST GTRXGROUP

Use this command to query the information about a TRX group.
MOD GTRXGROUP

Use this command to modify the attributes of the TRX group.
RMV GTRXGROUP

Use this command to remove a TRX group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
TRX Group ID

Indicates the identity of a TRX group. It uniquely identifies a TRX group for a GBTS function.
Local Cell ID

Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.
Sending Mode

Indicates the sending mode of the TRX in the TRX group.
Receiving Mode

Indicates the receiving mode of the TRX group.
Working Mode

Indicates the working mode of a TRX group. If each sector equipment serving the TRX group meets the requirements for the frequency and power of TRXs in the TRX group, this parameter is set to INDEPENDENT. If the bandwidth of the frequency set in the TRX group exceeds the maximum transmitting bandwidth of its serving sector equipment and all sector equipment serving the TRX group need to cooperate with each other, this parameter is set to INTERPARFFH. If the power of the TRXs in the TRX group exceeds the power specification for single sector equipment and all sector equipment serving the TRX group need to cooperate with each other, this parameter is set to INTERPAPS.
User Label

Indicates a user-defined message. Users can add remarks for the TRX group using this parameter.
