GBTSPATH

+-NE
  +-GBTSFUNCTION
    +-GBTSPATH

Description

The GBTSPATH MO manages the IP path used by a GBTS function.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GBTSFUNCTION
  • Relation with the GBTSPATH MO:
    • IPPATH used by GBTSPATH must have been configured.
  • Relation with the MPT and GTMU MOs:
    • The GBTSPATH cannot be configured for a GBTS function when GTMU with TYPE set to GTMU is configured, and MPT with TYPE set to UMPT is not configured.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GBTSPATH

Use this command to add an IP path used by a GBTS function. An IP path is used to transfer user-plane data between the BTS and the BSC. In the scenario where the GSM and UMTS networks share a main control board, if PEERIPADDR and DSCP for the IP path used by the GSM network are the same as those used by the UMTS network, but the IPADDR for the IP path used by the two networks is different, run this command to configure the IP path used by the current network.
LST GBTSPATH

Use this command to query the IP path used by a GBTS function.
RMV GBTSPATH

Use this command to remove the IP path used by a GBTS function.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Path ID

Indicates the ID of the IP path used by the GBTS function. This parameter uniquely identifies an IP path.
