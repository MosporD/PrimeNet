GLOCELLOTHPARA

+-NE
  +-GBTSFUNCTION
    +-GLOCELL
      +-GLOCELLOTHPARA

Description

The GLOCELLOTHPARA MO manages other parameters for a local cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    GLOCELL

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GLOCELLOTHPARA

Use this command to query the other parameters for a local cell.
SET GLOCELLOTHPARA

Use this command to set other parameters for a local cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Local Cell ID

Indicates the identity of a local cell. It uniquely identifies a local cell served by a GBTS function.
MultiTRX Brd Stable Channel Monitor Switch

Indicates whether a multi-carrier board performs a channel self-check when the board operates in the steady state.

When this parameter is set to ON, the board performs a channel self-check. When this parameter is set to OFF, the board does not perform a channel self-check.

This parameter is an advanced parameter. To change the parameter settings, ask Huawei Customer Center for help.
MultiTRX Brd Unstable Channel Monitor Switch

Indicates whether a multi-carrier board performs a channel self-check when the board is started.

When this parameter is set to ON, the board performs a channel self-check. When this parameter is set to OFF, the board does not perform a channel self-check.

This parameter is an advanced parameter. To change the parameter settings, ask Huawei Customer Center for help.
Immediate Assign Message Occupy PCH Opt Switch

Indicates whether to enable the optimization of PCH preemption by immediate assignment messages. When this parameter is set to ON, immediate assignment messages can preempt PCHs occupied by paging messages only after the cache time of the immediate assignment messages is longer than or equal to the specified delay. When this parameter is set to OFF, immediate assignment messages can preempt PCHs occupied by paging messages if required.
Immediate Assignment Message Occupy PCH Delay

Indicates the delay used for protecting PCHs occupied by paging messages from being preempted by immediate assignment messages. When the cache time of immediate assignment messages is greater than or equal to the value of this parameter, the immediate assignment messages can preempt PCHs occupied by paging messages.
Paging Expire Report Overload Prohibit Switch

Indicates whether the BTS sends paging overload messages to the BSC when the paging timer expires. When this parameter is set to ON, the BTS does not send paging overload messages to the BSC upon detecting that the paging timer expires. When this parameter is set to OFF, the BTS sends paging overload messages to the BSC upon detecting that the paging timer expires.
PTCCH Power Optimization Switch

Indicates whether to enable the PTCCH power optimization function. When this parameter is set to ON, no signals are transmitted or received on downlink PTCCHs on non-BCCH TRXs when no services are ongoing. When this parameter is set to OFF, signals are transmitted or received on downlink PTCCHs on non-BCCH TRXs even when no services are ongoing.
First MR Optimization Switch

Indicates whether to enable the first MR optimization function. When this parameter is set to ON, the BSC optimizes the first MR to ensure that the MR reflects the actual measurement result. When this parameter is set to OFF, the BSC does not optimize the first MR.

This parameter is an advanced parameter. To change the parameter settings, ask Huawei Customer Center for help.
Speech Delay Optimize Switch

Indicates whether to enable the speech delay optimization function. When this parameter is set to ON, the speech delay optimization function is enabled. In this case, the BTS decreases the size of downlink receive jitter buffer to decrease the E2E delay. When this parameter is set to OFF, the speech delay optimization function is disabled.
Speech Bad Frame Optimize Switch

Indicates whether to enable the speech bad frame optimization function. When this parameter is set to ON, the speech bad frame optimization function is enabled. In this case, the BTS optimizes the method for sending frames on the Um interface when receiving downlink speech bad frames, resolving the noise problem that occurs with a low probability during AMR-WB services. When this parameter is set to OFF, the speech bad frame optimization function is disabled.
Paging Overload Optimization Switch

Indicates whether to enable the paging overload optimization function. When this parameter is set to ON, the paging overload optimization function is enabled. If the congestion is caused by paging for PS services, the BTS only reports PS congestion and does not perform flow control on CS services. When this parameter is set to OFF, the paging overload optimization function is disabled.
RF Module State Detect Switch

Indicates whether the BTS checks the status of RF module components. If this parameter is set to ON, the BTS checks the status of RF module components. If this parameter is set to OFF, the BTS does not check the status of RF module components. This parameter is valid only for MRFU V2 and GRFU V2.
RF Module State Detect PN Threshold

Indicates the phase noise variance threshold for reporting an RF module state detection alarm. If RFMODULESTDETECTSW is set to ON and the phase noise variance is greater than or equal to the value of this parameter, the ALM-26532 RF Unit Hardware Fault alarm is reported.

This parameter is valid only when RFMODULESTDETECTSW is set to ON.
No Traffic Self-Healing Switch

Indicates whether the BTS performs self-healing when a no-traffic fault occurs. If this parameter is set to ON, the BTS performs self-healing upon a no-traffic fault in the sequence of TRX reconfiguration, RF unit level-2 reset, and RF unit warm reset based on the historical maximum no-traffic duration. If this parameter is set to OFF, the BTS does not perform level-by-level self-healing.
