GBTSFUNCTION

+-NE
  +-GBTSFUNCTION
    +-ABIS[0~1]
    +-GBTSABISCP[0~24]
    +-GBTSBBRES[0~8]
    +-GBTSENERGYMGTPARA[1~1]
    +-GBTSGLOBALPARA[1~1]
    +-GBTSPATH[0~128]
    +-GBTSPWRSHRGRP[0~48]
    +-GLOCELL[0~12]
    +-GTRXGROUP[0~72]

Description

The GBTSFUNCTION MO manages the root node of the GBTS function. This parameter uniquely identifies an instance of a GBTS function. One GBTS has only a GBTS function.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NE

  • Possible children:

    ABIS[0~1];GBTSABISCP[0~24];GBTSBBRES[0~8];GBTSENERGYMGTPARA[1~1];GBTSGLOBALPARA[1~1];GBTSPATH[0~128];GBTSPWRSHRGRP[0~48];GLOCELL[0~12];GTRXGROUP[0~72]
  • Relation with the GBTSFUNCTION MO:
    • APPLICATION used by GBTSFUNCTION must have been configured.
    • AT for APPLICATION used by GBTSFUNCTION must be set to GBTS.
    • The GBTSENERGYMGTPARA and GBTSGLOBALPARA corresponding to the GBTSFUNCTION must exist.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
GBTS Function Name

Indicates the GBTS function name. This parameter uniquely identifies an instance of a GBTS function.
Application Reference

Indicates the ID referenced by an application object for the GBTS function. This parameter must be consistent with AID in the ADD APP command.
User Label

Indicates a user-defined message. Users can add remarks for the GBTS function using this parameter.
NeRM Version

Indicates the model version of the NE software. For different NE software, if their model definitions are the same, their model versions are also the same.

In most cases, a software version uniquely corresponds to a model version. That is, the mapping between a software version and a model version is one-to-one. In few cases, their mapping is many-to-many. For example, the software version has been upgraded but the model version is not, or a software version may be compatible with multiple model versions.
Product Version

Indicates the product version.
