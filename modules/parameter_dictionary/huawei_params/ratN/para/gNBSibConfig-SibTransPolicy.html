Meaning

Indicates the system information transmission mode. The value OFF indicates that system information of a SIB type cannot be broadcast. The value BROADCAST indicates that system information of a SIB type is broadcast continuously. The value ON_DEMAND indicates that system information of a SIB type can be broadcast only after being subscribed by UEs. For details about this parameter, see 3GPP TS 38.331.

Impact on Radio Network Performance

If this parameter is set to OFF, system information of the corresponding SIB type cannot be broadcast. If this parameter is set to BROADCAST, system information of the corresponding SIB type is broadcast continuously. If this parameter is set to ON_DEMAND, system information of the corresponding SIB type can be broadcast only after being subscribed by UEs. When this parameter is set to ON_DEMAND, the system overhead and energy consumption are lower in light load scenarios but the UE access duration is longer in heavy load scenarios than those when this parameter is set to BROADCAST.
