Barring State for Special Access ID

MO gNBUacParamGroup
Parameter ID BarStateForSpecialAcsId
Parameter Name

Barring State for Special Access ID
NE

BTS3900, BTS3900 5G, BTS5900, BTS5900 5G
MML Command

ADD GNBUACPARAMGROUP

MOD GNBUACPARAMGROUP

LST GNBUACPARAMGROUP
Meaning

Indicates whether access barring check is required for UEs with a special access ID. During an access barring check, the uac-BarringFactor and uac-BarringTime IEs in SIB1 determine whether an access attempt is allowed. For details, see 3GPP TS 38.331.

ACCESS_ID1_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 1, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 1 is allowed.

ACCESS_ID2_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 2, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 2 is allowed.

ACCESS_ID11_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 11, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 11 is allowed.

ACCESS_ID12_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 12, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 12 is allowed.

ACCESS_ID13_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 13, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 13 is allowed.

ACCESS_ID14_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 14, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 14 is allowed.

ACCESS_ID15_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 15, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 15 is allowed.
