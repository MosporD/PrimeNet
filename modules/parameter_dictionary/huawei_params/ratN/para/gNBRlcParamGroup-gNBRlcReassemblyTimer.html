Impact on Radio Network Performance

UM: A small value of this parameter leads to useless HARQ retransmissions from the transmitter and a large number of lost packets. A large value of this parameter leads to a long delay for the receiver to determine an out-of-order fragment transmission failure, increasing service delay and reducing the throughput.

AM: A small value of this parameter results in useless HARQ retransmissions from the transmitter and repeated status reports from the receiver, thereby wasting resources. A large value of this parameter leads to a long delay for the receiver to determine an out-of-order packet transmission failure and therefore a long delay in sending status reports, thereby increasing the service delay and reducing the throughput.
