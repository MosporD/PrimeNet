Default Value

Recommended Value

This parameter can be set by the system by default. The default value is as follows: When the NR FDD and NR TDD FR1 bandwidth is less than or equal to 70 MHz and the slot assignment is 2_3_DSUUU, the recommended value is 2SYM. When other bandwidths and frequency bands are used, the recommended value is 1SYM.

When LTE FDD and NR Flash Dynamic Spectrum Sharing is enabled and the NR TX/RX mode is 2T2R or 2T4R, the recommended value is 2SYM. When the NR TX/RX mode is 4T4R, the recommended value is 1SYM.

Impact on Radio Network Performance

A smaller value of this parameter leads to fewer CCE resources, fewer UEs, but more PDSCH resources in the cell.

A larger value of this parameter leads to the opposite effects.
