Parameter Name

Frequency Range and Duplex Mode
NE

BTS3900, BTS3900 5G, BTS5900, BTS5900 5G
MML Command

ADD NRDUCELLTRP

LST NRDUCELLTRP
Meaning

Indicates the frequency range and duplex mode of the cell. The value FR1_TDD indicates that the current cell works in low-frequency TDD mode. The value FR2_TDD indicates that the current cell works in high-frequency TDD mode. The value FDD indicates that the current cell works in FDD mode. The value SUL indicates that the current cell works in SUL mode.

Caution

This parameter cannot be modified directly. It can be modified only by deleting and then adding the NRDUCellTrp MO.

This parameter must match the frequency band and duplex mode specified in NRDUCell.

After the setting of this parameter is changed, the cell needs to be reset for the change to take effect.
