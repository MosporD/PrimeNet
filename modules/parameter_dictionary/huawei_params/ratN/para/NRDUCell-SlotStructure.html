Parameter Relationship

-Configuration constraints:

  • If SlotAssignment in an NRDUCell MO is set to 8_2_DDDSUUDDDD, SlotStructure in the NRDUCell MO must be set to SS81, SS82, SS83, SS84, SS85, SS86, or SS818. If SlotStructure in an NRDUCell MO is set to SS818, LampSiteCellFlag in the NRDUCell MO must be set to NO.
  • In an NRDUCell MO, if SlotAssignment is set to 8_2_DDDDDDDSUU, SlotStructure must be set to SS51, SS52, SS53, SS54, SS55, SS56, or SS518. In addition, if SlotStructure in the NRDUCell MO is set to SS518, LampSiteCellFlag must be set to NO.
  • In an NRDUCell MO, if SlotAssignment is set to 7_3_DDDSUDDSUU, SlotStructure must be set to SS101, SS102, SS103, SS104, SS105, SS106, or SS1017. In addition, if SlotStructure in the NRDUCell MO is set to SS1017, LampSiteCellFlag must be set to NO.
  • In an NRDUCell MO, if FrequencyBand is set to N38, N40, N41, N77, N78, or N79, and SlotAssignment is set to 4_1_DDDSU, then SlotStructure must be set to SS1, SS2, SS3, SS4, SS5, SS6, or SS18. In addition, if SlotStructure in the NRDUCell MO is set to SS18, LampSiteCellFlag must be set to NO.
  • When FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, and SlotAssignment in this MO is set to 4_1_DDDSU, SlotStructure in the same MO must be set to SS201, SS202, SS203, SS204, SS205, or SS206.
  • If SlotAssignment in an NRDUCell MO is set to 2_3_DSUUU, SlotStructure in the NRDUCell MO must be set to SS21, SS22, or SS23.

-Parameter relationship with conditions:

  • If SlotAssignment is set to 2_3_DSUUU, 4_1_DDDSU, 7_3_DDDSUDDSUU, 8_2_DDDDDDDSUU, 8_2_DDDSUUDDDD, SlotStructure must be set.

Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

With the same slot assignment, a smaller enumerated value results in a smaller GP and higher downlink peak value. However, there is a higher probability of downlink-to-uplink loopback interference and interference among UEs running uplink services. That is, signals of remote UEs cannot reach the base station in time and UEs near the cell center are interfered. This affects uplink coverage and capacity.
