Meaning

Indicates whether to enable the functions of the adaptive edge experience improvement feature.

UL_WAVEFORM_ADAPT_SW: Indicates whether to enable the CP-OFDM and DFT-S-OFDM waveform adaption function in the uplink.

UL_IBLER_ADAPT_SW: Indicates whether to enable the uplink IBLER adaption function.

DL_PMI_SRS_ADAPT_SW: Indicates whether to enable SRS- and PMI-based weight adaption. This option applies only to low-frequency 64T/32T/8T/4T TDD cells.

DL_INTRF_RANDOM_SW: Indicates whether to enable the downlink interference randomization function.

Impact on Radio Network Performance

UL_WAVEFORM_ADAPT_SW: If this option is selected, adaptation between CP-OFDM waveforms and DFT-S-OFDM waveforms in the uplink is enabled to increase the cell coverage. If this option is deselected, the network performance is not affected.

UL_IBLER_ADAPT_SW: If this option is selected, the target IBLER is selected adaptively based on the link status in the uplink, increasing the throughput of edge UEs. If this option is deselected, the network performance is not affected.

DL_PMI_SRS_ADAPT_SW: If this option is selected, SRS-based weights and PMI-based weights are adaptively selected for MIMO. This way, for UEs at near points or far points, a proper weight can be selected to improve transmission performance when SRS resources are insufficient. If this option is deselected, only the SRS-based weights or PMI-based weights are used, which has no impact on network performance.

DL_INTRF_RANDOM_SW: If this option is selected, downlink interference randomization is used for scheduling in light-load scenarios. This decreases inter-cell interference and improves the downlink throughput. If this option is deselected, inter-cell interference increases and the downlink throughput decreases in light-load scenarios. This option does not affect network performance in heavy-load scenarios.
