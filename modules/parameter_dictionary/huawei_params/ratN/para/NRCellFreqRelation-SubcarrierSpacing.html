Meaning

Indicates the SSB subcarrier spacing of a neighboring frequency. The default value is 15KHZ for FDD and 30KHZ for TDD. For details, see 3GPP TS 38.104.

Parameter Relationship

-Configuration constraints:

  • If FrequencyBand in an NRCellFreqRelation MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, SubcarrierSpacing in the NRCellFreqRelation MO must be set to 15KHZ.
  • If FrequencyBand in an NRCellFreqRelation MO is set to N77, N78, or N79, SubcarrierSpacing in the NRCellFreqRelation MO must be set to 30KHZ.
  • If FrequencyBand in an NRCellFreqRelation MO is set to N38, SubcarrierSpacing in the NRCellFreqRelation MO must be set to 15KHZ or 30KHZ.
  • If FrequencyBand in an NRCellFreqRelation MO is set to N40, SubcarrierSpacing in the MO must be set to 30KHZ.
  • If FrequencyBand in an NRCellFreqRelation MO is set to N41, SubcarrierSpacing in the NRCellFreqRelation MO must be set to 15KHZ or 30KHZ.
  • If FrequencyBand in an NRCellFreqRelation MO is set to N257, N258, N260, or N261, SubcarrierSpacing in the NRCellFreqRelation MO must be set to 120KHZ or 240KHZ.
  • In an NRCellFreqRelation MO, if FrequencyBand is set to N38, SubcarrierSpacing is set to 30KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be greater than or equal to 6437 and less than or equal to 6538.
  • In an NRCellFreqRelation MO, if FrequencyBand is set to N38, SubcarrierSpacing is set to 15KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, SsbFreqPos must be set to 6432, 6443, 6457, 6468, 6479, 6493, 6507, 6518, 6532, or 6543.
  • In an NRCellFreqRelation MO, if SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, FrequencyBand is set to N38, and SubcarrierSpacing is set to 15KHZ, the value of the SsbFreqPos must be 514590, 515530, 516530, 517470, 518410, 519410, 520590, 521530, 522530, or 523470.
  • In an NRCellFreqRelation MO, if FrequencyBand is set to N38 and SubcarrierSpacing is set to 30KHZ, the value of SsbFreqPos must be greater than or equal to 515050 and less than or equal to 523010.
