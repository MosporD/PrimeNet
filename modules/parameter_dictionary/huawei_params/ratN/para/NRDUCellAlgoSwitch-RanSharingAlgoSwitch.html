Meaning

Indicates RAN sharing switches.

RB_DYNAMIC_SHARING_SW: If this option is selected and UEs of each operator have sufficient service requirements, the shared data channel resources are used based on the configured RB resource proportion. When the service requirements of an operator are insufficient, other operators can use the shared data channel resources beyond the configured proportion. If this option is deselected, RB resource scheduling is not operator-specific.

MAX_RB_LIMIT_SW: If this option is selected, the amount of data channel resources used by each operator cannot exceed the configured RB proportion. If this option is deselected, the gNodeB does not restrict the maximum proportion of available RBs for an operator.
