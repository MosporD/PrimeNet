Meaning

Indicates the PRACH configuration index of an NR DU cell. For details about this parameter, see 3GPP TS 38.211. When this parameter is set to a value in the range of 0 to 255, the PRACH configuration index of the NR DU cell equals this parameter value. When this parameter is set to 65535, the PRACH configuration index of the NR DU cell is automatically generated.

When this parameter is set to 189, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 120 kHz.

When this parameter is set to 187 or 65535, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 60 kHz.

The valid value range of this parameter is as follows:

When the system frequency band is sub-6 GHz, the duplex mode is FDD, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is SA-only, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is NSA or hybrid NSA and SA, and the subcarrier spacing is 15 kHz: 1, 2, 3, 5, 6, 7, 9, 10, 11, 13, 14, 15, 17, 18, 21, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 30 kHz: 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 0 to 7, 12, 17, 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 0 to 7, 12, 17, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 9, 14, 19, 195, 206, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 9, 14, 19, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 2_3_DSUUU, and the subcarrier spacing is 30 kHz: 10, 15, and 65535

When the system frequency band is mmWave, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz: 187, 189, and 65535

If the value range exceeds the preceding ranges, cell activation fails.

Impact on Radio Network Performance

If the parameter value corresponds to a longer PRACH period, the gNodeB supports lighter access load and fewer uplink resources are occupied. If the parameter value corresponds to a shorter PRACH period, the gNodeB supports heavier access load and more uplink resources are occupied.
