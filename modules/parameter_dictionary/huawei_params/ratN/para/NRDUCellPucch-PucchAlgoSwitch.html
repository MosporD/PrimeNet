Meaning

Indicates the PUCCH adaptation algorithm switch. It determines whether to enable PUCCH resource adjustment.

PUCCH_RES_ADAPTIVE_SWITCH: Indicates whether to enable symbol number resource adjustment for short PUCCH. If this option is selected, the gNodeB automatically adjusts symbols of short PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, symbols of short PUCCH are consumed based on the GUI value. This option applies only to high-frequency TDD cells.

PUCCH_RBRES_ADAPTIVE_SWITCH: Indicates whether to enable RB resource adjustment for long PUCCH. If this option is selected, the gNodeB automatically adjusts RBs of long PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, RBs of long PUCCH are consumed based on the GUI value. This option applies only to FDD and SUL cells not enabled with LTE and NR sharing and TDD cells with NRDUCell.HighSpeedFlag set to LOW_SPEED.

Impact on Radio Network Performance

PUCCH_RES_ADAPTIVE_SWITCH: If the PUCCH_RES_ADAPTIVE_SWITCH option is selected, the base station adaptively increases or decreases the number of PUCCH symbols based on the PUCCH resource load. This improves PUCCH resource utilization and reduces uplink control signaling overheads. If a small number of UEs access the network, the number of used PUCCH resources decreases, and the uplink throughput increases. If a large number of UEs access the network, the number of used PUCCH resources increases, and the uplink throughput decreases. If this option is deselected, this function does not take effect and network performance is not affected.

PUCCH_RBRES_ADAPTIVE_SWITCH: If the PUCCH_RBRES_ADAPTIVE_SWITCH option is selected, the base station adaptively increases or decreases the number of PUCCH RBs based on the PUCCH resource load. This improves PUCCH resource utilization and reduces uplink control signaling overheads. If a small number of UEs access the network, fewer PUCCH resources are used and the uplink throughput improves. If a large number of UEs access the network, more PUCCH resources are used and the uplink throughput deteriorates. If this option is deselected, the algorithm does not take effect and network performance is not affected.
