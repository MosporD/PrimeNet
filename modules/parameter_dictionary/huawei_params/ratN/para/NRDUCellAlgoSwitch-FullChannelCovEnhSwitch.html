MOD NRDUCELLALGOSWITCH

LST NRDUCELLALGOSWITCH
Meaning

Indicates whether to enable enhanced full-channel coverage functions.

SSB_PA_SW: Indicates whether to enable SSB power aggregation. When this option is selected and the MaxSsbPwrOffset parameter value is greater than 0, SSB power aggregation is enabled. When this option is deselected, SSB power aggregation is disabled.

Disuse statement: The SSB_PA_SW option no longer controls the SSB power aggregation function, and the MaxSsbPwrOffset parameter takes effect directly. This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

PDSCH_PRECISE_PMI_SW: Indicates whether to enable PDSCH precise PMI weight. PDSCH precise PMI weight is enabled only when this option is selected.

PUSCH_BEAM_DOMAIN_EHN_SW: Indicates whether to enable PUSCH beam-domain enhancement. PUSCH beam-domain enhancement is enabled only when this option is selected. This option takes effect only for low-frequency 64T/32T TDD cells.

PUSCH_TIME_DOMAIN_ENH_SW: Indicates whether to enable PUSCH time-domain enhancement. PUSCH time-domain enhancement is enabled only when this option is selected. This option takes effect only for low-frequency 64T/32T TDD cells.

NARROW_BEAM_PROBE_SW: Indicates whether to enable the narrow beam probe function for access channels. This function is enabled only if this option is selected. This option applies only to high-frequency TDD cells.

ACK_NACK_REPORTING_PUSCH_SW: Indicates whether to report ACK/NACK on the PUSCH. If this option is selected, ACK/NACK of cell edge users can be transmitted together with data on the PUSCH. If this option is deselected, ACK/NACK of cell edge users cannot be transmitted together with data on the PUSCH. This option applies only to high-frequency TDD cells.

Impact on Radio Network Performance

SSB_PA_SW: When this option is selected and the maximum SSB power offset is greater than 0 (MaxSsbPwrOffset > 0), the SSB coverage improves but the number of available PRBs slightly decreases. When this option is deselected, the SSB coverage decreases.

PDSCH_PRECISE_PMI_SW: When this option is selected, the PDSCH coverage increases. When this option is deselected, the PDSCH coverage decreases.

PUSCH_BEAM_DOMAIN_EHN_SW: When this option is selected, the PUSCH coverage increases. When this option is deselected, the PUSCH coverage decreases.

PUSCH_TIME_DOMAIN_ENH_SW: When this option is selected, the PUSCH coverage increases. When this option is deselected, the PUSCH coverage decreases.

NARROW_BEAM_PROBE_SW: When this option is selected, the access coverage radius increases, but the access delay may increase. When this option is deselected, the access coverage radius decreases.

ACK_NACK_REPORTING_PUSCH_SW: When this option is selected, the ACK/NACK feedback of UEs at the cell edge can be reported over the PUSCH, which extends the cell coverage but decreases the uplink traffic of UEs at the cell center by about 6%. When this option is deselected, the ACK/NACK feedback of UEs is reported over the short PUCCH.
