Meaning

Indicates the length of the long DRX cycle. The DRX feature takes effect only if the value of LongCycle is less than or equal to one sixth of the value of UlTimeAlignmentTimer in the NRDUCellUlTaConfig MO.

Impact on Radio Network Performance

This parameter, together with the OnDurationTimer, DrxInactivityTimer, ShortCycle, ShortCycleTimer, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay, and a larger value of this parameter results in the opposite effects.
