Meaning

Indicates the starting frequency-domain position of PRACH resources relative to the initial BWP. For details, see 3GPP TS 38.321.The values 0 to 272 indicate that the starting frequency-domain position of PRACH equals the parameter value. The value 65535 indicates that the starting frequency-domain position of PRACH is automatically generated. This parameter does not take effect when LTE FDD and NR Uplink Spectrum Sharing is enabled on both the LTE and NR sides and the uplink spectrum sharing mode is set to dynamic sharing or when LTE FDD and NR Flash Dynamic Spectrum Sharing is enabled.

Parameter Relationship

-Configuration constraints:

  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_10M, PrachFreqStartPosition can be set to a value within the range from 2 to 44, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_20M, PrachFreqStartPosition can be set to a value within the range from 2 to 98, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to 5 MHz, PrachFreqStartPosition can be set to a value within the range from 2 to 17, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_15M, PrachFreqStartPosition can be set to a value within the range from 2 to 71, or to 65535.

Caution

Modification of this parameter will cause the local cell to reset. If this parameter is set to 65535, the starting frequency-domain position of PRACH is automatically generated by the gNodeB.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

Adjusting this parameter affects the frequency domain position of PRACH resources.

Adjusting this parameter affects the interference to the PRACH in the cell and the interference to the PRACH and PUSCH of neighboring cells.

Adjusting this parameter affects the maximum number of RBs for consecutive scheduling of the PUSCH.
