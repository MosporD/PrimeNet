Meaning

Indicates whether to enable intra-RAT inter-frequency handover algorithms.

COVERAGE_BASED_HO: Indicates whether to enable coverage-based inter-frequency handover. If this option is selected, coverage-based inter-frequency handovers are enabled to ensure service continuity. If this option is deselected, coverage-based inter-frequency handovers are disabled.

FREQ_PRIORITY_BASED_HO: Indicates whether to enable frequency-priority-based inter-frequency handover. Select this option if a frequency is dedicated for absorbing traffic. If this option is selected, frequency-priority-based handovers can be triggered for UEs even when the serving cell has good signal quality. If this option is deselected, frequency-priority-based inter-frequency handovers cannot be triggered for UEs, and inter-frequency handovers can be triggered only when other conditions for triggering handovers are met.

REDIRECTION: Indicates whether to enable inter-frequency redirection. If this option is selected, inter-frequency redirection and blind redirection are supported. If this option is deselected, inter-frequency redirection and blind redirection are not supported.

OP_DED_PRI_BASED_HO: Indicates whether to enable operator-specific-priority-based inter-frequency handover. If this option is selected, an operator-specific-priority-based inter-frequency handover can be triggered for a UE served by a frequency meeting the following condition: the frequency is not an NR frequency in the operator-associated frequency group with the dedicated frequency priority for the connected mode set to a non-zero value. If this option is deselected, operator-specific-priority-based inter-frequency handovers cannot be triggered for the UE.

Impact on Radio Network Performance

COVERAGE_BASED_HO: When this option is selected, inter-frequency handovers ensure service continuity and reduce the service drop rate. When this option is deselected, the service drop rate may increase.

FREQ_PRIORITY_BASED_HO: When this option is selected, frequency-priority-based inter-frequency handovers are enabled. This increases the number of handovers but improves the data rates of UEs. When this option is deselected, network performance is not affected.

REDIRECTION: When this option is selected, coverage-based inter-frequency redirection can be triggered for UEs that do not support inter-frequency handovers. When the signal quality decreases sharply, blind redirection to another frequency can be performed to reduce the service drop rate. When this option is deselected, coverage-based inter-frequency redirection and blind redirection are disabled. This may increase the service drop rate.

OP_DED_PRI_BASED_HO: When this option is selected, operator-specific-priority-based inter-frequency handovers can be triggered for UEs. This increases the number of inter-frequency handovers but enables operator-level network steering. When this option is deselected, network performance is not affected.
