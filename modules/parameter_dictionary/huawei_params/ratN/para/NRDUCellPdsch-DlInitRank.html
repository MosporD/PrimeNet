Meaning

Indicates the initial downlink rank (number of PDSCH spatial multiplexing layers) during the period between the first SRS reporting and the first CQI reporting after the access. If this parameter is set to RANK1, RANK2, RANK3, or RANK4, the rank value that takes effect is the GUI value or the maximum downlink MIMO capability reported by the UE, whichever is smaller. This parameter applies only to 8T8R, 32T32R, and 64T64R TDD modules.

Disuse statement: In the current version, the value range of this parameter is RANK1 to RANK8. In later versions, the value range will be RANK1 to RANK4. In the current version, if this parameter is set to a value greater than RANK4 and less than or equal to RANK8, the value can still be synchronized and delivered. However, the system automatically takes RANK1 as the effective value. Therefore, you are advised not to set this parameter to a value greater than RANK4.
