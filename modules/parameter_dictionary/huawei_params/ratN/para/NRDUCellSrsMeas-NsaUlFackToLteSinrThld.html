Impact on Radio Network Performance

A larger value of this parameter results in a higher probability for the NSA DC uplink data split mode to change to the LTE-only mode based on the signal quality of the NR cell. If the LTE uplink throughput is low, the NSA DC uplink throughput may decrease. A smaller value of this parameter results in the opposite effect, and LTE uplink coverage gains may not be obtained in a timely manner.
