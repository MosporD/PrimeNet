Meaning

Indicates the azimuth mapping a weight for beamforming. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the azimuth is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the azimuth of the cell exceeds the range supported by the AAU, the cell becomes unavailable.

Caution

If only one cell in a sector is activated, the cell will be reestablished and services will be interrupted. Therefore, it is recommended that this operation be performed during off-peak hours. Ensure that this parameter is set to the same value for all cells in the same sector. In addition, the azimuth must be within the value range supported by the AAU. Otherwise, the cells are unavailable. It is recommended that the interval between two modifications be greater than 10 minutes.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

Adjusting the azimuth affects the radio coverage range, which results in network KPI changes. Set this parameter based on onsite coverage.
