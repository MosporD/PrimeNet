Impact

NRDUCell
Parameter Relationship

-Configuration constraints:

  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 15KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, SsbFreqPos must be set to 6432, 6443, 6457, 6468, 6479, 6493, 6507, 6518, 6532, or 6543.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 15KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, SsbFreqPos must be set to 514590, 515530, 516530, 517470, 518410, 519410, 520590, 521530, 522530, or 523470.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 30KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be greater than or equal to 6437 and less than or equal to 6538.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 30KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, the value of SsbFreqPos must be greater than or equal to 515050 and less than or equal to 523010.
  • If FrequencyBand in the NRDUCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66 or N71, SsbSubcarrierSpacing in the NRDUCell MO must be set to 15KHZ. If FrequencyBand in the NRDUCell MO is set to N80, N82, N83, N84, or N86, SsbSubcarrierSpacing in the NRDUCell MO must be set to 15KHZ. If FrequencyBand in an NRDUCell MO is set to N38, SsbSubcarrierSpacing in the NRDUCell MO must be set to 15KHZ or 30KHZ. If FrequencyBand in the NRDUCell MO is set to N41, N77, N78, or N79, SsbSubcarrierSpacing in the NRDUCell MO must be set to 30KHZ. If FrequencyBand in the NRDUCell MO is set to N257, N258, N260, or N261, SsbSubcarrierSpacing in the NRDUCell MO must be set to 120KHZ.
  • In an NRDUCell MO, if FrequencyBand is set to N40, SsbSubcarrierSpacing must be set to 30KHZ.

-Parameter relationship with conditions:

  • If FrequencyBand is set to N1, N2, N20, N25, N257, N258, N260, N261, N28, N3, N38, N40, N41, N5, N66, N7, N71, N77, N78, N79, N8, N80, N82, N83, N84, N86, SsbSubcarrierSpacing is valid.
