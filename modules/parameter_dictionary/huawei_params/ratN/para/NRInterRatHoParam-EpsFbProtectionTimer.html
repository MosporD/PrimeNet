Impact on Radio Network Performance

A large value of this parameter leads to a long waiting time and increases the EPS fallback delay. If this parameter is set to a small value, the source gNodeB triggers blind redirection before UEs complete measurement, send measurement results after measurement, or complete a normal handover procedure. In this case, UEs are handed over through blind redirection instead of a PS handover procedure which can be successfully performed, increasing the EPS fallback delay.
