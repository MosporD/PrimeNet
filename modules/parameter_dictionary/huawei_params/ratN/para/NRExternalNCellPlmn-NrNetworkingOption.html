Meaning

Indicates the secondary-operator networking option of an external NR cell. The value UNLIMITED indicates the initial state of the secondary operator to which an external cell belongs. That is, a secondary operator to which an external cell belongs works in unknown networking mode, and the cell can serve as a target cell for handovers. The value SA indicates that a secondary operator to which an external cell belongs works in SA networking mode. The value NSA indicates that a secondary operator to which an external cell belongs works in NSA networking mode. The value SA_NSA indicates that a secondary operator to which an external cell belongs works in SA and NSA hybrid networking mode.
