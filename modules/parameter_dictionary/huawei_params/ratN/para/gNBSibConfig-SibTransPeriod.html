Impact

gNBSibConfig
Parameter Relationship

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Caution

The cell that references SibConfigId will automatically restart.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

A smaller value of this parameter results in a shorter SIB transmission period, higher occupied resource overhead, shorter delay in SIB reading, and fewer SIB types that can be enabled. A larger value of this parameter results in the opposite effects.
