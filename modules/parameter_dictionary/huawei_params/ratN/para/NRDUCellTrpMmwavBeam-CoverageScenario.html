Meaning

Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. The DSP NRDUCELLTRP command can be executed to query the coverage scenarios supported by different types of AAUs. This parameter applies only to high-frequency cells.

Caution

Adjusting the scenario ID triggers cell reestablishment, and services are interrupted. Therefore, you are advised to perform this operation during off-peak hours. Ensure that this parameter is set to the same value for all cells in the same sector. Otherwise, the cells are unavailable. It is recommended that the interval between two modifications be greater than 10 minutes.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

Adjusting the beam form of an antenna affects the radio coverage range, which results in network KPI changes. Set this parameter based on onsite coverage.
