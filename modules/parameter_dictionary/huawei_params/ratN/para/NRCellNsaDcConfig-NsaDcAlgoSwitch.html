Meaning

Indicates LTE-NR NSA DC algorithm switches.

UL_FALLBACK_TO_LTE_SWITCH: Indicates whether to enable the function of falling back uplink transmission to LTE in NSA DC scenarios. This function is enabled only if this option is selected.

NSA_DC_ENH_UL_POWER_CONTROL_SW: Indicates whether to enable enhanced uplink power control for NSA DC UEs in a cell. If this option is selected, enhanced uplink power control for NSA DC UEs is enabled in a cell, and TDM power control or dynamic power sharing is performed in the uplink of NSA DC UEs based on their capabilities. If this option is deselected, enhanced uplink power control for NSA DC UEs is disabled in a cell. With TDM power control of enhanced uplink power control for NSA DC UEs triggered, the value of gNodeBParam.NsaDcResCoordScenario determines the TDM pattern the gNodeB sends to the eNodeB. When gNodeBParam.NsaDcResCoordScenario is set to ASYNC_NSA_DC, TDM power control does not take effect.

HIGH_POWER_UE_SUPPORT_SWITCH: Indicates whether a cell supports high-power UEs. A cell supports high-power UEs only if this option is selected.

SN_TERMN_MCG_BEARER_SWITCH: Indicates whether a cell supports SN-terminated MCG bearers. A cell supports SN-terminated MCG bearers only if this option is selected. SN is short for secondary node.

NSA_DC_PREALLOCATION_SW: Indicates whether to enable preallocation in NSA DC scenarios. Preallocation is enabled in NSA DC scenarios only if this option is selected.

SINGLE_UL_NSA_SW: Indicates whether a cell supports uplink single-RAT transmission. Uplink single-RAT transmission is supported only if this option is selected. This parameter applies only to FDD.

NSA_DC_COOPERATION_DPS_SW: Indicates whether to enable the coordinated dynamic power sharing function in NSA DC scenarios. The coordinated dynamic power sharing function is enabled in NSA DC scenarios only if this option is selected.

MENB_TRIG_INTRA_SGNB_CHANGE_SW: Indicates whether to support the intra-SgNB cell change procedure triggered by the MeNB. The intra-SgNB cell change procedure triggered by the MeNB is supported only if this option is selected.

NSA_DC_UL_PATH_SELECTION_SW: Indicates whether to support uplink data transmission path selection in NSA DC scenarios. The uplink data transmission path is selected based on factors such as load and air interface quality only if this option is selected.

PDCP_SN_OFFSET_SW: Indicates whether to apply the PDCP SN offset. If this option is selected, the PDCP SN offset takes effect so that an SN offset is added for the packets sent to the low-speed side. If this option is deselected, the PDCP SN offset does not take effect.

Impact on Radio Network Performance

UL_FALLBACK_TO_LTE_SWITCH: If this option is selected, uplink data transmission at the edge of an NR cell is performed only on the LTE side to avoid low transmission efficiency or transmission failure on the NR side. If this option is deselected, uplink data may be blocked on the NR side at the edge of the NR cell if the uplink data split policy is dynamic split or data transmission only on the NR side. In this case, the transmission efficiency is low or transmission fails.

NSA_DC_ENH_UL_POWER_CONTROL_SW: If this option is selected, there are two cases: if UEs support the TDM function, TDM uplink power control is triggered at the edge of an NR or LTE cell, which increases the maximum uplink transmit power and avoids service drops of NSA DC UEs; if UEs support dynamic power sharing, uplink power of NSA DC UEs is shared between LTE and NR and the uplink power is preferentially guaranteed for the LTE side, which increases the uplink transmit power on the LTE side and avoids service drops of NSA DC UEs. If this option is deselected, NSA DC UEs at the edge of an NR or LTE cell may experience service drops due to insufficient uplink power.

HIGH_POWER_UE_SUPPORT_SWITCH: If this option is selected, the configured maximum transmit power is dependent on the UE type. If device-pipe synergy UEs report a power value exceeding that specified in 3GPP specifications, the gNodeB configures the maximum transmit power for the UEs based on UE capabilities. This helps improve uplink coverage. If this option is deselected, the maximum transmit power configured on the NR side does not exceed the value specified in 3GPP specifications. In this case, the NR uplink coverage area decreases.

SN_TERMN_MCG_BEARER_SWITCH: If this option is selected, the bearer is still terminated on the NR side if the SCG needs to be deleted due to limited NR coverage. This eliminates switching the termination point of a bearer between NR and LTE. In this case, the number of ERAB MOD IND messages over the S1 interface is reduced. If this option is deselected, the termination point of a bearer is switched to LTE if the SCG needs to be deleted due to limited NR coverage. In this case, ERAB MOD IND messages need to be sent over the S1 interface.

NSA_DC_PREALLOCATION_SW: If this option is selected, uplink data transmission latency of NSA DC UEs is shortened but uplink interference and UE power consumption increase. If this option is deselected, network performance is not affected.

SINGLE_UL_NSA_SW: If this option is selected, uplink single-RAT transmission in NSA is supported for the band combination configured in the gNBDedNsaDcBandComb MO. This decreases the uplink throughput and improves the uplink coverage by 3 dB compared with two-RAT uplink transmission in NSA. If this option is deselected, uplink single-RAT transmission in NSA is not supported.

NSA_DC_COOPERATION_DPS_SW: If this option is selected and UEs support dynamic power sharing, the maximum power is configured for LTE and NR to improve LTE and NR coverage. If this option is deselected, network performance is not affected.

MENB_TRIG_INTRA_SGNB_CHANGE_SW: In MeNB and SgNB co-site co-coverage scenarios, if this option is selected, the intra-MeNB cell change and intra-SgNB cell change occur at the same time, reducing the number of intra-SgNB cell changes and the number of drastic NR user-plane rate decreases. If this option is deselected, the intra-MeNB cell change and intra-SgNB cell change do not occur at the same time, and the number of intra-SgNB cell changes is not affected.

NSA_DC_UL_PATH_SELECTION_SW: If this option is selected, uplink data transmission path is selected based on factors such as load and air interface quality, improving the uplink throughput of NSA DC UEs. If this option is deselected, network performance is not affected.

PDCP_SN_OFFSET_SW: If this option is deselected, network performance is not affected. If this option is selected, data is preferentially sent to the high-speed side between LTE and NR. In this case, downlink traffic volume of the high-speed side increases and that of the other side decreases.
