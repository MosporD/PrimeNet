Meaning

Indicates the UE-specific threshold of the PDU data volume to trigger polling. When the data volume of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.

Impact on Radio Network Performance

To prevent buffer overflow caused by an excessively long queue, the transmitter sends status reports based on the data volume of transmitted PDUs. A small value of this parameter may result in a large number of polling PDU transmissions. A large value leads to high buffer occupation and a slow speed of send window movement.
