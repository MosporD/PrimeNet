Meaning

Indicates the ANR mode switches.

NR_NR_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for intra-NR ANR. When the controlled mode is disabled, the gNodeB automatically configures neighboring NR cells. When the controlled mode is enabled, the gNodeB reports neighboring NR cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_NR_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring NR cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for intra-NR ANR.

NR_EUTRAN_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for ANR with E-UTRAN. When the controlled mode is disabled, the gNodeB automatically configures neighboring E-UTRAN cells. When the controlled mode is enabled, the gNodeB reports neighboring E-UTRAN cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_EUTRAN_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring E-UTRAN cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for ANR with E-UTRAN.

EUTRAN_NCELL_PLMN_RR_MODE_SW: Indicates whether neighboring E-UTRAN cells support the PLMN round robin mode in RAN sharing scenarios.

Impact on Radio Network Performance

NR_NR_ANR_CTRL_MODE_SW: When this option is selected, the gNodeB reports neighboring NR cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation. When this option is deselected, the gNodeB can automatically configure neighboring NR cells, with no reports sent to the MAE.

NR_NR_ANR_CTRL_MODE_HO_SW: When this option is selected, handovers can be initiated to the neighboring NR cells to be confirmed and added in controlled mode. When this option is deselected, handovers cannot be initiated to the neighboring NR cells to be confirmed and added in controlled mode.

NR_EUTRAN_ANR_CTRL_MODE_SW: When this option is selected, the gNodeB reports neighboring E-UTRAN cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation. When this option is deselected, the gNodeB can automatically configure neighboring E-UTRAN cells, with no reports sent to the MAE.

NR_EUTRAN_ANR_CTRL_MODE_HO_SW: When this option is selected, handovers can be initiated to the neighboring E-UTRAN cells to be confirmed and added in controlled mode. When this option is deselected, handovers cannot be initiated to the neighboring E-UTRAN cells to be confirmed and added in controlled mode.

EUTRAN_NCELL_PLMN_RR_MODE_SW: When this option is selected, neighboring E-UTRAN cells are considered as cells that support MOCN with round-robin of the PLMN ID list. The primary PLMN ID may not be listed at the top of the PLMN ID list, and you need to use the MAE to query the actual primary PLMN ID. When this option is deselected, neighboring E-UTRAN cells are not considered as cells that support MOCN with round-robin of PLMN IDs.
