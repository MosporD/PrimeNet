  • When FrequencyBand in an NRDUCell MO is set to N261, DlNarfcn in the NRDUCell MO must be set to a value within the range from 2070833 to 2084999.
  • In an NRDUCell MO, if FrequencyBand is set to N1, DlNarfcn must be set to a value greater than or equal to 422000 and less than or equal to 434000.
  • In an NRDUCell MO, if FrequencyBand is set to N2, DlNarfcn must be set to a value greater than or equal to 386000 and less than or equal to 398000.
  • In an NRDUCell MO, if FrequencyBand is set to N5, DlNarfcn must be set to a value greater than or equal to 173800 and less than or equal to 178800.
  • In an NRDUCell MO, if FrequencyBand is set to N7, DlNarfcn must be set to a value greater than or equal to 524000 and less than or equal to 538000.
  • In an NRDUCell MO, if FrequencyBand is set to N8, DlNarfcn must be set to a value greater than or equal to 185000 and less than or equal to 192000.
  • In an NRDUCell MO, if FrequencyBand is set to N20, DlNarfcn must be set to a value greater than or equal to 158200 and less than or equal to 164200.
  • In an NRDUCell MO, if FrequencyBand is set to N25, DlNarfcn must be set to a value greater than or equal to 386000 and less than or equal to 399000.
  • In an NRDUCell MO, if FrequencyBand is set to N66, When UlBandwidth is CELL_BW_10M and DlBandwidth is CELL_BW_20M, DlNarfcn must be set to a value greater than or equal to 423000 and less than or equal to 436000. Otherwise, DlNarfcn must be set to a value greater than or equal to 422000 and less than or equal to 440000.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than or equal to 2016667 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_100M or CELL_BW_200M.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than 537999 and less than or equal to 680000 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, CELL_BW_100M, CELL_BW_20M, CELL_BW_30M, CELL_BW_50M, CELL_BW_70M, or CELL_BW_90M.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than or equal to 693333, and less than or equal to 733333 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, or CELL_BW_100M.
  • In an NRDUCell MO, if DlNarfcn is set to a value smaller than 2016667 and DuplexMode is set to CELL_FDD, DlBandwidth must be set to CELL_BW_5M, CELL_BW_10M, CELL_BW_15M, or CELL_BW_20M.
  • When UlNarfcn in an NRDUCell MO is not set to 0 and DuplexMode in the same MO is set to CELL_TDD, DlNarfcn and UlNarfcn must be set to the same value.
  • If DuplexMode in the NRDUCell MO is set to CELL_FDD, the values of UlNarfcn and DlNarfcn in the NRDUCell MO must be integer multiples of 20.
  • When FrequencyBand in the NRDUCell MO is set to N41 and SubcarrierSpacing in the NRDUCell MO is set to 30KHZ, DlNarfcn in the NRDUCell MO must be set to a multiple of 6.
  • If UlNarfcn in the NRDUCell MO is not equal to 0, UlNarfcn in the NRDUCell MO must be set to a multiple of 6.
  • When FrequencyBand in the NRDUCell MO is set to N77, N78, or N79, and SubcarrierSpacing in the NRDUCell MO is set to 30KHZ, DlNarfcn in the NRDUCell MO must be set to a multiple of 2.
  • If UlNarfcn in the NRDUCell MO is not equal to 0, UlNarfcn in the NRDUCell MO must be set to a multiple of 2.
  • When FrequencyBand in the NRDUCell MO is set to N257, N258, N260, or N261, and SubcarrierSpacing in the NRDUCell MO is set to 120KHZ, DlNarfcn in the NRDUCell MO must be set to an odd number.
  • If UlNarfcn in the NRDUCell MO is not equal to 0, UlNarfcn in the NRDUCell MO must be set to an odd number.
  • If FrequencyBand in an NRDUCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, and DlBandwidth is set to CELL_BW_5M, the frequency spacing between the positions specified by SsbFreqPos and DlNarfcn must be less than or equal to the value of SubcarrierSpacing multiplied by 30.
  • When DuplexMode in an NRDUCell MO is set to CELL_FDD, and FrequencyBand in an NRDUCell MO is set to N66, and UlBandwidth in an NRDUCell MO is set to CELL_BW_10M, and DlBandwidth in an NRDUCell MO is set to CELL_BW_20M, and UlNarfcn in an NRDUCell MO is not set to 0, the difference between DlNarfcn and UlNarfcn must be greater than or equal to 79000 and less than or equal to 81000.
  • If FrequencyBand in an NRDUCell MO is set to N38, DlNarfcn in the NRDUCell MO must be set to an integer multiple of 20. If UlNarfcn in the NRDUCell MO is not set to 0, UlNarfcn in the NRDUCell MO must be set to an integer multiple of 20.
  • If FrequencyBand in an NRDUCell MO is set to N40, both DlNarfcn and UlNarfcn in the NRDUCell MO must be set to an integer multiple of 20.
  • If AdditionalFrequencyBand in an NRDUCell MO is set to N78, the following must be true:

  • When DlBandwidth in the NRDUCell MO is set to CELL_BW_50M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 621667 and less than or equal to 651666.
  • If AdditionalFrequencyBand in an NRDUCell MO is set to N257, the following must be true: When DlBandwidth in the NRDUCell MO is set to CELL_BW_100M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2054999 and less than or equal to 2103332; when DlBandwidth in the NRDUCell MO is set to CELL_BW_200M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2055832 and less than or equal to 2102499. If AdditionalFrequencyBand in an NRDUCell MO is set to N258, the following must be true: When DlBandwidth in the NRDUCell MO is set to CELL_BW_100M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2017499 and less than or equal to 2069999; when DlBandwidth in the NRDUCell MO is set to CELL_BW_200M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2018322 and less than or equal to 2069166. If AdditionalFrequencyBand in an NRDUCell MO is set to N261, the following must be true: When DlBandwidth in the NRDUCell MO is set to CELL_BW_100M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2071666 and less than or equal to 2084166; when DlBandwidth in the NRDUCell MO is set to CELL_BW_200M, the value of DlNarfcn in the NRDUCell MO must be greater than or equal to 2072499 and less than or equal to 2083332.
  • If AdditionalFrequencyBand in an NRDUCell MO is set to N2, the following must be true:
