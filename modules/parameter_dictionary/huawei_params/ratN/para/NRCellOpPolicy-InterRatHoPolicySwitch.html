Meaning

Indicates inter-RAT handover policy switches for an operator. The switches separately determine whether to enable a specific type of handover measures.

EUTRAN_HO_SWITCH: Indicates whether NG-RAN can hand over UEs to E-UTRAN. NG-RAN can hand over UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_HO_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

EUTRAN_REDIRECT_SWITCH: Indicates whether NG-RAN can redirect UEs to E-UTRAN. NG-RAN can redirect UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_REDIRECT_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

VOICE_BLIND_MODE_SWITCH: Indicates whether NG-RAN can perform EPS fallback and emergency call fallback in a blind mode. NG-RAN can perform EPS fallback and emergency call fallback in a blind mode only if this option is selected. In regard to the blind mode supported in the current version, only blind redirection is supported. This option takes effect only when the VOICE_BLIND_MODE_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.
