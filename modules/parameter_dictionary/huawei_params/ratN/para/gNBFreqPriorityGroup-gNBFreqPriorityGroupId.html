Parameter Relationship

-Configuration constraints:

  • A maximum of eight gNBFreqPriorityGroup MO instances with the same gNBFreqPriorityGroupId and RatType can be configured.
  • In the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId, the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to EUTRAN must be different from the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to NR.
  • The values of SsbFreqPos in the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId and RatType set to NR must be different.
  • The values of DlEarfcn in the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId and RatType set to EUTRAN must be different.
