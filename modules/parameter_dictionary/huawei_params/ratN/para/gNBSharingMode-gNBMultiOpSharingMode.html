Indicates the gNodeB multi-operator sharing mode, which can be independent operator mode, RAN sharing with common carriers, and RAN sharing with dedicated carriers.

Caution

In independent operator mode, only one operator can be configured and the operator must be the primary operator for the base station. After the multi-operator sharing mode is modified (by running the MOD GNBSHARINGMODE command), run the RST APP command to manually restart the application referenced by gNodeBFunction for the modification to take effect. You can run the LST GNODEBFUNCTION command to query the application ID referenced by gNodeBFunction. If the application is not restarted 10 minutes after the gNodeB multi-operator sharing mode is changed, ALM-26245 Configuration Data Inconsistency is reported.
Validation of Modification

The RST APP command must be executed to validate the parameter modification.
