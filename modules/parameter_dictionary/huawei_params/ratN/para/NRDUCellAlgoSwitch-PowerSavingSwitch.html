Meaning

Indicates the power saving switches.

TIMING_CARRIER_SHUTDOWN_SW: Indicates whether to enable timing carrier shutdown. This function is enabled only when this option is selected. When this function is enabled, carriers are shut down at the preset time.

LNR_SMART_CARRIER_SHUTDOWN_SW: Indicates whether to enable LTE and NR intelligent carrier shutdown. This function is enabled only when this option is selected. When this function is enabled, the carrier is shut down at the preset time based on the load information and cell status of the local cell and neighboring co-coverage LTE cells.

RF_SHUTDOWN_SW: Indicates whether to enable RF channel shutdown. This function is enabled only when this option is selected. When this function is enabled, RF channels are shut down at the preset time under the specified load condition.

POWER_SAVING_SCHEDULE_SW: Indicates whether to enable power saving scheduling. This function is enabled only when this option is selected. This function takes effect at the preset time under the specified load condition.

MULTI_RAT_SYMBOL_SHUTDOWN_SW: Indicates whether to enable multi-RAT symbol power saving in an NR DU cell. This function is enabled only when this option is selected.

DYNAMIC_SSB_SW: Indicates whether to enable functions related to the dynamic SSB. This function is enabled only when this option is selected.

LNR_BUNDLED_SCHEDULING_SW: Indicates whether to enable LTE and NR bundled scheduling for multi-RAT symbol power saving for an NR DU cell. This function is enabled only when this option is selected.

DEEP_SYMBOL_SHUTDOWN_SW: Indicates whether to enable deep symbol power saving. This function is enabled only when this option is selected.

Parameter Relationship

-Configuration constraints:

  • If the POWER_SAVING_SCHEDULE_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, SymbolShutdownSwitch in the NRDUCellAlgoSwitch MO under the same cell must be set to ON.
  • If the MULTI_RAT_SYMBOL_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, SymbolShutdownSwitch must be set to ON.
  • If the DYNAMIC_SSB option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, SymbolShutdownSwitch in the NRDUCellAlgoSwitch MO must be set to ON.
  • If the DEEP_SYMBOL_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, SymbolShutdownSwitch in the NRDUCellAlgoSwitch MO must be set to ON.
  • If the RF_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, VmimoSwitch in the NRDUCellAlgoSwitch MO must be set to OFF.
  • If the RF_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, the LTE_NR_TDD_SPCT_SHR_SW option of SpectrumCloudSwitch in the NRDUCellAlgoSwitch MO must be deselected.
  • If the LNR_BUNDLE_SCHEDULING_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, the POWER_SAVING_SCHEDULE_SW option of PowerSavingSwitch in the NRDUCellAlgoSwitch MO must also be selected.
  • If the LNR_BUNDLE_SCHEDULING_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, the MULTI_RAT_SYMBOL_SHUTDOWN option of PowerSavingSwitch in the NRDUCellAlgoSwitch MO must also be selected.

Impact on Radio Network Performance

TIMING_CARRIER_SHUTDOWN_SW: If this option is selected, cells do not provide services when the shutdown conditions are met, which reduces the base station power consumption. If this option is deselected, radio network performance is not affected.

LNR_SMART_CARRIER_SHUTDOWN_SW: If this option is selected, the user-perceived rate decreases when the cell enters the LTE and NR intelligent carrier shutdown mode. If this option is deselected and the cell exits the LTE and NR intelligent carrier shutdown mode, network performance is not affected.

RF_SHUTDOWN_SW: If this option is selected, the base station power consumption and user-perceived rate decrease when the cell enters the RF channel shutdown mode. If this option is deselected and the cell exits the RF channel shutdown mode, network performance is not affected.

POWER_SAVING_SCHEDULE_SW: If this option is selected, the base station power consumption decreases and the UE delay increases when the cell enters the power saving scheduling mode. If this option is deselected and the cell exits the power saving scheduling mode, network performance is not affected.

MULTI_RAT_SYMBOL_SHUTDOWN_SW: If this option is selected, the multimode base station power consumption decreases when the cell enters the multi-RAT symbol power saving mode. When multi-RAT bundled scheduling takes effect, the UE delay increases. If this option is deselected and the cell exits the multi-RAT symbol power saving mode, network performance is not affected.

DYNAMIC_SSB_SW: If this option is selected, the cell enters the dynamic SSB mode. When this feature takes effect, the multimode base station power consumption decreases. If this option is deselected and the cell exits the dynamic SSB mode, network performance is not affected.

LNR_BUNDLED_SCHEDULING_SW: If this option is selected, the multimode base station power consumption decreases and the UE delay increases when the cell enters the LTE and NR bundled scheduling mode. If this option is deselected and the cell exits the LTE and NR bundled scheduling mode, network performance is not affected.

DEEP_SYMBOL_SHUTDOWN_SW: If this option is selected, the base station power consumption decreases when the cell enters the deep symbol power saving mode, which has no impact on network performance. If this option is deselected and the cell exits the deep symbol power saving mode, network performance is not affected.
