Baseband Resource Mutual Aid Switch

Meaning

Indicates the baseband resource mutual aid switch for the TRP in an NR DU cell. This parameter is valid only when the baseband equipment ID is valid. When this parameter is set to ON, the cell can use other baseband equipment resources when the baseband equipment resources configured for the cell are faulty. After the baseband equipment recovers, the cell automatically reestablishes in the early morning and attempts to return to the configured baseband equipment. When this parameter is set to OFF, the cell can use only the baseband equipment resources corresponding to the baseband equipment ID.

Caution

After BbResMutualAidSw is set to ON, the cell can be reestablished on other baseband equipment if the baseband equipment used by the TRP for the specified NR DU cell is faulty.

After the fault in the baseband equipment used by the TRP for the specified NR DU cell is rectified, the system automatically resets at 03:00 in the morning and reestablishes the cell on this baseband equipment.

When the value of BbResMutualAidSw is changed from ON to OFF and the cell is using resources of other baseband equipment due to baseband resource mutual aid, the cell is automatically resets. In addition, the cell is set up again by using the baseband equipment resources used by the TRP for the specified NR DU cell. Before modifying this parameter, ensure that the baseband equipment used by the TRP for the specified cell is running properly.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
