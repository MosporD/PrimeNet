MO gNBPdcpParamGroup
Parameter ID gNBPdcpReorderingTimer
Parameter Name

gNodeB PDCP Reordering Timer
NE

BTS3900, BTS3900 5G, BTS5900, BTS5900 5G
MML Command

ADD GNBPDCPPARAMGROUP

MOD GNBPDCPPARAMGROUP

LST GNBPDCPPARAMGROUP
Meaning

Indicates the length of the gNodeB-specific timer for PDCP packet reordering. When this timer expires, the PDCP packets are reordered by PDCP sequence number and then transmitted to the upper layer. For details, see 3GPP TS 38.323.

Impact on Radio Network Performance

A smaller value of this parameter results in frequent TCP retransmissions, thereby wasting resources. A larger value of this parameter results in a longer delay for the receiver to determine an out-of-order packet transmission failure. This leads to a longer delay for triggering TCP retransmissions, thereby increasing the service delay and reducing the traffic volume.
