Meaning

Indicates the networking mode of an NR DU cell. The value NORMAL_CELL indicates that the cell is a common cell, the value HYPER_CELL indicates that the cell is a hyper cell, and the value HYPER_CELL_COMBINE_MODE indicates that the cell is a combined cell. This parameter applies only to low-frequency TDD cells.

Parameter Relationship

-Configuration constraints:

  • If NrDuCellNetworkingMode in an NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, DuplexMode in the NRDUCell MO must be set to CELL_TDD.
  • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, NrDuCellNetworkingMode must be set to NORMAL_CELL.

Caution

Changing the value of this parameter will cause the cell to reset.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

If this parameter is set to NORMAL_CELL, a standard cell handover procedure is used when a UE moves between cells. If this parameter is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, the number of handovers is reduced when a UE moves between TRPs.
