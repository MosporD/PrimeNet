Meaning

Indicates reserved 32-bit switch parameter 0 that is reserved for commissioning on the live network.

Note on parameter replacement: Reserved parameters are temporarily used and will be replaced with new parameters (for example, of which the IDs can signify the parameter functions) in later versions. Therefore, avoid using this parameter over the configuration interface.
