Duplex Mode

MO NRDUCell
Parameter ID DuplexMode
Parameter Name

Duplex Mode
NE

BTS3900, BTS3900 5G, BTS5900, BTS5900 5G
MML Command

ADD NRDUCELL

MOD NRDUCELL

LST NRDUCELL
Meaning

Indicates the duplex mode of an NR DU cell. The value CELL_FDD indicates the FDD mode, the value CELL_TDD indicates the TDD mode, and the value CELL_SUL indicates the SUL mode.

Parameter Relationship

-Configuration constraints:

  • In the NRDUCell MO, if DuplexMode is set to CELL_FDD or CELL_SUL, and SubcarrierSpacing is set to 15KHZ, the value range of CellRadius is 1 to 14500. In the NRDUCell MO, if DuplexMode is set to CELL_TDD, SlotAssignment is set to 4_1_DDDSU, and SubcarrierSpacing is set to 120KHZ, the value range of CellRadius is 1 to 2410.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_10M, PrachFreqStartPosition can be set to a value within the range from 2 to 44, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_20M, PrachFreqStartPosition can be set to a value within the range from 2 to 98, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to 5 MHz, PrachFreqStartPosition can be set to a value within the range from 2 to 17, or to 65535.
  • In an NRDUCell MO, when DuplexMode is set to CELL_FDD, SubcarrierSpacing is set to 15KHZ, and UlBandwidth is set to CELL_BW_15M, PrachFreqStartPosition can be set to a value within the range from 2 to 71, or to 65535.
  • When FrequencyBand in an NRDUCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, DuplexMode must be set to CELL_FDD.
  • When FrequencyBand in an NRDUCell MO is set to N80, N82, N83 or N84 or N86, DuplexMode must be set to CELL_SUL.
  • When FrequencyBand in an NRDUCell MO is set to N77, N78, N79, N38, N40, N41, N257, N258, N260, or N261, DuplexMode must be set to CELL_TDD.
  • The value of CellId in each NRDUCell MO in which DuplexMode is not set to CELL_SUL must be unique within a gNodeB, except that it is set to 65535.
  • When SubcarrierSpacing in an NRDUCell MO is set to 15KHZ and DuplexMode in the same NRDUCell MO is set to CELL_FDD, DlBandwidth must be set to CELL_BW_5M, CELL_BW_10M, CELL_BW_15M, or CELL_BW_20M.
  • When DuplexMode in an NRDUCell MO is not set to CELL_SUL, CellId must not be set to 65535.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than or equal to 2016667 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_100M or CELL_BW_200M.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than 537999 and less than or equal to 680000 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, CELL_BW_100M, CELL_BW_20M, CELL_BW_30M, CELL_BW_50M, CELL_BW_70M, or CELL_BW_90M.
  • In an NRDUCell MO, if DlNarfcn is set to a value greater than or equal to 693333, and less than or equal to 733333 and DuplexMode is set to CELL_TDD, DlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, or CELL_BW_100M.
  • In an NRDUCell MO, if DlNarfcn is set to a value smaller than 2016667 and DuplexMode is set to CELL_FDD, DlBandwidth must be set to CELL_BW_5M, CELL_BW_10M, CELL_BW_15M, or CELL_BW_20M.
  • When UlNarfcn in an NRDUCell MO is not set to 0 and DuplexMode in the same MO is set to CELL_TDD, DlNarfcn and UlNarfcn must be set to the same value.
  • When UlNarfcn in an NRDUCell MO is not set to 0: If the value of UlNarfcn in the NRDUCell MO is greater than 2016667 and DuplexMode in the NRDUCell MO is set to CELL_TDD, UlBandwidth must be set to CELL_BW_100M or CELL_BW_200M.
  • When UlNarfcn in an NRDUCell MO is set to a value greater than 537999, and less than or equal to 680000 and DuplexMode in the same MO is set to CELL_TDD, UlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, CELL_BW_100M, CELL_BW_20M, CELL_BW_30M, CELL_BW_50M, CELL_BW_70M, or CELL_BW_90M.
  • When UlNarfcn in an NRDUCell MO is set to a value greater than or equal to 693333, and less than or equal to 733333 and DuplexMode in the same MO is set to CELL_TDD, UlBandwidth must be set to CELL_BW_40M, CELL_BW_60M, CELL_BW_80M, or CELL_BW_100M.
  • When UlNarfcn in an NRDUCell MO is set to a value smaller than 2016667 and DuplexMode in the same MO is set to CELL_FDD, UlBandwidth must be set to CELL_BW_5M, CELL_BW_10M, CELL_BW_15M, or CELL_BW_20M.
  • If DuplexMode in the NRDUCell MO is set to CELL_FDD, the values of UlNarfcn and DlNarfcn in the NRDUCell MO must be integer multiples of 20.
  • When DuplexMode in an NRDUCell MO is set to CELL_SUL, RanNotificationAreaId must be set to 65535.
  • When DuplexMode in an NRDUCell MO is set to CELL_FDD or CELL_SUL, SubcarrierSpacing must be set to 15KHZ.
  • When DuplexMode in an NRDUCell MO is set to CELL_TDD, SubcarrierSpacing cannot be set to 15KHZ.
  • If NrDuCellNetworkingMode in an NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, DuplexMode in the NRDUCell MO must be set to CELL_TDD.
  • When HighSpeedFlag in the NRDUCell MO is set to HIGH_SPEED, DuplexMode in the NRDUCell MO must be set to CELL_TDD. In addition, FrequencyBand in the NRDUCell MO cannot be set to N257, N258, N260, or N261.
  • If DuplexMode in an NRDUCell MO is not set to CELL_SUL, the value of SmtcPeriod in the NRDUCell MO must be greater than or equal to the value of SsbPeriod.
  • When DuplexMode in an NRDUCell MO is set to CELL_TDD or CELL_FDD, and FrequencyBand in an NRDUCell MO is not set to N66, DlBandwidth and UlBandwidth must be set to the same value.
  • When DuplexMode in an NRDUCell MO is set to CELL_FDD, and FrequencyBand in an NRDUCell MO is set to N66, and UlBandwidth in an NRDUCell MO is set to CELL_BW_10M, and DlBandwidth in an NRDUCell MO is set to CELL_BW_20M, and UlNarfcn in an NRDUCell MO is not set to 0, the difference between DlNarfcn and UlNarfcn must be greater than or equal to 79000 and less than or equal to 81000.
