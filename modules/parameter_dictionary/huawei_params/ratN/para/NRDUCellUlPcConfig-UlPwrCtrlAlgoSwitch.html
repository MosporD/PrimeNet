Meaning

Indicates the uplink power control algorithm switch, which is used to specify the uplink power control policy.

PUSCH_DYN_SCH_CLOSED_LOOP_SW: Indicates whether the gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode. The gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode only if this option is selected.

PUCCH_OUTER_LOOP_SW: Indicates whether the gNodeB adjusts the target SINR for PUCCH power control. The gNodeB adjusts the target SINR for PUCCH power control only if this option is selected.

PUCCH_INNER_LOOP_SW: Indicates whether the gNodeB adjusts the PUCCH transmit power of the UE. The gNodeB adjusts the PUCCH transmit power of the UE only if this option is selected.

PO_SRS_ADAPT_SW: Indicates whether the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is selected, the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is deselected, the configured PO value of the SRS is used.

Impact on Radio Network Performance

PUSCH_DYN_SCH_CLOSED_LOOP_SW: When this option is selected, the throughput of UEs at the cell center and cell edge increases. When this option is deselected, the throughput of such UEs does not increase.

PUCCH_OUTER_LOOP_SW: When this option is selected and the PUCCH_INNER_LOOP_SW option is selected, the PUCCH transmit power can be increased and the PUCCH false detection rate can be reduced in the event of high PUCCH false detection rate. This helps increase the downlink throughput. The preceding gains cannot be achieved when this option is deselected.

PUCCH_INNER_LOOP_SW: When this option is selected, the PUCCH transmit power can be increased and the PUCCH false detection rate can be reduced if the channel quality of the PUCCH is poor. This helps increase the downlink throughput. The preceding gains cannot be achieved when this option is deselected.

PO_SRS_ADAPT_SW: When this option is selected, the SRS transmit power can be increased and the downlink throughput can be increased if SRS channel quality is poor. When this option is deselected, network performance is not affected.
