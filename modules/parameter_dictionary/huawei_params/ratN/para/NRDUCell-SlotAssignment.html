Meaning

Indicates the slot assignment. This parameter applies only to TDD.

The value 4_1_DDDSU indicates that the ratio of downlink timeslots to uplink timeslots is 4:1.

The value 8_2_DDDDDDDSUU indicates that the ratio of downlink timeslots to uplink timeslots is single-period 8:2.

The value 7_3_DDDSUDDSUU indicates that the ratio of downlink timeslots to uplink timeslots is dual-period 7:3.

The value 8_2_DDDSUUDDDD indicates that the ratio of downlink timeslots to uplink timeslots is dual-period 8:2.

The value 2_3_DSUUU indicates that the ratio of downlink timeslots to uplink timeslots is 2:3.

Parameter Relationship

-Configuration constraints:

  • In the NRDUCell MO, if DuplexMode is set to CELL_FDD or CELL_SUL, and SubcarrierSpacing is set to 15KHZ, the value range of CellRadius is 1 to 14500. In the NRDUCell MO, if DuplexMode is set to CELL_TDD, SlotAssignment is set to 4_1_DDDSU, and SubcarrierSpacing is set to 120KHZ, the value range of CellRadius is 1 to 2410.
  • If SlotAssignment in an NRDUCell MO is set to 8_2_DDDSUUDDDD, SlotStructure in the NRDUCell MO must be set to SS81, SS82, SS83, SS84, SS85, SS86, or SS818. If SlotStructure in an NRDUCell MO is set to SS818, LampSiteCellFlag in the NRDUCell MO must be set to NO.
  • In an NRDUCell MO, if SlotAssignment is set to 8_2_DDDDDDDSUU, SlotStructure must be set to SS51, SS52, SS53, SS54, SS55, SS56, or SS518. In addition, if SlotStructure in the NRDUCell MO is set to SS518, LampSiteCellFlag must be set to NO.
  • In an NRDUCell MO, if SlotAssignment is set to 7_3_DDDSUDDSUU, SlotStructure must be set to SS101, SS102, SS103, SS104, SS105, SS106, or SS1017. In addition, if SlotStructure in the NRDUCell MO is set to SS1017, LampSiteCellFlag must be set to NO.
  • In an NRDUCell MO, if FrequencyBand is set to N38, N40, N41, N77, N78, or N79, and SlotAssignment is set to 4_1_DDDSU, then SlotStructure must be set to SS1, SS2, SS3, SS4, SS5, SS6, or SS18. In addition, if SlotStructure in the NRDUCell MO is set to SS18, LampSiteCellFlag must be set to NO.
  • When FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, and SlotAssignment in this MO is set to 4_1_DDDSU, SlotStructure in the same MO must be set to SS201, SS202, SS203, SS204, SS205, or SS206.
  • In an NRDUCell MO, if SlotAssignment is set to 2_3_DSUUU, FrequencyBand must be set to N79.
  • When FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, SlotAssignment in the NRDUCell MO must be set to 4_1_DDDSU.
  • If SlotAssignment in an NRDUCell MO is set to 2_3_DSUUU, DlBandwidth and UlBandwidth in the NRDUCell MO must be set to CELL_BW_60M, CELL_BW_80M, or CELL_BW_100M.
  • If SlotAssignment in an NRDUCell MO is set to 2_3_DSUUU, SlotStructure in the NRDUCell MO must be set to SS21, SS22, or SS23.

-Parameter relationship with conditions:

  • If FrequencyBand is set to N257, N258, N260, N261, N38, N40, N41, N77, N78, N79, SlotAssignment must be set.

Caution

Changing the value of this parameter will cause the NR DU cell to reset.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

When this parameter is set to 8_2_DDDDDDDSUU or 8_2_DDDSUUDDDD, the HARQ delay of the network increases when compared with that when this parameter is set to 4_1_DDDSU. When this parameter is set to 7_3_DDDSUDDSUU, the uplink coverage and capacity of the network increase but the downlink capacity decreases when compared with that when this parameter is set to 4_1_DDDSU.
