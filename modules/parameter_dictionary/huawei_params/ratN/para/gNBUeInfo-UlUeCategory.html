Parameter Name

ADD GNBUEINFO

Meaning

Indicates the uplink UE categories supported by abnormal UEs, which correspond to the following fields in UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryUL-r12, ue-CategoryUL-v1310, ue-CategoryUL-v1340, ue-CategoryUL-v1350, ue-CategoryUL-v1430, ue-CategoryUL-v1430b, and ue-CategoryUL-v1530.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category defined in 3GPP specifications. Bits 0 to 13 stand for category 0 to category 13, respectively. Bit 14 indicates category_n14, bit 15 indicates category_m1, bit 16 indicates category 15, bit 17 indicates category 1bis, bit 18 indicates category_n16, bit 19 indicates category_n17, bit 20 indicates category_n18, bit 21 indicates category_n19, bit 22 indicates category_n20, bit 23 indicates category_m2, bit 24 indicates category_n21, bit 25 indicates category22, ..., and bit 29 indicates category 26. Other bits are reserved. If a bit value is 1, UEs of the corresponding UE category are defined as abnormal UEs. For example, to define UEs of category_n14 and category 8 as abnormal UEs, set this parameter to 16640, which is the decimal format of the binary number 100000100000000.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.
