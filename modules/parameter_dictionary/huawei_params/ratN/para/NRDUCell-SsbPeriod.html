Caution

Modification of this parameter will cause the cell to automatically restart.

When LTE FDD and NR Flash Dynamic Spectrum Sharing is enabled, this parameter is set to a value less than 20 ms, and the CSI-RS period (specified by CellCsiRsParaCfg.CsiRsPeriod) on the LTE side is set to a value less than 20 ms, the NR cell will be restarted. Therefore, the modification of this parameter must be negotiated with the LTE side.

When NSA Networking based on EPC is enabled, the value of this parameter must be the same as that of NrNFreq.SsbPeriod on the LTE side. Otherwise, the NR cell cannot be added as an SCell.

If this parameter is set to 5 ms, the time-domain positions of the SSB and RMSI may conflict. As a result, RMSI scheduling fails and UEs in some coverage areas of the cell cannot access the network.
Validation of Modification

The parameter modification takes effect after the cell is automatically reset.
Impact on Radio Network Performance

A larger value of this parameter results in higher downlink peak throughput of the cell and longer average duration for the UE to search for SSB. A smaller value of this parameter results in the opposite effects.
