Meaning

Indicates whether to enable the DRX algorithm for an NR DU cell.

BASIC_DRX_SW: Indicates whether to enable DRX for UEs in an NR DU cell.

LNR_DRX_SYNCHRONIZE_SW: Indicates whether to enable DRX synchronization for EN-DC UEs in an NR DU cell. This option takes effect only if the BASIC_DRX_SW option is selected.

Impact on Radio Network Performance

BASIC_DRX_SW: If this option is selected, the power consumption of UEs is further reduced when the UEs are triggered to enter DRX mode. However, the impact on network performance is subject to the DRX parameter configuration. If this option is deselected, network performance is not affected.

LNR_DRX_SYNCHRONIZE_SW: If this option is selected, the DRX sleep time of the LTE network is aligned with that of the NR network, and the power consumption of NSA UEs is further reduced. This option has no impact on network performance.
