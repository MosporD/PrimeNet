Parameter ID LogicalRootSequenceIndex
Parameter Name

MML Command

Meaning

Indicates the index of the start logical root sequence used to generate the cell preamble sequence. Each logical root sequence maps one physical root sequence. For details, see 3GPP TS 38.211.

Recommended Value

The logic root sequence index configured for each cell is planned on the entire network. It is recommended that Huawei root ZC sequence planning tool be used for configuration. In manual configuration, if the time-frequency resources of neighboring cells overlap and the root sequence index configuration ranges are the same, the root sequence indexes configured for neighboring cells must not conflict with each other. In the scenario with configuration constraints described in Parameter Relationship, the configuration range is 0 to 137. In other scenarios, the configuration range is 0 to 837.
