MML Command

MOD GNODEBPARAM

LST GNODEBPARAM
Meaning

Indicates whether to suppress the fault alarms of lower-layer links carrying terrestrial interfaces.

BEARER_OF_X2_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an X2 interface fault and an X2 transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29800 gNodeB X2 Interface Fault is reported when the values of GlobaleNodeBId_MCC-MNC-eNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_XN_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an Xn interface fault and an Xn transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29810 gNodeB Xn Interface Fault is reported when the values of GlobalgNBId_MCC-MNC-gNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_NG_SHIELD_SW: Indicates whether to suppress the transmission link alarm (ALM-25888 SCTP Link Fault). If this option is selected and an NG interface fault and an NG transmission link fault occur at the same time, the transmission link alarm is suppressed and only ALM-29815 gNodeB NG Interface Fault is reported. If this option is deselected, the transmission link alarm is not suppressed.
