SSB Frequency Position

Parameter ID SsbFreqPos
Parameter Name

SSB Frequency Position
NE

BTS3900, BTS3900 5G, BTS5900, BTS5900 5G
MML Command

ADD NRDUCELL

MOD NRDUCELL

LST NRDUCELL
Meaning

Indicates the frequency domain location of the cell SSB. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN(Global Synchronization Channel Number), this parameter indicates the global synchronization channel number corresponding to the cell SSB. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN(Absolute Frequency), this parameter indicates the absolute frequency number corresponding to the cell SSB.

Parameter Relationship

-Configuration constraints:

  • In an NRDUCell MO, if SsbDescMethod is set to SSB_DESC_TYPE_GSCN, and FrequencyBand is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N38, N40, N41, N66, or N71, SsbFreqPos must be set to a value greater than or equal to 2 and less than or equal to 7498.
  • In an NRDUCell MO, if SsbDescMethod is set to SSB_DESC_TYPE_GSCN and FrequencyBand is set to N77, N78, or N79, SsbFreqPos must be set to a value greater than or equal to 7499 and less than or equal to 22255.
  • In an NRDUCell MO, if SsbDescMethod is set to SSB_DESC_TYPE_GSCN and FrequencyBand is set to N257, N258, N260, or N261, SsbFreqPos must be set to a value greater than or equal to 22256 and less than or equal to 26639.
  • In an NRDUCell MO, if FrequencyBand is set to N79 and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be an integral multiple of 16.
  • In an NRDUCell MO, if FrequencyBand is set to N41 and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be an integral multiple of 3.
  • In an NRDUCell MO, if FrequencyBand is set to N40 and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be greater than or equal to 5762 and less than or equal to 5989.
  • In an NRDUCell MO, if FrequencyBand is set to N40 and SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, the value of SsbFreqPos must be greater than or equal to 461050 and less than or equal to 479090.
  • The frequency spacing between SsbFreqPos in the NRDUCell MO and the first RB in the cell must be an integer multiple of SubcarrierSpacing.
  • If FrequencyBand in an NRDUCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, and DlBandwidth is set to CELL_BW_5M, the frequency spacing between the positions specified by SsbFreqPos and DlNarfcn must be less than or equal to the value of SubcarrierSpacing multiplied by 30.
  • When SsbDescMethod in an NRDUCell MO is set to SSB_DESC_TYPE_GSCN:
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N77, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 7711 and less than or equal to 8329.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N78, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 7711 and less than or equal to 8051.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N257, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 22388 and less than or equal to 22558.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N258, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 22257 and less than or equal to 22443.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N261, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 22446 and less than or equal to 22492.
  • When SsbDescMethod in an NRDUCell MO is set to SSB_DESC_TYPE_NARFCN:
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N77, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 620000 and less than or equal to 680000.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N78, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 620000 and less than or equal to 653333.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N257, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 2054167 and less than or equal to 2104165.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N258, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 2016667 and less than or equal to 2070832.
  • If AdditionalFrequencyBand in the NRDUCell MO is set to N261, the value of SsbFreqPos in the NRDUCell MO must be greater than or equal to 2070833 and less than or equal to 2084999.
  • In an NRDUCell MO, if SsbDescMethod is set to SSB_DESC_TYPE_GSCN: When AdditionalFrequencyBand is set to N2, the value of SsbFreqPos must be greater than or equal to 4829 and less than or equal to 4969; when AdditionalFrequencyBand is set to N25, the value of SsbFreqPos must be greater than or equal to 4829 and less than or equal to 4981.
  • In an NRDUCell MO, if SsbDescMethod is set to SSB_DESC_TYPE_NARFCN: When AdditionalFrequencyBand is set to N2, the value of SsbFreqPos must be greater than or equal to 386000 and less than or equal to 398000; when AdditionalFrequencyBand is set to N25, the value of SsbFreqPos must be greater than or equal to 386000 and less than or equal to 399000.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 15KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, SsbFreqPos must be set to 6432, 6443, 6457, 6468, 6479, 6493, 6507, 6518, 6532, or 6543.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 15KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, SsbFreqPos must be set to 514590, 515530, 516530, 517470, 518410, 519410, 520590, 521530, 522530, or 523470.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 30KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos must be greater than or equal to 6437 and less than or equal to 6538.
  • In an NRDUCell MO, if FrequencyBand is set to N38, SsbSubcarrierSpacing is set to 30KHZ, and SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, the value of SsbFreqPos must be greater than or equal to 515050 and less than or equal to 523010.

-Parameter relationship with conditions:

  • If DuplexMode is set to CELL_FDD, CELL_TDD, SsbFreqPos must be set.
