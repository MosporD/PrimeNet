Meaning

Indicates whether to enable functions related to uplink PUSCH scheduling.

UL_PAMC_SWITCH: Indicates whether to enable uplink PAMC.

MSG3_TRANSFORMPRECODE_SWITCH: Indicates whether to configure a single carrier for the first uplink transmission and retransmission, for DCI_0_0 transmission, and when the transformPrecoder IE is not configured in PUSCH-Config. When this option is selected, the single-carrier waveform applies in the uplink for the UE. When this option is deselected, the multi-carrier waveform applies in the uplink for the UE.

Caution

MSG3_TRANSFORMPRECODE_SWITCH: Setting this option triggers resynchronization of online NSA DC UEs. The data rate of NSA DC UEs decreases for a short period of time (less than one second) and UEs at cell edge experience service drops. It is recommended that this option be set when a small number of UEs access the network.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

UL_PAMC_SWITCH: If this option is selected, the uplink user-perceived throughput increases and the uplink IBLER fluctuates. If this option is deselected, network performance is not affected.

MSG3_TRANSFORMPRECODE_SWITCH: If this option is selected, Msg3 can be transmitted at higher power to improve the coverage of Msg3. If this option is deselected, Msg3 is transmitted at normal power.
