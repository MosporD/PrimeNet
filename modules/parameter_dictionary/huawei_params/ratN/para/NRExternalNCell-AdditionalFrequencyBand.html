Parameter ID AdditionalFrequencyBand
Parameter Name

Additional Frequency Band
NE

ADD NREXTERNALNCELL

Meaning

Indicates the additional frequency band of an external cell. If this parameter is set to NULL, the additional frequency band of the external cell is not configured. For details, see 3GPP TS 38.104.

Parameter Relationship

-Configuration constraints:

  • When SsbDescMethod in an NRExternalNCell MO is set to SSB_DESC_TYPE_GSCN: If AdditionalFrequencyBand in the NRExternalNCell MO is set to N77, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 7711 and less than or equal to 8329. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N78, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 7711 and less than or equal to 8051. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N257, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 22388 and less than or equal to 22558. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N258, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 22257 and less than or equal to 22443. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N261, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 22446 and less than or equal to 22492.
  • If SsbDescMethod in an NRExternalNCell MO is set to SSB_DESC_TYPE_GSCN and AdditionalFrequencyBand in the NRExternalNCell MO is set to N2, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 4829 and less than or equal to 4969. If AdditionalFrequencyBand in an NRExternalNCell MO is set to N25, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 4829 and less than or equal to 4981. If SsbDescMethod in an NRExternalNCell MO is set to SSB_DESC_TYPE_NARFCN and AdditionalFrequencyBand in the NRExternalNCell MO is set to N2, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 386000 and less than or equal to 398000. If AdditionalFrequencyBand in an NRExternalNCell MO is set to N25, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 386000 and less than or equal to 399000.
  • When SsbDescMethod in an NRExternalNCell MO is set to SSB_DESC_TYPE_NARFCN: If AdditionalFrequencyBand in the NRExternalNCell MO is set to N77, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 620000 and less than or equal to 680000. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N78, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 620000 and less than or equal to 653333. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N257, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 2054167 and less than or equal to 2104165. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N258, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 2016667 and less than or equal to 2070832. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N261, the value of SsbFreqPos in the NRExternalNCell MO must be greater than or equal to 2070833 and less than or equal to 2084999.
  • If AdditionalFrequencyBand in an NRExternalNCell MO is set to N77, FrequencyBand in the NRExternalNCell MO must be set to N78. If AdditionalFrequencyBand in an NRExternalNCell MO is set to N78, FrequencyBand in the NRExternalNCell MO must be set to N77.
  • If AdditionalFrequencyBand in an NRExternalNCell MO is set to N2, FrequencyBand in the NRExternalNCell MO must be set to N25. If AdditionalFrequencyBand in the NRExternalNCell MO is set to N25, FrequencyBand in the NRExternalNCell MO must be set to N2.
  • In an NRExternalNCell MO, if AdditionalFrequencyBand is set to N257, FrequencyBand must be set to N258 or N261. If AdditionalFrequencyBand in an NRExternalNCell MO is set to N258, FrequencyBand in the NRExternalNCell MO must be set to N257. If AdditionalFrequencyBand in an NRExternalNCell MO is set to N261, FrequencyBand in the NRExternalNCell MO must be set to N257.
