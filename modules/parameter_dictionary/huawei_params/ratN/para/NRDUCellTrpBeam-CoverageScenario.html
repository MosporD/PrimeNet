Meaning

Indicates the coverage scenario of antennas. The system adjusts beam patterns based on the setting of this parameter. You can run the DSP NRDUCELLTRP command to query the coverage scenario supported by different AAU types. This parameter applies only to low-frequency TDD cells.

Caution

If the scenario ID is switched, random access may be re-initiated for NSA UEs and service drops may occur; for SA UEs, the success rate of incoming handovers and resynchronization may decrease. This operation will not cause cell reestablishment but will cause the throughput to decrease for a period of time.

Note the value range of the coverage scenario corresponding to the AAU of the cell. If the value is beyond the value range, the cell is unavailable.

The values EXPAND_SCENARIO_2 to EXPAND_SCENARIO_6 are for commissioning only. Do not use them in commercial scenarios.

Change the value during off-peak hours. The interval between two modifications must be greater than 10 minutes.
Validation of Modification

The parameter modification takes effect immediately.
Impact on Radio Network Performance

If the scenario ID is changed, random access may be re-initiated for NSA UEs and service drops may occur; for SA UEs, the success rate of incoming handovers and resynchronization may decrease. This operation will not cause cell reestablishment but will cause the throughput to decrease for a period of time (about 5 minutes).

Adjusting the beam pattern of an antenna affects the radio coverage range, which results in network KPI changes. It is good practice to set this parameter based on onsite coverage.
