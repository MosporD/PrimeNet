MOD NRDUCELLTRPBEAM

LST NRDUCELLTRPBEAM
Meaning

Indicates the configured horizontal azimuth mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs.

If the CoverageScenario parameter is set to CUSTOMIZED_BEAM_SCENARIO, this parameter must be set to 0, and the azimuth that takes effect is the NRDUCellTrpCustBeam.Azimuth parameter value.
