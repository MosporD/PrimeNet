Meaning

Indicates whether to enable X2 SON functions.

X2SON_SETUP_SWITCH: Indicates whether to enable the LTE-NR X2 self-setup function. The function is enabled only if this option is selected.

X2INIT_FAIL_DEL_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by initial self-setup faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2FAULT_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by link faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2USAGE_SWITCH: Indicates whether to enable the function of X2 self-removal based on X2 usage. The function is enabled only if this option is selected.

Impact on Radio Network Performance

X2INIT_FAIL_DEL_SWITCH: If this option is selected, the gNodeB automatically removes an LTE-NR X2 interface if the X2 interface encounters an initial self-setup fault. This prevents such faulty X2 interfaces from occupying the X2 specifications. Self-setup is disallowed for an automatically removed X2 interface before the corresponding X2 dynamic blacklist becomes invalid. DC is disallowed for a gNodeB and an eNodeB between which the X2 interface has been removed. If this option is deselected, the gNodeB does not automatically remove such faulty LTE-NR X2 interfaces. As a result, new X2 interfaces fail to be configured if the total number of X2 interfaces configured for a gNodeB has reached the maximum limit.

X2SON_DEL_FOR_X2FAULT_SWITCH: If this option is selected, the gNodeB automatically removes faulty LTE-NR X2 links. This prevents the faulty X2 interfaces from occupying the X2 specifications. The LTE-NR X2 removal based on X2 fault function cannot identify the fault type. If an LTE-NR X2 interface is faulty throughout a certain time, the gNodeB automatically removes the X2 interface. If this option is deselected, the gNodeB does not automatically remove faulty LTE-NR X2 interfaces. As a result, new X2 interfaces fail to be configured if the total number of X2 interfaces configured for a gNodeB has reached the maximum limit.

X2SON_DEL_FOR_X2USAGE_SWITCH: If this option is selected, the gNodeB can automatically remove X2 interfaces that are not used for many times. If this option is deselected, the gNodeB cannot automatically remove X2 interfaces based on X2 usage. As a result, new X2 interfaces cannot be configured if the total number of X2 interfaces configured for a gNodeB has reached its maximum.
