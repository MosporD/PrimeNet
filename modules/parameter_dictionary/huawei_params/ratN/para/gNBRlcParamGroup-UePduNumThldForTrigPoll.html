Meaning

Indicates the UE-specific threshold of the PDU number to trigger polling. When the number of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.

Impact on Radio Network Performance

To prevent the send window size from changing to 0, the transmitter initiates status reporting based on the number of PDUs. A small value (smaller than or equal to PDU16) of this parameter results in a large number of polling PDU transmissions, a short round-trip time for RLC packets, and a high speed of send window movement. If the send window size is not 0, however, a small value does not increase the transmission rate. Instead, it leads to an excessive number of status reports. A large value of this parameter results in a low speed of send window movement.
