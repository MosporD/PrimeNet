Meaning

Indicates the number of candidate frequency-domain resources for global RIM-RS characteristic sequence for remote interference management. This parameter applies only to low-frequency TDD cells.

The value FREQ_NUM_1 indicates that only one candidate frequency-domain resource is available.

The value FREQ_NUM_2 indicates that two candidate frequency-domain resources are available.

The value FREQ_NUM_4 indicates that four candidate frequency-domain resources are available.

The value NULL indicates an invalid value.

Recommended Value

The recommended value differs depending on the bandwidth combinations in a cell group for remote interference detection.

If the downlink bandwidth is 20 MHz or 30 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_1.

If the downlink bandwidth is 40 MHz, 50 MHz, 60 MHz, or 70 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_2.

If the downlink bandwidth is 80 MHz, 90 MHz, or 100 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_4.

In other scenarios, set this parameter based on the minimum bandwidth in the bandwidth combination.

Impact on Radio Network Performance

If this parameter is set to NULL, network performance is not affected. A smaller value of this parameter results in a longer interval at which the characteristic sequence is sent for remote interference management, less downlink capacity loss, and a longer sequence detection period. A larger value of this parameter results in the opposite effects.
