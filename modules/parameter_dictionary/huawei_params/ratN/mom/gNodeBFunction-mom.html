gNodeBFunction MOM Description

This section describes the functions and concepts of the gNodeBFunction. It also provides the classification of the gNodeBFunction.

Functions and Concepts

The gNodeBFunction provides radio access functions for a gNodeB, which involve radio resource management functions such as air interface management, access control, mobility management, and UE resource allocation.

MOM Introduction

The gNodeBFunction MO defines the root node in the gNodeB function domain.

Figure 1 shows the gNodeBFunction MOM.
Figure 1 gNodeBFunction MOM
The related MOs are defined as follows:
  • gNodeBFunction: A gNodeBFunction MO defines the root node in the gNodeB function domain. The gNodeB function provides radio access in the New Radio (NR) system. It mainly performs radio resource management functions such as air interface management, access control, mobility control, and UE resource allocation.
  • The other MOs are defined in the following sections:
    • Cell MOM Description: describes the MOs related to cell management.
    • DU Cell and Channel MOM Description: describes the MOs related to DU cell and channel management.
    • Interface MOM Description: describes the MOs related to interface management.
    • 5G RAN Sharing MOM Description: describes the MOs related to RAN sharing management.
    • Neighboring Cell and Neighbor Relationship MOM Description: describes the MOs related to neighboring cell and neighbor relationship management.
    • QCI MOM Description: describes the MOs related to QCI management.
  • Cell MOM Description

  • Interface MOM Description

  • 5G RAN Sharing MOM Description
    This section describes the concepts of 5G RAN sharing. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to 5G RAN sharing.
  • Neighboring Cell and Neighbor Relationship MOM Description
    This section describes the functions and concepts of neighboring cells and neighbor relationships. It also provides the managed object model (MOM) view and describes the managed objects (MOs).
  • QCI MOM Description
