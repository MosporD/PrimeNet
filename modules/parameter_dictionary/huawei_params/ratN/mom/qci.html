QCI MOM Description

This section describes the functions and concepts of cell-level QCI and gNodeB QCIs. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to cell-level QCIs and gNodeB-level QCIs.

Functions and Concepts

The QoS model in the SA architecture of 5GC is based on QoS flow. The AMF sends the QoS characteristic index (5QI) of each QoS flow to the gNodeB through the NG interface. The gNodeB then converts the 5QI to the QCI. 3GPP specifications define standard QCIs, that is, QCI 1 to QCI 9, QCI 65, QCI 66, QCI 69, QCI 70, QCI 75, and QCI 79. QCIs can be classified into cell-level QCIs, DU cell-level QCIs, and gNodeB-level QCIs.

The QCI MOs related to the CU cell are defined as follows:
  • NRCellQciBearer: An NRCellQciBearer MO defines the bearer parameters of the NR cell. Different parameters can be configured for different QCI bearers. The parameters include PDCP parameter group ID, DRX parameter group ID, flow control parameter group ID, Intra-freq handover measurement group ID, Inter-RAT handover measurement group ID and Inter-RAT handover to E-UTRAN measurement group ID.
  • NRCellInterRHoMeaGrp: An NRCellInterRHoMeaGrp MO consists of parameters related to inter-RAT handover for an NR cell. Different MOs of this class will be associated with serving cells with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 38.331.
  • NRCellHoEutranMeaGrp: An NRCellHoEutranMeaGrp MO consists of parameters related to inter-RAT handover to E-UTRAN. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 38.331.
  • NRCellIntraFHoMeaGrp: An NRCellIntraFHoMeaGrp MO consists of parameters related to intra-RAT intra-frequency handover. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 38.331.
  • NRCellInterFHoMeaGrp: An NRCellInterFHoMeaGrp MO consists of parameters related to measurement of intra-RAT inter-frequency handover.Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell. For details, see 3GPP TS 38.331.
  • NRCellNsaDcConfigGrp: An NRCellNsaDcConfigGrp MO is used to configure the NSA DC configuration parameter group for an NR cell. Different MOs of this class will be associated with different QCIs.
  • gNBPdcpParamGroup: A gNBPdcpParamGroup MO consists of parameters related to Packet Data Convergence Protocol (PDCP) functions. The parameters include the serial number, the discarding timer length, and the reordering timer length.
  • gNBDrxParamGroup: A gNBDrxParamGroup MO is used to configure parameters related to DRX, such as long and short DRX cycles.
  • gNBFlowCtrlParamGrp: A gNBFlowCtrlParamGrp MO defines a gNodeB flow control parameter group.
The QCI MOs related to the DU cell are defined as follows:
  • NRDUCellQciBearer: An NRDUCellQciBearer MO defines the bearer parameters of the NR DU cell. Different parameters can be configured for different QCI bearers. The parameters include RLC parameter group ID, DRX parameter group ID, and MAC parameter group ID.
  • gNBRlcParamGroup: A gNBRlcParamGroup MO defines the configuration of the gNodeB RLC parameter group.
  • gNBDUMacParamGroup: A gNBDUMacParamGroup MO defines the configuration group of the gNodeB DU MAC parameter.
  • gNBDUDrxParamGroup: A gNBDUDrxParamGroup MO defines parameter groups related to cell measurement. Different MOs of this class will be associated with different QCIs to meet various requirements of services for the target cell.
The QCI MOs related to the gNodeB are defined as follows:
  • gNBQciBearer: A gNBQciBearer MO defines bearer parameters at the gNodeB CU level. Different parameters can be configured for bearers with different QCIs.
  • gNB5qiConfig: A gNB5qiConfig MO defines the parameters related to gNodeB 5QI. Users can configure different parameters for QoS flow of different QoS attributes to complete the mapping from 5QI to QCI.
  • gNBMobilityCommParam: A gNBMobilityCommParam MO consists of common mobility parameter configurations of a gNodeB.
