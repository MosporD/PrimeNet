DU Cell and Channel MOM Description

This section describes the functions and concepts of DU cells, sectors, and channels. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to DU cells, sectors, and channels.

Functions and Concepts

DU Cell

A DU cell is the basic unit of an area providing the radio network NR cell service for the gNodeB DU function domain. DU cell attributes include function and algorithm parameters for physical cell identifier (PCI), tracking area code (TAC), the DU cell-level RLC layer, MAC layer, and physical layer.

Sectors

A sector is the smallest radio coverage area. Each sector uses one or more radio carriers to achieve coverage. Each radio carrier works at a frequency. A sector and a carrier together compose a cell that UEs can access. A DU cell references sector and carrier resources and provides services for the cell.

Sectors are classified into omnidirectional sectors and directional sectors. An omnidirectional sector covers a circle area of 360 degrees with an omnidirectional antenna at the center. Omnidirectional sectors are used for low-traffic coverage. Directional sectors are used for high-traffic coverage. Each directional sector uses a directional antenna for coverage. In three-sector scenarios, each directional antenna covers a sector area of 120 degrees. In six-sector scenarios, each directional antenna covers a sector area of 60 degrees. The coverage areas of adjacent sectors overlap each other because the actual azimuth of each sector is slightly larger than 60 or 120 degrees.

The number of cells supported by a base station is calculated as follows: Number of cells supported by a base station = Number of sectors x Number of carriers in each sector. Channels

In the NR system, channels are classified into logical channels, transport channels, and physical channels:
  • Logical channels are defined based on the types of data to be transmitted.
  • Transport channels are defined based on the formats of transmitted data packets.
  • Physical channels are defined based on the purposes of time and frequency resources on the Uu interface.

Sector-related MOs

Sector-related MOs are defined as follows:
  • RRU: An RRU MO defines a remote radio unit. It consists of multiple antenna ports and is connected to one or more antenna devices. The coverage of an RRU depends on the installation position and tilt of the connected antenna.
  • AAS: An AAS MO defines an active antenna system unit and provides the built-in antenna function. It generally supports beamforming, which determines the coverage of the AAS.
  • Sector: A Sector MO defines the smallest radio coverage area in a certain geographical area. It can contain a group of RRU antenna ports or AAS modules in the same coverage area.
  • SectorEqm: A SectorEqm MO defines a group of RRU antenna ports or the beam RF resources of a group of AAS modules that provide services for the same DU cell in a sector. If multiple DU cells share the same RRU antenna ports or AAS beam and associated RF resources, these DU cells can share the same SectorEqm MO.
  • BasebandEqm: A BasebandEqm MO defines a group of baseband resources provided by one or more UBBP boards. The DU cell TX/RX function is automatically deployed on these boards. When the TX/RX functions of multiple DU cells share the same baseband boards, the TX/RX functions of these DU cells can share the same BasebandEqm MO.

DU cell-related MOs

DU cell-related MOs are defined as follows:
  • gNBSibConfig: A gNBSibConfig MO defines the system information type, system information transmission period, and system information transmission mode.
  • gNBFreqBandConfig: A gNBFreqBandConfig MO specifies the gNodeB frequency band configuration. It is used to set the common configurations of the next frequency band configured for the gNodeB. The configurations automatically apply to all cells in this frequency band.
  • NRDUCell: An NRDUCell MO defines basic information of a DU cell, including the uplink bandwidth, downlink bandwidth, TDD uplink-downlink subframe assignment, subcarrier spacing, cyclic prefix length, physical cell identifier (PCI), tracking area code (TAC), and number of symbols in each timeslot. The air interface information of the DU cell must be configured by the network planning personnel based on the actual situation.
  • NRDUCellTrp: An NRDUCellTrp MO defines the basic information about the transmission reception point (TRP) of an NR DU cell, including the baseband and RF equipment information of the cell. The information of the DU cell must be configured by the network planning personnel based on the actual situation.
  • NRDUCellCoverage: An NRDUCellCoverage MO defines the basic information about the coverage area of an NR DU cell, including the RF equipment information of the cell. The information of the DU cell must be configured by the network planning personnel based on the actual situation.
  • NRDUCellTrpBeam: An NRDUCellTrpBeam MO defines parameters related to beam configurations. NEs can be configured with parameters such as the tilt angle and coverage scenario.
  • NRDUCellTrpMmwavBeam: An NRDUCellTrpMmwavBeam MO is used to configure mmWave-beam-related parameters such as tilt angles and coverage scenarios.
  • NRDUCellTrpCustBeam: An NRDUCellTrpCustBeam MO consists of parameters related to customized and scenario-based beam configurations. Users can configure parameters such as the tilt angle, azimuth, and power under the specified TRP ID and beam ID.
  • NRDUCellSul: An NRDUCellSul MO defines the supplementary uplink (SUL) resource configuration for a cell in which the uplink and downlink decoupling feature is enabled. The SUL resource configuration includes another DU cell that provides SUL services for the DU cell. One NRDUCell MO can be configured with only one NRDUCellSul MO. In addition, an NRDUCell MO in SUL duplex mode can provide SUL services for only one NRDUCell MO in TDD duplex mode.
  • NRDUCellAlgoSwitch: An NRDUCellAlgoSwitch MO defines the algorithm switches of a DU cell, including the beam algorithm switch, spectrum cloudification switch, and link adaptation switch.
  • NRDUCellChnPwr: An NRDUCellChnPwr MO defines the channel power configuration of a DU cell, including the physical broadcast channel power and synchronization channel power.
  • NRDUCellUlTaConfig: An NRDUCellUlTaConfig MO defines the uplink time alignment configuration of a DU cell, including the uplink time alignment timer.
  • NRDUCellUeTimerConst: An NRDUCellUeTimerConst MO defines the UE timer constants of an NR DU cell. For details, see 3GPP TS 38.331.
  • NRDUCellPagingConfig: An NRDUCellPagingConfig MO defines paging-related parameters. It is used to configure parameters related to paging cycle, number of paging groups, and paging.
  • NRDUCellSelConfig: An NRDUCellSelConfig MO defines the parameters related to NR DU cell selection.
  • NRDUCellUePwrSaving: An NRDUCellUePwrSaving MO defines the energy conservation parameters of UEs in an NR DU cell, such as the DRX feature.
  • NRDUCellSrsMeas: An NRDUCellSrsMeas MO defines the SRS measurement of an NR DU cell and provides different types of RSRP measurement , SINR hysteresis, and SINR thresholds.
  • NRDUCellUlPcConfig: An NRDUCellSrsMeas MO defines uplink power control parameters for common radio resources in an NR DU cell. For details about uplink power control, see 3GPP TS 38.213.
  • NRDUCellCarrMgmt: An NRDUCellSrsMeas MO defines NR DU cell-level carrier management, which is used to configure the conditions for adding and deleting secondary cells or auxiliary base stations.

Channel-related MOs

Channel-related MOs are defined as follows:
  • NRDUCellPrach: An NRDUCellPrach MO defines the PRACH configuration of a DU cell, including the logical root sequence index. For the random access procedure, see 3GPP TS 38.321.
  • NRDUCellPdcch: An NRDUCellPdcch MO defines the PDCCH configuration of a DU cell, including the number of occupied symbols and resource mapping mode.
  • NRDUCellPdsch: An NRDUCellPdsch MO defines the PDSCH configuration of a DU cell, including the PRB bundling size and the maximum number of MIMO layers.
  • NRDUCellPucch: An NRDUCellPucch MO defines the PUCCH configuration of a DU cell, including the PUCCH structure type.
  • NRDUCellPusch: An NRDUCellPusch MO defines the PUSCH configuration of a DU cell, including the uplink DMRS type.
  • NRDUCellCoreset: An NRDUCellCoreset MO defines the common control-resource set (CORESET) in an NR DU cell.
  • NRDUCellCsirs: An NRDUCellCsirs MO defines the CSI-RS algorithm and protocol parameter configuration, which is used for the CSI measurement configuration algorithm and resource allocation algorithm.
  • NRDUCellUacBar: An NRDUCellUacBar MO defines access control parameters configured for different access categories.
  • NRDUCellIntrfParam: An NRDUCellIntrfParam MO consists of the parameters related to the interference solution of an NR DU cell.
  • NRDUCellNsaDcConfig: An NRDUCellNsaDcConfig MO is used to configure parameters related to the LTE-NR NSA DC feature.
  • NRDUCellPowerSaving: An NRDUCellPowerSaving MO consists of parameters related to NR DU cell power saving.
  • NRDUCellRimConfig: This MO defines NR DU cell remote interference management (RIM) parameter configurations. It is used to configure parameters related to RIM reference signals.
  • NRDUCellUeCoop: An NRDUCellUeCoop MO defines parameters related to UE cooperation in an NR DU cell.
  • NRDUFddCellTrpBeam: An NRDUFddCellTrpBeam MO defines parameters related to FDD beams such as the coverage scenario and maximum power aggregation capability.
  • NRDUCell3DEirpThld: An NRDUCell3DEirpThld MO defines the 3D EIRP threshold configuration of an NR DU cell. Different thresholds are provided for different grids.
  • NRDUCellTrpDynPwrShr: An NRDUCellTrpDynPwrShr MO consists of parameters related to dynamic power sharing for an NR DU cell TRP, including the NR DU cell TRP ID, maximum power sharing rate, and power sharing margin.
