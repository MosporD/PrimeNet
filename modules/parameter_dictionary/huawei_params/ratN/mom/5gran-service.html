5G RAN Sharing MOM Description

This section describes the concepts of 5G RAN sharing. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to 5G RAN sharing.

Functions and Concepts

5G RAN sharing means that multiple operators share a 5G RAN. When any component of an operator is shared by multiple operators, it is termed as network sharing. Network sharing includes multiple sharing modes, such as access network sharing, core network sharing, and transmission sharing. This section focuses on the access network sharing with independent core network.

Sharing Mode

  • RAN sharing with common carrier: One base station has multiple operators, one frequency has multiple cells, and each cell has multiple operators.
  • RAN sharing with dedicated carrier: One base station has multiple operators, one frequency has multiple cells, and one cell has only one operator.
  • Independent operator mode: One base station has only one operator.

Primary/Secondary Operator

Primary/secondary operator: The OperatorType parameter in the gNBOperator MO specifies the primary and secondary types of operators. The PLMN ID of the primary operator is located in the first of the cell broadcast message. According to 3GPP TS 38.331, the PLMN ID at the first in the list in the cell broadcast message is referred to as the primary PLMN. It is the base station ID and the PLMN ID in the cell ID.

Tracking Area

The tracking area is used by the core network to determine the scope of paging messages to be sent. A tracking area may contain one or more cells. When a gNodeB is shared by multiple operators, the cells of the gNodeB may also be shared by multiple operators. During configuration, the mapping between the cell and the tracking area of the operator needs to be established.

MOM Introduction

Figure 1 5G RAN sharing MOM
The MOs related to 5G RAN SHARING are described as follows:
  • gNBOperator: A gNBOperator MO defines the operator information, including the operator name, mobile country code (MCC), and mobile network code (MNC). In the current version, each gNodeB supports only one operator.
  • gNBTrackingArea: A gNBTrackingArea MO defines a tracking area, which is identified by a tracking area code (TAC). The home gNBTrackingArea MO of an NRCell MO must be specified. One tracking area may contain one or more NR cells.
  • NRDUCellOp: An NRDUCellOp MO is used to identify the secondary operator of an NR DU cell. In different operator modes, the number of NRDUCellOp MO instances that can be configured for each NR DU cell is different. In non-shared mode, a cell has no NRDUCellOp MO instance. In RAN sharing with dedicated carrier, only one NRDUCellOp MO instance can be configured for a secondary operator cell. In RAN sharing with common carrier, a maximum of five NRDUCellOp MO instances can be configured for each cell.
  • gNBSharingMode: A gNBSharingMode MO consists of the parameter that indicates the sharing mode of the gNodeB. The gNodeB supports the following modes: independent operator, RAN sharing with common carrier, and RAN sharing with dedicated carrier.
  • NRCellOpPolicy: An NRCellOpPolicy MO defines parameters related to the operator-specific policies of an NR cell.
  • gNBFreqPriorityGroup: A gNBFreqPriorityGroup MO defines a gNodeB frequency priority group, which is used to configure the cell reselection priority.
  • gNBRfspConfig: A gNBRfspConfig MO consists of parameters related to the RAT/Frequency Selection Priority (RFSP). It is used to configure RFSP-based inter-frequency load balancing switch.
