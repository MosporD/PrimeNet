Cell MOM Description

This section describes the functions and concepts of cells. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to cells.

Functions and Concepts

Cell

A cell is an area that provides wireless communication services for users. All the cells jointly provide coverage for the entire radio network. A cell is not equivalent to a coverage area. Figure 1 shows the mapping between cells and coverage areas.

Figure 1 Mapping between cells and coverage areas

Cell attributes include the function and algorithm parameters related to cell radio services and RRC/PDCP layers. Cells can be classified into common cells, UL/DL decoupling cells, and HyperCell cells.

  • Common cell

    A common cell has one downlink frequency and one uplink frequency, and the duplex mode is FDD or TDD.

  • UL/DL decoupling cells

    A UL/DL decoupling cell has one downlink frequency and two uplink frequencies. One group of downlink and uplink frequencies works in TDD duplex mode, and the other uplink frequency works in supplementary uplink (SUL) mode.

  • HyperCell cell

    A HyperCell cell corresponds to multiple coverage areas. Each coverage area has one downlink frequency and one uplink frequency, and the duplex mode is FDD or TDD.

  • LampSite cell

    A LampSite cell is used for indoor digital coverage. pRRUs and RHUBs must be used as RF devices. A LampSite cell supports RF combination. When an RF combination cell is configured, one TRP corresponds to multiple coverage areas.

Cell-related MOs

Cell-related MOs are defined as follows:
  • NRCell: An NRCell MO defines basic information of a cell, including the NR cell global identifier (CGI), TDD/FDD duplex frequencies, and DU cell that provides services for the cell.
  • NRCellAlgoSwitch: An NRCellAlgoSwitch MO defines the parameters related to barring of access classes. These parameters are set by operators and broadcast through system information.
  • NRCellMobilityConfig: An NRCellMobilityConfig MO defines the cell-level common configurations of mobility management.
  • NRCellNsaDcConfig: An NRCellNsaDcConfig MO defines the parameters related to cell-level LTE-NR NSA DC, including the SCG split bearer mode of downlink data.
  • NRCellCaMgmtConfig: An NRCellCaMgmtConfig MO defines the configuration of CA/DC carrier management parameters for an NR cell. It is used to detect the channel quality of the secondary cell. If the measured value meets the threshold requirement, the UE reports the measurement report.
  • NRCellReselConfig: An NRCellReselConfig MO defines the parameters related to NR cell selection.
  • NRCellAnr: An NRCellAnr MO defines the parameters related to the Automatic Neighbor Relation (ANR) algorithm. It is used to specify the mode switch and over-distant coverage detection threshold in ANR.
  • NRCellComp: An NRCellComp MO defines the parameters related to the CoMP feature.
  • NRCellMlb: An NRCellMlb MO consists of the parameters for load balancing between NR cells.
  • gNBDedNsaDcBandComb: A gNBDedNsaDcBandComb MO is used to indicate a dedicated NSA DC band combination for a base station.
  • gNBUacParamGroup: A gNBUacParamGroup MO defines parameters related to access control.
