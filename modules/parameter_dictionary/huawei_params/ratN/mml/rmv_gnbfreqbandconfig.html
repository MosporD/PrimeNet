Remove gNodeB Frequency Band Configuration (RMV GNBFREQBANDCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove frequency-band-level configurations from the gNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the value of FrameOffset is not 4294967295, running this command will reset all cells running in the frequency band.

Parameters

ID Name Description
FrequencyBand Frequency Band

Meaning: Indicates a frequency band. For details about this parameter, see 3GPP TS 38.104.

If the value of the NrDuCell.FrequencyBand parameter is equal to the value of this parameter, the configuration in this MO is applied.

GUI Value Range: N1(n1), N2(n2), N3(n3), N5(n5), N7(n7), N8(n8), N20(n20), N25(n25), N28(n28), N38(n38), N40(n40), N41(n41), N66(n66), N71(n71), N77(n77), N78(n78), N79(n79), N257(n257), N258(n258), N260(n260), N261(n261)

Unit: None

Actual Value Range: N1, N2, N3, N5, N7, N8, N20, N25, N28, N38, N40, N41, N66, N71, N77, N78, N79, N257, N258, N260, N261

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N

Example

To remove a gNodeB Frequency Band Configuration with Frequency Band set to N3, run the following command:
RMV GNBFREQBANDCONFIG: FrequencyBand=N3;
