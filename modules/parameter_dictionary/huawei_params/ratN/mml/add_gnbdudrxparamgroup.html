Add gNodeB DU DRX Parameter Group (ADD GNBDUDRXPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB DU DRX parameter group.

Note

None.

Parameters

ID Name Description
DuDrxParamGroupId DU DRX Parameter Group ID

Meaning: Indicates the ID of a DRX parameter group of the DU.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
OnDurationTimer On Duration Timer

Meaning: Indicates the length of the DRX On Duration timer. Because of the impact of CSI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. Because of the impact of LongCycle or ShortCycle, the actual value of this parameter assigned to a UE may be smaller than the configured value.

GUI Value Range: MS1(1), MS2(2), MS3(3), MS4(4), MS5(5), MS6(6), MS8(8), MS10(10), MS20(20), MS30(30), MS40(40), MS50(50), MS60(60), MS80(80), MS100(100), MS200(200), MS300(300), MS400(400), MS500(500), MS600(600), MS800(800), MS1000(1000), MS1200(1200), MS1600(1600)

Unit: ms

Actual Value Range: MS1, MS2, MS3, MS4, MS5, MS6, MS8, MS10, MS20, MS30, MS40, MS50, MS60, MS80, MS100, MS200, MS300, MS400, MS500, MS600, MS800, MS1000, MS1200, MS1600

MML Default Value: MS10(10)

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

QCI 1, QCI 5, QCI 65, QCI 66, and QCI 69: DRX parameter not configured

QCI 2, QCI 3, QCI 7, QCI 75, and QCI 79: MS10(10)

QCI 4, QCI 6, QCI 8, QCI 9, and QCI 70: MS10(10)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongCycle, DrxInactivityTimer, ShortCycle, ShortCycleTimer, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: N
DrxInactivityTimer DRX Inactivity Timer

Meaning: Indicates the length of the DRX inactivity timer.

GUI Value Range: MS0(0), MS1(1), MS2(2), MS3(3), MS4(4), MS5(5), MS6(6), MS8(8), MS10(10), MS20(20), MS30(30), MS40(40), MS50(50), MS60(60), MS80(80), MS100(100), MS200(200), MS300(300), MS500(500), MS750(750), MS1280(1280), MS1920(1920), MS2560(2560)

Unit: ms

Actual Value Range: MS0, MS1, MS2, MS3, MS4, MS5, MS6, MS8, MS10, MS20, MS30, MS40, MS50, MS60, MS80, MS100, MS200, MS300, MS500, MS750, MS1280, MS1920, MS2560

MML Default Value: MS100(100)

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

QCI 1, QCI 5, QCI 65, QCI 66, and QCI 69: DRX parameter not configured

QCI 2, QCI 3, QCI 7, QCI 75, and QCI 79: MS20(20)

QCI 4, QCI 6, QCI 8, QCI 9, and QCI 70: MS100(100)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongCycle, OnDurationTimer, ShortCycle, ShortCycleTimer, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: N
DrxRetransTimer DRX Retransmission Timer

Meaning: Indicates the length of the DRX downlink and uplink retransmission timers.

GUI Value Range: SL8(8), SL16(16), SL24(24), SL33(33), SL40(40), SL64(64), SL80(80), SL96(96), SL112(112), SL128(128), SL160(160), SL320(320)

Unit: timeslot

Actual Value Range: SL8, SL16, SL24, SL33, SL40, SL64, SL80, SL96, SL112, SL128, SL160, SL320

MML Default Value: SL16(16)

Recommended Value: SL16(16)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongCycle, OnDurationTimer, DrxInactivityTimer, ShortCycle, and ShortCycleTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged and this parameter is set to a small value, the UE may enter sleep time before receiving the retransmitted data. In this case, the retransmitted data may not be correctly received. If this parameter is set to a large value and the settings of other DRX parameters remain unchanged, the UE may keep waiting for the retransmitted data even when the data is lost. In this case, the UE stays in active time and the power consumption is large.

Applicable Mode: N

Example

To add a gNodeB DU DRX parameter group with DuDrxParamGroupId being 2, run the following command:
ADD GNBDUDRXPARAMGROUP: DuDrxParamGroupId=2;
