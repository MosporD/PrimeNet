List NR External Neighboring Cell PLMN List (LST NREXTERNALNCELLPLMN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list NR external-cell PLMN list configurations.

Note

None.

Output Description

Field Description

Cell ID

Indicates the unique primary-operator cell ID of an external NR cell within a base station. An NR Cell Identity (NCI), which is 36 bits long, consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.

gNodeB ID

Indicates the unique primary-operator gNodeB ID of an external NR cell. An NR Cell Identity (NCI) consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.

Mobile Country Code

Indicates the primary-operator MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Mobile Network Code

Indicates the primary-operator MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Shared Mobile Country Code

Indicates the secondary-operator MCC of an external NR cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Shared Mobile Network Code

Indicates the secondary-operator MNC of an external NR cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Tracking Area Code

Indicates the secondary-operator TAC of an external NR cell. The TAC is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. TAC planning is not required when NrNetworkingOption is set to NSA for a secondary operator to which an external NR cell belongs and it is recommended that this parameter be set to the invalid value (4294967295). TAC planning is mandatory when NrNetworkingOption is set to SA or SA_NSA for a secondary operator to which an external NR cell belongs and this parameter must not be set to the invalid value.

NR Networking Option

Indicates the secondary-operator networking option of an external NR cell. The value UNLIMITED indicates the initial state of the secondary operator to which an external cell belongs. That is, a secondary operator to which an external cell belongs works in unknown networking mode, and the cell can serve as a target cell for handovers. The value SA indicates that a secondary operator to which an external cell belongs works in SA networking mode. The value NSA indicates that a secondary operator to which an external cell belongs works in NSA networking mode. The value SA_NSA indicates that a secondary operator to which an external cell belongs works in SA and NSA hybrid networking mode.

Shared PLMN Cell ID

Indicates the unique secondary-operator cell ID of an external NR cell within a base station. If this parameter is set to 65535, no exclusive cell ID is available for the operator, and the value of the NRExternalNCell.CellId parameter is used as the cell ID of the operator.

Shared PLMN gNodeB ID

Indicates the unique secondary-operator gNodeB ID of an external NR cell. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to 65535, this parameter is invalid. In this case, no exclusive gNodeB ID is available for the operator, and the value of the NRExternalNCell.gNBId parameter is used as the gNodeB ID of the operator. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to a value other than 65535, this parameter needs to be set to the operator's gNodeB ID configured on the corresponding neighboring base station.
