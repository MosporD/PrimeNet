List gNodeB DU DRX Parameter Group (LST GNBDUDRXPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list a gNodeB DU DRX parameter group.

Note

None.

Parameters

ID Name Description
DuDrxParamGroupId DU DRX Parameter Group ID

Meaning: Indicates the ID of a DRX parameter group of the DU.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of a gNodeB DU DRX parameter group, run the following command:
LST GNBDUDRXPARAMGROUP:;
The result is shown as follows:
+++    0        2018-08-21 21:17:42
O&M    #2685403175
%%LST GNBDUDRXPARAMGROUP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

DU DRX Parameter Group ID

Indicates the ID of a DRX parameter group of the DU.

On Duration Timer(ms)

Indicates the length of the DRX On Duration timer. Because of the impact of CSI reporting intervals and SRS transmission intervals, the actual value of this parameter assigned to a UE may be greater than the configured value. Because of the impact of LongCycle or ShortCycle, the actual value of this parameter assigned to a UE may be smaller than the configured value.

DRX Inactivity Timer(ms)

Indicates the length of the DRX inactivity timer.

DRX Retransmission Timer(timeslot)

Indicates the length of the DRX downlink and uplink retransmission timers.
