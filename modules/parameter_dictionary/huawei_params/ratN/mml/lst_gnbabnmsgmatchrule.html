List gNodeB Debugging Message Matching Rule (LST GNBABNMSGMATCHRULE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query gNodeB debugging message matching rule configurations.

Note

None.

Parameters

ID Name Description
MatchRuleIndex Match Rule Index

Meaning: Indicates the index of a debugging message matching rule.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list gNodeB debugging message matching rule, run the following command:
LST GNBABNMSGMATCHRULE:;
The result is shown as follows:
+++    0        2018-06-04 17:57:48
O&M    #2685403169
%%LST GNBABNMSGMATCHRULE:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Debugging Message Matching Rule
-------------------------------------------
  Match Rule Index  =  1
Match Field Offset  =  24
      Match Length  =  2
     Match Content  =  00
(Number of results = 1)


---    END

Output Description

Field Description

Match Rule Index

Indicates the index of a debugging message matching rule.

Match Field Offset

Indicates the matching field offset of the message received or sent by the gNodeB to be matched with a debugging message. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

Match Length

Indicates the matching length of the message received or sent by the gNodeB to be matched with a debugging message. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

Match Content

Indicates the matching content of the message received or sent by the gNodeB to be matched with a debugging message. The matching content is a hexadecimal number that consists of 1 to 100 characters. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
