List gNodeB X2 SON Configuration (LST GNBX2SONCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of gNodeB X2 SON functions.

Note

None.

Parameters

None.

Example

To list the configuration of gNodeB X2 SON functions, run the following command:
LST GNBX2SONCONFIG:;
The result is shown as follows:

Output Description

Field Description

X2 SON Configuration Switch

Indicates whether to enable X2 SON functions.

X2SON_SETUP_SWITCH: Indicates whether to enable the LTE-NR X2 self-setup function. The function is enabled only if this option is selected.

X2INIT_FAIL_DEL_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by initial self-setup faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2FAULT_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by link faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2USAGE_SWITCH: Indicates whether to enable the function of X2 self-removal based on X2 usage. The function is enabled only if this option is selected.

X2 SON Delete Timer for X2 Fault(min)

Indicates the length of the timer for X2 self-removal triggered by X2 faults. If an X2 link is faulty throughout the period specified by this timer, the gNodeB automatically removes the X2 link.

X2 SON Security Mode

Indicates the security mode for X2 self-setup when the local gNodeB receives the control-plane SCTP IP address, security tunnel IP address, and GTP-U IP address of the peer eNodeB at the same time during an X2 self-setup. If this parameter is set to CP_UP, security tunnels will be automatically set up for both the user plane and control plane. If this parameter is set to UP, a security tunnel will be automatically set up only for the user plane. This parameter takes effect only when an IPv4 security tunnel address is received but no IPv6 security tunnel address is received. In other scenarios, for example, only an IPv6 security tunnel address is received or both IPv4 and IPv6 security tunnel addresses are received, this parameter does not take effect.

X2 SON Delete gNodeB Addition Count Threshold

Indicates the threshold of the number of secondary gNodeB additions for automatically removing an X2 interface based on X2 usage. If the measured number of successful secondary en-gNodeB additions corresponding to an X2 interface within a timer length is less than or equal to this threshold, automatic removal of this X2 interface is triggered.
