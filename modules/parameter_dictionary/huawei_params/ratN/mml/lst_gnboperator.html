List gNodeB Operator (LST GNBOPERATOR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of operators.

Note

None.

Parameters

ID Name Description
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of operators, run the following command:
LST GNBOPERATOR:;
The result is shown as follows:

Output Description

Field Description

Operator ID

Indicates the ID of an operator.

Operator Name

Indicates the name of an operator.

Mobile Country Code

Indicates the MCC of an operator. The value of this parameter is a string of three decimal digits.

Mobile Network Code

Indicates the MNC of an operator. The value of this parameter is a string of two or three decimal digits.

Operator Type

Indicates the type of an operator. An operator can be the primary operator or a secondary operator. One gNodeB can be configured with only one primary operator and multiple secondary operators.

NR Networking Option

Indicates the architecture option of an operator. The value SA indicates that the operator supports standalone networking. The value NSA indicates that the operator supports non-standalone networking. The value SA_NSA indicates that the operator supports standalone and non-standalone networking.

RE License Percentage(%)

Indicates the proportion of the licensed number of REs for each operator when the gNodeB is shared among operators. This parameter must be set based on the contract signed among operators. Operator-based license control is applied only when this parameter is set to a valid value for all operators sharing the gNodeB. If this parameter is set to 255 for an operator sharing the gNodeB, operator-based license control is not applied.

RRC Connected User License Percentage(%)

Indicates the proportion of the licensed number of RRC_CONNECTED UEs for each operator when the gNodeB is shared among operators. This parameter must be set based on the contract signed among operators. Operator-based license control is applied only when this parameter is set to a valid value for all operators sharing the gNodeB. If this parameter is set to 255 for an operator sharing the gNodeB, operator-based license control is not applied.

gNodeB ID Length

Indicates the length of the gNodeB ID for an operator. This parameter specifies the number of bits for the gNodeB ID in an NCI and uniquely identifies the NCI. For details, see 3GPP TS 38.423. The parameter value needs to be planned, and the same parameter value must be planned for all gNodeBs in the same PLMN. If this parameter is set to 255 or the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the gNBIdLength parameter in the gNodeBFunction MO is used as the gNodeB ID length for this operator. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the gNodeB ID length for a specific operator depends on the value of this parameter.

gNodeB ID

Indicates the protocol-defined gNodeB ID of an operator. It is unique within a PLMN. If the gNBIdLength parameter in the gNBOperator MO is set to 255 for an operator or the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the parameter setting does not take effect. In this case, the value of the gNBId parameter in the gNodeBFunction MO is used as the gNodeB ID for this operator. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the parameter setting takes effect. In this case, operators use their respective gNodeB IDs over different protocol interfaces.

User Label

Indicates the operator-specific user label of a gNodeB. If the gNBIdLength parameter in the gNBOperator MO is set to 255 for an operator, the parameter setting does not take effect. In this case, the user label of a gNodeB is the same for all operators, namely, the value of the UserLabel parameter in the gNodeBFunction MO is used as the user label for all operators. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the parameter setting takes effect. In this case, operators use their respective user labels.
