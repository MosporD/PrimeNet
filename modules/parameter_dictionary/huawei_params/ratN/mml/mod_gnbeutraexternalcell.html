Modify gNodeB E-UTRAN External Cell (MOD GNBEUTRAEXTERNALCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify an external E-UTRAN cell for the gNodeB.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of the E-UTRAN neighboring cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in a gNBEutraExternalCell MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the mobile network code of a neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in a gNBEutraExternalCell MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
EnodebId eNodeB ID

Meaning: Indicates the eNodeB ID of an inter-RAT neighboring E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. A 28-bit E-UTRAN cell identifier (ECI) is comprised of a cell ID and an eNodeB ID (represented by the most significant 20 bits). An E-UTRAN cell global identifier (ECGI) is comprised of an ECI and a PLMN ID. For details, see 3GPP TS 36.413.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellId Cell ID

Meaning: Indicates the ID of the inter-RAT neighboring E-UTRAN cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
DlEarfcn Downlink EARFCN

Meaning: Indicates the DL EARFCN of the inter-RAT external E-UTRAN cell. For details, see 3GPP TS 36.104.

GUI Value Range: 0~70545,229376~229575

Unit: None

Actual Value Range: 0~70545,229376~229575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
PhysicalCellId Physical Cell ID

Meaning: Indicates the physical cell ID of the external E-UTRAN cell. For details about this parameter, see 3GPP TS 36.331.

GUI Value Range: 0~503

Unit: None

Actual Value Range: 0~503

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
Tac Tracking Area Code

Meaning: Indicates the TAC of the external E-UTRAN cell. According to 3GPP specifications, the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
CellName Cell Name

Meaning: Indicates the name of the neighboring E-UTRAN cell.

GUI Value Range: 0~99 characters

Unit: None

Actual Value Range: 0~99 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AggregationAttribute Aggregation Attribute

Meaning: Indicates the aggregation attributes of an external E-UTRAN cell.

MASTER_PLMN_RESERVED_FLAG: Indicates whether to reserve the primary PLMN ID of an external E-UTRAN cell. If this option is selected, the primary PLMN ID of the external E-UTRAN cell is reserved and the cell cannot be selected as a target cell for handovers of UEs served by the primary PLMN. If this option is deselected, the cell can be selected as a target cell for handovers of UEs served by the primary PLMN.

GUI Value Range: MASTER_PLMN_RESERVED_FLAG(Master PLMN Reserved Flag)

Unit: None

Actual Value Range: MASTER_PLMN_RESERVED_FLAG

MML Default Value: None

Recommended Value: MASTER_PLMN_RESERVED_FLAG:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify an external E-UTRAN cell for gNodeB with the parameters as follows: Mobile Country Code: "302", Mobile Network Code: "220", eNodeB ID: 0, Cell ID: 0, Downlink EARFCN: 2200, Physical Cell ID: 0, Tracking Area Code: 0, Cell Name: "0", run the following command:
MOD GNBEUTRAEXTERNALCELL: Mcc="302", Mnc="220", EnodebId=0, CellId=0, DlEarfcn=2200, PhysicalCellId=0, Tac=0, CellName="0";
