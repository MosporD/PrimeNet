List gNodeB CA Frequency (LST GNBCAFREQUENCY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list CA frequency configurations of a gNodeB.

Note

None.

Parameters

Meaning: Indicates the ID of a CA frequency group, which uniquely identifies the CA frequency group within a gNodeB.

Output Description

Field Description

CA Frequency Group ID

Indicates the ID of a CA frequency group, which uniquely identifies the CA frequency group within a gNodeB.

Downlink NARFCN

Indicates the downlink NR-ARFCN of a CA cell.

CA A2 RSRP Threshold Offset(dB)

Indicates the frequency-specific offset of the RSRP threshold for CA event A2. If the summed value of this parameter and the NRCellCaMgmtConfig.CaA2RsrpThld parameter is greater than -43 dBm, the effective threshold for CA event A2 is -43 dBm. If the summed value is less than -140 dBm, the effective threshold for CA event A2 is -140 dBm.

CA SCC A5 RSRP Threshold 2 Offset(dB)

Indicates the frequency-specific offset of the RSRP threshold 2 for CA event A5. If the summed value of this parameter and the NRCellCaMgmtConfig.CaA5RsrpThld2 parameter is greater than -43 dBm, the effective threshold 2 for CA event A5 is -43 dBm. If the summed value is less than -140 dBm, the effective threshold 2 for CA event A5 is -140 dBm.

SSB Frequency Position

Indicates the frequency-domain position of the SSB corresponding to a CA frequency. The value of this parameter depends on the description method of the SSB frequency-domain position (SsbDescMethod) of neighboring cells.

When SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value range from 2 to 26639 applies. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, other value ranges apply.
