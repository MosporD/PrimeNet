Modify NR DU Cell Uplink TA Configuration (MOD NRDUCELLULTACONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the uplink TA configuration of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
UlTimeAlignmentTimer Uplink Time Alignment Timer

Meaning: Indicates the length of the uplink time alignment timer for UEs in the cell. A UE is considered not time-aligned in the uplink if the timer expires. In uplink and downlink decoupling scenarios, the TA timer of an NUL cell must be the same as that of the SUL cell.

GUI Value Range: 500SF(500 Subframes), 750SF(750 Subframes), 1280SF(1280 Subframes), 1920SF(1920 Subframes), 2560SF(2560 Subframes), 5120SF(5120 Subframes), 10240SF(10240 Subframes), INFINITY(Infinity)

Unit: None

Actual Value Range: 500SF, 750SF, 1280SF, 1920SF, 2560SF, 5120SF, 10240SF, INFINITY

MML Default Value: None

Recommended Value: INFINITY(Infinity) in non-high-speed railway scenarios

1280SF(1280 Subframes) in high-speed railway scenarios

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter leads to less frequent delivery of uplink TA commands, consuming fewer air interface resources. However, the uplink TA deviation is traced and corrected in a less timely manner. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N

Example

To modify the settings of parameters related to the uplink TA algorithm for an NR DU cell with the parameters as follows: NR DU Cell ID: 0, Uplink Time Alignment Timer: 1920SF, run the following command:
MOD NRDUCELLULTACONFIG: NrDuCellId=0, UlTimeAlignmentTimer=1920SF;
