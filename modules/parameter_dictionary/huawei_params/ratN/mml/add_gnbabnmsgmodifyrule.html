Add gNodeB Debugging Message Modifying Rule (ADD GNBABNMSGMODIFYRULE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB debugging message-based modification rule.

Note

  • The parameters in this command must be modified under the guidance of Huawei technical support. This command must be executed under the guidance of Huawei technical support.

  • After the upgrade, if the problem resolved by gNBAbnMsgMatchRule before the upgrade persists, reconfigure the gNBAbnMsgMatchRule MO for the new version.

Parameters

ID Name Description
ModifyRuleIndex Modify Rule Index

Meaning: Indicates the index of a debugging message-based modification rule.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
ModifyFieldOffset Modify Field Offset

Meaning: Indicates the modification field offset of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

GUI Value Range: 0~268435455

Unit: None

Actual Value Range: 0~268435455

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
ModifyLen Modify Length

Meaning: Indicates the modification length of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

GUI Value Range: 0~400

Unit: None

Actual Value Range: 0~400

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
ModifyContent Modify Content

Meaning: Indicates the modification content of the message received or sent by the gNodeB. The modification content is a hexadecimal number that consists of 1 to 100 characters. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

GUI Value Range: 0~100 characters

Unit: None

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a gNodeB debugging message modifying rule with Modify Rule Index set to 1, ModifyFieldOffset set to 24, ModifyLen set to 2, and ModifyContent set to 00, run the following command:
ADD GNBABNMSGMODIFYRULE: ModifyRuleIndex=1, ModifyFieldOffset=24, ModifyLen=2, ModifyContent="00";
