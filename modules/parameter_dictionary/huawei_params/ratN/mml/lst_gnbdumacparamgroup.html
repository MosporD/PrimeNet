List gNodeB MAC Parameter Group (LST GNBDUMACPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query a gNodeB MAC parameter group.

Note

None.

Parameters

ID Name Description
MacParamGroupId MAC Parameter Group ID

Meaning: Indicates the ID of a MAC parameter group.

GUI Value Range: 0~159

Unit: None

Actual Value Range: 0~159

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of a gNodeB DU MAC parameter group, run the following command:
LST GNBDUMACPARAMGROUP:;

Output Description

Field Description

MAC Parameter Group ID

Indicates the ID of a MAC parameter group.

Downlink Guaranteed Rate(kbit/s)

Indicates the downlink guaranteed rate of services on a non-GBR radio bearer.

Uplink Guaranteed Rate(kbit/s)

Indicates the uplink guaranteed rate of services on a non-GBR radio bearer.

Downlink Scheduling Priority Weight Factor

Indicates the weight factor in the formula for calculating the downlink scheduling priority of a non-GBR radio bearer.

Uplink Scheduling Priority Weight Factor

Indicates the weight factor in the formula for calculating the uplink scheduling priority of a non-GBR radio bearer.

Logical Channel Group ID

Indicates the ID of a logical channel group for radio bearers.

Logical Channel Priority

Indicates the logical channel priority of a radio bearer.

Downlink Minimum Acceptable Rate(kbit/s)

Indicates the minimum downlink acceptable rate, which is used to calculate the downlink resource load of a cell. The value 1000001 is used for special applications.

When this parameter is set to 1000001 for a GBR bearer, the gNodeB reads the GBR value carried by the core network as the minimum acceptable rate of the bearer.

When this parameter is set to 1000001 for a non-GBR bearer, the effect of this value is the same as that of 0. Therefore, avoid setting this parameter to 1000001 for non-GBR bearers.

Uplink Minimum Acceptable Rate(kbit/s)

Indicates the minimum uplink acceptable rate, which is used to calculate the uplink resource load of a cell. The value 1000001 is used for special applications.

When this parameter is set to 1000001 for a GBR bearer, the gNodeB reads the GBR value carried by the core network as the minimum acceptable rate of the bearer.

When this parameter is set to 1000001 for a non-GBR bearer, the effect of this value is the same as that of 0. Therefore, avoid setting this parameter to 1000001 for non-GBR bearers.

Scheduling Type

Indicates the scheduling type of a bearer corresponding to each QCI.

The value BASIC_SCH indicates basic scheduling for a bearer. The value VOICE_SCH or IMS_SIGNALING_SCH indicates differentiated scheduling for a bearer.

The value LOW_LATENCY_SCH indicates delay optimization scheduling for a bearer.
