List NR DU Cell Interference Solution Parameter (LST NRDUCELLINTRFPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list interference solution parameters for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list interference solution parameter for an NR DU cell, run the following command:
LST NRDUCELLINTRFPARAM:;
The result is shown as follows:
+++    0        2019-06-22 10:57:19
O&M    #2685403167

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Interference Solution Type

Indicates the interference solution that needs to take effect.

Start RB Index of First Interference

Indicates the start RB index of the first interfered segment in narrowband interference or co-channel LTE interference. The value 273 indicates that the interfered segment does not take effect.

End RB Index of First Interference

Indicates the end RB index of the first interfered segment in narrowband interference or co-channel LTE interference. The value 273 indicates that the interfered segment does not take effect.

Start RB Index of Second Interference

Indicates the start RB index of the second interfered segment in narrowband interference or co-channel LTE interference. The value 273 indicates that the interfered segment does not take effect.

End RB Index of Second Interference

Indicates the end RB index of the second interfered segment in narrowband interference or co-channel LTE interference. The value 273 indicates that the interfered segment does not take effect.
