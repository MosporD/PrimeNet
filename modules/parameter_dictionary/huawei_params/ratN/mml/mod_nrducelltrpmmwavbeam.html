Modify NR DU Cell TRP mmWave Beam Configuration (MOD NRDUCELLTRPMMWAVBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of mmWave beams in an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP in an NR DU cell, which uniquely identifies the TRP within an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CoverageScenario Coverage Scenario

Meaning: Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. The DSP NRDUCELLTRP command can be executed to query the coverage scenarios supported by different types of AAUs. This parameter applies only to high-frequency cells.

GUI Value Range: DEFAULT(Default Scenario), SCENARIO_101(Capacity Scenario), SCENARIO_103(Tunnel Scenario)

Unit: None

Actual Value Range: DEFAULT, SCENARIO_101, SCENARIO_103

MML Default Value: None

Recommended Value: DEFAULT(Default Scenario)

Parameter Relationship:

-Configuration constraints:

  • If CoverageScenario in an NRDUCellTrpMmwavBeam MO is set to DEFAULT, or SCENARIO_101, Azimuth in the NRDUCellTrpMmwavBeam MO must be set to 0.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Adjusting the beam form of an antenna affects the radio coverage range, which results in network KPI changes. Set this parameter based on onsite coverage.

Applicable Mode: N-TDD-FR2
Tilt Tilt

Meaning: Indicates the configured downtilt angle mapping a weight for beamforming. If this parameter is set to 255, the default downtilt angle supported by the hardware is used. The DSP NRDUCELLTRP command can be executed to query the tilt angle adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the tilt angle is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the tilt angle of the cell exceeds the range supported by the AAU, the cell becomes unavailable.

GUI Value Range: -12~6,255

Unit: degree

Actual Value Range: -12~6,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Adjusting the tilt angle affects the radio coverage range, which results in network KPI changes. Set this parameter based on onsite coverage.

Applicable Mode: N-TDD-FR2
MaxSsbPwrOffset Max SSB Power Offset

Meaning: Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to high-frequency cells.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, when the value of MaxSsbPwrOffset decreases, the network searching success rate of UEs at the cell edge decreases.)

Impact on Radio Network Performance: A larger value of this parameter results in higher power used for sending an SSB and larger coverage of the SSB beam. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR2
Azimuth Azimuth

Meaning: Indicates the azimuth mapping a weight for beamforming. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the azimuth is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the azimuth of the cell exceeds the range supported by the AAU, the cell becomes unavailable.

GUI Value Range: -10~10

Unit: degree

Actual Value Range: -10~10

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • If CoverageScenario in an NRDUCellTrpMmwavBeam MO is set to DEFAULT, or SCENARIO_101, Azimuth in the NRDUCellTrpMmwavBeam MO must be set to 0.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Adjusting the azimuth affects the radio coverage range, which results in network KPI changes. Set this parameter based on onsite coverage.

Applicable Mode: N-TDD-FR2

Example

To modify the configuration of mmWave beams in an NR DU cell as follows: NR DU Cell TRP ID: 10, CoverageScenario: SCENARIO_101:
MOD NRDUCELLTRPMMWAVBEAM: NrDuCellTrpId=10, CoverageScenario=SCENARIO_101;
