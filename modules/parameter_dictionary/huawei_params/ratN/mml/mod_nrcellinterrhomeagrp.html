Modify Measurement Parameter Group Related to Inter-RAT Handover (MOD NRCELLINTERRHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a measurement parameter group related to inter-RAT handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterRatHoMeasGroupId Inter-RAT Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-RAT handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA2RsrpThld must be greater than that of CovHoToEutranBlindA2Thld.
  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA1RsrpThld must be greater than that of InterRatHoA2RsrpThld.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterRatHoA1RsrpThld Inter-RAT Handover A1 RSRP Threshold

Meaning: Indicates the RSRP threshold for event A1 related to inter-RAT handover. If the measured RSRP value of the serving cell is greater than the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A1 reports. For details, see 3GPP TS 38.331.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -111

Parameter Relationship:

-Configuration constraints:

  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA1RsrpThld must be greater than that of InterRatHoA2RsrpThld.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering event A1 and stopping inter-RAT measurement. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
InterRatHoA2RsrpThld Inter-RAT Handover A2 RSRP Threshold

Meaning: Indicates the RSRP threshold for event A2 related to inter-RAT handover. If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A2 measurement reports. For details, see 3GPP TS 38.331.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -115

Parameter Relationship:

-Configuration constraints:

  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA2RsrpThld must be greater than that of CovHoToEutranBlindA2Thld.
  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA1RsrpThld must be greater than that of InterRatHoA2RsrpThld.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering event A2 and starting inter-RAT measurement. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
InterRatHoA1A2Hyst Inter-RAT Handover A1A2 Hysteresis

Meaning: Indicates the hysteresis for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of meeting the entering and leaving conditions for event A1/A2 and for event A2 related to blind mobility procedures. A larger value of this parameter results in a lower probability of meeting the entering and leaving conditions for event A1/A2 and for event A2 related to blind mobility procedures.

Applicable Mode: N
InterRatHoA1A2TimeToTrig Inter-RAT Handover A1A2 Time To Trigger

Meaning: Indicates the time-to-trigger for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: None

Recommended Value: 320MS(320)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of meeting the entering and leaving conditions for event A1/A2 and for event A2 related to blind mobility procedures. A larger value of this parameter results in a lower probability of meeting the entering and leaving conditions for event A1/A2 and for event A2 related to blind mobility procedures. In this case, the average number of starting inter-RAT measurements decreases, and service drop risks increase.

Applicable Mode: N
CovHoToEutranBlindA2Thld Cov HO to E-UTRAN Blind A2 RSRP Thld

Meaning: Indicates the RSRP threshold for event A2 related to coverage-based blind handover to E-UTRAN and inter-frequency blind redirection.

If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger for event A1/A2 related to inter-RAT mobility procedures, UEs send event A2 reports related to blind mobility procedures. For details, see 3GPP TS 38.331.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -121

Parameter Relationship:

-Configuration constraints:

  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA2RsrpThld must be greater than that of CovHoToEutranBlindA2Thld.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering event A2 related to blind mobility procedures, thereby delaying inter-frequency or inter-RAT blind redirections. A larger value of this parameter results in a higher probability of triggering event A2 related to blind mobility procedures and a higher probability of starting inter-frequency or inter-RAT blind redirections.

Applicable Mode: N
CovHoToEutranB2RsrpThld1 Cov HO to E-UTRAN B2 RSRP Thld1

Meaning: Indicates the RSRP threshold 1 for event B2 related to coverage-based handover to E-UTRAN. If the measured RSRP value of the serving cell is below the event B2 RSRP threshold 1 throughout the corresponding time-to-trigger for event B1/B2 related to coverage-based handover to E-UTRAN and the RSRP of a neighboring E-UTRAN cell is greater than the RSRP threshold for event B1 related to coverage-based handover to E-UTRAN throughout the same time-to-trigger, UEs send event B2 measurement reports. For details, see 3GPP TS 38.331.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -115

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering event B2, which delays handovers and affects user experience. A larger value results in a higher probability of triggering event B2 and also a higher probability of incorrect decisions and ping-pong handovers.

Applicable Mode: N

Example

To modify a measurement parameter group related to inter-RAT handover for an NR cell with NR Cell ID set to 5, Inter-RAT Handover Measurement Group ID set to 1, Inter-RAT Handover A1 RSRP Threshold set to -112, Inter-RAT Handover A2 RSRP Threshold set to -116, Inter-RAT Handover A1A2 Hysteresis set to 0, Inter-RAT Handover A1A2 Time To Trigger set to 40MS, Cov HO to E-UTRAN Blind A2 RSRP Thld set to -122, and Cov HO to E-UTRAN B2 RSRP Thld1 set to -116, run the following command:
MOD NRCELLINTERRHOMEAGRP: NrCellId=5, InterRatHoMeasGroupId=1, InterRatHoA1RsrpThld=-112, InterRatHoA2RsrpThld=-116, InterRatHoA1A2Hyst=0, InterRatHoA1A2TimeToTrig=40MS, CovHoToEutranBlindA2Thld=-122, CovHoToEutranB2RsrpThld1=-116;
