Remove gNodeB Tracking Area (RMV GNBTRACKINGAREA)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a tracking area supported by the gNodeB.

Note

Before removing a gNBTrackingArea MO referenced by NRCell MOs, remove the NRCell MOs. Otherwise, the command execution fails.

Parameters

ID Name Description
TrackingAreaId Tracking Area ID

Meaning: Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This is different from the TAI configured in the TAL of the core network.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a tracking area with Tracking Area ID set to 0, run the following command:
RMV GNBTRACKINGAREA: TrackingAreaId=0;
