List NR DU Cell 3D EIRP Threshold (LST NRDUCELL3DEIRPTHLD)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list a 3D EIRP threshold for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
GridGroupNo Grid Group No

Meaning: Indicates the ID of a grid group, which uniquely identifies a grid group.

GUI Value Range: 0~27

Unit: None

Actual Value Range: 0~27

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

Query the 3D EIRP threshold in an NR DU cell with NR DU Cell TRP ID set to 99, run the following command:
LST NRDUCELL3DEIRPTHLD: NrDuCellTrpId=99;
The result is shown as follows:

+++    0        2019-12-14 15:54:57

             NR DU Cell TRP ID  =  99
                 Grid Group No  =  0

(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell within a gNodeB.

Grid Group No

Indicates the ID of a grid group, which uniquely identifies a grid group.

Power Control Threshold(0.1dB)

Indicates the power control threshold for the smart power lock feature. The average power within the average period must not exceed the maximum transmit power minus the value of this parameter.
