List NR DU Cell Algorithm Switch (LST NRDUCELLALGOSWITCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the settings of NR DU cell-level algorithm switches.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the settings of NR DU cell-level algorithm switches, run the following command:
LST NRDUCELLALGOSWITCH:;
The result is shown as follows:

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Adaptive Edge Experience Enhance Switch

Indicates whether to enable the functions of the adaptive edge experience improvement feature.

UL_WAVEFORM_ADAPT_SW: Indicates whether to enable the CP-OFDM and DFT-S-OFDM waveform adaption function in the uplink.

UL_IBLER_ADAPT_SW: Indicates whether to enable the uplink IBLER adaption function.

DL_PMI_SRS_ADAPT_SW: Indicates whether to enable SRS- and PMI-based weight adaption. This option applies only to low-frequency 64T/32T/8T/4T TDD cells.

DL_INTRF_RANDOM_SW: Indicates whether to enable the downlink interference randomization function.

MU-MIMO Switch

Indicates whether to enable the functions of the MU-MIMO feature in an NR DU cell.

UL_MU_MIMO_SW: Indicates whether to enable the uplink MU-MIMO function.

PDCCH_MU_SW: Indicates whether to enable the spatial multiplexing function on the PDCCH.

DL_MU_MIMO_SW: Indicates whether to enable the downlink MU-MIMO function.

Spectrum Cloudification Switch

Indicates whether to enable the functions of the spectrum cloudification feature.

LTE_NR_UL_SPECTRUM_SHARING_SW: Indicates whether to enable the LTE FDD and NR uplink spectrum sharing function. This option applies only to NR SUL.

LTE_NR_FDD_SPCT_SHR_SW: Indicates whether to enable the LTE FDD and NR spectrum sharing function. This option applies only to NR FDD cells.

LTE_NR_TDD_SPCT_SHR_SW: Indicates whether to enable the LTE TDD and NR spectrum sharing function. This option applies only to low-frequency TDD cells.

UL and DL Decoupling Switch

Indicates whether to enable the NR uplink and downlink decoupling feature. The NR uplink and downlink decoupling feature is enabled only if this parameter is set to ON.

Uplink Inconsecutive Scheduling Switch

Indicates whether to enable the uplink non-consecutive scheduling algorithm.

UL_NON_CON_SCH_SW: If this option is selected, the uplink non-consecutive scheduling algorithm is enabled. If this option is deselected, the uplink non-consecutive scheduling algorithm is disabled. This parameter applies only to low-frequency TDD cells.

DL Enhanced HARQ Switch

Indicates whether to enable the downlink enhanced HARQ function in an NR DU cell.

DL_EN_HARQ_SW: Indicates whether to enable the downlink enhanced HARQ function.

NSA DC Algorithm Switch

Indicates LTE-NR NSA DC algorithm switches.

CROSS_MDLT_INTRF_AVOID_SW: Indicates whether NR supports cross-modulation interference avoidance. NR supports cross-modulation interference avoidance only if this option is selected. The value of gNodeBParam.NsaDcResCoordScenario determines the cross-modulation interference avoidance bitmap the gNodeB sends to the eNodeB. When gNodeBParam.NsaDcResCoordScenario is set to ASYNC_NSA_DC, the cross-modulation interference avoidance function does not take effect.

HARMONIC_INTRF_AVOID_SW: Indicates whether NR supports harmonic interference avoidance. If this option is selected, NR supports harmonic interference avoidance. If this option is deselected, NR does not support harmonic interference avoidance. The value of gNodeBParam.NsaDcResCoordScenario determines the harmonic interference avoidance bitmap the gNodeB sends to the eNodeB.

SPKT_UL_PATH_BACK_TO_NR_SW: Indicates whether to enable the function of returning to the NR side for uplink small-packet UEs in the NSA DC uplink data transmission path selection feature. If this option is selected, uplink small-packet UEs directly transfer uplink data transmission to the NR side when the NSA DC uplink data transmission path selection feature is enabled. If this option is deselected, this function does not take effect.

Uplink 256QAM Switch

Indicates whether to enable the uplink 256QAM functions.

If the UL_256QAM_OFF option is selected, the uplink 256QAM functions at the cell level are disabled.

If the UL_256QAM_FIXED option is selected, the fixed uplink 256QAM function at the cell level is enabled.

If the UL_256QAM_ADAPT option is selected, the adaptive uplink 256QAM function at the cell level is enabled.

Uplink Interference Random Schedule Switch

Indicates whether to enable the uplink interference randomization for scheduling feature.

UE Feature Based Pairing Enhancement Switch

Indicates whether to enable UE feature-based pairing enhancement.

DL_MOBILE_MU_ENH_SW: Indicates whether to enable downlink mobile MU-MIMO enhancement. This option takes effect only for low frequency bands.

SU-MIMO Multiple Layers Switch

Indicates whether to enable multi-layer transmission for a UE, including downlink multi-layer transmission, uplink multi-layer transmission, and enhanced downlink single-user power control.

DL_SU_MULTI_LAYER_SW: Indicates whether to enable downlink multi-layer transmission for a single user. This option does not take effect for SUL cells.

UL_SU_MULTI_LAYER_SW: Indicates whether to enable uplink multi-layer transmission for a single user. This option does not take effect for SUL cells.

DL_SU_PWR_CTRL_ENH_SW: Indicates whether to enable enhanced downlink single-user power control. If this option is selected, this function is enabled and the base station adaptively selects a power control policy based on the single-user bit rate. If this option is deselected, this function is disabled. This option applies only to TDD.

CA Algorithm Switch

Indicates the CA algorithm switch.

INTRA_BAND_CA_SW: Indicates whether to enable intra-band downlink CA. If this option is selected, the local cell serves as a PCell or an SCell for intra-band downlink CA. If this option is deselected, the local cell cannot serve as a PCell or an SCell for intra-band downlink CA. This option does not take effect for SUL cells.

INTRA_FR_INTER_BAND_CA_SW: Indicates whether to enable intra-FR inter-band downlink CA. If this option is selected, the local cell serves as a PCell or an SCell for intra-FR inter-band downlink CA. If this option is deselected, the local cell cannot serve as a PCell or an SCell for intra-FR inter-band downlink CA. This option applies only in low frequency bands. This option does not take effect for SUL cells.

INTRA_BAND_UL_CA_SW: Indicates whether to enable intra-band uplink CA. If this option is selected, the local cell serves as a PCell or an SCell for intra-band uplink CA. If this option is deselected, the local cell cannot serve as a PCell or an SCell for intra-band uplink CA. This option does not take effect for SUL cells.

INTRA_FR_INTER_BAND_UL_CA_SW: Indicates whether to enable intra-FR inter-band uplink CA. If this option is selected, the local cell serves as a PCell or an SCell for intra-FR inter-band uplink CA. If this option is deselected, the local cell cannot serve as a PCell or an SCell for intra-FR inter-band uplink CA. This option applies only in low frequency bands. This option does not take effect for SUL cells.

Downlink 256QAM Switch

Indicates whether to enable fixed downlink 256QAM. This parameter is used to control whether the high-order modulation function takes effect in a cell.

If this switch is turned off, the downlink 256QAM function at the cell level is disabled.

If this switch is turned on, the downlink 256QAM function at the cell level is enabled.

This parameter applies only to FDD and TDD.

Symbol Shutdown Switch

Indicates the symbol shutdown switch, which is used to enable or disable the cell-level energy-saving feature. This parameter does not take effect when the carriers of the NR mode and other modes share the same RF module.

Full Channel Coverage Enhancement Switch

Indicates whether to enable enhanced full-channel coverage functions.

SSB_PA_SW: Indicates whether to enable SSB power aggregation. When this option is selected and the MaxSsbPwrOffset parameter value is greater than 0, SSB power aggregation is enabled. When this option is deselected, SSB power aggregation is disabled.

Disuse statement: The SSB_PA_SW option no longer controls the SSB power aggregation function, and the MaxSsbPwrOffset parameter takes effect directly. This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

PDSCH_PRECISE_PMI_SW: Indicates whether to enable PDSCH precise PMI weight. PDSCH precise PMI weight is enabled only when this option is selected.

PUSCH_BEAM_DOMAIN_EHN_SW: Indicates whether to enable PUSCH beam-domain enhancement. PUSCH beam-domain enhancement is enabled only when this option is selected. This option takes effect only for low-frequency 64T/32T TDD cells.

PUSCH_TIME_DOMAIN_ENH_SW: Indicates whether to enable PUSCH time-domain enhancement. PUSCH time-domain enhancement is enabled only when this option is selected. This option takes effect only for low-frequency 64T/32T TDD cells.

NARROW_BEAM_PROBE_SW: Indicates whether to enable the narrow beam probe function for access channels. This function is enabled only if this option is selected. This option applies only to high-frequency TDD cells.

ACK_NACK_REPORTING_PUSCH_SW: Indicates whether to report ACK/NACK on the PUSCH. If this option is selected, ACK/NACK of cell edge users can be transmitted together with data on the PUSCH. If this option is deselected, ACK/NACK of cell edge users cannot be transmitted together with data on the PUSCH. This option applies only to high-frequency TDD cells.

CoMP Switch

Indicates the switch that is used to enable and disable the CoMP function.

INTRA_GNB_UL_COMP_SW: Indicates whether to enable intra-gNodeB UL CoMP. Intra-gNodeB UL CoMP is enabled only when this option is selected.

INTRA_GNB_DL_JT_SW: Indicates whether to enable intra-gNodeB DL joint transmission. Intra-gNodeB DL joint transmission is enabled only when this option is selected.

INTRA_GNB_OVERLAPPING_MEAS_SW: Indicates whether to enable intra-gNodeB overlapping area measurement. Intra-gNodeB overlapping area measurement is enabled only when this option is selected.

Power Saving Switch

Indicates the power saving switches.

TIMING_CARRIER_SHUTDOWN_SW: Indicates whether to enable timing carrier shutdown. This function is enabled only when this option is selected. When this function is enabled, carriers are shut down at the preset time.

LNR_SMART_CARRIER_SHUTDOWN_SW: Indicates whether to enable LTE and NR intelligent carrier shutdown. This function is enabled only when this option is selected. When this function is enabled, the carrier is shut down at the preset time based on the load information and cell status of the local cell and neighboring co-coverage LTE cells.

RF_SHUTDOWN_SW: Indicates whether to enable RF channel shutdown. This function is enabled only when this option is selected. When this function is enabled, RF channels are shut down at the preset time under the specified load condition.

POWER_SAVING_SCHEDULE_SW: Indicates whether to enable power saving scheduling. This function is enabled only when this option is selected. This function takes effect at the preset time under the specified load condition.

MULTI_RAT_SYMBOL_SHUTDOWN_SW: Indicates whether to enable multi-RAT symbol power saving in an NR DU cell. This function is enabled only when this option is selected.

DYNAMIC_SSB_SW: Indicates whether to enable functions related to the dynamic SSB. This function is enabled only when this option is selected.

LNR_BUNDLED_SCHEDULING_SW: Indicates whether to enable LTE and NR bundled scheduling for multi-RAT symbol power saving for an NR DU cell. This function is enabled only when this option is selected.

DEEP_SYMBOL_SHUTDOWN_SW: Indicates whether to enable deep symbol power saving. This function is enabled only when this option is selected.

RIM Algorithm Switch

Indicates whether to enable remote interference management (RIM).

RIM_ADAPT_AVOID_SW: Indicates whether to enable adaptive remote interference avoidance. If this option is selected, adaptive avoidance is performed when remote interference is detected. If this option is deselected, adaptive remote interference avoidance is disabled. This option applies only to low-frequency TDD cells.

RIM_ADAPT_AVOID_ENH_SW: Indicates whether to enable enhanced adaptive remote interference avoidance. If this option is selected, enhanced adaptive avoidance is performed when remote interference is detected. If this option is deselected, enhanced adaptive remote interference avoidance is disabled. This option applies only to low-frequency TDD cells.

Super Uplink Switch

Indicates whether to enable functions related to the super uplink function.

SUPER_UL_TDM_SCH_SW: Indicates whether to enable UL and SUL time division multiplexing (TDM). This parameter applies only to SUL.

UE Link Abnormal Detect Switch

Indicates the UE link fault detection switch. If this switch is turned on, link fault detection is enabled for synchronized UEs. If this switch is turned off, link fault detection is not enabled for synchronized UEs.

Inter-RRU Channel Calibration Switch

Indicates whether to enable channel calibration.

INTER_RRU_CHN_CALIB_SW: Indicates whether to enable channel calibration. Channel calibration is enabled only if this option is selected. This option takes effect only when NRDUCell.LampSiteCellFlag is set to YES.

Low Latency Switch

Indicates whether to enable low-latency optimization functions.

NON_SLOT_SW: Indicates whether to enable low-latency non-slot symbol-level scheduling. This option applies only to low-frequency cells.

GRANT_FREE_SW: Indicates whether to enable the grant-free function. This option applies only to low-frequency TDD cells.

ANY_OCCASION_PDCCH_SW: Indicates whether to enable the function of transmitting the PDCCH at any occasion in a non-slot symbol. This option applies only to low-frequency TDD cells.

RAN Sharing Algorithm Switch

Indicates RAN sharing switches.

RB_DYNAMIC_SHARING_SW: If this option is selected and UEs of each operator have sufficient service requirements, the shared data channel resources are used based on the configured RB resource proportion. When the service requirements of an operator are insufficient, other operators can use the shared data channel resources beyond the configured proportion. If this option is deselected, RB resource scheduling is not operator-specific.

MAX_RB_LIMIT_SW: If this option is selected, the amount of data channel resources used by each operator cannot exceed the configured RB proportion. If this option is deselected, the gNodeB does not restrict the maximum proportion of available RBs for an operator.

Dynamic Power Sharing Switch

Indicates whether to enable dynamic power sharing. This parameter consists of the following options:

LTE_NR_DYN_POWER_SHARING_SW: Indicates whether to enable power sharing between LTE carriers and NR carriers when the LTE and NR carriers share RF resources. When this option is selected, power can be shared between LTE and NR carriers. When this option is deselected, power cannot be shared between LTE and NR carriers. This option applies only to low-frequency TDD cells.

Common Channel Interference Avoid Switch

Indicates whether to enable common channel interference avoidance.

SSB_INTRF_AVOID_SW: Indicates whether to enable SSB interference avoidance. This option applies only to FDD and low-frequency TDD cells.

VMIMO Switch

Indicates whether to enable virtual MIMO. Virtual MIMO is enabled only if this parameter is set to ON. This parameter applies only to low-frequency LampSite TDD cells.

BWP Configuration Policy Switch

Indicates the BWP configuration policy switches.

INIT_BWP_FULL_BW_SW: Indicates whether to configure the full-bandwidth initial BWP for UEs in the cell.

Service Differentiation Switch

Indicates service differentiation algorithm switches.

SPARSE_DIFF_SCH_SW: Indicates whether to enable differentiated scheduling for sparse-packet services. This parameter takes effect only when the gNodeBParam.ServiceDiffProcSwitch.SPARSE_DIFF_PROC_SW option is selected. If this option is selected, the base station performs differentiated scheduling for sparse-packet services. With this setting, preallocation is applied to sparse-packet services in the uplink and the target IBLER decreases. If this option is deselected, the base station does not perform differentiated scheduling for sparse-packet services. This parameter applies only in FDD and low-frequency TDD.
