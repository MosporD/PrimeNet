Modify Measurement Parameter Group Related to Inter-RAT Handover to E-UTRAN (MOD NRCELLHOEUTRANMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a measurement parameter group related to handover to E-UTRAN for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterRHoToEutranMeasGrpId Inter-RAT HO to E-UTRAN Meas Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-RAT handover to E-UTRAN.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CovBasedHoB1RsrpThld Coverage-based HO B1 RSRP Threshold

Meaning: Indicates the RSRP threshold for event B1 and RSRP threshold 2 for event B2. Both events are related to coverage-based handover to E-UTRAN. If the measured RSRP value of an E-UTRAN cell is greater than the event B1 threshold throughout the corresponding time-to-trigger, UEs send event B1 measurement reports. If the measured RSRP value of the serving cell is less than the event B2 RSRP threshold 1 throughout the corresponding time-to-trigger and the measured RSRP value of an E-UTRAN cell is greater than the event B2 RSRP threshold 2 throughout the corresponding time-to-trigger, UEs send event B2 measurement reports. For details, see 3GPP TS 38.331.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -111

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering event B1 or B2 related to coverage-based handover and stopping inter-RAT measurements. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CovBasedHoB1B2Hyst Coverage-based HO B1B2 Hysteresis

Meaning: Indicates the hysteresis for events B1 and B2 related to coverage-based handover to E-UTRAN. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of meeting the entering and leaving conditions for event B1/B2 related to coverage-based handover. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CovBasedHoB1B2TimeToTrig Coverage-based HO B1B2 Time to Trigger

Meaning: Indicates the time-to-trigger for event B1/B2 related to coverage-based handover to E-UTRAN. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the average number of handovers and the number of unexpected handovers and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: None

Recommended Value: 320MS(320)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of meeting the entering and leaving conditions for event B1/B2 related to coverage-based handover. A larger value of this parameter results in a lower probability of meeting the entering and leaving conditions for event B1/B2 related to coverage-based handover. In this case, the average number of starting E-UTRAN measurements decreases, and service drop risks increase.

Applicable Mode: N
EpsFbB1RsrpThld EPS FB B1 RSRP Threshold

Meaning: Indicates the RSRP threshold for event B1 related to EPS fallback to E-UTRAN. If the measured RSRP value of an E-UTRAN cell is greater than the B1 threshold throughout the corresponding time-to-trigger, UEs send event B1 measurement reports. For details, see 3GPP TS 38.331.

GUI Value Range: -140~-43

Unit: dBm

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -111

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering event B1 related to EPS fallback and stopping inter-RAT measurement. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
EpsFbB1Hyst EPS FB B1 Hysteresis

Meaning: Indicates the hysteresis for event B1 related to EPS fallback to E-UTRAN. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of meeting the entering and leaving conditions for event B1 related to EPS fallback. A larger value of this parameter results in a lower probability of meeting the entering and leaving conditions for event B1 related to EPS fallback.

Applicable Mode: N
EpsFbB1TimeToTrig EPS FB B1 Time to Trigger

Meaning: Indicates the time-to-trigger for the event related to EPS fallback to E-UTRAN. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Example

To modify a measurement parameter group related to inter-RAT handover to E-UTRAN for an NR cell with NR Cell ID set to 5, Inter-RAT HO to E-UTRAN Meas Group ID set to 1, Coverage-based HO B1 RSRP Threshold set to -112, Coverage-based HO B1B2 Hysteresis set to 3, Coverage-based HO B1B2 Time to Trigger set to 128MS, EPS FB B1 RSRP Threshold set to -112, EPS FB B1 Hysteresis set to 3, and EPS FB B1 Time to Trigger set to 160MS, run the following command:
MOD NRCELLHOEUTRANMEAGRP: NrCellId=5, InterRHoToEutranMeasGrpId=1, CovBasedHoB1RsrpThld=-112, CovBasedHoB1B2Hyst=3, CovBasedHoB1B2TimeToTrig=128MS, EpsFbB1RsrpThld=-112, EpsFbB1Hyst=3, EpsFbB1TimeToTrig=160MS;
