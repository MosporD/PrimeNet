Display gNodeB CU Xn Interface (DSP GNBCUXNINTERFACE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the status of an Xn interface and the information about the peer gNodeB. The information about the peer gNodeB includes the global ID of the gNodeB and the broadcast PLMN ID. If the status of an Xn interface is abnormal, the command output displays the information of the peer gNodeB in the last normal connection with the local gNodeB.

Note

None.

Parameters

ID Name Description
gNBCuXnInterfaceId gNodeB CU Xn Interface ID

Meaning: Indicates the ID of a gNodeB CU Xn interface.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
QueryType Query Type

Meaning: Indicates the state of gNodeB CU Xn interfaces to be queried. If this parameter is unspecified, the command output displays the information of all Xn interfaces regardless of their states. If gNBCuXnInterfaceId is specified, this QueryType parameter does not take effect.

GUI Value Range: FAULT_TYPE(Fault Type), NORMAL_TYPE(Normal Type)

Unit: None

Actual Value Range: FAULT_TYPE, NORMAL_TYPE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Output Description

Field Description

gNodeB CU Xn Interface ID

Indicates the ID of a gNodeB CU Xn interface.

gNodeB CU Xn Interface CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU Xn interface.

Operator ID

Indicates the ID of the home operator configured at the local end of the gNodeB CU Xn interface.

Abnormal Reason

Indicates the reason why a gNodeB CU Xn interface is abnormal.

gNodeB CU Xn Interface CP Bearer State

Indicates the state of the bottom-layer CP bearer of a gNodeB CU Xn interface.

gNodeB CU Xn Interface State

Indicates the state of a gNodeB CU Xn interface.

Last Fault Time

Indicates the time when the last gNodeB CU Xn interface fault occurred. The time format is YEAR-MONTH-DAY HH:MM:SS. For example, 2018-1-1 10:20:05 indicates 10:20:05 on January 1, 2018.

Neighboring gNodeB ID

Indicates the ID of the neighboring gNodeB on the peer end of a gNodeB CU Xn interface. The combination of this parameter and neighboring gNodeB PLMN ID uniquely identifies the neighboring gNodeB around the globe.

Neighboring gNodeB PLMN ID

Indicates the PLMN ID of the neighboring gNodeB on the peer end of a gNodeB CU Xn interface.

Neighboring gNodeB Serving PLMN ID

Indicates the IDs of all served PLMNs of the base stations over the gNodeB CU Xn interface. The ID of a served PLMN consists of the MCC and MNC. PLMN IDs are separated by commas (,).

gNodeB CU Xn Control Plane Host IP

Indicates the local IP address of the control plane of the gNodeB CU Xn interface.

gNodeB CU Xn Control Plane Peer IP

Indicates the peer IP address of the control plane of the gNodeB CU Xn interface.

gNodeB CU Xn User Plane Host IP

Indicates the local IP address of the user plane of the gNodeB CU Xn interface.

gNodeB CU Xn User Plane Peer IP

Indicates the peer IP address of the user plane of the gNodeB CU Xn interface.
