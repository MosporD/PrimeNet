Remove Measurement Parameter Group Related to Inter-frequency Handover (RMV NRCELLINTERFHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a measurement parameter group related to inter-frequency handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterFreqHoMeasGroupId Inter-freq Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-frequency handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of CovInterFreqA1RsrpThld must be greater than that of CovInterFreqA2RsrpThld.
  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of FreqPriInterFA1RsrpThld must be greater than that of FreqPriInterFA2RsrpThld.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N

Example

To remove a measurement parameter group related to inter-frequency handover for an NR cell with NR Cell ID set to 5 and Inter-freq Handover Measurement Group ID set to 0, run the following command:
RMV NRCELLINTERFHOMEAGRP: NrCellId=5, InterFreqHoMeasGroupId=0;
