Modify gNodeB Operator QCI Parameters (MOD GNBOPERATORQCIPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify operator-level QCI parameter configurations for a gNodeB.

Note

None.

Parameters

ID Name Description
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
Qci QoS Class Identifier

Meaning: Indicates a QoS class identifier, which is an attribute of radio bearers.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
EutranA2B2RsrpThldOffset E-UTRAN A2/B2 RSRP Threshold Offset

Meaning: For event A2, this parameter indicates the offset of the RSRP threshold for event A2 related to handover to E-UTRAN relative to the RSRP threshold for event A2 related to inter-RAT handover. This offset plus the RSRP threshold for event A2 related to inter-RAT handover (specified by the NRCellInterRHoMeaGrp.InterRatHoA2RsrpThld parameter) equals the RSRP threshold for event A2 related to handover to E-UTRAN.

For event B2, this parameter indicates the offset of the RSRP threshold 1 for event B2 related to handover to E-UTRAN relative to the RSRP threshold 1 for event B2 related to coverage-based handover to E-UTRAN. This offset plus the RSRP threshold 1 for event B2 related to coverage-based handover to E-UTRAN (specified by the NRCellInterRHoMeaGrp.CovHoToEutranB2RsrpThld1 parameter) equals the RSRP threshold 1 for event B2 related to handover to E-UTRAN.

GUI Value Range: -20~20

Unit: dB

Actual Value Range: -20~20

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering coverage-based handover to E-UTRAN for the operator. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD, N-FDD

Example

To modify the QCI parameters of a gNodeB operator with Operator ID set to 0, QoS Class Identifier set to 1, and E-UTRAN A2/B2 RSRP Threshold Offset set to 2, run the following command:
MOD GNBOPERATORQCIPARAM: OperatorId=0, Qci=1, EutranA2B2RsrpThldOffset=2;
