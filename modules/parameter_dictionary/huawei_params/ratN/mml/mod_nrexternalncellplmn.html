Modify NR External Neighboring Cell PLMN List (MOD NREXTERNALNCELLPLMN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the NR external-cell PLMN list.

Note

The TAC, gNodeB ID, and cell ID of secondary operators must be set based on neighboring cell configurations.

Parameters

ID Name Description
CellId Cell ID

Meaning: Indicates the unique primary-operator cell ID of an external NR cell within a base station. An NR Cell Identity (NCI), which is 36 bits long, consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.

GUI Value Range: 0~16383

Unit: None

Actual Value Range: 0~16383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the unique primary-operator gNodeB ID of an external NR cell. An NR Cell Identity (NCI) consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.

GUI Value Range: 0~4294967295

Mcc Mobile Country Code

Meaning: Indicates the primary-operator MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in an NRExternalNCellPlmn MO can contain only digits.
  • In an NRExternalNCellPlmn MO, the combination of Mcc and Mnc must be different from that of SharedMcc and SharedMnc.

Tac Tracking Area Code

Meaning: Indicates the secondary-operator TAC of an external NR cell. The TAC is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. TAC planning is not required when NrNetworkingOption is set to NSA for a secondary operator to which an external NR cell belongs and it is recommended that this parameter be set to the invalid value (4294967295). TAC planning is mandatory when NrNetworkingOption is set to SA or SA_NSA for a secondary operator to which an external NR cell belongs and this parameter must not be set to the invalid value.

GUI Value Range: 0~16777215,4294967295

Unit: None

Actual Value Range: 0~16777215,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
NrNetworkingOption NR Networking Option

Meaning: Indicates the secondary-operator networking option of an external NR cell. The value UNLIMITED indicates the initial state of the secondary operator to which an external cell belongs. That is, a secondary operator to which an external cell belongs works in unknown networking mode, and the cell can serve as a target cell for handovers. The value SA indicates that a secondary operator to which an external cell belongs works in SA networking mode. The value NSA indicates that a secondary operator to which an external cell belongs works in NSA networking mode. The value SA_NSA indicates that a secondary operator to which an external cell belongs works in SA and NSA hybrid networking mode.

GUI Value Range: UNLIMITED(Unlimited), SA(Standalone), NSA(Non-standalone), SA_NSA(SA and NSA)

Unit: None

Actual Value Range: UNLIMITED, SA, NSA, SA_NSA

MML Default Value: None

Recommended Value: It is recommended that the value of this parameter be consistent with the value of NrNetworkingOption of the corresponding operator of the peer gNodeB.

When the value of NrNetworkingOption of the corresponding operator of the peer gNodeB is SA: SA

When the value of NrNetworkingOption of the corresponding operator of the peer gNodeB is NSA: NSA

When the value of NrNetworkingOption of the corresponding operator of the peer gNodeB is SA_NSA: SA_NSA

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
SharedPlmnCellId Shared PLMN Cell ID

Meaning: Indicates the unique secondary-operator cell ID of an external NR cell within a base station. If this parameter is set to 65535, no exclusive cell ID is available for the operator, and the value of the NRExternalNCell.CellId parameter is used as the cell ID of the operator.

GUI Value Range: 0~16383,65535

Unit: None

Actual Value Range: 0~16383,65535

MML Default Value: None

Recommended Value: If multiple NCIs are configured for an external NR cell, the value of this parameter must be the same as the secondary-operator cell ID of the external cell.

If multiple NCIs are not configured for an external NR cell, the value 65535 is recommended.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
SharedPlmngNBId Shared PLMN gNodeB ID

Meaning: Indicates the unique secondary-operator gNodeB ID of an external NR cell. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to 65535, this parameter is invalid. In this case, no exclusive gNodeB ID is available for the operator, and the value of the NRExternalNCell.gNBId parameter is used as the gNodeB ID of the operator. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to a value other than 65535, this parameter needs to be set to the operator's gNodeB ID configured on the corresponding neighboring base station.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: If multiple NCIs are configured for an external NR cell, the value of this parameter must be the same as the secondary-operator gNodeB ID of the external cell.

If multiple NCIs are not configured for an external NR cell, the value 0 is recommended.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify a PLMN list of external neighboring cells of NR with Cell ID set to 30, gNodeB ID set to 20, Mobile Country Code set to "302", Mobile Network Code set to "220", Shared Mobile Country Code set to "103", Shared Mobile Network Code set to "103", and NR Networking Option set to SA, run the following command:
MOD NREXTERNALNCELLPLMN: CellId=30, gNBId=20, Mcc="302", Mnc="220", SharedMcc="103", SharedMnc="103", NrNetworkingOption=SA;
