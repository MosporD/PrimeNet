List NR DU Cell PDCCH (LST NRDUCELLPDCCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of the PDCCH in an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the PDCCH configuration of an NR DU cell with NR DU Cell ID set to 88, run the following command:
LST NRDUCELLPDCCH: NrDuCellId=88;
The result is shown as follows:

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Uplink Maximum CCE Percentage(%)

Indicates the maximum percentage of uplink available CCEs in a slot that is used for the transmission of both uplink and downlink scheduling information.

Occupied Symbol Number

Indicates the number of symbols occupied by the PDCCH.

Maximum Pairing Layer Number

Indicates the maximum number of pairing layers for PDCCH spatial multiplexing. This parameter can be set to specify the maximum number of PDCCH spatial layers only when the PDCCH_MU_SW option is selected. This parameter applies only to low-frequency TDD cells.

Number of Occupied RBs

Indicates the frequency domain range occupied by each PDCCH symbol in a cell. This parameter takes effect only when the rate matching function is enabled for PDCCH and PDSCH resources. If this parameter is set to 0, full band resources are occupied. If this parameter is set to a value greater than the downlink bandwidth (specified by DlBandwidth), the PDCCH uses full band resources by default.

PDCCH BLER Target

Indicates the target BLER value for PDCCH link adaptation. The PDCCH BLER needs to converge to this target value.

SUL Maximum CCE Percentage(%)

Indicates the maximum percentage of CCEs available in the uplink for decoupling UEs when decoupling UEs are scheduled in slots used only for downlink scheduling in TDD cells.

PDCCH Algorithm Switch

Indicates the PDCCH algorithm switches.

UL_DL_CCE_RATIO_ADAPT_SW: Indicates whether to enable uplink and downlink CCE percentage adaptation in a cell. If this option is selected, the gNodeB adaptively adjusts the maximum percentage of uplink CCEs based on uplink and downlink CCE requirements. If this option is deselected, the maximum percentage of uplink CCEs is specified by the NRDUCellPdcch.UlMaxCcePct or NRDUCellPdcch.SulMaxCcePct parameter. This option takes effect in scenarios other than FDD 5 MHz scenarios. In FDD 5 MHz scenarios, uplink and downlink CCE percentage adaptation takes effect by default.

Spectrum Sharing Start Symbol

Indicates the start symbol occupied by the PDCCH when LTE FDD and NR Spectrum Sharing is enabled. For details, see 3GPP TS 38.331. This parameter is valid only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.

PDCCH Algorithm Extension Switch

Indicates PDCCH algorithm extension switches.

UE_PDCCH_SYM_NUM_ADAPT_SW: Indicates whether to enable UE-specific PDCCH symbol number adaptation in a cell. If this option is selected, UE-specific PDCCH symbol number adaptation is enabled, and the NRDUCellPdcch.OccupiedSymbolNum parameter no longer takes effect. If this option is deselected, the number of UE-specific PDCCH symbols is specified by the NRDUCellPdcch.OccupiedSymbolNum parameter. This option does not take effect for high-frequency cells.

PDCCH Algorithm Enhancement Switch

Indicates the enhanced PDCCH algorithm switches.

AGG_LVL_INIT_SELECT_OPT_SW: Indicates whether to enable initial aggregation level selection optimization in a cell. This function is enabled only when this option is selected.

Number of Guaranteed RBs

Indicates the number of guaranteed PDCCH RBs allocated to an NR cell when resources are sufficient in LTE FDD and NR spectrum sharing scenarios. When the number of PDCCH RBs required by an NR cell is greater than the value of this parameter, PDCCH RBs are allocated based on the service requirement. When the number of PDCCH RBs required by an NR cell is smaller than the value of this parameter, PDCCH RBs are allocated based on the value of this parameter.

When the number of configured RBs exceeds the RB number corresponding to downlink bandwidth (specified by DlBandwidth), the PDCCH occupies full-band resources by default. This parameter takes effect only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.
