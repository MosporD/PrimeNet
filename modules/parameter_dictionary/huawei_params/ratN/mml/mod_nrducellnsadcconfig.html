Modify NR DU Cell NSA DC Parameter Configuration (MOD NRDUCELLNSADCCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of the LTE-NR NSA DC parameters for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
HarmonicIntrfAvoidRange Harmonic Interference Avoidance Range

Meaning: Indicates the frequency-domain range of NSA DC harmonic interference avoidance. If this parameter is set to NR_DL_COMMON_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to the NR downlink common channels (SSB/common PDCCH) in the uplink. If this parameter is set to NR_DL_COMMON_AND_DATA_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to the NR downlink common channels (SSB/common PDCCH) in the uplink. In addition, RBs that are not interfered by harmonic signals are preferentially allocated to NR downlink data channels. This parameter is valid only if the HARMONIC_INTRF_AVOID_SW option of the NRDUCellAlgoSwitch.NsaDcAlgoSwitch parameter is selected.

GUI Value Range: NR_DL_COMMON_CHANNEL(NR DL Common Channel), NR_DL_COMMON_AND_DATA_CHANNEL(NR DL Common and Data Channels)

Unit: None

Actual Value Range: NR_DL_COMMON_CHANNEL, NR_DL_COMMON_AND_DATA_CHANNEL

MML Default Value: None

Recommended Value: NR_DL_COMMON_CHANNEL(NR DL Common Channel)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NR_DL_COMMON_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to NR downlink common channels (SSB/common PDCCH) in the uplink. However, the gNodeB does not perform avoidance for the PDSCH RBs that may be interfered. As a result, the downlink data throughput on the NR side may decrease. If this parameter is set to NR_DL_COMMON_AND_DATA_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to the NR downlink common channels (SSB/common PDCCH) in the uplink. In addition, RBs that are not interfered by harmonic signals are preferentially allocated to NR downlink data channels. This increases the downlink data throughput.

Applicable Mode: N

Example

To modify the NSA DC parameter configurations of an NR DU cell with NR DU Cell ID set to 11177 and Harmonic Interference Avoidance Range set to NR_DL_COMMON_CHANNEL, run the following command:
MOD NRDUCELLNSADCCONFIG: NrDuCellId=11177, HarmonicIntrfAvoidRange=NR_DL_COMMON_CHANNEL;
