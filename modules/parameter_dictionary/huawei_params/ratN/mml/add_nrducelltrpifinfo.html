Add NR DU Cell TRP IF Information (ADD NRDUCELLTRPIFINFO)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the TRP intermediate frequency configuration of an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After this command is executed, the cell automatically restarts.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NrIfDlCenterFreq NR IF Downlink Center Frequency

Meaning: Indicates the downlink center frequency of intermediate frequency.

GUI Value Range: 63728~83728

Unit: 0.005MHz

Actual Value Range: 318.64~418.64

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
NrIfUlCenterFreq NR IF Uplink Center Frequency

Meaning: Indicates the uplink center frequency of intermediate frequency.

GUI Value Range: 14576~34576

Unit: 0.005MHz

Actual Value Range: 72.88~172.88

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
NrIfOutputPower NR IF Output Power

Meaning: Indicates the output power of intermediate frequency.

GUI Value Range: -200~-100

Unit: 0.1dBm

Actual Value Range: -20~-10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
NrIfUplinkReceiveGain NR IF Uplink Receive Gain

Meaning: Indicates the gains of the uplink RX channel.

GUI Value Range: 350~550

Unit: 0.1dB

Actual Value Range: 35~55

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add the TRP IF information about an NR DU cell with the parameters as follows: NR DU Cell TRP ID: 50, NR IF Downlink Center Frequency: 63728, NR IF Uplink Center Frequency: 14576, NR IF Output Power: –200, NR IF Uplink Receive Gain: 350, run the following command:
ADD NRDUCELLTRPIFINFO: NrDuCellTrpId=50, NrIfDlCenterFreq=63728, NrIfUlCenterFreq=14576, NrIfOutputPower=-200, NrIfUplinkReceiveGain=350;
