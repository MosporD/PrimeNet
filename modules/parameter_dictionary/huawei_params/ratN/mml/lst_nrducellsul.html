List NR DU Cell SUL (LST NRDUCELLSUL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of SUL carriers for an NR DU cell.

Note

None.

Parameters

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Example

To list the configuration of the SUL carrier for an NR DU cell with NR DU Cell ID set to 0, run the following command:
LST NRDUCELLSUL: NrDuCellId=0;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

SUL NR DU Cell ID

Indicates the ID of the SUL NR DU cell involved in NR uplink and downlink decoupling.

RSRP Threshold(dBm)

Indicates the RSRP threshold for selecting an uplink carrier for UEs in idle mode or during SgNB addition in EN-DC scenarios. If the RSRP is greater than the threshold, a UE performs access on the normal UL carrier. If the RSRP is lower than the threshold, the UE performs access on the SUL carrier.

UL and DL Decoupling Algorithm Switch

Indicates the algorithm switch for the NR uplink and downlink decoupling feature.

SEC_HARMONIC_INTRF_AVOID_SW: Indicates whether to enable secondary harmonic interference avoidance.

UL_CARR_SEL_FOR_UE_EXP_SW: Indicates whether to enable user-experience-based uplink carrier selection.

SUL_CHANNEL_DECOUPLE_SW: Indicates whether to enable decoupling of channels on the SUL carrier.

INTRA_GNB_SUL_COMP_SW: Indicates whether to enable SUL CoMP.

SRS RSRP Threshold(dBm)

Indicates the SRS RSRP threshold for selecting an uplink carrier for UEs in connected mode. If the SRS RSRP is greater than the threshold, the UE for which UL and DL Decoupling takes effect switches from the SUL carrier to the normal uplink (NUL) carrier. If the SRS RSRP is lower than the threshold, the UE for which UL and DL Decoupling takes effect switches from the NUL carrier to the SUL carrier.

Decoupling Estimate Throughput Gain Factor

Indicates the estimated throughput threshold percentage for switchover from NUL to SUL in uplink and downlink decoupling scenarios. When UEs for which UL and DL Decoupling takes effect camp on the NUL carrier and the estimated uplink throughput of the SUL is greater than the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are handed over from the NUL carrier to the SUL carrier. If the estimated uplink throughput of the SUL is less than or equal to the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are not handed over from the NUL carrier to the SUL carrier. This parameter applies only to SUL.
