Modify NR DU Cell Interference Solution Parameter (MOD NRDUCELLINTRFPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify interference solution parameters for an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed, the cell automatically resets for the modification to take effect.

  • Parameters, including MoId, ParaId, ParaBitId, and ConfigValue, in this command must be specified following the instructions from Huawei technical engineers. Run this command only under the guidance of Huawei technical support. The instances with incorrect parameter settings must be manually deleted.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterferenceSolutionType Interference Solution Type

Meaning: Indicates the interference solution that needs to take effect.

GUI Value Range: NOT_CONFIG(Not Configured), NARROWBAND_INTRF(Narrowband Interference), LTE_INTRF(LTE Interference)

Unit: None

Actual Value Range: NOT_CONFIG, NARROWBAND_INTRF, LTE_INTRF

MML Default Value: None

Recommended Value: NOT_CONFIG(Not Configured)

Parameter Relationship:

-Configuration constraints:

  • In the NRDUCellIntrfParam MO, if InterferenceSolutionType is set to NARROWBAND_INTRF, StartRbIndexOfIntrf1 is not set to 273, and EndRbIndexOfIntrf1 is not set to 273, then the maximum value of EndRbIndexOfIntrf1 is StartRbIndexOfIntrf1 plus 13.
  • If InterferenceSolutionType in the NRDUCellIntrfParam MO is set to LTE_INTRF and neither StartRbIndexOfIntrf1 nor EndRbIndexOfIntrf1 is set to 273, the difference between EndRbIndexOfIntrf1 and StartRbIndexOfIntrf1 must be greater than or equal to 24, the difference between EndRbIndexOfIntrf1 and StartRbIndexOfIntrf1 must be less than or equal to 216, and the value of StartRbIndexOfIntrf1 must be 0 or greater than or equal to 12.
  • In the NRDUCellIntrfParam MO, if InterferenceSolutionType is set to NARROWBAND_INTRF, StartRbIndexOfIntrf2 is not set to 273, and EndRbIndexOfIntrf2 is not set to 273, then the maximum value of EndRbIndexOfIntrf2 is StartRbIndexOfIntrf2 plus 13.
  • If InterferenceSolutionType in the NRDUCellIntrfParam MO is set to LTE_INTRF and neither StartRbIndexOfIntrf2 nor EndRbIndexOfIntrf2 is set to 273, the difference between EndRbIndexOfIntrf2 and StartRbIndexOfIntrf2 must be greater than or equal to 24, the difference between EndRbIndexOfIntrf2 and StartRbIndexOfIntrf2 must be less than or equal to 216, and the value of StartRbIndexOfIntrf2 must be 0 or greater than or equal to 12.
  • In the NRDUCellIntrfParam MO, if InterferenceSolutionType is not set to NOT_CONFIG, then StartRbIndexOfIntrf1 cannot be set to 273, EndRbIndexOfIntrf1 or StartRbIndexOfIntrf2 cannot be set to 273, and EndRbIndexOfIntrf2 cannot be set to 273.
  • If InterferenceSolutionType in the NRDUCellIntrfParam MO is set to LTE_INTRF and none of StartRbIndexOfIntrf1, EndRbIndexOfIntrf1, StartRbIndexOfIntrf2, and EndRbIndexOfIntrf2 is set to 273, the value of StartRbIndexOfIntrf2 must be equal to the value of EndRbIndexOfIntrf1 plus 1, or the value of StartRbIndexOfIntrf2 must be greater than or equal to the value of EndRbIndexOfIntrf1 plus 13.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to NARROWBAND_INTRF, the cell capacity increases when narrowband interference exists in a cell.

If this parameter is set to LTE_INTRF, the cell capacity increases when LTE interference exists in a cell.

Applicable Mode: N
StartRbIndexOfIntrf1 Start RB Index of First Interference

Meaning: Indicates the start RB index of the first interfered segment in narrowband interference or co-channel LTE interference. The value 273 indicates that the interfered segment does not take effect.

GUI Value Range: 0~273

Unit: None

Actual Value Range: 0~273

MML Default Value: None

Recommended Value: 273

Parameter Relationship:

-Configuration constraints:

  • In the NRDUCellIntrfParam MO, if InterferenceSolutionType is set to NARROWBAND_INTRF, StartRbIndexOfIntrf1 is not set to 273, and EndRbIndexOfIntrf1 is not set to 273, then the maximum value of EndRbIndexOfIntrf1 is StartRbIndexOfIntrf1 plus 13.

  • In the NRDUCellIntrfParam MO, if StartRbIndexOfIntrf1 and EndRbIndexOfIntrf1 are not set to 273, then the value of StartRbIndexOfIntrf1 must be less than or equal to that of EndRbIndexOfIntrf1.
  • In the NRDUCellIntrfParam MO, if InterferenceSolutionType is not set to NOT_CONFIG, then StartRbIndexOfIntrf1 cannot be set to 273, EndRbIndexOfIntrf1 or StartRbIndexOfIntrf2 cannot be set to 273, and EndRbIndexOfIntrf2 cannot be set to 273.
  • If InterferenceSolutionType in the NRDUCellIntrfParam MO is set to LTE_INTRF and none of StartRbIndexOfIntrf1, EndRbIndexOfIntrf1, StartRbIndexOfIntrf2, and EndRbIndexOfIntrf2 is set to 273, the value of StartRbIndexOfIntrf2 must be equal to the value of EndRbIndexOfIntrf1 plus 1, or the value of StartRbIndexOfIntrf2 must be greater than or equal to the value of EndRbIndexOfIntrf1 plus 13.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

MOD NRDUCELLINTRFPARAM: NrDuCellId=88, InterferenceSolutionType=NARROWBAND_INTRF;
