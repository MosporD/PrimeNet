List Common gNodeB Mobility Parameters (LST GNBMOBILITYCOMMPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list common gNodeB mobility parameters.

Note

None.

Parameters

None.

Example

List Common gNodeB Mobility Parameters:
LST GNBMOBILITYCOMMPARAM:;
The result is shown as follows:

Output Description

Field Description

Necessary HO Prepare Fail Punish Timer(s)

Indicates the penalty timer applied to handover (EPS fallback, coverage-based intra-RAT handover, or coverage-based inter-RAT handover) to a target cell. If a handover preparation fails due to resource-related causes, the handover to the target cell is prohibited within the timer. If this parameter is set to 0, penalty is not performed.

Optimized HO Prepare Fail Punish Timer(s)

Indicates the penalty timer applied to handover (frequency-priority-based handover) to a target cell. If a handover preparation fails due to resource-related causes, the handover to the target cell is prohibited within the timer. If this parameter is set to 0, penalty is not performed.

Non-Res HO Prepare Fail Punish Times(time)

Indicates the number of times penalty is performed following non-resource-related handover preparation failures. If a handover preparation fails due to non-resource-related causes during a handover to the target cell, the gNodeB prohibits the UE from being handed over to the target cell based on the number of penalty times. If this parameter is set to 0, the gNodeB does not impose a penalty on the target cell after a handover preparation fails due to non-resource-related causes.

Max Num of HO Fwd PDCP Pkt with SN

Indicates the maximum number of PDCP packets that can be forwarded with SNs during handovers when the PDCP SN size is less than 18 bits.

Max Rate of PDCP HO Trans(100Mbps)

Indicates the maximum rate at which PDCP data is forwarded during intra-RAT inter-gNodeB handovers. If this parameter is set to 65535, it does not take effect and PDCP data is forwarded at the maximum rate supported by the system. It is recommended that this parameter be set to a value not greater than the maximum rate allowed by the physical transmission bandwidth of the link. Otherwise, packet loss may occur in the forwarded data during handovers.

Wait NSA DC UE PDCP Status Report Timer(ms)

Indicates the length of the timer that governs the period in which the base station waits for a PDCP status report from an NSA-DC-capable UE. In data forwarding scenarios triggered by an NSA UE handover or SCG addition or deletion, the base station starts this timer. If the base station already receives the PDCP status report from the UE before the timer expires, the base station no longer sends the correctly received packets. If the base station does not receive the PDCP status report from the UE before the timer expires, the base station retransmits all packets forwarded by the source base station.

HO and PDU Session Conflict Handling Sw

Indicates switches of handling conflicts between intra-RAT and inter-RAT outgoing handover preparation and PDU session procedures.

VOICE_FB_FIRST_SWITCH: Indicates whether the NG-RAN preferentially processes voice fallbacks when a voice fallback request is received during an outgoing handover preparation procedure. When this option is selected, voice fallbacks are preferentially processed. If this option is deselected, outgoing handovers are preferentially processed.
