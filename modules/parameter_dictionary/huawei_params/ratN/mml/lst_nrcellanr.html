List NR Cell ANR (LST NRCELLANR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the ANR configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the ANR configuration of an NR cell with NR Cell ID set to 55, run the following command:
LST NRCELLANR: NrCellId=55;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

ANR Mode Switch

Indicates the ANR mode switches.

NR_NR_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for intra-NR ANR. When the controlled mode is disabled, the gNodeB automatically configures neighboring NR cells. When the controlled mode is enabled, the gNodeB reports neighboring NR cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_NR_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring NR cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for intra-NR ANR.

NR_EUTRAN_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for ANR with E-UTRAN. When the controlled mode is disabled, the gNodeB automatically configures neighboring E-UTRAN cells. When the controlled mode is enabled, the gNodeB reports neighboring E-UTRAN cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_EUTRAN_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring E-UTRAN cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for ANR with E-UTRAN.

EUTRAN_NCELL_PLMN_RR_MODE_SW: Indicates whether neighboring E-UTRAN cells support the PLMN round robin mode in RAN sharing scenarios.

Over Distant Neighboring Cell Threshold(m)

Indicates the threshold for evaluating an over-distant coverage neighboring cell.

If this parameter is set to a value other than 0, an over-distant neighboring cell is detected based on the distance. If the distance between a serving cell and a neighboring cell is greater than this threshold, the neighboring cell is an over-distant neighboring cell.

If this parameter is set to 0, the gNodeB does not evaluate whether a neighboring E-UTRAN cell is an over-distant neighboring cell. Instead, the gNodeB evaluates an over-distant neighboring NR cell based on the cell radius. That is, if the distance between a serving cell and a neighboring NR cell is greater than the sum of radii of both cells, this neighboring cell is an over-distant neighboring cell.
