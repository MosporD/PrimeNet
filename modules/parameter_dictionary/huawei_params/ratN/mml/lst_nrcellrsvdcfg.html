List NR Cell Commissioning Reserved Parameter Configuration (LST NRCELLRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of a reserved parameter for NR cell commissioning.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the settings of an NR cell's reserved parameters with NR Cell ID set to 1, run the following command:
LST NRCELLRSVDCFG: NrCellId=1;
The result is shown as follows:
