Remove NR DU Cell Power Saving (RMV NRDUCELLPOWERSAVING)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove NR DU cell power saving configurations.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The time difference between NRDUCellPowerSaving MO instances with the same NrDuCellId and PowerSavingType must be greater than 5 minutes.
  • The time segment of an NRDUCellPowerSaving MO instance with PowerSavingType set to TIMING_CARRIER_SHUTDOWN must not overlap with the time segments of other NRDUCellPowerSaving MO instances associated with the same NrDuCellId as this MO instance.
  • If an NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING exists, an NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE must exist for the cell. In addition, the time range in the record with PowerSavingType set to LNR_BUNDLED_SCHEDULING in the NRDUCellPowerSaving MO corresponding to the cell must be within the time range in the record with PowerSavingType set to POWER_SAVING_SCHEDULE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
PowerSavingPolicyIndex Power Saving Policy Index

Meaning: Indicates the index of an NR DU cell power saving policy. It uniquely identifies a power saving policy for an NR DU cell.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove the power-saving configurations of an NR DU cell with NR DU Cell ID set to 116 and Power Saving Policy Index set to 2,
run the following command:
RMV NRDUCELLPOWERSAVING: NrDuCellId=116, PowerSavingPolicyIndex=2;
