List gNodeB CU NG Operator Information (LST GNBCUNGOP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list gNodeB CU NG operator information.

Note

None.

Parameters

ID Name Description
gNBCuNgId gNodeB CU NG ID

Meaning: Indicates the ID of a gNodeB CU NG object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list gNodeB CU NG operator information, run the following command:
LST GNBCUNGOP:;
