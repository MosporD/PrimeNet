Modify gNodeB NR-LTE Cell Combination (MOD GNBNRLTECELLCOMB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a gNodeB NR-LTE cell combination.

Note

None.

Parameters

ID Name Description

Meaning: Indicates the MCC of the NR network operator.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in a gNBNrLteCellComb MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

LteCellId LTE Cell ID

Meaning: Indicates the E-UTRAN cell ID. It uniquely identifies an E-UTRAN cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The E-UTRAN cell global identifier (ECGI) is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

AggregationAttribute Aggregation Attribute

Meaning: Indicates the aggregation attributes of an LTE and NR co-deployment cell combination in NSA networking.

CO_DEPLOYMENT_NSA_FLAG: Indicates whether the current LTE and NR cell pair is a co-deployment cell pair. If this option is selected, NSA DC is allowed in the current LTE and NR cell pair in the co-deployment frequency band combination. If this option is deselected, NSA DC is not allowed in the current LTE and NR cell pair in the co-deployment frequency band combination.

GUI Value Range: CO_DEPLOYMENT_NSA_FLAG(Co-deployment NSA Flag)

Unit: None

Actual Value Range: CO_DEPLOYMENT_NSA_FLAG

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify an NR-LTE cell combination of a gNodeB with the parameters as follows: NR MCC: 262, NR MNC: 02, gNodeB ID: 37131, Cell ID: 62, LTE MCC: 262, LTE MNC: 02, eNodeB ID: 37130, LTE Cell ID: 61, CO_DEPLOYMENT_NSA_FLAG: On, run the following command:
MOD GNBNRLTECELLCOMB: Mcc="262", Mnc="02", gNodeBId=37131, CellId=62, LteMcc="262", LteMnc="02", eNodeBId=37130, LteCellId=61, AggregationAttribute=CO_DEPLOYMENT_NSA_FLAG-1;
