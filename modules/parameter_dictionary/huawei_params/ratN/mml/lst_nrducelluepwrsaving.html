List UE Power Saving in NR DU Cell (LST NRDUCELLUEPWRSAVING)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list UE power-saving parameters of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list power-saving parameters of an NR DU cell, run the following command:
LST NRDUCELLUEPWRSAVING: NrDuCellId=11;
The result is shown as follows:
+++    0        2018-08-21 21:26:45
O&M    #2685403188
%%LST NRDUCELLUEPWRSAVING: NrDuCellId=11;%%
RETCODE = 0  Operation succeeded.

                  NR DU Cell ID  =  11
NR DU Cell DRX Algorithm Switch  =  Basic DRX Switch:Off
                                 =  LTE and NR DRX Synchronization Switch:Off
        BWP Power Saving Switch  =  BWP Power Saving Switch:Off
(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

NR DU Cell DRX Algorithm Switch

Indicates whether to enable the DRX algorithm for an NR DU cell.

BASIC_DRX_SW: Indicates whether to enable DRX for UEs in an NR DU cell.

LNR_DRX_SYNCHRONIZE_SW: Indicates whether to enable DRX synchronization for EN-DC UEs in an NR DU cell. This option takes effect only if the BASIC_DRX_SW option is selected.

BWP Power Saving Switch

Indicates whether to allow UEs in the local cell to enter the BWP2 power saving state.

BWP2_SWITCH: Indicates whether the cell allows BWP2 power saving for UEs. When this option is selected, the cell allows UEs capable of this function to enter the BWP power saving state. When this option is deselected, the cell does not allow UEs to enter the BWP power saving state, even if the UEs support this function. This parameter takes effect only when NRDUCellPucch.StructureType is set to LONG_STRUCTURE. This parameter applies only to low-frequency TDD cells.
