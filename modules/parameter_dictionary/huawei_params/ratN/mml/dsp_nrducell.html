Display NR DU Cell (DSP NRDUCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the dynamic information of NR DU Cells.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the dynamic information of an NR DU cell with NR DU Cell ID set to 88, run the following command:
DSP NRDUCELL: NrDuCellId=88;
The result is shown as follows:

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Cell ID

Indicates the ID of an NR cell. This cell ID and the gNodeB ID compose the 3GPP-defined NR cell ID. The 3GPP-defined NR cell ID and the PLMN ID compose the NR CGI. For details, see 3GPP TS 38.413.

NR DU Cell State

Indicates the state of an NR DU cell instance. The state of an NR DU cell can be Normal, Not Set Up, or Access Barred.

NR DU Cell Latest State Change Reason

Indicates the reason for the latest state change of an NR DU cell, which can be an activation success or a setup failure of the NR DU cell.

Latest Time When NR DU Cell Become Available

Indicates the latest time when an NR DU cell becomes available.

Latest Operation Make NR DU Cell Available

Indicates the latest operation that makes an NR DU cell available.

Latest Time When NR DU Cell Become Unavailable

Indicates the latest time when an NR DU cell becomes unavailable.

Latest Operation Make NR DU Cell Unavailable

Indicates the latest operation that makes an NR DU cell unavailable.

Symbol Shutdown State

Indicates the symbol power saving status of a cell.

Power Saving State

Indicates the power saving state of an NR DU cell.

TIMING_CARRIER_SHUTDOWN: Indicates the timing carrier shutdown state.

LNR_SMART_CARRIER_SHUTDOWN: Indicates the LTE and NR intelligent carrier shutdown state.

ALL_RF_DORMANCY: Indicates the cell dormancy state of all RF modules.

PART_RF_DORMANCY: Indicates the cell dormancy state of some of the RF modules.

POWER_SAVING_SCHEDULE: Indicates the power saving scheduling state.

RF_SHUTDOWN: Indicates the RF channel shutdown state.

DYNAMIC_SSB: Indicates the dynamic SSB state.

MULTI_RAT_SYMBOL_SHUTDOWN: Indicates the multi-RAT symbol power saving state.

LNR_BUNDLED_SCHEDULING: Indicates the LTE and NR bundled scheduling state for multi-RAT symbol power saving of an NR DU cell.

DEEP_SYMBOL_SHUTDOWN: Indicates the deep symbol power saving state.
