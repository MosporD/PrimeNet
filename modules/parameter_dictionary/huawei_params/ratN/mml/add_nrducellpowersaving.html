Add NR DU Cell Power Saving (ADD NRDUCELLPOWERSAVING)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add NR DU cell power saving configurations.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The time difference between NRDUCellPowerSaving MO instances with the same NrDuCellId and PowerSavingType must be greater than 5 minutes.
  • The time segment of an NRDUCellPowerSaving MO instance with PowerSavingType set to TIMING_CARRIER_SHUTDOWN must not overlap with the time segments of other NRDUCellPowerSaving MO instances associated with the same NrDuCellId as this MO instance.
  • If an NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING exists, an NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE must exist for the cell. In addition, the time range in the record with PowerSavingType set to LNR_BUNDLED_SCHEDULING in the NRDUCellPowerSaving MO corresponding to the cell must be within the time range in the record with PowerSavingType set to POWER_SAVING_SCHEDULE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

PowerSavingType Power Saving Type

Meaning: Indicates the power saving type of an NR DU cell.

When this parameter is set to TIMING_CARRIER_SHUTDOWN, the local cell shuts down the carrier at the preset time.

When this parameter is set to LNR_SMART_CARRIER_SHUTDOWN, the local cell performs power saving based on the load on the NR and LTE networks.

When this parameter is set to RF_SHUTDOWN, the local cell shuts down RF channels at the preset time under the specified load condition.

When this parameter is set to POWER_SAVING_SCHEDULE, the local cell performs power saving scheduling at the preset time under the specified load condition.

When this parameter is set to DYNAMIC_SSB, the local cell performs dynamic SSB power saving at the preset time under specified load and user number conditions.

When this parameter is set to LNR_BUNDLED_SCHEDULING, the local cell performs LTE and NR bundled scheduling at the preset time under the specified load condition.

GUI Value Range: TIMING_CARRIER_SHUTDOWN(Scheduled Carrier Shutdown), LNR_SMART_CARRIER_SHUTDOWN(LNR Intelligent Carrier Shutdown), RF_SHUTDOWN(RF Channel Power Saving), POWER_SAVING_SCHEDULE(Power Saving Scheduling), DYNAMIC_SSB(Dynamic SSB), LNR_BUNDLED_SCHEDULING(LTE and NR Bundled Scheduling)

Unit: None

Actual Value Range: TIMING_CARRIER_SHUTDOWN, LNR_SMART_CARRIER_SHUTDOWN, RF_SHUTDOWN, POWER_SAVING_SCHEDULE, DYNAMIC_SSB, LNR_BUNDLED_SCHEDULING

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The time difference between NRDUCellPowerSaving MO instances with the same NrDuCellId and PowerSavingType must be greater than 5 minutes.
  • The time segment of an NRDUCellPowerSaving MO instance with PowerSavingType set to TIMING_CARRIER_SHUTDOWN must not overlap with the time segments of other NRDUCellPowerSaving MO instances associated with the same NrDuCellId as this MO instance.
  • If an NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING exists, an NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE must exist for the cell. In addition, the time range in the record with PowerSavingType set to LNR_BUNDLED_SCHEDULING in the NRDUCellPowerSaving MO corresponding to the cell must be within the time range in the record with PowerSavingType set to POWER_SAVING_SCHEDULE.
  • The value of DlPrbThld in the NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING must be less than or equal to the value of DlPrbThld in the NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to TIMING_CARRIER_SHUTDOWN, service drops occur at the preset carrier shutdown time. If this parameter is set to LNR_SMART_CARRIER_SHUTDOWN, the user-perceived rate decreases when the cell enters the LTE and NR intelligent carrier shutdown mode. If this parameter is set to RF_SHUTDOWN, the user-perceived rate decreases when the cell enters the RF channel shutdown mode. If this parameter is set to POWER_SAVING_SCHEDULE, the UE delay increases when the cell enters the power saving scheduling mode. In addition, common control messages in the cell may cause interference to the PDSCH of neighboring cells. It is recommended that the SSB_INTRF_AVOID_SW option also be selected. If this parameter is set to LNR_BUNDLED_SCHEDULING, the UE delay increases when the cell enters the LTE and NR bundled scheduling mode. If this parameter is set to DYNAMIC_SSB, interference may be caused due to unaligned SSBs between the local cell and neighboring cells when the local cell enters the dynamic SSB mode. It is recommended that the SSB_INTRF_AVOID_SW option also be selected.

Applicable Mode: N
UserNumThld UE Number Threshold

Meaning: Indicates the UE number threshold of power saving for an NR DU cell.

The gNodeB automatically migrates services of the local cell to neighboring E-UTRAN cells, shuts down carrier of the local cell, and enables the cell to enter the LTE and NR intelligent carrier shutdown mode when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to LNR_SMART_CARRIER_SHUTDOWN, the downlink PRB usage of the cell is less than or equal to the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld) within the configured power saving period, and the number of RRC_CONNECTED UEs in the local cell is less than or equal to the value of UserNumThld.

The gNodeB automatically adjusts the RMSI of the local cell when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to POWER_SAVING_SCHEDULE, the downlink PRB usage of the cell is less than or equal to the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld) within the configured power saving period, and the number of RRC_CONNECTED UEs in the local cell is less than or equal to the value of UserNumThld.

Dynamic SSB takes effect when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to DYNAMIC_SSB, and within the configured power saving period, the number of RRC_CONNECTED UEs in the local cell is less than or equal to the value of UserNumThld and the downlink PRB usage of the cell is less than or equal to the downlink PRB threshold.

GUI Value Range: 0~5000

Unit: None

Actual Value Range: 0~5000

MML Default Value: 20

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the value of NRDUCellPowerSaving.PowerSavingType is LNR_SMART_CARRIER_SHUTDOWN, a larger value of this parameter results in a higher probability of triggering LTE and NR intelligent carrier shutdown. A smaller value of this parameter results in a lower probability.

When the value of NRDUCellPowerSaving.PowerSavingType is DYNAMIC_SSB, a larger value of this parameter results in a higher probability of triggering dynamic SSB. A smaller value of this parameter results in a lower probability.

When the value of NRDUCellPowerSaving.PowerSavingType is POWER_SAVING_SCHEDULE, a larger value of this parameter results in a higher probability of triggering common period adjustment after the cell enters the power saving scheduling state. A smaller value of this parameter results in a lower probability of triggering common period adjustment after the cell enters the power saving scheduling state.

Applicable Mode: N
DlPrbThld Downlink PRB Threshold

Meaning: Indicates the downlink PRB usage threshold of power saving for an NR DU cell.

The gNodeB automatically migrates services of the local cell to neighboring E-UTRAN cells, shuts down carrier of the local cell, and enabled the cell to enter the LTE and NR intelligent carrier shutdown mode when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to LNR_SMART_CARRIER_SHUTDOWN, and within the configured power saving period, the number of UEs and neighboring E-UTRAN cell load meet the corresponding conditions and the downlink PRB usage of the local cell is less than or equal to the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld).

The gNodeB automatically enables the local cell to enter the RF channel shutdown mode when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to RF_SHUTDOWN, and within the configured power saving period, the downlink PRB usage of the cell is less than or equal to the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld).

The gNodeB automatically enables the local cell to enter the power saving scheduling mode when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to POWER_SAVING_SCHEDULE, and within the configured power saving period, the downlink PRB usage of the cell is less than or equal to the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld).

LTE and NR bundled scheduling for multi-RAT coordinated symbol power saving takes effect when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to LNR_BUNDLED_SCHEDULING, and within the configured power saving period, the PRB usage of the cell is less than or equal to this parameter value.

Dynamic SSB takes effect when the following conditions are met: NRDUCellPowerSaving.PowerSavingType is set to DYNAMIC_SSB, and within the configured power saving period, the number of RRC_CONNECTED UEs in the local cell is less than or equal to the UE number threshold and the downlink PRB usage of the cell is less than or equal to this parameter value.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

When the value of PowerSavingType is LNR_SMART_CARRIER_SHUTDOWN: 5

When the value of PowerSavingType is POWER_SAVING_SCHEDULE: 10

When the value of PowerSavingType is LNR_BUNDLED_SCHEDULING: 10

When the value of PowerSavingType is DYNAMIC_SSB: 10

When the value of PowerSavingType is RF_SHUTDOWN: 10

Parameter Relationship:

-Configuration constraints:

  • The value of DlPrbThld in the NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING must be less than or equal to the value of DlPrbThld in the NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When NRDUCellPowerSaving.PowerSavingType is set to LNR_SMART_CARRIER_SHUTDOWN, a larger value of this parameter results in a higher probability of triggering LTE and NR intelligent carrier shutdown. A smaller value of this parameter results in a lower probability.

When NRDUCellPowerSaving.PowerSavingType is set to RF_SHUTDOWN, a larger value of this parameter results in a higher probability of triggering channel shutdown. A smaller value of this parameter results in a lower probability.

When NRDUCellPowerSaving.PowerSavingType is set to POWER_SAVING_SCHEDULE, a larger value of this parameter results in a higher probability of triggering power saving scheduling. A smaller value of this parameter results in a lower probability.

When NRDUCellPowerSaving.PowerSavingType is set to LNR_BUNDLED_SCHEDULING, a larger value of this parameter results in a higher probability of triggering bundled scheduling. A smaller value of this parameter results in a lower probability.

When NRDUCellPowerSaving.PowerSavingType is set to DYNAMIC_SSB, a larger value of this parameter results in a higher probability of triggering dynamic SSB. A smaller value of this parameter results in a lower probability.

Applicable Mode: N
DlPrbOffset Downlink PRB Offset

Meaning: Indicates the downlink PRB usage offset of power saving for an NR DU cell.

The gNodeB automatically enables the local cell to exit the RF channel shutdown mode when the following conditions are met: The value of NRDUCellPowerSaving.PowerSavingType is RF_SHUTDOWN, and within the configured power saving period, the cell already enters the RF channel shutdown state and the downlink PRB usage is greater than the sum of the downlink PRB threshold (specified by NRDUCellPowerSaving.DlPrbThld) and the downlink PRB offset (specified by NRDUCellPowerSaving.DlPrbOffset). Under the same load conditions, the PRB usage increases after RF channels are shut down. It is recommended that this parameter be set to an appropriate value to prevent ping-pong RF channel shutdown.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 15

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

When the value of PowerSavingType is RF_SHUTDOWN: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the value of NRDUCellPowerSaving.PowerSavingType parameter is RF_SHUTDOWN, a larger value of this parameter results in a lower probability of exiting RF channel shutdown and a smaller value of this parameter results in a higher probability.

Applicable Mode: N-TDD

Example

To add the power-saving configurations of an NR DU cell with NR DU Cell ID set to 116,
Power Saving Policy Index set to 2, Start Time set to 16:55:57, Stop Time set to 18:51:50,
and Shutdown Type set to LNR_SMART_CARRIER_SHUTDOWN, run the following command:
ADD NRDUCELLPOWERSAVING: NrDuCellId=116, PowerSavingPolicyIndex=2, StartTime=16&55&57, StopTime=18&51&50,
PowerSavingType=LNR_SMART_CARRIER_SHUTDOWN;
