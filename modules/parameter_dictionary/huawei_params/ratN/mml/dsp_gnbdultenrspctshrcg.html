Display LTE and NR Spectrum Sharing Cell Set Configuration (DSP GNBDULTENRSPCTSHRCG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the dynamic configurations about an LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
NrSpctShrCellGrpId NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • LteSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.
  • NrSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To query the dynamic configuration of an LTE and NR spectrum sharing cell set with NR Spectrum Sharing Cell Group ID set to 11, run the following command:
DSP GNBDULTENRSPCTSHRCG: NrSpctShrCellGrpId=11;
The result is shown as follows:

Output Description

Field Description

NR Spectrum Sharing Cell Group ID

Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.

LTE Spectrum Sharing Cell Group ID

Indicates the ID of an LTE spectrum sharing cell group, which uniquely identifies the LTE spectrum sharing cell group within a gNodeB.

gNodeB ID

Indicates the gNodeB ID of the base station where the NR spectrum sharing cell set is located.

Peer eNodeB ID

Indicates the ID of the eNodeB for the LTE and NR spectrum sharing cell set on the LTE side corresponding to the NR spectrum sharing cell set on the NR side.

Peer LTE and NR Spectrum Sharing Cell Group ID

Indicates the ID of the LTE and NR spectrum sharing cell set on the LTE side corresponding to the NR spectrum sharing cell set on the NR side.

Peer PLMN ID

Indicates the PLMN ID of the primary operator of the eNodeB for the LTE and NR spectrum sharing cell set on the LTE side corresponding to the NR spectrum sharing cell set on the NR side.

PLMN ID

Indicates the PLMN ID of the primary operator of the gNodeB where the NR spectrum sharing cell set is located.

Spectrum Sharing Status

Indicates the spectrum sharing status of the LTE and NR spectrum sharing cell group on the LTE side and the corresponding NR spectrum sharing cell group on the NR side. For LTE cells or NR cells in the spectrum sharing cell group, the spectrum sharing status from the time when the spectrum is pre-shared to the time when the spectrum is successfully shared is WAITING.

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

NR DU Cell Available RB Count

Indicates the number of available RBs for an NR DU cell when LTE TDD and NR spectrum sharing is enabled. The value NULL indicates that the parameter query is not supported. This parameter applies only to low-frequency TDD cells.

Uplink Filtered PRB Usage Rate(%)

Indicates the filtering value of the uplink PRB usage of an NR cell in LTE TDD and NR spectrum sharing scenarios. This parameter applies only to low-frequency TDD cells.

Downlink Filtered PRB Usage Rate(%)

Indicates the filtering value of the downlink PRB usage of an NR cell in LTE TDD and NR spectrum sharing scenarios. This parameter applies only to low-frequency TDD cells.
