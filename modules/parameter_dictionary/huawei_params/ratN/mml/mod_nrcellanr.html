Modify NR Cell ANR (MOD NRCELLANR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the ANR configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AnrModeSwitch ANR Mode Switch

Meaning: Indicates the ANR mode switches.

NR_NR_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for intra-NR ANR. When the controlled mode is disabled, the gNodeB automatically configures neighboring NR cells. When the controlled mode is enabled, the gNodeB reports neighboring NR cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_NR_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring NR cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for intra-NR ANR.

NR_EUTRAN_ANR_CTRL_MODE_SW: Indicates whether to enable the controlled mode for ANR with E-UTRAN. When the controlled mode is disabled, the gNodeB automatically configures neighboring E-UTRAN cells. When the controlled mode is enabled, the gNodeB reports neighboring E-UTRAN cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation on the MAE.

NR_EUTRAN_ANR_CTRL_MODE_HO_SW: Indicates whether to allow handovers to unconfirmed neighboring E-UTRAN cells (with which neighbor relationships are reported in optimization suggestions but are not confirmed yet) in the controlled mode for ANR with E-UTRAN.

EUTRAN_NCELL_PLMN_RR_MODE_SW: Indicates whether neighboring E-UTRAN cells support the PLMN round robin mode in RAN sharing scenarios.

GUI Value Range: NR_NR_ANR_CTRL_MODE_SW(Intra-NR ANR Switch in Controlled Mode), NR_NR_ANR_CTRL_MODE_HO_SW(HO to Unconfirmed NR NCell Allowed), NR_EUTRAN_ANR_CTRL_MODE_SW(NR-to-EUTRAN ANR Sw in Controlled Mode), NR_EUTRAN_ANR_CTRL_MODE_HO_SW(HO to Unconfirmed E-UTRAN NCell Allowed), EUTRAN_NCELL_PLMN_RR_MODE_SW(E-UTRAN Neighboring Cell PLMN RR Switch)

Unit: None

Actual Value Range: NR_NR_ANR_CTRL_MODE_SW, NR_NR_ANR_CTRL_MODE_HO_SW, NR_EUTRAN_ANR_CTRL_MODE_SW, NR_EUTRAN_ANR_CTRL_MODE_HO_SW, EUTRAN_NCELL_PLMN_RR_MODE_SW

MML Default Value: None

Recommended Value: NR_NR_ANR_CTRL_MODE_SW:Off, NR_NR_ANR_CTRL_MODE_HO_SW:Off, NR_EUTRAN_ANR_CTRL_MODE_SW:Off, NR_EUTRAN_ANR_CTRL_MODE_HO_SW:Off, EUTRAN_NCELL_PLMN_RR_MODE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NR_NR_ANR_CTRL_MODE_SW: When this option is selected, the gNodeB reports neighboring NR cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation. When this option is deselected, the gNodeB can automatically configure neighboring NR cells, with no reports sent to the MAE.

NR_NR_ANR_CTRL_MODE_HO_SW: When this option is selected, handovers can be initiated to the neighboring NR cells to be confirmed and added in controlled mode. When this option is deselected, handovers cannot be initiated to the neighboring NR cells to be confirmed and added in controlled mode.

NR_EUTRAN_ANR_CTRL_MODE_SW: When this option is selected, the gNodeB reports neighboring E-UTRAN cell configuration optimization suggestions to the MAE and the optimization is subject to manual confirmation. When this option is deselected, the gNodeB can automatically configure neighboring E-UTRAN cells, with no reports sent to the MAE.

NR_EUTRAN_ANR_CTRL_MODE_HO_SW: When this option is selected, handovers can be initiated to the neighboring E-UTRAN cells to be confirmed and added in controlled mode. When this option is deselected, handovers cannot be initiated to the neighboring E-UTRAN cells to be confirmed and added in controlled mode.

EUTRAN_NCELL_PLMN_RR_MODE_SW: When this option is selected, neighboring E-UTRAN cells are considered as cells that support MOCN with round-robin of the PLMN ID list. The primary PLMN ID may not be listed at the top of the PLMN ID list, and you need to use the MAE to query the actual primary PLMN ID. When this option is deselected, neighboring E-UTRAN cells are not considered as cells that support MOCN with round-robin of PLMN IDs.

Applicable Mode: N
OverDistantNCellThld Over Distant Neighboring Cell Threshold

Meaning: Indicates the threshold for evaluating an over-distant coverage neighboring cell.

If this parameter is set to a value other than 0, an over-distant neighboring cell is detected based on the distance. If the distance between a serving cell and a neighboring cell is greater than this threshold, the neighboring cell is an over-distant neighboring cell.

If this parameter is set to 0, the gNodeB does not evaluate whether a neighboring E-UTRAN cell is an over-distant neighboring cell. Instead, the gNodeB evaluates an over-distant neighboring NR cell based on the cell radius. That is, if the distance between a serving cell and a neighboring NR cell is greater than the sum of radii of both cells, this neighboring cell is an over-distant neighboring cell.

GUI Value Range: 0~100000

Unit: m

Actual Value Range: 0~100000

MML Default Value: None

Recommended Value: 5000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a smaller distance from the serving cell to an over-distant neighboring cell. A larger value of this parameter results in the opposite effect.

Applicable Mode: N

Example

To modify the ANR configuration of an NR cell, with the parameters as follows: NR Cell ID:7, NR_NR_ANR_CTRL_MODE_SW:ON, NR_NR_ANR_CTRL_MODE_HO_SW:OFF, NR_EUTRAN_ANR_CTRL_MODE_SW:OFF, NR_EUTRAN_ANR_CTRL_MODE_HO_SW:OFF, EUTRAN_NCELL_PLMN_RR_MODE_SW:OFF, OverDistantNCellThld:1, run the following command:
MOD NRCELLANR: NrCellId=7, AnrModeSwitch=NR_NR_ANR_CTRL_MODE_SW-1&NR_NR_ANR_CTRL_MODE_HO_SW-0&NR_EUTRAN_ANR_CTRL_MODE_SW-0&NR_EUTRAN_ANR_CTRL_MODE_HO_SW-0&EUTRAN_NCELL_PLMN_RR_MODE_SW-0, OverDistantNCellThld=1;
