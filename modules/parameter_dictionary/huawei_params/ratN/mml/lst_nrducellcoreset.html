List NR DU Cell CORESET (LST NRDUCELLCORESET)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the settings of CORESET parameters for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the CORESET configuration of an NR DU cell with NR DU Cell ID set to 88, run the following command:
LST NRDUCELLCORESET: NrDuCellId=88;
The result is shown as follows:
+++    0        2019-12-20 15:45:12
O&M    #2685403170
%%LST NRDUCELLCORESET: NrDuCellId=88;%%
RETCODE = 0  Operation succeeded.

List NR DU Cell CORESET
-----------------------
                    NR DU Cell ID  =  88
Common Control Resource RB Number  =  48 RBs x 1 Symbol
(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Common Control Resource RB Number

Indicates the number of RBs for common control resources of a cell. By default, the common control resources of a cell occupy the first symbol in each of such RBs. The frequency domain position of the common PDCCH changes according to the SSB position. This parameter is invalid when SpectrumCloudSwitch(NRDUCellAlgoSwitch) is set to LTE_NR_FDD_SPCT_SHR_SW.
