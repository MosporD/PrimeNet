List NR Cell Relationship (LST NRCELLRELATION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list relationships with an NR cell.

Note

None.

LST NRCELLRELATION: NrCellId=5;

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

Mobile Country Code

Indicates the MCC of the operator who owns a neighboring NR cell. The MCC, together with the MNC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.

Mobile Network Code

Indicates the MNC of the operator who owns a neighboring NR cell. The MNC, together with the MCC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.

gNodeB ID

Indicates the gNodeB ID of a neighboring NR cell. It uniquely identifies a gNodeB within a PLMN.

Cell ID

Indicates the cell ID of a neighboring NR cell. It uniquely identifies an NR cell within a gNodeB.

Cell Individual Offset(dB)

Indicates the cell individual offset between an NR DU cell and a neighboring cell. It affects the probability of triggering measurement reports.

Blind SCell Configuration Flag

Indicates whether a neighboring NR cell can be blindly configured as an SCell. The neighboring NR cell can be configured as an SCell or PSCell in a blind manner only if this parameter is set to TRUE.

No Handover Flag

Indicates whether to allow UE handover based on a neighbor relationship.

No Removal Flag

Indicates whether removal of a neighbor relationship by ANR is permitted.

Neighboring Cell Reselection Offset(dB)

Indicates the cell reselection offset of an NR cell relative to a neighboring cell. This parameter is used to control the probability of cell reselection. If this parameter is set to a value other than 0 dB, this parameter is delivered in the q-OffsetCell IE of SIB3 and SIB4.

For details about this parameter, see 3GPP TS 38.304.

Neighboring Cell Class Label

Indicates whether the neighbor relationship is formal or extended.
