Add gNodeB QCI Bearer (ADD GNBQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add gNodeB-level QCI-specific bearer configurations. The configurations can be added for bearers based on their QCIs.

Note

None.

Parameters

ID Name Description
Qci QoS Class Identifier

Meaning: Indicates the QoS class identifier (QCI).

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AveragingWindowDur Averaging Window Duration

Meaning: Indicates the average window size. This parameter is valid only for GBR bearers. For details about this parameter, see 3GPP TS 23.501.

GUI Value Range: 0~4095

Unit: ms

Actual Value Range: 0~4095

MML Default Value: 2000

Recommended Value: This parameter can be set by the gNodeB by default as follows:

QCIs 1 to 4, 65, 66, and 75: 2000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to higher accuracy of GFBR and MFBR rate control. A larger value of this parameter leads to lower accuracy of GFBR and MFBR rate control.

Applicable Mode: N

Meaning: Indicates the service type of the bearer of the QCI. This parameter is set based on the operator's policy. The value OTHER indicates that other services are carried. The value INTERNET indicates that Internet services are carried. The value VIDEO indicates that video services are carried.

GUI Value Range: OTHER(Other Services), INTERNET(Internet Services), VIDEO(Video Services)

CounterObjSubscriptionInd Counter Object Subscription Indicator

Meaning: Indicates whether to subscribe to QCI-related performance counter objects of NSA UEs. Performance counter objects can be subscribed to only when this parameter is set to YES.

GUI Value Range: NO(Not Subscribe), YES(Subscribe)

Unit: None

Actual Value Range: NO, YES

MML Default Value: YES(Subscribe)

Recommended Value: This parameter can be set by the system by default as follows: YES(Subscribe) for QCI 9

NO(Not Subscribe) for other QCIs

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to YES, the number of subscribed QCI-related counter objects increases and the CPU and memory consumed by counter statistics processing increase. To avoid excessive resource consumption, the total number of subscribed 5QI-related counter objects in SA networking and QCI-related counter objects in NSA networking must not exceed 20. If this parameter is set to NO, the number of subscribed QCI-related counter objects decreases, and the CPU and memory consumed by counter statistics processing decrease.

Applicable Mode: N

Example

To add a gNodeB QCI bearer with QoS Class Identifier set to 10, run the following command:
ADD GNBQCIBEARER: Qci=10;
