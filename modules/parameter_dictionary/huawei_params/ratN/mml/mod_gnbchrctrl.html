Modify gNodeB CHR Control (MOD GNBCHRCTRL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the sampling output rate of internal CHRs.

Note

None.

Parameters

ID Name Description
DetailCauseVal Detailed Cause Value

Meaning: Indicates the detailed exception cause value for internal CHR recording. The value 0xFFFFFFFFFFFF indicates that the sampling output setting applies to all the exception cause values. In other cases, the sampling output setting applies only to the given exception cause value.

GUI Value Range: 0~281474976710655

Unit: None

Actual Value Range: 0~281474976710655

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SamplingInterval CHR Sampling Interval

Meaning: Indicates the frequency by which internal CHR data is generated.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: 25

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the CHR control configuration of the gNodeB with the parameters as follows: Detailed Cause Value: 4294967295, CHR Sampling Interval: 25, run the following command:
MOD GNBCHRCTRL: DetailCauseVal=4294967295, SamplingInterval=25;
