List NR DU Cell Coverage (LST NRDUCELLCOVERAGE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query an NR DU cell coverage item.

Note

None.

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB. It is used with the NrDuCellCoverageId parameter to uniquely identify the coverage area of the NR DU cell.

NR DU Cell Coverage ID

Indicates the ID of a coverage area of an NR DU cell, which is used with the NrDuCellTrpId parameter to uniquely identify the coverage area of the NR DU cell.

Sector Equipment ID

Indicates the ID of a set of sector equipment used by an NR DU cell coverage area, which uniquely identifies the set of sector equipment within a gNodeB. This parameter must be set by network planning engineers based on site requirements.

Max Transmit Power(0.1dBm)

Indicates the maximum transmit power of a single transmit channel for the carrier in the coverage area of an NR DU cell. This parameter applies only to low-frequency LampSite cells. If this parameter is set to a value in the range of 0 to 600, this parameter specifies the maximum transmit power of the carrier of the low-frequency LampSite RF module. If this parameter is set to 65535, the maximum transmit power of the carrier of the RF module is determined by the MaxTransmitPower parameter corresponding to the NR DU cell TRP.

Antenna Port Mapping

Indicates the mapping between antenna ports and RRU channels.

For TDD 4T cells and FDD 4T cells:

For example, value 4T_0312 indicates that ports 0, 3, 1, and 2 are mapped to RRU channels A, B, C, and D, respectively.

For TDD 4T cells, the RRU channels corresponding to antenna ports 0 and 2 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 1 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For FDD 4T cells, the RRU channels corresponding to antenna ports 0 and 1 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 2 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For TDD 8T cells:

For example, value 8T_01234567 indicates that ports 0 to 7 are mapped to RRU channels A to H, respectively.

The TDD 8T RRU ports must be correctly connected to the TDD 8T antenna ports. The default value of this parameter for TDD 8T RRUs is 8T_32107654.

When Huawei 8T8R RRUs are used, Huawei 8T8R antennas or antennas that comply with the Next Generation Mobile Network (NGMN) standard are recommended. If antennas from other vendors or antennas that do not comply with the NGMN standard are used, polarization sequence mismatch may occur, affecting the cell coverage.
