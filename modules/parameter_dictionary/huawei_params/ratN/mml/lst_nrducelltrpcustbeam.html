List NR DU Cell Customized TRP Beam (LST NRDUCELLTRPCUSTBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list Azimuth and Tilt configurations of a corresponding beam ID for a TRP in an NR DU cell in customized broadcast beam scenarios.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
BeamId Beam Id

Meaning: Indicates the beam ID of the customized and scenario-based beam. This parameter applies only to the TDD 64T low-frequency modules.

GUI Value Range: BEAM_0(SSB Beam 0), BEAM_1(SSB Beam 1), BEAM_2(SSB Beam 2), BEAM_3(SSB Beam 3), BEAM_4(SSB Beam 4), BEAM_5(SSB Beam 5), BEAM_6(SSB Beam 6), BEAM_7(SSB Beam 7)

Unit: None

Actual Value Range: BEAM_0, BEAM_1, BEAM_2, BEAM_3, BEAM_4, BEAM_5, BEAM_6, BEAM_7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1

Example

To query the configuration of customized beams with NR DU Cell TRP ID set to 88 and Beam Id set to BEAM_0, run the following command:
LST NRDUCELLTRPCUSTBEAM: NrDuCellTrpId=88, BeamId=BEAM_0;
The result is shown as follows:

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

Beam Id

Indicates the beam ID of the customized and scenario-based beam. This parameter applies only to the TDD 64T low-frequency modules.

Tilt(degree)

Indicates the configured downtilt angle mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different tilt angle ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Tilt is -3° to 15°.

Azimuth(degree)

Indicates the horizontal azimuth corresponding to the beamforming weight for a cell. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different azimuth ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Azimuth is -47° to 47°.
