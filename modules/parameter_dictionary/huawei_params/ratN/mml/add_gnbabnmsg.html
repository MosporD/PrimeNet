Add gNodeB Debugging Message (ADD GNBABNMSG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB debugging message. The gNodeB matches the received or sent message with the debugging message, and then discards or modifies the message according to the specified matching items such as matching point offset, matching length, and matching content.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Running this command will interrupt ongoing services. This command must be executed under the guidance of Huawei technical support.

  • If the values of UE Information Index, Message Protocol Type, Message Type, and Message Operate Type in different gNBAbnMsg MOs are the same, the instance with the smallest value of Rule Index takes effect.

  • After the version is upgraded, the existing gNBAbnMsg settings are not inherited. After the upgrade, if the problem resolved by gNBAbnMsg before the upgrade persists, reconfigure the gNBAbnMsg MO for the new version.

Example

To add a gNodeB debugging message with Rule Index set to 1, Message Protocol Type set to X2AP, Message Type set to 11, Message Operate Type set to DISCARD, Message Match Rule List set to 23, and UE Information Index set to 1, run the following command:
ADD GNBABNMSG: RuleIndex=1, MsgProtocolType=X2AP, MsgType=11, MsgOpType=DISCARD, MsgMatchRuleList="23", UeInfoIndex=1;
