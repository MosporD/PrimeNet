Modify NR DU Cell PDSCH (MOD NRDUCELLPDSCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the PDSCH configuration of an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation will automatically reset NR DU Cell.

MaxMimoLayerNum Downlink Maximum MIMO Layer Number Quota

Meaning: Indicates the maximum transport layer count quota for spatial multiplexing in downlink MIMO. This parameter does not take effect for low-frequency NR DU cells with NRDUCellTrp.TxRxMode set to 1T1R, 2R, 4R, 2T2R, 2T4R, 4T4R, or 8T8R. In this case, the maximum number of layers for downlink MIMO depends on the number of transmit antennas in the cell. If this parameter is set to LAYER_DEFAULT for low-frequency NR DU cells, the maximum number of downlink MIMO layers is 4. If this parameter is set to LAYER_DEFAULT for high-frequency NR DU cells, the maximum number of downlink MIMO layers is 2. NR DU cells consume layer number licenses based on the value of this parameter.

FixedAmcStepValue Fixed AMC Step Value

Meaning: Indicates the fixed step of PDSCH outer-loop adjustment.

GUI Value Range: 0~200

Unit: None

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter leads to quick outer-loop adjustment. In this case, when the channel conditions change, the MCS can be quickly adjusted to match the channel transmission capabilities. When the channel conditions are stable, the MCS fluctuation will affect the traffic volume.

A small value of this parameter leads to slow outer-loop adjustment. In this case, when the MCS matches the channel transmission capability, the MCS is stable. However, when the channel fluctuates greatly, the MCS cannot be quickly adjusted.

DlInitRankAfterHo Downlink Initial Rank After Handover

Meaning: Indicates the initial downlink rank (number of PDSCH spatial multiplexing layers) during the period between the first SRS reporting and the first CQI reporting after the handover. If this parameter is set to RANK1, RANK2, RANK3, or RANK4, the rank value that takes effect is the GUI value or the maximum downlink MIMO capability reported by the UE, whichever is smaller. This parameter applies only to 8T8R, 32T32R, and 64T64R TDD modules.

Disuse statement: In the current version, the value range of this parameter is RANK1 to RANK8. In later versions, the value range will be RANK1 to RANK4. In the current version, if this parameter is set to a value greater than RANK4 and less than or equal to RANK8, the value can still be synchronized and delivered. However, the system automatically takes RANK1 as the effective value. Therefore, you are advised not to set this parameter to a value greater than RANK4.

This parameter is valid only when all the following conditions are met: The DL_PMI_SRS_ADAPT_SW option of the NRDUCellAlgoSwitch.AdaptiveEdgeExpEnhSwitch parameter is deselected, the cell is a low-frequency TDD cell with the TX/RX mode being 4T4R, 8T8R, 32T32R, or 64T64R, and UEs support antenna selection.

Actual Value Range: -20~20

MML Default Value: None

Recommended Value: -100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a larger value, there is a higher probability that the SINR of a UE at or near the cell center is considered low and the PMI-based weight is used.

If this parameter is set to a smaller value, there is a higher probability that the SINR of a UE at or near the cell center is considered high and the SRS-based weight is used.

Applicable Mode: N-TDD
RateMatchSwitch Rate Match Switch

Meaning: Indicates whether to enable rate matching for the PDSCH.

PDCCH_RATEMATCH_SW: If this option is selected, the NRDUCellPdcch.OccupiedRbNum parameter is set to a value greater than 0, and the value is less than the number of RBs corresponding to the cell bandwidth specified by NRDUCell.DlBandwidth, the PDSCH can use the resources on the PDCCH symbols. If this option is deselected, the PDSCH cannot use the resources on the PDCCH symbols.

SSB_RATEMATCH_SW: If this option is selected and the SSB period is less than or equal to 40 ms, the PDSCH can use more PDSCH RB resources in the SSB subframe. If this option is deselected, the number of resources available for the PDSCH does not increase.

CSIRS_RATEMATCH_SW: If this option is selected, RE resources on CSI-RS symbols can be used for PDSCH data transmission if the RE resources are not occupied by CSI-RSs. If this option is deselected, CSI-RS symbols cannot be used for PDSCH data transmission.

TRS_RATEMATCH_SW: If this option is selected, the PDSCH cannot use TRS symbols. If this option is deselected, the PDSCH can use TRS symbols. This parameter applies only to low-frequency cells.

GUI Value Range: PDCCH_RATEMATCH_SW(PDCCH Rate Match Switch), SSB_RATEMATCH_SW(SSB Rate Match Switch), CSIRS_RATEMATCH_SW(CSI-RS Rate Match Switch), TRS_RATEMATCH_SW(TRS Rate Matching Switch)

Unit: None

Actual Value Range: PDCCH_RATEMATCH_SW, SSB_RATEMATCH_SW, CSIRS_RATEMATCH_SW, TRS_RATEMATCH_SW

MML Default Value: None

Recommended Value: PDCCH_RATEMATCH_SW:Off, SSB_RATEMATCH_SW:Off, CSIRS_RATEMATCH_SW:On, TRS_RATEMATCH_SW:On

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: PDCCH_RATEMATCH_SW: When this option is selected, the number of available PDSCH REs increases, the downlink UE throughput and cell capacity increase, and the number of UEs that can be simultaneously scheduled on the PDCCH decreases. When this option is deselected, network performance is not affected.

SSB_RATEMATCH_SW: When this option is selected and the SSB period is less than or equal to 40 ms, the PDSCH can use more PDSCH RB resources in SSB subframes, increasing the downlink UE throughput and cell capacity. When this option is deselected, network performance is not affected.

CSIRS_RATEMATCH_SW: When this option is selected, the number of available PDSCH REs increases, and the downlink UE throughput and cell capacity increase. When this option is deselected, network performance is not affected.

TRS_RATEMATCH_SW: When this option is selected, the number of available PDSCH REs decreases, inter-cell interference on the PDSCH decreases, the downlink UE throughput and cell capacity decrease in isolated cells, and the downlink UE throughput and cell capacity increase in cells with contiguous coverage. When this option is deselected, network performance is not affected.

DlLinkAdaptAlgoSwitch DL Link Adaptation Algorithm Switch

Meaning: Indicates the downlink adaptation algorithm switches.

DL_MCS_TABLE_ADAPT_SW: Indicates whether to enable MCS index table adaptation. If this option is selected, the base station dynamically selects an MCS index table based on channel quality. If high-index MCSs are selected for a long time, the base station automatically selects the 256QAM MCS index table. If low-index MCSs are selected for a long time, the base station automatically selects the 64QAM MCS index table for more precise MCS selection. If this option is deselected, the MCS index table is not dynamically selected based on channel quality.

GUI Value Range: DL_MCS_TABLE_ADAPT_SW(Adaptive DL MCS Selection Switch)

Unit: None

Actual Value Range: DL_MCS_TABLE_ADAPT_SW

MML Default Value: None

Recommended Value: DL_MCS_TABLE_ADAPT_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: DL_MCS_TABLE_ADPT_SW: If this option is deselected, the MCS index table is not selected based on channel quality. Network performance is not affected. If this option is selected, the base station selects the 256QAM MCS index table when high-index MCSs are selected for a long time, raising the upper limit of spectral efficiency and significantly increasing the downlink data rates of CCUs; the base station selects the 64QAM MCS index table when low-index MCSs are selected for a long time, allowing for more precise MCS selection and increasing the downlink data rates of CEUs.

DlAdditionalDmrsPos Downlink Additional DMRS Position

Meaning: Indicates the position of the downlink additional DMRS. This parameter, the maximum symbol configuration, and UE capability determine the DMRS position in RRC messages.

If this parameter is set to NOT_CONFIG, the effective DMRS position in RRC messages is POS0, indicating that additional DMRS is not configured.

If this parameter is set to POS1, the effective DMRS position in RRC messages is POS1, indicating that the maximum number of downlink additional DMRS positions is 1.

If this parameter is set to POS2 and the reported UE capability indicates that the POS2 configuration is not supported, the effective DMRS position in RRC messages is POS1, indicating that the maximum number of downlink additional DMRS positions is 1. If the reported UE capability indicates that the POS2 configuration is supported, the effective DMRS position in RRC messages is POS2, indicating that the maximum number of downlink additional DMRS positions is 2.

If this parameter is set to POS_ADAPTIVE, the base station adaptively sets the position of the downlink additional DMRS to NOT_CONFIG or POS1.

For details, see 3GPP TS 38.331 and 3GPP TS 38.211. This parameter takes effect only for UEs that newly access the network.

GUI Value Range: NOT_CONFIG(Not Configure), POS1(Position 1), POS2(Position 2), POS_ADAPTIVE(Adaptive)

Unit: None

Actual Value Range: NOT_CONFIG, POS1, POS2, POS_ADAPTIVE

MML Default Value: None

Recommended Value: POS1(Position 1)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_CONFIG, the additional pilot overhead is minimized, and the downlink data rate of fixed-point UEs increases.

If this parameter is set to POS1, a maximum of one additional pilot symbol overhead is added. This increases the downlink data rate of low-speed UEs.

If this parameter is set to POS2, a maximum of two additional pilot symbol overheads are added. This increases the downlink data rate of high-speed UEs.

If this parameter is set to POS_ADAPTIVE, the gNodeB adaptively configures additional pilots based on the UE moving speed. This increases the downlink data rate of UEs at or near the cell center when the UE moving speed changes, but increases the number of RRC connection reconfigurations.

Applicable Mode: N

Example

To modify the PDSCH configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, Maximum MIMO Layer Number: 2 Layers, run the following command:
MOD NRDUCELLPDSCH: NrDuCellId=88, MaxMimoLayerNum=LAYER_2;
