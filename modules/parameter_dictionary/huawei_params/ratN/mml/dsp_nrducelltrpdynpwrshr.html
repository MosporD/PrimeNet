Display Dynamic Power Sharing Configuration of NR DU Cell TRP (DSP NRDUCELLTRPDYNPWRSHR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the dynamic power sharing configuration of an NR DU cell TRP.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the dynamic power sharing configurations of an NR DU cell TRP with NR DU Cell TRP ID set to 88, run the following command:
DSP NRDUCELLTRPDYNPWRSHR: NrDuCellTrpId=88;
The result is shown as follows:
+++    0        2019-11-30 18:52:44
O&M    #2685403156
%%DSP NRDUCELLTRPDYNPWRSHR: NrDuCellTrpId=88;%%
RETCODE = 0  Operation succeeded.

Display Dynamic Power Sharing Configuration of NR DU Cell TRP
-------------------------------------------------------------
                     NR DU Cell TRP ID  =  88
 LTE-NR Dyn Power Sharing Valid Status  =  Off
LTE-NR Dyn Power Sharing Invalid Cause  =  Configuration Not Supported
(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell.

LTE-NR Dyn Power Sharing Valid Status

Indicates whether dynamic power sharing between LTE and NR has been enabled. This parameter applies only to low-frequency TDD cells.

LTE-NR Dyn Power Sharing Invalid Cause

Indicates the reason why dynamic power sharing does not take effect between LTE and NR. The reasons can be CONFIG_NOT_SUPPORT(Configuration Not Supported), NRDUCELLTRP_UNAVAILABLE(NR DU Cell TRP Unavailable), DEVICE_NOT_SUPPORT(Device Not Supported), INTER_RAT_NEGOTIATION_FAILURE(Inter-RAT Negotiation Failure), CHANNEL_FAILURE(Channel Failure), or OTHERS(Others). This parameter applies only to low-frequency TDD cells.
