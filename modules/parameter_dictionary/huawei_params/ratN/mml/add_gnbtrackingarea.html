Add gNodeB Tracking Area (ADD GNBTRACKINGAREA)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a tracking area supported by the gNodeB.

Note

A maximum of 108 gNBTrackingArea MOs can be configured on a gNodeB.

Parameters

ID Name Description
TrackingAreaId Tracking Area ID

Meaning: Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This is different from the TAI configured in the TAL of the core network.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Tac Tracking Area Code

Meaning: Indicates the TAC, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. The TAC must be planned for cells in SA networking and cannot be set to an invalid value.

GUI Value Range: 0~16777215,4294967295

Unit: None

Actual Value Range: 0~16777215,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The values of Tac in gNBTrackingArea MOs must differ from each other.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a tracking area with the parameters as follows: Tracking Area ID: 0, Tracking Area Code: 1, run the following command:
ADD GNBTRACKINGAREA: TrackingAreaId=0, Tac=1;
