Add NSA DC Configuration Parameter Group for an NR Cell (ADD NRCELLNSADCCONFIGGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add an NSA DC configuration parameter group of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NsaDcConfigGroupId NSA DC Configuration Group ID

Meaning: Indicates the ID of an NSA DC configuration parameter group.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
PscellA2RsrpThldOffset PSCell A2 RSRP Thld Offset

Meaning: Indicates the offset to the RSRP threshold for event A2 that triggers the removal of the PSCell of NSA DC UEs. The summed value of this parameter and the NRCellNsaDcConfig.PscellA2RsrpThld parameter is used as the event A2 threshold for the PSCell of NSA DC UEs. If the summed value exceeds -31 dBm, the actual threshold for event A2 equals -30 dBm. If the summed value is less than -156 dBm, the actual threshold for event A2 equals -156 dBm.

GUI Value Range: -20~20

Unit: dB

Actual Value Range: -20~20

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of deleting the PSCell of NSA DC UEs. Packet loss or abnormal releases caused by asynchronization may occur at the edge of an NR cell. A larger value of this parameter results in the opposite effect. The PSCell of NSA DC UEs may be deleted in areas with good NR coverage, affecting user experience.

Applicable Mode: N
PscellA2TimeToTrig PSCell A2 Time To Trigger

Meaning: Indicates the time-to-trigger for event A2 that triggers the removal of the PSCell of NSA DC UEs. When detecting that the entering conditions for event A2 are fulfilled, UEs do not immediately send measurement reports. Instead, UEs send measurement reports only when the entering conditions are fulfilled throughout the corresponding time-to-trigger.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: 640MS(640)

Recommended Value: 640MS(640)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering event A2 and a higher probability of deleting the PSCell of NSA DC UEs. In this case, the PSCell of NSA DC UEs may be deleted in areas with good NR coverage, affecting user experience. A larger value of this parameter results in a lower probability of triggering event A2 and a lower probability of deleting the PSCell of NSA DC UEs. In this case, packet loss or abnormal releases caused by asynchronization may occur at the edge of an NR cell.

Applicable Mode: N

Example

To add an NSA DC configuration parameter group for an NR cell with NR Cell ID set to 88, NSA DC Configuration Group ID set to 2, PSCell A2 RSRP Thld Offset set to 1, and PSCell A2 Time To Trigger set to 512, run the following command:
ADD NRCELLNSADCCONFIGGRP: NrCellId=88, NsaDcConfigGroupId=2, PscellA2RsrpThldOffset=1, PscellA2TimeToTrig=512MS;
