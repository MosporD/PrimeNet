Modify NR DU Cell Coverage (MOD NRDUCELLCOVERAGE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify an NR DU cell coverage item.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB. It is used with the NrDuCellCoverageId parameter to uniquely identify the coverage area of the NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NrDuCellCoverageId NR DU Cell Coverage ID

Meaning: Indicates the ID of a coverage area of an NR DU cell, which is used with the NrDuCellTrpId parameter to uniquely identify the coverage area of the NR DU cell.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of a set of sector equipment used by an NR DU cell coverage area, which uniquely identifies the set of sector equipment within a gNodeB. This parameter must be set by network planning engineers based on site requirements.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The number of NRDUCellCoverage MO instances with the same SectorEqmId must not exceed 8.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
MaxTransmitPower Max Transmit Power

Meaning: Indicates the maximum transmit power of a single transmit channel for the carrier in the coverage area of an NR DU cell. This parameter applies only to low-frequency LampSite cells. If this parameter is set to a value in the range of 0 to 600, this parameter specifies the maximum transmit power of the carrier of the low-frequency LampSite RF module. If this parameter is set to 65535, the maximum transmit power of the carrier of the RF module is determined by the MaxTransmitPower parameter corresponding to the NR DU cell TRP.

GUI Value Range: 0~600,65535

Unit: 0.1dBm

Actual Value Range: 0~60,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this parameter is added for pRRU-level power configuration, differentiated power configurations between the LampSite built-in antenna and external antenna can be achieved. This meets the requirements for scenario-based interference control and indoor signal leakage control.

Applicable Mode: N
AntennaPortMapping Antenna Port Mapping

Meaning: Indicates the mapping between antenna ports and RRU channels.

For TDD 4T cells and FDD 4T cells:

For example, value 4T_0312 indicates that ports 0, 3, 1, and 2 are mapped to RRU channels A, B, C, and D, respectively.

For TDD 4T cells, the RRU channels corresponding to antenna ports 0 and 2 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 1 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For FDD 4T cells, the RRU channels corresponding to antenna ports 0 and 1 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 2 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For TDD 8T cells:

For example, value 8T_01234567 indicates that ports 0 to 7 are mapped to RRU channels A to H, respectively.

The TDD 8T RRU ports must be correctly connected to the TDD 8T antenna ports. The default value of this parameter for TDD 8T RRUs is 8T_32107654.

When Huawei 8T8R RRUs are used, Huawei 8T8R antennas or antennas that comply with the Next Generation Mobile Network (NGMN) standard are recommended. If antennas from other vendors or antennas that do not comply with the NGMN standard are used, polarization sequence mismatch may occur, affecting the cell coverage.

GUI Value Range: DEFAULT(Default), 4T_0213(4T_0213), 4T_0231(4T_0231), 4T_0123(4T_0123), 4T_0132(4T_0132), 4T_0312(4T_0312), 4T_0321(4T_0321), 8T_01234567(8T_01234567)

Unit: None

Actual Value Range: DEFAULT, 4T_0213, 4T_0231, 4T_0123, 4T_0132, 4T_0312, 4T_0321, 8T_01234567

MML Default Value: None

Recommended Value: TDD 4T cells: DEFAULT

FDD cells served by combined RRUs and with 4T beams: 4T_0213

FDD cells served by an integrated RRU and with 4T beams: 4T_0321

TDD 8T cells: DEFAULT

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When RRU channels and physical antennas are sequentially connected, setting this parameter to DEFAULT has no impact on network performance and setting this parameter to the recommended value increases the downlink throughput. If the polarization mode of the RRU channels specified by this parameter does not match that of physical antennas, the downlink SSB RSRP may deteriorate. As a result, the cell coverage areas shrink, some UEs in the coverage areas fail to access the network, and the downlink throughput decreases.

Applicable Mode: N

Example

To modify an NR DU cell coverage item with the parameters as follows: NR DU Cell TRP ID: 1, NR DU Cell Coverage ID: 1, Sector Equipment ID: 2, run the following command:
MOD NRDUCELLCOVERAGE: NrDuCellTrpId=1, NrDuCellCoverageId=1, SectorEqmId=2;
