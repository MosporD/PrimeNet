Modify NR DU Cell SUL (MOD NRDUCELLSUL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify an SUL carrier for an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SulNrDuCellId SUL NR DU Cell ID

Meaning: Indicates the ID of the SUL NR DU cell involved in NR uplink and downlink decoupling.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-SUL
RsrpThld RSRP Threshold

Meaning: Indicates the RSRP threshold for selecting an uplink carrier for UEs in idle mode or during SgNB addition in EN-DC scenarios. If the RSRP is greater than the threshold, a UE performs access on the normal UL carrier. If the RSRP is lower than the threshold, the UE performs access on the SUL carrier.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -110

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a larger coverage area of the non-SUL carrier in the uplink, increasing the load of the non-SUL carrier. A larger value of this parameter allows the SUL carrier to carry more load. If this parameter is set to an excessively small value, the uplink coverage area indicated by the parameter value may exceed the capability of the non-SUL carrier, resulting in an increased uplink packet loss rate and decreased throughput.

Applicable Mode: N-SUL
UlDlDecouplingAlgoSwitch UL and DL Decoupling Algorithm Switch

Meaning: Indicates the algorithm switch for the NR uplink and downlink decoupling feature.

SEC_HARMONIC_INTRF_AVOID_SW: Indicates whether to enable secondary harmonic interference avoidance.

UL_CARR_SEL_FOR_UE_EXP_SW: Indicates whether to enable user-experience-based uplink carrier selection.

SUL_CHANNEL_DECOUPLE_SW: Indicates whether to enable decoupling of channels on the SUL carrier.

INTRA_GNB_SUL_COMP_SW: Indicates whether to enable SUL CoMP.

GUI Value Range: SEC_HARMONIC_INTRF_AVOID_SW(Secondary Harmonic Avoidance Switch), UL_CARR_SEL_FOR_UE_EXP_SW(User Experience UL Carrier Selection Sw), SUL_CHANNEL_DECOUPLE_SW(SUL Channel Decoupling Switch), INTRA_GNB_SUL_COMP_SW(Intra-gNodeB SUL CoMP Switch)

Unit: None

Actual Value Range: SEC_HARMONIC_INTRF_AVOID_SW, UL_CARR_SEL_FOR_UE_EXP_SW, SUL_CHANNEL_DECOUPLE_SW, INTRA_GNB_SUL_COMP_SW

MML Default Value: None

Recommended Value: SEC_HARMONIC_INTRF_AVOID_SW:On, UL_CARR_SEL_FOR_UE_EXP_SW:On, SUL_CHANNEL_DECOUPLE_SW:On, INTRA_GNB_SUL_COMP_SW:On

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: SEC_HARMONIC_INTRF_AVOID_SW: If this option is deselected, the secondary harmonic interference avoidance algorithm does not take effect, and UEs experience secondary harmonic interference in the related band. If this option is selected, the secondary harmonic interference avoidance algorithm takes effect, and the uplink and downlink UE performance improves.

UL_CARR_SEL_FOR_UE_EXP_SW: If this option is deselected, the uplink camping frequency is selected based only on the downlink RSRP threshold. If this option is selected, the uplink camping frequency is selected for a UE in connected mode based on the optimal user experience, which improves user experience.

SUL_CHANNEL_DECOUPLE_SW: If this option is selected, the uplink data rate of SUL UEs in a cell increases. If this option is deselected, network performance is not affected.

INTRA_GNB_SUL_COMP_SW: If this option is selected, the uplink throughput of CEUs in an intra-gNodeB cell increases. If this option is deselected, network performance is not affected.

Applicable Mode: N-SUL
SrsRsrpThld SRS RSRP Threshold

Meaning: Indicates the SRS RSRP threshold for selecting an uplink carrier for UEs in connected mode. If the SRS RSRP is greater than the threshold, the UE for which UL and DL Decoupling takes effect switches from the SUL carrier to the normal uplink (NUL) carrier. If the SRS RSRP is lower than the threshold, the UE for which UL and DL Decoupling takes effect switches from the NUL carrier to the SUL carrier.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -111

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a heavier load of the SUL carrier, which has a great impact on the performance of existing UEs on the SUL carrier. A smaller value of this parameter leads to a larger coverage area of the NUL carrier in the uplink and may exceed the capability of the NUL carrier, resulting in an increased uplink packet loss rate and decreased throughput.

Applicable Mode: N-SUL
SulEstThpGainFactor Decoupling Estimate Throughput Gain Factor

Meaning: Indicates the estimated throughput threshold percentage for switchover from NUL to SUL in uplink and downlink decoupling scenarios. When UEs for which UL and DL Decoupling takes effect camp on the NUL carrier and the estimated uplink throughput of the SUL is greater than the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are handed over from the NUL carrier to the SUL carrier. If the estimated uplink throughput of the SUL is less than or equal to the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are not handed over from the NUL carrier to the SUL carrier. This parameter applies only to SUL.

GUI Value Range: 12~32

Unit: None

Actual Value Range: 1.2~3.2, step: 0.1

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of switching from the NUL carrier to the SUL carrier and lower gains after the switching. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-SUL

Example

To modify the SUL carrier for an NR DU cell with the parameters as follows: NR DU Cell ID: 0, SUL NR DU Cell ID: 1, RSRP Threshold(dB): -120, run the following command:
MOD NRDUCELLSUL: NrDuCellId=0, SulNrDuCellId=1, RsrpThld=-120;
