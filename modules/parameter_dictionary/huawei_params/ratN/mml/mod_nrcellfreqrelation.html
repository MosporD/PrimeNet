Modify NR Cell Frequency Relationship (MOD NRCELLFREQRELATION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify frequency relationship configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Assume that there is a group of NRCellFreqRelation MO instances with the same NrCellId value. If SsbDescMethod in an NRCellFreqRelation MO in this group is set to SSB_DESC_TYPE_GSCN, then the NR-ARFCN mapped to the value of SsbFreqPos must not be the same as the value of SsbFreqPos in other NRCellFreqRelation MOs in this group.
  • Similarly, if SsbDescMethod in an NRCellFreqRelation MO in this group is set to SSB_DESC_TYPE_NARFCN, then the GSCN mapped to the value of SsbFreqPos must not be the same as the value of SsbFreqPos in other NRCellFreqRelation MOs in this group.
