Remove NR Cell Operator Policy (RMV NRCELLOPPOLICY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove operator-specific policies of an NR cell.

Note

Deleting a gNodeB frequency priority group for an operator may affect cell reselection of UEs served by the operator. Therefore, the gNodeB frequency priority group must be deleted based on the operator's network plan.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD

Example

To delete an operator policy of an NR cell with NR Cell ID set to 1 and Operator ID set to 1, run the following command:
RMV NRCELLOPPOLICY: NrCellId=1, OperatorId=1;
