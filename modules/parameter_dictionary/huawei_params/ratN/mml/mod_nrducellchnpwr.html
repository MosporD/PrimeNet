Modify NR DU Cell Channel Power (MOD NRDUCELLCHNPWR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of channel power in an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
MaxPdschConvPwrOffset Maximum Converged PDSCH Power

Meaning: Indicates the maximum power offset of the PDSCH power relative to the reference power in the PDSCH power aggregation algorithm. This parameter applies only to low-frequency cells and takes effect only when the PDCCH_RATEMATCH_SW option of the NRDUCellPdsch.RateMatchSwitch parameter is deselected.

GUI Value Range: 0~15

Unit: dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher PDSCH power convergence degree and a greater gain after power convergence takes effect. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
MaxCommonDciPwrOffset Maximum Common DCI Power Offset

Meaning: Indicates the maximum offset of the power of DCI in common search space relative to the reference power after DCI power aggregation in the common search space of a cell is performed. The actual effective value may be lower than the configured value because of the constraints of the power aggregation capability of the intermediate frequency (IF) and radio frequency (RF) or the power resource constraints during scheduling.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a larger coverage area of DCI in the common search space and a higher probability of scheduling failures of other DCIs. This decreases the cell throughput. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
TrsPwrOffset TRS Power Offset

Meaning: Indicates the maximum offset of the TRS channel power relative to the reference power after TRS power aggregation of a cell is performed. The actual effective value may be lower than the configured value because of the constraints of the power aggregation capability of the intermediate frequency (IF) and radio frequency (RF) or the power resource constraints during scheduling.

GUI Value Range: 0~3

Unit: dB

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter leads to a larger coverage area of TRS but greater interference between TRSs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify the channel power configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, Maximum Converged PDSCH Power(dB): 3, run the following command:
MOD NRDUCELLCHNPWR: NrDuCellId=88, MaxPdschConvPwrOffset=3;
