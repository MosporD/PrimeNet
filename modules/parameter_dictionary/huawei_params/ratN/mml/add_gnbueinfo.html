Add gNodeB UE Information (ADD GNBUEINFO)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add UE information.

Note

If multiple gNBUeInfo MO instances match the same terminal type, the instance with the smallest value of UE Information Index takes effect.

UeInfoType UE Information Type

Meaning: Indicates the UE information type. If this parameter is set to IMEISV_TAC, the UeImeisvTac parameter must be set. If this parameter is set to IMEISV_TAC_SVN, the UeImeisvTac and UeImeisvSvn parameters must be set. If this parameter is set to UE_CAPABILITY, the UeCapbOffset, UeCapbLength, and UeCapbContent parameters must be set. If there are instances with different UeInfoIndex values but with the UeCapbOffset, UeCapbLength, and UeCapbContent parameters collectively identifying the same UE, only the instance with the smallest UeInfoIndex value takes effect. If this parameter is set to UE_FEATUREVALUE, the UeFeatureValueMask and UeFeatureValueContent parameters must be set. If this parameter is set to UE_EUTRA_CAPABILITY, characteristic parameters related to the EUTRA capability need to be configured.

UeCategory UE Category

Meaning: Indicates the UE category supported by abnormal UEs, which corresponds to the UE categories in the ue-Category, ue-Category-v1020, ue-Category-v1170, and ue-Category-v11a0 IEs in UE-EUTRA-Capability defined in 3GPP TS 36.331.

When setting this parameter, you need to combine bit values in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category defined in 3GPP specifications. Bit 0 stands for category 1, bit 1 category 2, bit 2 category 3, ..., bit 9 category 10, bit 10 category 11, and bit 11 category 12. Other bits are reserved. If a bit value is 1, UEs of the corresponding UE category are defined as abnormal UEs. For example, to define UEs of categories 4 and 6 as abnormal UEs, set this parameter to 40, which is the decimal format of the binary number 101000.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.

DlUeCategory DL UE Category

Meaning: Indicates the downlink UE categories supported by abnormal UEs, which correspond to the following fields in UE-EUTRA-Capability defined in 3GPP TS 36.331: ue-CategoryDL-r12, ue-CategoryDL-v1260, ue-CategoryDL-v1310, ue-CategoryDL-v1330, ue-CategoryDL-v1350, ue-CategoryDL-v1430, ue-CategoryDL-v1450, ue-CategoryDL-v1460, and ue-CategoryDL-v1530.

When setting this parameter, you need to combine field values indicating the UE categories in binary format and then convert the binary number into a decimal number. The binary digit combination rule is as follows: Each bit from the right to the left stands for a UE category. Bits 0 to 16 stand for categories 0 to 16, respectively. Bits 17, 18, 19, 20, 21, 22, and 23 stand for category_n17, category_m1, category 18, category 19, category 1bis, category_m2, and category 20, respectively. Bit 29 indicates category 26. Other bits are reserved. If a bit value is 1, the corresponding UE category is supported by the UEs. For example, if a UE supports both categories 19 and 16, the binary number indicating the UE capabilities is 100010000000000000000. This binary number can be converted into 1114112 in decimal format, which can be taken as the parameter value.

If this parameter is set to 0, this parameter is not used for UE match. If this parameter is set to another value, a UE matches the UE type when the parameter value is completely identical to the UE capability information.

Example

To add the gNodeB Ue Info parameter with the parameters: UE Information Index: 1, UE Information Type: UE_CAPABILITY, UE Capability Offset: 8, UE Capability Length: 8, UE Capability Content: FF, UE Type Description: Huawei,run the following command:
ADD GNBUEINFO: UeInfoIndex=1,UeInfoType=UE_CAPABILITY,UeCapbOffset=8, UeCapbLength=8, UeCapbContent="FF", UeTypeDesc="Huawei";
