Modify gNodeB X2 SON Configuration (MOD GNBX2SONCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of gNodeB X2 SON functions.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • X2SON_SETUP_SWITCH: If the state of this option is changed from ON to OFF, X2 links between LTE and NR cannot be set up automatically, and NSA DC services may fail.

  • When X2SonSecurityMode is set to CP_UP, USERPLANEHOST.IPSECSWITCH and SCTPHOST.SIGIP1SECSWITCH must be set to ENABLE. When X2SonSecurityMode is set to UP, USERPLANEHOST.IPSECSWITCH must be set to ENABLE and SCTPHOST.SIGIP1SECSWITCH must be set to DISABLE. Otherwise, X2 links may fail to be set up and NSA UEs cannot access the network.

Parameters

ID Name Description
X2SonConfigSwitch X2 SON Configuration Switch

Meaning: Indicates whether to enable X2 SON functions.

X2SON_SETUP_SWITCH: Indicates whether to enable the LTE-NR X2 self-setup function. The function is enabled only if this option is selected.

X2INIT_FAIL_DEL_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by initial self-setup faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2FAULT_SWITCH: Indicates whether to enable the function of X2 self-removal triggered by link faults. The function is enabled only if this option is selected.

X2SON_DEL_FOR_X2USAGE_SWITCH: Indicates whether to enable the function of X2 self-removal based on X2 usage. The function is enabled only if this option is selected.

GUI Value Range: X2SON_SETUP_SWITCH(X2 Self-Setup SW), X2INIT_FAIL_DEL_SWITCH(X2 Self-Rmv on Init Self-Setup Fault SW), X2SON_DEL_FOR_X2FAULT_SWITCH(X2 Self-Removal on Link Fault SW), X2SON_DEL_FOR_X2USAGE_SWITCH(X2 Usage-based Self-removal Switch)

Unit: None

Actual Value Range: X2SON_SETUP_SWITCH, X2INIT_FAIL_DEL_SWITCH, X2SON_DEL_FOR_X2FAULT_SWITCH, X2SON_DEL_FOR_X2USAGE_SWITCH

MML Default Value: None

Recommended Value: X2SON_SETUP_SWITCH:On, X2INIT_FAIL_DEL_SWITCH:Off, X2SON_DEL_FOR_X2FAULT_SWITCH:Off, X2SON_DEL_FOR_X2USAGE_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: X2INIT_FAIL_DEL_SWITCH: If this option is selected, the gNodeB automatically removes an LTE-NR X2 interface if the X2 interface encounters an initial self-setup fault. This prevents such faulty X2 interfaces from occupying the X2 specifications. Self-setup is disallowed for an automatically removed X2 interface before the corresponding X2 dynamic blacklist becomes invalid. DC is disallowed for a gNodeB and an eNodeB between which the X2 interface has been removed. If this option is deselected, the gNodeB does not automatically remove such faulty LTE-NR X2 interfaces. As a result, new X2 interfaces fail to be configured if the total number of X2 interfaces configured for a gNodeB has reached the maximum limit.

X2SON_DEL_FOR_X2FAULT_SWITCH: If this option is selected, the gNodeB automatically removes faulty LTE-NR X2 links. This prevents the faulty X2 interfaces from occupying the X2 specifications. The LTE-NR X2 removal based on X2 fault function cannot identify the fault type. If an LTE-NR X2 interface is faulty throughout a certain time, the gNodeB automatically removes the X2 interface. If this option is deselected, the gNodeB does not automatically remove faulty LTE-NR X2 interfaces. As a result, new X2 interfaces fail to be configured if the total number of X2 interfaces configured for a gNodeB has reached the maximum limit.

X2SON_DEL_FOR_X2USAGE_SWITCH: If this option is selected, the gNodeB can automatically remove X2 interfaces that are not used for many times. If this option is deselected, the gNodeB cannot automatically remove X2 interfaces based on X2 usage. As a result, new X2 interfaces cannot be configured if the total number of X2 interfaces configured for a gNodeB has reached its maximum.

Applicable Mode: N
X2SonDeleteTimerForX2Fault X2 SON Delete Timer for X2 Fault

Meaning: Indicates the length of the timer for X2 self-removal triggered by X2 faults. If an X2 link is faulty throughout the period specified by this timer, the gNodeB automatically removes the X2 link.

GUI Value Range: 1~50400

Unit: min

Actual Value Range: 1~50400

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter statistical duration, and a higher probability of meeting the conditions for X2 self-removal triggered by X2 faults and therefore a higher probability that X2 links are incorrectly removed and then automatically set up. A larger value of this parameter results in a longer statistical duration, and a lower probability of meeting the conditions for X2 self-removal triggered by X2 faults and therefore lower efficiency in removing faulty X2 links. As a result, new X2 links fail to be configured if the total number of X2 links configured for a gNodeB has reached the maximum limit.

Applicable Mode: N
X2SonSecurityMode X2 SON Security Mode

Meaning: Indicates the security mode for X2 self-setup when the local gNodeB receives the control-plane SCTP IP address, security tunnel IP address, and GTP-U IP address of the peer eNodeB at the same time during an X2 self-setup. If this parameter is set to CP_UP, security tunnels will be automatically set up for both the user plane and control plane. If this parameter is set to UP, a security tunnel will be automatically set up only for the user plane. This parameter takes effect only when an IPv4 security tunnel address is received but no IPv6 security tunnel address is received. In other scenarios, for example, only an IPv6 security tunnel address is received or both IPv4 and IPv6 security tunnel addresses are received, this parameter does not take effect.

GUI Value Range: CP_UP(Control and User Planes), UP(User Plane)

Unit: None

Actual Value Range: CP_UP, UP

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When X2SonSecurityMode is set to CP_UP, USERPLANEHOST.IPSECSWITCH and SCTPHOST.SIGIP1SECSWITCH must be set to ENABLE. When X2SonSecurityMode is set to UP, USERPLANEHOST.IPSECSWITCH must be set to ENABLE and SCTPHOST.SIGIP1SECSWITCH must be set to DISABLE. Otherwise, X2 links may fail to be set up and NSA UEs cannot access the network.

Applicable Mode: N
X2SonDeleteGnbAddCntThld X2 SON Delete gNodeB Addition Count Threshold

Meaning: Indicates the threshold of the number of secondary gNodeB additions for automatically removing an X2 interface based on X2 usage. If the measured number of successful secondary en-gNodeB additions corresponding to an X2 interface within a timer length is less than or equal to this threshold, automatic removal of this X2 interface is triggered.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in a stricter condition for automatic X2 removal based on X2 usage. X2 interfaces with low usage may be retained, and therefore new X2 interfaces fail to be added. A larger value of this parameter results in a less strict condition. X2 interfaces may be mistakenly removed and then added back, causing ping-pong removal and addition.

Applicable Mode: N

Example

To modify the configuration of gNodeB X2 SON functions with X2 SON Delete Timer for X2 Fault set to 10081, run the following command:
MOD GNBX2SONCONFIG: X2SonDeleteTimerForX2Fault=10081;
