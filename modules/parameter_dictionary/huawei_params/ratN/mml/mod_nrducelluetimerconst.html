Modify UE Timer Constant Configuration for NR DU Cell (MOD NRDUCELLUETIMERCONST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of the constants related to UE timers for NR DU cells.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
N310 Constant N310

Meaning: Indicates the maximum number of consecutive bottom-layer "out-of-sync" indications received from a PCell by a UE. For details, see 3GPP TS 38.331.

GUI Value Range: N1(1), N2(2), N3(3), N4(4), N6(6), N8(8), N10(10), N20(20)

Unit: None

Actual Value Range: N1, N2, N3, N4, N6, N8, N10, N20

MML Default Value: None

Recommended Value: N10(10)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
N311 Constant N311

Meaning: Indicates the maximum number of consecutive bottom-layer "in-sync" indications received from a PCell by a UE. For details, see 3GPP TS 38.331.

GUI Value Range: N1(1), N2(2), N3(3), N4(4), N5(5), N6(6), N8(8), N10(10)

Unit: None

Actual Value Range: N1, N2, N3, N4, N5, N6, N8, N10

MML Default Value: None

Recommended Value: N1(1)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

T304 Timer 304

Meaning: Indicates the timer value of timer 304. For details, see 3GPP TS 38.331. This timer is started for a UE when the UE receives an RRC Connection Reconfiguration message containing the reconfigurationWithSync IE. This timer is stopped when the UE completes random access to an SpCell. If the timer expires, the UE sends an SCG Failure Information NR message to inform the eNodeB of the SCG failure.

GUI Value Range: MS50(50), MS100(100), MS150(150), MS200(200), MS500(500), MS1000(1000), MS2000(2000), MS10000(10000)

Unit: ms

Actual Value Range: MS50, MS100, MS150, MS200, MS500, MS1000, MS2000, MS10000

MML Default Value: None

Recommended Value: MS2000(2000)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
T310 Timer 310

Meaning: Indicates the timer value of timer 310. For details, see 3GPP TS 38.331. This timer is started for a UE when the UE detects any fault at the physical layer of an SpCell. Before the timer expires, this timer is stopped when the UE detects that the fault is rectified, the UE initiates a connection reestablishment procedure, the UE receives an SCG Release message, or the UE receives an RRC Connection Reconfiguration message containing the reconfigurationWithSync IE. If the timer expires, the UE sends an SCG Failure Information NR message inform the eNodeB of the SCG failure.

GUI Value Range: MS0(0), MS50(50), MS100(100), MS200(200), MS500(500), MS1000(1000), MS2000(2000), MS4000(4000), MS6000(6000)

Unit: ms

Actual Value Range: MS0, MS50, MS100, MS200, MS500, MS1000, MS2000, MS4000, MS6000

MML Default Value: None

Recommended Value: MS1000(1000)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
T300 Timer 300

Meaning: Indicates the timer value of Timer 300. For details, see 3GPP TS 38.331. This timer is started when the UE sends an RRCSetupRequest message. Before the timer expires, it is stopped if the UE receives an RRCSetup or RRCReject message. After the timer expires, the UE enters the RRC_IDLE state.

GUI Value Range: MS100(100), MS200(200), MS300(300), MS400(400), MS600(600), MS1000(1000), MS1500(1500), MS2000(2000)

Unit: ms

Actual Value Range: MS100, MS200, MS300, MS400, MS600, MS1000, MS1500, MS2000

MML Default Value: None

Recommended Value: MS1000(1000)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
T301 Timer 301

Meaning: Indicates the timer value of timer 301. For details, see 3GPP TS 38.331. This timer is started when the UE sends an RRCReestablishmentRequest message. This timer is stopped if the UE receives an RRCReestablishment message, or the selected cell becomes unsuitable. For details about an unsuitable cell, see 3GPP TS 38.331. After the timer expires, the UE enters the RRC_IDLE state.

GUI Value Range: MS100(100), MS200(200), MS300(300), MS400(400), MS600(600), MS1000(1000), MS1500(1500), MS2000(2000)

Unit: ms

Actual Value Range: MS100, MS200, MS300, MS400, MS600, MS1000, MS1500, MS2000

MML Default Value: None

Recommended Value: MS200(200)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
T311 Timer 311

Meaning: Indicates the timer value of timer 311. For details, see 3GPP TS 38.331. This timer is started when the UE starts a reestablishment. The timer is stopped if the UE selects an NR or inter-RAT cell to camp on before the timer expires. After the timer expires, the UE enters the RRC_IDLE state.

GUI Value Range: MS1000(1000), MS3000(3000), MS5000(5000), MS10000(10000), MS15000(15000), MS20000(20000), MS30000(30000)

Unit: ms

Actual Value Range: MS1000, MS3000, MS5000, MS10000, MS15000, MS20000, MS30000

MML Default Value: None

Recommended Value: MS10000(10000)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the ue const timer configuration of an NR DU cell with the parameters as follows: NR DU Cell ID:77, Const N310:N1, Const N311:N3, run the following command:
MOD NRDUCELLUETIMERCONST: NrDuCellId=77, N310=N1,N311=N3;
