List gNodeB Tracking Area (LST GNBTRACKINGAREA)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of tracking areas supported by the gNodeB.

Note

None.

Parameters

ID Name Description
TrackingAreaId Tracking Area ID

Meaning: Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This is different from the TAI configured in the TAL of the core network.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of a tracking area with tracking area ID set to 0, run the following command:
LST GNBTRACKINGAREA: TrackingAreaId=0;
The result is shown as follows:
+++    0        2018-12-04 21:39:50
O&M    #2685403235

List gNodeB Tracking Area
-------------------------
  Tracking Area ID  =  0

(Number of results = 1)


---    END

Output Description

Field Description

Tracking Area ID

Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This is different from the TAI configured in the TAL of the core network.

Tracking Area Code

Indicates the TAC, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. The TAC must be planned for cells in SA networking and cannot be set to an invalid value.
