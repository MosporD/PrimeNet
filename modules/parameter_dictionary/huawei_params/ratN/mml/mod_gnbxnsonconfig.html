Modify gNodeB Xn SON Configuration (MOD GNBXNSONCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of gNodeB Xn SON functions.

Note

None.

Parameters

ID Name Description
XnSonConfigSwitch Xn SON Configuration Switch

Meaning: Indicates whether to enable Xn self-configuration.

XN_SON_SETUP_SW: Indicates whether to enable Xn self-setup. This function is enabled only when this option is selected.

XN_SON_DEL_SW: Indicates whether to enable Xn self-removal. This function is enabled only when this option is selected.

XN_SON_DYN_BLACKLIST_SW: Indicates whether to enable the dynamic blacklisting function when an initial Xn self-setup procedure fails. This function is enabled only when this option is selected.

GUI Value Range: XN_SON_SETUP_SW(Xn Self-Setup Switch), XN_SON_DEL_SW(Xn Self-Removal Switch), XN_SON_DYN_BLACKLIST_SW(Xn Dynamic Blacklist Switch)

Unit: None

Actual Value Range: XN_SON_SETUP_SW, XN_SON_DEL_SW, XN_SON_DYN_BLACKLIST_SW

MML Default Value: None

Recommended Value: XN_SON_SETUP_SW:On, XN_SON_DEL_SW:Off, XN_SON_DYN_BLACKLIST_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: XN_SON_SETUP_SW: When this option is selected, Xn interfaces can be automatically set up, which decreases the delay of Xn-based handovers. When this option is deselected, Xn interfaces cannot be automatically set up, meaning that they need to be manually set up.

XN_SON_DEL_SW: When this option is selected, faulty or low-usage Xn interfaces can be automatically removed to release Xn resources for other base stations to set up Xn interfaces. When this option is deselected, Xn interfaces cannot be automatically removed, meaning that they need to be manually removed.

XN_SON_DYN_BLACKLIST_SW: When this option is selected, the Xn interface cannot be automatically set up before the dynamic Xn blacklist related to the Xn interface with an initial self-setup fault expires. UEs can be handed over between the local and peer base stations using the Xn interface only through NG-based handovers. When this option is deselected, dynamic Xn blacklisting does not take effect. When an Xn interface is faulty, Xn interface self-setup attempts are repeatedly initiated, occupying Xn resources.

Applicable Mode: N

Example

To modify the configuration of gNodeB Xn SON functions with XN_SON_SETUP_SW selected, run the following command:
MOD GNBXNSONCONFIG: XnSonConfigSwitch=XN_SON_SETUP_SW-1;
