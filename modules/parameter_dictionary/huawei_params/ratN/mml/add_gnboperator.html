Add gNodeB Operator (ADD GNBOPERATOR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add an operator.

Note

  • If an operator is configured on multiple gNodeBs managed by the same EMS, the operator must be configured with the same operator ID on these gNodeBs. An operator is uniquely identified by the PLMN ID that is composed of the MCC and MNC.

  • A maximum of six operators can be configured on a gNodeB.

  • The mobile country code is a string of three characters, each of which must be an integer in the range of 0 to 9.

  • The mobile network code is a string of two or three characters, each of which must be an integer in the range of 0 to 9.

gNBIdLength gNodeB ID Length

Meaning: Indicates the length of the gNodeB ID for an operator. This parameter specifies the number of bits for the gNodeB ID in an NCI and uniquely identifies the NCI. For details, see 3GPP TS 38.423. The parameter value needs to be planned, and the same parameter value must be planned for all gNodeBs in the same PLMN. If this parameter is set to 255 or the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the gNBIdLength parameter in the gNodeBFunction MO is used as the gNodeB ID length for this operator. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the gNodeB ID length for a specific operator depends on the value of this parameter.

GUI Value Range: 22~32,255

Unit: None

Actual Value Range: 22~32,255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship:

-Configuration constraints:

  • In a gNBOperator, if gNBIdLength is set to a value other than 255, the value of gNBId cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBOperator MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the protocol-defined gNodeB ID of an operator. It is unique within a PLMN. If the gNBIdLength parameter in the gNBOperator MO is set to 255 for an operator or the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the parameter setting does not take effect. In this case, the value of the gNBId parameter in the gNodeBFunction MO is used as the gNodeB ID for this operator. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the parameter setting takes effect. In this case, operators use their respective gNodeB IDs over different protocol interfaces.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a gNBOperator, if gNBIdLength is set to a value other than 255, the value of gNBId cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBOperator MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UserLabel User Label

Meaning: Indicates the operator-specific user label of a gNodeB. If the gNBIdLength parameter in the gNBOperator MO is set to 255 for an operator, the parameter setting does not take effect. In this case, the user label of a gNodeB is the same for all operators, namely, the value of the UserLabel parameter in the gNodeBFunction MO is used as the user label for all operators. If this parameter is set to a value ranging from 22 to 32 and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the parameter setting takes effect. In this case, operators use their respective user labels.

Example

To add an operator with the parameters as follows: Operator ID: 0, Operator Name: 5G_huawei, Mobile Country Code: 302, Mobile Network Code: 220, Operator Type:PRIMARY_OPERATOR, NR Networking Option: SA, run the following command:
ADD GNBOPERATOR: OperatorId=0, OperatorName="5G_huawei", Mcc="302", Mnc="220", OperatorType=PRIMARY_OPERATOR, NrNetworkingOption=SA;
