Display NR Cell (DSP NRCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the dynamic information of NR cells.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the dynamic information of an NR cell with NR Cell ID set to 7, run the following command:
DSP NRCELL: NrCellId=7;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

Cell Available State

Indicates the availability state of an NR cell.

NR Cell State

Indicates the state of a local cell instance. The cell for which NR Cell State is Normal can accommodate SA or NSA services. The cell for which NR Cell State is Not Set Up does not provide any services.

NR DU Cell State

Indicates the state of a DU local cell instance. The cell for which NR DU Cell State is Normal can accommodate SA or NSA services. The cell for which NR DU Cell State is Not Set Up does not provide any services.

Cell Latest State Change Reason

Indicates the reason for the latest state change of an NR cell, which can be an activation success, a deactivation success, or a setup failure of the NR cell.

Latest Time When Cell Become Available

Indicates the latest time when an NR cell becomes available.

Latest Operation Make Cell Available

Indicates the latest operation that makes an NR cell available.

Latest Time When Cell Become Unavailable

Indicates the latest time when an NR cell becomes unavailable.

Latest Operation Make NR Cell Unavailable

Indicates the latest operation that makes an NR cell unavailable.

Cell Control Node Information

Indicates the control node information of an NR cell. If the gNodeB applies CU/DU split deployment, the value of this parameter is in the format of "VM ID&Container name", which indicates the ID of the VM where the control-plane functions of the NR cell are deployed and the name of the VM container. If the gNodeB applies CU/DU integrated deployment, the value of this parameter is in the format of "Cabinet number-Subrack number-Slot number", which indicates the cabinet number, subrack number, and slot number of the board where the control-plane functions of the NR cell are deployed.
