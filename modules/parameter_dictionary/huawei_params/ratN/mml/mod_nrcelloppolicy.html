Modify NR Cell Operator Policy (MOD NRCELLOPPOLICY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify operator-specific policies of an NR cell.

Note

Modifying a gNodeB frequency priority group for an operator may affect cell reselection of UEs served by the operator. Therefore, the gNodeB frequency priority group must be configured based on the operator's network plan.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
gNBFreqPriorityGroupId gNodeB Frequency Priority Group ID

Meaning: Indicates the ID of a frequency priority group of the gNodeB. The value 255 indicates that the frequency priority group is not configured.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
EpsFbMode EPS Fallback Mode

Meaning: Indicates the operator-level mobility policy for EPS fallback and emergency call fallback.

If this parameter is set to NOT_CONFIG, the mobility policy for EPS fallback and emergency call fallback UEs is not operator-specific. In this case, the fallback mode is determined by the NRInterRatHoParam.EpsFbMode parameter.

If this parameter is set to HANDOVER, EPS fallback and emergency call fallback UEs fall back to E-UTRAN preferentially through handovers.

If this parameter is set to REDIRECTION, EPS fallback and emergency call fallback UEs fall back to E-UTRAN preferentially through redirections.

GUI Value Range: NOT_CONFIG(Not Configured), HANDOVER(Handover), REDIRECTION(Redirection)

Unit: None

Actual Value Range: NOT_CONFIG, HANDOVER, REDIRECTION

MML Default Value: None

Recommended Value: NOT_CONFIG(Not Configure)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to HANDOVER and the corresponding operator does not support handovers from NG-RAN to E-UTRAN, the delay of EPS fallback and emergency call fallback to E-UTRAN increases.

Applicable Mode: N
VoicePolicySwitch Voice Policy Switch

Meaning: Indicates the operator-specific voice policy switches.

OPERATOR_VONR_SW: Indicates whether to enable VoNR services for an operator. VoNR services are supported by an operator of the cell only if this option is selected. It is recommended that VoNR not be enabled in high-frequency scenarios. This option takes effect only when the VONR_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected.

GUI Value Range: OPERATOR_VONR_SW(Operator-level VoNR Switch)

Unit: None

Actual Value Range: OPERATOR_VONR_SW

MML Default Value: None

Recommended Value: OPERATOR_VONR_SW:On

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterRatHoPolicySwitch Inter-RAT Handover Policy Switch

Meaning: Indicates inter-RAT handover policy switches for an operator. The switches separately determine whether to enable a specific type of handover measures.

EUTRAN_HO_SWITCH: Indicates whether NG-RAN can hand over UEs to E-UTRAN. NG-RAN can hand over UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_HO_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

EUTRAN_REDIRECT_SWITCH: Indicates whether NG-RAN can redirect UEs to E-UTRAN. NG-RAN can redirect UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_REDIRECT_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

VOICE_BLIND_MODE_SWITCH: Indicates whether NG-RAN can perform EPS fallback and emergency call fallback in a blind mode. NG-RAN can perform EPS fallback and emergency call fallback in a blind mode only if this option is selected. In regard to the blind mode supported in the current version, only blind redirection is supported. This option takes effect only when the VOICE_BLIND_MODE_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

GUI Value Range: EUTRAN_HO_SWITCH(E-UTRAN Handover Switch), EUTRAN_REDIRECT_SWITCH(E-UTRAN Redirection Switch), VOICE_BLIND_MODE_SWITCH(Voice Blind Mode Switch)

Unit: None

Actual Value Range: EUTRAN_HO_SWITCH, EUTRAN_REDIRECT_SWITCH, VOICE_BLIND_MODE_SWITCH

MML Default Value: None

Recommended Value: EUTRAN_HO_SWITCH:On, EUTRAN_REDIRECT_SWITCH:On, VOICE_BLIND_MODE_SWITCH:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: EUTRAN_HO_SWITCH: None

EUTRAN_REDIRECT_SWITCH: None

VOICE_BLIND_MODE_SWITCH: If this option is selected, NG-RAN can perform EPS fallback and emergency call fallback in a blind mode, reducing the fallback delay. If this option is deselected, the fallback delay is increased.

Applicable Mode: N

Example

To modify an operator policy of an NR cell with NR Cell ID set to 1, Operator ID set to 1, and gNodeB Frequency Priority Group ID set to 2, EPS Fallback Mode set to HANDOVER, EUTRAN_HO_SWITCH set to On, run the following command:
MOD NRCELLOPPOLICY: NrCellId=1, OperatorId=1, gNBFreqPriorityGroupId=2, EpsFbMode=HANDOVER, InterRatHoPolicySwitch=EUTRAN_HO_SWITCH-1;
