List UE Compatibility Control Parameter Configuration for gNodeB (LST GNBUECOMPATIBLECTRL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list UE compatibility control parameter configurations.

Note

None.

Parameters

ID Name Description
UeInfoIndex UE Information Index

Meaning: Indicates the UE index.

GUI Value Range: 1~128

Unit: None

Actual Value Range: 1~128

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list UE compatibility control parameter configurations of the gNodeB, run the following command:
LST GNBUECOMPATIBLECTRL:;
The result is shown as follows:
+++    0        2020-07-16 14:51:12
O&M    #2685403140
%%LST GNBUECOMPATIBLECTRL:;%%
RETCODE = 0  Operation succeeded.

List UE Compatibility Control Parameter Configuration for gNodeB
----------------------------------------------------------------
     UE Information Index  =  1
OSS OAM Compatible Switch  =  Intra-Frequency MR Blacklist Switch:On
                           =  Inter-Frequency MR Blacklist Switch:On
                           =  Inter-RAT MR Blacklist Switch:On
(Number of results = 1)


---    END

Output Description

Field Description

UE Information Index

Indicates the UE index.

OSS OAM Compatible Switch

Indicates the OSS O&M blacklist switches.

OSS_INTRA_FREQ_MR_SWITCH: Indicates whether to disable periodic intra-frequency measurement of the strongest cells triggered by OSS subscription tasks for specified UEs. If this option is selected, periodic intra-frequency measurement of the strongest cells triggered by OSS subscription tasks is disabled for abnormal UEs. If this option is deselected, the gNodeB does not perform any processing.

OSS_INTER_FREQ_MR_SWITCH: Indicates whether to disable periodic inter-frequency measurement of the strongest cells triggered by OSS subscription tasks for specified UEs. If this option is selected, periodic inter-frequency measurement of the strongest cells triggered by OSS subscription tasks is disabled for abnormal UEs. If this option is deselected, the gNodeB does not perform any processing.

OSS_INTER_RAT_MR_SWITCH: Indicates whether to disable periodic inter-RAT measurement of the strongest cells triggered by OSS subscription tasks for specified UEs. If this option is selected, periodic inter-RAT measurement of the strongest cells triggered by OSS subscription tasks is disabled for abnormal UEs. If this option is deselected, the gNodeB does not perform any processing.
