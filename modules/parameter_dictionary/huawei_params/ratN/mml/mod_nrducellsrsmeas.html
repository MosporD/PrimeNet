Modify NR DU Cell SRS Measurement (MOD NRDUCELLSRSMEAS)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the SRS measurement configurations of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NsaTdmPcTrigSinrHyst NSA TDM Power Control Trigger SINR Hyst

Meaning: Indicates the hysteresis for the SINR threshold of triggering TDM uplink power control for NSA UEs.

GUI Value Range: 0~100

Unit: 0.1dB

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a lower probability that TDM uplink power control will be triggered for NSA UEs. A smaller value of this parameter leads to a higher probability. It also leads to a higher probability that NSA UEs exit the TDM power control mode. As a result, the probability of frequent TDM power control mode triggering and exit increases.

Applicable Mode: N
NsaTdmPcTrigSinrThld NSA TDM Power Control Trigger SINR Thld

Meaning: Indicates the threshold of triggering TDM uplink power control for an NSA UE. TDM uplink power control is triggered for an NSA DC UE only if the uplink SINR of the UE on the LTE side is less than or equal to this threshold.

GUI Value Range: -100~100

Unit: 0.1dB

Actual Value Range: -10~10

MML Default Value: None

Recommended Value: -60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher probability that TDM uplink power control will be triggered for NSA UEs. A smaller value of this parameter leads to a lower probability.

Applicable Mode: N
NsaUlFackToLteSinrHyst NSA Uplink Fallback to LTE SINR Hyst

Meaning: Indicates the hysteresis for the uplink signal quality threshold used to determine whether to change the uplink data split mode of NSA DC to the LTE-only mode in an NR cell.

GUI Value Range: 0~100

Unit: 0.1dB

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability for the NSA DC uplink data split mode to change to the LTE-only mode based on the signal quality of the NR cell. A smaller value of this parameter results in the opposite effect. However, the probability of ping-pong changes increases..

Applicable Mode: N
NsaUlFackToLteSinrThld NSA Uplink Fallback to LTE SINR Thld

Meaning: Indicates the uplink signal quality threshold used to determine whether to change the uplink data split mode of NSA DC to the LTE-only mode in an NR cell.

GUI Value Range: -200~200

Unit: 0.1dB

Actual Value Range: -20~20

MML Default Value: None

Recommended Value: -30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability for the NSA DC uplink data split mode to change to the LTE-only mode based on the signal quality of the NR cell. If the LTE uplink throughput is low, the NSA DC uplink throughput may decrease. A smaller value of this parameter results in the opposite effect, and LTE uplink coverage gains may not be obtained in a timely manner.

Applicable Mode: N
HyperCellTrpHoDeltaRsrp Hyper Cell TRP Handover Delta RSRP

Meaning: Indicates the SRS RSRP difference based on which handovers are triggered between TRPs for a hyper cell or combined cell. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 0~30

Unit: 0.5 dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering handovers between TRPs for a hyper cell and a lower probability of ping-pong handovers. However, delayed handovers may cause service drops. A smaller value of this parameter results in a higher probability of triggering handovers between TRPs for a hyper cell, a lower probability of service drops, and a higher probability of ping-pong handovers.

Applicable Mode: N-TDD-FR1
NsaUlPathSelSinrHighThld NSA UL Path Select SINR High Threshold

Meaning: Indicates the upper threshold of uplink signal quality for determining uplink data transmission path selection for non-NSA DC data split UEs. If the NR uplink signal quality is continuously greater than the upper threshold, the NSA DC uplink data transmission path selection function switches uplink data transmission to NR.

GUI Value Range: -100~350

Unit: 0.1dB

Actual Value Range: -10~35

MML Default Value: None

Recommended Value: 150

Parameter Relationship:

-Configuration constraints:

  • The value of NsaUlPathSelSinrHighThld in the NRDUCellSrsMeas MO must be greater than the value of NsaUlPathSelSinrLowThld in the NRDUCellSrsMeas MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability for the non-NSA DC data split UEs to change to the NR-only mode based on the signal quality of the NR cell. If the NR uplink throughput is high, the uplink throughput of NSA DC may decrease. A smaller value of this parameter results in a higher probability. If the NR uplink throughput is high, the uplink throughput of NSA DC increases.

Applicable Mode: N
NsaUlPathSelSinrLowThld NSA UL Path Select SINR Low Threshold

Meaning: Indicates the lower threshold of uplink signal quality for determining uplink data transmission path selection for non-NSA DC data split UEs. If the NR uplink signal quality is continuously lower than the lower threshold, the NSA DC uplink data transmission path selection function switches uplink data transmission to LTE.

GUI Value Range: -100~350

Unit: 0.1dB

Actual Value Range: -10~35

MML Default Value: None

Recommended Value: -30

Parameter Relationship:

-Configuration constraints:

  • The value of NsaUlPathSelSinrHighThld in the NRDUCellSrsMeas MO must be greater than the value of NsaUlPathSelSinrLowThld in the NRDUCellSrsMeas MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability for the non-NSA DC data split UEs to change to the LTE-only mode based on the signal quality of the NR cell. If the LTE uplink throughput is low, the uplink throughput of NSA DC may decrease. A smaller value of this parameter results in a lower probability, and LTE uplink coverage gains may not be obtained in a timely manner.

Applicable Mode: N
NsaSplitUlPathSelSinrThld NSA Split UL Path Select SINR Threshold

Meaning: Indicates the threshold of uplink signal quality for determining uplink path selection for NSA DC data split UEs.

GUI Value Range: -100~350

Unit: 0.1dB

Actual Value Range: -10~35

MML Default Value: None

Recommended Value: -30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability for the NSA DC uplink data split UEs to change to the LTE-only mode based on the signal quality of the NR cell. If the LTE uplink throughput is low, the NSA DC uplink throughput may decrease. A smaller value of this parameter results in a lower probability, and LTE uplink coverage gains may not be obtained in a timely manner.

Applicable Mode: N
NsaUlPathSelSinrHyst NSA UL Path Select SINR Hyst

Meaning: Indicates the hysteresis to the uplink signal quality evaluation threshold for the NSA DC uplink data transmission path selection function.

GUI Value Range: 0~100

Unit: 0.1dB

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that the NSA DC uplink data transmission path selection function changes the uplink carrier. As a result, the optimal NSA DC uplink experience cannot be achieved. A smaller value of this parameter results in a higher probability. However, the probability of ping-pong changes increases.

Applicable Mode: N
NsaUlPathSelSinrTimeToTrig NSA UL Path Select SINR Time-to-Trigger

Meaning: Indicates the time-to-trigger of uplink signal quality evaluation for the NSA DC uplink data transmission path selection function.

GUI Value Range: 1~200

Unit: 100ms

Actual Value Range: 100~20000

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that the NSA DC uplink data transmission path selection function changes the uplink carrier. As a result, the optimal NSA DC uplink experience cannot be achieved. A smaller value of this parameter results in a higher probability. However, the probability of ping-pong changes increases.

Applicable Mode: N
NsaUlPathToLteRateRatio NSA UL Path Change to LTE Rate Ratio

Meaning: Indicates the rate ratio of LTE to NR for the NSA DC uplink data transmission path selection function to switch uplink data transmission to LTE. When the estimated LTE data rate is greater than the estimated NR data rate multiplied by the value of this parameter, uplink data transmission is switched to LTE.

GUI Value Range: 1~50000

Unit: None

Actual Value Range: 0.01~500, step: 0.01

MML Default Value: None

Recommended Value: 400

Parameter Relationship:

-Configuration constraints:

  • The value of NsaUlPathToLteRateRatio in the NRDUCellSrsMeas MO must be greater than the value of NsaUlPathToNrRateRatio in the NRDUCellSrsMeas MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that the NSA DC uplink data transmission path selection function switches uplink data transmission to LTE. If the uplink LTE throughput is high, the optimal NSA DC uplink experience may not be achieved. A smaller value of this parameter results in a higher probability.

Applicable Mode: N
NsaUlPathToNrRateRatio NSA UL Path Change to NR Rate Ratio

Meaning: Indicates the rate ratio of LTE to NR for the NSA DC uplink data transmission path selection function to switch uplink data transmission to NR. When the estimated LTE data rate is less than the estimated NR data rate multiplied by the value of this parameter, uplink data transmission is switched to NR.

GUI Value Range: 1~50000

Unit: None

Actual Value Range: 0.01~500, step: 0.01

MML Default Value: None

Recommended Value: 200

Parameter Relationship:

-Configuration constraints:

  • The value of NsaUlPathToLteRateRatio in the NRDUCellSrsMeas MO must be greater than the value of NsaUlPathToNrRateRatio in the NRDUCellSrsMeas MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that the NSA DC uplink data transmission path selection function switches uplink data transmission to NR. If the uplink LTE throughput is high, the optimal NSA DC uplink experience may not be achieved. A smaller value of this parameter results in a lower probability.

Applicable Mode: N
NsaSPktUlBackToNrPenaltyTime NSA Small Pkt UL Back to NR Penalty Time

Meaning: Indicates the penalty duration for reselecting an uplink data transmission path after uplink small-packet UEs transfer uplink data transmission to the NR side in the NSA DC uplink data transmission path selection feature. This parameter applies only in FDD and low-frequency TDD.

GUI Value Range: 1~60

Unit: s

Actual Value Range: 1~60

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter interval between the time when uplink small-packet UEs transfer uplink data transmission to the NR side and the time of reselecting an uplink data transmission path. A larger value of this parameter results in a longer interval.

Applicable Mode: N-TDD-FR1, N-FDD

Example

To modify the settings of NR DU cell measurement with the parameters as follows: NR DU Cell ID: 77, NsaTdmPcTrigSinrHyst: 8, run the following command:
MOD NRDUCELLSRSMEAS: NrDuCellId=77, NsaTdmPcTrigSinrHyst=8;
