Remove gNodeB Tracking Area Network Slice (RMV GNBTANS)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a tracking-area network slice from the gNodeB.

Note

None.

Parameters

ID Name Description
TrackingAreaId Tracking Area ID

Meaning: Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the core network. It is different from the TAI configured in the TAL of the core network.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
SliceServiceType Slice Service Type

Meaning: Indicates the slice/service type. For details, see 3GPP TS 23.003.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
SliceDifferentiator Slice Differentiator

Meaning: Indicates the slice differentiator. For details, see 3GPP TS 23.003. If this parameter is set to 16777215, a slice/service type is configured for the slice but the slice differentiator is not configured. If this parameter is not set to 16777215, this parameter indicates the specific slice differentiator.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD

Example

To remove gNodeB tracking area network slices with Tracking Area ID being 0, Operator ID being 0, Slice Service Type being 146, and Slice Differentiator being 6543, run the following command:
RMV GNBTANS: TrackingAreaId=0, OperatorId=0, SliceServiceType=146, SliceDifferentiator=6543;
