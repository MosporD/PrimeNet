Remove NR Cell Frequency Relationship (RMV NRCELLFREQRELATION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove frequency relationship configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Assume that there is a group of NRCellFreqRelation MO instances with the same NrCellId value. If SsbDescMethod in an NRCellFreqRelation MO in this group is set to SSB_DESC_TYPE_GSCN, then the NR-ARFCN mapped to the value of SsbFreqPos must not be the same as the value of SsbFreqPos in other NRCellFreqRelation MOs in this group.
  • Similarly, if SsbDescMethod in an NRCellFreqRelation MO in this group is set to SSB_DESC_TYPE_NARFCN, then the GSCN mapped to the value of SsbFreqPos must not be the same as the value of SsbFreqPos in other NRCellFreqRelation MOs in this group.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SsbFreqPos SSB Frequency Position

Meaning: Indicates the frequency-domain position of the SSB on a neighboring frequency. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN(Global Synchronization Channel Number), this parameter indicates the GSCN corresponding to the SSB on a neighboring frequency. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN(Absolute Frequency), this parameter indicates the NR-ARFCN corresponding to the SSB on a neighboring frequency.

GUI Value Range: 2~26639,123400~130400,151600~164200,173800~178800,185000~192000,361000~376000,386000~399000,422000~440000,460000~480000,499200~538000,620000~680000,693334~733333,2016667~2104165,2229167~2279165

Unit: None

Actual Value Range: 2~26639,123400~130400,151600~164200,173800~178800,185000~192000,361000~376000,386000~399000,422000~440000,460000~480000,499200~538000,620000~680000,693334~733333,2016667~2104165,2229167~2279165

MML Default Value: None
