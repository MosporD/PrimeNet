List gNodeB DRX Parameter Group (LST GNBDRXPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list a gNodeB CU DRX parameter group.

Note

None.

Parameters

ID Name Description
DrxParamGroupId DRX Parameter Group ID

Meaning: Indicates the ID of a DRX parameter group.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of a gNodeB DRX parameter group, run the following command:
LST GNBDRXPARAMGROUP:;
The result is shown as follows:
+++    0        2018-08-21 21:15:25
O&M    #2685403172
%%LST GNBDRXPARAMGROUP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

DRX Parameter Group ID

Indicates the ID of a DRX parameter group.

Long Cycle(ms)

Indicates the length of the long DRX cycle. The DRX feature takes effect only if the value of LongCycle is less than or equal to one sixth of the value of UlTimeAlignmentTimer in the NRDUCellUlTaConfig MO.

Short Cycle(ms)

Indicates the length of the short DRX cycle. This parameter takes effect only when ShortCycleTimer is set to a value other than 0.

Short Cycle Timer

Indicates the number of short DRX cycle repetitions. If the parameter is set to 0, the ShortCycle parameter configuration does not take effect.
