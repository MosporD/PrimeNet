List gNodeB Ciphering Capability (LST GNBCIPHERCAPB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the priorities of gNodeB ciphering algorithms.

Note

None.

Parameters

None.

Example

To list the settings of gNodeB ciphering algorithm priority, run the following command:
LST GNBCIPHERCAPB:;
The result is shown as follows:
+++    0        2018-12-03 16:36:30
O&M    #2685403192
%%LST GNBCIPHERCAPB:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Ciphering Capability
--------------------------------
Ciphering Algorithm Priority       Ciphering Algorithm

Primary-Priority Cipher Algorithm  AES_128 Algorithm
Second-Priority Cipher Algorithm   SNOW3G_128 Algorithm
Third-Priority Cipher Algorithm    ZUC_128 Algorithm
Fourth-Priority Cipher Algorithm   NULL Algorithm
(Number of results = 4)


---    END

Output Description

Field Description

Ciphering Algorithm Priority

Indicates the priority of a ciphering algorithm. PRIMARY indicates the highest priority, SECOND indicates the second priority, THIRD indicates the third priority, and FOURTH indicates the fourth priority.

Ciphering Algorithm

Indicates a ciphering algorithm corresponding to a priority. If this parameter is set to NULL, data is not encrypted. If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting a ciphering algorithm.
