Modify gNodeB RLC Parameter Group (MOD GNBRLCPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configurations of an RLC parameter group of the gNodeB.

Note

None.

Meaning: Indicates the size of a downlink RLC sequence number for the gNodeB and UE.

GUI Value Range: BITS12(12), BITS18(18), BITS6(6)

Unit: bit

Actual Value Range: BITS12, BITS18, BITS6

MML Default Value: None

Recommended Value: SRB and QCIs 1, 5, 65, 66, and 69: BITS12(12)

QCIs 2 to 4, 6 to 9, 70, 75, and 79: BITS12(12) in UM mode and BITS18(18) in AM mode

Parameter Relationship:

-Configuration constraints:

  • When RlcMode is set to UM, DlRlcSnSize and UlRlcSnSize must be set to BITS6 or BITS12.
  • When RlcMode is set to AM, DlRlcSnSize and UlRlcSnSize must be set to BITS12 or BITS18.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The sequence number size specified by this parameter must be large enough to prevent sequence number ambiguity caused by HARQ retransmissions. However, a large size results in a heavy RLC header load. In AM mode, the PDCP sequence number size must be the same as the RLC sequence number size. In UM mode, the PDCP sequence number size must be greater than or equal to the RLC sequence number size. Otherwise, packet loss may occur.

MOD GNBRLCPARAMGROUP: RlcParamGroupId=1, RlcMode=UM;
