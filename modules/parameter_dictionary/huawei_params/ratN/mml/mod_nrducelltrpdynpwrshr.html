Modify Dynamic Power Sharing Configuration of NR DU Cell TRP (MOD NRDUCELLTRPDYNPWRSHR)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the dynamic power sharing configuration of an NR DU cell TRP.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
MaxPowerSharingRate Max Power Sharing Rate

Meaning: Indicates the maximum percentage of power that the NR cell can share from other cells. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 1~50

Unit: %

Actual Value Range: 1~50

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller percentage of power that the NR cell can share from other cells, resulting in lower gains in average downlink user-perceived rate for CEUs and average downlink user-perceived rate in the NR cell. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1

Example

To modify the dynamic power sharing configurations of an NR DU cell TRP with NR DU Cell TRP ID set to 88 and Max Power Sharing Rate set to 30%, run the following command:
MOD NRDUCELLTRPDYNPWRSHR: NrDuCellTrpId=88, MaxPowerSharingRate=30;
