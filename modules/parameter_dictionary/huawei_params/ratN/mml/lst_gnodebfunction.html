List gNodeB Function (LST GNODEBFUNCTION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of the gNodeB function.

Note

When connected to a gNodeB, the MAE automatically synchronizes the name of the gNodeB function with the gNodeB.

Parameters

None.

Example

To list the configuration of the gNodeB function, run the following command:
LST GNODEBFUNCTION:;
The result is shown as follows:

Output Description

Field Description

gNodeB Function Name

Indicates the name of a gNodeB function, which uniquely identifies the gNodeB function.

Referenced Application ID

Indicates the ID of the application referenced by the gNodeB function. The application provides operating environment for the gNodeB function.

gNodeB ID

Indicates the gNodeB ID defined in the service protocol interface, which is unique within a PLMN.

gNodeB ID Length(bit)

Indicates the length of the gNodeB ID. The gNBIdLength parameter specifies the number of bits occupied by the gNBId in the NR cell identity (NCI), which uniquely identifies the NCI. For details about the parameter, see 3GPP TS 38.423. This parameter must be planned and the values for all gNodeBs must be the same within a PLMN.

User Label

Indicates the user label related to the gNodeB function.

Network Resource Model Version

Indicates the model version of gNodeB resources, including MO definition, attribute definition, and configuration rules.

Product Version

Indicates the product version.
