List NR DU Cell Spectrum Cloud (LST NRDUCELLSPCTCLOUD)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list NR DU cell spectrum cloud configuration.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • NrDuCellId in an NRDUCellSpctCloud MO can correspond to only one NrSpctShrCellGrpId.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To list the configuration of  NR DU cell spectrum clouds, run the following command:
LST NRDUCELLSPCTCLOUD:;
The result is shown as follows:
+++    0        2018-05-04 12:20:44
O&M    #2685403150
%%LST NRDUCELLSPCTCLOUD:;%%
RETCODE = 0  Operation succeeded.
List NR DU Cell Spectrum Cloud
------------------------------
                    NR DU Cell ID  =  7
NR Spectrum Sharing Cell Group ID  =  11
(Number of results = 1)
---    END

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

NR Spectrum Sharing Cell Group ID

Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.
