List gNodeB CU Xn (LST GNBCUXN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of the gNodeB CU Xn object.

Note

None.

Parameters

ID Name Description
gNBCuXnId gNodeB CU Xn ID

Meaning: Indicates the ID of a gNodeB CU Xn object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of the gNodeB CU Xn object, run the following command:
LST GNBCUXN:;
The result is shown as follows:
+++    0        2018-09-15 09:13:21
O&M    #2685403143
%%LST GNBCUXN:;%%
RETCODE = 0  Operation succeeded.

List gNodeB CU Xn
-----------------
                gNodeB CU Xn ID  =  1
Control Plane Endpoint Group ID  =  2
   User Plane Endpoint Group ID  =  2
(Number of results = 1)


---    END

Output Description

Field Description

gNodeB CU Xn ID

Indicates the ID of a gNodeB CU Xn object.

Control Plane Endpoint Group ID

Indicates the ID of the control-plane endpoint group used by the gNodeB CU Xn object.

User Plane Endpoint Group ID

Indicates the ID of the user-plane endpoint group used by the gNodeB CU Xn object.
