List NR DU Cell Resource (LST NRDUCELLRES)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list group-specific resources of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In all the instances of an NRDUCellRes MO with the same NrDuCellId value and DlRbAverageRatio not set to 255, the sum of the values of DlRbAverageRatio must be less than or equal to 100.
  • In all the instances of an NRDUCellRes MO with the same NrDuCellId value and UlRbAverageRatio not set to 255, the sum of the values of UlRbAverageRatio must be less than or equal to 100.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellResId Cell Resource ID

Meaning: Indicates the resource ID of an NR DU cell.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N

Example

To list the static attributes of an NR DU cell Resource with NR DU Cell ID set to 88, run the following command:
LST NRDUCELLRES: NrDuCellId=88;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Cell Resource ID

Indicates the resource ID of an NR DU cell.

Downlink RB Max Ratio(%)

Indicates the maximum proportion of PDSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the maximum proportion of downlink PDSCH RBs that can be used by UEs served by an operator is not configured.

Downlink RB Average Ratio(%)

Indicates the average proportion of PDSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the average proportion of downlink PDSCH RBs that can be used by UEs served by an operator is not configured.

Uplink RB Max Ratio(%)

Indicates the maximum proportion of PUSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the maximum proportion of uplink PUSCH RBs that can be used by UEs served by an operator is not configured.

Uplink RB Average Ratio(%)

Indicates the average proportion of PUSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the average proportion of uplink PUSCH RBs that can be used by UEs served by an operator is not configured.
