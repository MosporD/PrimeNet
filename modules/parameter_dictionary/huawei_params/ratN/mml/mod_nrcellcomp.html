Modify NR Cell CoMP Parameters (MOD NRCELLCOMP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the CoMP parameter settings of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-SUL
OverlappingRsrpOffset Overlapping RSRP Offset

Meaning: Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the overlapping area measurement event.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship:

-Configuration constraints:

  • In the NRCellComp MO, the value of OverlappingRsrpOffset must be the same as that of DlCompRsrpOffset or UlCompRsrpOffset.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of sending event A3 reports related to overlapping area measurement. A smaller value of this parameter results in the opposite effect.

Applicable Mode: N-TDD-FR1, N-SUL
UlCompRsrpOffset UL CoMP RSRP Offset

Meaning: Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the UL CoMP or SUL CoMP measurement event.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -20

Parameter Relationship:

-Configuration constraints:

  • In the NRCellComp MO, the value of OverlappingRsrpOffset must be the same as that of DlCompRsrpOffset or UlCompRsrpOffset.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of sending measurement reports for UL CoMP and triggering UL CoMP, causing a smaller UL CoMP coordinating area. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1
DlCompRsrpOffset DL CoMP RSRP Offset

Meaning: Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the DL CoMP measurement event.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -12

Parameter Relationship:

-Configuration constraints:

  • In the NRCellComp MO, the value of OverlappingRsrpOffset must be the same as that of DlCompRsrpOffset or UlCompRsrpOffset.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of sending measurement reports for DL CoMP and triggering DL CoMP. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1
TimeToTrigger Time to Trigger

Meaning: Indicates the time-to-trigger for CoMP-related measurement events. Set this parameter to reduce the probability of occasional event triggering.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: None

Recommended Value: 320MS(320)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of sending measurement reports. A larger value of this parameter results in a lower probability of sending measurement reports.

Applicable Mode: N-TDD-FR1, N-SUL
Hysteresis Hysteresis

Meaning: Indicates the hysteresis for CoMP-related measurement events. Set this parameter to reduce frequent event triggering and incorrect decisions caused by radio signal fluctuation.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of event triggering. A larger value of this parameter results in a lower probability of event triggering.

Applicable Mode: N-TDD-FR1, N-SUL
SulCompSrsRsrpOffset SUL CoMP SRS RSRP Offset

Meaning: Indicates the positive SRS RSRP offset for a neighboring cell relative to that for the serving cell used to trigger SUL CoMP.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: -10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering SUL CoMP, causing a smaller SUL CoMP coordinating area. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-SUL

Example

To modify NR cell CoMP parameters of an NR cell with NR Cell ID set to 1, Overlapping RSRP Offset set to –2, UL CoMP RSRP Offset set to –2, DL CoMP RSRP Offset set to –3, Time to Trigger set to 80MS, Hysteresis set to 1, and SUL CoMP SRS RSRP Offset set to -10, run the following command:
MOD NRCELLCOMP: NrCellId=1, OverlappingRsrpOffset=-2, UlCompRsrpOffset=-2, DlCompRsrpOffset=-3, TimeToTrigger=80MS, Hysteresis=1, SulCompSrsRsrpOffset=-10;
