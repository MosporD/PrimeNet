List NR DU Cell TRP mmWave Beam Configuration (LST NRDUCELLTRPMMWAVBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of mmWave beams in an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP in an NR DU cell, which uniquely identifies the TRP within an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the configuration of mmwave beams in an NR DU cell with NR DU Cell TRP ID set to 10, run the following command:
LST NRDUCELLTRPMMWAVBEAM: NrDuCellTrpId=10;
The result is shown as follows:

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP in an NR DU cell, which uniquely identifies the TRP within an NR DU cell.

Coverage Scenario

Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. The DSP NRDUCELLTRP command can be executed to query the coverage scenarios supported by different types of AAUs. This parameter applies only to high-frequency cells.

Tilt(degree)

Indicates the configured downtilt angle mapping a weight for beamforming. If this parameter is set to 255, the default downtilt angle supported by the hardware is used. The DSP NRDUCELLTRP command can be executed to query the tilt angle adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the tilt angle is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the tilt angle of the cell exceeds the range supported by the AAU, the cell becomes unavailable.

Max SSB Power Offset(dB)

Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to high-frequency cells.

Azimuth(degree)

Indicates the azimuth mapping a weight for beamforming. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the azimuth is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the azimuth of the cell exceeds the range supported by the AAU, the cell becomes unavailable.
