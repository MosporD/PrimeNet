Modify NR DU Cell (MOD NRDUCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

An NRDUCell MO defines information such as the NR DU cell ID and RF information. It is configured by network planning engineers based on site requirements.
