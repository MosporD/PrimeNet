Display gNodeB CU NG Interface (DSP GNBCUNGINTERFACE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the information about an NG interface, such as the information about the CP, NG interface status, and peer AMF. If the status of an NG interface is abnormal, the command output displays the information of the peer AMF in the last normal connection with the local gNodeB.

Note

None.

Parameters

ID Name Description
gNBCuNgInterfaceId gNodeB CU NG Interface ID

Meaning: Indicates the ID of a gNodeB CU NG interface.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the status and other information of gNodeB CU NG interfaces, run the following command:
DSP GNBCUNGINTERFACE:;

Output Description

Field Description

gNodeB CU NG Interface ID

Indicates the ID of a gNodeB CU NG interface.

gNodeB CU NG Interface CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU NG interface.

gNodeB Operator ID

Indicates the list of IDs of the operators that own the NG interface. Operator IDs are separated by commas (,).

Served GUAMIs

Indicates the globally unique AMF ID (GUAMI) of the AMF connected over the NG interface. Each ID is represented by MCC-MNC-AMF Region ID-AMF Set ID-AMF Pointer. The GUAMIs of each serving core network are separated by commas (,).

Abnormal Reason

Indicates the reason why a gNodeB CU NG interface is abnormal.

AMF Name

Indicates the name of the AMF connected over the NG interface. This parameter is valid after the NG interface is established and the AMF name is contained in the NG interface establishment response message or the AMF configuration update message. In other conditions, the parameter value is NULL. For details, see 3GPP TS 38.413.

gNodeB CU NG Interface CP Bearer State

Indicates the state of the bottom-layer CP bearer of a gNodeB CU NG interface.

gNodeB CU NG Interface State

Indicates the state of a gNodeB CU NG interface.

Last Fault Time

Indicates the time when the last gNodeB CU NG interface fault occurred. The time format is YEAR-MONTH-DAY HH:MM:SS. For example, 2018-1-1 10:20:05 indicates 10:20:05 on January 1, 2018.

Served PLMNs

Indicates the IDs of all served PLMNs of the AMF connected over the NG interface. The ID of a served PLMN consists of the MCC and MNC. PLMN IDs are separated by commas (,).

AMF Overload Status

Indicates whether the AMF connected to the NG interface is overloaded. This parameter is valid after the NG interface is successfully set up. If the NG interface is not set up successfully, it is in the NULL state. For details about how to determine whether the AMF is overloaded after the NG interface is set up, see 3GPP TS 38.413.

AMF UE Num

Indicates the number of UEs accessed the AMF over the NG interface, which is collected on the gNodeB side.

gNodeB CU NG Interface Address

Indicates the IP address of the AMF connected to the NG interface.

gNodeB CU NG Interface UE Num

Indicates the number of UEs accessed over the NG interface. An AMF may contain multiple NG interfaces.

gNodeB CU NG Interface Weight Factor

Indicates the weight factor of the NG interface.

Relative AMF Capacity

Indicates the relative capacity of the AMF connected to the NG interface. That is, the capacity of the AMF relative to other AMFs. A larger value indicates that more UEs can access the AMF.
