Remove gNodeB External E-UTRAN Cell PLMN (RMV GNBEUTRAEXTCELLPLMN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a record from the E-UTRAN external-cell PLMN list of a gNodeB.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After this command is executed, UEs served by the operator cannot be handed over from the NR network to the external E-UTRAN cell.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of the operator who owns the external E-UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a gNBEutraExtCellPlmn MO, the combination of Mcc and Mnc must be different from that of SharedMcc and SharedMnc.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

EnodebId eNodeB ID

Meaning: Indicates the eNodeB ID of an external E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

CellId Cell ID

Meaning: Indicates the cell ID of an external E-UTRAN cell. It uniquely identifies an E-UTRAN cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

Example

To remove a gNodeB external neighboring E-UTRAN cell PLMN list with the parameters as follows: Mobile Country Code: "302", Mobile Network Code: "220", eNodeB ID: 1, Cell ID: 1, Shared Mobile Country Code: "302", Shared Mobile Network Code: "202", run the following command:
RMV GNBEUTRAEXTCELLPLMN: Mcc="302", Mnc="220", EnodebId=1, CellId=1, SharedMcc="302", SharedMnc="202";
