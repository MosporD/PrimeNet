Modify gNodeB Integrity Protection Capability (MOD GNBINTEGRITYCAPB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the priority of a gNodeB integrity protection algorithm.

Note

None.

Parameters

ID Name Description
IntegrityAlgoPriority Integrity Protection Algorithm Priority

Meaning: Indicates the priority of an integrity protection algorithm. PRIMARY indicates the highest priority, SECOND indicates the second priority, and THIRD indicates the third priority.

GUI Value Range: PRIMARY(Primary-Priority Integrity Algorithm), SECOND(Second-Priority Integrity Algorithm), THIRD(Third-Priority Integrity Algorithm)

Unit: None

Actual Value Range: PRIMARY, SECOND, THIRD

MML Default Value: None

Recommended Value: PRIMARY(Primary-Priority Integrity Algorithm)

Parameter Relationship:

-Configuration constraints:

  • In gNBIntegrityCapb MOs, different IntegrityAlgoPriority values must correspond to different IntegrityAlgo values, except for the case that the value of IntegrityAlgo is NOT_CONFIG.
  • In gNBIntegrityCapb MOs, at least one IntegrityAlgo value is not NOT_CONFIG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
IntegrityAlgo Integrity Protection Algorithm

Meaning: Indicates an integrity protection algorithm of a corresponding priority. If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting an integrity protection algorithm.

GUI Value Range: NOT_CONFIG(Not Configured), AES_128(AES_128 Algorithm), SNOW3G_128(SNOW3G_128 Algorithm), ZUC_128(ZUC_128 Algorithm)

Unit: None

Actual Value Range: NOT_CONFIG, AES_128, SNOW3G_128, ZUC_128

MML Default Value: None

Recommended Value: AES_128(AES 128 Algorithm)

Parameter Relationship:

-Configuration constraints:

  • In gNBIntegrityCapb MOs, different IntegrityAlgoPriority values must correspond to different IntegrityAlgo values, except for the case that the value of IntegrityAlgo is NOT_CONFIG.
  • In gNBIntegrityCapb MOs, at least one IntegrityAlgo value is not NOT_CONFIG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting an integrity protection algorithm. If the integrity protection algorithm list that the gNodeB supports and integrity protection algorithms that a UE supports have no intersection, the security mode configuration fails for the UE, resulting in an SRB/DRB setup failure or handover failure.

Applicable Mode: N

Example

To modify the settings of gNodeB integrity protection algorithm priority with the parameters as follows: Integrity Protection Algorithm Priority: Third Highest, Integrity Protection Algorithm: NOT_CONFIG, run the following command:
MOD GNBINTEGRITYCAPB: IntegrityAlgoPriority=THIRD, IntegrityAlgo=NOT_CONFIG;
