Modify gNodeB DRX Parameter Group (MOD GNBDRXPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a gNodeB CU DRX parameter group.

Note

None.

Parameters

ID Name Description
DrxParamGroupId DRX Parameter Group ID

Meaning: Indicates the ID of a DRX parameter group.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
LongCycle Long Cycle

Meaning: Indicates the length of the long DRX cycle. The DRX feature takes effect only if the value of LongCycle is less than or equal to one sixth of the value of UlTimeAlignmentTimer in the NRDUCellUlTaConfig MO.

GUI Value Range: MS10(10), MS20(20), MS40(40), MS60(60), MS70(70), MS80(80), MS160(160), MS320(320), MS640(640), MS1280(1280), MS2560(2560), MS5120(5120), MS10240(10240)

Unit: ms

Actual Value Range: MS10, MS20, MS40, MS60, MS70, MS80, MS160, MS320, MS640, MS1280, MS2560, MS5120, MS10240

MML Default Value: None

Recommended Value: This parameter can be set by the gNodeB by default as follows:

QCI 1, QCI 5, QCI 65, QCI 66, and QCI 69: DRX parameter not configured

QCI 2, QCI 3, QCI 7, QCI 75, and QCI 79: MS40(40)

QCI 4, QCI 6, QCI 8, QCI 9, and QCI 70: MS320(320)

Parameter Relationship:

-Configuration constraints:

  • The value of LongCycle is K times of the value of ShortCycle. K is an integer greater than or equal to 2.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the OnDurationTimer, DrxInactivityTimer, ShortCycle, ShortCycleTimer, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: N
ShortCycle Short Cycle

Meaning: Indicates the length of the short DRX cycle. This parameter takes effect only when ShortCycleTimer is set to a value other than 0.

GUI Value Range: MS2(2), MS3(3), MS4(4), MS5(5), MS6(6), MS7(7), MS8(8), MS10(10), MS14(14), MS16(16), MS20(20), MS30(30), MS32(32), MS35(35), MS40(40), MS64(64), MS80(80), MS128(128), MS160(160), MS256(256), MS320(320), MS512(512), MS640(640)

Unit: ms

Actual Value Range: MS2, MS3, MS4, MS5, MS6, MS7, MS8, MS10, MS14, MS16, MS20, MS30, MS32, MS35, MS40, MS64, MS80, MS128, MS160, MS256, MS320, MS512, MS640

MML Default Value: None

Recommended Value: This parameter can be set by the gNodeB by default as follows:

QCI 1, QCI 5, QCI 65, QCI 66, and QCI 69: DRX parameter not configured

QCI 2, QCI 3, QCI 7, QCI 75, and QCI 79: MS20(20)

QCI 4, QCI 6, QCI 8, QCI 9, and QCI 70: MS80(80)

Parameter Relationship:

-Configuration constraints:

  • The value of LongCycle is K times of the value of ShortCycle. K is an integer greater than or equal to 2.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongCycle, OnDurationTimer, DrxInactivityTimer, ShortCycleTimer, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in higher UE power consumption but shorter service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: N
ShortCycleTimer Short Cycle Timer

Meaning: Indicates the number of short DRX cycle repetitions. If the parameter is set to 0, the ShortCycle parameter configuration does not take effect.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter, together with the LongCycle, OnDurationTimer, DrxInactivityTimer, ShortCycle, and DrxRetransTimer parameters, affects the DRX mechanism. If the settings of other DRX parameters remain unchanged, a smaller value of this parameter results in lower UE power consumption but longer service delay, and a larger value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify a gNodeB DRX parameter group with the parameters as follows: DrxParamGroupId: 1, LongCycle: 320, ShortCycle: 80, run the following command:
MOD GNBDRXPARAMGROUP: DrxParamGroupId=1, LongCycle=MS320, ShortCycle=MS80;
