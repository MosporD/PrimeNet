Add gNodeB CU X2 (ADD GNBCUX2)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the gNodeB CU X2 object.

Note

  • Before adding the gNodeB CU X2 object, ensure that the control-plane and user-plane endpoint groups to be used by this object have been added.

  • When the gNodeB CU X2 object and the gNodeB CU Xn object use the same user-plane local IP address and peer IP address, they must be configured with the same user-plane endpoint group. Otherwise, only the first user-plane channel can be established, and the subsequent channels fail to be established.

  • A maximum of 6 gNodeB CU X2 objects can be configured on a gNodeB.

Example

To add the gNodeB CU X2 object with the parameters as follows: gNodeB CU X2 ID set to 1, Control Plane Endpoint Group ID set to 1, User Plane Endpoint Group ID set to 1, run the following command:
ADD GNBCUX2: gNBCuX2Id=1, CpEpGroupId=1, UpEpGroupId=1;
