Start NR DU Cell RF Loopback (STR NRDUCELLRFLOOPBACK)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to start RF loopback in an NR cell that has been set up.

Note

Only high-frequency NR DU cells support RF loopback, Low-frequency NR DU cells do not support RF loopback.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To start RF loopback, NR DU Cell ID is 77, run the following command:
STR NRDUCELLRFLOOPBACK: NrDuCellId=77;
