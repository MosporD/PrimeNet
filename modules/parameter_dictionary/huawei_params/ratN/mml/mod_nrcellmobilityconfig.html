Modify NR Cell Mobility Configuration (MOD NRCELLMOBILITYCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the mobility configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
BeamRsrpFilterCoeff Beam RSRP Filter Coefficient

Meaning: Indicates the filtering coefficient of the beam-level RSRP obtained through UE measurement.

GUI Value Range: FC0(FC0), FC1(FC1), FC2(FC2), FC3(FC3), FC4(FC4), FC5(FC5), FC6(FC6), FC7(FC7), FC8(FC8), FC9(FC9), FC11(FC11), FC13(FC13), FC15(FC15), FC17(FC17), FC19(FC19)

Unit: None

Actual Value Range: FC0, FC1, FC2, FC3, FC4, FC5, FC6, FC7, FC8, FC9, FC11, FC13, FC15, FC17, FC19

MML Default Value: None

Recommended Value: FC4(FC4)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a weaker smoothing effect of the beam-level RSRP and larger fluctuation of the beam-level RSRP. A larger value of this parameter leads to a stronger smoothing effect of the beam-level RSRP and higher stability of the beam-level RSRP.

Applicable Mode: N
CellRsrpFilterCoeff Cell RSRP Filter Coefficient

Meaning: Indicates the filtering coefficient of the cell-level RSRP obtained through UE measurement.

GUI Value Range: FC0(FC0), FC1(FC1), FC2(FC2), FC3(FC3), FC4(FC4), FC5(FC5), FC6(FC6), FC7(FC7), FC8(FC8), FC9(FC9), FC11(FC11), FC13(FC13), FC15(FC15), FC17(FC17), FC19(FC19)

Unit: None

Actual Value Range: FC0, FC1, FC2, FC3, FC4, FC5, FC6, FC7, FC8, FC9, FC11, FC13, FC15, FC17, FC19

MML Default Value: None

Recommended Value: FC4(FC4)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a weaker smoothing effect of the cell-level RSRP, larger fluctuation of the cell-level RSRP, and a higher probability of ping-pong handovers. A larger value of this parameter leads to a stronger smoothing effect of the cell-level RSRP, higher stability of the cell-level RSRP, and a lower probability of ping-pong handovers.

Applicable Mode: N
SsbConsolidationThld SSB Consolidation Threshold

Meaning: Indicates the threshold for combining beam measurement results when cell-level SSB measurement results are calculated. The threshold means an index. The parameter value in the range from 0 to 126 indicates a value of the index minus 157 in unit of dBm, and the parameter value 127 indicates infinity in unit of dBm. If the RSRP of one or more SSB beams in a cell is greater than the parameter value, the linear average RSRP of those SSB beams is used as the cell-level RSRP. If the RSRP of no SSB beam in a cell is greater than the parameter value, the largest RSRP among the RSRP values of those beams is used as the cell-level RSRP. For details about this parameter, see 3GPP TS 38.331 and TS 38.133.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to smaller RSRP during cell-level SSB measurement and higher probability of triggering handovers between cells in the same channel environment. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
SsbNumToAverage SSB Number To Average

Meaning: Indicates the maximum number of SSB beams that can be used by the UE when the UE obtains the cell-level RSRP based on the beam-level RSRP.

GUI Value Range: 2~16

Unit: None

Actual Value Range: 2~16

MML Default Value: None

Recommended Value: 8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a smaller number of SSB beams used by the UE to calculate the cell-level RSRP, higher cell-level RSRP, and a lower probability that the UE is handed over from the serving cell. A larger value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify the mobility configuration of an NR cell, with the parameters as follows:  NrCellId=55, BeamRsrpFilterCoeff=FC4, CellRsrpFilterCoeff=FC4, SsbConsolidationThld=70, SsbNumToAverage=6;
run the following command:
MOD NRCELLMOBILITYCONFIG: NrCellId=55, BeamRsrpFilterCoeff=FC4, CellRsrpFilterCoeff=FC4, SsbConsolidationThld=70, SsbNumToAverage=6;
