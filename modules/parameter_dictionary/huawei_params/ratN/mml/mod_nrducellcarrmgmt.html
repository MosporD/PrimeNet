Modify NR DU Cell Carrier Management (MOD NRDUCELLCARRMGMT)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of parameters related to carrier management in an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SccDeactvCqiThld SCC Deactivation CQI Threshold

Meaning: Indicates the CQI threshold for deactivating secondary cells based on channel quality. If the channel quality of a CA UE is lower than this threshold, the gNodeB deactivates the secondary cell. If this parameter is set to 0, the function of deactivating secondary cell based on channel quality is not enabled. This parameter is set on the secondary cell.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 5

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of secondary cell deactivation. A smaller value of this parameter results in a lower probability of secondary cell deactivation.

Applicable Mode: N
CaEnhancedAlgoSwitch CA Enhanced Algorithm Switch

Meaning: Indicates whether to enable enhanced CA algorithms.

CARR_CSI_BEAM_SWEEPING_SW: Indicates whether to enable CA SCC beam sweeping. CSI beam sweeping is enabled when this option is selected. With this function, the base station obtains the CSI beam information of the UE on the PUSCH-less SCC so that the PMI, RI, or CQI can be transmitted on the optimal beam. CSI beam sweeping is disabled when this option is deselected. This option applies only to low-frequency TDD cells.

GUI Value Range: CARR_CSI_BEAM_SWEEPING_SW(Carrier CSI Beam Sweeping Switch)

Unit: None

Actual Value Range: CARR_CSI_BEAM_SWEEPING_SW

MML Default Value: None

Recommended Value: CARR_CSI_BEAM_SWEEPING_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: CARR_CSI_BEAM_SWEEPING_SW:

When the beam configurations of the PCell and SCell are different, for example, they do not share an AAU:

If this option is selected, the base station obtains the beam information of UEs on the PUSCH-less SCC and enables CA for the UEs, increasing downlink UE throughput.

If this option is deselected, the base station cannot obtain the beam information of the UEs on the PUSCH-less SCC or enable CA for the UEs. As a result, the downlink UE throughput cannot increase.

When the beam configurations of the PCell and SCell are similar:Selecting or deselecting this option has no impact on network performance.

Applicable Mode: N-TDD-FR1

Example

To modify the NR DU cell Carrier management parameter configurations with the parameters as follows: NR DU Cell ID: 77, SCC Deactivation CQI Threshold: 2, run the following command:
MOD NRDUCELLCARRMGMT: NrDuCellId=77, SccDeactvCqiThld=2;
