Modify gNodeB OAM Param (MOD GNBOAMPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify gNodeB-level operation and maintenance parameters.

Note

None.

Parameters

ID Name Description
StatisticsStrategySwitch Statistics Strategy Switch

Meaning: Indicates the switches controlling counter statistics collection policies. NSA_CBRA_STATISTICS_OPT_SW: Indicates whether to enable statistics collection optimization for contention-based random access in NSA scenarios. If this option is selected and the base station triggers NSA UE access, all contention-based random access statistics within a fixed period of time are counted in related counters and contention-based random access statistics not within the fixed period of time are not counted. If this option is deselected, all contention-based random access statistics at any time are counted in related counters. It is recommended that this function be used in light-load scenarios. This parameter applies only to low-frequency TDD, FDD, and SUL cells. This parameter takes effect only for cells in NSA networking.

GUI Value Range: NSA_CBRA_STATISTICS_OPT_SW(NSA CBRA Statistics Optimization Switch)

Unit: None

Actual Value Range: NSA_CBRA_STATISTICS_OPT_SW

MML Default Value: None

Recommended Value: NSA_CBRA_STATISTICS_OPT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NSA_CBRA_STATISTICS_OPT_SW: This option has no impact on network performance.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To modify gNodeB-level Operation and maintenance parameters with the parameters as follows: NSA CBRA Statistics Optimization Switch: On, run the following command:
MOD GNBOAMPARAM: StatisticsStrategySwitch=NSA_CBRA_STATISTICS_OPT_SW-1;
