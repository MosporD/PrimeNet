Add NR DU Cell TRP (ADD NRDUCELLTRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a TRP for an NR DU cell.

Note

An NRDUCellTrp MO defines the basic TRP information such as information of baseband equipment and RF equipment. It is configured by network planning engineers based on site requirements. PowerConfigMode must be set to TRANSMIT_POWER for low-frequency cells and the power specified by MaxTransmitPower is used. PowerConfigMode must be set to EIRP for high-frequency cells and the power specified by MaxEirp is used. Set the MaxTransmitPower parameter for low-frequency cells and set the MaxEirp parameter for high-frequency cells based on the network plan and RF module capabilities to prevent cell setup failures caused by insufficient RF module capabilities.

MaxTransmitPower Max Transmit Power

Meaning: Indicates the maximum transmit power of a single TX channel of the NR DU cell TRP. This parameter is valid only when PowerConfigMode is set to TRANSMIT_POWER.

GUI Value Range: 0~600

Unit: 0.1dBm

Actual Value Range: 0~60

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: 1. Coverage: If the value of MaxTransmitPower is too large, overshoot coverage occurs and this causes interference to other cells. If the value is too small, coverage holes appear.

2. Interference: The setting of MaxTransmitPower varies with the interference from neighboring cells. A large interference margin is required where the interference is strong.

3. Channel estimation: A larger value of MaxTransmitPower leads to higher channel estimation accuracy, a lower demodulation threshold, and higher receiver sensitivity. However, a large value causes stronger interference to neighboring cells.

4. Capacity: A larger value of MaxTransmitPower brings better coverage. However, a large value limits the power used for data transmission and hence decreases system capacity.

The setting of MaxTransmitPower needs to ensure a reasonable tradeoff between coverage and capacity, effective channel estimation, and appropriate interference control.

Applicable Mode: N-TDD-FR1, N-FDD
MaxEirp Max EIRP

Meaning: Indicates the maximum equivalent isotropically radiated power (EIRP) of all TX channels of the NR DU cell TRP. This parameter is valid only when PowerConfigMode is set to EIRP.

GUI Value Range: 0~1000

Unit: 0.1dBm

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: 1. Coverage: If the value of MaxEirp is too large, overshoot coverage occurs. If the value of MaxEirp is too small, coverage holes appear.

2. Interference: The setting of MaxEirp varies with the interference from adjacent cells. A small MaxEirp value is required in places subject to strong interference.

3. Channel estimation: The setting of MaxEirp affects channel estimation. Specifically, a larger value of MaxEirp leads to higher channel estimation accuracy, a lower demodulation threshold, and higher receiver sensitivity. However, a larger value of MaxEirp causes stronger interference to neighboring cells.

4. The power configuration rules of the corresponding RF module need to be considered during MaxEirp configuration. If the value of this parameter exceeds the allowed range, cells cannot be activated or cell performance deteriorates.

The setting of MaxEirp needs to ensure a reasonable tradeoff between coverage and capacity, guarantee channel estimation accuracy, and offer appropriate interference control.

Applicable Mode: N-TDD-FR2

BbResMutualAidSw Baseband Resource Mutual Aid Switch

Meaning: Indicates the baseband resource mutual aid switch for the TRP in an NR DU cell. This parameter is valid only when the baseband equipment ID is valid. When this parameter is set to ON, the cell can use other baseband equipment resources when the baseband equipment resources configured for the cell are faulty. After the baseband equipment recovers, the cell automatically reestablishes in the early morning and attempts to return to the configured baseband equipment. When this parameter is set to OFF, the cell can use only the baseband equipment resources corresponding to the baseband equipment ID.

AntPolarization Antenna Polarization

Meaning: Indicates the antenna polarization mode of a 2T2R/4T4R/8T8R cell. The value SINGLE_POLARIZATION indicates single polarization for a 2T2R/4T4R cell. The value DOUBLE_POLARIZATION indicates dual polarization for a 2T2R/4T4R/8T8R 4H1V cell. The value 2H2V_DOUBLE_POLARIZATION indicates dual polarization for an 8T8R 2H2V cell. The value DEFAULT indicates that the antenna polarization mode of a 2T2R/4T4R cell cannot be obtained, and the antenna polarization mode of an 8T8R cell is the same as that of a 4H1V cell. This parameter applies only in TDD low frequency bands. This parameter applies only to modules with external antenna and does not apply to modules with internal antenna.

GUI Value Range: SINGLE_POLARIZATION(Single Polarization), DOUBLE_POLARIZATION(Dual Polarization), DEFAULT(Default Mode), 2H2V_DOUBLE_POLARIZATION(2H2V Dual Polarization)

Unit: None

Actual Value Range: SINGLE_POLARIZATION, DOUBLE_POLARIZATION, DEFAULT, 2H2V_DOUBLE_POLARIZATION

MML Default Value: DEFAULT(Default Mode)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to DEFAULT, the cell cannot obtain the antenna polarization mode and the SSB coverage performance is poor. If this parameter is set to SINGLE_POLARIZATION, DOUBLE_POLARIZATION, or 2H2V_DOUBLE_POLARIZATION, and the value of this parameter is consistent with the polarization state of the physical antenna, the SSB coverage gain increases by more than 2 dB.

Applicable Mode: N-TDD-FR1

Example

To add the TRP for an NR DU cell with parameters as follows: NR DU Cell TRP ID: 0, NR DU Cell ID: 0, Transmit and Receive Mode: 8T8R, Power Config Mode: TRANSMIT_POWER, Max Transmit Power(0.1 dBm): 100, CPRI Compression: No Compression, Baseband Resource Mutual Aid Switch: ON, run the following command:
ADD NRDUCELLTRP: NrDuCellTrpId=0, NrDuCellId=0, TxRxMode=8T8R, PowerConfigMode=TRANSMIT_POWER, MaxTransmitPower=100, CpriCompression=NO_COMPRESSION, BbResMutualAidSw=ON;
