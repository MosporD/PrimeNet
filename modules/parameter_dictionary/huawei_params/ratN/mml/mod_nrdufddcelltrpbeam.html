Modify NR DU FDD Cell TRP Beam (MOD NRDUFDDCELLTRPBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the TRP beam configuration of an FDD NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-FDD
CoverageScenario Coverage Scenario

Meaning: Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. This parameter applies only to FDD.

GUI Value Range: DEFAULT(Default Scenario), SCENARIO_201(Coverage Scenario)

Unit: None

Actual Value Range: DEFAULT, SCENARIO_201

MML Default Value: None

Recommended Value: DEFAULT(Default Scenario)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the scenario ID is changed, random access may be re-initiated for NSA UEs and service drops may occur; for SA UEs, the success rate of incoming handovers and resynchronization may decrease. This operation will not cause cell reestablishment but will cause the throughput to decrease for a period of time (about 5 minutes).

Adjusting the beam pattern of an antenna affects the radio coverage range, which results in network KPI changes. It is good practice to set this parameter based on onsite coverage.

Applicable Mode: N-FDD
MaxSsbPwrOffset Max SSB Power Offset

Meaning: Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to FDD.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, when the value of MaxSsbPwrOffset decreases, the network searching success rate of UEs at the cell edge decreases.)

Impact on Radio Network Performance: A larger value of this parameter results in higher power used for sending an SSB and larger coverage of the SSB beam. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-FDD

Example

To modify the configuration of beams in an NR DU FDD cell as follows: NR DU Cell TRP ID: 88, Coverage Scenario: DEFAULT, Max SSB Power Offset: 1, run the following command:
MOD NRDUFDDCELLTRPBEAM: NrDuCellTrpId=88, CoverageScenario=DEFAULT, MaxSsbPwrOffset=1;
