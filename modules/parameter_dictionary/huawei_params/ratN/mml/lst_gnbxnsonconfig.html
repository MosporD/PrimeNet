List gNodeB Xn SON Configuration (LST GNBXNSONCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of gNodeB Xn SON functions.

Note

None.

Parameters

None.

Example

To list the configuration of gNodeB Xn SON functions, run the following command:
LST GNBXNSONCONFIG:;
The result is shown as follows:
+++    0        2018-09-15 09:14:36
O&M    #2685403145
%%LST GNBXNSONCONFIG:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Xn SON Configuration
--------------------------------
Xn SON Configuration Switch  =  Xn Self-Setup Switch:On
                             =  Xn Self-Removal Switch:Off
                             =  Xn Dynamic Blacklist Switch:Off
(Number of results = 1)


---    END

Output Description

Field Description

Xn SON Configuration Switch

Indicates whether to enable Xn self-configuration.

XN_SON_SETUP_SW: Indicates whether to enable Xn self-setup. This function is enabled only when this option is selected.

XN_SON_DEL_SW: Indicates whether to enable Xn self-removal. This function is enabled only when this option is selected.

XN_SON_DYN_BLACKLIST_SW: Indicates whether to enable the dynamic blacklisting function when an initial Xn self-setup procedure fails. This function is enabled only when this option is selected.
