Start NR DU Cell Redeploy (STR NRDUCELLREDEPLOY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to re-deploy NR DU cells on the baseband equipment in one-click. When an NR DU cell reports ALM-29870 NR DU Cell TRP Unavailable with the cause being "Configuration conflict", "The baseband capability is insufficient", or "Insufficient IDX2 bandwidth", the system automatically configures the specified baseband equipment or CPRI/eCPRI direct interconnection baseband equipment for the cell. In addition, the system resets all the cells deployed on the baseband equipment serving the cell reporting the alarm with the preceding cause and deploys these cells again.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If NrDuCellId is specified in this command, this command takes effect when the NR DU cell reports ALM-29870 NR DU Cell TRP Unavailable with the cause being "Configuration conflict", "The BBP capability is insufficient", or "Insufficient IDX2 bandwidth."

  • The following will be reset and then deployed again: all TRPs of the cell, other cells whose cell instance status is normal on the baseband equipment bound to the cell TRP generating the alarm (when the cell TRP is bound to a baseband equipment) or the baseband equipment directly connected to the cell TRP over the CPRI/eCPRI port (when the cell TRP is not bound to any baseband equipment), and other cells whose cell instance status is normal on the baseband equipment where the faulty cell TRP resides.

  • When NrDuCellId is not specified in this command, automatic reset and redeployment are triggered for all TRPs and cells associated with faulty cells that meet the preceding conditions.

  • The DSP NRDUCELLANTENNA command can be executed to query the information about the baseband equipment serving the faulty cell TRP. If there are multiple sets of baseband equipment with the same fault, only the first faulty baseband equipment is displayed, and the redeployment is performed only on this baseband equipment.

  • The cell setup process takes a long time. You can run the DSP DUCELL command to query the cell status during the redeployment. The latest operation type that causes the DU cell unavailable is cell reconfiguration.

  • If this command is executed again during cell redeployment, the execution will fail with the cause value "An NR DU cell baseband resource re-deployment task already starts."

  • After this command is executed, cells that meet the conditions are redeployed. However, the cells may not return to normal after they are redeployed. If the problem persists after multiple redeployment operations, contact Huawei technical support.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To start the re-deploy of NR DU cell, NR DU Cell ID is 0, run the following command:
STR NRDUCELLREDEPLOY: NrDuCellId=0;
