Modify NR DU Cell UE Cooperation Configurations (MOD NRDUCELLUECOOP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify NR DU cell UE cooperation configurations.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SpecUeCooperationSwitch Specified UE Cooperation Switch

Meaning: Indicates whether to enable device-pipe synergy for specific UEs.

SPEC_UE_IDENTIFY_SW: Indicates whether to identify specific UEs. If this option is selected, the gNodeB identifies UEs supporting device-pipe synergy in the cell. If this option is deselected, the gNodeB does not identify UEs supporting device-pipe synergy in the cell.

GUI Value Range: SPEC_UE_IDENTIFY_SW(Specific UE Identification Switch)

Unit: None

Actual Value Range: SPEC_UE_IDENTIFY_SW

MML Default Value: None

Recommended Value: SPEC_UE_IDENTIFY_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SPEC_UE_IDENTIFY_SW: If this option is deselected, network performance is not affected. If this option is selected, the gNodeB broadcasts the identification information about specific UEs through system information, slightly increasing the downlink RB usage and decreasing the UE access delay.

Applicable Mode: N
UEAccessSwitch UE Access Switch

Meaning: Indicates whether to enable UE access.

80M_UE_ACCESS_SW: Indicates whether UEs with a bandwidth of 80 MHz can access a 100 MHz cell. If this option is selected, UEs with a bandwidth of 80 MHz can access a 100 MHz cell. If this option is deselected, UEs with a bandwidth of 80 MHz cannot access a 100 MHz cell. This option applies only in TDD low frequency bands.

GUI Value Range: 80M_UE_ACCESS_SW(80 MHz UE Access Switch)

Unit: None

Actual Value Range: 80M_UE_ACCESS_SW

MML Default Value: None

Recommended Value: 80M_UE_ACCESS_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: 80M_UE_ACCESS_SW: If this option is selected, UEs with a bandwidth of 80 MHz can access a 100 MHz cell. If this option is deselected, UEs with a bandwidth of 80 MHz cannot access a 100 MHz cell.

Applicable Mode: N-TDD-FR1

Example

To modify NR DU cell UE cooperation configurations with the parameters as follows: NR DU Cell ID:88, Specific UE Identification Switch:On, run the following command:
MOD NRDUCELLUECOOP: NrDuCellId=88, SpecUeCooperationSwitch=SPEC_UE_IDENTIFY_SW-1;
