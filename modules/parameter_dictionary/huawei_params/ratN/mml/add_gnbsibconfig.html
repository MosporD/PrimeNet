Add gNodeB System Information Configuration (ADD GNBSIBCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add gNodeB system information configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

For gNBSibConfig MO instances corresponding to SibPolicyId and with the minimum value of SibTransPeriod set to 320MS, the number of MO instances indicated by SibType is less than or equal to 4. When the ADD GNBSIBCONFIG command is executed to add the fifth SibType, an error message is displayed. For gNBSibConfig MO instances corresponding to SibPolicyId and with the minimum value of SibTransPeriod set to 640MS, the number of MO instances indicated by SibType is less than or equal to 8. When the ADD GNBSIBCONFIG command is executed to add the ninth SibType, an error message is displayed.

Parameters

ID Name Description
SibConfigId SIB Config ID

Meaning: Indicates the ID of a set of system information configuration, including the system information type, system information transmission period, and system information transmission mode.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SibType SIB Type

Meaning: Indicates the system information type. For details about this parameter, see 3GPP TS 38.331.

GUI Value Range: SIB_TYPE_2(Cell Reselection Common Information), SIB_TYPE_3(Intra-freq Cell Reselection Information), SIB_TYPE_4(Inter-freq Cell Reselection Information), SIB_TYPE_5(Inter-RAT Cell Reselection Information), SIB_TYPE_9(GPS and UTC Time Information)

Unit: None

Actual Value Range: SIB_TYPE_2, SIB_TYPE_3, SIB_TYPE_4, SIB_TYPE_5, SIB_TYPE_9

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SibTransPeriod SIB Transmission Period

Meaning: Indicates the system information transmission period. For details about this parameter, see 3GPP TS 38.331.

GUI Value Range: 320MS(320), 640MS(640)

Unit: ms

Actual Value Range: 320MS, 640MS

MML Default Value: None

Recommended Value: 320MS when SibType is set to SIB_TYPE_2

320MS when SibType is set to SIB_TYPE_3

320MS when SibType is set to SIB_TYPE_4

640MS when SibType is set to SIB_TYPE_5

320MS when SibType is set to SIB_TYPE_9

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter SIB transmission period, higher occupied resource overhead, shorter delay in SIB reading, and fewer SIB types that can be enabled. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
SibTransPolicy SIB Transmission Policy

Meaning: Indicates the system information transmission mode. The value OFF indicates that system information of a SIB type cannot be broadcast. The value BROADCAST indicates that system information of a SIB type is broadcast continuously. The value ON_DEMAND indicates that system information of a SIB type can be broadcast only after being subscribed by UEs. For details about this parameter, see 3GPP TS 38.331.

GUI Value Range: OFF(Off), BROADCAST(Broadcast), ON_DEMAND(On Demand)

Unit: None

Actual Value Range: OFF, BROADCAST, ON_DEMAND

MML Default Value: None

Recommended Value: BROADCAST when SibType is set to SIB_TYPE_2

BROADCAST when SibType is set to SIB_TYPE_3

BROADCAST when SibType is set to SIB_TYPE_4

BROADCAST when SibType is set to SIB_TYPE_5

OFF when SibType is set to SIB_TYPE_9

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to OFF, system information of the corresponding SIB type cannot be broadcast. If this parameter is set to BROADCAST, system information of the corresponding SIB type is broadcast continuously. If this parameter is set to ON_DEMAND, system information of the corresponding SIB type can be broadcast only after being subscribed by UEs. When this parameter is set to ON_DEMAND, the system overhead and energy consumption are lower in light load scenarios but the UE access duration is longer in heavy load scenarios than those when this parameter is set to BROADCAST.

Applicable Mode: N

Example

To add gNodeB system information configuration with the parameters as follows: SIB Config ID:1, SIB Type:SIB_TYPE_2, SIB Transmission Period:640MS, SIB Transmission Policy:BROADCAST, run the following command:
ADD GNBSIBCONFIG: SibConfigId=1, SibType=SIB_TYPE_2, SibTransPeriod=640MS, SibTransPolicy=BROADCAST;
