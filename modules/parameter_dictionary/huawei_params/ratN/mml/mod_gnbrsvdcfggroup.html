Modify gNodeB Commissioning Reserved Parameter Group Configuration (MOD GNBRSVDCFGGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a reserved parameter group for gNodeB commissioning.

Note

None.

Example

To modify the configuration of reserved parameter group of gNodeB with the parameters as follows: Rsvd Parameter Group ID: 1, Rsvd Identify Flag: 1, run the following command:
MOD GNBRSVDCFGGROUP: RsvdParamGroupId=1, RsvdIdentifyFlag=1;
