List CA Management Configuration for NR Cell (LST NRCELLCAMGMTCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the settings of parameters related to CA carrier management in an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the CA management configuration of an NR cell with NR Cell ID set to 3, run the following command:
LST NRCELLCAMGMTCONFIG: NrCellId=3;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

CA A2 RSRP Threshold(dBm)

Indicates the RSRP threshold for triggering event A2 in a CA SCell. When the RSRP measured by a UE is below this threshold, event A2 is reported.

CA A5 RSRP Threshold 2(dBm)

Indicates the RSRP threshold 2 for triggering event A5 in a CA SCell. If the signal quality of the serving cell is less than -31 dBm and the measured RSRP of a neighboring cell is greater than this threshold, UEs report event A5.

CA A6 Offset(0.5dB)

Indicates the offset between the signal quality of a neighboring cell and that of the serving cell, which is used to determine whether to report event A6 in an SCell.

CA Strategy Switch

Indicates the CA strategy switches.

SCC_BLIND_CONFIG_SW(SCC Blind Configuration Switch):

Indicates whether to allow blind SCell configuration. When this option is selected, candidate cells can be configured as SCells for CA UEs without measurement. When this option is deselected, candidate cells can be configured as SCells for CA UEs only based on event A5 measurement results of the corresponding SCCs.
