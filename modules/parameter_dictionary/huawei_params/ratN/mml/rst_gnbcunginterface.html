Reset gNodeB CU NG Interface (RST GNBCUNGINTERFACE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to restart the gNodeB CU NG interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

After this command is executed, all UEs carried on this NG interface will be released.

Parameters

ID Name Description
gNBCuNgInterfaceId gNodeB CU NG Interface ID

Meaning: Indicates the ID of a gNodeB CU NG interface.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To reset the gNodeB CU NG interface with gNodeB CU NG Interface ID set to 0, run the following command:
RST GNBCUNGINTERFACE: gNBCuNgInterfaceId=0;
