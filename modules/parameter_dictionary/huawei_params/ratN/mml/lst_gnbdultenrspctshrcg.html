List LTE and NR Spectrum Sharing Cell Set Configuration (LST GNBDULTENRSPCTSHRCG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query configurations of an LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
NrSpctShrCellGrpId NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • LteSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.
  • NrSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To list the configuration for an LTE and NR spectrum sharing cell set with NR Spectrum Sharing Cell Group ID set to 11, run the following command:
LST GNBDULTENRSPCTSHRCG: NrSpctShrCellGrpId=11;
The result is shown as follows:

Output Description

Field Description

NR Spectrum Sharing Cell Group ID

Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.

LTE Spectrum Sharing Cell Group ID

Indicates the ID of an LTE spectrum sharing cell group, which uniquely identifies the LTE spectrum sharing cell group within a gNodeB.

LTE and NR Uplink Spectrum Sharing Mode

Indicates the mode of uplink spectrum sharing between LTE FDD and NR. This parameter applies only to NR SUL. Disuse statement: This parameter will be deleted in later versions. In this version, configuration synchronization and delivery of this parameter are still supported on interfaces. Therefore, avoid using this parameter.

NR Reserved RB Start Index

Indicates the index of the start RB among the RBs reserved for NR when LTE TDD and NR spectrum sharing is enabled. This parameter, together with NrReservedRbEndIndex, specify the range of RBs reserved for NR. If the range of RBs reserved for NR exceeds the range of RBs corresponding to the NR cell bandwidth, the range of RBs corresponding to the NR cell bandwidth is reserved for NR. This parameter applies only to low-frequency TDD cells.

NR Reserved RB End Index

Indicates the index of the end RB among the RBs reserved for NR when LTE TDD and NR spectrum sharing is enabled. This parameter, together with NrReservedRbStartIndex, specify the range of RBs reserved for NR. If the range of RBs reserved for NR exceeds the range of RBs corresponding to the NR cell bandwidth, the range of RBs corresponding to the NR cell bandwidth is reserved for NR. This parameter applies only to low-frequency TDD cells.

PRB Usage Threshold(%)

Indicates the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. If the PRB usage on the NR side is greater than the sum of the PRB usage threshold and the PRB usage threshold offset, the NR side uses spectrum shared with the LTE side. If the PRB usage on the NR side is smaller than or equal to the PRB usage threshold minus the PRB usage threshold offset, the NR side shares out spectrum shared with the LTE side. This parameter applies only to low-frequency TDD cells.

PRB Usage Threshold Offset(%)

Indicates the offset relative to the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. If the PRB usage is greater than the sum of the PRB usage threshold and the PRB usage threshold offset, the NR side uses spectrum shared with the LTE side. If the PRB usage is less than or equal to the PRB usage threshold minus the PRB usage threshold offset, the NR side shares out spectrum shared with the LTE side. This parameter applies only to low-frequency TDD cells.
