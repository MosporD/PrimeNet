List gNodeB Air Interface Security Parameters (LST GNBAIRINTFSECPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list gNodeB air interface security parameters.

Note

None.

Parameters

None.

Example

To list the air interface security parameters of the gNodeB, run the following command:
LST GNBAIRINTFSECPARAM:;
The result is shown as follows:
+++    0        2019-06-29 16:28:38
O&M    #2685403138
%%LST GNBAIRINTFSECPARAM:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Air Interface Security Parameters
---------------------------------------------
                 Counter Check Switch  =  Disable
Unauthenticated Emergency Call Switch  =  Disable
(Number of results = 1)


---    END

Output Description

Field Description

Counter Check Switch

Indicates whether to enable counter check.

The value DISABLE indicates that PDCP counter check is disabled.

The value ENABLE_NOT_RELEASE indicates that PDCP counter check is enabled. When the DRB counter check is abnormal, the corresponding bearer is not released.

The value ENABLE_RELEASE_DRB indicates that PDCP counter check is enabled. When the DRB counter check is abnormal, the corresponding bearer is released. For details about this parameter, see 3GPP TS 33.401 and 3GPP TS 33.501.

Unauthenticated Emergency Call Switch

Indicates whether to allow unauthenticated emergency calls. The value ENABLE indicates that unauthenticated emergency calls are allowed. When this function is enabled, NEA0 and NIA0 (null ciphering and integrity protection algorithms) can be used during an unauthenticated emergency call. That is, an unauthenticated emergency call can be conducted irrespective of whether the NEA0 and NIA0 are enabled. The value DISABLE indicates that unauthenticated emergency calls are prohibited.
