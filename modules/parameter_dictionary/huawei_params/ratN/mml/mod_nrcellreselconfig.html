Modify NR Cell Reselection Parameter Configurations (MOD NRCELLRESELCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify parameter configurations related to NR cell reselection.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
MinimumRxLevel Minimum RX Level

Meaning: Indicates the minimum RX level required for a reselection to an intra-frequency neighboring cell, which corresponds to the q-RxLevMin IE of intra-frequency neighboring cell in SIB2. For details, see 3GPP TS 38.331.

GUI Value Range: -70~-22

Unit: 2dBm

Actual Value Range: -140~-44

MML Default Value: None

Recommended Value: -64

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter indicates a lower requirement for reselection to a neighboring cell, which means that an intra-frequency neighboring cell is more likely to become a suitable cell. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
IntraFreqMeasStartThld Intra-Freq Measurement Start Threshold

Meaning: Indicates the measurement triggering threshold for intra-frequency cell reselection, which corresponds to the s-IntraSearchP IE in SIB2. For details, see 3GPP TS 38.331.

GUI Value Range: 0~31

Unit: 2dB

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 29

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of intra-frequency cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of starting intra-frequency measurements, lower probability of triggering intra-frequency reselection, and delayed intra-frequency reselection. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CellReselHysteresis Cell Reselection Hysteresis

Meaning: Indicates the hysteresis for the measured RSRP value of the serving cell during cell reselection, which corresponds to the q-Hyst IE in SIB2. For details, see 3GPP TS 38.331.

GUI Value Range: DB0(0dB), DB1(1dB), DB2(2dB), DB3(3dB), DB4(4dB), DB5(5dB), DB6(6dB), DB8(8dB), DB10(10dB), DB12(12dB), DB14(14dB), DB16(16dB), DB18(18dB), DB20(20dB), DB22(22dB), DB24(24dB)

Unit: dB

Actual Value Range: DB0, DB1, DB2, DB3, DB4, DB5, DB6, DB8, DB10, DB12, DB14, DB16, DB18, DB20, DB22, DB24

MML Default Value: None

Recommended Value: DB4(4dB)

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter indicates easier intra-frequency or inter-frequency reselection of the same priority but a higher probability of ping-pong reselections. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CellReselPriority Cell Reselection Priority

Meaning: Indicates the cell reselection priority of the serving frequency. Value 0 indicates the lowest priority. This parameter corresponds to the cellReselectionPriority IE in SIB2. For details, see 3GPP TS 38.331. The value of this parameter must be determined together with the priorities of other frequencies during network planning.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher probability of cell reselection to other frequencies. A larger value leads to a lower probability of cell reselection to other frequencies.

Applicable Mode: N
EutranCellReselTimer E-UTRAN Cell Reselection Timer

Meaning: Indicates the timer used for E-UTRAN cell reselection. A UE initiates E-UTRAN cell reselection if the signal quality of the serving cell and that of the E-UTRAN cell constantly meet reselection threshold requirements before the timer expires and the UE has stayed in the serving cell for more than one second. If this parameter is set to 255, the UE in an NR cell is not reselected to the E-UTRAN cell.

GUI Value Range: 0~7,255

Unit: s

Actual Value Range: 0~7,255

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a higher probability that UEs in the serving cell initiate reselections but also a high probability of ping-pong reselections. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
NonIntraFreqMeasRsrpThld Non-Intra-Freq Measurement RSRP Threshold

Meaning: Indicates the threshold for triggering inter-frequency or inter-RAT cell reselection measurements. If the cell reselection priority of a neighboring NR frequency or an E-UTRAN frequency is higher than that of the serving frequency, UEs always start inter-frequency or inter-RAT cell reselection measurements. If the cell reselection priority of a neighboring NR frequency or an E-UTRAN frequency is lower than or equal to that of the serving frequency, UEs start inter-frequency or inter-RAT cell reselection measurements only when the value of Cell selection RX level value (dB) is less than or equal to the value of this parameter. This parameter corresponds to the SNonIntraSearchP IE in 3GPP TS 38.304.

GUI Value Range: 0~31

Unit: 2dB

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 9

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering measurement in inter-RAT cell reselection. A larger value of this parameter leads to the opposite effect.

Applicable Mode: N
ServFreqLowPriRsrpReselThd Serving Freq Low Priority RSRP Resel Thld

Meaning: Indicates the threshold used in the evaluation of reselection to a low-priority inter-frequency or inter-RAT cell. Reselection to a low-priority inter-frequency or inter-RAT cell is performed if no cell on the serving frequency or on a high-priority frequency fulfills criteria 1 for inter-frequency or inter-RAT reselection. This parameter corresponds to the ThreshServingLowP IE in 3GPP TS 38.304.

GUI Value Range: 0~31

Unit: 2dB

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of reselection to a low-priority inter-frequency or an inter-RAT cell. A larger value of this parameter results in a higher probability of reselection to a low-priority inter-frequency or an inter-RAT cell.

Applicable Mode: N

Example

To modify the NR cell reselection configuration with the parameters as follows: NR Cell ID: 0, Cell Reselection Hysteresis: 1DB, run the following command:
MOD NRCELLRESELCONFIG: NrCellId=0, CellReselHysteresis=DB1;
