Modify Common gNodeB Mobility Parameters (MOD GNBMOBILITYCOMMPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify common gNodeB mobility parameters.

Note

None.

Parameters

ID Name Description
NecHoPrepFailPunishTimer Necessary HO Prepare Fail Punish Timer

Meaning: Indicates the penalty timer applied to handover (EPS fallback, coverage-based intra-RAT handover, or coverage-based inter-RAT handover) to a target cell. If a handover preparation fails due to resource-related causes, the handover to the target cell is prohibited within the timer. If this parameter is set to 0, penalty is not performed.

GUI Value Range: 0~50

Unit: s

Actual Value Range: 0~50

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a larger number of invalid handover requests initiated after handover preparations fail due to resource-related causes. A larger value of this parameter results in a smaller number of invalid handover requests. However, the UE may experience service drops due to delayed handovers.

Applicable Mode: N
OptHoPrepFailPunishTimer Optimized HO Prepare Fail Punish Timer

Meaning: Indicates the penalty timer applied to handover (frequency-priority-based handover) to a target cell. If a handover preparation fails due to resource-related causes, the handover to the target cell is prohibited within the timer. If this parameter is set to 0, penalty is not performed.

GUI Value Range: 0~600

Unit: s

Actual Value Range: 0~600

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
NonResHoPrepFailPunishTimes Non-Res HO Prepare Fail Punish Times

Meaning: Indicates the number of times penalty is performed following non-resource-related handover preparation failures. If a handover preparation fails due to non-resource-related causes during a handover to the target cell, the gNodeB prohibits the UE from being handed over to the target cell based on the number of penalty times. If this parameter is set to 0, the gNodeB does not impose a penalty on the target cell after a handover preparation fails due to non-resource-related causes.

GUI Value Range: 0~200

Unit: time

Actual Value Range: 0~200

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller number of penalty times and a larger number of invalid handover requests initiated after handover preparations fail due to non-resource-related causes. A larger value of this parameter results in a smaller number of invalid handover requests. However, a large number of penalty times may cause service drops for UEs due to delayed handovers.

Applicable Mode: N
MaxNumHoFwdPdcpPktWithSn Max Num of HO Fwd PDCP Pkt with SN

Meaning: Indicates the maximum number of PDCP packets that can be forwarded with SNs during handovers when the PDCP SN size is less than 18 bits.

GUI Value Range: 1~2000

Unit: None

Actual Value Range: 1~2000

MML Default Value: None

Recommended Value: 200

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, the data rates of UEs may decrease during handovers, resulting in repeated packet delivery. If this parameter is set to a large value, HFN flipping may occur for UEs during handovers when the transmission link is unstable, resulting in user-plane service failures. If the parameter setting matches the inter-site transmission quality, the user-perceived rate can be effectively improved.

Applicable Mode: N
PdcpHoTransMaxRate Max Rate of PDCP HO Trans

Meaning: Indicates the maximum rate at which PDCP data is forwarded during intra-RAT inter-gNodeB handovers. If this parameter is set to 65535, it does not take effect and PDCP data is forwarded at the maximum rate supported by the system. It is recommended that this parameter be set to a value not greater than the maximum rate allowed by the physical transmission bandwidth of the link. Otherwise, packet loss may occur in the forwarded data during handovers.

GUI Value Range: 1~100,65535

Unit: 100Mbps

Actual Value Range: 100~10000,65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower transmission rate of PDCP data forwarded during handovers. A larger value of this parameter leads to a higher transmission rate.

Applicable Mode: N
WaitNsaDcUePdcpStsRptTmr Wait NSA DC UE PDCP Status Report Timer

Meaning: Indicates the length of the timer that governs the period in which the base station waits for a PDCP status report from an NSA-DC-capable UE. In data forwarding scenarios triggered by an NSA UE handover or SCG addition or deletion, the base station starts this timer. If the base station already receives the PDCP status report from the UE before the timer expires, the base station no longer sends the correctly received packets. If the base station does not receive the PDCP status report from the UE before the timer expires, the base station retransmits all packets forwarded by the source base station.

GUI Value Range: 20~200

Unit: ms

Actual Value Range: 20~200

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer period in which the base station waits for a PDCP status report from an NSA-DC-capable UE and a higher probability that the number of retransmitted data packets decreases. If the UE does not report the PDCP status, the downlink data rate decreases. A smaller value of this parameter results in a shorter period in which the base station waits for a PDCP status report from an NSA-DC-capable UE and a higher probability that the number of retransmitted data packets increases. As a result, the UE receives more duplicate data packets.

Applicable Mode: N
HoPduSessConflHandlingSw HO and PDU Session Conflict Handling Sw

Meaning: Indicates switches of handling conflicts between intra-RAT and inter-RAT outgoing handover preparation and PDU session procedures.

VOICE_FB_FIRST_SWITCH: Indicates whether the NG-RAN preferentially processes voice fallbacks when a voice fallback request is received during an outgoing handover preparation procedure. When this option is selected, voice fallbacks are preferentially processed. If this option is deselected, outgoing handovers are preferentially processed.

GUI Value Range: VOICE_FB_FIRST_SWITCH(Voice Fallback First Switch)

Unit: None

Actual Value Range: VOICE_FB_FIRST_SWITCH

MML Default Value: None

Recommended Value: VOICE_FB_FIRST_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: VOICE_FB_FIRST_SWITCH(Voice Fallback First Switch): When this option is selected, the NG-RAN cancels the handover procedure and preferentially processes voice fallbacks once a voice fallback request is received during the outgoing handover preparation procedure. This setting may delay handovers, increase the service drop rate, and decrease the handover success rate. However, if the outgoing handover preparation procedure conflicts with the voice fallback procedure, this setting increases the voice-fallback call setup success rate. If this option is deselected, the NG-RAN preferentially processes outgoing handovers, decreasing the voice-fallback call setup success rate.

Applicable Mode: N

Example

To modify common gNodeB mobility parameters with Necessary HO Prepare Fail Punish Timer set to 12, Optimized HO Prepare Fail Punish Timer set to 12, Non-Res HO Prepare Fail Punish Times set to 12, Max Num of HO Fwd PDCP Pkt with SN set to 200, Max Rate of PDCP HO Trans set to 100, and Wait NSA DC UE PDCP Status Report Timer set to 20, and run the following command:
MOD GNBMOBILITYCOMMPARAM: NecHoPrepFailPunishTimer=12, OptHoPrepFailPunishTimer=12, NonResHoPrepFailPunishTimes=12, MaxNumHoFwdPdcpPktWithSn=200, PdcpHoTransMaxRate=100, WaitNsaDcUePdcpStsRptTmr=20;
