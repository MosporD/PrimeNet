Modify NR Cell (MOD NRCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configurations of an NR cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the current NR cell serves as a neighboring cell of another intra-gNodeB cell, the values of the CellId cannot be modified for the current cell.

  • An NRCell MO defines information such as the cell ID. It is configured by network planning engineers based on site requirements.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellName Cell Name

Meaning: Indicates the name of an NR cell.

GUI Value Range: 1~99 characters

Unit: None

Actual Value Range: 1~99 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of CellName in an NRCell MO is a string of a maximum of 99 characters. The string cannot be all null characters or contain any of the following characters: double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
CellId Cell ID

Meaning: Indicates the cell ID of an NR cell. A cell ID and a gNodeB ID compose a 3GPP-defined NR Cell Identity (NCI). A 3GPP-defined NCI and a PLMN ID compose an NR cell global identifier (NCGI). For details, see 3GPP TS 38.413.

GUI Value Range: 0~16383

Unit: None

Actual Value Range: 0~16383

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of CellId in different NRCell MOs configured for a gNodeB must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
FrequencyBand Frequency Band

Meaning: Indicates the frequency band in which an NR cell operates. For details, see 3GPP TS 38.104.

GUI Value Range: N1(n1), N2(n2), N3(n3), N5(n5), N7(n7), N8(n8), N20(n20), N25(n25), N28(n28), N38(n38), N40(n40), N41(n41), N66(n66), N71(n71), N77(n77), N78(n78), N79(n79), N257(n257), N258(n258), N260(n260), N261(n261)

Unit: None

Actual Value Range: N1, N2, N3, N5, N7, N8, N20, N25, N28, N38, N40, N41, N66, N71, N77, N78, N79, N257, N258, N260, N261

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When FrequencyBand in an NRCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, DuplexMode in the NRCell MO must be set to CELL_FDD.
  • In an NRCell MO, if FrequencyBand is set to N38, N40, N41, N77, N78, N79, N257, N258, N260, or N261, DuplexMode must be set to CELL_TDD.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
DuplexMode Duplex Mode

Meaning: Indicates the duplex mode of an NR cell. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode.

GUI Value Range: CELL_FDD(FDD), CELL_TDD(TDD)

Unit: None

Actual Value Range: CELL_FDD, CELL_TDD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When FrequencyBand in an NRCell MO is set to N1, N2, N3, N5, N7, N8, N20, N25, N28, N66, or N71, DuplexMode in the NRCell MO must be set to CELL_FDD.
  • In an NRCell MO, if FrequencyBand is set to N38, N40, N41, N77, N78, N79, N257, N258, N260, or N261, DuplexMode must be set to CELL_TDD.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UserLabel User Label

Meaning: Indicates the user label of an NR cell.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the configuration of an NR cell with the parameters as follows: NR Cell ID: 0, Cell Name: 5g_0, run the following command:
MOD NRCELL: NrCellId=0, CellName="5g_0";
