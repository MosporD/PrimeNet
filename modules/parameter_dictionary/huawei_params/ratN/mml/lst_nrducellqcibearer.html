List NR DU Cell QCI Bearer (LST NRDUCELLQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the bearer configuration of an NR DU cell. The configurations can be listed for bearers based on their QCIs.

Note

None.

Output Description

Field Description

NR DU Cell ID

Indicates the ID of a local cell, which uniquely identifies the NR DU cell within a gNodeB.

QoS Class Identifier

Indicates the QoS class identifier of radio bearers.

MAC Parameter Group ID

Indicates the ID of a MAC parameter group.

AM RLC Parameter Group ID

Indicates the ID of an RLC parameter group in AM mode.

UM RLC Parameter Group ID

Indicates the ID of an RLC parameter group in UM mode.

UE Inactivity Timer(s)

Indicates the length of the UE inactivity timer in which the gNodeB monitors whether a UE transmits and receives data. If the gNodeB detects that a UE has neither received nor sent data within the timer length, the gNodeB checks whether the RRC_INACTIVE state takes effect for the UE. If it does, the UE state is changed to RRC_INACTIVE. If it does not, the UE is released. If this parameter is set to 0, the gNodeB releases the UE if it does not receive or send data for 3600s.

DU DRX Parameter Group ID

Indicates the ID of a DRX parameter group of an NR DU cell. If this parameter is set to 0 to 63, the QCI has valid DRX parameters. If this parameter is set to 255, DRX is disabled for the QCI.
