Display gNodeB CU Xn (DSP GNBCUXN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the information about the Xn interface managed by the gNodeB CU Xn object. The DSP GNBCUXN command output does not include user-plane information.

Note

None.

Parameters

ID Name Description
gNBCuXnId gNodeB CU Xn ID

Meaning: Indicates the ID of a gNodeB CU Xn object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the configuration of the gNodeB CU Xn object, run the following command:
DSP GNBCUXN:;
The result is shown as follows:
+++    0        2018-09-15 09:12:55
O&M    #2685403141
%%DSP GNBCUXN:;%%
RETCODE = 0  Operation succeeded.

Display gNodeB CU Xn
--------------------
                       gNodeB CU Xn ID  =  0
             gNodeB CU Xn Interface ID  =  0
          gNodeB CU Xn Interface State  =  Abnormal
   gNodeB CU Xn Interface CP Bearer ID  =  70006
gNodeB CU Xn Interface CP Bearer State  =  Abnormal
(Number of results = 1)


---    END

Output Description

Field Description

gNodeB CU Xn ID

Indicates the ID of a gNodeB CU Xn object.

gNodeB CU Xn Interface ID

Indicates the ID of a gNodeB CU Xn interface.

gNodeB CU Xn Interface State

Indicates the state of a gNodeB CU Xn interface.

gNodeB CU Xn Interface CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU Xn interface.

gNodeB CU Xn Interface CP Bearer State

Indicates the state of the bottom-layer CP bearer of a gNodeB CU Xn interface.
