Add gNodeB Debugging Message Matching Rule (ADD GNBABNMSGMATCHRULE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB debugging message matching rule.

Note

  • The parameters in this command must be modified under the guidance of Huawei technical support. This command must be executed under the guidance of Huawei technical support.

  • After the upgrade, if the problem resolved by gNBAbnMsgMatchRule before the upgrade persists, reconfigure the gNBAbnMsgMatchRule MO for the new version.

Parameters

Example

To add a gNodeB debugging message matching rule with Match Rule Index set to 1, Match Field Offset set to 24, Match Length set to 2, and Match Content set to 00, run the following command:
ADD GNBABNMSGMATCHRULE: MatchRuleIndex=1, MatchFieldOffset=24, MatchLen=2, MatchContent="00";
