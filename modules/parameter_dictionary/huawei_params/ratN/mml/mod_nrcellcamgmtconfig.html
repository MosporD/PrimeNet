Modify CA Management Configuration for NR Cell (MOD NRCELLCAMGMTCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of parameters related to CA carrier management in an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CaA2RsrpThld CA A2 RSRP Threshold

Meaning: Indicates the RSRP threshold for triggering event A2 in a CA SCell. When the RSRP measured by a UE is below this threshold, event A2 is reported.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -109

Parameter Relationship:

-Configuration constraints:

  • The value of CaA5RsrpThld2 in the NRCellCaMgmtConfig MO must be greater than the value of CaA2RsrpThld in the NRCellCaMgmtConfig MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The larger the value of this parameter, the higher the effective event A2 triggering threshold in CA and the more likely the SCells can be deleted for CA UEs. The smaller the value of this parameter, the lower the effective event A2 triggering threshold in CA and the less likely the SCells can be deleted for CA UEs.

Applicable Mode: N
CaA5RsrpThld2 CA A5 RSRP Threshold 2

Meaning: Indicates the RSRP threshold 2 for triggering event A5 in a CA SCell. If the signal quality of the serving cell is less than -31 dBm and the measured RSRP of a neighboring cell is greater than this threshold, UEs report event A5.

GUI Value Range: -156~-31

Unit: dBm

Actual Value Range: -156~-31

MML Default Value: None

Recommended Value: -105

Parameter Relationship:

-Configuration constraints:

  • The value of CaA5RsrpThld2 in the NRCellCaMgmtConfig MO must be greater than the value of CaA2RsrpThld in the NRCellCaMgmtConfig MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The larger the value of this parameter, the higher the effective event A5 triggering threshold 2 in CA and the less likely the SCells can be configured for CA UEs. The smaller the value of this parameter, the lower the effective event A5 triggering threshold 2 in CA and the more likely the SCells can be configured for CA UEs.

Applicable Mode: N
CaA6Offset CA A6 Offset

Meaning: Indicates the offset between the signal quality of a neighboring cell and that of the serving cell, which is used to determine whether to report event A6 in an SCell.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a small value, event A6 is reported even when the signal quality of a neighboring cell is slightly better that of the serving cell. If this parameter is set to a large value, event A6 is reported when the signal quality of a neighboring cell is much better than that of the serving cell.

Applicable Mode: N
CaStrategySwitch CA Strategy Switch

Meaning: Indicates the CA strategy switches.

SCC_BLIND_CONFIG_SW(SCC Blind Configuration Switch):

Indicates whether to allow blind SCell configuration. When this option is selected, candidate cells can be configured as SCells for CA UEs without measurement. When this option is deselected, candidate cells can be configured as SCells for CA UEs only based on event A5 measurement results of the corresponding SCCs.

GUI Value Range: SCC_BLIND_CONFIG_SW(SCC Blind Configuration Switch)

Unit: None

Actual Value Range: SCC_BLIND_CONFIG_SW

MML Default Value: None

Recommended Value: SCC_BLIND_CONFIG_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SCC_BLIND_CONFIG_SW(SCC Blind Configuration Switch):

When this option is selected and SCell coverage is poor, the transmission efficiency over the air interface is low in SCells for CA UEs, decreasing the throughput in the SCells. When this option is deselected, SCCs are added for CA UEs based on measurement results.

Applicable Mode: N

Example

To modify the CA Management configuration, NR Cell ID: 3, CA A2 RSRP Threshold: -109, CA A5 RSRP Threshold 2: -105, CA A6 Offset: 2, CA Strategy Switch: Off, run the following command:
MOD NRCELLCAMGMTCONFIG: NrCellId=3, CaA2RsrpThld=-109, CaA5RsrpThld2=-105, CaA6Offset=2, CaStrategySwitch=SCC_BLIND_CONFIG_SW-0;
