Add gNodeB RFSP Configuration (ADD GNBRFSPCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add gNodeB RFSP parameter configurations.

Note

None.

Parameters

ID Name Description
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
RfspIndex Index to RAT/Frequency Selection Priority

Meaning: Indicates the RAT/frequency selection priority (RFSP), which is equivalent to the subscriber profile ID (SPID) in LTE protocols. If this parameter is set to 0, the gNodeB does not obtain the RFSP from the AMF or the gNodeB is not configured with an RFSP for UEs. For details about this parameter, see 3GPP TS 23.501.

GUI Value Range: 0~256

Unit: None

Actual Value Range: 0~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
MlbAlgoSwitch MLB Algorithm Switch

Meaning: Indicates whether to enable the load balancing algorithm for UEs with a specific RFSP index of an operator.

INTER_FREQ_CONNECTED_MLB_SW: If this option is selected, UEs with the RFSP index of an operator in a cell enabled with the MLB algorithm can be transferred to a light-load cell on a different frequency for inter-frequency load balancing purposes. If this option is deselected, inter-frequency load balancing operations are not allowed for UEs with the RFSP index of an operator.

GUI Value Range: INTER_FREQ_CONNECTED_MLB_SW(Inter-freq MLB Sw for Connected Mode)

Unit: None

Actual Value Range: INTER_FREQ_CONNECTED_MLB_SW

MML Default Value: None

Recommended Value: INTER_FREQ_CONNECTED_MLB_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: INTER_FREQ_CONNECTED_MLB_SW:

If this option is deselected, inter-frequency MLB is disabled for UEs with the RFSP index of an operator. In this case, traffic cannot be offloaded from a heavy-load local cell to a light-load neighboring cell on a different frequency that can carry more services. Therefore, the probability of overload increases, and the access success rate and the total traffic volume decrease. Selecting this option results in the opposite effects.

Applicable Mode: N
HoPolicy Handover Policy

Meaning: Indicates the handover policy control switch.

TARGET_CELL_LOAD_EVAL_SW: Indicates whether to consider the load of a candidate cell during operator-specific priority-based inter-frequency handovers. If this option is selected, the gNodeB does not consider the load and load balancing status of a candidate cell during operator-specific priority-based inter-frequency handovers. If this option is deselected, the gNodeB obtains the load and load balancing status of a candidate cell prior to an operator-specific priority-based inter-frequency handover. If load balancing has been triggered in a candidate cell and the load of the candidate cell is higher than that of the serving cell, the gNodeB does not select the candidate cell as the target cell for an operator-specific priority-based inter-frequency handover.

GUI Value Range: TARGET_CELL_LOAD_EVAL_SW(Target Cell Load Evaluation Switch)

Unit: None

Actual Value Range: TARGET_CELL_LOAD_EVAL_SW

MML Default Value: None

Recommended Value: TARGET_CELL_LOAD_EVAL_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: TARGET_CELL_LOAD_EVAL_SW: If this option is selected, operator-specific priority-based inter-frequency handovers do not require load balancing in candidate cells, implementing UE steering. However, the number of invalid handovers may increase, decreasing UE rates. If this option is deselected and load balancing is enabled through NRCELLALGOSWITCH.MlbAlgoSwitch for candidate cells for operator-specific priority-based inter-frequency handovers, the gNodeB determines whether to perform a handover based on the load status of the candidate cell. This reduces the number of ping-pong handovers and has no impact on UE rates.

Applicable Mode: N

Example

To add the gNodeB RFSP configuration with Operator ID set to 0 and Index to RAT/Frequency Selection Priority set to 0, run the following command:
ADD GNBRFSPCONFIG: OperatorId=0, RfspIndex=0;
