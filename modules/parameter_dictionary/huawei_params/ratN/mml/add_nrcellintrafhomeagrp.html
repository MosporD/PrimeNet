Add Measurement Parameter Group Related to Intra-frequency Handover (ADD NRCELLINTRAFHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a measurement parameter group related to intra-frequency handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
IntraFreqHoMeasGroupId Intra-freq Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to intra-frequency handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
IntraFreqHoA3Offset Intra-frequency Handover A3 Offset

Meaning: Indicates the offset for event A3 related to intra-frequency handover. If the measured and reported RSRP value of an intra-frequency neighboring cell is greater than the offset specified by this parameter throughout the corresponding time-to-trigger, UEs send event A3 measurement reports. For details, see 3GPP TS 38.331.

GUI Value Range: -30~30

Unit: 0.5dB

Actual Value Range: -15~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates that better signal quality of a neighboring cell is required for handovers, leading to a lower probability of triggering event A3 and delaying handovers. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
IntraFreqHoA3Hyst Intra-frequency Handover A3 Hysteresis

Meaning: Indicates the hysteresis for event A3 related to intra-frequency handover. For details, see 3GPP TS 38.331.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: 2

Recommended Value: 2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of event triggering and a higher probability of ping-pong handovers and incorrect decisions. A larger value of this parameter results in a lower probability of event triggering, delayed handover, and deteriorated user experience.

Applicable Mode: N
IntraFreqHoA3TimeToTrig Intra-frequency Handover A3 Time To Trigger

Meaning: Indicates the time-to-trigger for event A3 related to intra-frequency handover. When the entering conditions for event A3 related to intra-frequency handover are met, a UE does not immediately send an event A3 report. Instead, a UE sends an event A3 report only if the entering conditions are met throughout the corresponding time-to-trigger. For details, see 3GPP TS 38.331.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: 320MS(320)

Recommended Value: 320MS(320)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of sending measurement reports. A larger value of this parameter results in a lower probability of sending measurement reports. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers.

Applicable Mode: N

Example

To add a measurement parameter group related to intra-frequency handover for an NR cell with NR Cell ID set to 5, Intra-freq Handover Measurement Group ID set to 1, Intra-frequency Handover A3 Offset set to 3, Intra-frequency Handover A3 Hysteresis set to 3, and Intra-frequency Handover A3 Time To Trigger set to 256MS, run the following command:
ADD NRCELLINTRAFHOMEAGRP: NrCellId=5, IntraFreqHoMeasGroupId=1, IntraFreqHoA3Offset=3, IntraFreqHoA3Hyst=3, IntraFreqHoA3TimeToTrig=256MS;
