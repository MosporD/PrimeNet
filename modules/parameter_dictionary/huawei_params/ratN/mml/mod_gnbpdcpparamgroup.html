Modify gNodeB PDCP Parameter Group (MOD GNBPDCPPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configurations of a PDCP parameter group of the gNodeB.

Note

None.

Parameters

ID Name Description
PdcpParamGroupId PDCP Parameter Group ID

Meaning: Indicates the ID of a PDCP parameter group.

GUI Value Range: 0~159

Unit: None

Actual Value Range: 0~159

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
DlPdcpDiscardTimer Downlink PDCP Discard Timer

Meaning: Indicates the length of the downlink PDCP discard timer of the gNodeB. If PDCP packets have been buffered for a period longer than the timer length, the gNodeB discards the packets. This timer is valid only for data transmitted on DRBs. For details, see 3GPP TS 38.323.

GUI Value Range: MS10(10), MS20(20), MS30(30), MS40(40), MS50(50), MS60(60), MS75(75), MS100(100), MS150(150), MS200(200), MS250(250), MS300(300), MS500(500), MS750(750), MS1500(1500), INFINITY(Infinity), MS2000(2000), MS2500(2500), MS3000(3000), MS3500(3500), MS4000(4000), MS5000(5000), MS8000(8000), MS10000(10000)

MML Default Value: None

Recommended Value: QCI 1, QCI 2, QCI 7, QCI 65, and QCI 66: MS150(150) for low frequency bands in UM mode, MS300(300) for low frequency bands in AM mode, MS150(150) for high frequency bands

QCI 3, QCI 75, and QCI 79: MS50(50) in UM mode, MS300(300) for low frequency bands in AM mode, MS150(150) for high frequency bands in AM mode

QCI 4: MS150(150) in UM mode, MS300(300) in AM mode

DlDataPdcpSplitMode Downlink Data PDCP Split Mode

Meaning: Indicates the downlink PDCP-layer data split mode. The value SCG_AND_MCG indicates that data is dynamically distributed to the eNodeB or gNodeB depending on the split algorithm. The value MCG_ONLY indicates that data is distributed only to the MCG (eNodeB). The value SCG_ONLY indicates that data is distributed only to the SCG (gNodeB). For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is distributed only to the SCG.

GUI Value Range: SCG_AND_MCG(Dynamically Transferred), MCG_ONLY(Transferred Only to MCG), SCG_ONLY(Transferred Only to SCG)

Unit: None

Actual Value Range: SCG_AND_MCG, MCG_ONLY, SCG_ONLY

MML Default Value: None

Recommended Value: SCG_ONLY(Transferred Only to SCG)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to SCG_ONLY, the throughput on the NR side increases. When this parameter is set to MCG_ONLY, the throughput on the LTE side increases. When this parameter is set to SCG_AND_MCG, the throughput on the LTE or NR side may increase.

Applicable Mode: N
DlPdcpSnSize Downlink PDCP SN Size

Meaning: Indicates the length of a downlink PDCP sequence number for the gNodeB and UE. For details, see 3GPP TS 38.323.

GUI Value Range: BITS12(12), BITS18(18)

Unit: bit

Actual Value Range: BITS12, BITS18

MML Default Value: None

Recommended Value: QCIs 1, 5, 65, 66, and 69: BITS12(12)

QCIs 2, 3, 4, 6, 7, 8, 9, and 70, 75, and 79: BITS18(18)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The PDCP sequence number length must be large enough to prevent hyper frame number (HFN) mismatch when a large number of packets are lost. However, a longer PDCP sequence number results in more PDCP header overhead and lower traffic volume. In AM mode, the PDCP sequence number length must be the same as the RLC sequence number length. In UM mode, the PDCP sequence number length must be greater than or equal to the RLC sequence number length. Otherwise, packet loss may occur.

Applicable Mode: N

UlDataSplitPrimaryPath Uplink Data Split Primary Path

Meaning: Indicates the primary path for uplink data split. The value MCG indicates master cell group (MCG), and the value SCG indicates secondary cell group (SCG). If this parameter is set to MCG, the primary path for uplink data split is MCG. If this parameter is set to SCG, the primary path for uplink data split is SCG. For details, see 3GPP TS 38.323. For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is split only to the secondary base station.

GUI Value Range: MCG(Primary Data Split Path Being MCG), SCG(Primary Data Split Path Being SCG)

Unit: None

Actual Value Range: MCG, SCG

MML Default Value: None

Recommended Value: SCG(Primary Data Split Path Being SCG)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
UlDataSplitThreshold Uplink Data Split Threshold

Meaning: Indicates the threshold of uplink data split for LTE-NR NSA DC UEs. For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is distributed only to the secondary base station.

PdcpReportPollingPeriod PDCP Report Polling Period

Meaning: Indicates the period for the NR PDCP layer to initiate report polling to the LTE RLC layer in the Option 3x architecture.

GUI Value Range: MS10(10), MS20(20), MS30(30), MS40(40), MS50(50), MS100(100)

Unit: ms

Actual Value Range: MS10, MS20, MS30, MS40, MS50, MS100

MML Default Value: None

Recommended Value: MS10(10)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a shorter polling period, more accurate traffic splitting, and higher TCP throughput. However, if this parameter is set to a value smaller than the delay over X2, the PDCP layer sends retransmission data repeatedly.

Applicable Mode: N

Example

To modify the settings of gNodeB PDCP parameter group with the parameters as follows: PDCP Parameter Group ID: 1, Downlink PDCP Discard Timer(ms): 50, run the following command:
MOD GNBPDCPPARAMGROUP: PdcpParamGroupId=1, DlPdcpDiscardTimer=MS50;
