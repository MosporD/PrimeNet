List NSA DC Configuration Parameter Group for an NR Cell (LST NRCELLNSADCCONFIGGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the NSA DC configuration parameter group configurations of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NsaDcConfigGroupId NSA DC Configuration Group ID

Meaning: Indicates the ID of an NSA DC configuration parameter group.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list an NSA DC configuration parameter group for an NR cell with NR Cell ID set to 88 and NSA DC Configuration Group ID set to 2, run the following command:
LST NRCELLNSADCCONFIGGRP: NrCellId=88, NsaDcConfigGroupId=2;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

NSA DC Configuration Group ID

Indicates the ID of an NSA DC configuration parameter group.

PSCell A2 RSRP Thld Offset(dB)

Indicates the offset to the RSRP threshold for event A2 that triggers the removal of the PSCell of NSA DC UEs. The summed value of this parameter and the NRCellNsaDcConfig.PscellA2RsrpThld parameter is used as the event A2 threshold for the PSCell of NSA DC UEs. If the summed value exceeds -31 dBm, the actual threshold for event A2 equals -30 dBm. If the summed value is less than -156 dBm, the actual threshold for event A2 equals -156 dBm.

PSCell A2 Time To Trigger(ms)

Indicates the time-to-trigger for event A2 that triggers the removal of the PSCell of NSA DC UEs. When detecting that the entering conditions for event A2 are fulfilled, UEs do not immediately send measurement reports. Instead, UEs send measurement reports only when the entering conditions are fulfilled throughout the corresponding time-to-trigger.
