Modify NR DU Cell Reserved Parameter (MOD NRDUCELLRSVDPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of reserved NR DU Cell parameters.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
