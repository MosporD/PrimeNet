Remove gNodeB Xn Blacklist or Whitelist (RMV GNBXNBLACKWHITELIST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a record from the gNodeB Xn blacklist or whitelist.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code (MCC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the mobile network code (MNC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the ID of the peer gNodeB to be added to the Xn blacklist or whitelist.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a gNodeB Xn blacklist and whitelist with the parameters as follows: Mobile Country Code set to "262", Mobile Network Code set to "02", gNodeB ID set to 1, run the following command:
RMV GNBXNBLACKWHITELIST: Mcc="262", Mnc="02", gNBId=1;
