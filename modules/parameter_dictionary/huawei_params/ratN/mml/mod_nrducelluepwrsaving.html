Modify UE Power Saving in NR DU Cell (MOD NRDUCELLUEPWRSAVING)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify UE power-saving parameters of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NrDuCellDrxAlgoSwitch NR DU Cell DRX Algorithm Switch

Meaning: Indicates whether to enable the DRX algorithm for an NR DU cell.

BASIC_DRX_SW: Indicates whether to enable DRX for UEs in an NR DU cell.

LNR_DRX_SYNCHRONIZE_SW: Indicates whether to enable DRX synchronization for EN-DC UEs in an NR DU cell. This option takes effect only if the BASIC_DRX_SW option is selected.

GUI Value Range: BASIC_DRX_SW(Basic DRX Switch), LNR_DRX_SYNCHRONIZE_SW(LTE and NR DRX Synchronization Switch)

Unit: None

Actual Value Range: BASIC_DRX_SW, LNR_DRX_SYNCHRONIZE_SW

MML Default Value: None

Recommended Value: BASIC_DRX_SW:Off, LNR_DRX_SYNCHRONIZE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: BASIC_DRX_SW: If this option is selected, the power consumption of UEs is further reduced when the UEs are triggered to enter DRX mode. However, the impact on network performance is subject to the DRX parameter configuration. If this option is deselected, network performance is not affected.

LNR_DRX_SYNCHRONIZE_SW: If this option is selected, the DRX sleep time of the LTE network is aligned with that of the NR network, and the power consumption of NSA UEs is further reduced. This option has no impact on network performance.

Applicable Mode: N
BwpPwrSavingSw BWP Power Saving Switch

Meaning: Indicates whether to allow UEs in the local cell to enter the BWP2 power saving state.

BWP2_SWITCH: Indicates whether the cell allows BWP2 power saving for UEs. When this option is selected, the cell allows UEs capable of this function to enter the BWP power saving state. When this option is deselected, the cell does not allow UEs to enter the BWP power saving state, even if the UEs support this function. This parameter takes effect only when NRDUCellPucch.StructureType is set to LONG_STRUCTURE. This parameter applies only to low-frequency TDD cells.

GUI Value Range: BWP2_SWITCH(BWP Power Saving Switch)

Unit: None

Actual Value Range: BWP2_SWITCH

MML Default Value: None

Recommended Value: BWP2_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: BWP2_SWITCH: When this option is selected, certain UEs work on the BWP2. In this case, certain RB resources cannot be used because the UEs cannot be flexibly distributed in the cell, wasting some radio resources. To maintain the optimal throughput on the network side, it is recommended that this option be deselected. When this option is deselected, UEs in the cell cannot enter the BWP2 mode and cannot save power using BWP.

Applicable Mode: N-TDD-FR1

Example

To modify power-saving parameters of an NR DU cell with the parameters as follows: NR DU Cell ID: 11, Basic DRX Switch: on, run the following command:
MOD NRDUCELLUEPWRSAVING: NrDuCellId=11, NrDuCellDrxAlgoSwitch=BASIC_DRX_SW-1;
