List NR DU Cell PUCCH (LST NRDUCELLPUCCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the PUCCH configuration of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the PUCCH configuration of an NR DU cell with NR DU Cell ID set to 88, run the following command:
LST NRDUCELLPUCCH: NrDuCellId=88;
The result is shown as follows:

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Structure Type

Indicates the PUCCH format. For high-frequency TDD cells, this parameter is always set to a value indicating short format. For FDD and SUL cells, this parameter is always set to a value indicating long format.

Format3 RB Number(RB)

Indicates the number of PUCCH format-3 RBs. They are used to transmit HARQ-ACKs whose size is greater than two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to low-frequency TDD cells, FDD cells with the INTRA_FR_INTER_BAND_CA_SW option selected, and SUL cells not enabled with LTE and NR sharing.

Format1 RB Number(RB)

Indicates the number of PUCCH format-1 RBs. It is used to transmit SRs and HARQ-ACK whose size is less than or equal to two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to SUL cells not enabled with LTE and NR sharing, low-frequency TDD cells, and FDD cells.

Short PUCCH Symbol Number

Indicates the number of symbols used for short PUCCH in a cell. This parameter takes effect only for high-frequency cells with a short PUCCH format and with the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter deselected.

SR Period(slot)

Indicates the period of sending SRs. The period range differs depending on cell mode or subcarrier spacing. For details, see 3GPP TS 38.331. This parameter takes effect only for UEs that newly access the network. Specifically, for TDM UEs in SUL cells, SRs are received only in uplink timeslots available for NR. This parameter does not take effect if SR period adaptation is enabled.

Format3 CSI-dedicated RB Number(RB)

Indicates the number of RBs reserved for format-3 periodic CSI. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to SUL cells not enabled with LTE and NR sharing, low-frequency TDD cells, and FDD cells.

PUCCH Algorithm Switch

Indicates the PUCCH adaptation algorithm switch. It determines whether to enable PUCCH resource adjustment.

PUCCH_RES_ADAPTIVE_SWITCH: Indicates whether to enable symbol number resource adjustment for short PUCCH. If this option is selected, the gNodeB automatically adjusts symbols of short PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, symbols of short PUCCH are consumed based on the GUI value. This option applies only to high-frequency TDD cells.

PUCCH_RBRES_ADAPTIVE_SWITCH: Indicates whether to enable RB resource adjustment for long PUCCH. If this option is selected, the gNodeB automatically adjusts RBs of long PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, RBs of long PUCCH are consumed based on the GUI value. This option applies only to FDD and SUL cells not enabled with LTE and NR sharing and TDD cells with NRDUCell.HighSpeedFlag set to LOW_SPEED.

SR Resource Algo Switch

Indicates the SR resource algorithm switch. It determines whether to enable SR resource adjustment. SR_PERIOD_ADAPT_SWITCH: Indicates whether to enable SR period adaptation. If this option is selected, SR period adjustment is enabled. If this option is deselected, the SR period is the value of the NRDUCellPucch.SrPeriod parameter.

Format4 RB Number(RB)

Indicates the number of PUCCH format-4 RBs. It is used to transmit HARQ-ACKs whose size is greater than two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to low-frequency TDD cells, FDD cells with the INTRA_FR_INTER_BAND_CA_SW option selected, and SUL cells not enabled with LTE and NR sharing.

CSI Report Period(slot)

Indicates the CSI reporting interval.This parameter is valid only when the CSI_REPORT_PERIOD_ADAPT_SWITCH option of the CsiResoureAlgoSwitch parameter is deselected. For TDD and FDD cells, the value of this parameter or the value of NRDUCellCsirs.CsiPeriod is used as the CSI reporting interval, whichever is larger. For SUL cells, the value of this parameter or the value of NRDUCellCsirs.CsiPeriod divided by two is used as the CSI reporting interval, whichever is larger.

This parameter applies only to low-frequency cells.

User Short PUCCH Symbol Number

Indicates the number of PUCCH format-2 symbols. This parameter can be set to ADAPTIVE only when the value of ShortPucchSymbolNum is greater than or equal to SYMBOL4 and the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to high-frequency TDD cells.

CSI Resource Algo Switch

Indicates the CSI resource algorithm switches.

CSI_REPORT_PERIOD_ADAPT_SWITCH: Indicates whether to enable CSI reporting period adaptation. If this option is selected, CSI reporting period adjustment is initiated. If this option is deselected, the CSI reporting period is the value of the NRDUCellPucch.CsiReportPeriod parameter. This option applies only to low-frequency cells.

Format4 CSI-dedicated RB Number(RB)

Indicates the number of RBs reserved for format-4 periodic CSI. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to SUL cells not enabled with LTE and NR sharing, low-frequency TDD cells, and FDD cells.
