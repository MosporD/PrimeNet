Modify NR DU Cell Selection Configurations (MOD NRDUCELLSELCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the NR DU cell selection configurations.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
MinimumRxLevel Minimum RX Level

Meaning: Indicates the minimum RX level for a cell. This value is included in criteria S and used in the evaluation of cell selection. It maps to the q-RxLevMin IE in SIB1. For details, see 3GPP TS 38.304.

GUI Value Range: -70~-22

Unit: 2dBm

Actual Value Range: -140~-44

MML Default Value: None

Recommended Value: -64

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that the UE meets the S criteria and the cell becomes a suitable cell. A larger value of this parameter leads to the opposite effects.

Applicable Mode: N

Example

To modify the selection configurations of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, Minimum RX Level: -30, run the following command:
MOD NRDUCELLSELCONFIG: NrDuCellId=88, MinimumRxLevel=-30;
