Modify NR DU Cell PDCCH (MOD NRDUCELLPDCCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of the PDCCH in an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifying the numbers of occupied RBs and occupied symbols will cause the cell to reset.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
UlMaxCcePct Uplink Maximum CCE Percentage

Meaning: Indicates the maximum percentage of uplink available CCEs in a slot that is used for the transmission of both uplink and downlink scheduling information.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to more uplink available CCE resources in a slot that is used for the transmission of both uplink and downlink scheduling information, more uplink scheduling chances, and larger uplink capacity. A smaller value of this parameter leads to the opposite effect.

Applicable Mode: N
OccupiedSymbolNum Occupied Symbol Number

Meaning: Indicates the number of symbols occupied by the PDCCH.

GUI Value Range: 1SYM(1 Symbol), 2SYM(2 Symbols), 3SYM(3 Symbols)

Unit: None

Actual Value Range: 1SYM, 2SYM, 3SYM

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows: When the NR FDD and NR TDD FR1 bandwidth is less than or equal to 70 MHz and the slot assignment is 2_3_DSUUU, the recommended value is 2SYM. When other bandwidths and frequency bands are used, the recommended value is 1SYM.

When LTE FDD and NR Flash Dynamic Spectrum Sharing is enabled and the NR TX/RX mode is 2T2R or 2T4R, the recommended value is 2SYM. When the NR TX/RX mode is 4T4R, the recommended value is 1SYM.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter leads to fewer CCE resources, fewer UEs, but more PDSCH resources in the cell.

A larger value of this parameter leads to the opposite effects.

Applicable Mode: N
MaxPairLayerNum Maximum Pairing Layer Number

Meaning: Indicates the maximum number of pairing layers for PDCCH spatial multiplexing. This parameter can be set to specify the maximum number of PDCCH spatial layers only when the PDCCH_MU_SW option is selected. This parameter applies only to low-frequency TDD cells.

GUI Value Range: LAYER_2(2 Layers), LAYER_3(3 Layers), LAYER_4(4 Layers)

Unit: None

Actual Value Range: LAYER_2, LAYER_3, LAYER_4

MML Default Value: None

Recommended Value: LAYER_2(2 Layers)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter increases the number of allowed pairing layers, PDCCH capacity, and interference between paired UEs. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N-TDD-FR1
OccupiedRbNum Number of Occupied RBs

Meaning: Indicates the frequency domain range occupied by each PDCCH symbol in a cell. This parameter takes effect only when the rate matching function is enabled for PDCCH and PDSCH resources. If this parameter is set to 0, full band resources are occupied. If this parameter is set to a value greater than the downlink bandwidth (specified by DlBandwidth), the PDCCH uses full band resources by default.

GUI Value Range: 0~22

Unit: None

Actual Value Range: 0~264, step: 12

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value (greater than 0) of this parameter allows the PDCCH to occupy fewer RBs in an NR DU cell. This leads to a higher probability of PDCCH capacity insufficiency but more available PDSCH resources and therefore higher PDSCH capacity. A larger value of this parameter leads to the opposite effects.

Applicable Mode: N
PdcchBlerTarget PDCCH BLER Target

Meaning: Indicates the target BLER value for PDCCH link adaptation. The PDCCH BLER needs to converge to this target value.

GUI Value Range: 0~200

Unit: None

Actual Value Range: 0~1, step: 0.005

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower PDCCH BLER. A larger value of this parameter results in the opposite effect. A high BLER reduces uplink and downlink throughput. A low BLER increases PDCCH resource consumption, reducing the system capacity and number of UEs that can be scheduled.

Applicable Mode: N
SulMaxCcePct SUL Maximum CCE Percentage

Meaning: Indicates the maximum percentage of CCEs available in the uplink for decoupling UEs when decoupling UEs are scheduled in slots used only for downlink scheduling in TDD cells.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in fewer available CCEs in the uplink of an SUL cell in slots used only for downlink scheduling in TDD cells. In this case, the uplink scheduling probability of the SUL cell is limited, the uplink capacity of the SUL cell decreases, and the number of available CCEs in TDD cells increases. This increases the scheduling probability of TDD cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-SUL
PdcchAlgoSwitch PDCCH Algorithm Switch

Meaning: Indicates the PDCCH algorithm switches.

UL_DL_CCE_RATIO_ADAPT_SW: Indicates whether to enable uplink and downlink CCE percentage adaptation in a cell. If this option is selected, the gNodeB adaptively adjusts the maximum percentage of uplink CCEs based on uplink and downlink CCE requirements. If this option is deselected, the maximum percentage of uplink CCEs is specified by the NRDUCellPdcch.UlMaxCcePct or NRDUCellPdcch.SulMaxCcePct parameter. This option takes effect in scenarios other than FDD 5 MHz scenarios. In FDD 5 MHz scenarios, uplink and downlink CCE percentage adaptation takes effect by default.

GUI Value Range: UL_DL_CCE_RATIO_ADAPT_SW(UL to DL CCE Ratio Adaptation Switch)

Unit: None

Actual Value Range: UL_DL_CCE_RATIO_ADAPT_SW

MML Default Value: None

Recommended Value: UL_DL_CCE_RATIO_ADAPT_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_DL_CCE_RATIO_ADAPT_SW: If this option is selected, the gNodeB adaptively determines the ratio of uplink CCE to downlink CCE based on uplink and downlink DCI transmission requirements, improving CCE resource usage and the number of scheduled UEs served by the PDCCH. If this option is deselected, CCE resources are not dynamically adjusted, which may decrease the CCE usage and the number of scheduled UEs served by the PDCCH.

Applicable Mode: N
SpctShrStartSymbol Spectrum Sharing Start Symbol

Meaning: Indicates the start symbol occupied by the PDCCH when LTE FDD and NR Spectrum Sharing is enabled. For details, see 3GPP TS 38.331. This parameter is valid only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.

GUI Value Range: SYM1(Symbol 1), SYM2(Symbol 2)

Unit: None

Actual Value Range: SYM1, SYM2

MML Default Value: None

Recommended Value: SYM1 when LTE FDD and NR spectrum sharing is enabled and the TX/RX mode of the NR cell is 2T2R or 2T4R; SYM2 when the TX/RX mode of the NR cell is 4T4R; SYM1 in other scenarios

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a large start symbol and the coordinated negotiation meets the request requirements on the NR side, the UE throughput decreases and the cell coverage performance decreases. If this parameter is set to a small start symbol and the coordinated negotiation meets the request requirements on the NR side, the UE throughput increases and the cell coverage performance increases.

Applicable Mode: N-FDD
PdcchAlgoExtSwitch PDCCH Algorithm Extension Switch

Meaning: Indicates PDCCH algorithm extension switches.

UE_PDCCH_SYM_NUM_ADAPT_SW: Indicates whether to enable UE-specific PDCCH symbol number adaptation in a cell. If this option is selected, UE-specific PDCCH symbol number adaptation is enabled, and the NRDUCellPdcch.OccupiedSymbolNum parameter no longer takes effect. If this option is deselected, the number of UE-specific PDCCH symbols is specified by the NRDUCellPdcch.OccupiedSymbolNum parameter. This option does not take effect for high-frequency cells.

GUI Value Range: UE_PDCCH_SYM_NUM_ADAPT_SW(UE-specific PDCCH Symbol Num Adapt Sw)

Unit: None

Actual Value Range: UE_PDCCH_SYM_NUM_ADAPT_SW

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

When the cell mode is FDD 5 MHz, FDD 10 MHz, TDD 20 MHz, or TDD 30 MHz: UE_PDCCH_SYM_NUM_ADAPT_SW:Off

Other scenarios: UE_PDCCH_SYM_NUM_ADAPT_SW:On

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: UE_PDCCH_SYM_NUM_ADAPT_SW: If this option is selected, the base station adaptively determines the number of UE-specific PDCCH symbols based on DCI transmission requirements. This increases the CCE resource usage and throughput. However, the number of RRC connection reconfiguration messages increases. If this option is deselected, UE-specific PDCCH symbol number adaptation is disabled, which has no impact on network performance.

Applicable Mode: N
PdcchAlgoEnhSwitch PDCCH Algorithm Enhancement Switch

Meaning: Indicates the enhanced PDCCH algorithm switches.

AGG_LVL_INIT_SELECT_OPT_SW: Indicates whether to enable initial aggregation level selection optimization in a cell. This function is enabled only when this option is selected.

GUI Value Range: AGG_LVL_INIT_SELECT_OPT_SW(Agg Level Initial Selection Opt Switch)

Unit: None

Actual Value Range: AGG_LVL_INIT_SELECT_OPT_SW

MML Default Value: None

Recommended Value: AGG_LVL_INIT_SELECT_OPT_SW: This option can be set by the system by default. The default value is as follows:

When NRDUCell.FrequencyBand is set to N257, N258, N260, or N261: OFF(Off)

Other scenarios: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: AGG_LVL_INIT_SELECT_OPT_SW: If this option is selected, the base station optimizes initial PDCCH aggregation level selection based on uplink measurement information, increasing the number of UEs served by PDCCH resources. If this option is deselected, the base station does not optimize initial aggregation level selection, which has no impact on network performance.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
GuaranteedRbNum Number of Guaranteed RBs

Meaning: Indicates the number of guaranteed PDCCH RBs allocated to an NR cell when resources are sufficient in LTE FDD and NR spectrum sharing scenarios. When the number of PDCCH RBs required by an NR cell is greater than the value of this parameter, PDCCH RBs are allocated based on the service requirement. When the number of PDCCH RBs required by an NR cell is smaller than the value of this parameter, PDCCH RBs are allocated based on the value of this parameter.

When the number of configured RBs exceeds the RB number corresponding to downlink bandwidth (specified by DlBandwidth), the PDCCH occupies full-band resources by default. This parameter takes effect only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.

GUI Value Range: 0~17

Unit: None

Actual Value Range: 0~102, step: 6

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in more guaranteed PDCCH resources for NR, fewer available resources for LTE, and lower LTE cell throughput. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-FDD

Example

To modify the PDCCH configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 0, Uplink CCE Maximum Ratio(%): 50, run the following command:
MOD NRDUCELLPDCCH: NrDuCellId=0, UlMaxCcePct=50;
