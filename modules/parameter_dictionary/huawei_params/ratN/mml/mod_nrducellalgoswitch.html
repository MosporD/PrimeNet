Modify NR DU Cell Algorithm Switch (MOD NRDUCELLALGOSWITCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of NR DU cell-level algorithm switches.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AdaptiveEdgeExpEnhSwitch Adaptive Edge Experience Enhance Switch

Meaning: Indicates whether to enable the functions of the adaptive edge experience improvement feature.

UL_WAVEFORM_ADAPT_SW: Indicates whether to enable the CP-OFDM and DFT-S-OFDM waveform adaption function in the uplink.

UL_IBLER_ADAPT_SW: Indicates whether to enable the uplink IBLER adaption function.

DL_PMI_SRS_ADAPT_SW: Indicates whether to enable SRS- and PMI-based weight adaption. This option applies only to low-frequency 64T/32T/8T/4T TDD cells.

DL_INTRF_RANDOM_SW: Indicates whether to enable the downlink interference randomization function.

GUI Value Range: UL_WAVEFORM_ADAPT_SW(Uplink Waveform Adaption Switch), UL_IBLER_ADAPT_SW(Uplink IBLER Adaption Switch), DL_PMI_SRS_ADAPT_SW(Downlink SRS and PMI Adaption Switch), DL_INTRF_RANDOM_SW(Downlink Interference Random Switch)

Unit: None

Actual Value Range: UL_WAVEFORM_ADAPT_SW, UL_IBLER_ADAPT_SW, DL_PMI_SRS_ADAPT_SW, DL_INTRF_RANDOM_SW

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

For FDD cells: UL_WAVEFORM_ADAPT_SW:Off, UL_IBLER_ADAPT_SW:Off, DL_PMI_SRS_ADAPT_SW:Off, DL_INTRF_RANDOM_SW:Off;

For other scenarios: UL_WAVEFORM_ADAPT_SW:Off, UL_IBLER_ADAPT_SW:Off, DL_PMI_SRS_ADAPT_SW:On, DL_INTRF_RANDOM_SW:On.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_WAVEFORM_ADAPT_SW: If this option is selected, adaptation between CP-OFDM waveforms and DFT-S-OFDM waveforms in the uplink is enabled to increase the cell coverage. If this option is deselected, the network performance is not affected.

UL_IBLER_ADAPT_SW: If this option is selected, the target IBLER is selected adaptively based on the link status in the uplink, increasing the throughput of edge UEs. If this option is deselected, the network performance is not affected.

DL_PMI_SRS_ADAPT_SW: If this option is selected, SRS-based weights and PMI-based weights are adaptively selected for MIMO. This way, for UEs at near points or far points, a proper weight can be selected to improve transmission performance when SRS resources are insufficient. If this option is deselected, only the SRS-based weights or PMI-based weights are used, which has no impact on network performance.

DL_INTRF_RANDOM_SW: If this option is selected, downlink interference randomization is used for scheduling in light-load scenarios. This decreases inter-cell interference and improves the downlink throughput. If this option is deselected, inter-cell interference increases and the downlink throughput decreases in light-load scenarios. This option does not affect network performance in heavy-load scenarios.

Applicable Mode: N

PDCCH_MU_SW: If this option is selected, the cell supports PDCCH spatial multiplexing and the PDCCH capacity is larger. However, inter-beam interference is introduced and PDCCH demodulation performance deteriorates. If this option is deselected, the cell does not support PDCCH spatial multiplexing, and the PDCCH capacity is easily limited. However, there is no inter-beam interference and the PDCCH demodulation performance is improved.

DL_MU_MIMO_SW: If this option is selected, spatial multiplexing is used for MU-MIMO in the downlink, increasing the downlink throughput. If this option is deselected, the network performance is not affected.

Ul256QamSwitch Uplink 256QAM Switch

Meaning: Indicates whether to enable the uplink 256QAM functions.

If the UL_256QAM_OFF option is selected, the uplink 256QAM functions at the cell level are disabled.

If the UL_256QAM_FIXED option is selected, the fixed uplink 256QAM function at the cell level is enabled.

If the UL_256QAM_ADAPT option is selected, the adaptive uplink 256QAM function at the cell level is enabled.

GUI Value Range: UL_256QAM_OFF(Off), UL_256QAM_FIXED(Fixed Uplink 256QAM Configuration), UL_256QAM_ADAPT(Adaptive Uplink 256QAM Configuration)

Unit: None

Actual Value Range: UL_256QAM_OFF, UL_256QAM_FIXED, UL_256QAM_ADAPT

MML Default Value: None

Recommended Value: UL_256QAM_OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to UL_256QAM_OFF, uplink 256QAM is disabled, which does not affect the network performance. If this parameter is set to UL_256QAM_FIXED, uplink 256QAM is always used, which increases the uplink data rate when the uplink SNR is high. If this parameter is set to UL_256QAM_ADAPT, uplink 256QAM adaptation is enabled. More MCS indexes can be selected for UEs at the cell edge when compared with UL_256QAM_FIXED, and the data rate at some fixed points may increase. However, the data rate does not increase in mobility scenarios. In addition, if this parameter is set to UL_256QAM_ADAPT, the rate of 256QAM may be lower than that of 64QAM due to power back-off before the switching from the 256QAM MCS index table to the 64QAM MCS index table.

Applicable Mode: N
