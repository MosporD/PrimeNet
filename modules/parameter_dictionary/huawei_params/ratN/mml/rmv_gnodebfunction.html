Remove gNodeB Function (RMV GNODEBFUNCTION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove the gNodeB function.

Note

  • Before removing the gNodeBFunction MO, remove its child MOs related to the configurations such as NR cells, neighboring cells, interfaces, and operators. Otherwise, the command execution fails.

  • After this command is executed, the gNodeB function including all radio services and commissioning and maintenance functions becomes unavailable. In addition, the configuration data of the gNodeB function will be deleted. Therefore, exercise caution when running this command.

Parameters

ID Name Description
gNodeBFunctionName gNodeB Function Name

Meaning: Indicates the name of a gNodeB function, which uniquely identifies the gNodeB function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of gNodeBFunctionName in a gNodeBFunction MO is a string of characters. The string cannot be all null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes (\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove the gNodeB function with gNodeB Function Name set to 5G_1, run the following command:
RMV GNODEBFUNCTION: gNodeBFunctionName="5G_1";
