Remove gNodeB Dedicated NSA DC Band Combination (RMV GNBDEDNSADCBANDCOMB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a dedicated NSA DC band combination from the gNodeB.

Note

None.

Parameters

ID Name Description
NrBandId NR Band ID

Meaning: Indicates ID of an NR band in a band combination. For details, see 3GPP TS 38.101-1 and 38.101-2.

GUI Value Range: N1(n1), N3(n3), N5(n5), N7(n7), N8(n8), N20(n20), N28(n28), N38(n38), N40(n40), N41(n41), N66(n66), N71(n71), N77(n77), N78(n78), N79(n79), N80(n80), N82(n82), N83(n83), N84(n84), N86(n86), N257(n257), N258(n258), N260(n260), N261(n261)

Unit: None

Actual Value Range: N1, N3, N5, N7, N8, N20, N28, N38, N40, N41, N66, N71, N77, N78, N79, N80, N82, N83, N84, N86, N257, N258, N260, N261

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
LteBandId LTE Band ID

Meaning: Indicates ID of an LTE band in a band combination. For details, see 3GPP TS 36.101.

GUI Value Range: 1~256

Unit: None

Actual Value Range: 1~256

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a dedicated NSA DC band combination of a gNodeB with the parameters as follows: NR Band ID: N3, LTE Band ID: 3, run the following command:
RMV GNBDEDNSADCBANDCOMB: NrBandId=N3, LteBandId=3;
