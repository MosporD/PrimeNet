Add gNodeB CA Frequency (ADD GNBCAFREQUENCY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a CA frequency for a gNodeB.

Note

None.

Parameters

ID Name Description
CaFreqGroupId CA Frequency Group ID

Meaning: Indicates the ID of a CA frequency group, which uniquely identifies the CA frequency group within a gNodeB.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
DlNarfcn Downlink NARFCN

Meaning: Indicates the downlink NR-ARFCN of a CA cell.

GUI Value Range: 151600~160600,361000~376000,422000~440000,499200~537999,620000~680000,693333~733333,2016667~2104166,2229167~2279166

Unit: None

Actual Value Range: 151600~160600,361000~376000,422000~440000,499200~537999,620000~680000,693333~733333,2016667~2104166,2229167~2279166

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CaA2RsrpThldOffset CA A2 RSRP Threshold Offset

Meaning: Indicates the frequency-specific offset of the RSRP threshold for CA event A2. If the summed value of this parameter and the NRCellCaMgmtConfig.CaA2RsrpThld parameter is greater than -43 dBm, the effective threshold for CA event A2 is -43 dBm. If the summed value is less than -140 dBm, the effective threshold for CA event A2 is -140 dBm.

GUI Value Range: -31~66

Unit: dB

Actual Value Range: -31~66

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The larger the value of this parameter, the higher the effective CA event A2 triggering threshold and the more likely the SCells can be deleted for CA UEs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
CaSccA5RsrpThld2Offset CA SCC A5 RSRP Threshold 2 Offset

Meaning: Indicates the frequency-specific offset of the RSRP threshold 2 for CA event A5. If the summed value of this parameter and the NRCellCaMgmtConfig.CaA5RsrpThld2 parameter is greater than -43 dBm, the effective threshold 2 for CA event A5 is -43 dBm. If the summed value is less than -140 dBm, the effective threshold 2 for CA event A5 is -140 dBm.

GUI Value Range: -35~62

Unit: dB

Actual Value Range: -35~62

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The larger the value of this parameter, the higher the effective CA event A5 triggering threshold 2 and the less likely the SCells can be configured for CA UEs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
SsbFreqPos SSB Frequency Position

Meaning: Indicates the frequency-domain position of the SSB corresponding to a CA frequency. The value of this parameter depends on the description method of the SSB frequency-domain position (SsbDescMethod) of neighboring cells.

When SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value range from 2 to 26639 applies. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, other value ranges apply.

GUI Value Range: 2~26639,123400~130400,151600~164200,173800~178800,185000~192000,361000~376000,422000~440000,499200~538000,620000~680000,693334~733333,2016667~2104165,2229167~2279165

Unit: None

Actual Value Range: 2~26639,123400~130400,151600~164200,173800~178800,185000~192000,361000~376000,422000~440000,499200~538000,620000~680000,693334~733333,2016667~2104165,2229167~2279165

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a gNodeB CA Frequency with the parameters as follows: CA Frequency Group ID: 1, Downlink NARFCN: 635000, Ssb Frequency Position: 634988, run the following command:
ADD GNBCAFREQUENCY: CaFreqGroupId=1, DlNarfcn=635000, SsbFreqPos=634988;
