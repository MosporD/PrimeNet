Modify NR DU Cell Commissioning Reserved Parameter Configuration (MOD NRDUCELLRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of a reserved parameter for NR DU cell commissioning.

Note

None.

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a DU.
