List NR DU Cell RIM Configuration (LST NRDUCELLRIMCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the RIM parameters of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1

Example

To query the RIM parameters of an NR DU cell, run the following command:
LST NRDUCELLRIMCONFIG:;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Set ID Size(bit)

Indicates the size of the set ID of type-1 RIM-RS. If this parameter is set to a value in the range of 15 to 22, the size of the set ID of type-1 RIM-RS is the same as the parameter value. If this parameter is set to 255, it indicates an invalid value, and the type-1 RIM-RS cannot be sent or detected. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Set ID

Indicates the set ID of type-1 RIM-RS. If this parameter is set to a value in the range of 0 to 4194303, the set ID of type-1 RIM-RS is the same as the parameter value. If this parameter is set to 4294967295, it indicates an invalid value, and the type-1 RIM-RS cannot be sent or detected. This parameter applies only to low-frequency TDD cells.

RIM-RS Frequency Candidate Number

Indicates the number of candidate frequency-domain resources for global RIM-RS characteristic sequence for remote interference management. This parameter applies only to low-frequency TDD cells.

The value FREQ_NUM_1 indicates that only one candidate frequency-domain resource is available.

The value FREQ_NUM_2 indicates that two candidate frequency-domain resources are available.

The value FREQ_NUM_4 indicates that four candidate frequency-domain resources are available.

The value NULL indicates an invalid value.

RIM-RS Type1 Sequence Candidate Number

Indicates the number of candidate resources for type-1 RIM-RS characteristic sequence for remote interference management. This parameter applies only to low-frequency TDD cells.

The value SEQ_NUM_1 indicates that only one candidate sequence resource is available.

The value SEQ_NUM_2 indicates that two candidate sequence resources are available.

The value SEQ_NUM_4 indicates that four candidate sequence resources are available.

The value SEQ_NUM_8 indicates that eight candidate sequence resources are available.

The value NULL indicates an invalid value.

RIM-RS Type1 Scrambling ID for IS0

Indicates the scrambling ID of type-1 RIM-RS for sequence 0. If this parameter is set to a value in the range of 0 to 1023, the scrambling ID of type-1 RIM-RS for sequence 0 is the same as the parameter value. If this parameter is set to 4294967295, it indicates an invalid value, and the type-1 RIM-RS cannot be sent or detected for sequence 0. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Scrambling ID for IS1

Indicates the scrambling ID of type-1 RIM-RS for sequence 1. If this parameter is set to a value in the range of 0 to 1023, the scrambling ID of type-1 RIM-RS for sequence 1 is the same as the parameter value. If this parameter is set to 4294967295, it indicates an invalid value, and the type-1 RIM-RS cannot be sent or detected for sequence 1. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Scrambling ID for IS2

RIM-RS Start Frequency Offset

Indicates the start frequency-domain offset for RIM-RS. The reference point is PRB 0. This parameter applies only to low-frequency TDD cells.

RIM-RS Scramble Timer Multiplier Factor

Indicates the multiplier factor of the scrambling timer for RIM-RS. This parameter applies only to low-frequency TDD cells.

RIM-RS Scramble Timer Offset

Indicates the offset of the scrambling timer for RIM-RS. This parameter applies only to low-frequency TDD cells.

RIM-RS Function Switch

Indicates the switch used to enable or disable the remote interference management reference signal (RIM-RS) function, including the near-far functionality in this function.

RIM_RS1_NEAR_FAR_SW: Indicates whether to enable the near-far functionality for type-1 RIM-RS. If this option is selected, the interference source at a longer distance can be detected. If this option is deselected, only the interference source at a limited distance can be detected. This option applies only to low-frequency TDD cells.

Average UL Intrf Pwr Threshold(dBm)

Indicates the threshold for determining average uplink interference power in RIM. This parameter is used to identify the atmospheric duct interference. The characteristic sequence can be sent only when the average uplink interference power is greater than this threshold. This parameter applies only to low-frequency TDD cells.

UL Pwr Difference Thld(dB)

Indicates the threshold for determining the uplink inter-symbol power difference in RIM. This parameter is used to identify the atmospheric duct interference. The characteristic sequence can be sent only when the inter-symbol power difference is greater than this threshold. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Intrf Thld(dBm)

Indicates the threshold for determining remote interference based on the type-1 RIM-RS characteristic sequences. When remote interference is detected, the base station uses the type-1 RIM-RS characteristic sequences to verify the remote interference. This parameter applies only to low-frequency TDD cells.

RIM-RS Type1 Intrf Thld Offset(dB)

Indicates the offset of the threshold for determining ultra-remote interference relative to the value of the RimRsType1IntrfThld parameter. That is, the actual threshold for determining ultra-remote interference is the sum of the RimRsType1IntrfThld and RimRsType1IntrfThldOfs parameter values. When remote interference is detected, the base station uses the type-1 RIM-RS characteristic sequences to verify the ultra-remote interference. This parameter applies only to low-frequency TDD cells.
