Remove gNodeB Neighboring Cell PLMN List (RMV GNBNCELLPLMNLIST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a record from the neighboring-cell PLMN list of a gNodeB.

Note

None.

Parameters

ID Name Description
RatType RAT Type

Meaning: Indicates the RAT of the neighboring cell corresponding to the PLMN.

GUI Value Range: NR(NR), EUTRAN(E-UTRAN)

Unit: None

Actual Value Range: NR, EUTRAN

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the gNBNCellPlmnList MO instances with RatType set to NR, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.
  • In the gNBNCellPlmnList MO instances with RatType set to EUTRAN, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mcc Mobile Country Code

Meaning: Indicates the MCC in the PLMN of the neighboring cell. The value of this parameter is a string of three decimal digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in a gNBNCellPlmnList MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC in the PLMN of the neighboring cell. The value of this parameter is a string of two or three decimal digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in a gNBNCellPlmnList MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a gNodeB neighboring cell PLMN list with RAT Type set to NR, Mobile Country Code set to "302", and Mobile Network Code set to "220", run the following command:
RMV GNBNCELLPLMNLIST: RatType=NR, Mcc="302", Mnc="220";
