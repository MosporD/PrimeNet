List NR DU Cell Reserved Parameter Extension (LST NRDUCELLRSVDEXT)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list reserved parameter for NR DU cell commissioning, which is an extension of the NRDUCellRsvdExt MO.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list reserved parameter for NR DU cell commissioning, run the following command:
LST NRDUCELLRSVDEXT:;
