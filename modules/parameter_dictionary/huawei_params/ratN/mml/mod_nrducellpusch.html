Modify NR DU Cell PUSCH (MOD NRDUCELLPUSCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the PUSCH configuration of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InitUlSinrAdjust Initial Uplink SINR Adjustment

Meaning: Indicates the initial uplink SINR adjustment value of UEs that are not paired. For paired UEs, the initial uplink SINR adjustment value is fixed to 0 dB.

GUI Value Range: -40~60

Unit: 0.5 dB

Actual Value Range: -20~30

MML Default Value: None

Recommended Value: -8

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher modulation order for uplink data and fewer uplink resources occupied by uplink data. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
UlDmrsType Uplink DMRS Type

Meaning: Indicates the uplink DMRS type. For details, see 3GPP TS 38.331 and 3GPP TS 38.211. This parameter takes effect only for UEs that initially access the network. If this parameter is set to TYPE2, this value applies only to low-frequency cells.

GUI Value Range: TYPE1(Type 1), TYPE2(Type 2)

Unit: None

Actual Value Range: TYPE1, TYPE2

MML Default Value: None

Recommended Value: TYPE1(Type 1)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to TYPE1, there are 4 DMRS ports per DMRS symbol in the uplink and the MU pairing performance is favorable. If this parameter is set to TYPE2, there are 6 DMRS ports per DMRS symbol in the uplink and the MU pairing performance is unfavorable.

Applicable Mode: N-TDD
UlAdditionalDmrsPos Uplink Additional DMRS Position

Meaning: Indicates the position of the uplink additional DMRS (number of hidden symbols). When this parameter is set to NOT_CONFIG, no additional DMRS is configured for the uplink. When this parameter is set to POS1, the number of uplink additional DMRS symbols is 1. When this parameter is set to POS2, the number of uplink additional DMRS symbols is 2. This parameter takes effect only for UEs that newly access the network.

GUI Value Range: NOT_CONFIG(Not Configure Additional Dmrs), POS1(Position 1), POS2(Position 2)

Unit: None

Actual Value Range: NOT_CONFIG, POS1, POS2

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Low-speed cell: POS1

High-speed cell: POS2

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to NOT_CONFIG, the rates of fixed-point UEs increase but the UE mobility speed cannot be measured. When this parameter is set to POS1, low UE mobility speeds can be measured. If this parameter is set to POS2, relatively high UE mobility speeds can be measured.

Applicable Mode: N
MaxMimoLayerCnt Uplink Maximum MIMO Layer Count Quota

Meaning: Indicates the maximum transport layer count quota for spatial multiplexing in uplink MIMO of a cell. This parameter does not take effect for low-frequency NR DU cells with NRDUCellTrp.TxRxMode set to 1T1R, 2R, 4R, 2T2R, 2T4R, 4T4R, or 8T8R. In this case, the maximum number of layers for uplink MIMO depends on the number of receive antennas in the cell.

GUI Value Range: LAYER_2(2 Layers), LAYER_4(4 Layers), LAYER_6(6 Layers), LAYER_8(8 Layers)

Unit: None

Actual Value Range: LAYER_2, LAYER_4, LAYER_6, LAYER_8

MML Default Value: None

Recommended Value: LAYER_2(2 Layers)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A larger value of this parameter leads to more transport layers allowed by the cell and increases cell throughput and spectral efficiency. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
UlPuschAlgoSwitch Uplink PUSCH Algorithm Switch

Meaning: Indicates whether to enable functions related to uplink PUSCH scheduling.

UL_PAMC_SWITCH: Indicates whether to enable uplink PAMC.

MSG3_TRANSFORMPRECODE_SWITCH: Indicates whether to configure a single carrier for the first uplink transmission and retransmission, for DCI_0_0 transmission, and when the transformPrecoder IE is not configured in PUSCH-Config. When this option is selected, the single-carrier waveform applies in the uplink for the UE. When this option is deselected, the multi-carrier waveform applies in the uplink for the UE.

GUI Value Range: UL_PAMC_SWITCH(Uplink PAMC Switch), MSG3_TRANSFORMPRECODE_SWITCH(Msg3 Transform Precoding Switch)

Unit: None

Actual Value Range: UL_PAMC_SWITCH, MSG3_TRANSFORMPRECODE_SWITCH

MML Default Value: None

Recommended Value: UL_PAMC_SWITCH: Off,

MSG3_TRANSFORMPRECODE_SWITCH: On

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: UL_PAMC_SWITCH: If this option is selected, the uplink user-perceived throughput increases and the uplink IBLER fluctuates. If this option is deselected, network performance is not affected.

MSG3_TRANSFORMPRECODE_SWITCH: If this option is selected, Msg3 can be transmitted at higher power to improve the coverage of Msg3. If this option is deselected, Msg3 is transmitted at normal power.

Applicable Mode: N
UlTargetIbler Uplink Target IBLER

Meaning: Indicates the uplink target IBLER when the uplink IBLER adaption algorithm is disabled.

GUI Value Range: 0~100

Unit: None

Actual Value Range: 0~1, step: 0.01

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower IBLER of cells and UEs and a lower MCS order. A larger value of this parameter leads to the opposite effects.

Applicable Mode: N
SinrThldforWaveformSel SINR Threshold for Waveform Selection

Meaning: Indicates the SINR threshold for waveform selection. The UE uses DFT-s-OFDM only when the SINR of the UE is less than this threshold.

GUI Value Range: -100~200

Unit: 0.1dB

Actual Value Range: -10~20

MML Default Value: None

Recommended Value: 32

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability that the UE uses DFT-s-OFDM, a higher probability that the UE can transmit higher power, and a higher probability that the allocated RBs are reduced. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
UlVonrRsvdRbNum UL VoNR Reserved RB Number

Meaning: Indicates the number of RB resources reserved for VoNR in the uplink. This parameter takes effect only when the UL_RB_RSV_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected. This parameter applies only to low-frequency cells.

GUI Value Range: N10(10), N15(15), N20(20), N25(25), N30(30), N35(35), N40(40)

Unit: None

Actual Value Range: N10, N15, N20, N25, N30, N35, N40

MML Default Value: None

Recommended Value: N10(10)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a larger increase in the uplink voice quality of voice UEs and a larger decrease in the peak uplink throughput of data services in the cell. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
UlVonrRsvdRbStartPos UL VoNR Reserved RB Start Position

Meaning: Indicates the start position of RB resources reserved for VoNR in the uplink. This parameter takes effect only when the UL_RB_RSV_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected. This parameter applies only to low-frequency cells.

GUI Value Range: 0~273

Unit: None

Actual Value Range: 0~273

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
UlPreallocationSwitch Uplink Preallocation Switch

Meaning: Indicates whether to enable uplink preallocation.

UL_BASIC_PREALLOCATION_SWITCH: Indicates whether to enable uplink basic preallocation.

UL_SMART_PREALLOCATION_SWITCH: Indicates whether to enable uplink smart preallocation.

GUI Value Range: UL_BASIC_PREALLOCATION_SWITCH(Basic Uplink Preallocation Switch), UL_SMART_PREALLOCATION_SWITCH(Smart Uplink Preallocation Switch)

Unit: None

Actual Value Range: UL_BASIC_PREALLOCATION_SWITCH, UL_SMART_PREALLOCATION_SWITCH

MML Default Value: None

Recommended Value: UL_BASIC_PREALLOCATION_SWITCH:Off, UL_SMART_PREALLOCATION_SWITCH:On

Parameter Relationship:

-Configuration constraints:

  • The UL_BASIC_PREALLOCATION_SWITCH and the UL_SMART_PREALLOCATION_SWITCH options of UlPreallocationSwitch in the NRDUCellPusch MO cannot be selected at the same time.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_BASIC_PREALLOCATION_SWITCH: If this option is deselected, uplink basic preallocation is disabled, which has no impact on network performance. If this option is selected, uplink basic preallocation is enabled, and the user-perceived delay decreases. However, uplink interference increases, and UE power consumption increases.

UL_SMART_PREALLOCATION_SWITCH: If this option is deselected, uplink smart preallocation is disabled, which has no impact on network performance. If this option is selected, uplink smart preallocation is enabled, and the user-perceived delay is decreased. Uplink smart preallocation delivers less delay decrease, less interference, and less UE power consumption than uplink basic preallocation does.

Applicable Mode: N
UlSmartPreallocationDur Uplink Smart Preallocation Duration

Meaning: Indicates the duration for uplink smart preallocation.

GUI Value Range: 1~2000

Unit: ms

Actual Value Range: 1~2000

MML Default Value: None

Recommended Value: 250

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer duration for uplink smart preallocation and better improvement in the delay of uplink services. However, the UE power consumption and uplink interference increase. A smaller value of this parameter results in the opposite effects. In addition, if this parameter is set to a value greater than 1000 and the value is in the valid value range, the ping delay is reduced.

Applicable Mode: N

Example

To modify the PUSCH configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, Maximum MIMO Layer Count: LAYER_4, run the following command:
MOD NRDUCELLPUSCH: NrDuCellId=88, MaxMimoLayerCnt=LAYER_4;
