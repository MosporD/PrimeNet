List gNodeB OAM Param (LST GNBOAMPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list gNodeB-level operation and maintenance parameters.

Note

None.

Parameters

None.

Example

To list gNodeB-level Operation and maintenance parameters, run the following command:
LST GNBOAMPARAM::
The result is shown as follows:
+++    0        2020-02-21 21:51:41
O&M    #2685403172
%%LST GNBOAMPARAM:;%%
RETCODE = 0  Operation succeeded.

List gNodeB OAM Param
---------------
Statistics Strategy Switch  =  NSA CBRA Statistics Optimization Switch:Off
(Number of results = 1)


---    END

Output Description

Field Description

Statistics Strategy Switch

Indicates the switches controlling counter statistics collection policies. NSA_CBRA_STATISTICS_OPT_SW: Indicates whether to enable statistics collection optimization for contention-based random access in NSA scenarios. If this option is selected and the base station triggers NSA UE access, all contention-based random access statistics within a fixed period of time are counted in related counters and contention-based random access statistics not within the fixed period of time are not counted. If this option is deselected, all contention-based random access statistics at any time are counted in related counters. It is recommended that this function be used in light-load scenarios. This parameter applies only to low-frequency TDD, FDD, and SUL cells. This parameter takes effect only for cells in NSA networking.
