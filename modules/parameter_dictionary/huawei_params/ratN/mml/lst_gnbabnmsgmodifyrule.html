List gNodeB Debugging Message Modifying Rule (LST GNBABNMSGMODIFYRULE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query gNodeB debugging message-based modification rule configurations.

Note

None.

Parameters

ID Name Description
ModifyRuleIndex Modify Rule Index

Meaning: Indicates the index of a debugging message-based modification rule.

GUI Value Range: 1~100

Unit: None

Actual Value Range: 1~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list gNodeB debugging message modifying rule, run the following command:
LST GNBABNMSGMODIFYRULE:;
The result is shown as follows:
+++    0        2018-06-04 17:58:17
O&M    #2685403172
%%LST GNBABNMSGMODIFYRULE:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Debugging Message Modifying Rule
--------------------------------------------
  Modify Rule Index  =  1
Modify Field Offset  =  24
      Modify Length  =  2
     Modify Content  =  00
(Number of results = 1)


---    END

Output Description

Field Description

Modify Rule Index

Indicates the index of a debugging message-based modification rule.

Modify Field Offset

Indicates the modification field offset of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

Modify Length

Indicates the modification length of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.

Modify Content

Indicates the modification content of the message received or sent by the gNodeB. The modification content is a hexadecimal number that consists of 1 to 100 characters. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
