Add NR External gNodeB (ADD NREXTERNALGNB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the configurations of an NR external gNodeB.

Note

This command is related to interconnection with gNodeBs not provided Huawei. Run this command under the guidance of Huawei technical support.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in the NRExternalgNB MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in the NRExternalgNB MO consists of digits only.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the gNodeB ID of an external NR cell. It uniquely identifies a gNodeB within a PLMN. The NR Cell Identity (NCI) is comprised of the cell ID and the gNodeB ID. The gNodeB ID is represented by the most significant 22 to 32 bits of the NCI. The NR cell global identifier (NCGI) is comprised of the NCI and the PLMN ID. For details, see 3GPP TS 38.413.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
PlmnPolicy PLMN Policy

Meaning: Indicates the policy of configuring the PLMN in the Global gNB ID of a neighboring gNodeB for an operator. If this parameter is set to PRIMARY_PLMN_PREFER, the primary-operator PLMN of the gNodeB is specified in the Global gNB ID for the given operator. If this parameter is set to SELECTED_PLMN_PREFER, the given operator's PLMN is specified in the Global gNB ID for the given operator.

GUI Value Range: PRIMARY_PLMN_PREFER, SELECTED_PLMN_PREFER

Unit: None

Actual Value Range: PRIMARY_PLMN_PREFER, SELECTED_PLMN_PREFER

MML Default Value: PRIMARY_PLMN_PREFER

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add an external gNodeB with the parameters as follows: Mobile Country Code: "302", Mobile Network Code: "220", gNodeB ID: 1, run the following command:
ADD NREXTERNALGNB: Mcc="302", Mnc="220", gNBId=1;
