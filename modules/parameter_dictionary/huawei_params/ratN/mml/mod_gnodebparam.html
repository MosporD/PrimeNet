Modify gNodeB Parameter (MOD GNODEBPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of a gNodeB Parameter.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

In LTE-NR co-MPT scenarios and co-BBU separate-MPT scenarios with backplane co-transmission, the X2uTransmissionType parameter cannot be set to ROUTING_TRANS. Otherwise, the SCG fails to be added in NSA DC scenarios. This restriction does not apply to other scenarios.

Parameters

ID Name Description
FrameOffset Frame Offset

Meaning: Indicates the offset of the frame start time for all the cells served by the gNodeB relative to the time of the reference clock.

If this parameter is set to a value in the range of 0 to 261120, the reference clock is delayed. The hysteresis is equal to the GUI value.

If this parameter is set to a value in the range of 275943 to 307200, the time advance is equal to 307200 minus the GUI value.

If the frame offset is configured for a cell working in a specific frequency band configured in the gNBFreqBandConfig MO, this frame offset takes effect preferentially.

GUI Value Range: 0~261120,275943~307200

Unit: Ts

Actual Value Range: 0~261120,275943~307200

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: In the case of intra-NR TDD systems or when NR TDD coexists with other TDD systems such as LTE TDD, WiMAX, TD-SCDMA, and PHS and the spectrum is close to each other, modifying the frame offset causes intra-RAT or inter-RAT unaligned uplink and downlink timeslots, which may cause severe interference. The access success rate and handover success rate decrease as a result.

Applicable Mode: N
AoaMeasSnrThld SNR Threshold for AOA Measurement

Meaning: Indicates the threshold of the signal-to-noise ratio for triggering angle of arrival (AoA) measurement. The AoA of signals transmitted or received by UEs needs to be measured to locate UEs. The gNodeB measures the AoA only when the signal-to-noise ratio of the signals reaches this threshold.

GUI Value Range: -10000~2000

Unit: 0.01dB

Actual Value Range: -100~20

MML Default Value: None

Recommended Value: -800

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a decreased number of UEs reporting measurement results and a decreased number of UEs with poor measurement precision. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
FrameOffsetAutoCorrectSw Frame Offset Auto Correction Switch

Meaning: Indicates whether to enable automatic frame offset correction. If this parameter is set to ON and the frame offset of the local gNodeB is different from that of other gNodeBs, the local gNodeB automatically changes the frame offset to that of other gNodeBs. If this parameter is set to OFF, the gNodeB cannot automatically change the frame offset.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
X2uTransmissionType X2-U Transmission Type

Meaning: Indicates the transmission mode of user-plane data between LTE and NR in NSA DC scenarios. If this parameter is set to ROUTING_TRANS, user-plane data between LTE and NR is transmitted based on route configurations. If this parameter is set to INTRA_TRANS, user-plane data between LTE and NR is transmitted through an internal network (CI interconnection or backplane transmission). If the internal network is unavailable, user-plane data is transmitted based on route configurations. This mode takes effect only in multimode co-site scenarios. Modification to this parameter applies only to UEs newly accessing the network. It does not apply to UEs that have accessed the network.

GUI Value Range: ROUTING_TRANS(Based on Route Configuration), INTRA_TRANS(Through Internal Network)

Unit: None

Actual Value Range: ROUTING_TRANS, INTRA_TRANS

MML Default Value: None

Recommended Value: INTRA_TRANS(Through Internal Network)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When user-plane data between LTE and NR is transmitted through an internal network, the transmission delay is reduced and user experience is improved.

Applicable Mode: N
NsaDcResCoordScenario NSA DC Resource Coordination Scenario

Meaning: Indicates the resource coordination application scenarios in NSA DC. When the CROSS_MDLT_INTRF_AVOID_SW or HARMONIC_INTRF_AVOID_SW option of the NRDUCellAlgoSwitch.NsaDcAlgoSwitch parameter or the NSA_DC_ENH_UL_POWER_CONTROL_SW option of the NRCellNsaDcConfig.NsaDcAlgoSwitch parameter is selected, the gNodeB generates different resource coordination diagrams based on this parameter and sends them to the eNodeB. The value SYNC_NSA_DC_0_FRAME_OFT indicates synchronous DC with the relative frame offset between LTE and NR being 0 ms. The value SYNC_NSA_DC_3Pl2Mi_FRAME_OFT indicates synchronous DC with the frame offset of NR relative to LTE being plus 3 ms or minus 2 ms. The value ASYNC_NSA_DC indicates asynchronous DC. The intermodulation interference avoidance function and TDM power control function do not take effect in asynchronous NSA DC mode. If this parameter value is changed, this parameter takes effect only for UEs that newly access the network.

GUI Value Range: SYNC_NSA_DC_0_FRAME_OFS(Sync NSA DC Zero Frame Ofs), SYNC_NSA_DC_3PL2MI_FRAME_OFS(Sync NSA DC Plus 3 or Minus 2 Frame Ofs), ASYNC_NSA_DC(Asynchronous NSA DC)

Unit: None

Actual Value Range: SYNC_NSA_DC_0_FRAME_OFS, SYNC_NSA_DC_3PL2MI_FRAME_OFS, ASYNC_NSA_DC

MML Default Value: None

Recommended Value: SYNC_NSA_DC_0_FRAME_OFS(Synchronous NSA DC Zero Frame Offset)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the value of this parameter is changed, the new value takes effect only for new NSA DC UEs. If an old NSA DC UE exists, the gNodeB uses the old parameter value when generating a resource coordination diagram for the UE. As a result, the diagram does not comply with the actual NSA DC networking, which may lead to a decrease in the uplink and downlink throughput in the NSA DC networking.

Applicable Mode: N
ClkOutofsyncDetSwitch Clock Out-of-sync Detect Switch

Meaning: Indicates the clock out-of-synchronization configuration switches.

CLK_DETECT_SW: Indicates whether to enable clock out-of-synchronization detection. Clock out-of-synchronization detection is enabled only if this option is selected. This option applies only to low-frequency TDD cells.

CLK_PROCESS_SW: Indicates whether to enable postprocessing for clock out-of-synchronization. If this option is deselected, the gNodeB does not take any measure after clock out-of-synchronization. If this option is selected, the gNodeB deactivates all NR TDD cells served by the gNodeB after clock out-of-synchronization. This option applies only to low-frequency TDD cells.

GUI Value Range: CLK_DETECT_SW(Clock Detection Switch), CLK_PROCESS_SW(Clock Out-of-Sync Postprocessing Switch)

Unit: None

Actual Value Range: CLK_DETECT_SW, CLK_PROCESS_SW

MML Default Value: None

Recommended Value: CLK_DETECT_SW:On, CLK_PROCESS_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: CLK_DETECT_SW: If this option is deselected, the clock out-of-synchronization detection function does not take effect. If a base station experiences clock out-of-synchronization, the base station cannot automatically detect the fault or generate an alarm. This does not facilitate troubleshooting of clock out-of-synchronization and cannot improve KPIs. If this option is selected, the clock out-of-synchronization detection function takes effect. If a base station experiences clock out-of-synchronization, the base station reports an alarm and automatically deactivates the TDD cells based on the setting of the CLK_PROCESS_SW option to avoid interference to neighboring sites.

CLK_PROCESS_SW: If this option is deselected, the out-of-synchronization base station does not take postprocessing measures. As a result, the out-of-synchronization base station causes co-channel interference to neighboring sites. If this option is selected, the out-of-synchronization base station automatically deactivates all NR TDD cells served by the base station. As a result, these TDD cells become unavailable. You can deselect this option to restore the status before the postprocessing function takes effect.

Applicable Mode: N-TDD-FR1
ClkOutofsyncIntrfRptThld Clock Out-of-sync Intrf Report Thld

Meaning: Indicates the threshold for reporting the clock out-of-synchronization interference value. If the average uplink interference is greater than this threshold, the base station reports the clock out-of-synchronization interference value. Then, the clock out-of-synchronization function detects the characteristic sequence. This parameter applies only to low frequency TDD cells.

GUI Value Range: -130~-50

Unit: dBm

Actual Value Range: -130~-50

MML Default Value: None

Recommended Value: -95

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering characteristic sequence detection. A smaller value of this parameter results in a higher probability.

Applicable Mode: N-TDD-FR1
SilDetIntrfDiffThld Silence Detect Intrf Difference Thld

Meaning: Indicates the interference difference threshold for silence detection in the clock out-of-synchronization detection. It is used to locate out-of-synchronization base stations. When the intersymbol interference difference between base stations performing silence detection is greater than this threshold, the silent base station is regarded as an out-of-synchronization base station. This parameter applies only to low frequency TDD cells.

GUI Value Range: -10~30

Unit: dB

Actual Value Range: -10~30

MML Default Value: None

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability that a silent base station is regarded as an out-of-synchronization base station. A smaller value of this parameter results in a higher probability.

Applicable Mode: N-TDD-FR1
NsaDcOptSwitch NSA DC Optimization Switch

Meaning: Indicates whether to enable NSA DC optimization.

NSA_DC_SRB3_SWITCH: Indicates whether to support the NSA DC SRB3 function. This function is enabled only if this option is selected. When this function is enabled, the gNodeB and UE can exchange signaling using SRB3. For details about this option, see 3GPP TS 37.340.

NSA_DC_FAST_RETRANS_SWITCH: Indicates whether to support fast retransmission for downlink data split in NSA DC scenarios. This function is supported only if this option is selected.

NON_CA_NSA_DC_COMB_SELECT_SW: Indicates whether to preferentially guarantee the throughput on the LTE side or the throughput on the NR side in non-CA scenarios. If this option is selected, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the NR side. If this option is deselected, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the LTE side.

GUI Value Range: NSA_DC_SRB3_SWITCH(NSA DC SRB3 Switch), NSA_DC_FAST_RETRANS_SWITCH(NSA DC Fast Retrans Switch), NON_CA_NSA_DC_COMB_SELECT_SW(Non-CA NSA DC Combination Select Switch)

Unit: None

Actual Value Range: NSA_DC_SRB3_SWITCH, NSA_DC_FAST_RETRANS_SWITCH, NON_CA_NSA_DC_COMB_SELECT_SW

MML Default Value: None

Recommended Value: NSA_DC_SRB3_SWITCH:Off, NSA_DC_FAST_RETRANS_SWITCH:Off, NON_CA_NSA_DC_COMB_SELECT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NSA_DC_SRB3_SWITCH: If this option is selected, the gNodeB and UE can exchange signaling using SRB3 in NSA networking, reducing signaling overheads on the LTE side. If this option is deselected, network performance is not affected.

NSA_DC_FAST_RETRANS_SWITCH: In downlink data split scenarios, if this option is selected, the NSA DC data split throughput increases. If this option is deselected, network performance is not affected.

NON_CA_NSA_DC_COMB_SELECT_SW: If this option is selected in non-CA scenarios, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the NR side, increasing the NR throughput. If the number of LTE carriers, bandwidth, and MIMO capability corresponding to the NSA DC combination are not the maximum, the LTE throughput decreases. If this option is deselected, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the LTE side, increasing the LTE throughput. If the bandwidth and MIMO capability on the NR side corresponding to the NSA DC combination are not the maximum, the NR throughput decreases.

Applicable Mode: N

SyncDiffDetectSwitch Synchronization Difference Detect Switch

Meaning: Indicates whether to enable clock synchronization deviation detection. If this parameter is set to ON, clock synchronization deviation detection is enabled on the local gNodeB. If this parameter is set to OFF, clock synchronization deviation detection is disabled on the local gNodeB. This parameter applies only to low-frequency TDD cells.

GUI Value Range: GAP_BASED_SYNC_DIFF_DET_SW(Gap-based Sync Deviation Detect Switch)

Unit: None

Actual Value Range: GAP_BASED_SYNC_DIFF_DET_SW

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: GAP_BASED_SYNC_DIFF_DET_SW: If this option is deselected, clock synchronization deviation detection does not take effect. In this case, base stations with clock deviations cannot be automatically detected. If this option is selected, clock synchronization deviation detection takes effect. Base stations with clock deviations detected are displayed on the EMS GUI, improving the efficiency of locating clock deviations.

Applicable Mode: N-TDD-FR1
MaxFhFiberLengthAdaptSw Max FH Fiber Length Adapt Switch

Meaning: Indicates whether the gNodeB adaptively selects a time budget based on the length of optical fiber for fronthaul in eCPRI/CPRI scenarios.

When this switch is turned on, the gNodeB automatically detects the length of optical fiber for fronthaul and adaptively selects a time budget based on the length. If the time budget for the 0.5 km length is used, better delay gains can be obtained. In this case, inter-BBP eCPRI/CPRI forwarding is not supported. When this switch is turned off, the gNodeB does not adaptively select a time budget and the time budget for the 20 km length is used by default.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: When this switch is turned on and the length of optical fiber for fronthaul is less than or equal to 0.5 km, the data transmission delay of UEs is shortened. In other scenarios, network performance is not affected.

Applicable Mode: N
MaxX2TransRate Max X2 Transmission Rate

Meaning: Indicates the maximum transmission rate for PDCP data split and data forwarding over the X2 interface in NSA DC scenarios. The value that takes effect equals the GUI value multiplied by the step. The packet transmission rate at the PDCP layer is the value that takes effect converted into megabits per millisecond.

GUI Value Range: 1~100

Unit: 100Mbps

Actual Value Range: 100~10000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower transmission rate over the X2 interface. A larger value of this parameter leads to a higher transmission rate over the X2 interface. If this parameter is set to a value greater than the transmission bandwidth, packet loss occurs and throughput decreases. If this parameter is set to a value less than the air interface capability of the target LTE cell (the cell's total air interface capability in CA configurations), the rate of an NSA UE is limited on the LTE side, and LTE resources cannot be fully used, thereby restricting the total rate of the NSA UE. Moreover, the forwarding rate is also limited, meaning slow data forwarding. If a handover occurs again during forwarding, packet loss occurs as well.

Applicable Mode: N
ServInterfaceAlmConfigSw Service Interface Alarm Config Switch

Meaning: Indicates whether to suppress the fault alarms of lower-layer links carrying terrestrial interfaces.

BEARER_OF_X2_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an X2 interface fault and an X2 transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29800 gNodeB X2 Interface Fault is reported when the values of GlobaleNodeBId_MCC-MNC-eNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_XN_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an Xn interface fault and an Xn transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29810 gNodeB Xn Interface Fault is reported when the values of GlobalgNBId_MCC-MNC-gNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_NG_SHIELD_SW: Indicates whether to suppress the transmission link alarm (ALM-25888 SCTP Link Fault). If this option is selected and an NG interface fault and an NG transmission link fault occur at the same time, the transmission link alarm is suppressed and only ALM-29815 gNodeB NG Interface Fault is reported. If this option is deselected, the transmission link alarm is not suppressed.

GUI Value Range: BEARER_OF_X2_SHIELD_SW(X2 Lower Layer Link Alarm Shield Switch), BEARER_OF_XN_SHIELD_SW(Xn Lower Layer Link Alarm Shield Switch), BEARER_OF_NG_SHIELD_SW(NG Lower Layer Link Alarm Shield Switch)

Unit: None

Actual Value Range: BEARER_OF_X2_SHIELD_SW, BEARER_OF_XN_SHIELD_SW, BEARER_OF_NG_SHIELD_SW

MML Default Value: None

Recommended Value: BEARER_OF_X2_SHIELD_SW:On, BEARER_OF_XN_SHIELD_SW:On, BEARER_OF_NG_SHIELD_SW:On

Example

To modify the settings of gNodeB parameter with the parameters as follows: FRAME OFFSET set to 0, run the following command:
MOD GNODEBPARAM: FrameOffset=0;
