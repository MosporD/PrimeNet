Modify gNodeB Frequency Priority Group (MOD GNBFREQPRIORITYGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a gNodeB frequency priority group.

Note

None.

Parameters

ID Name Description
gNBFreqPriorityGroupId gNodeB Frequency Priority Group ID

Meaning: Indicates the ID of a gNodeB frequency priority group.

GUI Value Range: 0~254

Unit: None

Actual Value Range: 0~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • A maximum of eight gNBFreqPriorityGroup MO instances with the same gNBFreqPriorityGroupId and RatType can be configured.
  • In the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId, the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to EUTRAN must be different from the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to NR.
  • The values of SsbFreqPos in the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId and RatType set to NR must be different.
  • The values of DlEarfcn in the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId and RatType set to EUTRAN must be different.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD

CellReselPri Cell Reselection Priority

Meaning: Indicates the cell reselection priority of the frequency. Value 0 indicates the lowest priority, and value 7 indicates the highest priority.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • In the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId, the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to EUTRAN must be different from the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to NR.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter indicates a higher priority and a higher probability of UEs in idle mode reselecting to this frequency. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD, N-FDD
CellReselSubPri Cell Reselection Sub-Priority

Meaning: Indicates the cell reselection sub-priority of the frequency. If this parameter is set to the invalid value 0DOT0, the sub-priority is not delivered. If this parameter is set to a valid value, the UE adds the value of this parameter to that of the gNBFreqPriorityGroup.CellReselPri parameter, uses the sum as the final cell reselection priority of the frequency, and performs cell reselection accordingly.

The summed values of the reselection priority and reselection sub-priority must be different between RATs. For details, see 3GPP TS 38.331.

GUI Value Range: 0DOT0(0), 0DOT2(0.2), 0DOT4(0.4), 0DOT6(0.6), 0DOT8(0.8)

Unit: None

Actual Value Range: 0DOT0, 0DOT2, 0DOT4, 0DOT6, 0DOT8

MML Default Value: None

Recommended Value: 0DOT0(0)

Parameter Relationship:

-Configuration constraints:

  • In the gNBFreqPriorityGroup MOs with the same gNBFreqPriorityGroupId, the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to EUTRAN must be different from the sum of the values of CellReselSubPri and CellReselPri corresponding to FreqIndex when RatType is set to NR.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD

Meaning: Indicates the SSB frequency domain position of an NR frequency. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN, this parameter indicates the Global Synchronization Channel Number (GSCN) corresponding to the SSB of the NR frequency. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, this parameter indicates the absolute frequency number corresponding to the SSB of the NR frequency.

ConnDedFreqPriority Dedicated Freq Priority for Connected Mode

Meaning: Indicates the connected-mode dedicated priority of a neighboring frequency. The connected-mode frequency priorities can be operator-specific. A larger value of this parameter indicates a higher priority. If this parameter is set to 0, the frequency is not selected as the candidate frequency for operator-specific priority-based handovers.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher priority and a higher probability of handovers to cells on this frequency. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify a gNodeB frequency priority group with gNodeB Frequency Priority Group ID set to 0, Frequency Index set to 0, RAT Type set to EUTRAN, Downlink EARFCN set to 0, Cell Reselection Sub-Priority set to 3, Cell Reselection Priority set to 0DOT2, and Dedicated Freq Priority for Connected Mode set to 1, run the following command:
MOD GNBFREQPRIORITYGROUP: gNBFreqPriorityGroupId=0, FreqIndex=0, RatType=EUTRAN, DlEarfcn=0, CellReselPri=3, CellReselSubPri=0DOT2, ConnDedFreqPriority=1;
