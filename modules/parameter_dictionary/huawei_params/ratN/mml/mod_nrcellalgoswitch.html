Modify NR Cell Algorithm Switch (MOD NRCELLALGOSWITCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of NR-cell-level algorithm switches.

Note

Do not execute this command in busy hours.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NsaDcSwitch NSA DC Switch

Meaning: Indicates whether to enable the LTE-NR non-standalone (NSA) dual connectivity (DC) function. The LTE-NR NSA DC function is enabled only if this switch is turned on on both the master base station and secondary base station. With this function, a UE can access an eNodeB and a gNodeB simultaneously and use resources of both base stations. The LTE-NR NSA DC function is disabled if this switch is turned off on the master base station or secondary base station.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
UlDlDecouplingAlgoSwitch UL and DL Decoupling Algorithm Switch

Meaning: Indicates the NR uplink and downlink decoupling algorithm switch.

UL_CARR_SEL_FOR_UE_EXP_SW: Indicates whether to enable user-experience-based uplink carrier selection.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: UL_CARR_SEL_FOR_UE_EXP_SW(User Experience UL Carrier Selection Sw)

Unit: None

Actual Value Range: UL_CARR_SEL_FOR_UE_EXP_SW

MML Default Value: None

Recommended Value: SA scenarios: UL_CARR_SEL_FOR_UE_EXP_SW: On;

NSA+SA/NSA scenarios: UL_CARR_SEL_FOR_UE_EXP_SW: Off.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: UL_CARR_SEL_FOR_UE_EXP_SW: If this option is deselected, the uplink camping frequency is selected only based on the NR TDD uplink SRS RSRP threshold. If this option is selected, the uplink camping frequency is selected for a UE in connected mode based on whether the optimal user experience can be guaranteed, which improves user experience. In this case, SRS measurement on the SUL is required, which causes LTE performance to deteriorate in NSA networking.

Applicable Mode: N-SUL
VoiceStrategySwitch Voice Strategy Switch

Meaning: Indicates the 5G voice policy control switch. EPS_FB_SWITCH(EPS Fallback Switch): Indicates whether to enable voice fallback from NG-RAN to E-UTRAN.

GUI Value Range: EPS_FB_SWITCH(EPS Fallback Switch)

Unit: None

Actual Value Range: EPS_FB_SWITCH

MML Default Value: None

Recommended Value: EPS_FB_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: EPS_FB_SWITCH(EPS Fallback Switch): If this option is selected, the gNodeB falls back voice services initiated by UEs to an LTE network through a PS handover procedure. This facilitates fast voice service roll-out in the initial 5G deployment phase featuring discontinuous NR coverage or in the case of insufficient IMS deployments. When this option is deselected, voice services initiating on an NR network cannot fall back to an LTE network.

Applicable Mode: N
InterRatServiceMobilitySw Inter-RAT Service Mobility Switch

Meaning: Indicates whether to enable inter-RAT mobility. When this switch is turned on, inter-RAT mobility from NG-RAN to E-UTRAN is enabled, and UEs can be reselected, handed over, or redirected from an NR cell to an E-UTRAN cell. When this switch is turned off, inter-RAT mobility from NG-RAN to E-UTRAN is disabled.

GUI Value Range: MOBILITY_TO_EUTRAN_SW(Mobility To E-UTRAN Switch)

Unit: None

Actual Value Range: MOBILITY_TO_EUTRAN_SW

MML Default Value: None

Recommended Value: MOBILITY_TO_EUTRAN_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: MOBILITY_TO_EUTRAN_SW: If this option is selected, inter-RAT mobility from NG-RAN to E-UTRAN is enabled, and UEs can be reselected, handed over, or redirected from an NR cell to an E-UTRAN cell. This helps reduce the service drop rate. If this option is deselected, network performance is not affected.

Applicable Mode: N
AnrSwitch ANR Switch

Meaning: Indicates whether to enable automatic neighbor relation (ANR) for a cell.

NR_NR_ANR_SW: Indicates whether to enable intra-NR ANR.

NR_EUTRAN_ANR_SW: Indicates whether to enable ANR with E-UTRAN.

NR_NR_ANR_DEL_SW: Indicates whether to enable neighbor relationship removal by intra-NR ANR.

NR_EUTRAN_ANR_DEL_SW: Indicates whether to enable neighbor relationship removal by ANR with E-UTRAN.

NR_NR_ANR_AUTO_NO_HO_SW: Indicates whether to enable the function of automatically prohibiting handovers to neighboring NR cells.

NR_EUTRAN_ANR_AUTO_NO_HO_SW: Indicates whether to enable the function of automatically prohibiting handovers to neighboring E-UTRAN cells.

PCI_COLLISION_DETECT_SW: Indicates whether to enable PCI collision detection in a cell.

PCI_CONFUSION_DETECT_SW: Indicates whether to enable PCI confusion detection in a cell.

NR_NR_ANR_OVER_DIST_DETECT_SW: Indicates whether to detect over-distant neighboring NR cells and automatically prohibit handovers to such cells if detected.

GUI Value Range: NR_NR_ANR_SW(NR and NR ANR Switch), NR_EUTRAN_ANR_SW(NR and E-UTRAN ANR Switch), NR_NR_ANR_DEL_SW(NR and NR Self-Removal Switch), NR_EUTRAN_ANR_DEL_SW(NR and E-UTRAN Self-Removal Switch), NR_NR_ANR_AUTO_NO_HO_SW(NR and NR Auto Handover Forbidden Sw), NR_EUTRAN_ANR_AUTO_NO_HO_SW(NR and E-UTRAN Auto HO Forbidden Switch), PCI_COLLISION_DETECT_SW(PCI Collision Detect Switch), PCI_CONFUSION_DETECT_SW(PCI Confusion Detect Switch), NR_NR_ANR_OVER_DIST_DETECT_SW(Overdistant Neighbor NR Cell Detect Sw)

Unit: None

Actual Value Range: NR_NR_ANR_SW, NR_EUTRAN_ANR_SW, NR_NR_ANR_DEL_SW, NR_EUTRAN_ANR_DEL_SW, NR_NR_ANR_AUTO_NO_HO_SW, NR_EUTRAN_ANR_AUTO_NO_HO_SW, PCI_COLLISION_DETECT_SW, PCI_CONFUSION_DETECT_SW, NR_NR_ANR_OVER_DIST_DETECT_SW

MML Default Value: None

Recommended Value: NR_NR_ANR_SW:On, NR_EUTRAN_ANR_SW:On, NR_NR_ANR_DEL_SW:On, NR_EUTRAN_ANR_DEL_SW:On, NR_NR_ANR_AUTO_NO_HO_SW:On, NR_EUTRAN_ANR_AUTO_NO_HO_SW:On, PCI_COLLISION_DETECT_SW:On, PCI_CONFUSION_DETECT_SW:On, NR_NR_ANR_OVER_DIST_DETECT_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: NR_NR_ANR_SW: When this option is selected, neighbor relationships with NR cells are automatically configured, reducing the intra-RAT handover failure rate caused by missing configuration of neighboring cells. When this option is deselected, neighbor relationships with NR cells are not automatically configured.

NR_EUTRAN_ANR_SW: When this option is selected, neighbor relationships with E-UTRAN cells are automatically configured, reducing the inter-RAT handover failure rate caused by missing configuration of neighboring cells. When this option is deselected, neighbor relationships with E-UTRAN cells are not automatically configured.

NR_NR_ANR_DEL_SW: When this option is selected, low-usage neighbor relationships with NR cells are removed when NR neighbor relationship specifications are reached and new neighbor relationships with NR cells need to be added. This reduces the intra-RAT handover failure rate caused by missing configuration of neighboring cells. When this option is deselected, neighbor relationships with NR cells are not automatically removed.

NR_EUTRAN_ANR_DEL_SW: When this option is selected, low-usage neighbor relationships with E-UTRAN cells are removed when E-UTRAN neighbor relationship specifications are reached and new neighbor relationships with E-UTRAN cells need to be added. This reduces the inter-RAT handover failure rate caused by missing configuration of neighboring cells. When this option is deselected, neighbor relationships with E-UTRAN cells are not automatically removed.

NR_NR_ANR_AUTO_NO_HO_SW: When this option is selected, the base station automatically sets the no handover flag for neighboring NR cells with low handover success rates. This prevents handover failures caused by handovers to such neighboring cells and increases the intra-RAT handover success rate. When this option is deselected, the base station does not automatically set the no handover flag for neighboring NR cells.

NR_EUTRAN_ANR_AUTO_NO_HO_SW: When this option is selected, the base station automatically sets the no handover flag for neighboring E-UTRAN cells with low handover success rates. This prevents handover failures caused by handovers to such neighboring cells and increases the inter-RAT handover success rate. When this option is deselected, the base station does not automatically set the no handover flag for neighboring E-UTRAN cells.

PCI_COLLISION_DETECT_SW: When this option is selected, PCI collision detection is enabled and the detected PCI collision is reported. When this function works with the automatic PCI optimization function on the MAE, the detected PCI collision can be eliminated and interference caused by PCI collision can be mitigated. This increases the system throughput and reduces the service drop rate. When this option is deselected, automatic PCI collision detection is not enabled.

PCI_CONFUSION_DETECT_SW: When this option is selected, PCI confusion detection is enabled and the detected PCI confusion is reported. When this function works with the automatic PCI optimization function on the MAE, the detected PCI confusion can be eliminated to avoid handover failures due to PCI confusion. This increases the handover success rate. When this option is deselected, automatic PCI confusion detection is not enabled.

NR_NR_ANR_OVER_DIST_DETECT_SW: When this option is selected, the base station automatically identifies over-distant neighboring NR cells and prohibits handovers to these cells. This reduces failures of handovers to these cells and increases the intra-RAT handover success rate. When this option is deselected, the base station does not automatically detect over-distant neighboring cells. This has no impact on network performance.

Applicable Mode: N
InterFreqHoSwitch Inter-Frequency Handover Switch

Meaning: Indicates whether to enable intra-RAT inter-frequency handover algorithms.

COVERAGE_BASED_HO: Indicates whether to enable coverage-based inter-frequency handover. If this option is selected, coverage-based inter-frequency handovers are enabled to ensure service continuity. If this option is deselected, coverage-based inter-frequency handovers are disabled.

FREQ_PRIORITY_BASED_HO: Indicates whether to enable frequency-priority-based inter-frequency handover. Select this option if a frequency is dedicated for absorbing traffic. If this option is selected, frequency-priority-based handovers can be triggered for UEs even when the serving cell has good signal quality. If this option is deselected, frequency-priority-based inter-frequency handovers cannot be triggered for UEs, and inter-frequency handovers can be triggered only when other conditions for triggering handovers are met.

REDIRECTION: Indicates whether to enable inter-frequency redirection. If this option is selected, inter-frequency redirection and blind redirection are supported. If this option is deselected, inter-frequency redirection and blind redirection are not supported.

OP_DED_PRI_BASED_HO: Indicates whether to enable operator-specific-priority-based inter-frequency handover. If this option is selected, an operator-specific-priority-based inter-frequency handover can be triggered for a UE served by a frequency meeting the following condition: the frequency is not an NR frequency in the operator-associated frequency group with the dedicated frequency priority for the connected mode set to a non-zero value. If this option is deselected, operator-specific-priority-based inter-frequency handovers cannot be triggered for the UE.

GUI Value Range: COVERAGE_BASED_HO(Coverage-based Inter-freq HO Switch), FREQ_PRIORITY_BASED_HO(Freq-pri-based Inter-freq HO Switch), REDIRECTION(Inter-freq Redirection Switch), OP_DED_PRI_BASED_HO(Op-specific Pri-based Inter-freq HO Sw)

Unit: None

Actual Value Range: COVERAGE_BASED_HO, FREQ_PRIORITY_BASED_HO, REDIRECTION, OP_DED_PRI_BASED_HO

MML Default Value: None

Recommended Value: COVERAGE_BASED_HO:On, FREQ_PRIORITY_BASED_HO:Off, REDIRECTION:On, OP_DED_PRI_BASED_HO:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: COVERAGE_BASED_HO: When this option is selected, inter-frequency handovers ensure service continuity and reduce the service drop rate. When this option is deselected, the service drop rate may increase.

FREQ_PRIORITY_BASED_HO: When this option is selected, frequency-priority-based inter-frequency handovers are enabled. This increases the number of handovers but improves the data rates of UEs. When this option is deselected, network performance is not affected.

REDIRECTION: When this option is selected, coverage-based inter-frequency redirection can be triggered for UEs that do not support inter-frequency handovers. When the signal quality decreases sharply, blind redirection to another frequency can be performed to reduce the service drop rate. When this option is deselected, coverage-based inter-frequency redirection and blind redirection are disabled. This may increase the service drop rate.

OP_DED_PRI_BASED_HO: When this option is selected, operator-specific-priority-based inter-frequency handovers can be triggered for UEs. This increases the number of inter-frequency handovers but enables operator-level network steering. When this option is deselected, network performance is not affected.

Applicable Mode: N
VonrSwitch VoNR Switch

Meaning: Indicates the voice over NR (VoNR) function switches.

VONR_SW: Indicates whether to enable VoNR. VoNR is supported only if this option is selected. It is recommended that VoNR not be enabled in high-frequency scenarios.

UL_DELAY_COV_OPT_SW: Indicates whether to enable coverage optimization by uplink delay configuration of voice services. This option applies only to low-frequency TDD cells.

ANBR_SW: Indicates whether to enable access network bitrate recommendation (ANBR). This option applies only to low-frequency cells.

UL_RB_RSV_SW: Indicates whether to enable uplink RB reservation for voice services. This option applies only to low-frequency cells.

GUI Value Range: VONR_SW(VoNR Switch), UL_DELAY_COV_OPT_SW(UL Delay Coverage Optimization Switch), ANBR_SW(ANBR Switch), UL_RB_RSV_SW(Uplink RB Reservation Switch)

Unit: None

Actual Value Range: VONR_SW, UL_DELAY_COV_OPT_SW, ANBR_SW, UL_RB_RSV_SW

MML Default Value: None

Recommended Value: VONR_SW:Off, UL_DELAY_COV_OPT_SW:Off, ANBR_SW:Off, UL_RB_RSV_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
RohcSwitch ROHC Switch

Meaning: Indicates the switches related to robust header compression (ROHC).

ROHC_SW: Indicates whether to enable ROHC. If this option is selected, ROHC is enabled. In this case, the ROHC Profiles parameter must be set to determine the profile that takes effect. If this option is deselected, ROHC is disabled. This option applies only in low frequency bands.

GUI Value Range: ROHC_SW(ROHC Switch)

Unit: None

Actual Value Range: ROHC_SW

MML Default Value: None

Recommended Value: ROHC_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: ROHC_SW: If this option is selected, ROHC is enabled to reduce the overhead caused by packet header transmission over the air interface, improving the coverage of VoNR services. If this option is deselected, network performance is not affected.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
RohcProfiles ROHC Profiles

Meaning: Indicates ROHC profile configurations.

PROFILE0X0001: Indicates the profile for RTP/UDP/IP. For details, see RFC 3095 and RFC 4815. This option applies only in low frequency bands.

PROFILE0X0002: Indicates the profile for UDP/IP. For details, see RFC 3095 and RFC 4815. This option applies only in low frequency bands.

GUI Value Range: PROFILE0X0001(Profile 0x0001), PROFILE0X0002(Profile 0x0002)

Unit: None

Actual Value Range: PROFILE0X0001, PROFILE0X0002

MML Default Value: None

Recommended Value: PROFILE0X0001:Off, PROFILE0X0002:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of this parameter affects supported ROHC profiles. For headers with an unsupported type, profile 0x0000 applies and header compression is not performed. That is, profile 0x0000 ROHC headers are added, which increases the transmission overhead over the air interface and reduces the overall ROHC gains.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
UePwrSavingSwitch UE Power Saving Switch

UE_DL_MIMO_LAYER_REDUCE_SW: Indicates whether to trigger downlink layer reduction for a UE. If this option is selected, downlink layer reduction is triggered for a UE that supports overheating protection when the UE requests for layer reduction. If this option is deselected, downlink layer reduction does not take effect. For details about this parameter, see 3GPP TS 38.331. This parameter applies only to low-frequency TDD and FDD cells.

GUI Value Range: UE_DL_MIMO_LAYER_REDUCE_SW(UE Downlink Layer Reduction Switch)

Actual Value Range: UE_DL_MIMO_LAYER_REDUCE_SW

This function has no impact on network KPIs because this function applies only to UEs performing low-rate services. If this option is deselected, network performance is not affected.

Applicable Mode: N
MeasPolicySwitch Measurement Policy Switch

Meaning: Indicates whether to enable measurement policy algorithms.

SSB_MEAS_POS_POLICY_SW: Indicates whether the SSB-ToMeasure IE delivered in SIB2, SIB4, or RRC signaling carries the time-domain position of a neighboring cell. If this option is selected, the SSB time-domain position of a neighboring cell can be obtained during Xn self-setup. The information is combined with the time-domain position of the local cell and is then sent to UEs. If this option is deselected, only the SSB time-domain position of the local cell is carried in the SSB-ToMeasure IE. For details about this parameter, see 3GPP TS 38.331.

This option applies only to high-frequency TDD.

GUI Value Range: SSB_MEAS_POS_POLICY_SW(SSB Measurement Position Policy Switch)

Unit: None

Actual Value Range: SSB_MEAS_POS_POLICY_SW

MML Default Value: None

Recommended Value: SSB_MEAS_POS_POLICY_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: SSB_MEAS_POS_POLICY_SW: If this option is deselected, the base station instructs UEs to perform measurement at the SSB time-domain position of the local cell. If the SSB beam transmission position of a neighboring cell is different from that of the local cell, UEs may fail to measure signals of neighboring cells.

If this option is selected, the base station triggers Xn self-setup and delivers the SSB time-domain position of neighboring cells and the time-domain position of the local cell to UEs. UEs perform SSB measurement in the corresponding time- and frequency-domain positions. Network transmission must support Xn links.

Applicable Mode: N-TDD-FR2
MlbAlgoSwitch MLB Algorithm Switch

Meaning: INTER_FREQ_CONNECTED_MLB_SW: Indicates whether to enable MLB between inter-frequency cells for RRC_CONNECTED UEs. This function is enabled only when this option is selected. This option applies only to UEs with the RFSP index of an operator not configured or UEs with the RFSP index of an operator with INTER_FREQ_CONNECTED_MLB_SW option of the gNBRfspConfig.MlbAlgoSwitch parameter selected.

GUI Value Range: INTER_FREQ_CONNECTED_MLB_SW(Inter-freq MLB Sw for Connected Mode)

Unit: None

Actual Value Range: INTER_FREQ_CONNECTED_MLB_SW

MML Default Value: None

Recommended Value: INTER_FREQ_CONNECTED_MLB_SW:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: INTER_FREQ_CONNECTED_MLB_SW: If this option is deselected, inter-frequency MLB is disabled. When the load in the local cell is heavy and the inter-frequency neighboring cell is capable of handling additional traffic, traffic is not offloaded from the local cell to the neighboring cell. Therefore, the probability of overload is high, and the access success rate and the total throughput are low. Selecting this option results in the opposite effects.

Applicable Mode: N

Example

To modify the settings of NR cell-level algorithm switches with the parameters as follows: NR Cell ID: 7, NSA DC Switch: ON, UL_CARR_SEL_FOR_UE_EXP_SW: ON, MOBILITY_TO_EUTRAN_SW: OFF, NR_NR_ANR_SW: ON, NR_EUTRAN_ANR_SW: OFF, REDIRECTION:On, run the following command:
MOD NRCELLALGOSWITCH: NrCellId=7, NsaDcSwitch=ON, UlDlDecouplingAlgoSwitch=UL_CARR_SEL_FOR_UE_EXP_SW-1, InterRatServiceMobilitySw=MOBILITY_TO_EUTRAN_SW-0, AnrSwitch=NR_NR_ANR_SW-1&NR_EUTRAN_ANR_SW-0, InterFreqHoSwitch=REDIRECTION-1;
