Modify Neighbor E-UTRAN Relationship of NR Cell (MOD NRCELLEUTRANRELATION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the neighbor E-UTRAN relationship of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mcc Mobile Country Code

Meaning: Indicates the mobile country code of the neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in an NRCellEutraNRelation MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the mobile network code of a neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in an NRCellEutraNRelation MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
EnodebId eNodeB ID

Meaning: Indicates the eNodeB ID of the inter-RAT neighboring E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.

GUI Value Range: 0~1048575

Unit: None

Actual Value Range: 0~1048575

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellId Cell ID

Meaning: Indicates the ID of an inter-RAT neighboring E-UTRAN cell. It uniquely identifies a cell within an eNodeB. A 28-bit E-UTRAN cell identifier (ECI) is comprised of a cell ID (represented by the least significant eight bits) and an eNodeB ID. An E-UTRAN cell global identifier (ECGI) is comprised of an ECI and a PLMN ID. For details, see 3GPP TS 36.413.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
EutranCellIndividualOffset E-UTRAN Cell Individual Offset

Meaning: Indicates the cell individual offset between the local cell and a neighboring E-UTRAN cell. It determines the probability of triggering event B1/B2 measurement reports. A larger value of this parameter results in a higher probability of triggering measurement reports.

GUI Value Range: DB_24(-24DB), DB_22(-22DB), DB_20(-20DB), DB_18(-18DB), DB_16(-16DB), DB_14(-14DB), DB_12(-12DB), DB_10(-10DB), DB_8(-8DB), DB_6(-6DB), DB_5(-5DB), DB_4(-4DB), DB_3(-3DB), DB_2(-2DB), DB_1(-1DB), DB0(0DB), DB1(1DB), DB2(2DB), DB3(3DB), DB4(4DB), DB5(5DB), DB6(6DB), DB8(8DB), DB10(10DB), DB12(12DB), DB14(14DB), DB16(16DB), DB18(18DB), DB20(20DB), DB22(22DB), DB24(24DB)

Unit: None

Actual Value Range: DB_24, DB_22, DB_20, DB_18, DB_16, DB_14, DB_12, DB_10, DB_8, DB_6, DB_5, DB_4, DB_3, DB_2, DB_1, DB0, DB1, DB2, DB3, DB4, DB5, DB6, DB8, DB10, DB12, DB14, DB16, DB18, DB20, DB22, DB24

MML Default Value: None

Recommended Value: DB0(0DB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of triggering event B1/B2 measurement reports and a larger number of handovers. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
EutranCellReselOffset E-UTRAN Cell Reselection Offset

Meaning: Indicates the reselection offset between the local cell and a neighboring E-UTRAN cell. It determines the probability of triggering cell reselection from NR to LTE.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: DB_24(-24DB), DB_22(-22DB), DB_20(-20DB), DB_18(-18DB), DB_16(-16DB), DB_14(-14DB), DB_12(-12DB), DB_10(-10DB), DB_8(-8DB), DB_6(-6DB), DB_5(-5DB), DB_4(-4DB), DB_3(-3DB), DB_2(-2DB), DB_1(-1DB), DB0(0DB), DB1(1DB), DB2(2DB), DB3(3DB), DB4(4DB), DB5(5DB), DB6(6DB), DB8(8DB), DB10(10DB), DB12(12DB), DB14(14DB), DB16(16DB), DB18(18DB), DB20(20DB), DB22(22DB), DB24(24DB)

Unit: dB

Actual Value Range: DB_24, DB_22, DB_20, DB_18, DB_16, DB_14, DB_12, DB_10, DB_8, DB_6, DB_5, DB_4, DB_3, DB_2, DB_1, DB0, DB1, DB2, DB3, DB4, DB5, DB6, DB8, DB10, DB12, DB14, DB16, DB18, DB20, DB22, DB24

MML Default Value: None

Recommended Value: DB0(0DB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a lower probability of triggering cell reselection from NR to LTE. A smaller value of this parameter results in the opposite effect.

Applicable Mode: N
NoHoFlag No Handover Flag

Meaning: Indicates whether to allow UEs to be handed over based on the neighbor relationship.

GUI Value Range: PERMIT_HO(Handover Permitted), FORBID_HO(Handover Forbidden)

Unit: None

Actual Value Range: PERMIT_HO, FORBID_HO

MML Default Value: None

Recommended Value: PERMIT_HO(Handover Permitted)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: For a neighbor relationship with a high handover success rate: If NoHoFlag is set to PERMIT_HO, the number of service drops caused by handover prohibition decreases; if it is set to FORBID_HO, the number of service drops caused by handover prohibition increases. For a neighbor relationship with a low handover success rate: If NoHoFlag is set to PERMIT_HO, the handover success rate of the cell decreases; if it is set to FORBID_HO, the handover success rate of a cell increases because handover attempts with this neighbor relationship are prohibited.

Applicable Mode: N
NoRmvFlag No Removal Flag

Meaning: Indicates whether removal of a neighbor relationship by ANR is permitted.

GUI Value Range: PERMIT_ANR_RMV(Permit ANR Removal), FORBID_ANR_RMV(Forbid ANR Removal)

Unit: None

Actual Value Range: PERMIT_ANR_RMV, FORBID_ANR_RMV

MML Default Value: None

Recommended Value: PERMIT_ANR_RMV(Permit ANR Removal)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
MinimumRxLevelOffset Minimum RX Level Offset

Meaning: Indicates the offset to the minimum required RX level of an E-UTRAN cell. This value is included in criteria S and used in the evaluation of cell selection. This parameter is valid only when cell selection is triggered by periodic searches for high-priority PLMNs and a UE is served by a visited public land mobile network (VPLMN). For details, see 3GPP TS 38.304.

GUI Value Range: 1~8

Unit: 2dB

Actual Value Range: 2~16

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the cell reselection of the UEs)

Impact on Radio Network Performance: A smaller value of this parameter leads to a lower probability of the cell meeting criteria S and becoming a suitable cell for cell selection. A larger value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify an E-UTRAN neighbor relationship with the parameters as follows: NR Cell ID: 2, Mobile Country Code: "302", Mobile Network Code: "220", eNodeB ID: 0, Cell ID: 0, E-UTRAN Cell Reselection Offset: DB_24, run the following command:
MOD NRCELLEUTRANRELATION: NrCellId=2, Mcc="302", Mnc="220", EnodebId=0, CellId=0, EutranCellReselOffset=DB_24;
