Add gNodeB CU S1 (ADD GNBCUS1)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the gNodeB CU S1 object.

Note

  • Before adding the gNodeB CU S1 object, ensure that the user-plane endpoint group to be used by this object has been added.

  • A maximum of 6 gNodeB CU S1 objects can be configured on a gNodeB.

Parameters

ID Name Description
gNBCuS1Id gNodeB CU S1 ID

Meaning: Indicates the ID of the gNodeB CU S1 object.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
UpEpGroupId User Plane Endpoint Group ID

Meaning: Indicates the ID of the user-plane endpoint group used by the gNodeB CU S1 object.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UserLabel User Label

Meaning: Indicates the user label of a gNodeB CU S1 object.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add the gNodeB CU S1 object with the parameters as follows: gNodeB CU S1 ID set to 0, User Plane Endpoint Group ID set to 1, User Label set to "huawei", run the following command:
ADD GNBCUS1: gNBCuS1Id=0, UpEpGroupId=1, UserLabel="huawei";
