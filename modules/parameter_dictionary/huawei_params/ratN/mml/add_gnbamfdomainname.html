Add gNodeB AMF Domain Name (ADD GNBAMFDOMAINNAME)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB AMF domain name.

Note

You are advised to configure only one gNodeB CU NG object when adding a gNodeB AMF domain name.

Parameters

ID Name Description
gNBCuNgId gNodeB CU NG ID

Meaning: Indicates the ID of a gNodeB CU NG object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AmfDomainName AMF Domain Name

Meaning: Indicates the AMF domain name.

GUI Value Range: 1~127 characters

Unit: None

Actual Value Range: 1~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a gNodeB AMF domain name with the parameters as follows: gNodeB CU NG ID set to 1, AMF Domain Name set to "amf1", run the following command:
ADD GNBAMFDOMAINNAME: gNBCuNgId=1, AmfDomainName="amf1";
