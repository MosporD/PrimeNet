Modify Measurement Parameter Group Related to Inter-frequency Handover (MOD NRCELLINTERFHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a measurement parameter group related to inter-frequency handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterFreqHoMeasGroupId Inter-freq Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-frequency handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of CovInterFreqA1RsrpThld must be greater than that of CovInterFreqA2RsrpThld.
  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of FreqPriInterFA1RsrpThld must be greater than that of FreqPriInterFA2RsrpThld.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N
InterFreqA4A5TimeToTrig Inter-frequency A4A5 Time to Trigger

Meaning: Indicates the time-to-trigger of events A4 and A5 related to inter-frequency measurement. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.

GUI Value Range: 0MS(0), 40MS(40), 64MS(64), 80MS(80), 100MS(100), 128MS(128), 160MS(160), 256MS(256), 320MS(320), 480MS(480), 512MS(512), 640MS(640), 1024MS(1024), 1280MS(1280), 2560MS(2560), 5120MS(5120)

Unit: ms

Actual Value Range: 0MS, 40MS, 64MS, 80MS, 100MS, 128MS, 160MS, 256MS, 320MS, 480MS, 512MS, 640MS, 1024MS, 1280MS, 2560MS, 5120MS

MML Default Value: None

Recommended Value: 320MS(320)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of sending A4/A5 inter-frequency measurement reports. A larger value of this parameter results in a lower probability of sending A4/A5 inter-frequency measurement reports.

Applicable Mode: N
InterFreqA4A5Hyst Inter-frequency A4A5 Hysteresis

Meaning: Indicates the hysteresis of events A4 and A5 related to inter-frequency measurement. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

GUI Value Range: 0~30

Unit: 0.5dB

Actual Value Range: 0~15

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of triggering events A4 and A5 related to inter-frequency measurement and a higher probability of ping-pong handovers and incorrect decisions. A larger value of this parameter results in a lower probability of triggering events A4 and A5 related to inter-frequency measurement, handover delaying, and user experience deterioration.

Example

To modify a measurement parameter group related to inter-frequency handover for an NR cell with NR Cell ID set to 5, Inter-freq Handover Measurement Group ID set to 0, and Inter-frequency A4A5 Time to Trigger set to 80MS, run the following command:
MOD NRCELLINTERFHOMEAGRP: NrCellId=5, InterFreqHoMeasGroupId=0, InterFreqA4A5TimeToTrig=80MS;
