Modify NR DU Cell Reserved Parameter Extension 00 (MOD NRDUCELLRSVDEXT00)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of an extended reserved parameter 00 for NR DU cell commissioning.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a DU.
