List NR DU FDD Cell TRP Beam (LST NRDUFDDCELLTRPBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the TRP beam configuration of an FDD NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-FDD

Example

To query the configuration of beams in an NR DU FDD cell with NR DU FDD Cell TRP ID set to 88, run the following command:
LST NRDUFDDCELLTRPBEAM: NrDuCellTrpId=88;
The result is shown as follows:

+++    0        2019-12-14 16:03:09
O&M    #2685403143
%%LST NRDUFDDCELLTRPBEAM: NrDuCellTrpId=88;%%
RETCODE = 0  Operation succeeded.

List NR DU FDD Cell TRP Beam
----------------------------
       NR DU Cell TRP ID  =  88
       Coverage Scenario  =  Default Scenario
Max SSB Power Offset(dB)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell.

Coverage Scenario

Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. This parameter applies only to FDD.

Max SSB Power Offset(dB)

Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to FDD.
