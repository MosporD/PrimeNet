Modify NR Cell Relationship (MOD NRCELLRELATION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a relationship with an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mcc Mobile Country Code

Meaning: Indicates the MCC of the operator who owns a neighboring NR cell. The MCC, together with the MNC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in an NRCellRelation MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC of the operator who owns a neighboring NR cell. The MNC, together with the MCC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in an NRCellRelation MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the gNodeB ID of a neighboring NR cell. It uniquely identifies a gNodeB within a PLMN.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellId Cell ID

Meaning: Indicates the cell ID of a neighboring NR cell. It uniquely identifies an NR cell within a gNodeB.

GUI Value Range: 0~16383

Unit: None

Actual Value Range: 0~16383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellIndividualOffset Cell Individual Offset

Meaning: Indicates the cell individual offset between an NR DU cell and a neighboring cell. It affects the probability of triggering measurement reports.

GUI Value Range: DB_24(-24 dB), DB_22(-22 dB), DB_20(-20 dB), DB_18(-18 dB), DB_16(-16 dB), DB_14(-14 dB), DB_12(-12 dB), DB_10(-10 dB), DB_8(-8 dB), DB_6(-6 dB), DB_5(-5 dB), DB_4(-4 dB), DB_3(-3 dB), DB_2(-2 dB), DB_1(-1 dB), DB0(0 dB), DB1(1 dB), DB2(2 dB), DB3(3 dB), DB4(4 dB), DB5(5 dB), DB6(6 dB), DB8(8 dB), DB10(10 dB), DB12(12 dB), DB14(14 dB), DB16(16 dB), DB18(18 dB), DB20(20 dB), DB22(22 dB), DB24(24 dB)

Unit: dB

Actual Value Range: DB_24, DB_22, DB_20, DB_18, DB_16, DB_14, DB_12, DB_10, DB_8, DB_6, DB_5, DB_4, DB_3, DB_2, DB_1, DB0, DB1, DB2, DB3, DB4, DB5, DB6, DB8, DB10, DB12, DB14, DB16, DB18, DB20, DB22, DB24

Impact on Radio Network Performance: A larger value of this parameter results in a higher probability of triggering measurement reporting and handovers, increasing the number of handovers. A smaller value of this parameter results in the opposite effect.

Applicable Mode: N
BlindScellConfigFlag Blind SCell Configuration Flag

Meaning: Indicates whether a neighboring NR cell can be blindly configured as an SCell. The neighboring NR cell can be configured as an SCell or PSCell in a blind manner only if this parameter is set to TRUE.

GUI Value Range: FALSE(False), TRUE(True)

Unit: None

Actual Value Range: FALSE, TRUE

MML Default Value: None

Recommended Value: FALSE(False)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
NoHoFlag No Handover Flag

Meaning: Indicates whether to allow UE handover based on a neighbor relationship.

GUI Value Range: PERMIT_HO(Handover Permitted), FORBID_HO(Handover Forbidden)

Unit: None

Actual Value Range: PERMIT_HO, FORBID_HO

MML Default Value: None

Recommended Value: PERMIT_HO(Handover Permitted)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: For a neighbor relationship with a high handover success rate: If NoHoFlag is set to PERMIT_HO, the number of service drops caused by handover prohibition decreases; if it is set to FORBID_HO, the number of service drops caused by handover prohibition increases. For a neighbor relationship with a low handover success rate: If NoHoFlag is set to PERMIT_HO, the handover success rate of the cell decreases; if it is set to FORBID_HO, the handover success rate of a cell increases because handover attempts with this neighbor relationship are prohibited.

Applicable Mode: N
NoRmvFlag No Removal Flag

Meaning: Indicates whether removal of a neighbor relationship by ANR is permitted.

GUI Value Range: PERMIT_ANR_RMV(Permit ANR Removal), FORBID_ANR_RMV(Forbid ANR Removal)

Unit: None

Actual Value Range: PERMIT_ANR_RMV, FORBID_ANR_RMV

MML Default Value: None

Recommended Value: PERMIT_ANR_RMV(Permit ANR Removal)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
NCellReselOffset Neighboring Cell Reselection Offset

Meaning: Indicates the cell reselection offset of an NR cell relative to a neighboring cell. This parameter is used to control the probability of cell reselection. If this parameter is set to a value other than 0 dB, this parameter is delivered in the q-OffsetCell IE of SIB3 and SIB4.

For details about this parameter, see 3GPP TS 38.304.

GUI Value Range: DB_24(-24DB), DB_22(-22DB), DB_20(-20DB), DB_18(-18DB), DB_16(-16DB), DB_14(-14DB), DB_12(-12DB), DB_10(-10DB), DB_8(-8DB), DB_6(-6DB), DB_5(-5DB), DB_4(-4DB), DB_3(-3DB), DB_2(-2DB), DB_1(-1DB), DB0(0DB), DB1(1DB), DB2(2DB), DB3(3DB), DB4(4DB), DB5(5DB), DB6(6DB), DB8(8DB), DB10(10DB), DB12(12DB), DB14(14DB), DB16(16DB), DB18(18DB), DB20(20DB), DB22(22DB), DB24(24DB)

Unit: dB

Actual Value Range: DB_24, DB_22, DB_20, DB_18, DB_16, DB_14, DB_12, DB_10, DB_8, DB_6, DB_5, DB_4, DB_3, DB_2, DB_1, DB0, DB1, DB2, DB3, DB4, DB5, DB6, DB8, DB10, DB12, DB14, DB16, DB18, DB20, DB22, DB24

MML Default Value: None

Recommended Value: DB0(0 dB)

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, modification of this parameter affects the probability of intra-frequency cell reselection of the UEs.)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability of reselection to a neighboring cell. A larger value of this parameter results in the opposite effect. The access success rate is affected if this parameter is not properly set.

Applicable Mode: N

Example

To modify the configuration of a neighboring NR cell with the parameters as follows: NR Cell ID: 0, Mobile Country Code: "302", Mobile Network Code: "220", gNodeB ID: 1, Cell ID: 0, Blind SCell Configuration Flag: TRUE, run the following command:
MOD NRCELLRELATION: NrCellId=0, Mcc="302", Mnc="220", gNBId=1, CellId=0,  BlindScellConfigFlag=TRUE;
