Display gNodeB CU X2 (DSP GNBCUX2)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the information about the X2 interface managed by the gNodeB CU X2 object. The DSP GNBCUX2 command output does not include user-plane information.

Note

None.

Parameters

ID Name Description
gNBCuX2Id gNodeB CU X2 ID

Meaning: Indicates the ID of the gNodeB CU X2 object.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the configuration of the gNodeB CU X2 object, run the following command:
DSP GNBCUX2:;
The result is shown as follows:
+++    0        2020-01-13 11:28:23
O&M    #2685403163
%%DSP GNBCUX2:;%%
RETCODE = 0  Operation succeeded.

Display gNodeB CU X2
--------------------
             gNodeB CU X2 ID  =  0
   gNodeB CU X2 Interface ID  =  0
gNodeB CU X2 Interface State  =  Abnormal
   gNodeB CU X2 CP Bearer ID  =  70005
gNodeB CU X2 CP Bearer State  =  Normal
(Number of results = 1)


---    END

Output Description

Field Description

gNodeB CU X2 ID

Indicates the ID of the gNodeB CU X2 object.

gNodeB CU X2 Interface ID

Indicates the ID of a gNodeB CU X2 interface.

gNodeB CU X2 Interface State

Indicates the state of a gNodeB CU X2 interface.

gNodeB CU X2 CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU X2 interface.

gNodeB CU X2 CP Bearer State

Indicates the state of the bottom-layer CP bearer of a gNodeB CU X2 interface.
