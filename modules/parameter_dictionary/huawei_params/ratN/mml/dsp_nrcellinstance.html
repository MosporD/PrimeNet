Display NR Cell Instance (DSP NRCELLINSTANCE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query information about configuration instances in an NR cell.

Note

None.

Parameters

ID Name Description
CellId Cell ID

Meaning: Indicates the ID of an NR cell. This cell ID and the gNodeB ID compose the 3GPP-defined NR cell ID. The 3GPP-defined NR cell ID and the PLMN ID compose the NR CGI. For details, see 3GPP TS 38.413.

GUI Value Range: 0~16383,65535

Unit: None

Actual Value Range: 0~16383,65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of CellId in each NRDUCell MO in which DuplexMode is not set to CELL_SUL must be unique within a gNodeB, except that it is set to 65535.
  • When DuplexMode in an NRDUCell MO is not set to CELL_SUL, CellId must not be set to 65535.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the configuration information of an NR cell with Cell ID set to 88, run the following command:
DSP NRCELLINSTANCE: CellId=88;
The result is shown as follows:

Output Description

Field Description

Cell ID

Indicates the ID of an NR cell. This cell ID and the gNodeB ID compose the 3GPP-defined NR cell ID. The 3GPP-defined NR cell ID and the PLMN ID compose the NR CGI. For details, see 3GPP TS 38.413.

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

The value of this parameter is NULL if an NR DU cell is not bound to any NR cells.

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

SUL NR DU Cell ID

Indicates the NR DU cell ID of the auxiliary uplink in NR uplink and downlink decoupling. If this parameter is set to NULL, no secondary uplink NR DU cell exists in the NR cell.

NR DU Cell TRP ID

Indicates the ID of a TRP in an NR DU cell, which uniquely identifies the TRP of the NR DU cell within a gNodeB.

NR DU Cell Coverage ID

Indicates the ID of a coverage area of an NR DU cell, which is used with the NrDuCellTrpId parameter to uniquely identify the coverage area of the NR DU cell.
