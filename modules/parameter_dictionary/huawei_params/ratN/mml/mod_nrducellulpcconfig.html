Modify NR DU Cell Uplink Power Control Configuration (MOD NRDUCELLULPCCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of uplink power control for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
UlPwrCtrlAlgoSwitch Uplink Power Control Algorithm Switch

Meaning: Indicates the uplink power control algorithm switch, which is used to specify the uplink power control policy.

PUSCH_DYN_SCH_CLOSED_LOOP_SW: Indicates whether the gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode. The gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode only if this option is selected.

PUCCH_OUTER_LOOP_SW: Indicates whether the gNodeB adjusts the target SINR for PUCCH power control. The gNodeB adjusts the target SINR for PUCCH power control only if this option is selected.

PUCCH_INNER_LOOP_SW: Indicates whether the gNodeB adjusts the PUCCH transmit power of the UE. The gNodeB adjusts the PUCCH transmit power of the UE only if this option is selected.

PO_SRS_ADAPT_SW: Indicates whether the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is selected, the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is deselected, the configured PO value of the SRS is used.

GUI Value Range: PUSCH_DYN_SCH_CLOSED_LOOP_SW(PUSCH Closed-loop PC in Dynamic Sch), PUCCH_OUTER_LOOP_SW(PUCCH Outer-loop Power Control Switch), PUCCH_INNER_LOOP_SW(PUCCH Inner-loop Power Control Switch), PO_SRS_ADAPT_SW(SRS PO Adaptation Switch)

Unit: None

Actual Value Range: PUSCH_DYN_SCH_CLOSED_LOOP_SW, PUCCH_OUTER_LOOP_SW, PUCCH_INNER_LOOP_SW, PO_SRS_ADAPT_SW

MML Default Value: None

Recommended Value: PUSCH_DYN_SCH_CLOSED_LOOP_SW:On, PUCCH_OUTER_LOOP_SW:On, PUCCH_INNER_LOOP_SW:On, PO_SRS_ADAPT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: PUSCH_DYN_SCH_CLOSED_LOOP_SW: When this option is selected, the throughput of UEs at the cell center and cell edge increases. When this option is deselected, the throughput of such UEs does not increase.

PUCCH_OUTER_LOOP_SW: When this option is selected and the PUCCH_INNER_LOOP_SW option is selected, the PUCCH transmit power can be increased and the PUCCH false detection rate can be reduced in the event of high PUCCH false detection rate. This helps increase the downlink throughput. The preceding gains cannot be achieved when this option is deselected.

PUCCH_INNER_LOOP_SW: When this option is selected, the PUCCH transmit power can be increased and the PUCCH false detection rate can be reduced if the channel quality of the PUCCH is poor. This helps increase the downlink throughput. The preceding gains cannot be achieved when this option is deselected.

PO_SRS_ADAPT_SW: When this option is selected, the SRS transmit power can be increased and the downlink throughput can be increased if SRS channel quality is poor. When this option is deselected, network performance is not affected.

Applicable Mode: N
PoNominalPusch PO Nominal PUSCH

Meaning: Indicates the nominal PO value of the PUSCH. For details, see 3GPP TS 38.213.

GUI Value Range: -101~12

Unit: 2dBm

Actual Value Range: -202~24

MML Default Value: None

Recommended Value: -37

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in higher transmit power of the PUSCH, higher SINR of the PUSCH, and greater interference to neighboring cells. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
PathLossCoeff Path Loss Coefficient

Meaning: Indicates the compensation factor for path loss. It is used in uplink power control. For details, see 3GPP TS 38.213.

GUI Value Range: ALPHA0(0), ALPHA04(0.4), ALPHA05(0.5), ALPHA06(0.6), ALPHA07(0.7), ALPHA08(0.8), ALPHA09(0.9), ALPHA1(1)

Unit: None

Actual Value Range: ALPHA0, ALPHA04, ALPHA05, ALPHA06, ALPHA07, ALPHA08, ALPHA09, ALPHA1

MML Default Value: None

Recommended Value: ALPHA08(0.8)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the UE path loss increases, a larger value of this parameter results in larger increases in the transmit power and interference to neighboring cells. When the UE path loss decreases, a larger value of this parameter results in smaller increases in the transmit power and interference to neighboring cells. A smaller value of this parameter and UE path loss results in the opposite effects.

Applicable Mode: N
PoNominalPucch PO Nominal PUCCH

Meaning: Indicates the nominal PO value of the PUCCH. For details, see 3GPP TS 38.213.

GUI Value Range: -101~12

Unit: 2dBm

Actual Value Range: -202~24

MML Default Value: None

Recommended Value: -50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in higher PUCCH transmit power, higher probability that the PUCCH is correctly received by the gNodeB, and greater interference to neighboring cells. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
PreambleInitRxTargetPwr Preamble Initial Received Target Power

Meaning: Indicates the initial receive target power of the preamble. For details, see 3GPP TS 38.213.

GUI Value Range: -101~-30

Unit: 2dBm

Actual Value Range: -202~-60

MML Default Value: None

Recommended Value: -50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher success rate of random access by sending only one preamble but stronger interference to neighboring cells. A smaller value leads to the opposite effects.

Applicable Mode: N
PwrRampingStep Power Ramping Step

Meaning: Indicates the preamble power increase step. For details, see 3GPP TS 38.321.

GUI Value Range: DB0(0dB), DB2(2dB), DB4(4dB), DB6(6dB)

Unit: None

Actual Value Range: DB0, DB2, DB4, DB6

MML Default Value: None

Recommended Value: DB4(4dB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher success rate of random access by resending preambles but stronger interference to neighboring cells. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
TpcValueInMsg2 TPC Value In Msg2

Meaning: Indicates the power adjustment value in Msg2. For details, see 3GPP TS 38.213.

GUI Value Range: DB_6(-6dB), DB_4(-4dB), DB_2(-2dB), DB0(0dB), DB2(2dB), DB4(4dB), DB6(6dB), DB8(8dB)

Unit: None

Actual Value Range: DB_6, DB_4, DB_2, DB0, DB2, DB4, DB6, DB8

MML Default Value: None

Recommended Value: DB6(6dB)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in smaller transmit power of Msg3 and lower interference to neighboring cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
DeltaPreambleMsg3 Delta Preamble Msg3

Meaning: Indicates the power offset of Msg3 relative to preamble. For details, see 3GPP TS 38.213.

GUI Value Range: -1~6

Unit: 2dB

Actual Value Range: -2~12

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in lower transmit power of Msg3, a smaller probability that Msg3 is successfully received by the gNodeB, and less interference to neighboring cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
SrsPcSinrTarget SRS Power Control SINR Target

Meaning: Indicates the target SINR value for SRS power control.

GUI Value Range: -100~300

Unit: 0.1dB

Actual Value Range: -10~30

MML Default Value: None

Recommended Value: 100 when NRDUCellTrp.TxRxMode is set to 32T32R or 64T64R

10 when NRDUCellTrp.TxRxMode is set to other values

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in higher SRS transmit power of the UE, higher SINR of the SRS, and greater interference to neighboring cells. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
PoSrs SRS PO

Meaning: Indicates the nominal PO value of the SRS. For details, see 3GPP TS 38.213.

If the PO_SRS_ADAPTIVE_SW option of the UlPwrCtrlAlgoSwitch parameter is selected, the value of this parameter is used as the initial value of the nominal PO value, which is then adaptively adjusted by the gNodeB.

GUI Value Range: -101~12

Unit: 2dBm

Actual Value Range: -202~24

MML Default Value: None

Recommended Value: -37

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in lower SRS transmit power of the UE in the local cell, lower SINR of the SRS, and less interference to neighboring cells. A larger value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify the settings of NR DU cell uplink power configurations with the parameters as follows: NR DU Cell ID: 77, PO Nominal PUSCH: 2, run the following command:
MOD NRDUCELLULPCCONFIG: NrDuCellId=77, PoNominalPusch=2;
