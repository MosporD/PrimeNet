Modify gNodeB NG SON Configuration (MOD GNBNGSONCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of gNodeB NG SON functions.

Note

None.

Parameters

ID Name Description
NgcSonSwitch NG-C SON Switch

Meaning: Indicates whether to enable NG-C self-configuration.

NGC_SON_SETUP_SW(NG-C Self-Setup Switch): Indicates whether to enable NG-C self-setup. NG-C self-setup is enabled only when this option is selected.

NGC_SON_DELETE_SW(NG-C Self-Removal Switch): Indicates whether to enable NG-C self-removal. NG-C self-removal is enabled only when this option is selected.

GUI Value Range: NGC_SON_SETUP_SW(NG-C Self-Setup Switch), NGC_SON_DELETE_SW(NG-C Self-Removal Switch)

Unit: None

Actual Value Range: NGC_SON_SETUP_SW, NGC_SON_DELETE_SW

MML Default Value: None

Recommended Value: NGC_SON_SETUP_SW:Off, NGC_SON_DELETE_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the configuration of gNodeB NG SON functions with NGC_SON_SETUP_SW selected, run the following command:
MOD GNBNGSONCONFIG: NgcSonSwitch=NGC_SON_SETUP_SW-1;
