List gNodeB Integrity Protection Capability (LST GNBINTEGRITYCAPB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the gNodeB integrity protection algorithms and their priorities.

Note

None.

Parameters

None.

Example

To list the settings of gNodeB integrity protection algorithm priority, run the following command:
LST GNBINTEGRITYCAPB:;
The result is shown as follows:
+++    0        2018-12-03 16:42:38
O&M    #2685403195
%%LST GNBINTEGRITYCAPB:;%%
RETCODE = 0  Operation succeeded.

List gNodeB Integrity Protection Capability
-------------------------------------------
Integrity Protection Algorithm Priority  Integrity Protection Algorithm

Primary-Priority Integrity Algorithm     AES_128 Algorithm
Second-Priority Integrity Algorithm      SNOW3G_128 Algorithm
Third-Priority Integrity Algorithm       ZUC_128 Algorithm
(Number of results = 3)


---    END

Output Description

Field Description

Integrity Protection Algorithm Priority

Indicates the priority of an integrity protection algorithm. PRIMARY indicates the highest priority, SECOND indicates the second priority, and THIRD indicates the third priority.

Integrity Protection Algorithm

Indicates an integrity protection algorithm of a corresponding priority. If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting an integrity protection algorithm.
