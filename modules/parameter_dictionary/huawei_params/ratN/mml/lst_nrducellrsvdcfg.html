List NR DU Cell Commissioning Reserved Parameter Configuration (LST NRDUCELLRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of a reserved parameter for NR DU cell commissioning.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the settings of reserved NR DU Cell configuration, run the following command:
LST NRDUCELLRSVDCFG:;
The result is shown as follows:
