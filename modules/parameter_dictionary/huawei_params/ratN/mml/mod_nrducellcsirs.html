Modify NR DU Cell CSI-RS (MOD NRDUCELLCSIRS)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the CSI-RS configuration of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
TrsPeriod TRS Period

Meaning: Indicates the period of transmitting TRSs.

If this parameter is set to MS0, TRS transmission is disabled.

The values MS10, MS20, MS40, and MS80 indicate that TRSs are transmitted every 10 ms, 20 ms, 40 ms, and 80 ms, respectively.

GUI Value Range: MS0(0), MS10(10), MS20(20), MS40(40), MS80(80)

Unit: ms

Actual Value Range: MS0, MS10, MS20, MS40, MS80

MML Default Value: None

Recommended Value: MS20(20)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to MS0, the gNodeB does not transmit TRSs, and the TRS overhead is 0. However, the time-frequency offset measurement result of UEs is inaccurate, and the downlink cell throughput decreases. When aperiodic CSI-RSs are configured, the QCL relationship between aperiodic CSI-RSs and TRS resources needs to be configured by using the qcl-info field, as specified in 3GPP TS 38.331. When TRS transmission is disabled, TRS resources are not configured for UEs. As a result, UEs that must verify the qcl-info field in the CSI-AssociatedReportConfigInfo message experience service drops or even fail to access the network. If this parameter is set to a value other than MS0, a smaller value of this parameter results in a shorter TRS transmission period, larger downlink resource overhead, and lower downlink cell throughput when channel conditions change slowly. When channel conditions change quickly, the time-frequency offset measurement result is more accurate, and the downlink cell throughput increases. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CsiPeriod CSI Period

Meaning: Indicates the period for transmitting periodic CSI-RSs. This parameter takes effect only for UEs that initially access the network. This parameter applies only to low-frequency cells.

GUI Value Range: SLOT10(10), SLOT20(20), SLOT40(40), SLOT80(80), SLOT160(160), SLOT320(320)

Unit: slot

Actual Value Range: SLOT10, SLOT20, SLOT40, SLOT80, SLOT160, SLOT320

MML Default Value: None

Recommended Value: SLOT40(40)

Parameter Relationship:

-Configuration constraints:

  • If CsiPeriod in an NRDUCellCsirs MO is set to SLOT10, CsirsCellResourceNum in the NRDUCellCsirs MO cannot be set to 4_RESOURCE or 2_RESOURCE.
  • If CsiPeriod in an NRDUCellCsirs MO is set to SLOT20, CsirsCellResourceNum in the NRDUCellCsirs MO cannot be set to 4_RESOURCE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter results in more frequent CSI-RS transmissions and more downlink resource overhead. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD
CsiAlgoSwitch CSI Algorithm Switch

Meaning: Indicates the switch for the CSI algorithm.

PERIODIC_CSI_SWITCH: When this option is selected, periodic CSI is configured for UEs. When this option is deselected, aperiodic CSI is configured for UEs. In high frequency bands, only aperiodic CSI is supported. Therefore, this option must be deselected.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: PERIODIC_CSI_SWITCH(Periodic CSI Switch)

Unit: None

Actual Value Range: PERIODIC_CSI_SWITCH

MML Default Value: None

Recommended Value: PERIODIC_CSI_SWITCH:ON for low frequency bands, and PERIODIC_CSI_SWITCH:OFF for high frequency bands.

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: PERIODIC_CSI_SWITCH: When this option is deselected, the PDCCH overhead increases and the PUCCH overhead decreases. When this option is selected, the PDCCH overhead decreases and the PUCCH overhead increases.

Applicable Mode: N
CsirsCellResourceNum CSIRS Cell Resource Number

Meaning: Indicates the number of resources for periodic CSI-RS transmission in a cell. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 1_RESOURCE(1 Resource), 2_RESOURCE(2 Resources), 4_RESOURCE(4 Resources)

Unit: None

Actual Value Range: 1_RESOURCE, 2_RESOURCE, 4_RESOURCE

MML Default Value: None

Recommended Value: 4_RESOURCE(4 Resources)

Parameter Relationship:

-Configuration constraints:

  • If CsiPeriod in an NRDUCellCsirs MO is set to SLOT10, CsirsCellResourceNum in the NRDUCellCsirs MO cannot be set to 4_RESOURCE or 2_RESOURCE.
  • If CsiPeriod in an NRDUCellCsirs MO is set to SLOT20, CsirsCellResourceNum in the NRDUCellCsirs MO cannot be set to 4_RESOURCE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to 4_RESOURCE, the cell coverage is favorable, but the number of RRC connection reconfigurations in the cell is large, increasing the service drop probability. If this parameter is set to 2_RESOURCE, the cell coverage is moderate, but the number of RRC connection reconfigurations in the cell is small, reducing the service drop probability. If this parameter is set to 1_RESOURCE, the cell coverage is poor but RRC connection reconfiguration triggered by this function does not occur in the cell.

Applicable Mode: N-TDD-FR1

Example

To modify the CSI-RS configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 77, TRS Period: 0, run the following command:
MOD NRDUCELLCSIRS: NrDuCellId=77, TrsPeriod=MS0;
