Add gNodeB Neighboring Cell PLMN List (ADD GNBNCELLPLMNLIST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a record to the neighboring-cell PLMN list of a gNodeB.

Note

None.

Parameters

ID Name Description
RatType RAT Type

Meaning: Indicates the RAT of the neighboring cell corresponding to the PLMN.

GUI Value Range: NR(NR), EUTRAN(E-UTRAN)

Unit: None

Actual Value Range: NR, EUTRAN

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the gNBNCellPlmnList MO instances with RatType set to NR, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.
  • In the gNBNCellPlmnList MO instances with RatType set to EUTRAN, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mcc Mobile Country Code

Meaning: Indicates the MCC in the PLMN of the neighboring cell. The value of this parameter is a string of three decimal digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in a gNBNCellPlmnList MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC in the PLMN of the neighboring cell. The value of this parameter is a string of two or three decimal digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in a gNBNCellPlmnList MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
PlmnListType PLMN List Type

Meaning: Indicates the type of a PLMN list. If this parameter is set to BLACKLIST, the cell of the blacklisted PLMN cannot be configured as a neighboring cell or an external cell by ANR. If this parameter is set to GREYLIST, the cell of the graylisted PLMN can be added as a neighboring cell and an external cell by ANR, but handovers to the cell of the graylisted PLMN are not allowed. If this parameter is set to WHITELIST, the cell of the whitelisted PLMN can be added as a neighboring cell and an external cell by ANR. This parameter can be set to only two of the three values for all PLMNs in NR and E-UTRAN. The type of PLMNs for which this parameter is not configured is considered the third type by default.

GUI Value Range: BLACKLIST(Blacklist), GREYLIST(Greylist), WHITELIST(Whitelist)

Unit: None

Actual Value Range: BLACKLIST, GREYLIST, WHITELIST

MML Default Value: BLACKLIST(Blacklist)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In the gNBNCellPlmnList MO instances with RatType set to NR, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.
  • In the gNBNCellPlmnList MO instances with RatType set to EUTRAN, PlmnListType can be set to any two values among BLACKLIST, WHITELIST, and GREYLIST.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: If this parameter is set to BLACKLIST, the source base station does not add a detected neighboring cell to the corresponding NRT and NCL after obtaining information about the cell corresponding to the blacklisted PLMN. You are advised to set this parameter to BLACKLIST when abnormal UEs report incorrect CGIs. If this parameter is set to WHITELIST or GREYLIST, the source base station adds a detected neighboring cell to the corresponding NRT and NCL after obtaining information about the cell corresponding to the whitelisted PLMN or graylisted PLMN. This has no impact on network performance.

Applicable Mode: N

Example

To add a gNodeB neighboring cell PLMN list with RAT Type set to NR, Mobile Country Code set to "302", Mobile Network Code set to "220", and PLMN List Type set to WHITELIST, run the following command:
ADD GNBNCELLPLMNLIST: RatType=NR, Mcc="302", Mnc="220", PlmnListType=WHITELIST;
