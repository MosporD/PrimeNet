List UE Timer Constant Configuration for NR DU Cell (LST NRDUCELLUETIMERCONST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of the constants related to UE timers for NR DU cells.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the UE CONST TIMER configuration of an NR DU cell with NR DU Cell ID set to 77, run the following command:
LST NRDUCELLUETIMERCONST: NrDuCellId=77;
The result is shown as follows:
+++    0        2018-12-03 15:58:24
O&M    #2685406153
%%LST NRDUCELLUETIMERCONST: NrDuCellId=77;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Constant N310

Indicates the maximum number of consecutive bottom-layer "out-of-sync" indications received from a PCell by a UE. For details, see 3GPP TS 38.331.

Constant N311

Indicates the maximum number of consecutive bottom-layer "in-sync" indications received from a PCell by a UE. For details, see 3GPP TS 38.331.

Timer 304(ms)

Indicates the timer value of timer 304. For details, see 3GPP TS 38.331. This timer is started for a UE when the UE receives an RRC Connection Reconfiguration message containing the reconfigurationWithSync IE. This timer is stopped when the UE completes random access to an SpCell. If the timer expires, the UE sends an SCG Failure Information NR message to inform the eNodeB of the SCG failure.

Timer 310(ms)

Indicates the timer value of timer 310. For details, see 3GPP TS 38.331. This timer is started for a UE when the UE detects any fault at the physical layer of an SpCell. Before the timer expires, this timer is stopped when the UE detects that the fault is rectified, the UE initiates a connection reestablishment procedure, the UE receives an SCG Release message, or the UE receives an RRC Connection Reconfiguration message containing the reconfigurationWithSync IE. If the timer expires, the UE sends an SCG Failure Information NR message inform the eNodeB of the SCG failure.

Timer 300(ms)

Indicates the timer value of Timer 300. For details, see 3GPP TS 38.331. This timer is started when the UE sends an RRCSetupRequest message. Before the timer expires, it is stopped if the UE receives an RRCSetup or RRCReject message. After the timer expires, the UE enters the RRC_IDLE state.

Timer 301(ms)

Indicates the timer value of timer 301. For details, see 3GPP TS 38.331. This timer is started when the UE sends an RRCReestablishmentRequest message. This timer is stopped if the UE receives an RRCReestablishment message, or the selected cell becomes unsuitable. For details about an unsuitable cell, see 3GPP TS 38.331. After the timer expires, the UE enters the RRC_IDLE state.

Timer 311(ms)

Indicates the timer value of timer 311. For details, see 3GPP TS 38.331. This timer is started when the UE starts a reestablishment. The timer is stopped if the UE selects an NR or inter-RAT cell to camp on before the timer expires. After the timer expires, the UE enters the RRC_IDLE state.
