Modify gNodeB Flow Control Parameter Group (MOD GNBFLOWCTRLPARAMGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of a gNodeB flow control parameter group.

Note

None.

Parameters

ID Name Description
FlowCtrlParamGroupId Flow Control Parameter Group ID

Meaning: Indicates the ID of a flow control parameter group.

GUI Value Range: 0~159

Unit: None

Actual Value Range: 0~159

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
FlowCtrlType Flow Control Type

Meaning: Indicates whether to enable flow control for bearers with a type of QCI. When this parameter is set to FLOW_CTRL for bearers with a type of QCI, flow control is enabled for the bearers with this type of QCI. When this parameter is set to NON_FLOW_CTRL for bearers with a type of QCI, flow control is not enabled for the bearers with this type of QCI. The QCI for GBR services is always NON_FLOW_CTRL. The value FLOW_CTRL does not apply to GBR services.

GUI Value Range: FLOW_CTRL(Flow Control), NON_FLOW_CTRL(Non Flow Control)

Unit: None

Actual Value Range: FLOW_CTRL, NON_FLOW_CTRL

MML Default Value: None

Recommended Value: This parameter can be set by the gNodeB by default as follows:

QCI 1: NON_FLOW_CTRL(Non Flow Control)

QCI 2: NON_FLOW_CTRL(Non Flow Control)

QCI 3: NON_FLOW_CTRL(Non Flow Control)

QCI 4: NON_FLOW_CTRL(Non Flow Control)

QCI 65: NON_FLOW_CTRL(Non Flow Control)

QCI 66: NON_FLOW_CTRL(Non Flow Control)

QCI 75: NON_FLOW_CTRL(Non Flow Control)

QCI 5: NON_FLOW_CTRL(Non Flow Control)

QCI 6: FLOW_CTRL(Flow Control)

QCI 7: FLOW_CTRL(Flow Control)

QCI 8: FLOW_CTRL(Flow Control)

QCI 9: FLOW_CTRL(Flow Control)

QCI 69: NON_FLOW_CTRL(Non Flow Control)

QCI 70: FLOW_CTRL(Flow Control)

QCI 79: FLOW_CTRL(Flow Control)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to FLOW_CTRL for bearers with a type of QCI, flow control is performed on services of bearers with this type of QCI if transmission congestion occurs. This setting increases the service delay and packet loss rate. When this parameter is set to NON_FLOW_CTRL for bearers with a type of QCI, flow control is not performed on services of bearers with this type of QCI if transmission congestion occurs. This setting does not increase the service delay and packet loss rate.

Applicable Mode: N
UlFlowCtrlMinCir Uplink Flow Control Minimum CIR

Meaning: Indicates the uplink minimum CIR when flow control is performed on bearers with a type of QCI.

GUI Value Range: 0~62500

Unit: kB/s

Actual Value Range: 0~62500

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to lower uplink minimum CIR for services with a type of QCI when uplink transmission congestion occurs. A larger value of this parameter leads to the opposite effect.

Applicable Mode: N
UlFlowCtrlPriWeightFactor Uplink Flow Control Priority Weight Factor

Meaning: Indicates the weight factor for calculating the step of rate increase for bearers with a type of QCI when flow control is performed.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 0.001~1, step: 0.001

MML Default Value: None

Recommended Value: This parameter can be automatically set by the system to the following default values for bearers with different types of QCIs when flow control is performed:

QCI6: 950

QCI7: 900

QCI8: 800

QCI9: 700

QCI70: 1000

QCI79: 925

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter leads to smaller uplink bandwidth allocated to services with a type of QCI when uplink transmission congestion occurs. A larger value of this parameter leads to the opposite effect.

Applicable Mode: N

Example

To modify a gNodeB flow control parameter group with the parameters as follows: Flow Control Parameter Group ID: 1, Flow Control Type: FLOW_CTRL, Uplink Flow Control Minimum CIR: 2, Uplink Flow Control Priority Weight Factor: 600, run the following command:
MOD GNBFLOWCTRLPARAMGRP: FlowCtrlParamGroupId=1, FlowCtrlType=FLOW_CTRL, UlFlowCtrlMinCir=2, UlFlowCtrlPriWeightFactor=600;
