Modify gNodeB Air Interface Security Parameters (MOD GNBAIRINTFSECPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify gNodeB air interface security parameters.

Note

None.

Parameters

ID Name Description
CounterCheckSwitch Counter Check Switch

Meaning: Indicates whether to enable counter check.

The value DISABLE indicates that PDCP counter check is disabled.

The value ENABLE_NOT_RELEASE indicates that PDCP counter check is enabled. When the DRB counter check is abnormal, the corresponding bearer is not released.

The value ENABLE_RELEASE_DRB indicates that PDCP counter check is enabled. When the DRB counter check is abnormal, the corresponding bearer is released. For details about this parameter, see 3GPP TS 33.401 and 3GPP TS 33.501.

GUI Value Range: DISABLE(Disable), ENABLE_NOT_RELEASE(Enable and Not Release Abnormal Bearer), ENABLE_RELEASE_DRB(Enable and Release Abnormal Bearer)

Unit: None

Actual Value Range: DISABLE, ENABLE_NOT_RELEASE, ENABLE_RELEASE_DRB

MML Default Value: None

Recommended Value: ENABLE_RELEASE_DRB(Enable and Release Abnormal Bearer)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE_RELEASE_DRB, the DRB with abnormal PDCP counter check is released.

If this parameter is set to DISABLE or ENABLE_NOT_RELEASE, network performance is not affected.

Applicable Mode: N
UnauthEmergencyCallSwitch Unauthenticated Emergency Call Switch

Meaning: Indicates whether to allow unauthenticated emergency calls. The value ENABLE indicates that unauthenticated emergency calls are allowed. When this function is enabled, NEA0 and NIA0 (null ciphering and integrity protection algorithms) can be used during an unauthenticated emergency call. That is, an unauthenticated emergency call can be conducted irrespective of whether the NEA0 and NIA0 are enabled. The value DISABLE indicates that unauthenticated emergency calls are prohibited.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the air interface security parameters of the gNodeB with the parameters as follows: Counter Check Switch: ENABLE_NOT_RELEASE, Unauthenticated Emergency Call Switch: ENABLE, run the following command:
MOD GNBAIRINTFSECPARAM: CounterCheckSwitch=ENABLE_NOT_RELEASE, UnauthEmergencyCallSwitch=ENABLE;
