Modify gNodeB Commissioning Reserved Parameter Configuration (MOD GNBRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of the reserved parameter for gNodeB commissioning.

Note

None.

Parameters

ID Name Description
RsvdSwParam0 Reserved Switch Parameter 0

Meaning: Indicates reserved switch parameter 0, which is used to facilitate commissioning on the live network.

GUI Value Range: RSVDSWPARAM0_BIT1(Bit 1 of Reserved Parameter 0), RSVDSWPARAM0_BIT2(Bit 2 of Reserved Parameter 0), RSVDSWPARAM0_BIT3(Bit 3 of Reserved Parameter 0), RSVDSWPARAM0_BIT4(Bit 4 of Reserved Parameter 0), RSVDSWPARAM0_BIT5(Bit 5 of Reserved Parameter 0), RSVDSWPARAM0_BIT6(Bit 6 of Reserved Parameter 0), RSVDSWPARAM0_BIT7(Bit 7 of Reserved Parameter 0)

Unit: None

Actual Value Range: RSVDSWPARAM0_BIT1, RSVDSWPARAM0_BIT2, RSVDSWPARAM0_BIT3, RSVDSWPARAM0_BIT4, RSVDSWPARAM0_BIT5, RSVDSWPARAM0_BIT6, RSVDSWPARAM0_BIT7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
