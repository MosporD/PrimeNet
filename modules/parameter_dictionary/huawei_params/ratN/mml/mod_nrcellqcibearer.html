Modify NR Cell QCI Bearer (MOD NRCELLQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the bearer configurations of an NR cell. The configurations can be modified for bearers based on their QCIs.

Note

None.

Example

To modify the QCI bearer configuration of an NR cell with the parameters as follows: NR Cell ID: 3, QoS Class Identifier: 1, AM PDCP Parameter Group ID: 5, run the following command:
MOD NRCELLQCIBEARER: NrCellId=3, Qci=1, AmPdcpParamGroupId=5;
