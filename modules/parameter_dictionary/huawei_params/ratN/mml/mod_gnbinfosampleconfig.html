Modify gNodeB Information Sampling Configuration (MOD GNBINFOSAMPLECONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the information sampling configuration on the gNodeB side.

Note

Before running this command, obtain the permission of end users and sign a disclaimer with end users.

Parameters

ID Name Description
IpSamplePseuSwitch IP Address Sample and Pseudonymization Sw

Meaning: Indicates whether an operator allows the gNodeB to perform IP address resolution and pseudonymization and specifies the usage of the IP address after pseudonymization.

CPE_PRFM_EVALUATION_SW(CPE Performance Evaluation Switch): Indicates whether the IP address after pseudonymization can be used for CPE performance evaluation.

GUI Value Range: CPE_PRFM_EVALUATION_SW(CPE Performance Evaluation Switch)

Unit: None

Actual Value Range: CPE_PRFM_EVALUATION_SW

MML Default Value: None

Recommended Value: CPE_PRFM_EVALUATION_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

IP Address Sample and Pseudonymization Sw:ON
MOD GNBINFOSAMPLECONFIG: IpSamplePseuSwitch=CPE_PRFM_EVALUATION_SW-1;
