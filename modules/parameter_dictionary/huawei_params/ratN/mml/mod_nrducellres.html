Modify NR DU Cell Resource (MOD NRDUCELLRES)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify group-specific resources of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In all the instances of an NRDUCellRes MO with the same NrDuCellId value and DlRbAverageRatio not set to 255, the sum of the values of DlRbAverageRatio must be less than or equal to 100.
  • In all the instances of an NRDUCellRes MO with the same NrDuCellId value and UlRbAverageRatio not set to 255, the sum of the values of UlRbAverageRatio must be less than or equal to 100.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellResId Cell Resource ID

Meaning: Indicates the resource ID of an NR DU cell.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N
DlRbMaxRatio Downlink RB Max Ratio

Meaning: Indicates the maximum proportion of PDSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the maximum proportion of downlink PDSCH RBs that can be used by UEs served by an operator is not configured.

GUI Value Range: 1~100,255

Unit: %

Actual Value Range: 1~100,255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • When neither DlRbMaxRatio nor DlRbAverageRatio in an NRDUCellRes MO is set to 255, the value of DlRbMaxRatio must be greater than or equal to that of DlRbAverageRatio.
  • DlRbMaxRatio, DlRbAverageRatio, UlRbMaxRatio, and UlRbAverageRatio in an NRDUCellRes MO cannot all be set to 255.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in fewer available RBs and lower peak throughput for UEs in a resource use object. A larger value of this parameter results in more available RBs and higher peak throughput for UEs in a resource use object.

Applicable Mode: N

Example

To modify an NR DU cell resource with the parameters as follows: NR DU Cell ID: 88, Cell Resource ID:0, Downlink RB Max Ratio:50, run the following command:
MOD NRDUCELLRES: NrDuCellId=88, CellResId=0, DlRbMaxRatio=50;
