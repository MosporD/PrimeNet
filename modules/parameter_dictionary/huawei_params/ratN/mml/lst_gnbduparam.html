List gNodeB DU Parameter Configuration (LST GNBDUPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list gNodeB DU parameter configurations.

Note

None.

Parameters

None.

Example

To list gNodeB DU parameter configurations, run the following command:
LST GNBDUPARAM:;

Output Description

Field Description

LTE-NR Power Sharing Enable Time

Indicates the time segments in which dynamic power sharing between LTE and NR is enabled. Dynamic power sharing between LTE and NR can be enabled in different time segments based on traffic distribution on the live network. This parameter applies only to low-frequency TDD cells.
