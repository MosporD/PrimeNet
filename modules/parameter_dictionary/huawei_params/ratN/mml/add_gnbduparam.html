Add gNodeB DU Parameter Configuration (ADD GNBDUPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add gNodeB DU parameter configurations.

Note

None.

Parameters

ID Name Description
LteNrPowerShrEnableTime LTE-NR Power Sharing Enable Time

Meaning: Indicates the time segments in which dynamic power sharing between LTE and NR is enabled. Dynamic power sharing between LTE and NR can be enabled in different time segments based on traffic distribution on the live network. This parameter applies only to low-frequency TDD cells.

GUI Value Range: TIME0(00:00:00 to 00:59:59), TIME1(01:00:00 to 01:59:59), TIME2(02:00:00 to 02:59:59), TIME3(03:00:00 to 03:59:59), TIME4(04:00:00 to 04:59:59), TIME5(05:00:00 to 05:59:59), TIME6(06:00:00 to 06:59:59), TIME7(07:00:00 to 07:59:59), TIME8(08:00:00 to 08:59:59), TIME9(09:00:00 to 09:59:59), TIME10(10:00:00 to 10:59:59), TIME11(11:00:00 to 11:59:59), TIME12(12:00:00 to 12:59:59), TIME13(13:00:00 to 13:59:59), TIME14(14:00:00 to 14:59:59), TIME15(15:00:00 to 15:59:59), TIME16(16:00:00 to 16:59:59), TIME17(17:00:00 to 17:59:59), TIME18(18:00:00 to 18:59:59), TIME19(19:00:00 to 19:59:59), TIME20(20:00:00 to 20:59:59), TIME21(21:00:00 to 21:59:59), TIME22(22:00:00 to 22:59:59), TIME23(23:00:00 to 23:59:59)

Unit: None

Actual Value Range: TIME0, TIME1, TIME2, TIME3, TIME4, TIME5, TIME6, TIME7, TIME8, TIME9, TIME10, TIME11, TIME12, TIME13, TIME14, TIME15, TIME16, TIME17, TIME18, TIME19, TIME20, TIME21, TIME22, TIME23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1

Example

To add gNodeB DU parameter configurations with LTE-NR Power Sharing Enable Time set to 06:00:00 to 06:59:59, run the following command:
ADD GNBDUPARAM: LteNrPowerShrEnableTime=TIME6-1;
