List NR Cell QCI Bearer (LST NRCELLQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the bearer configurations of an NR cell. The configurations can be queried for bearers based on their QCIs.

Note

None.

Parameters

NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~255

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

QoS Class Identifier

Indicates the QoS class identifier of radio bearers.

Flow Control Parameter Group ID

Indicates the ID of a flow control parameter group.

AM PDCP Parameter Group ID

Indicates the ID of a PDCP parameter group in AM mode.

UM PDCP Parameter Group ID

Indicates the ID of a PDCP parameter group in UM mode.

RLC Mode

Indicates the RLC transmission mode, which can only be AM or UM. This parameter applies only to the scenario where the setup of the PDCP of the UE bearer is triggered by the current gNodeB. If the RLC mode of the related bearer over the terrestrial link (X2/Xn/NG) is obtained, this RLC mode is used, and this parameter does not take effect.

DRX Parameter Group ID

Indicates the ID of a DRX parameter group. If this parameter is set to a value in the range of 0 to 63, valid DRX parameters are configured for a QCI. If this parameter is set to 255, DRX is disabled for a QCI.

Inter-RAT HO Meas Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover.

Inter-RAT HO to E-UTRAN Meas Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover to E-UTRAN.

Intra-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to intra-frequency handover.

Inter-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-frequency handover.

NSA DC Configuration Group ID

Indicates the ID of an NSA DC configuration parameter group.
