Modify Reserved Parameter for NR DU Cell Commissioning (MOD NRDUCELLRSVD)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of a reserved parameter for NR DU cell commissioning.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.
