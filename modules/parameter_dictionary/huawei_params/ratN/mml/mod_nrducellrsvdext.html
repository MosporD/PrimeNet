Modify NR DU Cell Reserved Parameter Extension (MOD NRDUCELLRSVDEXT)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify reserved parameter for NR DU cell commissioning, which is an extension of the NRDUCellRsvd MO.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.
