List gNodeB DU Reserved Parameter (LST GNBDURSVDPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the settings of reserved gNodeB DU parameters.

Note

None.

Parameters

None.

Example

To list the settings of reserved gNodeB DU parameters, run the following command:
LST GNBDURSVDPARAM:;
The result is shown as follows:
+++    0        2018-02-07 14:30:34
O&M    #2685403148
%%LST GNBDURSVDPARAM:;%%
RETCODE = 0  Operation succeeded.

List gNodeB DU Reserved Parameter
----------------------
Reserved U8 Parameter 1  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Reserved U8 Parameter 1

Indicates reserved U8 parameter 1 that is reserved for future requirements.

Note on parameter replacement: Reserved parameters are temporarily used in the current version and will be replaced with new parameters (for example, of which the IDs can signify the parameter functions) in later versions. Therefore, avoid using this parameter.
