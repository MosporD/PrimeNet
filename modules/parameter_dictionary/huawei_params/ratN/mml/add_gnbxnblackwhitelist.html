Add gNodeB Xn Blacklist or Whitelist (ADD GNBXNBLACKWHITELIST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a record to the gNodeB Xn blacklist or whitelist.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the mobile country code (MCC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the mobile network code (MNC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99,000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the ID of the peer gNodeB to be added to the Xn blacklist or whitelist.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
XnListType Xn List Type

Meaning: Indicates whether the Xn list is a whitelist or blacklist. If the peer gNodeB is in the Xn blacklist, the Xn interface between the two gNodeBs cannot be automatically set up. If the peer gNodeB is in the Xn whitelist, the Xn interface between the two gNodeBs cannot be automatically removed.

GUI Value Range: XN_BLACKLIST_TYPE(Xn Blacklist Type), XN_WHITELIST_TYPE(Xn Whitelist Type)

Unit: None

Actual Value Range: XN_BLACKLIST_TYPE, XN_WHITELIST_TYPE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a gNodeB Xn blacklist and whitelist with the parameters as follows: Mobile Country Code set to "262", Mobile Network Code set to "02", gNodeB ID set to 1, Xn List Type set to XN_BLACKLIST_TYPE, run the following command:
ADD GNBXNBLACKWHITELIST: Mcc="262", Mnc="02", gNBId=1, XnListType=XN_BLACKLIST_TYPE;
