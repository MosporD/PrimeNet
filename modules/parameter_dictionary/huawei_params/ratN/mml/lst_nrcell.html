List NR Cell (LST NRCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the static attributes of NR cells.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the static attributes of an NR cell with NR Cell ID set to 0, run the following command:
LST NRCELL: NrCellId=0;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

Cell Name

Indicates the name of an NR cell.

Cell ID

Indicates the cell ID of an NR cell. A cell ID and a gNodeB ID compose a 3GPP-defined NR Cell Identity (NCI). A 3GPP-defined NCI and a PLMN ID compose an NR cell global identifier (NCGI). For details, see 3GPP TS 38.413.

Frequency Band

Indicates the frequency band in which an NR cell operates. For details, see 3GPP TS 38.104.

Duplex Mode

Indicates the duplex mode of an NR cell. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode.

User Label

Indicates the user label of an NR cell.

Cell Activate State

Indicates the activation state of an NR cell.
