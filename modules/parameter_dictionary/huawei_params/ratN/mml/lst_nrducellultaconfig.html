List NR DU Cell Uplink TA Configuration (LST NRDUCELLULTACONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the uplink TA configuration of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the settings of parameters related to the uplink TA algorithm for an NR DU cell with NR DU Cell ID set to 88, run the following command:
LST NRDUCELLULTACONFIG: NrDuCellId=88;
The result is shown as follows:
+++    0        2019-01-15 12:30:24
O&M    #2685403178
%%LST NRDUCELLULTACONFIG: NrDuCellId=88;%%
RETCODE = 0  Operation succeeded.

List NR DU Cell Uplink TA Configuration
---------------------------------------
              NR DU Cell ID  =  88
Uplink Time Alignment Timer  =  10240 Subframes
(Number of results = 1)


---    END

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Uplink Time Alignment Timer

Indicates the length of the uplink time alignment timer for UEs in the cell. A UE is considered not time-aligned in the uplink if the timer expires. In uplink and downlink decoupling scenarios, the TA timer of an NUL cell must be the same as that of the SUL cell.
