Display NR Cell PCI Conflict Records (DSP NRCELLPCICONFLICT)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the PCI conflict records of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the PCI conflict of an NR cell with NR Cell ID set to 11148, run the following command:
DSP NRCELLPCICONFLICT: NrCellId=11148;
The result is shown as follows:
+++    0        2019-04-09 21:56:41
O&M    #2685403411
%%DSP NRCELLPCICONFLICT: NrCellId=11148;%%

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

PCI Conflict Type

Indicates the PCI conflict type, which can be PCI conflict and PCI confusion.

Conflict Cell MCC

Indicates the MCC of the cell with PCI conflict. The value of this parameter is a string of three decimal digits.

Conflict Cell MNC

Indicates the MNC of the cell with PCI conflict. The value of this parameter is a string of two or three decimal digits.

Conflict Cell gNodeB ID

Indicates the gNodeB ID of the cell with PCI conflict.

Conflict Cell ID

Indicates the ID of the cell with PCI conflict.

Conflict Cell PCI

Indicates the physical cell ID of the cell with PCI conflict.

Conflict Cell SSB NARFCN

Indicates the SSB NR-ARFCN of the cell with PCI conflict.
