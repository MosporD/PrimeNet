Modify gNodeB 5QI Configuration (MOD GNB5QICONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a gNodeB 5QI configuration.

Note

None.

Parameters

ID Name Description
Nr5qi NR 5G QoS Indicator

Meaning: Indicates a 5G QoS Identifier (5QI). When a 5QI is added on the core network:

1. If configuration for the corresponding Nr5qi value has not been added in the gNB5qiConfig MO, parameter configuration with Nr5qi being 9 is used by default.

2. If configuration for the corresponding Nr5qi value has been added in the gNB5qiConfig MO:

gNB5qiConfig.Qci for the corresponding Nr5qi value must be already configured in the NRCellQciBearer and NRDUCellQciBearer MOs. If it is not configured, parameter configuration with Qci being 9 in the NRCellQciBearer and NRDUCellQciBearer MOs is used by default.

For non-dynamic 5QIs (including pre-configured 5QIs and standardized 5QIs), when the core network does not carry AveragingWindowDur, PacketDelayBudget, or PriorityLevel, gNB5qiConfig.Qci corresponding to the new Nr5qi value must be configured in the gNBQciBearer MO on the gNodeB. Otherwise, parameter configuration with Qci being 9 in the gNBQciBearer MOs is used.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Qci QoS Class Identifier

Meaning: Indicates the QoS class identifier (QCI) of the radio bearer corresponding to a 5QI.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: This parameter can be set by the gNodeB by default as follows:

5QI 1: 1

5QI 2: 2

5QI 3: 3

5QI 4: 4

5QI 5: 5

5QI 6: 6

5QI 7: 7

5QI 8: 8

5QI 9: 9

5QI 65: 65

5QI 66: 66

5QI 69: 69

5QI 70: 70

5QI 75: 75

5QI 79: 79

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
CounterObjSubscriptionInd Counter Object Subscription Indicator

Meaning: Indicates whether to subscribe to the 5QI counter objects. If this parameter is set to YES, counter objects are subscribed to. If this parameter is set to NO, counter objects are not subscribed to.

GUI Value Range: NO(Not Subscribe), YES(Subscribe)

Unit: None

Actual Value Range: NO, YES

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

YES(Subscribe) for 5QI 9; NO(Not Subscribe) for 5QIs other than 5QI 9

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to YES, the number of subscribed 5QI counter objects increases and the CPU and memory consumed by counter statistics increase. To avoid excessive resource consumption, the total number of subscribed 5QI counter objects in SA networking and QCI counter objects in NSA networking must not exceed 20. If this parameter is set to NO, the number of subscribed 5QI counter objects decreases, and the CPU and memory consumed by counter statistics decrease.

Applicable Mode: N
AsReflectiveQosSwitch AS Reflective QoS Switch

Meaning: Indicates whether to enable the AS reflective QoS function. When the switch is turned on, a UE can obtain the relationship between a QoS flow and a DRB by monitoring the QFI of the data packets transmitted on the DRB. When this switch is turned off, this function is disabled.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is turned on, a UE can obtain the mapping from a QoS flow to a DRB by monitoring the QoS flow transmitted on the DRB. When multiple QoS flows map to the same DRB, the RRC signaling overhead can be reduced. When this switch is turned off, all the mappings from QoS flows to DRBs need to be sent to UEs through RRC signaling. When multiple QoS flows map to the same DRB, extra RRC signaling overhead is generated.

Applicable Mode: N

Example

To modify the gNodeB 5QI configuration, NR 5G QoS Indicator: 10, AS Reflective QoS Switch: ON, run the following command:
MOD GNB5QICONFIG: Nr5qi=10, AsReflectiveQosSwitch=ON;
