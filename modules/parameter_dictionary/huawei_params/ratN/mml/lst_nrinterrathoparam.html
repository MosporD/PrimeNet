List NR Cell Inter-RAT Handover Parameter (LST NRINTERRATHOPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list parameter configurations related to inter-RAT handover.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list inter-RAT handover configurations with NR Cell ID of 5, run the following command:
LST NRINTERRATHOPARAM: NrCellId=5;
The result is shown as follows:

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

Handover Mode Switch

Indicates the handover mode switches, which correspond to the inputs based on which the gNodeB determines handover policies.

EUTRAN_HO_SWITCH: Indicates whether NG-RAN can hand over UEs to E-UTRAN. NG-RAN can hand over UEs to E-UTRAN only if this option is selected.

EUTRAN_REDIRECT_SWITCH: Indicates whether NG-RAN can redirect UEs to E-UTRAN. NG-RAN can redirect UEs to E-UTRAN only if this option is selected.

VOICE_BLIND_MODE_SWITCH: Indicates whether EPS fallback and emergency call fallback to E-UTRAN can be performed in blind mode. If this option is selected, EPS fallback and emergency call fallback to E-UTRAN can be performed in blind mode. If this option is deselected, EPS fallback and emergency call fallback to E-UTRAN cannot be performed in blind mode. In regard to the blind mode supported in the current version, only blind redirection is supported.

EPS FB Protection Timer(100ms)

Indicates the length of the EPS fallback protection timer. If this timer expires, the gNodeB blindly redirects UEs.

Inter-RAT Handover Trigger Event Type

Indicates the type of the inter-RAT handover event. The event type can be B1 or B2. This parameter applies only to coverage-based handovers. For details, see 3GPP TS 38.331.

EPS FB Mode

Indicates the mobility policy for EPS fallback and emergency call fallback. If this parameter is set to HANDOVER, EPS fallback and emergency call fallback UEs preferentially fall back to E-UTRAN through handovers.

If this parameter is set to REDIRECTION, EPS fallback and emergency call fallback UEs preferentially fall back to E-UTRAN through redirections.
