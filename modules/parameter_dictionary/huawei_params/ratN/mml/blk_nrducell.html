Block NR DU Cell (BLK NRDUCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to block an NR DU cell.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Blocking the cell will result in unavailability of the cell. When this parameter is set to CELL_HIGH_BLOCK, the cell is forcibly deactivated after 10 seconds even if there are still RRC_CONNECTED UEs in the cell. When this parameter is set to CELL_MID_BLOCK, the cell is forcibly deactivated after 60 seconds even if there are still RRC_CONNECTED UEs in the cell. When this parameter is set to CELL_LOW_BLOCK, the cell is deactivated only after all RRC_CONNECTED UEs in the cell are released.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellAdminState Cell Administration State

Meaning: Indicates the administrative state of a cell. The setting of this parameter affects the working state of the cell. If this parameter is set to CELL_HIGH_BLOCK, CELL_MID_BLOCK, or CELL_LOW_BLOCK, new UEs are not allowed to access the cell. If there is no RRC_CONNECTED UE in the cell, the cell is deactivated immediately. If the cell is serving RRC_CONNECTED UEs, the base station checks the number of RRC_CONNECTED UEs in the cell every 5s. If the number becomes 0, the base station immediately deactivates the cell. If this parameter is set to CELL_HIGH_BLOCK, UEs need to be transferred out of the cell within 10 seconds. The cell is forcibly deactivated after 10 seconds even if there are still UEs in the cell. If this parameter is set to CELL_MID_BLOCK, UEs need to be transferred out of the cell within 60 seconds. The cell is forcibly deactivated after 60 seconds even if there are still UEs in the cell. If this parameter is set to CELL_LOW_BLOCK, the cell is deactivated only when there is no RRC_CONNECTED UE in the cell.

GUI Value Range: CELL_HIGH_BLOCK, CELL_MID_BLOCK, CELL_LOW_BLOCK

Unit: None

Actual Value Range: CELL_HIGH_BLOCK, CELL_MID_BLOCK, CELL_LOW_BLOCK

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To block an NR DU cell with the parameters as follows: NR DU Cell ID: 77, CellAdminState:CELL_HIGH_BLOCK:
BLK NRDUCELL: NrDuCellId=77, CellAdminState=CELL_HIGH_BLOCK;
