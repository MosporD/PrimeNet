Modify gNodeB Acceleration Service Parameter Group (MOD GNBASPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify a gNodeB acceleration service parameter group.

Note

None.

Parameters

ID Name Description
AsOptSw AS Optimization Switch

Meaning: Indicates whether to enable the acceleration service optimization algorithm. If this parameter is set to ON, UEs running acceleration services are preferentially guaranteed. If this parameter is set to OFF, UEs running acceleration services are not preferentially guaranteed.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, user experience of UEs running acceleration services is improved, but user experience of UEs not running acceleration services deteriorates. If this parameter is set to OFF, network performance is not affected.

Applicable Mode: N
AsIpDetectIntvl AS IP Detection Interval

Meaning: Indicates the interval at which the gNodeB detects the IP headers of downlink packets to identify UEs running acceleration services. To be specific, the gNodeB detects IP headers every X packets, where X is the value of by this parameter.

GUI Value Range: 1~3600

Unit: None

Actual Value Range: 1~3600

MML Default Value: None

Recommended Value: 70

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more frequent IP header detection of downlink packets. Therefore, the gNodeB can identify UEs running acceleration services more quickly. However, the load of the BBP increases. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
AsGuaranteeDuration AS Guarantee Duration

Meaning: Indicates the duration during which UEs running acceleration services are preferentially guaranteed.

GUI Value Range: 1~3600

Unit: s

Actual Value Range: 1~3600

MML Default Value: None

Recommended Value: 60

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer period of time to preferentially guarantee the data rates of UEs running acceleration services and a longer period of time in which user experience of UEs not running acceleration services deteriorate. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
AsPreallocPktSize AS Preallocation Packet Size

Meaning: Indicates the amount of uplink data preallocated for UEs running acceleration services.

GUI Value Range: 1~1500

Unit: byte

Actual Value Range: 1~1500

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in shorter uplink data transmission delay but more UE power consumption and severer uplink interference. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
AsSchPriFactor AS Schedule Priority Factor

Meaning: Indicates the weight factor used to calculate the basic scheduling priority for UEs running acceleration services. This parameter is used to preferentially guarantee UEs running acceleration services in the uplink and downlink. If this parameter is set to a value in the range from 1 to 999, the priority is calculated using the normal weight factor. If this parameter is set to 1000, UEs running acceleration services have the highest priority.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a higher scheduling priority for UEs running acceleration services and therefore data rates of these UEs are more likely to be preferentially guaranteed. Such setting also results in a lower scheduling priority for UEs not running acceleration services and therefore user experience of these UEs deteriorate. A smaller value of this parameter leads to a smaller difference between the scheduling priorities of UEs running acceleration services and those of UEs not running acceleration services, and fewer user experience improvements for UEs running acceleration services.

Applicable Mode: N

Example

To modify the configuration of the gNodeB acceleration service parameter group with AS Optimization Switch set to ON, run the following command:
MOD GNBASPARAMGROUP: AsOptSw=ON;
