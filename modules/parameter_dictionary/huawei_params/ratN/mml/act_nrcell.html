Activate NR Cell (ACT NRCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to activate an NR cell.

Note

  • The cell setup result can be observed based on the cell status. You are advised to query the cell status by running the DSP NRCELL command 1 minute after the execution of this command. If the cell status is still unavailable, check whether an alarm is reported. If an alarm is reported, clear the alarm by referring to the alarm reference.

  • It may take more than one minute to set up a high-frequency multi-carrier cell. You can confirm the cell setup result two minutes later.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To activate an NR cell with NR Cell ID set to 0, run the following command:
ACT NRCELL: NrCellId=0;
