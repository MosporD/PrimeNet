Modify NR DU Cell Customized TRP Beam (MOD NRDUCELLTRPCUSTBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify Azimuth and Tilt configurations of a corresponding beam ID for a TRP in an NR DU cell in customized broadcast beam scenarios.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
BeamId Beam Id

Meaning: Indicates the beam ID of the customized and scenario-based beam. This parameter applies only to the TDD 64T low-frequency modules.

GUI Value Range: BEAM_0(SSB Beam 0), BEAM_1(SSB Beam 1), BEAM_2(SSB Beam 2), BEAM_3(SSB Beam 3), BEAM_4(SSB Beam 4), BEAM_5(SSB Beam 5), BEAM_6(SSB Beam 6), BEAM_7(SSB Beam 7)

Unit: None

Actual Value Range: BEAM_0, BEAM_1, BEAM_2, BEAM_3, BEAM_4, BEAM_5, BEAM_6, BEAM_7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1
Tilt Tilt

Meaning: Indicates the configured downtilt angle mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different tilt angle ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Tilt is -3° to 15°.

GUI Value Range: -3~15

Unit: degree

Actual Value Range: -3~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter setting must be consistent with the network plan. Otherwise, the service drop rate of UEs at the cell edge increases, the access success rate decreases, and the interference to neighboring cells increases.

Applicable Mode: N-TDD-FR1
Azimuth Azimuth

Meaning: Indicates the horizontal azimuth corresponding to the beamforming weight for a cell. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different azimuth ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Azimuth is -47° to 47°.

GUI Value Range: -47~47

Unit: degree

Actual Value Range: -47~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter setting must be consistent with the network plan. Otherwise, the service drop rate of UEs at the cell edge increases, the access success rate decreases, and the interference to neighboring cells increases.

Applicable Mode: N-TDD-FR1

Example

To modify the customized broadcast beam scenario under NR TRP with the parameters as follows: NR DU Cell TRP ID: 88, Beam Id: BEAM_0, Tilt: 1, Azimuth: 1, run the following command:
MOD NRDUCELLTRPCUSTBEAM: NrDuCellTrpId=88, BeamId=BEAM_0, Tilt=1, Azimuth=1;
