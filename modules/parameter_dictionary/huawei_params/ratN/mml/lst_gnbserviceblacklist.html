List gNodeB Service Blacklist (LST GNBSERVICEBLACKLIST)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list gNodeB service blacklist configurations.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of the operator who owns an external NR cell. The MCC, together with the MNC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in a gNBServiceBlacklist MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC of the operator who owns an external NR cell. The MCC, together with the MNC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in a gNBServiceBlacklist MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Tac Tracking Area Code

Meaning: Indicates the TAC of a neighboring cell, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells.

GUI Value Range: 0~16777215

Unit: None

Actual Value Range: 0~16777215

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list a gNodeB service blacklist with Mobile Country Code set to 302, Mobile Network Code set to 220, and Tracking Area Code set to 1, run the following command:
LST GNBSERVICEBLACKLIST: Mcc="302", Mnc="220", Tac=1;
The result is shown as follows:
+++    0        2019-08-16 20:33:13

Output Description

Field Description

Mobile Country Code

Indicates the MCC of the operator who owns an external NR cell. The MCC, together with the MNC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

Mobile Network Code

Indicates the MNC of the operator who owns an external NR cell. The MCC, together with the MNC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.

Tracking Area Code

Indicates the TAC of a neighboring cell, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells.

IMS Service Indicator

Indicates the IMS service indicator of a cell in a tracking area.
