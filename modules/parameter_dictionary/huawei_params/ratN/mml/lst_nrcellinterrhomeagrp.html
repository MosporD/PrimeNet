List Measurement Parameter Group Related to Inter-RAT Handover (LST NRCELLINTERRHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list one or more measurement parameter groups related to inter-RAT handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterRatHoMeasGroupId Inter-RAT Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-RAT handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA2RsrpThld must be greater than that of CovHoToEutranBlindA2Thld.
  • In an NRCellInterRHoMeaGrp MO identified by an InterRatHoMeasGroupId value, the value of InterRatHoA1RsrpThld must be greater than that of InterRatHoA2RsrpThld.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list a measurement parameter group related to inter-RAT handover for an NR cell with NR Cell ID set to 5 and Inter-RAT Handover Measurement Group ID set to 0, run the following command:
LST NRCELLINTERRHOMEAGRP: NrCellId=5, InterRatHoMeasGroupId=0;

Output Description

Field Description

NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

Inter-RAT Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover.

Inter-RAT Handover A1 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A1 related to inter-RAT handover. If the measured RSRP value of the serving cell is greater than the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A1 reports. For details, see 3GPP TS 38.331.

Inter-RAT Handover A2 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A2 related to inter-RAT handover. If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A2 measurement reports. For details, see 3GPP TS 38.331.

Inter-RAT Handover A1A2 Hysteresis(0.5dB)

Indicates the hysteresis for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

Inter-RAT Handover A1A2 Time To Trigger(ms)

Indicates the time-to-trigger for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.

Cov HO to E-UTRAN Blind A2 RSRP Thld(dBm)

Indicates the RSRP threshold for event A2 related to coverage-based blind handover to E-UTRAN and inter-frequency blind redirection.

If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger for event A1/A2 related to inter-RAT mobility procedures, UEs send event A2 reports related to blind mobility procedures. For details, see 3GPP TS 38.331.

Cov HO to E-UTRAN B2 RSRP Thld1(dBm)

Indicates the RSRP threshold 1 for event B2 related to coverage-based handover to E-UTRAN. If the measured RSRP value of the serving cell is below the event B2 RSRP threshold 1 throughout the corresponding time-to-trigger for event B1/B2 related to coverage-based handover to E-UTRAN and the RSRP of a neighboring E-UTRAN cell is greater than the RSRP threshold for event B1 related to coverage-based handover to E-UTRAN throughout the same time-to-trigger, UEs send event B2 measurement reports. For details, see 3GPP TS 38.331.
