Add gNodeB CU Xn (ADD GNBCUXN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the gNodeB CU Xn object.

Note

  • Before adding the gNodeB CU Xn object, ensure that the control-plane and user-plane endpoint groups to be used by this object have been added.

  • When the gNodeB CU X2 object and the gNodeB CU Xn object use the same user-plane local IP address and peer IP address, they must be configured with the same user-plane endpoint group. Otherwise, only the first user-plane channel can be established, and the subsequent channels fail to be established.

Meaning: Indicates the ID of the user-plane endpoint group used by the gNodeB CU Xn object.

GUI Value Range: 0~65535

Unit: None

MML Default Value: None

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add the gNodeB CU Xn object with the parameters as follows: gNodeB CU Xn ID set to 0, Control Plane Endpoint Group ID set to 1, User Plane Endpoint Group ID set to 1, run the following command:
ADD GNBCUXN: gNBCuXnId=0, CpEpGroupId=1, UpEpGroupId=1;
