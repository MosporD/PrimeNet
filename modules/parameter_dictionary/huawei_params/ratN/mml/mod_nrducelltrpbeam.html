Modify NR DU Cell TRP Beam (MOD NRDUCELLTRPBEAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the TRP beam configuration of a TDD NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the scenario ID is changed, random access may be re-initiated for NSA UEs and service drops may occur; for SA UEs, the success rate of incoming handovers and resynchronization may decrease. This operation will not cause cell reestablishment but will cause the throughput to decrease for a period of time (about 5 minutes).

Adjusting the beam pattern of an antenna affects the radio coverage range, which results in network KPI changes. It is good practice to set this parameter based on onsite coverage.

Applicable Mode: N-TDD-FR1
Tilt Tilt

Meaning: Indicates the configured downtilt angle mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. If this parameter is set to 255, the default downtilt angle supported by the hardware is used. The DSP NRDUCELLTRP command can be executed to query the tilt angle adjustment range supported by different types of AAUs.

Before a cell is set up, if the value range of the tilt angle is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the tilt angle of the cell exceeds the range supported by the AAU, the value configured last time takes effect.

When multiple cells are configured on an AAU with an RET system, the downtilt angles of all cells must be the same. Otherwise, cell setup fails.

If the CoverageScenario parameter is set to CUSTOMIZED_BEAM_SCENARIO, this parameter must be set to 0, and the tilt that takes effect is the NRDUCellTrpCustBeam.Tilt parameter value.

MaxSsbPwrOffset Max SSB Power Offset

Meaning: Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to low-frequency TDD cells.

GUI Value Range: -15~15

Unit: dB

Actual Value Range: -15~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • When CoverageScenario in the NRDUCellTrpBeam MO is set to CUSTOMIZED_BEAM_SCENARIO, MaxSsbPwrOffset must be set to 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in higher power used for sending an SSB, larger coverage of the SSB beam, and lower available transmit power for data transmitted at the same time. In this case, the cell throughput decreases when the inbound traffic of the cell is sufficient. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1

Example

To modify the configuration of beams in an NR DU cell as follows: NR DU Cell TRP ID: 77, Coverage Scenario: SCENARIO_1, Tilt: 3, Azimuth: 0, run the following command:
MOD NRDUCELLTRPBEAM: NrDuCellTrpId=77, CoverageScenario=SCENARIO_1, Tilt=3, Azimuth=0;
