Modify gNodeB Ciphering Capability (MOD GNBCIPHERCAPB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the priorities of gNodeB ciphering algorithms.

Note

None.

Parameters

ID Name Description
CipherAlgoPriority Ciphering Algorithm Priority

Meaning: Indicates the priority of a ciphering algorithm. PRIMARY indicates the highest priority, SECOND indicates the second priority, THIRD indicates the third priority, and FOURTH indicates the fourth priority.

GUI Value Range: PRIMARY(Primary-Priority Cipher Algorithm), SECOND(Second-Priority Cipher Algorithm), THIRD(Third-Priority Cipher Algorithm), FOURTH(Fourth-Priority Cipher Algorithm)

Unit: None

Actual Value Range: PRIMARY, SECOND, THIRD, FOURTH

MML Default Value: None

Recommended Value: PRIMARY(Primary-Priority Cipher Algorithm)

Parameter Relationship:

-Configuration constraints:

  • In gNBCipherCapb MOs, different CipherAlgoPriority values must correspond to different CipherAlgo values, except for the case that the value of CipherAlgo is NOT_CONFIG.
  • In gNBCipherCapb MOs, at least one CipherAlgo value is not NOT_CONFIG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
CipherAlgo Ciphering Algorithm

Meaning: Indicates a ciphering algorithm corresponding to a priority. If this parameter is set to NULL, data is not encrypted. If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting a ciphering algorithm.

GUI Value Range: NULL(NULL Algorithm), NOT_CONFIG(Not Configured), AES_128(AES_128 Algorithm), SNOW3G_128(SNOW3G_128 Algorithm), ZUC_128(ZUC_128 Algorithm)

Unit: None

Actual Value Range: NULL, NOT_CONFIG, AES_128, SNOW3G_128, ZUC_128

MML Default Value: None

Recommended Value: AES_128(AES 128 Algorithm)

Parameter Relationship:

-Configuration constraints:

  • In gNBCipherCapb MOs, different CipherAlgoPriority values must correspond to different CipherAlgo values, except for the case that the value of CipherAlgo is NOT_CONFIG.
  • In gNBCipherCapb MOs, at least one CipherAlgo value is not NOT_CONFIG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NOT_CONFIG, the gNodeB skips the corresponding priority when selecting a ciphering algorithm. If the ciphering algorithm list that the gNodeB supports and ciphering algorithms that a UE supports have no intersection, the security mode configuration fails for the UE, resulting in an SRB/DRB setup failure or handover failure.

Applicable Mode: N

Example

To modify the settings of gNodeB ciphering algorithm priority with the parameters as follows: Ciphering Algorithm Priority: Fourth Highest, Ciphering Algorithm: NOT_CONFIG, run the following command:
MOD GNBCIPHERCAPB: CipherAlgoPriority=FOURTH, CipherAlgo=NOT_CONFIG;
