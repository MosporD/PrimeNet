Remove gNodeB DU Co-NARFCN Cell Group Cell (RMV GNBDUNARFCNCGCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove a gNodeB DU co-NARFCN cell group cell.

Note

None.

Parameters

ID Name Description
NarfcnCellGroupId NARFCN Cell Group ID

Meaning: Indicates the ID of an NARFCN cell group, which uniquely identifies the NARFCN cell group within a gNodeB.

GUI Value Range: 0~191

Unit: None

Actual Value Range: 0~191

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The values of NrDuCellId in all gNBDUNarfcnCgCell MOs must be different.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a gNodeB DU NARFCN Cell with NARFCN Cell Group ID set to 0 and NR DU Cell ID set to 88, run the following command:
RMV GNBDUNARFCNCGCELL: NarfcnCellGroupId=0, NrDuCellId=88;
