List NR DU Cell PRACH (LST NRDUCELLPRACH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the PRACH configuration of NR DU Cells.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the PRACH configuration of an NR DU cell with NR DU Cell ID set to 0, run the following command:
LST NRDUCELLPRACH: NrDuCellId=0;
The result is shown as follows:

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

Prach Configuration Index

Indicates the PRACH configuration index of an NR DU cell. For details about this parameter, see 3GPP TS 38.211. When this parameter is set to a value in the range of 0 to 255, the PRACH configuration index of the NR DU cell equals this parameter value. When this parameter is set to 65535, the PRACH configuration index of the NR DU cell is automatically generated.

When this parameter is set to 189, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 120 kHz.

When this parameter is set to 187 or 65535, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 60 kHz.

The valid value range of this parameter is as follows:

When the system frequency band is sub-6 GHz, the duplex mode is FDD, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is SA-only, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is NSA or hybrid NSA and SA, and the subcarrier spacing is 15 kHz: 1, 2, 3, 5, 6, 7, 9, 10, 11, 13, 14, 15, 17, 18, 21, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 30 kHz: 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 0 to 7, 12, 17, 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 0 to 7, 12, 17, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 9, 14, 19, 195, 206, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 9, 14, 19, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 2_3_DSUUU, and the subcarrier spacing is 30 kHz: 10, 15, and 65535

When the system frequency band is mmWave, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz: 187, 189, and 65535

If the value range exceeds the preceding ranges, cell activation fails.

RSRP Threshold for SSB Selection

Indicates the RSRP threshold index for SSB selection. This parameter corresponds to the rsrp-ThresholdSSB IE specified in 3GPP TS 38.331. For details about this parameter, see 3GPP TS 38.321.

CBRA Preamble Percentage(%)

Indicates the proportion of contention-based preambles to the sum of contention-based preambles and dedicated preambles. If this parameter is set to 255, the GUI value is invalid. In this case, the proportion is determined by the system. If this parameter is set to other values, the proportion is determined by the value of this parameter.

Maximum Preamble Transmission Count

Indicates the maximum number of preamble transmissions of a cell. For details about this parameter, see 3GPP TS 38.321.

PRACH Threshold Increase Rate(%)

Indicates the percentage by which the PRACH preamble detection threshold increases. The value x indicates that the PRACH preamble detection threshold increases by x%.

Narrow Beam Probe Threshold

Indicates the SSB RSRP threshold for triggering narrow-beam probe after narrow-beam probe is enabled. If the RSRP reported by a UE is less than this threshold, the cell attempts to use the narrow beam to receive or transmit UE access messages. Otherwise, the cell still uses the wide beam. This parameter applies only to high-frequency TDD cells.

Random Access Algorithm Opt Switch

Indicates the random access optimization switches.

CONTENTION_FREE_RA_OPT_SW: Indicates whether to optimize the handling of non-contention-based random access for UEs located beyond the planned cell radius. If this option is selected, the gNodeB optimizes the handling of non-contention-based random access for UEs located beyond the planned cell radius and allows these UEs to access the network. If this option is deselected, this function is disabled.

PRACH_FALSE_ALARM_DET_ALGO_SW: Indicates whether to enable PRACH false alarm detection. If this option is selected, PRACH false alarm detection is enabled. If the gNodeB considers the initial contention-based preamble sent by a UE as a PRACH false alarm, the gNodeB does not send the UE a random access response (RAR) message and does not count the preamble in the counter indicating the number of random preamble receptions. If this option is deselected, PRACH false alarm detection is disabled. This parameter applies only to low-frequency TDD, FDD, and SUL cells.

PRACH False Alarm Detect Distance Thld(m)

Indicates the distance threshold for PRACH false alarm detection. When the gNodeB detects that the distance is greater than this parameter value, the contention-based preamble is considered as a falsely detected preamble. The distance is calculated based on the timing advance (TA) of the contention-based preamble that the gNodeB received for the first time from a UE. This parameter takes effect only when the PRACH_FALSE_ALARM_DET_ALGO_SW option of NRDUCellPrach.RachAlgoOptSwitch is selected. This parameter applies only to low-frequency TDD, FDD, and SUL cells.
