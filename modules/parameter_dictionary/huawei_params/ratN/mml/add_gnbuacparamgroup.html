Add gNodeB Unified Access Control Parameter Group (ADD GNBUACPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB UAC parameter group.

Note

None.

Parameters

ID Name Description
AccessControlParamGrpId Access Control Parameter Group ID

Meaning: Indicates the ID of an access control parameter group.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
BarStateForSpecialAcsId Barring State for Special Access ID

Meaning: Indicates whether access barring check is required for UEs with a special access ID. During an access barring check, the uac-BarringFactor and uac-BarringTime IEs in SIB1 determine whether an access attempt is allowed. For details, see 3GPP TS 38.331.

ACCESS_ID1_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 1, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 1 is allowed.

ACCESS_ID2_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 2, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 2 is allowed.

ACCESS_ID11_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 11, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 11 is allowed.

ACCESS_ID12_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 12, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 12 is allowed.

ACCESS_ID13_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 13, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 13 is allowed.

ACCESS_ID14_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 14, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 14 is allowed.

ACCESS_ID15_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 15, and the UEs determine whether the access attempt is allowed based on the check result. If this option is deselected, the access attempt of UEs with Access Identity 15 is allowed.

GUI Value Range: ACCESS_ID1_BAR_STATE(Access Identity 1 Barring State), ACCESS_ID2_BAR_STATE(Access Identity 2 Barring State), ACCESS_ID11_BAR_STATE(Access Identity 11 Barring State), ACCESS_ID12_BAR_STATE(Access Identity 12 Barring State), ACCESS_ID13_BAR_STATE(Access Identity 13 Barring State), ACCESS_ID14_BAR_STATE(Access Identity 14 Barring State), ACCESS_ID15_BAR_STATE(Access Identity 15 Barring State)

Unit: None

Actual Value Range: ACCESS_ID1_BAR_STATE, ACCESS_ID2_BAR_STATE, ACCESS_ID11_BAR_STATE, ACCESS_ID12_BAR_STATE, ACCESS_ID13_BAR_STATE, ACCESS_ID14_BAR_STATE, ACCESS_ID15_BAR_STATE

MML Default Value: None

Recommended Value: ACCESS_ID1_BAR_STATE:Allow, ACCESS_ID2_BAR_STATE:Allow, ACCESS_ID11_BAR_STATE:Allow, ACCESS_ID12_BAR_STATE:Allow, ACCESS_ID13_BAR_STATE:Allow, ACCESS_ID14_BAR_STATE:Allow, ACCESS_ID15_BAR_STATE:Allow

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, if one or more options of this parameter are selected, UEs corresponding to the access ID cannot initiate access.)

Impact on Radio Network Performance: If one or more of the ACCESS_ID1_BAR_STATE, ACCESS_ID2_BAR_STATE, ACCESS_ID11_BAR_STATE, ACCESS_ID12_BAR_STATE, ACCESS_ID13_BAR_STATE, ACCESS_ID14_BAR_STATE, and ACCESS_ID15_BAR_STATE options of the BarStateForSpecialAccID parameter are selected, UEs with the corresponding access ID are not allowed to initiate access.

Applicable Mode: N

Example

To add a gNodeB UAC parameter group with Access Control Parameter Group ID set to 1:
ADD GNBUACPARAMGROUP: AccessControlParamGrpId=1;
