Add gNodeB External PLMN List (ADD GNBEXTERNALPLMN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add external PLMN configurations of a gNodeB.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC in the external PLMN ID of a gNodeB.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc in an gNBExternalPlmn MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
Mnc Mobile Network Code

Meaning: Indicates the MNC in the external PLMN ID of a gNodeB.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc in an gNBExternalPlmn MO can contain only digits.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBIdLength gNodeB ID Length

Meaning: Indicates the length of the gNodeB ID in the NCI corresponding to the external PLMN ID of a gNodeB.

GUI Value Range: 22~32

Unit: None

Actual Value Range: 22~32

MML Default Value: 22

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add an external PLMN list with the parameters as follows: Mobile Country Code: 402, Mobile Network Code: 02, gNodeB ID Length: 24, run the following command:
ADD GNBEXTERNALPLMN: Mcc="402", Mnc="02", gNBIdLength=24;
