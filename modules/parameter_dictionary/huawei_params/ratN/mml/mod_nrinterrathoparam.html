Modify NR Cell Inter-RAT Handover Parameter (MOD NRINTERRATHOPARAM)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify parameter configurations related to inter-RAT handover.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
HoModeSwitch Handover Mode Switch

Meaning: Indicates the handover mode switches, which correspond to the inputs based on which the gNodeB determines handover policies.

EUTRAN_HO_SWITCH: Indicates whether NG-RAN can hand over UEs to E-UTRAN. NG-RAN can hand over UEs to E-UTRAN only if this option is selected.

EUTRAN_REDIRECT_SWITCH: Indicates whether NG-RAN can redirect UEs to E-UTRAN. NG-RAN can redirect UEs to E-UTRAN only if this option is selected.

VOICE_BLIND_MODE_SWITCH: Indicates whether EPS fallback and emergency call fallback to E-UTRAN can be performed in blind mode. If this option is selected, EPS fallback and emergency call fallback to E-UTRAN can be performed in blind mode. If this option is deselected, EPS fallback and emergency call fallback to E-UTRAN cannot be performed in blind mode. In regard to the blind mode supported in the current version, only blind redirection is supported.

GUI Value Range: EUTRAN_HO_SWITCH(E-UTRAN Handover Switch), EUTRAN_REDIRECT_SWITCH(E-UTRAN Redirection Switch), VOICE_BLIND_MODE_SWITCH(Voice Service Blind Mode Switch)

Unit: None

Actual Value Range: EUTRAN_HO_SWITCH, EUTRAN_REDIRECT_SWITCH, VOICE_BLIND_MODE_SWITCH

MML Default Value: None

Recommended Value: EUTRAN_HO_SWITCH:Off, EUTRAN_REDIRECT_SWITCH:Off, VOICE_BLIND_MODE_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: VOICE_BLIND_MODE_SWITCH: If this option is selected, NG-RAN can perform EPS fallback and emergency call fallback in a blind mode, reducing the fallback delay. If this option is deselected, the fallback delay is increased.

Applicable Mode: N
EpsFbProtectionTimer EPS FB Protection Timer

Meaning: Indicates the length of the EPS fallback protection timer. If this timer expires, the gNodeB blindly redirects UEs.

GUI Value Range: 1~100

Unit: 100ms

Actual Value Range: 100~10000

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A large value of this parameter leads to a long waiting time and increases the EPS fallback delay. If this parameter is set to a small value, the source gNodeB triggers blind redirection before UEs complete measurement, send measurement results after measurement, or complete a normal handover procedure. In this case, UEs are handed over through blind redirection instead of a PS handover procedure which can be successfully performed, increasing the EPS fallback delay.

Applicable Mode: N
InterRatHoTriggerEventType Inter-RAT Handover Trigger Event Type

Meaning: Indicates the type of the inter-RAT handover event. The event type can be B1 or B2. This parameter applies only to coverage-based handovers. For details, see 3GPP TS 38.331.

GUI Value Range: EVENT_B1(Event B1), EVENT_B2(Event B2)

Unit: None

Actual Value Range: EVENT_B1, EVENT_B2

MML Default Value: None

Recommended Value: EVENT_B2(Event B2)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to EVENT_B1(Event B1), coverage-based NR to LTE handovers depend on the service quality of neighboring cells. When this parameter is set to EVENT_B2(Event B2), coverage-based NR to LTE handovers depend on the service quality of the serving cell and neighboring cells.

Applicable Mode: N
EpsFbMode EPS FB Mode

Meaning: Indicates the mobility policy for EPS fallback and emergency call fallback. If this parameter is set to HANDOVER, EPS fallback and emergency call fallback UEs preferentially fall back to E-UTRAN through handovers.

If this parameter is set to REDIRECTION, EPS fallback and emergency call fallback UEs preferentially fall back to E-UTRAN through redirections.

GUI Value Range: HANDOVER(Handover), REDIRECTION(Redirection)

Unit: None

Actual Value Range: HANDOVER, REDIRECTION

MML Default Value: None

Recommended Value: HANDOVER(Handover)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify inter-RAT handover configurations with the parameters as follows: NR Cell ID: 2, EUTRAN_HO_SWITCH: On, EPS FB Protection Timer: 100, Inter-RAT Handover Trigger Event Type: EVENT_B1, EPS FB Mode:REDIRECTION, run the following command:
MOD NRINTERRATHOPARAM: NrCellId=2, HoModeSwitch=EUTRAN_HO_SWITCH-1, EpsFbProtectionTimer=100, InterRatHoTriggerEventType=EVENT_B1, EpsFbMode=REDIRECTION;
