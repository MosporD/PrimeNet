Modify NR DU Cell RIM Configuration (MOD NRDUCELLRIMCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the RIM configuration of an NR DU cell.

Note

In remote interference management for NR DU cells, the values of the RimRsType1SetIdSize, RimRsFreqCandNum, RimRsType1SeqCandNum, RimRsFunctionSwitch, RimRsScrTimerMultiFactor, RimRsScrTimerOffset, and RimRsType1ScidForIs0~RimRsType1ScidForIs7 parameters must be consistent with those on the peer NR base station. The value of the RimRsType1SetId parameter must be different from that of the corresponding parameter of the peer NR base station. RimRsStartFreqOffset must be aligned with the start PRB frequency domain position of the RIM-RS signal on the peer NR base station.

RimRsFreqCandNum RIM-RS Frequency Candidate Number

Meaning: Indicates the number of candidate frequency-domain resources for global RIM-RS characteristic sequence for remote interference management. This parameter applies only to low-frequency TDD cells.

The value FREQ_NUM_1 indicates that only one candidate frequency-domain resource is available.

The value FREQ_NUM_2 indicates that two candidate frequency-domain resources are available.

The value FREQ_NUM_4 indicates that four candidate frequency-domain resources are available.

The value NULL indicates an invalid value.

GUI Value Range: FREQ_NUM_1(One Frequency Domain), FREQ_NUM_2(Two Frequency Domains), FREQ_NUM_4(Four Frequency Domains), NULL(Invalid Value)

Unit: None

Actual Value Range: FREQ_NUM_1, FREQ_NUM_2, FREQ_NUM_4, NULL

MML Default Value: None

Recommended Value: The recommended value differs depending on the bandwidth combinations in a cell group for remote interference detection.

If the downlink bandwidth is 20 MHz or 30 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_1.

If the downlink bandwidth is 40 MHz, 50 MHz, 60 MHz, or 70 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_2.

If the downlink bandwidth is 80 MHz, 90 MHz, or 100 MHz, the recommended value of RimRsFreqCandNum is FREQ_NUM_4.

In other scenarios, set this parameter based on the minimum bandwidth in the bandwidth combination.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NULL, network performance is not affected. A smaller value of this parameter results in a longer interval at which the characteristic sequence is sent for remote interference management, less downlink capacity loss, and a longer sequence detection period. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1
RimRsType1SeqCandNum RIM-RS Type1 Sequence Candidate Number

Meaning: Indicates the number of candidate resources for type-1 RIM-RS characteristic sequence for remote interference management. This parameter applies only to low-frequency TDD cells.

The value SEQ_NUM_1 indicates that only one candidate sequence resource is available.

The value SEQ_NUM_2 indicates that two candidate sequence resources are available.

The value SEQ_NUM_4 indicates that four candidate sequence resources are available.

The value SEQ_NUM_8 indicates that eight candidate sequence resources are available.

The value NULL indicates an invalid value.

GUI Value Range: SEQ_NUM_1(One Sequence), SEQ_NUM_2(Two Sequences), SEQ_NUM_4(Four Sequences), SEQ_NUM_8(Eight Sequences), NULL(Invalid Value)

Unit: None

Actual Value Range: SEQ_NUM_1, SEQ_NUM_2, SEQ_NUM_4, SEQ_NUM_8, NULL

MML Default Value: None

Recommended Value: If RimRsFreqCandNum is set to FREQ_NUM_1, it is recommended that RimRsType1SeqCandNum be set to SEQ_NUM_8.

If RimRsFreqCandNum is set to FREQ_NUM_2 and the slot assignment is 4:1 or 7:3, it is recommended that RimRsType1SeqCandNum be set to SEQ_NUM_4. If the slot assignment is single-period 8:2 or dual-period 8:2, it is recommended that NumOfRimRsTpye1SeqCand be set to SEQ_NUM_8.

If RimRsFreqCandNum is set to FREQ_NUM_4 and the slot assignment is 4:1 or 7:3, it is recommended that RimRsType1SeqCandNum be set to SEQ_NUM_2. If the slot assignment is single-period 8:2 or dual-period 8:2, it is recommended that NumOfRimRsTpye1SeqCand be set to SEQ_NUM_4.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to NULL, network performance is not affected. A smaller value of this parameter results in a longer interval at which the characteristic sequence is sent for remote interference management, less downlink capacity loss, and a longer sequence detection period. A larger value of this parameter results in the opposite effects.

RimRsFunctionSwitch RIM-RS Function Switch

Meaning: Indicates the switch used to enable or disable the remote interference management reference signal (RIM-RS) function, including the near-far functionality in this function.

RIM_RS1_NEAR_FAR_SW: Indicates whether to enable the near-far functionality for type-1 RIM-RS. If this option is selected, the interference source at a longer distance can be detected. If this option is deselected, only the interference source at a limited distance can be detected. This option applies only to low-frequency TDD cells.

GUI Value Range: RIM_RS1_NEAR_FAR_SW(Type1 RIM-RS Near-Far Switch)

Unit: None

Actual Value Range: RIM_RS1_NEAR_FAR_SW

MML Default Value: None

Recommended Value: RIM_RS1_NEAR_FAR_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: RIM_RS1_NEAR_FAR_SW: If this option is deselected, network performance is not affected. If this option is selected, the interval at which the characteristic sequence is sent for RIM and the sequence detection period are extended. In this time, a longer time may be required for the adaptive remote interference avoidance function to take effect, but interference sources with a longer distance can be detected.

Applicable Mode: N-TDD-FR1
AvgUlIntrfPwrThld Average UL Intrf Pwr Threshold

Meaning: Indicates the threshold for determining average uplink interference power in RIM. This parameter is used to identify the atmospheric duct interference. The characteristic sequence can be sent only when the average uplink interference power is greater than this threshold. This parameter applies only to low-frequency TDD cells.

GUI Value Range: -140~-50

Actual Value Range: -140~-50

RimRsType1IntrfThld RIM-RS Type1 Intrf Thld

Meaning: Indicates the threshold for determining remote interference based on the type-1 RIM-RS characteristic sequences. When remote interference is detected, the base station uses the type-1 RIM-RS characteristic sequences to verify the remote interference. This parameter applies only to low-frequency TDD cells.

GUI Value Range: -140~-50

Unit: dBm

Actual Value Range: -140~-50

MML Default Value: None

Recommended Value: -102

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a higher probability that the downlink peak rate or average throughput decreases but lower uplink interference. This helps improve accessibility KPIs and uplink throughput. A larger value of this parameter results in a lower probability that the downlink peak rate or average throughput decreases. However, the uplink interference may not decrease. As a result, accessibility KPIs and uplink throughput do not improve significantly.

Applicable Mode: N-TDD-FR1

Example

To modify the RIM parameter configurations of an NR DU cell with NR DU Cell ID set to 88 and RIM-RS Type1 Set ID Size set to 20, run the following command:
MOD NRDUCELLRIMCONFIG: NrDuCellId=88, RimRsType1SetIdSize=20;
