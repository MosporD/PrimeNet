Modify NR DU Cell QCI Bearer (MOD NRDUCELLQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the bearer configuration of an NR DU cell. The configurations can be modified for bearers based on their QCIs.

Note

None.

Parameters

Meaning: Indicates the ID of a local cell, which uniquely identifies the NR DU cell within a gNodeB.

UeInactivityTimer UE Inactivity Timer

Meaning: Indicates the length of the UE inactivity timer in which the gNodeB monitors whether a UE transmits and receives data. If the gNodeB detects that a UE has neither received nor sent data within the timer length, the gNodeB checks whether the RRC_INACTIVE state takes effect for the UE. If it does, the UE state is changed to RRC_INACTIVE. If it does not, the UE is released. If this parameter is set to 0, the gNodeB releases the UE if it does not receive or send data for 3600s.

GUI Value Range: 0~3600

Unit: s

Actual Value Range: 0~3600

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in earlier RRC connection releases or transitions to the RRC_INACTIVE state for UEs not performing services, more frequent RRC connection setup or resume request initiations, and better network performance due to more normal RRC connection releases or more transitions from the RRC_CONNECTED state to the RRC_INACTIVE state. A larger value of this parameter results in later RRC connection releases or transitions to the RRC_INACTIVE state for UEs not performing services and longer RRC connection duration, occupying radio resources. In addition, network performance deteriorates due to decreased number of normal RRC connection releases or fewer transitions from the RRC_CONNECTED state to the RRC_INACTIVE state.

Applicable Mode: N
DuDrxParamGroupId DU DRX Parameter Group ID

Meaning: Indicates the ID of a DRX parameter group of an NR DU cell. If this parameter is set to 0 to 63, the QCI has valid DRX parameters. If this parameter is set to 255, DRX is disabled for the QCI.

GUI Value Range: 0~63,255

Unit: None

Actual Value Range: 0~63,255

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

QCI 1, QCI 5, QCI 65, QCI 66, and QCI 69: 255

QCI 2, QCI 3, QCI 7, QCI 75, and QCI 79: 0

QCI 4, QCI 6, QCI 8, QCI 9, and QCI 70: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the QCI bearer of an NR DU cell with the parameters as follows: NR DU Cell ID:88, Qci:8, MacParamGroupId:1, run the following command:
MOD NRDUCELLQCIBEARER: NrDuCellId=88, Qci=8, MacParamGroupId=1;
