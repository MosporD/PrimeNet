Modify NR DU Cell Operator (MOD NRDUCELLOP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify an NR DU cell operator.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When a cell is in the active state, the cell automatically restarts if the operator cell ID is modified.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In all records of an NRDUCellOp MO with the same NrDuCellId value and with CellResId not set to 255, CellResId must be unique.
  • CellPrimaryOpFlag can be set to TRUE in no more than one of the NRDUCellOp MOs with the same NrDuCellId value.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
TrackingAreaId Tracking Area ID

Meaning: Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the core network. It is different from the TAI configured in the TAL of the core network. If this parameter is set to 4294967295, the TAI of the operator corresponding to the cell is the value of TrackingAreaId in the NRDUCell MO. If this parameter is set to a value in the range of 0 to 65535, the TAI of the operator corresponding to the cell is the value of this parameter.

GUI Value Range: 0~65535,4294967295

Unit: None

Actual Value Range: 0~65535,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
PolicySwitch Policy Switch

Meaning: Indicates the policy switches configured for different operators in non-independent operator mode.

OP_SUL_SWITCH: Indicates whether Super Uplink or UL and DL Decoupling can be enabled for an operator. This option applies only to SUL.

GUI Value Range: OP_SUL_SWITCH(Operator SUL Switch)

Unit: None

Actual Value Range: OP_SUL_SWITCH

MML Default Value: None

Recommended Value: OP_SUL_SWITCH:On

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: OP_SUL_SWITCH: If this option is selected, Super Uplink or UL and DL Decoupling can be enabled for an operator. This increases the uplink coverage and uplink UE throughput. If this option is deselected, Super Uplink or UL and DL Decoupling cannot be enabled for an operator, which has no impact on network performance.

Applicable Mode: N-SUL
CellId Cell ID

Meaning: Indicates the operator-specific cell ID of an NR cell. This cell ID and the gNodeB ID of the operator compose the 3GPP-defined NR cell ID (NCI) of the operator. The NCI and the PLMN ID compose the NCGI. For details, see 3GPP TS 38.413. If this parameter is set to 65535, this parameter is invalid. In this case, no exclusive cell ID is available for the operator. If this parameter is set to a value in the range of 0 to 16383 and gNBSharingMode.MultipleNCISwitch is set to ON, the setting of this parameter takes effect. In this case, operators use their own cell IDs.

GUI Value Range: 0~16383,65535

Unit: None

Actual Value Range: 0~16383,65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
CellPrimaryOpFlag Cell Primary Operator Flag

Meaning: Indicates the primary operator of a cell. If the gNBSharingMode.MultipleNCISwitch parameter is set to ON, the primary operator must be specified. If the gNBSharingMode.MultipleNCISwitch parameter is set to OFF, there is no need to specify the primary operator.

GUI Value Range: FALSE(False), TRUE(True)

Unit: None

Actual Value Range: FALSE, TRUE

MML Default Value: None

Recommended Value: FALSE(False)

Parameter Relationship:

-Configuration constraints:

  • CellPrimaryOpFlag can be set to TRUE in no more than one of the NRDUCellOp MOs with the same NrDuCellId value.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CellResId Cell Resource ID

Meaning: Indicates the NR DU cell resource ID, which is used to add cell resources for an operator in multi-operator sharing scenarios. The value 255 indicates an invalid value, which means that cell resources are not added for the operator.

GUI Value Range: 0~5,255

Unit: None

Actual Value Range: 0~5,255

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In all records of an NRDUCellOp MO with the same NrDuCellId value and with CellResId not set to 255, CellResId must be unique.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify an NR DU cell operator with the parameters as follows: NR DU Cell ID: 88, Operator ID: 0, Tracking Area ID: 2, run the following command:
MOD NRDUCELLOP: NrDuCellId=88, OperatorId=0, TrackingAreaId=2;
