Modify NR DU Cell Paging Configuration (MOD NRDUCELLPAGINGCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the paging configurations of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
DefaultPagingCycle Default Paging Cycle

Meaning: Indicates the default paging cycle of a cell.

GUI Value Range: RF32(32 Radio Frames), RF64(64 Radio Frames), RF128(128 Radio Frames), RF256(256 Radio Frames)

Unit: None

Actual Value Range: RF32, RF64, RF128, RF256

MML Default Value: None

Recommended Value: RF128(128 Radio Frames)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter results in a longer paging cycle and lower UE power consumption. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify the paging configurations of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, Default Paging Cycle: RF64, run the following command:
MOD NRDUCELLPAGINGCONFIG: NrDuCellId=88, DefaultPagingCycle=RF64;
