Remove gNodeB QCI Bearer (RMV GNBQCIBEARER)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove gNodeB-level QCI-specific bearer configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the QCI configuration is deleted, the services corresponding to the QCI may not have proper QoS parameters, affecting the service rate and delay.

Parameters

ID Name Description
Qci QoS Class Identifier

Meaning: Indicates the QoS class identifier (QCI).

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove a gNodeB QCI bearer with QoS Class Identifier set to 10, run the following command:
RMV GNBQCIBEARER: Qci=10;
