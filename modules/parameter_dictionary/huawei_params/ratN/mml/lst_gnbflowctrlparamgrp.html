List gNodeB Flow Control Parameter Group (LST GNBFLOWCTRLPARAMGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the configuration of a gNodeB flow control parameter group.

Note

None.

Parameters

ID Name Description
FlowCtrlParamGroupId Flow Control Parameter Group ID

Meaning: Indicates the ID of a flow control parameter group.

GUI Value Range: 0~159

Unit: None

Actual Value Range: 0~159

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

To query the gNodeB flow control parameter group, run the following command:
LST GNBFLOWCTRLPARAMGRP:;

Output Description

Field Description

Flow Control Parameter Group ID

Indicates the ID of a flow control parameter group.

Flow Control Type

Indicates whether to enable flow control for bearers with a type of QCI. When this parameter is set to FLOW_CTRL for bearers with a type of QCI, flow control is enabled for the bearers with this type of QCI. When this parameter is set to NON_FLOW_CTRL for bearers with a type of QCI, flow control is not enabled for the bearers with this type of QCI. The QCI for GBR services is always NON_FLOW_CTRL. The value FLOW_CTRL does not apply to GBR services.

Uplink Flow Control Minimum CIR(kB/s)

Indicates the uplink minimum CIR when flow control is performed on bearers with a type of QCI.

Uplink Flow Control Priority Weight Factor

Indicates the weight factor for calculating the step of rate increase for bearers with a type of QCI when flow control is performed.
