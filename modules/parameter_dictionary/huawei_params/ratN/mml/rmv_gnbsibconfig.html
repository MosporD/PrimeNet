Remove gNodeB System Information Configuration (RMV GNBSIBCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to remove gNodeB system information configuration.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
SibConfigId SIB Config ID

Meaning: Indicates the ID of a set of system information configuration, including the system information type, system information transmission period, and system information transmission mode.

GUI Value Range: 0~10

Unit: None

Actual Value Range: 0~10

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SibType SIB Type

Meaning: Indicates the system information type. For details about this parameter, see 3GPP TS 38.331.

GUI Value Range: SIB_TYPE_2(Cell Reselection Common Information), SIB_TYPE_3(Intra-freq Cell Reselection Information), SIB_TYPE_4(Inter-freq Cell Reselection Information), SIB_TYPE_5(Inter-RAT Cell Reselection Information), SIB_TYPE_9(GPS and UTC Time Information)

Unit: None

Actual Value Range: SIB_TYPE_2, SIB_TYPE_3, SIB_TYPE_4, SIB_TYPE_5, SIB_TYPE_9

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • For MO instances with the same SibConfigId and with SibTransPolicy not set to OFF:
  • When there is at least one MO instance with SibTransPeriod set to 320MS, the number of MO instances is less than or equal to 4.
  • When there is no MO instance with SibTransPeriod set to 320MS but there is at least one MO instance with SibTransPeriod set to 640MS, the number of MO instances is less than or equal to 8.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To remove gNodeB system information configuration with the parameters as follows: SIB Config ID:1, SIB Type:SIB_TYPE_2, run the following command:
RMV GNBSIBCONFIG: SibConfigId=1, SibType=SIB_TYPE_2;
