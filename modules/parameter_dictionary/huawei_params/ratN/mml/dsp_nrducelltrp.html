Display NR DU Cell TRP (DSP NRDUCELLTRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the configuration of TRPs for an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB. When virtual MIMO is enabled for LampSite base stations, the NrDuCellId parameter of the slave TRP must be set to 65535.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of TRP for NR DU cell with NR DU Cell TRP ID set to 88, run the following command:
DSP NRDUCELLTRP: NrDuCellId=88;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB. When virtual MIMO is enabled for LampSite base stations, the NrDuCellId parameter of the slave TRP must be set to 65535.

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB.

NR DU Cell TRP State

Indicates the NR DU cell TRP state.

NR DU Cell TRP Unavailable Reason

Indicates the cause of the NR DU cell TRP setup failure.

Supported Beam Scenario

Indicates the beam scenarios supported by an AAU.

TDD Low-Frequency:

0: DEFAULT, 1~16: SCENARIO_1~SCENARIO_16, 17~22: EXPAND_SCENARIO_1~EXPAND_SCENARIO_6, 99: CUSTOMIZED_BEAM_SCENARIO

TDD High-Frequency:

100: DEFAULT, 101: SCENARIO_101, 103: SCENARIO_103

FDD:

200: DEFAULT, 201: SCENARIO_201

Default Beam Scenario

Indicates the default beam scenario. If this parameter is displayed as NULL, the gNodeB cannot directly obtain the coverage shape of the antenna beam. In this case, the coverage beam shape is determined by the antenna type.

Actual Beam Scenario

Indicates the actual beam scenario.

Supported Azimuth Config Range(degree)

Indicates the range of the azimuth supported by the AAU. This parameter applies only to TDD.

Supported Tilt Config Range(degree)

Indicates the range of the tilt angle supported by the AAU. This parameter applies only to TDD.

Actual Azimuth(degree)

Indicates the actual azimuth of an AAU. This parameter applies only to TDD.

Actual Tilt(degree)

Indicates the actual tilt angle of an AAU. This parameter applies only to TDD.
