Modify NR DU Cell PRACH (MOD NRDUCELLPRACH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the PRACH configuration of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
PrachConfigurationIndex Prach Configuration Index

Meaning: Indicates the PRACH configuration index of an NR DU cell. For details about this parameter, see 3GPP TS 38.211. When this parameter is set to a value in the range of 0 to 255, the PRACH configuration index of the NR DU cell equals this parameter value. When this parameter is set to 65535, the PRACH configuration index of the NR DU cell is automatically generated.

When this parameter is set to 189, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 120 kHz.

When this parameter is set to 187 or 65535, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz, the subcarrier spacing of Msg1 must be 60 kHz.

The valid value range of this parameter is as follows:

When the system frequency band is sub-6 GHz, the duplex mode is FDD, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is SA-only, and the subcarrier spacing is 15 kHz: 0 to 21 and 65535

When the system frequency band is sub-6 GHz, the duplex mode is SUL, the networking mode is NSA or hybrid NSA and SA, and the subcarrier spacing is 15 kHz: 1, 2, 3, 5, 6, 7, 9, 10, 11, 13, 14, 15, 17, 18, 21, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 30 kHz: 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 0 to 7, 12, 17, 200, 202, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDDDDDSUU or 7_3_DDDSUDDSUU, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 0 to 7, 12, 17, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is less than or equal to 9650 m: 9, 14, 19, 195, 206, 210, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 8_2_DDDSUUDDDD, the subcarrier spacing is 30 kHz, and the cell radius is greater than 9650 m: 9, 14, 19, and 65535

When the system frequency band is sub-6 GHz, the duplex mode is TDD, the slot assignment is 2_3_DSUUU, and the subcarrier spacing is 30 kHz: 10, 15, and 65535

When the system frequency band is mmWave, the duplex mode is TDD, the slot assignment is 4_1_DDDSU, and the subcarrier spacing is 120 kHz: 187, 189, and 65535

If the value range exceeds the preceding ranges, cell activation fails.

GUI Value Range: 0~255,65535

Unit: None

Actual Value Range: 0~255,65535

MML Default Value: None

Recommended Value: 65535

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If the parameter value corresponds to a longer PRACH period, the gNodeB supports lighter access load and fewer uplink resources are occupied. If the parameter value corresponds to a shorter PRACH period, the gNodeB supports heavier access load and more uplink resources are occupied.

Applicable Mode: N
RsrpThldForSsbSelection RSRP Threshold for SSB Selection

Meaning: Indicates the RSRP threshold index for SSB selection. This parameter corresponds to the rsrp-ThresholdSSB IE specified in 3GPP TS 38.331. For details about this parameter, see 3GPP TS 38.321.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower RSRP of the SSB selected by the UE and a lower access success probability. However, the time for searching for a proper SSB is shorter, which shortens the access delay. A larger value of this parameter results in the opposite effects.

Applicable Mode: N
CbraPreamblePct CBRA Preamble Percentage

Meaning: Indicates the proportion of contention-based preambles to the sum of contention-based preambles and dedicated preambles. If this parameter is set to 255, the GUI value is invalid. In this case, the proportion is determined by the system. If this parameter is set to other values, the proportion is determined by the value of this parameter.

GUI Value Range: 6~94,255

Unit: %

Actual Value Range: 6~94,255

MML Default Value: None

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to 255, the network performance is not affected. If this parameter is set to a value other than 255, a smaller value of this parameter leads to a higher probability of contention-based access collision, a longer contention-based access delay, a higher probability that dedicated preambles are allocated to non-contention-based access UEs, and a shorter non-contention-based access delay. A larger value of this parameter leads to the opposite effects. The service drop rate may increase if the access delay increases.

Applicable Mode: N
MaxPreambleTransCnt Maximum Preamble Transmission Count

Meaning: Indicates the maximum number of preamble transmissions of a cell. For details about this parameter, see 3GPP TS 38.321.

GUI Value Range: N3(3 Times), N4(4 Times), N5(5 Times), N6(6 Times), N7(7 Times), N8(8 Times), N10(10 Times), N20(20 Times), N50(50 Times), N100(100 Times), N200(200 Times)

Unit: None

Actual Value Range: N3, N4, N5, N6, N7, N8, N10, N20, N50, N100, N200

MML Default Value: None

Recommended Value: N10(10 Times)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher probability that the gNodeB correctly receives the preamble sent by the UE and a longer time that a UE experiencing radio link failures must wait before the RRC connection reestablishment procedure starts. A smaller value of this parameter leads to the opposite effects.

Applicable Mode: N
PrachThldIncreaseRate PRACH Threshold Increase Rate

Meaning: Indicates the percentage by which the PRACH preamble detection threshold increases. The value x indicates that the PRACH preamble detection threshold increases by x%.

GUI Value Range: 0~1000

Unit: %

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (For UEs in idle mode, if this parameter is set to a non-zero integer, a larger value of this parameter may result in a lower probability that UEs at the cell edge successfully access the network.)

Impact on Radio Network Performance: When this parameter is set to 0, network performance is not affected. When this parameter is set to a value other than 0, a larger value of this parameter results in a lower probability of both preambles detected and false alarms. It also results in a higher probability of both missing detection and UE access failures due to weak coverage at the cell edge. A smaller value of this parameter results in a higher probability of both preambles detected and false alarms.

Applicable Mode: N
NarrowBeamProbeThld Narrow Beam Probe Threshold

Meaning: Indicates the SSB RSRP threshold for triggering narrow-beam probe after narrow-beam probe is enabled. If the RSRP reported by a UE is less than this threshold, the cell attempts to use the narrow beam to receive or transmit UE access messages. Otherwise, the cell still uses the wide beam. This parameter applies only to high-frequency TDD cells.

GUI Value Range: -140~-43

Unit: None

Actual Value Range: -140~-43

MML Default Value: None

Recommended Value: -108

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in a lower probability of triggering narrow-beam probe during the access, which leads to smaller gains. A larger value of this parameter results in a higher probability of triggering narrow-beam probe, a higher access probability for UEs at the cell edge, and a longer access delay.

Applicable Mode: N-TDD-FR2
RachAlgoOptSwitch Random Access Algorithm Opt Switch

Meaning: Indicates the random access optimization switches.

CONTENTION_FREE_RA_OPT_SW: Indicates whether to optimize the handling of non-contention-based random access for UEs located beyond the planned cell radius. If this option is selected, the gNodeB optimizes the handling of non-contention-based random access for UEs located beyond the planned cell radius and allows these UEs to access the network. If this option is deselected, this function is disabled.

PRACH_FALSE_ALARM_DET_ALGO_SW: Indicates whether to enable PRACH false alarm detection. If this option is selected, PRACH false alarm detection is enabled. If the gNodeB considers the initial contention-based preamble sent by a UE as a PRACH false alarm, the gNodeB does not send the UE a random access response (RAR) message and does not count the preamble in the counter indicating the number of random preamble receptions. If this option is deselected, PRACH false alarm detection is disabled. This parameter applies only to low-frequency TDD, FDD, and SUL cells.

GUI Value Range: CONTENTION_FREE_RA_OPT_SW(Contention-Free RA Optimization Switch), PRACH_FALSE_ALARM_DET_ALGO_SW(PRACH False Alarm Detection Switch)

Unit: None

Actual Value Range: CONTENTION_FREE_RA_OPT_SW, PRACH_FALSE_ALARM_DET_ALGO_SW

MML Default Value: None

Recommended Value: CONTENTION_FREE_RA_OPT_SW:Off, PRACH_FALSE_ALARM_DET_ALGO_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: CONTENTION_FREE_RA_OPT_SW: If this option is selected and UEs located beyond the planned cell radius successfully access the network through non-contention-based random access, the number of RRC connection reestablishments decreases, the RRC connection reestablishment percentage increases, the RACH access success rate increases, and the uplink and downlink throughput increases when RBs are not fully scheduled. However, the access or handover delay increases. If the UE coverage is poor, the UE may still fail to access the network and the service drop rate may increase. If this option is deselected, network performance is not affected.

PRACH_FALSE_ALARM_DET_ALGO_SW: If PRACH false alarm detection is disabled, network performance is not affected. If PRACH false alarm detection is enabled, the probability of preamble false alarms decreases and the RACH access success rate increases when there are UEs with TA distance is greater than the PRACH false alarm detection distance threshold. However, there is a probability that some preambles are not detected, and the RACH access delay increases.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
PrachFalseAlmDetDisThld PRACH False Alarm Detect Distance Thld

Meaning: Indicates the distance threshold for PRACH false alarm detection. When the gNodeB detects that the distance is greater than this parameter value, the contention-based preamble is considered as a falsely detected preamble. The distance is calculated based on the timing advance (TA) of the contention-based preamble that the gNodeB received for the first time from a UE. This parameter takes effect only when the PRACH_FALSE_ALARM_DET_ALGO_SW option of NRDUCellPrach.RachAlgoOptSwitch is selected. This parameter applies only to low-frequency TDD, FDD, and SUL cells.

GUI Value Range: 0~100000

Unit: m

Actual Value Range: 0~100000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If PRACH false alarm detection is disabled, network performance is not affected. If PRACH false alarm detection is enabled, a larger value of this parameter results in a lower probability that the gNodeB correctly detects false alarms, a lower random access success rate, a smaller probability that contention-based preambles are falsely detected as false alarms, and a shorter random access delay. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To modify the PRACH configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 0, Prach Configuration Index: 202, run the following command:
MOD NRDUCELLPRACH: NrDuCellId=0, PrachConfigurationIndex=202;
