List gNodeB Commissioning Reserved Parameter Configuration (LST GNBRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of the reserved parameter for gNodeB commissioning.

Note

None.

Parameters

None.

Example

To list the configuration of the reserved parameter for gNodeB commissioning, run the following command:
LST GNBRSVDCFG:;
The result is shown as follows:

Reserved Switch Parameter 0

Indicates reserved switch parameter 0, which is used to facilitate commissioning on the live network.
