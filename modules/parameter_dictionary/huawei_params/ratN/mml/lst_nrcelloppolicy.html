List NR Cell Operator Policy (LST NRCELLOPPOLICY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list operator-specific policies of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD
OperatorId Operator ID

Meaning: Indicates the ID of an operator.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N-TDD, N-FDD

To list operator policies of NR cells, run the following command:
LST NRCELLOPPOLICY:;

Output Description

Field Description

NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

Operator ID

Indicates the ID of an operator.

gNodeB Frequency Priority Group ID

Indicates the ID of a frequency priority group of the gNodeB. The value 255 indicates that the frequency priority group is not configured.

EPS Fallback Mode

Indicates the operator-level mobility policy for EPS fallback and emergency call fallback.

If this parameter is set to NOT_CONFIG, the mobility policy for EPS fallback and emergency call fallback UEs is not operator-specific. In this case, the fallback mode is determined by the NRInterRatHoParam.EpsFbMode parameter.

If this parameter is set to HANDOVER, EPS fallback and emergency call fallback UEs fall back to E-UTRAN preferentially through handovers.

If this parameter is set to REDIRECTION, EPS fallback and emergency call fallback UEs fall back to E-UTRAN preferentially through redirections.

Voice Policy Switch

Indicates the operator-specific voice policy switches.

OPERATOR_VONR_SW: Indicates whether to enable VoNR services for an operator. VoNR services are supported by an operator of the cell only if this option is selected. It is recommended that VoNR not be enabled in high-frequency scenarios. This option takes effect only when the VONR_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected.

Inter-RAT Handover Policy Switch

Indicates inter-RAT handover policy switches for an operator. The switches separately determine whether to enable a specific type of handover measures.

EUTRAN_HO_SWITCH: Indicates whether NG-RAN can hand over UEs to E-UTRAN. NG-RAN can hand over UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_HO_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

EUTRAN_REDIRECT_SWITCH: Indicates whether NG-RAN can redirect UEs to E-UTRAN. NG-RAN can redirect UEs to E-UTRAN only if this option is selected. This option takes effect only when the EUTRAN_REDIRECT_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.

VOICE_BLIND_MODE_SWITCH: Indicates whether NG-RAN can perform EPS fallback and emergency call fallback in a blind mode. NG-RAN can perform EPS fallback and emergency call fallback in a blind mode only if this option is selected. In regard to the blind mode supported in the current version, only blind redirection is supported. This option takes effect only when the VOICE_BLIND_MODE_SWITCH option of the NRInterRatHoParam.HoModeSwitch parameter is selected.
