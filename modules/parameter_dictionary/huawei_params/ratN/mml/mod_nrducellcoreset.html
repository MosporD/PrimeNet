Modify NR DU Cell CORESET (MOD NRDUCELLCORESET)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the settings of CORESET parameters for an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CommonCtrlResRbNum Common Control Resource RB Number

Meaning: Indicates the number of RBs for common control resources of a cell. By default, the common control resources of a cell occupy the first symbol in each of such RBs. The frequency domain position of the common PDCCH changes according to the SSB position. This parameter is invalid when SpectrumCloudSwitch(NRDUCellAlgoSwitch) is set to LTE_NR_FDD_SPCT_SHR_SW.

GUI Value Range: RB24(24 RBs x 2 Symbols), RB48(48 RBs x 1 Symbol), RB96(48 RBs x 2 Symbols)

Unit: None

Actual Value Range: RB24, RB48, RB96

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

When the bandwidth of a TDD cell is 20 MHz or 30 MHz or frequency band being n40 and the SSB subcarrier spacing being 15 kHz: RB24(24 RBs x 2 Symbols)

When the bandwidth of an FDD cell is 5 MHz or 10 MHz: RB24(24 RBs x 2 Symbols)

Other scenarios: RB48(48 RBs x 1 Symbol)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To modify the CORESET configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 0, Common Control Resource RB Number: RB48, run the following command:
MOD NRDUCELLCORESET: NrDuCellId=0, CommonCtrlResRbNum=RB48;
