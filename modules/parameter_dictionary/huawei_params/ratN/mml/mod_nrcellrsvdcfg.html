Modify NR Cell Commissioning Reserved Parameter Configuration (MOD NRCELLRSVDCFG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the configuration of a reserved parameter for NR cell commissioning.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
