Add gNodeB Frequency Band Configuration (ADD GNBFREQBANDCONFIG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add frequency-band-level configurations for the gNodeB. The configurations automatically apply to all cells in this frequency band.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the value of FrameOffset is not 4294967295, running this command will reset all cells running in the frequency band.

Parameters

ID Name Description
FrequencyBand Frequency Band

Meaning: Indicates a frequency band. For details about this parameter, see 3GPP TS 38.104.

If the value of the NrDuCell.FrequencyBand parameter is equal to the value of this parameter, the configuration in this MO is applied.

GUI Value Range: N1(n1), N2(n2), N3(n3), N5(n5), N7(n7), N8(n8), N20(n20), N25(n25), N28(n28), N38(n38), N40(n40), N41(n41), N66(n66), N71(n71), N77(n77), N78(n78), N79(n79), N257(n257), N258(n258), N260(n260), N261(n261)

Unit: None

Actual Value Range: N1, N2, N3, N5, N7, N8, N20, N25, N28, N38, N40, N41, N66, N71, N77, N78, N79, N257, N258, N260, N261

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N
FrameOffset Frame Offset

Meaning: Indicates the offset of the start frame against a reference clock for all cells working in the given frequency band and their associated uplink and downlink decoupling cells.

If this parameter is set to a value in the range of 0 to 261120, frame transmission is started at a time later than the reference clock, with a deviation equal to the parameter value.

If this parameter is set to a value in the range of 275943 to 307200, frame transmission is started at a time earlier than the reference clock, with a deviation equal to 307200 minus the parameter value.

If this parameter is set to a value in the range of 0 to 261120 or 275943 to 307200, the frame offset of the cells working in the frequency band and their associated uplink and downlink decoupling cells is equal to the value of this parameter.

If this parameter is set to 4294967295, the frame offset of the cells working in the given frequency band and their associated uplink and downlink decoupling cells is equal to the value of the gNodeBParam.FrameOffset parameter.

GUI Value Range: 0~261120,275943~307200,4294967295

Unit: Ts

Actual Value Range: 0~261120,275943~307200,4294967295

MML Default Value: 4294967295

Recommended Value: 4294967295

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: In the case of intra-NR TDD systems or when NR TDD coexists with other TDD systems such as LTE TDD, WiMAX, TD-SCDMA, and PHS and the spectrum is close to each other, modifying the frame offset causes intra-RAT or inter-RAT unaligned uplink and downlink timeslots, which may cause severe interference. The access success rate and handover success rate decrease as a result.

If the frame offsets of different frequency bands differ, UEs need a longer measurement gap to include the SMTC of cells in different frequency bands, which reduces the throughput during inter-frequency and inter-RAT measurements. If the maximum difference between the frame offsets of different NR frequency bands is greater than 3 ms, the measurement gap is insufficient to include the SMTC of all cells. In this case, certain inter-frequency cells cannot be measured, affecting the handover success rate.

Applicable Mode: N

Example

To add a Add gNodeB Frequency Band Configuration with Frequency Band set to N3, run the following command:
ADD GNBFREQBANDCONFIG: FrequencyBand=N3;
