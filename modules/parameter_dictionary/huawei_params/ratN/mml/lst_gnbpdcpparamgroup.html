List gNodeB PDCP Parameter Group (LST GNBPDCPPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the PDCP parameter group configurations of the gNodeB.

Note

None.

Parameters

ID Name Description
PdcpParamGroupId PDCP Parameter Group ID

Meaning: Indicates the ID of a PDCP parameter group.

GUI Value Range: 0~159

Unit: None

Actual Value Range: 0~159

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the configuration of PDCP parameter groups for the gNodeB, run the following command:
LST GNBPDCPPARAMGROUP:;

Output Description

Field Description

PDCP Parameter Group ID

Indicates the ID of a PDCP parameter group.

Downlink PDCP Discard Timer(ms)

Indicates the length of the downlink PDCP discard timer of the gNodeB. If PDCP packets have been buffered for a period longer than the timer length, the gNodeB discards the packets. This timer is valid only for data transmitted on DRBs. For details, see 3GPP TS 38.323.

Uplink PDCP Discard Timer(ms)

Indicates the length of the uplink PDCP discard timer for UEs. If PDCP packets have been buffered for a period longer than the timer length, the gNodeB discards the packets. This timer is valid only for data transmitted on DRBs. For details, see 3GPP TS 38.323.

gNodeB PDCP Reordering Timer(ms)

Indicates the length of the gNodeB-specific timer for PDCP packet reordering. When this timer expires, the PDCP packets are reordered by PDCP sequence number and then transmitted to the upper layer. For details, see 3GPP TS 38.323.

UE PDCP Reordering Timer(ms)

Indicates the length of the UE-specific timer for PDCP packet reordering. When this timer expires, the PDCP packets are reordered by PDCP sequence number and then transmitted to the upper layer. For details, see 3GPP TS 38.323.

Downlink Data PDCP Split Mode

Indicates the downlink PDCP-layer data split mode. The value SCG_AND_MCG indicates that data is dynamically distributed to the eNodeB or gNodeB depending on the split algorithm. The value MCG_ONLY indicates that data is distributed only to the MCG (eNodeB). The value SCG_ONLY indicates that data is distributed only to the SCG (gNodeB). For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is distributed only to the SCG.

Downlink PDCP SN Size(bit)

Indicates the length of a downlink PDCP sequence number for the gNodeB and UE. For details, see 3GPP TS 38.323.

Uplink PDCP SN Size(bit)

Indicates the length of an uplink PDCP sequence number for the gNodeB and UE. For details, see 3GPP TS 38.323.

Uplink Data Split Primary Path

Indicates the primary path for uplink data split. The value MCG indicates master cell group (MCG), and the value SCG indicates secondary cell group (SCG). If this parameter is set to MCG, the primary path for uplink data split is MCG. If this parameter is set to SCG, the primary path for uplink data split is SCG. For details, see 3GPP TS 38.323. For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is split only to the secondary base station.

Uplink Data Split Threshold(byte)

Indicates the threshold of uplink data split for LTE-NR NSA DC UEs. If the PDCP buffer of a UE is higher than the threshold, data of the UE is distributed to both the master and secondary base stations. For details, see 3GPP TS 38.323 and 3GPP TS 38.331. For QCIs 2 to 4, QCIs 65 to 67, QCI 75, and QCIs 82 to 85, this parameter does not take effect, and data is distributed only to the secondary base station.

PDCP Report Polling Period(ms)

Indicates the period for the NR PDCP layer to initiate report polling to the LTE RLC layer in the Option 3x architecture.
