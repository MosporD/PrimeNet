Add gNodeB Acceleration Service Application Configuration (ADD GNBASAPP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB acceleration application.

Note

None.

Parameters

ID Name Description
AppId Application Index

Meaning: Indicates the index of the acceleration application.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
AppIdentificationType Application Identification Type

Meaning: Indicates the acceleration application identification type. If this parameter is set to IPV4, the AppIpv4 parameter must be set. If this parameter is set to IPV6, the AppIpv6 parameter must be set.

GUI Value Range: IPV4(IPv4 Address), IPV6(IPv6 Address)

Unit: None

Actual Value Range: IPV4, IPV6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
AppIpv4 Application IPv4

Meaning: Indicates an IPv4 address for acceleration application (acceleration service) identification. This parameter is used during identification based on an IP address and is mandatory when AppIdentType is set to IPV4.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
AppIpv6 Application IPv6

Meaning: Indicates an IPv6 address for acceleration application (acceleration service) identification. This parameter is used during identification based on an IP address and is mandatory when AppIdentType is set to IPV6.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
ProtocolType Protocol Type

Meaning: Indicates the protocol type for acceleration application identification. If this parameter is set to ALL, the gNodeB does not check the protocol type during acceleration application identification and applications of any protocol types are identified as acceleration applications. If this parameter is set to TCP, the gNodeB checks whether the protocol type is TCP during acceleration application identification. If this parameter is set to UDP, the gNodeB checks whether the protocol type is UDP during acceleration application identification.

GUI Value Range: ALL(Not Check Protocol Type), TCP(Check Whether Protocol Type Is TCP), UDP(Check Whether Protocol Type Is UDP)

Unit: None

Actual Value Range: ALL, TCP, UDP

MML Default Value: ALL(Not Check Protocol Type)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
PortNumber Port Number

Meaning: Indicates the server port number for acceleration application identification. This parameter is valid only when ProtocolType is set to TCP or UDP. The value 0 indicates that the gNodeB does not check the server port number.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add a gNodeB acceleration service application with Application Index set to 0, Application Identification Type set to IPV4, and Application IPv4 set to 10.141.125.234, run the following command:
ADD GNBASAPP: AppId=0, AppIdentificationType=IPV4, AppIpv4="10.141.125.234";
