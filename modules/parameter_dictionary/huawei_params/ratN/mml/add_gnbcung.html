Add gNodeB CU NG (ADD GNBCUNG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB CU NG object.

Note

  • Before adding the gNodeB CU NG object, ensure that the control-plane and user-plane endpoint groups to be used by this object have been added.

  • In independent operator mode, it is recommended that one gNodeB CU NG object be configured.

Parameters

ID Name Description
gNBCuNgId gNodeB CU NG ID

Meaning: Indicates the ID of a gNodeB CU NG object.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
CpEpGroupId Control Plane Endpoint Group ID

Meaning: Indicates the ID of the control-plane endpoint group used by a gNodeB CU NG object. The value 4294967295 is invalid.

GUI Value Range: 0~65535,4294967295

Unit: None

Actual Value Range: 0~65535,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Either CpEpGroupId or UpEpGroupId in a gNBCUNg MO must be configured.
  • In a gNBCUNg MO, if CuNgType is set to DEFAULT_CP, CpEpGroupId cannot be set to 4294967295.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UpEpGroupId User Plane Endpoint Group ID

Meaning: Indicates the ID of the user-plane endpoint group used by a gNodeB CU NG object. The value 4294967295 is invalid.

GUI Value Range: 0~65535,4294967295

Unit: None

Actual Value Range: 0~65535,4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Either CpEpGroupId or UpEpGroupId in a gNBCUNg MO must be configured.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UserLabel User Label

Meaning: Indicates the user label of a gNodeB CU NG object.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
CuNgType CU NG Type

Meaning: Indicates the configuration type of the control-plane endpoint used by a gNodeB CU NG object. If this parameter is set to DEFAULT_CP, message transmission over the NG interface will be based on the default control plane that corresponds to this parameter when an RRC connection setup message does not contain slice information or a Temp ID during initial access initiated by a UE. If an operator has multiple default control plane settings, load sharing is applied in message transmission over the NG interface. If this parameter is set to NORMAL, load sharing is applied in message transmission over the NG interface when an RRC connection setup message does not contain slice information or a Temp ID during initial access initiated by a UE.

GUI Value Range: NORMAL, DEFAULT_CP

Unit: None

Actual Value Range: NORMAL, DEFAULT_CP

MML Default Value: NORMAL

Recommended Value: NORMAL(Normal)

Parameter Relationship:

-Configuration constraints:

  • In a gNBCUNg MO, if CuNgType is set to DEFAULT_CP, CpEpGroupId cannot be set to 4294967295.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add the gNodeB CU NG object with the parameters as follows: gNodeB CU NG ID set to 0, Control Plane Endpoint Group ID set to 1, User Plane Endpoint Group ID set to 1, User Label set to "huawei", run the following command:
ADD GNBCUNG: gNBCuNgId=0, CpEpGroupId=1, UpEpGroupId=1, UserLabel="huawei";
