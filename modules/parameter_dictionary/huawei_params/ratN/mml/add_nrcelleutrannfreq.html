Add Neighboring E-UTRAN Frequency of NR Cell (ADD NRCELLEUTRANNFREQ)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add an inter-RAT neighboring E-UTRAN frequency.

Note

None.

Meaning: Indicates the RX level threshold for reselecting to a cell on a high-priority E-UTRAN frequency. EutranFreqReselPriority E-UTRAN Frequency Resel Priority

Meaning: Indicates the cell reselection priority of an E-UTRAN frequency. The value 0 indicates the lowest priority. The value 255 indicates that no reselection priority is configured for the E-UTRAN frequency. For how UEs process the reselection priority of frequencies, see 3GPP TS 38.304.

A UE calculates the sum of this parameter and the cell reselection sub-priority of an E-UTRAN frequency (specified by NRCellEutranNFreq.EutranFreqReselSubPriority) and compares the sum with the cell reselection priority of the serving cell (specified by NRCellReselConfig.CellReselPriority). The target frequency for cell reselection is determined based on the result.

If the sum is greater than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring E-UTRAN frequency. If the signal quality of a cell on the neighboring E-UTRAN frequency meets requirements throughout the time specified by NRCellReselConfig.EutranCellReselTimer, the UE starts reselection to that cell. If the sum is smaller than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring frequency only when the signal quality of the serving cell is poor. When the signal quality of the serving cell is lower than the threshold specified by NRCellReselConfig.ServFreqLowPriRsrpReselThd throughout the time defined by the E-UTRAN cell reselection timer, the signal quality of a cell on the neighboring frequency is higher than the threshold specified by NRCellEutranNFreq.EutranFreqLowPriReselThld, and the UE has camped on the serving cell for more than 1s, the UE starts cell reselection. The sum of reselection priorities and that of reselection sub-priorities must be different between RATs. For details, see 3GPP TS 38.331.

VoltePriority VoLTE Priority

Meaning: Indicates the priority of a neighboring E-UTRAN frequency for carrying VoLTE services. If this parameter is set to 255 for a neighboring E-UTRAN frequency, the frequency does not support VoLTE during EPS fallback, emergency call fallback, and VoNR-to-VoLTE switching. If this parameter is set to a value in the range of 0 to 16, a larger value indicates a higher priority. The base station selects frequencies to be measured based on this priority and UEs preferentially select the frequency with a high priority for measurement. If this parameter is set to 0, the frequency is not selected as the target frequency for EPS fallback through blind redirection and VoNR-to-VoLTE switching through blind redirection.

GUI Value Range: 0~16,255

Unit: None

Actual Value Range: 0~16,255

MML Default Value: 1

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a value in the range of 0 to 16, a smaller value indicates a lower priority. A larger value indicates a higher priority. A lower priority indicates a lower probability that voice-service UEs are handed over to this frequency during EPS fallback, emergency call fallback, or VoNR-to-VoLTE switching. If this parameter is set to a smaller value for a frequency with worse coverage, UEs are less likely to be handed over to this frequency, avoiding voice service quality deterioration. A higher priority results in the opposite effects. If this parameter is set to a large value for a frequency with favorable coverage, the number of handovers decreases, improving voice service quality.

Applicable Mode: N
AggregationAttribute Aggregation Attribute

Meaning: Indicates the aggregation attributes of a neighboring E-UTRAN frequency.

SEPARATED_FREQ_SPEC_SHR_FLAG: Indicates whether a neighboring E-UTRAN frequency is a secondary operator's frequency in RAN sharing with special dedicated carrier mode. If this option is selected, the neighboring E-UTRAN frequency is a secondary operator's frequency in RAN sharing with special dedicated carrier mode. If this option is deselected, the neighboring E-UTRAN frequency is not a secondary operator's frequency in RAN sharing with special dedicated carrier mode. This option applies only to two-operator sharing with special dedicated carrier, not to two-operator sharing with common carrier.

Example

To add neighboring E-UTRAN frequencies for the NR cell with the parameters as follows: NR Cell ID: 2, Downlink EARFCN: 5000, E-UTRAN Freq High Priority Resel Threshold: 8, E-UTRAN Freq Low Priority Resel Threshold: 8, E-UTRAN Frequency Resel Priority: 2, Frequency-specific Offset: 1DB, Measurement Bandwidth: 3M, Minimum RX Level: –32, Frequency Priority for Connected Mode: 2, VoLTE Priority: 2, run the following command:
ADD NRCELLEUTRANNFREQ: NrCellId=2, DlEarfcn=5000, EutranFreqHighPriReselThld=8, EutranFreqLowPriReselThld=8, EutranFreqReselPriority=2, FreqSpecificOffset=DB1, MeasurementBandwidth=MBW15, MinimumRxLevel=-32, ConnFreqPriority=2, VoltePriority=2;
