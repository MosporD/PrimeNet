List NR External gNodeB (LST NREXTERNALGNB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configurations of an NR external gNodeB.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Output Description

Field Description

Mobile Country Code

Indicates the MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

Mobile Network Code

Indicates the MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.

gNodeB ID

Indicates the gNodeB ID of an external NR cell. It uniquely identifies a gNodeB within a PLMN. The NR Cell Identity (NCI) is comprised of the cell ID and the gNodeB ID. The gNodeB ID is represented by the most significant 22 to 32 bits of the NCI. The NR cell global identifier (NCGI) is comprised of the NCI and the PLMN ID. For details, see 3GPP TS 38.413.

PLMN Policy

Indicates the policy of configuring the PLMN in the Global gNB ID of a neighboring gNodeB for an operator. If this parameter is set to PRIMARY_PLMN_PREFER, the primary-operator PLMN of the gNodeB is specified in the Global gNB ID for the given operator. If this parameter is set to SELECTED_PLMN_PREFER, the given operator's PLMN is specified in the Global gNB ID for the given operator.
