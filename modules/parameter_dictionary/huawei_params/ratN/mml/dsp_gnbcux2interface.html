Display gNodeB CU X2 Interface (DSP GNBCUX2INTERFACE)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the status of gNodeB CU X2 interfaces and the information of peer eNodeBs. If the status of an X2 interface is abnormal, the command output displays the information of the peer eNodeB in the last normal connection with the local gNodeB.

Note

None.

Parameters

ID Name Description
gNBCuX2InterfaceId gNodeB CU X2 Interface ID

Meaning: Indicates the ID of a gNodeB CU X2 interface.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N
QueryType Query Type

Meaning: Indicates the state of gNodeB CU X2 interfaces to be queried. If this parameter is unspecified, the command output displays the information of all X2 interfaces regardless of their states. If gNBCuX2InterfaceId is specified, this QueryType parameter does not take effect.

GUI Value Range: FAULT_TYPE(Faulty Type), NORMAL_TYPE(Normal Type)

Unit: None

Actual Value Range: FAULT_TYPE, NORMAL_TYPE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N

To query the status and other information of gNodeB CU X2 interfaces, run the following command:
DSP GNBCUX2INTERFACE:;

Output Description

Field Description

gNodeB CU X2 Interface ID

Indicates the ID of a gNodeB CU X2 interface.

gNodeB CU X2 CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU X2 interface.

Operator ID

Indicates the ID of the home operator configured at the local end of the gNodeB CU X2 interface.

gNodeB CU X2 CP Bearer State

Indicates the state of the bottom-layer CP bearer of a gNodeB CU X2 interface.

Neighboring eNodeB ID

Indicates the ID of the neighboring eNodeB on the peer end of a gNodeB CU X2 interface. The combination of this parameter and NeighboringEnodebPlmnId uniquely identifies the neighboring eNodeB around the globe.

Neighboring eNodeB PLMN ID

Indicates the PLMN ID of the neighboring eNodeB on the peer end of a gNodeB CU X2 interface.

gNodeB CU X2 Interface State

Indicates the state of a gNodeB CU X2 interface.

Reason for Abnormal State

Indicates the reason why a gNodeB CU X2 interface is abnormal.

Last Fault Occur Time

Indicates the time when the last gNodeB CU X2 interface fault occurred. The time format is YEAR-MONTH-DAY HH:MM:SS. For example, 2018-1-1 10:20:05 indicates 10:20:05 on January 1, 2018.

gNodeB CU X2 Control Plane Host IP

Indicates the local IP address of the control plane of the gNodeB CU X2 interface.

gNodeB CU X2 Control Plane Peer IP

Indicates the peer IP address of the control plane of the gNodeB CU X2 interface.

gNodeB CU X2 User Plane Host IP

Indicates the local IP address of the user plane of the gNodeB CU X2 interface.

When multiple paths are configured on the user plane of an X2 interface, only one user-plane path can be displayed in the DSP GNBCUX2INTERFACE command output. The DSP GNBCUX2UPINFO command can be executed to display multiple user-plane paths.

gNodeB CU X2 User Plane Peer IP

Indicates the peer IP address of the user plane of the gNodeB CU X2 interface.

When multiple paths are configured on the user plane of an X2 interface, only one user-plane path can be displayed in the DSP GNBCUX2INTERFACE command output. The DSP GNBCUX2UPINFO command can be executed to display multiple user-plane paths.

gNodeB CU X2 User Plane Two-Way Delay(0.1microsecond)

Indicates the two-way delay of the user plane of the gNodeB CU X2 interface.

gNodeB CU X2 User Plane One-Way Delay(0.1microsecond)

Indicates the one-way delay of the user plane of the gNodeB CU X2 interface.
