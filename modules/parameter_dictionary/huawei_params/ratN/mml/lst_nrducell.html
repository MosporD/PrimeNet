List NR DU Cell (LST NRDUCELL)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the configuration of NR DU Cells.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the static attributes of an NR DU cell with NR DU Cell ID set to 88, run the following command:
LST NRDUCELL: NrDuCellId=88;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

NR DU Cell Name

Indicates the name of an NR DU cell.

Duplex Mode

Indicates the duplex mode of an NR DU cell. The value CELL_FDD indicates the FDD mode, the value CELL_TDD indicates the TDD mode, and the value CELL_SUL indicates the SUL mode.

Cell ID

Indicates the ID of an NR cell. This cell ID and the gNodeB ID compose the 3GPP-defined NR cell ID. The 3GPP-defined NR cell ID and the PLMN ID compose the NR CGI. For details, see 3GPP TS 38.413.

Physical Cell ID

Indicates the physical cell ID. For details, see 3GPP TS 38.331.

Frequency Band

Indicates the frequency band in which an NR DU cell operates. For details, see 3GPP TS 38.104.

Uplink NARFCN

Indicates the uplink NARFCN of an NR DU cell. The value 0 indicates that the uplink NARFCN is not configured. This parameter is optional when DuplexMode is set to CELL_FDD or CELL_TDD. This parameter is mandatory when DuplexMode is set to CELL_SUL. If DuplexMode is set to CELL_FDD and the uplink NARFCN is not configured, the system calculates the uplink NARFCN based on the default uplink and downlink frequency TX/RX intervals and downlink NARFCN and automatically updates the uplink NARFCN. When DuplexMode is set to CELL_TDD and the uplink NARFCN is not configured, the uplink NARFCN is equal to the downlink NARFCN, and the uplink NARFCN is automatically updated. For details, see 3GPP TS 38.104.

Downlink NARFCN

Indicates the downlink NARFCN of an NR DU cell. For details, see 3GPP TS 38.104.

Uplink Bandwidth

Indicates the uplink bandwidth of an NR DU cell. For details about this parameter, see 3GPP TS 38.104.

Downlink Bandwidth

Indicates the downlink bandwidth of an NR DU cell. For details, see 3GPP TS 38.104.

Cell Radius(m)

Indicates the radius of an NR DU cell, which is the farthest distance that the cell can cover under the condition of keeping certain network performance.

Subcarrier Spacing(KHz)

Indicates the subcarrier spacing. For details about this parameter, see 3GPP TS 38.331.

The default value is 15KHZ for FDD and 30KHZ for TDD.

Cyclic Prefix Length

Indicates the cyclic prefix length of an NR DU cell. A cyclic prefix can be a normal or extended cyclic prefix. An extended cyclic prefix is used in complex environment, for example, with strong multipath effect or long delay. For details, see 3GPP TS 38.211. The current version supports only the normal cyclic prefix.

Slot Assignment

Indicates the slot assignment. This parameter applies only to TDD.

The value 4_1_DDDSU indicates that the ratio of downlink timeslots to uplink timeslots is 4:1.

The value 8_2_DDDDDDDSUU indicates that the ratio of downlink timeslots to uplink timeslots is single-period 8:2.

The value 7_3_DDDSUDDSUU indicates that the ratio of downlink timeslots to uplink timeslots is dual-period 7:3.

The value 8_2_DDDSUUDDDD indicates that the ratio of downlink timeslots to uplink timeslots is dual-period 8:2.

The value 2_3_DSUUU indicates that the ratio of downlink timeslots to uplink timeslots is 2:3.

RAN Notification Area ID

Indicates the RAN notification area ID of a cell. This parameter is used for UEs in the RRC_INACTIVE state. This parameter is invalid when being set to 65535.

LampSite Cell Flag

Indicates the LampSite cell flag. If this parameter is set to YES, the cell is a LampSite cell and works with LampSite-specific RF modules. If this parameter is set to NO, the cell is a macro cell and works with RF modules of macro base stations.

Tracking Area ID

Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This parameter is different from the TAI configured in the CN TAL.

TA Offset

Indicates the TA offset, which is used to set the offset of the TA value used by the UE to send uplink data relative to the TA value measured by the gNodeB. The value for FDD NR FR1 can be 25600TC or 0TC and the value for TDD NR FR1 can be 39936TC or 25600TC. For details about the parameter, see 3GPP TS 38.133.

Cell Administration State

Indicates the administrative state of a cell. The setting of this parameter affects the working state of the cell. If this parameter is set to CELL_HIGH_BLOCK, CELL_MID_BLOCK, or CELL_LOW_BLOCK, new UEs are not allowed to access the cell. If there is no RRC_CONNECTED UE in the cell, the cell is deactivated immediately. If the cell is serving RRC_CONNECTED UEs, the base station checks the number of RRC_CONNECTED UEs in the cell every 5s. If the number becomes 0, the base station immediately deactivates the cell. If this parameter is set to CELL_HIGH_BLOCK, UEs need to be transferred out of the cell within 10 seconds. The cell is forcibly deactivated after 10 seconds even if there are still UEs in the cell. If this parameter is set to CELL_MID_BLOCK, UEs need to be transferred out of the cell within 60 seconds. The cell is forcibly deactivated after 60 seconds even if there are still UEs in the cell. If this parameter is set to CELL_LOW_BLOCK, the cell is deactivated only when there is no RRC_CONNECTED UE in the cell.

SSB Frequency Position Describe Method

Indicates the description method of the SSB frequency domain position of a cell.

SSB Frequency Position

Indicates the frequency domain location of the cell SSB. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN(Global Synchronization Channel Number), this parameter indicates the global synchronization channel number corresponding to the cell SSB. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN(Absolute Frequency), this parameter indicates the absolute frequency number corresponding to the cell SSB.

SSB Period(ms)

Indicates the SSB period. For details about this parameter, see 3GPP TS 38.331.

SIB1 Period(ms)

Indicates the SIB1 transmission period.

NR DU Cell Networking Mode

Indicates the networking mode of an NR DU cell. The value NORMAL_CELL indicates that the cell is a common cell, the value HYPER_CELL indicates that the cell is a hyper cell, and the value HYPER_CELL_COMBINE_MODE indicates that the cell is a combined cell. This parameter applies only to low-frequency TDD cells.

SIB Config ID

Indicates the ID of a set of system information configuration, including the system information type, system information transmission period, and system information transmission mode.

Logical Root Sequence Index

Indicates the index of the start logical root sequence used to generate the cell preamble sequence. Each logical root sequence maps one physical root sequence. For details, see 3GPP TS 38.211.

PRACH Frequency Start Position

Indicates the starting frequency-domain position of PRACH resources relative to the initial BWP. For details, see 3GPP TS 38.321.The values 0 to 272 indicate that the starting frequency-domain position of PRACH equals the parameter value. The value 65535 indicates that the starting frequency-domain position of PRACH is automatically generated. This parameter does not take effect when LTE FDD and NR Uplink Spectrum Sharing is enabled on both the LTE and NR sides and the uplink spectrum sharing mode is set to dynamic sharing or when LTE FDD and NR Flash Dynamic Spectrum Sharing is enabled.

High Speed Flag

Indicates the speed flag of a cell. Set this parameter to HIGH_SPEED if the cell is used to provide coverage for a high-speed railway. Set this parameter to LOW_SPEED in other scenarios.

Supplementary Cell Indicator

Indicates whether a high-frequency cell is a supplementary cell for CA.

The value NORMAL_CELL indicates a common cell.

The value SUPPLEMENTARY_CELL indicates a supplementary cell, which can serve only as an SCell for CA.

A maximum of four NR DU cells of the NORMAL_CELL type and a maximum of four NR DU cells of the SUPPLEMENTARY_CELL type can be configured under the same sector.

For an NR DU cell in eCPRI 8T8R or CPRI 4T4R mode, this parameter must be set to NORMAL_CELL.

This parameter applies only to high-frequency cells.

SMTC Duration(ms)

Indicates the intra-frequency SMTC duration for an NR cell. For details, see 3GPP TS 38.331. This parameter applies only to low-frequency TDD and FDD cells.

SMTC Period(ms)

Indicates the intra-frequency SMTC measurement period for an NR cell. For details, see 3GPP TS 38.331.

Additional Frequency Band

Indicates the additional frequency band of a cell. If this parameter is set to NULL, no additional frequency band is configured. For details, see 3GPP TS 38.104.

SSB Subcarrier Spacing(KHz)

Indicates the SSB subcarrier spacing. For details about this parameter, see 3GPP TS 38.331.
