Modify NR DU Cell PUCCH (MOD NRDUCELLPUCCH)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the PUCCH configuration of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
StructureType Structure Type

Meaning: Indicates the PUCCH format. For high-frequency TDD cells, this parameter is always set to a value indicating short format. For FDD and SUL cells, this parameter is always set to a value indicating long format.

GUI Value Range: LONG_STRUCTURE(Long Structure), SHORT_STRUCTURE(Short Structure)

Unit: None

Actual Value Range: LONG_STRUCTURE, SHORT_STRUCTURE

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

High-frequency TDD cells: SHORT_STRUCTURE(Short Structure); other scenarios: LONG_STRUCTURE(Long Structure)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to LONG_STRUCTURE, the PUCCH resource overhead is high, uplink cell throughput decreases, but cell edge coverage performance is good. Setting this parameter to SHORT_STRUCTURE leads to the opposite effects.

Applicable Mode: N
Format3RbNum Format3 RB Number

Meaning: Indicates the number of PUCCH format-3 RBs. They are used to transmit HARQ-ACKs whose size is greater than two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to low-frequency TDD cells, FDD cells with the INTRA_FR_INTER_BAND_CA_SW option selected, and SUL cells not enabled with LTE and NR sharing.

GUI Value Range: RB2(2), RB4(4), RB6(6), RB8(8), RB10(10), RB12(12), RB14(14), RB16(16), RB18(18), RB20(20), RB22(22), RB24(24)

Unit: RB

Actual Value Range: RB2, RB4, RB6, RB8, RB10, RB12, RB14, RB16, RB18, RB20, RB22, RB24

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows: In FDD mode: RB4(4); other scenarios: RB14(14).

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller number of PUCCH RBs in a timeslot, fewer UEs that can be scheduled in the downlink in a timeslot, and higher uplink throughput. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Meaning: Indicates the number of PUCCH format-1 RBs. It is used to transmit SRs and HARQ-ACK whose size is less than or equal to two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to SUL cells not enabled with LTE and NR sharing, low-frequency TDD cells, and FDD cells.

GUI Value Range: RB2(2), RB4(4), RB6(6), RB8(8), RB10(10)

Unit: RB

Actual Value Range: RB2, RB4, RB6, RB8, RB10

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows: In FDD mode: RB2(2); other scenarios: RB4(4).

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a smaller number of PUCCH RBs in a timeslot, fewer UEs that can be scheduled in the downlink in a timeslot, and higher uplink throughput. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
ShortPucchSymbolNum Short PUCCH Symbol Number

Meaning: Indicates the number of symbols used for short PUCCH in a cell. This parameter takes effect only for high-frequency cells with a short PUCCH format and with the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter deselected.

GUI Value Range: SYMBOL1(1 Symbol), SYMBOL2(2 Symbols), SYMBOL3(3 Symbols), SYMBOL4(4 Symbols), SYMBOL5(5 Symbols), SYMBOL6(6 Symbols), SYMBOL7(7 Symbols)

Unit: None

Actual Value Range: SYMBOL1, SYMBOL2, SYMBOL3, SYMBOL4, SYMBOL5, SYMBOL6, SYMBOL7

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

When FrequencyBand is set to N257, N258, N260, or N261 and DuplexMode is set to CELL_TDD: SYMBOL5

Other scenarios: SYMBOL1

Parameter Relationship:

-Configuration constraints:

  • UserShortPucchSymbolNum in the NRDUCellPucch MO can be set to ADAPTIVE only when ShortPucchSymbolNum in the NRDUCellPucch MO is set to SYMBOL4, SYMBOL5, SYMBOL6, or SYMBOL7 and the PUCCH_RES_ADAPTIVE_SWITCH option of PucchAlgoSwitch in the NRDUCellPucch MO is deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in a lower PUCCH overhead and better uplink performance. A larger value of this parameter leads to the opposite effects.

Applicable Mode: N-TDD
SrPeriod SR Period

Meaning: Indicates the period of sending SRs. The period range differs depending on cell mode or subcarrier spacing. For details, see 3GPP TS 38.331. This parameter takes effect only for UEs that newly access the network. Specifically, for TDM UEs in SUL cells, SRs are received only in uplink timeslots available for NR. This parameter does not take effect if SR period adaptation is enabled.

GUI Value Range: SLOT1(1), SLOT2(2), SLOT4(4), SLOT5(5), SLOT8(8), SLOT10(10), SLOT16(16), SLOT20(20), SLOT40(40), SLOT80(80), SLOT160(160), SLOT320(320), SLOT640(640)

Unit: slot

Actual Value Range: SLOT1, SLOT2, SLOT4, SLOT5, SLOT8, SLOT10, SLOT16, SLOT20, SLOT40, SLOT80, SLOT160, SLOT320, SLOT640

MML Default Value: None

Recommended Value: SLOT40(40)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A smaller value of this parameter indicates a smaller delay. A larger value of this parameter indicates more number of RRC_CONNECTED UEs.

Applicable Mode: N
CsiDedicatedRbNum Format3 CSI-dedicated RB Number

Meaning: Indicates the number of RBs reserved for format-3 periodic CSI. This parameter takes effect only when the PUCCH format is long and the PUCCH_RBRES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to SUL cells not enabled with LTE and NR sharing, low-frequency TDD cells, and FDD cells.

GUI Value Range: RB0(0), RB2(2), RB4(4), RB6(6), RB8(8), RB10(10)

Unit: RB

Actual Value Range: RB0, RB2, RB4, RB6, RB8, RB10

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

RB4 for FDD scenarios

RB2 for other scenarios

Parameter Relationship:

-Configuration constraints:

  • In an NRDUCellPucch MO, the sum of CsiDedicatedRbNum and Format4CsiDedicatedRbNum cannot exceed 10.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter results in fewer UEs that can be configured with periodic format-3 CSI resources in a cell but higher uplink throughput performance. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
PucchAlgoSwitch PUCCH Algorithm Switch

Meaning: Indicates the PUCCH adaptation algorithm switch. It determines whether to enable PUCCH resource adjustment.

PUCCH_RES_ADAPTIVE_SWITCH: Indicates whether to enable symbol number resource adjustment for short PUCCH. If this option is selected, the gNodeB automatically adjusts symbols of short PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, symbols of short PUCCH are consumed based on the GUI value. This option applies only to high-frequency TDD cells.

PUCCH_RBRES_ADAPTIVE_SWITCH: Indicates whether to enable RB resource adjustment for long PUCCH. If this option is selected, the gNodeB automatically adjusts RBs of long PUCCH in the case of insufficient PUCCH resources or many idle PUCCH resources. If this option is deselected, RBs of long PUCCH are consumed based on the GUI value. This option applies only to FDD and SUL cells not enabled with LTE and NR sharing and TDD cells with NRDUCell.HighSpeedFlag set to LOW_SPEED.

GUI Value Range: PUCCH_RES_ADAPTIVE_SWITCH(PUCCH Adaptation Switch), PUCCH_RBRES_ADAPTIVE_SWITCH(PUCCH RB Adaptation Switch)

Unit: None

Actual Value Range: PUCCH_RES_ADAPTIVE_SWITCH, PUCCH_RBRES_ADAPTIVE_SWITCH

MML Default Value: None

Recommended Value: PUCCH_RES_ADAPTIVE_SWITCH:On

The PUCCH_RBRES_ADAPTIVE_SWITCH option can be set by the system by default. The default value is as follows:

Low-speed scenarios for low-frequency TDD cells with long PUCCH format or FDD and SUL cells: PUCCH_RBRES_ADAPTIVE_SWITCH:On

Other scenarios: PUCCH_RBRES_ADAPTIVE_SWITCH:Off

Parameter Relationship:

-Configuration constraints:

  • UserShortPucchSymbolNum in the NRDUCellPucch MO can be set to ADAPTIVE only when ShortPucchSymbolNum in the NRDUCellPucch MO is set to SYMBOL4, SYMBOL5, SYMBOL6, or SYMBOL7 and the PUCCH_RES_ADAPTIVE_SWITCH option of PucchAlgoSwitch in the NRDUCellPucch MO is deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: PUCCH_RES_ADAPTIVE_SWITCH: If the PUCCH_RES_ADAPTIVE_SWITCH option is selected, the base station adaptively increases or decreases the number of PUCCH symbols based on the PUCCH resource load. This improves PUCCH resource utilization and reduces uplink control signaling overheads. If a small number of UEs access the network, the number of used PUCCH resources decreases, and the uplink throughput increases. If a large number of UEs access the network, the number of used PUCCH resources increases, and the uplink throughput decreases. If this option is deselected, this function does not take effect and network performance is not affected.

PUCCH_RBRES_ADAPTIVE_SWITCH: If the PUCCH_RBRES_ADAPTIVE_SWITCH option is selected, the base station adaptively increases or decreases the number of PUCCH RBs based on the PUCCH resource load. This improves PUCCH resource utilization and reduces uplink control signaling overheads. If a small number of UEs access the network, fewer PUCCH resources are used and the uplink throughput improves. If a large number of UEs access the network, more PUCCH resources are used and the uplink throughput deteriorates. If this option is deselected, the algorithm does not take effect and network performance is not affected.

Applicable Mode: N
SrResoureAlgoSwitch SR Resource Algo Switch

Meaning: Indicates the SR resource algorithm switch. It determines whether to enable SR resource adjustment. SR_PERIOD_ADAPT_SWITCH: Indicates whether to enable SR period adaptation. If this option is selected, SR period adjustment is enabled. If this option is deselected, the SR period is the value of the NRDUCellPucch.SrPeriod parameter.

GUI Value Range: SR_PERIOD_ADAPT_SWITCH(SR Period Adaptation Switch)

Unit: None

Actual Value Range: SR_PERIOD_ADAPT_SWITCH

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Low-speed scenarios: SR_PERIOD_ADAPT_SWITCH:On

Other scenarios: SR_PERIOD_ADAPT_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: SR_PERIOD_ADAPT_SWITCH: If this option is selected, the gNodeB adaptively adjusts the SR period based on the number of RRC_CONNECTED UEs. The maximum number of RRC_CONNECTED UEs is supported. During the reconfiguration, a small number of UEs experience RRC connection reconfiguration. If this option is deselected, network performance is not affected.

Applicable Mode: N
Format4RbNum Format4 RB Number

Meaning: Indicates the number of PUCCH format-4 RBs. It is used to transmit HARQ-ACKs whose size is greater than two bits. This parameter takes effect only when the PUCCH format is long and the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to low-frequency TDD cells, FDD cells with the INTRA_FR_INTER_BAND_CA_SW option selected, and SUL cells not enabled with LTE and NR sharing.

GUI Value Range: RB0(0), RB2(2), RB4(4), RB6(6), RB8(8)

Unit: RB

MML Default Value: None

Service Interrupted After Modification: Yes

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
CsiReportPeriod CSI Report Period

Meaning: Indicates the CSI reporting interval.This parameter is valid only when the CSI_REPORT_PERIOD_ADAPT_SWITCH option of the CsiResoureAlgoSwitch parameter is deselected. For TDD and FDD cells, the value of this parameter or the value of NRDUCellCsirs.CsiPeriod is used as the CSI reporting interval, whichever is larger. For SUL cells, the value of this parameter or the value of NRDUCellCsirs.CsiPeriod divided by two is used as the CSI reporting interval, whichever is larger.

This parameter applies only to low-frequency cells.

GUI Value Range: SLOT10(10), SLOT20(20), SLOT40(40), SLOT80(80), SLOT160(160), SLOT320(320)

Unit: slot

Actual Value Range: SLOT10, SLOT20, SLOT40, SLOT80, SLOT160, SLOT320

MML Default Value: None

Recommended Value: SLOT80(80)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter results in more frequent CSI reporting, higher downlink throughput, less supported UEs, and more RBs required for PUCCH. A larger value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
UserShortPucchSymbolNum User Short PUCCH Symbol Number

Meaning: Indicates the number of PUCCH format-2 symbols. This parameter can be set to ADAPTIVE only when the value of ShortPucchSymbolNum is greater than or equal to SYMBOL4 and the PUCCH_RES_ADAPTIVE_SWITCH option of the PucchAlgoSwitch parameter is deselected. This parameter applies only to high-frequency TDD cells.

GUI Value Range: SYMBOL1(1 Symbol), ADAPTIVE(Adaptive)

Unit: None

Actual Value Range: SYMBOL1, ADAPTIVE

MML Default Value: None

Recommended Value: SYMBOL1(1 Symbol)

Parameter Relationship:

-Configuration constraints:

  • UserShortPucchSymbolNum in the NRDUCellPucch MO can be set to ADAPTIVE only when ShortPucchSymbolNum in the NRDUCellPucch MO is set to SYMBOL4, SYMBOL5, SYMBOL6, or SYMBOL7 and the PUCCH_RES_ADAPTIVE_SWITCH option of PucchAlgoSwitch in the NRDUCellPucch MO is deselected.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to SYMBOL1, format-2 PUCCH transmits data using one symbol. In this case, the number of UEs that can be scheduled simultaneously in the downlink increases but the PUCCH coverage decreases. If this parameter is set to ADAPTIVE, the gNodeB adaptively selects the number of symbols for data transmission on the PUCCH based on the coverage size.

Applicable Mode: N-TDD-FR2
CsiResoureAlgoSwitch CSI Resource Algo Switch

Meaning: Indicates the CSI resource algorithm switches.

CSI_REPORT_PERIOD_ADAPT_SWITCH: Indicates whether to enable CSI reporting period adaptation. If this option is selected, CSI reporting period adjustment is initiated. If this option is deselected, the CSI reporting period is the value of the NRDUCellPucch.CsiReportPeriod parameter. This option applies only to low-frequency cells.

GUI Value Range: CSI_REPORT_PERIOD_ADAPT_SWITCH(CSI Reporting Period Adaptation Switch)

Unit: None

Actual Value Range: CSI_REPORT_PERIOD_ADAPT_SWITCH

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Low-frequency and low-speed cells: CSI_REPORT_PERIOD_ADAPT_SWITCH:On

Other scenarios: CSI_REPORT_PERIOD_ADAPT_SWITCH:Off

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: CSI_REPORT_PERIOD_ADAPT_SWITCH: When this option is selected, the CSI reporting period is adaptively adjusted based on the number of RRC_CONNECTED UEs. The maximum number of UEs can be reported in periodic CSI reporting. During the adjustment, RRC connection reconfiguration occurs for a small number of UEs. When this option is deselected, the maximum number of UEs that can report periodic CSIs is determined based on the CSI reporting period specified by the NRDUCellPucch.CsiReportPeriod parameter.

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL

Example

To modify the PUCCH configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 0, Format3 RB Number: 8, run the following command:
MOD NRDUCELLPUCCH: NrDuCellId=0, Format3RbNum=RB8;
