Add LTE and NR Spectrum Sharing Cell Set (ADD GNBDULTENRSPCTSHRCG)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add an LTE and NR spectrum sharing cell group and bind the LTE and NR spectrum sharing cell group.

Note

None.

Parameters

ID Name Description
NrSpctShrCellGrpId NR Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an NR spectrum sharing cell group, which uniquely identifies the NR spectrum sharing cell group within a gNodeB.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • LteSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.
  • NrSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
LteSpctShrCellGrpId LTE Spectrum Sharing Cell Group ID

Meaning: Indicates the ID of an LTE spectrum sharing cell group, which uniquely identifies the LTE spectrum sharing cell group within a gNodeB.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • LteSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.
  • NrSpctShrCellGrpId in each gNBDULteNrSpctShrCg MO must be unique.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1, N-FDD, N-SUL
LteNrUlSpectrumShrMode LTE and NR Uplink Spectrum Sharing Mode

Meaning: Indicates the mode of uplink spectrum sharing between LTE FDD and NR. This parameter applies only to NR SUL. Disuse statement: This parameter will be deleted in later versions. In this version, configuration synchronization and delivery of this parameter are still supported on interfaces. Therefore, avoid using this parameter.

GUI Value Range: STATIC_SHARING(Static Sharing), DYNAMIC_SHARING(Dynamic Sharing)

Unit: None

Actual Value Range: STATIC_SHARING, DYNAMIC_SHARING

MML Default Value: DYNAMIC_SHARING(Dynamic Sharing)

Recommended Value: DYNAMIC_SHARING(Dynamic Sharing)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to STATIC_SHARING, the total throughput of LTE and NR spectrum sharing cells is not affected. If this parameter is set to DYNAMIC_SHARING, the total throughput of LTE and NR spectrum sharing cells increases.

Applicable Mode: N-SUL
NrReservedRbStartIndex NR Reserved RB Start Index

Meaning: Indicates the index of the start RB among the RBs reserved for NR when LTE TDD and NR spectrum sharing is enabled. This parameter, together with NrReservedRbEndIndex, specify the range of RBs reserved for NR. If the range of RBs reserved for NR exceeds the range of RBs corresponding to the NR cell bandwidth, the range of RBs corresponding to the NR cell bandwidth is reserved for NR. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 0~272

Unit: None

Actual Value Range: 0~272

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • NrReservedRbStartIndex in the gNBDULteNrSpctShrCg MO must be smaller than NrReservedRbEndIndex in the gNBDULteNrSpctShrCg MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1
NrReservedRbEndIndex NR Reserved RB End Index

Meaning: Indicates the index of the end RB among the RBs reserved for NR when LTE TDD and NR spectrum sharing is enabled. This parameter, together with NrReservedRbStartIndex, specify the range of RBs reserved for NR. If the range of RBs reserved for NR exceeds the range of RBs corresponding to the NR cell bandwidth, the range of RBs corresponding to the NR cell bandwidth is reserved for NR. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 0~272

Unit: None

Actual Value Range: 0~272

MML Default Value: 163

Recommended Value: 163

Parameter Relationship:

-Configuration constraints:

  • NrReservedRbStartIndex in the gNBDULteNrSpctShrCg MO must be smaller than NrReservedRbEndIndex in the gNBDULteNrSpctShrCg MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N-TDD-FR1
PrbUsageThld PRB Usage Threshold

Meaning: Indicates the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. If the PRB usage on the NR side is greater than the sum of the PRB usage threshold and the PRB usage threshold offset, the NR side uses spectrum shared with the LTE side. If the PRB usage on the NR side is smaller than or equal to the PRB usage threshold minus the PRB usage threshold offset, the NR side shares out spectrum shared with the LTE side. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 20~80

Unit: %

Actual Value Range: 20~80

MML Default Value: 50

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Set this parameter based on the load on the live network to allocate NR spectrum suitably and maximize spectral efficiency. A too large value of this parameter leads to a low probability that NR is allocated shared spectrum. A too small value of this parameter leads to a long duration in which NR occupies shared spectrum.

Applicable Mode: N-TDD-FR1
PrbUsageThldOffset PRB Usage Threshold Offset

Meaning: Indicates the offset relative to the PRB usage threshold for triggering LTE TDD and NR spectrum sharing. If the PRB usage is greater than the sum of the PRB usage threshold and the PRB usage threshold offset, the NR side uses spectrum shared with the LTE side. If the PRB usage is less than or equal to the PRB usage threshold minus the PRB usage threshold offset, the NR side shares out spectrum shared with the LTE side. This parameter applies only to low-frequency TDD cells.

GUI Value Range: 0~30

Unit: %

Actual Value Range: 0~30

MML Default Value: 20

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Set this parameter based on the load on the live network to allocate NR spectrum suitably and maximize spectral efficiency. An excessively large value of this parameter may cause the NR cell to retain its current spectrum usage and a low probability that the NR cell shares spectrum or receives shared spectrum. An excessively small value of this parameter may lead to ping-pong effects, meaning the NR cell frequently shares spectrum or receives shared spectrum.

Applicable Mode: N-TDD-FR1

Example

To add the configuration for an LTE and NR spectrum sharing cell set with the parameters as follows: NR Spectrum Sharing Cell Group ID: 2,
LTE Spectrum Sharing Cell Group ID: 2, run the following command:
ADD GNBDULTENRSPCTSHRCG: NrSpctShrCellGrpId=2, LteSpctShrCellGrpId=2;
