Add gNodeB MAC Parameter Group (ADD GNBDUMACPARAMGROUP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add a gNodeB MAC parameter group.

Note

None.

DlMinAcceptableRate Downlink Minimum Acceptable Rate

Meaning: Indicates the minimum downlink acceptable rate, which is used to calculate the downlink resource load of a cell. The value 1000001 is used for special applications.

When this parameter is set to 1000001 for a GBR bearer, the gNodeB reads the GBR value carried by the core network as the minimum acceptable rate of the bearer.

When this parameter is set to 1000001 for a non-GBR bearer, the effect of this value is the same as that of 0. Therefore, avoid setting this parameter to 1000001 for non-GBR bearers.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0~1000001

Unit: kbit/s

Actual Value Range: 0~1000000,1000001

MML Default Value: 1000

Recommended Value: This parameter can be set by the gNodeB by default.

QCIs 1 to 4, 65, 66, and 75: 1000001

QCIs 5 and 69: 20

Other QCIs: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller value of this parameter indicates a lower cell downlink resource usage load calculated in the same scenario and a later load algorithm start time.

A larger value of this parameter leads to the opposite effects.

If this parameter is set to a too large value but the data volume of the bearer is insufficient, the calculated downlink resource usage is high even if air interface resources are not used up. As a result, the load algorithm is started too early. This is because according to the principle of the load statistics mechanism, the gNodeB checks whether the bandwidth resources of the entire system can meet the GUI value of the minimum acceptable rate. If the rate cannot be met, the current cell is considered not meeting the service requirements regardless of the number of used resources.

Applicable Mode: N

SchedulingType Scheduling Type

Meaning: Indicates the scheduling type of a bearer corresponding to each QCI.

The value BASIC_SCH indicates basic scheduling for a bearer. The value VOICE_SCH or IMS_SIGNALING_SCH indicates differentiated scheduling for a bearer.

The value LOW_LATENCY_SCH indicates delay optimization scheduling for a bearer.

GUI Value Range: VOICE_SCH(Voice Scheduling), IMS_SIGNALING_SCH(IMS Signaling Scheduling), BASIC_SCH(Basic Scheduling), LOW_LATENCY_SCH(Low Latency Scheduling)

Unit: None

Actual Value Range: VOICE_SCH, IMS_SIGNALING_SCH, BASIC_SCH, LOW_LATENCY_SCH

MML Default Value: BASIC_SCH(Basic Scheduling)

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

QCI 1, QCI 65, and QCI 66: VOICE_SCH(Voice Scheduling)

QCI 5 and QCI 69: IMS_SIGNALING_SCH(IMS Signaling Scheduling)

QCI 2 to QCI 4, QCI 6 to QCI 9, QCI 70, QCI 75, QCI 79: BASIC_SCH(Basic Scheduling)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to VOICE_SCH or IMS_SIGNALING_SCH, the scheduling priority is increased to ensure user experience, but more resources are consumed. When the involved UEs are located at the cell edge, the spectral efficiency of the cell decreases. If this parameter is set to BASIC_SCH, the basic scheduling priority is used. If this parameter is set to LOW_LATENCY_SCH, the user-plane delay is optimized in light load scenarios, but more resources are consumed.

Applicable Mode: N

Example

To add a configuration of a gNodeB MAC parameter group with the parameters as follows:GNBDUMACPARAMGROUP: 10, run the following command:
ADD GNBDUMACPARAMGROUP: MacParamGroupId=10;
