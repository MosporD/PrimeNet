Modify NR Cell MLB Parameters (MOD NRCELLMLB)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the MLB parameter settings of an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterFreqMlbUeNumThld Inter-frequency MLB UE Number Threshold

Meaning: Indicates the RRC_CONNECTED UE number threshold for triggering inter-frequency MLB. MLB is triggered when the number of RRC_CONNECTED UEs in the given cell is greater than or equal to the summed value of InterFreqMlbUeNumThld and MlbUeNumOffset. MLB is stopped when the number of RRC_CONNECTED UEs is less than the value of InterFreqMlbUeNumThld.

GUI Value Range: 1~10000

Unit: None

Actual Value Range: 1~10000

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, MLB may not be triggered when user experience is poor. If this parameter is set to a small value, MLB will be frequently triggered.

Applicable Mode: N
MlbUeNumOffset MLB UE Number Offset

Meaning: Indicates the offset to the number of RRC_CONNECTED UEs for triggering inter-frequency MLB. UE-number-based MLB is triggered if the number of RRC_CONNECTED UEs in the given cell is greater than or equal to the summed value of InterFreqMlbUeNumThld and MlbUeNumOffset.

GUI Value Range: 0~10000

Unit: None

Actual Value Range: 0~10000

MML Default Value: None

Recommended Value: 20

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to a large value, load balancing may not be initiated or stopped in time. If this parameter is set to a small value, load balancing may be initiated and stopped frequently.

Applicable Mode: N
UeNumDiffThld UE Number Difference Threshold

Meaning: Indicates the UE number difference threshold for MLB. A neighboring cell can be the target cell for MLB when the following conditions are met: (Number of UEs in the serving cell - Number of UEs in the neighboring cell)/Number of UEs in the serving cell > Threshold specified by this parameter; Number of UEs in the serving cell - Number of UEs in the neighboring cell > 5; Neighboring cell load (in percentage) < 90%.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 15

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter leads to a higher requirement on resource sufficiency of neighboring cells. Therefore, it is less likely that neighboring cells meet the requirement, and it is more difficult to trigger MLB. However, once a neighboring cell meets the requirement within an MLB period, more UEs can be transferred to the neighboring cell. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N

Example

To modify the MLB parameters of an NR cell with NR Cell ID set to 0 and Inter-frequency MLB UE Number Threshold set to 80, run the following command:
MOD NRCELLMLB: NrCellId=0, InterFreqMlbUeNumThld=80;
