List Measurement Parameter Group Related to Inter-frequency Handover (LST NRCELLINTERFHOMEAGRP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list one or more measurement parameter groups related to inter-frequency handover for an NR cell.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
InterFreqHoMeasGroupId Inter-freq Handover Measurement Group ID

Meaning: Indicates the ID of a measurement parameter group related to inter-frequency handover.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of CovInterFreqA1RsrpThld must be greater than that of CovInterFreqA2RsrpThld.
  • Under the NRCellInterFHoMeaGrp MO with the same InterFreqHoMeasGroupId, the value of FreqPriInterFA1RsrpThld must be greater than that of FreqPriInterFA2RsrpThld.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: N/A

Applicable Mode: N

Example

To list a measurement parameter group related to inter-frequency handover for an NR cell with NR Cell ID set to 5 and Inter-freq Handover Measurement Group ID set to 0, run the following command:
LST NRCELLINTERRHOMEAGRP: NrCellId=5, InterRatHoMeasGroupId=0;

Output Description

Field Description

NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

Inter-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-frequency handover.

Inter-frequency A4A5 Time to Trigger(ms)

Indicates the time-to-trigger of events A4 and A5 related to inter-frequency measurement. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.

Inter-frequency A4A5 Hysteresis(0.5dB)

Indicates the hysteresis of events A4 and A5 related to inter-frequency measurement. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

Inter-frequency A1A2 Time to Trigger(ms)

Indicates the time-to-trigger of events A1 and A2 related to inter-frequency measurement. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. For details, see 3GPP TS 38.331.

Inter-frequency A1A2 Hysteresis(0.5dB)

Indicates the hysteresis of events A1 and A2 related to inter-frequency measurement. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.

Freq Priority Inter-freq A2 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A2 related to frequency-priority-based inter-frequency handover. If the measured RSRP value of the serving cell is below this threshold throughout the time-to-trigger specified by InterFreqA1A2TimeToTrig, an event A2 report will be sent. For details, see 3GPP TS 38.331.

Freq Priority Inter-freq A1 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A1 related to frequency-priority-based inter-frequency handover. If the measured RSRP value of the serving cell is greater than this threshold throughout the time-to-trigger specified by InterFreqA1A2TimeToTrig, an event A1 report will be sent. For details, see 3GPP TS 38.331.

Cov Inter-freq Handover A5 RSRP Threshold1(dBm)

Indicates the RSRP threshold 1 of the serving cell for event A5 related to coverage-based inter-frequency handover. If the measured RSRP value of the serving cell is below this threshold throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig and the measured RSRP value of a neighboring cell is greater than the threshold specified by the CovInterFreqA5RsrpThld2 parameter, an event A5 report will be sent. For details, see 3GPP TS 38.331.

Cov Inter-freq Handover A5 RSRP Threshold2(dBm)

Indicates the RSRP threshold 2 of a neighboring cell for event A5 related to coverage-based inter-frequency handover. If the measured RSRP value of the serving cell is below the threshold specified by CovInterFreqA5RsrpThld1 throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig and the measured RSRP value of a neighboring cell is greater than the threshold specified by the CovInterFreqA5RsrpThld2 parameter, an event A5 report will be sent. For details, see 3GPP TS 38.331.

Cov Inter-freq Handover A2 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A2 related to coverage-based inter-frequency handover. If the measured RSRP value of the serving cell is below this threshold throughout the time-to-trigger specified by InterFreqA1A2TimeToTrig, an event A2 report will be sent. For details, see 3GPP TS 38.331.

Cov Inter-freq Handover A1 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A1 related to coverage-based inter-frequency handover. If the measured RSRP value of the serving cell is greater than this threshold throughout the time-to-trigger specified by InterFreqA1A2TimeToTrig, an event A1 report will be sent. For details, see 3GPP TS 38.331.

Freq Priority Inter-freq A4 RSRP Threshold(dBm)

Indicates the RSRP threshold for event A4 related to frequency-priority-based inter-frequency handover. If the measured RSRP value of a neighboring cell is greater than this threshold throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig, an event A4 inter-frequency measurement report will be sent. For details, see 3GPP TS 38.331.

MLB-based Inter-Frequency RSRP Threshold(dBm)

Indicates the RSRP threshold for event A4 related to load-balancing-based inter-frequency measurement. If the measured RSRP value of a neighboring cell is greater than this threshold throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig, an event A4 inter-frequency measurement report will be sent. For details, see 3GPP TS 38.331.

Operator Ded Pri Inter-freq HO A4 RSRP Thld(dBm)

Indicates the RSRP threshold for event A4 related to operator-specific priority-based inter-frequency handover. If the measured RSRP value of a neighboring cell is greater than this threshold throughout the time-to-trigger specified by NRCellnterFHoMeaGrp.InterFreqA4A5TimeToTrig, an event A4 inter-frequency measurement report will be sent. For details, see 3GPP TS 38.331.
