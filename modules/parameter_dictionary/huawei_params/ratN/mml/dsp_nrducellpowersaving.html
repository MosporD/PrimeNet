Display NR DU Cell Power Saving (DSP NRDUCELLPOWERSAVING)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to query the power saving information about an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The time difference between NRDUCellPowerSaving MO instances with the same NrDuCellId and PowerSavingType must be greater than 5 minutes.
  • The time segment of an NRDUCellPowerSaving MO instance with PowerSavingType set to TIMING_CARRIER_SHUTDOWN must not overlap with the time segments of other NRDUCellPowerSaving MO instances associated with the same NrDuCellId as this MO instance.
  • If an NRDUCellPowerSaving MO with PowerSavingType set to LNR_BUNDLED_SCHEDULING exists, an NRDUCellPowerSaving MO with PowerSavingType set to POWER_SAVING_SCHEDULE must exist for the cell. In addition, the time range in the record with PowerSavingType set to LNR_BUNDLED_SCHEDULING in the NRDUCellPowerSaving MO corresponding to the cell must be within the time range in the record with PowerSavingType set to POWER_SAVING_SCHEDULE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To query the information of an NR DU Cell Powersaving, run the following command:
DSP NRDUCELLPOWERSAVING:;

Output Description

Field Description

NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.

Power Saving Type

Indicates the power saving type of an NR DU cell.

When this parameter is set to TIMING_CARRIER_SHUTDOWN, the local cell shuts down the carrier at the preset time.

When this parameter is set to LNR_SMART_CARRIER_SHUTDOWN, the local cell performs power saving based on the load on the NR and LTE networks.

When this parameter is set to RF_SHUTDOWN, the local cell shuts down RF channels at the preset time under the specified load condition.

When this parameter is set to POWER_SAVING_SCHEDULE, the local cell performs power saving scheduling at the preset time under the specified load condition.

When this parameter is set to DYNAMIC_SSB, the local cell performs dynamic SSB power saving at the preset time under specified load and user number conditions.

When this parameter is set to LNR_BUNDLED_SCHEDULING, the local cell performs LTE and NR bundled scheduling at the preset time under the specified load condition.

Current State

Indicates the status of the power saving feature for the cell. The value can be DISABLED(Disabled) or ENABLED(Enabled).

Current Disabled Cause

Indicates the cause why cell power saving does not take effect. The cause can be NA(N/A), LICENSE_INSUFFICIENT(Insufficient License), SWITCH_OFF(Switch Turned Off), NEIGHBORING_CELL_NOT_CONFIG(Neighboring Cell Not Configured), CELL_UNAVAILABLE(Cell Unavailable), NOT_IN_SHUTDOWN_TIME(Triggering Time Not Reached), NEIGHBORING_CELL_UNAVAILABLE(Neighboring Cell Unavailable), IMPACTED_FEATURE_TAKEN_EFFECT(Impacted Feature Taken Effect), DEPENDENT_FEATURE_DISABLED(Prerequisite Feature Not Taken Effect), NOT_IN_DL_PRB_THRESHOLD(Downlink PRB Threshold Not Reached), NOT_IN_UE_NUM_THRESHOLD(UE Number Threshold Not Reached), NCELL_PRB_EXCEED_THRESHOLD(Neighboring Cell Load Exceeding Threshold), IN_PENALTY_STATE(In Penalty State), RF_HW_CAPB_NOT_SUPPORTED(RF Hardware Capability Not Supported), BBP_SW_CAPB_NOT_SUPPORTED(BBP Software Capability Not Supported), or OTHERS(Others).
