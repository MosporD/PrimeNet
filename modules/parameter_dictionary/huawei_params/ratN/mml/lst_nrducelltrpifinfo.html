List NR DU Cell TRP IF Information (LST NRDUCELLTRPIFINFO)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the TRP intermediate frequency configuration of an NR DU cell.

Note

None.

Parameters

ID Name Description
NrDuCellTrpId NR DU Cell TRP ID

Meaning: Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the TRP IF information for an NR DU cell with NR DU Cell TRP ID set to 50, run the following command:
LST NRDUCELLTRPIFINFO: NrDuCellTrpId=50;
The result is shown as follows:
+++    0        2018-09-30 10:36:29
O&M    #2685403149
%%LST NRDUCELLTRPIFINFO: NrDuCellTrpId=50;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.

NR IF Downlink Center Frequency(0.005MHz)

Indicates the downlink center frequency of intermediate frequency.

NR IF Uplink Center Frequency(0.005MHz)

Indicates the uplink center frequency of intermediate frequency.

NR IF Output Power(0.1dBm)

Indicates the output power of intermediate frequency.

NR IF Uplink Receive Gain(0.1dB)

Indicates the gains of the uplink RX channel.
