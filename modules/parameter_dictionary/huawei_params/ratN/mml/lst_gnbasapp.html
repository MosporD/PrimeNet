List gNodeB Acceleration Service Application Configuration (LST GNBASAPP)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list a gNodeB acceleration application.

Note

None.

Parameters

ID Name Description
AppId Application Index

Meaning: Indicates the index of the acceleration application.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list a gNodeB acceleration service application with Application Index set to 0, run the following command:
LST GNBASAPP: AppId=0;
The result is shown as follows:

Output Description

Field Description

Application Index

Indicates the index of the acceleration application.

Application Identification Type

Indicates the acceleration application identification type. If this parameter is set to IPV4, the AppIpv4 parameter must be set. If this parameter is set to IPV6, the AppIpv6 parameter must be set.

Application IPv4

Indicates an IPv4 address for acceleration application (acceleration service) identification. This parameter is used during identification based on an IP address and is mandatory when AppIdentType is set to IPV4.

Application IPv6

Indicates an IPv6 address for acceleration application (acceleration service) identification. This parameter is used during identification based on an IP address and is mandatory when AppIdentType is set to IPV6.

Protocol Type

Indicates the protocol type for acceleration application identification. If this parameter is set to ALL, the gNodeB does not check the protocol type during acceleration application identification and applications of any protocol types are identified as acceleration applications. If this parameter is set to TCP, the gNodeB checks whether the protocol type is TCP during acceleration application identification. If this parameter is set to UDP, the gNodeB checks whether the protocol type is UDP during acceleration application identification.

Port Number

Indicates the server port number for acceleration application identification. This parameter is valid only when ProtocolType is set to TCP or UDP. The value 0 indicates that the gNodeB does not check the server port number.
