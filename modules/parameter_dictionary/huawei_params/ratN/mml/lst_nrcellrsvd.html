List Reserved Parameter for NR Cell Commissioning (LST NRCELLRSVD)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list the settings of a reserved parameter for NR cell commissioning.

Note

None.

Parameters

ID Name Description
NrCellId NR Cell ID

Meaning: Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To list the NR cell commissioning reserved parameter, NR Cell Id: 5, run the following command:
LST NRCELLRSVD: NrCellId=5;
The result is shown as follows:
