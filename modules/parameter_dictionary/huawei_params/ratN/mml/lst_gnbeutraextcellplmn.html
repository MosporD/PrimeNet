List gNodeB External E-UTRAN Cell PLMN (LST GNBEUTRAEXTCELLPLMN)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list E-UTRAN external-cell PLMN list configurations of a gNodeB.

Note

None.

Parameters

ID Name Description
Mcc Mobile Country Code

Meaning: Indicates the MCC of the operator who owns the external E-UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • In a gNBEutraExtCellPlmn MO, the combination of Mcc and Mnc must be different from that of SharedMcc and SharedMnc.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N

The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID.
