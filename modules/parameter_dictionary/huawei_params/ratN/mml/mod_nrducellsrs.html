Modify NR DU Cell SRS Configuration (MOD NRDUCELLSRS)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to modify the SRS configuration of an NR DU cell.

Note

This is a high-risk MML command, and therefore exercise caution when executing this command.

Parameters

ID Name Description
NrDuCellId NR DU Cell ID

Meaning: Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.

GUI Value Range: 0~65534

Unit: None

Actual Value Range: 0~65534

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
SrsPeriod SRS Period

Meaning: Indicates the SRS period configured for a UE. The actual SRS period is dependent on the value of this parameter and other factors such as available SRS resources, slot assignment, and UE capability. The actual SRS period for a common UE is greater than or equal to the value of this parameter. For details, see 3GPP TS 38.214.

This parameter is valid only when the SRS_PERIOD_ADAPT_SW option is deselected.

GUI Value Range: SL5(5 Slots), SL10(10 Slots), SL20(20 Slots), SL40(40 Slots), SL80(80 Slots), SL160(160 Slots), SL320(320 Slots), SL640(640 Slots)

Unit: None

Actual Value Range: SL5, SL10, SL20, SL40, SL80, SL160, SL320, SL640

MML Default Value: None

Recommended Value: For UEs not supporting antenna selection:

SL80(80 Slots) if the number of UEs is smaller than or equal to 100

SL160(160 Slots) if the number of UEs is greater than 100 and smaller than or equal to 200

SL320(320 Slots) if the number of UEs is greater than 200 and smaller than or equal to 500

SL640(640 Slots) if the number of UEs is greater than 500

For UEs supporting antenna selection:

SL80(80 Slots) if the number of UEs is smaller than or equal to 50

SL160(160 Slots) if the number of UEs is greater than 50 and smaller than or equal to 100

SL320(320 Slots) if the number of UEs is greater than 100 and smaller than or equal to 250

SL640(640 Slots) if the number of UEs is greater than 250

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter results in a longer SRS period and more supported UEs. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N
SrsAlgoSwitch SRS Algorithm Switch

Meaning: Indicates the SRS algorithm switch, which is used to control SRS resource allocation policies.

SRS_PERIOD_ADAPT_SW: Indicates whether the gNodeB adaptively adjusts the SRS period. When this option is selected, the gNodeB adaptively adjusts the SRS period. When this option is deselected, the fixed SRS period is used.

GUI Value Range: SRS_PERIOD_ADAPT_SW(SRS Period Adaptation Switch)

Unit: None

Actual Value Range: SRS_PERIOD_ADAPT_SW

MML Default Value: None

Recommended Value: This parameter can be set by the system by default. The default value is as follows:

Low-speed cells: SRS_PERIOD_ADAPT_SW:On

High-speed cells: SRS_PERIOD_ADAPT_SW:Off

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: SRS_PERIOD_ADAPT_SW: When this option is selected, the gNodeB adaptively adjusts the SRS period based on the SRS resource load. This achieves a tradeoff between the number of UEs served and network performance. When this option is deselected, network performance is not affected.

Applicable Mode: N
SrsSlotNum SRS Slot Number

Meaning: Indicates the number of cell-specific SRS slots configured for high-frequency SRS within 5 ms. This parameter applies only to high-frequency TDD cells.

GUI Value Range: ONE(1), TWO(2), FOUR(4), EIGHT(8)

Unit: None

Actual Value Range: ONE, TWO, FOUR, EIGHT

MML Default Value: None

Recommended Value: EIGHT(8)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A larger value of this parameter results in a larger number of cell-specific SRS resources, a smaller SRS measurement period, and a higher uplink and downlink throughput. A smaller value of this parameter results in the opposite effects.

Applicable Mode: N-TDD-FR2

Example

To modify the SRS configuration of an NR DU cell with the parameters as follows: NR DU Cell ID: 88, SRS Period: SL160, run the following command:
MOD NRDUCELLSRS: NrDuCellId=88, SrsPeriod=SL160;
