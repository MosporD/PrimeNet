Add gNodeB Function (ADD GNODEBFUNCTION)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to add the gNodeB function.

Note

  • Only one gNodeBFunction MO can be configured on a gNodeB.

  • When connected to a gNodeB, the MAE automatically synchronizes the name of the gNodeB function with the gNodeB.

  • The Application MO referenced by the gNodeBFunction MO must have been configured. In the Application MO, Application Type must be set to gNodeB. Before adding the gNodeBFunction MO, ensure that the referenced Application MO has been added.

Parameters

ID Name Description
gNodeBFunctionName gNodeB Function Name

Meaning: Indicates the name of a gNodeB function, which uniquely identifies the gNodeB function.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of gNodeBFunctionName in a gNodeBFunction MO is a string of characters. The string cannot be all null characters or contain any of the following characters: question marks (?), colons (:), right angle brackets (>), left angle brackets (<), stars (*), slashes (/), backslashes (\), pipes (|), double quotation marks ("), commas (,), semicolons (;), equal signs (=), single quotation marks ('), three or more consecutive plus signs (+), two or more consecutive spaces, and two or more consecutive percentage signs (%).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N
ReferencedApplicationId Referenced Application ID

Meaning: Indicates the ID of the application referenced by the gNodeB function. The application provides operating environment for the gNodeB function.

GUI Value Range: 1~255

Unit: None

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: N
gNBId gNodeB ID

Meaning: Indicates the gNodeB ID defined in the service protocol interface, which is unique within a PLMN.

GUI Value Range: 0~4294967295

Unit: None

Actual Value Range: 0~4294967295

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
gNBIdLength gNodeB ID Length

Meaning: Indicates the length of the gNodeB ID. The gNBIdLength parameter specifies the number of bits occupied by the gNBId in the NR cell identity (NCI), which uniquely identifies the NCI. For details about the parameter, see 3GPP TS 38.423. This parameter must be planned and the values for all gNodeBs must be the same within a PLMN.

GUI Value Range: 22~32

Unit: bit

Actual Value Range: 22~32

MML Default Value: 22

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: N
UserLabel User Label

Meaning: Indicates the user label related to the gNodeB function.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: N

Example

To add the gNodeB function with the parameters as follows: gNodeB Function Name: 5G, Referenced Application ID: 1, gNBId: 0, User Label: HuaWei, run the following command:
ADD GNODEBFUNCTION: gNodeBFunctionName="5G", ReferencedApplicationId=1, gNBId=0, UserLabel="HuaWei";
