NRDUCellCarrMgmt

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellCarrMgmt

Description

An NRDUCellCarrMgmt MO defines NR DU cell-level carrier management, which is used to configure the conditions for adding and deleting secondary cells or auxiliary base stations.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLCARRMGMT

Use this command to list the settings of parameters related to carrier management in an NR DU cell.
MOD NRDUCELLCARRMGMT

Use this command to modify the settings of parameters related to carrier management in an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
SCC Deactivation CQI Threshold

Indicates the CQI threshold for deactivating secondary cells based on channel quality. If the channel quality of a CA UE is lower than this threshold, the gNodeB deactivates the secondary cell. If this parameter is set to 0, the function of deactivating secondary cell based on channel quality is not enabled. This parameter is set on the secondary cell.
CA Enhanced Algorithm Switch

Indicates whether to enable enhanced CA algorithms.

CARR_CSI_BEAM_SWEEPING_SW: Indicates whether to enable CA SCC beam sweeping. CSI beam sweeping is enabled when this option is selected. With this function, the base station obtains the CSI beam information of the UE on the PUSCH-less SCC so that the PMI, RI, or CQI can be transmitted on the optimal beam. CSI beam sweeping is disabled when this option is deselected. This option applies only to low-frequency TDD cells.
