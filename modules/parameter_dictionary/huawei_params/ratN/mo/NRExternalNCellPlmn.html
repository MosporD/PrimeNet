NRExternalNCellPlmn

+-gNodeBFunction
  +-NRExternalNCell
    +-NRExternalNCellPlmn

Description

This MO defines the NR external-cell PLMN list.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRExternalNCell
  • Relation with the NRExternalNCell MO:
    • A maximum of 5 NRExternalNCellPlmn MO instances can be configured for an NRExternalNCell MO.
  • Relation with the gNBNCellPlmnList MO:
    • If the values of SharedMnc and SharedMcc in the NRExternalNCellPlmn MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to NR, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
  • Relation with the gNBNCellPlmnList and gNBOperator MOs:
    • In all the gNBNCellPlmnList MOs with RatType set to NR, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of SharedMnc and SharedMcc in all the NRExternalNCellPlmn MOs must be the same as those of Mnc and Mcc in a gNBOperator MO, respectively; or the values of SharedMnc and SharedMcc in all the NRExternalNCellPlmn MOs must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to NR, respectively.
  • Relation with the gNodeBFunction, gNBExternalPlmn, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, and the PLMN indicated by the combination of SharedMcc and SharedMnc in the NRExternalNCellPlmn MO is not existent in a gNBExternalPlmn MO, then the value of SharedPlmngNBId must not exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, and the PLMN indicated by the combination of SharedMcc and SharedMnc in the NRExternalNCellPlmn MO is not existent in a gNBExternalPlmn MO, then the value of SharedPlmnCellId must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the gNBOperator and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, the value of SharedPlmnCellId cannot exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBOperator MO configured with the combination of Mcc and Mnc corresponding to SharedMcc and SharedMnc in the NRExternalNCellPlmn MO.
  • Relation with the gNBSharingMode and gNBOperator MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, the value of SharedPlmngNBId cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBOperator MO configured with the combination of Mcc and Mnc corresponding to SharedMcc and SharedMnc in the NRExternalNCellPlmn MO.
  • Relation with the gNBExternalPlmn MO:
    • If SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, the value of this parameter must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the PLMN indicated by the combination of SharedMcc and SharedMnc.
    • The value of SharedPlmngNBId in an NRExternalNCellPlmn MO must not exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the PLMN indicated by the combination of SharedMcc and SharedMnc.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Cell ID

Indicates the unique primary-operator cell ID of an external NR cell within a base station. An NR Cell Identity (NCI), which is 36 bits long, consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.
gNodeB ID

Indicates the unique primary-operator gNodeB ID of an external NR cell. An NR Cell Identity (NCI) consists of a cell ID and a gNodeB ID. An NR cell global identifier (NCGI) consists of an NCI and a PLMN ID. For details, see 3GPP TS 38.413.
Mobile Country Code

Indicates the primary-operator MCC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Mobile Network Code

Indicates the primary-operator MNC of an external NR cell.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Shared Mobile Country Code

Indicates the secondary-operator MCC of an external NR cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Shared Mobile Network Code

Indicates the secondary-operator MNC of an external NR cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Tracking Area Code

Indicates the secondary-operator TAC of an external NR cell. The TAC is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. TAC planning is not required when NrNetworkingOption is set to NSA for a secondary operator to which an external NR cell belongs and it is recommended that this parameter be set to the invalid value (4294967295). TAC planning is mandatory when NrNetworkingOption is set to SA or SA_NSA for a secondary operator to which an external NR cell belongs and this parameter must not be set to the invalid value.
NR Networking Option

Indicates the secondary-operator networking option of an external NR cell. The value UNLIMITED indicates the initial state of the secondary operator to which an external cell belongs. That is, a secondary operator to which an external cell belongs works in unknown networking mode, and the cell can serve as a target cell for handovers. The value SA indicates that a secondary operator to which an external cell belongs works in SA networking mode. The value NSA indicates that a secondary operator to which an external cell belongs works in NSA networking mode. The value SA_NSA indicates that a secondary operator to which an external cell belongs works in SA and NSA hybrid networking mode.
Shared PLMN Cell ID

Indicates the unique secondary-operator cell ID of an external NR cell within a base station. If this parameter is set to 65535, no exclusive cell ID is available for the operator, and the value of the NRExternalNCell.CellId parameter is used as the cell ID of the operator.
Shared PLMN gNodeB ID

Indicates the unique secondary-operator gNodeB ID of an external NR cell. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to 65535, this parameter is invalid. In this case, no exclusive gNodeB ID is available for the operator, and the value of the NRExternalNCell.gNBId parameter is used as the gNodeB ID of the operator. If the NRExternalNCellPlmn.SharedPLMNCellId parameter is set to a value other than 65535, this parameter needs to be set to the operator's gNodeB ID configured on the corresponding neighboring base station.
