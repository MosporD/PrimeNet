NRDUCellOp

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellOp

Description

This MO is used to identify the operator of an NR DU cell. In different operator modes, the number of NRDUCellOp MO instances that can be configured for each NR DU cell is different. In independent operator mode, no NRDUCellOp MO instance is configured for each cell. In MORAN mode, only one NRDUCellOp MO instance can be configured for each cell. In MOCN mode, a maximum of six NRDUCellOp MO instances can be configured for each cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the gNBSharingMode and NRDUCell MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be 0.
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be less than or equal to 6.
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be less than or equal to 1.
  • Relation with the NRDUCell MO:
    • When DuplexMode in an NRDUCell MO is set to CELL_SUL, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be 0.
    • If CellPrimaryOpFlag in an NRDUCellOp MO is set to TRUE, the value of CellId in the NRDUCellOp MO must be identical with that of CellId in the corresponding NRDUCell MO.
  • Relation with the gNBOperator MO:
    • OperatorId in an NRDUCellOp MO must be set to a value configured in the corresponding gNBOperator MO.
    • If the CellId parameter in an NRDUCellOp MO is set to a value other than 65535, and the gNBIdLength parameter in an gNBOperator MO is set to a value other than 255, the value of this parameter must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBOperator MO corresponding to OperatorId in the NRDUCellOp MO.
  • Relation with the gNBSharingMode, NRDUCell, and gNBOperator MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, and NrNetworkingOption is set to SA or SA_NSA in at least one of the gNBOperator MOs corresponding to OperatorId in all the NRDUCellOp MOs associated with NrDuCellId in an NRDUCell MO, SsbDescMethod in the NRDUCell MO must be set to SSB_DESC_TYPE_GSCN.
  • Relation with the NRDUCellAlgoSwitch and gNBOperator MOs:
    • If the LNR_SMART_CARRIER_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO is not configured, NrNetworkingOption in the gNBOperator MO with OperatorType set to PRIMARY_OPERATOR must be set to NSA or SA_NSA.
    • If the LNR_SMART_CARRIER_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO is configured, NrNetworkingOption in the gNBOperator MO corresponding to OperatorId in all the NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO must be set to NSA or SA_NSA.
  • Relation with the NRCell, gNBSharingMode, and NRDUCell MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and gNBMultiOpSharingMode is set to SEPARATED_FREQ, the NRDUCellOp MO corresponding to NrDuCellId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the CellPrimaryOpFlag parameter must be set to TRUE in one of the NRDUCellOp MOs corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO.
    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the CellPrimaryOpFlag parameter in the NRDUCellOp MO corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO can only be set to FALSE.
  • Relation with the NRCell, gNBSharingMode, NRDUCell, and gNBOperator MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and gNBMultiOpSharingMode is set to SHARED_FREQ, the NRDUCellOp MO corresponding to NrDuCellId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured. In addition, there must be a gNBOperator MO specified by OperatorId with OperatorType set to PRIMARY_OPERATOR.
    • When CellActiveState in an NRCell MO is set to CELL_ACTIVE and MultipleNCISwitch in the gNBSharingMode MO is set to ON, CellId in the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO must be different from the 3GPP-defined NR Cell Identity (NCI) determined based on gNBId and gNBIdLength in the gNBOperator MO associated with OperatorId in the NRDUCellOp MO. This rule applies to all the NRDUCellOp MOs corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO.
  • Relation with the gNBCUNgOp, NRCell, and gNBOperator MOs:
    • If CellActiveState in any NRCell MO is CELL_ACTIVE and the gNodeB has at least two NRDUCellOp MO instances with OperatorId specifying operators for which NrNetworkingOption is set to SA or SA_NSA, the gNBCUNgOp MOs corresponding to such OperatorId values must be configured.
  • Relation with the NRCellOpPolicy, NRCell, and NRDUCell MOs:
    • The value of OperatorId in an NRCellOpPolicy MO must have been configured in all the NRDUCellOp MOs corresponding to the NRDUCell MO associated with CellId in the NRCell MO corresponding to the NRCellOpPolicy MO.
  • Relation with the NRCellInterRHoMeaGrp, gNBSharingMode, NRCell, NRCellQciBearer, gNBOperator, gNBOperatorQciParam, and NRDUCell MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator MO associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO < InterRatHoA1RsrpThld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
  • Relation with the gNBOperator and gNBTrackingArea MOs:
    • If TrackingAreaId in an NRDUCellOp MO is not set to 4294967295 and NrNetworkingOption in the gNBOperator MO corresponding to OperatorId is set to SA or SA_NSA, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId cannot be set to 4294967295.
  • Relation with the gNBSharingMode MO:
    • TrackingAreaId in an NRDUCellOp MO can be set to a value in the range of 0 to 65535 only when gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ.
    • When the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the CellId parameter in an NRDUCellOp MO must not be set to 65535.
    • When the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the CellId parameter values must be unique in all the NRDUCellOp MOs with the same OperatorId parameter value.
  • Relation with the gNBTrackingArea MO:
    • If TrackingAreaId in an NRDUCellOp MO is not set to 4294967295, the value of TrackingAreaId must be set to the value configured in a gNBTrackingArea MO.
  • Relation with the gNBSharingMode, NRCellRelation, gNBOperator, NRDUCell, and NRCell MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the NR CGI of the serving cell (consisting of Mcc, Mnc, gNBId, and CellId corresponding to OperatorId in the NRDUCellOp MO with CellPrimaryOpFlag set to TRUE associated with the NRDUCell MO corresponding to NrCellId in the NRCellRelation MO) must not be identical with the CGIs of neighboring cells. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the gNBOperator, NRCellRelation, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and the combination of Mcc, Mnc, and gNBId in an NRCellRelation MO has been configured in a gNBOperator MO, the combination of CellId and OperatorId corresponding to Mnc and Mcc must already be configured in an NRDUCellOp MO with CellPrimaryOpFlag set to TRUE.
  • Relation with the NRCellRelation, NRDUCell, NRCell, gNBOperator, and gNBSharingMode MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to ON and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which referenced by NrCellId in an NRCellRelation MO. The combination of gNBId, Mcc, and Mnc in this NRCellRelation MO has been configured in the gNBOperator. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with NrDuCellId in the NRDUCellOp MO in which the combination of OperatorId and CellId corresponding to Mnc and Mcc in the NRCellRelation MO has been configured. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRDUCell, gNBOperator, and gNBTrackingArea MOs:
    • In the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCell MO, if NrNetworkingOption in any gNBOperator MO corresponding to OperatorId is set to SA or SA_NSA, and DuplexMode in the NRDUCell MO is not set to CELL_SUL, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId in the NRDUCell MO cannot be set to 4294967295.
    • If the NRDUCellOp MO corresponding to NrDuCellId in an NRDUCell MO does not exist, OperatorType in a gNBOperator MO is set to PRIMARY_OPERATOR, and NrNetworkingOption in the gNBOperator MO is set to SA or SA_NSA, and DuplexMode in the NRDUCell MO is not set to CELL_SUL, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId in the NRDUCell MO cannot be set to 4294967295.
  • Relation with the NRDUCellUacBar MO:
    • When OperatorId in the NRDUCellUacBar MO is not set to 255, the NRDUCellOp MO with OperatorId set to the same value as OperatorId must already be configured.
  • Relation with the NRDUCellAlgoSwitch MO:
    • When RB_DYNAMIC_SHARING_SW or MAX_RB_LIMIT_SW of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO has been configured, CellResId in an NRDUCellOp MO associated with NrDuCellId cannot be set to 255.
  • Relation with the NRDUCellAlgoSwitch and NRDUCellRes MOs:
    • When RB_DYNAMIC_SHARING_SW of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO has been configured, neither DlRbAverageRatio nor UlRbAverageRatio in an NRDUCellRes MO associated with CellResId in an NRDUCellOp MO can be set to 255.
    • When MAX_RB_LIMIT_SW of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO has been configured, neither DlRbMaxRatio nor UlRbMaxRatio in an NRDUCellRes MO associated with CellResId in an NRDUCellOp MO can be set to 255.
  • Relation with the NRDUCellRes MO:
    • If CellResId in an NRDUCellOp MO is not set to 255, the NRDUCellRes MO associated with NrDuCellId and CellResId must have been configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the cell within a gNodeB.
Operator ID

Indicates the ID of an operator.
Tracking Area ID

Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the core network. It is different from the TAI configured in the TAL of the core network. If this parameter is set to 4294967295, the TAI of the operator corresponding to the cell is the value of TrackingAreaId in the NRDUCell MO. If this parameter is set to a value in the range of 0 to 65535, the TAI of the operator corresponding to the cell is the value of this parameter.
Policy Switch

Indicates the policy switches configured for different operators in non-independent operator mode.

OP_SUL_SWITCH: Indicates whether Super Uplink or UL and DL Decoupling can be enabled for an operator. This option applies only to SUL.
Cell ID

Indicates the operator-specific cell ID of an NR cell. This cell ID and the gNodeB ID of the operator compose the 3GPP-defined NR cell ID (NCI) of the operator. The NCI and the PLMN ID compose the NCGI. For details, see 3GPP TS 38.413. If this parameter is set to 65535, this parameter is invalid. In this case, no exclusive cell ID is available for the operator. If this parameter is set to a value in the range of 0 to 16383 and gNBSharingMode.MultipleNCISwitch is set to ON, the setting of this parameter takes effect. In this case, operators use their own cell IDs.
Cell Primary Operator Flag

Indicates the primary operator of a cell. If the gNBSharingMode.MultipleNCISwitch parameter is set to ON, the primary operator must be specified. If the gNBSharingMode.MultipleNCISwitch parameter is set to OFF, there is no need to specify the primary operator.
Cell Resource ID

Indicates the NR DU cell resource ID, which is used to add cell resources for an operator in multi-operator sharing scenarios. The value 255 indicates an invalid value, which means that cell resources are not added for the operator.
