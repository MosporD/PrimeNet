gNBCUX2Interface

+-gNodeBFunction
  +-gNBCUX2Interface

Description

A gNBCUX2Interface MO defines an X2 interface between the gNodeB and an eNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP GNBCUX2INTERFACE

Use this command to query the status of gNodeB CU X2 interfaces and the information of peer eNodeBs. If the status of an X2 interface is abnormal, the command output displays the information of the peer eNodeB in the last normal connection with the local gNodeB.
DSP GNBCUX2UPINFO

Use this command to query gNodeB CU X2 user plane information.

Related Parameters

Table 2 and Table 3 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB CU X2 Interface ID

Indicates the ID of a gNodeB CU X2 interface.
gNodeB CU X2 CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU X2 interface.
gNodeB CU X2 Control Plane Peer IP

Indicates the peer IP address of the control plane of the gNodeB CU X2 interface.
Table 3 Dynamic parameters

Parameter

Description
Neighboring eNodeB ID

Indicates the ID of the neighboring eNodeB on the peer end of a gNodeB CU X2 interface. The combination of this parameter and NeighboringEnodebPlmnId uniquely identifies the neighboring eNodeB around the globe.
Neighboring eNodeB PLMN ID

Indicates the PLMN ID of the neighboring eNodeB on the peer end of a gNodeB CU X2 interface.
