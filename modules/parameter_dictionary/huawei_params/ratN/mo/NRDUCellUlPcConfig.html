NRDUCellUlPcConfig

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellUlPcConfig

Description

This MO defines uplink power control parameters for common radio resources in an NR DU cell. For details about uplink power control, see 3GPP TS 38.213.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLULPCCONFIG

Use this command to list the configuration of uplink power control for an NR DU cell.
MOD NRDUCELLULPCCONFIG

Use this command to modify the configuration of uplink power control for an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Uplink Power Control Algorithm Switch

Indicates the uplink power control algorithm switch, which is used to specify the uplink power control policy.

PUSCH_DYN_SCH_CLOSED_LOOP_SW: Indicates whether the gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode. The gNodeB adjusts the PUSCH transmit power of the UE in dynamic scheduling mode only if this option is selected.

PUCCH_OUTER_LOOP_SW: Indicates whether the gNodeB adjusts the target SINR for PUCCH power control. The gNodeB adjusts the target SINR for PUCCH power control only if this option is selected.

PUCCH_INNER_LOOP_SW: Indicates whether the gNodeB adjusts the PUCCH transmit power of the UE. The gNodeB adjusts the PUCCH transmit power of the UE only if this option is selected.

PO_SRS_ADAPT_SW: Indicates whether the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is selected, the gNodeB adaptively adjusts the nominal PO value of the SRS. If this option is deselected, the configured PO value of the SRS is used.
PO Nominal PUSCH

Indicates the nominal PO value of the PUSCH. For details, see 3GPP TS 38.213.
Path Loss Coefficient

Indicates the compensation factor for path loss. It is used in uplink power control. For details, see 3GPP TS 38.213.
PO Nominal PUCCH

Indicates the nominal PO value of the PUCCH. For details, see 3GPP TS 38.213.
Preamble Initial Received Target Power

Indicates the initial receive target power of the preamble. For details, see 3GPP TS 38.213.
Power Ramping Step

Indicates the preamble power increase step. For details, see 3GPP TS 38.321.
TPC Value In Msg2

Indicates the power adjustment value in Msg2. For details, see 3GPP TS 38.213.
Delta Preamble Msg3

Indicates the power offset of Msg3 relative to preamble. For details, see 3GPP TS 38.213.
SRS Power Control SINR Target

Indicates the target SINR value for SRS power control.
SRS PO

Indicates the nominal PO value of the SRS. For details, see 3GPP TS 38.213.

If the PO_SRS_ADAPTIVE_SW option of the UlPwrCtrlAlgoSwitch parameter is selected, the value of this parameter is used as the initial value of the nominal PO value, which is then adaptively adjusted by the gNodeB.
