NRCellInterRHoMeaGrp

+-gNodeBFunction
  +-NRCell
    +-NRCellInterRHoMeaGrp

Description

An NRCellInterRHoMeaGrp MO defines a group of measurement parameters related to inter-RAT handover. Handover measurement parameter settings can be QCI-specific to meet various requirements of services for target cells. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellQciBearer MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellInterRHoMeaGrp MO, the value of InterRatHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellInterRHoMeaGrp MO.
  • Relation with the NRCell MO:
    • A maximum of 15 NRCellInterRHoMeaGrp MO instances can be configured for each NRCell MO.
  • Relation with the NRCellQciBearer and NRCellInterFHoMeaGrp MOs:
    • For NRCellInterRHoMeaGrp and NRCellInterFHoMeaGrp MOs associated with the same NRCellQciBearer MO, the sum of CovInterFreqA2RsrpThld and InterFreqA1A2Hyst must be greater than the sum of CovHoToEutranBlindA2Thld and InterRatHoA1A2Hyst.
  • Relation with the gNBSharingMode, NRCellQciBearer, and gNBOperatorQciParam MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to a gNBOperator MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO < InterRatHoA1RsrpThld in the NRCellInterRHoMeaGrp MO.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in the gNBOperatorQciParam MOs corresponding to a gNBOperator MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO.
  • Relation with the gNBSharingMode, NRCell, NRCellQciBearer, gNBOperator, gNBOperatorQciParam, NRDUCell, and NRDUCellOp MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator MO associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO < InterRatHoA1RsrpThld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.
Inter-RAT Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover.
Inter-RAT Handover A1 RSRP Threshold

Indicates the RSRP threshold for event A1 related to inter-RAT handover. If the measured RSRP value of the serving cell is greater than the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A1 reports. For details, see 3GPP TS 38.331.
Inter-RAT Handover A2 RSRP Threshold

Indicates the RSRP threshold for event A2 related to inter-RAT handover. If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger, UEs send event A2 measurement reports. For details, see 3GPP TS 38.331.
Inter-RAT Handover A1A2 Hysteresis

Indicates the hysteresis for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.
Inter-RAT Handover A1A2 Time To Trigger

Indicates the time-to-trigger for event A1/A2 related to inter-RAT mobility procedures and for event A2 related to blind mobility procedures. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.
Cov HO to E-UTRAN Blind A2 RSRP Thld

Indicates the RSRP threshold for event A2 related to coverage-based blind handover to E-UTRAN and inter-frequency blind redirection.

If the measured RSRP value of the serving cell is below the threshold specified by this parameter throughout the corresponding time-to-trigger for event A1/A2 related to inter-RAT mobility procedures, UEs send event A2 reports related to blind mobility procedures. For details, see 3GPP TS 38.331.
Cov HO to E-UTRAN B2 RSRP Thld1

Indicates the RSRP threshold 1 for event B2 related to coverage-based handover to E-UTRAN. If the measured RSRP value of the serving cell is below the event B2 RSRP threshold 1 throughout the corresponding time-to-trigger for event B1/B2 related to coverage-based handover to E-UTRAN and the RSRP of a neighboring E-UTRAN cell is greater than the RSRP threshold for event B1 related to coverage-based handover to E-UTRAN throughout the same time-to-trigger, UEs send event B2 measurement reports. For details, see 3GPP TS 38.331.
