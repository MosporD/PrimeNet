NRDUCellCsirs

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellCsirs

Description

The NRDUCellCsirs MO defines channel state information-reference signals (CSI-RSs) for an NR DU cell. It is used to configure the CSI measurement algorithm and resource allocation algorithm.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCell MO:
    • When HighSpeedFlag in the NRDUCell MO is set to HIGH_SPEED, TrsPeriod in the NRDUCellCsirs MO must be set to MS0, MS10, or MS20. When HighSpeedFlag in the NRDUCell MO is set to LOW_SPEED, TrsPeriod in the NRDUCellCsirs MO cannot be set to MS10.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, TrsPeriod in the NRDUCellCsirs MO cannot be set to MS0.
  • Relation with the NRDUCell and NRDUCellIntrfParam MOs:
    • If HighSpeedFlag in the NRDUCell MO is set to LOW_SPEED and InterferenceSolutionType in the NRDUCellIntrfParam MO is set to LTE_INTRF, CsiPeriod in the associated NRDUCellCsirs MO cannot be set to SLOT10.
  • Relation with the NRDUCellAlgoSwitch MO:
    • The LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO can be selected only when TrsPeriod in the associated NRDUCellCsirs MO is not set to MS10.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected, CsiPeriod in the associated NRDUCellCsirs MO cannot be set to SLOT10.
  • Relation with the NRDUCellIntrfParam and NRDUCell MOs:
    • If InterferenceSolutionType in an NRDUCellIntrfParam MO is set to LTE_INTRF, HighSpeedFlag in the NRDUCell MO is set to LOW_SPEED, and CsiPeriod in the NRDUCellCsirs MO is set to SLOT20, CsirsCellResourceNum in the NRDUCellCsirs MO must be set to 1_RESOURCE.
    • If InterferenceSolutionType in an NRDUCellIntrfParam MO is set to LTE_INTRF, HighSpeedFlag in the NRDUCell MO is set to LOW_SPEED, and CsiPeriod in the NRDUCellCsirs MO is set to SLOT40, CsirsCellResourceNum in the NRDUCellCsirs MO cannot be set to 4_RESOURCE.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
TRS Period

Indicates the period of transmitting TRSs.

If this parameter is set to MS0, TRS transmission is disabled.

The values MS10, MS20, MS40, and MS80 indicate that TRSs are transmitted every 10 ms, 20 ms, 40 ms, and 80 ms, respectively.
CSI Period

Indicates the period for transmitting periodic CSI-RSs. This parameter takes effect only for UEs that initially access the network. This parameter applies only to low-frequency cells.
CSI Algorithm Switch

Indicates the switch for the CSI algorithm.

PERIODIC_CSI_SWITCH: When this option is selected, periodic CSI is configured for UEs. When this option is deselected, aperiodic CSI is configured for UEs. In high frequency bands, only aperiodic CSI is supported. Therefore, this option must be deselected.
CSIRS Cell Resource Number

Indicates the number of resources for periodic CSI-RS transmission in a cell. This parameter applies only to low-frequency TDD cells.
