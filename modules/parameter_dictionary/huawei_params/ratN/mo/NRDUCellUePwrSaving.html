NRDUCellUePwrSaving

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellUePwrSaving

Description

This MO consists of parameters related to UE power saving features such as DRX in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellPdsch MO:
    • When BwpPwrSavingSw in the NRDUCellUePwrSaving MO is turned on, the options of RateMatchSwitch in the NRDUCellPdsch MO must be deselected.
  • Relation with the NRDUCell MO:
    • When the BWP2_SWITCH option of BwpPwrSavingSw in the NRDUCellUePwrSaving MO is selected, NrDuCellNetworkingMode in the NRDUCell MO corresponding to NrDuCellId parameter in the NRDUCellUePwrSaving MO must be set to NORMAL_CELL.
    • When HighSpeedFlag in the NRDUCell MO is set to HIGH_SPEED, the BASIC_DRX_SW option of NrDuCellDrxAlgoSwitch in the NRDUCellUePwrSaving MO must be deselected.
    • The BWP2_SWITCH option of BwpPwrSavingSw in the NRDUCellUePwrSaving MO can be selected only when all the following conditions are met in the associated NRDUCell MO: DuplexMode is set to CELL_TDD, FrequencyBand is set to N38, N40, N41, N77, N78, or N79, and DlBandwidth and UlBandwidth are set to CELL_BW_60M, CELL_BW_70M, CELL_BW_80M, CELL_BW_90M, or CELL_BW_100M.
  • Relation with the NRDUCellAlgoSwitch and NRDUCell MOs:
    • If the INIT_BWP_FULL_BW_SW option of BwpConfigPolicySwitch in an NRDUCellAlgoSwitch MO is selected and the BWP2_SWITCH option of BwpPwrSavingSw in an NRDUCellUePwrSaving MO is selected, PrachFreqStartPosition in the NRDUCell MO must be set to 65535.
  • Relation with the NRDUCellSrs MO:
    • If the BWP2_SWITCH option of BwpPwrSavingSw in an NRDUCellUePwrSaving MO is selected, the SRS_PERIOD_ADAPT_SW option of SrsAlgoSwitch in the NRDUCellSrs MO must also be selected.
  • Relation with the NRDUCellUePwrSaving MO:
    • If the LNR_DRX_SYNCHRONIZE_SW option of NrDuCellDrxAlgoSwitch in an NRDUCellUePwrSaving MO is selected, the BASIC_DRX_SW option of NrDuCellDrxAlgoSwitch in an NRDUCellUePwrSaving MO must be selected.
  • Relation with the NRDUCellPucch MO:
    • If the BWP2_SWITCH option of BwpPwrSavingSw in the NRDUCellUePwrSaving MO is selected, StructureType in the associated NRDUCellPucch MO must be set to LONG_STRUCTURE.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
NR DU Cell DRX Algorithm Switch

Indicates whether to enable the DRX algorithm for an NR DU cell.

BASIC_DRX_SW: Indicates whether to enable DRX for UEs in an NR DU cell.

LNR_DRX_SYNCHRONIZE_SW: Indicates whether to enable DRX synchronization for EN-DC UEs in an NR DU cell. This option takes effect only if the BASIC_DRX_SW option is selected.
BWP Power Saving Switch

Indicates whether to allow UEs in the local cell to enter the BWP2 power saving state.

BWP2_SWITCH: Indicates whether the cell allows BWP2 power saving for UEs. When this option is selected, the cell allows UEs capable of this function to enter the BWP power saving state. When this option is deselected, the cell does not allow UEs to enter the BWP power saving state, even if the UEs support this function. This parameter takes effect only when NRDUCellPucch.StructureType is set to LONG_STRUCTURE. This parameter applies only to low-frequency TDD cells.
