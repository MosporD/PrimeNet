gNBCUX2Op

+-gNodeBFunction
  +-gNBCUX2
    +-gNBCUX2Op

Description

This MO is used to indicate the operator information of an X2 object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBCUX2
  • Relation with the gNBOperator MO:
    • OperatorId in a gNBCUX2Op MO must be set to the value configured in the associated gNBOperator MO.
    • NrNetworkingOption in the gNBOperator MO corresponding to OperatorId in a gNBCUX2Op MO must be set to NSA or SA_NSA.
  • Relation with the gNBSharingMode MO:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the value of gNBCuX2Id corresponding to OperatorId in the gNBCUX2Op MO must be unique.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCUX2OP

Use this command to add a gNodeB CU X2 operator.
LST GNBCUX2OP

Use this command to list the operator information about gNodeB CU X2 objects.
RMV GNBCUX2OP

Use this command to remove a gNodeB CU X2 operator.
