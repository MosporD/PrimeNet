NRDUCellTrpCustBeam

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellTrpBeam
      +-NRDUCellTrpCustBeam

Description

This MO consists of parameters related to customized and scenario-based beam configurations. The MO applies only to low-frequency cells. Users can configure parameters such as the tilt angle and azimuth under the specified TRP ID and beam ID.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrpBeam
  • Relation with the NRDUCellTrpBeam, NRDUCellTrp, and NRDUCell MOs:
    • When CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the NRDUCell MO is set to 4_1_DDDSU or 7_3_DDDSUDDSUU, BeamId with the value range from 0 to 6 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.
    • When CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the NRDUCell MO is set to 8_2_DDDDDDDSUU, BeamId with the value range from 0 to 7 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.
  • Relation with the NRDUCellTrp, NRDUCellTrpBeam, and NRDUCell MOs:
    • If CoverageScenario in the NRDUCellTrpBeam MO under an NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the associated NRDUCell MO is set to 8_2_DDDSUUDDDD, BeamId with IDs from 0 to 5 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.
Beam Id

Indicates the beam ID of the customized and scenario-based beam. This parameter applies only to the TDD 64T low-frequency modules.
Tilt

Indicates the configured downtilt angle mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different tilt angle ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Tilt is -3° to 15°.
Azimuth

Indicates the horizontal azimuth corresponding to the beamforming weight for a cell. This parameter applies only to low-frequency TDD cells. Different types of AAUs support different azimuth ranges. This parameter applies only to the TDD 64T low-frequency modules. For 64T low-frequency AAUs, the value range of Azimuth is -47° to 47°.
