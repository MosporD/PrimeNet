NRCellFreqRelation

+-gNodeBFunction
  +-NRCell
    +-NRCellFreqRelation

Description

The NRCellFreqRelation MO consists of parameters related to neighboring frequencies, which are used for inter-frequency handover and cell reselection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCell MO:
    • A maximum of 16 NRCellFreqRelation MO instances can be configured for each NRCell MO.
  • Relation with the NRCell and NRDUCell MOs:
    • If SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos in the NRCellFreqRelation MO must be different from the value of SsbFreqPos in the NRDUCell MO corresponding to the associated NRCell MO when SsbDescMethod in the NRDUCell MO is set to SSB_DESC_TYPE_GSCN, or from the GSCN mapped to the value of SsbFreqPos when SsbDescMethod is set to SSB_DESC_TYPE_NARFCN.
    • Similarly, if SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, the value of SsbFreqPos in the NRCellFreqRelation MO must be different from the value of SsbFreqPos in the NRDUCell MO corresponding to the associated NRCell MO when SsbDescMethod in the NRDUCell MO is set to SSB_DESC_TYPE_NARFCN, or from the NR-ARFCN mapped to the value of SsbFreqPos when SsbDescMethod is set to SSB_DESC_TYPE_GSCN.
  • Relation with the NRCellOpPolicy, gNBFreqPriorityGroup, NRCell, and NRDUCell MOs:
    • The combination of SsbFreqPos and SsbDescMethod in the gNBFreqPriorityGroup MO corresponding to gNBFreqPriorityGroupId in an NRCellOpPolicy MO must already be existent in the NRCellFreqRelation MO corresponding to NrCellId in the NRCellOpPolicy MO or in the NRDUCell MO corresponding to NrCellId in the NRCellOpPolicy MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
SSB Frequency Position

Indicates the frequency-domain position of the SSB on a neighboring frequency. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN(Global Synchronization Channel Number), this parameter indicates the GSCN corresponding to the SSB on a neighboring frequency. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN(Absolute Frequency), this parameter indicates the NR-ARFCN corresponding to the SSB on a neighboring frequency.
Frequency Band

Indicates the band of a neighboring frequency. For details, see 3GPP TS 38.104.
Subcarrier Spacing

Indicates the SSB subcarrier spacing of a neighboring frequency. The default value is 15KHZ for FDD and 30KHZ for TDD. For details, see 3GPP TS 38.104.
Cell Reselection Priority

Indicates the cell reselection priority of a neighboring frequency. The value 0 indicates the lowest priority, which is contained in SIB4. A UE determines whether to reselect to a neighboring cell on the frequency based on the value of this parameter and the absolute priority of the serving cell.

If the value of this parameter is larger than the priority of the serving cell, the UE starts measuring cells on the neighboring frequency. Then, if the signal quality of a cell on the neighboring frequency meets the requirements, the UE starts cell reselection.

If the value of this parameter is less than or equal to the priority of the serving cell, the UE starts measuring cells on the neighboring frequency only when the signal quality of the serving cell is poor. Then, if the signal quality of a cell on the neighboring frequency meets the requirements, the UE starts cell reselection. Cell reselection priorities for different RATs cannot be the same.

This parameter corresponds to the cellReselectionPriority IE in SIB4. For details, see 3GPP TS 38.331.
Minimum RX Level

Indicates the minimum RX level required for reselection to an inter-frequency neighboring cell, which corresponds to the q-RxLevMin IE in SIB4. For details, see 3GPP TS 38.331.
High Priority Reselection Threshold

Indicates the RX level threshold for reselecting to a cell on a high-priority neighboring frequency. If the cell reselection priority of the target frequency is higher than that of the serving cell, this threshold is used as the RX level threshold for a UE to reselect from the serving cell to the cell on the target frequency.

After reselection measurements are started for neighboring cells on the target frequency, the UE reselects to a cell on the target frequency only if the RX level of the cell is higher than the threshold specified by this parameter for the corresponding time-to-trigger.

This parameter corresponds to the threshX-HighP IE in SIB4. For details, see 3GPP TS 38.331.
Low Priority Reselection Threshold

Indicates the RX level threshold for reselecting to a low-priority neighboring frequency. If the absolute priority of the target frequency is lower than that of the serving cell, this threshold is used as the RX level threshold for a UE to reselect from the serving cell to the cell on the target frequency.

After reselection measurements are started for cells on the target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter and that of the serving cell is lower than a low-priority serving-frequency reselection threshold for the corresponding time-to-trigger.

This parameter corresponds to the threshX-LowP IE in SIB4. For details, see 3GPP TS 38.331.
Frequency Offset

Indicates the RSRP offset for reselection to a neighboring frequency. This parameter corresponds to the QoffsetFreq IE in SIB4. For details, see 3GPP TS 38.331.
Frequency Priority for Connected Mode

Indicates the connected-mode priority of a neighboring frequency. When measurement for coverage-based handovers is performed, the frequency with a high priority specified by this parameter is preferentially selected. A larger value of this parameter indicates a higher priority. The value 0 indicates that the corresponding frequency is not selected as the target frequency for blind redirection.
Frequency Offset for Connected Mode

Indicates the connected-mode frequency-specific offset of a neighboring frequency. This parameter is delivered to RRC_CONNECTED UEs through measurement configurations to control the probability of measurement reporting. This parameter corresponds to the OffsetMO IE. For details, see 3GPP TS 38.331.
Traffic Priority

Indicates the traffic priority for a neighboring frequency. During the measurement for a frequency-priority-based handover, the frequency with a high priority specified by this parameter is preferentially selected to absorb traffic. A larger value of this parameter indicates a higher priority. If this parameter is set to 0, the frequency is not selected as the target frequency for frequency-priority-based handovers.
SSB Frequency Position Describe Method

Indicates the frequency-domain position description method of the SSB on a neighboring frequency.
SMTC Period

Indicates the inter-frequency SMTC period. For details, see 3GPP TS 38.331.
SMTC Duration

Indicates the inter-frequency SMTC duration. For details, see 3GPP TS 38.331. This parameter applies only to low-frequency TDD and FDD.
Additional Frequency Band

Indicates the additional frequency band of a neighboring frequency. If this parameter is set to NULL, the additional frequency band is not configured. For details, see 3GPP TS 38.104.
