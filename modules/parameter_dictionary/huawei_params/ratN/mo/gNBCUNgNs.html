gNBCUNgNs

+-gNodeBFunction
  +-gNBCUNgNs

Description

This MO is used to configure a gNodeB CU NG network slice, including the gNodeB CU NG object ID, operator ID, slice/service type, and slice differentiator.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBCUNg MO:
    • gNBCuNgId in a gNBCUNgNs MO must be set to a value configured in the associated gNBCUNg MO.
  • Relation with the gNBNetworkSlice MO:
    • OperatorId, SliceServiceType, and SliceDifferentiator in a gNBCUNgNs MO must be set to values configured in the associated gNBNetworkSlice MO.
  • Relation with the gNBCUNgOp MO:
    • gNBCuNgId and OperatorId in a gNBCUNgNs MO must be set to values configured in the associated gNBCUNgOp MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCUNGNS

Use this command to add a gNodeB CU NG network slice.
LST GNBCUNGNS

Use this command to list one or more gNodeB CU NG network slices.
RMV GNBCUNGNS

Use this command to remove a gNodeB CU NG network slice.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB CU NG ID

Indicates the ID of a gNodeB CU NG object.
Operator ID

Indicates the ID of an operator.
Slice Service Type

Indicates the slice/service type. For details, see 3GPP TS 23.003.
Slice Differentiator

Indicates the slice differentiator. For details, see 3GPP TS 23.003. If this parameter is set to 16777215, a slice/service type is configured for the slice but the slice differentiator is not configured. If this parameter is not set to 16777215, this parameter indicates the specific slice differentiator.
