NRExternalNCell

+-gNodeBFunction
  +-NRExternalNCell
    +-NRExternalNCellPlmn[0~5]

Description

An NRExternalNCell MO defines the common parameters of an external NR cell. Each external NR cell is under a gNodeB different from the local gNodeB and can be configured as an intra- or inter-frequency neighboring cell of one or more cells under the local gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

  • Possible children:

    NRExternalNCellPlmn[0~5]
  • Relation with the gNodeBFunction, gNBOperator, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the value of gNBId in an NRExternalNCell MO is identical with the value of gNBId in the gNodeBFunction MO, the values of Mcc and Mnc in the NRExternalNCell MO cannot be identical with the values of Mcc and Mnc in the gNBOperator MO.
  • Relation with the gNodeBFunction, gNBSharingMode, and gNBExternalPlmn MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of gNBId in the NRExternalNCell MO cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of CellId in the NRExternalNCell MO cannot exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the NRExternalNCellPlmn MO:
    • A maximum of 5 NRExternalNCellPlmn MO instances can be configured for an NRExternalNCell MO.
  • Relation with the gNodeBFunction, gNBOperator, NRCellRelation, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the value of gNBId in an NRCellRelation MO is inconsistent with that of gNBId in the gNodeBFunction MO, an NRExternalNCell MO must be configured first.
  • Relation with the gNBNCellPlmnList MO:
    • If the values of Mnc and Mcc in the NRExternalNCell MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to NR, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
  • Relation with the NRCellRelation, NRDUCell, and NRCell MOs:
    • The NRDUCell and NRExternalNCell MO instances meet the following conditions: 1. The NRDUCell MO instance is associated with CellId in an NRCell MO, which is correlated with the NRCellRelation MO through NrCellId. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. 2. The values of Mcc, Mnc, gNBId, and CellId in the NRCellRelation MO are equal to their counterparts in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is the same as the value of SsbDescMethod in the NRExternalNCell MO, the value of SsbFreqPos in the NRDUCell MO must be different from the value of SsbFreqPos in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is different from the value of SsbDescMethod in the NRExternalNCell MO, the NR-ARFCN corresponding to SsbFreqPos in the NRDUCell MO must be different from the NR-ARFCN corresponding to SsbFreqPos in the NRExternalNCell MO.
  • Relation with the gNBNCellPlmnList and gNBOperator MOs:
    • In all the gNBNCellPlmnList MOs with RatType set to NR, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of Mnc and Mcc in all the NRExternalNCell MOs must be the same as those of Mnc and Mcc in a gNBOperator MO, respectively; or the values of Mnc and Mcc in all the NRExternalNCell MOs must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to NR, respectively.
  • Relation with the gNBOperator and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the value of CellId in an NRExternalNCell MO cannot exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBOperator MO configured with the combination of Mcc and Mnc corresponding to Mcc and Mnc in the NRExternalNCell MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the value of gNBId in an NRExternalNCell MO cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBOperator MO configured with the combination of Mcc and Mnc corresponding to Mcc and Mnc in the NRExternalNCell MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the combination of Mcc, Mnc, and gNBId in the NRExternalNCell MO must not be configured in the gNBOperator MO.
  • Relation with the gNBOperator, NRCellRelation, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and the combination of Mnc, Mcc, and gNBId in an NRCellRelation MO is inconsistent with the combination of Mcc, Mnc, and gNBId in the gNBOperator MO, the combination of Mnc, Mcc, gNBId, and CellId in the NRCellRelation MO must already be configured in an NRExternalNCell MO.
  • Relation with the gNBExternalPlmn MO:
    • The value of CellId in an NRExternalNCell MO cannot exceed the maximum value of 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the combination of Mcc and Mnc.
    • The value of gNBId in an NRExternalNCell MO cannot exceed the maximum value of 2^N - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the combination of Mcc and Mnc.
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the NRExternalNCell cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe. If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRExternalNCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRExternalNCell MO instances must be less than or equal to 144 x 32.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRExternalNCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRExternalNCell MO instances must be less than or equal to 36 x 32.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRExternalNCell MO instance cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRExternalNCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRExternalNCell MO instances must be less than or equal to 36 x 32.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRExternalNCell MO instances cannot be added.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the MCC of the operator who owns an external NR cell. The MCC, together with the MNC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.
Mobile Network Code

Indicates the MNC of the operator who owns an external NR cell. The MNC, together with the MCC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.
gNodeB ID

Indicates the gNodeB ID of an external NR cell. It uniquely identifies a gNodeB within a PLMN.
Cell ID

Indicates the cell ID of an external NR cell. It uniquely identifies an NR cell within a gNodeB.
Physical Cell ID

Indicates the physical cell ID of an external NR cell.
Cell Name

Indicates the name of an external NR cell.
RAN Notification Area ID

Indicates the RAN notification area ID of an external cell. This parameter is invalid when it is set to 65535.
Tracking Area Code

Indicates the TAC of a neighboring cell, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. TACs do not need to be planned when the external cell is an NSA cell and you are advised to set this parameter to the invalid value (4294967295). TACs must be planned when the external cell is an SA or SA_NSA cell and cannot be set to an invalid value.
SSB Frequency Position Describe Method

Indicates the description method of the SSB frequency domain position of a cell.
SSB Frequency Position

Indicates the frequency-domain position of the cell's SSB. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN(Global Synchronization Channel Number), this parameter indicates the GSCN corresponding to the cell's SSB. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN(Absolute Frequency), this parameter indicates the NR-ARFCN corresponding to the cell's SSB.
NR Networking Option

Indicates the architecture option of an external NR cell. The value UNLIMITED indicates that the external cell is in its initial state. That is, the networking mode of the external cell is unknown, and the cell can serve as a target cell for handover. The value SA indicates that the external cell works in SA networking mode. The value NSA indicates that the external cell works in NSA networking mode. The value SA_NSA indicates that the external cell can work in both SA and NSA networking modes.
Frequency Band

Indicates the frequency band of an external cell. If this parameter is set to NULL, the frequency band of the external cell is not configured. For details, see 3GPP TS 38.104.
Additional Frequency Band

Indicates the additional frequency band of an external cell. If this parameter is set to NULL, the additional frequency band of the external cell is not configured. For details, see 3GPP TS 38.104.
PLMN Reserved Flag

Indicates whether to reserve the PLMN ID of an external NR cell. If this parameter is set to TRUE, the PLMN ID of the external NR cell is reserved and this cell cannot be selected as a target cell for UEs served by the PLMN. If this parameter is set to FALSE, this cell can be selected as a target cell for UEs served by the PLMN.
