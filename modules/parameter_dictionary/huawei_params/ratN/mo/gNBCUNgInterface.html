gNBCUNgInterface

+-gNodeBFunction
  +-gNBCUNgInterface

Description

A gNBCUNgInterface MO consists of user-configured parameters related to an NG interface between a gNodeB and an AMF. The parameters specify information about the NG interface and the AMF, including the control port bearer used for the NG interface, the globally unique AMF ID, and PLMN ID of the AMF.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP GNBCUNGINTERFACE

Use this command to query the information about an NG interface, such as the information about the CP, NG interface status, and peer AMF. If the status of an NG interface is abnormal, the command output displays the information of the peer AMF in the last normal connection with the local gNodeB.
RST GNBCUNGINTERFACE

Use this command to restart the gNodeB CU NG interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB CU NG Interface ID

Indicates the ID of a gNodeB CU NG interface.
gNodeB CU NG Interface CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU NG interface.
Served GUAMIs

Indicates the globally unique AMF ID (GUAMI) of the AMF connected over the NG interface. Each ID is represented by MCC-MNC-AMF Region ID-AMF Set ID-AMF Pointer. The GUAMIs of each serving core network are separated by commas (,).
AMF Name

Indicates the name of the AMF connected over the NG interface. This parameter is valid after the NG interface is established and the AMF name is contained in the NG interface establishment response message or the AMF configuration update message. In other conditions, the parameter value is NULL. For details, see 3GPP TS 38.413.
gNodeB Operator ID

Indicates the list of IDs of the operators that own the NG interface. Operator IDs are separated by commas (,).
