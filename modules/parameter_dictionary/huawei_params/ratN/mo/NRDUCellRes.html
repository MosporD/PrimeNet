NRDUCellRes

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellRes

Description

This MO is used to configure the resources of an NR DU cell, including uplink RBs and downlink RBs. The configured resources can be added to a resource use object for resource control. When configured resources are added to an operator group, this MO specifies the uplink and downlink RBs of the operator group in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellAlgoSwitch and NRDUCellOp MOs:
    • When RB_DYNAMIC_SHARING_SW of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO has been configured, neither DlRbAverageRatio nor UlRbAverageRatio in an NRDUCellRes MO associated with CellResId in an NRDUCellOp MO can be set to 255.
    • When MAX_RB_LIMIT_SW of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO is selected and the NRDUCellOp MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO has been configured, neither DlRbMaxRatio nor UlRbMaxRatio in an NRDUCellRes MO associated with CellResId in an NRDUCellOp MO can be set to 255.
  • Relation with the NRDUCellOp MO:
    • If CellResId in an NRDUCellOp MO is not set to 255, the NRDUCellRes MO associated with NrDuCellId and CellResId must have been configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Cell Resource ID

Indicates the resource ID of an NR DU cell.
Downlink RB Max Ratio

Indicates the maximum proportion of PDSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the maximum proportion of downlink PDSCH RBs that can be used by UEs served by an operator is not configured.
Downlink RB Average Ratio

Indicates the average proportion of PDSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the average proportion of downlink PDSCH RBs that can be used by UEs served by an operator is not configured.
Uplink RB Max Ratio

Indicates the maximum proportion of PUSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the maximum proportion of uplink PUSCH RBs that can be used by UEs served by an operator is not configured.
Uplink RB Average Ratio

Indicates the average proportion of PUSCH RBs that can be used by UEs served by an operator in a cell. If this parameter is set to 255, the average proportion of uplink PUSCH RBs that can be used by UEs served by an operator is not configured.
