NRCellComp

+-gNodeBFunction
  +-NRCell

Description

This MO consists of parameters related to CoMP.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRCELLCOMP

Use this command to list the CoMP parameter settings of an NR cell.
MOD NRCELLCOMP

Use this command to modify the CoMP parameter settings of an NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Overlapping RSRP Offset

Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the overlapping area measurement event.
UL CoMP RSRP Offset

Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the UL CoMP or SUL CoMP measurement event.
DL CoMP RSRP Offset

Indicates the positive RSRP offset for a neighboring cell relative to that for the serving cell used in the DL CoMP measurement event.
Time to Trigger

Indicates the time-to-trigger for CoMP-related measurement events. Set this parameter to reduce the probability of occasional event triggering.
Hysteresis

Indicates the hysteresis for CoMP-related measurement events. Set this parameter to reduce frequent event triggering and incorrect decisions caused by radio signal fluctuation.
SUL CoMP SRS RSRP Offset

Indicates the positive SRS RSRP offset for a neighboring cell relative to that for the serving cell used to trigger SUL CoMP.
