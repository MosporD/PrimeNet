gNBNrLteCellComb

+-gNodeBFunction
  +-gNBNrLteCellComb

Description

This MO is used to configure an NR and LTE cell combination in NSA networking.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBNRLTECELLCOMB

Use this command to add a gNodeB NR-LTE cell combination.
LST GNBNRLTECELLCOMB

Use this command to list gNodeB NR-LTE cell combinations.
MOD GNBNRLTECELLCOMB

Use this command to modify a gNodeB NR-LTE cell combination.
RMV GNBNRLTECELLCOMB

Use this command to remove a gNodeB NR-LTE cell combination.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR MCC

Indicates the MCC of the NR network operator.
NR MNC

Indicates the MNC of the NR network operator.
gNodeB ID

Indicates the ID of the gNodeB serving the NR cell.
Cell ID

Indicates the cell ID of an NR cell. A cell ID and a gNodeB ID compose a 3GPP-defined NR Cell Identity (NCI). A 3GPP-defined NCI and a PLMN ID compose an NR cell global identifier (NCGI). For details, see 3GPP TS 38.413.
LTE MCC

Indicates the MCC of the LTE network operator.
LTE MNC

Indicates the MNC of the LTE network operator.
eNodeB ID

Indicates the ID of the eNodeB serving the LTE cell.
LTE Cell ID

Indicates the E-UTRAN cell ID. It uniquely identifies an E-UTRAN cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The E-UTRAN cell global identifier (ECGI) is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Aggregation Attribute

Indicates the aggregation attributes of an LTE and NR co-deployment cell combination in NSA networking.

CO_DEPLOYMENT_NSA_FLAG: Indicates whether the current LTE and NR cell pair is a co-deployment cell pair. If this option is selected, NSA DC is allowed in the current LTE and NR cell pair in the co-deployment frequency band combination. If this option is deselected, NSA DC is not allowed in the current LTE and NR cell pair in the co-deployment frequency band combination.
