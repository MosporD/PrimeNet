gNBDedNsaDcBandComb

+-gNodeBFunction
  +-gNBDedNsaDcBandComb

Description

This MO is used to indicate a dedicated NSA DC band combination for a base station.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBDEDNSADCBANDCOMB

Use this command to add a dedicated NSA DC band combination for the gNodeB.
LST GNBDEDNSADCBANDCOMB

Use this command to list dedicated NSA DC band combinations for the gNodeB.
MOD GNBDEDNSADCBANDCOMB

Use this command to modify a dedicated NSA DC band combination for the gNodeB.
RMV GNBDEDNSADCBANDCOMB

Use this command to remove a dedicated NSA DC band combination from the gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Band ID

Indicates ID of an NR band in a band combination. For details, see 3GPP TS 38.101-1 and 38.101-2.
LTE Band ID

Indicates ID of an LTE band in a band combination. For details, see 3GPP TS 36.101.
Aggregation Attribute

Indicates the aggregation attribute switches for LTE and NR band combinations.

CO_DEPLOYMENT_NSA_FLAG: If this option is selected, mobility management procedures specific to collocated deployment are allowed for the frequency band combination. If this option is deselected, mobility management procedures specific to collocated deployment are not allowed for the frequency band combination.

SINGLE_UL_NSA_FLAG: If this option is selected, single-RAT uplink transmission is allowed for the frequency band combination in NSA DC scenarios. If this option is deselected, single-RAT uplink transmission is not allowed for the frequency band combination in NSA DC scenarios.
