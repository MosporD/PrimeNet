Description

An NRCell MO defines information such as the cell ID. It is configured by network planning engineers based on site requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Relation with the NRDUCellSul, NRDUCellTrp, and NRDUCell MOs:
    • If CellActiveState in the NRCell MO corresponding to SulNrDuCellId in the NRDUCellSul MO is CELL_ACTIVE, BasebandEqmId in the NRDUCellTrp MO under the NRDUCell MO corresponding to NRCell must be the same as BasebandEqmId in the NRDUCellTrp MO under the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO or be set to 255.
  • Relation with the NRDUCell, NRDUCellTrp, and NRDUCellCoverage MOs:
    • If CellActiveState in an NRCell MO is set to CELL_ACTIVE, an NRDUCell MO must already be configured and CellId in this NRDUCell MO must be set to the same value as CellId in the NRCell MO. In addition, the NRDUCell MO must be configured with at least one NRDUCellTrp MO and one NRDUCellCoverage MO.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and TrpType in the NRDUCellTrp MO corresponding to the NRDUCell MO is set to MASTER_8T8R or MASTER_4T4R, at least one NRDUCellCoverage MO must be configured for the NRDUCellTrp MO instance with TrpType set to SLAVE.
  • Relation with the NRDUCellSul, NRDUCell, NRDUCellTrp, and NRDUCellCoverage MOs:
    • If the value of CellActiveState in an NRCell MO is CELL_ACTIVE, an NRDUCell MO must have been configured and CellId in this NRDUCell MO must be set to the same value as CellId in the NRCell MO. If the NRDUCell MO is configured with an NRDUCellSul MO, the NRDUCell MO corresponding to each NRDUCellSul MO must be configured with at least one NRDUCellTrp MO and each NRDUCellTrp MO must be configured with at least one NRDUCellCoverage MO.
  • Relation with the gNodeBFunction MO:
    • When CellId in an NRCell MO is set to a value other than 65535, the value of this parameter must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the NRCellQciBearer MO:
    • The instance with Qci set to 9 must always exist.
  • Relation with the NRDUCell MO:
    • If the value of CellActiveState in an NRCell MO is CELL_ACTIVE, and DuplexMode in the corresponding NRDUCell MO with the same CellId is not set to CELL_SUL, then the value of DuplexMode in the NRCell MO must be the same as the value of DuplexMode in the corresponding NRDUCell MO, and the value of FrequencyBand in the NRCell MO must be the same as the value of FrequencyBand in the corresponding NRDUCell MO.
  • Relation with the NRCellEutranNFreq MO:
    • A maximum of 64 NRCellEutranNFreq instances can be configured for each NRCell.
  • Relation with the NRCellRelation MO:
    • The serving cell specified by NrCellId in an NRCellRelation MO can be configured with a maximum of 384 neighboring cells.
  • Relation with the gNBSharingMode, NRCellRelation, gNodeBFunction, and gNBOperator MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, the CGI of the serving cell specified by NrCellId in an NRCellRelation MO must not be identical with the CGIs of neighboring cells specified by CellId in the NRCellRelation MO. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the gNodeBFunction, gNBOperator, NRCellRelation, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and intra-site cells are configured as neighboring cells of each other in the NRCellRelation MOs, a neighboring cell specified by CellId in the NRCellRelation MOs and the serving cell must already be configured. In addition, an NRCell MO referenced by CellId, Mcc, and Mnc of the neighboring cell must already be configured.
  • Relation with the NRCellAlgoSwitch MO:
    • If DuplexMode in an NRCell MO is set to CELL_FDD, the UL_DELAY_COV_OPT_SW option of VonrSwitch in the NRCellAlgoSwitch MO must be deselected.
  • Relation with the NRCellFreqRelation MO:
    • A maximum of 16 NRCellFreqRelation MO instances can be configured for each NRCell MO.
  • Relation with the NRCellFreqRelation and NRDUCell MOs:
    • If SsbDescMethod is set to SSB_DESC_TYPE_GSCN, the value of SsbFreqPos in the NRCellFreqRelation MO must be different from the value of SsbFreqPos in the NRDUCell MO corresponding to the associated NRCell MO when SsbDescMethod in the NRDUCell MO is set to SSB_DESC_TYPE_GSCN, or from the GSCN mapped to the value of SsbFreqPos when SsbDescMethod is set to SSB_DESC_TYPE_NARFCN.
    • Similarly, if SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, the value of SsbFreqPos in the NRCellFreqRelation MO must be different from the value of SsbFreqPos in the NRDUCell MO corresponding to the associated NRCell MO when SsbDescMethod in the NRDUCell MO is set to SSB_DESC_TYPE_NARFCN, or from the NR-ARFCN mapped to the value of SsbFreqPos when SsbDescMethod is set to SSB_DESC_TYPE_GSCN.
  • Relation with the NRCellEutraNRelation MO:
    • The serving cell specified by NrCellId in an NRCellEutraNRelation MO can be configured with a maximum of 384 E-UTRAN neighboring cells.
  • Relation with the NRCellInterRHoMeaGrp MO:
    • A maximum of 15 NRCellInterRHoMeaGrp MO instances can be configured for each NRCell MO.
  • Relation with the NRCellHoEutranMeaGrp MO:
    • A maximum of 15 NRCellHoEutranMeaGrp MO instances can be configured for each NRCell MO.
  • Relation with the NRCellIntraFHoMeaGrp MO:
    • A maximum of 15 NRCellIntraFHoMeaGrp MO instances can be configured for each NRCell MO.
  • Relation with the NRCellRelation, gNodeBFunction, NRDUCell, gNBOperator, and gNBSharingMode MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to OFF and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which is referenced by NrCellId in an NRCellRelation MO. The values of Mcc and Mnc in this NRCellRelation MO are the same as Mcc and Mnc in the gNBOperator MO, respectively. gNBId in this NRCellRelation MO is the same as gNBId in the gNodeBFunction MO. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with CellId in the NRCellRelation MO, and DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRCellRelation, NRExternalNCell, and NRDUCell MOs:
    • The NRDUCell and NRExternalNCell MO instances meet the following conditions: 1. The NRDUCell MO instance is associated with CellId in an NRCell MO, which is correlated with the NRCellRelation MO through NrCellId. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. 2. The values of Mcc, Mnc, gNBId, and CellId in the NRCellRelation MO are equal to their counterparts in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is the same as the value of SsbDescMethod in the NRExternalNCell MO, the value of SsbFreqPos in the NRDUCell MO must be different from the value of SsbFreqPos in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is different from the value of SsbDescMethod in the NRExternalNCell MO, the NR-ARFCN corresponding to SsbFreqPos in the NRDUCell MO must be different from the NR-ARFCN corresponding to SsbFreqPos in the NRExternalNCell MO.
  • Relation with the gNBSharingMode, NRDUCell, and NRDUCellOp MOs:

    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the CellPrimaryOpFlag parameter must be set to TRUE in one of the NRDUCellOp MOs corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO.
    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the CellPrimaryOpFlag parameter in the NRDUCellOp MO corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO can only be set to FALSE.
  • Relation with the gNBSharingMode, NRDUCell, NRDUCellOp, and gNBOperator MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and gNBMultiOpSharingMode is set to SHARED_FREQ, the NRDUCellOp MO corresponding to NrDuCellId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured. In addition, there must be a gNBOperator MO specified by OperatorId with OperatorType set to PRIMARY_OPERATOR.
    • When CellActiveState in an NRCell MO is set to CELL_ACTIVE and MultipleNCISwitch in the gNBSharingMode MO is set to ON, CellId in the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO must be different from the 3GPP-defined NR Cell Identity (NCI) determined based on gNBId and gNBIdLength in the gNBOperator MO associated with OperatorId in the NRDUCellOp MO. This rule applies to all the NRDUCellOp MOs corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO.

  • Relation with the NRDUCellAlgoSwitch, NRDUCellTrp, and NRDUCell MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and TrpType in the NRDUCellTrp MO is set to MASTER_8T8R or MASTER_4T4R, VmimoSwitch in the NRDUCellAlgoSwitch MO must be set to ON.
  • Relation with the NRCellOpPolicy, NRDUCellOp, and NRDUCell MOs:
    • The value of OperatorId in an NRCellOpPolicy MO must have been configured in all the NRDUCellOp MOs corresponding to the NRDUCell MO associated with CellId in the NRCell MO corresponding to the NRCellOpPolicy MO.
  • Relation with the NRCellInterRHoMeaGrp, gNBSharingMode, NRCellQciBearer, gNBOperator, gNBOperatorQciParam, NRDUCell, and NRDUCellOp MOs:

All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
  • Relation with the NRCellOpPolicy, NRCellFreqRelation, gNBFreqPriorityGroup, and NRDUCell MOs:
    • The combination of SsbFreqPos and SsbDescMethod in the gNBFreqPriorityGroup MO corresponding to gNBFreqPriorityGroupId in an NRCellOpPolicy MO must already be existent in the NRCellFreqRelation MO corresponding to NrCellId in the NRCellOpPolicy MO or in the NRDUCell MO corresponding to NrCellId in the NRCellOpPolicy MO.
  • Relation with the NRDUCellPrach, NRCellNsaDcConfig, and NRDUCell MOs:
    • If the SINGLE_UL_NSA_SW option of NsaDcAlgoSwitch in the NRCellNsaDcConfig MO is selected, PrachConfigurationIndex in the associated NRDUCellPrach MO must be set to 1, 2, 5, 6, 9, 10, 13, 14, 17, 18, or 21.
  • Relation with the NRDUCell and NRDUCellTrp MOs:
    • When CellActiveState in an NRCell MO corresponding to CellId in an NRDUCell MO is CELL_ACTIVE, if FrequencyBand in the NRDUCell MO is set to N257, N258, N260, or N261, PowerConfigMode in the associated NRDUCellTrp MO must be set to EIRP. Otherwise, if TxRxMode in the NRDUCellTrp MO corresponding to the NRDUCell MO is not set to 2R or 4R, PowerConfigMode in the NRDUCellTrp MO must be set to TRANSMIT_POWER.
  • Relation with the NRDUCellTrp, NRDUCell, and NRDUCellAlgoSwitch MOs:
    • If CellActiveState in an NRCell MO is set to CELL_ACTIVE, an NRDUCell MO exists. If TrpType in the corresponding NRDUCellTrp MO is set to DEFAULT, no NRDUCellTrp MO with TrpType set to SLAVE can exist, and VmimoSwitch in the NRDUCellAlgoSwitch MO must be set to OFF. If TrpType in the NRDUCellTrp MO is set to MASTER_8T8R or MASTER_4T4R, there must be an NRDUCellTrp MO instance with TrpType set to SLAVE.
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If CellActiveState in an NRCell MO is set to CELL_ACTIVE, an NRDUCell MO exists. If TrpType in the corresponding NRDUCellTrp MO is set to MASTER_8T8R, TxRxMode in the associated NRDUCellTrp MO must be set to 4T4R. In addition, TxRxMode in another NRDUCellTrp MO must be set to 4T4R if the TrpType parameter in this NRDUCellTrp MO is set to SLAVE.
    • If TrpType in the corresponding NRDUCellTrp MO is set to MASTER_4T4R, TxRxMode in the associated NRDUCellTrp MO must be set to 2T2R. In addition, TxRxMode in another NRDUCellTrp MO must be set to 2T2R if the TrpType parameter in this NRDUCellTrp MO is set to SLAVE.
    • If CellActiveState in the NRCell MO corresponding to CellId in the NRDUCell MO is CELL_ACTIVE and NrDuCellNetworkingMode in the NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, the number of NRDUCellTrp MOs corresponding to NrDuCellId in the NRDUCell MO must be greater than 1.
  • Relation with the gNBSharingMode, NRCellRelation, gNBOperator, NRDUCell, and NRDUCellOp MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the NR CGI of the serving cell (consisting of Mcc, Mnc, gNBId, and CellId corresponding to OperatorId in the NRDUCellOp MO with CellPrimaryOpFlag set to TRUE associated with the NRDUCell MO corresponding to NrCellId in the NRCellRelation MO) must not be identical with the CGIs of neighboring cells. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the NRCellRelation, NRDUCell, gNBOperator, NRDUCellOp, and gNBSharingMode MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to ON and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which referenced by NrCellId in an NRCellRelation MO. The combination of gNBId, Mcc, and Mnc in this NRCellRelation MO has been configured in the gNBOperator. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with NrDuCellId in the NRDUCellOp MO in which the combination of OperatorId and CellId corresponding to Mnc and Mcc in the NRCellRelation MO has been configured. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRCell MO:

    • If BRDSPEC in the MPT is set to UMPTe, the board type is UMPTe.

    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCell MO instances must be less than or equal to 144.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCell MO instances must be less than or equal to 72.
    • When the board type is UMPTga and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCell MO instances must be less than or equal to 36.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCell MO instances cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCell MO instances must be less than or equal to 72.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCell MO instances must be less than or equal to 36.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCell MO instances cannot be added.
  • Relation with the NRDUCell, NRDUCellTrpMmwavBeam, NRDUCellCoverage, SECTOREQM, and NRDUCellTrp MOs:

Function
ACT NRCELL

Use this command to activate an NR cell.
ADD NRCELL

Use this command to add an NR cell.
DEA NRCELL

Use this command to deactivate an NR cell.
DSP NRCELL

Use this command to query the dynamic information of NR cells.
DSP NRCELLPCICONFLICT

Use this command to query the PCI conflict records of an NR cell.
LST NRCELL

Use this command to list the static attributes of NR cells.
MOD NRCELL

Use this command to modify the configurations of an NR cell.
RMV NRCELL

Use this command to remove an NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Cell Name

Indicates the name of an NR cell.
Cell ID

Indicates the cell ID of an NR cell. A cell ID and a gNodeB ID compose a 3GPP-defined NR Cell Identity (NCI). A 3GPP-defined NCI and a PLMN ID compose an NR cell global identifier (NCGI). For details, see 3GPP TS 38.413.
Frequency Band

Indicates the frequency band in which an NR cell operates. For details, see 3GPP TS 38.104.
Duplex Mode

Indicates the duplex mode of an NR cell. CELL_FDD indicates the FDD mode, and CELL_TDD indicates the TDD mode.
User Label

Indicates the user label of an NR cell.
Cell Activate State

Indicates the activation state of an NR cell.
