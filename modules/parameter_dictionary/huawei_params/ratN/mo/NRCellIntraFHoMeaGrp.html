NRCellIntraFHoMeaGrp

+-gNodeBFunction
  +-NRCell
    +-NRCellIntraFHoMeaGrp

Description

An NRCellIntraFHoMeaGrp MO defines a group of measurement parameters related to intra-RAT intra-frequency handover. Handover measurement parameter settings can be QCI-specific to meet various requirements of services for target cells. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellQciBearer MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellIntraFHoMeaGrp MO, the value of IntraFreqHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellIntraFHoMeaGrp MO.
  • Relation with the NRCell MO:
    • A maximum of 15 NRCellIntraFHoMeaGrp MO instances can be configured for each NRCell MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Intra-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to intra-frequency handover.
Intra-frequency Handover A3 Offset

Indicates the offset for event A3 related to intra-frequency handover. If the measured and reported RSRP value of an intra-frequency neighboring cell is greater than the offset specified by this parameter throughout the corresponding time-to-trigger, UEs send event A3 measurement reports. For details, see 3GPP TS 38.331.
Intra-frequency Handover A3 Hysteresis

Indicates the hysteresis for event A3 related to intra-frequency handover. For details, see 3GPP TS 38.331.
Intra-frequency Handover A3 Time To Trigger

Indicates the time-to-trigger for event A3 related to intra-frequency handover. When the entering conditions for event A3 related to intra-frequency handover are met, a UE does not immediately send an event A3 report. Instead, a UE sends an event A3 report only if the entering conditions are met throughout the corresponding time-to-trigger. For details, see 3GPP TS 38.331.
