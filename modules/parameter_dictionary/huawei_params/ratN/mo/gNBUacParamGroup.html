gNBUacParamGroup

+-gNodeBFunction
  +-gNBUacParamGroup

Description

The gNBUacParamGroup MO defines parameters related to access control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRDUCellUacBar MO:
    • AccessControlParamGrpId in the NRDUCellUacBar MO must be set to the value configured in the gNBUacParamGroup MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBUACPARAMGROUP

Use this command to add a gNodeB UAC parameter group.
LST GNBUACPARAMGROUP

Use this command to list one or more gNodeB UAC parameter groups.
MOD GNBUACPARAMGROUP

Use this command to modify a gNodeB UAC parameter group.
RMV GNBUACPARAMGROUP

Use this command to remove a gNodeB UAC parameter group.

Description
Access Control Parameter Group ID

Indicates the ID of an access control parameter group.
Barring State for Special Access ID

Indicates whether access barring check is required for UEs with a special access ID. During an access barring check, the uac-BarringFactor and uac-BarringTime IEs in SIB1 determine whether an access attempt is allowed. For details, see 3GPP TS 38.331.

ACCESS_ID1_BAR_STATE: If this option is selected, access barring check is required for the access attempt of UEs with Access Identity 1, and the UEs determine whether the access attempt is allowed based on the check result.
