NRDUCellPusch

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellPusch

Description

The NRDUCellPusch MO defines parameters related to PUSCH resources in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured and NrDuCellNetworkingMode in the NRDUCell MO is not set to HYPER_CELL or HYPER_CELL_COMBINE_MODE: (1) When FrequencyBand in the NRDUCell MO is set to N257, N258, N260, or N261 and TxRxMode in the NRDUCellTrp MO is set to 8T8R or 4T4R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2 or LAYER_4. (2) When FrequencyBand in the NRDUCell MO is set to N257, N258, N260, or N261 and TxRxMode in the NRDUCellTrp MO is set to 2T2R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2.
    • If the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured and NrDuCellNetworkingMode in the NRDUCell MO is not set to HYPER_CELL or HYPER_CELL_COMBINE_MODE: (1) When FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261 and TxRxMode in the NRDUCellTrp MO is set to 64T64R or 32T32R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2, LAYER_4, LAYER_6, or LAYER_8. (2) When FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, TrpType in the NRDUCellTrp MO is set to DEFAULT, and TxRxMode in the NRDUCellTrp MO is set to 4R, 4T4R, 8T8R, or 2T4R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2 or LAYER_4. (3) When FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, TrpType in the NRDUCellTrp MO is set to DEFAULT and TxRxMode in the NRDUCellTrp MO is set to 2R or 2T2R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2.
    • If the NRDUCell MO corresponding to the NrDuCellId parameter in the NRDUCellTrp MO has been configured and NrDuCellNetworkingMode in the NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, the following must be true: (1) If FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261 and TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO is set to 64T64R or 32T32R, MaxMimoLayerCnt in the NRDUCellPusch MO can be set to LAYER_2, LAYER_4, LAYER_6, or LAYER_8. (2) If FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, and the values of TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO include 4R, 4T4R, 8T8R, or 2T4R and do not include 64T64R or 32T32R, MaxMimoLayerCnt in the NRDUCellPusch MO can be set to LAYER_2 or LAYER_4. (3) If FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, and TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO is set to 2R or 2T2R, MaxMimoLayerCnt in the NRDUCellPusch MO must be set to LAYER_2.
  • Relation with the NRDUCell MO:
    • If UlBandwidth in an NRDUCell MO is set to CELL_BW_20M or CELL_BW_30M, the value of UlVonrRsvdRbNum in the associated NRDUCellPusch MO cannot be greater than N10.
    • If UlBandwidth in an NRDUCell MO is set to CELL_BW_40M, the value of UlVonrRsvdRbNum in the associated NRDUCellPusch MO cannot be greater than N20.
    • If UlBandwidth in an NRDUCell MO is set to CELL_BW_50M, the value of UlVonrRsvdRbNum in the associated NRDUCellPusch MO cannot be greater than N25.
    • If UlBandwidth in an NRDUCell MO is set to CELL_BW_60M, the value of UlVonrRsvdRbNum in the associated NRDUCellPusch MO cannot be greater than N30.
    • If UlBandwidth in an NRDUCell MO is set to CELL_BW_70M, the value of UlVonrRsvdRbNum in the associated NRDUCellPusch MO cannot be greater than N35.
    • When HighSpeedFlag in the NRDUCell MO is set to HIGH_SPEED, UlAdditionalDmrsPos in the NRDUCellPusch MO must be set to POS2 or POS1.
  • Relation with the NRDUCellTrp, NRDUCell, and NRDUCellPdsch MOs:
    • When the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, the following must be true: If TrpType in the NRDUCellTrp MO is set to MASTER_8T8R and TxRxMode in the NRDUCellTrp MO is set to 4T4R, the value range of MaxMimoLayerNum in the NRDUCellPdsch MO is LAYER_2, LAYER_4, LAYER_6, LAYER_8, and LAYER_DEFAULT; if TrpType in the NRDUCellTrp MO is set to MASTER_4T4R and TxRxMode in the NRDUCellTrp MO is set to 2T2R, the value range of MaxMimoLayerNum in the NRDUCellPdsch MO is LAYER_2, LAYER_4, and LAYER_DEFAULT. When the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, the following must be true: If TrpType in the NRDUCellTrp MO is set to MASTER_8T8R and TxRxMode in the NRDUCellTrp MO is set to 4T4R, the value range of MaxMimoLayerCnt in the NRDUCellPusch MO is LAYER_2, LAYER_4, LAYER_6, and LAYER_8; if TrpType in the NRDUCellTrp MO is set to MASTER_4T4R and TxRxMode in the NRDUCellTrp MO is set to 2R or 2T2R, the value range of MaxMimoLayerCnt in the NRDUCellPusch MO is LAYER_2 and LAYER_4.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Initial Uplink SINR Adjustment

Indicates the initial uplink SINR adjustment value of UEs that are not paired. For paired UEs, the initial uplink SINR adjustment value is fixed to 0 dB.
Uplink DMRS Type

Indicates the uplink DMRS type. For details, see 3GPP TS 38.331 and 3GPP TS 38.211. This parameter takes effect only for UEs that initially access the network. If this parameter is set to TYPE2, this value applies only to low-frequency cells.
Uplink Additional DMRS Position

Indicates the position of the uplink additional DMRS (number of hidden symbols). When this parameter is set to NOT_CONFIG, no additional DMRS is configured for the uplink. When this parameter is set to POS1, the number of uplink additional DMRS symbols is 1. When this parameter is set to POS2, the number of uplink additional DMRS symbols is 2. This parameter takes effect only for UEs that newly access the network.
Uplink Maximum MIMO Layer Count Quota

Indicates the maximum transport layer count quota for spatial multiplexing in uplink MIMO of a cell. This parameter does not take effect for low-frequency NR DU cells with NRDUCellTrp.TxRxMode set to 1T1R, 2R, 4R, 2T2R, 2T4R, 4T4R, or 8T8R. In this case, the maximum number of layers for uplink MIMO depends on the number of receive antennas in the cell.
Uplink PUSCH Algorithm Switch

Indicates whether to enable functions related to uplink PUSCH scheduling.

UL_PAMC_SWITCH: Indicates whether to enable uplink PAMC.

MSG3_TRANSFORMPRECODE_SWITCH: Indicates whether to configure a single carrier for the first uplink transmission and retransmission, for DCI_0_0 transmission, and when the transformPrecoder IE is not configured in PUSCH-Config. When this option is selected, the single-carrier waveform applies in the uplink for the UE. When this option is deselected, the multi-carrier waveform applies in the uplink for the UE.
Uplink Target IBLER

Indicates the uplink target IBLER when the uplink IBLER adaption algorithm is disabled.
SINR Threshold for Waveform Selection

Indicates the SINR threshold for waveform selection. The UE uses DFT-s-OFDM only when the SINR of the UE is less than this threshold.
UL VoNR Reserved RB Number

Indicates the number of RB resources reserved for VoNR in the uplink. This parameter takes effect only when the UL_RB_RSV_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected. This parameter applies only to low-frequency cells.
UL VoNR Reserved RB Start Position

Indicates the start position of RB resources reserved for VoNR in the uplink. This parameter takes effect only when the UL_RB_RSV_SW option of the NRCellAlgoSwitch.VonrSwitch parameter is selected. This parameter applies only to low-frequency cells.
Uplink Preallocation Switch

Indicates whether to enable uplink preallocation.

UL_BASIC_PREALLOCATION_SWITCH: Indicates whether to enable uplink basic preallocation.

UL_SMART_PREALLOCATION_SWITCH: Indicates whether to enable uplink smart preallocation.
Uplink Smart Preallocation Duration

Indicates the duration for uplink smart preallocation.
