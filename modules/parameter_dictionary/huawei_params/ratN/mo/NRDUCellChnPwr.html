NRDUCellChnPwr

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellChnPwr

Description

This MO consists of cell-level common configurations related to NR downlink power control.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCell and NRDUCellPdsch MOs:
    • If FrequencyBand in an NRDUCell MO is not set to N257, N258, N260, or N261 and the TRS_RATEMATCH_SW option of RateMatchSwitch in the associated NRDUCellPdsch MO is deselected, TrsPwrOffset in the NRDUCellChnPwr MO corresponding to NrDuCellId in the NRDUCellPdsch MO must be set to 0.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLCHNPWR

Use this command to list the configuration of channel power in an NR DU cell.
MOD NRDUCELLCHNPWR

Use this command to modify the configuration of channel power in an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Maximum Converged PDSCH Power

Indicates the maximum power offset of the PDSCH power relative to the reference power in the PDSCH power aggregation algorithm. This parameter applies only to low-frequency cells and takes effect only when the PDCCH_RATEMATCH_SW option of the NRDUCellPdsch.RateMatchSwitch parameter is deselected.
Maximum Common DCI Power Offset

Indicates the maximum offset of the power of DCI in common search space relative to the reference power after DCI power aggregation in the common search space of a cell is performed. The actual effective value may be lower than the configured value because of the constraints of the power aggregation capability of the intermediate frequency (IF) and radio frequency (RF) or the power resource constraints during scheduling.
TRS Power Offset

Indicates the maximum offset of the TRS channel power relative to the reference power after TRS power aggregation of a cell is performed. The actual effective value may be lower than the configured value because of the constraints of the power aggregation capability of the intermediate frequency (IF) and radio frequency (RF) or the power resource constraints during scheduling.
