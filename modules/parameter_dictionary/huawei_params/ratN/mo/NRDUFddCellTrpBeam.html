NRDUFddCellTrpBeam

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUFddCellTrpBeam

Description

This MO defines parameters related to FDD beams such as the coverage scenario and maximum power aggregation capability.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp
  • Relation with the NRDUCell and NRDUCellTrp MOs:
    • If DuplexMode in an NRDUCell MO is set to CELL_FDD and TxRxMode in the NRDUCellTrp MO is set to 4T4R, CoverageScenario in the NRDUFddCellTrpBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT or SCENARIO_201. If DuplexMode in an NRDUCell MO is not set to CELL_FDD or TxRxMode in the NRDUCellTrp MO is not set to 4T4R, CoverageScenario in the NRDUFddCellTrpBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT.
  • Relation with the NRDUCellAlgoSwitch and NRDUCellTrp MOs:
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in the NRDUCellAlgoSwitch MO is selected and CoverageScenario in the NRDUFddCellTrpBeam MO is set to SCENARIO_201, MaxSsbPwrOffset in the NRDUFddCellTrpBeam MO must be set to 0.
  • Relation with the NRDUCellAlgoSwitch, NRDUCellPdsch, and NRDUCellTrp MOs:
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in the NRDUCellAlgoSwitch MO is selected and the SSB_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO corresponding to the cell is selected, CoverageScenario in the NRDUFddCellTrpBeam MO corresponding to the cell must be set to DEFAULT.
  • Relation with the NRCell, NRDUCell, NRDUCellTrp, NRDUCellTrpBeam, and NRDUCellTrpMmwavBeam MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR1_TDD, the NRDUCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR2_TDD, the NRDUCellTrpMmwavBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FDD, the NRDUFddCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.

Function

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell.
Coverage Scenario

Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. This parameter applies only to FDD.
Max SSB Power Offset

Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to FDD.
