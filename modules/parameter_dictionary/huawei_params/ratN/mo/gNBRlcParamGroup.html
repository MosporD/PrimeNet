gNBRlcParamGroup

+-gNodeBFunction
  +-gNBRlcParamGroup

Description

A gNBRlcParamGroup MO consists of parameters required for radio link control (RLC) entities. The RLC layer provides data transmission in acknowledged mode (AM), unacknowledged mode (UM), or transparent mode (TM).

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNodeBFunction MO:
    • The eight default instances of gNBRlcParamGroup corresponding to RlcParamGroupId ranging from 0 to 7 cannot be deleted.
  • Relation with the NRDUCellQciBearer MO:
    • RlcMode in a gNBRlcParamGroup MO corresponding to AmRlcParamGroupId in an NRDUCellQciBearer MO must be set to AM.
    • RlcMode in a gNBRlcParamGroup MO corresponding to UmRlcParamGroupId in an NRDUCellQciBearer MO must be set to UM.
    • The value of AmRlcParamGroupId in an NRDUCellQciBearer MO must have been configured in a gNBRlcParamGroup MO.
    • The value of UmRlcParamGroupId in an NRDUCellQciBearer MO must have been configured in a gNBRlcParamGroup MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RLC Parameter Group ID

Indicates the ID of an RLC parameter group.
RLC Mode

Indicates the RLC transmission mode, which can only be AM or UM.
UE AM Byte Num Threshold for Trig Polling

Indicates the UE-specific threshold of the PDU data volume to trigger polling. When the data volume of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.
gNodeB AM Byte Num Threshold for Trig Polling

Indicates the gNodeB-specific threshold of the PDU data volume to trigger polling. When the data volume of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.
UE PDU Num Threshold for Trig Polling

Indicates the UE-specific threshold of the PDU number to trigger polling. When the number of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.
gNodeB PDU Num Threshold for Trig Polling

Indicates the gNodeB-specific threshold of the PDU number to trigger polling. When the number of transmitted PDUs reaches the value of this parameter, the Poll flag is set in the PDU header. It is recommended that this parameter be modified under the guidance of Huawei technical support.
Polling PDU Retransmission Timer for UE

Indicates the length of the polling PDU retransmission timer for the UE. It is recommended that this parameter be modified under the guidance of Huawei technical support.
Polling PDU Retransmission Timer for gNodeB

Indicates the length of the polling PDU retransmission timer for the gNodeB. It is recommended that this parameter be modified under the guidance of Huawei technical support.

Indicates the length of the gNodeB-specific timer for RLC reassembly. It is recommended that this parameter be modified under the guidance of Huawei technical support.
RLC Reassembly Timer for UE

Indicates the length of the UE-specific timer for reassembly. It is recommended that this parameter be modified under the guidance of Huawei technical support.
Downlink RLC SN Size

Indicates the size of a downlink RLC sequence number for the gNodeB and UE.
Uplink RLC SN Size

Indicates the size of an uplink RLC sequence number for the gNodeB and UE.
