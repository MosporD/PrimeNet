gNBEutraExternalCell

+-gNodeBFunction
  +-gNBEutraExternalCell
    +-gNBEutraExtCellPlmn[0~5]

Description

A gNBEutraExternalCell MO consists of the parameters related to an external E-UTRAN cell, which can be configured as a neighboring cell for one or more cells served by the local gNodeB. The E-UTRAN neighbor cell list (NCL) of a gNodeB contains the common information about external E-UTRAN cells. If an E-UTRAN external cell works in RAN sharing mode, their PLMN IDs must be added.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

  • Possible children:

    gNBEutraExtCellPlmn[0~5]
  • Relation with the NRCellEutranNFreq MO:
    • DlEarfcn in a gNBEutraExternalCell MO must be set to a value configured in the associated NRCellEutranNFreq MO.
  • Relation with the NRCellEutraNRelation MO:
    • The gNBEutraExternalCell MO corresponding to an NRCellEutraNRelation MO must have been configured.
  • Relation with the gNBEutraExtCellPlmn MO:
    • A maximum of five gNBEutraExtCellPlmn MO instances can be configured for each gNBEutraExternalCell MO.
  • Relation with the gNBNCellPlmnList MO:
    • If the values of Mnc and Mcc in the gNBEutraExternalCell MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to EUTRAN, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
    • In all the gNBNCellPlmnList MOs with RatType set to EUTRAN, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of Mnc and Mcc in all the gNBEutraExternalCell MOs configured for the local gNodeB must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to EUTRAN, respectively.
  • Relation with the NRCellEutraNRelation and NRCellEutranNFreq MOs:
    • The value of DlEarfcn in a gNBEutraExternalCell MO corresponding to an NRCellEutraNRelation MO must be the same as the value of DlEarfcn in an NRCellEutranNFreq MO corresponding to the NRCellEutraNRelation MO.
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the gNBEutraExternalCell cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe. If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of gNBEutraExternalCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of gNBEutraExternalCell MO instances must be less than or equal to 144 x 32.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of gNBEutraExternalCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of gNBEutraExternalCell MO instances must be less than or equal to 36 x 32.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the gNBEutraExternalCell MO instance cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of gNBEutraExternalCell MO instances must be less than or equal to 72 x 32.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of gNBEutraExternalCell MO instances must be less than or equal to 36 x 32.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, gNBEutraExternalCell MO instances cannot be added.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the mobile country code of the E-UTRAN neighboring cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.
Mobile Network Code

Indicates the mobile network code of a neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.
eNodeB ID

Indicates the eNodeB ID of an inter-RAT neighboring E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. A 28-bit E-UTRAN cell identifier (ECI) is comprised of a cell ID and an eNodeB ID (represented by the most significant 20 bits). An E-UTRAN cell global identifier (ECGI) is comprised of an ECI and a PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the ID of the inter-RAT neighboring E-UTRAN cell. It uniquely identifies a cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The cell global identity (CGI) of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Downlink EARFCN

Indicates the DL EARFCN of the inter-RAT external E-UTRAN cell. For details, see 3GPP TS 36.104.
Physical Cell ID

Indicates the physical cell ID of the external E-UTRAN cell. For details about this parameter, see 3GPP TS 36.331.
Tracking Area Code

Indicates the TAC of the external E-UTRAN cell. According to 3GPP specifications, the TAC values 0x0000(0) and 0xFFFE(65534) are reserved, and therefore these two TAC values cannot be used in later versions. You are advised not to set 0 or 65534 as the TAC value in network planning and configuration.
Cell Name

Indicates the name of the neighboring E-UTRAN cell.
Aggregation Attribute

Indicates the aggregation attributes of an external E-UTRAN cell.

MASTER_PLMN_RESERVED_FLAG: Indicates whether to reserve the primary PLMN ID of an external E-UTRAN cell. If this option is selected, the primary PLMN ID of the external E-UTRAN cell is reserved and the cell cannot be selected as a target cell for handovers of UEs served by the primary PLMN. If this option is deselected, the cell can be selected as a target cell for handovers of UEs served by the primary PLMN.
