gNBNetworkSlice

+-gNodeBFunction
  +-gNBOperator
    +-gNBNetworkSlice

Description

This MO is used to configure parameters related to a gNodeB network slice, including the slice/service type and slice differentiator.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBOperator
  • Relation with the gNBCUNgNs MO:
    • OperatorId, SliceServiceType, and SliceDifferentiator in a gNBCUNgNs MO must be set to values configured in the associated gNBNetworkSlice MO.
  • Relation with the gNBTaNs MO:
    • The gNBNetworkSlice MO instance corresponding to OperatorId, SliceServiceType, and SliceDifferentiator in the gNBTaNs MO must already exist.
  • Relation with the gNBOperator MO:
    • NrNetworkingOption in the gNBOperator MO corresponding to OperatorId in a gNBNetworkSlice MO must be set to SA or SA_NSA.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBNETWORKSLICE

Use this command to add a gNodeB network slice.
LST GNBNETWORKSLICE

Use this command to list one or more gNodeB network slices.
MOD GNBNETWORKSLICE

Use this command to modify a gNodeB network slice.
RMV GNBNETWORKSLICE

Use this command to remove a gNodeB network slice.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Operator ID

Indicates the ID of an operator.
Slice Service Type

Indicates the slice/service type. For details, see 3GPP TS 23.003.
Slice Differentiator

Indicates the slice differentiator. For details, see 3GPP TS 23.003. If this parameter is set to 16777215, a slice/service type is configured for the slice but the slice differentiator is not configured. If this parameter is not set to 16777215, this parameter indicates the specific slice differentiator.
Slice Description

Indicates the description of a slice. The description is configured by the operator.
