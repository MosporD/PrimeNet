NRCellReselConfig

+-gNodeBFunction
  +-NRCell
    +-NRCellReselConfig

Description

This MO consists of parameter configurations related to NR cell selection and cell reselection.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellEutranNFreq MO:
    • The value of CellReselPriority in the NRCellReselConfig MO for a cell must be different from the summed value of EutranFreqReselPriority and EutranFreqReselSubPriority in the NRCellEutranNFreq MO for the same cell.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRCELLRESELCONFIG

Use this command to list parameter configurations related to NR cell reselection.
MOD NRCELLRESELCONFIG

Use this command to modify parameter configurations related to NR cell reselection.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.
Minimum RX Level

Indicates the minimum RX level required for a reselection to an intra-frequency neighboring cell, which corresponds to the q-RxLevMin IE of intra-frequency neighboring cell in SIB2. For details, see 3GPP TS 38.331.
Intra-Freq Measurement Start Threshold

Indicates the measurement triggering threshold for intra-frequency cell reselection, which corresponds to the s-IntraSearchP IE in SIB2. For details, see 3GPP TS 38.331.
Cell Reselection Hysteresis

Indicates the hysteresis for the measured RSRP value of the serving cell during cell reselection, which corresponds to the q-Hyst IE in SIB2. For details, see 3GPP TS 38.331.
Cell Reselection Priority

Indicates the cell reselection priority of the serving frequency. Value 0 indicates the lowest priority. This parameter corresponds to the cellReselectionPriority IE in SIB2. For details, see 3GPP TS 38.331. The value of this parameter must be determined together with the priorities of other frequencies during network planning.
E-UTRAN Cell Reselection Timer

Indicates the timer used for E-UTRAN cell reselection. A UE initiates E-UTRAN cell reselection if the signal quality of the serving cell and that of the E-UTRAN cell constantly meet reselection threshold requirements before the timer expires and the UE has stayed in the serving cell for more than one second. If this parameter is set to 255, the UE in an NR cell is not reselected to the E-UTRAN cell.
Non-Intra-Freq Measurement RSRP Threshold

Indicates the threshold for triggering inter-frequency or inter-RAT cell reselection measurements. If the cell reselection priority of a neighboring NR frequency or an E-UTRAN frequency is higher than that of the serving frequency, UEs always start inter-frequency or inter-RAT cell reselection measurements. If the cell reselection priority of a neighboring NR frequency or an E-UTRAN frequency is lower than or equal to that of the serving frequency, UEs start inter-frequency or inter-RAT cell reselection measurements only when the value of Cell selection RX level value (dB) is less than or equal to the value of this parameter. This parameter corresponds to the SNonIntraSearchP IE in 3GPP TS 38.304.
Serving Freq Low Priority RSRP Resel Thld

Indicates the threshold used in the evaluation of reselection to a low-priority inter-frequency or inter-RAT cell. Reselection to a low-priority inter-frequency or inter-RAT cell is performed if no cell on the serving frequency or on a high-priority frequency fulfills criteria 1 for inter-frequency or inter-RAT reselection. This parameter corresponds to the ThreshServingLowP IE in 3GPP TS 38.304.
