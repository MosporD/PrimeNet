NRCellHoEutranMeaGrp

+-gNodeBFunction
  +-NRCell
    +-NRCellHoEutranMeaGrp

Description

An NRCellHoEutranMeaGrp MO defines a group of measurement parameters related to inter-RAT handover to E-UTRAN. Handover measurement parameter settings can be QCI-specific to meet various requirements of services for target cells. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellQciBearer MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellHoEutranMeaGrp MO, the value of InterRHoToEutranMeasGrpId in the NRCellQciBearer MO must be set to the value configured in the NRCellHoEutranMeaGrp MO.
  • Relation with the NRCell MO:
    • A maximum of 15 NRCellHoEutranMeaGrp MO instances can be configured for each NRCell MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.
Inter-RAT HO to E-UTRAN Meas Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover to E-UTRAN.
Coverage-based HO B1 RSRP Threshold

Indicates the RSRP threshold for event B1 and RSRP threshold 2 for event B2. Both events are related to coverage-based handover to E-UTRAN. If the measured RSRP value of an E-UTRAN cell is greater than the event B1 threshold throughout the corresponding time-to-trigger, UEs send event B1 measurement reports. If the measured RSRP value of the serving cell is less than the event B2 RSRP threshold 1 throughout the corresponding time-to-trigger and the measured RSRP value of an E-UTRAN cell is greater than the event B2 RSRP threshold 2 throughout the corresponding time-to-trigger, UEs send event B2 measurement reports. For details, see 3GPP TS 38.331.
Coverage-based HO B1B2 Hysteresis

Indicates the hysteresis for events B1 and B2 related to coverage-based handover to E-UTRAN. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.
Coverage-based HO B1B2 Time to Trigger

Indicates the time-to-trigger for event B1/B2 related to coverage-based handover to E-UTRAN. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the average number of handovers and the number of unexpected handovers and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.
EPS FB B1 RSRP Threshold

Indicates the RSRP threshold for event B1 related to EPS fallback to E-UTRAN. If the measured RSRP value of an E-UTRAN cell is greater than the B1 threshold throughout the corresponding time-to-trigger, UEs send event B1 measurement reports. For details, see 3GPP TS 38.331.
EPS FB B1 Hysteresis

Indicates the hysteresis for event B1 related to EPS fallback to E-UTRAN. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.
EPS FB B1 Time to Trigger

Indicates the time-to-trigger for the event related to EPS fallback to E-UTRAN. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the average number of handovers and the number of unexpected handovers and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.
