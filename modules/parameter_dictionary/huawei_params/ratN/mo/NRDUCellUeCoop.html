NRDUCellUeCoop

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellUeCoop

Description

This MO defines parameters related to UE cooperation in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCell MO:
    • The 80M_UE_ACCESS_SW option of UEAccessSwitch in an NRDUCellUeCoop MO can be selected only when FrequencyBand in an NRDUCell MO is set to N41 and DlBandwidth in the NRDUCell MO is set to CELL_BW_100M.
  • Relation with the NRDUCellSpctCloud and gNBDULteNrSpctShrCg MOs:
    • When the 80M_UE_ACCESS_SW option of UEAccessSwitch in an NRDUCellUeCoop MO is selected, NrReservedRbEndIndex in a gNBDULteNrSpctShrCg MO associated with NrSpctShrCellGrpId in an NRDUCellSpctCloud MO corresponding to NrDuCellId in an NRDUCellUeCoop MO must be set to 272.
  • Relation with the NRDUCell and NRDUCellCoreset MOs:
    • When FrequencyBand in an NRDUCell MO is set to N41, 80M_UE_ACCESS_SW of UEAccessSwitch in an NRDUCellUeCoop MO is selected, and CommonCtrlResRbNum in an NRDUCellCoreset MO is set to RB48 or RB96, the following condition must apply: 86 ≤ Rounddown ((Frequency corresponding to SsbFreqPos - Frequency corresponding to DlNarfcn + (6 x NRB x SubcarrierSpacing))/(12 x SubcarrierSpacing)) ≤ (NRB - 26). NRB indicates the number of RBs corresponding to the cell bandwidth specified in Table 5.3.2-1 in 3GPP TS 38.104.
    • When FrequencyBand in an NRDUCell MO is set to N41, 80M_UE_ACCESS_SW of UEAccessSwitch in an NRDUCellUeCoop MO is selected, and CommonCtrlResRbNum in an NRDUCellCoreset MO is set to RB24, the following condition must apply: 74 ≤ Rounddown ((Frequency corresponding to SsbFreqPos - Frequency corresponding to DlNarfcn + (6 x NRB x SubcarrierSpacing))/(12 x SubcarrierSpacing)) ≤ (NRB - 14). NRB indicates the number of RBs corresponding to the cell bandwidth specified in Table 5.3.2-1 in 3GPP TS 38.104.
  • Relation with the NRDUCellAlgoSwitch MO:
    • When the 80M_UE_ACCESS_SW option of UEAccessSwitch in an NRDUCellUeCoop MO is selected, the INTRA_BAND_CA_SW option of CaAlgoSwitch in an NRDUCellAlgoSwitch MO must be deselected.
    • When the 80M_UE_ACCESS_SW option of UEAccessSwitch in an NRDUCellUeCoop MO is selected, the INTRA_FR_INTER_BAND_CA_SW option of CaAlgoSwitch in an NRDUCellAlgoSwitch MO must be deselected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.
Specified UE Cooperation Switch

Indicates whether to enable device-pipe synergy for specific UEs.

SPEC_UE_IDENTIFY_SW: Indicates whether to identify specific UEs. If this option is selected, the gNodeB identifies UEs supporting device-pipe synergy in the cell. If this option is deselected, the gNodeB does not identify UEs supporting device-pipe synergy in the cell.
UE Access Switch

Indicates whether to enable UE access.

80M_UE_ACCESS_SW: Indicates whether UEs with a bandwidth of 80 MHz can access a 100 MHz cell. If this option is selected, UEs with a bandwidth of 80 MHz can access a 100 MHz cell. If this option is deselected, UEs with a bandwidth of 80 MHz cannot access a 100 MHz cell. This option applies only in TDD low frequency bands.
