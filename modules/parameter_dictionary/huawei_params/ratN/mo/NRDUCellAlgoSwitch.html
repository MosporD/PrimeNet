NRDUCellAlgoSwitch

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellAlgoSwitch

Description

An NRDUCellAlgoSwitch MO defines algorithm switches that determine whether to enable features in an NR DU cell.

Effective Scenario

Immediately
