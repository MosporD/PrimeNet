gNBCUX2

+-gNodeBFunction
  +-gNBCUX2
    +-gNBCUX2Op[0~6]

Description

The gNBCUX2 MO defines transmission resources of an X2 interface between the gNodeB and the eNodeB. It includes the user-defined information (such as control-plane and user-plane endpoint groups) related to a gNodeB CU X2 object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

  • Possible children:

    gNBCUX2Op[0~6]
  • Relation with the gNBCUNg MO:
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUX2 MO.
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUX2 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
  • Relation with the gNBCUXn MO:
    • The value of CpEpGroupId in a gNBCUXn MO must differ from the value of CpEpGroupId in a gNBCUX2 MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • MULTICASTLISTENERSW in the USERPLANEHOST MO referenced by the gNBCUX2 MO must be set to DISABLE.
    • The value of UpEpGroupId in a gNBCUX2 MO must be already configured in the associated EPGROUP MO. In addition, the EPGROUP MO must have a USERPLANEHOST MO configured.
  • Relation with the EPGROUP and SCTPHOST MOs:
    • The value of CpEpGroupId in a gNBCUX2 MO must have been configured in the associated EPGROUP MO. In addition, the EPGROUP MO must have an SCTPHOST MO configured.
    • SCTPHOSTID in the SCTPHOST MOs referenced by CpEpGroupId in different gNBCUX2 MOs must be different.
  • Relation with the gNBCUS1 MO:
    • The value of UpEpGroupId in a gNBCUS1 MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
  • Relation with the gNBCUXn and EPGROUP MOs:
    • When the value of UpEpGroupId in the gNBCUXn MO is different from that of UpEpGroupId in the gNBCUX2 MO, UPHOSTID referenced by UpEpGroupId and UpEpGroupId in the MOs must be different.
  • Relation with the gNBCUX2 MO:
    • Different gNBCUX2 MOs must reference different CpEpGroupId values.
  • Relation with the NRCell and gNBOperator MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and NrNetworkingOption in a gNBOperator MO of a gNodeB is set to NSA, the gNBCUX2 MO must be set for the gNodeB.
  • Relation with the NRCell, gNBOperator, and gNBCUNg MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and NrNetworkingOption in a gNBOperator MO of a gNodeB is set to SA_NSA, the gNBCUNg and gNBCUX2 MOs must be set for the gNodeB.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCUX2

Use this command to add the gNodeB CU X2 object.
DSP GNBCUX2

Use this command to query the information about the X2 interface managed by the gNodeB CU X2 object. The DSP GNBCUX2 command output does not include user-plane information.
LST GNBCUX2

Use this command to list the configuration of the gNodeB CU X2 object.
MOD GNBCUX2

Use this command to modify the configuration of the gNodeB CU X2 object.
RMV GNBCUX2

Use this command to remove the gNodeB CU X2 object.
