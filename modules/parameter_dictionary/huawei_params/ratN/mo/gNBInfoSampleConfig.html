gNBInfoSampleConfig

+-gNodeBFunction
  +-gNBInfoSampleConfig

Description

This MO consists of parameters used by operators to configure information sampling and usage on the gNodeB side.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNBINFOSAMPLECONFIG

Use this command to query the information sampling configuration on the gNodeB side.
MOD GNBINFOSAMPLECONFIG

Use this command to modify the information sampling configuration on the gNodeB side.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
IP Address Sample and Pseudonymization Sw

Indicates whether an operator allows the gNodeB to perform IP address resolution and pseudonymization and specifies the usage of the IP address after pseudonymization.

CPE_PRFM_EVALUATION_SW(CPE Performance Evaluation Switch): Indicates whether the IP address after pseudonymization can be used for CPE performance evaluation.
