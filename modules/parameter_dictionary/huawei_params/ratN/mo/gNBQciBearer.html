gNBQciBearer

+-gNodeBFunction
  +-gNBQciBearer

Description

A gNBQciBearer MO defines bearer parameter configurations of a gNodeB CU. The configurations can vary with the QCIs of bearers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBQciBearer MO:
    • The gNBQciBearer MO instances with Qci separately set to values corresponding to QCI 65, QCI 66, QCI 69, QCI 70, QCI 75, QCI 79, and values in the range from QCI 1 to QCI 9 must always exist.
  • Relation with the gNB5qiConfig MO:
    • The sum of gNB5qiConfig MO instances with CounterObjSubscriptionInd set to YES and gNBQciBearer MO instances with CounterObjSubscriptionInd set to YES must be less than or equal to 20.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBQCIBEARER

Use this command to add gNodeB-level QCI-specific bearer configurations. The configurations can be added for bearers based on their QCIs.
LST GNBQCIBEARER

Use this command to list gNodeB-level QCI-specific bearer configurations.
MOD GNBQCIBEARER

Use this command to modify gNodeB-level QCI-specific bearer configurations. The configurations can be modified for bearers based on their QCIs.
RMV GNBQCIBEARER

Use this command to remove gNodeB-level QCI-specific bearer configurations.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
QoS Class Identifier

Indicates the QoS class identifier (QCI).
Averaging Window Duration

Indicates the average window size. This parameter is valid only for GBR bearers. For details about this parameter, see 3GPP TS 23.501.
Packet Delay Budget

Indicates the packet delay budget. For details about this parameter, see 3GPP TS 23.501.
Priority Level

Indicates the priority of each QoS flow. For details about this parameter, see 3GPP TS 23.501.
B2H Service Type

Indicates the service type of the bearer of the QCI. This parameter is set based on the operator's policy. The value OTHER indicates that other services are carried. The value INTERNET indicates that Internet services are carried. The value VIDEO indicates that video services are carried.
Counter Object Subscription Indicator

Indicates whether to subscribe to QCI-related performance counter objects of NSA UEs. Performance counter objects can be subscribed to only when this parameter is set to YES.
