gNBAsParamGroup

+-gNodeBFunction
  +-gNBAsParamGroup

Description

The gNBAsParamGroup MO consists of parameters related to the acceleration service guarantee algorithm switch and guarantee policy.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNBASPARAMGROUP

Use this command to list a gNodeB acceleration service parameter group.
MOD GNBASPARAMGROUP

Use this command to modify a gNodeB acceleration service parameter group.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
AS Optimization Switch

Indicates whether to enable the acceleration service optimization algorithm. If this parameter is set to ON, UEs running acceleration services are preferentially guaranteed. If this parameter is set to OFF, UEs running acceleration services are not preferentially guaranteed.
AS IP Detection Interval

Indicates the interval at which the gNodeB detects the IP headers of downlink packets to identify UEs running acceleration services. To be specific, the gNodeB detects IP headers every X packets, where X is the value of by this parameter.
AS Guarantee Duration

Indicates the duration during which UEs running acceleration services are preferentially guaranteed.
AS Preallocation Packet Size

Indicates the amount of uplink data preallocated for UEs running acceleration services.
AS Schedule Priority Factor

Indicates the weight factor used to calculate the basic scheduling priority for UEs running acceleration services. This parameter is used to preferentially guarantee UEs running acceleration services in the uplink and downlink. If this parameter is set to a value in the range from 1 to 999, the priority is calculated using the normal weight factor. If this parameter is set to 1000, UEs running acceleration services have the highest priority.
