gNBAmfDomainName

+-gNodeBFunction
  +-gNBAmfDomainName

Description

The gNBAmfDomainName MO is used by the gNodeB to obtain the AMF IP address through DNS query.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBCUNg MO:
    • gNBCuNgId in the gNBAmfDomainName MO must be set to a value of gNBCuNgId in the gNBCUNg MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBAMFDOMAINNAME

Use this command to add a gNodeB AMF domain name.
LST GNBAMFDOMAINNAME

Use this command to list a gNodeB AMF domain name.
RMV GNBAMFDOMAINNAME

Use this command to remove a gNodeB AMF domain name.
