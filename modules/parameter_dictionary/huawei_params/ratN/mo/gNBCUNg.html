gNBCUNg

+-gNodeBFunction
  +-gNBCUNg
    +-gNBCUNgOp[0~6]

Description

A gNBCUNg MO defines transmission resources of an NG interface between the gNodeB and the 5GC. It includes the user-defined information (such as control-plane and user-plane endpoint groups) related to a gNodeB CU NG object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

  • Possible children:

    gNBCUNgOp[0~6]
  • Relation with the gNBCUX2 MO:
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUX2 MO.
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUX2 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
  • Relation with the gNBCUXn MO:
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUXn MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUXn MO.
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of CpEpGroupId in a gNBCUXn MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUXn MO.
  • Relation with the gNBCUS1 MO:
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
  • Relation with the EPGROUP and SCTPHOST MOs:
    • The value of CpEpGroupId in a gNBCUNg MO must be already configured in the associated EPGROUP MO. In addition, the EPGROUP MO must have an SCTPHOST MO configured.
    • The value of CpEpGroupId in a gNBCUNg MO must be already configured in the associated EPGROUP MO. In addition, the EPGROUP MO can be configured with only one SCTPHOST MO with IP version of IPv6.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • The value of UpEpGroupId in a gNBCUNg MO must be already configured in the associated EPGROUP MO. In addition, the EPGROUP MO must have a USERPLANEHOST MO configured.
    • MULTICASTLISTENERSW in the USERPLANEHOST MO referenced by the gNBCUNg MO must be set to DISABLE.
  • Relation with the gNBCUNg MO:
    • CpEpGroupId referenced by different gNBCUNg MOs must be different.
  • Relation with the gNBAmfDomainName MO:
    • gNBCuNgId in the gNBAmfDomainName MO must be set to a value of gNBCuNgId in the gNBCUNg MO.
  • Relation with the gNBCUNgNs MO:
    • gNBCuNgId in a gNBCUNgNs MO must be set to a value configured in the associated gNBCUNg MO.
  • Relation with the NRCell and gNBOperator MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and NrNetworkingOption in a gNBOperator MO of a gNodeB is set to SA, the gNBCUNg MO must be set for the gNodeB.
  • Relation with the NRCell, gNBOperator, and gNBCUX2 MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and NrNetworkingOption in a gNBOperator MO of a gNodeB is set to SA_NSA, the gNBCUNg and gNBCUX2 MOs must be set for the gNodeB.
  • Relation with the gNBSharingMode and gNBTaNs MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, gNBTaNs and gNBCUNg MO configurations are existent, and the gNBCUNg MO with CpEpGroupId not set to 4294967295 is existent, the gNBCUNg MO with CuNgType set to DEFAULT_CP must be existent.
  • Relation with the gNBSharingMode, gNBTaNs, and gNBCUNgOp MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, and gNBCUNg MO configurations with CpEpGroupId not set to 4294967295 are existent for the operator specified by OperatorId in a gNBTaNs MO, the gNBCUNg MO with CuNgType set to DEFAULT_CP must be existent for the operator.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCUNG

Use this command to add a gNodeB CU NG object.
DSP GNBCUNG

Use this command to query the information about the NG interface managed by a gNodeB CU NG object. The DSP GNBCUNG command output does not include user-plane information.
LST GNBCUNG

Use this command to list the configurations of a gNodeB CU NG object.
MOD GNBCUNG

Use this command to modify the configurations of a gNodeB CU NG object.
RMV GNBCUNG

Use this command to remove a gNodeB CU NG object.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB CU NG ID

Indicates the ID of a gNodeB CU NG object.
Control Plane Endpoint Group ID

Indicates the ID of the control-plane endpoint group used by a gNodeB CU NG object. The value 4294967295 is invalid.
User Plane Endpoint Group ID

Indicates the ID of the user-plane endpoint group used by a gNodeB CU NG object. The value 4294967295 is invalid.
User Label

Indicates the user label of a gNodeB CU NG object.
CU NG Type

Indicates the configuration type of the control-plane endpoint used by a gNodeB CU NG object. If this parameter is set to DEFAULT_CP, message transmission over the NG interface will be based on the default control plane that corresponds to this parameter when an RRC connection setup message does not contain slice information or a Temp ID during initial access initiated by a UE. If an operator has multiple default control plane settings, load sharing is applied in message transmission over the NG interface. If this parameter is set to NORMAL, load sharing is applied in message transmission over the NG interface when an RRC connection setup message does not contain slice information or a Temp ID during initial access initiated by a UE.
