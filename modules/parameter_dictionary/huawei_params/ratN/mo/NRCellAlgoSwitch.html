NRCellAlgoSwitch

+-gNodeBFunction
  +-NRCell
    +-NRCellAlgoSwitch

Description

The NRCellAlgoSwitch MO defines algorithm switches which determine whether to enable features in an NR cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRInterRatHoParam MO:
    • When the MOBILITY_TO_EUTRAN_SW option of InterRatServiceMobilitySw in the NRCellAlgoSwitch MO is selected, at least one of the EUTRAN_HO_SWITCH and EUTRAN_REDIRECT_SWITCH options of HoModeSwitch in the NRInterRatHoParam MO must be selected.
  • Relation with the NRDUCell MO:
    • If UlBandwidth in an NRDUCell MO is set to a value less than CELL_BW_20M, the UL_RB_RSV_SW option of VonrSwitch in the associated NRCellAlgoSwitch MO must be deselected.
  • Relation with the NRCell MO:
    • If DuplexMode in an NRCell MO is set to CELL_FDD, the UL_DELAY_COV_OPT_SW option of VonrSwitch in the NRCellAlgoSwitch MO must be deselected.
  • Relation with the NRCellAlgoSwitch MO:
    • If the NR_NR_ANR_SW option of AnrSwitch in the NRCellAlgoSwitch MO is deselected, the NR_NR_ANR_DEL_SW option must also be deselected.
    • If the NR_EUTRAN_ANR_SW option of AnrSwitch in the NRCellAlgoSwitch MO is deselected, the NR_EUTRAN_ANR_DEL_SW option must also be deselected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
NSA DC Switch

Indicates whether to enable the LTE-NR non-standalone (NSA) dual connectivity (DC) function. The LTE-NR NSA DC function is enabled only if this switch is turned on on both the master base station and secondary base station. With this function, a UE can access an eNodeB and a gNodeB simultaneously and use resources of both base stations. The LTE-NR NSA DC function is disabled if this switch is turned off on the master base station or secondary base station.
UL and DL Decoupling Algorithm Switch

Indicates the NR uplink and downlink decoupling algorithm switch.

UL_CARR_SEL_FOR_UE_EXP_SW: Indicates whether to enable user-experience-based uplink carrier selection.
Voice Strategy Switch

Indicates the 5G voice policy control switch. EPS_FB_SWITCH(EPS Fallback Switch): Indicates whether to enable voice fallback from NG-RAN to E-UTRAN.
Inter-RAT Service Mobility Switch

Indicates whether to enable inter-RAT mobility. When this switch is turned on, inter-RAT mobility from NG-RAN to E-UTRAN is enabled, and UEs can be reselected, handed over, or redirected from an NR cell to an E-UTRAN cell. When this switch is turned off, inter-RAT mobility from NG-RAN to E-UTRAN is disabled.
ANR Switch

Indicates whether to enable automatic neighbor relation (ANR) for a cell.

NR_NR_ANR_SW: Indicates whether to enable intra-NR ANR.

NR_EUTRAN_ANR_SW: Indicates whether to enable ANR with E-UTRAN.

NR_NR_ANR_DEL_SW: Indicates whether to enable neighbor relationship removal by intra-NR ANR.

NR_EUTRAN_ANR_DEL_SW: Indicates whether to enable neighbor relationship removal by ANR with E-UTRAN.

NR_NR_ANR_AUTO_NO_HO_SW: Indicates whether to enable the function of automatically prohibiting handovers to neighboring NR cells.

NR_EUTRAN_ANR_AUTO_NO_HO_SW: Indicates whether to enable the function of automatically prohibiting handovers to neighboring E-UTRAN cells.

PCI_COLLISION_DETECT_SW: Indicates whether to enable PCI collision detection in a cell.

PCI_CONFUSION_DETECT_SW: Indicates whether to enable PCI confusion detection in a cell.

NR_NR_ANR_OVER_DIST_DETECT_SW: Indicates whether to detect over-distant neighboring NR cells and automatically prohibit handovers to such cells if detected.
Inter-Frequency Handover Switch

Indicates whether to enable intra-RAT inter-frequency handover algorithms.

COVERAGE_BASED_HO: Indicates whether to enable coverage-based inter-frequency handover. If this option is selected, coverage-based inter-frequency handovers are enabled to ensure service continuity. If this option is deselected, coverage-based inter-frequency handovers are disabled.

FREQ_PRIORITY_BASED_HO: Indicates whether to enable frequency-priority-based inter-frequency handover. Select this option if a frequency is dedicated for absorbing traffic. If this option is selected, frequency-priority-based handovers can be triggered for UEs even when the serving cell has good signal quality. If this option is deselected, frequency-priority-based inter-frequency handovers cannot be triggered for UEs, and inter-frequency handovers can be triggered only when other conditions for triggering handovers are met.

REDIRECTION: Indicates whether to enable inter-frequency redirection. If this option is selected, inter-frequency redirection and blind redirection are supported. If this option is deselected, inter-frequency redirection and blind redirection are not supported.

OP_DED_PRI_BASED_HO: Indicates whether to enable operator-specific-priority-based inter-frequency handover. If this option is selected, an operator-specific-priority-based inter-frequency handover can be triggered for a UE served by a frequency meeting the following condition: the frequency is not an NR frequency in the operator-associated frequency group with the dedicated frequency priority for the connected mode set to a non-zero value. If this option is deselected, operator-specific-priority-based inter-frequency handovers cannot be triggered for the UE.
VoNR Switch

Indicates the voice over NR (VoNR) function switches.

VONR_SW: Indicates whether to enable VoNR. VoNR is supported only if this option is selected. It is recommended that VoNR not be enabled in high-frequency scenarios.

UL_DELAY_COV_OPT_SW: Indicates whether to enable coverage optimization by uplink delay configuration of voice services. This option applies only to low-frequency TDD cells.

ANBR_SW: Indicates whether to enable access network bitrate recommendation (ANBR). This option applies only to low-frequency cells.

UL_RB_RSV_SW: Indicates whether to enable uplink RB reservation for voice services. This option applies only to low-frequency cells.
ROHC Switch

Indicates the switches related to robust header compression (ROHC).

ROHC_SW: Indicates whether to enable ROHC. If this option is selected, ROHC is enabled. In this case, the ROHC Profiles parameter must be set to determine the profile that takes effect. If this option is deselected, ROHC is disabled. This option applies only in low frequency bands.
ROHC Profiles

Indicates ROHC profile configurations.

PROFILE0X0001: Indicates the profile for RTP/UDP/IP. For details, see RFC 3095 and RFC 4815. This option applies only in low frequency bands.

PROFILE0X0002: Indicates the profile for UDP/IP. For details, see RFC 3095 and RFC 4815. This option applies only in low frequency bands.
UE Power Saving Switch

Indicates the UE power saving switches.

UE_DL_MIMO_LAYER_REDUCE_SW: Indicates whether to trigger downlink layer reduction for a UE. If this option is selected, downlink layer reduction is triggered for a UE that supports overheating protection when the UE requests for layer reduction. If this option is deselected, downlink layer reduction does not take effect. For details about this parameter, see 3GPP TS 38.331. This parameter applies only to low-frequency TDD and FDD cells.
INACTIVE Strategy Switch

Indicates whether to enable RRC_INACTIVE state management.

RRC_INACTIVE_SWITCH: Indicates whether to enable RRC_INACTIVE state management. If this option is selected, transition between RRC_CONNECTED and RRC_INACTIVE states is supported. If this option is deselected, RRC_INACTIVE state management is disabled.
Measurement Policy Switch

Indicates whether to enable measurement policy algorithms.

SSB_MEAS_POS_POLICY_SW: Indicates whether the SSB-ToMeasure IE delivered in SIB2, SIB4, or RRC signaling carries the time-domain position of a neighboring cell. If this option is selected, the SSB time-domain position of a neighboring cell can be obtained during Xn self-setup. The information is combined with the time-domain position of the local cell and is then sent to UEs. If this option is deselected, only the SSB time-domain position of the local cell is carried in the SSB-ToMeasure IE. For details about this parameter, see 3GPP TS 38.331.

This option applies only to high-frequency TDD.
MLB Algorithm Switch

INTER_FREQ_CONNECTED_MLB_SW: Indicates whether to enable MLB between inter-frequency cells for RRC_CONNECTED UEs. This function is enabled only when this option is selected. This option applies only to UEs with the RFSP index of an operator not configured or UEs with the RFSP index of an operator with INTER_FREQ_CONNECTED_MLB_SW option of the gNBRfspConfig.MlbAlgoSwitch parameter selected.
