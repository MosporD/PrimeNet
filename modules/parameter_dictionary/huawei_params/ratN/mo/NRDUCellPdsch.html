NRDUCellPdsch

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellPdsch

Description

The NRDUCellPdsch MO defines parameters related to PDSCH resources in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured, TrpType in the NRDUCellTrp MO is set to DEFAULT, NrDuCellNetworkingMode in the NRDUCell MO is not set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260 or N261, the following must be true: If TxRxMode in the NRDUCellTrp MO is set to 64T64R or 32T32R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, LAYER_6, LAYER_8, LAYER_10, LAYER_12, LAYER_14, LAYER_16, or LAYER_DEFAULT; if TxRxMode in the NRDUCellTrp MO is set to 8T8R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, LAYER_6, LAYER_8, or LAYER_DEFAULT; if TxRxMode in the NRDUCellTrp MO is set to 4T4R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, or LAYER_DEFAULT; if TxRxMode in the NRDUCellTrp MO is set to 2T2R or 2T4R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2 or LAYER_DEFAULT.
    • If the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured, TrpType in the NRDUCellTrp MO is set to DEFAULT, NrDuCellNetworkingMode in the NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260 or N261, the following must be true: If TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO is set to 64T64R or 32T32R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, LAYER_6, LAYER_8, LAYER_10, LAYER_12, LAYER_14, LAYER_16, or LAYER_DEFAULT; if the values of TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO include 8T8R and do not include 64T64R or 32T32R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, LAYER_6, LAYER_8, or LAYER_DEFAULT; if the values of TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO include 4T4R and do not include 64T64R, 32T32R, or 8T8R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2, LAYER_4, or LAYER_DEFAULT; if TxRxMode in all the NRDUCellTrp MO instances corresponding to this NRDUCell MO is set to 2T2R or 2T4R, MaxMimoLayerNum in the NRDUCellPdsch MO can be set to LAYER_2 or LAYER_DEFAULT.
    • When NrDuCellId in an NRDUCellTrp MO is set to a value configured in the associated NRDUCell MO:
    • If FrequencyBand in the NRDUCell MO is set to N257, N258, N260 or N261 and TxRxMode in the NRDUCellTrp MO is set to 8T8R, MaxMimoLayerNum in the NRDUCellPdsch MO must be set to LAYER_2, LAYER_4, LAYER_6, LAYER_8, or LAYER_DEFAULT.
    • If FrequencyBand in the NRDUCell MO is set to N257, N258, N260 or N261 and TxRxMode in the NRDUCellTrp MO is set to 4T4R, MaxMimoLayerNum in the NRDUCellPdsch MO must be set to LAYER_2, LAYER_4, or LAYER_DEFAULT.
    • If FrequencyBand in the NRDUCell MO is set to N257, N258, N260 or N261 and TxRxMode in the NRDUCellTrp MO is set to 2T2R, MaxMimoLayerNum in the NRDUCellPdsch MO must be set to LAYER_2 or LAYER_DEFAULT.
  • Relation with the NRDUCellChnPwr and NRDUCell MOs:
    • If FrequencyBand in an NRDUCell MO is not set to N257, N258, N260, or N261 and the TRS_RATEMATCH_SW option of RateMatchSwitch in the associated NRDUCellPdsch MO is deselected, TrsPwrOffset in the NRDUCellChnPwr MO corresponding to NrDuCellId in the NRDUCellPdsch MO must be set to 0.
  • Relation with the NRDUCellAlgoSwitch MO:
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected, DlDmrsMaxLength in the associated NRDUCellPdsch MO must be set to 1SYMBOL.
    • When the TRS_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO is deselected, the INTRA_GNB_DL_JT_SW option of CompSwitch in the NRDUCellAlgoSwitch MO must be deselected.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected, DlAdditionalDmrsPos in the NRDUCellPdsch MO must be set to NOT_CONFIG or POS1.
    • If the PDCCH_RATEMATCH_SW option of RateMatchSwitch in an NRDUCellPdsch MO is selected, the LTE_NR_DYN_POWER_SHARING_SW option of DynPowerSharingSwitch in the NRDUCellAlgoSwitch MO must be deselected.
    • If the PDCCH_RATEMATCH_SW option of RateMatchSwitch in an NRDUCellPdsch MO is selected, then the INTRA_FR_INTER_BAND_CA_SW option of CaAlgoSwitch in an NRDUCellAlgoSwitch MO cannot be selected.
  • Relation with the NRDUCell MO:
    • If HighSpeedFlag in an NRDUCell MO is set to HIGH_SPEED, DlDmrsMaxLength in the associated NRDUCellPdsch MO must not be set to 2SYMBOL.
    • If HighSpeedFlag in an NRDUCell MO is set to HIGH_SPEED, DlAdditionalDmrsPos in the associated NRDUCellPdsch MO must be set to POS1 or POS2.
    • If NrDuCellNetworkingMode in an NRDUCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, the TRS_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO must be selected.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, DlAdditionalDmrsPos in the associated NRDUCellPdsch MO cannot be set to POS_ADAPTIVE.
    • If FrequencyBand in an NRDUCell MO is set to N38, SsbSubcarrierSpacing in the NRDUCell MO is set to 15KHZ, the SSB_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO must be deselected.
    • If SlotAssignment in an NRDUCell MO is set to 2_3_DSUUU, DlDmrsMaxLength in the NRDUCellPdsch MO must be set to 1SYMBOL.
    • The INIT_DELTA_CQI_AUTO_OPT_SW option of AutoParamOptSwitch in an NRDUCellPdsch MO can be selected only when DuplexMode in the NRDUCell MO is set to CELL_TDD and FrequencyBand in the NRDUCell MO is set to N38, N40, N41, N77, N78, or N79.
  • Relation with the NRDUCellAlgoSwitch, NRDUCellPdcch, NRDUCellSpctCloud, and gNBDULteNrSpctShrCg MOs:
    • If the LTE_NR_TDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected and the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO corresponding to NrDuCellId in this NRDUCellAlgoSwitch MO is selected, OccupiedRbNum in the NRDUCellPdcch MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO cannot be set to 0. When the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO has been configured, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, the following must be true: If TrpType in the NRDUCellTrp MO is set to MASTER_8T8R and TxRxMode in the NRDUCellTrp MO is set to 4T4R, the value range of MaxMimoLayerCnt in the NRDUCellPusch MO is LAYER_2, LAYER_4, LAYER_6, and LAYER_8; if TrpType in the NRDUCellTrp MO is set to MASTER_4T4R and TxRxMode in the NRDUCellTrp MO is set to 2R or 2T2R, the value range of MaxMimoLayerCnt in the NRDUCellPusch MO is LAYER_2 and LAYER_4.
  • Relation with the NRDUCell and NRDUCellAlgoSwitch MOs:

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Downlink Target IBLER

Indicates the downlink target IBLER.
Downlink Maximum MIMO Layer Number Quota

Indicates the maximum transport layer count quota for spatial multiplexing in downlink MIMO. This parameter does not take effect for low-frequency NR DU cells with NRDUCellTrp.TxRxMode set to 1T1R, 2R, 4R, 2T2R, 2T4R, 4T4R, or 8T8R. In this case, the maximum number of layers for downlink MIMO depends on the number of transmit antennas in the cell. If this parameter is set to LAYER_DEFAULT for low-frequency NR DU cells, the maximum number of downlink MIMO layers is 4. If this parameter is set to LAYER_DEFAULT for high-frequency NR DU cells, the maximum number of downlink MIMO layers is 2. NR DU cells consume layer number licenses based on the value of this parameter.
Downlink DMRS Configuration Type

Indicates the downlink DMRS type.
Downlink DMRS Maximum Length

Indicates the maximum number of downlink DMRS symbols.
Fixed AMC Step Value

Indicates the fixed step of PDSCH outer-loop adjustment.
Downlink Initial MCS After Handover

Indicates the downlink initial MCS after a UE handover.
Downlink Initial Rank After Handover

Indicates the initial downlink rank (number of PDSCH spatial multiplexing layers) during the period between the first SRS reporting and the first CQI reporting after the handover. If this parameter is set to RANK1, RANK2, RANK3, or RANK4, the rank value that takes effect is the GUI value or the maximum downlink MIMO capability reported by the UE, whichever is smaller. This parameter applies only to 8T8R, 32T32R, and 64T64R TDD modules.
Fixed Weight Type

Indicates the fixed weight type. It specifies the weight type for downlink data channel selection in MIMO. This parameter is valid only when all the following conditions are met: The DL_PMI_SRS_ADAPT_SW option of the NRDUCellAlgoSwitch.AdaptiveEdgeExpEnhSwitch parameter is deselected, the cell is a low-frequency TDD cell with the TX/RX mode being 4T4R, 8T8R, 32T32R, or 64T64R, and UEs support antenna selection.
SRS Pre-SINR Judge Threshold

Indicates the threshold used to determine whether the SINR of a UE SRS is low or high. This parameter applies only to TDD.
Rate Match Switch

Indicates whether to enable rate matching for the PDSCH.

PDCCH_RATEMATCH_SW: If this option is selected, the NRDUCellPdcch.OccupiedRbNum parameter is set to a value greater than 0, and the value is less than the number of RBs corresponding to the cell bandwidth specified by NRDUCell.DlBandwidth, the PDSCH can use the resources on the PDCCH symbols. If this option is deselected, the PDSCH cannot use the resources on the PDCCH symbols.

SSB_RATEMATCH_SW: If this option is selected and the SSB period is less than or equal to 40 ms, the PDSCH can use more PDSCH RB resources in the SSB subframe. If this option is deselected, the number of resources available for the PDSCH does not increase.

CSIRS_RATEMATCH_SW: If this option is selected, RE resources on CSI-RS symbols can be used for PDSCH data transmission if the RE resources are not occupied by CSI-RSs. If this option is deselected, CSI-RS symbols cannot be used for PDSCH data transmission.

TRS_RATEMATCH_SW: If this option is selected, the PDSCH cannot use TRS symbols. If this option is deselected, the PDSCH can use TRS symbols. This parameter applies only to low-frequency cells.
DL Link Adaptation Algorithm Switch

Indicates the downlink adaptation algorithm switches.

DL_MCS_TABLE_ADAPT_SW: Indicates whether to enable MCS index table adaptation. If this option is selected, the base station dynamically selects an MCS index table based on channel quality. If high-index MCSs are selected for a long time, the base station automatically selects the 256QAM MCS index table. If low-index MCSs are selected for a long time, the base station automatically selects the 64QAM MCS index table for more precise MCS selection. If this option is deselected, the MCS index table is not dynamically selected based on channel quality.
Downlink Initial MCS

Indicates the downlink initial modulation and coding scheme (MCS) after UE access.
Downlink Initial Rank

Indicates the initial downlink rank (number of PDSCH spatial multiplexing layers) during the period between the first SRS reporting and the first CQI reporting after the access. If this parameter is set to RANK1, RANK2, RANK3, or RANK4, the rank value that takes effect is the GUI value or the maximum downlink MIMO capability reported by the UE, whichever is smaller. This parameter applies only to 8T8R, 32T32R, and 64T64R TDD modules.
Downlink Additional DMRS Position

Indicates the position of the downlink additional DMRS. This parameter, the maximum symbol configuration, and UE capability determine the DMRS position in RRC messages.

If this parameter is set to NOT_CONFIG, the effective DMRS position in RRC messages is POS0, indicating that additional DMRS is not configured.

If this parameter is set to POS1, the effective DMRS position in RRC messages is POS1, indicating that the maximum number of downlink additional DMRS positions is 1.

If this parameter is set to POS2 and the reported UE capability indicates that the POS2 configuration is not supported, the effective DMRS position in RRC messages is POS1, indicating that the maximum number of downlink additional DMRS positions is 1. If the reported UE capability indicates that the POS2 configuration is supported, the effective DMRS position in RRC messages is POS2, indicating that the maximum number of downlink additional DMRS positions is 2.

If this parameter is set to POS_ADAPTIVE, the base station adaptively sets the position of the downlink additional DMRS to NOT_CONFIG or POS1.

For details, see 3GPP TS 38.331 and 3GPP TS 38.211. This parameter takes effect only for UEs that newly access the network.
Downlink Initial MCS Adjust Value

Indicates the initial adjustment value of the MCS for downlink transmission.

The MCS adjustment value is used to correct the CQI and reduce the amount that the selected MCS corresponding to the CQI deviates from the actual channel quality. The parameter can be used to adjust the initial adjustment value of the MCS.
Maximum Downlink HARQ Transmission Number

Indicates the maximum number of HARQ transmissions in the downlink.
Auto Parameter Optimization Switch

Indicates whether to enable automatic optimization for radio parameters.

INIT_DELTA_CQI_AUTO_OPT_SW: Indicates whether to enable automatic optimization for the initial CQI adjustment amount. This function is enabled only if this option is selected. This option applies only to low-frequency TDD cells.
