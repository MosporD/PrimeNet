NRDUCellQciBearer

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellQciBearer

Description

An NRDUCellQciBearer MO defines bearer parameter configuration of NR DU cells. The configurations can vary with the QCIs of bearers.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the gNBRlcParamGroup MO:
    • RlcMode in a gNBRlcParamGroup MO corresponding to AmRlcParamGroupId in an NRDUCellQciBearer MO must be set to AM.
    • RlcMode in a gNBRlcParamGroup MO corresponding to UmRlcParamGroupId in an NRDUCellQciBearer MO must be set to UM.
    • The value of AmRlcParamGroupId in an NRDUCellQciBearer MO must have been configured in a gNBRlcParamGroup MO.
    • The value of UmRlcParamGroupId in an NRDUCellQciBearer MO must have been configured in a gNBRlcParamGroup MO.
  • Relation with the gNBDUMacParamGroup MO:
    • The value of MacParamGroupId in an NRDUCellQciBearer MO must have been configured in a gNBDUMacParamGroup MO.
  • Relation with the NRDUCell MO:
    • The configuration with Qci being 9 must always exist.
  • Relation with the gNBDUDrxParamGroup MO:
    • When DuDrxParamGroupId in an NRDUCellQciBearer MO is set to a value other than 255, the corresponding gNBDUDrxParamGroup MO instance must already be configured.
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the NRDUCellQciBearer cannot be added.
    • If BRDSPEC in the MPT is set to UMPTe, the board type is UMPTe.
    • If BRDSPEC in the MPT is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRDUCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellQciBearer MO instances must be less than or equal to 144 x 30.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTga and WM in the NODE MO is set to CONCURRENT, the number of NRDUCellQciBearer MO instances must be less than or equal to 36 x 30.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRDUCellQciBearer MO instances cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRDUCellQciBearer MO instances must be less than or equal to 36 x 30.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRDUCellQciBearer MO instances cannot be added.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NRDUCELLQCIBEARER

Use this command to add the bearer configuration of an NR DU cell. The configurations can be added for bearers based on their QCIs.
LST NRDUCELLQCIBEARER

Use this command to list the bearer configuration of an NR DU cell. The configurations can be listed for bearers based on their QCIs.
MOD NRDUCELLQCIBEARER

Use this command to modify the bearer configuration of an NR DU cell. The configurations can be modified for bearers based on their QCIs.
RMV NRDUCELLQCIBEARER

Use this command to remove the bearer configuration of an NR DU cell. The configurations can be removed for bearers based on their QCIs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of a local cell, which uniquely identifies the NR DU cell within a gNodeB.
QoS Class Identifier

Indicates the QoS class identifier of radio bearers.
MAC Parameter Group ID

Indicates the ID of a MAC parameter group.
AM RLC Parameter Group ID

Indicates the ID of an RLC parameter group in AM mode.
UM RLC Parameter Group ID

Indicates the ID of an RLC parameter group in UM mode.
UE Inactivity Timer

Indicates the length of the UE inactivity timer in which the gNodeB monitors whether a UE transmits and receives data. If the gNodeB detects that a UE has neither received nor sent data within the timer length, the gNodeB checks whether the RRC_INACTIVE state takes effect for the UE. If it does, the UE state is changed to RRC_INACTIVE. If it does not, the UE is released. If this parameter is set to 0, the gNodeB releases the UE if it does not receive or send data for 3600s.
DU DRX Parameter Group ID

Indicates the ID of a DRX parameter group of an NR DU cell. If this parameter is set to 0 to 63, the QCI has valid DRX parameters. If this parameter is set to 255, DRX is disabled for the QCI.
