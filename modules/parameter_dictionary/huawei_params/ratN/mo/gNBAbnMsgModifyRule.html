gNBAbnMsgModifyRule

+-gNodeBFunction
  +-gNBAbnMsgModifyRule

Description

This MO defines a gNodeB debugging message-based modification rule. After successfully matching the received or sent message with a debugging message, the gNodeB modifies the message according to the modification rule to solve some network problems.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Table 1 Related MML commands

MML Command

Function

Use this command to remove a gNodeB debugging message-based modification rule.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Modify Content

Indicates the modification content of the message received or sent by the gNodeB. The modification content is a hexadecimal number that consists of 1 to 100 characters. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Modify Field Offset

Indicates the modification field offset of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Modify Length

Indicates the modification length of the message received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Modify Rule Index

Indicates the index of a debugging message-based modification rule.
