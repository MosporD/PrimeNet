gNBFreqBandConfig

+-gNodeBFunction
  +-gNBFreqBandConfig

Description

This MO specifies frequency band configurations of the gNodeB. It is used to set the common configurations of the next frequency band configured for the gNodeB. The configurations automatically apply to all cells in this frequency band.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBFREQBANDCONFIG

Use this command to add frequency-band-level configurations for the gNodeB. The configurations automatically apply to all cells in this frequency band.
LST GNBFREQBANDCONFIG

Use this command to list frequency-band-level configurations for the gNodeB.
MOD GNBFREQBANDCONFIG

Use this command to modify frequency-band-level configurations for the gNodeB. The configurations automatically apply to all cells in this frequency band.
RMV GNBFREQBANDCONFIG

Use this command to remove frequency-band-level configurations from the gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Frequency Band

Indicates a frequency band. For details about this parameter, see 3GPP TS 38.104.

If the value of the NrDuCell.FrequencyBand parameter is equal to the value of this parameter, the configuration in this MO is applied.
Frame Offset

Indicates the offset of the start frame against a reference clock for all cells working in the given frequency band and their associated uplink and downlink decoupling cells.

If this parameter is set to a value in the range of 0 to 261120, frame transmission is started at a time later than the reference clock, with a deviation equal to the parameter value.

If this parameter is set to a value in the range of 275943 to 307200, frame transmission is started at a time earlier than the reference clock, with a deviation equal to 307200 minus the parameter value.

If this parameter is set to a value in the range of 0 to 261120 or 275943 to 307200, the frame offset of the cells working in the frequency band and their associated uplink and downlink decoupling cells is equal to the value of this parameter.

If this parameter is set to 4294967295, the frame offset of the cells working in the given frequency band and their associated uplink and downlink decoupling cells is equal to the value of the gNodeBParam.FrameOffset parameter.
