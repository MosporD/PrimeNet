NRCellNsaDcConfigGrp

+-gNodeBFunction
  +-NRCell
    +-NRCellNsaDcConfigGrp

Description

This MO is used to configure an NSA DC configuration parameter group for an NR cell. NSA DC parameter configurations can be QCI-specific.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellQciBearer MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellNsaDcConfigGrp MO, the value of NsaDcConfigGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellNsaDcConfigGrp MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NRCELLNSADCCONFIGGRP

Use this command to add an NSA DC configuration parameter group of an NR cell.
LST NRCELLNSADCCONFIGGRP

Use this command to list the NSA DC configuration parameter group configurations of an NR cell.
MOD NRCELLNSADCCONFIGGRP

Use this command to modify the NSA DC configuration parameter group configurations of an NR cell.
RMV NRCELLNSADCCONFIGGRP

Use this command to remove an NSA DC configuration parameter group of an NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
NSA DC Configuration Group ID

Indicates the ID of an NSA DC configuration parameter group.
PSCell A2 RSRP Thld Offset

Indicates the offset to the RSRP threshold for event A2 that triggers the removal of the PSCell of NSA DC UEs. The summed value of this parameter and the NRCellNsaDcConfig.PscellA2RsrpThld parameter is used as the event A2 threshold for the PSCell of NSA DC UEs. If the summed value exceeds -31 dBm, the actual threshold for event A2 equals -30 dBm. If the summed value is less than -156 dBm, the actual threshold for event A2 equals -156 dBm.
PSCell A2 Time To Trigger

Indicates the time-to-trigger for event A2 that triggers the removal of the PSCell of NSA DC UEs. When detecting that the entering conditions for event A2 are fulfilled, UEs do not immediately send measurement reports. Instead, UEs send measurement reports only when the entering conditions are fulfilled throughout the corresponding time-to-trigger.
