NRDUCellPdcch

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellPdcch

Description

The NRDUCellPdcch MO defines parameters related to PDCCH resources in an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellPdsch and NRDUCell MOs:
    • When DuplexMode in the NRDUCell MO is set to CELL_TDD and OccupiedSymbolNum in the NRDUCellPdcch MO is set to 2SYM, the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO must be deselected.
  • Relation with the NRDUCellPdsch and NRDUCellAlgoSwitch MOs:
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is deselected and OccupiedSymbolNum in the NRDUCellPdcch MO is set to 3SYM, the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO must be deselected.
  • Relation with the NRDUCellPdsch, NRDUCellCoreset, NRDUCell, and NRDUCellAlgoSwitch MOs:
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is deselected, DuplexMode in the associated NRDUCell MO is set to CELL_FDD, the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO is selected, and OccupiedSymbolNum in the NRDUCellPdcch MO is set to 2SYM, CommonCtrlResRbNum in the NRDUCellCoreset MO must be set to RB24 or RB96.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is deselected, DuplexMode in the associated NRDUCell MO is set to CELL_FDD, the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO is selected, and OccupiedSymbolNum in the NRDUCellPdcch MO is set to 1SYM, CommonCtrlResRbNum in the NRDUCellCoreset MO must be set to RB48.
  • Relation with the NRDUCell, NRDUCellAlgoSwitch, and NRCell MOs:
    • If DuplexMode in an NRCell MO is set to CELL_TDD, OccupiedSymbolNum in an NRDUCellPdcch MO cannot be set to 3SYM.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected, OccupiedSymbolNum in the NRDUCellPdcch MO cannot be set to 3SYM.
  • Relation with the NRDUCellIntrfParam and NRDUCellPdsch MOs:
    • If InterferenceSolutionType in the NRDUCellIntrfParam MO is set to NARROWBAND_INTRF and the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO is selected, OccupiedRbNum in the NRDUCellPdcch MO must be set to 0 or a value greater than or equal to (EndRbIndexOfIntrf1 - StartRbIndexOfIntrf1 + EndRbIndexOfIntrf2 - StartRbIndexOfIntrf2)/12 + 3.
  • Relation with the NRDUCellAlgoSwitch and NRDUCellPdsch MOs:
    • When the PDCCH_RATEMATCH_SW option of RateMatchSwitch in an NRDUCellPdsch MO is selected and the INIT_BWP_FULL_BW_SW option of BwpConfigPolicySwitch in the NRDUCellAlgoSwitch MO is selected, the AGG_LVL_INIT_SELECT_OPT_SW option of PdcchAlgoEnhSwitch in the NRDUCellPdcch MO must be selected.
  • Relation with the NRDUCellPdsch MO:
    • If the UE_PDCCH_SYM_NUM_ADAPT_SW option of PdcchAlgoExtSwitch in the NRDUCellPdcch MO is selected, the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO must be deselected.
  • Relation with the NRDUCell MO:
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, the AGG_LVL_INIT_SELECT_OPT_SW option of PdcchAlgoEnhSwitch in the corresponding NRDUCellPdcch MO must be deselected.
    • If SlotAssignment in an NRDUCell MO is set to 2_3_DSUUU, OccupiedSymbolNum in the NRDUCellPdcch MO must be set to 2SYM.
    • If DuplexMode in the NRDUCell MO is set to CELL_TDD and DlBandwidth in the NRDUCell MO is set to CELL_BW_20M or CELL_BW_30M, then the UE_PDCCH_SYM_NUM_ADAPT_SW option of PdcchAlgoExtSwitch in the NRDUCellPdcch MO must be deselected.
    • If DuplexMode in the NRDUCell MO is set to CELL_FDD and DlBandwidth in the NRDUCell MO is set to CELL_BW_5M or CELL_BW_10M, then the UE_PDCCH_SYM_NUM_ADAPT_SW option of PdcchAlgoExtSwitch in the NRDUCellPdcch MO must be deselected.
  • Relation with the NRDUCellAlgoSwitch MO:
    • When the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDuCellAlgoSwitch MO is deselected, GuaranteedRbNum in the NRDUCellPdcch MO must be set to 0.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected, the ANY_OCCASION_PDCCH_SW option of LowLatencySwitch in the NRDUCellAlgoSwitch MO is selected, or the INTRA_GNB_DL_JT_SW option of CompSwitch in the NRDUCellAlgoSwitch MO is selected, the UE_PDCCH_SYM_NUM_ADAPT_SW option of PdcchAlgoExtSwitch in the NRDUCellPdcch MO must be deselected.
    • If the LTE_NR_FDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected and SpctShrStartSymbol in the associated NRDUCellPdcch MO is set to SYM2, OccupiedSymbolNum parameter in the NRDUCellPdcch MO must be set to 1SYM.
  • Relation with the NRDUCellAlgoSwitch, NRDUCellPdsch, NRDUCellSpctCloud, and gNBDULteNrSpctShrCg MOs:
    • If the LTE_NR_TDD_SPCT_SHR_SW option of SpectrumCloudSwitch in an NRDUCellAlgoSwitch MO is selected and the PDCCH_RATEMATCH_SW option of RateMatchSwitch in the NRDUCellPdsch MO corresponding to NrDuCellId in this NRDUCellAlgoSwitch MO is selected, OccupiedRbNum in the NRDUCellPdcch MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO cannot be set to 0. In addition, the value of OccupiedRbNum multiplied by 12 must be less than 1 plus the value of NrReservedRbEndIndex in the gNBDULteNrSpctShrCg MO corresponding to NrSpctShrCellGrpId in the NRDUCellSpctCloud MO associated with NrDuCellId in the NRDUCellAlgoSwitch MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Uplink Maximum CCE Percentage

Indicates the maximum percentage of uplink available CCEs in a slot that is used for the transmission of both uplink and downlink scheduling information.
Occupied Symbol Number

Indicates the number of symbols occupied by the PDCCH.
Maximum Pairing Layer Number

Indicates the maximum number of pairing layers for PDCCH spatial multiplexing. This parameter can be set to specify the maximum number of PDCCH spatial layers only when the PDCCH_MU_SW option is selected. This parameter applies only to low-frequency TDD cells.
Number of Occupied RBs

Indicates the frequency domain range occupied by each PDCCH symbol in a cell. This parameter takes effect only when the rate matching function is enabled for PDCCH and PDSCH resources. If this parameter is set to 0, full band resources are occupied. If this parameter is set to a value greater than the downlink bandwidth (specified by DlBandwidth), the PDCCH uses full band resources by default.
PDCCH BLER Target

Indicates the target BLER value for PDCCH link adaptation. The PDCCH BLER needs to converge to this target value.
SUL Maximum CCE Percentage

Indicates the maximum percentage of CCEs available in the uplink for decoupling UEs when decoupling UEs are scheduled in slots used only for downlink scheduling in TDD cells.
PDCCH Algorithm Switch

Indicates the PDCCH algorithm switches.

UL_DL_CCE_RATIO_ADAPT_SW: Indicates whether to enable uplink and downlink CCE percentage adaptation in a cell. If this option is selected, the gNodeB adaptively adjusts the maximum percentage of uplink CCEs based on uplink and downlink CCE requirements. If this option is deselected, the maximum percentage of uplink CCEs is specified by the NRDUCellPdcch.UlMaxCcePct or NRDUCellPdcch.SulMaxCcePct parameter. This option takes effect in scenarios other than FDD 5 MHz scenarios. In FDD 5 MHz scenarios, uplink and downlink CCE percentage adaptation takes effect by default.
Spectrum Sharing Start Symbol

Indicates the start symbol occupied by the PDCCH when LTE FDD and NR Spectrum Sharing is enabled. For details, see 3GPP TS 38.331. This parameter is valid only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.
PDCCH Algorithm Extension Switch

Indicates PDCCH algorithm extension switches.

UE_PDCCH_SYM_NUM_ADAPT_SW: Indicates whether to enable UE-specific PDCCH symbol number adaptation in a cell. If this option is selected, UE-specific PDCCH symbol number adaptation is enabled, and the NRDUCellPdcch.OccupiedSymbolNum parameter no longer takes effect. If this option is deselected, the number of UE-specific PDCCH symbols is specified by the NRDUCellPdcch.OccupiedSymbolNum parameter. This option does not take effect for high-frequency cells.
PDCCH Algorithm Enhancement Switch

Indicates the enhanced PDCCH algorithm switches.

AGG_LVL_INIT_SELECT_OPT_SW: Indicates whether to enable initial aggregation level selection optimization in a cell. This function is enabled only when this option is selected.
Number of Guaranteed RBs

Indicates the number of guaranteed PDCCH RBs allocated to an NR cell when resources are sufficient in LTE FDD and NR spectrum sharing scenarios. When the number of PDCCH RBs required by an NR cell is greater than the value of this parameter, PDCCH RBs are allocated based on the service requirement. When the number of PDCCH RBs required by an NR cell is smaller than the value of this parameter, PDCCH RBs are allocated based on the value of this parameter.

When the number of configured RBs exceeds the RB number corresponding to downlink bandwidth (specified by DlBandwidth), the PDCCH occupies full-band resources by default. This parameter takes effect only when the LTE_NR_FDD_SPCT_SHR_SW option of the NRDuCellAlgoSwitch.SpectrumCloudSwitch parameter is selected.
