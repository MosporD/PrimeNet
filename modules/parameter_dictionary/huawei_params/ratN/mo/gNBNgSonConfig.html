gNBNgSonConfig

+-gNodeBFunction
  +-gNBNgSonConfig

Description

This MO is used to configure gNodeB-level parameters for self-configuration of the NG interface.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNBNGSONCONFIG

Use this command to list the configuration of gNodeB NG SON functions.
MOD GNBNGSONCONFIG

Use this command to modify the configuration of gNodeB NG SON functions.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NG-C SON Switch

Indicates whether to enable NG-C self-configuration.

NGC_SON_SETUP_SW(NG-C Self-Setup Switch): Indicates whether to enable NG-C self-setup. NG-C self-setup is enabled only when this option is selected.

NGC_SON_DELETE_SW(NG-C Self-Removal Switch): Indicates whether to enable NG-C self-removal. NG-C self-removal is enabled only when this option is selected.
