gNBTaNs

+-gNodeBFunction
  +-gNBTaNs

Description

This MO is used to configure a tracking-area network slice of the gNodeB, including the tracking area ID, operator ID, slice/service type, and slice differentiator.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBSharingMode and gNBCUNg MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, gNBTaNs and gNBCUNg MO configurations are existent, and the gNBCUNg MO with CpEpGroupId not set to 4294967295 is existent, the gNBCUNg MO with CuNgType set to DEFAULT_CP must be existent.
  • Relation with the gNBSharingMode, gNBCUNgOp, and gNBCUNg MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, and gNBCUNg MO configurations with CpEpGroupId not set to 4294967295 are existent for the operator specified by OperatorId in a gNBTaNs MO, the gNBCUNg MO with CuNgType set to DEFAULT_CP must be existent for the operator.
  • Relation with the gNBNetworkSlice MO:
    • The gNBNetworkSlice MO instance corresponding to OperatorId, SliceServiceType, and SliceDifferentiator in the gNBTaNs MO must already exist.
  • Relation with the gNBTrackingArea MO:
    • TrackingAreaId in a gNBTaNs MO must be set to a value configured in the associated gNBTrackingArea MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBTANS

Use this command to add a tracking-area network slice of the gNodeB.

Use this command to list one or more tracking-area network slices of the gNodeB.
RMV GNBTANS

Use this command to remove a tracking-area network slice from the gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Tracking Area ID

Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the core network. It is different from the TAI configured in the TAL of the core network.
Operator ID

Indicates the ID of an operator.
Slice Service Type

Indicates the slice/service type. For details, see 3GPP TS 23.003.
Slice Differentiator

Indicates the slice differentiator. For details, see 3GPP TS 23.003. If this parameter is set to 16777215, a slice/service type is configured for the slice but the slice differentiator is not configured. If this parameter is not set to 16777215, this parameter indicates the specific slice differentiator.
