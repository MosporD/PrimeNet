NRDUCellSpctCloud

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellSpctCloud

Description

The NRDUCellSpctCloud MO is used to configure spectrum cloudification parameters for a cell.

Effective Scenario

Immediately
