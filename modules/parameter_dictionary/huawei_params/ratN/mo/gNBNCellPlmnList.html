gNBNCellPlmnList

+-gNodeBFunction
  +-gNBNCellPlmnList

Description

This MO defines the neighboring-cell PLMN list of a gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBOperator MO:
    • Among gNBNCellPlmnList MO instances with RatType set to NR, if the values of Mnc and Mcc are the same as those of Mnc and Mcc in the gNBOperator MO, respectively, PlmnListType in these MO instances must be set to WHITELIST.
  • Relation with the NRExternalNCellPlmn MO:
    • If the values of SharedMnc and SharedMcc in the NRExternalNCellPlmn MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to NR, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
  • Relation with the NRExternalNCell MO:
    • If the values of Mnc and Mcc in the NRExternalNCell MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to NR, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
  • Relation with the gNBEutraExtCellPlmn MO:
    • If the values of SharedMnc and SharedMcc in the gNBEutraExtCellPlmn MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to EUTRAN, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
    • In all the gNBNCellPlmnList MOs with RatType set to EUTRAN, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of SharedMnc and SharedMcc in all the gNBEutraExtCellPlmn MOs configured for the local gNodeB must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to EUTRAN, respectively.
  • Relation with the gNBEutraExternalCell MO:
    • If the values of Mnc and Mcc in the gNBEutraExternalCell MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to EUTRAN, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
    • In all the gNBNCellPlmnList MOs with RatType set to EUTRAN, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of Mnc and Mcc in all the gNBEutraExternalCell MOs configured for the local gNodeB must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to EUTRAN, respectively.
  • Relation with the NRExternalNCellPlmn and gNBOperator MOs:
    • In all the gNBNCellPlmnList MOs with RatType set to NR, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of SharedMnc and SharedMcc in all the NRExternalNCellPlmn MOs must be the same as those of Mnc and Mcc in a gNBOperator MO, respectively; or the values of SharedMnc and SharedMcc in all the NRExternalNCellPlmn MOs must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to NR, respectively.
  • Relation with the NRExternalNCell and gNBOperator MOs:
    • In all the gNBNCellPlmnList MOs with RatType set to NR, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of Mnc and Mcc in all the NRExternalNCell MOs must be the same as those of Mnc and Mcc in a gNBOperator MO, respectively; or the values of Mnc and Mcc in all the NRExternalNCell MOs must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to NR, respectively.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBNCELLPLMNLIST

Use this command to add a record to the neighboring-cell PLMN list of a gNodeB.
LST GNBNCELLPLMNLIST

Use this command to list neighboring-cell PLMN list configurations of a gNodeB.
RMV GNBNCELLPLMNLIST

Use this command to remove a record from the neighboring-cell PLMN list of a gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
RAT Type

Indicates the RAT of the neighboring cell corresponding to the PLMN.
Mobile Country Code

Indicates the MCC in the PLMN of the neighboring cell. The value of this parameter is a string of three decimal digits.
Mobile Network Code

Indicates the MNC in the PLMN of the neighboring cell. The value of this parameter is a string of two or three decimal digits.
PLMN List Type

Indicates the type of a PLMN list. If this parameter is set to BLACKLIST, the cell of the blacklisted PLMN cannot be configured as a neighboring cell or an external cell by ANR. If this parameter is set to GREYLIST, the cell of the graylisted PLMN can be added as a neighboring cell and an external cell by ANR, but handovers to the cell of the graylisted PLMN are not allowed. If this parameter is set to WHITELIST, the cell of the whitelisted PLMN can be added as a neighboring cell and an external cell by ANR. This parameter can be set to only two of the three values for all PLMNs in NR and E-UTRAN. The type of PLMNs for which this parameter is not configured is considered the third type by default.
