gNBCUXnInterface

+-gNodeBFunction
  +-gNBCUXnInterface

Description

A gNBCUXnInterface MO consists of user-configured parameters related to an Xn interface between gNodeBs. The parameters specify information about the Xn interface and the peer gNodeB, including the CP bearer used for the Xn interface and the peer gNodeB ID.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
DSP GNBCUXNINTERFACE

Use this command to query the status of an Xn interface and the information about the peer gNodeB. The information about the peer gNodeB includes the global ID of the gNodeB and the broadcast PLMN ID. If the status of an Xn interface is abnormal, the command output displays the information of the peer gNodeB in the last normal connection with the local gNodeB.
RST GNBCUXNINTERFACE

Use this command to restart the gNodeB CU Xn interface.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB CU Xn Interface ID

Indicates the ID of a gNodeB CU Xn interface.
gNodeB CU Xn Interface CP Bearer ID

Indicates the ID of the bottom-layer CP bearer of a gNodeB CU Xn interface.
