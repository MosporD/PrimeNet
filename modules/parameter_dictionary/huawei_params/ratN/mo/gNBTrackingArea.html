gNBTrackingArea

+-gNodeBFunction
  +-gNBTrackingArea

Description

A gNBTrackingArea MO defines a tracking area, which is identified by a tracking area code (TAC). The TAC is used by the core network (CN) to determine the area within which paging messages are sent. One tracking area is composed of one or more cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRDUCell MO:
    • TrackingAreaId in an NRDUCell MO must be set to a value configured in the associated gNBTrackingArea MO.
  • Relation with the NRDUCell, NRDUCellOp, and gNBOperator MOs:
    • In the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCell MO, if NrNetworkingOption in any gNBOperator MO corresponding to OperatorId is set to SA or SA_NSA, and DuplexMode in the NRDUCell MO is not set to CELL_SUL, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId in the NRDUCell MO cannot be set to 4294967295.
    • If the NRDUCellOp MO corresponding to NrDuCellId in an NRDUCell MO does not exist, OperatorType in a gNBOperator MO is set to PRIMARY_OPERATOR, and NrNetworkingOption in the gNBOperator MO is set to SA or SA_NSA, and DuplexMode in the NRDUCell MO is not set to CELL_SUL, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId in the NRDUCell MO cannot be set to 4294967295.
  • Relation with the gNBTaNs MO:
    • TrackingAreaId in a gNBTaNs MO must be set to a value configured in the associated gNBTrackingArea MO.
  • Relation with the NRDUCellOp and gNBOperator MOs:
    • If TrackingAreaId in an NRDUCellOp MO is not set to 4294967295 and NrNetworkingOption in the gNBOperator MO corresponding to OperatorId is set to SA or SA_NSA, Tac in the gNBTrackingArea MO corresponding to TrackingAreaId cannot be set to 4294967295.
  • Relation with the NRDUCellOp MO:
    • If TrackingAreaId in an NRDUCellOp MO is not set to 4294967295, the value of TrackingAreaId must be set to the value configured in a gNBTrackingArea MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBTRACKINGAREA

Use this command to add a tracking area supported by the gNodeB.

Use this command to list the configuration of tracking areas supported by the gNodeB.
MOD GNBTRACKINGAREA

Use this command to modify the configuration of a tracking area supported by the gNodeB.
RMV GNBTRACKINGAREA

Use this command to remove a tracking area supported by the gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Tracking Area ID

Indicates the ID of a tracking area, which uniquely identifies an entry of tracking area information. This parameter is used only within the gNodeB and is not used in the information exchanged with the CN. This is different from the TAI configured in the TAL of the core network.
Tracking Area Code

Indicates the TAC, which is used by the core network to determine the area within which paging messages are sent. One tracking area may contain one or more cells. The TAC must be planned for cells in SA networking and cannot be set to an invalid value.
