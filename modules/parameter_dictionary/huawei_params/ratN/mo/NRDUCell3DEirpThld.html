NRDUCell3DEirpThld

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCell3DEirpThld

Description

This MO defines the 3D EIRP threshold configuration of an NR DU cell. Different thresholds are provided for different grids.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NRDUCELL3DEIRPTHLD

Use this command to add a 3D EIRP threshold for an NR DU cell.
LST NRDUCELL3DEIRPTHLD

Use this command to list a 3D EIRP threshold for an NR DU cell.
MOD NRDUCELL3DEIRPTHLD

Use this command to modify a 3D EIRP threshold for an NR DU cell.
RMV NRDUCELL3DEIRPTHLD

Use this command to remove a 3D EIRP threshold for an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for an NR DU cell within a gNodeB.
Grid Group No

Indicates the ID of a grid group, which uniquely identifies a grid group.
Power Control Threshold

Indicates the power control threshold for the smart power lock feature. The average power within the average period must not exceed the maximum transmit power minus the value of this parameter.
