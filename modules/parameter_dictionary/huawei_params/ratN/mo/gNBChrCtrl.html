gNBChrCtrl

+-gNodeBFunction
  +-gNBChrCtrl

Description

A gNBChrCtrl MO is used to configure the internal CHR recording and output mode.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCHRCTRL

Use this command to set the sampling output rate of internal CHRs.
LST GNBCHRCTRL

Use this command to list the internal CHR output mode.
MOD GNBCHRCTRL

Use this command to modify the sampling output rate of internal CHRs.
RMV GNBCHRCTRL

Use this command to remove the internal CHR sampling output mode.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Detailed Cause Value

Indicates the detailed exception cause value for internal CHR recording. The value 0xFFFFFFFFFFFF indicates that the sampling output setting applies to all the exception cause values. In other cases, the sampling output setting applies only to the given exception cause value.
CHR Sampling Interval

Indicates the frequency by which internal CHR data is generated.
