gNBXnBlackWhiteList

+-gNodeBFunction
  +-gNBXnBlackWhiteList

Description

This MO defines the Xn blacklist and whitelist. If the peer gNodeB is in the Xn blacklist, the Xn interface between the two gNodeBs cannot be automatically set up. If the peer gNodeB is in the Xn whitelist, the Xn interface between the two gNodeBs cannot be automatically removed.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Function

Use this command to list Xn blacklist or whitelist configurations.

Use this command to remove a record from the gNodeB Xn blacklist or whitelist.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the mobile country code (MCC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.
Mobile Network Code

Indicates the mobile network code (MNC) of the peer gNodeB to be added to the Xn blacklist or whitelist. The MNC, together with the MCC, forms the PLMN. The MCC consists of three digits. The MNC consists of two or three digits.
gNodeB ID

Indicates the ID of the peer gNodeB to be added to the Xn blacklist or whitelist.
Xn List Type

Indicates whether the Xn list is a whitelist or blacklist. If the peer gNodeB is in the Xn blacklist, the Xn interface between the two gNodeBs cannot be automatically set up. If the peer gNodeB is in the Xn whitelist, the Xn interface between the two gNodeBs cannot be automatically removed.
