gNBCUNgOp

+-gNodeBFunction
  +-gNBCUNg
    +-gNBCUNgOp

Description

This MO is used to indicate the operator information of an NG object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBCUNg
  • Relation with the gNBOperator MO:
    • OperatorId in a gNBCUNgOp MO must be set to a value configured in the associated gNBOperator MO.
    • NrNetworkingOption corresponding to OperatorId in a gNBCUNgOp MO cannot be set to NSA.
  • Relation with the NRCell, NRDUCellOp, and gNBOperator MOs:
    • If CellActiveState in any NRCell MO is CELL_ACTIVE and the gNodeB has at least two NRDUCellOp MO instances with OperatorId specifying operators for which NrNetworkingOption is set to SA or SA_NSA, the gNBCUNgOp MOs corresponding to such OperatorId values must be configured.
  • Relation with the gNBCUNgNs MO:
    • gNBCuNgId and OperatorId in a gNBCUNgNs MO must be set to values configured in the associated gNBCUNgOp MO.
  • Relation with the gNBSharingMode MO:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the value of gNBCuNgId corresponding to OperatorId in the gNBCUNgOp MO must be unique.
  • Relation with the gNBSharingMode, gNBTaNs, and gNBCUNg MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, and gNBCUNg MO configurations with CpEpGroupId not set to 4294967295 are existent for the operator specified by OperatorId in a gNBTaNs MO, the gNBCUNg MO with CuNgType set to DEFAULT_CP must be existent for the operator.
