NRDUCellNsaDcConfig

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellNsaDcConfig

Description

The NRDUCellNsaDcConfig MO is used to configure parameters related to the LTE-NR NSA DC feature.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLNSADCCONFIG

Use this command to list the settings of the LTE-NR NSA DC parameters for NR DU cells.
MOD NRDUCELLNSADCCONFIG

Use this command to modify the settings of the LTE-NR NSA DC parameters for an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB.
Harmonic Interference Avoidance Range

Indicates the frequency-domain range of NSA DC harmonic interference avoidance. If this parameter is set to NR_DL_COMMON_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to the NR downlink common channels (SSB/common PDCCH) in the uplink. If this parameter is set to NR_DL_COMMON_AND_DATA_CHANNEL, the gNodeB instructs the eNodeB not to schedule the RBs that cause interference to the NR downlink common channels (SSB/common PDCCH) in the uplink. In addition, RBs that are not interfered by harmonic signals are preferentially allocated to NR downlink data channels. This parameter is valid only if the HARMONIC_INTRF_AVOID_SW option of the NRDUCellAlgoSwitch.NsaDcAlgoSwitch parameter is selected.
