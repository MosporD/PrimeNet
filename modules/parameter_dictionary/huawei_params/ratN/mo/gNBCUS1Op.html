gNBCUS1Op

+-gNodeBFunction
  +-gNBCUS1
    +-gNBCUS1Op

Description

This MO is used to indicate the operator information of an S1 object. The referenced S1 object must be configured with a user-plane endpoint group. In RAN sharing mode, S1 links must be bound to operators.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBCUS1
  • Relation with the gNBOperator MO:
    • OperatorId in a gNBCUS1Op MO must be set to a value configured in the corresponding gNBOperator MO.
    • NrNetworkingOption in the gNBOperator MO corresponding to OperatorId in a gNBCUS1Op MO must be set to NSA or SA_NSA.
  • Relation with the gNBCUS1 MO:
    • gNBCuS1Id in a gNBCUS1Op MO must be set to a value configured in the corresponding gNBCUS1 MO.
  • Relation with the gNBSharingMode, gNBCUS1, and gNBOperator MOs:
    • In the gNBSharingMode MO, if gNBMultiOpSharingMode is set to INDEPENDENT, OperatorType in the gNBOperator MO associated with OperatorId in the gNBCUS1Op MO corresponding to gNBCuS1Id in the gNBCUS1 MO must be set to PRIMARY_OPERATOR.
