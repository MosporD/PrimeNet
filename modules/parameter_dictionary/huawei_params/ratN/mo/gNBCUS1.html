gNBCUS1

+-gNodeBFunction
  +-gNBCUS1
    +-gNBCUS1Op[0~6]

Description

The gNBCUS1 MO defines transmission resources of an S1 interface between the gNodeB and the S-GW. It includes the user-defined information (such as the user-plane endpoint group) related to a gNodeB CU S1 object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

  • Possible children:

    gNBCUS1Op[0~6]
  • Relation with the gNBCUNg MO:
    • The value of UpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
    • The value of CpEpGroupId in a gNBCUNg MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
  • Relation with the gNBCUXn MO:
    • The value of UpEpGroupId in a gNBCUXn MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
    • The value of CpEpGroupId in a gNBCUXn MO must differ from the value of UpEpGroupId in a gNBCUS1 MO.
  • Relation with the gNBCUS1Op MO:
    • gNBCuS1Id in a gNBCUS1Op MO must be set to a value configured in the corresponding gNBCUS1 MO.
  • Relation with the EPGROUP and USERPLANEHOST MOs:
    • MULTICASTLISTENERSW in the USERPLANEHOST MO referenced by the gNBCUS1 MO must be set to DISABLE.
    • The value of UpEpGroupId in a gNBCUS1 MO must have been configured in the associated EPGROUP MO. In addition, the EPGROUP MO must have a USERPLANEHOST MO configured.
  • Relation with the gNBSharingMode, gNBCUS1Op, and gNBOperator MOs:
    • In the gNBSharingMode MO, if gNBMultiOpSharingMode is set to INDEPENDENT, OperatorType in the gNBOperator MO associated with OperatorId in the gNBCUS1Op MO corresponding to gNBCuS1Id in the gNBCUS1 MO must be set to PRIMARY_OPERATOR.
  • Relation with the gNBCUX2 MO:
    • The value of UpEpGroupId in a gNBCUS1 MO must differ from the value of UpEpGroupId in a gNBCUX2 MO.
