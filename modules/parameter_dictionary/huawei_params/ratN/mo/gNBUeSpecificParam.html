gNBUeSpecificParam

+-gNodeBFunction
  +-gNBUeSpecificParam

Description

A gNBUeSpecificParam MO consists of parameters related to UE compatibility and optimization to reduce the impact of UE incompatibility issues on network performance and improve end user experience.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBUeInfo MO:
    • UeInfoIndex in the gNBUeSpecificParam MO must be already configured in the gNBUeInfo MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBUESPECIFICPARAM

Use this command to add UE-specific configuration.
LST GNBUESPECIFICPARAM

Use this command to list UE-specific configuration.
RMV GNBUESPECIFICPARAM

Use this command to remove UE-specific configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Specific UE Config Index

Indicates the index of a UE-specific configuration.
UE Information Index

Indicates the UE index.
MO ID

Indicates the ID of an MO in the UE-specific configuration. Set this parameter under the guidance of Huawei technical support.
Parameter ID

Indicates the number of a parameter within the specified MO. Set this parameter under the guidance of Huawei technical support.

This parameter is a user-level parameter, and the modification of one record of this parameter takes effect for only one user. For example, records of parameters in the NRDUCellAlgoSwitch MO have one-to-one relationship with users and therefore can be modified as a parameter ID. Records of parameters in the NRDUCellQciBearer MO do not have one-to-one relationship with users and therefore cannot be modified as a parameter ID.
Parameter Bit ID

Indicates the number of an option within the specified parameter when the parameter is of bit field type. A parameter value greater than 31 is an invalid value. A parameter value less than or equal to 31 is valid. For example, to change the value of bit 15, set this parameter to 15. The value 255 is invalid. Set this parameter under the guidance of Huawei technical support.
Configured Value

Indicates the value of the specified parameter or option. Set this parameter under the guidance of Huawei technical support.

1. The value of the ConfigValue parameter must be within the GUI value range of the parameter or option specified by MoId, ParamId, and ParamBitId unless the ConfigValue parameter value is processed in a special manner.

2. If the ParamBitId parameter value is valid, the ConfigValue parameter specifies whether to enable the function that is controlled by the option identified by the ParamBitId parameter. The values 0 and 1 indicate that the function is disabled and enabled, respectively.

3. If the ParamBitId parameter value is invalid, the ConfigValue parameter specifies whether to enable the function that is controlled by the parameter identified by the ParamId parameter. Set ConfigValue based on the setting of the identified parameter.

4. If the ParamBitId parameter value is invalid and the magnitude of the ConfigValue parameter value needs to be greater than 2147483647 (0x7FFFFFFF in the hexadecimal format), set ConfigValue on the GUI to the negation of the number in two's complement. The unsigned number takes effect. For example, if the expected parameter value is 4294967294 (0xFFFFFFFE in the hexadecimal format), set ConfigValue on the GUI to -2 (0xFFFFFFFE in the hexadecimal format).
Specific UE Config Description

Indicates the description of the UE-specific configuration.
Parameter Control Switch

Indicates the application scope of the blacklist and whitelist.

TDD_VALID_SW: Indicates whether to enable the blacklisting and whitelisting functions in TDD mode. The functions are enabled only when this option is selected.

FDD_VALID_SW: Indicates whether to enable the blacklisting and whitelisting functions in FDD mode. The functions are enabled only when this option is selected.

For example, blacklist parameters include the NsaDcSwitch parameter in the NRCellAlgoSwitch MO and the SrsPeriod parameter in the NRDUCellSrs MO.
