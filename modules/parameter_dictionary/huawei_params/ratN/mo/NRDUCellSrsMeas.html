NRDUCellSrsMeas

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellSrsMeas

Description

The NRDUCellSrsMeas MO defines NR DU cell SRS measurement, which provides different types of RSRP measurements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLSRSMEAS

Use this command to list the SRS measurement configurations of an NR DU cell.
MOD NRDUCELLSRSMEAS

Use this command to modify the SRS measurement configurations of an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
NSA TDM Power Control Trigger SINR Hyst

Indicates the hysteresis for the SINR threshold of triggering TDM uplink power control for NSA UEs.
NSA TDM Power Control Trigger SINR Thld

Indicates the threshold of triggering TDM uplink power control for an NSA UE. TDM uplink power control is triggered for an NSA DC UE only if the uplink SINR of the UE on the LTE side is less than or equal to this threshold.
NSA Uplink Fallback to LTE SINR Hyst

Indicates the hysteresis for the uplink signal quality threshold used to determine whether to change the uplink data split mode of NSA DC to the LTE-only mode in an NR cell.
NSA Uplink Fallback to LTE SINR Thld

Indicates the uplink signal quality threshold used to determine whether to change the uplink data split mode of NSA DC to the LTE-only mode in an NR cell.
Hyper Cell TRP Handover Delta RSRP

Indicates the SRS RSRP difference based on which handovers are triggered between TRPs for a hyper cell or combined cell. This parameter applies only to low-frequency TDD cells.
NSA UL Path Select SINR High Threshold

Indicates the upper threshold of uplink signal quality for determining uplink data transmission path selection for non-NSA DC data split UEs. If the NR uplink signal quality is continuously greater than the upper threshold, the NSA DC uplink data transmission path selection function switches uplink data transmission to NR.
NSA UL Path Select SINR Low Threshold

Indicates the lower threshold of uplink signal quality for determining uplink data transmission path selection for non-NSA DC data split UEs. If the NR uplink signal quality is continuously lower than the lower threshold, the NSA DC uplink data transmission path selection function switches uplink data transmission to LTE.
NSA Split UL Path Select SINR Threshold

Indicates the threshold of uplink signal quality for determining uplink path selection for NSA DC data split UEs.
NSA UL Path Select SINR Hyst

Indicates the hysteresis to the uplink signal quality evaluation threshold for the NSA DC uplink data transmission path selection function.
NSA UL Path Select SINR Time-to-Trigger

Indicates the time-to-trigger of uplink signal quality evaluation for the NSA DC uplink data transmission path selection function.
NSA UL Path Change to LTE Rate Ratio

Indicates the rate ratio of LTE to NR for the NSA DC uplink data transmission path selection function to switch uplink data transmission to LTE. When the estimated LTE data rate is greater than the estimated NR data rate multiplied by the value of this parameter, uplink data transmission is switched to LTE.
NSA UL Path Change to NR Rate Ratio

Indicates the rate ratio of LTE to NR for the NSA DC uplink data transmission path selection function to switch uplink data transmission to NR. When the estimated LTE data rate is less than the estimated NR data rate multiplied by the value of this parameter, uplink data transmission is switched to NR.
NSA Small Pkt UL Back to NR Penalty Time

Indicates the penalty duration for reselecting an uplink data transmission path after uplink small-packet UEs transfer uplink data transmission to the NR side in the NSA DC uplink data transmission path selection feature. This parameter applies only in FDD and low-frequency TDD.
