gNBAbnMsg

+-gNodeBFunction
  +-gNBAbnMsg

Description

This MO defines a gNodeB debugging message. The gNodeB matches the received or sent message with the debugging message, and discards or modifies the message to solve some network problems. Note that running the ADD GNBABLMSG command will lead to service interruption. Run this command only under the guidance of Huawei technical support.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNBUeInfo MO:
    • If the value of UeInfoIndex in the gNBAbnMsg MO is greater than 0, UeInfoIndex must be already configured in the gNBUeInfo MO.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBABNMSG

Use this command to add a gNodeB debugging message. The gNodeB matches the received or sent message with the debugging message, and then discards or modifies the message according to the specified matching items such as matching point offset, matching length, and matching content.
LST GNBABNMSG

Use this command to query gNodeB debugging message configurations.
RMV GNBABNMSG

Use this command to remove a gNodeB debugging message.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Rule Index

Indicates the index of a rule for a debugging message.
Message Protocol Type

Indicates the interface protocol type of a debugging message. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Message Type

Indicates the No. of the messages transmitted over 3GPP-defined interfaces. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Message Operate Type

Indicates the operation type of messages received or sent by the gNodeB. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Message Match Rule List

Indicates the ID of a matching rule list for messages received or sent by the gNodeB to be matched with a debugging message. The matching rule list ID is a hexadecimal number that consists of a maximum of 20 characters. The associated rule configuration is provided by the gNBAbnMsgMatchRule MO. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
Message Modify Rule List

Indicates the ID of a modification rule list for messages received or sent by the gNodeB. The modification rule list ID is a hexadecimal number that consists of a maximum of 20 characters. The associated rule configuration is provided by the gNBAbnMsgModifyRule MO. If you need to change the value of this parameter, ask for assistance from Huawei technical support.
UE Information Index

Indicates the UE index. The value 0 indicates that all UEs are applicable.
