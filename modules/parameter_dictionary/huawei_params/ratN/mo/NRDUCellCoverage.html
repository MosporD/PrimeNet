NRDUCellCoverage

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellCoverage

Description

An NRDUCellCoverage MO defines the RF equipment information about an NR DU cell. It is configured by network planning engineers based on site requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp
  • Relation with the NRDUCellTrp, NRDUCell, and SECTOREQM MOs:
    • When DuplexMode in the NRDUCell MO corresponding to the NRDUCellTrp MO is set to CELL_SUL, ANTCFGMODE in the SECTOREQM MO corresponding to the NRDUCellCoverage MO must be set to ANTENNAPORT.
  • Relation with the NRDUCell, NRDUCellTrp, and SECTOREQM MOs:
    • If LampSiteCellFlag in the NRDUCell MO corresponding to the NRDUCellTrp MO associated with the NRDUCellCoverage MO is set to YES, DuplexMode is set to CELL_FDD, and ANTCFGMODE in the SECTOREQM MO corresponding to the NRDUCellCoverage MO is set to ANTENNAPORT, the number of TX antennas and the number of RX antennas specified by TxRxMode in the corresponding NRDUCellTrp MO must be the same as the number of TX antennas and the number of RX antennas included in SECTOREQMANTENNA in the corresponding SECTOREQM MO.
    • If LampSiteCellFlag in the NRDUCell MO corresponding to the NRDUCellTrp MO associated with the NRDUCellCoverage MO is set to YES, DuplexMode is set to CELL_TDD, and ANTCFGMODE in the SECTOREQM MO corresponding to the NRDUCellCoverage MO is set to ANTENNAPORT, the number of RX/TX antennas in SECTOREQMANTENNA in the SECTOREQM MO corresponding to the NRDUCellCoverage MO must be 1, 2, or 4, the number of TX antennas must be equal to the number of RX antennas, and the number of RX/TX antennas must be less than or equal to that specified by TxRxMode in the NRDUCellTrp MO.
  • Relation with the SECTOREQM MO:
    • The SECTOREQM MO corresponding to SectorEqmId in an NRDUCellCoverage MO must have been configured.
    • When ANTCFGMODE in the SECTOREQM MO corresponding to the NRDUCellCoverage MO is set to ANTENNAPORT, the active/standby mode of the transmit antenna included in SECTOREQMANTENNA in the corresponding SECTOREQM MO must be MASTER.
    • When at least one NRDUCellCoverage MO is configured, at least one SECTOREQM MO must be configured.
  • Relation with the NRDUCellTrp, SECTOREQM, and NRDUCell MOs:
    • If TxRxMode in an NRDUCellTrp MO corresponding to the NRDUCellCoverage MO is set to 64T64R or 32T32R, ANTCFGMODE in the corresponding SECTOREQM MO must be set to BEAM, BEAMSHAPE must be set to SEC_120DEG, BEAMLAYERSPLIT must be set to None, and BEAMAZIMUTHOFFSET must be set to None. If TxRxMode in an NRDUCellTrp MO corresponding to the NRDUCellCoverage MO is set to 8T8R and FrequencyBand in the associated NRDUCell MO is set to N257, N258, N260, or N261, ANTCFGMODE in the associated SECTOREQM MO must be set to BEAM. If TxRxMode in the NRDUCellTrp MO corresponding to the NRDUCellCoverage MO is set to 8T8R, and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, ANTCFGMODE in the corresponding SECTOREQM MO must be set to ANTENNAPORT.
    • When LampSiteCellFlag in the NRDUCell MO corresponding to the NRDUCellTrp MO associated with the NRDUCellCoverage MO is set to NO and ANTCFGMODE in a SECTOREQM MO corresponding to the NRDUCellCoverage MO is set to ANTENNAPORT, the number of TX antennas and the number of RX antennas specified by TxRxMode in the corresponding NRDUCellTrp MO must be the same as the number of TX antennas and the number of RX antennas included in SECTOREQMANTENNA in the corresponding SECTOREQM MO.
    • When FrequencyBand in the NRDUCell MO corresponding to the NRDUCellTrp MO associated with the NRDUCellCoverage MOs that reference the same sector equipment ID SectorEqmId is set to N257, N258, N260, or N261, at least one SupplementaryCellInd is set to NORMAL_CELL.
    • If FrequencyBand in an NRDUCell MO is not set to N257, N258, N260, or N261 and TxRxMode in the associated NRDUCellTrp MO is set to 2T2R, 4T4R, 2R, 4R, 1T1R, or 2T4R, ANTCFGMODE in the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO must be set to ANTENNAPORT. If TxRxMode in an NRDUCellTrp MO is set to 4R, or DuplexMode in the NRDUCell MO is set to CELL_FDD and TxRxMode in the NRDUCellTrp MO is set to 4T4R, the RRUs corresponding to each antenna can be different (the values of ANTxCN, ANTxSRN, and ANTxSN can be different). The RRUs corresponding to the antennas of a 4T4R cell can be the same RRU or two channels of two different RRUs.
  • Relation with the SECTOREQM and RRU MOs:
    • RS in the RRU MO referenced by the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO must contain the NR RAT.
  • Relation with the NRDUCell, NRDUCellTrpMmwavBeam, SECTOREQM, NRDUCellTrp, and NRCell MOs:
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, NRDUCellTrpMmwavBeam MO instances identified by different NrDuCellTrpId correspond to the same SectorEqmId in the NRDUCellCoverage MO, and the values of RRUCN, RRUSRN, and RRUSN in the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO are the same, Tilt in different NRDUCellTrpMmwavBeam MO instances must be the same when the following conditions are met: 1. The NRDUCellTrpMmwavBeam MO instances are associated with the NRDUCellTrp MO instances through NrDuCellTrpId. 2. NRDUCellTrp MO instances are associated with the NRDUCell MO instances through NrDuCellId. 3. CellActiveState in the NRCell MO corresponding to CellId in the associated NRDUCell MO instances is set to CELL_ACTIVE.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, NRDUCellTrpMmwavBeam MO instances identified by different NrDuCellTrpId correspond to the same SectorEqmId in the NRDUCellCoverage MO, and the values of RRUCN, RRUSRN, and RRUSN in the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO are the same, CoverageScenario in different NRDUCellTrpMmwavBeam MO instances must be the same when the following conditions are met: 1. The NRDUCellTrpMmwavBeam MO instances are associated with the NRDUCellTrp MO instances through NrDuCellTrpId. 2. NRDUCellTrp MO instances are associated with the NRDUCell MO instances through NrDuCellId. 3. CellActiveState in the NRCell MO corresponding to CellId in the associated NRDUCell MO instances is set to CELL_ACTIVE.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, and the values of SECTOREQMID in some SECTOREQM MO instances corresponding to the NRCell MO with CellActiveState being CELL_ACTIVE are the same, then the values of Azimuth in the NRDUCellTrpMmwavBeam MO instances corresponding to the cells with the same SECTOREQMID must be the same.
  • Relation with the NRDUCell, NRDUCellTrp, NRDUCellAlgoSwitch, and SECTOREQM MOs:
    • If the INTER_RRU_CHN_CALIB_SW option of ChnCalibSwitch in the NRDUCellAlgoSwitch MO corresponding to NrDuCellId in the NRDUCell MO is selected, LampSiteCellFlag in the NRDUCell MO must be set to YES, and the number of TX antennas and the number of RX antennas included in SECTOREQMANTENNA in the SECTOREQM MO corresponding to the NRDUCellCoverage MO under the NRDUCellTrp MO corresponding to the NRDUCell MO must be 4.
  • Relation with the NRDUCellAlgoSwitch, NRDUCellTrp, SECTOREQM, and NRDUCell MOs:
    • When the combinations of RRUCN, RRUSRN, and RRUSN in the SECTOREQM MOs corresponding to SectorEqmId in the NRDUCellCoverage MOs corresponding to different NRDUCell MO instances are the same, and LampSiteCellFlag in at least two NRDUCell MO instances is set to NO, the RF_SHUTDOWN_SW option of PowerSavingSwitch in the NRDUCellAlgoSwitch MOs corresponding to these cells must be deselected.
  • Relation with the NRDUCellAlgoSwitch, NRDUCell, SECTOREQM, NRDUCellTrp, and RRU MOs:
    • When the RF_SHUTDOWN_SW option of PowerSavingSwitch in the NRDUCellAlgoSwitch MO is selected, RS must be set to NO(NR_ONLY) or TN(LTE_TDD_NR) in the RRU MO corresponding to RRUCN, RRUSRN, and RRUSN in the SECTOREQM MO associated with SectorEqmId in all the NRDUCellCoverage MOs configured for the corresponding cell.
  • Relation with the NRDUCellTrp, SECTOREQM, and RRU MOs:
    • If TxRxMode in the NRDUCellTrp MO corresponding to the NRDUCellCoverage MO is set to 64T64R, the SPEC_SUB6G_PFM_ENH_NR_TDD option of CUSTOMEDRFSPECSW in the RRU MO used by the corresponding SECTOREQM MO must be deselected.
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If the NRDUCell MO associated with NrDuCellId in the NRDUCellTrp MO is configured, when LampSiteCellFlag in the NRDUCell MO is set to NO, the NRDUCellTrp MO can be configured with a maximum of one associated NRDUCellCoverage MO; When LampSiteCellFlag in the NRDUCell MO is set to YES, the NRDUCellTrp MO can be configured with a maximum of 32 associated NRDUCellCoverage MOs.
    • In an NRDUCell MO, if LampSiteCellFlag and DuplexMode are set to YES and CELL_FDD, respectively, a maximum of 16 associated NRDUCellCoverage MO instances can be configured for the NRDUCellTrp MO.
    • If DuplexMode in an NRDUCell MO is set to CELL_FDD or CELL_TDD, and TxRxMode in the NRDUCellTrp MO is set to 4T4R, AntennaPortMapping in the NRDUCellCoverage MO must be set to DEFAULT, 4T_0213, 4T_0231, 4T_0123, 4T_0132, 4T_0312, or 4T_0321.
    • If DuplexMode in an NRDUCell MO is set to CELL_TDD, and TxRxMode in the NRDUCellTrp MO is set to 8T8R, AntennaPortMapping in the NRDUCellCoverage MO must be set to DEFAULT or 8T_01234567.
    • If DuplexMode in an NRDUCell MO is not set to CELL_FDD or CELL_TDD, TxRxMode in the NRDUCellTrp MO is not set to 4T4R or 8T8R, or LampSiteCellFlag in the NRDUCell MO is set to YES, AntennaPortMapping in the NRDUCellCoverage MO must be set to DEFAULT.
  • Relation with the NRCell, NRDUCell, and NRDUCellTrp MOs:
    • If CellActiveState in an NRCell MO is set to CELL_ACTIVE, an NRDUCell MO must already be configured and CellId in this NRDUCell MO must be set to the same value as CellId in the NRCell MO. In addition, the NRDUCell MO must be configured with at least one NRDUCellTrp MO and one NRDUCellCoverage MO.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and TrpType in the NRDUCellTrp MO corresponding to the NRDUCell MO is set to MASTER_8T8R or MASTER_4T4R, at least one NRDUCellCoverage MO must be configured for the NRDUCellTrp MO instance with TrpType set to SLAVE.
  • Relation with the NRCell, NRDUCellSul, NRDUCell, and NRDUCellTrp MOs:
    • If the value of CellActiveState in an NRCell MO is CELL_ACTIVE, an NRDUCell MO must have been configured and CellId in this NRDUCell MO must be set to the same value as CellId in the NRCell MO. If the NRDUCell MO is configured with an NRDUCellSul MO, the NRDUCell MO corresponding to each NRDUCellSul MO must be configured with at least one NRDUCellTrp MO and each NRDUCellTrp MO must be configured with at least one NRDUCellCoverage MO.
  • Relation with the NRDUCell and NRDUCellTrp MOs:
    • When NrDuCellId in an NRDUCellTrp MO is set to a value configured in the associated NRDUCell MO:
    • If LampSiteCellFlag in the NRDUCell MO is set to YES, SectorEqmId in the associated NRDUCellCoverage MOs must be set to different values.
    • If LampSiteCellFlag in the NRDUCell MO is set to NO, MaxTransmitPower in the corresponding NRDUCellCoverage MO must be set to 65535.
  • Relation with the NRDUCellTrp MO:
    • If TrpType in an NRDUCellTrp MO is set to SLAVE, the values of SectorEqmId in the associated NRDUCellCoverage MOs must be different. In addition, the values must be different from those of SectorEqmId in the associated NRDUCellCoverage MOs associated with the master TRP.
    • When TrpType in an NRDUCellTrp MO is set to SLAVE, a maximum of 32 associated NRDUCellCoverage MOs can be configured for the NRDUCellTrp MO.
  • Relation with the NRDUCellTrp, NRCell, and NRDUCell MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and NrDuCellNetworkingMode in the NRDUCell MO corresponding to the NRCell MO is set to HYPER_CELL or HYPER_CELL_COMBINE_MODE, at least one NRDUCellCoverage MO must be configured under each NRDUCellTrp MO in the NRDUCell MO.
  • Relation with the NRDUCellTrp, NRDUCell, and NRCell MOs:
    • If DuplexMode in NRDUCell MOs corresponding to different NRDUCellTrp MOs associated with the same SectorEqmId in the NRDUCellCoverage MO is set to CELL_TDD and CellActiveState in the NRCell MO corresponding to the NRDUCell MO is set to CELL_ACTIVE, SlotAssignment and SlotStructure configurations for these NRDUCell MOs must be consistent.
  • Relation with the NRDUCellTrp, SECTOREQM, and NRDUCellAlgoSwitch MOs:
    • A maximum of one NRDUCellAlgoSwitch MO with the LTE_NR_DYN_POWER_SHARING_SW option of DynPowerSharingSwitch selected can be configured if this MO corresponds to the NRDUCellTrp MO corresponding to NRDUCellCoverage MOs that reference the same sector equipment ID (specified by SectorEqmId).

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB. It is used with the NrDuCellCoverageId parameter to uniquely identify the coverage area of the NR DU cell.
NR DU Cell Coverage ID

Indicates the ID of a coverage area of an NR DU cell, which is used with the NrDuCellTrpId parameter to uniquely identify the coverage area of the NR DU cell.
Sector Equipment ID

Indicates the ID of a set of sector equipment used by an NR DU cell coverage area, which uniquely identifies the set of sector equipment within a gNodeB. This parameter must be set by network planning engineers based on site requirements.
Max Transmit Power

Indicates the maximum transmit power of a single transmit channel for the carrier in the coverage area of an NR DU cell. This parameter applies only to low-frequency LampSite cells. If this parameter is set to a value in the range of 0 to 600, this parameter specifies the maximum transmit power of the carrier of the low-frequency LampSite RF module. If this parameter is set to 65535, the maximum transmit power of the carrier of the RF module is determined by the MaxTransmitPower parameter corresponding to the NR DU cell TRP.
Antenna Port Mapping

Indicates the mapping between antenna ports and RRU channels.

For TDD 4T cells and FDD 4T cells:

For example, value 4T_0312 indicates that ports 0, 3, 1, and 2 are mapped to RRU channels A, B, C, and D, respectively.

For TDD 4T cells, the RRU channels corresponding to antenna ports 0 and 2 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 1 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For FDD 4T cells, the RRU channels corresponding to antenna ports 0 and 1 must be connected to a pair of physical antennas with the same polarization mode, and the RRU channels corresponding to antenna ports 2 and 3 must be connected to another pair of physical antennas with the same polarization mode.

For TDD 8T cells:

For example, value 8T_01234567 indicates that ports 0 to 7 are mapped to RRU channels A to H, respectively.

The TDD 8T RRU ports must be correctly connected to the TDD 8T antenna ports. The default value of this parameter for TDD 8T RRUs is 8T_32107654.

When Huawei 8T8R RRUs are used, Huawei 8T8R antennas or antennas that comply with the Next Generation Mobile Network (NGMN) standard are recommended. If antennas from other vendors or antennas that do not comply with the NGMN standard are used, polarization sequence mismatch may occur, affecting the cell coverage.
