NRCellRelation

+-gNodeBFunction
  +-NRCell
    +-NRCellRelation

Description

An NRCellRelation MO consists of parameters included in the measurement configuration, which are used in handovers and cell reselections.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the NRCellRelation cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe. If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRCellRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellRelation MO instances must be less than or equal to 144 x 256.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellRelation MO instances must be less than or equal to 36 x 256.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRCellRelation MO instance cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellRelation MO instances must be less than or equal to 36 x 256.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCellRelation MO instances cannot be added.
  • Relation with the NRCell MO:
    • The serving cell specified by NrCellId in an NRCellRelation MO can be configured with a maximum of 384 neighboring cells.
  • Relation with the gNBSharingMode, gNodeBFunction, gNBOperator, and NRCell MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, the CGI of the serving cell specified by NrCellId in an NRCellRelation MO must not be identical with the CGIs of neighboring cells specified by CellId in the NRCellRelation MO. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the gNodeBFunction, gNBOperator, NRExternalNCell, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the value of gNBId in an NRCellRelation MO is inconsistent with that of gNBId in the gNodeBFunction MO, an NRExternalNCell MO must be configured first.
  • Relation with the gNodeBFunction, gNBOperator, NRCell, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and intra-site cells are configured as neighboring cells of each other in the NRCellRelation MOs, a neighboring cell specified by CellId in the NRCellRelation MOs and the serving cell must already be configured. In addition, an NRCell MO referenced by CellId, Mcc, and Mnc of the neighboring cell must already be configured.
  • Relation with the gNodeBFunction, NRDUCell, NRCell, gNBOperator, and gNBSharingMode MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to OFF and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which is referenced by NrCellId in an NRCellRelation MO. The values of Mcc and Mnc in this NRCellRelation MO are the same as Mcc and Mnc in the gNBOperator MO, respectively. gNBId in this NRCellRelation MO is the same as gNBId in the gNodeBFunction MO. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with CellId in the NRCellRelation MO, and DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRExternalNCell, NRDUCell, and NRCell MOs:
    • The NRDUCell and NRExternalNCell MO instances meet the following conditions: 1. The NRDUCell MO instance is associated with CellId in an NRCell MO, which is correlated with the NRCellRelation MO through NrCellId. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. 2. The values of Mcc, Mnc, gNBId, and CellId in the NRCellRelation MO are equal to their counterparts in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is the same as the value of SsbDescMethod in the NRExternalNCell MO, the value of SsbFreqPos in the NRDUCell MO must be different from the value of SsbFreqPos in the NRExternalNCell MO. If the value of PhysicalCellId in the NRDUCell MO is the same as the value of PhysicalCellId in the NRExternalNCell MO and the value of SsbDescMethod in the NRDUCell MO is different from the value of SsbDescMethod in the NRExternalNCell MO, the NR-ARFCN corresponding to SsbFreqPos in the NRDUCell MO must be different from the NR-ARFCN corresponding to SsbFreqPos in the NRExternalNCell MO.
  • Relation with the gNBSharingMode, gNBOperator, NRDUCell, NRDUCellOp, and NRCell MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the NR CGI of the serving cell (consisting of Mcc, Mnc, gNBId, and CellId corresponding to OperatorId in the NRDUCellOp MO with CellPrimaryOpFlag set to TRUE associated with the NRDUCell MO corresponding to NrCellId in the NRCellRelation MO) must not be identical with the CGIs of neighboring cells. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the gNBOperator, NRExternalNCell, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and the combination of Mnc, Mcc, and gNBId in an NRCellRelation MO is inconsistent with the combination of Mcc, Mnc, and gNBId in the gNBOperator MO, the combination of Mnc, Mcc, gNBId, and CellId in the NRCellRelation MO must already be configured in an NRExternalNCell MO.
  • Relation with the gNBOperator, NRDUCellOp, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON and the combination of Mcc, Mnc, and gNBId in an NRCellRelation MO has been configured in a gNBOperator MO, the combination of CellId and OperatorId corresponding to Mnc and Mcc must already be configured in an NRDUCellOp MO with CellPrimaryOpFlag set to TRUE.
  • Relation with the NRDUCell, NRCell, gNBOperator, NRDUCellOp, and gNBSharingMode MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to ON and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which referenced by NrCellId in an NRCellRelation MO. The combination of gNBId, Mcc, and Mnc in this NRCellRelation MO has been configured in the gNBOperator. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with NrDuCellId in the NRDUCellOp MO in which the combination of OperatorId and CellId corresponding to Mnc and Mcc in the NRCellRelation MO has been configured. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Mobile Country Code

Indicates the MCC of the operator who owns a neighboring NR cell. The MCC, together with the MNC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.
Mobile Network Code

Indicates the MNC of the operator who owns a neighboring NR cell. The MNC, together with the MCC, forms the PLMN. The MCC is a string of three decimal digits, and the MNC is a string of two to three decimal digits.
gNodeB ID

Indicates the gNodeB ID of a neighboring NR cell. It uniquely identifies a gNodeB within a PLMN.
Cell ID

Indicates the cell ID of a neighboring NR cell. It uniquely identifies an NR cell within a gNodeB.
Cell Individual Offset

Indicates the cell individual offset between an NR DU cell and a neighboring cell. It affects the probability of triggering measurement reports.
Blind SCell Configuration Flag

Indicates whether a neighboring NR cell can be blindly configured as an SCell. The neighboring NR cell can be configured as an SCell or PSCell in a blind manner only if this parameter is set to TRUE.
No Handover Flag

Indicates whether to allow UE handover based on a neighbor relationship.
No Removal Flag

Indicates whether removal of a neighbor relationship by ANR is permitted.
Neighboring Cell Reselection Offset

Indicates the cell reselection offset of an NR cell relative to a neighboring cell. This parameter is used to control the probability of cell reselection. If this parameter is set to a value other than 0 dB, this parameter is delivered in the q-OffsetCell IE of SIB3 and SIB4.

For details about this parameter, see 3GPP TS 38.304.
Neighboring Cell Class Label

Indicates whether the neighbor relationship is formal or extended.
