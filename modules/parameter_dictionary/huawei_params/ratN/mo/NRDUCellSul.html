NRDUCellSul

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellSul

Description

An NRDUCellSul MO defines a supplementary uplink (SUL) carrier for an NR DU cell. The SUL carrier is used only for spectrum sharing and NR uplink and downlink decoupling. This MO specifies basic information such as the ID of the NR DU cell to which the SUL carrier belongs and the SUL NR DU cell ID. It is configured by network planning engineers based on site requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellTrp, NRDUCell, and NRCell MOs:
    • If CellActiveState in the NRCell MO corresponding to SulNrDuCellId in the NRDUCellSul MO is CELL_ACTIVE, BasebandEqmId in the NRDUCellTrp MO under the NRDUCell MO corresponding to NRCell must be the same as BasebandEqmId in the NRDUCellTrp MO under the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO or be set to 255.
  • Relation with the NRDUCell MO:
    • The NRDUCell MO corresponding to SulNrDuCellId in an NRDUCellSul MO must have been configured. In addition, FrequencyBand in the NRDUCell MO must be set to N80 or N82 or N83 or N84 or N86.
    • DuplexMode in an NRDUCell MO corresponding to SulNrDuCellId in an NRDUCellSul MO must be set to CELL_SUL.
    • FrequencyBand in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO must be set to N78 or N79 or N41. If FrequencyBand in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO is set to N78, FrequencyBand in the NRDUCell MO corresponding to SulNrDuCellId must be set to N80, N82, N83, N84, or N86. If FrequencyBand in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO is set to N79, FrequencyBand in the NRDUCell MO corresponding to SulNrDuCellId must be set to N80. If FrequencyBand in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO is set to N41, FrequencyBand in the NRDUCell MO corresponding to SulNrDuCellId must be set to N80 or N83.
    • The NRDUCell MOs associated with NrDuCellId and SulNrDuCellId in the NRDUCellSul MO must be configured, and the values of NrDuCellId and SulNrDuCellId must be different.
    • SibConfigId in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellSul MO must be the same as SibConfigId in the NRDUCell MO corresponding to SulNrDuCellId in the NRDUCellSul MO.
  • Relation with the NRDUCellSul MO:
    • The NRDUCell MO can be associated with either NrDuCellId or SulNrDuCellId in the NRDUCellSul MO.
    • The value of SulNrDuCellId in a maximum of one NRDUCellSul MO can be the same as the value of NrDuCellId.
  • Relation with the NRCell, NRDUCell, NRDUCellTrp, and NRDUCellCoverage MOs:
    • If the value of CellActiveState in an NRCell MO is CELL_ACTIVE, an NRDUCell MO must have been configured and CellId in this NRDUCell MO must be set to the same value as CellId in the NRCell MO. If the NRDUCell MO is configured with an NRDUCellSul MO, the NRDUCell MO corresponding to each NRDUCellSul MO must be configured with at least one NRDUCellTrp MO and each NRDUCellTrp MO must be configured with at least one NRDUCellCoverage MO.
  • Relation with the NRDUCellAlgoSwitch MO:
    • In the NRDUCellAlgoSwitch MO, if UlDlDecouplingSwitch is set to ON, the NRDUCellSul MO instance corresponding to NrDuCellId must already be configured.
    • If the SUPER_UL_TDM_SCH_SW option of SuperUplinkSwitch in an NRDUCellAlgoSwitch MO is selected, the NRDUCellSul MO corresponding to NrDuCellId must already be configured.
  • Relation with the NRDUCell and NRDUCellAlgoSwitch MOs:
    • When DuplexMode in an NRDUCell MO is set to CELL_SUL and the RB_DYNAMIC_SHARING_SW option of RanSharingAlgoSwitch in the NRDUCellAlgoSwitch MO corresponding to NrDuCellId in the NRDUCellSul MO associated with the cell is deselected, the RB_DYNAMIC_SHARING_SW option of RanSharingAlgoSwitch in the NRDUCellAlgoSwitch MO corresponding to the cell must be deselected.
    • When DuplexMode in an NRDUCell MO is set to CELL_SUL and the MAX_RB_LIMIT_SW option of RanSharingAlgoSwitch in the NRDUCellAlgoSwitch MO corresponding to NrDuCellId in the NRDUCellSul MO associated with the cell is deselected, the MAX_RB_LIMIT_SW option of RanSharingAlgoSwitch in the NRDUCellAlgoSwitch MO corresponding to the cell must be deselected.
  • Relation with the NRDUCellSpctCloud and gNBDULteNrSpctShrCg MOs:
    • If the SUL_CHANNEL_DECOUPLE_SW option of UlDlDecouplingAlgoSwitch in an NRDUCellSul MO is selected, LteNrUlSpectrumShrMode in the gNBDULteNrSpctShrCg MO corresponding to NrSpctShrCellGrpId in the NRDUCellSpctCloud MO corresponding to SulNrDuCellId in the NRDUCellSul MO cannot be set to STATIC_SHARING.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
SUL NR DU Cell ID

Indicates the ID of the SUL NR DU cell involved in NR uplink and downlink decoupling.
RSRP Threshold

Indicates the RSRP threshold for selecting an uplink carrier for UEs in idle mode or during SgNB addition in EN-DC scenarios. If the RSRP is greater than the threshold, a UE performs access on the normal UL carrier. If the RSRP is lower than the threshold, the UE performs access on the SUL carrier.
UL and DL Decoupling Algorithm Switch

Indicates the algorithm switch for the NR uplink and downlink decoupling feature.

SEC_HARMONIC_INTRF_AVOID_SW: Indicates whether to enable secondary harmonic interference avoidance.

UL_CARR_SEL_FOR_UE_EXP_SW: Indicates whether to enable user-experience-based uplink carrier selection.

SUL_CHANNEL_DECOUPLE_SW: Indicates whether to enable decoupling of channels on the SUL carrier.

INTRA_GNB_SUL_COMP_SW: Indicates whether to enable SUL CoMP.
SRS RSRP Threshold

Indicates the SRS RSRP threshold for selecting an uplink carrier for UEs in connected mode. If the SRS RSRP is greater than the threshold, the UE for which UL and DL Decoupling takes effect switches from the SUL carrier to the normal uplink (NUL) carrier. If the SRS RSRP is lower than the threshold, the UE for which UL and DL Decoupling takes effect switches from the NUL carrier to the SUL carrier.
Decoupling Estimate Throughput Gain Factor

Indicates the estimated throughput threshold percentage for switchover from NUL to SUL in uplink and downlink decoupling scenarios. When UEs for which UL and DL Decoupling takes effect camp on the NUL carrier and the estimated uplink throughput of the SUL is greater than the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are handed over from the NUL carrier to the SUL carrier. If the estimated uplink throughput of the SUL is less than or equal to the estimated uplink throughput of the NUL multiplied by this parameter value, the UEs are not handed over from the NUL carrier to the SUL carrier. This parameter applies only to SUL.
