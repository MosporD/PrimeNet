gNBConnStateTimer

+-gNodeBFunction
  +-gNBConnStateTimer

Description

This MO defines connected state timers of the gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNBCONNSTATETIMER

Use this command to list the connected state timer configurations of the gNodeB.
MOD GNBCONNSTATETIMER

Use this command to modify the connected state timer configurations of the gNodeB.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Uu Message Waiting Timer

Indicates the timer governing the period in which the gNodeB waits for a Uu response message from a UE. If the timer expires, the gNodeB initiates a UE context release.
