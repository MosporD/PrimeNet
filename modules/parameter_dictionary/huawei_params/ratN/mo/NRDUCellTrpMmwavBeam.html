NRDUCellTrpMmwavBeam

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellTrpMmwavBeam

Description

The NRDUCellTrpMmwavBeam MO is used to configure mmWave-beam-related parameters such as tilt angles and coverage scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO is configured and FrequencyBand in the NRDUCell MO is not set to N257, N258, N260, or N261, CoverageScenario in the NRDUCellTrpMmwavBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT.
    • If SlotStructure in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO associated with NrDuCellTrpId in the NRDUCellTrpMmwavBeam MO is set to SS203, SS204, SS205, or SS206, CoverageScenario in the NRDUCellTrpMmwavBeam MO must be set to DEFAULT, SCENARIO_101, or SCENARIO_103.
  • Relation with the NRDUCellTrp MO:
    • If TxRxMode in an NRDUCellTrp MO is not set to 2T2R, CoverageScenario in the NRDUCellTrpMmwavBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT, or SCENARIO_101.
  • Relation with the NRDUCell, NRDUCellTrp, and NRDUCellAlgoSwitch MOs:
    • If CoverageScenario in the NRDUCellTrpMmwavBeam MO corresponding to the NRDUCellTrp MO is set to SCENARIO_103, the NARROW_BEAM_PROBE_SW option of FullChannelCovEnhSwitch in the NRDUCellAlgoSwitch MO corresponding to the NRDUCell MO corresponding to the NRDUCellTrp MO must be deselected.
  • Relation with the NRDUCell, NRDUCellCoverage, SECTOREQM, NRDUCellTrp, and NRCell MOs:
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, NRDUCellTrpMmwavBeam MO instances identified by different NrDuCellTrpId correspond to the same SectorEqmId in the NRDUCellCoverage MO, and the values of RRUCN, RRUSRN, and RRUSN in the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO are the same, Tilt in different NRDUCellTrpMmwavBeam MO instances must be the same when the following conditions are met: 1. The NRDUCellTrpMmwavBeam MO instances are associated with the NRDUCellTrp MO instances through NrDuCellTrpId. 2. NRDUCellTrp MO instances are associated with the NRDUCell MO instances through NrDuCellId. 3. CellActiveState in the NRCell MO corresponding to CellId in the associated NRDUCell MO instances is set to CELL_ACTIVE.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, NRDUCellTrpMmwavBeam MO instances identified by different NrDuCellTrpId correspond to the same SectorEqmId in the NRDUCellCoverage MO, and the values of RRUCN, RRUSRN, and RRUSN in the SECTOREQM MO corresponding to SectorEqmId in the NRDUCellCoverage MO are the same, CoverageScenario in different NRDUCellTrpMmwavBeam MO instances must be the same when the following conditions are met: 1. The NRDUCellTrpMmwavBeam MO instances are associated with the NRDUCellTrp MO instances through NrDuCellTrpId. 2. NRDUCellTrp MO instances are associated with the NRDUCell MO instances through NrDuCellId. 3. CellActiveState in the NRCell MO corresponding to CellId in the associated NRDUCell MO instances is set to CELL_ACTIVE.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, and the values of SECTOREQMID in some SECTOREQM MO instances corresponding to the NRCell MO with CellActiveState being CELL_ACTIVE are the same, then the values of Azimuth in the NRDUCellTrpMmwavBeam MO instances corresponding to the cells with the same SECTOREQMID must be the same.
  • Relation with the NRCell, NRDUCell, NRDUCellTrp, NRDUCellTrpBeam, and NRDUFddCellTrpBeam MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR1_TDD, the NRDUCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR2_TDD, the NRDUCellTrpMmwavBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FDD, the NRDUFddCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP in an NR DU cell, which uniquely identifies the TRP within an NR DU cell.
Coverage Scenario

Indicates the antenna coverage scenario. This parameter can be used to adjust the antenna beam pattern. The DSP NRDUCELLTRP command can be executed to query the coverage scenarios supported by different types of AAUs. This parameter applies only to high-frequency cells.
Tilt

Indicates the configured downtilt angle mapping a weight for beamforming. If this parameter is set to 255, the default downtilt angle supported by the hardware is used. The DSP NRDUCELLTRP command can be executed to query the tilt angle adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the tilt angle is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the tilt angle of the cell exceeds the range supported by the AAU, the cell becomes unavailable.
Max SSB Power Offset

Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to high-frequency cells.
Azimuth

Indicates the azimuth mapping a weight for beamforming. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs. This parameter applies only to high-frequency TDD cells.

Before a cell is set up, if the value range of the azimuth is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the azimuth of the cell exceeds the range supported by the AAU, the cell becomes unavailable.
