NRCellQciBearer

+-gNodeBFunction
  +-NRCell
    +-NRCellQciBearer

Description

An NRCellQciBearer MO defines bearer parameter configurations of an NR cell. The configuration can vary with the QCI of a bearer.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the gNBPdcpParamGroup MO:
    • UmPdcpParamGroupId in an NRCellQciBearer MO must be set to a value configured in the associated gNBPdcpParamGroup MO.
    • AmPdcpParamGroupId in an NRCellQciBearer MO must be set to a value configured in the associated gNBPdcpParamGroup MO.
  • Relation with the gNBFlowCtrlParamGrp MO:
    • FlowCtrlParamGroupId in an NRCellQciBearer MO must be set to a value configured in the associated gNBFlowCtrlParamGrp MO.
  • Relation with the NRCell MO:
    • The instance with Qci set to 9 must always exist.
  • Relation with the gNBDrxParamGroup MO:
    • When DrxParamGroupId in an NRCellQciBearer MO is set to a value other than 255, the corresponding gNBDrxParamGroup MO instance must already be configured.
  • Relation with the NRCellInterRHoMeaGrp MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellInterRHoMeaGrp MO, the value of InterRatHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellInterRHoMeaGrp MO.
  • Relation with the NRCellHoEutranMeaGrp MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellHoEutranMeaGrp MO, the value of InterRHoToEutranMeasGrpId in the NRCellQciBearer MO must be set to the value configured in the NRCellHoEutranMeaGrp MO.
  • Relation with the NRCellIntraFHoMeaGrp MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellIntraFHoMeaGrp MO, the value of IntraFreqHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellIntraFHoMeaGrp MO.
  • Relation with the NRCellInterFHoMeaGrp MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellInterFHoMeaGrp MO, the value of InterFreqHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellInterFHoMeaGrp MO.
  • Relation with the NRCellInterFHoMeaGrp and NRCellInterRHoMeaGrp MOs:
    • For NRCellInterRHoMeaGrp and NRCellInterFHoMeaGrp MOs associated with the same NRCellQciBearer MO, the sum of CovInterFreqA2RsrpThld and InterFreqA1A2Hyst must be greater than the sum of CovHoToEutranBlindA2Thld and InterRatHoA1A2Hyst.
  • Relation with the NRCellInterRHoMeaGrp, gNBSharingMode, and gNBOperatorQciParam MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to a gNBOperator MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO < InterRatHoA1RsrpThld in the NRCellInterRHoMeaGrp MO.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in the gNBOperatorQciParam MOs corresponding to a gNBOperator MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO.
  • Relation with the NRCellInterRHoMeaGrp, gNBSharingMode, NRCell, gNBOperator, gNBOperatorQciParam, NRDUCell, and NRDUCellOp MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator MO associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO < InterRatHoA1RsrpThld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in all the gNBOperatorQciParam MOs corresponding to the gNBOperator associated with the NRCell MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO. All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.
  • Relation with the NRCellNsaDcConfigGrp MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellNsaDcConfigGrp MO, the value of NsaDcConfigGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellNsaDcConfigGrp MO.
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the NRCellQciBearer cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe.
    • If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellQciBearer MO instances must be less than or equal to 144 x 30.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTga and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellQciBearer MO instances must be less than or equal to 36 x 30.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCellQciBearer MO instances cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellQciBearer MO instances must be less than or equal to 72 x 30.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellQciBearer MO instances must be less than or equal to 36 x 30.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCellQciBearer MO instances cannot be added.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD NRCELLQCIBEARER

Use this command to add the bearer configurations of an NR cell. The configurations can be added for bearers based on their QCIs.
LST NRCELLQCIBEARER

Use this command to list the bearer configurations of an NR cell. The configurations can be queried for bearers based on their QCIs.
MOD NRCELLQCIBEARER

Use this command to modify the bearer configurations of an NR cell. The configurations can be modified for bearers based on their QCIs.
RMV NRCELLQCIBEARER

Use this command to remove the bearer configurations of an NR cell. The configurations can be removed for bearers based on their QCIs.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
QoS Class Identifier

Indicates the QoS class identifier of radio bearers.
Flow Control Parameter Group ID

Indicates the ID of a flow control parameter group.
AM PDCP Parameter Group ID

Indicates the ID of a PDCP parameter group in AM mode.
UM PDCP Parameter Group ID

Indicates the ID of a PDCP parameter group in UM mode.
RLC Mode

Indicates the RLC transmission mode, which can only be AM or UM. This parameter applies only to the scenario where the setup of the PDCP of the UE bearer is triggered by the current gNodeB. If the RLC mode of the related bearer over the terrestrial link (X2/Xn/NG) is obtained, this RLC mode is used, and this parameter does not take effect.
DRX Parameter Group ID

Indicates the ID of a DRX parameter group. If this parameter is set to a value in the range of 0 to 63, valid DRX parameters are configured for a QCI. If this parameter is set to 255, DRX is disabled for a QCI.
Inter-RAT HO Meas Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover.
Inter-RAT HO to E-UTRAN Meas Group ID

Indicates the ID of a measurement parameter group related to inter-RAT handover to E-UTRAN.
Intra-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to intra-frequency handover.
Inter-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-frequency handover.
NSA DC Configuration Group ID

Indicates the ID of an NSA DC configuration parameter group.
