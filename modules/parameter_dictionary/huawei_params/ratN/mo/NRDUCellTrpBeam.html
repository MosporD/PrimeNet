NRDUCellTrpBeam

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellTrpBeam
      +-NRDUCellTrpCustBeam[0~8]

Description

This MO is used to configure beam-related parameters such as tilt angles and coverage scenarios. It applies only to low-frequency cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp

  • Possible children:

    NRDUCellTrpCustBeam[0~8]
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • When the NRDUCell MO corresponding to NrDuCellId in the NRDUCellTrp MO is configured and FrequencyBand in the NRDUCell MO is set to N41, N77, N78, or N79, CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT, SCENARIO_1 to SCENARIO_16, EXPAND_SCENARIO_1 to EXPAND_SCENARIO_6, or CUSTOMIZED_BEAM_SCENARIO. When FrequencyBand in the NRDUCell MO is set to other values for low frequencies, CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO must be set to DEFAULT.
  • Relation with the NRDUCellTrp, NRDUCell, and NRDUCellTrpCustBeam MOs:
    • When CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the NRDUCell MO is set to 4_1_DDDSU or 7_3_DDDSUDDSUU, BeamId with the value range from 0 to 6 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.
    • When CoverageScenario in the NRDUCellTrpBeam MO corresponding to the NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the NRDUCell MO is set to 8_2_DDDDDDDSUU, BeamId with the value range from 0 to 7 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.
    • If CoverageScenario in the NRDUCellTrpBeam MO under an NRDUCellTrp MO is set to CUSTOMIZED_BEAM_SCENARIO and SlotAssignment in the associated NRDUCell MO is set to 8_2_DDDSUUDDDD, BeamId with IDs from 0 to 5 corresponding to NrDuCellTrpId in the NRDUCellTrpCustBeam MO must already be configured.
  • Relation with the NRDUCellAlgoSwitch and NRDUCellTrp MOs:
    • If the SSB_PA_SW option of FullChannelCovEnhSwitch in an NRDUCellAlgoSwitch MO is selected and MaxSsbPwrOffset in the NRDUCellTrpBeam MO is set to a value greater than 0, the RF_SHUTDOWN_SW option of PowerSavingSwitch in the NRDUCellAlgoSwitch MO under the same cell must be deselected.
    • If the RIM_ADAPT_AVOID_SW option of RimAlgoSwitch in an NRDUCellAlgoSwitch MO is selected, CoverageScenario in the NRDUCellTrpBeam MO corresponding to NrDuCellId in the NRDUCellAlgoSwitch MO must be set to DEFAULT, SCENARIO_6, or SCENARIO_12.
  • Relation with the NRDUCellAlgoSwitch, NRDUCellTrp, and NRDUCell MOs:
    • If LampSiteCellFlag in an NRDUCell MO is set to NO and the RF_SHUTDOWN_SW option of PowerSavingSwitch in the NRDUCellAlgoSwitch MO is selected, CoverageScenario parameter in the associated NRDUCellTrpBeam MO must be set to DEFAULT, SCENARIO_1, SCENARIO_6, SCENARIO_12, SCENARIO_3, SCENARIO_13 or EXPAND_SCENARIO_1.
  • Relation with the NRDUCell and NRDUCellTrp MOs:
    • If SlotStructure in an NRDUCell MO is set to SS18, SS518, SS1017, or SS818, CoverageScenario in the NRDUCellTrpBeam MO corresponding to NrDuCellId in the NRDUCell MO must be set to DEFAULT, SCENARIO_6, or SCENARIO_12.
  • Relation with the NRCell, NRDUCell, NRDUCellTrp, NRDUCellTrpMmwavBeam, and NRDUFddCellTrpBeam MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR1_TDD, the NRDUCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FR2_TDD, the NRDUCellTrpMmwavBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and FrAndDuplexMode in the NRDUCellTrp MO is set to FDD, the NRDUFddCellTrpBeam MO corresponding to NrDuCellTrpId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.
Coverage Scenario

Indicates the coverage scenario of antennas. The system adjusts beam patterns based on the setting of this parameter. You can run the DSP NRDUCELLTRP command to query the coverage scenario supported by different AAU types. This parameter applies only to low-frequency TDD cells.
Tilt

Indicates the configured downtilt angle mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. If this parameter is set to 255, the default downtilt angle supported by the hardware is used. The DSP NRDUCELLTRP command can be executed to query the tilt angle adjustment range supported by different types of AAUs.

Before a cell is set up, if the value range of the tilt angle is beyond the range supported by the AAU, the cell fails to be set up. After the cell is set up, if the tilt angle of the cell exceeds the range supported by the AAU, the value configured last time takes effect.

When multiple cells are configured on an AAU with an RET system, the downtilt angles of all cells must be the same. Otherwise, cell setup fails.

If the CoverageScenario parameter is set to CUSTOMIZED_BEAM_SCENARIO, this parameter must be set to 0, and the tilt that takes effect is the NRDUCellTrpCustBeam.Tilt parameter value.
Azimuth

Indicates the configured horizontal azimuth mapping a weight for beamforming. This parameter applies only to low-frequency TDD cells. The DSP NRDUCELLTRP command can be executed to query the azimuth adjustment range supported by different types of AAUs.

If the CoverageScenario parameter is set to CUSTOMIZED_BEAM_SCENARIO, this parameter must be set to 0, and the azimuth that takes effect is the NRDUCellTrpCustBeam.Azimuth parameter value.
Max SSB Power Offset

Indicates the maximum offset of the power used for sending all SSBs of the specific TRP for a specific cell relative to the reference power. If the configured value exceeds the maximum aggregation capability, the actual value is determined by the maximum aggregation capability. This parameter applies only to low-frequency TDD cells.
Scenario Beam Algorithm Switch

Indicates the switch of the scenario-based beam algorithm. SCENARIO_BEAM_DENSIFY_ALGO_SW: Indicates whether to enable beam densification (broadcast/RMSI beam densification). This parameter applies only to low-frequency TDD cells.
