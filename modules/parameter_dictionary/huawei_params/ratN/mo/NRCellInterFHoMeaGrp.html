NRCellInterFHoMeaGrp

+-gNodeBFunction
  +-NRCell
    +-NRCellInterFHoMeaGrp

Description

An NRCellInterFHoMeaGrp MO defines a group of measurement parameters related to intra-RAT inter-frequency handover. Parameter settings can be QCI-specific to meet various requirements of services for target cells. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the NRCellQciBearer MO:
    • If the value of NrCellId in an NRCellQciBearer MO is the same as that of NrCellId in an NRCellInterFHoMeaGrp MO, the value of InterFreqHoMeasGroupId in the NRCellQciBearer MO must be set to the value configured in the NRCellInterFHoMeaGrp MO.
  • Relation with the NRCellQciBearer and NRCellInterRHoMeaGrp MOs:
    • For NRCellInterRHoMeaGrp and NRCellInterFHoMeaGrp MOs associated with the same NRCellQciBearer MO, the sum of CovInterFreqA2RsrpThld and InterFreqA1A2Hyst must be greater than the sum of CovHoToEutranBlindA2Thld and InterRatHoA1A2Hyst.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Inter-freq Handover Measurement Group ID

Indicates the ID of a measurement parameter group related to inter-frequency handover.
Inter-frequency A4A5 Time to Trigger

Indicates the time-to-trigger of events A4 and A5 related to inter-frequency measurement. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. Set this parameter to reduce the probability of occasional event reports, the average number of handovers, and the number of unexpected handovers, and to prevent unnecessary handovers. For details, see 3GPP TS 38.331.
Inter-frequency A4A5 Hysteresis

Indicates the hysteresis of events A4 and A5 related to inter-frequency measurement. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.
Inter-frequency A1A2 Time to Trigger

Indicates the time-to-trigger of events A1 and A2 related to inter-frequency measurement. When detecting that the entering conditions for the corresponding event are fulfilled, a UE does not immediately send a measurement report. Instead, a UE sends a measurement report only when the entering conditions are fulfilled throughout the corresponding time-to-trigger. For details, see 3GPP TS 38.331.
Inter-frequency A1A2 Hysteresis

Indicates the hysteresis of events A1 and A2 related to inter-frequency measurement. Set this parameter to prevent the entering and leaving conditions from being frequently satisfied in the case of radio signal fluctuation. In this way, the probability of ping-pong handovers and incorrect decisions is reduced. A larger value of this parameter results in a lower probability of ping-pong handovers and incorrect decisions. For details, see 3GPP TS 38.331.
Freq Priority Inter-freq A2 RSRP Threshold

Indicates the RSRP threshold for event A2 related to frequency-priority-based inter-frequency handover. For details, see 3GPP TS 38.331.

Indicates the RSRP threshold for event A1 related to frequency-priority-based inter-frequency handover. For details, see 3GPP TS 38.331.

If the measured RSRP value of the serving cell is below this threshold throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig and the measured RSRP value of a neighboring cell is greater than the threshold specified by the CovInterFreqA5RsrpThld2 parameter, an event A5 report will be sent. For details, see 3GPP TS 38.331.

If the measured RSRP value of the serving cell is below the threshold specified by CovInterFreqA5RsrpThld1 throughout the time-to-trigger specified by InterFreqA4A5TimeToTrig and the measured RSRP value of a neighboring cell is greater than the threshold specified by the CovInterFreqA5RsrpThld2 parameter, an event A5 report will be sent. Indicates the RSRP threshold for event A4 related to operator-specific priority-based inter-frequency handover. If the measured RSRP value of a neighboring cell is greater than this threshold throughout the time-to-trigger specified by NRCellnterFHoMeaGrp.InterFreqA4A5TimeToTrig, an event A4 inter-frequency measurement report will be sent.
