gNBSibConfig

+-gNodeBFunction
  +-gNBSibConfig

Description

This MO is used to customize a set of system information transmission policies to meet customized requirements in different scenarios. The MO defines the system information type, system information transmission period, and system information transmission mode.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRDUCell MO:
    • If the instance referenced by NRDUCell contains SibConfigId, ensure that at least one instance contains SibConfigId.
  • Relation with the gNodeBFunction MO:
    • When the gNodeBFunction MO instance associated with the gNBSibConfig MO exists and SibConfigId is set to 0:
    • There must be a gNBSibConfig MO with SibType set to SIB_TYPE_2, SibTransPeriod set to 320MS, and SibTransPolicy set to BROADCAST.
    • There must be a gNBSibConfig MO with SibType set to SIB_TYPE_3, SibTransPeriod set to 320MS, and SibTransPolicy set to BROADCAST.
    • There must be a gNBSibConfig MO with SibType set to SIB_TYPE_4, SibTransPeriod set to 320MS, and SibTransPolicy set to BROADCAST.
    • There must be a gNBSibConfig MO with SibType set to SIB_TYPE_5, SibTransPeriod set to 640MS, and SibTransPolicy set to BROADCAST.
    • There must be a gNBSibConfig MO with SibType set to SIB_TYPE_9, SibTransPeriod set to 320MS, and SibTransPolicy set to OFF.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
SIB Config ID

Indicates the ID of a set of system information configuration, including the system information type, system information transmission period, and system information transmission mode.
SIB Type

Indicates the system information type. For details about this parameter, see 3GPP TS 38.331.
SIB Transmission Period

Indicates the system information transmission period. For details about this parameter, see 3GPP TS 38.331.
SIB Transmission Policy

Indicates the system information transmission mode. The value OFF indicates that system information of a SIB type cannot be broadcast. The value BROADCAST indicates that system information of a SIB type is broadcast continuously. The value ON_DEMAND indicates that system information of a SIB type can be broadcast only after being subscribed by UEs. For details about this parameter, see 3GPP TS 38.331.
