NRCellEutraNRelation

+-gNodeBFunction
  +-NRCell
    +-NRCellEutraNRelation

Description

This MO consists of inter-RAT neighboring E-UTRAN cell parameters used for handovers. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the gNBEutraExternalCell MO:
    • The gNBEutraExternalCell MO corresponding to an NRCellEutraNRelation MO must have been configured.
  • Relation with the NRCell MO:
    • The serving cell specified by NrCellId in an NRCellEutraNRelation MO can be configured with a maximum of 384 E-UTRAN neighboring cells.
  • Relation with the gNBEutraExternalCell and NRCellEutranNFreq MOs:
    • The value of DlEarfcn in a gNBEutraExternalCell MO corresponding to an NRCellEutraNRelation MO must be the same as the value of DlEarfcn in an NRCellEutranNFreq MO corresponding to the NRCellEutraNRelation MO.
  • Relation with the MPT and NODE MOs:
    • If the value of TYPE in the MPT is not UMPT, the NRCellEutraNRelation cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe. If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • When the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRCellEutraNRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutraNRelation MO instances must be less than or equal to 144 x 256.
    • When the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutraNRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellEutraNRelation MO instances must be less than or equal to 36 x 256.
    • When the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRCellEutraNRelation MO instance cannot be added.
    • When the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutraNRelation MO instances must be less than or equal to 72 x 256.
    • When the board type is UMPTe and WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellEutraNRelation MO instances must be less than or equal to 36 x 256.
    • When the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, NRCellEutraNRelation MO instances cannot be added.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the cell within a gNodeB.
Mobile Country Code

Indicates the mobile country code of the neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.
Mobile Network Code

Indicates the mobile network code of a neighboring E-UTRAN cell. A PLMN ID is comprised of an MCC and an MNC. The MCC consists of three digits. The MNC consists of two or three digits. For example, MCC = 123, MNC = 45, PLMN = 12345.
eNodeB ID

Indicates the eNodeB ID of the inter-RAT neighboring E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the ID of an inter-RAT neighboring E-UTRAN cell. It uniquely identifies a cell within an eNodeB. A 28-bit E-UTRAN cell identifier (ECI) is comprised of a cell ID (represented by the least significant eight bits) and an eNodeB ID. An E-UTRAN cell global identifier (ECGI) is comprised of an ECI and a PLMN ID. For details, see 3GPP TS 36.413.
E-UTRAN Cell Individual Offset

Indicates the cell individual offset between the local cell and a neighboring E-UTRAN cell. It determines the probability of triggering event B1/B2 measurement reports. A larger value of this parameter results in a higher probability of triggering measurement reports.
E-UTRAN Cell Reselection Offset

Indicates the reselection offset between the local cell and a neighboring E-UTRAN cell. It determines the probability of triggering cell reselection from NR to LTE.
No Handover Flag

Indicates whether to allow UEs to be handed over based on the neighbor relationship.
No Removal Flag

Indicates whether removal of a neighbor relationship by ANR is permitted.
Minimum RX Level Offset

Indicates the offset to the minimum required RX level of an E-UTRAN cell. This value is included in criteria S and used in the evaluation of cell selection. This parameter is valid only when cell selection is triggered by periodic searches for high-priority PLMNs and a UE is served by a visited public land mobile network (VPLMN). For details, see 3GPP TS 38.304.
