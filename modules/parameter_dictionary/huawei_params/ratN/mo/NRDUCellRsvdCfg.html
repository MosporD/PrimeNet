NRDUCellRsvdCfg

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellRsvdCfg

Description

This MO consists of parameters used in comparison tests and is used to improve performance in extreme test scenarios.

Parameters in this MO will be used for a long term.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Table 1 Related MML commands

Function

Use this command to modify the configuration of a reserved parameter for NR DU cell commissioning.
