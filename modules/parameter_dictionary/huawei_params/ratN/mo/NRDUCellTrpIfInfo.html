NRDUCellTrpIfInfo

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellTrpIfInfo

Description

This MO consists of the intermediate frequency information of a cell, including uplink and downlink frequency information, output power, and uplink channel gains. It is used for interconnecting to an intermediate frequency repeater. This MO applies to NR TDD.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to add the TRP intermediate frequency configuration of an NR DU cell.
LST NRDUCELLTRPIFINFO

Use this command to list the TRP intermediate frequency configuration of an NR DU cell.
MOD NRDUCELLTRPIFINFO

Use this command to modify the TRP intermediate frequency configuration of an NR DU cell.
RMV NRDUCELLTRPIFINFO

Use this command to remove the TRP intermediate frequency configuration of an NR DU cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a DU.
NR IF Downlink Center Frequency

Indicates the downlink center frequency of intermediate frequency.
NR IF Uplink Center Frequency

Indicates the uplink center frequency of intermediate frequency.
NR IF Output Power

Indicates the output power of intermediate frequency.
NR IF Uplink Receive Gain

Indicates the gains of the uplink RX channel.
