gNodeBParam

+-gNodeBFunction
  +-gNodeBParam

Description

A gNodeBParam MO defines gNodeB-level parameters.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNODEBPARAM

Use this command to query the configuration of gNodeB parameters.
MOD GNODEBPARAM

Use this command to modify the configuration of a gNodeB Parameter.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Frame Offset

Indicates the offset of the frame start time for all the cells served by the gNodeB relative to the time of the reference clock.

If this parameter is set to a value in the range of 0 to 261120, the reference clock is delayed. The hysteresis is equal to the GUI value.

If this parameter is set to a value in the range of 275943 to 307200, the time advance is equal to 307200 minus the GUI value.

If the frame offset is configured for a cell working in a specific frequency band configured in the gNBFreqBandConfig MO, this frame offset takes effect preferentially.
SNR Threshold for AOA Measurement

Indicates the threshold of the signal-to-noise ratio for triggering angle of arrival (AoA) measurement. The AoA of signals transmitted or received by UEs needs to be measured to locate UEs. The gNodeB measures the AoA only when the signal-to-noise ratio of the signals reaches this threshold.
Frame Offset Auto Correction Switch

Indicates whether to enable automatic frame offset correction. If this parameter is set to ON and the frame offset of the local gNodeB is different from that of other gNodeBs, the local gNodeB automatically changes the frame offset to that of other gNodeBs. If this parameter is set to OFF, the gNodeB cannot automatically change the frame offset.
X2-U Transmission Type

Indicates the transmission mode of user-plane data between LTE and NR in NSA DC scenarios. If this parameter is set to ROUTING_TRANS, user-plane data between LTE and NR is transmitted based on route configurations. If this parameter is set to INTRA_TRANS, user-plane data between LTE and NR is transmitted through an internal network (CI interconnection or backplane transmission). If the internal network is unavailable, user-plane data is transmitted based on route configurations. This mode takes effect only in multimode co-site scenarios. Modification to this parameter applies only to UEs newly accessing the network. It does not apply to UEs that have accessed the network.
NSA DC Resource Coordination Scenario

Indicates the resource coordination application scenarios in NSA DC. When the CROSS_MDLT_INTRF_AVOID_SW or HARMONIC_INTRF_AVOID_SW option of the NRDUCellAlgoSwitch.NsaDcAlgoSwitch parameter or the NSA_DC_ENH_UL_POWER_CONTROL_SW option of the NRCellNsaDcConfig.NsaDcAlgoSwitch parameter is selected, the gNodeB generates different resource coordination diagrams based on this parameter and sends them to the eNodeB. The value SYNC_NSA_DC_0_FRAME_OFT indicates synchronous DC with the relative frame offset between LTE and NR being 0 ms. The value SYNC_NSA_DC_3Pl2Mi_FRAME_OFT indicates synchronous DC with the frame offset of NR relative to LTE being plus 3 ms or minus 2 ms. The value ASYNC_NSA_DC indicates asynchronous DC. The intermodulation interference avoidance function and TDM power control function do not take effect in asynchronous NSA DC mode. If this parameter value is changed, this parameter takes effect only for UEs that newly access the network.
Clock Out-of-sync Detect Switch

Indicates the clock out-of-synchronization configuration switches.

CLK_DETECT_SW: Indicates whether to enable clock out-of-synchronization detection. Clock out-of-synchronization detection is enabled only if this option is selected. This option applies only to low-frequency TDD cells.

CLK_PROCESS_SW: Indicates whether to enable postprocessing for clock out-of-synchronization. If this option is deselected, the gNodeB does not take any measure after clock out-of-synchronization. If this option is selected, the gNodeB deactivates all NR TDD cells served by the gNodeB after clock out-of-synchronization. This option applies only to low-frequency TDD cells.
Clock Out-of-sync Intrf Report Thld

Indicates the threshold for reporting the clock out-of-synchronization interference value. If the average uplink interference is greater than this threshold, the base station reports the clock out-of-synchronization interference value. Then, the clock out-of-synchronization function detects the characteristic sequence. This parameter applies only to low frequency TDD cells.
Silence Detect Intrf Difference Thld

Indicates the interference difference threshold for silence detection in the clock out-of-synchronization detection. It is used to locate out-of-synchronization base stations. When the intersymbol interference difference between base stations performing silence detection is greater than this threshold, the silent base station is regarded as an out-of-synchronization base station. This parameter applies only to low frequency TDD cells.
NSA DC Optimization Switch

Indicates whether to enable NSA DC optimization.

NSA_DC_SRB3_SWITCH: Indicates whether to support the NSA DC SRB3 function. This function is enabled only if this option is selected. When this function is enabled, the gNodeB and UE can exchange signaling using SRB3. For details about this option, see 3GPP TS 37.340.

NSA_DC_FAST_RETRANS_SWITCH: Indicates whether to support fast retransmission for downlink data split in NSA DC scenarios. This function is supported only if this option is selected.

NON_CA_NSA_DC_COMB_SELECT_SW: Indicates whether to preferentially guarantee the throughput on the LTE side or the throughput on the NR side in non-CA scenarios. If this option is selected, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the NR side. If this option is deselected, the gNodeB selects an NSA DC combination that can preferentially guarantee the throughput on the LTE side.
Base Station Deep Dormancy Switch

Indicates whether to enable deep dormancy for the base station. BB_SHUTDOWN_POWERSAVING_SW: Indicates whether to enable energy saving by baseband shutdown. If this option is selected, the baseband can be shut down for energy saving when no cells are set up on the baseband, the carriers of deployed cells are shut down, or the deployed cells are blocked. If this option is deselected, energy saving by baseband shutdown is disabled.
LF Holdover Duration After GPS Failure

Indicates the holdover duration after the GPS clock source is unavailable in low-frequency NR TDD cells.
Synchronization Difference Detect Switch

Indicates whether to enable clock synchronization deviation detection. If this parameter is set to ON, clock synchronization deviation detection is enabled on the local gNodeB. If this parameter is set to OFF, clock synchronization deviation detection is disabled on the local gNodeB. This parameter applies only to low-frequency TDD cells.
Max FH Fiber Length Adapt Switch

Indicates whether the gNodeB adaptively selects a time budget based on the length of optical fiber for fronthaul in eCPRI/CPRI scenarios.

When this switch is turned on, the gNodeB automatically detects the length of optical fiber for fronthaul and adaptively selects a time budget based on the length. If the time budget for the 0.5 km length is used, better delay gains can be obtained. In this case, inter-BBP eCPRI/CPRI forwarding is not supported. When this switch is turned off, the gNodeB does not adaptively select a time budget and the time budget for the 20 km length is used by default.
Max X2 Transmission Rate

Indicates the maximum transmission rate for PDCP data split and data forwarding over the X2 interface in NSA DC scenarios. The value that takes effect equals the GUI value multiplied by the step. The packet transmission rate at the PDCP layer is the value that takes effect converted into megabits per millisecond.
Service Interface Alarm Config Switch

Indicates whether to suppress the fault alarms of lower-layer links carrying terrestrial interfaces.

BEARER_OF_X2_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an X2 interface fault and an X2 transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29800 gNodeB X2 Interface Fault is reported when the values of GlobaleNodeBId_MCC-MNC-eNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_XN_SHIELD_SW: Indicates whether to suppress transmission link alarms (ALM-25888 SCTP Link Fault and ALM-25952 User Plane Path Fault). If this option is selected and an Xn interface fault and an Xn transmission link fault occur at the same time, transmission link alarms are suppressed and only ALM-29810 gNodeB Xn Interface Fault is reported when the values of GlobalgNBId_MCC-MNC-gNodeBId included in user labels of the user-plane peer and SCTP peer are the same. If this option is deselected, transmission link alarms are not suppressed.

BEARER_OF_NG_SHIELD_SW: Indicates whether to suppress the transmission link alarm (ALM-25888 SCTP Link Fault). If this option is selected and an NG interface fault and an NG transmission link fault occur at the same time, the transmission link alarm is suppressed and only ALM-29815 gNodeB NG Interface Fault is reported. If this option is deselected, the transmission link alarm is not suppressed.
CHR Switch

Indicates whether to enable CHR-related functions.

STMSI_MASK_SW: Indicates whether to record S-TMSIs in CHRs. For details, see 3GPP TS 23.003. When this option is selected, S-TMSIs are not recorded in CHRs. When this option is deselected, S-TMSIs can be recorded in CHRs as required.
Auto Cell Bind Baseband Equipment Switch

Indicates whether to automatically bind baseband equipment to the NR DU cell TRP. This parameter is valid only when the NRDUCellTrp.BasebandEqmId parameter is set to 255. If this switch is turned on, the system automatically changes the value of NRDUCellTrp.BasebandEqmId to the ID of the baseband equipment used by the cell after the cell is successfully set up. If the NRDUCellTrp.BasebandEqmId parameter is automatically modified by the system while this parameter is modified on the OSS, the modification on the OSS may be overwritten by the automatic modification. If this switch is turned off, the system does not automatically modify the NRDUCellTrp.BasebandEqmId parameter.
Service Differentiation Process Switch

Indicates differentiated service processing algorithm switches.

SPARSE_DIFF_PROC_SW: Indicates whether to enable differentiated processing for sparse-packet services. If this option is selected, the base station performs differentiated processing for sparse-packet services. If this option is deselected, the base station does not perform differentiated processing for sparse-packet services. This parameter applies only in FDD and low-frequency TDD.
