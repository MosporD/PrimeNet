NRDUCellTrp

    +-NRDUCellCoverage[0~1]

Description

An NRDUCellTrp MO defines the basic TRP information such as information of baseband equipment and RF equipment. It is configured by network planning engineers based on site requirements.

Immediately

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB.
NR DU Cell ID

Indicates the ID of an NR DU cell. It uniquely identifies an NR DU cell within a gNodeB. When virtual MIMO is enabled for LampSite base stations, the NrDuCellId parameter of the slave TRP must be set to 65535.
Transmit and Receive Mode

Indicates the TX and RX modes of a TRP in an NR DU cell.
Baseband Equipment ID

Indicates the ID of the baseband equipment used by a TRP in an NR DU cell. If this parameter is set to 255, the baseband equipment used by the TRP in the NR DU cell is unspecified and will be selected automatically by the software.

If this parameter is not set to 255, the baseband equipment used by the TRP in the NR DU cell is specified and the TRP can only use the baseband processing boards in the specified set of baseband equipment.
Max Transmit Power

Indicates the maximum transmit power of a single TX channel of the NR DU cell TRP. This parameter is valid only when PowerConfigMode is set to TRANSMIT_POWER.
CPRI Compression

Indicates the CPRI data compression mode between the baseband processing board and RF module for an NR DU cell. This parameter is valid only when the CPRI protocol is used for data transmission between the baseband processing board and the RF module.
Baseband Resource Mutual Aid Switch

Indicates the baseband resource mutual aid switch for the TRP in an NR DU cell. This parameter is valid only when the baseband equipment ID is valid. When this parameter is set to ON, the cell can use other baseband equipment resources when the baseband equipment resources configured for the cell are faulty. After the baseband equipment recovers, the cell automatically reestablishes in the early morning and attempts to return to the configured baseband equipment. When this parameter is set to OFF, the cell can use only the baseband equipment resources corresponding to the baseband equipment ID.
Branch CPRI Compression

Indicates the mode of CPRI compression over a branch chain of a LampSite cell. This parameter is valid only when the CPRI protocol is used for data transmission between the RHUB and RF unit.
Antenna Polarization

Indicates the antenna polarization mode of a 2T2R/4T4R/8T8R cell. The value SINGLE_POLARIZATION indicates single polarization for a 2T2R/4T4R cell. The value DOUBLE_POLARIZATION indicates dual polarization for a 2T2R/4T4R/8T8R 4H1V cell. The value 2H2V_DOUBLE_POLARIZATION indicates dual polarization for an 8T8R 2H2V cell. The value DEFAULT indicates that the antenna polarization mode of a 2T2R/4T4R cell cannot be obtained, and the antenna polarization mode of an 8T8R cell is the same as that of a 4H1V cell. This parameter applies only in TDD low frequency bands. This parameter applies only to modules with external antenna and does not apply to modules with internal antenna.
Power Config Mode

Indicates the power configuration mode of the NR DU cell TRP. This parameter does not take effect when TxRxMode in the NRDUCellTrp MO is set to 2R or 4R. This parameter must be set to TRANSMIT_POWER for low-frequency cells and the power specified by MaxTransmitPower is used. This parameter must be set to EIRP for high-frequency cells and the power specified by MaxEirp is used.
Max EIRP

Indicates the maximum equivalent isotropically radiated power (EIRP) of all TX channels of the NR DU cell TRP. This parameter is valid only when PowerConfigMode is set to EIRP.
TRP Type

Indicates whether the TRP for a virtual MIMO cell is a master TRP or a slave TRP. This parameter applies only to low-frequency LampSite TDD cells.
Master TRP ID

Indicates the ID of the master TRP for a virtual MIMO cell, which uniquely identifies the master TRP within the virtual MIMO cell. This parameter is valid only when TrpType is set to Slave. This parameter applies only to low-frequency LampSite TDD cells.
Frequency Range and Duplex Mode

Indicates the frequency range and duplex mode of the cell. The value FR1_TDD indicates that the current cell works in low-frequency TDD mode. The value FR2_TDD indicates that the current cell works in high-frequency TDD mode. The value FDD indicates that the current cell works in FDD mode. The value SUL indicates that the current cell works in SUL mode.
