NRDUCellCoreset

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellCoreset

Description

The NRDUCellCoreset MO defines the common control-resource set (CORESET) in an NR DU cell.

Effective Scenario

Immediately
