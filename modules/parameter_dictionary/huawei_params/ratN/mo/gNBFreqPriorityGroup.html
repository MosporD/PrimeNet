gNBFreqPriorityGroup

+-gNodeBFunction
  +-gNBFreqPriorityGroup

Description

This MO defines a gNodeB frequency priority group, which is used to configure the cell reselection priority.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRCellOpPolicy MO:
    • If gNBFreqPriorityGroupId in an NRCellOpPolicy MO is not set to 255, the gNBFreqPriorityGroup MO corresponding to gNBFreqPriorityGroupId must already be configured.
  • Relation with the NRCellOpPolicy and NRCellEutranNFreq MOs:
    • If gNBFreqPriorityGroupId in an NRCellOpPolicy MO is not set to 255, the value of DlEarfcn in all the gNBFreqPriorityGroup MOs with RatType set to EUTRAN must be existent in the NRCellEutranNFreq MOs corresponding to NrCellId in the NRCellOpPolicy MO.
  • Relation with the NRCellOpPolicy, NRCellFreqRelation, NRCell, and NRDUCell MOs:
    • The combination of SsbFreqPos and SsbDescMethod in the gNBFreqPriorityGroup MO corresponding to gNBFreqPriorityGroupId in an NRCellOpPolicy MO must already be existent in the NRCellFreqRelation MO corresponding to NrCellId in the NRCellOpPolicy MO or in the NRDUCell MO corresponding to NrCellId in the NRCellOpPolicy MO.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB Frequency Priority Group ID

Indicates the ID of a gNodeB frequency priority group.
Frequency Index

Indicates the index of a frequency in the gNodeB frequency priority group.
RAT Type

Indicates the RAT corresponding to the frequency.
Downlink EARFCN

Indicates the downlink EARFCN of a neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.104.
Cell Reselection Priority

Indicates the cell reselection priority of the frequency. Value 0 indicates the lowest priority, and value 7 indicates the highest priority.
Cell Reselection Sub-Priority

Indicates the cell reselection sub-priority of the frequency. If this parameter is set to the invalid value 0DOT0, the sub-priority is not delivered. If this parameter is set to a valid value, the UE adds the value of this parameter to that of the gNBFreqPriorityGroup.CellReselPri parameter, uses the sum as the final cell reselection priority of the frequency, and performs cell reselection accordingly.

The summed values of the reselection priority and reselection sub-priority must be different between RATs. For details, see 3GPP TS 38.331.
SSB Frequency Position

Indicates the SSB frequency domain position of an NR frequency. When SsbDescMethod is set to SSB_DESC_TYPE_GSCN, this parameter indicates the Global Synchronization Channel Number (GSCN) corresponding to the SSB of the NR frequency. When SsbDescMethod is set to SSB_DESC_TYPE_NARFCN, this parameter indicates the absolute frequency number corresponding to the SSB of the NR frequency.
SSB Frequency Position Describe Method

Indicates the frequency-domain position description method of the SSB on a neighboring frequency.
Dedicated Freq Priority for Connected Mode

Indicates the connected-mode dedicated priority of a neighboring frequency. The connected-mode frequency priorities can be operator-specific. A larger value of this parameter indicates a higher priority. If this parameter is set to 0, the frequency is not selected as the candidate frequency for operator-specific priority-based handovers.
