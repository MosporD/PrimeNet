gNB5qiConfig

+-gNodeBFunction
  +-gNB5qiConfig

Description

A gNB5qiConfig MO is used to configure parameters of QoS flows with different QoS attributes.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the gNB5qiConfig MO:
    • The gNB5qiConfig MO instances created by the gNodeB by default with Nr5qi separately set to 65, 66, 69, 70, 75, 79, and values in the range from 1 to 9 must always exist, and the value of Qci corresponding to Nr5qi must not be modified.
  • Relation with the gNBQciBearer MO:
    • The sum of gNB5qiConfig MO instances with CounterObjSubscriptionInd set to YES and gNBQciBearer MO instances with CounterObjSubscriptionInd set to YES must be less than or equal to 20.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to add a gNodeB 5QI configuration.

Use this command to list a gNodeB 5QI configuration.

Use this command to modify a gNodeB 5QI configuration.
RMV GNB5QICONFIG

Use this command to remove a gNodeB 5QI configuration.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR 5G QoS Indicator

Indicates a 5G QoS Identifier (5QI). When a 5QI is added on the core network:

1. If configuration for the corresponding Nr5qi value has not been added in the gNB5qiConfig MO, parameter configuration with Nr5qi being 9 is used by default.

2. If configuration for the corresponding Nr5qi value has been added in the gNB5qiConfig MO:

gNB5qiConfig.Qci for the corresponding Nr5qi value must be already configured in the NRCellQciBearer and NRDUCellQciBearer MOs. If it is not configured, parameter configuration with Qci being 9 in the NRCellQciBearer and NRDUCellQciBearer MOs is used by default.

For non-dynamic 5QIs (including pre-configured 5QIs and standardized 5QIs), when the core network does not carry AveragingWindowDur, PacketDelayBudget, or PriorityLevel, gNB5qiConfig.Qci corresponding to the new Nr5qi value must be configured in the gNBQciBearer MO on the gNodeB. Otherwise, parameter configuration with Qci being 9 in the gNBQciBearer MOs is used.
QoS Class Identifier

Indicates the QoS class identifier (QCI) of the radio bearer corresponding to a 5QI.
Counter Object Subscription Indicator

Indicates whether to subscribe to the 5QI counter objects. If this parameter is set to YES, counter objects are subscribed to. If this parameter is set to NO, counter objects are not subscribed to.
AS Reflective QoS Switch

Indicates whether to enable the AS reflective QoS function. When the switch is turned on, a UE can obtain the relationship between a QoS flow and a DRB by monitoring the QFI of the data packets transmitted on the DRB. When this switch is turned off, this function is disabled.
