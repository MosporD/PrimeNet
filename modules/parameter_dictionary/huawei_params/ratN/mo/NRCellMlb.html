NRCellMlb

+-gNodeBFunction
  +-NRCell
    +-NRCellMlb

Description

This MO consists of the parameters for load balancing between NR cells.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function

Use this command to list the MLB parameter settings of an NR cell.

Use this command to modify the MLB parameter settings of an NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of a cell, which uniquely identifies the cell within a gNodeB.
Inter-frequency MLB UE Number Threshold

Indicates the RRC_CONNECTED UE number threshold for triggering inter-frequency MLB. MLB is triggered when the number of RRC_CONNECTED UEs in the given cell is greater than or equal to the summed value of InterFreqMlbUeNumThld and MlbUeNumOffset. MLB is stopped when the number of RRC_CONNECTED UEs is less than the value of InterFreqMlbUeNumThld.
MLB UE Number Offset

Indicates the offset to the number of RRC_CONNECTED UEs for triggering inter-frequency MLB. UE-number-based MLB is triggered if the number of RRC_CONNECTED UEs in the given cell is greater than or equal to the summed value of InterFreqMlbUeNumThld and MlbUeNumOffset.
UE Number Difference Threshold

Indicates the UE number difference threshold for MLB. A neighboring cell can be the target cell for MLB when the following conditions are met: (Number of UEs in the serving cell - Number of UEs in the neighboring cell)/Number of UEs in the serving cell > Threshold specified by this parameter; Number of UEs in the serving cell - Number of UEs in the neighboring cell > 5; Neighboring cell load (in percentage) < 90%.
