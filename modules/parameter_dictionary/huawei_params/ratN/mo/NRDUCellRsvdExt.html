NRDUCellRsvdExt

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellRsvdExt

Description

This MO consists of parameters whose values need to be continuously adjusted on commercial networks to find the values that produce optimal performance. Then the values are fixed and do not need to be modified.

This MO also consists of parameters used in comparison tests and used to improve performance in extreme test scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRDUCELLRSVDEXT

Use this command to list reserved parameter for NR DU cell commissioning, which is an extension of the NRDUCellRsvdExt MO.
MOD NRDUCELLRSVDEXT

Use this command to modify reserved parameter for NR DU cell commissioning, which is an extension of the NRDUCellRsvd MO.
