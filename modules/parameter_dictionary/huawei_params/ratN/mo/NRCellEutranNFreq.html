NRCellEutranNFreq

+-gNodeBFunction
  +-NRCell
    +-NRCellEutranNFreq

Description

An NRCellEutranNFreq MO consists of the common parameters related to a neighboring E-UTRAN frequency. The parameters include the priority for cell reselection and the measurement bandwidth. They are used in measurement configuration and SIB5 for inter-RAT cell reselection. For details, see 3GPP TS 38.331.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell
  • Relation with the gNBEutraExternalCell MO:
    • DlEarfcn in a gNBEutraExternalCell MO must be set to a value configured in the associated NRCellEutranNFreq MO.
  • Relation with the NRCell MO:
    • A maximum of 64 NRCellEutranNFreq instances can be configured for each NRCell.
  • Relation with the NRCellEutraNRelation and gNBEutraExternalCell MOs:
    • The value of DlEarfcn in a gNBEutraExternalCell MO corresponding to an NRCellEutraNRelation MO must be the same as the value of DlEarfcn in an NRCellEutranNFreq MO corresponding to the NRCellEutraNRelation MO.
  • Relation with the NRCellOpPolicy and gNBFreqPriorityGroup MOs:
    • If gNBFreqPriorityGroupId in an NRCellOpPolicy MO is not set to 255, the value of DlEarfcn in all the gNBFreqPriorityGroup MOs with RatType set to EUTRAN must be existent in the NRCellEutranNFreq MOs corresponding to NrCellId in the NRCellOpPolicy MO.
  • Relation with the NRCellReselConfig MO:
    • The value of CellReselPriority in the NRCellReselConfig MO for a cell must be different from the summed value of EutranFreqReselPriority and EutranFreqReselSubPriority in the NRCellEutranNFreq MO for the same cell.
  • Relation with the MPT and NODE MOs:
    • If TYPE in the MPT MO is not set to UMPT, the NRCellEutranNFreq MO instance cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe.
    • If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • If the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRCellEutranNFreq MO instances must be less than or equal to 72 x 32.
    • If the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutranNFreq MO instances must be less than or equal to 144 x 32.
    • If the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutranNFreq MO instances must be less than or equal to 72 x 32.
    • If the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellEutranNFreq MO instances must be less than or equal to 36 x 32.
    • If the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRCellEutranNFreq MO instance cannot be added.
    • If the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRCellEutranNFreq MO instances must be less than or equal to 72 x 32.
    • If the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRCellEutranNFreq MO instances must be less than or equal to 36 x 32.
    • If the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRCellEutranNFreq MO instance cannot be added.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the cell within a gNodeB.
Downlink EARFCN

Indicates the DL EARFCN of an inter-RAT neighboring E-UTRAN cell. For details about this parameter, see 3GPP TS 36.104.
E-UTRAN Frequency High Priority Resel Threshold

Indicates the RX level threshold for reselecting to a cell on a high-priority E-UTRAN frequency. If the cell reselection priority of the target frequency is higher than that of the serving cell, this threshold is used as the RX level threshold for a UE to reselect from the serving cell to the cell on the target frequency. After measurements are started for cells on the target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter for the corresponding time-to-trigger. For details, see 3GPP TS 38.331.
E-UTRAN Frequency Low Priority Resel Threshold

Indicates the RX level threshold for reselecting to a cell on a low-priority E-UTRAN frequency. If the absolute priority of the target frequency is lower than that of the serving cell, this threshold is used as the RX level threshold for a UE to reselect from the serving cell to the cell on the target frequency. After measurements are started for cells on the target frequency, the UE reselects to a cell on the frequency only if the RX level of the cell is higher than the threshold specified by this parameter and that of the serving cell is lower than a specific reselection threshold for the corresponding time-to-trigger. For details, see 3GPP TS 38.331.
E-UTRAN Frequency Resel Priority

Indicates the cell reselection priority of an E-UTRAN frequency. The value 0 indicates the lowest priority. The value 255 indicates that no reselection priority is configured for the E-UTRAN frequency. For how UEs process the reselection priority of frequencies, see 3GPP TS 38.304.

A UE calculates the sum of this parameter and the cell reselection sub-priority of an E-UTRAN frequency (specified by NRCellEutranNFreq.EutranFreqReselSubPriority) and compares the sum with the cell reselection priority of the serving cell (specified by NRCellReselConfig.CellReselPriority). The target frequency for cell reselection is determined based on the result.

If the sum is greater than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring E-UTRAN frequency. If the signal quality of a cell on the neighboring E-UTRAN frequency meets requirements throughout the time specified by NRCellReselConfig.EutranCellReselTimer, the UE starts reselection to that cell. If the sum is smaller than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring frequency only when the signal quality of the serving cell is poor. When the signal quality of the serving cell is lower than the threshold specified by NRCellReselConfig.ServFreqLowPriRsrpReselThd throughout the time defined by the E-UTRAN cell reselection timer, the signal quality of a cell on the neighboring frequency is higher than the threshold specified by NRCellEutranNFreq.EutranFreqLowPriReselThld, and the UE has camped on the serving cell for more than 1s, the UE starts cell reselection. The sum of reselection priorities and that of reselection sub-priorities must be different between RATs. For details, see 3GPP TS 38.331.
Frequency-specific Offset

Indicates the frequency-specific offset of an E-UTRAN frequency. This parameter determines the probability of triggering event B1/B2 measurement reports. For details, see 3GPP TS 38.331.
Measurement Bandwidth

Indicates the measurement bandwidth of an inter-RAT neighboring E-UTRAN cell. The setting of this parameter depends on the bandwidth configuration of the neighboring E-UTRAN cell. In E-UTRAN, a cell bandwidth is expressed in units of resource blocks (RBs). Cell bandwidths 1.4 MHz, 3 MHz, 5 MHz, 10 MHz, 15 MHz, and 20 MHz correspond to 6, 15, 25, 50, 75, and 100 RBs, respectively. For details, see 3GPP TS 38.331.
Minimum RX Level

Indicates the minimum RX level required for an inter-RAT E-UTRAN cell to become a candidate for cell selection. The level is included in criteria S and used in the evaluation of cell selection. During the evaluation for cell reselection, the following calculation applies: Srxlev = Measured RSRP value of a cell on the target frequency - Value of this parameter - Compensated power. If Srxlev for a cell is better than a threshold for the corresponding time-to-trigger, reselection to the cell is started. For details, see 3GPP TS 36.304.
Frequency Priority for Connected Mode

Indicates the frequency priority for handover or redirection for UEs not running voice services. Frequencies with higher priorities are delivered preferentially. A larger value of this parameter indicates a higher priority. If this parameter is set to 0 for a frequency, this frequency will not be selected as the target frequency for blind redirection.
E-UTRAN Frequency Resel Sub-Priority

Indicates the cell reselection sub-priority of an E-UTRAN frequency.

If this parameter is set to ZERO, the reselection sub-priority of an E-UTRAN frequency is not delivered.

A UE calculates the sum of this parameter and the reselection priority of an E-UTRAN frequency (specified by NRCellEutranNFreq.EutranFreqReselPriority) and compares the sum with the cell reselection priority of the serving cell (specified by NRCellReselConfig.CellReselPriority). The target frequency for cell reselection is determined based on the result.

If the sum is greater than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring E-UTRAN frequency. If the signal quality of a cell on the neighboring E-UTRAN frequency meets requirements throughout the time specified by NRCellReselConfig.EutranCellReselTimer, the UE starts reselection to that cell. If the sum is smaller than the cell reselection priority of the serving cell, the UE initiates a measurement on the neighboring frequency only when the signal quality of the serving cell is poor. When the signal quality of the serving cell is lower than the threshold specified by NRCellReselConfig.ServFreqLowPriRsrpReselThd throughout the time defined by the E-UTRAN cell reselection timer, the signal quality of a cell on the neighboring frequency is higher than the threshold specified by NRCellEutranNFreq.EutranFreqLowPriReselThld, and the UE has camped on the serving cell for more than 1s, the UE starts cell reselection. The sum of reselection priorities and that of reselection sub-priorities must be different between RATs. For details, see 3GPP TS 38.331.
VoLTE Priority

Indicates the priority of a neighboring E-UTRAN frequency for carrying VoLTE services. If this parameter is set to 255 for a neighboring E-UTRAN frequency, the frequency does not support VoLTE during EPS fallback, emergency call fallback, and VoNR-to-VoLTE switching. If this parameter is set to a value in the range of 0 to 16, a larger value indicates a higher priority. The base station selects frequencies to be measured based on this priority and UEs preferentially select the frequency with a high priority for measurement. If this parameter is set to 0, the frequency is not selected as the target frequency for EPS fallback through blind redirection and VoNR-to-VoLTE switching through blind redirection.
Aggregation Attribute

Indicates the aggregation attributes of a neighboring E-UTRAN frequency.

SEPARATED_FREQ_SPEC_SHR_FLAG: Indicates whether a neighboring E-UTRAN frequency is a secondary operator's frequency in RAN sharing with special dedicated carrier mode. If this option is selected, the neighboring E-UTRAN frequency is a secondary operator's frequency in RAN sharing with special dedicated carrier mode. If this option is deselected, the neighboring E-UTRAN frequency is not a secondary operator's frequency in RAN sharing with special dedicated carrier mode. This option applies only to two-operator sharing with special dedicated carrier, not to two-operator sharing with common carrier.
