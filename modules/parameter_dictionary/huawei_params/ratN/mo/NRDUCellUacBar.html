NRDUCellUacBar

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellUacBar

Description

The NRDUCellUacBar MO defines access control parameters configured for different access categories.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCellOp MO:
    • When OperatorId in the NRDUCellUacBar MO is not set to 255, the NRDUCellOp MO with OperatorId set to the same value as OperatorId must already be configured.
  • Relation with the gNBUacParamGroup MO:
    • AccessControlParamGrpId in the NRDUCellUacBar MO must be set to the value configured in the gNBUacParamGroup MO.
  • Relation with the NRDUCell MO:
    • DuplexMode in the NRDUCell MO corresponding to NrDuCellId in the NRDUCellUacBar MO must be set to CELL_FDD or CELL_TDD.
  • Relation with the MPT and NODE MOs:
    • If TYPE in the MPT MO is not set to UMPT, the NRDUCellUacBar MO instance cannot be added.
    • If BRDSPEC in the MPT MO is set to UMPTe, the board type is UMPTe.
    • If BRDSPEC in the MPT MO is set to UMPTga, the board type is UMPTga. Otherwise, the board type is UMPTg.
    • If the board type is UMPTg and WM in the NODE MO is set to CONCURRENT, the number of NRDUCellUacBar MO instances must be less than or equal to 72x32.
    • If the board type is UMPTg and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellUacBar MO instances must be less than or equal to 144x32.
    • If the board type is UMPTga and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellUacBar MO instances must be less than or equal to 72x32.
    • If the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRDUCellUacBar MO instances must be less than or equal to 36 x 32.
    • If the board type is UMPTga, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRDUCellUacBar MO instance cannot be added.
    • If the board type is UMPTe and WM in the NODE MO is set to NON-CONCURRENT, the number of NRDUCellUacBar MO instances must be less than or equal to 72x32.
    • If the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM2, the number of NRDUCellUacBar MO instances must be less than or equal to 36 x 32.
    • If the board type is UMPTe, WM in the NODE MO is set to CONCURRENT, and WMEXTENSION is set to COMM, the NRDUCellUacBar MO instance cannot be added.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
Operator ID

Indicates the ID of an operator. If this parameter is set to 255, the access control policy applies to a specific operator whose policies are not configured. If this parameter is set to a value in the range from 0 to 5, the access control policy is configured for a specific operator.
Access Category

Indicates the access category that require access control in a cell. For details, see 3GPP TS 22.261.
Access Control Parameter Group ID

Indicates the access control parameter group ID mapping to an access category.
