gNBEutraExtCellPlmn

+-gNodeBFunction
  +-gNBEutraExternalCell
    +-gNBEutraExtCellPlmn

Description

This MO defines the E-UTRAN external-cell PLMN list of a gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBEutraExternalCell
  • Relation with the gNBEutraExternalCell MO:
    • A maximum of five gNBEutraExtCellPlmn MO instances can be configured for each gNBEutraExternalCell MO.
  • Relation with the gNBNCellPlmnList MO:
    • If the values of SharedMnc and SharedMcc in the gNBEutraExtCellPlmn MO are the same as the respective values of Mnc and Mcc in the gNBNCellPlmnList MO, and RatType in the gNBNCellPlmnList MO is set to EUTRAN, PlmnListType in the gNBNCellPlmnList MO cannot be set to BLACKLIST.
    • In all the gNBNCellPlmnList MOs with RatType set to EUTRAN, if the PlmnListType values include WHITELIST and GREYLIST, the following condition must be true: the values of SharedMnc and SharedMcc in all the gNBEutraExtCellPlmn MOs configured for the local gNodeB must be the same as those of Mnc and Mcc in a gNBNCellPlmnList MO with RatType set to EUTRAN, respectively.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the MCC of the operator who owns the external E-UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.
Mobile Network Code

Indicates the MNC of the operator who owns the external E-UTRAN cell.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.
eNodeB ID

Indicates the eNodeB ID of an external E-UTRAN cell. It uniquely identifies an eNodeB within a PLMN. The 28-bit E-UTRAN cell ID is comprised of the cell ID and the eNodeB ID (represented by the most significant 20 bits). The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Cell ID

Indicates the cell ID of an external E-UTRAN cell. It uniquely identifies an E-UTRAN cell within an eNodeB. The 28-bit E-UTRAN cell ID is comprised of the cell ID (represented by the least significant eight bits) and the eNodeB ID. The CGI of an E-UTRAN cell is comprised of the E-UTRAN cell ID and the PLMN ID. For details, see 3GPP TS 36.413.
Shared Mobile Country Code

Indicates the secondary operator's MCC of an external E-UTRAN cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.
Shared Mobile Network Code

Indicates the secondary operator's MNC of an external E-UTRAN cell in multi-operator sharing.

A PLMN ID is comprised of an MCC and an MNC.

The MCC consists of three digits.

The MNC consists of two to three digits.

For example, MCC = 123, MNC = 45, PLMN = 12345.
