NRDUCellSmartPwrLock

+-gNodeBFunction
  +-NRDUCellTrp
    +-NRDUCellSmartPwrLock

Description

This MO defines the smart power lock configuration of an NR DU cell.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCellTrp
  • Relation with the NRDUCellTrp and NRDUCell MOs:
    • If DuplexMode in an NRDUCell MO is set to CELL_FDD or CELL_SUL, the AVERAGE_POWER_CONTROL_SW option of SmartPowerLockSw in the NRDUCellSmartPwrLock MO must be deselected.
    • If FrequencyBand in an NRDUCell MO is set to N257, N258, N260, or N261, the AVERAGE_POWER_CONTROL_SW option of SmartPowerLockSw in the NRDUCellSmartPwrLock MO must be deselected.
    • If TxRxMode in an NRDUCellTrp MO is set to 2R, 4R, 1T1R, or 2T4R, the AVERAGE_POWER_CONTROL_SW option of SmartPowerLockSw in the NRDUCellSmartPwrLock MO must be deselected.
  • Relation with the NRDUCellAlgoSwitch and NRDUCellTrp MOs:
    • If the RF_SHUTDOWN_SW option of PowerSavingSwitch in an NRDUCellAlgoSwitch MO is selected, the options of SmartPowerLockSw in the associated NRDUCellSmartPwrLock MO must be deselected.
  • Relation with the NRDUCellTrp MO:
    • If the AVERAGE_3DEIRP_CONTROL_SW option of SmartPowerLockSw in the NRDUCellSmartPwrLock MO is selected, the AVERAGE_POWER_CONTROL_SW option must also be selected. The AVERAGE_3DEIRP_CONTROL_SW option can be selected only when TxRxMode in the NRDUCellTrp MO is set to 64T64R or 32T32R.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell TRP ID

Indicates the ID of a TRP for an NR DU cell, which uniquely identifies the TRP for the NR DU cell within a gNodeB.
Smart Power Lock Switch

Indicates smart power control switches.

AVERAGE_POWER_CONTROL_SW: Indicates whether the average power control function of the smart power lock feature is enabled. This function is enabled only when this option is selected.

AVERAGE_3DEIRP_CONTROL_SW: Indicates whether the grid-based power control function of the smart power lock feature is enabled. This function is enabled only when this option is selected.
Average Period

Indicates the average power statistical period for the smart power lock feature.
Power Control Threshold

Indicates the power control threshold for the smart power lock feature. The average power within the average period must not exceed the maximum transmit power minus the value of this parameter.
