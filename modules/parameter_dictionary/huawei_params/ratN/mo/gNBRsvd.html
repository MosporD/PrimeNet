gNBRsvd

+-gNodeBFunction
  +-gNBRsvd

Description

This MO consists of parameters whose values need to be continuously adjusted on commercial networks to find the values that produce optimal performance. Then the values are fixed and do not need to be modified.

This MO also consists of parameters used in comparison tests and used to improve performance in extreme test scenarios.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST GNBRSVD

Use this command to list the settings of reserved gNodeB parameters for commissioning.
MOD GNBRSVD

Use this command to modify the settings of reserved gNodeB parameters for commissioning.
