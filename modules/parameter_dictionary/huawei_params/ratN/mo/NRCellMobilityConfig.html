NRCellMobilityConfig

+-gNodeBFunction
  +-NRCell
    +-NRCellMobilityConfig

Description

The NRCellMobilityConfig MO defines cell-level common configurations related to mobility management.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRCell

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST NRCELLMOBILITYCONFIG

Use this command to list the mobility configurations of an NR cell.
MOD NRCELLMOBILITYCONFIG

Use this command to modify the mobility configurations of an NR cell.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR Cell ID

Indicates the ID of an NR cell, which uniquely identifies the NR cell within a gNodeB.
Beam RSRP Filter Coefficient

Indicates the filtering coefficient of the beam-level RSRP obtained through UE measurement.
Cell RSRP Filter Coefficient

Indicates the filtering coefficient of the cell-level RSRP obtained through UE measurement.
SSB Consolidation Threshold

Indicates the threshold for combining beam measurement results when cell-level SSB measurement results are calculated. The threshold means an index. The parameter value in the range from 0 to 126 indicates a value of the index minus 157 in unit of dBm, and the parameter value 127 indicates infinity in unit of dBm. If the RSRP of one or more SSB beams in a cell is greater than the parameter value, the linear average RSRP of those SSB beams is used as the cell-level RSRP. If the RSRP of no SSB beam in a cell is greater than the parameter value, the largest RSRP among the RSRP values of those beams is used as the cell-level RSRP. For details about this parameter, see 3GPP TS 38.331 and TS 38.133.
SSB Number To Average

Indicates the maximum number of SSB beams that can be used by the UE when the UE obtains the cell-level RSRP based on the beam-level RSRP.
