Indicates the administrative state of a cell. The setting of this parameter affects the working state of the cell. If this parameter is set to CELL_HIGH_BLOCK, CELL_MID_BLOCK, or CELL_LOW_BLOCK, new UEs are not allowed to access the cell. If there is no RRC_CONNECTED UE in the cell, the cell is deactivated immediately. If the cell is serving RRC_CONNECTED UEs, the base station checks the number of RRC_CONNECTED UEs in the cell every 5s. If the number becomes 0, the base station immediately deactivates the cell. If this parameter is set to CELL_HIGH_BLOCK, UEs need to be transferred out of the cell within 10 seconds. The cell is forcibly deactivated after 10 seconds even if there are still UEs in the cell. If this parameter is set to CELL_MID_BLOCK, UEs need to be transferred out of the cell within 60 seconds. The cell is forcibly deactivated after 60 seconds even if there are still UEs in the cell. If this parameter is set to CELL_LOW_BLOCK, the cell is deactivated only when there is no RRC_CONNECTED UE in the cell.

Supplementary Cell Indicator

Indicates whether a high-frequency cell is a supplementary cell for CA.

The value NORMAL_CELL indicates a common cell.

The value SUPPLEMENTARY_CELL indicates a supplementary cell, which can serve only as an SCell for CA.

A maximum of four NR DU cells of the NORMAL_CELL type and a maximum of four NR DU cells of the SUPPLEMENTARY_CELL type can be configured under the same sector.

For an NR DU cell in eCPRI 8T8R or CPRI 4T4R mode, this parameter must be set to NORMAL_CELL.

This parameter applies only to high-frequency cells.
