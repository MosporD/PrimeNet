gNBSharingMode

+-gNodeBFunction
  +-gNBSharingMode

Description

The gNBSharingMode MO consists of the parameter that indicates the sharing mode of the gNodeB. The gNodeB supports the following modes: independent operator, RAN sharing with common carrier, and RAN sharing with dedicated carrier.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRExternalNCell, gNodeBFunction, and gNBOperator MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the value of gNBId in an NRExternalNCell MO is identical with the value of gNBId in the gNodeBFunction MO, the values of Mcc and Mnc in the NRExternalNCell MO cannot be identical with the values of Mcc and Mnc in the gNBOperator MO.
  • Relation with the NRExternalNCell, gNodeBFunction, and gNBExternalPlmn MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of gNBId in the NRExternalNCell MO cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of CellId in the NRExternalNCell MO cannot exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the NRDUCell and NRDUCellOp MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be 0.
  • Relation with the NRDUCellOp and NRDUCell MOs:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be less than or equal to 6.
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ, the number of NRDUCellOp MO instances corresponding to NrDuCellId in the NRDUCell MO must be less than or equal to 1.
  • Relation with the gNBCUS1Op, gNBCUS1, and gNBOperator MOs:
    • In the gNBSharingMode MO, if gNBMultiOpSharingMode is set to INDEPENDENT, OperatorType in the gNBOperator MO associated with OperatorId in the gNBCUS1Op MO corresponding to gNBCuS1Id in the gNBCUS1 MO must be set to PRIMARY_OPERATOR.
  • Relation with the NRCellRelation, gNodeBFunction, gNBOperator, and NRCell MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, the CGI of the serving cell specified by NrCellId in an NRCellRelation MO must not be identical with the CGIs of neighboring cells specified by CellId in the NRCellRelation MO. The CGI of a neighboring cell consists of the MCC, MNC, gNodeB ID, and cell ID, which are specified by Mcc, Mnc, gNBId, and CellId, respectively.
  • Relation with the gNodeBFunction, gNBOperator, NRExternalNCell, and NRCellRelation MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the value of gNBId in an NRCellRelation MO is inconsistent with that of gNBId in the gNodeBFunction MO, an NRExternalNCell MO must be configured first.
  • Relation with the gNodeBFunction, gNBOperator, NRCell, and NRCellRelation MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and intra-site cells are configured as neighboring cells of each other in the NRCellRelation MOs, a neighboring cell specified by CellId in the NRCellRelation MOs and the serving cell must already be configured. In addition, an NRCell MO referenced by CellId, Mcc, and Mnc of the neighboring cell must already be configured.
  • Relation with the gNBOperator MO:
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, the number of gNBOperator MO instances must not be greater than 1. If a gNBOperator is configured, OperatorType must be set to PRIMARY_OPERATOR.
    • When the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the gNBIdLength parameter in a gNBOperator MO must not be set to 255.
    • When gNBMultiOpSharingMode in the gNBSharingMode MO is set to SEPARATED_FREQ or SHARED_FREQ, the gNBOperator MO with OperatorType set to PRIMARY_OPERATOR must already be configured when a gNBOperator MO with OperatorType being SECONDARY_OPERATOR is added.
  • Relation with the gNBOperator and NRDUCell MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, OperatorType in a gNBOperator MO is set to PRIMARY_OPERATOR, and NrNetworkingOption is set to SA or SA_NSA, SsbDescMethod in the associated NRDUCell MO must be set to SSB_DESC_TYPE_GSCN.
  • Relation with the NRDUCell, NRDUCellOp, and gNBOperator MOs:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to SHARED_FREQ or SEPARATED_FREQ, and NrNetworkingOption is set to SA or SA_NSA in at least one of the gNBOperator MOs corresponding to OperatorId in all the NRDUCellOp MOs associated with NrDuCellId in an NRDUCell MO, SsbDescMethod in the NRDUCell MO must be set to SSB_DESC_TYPE_GSCN.
  • Relation with the NRCellRelation, gNodeBFunction, NRDUCell, NRCell, and gNBOperator MOs:
    • Assume that MultipleNCISwitch in the gNBSharingMode MO is set to OFF and two NRDUCell MO instances meet the following conditions: (1) The first NRDUCell MO instance is associated with CellId in an NRCell MO, which is referenced by NrCellId in an NRCellRelation MO. The values of Mcc and Mnc in this NRCellRelation MO are the same as Mcc and Mnc in the gNBOperator MO, respectively. gNBId in this NRCellRelation MO is the same as gNBId in the gNodeBFunction MO. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with CellId in the NRCellRelation MO, and DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRCell, NRDUCell, and NRDUCellOp MOs:
    • If CellActiveState in an NRCell MO is CELL_ACTIVE and gNBMultiOpSharingMode is set to SEPARATED_FREQ, the NRDUCellOp MO corresponding to NrDuCellId associated with CellId corresponding to NrCellId in the NRCell MO must already be configured.
    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to ON, the CellPrimaryOpFlag parameter must be set to TRUE in one of the NRDUCellOp MOs corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO.
    • When the CellActiveState parameter in an NRCell MO is set to CELL_ACTIVE and the MultipleNCISwitch parameter in the gNBSharingMode MO is set to OFF, the CellPrimaryOpFlag parameter in the NRDUCellOp MO corresponding to the NrDuCellId parameter in the NRDUCell MO associated with the CellId parameter in the NRCell MO can only be set to FALSE.

In addition, there must be a gNBOperator MO specified by OperatorId with OperatorType set to PRIMARY_OPERATOR.
    • When CellActiveState in an NRCell MO is set to CELL_ACTIVE and MultipleNCISwitch in the gNBSharingMode MO is set to ON, CellId in the NRDUCellOp MO corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO must be different from the 3GPP-defined NR Cell Identity (NCI) determined based on gNBId and gNBIdLength in the gNBOperator MO associated with OperatorId in the NRDUCellOp MO. This rule applies to all the NRDUCellOp MOs corresponding to NrDuCellId in the NRDUCell MO associated with CellId in the NRCell MO.

    • If gNBMultiOpSharingMode in the gNBSharingMode MO is set to INDEPENDENT, and the QCIs in all the NRCellQciBearer MOs corresponding to an NRCell MO and those in the gNBOperatorQciParam MOs corresponding to a gNBOperator MO are the same, the following condition must be met: InterRatHoA2RsrpThld in the NRCellInterRHoMeaGrp MO corresponding to InterRatHoMeasGroupId in the NRCellQciBearer MO + EutranA2B2RsrpThldOffset in the gNBOperatorQciParam MO > CovHoToEutranBlindA2Thld in the NRCellInterRHoMeaGrp MO.

All the gNBOperator MOs corresponding to an NRCell MO are determined by the gNBOperator MOs corresponding to the NRDUCellOp MOs associated with the NRDUCell MO identified by CellId.

    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the combination of Mcc, Mnc, and gNBId in the NRExternalNCell MO must not be configured in the gNBOperator MO.

The combination of gNBId, Mcc, and Mnc in this NRCellRelation MO has been configured in the gNBOperator. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. (2) The second NRDUCell MO instance is associated with NrDuCellId in the NRDUCellOp MO in which the combination of OperatorId and CellId corresponding to Mnc and Mcc in the NRCellRelation MO has been configured. In addition, DuplexMode in the NRDUCell MO is set to CELL_FDD or CELL_TDD. Based on this assumption, if the values of PhysicalCellId and SsbDescMethod are equal to their counterparts in the two NRDUCell MO instances, the values of SsbFreqPos in the two NRDUCell MO instances must be different. If the values of PhysicalCellId are the same but the values of SsbDescMethod are different in the two NRDUCell MO instances, the NR-ARFCNs corresponding to SsbFreqPos in the two NRDUCell MO instances must be different.
  • Relation with the NRDUCellAlgoSwitch MO:
    • If gNBMultiOpSharingMode in the gNBSharingMode MO is not set to SHARED_FREQ, the RB_DYNAMIC_SHARING_SW and MAX_RB_LIMIT_SW options of RanSharingAlgoSwitch in an NRDUCellAlgoSwitch MO cannot be selected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
gNodeB Multi Operator Sharing Mode

Indicates the gNodeB multi-operator sharing mode, which can be independent operator mode, RAN sharing with common carriers, and RAN sharing with dedicated carriers.
Multiple NR Cell Identity Switch

Indicates whether to enable operator-specific differentiated NR Cell Identity (NCI) configuration in multi-operator sharing. An NCI is comprised of a gNodeB ID and a cell ID, and contains 36 bits in total. The gNodeB ID contains 22 to 32 bits. If this parameter is set to ON, cell IDs or gNodeB IDs vary among operators. In RAN sharing with common carrier, the system information contains the different NCIs of operators. In RAN sharing with dedicated carrier, gNodeB IDs vary among operators. If this parameter is set to OFF, different operators use the same cell ID or gNodeB ID. In RAN sharing with common carrier, different operators use the same cell ID and gNodeB ID. In RAN sharing with dedicated carrier, different operators use the same gNodeB ID.
