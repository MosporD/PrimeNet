NRDUCellSrs

+-gNodeBFunction
  +-NRDUCell
    +-NRDUCellSrs

Description

This MO defines SRS parameter configurations of common radio resources for an NR DU cell. For details about SRS, see 3GPP TS 38.211.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NRDUCell
  • Relation with the NRDUCell MO:
    • If HighSpeedFlag in an NRDUCell MO is set to HIGH_SPEED, the SRS_PERIOD_ADAPT_SW option of SrsAlgoSwitch in the corresponding NRDUCellSrs MO cannot be selected.
  • Relation with the NRDUCellAlgoSwitch MO:
    • The LTE_NR_TDD_SPCT_SHR_SW option of SpectrumCloudSwitch in the NRDUCellAlgoSwitch MO corresponding to NrDuCellId in an NRDUCellSrs MO can be selected only when the SRS_PERIOD_ADAPT_SW option of SrsAlgoSwitch in the NRDUCellSrs MO is selected.
  • Relation with the NRDUCellUePwrSaving MO:
    • If the BWP2_SWITCH option of BwpPwrSavingSw in an NRDUCellUePwrSaving MO is selected, the SRS_PERIOD_ADAPT_SW option of SrsAlgoSwitch in the NRDUCellSrs MO must also be selected.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
NR DU Cell ID

Indicates the ID of an NR DU cell, which uniquely identifies the NR DU cell within a gNodeB.
SRS Period

Indicates the SRS period configured for a UE. The actual SRS period is dependent on the value of this parameter and other factors such as available SRS resources, slot assignment, and UE capability. The actual SRS period for a common UE is greater than or equal to the value of this parameter. For details, see 3GPP TS 38.214.

This parameter is valid only when the SRS_PERIOD_ADAPT_SW option is deselected.
SRS Algorithm Switch

Indicates the SRS algorithm switch, which is used to control SRS resource allocation policies.

SRS_PERIOD_ADAPT_SW: Indicates whether the gNodeB adaptively adjusts the SRS period. When this option is selected, the gNodeB adaptively adjusts the SRS period. When this option is deselected, the fixed SRS period is used.
SRS Slot Number

Indicates the number of cell-specific SRS slots configured for high-frequency SRS within 5 ms. This parameter applies only to high-frequency TDD cells.
