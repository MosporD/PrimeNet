gNBExternalPlmn

+-gNodeBFunction
  +-gNBExternalPlmn

Description

This MO consists of parameters related to external PLMN configurations of a gNodeB.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNodeBFunction
  • Relation with the NRExternalNCell, gNodeBFunction, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of gNBId in the NRExternalNCell MO cannot exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF and the commbination of Mcc and Mnc in an NRExternalNCell MO is not existent in a gNBExternalPlmn MO, the value of CellId in the NRExternalNCell MO cannot exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the NRExternalNCellPlmn, gNodeBFunction, and gNBSharingMode MOs:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, and the PLMN indicated by the combination of SharedMcc and SharedMnc in the NRExternalNCellPlmn MO is not existent in a gNBExternalPlmn MO, then the value of SharedPlmngNBId must not exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
    • If MultipleNCISwitch in the gNBSharingMode MO is set to OFF, SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, and the PLMN indicated by the combination of SharedMcc and SharedMnc in the NRExternalNCellPlmn MO is not existent in a gNBExternalPlmn MO, then the value of SharedPlmnCellId must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNodeBFunction MO.
  • Relation with the gNBOperator MO:
    • The combination of Mcc and Mnc in a gNBExternalPlmn MO must be different from that in a gNBOperator MO.
  • Relation with the NRExternalNCell MO:
    • The value of CellId in an NRExternalNCell MO cannot exceed the maximum value of 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the combination of Mcc and Mnc.
    • The value of gNBId in an NRExternalNCell MO cannot exceed the maximum value of 2^N - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the combination of Mcc and Mnc.
  • Relation with the NRExternalNCellPlmn MO:
    • If SharedPlmnCellId in an NRExternalNCellPlmn MO is not set to 65535, the value of this parameter must not exceed the maximum value 2^(36 - N) - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the PLMN indicated by the combination of SharedMcc and SharedMnc.
    • The value of SharedPlmngNBId in an NRExternalNCellPlmn MO must not exceed the maximum value 2^N - 1, where N is specified by gNBIdLength in the gNBExternalPlmn MO corresponding to the PLMN indicated by the combination of SharedMcc and SharedMnc.

Related Parameters

Table 2 describes the parameters related to this MO.

Table 2 Configuration parameters

Parameter

Description
Mobile Country Code

Indicates the MCC in the external PLMN ID of a gNodeB.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
Mobile Network Code

Indicates the MNC in the external PLMN ID of a gNodeB.

A PLMN ID is comprised of an MCC and an MNC.

An MCC consists of three digits.

An MNC consists of two or three digits.

For example, if the MCC is 123 and the MNC is 45, the PLMN ID is 12345.
gNodeB ID Length

Indicates the length of the gNodeB ID in the NCI corresponding to the external PLMN ID of a gNodeB.
