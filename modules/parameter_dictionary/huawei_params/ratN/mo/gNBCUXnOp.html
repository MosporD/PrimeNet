gNBCUXnOp

+-gNodeBFunction
  +-gNBCUXn
    +-gNBCUXnOp

Description

This MO is used to indicate the operator information of an Xn object.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    gNBCUXn
  • Relation with the gNBOperator MO:
    • OperatorId in a gNBCUXnOp MO must be set to the value configured in the associated gNBOperator MO.
  • Relation with the gNBSharingMode MO:
    • If MultipleNCISwitch in the gNBSharingMode MO is set to ON, the value of gNBCuXnId corresponding to OperatorId in the gNBCUXnOp MO must be unique.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD GNBCUXNOP

Use this command to add an operator for a gNodeB CU Xn object.
LST GNBCUXNOP

Use this command to list operator information about a gNodeB CU Xn object.
RMV GNBCUXNOP

Use this command to remove an operator from a gNodeB CU Xn object.
