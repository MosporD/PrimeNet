RFALoCell

+-NE
  +-RFAFunction
    +-RFALoCell
      +-CellRFAEqm[0~1]
      +-RFACellAlgoSwitch[1~1]
      +-RFACellOperator[0~1]
      +-RFACellRsvdPara[1~1]
      +-RFACellSectorEqm[0~96]
      +-RFACellSectorEqmGrp[0~12]

Description

RFA_Function local cell

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFAFunction

  • Possible children:

    CellRFAEqm[0~1];RFACellAlgoSwitch[1~1];RFACellOperator[0~1];RFACellRsvdPara[1~1];RFACellSectorEqm[0~96];RFACellSectorEqmGrp[0~12]
  • Relation with the RFACellOperator MO:
    • If CellActiveState in a RFALoCell is ACTIVATE, a RFACellOperator must be configured under this RFALoCell.
  • Relation with the CellRFAEqm MO:
    • If CellActiveState in a RFALoCell is ACTIVATE, CellRFAEqm MO must be configured under this RFALoCell.
  • Relation with the CellRFAEqm and RFAEQM MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, RFAEqmId in a CellRFAEqm MO must have been set in the associated RFAEQM.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(1T1R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(1T2R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(2T2R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
  • Relation with the RFALoCell MO:
    • A maximum of 120 RFALoCell MOs can be configured in system.
  • Relation with the RFACellSectorEqm and SECTOREQM MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, the SECTOREQM MO associated with this RFACellSectorEqm MO must be configured.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T1R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T2R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(2T2R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
  • Relation with the RFASectorEqmGroup MO:
    • If CellActiveState in a RFALoCell is ACTIVATE, the SECTOREQM MO associated with this RFACellSectorEqmGrp MO must be configured.
  • Relation with the RFASectorEqmGroup, SECTOREQM, and RFACellSectorEqmGrp MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T1R) must be matched with the SECTOREQM of SectorEqmListRef in each RFACellSectorEqmGrp MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T2R) must be matched with the SECTOREQM of SectorEqmListRef in each RFACellSectorEqmGrp MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(2T2R) must be matched with the SECTOREQM of SectorEqmListRef in each RFACellSectorEqmGrp MO under this RFALoCell.
  • Relation with the RFASectorEqmGroup, RFACellSectorEqmGrp, and RFACellSectorEqm MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, in RFACellSectorEqmGrp or RFACellSectorEqm at least one SECTOREQM be configured under this RFALoCell.
  • Relation with the RFACellRsvdPara MO:
    • When the bit 1 switch under RsvdSwPara1 in RFACellRsvdPara is turned on, TxRxMode in RFALoCell must be set to 1T1R, and AccessStandard in RFALoCell must be set to GSM.
    • When the bit 1 switch under RsvdSwPara1 in RFACellRsvdPara is turned on, LocalCellId in RFALoCell must not be set to the same value as RsvdU8Para1 in RFACellRsvdPara.
  • Relation with the RFACellSectorEqmGrp and RFACellSectorEqm MOs:
    • When the CellActiveState parameter in the RFALoCell MO is set to ACTIVATE, different sector equipment for the cell cannot be configured on the same RF module.

Cell Radius

Indicates the radius of the RFA cell. The setting of this parameter must be less than or equal to the radius of the donor cell. The cell radius indicates the maximum latency of the RFA system, including the processing latency and air interface delay of the RFA system. For modes other than NR-TDD, the recommended cell radius is calculated as follows: 12500 (m) + Optical fiber length (m) x 1.5. When the cell radius is set to 0, the latency is automatically aligned. According to 3GPP TS 36.104 and TS 36.300, CA requires that delay differences among carriers do not exceed the upper limit. If different RFA carriers need to support CA, the corresponding RFA cells must have the same cell radius. This setting ensures that the DCU does not introduce extra delay differences.
