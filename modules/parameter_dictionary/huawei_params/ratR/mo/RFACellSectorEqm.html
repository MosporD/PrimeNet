RFACellSectorEqm

+-NE
  +-RFAFunction
    +-RFALoCell
      +-RFACellSectorEqm

Description

This MO is used to configure the sector equipment of a cell, including the sector equipment ID, uplink attenuation, and downlink attenuation.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFALoCell
  • Relation with the SECTOREQM and RFALoCell MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, the SECTOREQM MO associated with this RFACellSectorEqm MO must be configured.
  • Relation with the RFALoCell and SECTOREQM MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T1R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(1T2R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
    • If CellActiveState in a RFALoCell is ACTIVATE, the TxRxMode(2T2R) must be matched with the SECTOREQM in RFACellSectorEqm MO under this RFALoCell.
  • Relation with the RFACellSectorEqmGrp and RFASectorEqmGroup MOs:
    • A maximum of 96 SECTOREQM MOs can be configured in an RFALoCell.
  • Relation with the RFALoCell, RFASectorEqmGroup, and RFACellSectorEqmGrp MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, in RFACellSectorEqmGrp or RFACellSectorEqm at least one SECTOREQM be configured under this RFALoCell.
  • Relation with the RFALoCell and RFACellSectorEqmGrp MOs:
    • When the CellActiveState parameter in the RFALoCell MO is set to ACTIVATE, different sector equipment for the cell cannot be configured on the same RF module.

Related Parameters

Parameter

Description

Indicates the ID of the sector device that serves the cell.

Indicates the downlink attenuation of an RRU cell.
