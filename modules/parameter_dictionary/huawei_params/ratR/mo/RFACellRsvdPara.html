RFACellRsvdPara

+-NE
  +-RFAFunction
    +-RFALoCell
      +-RFACellRsvdPara

Description

An RFARsvdPara MO consists of the RFA-level parameters that are reserved for future requirements.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFALoCell
  • Relation with the RFALoCell MO:
    • When the bit 1 switch under RsvdSwPara1 in RFACellRsvdPara is turned on, TxRxMode in RFALoCell must be set to 1T1R, and AccessStandard in RFALoCell must be set to GSM.
    • When the bit 1 switch under RsvdSwPara1 in RFACellRsvdPara is turned on, LocalCellId in RFALoCell must not be set to the same value as RsvdU8Para1 in RFACellRsvdPara.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
LST RFACELLRSVDPARA

Use this command to list reserved cell-level parameters.
MOD RFACELLRSVDPARA

Use this command to modify reserved cell-level parameters.
