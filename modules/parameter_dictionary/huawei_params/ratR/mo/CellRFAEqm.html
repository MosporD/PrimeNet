CellRFAEqm

+-NE
  +-RFAFunction
    +-RFALoCell
      +-CellRFAEqm

Description

This MO is used to configure RFA equipment parameters of a cell, including the local cell ID and RFA equipment ID.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFALoCell
  • Relation with the RFALoCell MO:
    • If CellActiveState in a RFALoCell is ACTIVATE, CellRFAEqm MO must be configured under this RFALoCell.
  • Relation with the RFAEQM and RFALoCell MOs:
    • If CellActiveState in a RFALoCell is ACTIVATE, RFAEqmId in a CellRFAEqm MO must have been set in the associated RFAEQM.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(1T1R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(1T2R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
    • If CellActiveState in a RFALoCell is ACTIVATE, TxRxMode(2T2R) in a RFALoCell must be matched with the RFAEQM TXRXMODE.
  • Relation with the CellRFAEqm MO:
    • The number of carriers (1T1R or 0T1R defined a carrier) in an MERC board in this RFAEQM should be less than 24.
  • Relation with the RFAEQM MO:
    • A maximum of eight RFALoCell MOs can be configured on one port of the board where the RFAEQM MO is configured.
    • A maximum of eight RFALoCell MOs can be configured on one port of the board where the RFAEQM MO is configured.
