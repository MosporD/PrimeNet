RCSClientOp

+-NE
  +-RFAFunction
    +-RCSClientOp

Description

This MO is used to configure operator information for an RCS client.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    RFAFunction
  • Relation with the RFAOperator and RCSCLIENT MOs:
    • RcsClientNo in a RCSClientOp MO must set in the associated RCSCLIENT.
    • RFAOperatorId in a RCSClientOp MO must set in the associated RFAOperator.

Related MML Commands

Table 1 describes the MML commands related to this MO.

Table 1 Related MML commands

MML Command

Function
ADD RCSCLIENTOP

Use this command to add RCS client operator information.
LST RCSCLIENTOP

Use this command to list RCS client operator information.
MOD RCSCLIENTOP

Use this command to modify RCS client operator information.
RMV RCSCLIENTOP

Use this command to delete RCS client operator information.
