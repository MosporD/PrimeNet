RFAFunction

+-NE
  +-RFAFunction
    +-RCSClientOp[0~3]
    +-RFAALGOSWITCH[1~1]
    +-RFALoCell[0~120]
    +-RFAOperator[0~6]
    +-RFARsvdPara[1~1]
    +-RFASectorEqmGroup[0~65535]

Description

This MO defines the root node in the RFA function domain. It is mainly used for RF access. It manages RFA cell configuration, power allocation, operator information, and sector equipment groups.

Effective Scenario

Immediately

Relations Between MOs

  • Possible parents:

    NE

  • Possible children:

    RCSClientOp[0~3];RFAALGOSWITCH[1~1];RFALoCell[0~120];RFAOperator[0~6];RFARsvdPara[1~1];RFASectorEqmGroup[0~65535]
  • Relation with the RFAFunction MO:
    • ApplicationRef in RFAFunction MO must have been set in the associated APPLICATION MO with RFA AT.
