Mod RFACellAlgoSwitch (MOD RFACELLALGOSWITCH)

Network Element: BTS3900,BTS5900

Function

Indicates whether to loosen guard bandwidth check. When this parameter is set to ON, guard bandwidth check is loosened.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

When this parameter is set to ON, guard bandwidth check is loosened, which may affect the maximum transmit power of the carrier and result in interference over the air interface. Currently, this parameter can be set to ON only in the GSM/NB-IoT 0.2 MHz+LTE 9.6 MHz+GSM/NB-IoT 0.2 MHz scenario and the pilot power ratio must be set to correct the LTE carrier power. Do not set this parameter to ON in other scenarios.
