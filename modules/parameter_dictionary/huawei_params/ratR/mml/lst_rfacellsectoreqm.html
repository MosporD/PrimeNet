List RFA Cell Sector Equipment (LST RFACELLSECTOREQM)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about cell sector equipment.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of the sector device that serves the cell.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

Example 1:To query information about a piece of cell sector equipment (no parameter specified), run the following command:
+++    0        2017-05-08 17:58:50
O&M    #2148532346
%%LST RFACELLSECTOREQM:;%%
RETCODE = 0  Operation succeeded.

List RFA Cell Sector Equipment
------------------------------
Local Cell ID  Sector Equipment ID  Receive Attenuation(0.1dB)  Transmit Attenuation(0.1dB)

1              70                   -50                         0                          
2              70                   0                           -25                        
(Number of results = 2)


---    END
Example 2:To query information about a piece of cell sector equipment(Local Cell ID = 1), run the following command:
+++    0        2017-05-08 17:59:04
O&M    #2148532347
%%LST RFACELLSECTOREQM: LocalCellId=1, SectorEqmId=70;%%
RETCODE = 0  Operation succeeded.

------------------------------
              Local Cell ID  =  1
        Sector Equipment ID  =  70
 Receive Attenuation(0.1dB)  =  -50
Transmit Attenuation(0.1dB)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Sector Equipment ID

Indicates the ID of the sector device that serves the cell.

Transmit Attenuation(0.1dB)

Indicates the downlink attenuation of an RRU cell.

Receive Attenuation(0.1dB)

Indicates the uplink attenuation of an RRU cell.
