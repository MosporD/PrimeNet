Modify Cell Reserved Parameter (MOD RFACELLRSVDPARA)

Network Element: BTS3900,BTS5900

Function

Use this command to modify reserved cell-level parameters.

Note

None.

Parameters

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.
