List RFA Sector Equipment Group (LST RFASECTOREQMGRP)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about an RFA sector equipment group.

Note

None.

Parameters

ID Name Description
SectorEqmGroupId Sector Eqm Group ID

Meaning: Indicates the ID of a sector equipment group.

GUI Value Range: 0~1439

Unit: None

Actual Value Range: 0~1439

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

Example 1:To query an RFA sector equipment group, run the following command:
+++    0        2018-01-09 14:30:34
O&M    #2148532302
%%LST RFASECTOREQMGRP:;%%
RETCODE = 0  Operation succeeded.

List RFA Sector Equipment Group
-------------------------------
Sector Eqm Group ID  Sector Equipment ID List

0                    5/75/6                      
1                    5                       
(Number of results = 2)

---    END


Example 2:To query an RFA sector equipment group (Sector Eqm Group ID: 0), run the following command:
+++    0        2018-01-09 14:31:23
O&M    #2148532303
%%LST RFASECTOREQMGRP: SectorEqmGroupId=0;%%
RETCODE = 0  Operation succeeded.

List RFA Sector Equipment Group
-------------------------------
     Sector Eqm Group ID  =  0
Sector Equipment ID List  =  5/75
(Number of results = 1)

---    END

Output Description

Field Description

Sector Eqm Group ID

Indicates the ID of a sector equipment group.

Sector Equipment ID List

Indicates the number list of sector equipment in a sector equipment group.
