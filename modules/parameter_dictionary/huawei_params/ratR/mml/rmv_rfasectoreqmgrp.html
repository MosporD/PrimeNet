Remove RFA Sector Equipment Group (RMV RFASECTOREQMGRP)

Network Element: BTS3900,BTS5900

Function

Use this command to delete an RFA sector equipment group.

Note

None.

Parameters

ID Name Description
SectorEqmGroupId Sector Eqm Group ID

Meaning: Indicates the ID of a sector equipment group.

GUI Value Range: 0~1439

Unit: None

Actual Value Range: 0~1439

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To delete an RFA sector equipment group (Sector Eqm Group ID: 0), run the following command:
+++    0        2018-01-09 14:32:28
O&M    #2148532304
%%RMV RFASECTOREQMGRP: SectorEqmGroupId=0;%%
RETCODE = 0  Operation succeeded.

---    END
