Add RFA Cell Sector Equipment Group (ADD RFACELLSECTOREQMGRP)

Network Element: BTS3900,BTS5900

Function

Use this command to add a cell sector equipment group.

Note

  • When a cell is activated, if you need to add an RFACELLSECTOREQMGRP, deactivate the cell first.

  • Each cell can be configured with a maximum of 12 RFACELLSECTOREQMGRP instances.

  • Sector equipment groups support only the LampSite MPMU; they do not support other types of RRUs or mixed configurations of RRUs with MPMUs.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell, It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmGroupId Sector Equipment Group ID

Meaning: Indicates the sector equipment group ID.

GUI Value Range: 0~1439

Unit: None

Actual Value Range: 0~1439

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To add a sector equipment group record (Local Cell ID = 1, Sector Equipment Group ID = 0), run the following command:
+++    0        2017-05-08 16:10:22
O&M    #2148532306
%%ADD RFACELLSECTOREQMGRP: LocalCellId=1, SectorEqmGroupId=0;%%
RETCODE = 0  Operation succeeded.
