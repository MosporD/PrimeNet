List RFA Function Configuration (LST RFAFUNCTION)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about the RFA function.

Note

The MAE automatically synchronizes RFA names to the BTS.

Parameters

None.

Example

To query RFA function configurations, run the following command:
+++    0        2017-05-06 15:10:01
O&M    #2148532230
%%LST RFAFUNCTION:;%%
RETCODE = 0  Operation succeeded.

List RFA Function Configuration
-------------------------------
       RFA Name  =  1
Application Ref  =  1
         RFA ID  =  2
     User Label  =  NULL
   NeRM Version  =  RFADATAV100R012C10SPC100B565
Product Version  =  BTS3900 V100R012C10SPC100B565
(Number of results = 1)


---    END

Output Description

Field Description

RFA Name

Indicates the name of an RFA function, which uniquely identifies the RFA function.

Application Ref

Indicates the ID of the application referenced by an RFA function. The application provides an operating environment for the RFA function.

RFA ID

Indicates the RFA ID defined in the service protocol interface.

User Label

Indicates user-defined remarks.

NeRM Version

Indicates model definition version of RFA resources, including the management object (MO) definition, attribute definition, and configuration rules.

Product Version

Indicates the version of the product. This parameter is valid for version query.
