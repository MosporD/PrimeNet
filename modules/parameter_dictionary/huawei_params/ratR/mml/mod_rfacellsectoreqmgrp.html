Modify a Cell Sector Equipment Group (MOD RFACELLSECTOREQMGRP)

Network Element: BTS3900,BTS5900

Function

Use this command to modify configuration information about a cell sector equipment group.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell, It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmGroupId Sector Equipment Group ID

Meaning: Indicates the sector equipment group ID.

GUI Value Range: 0~1439

Unit: None

Actual Value Range: 0~1439

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
TxAttenuation Transmit Attenuation

Meaning: Indicates the downlink attenuation of an RRU cell.

GUI Value Range: -150~0

Unit: 0.1dB

Actual Value Range: -150~0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
RxAttenuation Receive Attenuation

Meaning: Indicates the uplink attenuation of an RRU cell.

GUI Value Range: -150~0

Unit: 0.1dB

Actual Value Range: -150~0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To modify a sector equipment group record (Local Cell ID = 1, Sector Equipment Group ID = 0, Receive Attenuation = –140, Transmit Attenuation = 0), run the following command:
+++    0        2017-05-08 16:10:49
O&M    #2148532307
%%MOD RFACELLSECTOREQMGRP: LocalCellId=1, SectorEqmGroupId=0, RxAttenuation=-140, TxAttenuation=0;%%
RETCODE = 0  Operation succeeded.


---    END
