Remove Telecom Operator (RMV RFAOPERATOR)

Network Element: BTS3900,BTS5900

Function

Use this command to remove a telecom operator.

Note

Before removing an operator, remove related objects (such as the RFACELLOP) using this operator. Otherwise, command execution fails.

Parameters

ID Name Description
RFAOperatorId RFA Operator ID

Meaning: Indicates the operator ID.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To remove an operator (RFA Operator ID = 1), run the following command:
+++    0        2017-05-04 14:40:58
TRAFFIC    #2148532234
%%RMV RFAOPERATOR: RFAOperatorId=1;%%
RETCODE = 0  Operation succeeded.
