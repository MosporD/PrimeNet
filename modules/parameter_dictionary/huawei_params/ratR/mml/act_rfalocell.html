Active RFA Local Cell (ACT RFALOCELL)

Network Element: BTS3900,BTS5900

Function

Use this command to activate an RFA cell.

Note

  • Only unblocked cells can be properly established.

  • The cell activation failure may be caused by the unavailability of carrier resources. The preparation of carrier resources takes a few seconds. After carrier resources are available, the cell will be automatically activated. You are advised to query the cell status by running the (DSP RFALOCELL) command 10 seconds later. If the cell is still not activated, check whether an alarm is reported. If an alarm is reported, clear the alarm by referring to RFA Alarm Reference.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To activate an RFA cell (Local Cell ID = 2), run the following command:
+++    0        2017-05-08 17:27:02
O&M    #2148532339
%%ACT RFALOCELL: LocalCellId=2;%%
RETCODE = 0  Operation succeeded.
