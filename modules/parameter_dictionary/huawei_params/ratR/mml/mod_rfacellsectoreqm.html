Modify RFA Cell Sector Equipment (MOD RFACELLSECTOREQM)

Network Element: BTS3900,BTS5900

Function

Use this command to modify configuration information about cell sector equipment.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of the sector device that serves the cell.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
TxAttenuation Transmit Attenuation

Meaning: Indicates the downlink attenuation of an RRU cell.

GUI Value Range: -150~0

Unit: 0.1dB

Actual Value Range: -150~0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
RxAttenuation Receive Attenuation

Meaning: Indicates the uplink attenuation of an RRU cell.

GUI Value Range: -150~0

Unit: 0.1dB

Actual Value Range: -150~0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To modify a piece of cell sector equipment (Local Cell ID = 1, Sector Equipment ID = 70, Receive Attenuation = 0, Transmit Attenuation = –25), run the following command:
+++    0        2017-05-08 18:00:43
O&M    #2148532352
%%MOD RFACELLSECTOREQM: LocalCellId=1, SectorEqmId=70, RxAttenuation=0, TxAttenuation=-25;%%
RETCODE = 0  Operation succeeded.


---    END
