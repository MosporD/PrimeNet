List Telecom Operator Information (LST RFAOPERATOR)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about an operator.

Note

None.

Parameters

ID Name Description
RFAOperatorId RFA Operator ID

Meaning: Indicates the operator ID.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

Example 1:To query operator information (RFA Operator ID = 1), run the following command:
+++    0        2017-05-04 14:40:00
O&M    #2148532232
%%LST RFAOPERATOR: RFAOperatorId=1;%%
RETCODE = 0  Operation succeeded.

List Telecom Operator Information
---------------------------------
  RFA Operator ID  =  1
RFA Operator Name  =  LIANTONG
(Number of results = 1)


---    END
Example 2:To query operator information (no parameter specified), run the following command:
+++    0        2017-05-04 14:40:15
O&M    #2148532233
%%LST RFAOPERATOR:;%%
RETCODE = 0  Operation succeeded.

List Telecom Operator Information
---------------------------------
RFA Operator ID  RFA Operator Name

0                CMCC             
1                LIANTONG         
(Number of results = 2)


---    END

Output Description

Field Description

RFA Operator ID

Indicates the operator ID.

RFA Operator Name

Indicates the operator name.

Mobile country code

Indicates the mobile country code (MCC) of the operator.

Mobile network code

Indicates the mobile network code (MNC) of the operator. The value of this parameter is a string of two or three characters, each of which must be a digit in the range from 0 to 9.
