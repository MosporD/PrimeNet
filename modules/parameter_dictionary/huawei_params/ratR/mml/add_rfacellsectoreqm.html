Add RFA Cell Sector Equipment (ADD RFACELLSECTOREQM)

Network Element: BTS3900,BTS5900

Function

Use this command to add a cell sector equipment.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmId Sector Equipment ID

Meaning: Indicates the ID of the sector device that serves the cell.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To add a piece of cell sector equipment (Local Cell ID = 1, Sector Equipment ID = 0), run the following command:
+++    0        2017-05-08 18:00:00
O&M    #2148532349
%%ADD RFACELLSECTOREQM: LocalCellId=1, SectorEqmId=70;%%
RETCODE = 0  Operation succeeded.
