Add RFA Local Cell (ADD RFALOCELL)

Network Element: BTS3900,BTS5900

Function

Use this command to add an RFA cell.

Note

  • A cell can be configured with a maximum of 120 instances.

  • Before adding a cell, ensure the RFAFunction object has been configured.

  • If the bandwidth is greater than or equal to 1 MHz, the start and end frequencies can be configured to define a subband. If the bandwidth is less than 1 MHz, only downlink EARFCNs can be configured to define a subband.

  • The input frequency value can only be any digit from 0 to 9. Each frequency is separated by a hyphen (-).

  • The cell downlink frequency setting must comply with 3GPP specifications.

    When AccessStandard is set to GSM or CDMA, Dlearfcn must be specified in compliance with 3GPP TS 45.005.

    When AccessStandard is set to LTE_FDD or LTE_TDD, Dlearfcn must be specified in compliance with 3GPP TS 36.104.

    When AccessStandard is set to UMTS, Dlearfcn must be specified in compliance with 3GPP TS 32.410.

  • When BandWidth is set to OTHER, FreqL and FreqH must be configured. The bandwidth is the difference between values of FreqH and FreqL. The restrictions on the bandwidth are as follows:

    1. When AccessStandard is set to LTE_FDD, the bandwidth must be 8 MHz, or within the range of 4.8 MHz to 4.9 MHz, 7.4 MHz to 7.5 MHz, 9.6 MHz to 9.9 MHz, 14.6 MHz to 14.9 MHz or 18.3 MHz to 18.5 MHz.

    2. When AccessStandard is set to UMTS, the bandwidth must be within the range of 4.2 MHz, 4.6 MHz or 4.8 MHz.

    3. When AccessStandard is set to GSM or CDMA, the bandwidth must be within the range of 1 MHz to 20 MHz.

    4.If AccessStandard is set to GSM, the configured bandwidth includes the guard bandwidth and passband bandwidth, which is 250 KHz, 400 KHz, or 800 KHz when the passband bandwidth is 0-4.6 MHz, 4.601-9.2 MHz, or 9.201-18.4 MHz, respectively.

  • If the specified cell radius is greater than the value of this parameter, UEs cannot properly access the cell.

  • In UMTS multi-carrier scenarios, the effective bandwidth of each carrier cannot overlap, and the frequencies of all ARFCNs cannot exceed configured bandwidth. The difference between two ARFCNs must be within 21 to 25.

  • When the FRA equipment needs to be added to cells with AccessStandard set to LTE_TDD, the restrictions on configuring SubframeAssignment and SpecialSubframePatterns of the cells are as follows:

    1. The cells with AccessStandard set to LTE_TDD to be added to the same RFA equipment must have consistent configurations of SubframeAssignment and SpecialSubframePatterns.

    2. The LTE TDD cells to be added to ports 0 and 1 on the same MERC board must have consistent configurations of SubframeAssignment and SpecialSubframePatterns. The same rule applies to ports 2 and 3 and ports 4 and 5 and ports 6 and 7.

    3. For a TDD cell , only the following combinations of SubframeAssignmentand SpecialSubframePatterns are supported: [SA0,SSP5], [SA0,SSP6], [SA0,SSP7], [SA1,SSP5], [SA1,SSP6], [SA1,SSP7], [SA2,SSP6], [SA2,SSP7].

  • After the frame offset is modified, the RFA cell needs to be reactivated for the modification to take effect.

    The hRRU and pRRU support only frame offset configuration for a single frequency band. The frame offset must be the same for cells in BBU access mode and signal sources for RF input.

  • When AccessStandard is set to CM or GM, only 39XX series pRRUs support this function.

  • The frequencies for RFALOCELL on the same MERC port cannot overlap.

  • In joint calibration on two RFA cells using non-contiguous spectrum, the sources for both RFA cells are ready and full-load power is configured for both RFA cells. After full-load power is modified, the STR PORTPWRADJUST command must be executed for the modification to take effect.
