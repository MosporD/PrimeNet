List Static Parameters of an RFA Cell (LST RFALOCELL)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about an RFA cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Cell Name

Indicates the name of the cell.

Signal Mode

Indicates the network standard of signals received by the MERC. If AccessStandard is set to MO(NB-IoT), all signals are sent only from NB-IoT cells. If AccessStandard is set to GM(GSM_NB-IoT), CM(CDMA_NB-IoT), or LM(LTE_FDD_NB-IoT), some signals are sent from NB-IoT cells. Set the signal source to the long CP mode for NB-IoT RF signal input. For NB-IoT input signals, the cyclic prefix length must be changed to 266.7 μs.

Frequency Channel

Indicates the frequency band attribute of the RFA cell. The setting must match the signal source and comply with 3GPP specifications.

Networks: GSM, frequency channel: GSM450(GSM450), GSM480(GSM480), GSM850(GSM850), P-GSM900(P-GSM900), E-GSM900(E-GSM900), R-GSM900(R-GSM900), DCS1800(DCS1800), PCS1900(PCS1900);

Networks: CDMA, frequency channel: CDMA850(CDMA850), CDMA1900(CDMA1900).

Bandwidth

Indicates the bandwidth. The setting of this parameter must match that of the source cell. For a GSM cell, set this parameter to OTHER with the start and end frequencies specified if a non-standard bandwidth is used and to AUTO without the need to set the start and end frequencies if a standard bandwidth is used.

Cell Radius(1m)

Indicates the radius of the RFA cell. The setting of this parameter must be less than or equal to the radius of the donor cell. The cell radius indicates the maximum latency of the RFA system, including the processing latency and air interface delay of the RFA system. For modes other than NR-TDD, the recommended cell radius is calculated as follows: 12500 (m) + Optical fiber length (m) x 1.5. When the cell radius is set to 0, the latency is automatically aligned. According to 3GPP TS 36.104 and TS 36.300, CA requires that delay differences among carriers do not exceed the upper limit. If different RFA carriers need to support CA, the corresponding RFA cells must have the same cell radius. This setting ensures that the DCU does not introduce extra delay differences.

Indicates the ratio of UL subframes to DL subframes in a TDD cell. For details, see 3GPP TS 36.211.

Special subframe patterns

Indicates the ratio of special UL subframes to special DL subframes in a TDD cell. For details, see 3GPP TS 36.211.

Carrier Max Input Power(0.1dBm)

Indicates the Carrier Max Input Power.

Associated Cell Id

Indicates the local ID of the associated cell of an RFA cell. It uniquely identifies a cell associated with the RFA cell within the base station.

Associated Cell Switch

Indicates whether an RFA cell has associated RFA cells. If this parameter is set to ON, the RFA cell has associated RFA cells. If this parameter is set to OFF, the RFA cell does not have associated RFA cells.

ULBandwidth

Indicates the uplink bandwidth of the NR cell. The value must be the same as that of the source cell.

Uplink EARFCN

Indicates the uplink frequency of the RF access cell. The value of this parameter must be the same as that of the source cell.

Receive Start Frequency(1kHz)

Indicates the uplink start frequency of the NR RF access cell. The value must be the same as that of the source cell. The value of 4294967295 indicates an invalid value. In this case, the uplink start frequency and downlink start frequency comply with the default conversion rule of the 3GPP protocol.

Receive End Frequency(1kHz)

Indicates the uplink end frequency of the NR RF access cell. The value must be the same as that of the source cell. The value of 4294967295 indicates an invalid value. In this case, the uplink start frequency and downlink start frequency comply with the default conversion rule of the 3GPP protocol.
