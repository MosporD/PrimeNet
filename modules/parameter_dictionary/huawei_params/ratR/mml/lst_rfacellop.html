List RFA Cell Operator (LST RFACELLOP)

Network Element: BTS3900,BTS5900

Function

Use this command to query configuration information about a cell operator.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

Example 1:To query cell operator information (no parameter specified), run the following command: 
+++    0        2017-05-04 15:43:31
O&M    #2148532248
%%LST RFACELLOP:;%%
RETCODE = 0  Operation succeeded.

List RFA Cell Operator
----------------------
Local Cell ID  RFA Operator ID

0              0              
1              0              
(Number of results = 2)


---    END
Example 2:To query cell operator information (Local Cell ID = 1), run the following command:
+++    0        2017-05-04 15:43:51
O&M    #2148532249
%%LST RFACELLOP: LocalCellId=1;%%
RETCODE = 0  Operation succeeded.

List RFA Cell Operator
----------------------
  Local Cell ID  =  1
RFA Operator ID  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

RFA Operator ID

Indicates the operator ID.
