Add RFA Sector Equipment Group (ADD RFASECTOREQMGRP)

Network Element: BTS3900,BTS5900

Function

Use this command to add an RFA sector equipment group.

Note

You can enter multiple equipment numbers in the sector equipment list. The sector equipment number consists of digits from 0 to 9 and ranges from 0 to 65535. Use the hyphen (~) to indicate a range, and use the slash (/) to separate nonconsecutive numbers.

Parameters

ID Name Description
SectorEqmGroupId Sector Eqm Group ID

Meaning: Indicates the ID of a sector equipment group.

GUI Value Range: 0~1439

Unit: None

Actual Value Range: 0~1439

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
SectorEqmIdList Sector Equipment ID List

Meaning: Indicates the number list of sector equipment in a sector equipment group.

GUI Value Range: 1~99 characters

Unit: None

Actual Value Range: 1~99

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To add an RFA sector equipment group (Sector Eqm Group ID: 0; Sector Equipment ID List: 70, 75, 80-90), run the following command:
+++    0        2018-01-09 14:33:49
O&M    #2148532305
%%ADD RFASECTOREQMGRP: SectorEqmGroupId=0, SectorEqmIdList="70/75/80~90";%%
RETCODE = 0  Operation succeeded.

---    END
