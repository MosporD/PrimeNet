List Dynamic Parameters of an RFA Cell (DSP RFALOCELL)

Network Element: BTS3900,BTS5900

Function

Use this command to query dynamic attributes of an RFA cell.

Note

None.

Parameters

ID Name Description
LocalCellId Local Cell ID

Meaning: Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Output Description

Field Description

Local Cell ID

Indicates the local ID of the cell. It uniquely identifies a cell within a base station.

Cell Name

Indicates the name of the cell.

Cell Instance State

Indicates the cell state.

Reason For Latest State Change

Indicates the reason that causes the latest state change of the cell, which can be a cell activation success or a cell setup failure.

Cell Latest Setup Time

Indicates the latest setup time of the cell.

Cell Latest Setup Operate Type

Indicates the latest setup type of the cell.

Cell Latest Remove Time

Indicates the latest remove time of the cell.

Cell Latest Remove Operate Type

Indicates the latest remove type of the cell.

Work Status

Indicates the working status of RF units used by a cell.

Center Frequency(1kHz)

Indicates center frequency of a cell.

Customized Bandwidth Frequency Range(1kHz)

Indicates the frequency range of a Customized bandwidth. The customized bandwidth is the full bandwidth occupied by the user carrier, including pass bandwidth and protection bandwidth. The pass bandwidth is the bandwidth that is used to carry the useful signal in the customized bandwidth. The protection bandwidth is reserved for the purpose of reducing the inter-carrier interference. Protection Bandwidth = Customized Bandwidth - Pass Bandwidth.

Pass Bandwidth Frequency Range(1kHz)

Indicates the frequency range of a pass bandwidth. The customized bandwidth is the full bandwidth occupied by the user carrier, including pass bandwidth and protection bandwidth. The pass bandwidth is the bandwidth that is used to carry the useful signal in the customized bandwidth. The protection bandwidth is reserved for the purpose of reducing the inter-carrier interference. Protection Bandwidth = Customized Bandwidth - Pass Bandwidth.

Cell Radius Target Delay(1ns)

Indicates target delay corresponding to the cell radius.

Maximum Delay Equivalent Cell Radius(1m)

Indicates cell radius equivalent to the maximum cell delay.

RFA Equipment Work Status

Indicates the work status of the radio frequency access equipment that serves the cell.

RFA Equipment Information

Indicates the cabinet, subrack, slot, and port information of the cell RFA equipment.

RF Module Information

Indicates the cabinet, subrack, and slot where the RF module serves the cell is located.

TX Channel No.

Indicates the TX channel information about the RF unit that serves a cell.

RX Channel No.

Indicates the RX channel information about the RF unit that serves a cell.

MERC Carrier Auto Calibration Amount(0.1dB)

Indicates MERC carrier auto calibration amount.

MERC Carrier Downlink Input Power(0.1dBm)

Indicates downlink input power of carriers on the MERC port (manually configured maximum input power of the carrier).

Adjusted MERC Carrier Downlink Power(0.1dBm)

Indicates adjusted downlink power of carriers on the MERC port.

MERC Carrier DL Output Power in Digital Domain(0.1dBFS)

Indicates downlink output power of MERC carriers in the digital domain.

MERC Carrier UL Input Power in Digital Domain(0.1dBFS)

Indicates uplink input power of MERC carriers in the digital domain.

MERC Carrier Uplink Output Power(0.1dBm)

Indicates uplink output power of carriers on the MERC port (Attenuation).

Target and Compensation Delay Difference(1ns)

Indicates difference between the target delay corresponding to the cell radius and the delay after compensation.

Information about the board for providing optical fiber connections

Indicates the TX channel information about the RF unit that serves a cell.

Frame Offset(Ts)

Indicates the offset of the start time of a cell frame against a reference clock source.

The mapping between a configured value and an actual value is as follows:

If the configured value is [0,3072) Ts, the actual value is [0,3072) Ts

If the configured value is [3072,12295] Ts, the actual value is [156672,165895] Ts

If the configured value is (12295,153600) Ts, the actual value is (12295,153600) Ts

If the configured value is [153600,156672) Ts, the actual value is [0,3072) Ts

If the configured value is [156672,165895] Ts, the actual value is [156672,165895] Ts

If the configured value is (165895,261120] Ts, the actual value is (12295,107520] Ts

If the configured value is [275943,307200] Ts, the actual value is [275943,307200] Ts
