Add Telecom Operator (ADD RFAOPERATOR)

Network Element: BTS3900,BTS5900

Function

Use this command to add a telecom operator.

Note

  • Before adding an operator, ensure the RFAFunction object has been configured.

  • A maximum of six operators can be configured.

Parameters

ID Name Description
RFAOperatorId RFA Operator ID

Meaning: Indicates the operator ID.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
RFAOperatorName RFA Operator Name

Meaning: Indicates the operator name.

GUI Value Range: 0~99 characters

Unit: None

Actual Value Range: 0~99 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
Mcc Mobile country code

Meaning: Indicates the mobile country code (MCC) of the operator.

GUI Value Range: 3 characters

Unit: None

Actual Value Range: 000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mcc is a string of three characters, each of which must be a digit in the range from 0 to 9.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: R
Mnc Mobile network code

Meaning: Indicates the mobile network code (MNC) of the operator. The value of this parameter is a string of two or three characters, each of which must be a digit in the range from 0 to 9.

GUI Value Range: 2~3 characters

Unit: None

Actual Value Range: 00~99;000~999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • The value of Mnc is a string of two or three characters, each of which must be a digit in the range from 0 to 9.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To add an operator (RFA Operator ID = 1, RFA Operator Name = CMCC), run the following command:
+++    0        2017-05-04 14:38:46
TRAFFIC    #2148532230
%%ADD RFAOPERATOR: RFAOperatorId=1, RFAOperatorName="CMCC";%%
RETCODE = 0  Operation succeeded.

---    END
