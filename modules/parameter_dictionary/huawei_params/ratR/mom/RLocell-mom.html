RFA Local Cell MOM Description

This section describes the functions and concepts of RFA local cells and also provides the managed object model (MOM) view and related managed objects (MOs).

Functions and Concepts

RFA Local cell (RFALoCell)

An RFA cell defined by this MO is a wireless coverage area identified using a base transceiver station identity code (BSIC) and is the minimum service unit that allows a UE to access a network. An RFA local cell is the functional set of an RFA cell on the base station.

Sector equipment (SECTOREQM)

This MO defines antenna channels and their working modes in a sector. An antenna channel can serve as a Tx channel, Rx channel, Tx/Rx channel, or active/standby channel. One sector can be equipped with multiple pieces of sector equipment.

Sector equipment of an RFA local cell (RFACellSectorEqm)

This MO defines sector equipment used in a cell and the configurations of each piece of sector equipment. One piece of sector equipment can serve one or multiple cells in different manners, for example, transmitting signals with different maximum power.

Radio Frequency Access equipment (RFAEqm)

This MO defines configurations of radio frequency access resource used in a cell, including the number of configured boards and the port.

The MOs related to an RFA local cell are described as follows:
  • RFALoCell defines basic information about a radio frequency access cell, including the local cell type, baseband resource group configurations, frequency, and activated features.
  • RFACellOperator defines the information about the operator of a cell.
  • CellRFAEqm defines equipment of radio frequency access used in a cell.
  • RFACellSectorEqmGrp defines the pRRU grouping relationship of a hybrid multi-RRU cell.
  • RFACellSectorEqm defines sector equipment used in a cell and the configurations of each piece of sector equipment. One piece of sector equipment can serve one or multiple cells in different manners, for example, transmitting signals with different maximum power.
  • SECTOREQM defines antenna channels and their working modes in a sector. An antenna channel can serve as an Rx channel, Tx channel, Tx/Rx channel, or active/standby channel. One sector can be equipped with multiple pieces of sector equipment.
