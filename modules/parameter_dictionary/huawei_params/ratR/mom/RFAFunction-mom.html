RFAFunction MOM Description

This section describes the functions and concepts of RFAFunction and also provides the managed object model (MOM) view and MOs related to RFAFunction.

Functions and Concepts

RFAFunction: RFAFunction is the root node of an RFA function and is used to perform RFA radio access functions, including Radio Frequency Access management, resource allocation.

MOM View

Figure 1 is a subset of the RFA MOM and provides MOs related to RFAFunction.
Figure 1 RFAFunction MOM view

In the RFAFunction MOM view, the RFAFunction MO is attributed to the NE MO which is the root node of NEs. The RFAFunction MO is the root node of an RFA function. Before creating a RFAFunction MO, the Application ID (under the APLLICATION MO) referenced by the RFAFunction MO must be available and the application object type must be RFA.

One RFAFunction MO corresponds to one RFA instance, and an RFA has only one RFAFunction MO.

The RFAFunction MOM includes RFA Local Cell MOM.

For detailed descriptions about the RFA Local Cell MOM, see RFA Local Cell MOM Description.

For details about NE and APPLICATION MOs, see NE MOM Description and Application Management MOM Description respectively.
