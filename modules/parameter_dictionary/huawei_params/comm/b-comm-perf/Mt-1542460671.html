Description

These counters provide the maximum and average allocated bandwidth ratios in a resource group in a measurement period. The sampling value depends on the current service access status. The counters only indicate the bandwidth allocation instead of real-time usage.

Measurement Points

The allocated bandwidth ratio is sampled every 10 seconds. The allocated bandwidth ratio is calculated by multiplying the allocated bandwidth by the total bandwidth. If the calculated result is greater than 1, the allocated bandwidth ratio is 100. At the end of a measurement period, the maximum and average sampling results are used as the values of the corresponding counters.
