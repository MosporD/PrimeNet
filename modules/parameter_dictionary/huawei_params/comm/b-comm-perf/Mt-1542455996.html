Description

These counters provide the packet loss rate on the transport network and indicate the transmission quality on the detected links. The average forward packet loss rate, peak forward packet loss rate, average backward packet loss rate, and peak backward packet loss rate are valid only when the TWAMP sender is deployed in the full architecture, or stateful mode in the light architecture. The average two-way packet loss rate and peak two-way packet loss rate are valid only when the TWAMP sender is deployed in the stateless mode in the light architecture.

Measurement Points

The sampling period is 30s. In each sampling period, the base station measures the number of packets sent by the TWAMP sender, the number of packets sent by the TWAMP responder, and the number of packets received by the TWAMP sender.

Number of lost forward packets = Number of packets sent by the TWAMP sender - Number of packets sent by the TWAMP responder

Number of lost backward packets = Number of packets sent by the TWAMP responder - Number of packets received by the TWAMP sender

Number of two-way discarded packets = Number of packets sent by the TWAMP sender - Number of packets received by the TWAMP sender

VS.BSTWAMP.Forward.DropMeans:

The system measures the number of packets sent by the TWAMP sender and the number of lost forward packets on the link every 30 seconds and calculates the total number in a measurement period. The value of the VS.BSTWAMP.Forward.DropMeans counter is the result of dividing the total number of lost forward packets by the total number of packets sent by the TWAMP sender.

VS.BSTWAMP.Forward.Peak.DropRates:

The forward packet loss rate per 30 seconds can be calculated by dividing the number of lost forward packets by the number of packets sent by the TWAMP sender. The value of the VS.BSTWAMP.Forward.Peak.DropRates counter is the maximum forward packet loss rate in a measurement period.

VS.BSTWAMP.Backward.DropMeans:

The system measures the number of packets sent by the TWAMP responder and the number of lost backward packets on the link every 30 seconds and calculates the total number in a measurement period. The value of the VS.BSTWAMP.Backward.DropMeans counter is the result of dividing the total number of lost backward packets by the total number of packets sent by the TWAMP responder.

VS.BSTWAMP.Backward.Peak.DropRates:

The backward packet loss rate per 30 seconds can be calculated by dividing the number of lost backward packets by the number of packets sent by the TWAMP responder. The value of the VS.BSTWAMP.Backward.Peak.DropRates counter is the maximum backward packet loss rate in a measurement period.

VS.BSTWAMP.RoundTrip.DropMeans:

The system obtains the number of packets sent by the TWAMP sender and the number of two-way discarded packets on the link every 30 seconds and calculates the total numbers in all sampling periods in a measurement period. Then, the system calculates the average two-way packet loss rate by dividing the total number of discarded two-way packets by the total number of packets sent by the TWAMP sender.

VS.BSTWAMP.RoundTrip.Peak.DropRates:

The packet loss rate in each 30-second sampling period is calculated by dividing the number of two-way discarded packets by the number of packets sent by the TWAMP sender. The value of the VS.BSTWAMP.RoundTrip.Peak.DropRates counter is the maximum two-way packet loss rate in all sampling periods in a measurement period.
