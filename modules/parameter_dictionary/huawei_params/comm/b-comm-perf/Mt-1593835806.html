Input power of MERC port

Counters

Counter ID Counter Name Counter Description Network Element Applicable Mode RAN Architecture Option
1593835806 VS.RFA.RFCPORT.MaxINPUTPWR Maximum input power of MERC port BTS3900 R N/A
1593835807 VS.RFA.RFCPORT.AvgINPUTPWR Average input power of MERC port BTS3900 R N/A

Description

During the statistical period, the MERC port is sampled periodically, and the sampling period is 10 seconds. Record the maximum and the average port power in the statistical period.

Measurement Points

During the statistical period, Record the maximum port power in the statistical period. The power value of the port is accumulated and recorded as A, while the number of statistics is recorded as B, the average value is equal to A/B.

Formula

None

Unit

dBm
