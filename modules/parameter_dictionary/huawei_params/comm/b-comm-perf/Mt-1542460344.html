Description

This counter measures the number of packets discarded by the receiver end of the base station if these packets fail the replay checking within a measurement period. A packet received by the local end is discarded if it is duplicated or its sequence number is less than any packet in the anti-replay checking window.

Measurement Points

The number of discarded packets received due to replay checking fail is sampled per second. At the end of a measurement period, the sum of these sampling results is used as the value of the counter.
