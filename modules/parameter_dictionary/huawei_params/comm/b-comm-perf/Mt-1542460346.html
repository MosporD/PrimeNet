Description

This counter measures the number of packets discarded by the base station RX due to the ESP authentication failure or decryption failure.

Measurement Points

The number of discarded packets received due to ESP fail is sampled per second. At the end of a measurement period, the sum of these sampling results is used as the value of the counter.
