Description

These counters provide the maximum and average Main Core usage of a board in a specified measurement period. The value type of these counters is integer and the results are in round numbers. For example, if the result is 0%, the actual value ranges from 0.00% to 0.99%. This counter is valid only for LMPT boards.

Measurement Points

The Main Core (MC) usage is sampled every second, and the average MC usage of each 5s is used as the sampling result. The maximum or the average of the final sampling results is used as the value of this counter. For example, sampling values X1, X2, X3, ..., and Xn are obtained every 5s in the measurement period. Then, the values of the VS.BBUBoard.MCLoad.Max and VS.BBUBoard.MCLoad.Mean counters are calculated using the following formula:

VS.BBUBoard.MCLoad.Max = MAX(Xi)

VS.BBUBoard.MCLoad.Mean = (X1+X2+...+Xn)/n
