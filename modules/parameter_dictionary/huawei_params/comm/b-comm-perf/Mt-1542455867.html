Description

This counter provides the total severely errored seconds (SESs) in the TX direction on an E1/T1 link. It reflects the quality on the E1/T1 link. A second is considered a severe error bit second in the TX direction if the e-bit error rate is larger than 30% or an RDI alarm is generated in this second.

Measurement Points

This counter is sampled per second in the TX direction. This counter is increased by one each time a second is considered as a severely errored second.
