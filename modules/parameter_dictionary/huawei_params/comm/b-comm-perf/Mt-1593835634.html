Description

This counter provides the percentage of the period during which the CPU usage of a board exceeds the threshold to the entire measurement period.

Measurement Points

The CPU usage is sampled every second, and the average CPU usage of each 5s is used as the sampling result. The percentage of the period during which the CPU usage of a board exceeds the preconfigured threshold to the entire measurement period is used as the value of this counter. The preconfigured threshold is 85%.
