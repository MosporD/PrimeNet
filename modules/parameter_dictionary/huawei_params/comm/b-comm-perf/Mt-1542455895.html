Description

This counter measures the number of discarded packets transmitted to the AAL5 layer on an SAAL link within a measurement period. It indicates the traffic volume on the SAAL link. A packet is discarded when errors occur during frame encapsulation.

Measurement Points

This counter is measured when data fails to be transmitted to the AAL5 layer on the SAAL link in a measurement period.
