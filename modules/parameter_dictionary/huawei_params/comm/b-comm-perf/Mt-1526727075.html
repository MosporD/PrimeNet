Description

These counters measure the numbers of bytes in the packets transmitted, received, and discarded due to reception failure on a GTP-U tunnel within a measurement period. The measured fields include GTP-U headers, as shown in Figure 1. These packets include GTP-U control packets and user data. These counters reflect the user-plane traffic volume.

The VS.Gtpu.RxDropBytes counter measures the number of bytes in packets discarded due to reception failure at the GTP-U layer in the following cases: (1) Service context matching fails: The tunnel endpoint identifier (TEID) in the received GTP-U packet cannot match the established bearer. (2) Errors occur in version check. (3) The protocol type is incorrect. (4) The packet length is incorrect. (5) The TEID is not in the configured range. When the service context matching fails, the base station may release the context before the peer end does during service release. In this case, the peer end still sends service packets to the base station. As a result, the base station counts the packets as discarded packets. Therefore, this counter cannot reflect the quality of transmission links.

Measurement Points

The number of bytes in the packets transmitted, received, or discarded in the receive direction on a GTP-U tunnel is sampled per second. At the end of a measurement period, the sum of these sampling results is used as the value of the corresponding counter.
