Description

This counter measures the shutdown duration of all power supplying units (PSUs) in the base station within the measurement period.

Measurement Points

In a measurement period, the intelligent shutdown status of each PSU is sampled every second. When one or more PSUs are intelligently shut down, this counter is added by one.
