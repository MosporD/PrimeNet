Meaning

Indicates whether to use the second local IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the second local IP address of the SCTP host. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPHOST command, the system automatically deletes the IPsec tunnel that has been automatically set up.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPHOST MO is not set to SIMPLE_MODE_OFF, both the SIGIP1SECSWITCH and SIGIP2SECSWITCH parameters in the SCTPHOST MO must be set to DISABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv4 and SIGIP1SECSWITCH or SIGIP2SECSWITCH is set to ENABLE, VRFIDX must be set to 0.
  • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv6 and SIGIP2V6 is valid, SIGIP1SECSWITCH and SIGIP2SECSWITCH in the SCTPHOST MO must be set to DISABLE.
