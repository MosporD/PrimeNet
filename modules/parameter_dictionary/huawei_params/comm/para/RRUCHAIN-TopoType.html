Meaning

Indicates the type of the topology. In a ring topology, service data is transmitted on the fiber optic cable that carries the HDLC link. In a load sharing topology, service data is transmitted on two fiber optic cables simultaneously, which enhances the transmission capability. The physical connection in the ring topology is similar to that in the load sharing topology. The trunk chain enables multiple CPRI fiber optic cables to simultaneously transmit service data.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with AT set to PEERPORT and PROTOCOL is not set to eCPRI, TT must be set to CHAIN or LOADBALANCE or TRUNK_CHAIN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the RRUCHAIN MO where the RHUB MO is located, if TT is set LOADBALANCE, the values of HCN, HSRN, and HSN must be the same as those of TCN, TSRN, TSN, respectively.
  • [Co-MPT, NodeB, eNodeB, gNodeB]TT in the RRUCHAIN MO where the RHUB MO is located must be set to CHAIN, LOADBALANCE or TRUNK_CHAIN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT and TT in an RRUCHAIN MO are set to PEERPORT and CHAIN or LOADBALANCE, respectively, and TYPE in the associated SUBRACK MO is set to BBU5900A, then LCN and LSRN cannot be set to 255, HCN cannot be set to LCN, or HSRN cannot be set to LSRN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT and TT in an RRUCHAIN MO are set to PEERPORT and TRUNK_CHAIN, respectively, and TYPE in the associated SUBRACK MO is set to BBU5900A, then the RRUCHAIN MO cannot be set.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO connected to a CXU MO with CXUTYPE set to RMU, TT must be set to CHAIN and AT must be set to LOCALPORT or TT must be set to LOADBALANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if PROTOCOL is set to eCPRI and TT is set to CHAIN or LOADBALANCE, then CR must be set to 10.0G, 25.0G or AUTO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if PROTOCOL is set to eCPRI, TT cannot be set to RING or TRUNK_CHAIN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if PROTOCOL is set to eCPRI and TT is set to CHAIN or LOADBALANCE, USERDEFRATENEGOSW must be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in the BBP MO specified by LCN, LSRN, and LSN in an RRUCHAIN MO must be set to UBBP or UBBP-W if the RRUCHAIN MO meets the following conditions: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, none of LCN, LSRN, and LSN can be set to 255 if the following conditions are met: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively, or the subrack corresponding to HCN and HSRN is not located in the local base station.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, HSN must be set to a value less than or equal to 5 if the following conditions are met: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT is set to PEERPORT and TT is set to CHAIN, and LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively in an RRUCHAIN MO, then there must be a CTRLLNK MO with CN equal to LCN and SRN equal to LSRN or with UPCN equal to LCN and UPSRN equal to LSRN.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an RRUCHAIN MO, if CR is set to MANUAL, TT must be set to CHAIN.
  • [Co-MPT, eGBTS, eNodeB, gNodeB]When RT in the RFU MO is set to LRFU, TT in the RRUCHAIN MO corresponding to RCN cannot be set to LOADBALANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (2) Neither LCN nor LSRN is set to 255. (3) When TT is set to CHAIN, the combination of LCN and HCN is different from the combination of LSRN and HSRN; or when TT is set to TRUNK_CHAIN, the combination of LCN and CONNCN1 is different from the combination of LSRN and CONNSRN. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an RRUCHAIN MO, if AT is set to PEERPORT, TT is set to LOADBALANCE, the board corresponding to HCN, HSRN and HRN must be the same as the board corresponding to TCN, TSRN and TRN.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a SUBRACK MO, when TYPE is set to BBU3900-1U or BLADEBBU, the TT of RRUCHAIN connected to the SUBRACK should not be TRUNK_CHAIN.
  • [gNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (2) Neither LCN nor LSRN is set to 255. (3) When TT is set to CHAIN, the combination of LCN and HCN is different from the combination of LSRN and HSRN; or when TT is set to TRUNK_CHAIN, the combination of LCN and CONNCN1 is different from the combination of LSRN and CONNSRN. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.
