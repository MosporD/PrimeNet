Meaning

Indicates the modes for which the UBBP, LCOP, UMDU or UBBP-W provides baseband processing resources. If the UBBP, UMDU or UBBP-W provides only CPRI ports for a mode, you do not need to select this mode for the UBBP, UMDU or UBBP-W.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If WM in a BBP MO is set to HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, or HYBRID_NORMALCELL_ENHANCE, BBWS must be set to: LTE-TDD&LTE-FDD&NBIOT, LTE-TDD&LTE-FDD, LTE-FDD&NBIOT, LTE-TDD&NBIOT, LTE-TDD, or LTE-FDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If WM in a BBP MO is set to SPEC_MODE1, BBWS must be set to: LTE-FDD, LTE-FDD&NBIOT, LTE-TDD, LTE-FDD&LTE-TDD, UMTS&LTE-TDD or UMTS&LTE-FDD&LTE-TDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If WM in a BBP MO is set to SPEC_MODE1, and BBWS is set to: LTE-FDD, LTE-FDD&NBIOT, SRT must be set to DEFAULT.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only the UBBP, LCOP, UBBP-W or UMDU supports the BBWS parameter.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UBBP board, the BBWS parameter cannot be set to a combination of LTE TDD and GSM.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UBBP board, the BBWS parameter cannot be set to a combination of NR and GSM.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the value of BRDSPEC for a UBBP board contains UBBPem, UBBPf1, UBBPf0, UBBPf3 or UBBPF1 BBWS can only be set to LTE_TDD(LTE TDD).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UBBP board, when the BBWS parameter is set to a combination that involves UMTS, the HCE parameter must be set to FULL.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of the BRDSPEC parameter of a UBBP indicates that the UBBP may be a UBBPe or UBBPg, the BBWS parameter must not be GSM.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the value of BRDSPEC for a UBBP board contains UBBPg4 (case insensitive), BBWS can only be set to LTE_TDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes only LTE_FDD and NR, includes only LTE_TDD and NR, or includes only LTE_FDD, NBIOT and NR, SRT cannot be set to NR_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS includes only LTE_FDD and NR, only LTE_TDD and NR, or only LTE_FDD, NBIOT and NR, SRT must be set to DEFAULT or NR_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS includes only LTE_TDD and NBIOT, SRT must be set to DEFAULT or NBIOT_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes LTE_FDD and LTE_TDD,
  • includes only UMTS and LTE_FDD, includes only LTE_FDD and NBIOT, includes only LTE_TDD and NBIOT, includes only UMTS, LTE_FDD and NBIOT, includes only LTE_FDD and NR, includes only LTE_TDD and NR, includes only LTE_FDD, NBIOT and NBIOT, or includes only LTE_FDD, SRT must be set to DEFAULT.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS includes only UMTS and LTE_FDD, includes only UMTS, LTE_FDD and NBIOT, or includes only LTE_FDD, SRT must be set to DEFAULT or FDD_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS includes only LTE_FDD and NBIOT, SRT must be set to DEFAULT, FDD_ENHANCE or NBIOT_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes only LTE_FDD and NBIOT or includes only LTE_TDD and NBIOT, SRT cannot be set to NBIOT_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes only LTE_FDD and LTE_TDD or includes only LTE_FDD, LTE_TDD and NBIOT, LTEFLEXSPECSW cannot be set to ON.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UBBP-W board, the BBWS parameter can be only set to NR or LTE_TDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, BBWS can be set to NR only if the board type is set to UBBP-W or the value of BRDSPEC of a UBBP includes UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 (case insensitive), or null.

-Parameter relationship with conditions:

  • If TYPE is set to LCOP, UBBP, UBBP-W, BBWS must be set.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UMDU board, the BBWS parameter can be set to a combination of LTE TDD and LTE FDD, and cannot be set to a combination of LTE TDD and a mode other than LTE FDD.
