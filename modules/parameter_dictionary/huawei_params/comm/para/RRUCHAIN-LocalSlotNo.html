Meaning

Indicates the slot number of the converged party in CPRI MUX/eCPRI MUX. If this parameter is set to 255, the slot number of the converged party is not specified. When the converging party is in a BBU3900, this parameter can be left unspecified. When the converging party is in a BBU3910, BBU5900 or BBU5900A, this parameter must be specified.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, LSN must be set to 2 or 3 if the following conditions are met: TT is set to CHAIN; AT is set to PEERPORT; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively; TYPE in the SUBRACK MO where the slot specified by LSN is located is set to BBU3900.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, LSN cannot be set to 255 and HSN cannot be set to 6 if the following conditions are met: AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the cabinet number and subrack number of the board connected to the chain/ring respectively; TT is set to CHAIN or LOADBALANCE; TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3910 or BBU5900.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A BBP MO with SN equal to LSN in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN; AT is set to PEERPORT; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU3910; TYPE in the BBP MO corresponding to the converged board is set to UBBP.
  • [Co-MPT, NodeB, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU5900 or BBU5900A; TYPE in the BBP MO corresponding to the converged board is set to UBBP or UBBP-W.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The combination of the cabinet number, subrack number, and slot number of the converged board is different from the combination of HCN, HSRN, and HSN values in an RRUCHAIN MO with TT set to CHAIN or LOADBALANCE or the combination of CONNCN1, CONNSRN1, and CONNSN1 value in an RRUCHAIN MO with TT set to TRUNK_CHAIN if the RRUCHAIN MO meets the following conditions: AT is set to PEERPORT; the chain/ring is connected to the baseband processing boards corresponding to two different BBP MOs; TYPE in the BBP corresponding to the converged board is not set to UBBP-W or PROTOCOL is set to eCPRI in the RRUCHAIN MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, CONNSN1 must be set to 2 or 3 and LSN must be set to 255, 2, or 3 if the following conditions are met:
  • - TT in the RRUCHAIN MO is set to TRUNK_CHAIN.
  • - AT in the RRUCHAIN MO is set to PEERPORT.
  • - TYPE in the SUBRACK MO where the RRUCHAIN MO is located is set to BBU3900.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, LSN cannot be set 255 or 6 if the following conditions are met:
  • - TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3910.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, LSN cannot be set to 255 or 6 if the following conditions are met:
  • - TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU5900.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to TRUNK_CHAIN, AT set to PEERPORT, and LSN set to a value other than 255, LCN set to 255 or CONNCN1, LSRN set to 255 or CONNSRN1, a BBP MO with SN set to the same value as LSN must be configured.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT in each RRUCHAIN MO is set to PEERPORT, and HCN, HSRN, and HSN in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE or CONNCN1, CONNSRN1, and CONNSN1 in RRUCHAIN MOs with TT set to TRUNK_CHAIN are set to the same values respectively, then LSN in these RRUCHAIN MOs must be set to the same value when either of the following conditions must be met:
  • 1. LCN and LSRN are equal to 255 or correspond to the subrack where the board connected to the fiber optic cable is located. LSN is not equal to 255, and not all TT is equal to CHAIN.
  • 2. LCN and LSRN are not equal to 255 or do not correspond to the subrack where the board connected to the fiber optic cable is located, and LSN is not equal to 255.
  • 3. PROTOCOL in the RRUCHAIN MO is set to eCPRI.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT in each RRUCHAIN MO is set to PEERPORT, and HCN, HSRN, and HSN in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE or CONNCN1, CONNSRN1, and CONNSN1 in RRUCHAIN MOs with TT set to TRUNK_CHAIN are set to the same values respectively, then the following conditions must be met: If LSN is not set to 255, and LCN and LSRN are set to 255 or correspond to the subrack where the board connected to the optical fiber is located, then the number of RRUCHAIN MO instances with different LSN values must not exceed 2.

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an RRUCHAIN MO, HSN must be set to 2 or 3, and LSN must be set to 255, 6 (only for a GTMU MO), 3, or 2 if the following conditions are met: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN; TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900.
