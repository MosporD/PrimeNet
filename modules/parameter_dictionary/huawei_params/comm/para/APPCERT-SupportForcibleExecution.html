MML Command

MOD APPCERT
Meaning

Indicates whether forcible changes to APPCERT objects are made. When this parameter is set to YES, forcible changes to APPCERT objects are made. When this parameter is set to NO, forcible changes to the APPCERT objects that affect associated objects are not allowed. When forcible changes are not allowed, only the local IP address is checked.

The associated objects include CA, CERTREQ, and IKEPEER. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when setting this parameter:

1. The system checks whether forcible changes to APPCERT objects affect associated objects based on the object configuration data instead of the actual object running status.

2. If an NE is configured with an SRCIPRT, SRCIPROUTE4, PPPLNK, or MPGRP object, the system will not check whether forcible changes to APPCERT objects affect associated objects.
