Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RASDEVICEDATA MO, when BAND4 is not set to UNUSED, BAND3 cannot be set to UNUSED. When BAND3 is not set to UNUSED, BAND2 cannot be set to UNUSED. When BAND2 is not set to UNUSED, BAND1 cannot be set to UNUSED.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RASDEVICEDATA MO, when BAND4 is not set to UNUSED, BAND4 must be greater than BAND3. When BAND3 is not set to UNUSED, BAND3 must be greater than BAND2. When BAND2 is not set to UNUSED, BAND2 must be greater than BAND1.
