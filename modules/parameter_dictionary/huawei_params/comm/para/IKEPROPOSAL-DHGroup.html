Meaning

Indicates the Diffie-Hellman (DH) group of the IKE proposal. The core technology used in an IKE proposal is the Diffie-Hellman (DH) exchange technology. The DH exchange technology is used to calculate private information based on public information. It is mathematically proven that decrypting the DH information is impractical due to calculation complexity. The Diffie-Hellman group specified by the value DH_GROUP14 or a value indicating a later algorithm provides better security but consumes more CPU resources. Therefore, set this parameter based on both the security concern and the CPU load. The values DH_GROUP19 and DH_GROUP20 are supported only by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7, UBBPg9 and UMDU boards.

Disuse statement: In later versions, the values DH_GROUP1(768-bit Diffie-Hellman Group) and DH_GROUP2(1024-bit Diffie-Hellman Group) will be removed from the value range of this parameter. In the current version, these values can still be configured and take effect. Therefore, you are not advised to use the values DH_GROUP1(768-bit Diffie-Hellman Group) and DH_GROUP2(1024-bit Diffie-Hellman Group).
