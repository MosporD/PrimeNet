Meaning

Indicates the port frame loss rate threshold of the IP DL flow control algorithm switch. When the frame loss rate is less than or equal to this threshold, the base station determines that the link is not congested.

Impact on Radio Network Performance

When the frame loss rate is smaller than or equal to the value of this parameter, bandwidth adjustment is not performed.

When the frame loss rate is greater than the value of this parameter, bandwidth adjustment is performed based on the user configuration.
