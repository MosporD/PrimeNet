Meaning

Indicates the working mode of a base station. The value of this parameter can only be Non-ConCurrent when the product type of the NE is not DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900 LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900 LampSite.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BRDASSIGNMENT in the BRDRESASSIGNMENT MO is set to MODE2, any of the following conditions must be met:
  • 1. If AT in the APPLICATION MO is set to eNodeB and WM in the NODE MO is set to NON-CONCURRENT, BRDASSIGNMENT in the MPT MO is set to MODE2.
  • 2. When WM in the NODE MO is set to CONCURRENT, WMEXTENSION is set to COMM2, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTe (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 3. When WM in the NODE MO is set to CONCURRENT, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTg, or UMPTga (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTg, or UMPTga (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 4. When WM in the NODE MO is set to CONCURRENT, WMEXTENSION is set to COMM2, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 5. When WM in the NODE MO is set to CONCURRENT, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTg, or UMPTga (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BRDASSIGNMENT in a BRDRESASSIGNMENT MO can be set to MODE3 only if AT in the APPLICATION MO and WM in the NODE MO are set to eNodeB or EXTAPPTYPE and NON-CONCURRENT, respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BRDASSIGNMENT in a BRDRESASSIGNMENT MO can be set to MODE4 only if AT in the APPLICATION MO and WM in the NODE MO are set to gNodeB and NON-CONCURRENT, respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When AT in the APPLICATION MO is set to eNodeB, WM in the NODE MO is set to NON-CONCURRENT, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) cannot be set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When AT in the APPLICATION MO is set to eNodeB, WM in the NODE MO is set to NON-CONCURRENT, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) cannot be set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]BRDASSIGNMENT in a BRDRESASSIGNMENT MO can be set to MODE5 only if WM in the NODE MO and TYPE in the MPT MO are set to CONCURRENT and UMPT, respectively.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When the PRODUCTTYPE in a NODE MO is set to DBS3900_LTE, BTS3900_LTE, BTS3900A_LTE, BTS3900L_LTE, BTS3900AL_LTE, DBS3900_LampSite_LTE, DBS3900_WCDMA, BTS3900_WCDMA, BTS3900A_WCDMA, BTS3900L_WCDMA, BTS3900AL_WCDMA, DBS3900_LampSite_WCDMA, DBS3900-1U_WCDMA, BTS3900-1U_WCDMA, DBS3900_5G, DBS5900_LTE, BTS5900_LTE, BTS5900A_LTE, BTS5900L_LTE, BTS5900AL_LTE, DBS5900_LampSite_LTE, DBS5900_WCDMA, BTS5900_WCDMA, BTS5900A_WCDMA, BTS5900L_WCDMA, BTS5900AL_WCDMA, DBS5900_LampSite_WCDMA or DBS5900_5G, DBS5900_5G, DBS3900_LampSite_5G, or DBS5900_LampSite_5G, WM parameter must be set to NON-CONCURRENT.
  • [Co-MPT, eGBTS]When there is a GTMU MO where TYPE is set to GTMU and there is no MPT MO where TYPE is set to UMPT, WM in the NODE MO must be set to NON-CONCURRENT.

-Parameter relationship with conditions:

  • If PRODUCTTYPE is set to BTS3900, BTS3900A, BTS3900AL, BTS3900L, DBS3900, DBS3900_DCU, DBS3900_LampSite, WM is valid.
