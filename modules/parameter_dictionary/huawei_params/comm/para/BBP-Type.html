Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the BBP MO, when TYPE is set to UBBP, WM must be set to NORMAL, HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, or SPEC_MODE1.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]WM can be set to the following values only when TYPE in the BBP MO is set to UBBP: NORMAL, HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, and SPEC_MODE1.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the SUBRACK MO where the BBP MO is located is set to BBU3910, TYPE in the BBP MO must be set to UBBP, LPMP or LCOP.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the SUBRACK MO housing the BBP MO is set to BBU5900A, TYPE in the BBP MO must be set to UBBP.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the SUBRACK MO housing the BBP MO is set to BBU5900A, SN in the BBP MO must be set to 0, 2, or 4.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in BBP is set to 0, 2 and 4, the TYPE in BBP can set to UBBP-W.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When TYPE in the SUBRACK MO where the BBP MO is located is set to BBU5900, TYPE in the BBP MO must be set to UBBP, LCOP, or UBBP-W.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU3910; TYPE in the BBP MO corresponding to the converged board is set to UBBP.
  • [Co-MPT, NodeB, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU5900 or BBU5900A; TYPE in the BBP MO corresponding to the converged board is set to UBBP or UBBP-W.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The combination of the cabinet number, subrack number, and slot number of the converged board is different from the combination of HCN, HSRN, and HSN values in an RRUCHAIN MO with TT set to CHAIN or LOADBALANCE or the combination of CONNCN1, CONNSRN1, and CONNSN1 value in an RRUCHAIN MO with TT set to TRUNK_CHAIN if the RRUCHAIN MO meets the following conditions: AT is set to PEERPORT; the chain/ring is connected to the baseband processing boards corresponding to two different BBP MOs; TYPE in the BBP corresponding to the converged board is not set to UBBP-W or PROTOCOL is set to eCPRI in the RRUCHAIN MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP, the value of SRT in the BBP MO must be set to DEFAULT.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP, CPRIITFTYPE in the BBP MO must be set to CPRI_SFP.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP or UBBP-W, OVERLOADALMRPTTHLD in the BBP MO must be set to 90 and OVERLOADALMCLRTHLD in the BBP MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the BBP MO must be greater than the value of OVERLOADALMCLRTHLD in the BBP MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a UBBP-W board, the BBWS parameter can be only set to NR or LTE_TDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, BBWS can be set to NR only if the board type is set to UBBP-W or the value of BRDSPEC of a UBBP includes UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 (case insensitive), or null.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in the BBP MO specified by LCN, LSRN, and LSN in an RRUCHAIN MO must be set to UBBP or UBBP-W if the RRUCHAIN MO meets the following conditions: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB]HCN, HSRN, and HSN in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE or CONNCN1, CONNSRN1, and CONNSN1 in RRUCHAIN MOs with TT set to TRUNK_CHAIN must be set to the same values if each RRUCHAIN MO meets the following conditions: these RRUCHAIN MOs use the same converged board; AT is set to PEERPORT; TYPE in the BBP MO corresponding to the converged board is not set to UBBP; TYPE in the SUBRACK MO where the slot specified by LSN is located is set to BBU3910.
  • [Co-MPT, eNodeB, gNodeB]When TYPE in a BBP MO is not set to UBBP or UBBP-W, PROTOCOL in all RRUCHAIN MOs under this BBP MO must be set to the same value.
  • [gNodeB]HCN, HSRN, and HSN in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE or CONNCN1, CONNSRN1, and CONNSN1 in RRUCHAIN MOs with TT set to TRUNK_CHAIN must be set to the same values if each RRUCHAIN MO meets the following conditions: these RRUCHAIN MOs use the same converged board; AT is set to PEERPORT; TYPE in the BBP MO corresponding to the converged board is not set to UBBP; TYPE in the SUBRACK MO where the slot specified by LSN is located is set to BBU3910.

-Parameter relationship with conditions:

  • If SN is set to 0, 1, 2, 3, 4, 5, 6, TYPE must be set.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the MPT MO is not UMPT, the value of OVERLOADALMRPTTHLD in the MPT MO must be set to 90 and OVERLOADALMCLRTHLD in the MPT MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the MPT MO must be greater than the value of OVERLOADALMCLRTHLD in the MPT MO.
