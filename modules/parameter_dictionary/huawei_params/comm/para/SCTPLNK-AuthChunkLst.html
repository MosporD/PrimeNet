Parameter Name

SCTP Authentication Chunk List
NE

MML Command

LST SCTPLNK
Meaning

Indicates the list of SCTP chunk types for which the local end requires the peer end to support authentication. The IDs of SCTP chunks that can be authenticated by the base station are 0, and 3 to 9. For details, see RFC4895 and RFC4960. Currently, SCTP block authentication is supported only in DTLS over SCTP scenarios. This parameter applies only to NR.
