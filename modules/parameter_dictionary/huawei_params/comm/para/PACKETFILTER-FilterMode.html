Meaning

Indicates the packet filtering mode. The BS can filter packets based on the advanced ACL, layer-2 ACL, or both at the same time.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Filter Mode parameter in the PACKETFILTERING MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.
