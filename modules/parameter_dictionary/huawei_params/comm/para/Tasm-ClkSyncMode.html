Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PROFILETYPE in the IPCLKLNK MO is set to G.8265.1, CLKSYNCMODE in the TASM MO must be set to FREQ or HYBRID.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PROFILETYPE in the IPCLKLNK MO is set to G.8275.1, CLKSYNCMODE in the TASM MO must be set to TIME.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If IPMODE in the IPCLKLNK MO is set to IPV6, CLKSYNCMODE in the TASM MO must be set to FREQ.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CLKSYNCMODE and MODE and CLKSRC in a TASM MO are set to TIME and MANUAL and IPCLK, respectively, SYNMODE must be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a TASM MO, if CLKSYNCMODE is set to TIME and LOOSETIME is set to ON, MODE cannot be set to AUTO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a TASM MO, if CLKSYNCMODE is set to TIME, LOOSETIME is set to ON, and MODE is set to MANUAL, CLKSRC must be set to IPCLK or PEERCLK.
