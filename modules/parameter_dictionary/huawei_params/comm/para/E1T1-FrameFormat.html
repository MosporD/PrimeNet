Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an E1T1 MO, if PS is set to ALLPORT and WORKMODE is set to E1_UNBA or E1_BA, FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME.
  • In an E1T1 MO, if PS and WORKMODE are set to ALLPORT and T1, respectively, FRAME can be set to T1_SUPER_FRAME or T1_EXTENDED_SUPER_FRAME.
  • If WORKMODE in an all-port E1T1 MO is set to E1_UNBA or E1_BA, FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME in each single-port E1T1 MO. If WORKMODE in an all-port E1T1 MO is set to T1, FRAME can be set to T1_SUPER_FRAME or T1_EXTENDED_SUPER_FRAME in each single-port E1T1 MO. If no all-port E1T1 MO is configured, the default value of WORKMODE in each single-port E1T1 MO is E1_UNBA, and FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME.

-Parameter relationship with conditions:

  • FRAME is must be set if one of the following conditions is met:
  • 1 PS is set to SINGLEPORT.
  • 2 WORKMODE is set to E1_BA, E1_UNBA, T1.
