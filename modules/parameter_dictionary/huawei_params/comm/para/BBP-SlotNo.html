Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to CHAIN or LOADBALANCE and AT set to PEERPORT, a board must not be configured in the slot specified by HCN, HSRN, and HSN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to TRUNK_CHAIN and AT set to PEERPORT, the following requirements must be satisfied:
  • 1. If the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 1, a board cannot be configured in the slot specified by CONNCN1, CONNSRN1, and CONNSN1.
  • 2. If the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 2, a board cannot be configured in the slot specified by CONNCN2, CONNSRN2, and CONNSN2.
  • 3. If the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 3, a board cannot be configured in the slot specified by CONNCN3, CONNSRN3, and CONNSN3.
  • 4. If the value of CONNPORTNUM in the RRUCHAIN MO is 4, a board cannot be configured in the slot specified by CONNCN4, CONNSRN4, and CONNSN4.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A BBP MO with SN equal to LSN in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN; AT is set to PEERPORT; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB]A BBP or GTMU MO with SN equal to LSN in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN respectively; LSN is not set to 255.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TT and AT in an RRUCHAIN MO are set to TRUNK_CHAIN and PEERPORT, respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900:
  • - If the value of CONNSN1 is 2, a BBP MO with SN set to 3 must be configured.
  • - If the value of CONNSN1 is 3, a BBP MO with SN set to 2 must be configured.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to TRUNK_CHAIN, AT set to PEERPORT, and LSN set to a value other than 255, LCN set to 255 or CONNCN1, LSRN set to 255 or CONNSRN1, a BBP MO with SN set to the same value as LSN must be configured.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For boards that have baseband processing capabilities, only SN in the MDU MO and SN in the GTMU MO can be set to 6, and SN in the BBP MO cannot be set to 6.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the values of TYPE and CPRIITFTYPE in a BBP MO are UBBP and XCI_QSFP, respectively and the value of TYPE in the SUBRACK MO is BBU3900, the value of SN in the BBP MO must be less than 4.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an RRUCHAIN MO, if TT is set to CHAIN or LOADBALANCE, AT is set to PEERPORT, LCN and LSRN are both set to 255 or are set to the values of as HCN and HSRN respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900, then the following conditions must be met: when HSN is set to 2, a BBP MO with SN set to 3 or a GTMU MO with SN set to 6 is configured; when HSN is set to 3, a BBP MO with SN set to 2 or a GTMU MO with SN set to 6 is configured.
  • [gNodeB]In an RRUCHAIN MO, if TT is set to CHAIN or LOADBALANCE, AT is set to PEERPORT, LCN and LSRN are both set to 255 or are set to the values of as HCN and HSRN respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900, then the following conditions must be met: when HSN is set to 2, a BBP MO with SN set to 3 is configured; when HSN is set to 3, a BBP MO with SN set to 2 is configured.
  • [gNodeB]A BBP equal to the converged board in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN respectively; LSN is not set to 255.
