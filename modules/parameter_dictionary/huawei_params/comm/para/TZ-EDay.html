Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When DST in the TZ MO is set to YES and EM is DATEWEEK, EDAY plus 6 should not be beyond the end of the month specified by EMONTH.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When DST in the TZ MO is set to YES and EM is DATE, if EMONTH is FEB, then EDAY should not be greater than 28.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When DST in the TZ MO is set to YES and EM is DATE, EDAY should not be greater than normal day.

-Parameter relationship with conditions:

  • If EM is set to DATE, DATEWEEK, EDAY must be set.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when DST in the TZ MO is set to YES and EM is DATEWEEK or DATE.
