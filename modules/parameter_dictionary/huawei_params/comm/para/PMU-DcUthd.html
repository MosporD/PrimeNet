Meaning

Indicates the upper threshold of the DC voltage. When the output voltage of the busbar is higher than the value, an ALM-25621 Power Supply DC Output Out of Range alarm is reported.

Impact

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a PMU MO, when PTYPE is set to SC48200, BCV in the BATTERY MO corresponding to the PMU MO must be smaller than or equal to DCVUTHD in the PMU MO minus 15.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a PMU MO, when PTYPE is set to a value other than SC48200, BCV in the BATTERY MO corresponding to the PMU MO must be smaller than DCVUTHD in the PMU MO minus 10.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a PMU MO, when PTYPE is set to SC48200, the value of DCVLTHD must be greater than or equal to 460 and smaller than or equal to 500, and the value of DCVUTHD must be greater than or equal to 580 and smaller than or equal to 600.

-Parameter relationship with conditions:

  • If PTYPE is set to APM100, APM200, APM30, EPS4815, EPS48200, EPS4890, ETP, SC48200, TP48300A, DCVUTHD is valid.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the PMU MO, when PTYPE is set to SC48200, DCVUTHD is set to 585 by default. When PTYPE is set to a value other than SC48200, DCVUTHD is set to 580 by default.
