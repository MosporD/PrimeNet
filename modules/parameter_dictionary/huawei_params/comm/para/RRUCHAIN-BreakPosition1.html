Meaning

Indicates breakpoint position 1 on the chain/ring. When this parameter is set to 255, the breakpoint is disabled.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to CHAIN, LOADBALANCE or TRUNK_CHAIN and AT set to PEERPORT, BRKPOS1 and BRKPOS2 must be set to 255.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, BRKPOS2 must be set to a value other than 255 if the following conditions are met:
  • 1. TT is not set to CHAIN or TRUNK_CHAIN.
  • 2. BRKPOS1 is not set to 255.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, BRKPOS2 must be set to 255 if the following conditions are met:
  • 2. BRKPOS1 is set to 255.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is not set to CHAIN or TRUNK_CHAIN, the value of BRKPOS1 must be less than or equal to that of BRKPOS2.
  • [Co-MPT, NodeB, eNodeB]If BRKPOS1 or BRKPOS2 in an RRUCHAIN MO is not set to 255, the value of BRKPOS1 or BRKPOS2 must be less than or equal to the total number of RRU, RFU, RHUB, AAMU, and CXU MOs on the main chain/ring.
  • [eGBTS]If BRKPOS1 or BRKPOS2 in an RRUCHAIN MO is not set to 255, the value of BRKPOS1 or BRKPOS2 must be less than or equal to the total number of RRU, RFU, AAMU, and CXU MOs on the main chain/ring.
  • [gNodeB]If BRKPOS1 or BRKPOS2 in an RRUCHAIN MO is not set to 255, the value of BRKPOS1 or BRKPOS2 must be less than or equal to the total number of RRU, RFU, RHUB, and CXU MOs on the main chain/ring.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the RRUCHAIN MO, BRKPOS1 must be set to 0 before you change the value of TT.
Access

Read & Write
Service Interrupted After Modification

Yes
Interruption Scope

The cells carried by the RRUs behind the breakpoint on the RRU chain become unavailable. The cells carried by the RRUs between breakpoints 1 and 2 on the RRU ring become unavailable.
Interruption Duration (min)

The cells carried by the RRUs on the RRU chain/ring become available after the breakpoints are removed.
Caution

If this parameter is modified, the cells carried by the RRUs behind the breakpoint on the RRU chain become unavailable. The cells carried by the RRUs between breakpoints 1 and 2 on the RRU ring become unavailable.
Validation of Modification

The parameter modification takes effect immediately.
