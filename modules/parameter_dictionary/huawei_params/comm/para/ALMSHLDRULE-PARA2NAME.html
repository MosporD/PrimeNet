-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ALMSHLDRULE MO must meet the following condition 1: There is at least one of the following five parameter combinations whose parameter values are both specified: combination 1 (PARA1NAME, PARA1VALUE), combination 2 (PARA2NAME, PARA2VALUE), combination 3 (PARA3NAME, PARA3VALUE), combination 4 (PARA4NAME, PARA4VALUE), and combination 5 (PARA5NAME, PARA5VALUE).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ALMSHLDRULE MO must meet the following condition 2: If one of the parameter values in a parameter combination is specified, the other parameter value must be specified. The parameter combinations include the following: combination 1 (PARA1NAME, PARA1VALUE), combination 2 (PARA2NAME, PARA2VALUE), combination 3 (PARA3NAME, PARA3VALUE), combination 4 (PARA4NAME, PARA4VALUE), and combination 5 (PARA5NAME, PARA5VALUE).
