Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When any one of the parameters PA, SPEED and DUPLEX is set to UNCONFIG, the other two must also be set to UNCONFIG.

-Parameter relationship with conditions:

  • DUPLEX is must be set if one of the following conditions is met:
  • 1 PA is set to UNCONFIG.
  • 2 SPEED is set to 1000M, 100G, 100M, 10G, 10M, 25G, 40G, AUTO.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ETHPORT MO, if SPEED is set to AUTO, this parameter must be AUTO.
  • In the ETHPORT MO, if SPEED is set to 10M, 100M, 1000M, 10G, 25G, 40G or 100G, this parameter must be FULL.
  • In the ETHPORT MO, if PA is set to UNCONFIG, this parameter must be UNCONFIG.
