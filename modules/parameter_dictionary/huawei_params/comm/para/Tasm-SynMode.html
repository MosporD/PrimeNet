MML Command

SET CLKMODE

LST CLKMODE
Meaning

Indicates the mode of scheduled synchronization for the IP clock link. In ABSOLUTE mode, the system clock obtains synchronization signals from the clock server at a fixed time every few days until the system clock is stable. In RELATIVE mode, the system clock obtains synchronization signals from the clock server at regular intervals until the system clock is stable. In OFF mode, the system clock obtains only messages from the clock server in real time. The LTE currently does not support this function.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If ICPT and CNM in an IPCLKLNK MO are set to PTP and UNICAST, respectively, and MODE and CLKSRC in a TASM MO are set to MANUAL and IPCLK, respectively, SYNMODE in the TASM MO can be set to a value ABSOLUTE or RELATIVE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CLKSYNCMODE and MODE and CLKSRC in a TASM MO are set to TIME and MANUAL and IPCLK, respectively, SYNMODE must be set to OFF.

-Parameter relationship with conditions:

  • If CLKSRC is set to IPCLK, SYNMODE is valid.
