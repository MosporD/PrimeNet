MML Command

ADD BRD
Meaning

Indicates the type of a board. If the value of Board Type is UBBP, LCOP or UMDU and users do not forcibly verify the board specifications on the MAE-Deployment, this parameter does not need to be specified. If users forcibly verify the board specifications on the MAE-Deployment, this parameter must be specified based on the actual hardware type of the board. For example, if the value of Board Type is UMDU, this parameter can be set to a value such as BBU3910a1 or BBU3910a2. If the value of Board Type is UBBPd, this parameter can be set to a value such as UBBPd1 or UBBPd2. If the value of Board Type is UBBPe, this parameter can be set to a value such as UBBPe1 or UBBPe2. If the value of Board Type is UBBPf, this parameter can be set to a value such as UBBPf1. If the value of Board Type is UBBPg, this parameter can be set to a value such as UBBPg2 or UBBPg3. If the value of Board Type is UMPT, this parameter must be set to UMPTa, UMPTb, UMPTa/b, UMPTe, UMPTg or UMPTga (the values are case insensitive). If the value of Board Type is GTMU, this parameter must be set to GTMUb or GTMUc (the values are case insensitive). If this parameter is not specified, the default value is NULL and the system does not check the configurations based on the board specifications.
