MML Command

ADD EPGROUP

LST EPGROUP
Meaning

Indicates the eNodeB interface that uses the endpoint group. When this parameter is set to DUX2_U, the endpoint group is used by the eNodeB to automatically generate the DUX2 object. Only the DUX2_U and DUEX2_NON_IDEAL options can be selected together. Other options must be selected separately. This parameter takes effect only for CU-DU Split.
