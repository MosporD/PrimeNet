Meaning

Indicates the line rate of port 1 of the trunk chain. The value AUTO indicates that the auto-negotiation mode is used. The value MANUAL indicates that the rate is set manually and the rate must be set to a fixed value for each board on the RRU chain/ring. Other values indicate the corresponding fixed rates.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is set to TRUNK_CHAIN, AT is not set to PEERPORT, and PROTOCOL is set to CPRI, then the following conditions must be met:
  • 1. If CONNPORTNUM is set to 2, both CONNCR1 and CONNCR2 are set to AUTO or neither CONNCR1 nor CONNCR2 is set to AUTO.
  • 2. If CONNPORTNUM is set to 3, all of CONNCR1, CONNCR2, and CONNCR3 are set to AUTO or none of them is set to AUTO.
  • 3. If CONNPORTNUM is set to 4, all of CONNCR1, CONNCR2, CONNCR3, and CONNCR4 are set to AUTO or none of them is set to AUTO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TT in an RRUCHAIN MO is set to TRUNK_CHAIN, and CPRIITFTYPE in the BBP MO is set to XCI_QSFP, 40.4G and 39.2G2 cannot coexist for the CONNCR1 parameters corresponding to the ports of this RRUCHAIN MO and other RRUCHAIN MOs on the baseband processing unit where the RRUCHAIN MO is located.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TT and CONNPORTNUM in the RRUCHAIN MO are set to TRUNK_CHAIN and 2, respectively, and CPRIITFTYPE in the BBP MO is set to XCI_QSFP, the ports of the RRUCHAIN MO must not have any two of the following line rates at the same time: 40.4G, 39.2G, and 97.2G.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is set to TRUNK_CHAIN, then CONNCR1, CONNCR2, CONNCR3, and CONNCR4 cannot be set to 10G or 25G. If PROTOCOL is not set to eCPRI and TT is set to CHAIN, LOADBALANCE, or RING, CR cannot be set to 10G or 25G.

-Parameter relationship with conditions:

  • If CONNPORTNUM is set to 1, 2, 3, 4, CONNCR1 is valid.
