Meaning

Indicates the speed mode of the Ethernet port. This parameter must be set to the same value as that of the peer port. GE electrical ports of base board support 1000 Mbit/s only when working in auto-negotiation mode. When Port Attribute is set to FIBER and Speed is set to AUTO for a GE optical port, the port works at a rate of 1000 Mbit/s in auto-negotiation mode. In this case, the base station can only negotiate the duplex mode with the peer device at a fixed rate of 1000 Mbit/s. When Port Attribute is set to FIBER and Speed is set to 1000M for a GE optical port, the port works at a rate of 1000 Mbit/s in forced mode. If the Ethernet port corresponding to the optical port of the main control board is not configured, the system uses the 1000 Mbit/s auto-negotiation mode by default. If the non-default 1000 Mbit/s auto-negotiation mode is used, for example, 10 Gbit/s optical port is used, you need to run the ADD ETHPORT command to set parameters such as the rate.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When any one of the parameters PA, SPEED and DUPLEX is set to UNCONFIG, the other two must also be set to UNCONFIG.

-Parameter relationship with conditions:

  • If PA is set to AUTO, COPPER, FIBER, UNCONFIG, SPEED must be set.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ETHPORT MO, if SBT and PA are set to ETH_COVERBOARD and COPPER, respectively, this parameter can be set to 10M, 100M, 1000M, or AUTO.
  • In the ETHPORT MO, if SN is within the range from 0 to 5, SBT and PA are set to ETH_COVERBOARD and FIBER, respectively, this parameter can be set to 100M, 1000M, 10G, AUTO, 40G or 100G.
  • In the ETHPORT MO, if SN is set to 6 or 7, SBT and PA are set to ETH_COVERBOARD and FIBER, respectively, this parameter can be set to 100M, 1000M, or AUTO.
  • In the ETHPORT MO, if SBT and PA are set to ETH_COVERBOARD and AUTO, respectively, this parameter can be set to 100M, 1000M, or AUTO.
  • In the ETHPORT MO, if SBT and PA are set to BASE_BOARD and COPPER, respectively, this parameter can be set to 10M, 100M, or AUTO.
  • In the ETHPORT MO, if SBT and PA are set to BASE_BOARD and FIBER, respectively, this parameter can be set to 100M, 1000M, 10G, 25G, or AUTO.
  • In the ETHPORT MO, if SBT and PA are set to BASE_BOARD and AUTO, respectively, this parameter must be set to 100M, 1000M, or AUTO.
  • In the ETHPORT MO, if PA is set to UNCONFIG, this parameter must be UNCONFIG.
