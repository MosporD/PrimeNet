LST BBP
Meaning

Indicates whether the specifications for LTE FDD and LTE TDD cells supported by a baseband processing board can be flexibly adjusted. When this switch is turned on, the RAT resource proportion can be flexibly allocated. In this case, a cell must be bound to a baseband processing board. When this switch is turned off, the RAT resource proportion needs to be configured. Currently, this parameter applies only to the UBBPg.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If WM in a BBP MO is set to HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, or SPEC_MODE1, LTEFLEXSPECSW must be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes only LTE_FDD and LTE_TDD or includes only LTE_FDD, LTE_TDD and NBIOT, LTEFLEXSPECSW cannot be set to ON.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when LTEFLEXSPECSW is set to ON, SRT cannot be set to FDD_ENHANCE, TDD_ENHANCE or NBIOT_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only the UBBP supports the LTEFLEXSPECSW parameter.

-Parameter relationship with conditions:

  • If TYPE is set to UBBP, LTEFLEXSPECSW is valid.
