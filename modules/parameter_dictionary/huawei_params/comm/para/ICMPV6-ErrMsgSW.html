Meaning

Indicates whether to send ICMPv6 error messages. ICMPv6 error messages include Destination Unreachable message and Packet Too Big message. Both can be selected. The value DST_UNREACHABLE(Destination Unreachable) indicates that ICMPv6 Destination Unreachable messages will be sent. Generally, if a base station does not find the corresponding interface after receiving a TCP/UDP IPv6 packet, it sends an ICMPv6 Destination Unreachable message. Sending this message exposes the device or brings pressure on network devices. You can disable the transmission of Destination Unreachable messages by setting this parameter, avoiding network security risks. The value PTB(Packet Too Big) indicates that ICMPv6 Packet Too Big messages will be sent. In cascading or panel-based co-transmission scenarios, if the length of a forwarded IPv6 packet received by the base station exceeds the IPv6 MTU (specified by the INTERFACE.MTU6 parameter), the base station discards the packet and sends an ICMPv6 Packet Too Big message to the source end of the IPv6 packet. IPv6 allows the source end of an IPv6 packet to detect the MTU of the transmission link based on Packet Too Big messages and adjust the length of packets to be sent. This prevents packet discarding because the packet length exceeds the MTU of the transmission devices. Sending this error message also exposes devices or poses pressure on network devices. You can disable the sending of ICMPv6 Packet Too Big messages to prevent network security risks. If this option is deselected, ensure that the value of the INTERFACE.MTU6 parameter for the forwarding interface is greater than or equal to the maximum IPv6 packet length of the lower-level base station. If NULL is displayed in the command output, the ICMPv6 error messages specified by this parameter are not sent.
