Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an MPLNK MO, if E1T1SN is the same as SN, E1T1SBT must be the same as SBT.

-Parameter relationship with conditions:

  • If SN is set to 0~5, 6~7, SBT must be set.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In the MPLNK MO, if the value of SN is within the range from 0 to 5, this parameter must be set to E1_COVERBOARD.
  • In the MPLNK MO, if SN is set to 6 or 7, this parameter can be set to BASE_BOARD or BACK_BOARD.
