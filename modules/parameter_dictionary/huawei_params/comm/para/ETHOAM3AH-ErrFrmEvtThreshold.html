MML Command

ACT ETHOAM3AH

LST ETHOAM3AH
Meaning

Indicates the threshold for the erroneous frame event. If the number of erroneous frames within a second exceeds the threshold, an erroneous frame event occurs. This event is checked every other second.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Error Frame Event Threshold parameter in the ETH3AH MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.
