Meaning

Indicates the user-defined rate. The value AUTO indicates that auto-negotiation is used. The value MANUAL indicates that the rate is set manually and the rate must be set to a fixed value for each board on the RRU chain/ring. Other values indicate the corresponding fixed rates. If the CPRI link fails with this parameter set to a fixed rate, the RRU cannot work with this CPRI rate.

Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an RRUCHAIN MO corresponds to a CXU MO with CXUTYPE set to RMU, CR in the RRUCHAIN MO must be set to a value other than MANUAL.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CR in an RRUCHAIN MO is not set to AUTO, USERDEFRATENEGOSW of the RRUCHAIN MO can only be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If RESVBW of an RRUCHAIN is not set to NULL, the RRUCHAIN must correspond to the RHUB and the TopoType of the RRUCHAIN must be set to CHAIN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If RESVBW of an RRUCHAIN unequal to NULL, the CpriRate of the RRUCHAIN must be set to 10.1G or 24.3G.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an RRUCHAIN MO, if CR is set to MANUAL, TT must be set to CHAIN.
  • [Co-MPT, NodeB, eNodeB, gNodeB]If SCR in an RFU MO is set to AUTO, CR in the RRUCHAIN MO corresponding to RCN in the RFU MO cannot be set to MANUAL.
  • [Co-MPT, NodeB, eNodeB, gNodeB]SCR in an RRU MO cannot be set to a value greater than that in its upper-level RRU MO if PS is not set to 0 in each RRU MO and CR is set to MANUAL or CONNCR1 is set to MANUAL in the RRUCHAIN MO associated with the RRU MOs.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When PS in an RFU MO is not set to 0, and CR in the RRUCHAIN where the RFU MO is located is set to MANUAL, the value of SCR in the RFU MO must be less than or equal to that of SCR in the upper-level RFU in this RRUCHAIN MO.
  • [Co-MPT, NodeB, eNodeB, gNodeB]If CR is set to MANUAL or CONNCR1 is set to MANUAL in an RRUCHAIN MO, SCR in the RRU MOs associated with the RRUCHAIN MO can have two different values at most.
  • [Co-MPT, NodeB, eNodeB, gNodeB]When CR in an RRUCHAIN MO is set to MANUAL, SCR in the RFU MOs on this RRUCHAIN MO can be set to a maximum of two different values.
  • [Co-MPT, eNodeB, gNodeB]When PROTOCOL in an EQUIPMENT MO is set to TDL_IR and PROTOCOL in an RRUCHAIN MO is set to DEFAULT, CR in the RRUCHAIN MO cannot be set to MANUAL.

-Parameter relationship with conditions:

  • If TT is set to CHAIN, LOADBALANCE, RING, CR is valid.
