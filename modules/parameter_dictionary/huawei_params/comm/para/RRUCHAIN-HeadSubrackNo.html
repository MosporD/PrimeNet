Parameter Relationship

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TT in the RRUCHAIN MO is set to RING or LOADBALANCE, HCN, HSRN, HSN, HPN, and HSPN in the RRUCHAIN MO must be different from TCN, TSRN, TSN, TPN, and TSPN, respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An RRUCHAIN MO must meet the following conditions:
  • 1. When TT in the RRUCHAIN MO is not set to TRUNK_CHAIN, the CPRIPORT MO associated with HCN, HSRN, HSN, HPN, and HSPN must not be occupied.
  • 2. When TT in the RRUCHAIN MO is set to RING or LOADBALANCE, the CPRIPORT MO associated with TCN, TSRN, TSN, TPN, and TSPN in the RRUCHAIN MO must not be occupied.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the RRUCHAIN MO, when TT is set to RING and BM is set to HOT, the combination of HCN, HSRN, and HSN cannot be the same as the combination of TCN, TSRN, and TSN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an RRUCHAIN MO with TT set to LOADBALANCE is connected to a CXU MO with CXUTYPE set to RMU, HCN, HSRN, and HSN are set to the values of TCN, TSRN, and TSN, respectively.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an RRUCHAIN MO, when TT is not set to CHAIN and HCN, HSRN, and HSN are configured on the RHUB MO or TCN, TSRN, and TSN are configured on the RHUB MO, TCN, TSRN, and TSN must be configured on the same RHUB MO as the HCN, HSRN, and HSN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, if TT is set to RING, HCN and TCN must be set to the same value, and HSRN and TSRN must be set to the same value.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]An RFU MO with RT set to MTXU cannot be configured on an RRUCHAIN MO when one of the following conditions is met: 1. TYPE in the BBP MO specified by HCN, HSRN, and HSN in the RRUCHAIN MO is not set to UBBP and WM in this BBP MO is not set to HYBRID. 2. TT in the RRUCHAIN MO is set to RING, and TYPE in the BBP MO specified by TCN, TSRN, and TSN is not set to UBBP and WM in this BBP MO is not set to HYBRID.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU3910; TYPE in the BBP MO corresponding to the converged board is set to UBBP.
  • [Co-MPT, NodeB, eNodeB, gNodeB]The total number of combinations of HCN, HSRN, and HSN values in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE and combinations of CONNCN1, CONNSRN1, and CONNSN1 values in RRUCHAIN MOs with TT set to TRUNK_CHAIN cannot exceed two if the RRUCHAIN MOs meet the following conditions: they use the same converged board; TYPE in the SUBRACK MO where the converged board is located is set to BBU5900 or BBU5900A; TYPE in the BBP MO corresponding to the converged board is set to UBBP or UBBP-W.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an RRUCHAIN MO corresponds to the RHUB or CXU MO, USERDEFRATENEGOSW of the RRUCHAIN MO can only be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If an RRUCHAIN MO corresponds to the RHUB or CXU MO, the PROTOCOL of the RRUCHAIN cannot be set to eCPRI.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in the BBP MO specified by LCN, LSRN, and LSN in an RRUCHAIN MO must be set to UBBP or UBBP-W if the RRUCHAIN MO meets the following conditions: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, none of LCN, LSRN, and LSN can be set to 255 if the following conditions are met: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively, or the subrack corresponding to HCN and HSRN is not located in the local base station.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RRUCHAIN MO, HSN must be set to a value less than or equal to 5 if the following conditions are met: AT is set to PEERPORT; TT is set to CHAIN; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT is set to PEERPORT and TT is set to CHAIN, and LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively in an RRUCHAIN MO, then there must be a CTRLLNK MO with CN equal to LCN and SRN equal to LSRN or with UPCN equal to LCN and UPSRN equal to LSRN.
  • [Co-MPT, NodeB, eGBTS, eNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (2) Neither LCN nor LSRN is set to 255. (3) When TT is set to CHAIN, the combination of LCN and HCN is different from the combination of LSRN and HSRN; or when TT is set to TRUNK_CHAIN, the combination of LCN and CONNCN1 is different from the combination of LSRN and CONNSRN. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.
  • [gNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (2) Neither LCN nor LSRN is set to 255. (3) When TT is set to CHAIN, the combination of LCN and HCN is different from the combination of LSRN and HSRN; or when TT is set to TRUNK_CHAIN, the combination of LCN and CONNCN1 is different from the combination of LSRN and CONNSRN. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.
  • [gNodeB]In an RRUCHAIN MO, HSN must be set to 2 or 3, and LSN must be set to 255, 3, or 2 if the following conditions are met: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN; TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900.
  • [gNodeB]In an RRUCHAIN MO, if TT is set to CHAIN or LOADBALANCE, AT is set to PEERPORT, LCN and LSRN are both set to 255 or are set to the values of as HCN and HSRN respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900, then the following conditions must be met: when HSN is set to 2, a BBP MO with SN set to 3 is configured; when HSN is set to 3, a BBP MO with SN set to 2 is configured.
  • [gNodeB]A BBP equal to the converged board in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN respectively; LSN is not set to 255.
  • [gNodeB]HCN, HSRN, and HSN in RRUCHAIN MOs with TT set to CHAIN or LOADBALANCE or CONNCN1, CONNSRN1, and CONNSN1 in RRUCHAIN MOs with TT set to TRUNK_CHAIN must be set to the same values if each RRUCHAIN MO meets the following conditions: these RRUCHAIN MOs use the same converged board; AT is set to PEERPORT; TYPE in the BBP MO corresponding to the converged board is not set to UBBP; TYPE in the SUBRACK MO where the slot specified by LSN is located is set to BBU3910.

-Parameter relationship with conditions:

  • If TT is set to CHAIN, LOADBALANCE, RING, HSRN is valid.
