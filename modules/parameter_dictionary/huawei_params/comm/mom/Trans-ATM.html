ATM MOM Description

This section describes the functions and concepts of asynchronous transfer mode (ATM). It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to ATM.

Functions and Concepts

ATM protocol architecture consists of user plane, control plane, and management plane. Functions of each plane are as follows:
  • The user plane involves protocols for user data exchange between an ATM endpoint and a switch and protocols for traffic management, such as congestion control and error recovery. Data defined by these protocols can be carried only by established virtual path connections (VPCs) and virtual channel connections (VCCs). The user plane involves physical layer, ATM layer, ATM adaptation layer, and upper layer.
  • The control plane uses signaling protocols to establish or release connections. The control plane involves physical layer, ATM layer, ATM adaptation layer, and upper layer.
  • The management plane involves layer management and plane management. Layer management manages the layers of each plane and has the same hierarchy as other planes. Plane management manages the whole system and communication between planes.

MOs related to ATM channels are defined as follows.
Table 1 MOs related to ATM channels

Protocol Layer

MO

Description

ATM layer

IMAGRP

Indicates a group of combined physical links using Inverse Multiplexing over ATM (IMA).

An IMA group is used to obtain higher bandwidth to transmit high-speed ATM cell streams.

UNLINK

Indicates the user-network interface (UNI) link.

The UNI link directly transmits ATM cells using E1/T1 at the transmission convergence (TC) sublayer of the ATM physical layer.

FRAATM

Indicates the fractional ATM.

The fractional ATM applies to the TC sublayer of the ATM physical layer.

In this mode, multiple timeslots out of the 32 timeslots on an E1 (or 24 timeslots on a T1) are used to transmit an ATM cell. The ATM cell is restored in the associated timeslots on the E1/T1.

ATM adaptation layer

SAALINK

Indicates the Signaling ATM Adaptation Layer (SAAL) link.

The SAAL carries signaling protocols in ATM-based networks to ensure reliable transmission of signaling.

Transport layer and application layer

AAL2NODE

Indicates the AAL2 node.

The AAL2 node is used to trigger the establishment of Access Link Control Application Part (ALCAP).

ALCAP is a general name for transport signaling protocols used to set up or release transmission bearers, which are used to communicate between the transport layer and other external modules.

The AAL2 node provides functions such as ALCAP protocol processing, data configuration, status query, and resource management.

AAL2PATH

Indicates the AAL2 path.

The AAL2 path transmits service data between AAL2 nodes.

OMCH

Indicates the maintenance channel between the base station and the EMS. The EMS manages and maintains the base station through this channel.
