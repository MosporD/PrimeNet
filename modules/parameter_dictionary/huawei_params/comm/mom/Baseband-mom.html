Baseband Equipment MOM Description

This section describes the functions and concepts of baseband equipment. It also illustrates managed object models (MOMs) and describes the corresponding managed objects (MOs).

Functions and Concepts

Baseband equipment

Baseband equipment is a set of baseband processing units, which process uplink data, downlink data, or both uplink and downlink data. Cabinet number, subrack number, and subrack number are configured to add a baseband processing board to baseband equipment as a baseband processing unit. A cell uses baseband resources based on baseband equipment.

All baseband processing boards in the baseband equipment form a baseband processing resource pool for processing baseband data in the cells. For the LTE mode, if no baseband equipment is assigned to a cell, all baseband processing boards in a BBU serve as a resource pool to provide services for the cell.

Managed Object Model

Figure 1 is a subset of the eNodeB MOM and it shows MOs related to baseband equipment.

Figure 1 Baseband equipment MOM

The baseband equipment MOs are described as follows:

  • CarrierResource defines a carrier management root object, which manages MOs associated with carrier resources.
  • BasebandEqm defines a set of baseband processing units, which are classified into three types: uplink, downlink, and uplink and downlink combined.
