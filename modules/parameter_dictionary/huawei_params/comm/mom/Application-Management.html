Application Management MOM Description

This section describes the functions and concepts of application management. It also provides the managed object model (MOM) view and describes managed objects (MOs) related to application management.

Functions and Concepts

The application management provides the operating environment for a function. If a base station needs to provide a function of a certain mode, a corresponding application of this mode must be added. For example, if the radio access function of LTE needs to be added in mode evolution scenarios, a correspoding application of the eNodeB must be added.
