Transport MOMs

This chapter describes the MOMs related to transmission.

  • IPv4 MOM Description
    This section describes the functions and concepts of IPv4. It also provides the managed object model (MOM) views and describes the managed objects (MOs) related to IPv4.
  • IPv6 MOM Description
    This section describes the functions and concepts of IPv6. It also provides the managed object model (MOM) views and describes the managed objects (MOs) related to IPv6.
  • Transmission Security MOM Description
    This section describes the functions and concepts of IEEE 802.1X-based access control, IPsec, packet filtering, and IP attack defense policy. It also provides the managed object model (MOM) view of and the managed objects (MOs) related to transmission security.
  • PKI MOM Description
    This section describes the functions and concepts of the public key infrastructure (PKI) system architecture, digital certificate classifications, and device certificate management. It also provides the managed object model (MOM) view and describes managed objects (MOs) related to device certificates, trust certificates, and certificate revocation lists (CRLs).
  • Transmission Maintenance and Test MOM Description
    This section describes the functions and concepts of point-to-point and end-to-end transmission maintenance and test methods. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to transmission maintenance and test.
  • Transmission Resource Management MOM Description
    This section describes the functions and concepts related to transport resource management. It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to transport resource management.
  • ATM MOM Description
    This section describes the functions and concepts of asynchronous transfer mode (ATM). It also provides the managed object model (MOM) view and describes the managed objects (MOs) related to ATM.
