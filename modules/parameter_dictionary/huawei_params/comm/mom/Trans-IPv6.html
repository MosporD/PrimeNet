IPv6 MOM Description

This section describes the functions and concepts of IPv6. It also provides the managed object model (MOM) views and describes the managed objects (MOs) related to IPv6.

Functions and Concepts

IPv4 has a limited number of available IP addresses. IPv6, an improved IP version, has been introduced to overcome IP address exhaustion.

IPv4/IPv6 dual-stack is a technique that supports both IPv4 and IPv6. This technique is used during IPv4-to-IPv6 transition. A node that supports IPv4/IPv6 dual-stack is called a dual-stack node. A dual-stack node can work in any of the following modes:
  • IPv6-only mode
  • IPv4-only mode
  • IPv4/IPv6 dual-stack mode
The base station type determines MO configurations.
  • If a base station functions as an IPv4 node, only IPv4-related MOs need to be configured.
  • If a base station functions as an IPv6 node, only IPv6-related MOs need to be configured.
  • If a base station functions as a dual-stack node, both IPv4- and IPv6-related MOs need to be configured.

The IPv6-related MOs are different from the IPv4-related MOs for a base station. This document focuses on IPv6-related MOs. For details on IPv4-related MOs and MOs shared by IPv4 and IPv6, see IPv4 MOM Description and Transmission Maintenance and Test MOM Description.

IPv6-related MOs are defined as follows:

  • PMTUCFG defines the global path maximum transmission unit (PMTU) detection configurations, including the detection mode, User Datagram Protocol (UDP) port number, detection period, PMTU aging period, and differentiated services code point (DSCP).
  • IPROUTE6 defines an IPv6 static route. An associated INTERFACE MO must be created before an IPROUTE6 MO. The ITFID parameter in the IPROUTE6 MO must be already configured in the INTERFACE MO.
  • INTERFACE defines an interface. When the value of IPV6SW in an INTERFACE MO is ENABLE, the interface supports the IPv6 function.
  • IPADDR6 defines an IPv6 address for an interface. The IPv6 address must be a global unicast address. An associated INTERFACE MO must be created before an IPADDR6 MO. The ITFID parameter in the IPADDR6 MO must be already configured in the INTERFACE MO.
  • OMCH defines an OM channel between a base station and an EMS. When the value of BEAR in an OMCH MO is IPV6, this MO defines an IPv6-based OM channel, including the IPv6 addresses of the base station and EMS.
