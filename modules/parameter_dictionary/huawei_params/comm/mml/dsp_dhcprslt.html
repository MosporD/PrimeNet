Display OM Channel Automatic Establishment Result (DSP DHCPRSLT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the automatically obtained results after automatic establishment of the remote maintenance channel.

Note

  • The result of this command is the latest automatic establishment result of the remote maintenance channel.

  • When an NE transmits data through an Ethernet port, the NE automatically checks whether the user configuration is consistent with the automatic OMCH establishment result. The check items include whether the board providing the transmission port is working, Ethernet port attributes, VLAN ID, interface IP address, default gateway IP address, IKE proposal, IPSec proposal, and OMCH.

Parameters

None.

Example

Example 1: To query the result of automatic establishment of the remote maintenance channel and no valid response has been received, run the following command:
DSP DHCPRSLT:;
The result is shown as follows:
+++    0        2010-09-20 22:57:38
O&M    #25
%%DSP DHCPRSLT:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

BS Running State

Indicates the running status of the BS during automatic establishment of a remote maintenance channel.

Receive Response Flag

Indicates whether to obtain the valid response during automatic establishment of a remote maintenance channel.

Response Time

Indicates the latest time when a DHCP or BOOTP response is received during automatic establishment of the remote maintenance channel.

Check Result

Indicates the results of checking the automatically obtained results after automatic establishment of a remote maintenance channel.

Number of inconsistent key parameters

Indicates the number of inconsistent key parameters.

Values of inconsistent key parameters

Indicates the values of inconsistent key parameters in the check result.

Bearer Type

Indicates the bearer type of an OM channel. If this parameter is set to ATM, the element management system (EMS) uses the ATM-based transmission network to maintain the device. If this parameter is set to IPV4, the EMS uses the IPv4-based transmission network to maintain the device. If this parameter is set to IPV6, the EMS uses the IPv6-based transmission network to maintain the device. ATM does not apply to LTE and NR networks. IPv6 does not apply to GSM and UMTS networks.

Data Source for OMCH Setup

Indicates the data source for establishing an OM link.

DHCP Server IP

Indicates the IP address of DHCP Server.

DHCP Server IPv6 Address

Indicates the IPv6 address of the DHCP server.

Cabinet No.

Indicates the cabinet number of the board where the remote maintenance channel is located.

Subrack No.

Indicates the subrack number of the board where the remote maintenance channel is located.

Slot No.

Indicates the slot number of the board where the remote maintenance channel is located.

Networking Scene

Indicates the networking scenario obtained during automatic establishment of the remote maintenance channel.

Local IP

Indicates the local IP address of the remote maintenance channel.

Local Mask

Indicates the local subnet mask of a remote maintenance channel.

Mask

Indicates the subnet mask of the local IP address of PPPLNK or MPLNK. If this parameter is set to 0.0.0.0, it needs to be negotiated.

Peer IP

Indicates the peer IP address of the remote maintenance channel, indicates the IP address of the MAE in an IP network and the device IP address of the RNC in an ATM network.

Peer Mask

Indicates the subnet mask of the peer IP address for the remote maintenance channel.

Local IPv6 Address

Indicates the local IPv6 address of an OM channel. This address must be a globally scoped unicast address.

Peer IPv6 Address

Indicates the peer IPv6 address of an OM channel. This address must be a globally scoped unicast address.

Peer IPv6 Address Prefix Length

Indicates the prefix length of the peer IPv6 address of an OM channel.

VLAN ID

Indicates the OM VLANID of the remote maintenance channel.

VLAN Priority

Indicates the OM VLANID priority of the remote maintenance channel.

Interface IP

Indicates the IP address of the port of the remote maintenance channel.

Interface IP Mask

Indicates the subnet mask of the IP address of the port of the remote maintenance channel.

Default Gateway

Indicates the default gateway address of the remote maintenance channel.

Number of Interface IPv6 Address

Indicates the number of interface IPv6 addresses of an OM channel.

Interface IPv6 Address List

Indicates the list of interface IPv6 addresses of an OM channel.

Next-Hop IPv6 Address

Indicates the default gateway IPv6 address of an OM channel.

Port Type

Indicates the type of physical port that carries a remote maintenance channel. When the base station successfully performs a DHCP detection on a sub-interface, the value of this parameter is the type of the physical port that carries the sub-interface.

Port No.

Indicates the number of physical port that carries a remote maintenance channel. When the base station successfully performs a DHCP detection on a sub-interface, the value of this parameter is the number of the physical port that carries the sub-interface.

Link Change Flag

Indicates whether the configuration of the link that is obtained during automatic establishment of a remote maintenance channel on the BS is the same as the user configuration.

Soft Version Same Flag

Indicates whether the software version of the main control board is the same as that of the board that is involved in the link configuration obtained by automatic remote maintenance channel establishment.

Port Attribute

Indicates whether an Ethernet port is an electrical port or optical port. When the system starts, the system binds an Ethernet port to an electrical port preferentially if the default value of the port attribute is AUTO. If the BS does not support cascading, the port attribute is set to AUTO. If this parameter is incorrectly set, services of a base station will be interrupted after the base station is reset.

Speed

Indicates the speed mode of the Ethernet port. This parameter must be set to the same value as that of the peer port. GE electrical ports of base board support 1000 Mbit/s only when working in auto-negotiation mode. When Port Attribute is set to FIBER and Speed is set to AUTO for a GE optical port, the port works at a rate of 1000 Mbit/s in auto-negotiation mode. In this case, the base station can only negotiate the duplex mode with the peer device at a fixed rate of 1000 Mbit/s. When Port Attribute is set to FIBER and Speed is set to 1000M for a GE optical port, the port works at a rate of 1000 Mbit/s in forced mode. If the Ethernet port corresponding to the optical port of the main control board is not configured, the system uses the 1000 Mbit/s auto-negotiation mode by default. If the non-default 1000 Mbit/s auto-negotiation mode is used, for example, 10 Gbit/s optical port is used, you need to run the ADD ETHPORT command to set parameters such as the rate.

Duplex

Indicates the duplex mode of the Ethernet port.

Trunk Type

Indicates the type of Ethernet trunk. When this parameter is set to DISABLE, the Ethernet trunk is in manual mode, and its status cannot be notified to the peer end. In this case, you need to manually configure the member ports of the Ethernet trunk. The base station considers these member ports as valid member ports of the Ethernet trunk. If this parameter is set to ENABLE, the Ethernet trunk is in static mode. In this case, the member ports added to the Ethernet trunk do not take effect immediately. The base station needs to negotiate with the peer end about the actual valid member ports through LACP.

Ethernet Port No.

Indicates the number of the member port in an Ethernet trunk.

Link No.

Indicates the number of the PPP link.

Time Slot No.

Indicates the number of the ET/T1 timeslot that carries the PPP link or the MLPPP sublink.

Group No.

Indicates the number of the MLPPP group.

Link No.

Indicates the number of the MLPPP link.

IKE Authentication Method

Indicates the authentication method used in the IKE proposal during the successful detection of automatic establishment of the remote maintenance channel.

IKE Version

Indicates the version of the IKE used during the successful detection of automatic establishment of the remote maintenance channel.

Link No.

Indicates the number of the UNI link, or indicates the E1/T1 port number of the board of the UNI link.

16th Time Slot Support

Indicates whether the UNI link or the IMA link can use timeslot 16 of an E1 port.

Scramble Mode

Indicates whether scrambling is applied to the IMA group, the UNI link or the fractional ATM link.

Link No.

Indicates the number of the fractional ATM link.

E1/T1 Timeslot No.

Indicates the number of the ET/T1 timeslot that carries the fractional ATM link.

Group No.

Indicates the number of the IMA group.

IMA Protocol Version

Indicates the version of the IMA protocol. If this parameter is set to V1.0, the position of RX link information in an IMA Control Protocol (ICP) cell is determined by the TX Link ID (LID) transmitted by the local end. If this parameter is set to V1.1, the position of RX link information in an ICP cell is determined by the TX LID transmitted by the peer end.

Tx Frame Length

Indicates the length of the frame used for data transmission on the IMA link in the IMA group. A larger value of this parameter results in higher efficiency but lower sensitivity to bit errors.

Min Number of Links Activated

Indicates the minimum number of active links that must be contained in an available IMA group. If the number of active links contained in the IMA group is smaller than the minimum number, the IMA group is unavailable.

Diff Max Delay(ms)

Indicates the allowed maximum differentiated delay of the IMA group.

Clock Mode

Indicates the clock mode of the E1/T1 port or the IMA group.

Frame Mode

Indicates the frame format of a specified optical port.

E1T1 Type

Indicates the type of E1/T1 port used during the successful detection of automatic establishment of the remote maintenance channel on the BS.

E1T1 Port No.

Indicates the number of the E1/T1 port.

Actual Work Mode

Indicates the actual work mode of the E1/T1 port.

Actual Frame Format

Indicates the actual frame format of the E1/T1 port.

Actual Line Code

Indicates the actual line coding mode of the E1/T1 port.

Destination Slot No.

Indicates the number of the slot housing the destination board whose backplane has an E1/T1 port.

SeGW IP

Indicates the IP address of the security gateway (SeGW) when a base station is deployed in IPsec mode.

IKE Encryption Algorithm

Indicates the encryption algorithm used in the IKE proposal during the successful detection of automatic establishment of the remote maintenance channel.

IKE Authentication Algorithm

Indicates the authentication algorithm used in the IKE proposal during the successful detection of automatic establishment of the remote maintenance channel.

IKE Diffie-Hellman Group

Indicates the Diffie-Hellman (DH) group used in the IKE proposal during the successful detection of automatic establishment of the remote maintenance channel.

IKE PRF Algorithm

Indicates the Pseudo-random Function (PRF) algorithm used in the IKE proposal during the successful detection of automatic establishment of the remote maintenance channel.

IPSec Encapsulation Mode

Indicates the encapsulation mode used in the IPSec proposal during the successful detection of automatic establishment of the remote maintenance channel.

IPSec Transform

Indicates the security protocol used in the IPSec proposal during the successful detection of automatic establishment of the remote maintenance channel.

IPSec AH Authentication Algorithm

Indicates the AH authentication algorithm used in the IPSec proposal during the successful detection of automatic establishment of the remote maintenance channel.

IPSec ESP Authentication Algorithm

Indicates the ESP authentication algorithm used in the IPSec proposal during the successful detection of automatic establishment of the remote maintenance channel.

IPSec ESP Encryption Algorithm

Indicates the ESP encryption algorithm used in the IPSec proposal during the successful detection of automatic establishment of the remote maintenance channel.

Local VRF Index

Indicates the local VRF index of the remote maintenance channel.

Interface VRF Index

Indicates the interface VRF index of the remote maintenance channel.

Security Gateway Local IPv6

Indicates the local IPv6 address of the security gateway when the base station is securely opening.

Security Gateway Peer IPv6

Indicates the peer IPv6 address of the security gateway when the base station is securely opening.
