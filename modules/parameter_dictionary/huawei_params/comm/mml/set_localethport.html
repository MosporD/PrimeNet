Set Enabling Status for Local Ethernet Port (SET LOCALETHPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to enable or disable the local maintenance Ethernet port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If users run this command disable the local maintenance Ethernet port at the local end after the network management system connects to the NE, this command takes effect but the command outputs cannot be displayed.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]If this command is executed to disable the local maintenance Ethernet port through the local maintenance channel when the EMS is connected to the NE, If this command is executed to disable the IPv6 switch through the IPv6 local maintenance channel, the command execution success response cannot be reported after the command takes effect.

Parameters

ID Name Description
SWITCH Enable Flag

Meaning: Indicates whether to enable the local maintenance Ethernet port. When the parameter is set to DISABLE, the local maintenance Ethernet port is disabled if the remote OM channel is working properly, but is enabled if the remote OM channel is faulty. When the parameter is set to ENABLE, the local maintenance Ethernet port is permanently enabled.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
GRATUITOUSARPSW Gratuitous ARP Switch

Meaning: Indicates whether a local maintenance port sends gratuitous ARP packets. When this switch is turned on, a local maintenance port sends gratuitous ARP packets. When this switch is turned off, a local maintenance port does not send gratuitous ARP packets.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
IP6SW IPv6 Switch

Meaning: Indicates whether to enable IPv6 on a local maintenance Ethernet port. When this switch is turned on, a local maintenance IPv6 address can be used to maintain a base station and the local maintenance Ethernet port actively sends IPv6 packets. When this switch is turned off, a local maintenance IPv6 address cannot be used to maintain a base station and the local maintenance Ethernet port does not actively send IPv6 packets. The parameter takes effect only in LTE and NR.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the local maintenance Ethernet port with the parameters as follows: Gratuitous ARP Switch: Disable, IPv6 Switch: Disable, run the following command:
SET LOCALETHPORT: GRATUITOUSARPSW=DISABLE, IP6SW=DISABLE;
