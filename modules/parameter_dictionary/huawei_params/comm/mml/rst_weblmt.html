Reset Web LMT (RST WEBLMT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to reset the Web LMT.

Note

  • [NodeB]This command takes no effect to local Web LMT.

  • [NodeB]Running this command will reboot the Web LMT.

Parameters

None.

Example

Reset Web LMT:
RST WEBLMT:;
