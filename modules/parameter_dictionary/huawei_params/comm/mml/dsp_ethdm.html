Display Delay Measurement Status (DSP ETHDM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the bidirectional delay and jitter on the Ethernet.

Note

None.

Parameters

ID Name Description
SESSIONID Session ID

Meaning: Indicates the number of a performance detection session.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the delay measurement with the parameters as follows: Session ID: 0, run the following command: 
DSP ETHDM: SESSIONID=0;
The result is shown as follows:

Output Description

Field Description

Session ID

Indicates the number of a performance detection session.

MEP ID

Indicates the MEP ID.

Destination Type

Indicates the ITU-T Y.1731 measurement destination type. The parameter value RMEP is the local MEP ID of the peer end. The parameter value MAC is the MAC address configured for the RMEP.

RMEP ID

Indicates the RMEP ID.

MAC Address

Indicates the configured destination MAC address in the format of XXXX-XXXX-XXXX.

Measurement State

Indicates the state of ITU-T Y.1731 performance measurement.

Tx DMM Frames(frame)

Indicates the number of transmitted delay measurement message (DMM) frames.

Rx DMR Frames(frame)

Indicates the number of received delay measurement reply (DMR) frames.

Jitter Std Deviation(microsecond)

Indicates the jitter standard deviation. This parameter measures the standard deviation of jitters sampled in the latest measurement period of 5s compared with the average jitter.

RTT Sum(microsecond)

Indicates the total round trip time (RTT) delay within the latest 5s sampling period.

RTT Average Delay(microsecond)

Indicates the average round trip time (RTT) delay within the latest 5s sampling period.
