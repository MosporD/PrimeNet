Display IMA Link Status (DSP IMALNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of an IMA link.

Note

None.

-Others:

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IMALNK MO, if SN is within the range from 0 to 5 and SBT is set to E1_COVERBOARD, the value range of this parameter is from 0 to 7.
  • In the IMALNK MO, if SN is set to 6 or 7 and SBT is set to BASE_BOARD, the value range of this parameter is from 0 to 3.
  • In the IMALNK MO, if SN is set to 6 or 7 and SBT is set to BACK_BOARD, the value range of this parameter is from 0 to 3.

Service Interrupted After Modification: N/A

If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Actual Value Range: NO, YES

Recommended Value: None

Example

To query the status of an IMA link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 0, Clear Statistic: NO, run the following command:
DSP IMALNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, IMALNKN=0, CLEAR=NO;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board of the IMA link.

Subrack No.

Indicates the subrack number of the board of the IMA link.

Slot No.

Indicates the slot number of the board of the IMA link.

Subboard Type

Indicates the type of sub-board on the board where the IMA link is established.

Link No.

Indicates the number of the IMA link, or indicates the E1/T1 port number of the board of the IMA link.

IMA Group No.

Indicates the IMA group number of the IMA link.

NE TX Link State

Indicates the TX status of the IMA link at the near end. The near end inversely multiplexes one ATM cell stream (unit: cell) to enable the cells to be transmitted on multiple physical links.

NE RX Link State

Indicates the RX status of the IMA link at the near end.

FE TX Link State

Indicates the TX status of the IMA link at the far end. The far end multiplexes the cell streams transmitted on multiple physical connections into a single cell stream.

FE RX Link State

Indicates the RX status of the IMA link at the far end.

NE IMA RX Link Invalid State

Indicates the invalid RX status of the local IMA link at the near end.

FE IMA RX Link Invalid State

Indicates the invalid RX status of the IMA link at the far end.

Number of Tx User Cells(cell)

Indicates the number of user cells transmitted by the IMA link.

Number of Rx User Cells(cell)

Indicates the number of user cells received by the IMA link.

Number of Rx Filtered Cells(cell)

Indicates the number of incorrect user cells discarded by the IMA link.

Number of Rx Dropped Cells(cell)

Indicates the number of discarded idle cells received by the IMA link.

Number of Rx Abnormal Synchronized frame Cells(cell)

Indicates the number of cells with abnormal frame synchronization on the IMA link.

Number of Violation ICP Cells(cell)

Indicates the number of invalid IMA Control Protocol (ICP) cells received by the IMA link.

Number of Correct ICP Cells(cell)

Indicates the number of valid IMA Control Protocol (ICP) cells received by an IMA link.

Number of HEC Failure Cells(cell)

Indicates the number of Header Error Control (HEC) error cells received by the IMA link.

Number of Tx Stuff Cells(cell)

Indicates the number of stuff cells transmitted by the IMA link.

Number of Rx Stuff Cells(cell)

Indicates the number of stuff cells received by the IMA link.

Number of Rx Filler Cells(cell)

Indicates the number of filler cells received by the IMA link.
