Set CPRI Link Loopback (SET CPRILNKLOOP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set a loopback on devices of a CPRI link. After a loopback is set on a CPRI link, a CPRI link performance test can be started to check the quality of the CPRI link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Command Restrictions:

    The CPRI link loopback does not support the ring topology, RHUB board, or branch chain/ring on the RHUB.

    THE CPRI link loopback can be set only between two adjacent nodes.

    Only one CPRI link loopback can be set on a CPRI link.

    Before setting a CPRI link loopback, you must block all downstream RF modules or CXUs (including the lower-level RF module or CXU) of the CPRI link to be tested.

    You cannot set a CPRI link loopback an RRU chain where a CPRI link performance test is in progress.

    In separate-MPT scenarios using the CPRI MUX feature, a loopback for the converged party cannot be set on the RRU chain/ring of the converging party.

    If the results of setting a CPRI link loopback contain "The operation timed out", the status of links on the control and service planes of all downlink RF modules on the CPRI link to be tested is unknown. Only after the performance test period specified by users ends, the RF modules can restore to the status before the CPRI link loopback is set, a new CPRI link loopback can be set, and a new CPRI link performance test can be started.

    If the CPRI port on the specified upper-level node is blocked or a breakpoint is set on this node, CPRI link loopback cannot be started.

    You are allowed to start a new CPRI link loopback task 10 minutes after the loopback period reaches the end.

    The eCPRI protocol does not support CPRI link loopback setting.

  • Impact on System:

    After a CPRI link loopback is set, maintenance links of all downstream boards (including the lower-level RF module) on the CPRI link to be tested will be interrupted.

    After a CPRI link loopback is set, if links cannot be established for the associated boards or the established links cannot work at the maximum CPRI line rate, run the STR CPRILBRNEG command to initiate negotiation.

  • The hardware type of RF modules is indicated by the Description field in the DSP BRDMFRINFO command output. If Description contains V3, V6, KUNLUN, or WUYI, the RF module supports the SET CPRILNKLOOP command.

Example

To set CPRI link loopback with the parameters as follows: UpperLevelNodeCabinetNo: 0, UpperLevelNodeSubrackNo: 0, UpperLevelNodeSlotNo: 3, UpperLevelNodePortNo: 0, UpperLevelNodeSubPortNo: 0, LowerLevelNodeCabinetNo: 0, LowerLevelNodeSubrackNo: 60, LowerLevelNodeSlotNo: 0, LoopbackMode: Upper-Level Loopback, LoopbackPeriod: 300, run the following command:
SET CPRILNKLOOP: UCN=0, USRN=0, USN=3, UPN=0, USPN=0, LCN=0, LSRN=60, LSN=0, LM=UPPERLEVELNODE;
