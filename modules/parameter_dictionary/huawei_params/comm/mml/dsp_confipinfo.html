Display MAC Address of the Conflicting IP Address (DSP CONFIPINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the IP and MAC addresses of the external device whose IP address conflicts with that of the system.

Note

  • A maximum of 100 records can be displayed for each main control board or transmission extension board.

  • A maximum of four records can be displayed for the same IP address in the same virtual routing domain.

  • If the IP address of the loopback interface is detected as address conflict through port detection in the ARP proxy function, this command displays the cabinet number, subrack number, and slot number of the port where the ARP proxy function is enabled.

  • [Co-MPT,NodeB,eGBTS]The output of this command does not show the conflict between an existing device IP address in the system and the IP address obtained from PPP/MP negotiation.

Example

To query MAC Address of the Conflicting IP Address with the parameters as follows: Slot No.: 7, run the following command:
DSP CONFIPINFO: SN=7;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

VRF Index

Indicates the index of a VRF instance.

IP Address

Indicates the conflicting IP address used by the system and the external device.

MAC Address

Indicates the MAC address of the external device whose IP address conflicts with that of the system. The value of this parameter is in the format of XXXX-XXXX-XXXX.

Conflict Occurrence Time

Indicates the time when the IP address conflict occurs.

Conflict Recovery Time

Indicates the time when the IP address conflict recovers.
