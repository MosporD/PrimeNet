Add AAL2 Path (ADD AAL2PATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add an AAL2 path.

Note

  • [Co-MPT,NodeB]Before adding an AAL2 path, ensure that the ATM link (such as an IMA group or a UNI link) used to carry the AAL2 path and the associated AAL2 node have been configured.

  • [Co-MPT,NodeB]When configuring logical resources, the BS checks the bandwidth according to the following rules:

    - Bandwidth configuration rule 1: If A is the bandwidth of the bearer physical port and an AAL2 path does not join a transmission resource group, the total bandwidth of the remote maintenance channels and SAAL links carried on the physical port must be lower than or equal to A and the maximum bandwidth of AAL2 paths or treelink PVCs carried on the port must be lower than or equal to A. The bandwidth of the remote maintenance channel or an SAAL link is determined by the type of carried service. The bandwidth for VBR services is calculated based on the SCR. The bandwidth for CBR or UBR services is calculated based on the PCR. The bandwidth for UBR+ services is calculated based on the MCR. The bandwidth of an AAL2 path or a treelink PVC is calculated based on the PCR.

    - Bandwidth configuration rule 2: If an AAL2 path has joined a transmission resource group (that is, a transmission resource group exists at the bearer physical port) and B is the bandwidth of the physical port, the total bandwidth of the remote maintenance channels and SAAL links carried on the physical port but not added to any transmission resource group must be lower than or equal to B. In addition, the maximum bandwidth of treelink PVCs carried on the port but not added to any transmission resource group must be lower than or equal to B. If C is the TX bandwidth of the transmission resource group, the total bandwidth of the remote maintenance channels and SAAL links that join the transmission resource group must be lower than or equal to C, and the maximum bandwidth of the AAL2 paths or treelink PVCs that join the transmission resource group must be lower than or equal to C. In addition, the total TX bandwidth or RX bandwidth of all the transmission resource groups carried on the physical port must be lower than or equal to B. The bandwidth of the remote maintenance channel or an SAAL link is determined by the type of carried service. The bandwidth for VBR services is calculated based on the SCR. The bandwidth for CBR or UBR services is calculated based on the PCR. The bandwidth for UBR+ services is calculated based on the MCR. The bandwidth of an AAL2 path or a treelink PVC is calculated based on the PCR.

    Method of calculating the physical bandwidth (A) of the transmission interface:

    1. E1 mode (unit: Mbit/s):

    (1) IMA group:

    When timeslot 16 is not used: then A = (1.92 x 2048/2049 x (TX frame length - 1)/TX frame length) x Number of IMA links.

    When timeslot 16 is used: then A = (1.984 x 2048/2049 x (TX frame length - 1)/TX frame length) x Number of IMA links.

    (2) UNI link:

    When timeslot 16 is not used: then A = 1.92.

    When timeslot 16 is used: then A = 1.984.

    (3) Fractional ATM: A = 0.064 x Number of occupied timeslots.

    2. T1 mode (unit: Mbit/s):

    (1) IMA group: A = (1.536 x 2048/2049 x (TX frame length - 1)/TX frame length) x Number of IMA links

    (2) UNI link: then A = 1.536.

    (3) Fractional ATM: A = 0.064 x Number of occupied timeslots.

  • [Co-MPT,NodeB]The permanent virtual circuit (PVC) that carries the AAL2 path must be different from those that exist on the bearer physical port of the AAL2 path.

  • [Co-MPT,NodeB]All the AAL2 paths added on the physical port must join the transmission resource groups that already exist, or none of these AAL2 paths join the transmission resource groups.

  • [Co-MPT,NodeB]An AAL2 path can only join an existing transmission resource group.

  • [Co-MPT,NodeB]A maximum of 248 micro paths can be configured on an AAL2 path.

  • [Co-MPT,NodeB]When a lower-level base station is connected to the RNC through a hub base station, both the AAL2 paths from the hub base station to the RNC and to the lower-level base station are added to transmission resource groups or neither of them is added to a resource group. If both AAL2 paths are added to transmission resource groups, ensure that they are added to transmission resource groups with the same ID. Otherwise, the lower-level base station cannot establish services.

  • [Co-MPT,NodeB]The sum of the following numbers cannot exceed 200: (1) Twice the number of the treelink PVCs configured on this board (2) Total number of the following objects configured on this board: OMCH in which the Bearer Type parameter is set to ATM(ATM), AAL2PATH, and SAALLNK.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT is the main control board, a maximum of 64 AAL2 paths can be configured. If the UMDU is the main control board, a maximum of 32 AAL2 paths can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 32 AAL2 paths can be configured on a WMPT/UMPTa/UMPTb/UMDU/UTRP (subboard type: UAEC).

  • [Co-MPT,NodeB]A maximum of 16 AAL2 paths can be configured on a physical port or for a transmission resource group.

PCR Peak Cell Rate

Meaning: Indicates the peak cell rate (PCR) of an AAL2 path, which is the maximum cell burst rate supported by the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

GUI Value Range: 30~49529

Unit: None

Actual Value Range: 30~49529

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST and RU are set to UBR+ and KBPS, respectively, MCR must be less than PCR.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to UBR+ and RU is set to CELL/S, MCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to RTVBR or NRTVBR and RU is set to KBPS, SCR must be less than PCR.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to RTVBR or NRTVBR and RU is set to CELL/S, SCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.

-Others:

  • In an AAL2PATH MO, if SBT is set to BASE_BOARD, BACK_BOARD, or E1_COVERBOARD, RU is set to KBPS, and ST is set to CBR or UBR, the value range of this parameter is from 30 to 15800.

Example

To add an AAL2 path with the parameters as follows: Node Type: LOCAL, Path ID: 1, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Bearer Port Type: IMA, Bearer Port No.: 0, Join Transmission Resource Group: ENABLE, Transmission Resource Group ID: 0, VPI: 1, VCI: 32, Rate Unit: KBPS, Bearer Service Type: RTVBR, Peak Cell Rate: 31, Sustain Cell Rate: 30, Receive Cell Rate: 30, run the following command:
ADD AAL2PATH: NT=LOCAL, PATHID=1, CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=IMA, PN=0, JNRSCGRP=ENABLE, RSCGRPID=0, VPI=1, VCI=32, RU=KBPS, ST=RTVBR, PCR=31, SCR=30, RCR=30;
