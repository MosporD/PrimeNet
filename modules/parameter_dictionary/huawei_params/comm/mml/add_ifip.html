Add Interface IP Address (ADD IFIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an interface IP address.

Note

  • In the same routing domain, the IP addresses of different ports must be on different network segments, whereas the IP addresses of the same port can be on the same network segment.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT is the main control board, a maximum of 128 interface IP addresses can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 64 interface IP addresses can be configured.

  • Board specifications: A maximum of 128 interface IP addresses can be configured on a WMPT/UMPT/UMDU/LMPT/UTRP (subboard type: UAEC/UIEC). A maximum of 16 interface IP addresses can be configured on a GTMUb/GTMUc. A maximum of 56 interface IP addresses can be configured on a UTRPc. A maximum of 24 interface IP addresses can be configured on a UTRP (subboard type: UEOC). A maximum of 40 interface IP addresses can be configured on a UTRP (subboard type: UQEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • [Co-MPT,NodeB,eNodeB]If an error message indicating an IP address conflict is displayed during the configuration of an interface IP address, search the existing IP address in the system that may conflict with the interface IP address by running the following commands: LST IFIP, DSP IFIP, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, DSP MPGRP, LST IPRT, DSP IPRT, LST SRCIPRT, and DSP SRCIPRT. Then, manually resolve the IP address conflict. The conflicting IP address may be an interface IP address, local IP address of a remote maintenance channel, local IP address of a PPP link, IP address for local maintenance, local IP address of an MP group, next-hop IP address of an IP route, or next-hop IP address of a source IP route.

  • [Co-MPT,NodeB,eNodeB]A maximum of eight interface IP addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, an Ethernet CI port, or a sub-interface. A maximum of seven interface IP addresses can be configured on a port that carries a PPP link or an MP group.

  • [eNodeB]If the LMPT is used as the main control board, the interface IP address with the port type set to PPP or MPGRP can be successfully configured but will fail to take effect.

  • [gNodeB]If an error message indicating an IP address conflict is displayed during the configuration of an interface IP address, search the existing IP address in the system that may conflict with the interface IP address by running the following commands: LST IFIP, DSP IFIP, LST OMCH, DSP OMCH, LST LOCALIP, DSP LOCALIP, LST IPRT, DSP IPRT, LST SRCIPRT, and DSP SRCIPRT. Then, manually resolve the IP address conflict. The conflicting IP address may be an interface IP address, local IP address of a remote maintenance channel, IP address for local maintenance, next-hop IP address of an IP route, or next-hop IP address of a source IP route.

  • [gNodeB]A maximum of eight interface IP addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, an Ethernet CI port, or a sub-interface.

Example

Example 1: To add an interface IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, IP Address: 192.168.2.24, Mask: 255.255.255.0, run the following command: 
ADD IFIP: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, IP="192.168.2.24", MASK="255.255.255.0";
Example 2: To add an interface IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Subboard Type: E1_COVERBOARD, Port Type: MPGRP, Port No.: 1, IP Address: 192.168.11.23, Mask: 255.255.255.0, run the following command: 
ADD IFIP: CN=0, SRN=0, SN=1, SBT=E1_COVERBOARD, PT=MPGRP, PN=1, IP="192.168.11.23", MASK="255.255.255.0";
