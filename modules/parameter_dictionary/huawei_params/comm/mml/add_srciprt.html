Add Source IP Route (ADD SRCIPRT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a source IP route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • System specifications: A base station supports a maximum of 32 source IP routes.

  • Board specifications: A UMPT, UMDU, LMPT, UTRPc, UCCU, UTRPa, UBBPe (excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf1, UBBPf0, UBBPg1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 supports a maximum of 32 source IP route.

  • Source IP routes support only the default VRF domain (VRF index is 0).

  • The priority of a source IP route is higher than that of a destination IP route (including static routes configured by users and direct routes). In other words, the source IP route is preferentially used for forwarding packets. If no source IP route can be obtained, a destination IP route is used.

  • A source IP address and a UDP loop with specified Appoint Interface cannot coexist.

  • If Destination IP is set to a local IP address when the PING command is executed, the source IP address of the source IP route must be different from the value of Source IP or Destination IP in the PING command.

  • After a base station disconnects from the network management system, using DHCP to repair the O&M channel generates a local IP address same as the source IP address of the source IP route, and the destination subnet code of the DHCP-generated route is 255.255.255.255. In this case, if the outgoing port or the next-hop address of this route differs from that of the source IP route, the system disables this source IP route.

  • The source address route does not support load sharing.

  • A base station supports source-based routes only when both the main control board and the board that provides a port for connecting to the transport network support source-based routes.

  • Either IPPATHRT or SRCIPRT or SRCIPROUTE4 can be configured at one time. You need to remove the SRCIPRT before adding an IPPATHRT or SRCIPROUTE4.

Example

To add a source IP route with the parameters as follows: Source Route Index: 0, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Source IP Address: 192.168.10.1, Route Type: NEXTHOP, Next Hop IP: 192.168.10.20, run the following command:
ADD SRCIPRT: SRCRTIDX=0, CN=0, SRN=0, SN=6, SBT=BASE_BOARD, SRCIP="192.168.10.1", RTTYPE=NEXTHOP, NEXTHOP="192.168.10.20";
