Display IP Path Status (DSP IPPATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the status of an IP path.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]If flow control is applied to the transmission resource group associated with the IP path, the bandwidth displayed in the execution result of this command may differ from the actual bandwidth.

  • [Co-MPT,eNodeB]"TX Bandwidth", "Realtime TX Bandwidth", "Non-Realtime TX Bandwidth" specify the service traffic before traffic shaping.

  • [NodeB]You cannot use this command to query whether the IP MUX function is enabled for an IP path on a faulty board.

  • [eNodeB]The transmit bandwidth and receive bandwidth for an IP path are calculated based on the IP layer.

  • [eNodeB]The value of the IP Path Check Result parameter is CHECK_DISABLED in the following cases:

    1. The Static Check Switch parameter in the IPPATH MO is set to DISABLE the IP path.

    2. The Static Check Switch parameter in the IPPATH MO is set to FOLLOW_GLOBAL, and the Static Check Switch parameter in the GTPU MO is set to DISABLE.

    3. The Static Check Switch parameter in the IPPATH MO is modified to ENABLE, but the IP path state has not been detected yet.

    4. The Static Check Switch parameter in the IPPATH MO is set to FOLLOW_GLOBAL and the Static Check Switch parameter in the GTPU MO is modified to ENABLE, but the IP path state has not been detected yet.

To query the status of the IP path with the ID of 0, run the following command:
DSP IPPATH: PATHID=0;

Output Description

Field Description

Path ID

Indicates the ID of an IP path.

TX Bandwidth(kbit/s)

Indicates the actual total traffic transmitted on the IP path.

RX Bandwidth(kbit/s)

Indicates the actual total traffic received on the IP path.

Non-Realtime Reserved TX Bandwidth(kbit/s)

Indicates the actual TX bandwidth reserved for the non-real-time service transmitted on the IP path. The parameter takes effect only in LTE.

Non-Realtime Reserved RX Bandwidth(kbit/s)

Indicates the actual RX bandwidth reserved for the non-real-time service received on the IP path. The parameter takes effect only in LTE.

Realtime TX Bandwidth(kbit/s)

Indicates the actual real-time traffic transmitted on the IP path. The parameter takes effect only in LTE.

Realtime RX Bandwidth(kbit/s)

Indicates the actual real-time traffic received on the IP path. The parameter takes effect only in LTE.

Non-Realtime TX Bandwidth(kbit/s)

Indicates the actual non-real-time traffic transmitted on the IP path. The parameter takes effect only in LTE.

Non-Realtime RX Bandwidth(kbit/s)

Indicates the actual non-real-time traffic received on the IP path. The parameter takes effect only in LTE.

Transmission Resource Type

Indicates the type of transport resource for the IP path. The value HQ indicates high-quality transport resources, and the value LQ indicates low-quality transport resources. This parameter must be set in the hybrid transmission scenario. In other scenarios, the default value of this parameter is used. The parameter takes effect only in LTE.

IP Path Check Result

Indicates the check result for the GTP-U static detection of an IP path. The parameter takes effect only in LTE.

IP MUX Switch

Indicates whether the IP MUX function is enabled on IP paths. LTE currently does not support this function.

Service Type

Indicates the service type of an IP path.

Fault Generation Time

Indicates the time when an IP path becomes faulty.
