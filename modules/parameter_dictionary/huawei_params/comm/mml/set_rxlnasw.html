Set LNA Switch of RX Channel (SET RXLNASW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of the switch and shutdown duration of the low noise amplifier (LNA) for the RRU receive channel.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When the LNA switch for a specified receive channel is turned off, the performance of corresponding cells is affected in terms of the throughput, access success rate, and call drop rate.

  • Do not remove any carrier of LTE TDD mode from an RRU receive channel for which the LNA switch is turned off.

  • If the LNA switch for an RRU receive channel is turned off, it will be turned on after a cell served by the RRU is reestablished.

  • Before turning off the LNA switch for an RRU receive channel in a base station working in TD-SCDMA and LTE TDD mode, block all the carriers on the channel.

  • For an RRU on which one LNA switch controls two receive channels, the settings of one LNA switch take effect on both receive channels. RRUs on which one LNA switch controls two receive channels include: RRU3158-fa, RRU3158e-fa, RRU3168-fa DTC, RRU3168e-fa, RRU3253, RRU3257, RRU3657, RRU3757, RRU3259, AAU3240, and AAU5242.

  • The LNA switches for receive channels of one RRU can only be turned off one by one.

  • When a receive channel is not carrying any services, the LNA switch for this receive channel is turned off by default and cannot be turned on. After an RRU is reset, the LNA switches for receive channels are automatically reset based on service conditions.

SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU where the RX channel is located.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]SRN and SN in the RXBRANCH must meet the following conditions: 1. When SRN is set to 4~5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to 0~8; 2. When SRN is set to 4~5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to 0~5; 3. When SRN is set to 60~254, SN must be set to 0; 4. When the value of SRN in an RXBRANCH MO ranges from 60 to 254 and RT in the RRU MO is set to MPRF, the value of SN in the RXBRANCH MO ranges from 1 to 3; 4. When the value of SRN in an RXBRANCH MO is set to 60 and RT in the RRU MO is not set to MPRF, SN in the RXBRANCH MO ranges from 0 to 5; 5. When the value of SRN in an RXBRANCH MO ranges from 61 to 254 and RT in the RRU MO is not set to MPRF, SN in the RXBRANCH MO must be set to 0.
  • [eGBTS]SRN and SN in the RXBRANCH must meet the following conditions: 1. When SRN is set to 4~5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to 0~8; 2. When SRN is set to 4~5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to 0~5; 4. When SRN is set to 60, SN must be set to 0~5; 4. When SRN is set to 61~254, SN must be set to 0.

RXLNASW LNA Switch of RX Channel

Meaning: Indicates the low noise amplifier (LNA) switch for the RRU receive channel. If this parameter is set to ON, the switch is turned on. If this parameter is set to OFF, the switch is turned off. NULL indicates that the query fails or the board does not support the query.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L-TDD, R, N-TDD
DURATION Receive Channel LNA Shutdown Duration

Meaning: Indicates the duration in which the low noise amplifier (LNA) of the RRU receive channel is shut down. This parameter applies only when RXLNASW is set to OFF.

GUI Value Range: 10~30

Unit: min

Example

To modify the configuration of the switch and shutdown duration of the low noise amplifier (LNA) for the RRU receive channel, the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, RX Channel No.: 0, LNA Switch of RX Channel:OFF, and Receive Channel LNA Shutdown Duration:10, run the following command: 
SET RXLNASW: CN=0, SRN=60, SN=0, RXNO=0, RXLNASW=OFF, DURATION=10;
