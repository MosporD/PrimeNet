List RAE Subunit (LST RAESUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a Remote eAntenna Extension (RAE) subunit.

Note

When the cabinet number of an RAE subunit is 255, the connection between the RAE subunit and the RRU or RFU is not configured. In this case, the subrack number and slot number of this RAE subunit are also set to 255.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RAE.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RAE subunit, which starts from 1.

GUI Value Range: 1~6

Unit: None

Actual Value Range: 1~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the configuration of the RAE subunit with the parameters as follows: Device No.: 10, Subunit No.: 1, run the following command:
LST RAESUBUNIT: DEVICENO=10, SUBUNITNO=1;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the RAE.

Subunit No.

Indicates the number of the RAE subunit, which starts from 1.

Subunit Name

Indicates the name of the RAE subunit. The name of the RAE subunit is optional, but the name configured for each RAE subunit must be unique.

Connect Port Cabinet No.

Indicates the cabinet number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.

Connect Port Subrack No.

Indicates the subrack number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.

Connect Port Slot No.

Indicates the slot number of the RRU or RFU that provides the antenna port to which the RAE subunit is connected.
