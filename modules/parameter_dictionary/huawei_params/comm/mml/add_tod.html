Add TOD (ADD TOD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a Time of Day (TOD) clock link. If the NE can properly obtain the TOD synchronization signals, this link becomes available.

Note

  • Before adding a TOD clock link to a UMPT, you must run the DSP PHYPORT command to check whether the corresponding clock port is enabled. A TOD clock link can be successfully added to a UMPT only if the corresponding clock port is enabled.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The TOD clock link is supported by the USCUb and UMPT only.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]If the USCUb is configured with a BITS clock link, no TOD clock link can be added to the USCUb.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]After a TOD clock link is added, the TOD clock is only an optional reference clock source for the system.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]There is no international standard for the TOD clock. The TOD clock of Huawei currently complies with regulations in the TD TOD protocol of China Mobile. The TOD clock of Huawei cannot be interconnected with a TOD clock of another vendor if that TOD clock of another vendor does not comply with regulations in the TD TOD protocol of China Mobile. For details, see the TD TOD Protocol of China Mobile.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The system supports a maximum of two TOD clock links.

  • [NodeB]The UMTS currently does not support this function.

Parameters

ID Name Description
TN TOD Clock No.

Meaning: Indicates the number of a TOD clock link. When TOD clock links are configured on a USCUb board, the numbers of the TOD clock links have a one-to-one relationship with the numbers of the TOD ports on the USCUb. For example, TOD clock link 0 corresponds to port 0, and TOD clock link 1 to port 1.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
TYPE TOD Type

Meaning: Indicates the type of a TOD clock link. It indicates whether the corresponding TOD port is an input or output port. An input port is used to input clock signals to the NE, and an output port is used to provide clock signals for other NEs. Only the TOD clock of input type can serve as a clock source.

GUI Value Range: IN(Input), OUT(Output)

Unit: None

Actual Value Range: IN, OUT

MML Default Value: IN(Input)

Recommended Value: IN(Input)

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If MODE and CLKSRC in the TASM MO are set to MANUAL and TOD, respectively, TYPE of the corresponding TOD MO must be set to IN.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a TOD MO, when SN is set to 6 or 7, TYPE cannot be set to OUT.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

-Configuration constraints:

Meaning: Indicates the length of the TOD feeder. The feeder delay is calculated on the basis of the TOD feeder length to ensure the clock accuracy. The clock accuracy is affected if there is an excessively large difference [more than 20 m (66 ft)] between the value of this parameter and the actual feeder length.

Example

To add a TOD clock link with the parameters as follows: TOD Type: IN, Slot No.: 3, run the following command:
ADD TOD: TYPE=IN, SN=3;
