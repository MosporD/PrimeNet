Download RET Configuration Data (DLD RETCFGDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to load the remote electrical tilting (RET) configuration data. The RET configuration file is provided by the antenna manufacturer.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the following conditions are met:

    The FTP server has been configured.

    The FTP server is running properly. The IP address of the FTP server is on the same network segment as the IP address of the base station, and the FTP server is properly connected to the base station.

    There is no firewall between the FTP server and the base station.

    The user of the FTP server has the permission to read files in specified paths.

  • The RET unit does not provide any file checking function. Therefore, loading incorrect RET configuration data leads to incorrect configuration data on the RET unit. Before loading RET configuration data, verify with the RET vendor to ensure that the RET manufacturer, model, and working frequency band in the RET configuration data matches the RET unit.

  • The RET configuration data takes effect immediately after the loading.

  • When the Operate Mode parameter is set to SITE, SECTOR or CTRLPORT, a maximum of eight RET Subunits can be loaded with configuration data. When more than twelve RET Subunits need to be loaded with configuration data, set the Operate Mode parameter to SUBUNIT.

  • If there is insufficient disk space, it is recommended that you run related commands such as the CLR FILE command to delete files that are no longer in use.

Example

To load the RET configuration data with the parameters as follows: Operate Mode: CTRLPORT, Control Port Cabinet No.: 0, Control Port Subrack No.: 60, Control Port Slot No.: 0, IP Mode: IPV4, FTP Server IP: 127.0.0.1, User Name: admin, Password: admin, Source File Name: \data\ret.bin, run the following command:
DLD RETCFGDATA: OPMODE=CTRLPORT, CTRLCN=0, CTRLSRN=60, CTRLSN=0, IP="127.0.0.1", USR="admin", PWD="*****", SRCF="\data\ret.bin";
