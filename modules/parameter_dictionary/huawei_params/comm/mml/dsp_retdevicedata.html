Display RET Device Data (DSP RETDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information in the remote electrical tilting (RET) device data.

Note

The execution of this command fails when the RET unit is being calibrated or its tilt angle is being adjusted.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RET.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RET subunit, which starts from 1.

GUI Value Range: 1~12

Unit: None

Actual Value Range: 1~12

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the dynamic information in the RET device data with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP RETDEVICEDATA: DEVICENO=0, SUBUNITNO=1;

Output Description

Field Description

Device No.

Indicates the device number of the RET.

Device Name

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

Subunit No.

Indicates the number of the RET subunit, which starts from 1.

Subunit Name

Indicates the name of the RET subunit. The name of the RET subunit is optional, but the name configured for each RET subunit must be unique.

Antenna Model Number

Indicates the model of the RET antenna module.

Antenna Serial No.

Indicates the serial number of the RET unit.

Max Tilt(0.1degree)

Indicates the maximum tilt supported by the RET subunit.

Min Tilt(0.1degree)

Indicates the minimum tilt supported by the RET subunit.

Band1

Indicates band 1 supported by the antenna.

Beamwidth1(degree)

Indicates the beamwidth of band 1. This parameter is valid only if band 1 is in use. Beamwidth describes the capability of an antenna to transmit RF signals. It also defines the width of the antenna pattern.

Gain1(0.1dBi)

Indicates the gain of band 1. This parameter is valid only if band 1 is in use.

Band2

Indicates band 2 supported by the antenna.

Beamwidth2(degree)

Indicates the beamwidth of band 2. This parameter is valid only if band 2 is in use. Beamwidth describes the capability of an antenna to transmit RF signals. It also defines the width of the antenna pattern.

Gain2(0.1dBi)

Indicates the gain of band 2. This parameter is valid only if band 2 is in use.

Band3

Indicates band 3 supported by the antenna.

Beamwidth3(degree)

Indicates the beamwidth of band 3. This parameter is valid only if band 3 is in use. Beamwidth describes the capability of an antenna to transmit RF signals. It also defines the width of the antenna pattern.

Gain3(0.1dBi)

Indicates the gain of band 3. This parameter is valid only if band 3 is in use.

Band4

Indicates band 4 supported by the antenna.

Beamwidth4(degree)

Indicates the beamwidth of band 4. This parameter is valid only if band 4 is in use. Beamwidth describes the capability of an antenna to transmit RF signals. It also defines the width of the antenna pattern.

Gain4(0.1dBi)

Indicates the gain of band 4. This parameter is valid only if band 4 is in use.

Installation Date

Indicates the date when the antenna is installed.

Installer's ID

Indicates the ID of the installation technician who installed the antenna.

Base Station ID

Indicates the base station ID. AISG1.1-based RET supports a maximum length of 12 characters for the base station ID. If the input base station ID has more than 12 characters, only the first 12 characters are saved on the RET antenna.

AISG Sector ID

Indicates the AISG sector ID. An AISG1.1-based TMA unit supports the longest sector ID of 4. If the input sector ID has more than 4 characters, only the first 4 characters are saved on the RET unit.

Antenna Bearing(degree)

Indicates the antenna azimuth. If this parameter is set to 4294967295, the parameter value is not delivered to the device. In this case, the parameter value in the LST RETDEVICEDATA command output is NULL.

Installed Mechanical Tilt(0.1degree)

Indicates the mechanical tilt of the installation. If this parameter is set to 2147483647, the parameter value is not delivered to the device. In this case, the parameter value in the LST RETDEVICEDATA command output is NULL.
