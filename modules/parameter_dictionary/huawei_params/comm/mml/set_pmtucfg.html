Set PMTU Discovery Global Configuration (SET PMTUCFG)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the global configuration of IPv6 PMTU discovery.

Note

  • [Co-MPT,eNodeB,gNodeB]If a port number is specified, ensure that the port is not occupied at the destination end. Otherwise, PMTU discovery fails.

    When MODE is set to ACTIVE, you need to run the SET ICMPV6 command to allow ICMPv6 messages to be sent, and ensure that the transmission equipment and the peer end can respond with the ICMPv6 Packet Too Big and Destination Unreachable messages. Otherwise, the PMTU discovery fails.

    When MODE is set to ACTIVE, the base station actively sends PMTU discovery packets. When the base station has a large number of links, the peer equipment receives a large number of discovery packets.

  • [Co-MPT,eNodeB,gNodeB]When the base station route is changed or the interface MTU is increased, the base station cannot update the PMTU until the next PMTU detection.

  • [Co-MPT,eNodeB,gNodeB]When the MTU of the transmission network is increased, the base station cannot update the PMTU until the next PMTU detection.

  • [Co-MPT,eNodeB,gNodeB]When MODE is set to PASSIVE, PMTU entries of the SCTP link, tunnel interface, and user-plane path are aged at 02:00 every day.

Parameters

ID Name Description
MODE Mode

Meaning: Indicates the PMTU discovery mode, which can be active or passive. In active mode, the base station sends discovery packets to perform PMTU discovery. In passive mode, the base station automatically adjusts the PMTU size based on the received ICMPv6 Packet Too Big message.

GUI Value Range: PASSIVE(Passive Mode), ACTIVE(Active Mode)

Unit: None

Actual Value Range: PASSIVE, ACTIVE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
PROTOCOLTYPE Protocol Type

Meaning: Indicates the protocol type of PMTU discovery packets.

GUI Value Range: UDP(UDP)

Unit: None

Actual Value Range: UDP

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
PORTNO Port No.

Meaning: Indicates the destination port number specified for PMTU discovery packets. The UDP port numbers of 60000-62559, 64679-64710, 65020, 65040, and 65043 are reserved for certain features of the base station such as NTP and cannot be used as this parameter value.

GUI Value Range: 49152~65535

Unit: None

Actual Value Range: 49152~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If MODE in the PMTUCFG MO is set to ACTIVE, PORTNO cannot be equal to 60000~62559, 64679~64710, 65020, 65040, 65043.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
TIMEOUTDUR Timeout Duration

Meaning: Indicates the timeout duration of waiting for a response to a single PMTU discovery.

GUI Value Range: 500~5000

Unit: ms

Actual Value Range: 500~5000

MML Default Value: None

Recommended Value: 5000

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
AGINGTIME AgingTime

Meaning: Indicates the aging time of a PMTU entry. The recommended value range is 30 minutes to 60 minutes. In passive mode, this parameter is invalid for the user-plane path, SCTP link, and IKE link. PMTU entries of these links always become aged between 2:00 a.m. and 3:00 a.m.

GUI Value Range: 5~60

Unit: min

Actual Value Range: 5~60

MML Default Value: None

Recommended Value: 30

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
DSCP DSCP

Meaning: Indicates the DSCP value used by PMTU detection packets.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 46

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To set the global parameters related to basic PMTU detection configurations with the parameters as follows: Detection Mode: ACTIVE, Protocol Type: UDP, Port No.:49152, Timeout Duration: 500ms, Aging Time: 5min, DSCP: 0, run the following command: 
SET PMTUCFG: MODE=ACTIVE, PROTOCOLTYPE=UDP, PORTNO=49152, TIMEOUTDUR=500, AGINGTIME=5, DSCP=0;
