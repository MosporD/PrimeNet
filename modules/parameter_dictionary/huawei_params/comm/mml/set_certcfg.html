Set Digital Certificate Basic Configuration (SET CERTCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to set the basic configuration of a digital certificate.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the current digital certificate whitelist is not activated, the digital certificate whitelist function fails to take effect even though the IKE Check Switch parameter has been set to ON in the SET CERTCFG command. If the failure lasts for one hour, ALM-26841 Certificate Invalid is reported.

Parameters

ID Name Description
IKECHECKSW IKE Check Switch

Meaning: Indicates the whitelist check switch for an IKE digital certificate. If an IKE peer uses the RSA digital signature to authenticate an IKE proposal, authentication of the peer identity fails, resulting in an IKE negotiation failure when the following conditions are met: this parameter is set to ON; the base station digital certificate whitelist file has been activated but the common name of the peer device certificate is not among the digital certificate whitelist file. You can run the LST CERTFILE command to query whether the digital certificate whitelist has been activated, and the DSP CERTWHITELSTITEM command to query whether the common name of the peer device certificate is among the digital certificate whitelist file. When this parameter is set to OFF, the common name of the peer device certificate is not checked no matter whether the base station certificate whitelist has been activated.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set digital certificate basic configuration with the parameters as follows: IKE Check Switch: ON:
SET CERTCFG: IKECHECKSW=ON;
