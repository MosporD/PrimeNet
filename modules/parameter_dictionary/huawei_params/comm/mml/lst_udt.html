List User Data Type Configuration (LST UDT)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a user data type.

Note

[Co-MPT,eGBTS,eNodeB,gNodeB]This command takes effect only for LTE and NR.

Parameters

None.

Example

To list the configuration of a user data type, run the following command:
LST UDT:;
The result is shown as follows:

Output Description

Field Description

User Data Type Number

Indicates the number of a user data type. User data types numbered from 1 to 9, 65, 66, 69, 70, 75, 79, 80, and 85 are standard user data types that are automatically configured by a base station. User data types numbered 0, and from 10 to 255 excluding 65, 66, 69, 70, 75, 79, 80, and 85 are extended user data types.

User Data Type Transfer Parameter Group ID.

Indicates the ID of a transport parameter group of services corresponding to a user data type. User data types numbered from 1 to 9, 65, 66, 69, 70, 75, 79, 80, and 85 are standard user data types. User data types numbered from 1 to 9 correspond to transport parameter groups with IDs 40 to 48, user data types numbered 65, 66, 75 and 85 correspond to the transport parameter group with ID 40, user data types numbered 69 correspond to the transport parameter group with ID 44, and user data types numbered 70, 79 and 80 correspond to the transport parameter group with ID 45. All of these IDs are automatically configured by a base station.
