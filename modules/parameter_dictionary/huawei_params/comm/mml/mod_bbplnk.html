Modify Base Band Processor Link (MOD BBPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a baseband processing link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The BLADEBBU does not support this function.

  • Only UBBP, WBBPf, LBBPd and UBBP-W support this function.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the configuration differs from its actual connection topology, the baseband data and signaling exchanged between the BBUs will be affected, then the mode where this alarm is reported may not be able to provide services, or the service processing capability is degraded.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the interconnection link.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
HCN Head Cabinet No.

Meaning: Indicates the cabinet number of the head node at one end of the interconnection link.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The combination of HCN and HSRN in a BBPLINK MO must be different from the combination of TCN and TSRN in the same BBPLINK MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (2) Neither LCN nor LSRN is set to 255. (3) When TT is set to CHAIN, the combination of LCN and HCN is different from the combination of LSRN and HSRN; or when TT is set to TRUNK_CHAIN, the combination of LCN and CONNCN1 is different from the combination of LSRN and CONNSRN. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.
  • [gNodeB]A BBPLINK MO is required with HCN, HSRN, and HSN, or with TCN, TSRN, and TSN, set to the same values as LCN, LSRN, and LSN in the RRUCHAIN MO, respectively, when all of the following conditions are met for the RRUCHAIN MO: (1) AT is set to PEERPORT. (4) The first-level board for the RRUCHAIN is not a CXU MO with CXUTYPE set to RPCU.

Example

To modify the configuration of a baseband processing link with the parameters as follows:Link No.: 0, Head Cabinet No.: 0, Head Subrack No.: 0, Head Slot No.: 3, run the following command:
MOD BBPLNK: LN=0, HCN=0, HSRN=0, HSN=3;
