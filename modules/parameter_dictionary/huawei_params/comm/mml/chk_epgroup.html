Check End Point Group (CHK EPGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the user-plane end point groups of which the configurations conflict and the interface type of the conflict.

Note

None.

Parameters

None.

Example

To check the configuration conflict information of the end point group, run the following command:
CHK EPGROUP:;
+++    0        2016-12-12 14:44:15
O&M    #5222
%%CHK EPGROUP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

End Point Group ID

Indicates the ID of the end point group to which an end point belongs.

Configuration Conflict State

Indicates whether there is an end point group configuration conflict.

Configuration Conflict Information

Indicates the information about an end point group configuration conflict.
