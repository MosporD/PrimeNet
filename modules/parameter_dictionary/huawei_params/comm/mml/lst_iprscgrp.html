List IP Transmission Resource Group Configuration (LST IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of all IP transmission resource groups.

Note

None.

Parameters

None.

Example

To list IP Transmission Resource Group Configuration, run the following command:
LST IPRSCGRP:;
The result is shown as follows:

Output Description

Field Description

IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group.

Bearing Port Type

Indicates the type of port where an IP transmission resource group is carried.

Bearing Port ID

Indicates the ID of the port where the IP transmission resource group is configured.

Resource Group Number

Indicates the number of an IP transmission resource group on a port. When you use an MML command to add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates an IP transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the IP transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, or an uplink tunnel on the MAE-Deployment, if there is no default port and auto port IP transmission resource group, the system automatically creates an IP transmission resource group with Transmission Resource Group ID set to AUTOPORT(Autoport Port), The Transmission Resource Group ID is created by using the port type and port ID combination of the corresponding port, it is recommended to set the Transmission Resource Group ID of the user-defined resource group to 0 to 59999 to avoid Transmission Resource Group ID conflict. When you remove any of the preceding objects on the MAE-Deployment, the system automatically removes the IP transmission resource group.

Rate Unit

Indicates the rate unit of the TX bandwidth, RX bandwidth, TX CIR, RX CIR, TX PIR and RX PIR of the IP transmission resource group.

TX Bandwidth

Indicates the maximum uplink bandwidth of an IP transmission resource group at the MAC layer. This parameter value is used as the uplink transport admission bandwidth and TX traffic shaping bandwidth. The minimum rate supported by the UMPTa, UMPTb, UMDU, GTMUb or GTMUc is 64 kbit/s. The LMPT can be configured with a maximum of 360 Mbit/s TX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the ip transmission resource group that is carried on the PPP link.

RX Bandwidth

Indicates the RX bandwidth of an IP transmission resource group. To LTE, this parameter value is also used as the downlink transport admission bandwidth. The LMPT can be configured with a maximum of 540 Mbit/s RX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s RX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s RX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s RX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s RX bandwidth. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX bandwidth. The value of RX bandwidth is set to the maximum value of RX bandwidth supported by the board when it bigger than the maximum one.

TX Committed Burst Size(kbit)

Indicates the TX committed burst size of an IP transmission resource group. The LMPT can be configured with a maximum of 400 Mbit/s TX committed burst size. The WMPT can be configured with a maximum of 600 Mbit/s TX committed burst size. The WMPT, GTMUb or GTMUc can be configured with a maximum of 600 Mbit/s TX committed burst size. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX committed burst size. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX committed burst size. The UMPTg can be configured with a maximum of 25 Gbit/s TX committed burst size. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX committed burst size. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX committed burst size. The value of TX committed burst size is set to the maximum value of TX committed burst size supported by the board when it bigger than the maximum one.

TX Excessive Burst Size(kbit)

Indicates the TX excessive burst size of an IP transmission resource group. The LMPT can be configured with a maximum of 450 Mbit/s TX excessive burst size. The WMPT, GTMUb or GTMUc can be configured with a maximum of 600 Mbit/s TX excessive burst size. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX excessive burst size. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX excessive burst size. The UMPTg can be configured with a maximum of 25 Gbit/s TX excessive burst size. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX excessive burst size. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX excessive burst size. The value of TX excessive burst size is set to the maximum value of TX excessive burst size supported by the board when it bigger than the maximum one.

Operator ID

Indicates the index of the operator. This parameter is used to differentiate between operators. This parameter is reserved for future extension and does not take effect currently.

Scheduling Weight

Indicates the scheduling weight of an IP transmission resource group. This parameter is used in calculating the bandwidth scheduled to a resource group, which helps achieve the user admission control.

TX Committed Information Rate

Indicates the transmit CIR of the IP transmission resource group. The LMPT can be configured with a maximum of 360 Mbit/s TX committed information rate. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX committed information rate. The GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX committed information rate. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX committed information rate. The UMPTg can be configured with a maximum of 25 Gbit/s TX committed information rate. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX committed information rate. The value of TX committed information rate is set to the maximum value of TX committed information rate supported by the board when it bigger than the maximum one.

RX Committed Information Rate

The value of RX committed information rate is set to the maximum value of RX committed information rate supported by the board when it bigger than the maximum one. Only the LTE supports this function currently.
