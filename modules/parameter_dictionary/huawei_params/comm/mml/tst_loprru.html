RRU Loop Test (TST LOPRRU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to perform an RRU loopback test to check whether the physical link between an RRU and its next lower-level RRU is normal. The execution of this command does not affect the running of the RRUs.

Note

This command applies only to LTE, and the protocol type must be IR.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the RRU MO, when RFCONNTYPE is set to INTRA_SYS_INTERCONN, the combination of CN, SRN, SN cannot be the same as the combination of RFCONNCN2, RFCONNSRN2, RFCONNSN2.
  • [Co-MPT, NodeB, eNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [eGBTS]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, AAMU, CXU.
  • [gNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Example

To start a loopback test with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, Loop Type: NXTLVLLP, Loop Period: 5000, Rru Port No.: 1, run the following command:
TST LOPRRU: CN=0, SRN=60, SN=0, LOOPTYPE=NXTLVLLP, LOOPPERIOD=5000, RPN=1;
The result is shown as follows:
+++    0        2012-02-20 15:23:48
O&M    #333
%%TST LOPRRU: CN=0, SRN=60, SN=0, LOOPTYPE=NXTLVLLP, LOOPPERIOD=5000, RPN=1;%%
RETCODE = 0  Operation succeeded.
