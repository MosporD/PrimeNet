Display PSU (DSP PSU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a power supplying unit (PSU).

Note

If the operational status of the PMU that manages the PSU is unavailable, the query fails.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the PSU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the PSU is located.

GUI Value Range: 7

Unit: None

Actual Value Range: 7

MML Default Value: 7

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the PSU is located.

GUI Value Range: 1~10

Unit: None

Actual Value Range: 1~10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the dynamic information about the PSU in slot 1 of subrack 7 in cabinet 0, run the following command:
DSP PSU: CN=0, SRN=7, SN=1;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the PSU is located.

Subrack No.

Indicates the number of the subrack where the PSU is located.

Slot No.

Indicates the number of the slot where the PSU is located.

Running Status

Indicates the running status of the PSU.

Software Version

Indicates the software version of the board.

PCB Version

Indicates the PCB version of the PSU.

EPLD Version

Indicates the erasable programmable logic device (EPLD) version of the PSU.

Produce Date

Indicates the manufacturing date of the PSU.
