Display Current Time Source (DSP TIMESRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the type of available time source and autoswitch.

Note

  • If the time source is a GPS clock, its clock mode cannot be free-running.

  • After initial time synchronization, if the time source is set to NTP or GPS but the configured time source is unavailable, the BS automatically switches to an available GPS or NTP time source. Therefore, the current time source(DSP TIMESRC) is not the configured one(LST TIMESRC).

Parameters

None.

Example

To list the current time source, run the following command:
DSP TIMESRC:;
The result is shown as follows:
+++    0        2018-12-21 14:37:22
O&M    #3657
%%DSP TIMESRC:;%%
RETCODE = 0  Operation succeeded.

Display Available Time Source Currently
---------------------------------------
     Time Source  =  NTP
Automatic Switch  =  On
(Number of results = 1)


---    END

Output Description

Field Description

Time Source

Indicates the external reference time source of the NE.

Automatic Switch

Indicates whether to enable automatic time source switchover. When the switch is turned on, the system switches over the time source when time synchronization fails. When the switch is turned off, the system does not switch over the time source.
