Remove Ethernet Trunk (RMV ETHTRK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an Ethernet trunk.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the corresponding transmission resource group is removed.

  • Before running this command, ensure that the corresponding device IP address is removed.

  • Before running this command, ensure that the corresponding MEP is removed.

  • Before running this command, ensure that the IPSec policy group to which the Ethernet trunk is bound is removed.

  • Before running this command, ensure that the corresponding packet filtering object is removed.

  • When an ETHTRK MO is removed on the MAE-Deployment, its adaptive port transmission resource group is automatically removed, regardless of whether the transmission resource group is manually or automatically created.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]Before running this command, ensure that the corresponding IPv6 port is removed.

-Others:

TN Trunk No.

Meaning: Indicates the number of the Ethernet trunk. When the board is a UTRPc board, the value of this parameter ranges from 0 to 2. When the board is a board other than the UTRPc board, the value of this parameter ranges from 0 to 1.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port ID parameter in the ETHTRUNK MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an ETHTRK MO, this parameter can be set to a value within the range from 0 to 2 if SBT is set to ETH_COVERBOARD.
  • In an ETHTRK MO, this parameter can be set to 0 or 1 if SBT is set to BASE_BOARD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an Ethernet trunk with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Trunk No.: 0, run the following command:
RMV ETHTRK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, TN=0;
