Test Certificate (TST CERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to test the validity of the certificates that are configured on the BS before delivery. These certificates are a device certificate named appcert.pem and a trusted certificate named caroot.pem.

Note

  • This command is used only in manufacturing phase. Do not use it on other occasions.

  • If Slot No. is set to the physical slot number in active/standby mode, the certificate file on board in the specified physical slot is tested.

Example

To test the validity of the certificates that are configured on the board before delivery with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, run the following command:
TST CERT: CN=0, SRN=0, SN=3;
