Query the effective status of POE power supply (DSP PWRPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the effective status of POE power supply.

Note

This command is supported when the subrack type is BBU5900A.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the power supply port.

Subrack No.

Indicates the subrack number of the power supply port.

Slot No.

Indicates the slot number of the power supply port.

Port No.

Indicates the port number of the power supply port.

Power Supply Capability

Indicates whether a power supply port supports power supply. If the power supply port does not support power supply, the value of this parameter is NULL.

Power Type

Indicates the power supply mode of a power supply port. The power supply mode can be Auto, Force, or NULL.

Output Voltage(0.1V)

Indicates the output voltage of the power supply port. Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Output Current(0.1A)

Indicates the output current of the power supply port. Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.
