Remove Downlink Flow Control Para (RMV DLFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove the user-defined configuration of a downlink flow control algorithm. The execution of this command restores the default configuration of the algorithm.

Note

[Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

SBT Subboard Type

Meaning: Indicates the type of sub-board having the port on which the DL flow control algorithm switch is configured.

Meaning: Indicates the bearer type of the physical port where the DL flow control algorithm is configured.

In the current version, this value can be set and take effect when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, and cannot be set when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

  • In the DLFLOWCTRLPARA MO, if SBT is set to UNCHANNELLED_COVERBOARD, this parameter must be set to ATM.
  • In the DLFLOWCTRLPARA MO, if SBT is set to ETH_COVERBOARD, this parameter must be set to IP.

PT Port Type

Meaning: Indicates the type of port where the DL flow control algorithm is configured.

Disuse statement: In later versions, the values LOOPINT, PPP, MPGRP, ETH, ETHTRK, and TUNNEL of this parameter will be deleted. In the current version, these values can be set and take effect when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, and cannot be set when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: IMA(IMAGRP), UNI(UNILNK), FRAATM(FRAATM), PPP(PPP Link), MPGRP(Multi-link PPP Group), ETH(Ethernet Port), LOOPINT(Loop Interface), ETHTRK(Ethernet Trunk), TUNNEL(Tunnel), STM1(STM1)

  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to BASE_BOARD and IP, respectively, this parameter can be set to PPP, MPGRP, ETH, LOOPINT, or ETHTRK.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to BACK_BOARD and ATM, respectively, this parameter can be set to UNI or FRAATM.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to BACK_BOARD and IP, respectively, this parameter can be set to PPP or TUNNEL.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to E1_COVERBOARD and ATM, respectively, this parameter can be set to IMA, UNI, or FRAATM.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to E1_COVERBOARD and IP, respectively, this parameter can be set to PPP or MPGRP.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to UNCHANNELLED_COVERBOARD and ATM, respectively, this parameter must be set to STM1.
  • In the DLFLOWCTRLPARA MO, if SBT and BEAR are set to ETH_COVERBOARD and IP, respectively, this parameter can be set to ETH, ETHTRK, or LOOPINT.

  • In the DLFLOWCTRLPARA MO, if PT is set to TUNNEL, this parameter can be set to any value in the range of 0 to 14.

Example

To remove the user-defined configuration of the DL flow control algorithm with the parameters as follows: Slot No.: 7, Subboard Type: BASE_BOARD, Bear Type: IP, Port Type: ETH, Port No.: 0, run the following command:
RMV DLFLOWCTRLPARA: SN=7, SBT=BASE_BOARD, BEAR=IP, PT=ETH, PN=0;
