Modify TWAMP Sender Configuration (MOD TWAMPSENDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a TWAMP sender.

Note

  • TWAMP uses intrusive measurement. A TWAMP sender actively sends packets to perform the intrusive measurement, which consumes the bandwidth.

  • Modifying the configuration of a TWAMP sender in the full architecture may cause re-negotiation of the corresponding TWAMP client and all the TWAMP senders under this client.

Example

To modify a TWAMP Sender with the parameters as follows: Client Index: 0, Sender Index: 0, DSCP: 50, run the following command: 
MOD TWAMPSENDER: CLIENTID=0, SENDERID=0, DSCP=50;
