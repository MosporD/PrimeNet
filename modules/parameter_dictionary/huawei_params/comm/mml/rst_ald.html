Reset ALD (RST ALD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to reset an antenna line device (ALD) or all ALDs connected to the same port on the RF module.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The reset of a remote electrical tilt (RET) does not change the actual tilt of the antenna.

  • The reset of a tower-mounted Amplifier (TMA) does not change the actual working mode and gain of the TMA.

  • The reset of an ALD takes about 1 minute.

  • If an AISG1.1-based twin TMA is configured as two devices, running this command will reset the first TMA device only. An error message will be returned, indicating the second TMA device reset failure. In this case, run this command on the two devices one by one.

CTRLSRN Control Port Subrack No.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLCN in the ALD MO ranges from 0 to 15, the value of CTRLSRN can be 4, 5, or a number ranging from 60 to 254. When the value of CTRLCN in the ALD MO ranges from 16 to 62, CTRLSRN must be set to 4 or 5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CTRLSN Control Port Slot No.

Meaning: Indicates the slot number of the RRU or RFU that controls the ALD.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLSRN in the ALD MO is set to 4 or 5, the value of CTRLSN ranges from 0 to 8 if TYPE in the CABINET MO where the ALD MO is located is set to BTS3900AL. The value of CTRLSN ranges from 0 to 5 if TYPE is not set to BTS3900AL. When the value of CTRLSRN in the ALD MO is set to 60, CTRLSN ranges from 0 to 5. When the value of CTRLSRN in the ALD MO ranges from 61 to 254, CTRLSN is set to 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Example 1: To reset the ALD whose device number is 0, run the following command:
RST ALD: OPMODE=DEVICENO, DEVICENO=0;
The result is shown as follows:
+++    0        2010-01-06 19:54:02
O&M    #1481
%%RST ALD: OPMODE=DEVICENO, DEVICENO=0;%%

Example 2: To reset the ALD with the parameters as follows: Operate Mode: CTRLPORT, Control Port Cabinet No.: 0, Control Port Subrack No.: 60, Control Port Slot No.: 0, run the following command:
RST ALD: OPMODE=CTRLPORT, CTRLCN=0, CTRLSRN=60, CTRLSN=0;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the ALD. The device number of the ALD must be unique.

Result

Indicates the returned result value after the maintenance command is executed.
