Display Source IPv6 Route (DSP SRCIPROUTE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about effective source IPv6 routes.

Note

None.

Parameters

ID Name Description
SRCRTIDX IPv6 Source Route Index

Meaning: Indicates the index of a source IPv6 route.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To query the information about the Source IPv6 Route, run the following command:
DSP SRCIPROUTE6:;
The result is shown as follows:

Output Description

Field Description

IPv6 Source Route Index

Indicates the index of a source IPv6 route.

VRF Index

Indicates the index of a VRF instance.

Source IPv6 Address

Indicates the source IPv6 address of a source IPv6 route.

Route Type

Indicates the type of a source-based IPv6 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded through a specified outbound interface to a specified next-hop IP address.

Next-Hop IPv6 Address

Indicates the next-hop IPv6 address of a source IPv6 route.

Interface ID

Indicates the ID of the specified outbound interface.

Preference

Indicates the priority of the source IPv6 routing entry. A smaller parameter value indicates a higher priority.

Cabinet No.

Indicates the cabinet number of the board to which a source IPv6 route belongs.

Subrack No.

Indicates the subrack number of the board to which a source IPv6 route belongs.

Slot No.

Indicates the slot number of the board to which a source IPv6 route belongs.

Actual Port Type

Indicates the type of the actual port.

Actual Port No.

Indicates the number of the actual port.

Valid State

Indicates the validity state of a source IPv6 route.

Number of Transmit Packets(packet)

Indicates the number of transmitted packets. When enhanced ping6 connectivity check is enabled, ping6 packets are directly forwarded without matching routes and the number of transmitted packets cannot be measured.
