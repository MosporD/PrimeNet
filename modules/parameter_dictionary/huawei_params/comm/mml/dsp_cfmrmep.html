Display CFM RMEP Status (DSP CFMRMEP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the Remote maintenance association end point (RMEP).

Note

None.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the RMEP belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM RMEP.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMRMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MANAME MA Name

Meaning: Indicates the name of the MA to which the RMEP belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MANAME value of a CFM RMEP.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MANAME in a CFMRMEP MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMRMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
RMEPID RMEP ID

Meaning: Indicates the RMEP ID.

GUI Value Range: 1~8191

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CLEAR Clear Statistic

Meaning: Indicates whether to delete the historical statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Example

To query the CFM RMEP with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, RMEP ID: 2000, run the following command: 
DSP CFMRMEP: MDNAME="CHINA", MANAME="SHANGHAI", RMEPID=2000;

Output Description

Field Description

MD Name

Indicates the name of the MD to which the RMEP belongs.

MD Level

Indicates the level of the CFM MD.

MA Name

Indicates the name of the MA to which the RMEP belongs.

Binding VLAN

Indicates the priority of a VLAN of the MA to which the RMEP belongs.

VLAN ID

Indicates the ID of a VLAN of the MA to which the RMEP belongs.

RMEP ID

Indicates the RMEP ID.

MAC Address

Indicates the MAC address of the RMEP. It must be a valid unicast address in the format of XXXX-XXXX-XXXX. The MAC address of the RMEP can be obtained from the MAC address field carried in the CCM message. If the MAC address configured by the user is different from that carried in the CCM message, the MAC address carried in the MAC message prevails.

Actual MAC Address

Indicates the actual MAC address of the RMEP. The format is XXXX-XXXX-XXXX.

Status

Indicates the status of the RMEP. When CC Switch in the CFMMA MO is set to DISABLE, this status is normal.

Number of RX CCM PDUs(packet)

Indicates the number of received CCM packets from the RMEP.

Number of Bound IPs

Indicates the number of the IP addresses bound to the RMEP.

IP Address List

Indicates the list of the IP addresses bound to the RMEP.
