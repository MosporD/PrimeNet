Display PMTU Entry (DSP PMTU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the IPv6 PMTU entry.

Note

  • [Co-MPT,eNodeB,gNodeB]If the queried IPv6 address of the node with the smallest MTU is NULL, this indicates that the MTU is not obtained from the Packet Too Big Message. Instead, the MTU is obtained through system detection (for example, enabling the packet size to be longer than the MRU of the Layer 2 switch). In this case, the specific IPv6 address cannot be obtained and the queried IPv6 address is displayed as NULL.

  • [Co-MPT,eNodeB,gNodeB]For the IPv6 address of the node with the minimum MTU in the same base station, the PMTU values may be different due to different outbound interfaces of routes.

  • [Co-MPT,eNodeB,gNodeB]When MODE is set to ACTIVE, the query result of the first PMTU detection entry may be inaccurate due to the sequence in which the routes take effect during the upgrade or restart of the base station.

  • [Co-MPT,eNodeB,gNodeB]A maximum of 1024 IPv6 PMTU entries can be displayed. If there are more than 1024 entries, you are advised to filter the entries by the source IPv6 address, destination IPv6 address, or VRF index.

To query the IPv6 PMTU entry, run the following command: 
DSP PMTU:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board to which a PMTU entry belongs.

Subrack No.

Indicates the subrack number of the board to which a PMTU entry belongs.

Slot No.

Indicates the slot number of the board to which a PMTU entry belongs.

VRF Index

Indicates the index of a VRF instance.

Source IPv6 Address

Indicates the source IPv6 address of a PMTU entry.

Destination IPv6 Address

Indicates the destination IPv6 address of a PMTU entry.

Detection State

Indicates the discovery status of a PMTU entry with MODE set to ACTIVE. The value NULL indicates that the PMTU entry is not actively initiated by the base station.

Pmtu Value(byte)

Indicates the PMTU size of a PMTU entry.

IPv6 Address of Minimum MTU Hop

Indicates the IPv6 address of the node where the minimum MTU is detected by a PMTU entry. If the IPv6 address is the source address of a path, the PMTU entry does not receive a PTB packet and uses the MTU corresponding to the outbound interface of the base station route for detection.

Remaining Aging Time(min)

Indicates the remaining aging time of the PMTU entry.
