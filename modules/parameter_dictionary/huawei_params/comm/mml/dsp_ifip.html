Display Interface IP Address (DSP IFIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the interface IP addresses that take effect.

Note

  • [Co-MPT,NodeB,eNodeB]The execution result shows all IP addresses (including user-configured and negotiated IP addresses) that are set on PPP ports, MLPPP ports, Ethernet ports, Ethernet trunk ports, Ethernet CI ports, and sub-interfaces.

  • [Co-MPT,NodeB,eNodeB]The local maintenance port and wireless local maintenance port have been isolated from service ports. Therefore, the IP address that is negotiated by the PPP or MP link on a service port can be the same as the IP address of the local maintenance port or wireless local maintenance port.

  • [Co-MPT,NodeB,eNodeB]If Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, when the MODELSELECT parameter is set to TRADITION(Traditional Mode), the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP DEVIP command. When the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP IFIP command. If Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, the IP address used by the LOCALIP or WLOCALIP object or generated by PPP link or multi-link PPP group must be queried using the DSP IPADDR4 command.

  • [gNodeB]The execution result shows all IP addresses (including user-configured and negotiated IP addresses) that are set on Ethernet ports, Ethernet trunk ports, Ethernet CI ports, and sub-interfaces.

  • [gNodeB]When the MODELSELECT parameter is set to TRADITION(Traditional Mode), the IP address used by the LOCALIP or WLOCALIP object must be queried using the DSP DEVIP command. When the MODELSELECT parameter is set to HOSTGW(Host-Gateway Mode), the IP address used by the LOCALIP or WLOCALIP object must be queried using the DSP IFIP command.

To query the interface IP addresses that take effect, run the following command:
DSP IFIP:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the port is located.

Subrack No.

Indicates the subrack number of the board where the port is located.

Slot No.

Indicates the slot number of the board where the port is located.

Subboard Type

Indicates the type of sub-board on the board where a port is located.

Port Type

Indicates the type of the physical port. The UMTS currently does not support SUBIF.

Port No.

Indicates the number of a port.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Address

Indicates the IP address configured for the port.

Mask

Indicates the subnet mask of the interface IP address configured on the port.

Address Status

Indicates the status of the IP address. If Valid is displayed, it indicates that the IP address is available. If Invalid is displayed, it indicates that the port corresponding to the IP address is not activated. If Duplicate is displayed, it indicates that the IP address conflicts with the IP address of an external interface.
