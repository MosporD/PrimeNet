Modify ACL Rule (MOD ACLRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify an access control list (ACL) rule.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The execution of this command may disrupt the service that references the ACL rule. For details, see the "Service Interrupted After Modification" of each parameter in this command.

  • If an ACLRULE can be queried by running the LST ACLRULE command and the value of the "Auto Config Flag" field is "Auto Created", the ACLRULE object is automatically created by the system and cannot be modified by users.

  • For a UTRP (subboard type: UEOC/UQEC), if 48 ACL rules have taken effect and not all ACL rules referenced by a packet filter have taken effect, running this command to modify any one valid ACL rule makes this ACL rule invalid and automatically validates one ACL rule that is referenced by a packet filter. You can run the DSP ACLRULE command to query the currently valid ACL rules.

  • This operation may interrupt the services or OM channels that references the ACL rule. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • When packet filtering ACL rules are automatically configured by the system or manually configured by users, data forwarding performance fluctuates temporarily.

Unit: None

Parameter Relationship:

-Configuration constraints:

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
RULEID Rule ID

Meaning: Indicates the ID of an ACL rule. The values 1 to 65535 indicate ACL rules manually configured by users or automatically generated for packet filtering. (When the value of ACL Rule Automatic Setup and Deletion Switch of packet filtering is ON, IDs from 50000 to 59999 cannot be used for manually configured ACL rules and are used for automatically generated ACL rules for packet filtering only.) The values 65431 to 65536 indicate the ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate ACL rules automatically generated for packet filtering in endpoint configuration mode. The values 80000 to 89999 indicate ACL rules automatically generated for IPsec in endpoint configuration mode.

GUI Value Range: 1~65535,70000~89999

Unit: None

Actual Value Range: 1~65535,70000~79999,80000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

VLANIDOP VLAN ID Operate

Meaning: Indicates the filter criteria for VLAN IDs. This parameter is valid only when the ACL ID ranges from 4000 to 4999. When this parameter is set to OP_NOVLAN, only packets without VLAN tags are valid.

Example

To modify an ACL rule with the parameters as follows: ACL ID: 3000, Rule ID: 10, Source IP Address: 192.168.5.5, Source Wildcard: 0.0.0.255, Destination IP Address: 192.168.5.10, Destination Wildcard: 0.0.0.255, run the following command:
MOD ACLRULE: ACLID=3000, RULEID=10, SIP="192.168.5.5", SWC="0.0.0.255", DIP="192.168.5.10", DWC="0.0.0.255";
