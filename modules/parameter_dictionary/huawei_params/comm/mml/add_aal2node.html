Add AAL2 Node (ADD AAL2NODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add an AAL2 node.

Note

  • [Co-MPT,NodeB]Before running this command, ensure that the associated SAAL link has been configured.

  • [Co-MPT,NodeB]Before adding the slave AAL2 node, ensure that the master AAL2 node has been configured.

  • [Co-MPT,NodeB]The SAAL link carried on an AAL2 node cannot be used by any other AAL2 node, AAL2 adjacent node, or Iub port.

  • [Co-MPT,NodeB]The ATM address of an AAL2 node must be different from that of any other AAL2 node or AAL2 adjacent node.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT/UMDU is the main control board, a maximum of 5 AAL2 nodes can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 5 AAL2 nodes can be configured on a WMPT/UMPTa/UMPTb/UMDU/UTRP (subboard type: UAEC).

  • [Co-MPT,NodeB]When both active and standby AAL2 nodes are configured and channel switchover is enabled, the standby AAL2 node becomes the active one and automatically takes over services when the active AAL2 node becomes faulty. If channel switchover is disabled, an active/standby switchover will not be triggered even if the active or standby AAL2 node becomes faulty. To support the disaster tolerance scheme for the RNC, the AAL node can work in either primary homing mode or secondary homing mode. By default, the AAL2 node works in primary homing mode. If the default configuration needs to be modified, ensure that disaster tolerance has been configured for the RNC.

Parameters

ID Name Description
NT Node Type

Meaning: Indicates the type of an AAL2 node. If this parameter is set to LOCAL, the AAL2 node is used to control the local services on the BS. If this parameter is set to HUB, the AAL2 node is used to control services of the lower-level BS cascaded to the hub BS.

GUI Value Range: LOCAL(End Node), HUB(Switching Node)

Unit: None

Actual Value Range: LOCAL, HUB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
LN SAAL Link No.

Meaning: Indicates the SAAL link number of an AAL2 node.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
FLAG Transport Channel Flag

Meaning: Indicates the transport channel of an AAL2 node, which can be master or slave.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(Master)

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ADDR ATM Address

Meaning: Indicates the ATM address of an AAL2 node. The value of this parameter is a string of 40 hexadecimal characters with or without the prefix H' (or h'). For example, this parameter can be set to H'3902030405060708090001020304050607080900 or 3902030405060708090001020304050607080900. The ATM address must begin with 39, 45, 47, or 49 to comply with the protocol.

GUI Value Range: Valid ATM address

Unit: None

Actual Value Range: Valid ATM address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In an AAL2NODE MO, ADDR must be comprised of a 40-character hexadecimal string with or without the leading "H'" or "h'". Note that "H'" or "h'" is not included in the length of the string.
  • In the AAL2NODE MO, ADDR can only contain digits (from 0 to 9), lower-case letters (from "a" to "f") and upper-case letters (from "A" to "F"). In addition, it must begin with one of the following numerals: 39, 45, 47 and 49.

-Others:

  • [Co-MPT, NodeB]In the AAL2NODE MO, this parameter is valid only when NT is set to LOCAL and FLAG is set to MASTER.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the type of controller to which an AAL2 node is connected. The controller is either a master controller or a slave controller.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(Master)

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To add an AAL2 node with the parameters as follows: Node Type: LOCAL, SAAL Link No.: 0, Transport Channel Flag: MASTER, ATM Address: H'3902030405060708090001020304050607080900, Belong Flag: MASTER, run the following command: 
ADD AAL2NODE:NT=LOCAL, LN=0, FLAG=MASTER, ADDR="H'3902030405060708090001020304050607080900", BELONG=MASTER;
