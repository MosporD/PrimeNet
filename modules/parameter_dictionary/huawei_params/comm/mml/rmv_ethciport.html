Remove Ethernet CI Port (RMV ETHCIPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to remove an Ethernet CI port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the Ethernet CI port is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the Ethernet CI port is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SN Slot No.

Meaning: Indicates the slot number of the board where the Ethernet CI port is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SBT Subboard Type

Meaning: Indicates the subboard type of the board where the Ethernet CI port is located.

GUI Value Range: BASE_BOARD(Base Board)

Unit: None

Actual Value Range: BASE_BOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
PN Port No.

Meaning: Indicates the number of the Ethernet CI port.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To remove an Ethernet CI port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port No.: 0, run the following command: 
RMV ETHCIPORT: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0;
