Add Source IPv4 Route (ADD SRCIPROUTE4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a source IPv4 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • System specifications: A base station supports a maximum of 32 source IPv4 routes.

  • Board specifications: A UMPT, UMDU, LMPT, UTRPc, UCCU, UTRPa, UBBPe (excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0, UBBPf1, UBBPg1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 supports a maximum of 32 source IPv4 route.

  • The priority of a source IPv4 route is higher than that of a destination IP route (including static routes configured by users and direct routes). In other words, the source IPv4 route is preferentially used for forwarding packets. If no source IPv4 route can be obtained, a destination IP route is used.

  • A source IPv4 route and a UDP loop with specified Appoint Interface cannot coexist.

  • In the same routing domain, if Destination IP is set to a local IP address when the PING command is executed, the source IP address of the source IPv4 route must be different from the value of Source IP or Destination IP in the PING command.

  • After a base station disconnects from the network management system, using DHCP to repair the O&M channel generates a local IP address same as the source IP address of the source IPv4 route, and the destination subnet code of the DHCP-generated route is 255.255.255.255. In this case, if the outgoing port or the next-hop address of this route differs from that of the source IPv4 route, the system disables this source IPv4 route.

  • The source IPv4 route does not support load sharing.

  • A base station supports only source IPv4 routes that are supported by all boards configured in this base station.

  • Either IPPATHRT or SRCIPROUTE4 can be configured at one time. You need to remove the IPPATHRT before adding a source IPv4 route.

Parameters

SRCRTIDX Source Route Index

Meaning: Indicates the index of a source IPv4 route.

Unit: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SRCIPROUTE4 MO, if VRFIDX is set to a value in the range of 1 to 7, PT in the referenced SRCIPROUTE4 MO cannot be set to PPP, MPGRP, and TUNNEL.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SRCIP Source IP Address

Meaning: Indicates the source IPv4 address of a source IPv4 route.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRCIP in an SRCIPROUTE4 MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
RTTYPE Route Type

Meaning: Indicates the type of a source IPv4 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded to a specified outbound interface.

GUI Value Range: NEXTHOP(Next Hop), IF(Exit Interface)

Unit: None

Actual Value Range: NEXTHOP, IF

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to PPP.
  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to MPGRP.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Unit: None

-Others:

Example

To add a Source IPv4 Route with the parameters as follows: SRCRTIDX:1, SRCIP:"192.168.100.10", RTTYPE:NEXTHOP, NEXTHOP:"192.168.100.1", run the following command:
ADD SRCIPROUTE4: SRCRTIDX=1, SRCIP="192.168.100.10", RTTYPE=NEXTHOP, NEXTHOP="192.168.100.1";
