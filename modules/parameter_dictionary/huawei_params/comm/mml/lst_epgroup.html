List End Point Group Configuration (LST EPGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of end point groups.

Note

None.

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the configuration of an end point group, run the following command:
LST EPGROUP:;
The result is as follows:

Output Description

Field Description

End Point Group ID

Indicates the ID of the end point group to which an end point belongs.

VRF Index

Indicates the index of an IPv4 VRF instance.

IPv6 VRF Index

Indicates the index of an IPv6 VRF instance. This parameter takes effect only in LTE and NR.

SCTP Host List

Indicates the list of all SCTP hosts in the end point group. This parameter takes effect only in UMTS, LTE, and NR.

SCTP Peer List

Indicates the list of all SCTP peers in the end point group. This parameter takes effect only in UMTS, LTE and NR.

User Plane Host List

Indicates the list of all user plane hosts in the end point group.

User Plane Peer List

Indicates the list of all user plane peers in the end point group.

Packet Filter ACL Rule Auto-Setup-Deletion SW

Indicates whether to enable the ACL rule self-configuration function for packet filtering. When this parameter is set to ENABLE(Enable), the system automatically generates packet filtering rules for all links of the local and peer end points. If this parameter is set to DISABLE(Disable), the system does not generate packet filtering rules. When the MOD EPGROUP command is executed to change the value of this parameter from ENABLE(Enable) to DISABLE(Disable), the system automatically deletes the packet filtering rules related to links of the local and peer end points.

User Label

Indicates the description of an end point group.

Type

Indicates the type of an end point group. When this parameter is set to COMMON, the local end point group is a common group. When this parameter is set to CENTRALIZED_EX2, the local end point group is dedicated group for the centralized eX2. The parameter takes effect only in LTE.

Link Performance Statistics Switch

Indicates the switch controlling link performance measurement for user plane. When this parameter is set to ENABLE for an endpoint group, the base station performs link performance measurement for this endpoint group. When this parameter is set to DISABLE for an endpoint group, the base station does not perform link performance measurement for this endpoint group. This parameter takes effect only on the UMPT, UTRPc, or UMDU board. The measurement results must be parsed using the maintenance tool.

Control Mode

Indicates whether the object can be modified or deleted by the system. The value MANUAL_MODE means that both the system and the user can modify or delete the object. The value AUTO_MODE means that only the system can modify or delete the object.

Auto Config Flag

Indicates whether the object is created by the system. The value MANUAL_CREATED means that the object is configured by the user manually. The value AUTO_CREATED means that the object is created by the system.

Static Check Switch

Indicates whether the GTP-U static detection function takes effect on user-plane links in an endpoint group. When this parameter is set to ENABLE(Enable), the GTP-U static detection function is enabled on all user-plane links in an endpoint group. When this parameter is set to DISABLE(Disable), the GTP-U static detection function is disabled on all user-plane links in an endpoint group. This parameter is valid only when STATICCHKMODE is set to EPSTATICCHK(Endpoint Group Static Check) in the GEPMODELPARA MO. This parameter takes effect only for LTE and NR.

IP PM Automatic Setup and Deletion Switch

Indicates whether to enable the IP PM session self-configuration function. If this parameter is set to ENABLE(Enable), the system will automatically generate IP PM sessions for links related to the local and peer end points. If this parameter is set to DISABLE(Disable), the system will not automatically generate IP PM sessions. If the value of this parameter is changed from ENABLE(Enable) to DISABLE(Disable) using the MOD EPGROUP command, the system will delete the automatically generated IP PM sessions for links related to the local and peer end points. This parameter is valid only for the user-plane links over the LTE S1 interface. IP PM is a Huawei proprietary protocol. Ensure that IP PM is supported by and has been enabled on the CN equipment before turning on this switch.

IP PM DSCP

Indicates the differentiated services code point (DSCP) of an IP PM session that is automatically generated by a base station. The parameter takes effect only in LTE.

Application Type

Indicates the type of the application referenced by a DFU. The application provides the running environment for the DFU.

eNodeB Interface

Indicates the eNodeB interface that uses the endpoint group. When this parameter is set to DUX2_U, the endpoint group is used by the eNodeB to automatically generate the DUX2 object. Only the DUX2_U and DUEX2_NON_IDEAL options can be selected together. Other options must be selected separately. This parameter takes effect only for CU-DU Split.

gNodeB Interface

Indicates the gNodeB interface that uses the endpoint group. When this parameter is set to GNBDUF1, the endpoint group is used by the gNodeB to automatically generate the GNBDUF1 object. Currently, only one option can be selected. This parameter takes effect only for CU-DU Split.

IP Protocol Version Preference

Indicates the IP protocol version that is preferentially used to automatically establish a control-plane link or user-plane path when the SCTP local IP address or user-plane local IP address in an EPGROUP MO is dual-stack and the IP address of the peer device is also dual-stack. If this parameter is set to IPv4, the IPv4 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. If this parameter is set to IPv6, the IPv6 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. Only one IP protocol can be selected to set up a control-plane link or user-plane path. IPv4 and IPv6 cannot be backed up for each other. This parameter is invalid when the local address or the IP address of the peer device is single-stack. This parameter takes effect only for LTE and NR.
