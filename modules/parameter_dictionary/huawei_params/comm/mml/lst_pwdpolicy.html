List Password Policy (LST PWDPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the password security policy.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]NR does not support the Wi-Fi maintenance function currently. The Wi-Fi access compliance principle in the password security policy parameter is not applicable to NR.

Parameters

None.

Example

To list the password security policy, you should first set the security policy with the parameters as follows: Password minimal length: 10, Password complicacy: LOWERCASE-1&UPPERCASE-0&DIGIT-1&SPECHAR-0, Password max miss times: 3, Auto unlock time: 30, Reset interval of account: 5, Password repeat limit: 5, Password max period: 30, Password min period: 1440, Prompting expiry number of days: 10, Must Modify password when first login switch: Off, Max repeat char times: 2, Weak password dictionary check switch: Off, Maximum Consecutive Characters from User Name:1,and then run the following command:
LST PWDPOLICY:;
The result is as follows:

Output Description

Field Description

Password Minimal Length

Indicates the minimum length of the password. The default value of this parameter is 12.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) must comply with this policy.

WiFi users' passwords must comply with this policy.

Password Complicacy

Indicates the minimum requirements for password complexity. This parameter is used to set the character types that a password must contain, which can be any combination of lowercase letters, uppercase letters, digits, and special characters. If NULL is displayed in the query result, there is no special limitation on the character type. A password contains lowercase letters, uppercase letters, digits, and special characters by default.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) must comply with this policy.

WiFi users' passwords must comply with this policy.

Password Max Miss Times

Indicates the maximum times of attempts with incorrectly entered passwords. The default value of this parameter is 3. If the times of attempts with incorrectly entered passwords reached this parameter, the NE will lock the operator account.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Auto Unlock Time(min)

Indicates the time that needs to elapse for an account to be unlocked after it is locked due to incorrect password inputs. The default value of this parameter is 30.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Reset Interval of Account Lock(min)

Indicates the interval between two incorrect password inputs. The default value of this parameter is 5. If a user inputs the password incorrectly for x times (x can be configured) and the interval between any two consecutive incorrect inputs is smaller than the value specified by this parameter, the user account is locked.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

New Password Repeat Limit

Indicates how many previous passwords the current password must be different from. The default value of this parameter is 10.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords must comply with this policy.

Password Validity(day)

Indicates the password validity period, in days. The default value is 90. The value 0 indicates that the validity period is unlimited.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Minimum Password Duration(min)

Indicates the minimum validity period for the password. The default value of this parameter is 1440. Users are not allowed to change the password in this period.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Password Expiration Reminder(day)

Indicates the number of days in advance users are notified that their passwords are about to expire. The default value of this parameter is 10.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Must Modify Password When First Login Switch

Indicates whether the system forces a user to change the initial password.The default value of this parameter is ON. If this parameter is set to ON, the system forces a user who logs in to an NE using the initial password to change the password.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Max Repeat Char Times

Indicates the maximum repeat times of one character. The default value of this parameter is 2.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Weak Dictionary Check Switch

Indicates whether the system checks the password in weak password dictionary.The default value of this parameter is ON.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) do not comply with this policy.

WiFi users' passwords do not comply with this policy.

Maximum Consecutive Characters from User Name

Indicates the number of consecutive characters from a user name that cannot be contained in a password. Note that characters from a user name are case-insensitive in a password. The default value is 5. The value 0 indicates that the system does not check for consecutive characters.

For example, if a user name is userA123 and this parameter is set to 3, a password cannot contain three or more consecutive characters from userA123. That is, passwords, such as use5678, ser5678, and erA5678, cannot be used.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) must comply with this policy.

WiFi users' passwords do not comply with this policy.
