Add User Plane Peer to End Point Group (ADD UPPEER2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a user-plane peer to an end point group.

Note

  • Before adding a user plane peer to an endpoint group, ensure that the endpoint group added by using the ADD EPGROUP command and the user plane peer added by using the ADD USERPLANEPEER command have been configured.

  • If there are user plane hosts with the same local IPv4 address configured in different endpoint groups, the same user plane peer with the IPv4 address is only allowed to be configured in one of these endpoint groups.

  • If this command is executed, a base station will automatically set up a user-plane link with Path Type set to ANY(Any QoS).

  • If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects for the IPv4 user-plane link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEHOST object in the same end point group and the USERPLANEPEER object.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects for the IPv4 user-plane link and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEHOST object in the same end point group and the USERPLANEPEER object.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch is set to DISABLE(Disable) for the USERPLANEHOST object in the same end point group and the USERPLANEPEER object, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • If this command is used to add a user-plane peer that is automatically created by the system to an endpoint group, the addition takes effect only after the base station is reset.

  • [Co-MPT,eNodeB,gNodeB]If there are user plane hosts with the same local IPv6 address configured in different endpoint groups, the same user plane peer with the IPv6 address is only allowed to be configured in one of these endpoint groups.

  • [NodeB]User-plane paths are established when this command is executed to add a user plane peer to an endpoint group if the following conditions are met: (1) The endpoint group is referenced by an IUB MO. (2) The user plane host exists in the endpoint group. A maximum of 64 user-plane paths can be configured on a WMPT/UTRP (subboard type: UEOC/UIEC/UQEC).

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
UPPEERID User Plane Peer ID

Meaning: Indicates the ID of the user-plane peer.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a user-plane peer to an end point group with the parameters as follows: End Point Group ID: 0, User Plane Peer ID: 0, run the following command:
ADD UPPEER2EPGRP: EPGROUPID=0, UPPEERID=0;
