Calibrate ALD (CLB ALD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to calibrate an antenna. The calibration is to ensure that the tilt angle of every RET unit, horizontal azimuth of every RAS unit, or vertical beamwidth of every RVD are configured correctly and consistent with the parameter settings.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During the calibration, do not perform any other operations on the ALD.

  • After an ALD is installed, run this command to calibrate an ALD if ALM-26753 RET Antenna Not Calibrated is reported.

  • After calibration, the vertical beamwidth, the tilt or the azimuth is adjusted automatically according to the configured value. It takes less than 8 minutes to calibrate a single subunit.

  • During calibration, the antenna tilt of an RET antenna, the vertical beamwidth of an RVD or the azimuth of an RAS antenna will be adjusted, affecting the network coverage.

  • If an unavailable RPCU exists on the base station, the execution of this command fails.

Example

To calibrate ALD with the parameters as follows: Device Type: RVD, Operate Mode: SITE, run the following command:
CLB ALD: CLBDEVICETYPE=RVD, OPMODE=SITE;

Device No.

Indicates the device number of the ALD. The device number of the ALD must be unique.

Subunit No.

Indicates the number of the subunit, which starts from 1.

Indicates the returned result value after the maintenance command is executed.
