List MLPPP Link Configuration (LST MPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configurations of the MLPPP links in an MLPPP group.

Note

None.

Parameters

None.

Example

To list the configuration of the PPP links in the MLPPP group, run the following command:
LST MPLNK:
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the MLPPP link is located.

Subrack No.

Indicates the number of the subrack where the MLPPP link is located.

Slot No.

Indicates the number of the slot where the MLPPP link is located.

Subboard Type

Indicates the type of sub-board where an MLPPP link is established.

Link No.

Indicates the number of the MLPPP link.

MLPPP Group Subboard Type

Indicates the type of sub-board where an MLPPP group is established.

MLPPP Group No.

Indicates the number of the MLPPP group.

E1/T1 Subrack No.

Indicates the number of the subrack housing the board where the E1/T1 port carrying the MLPPP link is located.

E1/T1 Slot No.

Indicates the number of slot holding the board where the E1/T1 port carrying the MLPPP link is located.

E1/T1 Subboard Type

Indicates the type of sub-board on the board where the E1/T1 port carrying the MLPPP link is located.

E1/T1 Port No.

Indicates the number of the E1/T1 port carrying the MLPPP link.

Timeslot No.

Indicates the number of the E1/T1 slot carrying the MLPPP link.

Maximum Receive Unit(byte)

Indicates the Maximum Receive Unit (MRU). The received packet whose length is greater than this parameter value is discarded.

Protocol Field Compression

Indicates whether to enable protocol field compression.

Address and Control Field Compression

Indicates whether to enable the compression of the address field and control field.

Negotiation Time(ms)

Indicates the timeout duration of the MLPPP link negotiation.
