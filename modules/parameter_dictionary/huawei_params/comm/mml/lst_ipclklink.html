List IP Clock Link (LST IPCLKLINK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of all the IP clock links.

Note

None.

Parameters

None.

Example

To list the IP clock configuration, run the following command:
LST IPCLKLINK:;
The result is shown as follows:

Output Description

Field Description

Link No.

Indicates the number of the IP clock link.

Protocol Type

Indicates the type of the IP clock protocol, which can be PTP or Huawei proprietary protocol. PTP includes IEEE1588 V2, G.8265.1, 1588V2_16.1, G.8275.1 and G.8275.2. IEEE1588 V2, defined by the IEEE, supports both time synchronization and frequency synchronization. G.8265.1 supports frequency synchronization only. 1588 V2_16.1 supports both time synchronization and frequency synchronization. G.8275.1 supports time synchronization only. G.8275.2 supports time synchronization only. Huawei proprietary protocol, which is the Huawei-defined IP clock protocol, applies to the interconnection between Huawei equipment and supports frequency synchronization only.

Device Type

Indicates the device type of the IP clock. The value of this parameter can be OC_SLAVE or OC_MASTER. In OC_SLAVE mode, the NE serves as the clock equipment that is synchronized with the upstream clock. In OC_MASTER mode, the NE works as a master clock device to provide IP clock signals, and you need to configure an external reference clock source for supplying reference clock signals.

Cabinet No.

Indicates the number of the cabinet where the IP clock link is configured.

Subrack No.

Indicates the number of the subrack where the IP clock link is configured.

Slot No.

Indicates the number of the slot where the IP clock link is configured.

Clock Net Mode

Indicates the networking type for the IP clock. The LTE and NR currently do not support L3 Multicast function.

Profile Type

Indicates the type of protocol supported by the IEEE 1588 V2-compliant IP clock link, which can be ITU-T G.8265.1, IEEE 1588 V2, IEEE1588V2_16.1, ITU-T G.8275.1 or ITU-T G.8275.2. ITU-T G.8265.1 is defined by the International Telecommunication Union (ITU) for frequency synchronization of an IEEE 1588 V2-compliant IP clock link with the networking type of UNICAST. An IP clock link in compliant with ITU-T G.8265.1 supports interconnection with servers from other vendors. An IP clock link in compliant with IEEE 1588 V2 supports interconnection with clock service devices from other vendors only in L2 or L3 multicast networking. IEEE1588V2_16.1 can also be used for interconnection with clock service devices from other vendors when the other vendors do not support ITU-T G.8265.1.The content of IEEE1588V2_16.1 refer to the optional section 16.1 of IEEE1588V2 protocol. ITU-T G.8275.1 is defined by the International Telecommunication Union (ITU) for time synchronization of an IEEE 1588 V2-compliant IP clock link with the networking type of L2 multicast. An IP clock link in compliant with ITU-T G.8275.1 supports interconnection with clock service devices from other vendors. ITU-T G.8275.2 is defined by the International Telecommunication Union (ITU) for time synchronization of an IEEE 1588 V2-compliant IP clock link with the networking type of L3 unicast. An IP clock link in compliant with ITU-T G.8275.2 supports interconnection with clock service devices from other vendors.

IP mode

Indicates the mode of the IP address.

Client IPv4

Indicates the client IPv4 address of the IP clock link.

Server IPv4

Indicates the server IPv4 address of the IP clock link.

Client IPv6

Indicates the client IPv6 address of the IP clock link. The UMTS currently does not support this function.

Server IPv6

Indicates the server IPv6 address of the IP clock link. The UMTS currently does not support this function.

Domain

Indicates the domain to which the IP clock link belongs. The setting of this parameter must be the same as the setting of the clock server.

Phase Deviation Report Switch

Indicates whether the base station reports information required for automatic compensation for IP clock link asymmetry to the transmission equipment. The bearer network automatically performs the compensation. If this parameter is set to ON, the base station reports the following information to the transmission equipment: phase offset of the 1588 clock relative to the GPS, whether the base station has the GPS, whether the GPS is available, and protocol-defined information such as the 1588 Clock ID. If this parameter is set to OFF, the base station does not report such information.

Compensation(ns)

Indicates the compensation for asymmetry of IP clock links.

Delay Type

Indicates the compensation mechanism for the transmission delay between the clock server and the NE. The E2E mode uses the Delay-Request-Response mechanism to measure the average delay between the primary and secondary devices. The P2P mode uses the Peer-Delay mechanism to measure the average delay between two devices.

Priority

Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.

Announce Freq(Hz)

Indicates the frequency at which the clock source sends announcement packets based on its negotiation with the NE.

Sync Freq(Hz)

Indicates the frequency at which the clock source sends synchronization packets based on its negotiation with the NE.

Delay Freq(Hz)

Indicates the frequency at which the clock source sends delay packets based on its negotiation with the NE.

Master Priority

Indicates the priority of the IP clock server. The value 0 indicates the highest priority, and the value 255 indicates the lowest priority. If two IP clock servers are required, the value of this parameter is used to identify the active and standby IP clock servers. The IP clock server with a higher priority serves as the active server and the IP clock server with a lower priority serves as the standby server.

Negotiate Duration(s)

Indicates the interval at which negotiations are performed between the NE and IP clock server. After the interval elapses, the NE initiates another negotiation with the IP clock server.

Clock Source Specified or Not

Indicates whether the clock source is specified.

Clock Source MAC Address

Indicates the MAC address of the clock source for the IP clock server. The MAC address must be in the format of XXXX-XXXX-XXXX.

Pre-Hop IPv4

Indicates the pre-hop IPv4 address of an IP clock.

PDelay Request Freq(Hz)

Indicates the frequency at which PDelay Request packets are sent on an IP clock link.

Destination Multicast MAC Address Type

Indicates the type of the destination multicast MAC address to which an NE sends G.8275.1 clock synchronization packets. Forwardable Multicast MAC Address (FMAC) means that the destination MAC address to which the NE sends clock synchronization packets is 01-1B-19-00-00-00. Non-Forwardable Multicast MAC Address (NFMAC) means that the destination MAC address to which the NE sends clock synchronization packets is 01-80-C2-00-00-0E. The NE can handle clock synchronization packets from both FMAC and NFMAC.

Clock Server Description

Indicates the description of the clock server at the peer end of the clock link.

IP Clock Sync Mode

Indicates the IP clock synchronization mode. This parameter is applicable only when Clock Synchronization Mode is set to HYBRID.

VRF Index

Indicates the index of a virtual routing domain.
