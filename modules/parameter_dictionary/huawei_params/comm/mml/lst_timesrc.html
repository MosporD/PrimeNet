List Time Source Setting (LST TIMESRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the type of the configured time sources and autoswitch.

Note

When the configured time source is unavailable, the BS dynamically switches to an available one. When this occurs, the current time source(DSP TIMESRC) is different from the configured one(LST TIMESRC).

Parameters

None.

Example

To list the current time source, run the following command:
LST TIMESRC:;
The result is shown as follows:
+++    0        2018-12-21 14:28:24
O&M    #3592
%%LST TIMESRC:;%%
RETCODE = 0  Operation succeeded.

Time Source Information
-----------------------
     Time Source  =  NTP
Automatic Switch  =  On
(Number of results = 1)


---    END

Output Description

Field Description

Time Source

Indicates the external reference time source of the NE.

Automatic Switch

Indicates whether to enable automatic time source switchover. When the switch is turned on, the system switches over the time source when time synchronization fails. When the switch is turned off, the system does not switch over the time source.
