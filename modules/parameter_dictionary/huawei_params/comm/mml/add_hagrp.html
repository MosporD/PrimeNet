Add Transport HA Group (ADD HAGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a high availability (HA) group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Adding an HA group fails if the existing data is not configured on the logical slot.

  • Before adding an HA group, ensure that the Ethernet port attributes of the active board and the standby board are set to electrical port or optical port.

  • Before running this command, ensure that the two boards are of the same physical type.

  • The HA group adopts the cold backup scheme. That is, adding an HA group will result in the reset of the BS; the active and standby boards of the HA group are determined after the BS restarts. Due to hardware limitation, a UMDU cannot implement the cold backup of main control and transmission after the UMDU is configured with an HAGRP MO and then resets.

  • After an HA group is added, the BS works in active/standby mode. In this situation, the Ethernet ports for local maintenance and those for services on the active and standby boards must all be connected to a switch or router. Otherwise, the maintenance terminal fails to access the BS through the Ethernet port for local maintenance or that for services after a switchover.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT is the main control board, a maximum of 1 HA groups can be configured.

  • Board specifications: A maximum of 1 HA groups can be configured on a WMPT/UMPT/UMDU/LMPT.

  • In HAGRP scenarios, the board in a non-logical slot automatically creates an ETHPORT MO. You need to remove this MO before adding the board to a high availability group. The default transmission resource group (with Transmission Resource Group ID set to AUTOPORT) related to this port will be automatically removed. After removing an HAGRP MO from a board, you need to create the ETHPORT MO. The default transmission resource group (with Transmission Resource Group ID set to AUTOPORT) related to this port will be automatically added.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet housing the board where the HA group is established.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the number of the subrack housing the board where the HA group is established.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Logic Slot No.

Meaning: Indicates the logical slot number of the HA group. The logical slot number of an HA group is the number of the physical slot housing one of the two boards constituting the HA group.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: 6

Recommended Value: 6

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add an HA group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Logic Slot No.: 6, run the following command:
ADD HAGRP: CN=0, SRN=0, SN=6;
