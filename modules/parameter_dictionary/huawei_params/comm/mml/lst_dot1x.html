List IEEE 802.1X Authentication (LST DOT1X)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of 802.1X.

Note

None.

Parameters

None.

Example

To list the configuration of 802.1x, run the following command: 
LST DOT1X:;
The result is shown as follows:
+++    0        2011-12-17 10:23:06
O&M    #353
%%LST DOT1X:;%%
RETCODE = 0  Operation succeeded.

List 802.1x
-----------
Cabinet No.  Subrack No.  Slot No.  Subboard Type  Port No.  Authentic Method        

0            0            6         Base Board     0         EAP-TLS authentic method
0            0            6         Base Board     1         EAP-TLS authentic method
(Number of results = 2)


---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that provides the port on which IEEE 802.1X authentication is configured.

Subrack No.

Indicates the number of the subrack that provides the port on which IEEE 802.1X authentication is configured.

Slot No.

Indicates the number of the slot that provides the port on which IEEE 802.1X authentication is configured.

Subboard Type

Indicates the type of sub-board that provides the port on which IEEE 802.1X authentication is configured.

Port No.

Indicates the number of the port on which IEEE 802.1X authentication is configured.

Authentic Method

Indicates the IEEE 802.1X authentication method. Currently, only Extensible Authentication Protocol Transport Layer Security (EAP-TLS), a unidirectional authentication method, is supported.
