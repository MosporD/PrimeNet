Set IPSec Bypass (SET IPSECBYPASS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the parameters related to IPSec bypass so that a base station can switch between the IPSec network and the non-security network.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • In IPSec networking, running this command may interrupt ongoing services on a BS.

  • Before running this command, ensure that IPSec Bypass Switch has been set to ENABLE(Enable) using the SET IPSECBYPASSCFG command and the value of IPSec Bypass Check Code is consistent with that of IPSec Bypass Code set in the SET IPSECBYPASSCFG command.

  • [Co-MPT,eNodeB,gNodeB]This function is not supported in IPv6 IPsec networking.

  • [Co-MPT]The GTMUb/GTMUc does not support this command.

  • [NodeB]The WMPT does not support this command.

Parameters

ID Name Description
ACTION IPSec Bypass Action

Meaning: Indicates the switchover of IPSec Bypass. If this parameter is set to BYPASS2IPSEC, the base station can switch from a non-IPSec network to an IPSec network. If this parameter is set to IPSEC2BYPASS, the base station can switch from an IPSec network to a non-IPSec network.

GUI Value Range: BYPASS2IPSEC, IPSEC2BYPASS

Unit: None

Actual Value Range: BYPASS2IPSEC, IPSEC2BYPASS

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CFM IPSec Bypass Check Code

Meaning: Indicates the check code for switching IPSec Bypass.

GUI Value Range: 1~19 characters

Unit: None

Actual Value Range: 1~19 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when ACTION is set to IPSEC2BYPASS.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set IPSec Bypass status with the parameters as follows: IPSec Bypass Action: "IPSEC2BYPASS", IPSec Bypass Check Code: "******", run the following command:
SET IPSECBYPASS: ACTION=IPSEC2BYPASS, CFM="******";
