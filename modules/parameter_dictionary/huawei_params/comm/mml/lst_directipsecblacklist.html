List Blacklist for Direct IPsec Tunnel (LST DIRECTIPSECBLACKLIST)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list direct IPsec blacklist.

Note

None.

Parameters

ID Name Description
DIRECTIPSECBLACKLISTID ID of Blacklist for Direct IPsec Tunnel

Meaning: Indicates the ID of a direct IPsec blacklist.

GUI Value Range: 0~383

Unit: None

Actual Value Range: 0~383

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To list the configurations of the blacklist for direct IPSec tunnels, run the following command:
LST DIRECTIPSECBLACKLIST:;
The result is as follows:
+++    0        2019-09-23 09:28:55
O&M    #71
%%LST DIRECTIPSECBLACKLIST:;%%
RETCODE = 0  Operation succeeded.

List Blacklist for Direct IPsec Tunnel
--------------------------------------
ID of Blacklist for Direct IPsec Tunnel  =  0
                             IP Version  =  IPv4
             Security Peer IPv4 Address  =  192.168.1.1
             Security Peer IPv6 Address  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

ID of Blacklist for Direct IPsec Tunnel

Indicates the ID of a direct IPsec blacklist.

IP Version

Indicates the IP version of a direct IPsec blacklist.

Security Peer IPv4 Address

Indicates the security peer IP address of a direct IPsec blacklist. This address must be a valid IP address of class A, B, or C.

Security Peer IPv6 Address

Indicates the security peer IPv6 address of a direct IPsec blacklist. This IPv6 address must be set to a globally scoped unicast address.
