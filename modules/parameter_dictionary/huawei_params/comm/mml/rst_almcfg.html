Reset Alarm Configuration (RST ALMCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to initialize the settings of parameters related to the alarm severity, alarm shield flag, duration-based alarm filtering rule, and times-based alarm filtering rule for a specified alarm (indicated by the alarm ID).

Note

  • The settings of the alarm severity and alarm shield flag to be initialized can be queried by running the LST ALMCFG command.

  • The settings of the duration-based alarm filtering rule and times-based alarm filtering rule to be initialized can be queried by running the LST ALMFILTER command.

Parameters

ID Name Description
AID Alarm ID

Meaning: Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To initialize the configuration with the parameter as follows: Alarm ID: 26812, run the following command:
RST ALMCFG: AID=26812;
