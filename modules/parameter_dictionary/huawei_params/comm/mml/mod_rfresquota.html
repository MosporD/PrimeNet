Modify RF Resource Quota (MOD RFRESQUOTA)

Network Element: BTS3900, BTS5900

Function

Use this command to modify an RF resource quota. Each client NE can correspond to multiple quotas.

Note

None.

Example

Example 1: To modify RF resource quota with the parameters as follows: RF Resource Quota ID: 0, RRU Scope: "ALL", run the following command: 
MOD RFRESQUOTA: RFRESQUOTAID=0, SCOPE=ALL;
Example 2: To modify RF resource quota with the parameters as follows: RF Resource Quota ID: 0, RRU Scope: "SPECIFIC_RU", Operational Mode: "ADD", Number of RRUs: 1, Cabinet No. of RRU 1: 0, Subrack No. of RRU 1: 70, Slot No. of RRU 1: 0, run the following command:
MOD RFRESQUOTA: RFRESQUOTAID=0, SCOPE=SPECIFIC_RU, OPMODE=ADD, RRUNUM=1, RRU1CN=0, RRU1SRN=70, RRU1SN=0;
