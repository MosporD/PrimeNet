Display Switchover Logs (DSP SWAPLOG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the recent swap records.

Note

  • A maximum of ten swap records can be queried.

  • In the current version, only the swap records of the MPT can be queried. CN and SRN are set to the cabinet No. and subrack No. of the MPT, respectively, and SN is set to 6.

  • The BLADEBBU does not support this command.

Example

To query the swap records, run the following command:
DSP SWAPLOG:;
The result is shown as follows:

Output Description

Field Description

Swap Time

Indicates the time when the Switchover starts.

Swap Type

Indicates the swap type. There are two swap types specified by the values Manually and Fault. Manually indicates that the swap is delivered by an MML command. In other cases, the swap type is Fault.

Swap Reason

Indicates the switchover reason, which can be specified by the value specified by the values Hardware Failure, Clock Failure, Transmission Failure, Communication Failure, Manually, Configuration Failure, or Other Failure.

Swap Result

Indicates the Switchover result.
