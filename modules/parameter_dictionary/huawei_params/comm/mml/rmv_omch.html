Remove OM Channel (RMV OMCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a remote maintenance channel.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The remote maintenance channel will be disconnected if a currently used remote maintenance channel is removed. Use this command with caution.

  • When a working remote maintenance channel is removed, the other channel does not take over services immediately. A switchover between the two channels is triggered only upon the instruction from the MAE.

Parameters

ID Name Description
FLAG Standby Status

Meaning: Indicates the master/slave flag of the remote maintenance channel.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an OMCH MO, if CHECKTYPE is set to AUTO_UDPSESSION, FLAG must be set to MASTER.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove the remote maintenance channel whose Standby Status: "MASTER", run the following 
RMV OMCH: FLAG=MASTER;
