List Tree Link PVC Configuration (LST TREELNKPVC)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list configurations of all treelink PVCs.

Note

None.

Parameters

None.

Example

To list configurations of a networking PVC, run the following command:
LST TREELNKPVC:;
The result is shown as follows:

Output Description

Field Description

Tree Link PVC No.

Indicates the treelink PVC number.

Join Transmission Resource Group

Indicates whether the treelink PVC joins a transmission resource group.

Tree Link PVC Switch Type

Indicates the switching type of a treelink PVC, which is classified into VC_SWITCH and VP_SWITCH.

Cabinet No.

Indicates the number of the cabinet where the board is located.

Source Subrack No.

Indicates the subrack number of the source port for the treelink PVC.

Source Slot No.

Indicates the slot number of the source port for the treelink PVC.

Source Subboard Type

Indicates the subboard type of the board providing the source port for the treelink PVC.

Source Port Type

Indicates the type of the source port for the treelink PVC.

Source Port No.

Indicates the number of the source port for the treelink PVC.

Source Transmission Resource Group ID

Indicates the number of the transmission resource group to which the source port for the treelink PVC belongs.

Source Port VPI

Indicates the virtual path identifier (VPI) of the source port for the treelink PVC.

Source Port VCI

Indicates the virtual channel identifier (VCI) of the source port for the treelink PVC.

Destination Subrack No.

Indicates the subrack number of the destination port for the treelink PVC.

Destination Slot No.

Indicates the slot number of the source port for the treelink PVC.

Destination Subboard Type

Indicates the subboard type of the board providing the destination port for the treelink PVC.

Destination Port Type

Indicates the type of the destination port for the treelink PVC.

Destination Port No.

Indicates the number of the destination port for the treelink PVC.

Destination Transmission Resource Group ID

Indicates the number of the transmission resource group to which the destination port for the treelink PVC belongs.

Destination Port VPI

Indicates the virtual path identifier (VPI) of the destination port for the treelink PVC.

Destination Port VCI

Indicates the virtual channel identifier (VCI) of the destination port for the treelink PVC.

Rate Unit

Indicates the rate unit of the peak cell rate (PCR), minimum cell rate (MCR), and sustainable cell rate (SCR). 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted into 30 kbit/s.

Bearer Service Type

In terms of flow control, services are classified into four categories: the Real-Time Variable Bit Rate (RTVBR) service, Non-Real-Time Variable Bit Rate (NRTVBR) service, Unspecified Bit Rate Plus (UBR+) service, and Unspecified Bit Rate (UBR) service.

Peak Cell Rate

Indicates the peak rate of transmitting cells on an ATM connection, such as a VPC or VCC.

Sustain Cell Rate

Indicates the average cell rate that is measured in a certain period of time.

Min Cell Rate

Indicates the rate of transmitting cells on an ATM connection while ensuring the transmission quality.

Max Burst Size(cell)

Indicates the maximum number of cells transmitted at the PCR.

Cell Delay Variation Tolerance(0.1microsecond)

Indicates the time delay for transmitting a cell burst from the source port to the destination port.

Description

Indicates the description of the treelink PVC.
