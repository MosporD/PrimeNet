Set OM Connection Security Policy (SET OMCONNPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the security policy of OM connections.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Under the IPv4 networking, After the OM connection security policy is changed, the NE may disconnect from the network management system (NMS). In this case, the NMS needs to initiate a connection to the NE.

  • Setting Enable Access to NE Using Maintenance IP Addresses Only to ENABLE in IPv4 networking, ensure that the OM channel is correctly configured and the MAE can use the maintenance IP address to access the NE. If the OM channel is not configured, the MAE can use a non-maintenance IP address to access the NE. If the OM channel is configured but the configuration is incorrect, the OM channel is disconnected. It is recommended that the CFM CB command be executed to enable configuration data rollback.

  • [Co-MPT,eNodeB,gNodeB]In IPv6 networking with an IPv6 OM channel configured, the configured value of the Enable Access to NE Using Maintenance IP Addresses Only parameter is invalid and the function of allowing only the access using the maintenance IP access is enabled.

Parameters

ID Name Description
ONLYOMIP Enable Access to NE Using Maintenance IP Addresses Only

Meaning: Indicates whether to enable only the maintenance of IP (OMCH IP and local IP) access to the network is enabled under the IPV4 group network. This parameter does not take effect when OMCH IP is not configured. It is recommended to enable only the maintenance of IP access elements, or there may be security risks. When an IPv6 OM channel configured, the configured value of the Enable Access to NE Using Maintenance IP Addresses Only parameter is invalid and the function of allowing only the access using the maintenance IP access is enabled.

GUI Value Range: DISABLE(DISABLE), ENABLE(ENABLE)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Run the following command to set Connection Security Policy to NE access by using maintenance IP addresses only:
SET OMCONNPOLICY: ONLYOMIP=ENABLE;
