Add RCS Client (ADD RCSCLIENT)

Network Element: BTS3900, BTS5900

Function

Use this command to add an RCS client and to add the local NE ports that are connected to the RCS client. The RCS client uses the shared external RRU resources provided by the local NE.

Note

None.

Parameters

Meaning: Indicates the ID of an RCS client.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
RCSCLIENTNAME RCS Client Name

Meaning: Indicates the name of an RCS client. When a DCU functions as an RCS server and a BBU functions as an RCS client, this parameter must be set to the NE name of the BBU.

Unit: None

MML Default Value: None

Example

To add an RCS client with the parameters as follows: RCS Client No.: 0, RCS Client Name: "Rcstest", Number of RCS Connection Ports No.: 1, ID of Connection Port 1 No.: 1, run the following command: 
ADD RCSCLIENT: RCSCLIENTNO=0, RCSCLIENTNAME="RCStest", CONNPORTNUM=1, CONNPORT1ID=1;
