Set SSL Configuration (SET SSLCONF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set configurations of the SSL.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If Renegotiation Interval is set to 0, the NE has no limit on the frequency and number of renegotiation requests from the peer end.

  • Reducing the lowest level of cipher suites may increase system security risks. Set this parameter to a proper value.

  • Before changing the lowest level of cipher suites to a higher level, check whether the SSL certificate is correctly configured for the base station. If the SSL certificate is incorrectly configured, the maintenance channel may be interrupted when the lowest level of cipher suites is changed to a higher level.

  • Before modifying the value of TLS/SSL Version, ensure that the MAE supports the new TLS/SSL version. If the MAE does not support the new TLS/SSL version, modifying the value may interrupt the maintenance channel.

  • When setting the TLS/SSL version, you are advised to use TLS1.2/TLS1.3 for SSL connection. SSL3.0, TLS1.0 and TLS1.1 are reserved to be compatible with the MAE of earlier versions.

  • Before referencing a TLS configuration policy, ensure that the TLS configuration policy exists.

VERSION TLS/SSL Version

Meaning: Indicates the TLS or SSL version supported by the NE.TLS(Transport Layer Security). The TLS1.2 and TLS1.3 version are enabled eternally in the system, and therefore they cannot be disabled currently. You are not advised to use SSL3.0, TLS1.0 and TLS1.1 because they have security risks.

Disuse statement: In the later versions, the value SSLV3(SSL3.0) and TLSV10(TLS1.0) will be removed from the value range of this parameter. In the current version, the value can still be configured, but the value SSLV3(SSL3.0) can not take effect, the value TLSV10(TLS1.0) can take effect. Therefore, you are not advised to use the value SSLV3(SSL3.0) and TLSV10(TLS1.0).

GUI Value Range: SSLV3(SSL3.0), TLSV10(TLS1.0), TLSV11(TLS1.1), TLSV12(TLS1.2), TLSV13(TLS1.3)

Unit: None

Actual Value Range: SSLV3, TLSV10, TLSV11, TLSV12, TLSV13

MML Default Value: None

Recommended Value: TLSV12(TLS1.2),TLSV13(TLS1.3)

Example

Example 1: To enable SSL renegotiations with an interval of 60s, run the following command:
SET SSLCONF: RENEGO=ENABLE, RENEGOINTERVAL=60;

Example 2: To disable SSL renegotiations, run the following command:
SET SSLCONF: RENEGO=DISABLE;

Example 3: To set the SSL version of the NE, run the following command:
SET SSLCONF: VERSION=SSLV3-0&TLSV10-0&TLSV11-1&TLSV12-1&TLSV13-1;

Example 4: To set the lowest SSL encryption level to low, run the following command:
SET SSLCONF: LOWESTCSLEVEL=LOW;
