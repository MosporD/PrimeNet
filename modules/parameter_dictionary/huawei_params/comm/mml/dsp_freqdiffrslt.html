Display the Reference Clock Excessive Frequency Deviation Check Result (DSP FREQDIFFRSLT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the result of a reference clock excessive frequency deviation check.

Note

  • The reference clock excessive frequency deviation check takes about 15 minutes and after the check is finished, you need to run this command to query the result.

  • This command queries the result of the latest reference clock excessive frequency deviation check. If the current reference clock is changed, the displayed result is incorrect. You are advised to start a reference clock excessive frequency deviation check again.

  • If the reference clock is deleted, lost, or changed during the reference clock excessive frequency deviation check, this command returns failure.

Example

To display the reference clock excessive frequency deviation check result with the parameters as follows: Slot No.: 6, run the following command:
DSP FREQDIFFRSLT: SN=6;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Start Time of the Excessive Frequency Deviation Check

Indicates the start time of the reference clock excessive frequency deviation check.

The Reason of Excessive Frequency Deviation

Indicates the reason of clock reference excessive frequency deviation, which can be OCXO/DAC Fault, Reference Clock Source Fault or Unknown Fault.
