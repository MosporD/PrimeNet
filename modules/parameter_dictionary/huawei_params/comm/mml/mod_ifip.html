Modify Interface IP Address (MOD IFIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an interface IP address.

Note

Only the value of the User Label parameter can be changed by running this command.

Meaning: Indicates the cabinet number of the board where the port is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Interface ID parameter in the IPADDR4 MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

-Configuration constraints:

  • [gNodeB]The value of PT in an IFIP MO cannot be set to PPP.
  • [gNodeB]The value of PT in an IFIP MO cannot be set to ETHCI.

  • In the IFIP MO, if SBT is set to E1_COVERBOARD, this parameter can be set to PPP or MPGRP.
  • In the IFIP MO, if SBT is set to ETH_COVERBOARD, this parameter can be set to ETH or ETHTRK.

Example

To modify an interface IP address with the parameters as follows: Slot No.: 6, Subboard Type: Base Board, Port Type: ETH, Port No.: 0, IP Address: 192.168.2.24, User Label: Modify IFIP, run the following command:
MOD IFIP: SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, IP="192.168.2.24", USERLABEL="Modify IFIP";
