Add RET (ADD RET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a remote electrical tilting (RET) unit. The subunits and device data are also added at the same time.

Note

  • Only an RET unit supporting the AISG1.1, AISG2.0 or 3GPP TS 25.466 protocol needs to be configured.

  • An RET unit is available only when the ALD current alarm threshold is set and the ALD power switch is turned on. For details about how to query the port status, see the DSP ANTENNAPORT and DSP RETPORT commands. For details about how to modify the port status, see the MOD ANTENNAPORT and MOD RETPORT commands.

  • In regular scenarios, the vendor code and serial number of the device can be left blank when the RET unit is added. They are automatically obtained after the scan. In other scenarios, the vendor code and the serial number of the device must be specified. Otherwise, the system cannot communicate with the ALD properly.

  • If the vendor code and serial number of the device need to be specified, ensure that neither of them is left blank. If one of them is left blank, the command execution fails. To query the vendor code and the serial number of the device, run the SCN ALD command. To modify the vendor code and the serial number of the device, run the MOD RET command.

  • If a combiner is used or RRUs are interconnected, all the ALD devices must be controlled by the same RF.

  • About the cabinet number, subrack number, and slot number of the control port: In regular scenarios, the RF module that physically connects to the ALD controls the ALD. In other scenarios, you must ensure the consistency between the configured port (with the cabinet number, subrack number, and slot number of the control port) and the physically connected RET control port on the RRU or RFU. Otherwise, the system cannot identify the communication link between the RET antenna and the main control board correctly.

  • The device name is optional, but the device name configured for each ALD must be unique.

  • The maximum number of RET subunits that can be configured for an RET antenna varies depending on the RET antenna type. A maximum of twelve RET subunits can be configured for an RET antenna of the MULTI_RET type. The number of RET subunits for an RET antenna of the SINGLE_RET type is 1 by default and therefore does not need to be specified.

  • The antenna scenario must be set based on the hardware installation.

  • The RRU or RFU specified by the Control Port Cabinet No., Control Port Subrack No., and Control Port Slot No. of the RET unit must have been configured.

  • Adding the first device in a manual scanning process will terminate the current scan.

  • The RET antenna cannot work properly if the antenna type is incorrectly configured.

DEVICENAME Device Name

Meaning: Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

Example

To add an RET antenna with the parameters as follows: Device No.: 0, Device Name: PEOPLESQUARE_SEC1_RET_01, Control Port Cabinet No.: 0, Control Port Subrack No.: 63, Control Port Slot No.: 0, RET Type: SINGLE_RET, Polar type: SINGLE, and Antenna Scenario: REGULAR, run the following command:
ADD RET: DEVICENO=0, DEVICENAME="PEOPLESQUARE_SEC1_RET_01", CTRLCN=0, CTRLSRN=63, CTRLSN=0, RETTYPE=SINGLE_RET, POLARTYPE=SINGLE, SCENARIO=REGULAR;
