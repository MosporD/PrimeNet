Add IPv6 Address (ADD IPADDR6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IPv6 address.

Note

  • [Co-MPT,eNodeB,gNodeB]An IPv6 interface can be configured with a maximum of eight IPv6 addresses.

  • [Co-MPT,eNodeB,gNodeB]System specifications: If the UMPT/UMDU is the main control board, a maximum of 64 IPv6 addresses can be configured.

  • [Co-MPT,eNodeB,gNodeB]Board specifications: A maximum of 64 IPv6 addresses can be configured on a UMPT/UMDU.

  • [Co-MPT,eNodeB,gNodeB]Except the IPv6 address configured on the loopback interface, after an IPv6 address is added, the system performs duplicate address detection (DAD) and the new IPv6 address does not take effect immediately. The address conflict detection process takes 1 to 3 seconds. If no conflict is detected, the new IPv6 address takes effect.

  • [Co-MPT,eNodeB,gNodeB]When an IPv6 address is configured, an error message may be displayed, indicating that an existing IPv6 address conflicts with the configured IPv6 address. In this case, you can run the LST IPADDR6, DSP IPADDR6, LST OMCH, DSP OMCH, LST IPROUTE6, or DSP IPROUTE6 command to query the conflicting IPv6 address (IPv6 address, local IPv6 address of the OM channel, or next-hop IPv6 address of the IPv6 route). Then manually eliminate the conflict.

  • [Co-MPT,eNodeB,gNodeB]An IPv6 address must be a globally scoped unicast address (such as 2001:DB8:1100::1).

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]When the IPADDR6 MO is added, the value of IPADDR6ID is case insensitive but is case sensitive when being referenced by other MOs.
  • [Co-MPT, eNodeB, gNodeB]The value of IPADDR6ID in the IPADDR6 MO cannot be prefixed with SON_, _SON, AUTO_, or _AUTO.

Example

To add an IPv6 address with the parameters as follows: IPv6 Address ID: 0, Interface ID: 0, IPv6 Address: 2001:DB8::1, Prefix Length: 32, run the following command:
ADD IPADDR6: IPADDR6ID="0", ITFID=0, IPV6="2001:DB8::1", PFXLEN=32;
