Start Antenna Quality Test (STR ANTTEST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to start an antenna quality test for an active antenna-radio unit (AARU), a radio unit (RU) in the AAU that supports this test, or a radio phase calibration unit (RPCU).

Note

For details about which type of AAU supports the antenna quality test, see 3900 Series Base Station Technical Description.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SRN Subrack No.

Meaning: Indicates the subrack number of the board.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SN Slot No.

Meaning: Indicates the slot number of the board. For an AARU, the slot number ranges from 1 to 3. For an RPCU, the value range of the slot number is 0. For an RU, the slot number ranges from 0 to 5.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To start an antenna quality test with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 1, run the following command:
STR ANTTEST: CN=0, SRN=60, SN=1;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board. For an AARU, the slot number ranges from 1 to 3. For an RPCU, the value range of the slot number is 0. For an RU, the slot number ranges from 0 to 5.

Test Result

Indicates the result of an antenna quality test for the AARU, RU or RPCU.
