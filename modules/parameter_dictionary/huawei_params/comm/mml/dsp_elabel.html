Display Electronic Label (DSP ELABEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the electronic label of the specified device. The command output includes the manufacturing information.

Note

  • When used to query the electronic label of a cabinet, this command applies only to the APM30, TMC, BBC, OMB, RFC, BTS3900, BTS3900L, BTS3900AL, BTS5900, BTS5900L, TP48600A, MRE1000, APM5930, ILC29, IFS5906, RFC5906 and virtual cabinets.

  • When used to query the electronic label of a subrack, this command is applicable to the subrack housing the MPT. For other subracks, whether this command is applicable depends on the subrack capability.

  • Before querying the electronic label of a BBU board (including the UPEU and FAN), ensure that this board has been installed and powered on. The electronic label of an FAN board that has not been configured cannot be queried.

  • Before querying the electronic label of a sub-board, ensure that the operational state of the board where the sub-board is attached is Enable.

  • During software loading, querying the electronic label of any electromechanical unit connected to the same serial port fails because of time expiry.

  • The electronic label of a cabinet is stored on the electronic label Unit (ELU). If the TCU, FMU, or CCU connected to the ELU is not configured or unavailable, querying the electronic label fails.

  • To query the electronic label of an LOCALWAP(Local Wireless Access Point), run the command with the parameters as follows: DEVTYPE.: SUBBOARD, Sub Slot No.: 2.

  • The value of Sub Slot No. for the PMI transfer board managed by a PMU is 40. The value of Sub Slot No. for a lithium battery managed by a PMU ranges from 1 to 32. The value of Sub Slot No. for an HVDU managed by a PMU ranges from 50 to 52. The value of Sub Slot No. for an HSMU managed by a PMU ranges from 60 to 62.

  • The values of Sub Slot No. for the eBOX and eBAT in a CCU are same as those of Logical No. in the DSP CCUBATSENSORSTATE command output.

  • The e-label for the satellite card of a CGPS cannot be queried.

  • The type of an SFP port on a BBP is CPRI or HEI. The number of a CPRI port ranges from 0 to 5 (set the port number based on the board hardware capability, the number of a CPRI port on a UBBPem or UBBPf0 is 0 or 1, and the number of a CPRI port on a UBBPf1 or UBBPg4 ranges from 0 to 2). The number of the HEI port is 6 (set the port number based on the board hardware capability, the number of a CPRI port ranges from 0 to 1 on a UBBPem). The type of a UBBPei port is XCI or HEI. The number of an XCI port is 0 or 1. The number of the HEI port is 6. The type of an SFP port on a GTMU is CPRI or FE/GE/XGE/YGE. The number of a CPRI port ranges from 0 to 5. The number of the FE/GE/XGE/YGE port is 1. The type of an SFP port on a BRI is CPRI and the port number ranges from 0 to 5. The type of an SFP port on a UCCU or UCXU is M and the port number ranges from 0 to 5. The type of an SFP port on a UCIU is M or S. The number of an M port ranges from 0 to 4. The number of the S port is 8. The type of an SFP port on a UMDU is CPRI, FE/GE/XGE/YGE, or HEI. The number of a CPRI port ranges from 0 to 5. The number of the FE/GE/XGE/YGE port is 1. The number of an HEI port is 6 or 7. The type of an SFP port on an RRU, RFU, AAS, CGPS, or RPCU is CPRI and the port number is 0 or 1. The type of an SFP port on a TRP is FE/GE/XGE/YGE and the port number is 0 or 1 (set the port number based on the board hardware capability). The type of the SFP port on a WMPT is FE/GE/XGE/YGE and the port number is 1. The type of the SFP port on an LMPT is FE/GE/XGE/YGE and the port number is 0 or 1. The type of an SFP port on a UMPTa or UMPTb is FE/GE/XGE/YGE or CI. The number of the FE/GE/XGE/YGE port is 1. The number of the CI port is 8. The type of an SFP port on a UMPTe, UMPTg or UMPTga is FE/GE/XGE/YGE or CI. The number of an FE/GE/XGE/YGE port is 1 or 3. The number of the CI port is 8. The type of an SFP port on an RMU is CPRI or XCI. The number of a CPRI port ranges from 0 to 11. The number of an XCI port is 0 or 1. The type of an SFP port on an RHUB is CPRI or CPRI_E/CPRI_O. The number of a CPRI port ranges from 0 to 3. The number of a CPRI_E/CPRI_O port is 0 to 15.

  • This command may conflict with periodic electronic label tasks. If a conflict occurs, the system displays the following error message: "The e-label query process included in this operation conflicts with an existing e-label query process. Please try later." In this case, run this command one minute later.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

Sub Slot No.

Indicates the subslot number of the board.

Port Type

Indicates the type of the port.

Port No.

Indicates the port number of the board.

Device No.

Indicates the device number of the ALD. The device number of the ALD must be unique.

Electronic Label

Indicates the electronic label, which is a text file with a maximum of 2 KB used to record the manufacturing information about equipment such as the board, sub-board, and optical module. "BoardType" indicates the type of the board. "BarCode" indicates the bar code of the board and is the same as the code labeled on the board. "Item" indicates the BOM code. "Description" indicates the board description in English. "Manufactured" indicates the manufacturing date of the board. "VendorName" indicates the name of the vendor providing the board. "IssueNumber" indicates the board hardware version. "CLEICode" indicates the common language equipment indicator (CLEI) code of the board. "BOM" indicates the fine-grained item code of the board. "Model" indicates the model displayed on the customer interface, such as Bill of Quotation (BOQ) and paper labels.
