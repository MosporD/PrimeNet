Display User-Plane Path Historical Fault Information (DSP EPUPALMINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the historical fault information about user-plane paths in a user-plane endpoint group.

Note

When the LMPT is used as the main control board, a maximum of 100 records can be queried. When the UMPT/UMDU is used as the main control board, a maximum of 1000 records can be queried.

Parameters

ID Name Description
EPGROUPID End Point Group ID

Meaning: Indicates the ID of the end point group to which an end point belongs.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the historical fault information about user-plane paths in a user-plane endpoint group with the parameters as follows: EPGROUPID: 0, run the following command: 
DSP EPUPALMINFO: EPGROUPID=0;
The result is shown as follows:

Output Description

Field Description

End Point Group ID

Indicates the ID of the end point group to which an end point belongs.

VRF Index

Indicates the index of an IPv4 VRF instance.

IPv6 VRF Index

Indicates the index of an IPv6 VRF instance. This parameter takes effect only in LTE and NR.

Local IP Address

Indicates the IP Address of the user plane host.

Local IPv6 Address

Indicates the IPv6 Address of the user plane host. This parameter takes effect only in LTE and NR.

Peer IP Address

Indicates the IP Address of the user plane peer.

Peer IPv6 Address

Indicates the IPv6 Address of the user plane peer. This parameter takes effect only in LTE and NR.

Fault Generation Time

Indicates the time when a user-plane link becomes faulty.

Fault Recovery Time

Indicates the time when a faulty user-plane path is recovered.
