List Type of Activated Device Certificate (LST CERTTYPE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list all NE-supported application types of device certificates.

Note

[Co-MPT,eGBTS]The device certificate with application type of IKE is not supported for a GTMUc.

Parameters

None.

Example

To list the application type supported by NE, run the following command:
LST CERTTYPE:;
The result is shown as follows:
+++    0        2019-09-24 19:27:07
O&M    #250
%%LST CERTTYPE:;%%
RETCODE = 0  Operation succeeded.

Application Type Supported By NE
--------------------------------
Application Type

IKE             
SSL             
DTLS            
(Number of results = 3)


---    END

Output Description

Field Description

Application Type

Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS. When APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to Appcert, the device certificate being used during IKE negotiation is the certificate configured in the APPCERT object. When APPTYPE is set to SSL, the device certificate being used is the certificate used during SSL connection, 802.1x-based, or inter-BBU interconnection authentication. When APPTYPE is set to DTLS, the device certificate being used is the certificate used during DTLS connection authentication.
