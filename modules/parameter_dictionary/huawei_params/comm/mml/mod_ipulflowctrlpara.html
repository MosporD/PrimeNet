Modify IP Uplink Flow Control Para (MOD IPULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the parameters of the IP uplink flow control algorithm.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [Co-MPT,NodeB]When the Port Type parameter is set to Loop Interface for the user-plane bearer, settings of parameters in the IPULFLOWCTRLPARA MO on the actual output port of the loopback interface take effect.

Parameters

ID Name Description
IPULFLOWCTRALGID IP Uplink Flow Control Algorithm ID

Meaning: Indicates the ID of the IP UL flow control algorithm.

GUI Value Range: 0~143

Unit: None

Actual Value Range: 0~143

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
PT Port Type

Meaning: Indicates the type of port where the IP UL flow control algorithm is configured.

GUI Value Range: LOOPINT(Loop Interface), PPP(PPP Link), MPGRP(Multi-link PPP Group), ETH(Ethernet Port), ETHTRK(Ethernet Trunk), TUNNEL(Tunnel)

Unit: None

Actual Value Range: LOOPINT, PPP, MPGRP, ETH, ETHTRK, TUNNEL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
PORTID Port ID

Meaning: Indicates the ID of the port where the IP UL flow control algorithm is configured.

GUI Value Range: 0~99999

Unit: None

Actual Value Range: 0~99999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
BWPRTSWITCH Bandwidth Adjustment Protection Switch

Meaning: Indicates whether to adjust the IP available UL bandwidth. When this parameter is set to ON, the BS stops adjusting the available UL bandwidth of the physical port if the bit error rate (BER) on the transmission line exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
TNLCONGCTRLSWITCH Congestion Control Switch

Meaning: Indicates whether to perform congestion control. When this switch is turned on, the BS lowers the TX rate if the BS detects that links experience transmission delay or packet loss.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
TNLCONGCTRLENHSW Congestion Control Enhancement Switch

Meaning: Indicates the switch for the enhanced congestion control. When the switch is set to ON, the enhanced congestion control prevents uplink available bandwidth from sharply decreasing and uplink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

This feature requires the uplink FPDT IP GPM detection result. Before using this feature, run the ADD IPGPM or MOD IPGPM command to enable the uplink FPDT IP GPM detection function for the NodeB.

This switch can be configured only when the flow control function is enabled.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the cell supports the enhanced HSUPA Iub traffic control when the Iub interface is congested.

This feature improves the uplink throughput of the cell when packet loss occurs due to bit errors in the transport network.

When this parameter is set to OFF, the network is not affected.

Applicable Mode: G, U
ULIUBMINBW Minimum UL Available Bandwidth of Logical Port

Meaning: Indicates the minimum UL bandwidth of logic port.

GUI Value Range: 0~1000000

Unit: kbit/s

Actual Value Range: 0~1000000

MML Default Value: None

Recommended Value: 600

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the transport network provides small available bandwidth over the physical port, congestion on the transport network causes the bandwidth to fail to decrease and therefore packets are discarded and the bandwidth is not effectively used if the parameter is set to a large value. When the transport network provides large available bandwidth over the physical port, incorrect bandwidth adjustment decreases system capacity if packets are discarded due to error codes or other exceptions occur during the transmission.

Applicable Mode: G, U

Example

To modify the IP uplink flow control algorithm with the parameters as follows: IP Uplink Flow Control Algorithm ID: 0, Port Type: ETH, Port ID: 1, BW Adjust Protection Switch: ON, Congestion Ctrl Switch: ON, The minimum UL available bandwidth of logic port.: 600, run the following command:
MOD IPULFLOWCTRLPARA: IPULFLOWCTRALGID=0, PT=ETH, PORTID=1, BWPRTSWITCH=ON, TNLCONGCTRLSWITCH=ON, ULIUBMINBW=600;
