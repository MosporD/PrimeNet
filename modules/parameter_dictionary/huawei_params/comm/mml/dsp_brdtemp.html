Display Board Temperature (DSP BRDTEMP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the temperature of a board. The temperature of the board includes the board temperature and power amplifier temperature.

Note

  • This command can be executed only when the specified board works properly.

  • A board in the BBU has the board temperature only. The temperature of other RF module includes the board temperature and power amplifier temperature.

  • [Co-MPT,NodeB,eGBTS]A WBBP without temperature sensor couldn't support querying temperature.

Example

Example 1:To query the temperature of the board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command:
DSP BRDTEMP: CN=0, SRN=0, SN=6;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

Board Temperature[degree Celsius(degree Fahrenheit)]

Indicates the temperature of a board.

HPA Temperature[degree Celsius(degree Fahrenheit)]

Indicates the temperature of the power amplifier. A power amplifier is a component on an RF module. If there is no power amplifier on an RF module, this parameter value is NULL.
