Set Alarm Filter (SET ALMFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set parameters related to the duration-based alarm filtering rule and times-based alarm filtering rule. The times-based alarm filtering rule is complementary to the duration-based alarm filtering rule to ensure that all useful alarms are reported.

An alarm is reported when the accumulated fault duration reaches the threshold or when the accumulated number of fault occurrences reaches the threshold. A cleared alarm is reported when the accumulated alarm cease duration and the number of fault recoveries reach the thresholds.

Note

  • The Alarm Raise Time Window and Alarm Raise Time Threshold parameters must be both set to 0 or non-zero values.

  • The value for Alarm Raise Time Threshold cannot be greater than that for Alarm Raise Time Window.

  • The value of Alarm Cease Time Threshold must be smaller than the value of Alarm Cease Time Window.

  • The ratio of Alarm Raise Time Threshold to Alarm Raise Time Window must be greater than the ratio of Alarm Cease Time Threshold to Alarm Cease Time Window.

  • If both Alarm Raise Time Window and Alarm Raise Time Threshold are 0 but Alarm Cease Time Window is not 0, clear alarms, which are cleared and generated intermittently, will be filtered. If neither Alarm Raise Time Window nor Alarm Raise Time Threshold is 0 but both Alarm Cease Time Window and Alarm Cease Time Threshold are 0, generated alarms, which are generated and cleared intermittently, will be filtered.

  • If Alarm Raise Time Window, Alarm Raise Time Threshold, Alarm Cease Time Window, and Alarm Cease Time Threshold are all 0, the alarm will not be filtered.

  • The value of Alarm Raise Frequency Threshold must be greater than the value of Alarm Cease Frequency Threshold.

  • If the values of Alarm Stat Time Window, Alarm Raise Frequency Threshold, and Alarm Cease Frequency Threshold are all 0, times-based alarm filtering is not performed.

  • When Window for Raising Alarm is 0, do not set Alarm Stat Time Window, Alarm Raise Frequency Threshold, and Alarm Cease Frequency Threshold.

  • When Alarm Raise Time Window is set to 0, Alarm Measurement Time Window, Alarm Raise Frequency Threshold and Alarm Cease Frequency Threshold will be set to 0 automatically.

Example

Example 1: To set the alarm filtering parameters as follows: Alarm ID: 26819, Filter Rule Type: RATIO, Window for Raising Alarm: 10, Threshold for Raising Alarm: 5, Window for Ceasing Alarm: 12, Threshold for Ceasing Alarm: 5, run the following command:
SET ALMFILTER: AID=26819, RTP=RATIO, RTW=10, RTH=5, CTW=12, CTH=5;
Example 2: To set the alarm filtering parameters as follows: Alarm ID: 26819, Filter Rule Type: STAT, Alarm Stat Time Window: 10, Alarm Raise Frequency Threshold: 5, Alarm Cease Frequency Threshold: 2, run the following command: 
SET ALMFILTER: AID=26819, RTP=STAT, STATTW=10, STATRTH=5, STATCTH=2;
