Download ALD Software (DLD ALDSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to load software for the Antenna Line Device (ALD). The ALD software is provided by the ALD manufacturer.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the following conditions are met:

    The FTP server has been configured.

    The FTP server is running properly. The IP address of the FTP server is on the same network segment as the IP address of the base station, and the FTP server is properly connected to the base station.

    There is no firewall between the FTP server and the base station.

    The user of the FTP server has the permission to read files in specified paths.

  • The ALD does not provide any file checking function. Therefore, loading wrong ALD software leads to ALD unavailability. Before loading ALD software, check with the ALD supplier whether the software to be loaded matches the ALD.

  • After the software is loaded, the ALD is automatically reset. The new software takes effect after the reset of the ALD.

  • The loading duration depends on the number of ALDs connected to the BS, but cannot be more than 120 minutes.

  • If an AISG1.1-based twin TMA is configured as two devices, software loading fails for the second device if any of the following happens:

    1. The TMA is reset after the software loading to the first device is complete.

    2. The TMA does not respond to the command for loading software to the second device.

    3. An error message is returned for the software loading to the second device.

    In these cases, only one TMA device functions and the software loading to this twin TMA is complete. After the software loading, you can run the DSP ALDVER command to query the TMA version and check whether the software loading is successful.

  • When this command is used to execute batch operations, some ALDs will report ALM-26541 ALD Maintenance Link Failure. This alarm will be cleared automatically after the software loading is complete.

  • Before upgrading software for the ALD, read documents provided by the ALD manufacturer and get familiar with precautions for upgrading the software.

  • If there is insufficient disk space, it is recommended that you run related removal commands or the CLR FILE command to delete files that are no longer in use.

  • If a physical ALD is mapped to multiple ALD objects, it is recommended that software be loaded in order of device number. In addition, it is recommended that you run the DSP ALDVER command to query software of other ALDs after loading software of the first ALD. If software of other ALDs is also loaded, you do not need to run this command any more.

  • [Co-MPT,eNodeB]For LTE, this command cannot be used to load software for the SASU.

Example

To load ALD software with the parameters as follows: Operation Type: Control Port, Device Type: RET, Control Port Cabinet No.: 0, Control Port Subrack No.: 60, Control Port Slot No.: 0, IP Mode: IPV4, FTP Server IP: 127.0.0.1, User Name: admin, Password: admin, Source File Name: \aldsw.bin, run the following command:
DLD ALDSW: OPMODE=CTRLPORT, DEVICETYPE=RET, CTRLCN=0, CTRLSRN=60, CTRLSN=0, MODE=IPV4, IP="127.0.0.1", USR="admin", PWD="*****", SRCF="\aldsw.bin";
