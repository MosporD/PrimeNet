Set IP Transmission Resource Group Algorithm (SET IPRSCGRPALG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the algorithm of an IP transmission resource group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the corresponding IP transmission resource group has been configured.

  • If the port type of IP path is set to LOOPINT, it is not recommended that flow control be configured for the IP transmission resource group that the IP path uses by default.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth will not be reduced if the average delay variation detected by an IP PM session is greater than the Delay Variation Down Threshold parameter and no packet loss is detected by the IP PM session; the estimated available transport bandwidth will be reduced if the average delay variation detected by an IP PM session is greater than the Delay Variation Down Threshold parameter and packet loss is detected by the IP PM session.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]Bandwidth-related parameters of an adaptive port IP transmission resource group cannot be modified, they take effect as the default values according to the board capacity. Before modifying the algorithm of an IP transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port), remove the IP transmission resource group with Transmission Resource Group ID set to AUTOPORT(Auto Port), and add an IP transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port).

When you remove any of the preceding objects, the system automatically removes the algorithm for the IP transmission resource group.

TXSSW TX Traffic Shaping Switch

Meaning: Indicates whether to enable traffic shaping for an IP transmission resource group. If this parameter is set to ON, traffic shaping is performed according to the TX bandwidth so that the transmit traffic would not exceed the capability of downstream routers, therefore avoiding unnecessary packet loss and congestion. If this parameter is set to OFF, traffic shaping is not performed during data transmission.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the TX rate of a transmission resource group can be kept less than or equal to the configured TX bandwidth. Therefore, congestion is avoided and QoS is ensured.

If this parameter is set to OFF, the TX rate of a transmission resource group can exceed the configured TX bandwidth. In this case, packet loss is easy to occur on the transport network, affecting the QoS of services.

Applicable Mode: G, U, L, N
TXBWASW TX Bandwidth Adjustment Switch

Meaning: Indicates whether to enable the dynamic adjustment of the TX bandwidth of an IP transmission resource group. If this parameter is set to ON, the TX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). The network performance is monitored through IP PM sessions, which can be enabled at the local end or at the peer end. If this parameter is set to OFF, the TX bandwidth is not adjusted. If mapping between the transmission resource group and a NodeB IP path or an IP path for no RAT is configured, this parameter does not take effect on the IP transmission resource group even though the parameter is set to ON. This parameter does not take effect in UMTS.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: In the scenario where the bandwidth on the transport network changes dynamically:

If this parameter is set to ON, less packets are lost because the TX bandwidth is adjusted dynamically.

If this parameter is set to OFF, the bandwidth and TX rate is not adjusted due to packet loss on the transport network.

Applicable Mode: G, U, L, N

If the packet loss rate detected through IP PM is lower than this threshold, the estimated available transport bandwidth is increased.

TCSW Traffic Control Switch

Meaning: Indicates whether to enable the backpressure algorithm of an IP transmission resource group.

The BS monitors the data buffered in the queues of each IP transmission resource group, determines whether the IP transmission resource group is congested, and transmits the backpressure signals (the ID and congestion status of the IP transmission resource group) to each flow control service.

If the size of buffered data packets in any backpressure queue exceeds 75% of the queue capacity, the BS regards this IP transmission resource group as congested and transmits congestion signals.

If the size of buffered data packets in each backpressure queue is less than 50% of the corresponding buffer capacity, the BS decides that the IP transmission resource group is not congested. In this situation, no congestion signal or congestion release signal is transmitted.

When this parameter is set to ENABLE, both intra-mode traffic control and inter-mode traffic control are supported.

The inter-mode traffic control for IP transmission resource groups applies only to separate-MPT base stations with co-transmission implemented through backplane interconnection. However, it does not apply to cascaded base stations, base stations with co-transmission implemented through panel interconnection, or base stations enabled with route load sharing.

When the inter-mode traffic control function is enabled for a separate-MPT base station with co-transmission implemented through backplane interconnection, the Tunnel Type parameter must be set to DL(DL) for the tunnel of the mode providing transmission ports and must be set to UL(UL) for the tunnel of the mode providing no transmission port.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE, congestion of transmission resource groups can be avoided. Therefore, fairness and differentiation of non-real-time services are ensured.

If this parameter is set to DISABLE, packet loss is easy to occur. In this case, fairness and differentiation of non-real-time services cannot be ensured.

Applicable Mode: G, U, L, N
PQN PQ Number

Meaning: Indicates the number of PQs in an IP transmission resource group. The queues in an IP transmission resource group are classified into PQs and non-PQs. The scheduling priority of any PQ is higher than that of any non-PQ. The queues numbered from 0 to the result after this parameter value minus 1 are PQs. PQ scheduling is used between PQs. A smaller PQ number indicates a higher scheduling priority. The queues numbered from this parameter value to 6 are non-PQs. WPR scheduling is used between non-PQs.

GUI Value Range: 0~6

Unit: None

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Real-time services should be in a PQ, and non-real-time services should be in a non-PQ. Otherwise, preferential transmission of real-time service data cannot be ensured.

Applicable Mode: G, U, L, N
CTTH Congestion Time Threshold

Meaning: Indicates the congestion time threshold of an IP transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in an IP transmission resource group exceeds the threshold, the IP transmission resource group is congested, and backpressure signals are transmitted.

Impact on Radio Network Performance: A smaller parameter value indicates a higher probability of the TX rate change of the transport resource group but a shorter delay.

A larger parameter value indicates a lower probability of the TX rate change of the transport resource group but a longer delay.

CCTTH Congestion Clear Time Threshold

Meaning: Indicates the congestion clear time threshold of an IP transmission resource group. When TCSW is set to ENABLE, if the buffer time of non-real-time service data in an IP transmission resource group is less than the threshold, the IP transmission resource group is not congested, and congestion clear signals are transmitted.

GUI Value Range: 0~500

Unit: ms

Actual Value Range: 0~500

MML Default Value: None

Recommended Value: 25

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an IPRSCGRPALG MO, CCTTH must be less than CTTH.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

A larger parameter value indicates a worse differentiation effect for bandwidth allocation of non-real-time services. This, however, leads to a lower probability of emptying the buffer of the transmission resource group and is unlikely to affect the bandwidth usage.

Applicable Mode: G, U, L, N
TXRSVBW TX Reserved Bandwidth

Meaning: Indicates the TX bandwidth reserved for signaling data, OM data, or real-time services. This parameter should be set to a value less than the TX bandwidth of an IP transmission resource group. It is recommended that the reserved TX bandwidth be set to a value less than or equal to 3% of the TX bandwidth of an IP transmission resource group. The UMTS currently does not support this function.

DROPPKTNUM Drop Packet Number Threshold

Meaning: Indicates the threshold for the number of discarded packets. This parameter indicates the capability of the queue in an IP transmission resource group to buffer packets. A greater parameter value indicates a stronger capability. If this parameter is set to 0, the queue in an IP transmission resource group cannot buffer packets, and therefore all the delayed packets on the TX channel are discarded. The threshold for the number of discarded packets determines the maximum amount of data that can be buffered in an IP transmission resource group. The congestion time threshold of a transmission resource group determines the amount of data that is buffered when the IP transmission resource group is congested. Ensure that the maximum amount of data that can be buffered is not less than the amount of data that is buffered during congestion.

GUI Value Range: 0~8192

Unit: packet

Actual Value Range: 0~8192

MML Default Value: None

Recommended Value: 1000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A greater value indicates a larger capability of the queue in a transmission resource group to buffer packets.

Applicable Mode: G, U, L, N

Example

To modify the algorithm of an IP transmission resource group with the parameters as follows: IP Transmission Resource Group ID: 0, TX Traffic Shaping Switch: ON, run the following command:
SET IPRSCGRPALG: IPRSCGRPID=0, TXSSW=ON;
