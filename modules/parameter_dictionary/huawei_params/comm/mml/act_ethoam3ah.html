Activate Ethernet OAM 3AH (ACT ETHOAM3AH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to activate Ethernet OAM 3AH, where OAM stands for Operation, Administration and Maintenance.

Note

  • The detection periods at both ends of the link must be the same. The default period is 1000 ms, as specified in protocols.

  • System specifications: If the WMPT/UMPT/LMPT/GTMUb/GTMUc is the main control board, a maximum of 48 Ethernet OAM 3AHs can be activated. If the UMDU is the main control board, a maximum of 2 Ethernet OAM 3AHs can be activated.

  • Board specifications: A maximum of 2 Ethernet OAM 3AHs can be activated on a WMPT/UMPTa/UMPTb/UMDU/LMPT/GTMUb/GTMUc/UTRP (subboard type: UEOC). A maximum of 4 Ethernet OAM 3AHs can be activated on a UMPTe/UMPTg/UMPTga. A maximum of 6 Ethernet OAM 3AHs can be activated on a UTRPc. A maximum of 4 Ethernet OAM 3AHs can be activated on a UTRP (subboard type: UQEC).

  • [Co-MPT,eGBTS]The GTMUb/GTMUc does not allow the Detection Period parameter to be set to 10 ms.

WORKMODE Work Mode

Meaning: Indicates the work mode of the IEEE802.3ah Ethernet OAM.

If this parameter is set to ACTIVE, the local end initiates the IEEE802.3ah Ethernet OAM negotiation.

If this parameter is set to PASSIVE, the local end does not initiate the negotiation; instead, the local end waits for receiving negotiation packets from the peer end.

In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Work Mode parameter in the ETH3AH MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Meaning: Indicates whether remote loopback can be enabled at the port where 3AH detection is activated. If remote loopback is enabled, the OAM 3AH loopback is allowed. If remote loopback is disabled, the local end cannot initiate the loopback.

Example

To activate Ethernet OAM 3AH with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Port Type: Ethernet Port, Port No.: 0, Work Mode: Active Mode, PDU Size: 128, Error Frame Event Duration: 1, Error Frame Event Threshold: 1, Error Frame Seconds Summary Event Duration: 60, Error Frame Seconds Summary Event Threshold: 1, run the following command:
ACT ETHOAM3AH: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, PT=ETH, PN=0, WORKMODE=ACTIVE, PDUSIZE=128, ERRFRMEVTPRD=1, ERRFRMEVTTHD=1, ERRFRMSCDEVTPRD=60, ERRFRMSCDEVTTHD=1;
