Set Network Element Configuration (SET NE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set Network Element Name, Site Location, Deployment Identifier, Site Name, User Label and Cloud BB identifier.

Note

  • If the DID parameter is set to a space, the DID information will be deleted.

  • The NE name will be synchronized from MAE to the base station automatically.

Parameters

ID Name Description
NENAME Network Element Name

Meaning: Indicates the NE name.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • The changed NE name must be the same as the NE name configured on the MAE. For the DBS3900 WCDMA/BTS3900 WCDMA/BTS3900A WCDMA/BTS3900L WCDMA/BTS3900AL WCDMA/DBS5900 WCDMA/BTS5900 WCDMA/BTS5900A WCDMA/BTS5900L WCDMA/BTS5900AL WCDMA base station, the value of this parameter must be consistent with the value of the NODEBNAME parameter in the UNodeB MO of the corresponding logical base station configured on the RNC.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

DID Deployment Identifier

Meaning: Indicates the deployment identifier that specifies the site of the NE. When multiple NEs are deployed at the same site, these NEs have the same deployment identifier.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SITENAME Site Name

Meaning: Indicates the site name. When multiple NEs are at the same site, these NEs are configured with the same site name.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • The changed site names of a separate-MPT base station must be the same.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
USERLABEL User Label

Meaning: Indicates the user-defined information of the NE.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

Meaning: Indicates the Cloud BB identifier that specifies the Cloud BB to which the NE belongs. When multiple NEs are deployed under the same Cloud BB, these NEs have the same Cloud BB identifier. The default value 0 cannot be used as a Cloud BB identifier.

GUI Value Range: 0~65535

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Set Network Element Configuration, NENAME(Network Element Name) is "HUAWEI", LOCATION(Site Location) is "HANGZHOU-JIANGUOLU-3-3", DID(Deployment Identifier) is "DID_NODEB12345", SITENAME(Site Name) is "LTE_1526", USERLABEL(User Label)is "hangzhou", CLOUDBBID(Cloud BB Identifier)is"0":
SET NE: NENAME="HUAWEI", LOCATION="HANGZHOU-JIANGUOLU-3-3", DID="DID_NODEB12345", SITENAME="LTE_1526", USERLABEL="hangzhou", CLOUDBBID=0;
