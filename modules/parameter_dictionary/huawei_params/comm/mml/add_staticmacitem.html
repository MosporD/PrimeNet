Add Static MAC Entry (ADD STATICMACITEM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an entry to a static MAC forwarding table.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB]Entries of static MAC forwarding tables are configured only for switch ports (ranging from 1 to 32) of air-interface link type.

  • [Co-MPT,eNodeB]A static MAC forwarding table for each switch port can be configured with a maximum of 100 entries. A global static MAC forwarding table for the L2 LAN switch can also be configured with a maximum of 100 entries.

  • [Co-MPT,eNodeB]If the alarm ALM-25950 Base Station Being Attacked (Specific problem: Source MAC Address Attack) is not cleared, the configured entries in a MAC forwarding table may not take effect.

Parameters

ID Name Description
MACIDX MAC Entry Index

Meaning: Indicates the index of an entry in a MAC forwarding table.

GUI Value Range: 0~99

Unit: None

Actual Value Range: 0~99

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
SWPORTIDX Switch Port Index

Meaning: Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
DSTMAC Destination MAC Address

Meaning: Indicates the destination MAC address of an entry in a MAC forwarding table. The format must be "XXXX-XXXX-XXXX".

GUI Value Range: 14 characters

Unit: None

Actual Value Range: 14 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB]The DSTMAC parameters in any two STATICMACITEM MOs must be set to different values.
  • [Co-MPT, eNodeB]DSTMAC in the STATICMACITEM MO cannot be set to any one of the following values: broadcast MAC address (FFFF-FFFF-FFFF), multicast MAC address (the first left byte in the Destination Address field is an odd number), and default MAC address (0000-0000-0000).

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To add a static mac entry with the parameters as follows: MAC Entry Index: 0, Switch Port Index: 1, Destination MAC Address: 2014-0A26-1024, run the following command: 
ADD STATICMACITEM: MACIDX=0, SWPORTIDX=1, DSTMAC="2014-0A26-1024";
