List MLPPP Group Configuration (LST MPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of the MLPPP group.

Note

None.

Parameters

None.

Example

To list the configuration of the MLPPP group, run the following command:
LST MPGRP:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the MLPPP group is located.

Subrack No.

Indicates the number of the subrack where the MLPPP group is located.

Slot No.

Indicates the number of the slot where the MLPPP group is located.

Subboard Type

Indicates the type of sub-board on the board where an MLPPP group is established.

Group No.

Indicates the number of the MLPPP group.

Port ID

Indicates the ID of an MLPPP group, which uniquely identifies the MLPPP group. In the old model, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. In the new model, this parameter is mandatory and must be unique in the system.

Multi-Class PPP

Indicates whether an MLPPP group supports the multi-class feature.

If this parameter is set to ENABLE, the MLPPP group supports the Class of Service (CoS) feature and four or eight service types of different priorities.

Authentication Type

Indicates the authentication type of the MLPPP group.

User Name

Indicates the authentication user name of an MLPPP group.

Password

Indicates the authentication password.

Local IP

Indicates the local IP address. If this parameter is set to 0.0.0.0, this IP address needs to be negotiated. If this parameter is not set to 0.0.0.0, it must be set to a valid IP address of class A, B, or C but must not be the reserved address 0.x.x.x or 127.x.x.x.

Mask

Indicates the subnet mask of the local IP address. If this parameter is set to 0.0.0.0, it needs to be negotiated.

Peer IP

Indicates the peer IP address. When the BS is connected to a peer equipment, the peer IP address can be either user-specified or set to 0.0.0.0. If this parameter is set to 0.0.0.0, this IP address is obtained by means of negotiation.

MP/MC Header Option

Indicates the MP/MC head option of the MLPPP.

PPPMUX

Indicates whether to enable PPP multi-frame multiplexing.

MLPPP Fragment Size(byte)

Indicates the fragment size of an MLPPP group.

PPP Mux Subframe Max Length(byte)

Indicates the maximum length of the PPP MUX subframe.

PPP Muxframe Max Length(byte)

Indicates the maximum length of the PPP MUX frame.

PPPMUX Combine Timeout(ms)

Indicates the timeout duration of a PPP MUX combination. If the PPP MUX combination takes longer time than this parameter value, an alarm related to the PPP MUX combination timeout is reported.

MCPPP Class

Indicates the number of classes of service.

IP Header Compression

Indicates whether to enable IP header compression.

IPHC SubOption

Indicates whether to enable IPHC suboption negotiation.

MLPPP Packets Discard Alarm Appear Threshold(per mill)

Indicates the threshold above which the MLPPP packet loss alarm is generated.

MLPPP Packets Discard Alarm Disappear Threshold(per mill)

Indicates the threshold below which the MLPPP packet loss alarm is cleared.
