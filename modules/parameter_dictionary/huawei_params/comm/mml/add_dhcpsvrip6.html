Add IP Address of DHCPv6 Server (ADD DHCPSVRIP6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add the IP address of a DHCPv6 server.

Note

  • [Co-MPT,eNodeB,gNodeB]System specifications: A base station supports a maximum of 4 DHCPv6 server IP addresses.

  • [Co-MPT,eNodeB,gNodeB]After adding a DHCPv6 server IP address, you still need to run the ADD INTERFACEPARA6 or MOD INTERFACEPARA6 command to enable the DHCPv6 Relay Switch so that the interface can receive DHCPv6 request packets.

  • [Co-MPT,eNodeB,gNodeB]Currently, the DHCPv6 relay function does not support co-transmission through backplane interconnection or cross-board interconnection.

  • [Co-MPT,eNodeB,gNodeB]If the IPv6 address for activating an OMCH is configured and the VRF index is 0, the second-level relay is also attempted.

Parameters

ID Name Description
DHCPSVRIP DHCPv6 Server IP Address

Meaning: Indicates the IP address of the DHCPv6 server.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The DHCPSVRIP parameter in the DHCPSVRIP6 MO must be set to a valid IPv6 address, and this IPv6 address must be set to a globally scoped unicast address.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To add an IP address of a DHCPv6 server with the parameter as follows: DHCPv6 Server IP Address: 2001:DB8::1, run the following command:
ADD DHCPSVRIP6: DHCPSVRIP="2001:DB8::1";
