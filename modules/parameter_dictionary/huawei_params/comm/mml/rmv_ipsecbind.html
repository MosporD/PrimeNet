Remove Binding from IPSec Policy Group to Port (RMV IPSECBIND)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove the binding of an IPSec policy group to a port. The execution of this command terminates the protection mechanism applied to the data streams flowed through the port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The binding of an IPSec policy group to a port cannot be removed if the IPSec policy group is referenced by an IPSec tunnel pair.

  • If the master and slave IKE peers are configured in different IPSec policy groups, you must remove the IPSECBIND MO of the slave IKE peer before removing the IPSECBIND MO of the master IKE peer.

  • When the master and slave IKE peers are configured in different IPSec policy groups, if the user remove the IPSECBIND references the slave IKE peer in use, the system will use the slave IKE peer of a lower priority for negotiation. If there is not exist any other slave IKE peers, a switchover is performed from slave IKE tunnel to the master IKE tunnel regardless of whether back switchover is enabled.

  • When the user remove the IPSECBIND references the master IKE peer, the master IKE tunnel is reused regardless of whether the master or slave IKE peer is used currently.

  • This operation may interrupt the services or OM channels. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • When an IPSECBIND MO is removed, if the IPSECPOLICY, IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects, which the IPSECBIND MO directly or indirectly depends on, do not have a bearer MO (PACKETFILTER, IPSECBIND) on the board where the IPSECBIND MO has taken effect, the IPSECPOLICY, IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects will not take effect on the board.

Example

To remove the binding of an IPSec policy group to a port with the parameters as follows: Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, Policy Group Name: policy, run the following command: 
RMV IPSECBIND: SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, SPGN="policy";
