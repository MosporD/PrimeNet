Display Activated Device Certificate (DSP APPCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of activated device certificates.

Note

In the multi-PKI scenario, when APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to APPCERT, the device certificate displayed by running this command is the one used in IKE negotiation. To query all activated device certificates, run the LST CERTFILE command and set CERTFILETYPE to DEVCERT.

Parameters

ID Name Description
APPTYPE Application Type

Meaning: Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS. When APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to Appcert, the device certificate being used during IKE negotiation is the certificate configured in the APPCERT object. When APPTYPE is set to SSL, the device certificate being used is the certificate used during SSL connection, 802.1x-based, or inter-BBU interconnection authentication. When APPTYPE is set to DTLS, the device certificate being used is the certificate used during DTLS connection authentication.

GUI Value Range: IKE(IKE), SSL(SSL), DTLS(DTLS)

Unit: None

Actual Value Range: IKE, SSL, DTLS

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a BS, there is only one activated device certificate for each application type.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

To query the information about the activated device certificates, run the following command:
DSP APPCERT:;

Output Description

Field Description

Application Type

Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS. When APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to Appcert, the device certificate being used during IKE negotiation is the certificate configured in the APPCERT object. When APPTYPE is set to SSL, the device certificate being used is the certificate used during SSL connection, 802.1x-based, or inter-BBU interconnection authentication. When APPTYPE is set to DTLS, the device certificate being used is the certificate used during DTLS connection authentication.

Certificate File Name

Indicates the file name of an activated device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

Issuer

Indicates the issuer of an activated device certificate.

Common Name

Indicates the common name of an activated device certificate.

Serial Number

Indicates the serial number of an activated device certificate.

Effective Date

Indicates the date when an activated device certificate begins to take effect.

Expiration Date

Indicates the expiration date of an activated device certificate.

Status

Indicates the loading status of an activated device certificate.
