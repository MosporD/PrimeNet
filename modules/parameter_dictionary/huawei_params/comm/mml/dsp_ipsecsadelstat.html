Display IPSec SA Statistics (DSP IPSECSADELSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query statistics on an IP Security (IPSec) SA.

Note

[NodeB]The WMPT does not support this function.

Example

To query statistics on an IPSec SA with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command: 
DSP IPSECSADELSTAT: CN=0, SRN=0, SN=6;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the local IKE board.

Subrack No.

Indicates the subrack number of the local IKE board.

Slot No.

Indicates the slot number of the local IKE board.

Number of AH or ESP Packets Established in the First SA Connection

Indicates the number of IP Authentication Header (AH) or IP Encapsulating Security Payload (ESP) packets established in the first SA connection.

Number of AH and ESP Packets Established in the First SA Connection

Indicates the number of IP AH and IP ESP packets established in the first SA connection.

Number of AH or ESP Packets Updated by SA After Re-authentication or Key Re-application

Indicates the number of IP AH or IP ESP packets updated by SA after re-authentication or key re-application.

Number of AH and ESP Packets Updated by SA After Re-authentication or Key Re-application

Indicates the number of IP AH and IP ESP packets updated by SA after re-authentication or key re-application.

Number of Soft Timeouts Occurring for the First Time

Indicates the number of soft timeouts occurring for the first time (70% data of the key that is re-applied for has been configured).

Number of Soft Timeouts Occurring for the Second Time

Indicates the number of soft timeouts occurring for the second time. Soft timeout means that 80% of the data for the key that is re-applied for has been configured.

Number of Soft Timeouts Occurring for the Third Time

Indicates the number of soft timeouts occurring for the third time (90% data of the key that is re-applied for has been configured).

Number of Hard Timeouts

Indicates the number of hard timeouts. Hard timeout means that the key that is re-applied for has been completely configured.

Number of Removed SAs

Indicates the number of removed SAs (including old and new SAs that are removed because of SA API clearance, key re-application, and re-authentication).

Number of Removed New SAs

Indicates the number of removed new SAs.

Number of Old SAs Removed Within One Second

Indicates the number of old SAs removed within one second. This indicates the warning event that will take place within one second. If packets may be discarded because old SAs are removed, this warning event is not an expected activity.

Number of Old SAs Removed One Second Later

Indicates the number of old SAs removed within one second. This indicates the warning event that will take place one second later and the warning event is an expected activity.

Number of Reserved Incoming IPSec Tunnel Descriptor Blocks

Indicates the number of reserved incoming IPSec Tunnel Descriptor Blocks (TDBs).

Number of Arriving Incoming DHCP Packets

Indicates the number of arrived incoming DHCP packets.

Number of Arriving Outgoing DHCP Packets

Indicates the number of arrived outgoing DHCP packets.

Number of Outgoing Packets due to Certificate Expiry or Revocation

Indicates the number of outbound packets bypassed due to certificate expiry or revocation.

Number of Incoming AH Packets Discarded due to Certificate Expiry or Revocation

Indicates the number of incoming IP AH packets discarded due to certificate expiry or revocation.

Number of Outgoing ESP Packets Discarded due to Certificate Expiry or Revocation

Indicates the number of outgoing IP ESP packets discarded due to certificate expiry or revocation.
