Reset Alarm Correlation Shield Flag (RST ALMCORRSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to restore the default setting of the Report Flag of Son Alarm for a specified alarm.

Note

  • If an alarm is suppressed as a correlative alarm, this alarm will be reported again after Report Flag of Son Alarm is reconfigured to REPORT(Report).

  • If an alarm is reported as a correlative alarm, this alarm remains unchanged after Report Flag of Son Alarm is reconfigured to NOT_REPORT(Not Report).

  • You can run the LST ALMCORRSHLD command to query the setting of Report Flag of Son Alarm for an alarm to be reconfigured. You cannot query the reconfigured alarm by running the LST ALMCORRSHLD command.

Parameters

ID Name Description
AID Alarm ID

Meaning: Indicates the alarm ID. The alarm ID is the only index for alarms.

GUI Value Range: 1~65032

Unit: None

Actual Value Range: 1~65032

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To initialize the correlation shield flag of a specified alarm with the parameter as follows: Alarm ID: 26235, run the following command:
RST ALMCORRSHLD: AID=26235;
