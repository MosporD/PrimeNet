List Certification Deploy Position (LST CERTDEPLOY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list where a certificate is configured.

Note

None.

Parameters

None.

Example

To query the CERTDEPLOY configuration, run the following command: 
LST CERTDEPLOY:;
The result is shown as follows:
+++    0        2011-09-22 19:54:50
O&M    #5408
%%LST CERTDEPLOY:;%%
RETCODE = 0  Operation succeeded.

Display CERTDEPLOY
------------------
Certification Deploy Position Type  =  Default
                       Cabinet No.  =  NULL
                       Subrack No.  =  NULL
                          Slot No.  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

Certification Deploy Position Type

Indicates the deployment position of a digital certificate. If this parameter is set to DEFAULT, the certificate is configured on the main control board. If this parameter is set to SPECIFIC, the certificate is configured on the board in the specified slot. If this parameter is set to NULL, no certificate is configured on the BS.

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.
