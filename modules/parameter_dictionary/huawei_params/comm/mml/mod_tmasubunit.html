Modify TMA Subunit (MOD TMASUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a tower mounted amplifier (TMA) subunit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • In bypass mode, the TMA cannot help achieve the gain of signals. This affects network coverage.

  • In normal working mode, the gain value of the subunit can be set.

  • The value range of the gain supported by the TMA varies according to the manufacturer and TMA model. Run the DSP TMADEVICEDATA command to query the value range of the gain supported by the TMA before configuration. If the gain supported by the TMA is a fixed value and the gain cannot be set, the gain setting fails to take effect.

  • The TMA subunits cannot be connected to the same port.

  • A single TMA is connected to only one physical port. An AISG1.1-based twin TMA, however, consists of two internal TMAs and functions as two subunits of an AISG2.0-based TMA.

  • If the system is busy, the configuration may take effect beyond the specified time, and the configuration data will be sent to the TMA later. The execution result of this command can be obtained by running the DSP TMASUBUNIT to query the status of the TMA subunit.

  • When the cabinet number of the port to which the TMA subunit is connected is 255, the port is not connected. In this case, the corresponding subrack number and slot number are set to 255.

  • The parameter settings of the antenna port to which the TMA subunit is connected must be consistent with the actual physical connection so that the status of the connected antenna port can be correctly queried. Once the status of the connected antenna port is abnormal, proper troubleshooting measures should be taken.

MODE Work Mode

Meaning: Indicates the working mode of the TMA subunit. The value NORMAL indicates that the TMA subunit works in normal mode and properly amplifies uplink signals. The value BYPASS indicates that the TMA subunit works in bypass mode and does not amplify uplink signals. The value DEVICE_DEFAULT_VALUE indicates that the TMA subunit works in default mode.

GUI Value Range: NORMAL, BYPASS

Unit: None

Actual Value Range: NORMAL, BYPASS

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter must be consistent with the network plan. Otherwise, the call drop rate increases and the access success rate decreases for users at the coverage edge.

Applicable Mode: G, U, L, N
GAIN Gain

Meaning: Indicates the gain of the TMA subunit. If this parameter is set to 255, it is invalid and the actual gain is not changed.

GUI Value Range: 0~255

Unit: 0.25dB

Actual Value Range: 0~63.75, step: 0.25

MML Default Value: None

Recommended Value: None

Impact on Radio Network Performance: This parameter must be consistent with the network plan. Otherwise, the call drop rate increases and the access success rate decreases for users at the coverage edge.

Applicable Mode: G, U, L, N

Example

To modify a TMA subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, Connect Port Cabinet No.: 0, Connect Port Subrack No.: 60, Connect Port Slot No.: 0, Connect Port No.: R0A, Mode: Normal, Gain: 48, run the following command:
MOD TMASUBUNIT: DEVICENO=0, SUBUNITNO=1, CONNCN=0, CONNSRN=60, CONNSN=0, CONNPN=R0A, MODE=NORMAL, GAIN=48;
