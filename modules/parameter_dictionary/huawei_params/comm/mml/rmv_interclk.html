Remove Interconnection Reference Clock (RMV INTERCLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a specified interconnection reference clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the working mode of the clock is manual and the interconnection reference clock link is specified as the reference clock source, this clock link cannot be removed. If the working mode of the clock is automatic, the clock link can be removed. After removal of the clock link, the system clock is switched to another clock source.

  • Ongoing services are affected if a clock source in use is removed, the NE does not obtain another reference clock within the holding period of the crystal oscillator, and the crystal oscillator running time exceeds the hold period.

Parameters

ID Name Description
LN Interconnection Clock No.

Meaning: Indicates the number of the interconnection reference clock link.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove interconnection reference clock link 0, run the following command:
RMV INTERCLK: LN=0;
