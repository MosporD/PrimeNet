Set Clock Quality Level (SET LOCALCLKQL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the clock quality level of a BS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

If the local clock quality level is changed, the clock quality level of IP clock input signals may become lower than the local clock quality level. In this case, if Profile Type of the IP clock is set to G.8265.1, the IP clock will become unavailable.

If the local clock quality level is changed, the clock quality level of SYNCETH clock input signals may become lower than the local clock quality level, which will cause the SYNCETH clock to become unavailable.

Parameters

ID Name Description
QL Quality Level

Meaning: Indicates the clock quality level of the BS. The values for this parameter are listed in quality descending order. QL-PRC indicates the highest quality level.

GUI Value Range: QL-PRC(QL-PRC), QL-SSU-A(QL-SSU-A), QL-SSU-B(QL-SSU-B), QL-EEC2(QL-EEC2), QL-EEC1(QL-EEC1)

Unit: None

Actual Value Range: QL-PRC, QL-SSU-A, QL-SSU-B, QL-EEC2, QL-EEC1

MML Default Value: QL-SSU-B(QL-SSU-B)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the clock quality level of a BS with parameters as follows: Quality Level: QL-PRC, run the following command:
SET LOCALCLKQL: QL=QL-PRC;
