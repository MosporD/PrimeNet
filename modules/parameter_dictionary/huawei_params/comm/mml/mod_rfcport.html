Modify RF Card Port (MOD RFCPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of ports.

Note

None.

Parameters

Meaning: Indicates the number of the cabinet housing the RF card which provides the port.

GUI Value Range: 0~7

Actual Value Range: 0~7

MML Default Value: None

Example

To modify a set of RFC Port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, Port No.: 0, DL Switch: ON, UL Switch: ON, Power Attenuation: -10, and UL Gain Adjustment: -10, run the following command:
MOD RFCPORT: CN=0, SRN=0, SN=3, PN=0, DLSWITCH=ON, ULSWITCH=ON, PWRATTENUATION=-10, ULGAINADJUSTMENT=-10;
