Display AAS Dynamic Information (DSP AAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the dynamic information about an Active Antenna System (AAS).

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the AAS is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SRN Subrack No.

Meaning: Indicates the number of the subrack where the AAS is located.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
LOCATIONNAME Location Name

Meaning: Indicates the location information of an AAS. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To query the dynamic information about all AASs, run the following command:
DSP AAS;
The result is shown as follows:
+++    0        2012-11-07 01:12:36
O&M    #7526
%%DSP AAS:;%%
RETCODE = 0  Operation succeeded.

Display AAS Dynamic Information
-------------------------------
     Cabinet No.  =  0
     Subrack No.  =  60
Access Direction  =  Access from chain head or ring head
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the AAS is located.

Subrack No.

Indicates the number of the subrack where the AAS is located.

Access Direction

Indicates the access direction of the services.
