List CCU (LST CCU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of one or all cabinet control units (CCUs).

Note

For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

To list the configuration of a CCU, run the following command:
LST CCU:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the CCU.

Subrack No.

Indicates the subrack number of the CCU.

Slot No.

Indicates the slot number of the CCU.

Manager Cabinet No.

Indicates the cabinet number of the manager unit of the CCU.

Manager Subrack No.

Indicates the subrack number of the manager unit of the CCU.

Manager Port No.

Indicates the number of the serial port where the CCU is connected. The serial port is the port through which the CCU is connected to the manager unit.

DirectConnectFlag

Indicates whether the CCU is directly connected to its manager unit.

Cascade No.

Indicates the position of the CCU on a CCU chain. On a CCU chain, the FE_R port on the upper-level CCU is connected to the FE_L port on the lower-level CCU. A CCU whose FE_L port is left unconnected is the first-level CCU and the CCU directly connected to the first-level CCU is the second-level CCU and so on.

Connected RAT

Indicates the working standard of the manager unit to which the CCU is connected.LTE TDD needs to be added to the working standard of the manager unit to which the CCU is connected only when the working mode of an NE to which the CCU is connected is LTE TDD. The working mode is LTE TDD only when Product Type is set to DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900_LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900_LampSite, Working Mode to NON-CONCURRENT, and LTE Mode to LTE_TDD, or when Product Type is set to DBS3900_LTE, BTS3900_LTE, BTS3900A_LTE, BTS3900L_LTE, BTS3900AL_LTE, DBS3900_LampSite_LTE, DBS5900_LTE, BTS5900_LTE, BTS5900A_LTE, BTS5900L_LTE, BTS5900AL_LTE, or DBS5900_LampSite_LTE and LTE Mode to LTE_TDD.

Special Boolean Alarm Flag

Indicates whether to allow the reporting of a dedicated Boolean alarm. If the shield flag for a Boolean alarm is enabled, the Boolean alarm cannot be reported.

Number of eBAT

Indicates the number of eBATs connected to a CCU. If this parameter is set to 0, no eBAT provides the monitoring function.

Battery Inner Resistance Alarm Threshold(0.1mΩ)

Indicates the internal resistance alarm threshold of the battery monitored by the eBAT to which a CCU is connected.
