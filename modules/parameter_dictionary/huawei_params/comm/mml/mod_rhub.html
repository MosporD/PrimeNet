Modify RHUB (MOD RHUB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an RHUB.

Note

None.

-Configuration constraints:

MNTMODE Maintenance Mode

Meaning: Indicates the maintenance mode of an RHUB. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes. The default value of this parameter is NORMAL.

RHUBSPEC RHUB Specification

Meaning: Indicates the type of an RHUB. This parameter needs to be set only when the MAE-Deployment is used for offline configuration. If this parameter is not set, the operation of the entire base station is not affected. Set this parameter based on the actual RHUB hardware type. The MAE-Deployment verifies the configuration based on the actual RHUB type. The MAE-Deployment can identify configuration errors before delivering the configuration to the base station, and display the main chain and branch chain ports of the RHUB based on the configuration type on the device panel. The value of this parameter must be the same as the hardware type of the RHUB. For example, for the RHUB5921 module, the value of this parameter is RHUB5921; for the RHUB5961 module, the value of this parameter is RHUB5961.

GUI Value Range: 0~15 characters

Unit: None

Actual Value Range: 0~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Example

To modify the configuration of an RHUB with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, RHUB Name: RhubName, run the following command:
MOD RHUB: CN=0, SRN=60, SN=0, RN="RhubName";
