List Certificate Request Configuration (LST CERTREQ)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the registration information used to create the certificate request.

Note

None.

Parameters

None.

Example

To list the configuration of the certificate request file, run the following command:
LST CERTREQ:;
The result is shown as follows:

Output Description

Field Description

Common Name

Indicates the common name of the certificate request file, which can be the electronic serial number (ESN), media access control (MAC) address, or IP address of a board. If this parameter is set to MAC or IP, the RRU still uses the ESN as the common name of the certificate request file.

Common Name Additional Info.

Indicates the additional information about a certificate common name. The information will be added behind the value of the COMMNAME parameter to compose a complete common name for a certificate request file. The default value is .huawei.com. A space is not supported before the value of this parameter, that is, a space is not supported before the character string. However, to meet requirements of consistency checks performed by some CA servers to the certificate common name in a certificate request packet and that in a Huawei device certificate, the certificate common name in a certificate request packet is displayed as "Board ESN"+space+"Common Name Additional Info" only when the certificate common name in a Huawei device certificate is "Board ESN"+space+"Common Name Additional Info". For example, when the value of this parameter is "eNodeB" and the certificate common name in a Huawei device certificate is "ESN eNodeB", a space is automatically added before "eNodeB", that is, the certificate common name in a certificate request packet is displayed as "ESN eNodeB".

Country

Indicates the country where a BS is located.

Organization

Indicates the organization that owns a BS.

Organizational Unit

Indicates the organization unit that owns a BS.

State or Province

Indicates the state or province where a BS is located.

Locality

Indicates the location of a BS.

Key Usage

Indicates the usage for a key, including KEY_AGREEMENT (key negotiation), DATA_ENCIPHERMENT (data encryption), KEY_ENCIPHERMENT (key encryption), and DIGITAL_SIGNATURE (digital signature). This parameter can be set to one or multiple values. NON_REPUDIATION, KEY_CERT_SIGN, CRL_SIGN, ENCIPHER_ONLY and DECIPHER_ONLY are supported when query information.

Signature Algorithm

Indicates the signature algorithm for a certificate request file. If this parameter is set to SHA1, the RRU still uses the SHA256 algorithm as the signature algorithm for the certificate request file.

Key Type

Indicates type of key of one certificate, which can be RSA or ECDSA.

Key Size

Indicates the key length, which can be 1024 bits, 2048 bits, 3072 bits or 4096 bits. The key length of 1024 bits is not recommended. Otherwise, the security is undermined. If this parameter is set to KEYSIZE1024, the RRU still uses the value KEYSIZE2048 as the key length.

ECC Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), and ED25519. ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.

Local Name

Indicates the local name of a BS. This parameter is used to generate the DNS name of the subject alternative name of a certificate, to verify the peer's identification in IKE negotiation. If this parameter is not configured, the BS automatically uses the common name and its additional information to generate the DNS name. This parameter does not take effect for RRUs.

Local IP

Indicates the IP address of the subject alternative name of a certificate. This parameter does not take effect for RRUs.

Local IPv6

Indicates the IPv6 address of the subject alternative name of a certificate. This parameter does not take effect for RRUs. This parameter is invalid in the old transmission model.
