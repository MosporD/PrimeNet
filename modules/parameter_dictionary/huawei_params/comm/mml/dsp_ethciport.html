Display Ethernet CI Port Status (DSP ETHCIPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an Ethernet CI port.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]When the status of the Ethernet CI port on a UMPTe/UMPTg/UMPTga board is displayed as down, all the statistical values related to the port, such as the number of received packets, are displayed as 0.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In BBU interconnection mode, the traffic statistics in the DSP ETHCIPORT command output are meaningless. To query the link traffic statistics in this case, run the DSP CTRLLNKSTAT command.

Example

To query the status of the Ethernet CI port with the parameters as follows: Slot No.: 6, Subboard Type: Base Board, Port No.: 0, run the following command:
DSP ETHCIPORT: SN=6, SBT=BASE_BOARD, PN=0;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the Ethernet CI port is located.

Subrack No.

Indicates the subrack number of the board where the Ethernet CI port is located.

Slot No.

Indicates the slot number of the board where the Ethernet CI port is located.

Subboard Type

Indicates the subboard type of the board where the Ethernet CI port is located.

Port No.

Indicates the number of the Ethernet CI port.

Port ID

Indicates the MTU on the Ethernet CI port.

Maximum Transmission Unit(byte)

Indicates the MTU on the Ethernet CI port. This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD. This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

ARP Proxy

Indicates whether to enable the proxy ARP function on the Ethernet CI port. This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD. This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

Topo Status

Indicates the topology mode on the infrastructure interconnection ports.

Port Status

Indicates the status of the Ethernet CI port.

Port Mode

Indicates the mode of a port on the Ethernet CI port.

Number of RX Packets(packet)

Indicates the number of packets received on the Ethernet CI port.

Number of RX Bytes(byte)

Indicates the number of bytes in the packets received on the Ethernet CI port.

Number of RX CRC Error Packets(packet)

Indicates the number of CRC error packets received on the Ethernet CI port.

RX Traffic(byte/s)

Indicates the receive rate on the Ethernet CI port.

Number of TX Packets(packet)

Indicates the number of packets transmitted on the Ethernet CI port.

Number of TX Bytes(byte)

Indicates the number of bytes in the packets transmitted on the Ethernet CI port.

TX Traffic(byte/s)

Indicates the transmit rate on the Ethernet CI port.

MAC Error Rate(per mill)

Indicates the MAC FER on the Ethernet CI port.

RX Broadcast Packet Traffic(packet/s)

Indicates the traffic volume of broadcast packets received on the Ethernet CI port.
