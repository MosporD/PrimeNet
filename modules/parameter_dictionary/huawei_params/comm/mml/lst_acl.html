List ACL Configuration (LST ACL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an ACL.

Note

None.

Parameters

ID Name Description
ACLID ACL ID

Meaning: Indicates the ID of the access control list (ACL) to which an access control rule belongs. An ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An ACL rule with an ACL ID ranging from 4000 to 4999 indicates a layer 2 rule based on the MAC layer information configured by users. An ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

GUI Value Range: 3000~4999,7000~7999

Unit: None

Actual Value Range: 3000~4999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The ID of an ACL that is manually configured must range from 3000 to 4999.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the ACL configuration, run the following command: 
LST ACL:;

Output Description

Field Description

ACL ID

Indicates the ID of the access control list (ACL) to which an access control rule belongs. An ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An ACL rule with an ACL ID ranging from 4000 to 4999 indicates a layer 2 rule based on the MAC layer information configured by users. An ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Description

Indicates the brief description of an ACL.

Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only users can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.

Auto Config Flag

Indicates whether an object is created by the system. The value MANUAL_CREATED means that the object is manually configured by users. The value AUTO_CREATED means that the object is created by the system.
