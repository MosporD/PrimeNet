Set Clock Synchronization Mode (SET CLKSYNCMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the clock synchronization mode of a BS, the GSM frame bit offset, the GSM Frame Sync Switch, the frame synchronization switch, the locked system clock source, the Enhanced SYSCLK failure check switch, the low-precision frame No. synchronization switch and the Major Standard Change Optimization Switch.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Setting LTE TDD and NR TDD to frequency synchronization mode will interrupt services.

  • If the current clock source is provided by an IEEE 1588 V2 clock link on a UTRPc port, changing the clock synchronization mode from frequency synchronization to time synchronization disconnects links carried over the port for about 3s.

  • When the clock synchronization mode is changed from frequency synchronization to time synchronization, if the current clock source is an IEEE1588 V2 clock, Clock Net Mode is set to UNICAST, and Profile Type is set to 1588V2, 1588V2_16.1 and G.8275.2, check whether IEEE1588 V2 time synchronization needs to be enabled hop by hop with bearer network engineers or whether the ATR or XXX switch needs to be turned on on the base station side. Otherwise, services will become unavailable.

  • The frame synchronization function applies to the Cloud BB that works in frequency synchronization mode. In addition, this function can be enabled only for an NE that connects to the clock source indirectly.

  • The frame synchronization function takes effect only when the system clock source is an IEEE 1588 V2 clock source or interconnection clock source.

  • The GSM frame synchronization switch must be turned off when an NE does not require time synchronization. Before turning on the GSM frame synchronization switch, plan the frame offset and TSC to avoid inter-cell interference.

  • In the backup of the first-level USU3910, the standby main control board in the BBU does not support the D-MIMO function.

  • In a multi-mode BS (excluding the D-MIMO scenarios), the system clock will not lock to Inter-sysclk.

  • The Enhanced SYSCLK Failure Check Switch parameter can be specified when only one reference clock source is configured.

  • When the clock synchronization mode of a BBU is frequency synchronization, the low-precision frame No. synchronization function cannot be enabled simultaneously with the functions of frame synchronization or CIoT frame No. synchronization.

  • The low-precision frame No. synchronization function can be used in CIoT frame No. synchronization. With this function enabled, the system frame No. (SFN) and hyper system frame No. (HSFN) are aligned when the initial time shift after the lock of the system clock is longer than 1s. This function applies only when the IP clock source is used in unicast networking mode and compliant with the IEEE 1588V2 or 1588V2_16.1 protocol.

  • Only the UMPT and LMPT support the function of low-precision frame No. synchronization.

  • In hybrid clock synchronization mode, Locked System Clock Source must be set to LOCAL.

  • In hybrid clock synchronization mode, Clock Working Mode can be set to AUTO, MANUAL, or FREE. When this parameter is set to MANUAL, Selected Clock Source, Clock Source No., and IP Clock Time Synchronization Mode must be set to IPCLK, AUTO, and OFF, respectively.

  • If the BBU is interconnected with the DCU and the clock reference source on the BBU side is set to PEERCLK, the clock synchronization mode on the BBU side supports only time synchronization.

  • Only the UMPT supports the loose time synchronization mode.

Parameters

ID Name Description
CLKSYNCMODE Clock Synchronization Mode

Meaning: Indicates the clock synchronization mode of a BS, which can be frequency synchronization or time synchronization.

GUI Value Range: FREQ(FREQ), TIME(TIME), HYBRID(HYBRID)

Unit: None

Actual Value Range: FREQ, TIME, HYBRID

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PROFILETYPE in the IPCLKLNK MO is set to G.8265.1, CLKSYNCMODE in the TASM MO must be set to FREQ or HYBRID.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If PROFILETYPE in the IPCLKLNK MO is set to G.8275.1, CLKSYNCMODE in the TASM MO must be set to TIME.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If IPMODE in the IPCLKLNK MO is set to IPV6, CLKSYNCMODE in the TASM MO must be set to FREQ.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If CLKSYNCMODE and MODE and CLKSRC in a TASM MO are set to TIME and MANUAL and IPCLK, respectively, SYNMODE must be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a TASM MO, if CLKSYNCMODE is set to TIME and LOOSETIME is set to ON, MODE cannot be set to AUTO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a TASM MO, if CLKSYNCMODE is set to TIME, LOOSETIME is set to ON, and MODE is set to MANUAL, CLKSRC must be set to IPCLK or PEERCLK.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Example 1: To set clock synchronization mode with parameters as follows:
clock synchronization mode: FREQ, run the following command:
SET CLKSYNCMODE: CLKSYNCMODE=FREQ;

Example 2: To set clock synchronization mode with parameters as follows:
clock synchronization mode: TIME, run the following command:
SET CLKSYNCMODE: CLKSYNCMODE=TIME;

Example 3: To set locked system clock source with parameters as follows:
locked system clock source: INTER_SYSCLK, run the following command:
SET CLKSYNCMODE: SYSCLKSRC=INTER_SYSCLK;

Example 4: To set frame synchronization switch with parameters as follows:
clock synchronization mode: FREQ, frame synchronization switch: ON, run the following command:
SET CLKSYNCMODE: CLKSYNCMODE=FREQ, FRAMESYNCSW=ON;

Example 5: To set loose time synchronization with parameters as follows:
clock synchronization mode: TIME, loose time synchronization: ON, run the following command:
SET CLKSYNCMODE: CLKSYNCMODE=TIME, LOOSETIME=ON;
