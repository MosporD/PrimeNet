Display Certificate Diagnosis Information (DSP CERTDIAG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query errors generated during certificate application, certificate update, and periodic CRL obtaining.

Note

A maximum of 120 records of diagnosis information can be displayed.

Parameters

ID Name Description
CERTTYPE Cert Type

Meaning: Indicates the certificate type.

GUI Value Range: DEVCERT(Device Certificate), CRL(CRL)

Unit: None

Actual Value Range: DEVCERT, CRL

MML Default Value: DEVCERT(Device Certificate)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Example 1: To query the certification diagnosis information with the parameters as follows: Cert Type: Device Certificate, run the following command:
DSP CERTDIAG:;
The result is shown as follows:
+++    0        2019-09-23 17:53:33
O&M    #54
%%DSP CERTDIAG:;%%
RETCODE = 0  Operation succeeded.

Display Certificate Diagnosis Information
-----------------------------------------
Diagnose Information                                                                                                                             

FileName: tst.pem                                                                                                                                
2019-09-23 17:47:20  Opr: request manually, Msg: IR, Server IP: 10.160.30.120, Err: 0x00009D23, Dsc: Receiving the response failed.              
2019-09-23 17:47:20  Opr: request manually, Msg: IR, Server IP: 10.160.30.120, Err: 0x00009DD6, Dsc: The request message fails to be transmitted.
(Number of results = 3)

Example 2: To query the certification diagnosis information with the parameters as follows: Cert Type: CRL, run the following command:
DSP CERTDIAG: CERTTYPE=CRL;
The result is shown as follows:

---    END

Output Description

Field Description

Diagnose Information

Indicates the diagnosis information.
