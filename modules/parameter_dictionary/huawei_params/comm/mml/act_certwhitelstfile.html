Activate the Digital Certificate Whitelist File (ACT CERTWHITELSTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to activate the digital certificate whitelist file.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only one digital certificate whitelist file can be activated. If the digital certificate whitelist has been activated for the current base station and then the ACT CERTWHITELSTFILE command is executed, the original digital certificate whitelist file will be overwritten after the successful activation, and the latest activated certificate whitelist file will be used for check during IKE negotiation.

  • Digital certificate whitelist files with the same file name cannot be activated and downloaded at the same time.

  • When running the ACT CERTWHITELSTFILE command to activate the digital certificate whitelist file, you are not advised to perform other operations on files.

  • A maximum of 40000 valid digital certificate whitelist records can be activated for a base station. If the number of whitelist records exceeds 40000 in a digital certificate whitelist file or there are same whitelist records in a digital certificate whitelist file, execution of the ACT CERTWHITELSTFILE command will fail.

  • When the INTEGRITYCHECKSW is set to ON and the number of whitelist records is not zero, all IKEs that use cert to negotiate will reauthenticate if the digital certificate whitelist file activated successfully.

Parameters

ID Name Description
CERTWHITELSTFILENAME Digital Certificate Whitelist File Name

Meaning: Indicates the digital certificate whitelist file name. The file name cannot contain any one of these characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotes("), left angle bracket (<), right angle bracket (>), less-than sign (<), greater-than sign (>), and vertical slash (|). Only a .gz (case-insensitive) file is supported currently.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
INTEGRITYCHECKSW Integrity Check Switch

Meaning: Indicates the integrity check switch for a digital certificate whitelist file. If this parameter is set to ON, you can run the ACT CERTWHITELSTFILE command to successfully activate the digital certificate whitelist file only when the integrity check password is correct. If this parameter is set to OFF, integrity check will not be performed when you run the ACT CERTWHITELSTFILE command to activate the digital certificate whitelist. By default, integrity check is not performed in board reset scenarios where the digital certificate whitelist is automatically activated.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(On)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FILEPWD Integrity Check Password

Meaning: Indicates the password for integrity check on a digital certificate whitelist file.

GUI Value Range: 8~32 characters

Unit: None

Actual Value Range: 8~32 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when INTEGRITYCHECKSW is set to ON.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To activate the digital certificate whitelist file with the parameters as follows: Digital Certificate Whitelist File Name: certwhitelist.gz, Integrity Check Switch: ON, Integrity Check Password: *****, run the following command:
ACT CERTWHITELSTFILE: CERTWHITELSTFILENAME="certwhitelist.gz", INTEGRITYCHECKSW=ON, FILEPWD="*****";
