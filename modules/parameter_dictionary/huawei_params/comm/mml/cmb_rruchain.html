Combine RRU Chain/Ring (CMB RRUCHAIN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to combine two RRU chains into a cold backup RRU ring. The cold backup mode is described in the backup mode parameter of the MOD RRUCHAIN command.

To improve the reliability of RRU chains, use a fiber optic cable to connect two RRUs on the tails of two chains. Then, run this command to combine them into a ring.

When two RRU chains are combined successfully, the number of the first chain is used as the number of the newly created ring by default.

If the original two RRU chains have no breakpoints, the new ring has no breakpoint.

If only one RRU chain has breakpoints, breakpoints 1 and 2 of the new ring coincide.

If both the original RRU chains have breakpoints, the new ring has two breakpoints. The position of breakpoint 1 is that of the breakpoint on the first RRU chain. The position of breakpoint 2 is the level of the new ring minus the position of the breakpoint on the second RRU chain.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The two RRU chains to be combined cannot have the same chain number, and their topology types should only be CHAIN.

  • The total number of board levels on the two RRU chains should not exceed 21 before combination.

  • Before combining two chains, run the DSP CPRILBR command to query the CPRI line rate modes and the CPRI line rates of the two chains. If the two chains have different CPRI line rates or modes, the first old chain CPRI rate or mode will be as the result of the new ring. After combining two chains, run the LST RRUCHAIN command to query the current fixed CPRI line rate and run the DSP CPRILBR command to query the current running CPRI line rate. If the result of fixed mode is not up to the expectation, set the appropriate CPRI line rate by the MOD RRUCHAIN command again. If the result of auto mode is not up to the expectation, run the STR CPRILBRNEG command to implement rate negotiation.

  • In a ring topology, neither multimode RRUs nor single-mode RRUs working in a mode different from the baseband processing board can be configured.

Example

To combine two RRU chains numbered 0 and 1, run the following command:
CMB RRUCHAIN: RCN1=0, RCN2=1;
