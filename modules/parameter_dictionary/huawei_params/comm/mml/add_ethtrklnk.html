Add Ethernet Trunk Member (ADD ETHTRKLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an Ethernet trunk link in the Ethernet trunk.

Note

  • Before running this command, ensure that the parent Ethernet trunk is configured.

  • If a port added to an Ethernet trunk works in AUTO negotiation mode, ensure that the port with a higher transmission rate has a higher priority.

  • Only four member ports in an Ethernet trunk on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 can take effect. Only two member ports in an Ethernet trunk on other boards can take effect.

  • Before adding an Ethernet trunk link, ensure that the associated Ethernet port has not joined any other Ethernet trunk.

  • All links contained in one Ethernet trunk must have the same rate and duplex mode. Therefore, before adding an Ethernet trunk link, ensure that its rate and duplex mode that take effect are the same as those of other links in the Ethernet trunk.

  • Before adding an Ethernet trunk link, ensure that the associated Ethernet trunk has only one primary port. The associated Ethernet trunk uses the MAC address which belongs to the Ethernet port configured as primary port.

  • Before adding an Ethernet trunk link to an Ethernet trunk as a secondary port, ensure that the Ethernet trunk has already been configured with a primary port.

  • System specifications: If the WMPT/UMPT/LMPT/UMDU/GTMUb/GTMUc is the main control board, a maximum of 32 Ethernet trunk links can be configured.

  • Board specifications: A maximum of 2 Ethernet trunk links can be configured on a WMPT/UMPTa/UMPTb/UMDU/LMPT. A maximum of 4 Ethernet trunk links can be configured on a UMPTe/UMPTg/UMPTga. A maximum of 6 Ethernet trunk links can be configured on a UTRPc. A maximum of 2 Ethernet trunk links can be configured on a UTRP (subboard type: UEOC). A maximum of 4 Ethernet trunk links can be configured on a UTRP (subboard type: UQEC). A maximum of 4 Ethernet trunk links can be configured on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • An ETHTRKLNK MO cannot be configured when an ETHPORT MO has a default port transmission resource group, to configure an ETHTRKLNK MO, remove the default port transmission resource group and algorithm. This limitation does not take effect on an adaptive port transmission resource group.

Example

To add a member port to an Ethernet trunk with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Trunk No.: 0, Port No.: 0, Port Priority: 255, Master Flag: "YES", run the following command: 
ADD ETHTRKLNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, TN=0, PN=0, PRI=255, FLAG=YES;
