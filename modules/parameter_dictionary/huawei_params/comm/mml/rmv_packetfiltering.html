Remove Packet Filtering Policy (RMV PACKETFILTERING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a packet filtering policy object.

Note

  • When a packet filtering policy object is removed, the ACL rules automatically created by the packet filtering policy object are removed. The corresponding ACL can be removed only when all these ACL rules are automatically removed.

  • When a packet filtering policy object is removed, if the ACL and ACL6 on which the packet filtering policy object depends does not have a bearer object (packet filtering policy, IPsec policy group binding, or IPv6 security policy group binding) on the board where the packet filtering policy object has taken effect, the ACL will not take effect on the board.

  • [NodeB]When a packet filtering policy object is removed from a UTRP (subboard type: UEOC/UQEC) by running this command, and the ACL is referenced only by this packet filtering policy object, the effective ACL rules in this ACL will automatically become ineffective.

Parameters

ID Name Description
PACKETFILTERINGID Packet Filtering ID

Meaning: Indicates the ID of the packet filtering policy.

GUI Value Range: 0~59

Unit: None

Actual Value Range: 0~59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove a packet filtering policy MO with the parameters as follows: Packet Filtering ID: 3, run the following command: 
RMV PACKETFILTERING: PACKETFILTERINGID=3;
