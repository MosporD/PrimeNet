List Transmission Resource Group Configuration (LST RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of all transmission resource groups.

Note

None.

Parameters

None.

Example

To list the configuration of all transmission resource groups, run the following command:
LST RSCGRP:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a transmission resource group is established.

Subrack No.

Indicates the number of the subrack that houses the board where a transmission resource group is established.

Slot No.

Indicates the number of the slot corresponding to the board where a transmission resource group is established.

Transmission Resource Group Bear Type

Indicates the bearer type of the transmission group. The LTE and NR do not support ATM.

Subboard Type

Indicates the type of sub-board on the transmission group. The LTE and NR do not support UNCHANNELLED_COVERBOARD.

Bearing Port Type

Indicates the type of port where a transmission resource group is carried. The LTE and NR do not support STM1, IMA, UNI, or FRAATM.

Bearing Port No.

Indicates the number of the port where the transmission resource group is configured.

Transmission Resource Group ID

Indicates the ID of a transmission resource group. When you use an MML command to add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates a transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, or an uplink tunnel on the MAE-Deployment, if the default transmission resource group does not exist, the system automatically creates a transmission resource group with Transmission Resource Group ID set to AUTOPORT(Autoport Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group.

Rate Unit

Indicates the rate unit of the TX bandwidth, RX bandwidth, TX CIR, RX CIR, TX PIR and RX PIR of the transmission resource group. The LTE and NR do not support CELL/S.

Tx Bandwidth

Indicates the maximum uplink bandwidth of a transmission resource group at the MAC layer when the transmission resource group is carried over IP. This parameter value is used as the uplink transport admission bandwidth and TX traffic shaping bandwidth. The minimum rate supported by the UMPTa, UMPTb, UMDU, GTMUb or GTMUc is 64 kbit/s. The LMPT can be configured with a maximum of 360 Mbit/s TX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the transmission resource group that is carried on the PPP link.

Rx Bandwidth

Indicates the RX bandwidth of a transmission resource group. To LTE, this parameter value is also used as the downlink transport admission bandwidth. The LMPT can be configured with a maximum of 540 Mbit/s RX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s RX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s RX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s RX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s RX bandwidth. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX bandwidth. The value of RX bandwidth is set to the maximum value of RX bandwidth supported by the board when it bigger than the maximum one.

TX Committed Burst Size(kbit)

Indicates the TX committed burst size of a transmission resource group. The LMPT can be configured with a maximum of 400 Mbit/s TX committed burst size. The WMPT can be configured with a maximum of 600 Mbit/s TX committed burst size. The WMPT, GTMUb or GTMUc can be configured with a maximum of 600 Mbit/s TX committed burst size. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX committed burst size. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX committed burst size. The UMPTg can be configured with a maximum of 25 Gbit/s TX committed burst size. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX committed burst size. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX committed burst size. The value of TX committed burst size is set to the maximum value of TX committed burst size supported by the board when it bigger than the maximum one.

TX Excessive Burst Size(kbit)

Indicates the TX excessive burst size of a transmission resource group. The LMPT can be configured with a maximum of 450 Mbit/s TX excessive burst size. The WMPT, GTMUb or GTMUc can be configured with a maximum of 600 Mbit/s TX excessive burst size. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX excessive burst size. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX excessive burst size. The UMPTg can be configured with a maximum of 25 Gbit/s TX excessive burst size. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX excessive burst size. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX excessive burst size. The value of TX excessive burst size is set to the maximum value of TX excessive burst size supported by the board when it bigger than the maximum one.

Operator ID

Indicates the index of the operator. This parameter is used to differentiate between operators. This parameter is reserved for future extension and does not take effect currently.

Scheduling Weight

Indicates the scheduling weight of a transmission resource group. This parameter is used in calculating the bandwidth scheduled to a resource group, which helps achieve the user admission control.

TX Committed Information Rate

Indicates the transmit CIR of the transmission resource group. The LMPT can be configured with a maximum of 360 Mbit/s TX committed information rate. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX committed information rate. The GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX committed information rate. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX committed information rate. The UMPTg can be configured with a maximum of 25 Gbit/s TX committed information rate. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX committed information rate. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX committed information rate. The value of TX committed information rate is set to the maximum value of TX committed information rate supported by the board when it bigger than the maximum one.

RX Committed Information Rate

Indicates the receive CIR of the transmission resource group. This parameter value is used as the downlink transport admission bandwidth for non-flow-control services. The LMPT can be configured with a maximum of 540 Mbit/s RX committed information rate. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s RX committed information rate. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s RX committed information rate. The UMPTg can be configured with a maximum of 25 Gbit/s RX committed information rate. The UBBPe (excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX committed information rate. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX committed information rate. The value of RX committed information rate is set to the maximum value of RX committed information rate supported by the board when it bigger than the maximum one. Only the LTE supports this function currently.

The value of TX peak information rate is set to the maximum value of TX peak information rate supported by the board when it bigger than the maximum one.

The LMPT can be configured with a maximum of 540 Mbit/s RX peak information rate. The UMPTa, UMPTb, UMDU or URTPc can be configured with a maximum of 1 Gbit/s RX peak information rate. The value of RX peak information rate is set to the maximum value of RX peak information rate supported by the board when it bigger than the maximum one. Only the LTE supports this function currently.

TX Peak Burst Size(kbit)

Indicates the size of the peak burst transmitted from the transmission resource group. The LMPT can be configured with a maximum of 540 Mbit/s TX peak burst size. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX peak burst size. The GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX peak burst size.
