Set Overload Control Algorithm (SET TOLCALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the parameters for the overload control algorithm.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eGBTS,eNodeB]When TRMULOLCSWITCH in the TOLCALG MO is set to ON, TRMULOLCRELTH must be greater than TRMULLDRTRGTH of the TLDRALG MO.

  • [Co-MPT,eGBTS,eNodeB]When TRMDLOLCSWITCH in the TOLCALG MO is set to ON, TRMDLOLCRELTH must be greater than TRMDLLDRTRGTH of the TLDRALG MO.

  • [Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

Parameters

ID Name Description
TRMULOLCSWITCH Uplink OLC Algorithm Switch

Meaning: Indicates the UL Over Load Control (OLC) algorithm switch. When this switch is set to ON, bandwidth of the services with a low priority will be released to guarantee the QoS of the services with a high priority when TX bandwidth changes or during the overload caused by non-flow-control services.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship:

-Others:

  • [Co-MPT, eGBTS, eNodeB]When TRMULOLCSWITCH in the TOLCALG MO is set to ON, the QoS of high-priority services can be guaranteed in the case of transport overload in the uplink. When TRMULOLCSWITCH in the TOLCALG MO is set to OFF, the QoS of high-priority services cannot be guaranteed in the case of transport overload in the uplink.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the quality of high-priority services is guaranteed when UL transport is overloaded.

If this parameter is set to OFF, the quality of high-priority services is not guaranteed when UL transport is overloaded.

Applicable Mode: G, L
TRMDLOLCSWITCH Downlink OLC Algorithm Switch

Meaning: Indicates the UL Over Load Control (OLC) algorithm switch. When this switch is set to ON, bandwidth of the services with a low priority will be released to guarantee the QoS of the services with a high priority when TX bandwidth changes or during the overload caused by non-flow-control services.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship:

-Others:

  • [Co-MPT, eGBTS, eNodeB]If TRMDLOLCSWITCH in the TOLCALG MO is set to ON, the quality of high-priority services are ensured. If TRMDLOLCSWITCH in the TOLCALG MO is set to OFF, the quality of high-priority services may deteriorate in the case of transport overload in the downlink.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the quality of high-priority services is guaranteed when the transport network is overloaded with downlink services.

If this parameter is set to OFF, the quality of high-priority services is not guaranteed when the transport network is overloaded with downlink services.

Applicable Mode: G, L
TRMULOLCTRIGTH Uplink OLC Trigger Threshold

Meaning: Indicates the threshold for triggering the UL OLC. When the UL bandwidth usage reaches the threshold, low-priority services are removed to guarantee the quality of high-priority services.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 95

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]In a TOLCALG MO, TRMULOLCTRIGTH must be greater than TRMULOLCRELTH.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value indicates a lower probability of triggering the UL transport overload algorithm, ensuring the bandwidth for fewer high-priority services, and releasing fewer low-priority services.

A smaller value indicates a higher probability of triggering the UL transport overload algorithm, ensuring the bandwidth for more high-priority services, and releasing more low-priority services.

Applicable Mode: G, L
TRMULOLCRELTH Uplink OLC Release Threshold

Meaning: Indicates the threshold for clearing the UL OLC. When the UL bandwidth usage is below this threshold, user services are no longer removed.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 90

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]In a TOLCALG MO, TRMULOLCTRIGTH must be greater than TRMULOLCRELTH.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value indicates a smaller number of services released by OLC but a higher probability of ping-pong OLC actions. In the case of frequent OLC actions, the transport load status is frequently switched between overload and overload relief.

A smaller value indicates a larger number of services released by OLC but a lower probability of ping-pong OLC actions. In the case of less frequent OLC actions, the transport load status is relatively stable.

Applicable Mode: G, L

Meaning: Indicates the number of released services during an OLC action period.

GUI Value Range: 0~100

Example

To set the overload control algorithm with the parameters as follows: Uplink OLC Algorithm Switch: On, Downlink OLC Algorithm Switch: On, run the following command:
SET TOLCALG: TRMULOLCSWITCH=ON, TRMDLOLCSWITCH=ON;
