Add Control Link (ADD CTRLLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a control link. The control link is a logical concept. The physical entity of the control link is the topology between the interconnected BBUs.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before you add a control link, the local subrack or the upper-level subrack must have been configured.

  • In this command, the local node refers to the leaf BBU and the upper-level node refers to the root BBU. In UCIU+UMPT interconnection scenarios, the root BBU is the BBU housing the UCIU. In UMPT+UMPT interconnection scenarios, if the UMPT boards are connected using an SFP electrical cable, the root BBU is the BBU connected to the cable end with a Master color-coding label; if the UMPT boards are connected using single-fiber bidirectional optical modules, the root BBU is the BBU where the optical module with a blue puller is installed in the interconnection port.

  • In a multimode base station, this command must be executed on all modes to ensure that all control links have the same configuration.

  • When the upper-level node is a UCIU, the value of the Upper Port No. parameter must range from 0 to 4. When the upper-level node is a UMPT, the value must be 8. When the upper-level node is a UMDU, the value must be 6.

  • Check whether the configuration is consistent with the network plan. When a RAT is served by two interconnected BBUs, incorrect configuration of the relationship between the upper- and lower-level nodes on the control link may lead to OM channel disconnection and service interruption.

GUI Value Range: 0~7

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If AT is set to PEERPORT and TT is set to CHAIN, and LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively in an RRUCHAIN MO, then there must be a CTRLLNK MO with CN equal to LCN and SRN equal to LSRN or with UPCN equal to LCN and UPSRN equal to LSRN.

Example

To add a control link with the parameters as follows: Local Link No.: 0, Local Cabinet No.: 0, Local Subrack No.: 1, Local Slot No.: 7, Upper Cabinet No.: 0, Upper Subrack No.: 0, Upper Slot No.: 5, Upper Port No.: 0, run the following command: 
ADD CTRLLNK: LN=0, CN=0, SRN=1, SN=7, UPCN=0, UPSRN=0, UPSN=5, UPPT=0;
