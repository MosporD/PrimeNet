Start CPRI Line Bit Rate Negotiation (STR CPRILBRNEG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start negotiation on the common public radio interface (CPRI) line rate of a specified chain/ring. If the link cannot recover for 5 minutes or a longer time after the topology changes, try to recover the link by running this command.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Do not initiate the negotiation when breakpoints exist.

  • If the current CPRI line rate is not the optimum one, the execution of this command will cause link disconnection, interrupting services.

  • For a multi-mode BS in CPRI MUX/eCPRI MUX, this command cannot be executed on the RRU chain/ring on the mode whose data is aggregated. If this command is executed on the mode that aggregates data, services of the peer mode will be interrupted.

  • Run the DSP CPRILBR command to query the test result.

Parameters

ID Name Description
RCN Chain No.

Meaning: Indicates the ID of the RRU chain/ring. It uniquely identifies a chain within a base station.

GUI Value Range: 0~249

Unit: None

Actual Value Range: 0~249

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To start the CPRI line bit rate negotiation, Chain No.: 1, run the following command:
STR CPRILBRNEG: RCN=1;
