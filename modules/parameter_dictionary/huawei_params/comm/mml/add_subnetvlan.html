Add Subnet VLAN Mapping (ADD SUBNETVLAN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a subnet VLAN mapping relationship.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Current, this command can be used to add mapping between only a source IP addresses and a VLAN.

  • The subnet mask of the IP address must be 32 bits.

  • Either VLANMAP or SUBNETVLAN can be configured at one time. You need to remove the VLANMAP before adding a SUBNETVLAN.

  • Board specifications: A maximum of 128 SUBNETVLANs can be configured on a WMPT/UMPT/UMDU/LMPT/UTRPc/UCCU/UTRP (subboard type: UEOC/UQEC/UIEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • System specifications: If the WMPT/LMPT/UMPT/UMDU is the main control board, a maximum of 128 SUBNETVLANs can be configured.

  • When Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, the VLAN priority mappings are configured using the SET DSCPMAP command. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, the VLAN priority mappings are configured using the DSCP2PCPMAP MO with DSCP-to-PCP Mapping ID being 0.

  • This operation may interrupt the services or OM channels. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
IP IP Address

Meaning: Indicates the source IP address used for mapping the VLAN.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the SUBNETVLAN MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MASK Mask

Meaning: Indicates the subnet mask of the source IP address used for mapping the VLAN.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: 255.255.255.255

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MASK in the SUBNETVLAN MO must be 255.255.255.255.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VLANID VLAN ID

Meaning: Indicates the VLAN ID in the VLAN tag.

GUI Value Range: 1~4094

Unit: None

Actual Value Range: 1~4094

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To add a subnet VLAN mapping with the parameters as follows: IP Address: 10.1.1.1, Mask: 255.255.255.255, VLAN ID: 1024, run the following command:
ADD SUBNETVLAN: IP="10.1.1.1", MASK="255.255.255.255", VLANID=1024;
