Remove E1/T1 Bear Mode (RMV E1T1BEAR)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove an E1/T1 bearing mode of a specified board.

Note

[Co-MPT,NodeB]For a WMPT and UTRP board (subboard type is UAEC, excluding the UTRPa), the board retains its original E1/T1 bearing mode that has taken effect the last time after the execution of this command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet housing the board where the bearing mode of an E1/T1 port is configured.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SRN Subrack No.

Meaning: Indicates the number of the subrack housing the board where the bearing mode of an E1/T1 port is configured.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SN Slot No.

Meaning: Indicates the number of the slot housing the board where the bearing mode of an E1/T1 port is configured.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove an E1/T1 bearing mode of a board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command:
RMV E1T1BEAR: CN=0, SRN=0, SN=6;
