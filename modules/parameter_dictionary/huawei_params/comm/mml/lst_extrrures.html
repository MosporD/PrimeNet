List Shared External RRU Resources Configuration (LST EXTRRURES)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of shared external RRU resources.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of shared external RRU resources.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of shared external RRU resources.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N
SN Slot No.

Meaning: Indicates the slot number of shared external RRU resources.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

Example

Example 1: To query the configuration of the Shared External RRU Resources, run the following command:
LST EXTRRURES:;
The result is shown as follows:
+++    0        2017-12-15 00:16:50
O&M    #103
%%LST EXTRRURES:;%%
RETCODE = 0  Operation succeeded.

List Shared External RRU Resources Configuration
------------------------------------------------

0            60           0         0               NewRRU           NULL      
0            61           0         0               EXTRRU           NULL

Example 2: To query the configuration of the Shared External RRU Resources, in slot 0 of subrack 60 in cabinet 0, run the following command:
LST EXTRRURES: CN=0, SRN=60, SN=0;
The result is shown as follows:

O&M    #47
%%LST EXTRRURES: CN=0, SRN=60, SN=0;%%

---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of shared external RRU resources.

Subrack No.

Indicates the subrack number of shared external RRU resources.

Slot No.

Indicates the slot number of shared external RRU resources.

RCS Server No.

Indicates the number of the RCS server where an RRU entity providing the shared external RRU resources is located.

Server RRU Name

Indicates the name of an RRU entity providing the shared external RRU resources. This parameter must be set to the name of this RRU entity configured on the RCS server that provides the RRU.

User Label

Indicates the user-defined information about shared external RRU resources.
