Clear Dynamic MAC Entry (CLR DYNAMICMAC)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to clear one specific dynamic MAC entry, effective entries in the dynamic MAC forwarding table on a specified switch port, or effective entries in the dynamic MAC forwarding tables on all switch ports.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eNodeB]If an entry in a dynamic MAC forwarding table is removed, the downlink relay data that relies on this entry will be discarded because they cannot be forwarded. The data forwarding recovers until the switching relationship is learned through the uplink packets. Therefore, exercise care when executing this command.

Parameters

ID Name Description
SWPORTIDX Switch Port Index

Meaning: Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
DSTMAC Destination MAC Address

Meaning: Indicates the destination MAC address of an entry in a MAC forwarding table. The format must be "XXXX-XXXX-XXXX".

GUI Value Range: 14 characters

Unit: None

Actual Value Range: 14 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB]The DSTMAC parameters in any two STATICMACITEM MOs must be set to different values.
  • [Co-MPT, eNodeB]DSTMAC in the STATICMACITEM MO cannot be set to any one of the following values: broadcast MAC address (FFFF-FFFF-FFFF), multicast MAC address (the first left byte in the Destination Address field is an odd number), and default MAC address (0000-0000-0000).

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To clear dynamic mac item with the parameters as follows: Switch Port Index: 1, Destination MAC Address: 2014-0A26-1024, run the following command: 
CLR DYNAMICMAC: SWPORTIDX=1, DSTMAC="2014-0A26-1024";
