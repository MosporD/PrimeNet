Set Frequency Bandwidth (SET FREQBWH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the minimum frequency spacing in the UO and GU scenarios. If the bandwidth resources of the operator are limited, smaller frequency spacing (than normal bandwidth) can be set in the UO and GU scenarios during the network planning. In addition, the RRU or RFU can work with small frequency spacing after the effective frequency bandwidth of the RRU or RFU is set, thus achieving the optimal performance in the case of small frequency spacing.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the modified frequency bandwidth is greater than the center frequency spacing of two cells, the air interface spectrums of different cells overlap, the service performance deteriorates, and ALM-28210 Frequency Separation Configuration Mismatch is reported.

  • This command applies only to UMTS.

  • After the RF module works, if Frequency Min Bandwidth is set to 5000, the minimum effective carrier bandwidth of the RF module is 5000. However, after the RF module is reset, the RF module may operate at the default manufacturing Frequency Min Bandwidth.

  • [Co-MPT,NodeB,eGBTS]The function may have an impact on the performance KPIs while saving the bandwidth, and it must be configured during network planning. It is not recommended when the bandwidth resources are sufficient.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU or RFU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CN in the RRU MO is set to 0~15.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the RRU or RFU is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of SRN in the RRU MO ranges from 60 to 254. The value of SRN in the RFU MO ranges from 4 to 5.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO where the RFU MO is located is set to BTS3900AL, the value of SN in the RFU MO ranges from 0 to 8. Otherwise, the value of SN in the RFU MO ranges from 0 to 5. When the value of SRN in the RRU MO is set to 60, SN in the RRU MO ranges from 0 to 5. When the value of SRN in the RRU MO ranges from 61 to 254, the value of SN in the RRU MO ranges from 0 to 3.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the RRU MO is set to a value greater than 0 and RT in the RRU MO is not set to MPRF, SRN in the RRU MO must be set to 60, and TYPE in the CABINET MO where the RRU MO is located must be set to RFC5906 or IFS5906.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
FMBWH Frequency Min Bandwidth

Meaning: Indicates the minimum effective bandwidth of the carrier. This parameter takes effect only to UMTS.

GUI Value Range: 5000, 4800, 4600, 4400, 4200, 4000, 3800

Unit: kHz

Actual Value Range: 5000, 4800, 4600, 4400, 4200, 4000, 3800

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the minimum frequency spacing with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, Frequency Min Bandwidth: 5000, run the following command:
SET FREQBWH: CN=0, SRN=60, SN=0, FMBWH=5000;
