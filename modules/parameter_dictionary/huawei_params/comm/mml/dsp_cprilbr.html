Display CPRI Line Bit Rate (DSP CPRILBR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the current line rate of the specified chain/ring and the maximum line rates of the remote equipment controller (REC) and each remote equipment (RE).

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]For a trunk chain, the maximum bit rates of the BBP ports are displayed in the ascending order of the logical port number of the chain. The following values indicate the maximum bit rates of board ports which connect to the BBP ports in the same order. If the connection information cannot be obtained, the values of Port No., Subport No., and Max bit rate of the board are displayed as NULL.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The line rates of all UBBPei ports must be the same due to the hardware capability limitations. If the line rate of a UBBPei port is set to a fixed rate, all the UBBPei ports work at the fixed rate.

  • [Co-MPT,NodeB,eNodeB,gNodeB]In a separate-MPT base station deployed with CPRI MUX, when the converged board is an LBBP or WBBP and the CPRI line rates of the ports connecting to a trunk chain on the converging party are set to AUTO:

    - If the converging board is not a UBBPei, the CPRI line rates must not exceed 9.8 Gbit/s.

    - If the converging board is a UBBPei, the CPRI line rates must not exceed 39.2 Gbit/s.

    If links cannot be set up for the associated boards or links cannot work at the expected CPRI line rate, a negotiation for the CPRI line rate should be manually started. For details, see the help of the STR CPRILBRNEG command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If multiple modes of a separate-MPT base station share an RMU, the chains/rings connecting to the RMU work at the same line rate as the chain/ring with the maximum number of board cascading levels. If links cannot be set up for the associated boards or links cannot work at the expected CPRI line rate, run the STR CPRILBRNEG command to initiate a CPRI line rate negotiation.

  • [Co-MPT,NodeB,eNodeB,gNodeB]In auto-negotiation mode, the settings of the user-defined rate negotiation switch and the bit rate set do not take effect immediately after they are modified. The settings take effect from the next rate negotiation. To make the settings take effect immediately, you can manually initiate a negotiation. For details, see the help of the STR CPRILBRNEG command.

Output Description

Field Description

Current line bit rate

Indicates the current Common Public Radio Interface (CPRI) line rate of the RRU chain/ring.

Current head line bit rate

Indicates the current CPRI line rate at the head of the RRU chain/ring. In auto-negotiation mode, the rate specified by this parameter is the optimal one among the rate set supported by this port, the rate set supported by the RRU/RFU/CXU/AAS, and the rate set for automatic rate negotiation.

Current head negotiation status

Indicates the negotiation state of the CPRI port, which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value NOTREADY(Not Ready) indicates that the rate negotiation has not been started. The value NEGOTIATING(Negotiating) indicates that the rate is being negotiated. The value NEGOTIATED(Negotiated) indicates that the rate negotiation is complete. The value TIMEOUT(Timeout) indicates that the rate negotiation timed out due to a software or hardware fault during the negotiation. The value USERCONFIG(USERCONFIG) indicates that the rate is configured by users and does not support negotiation.

Current tail line bit rate

Indicates the current CPRI line rate at the tail of the RRU chain/ring. In auto-negotiation mode, the rate specified by this parameter is the optimal one among the rate set supported by this port, the rate set supported by the RRU/RFU/CXU/AAS, and the rate set for automatic rate negotiation.

Current tail negotiation status

Indicates the negotiation state at the tail of the CPRI ring, which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value NOTREADY(Not Ready) indicates that rate negotiation has not been started. The value NEGOTIATING(Negotiating) indicates that the rate is being negotiated. The value NEGOTIATED(Negotiated) indicates that the rate negotiation is complete. The value TIMEOUT(Timeout) indicates that the rate negotiation timed out due to a software or hardware fault during the negotiation. The value USERCONFIG(User Configured) indicates that the rate is configured by users and does not support negotiation.

Cabinet No.

Indicates the cabinet number.

Subrack No.

Indicates the subrack number.

Slot No.

Indicates the slot number.

Node

Indicates the number of an RRU/RFU/CXU/AAS on the RRU chain/ring. The RRUs/RFUs/CXUs/AASs are numbered from 0 in ascending order. The value Head indicates the port on the baseband processing board connecting to the first RRU/RFU/CXU/AAS on the RRU chain/ring. The value Tail indicates the port on the baseband processing board connecting to the last board on the RRU chain/ring.

Max bit rate

Indicates the maximum bit rate at the Common Public Radio Interface (CPRI) port. If the maximum bit rate is NULL, the RF module or baseband processing board does not support the rate negotiation, or the rate negotiation fails. If the maximum bit rates of two ports on the RRU/RFU are the same, only one rate is displayed. When the maximum bit rates of two ports on the RRU/RFU are different, two rates are displayed.

Multirate cascading capability

Indicates the capability of multirate cascading. SUPPORTED indicates two ports of the RF module can work at different rates.

Current port 1 line bit rate

Indicates the current CPRI line rate at port 1 of the RRU trunk chain.

Current port 1 negotiation status

Indicates the negotiation state at port 1 of the CPRI trunk chain which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value NOTREADY(Not Ready) indicates that rate negotiation has not been started. The value NEGOTIATING(Negotiating) indicates that the rate is being negotiated. The value NEGOTIATED(Negotiated) indicates that the rate negotiation is complete. The value TIMEOUT(Timeout) indicates that the rate negotiation timed out due to a software or hardware fault during the negotiation. The value USERCONFIG(User Configured) indicates that rate is configured by users and does not support negotiation.

Current port 2 line bit rate

Indicates the current CPRI line rate at port 2 of the RRU trunk chain.

Current port 2 negotiation status

Indicates the negotiation state at port 2 of the CPRI trunk chain which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value NOTREADY(Not Ready) indicates that rate negotiation has not been started. The value NEGOTIATING(Negotiating) indicates that the rate is being negotiated. The value NEGOTIATED(Negotiated) indicates that the rate negotiation is complete. The value TIMEOUT(Timeout) indicates that the rate negotiation timed out due to a software or hardware fault during the negotiation. The value USERCONFIG(User Configured) indicates that rate is configured by users and does not support negotiation.

Indicates the current CPRI line rate at port 3 of the RRU trunk chain.

Current port 3 negotiation status

Indicates the negotiation state at port 3 of the CPRI trunk chain which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value USERCONFIG(User Configured) indicates that rate is configured by users and does not support negotiation.

Current port 4 line bit rate

Indicates the current CPRI line rate at port 4 of the RRU trunk chain.

Current port 4 negotiation status

Indicates the negotiation state at port 4 of the CPRI trunk chain which can be NOTREADY(Not Ready), NEGOTIATING(Negotiating), NEGOTIATED(Negotiated), TIMEOUT(Timeout), or USERCONFIG(User Configured). The value NOTREADY(Not Ready) indicates that rate negotiation has not been started. The value NEGOTIATING(Negotiating) indicates that the rate is being negotiated. The value NEGOTIATED(Negotiated) indicates that the rate negotiation is complete. The value TIMEOUT(Timeout) indicates that the rate negotiation timed out due to a software or hardware fault during the negotiation. The value USERCONFIG(User Configured) indicates that rate is configured by users and does not support negotiation.

Port No.

Indicates the port number of the node on a CPRI link. The value NULL indicates that obtaining the port number fails.

Subport No.

Indicates the sub-port number of the node on a CPRI link. The value NULL indicates that there are no subport on the connected port.
