Display Uplink Flow Control Para (DSP ULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the effective settings of uplink flow control parameters.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [Co-MPT,NodeB,eGBTS]When the Port Type parameter is set to LOOPINT(Loop Interface), the command output displays the settings of the uplink flow control parameters for boards that provide Ethernet ports.

  • [Co-MPT,NodeB,eGBTS]Only the effective settings of uplink flow control parameters for a WMPT/UMPT/UMDU/UTRPc/UTRP board can be queried using this command.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet housing the board on whose port the UL flow control algorithm is configured.

Subrack No.

Indicates the number of the subrack housing the board on whose port the UL flow control algorithm is configured.

Slot No.

Indicates the number of the slot holding the board on whose port the UL flow control algorithm is configured.

Subboard Type

Indicates the type of sub-board on whose port the UL flow control algorithm is configured.

Bear Type

Indicates the bearer type of the physical port on which the UL flow control algorithm is configured. This parameter can be set to ATM or IP.

Port Type

Indicates the type of port where the UL flow control algorithm is configured.

Port No.

Indicates the number of the port where the UL flow control algorithm is configured.

BW Adjust Protection Switch

Indicates whether to adjust the available UL bandwidth. When this parameter is set to ON, the BS stops adjusting the available UL bandwidth of the physical port if the bit error rate (BER) on the transmission line exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

Congestion Ctrl Switch

Indicates whether to perform congestion control. When this switch is turned on, the BS lowers the TX rate if the BS detects that links experience transmission delay or packet loss.

Min UL Avail Bandwidth of Logical Port(kbit/s)

Indicates the minimum UL bandwidth of logic port.

Congestion Control Enhancement Switch

Indicates the switch for the enhanced congestion control. When the switch is set to ON, the enhanced congestion control prevents uplink available bandwidth from sharply decreasing and uplink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

This feature requires the uplink FPDT GPM detection result. Before using this feature, run the ADD GPM or MOD GPM command to enable the uplink FPDT GPM detection function for the NodeB.

This switch can be configured only when the flow control function is enabled. This configuration takes effect only in IP transmission, but cannot take effect in ATM transmission even though the configuration succeeds.
