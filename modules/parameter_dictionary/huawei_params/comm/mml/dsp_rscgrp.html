Display Transmission Resource Group Status (DSP RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a transmission resource group.

Note

  • [eNodeB,gNodeB]In the execution result of this command, the returned bearing port No. is the number of the physical port that carries the transmission resource group. The value of this parameter is different from the previously configured one if there has been a resource group switchover.

  • [eNodeB,gNodeB]The real-time and non-real-time service traffic as well as non-real-time reserved TX and RX bandwidths of a transmission resource group are measured based on the statistics at the IP layer. Other TX and RX bandwidths, admission bandwidth, and actual traffic of the resource group are measured based on the statistics at the data link layer.

  • [eNodeB,gNodeB]In the execution result of this command, the real-time and non-real-time traffic measures traffic created by the real-time and non-real-time user plane packets carried on the transmission resource group, respectively. These user plane packets consist of the user plane packets on all IP paths associated with this transmission resource group, and do not include the forwarded packets.

  • [eNodeB,gNodeB]"Realtime TX Bandwidth", "Non-Realtime TX Bandwidth", "GBR Tx Bandwidth" specify the service traffic before traffic shaping. "Realtime Tx Traffic" specifies the service traffic after traffic shaping.

RSCGRPID Transmission Resource Group ID

Meaning: Indicates the ID of a transmission resource group. When you use an MML command to add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates a transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, or an uplink tunnel on the MAE-Deployment, if the default transmission resource group does not exist, the system automatically creates a transmission resource group with Transmission Resource Group ID set to AUTOPORT(Autoport Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group.

Example

To query the status of a transmission resource group with the parameters as follows: Slot No.: 6, Transmission Resource Group Bear Type: IP, Subboard Type: BASE_BOARD, Bearing Port Type: ETH, run the following command:
DSP RSCGRP: SN=6, BEAR=IP, SBT=BASE_BOARD, PT=ETH;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a transmission resource group is established.

Subrack No.

Indicates the number of the subrack that houses the board where a transmission resource group is established.

Slot No.

Indicates the number of the slot corresponding to the board where a transmission resource group is established.

Transmission Resource Group Bear Type

Indicates the bearer type of the transmission group. The LTE and NR do not support ATM.

Subboard Type

Indicates the type of sub-board on the transmission group. The LTE and NR do not support UNCHANNELLED_COVERBOARD.

Bearing Port Type

Indicates the type of port where a transmission resource group is carried. The LTE and NR do not support STM1, IMA, UNI, or FRAATM.

Bearing Port No.

Indicates the number of the port where the transmission resource group is configured.

Transmission Resource Group ID

Indicates the ID of a transmission resource group. When you use an MML command to add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates a transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, or an uplink tunnel on the MAE-Deployment, if the default transmission resource group does not exist, the system automatically creates a transmission resource group with Transmission Resource Group ID set to AUTOPORT(Autoport Port). When you remove any of the preceding objects, the system automatically removes the transmission resource group.

Rate Unit

Indicates the rate unit of the TX bandwidth, RX bandwidth, TX CIR, RX CIR, TX PIR and RX PIR of the transmission resource group. The LTE and NR do not support CELL/S.

Realtime TX Bandwidth

Indicates the local real-time traffic that is transmitted in a transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE and NR.

Realtime RX Bandwidth

Indicates the local real-time traffic that is received in a transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE and NR.

Non-Realtime TX Bandwidth

Indicates the local non-real-time traffic that is transmitted in a transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE and NR.

Non-Realtime RX Bandwidth

Indicates the local non-real-time traffic that is received in a transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE and NR.

Non-Realtime Reserved TX Bandwidth

Indicates the TX bandwidth reserved for non-real-time services in a transmission resource group. The parameter takes effect only in LTE and NR.

Non-Realtime Reserved RX Bandwidth

Indicates the RX bandwidth reserved for non-real-time services in a transmission resource group. The parameter takes effect only in LTE and NR.

Tx Bandwidth

Indicates the maximum uplink bandwidth of a transmission resource group at the MAC layer when the transmission resource group is carried over IP. This parameter value is used as the uplink transport admission bandwidth and TX traffic shaping bandwidth. The minimum rate supported by the UMPTa, UMPTb, UMDU, GTMUb or GTMUc is 64 kbit/s. The LMPT can be configured with a maximum of 360 Mbit/s TX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the transmission resource group that is carried on the PPP link.

Rx Bandwidth

Indicates the RX bandwidth of a transmission resource group. To LTE, this parameter value is also used as the downlink transport admission bandwidth. The LMPT can be configured with a maximum of 540 Mbit/s RX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s RX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s RX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s RX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s RX bandwidth. The UBBPe(excluding UBBPe15), UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX bandwidth. The value of RX bandwidth is set to the maximum value of RX bandwidth supported by the board when it bigger than the maximum one.

Tx Bandwidth Used

Indicates the TX bandwidth that is already used by a transmission resource group.

Rx Bandwidth Used

Indicates the RX bandwidth that are already used by a transmission resource group.

Tx Bandwidth Usable

Indicates the TX bandwidth that can be used by a transmission resource group.

Rx Bandwidth Usable

Indicates the RX bandwidth that can be used by a transmission resource group.

GBR Tx Bandwidth

Indicates the GBR service traffic that is transmitted by the transmission resource group. The parameter takes effect only in LTE and NR.

GBR Rx Bandwidth

Indicates the GBR service traffic received by the transmission resource group. The parameter takes effect only in LTE and NR.

Rate Configuration Type

Indicates the rate configuration mode of the transmission resource group.

UL Admission Bandwidth

Indicates the uplink admission bandwidth of the transmission resource group. When Physical Port Up Link OverBooking Switch is ON in the command output of the LST TACALG command, the value of this parameter can exceed the uplink bandwidth of the physical port. The parameter takes effect only in LTE and NR.

DL Admission Bandwidth

Indicates the downlink admission bandwidth of the transmission resource group. When Physical Port Down Link OverBooking Switch is ON in the command output of the LST TACALG command, the value of this parameter can exceed the downlink bandwidth of the physical port. The parameter takes effect only in LTE and NR.

UL CIR Admission Bandwidth

Indicates the UL Committed Information Rate (CIR) admission bandwidth for the transmission resource group. The parameter takes effect only in LTE and NR.

DL CIR Admission Bandwidth

Indicates the CIR admission bandwidth of the transmission resource group in DL. The parameter takes effect only in LTE and NR.

UL PIR Admission Bandwidth

Indicates the UL PIR admission bandwidth of the transmission resource group. The parameter takes effect only in LTE and NR.

DL PIR Admission Bandwidth

Indicates the PIR admission bandwidth of the transmission resource group in DL. The parameter takes effect only in LTE and NR.

Realtime Tx Traffic(byte/s)

Indicates the realtime traffic sent on a transmission resource group.
