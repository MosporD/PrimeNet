Clear Board Files (CLR FILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to clear trash files from a board based on their deletion levels when the board has insufficient flash memory. The deletion level can be high, medium, or low.

Note

  • If the deletion level is high, some important files, such as backup files are deleted, and the logs may not be uploaded. Therefore, exercise caution while choosing the detection level.

  • It is recommended that you reset the base station after running this command.

DL Delete Level

Meaning: Indicates the level at which files are deleted. The high level indicates that all files required during the proper running of a board are saved and others are deleted. The medium level indicates that secondary log files and trash files are deleted. The low level indicates that trash files are deleted.

GUI Value Range: LOW(Low), MED(Medium), HIGH(High)

Unit: None

Actual Value Range: LOW, MED, HIGH

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To clear trash files with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Delete Level: LOW, run the following command:
CLR FILE: SRN=0, SN=7, DL=LOW;
