Set SSL Cipher Suite Level (SET SSLCS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the security level of an SSL cipher suite.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is used only to modify the security level of an SSL cipher suite when the security of the SSL cipher suite becomes weak. In other scenarios, this command is not recommended.

  • If the currently used SSL cipher suite is forbidden, the WebLMT connection switches to another valid cipher suite, other connections will be interrupted after 10s.

  • Before modifying the value of Cipher Suite Level, ensure that the MAE supports the new cipher suite. If the MAE does not support the new cipher suite, modifying the value may interrupt the maintenance channel.

  • When an SSL certificate is available, the NE does not use an anonymous algorithm suite to set up a connection.

  • The NE selects the cipher suite list for SSL negotiation according to both the value of the Lowest Cipher Suite Level parameter (queried by running the LST SSLCONF command) and the level of the cipher suite (queried by running the DSP SSLCS command). You can run the SET SSLCONF and SET SSLCS commands to set the cipher suite list for SSL negotiation. For example, RSA_AES_256_CBC_SHA256, RSA_AES_128_CBC_SHA256, and RSA_3DES_EDE_CBC_SHA indicate high, medium, and low levels, respectively. If the Lowest Cipher Suite Level parameter is set to HIGH, the name of the cipher suite for SSL negotiation is RSA_AES_256_CBC_SHA256. If the Lowest Cipher Suite Level parameter is set to MEDIUM, the names of the cipher suite for SSL negotiation are RSA_AES_256_CBC_SHA256 and RSA_AES_128_CBC_SHA256.

CSLEVEL Cipher Suite Level

Meaning: Indicates the security level of an SSL cipher suite. Raising the level of cipher suites may increase system security risks. Set this parameter to a proper value.

GUI Value Range: DISABLE(Disable), LOW(Low), MEDIUM(Medium), HIGH(High)

Unit: None

Actual Value Range: DISABLE, LOW, MEDIUM, HIGH

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the security level of an SSL cipher suite to LOW, run the following command:
SET SSLCS: CSNAME=RSA_AES_256_CBC_SHA256, CSLEVEL=LOW;
