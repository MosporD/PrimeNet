Set Base Station Global Transport Parameters (SET GTRANSPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the global transport parameters within a BS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Configure Forward Mode in strict accordance with the actual networking. For non-cascaded base stations (without passerby data flow), set Forward Mode to HOST; for cascaded base stations (with passerby data flow), set Forward Mode to ROUTE. If cascaded base stations do not need intra-port data forwarding, disable Same Port Forward Switch. If you set Forward Mode to HOST for cascaded base stations, the services on the lower-level base station will be interrupted. To rectify this fault, set Forward Mode to ROUTE for the cascaded base stations.

  • For the UMPT/LMPT/UMDU/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UTRPc/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 board, the Forward Mode and Same Port Forward Switch parameters take effect according to the configured values. For other boards, the two parameters are set to ROUTE and Enable by default, respectively.

  • When Endpoint Object Auto-configure Switch is set to DISABLE, the automatic transmission configuration function is disabled, which affects other functions that depend on this function. Therefore, disable the automatic transmission configuration function only during MAE-Deployment configuration or when rollback is required, and enable this function after related operations are complete.

  • In the scenarios of co-transmission through panel, set Forward Mode to ROUTE for the base station that provides the co-transmission port, and meanwhile set Same Port Forward Switch to DISABLE when intra-port data forwarding is not required. If you set Forward Mode to HOST for the base station that provides the co-transmission port, services of base stations that do not provide the co-transmission port will be interrupted. To solve this problem, set Forward Mode to ROUTE for the base station that provides the co-transmission port. In co-transmission through backplane interconnection, the packet forwarding mode is not controlled by the Forward Mode parameter.

  • The ARP aging time of this NE must be set according to the ARP aging time of the switch and router on the network. If the ARP aging time of this NE is longer than the ARP aging time of the network device, network issues such as broadcast storms may occur.

  • When the load sharing function is enabled by setting Control Port Load Balance Switch to ENABLE (Enable) and the board on which the SCTP link is deployed changes, the SCTP link status is checked again. If the SCTP link is faulty, the link fault alarm will be reported.

  • [Co-MPT,eNodeB,gNodeB]Configured values of LPSCHSW and RATECFGTYPE only take effect on the main control board and UTRPc board; for the UTRP board, LPSCHSW and RATECFGTYPE are permanently set to be DISABLE and SINGLE_RATE respectively due to the board's limited capabilities. Whether the resource group scheduling weight is supported mostly depends on the board capabilities. If RATECFGTYPE is set to DUAL_RATE, LPSCHSW is enabled by default. Therefore, the configured value of LPSCHSW does not take effect when RATECFGTYPE is set to DUAL_RATE.

  • [Co-MPT,eNodeB,gNodeB]Configured values of CPLISTENINGMODE only take effect on the UMPT/UMDU board.

  • [Co-MPT,eNodeB]The port mode adaptation function is not supported over an optical Ethernet port on an LMPT when the port status is detected as DOWN.

  • [NodeB]Configured values of LPSCHSW and RATECFGTYPE only take effect on the UTRPc board; for the WMPT or UTRP board, LPSCHSW and RATECFGTYPE are permanently set to be DISABLE and SINGLE_RATE respectively due to the board's limited capabilities. Whether the resource group scheduling weight is supported mostly depends on the board capabilities. If RATECFGTYPE is set to DUAL_RATE, LPSCHSW is enabled by default. Therefore, the configured value of LPSCHSW does not take effect when RATECFGTYPE is set to DUAL_RATE.

Parameters

ID Name Description
LPSCHSW Resource Group Scheduling Weight Switch

Meaning: Indicates the switch used to control whether to allocate bandwidths to transmission resource groups on the physical port based on their scheduling weights. When RATECFGTYPE (the rate configuration type) is set to SINGLE_RATE and Physical Port Up Link OverBooking Switch or Physical Port Down Link OverBooking Switch is set to OFF, different values of this parameter lead to different bandwidth allocation methods as follows: (1) If this parameter is set to DISABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its configured TX bandwidth; (2) If this parameter is set to ENABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its scheduling weight. When RATECFGTYPE (the rate configuration type) is set to DUAL_RATE, different values of this parameter lead to different CIR allocation methods as follows: (1) If the sum of CIRs of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a CIR that is directly proportional to its configured CIR; (2) If the sum of CIRs of the associated resource groups is smaller than the bandwidth of the physical port, each resource group is allocated a non-CIR that is directly proportional to its scheduling weight. In this case, the PIR of a resource group is the sum of the CIR and the non-CIR.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Modifications to this parameter affect the admission of new services and the quality of admitted services carried on resource groups.

Applicable Mode: G, U, L, N, R
RATECFGTYPE Rate Config Type

Meaning: Indicates the rate configuration mode of transmission resource groups in the BS, which can be set to SINGLE_RATE or DUAL_RATE. The dual rate configuration refers to the hybrid of the peak information rate (PIR) and committed information rate (CIR). If this parameter is set to SINGLE_RATE, the transmission resource group performs traffic shaping based on its transmit bandwidth. If this parameter is set to DUAL_RATE, the transmission resource group performs traffic shaping based on PIR and the transmission admission algorithm ensures that the non-flow-controllable traffic does not exceed CIR.

GUI Value Range: SINGLE_RATE(Single Rate), DUAL_RATE(Dual Rate)

Unit: None

Actual Value Range: SINGLE_RATE, DUAL_RATE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

SBTIME Switch Back Time

Meaning: Indicates the period during which the active and standby routes are switched over twice. This period indicates the interval between the time single-hop BFD detects that an active route changes from DOWN to UP and the time the active route becomes available. During the switchover, if the previous standby route becomes faulty, the system waits for 10 seconds and then switches back to the active route.

OMCHSWITCHBACK OMCH Switch Back

Meaning: Indicates whether the OM channel supports switchback. This parameter is valid only when the OM channel is bound to a UDP session, UDP session group, or automatic UDP session detection. If this parameter is set to ENABLE and a switchover from the active OM channel to the standby OM channel has been triggered, an OM channel switchback is automatically triggered after a UDP session, UDP session group, or automatic UDP session detects that the active channel recovers. If this parameter is set to DISABLE and a switchover from the active OM channel to the standby OM channel has been triggered, an OM channel switchback will not be automatically triggered.

SCTPRTRPTSW SCTP Fault Real-time Reporting Switch

Meaning: Indicates whether to report an SCTP link fault alarm in real time. If this parameter is set to ENABLE, the base station considers an SCTP link faulty when it detects that the SCTP link is disconnected. If this parameter is set to DISABLE, the base station starts a timer once it detects that an SCTP link is disconnected. If the base station detects that the SCTP link is disconnected for 18 seconds in the 30-second period, the base station considers that the SCTP link is faulty. Whether an alarm is reported is also determined by the alarm filtering parameter settings.

DIRECTIPSECPRIMATCHSW Direct IPSec Priorities Match Switch

Meaning: Indicates the switch for preferentially matching the IPSec policy of the directly connected IPv4 IPSec in end point mode. The IPSec policy of a direct IPSec tunnel is automatically generated and the IKE peer on which the IPSec policy depends is also automatically generated. Other types of IPSec policies belong to non-direct IPSec tunnels. When this parameter is set to ENABLE(Enable), the IPSec policy of a direct IPSec tunnel is preferentially matched. If the direct IPSec tunnel corresponding to the IPSec policy is faulty in this case, IPSec policies of other non-direct IPSec tunnels are preferentially matched. When this parameter is set to DISABLE(Disable), the matching is performed based on the default priorities, that is, the IPSec policy with a smaller sequence number is preferentially matched. This parameter takes effect only for LTE and NR.

TRANSCFGMODE Transmission Configuration Mode

Meaning: Indicates the configuration mode of the transmission model. The transmission model can be configured in old or new mode.

In old mode, the transmission model contains information such as cabinet, subrack, and slot numbers. Transmission configurations are bound to device boards.

In new mode, the transmission model has decoupled transmission and device models, That is, transmission configurations are not bound to device boards. This facilitates the addition of new transmission functions and reduces transmission configuration parameters.

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

Example

1.To set the global transport parameters within a BS with the parameters as follows: Resource Group Scheduling Weight Switch: Enable, Rate Config Type: Dual Rate, Switch Back Time: 30, ARP Aging Time: 20, OMCH Switch Back: Enable, OMCH Switch Back Wait Time: 100, SCTP Fault Real-time Reporting Switch: Disable, Control Port Listening Mode: Enable, End Point Configure Mode: S1SIMPLE_MODE-1&X2SIMPLE_MODE-1, Port Mode Auto Switch: Enable, Direct IPSec Priorities Match Switch: Enable, run the following command:
SET GTRANSPARA: LPSCHSW=ENABLE, RATECFGTYPE=DUAL_RATE, SBTIME=30, ARPAGINGTIME=20, OMCHSWITCHBACK=ENABLE, OMCHSBWAITTIME=100, SCTPRTRPTSW=DISABLE, CPLISTENINGMODE=ENABLE, EPCFGMODE=S1SIMPLE_MODE-1&X2SIMPLE_MODE-1, PMAUTOSW=ENABLE, DIRECTIPSECPRIMATCHSW=ENABLE;

2.To set the global transport parameters within a BS with the parameters as follows: Transmission Configuration Mode: New, run the following command:
SET GTRANSPARA: TRANSCFGMODE=NEW;
