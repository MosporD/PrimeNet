Display MBTS Major Standard for Clock Mutual Lock (DSP CLKMUTUALLOCK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the major standard for clock mutual lock on an MBTS. The clock on the side of the major standard for clock mutual lock is used as the criterion clock.

Note

None.

Parameters

None.

Example

To query MBTS major standard for clock mutual lock, run the following command: 
DSP CLKMUTUALLOCK:;
The result is shown as follows:  
+++    0        2012-11-05 06:50:24
O&M    #1282
%%DSP CLKMUTUALLOCK:;%%
RETCODE = 0  Operation succeeded.

Query MBTS Major Standard for Clock Mutual Lock
-----------------------------------------------
Major Standard for Clock Mutual Lock  =  UMTS
(Number of results = 1)


---    END

Output Description

Field Description

Major Standard for Clock Mutual Lock

Indicates the standard on which side the clock is used as the criterion clock when clock mutual lock is implemented on an MBTS. The value is NULL when the standard is not existed.
