Set Environmental Signal Input Port (SET ALMPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set an environment signal input port.

Note

  • If the port is on an unavailable board, the setting of the port fails.

  • Only the electromechanical boards, RRUs, power boards, and UMDUs provide ports for environment monitoring. FMUs which are not located in radio frequency cabinets (RFCs) or BTS3900AL cabinets do not provide environment signal input ports.

  • If Power System Type of a PMU is set to EPS4815, this command cannot be successfully executed.

  • If Power System Type of a PMU is set to SC48200, this command cannot be successfully executed.

  • Only the ports on RF modules support the setting of the alarm detection period.

  • In a distributed power supply scenario, all the dry-contact ports used to report alarms related to mains cut-off must be configured with the same customized alarm ID. Other dry-contact ports must not be configured with this ID to prevent false alarms.

PT Port Type

Meaning: Indicates the alarm port types: analog alarm port and digital alarm port. This parameter is valid only if the port switch is turned on. An analog alarm port is used to monitor the external environment that changes continuously. The port is supported only by the EMU. A digital alarm port is used to monitor the external environment of which the change is indicated by Boolean or discrete values. It is contained in the EMU, PMU, TCU, FMU, RRU, UMDU, CCU, and power boards. The SC48200 PMU and the EPS4815 PMU do not support digital ports.

GUI Value Range: BOOL(Digital Port), VALUE(Analog Port)

Unit: None

Actual Value Range: BOOL, VALUE

MML Default Value: None

Recommended Value: The same as the actual type of the port.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ALMPORT MO, PT must be set to VALUE when all the following conditions are met: 1. The device corresponding to the ALMPORT MO is an EMU MO, and the value of SRN in this EMU MO ranges from 40 to 59; 2. The value of PN ranges from 32 to 35; 3. SW is set to ON.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ALMPORT MO, PT must be set to BOOL when all the following conditions are met: 1. The device corresponding to the ALMPORT MO is an EMU MO, and the value of SRN in this EMU MO ranges from 40 to 59; 2. The value of PN ranges from 0 to 31; 3. SW is set to ON.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

UL Alarm Upper Limit

Meaning: Indicates the alarm upper limit. If the environment measurement value is greater than the alarm upper limit configured for the sensor, the alarm is reported. Environment measurement value = Measurement lower limit + (Measurement upper limit - Measurement lower limit) x (Observed electric current or voltage - Output lower limit)/(Output upper limit - Output lower limit). Temperature is measured in the unit of degree Celsius, voltage is measured in the unit of volts, and current is measured in the unit of milliampere.

GUI Value Range: -99999~999999

Unit: 0.01

Actual Value Range: -999.99~9999.99, step: 0.01

MML Default Value: None

Recommended Value: 9900

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ALMPORT MO, when the values of SW and PT are set to ON and VALUE, respectively, the value of UL must be greater than the value of LL.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the ALMPORT MO, when the values of SW and PT are set to ON and VALUE, respectively, the value of SMUL must be greater than or equal to the value of UL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the environmental signal input port with the parameters as follows: Cabinet No.: 0, Subrack No.: 40, Slot No.: 0, Port No.: 0, Port switch: open, run the following command:
SET ALMPORT: CN=0, SRN=40, SN=0, PN=0, SW=ON;
