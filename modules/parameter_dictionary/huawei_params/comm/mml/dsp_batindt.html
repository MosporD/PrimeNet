Display Battery Installation Date (DSP BATINDT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the installation date of a battery.

Note

  • Before querying the installation date of a battery, ensure that the battery is added.

  • If the operational status of the PMU that manages the battery is unavailable, the query fails.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the PMU managing the battery is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the PMU managing the battery is located.

GUI Value Range: 7

Unit: None

Actual Value Range: 7

MML Default Value: 7

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the PMU managing the battery is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the installation date of the battery with the cabinet number of 61, run the following command:
DSP BATINDT: CN=61;
The result is shown as follows:
+++    0        2009-06-01 01:01:58
O&M    #1281
%%DSP BATINDT: CN=61, SRN=7, SN=0;%%
RETCODE = 0  Operation succeeded
    
Battery Installation Date
-------------------------
Installation Date  =  2004-2-28
(Number of results = 1)
    
    
---    END

Output Description

Field Description

Installation Date

Indicates the date when the battery is installed. The scheduled tests for the battery are dependent on the installation date.
