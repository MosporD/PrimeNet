List DHCP Relay Switch Configuration (LST DHCPRELAYSWITCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the setting of the Dynamic Host Configuration Protocol (DHCP) relay switch.

Note

None.

Parameters

None.

Example

To list the setting of the DHCP relay switch, run the following command:
LST DHCPRELAYSWITCH:;
The result is shown as follows:
+++    0        2008-01-06 12:10:02
O&M    #385
%%LST DHCPRELAYSWITCH:;%%
RETCODE = 0  Operation succeeded.

DHCP Relay Switch
-----------------
DHCP Relay Switch  =  Enable
(Number of results = 1)


---    END

Output Description

Field Description

DHCP Relay Switch

Indicates whether to enable the DHCP relay switch.
