Modify Tree Link PVC (MOD TREELNKPVC)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the parameters related to a treelink PVC.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [NodeB]Only configured treelink PVCs can be modified by running this command.

  • [NodeB]The execution of this command may interrupt services carried on the treelink PVC. For details, see the "Service Interrupted After Modification" of each parameter in this command.

Parameters

ID Name Description
NO Tree Link PVC No.

Meaning: Indicates the treelink PVC number.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
RU Rate Unit

Meaning: Indicates the rate unit of the peak cell rate (PCR), minimum cell rate (MCR), and sustainable cell rate (SCR). 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted into 30 kbit/s.

GUI Value Range: KBPS(kbit/s), CELL/S(cell/s)

Unit: None

Actual Value Range: KBPS, CELL/S

MML Default Value: None

Recommended Value: KBPS(kbit/s)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
ST Bearer Service Type

Meaning: In terms of flow control, services are classified into four categories: the Real-Time Variable Bit Rate (RTVBR) service, Non-Real-Time Variable Bit Rate (NRTVBR) service, Unspecified Bit Rate Plus (UBR+) service, and Unspecified Bit Rate (UBR) service.

GUI Value Range: RTVBR(RTVBR), NRTVBR(NRTVBR), UBR+(UBR+), UBR(UBR)

Unit: None

Actual Value Range: RTVBR, NRTVBR, UBR+, UBR

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
PCR Peak Cell Rate

Meaning: Indicates the peak rate of transmitting cells on an ATM connection, such as a VPC or VCC.

GUI Value Range: 30~49529

Unit: None

Actual Value Range: 30~49529

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST and RU are set to UBR+ and KBPS, respectively, MCR must be less than PCR.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to UBR+ and RU is set to CELL/S, MCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to RTVBR or NRTVBR and RU is set to KBPS, SCR must be less than PCR.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to RTVBR or NRTVBR and RU is set to CELL/S, SCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.

-Others:

  • [Co-MPT, NodeB]In a TREELNKPVC MO, this parameter can be set to any value within the range of 31 to 21000 if RU is set to KBPS and ST is set to RTVBR, NRTVBR, or UBR+.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 30 to 21000 if RU is set to KBPS and ST is set to UBR.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 74 to 49529 if RU is set to CELL/S and ST is set to RTVBR, NRTVBR, or UBR+.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 71 to 49529 if RU is set to CELL/S and ST is set to UBR.
  • [Co-MPT, NodeB]In the TREELNKPVC MO, if ST is set to UBR+, the value of this parameter must be greater than that of MCR.
  • [Co-MPT, NodeB]In the TREELNKPVC MO, if ST is set to RTVBR or NRTVBR, the value of this parameter must be greater than that of SCR.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To modify a treelink PVC with the parameters as follows: Tree Link PVC No.: 0, Rate Unit: KBPS, Bearer Service Type: RTVBR, Peak Cell Rate: 31, Sustain Cell Rate: 30, run the following command: 
MOD TREELNKPVC: NO=0, RU=KBPS, ST=RTVBR, PCR=31, SCR=30;
