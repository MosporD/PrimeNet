List Static MAC Entry (LST STATICMACITEM)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list all configured entries in static MAC forwarding tables.

Note

None.

Parameters

None.

Example

To list the information of Static MAC Entry in the database, run the following command: 
LST STATICMACITEM:;
The result is shown as follows:
+++    0        2015-05-17 21:59:41
O&M    #805308662
%%LST STATICMACITEM:;%%
RETCODE = 0  Operation succeeded.

List Static MAC Entry
---------------------
MAC Entry Index  Switch Port Index  Destination MAC Address

0                1                  2014-0A26-1024 
1                1                  2014-0A26-1025 
2                2                  2014-0A26-1026
(Number of results = 3)


---    END

Output Description

Field Description

MAC Entry Index

Indicates the index of an entry in a MAC forwarding table.

Switch Port Index

Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.

Destination MAC Address

Indicates the destination MAC address of an entry in a MAC forwarding table. The format must be "XXXX-XXXX-XXXX".
