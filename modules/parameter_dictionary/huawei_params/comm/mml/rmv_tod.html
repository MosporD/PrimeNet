Remove TOD (RMV TOD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a specified Time of Day (TOD) clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eGBTS,eNodeB,gNodeB]If the working mode of the clock is manual and the TOD clock link is specified as the reference clock source, this clock link cannot be removed. If the working mode of the clock is automatic, the clock link can be removed. After removal of the clock link, the system clock is switched to another clock source.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]Ongoing services are affected if a clock source in use is removed, the NE does not obtain another reference clock within the holding period of the crystal oscillator, and the crystal oscillator running time exceeds the hold period.

  • [NodeB]The UMTS currently does not support this function.

Parameters

ID Name Description
TN TOD Clock No.

Meaning: Indicates the number of a TOD clock link. When TOD clock links are configured on a USCUb board, the numbers of the TOD clock links have a one-to-one relationship with the numbers of the TOD ports on the USCUb. For example, TOD clock link 0 corresponds to port 0, and TOD clock link 1 to port 1.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove a TOD clock link whose TOD Clock number is 0, run the following command:
RMV TOD: TN=0;
