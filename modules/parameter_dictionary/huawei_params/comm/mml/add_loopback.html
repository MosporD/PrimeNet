Add Loopback Interface (ADD LOOPBACK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a loopback interface.

Note

  • Board specifications: A board supports a maximum of 32 loopback interfaces.

  • System specifications: An NE supports a maximum of 128 loopback interfaces.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of a loopback interface and is unique in the system.Port IDs 4 to 7 are reserved by the system and cannot be manually configured.

GUI Value Range: 0~99999

Unit: None

Actual Value Range: 0~99999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The value of PORTID from 4 to 7 in an LOOPBACK MO cannot be set.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CN Cabinet No.

Meaning: Indicates the cabinet number of the board to which the loopback interface belongs.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board to which the loopback interface belongs.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the slot number of the board to which the loopback interface belongs.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
USERLABEL User Label

Meaning: Indicates the user-defined information about a loopback interface.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a loopback interface with the parameters as follows: Port ID: 0, Slot No.: 6, run the following command: 
ADD LOOPBACK: PORTID=0, SN=6;
