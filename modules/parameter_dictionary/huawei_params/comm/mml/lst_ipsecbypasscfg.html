List IPSec Bypass Switch (LST IPSECBYPASSCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the IPSec Bypass.

Note

None.

Parameters

None.

Example

To list the information about IPSec Bypass configuration, run the following command:  
LST IPSECBYPASSCFG:;
The result is shown as follows:
+++    0        2012-09-04 20:15:59
O&M    #189
%%LST IPSECBYPASSCFG:;%%
RETCODE = 0  Operation succeeded.

List IPSec Bypass Switch
------------------------
IPSec Bypass Switch  =  Enable
  IPSec Bypass Code  =  *****
(Number of results = 1)


---    END

Output Description

Field Description

IPSec Bypass Switch

Indicates whether to enable the switchover of IPSec Bypass. If this parameter is set to DISABLE, the base station cannot switch between an IPSec network and a non-IPSec network.

IPSec Bypass Code

Indicates the password used for switching the base station between an IPSec network and a non-IPSec network.
