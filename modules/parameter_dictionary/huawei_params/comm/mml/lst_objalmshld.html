List Object Alarm Shield (LST OBJALMSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query alarm shielding conditions by object.

Note

None.

Parameters

ID Name Description
QRMD Query Mode

Meaning: Indicates that the query is performed by the alarm masking conditions of the object.

GUI Value Range: OBJ(OBJ)

Unit: None

Actual Value Range: OBJ

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Example 1:To query alarm shielding conditions by object: Query Mode:OBJ, run the following command:
LST OBJALMSHLD: QRMD=OBJ; 
The result is shown as follows:

Output Description

Field Description

Object Type

Indicates the type of an object according to which alarms are shielded.

Cabinet No.

Indicates the number of the cabinet shielded by physical location.

Subrack No.

Indicates the number of the subrack shielded by physical location.

Slot No.

Indicates the number of the slot shielded by physical location.

[NodeB]Bound of Slot No. is [0~8;16;18] in UMTS.

Port No.

Indicates the port number of the object.

Alarm ID

Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.
