Remove Device Certificate (RMV CERTMK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a device certificate and the corresponding certificate file.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During automatic establishment of a remote maintenance channel, do not run this command. Otherwise, the corresponding certificate file can not be deleted.

  • Before running this command, run the LST APPCERT command to check whether the device certificate to be removed has been activated. If this device certificate has been activated, run the MOD APPCERT command to activate another device certificate. Then, run the LST IKEPEER command to check whether the device certificate to be removed has been referenced by IKEPEER. If this device certificate has been referenced by IKEPEER, run the MOD IKEPEER command to reference another device certificate so that the certificate to be removed becomes deactivated.

  • When running this command, ensure that the certificate file name specified in this command is the same as that of a configured device certificate.

Parameters

ID Name Description
APPCERT Certificate File Name

Meaning: Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in a CERTMK MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CERTMK MO is being added, the APPCERT is case-insensitive; but when a CERTMK MO is referenced, the APPCERT is case-sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery. There is only one such MO on an NE and this MO cannot be added or removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove a device certificate file with the parameters as follows: Certificate File Name: eNodeBCert.pem, run the following command:
RMV CERTMK: APPCERT="eNodeBCert.pem";
