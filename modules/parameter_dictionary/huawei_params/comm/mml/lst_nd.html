List the IPv6 Neighbor Discovery Protocol Parameters (LST ND)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an IPv6 ND parameter.

Note

None.

Parameters

None.

Example

To list the configuration of neighbor discovery reachable time, run the following command:
LST ND:;
The result is shown as follows:
+++    0        2018-08-06 07:52:32
O&M    #1676
%%LST ND:;%%
RETCODE = 0  Operation succeeded.

List the IPv6 Neighbor Discovery Protocol Parameters
----------------------------------------------------
Neighbor Discovery Reachable Time(ms)  =  5000
(Number of results = 1)


---    END

Output Description

Field Description

Neighbor Discovery Reachable Time(ms)

Indicates the length of the timer for the reachable status of the neighbor discovery protocol entry in IPv6 transmission.
