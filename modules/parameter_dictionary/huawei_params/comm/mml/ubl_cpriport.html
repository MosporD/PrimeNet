Unblock CPRI Port (UBL CPRIPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to unblock a CPRI port.

Note

  • The boards supporting unblock CPRI port include the BBP, UBRI, GTMU, UMDU, RHUB and RMU.

  • The port can be unblocked only when the port type of the RHUB is CPRI_E/CPRI_O.

  • When the laser of the SFP optical module on the baseband processing board is off, the laser of the optical module is turned on by running this command.

Example

To unblock the CPRI port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, Port No.: 0, run the following command:
UBL CPRIPORT: CN=0, SRN=0, SN=3, OPTN=0;
