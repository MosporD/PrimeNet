Stop Ethernet Port OAM Loopback Test (STP ETHOAMLOOPTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to stop the Ethernet OAM 3ah loopback test.

Note

  • After the Ethernet OAM 3AH loopback test is started, you can run the STP ETHOAMLOOPTST command to check the general statistical result or wait until the test is complete. The result reported by the system is the general statistical result within the test duration or the period from the start of the test to the execution of this command.

  • After the Ethernet OAM 3AH loopback test is started, you can run the STP ETHOAMLOOPTST command to check the general statistical result or wait until the test is complete.

  • The test automatically stops when you exit the maintenance console, and as a result, the test result is not reported.

  • An Ethernet OAM 3AH loopback test started by a user cannot be terminated by another user.

Example

To stop an Ethernet OAM 3ah loopback test with the parameters as follows: Slot No.: 6, Subboard Type: Base Board, run the following command: 
STP ETHOAMLOOPTST: SN=6, SBT=BASE_BOARD;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the Ethernet OAM 3AH loopback is started.

Subrack No.

Indicates the subrack number of the board where the Ethernet OAM 3AH loopback is started.

Slot No.

Indicates the slot number of the board where the Ethernet OAM 3AH loopback is started.

Subboard Type

Indicates the type of sub-board on the board where the Ethernet OAM 3ah loopback test is started.

Port Type

Indicates the type of the port where the Ethernet OAM 3AH loopback test is started.

Port No.

Indicates the number of the port where the Ethernet OAM 3AH loopback test is performed.

Remain Time

Indicates the remaining time.

Duration

Indicates the duration of the loopback.

TX Packets(packet)

Indicates the total number of packets transmitted during the loopback.

RX Packets(packet)

Indicates the total number of packets received during the loopback.

Average Delay(microsecond)

Indicates the average delay of packets during the loopback.

Max Delay(microsecond)

Indicates the maximum delay of packets during the loopback.

Min Delay(microsecond)

Indicates the minimum delay of packets during the loopback.
