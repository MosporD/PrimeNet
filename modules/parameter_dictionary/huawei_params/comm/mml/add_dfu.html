Add DFU (ADD DFU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a DFU.

Note

  • Currently, only one DFU can be configured for each RAT of a base station.

  • The operation and maintenance of the RAT served by the DFU is performed centrally on the RANCU side.

Parameters

ID Name Description
UID Unit ID

Meaning: Indicates the ID of a DFU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
NETWORKID NetWork ID

Meaning: Indicates the network ID of a DFU. The network ID is unique for each application type on the entire network.

GUI Value Range: 0~68719476735

Unit: None

Actual Value Range: 0~68719476735

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If the APPTYPE parameters in different DFU MOs are set to the same value, the NETWORKID parameters in these DFU MOs must be set to different values.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
APPTYPE Application Type

Meaning: Indicates the type of the application referenced by a DFU. The application provides the running environment for the DFU.

GUI Value Range: ENODEB(eNodeB), GNODEB(gNodeB)

Unit: None

Actual Value Range: ENODEB, GNODEB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
APPREF Application Reference

Meaning: Indicates the ID of the application referenced by a DFU. The application provides the running environment for the DFU.

GUI Value Range: 1~255

Unit: None

Actual Value Range: 1~255

Applicable Mode: L, N

Meaning: Indicates the name of a DFU.

Unit: None

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To add a DFU with the parameters as follows: Unit ID: 1, NetWork ID: 20, Application Type: eNodeB, Application Reference: 22, Unit Name: eNodeb_A, run the following command:
ADD DFU: UID=1, NETWORKID=20, APPTYPE=ENODEB, APPREF=22, UNITNAME="eNodeb_A";
