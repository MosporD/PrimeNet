List PMTU Discovery Global Configuration (LST PMTUCFG)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the global configuration of IPv6 PMTU discovery.

Note

None.

Parameters

None.

Example

To list basic PMTU detection configurations, run the following command: 
LST PMTUCFG:;
The result is shown as follows:
+++    0        2018-10-09 11:36:55
O&M    #124
%%LST PMTUCFG:;%%
RETCODE = 0  Operation succeeded.

List PMTU Detection Config
--------------------------
                Mode  =  Active Mode
       Protocol Type  =  UDP
            Port No.  =  49152
Timeout Duration(ms)  =  500
      AgingTime(min)  =  5
                DSCP  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Mode

Indicates the PMTU discovery mode, which can be active or passive. In active mode, the base station sends discovery packets to perform PMTU discovery. In passive mode, the base station automatically adjusts the PMTU size based on the received ICMPv6 Packet Too Big message.

Protocol Type

Indicates the protocol type of PMTU discovery packets.

Port No.

Indicates the destination port number specified for PMTU discovery packets. The UDP port numbers of 60000-62559, 64679-64710, 65020, 65040, and 65043 are reserved for certain features of the base station such as NTP and cannot be used as this parameter value.

Timeout Duration(ms)

Indicates the timeout duration of waiting for a response to a single PMTU discovery.

AgingTime(min)

Indicates the aging time of a PMTU entry. The recommended value range is 30 minutes to 60 minutes. In passive mode, this parameter is invalid for the user-plane path, SCTP link, and IKE link. PMTU entries of these links always become aged between 2:00 a.m. and 3:00 a.m.

DSCP

Indicates the DSCP value used by PMTU detection packets.
