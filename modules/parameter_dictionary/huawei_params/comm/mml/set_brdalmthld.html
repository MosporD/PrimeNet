Set Board Alarm Threshold (SET BRDALMTHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the thresholds for reporting and clearing the board overload alarm.

Note

None.

OVERLOADALMRPTTHLD Board Overload Alarm Report Threshold

Meaning: Indicates the threshold for reporting the board overload alarm. If the usage of the processing chip on the board is greater than or equal to this parameter value, ALM-26202 Board Overload is reported.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 90

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP or UBBP-W, OVERLOADALMRPTTHLD in the BBP MO must be set to 90 and OVERLOADALMCLRTHLD in the BBP MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the BBP MO must be greater than the value of OVERLOADALMCLRTHLD in the BBP MO.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the MPT MO is not UMPT, the value of OVERLOADALMRPTTHLD in the MPT MO must be set to 90 and OVERLOADALMCLRTHLD in the MPT MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the MPT MO must be greater than the value of OVERLOADALMCLRTHLD in the MPT MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
OVERLOADALMCLRTHLD Board Overload Alarm Clear Threshold

Meaning: Indicates the threshold for clearing the board overload alarm. If the usage of the processing chip on the board is less than this parameter value, ALM-26202 Board Overload is cleared.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 85

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the BBP MO is not UBBP or UBBP-W, OVERLOADALMRPTTHLD in the BBP MO must be set to 90 and OVERLOADALMCLRTHLD in the BBP MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the BBP MO must be greater than the value of OVERLOADALMCLRTHLD in the BBP MO.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the MPT MO is not UMPT, the value of OVERLOADALMRPTTHLD in the MPT MO must be set to 90 and OVERLOADALMCLRTHLD in the MPT MO must be set to 85.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of OVERLOADALMRPTTHLD in the MPT MO must be greater than the value of OVERLOADALMCLRTHLD in the MPT MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the thresholds for reporting and clearing the board overload alarm the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Board Overload Alarm Report Threshold: 85, Board Overload Alarm Clear Threshold: 80, run the following command:
SET BRDALMTHLD: CN=0, SRN=0, SN=6, OVERLOADALMRPTTHLD=85, OVERLOADALMCLRTHLD=80;
The result is shown as follows:
