List Certificate File (LST CERTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list all certificate files in the BS. The certificate files in the download directory, and those added to the configured device certificate, trust certificate, cross-certificate, and CRL, and the existing digital certificate whitelist file specified in the running area.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]When automatic establishment of a remote maintenance channel starts or stops, certificate files are uninstalled or loaded. During the process, you cannot run this command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]A maximum of 45 certificate files can be queried by running this command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If Slot No. is set to the physical slot number in active/standby mode, the name of the certificate file on the board in the specified physical slot is displayed.

CERTFILETYPE Certificate File Type

Meaning: Indicates the certificate file type. If this parameter is set to UNUSED, you can query or delete the certificate files in the download area. If this parameter is set to DEVCERT, you can query or delete the existing certificate files specified in the CERTMK MO. The query results show that the certificate with Application Type in the APPCERT MO set to IKE and the certificate specified by the Certificate File Name parameter in the IKEPEER MO have been loaded. If this parameter is set to TRUSTCERT, CROSSCERT, or CRL, you can query or delete the existing certificate files specified in the TRUSTCERT, CROSSCERT, and CRL MOs. When a certificate has been configured using the ADD TRUSTCERT, ADD CRL, or ADD CROSSCERT command, the query results show that the certificate has been loaded. If this parameter is set to CERTWHITELST, you can query or delete the existing digital certificate whitelist file specified in the running area.

Output Description

Field Description

Certificate File Name

Indicates the certificate file name. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

Certificate File Type

Indicates the certificate file type. If this parameter is set to UNUSED, you can query or delete the certificate files in the download area. If this parameter is set to DEVCERT, you can query or delete the existing certificate files specified in the CERTMK MO. The query results show that the certificate with Application Type in the APPCERT MO set to IKE and the certificate specified by the Certificate File Name parameter in the IKEPEER MO have been loaded. If this parameter is set to TRUSTCERT, CROSSCERT, or CRL, you can query or delete the existing certificate files specified in the TRUSTCERT, CROSSCERT, and CRL MOs. When a certificate has been configured using the ADD TRUSTCERT, ADD CRL, or ADD CROSSCERT command, the query results show that the certificate has been loaded. If this parameter is set to CERTWHITELST, you can query or delete the existing digital certificate whitelist file specified in the running area.

Version

Indicates the version of a certificate file.

Issuer

Indicates the issuer of a device certificate.

Common Name

Indicates the common name of a device certificate.

Serial Number

Indicates the serial number of a certificate.

Key Usage

Indicates the usage for a key, including KEY_AGREEMENT (key negotiation), DATA_ENCIPHERMENT (data encryption), KEY_ENCIPHERMENT (key encryption), and DIGITAL_SIGNATURE (digital signature). This parameter can be set to one or multiple values. NON_REPUDIATION, KEY_CERT_SIGN, CRL_SIGN, ENCIPHER_ONLY and DECIPHER_ONLY are supported when query information.

Key Type

Indicates type of key of one certificate, which can be RSA or ECDSA.

Key Size

Indicates the key length, which can be 1024 bits, 2048 bits, 3072 bits or 4096 bits. The key length of 1024 bits is not recommended. Otherwise, the security is undermined. If this parameter is set to KEYSIZE1024, the RRU still uses the value KEYSIZE2048 as the key length.

ECC Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), ED25519 and P521(secp521r1). ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.

Signature Algorithm

Indicates the signature algorithm for a certificate file.

Effective Date

Indicates the effective date of a certificate.

Expiration Date

Indicates the expiration date of a certificate.

Local Name

Indicates the local name of a BS. This parameter is used to generate the DNS name of the subject alternative name of a certificate, to verify the peer's identification in IKE negotiation. If this parameter is not configured, the BS automatically uses the common name and its additional information to generate the DNS name. This parameter does not take effect for RRUs.

CRL Number

Indicates the number of a certificate revocation list (CRL).

This Update

Indicates the latest update time of the CRL.

Next Update

Indicates the next update time of the CRL.

Load State

Indicates the loading status of a certificate.

Activation Time

Indicates the activation time of a digital certificate whitelist file.

Activation State

Indicates the activation state of a digital certificate whitelist file.

Local IP

Indicates the IP address of the subject alternative name of a certificate. This parameter does not take effect for RRUs.

Local IPv6

Indicates the IPv6 address of the subject alternative name of a certificate. This parameter does not take effect for RRUs. This parameter is invalid in the old transmission model.
