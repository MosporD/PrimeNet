Set LOCALWAP Enable Switch (SET LOCALWAPSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to configure the switch for enabling the local WAP.

Note

[Co-MPT,NodeB,eGBTS,eNodeB]After the OMCH is disconnected from the base station, the local wireless AP is automatically activated if the switch for the local wireless AP device is set to on. In addition, you cannot set the switch for the local wireless AP and this command will fail to be executed.

Parameters

ID Name Description
ENABLESW Enable Switch

Meaning: Indicates the switch for the LOCALWAP(Local Wireless Access Point). If this parameter is set to ENABLE, the wireless AP provides 2.4 Gbit/s WLAN signals when this parameter value takes effect, and the wireless AP is automatically disabled upon expiration. If this parameter is set to DISABLE, the wireless AP is automatically disabled.

GUI Value Range: DISABLE(DISABLE), ENABLE(ENABLE)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(DISABLE)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R
ENABLEELAPSETIME Enable Elapse Time

Meaning: Indicates the length that the LOCALWAP(Local Wireless Access Point) is enabled.

GUI Value Range: 1~1440

Unit: min

Actual Value Range: 1~1440

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R

Example

To set the WLAN AP Enable Switch with the parameters as follows: AP Enable Switch: ENABLE, AP Enable Elapse Time: 120 min, run the following command:
SET LOCALWAPSW: ENABLESW=ENABLE, ENABLEELAPSETIME=120;
