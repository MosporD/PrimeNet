Add ACL (ADD ACL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a record of the ACL.

Note

  • Board specifications: A maximum of 320 ACLs can take effect on a UMPTa/UMPTb/UMDU/UTRPc. A maximum of 128 ACLs can take effect on an LMPT/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 400 ACLs can take effect on a UMPTe/UMPTg/UMPTga. A maximum of 6 ACLs can take effect on a UTRP (subboard type: UEOC/UQEC) or WMPT. A maximum of 4 ACLs can take effect on a GTMUc.

  • System specifications: If a WMPT is used as the main control board, a maximum of 6 ACLs can be configured for a base station. If an LMPT is used as the main control board, a maximum of 128 ACLs can be configured for a base station. If a UMPTa/UMPTb/UMDU is used as the main control board, a maximum of 320 ACLs can be configured for a base station. If a UMPTe/UMPTg/UMPTga is used as the main control board, a maximum of 400 ACLs can be configured for a base station. If a GTMU is used as the main control board, a maximum of 16 ACLs can be configured for a base station. If a UMPT/UMDU is used as the main control board, the number of manually configured ACLs must not exceed 256 for a base station.

  • An ACL takes effect on a board together with packet filtering, packet filtering policy, IPsec policy group binding, and IPsec policy group binding interface. That is, the ACL MO does not take effect when being configured, and takes effect on a board when the bearer of packet filtering, packet filtering policy, IPsec policy group binding, or IPsec policy group binding interface is configured.

  • User-configured ACLs count in the specifications of automatically setup ACLs even if the user-configured ACLs are not referenced by any bearer.

  • [Co-MPT,eNodeB,gNodeB]A maximum of 320 ACLs and ACL6s can take effect on a UMPTa/UMPTb/UMDU. A maximum of 456 ACLs and ACL6s can take effect on a UMPTe. A maximum of 584 ACLs and ACL6s can take effect on a UMPTg/UMPTga.

  • [Co-MPT,eNodeB,gNodeB]On a BS, the total number of ACLs and ACL6s must be smaller than or equal to 584.

  • [Co-MPT,eNodeB,gNodeB]If the UMPTa/UMPTb/UMDU is the main control board, a maximum of 320 ACLs and ACL6s can take effect on a BS. If the UMPTe is the main control board, a maximum of 456 ACLs and ACL6s can take effect on a BS. If the UMPTg/UMPTga is the main control board, a maximum of 584 ACLs and ACL6s can take effect on a BS.

  • [Co-MPT,eNodeB,gNodeB]In IPSec scenarios, the VRF index parameter in the ACL has no actual meaning.

Parameters

ID Name Description
ACLID ACL ID

Meaning: Indicates the ID of the access control list (ACL) to which an access control rule belongs. An ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An ACL rule with an ACL ID ranging from 4000 to 4999 indicates a layer 2 rule based on the MAC layer information configured by users. An ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

GUI Value Range: 3000~4999,7000~7999

Unit: None

Actual Value Range: 3000~4999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The ID of an ACL that is manually configured must range from 3000 to 4999.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ACLDESC Description

Meaning: Indicates the brief description of an ACL.

GUI Value Range: 0~127 characters

Unit: None

Actual Value Range: 0~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter is valid only when the TRANSCFGMODE parameter in the GTRANSPARA MO is set to OLD. When the TRANSCFGMODE parameter in the GTRANSPARA MO is set to NEW and the ACL is referenced by packet filtering or IPSec, this parameter is invalid and is replaced by the VRFIDX parameter of the INTERFACE MO referenced by packet filtering or IPSec. Therefore, avoid using this parameter.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add an ACL with the parameters as follows: ACL ID: 3000, Description: Acl Group is created, run the following command: 
ADD ACL: ACLID=3000, ACLDESC="Acl Group is created";
