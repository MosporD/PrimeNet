Set Line Rate (SET LR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the data rate of a physical port. Rate limitation is implemented between the data link layer and the physical layer. The length of a packet measures only the header of the data link layer, not the header of the physical layer. If the port type is set to MPGRP, rate limitation is performed only at the IP layer, but not at the MP header.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The sum of the committed burst size (CBS) and the excess burst size (EBS) must be greater than the uplink committed information rate (CIR). It is recommended that this sum be twice the uplink CIR.

  • The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s the uplink committed information rate and 1 Gbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • The UTRP can be configured with a maximum of 300 Mbit/s the uplink committed information rate and 300 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • The UMPTe/UMPTga can be configured with a maximum of 10 Gbit/s the uplink committed information rate and 10 Gbit/s the downlink committed information rate. The UMPTg can be configured with a maximum of 25 Gbit/s the uplink committed information rate and 25 Gbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • When an Ethernet port is deleted, the system automatically deletes the LR objects depending on the Ethernet port. If no Ethernet port object exists in the database, you can run the ADD ETHPORT/SET ETHPORT command to add an Ethernet port, and then run the RMV ETHPORT command to remove the Ethernet port. In this case, the system automatically deletes the LR objects depending on the Ethernet port.

  • [Co-MPT,NodeB,eNodeB,gNodeB]System specifications: If the WMPT/UMPT/LMPT/GTMUb/GTMUc is the main control board, a maximum of 80 Line Rates can be configured. If the UMDU is the main control board, a maximum of 7 Line Rates can be configured.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Board specifications: A maximum of 7 Line Rates can be configured on a WMPT/UMPTa/UMPTb/UMDU. A maximum of 5 Line Rates can be configured on a UMPTe/UMPTg/UMPTga/GTMUb/GTMUc. A maximum of 3 Line Rates can be configured on an LMPT. A maximum of 6 Line Rates can be configured on a UTRPc. A maximum of 4 Line Rates can be configured on a UTRP (subboard type: UIEC/UQEC/UAEC). A maximum of 2 Line Rates can be configured on a UTRP (subboard type: UEOC). A maximum of 4 Line Rates can be configured on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Currently, the base station supports a maximum of four modes, and therefore tunnel-based transmission resource groups are used only for rate limitation on uplink data streams. It is recommended that each base station with an uplink tunnel be configured with a tunnel-based transmission resource group whose rate configurations are the same as line rates.

  • [Co-MPT,eNodeB,gNodeB]The LMPT board can be configured with a maximum of 360 Mbit/s the uplink committed information rate, 400 Mbit/s committed burst size, 450 Mbit/s excessive burst size and 540 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,eGBTS]The GTMUb/GTMUc can be configured with a maximum of 100 Mbit/s the uplink committed information rate and 100 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [NodeB]The WMPT board can be configured with a maximum of 100 Mbit/s the uplink committed information rate, 600 Mbit/s committed burst size, 600 Mbit/s excessive burst size and 100 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

LRSW LR Switch

Meaning: Indicates the switch for limiting the line rate at the port.

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE, the rate of a physical port is restricted. If this parameter is set to DISABLE, the rate of a physical port is not restricted. Rate restriction of physical ports is necessary if the bandwidth of a transport network is limited. The transport network may incur congestion or packet loss when its bandwidth is limited and rate restriction is disabled.

Applicable Mode: G, U, L, N
CIR UL Committed Information Rate

Meaning: Indicates the UL committed information rate after rate limitation is configured at a port. The precision of the UL committed information rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s, the precision supported by the other board is 32 kbit/s. If the configured UL committed information rate is not a multiple of the precision, the UL committed information rate is rounded up. For the GTMUb, the value of CIR ranges from 64 to 100000. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the UL Committed Information Rate parameter in the PORTLR MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

DLCIR DL Committed Information Rate

Meaning: Indicates the DL committed information rate after rate limitation is configured at a port. The parameter does not take effect in GSM and NR. For UMTS, if the downlink flow control switch is set to DYNAMIC_BW_SHAPING or STATIC_BW_SHAPING, this parameter is valid. If the downlink flow control switch is set to BW_SHAPING_ONOFF_TOGGLE, this parameter is valid when traffic congestion is detected. In other cases, this parameter is invalid. For LTE, this parameter computes the value of Physical Port Down Link Admission. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga or UMDU is 64 kbit/s.

Example

To set the line rate with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Port Type: Ethernet Port, Port No.: 0, LR Switch: Enable, UL Committed Information Rate: 32, Committed Burst Size: 64, Excess Burst Size: 3, DL Committed Information Rate: 100000, run the following command:
SET LR: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, LRSW=ENABLE, CIR=32, CBS=64, EBS=3, DLCIR=100000;
