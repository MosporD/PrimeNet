Remove Ethernet Trunk (RMV ETHTRUNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an Ethernet trunk.

Note

When an ETHTRUNK MO is removed on the MAE-Deployment, its adaptive port IP transmission resource group is automatically removed, regardless of whether the IP transmission resource group is manually or automatically created.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of the Ethernet trunk.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an Ethernet trunk with the parameter as follows: Port ID: 0, run the following command: 
RMV ETHTRUNK: PORTID=0;
