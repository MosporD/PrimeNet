Modify AAS Configuration (MOD AAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the Active Antenna System (AAS) configuration.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the AAS is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SRN Subrack No.

Meaning: Indicates the number of the subrack where the AAS is located.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
AN AAS Name

Meaning: Indicates the AAS name.

GUI Value Range: 0~99 characters

Unit: None

Actual Value Range: 0~99 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
AAUSPEC AAU Specification

Meaning: Indicates the type of an AAS. This parameter must be set to the hardware type of the AAS. After this parameter is specified, the MAE-Deployment checks the configurations of power, carrier, and receive and transmit capabilities based on the value of this parameter. This ensures that these configurations are correct before they take effect. If the user does not need to forcibly verify the AAS specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. For example, this parameter must be set to AAU3902 for AAU3902.

GUI Value Range: 0~63 characters

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
LOCATIONNAME Location Name

Meaning: Indicates the location information of an AAS. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.

GUI Value Range: 0~64 characters

Unit: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To modify an AAS with the parameters as follows: Cabinet No.: 0, Subrack No.: 70, AAS Name: "AAS-1", AAU Specification: "AAU3902", run the following command:
MOD AAS: CN=0, SRN=70, AN="AAS-1", AAUSPEC="AAU3902";
