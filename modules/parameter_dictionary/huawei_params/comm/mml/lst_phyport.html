List Management Status of Physical Port (LST PHYPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the management status configured for a physical port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the physical port is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the physical port is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board where the physical port is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Impact on Radio Network Performance: None

Example

List Management Status of Physical Port: 
LST PHYPORT:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the physical port is located.

Subrack No.

Indicates the subrack number of the board where the physical port is located.

Slot No.

Indicates the slot number of the board where the physical port is located.

Port Type

Indicates the type of the physical port.

Port No.

Indicates the number of the physical port.

Administrative State

Indicates the management status of a physical port, including blocking and unblocking.
