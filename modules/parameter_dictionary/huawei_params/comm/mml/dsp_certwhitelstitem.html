Display Digital Certificate Whitelist Record (DSP CERTWHITELSTITEM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to query the status information of a specified whitelist record.

Note

None.

Parameters

ID Name Description
CERTWHITELSTITEM Digital Certificate Whitelist Record

Meaning: Indicates the record in a digital certificate whitelist file to be queried. The record is case-insensitive.

GUI Value Range: 1~128 characters

Unit: None

Actual Value Range: 1~128 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the digital certificate whitelist record that takes effect, run the following command:
DSP CERTWHITELSTITEM: CERTWHITELSTITEM="210305394710C3000249.huawei.com";
The result is shown as follows:
+++    0        2015-09-19 20:02:05
O&M    #805306427
%%DSP CERTWHITELSTITEM: CERTWHITELSTITEM="210305394710C3000249.huawei.com";%%
RETCODE = 0  Operation succeeded.

Display CERTWHITELST
--------------------
Digital Certificate Whitelist Record  =  210305394710C3000249.huawei.com
                Configuration Status  =  Configured
(Number of results = 1)


---    END

Output Description

Field Description

Digital Certificate Whitelist Record

Indicates the record in a digital certificate whitelist file to be queried. The record is case-insensitive.

Configuration Status

Indicates the configuration status of digital certificate whitelist record.
