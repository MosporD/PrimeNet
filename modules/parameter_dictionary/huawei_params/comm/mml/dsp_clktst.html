Display Clock Quality Test Monitoring Result (DSP CLKTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the clock quality test monitoring result. The result shows the frequency or phase offset of the current clock source. The offset indicates the quality of the clock.

Note

  • The frequency offsets of different clock sources are reported at different intervals as follows: E1/T1 line clock source: 30 minutes; IP clock source: 20 minutes to 21 hours; GPS clock source: 40s to 96s; other clock source: 64s to 96s.

  • The phase offset is reported every second.

  • There is one monitoring record every filtering period. If the monitoring results of two neighboring periods are the same, the later monitoring result is filtered and not reported. Different clock sources have different filtering periods.

  • If this command is executed on a standby board, no result is displayed in the command output.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The RRU does not support frequency deviation query.

Example 1: To query the clock quality test monitoring result in slot 7 with Frequency Discrimination type, run the following command:
DSP CLKTST: SRN=0, SN=7;

Output Description

Field Description

Time

Indicates the time corresponding to each record.

Frequency Discrimination(ppb)

Indicates the frequency offset of clock references.

Phase Discrimination(ns)

Indicates the phase offset of clock references. NULL indicates that the phase offset value is invalid.

PLL Status

Indicates the PLL status of the board. It also indicates whether the system clock is stable. The PLL status of the board can be Fast tracking, Locked, Holdover, or Free running.
