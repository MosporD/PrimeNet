Modify CCU (MOD CCU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a cabinet control unit (CCU).

Note

  • If the manager unit is a BBU, the CCU can only connect to the MON0 port on the BBU.

  • A manager unit can directly connect to only one CCU.

  • If a CCU directly connects to a manager unit RRU, this command can be executed to change the manager unit of the CCU only when Operational State of the RRU is Enabled.

  • If a CCU connects a primary BBU and a secondary BBU, the manager of the CCU must be the primary BBU.

  • The Connected RAT parameter does not apply to 5G.

  • For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

Example

To modify a CCU with the parameters as follows: Cabinet No.: 0, Cascade No.: 2, run the following command:
MOD CCU: CN=0, CCN=2;
