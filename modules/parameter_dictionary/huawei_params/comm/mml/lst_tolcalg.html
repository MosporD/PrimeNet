List Overload Control Algorithm Configuration (LST TOLCALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations for the overload control algorithm.

Note

[Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

Parameters

None.

Example

To list the OLC configuration, run the following command:
LST TOLCALG:;
The result is shown as follows:

Output Description

Field Description

Uplink OLC Algorithm Switch

Indicates the UL Over Load Control (OLC) algorithm switch. When this switch is set to ON, bandwidth of the services with a low priority will be released to guarantee the QoS of the services with a high priority when TX bandwidth changes or during the overload caused by non-flow-control services.

Downlink OLC Algorithm Switch

Indicates the UL Over Load Control (OLC) algorithm switch. When this switch is set to ON, bandwidth of the services with a low priority will be released to guarantee the QoS of the services with a high priority when TX bandwidth changes or during the overload caused by non-flow-control services.

Uplink OLC Trigger Threshold(%)

Indicates the threshold for triggering the UL OLC. When the UL bandwidth usage reaches the threshold, low-priority services are removed to guarantee the quality of high-priority services.

Uplink OLC Release Threshold(%)

Indicates the threshold for clearing the UL OLC. When the UL bandwidth usage is below this threshold, user services are no longer removed.

Number of Bearers Released During OLC

Indicates the number of released services during an OLC action period.

Downlink OLC Trigger Threshold(%)

Indicates the threshold for triggering the DL OLC. When the DL bandwidth usage reaches the threshold, low-priority services are removed to guarantee the quality of high-priority services.

Downlink OLC Release Threshold(%)

Indicates the threshold for clearing the DL OLC. When the DL bandwidth usage is below this threshold, user services are no longer removed.
