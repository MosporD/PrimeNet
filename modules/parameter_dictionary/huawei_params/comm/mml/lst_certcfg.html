List Digital Certificate Basic Configuration (LST CERTCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to query the basic configuration of a digital certificate.

Note

None.

Parameters

None.

Example

To list cert basic configuration data, run the following command:
LST CERTCFG:;
The result is shown as follows: 
+++    0        2015-09-19 20:00:43
O&M    #805306417
%%LST CERTCFG:;%%
RETCODE = 0  Operation succeeded.

List Cert Basic Configuration Data
----------------------------------
IKE Check Switch  =  Off
(Number of results = 1)


---    END

Output Description

Field Description

IKE Check Switch

Indicates the whitelist check switch for an IKE digital certificate. If an IKE peer uses the RSA digital signature to authenticate an IKE proposal, authentication of the peer identity fails, resulting in an IKE negotiation failure when the following conditions are met: this parameter is set to ON; the base station digital certificate whitelist file has been activated but the common name of the peer device certificate is not among the digital certificate whitelist file. You can run the LST CERTFILE command to query whether the digital certificate whitelist has been activated, and the DSP CERTWHITELSTITEM command to query whether the common name of the peer device certificate is among the digital certificate whitelist file. When this parameter is set to OFF, the common name of the peer device certificate is not checked no matter whether the base station certificate whitelist has been activated.
