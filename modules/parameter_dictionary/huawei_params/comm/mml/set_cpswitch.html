Set CP Switch (SET CPSWITCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the switch for the active/standby control port (CP) switchover.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [NodeB]If only the standby CP bearer is configured, it takes effect regardless of whether active/standby CP bearer switchover is enabled.

  • [NodeB]If a BS currently uses the standby CP bearer, the BS does not switch back to the active CP bearer even if the active CP bearer is recovered after this switch is disabled.

  • [NodeB]The settings of this switch must be the same as those on the base station controller sides. Otherwise, the switchover status is inconsistent on both sides, which leads to faulty CP bearers.

Parameters

ID Name Description
ES CP Switch Flag

Meaning: Indicates whether to enable active/standby switchover between CPs.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To set the status of the switch for the active/standby CP with the parameter as follows: CP Switch Flag: ENABLE, run the following command: 
SET CPSWITCH: ES=ENABLE;
