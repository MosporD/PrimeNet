Display LLDP Local Global Info (DSP LLDPPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of an LLDP port.

Note

  • The default values configured automatically by the system, see Note of the command ADD LLDPPORT.

  • The chassis ID is the MAC address of the LLDP port. The value of Chassis ID Subtype is MAC Address.

  • The value of Port ID Subtype is Interface Name.

  • Both the values of Port ID and Port Description consist of the Ethernet and the cabinet, subrack, slot, and port number for the LLDP port.

  • The system name is the same as the NE name.

  • System Description consists of the vendor, product family, and base station model.

  • Both System Capabilities Supported and System Capabilities Enabled are set to Router.

  • If an OMCH is configured, the management address is the OM IP address or OM IP6 address. Otherwise, the management address is empty.

  • The BS does not support port VLANs.

  • The system does not support or enable ports and protocol VLANs.

  • By default, the system supports auto negotiation and Ethernet trunk.

  • The maximum frame size is the sum of the MAC header and MAC check bit length (18 bytes in total), VLAN header length (4 bytes when a VLAN is configured or 0 bytes when VLANs are not configured), and maximum transmission unit (MTU) length. If the LLDP port has been added to an Ethernet trunk link, the MTU is that of the Ethernet trunk. Otherwise, the MTU is that of the LLDP port.

  • The VLAN name consists of the string "VLAN" and the VLAN ID. The VLAN ID can be that in the ADD VLANMAP command, that in the ADD VLANCLASS command, or that in the ADD SUBNETVLAN command. The same VLAN ID in these commands is processed for only once. The system supports a maximum of 32 VLAN names.

Example

To query the LLDP Port Status with the parameters as follows: Slot No.: 7, Subboard Type: Base Board, Port No.: 1, run the following command:
DSP LLDPPORT: SN=7, SBT=BASE_BOARD, PN=1;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the LLDPLOCAL is located.

Subrack No.

Indicates the subrack number of the board where the LLDPLOCAL is located.

Slot No.

Indicates the slot number of the board where the LLDPLOCAL is located.

Subboard Type

Indicates the type of sub-board on the board where the LLDPLOCAL is located.

Port No.

Indicates the number of the Ethernet port where the LLDPLOCAL is located.

Chassis ID Subtype

Indicates the subtype of a chassis ID.

Chassis ID

Indicates the chassis ID of a device. The port that receives LLDP information can use Chassis ID and Port ID to identify a peer device.

Port ID Subtype

Indicates the subtype of a port ID.

Port ID

Indicates the ID of a port.

Port Description

Indicates the description of an LLDP port.

System Name

Indicates the system name.

System Description

Indicates the system description, such as the vendor, device name, hardware type, and version information about the software operating system. Such system data is useful in collecting the network traffic.

System Capabilities Supported

Indicates the capabilities supported by the system. The capabilities reflect the main functions of the system. A single system can provide multiple functions, such as routing, bridge, and relay.

System Capabilities Enabled

Indicates the enabled system capabilities.

Management Address Type

Indicates the type of a management address.

Management Address

Indicates the management address that the network management system uses to manage and identify a network device.

Number of VLAN Name

Indicates the number of VLAN names recorded in the VLAN name list.

VLAN Name List

Indicates the list of VLAN names. A VLAN name list consists of three fields: VLAN ID, bracket, and VLAN name. A VLAN name list supports a maximum of 32 VLAN names.

Binding VLAN

Indicates whether the local LLDP port is associated with the VLAN. If the local LLDP port is bound to a VLAN, LLDP packets sent by the local end carry the VLAN ID.

VLAN ID

Indicates the VLAN ID of local LLDP port.

VLAN Priority

Indicates the VLAN priority of local LLDP port.
