Modify SCTP Host (MOD SCTPHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify an SCTP host.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eNodeB,gNodeB]If one or more of the following parameters in an SCTPHOST object are modified, the link objects that are automatically created for the SCTP host will be modified, or removed and then added: First Local IP Address, IPSec Auto Configure Switch for First Local IP, Security Host ID for First Local IP, Second Local IP Address, IPSec Auto Configure Switch for Second Local IP, Security Host ID for Second Local IP, Local SCTP Port No., VRF Index, Simple Mode Switch, First End Point Group ID, and Second End Point Group ID. Link objects include SCTPLNK, CPBEARER, ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY .

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the DEVIP or IPADDR4 object on which an SCTPHOST object depends is modified, the following link objects that are automatically created for the SCTPHOST object will be modified: SCTPLNK, CPBEARER, ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects that are automatically configured for an SCTP link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the SCTPHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPPEER object in the same end point group.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects that are automatically configured for an SCTP link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the SCTPHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPPEER object in the same end point group.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

  • [NodeB,eGBTS,eNodeB,gNodeB]During self-setup of the control plane (for example, for the X2/eX2/uX2 interface), the port numbers of the SCTP hosts for adjacent base stations must be the same. In addition, the port number of the SCTP peer must be the same as the port number of the SCTP host for these base stations. Otherwise, the SCTP link negotiation fails.

  • [Co-MPT,eNodeB,gNodeB]Modifying any of the following parameters interrupts service that references this SCTP host: First Local IP Address, First Local IPv6 Address, IPSec Auto Configure Switch for First Local IP, Security Host ID for First Local IP, Second Local IP Address, Second Local IPv6 Address, IPSec Auto Configure Switch for Second Local IP, Security Host ID for Second Local IP, Local SCTP Port No., VRF Index, Simple Mode Switch, First End Point Group ID and Second End Point Group ID.

  • [Co-MPT,eNodeB,gNodeB]If one or more of the following parameters in an SCTPHOST object are modified, the link objects that are automatically created for the SCTPHOST object will be modified, or removed and then added: First Local IPv6 Address, IPSec Auto Configure Switch for First Local IP, Security Host ID for First Local IP, Second Local IPv6 Address, IPSec Auto Configure Switch for Second Local IP, Security Host ID for Second Local IP, Local SCTP Port No., VRF Index, Simple Mode Switch, First End Point Group ID, and Second End Point Group ID. Link objects include SCTPLNK.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met, the system will remove the TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects that are automatically configured for an SCTP link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the SCTPHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPPEER object in the same end point group.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

  • [NodeB]Modifying any of the following parameters interrupts service that references this SCTP host: First Local IP Address, IPSec Auto Configure Switch for First Local IP, SIGIP1SECHOSTID, Security Host ID for First Local IP, IPSec Auto Configure Switch for Second Local IP, Security Host ID for Second Local IP, Local SCTP Port No.

SIGIP1SECSWITCH IPSec Auto Configure Switch for First Local IP

Meaning: Indicates whether to use the first local IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the first local IP address of the SCTP host. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPHOST command, the system automatically deletes the IPsec tunnel that has been automatically set up.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: If the networking mode does not support IPSec or IPSec tunnels are to be set up by manually configuring IPSec objects, this parameter must be set to DISABLE.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPHOST MO is not set to SIMPLE_MODE_OFF, both the SIGIP1SECSWITCH and SIGIP2SECSWITCH parameters in the SCTPHOST MO must be set to DISABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv4 and SIGIP1SECSWITCH or SIGIP2SECSWITCH is set to ENABLE, VRFIDX must be set to 0.
  • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv6 and SIGIP2V6 is valid, SIGIP1SECSWITCH and SIGIP2SECSWITCH in the SCTPHOST MO must be set to DISABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Control-plane SCTP links or IPv6 SCTP links are unavailable, cells are abnormal, and UEs cannot access the network if this parameter is set to DISABLE and no IPSec tunnel has been set up between the SCTP host and the SCTP peer for the SCTP links or IPv6 SCTP links in an IPSec-protected network.

Applicable Mode: U, L, N

DTLSCONNPOLICY DTLS Connection Policy

Meaning: Indicates the DTLS connection policy. DTLS_ONLY indicates that the local end uses only DTLS connections. If the peer end does not support or is not configured with DTLS, the negotiation fails. DTLS_PRIORITY indicates that the local end attempts to establish a DTLS connection for the first time. If the peer end does not support or is not configured with DTLS, the local end uses the SCTP connection. If this parameter is set to DTLS_PRIORITY, the security is reduced. Therefore, you are advised not to set this parameter to DTLS_PRIORITY. This parameter applies only to NR.

GUI Value Range: DTLS_ONLY(DTLS Forcible Connection), DTLS_PRIORITY(DTLS Preferential Connection)

Unit: None

Actual Value Range: DTLS_ONLY, DTLS_PRIORITY

MML Default Value: None

Recommended Value: DTLS_ONLY(DTLS Forcible Connection)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

Meaning: Indicates the list of SCTP chunk types for which the local end requires the peer end to support authentication. Example

To modify an SCTP host with the parameters as follows: SCTP Host ID: 0, Local SCTP Port No.: 1080, SCTP Parameters Template ID: 1, DTLS Policy ID: NULL, User Label: signaling plane host, run the following command:
MOD SCTPHOST: SCTPHOSTID=0, PN=1080, SCTPTEMPLATEID=1, DTLSPOLICYID=NULL, USERLABEL="signaling plane host";
