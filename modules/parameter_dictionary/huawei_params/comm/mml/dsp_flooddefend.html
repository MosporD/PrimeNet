Display Statistical Information of Flood Attack Packets (DSP FLOODDEFEND)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query information about flood packets.

Note

The system measures the number of flood packets only when the flood attack defense object exists and the flood attack defense function is enabled.

Parameters

ID Name Description
FLDTYPE Flood Type

Meaning: Indicates the type of the flood packet. If the control bits are all 0 or both the Synchronize bit and No More Data bit are 1 in TCP packets, the packets are directly discarded and flood attack defense is not performed. SYN packets refer to packets whose Synchronize bit is 1 and Acknowledgement bit is 0. When the defenses against attacks of the SYN and TCP packets are both enabled but the SYN packet data rate does not reach the flood attack defense threshold for SYN packets, the flood attack defense threshold for TCP packets is used to trigger the defense. When the data rate of some SYN packets reaches the flood attack defense threshold for SYN packets, this threshold is used to trigger the defense against the attack of these SYN packets and the flood attack defense threshold for TCP packets is used to defend against the attack of SYN packets of which the rate does not reach the flood attack defense threshold for SYN packets.

Disuse statement: In the later versions, the value SCTP_INIT (SCTP_INIT) will be removed from the value range of this parameter. In the current version, this value can still be configured but the value does not take effect. Therefore, you are not advised to use the value SCTP_INIT (SCTP_INIT).

Example

To query information about flood packets with the parameters as follows: Flood Type: ICMP, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Clear Flag: NO, run the following command:
DSP FLOODDEFEND: FLDTYPE=ICMP, CN=0, SRN=0, SN=6, CLEAR=NO;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.

Flood Type

Indicates the type of the flood packet. If the control bits are all 0 or both the Synchronize bit and No More Data bit are 1 in TCP packets, the packets are directly discarded and flood attack defense is not performed. SYN packets refer to packets whose Synchronize bit is 1 and Acknowledgement bit is 0. When the defenses against attacks of the SYN and TCP packets are both enabled but the SYN packet data rate does not reach the flood attack defense threshold for SYN packets, the flood attack defense threshold for TCP packets is used to trigger the defense. When the data rate of some SYN packets reaches the flood attack defense threshold for SYN packets, this threshold is used to trigger the defense against the attack of these SYN packets and the flood attack defense threshold for TCP packets is used to defend against the attack of SYN packets of which the rate does not reach the flood attack defense threshold for SYN packets.

Number of Flood Dropped Packets(packet)

Indicates the number of packets discarded because the total number of flood packets exceeds the specified threshold.

Receive Total Packets(packet)

Indicates the total number of received attack packets.
