Display Board Certificate Information (DSP BRDCERTMK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the certificate information of boards.

Note

  • Certificates on all boards can be queried.

  • This command is used to query only the preconfigured device certificate of a certificate deployment board. To query the operator certificate, run the DSP CERTMK command.

  • This command performs operations to files, which may cause query failures when the system is busy. In this case, try again later.

SN Slot No.

Meaning: Indicates the number of the slot where the board is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SN must meet the following conditions: 1. When SRN is set to 0 or 1, SN must be set to a value within the range of 0 to 7, 16, 18, or 19. In addition, the value of SN ranges from 0 to 6 in the BLK BRD or UBL BRD command, the value of SN ranges from 6 to 7 in the MOD PEERMODE command; 2. When SRN is set to 4 or 5 and TYPE in the CABINET MO is set to BTS3900AL, the value of SN ranges from 0 to 8; When SRN is set to 4 or 5 and TYPE in the CABINET MO is not set to BTS3900AL, the value of SN ranges from 0 to 5; 3. When the value of SRN is set to 60, SN ranges from 0 to 5; 4. When the value of SRN ranges from 61 to 254, SN ranges from 0 to 3; 5. When TYPE in the SUBRACK MO is set to BBU5900A, SN can be set to 0, 2, 4, 6, or 16 to 19.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the number of the subrack where the board is located.

Slot No.

Indicates the number of the slot where the board is located.

Certificate File Name

Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colons (:), asterisks (*), question marks (?), double quotation marks ("), left angle brackets (<), right angle brackets (>), and bars (|).

Issuer

Indicates the issuer of a device certificate.

Common Name

Indicates the common name of a device certificate.

Serial Number

Indicates the serial number of a device certificate.

Effective Date

Indicates the date when a device certificate begins to take effect.

Expiration Date

Indicates the expiration date of a device certificate.

Status

Indicates the status of a device certificate.

Key Type

Indicates the key type.

Key Size

Indicates the key size.

Ecc Curve

Indicates the name of the elliptic curve used by the key when the certificate key type is ECDSA. The elliptic curve allows P256 (secp256r1), P384 (secp384r1), and ED25519. ED25519 indicates the EdDSA signature scheme using SHA-512 and Curve25519.
