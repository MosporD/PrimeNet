Modify RVD (MOD RVD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a remote vendor-defined antenna line device (RVD).

Note

  • Before modifying the controlling RRU or RFU, ensure that the power switch for the control port is turned on. This ensures that the RVD can work properly. For details about how to query the port status, see the reference of the DSP ANTENNAPORT and DSP RETPORT commands. For details about how to modify the port status, see the reference of the MOD ANTENNAPORT and MOD RETPORT commands.

  • The antenna scenario must be set based on the hardware installation. In non-regular scenarios, the vendor code and serial number of the device must be specified. Otherwise, the system cannot communicate with the ALD properly. When modifying the vendor code or serial number of the device, ensure that neither of them is left blank. If one of them is left blank, the command execution fails. To query the vendor code and the serial number of the device, run the SCN ALD command.

  • In the scenario where two RRUs/RFUs share a TMA, if the controller of an RVD is changed from RRU/RFU 1 to RRU/RFU 2, the controller of other ALDs must also be changed from RRU/RFU 1 to RRU/RFU 2. The change of the controller is implemented by reconfiguring CTRLCN, CTRLSRN, and CTRLSN. The period of time required by the control port switchover varies with the TMA model. If the TMA software does not switch over the control port within a period of time after this command is executed, ALM-26541 ALD Maintenance Link Failure will be generated. In this case, wait for 5 to 10 minutes after all the controllers are changed, and then run the SCN ALD command to scan the RRU/RFU controlling the ALDs. After the scanning is complete, the RVD maintenance link will recover and the alarm will be cleared. If the alarm persists, clear the alarm with recommended actions.

DEVICENAME Device Name

Meaning: Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

GUI Value Range: 0~83 characters

Unit: None

Actual Value Range: 0~83 characters

MML Default Value: None

Recommended Value: None

[eNodeB]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

Example

To modify an RVD with the parameters as follows: Device No.: 0, Antenna Scenario: REGULAR, run the following command:
MOD RVD: DEVICENO=0, SCENARIO=REGULAR;
