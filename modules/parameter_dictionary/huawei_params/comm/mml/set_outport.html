Set Output Port (SET OUTPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an output port (relay).

Note

  • Before setting an output port, ensure that the corresponding EMU or UMDU has been added.

  • If the EMU or UMDU is not started, this command may fail.

  • The output port can be configured only on an EMU or UMDU.

Example

To set the information about the output port with the parameters as follows: Subrack No.: 40, Port No.: 5, Port Name: Water Alarm, Port Switch: ON, run the following command:
SET OUTPORT: SRN=40, PN=5, NAME="Water Alarm", SW=ON;
