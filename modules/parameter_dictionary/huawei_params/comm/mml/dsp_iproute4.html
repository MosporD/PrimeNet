Display IPv4 Route Table (DSP IPROUTE4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about all the static IPv4 routes.

Note

  • The DSP IPROUTE4 command output shows the MTU value that takes effect. If an MTU value has been configured using the ADD IPROUTE4 command, the effective MTU value is the smaller one between the MTU value of the actual outbound interface and the configured MTU value. If an MTU value has not been configured using the ADD IPROUTE4 command, the effective MTU value is the MTU value of the actual outbound interface.

  • The MTU value of the direct route is the MTU value of the actual outbound interface.

  • The IPv4 route index cannot be used to query a single route that does not take effect.

  • When the port type of the queried IPv4 route is interface, the port ID indicates the interface number. That is, IPv4 packets are transmitted through this interface.

  • When active and standby OM channels are used, the active and standby OM channels must be bound to routes. Only the route that is bound to the activated OM channel takes effect, and the route that is bound to the deactivated OM channel does not take effect. This command can be used to query the ineffective route bound to the OM channel.

  • The queried values of Port Type and Port ID are invalid for the direct gateway route generated using an IP address synchronized from the USU side. The IP address can be queried using the DSP TPMSYNINFO command.

DSTIP Destination IP

Meaning: Indicates the destination IP address of the IPv4 route.

Unit: None

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]DSTIP in an IPROUTE4 MO must be a valid IP address of class A, B, or C. It can be set to 0.0.0.0, but cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If one of DSTMASK and DSTIP in an IPROUTE4 MO is set to 0.0.0.0, the other must be set to 0.0.0.0, too.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The result of DSTIP AND DSTMASK in an IPROUTE4 MO must be equal to DSTIP. That is, DSTIP must be set to a network IP address.

Service Interrupted After Modification: Yes

Output Description

Field Description

Route Index

Indicates the index of an IPv4 route.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Destination IP

Indicates the destination IP address of the IPv4 route.

Mask

Indicates the destination subnet mask of the IPv4 route.

Route Type

Indicates the type of an IPv4 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded to a specified outbound interface.

Next Hop IP

Indicates the next-hop IP address.

Port Type

Indicates the type of the port.

Port ID

Indicates the port ID of an IPv4 route.

Peer IP

Indicates the peer IP address of an air interface link. Only UMPT/LMPT/UMDU boards for LTE support IP routes of the air interface link type.

Maximum Transmission Unit(byte)

Indicates the maximum transmission unit of a transmission link. The smaller value between this parameter value and the maximum transmission unit configured for interface corresponding to the routed interface prevails on the base station.

Preference

Indicates the priority of the routing entry. A smaller parameter value indicates a higher priority.

Cabinet No.

Indicates the cabinet number of the board to which an IPv4 route belongs.

Subrack No.

Indicates the subrack number of the board to which an IPv4 route belongs.

Slot No.

Indicates the slot number of the board to which an IPv4 route belongs.

Actual Port Type

Indicates the type of the actual port.

Actual Port No.

Indicates the number of the actual port. When the actual port type is Ethernet trunk, the actual port number indicates the port ID of the Ethernet trunk. When the actual port type is tunnel, the actual port number indicates the port ID of the backplane tunnel.

Route Protocol

Indicates the type of the router entry of an IPv4 route. A static host route is a manually configured route with the subnet mask set to 255.255.255.255. A static gateway route is a manually configured route with the subnet mask not being 255.255.255.255. A direct host route is a dynamically generated IPv4 route with the subnet mask being 255.255.255.255. A direct gateway route is a dynamically generated IPv4 route with the subnet mask not being 255.255.255.255.

Valid State

Indicates the validity state of an IPv4 route.
