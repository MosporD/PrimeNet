Check E1/T1 Port for Crossed Pair Connection (CHK E1T1CRS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to check an E1/T1 port for crossed pair connections.

Note

[Co-MPT,NodeB,eGBTS,eNodeB]Checking an E1/T1 port for crossed pair connections will interrupt services carried on the E1/T1 port. It is recommended that this operation be performed only during site deployment or site upgrade.

SBT Subboard Type

GUI Value Range: E1_COVERBOARD(E1 Cover Board), BASE_BOARD(Base Board)

Unit: None

Actual Value Range: E1_COVERBOARD, BASE_BOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB]When configuring an E1T1 MO, ensure that this parameter is set to E1_COVERBOARD if SN is set to 0 to 5.
  • When configuring an E1T1 MO, ensure that this parameter is set to BASE_BOARD if SN is set to 6 or 7.
  • When adding an E1T1 MO to a backplane, ensure that this parameter is set to BACK_BOARD.
  • When querying an E1T1 MO, ensure that this parameter is set to E1_COVERBOARD or BACK_BOARD if SN is set to 0 to 5.
  • When querying an E1T1 MO, ensure that this parameter is set to BASE_BOARD or BACK_BOARD if SN is set to 6 or 7.

Example

To check the status of the E1/T1 port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: BASE_BOARD, run the following command: 
CHK E1T1CRS: CN=0, SRN=0, SN=7, SBT=BASE_BOARD;
The result is shown as follows:

Indicates the number of the subrack where the port is located.

Slot No.

Indicates the port number.

Indicates the number of the peer port.
