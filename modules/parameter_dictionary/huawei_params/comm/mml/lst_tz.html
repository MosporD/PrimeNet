List Time Zone and DST Information (LST TZ)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the time zone and the daylight saving time (DST) information about the NE.

Note

In the displayed result, the start time observes standard time, and the end time observes DST.

Parameters

None.

Example

Example 1: To list the time zone and DST information, run the following command:
LST TZ:;
The result is shown as follows:
+++    0        2008-05-17 07:37:40
O&M    #32
%%LST TZ:;%%
RETCODE = 0  Operation succeeded.

Time Zone and Daylight Saving Time Information
----------------------------------------------
      Time Zone  =  GMT-12:00
DST Information  =  No

---    END

Example 2: To query DST information with parameters as follows: DST Start Mode: DATE, DST End Mode: DATE, run the following command:
LST TZ:;
The result is shown as follows:
+++    0        2008-05-17 12:06:55
O&M    #30
%%LST TZ:;%%
RETCODE = 0  Operation succeeded.

Time Zone and Daylight Saving Time Information
----------------------------------------------
      Time Zone  =  GMT-12:00
 DST Start Date  =  January 2
 DST Start Time  =  10:49:46
   DST End Date  =  February 26
   DST End Time  =  10:49:46
DST Offset(min)  =  30
   
---    END

Example 3: To query DST information with parameters as follows: DST Start Mode: WEEK, DST End Mode: DATE, run the following command:
LST TZ:;
The result is shown as follows:
+++    0        2008-01-03 10:01:02
O&M    #8
%%LST TZ:;%%
RETCODE = 0  Operation succeeded.

Time Zone and Daylight Saving Time Information
----------------------------------------------
      Time Zone  =  GMT-12:00
 DST Start Date  =  Last Tuesday in January
 DST Start Time  =  10:53:06
   DST End Date  =  February 26
   DST End Time  =  10:53:06
DST Offset(min)  =  30
   
---    END

Example 4: To query DST information with parameters as follows: DST Start Mode: DATEWEEK, DST End Mode: DATE, run the following command:
LST TZ:;
The result is shown as follows:
+++    0        2008-01-03 10:01:57 DST
O&M    #10
%%LST TZ:;%%
RETCODE = 0  Operation succeeded.

Time Zone and Daylight Saving Time Information
----------------------------------------------
      Time Zone  =  GMT-12:00
 DST Start Date  =  First Tuesday starting from January 1
 DST Start Time  =  10:59:42
   DST End Date  =  February 26
   DST End Time  =  10:59:42
DST Offset(min)  =  30
   
---    END

Output Description

Field Description

Time Zone

Indicates the time zone of the NE.

DST Information

Indicates the Daylight Saving Time (DST) information.

DST Start Date

Indicates the day of the month on which DST starts.

DST Start Time

Indicates the time when DST starts.

DST End Date

Indicates the day of the month on which DST ends.

DST End Time

Indicates the time when DST ends.

DST Offset(min)

Indicates the offset of DST from standard time (unit: minute).
