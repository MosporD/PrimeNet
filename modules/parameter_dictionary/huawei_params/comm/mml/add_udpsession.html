Add UDP Session (ADD UDPSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add a UDP session.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]This command requires support from the peer NE. Therefore, the UDP loopback must be enabled on the peer NE, and the loopback UDP port number must be 65043. Only GSM currently supports this function.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The local IP address for the UDP session must be different from the peer IP address.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The local IP address for the UDP session must be the configured DEVIP or IPADDR4 in the same routing domain or the local IP address of PPPLNK or MPGRP.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The peer IP address for the UDP session must not be the configured local DEVIP or IPADDR4 in the same routing domain, the local IP address of PPPLNK or MPGRP, or the IP address of the local or remote maintenance channel.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The source and destination IP addresses of two UDP sessions cannot be the same at the same time.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the UMPT/UMDU/GTMUb/GTMUc is the main control board, a maximum of 4 UDP sessions can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum of 4 UDP sessions can be configured on a UMDU/LMPT/GTMUb/GTMUc/UTRPc/UCCU/UTRP (the subboard type is UEOC/UQEC/UIEC/UAEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • [Co-MPT,NodeB,eGBTS,eNodeB]A maximum of two UDP sessions with the same UDP session group ID can be configured.

Example

To add a UDP session with the parameters as follows: UDP Session ID: 0, Local IP Address: 172.16.177.2, Peer IP Address: 172.16.177.3, run the following command: 
ADD UDPSESSION: UDPSN=0, LOCALIP="172.16.177.2", PEERIP="172.16.177.3";
