Remove IP Path Route (RMV IPPATHRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to remove an IP path route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

  • [Co-MPT,eNodeB]Running this command interrupts services depending on the IP path route.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L
SRCIP Source IP

Meaning: Indicates the source IP address of an IP path route. The source IP address must be the same as the configured device IP address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]SRCIP in an IPPATHRT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, eGBTS, eNodeB]In an IPPATHRT MO, SRCIP must be different from DSTIP.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L
DSTIP Destination IP

Meaning: Indicates the destination IP address of an IP path route.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]DSTIP in an IPPATHRT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, eGBTS, eNodeB]In an IPPATHRT MO, SRCIP must be different from DSTIP.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L

Example

To remove an IP path route with the parameters as follows: VRF Index: 0, Source IP: 10.52.21.89, Destination IP: 10.52.26.1, run the following command:
RMV IPPATHRT: VRFIDX=0, SRCIP="10.52.21.89", DSTIP="10.52.26.1";
