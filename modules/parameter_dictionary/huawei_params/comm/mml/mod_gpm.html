Modify GPM Detection (MOD GPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify a GPM detection.

Note

None.

Parameters

ID Name Description
GPMID GPM ID

Meaning: Indicates the No. of a GPM detection.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the IP GPM Detection ID parameter in the IPGPM MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To modify a GPM with parameters as follows: GPM ID: 0, Detect Direction: UP, Delay Detect Method: FPDT, Detect Object: RSCGRP, Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Subboard Type: E1_COVERBOARD, Port Type: PPP, Port No.: 0, Transmission Resource Group ID: 1, run the following command:
MOD GPM: GPMID=0, DIR=UP, DDM=FPDT, DETECTOBJECT=RSCGRP, CN=0, SRN=0, SN=0, SBT=E1_COVERBOARD, PT=PPP, PN=0, RSCGRPID=1;
