Display ARP Blacklist (DSP ARPSPOOFING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the blacklist in an ARP table.

Note

  • After the system learns the ARP table entries for 1 min, ARP spoofing is performed on the system.

  • This command lists a maximum of 390 IP addresses that have more than one MAC addresses for each board. For each of the IP addresses, this command records the top 10 MAC addresses from which the IP address receives the most attacks.

  • The ARP blacklist records the IP address and MAC address deemed performing ARP spoofing attacks to NEs. In addition, the security log of the base station records historical information about ARP spoofing. There is a lot of ARP spoofing attack sources. Therefore, to ensure information effectiveness, the security log of the base station records only the following information: IP address and MAC address that perform the most ARP spoofing attacks in each detection period, date and time of the first attack, and number that the ARP spoofing-related alarm is reported.

Example

To query the ARP blacklist with the parameters as follows: Slot No.: 6, run the following command:
DSP ARPSPOOFING: SN=6;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the slot number of a board.

VRF Index

Indicates the index of a VRF instance.

IP Address

Indicates the IP address in an ARP table.

Mac Address Number

Indicates the number of MAC addresses in the black list of an ARP table.

Mac Address

Indicates the MAC address list in the black list of an ARP table.
