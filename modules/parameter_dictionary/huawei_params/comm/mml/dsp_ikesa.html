Display IKE SA Status (DSP IKESA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the IKE Security Association (SA).

Note

  • Board specifications: For the UMPTa/UMPTb/UMDU/UTRPc board, a maximum of 600 SA information records can be displayed when Display Mode is set to BRIEF and a maximum of 264 SA information records can be displayed when Display Mode is set to VERBOSE. For the UMPTe/UMPTg/UMPTga board, a maximum of 1000 SA information records can be displayed when Display Mode is set to BRIEF and a maximum of 512 SA information records can be displayed when Display Mode is set to VERBOSE. For the LMPT/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 board, a maximum of 256 SA information records can be displayed when Display Mode is set to BRIEF and a maximum of 128 SA information records can be displayed when Display Mode is set to VERBOSE.

  • When the ACL rules at the two ends do not match, the IPSEC SA of IKEv1 remains in the negotiation state for a long time and the ACL rule record can be queried. An IPSEC SA of IKEv2 in the negotiation state will be deleted if the negotiation fails. In the next negotiation, a new IPSEC SA of IKEv2 is created.

  • [NodeB]The WMPT does not support this function.

Output Description

Field Description

IKE Version

Indicates the version of IKE.

User Display Phase

Indicates the phase of an IKE negotiation.

IKE Peer Name

Indicates the IKE SA peer name.

Connection ID

Indicates the connection ID.

IPv4 Peer Address

Indicates the peer IP address of the IKE SA.

IPv6 Peer Address

Indicates the IPv6 address of the IPv6 IKE SA peer.

SA Flag

Indicates the status of an SA. When the value of this parameter is Ready, this SA has been successfully set up. When the value of this parameter is StayAlive, the negotiation is initiated by the local end. When the value of this parameter is Heartbeat, a keepalive packet has been successfully negotiated. When the value of this parameter is Last Known Good Seq No., the local end successfully receives and authenticates the last keepalive packet from the peer end if the keepalive function is enabled. When the value of this parameter is Timeout, the keepalive packet expires. When the value of this parameter is Fading, this SA is about to expire. When the value of this parameter is Replaced, this SA is replaced by another SA that has been successfully negotiated and this SA will be removed. When the value of this parameter is None, there is no SA at present.

Exchange Mode

Indicates the exchange mode of the IKE.

UDP Source Port

Indicates the number of the source UDP port.

UDP Destination Port

Indicates the number of the destination UDP port.

Lifetime(s)

Indicates the lifetime of SA.

ACL Type

Indicates the type of the ID of the access control list.

ACL ID

Indicates the ID of an Access Control List (ACL).

Rule ID

Indicates the ID of the ACL rule.

Policy Name

Indicates the name of an IPSec policy group, which consists of four parts: the name of the IPSec policy group, the sequence number of the IPSec policy group, Rule ID, and Mod Cfg Flag. Currently, Huawei IPSec policy names do not support Mod Cfg.

Phase 1 Connection ID

Indicates the connection ID of phase 1.

Encapsulation Mode

Indicates the encapsulation mode.

Protocol 1

Indicates the type of Protocol 1. When Transform in the IPSECPROPOSAL MO is set to AH or ESP, the value of this parameter displayed in the command output is the configured protocol type. When Transform in the IPSECPROPOSAL MO is set to AH_ESP, the values of Protocol 1 and Protocol 2 are AH and ESP in the command output. These values are not necessarily displayed in this sequence.

Outgoing Protocol 1 SPI

Indicates the TX Protocol 1 SPI.

Incoming Protocol 1 SPI

Indicates the RX Protocol 1 SPI.

Protocol 2

Indicates the type of Protocol 2. When Transform in the IPSECPROPOSAL MO is set to AH or ESP, the value of this parameter displayed in the command output is NULL. When Transform in the IPSECPROPOSAL MO is set to AH_ESP, the values of Protocol 1 and Protocol 2 are AH and ESP in the command output. These values are not necessarily displayed in this sequence.

Outgoing Protocol 2 SPI

Indicates the TX Protocol 2 SPI.

Incoming Protocol 2 SPI

Indicates the RX Protocol 2 SPI.

Request Pending

Indicates requesting Pending.

Send Message ID

Indicates the sent message ID.

Received Message ID

Indicates the received message ID.

State

Indicates the SA state.

Redundancy Flag

Indicates the attribute (none/master/slave) of current IKE peer. When this parameter is set to None, the IPSec redundancy function is disabled for the current IKE peer.

IKE Reauthentication Lifetime(s)

Indicates the life cycle of IKEv2 re-authentication. If the parameter is set to NULL, the IKEv2 re-authentication function is not used. When the IKE Reauthentication Switch on NE is set to ON, if the NE serves as the initiation end and receives the re-authentication lifetime from the peer end, the NE starts the IKEv2 re-authentication using the smaller one between the re-authentication lifetimes at the local and peer ends. When this parameter is set to ON, if the NE does not receive the re-authentication lifetime from the peer end, the NE starts the IKEv2 re-authentication using the re-authentication lifetime at the local end.

IKE Reauthentication Remaining Time(s)

Indicates the remaining living time of IKEv2 re-authentication. If the parameter is set to NULL, the IKEv2 re-authentication function is not used.

Protected Flow Source IP Address

Indicates the source address of the data flow protected by the IPSec SA.

Protected Flow Source Wildcard

Indicates the source address wildcard of the data flow protected by the IPSec SA. The wildcard is used to determine which bits can be neglected when IP address matching is being performed. It can be considered as the inverse of the corresponding subnet mask.

Protected Flow Destination IP Address

Indicates the destination address of the data flow protected by the IPSec SA.

Protected Flow Destination Wildcard

Indicates the destination address wildcard of the data flow protected by the IPSec SA. The wildcard is used to determine which bits can be neglected when IP address matching is being performed. It can be considered as the inverse of the corresponding subnet mask.

IPv6 Protected Flow Source IP Address

Indicates the source IPv6 address of the data flow protected by the IPSec SA.

Prefix Length of IPv6 Protected Flow Source IP Address

Indicates the prefix length of the source IPv6 address of the data flow protected by the IPSec SA.

IPv6 Protected Flow Destination IP Address

Indicates the destination IPv6 address of the data flow protected by the IPSec SA.

Prefix Length of IPv6 Protected Flow Destination IP Address

Indicates the prefix length of the destination IPv6 address of the data flow protected by the IPSec SA.
