Modify RX Channel (MOD RXBRANCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the RX channel of an RRU or RFU. If the main antenna is responsible only for transmitting signals, you can run this command to set the switch of the RX channel of the main antenna to OFF.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • In normal conditions, the switch of the RRU or RFU RX channel is set to ON. If the switch is set to OFF, cells carried on the RRU or RFU are not functional.

  • For a separate-MPT multimode base station, RRU/RFU RX channel physical switches can be turned off only when the RX channel logical switches for all RATs are turned off. If this switch is turned on for any RAT, the RRU/RFU RX channel physical switches are turned on. On a co-MPT multimode base station, turning off the RX channel logical switches affects all RATs carried on the channel.

  • When the RRU type is MRIU, the Attenuation, the RTWP Initial0, RTWP Initial1, RTWP Initial2, RTWP Initial3, RTWP Initial4, RTWP Initial5, RTWP Initial6, and RTWP Initial7 parameters are invalid.

  • You are advised to set parameters related to the initial correction value of the RTWP only when UMTS carriers are carried over the channel specified by this parameter.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]If an RRU working in LTE TDD mode, the Attenuation, RTWP Initial0, RTWP Initial1, RTWP Initial2, RTWP Initial3, RTWP Initial4, RTWP Initial5, RTWP Initial6, and RTWP Initial7 parameters are invalid.

Meaning: Indicates the logical switch of the RX channel of the RRU or RFU, which can be set to ON or OFF. ON indicates that the logical switch of the RX channel is set to on and OFF indicates that the logical switch of the RX channel is set to off. This parameter is set to ON by default. Example

To query the dynamic information of the RX channel of the RRU with parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, RX Channel No.: 0, Attenuation: 0, run the following command:
MOD RXBRANCH: CN=0, SRN=60, SN=0, RXNO=0, ATTEN=0;
