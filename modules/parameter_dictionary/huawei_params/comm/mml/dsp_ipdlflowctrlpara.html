Display IP Downlink Flow Control Para (DSP IPDLFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the effective settings of IP downlink flow control parameters.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [Co-MPT,NodeB,eGBTS]When the Port Type parameter which it bears on is set to LOOPINT(Loop Interface), the command output displays the settings of IPDLFLOWCTRLPARA for boards that provide Ethernet ports.

  • [Co-MPT,NodeB,eGBTS]Only the effective settings of IPDLFLOWCTRLPARA for a WMPT/UMPT/UMDU/UTRPc/UTRP board can be queried using this command.

Parameters

ID Name Description
IPDLFLOWCTRALGID IP Downlink Flow Control Algorithm ID

Meaning: Indicates the ID of the IP DL flow control algorithm.

GUI Value Range: 0~143

Unit: None

Actual Value Range: 0~143

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To display IP downlink flow control para with the parameters as follows: IP Downlink Flow Control Algorithm ID: 2, run the following command:
DSP IPDLFLOWCTRLPARA: IPDLFLOWCTRALGID=2;

Output Description

Field Description

IP Downlink Flow Control Algorithm ID

Indicates the ID of the IP DL flow control algorithm.

Port Type

Indicates the type of port where the IP DL flow control algorithm is configured.

Port ID

Indicates the ID of a port where the IP DL flow control algorithm is configured.

Flow Control Switch

Indicates the switch for the IP DL flow control algorithm. If this parameter is set to STATIC_BW_SHAPING, the available HSDPA bandwidth equals the total bandwidth minus the R99 bandwidth. If this parameter is set to DYNAMIC_BW_SHAPING, flow allocation for HSDPA users is performed according to the delay and packet loss of the transmission interface board in STATIC_BW_SHAPING mode. This function requires the network controller using the 3GPP R6 protocol. Therefore, you are advised to use this function with the RNC that complies with the 3GPP R6 protocol. If this parameter is set to NO_BW_SHAPING, the BS does not allocate bandwidth according to the configuration and delay of the transmission interface board. The BS reports the air interface conditions to the controller, and then the controller allocates bandwidth. When this parameter is set to NO_BW_SHAPING, the backpressure function must be enabled on the controller side. If this parameter is set to BW_SHAPING_ONOFF_TOGGLE, the BS automatically selects either DYNAMIC_BW_SHAPING or NO_BW_SHAPING during a flow control congestion detection on a port. That is, DYNAMIC_BW_SHAPING is selected if congestion is detected; NO_BW_SHAPING is selected if congestion is not detected for a certain period of time.

Delay Variation Noise Floor Threshold(5ms)

Indicates the background noise threshold of the delay jitter above which the IP DL flow control algorithm is enabled. A link is considered to be non-congested if the delay jitter on the link is below the threshold.

Frame Loss Rate Threshold(per mill)

Indicates the port frame loss rate threshold of the IP DL flow control algorithm switch. When the frame loss rate is less than or equal to this threshold, the base station determines that the link is not congested.

Transmission Mode

Indicates the transport mode of the port.

Downlink Flow Control Enhancement Switch

Indicates the switch for controlling the enhanced IP downlink flow control feature. When the switch is set to on, the enhanced downlink flow control prevents downlink available bandwidth from sharply decreasing and downlink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

The enhanced downlink flow control feature requires the downlink FPDT IP GPM detection results. Before using this feature, run the ADD IPGPM or MOD IPGPM command to enable the downlink FPDT IP GPM detection function for the NodeB.

This switch can be configured only when flow control is set to dynamic flow control or self-selection flow control.

Bandwidth Adjustment Protection Switch

Indicates the adjustment protection switch for the IP available DL bandwidth. When this parameter is set to ON, the BS stops adjusting the available DL bandwidth of the physical port if bit error occurs on the transmission line and the bit error rate (BER) exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

Fair Flow Control Switch

Indicates the switch for the IP downlink fairness flow control. If multiple modes share transmission bandwidth and congestion occurs, the UMTS data rate may decrease due to downlink flow control and the LTE data rate may increase due to bandwidth preemption when the Flow Control Switch parameter is set to DYNAMIC_BW_SHAPING or is set to BW_SHAPING_ONOFF_TOGGLE but actually takes effect using the DYNAMIC_BW_SHAPING value. When this switch is turned on, the system guarantees the minimum downlink transmission bandwidth of the UMTS mode. This switch applies only to Ethernet ports, Ethernet trunks, and loop interfaces with Port Type set to ETH or ETHTRK.

Minimum Fair Flow Control Protection Ratio(%)

Indicates the minimum protection ratio of IP downlink fairness flow control. When the fairness flow control switch is turned on whereas the flow control is based on unfairness, the system guarantees the minimum UMTS transmission bandwidth based on the value of this parameter.

Minimum DL Available Bandwidth of Logical Port(kbit/s)

Indicates the minimum DL bandwidth of a logical port.

Min DL BW Protection Ratio of Iub Interface(%)

Indicates the minimum ratio of reducing the available downlink bandwidth over the Iub interface.

Cabinet No.

Indicates the cabinet number of the IP DL flow control algorithm switch.

Subrack No.

Indicates the subrack number of the IP DL flow control algorithm switch.

Slot No.

Indicates the slot number of the IP DL flow control algorithm switch.
