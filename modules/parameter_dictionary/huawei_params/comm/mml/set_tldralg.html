Set Transport Load Algorithm (SET TLDRALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the parameters of the traffic load threshold.

Note

  • [Co-MPT,eGBTS,eNodeB]When TRMULOLCSWITCH in the TOLCALG is set to ON, TRMULOLCRELTH must be greater than TRMULLDRTRGTH of the TLDRALG.

  • [Co-MPT,eGBTS,eNodeB]When TRMDLOLCSWITCH in the TOLCALG is set to ON, TRMDLOLCRELTH must be greater than TRMDLLDRTRGTH of the TLDRALG.

  • [Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

Parameters

ID Name Description
TRMULLDRTRGTH Uplink High Load Trigger Threshold

Meaning: Indicates the threshold for triggering the UL high load. If the ratio of the UL transport load to the UL transport bandwidth of the BS keeps above this threshold for a period of hysteresis, the UL transport load of the BS enters the high-load state. In UL high-load state, the BS sends a UL S1 TNL Load Indicator, which is set to HighLoad, to each neighboring BS through the X2 interface.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 70

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]In a TLDRALG MO, TRMULLDRTRGTH must be greater than TRMULLDRCLRTH.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value results in a higher probability that the BS UL transport load enters the high load state.

Applicable Mode: G, L

Example

To set the load reshuffling algorithm with the parameters as follows: Uplink High Load Trigger Threshold: 70, Downlink High Load Trigger Threshold: 70, Uplink High Load Clear Threshold: 65, Downlink High Load Clear Threshold: 65, Uplink Medium Load Trigger Threshold: 50, Downlink Medium Load Trigger Threshold: 50, Uplink Medium Load Clear Threshold: 45, Downlink Medium Load Clear Threshold: 45, run the following command:
SET TLDRALG: TRMULLDRTRGTH=70, TRMDLLDRTRGTH=70, TRMULLDRCLRTH=65, TRMDLLDRCLRTH=65, TRMULMLDTRGTH=50, TRMDLMLDTRGTH=50, TRMULMLDCLRTH=45, TRMDLMLDCLRTH=45;
