List RF Resource Quota Configuration (LST RFRESQUOTA)

Network Element: BTS3900, BTS5900

Function

Use this command to list configuration of RF resource quotas.

Note

None.

Parameters

ID Name Description
RFRESQUOTAID RF Resource Quota ID

Meaning: Indicates the quota ID of RF resources.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

Example 1: To list the configuration of all RF resource quota, run the following command:
LST RFRESQUOTA:;
+++    0        2018-01-09 09:38:09
O&M    #62
%%LST RFRESQUOTA:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

RF Resource Quota ID

Indicates the quota ID of RF resources.

RCS Client No.

Indicates the number of the client NE to which the quota is allocated.

Band Minimum Frequency(0.1MHz)

Indicates the minimum frequency of a band.

Band Maximum Frequency(0.1MHz)

Indicates the maximum frequency of a band.

Maximum Power(mW)

Indicates the maximum power.

RRU Scope

Indicates the scope of RRUs to which the quota is allocated.

Cabinet No.

Indicates the number of the cabinet that houses the RRU.

Subrack No.

Indicates the number of the subrack that houses the RRU.

Slot No.

Indicates the number of the slot that houses the RRU.
