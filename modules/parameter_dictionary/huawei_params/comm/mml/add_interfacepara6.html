Add IPv6 parameters of interface (ADD INTERFACEPARA6)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add IPv6 parameters of interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]If the DHCPv6 Relay Switch is enabled, you need to run the ADD DHCPSVRIP6 command to add a DHCPv6 server IP address.

  • [Co-MPT,eNodeB,gNodeB]If the DHCPv6 Relay Switch is enabled, after receiving a DHCPv6 request from a lower-level base station through a port, the base station sends a unicast DHCP request to the DHCPv6 server with the IPv6 address of the port as the source IPv6 address. Therefore, the DHCPv6 server must be able to communicate properly with the IPv6 address of the port.

  • [Co-MPT,eNodeB,gNodeB]DHCPv6 Relay function does not support multiple VRF indexes. Only VRF index 0 is supported.

  • [Co-MPT,eNodeB,gNodeB]The SEND protocol switch must be set according to the actual transmission network plan. Currently, the base station works in compatible mode and can receive both secure and insecure ND packets.

Example

Example 1: To add IPv6 parameters of interface with the parameters as follows: Interface ID: 0, SEND Switch: DISABLE, DHCPv6 Relay Switch: DISABLE, run the following command:
ADD INTERFACEPARA6: ITFID=0, SENDSW=DISABLE, DHCPRELAYSW=DISABLE;

Example 2: To add IPv6 parameters of interface with the parameters as follows: Interface ID: 0, SEND Switch: ENABLE, DHCPv6 Relay Switch: ENABLE, run the following command:
ADD INTERFACEPARA6: ITFID=0, SENDSW=ENABLE, DHCPRELAYSW=ENABLE;
