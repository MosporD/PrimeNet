Modify L2 LAN Switch Port (MOD LANSWITCHPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to modify the configuration of a layer 2 LAN switch port.

Note

[Co-MPT,eNodeB]Only the value of the User Label parameter can be changed by running this command.

Parameters

ID Name Description
PORTIDX Port Index

Meaning: Indicates the index of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port Index parameter in the LSWPORT MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~32

Unit: None

Actual Value Range: 0~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
USERLABLE User Label

Meaning: Indicates the object descriptions of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the User Label parameter in the LSWPORT MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To modify the parameter settings of the L2 lanswitch port with the parameters as follows: Port Index: 0, User Label: l2 relay, run the following command:
MOD LANSWITCHPORT: PORTIDX=0, USERLABLE="l2 relay";
