Display the Statistics of the Data Link Between Subracks (DSP BBPLNKSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of the data link between subracks. The transmission quality of the data link is measured by performing sampling on the extended interconnection port every second and accumulating the sampled values obtained in a certain period of time.

Note

  • Compared with control links, the data links are measured with a longer sample interval, which leads to lower measurement precision.

  • The BLADEBBU does not support this command.

  • This command applies only to the expanded cascade port. You can run the LST CASCADEPORT command to get the configuration of all cascade ports.

Example

To query the statistics of the data link between Subracks with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, Port No.: 6, run the following command:
DSP BBPLNKSTAT:CN=0,SRN=0,SN=3,PN=6;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the interconnection port is located.

Subrack No.

Indicates the subrack number of the board where the interconnection port is located.

Slot No.

Indicates the slot number of the board where the interconnection port is located.

Port No.

Indicates the number of the port that carries the interconnection link.

Measurement Start Time

Indicates the start time of the measurement.

IDX2 Channel No.

Indicates the number of the IDX2 channel carried on the extended interconnection port.

Total LOS Time(s)

Indicates the total Loss Of Signal (LOS) duration within the measurement periods.

Total Measured Time(s)

Indicates the total length about Loss Of Signal (LOS) or link disconnection of measurement periods.

1 Hour LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one hour. The LOS duration is measured within the measurement periods in the latest one hour.

1 Hour LOS Time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one hour.

1 Day LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one day. The LOS duration is measured within the measurement periods in the latest one day.

1 Day LOS Time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one day.

1 Week LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one week. The LOS duration is measured within the measurement periods in the latest one week.

1 Week LOS Time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one week.

sRIO Channel No.

Indicates the number of the sRIO channel carried on the extended interconnection port.

Total Link Down Time(s)

Indicates the total link disconnection duration within the measurement periods.

Total Measured Time(s)

Indicates the total length about Loss Of Signal (LOS) or link disconnection of measurement periods.

1 Hour Link Down Rate(per mill)

Indicates the ratio of the link disconnection duration to one hour. The link disconnection duration is measured within the measurement periods in the latest one hour.

1 Hour Link Down Time(s)

Indicates the link disconnection duration measured within the measurement periods in the latest one hour.

1 Day Link Down Rate(per mill)

Indicates the ratio of the link disconnection duration to one day. The LOS duration is measured within the measurement periods in the latest one day.

1 Day Link Down Time(s)

Indicates the link disconnection duration measured within the measurement periods in the latest one day.

1 Week Link Down Rate(per mill)

Indicates the ratio of the link disconnection duration to one week. The LOS duration is measured within the measurement periods in the latest one week.

1 Week Link Down Time(s)

Indicates the link disconnection duration measured within the measurement periods in the latest one week.
