Display SSL Connection Error Information (DSP SSLERRINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the error information about the Secure Sockets Layer (SSL) connection.

Note

Only the latest twenty pieces of information are displayed.

Parameters

None.

Example

To query the error information about the Secure Sockets Layer (SSL) connection, run the following command:
DSP SSLERRINFO:;
The result is shown as follows:
+++    0        2012-10-09 00:06:37
O&M    #164
%DSP SSLERRINFO:;%%
RETCODE = 0 Operation Success

Output Description

Field Description

Peer IP address

Indicates the peer IP address of the SSL connection.

TLS/SSL Version

Indicates the TLS or SSL version supported by the NE.TLS(Transport Layer Security). The TLS1.2 and TLS1.3 version are enabled eternally in the system, and therefore they cannot be disabled currently. You are not advised to use SSL3.0, TLS1.0 and TLS1.1 because they have security risks.

Error Code

Indicates the error code for the latest SSL connection check failure.

Error Description

Indicates the error description for the latest SSL connection check failure.

Certificate Verify Result

Indicates the failure code verification of the peer certificate during SSL connection setup(if certificate authentication is used).

Verify Result Description

Indicates the failure description in verification of the peer certificate during SSL connection setup.

Occurrence Time

Indicates the time when an SSL connection check fails.
