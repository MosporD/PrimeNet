Set RRU Security Policy (SET RRUSECPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the RRU/AAU authentication mode configured on the BBU during Secure Sockets Layer (SSL) handshakes.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed, the NE uses the new authentication mode during the next SSL connection setup. This operation does not affect existing connections.

  • Before setting Authentication Mode to PEER(Verify Peer Certificate), ensure that the required certificates have been obtained. Otherwise, setting Authentication Mode to PEER(Verify Peer Certificate) may interrupt the maintenance channel.

Parameters

ID Name Description
RRUAUTHMODE RRU Authentication Mode

Meaning: Indicates the authentication mode of the SSL connection via the BBU eCPRI port. If this parameter is set to NONE(Verify None), the RRU can use anonymous authentication to establish a link with the BBU after the first TLS bidirectional authentication between the BBU and the RRU fails. If this parameter is set to PEER(Verify Peer Certificate), the NE must verify the certificate of the RRU eCPRI port during SSL connection setup. If the certificate verification fails, SSL the SSL connection cannot be set up. If this parameter is set to NONE(Verify None), the NE will not verify the peer certificate, so that unauthorized clients are more likely to access the NE. Please set this parameter to a proper value.

GUI Value Range: NONE(Verify None), PEER(Verify Peer Certificate)

Unit: None

Actual Value Range: NONE, PEER

MML Default Value: PEER(Verify Peer Certificate)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
RRUHWCERTAUTHSW RRU Huawei Certificate Authentication Switch

Meaning: Indicates whether an RRU can use the Huawei certificate for mutual authentication with a BBU. If this switch is turned on, the RRU can use the Huawei certificate to establish connections with the BBU. If this switch is turned off, the RRU cannot use the Huawei certificate to establish connections with the BBU.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(ON)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]When RRUCERTREQSW in the APPCERT MO is set to OFF, RRUHWCERTAUTHSW in the SSL MO must be set to ON.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the authentication mode to NONE, run the following command:
SET RRUSECPOLICY: RRUAUTHMODE=NONE;
