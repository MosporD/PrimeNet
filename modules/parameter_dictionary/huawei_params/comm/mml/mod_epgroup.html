Modify End Point Group (MOD EPGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an end point group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When Packet Filter ACL Rule Auto-Setup-Deletion SW is set to ENABLE, the system automatically creates the ACL rule for packet filtering. If the local IP address of the base station is of loopback type, the ACL rule is automatically added to all physical ports configured with packet filtering; If the local IP address of the base station is of non-loopback type, the ACL rule is automatically added to the physical port configured with packet filtering of the board on which the local IP address is configured.

  • When the value of Packet Filter ACL Rule Auto-Setup-Deletion SW is modified, the system will automatically generate or delete packet filtering rules for links related to the local and peer endpoints. To avoid service interruption during this procedure, pay attention to the following:

    1. To change the configuration method of packet filtering rules from automatic mode to manual mode, first add manually configured packet filtering rules and then change the value of Packet Filter ACL Rule Auto-Setup-Deletion SW from ENABLE(Enable) to DISABLE(Disable).

    2. To change the configuration method of packet filtering rules from manual mode to automatic mode, first change the value of Packet Filter ACL Rule Auto-Setup-Deletion SW from DISABLE(Disable) to ENABLE(Enable) and then delete manually configured packet filtering rules.

    3. To disable the packet filtering function, use batch commands to change the value of Packet Filter ACL Rule Auto-Setup-Deletion SW from ENABLE(Enable) to DISABLE(Disable) and delete the packet filtering to avoid service interruption during the interval between the two operations.

    4. To enable the packet filtering function, use batch commands to change the value of Packet Filter ACL Rule Auto-Setup-Deletion SW from DISABLE(Disable) to ENABLE(Enable) and add the packet filtering to avoid service interruption during the interval between the two operations.

    5. To disable the packet filtering function and then enable it, first perform step 3 and then step 4.

  • [Co-MPT,eNodeB,gNodeB]When IP PM Automatic Setup and Deletion Switch is set to ENABLE(Enable) and the value of IP PM DSCP or user-plane host or peer IP address in the EPGROUP object is modified, the IP PM session that is automatically established based on the user-plane host or peer is first deleted and then reestablished.

  • [Co-MPT,eNodeB,gNodeB]If the IP Protocol Version Preference parameter value is modified, the established control-plane link or user-plane path will not be reestablished. The value of this parameter will be checked only when a control-plane link or user-plane path needs to be reestablished.

  • [Co-MPT,eNodeB,gNodeB]When the control plane or user plane of the service interface between the local and peer base stations is automatically generated and both IPv4 and IPv6 SCTPHOST/USERPLANEHOST objects are configured in the EPGROUP MOs at both ends, the values of IPVERPREFERENCE in the EPGROUP MOs to which the service interface belongs must be the same.

IPPMSWITCH IP PM Automatic Setup and Deletion Switch

Meaning: Indicates whether to enable the IP PM session self-configuration function. If this parameter is set to ENABLE(Enable), the system will automatically generate IP PM sessions for links related to the local and peer end points. If this parameter is set to DISABLE(Disable), the system will not automatically generate IP PM sessions. If the value of this parameter is changed from ENABLE(Enable) to DISABLE(Disable) using the MOD EPGROUP command, the system will delete the automatically generated IP PM sessions for links related to the local and peer end points. This parameter is valid only for the user-plane links over the LTE S1 interface. IP PM is a Huawei proprietary protocol. Ensure that IP PM is supported by and has been enabled on the CN equipment before turning on this switch.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE(Enable), the IP PM sessions that are automatically generated by the system will periodically send FM frames and BR frames, increasing the transmission bandwidth overhead. One IP PM session consumes about 6 kbit/s transmission bandwidth.

Applicable Mode: G, U, L, N

IPVERPREFERENCE IP Protocol Version Preference

Meaning: Indicates the IP protocol version that is preferentially used to automatically establish a control-plane link or user-plane path when the SCTP local IP address or user-plane local IP address in an EPGROUP MO is dual-stack and the IP address of the peer device is also dual-stack. If this parameter is set to IPv4, the IPv4 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. If this parameter is set to IPv6, the IPv6 protocol is used to set up a control-plane link or user-plane path in the EPGROUP MO with the dual-stack peer device. Only one IP protocol can be selected to set up a control-plane link or user-plane path. IPv4 and IPv6 cannot be backed up for each other. This parameter is invalid when the local address or the IP address of the peer device is single-stack. This parameter takes effect only for LTE and NR.

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify an end point group with the parameters as follows: End Point Group ID: 0, Packet Filter ACL Rule Auto-Setup-Deletion SW: ENABLE, run the following command:
MOD EPGROUP: EPGROUPID=0, PACKETFILTERSWITCH=ENABLE;
