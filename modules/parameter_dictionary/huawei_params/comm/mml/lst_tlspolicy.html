List TLS Configuration Policy (LST TLSPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list TLS configuration policies.

Note

None.

Parameters

ID Name Description
POLICYID POLICY ID

Meaning: Indicates the ID of a TLS configuration policy.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]POLICYID in a CA MO must be set to a configured value of POLICYID in an TLSPOLICY MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]POLICYID in a CRLTSK MO must be set to a configured value of POLICYID in an TLSPOLICY MO.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CRLTSK MO, this parameter is valid only when CRLGETMETHOD is set to LDAP, CONNMODE is set to SSL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To list the TLS configuration policies, run the following command:
LST TLSPOLICY:;
The result is shown as follows:

Output Description

Field Description

POLICY ID

Indicates the ID of a TLS configuration policy.

Key Update Switch

Indicates whether to enable the TLS key update function. This function updates the key in current use. For details, see RFC 8446.

Key Update Lifetime(min)

Indicates the TLS key update period.

Diffie-Hellman Group

Indicates the Diffie-Hellman group for TLS key negotiation.

Signature Algorithm

Indicates the TLS signature algorithm.

Cipher Suite

Indicates the TLS cipher suite.
