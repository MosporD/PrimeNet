List IPv6 ACL Configuration (LST ACL6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an IPv6 Access Control List (ACL).

Note

None.

Parameters

ID Name Description
ACLID IPv6 ACL ID

Meaning: Indicates the ID of the IPv6 ACL to which an IPv6 ACL rule belongs. An IPv6 ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An IPv6 ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

GUI Value Range: 3000~3999,7000~7999

Unit: None

Actual Value Range: 3000~3999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The ID of an IPv6 ACL that is manually configured must range from 3000 to 3999.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To list the IPv6 ACL configuration, run the following command: 
LST ACL6:;
The result is shown as follows:

Output Description

Field Description

IPv6 ACL ID

Indicates the ID of the IPv6 ACL to which an IPv6 ACL rule belongs. An IPv6 ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An IPv6 ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

Description

Indicates the brief description of an IPv6 ACL.

Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only users can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.

Auto Config Flag

Indicates whether an object is created by the system. The value MANUAL_CREATED means that the object is manually configured by a user. The value AUTO_CREATED means that the object is created by the system.
