List RVD Subunit (LST RVDSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a remote vendor-defined antenna line device (RVD) subunit.

Note

When the cabinet number of the port to which the RVD subunit is connected is 255, the port is not connected. In this case, the corresponding subrack number and slot number are also set to 255.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RVD.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RVD subunit, which starts from 1.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

1.To query the configuration of an RVD subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
LST RVDSUBUNIT: DEVICENO=0, SUBUNITNO=1;

Output Description

Field Description

Device No.

Indicates the device number of the RVD.

Subunit No.

Indicates the number of the RVD subunit, which starts from 1.

Subunit Name

Indicates the name of the RVD subunit. The name of the RVD subunit is optional, but the name configured for each RVD subunit must be unique.

Connect Port 1 Cabinet No.

Indicates the cabinet number of the RRU or RFU that is connected to antenna port 1.

Connect Port 1 Subrack No.

Indicates the subrack number of the RRU or RFU that is connected to antenna port 1.

Connect Port 1 Slot No.

Indicates the slot number of the RRU or RFU that is connected to antenna port 1.

Connect Port 1 Port No.

Indicates the port number of the RRU or RFU that is connected to antenna port 1.

Connect Port 2 Cabinet No.

Indicates the cabinet number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.

Connect Port 2 Subrack No.

Indicates the subrack number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.

Connect Port 2 Slot No.

Indicates the slot number of the RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.

Connect Port 2 Port No.

Indicates the port number of RRU or RFU that is connected to antenna port 2. This parameter is valid when a dual-polarized antenna is used.

Vertical BeamWidth(0.1degree)

Indicates the vertical beamwidth of RVD subunit.

Software-defined Antenna Mode

Indicates the working mode of the programmable antenna.
