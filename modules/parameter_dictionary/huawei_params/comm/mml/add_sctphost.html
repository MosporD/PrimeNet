Add SCTP Host (ADD SCTPHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an SCTP host.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the IP addresses of the SCTP host and SCTP peer are set to valid IP addresses and the two local IP addresses are configured on the same board, the base station does not make cross-link attempts. That is, the base station does not support the SCTP link between the first local IP address and the second peer IP address or the link between the second local IP address and the first peer IP address. The base station makes cross-link attempts only when the two local IP addresses are valid and are configured on different boards. This requires that the peer device should support this multi-homing mode.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When security automatic establishment is enabled on an SCTP host, the IPSec Auto Configure Switch is enabled for the SCTP host and a security host is referenced. Therefore, before enabling this feature, ensure that the security host to be referenced has been added by using the ADD SECURITYHOST command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the SIGIP2V4 of an SCTP host is not 0.0.0.0, ensure that the SIGIP1V4 and SIGIP2V4 of the SCTP host have been configured by using the ADD DEVIP or ADD IPADDR4 command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The local IP addresses configured in this MO must be mutually reachable with the IP addresses of base station controllers or CN equipment. If some IP addresses are unreachable, services setup will fail on the corresponding equipment.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met during setup of an IPv4 SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the SCTP link:

    - IPSec Auto Configure Switch for First Local IP, IPSec Auto Configure Switch for Second Local IP, IPSec Auto Configure Switch for First Peer IP, and IPSec Auto Configure Switch for Second Peer IP are set to ENABLE for the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an SCTP link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the SCTP link:

    - IPSec Auto Configure Switch for First Local IP, IPSec Auto Configure Switch for Second Local IP, IPSec Auto Configure Switch for First Peer IP, and IPSec Auto Configure Switch for Second Peer IP are set to ENABLE for the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch for First Local IP, IPSec Auto Configure Switch for Second Local IP, IPSec Auto Configure Switch for First Peer IP, and IPSec Auto Configure Switch for Second Peer IP are set to DISABLE for the SCTPHOST and SCTPPEER objects in the same endpoint group, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the signaling links are set up automatically, the base station automatically establishes an SCTP link if an SCTP link which is same as that of the following information in an endpoint group is not configured:

    The first local IP address of the SCTP host

    The second local IP address of the SCTP host

    The local SCTP port number of the SCTP host

    The first peer IP address of the SCTP peer

    The second peer IP address of the SCTP peer

    The peer SCTP port number of the SCTP peer.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When signaling links are automatically set up, the base station does not automatically establish another SCTP peer and SCTP link if the base station has been configured with an SCTPLNK MO and the following parameters are set to the same values as those of the configured SCTP link:

    First Local IP Address, Second Local IP Address, and Local SCTP Port No. in the SCTP host in the same endpoint group as the SCTP peer to be created

    First Peer IP Address, Second Peer IP Address, and Peer SCTP Port No. in the SCTP peer to be created.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Ensure that the SCTPTEMPLATEID of the SCTP host has been configured by using the ADD SCTPTEMPLATE command.

  • [Co-MPT,NodeB,eNodeB,gNodeB]System specifications: If the LMPT/UMPT/UMDU is the main control board, a maximum of 24 SCTP hosts can be configured.

  • [NodeB,eGBTS,eNodeB,gNodeB]During self-setup of the control plane (for example, for the X2/eX2/uX2 interface), the port numbers of the SCTP hosts for adjacent base stations must be the same. In addition, the port number of the SCTP peer must be the same as the port number of the SCTP host for these base stations. Otherwise, the SCTP link negotiation fails.

  • [Co-MPT,NodeB,eNodeB]When the port type is MPGRP or PPP, it is not supported to run the ADD PPPLNK or ADD MPGRP command to configure the first local IP address or the second local IP address of an SCTP host.

  • [Co-MPT,eNodeB,gNodeB]If the SIGIP2V6 of an SCTP host is not 0:0:0:0:0:0:0:0, ensure that the SIGIP1V6 and SIGIP2V6 of the SCTP host have been configured by using the ADD IPADDR6 command.

  • [Co-MPT,eNodeB,gNodeB]If the local and peer IPv6 addresses of the SCTP host and SCTP peer are set to valid IPv6 addresses, the BS does not make cross-link attempts. That is, the BS does not support the SCTP link between the first local IPv6 address and the second peer IPv6 address or the link between the second local IPv6 address and the first peer IPv6 address.

  • [Co-MPT,eNodeB,gNodeB]When the signaling links are set up automatically, the base station automatically establishes an SCTP link if an SCTP link which is same as that of the following information in an endpoint group is not configured:

    The first local IPv6 address of the SCTP host

    The second local IPv6 address of the SCTP host

    The local SCTP port number of the SCTP host

    The first peer IPv6 address of the SCTP peer

    The second peer IPv6 address of the SCTP peer

    The peer SCTP port number of the SCTP peer.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met during setup of an IPv6 SCTP link, the system will automatically configure the SCTPLNK, TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects and set up an IPsec tunnel for the SCTP link:

    - IPSec Auto Configure Switch for First Local IP, IPSec Auto Configure Switch for Second Local IP, IPSec Auto Configure Switch for First Peer IP, and IPSec Auto Configure Switch for Second Peer IP are set to ENABLE for the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • [Co-MPT,eNodeB]When the local ip for inside sctplnk is configured on the loopback interface, the corresponding port failure will cause the SCTP link fault.

SIGIP1SECSWITCH IPSec Auto Configure Switch for First Local IP

Meaning: Indicates whether to use the first local IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the first local IP address of the SCTP host. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPHOST command, the system automatically deletes the IPsec tunnel that has been automatically set up.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: If the networking mode does not support IPSec or IPSec tunnels are to be set up by manually configuring IPSec objects, this parameter must be set to DISABLE.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]When the SIMPLEMODESWITCH parameter in the SCTPHOST MO is not set to SIMPLE_MODE_OFF, both the SIGIP1SECSWITCH and SIGIP2SECSWITCH parameters in the SCTPHOST MO must be set to DISABLE.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv4 and SIGIP1SECSWITCH or SIGIP2SECSWITCH is set to ENABLE, VRFIDX must be set to 0.
  • [Co-MPT, eNodeB, gNodeB]In an SCTPHOST MO, if IPVERSION is set to IPv6 and SIGIP2V6 is valid, SIGIP1SECSWITCH and SIGIP2SECSWITCH in the SCTPHOST MO must be set to DISABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: Control-plane SCTP links or IPv6 SCTP links are unavailable, cells are abnormal, and UEs cannot access the network if this parameter is set to DISABLE and no IPSec tunnel has been set up between the SCTP host and the SCTP peer for the SCTP links or IPv6 SCTP links in an IPSec-protected network.

Applicable Mode: U, L, N

DTLSCONNPOLICY DTLS Connection Policy

Meaning: Indicates the DTLS connection policy. DTLS_ONLY indicates that the local end uses only DTLS connections. If the peer end does not support or is not configured with DTLS, the negotiation fails. DTLS_PRIORITY indicates that the local end attempts to establish a DTLS connection for the first time. If the peer end does not support or is not configured with DTLS, the local end uses the SCTP connection. If this parameter is set to DTLS_PRIORITY, the security is reduced. Therefore, you are advised not to set this parameter to DTLS_PRIORITY. This parameter applies only to NR.

GUI Value Range: DTLS_ONLY(DTLS Forcible Connection), DTLS_PRIORITY(DTLS Preferential Connection)

Unit: None

Actual Value Range: DTLS_ONLY, DTLS_PRIORITY

MML Default Value: DTLS_ONLY(DTLS Forcible Connection)

Recommended Value: DTLS_ONLY(DTLS Forcible Connection)

Example

To add an SCTP host with the parameters as follows: SCTP Host ID: 0, IP Version: IPv4, First Local IP Address: 192.168.1.1, IPSec Auto Configure Switch for First Local IP: DISABLE, Second Local IP Address: 0.0.0.0, IPSec Auto Configure Switch for Second Local IP: DISABLE, Local SCTP Port No.: 1024, Simple Mode Switch: SIMPLE_MODE_OFF, SCTP Parameters Template ID: 0, DTLS Policy ID: NULL, run the following command:
ADD SCTPHOST: SCTPHOSTID=0, IPVERSION=IPv4, SIGIP1V4="192.168.1.1", SIGIP1SECSWITCH=DISABLE, SIGIP2V4="0.0.0.0", SIGIP2SECSWITCH=DISABLE, PN=1024, SIMPLEMODESWITCH=SIMPLE_MODE_OFF, SCTPTEMPLATEID=0, DTLSPOLICYID=NULL;
