Set Backup Mode of Reference Clock Source (SET CLKSRCBKPMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the backup mode of the GPS or TOD clock source whose signals are introduced by a main control board. The backup mode is controlled by the Clock Source Backup Mode parameter. When this parameter is set to BRDBKMODE, the primary main control board introduces clock signals from the clock source regardless of whether the GPS or TOD clock link is configured on the active or standby board. When this parameter is set to CLKSRCBRDCFG, the active and standby boards can be configured with both GPS clock links or both TOD clock links, and the standby board introduces clock signals from the clock source if it is configured with a GPS or TOD clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When the Clock Source Backup Mode parameter is set to BRDBKMODE, only one GPS or TOD clock link to a main control board can be configured.

  • Switchover of the clock source backup mode results in the unavailable system clock in a specific period of time.

  • The clock quality will be affected if the reference clock source is changed. Do not use this command frequently.

Parameters

ID Name Description
BKPMODE Clock Source Backup Mode

Meaning: Indicates the backup mode of the reference clock sources. This parameter applies only to backup of GPS clock sources or TOD clock sources whose signals are introduced by a main control board. When this parameter is set to BRDBKMODE, only the primary main control board can introduce clock signals from the clock source. When this parameter is set to CLKSRCBRDCFG, the board in the specified slot introduces clock signals from the clock source.

GUI Value Range: BRDBKMODE(BRDBKMODE), CLKSRCBRDCFG(CLKSRCBRDCFG)

Unit: None

Actual Value Range: BRDBKMODE, CLKSRCBRDCFG

MML Default Value: BRDBKMODE(BRDBKMODE)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the backup mode of the reference clock source with Backup Mode set to CLKSRCBRDCFG, run the following command:
SET CLKSRCBKPMODE: BKPMODE=CLKSRCBRDCFG;
