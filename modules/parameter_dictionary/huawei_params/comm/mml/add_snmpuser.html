Add Snmp User (ADD SNMPUSER)

Network Element: BTS3900, BTS5900

Function

Use this command to add an SNMP user.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

Parameters

ID Name Description
USERNAME User Name

Meaning: Indicates the name of an SNMP user.

GUI Value Range: 1~32 characters

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Meaning: Indicates the authentication mode of an SNMP user, MD5(HMAC-MD5), SHA(HMAC-SHA). NONE, MD5 have security risks and are not recommended.

Disuse statement: In later versions, the value MD5(MD5) will be removed from the value range of this parameter. In the current version, this value can still be configured and take effect.Therefore, you are not advised to use the value MD5(MD5).

KEY Authentication Key

Meaning: Indicates the authentication password of an SNMP user. An authentication password is a 16-bit to 64-bit string that must contain the following types of characters: uppercase letters, lowercase letters, digits, and supported special characters (. - _ ~ @ $ ^ & ( ) ` # [ ] { }). No Chinese character is allowed in the name. The value of Character String Type cannot contain the following characters: 1. Such special characters as < > ! ? \ / : ; , = + % * " ' | or 2. Two or more percent signs (%), space, +++ (start character of an MML message), or --- (end character of an MML message).

Example

To add SNMP user parameters as follows: User Name: "User0", Authentication Protocol: SHA, Authentication Key: "*****", Private Protocol: AES, Private Key: "*****", run the following command: 
ADD SNMPUSER: USERNAME="User0", AUTHPROTOCOL=SHA, KEY="*****", PRIVPROTOCOL=AES, PKEY="*****";
