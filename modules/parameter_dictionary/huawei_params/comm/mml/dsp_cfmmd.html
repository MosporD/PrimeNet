Display CFM MD Status (DSP CFMMD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of one or all CFM MDs.

Note

If neither CFM MD name nor CFM MD level is specified, the information about all CFM MDs in the BS is displayed.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the CFM MD.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MD.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MDNAME in a CFMMD MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
LEVEL MD Level

Meaning: Indicates the level of the CFM MD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

DSP CFMMD:;

Output Description

Field Description

MD Name

Indicates the name of the CFM MD.

MD Level

Indicates the level of the CFM MD.

MA Number

Indicates the number of MAs in a CFM MD.

MA List

Indicates the list of all MAs in a CFM MD.
