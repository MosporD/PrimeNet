List RRU Chain/Ring (LST RRUCHAIN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configurations of RRU chains/rings.

Note

Parameters

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Output Description

Field Description

Chain No.

Indicates the ID of the RRU chain/ring. It uniquely identifies a chain within a base station.

Topo Type

Indicates the type of the topology. In a ring topology, service data is transmitted on the fiber optic cable that carries the HDLC link. In a load sharing topology, service data is transmitted on two fiber optic cables simultaneously, which enhances the transmission capability. The physical connection in the ring topology is similar to that in the load sharing topology. The trunk chain enables multiple CPRI fiber optic cables to simultaneously transmit service data.

Backup Mode

Indicates the backup mode of the RRU chain/ring. There are two modes: cold backup and hot backup. Cold backup indicates that when the link on one end of the chain/ring fails, services are interrupted for a short period of time, and then re-established on the other end of the chain/ring. Hot backup indicates that when the link on one end of the chain/ring fails, services are taken over by the other end of the chain/ring immediately. There is only one RRU on the chain/ring in hot backup mode. In the RRUCHAIN MO, if TT is set to RING and BM is set to HOT, the head CPRI port and the tail CPRI port of the RRU ring must be on different baseband processing boards.

Head Cabinet No.

Indicates the cabinet number of the board where the head CPRI port is located.

Head Subrack No.

Indicates the subrack number of the board where the head CPRI port is located.

Head Slot No.

Indicates the slot number of the board where the head CPRI port is located.

Head Port No.

Indicates the number of the head CPRI port.

Head SubPort No.

Indicates the number of the head CPRI sub-port.

Tail Cabinet No.

Indicates the cabinet number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Subrack No.

Indicates the subrack number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Slot No.

Indicates the slot number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Port No.

Indicates the number of the tail CPRI port. If there is no tail, the value of this parameter is NULL.

Tail SubPort No.

Indicates the number of the tail CPRI sub-port. If there is no tail or the tail has no sub-ports, the value of this parameter is NULL.

BreakPoint Position1

Indicates breakpoint position 1 on the chain/ring. When this parameter is set to 255, the breakpoint is disabled.

BreakPoint Position2

Indicates breakpoint position 2 on the chain/ring. When this parameter is set to 255, the breakpoint is disabled.

Access Type

Indicates the access type of the board on an RRU chain/ring. When Access Type is set to LOCALPORT, the BBP connects to the board on an RRU chain/ring through CPRI ports. When Access Type is set to PEERPORT, the local BBP connects to the peer BBP through a IDX2 ports and the peer BBP connects to a board on an RRU chain/ring.

CPRI Line Rate(Gbit/s)

Indicates the user-defined rate. The value AUTO indicates that auto-negotiation is used. The value MANUAL indicates that the rate is set manually and the rate must be set to a fixed value for each board on the RRU chain/ring. Other values indicate the corresponding fixed rates. If the CPRI link fails with this parameter set to a fixed rate, the RRU cannot work with this CPRI rate.

Local Cabinet No.

Indicates the cabinet number of the converged party in CPRI MUX/eCPRI MUX. The Local Cabinet No. parameter and the Local Subrack No. parameter must be both set to 255 or neither set to 255. If they are both set to 255, the converging party and converged party are deployed in the same subrack. If they are not set to 255, the deployment depends on the configurations.

Local Subrack No.

Indicates the subrack number of the converged party in CPRI MUX/eCPRI MUX. The Local Cabinet No. parameter and the Local Subrack No. parameter must be both set to 255 or neither set to 255. If they are both set to 255, the converging party and converged party are deployed in the same subrack. If they are not set to 255, the deployment depends on the configurations.

Local Slot No.

Indicates the slot number of the converged party in CPRI MUX/eCPRI MUX. If this parameter is set to 255, the slot number of the converged party is not specified. When the converging party is in a BBU3900, this parameter can be left unspecified. When the converging party is in a BBU3910, BBU5900 or BBU5900A, this parameter must be specified.

Protocol Type

Indicates the communication protocol used by the chain/ring. The value DEFAULT indicates that the chain/ring uses the protocol specified in the Equipment MO. The protocol specified by this parameter prevails when it differs from that specified in the Equipment MO.

Severely Errored Second Threshold

Indicates the threshold for a SES in CPRI link performance measurement results. A second is an SES if the bit error rate on a CPRI link is greater than the value of this parameter within this second.

Connect Port Num

Indicates the number of ports used for a trunk chain.

Port 1 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 1 of the trunk chain.

Port 1 Subrack No.

Indicates the subrack number of the board a port of which works as port 1 of the trunk chain.

Port 1 Slot No.

Indicates the slot number of the board a port of which works as port 1 of the trunk chain.

Port 1 Port No.

Indicates the port number of the board a port of which works as port 1 of the trunk chain.

Port 1 SubPort No.

Indicates the number of the sub-port through which port 1 connects to the trunk chain.

Port 1 CPRI Line Rate(Gbit/s)

Indicates the line rate of port 1 of the trunk chain. The value AUTO indicates that the auto-negotiation mode is used. The value MANUAL indicates that the rate is set manually and the rate must be set to a fixed value for each board on the RRU chain/ring. Other values indicate the corresponding fixed rates.

Port 1 Severely Errored Second Threshold

Indicates the threshold for a severely errored second (SES) in CPRI link performance measurement results. A second is an SES if the bit error rate on a CPRI link is greater than the value of this parameter within this second.

Port 2 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Subrack No.

Indicates the subrack number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Slot No.

Indicates the slot number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Port No.

Indicates the port number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 SubPort No.

Indicates the number of the sub-port through which port 2 connects to the trunk chain.

Port 2 CPRI Line Rate(Gbit/s)

Indicates the line rate of port 2 of the trunk chain. The value AUTO indicates that the auto-negotiation mode is used. Other values indicate the corresponding fixed rates. The value of this parameter is NULL if the current port is not used.

Port 2 Severely Errored Second Threshold

Indicates the threshold for a SES in CPRI link performance measurement results. A second is an SES if the bit error rate on a CPRI link is greater than the value of this parameter within this second. The value of this parameter is NULL if the current port is not used.

Port 3 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Subrack No.

Indicates the subrack number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Slot No.

Indicates the slot number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Port No.

Indicates the port number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 SubPort No.

Indicates the number of the sub-port through which port 3 connects to the trunk chain.

Port 3 CPRI Line Rate(Gbit/s)

Indicates the line rate of port 3 of the trunk chain. The value AUTO indicates that the auto-negotiation mode is used. Other values indicate the corresponding fixed rates. The value of this parameter is NULL if the current port is not used.

Port 3 Severely Errored Second Threshold

Indicates the threshold for a severely errored second (SES) in CPRI link performance measurement results.A second is an SES if the bit error rate on a CPRI link is greater than the value of this parameter within this second. The value of this parameter is NULL if the current port is not used.

Port 4 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Subrack No.

Indicates the subrack number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Slot No.

Indicates the slot number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Port No.

Indicates the port number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 SubPort No.

Indicates the number of the sub-port through which port 4 connects to the trunk chain.

Port 4 CPRI Line Rate(Gbit/s)

Indicates the line rate of port 4 of the trunk chain. The value AUTO indicates that the auto-negotiation mode is used. Other values indicate the corresponding fixed rates. The value of this parameter is NULL if the current port is not used.

Port 4 Severely Errored Second Threshold

Indicates the threshold for a SES in CPRI link performance measurement results. A second is an SES if the bit error rate on a CPRI link is greater than the value of this parameter within this second. The value of this parameter is NULL if the current port is not used.

User-Defined Rate Negotiation Switch

Indicates the user-defined rate negotiation switch. If this switch is turned on, users can specify a bit rate set and a rate change period for automatic rate negotiation.

Bit Rate Set(Gbit/s)

Indicates the bit rate set for rate negotiation. This parameter takes effect only when the user-defined rate negotiation switch is turned on. If this bit rate set does not overlap with the rate set supported by the port, the rate set supported by the port is used for rate negotiation by default.

Rate Change Period(s)

Indicates the duration of a port working in each negotiated rate. This parameter takes effect only when the user-defined rate negotiation switch is turned on.

Reserved Bandwidth

Indicates the bandwidth reserved for other applications.
