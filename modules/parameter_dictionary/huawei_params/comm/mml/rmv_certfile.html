Remove Certificate File (RMV CERTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a certificate file from the BS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • You can use this command to remove a certificate file from a board that is not configured with a certificate or remove a certificate file that is not configured on the board for certificate deployment.

  • This command can be used to remove the certificate file that has been downloaded running the DLD CERTFILE command.

  • During automatic establishment of a remote maintenance channel, you cannot run this command.

  • You cannot run this command to remove any certificate file configured on a certificate-configured board. To remove the certificate file, you can run the following commands: RMV CERTMK, RMV TRUSTCERT, RMV CROSSCERT, and RMV CRL.

  • If Slot No. is set to the physical slot number in active/standby mode, the certificate file on board in the specified physical slot is removed.

  • This command can be used to remove all operator certificates, including the device certificate, trust certificate, and CRL, from an RRU with an eCPRI port. After this command is executed, the corresponding RRU will reset.

  • When the IKE check switch is set to ON in the basic digital certificate configuration, you cannot delete the digital certificate whitelist file that is in use.

CERTFILETYPE Certificate File Type

Meaning: Indicates the certificate file type. If this parameter is set to UNUSED, you can query or delete the certificate files in the download area. If this parameter is set to DEVCERT, you can query or delete the existing certificate files specified in the CERTMK MO. The query results show that the certificate with Application Type in the APPCERT MO set to IKE and the certificate specified by the Certificate File Name parameter in the IKEPEER MO have been loaded. If this parameter is set to TRUSTCERT, CROSSCERT, or CRL, you can query or delete the existing certificate files specified in the TRUSTCERT, CROSSCERT, and CRL MOs. When a certificate has been configured using the ADD TRUSTCERT, ADD CRL, or ADD CROSSCERT command, the query results show that the certificate has been loaded. If this parameter is set to CERTWHITELST, you can query or delete the existing digital certificate whitelist file specified in the running area.

Example

1. To remove a certificate file with the parameters as follows: Subrack No.: 0, Slot No.: 0, Certificate File Type: Unused Certificate File, Certificate File Name: "btscert.cer", run the following command:
RMV CERTFILE: SRN=0, SN=0, CERTFILETYPE=UNUSED, CERTFILENAME="btscert.cer";

2. To remove a device certificate with the parameters as follows:Subrack No.: 0, Slot No.: 0, Certificate File Type: Device Certificate, Certificate File Name: "0801.cer", run the following command:
RMV CERTFILE: SRN=0, SN=0, CERTFILETYPE=DEVCERT, CERTFILENAME="0801.cer";
