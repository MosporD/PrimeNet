Remove Sub-interface (RMV SUBIF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a sub-interface.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the sub-interface is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port ID parameter and Port Type parameter in the INTERFACE MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To remove a sub-interface with the parameters as follows: Slot No.: 7, Subboard Type: BASE_BOARD, Sub-interface No.: 1, run the following command:
RMV SUBIF: SN=7, SBT=BASE_BOARD, ID=1;
