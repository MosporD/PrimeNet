Display Device Configuration Conflict Information (DSP DEVCONFLICTINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information of devices encountering configuration conflicts.

Note

None.

Parameters

None.

Example

To query the information of devices encountering configuration conflicts, run the following command:
DSP DEVCONFLICTINFO:;
The result is as follows:
+++    0        2017-6-24 15:56:56
O&M    #6890
%%DSP DEVCONFLICTINFO:;%%
RETCODE = 0  Operation succeeded.

Display Device Configuration Conflict Information
-------------------------------------------------
DEVTYPE   Equipment Serial Number  Standard  Cabinet No.  Subrack No.  Slot No.  Manager Cabinet No.  Manager Subrack No.

PMU       210305394710CC000982     UMTS      0            7            0         0                    60 
PMU       210305394710CC000982     LTE       1            7            0         0                    61            
(Number of results = 1)


---    END

Output Description

Field Description

DEVTYPE

Indicates the type of the device.

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the number of the subrack where the board is located.

Slot No.

Indicates the number of the slot where the board is located.

Equipment Serial Number

Indicates the equipment serial number (ESN) of the device.

Manager Cabinet No.

Indicates the cabinet number of the manager.

Manager Subrack No.

Indicates the subrack number of the manager.

Standard

Indicates the working standard of the NE.
