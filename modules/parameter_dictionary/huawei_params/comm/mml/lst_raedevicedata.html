List RAE Device Data (LST RAEDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of Remote eAntenna Extension (RAE) device data.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RAE.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RAE subunit, which starts from 1.

GUI Value Range: 1~6

Unit: None

Actual Value Range: 1~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the configuration in the RAE device data with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
LST RAEDEVICEDATA: DEVICENO=0, SUBUNITNO=1;

Output Description

Field Description

Device No.

Indicates the device number of the RAE.

Subunit No.

Indicates the number of the RAE subunit, which starts from 1.

Antenna Model Number

Indicates the model of the RAE.

Serial No.

Indicates the serial number of the RAE.

Band1

Indicates band 1 supported by the antenna. NULL indicates that the band is not configured or the band fails to be obtained.

Beamwidth1(degree)

Indicates the beamwidth of band 1. This parameter is valid only if band 1 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern. NULL indicates that the beamwidth is not configured or the beamwidth fails to be obtained.

Gain1(0.1dBi)

Indicates the gain of band 1. This parameter is valid only if band 1 is in use. NULL indicates that the gain is not configured or the gain fails to be obtained.

Band2

Indicates band 2 supported by the antenna. NULL indicates that the band is not configured or the band fails to be obtained.

Beamwidth2(degree)

Indicates the beamwidth of band 2. This parameter is valid only if band 2 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern. NULL indicates that the beamwidth is not configured or the beamwidth fails to be obtained.

Gain2(0.1dBi)

Indicates the gain of band 2. This parameter is valid only if band 2 is in use. NULL indicates that the gain is not configured or the gain fails to be obtained.

Band3

Indicates band 3 supported by the antenna. NULL indicates that the band is not configured or the band fails to be obtained.

Beamwidth3(degree)

Indicates the beamwidth of band 3. This parameter is valid only if band 3 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern. NULL indicates that the beamwidth is not configured or the beamwidth fails to be obtained.

Gain3(0.1dBi)

Indicates the gain of band 3. This parameter is valid only if band 3 is in use. NULL indicates that the gain is not configured or the gain fails to be obtained.

Band4

Indicates band 4 supported by the antenna. NULL indicates that the band is not configured or the band fails to be obtained.

Beamwidth4(degree)

Indicates the beamwidth of band 4. This parameter is valid only if band 4 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern. NULL indicates that the beamwidth is not configured or the beamwidth fails to be obtained.

Gain4(0.1dBi)

Indicates the gain of band 4. This parameter is valid only if band 4 is in use. NULL indicates that the gain is not configured or the gain fails to be obtained.

Installation Date

Indicates the date when the antenna is installed.

Installer's ID

Indicates the ID of the installation technician who installed the antenna.

Base Station ID

Indicates the base station ID.

AISG Sector ID

Indicates the AISG sector ID.

Antenna Bearing(0.1degree)

Indicates the antenna azimuth. If this parameter is set to 4294967295, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.

Installed Mechanical Tilt(0.1degree)

Indicates the mechanical tilt of the installation. If this parameter is set to 2147483647, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.

Altitude[0.1m(0.1ft)]

Indicates the altitude of the location where the antenna equipment is located. The RAE complies with the AISG2.1 specification. The unit of this parameter in the specification is 0.1 m. If the imperial system is used, the base station converts the input imperial value into a metric value using the 0.3048 x input imperial value formula, rounds off the calculated value, and then applies the result to the RAE. When you query the altitude of the antenna, the base station coverts the metric value stored on the RAE into an imperial value using the 3.2808 x metric value stored on the RAE formula, rounds off the calculated value, and then displays the result. If this parameter is set to 4000000 in the metric system or 13123200 in the imperial system, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.

Latitude With Degree Format(1e-6 degree)

Indicates the latitude of the antenna equipment. Values less than 0 indicate south latitude and values greater than 0 indicate north latitude. If this parameter is set to 2147483647, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.

Longitude With Degree Format(1e-6 degree)

Indicates the longitude of the antenna equipment. Values less than 0 indicate west longitude and values greater than 0 indicate east longitude. If this parameter is set to 2147483647, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.
