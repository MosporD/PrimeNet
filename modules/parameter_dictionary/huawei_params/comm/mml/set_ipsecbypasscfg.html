Set IPSec Bypass Switch (SET IPSECBYPASSCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the IPSec bypass function. If the IPSec bypass switch is turned on, the base station can switch between the IPSec network and the non-security network.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]LTE TDD does not support IPSec bypass function.

  • [Co-MPT,eNodeB,gNodeB]This function is not supported in IPv6 IPsec networking.

  • [Co-MPT]The GTMUb/GTMUc does not support this command.

  • [NodeB]The WMPT does not support this command.

Parameters

ID Name Description
BYPASSSWITCH IPSec Bypass Switch

Meaning: Indicates whether to enable the switchover of IPSec Bypass. If this parameter is set to DISABLE, the base station cannot switch between an IPSec network and a non-IPSec network.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PWD IPSec Bypass Code

Meaning: Indicates the password used for switching the base station between an IPSec network and a non-IPSec network.

GUI Value Range: 1~19 characters

Unit: None

Actual Value Range: 1~19 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set IPSec Bypass status with the parameters as follows: IPSec Bypass Switch: ENABLE, IPSec Bypass Code: "******", run the following command:
SET IPSECBYPASSCFG: BYPASSSWITCH=ENABLE, PWD="******";
