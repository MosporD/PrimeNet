Add CP Bearer (ADD CPBEARER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add Control Port Bearer.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum of 512 CP bearers can take effect on a UTRPc/UCCU/LMPT/GTMUb/GTMUc/UTRP (subboard type: UEOC/UQEC/UIEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 36 CP bearers can take effect on a WMPT. A maximum of 16 CP bearers can take effect on a UTRP (subboard type: UAEC). A maximum of 400 CP bearers can take effect on a UMPTa/UMPTb/UMDU. A maximum of 1024 CP bearers can take effect on a UMPTe/UMPTg/UMPTga.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the LMPT is the main control board, a maximum of 112 CP bearers can be configured. If the WMPT is the main control board, a maximum of 84 CP bearers can be configured. If the UMPTa/UMPTb is the main control board, a maximum of 1072 CP bearers can be configured, but only a maximum of 432 CP bearers can be used. If the UMPTe/UMPTg/UMPTga is the main control board, a maximum of 1072 CP bearers can be configured. If the UMDU is the main control board, a maximum of 400 CP bearers can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 4 CP bearers can be configured.

  • [Co-MPT]In ATM/IP dual-stack scenarios, active and standby CP bearers must be carried on an SAAL link and an SCTP link, respectively. Otherwise, the CP bearers fail to be configured. You can run the SET CPSWITCH command to enable active/standby switchover in ATM/IP dual-stack scenarios.

  • [Co-MPT]Before running this command, ensure that the bearer SAAL, SCTP link is configured.

  • [Co-MPT]Only one Control Port (CP) bearer can be carried on each SAAL, SCTP link.

  • [NodeB]In ATM/IP dual-stack scenarios, active and standby CP bearers must be carried on an SAAL link and an SCTP link of IPv4, respectively. Otherwise, the CP bearers fail to be configured. You can run the SET CPSWITCH command to enable active/standby switchover in ATM/IP dual-stack scenarios.

  • [NodeB]Before running this command, ensure that the bearer SAAL or SCTP link is configured.

  • [NodeB]Only one CP bearer can be carried on each SAAL or SCTP link.

  • [eGBTS]Only one CP bearer can be carried on each SCTP link.

  • [eGBTS]Before running this command, ensure that the bearer SCTP link is configured.

  • [eNodeB]Before running this command, ensure that the bearer SCTP link is configured.

  • [eNodeB]Only one CP bearer can be carried on each SCTP link.

Parameters

ID Name Description
CPBEARID CP Bear No.

Meaning: Indicates the number of a Control Port (CP) bearer. The value of CPBEARID in the CPBEARER MOs configured by users ranges from 0 to 65535. The value of CPBEARID in the CPBEARER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of CP Bear No. in a manually configured CPBEARER MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
BEARTYPE Bear Type

Meaning: Indicates the type of CP bearer. The LTE and NR do not support SAAL.

GUI Value Range: SAAL(SAALLNK), SCTP(SCTPLNK)

Unit: None

Actual Value Range: SAAL, SCTP

MML Default Value: SCTP(SCTPLNK)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
LINKNO Link No.

Meaning: Indicates the number of a link carried on the CP bearer.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FLAG Flag

Meaning: Indicates whether the transport channel carried on the CP bearer is a master or slave channel.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add CpBearer with the parameters as follows: CP Bear No.: 0, Bear Type: SCTP, Link No.: 0, Flag: MASTER, run the following command:
ADD CPBEARER: CPBEARID=0, BEARTYPE=SCTP, LINKNO=0, FLAG=MASTER;
