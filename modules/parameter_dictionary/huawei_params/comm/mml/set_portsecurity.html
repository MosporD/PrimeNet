Set Port Security Switch (SET PORTSECURITY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the port security switch of a port.

Note

  • Service processing cannot be prohibited on the port configured with upper-layer objects.

  • When an Ethernet port, E1/T1 port, or Ethernet CI port is deleted, the system automatically deletes the port security objects depending on the deleted physical port. If no Ethernet port object, E1/T1 port or Ethernet CI port object exists in the database, you can run the ADD ETHPORT/SET ETHPORT, ADD E1T1/SET E1T1, or ADD ETHCIPORT command to add a physical port, and then run RMV ETHPORT, RMV E1T1, or RMV ETHCIPORT command to remove the physical port. In this case, the system automatically deletes the port security objects depending on the physical port.

SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where port security is enabled.

GUI Value Range: E1_COVERBOARD(E1 Cover Board), ETH_COVERBOARD(Ethernet Cover Board), BASE_BOARD(Base Board)

Unit: None

Actual Value Range: E1_COVERBOARD, ETH_COVERBOARD, BASE_BOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In a PORTSECURITY MO, this parameter can be set to E1_COVERBOARD or ETH_COVERBOARD if SN is set to a value within the range of 0 to 5.
  • In a PORTSECURITY MO, this parameter can be set to BASE_BOARD or ETH_COVERBOARD if SN is set to 6 or 7.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PT Port Type

Meaning: Indicates the type of port on which port security is enabled.

GUI Value Range: ETH(Ethernet Port), E1T1(E1/T1 Port), ETHCI(Ethernet CI Port)

Unit: None

Actual Value Range: ETH, E1T1, ETHCI

MML Default Value: None

Recommended Value: ETH(Ethernet Port)

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In a PORTSECURITY MO, this parameter can be set to ETH, E1T1, or ETHCI if SBT is set to BASE_BOARD.
  • In a PORTSECURITY MO, this parameter must be set to E1T1 if SBT is set to E1_COVERBOARD.
  • In a PORTSECURITY MO, this parameter must be set to ETH if SBT is set to ETH_COVERBOARD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PN Port No.

Meaning: Indicates the number of the port on which port security is configured.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the PORTSECURITY MO, this parameter can be set to 0 to 3 if SBT is set to BASE_BOARD and PT is set to ETH.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 3 if SBT is set to BASE_BOARD and PT is set to E1T1.
  • In the PORTSECURITY MO, this parameter can be set to 0 if SBT is set to BASE_BOARD and PT is set to ETHCI.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 7 if SBT is set to E1_COVERBOARD and PT is set to E1T1.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 5 if SBT is set to ETH_COVERBOARD and PT is set to ETH.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SWITCH Enable Flag

Meaning: Indicates whether to enable services on a specified port to implement port security. If this parameter is set to DISABLE, running services on the port is prohibited, thereby guaranteeing the security of the port.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: ENABLE(Enable)

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set the port security switch of a port with the parameters as follows: Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, Enable Flag: DISABLE, run the following command:
SET PORTSECURITY: SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, SWITCH=DISABLE;
