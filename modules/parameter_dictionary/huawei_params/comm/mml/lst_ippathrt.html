List IP Path Route Configuration (LST IPPATHRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configuration of an IP path routes.

Note

[Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L

Example

To list the configuration of an IP path route, run the following command:
LST IPPATHRT:;
The result is shown as follows:
+++    0        2010-09-20 06:42:45
O&M    #1196
%%LST IPPATHRT:;%%
RETCODE = 0  Operation succeeded.

List IP Path Route Configuration
--------------------------------
              VRF Index  =  0
              Source IP  =  10.52.21.89
         Destination IP  =  10.52.26.1
Transport Resource Type  =  High Quality
            Next Hop IP  =  10.52.21.88
(Number of results = 1)


---    END

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Source IP

Indicates the source IP address of an IP path route. The source IP address must be the same as the configured device IP address.

Destination IP

Indicates the destination IP address of an IP path route.

Transport Resource Type

Indicates the type of transport resource carried on an IP path route. The value HQ indicates high-quality transport resources, and the value LQ indicates low-quality transport resources.

Next Hop IP

Indicates the next-hop IP address of an IP path route. The next-hop IP address and the configured device IP address must be on the same network segment, but cannot be the same.
