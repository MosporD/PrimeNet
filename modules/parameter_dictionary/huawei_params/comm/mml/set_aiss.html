Set Air Interface Soft Synchronization Parameters (SET AISS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set parameters related to air interface soft synchronization.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only LMPT and UMPT as the main control board in LTE FDD mode support the air interface soft synchronization function.

  • The air interface soft synchronization phase lock function cannot be enabled on the GSM and LTE FDD sides simultaneously.

  • The air interface soft synchronization phase lock function can take effect on the GSM side only when the E1T1 or SYNCETH shared by the peer standard, E1T1, or SYNCETH is used as the system clock.

  • The air interface soft synchronization phase lock function can take effect on the LTE FDD side only when the SYNCETH shared by the peer standard or SYNCETH is used as the system clock.

  • The LMPT board supports the air interface soft synchronization phase lock function only for LTE FDD. The GTMU and UMDU boards support the air interface soft synchronization phase lock function only for GSM. The WMPT does not support the air interface soft synchronization phase lock function.

  • Enabling air interface soft synchronization will increase the filtering period that is invisible to users, which affects the time the ALM-26262 External Clock Reference Problem alarm is reported. In co-MPT scenarios, enabling air interface soft synchronization will affect the filtering periods of all modes deployed on the main control board.

  • If air interface soft synchronization switch is set to OFF, the air interface soft synchronization function will become unavailable.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Only GSM and LTE FDD support the air interface soft synchronization function.

  • [Co-MPT,eGBTS]The air interface soft synchronization phase lock function cannot be enabled when the current system clock is changed from E1T1, SYNCETH, or E1T1 or SYNCETH shared by the peer standard to other clock sources.

  • [Co-MPT,eGBTS]The air interface soft synchronization phase lock function can take effect only when frequency synchronization is used and the current system clock source is E1T1, SYNCETH, or E1T1 or SYNCETH shared by the peer standard, the NR currently does not support this function.

  • [Co-MPT,eGBTS]The air interface soft synchronization phase lock function cannot take effect when the clock synchronization mode is changed from frequency synchronization to time synchronization.

  • [Co-MPT]When air interface soft synchronization enhancement is enabled, the STR FREQDIFFCHK and DSP FREQDIFFRSLT commands are not supported and the faults related to a large offset of the reference clock source cannot be detected.

  • [Co-MPT]When air interface soft synchronization enhancement is enabled, the STR CLKTST, STP CLKTST, and DSP CLKTST commands are not supported and clock quality cannot be monitored using MML commands or on the monitoring interface.

Parameters

ID Name Description
FLAG Air Interface Soft Synchronization Switch

Meaning: Indicates whether the Air interface Soft synchronization Phase Lock function is enabled on the NE, which can be set to ON or OFF. ON indicates that the switch for the Air interface soft synchronization phase lock function is set to on and OFF indicates that the Air interface soft synchronization phase lock function is set to off.

GUI Value Range: ON(On), OFF(Off)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: OFF(Off)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L-FDD, R, N-FDD
STANDARD Air Interface Soft Synchronization Standard

Meaning: Indicates the standard where the Air interface soft synchronization function is enabled.

GUI Value Range: GSM(GSM), LTE(LTE)

Unit: None

Actual Value Range: GSM, LTE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
NETMODE Soft-Synchronized Network Adaption Mode

Meaning: Indicates the adaption mode of the soft synchronous transport network. The value of this parameter depends on the synchronous status of the transport network.

GUI Value Range: GEN(General Mode), ENH(Enhanced Mode)

Unit: None

Actual Value Range: GEN, ENH

MML Default Value: GEN(General Mode)

Recommended Value: If the network jitter is large, this parameter is set to AissNetModeEnh. Otherwise, this parameter is set to AissNetModeGen.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
FREQUENCE Air Soft Syn Phase Adjustment Period

Meaning: Indicates the adjustment period of the frame clock phase when the Air interface soft synchronization Phase Lock function is enabled on the NE.

GUI Value Range: 300SEC(300 Seconds), 480SEC(480 Seconds)

Unit: None

Actual Value Range: 300SEC, 480SEC

MML Default Value: 300SEC(300 Seconds)

Recommended Value: It is recommended that this parameter be set to its default value, 300 seconds, in normal conditions. If the network jitter is large, set this parameter to 480 seconds and the Soft-synchronized Network Adaption Mode parameter to ENH.

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set set parameters related to Air interface soft synchronization with parameters as follows: Air Interface Soft Synchronization Switch: On, Air Interface Soft Synchronization standard: GSM, Soft-synchronized Network Adaption Mode: Enhanced Mode, Air Soft Syn Phase Adjustment Period: 480 Seconds, run the following command:
SET AISS: FLAG=ON, STANDARD=GSM, NETMODE=ENH, FREQUENCE=480SEC;
