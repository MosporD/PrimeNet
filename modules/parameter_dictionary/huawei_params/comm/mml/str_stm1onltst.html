Start STM-1 Online Performance Test (STR STM1ONLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start the STM-1 online performance test.

Note

  • [Co-MPT,NodeB]Ensure that the unchannelized optical sub-board to be listed is in position and work properly.

  • [Co-MPT,NodeB]After this command is executed, services are not interrupted.

SW Period Report Switch

Meaning: Indicates whether to report the test result every one second. If this parameter is set to ON, the test result is reported every one second after the test is started. If this parameter is set to OFF, the test result is reported only after the STP STM1ONLTST command is executed.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Example

To enable the STM1 online performance test with the parameters as follows: Slot No. 0, Subboard Type: UNCHANNELLED_COVERBOARD, Port No.: 0, Period Report Switch: Off, run the following command:
STR STM1ONLTST: SN=0, SBT=UNCHANNELLED_COVERBOARD, STM1N=0, SW=OFF;
