Start Reference Clock Excessive Frequency Deviation Check (STR FREQDIFFCHK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to check the cause of an excessive frequency deviation when ALM-26262 External Clock Reference Problem is reported and the alarm cause is Excessive Frequency Difference Between Clock Reference and Local Crystal Oscillator.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The reference clock excessive frequency deviation check takes about 15 minutes and services will be interrupted during the check. It is recommended that this command be executed when there is no service or the traffic is light.

  • You need to run the STR CLKTST command before running this command. This command can check the cause of an excessive frequency deviation only when the frequency deviation in the output of the STR CLKTST command is fixed (the latest three frequency jitters between -0.16 Hz and +0.16 Hz). Otherwise, the output of this command is meaningless.

  • If there is no excessive frequency deviation when this command is executed, this command returns failure.

  • This command cannot be executed on IP clocks. Otherwise, this command fails to be started.

  • When an excessive frequency deviation check is in progress, the values of the Center DA, Current DA, Clock Synchronization Mode, and Air Interface Soft Synchronization Switch parameters cannot be modified.

  • Run the DSP FREQDIFFRSLT command to query the test result.
