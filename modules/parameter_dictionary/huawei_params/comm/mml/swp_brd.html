Switch over Active/Standby Board (SWP BRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to manually start the swap of the active and standby boards. When this command is executed successfully, the previous standby board becomes active and functions as the active board, while the previous active one becomes standby.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The active and standby boards cannot be switched over when the two boards are synchronizing data, downloading software, supplementing software, or activating software.

  • The BS will be reset after the swap. To avoid data inconsistency before and after the swap, the BS forces the active and standby main control boards to synchronize data after this command is executed, and the BS will be reset only after the data synchronization is complete.

  • In the current version, only the swap of the active and standby main control boards in the same BBU is supported.

  • It takes some time to back up and synchronize data between the active and standby main control boards. Before running this command, ensure that the two boards have worked properly for more than half an hour and no modification is made to the data of the base station during this period of time. Otherwise, data on the active main control board may not be synchronized to the standby main control board and data may be inconsistent between the active and standby main control boards after the two boards are swapped.

  • If the key data on the active and standby boards is inconsistent, data synchronization will be performed between the active and standby boards. After the synchronization, these two boards will not be swapped.

  • The slot number in this command is set to the slot number of the first board in the HA group. For example, if the HA group consists of the main control boards configured in slot 6 and slot 7, the slot number is set to 6.

  • The BLADEBBU does not support this command.

  • When HA Switch is set to OFF, the active/standby switchover of the main control board is disabled. You can run the DSP HASW command to query the active/standby switchover switch and run the SET HASW command to set the switch.

Example

To perform the active/standby board swap with parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command:
SWP BRD: CN=0, SRN=0, SN=6;
