Modify VRET Configuration (MOD VRET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configuration of a virtual remote electrical tilting (VRET) antenna. The VRET antenna is added automatically when an active antenna radio unit (AARU) is added. The configuration information about the VRET antenna can be queried by running the LST VRET command.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the VRET antenna. The device number of the VRET antenna must be unique.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
DEVICENAME Device Name

Meaning: Indicates the name of the VRET antenna. The device name is optional, but the device name configured for each ALD must be unique.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the SASU MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.
  • [eNodeB]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SUBUNITQUANTITY Subunit Quantity

Meaning: Indicates the number of subunits contained in the VRET antenna.

GUI Value Range: 8

Unit: None

Actual Value Range: 8

MML Default Value: 8

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To modify the configuration of a VRET antenna with the parameters as follows: Device No.: 60, Device Name: "PEOPLESQUARE_SEC1_VRET_01", Subunit Quantity: 8, run the following command:
MOD VRET: DEVICENO=60, DEVICENAME="PEOPLESQUARE_SEC1_VRET_01";
