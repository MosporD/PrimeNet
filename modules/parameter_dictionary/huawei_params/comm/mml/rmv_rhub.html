Remove RHUB (RMV RHUB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an RHUB.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]The RHUB to be removed must be located at the chain tail or in any position behind the breakpoint.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Before removing an RHUB, ensure that the branch chains and MPMUs connected with the RHUB are removed.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After an RHUB is removed, the positions of the RHUBs (if configured) behind the removed RHUB are automatically adjusted.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After an RHUB is removed, if links cannot be set up for the associated RHUBs or links cannot work at the highest CPRI line rate, you need to run the STR CPRILBRNEG command to initiate negotiation.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RHUB is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [gNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Example

To remove an RHUB with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, run the following command:
RMV RHUB: CN=0, SRN=60, SN=0;
