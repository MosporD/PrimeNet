List IP to IP Transmission Resource Group Mapping Configuration (LST IP2IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the mapping between the IP address and the IP transmission resource group.

Note

None.

Parameters

None.

Example

To list the configuration of the mapping between the IP address and the IP transmission resource group, run the following command: 
LST IP2IPRSCGRP:;
The result is as follows:
+++    0        2018-04-21 10:49:32
O&M    #2160
%%LST IP2IPRSCGRP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

IP to IP Transmission Resource Group ID

Indicates the ID of the mapping between an IP address and an IP transmission resource group.

IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the destination IP protocol version of the service flow that is bound to an IP transmission resource group.

Destination IPv4 Address

Indicates the destination IPv4 address of the service flow that is bound to an IP transmission resource group.

Subnet Mask

Indicates the subnet mask of the destination IPv4 address of the service traffic bound to an IP transmission resource group.

Destination IPv6 Address

Indicates the destination IPv6 address of the service flow that is bound to an IP transmission resource group.

Prefix Length

Indicates the prefix length of the destination IPv6 address of the service flow that is bound to an IP transmission resource group.
