Display Ethernet Trunk Member Status (DSP ETHTRUNKLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a member port of an Ethernet trunk.

Note

None.

Parameters

ID Name Description
ETHTRKPORTID Ethernet Trunk Port ID

Meaning: Indicates the ID of the Ethernet trunk to which an Ethernet trunk member port belongs.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ETHTRUNKLNKID Ethernet Trunk Link ID

Meaning: Indicates the ID of an Ethernet trunk member port. This parameter value must be unique at the system level.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CLEAR Clear Statistic

Meaning: Indicates whether to delete the statistics about the member ports of an Ethernet trunk. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: NO(No)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the status of a member port of an Ethernet trunk as follows, run the following command: 
DSP ETHTRUNKLNK:;:;

Output Description

Field Description

Ethernet Trunk Port ID

Indicates the ID of the Ethernet trunk to which an Ethernet trunk member port belongs.

Ethernet Trunk Link ID

Indicates the ID of an Ethernet trunk member port. This parameter value must be unique at the system level.

Ethernet Port ID

Indicates the Ethernet port ID associated with an Ethernet trunk member port.

Port Priority

Indicates the priority of the member port in an Ethernet trunk. A smaller parameter value indicates a higher priority.

Cabinet No.

Indicates the number of the cabinet housing the board where the member port of an Ethernet trunk is located.

Subrack No.

Indicates the number of the subrack housing the board where the member port of an Ethernet trunk is located.

Slot No.

Indicates the number of the slot housing the board where the member port of an Ethernet trunk is located.

Ethernet Port No.

Indicates the Ethernet port number referenced by an Ethernet trunk member port.

Port Status

Indicates the status of the member port in an Ethernet trunk.

Local Timeout Mode

Indicates which period is used for transmitting the LACP Protocol Data Units (PDUs) at the local end. When the long period is used, the LACP PDUs are transmitted at a long interval.

Peer Timeout Mode

Indicates which period is used for transmitting the LACP PDUs at the peer end.

MAC Address

Indicates the MAC address of the member port when being added to an Ethernet trunk. The format of the MAC address is XXXX-XXXX-XXXX.

Number of TX LACP Packets(packet)

Indicates the number of LACP PDUs transmitted on the member port of an Ethernet trunk.

Number of RX LACP Packets(packet)

Indicates the number of LACP PDUs received on the member port of an Ethernet trunk.
