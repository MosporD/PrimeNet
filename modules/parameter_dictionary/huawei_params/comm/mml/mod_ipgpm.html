Modify IP General Performance Management (MOD IPGPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify an IP GPM detection.

Note

None.

Parameters

ID Name Description
IPGPMID IP GPM Detection ID

Meaning: Indicates the ID of an IP GPM detection.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
DIR Detection Direction

Meaning: Indicates the direction of an IP GPM detection.

GUI Value Range: UP(UP), DOWN(DOWN)

Unit: None

Actual Value Range: UP, DOWN

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
DDM Delay Detection Method

Meaning: Indicates the delay detection method at the bottom layer used by the IP GPM detection.

GUI Value Range: FPDT(FPDT)

Unit: None

Actual Value Range: FPDT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
DETECTOBJECT Detection Object

Meaning: Indicates the object to be detected by the IP GPM on the base station side. If the detection object is IPRSCGRP, the IP GPM detects congestion on transmission links of users in the IP transmission resource group.

GUI Value Range: IPRSCGRP(IP Transmission Resource Group)

Unit: None

Actual Value Range: IPRSCGRP

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
PT Port Type

Meaning: Indicates the type of the port where an IP transmission resource group detected by the IP GPM is carried.

GUI Value Range: LOOPINT(Loopback Interface), OTHER(Other)

Unit: None

Actual Value Range: LOOPINT, OTHER

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
PORTID Port ID

Meaning: Indicates the ID of the port where an IP transmission resource group detected by the IP GPM is carried.

GUI Value Range: 0~99999

Unit: None

Actual Value Range: 0~99999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IPGPM MO, PORTID is valid only when PT is set to DETECTOBJECT and PT is set to LOOPINT.

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
IPRSCGRPID IP Transmission Resource Group ID

Meaning: Indicates the ID of the IP transmission resource group detected by the IP GPM.

GUI Value Range: 0~150014

Unit: None

Actual Value Range: 0~150014

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IPGPM MO, IPRSCGRPID is valid only when PT is set to DETECTOBJECT and PT is set to OTHER.

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To modify an IP General Performance Management with the parameters as follows: IP GPM Detection ID: 0, Detection Direction: UP, Delay Detection Method: FPDT, Detection Object: IPRSCGRP, Port Type: OTHER, IP Transmission Resource Group ID: 0, run the following command:
MOD IPGPM: IPGPMID=0, DIR=UP, DDM=FPDT, DETECTOBJECT=IPRSCGRP, PT=OTHER, IPRSCGRPID=0;
