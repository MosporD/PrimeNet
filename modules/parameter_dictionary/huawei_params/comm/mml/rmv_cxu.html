Remove CXU (RMV CXU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a CXU.

Note

  • When there is no breakpoint on a chain, only the CGPS or RPCU at the chain tail can be removed from the chain. When there is a breakpoint on the chain, only the CGPS or RPCU behind the breakpoint can be removed from the chain.

  • If a CGPS is to be removed from the cold backup ring, the CGPS must be located between two breakpoints.

  • After a CXU is removed, the positions of other boards (if configured) behind the removed CXU are automatically adjusted.

  • After a CXU on a multi-level RRU chain/ring is removed, if links cannot be established for the associated boards or the established links cannot work at the maximum CPRI line rate, run the STR CPRILBRNEG command to initiate negotiation.

  • Before removing an RMU, ensure that the RRU branch chain and boards which connect to the RMU have been removed.
