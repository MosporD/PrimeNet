Set Local BBU As Reference Clock Source in Cloud BB (SET CLOUDSRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set whether the local NE serves as the reference clock source in the Cloud BB. When the NE is enabled, the other NEs in the Cloud BB can share the reference clock source of the local NE by adding an interconnection clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Activating the interconnection reference clock is mutually exclusive with enabling the Cloud BB reference clock.

  • This command only applies to the UMPT.

  • If Cloud BB Clock Reference Source Flag is set to DISABLE, the clock of other NEs sharing the interconnection clock source provided by this NE will become unavailable.

Parameters

ID Name Description
CLOUDSRC Cloud BB Clock Reference Source Flag

Meaning: Indicates whether the local BBU serves as the clock reference source in the Cloud BB.

GUI Value Range: DISABLE(DISABLE), ENABLE(ENABLE)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(DISABLE)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the values of SYSCLKSRC and CLOUDSRC in the TASM MO are INTER_SYSCLK and ENABLE, respectively, the value of any SRN parameter in the corresponding GPS MO must be less than or equal to 60.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Set Local BBU As Reference Clock Source in Cloud BB, Cloud BB Clock Reference Source Flag: ENABLE, run the following command:
SET CLOUDSRC: CLOUDSRC=ENABLE;
