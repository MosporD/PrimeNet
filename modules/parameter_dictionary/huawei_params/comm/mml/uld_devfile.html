Upload Inventory File (ULD DEVFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to upload device files to an FTP server.

Note

  • Before running this command, ensure that the following conditions are met:

    1. The FTP server has been configured.

    2. The FTP server is running properly. The IP address of the FTP server is on the same network segment as the IP address of the base station, and the FTP server is properly connected to the base station.

    3. There is no firewall between the FTP server and the base station.

    4. The user of the FTP server has the permission to read and write files in specified paths.

    5. There is no file with the same name as the destination file on the FTP server. If there is such a file on the server, the file would be replaced after the upload.

  • Before running this command, ensure that the device file is exported by running the EXP DEVFILE command.

  • If this command is delivered again during the execution of this command, the system displays a message indicating the failure in uploading the file for the second execution of the command. The first execution of the command, however, is not affected.

  • Destination File Name contains the file name and its save path. The length of the file name must not exceed 64 characters and the maximum length of the file name plus the path cannot exceed 230 characters.

Example

To upload a device file with the parameters as follows: IP Mode:IPV4, FTP Server IP: 192.168.70.150, User Name: ge, Password: *****, Destination File Name: test.xml, run the following command:
1.Upload to the default path:
ULD DEVFILE: MODE=IPV4, IP="192.168.70.150", USR="ge", PWD="*****", DSTF="test.xml";

2.Upload to the relative path on the FTP Server:
ULD DEVFILE: MODE=IPV4, IP="192.168.70.150", USR="ge", PWD="*****", DSTF="\files\brdlog\test.xml";

3.Upload to the relative path on the MAE FTP server:
ULD DEVFILE: MODE=IPV4, IP="192.168.70.150", USR="ge", PWD="*****", DSTF="/ftproot/Other/expt/test.xml";
