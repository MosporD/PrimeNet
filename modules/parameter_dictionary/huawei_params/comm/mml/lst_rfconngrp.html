List RF Connect Group (LST RFCONNGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configured RF interconnection.

Note

RF interconnection indicates that two RF modules are interconnected. The sequence in which two RF modules are configured does not affect this command. The numbers in "RRU1" and "RRU2" are used to differentiate the two RF modules and do not indicate the sequence in which two RF modules are configured. The sequence in which two RF modules are displayed in the output of this command may be different from the sequence in which two RF modules are configured.

Parameters

None.

Example

To list the configuration of all RRU/RFU interconnections, run the following command:
LST RFCONNGRP:;
The result is shown as follows:
+++    0        2012-07-04 18:05:39
O&M    #1399
%%LST RFCONNGRP:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

RF Connect Type

Indicates the RF interconnection type. Intra interconnection means the interconnection between two RRUs or RFUs managed by the same main control board. Outer connection means the interconnection between two RRUs or RFUs managed by different main control boards.

Cabinet No. of RRU1

Indicates the cabinet number of RRU1/RFU1 for RF interconnection.

Subrack No. of RRU1

Indicates the subrack number of RRU1/RFU1 for RF interconnection.

Slot No. of RRU1

Indicates the slot number of RRU1/RFU1 for RF interconnection.

Cabinet No. of RRU2

Indicates the cabinet number of RRU2/RFU2 for RF interconnection. For RF interconnection in outer interconnection mode, value NULL is displayed because the cabinet No., subrack No., and slot No. of the peer RRU remain unknown.

Subrack No. of RRU2

Indicates the subrack number of RRU2/RFU2 for RF interconnection. For RF interconnection in outer interconnection mode, value NULL is displayed because the cabinet No., subrack No., and slot No. of the peer RRU remain unknown.

Slot No. of RRU2

Indicates the slot number of RRU2/RFU2 for RF interconnection. For RF interconnection in outer interconnection mode, value NULL is displayed because the cabinet No., subrack No., and slot No. of the peer RRU remain unknown.
