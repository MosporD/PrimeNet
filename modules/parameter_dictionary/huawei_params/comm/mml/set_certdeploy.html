Set Certification Deploy Position (SET CERTDEPLOY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set where a certificate is configured.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • All certificate-related commands take effect only on the board specified by this command. When you change the transport board or run this command to deploy a certificate on a board that is not configured with a specified certificate file, an alarm will be reported. Under this circumstance, you need to remove the configuration of the certificate files in the system and apply for a new certificate.

  • When there is an HA group, please ensure the board specified by this command has been configured.

  • If the position where a certificate is configured changes, you must reset the base station to validate the change.

  • This operation may disable certificates, and therefore interrupt ongoing services or disconnect OM channels. You are advised to run the CFM CB command to enable configuration data rollback.

  • Except for multi-interface IPsec scenarios, the board on which a certificate is deployed must be the same as the board that is bound to the IPsec policy group. In multi-interface IPsec scenarios, multiple boards can be bound to IPsec policy groups and use the same certificate.

  • [Co-MPT,eGBTS]The GTMUb does not support this function.

Parameters

ID Name Description
DEPLOYTYPE Certification Deploy Position Type

Meaning: Indicates the deployment position of a digital certificate. If this parameter is set to DEFAULT, the certificate is configured on the main control board. If this parameter is set to SPECIFIC, the certificate is configured on the board in the specified slot. If this parameter is set to NULL, no certificate is configured on the BS.

GUI Value Range: DEFAULT(Default), SPECIFIC(Specific), NULL(NULL)

Unit: None

Actual Value Range: DEFAULT, SPECIFIC, NULL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set certification deployment position with the parameters as follows: Certification Deploy Position Type: SPECIFIC, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command: 
SET CERTDEPLOY: DEPLOYTYPE=SPECIFIC, CN=0, SRN=0, SN=6;
