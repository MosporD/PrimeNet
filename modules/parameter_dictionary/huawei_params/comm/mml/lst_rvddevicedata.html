List RVD Device Data (LST RVDDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration in the remote vendor-defined antenna line device (RVD) data.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RVD.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RVD subunit, which starts from 1.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Output Description

Field Description

Device No.

Indicates the device number of the RVD.

Subunit No.

Indicates the number of the RVD subunit, which starts from 1.

Antenna Model Number

Indicates the model of the RVD module.

Antenna Serial No.

Indicates the serial number of the RVD module.

Band1

Indicates band 1 supported by the antenna.

Beamwidth1(degree)

Indicates the beamwidth of band 1. This parameter is valid only if band 1 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern.

Gain1(0.1dBi)

Indicates the gain of band 1. This parameter is valid only if band 1 is in use.

Band2

Indicates band 2 supported by the antenna.

Beamwidth2(degree)

Indicates the beamwidth of band 2. This parameter is valid only if band 2 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern.

Gain2(0.1dBi)

Indicates the gain of band 2. This parameter is valid only if band 2 is in use.

Band3

Indicates band 3 supported by the antenna.

Beamwidth3(degree)

Indicates the beamwidth of band 3. This parameter is valid only if band 3 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern.

Gain3(0.1dBi)

Indicates the gain of band 3. This parameter is valid only if band 3 is in use.

Band4

Indicates band 4 supported by the antenna.

Beamwidth4(degree)

Indicates the beamwidth of band 4. This parameter is valid only if band 4 is in use. Beamwidth is used to describe the capability of the antenna to transmit RF signals. It is also used to measure the antenna pattern.

Gain4(0.1dBi)

Indicates the gain of band 4. This parameter is valid only if band 4 is in use.

Installation Date

Indicates the date when the antenna is installed.

Installer's ID

Indicates the ID of the installation technician who installed the antenna.

Base Station ID

Indicates the base station ID. AISG1.1-based RVD antennas support a maximum length of 12 characters for the base station ID. If the input base station ID has more than 12 characters, only the first 12 characters are saved on the RVD antenna.

AISG Sector ID

Indicates the AISG sector ID. An AISG1.1-based RVD unit supports the longest sector ID of 4 characters. If the input sector ID has more than 4 characters, only the first 4 characters are saved on the RVD.

Antenna Bearing(degree)

Indicates the antenna azimuth. If this parameter is set to 4294967295, the parameter value is not delivered to the device. In this case, the parameter value in the LST RVDDEVICEDATA command output is NULL.

Installed Mechanical Tilt(0.1degree)

Indicates the mechanical tilt of the installation. If this parameter is set to 2147483647, the parameter value is not delivered to the device. In this case, the parameter value in the LST RVDDEVICEDATA command output is NULL.
