List BBP (LST BBP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of baseband processing boards.

Note

The BLADEBBU does not support this function.

Parameters

-Configuration constraints:

  • 3. If the value of CONNPORTNUM in the RRUCHAIN MO is greater than or equal to 3, a board cannot be configured in the slot specified by CONNCN3, CONNSRN3, and CONNSN3.
  • 4. If the value of CONNPORTNUM in the RRUCHAIN MO is 4, a board cannot be configured in the slot specified by CONNCN4, CONNSRN4, and CONNSN4.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]A BBP MO with SN equal to LSN in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN; AT is set to PEERPORT; LCN and LSRN are neither set to 255 and are not simultaneously set to the values of HCN and HSRN respectively.

  • - If the value of CONNSN1 is 3, a BBP MO with SN set to 2 must be configured.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For an RRUCHAIN MO with TT set to TRUNK_CHAIN, AT set to PEERPORT, and LSN set to a value other than 255, LCN set to 255 or CONNCN1, LSRN set to 255 or CONNSRN1, a BBP MO with SN set to the same value as LSN must be configured.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For boards that have baseband processing capabilities, only SN in the MDU MO and SN in the GTMU MO can be set to 6, and SN in the BBP MO cannot be set to 6.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the values of TYPE and CPRIITFTYPE in a BBP MO are UBBP and XCI_QSFP, respectively and the value of TYPE in the SUBRACK MO is BBU3900, the value of SN in the BBP MO must be less than 4.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an RRUCHAIN MO, if TT is set to CHAIN or LOADBALANCE, AT is set to PEERPORT, LCN and LSRN are both set to 255 or are set to the values of as HCN and HSRN respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900, then the following conditions must be met: when HSN is set to 2, a BBP MO with SN set to 3 or a GTMU MO with SN set to 6 is configured; when HSN is set to 3, a BBP MO with SN set to 2 or a GTMU MO with SN set to 6 is configured.
  • [gNodeB]In an RRUCHAIN MO, if TT is set to CHAIN or LOADBALANCE, AT is set to PEERPORT, LCN and LSRN are both set to 255 or are set to the values of as HCN and HSRN respectively, and TYPE in the SUBRACK MO to which the RRUCHAIN MO is connected is set to BBU3900, then the following conditions must be met: when HSN is set to 2, a BBP MO with SN set to 3 is configured; when HSN is set to 3, a BBP MO with SN set to 2 is configured.
  • [gNodeB]A BBP equal to the converged board in an RRUCHAIN MO must be configured if the RRUCHAIN MO meets the following conditions: TT is set to CHAIN or LOADBALANCE; AT is set to PEERPORT; LCN and LSRN are both set to 255 or are set to the values of HCN and HSRN respectively; LSN is not set to 255.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the baseband processing board.

Subrack No.

Indicates the subrack number of the baseband processing board.

Slot No.

Indicates the slot number of the baseband processing board. Baseband processing boards can be configured only in slots 0 to 5 and the multimode digital unit can be configured only in slot 6.

Work Mode

Indicates the working mode of the baseband processing board. There are sixteen working modes: FDD, TDD, HYBRID, TDD_ENHANCE, TDD_8T8R, TDD_TL, FDD_ATG, FDD_NBIOT, NBIOT, FDD_NBIOT_ENHANCE , FDD_NBIOT_CUSTOM, NORMAL, HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, SPEC_MODE1. The Frequency Division Duplex (FDD) mode carries the traditional voice and data services. TDD is short for Time Division Duplex. The HYBRID mode is a combination of FDD and IMB modes. In Integrated Mobile Broadcasting (IMB) mode, the baseband processing board carries the mobile TV services. The value TDD_ENHANCE indicates the TDD mode integrated with the BeamForming (BF) function. The BF function provides the data transmission service in transmission modes 7 and 8 defined in protocols. For details, see 3GPP TS 36.213. In TDD_8T8R mode, the baseband processing board supports TD-LTE single-mode 8T8R. In addition, the baseband processing board supports the BF function and CPRI specifications are applied between the BBU and RRU. In TDD_TL mode, the baseband processing board supports the TD-LTE&TD-SCDMA dual mode and the TD-LTE single mode. In addition, the baseband processing board supports 8T8R BF and 2T2R Multiple-Input Multiple-Output (MIMO) and CMCC TD-LTE IR specifications are applied between the BBU and RRU. In FDD_ATG mode, the baseband processing board supports communication between Air and Ground. The FDD_ATG mode applies only to communication between air and ground. The value FDD_NBIOT indicates that the baseband processing board supports both LTE FDD and NB-IoT. The value NBIOT indicates that the baseband processing board supports NB-IoT. The value FDD_NBIOT_ENHANCE indicates that the baseband processing board supports both LTE FDD and NB-IoT and the NB-IoT capability is enhanced. The value FDD_NBIOT_CUSTOM indicates customized FDD&NB-IoT dual-mode specifications. NORMAL indicates the normal mode. HYBRID_BALANCE indicates the mixed configuration balancing mode. HYBRID_MMCELL_ENHANCE indicates the mixed configuration enhanced MM mode. HYBRID_NORMALCELL_ENHANCE indicates the mixed configuration enhanced common cell mode. SPEC_MODE1 indicates specification mode 1 of a specific BBP.

Hardware Capacity Enhance

Indicates the hardware capabilities of the baseband processing board. For a WBBP, NORMAL indicates basic hardware capabilities, and FULL indicates full hardware capabilities. For a UBBP, NORMAL indicates basic hardware capabilities, PARTIAL indicates partial hardware capabilities, and FULL indicates full hardware capabilities. This parameter takes effect only for UMTS.

CPRI Extension

Indicates the CPRI extension switch of a BBP. This parameter takes effect only on LBBPd(excluding LBBPd5) boards.

CPRI Extension Mode

Indicates the CPRI extension mode. If this parameter is set to FRONTPANELEXTENSION, the transmission capability of a single fiber optic cable is enhanced. If this parameter is set to BACKPANELEXTENSION, the forwarding capability of the backplane is enhanced. This parameter takes effect only for LBBPd(excluding LBBPd5) boards. The value FRONTPANELEXTENSION can take effect for a board in any of slots 0 to 5, but the value BACKPANELEXTENSION can take effect only for a board in slot 4 or 5. If this parameter is set to BACKPANELEXTENSION, the board connected to the cable can only process baseband signals. If this parameter is set to BACKPANELEXTENSION, the cable can transmit data only for TDD cells when CPRI Compression is set to NORMAL_COMPRESSION. If this parameter is set to FRONTPANELEXTENSION, the cable can transmit data for TDD or FDD cells only when CPRI Compression is set to NORMAL_COMPRESSION. If the value of this parameter for a board is modified and the parameter setting takes effect, the board will be automatically reset.

Board Specification

Indicates the type of a board. If the user does not need to forcibly verify the board specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. If the user needs to forcibly verify the board specifications using the MAE-Deployment, this parameter must be set to the hardware type of the board. For example, this parameter must be set to UBBPd1 for a UBBPd1 board, this parameter must be set to UBBPe1 for a UBBPe1 board and be set to UBBPf1 for a UBBPf1 board. After this parameter is specified, the MAE-Deployment checks the configurations of the board based on the value of this parameter. This ensures that these configurations are correct before they take effect.

Cell Channel Number Extension

Indicates the cell channel number extension switch. When this parameter is set to ON, more cell channels are supported and the distance between channels decreases. Only the UBBP supports this parameter and it takes effect only to the UBBPd9 or UBBPdc. In addition, the UBBPd9 or UBBPdc is reset after this parameter is modified. The parameter takes effect only in LTE.

Base Band Work Standard

Indicates the modes for which the UBBP, LCOP, UMDU or UBBP-W provides baseband processing resources. If the UBBP, UMDU or UBBP-W provides only CPRI ports for a mode, you do not need to select this mode for the UBBP, UMDU or UBBP-W.

Standard Ratio

Indicates the resource ratio of each mode. Currently, only UBBP boards support this parameter. If other baseband processing boards are used, this parameter is invalid. When the Working Standard parameter of a UBBP is set to multiple modes the Standard Ratio parameter is set to FDD_ENHANCE(FDD Enhance), TDD_ENHANCE(TDD Enhance), NBIOT_ENHANCE(NB-IoT Enhance), or NR_ENHANCE(NR Enhance), compared with the scenario where the Standard Ratio parameter is set to DEFAULT(Default), the cell specifications of this mode increase or remain unchanged and the cell specifications of other modes decrease or remain unchanged. For example, if the Working Standard parameter of a UBBPe6 is set to UMTS&LTE and the Standard Ratio parameter is set to FDD_ENHANCE(FDD Enhance), the specifications of LTE FDD cells increase and the specifications of UMTS cells decrease.

CPRI Interface Type

When this parameter is set to CPRI_SFP, the port type is CPRI and the port is interconnected to the SFP module. If this parameter is set to XCI_QSFP, the port type is XCI and the port is interconnected to the QSFP module. If this parameter is set to CPRI_QSFP, the port type is CPRI_QSFP and the port is interconnected to the QSFP module. If this parameter is set to CPRI_SFPPLUS, the port type is CPRI and the port is interconnected to the DSFP module. If this parameter is set to CPRI_QSFPPLUS, the port type is CPRI and the port is interconnected to the DSFP module through a conversion connector.After the value of this parameter is changed, the board will reset.

LTE Flexible Specification Switch

Indicates whether the specifications for LTE FDD and LTE TDD cells supported by a baseband processing board can be flexibly adjusted. When this switch is turned on, the RAT resource proportion can be flexibly allocated. In this case, a cell must be bound to a baseband processing board. When this switch is turned off, the RAT resource proportion needs to be configured. Currently, this parameter applies only to the UBBPg.
