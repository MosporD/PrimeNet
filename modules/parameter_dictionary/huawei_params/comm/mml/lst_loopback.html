List Loopback Interface Configuration (LST LOOPBACK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of loopback interfaces.

Note

None.

Parameters

None.

Example

To list the configurations of a loopback interface, run the following command: 
LST LOOPBACK:;
The result is shown as follows:
+++    0        2018-03-08 20:27:28
O&M    #9461
%%LST LOOPBACK:;%%
RETCODE = 0  Operation succeeded.

List Loopback Interface Configuration
-------------------------------------
    Port ID  =  0
Cabinet No.  =  0
Subrack No.  =  0
   Slot No.  =  6
 User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

Port ID

Indicates the ID of a loopback interface and is unique in the system.Port IDs 4 to 7 are reserved by the system and cannot be manually configured.

Cabinet No.

Indicates the cabinet number of the board to which the loopback interface belongs.

Subrack No.

Indicates the subrack number of the board to which the loopback interface belongs.

Slot No.

Indicates the slot number of the board to which the loopback interface belongs.

User Label

Indicates the user-defined information about a loopback interface.
