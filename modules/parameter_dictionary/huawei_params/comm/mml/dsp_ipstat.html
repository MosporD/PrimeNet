Display Statistical Information About IP Packet (DSP IPSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the statistical information about transmitted and received IP packets.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]When multiple VRF instances are configured on the UMPTg board, the number of packets discarded by the UMPTg due to replay detection in all virtual routing domains is displayed in the default routing domain. This value is 0 for all non-default routing domains.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The maximum number of packets discarded due to replay detection by the UMPTg per second is 65535. When the number of replayed packets received per second is greater than 65535, the query result is less than the number of actually discarded replayed packets.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Packets entering the IPSec module in the encryption direction are in plain text. Statistics are collected in all encryption directions based on the inner layer (encryption service IP protocol version + virtual routing domain).

  • [Co-MPT,NodeB,eNodeB,gNodeB]Packets entering the IPSec module in the decryption direction are in cipher text. Statistics are collected in all decryption directions based on the outer layer (IKE tunnel IP protocol version + virtual routing domain).

  • [Co-MPT,NodeB,eNodeB,gNodeB]The number of fragments that are discarded due to incomplete fragment reassembly within the timeout period is counted in the reassembly timeout statistics. The number of fragments discarded due to abnormal fragmentation or exceeding the board reassembly specifications is counted in the reassembly exception statistics. The UMPTg does not support the measurement of reassembly timeout and reassembly exception separately. The value of reassembly timeout packets is constantly 0, and reassembly timeout packets are counted in the statistics of reassembly exception packets.

  • [Co-MPT,eNodeB,gNodeB]In the IPv4 and IPv6 IPsec hybrid scenario, packet statistics in all encryption directions are calculated based on the plaintext IP version, and packet statistics in all decryption directions are calculated based on the ciphertext IP version.

  • [Co-MPT,eGBTS]The GTMUb does not support packet fragmentation and reassembly measurement.

  • [Co-MPT,eGBTS]The GTMUb/GTMUc does not support IKE- or IPSec-related measurement.

  • [Co-MPT,eGBTS]The GTMUb/GTMUc does not support passing-by data flow measurement.

  • [NodeB]The WMPT does not support IKE- or IPSec-related measurement.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the number of the subrack where the board is located.

Slot No.

Indicates the number of the slot where the board is located.

VRF Index

Indicates the index of a VRF instance.

Total Number of IP Layer RX PDUs(packet)

Indicates the total number of packets received at the IP layer.

Total Number of IP Layer TX PDUs(packet)

Indicates the total number of packets transmitted at the IP layer.

Total Number of IP Layer Header Check Failure PDUs(packet)

Indicates the total number of packets with header check failures at the IP layer.

Total Number of IP Layer Route Failure PDUs(packet)

Indicates the total number of packets with routing failures at the IP layer.

Total Number of IP Layer TX Fragment PDUs(chip)

Indicates the total number of fragments transmitted at the IP layer.

Total Number of IP Layer Reform Succeeded PDUs(packet)

Indicates the total number of successfully reassembled packets at the IP layer.

Total Number of IP Layer Reform Discard PDUs(packet)

Indicates the total number of reassembled packets discarded at the IP layer.

Total Number of IP Layer Reform Timeout PDUs(packet)

Indicates the total number of reassembled packets after timeout at the IP layer.

Total Number of IP Layer Reform Abnormal PDUs(packet)

Indicates the total number of abnormal reformed packets at the IP layer.

Number of Packets Discarded Due to Fragmentation Failures(packet)

Indicates the number of packets discarded due to fragmentation failures on the transmitter.

Total Number of Packets Received by the Decryption Module of the Receiver(packet)

Indicates the total number of packets received by the decryption module of the receiver at the IP layer.

Total Number of Encrypted Packets Received at the IP Layer of the Receiver(packet)

Indicates the number of received packets that have been encrypted.

Number of Failing Decrypted Packets at the Receiver(packet)

Indicates the total number of packets that fail decryption at the IP layer of the receiver.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to Invalid Source IP Addresses(packet)

Indicates the number of encrypted packets received by the IP layer of the receiver from invalid IP addresses.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to Replay Attacks(packet)

Indicates the total number of packets discarded at the IP layer of the receiver due to replay attacks.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to No Inbound SA(packet)

Indicates the total number of packets discarded at the IP layer of the receiver due to a lack of inbound SA.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to Unsupported AH Algorithm(packet)

Indicates the total number of packets discarded because the IP layer of the receiver does not support the AH algorithm.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to Unsupported ESP Algorithm(packet)

Indicates the total number of packets discarded because the IP layer of the receiver does not support the ESP algorithm.

Total Number of Packets Failed in AH Authentication at the IP Layer of the Receiver Hardware(packet)

Indicates the number of received packets that fail the AH-based authentication.

Total Number of Packets Failed in ESP Decryption at the IP Layer of the Receiver Hardware(packet)

Indicates the number of received packets that fail the ESP-based decryption.

Total Number of Packets Failed in ESP Authentication at the IP Layer of the Receiver Hardware(packet)

Indicates the number of received packets that fail the ESP-based authentication. The parameter takes effect only in UMPT.

Number of Packets Successfully Decrypted at the IP Layer of the Receiver(packet)

Indicates the number of packets that have been successfully decrypted at the receiver.

Total Number of Packets Discarded at the IP Layer of the Receiver Due to Having Been Encrypted(packet)

Indicates the number of received packets that should not have been encrypted.

Total Number of Plain Packets Received at the IP Layer of the Receiver(packet)

Indicates the total number of plain packets received at the IP layer of the receiver.

Number of Packets Discarded at the IP Layer of the Receiver Due to not Being Encrypted(packet)

Indicates the number of packets received at the IP layer that comply with ACL rules and should have been encrypted.

Total Number of Packets Received by the Encryption Module of the Transmitter(packet)

Indicates the total number of packets received by the encryption module of the transmitter.

Number of Packets That Should be Encrypted at the Transmitter(packet)

Indicates the number of packets that need to be encrypted at the transmitter.

Number of Packets Successfully Encrypted at the IP Layer of the Transmitter(packet)

Indicates the number of transmitted packets that are successfully encrypted.

Total Number of Packets Failed to Be Encrypted at the IP Layer of the Transmitter(packet)

Indicates the number of packets that fail to be encrypted at the transmitter.

Total Number of Packets Discarded at the IP Layer of the Transmitter due to No Outbound SA(packet)

Indicates the number of packets discarded at the transmitter because the outbound SAs do not exist.

Total Number of Packets Discarded at the IP Layer of the Transmitter Due to Unsupported AH Algorithm(packet)

Indicates the number of packets discarded because the transmitter does not support the AH algorithm.

Total Number of Packets Discarded at the IP Layer of the Transmitter Due to Unsupported ESP Algorithm(packet)

Indicates the number of packets discarded because the transmitter does not support the ESP algorithm.

Total Number of Packets Failed in AH Authentication at the IP Layer of the Transmitter Hardware(packet)

Indicates the number of packets that fail the AH-based authentication at the transmitter.

Total Number of Packets Failed in ESP Encryption at the IP Layer of the Transmitter(packet)

Indicates the number of transmitted packets that fail ESP encryption.

Total Number of Packets Discarded at the IP Layer of the Transmitter Due to SN Overflow(packet)

Indicates the number of packets discarded due to transmitting sequence number overflow.

Total Number of Packets That Should Not Have Been Encrypted at the IP Layer of the Transmitter(packet)

Indicates the number of packets that do not need to be encrypted at the transmitter.

Number of Received ICMP Port Unreachable Packets(packet)

Indicates the number of received ICMP port unreachable packets.

Number of Received ICMP Request Packets(packet)

Indicates the number of received ICMP echo request packets.

Number of Received ICMP Reply Packets(packet)

Indicates the number of received ICMP echo reply packets.

Number of Transmitted ICMP Port Unreachable Packets(packet)

Indicates the number of transmitted ICMP port unreachable packets.

Number of Transmitted ICMP Request Packets(packet)

Indicates the number of transmitted ICMP echo request packets.

Number of Transmitted ICMP Reply Packets(packet)

Indicates the number of transmitted ICMP echo reply packets.

Number of Received UDP Ping Packets(packet)

Indicates the number of received UDP ping packets. This parameter is valid only in GSM and UMTS modes.

Number of Transmitted UDP Ping Loop Packets(packet)

Indicates the number of transmitted UDP ping loop packets. This parameter is valid only in GSM and UMTS modes.

Number of Bypass Packets(packet)

Indicates the number of bypass packets at the IP layer.
