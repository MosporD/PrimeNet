Display Status of 225-400 V DC Power Distribution Unit (DSP HVDCSTATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the operating status of a 225-400 V DC power distribution unit

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the PMU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the PMU is located.

GUI Value Range: 7,17~18

Unit: None

Actual Value Range: 7,17~18

MML Default Value: None

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the PMU is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the operating status of a 225-400 V DC power distribution unit with parameters as follows:  Cabinet No.: 0, Subrack No.: 7:
DSP HVDCSTATE: CN=0, SRN=7;
The result is shown as follows:

Output Description

Field Description

SubNo

Indicates the subboard number.

BPGNDR(kohm)

Indicates the positive resistance of the total line bank to the ground.

BNGNDR(kohm)

Indicates the negative resistance of the total line bank to the ground.

HVDU Output Status

Indicates the output status of the 225-400 V DC power distribution unit (HVDU).

Subboard Software Version

Indicates the software version of the subboard.

Subboard PCB Version

Indicates the PCB version of the subboard.

Mains Intrusion Test Result

Indicates the mains intrusion test result of the test port on the subboard.

IR Test Result for Positive Electrode to GND

Indicates the insulation resistance test result for the positive electrode to the ground of the test port on the subboard.

IR Test Result for Negative Electrode to GND

Indicates the insulation resistance test result for the negative electrode to the ground of the test port on the subboard.
