Request Device Certificate (REQ DEVCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to apply for a new device certificate from a certificate authority (CA) by starting a Certificate Management Protocol (CMP) session. After the BS successfully obtains a device certificate, users can list the configuration or query the status of the certificate by running the LST CERTMK or DSP CERTMK command, respectively. After a CMP session is started, its status can be queried by running the DSP CMPSESSION command.

Note

  • If certificate number reaches 30, this command will return failure, please manually delete the certificates which are useless.

  • After a device certificate is successfully applied for by running the REQ DEVCERT command, the system automatically detects the following scenarios:

    -The NE is configured with more than one CA objects.

    -The NE is configured with CA objects with CERTREQSW set to USERDEFINE.

    -The NE is configured with CERTMK MO with the CASW set to ON.

    -The NE is configured with an IKE peer with CERTSOURCE set to CERTMK.

    In any one of the preceding scenarios, the system sets CASW to ON in the configuration for the new device certificate, and it also incorporates the CA name specified by the user during the application into this configuration.

  • You can run the DSP CERTMK command to query whether a certificate, which has been obtained, takes effect. Do not apply for or update a certificate repeatedly before the certificate takes effect, otherwise the current applied certificate will load failed.

  • Synchronize the NE with the CA server before applying for or updating a device certificate. Otherwise, the validity date of the certificate may have not arrived and the certificate cannot immediately take effect, affecting the subsequent application process.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Before running this command to apply for an operator-issued device certificate, ensure that the preset certificate file appcert.pem exists and has been properly loaded.

Parameters

ID Name Description
CANAME Certificate Authority Name

Meaning: Indicates the name of the CA. The CA name except item "ORGANIZATIONNAME" must not contain the following invalid characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), bar (|) and underscore (_). Otherwise, an error occurs when you run the REQ DEVCERT command to apply for a device certificate.

GUI Value Range: 1~127 characters

Unit: None

Actual Value Range: 1~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
APPCERT Certificate File Name

Meaning: Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in a CERTMK MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CERTMK MO is being added, the APPCERT is case-insensitive; but when a CERTMK MO is referenced, the APPCERT is case-sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery. There is only one such MO on an NE and this MO cannot be added or removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
REKEY Renew Key

Meaning: Indicates whether to generate a new key pair.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: YES(YES)

Recommended Value: YES(YES)

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when REQMODE is set to UPDATE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To obtain a device certificate by starting a CMP session with the parameters as follows: Certificate Authority Name: "C = CN,S = Some-State,O = Internet Widgits Pty Ltd,CN = aksz", Certificate File Name: "basestationCert.pem", run the following command:
REQ DEVCERT: CANAME="C = CN,S = Some-State,O = Internet Widgits Pty Ltd,CN = aksz", APPCERT="basestationCert.pem";
