Display Packet Filter Statistics (DSP PACKETFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of the packets that are matched with the ACL rules after the packet filtering is bound to the Ethernet port.

Note

  • If Filter Mode is set to ADV_AND_L2, the number of packets or bytes that are allowed to pass according to the advanced ACL and the number of packets or bytes that are allowed to pass according to the layer 2 ACL are measured, respectively.

  • When CATALOG is set to ACLGRP or ACLRULE, statistics of the packets on all bound ports of the corresponding board are displayed.

Example

To query the packet filtering statistics with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, Catalog: PORT, Clear Statistic: NO, run the following command:
DSP PACKETFILTER: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, CATALOG=PORT, CLEAR=NO;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the packet filtering is used.

Subrack No.

Indicates the subrack number of the board where the packet filtering is used.

Slot No.

Indicates the slot number of the board where the packet filtering is used.

Subboard Type

Indicates the subboard type of the board where the packet filtering is used.

Port Type

Indicates the port type. This parameter cannot be set to SUBIF for UMTS.

Port No.

Indicates the port number.

Filter Mode

Indicates the packet filtering mode. The BS can filter packets based on the advanced ACL, layer-2 ACL, or both at the same time.

Advanced ACL ID

Indicates the ID of an advanced ACL. The value of this parameter ranges from 3000 to 3999.

Layer 2 ACL ID

Indicates the ID of an ACL at layer 2. The value of this parameter ranges from 4000 to 4999. The BS filters packets based on only VLAN IDs.

Match Behavior

Indicates whether to permit or reject access of the data that does not match the ACL rule. If this parameter is set to PERMIT, data that does not match the ACL rule is allowed to pass. If this parameter is set to DENY, data that does not match the ACL rule is discarded.

Number of TX Packets(packet)

Indicates the number of transmitted packets. This parameter is reserved for further extension.

Number of RX Packets(packet)

Indicates the number of received packets.

Number of TX Permit Packets(packet)

Indicates the number of permitted packets on the TX channel. This parameter is reserved for further extension.

Number of TX Deny Packets(packet)

Indicates the number of rejected packets on the TX channel. This parameter is reserved for further extension.

Number of RX Permit Packets(packet)

Indicates the number of permitted packets on the RX channel.

Number of RX Deny Packets(packet)

Indicates the number of rejected packets on the RX channel.

Number of RX Packets Matched Default Behavior(packet)

Indicates the number of the packets that do not match the ACL rules for packet filtering. If MB is set to PERMIT, this parameter measures the number of accessed packets. If MB is set to DENY, this parameter measures the number of discarded packets. This parameter is valid only when CATALOG is set to PORT.

Bytes of TX Packets(byte)

Indicates the number of bytes contained in transmitted packets. This parameter is reserved for further extension.

Bytes of RX Packets(byte)

Indicates the number of bytes contained in received packets.

Bytes of TX Permit Packets(byte)

Indicates the number of bytes contained in permitted packets on the TX channel. This parameter is reserved for further extension.

Bytes of TX Deny Packets(byte)

Indicates the number of bytes contained in rejected packets on the TX channel. This parameter is reserved for further extension.

Bytes of RX Permit Packets(byte)

Indicates the number of bytes contained in permitted packets on the RX channel.

Bytes of RX Deny Packets(byte)

Indicates the number of bytes contained in rejected packets on the RX channel.

Bytes of RX Packets Matched Default Behavior(byte)

Indicates the number of bytes contained in the packets that do not match the ACL rules for packet filtering. If MB is set to PERMIT, this parameter measures the number of bytes contained in the accessed packets. If MB is set to DENY, this parameter measures the number of bytes contained in the discarded packets. This parameter is valid only when CATALOG is set to PORT.
