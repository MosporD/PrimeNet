Add Peer Reference Clock (ADD PEERCLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a peer reference clock link. If the NE can properly obtain synchronization signals from the peer reference clock, this link becomes available.

Note

After a peer reference clock link is added, the peer reference clock is only an optional reference clock source for the system.
