Remove Board (RMV BRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a board.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Removing a board causes the reset of the board.

  • When a board is removed, all services carried by the board are interrupted.

  • Before removing a BBP, ensure that no RRUCHAIN is configured on the BBP.

  • If a sub-board is configured on the board, removing the board causes the removal of the sub-board.

  • Board to be removed must comply with the base station hardware plan. Otherwise, the ongoing services of the base station or the remote maintenance channel may be interrupted.

  • Before removing a board, remove the clock reference source from the board.

  • If a TDS main control board has been converted and the base station software is upgraded, the board cannot be rolled back to the TD-SCDMA mode after being removed.

  • Ensure that the board is available before removing a main control board working in TDS evolution mode.

  • [NodeB]If a NodeB uses a WMPT as the main control board, a UTRPc may be used for data transmission. In this case, the NodeB will be reset if the UTRPc is removed after starting working.

CN Cabinet No.

Meaning: Indicates the number of the cabinet where the board is located.

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the board is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the board is located.

GUI Value Range: 0~7,16~19

Unit: None

Actual Value Range: 0~7,16~19

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SN must meet the following conditions: 1. When SRN is set to 0 or 1, SN must be set to a value within the range of 0 to 7, 16, 18, or 19. In addition, the value of SN ranges from 0 to 6 in the BLK BRD or UBL BRD command, the value of SN ranges from 6 to 7 in the MOD PEERMODE command; 2. When SRN is set to 4 or 5 and TYPE in the CABINET MO is set to BTS3900AL, the value of SN ranges from 0 to 8; When SRN is set to 4 or 5 and TYPE in the CABINET MO is not set to BTS3900AL, the value of SN ranges from 0 to 5; 3. When the value of SRN is set to 60, SN ranges from 0 to 5; 4. When the value of SRN ranges from 61 to 254, SN ranges from 0 to 3; 5. When TYPE in the SUBRACK MO is set to BBU5900A, SN can be set to 0, 2, 4, 6, or 16 to 19.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove a board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, run the following command:
RMV BRD: CN=0, SRN=0, SN=1;
