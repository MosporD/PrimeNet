Ping6 (PING6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to test the quality of the IPv6 network cable and determine whether faults exist in the network connections.

Note

  • [Co-MPT,eNodeB,gNodeB]This command cannot be used with the CFMTRACE, CFMPING, PING, TRACERT, TRACERT6, and UDPECHO commands.

  • [Co-MPT,eNodeB,gNodeB]If CONTPING is set to ENABLE, press Ctrl+Q or run the STP PATHCHK command to stop the execution of the PING6 command.

  • [Co-MPT,eNodeB,gNodeB]In this command, if Destination Ipv6 Address Type is set to IPADDR6_TYPE_LINK_LOCAL(Link Local Address), the Interface Index is valid and the interface type corresponding to the Interface Index must be Ethernet port or Ethernet trunk.

  • [Co-MPT,eNodeB,gNodeB]The ping packet length for a successful ping depends on the maximum transmit unit size, fragment reassembly capability, maximum receive unit size, and difference in ICMP6 outer protocol encapsulation. The ping packet length for a successful ping varies with hardware and scenario.

  • [Co-MPT,eNodeB,gNodeB]In the same routing domain, if the destination IPv6 address is set to the local IPv6 address when the PING6 command is executed, the source IPv6 route meeting the following condition cannot be configured: The source IPv6 address of this source IPv6 route is the same as the source IPv6 address or destination IPv6 address in the PING6 command.

Example

To perform the PING6 test with the parameters as follows: Destination Ipv6 Address Type: Globally Scoped Unicast Address, Source IPv6 Address: 2001:DB8::1, Destination IPv6 Address: 2001:DB8::2, Continuous Ping: DISABLE, run the following command:
PING6: DSTIPTYPE=IPADDR6_TYPE_GLOBAL_UNICAST, SRCIP="2001:DB8::1", DSTIP="2001:DB8::2", CONTPING=DISABLE;
