Add Source IPv6 Route (ADD SRCIPROUTE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a source IPv6 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]System specifications: A base station supports a maximum of 32 source IPv6 routes.

  • [Co-MPT,eNodeB,gNodeB]A source-based IPv6 route has a higher priority than all destination-based routes (including direct routes and static routes configured by users). That is, source-based IPv6 routes are preferentially matched when packets need to be forwarded. If no match is found, source-based IPv6 routes are matched. If still no match is found, packets are forwarded based on a destination-based route.

  • [Co-MPT,eNodeB,gNodeB]In the same routing domain, if destination IPv6 address is set to a local IPv6 address when the PING6 command is executed, the source IPv6 address of the source IPv6 route must be different from the value of source IPv6 address or destination IPv6 address in the PING6 command.

  • [Co-MPT,eNodeB,gNodeB]A base station supports only source IPv6 routes that are supported by all boards configured in this base station.

Example

To add a Source IPv6 Route with the parameters as follows: IPv6 Source Route Index: 0, Source IPv6 Address: 2001:DB8::1, Route Type: NEXTHOP, Next-Hop IPv6 Address: 2001:DB8::2, run the following command:
ADD SRCIPROUTE6: SRCRTIDX=0, SRCIP="2001:DB8::1", RTTYPE=NEXTHOP, NEXTHOP="2001:DB8::2";
