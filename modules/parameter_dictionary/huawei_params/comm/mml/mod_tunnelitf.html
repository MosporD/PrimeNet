Modify Tunnel Interface (MOD TUNNELITF)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a tunnel interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]Modifying a tunnel interface may interrupt services or OM channel carried on the interface. Therefore, exercise caution when running this command.

  • [Co-MPT,eNodeB,gNodeB]If the IPsec policy group has been bound to a tunnel interface and the tunnel interface is modified, the system will unbind the IPsec policy group from the tunnel interface and then rebind the IPsec policy group to the tunnel interface. If an outbound interface route exists on the interface, the route is deleted and then added again.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the port ID of a tunnel interface. The value of PORTID in the TUNNELITF MOs configured by users ranges from 0 to 127. The value of PORTID in the TUNNELITF MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~127,10000~19999

Unit: None

Actual Value Range: 0~127,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In a TUNNELITF MO, if PORTID is within the range from 0 to 127, CTRLMODE must be set to MANUAL_MODE. In a TUNNELITF MO, if PORTID is within the range from 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes to TUNNELITF objects are made. When this parameter is set to YES, forcible changes to TUNNELITF objects are made. When this parameter is set to NO, forcible changes to the TUNNELITF objects that affect associated objects are not allowed. When forcible changes are not allowed, only the local IPv6 address is checked. The associated objects include CA, CERTREQ, and IKEPEER. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when using this parameter:

1.If an NE is configured with an SRCIPROUTE6 MO, the system will not check whether forcible changes to IPSECBINDITF objects affect associated objects.

Example

To modify the configurations of a tunnel interface with the parameters as follows: Port ID: 0, Mode: IPsec IPv6, Local IPv6 Address: 2001:DB8::1, Remote IPv6 Address: 2001:DB8::2, Support Forcible Execution: No, run the following command:
MOD TUNNELITF: PORTID=0, MODE=IPSEC_IPV6, LOCALIP6="2001:DB8::1", REMOTEIP6="2001:DB8::2", FORCEEXECUTE=NO;
