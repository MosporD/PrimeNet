Add IP Path Route (ADD IPPATHRT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to add an IP path route.

Note

  • [Co-MPT,eGBTS,eNodeB]IP path routes and active/standby routes cannot co-exist.

  • [Co-MPT,eGBTS,eNodeB]In IPSec networking, an IP path does not support path check if it is configured with IP path routes.

  • [Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

  • [Co-MPT,eGBTS,eNodeB]If an IPPATHRT object has the same destination IP address as an IPRT or IPROUTE4 object but has a different next-hop IP address, the priority of the route specified by the IPPATHRT object is higher than that specified by the IPRT or IPROUTE4 object.

  • [Co-MPT,eGBTS,eNodeB]System specifications: If the LMPT/UMPT/UMDU is the main control board, a maximum of 64 IP path routes can be configured.

  • [Co-MPT,eGBTS,eNodeB]Board specifications: A maximum of 64 IP path routes can be configured on an LMPT/UMPT/UMDU.

  • [Co-MPT,eGBTS,eNodeB]An IPPATHRT object cannot coexist with the SRCIPRT or SRCIPROUTE4 object. Before adding an IPPATHRT object, delete the SRCIPRT or SRCIPROUTE4 object.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L
SRCIP Source IP

Meaning: Indicates the source IP address of an IP path route. The source IP address must be the same as the configured device IP address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]SRCIP in an IPPATHRT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, eGBTS, eNodeB]In an IPPATHRT MO, SRCIP must be different from DSTIP.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L
DSTIP Destination IP

Meaning: Indicates the destination IP address of an IP path route.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]DSTIP in an IPPATHRT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

TRANRSCTYPE Transport Resource Type

Meaning: Indicates the type of transport resource carried on an IP path route. The value HQ indicates high-quality transport resources, and the value LQ indicates low-quality transport resources.

GUI Value Range: HQ(High Quality), LQ(Low Quality)

Unit: None

Actual Value Range: HQ, LQ

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L
NEXTHOPIP Next Hop IP

Meaning: Indicates the next-hop IP address of an IP path route. The next-hop IP address and the configured device IP address must be on the same network segment, but cannot be the same.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L

Example

To add an IP path route with the parameters as follows: VRF Index: 0, Source IP: 10.10.10.10, Destination IP: 172.16.21.89, Transport Resource Type: HQ, Next Hop IP: 10.10.10.1, run the following command: 
ADD IPPATHRT: VRFIDX=0, SRCIP="10.10.10.10", DSTIP="172.16.21.89", TRANRSCTYPE=HQ, NEXTHOPIP="10.10.10.1";
