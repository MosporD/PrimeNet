Remove IPv4 Address (RMV IPADDR4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an IPv4 address from a port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is used to remove only the IPv4 address that is added by running the ADD IPADDR4 command. The added IPv4 addresses can be listed by running the LST IPADDR4 command.

  • This operation may interrupt the services or OM channels carried on this IPv4 address. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • [NodeB,eNodeB,gNodeB]You cannot remove an IPv4 address used by a link such as an IP path, remote maintenance channel, and BFD session.

Parameters

ID Name Description
ITFID Interface ID

Meaning: Indicates the ID of an interface.

GUI Value Range: 0~1499

Unit: None

Actual Value Range: 0~1499

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
IP IP Address

Meaning: Indicates the IP address configured on the port.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the IPADDR4 MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical operation result of IP and MASK in an IPADDR4 MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an IPv4 address with the parameters as follows: Interface ID: 100, IP Address: 192.168.2.24, run the following command: 
RMV IPADDR4: ITFID=100, IP="192.168.2.24";
