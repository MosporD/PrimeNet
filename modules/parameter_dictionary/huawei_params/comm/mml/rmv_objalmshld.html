Remove Alarm Shield by Object Type (RMV OBJALMSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an alarm shielding condition by object that has been configured.

Note

To query the alarm shielding condition by object that has been configured, run the LST OBJALMSHLD command.

Parameters

ID Name Description
OBJTP Object Type

Meaning: Indicates the type of an object according to which alarms are shielded.

GUI Value Range: BRD(Board), E1T1PT(E1T1 Port), ETHPT(ETH Port)

Unit: None

Actual Value Range: BRD, E1T1PT, ETHPT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CN Cabinet No.

Meaning: Indicates the number of the cabinet shielded by physical location.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SRN Subrack No.

Meaning: Indicates the number of the subrack shielded by physical location.

GUI Value Range: 0~254

Unit: None

Actual Value Range: 0~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SN Slot No.

Meaning: Indicates the number of the slot shielded by physical location.

[NodeB]Bound of Slot No. is [0~8;16;18] in UMTS.

GUI Value Range: 0~19

Unit: None

Actual Value Range: 0~19

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PN Port No.

Meaning: Indicates the port number of the object.

GUI Value Range: 0~35

Unit: None

Actual Value Range: 0~35

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • This parameter does not take effect if OBJTP is set to BRD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an alarm shielding condition by object with the parameters as follows: Object Type: BRD, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command:
RMV OBJALMSHLD: OBJTP=BRD, CN=0, SRN=0, SN=6;
