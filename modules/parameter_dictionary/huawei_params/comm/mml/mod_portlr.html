Modify Port Rate Limit (MOD PORTLR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration for the data rate of a physical port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The sum of the committed burst size (CBS) and the excess burst size (EBS) must be greater than the uplink committed information rate (CIR). It is recommended that this sum be twice the uplink CIR.

  • The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s the uplink committed information rate and 1 Gbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • The UTRP can be configured with a maximum of 300 Mbit/s the uplink committed information rate and 300 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • The UMPTe/UMPTga can be configured with a maximum of 10 Gbit/s the uplink committed information rate and 10 Gbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • The UMPTg can be configured with a maximum of 25 Gbit/s the uplink committed information rate and 25 Gbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Currently, the base station supports a maximum of four modes, and therefore tunnel-based IP transmission resource groups are used only for rate limitation on uplink data streams. It is recommended that each base station with an uplink tunnel be configured with a tunnel-based IP transmission resource group whose rate configurations are the same as line rates.

  • [Co-MPT,eNodeB,gNodeB]The LMPT board can be configured with a maximum of 360 Mbit/s the uplink committed information rate, 400 Mbit/s committed burst size, 450 Mbit/s excessive burst size and 540 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,eGBTS]The GTMUb/GTMUc can be configured with a maximum of 100 Mbit/s the uplink committed information rate and 100 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [NodeB]The WMPT board can be configured with a maximum of 100 Mbit/s the uplink committed information rate, 600 Mbit/s committed burst size, 600 Mbit/s excessive burst size and 100 Mbit/s the downlink committed information rate. The value is set to the maximum value supported by the board when it bigger than the maximum one.

CIR UL Committed Information Rate

Meaning: Indicates the UL committed information rate after rate limitation is configured at a port. The precision of the UL committed information rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s, the precision supported by the other board is 32 kbit/s. If the configured UL committed information rate is not a multiple of the precision, the UL committed information rate is rounded up. For the GTMUb, the value of CIR ranges from 64 to 100000. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.

GUI Value Range: 32~100000000

Unit: kbit/s

Actual Value Range: 32~100000000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the PORTLR MO, CIR can be set to any value within the range of 32 to 31744 if PT is set to MPGRP.
  • In the PORTLR MO, CIR can be set to any value within the range of 32 to 100000000 if PT is set to ETH or ETHTRK or TUNNEL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter value is greater than the available transport bandwidth, the transport network may be congested, affecting the QoS.

If this parameter value is smaller than the available transport bandwidth, the transport network may incur a waste of bandwidth, affecting the number of admitted services and throughput.

Applicable Mode: G, U, L, N
CBS Committed Burst Size

Meaning: Indicates the Committed Burst Size (CBS) after rate limitation is configured at a port. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s. For the GTMUb, the value of CBS ranges from 63 kbit to 256 kbit. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.

GUI Value Range: 32~100000000

Unit: kbit

Actual Value Range: 32~100000000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the PORTLR MO, CBS can be set to any value within the range of 32 to 155000 if PT is set to MPGRP.
  • In the PORTLR MO, CBS can be set to any value within the range of 32 to 100000000 if PT is set to ETH or ETHTRK or TUNNEL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A smaller parameter value indicates a lower tolerance for data burst, which results in packet loss.

A larger parameter value indicates higher consumption of system resources, which results in a waste of resources.

Applicable Mode: G, U, L, N

DLCIR DL Committed Information Rate

Meaning: Indicates the DL committed information rate after rate limitation is configured at a port. The parameter does not take effect in GSM and NR. For UMTS, if the downlink flow control switch is set to DYNAMIC_BW_SHAPING or STATIC_BW_SHAPING, this parameter is valid. If the downlink flow control switch is set to BW_SHAPING_ONOFF_TOGGLE, this parameter is valid when traffic congestion is detected. In other cases, this parameter is invalid. For LTE, this parameter computes the value of Physical Port Down Link Admission. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga or UMDU is 64 kbit/s.

GUI Value Range: 32~100000000

Unit: kbit/s

Actual Value Range: 32~100000000

MML Default Value: None

Recommended Value: The recommended value for this parameter is 31744 if PT is set to MPGRP.

The recommended value is 1000000 if PT is set to ETH or ETHTRK.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the PORTLR MO, DLCIR can be set to any value within the range of 32 to 31744 if PT is set to MPGRP.
  • In the PORTLR MO, DLCIR can be set to any value within the range of 32 to 100000000 if PT is set to ETH or ETHTRK or TUNNEL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify the port rate Limit with the parameters as follows: Port Rate Limit ID: 0, Port Type: Ethernet Port, Port ID: 0, UL Committed Information Rate: 32, Committed Burst Size: 64, Excess Burst Size: 3, DL Committed Information Rate: 100000, run the following command:
MOD PORTLR: PORTLRID=0, PT=ETH, PORTID=0, CIR=32, CBS=64, EBS=3, DLCIR=100000;
