Modify Peer Reference Clock (MOD PEERCLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a specified peer reference clock link.

Note

None.

Parameters

ID Name Description
PN Peer Clock No.

Meaning: Indicates the number of the peer reference clock link.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
PRI Priority

Meaning: Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.

GUI Value Range: 1~4

Unit: None

Actual Value Range: 1~4

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify a peer reference clock link with parameters as follows: Link No: 0, Priority: 2, run the following command:
MOD PEERCLK: PN=0, PRI=2;
