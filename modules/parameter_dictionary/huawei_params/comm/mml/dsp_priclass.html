Display Clock Class (DSP PRICLASS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query priority clock classes.

Note

None.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the IP clock link.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the IPCLKLNK MO, when the value of DEVTYPE is set to OC_SLAVE, the value of LN must be 0 or 1. When the value of DEVTYPE is set to OC_MASTER, the value of LN must be 2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To display clock classes, run the following command:
DSP PRICLASS:;
The result is shown as follows:

Output Description

Field Description

Link No.

Indicates the number of the IP clock link.

Priority Clock Class0

Indicates the priority configured by the user for the BMC (Best Master Clock) algorithm. The information about the priority can be collected from the upper-level clock equipment. This parameter specifies the clock quality that is anticipated by the user. The upper-level clock equipment with the matching clock quality is selected as the target server. Class0 has the highest priority, and Class0 to Class3 indicate priorities in descending order.

Priority Clock Class1

Indicates the priority configured by the user for the BMC (Best Master Clock) algorithm. The information about the priority can be collected from the upper-level clock equipment. This parameter specifies the clock quality that is anticipated by the user. The upper-level clock equipment with the matching clock quality is selected as the target server. Class0 has the highest priority, and Class0 to Class3 indicate priorities in descending order.

Priority Clock Class2

Indicates the priority configured by the user for the BMC (Best Master Clock) algorithm. The information about the priority can be collected from the upper-level clock equipment. This parameter specifies the clock quality that is anticipated by the user. The upper-level clock equipment with the matching clock quality is selected as the target server. Class0 has the highest priority, and Class0 to Class3 indicate priorities in descending order.

Priority Clock Class3

Indicates the priority configured by the user for the BMC (Best Master Clock) algorithm. The information about the priority can be collected from the upper-level clock equipment. This parameter specifies the clock quality that is anticipated by the user. The upper-level clock equipment with the matching clock quality is selected as the target server. Class0 has the highest priority, and Class0 to Class3 indicate priorities in descending order.

Current Priority Clock Class

Indicates the current priority class of the IP clock link.

Priority Clock Class Identify Flag

Indicates whether the BMC (Best Master Clock) algorithm is enabled or not. ON indicates that the BMC algorithm is enabled, and OFF indicates that the BMC algorithm is disabled.
