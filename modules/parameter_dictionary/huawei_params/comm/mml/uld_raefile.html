Upload RAE File (ULD RAEFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to upload the weighting factor file and antenna pattern file to the Remote eAntenna Extension (RAE).

Note

Before running this command, ensure that the following conditions are met:

The FTP server has been configured.

The FTP server is running properly. The IP address of the FTP server is on the same network segment as the IP address of the base station, and the FTP server is properly connected to the base station.

There is no firewall between the FTP server and the base station.

The user of the FTP server has the permission to read and write files in specified paths.

There is no file with the same name as the destination file on the FTP server. If there is such a file on the server, the file would be replaced after the upload.
