Sync End Point Group (SYN EPGROUP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to synchronize end point MOs with corresponding generated link MOs (such as SCTPLNK and CPBEARER) to ensure that the end point MOs are consistent with corresponding generated link MOs.

Note

If the end point objects are inconsistent with the associated link objects that have been created, this command will cause the system to create link objects that are associated with the end point objects and remove the link objects that have Control Mode set to AUTO_MODE(Auto Mode) and do not match the end point objects.

Parameters

None.

Example

To synchronize end point MOs, run the following command:
SYN EPGROUP:;
