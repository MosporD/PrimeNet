List MEB (LST MEB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of a monitoring extension box (MEB).

Note

For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of an MEB.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of an MEB.

GUI Value Range: 40~59

Unit: None

Actual Value Range: 40~59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the slot number of an MEB.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the configuration of an MEB, run the following command:
LST MEB: CN=0, SRN=40;
The result is shown as follows:
+++    0        2016-08-13 17:14:52
O&M    #1050
%%LST MEB: CN=0, SRN=40;%%

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of an MEB.

Subrack No.

Indicates the subrack number of an MEB.

Slot No.

Indicates the slot number of an MEB.

Manager Cabinet No.

Indicates the cabinet number of the manager of an MEB.

Manager Subrack No.

Indicates the subrack number of the manager of an MEB.

Manager Port No.

Indicates the number of the MEB serial port connecting to the manager.
