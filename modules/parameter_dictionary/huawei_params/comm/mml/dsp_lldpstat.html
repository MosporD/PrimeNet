Display LLDP Statistic Info (DSP LLDPSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query statistics on an LLDP port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the LLDPLOCAL is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the LLDP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To query the LLDP statistic information with the parameters as follows: Slot No.: 7, Subboard Type: Base Board, Port No.: 1, run the following command:
DSP LLDPSTAT: SN=7, SBT=BASE_BOARD, PN=1;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the LLDPLOCAL is located.

Subrack No.

Indicates the subrack number of the board where the LLDPLOCAL is located.

Slot No.

Indicates the slot number of the board where the LLDPLOCAL is located.

Subboard Type

Indicates the type of sub-board on the board where the LLDPLOCAL is located.

Port No.

Indicates the number of the Ethernet port where the LLDPLOCAL is located.

The Number Of LLDP Frames Transmitted(frame)

Indicates the total number of sent LLDP frames.

The Number Of LLDP Frames Received(frame)

Indicates the total number of received LLDP frames.

The Number Of Rx LLDP Frames Discarded(frame)

Indicates the total number of discarded LLDP frames.

The Number Of Rx LLDP Error Frames(frame)

Indicates the total number of received erroneous LLDP frames.

The Number Of Rx LLDP TLVs Discarded

Indicates the total number of discarded LLDP type-length-values (TLVs).

The Number Of LLDP TLVs Unrecognized

Indicates the total number of unrecognizable LLDP type-length-values (TLVs).

The Number Of LLDP Neighbor Information Aged Out

Indicates the total number of aged LLDP neighbors.
