Modify Cabinet (MOD CABINET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify attributes, including the cabinet description of a cabinet.

Note

  • Only the type of a virtual cabinet can be changed to other types.

  • If the virtual cabinet contains only a BBU subrack, and the BBU subrack is supported by the target cabinet type, the cabinet type can be changed. In other cases, the cabinet type cannot be changed.

  • If the virtual cabinet contains no subrack, the cabinet type can be changed to any type matching the type of an actual cabinet.

Parameters

Meaning: Indicates the cabinet number.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

DESC Cabinet Description

Meaning: Indicates a brief description of the cabinet, which can be the function, location, and some other information of the cabinet. If the value of this parameter for the cabinet housing the root BBU includes tlmmpsw, both the MLPPP group fault detection period and PPP link fault detection period are automatically set to 1s.

GUI Value Range: 0~79 characters

Unit: None

Actual Value Range: 0~79 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

GUI Value Range: APM30(APM30), APM100(APM100), APM200(APM200), PS4890(PS4890), OMB(OMB), TMC(TMC), BBC(BBC), RFC(RFC), BTS3900(BTS3900), BTS3900L(BTS3900L), BTS3900D(BTS3900D), BTS3012_SRAN(BTS3012_SRAN), BTS3012AE_SRAN(BTS3012AE_SRAN), BTS3012II_SRAN(BTS3012II_SRAN), TP48300A(TP48300A), VIRTUAL(Virtual Cabinet), BTS3900AL(BTS3900AL), TP48600A(TP48600A), ILC29(ILC29), APM300(APM300), MRE1000(MRE1000), BTS5900(BTS5900), BTS5900L(BTS5900L), APM5930(APM5930), IBC10(IBC10), OBU5900A(OBU5900A), IFS5906(IFS5906), RFC5906(RFC5906), OPM(OPM)

Unit: None

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in a SUBRACK MO can be set to BBU3900, BBU3900-1U, BBU3910, BBU5900, DCU3911, or DCU5900 only when TYPE in the associated CABINET MO is set to any of the following values: APM30, APM100, APM200, TMC, OMB, BTS3900, BTS3900L, BTS3900AL, BTS3900D, PS4890, VIRTUAL, BTS3012_SRAN, BTS3012AE_SRAN, BTS3012II_SRAN, TP48600A, APM300, MRE1000, BTS5900, BTS5900L, APM5930 and IBC10.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE in the SUBRACK MO can be set to RFU only when TYPE in the CABINET MO is set to one of the following values: RFC, BTS3900, BTS3900L, VIRTUAL, BTS3012_SRAN, BTS3012AE_SRAN, BTS3012II_SRAN, BTS3900AL, BTS5900 and BTS5900L.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to OBU5900A, TYPE in the SUBRACK MO must be set to BBU5900A.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the SUBRACK MO is set to BBU5900A, TYPE in the CABINET MO must be set to OBU5900A.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to OBU5900A, only one SUBRACK MO instance can be configured.
  • [Co-MPT, NodeB, eNodeB, gNodeB]TYPE in the SUBRACK MO can be set to BBU5900 only when TYPE in the CABINET MO is set to one of the following values: APM30, APM100, APM200, TMC, OMB, BTS3900, BTS3900L, BTS3900AL, BTS3900D, PS4890, VIRTUAL, BTS3012_SRAN, BTS3012AE_SRAN, BTS3012II_SRAN, TP48600A, APM300, MRE1000, BTS5900, BTS5900L, APM5930 and IBC10.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRN in a SUBRACK MO must be set to 0 when TYPE in the SUBRACK MO is set to BBU3900, BBU3910, BBU5900, DCU3911, or DCU5900, and TYPE in the associated CABINET MO is set to OMB or BTS3900D.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE must be set to BBU3900, BBU3910, or BBU5900 when TYPE in the CABINET MO is set to IBC10 and SRN in the SUBRACK MO is set to 0 or 1.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the SUBRACK MO is set to BBU5900A and TYPE in the CABINET MO is set to OBU5900A, SRN in the SUBRACK MO must be set to 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRN in a TCU MO can be set to 14 only when TYPE in the CABINET MO where the TCU MO is located is set to VIRTUAL or APM300.
  • [NodeB]SRN in the SUBRACK MO must be set to 0 when TYPE is set to BBU3900-1U, and TYPE in the CABINET MO is set to one of the following values: OMB, BTS3900D.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]PHYSRN can be set to a valid value only when TYPE in the SUBRACK MO is set to BBU3900, BBU3910, or BBU5900 and TYPE in the CABINET MO is set to IBC10.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the CABINET MO to which the TCU MO belongs is APM300, the manager unit for the TCU MO must be the CCUMO in which SRN is 15.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the CABINET MO to which the PMU MO belongs is APM300, the manager unit for the PMU MO must be the CCUMO in which SRN is 15.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the CABINET MO to which the EMU MO belongs is APM300, the manager unit for the EMU MO must be the CCUMO in which SRN is 15.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO is set to RFC5906 or IFS5906, the value of CN must range from 0 to 15.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

LOCATIONNAME Location Name

Meaning: Indicates the location information of a cabinet. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Example

To modify the cabinet with the parameters as follows: Cabinet No.: 0, Cabinet Description: "APM 30 Cabinet", Cabinet Type: "APM30", run the following command:
MOD CABINET: CN=0, DESC="APM 30 Cabinet", TYPE=APM30;
