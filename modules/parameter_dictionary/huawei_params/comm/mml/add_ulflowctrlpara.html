Add Uplink Flow Control Para (ADD ULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a configuration of the uplink flow control algorithm.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [Co-MPT,NodeB]System specifications: If the main control board is a WMPT/UMPT, a maximum of 144 uplink flow control parameters can be configured and take effect. If the main control board is a UMDU, a maximum of 43 uplink flow control parameters can be configured and take effect.

  • [Co-MPT,NodeB]Board specifications: On a WMPT/UMDU/UMPTa/b, a maximum of 43 uplink flow control parameters can be configured and take effect. On a UMPTe/UMPTg/UMPTga, a maximum of 45 uplink flow control parameters can be configured and take effect. On a UTRPc, a maximum of 13 uplink flow control parameters can be configured and take effect. On a UTRP (subboard type: UEOC), a maximum of 8 uplink flow control parameters can be configured and take effect. On a UTRP (subboard type: UQEC), a maximum of 10 uplink flow control parameters can be configured and take effect. On a UTRP (subboard type: UIEC), a maximum of 20 uplink flow control parameters can be configured and take effect. On a UTRP (subboard type: UAEC), a maximum of 20 uplink flow control parameters can be configured and take effect. On a UTRP (subboard type: UUAS), only one uplink flow control parameter can be configured and take effect.

  • [Co-MPT,NodeB]When the Port Type parameter is set to Loop Interface for the user-plane bearer, settings of parameters in the ULFLOWCTRLPARA MO on the actual output port of the loopback interface take effect.

BWPRTSWITCH BW Adjust Protection Switch

Meaning: Indicates whether to adjust the available UL bandwidth. When this parameter is set to ON, the BS stops adjusting the available UL bandwidth of the physical port if the bit error rate (BER) on the transmission line exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(On)

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
TNLCONGCTRLSWITCH Congestion Ctrl Switch

Meaning: Indicates whether to perform congestion control. When this switch is turned on, the BS lowers the TX rate if the BS detects that links experience transmission delay or packet loss.

TNLCONGCTRLENHSW Congestion Control Enhancement Switch

Meaning: Indicates the switch for the enhanced congestion control. When the switch is set to ON, the enhanced congestion control prevents uplink available bandwidth from sharply decreasing and uplink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

This feature requires the uplink FPDT GPM detection result. Before using this feature, run the ADD GPM or MOD GPM command to enable the uplink FPDT GPM detection function for the NodeB.

This switch can be configured only when the flow control function is enabled. This configuration takes effect only in IP transmission, but cannot take effect in ATM transmission even though the configuration succeeds.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the cell supports the enhanced HSUPA Iub traffic control when the Iub interface is congested.

This feature improves the uplink throughput of the cell when packet loss occurs due to bit errors in the transport network.

When this parameter is set to OFF, the network is not affected.

Applicable Mode: G, U
ULIUBMINBW Min UL Avail Bandwidth of Logical Port

Meaning: Indicates the minimum UL bandwidth of logic port.

GUI Value Range: 0~1000000

Unit: kbit/s

Actual Value Range: 0~1000000

MML Default Value: 600

Recommended Value: 600

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the transport network provides small available bandwidth over the physical port, congestion on the transport network causes the bandwidth to fail to decrease and therefore packets are discarded and the bandwidth is not effectively used if the parameter is set to a large value. When the transport network provides large available bandwidth over the physical port, incorrect bandwidth adjustment decreases system capacity if packets are discarded due to error codes or other exceptions occur during the transmission.

Applicable Mode: G, U

Example

To add a configuration of the uplink flow control algorithm with the parameters as follows: Slot No.: 0, Subboard Type: E1_COVERBOARD, Bear Type: ATM, Port Type: IMA, BW Adjust Protection Switch: ON, Congestion Ctrl Switch: ON, The minimum UL available bandwidth of logic port.: 600, run the following command:
ADD ULFLOWCTRLPARA: SN=0, SBT=E1_COVERBOARD, BEAR=ATM, PT=IMA, BWPRTSWITCH=ON, TNLCONGCTRLSWITCH=ON, ULIUBMINBW=600;
