Display ND Blacklist (DSP NDSPOOFING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the blacklist in an ND table.

Note

  • After the system learns the ND table entries for 1 min, ND spoofing is performed on the system.

  • This command lists a maximum of 1024 IP addresses that have more than one MAC addresses for each board. For each of the IP addresses, this command records the top 10 MAC addresses from which the IP address receives the most attacks.

  • The ND blacklist records the IP address and MAC address deemed performing ND spoofing attacks to NEs. In addition, the security log of the base station records historical information about ND spoofing. There is a lot of ND spoofing attack sources. Therefore, to ensure information effectiveness, the security log of the base station records only the following information: IP address and MAC address that perform the most ND spoofing attacks in each detection period, date and time of the first attack, and number that the ND spoofing-related alarm is reported.

DSP NDSPOOFING: SN=7;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the slot number of a board.

VRF Index

Indicates the index of a VRF instance.

IP Address

Indicates the IP address in an ND table.

Mac Address Number

Indicates the number of MAC addresses in the black list of an ND table.

Mac Address

Indicates the MAC address list in the black list of an ND table.
