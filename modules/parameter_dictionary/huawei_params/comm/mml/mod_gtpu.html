Modify GTP-U Configuration (MOD GTPU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify GTP-U global parameters.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]A GTP-U echo request frame is a type of user data packet. When VLAN mapping is performed based on the VLANCLASS object, GTP-U echo request frames on an IP path with Path Type set to FIXED(Fixed QoS) use the DSCP of this IP path, and VLAN tags are attached to these frames based on this DSCP. GTP-U echo request frames on IP paths with Path Type set to ANY(Any QoS) and those on user-plane paths use the DSCP configured for GTP-U, and VLAN tags are attached to these frames based on this DSCP. If VLAN planning is required, you need to configure the VLANCLASS MO with Traffic Type set to USERDATA(User Data) and User Data Service Priority set to the same value as the GTP-U DSCP. In addition, if an IP path with Path Type set to FIXED(Fixed QoS) is configured, you also need to configure the VLANCLASS MO with Traffic Type set to USERDATA(User Data) and User Data Service Priority set to the DSCP of this IP path. Otherwise, faults may occur during GTP-U detection. If the bandwidth is insufficient and the DSCP value is small, GTP-U detection packets may be under flow control, causing link detection faults and affecting services.

  • [Co-MPT,eNodeB,gNodeB]It is recommended that the ECHO Frame Timeout parameter be set to a value greater than 30000 ms when over 256 user-plane links are configured. In this situation, if the GTP-U static detection is enabled and physical transmission links are disconnected, the CPU usage may increase.

  • [Co-MPT,eNodeB,gNodeB]When the software of the base station complies with 3GPP Release 8 or Release 9 and the ACL rule automatic setup and deletion function in the packet filtering object is enabled, it is recommended that the GTP-U static detection not be enabled. If the GTP-U static detection is enabled, the peer base station fails to obtain the IP address of the local base station and fails to create the corresponding ACLRULE MO due to the mechanism for one-way handovers over the X2 interface. In this case, the GTP-U packets sent by the source base station will be discarded by the peer base station, and therefore faults occur in the GTP-U detection.

  • [Co-MPT,eNodeB,gNodeB]GTP-U static detection in the link model has a global switch and a link-level switch. GTP-U static detection in the EP model has a global switch, link-level switch, and endpoint group switch. When STATICCHKMODE is set to UPPEERSTATICCHK(User-Plane Peer Static Check) in the GEPMODELPARA MO, the global switch and link-level switch take effect. When STATICCHKMODE is set to EPSTATICCHK(Endpoint Group Static Check) in the GEPMODELPARA MO, the endpoint group static detection switch takes effect.

  • [Co-MPT,eNodeB,gNodeB]After the downlink GTP-U packet sequence number check function is enabled, statistics on the downlink GTP-U service packets on the local end theoretically consumes about 5% of the UMPT/UMDU board forwarding performance.

  • [Co-MPT,gNodeB]In 5G SA networking, it is recommended that the Uplink GTP-U Sequence Number Padding Switch parameter be set to DISABLE.

Parameters

ID Name Description
TIMEOUTTH ECHO Frame Timeout

Meaning: Indicates the maximum wait time for an echo response. If no echo response is received during the period specified by this parameter, the timer has expired.

GUI Value Range: 5000~60000

Unit: ms

Actual Value Range: 5000~60000

MML Default Value: None

Recommended Value: 5000

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter makes ECHO frame timeout less vulnerable to network delay, but it leads to a longer time required to detect disconnection and therefore a higher probability of long-time packet loss. A smaller value of this parameter results in a higher probability of detecting network status, but it leads to higher sensitivity to packet loss and delay and therefore a higher probability of incorrect decisions.

Applicable Mode: L, N
TIMEOUTCNT ECHO Frame Timeout Count

Meaning: Indicates the maximum number of timeouts of the echo response waiting timer. If no echo response is received after the number specified by this parameter is reached, the GTP-U path in use fails.

GUI Value Range: 3~6

Unit: None

Actual Value Range: 3~6

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value of this parameter makes ECHO frame timeout less vulnerable to network delay, but it leads to a longer time required to detect disconnection and therefore a higher probability of long-time packet loss. A smaller value of this parameter results in a higher probability of detecting network status, but it leads to higher sensitivity to packet loss and delay and therefore a higher probability of incorrect decisions.

Applicable Mode: L, N
DSCP DSCP

Meaning: Indicates the differentiated services code point (DSCP) of a GTP-U control packet.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 46

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
STATICCHK Static Check Switch

Meaning: Indicates whether to enable static detection in compliance with GPRS Tunneling Protocol for User Plane (GTP-U). If this parameter is set to ENABLE, the GTP-U static check is enabled. If this parameter is set to DISABLE, the GTP-U static check is disabled.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
ULGTPUSNPADSW Uplink GTP-U Sequence Number Padding Switch

Meaning: Indicates the switch for padding the sequence numbers of uplink GTP-U service packets. If this parameter is set to ENABLE(Enable), consecutive sequence numbers in ascending order will be padded for uplink GTP-U service packets sent by the local end. If this parameter is set to DISABLE(Disable), the padding function will not take effect. This parameter is valid for the S1 interface only and its setting takes effect on the UMPT/UMDU board only.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is turned on, consecutive sequence numbers in ascending order will be padded for uplink GTP-U service packets sent by the local end and therefore each GTP-U packet will occupy an extra 4-byte transmission bandwidth.

Applicable Mode: L, N
DLGTPUSNCHKSW Downlink GTP-U Sequence Number Check Switch

Meaning: Indicates the switch for checking the sequence numbers of downlink GTP-U service packets. If this parameter is set to ENABLE(Enable), the local end performs statistics on the disorders and discontinuous sequence numbers on downlink GTP-U service packets. If this parameter is set to DISABLE(Disable), the check function will not take effect and the values of corresponding performance counters are invalid. This parameter is valid only for the UMPT/UMDU board. The values of corresponding performance counters reported for boards that do not support this parameter are invalid.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify the parameters of the GTP-U control message with the parameters as follows: ECHO Frame Timeout: 5000, ECHO Frame Timeout Count: 3, DSCP: 0, Static Check Switch: Enable, Uplink GTP-U Sequence Number Padding Switch: DISABLE, Downlink GTP-U Sequence Number Check Switch: DISABLE, run the following command:
MOD GTPU: TIMEOUTTH=5000, TIMEOUTCNT=3, DSCP=0, STATICCHK=ENABLE, ULGTPUSNPADSW=DISABLE, DLGTPUSNCHKSW=DISABLE;
