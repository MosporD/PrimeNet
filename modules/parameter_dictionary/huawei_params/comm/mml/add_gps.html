Add GPS (ADD GPS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a GPS clock link. After the GPS clock link is added, if the NE can properly obtain synchronization signals from the GPS clock, this link becomes available.

Note

  • If the USCU has been configured with a BITS clock link, no GPS clock link can be added to the USCU.

  • The BBU supports a maximum of two GPS clock links. The RRU supports a maximum of 18 GPS clock links. A CGPS supports a maximum of two GPS clock links.

  • After a GPS clock link has been added, the GPS clock is only an optional reference clock source for the system.

  • When configuring multiple GPS clock links, ensure that the GPS clock links are configured on a BBU, RRU, or CGPS.

  • For a pair of main control boards working in active/standby mode, if the reference clock source is configured on the standby board and the Clock Source Backup Mode parameter is set to BRDBKMODE, the reference clock source configurations take effect on the active board rather than on the standby board.

  • A GPS clock link configured on AAU is available only when the ALD current alarm threshold is set and the ALD power switch is turned on. For details about how to query the port status, see the DSP RETPORT commands. For details about how to modify the port status, see the DSP RETPORT commands.

  • [eNodeB,gNodeB]Before adding a GPS clock link to a TD-SCDMA board, ensure that the TD-SCDMA board has been converted successfully. If the GPS clock link is added before the TD-SCDMA board is converted, the GPS function may be abnormal.

  • [NodeB]The UMTS does not support the GPS clock link which is configured on the RRU.

CABLE_LEN Cable Length

Meaning: Indicates the length of the GPS feeder. The actual feeder length is the one between the GPS antenna and the board connected to the GPS antenna. Based on the feeder length, the feeder delay is calculated to ensure the clock accuracy. Ensure that the value of this parameter is the same as the actual length of the feeder. If the difference between the value of this parameter and the actual feeder length exceeds 20 m, the clock precision is affected. In certain conditions, normal services may be severely affected.

MODE GPS Work Mode

Meaning: Indicates the working mode of the satellite card. Satellite cards are classified into dual-mode satellite cards and single-mode satellite cards. A dual-mode satellite card supports two satellite searching modes. For example, the working mode of a BDS/GPS satellite card can be BDS prioritized or GPS prioritized. In BDS prioritized mode, the satellite card preferentially processes signals from BDS satellites. In GPS prioritized mode, the satellite card preferentially processes signals from GPS satellites. In addition, some satellite cards such as the UBOLX8M do not prioritize the BDS or GPS but process signals from both BDS satellites and GPS satellites. A single-mode satellite card supports only one satellite searching mode. For example, a GPS satellite card supports only the GPS mode.

POSCHECKSW Position Check Switch

Meaning: Indicates the position check switch of a satellite card. If this switch is turned on, the NE records the position where a satellite card is locked as the initial position and calculates the deviation between this initial position and the current position. If the deviation is excessively large, the NE regards the output signals of the satellite card unreliable and reports ALM-26120 GPS Clock Output Unavailable. The position check is applicable only when the NE position is fixed and the satellite card in the BBU supports this check.

Example

To add a GPS clock link with the parameters as follows: Link No.: 0, Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Cable Length: 1000, GPS Work Mode: GPS, Priority: 4, Position Check Switch: ON, run the following command:
ADD GPS: GN=0, CN=0, SRN=0, SN=7, CABLE_LEN=1000, MODE=GPS, PRI=4, POSCHECKSW=ON;
