Display Board Version Information (DSP BRDVER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the version information of a board.

Note

  • If no parameter of this command is specified, the version information of all boards will be displayed after this command is executed.

  • If no version number is available, the version will be displayed as NULL in the execution result.

Parameters

Meaning: Indicates the number of the cabinet where the board is located.

Unit: None

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the number of the subrack where the board is located.

Slot No.

Indicates the number of the slot where the board is located.

Type

Indicates the board type.

Application Type

Indicates the type of application software in the NE.

Software Version

Indicates the software version.

Hardware Version

Indicates the hardware version of the board.

BootROM Version

Indicates the BootROM version.

Operation Result

Indicates the result of the board information query operation.
