Upload Certificate File (ULD CERTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to upload a certificate file to the specified FTP server directory by using FTP. The current version only supports the upload of certificate request file and CRL(Certificate revocation list) file.

Note

None.

Example

To upload a file with the parameters as follows: FTP Server IP: 192.168.58.118, User Name: admin, Password: *****, Source File Name: basestationCert.req, Destination File Name: basestationCert.req;
To upload the file to the default directory, run the following command:
ULD CERTFILE: MODE=IPV4, IP="192.168.58.118", USR="admin", PWD="*****", SRCF="basestationCert.req", DSTF="basestationCert.req";
To upload the file to the FTP Server relative directory, run the following command:
ULD CERTFILE: MODE=IPV4, IP="192.168.58.118", USR="admin", PWD="*****", SRCF="basestationCert.req", DSTF="\files\brdlog\basestationCert.req";
To upload the file to the MAE FTP Server relative directory, run the following command:
ULD CERTFILE: MODE=IPV4, IP="192.168.58.118", USR="admin", PWD="*****", SRCF="basestationCert.req", DSTF="/export/home/sysm/ftproot/DBS3900/Other/3221282846/basestationCert.req";
