Add IMA Link (ADD IMALNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add an Inverse Multiplexing on ATM (IMA) link to an IMA group.

Note

  • [Co-MPT,NodeB]One IMA link can be added to only one IMA group.

  • [Co-MPT,NodeB]When an IMA group is under test, adding an IMA link to the IMA group prevents the newly-added IMA link from taking effect.

  • [Co-MPT,NodeB]If an IMA link is configured on a base-board or cover-board, the link and the IMA group to which it belongs must be located on the same base-board or cover-board; an IMA link configured on a back-board can only be added to an IMA group on a base-board.

  • [Co-MPT,NodeB]When LNCODE (line coding mode) of the E1/T1 port that carries the IMA link to be added is set to AMI, the IMA group to which the IMA link belongs must be scrambled.

  • [Co-MPT,NodeB]The total number of IMA links, UNI links, and fractional ATM links on a board must be smaller than or equal to the maximum number of E1/T1 ports that can be configured on the board.

  • [Co-MPT,NodeB]The timeslots at the E1/T1 ports used by IMA links, UNI links, FRAATM links, and timeslot cross connections must be mutually different.

  • [Co-MPT,NodeB]The E1/T1 port that carries an IMA link must not be associated with any port security, or SWITCH of the associated port security must set to ENABLE.

  • [Co-MPT,NodeB]The IMA group to which an IMA link is added must have been configured.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT is the main control board, a maximum of 64 IMA links can be configured. If the UMDU is the main control board, a maximum of 4 IMA links can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 4 IMA links can be configured on a WMPT/UMPTa/UMPTb/UMDU. A maximum of 8 IMA links can be configured on a UTRP (subboard type: UAEC).

  • [Co-MPT,NodeB]When local loopback is set for the underlying bearer link, the IMA group, IMA link, UNI link, and FRAATM link succeed in the self-negotiation based on related protocols.

SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where the IMA link is established.

-Others:

  • In the IMALNK MO, if SN is set to 6 or 7, this parameter can be set to BASE_BOARD or BACK_BOARD.
  • [Co-MPT, NodeB]In the IMALNK MO, if SBT is not set to BACK_BOARD, SBT must be the same as IMAGRPSBT.
  • [Co-MPT, NodeB]In the IMALNK MO, if SBT is set to BACK_BOARD, IMAGRPSBT must be set to BASE_BOARD.

-Others:

  • [Co-MPT, NodeB]In the IMALNK MO, if SN is within the range from 0 to 5 and SBT is set to E1_COVERBOARD, the value range of this parameter is from 0 to 7.
  • In the IMALNK MO, if SN is set to 6 or 7 and SBT is set to BASE_BOARD, the value range of this parameter is from 0 to 3.

IMAGRPSBT IMA Group Subboard Type

Meaning: Indicates the type of sub-board on the board where the IMA group containing an IMA link is established.

GUI Value Range: E1_COVERBOARD(E1 Cover Board), BASE_BOARD(Base Board)

Actual Value Range: E1_COVERBOARD, BASE_BOARD

If SBT is set to BACK_BOARD or BASE_BOARD, it is recommended that IMAGRPSBT be set to BASE_BOARD.

Parameter Relationship:

  • In the IMALNK MO, if SN is set to 6 or 7 and SBT is set to BACK_BOARD, this parameter must be set to BASE_BOARD.

Example

To add an IMA link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 0, IMA Group Subboard Type: BASE_BOARD, IMA Group No.: 0, run the following command: 
ADD IMALNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, IMALNKN=0, IMAGRPSBT=BASE_BOARD, IMAGRPN=0;
