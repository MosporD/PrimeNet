List Location (LST LOCATION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the parameters of the location.

Note

None.

Parameters

ID Name Description
LOCATIONNAME Location Name

Meaning: Indicates the location name of the base station.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To list the location information about a base station, run the following command:
LST LOCATION:;
The result is shown as follows:

Output Description

Field Description

Location Name

Indicates the location name of the base station.

Mode

Indicates the configuration mode of the base station longitude and altitude. This parameter can be set to AUTO or MANUAL. In automatic mode, the base station longitude and altitude are obtained from the GPS antenna or UE, and the configured longitude and latitude information is overwritten. In manual mode, the base station longitude and altitude are configured manually.

Positioning Method

Indicates the automatic location mode of the physical equipment of the base station.

PosStandard

Indicates the RAT corresponding to the longitude and latitude. The default value is the local RAT.

Geo-coordinate Data Format

Indicates the format of geographical coordinates.

Latitude With Degree Format(1e-6 degree)

Indicates the latitude of the base station. A negative value indicates the south and a positive value indicates the north.

Longitude With Degree Format(1e-6 degree)

Indicates the longitude of the base station. A negative value indicates the west and a positive value indicates the east.

Latitude With Second Format(s)

Indicates the latitude of the base station in the WGS-84 coordinate system.

Longitude With Second Format(s)

Indicates the longitude of the base station in the WGS-84 coordinate system.

Location Id

Indicates the location ID of the base station.

Altitude[m(ft)]

Indicates the altitude of the base station.

Range[m(ft)]

Indicates the range of the base location.

City

Indicates the city where the base station is located.

Region

Indicates the block where the base station is located.

address

Indicates the address of the base station.

Office

Indicates the site that the base station belongs to.

Contact

Indicates the addresses related to this base station or telephone numbers of the personnel related to this base station.

Telephone

Indicates the telephone number of the maintenance personnel of the base station.

User Label

Indicates the user-defined information of the location.

Precise[m(ft)]

Indicates the positioning accuracy of the base station's geographical location.

Location Type

Indicates the location type. The value BTSSITE indicates a traditional site deployed with both BBUs and RF modules. The value RFSITE indicates an RF site deployed only with RF modules (including their auxiliary devices). The value BBSITE indicates a baseband site deployed only with BBUs.
