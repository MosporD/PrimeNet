Modify Ethernet CI Port (MOD ETHCIPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configurations about an Ethernet CI port.

Note

If the transmission configuration mode is new and no ETHCIPORT object is configured, run the MOD ETHCIPORT command with Port ID set to a valid value.

PORTID Port ID

Meaning: Indicates the ID of an Ethernet CI port, which uniquely identifies the Ethernet CI port. When the system automatically creates an Ethernet CI port, the most significant bit to the least significant bit of this parameter value indicate the slot number, subrack number, slot number, and port number of the Ethernet CI port, respectively. When Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter is mandatory and must be unique in the system. If the ETHCIPORT MO is not configured, the default value 4294967295 of PORTID is displayed.

GUI Value Range: 0~9999,4294967295

MTU Maximum Transmission Unit

Meaning: Indicates the IPv4 maximum transmission unit on the Ethernet CI port. For the UMPT, the value of this parameter ranges from 46 to 1500. If this parameter is set to a value greater than the maximum allowed value, the maximum allowed value takes effect. A value greater than or equal to 776 is recommended, because broadcast packets, such as DHCP packets, may experience reception or transmission failures if the maximum transmission unit is smaller than 776.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the IPv4 Maximum Transmission Unit parameter in the INTERFACE MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To modify an Ethernet CI port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port No.: 0, Maximum Transmission Unit: 1400, ARP Proxy: DISABLE, run the following command: 
MOD ETHCIPORT: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0, MTU=1400, ARPPROXY=DISABLE;
