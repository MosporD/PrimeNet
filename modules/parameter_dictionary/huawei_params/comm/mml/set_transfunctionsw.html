Set Transmission Function Switch (SET TRANSFUNCTIONSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the transmission function switch.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • In the following cases, the local IP address is not controlled by the IP PM passive activation switch:

    1. If the base station already has an IP PM session, the local IP address referenced by the IP PM session or the local IP address referenced by an IP path bound to the IP PM session can respond to the IP PM activation requests sent by the peer end and the peer end can activate IP PM sessions.

    2. If an IP address is configured on the WMPT board, this IP address can respond to the IP PM passive activation requests sent by the peer end and the peer end can activate IP PM sessions.

  • If a local IP address is configured on the WMPT board, the local IP address is not controlled by the IP MUX demultiplexing switch and always supports demultiplexing of IPMUX frames.

  • When the value of IP PM Passive Activation Switch is changed from DISABLE to ENABLE, the switch setting takes effect immediately. When the value of this parameter is changed from ENABLE to DISABLE, the switch setting takes effect within three minutes.

  • When the value of IP MUX Demultiplexing Switch is changed from DISABLE to ENABLE, the switch setting takes effect immediately. When the value of this parameter is changed from ENABLE or DISABLE, the switch setting takes effect within three minutes.

Parameters

ID Name Description
IPPMPASSIVEACTIVATIONSW IP PM Passive Activation Switch

Meaning: Indicates whether to support IP PM passive activation. When this parameter is set to ENABLE, only user-plane IP addresses can respond to IP PM activation requests sent from the peer end and the peer end can activate IP PM sessions. When this parameter is set to DISABLE, none of IP addresses can respond to IP PM activation requests sent from the peer end and the peer end cannot activate IP PM sessions.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
IPMUXDEMULTIPLEXSW IP MUX Demultiplexing Switch

Meaning: Indicates whether to support IP MUX demultiplexing. When this parameter is set to ENABLE, only user-plane IP addresses support demultiplexing of IPMUX frames. When this parameter is set to DISABLE, none of IP addresses support demultiplexing of IPMUX frames. This parameter takes effect only for UMTS and GSM.

IPLOOPTSTRSPSW IP Loopback Detection Response Switch

Meaning: Indicates whether to support the IP loopback detection response function. If this parameter is set to ENABLE, only the IP addresses used by the IPPATH or EPGROUP MOs subscribed to by GSM and UMTS support responding to IP loopback detection UDP packets sent by the peer end. The destination UDP port number is 65040. If this parameter is set to DISABLE, none of the IP addresses support responding to IP loopback detection UDP packets sent from the peer end. This parameter takes effect only for UMTS and GSM.

ICMPPORTUNREACHABLESW ICMP Port Unreachable Send Switch

Meaning: Indicates whether to send ICMP destination unreachable response packets. Generally, if the base station fails to find the corresponding interface after receiving the TCP/UDP packets, it sends ICMP destination unreachable response packets. The response packets will expose the equipment. If a large number of ICMP response packets are sent to the network, the network equipment may be overloaded. You can use this parameter to disable the sending of ICMP response packets to prevent network security risks. By default, the base station does not send destination unreachable response packets.

SCTPSERVERSW SCTP Server Switch

Meaning: Indicates whether the server function is supported for SCTP of any of the following service types: RSL, NCP, CCP, S1-AP, R6-AP, R8-AP, ALCAP-AP, M2-AP, Se-AP, So-AP, gNodeB NG-AP, DSA S1-AP, and M3-AP. When this switch is turned on, the SCTP server function is supported. When this switch is turned off, the SCTP server function is disabled.

Example

To set the transmission function switch with IP PM Passive Activation Switch set to ENABLE, IPMUX Demultiplexing Switch set to ENABLE, IP Loopback Detection Response Switch set to ENABLE, Path Ping Detection Response Switch set to ENABLE, ICMP Port Unreachable Send Switch set to ENABLE, SCTP Server Switch set to ENABLE, Downlink Rate Limiting Switch set to ENABLE, IP Receive Switch set to ENABLE, run the following command:
SET TRANSFUNCTIONSW: IPPMPASSIVEACTIVATIONSW=ENABLE, IPMUXDEMULTIPLEXSW=ENABLE, IPLOOPTSTRSPSW=ENABLE, PATHPINGRSPSW=ENABLE, ICMPPORTUNREACHABLESW=ENABLE, SCTPSERVERSW=ENABLE, DLLIMITSW=ENABLE, IPRCVSW=ENABLE;
