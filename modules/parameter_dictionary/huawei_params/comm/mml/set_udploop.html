Set UDP Loopback (SET UDPLOOP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the UDP-type IP packet loopback. The UDP-type IP packet loopback can be used to check the connectivity and quality of the network based on the UDP packets sent by the peer end.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only one loopback mode can be configured for IP packets. The new loopback configuration overwrites the existing loopback configuration. If the Loopback Mode is set to NOLOOP(No Loopback), the loopbacks in all virtual routing and forwarding (VRF) domains (0 to 7) are terminated.

  • When LM is set to SPECIALIPUDPPORTREMOTE and the local source port number is 65535, the base station performs a loopback on all UDP packets with the destination port number.

  • When the loopback is configured for all the IP packets or IP packets involving specified source and destination IP addresses, the loopback mode is used only for the detection of connectivity of the network. When LM is set to SPECIALIPUDPPORTREMOTE, the loopback mode could be used for the detection of connectivity, performance and quality of the network.

  • The Appoint Interface parameter can be set for only the WMPT, UMPT and UMDU boards.

  • After the board is reset, the loop mode (LM) is automatically switched to NOLOOP.

  • The source IP address and the UDPLOOP MO with the Appoint Interface parameter configured cannot both be set.

  • ALM-25896 IP Remote Loopback is reported only when the Loopback Mode parameter is set to ALLIPREMOTE(All IP Remote Loopback) or SPECIALIPREMOTE(Special IP Remote Loopback) by running this command.

  • The UCCU/UBBPe/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 board does not support ALLIPREMOTE and SPECIALIPREMOTE. When LM is set to SPECIALIPUDPPORTREMOTE, loopbacks of local source port numbers ranging from 62048 to 62559 cannot be performed.

  • [Co-MPT,NodeB,eGBTS]When the IP loopback detection switch is turned on (queried using the LST TRANSFUNCTIONSW command) and an IP path or user-plane host is configured, a port loopback is enabled by default with the local destination port number being 65040.

  • [NodeB,eNodeB,gNodeB]When LM of IP packets is set to ALLIPREMOTE or SPECIALIPREMOTE, the functions of tracing IP packets and MAC packets cannot be enabled.

  • [eNodeB,gNodeB]If LM is set to SPECIALIPUDPPORTREMOTE or SPECIALIPUDPPORTLOCAL, the services in the same routing domain carried by the IP addresses and UDP ports specified in this command are interrupted. Exercise caution when running this command.

  • [eNodeB,gNodeB]When the loopback is configured for all the IP packets or IP packets involving specified source and destination IP addresses, the loopback takes effect only in the UDP datagrams encapsulated in IP packets.

  • [Co-MPT,eGBTS]The GTMUb does not support ALLIPREMOTE and SPECIALIPREMOTE.

  • [eNodeB,gNodeB]When the remote loopback is enabled, the original loopback mode takes effect after all the loopbacks or the loopbacks involving the specified IP addresses fail to be enabled.

  • [NodeB,eGBTS]If the local destination port number is 65040 and the local destination IP address is the same as the local IP address of the USERPLANEHOST MO in the endpoint model, which are specified in the configuration of a UDP loop, the link loopback detection function in the endpoint model may be abnormal.

LM Loopback Mode

Meaning: Indicates the UDP loopback mode.

If this parameter is set to SPECIALIPUDPPORTREMOTE, the UDP packets from a BS that meet the specified conditions are looped back to the peer device.

If this parameter is set to ALLIPREMOTE, all the UDP packets received on a BS are looped back to the peer device.

If this parameter is set to SPECIALIPREMOTE, the UDP packets received on a BS, whose local and peer IP addresses are the same as the specified address couple, are looped back to the peer device.

GUI Value Range: NOLOOP(No Loopback), SPECIALIPUDPPORTREMOTE(Special IP and UDP Port Remote Loopback), ALLIPREMOTE(All IP Remote Loopback), SPECIALIPREMOTE(Special IP Remote Loopback)

Unit: None

Actual Value Range: NOLOOP, SPECIALIPUDPPORTREMOTE, ALLIPREMOTE, SPECIALIPREMOTE

MML Default Value: NOLOOP(No Loopback)

Recommended Value: NOLOOP(No Loopback)

Example

To set the UDP loopback with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Loopback Mode: SPECIALIPUDPPORTREMOTE, RX Source IP Address: 172.16.81.122, RX Destination IP Address: 172.16.81.123, RX Source Port Number: 1111, RX Destination Port Number: 1025, TX Source IP Address: 172.16.81.124, TX Destination IP Address: 172.16.81.125, TX Source Port Number: 1026, TX Destination Port Number: 1027, Loopback Time: 1, Appoint Interface: NO, run the following command: 
SET UDPLOOP: CN=0, SRN=0, SN=7, LM=SPECIALIPUDPPORTREMOTE, RXSIP="172.16.81.122", RXDIP="172.16.81.123", RXSPN=1111, RXDPN=1025, TXSIP="172.16.81.124", TXDIP="172.16.81.125", TXSPN=1026, TXDPN=1027, LT=1, APPTIF=NO;
