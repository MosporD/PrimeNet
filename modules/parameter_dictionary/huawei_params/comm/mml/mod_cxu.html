Modify CXU (MOD CXU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configurations of a CXU.

Note

When the CXU is in maintenance mode, the way of alarm reporting is changed and the performance data is implausible.

Parameters

ID Name Description

Meaning: Indicates the number of the cabinet where the CXU is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each CXU MO must have a unique combination of CN, SRN, and SN among all RRU, AAMU, RHUB, and CXU MOs.
  • [eGBTS]Each CXU MO must have a unique combination of CN, SRN, and SN among all RRU, AAMU, and CXU MOs.
  • [gNodeB]Each CXU MO must have a unique combination of CN, SRN, and SN among all RRU, RHUB, and CXU MOs.

MNTMODE Maintenance Mode

Meaning: Indicates the maintenance mode of a CXU. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes. The default value of this parameter is Normal.

GUI Value Range: NORMAL(NORMAL), INSTALL(INSTALL), EXPAND(EXPAND), UPGRADE(UPGRADE), TESTING(TESTING), ExpandStatus1(ExpandStatus1), ExpandStatus2(ExpandStatus2), ExpandStatus3(ExpandStatus3), ExpandStatus4(ExpandStatus4), ExpandStatus5(ExpandStatus5), ExpandStatus6(ExpandStatus6), ExpandStatus7(ExpandStatus7), ExpandStatus8(ExpandStatus8), ExpandStatus9(ExpandStatus9), ExpandStatus10(ExpandStatus10)

To modify the CXU configurations with the parameters as follows: Subrack No.: 60, CXU Name: CXU, run the following command:
