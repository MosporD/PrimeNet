Display Peer Reference Clock (DSP PEERCLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the running status of a specified peer reference clock link.

Note

None.

Parameters

ID Name Description
PN Peer Clock No.

Meaning: Indicates the number of the peer reference clock link.

GUI Value Range: 0~11

Unit: None

Actual Value Range: 0~11

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the status of the peer reference clock link, run the following command:
DSP PEERCLK:;
The result is shown as follows:
+++    0        2010-01-05 23:16:36
O&M    #249
%%DSP PEERCLK:;%%
RETCODE = 0  Operation succeeded.

Display PeerClk State
---------------------
      Peer Clock No.  =  0
Link Available State  =  Unavailable
   Link Active State  =  Deactivated
(Number of results = 1)


---    END

Output Description

Field Description

Peer Clock No.

Indicates the number of the peer reference clock link.

Link Available State

Indicates the availability of the peer reference clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.

Link Active State

Indicates the activation status of the peer reference clock link. If the link is active, the peer reference clock link is the current clock source of the system.
