Display RET Subunit (DSP RETSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a remote electrical tilting (RET) subunit.

Note

Calibration is required before querying the information of the RET subunit and the installation is complete. If the RET is not calibrated. In addition, the querying of the tilt fails and invalid values are returned.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RET.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RET subunit, which starts from 1.

GUI Value Range: 1~12

Unit: None

Actual Value Range: 1~12

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the dynamic information about the RET subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP RETSUBUNIT: DEVICENO=0, SUBUNITNO=1;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the RET.

Device Name

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

Subunit No.

Indicates the number of the RET subunit, which starts from 1.

Subunit Name

Indicates the name of the RET subunit. The name of the RET subunit is optional, but the name configured for each RET subunit must be unique.

Online Status

Indicates the online status of the subunit.

Actual Tilt(0.1degree)

Indicates the actual tilt of the RET subunit.

Actual Sector ID

Indicates the sector ID of the RET subunit.

RET Configuration Data File Name

Indicates the name of the RET configuration data file that is loaded last time.

Configuration Data File Load Time

Indicates the time when the RET configuration data file is loaded last time.
