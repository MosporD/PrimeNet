Set Direct Voltage Alarm Switch Status (SET DVAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the DC voltage alarm switch and threshold.

Note

The ALM-26113 Base Station DC Power Supply Abnormal is reported only when the -48V DC digital power board is configured.

Parameters

ID Name Description
DVAS Direct Voltage Alarm Switch

Meaning: Indicates the direct voltage alarm switch. The switch controls whether to report the ALM-26113 Base Station DC Power Supply Abnormal in the case of low DC input voltage.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
DVAH Direct Voltage Alarm Occurred Threshold

Meaning: Indicates the DC voltage alarm occurrence threshold. When the load voltage is lower than the DC voltage alarm occurred threshold and the direct voltage alarm switch is set to ENABLE, ALM-26113 Base Station DC Power Supply Abnormal is reported.

GUI Value Range: 390~556

Unit: 0.1V

Actual Value Range: 39.0~55.6, step: 0.1

MML Default Value: 450

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the EQUIPMENT MO, the value of DVAH must be smaller than or equal to the value of DVAL minus 5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
DVAL Direct Voltage Alarm Restored Threshold

Meaning: Indicates the DC voltage alarm Restoration threshold. When the load voltage is higher than the DC voltage alarm restored threshold and the direct voltage alarm switch is set to ENABLE, an ALM-26113 Base Station DC Power Supply Abnormal is cleared.

GUI Value Range: 390~600

Unit: 0.1V

Actual Value Range: 39.0~60.0, step: 0.1

MML Default Value: 455

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the EQUIPMENT MO, the value of DVAH must be smaller than or equal to the value of DVAL minus 5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the direct voltage alarm switch and threshold with the parameters as follows: Direct Voltage Alarm Switch: ENABLE, Direct Voltage Alarm Occurred Threshold: 450, Direct Voltage Alarm Restored Threshold: 455, run the following command:
SET DVAS: DVAS=ENABLE, DVAH=450, DVAL=455;
