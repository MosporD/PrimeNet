Add IP to IP Transmission Resource Group Mapping Configuration (ADD IP2IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add mapping between an IP address and an IP transmission resource group. The mapping between an IP address and an IP transmission resource group is the mapping between the destination IP address of the passing-by data or local OM data (over IP transmission)/signaling data and an IP transmission resource group.

Note

  • System specifications: If the WMPT/UMPT/LMPT is the main control board, a maximum of 128 entries of mapping from IP addresses to ip transmission resource groups can be configured. If the UMDU is the main control board, a maximum of 32 entries of mapping from IP addresses to ip transmission resource groups can be configured.

  • Board specifications: A maximum of 32 entries of mapping from IP addresses to ip transmission resource groups can be configured on a UMPT/UMDU/LMPT/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC). A maximum of 16 entries of mapping from IP addresses to ip transmission resource groups can be configured on a WMPT. If the GTMUb/GTMUc is the evolution scenario board, a maximum of 8 entries of mapping from IP addresses to ip transmission resource groups can be configured on a GTMUb/GTMUc.

  • OM flow cannot be joined into the backplane ip transmission resource group on the UMPT board.

  • In a security scenario, the passing-by data or local OM/signaling data (over IP transmission) is encrypted and sent to the security gateway and therefore the destination IPv4 address can only be the address of the peer security gateway.

  • When the user does not add mapping between an IP address and an IP transmission resource group, data are carried in the default ip transmission resource group with the actual service outbound interface.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]System specifications: A maximum of 32 IPv4 type IP-to-transmission-resource-group mapping relations can be configured in each ip transmission resource group.

  • [Co-MPT,eNodeB,gNodeB]Before adding the mapping between an IP address and an ip transmission resource group, ensure that the transmission resource group has been added by running the ADD IPRSCGRP command.

  • [Co-MPT,eNodeB,gNodeB]Board specifications: A maximum of 32 entries of mapping from IPv6 addresses toip transmission resource groups can be configured on a UMPT/UMDU.

  • [Co-MPT,eNodeB,gNodeB]System specifications: If the UMPT is the main control board, a maximum of 128 entries of mapping from IPv6 addresses to ip transmission resource groups can be configured. If the UMDU is the main control board, a maximum of 32 entries of mapping from IPv6 addresses to ip transmission resource groups can be configured.

  • [Co-MPT,eNodeB,gNodeB]A maximum of 32 mappings of IPv6 addresses to IP transmission resource groups can be configured on each IP transmission resource group.

  • [Co-MPT,eNodeB,gNodeB]In a security scenario, the passing-by data or local OM/signaling data (over IP transmission) is encrypted and sent to the security gateway and therefore the destination IPv6 address can only be the address of the peer security gateway.

  • [Co-MPT,NodeB,eGBTS]OM flow cannot be joined into the ip transmission resource group on the WMPT/UTRP/GTMUb board.

  • [NodeB]A maximum of 16 IPv4 type IP-to-transmission-resource-group mapping relations can be configured in each ip transmission resource group.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]DSTIPV4 in an IP2IPRSCGRP MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In an IP2IPRSCGRP MO, the logic AND result of DSTIPV4 and DSTMASK must be the same as DSTIPV4. That is, DSTIPV4 must be set to a network IP address.

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the IP2IPRSCGRP MO, if IPVERSION are set to IPV4, this parameter must be set.

Example

To add mapping between an IP address and an IP transmission resource group with the parameters as follows: IP to IP Transmission Resource Group ID: 0, IP Transmission Resource Group ID: 0, IP Version: IPV4, Destination IPv4 Address: 10.52.21.0, Subnet Mask: 255.255.255.0, run the following command:
ADD IP2IPRSCGRP: IP2IPRSCGRPID=0, IPRSCGRPID=0, IPVERSION=IPV4, DSTIPV4="10.52.21.0", DSTMASK="255.255.255.0";
