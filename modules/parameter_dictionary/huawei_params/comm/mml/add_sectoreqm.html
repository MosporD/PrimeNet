Add Sector Equipment (ADD SECTOREQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add sector equipment and sector equipment antennas.

Note

  • When the UMPTa/UMPTb or UMDU is used as the main control board, a base station supports a maximum of 960 sector device antennas. When the UMPTe, UMPTg, or UMPTga is used as the main control board, a base station supports a maximum of 1920 sector device antennas. When the GTMUb is used as the main control board, a base station supports a maximum of 120 sector device antennas. When the GTMUc is used as the main control board, a base station supports a maximum of 288 sector device antennas. Otherwise, a base station supports a maximum of 216 sector device antennas.

  • When the UMPTa/UMPTb or UMDU is used as the main control board, a base station supports a maximum of 480 sector devices. When the UMPTe, UMPTg, or UMPTga is used as the main control board, a base station supports a maximum of 960 sector devices. When the GTMUb is used as the main control board, a base station supports a maximum of 24 sector devices. When the GTMUc is used as the main control board, a base station supports a maximum of 108 sector devices. Otherwise, a base station supports a maximum of 102 sector devices.

  • When Antenna Config Mode is set to ANTENNAPORT for the sector equipment, the sector equipment antenna must be configured and exist in the sector antennas of the corresponding sector.

  • A maximum of eight sector equipment antennas can be added through this command. After that, operators can run the MOD SECTOREQM command to continue to add sector equipment antennas.

  • When the sector equipment antenna is the antenna connection port of the RF module, the channel number of the sector equipment antenna is identified by R0A to R0P. When the sector equipment antenna is the virtual antenna port of the AAS, the channel number of the sector equipment antenna is identified by R0A to R7D.

  • When Antenna Config Mode is set to BEAM for the sector equipment, the sector equipment does not need to be configured with an antenna and the corresponding sector does not need to be configured with an antenna for the sector equipment.
