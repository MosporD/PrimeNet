List TX Channel (LST TXBRANCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the RRU/RFU transmit channel.

Note

The command execution result is the number of TX channels configured by the RRU or RFU. The actual number of TX channels of the RRU or RFU can be queried by running the DSP TXBRANCH command.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the TX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the TX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the TX channel is located.

TX Channel No.

Indicates the number of the TX channel of the RRU or RFU.

Logical Switch of TX Channel

Indicates the logical switch of the TX channel of the RRU or RFU. This switch is used to open or close the TX channel. The logical switch of the TX channel and the ARFCNs(absolute radio frequency channel numbers) on the TX channel determine the state of the physical switch of the TX channel: When this switch is ON and the TX channel is configured with ARFCNs(absolute radio frequency channel numbers), the physical switch is ON. In other cases, the physical switch is OFF. The value NULL for the Logical Switch of TX Channel parameter indicates that the parameter setting remains unchanged.
