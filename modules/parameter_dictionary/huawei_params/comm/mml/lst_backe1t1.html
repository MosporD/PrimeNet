List Back E1/T1 Port Configuration (LST BACKE1T1)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of an E1/T1 port configured on the backplane.

Note

None.

Parameters

None.

Example

To list the configuration of an E1/T1 port configured on the backplane, run the following command: 
LST BACKE1T1:;
The result is shown as follows:
+++    0        2010-07-23 20:00:20
O&M    #224
%%LST BACKE1T1:;%%
RETCODE = 0  Operation succeeded.

List Back E1/T1 Port Configuration
----------------------------------
         Cabinet No.  =  0
         Subrack No.  =  0
            Slot No.  =  0
       Subboard Type  =  Back Board
            Port No.  =  0
Destination Slot No.  =  3
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where an E1/T1 port is located.

Subrack No.

Indicates the subrack number of the board where an E1/T1 port is located.

Slot No.

Indicates the slot number of the board where an E1/T1 port is located.

Subboard Type

Indicates the type of sub-board on the board where the E1/T1 port is located.

Port No.

Indicates the number of the E1/T1 port.

Destination Slot No.

Indicates the number of the slot housing the destination board whose backplane has an E1/T1 port.
