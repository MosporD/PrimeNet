Modify VRET Subunit Configuration (MOD VRETSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configuration of a virtual remote electrical tilting (VRET) subunit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS,eNodeB]When a VRET subunit is initially configured, at least one valid connected port must be set.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The value range of Downlink Tilt, Uplink Tilt, BeamAzimuth, and BeamWidth of the VRET subunit can be queried by running the DSP AARU command.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When the Uplink Tilt, Downlink Tilt, BeamAzimuth, and BeamWidth of multiple VRET subunits on the AARU are beyond the AARU hardware capacity, you need to run this command multiple times to correct all the configuration data, only the last command can take effect, after the last command, the configuration data of all VRET subunits on the AARU will take effect.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The combination of the BeamAzimuth and BeamWidth needs to be supported by the active antenna system (AAS). Otherwise, the configuration will not take effect. For details, see AAS Feature Parameter Description.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When a virtual antenna port to which the virtual RET subunit is connected has been configured with activated carriers, the polarization type, BeamAzimuth or BeamWidth of this virtual antenna port cannot be modified.

  • [Co-MPT,NodeB,eGBTS,eNodeB]For some types of AASs, the difference of tilt angles of beams working in the same band and that of beams working in different bands need to meet some specific requirements. For details, see 3900 Series Base Station Technical Description.

Example

To modify the configuration of a VRET subunit with the parameters as follows: Device No.: 60, Subunit No.: 1, Subunit Name: PEOPLESQUARE_SEC1_VRETSUBUNIT_01, PORTNUM: 2, Connect Port 1: R4A, Polar type 1: VERTICAL, Connect Port 2: R4B, Polar type 2: HORIZONTAL, Uplink Tilt: 5.6 degrees, Downlink Tilt: 6.5 degrees, Beam Azimuth: 0 degree, Beam Width:65 degrees, run the following command:
MOD VRETSUBUNIT: DEVICENO=60, SUBUNITNO=1, SUBNAME="PEOPLESQUARE_SEC1_VRETSUBUNIT_01", PORTNUM=2, CONNPN1=R4A, POLARTYPE1=VERTICAL, CONNPN2=R4B, POLARTYPE2=HORIZONTAL, ULTILT=56, DLTILT=65, BEAMAZIMUTH=0, BEAMWIDTH=650;
