Set Environmental Alarm Parameter (SET ENVALMPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the name, severity, and type of an environmental alarm.

Note

  • To query whether the setting has taken effect after execution of this command, run the LST ALMCFG command.

  • The change of the name, severity, or type of an environment alarm takes effect only on the local NE.

Parameters

ID Name Description
ALMID Alarm ID

Meaning: Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.

GUI Value Range: 65033~65233

Unit: None

Actual Value Range: 65033~65233

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ANM Alarm Name

Meaning: Indicates the alarm name, which is the unique name of an alarm in the same product. It corresponds to the alarm ID and clearly and accurately conveys the meaning of the alarm.

GUI Value Range: 0~111 characters

Unit: None

Actual Value Range: 0~111 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ALVL Alarm Level

Meaning: Indicates the alarm severity, that is the impact of the fault on services.

GUI Value Range: CRITICAL(Critical Alarm), MAJOR(Major Alarm), MINOR(Minor Alarm), WARNING(Warning)

Unit: None

Actual Value Range: CRITICAL, MAJOR, MINOR, WARNING

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ASS Event Type

Meaning: Indicates the network management type.

GUI Value Range: POWER(Power System), ENV(Environment System), SIG(Signaling System), TRUNK(Relay System), HARDWARE(Hardware System), SOFTWARE(Software System), RUN(Running System), COMM(Communications System), SERVICE(Service Quality), HANDLE(Handling error)

Unit: None

Actual Value Range: POWER, ENV, SIG, TRUNK, HARDWARE, SOFTWARE, RUN, COMM, SERVICE, HANDLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the name, severity, and type of an environmental alarm with the parameters as follows: Alarm ID: 65230, Alarm Name: alm00001, Alarm Level: MAJOR, Event Type: HARDWARE, run the following command:
SET ENVALMPARA: ALMID=65230, ANM="alm00001", ALVL=MAJOR, ASS=HARDWARE;
