Display NE Interconnection Topology (DSP INTERCONTOPO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the interconnection topology between NEs.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]This command can be used to query the following information:

    - Topology between BBU and USU3900 as well as the topology between USU3900s in multi-BBU interconnection scenarios.

    - Topology between BBU and USU3910 as well as the topology between USU3910s in Cloud BB scenarios.

  • [Co-MPT,NodeB,eNodeB,gNodeB]This command cannot be used to query the intra-site multi-BBU interconnection topology. In intra-site multi-BBU interconnection scenarios, you can run the DSP BBPLNK command to query the actual inter-BBU baseband interconnection topology and the LST CTRLLNK command to query the control link configuration.

Parameters

None.

Example

To query the NE interconnection topology, run the following command:
DSP INTERCONTOPO:;
The result is shown as follows:

Output Description

Field Description

Local Slot No.

Indicates the slot number of the local board.

Local Port Type

Indicates the port type of the local port.

Local Port No.

Indicates the port number of the local port.

Local Sub Port No.

Indicates the sub port number of the local port. The value of this field is valid only when the actual application mode port is 4*10GE or 40GE. The invalid value of this field is displayed as NULL.

Peer ESN

Indicates the ESN of the peer subrack.

Peer Level

Indicates the topology hierarchy of the peer NE. The value of this field is valid only when the type of peer subrack is USU3910. The invalid value of this field is displayed as NULL.

Peer Node ID

Indicates the node number of the peer NE among all NEs in the same hierarchy. The value of this field is valid only when the type of peer subrack is USU3910. The invalid value of this field is displayed as NULL.

Peer Frame Type

Indicates the type of peer subrack.

Peer Slot No.

Indicates the slot number of the peer board.

Peer Port Type

Indicates the port type of the peer port.

Peer Port No.

Indicates the port number of the peer port.

Peer Sub Port No.

Indicates the sub port number of the peer port. The value of this field is valid only when the actual application mode of the peer port is 4*10GE or 40GE. The invalid value of this field is displayed as NULL.

Peer OM IP Address

Indicates the OM channel IP address configured for a peer NE. This parameter can be obtained only when the local port is a CI port, and the master IP address is displayed when the OM channel works in active/standby mode.
