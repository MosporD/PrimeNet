Reset ALD Power Switch (RST ALDPWRSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to turn on the antenna line device (ALD) power switch that has been powered off automatically due to an exception. This command is used to terminate the self-protection state of the ALD.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be executed successfully only when the specified RRU or RFU works properly.

  • Do not run this command frequently. Otherwise, the hardware lifespan will be impacted and the hardware may be damaged.

  • After the execution of this command, power supply to the specified port is reset and all the links for the ALDs on the specified port are interrupted.

Example

To reset the ALD power switch with parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, Port No.: R0A, run the following command:
RST ALDPWRSW: CN=0, SRN=60, SN=0, PN=R0A;
