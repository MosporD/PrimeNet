Modify CB (MOD CB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to change the properties of a Configuration Baseline (CB), for example, the comment of a CB, the automatic rollback switch, the rollback time, the rollback condition.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When the period of time specified by RBKTIME expires, if the rollback conditions are not met, the system waits five minutes before making a decision again. The remaining rollback time is five minutes and the timing restarts. After the five minutes expire, if rollback conditions specified by the parameter RBKCONDITION are met, the base station resets, data configuration is rolled back to the corresponding CB used to enable this function. If the rollback succeeds, the base station disables this function. If rollback conditions are not met (for example, the OMCH is normal or has recovered to its normal state), the base station disables this function.

  • If automatic rollback is enabled, the system is reset and restores the CB confirmed by this command at the end of rollback duration specified by RBKTIME when the link is continuously interrupted and rollback conditions specified by the parameter RBKCONDITION are met. After the rollback is performed, the system reports ALM-26255 Automatic Version Rollback alarm, and automatically disables automatic rollback.

  • Before the period of time specified by RBKTIME expires, if the NE resets and related conditions are met, the automatic configuration data rollback function still takes effect after the reset.

  • If the RBKCONDITION parameter is set to OMCH_AND_SERVICE_FAULT(OMCH_AND_SERVICE_FAULT), the automatic configuration data rollback function will be triggered only when the OMCH and all service channels are faulty.

Parameters

ID Name Description
NAME Name of CB

Meaning: Indicates the name of the CB. The name of each CB must be unique, and is case insensitive. The name cannot contain any of the following characters: question mark (?), exclamation mark (!), right angle bracket (>), left angle bracket (<), bar (|), slash (/), backslash (\), colon (:), and asterisk (*). It is not recommended that the name contain any space, because an error message will be displayed when the name containing spaces is not supported by a file system in the BS. Different file systems differ from one another in their support for the CB name containing spaces.

Example

To modify the attributes of a CB whose name is set to CB1, for example, modify Comment of CB to Launch, Automatic Roll Back Switch to ENABLE, Roll Back Time to 30 and Roll Back Condition to OMCH_FAULT, run the following command:
MOD CB: NAME="CB1", COMMENT="Launch", AUTORBKSW=ENABLE, RBKTIME=30, RBKCONDITION=OMCH_FAULT;
The result is as follows:
