List Output Port (LST OUTPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an output port (relay).

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the output port is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the output port is located.

GUI Value Range: 0~1,40~59

Unit: None

Actual Value Range: 0~1,40~59

MML Default Value: None

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board where the output port is located.

GUI Value Range: 0,6,18~19

Unit: None

Actual Value Range: 0,6,18~19

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
PN Port No.

GUI Value Range: 0~5

Example

To list the configuration of the output port, run the following command:
LST OUTPORT:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the output port is located.

Subrack No.

Indicates the subrack number of the board where the output port is located.

Slot No.

Indicates the slot number of the board where the output port is located.

Port No.

Indicates the number of the output port.

Port Name

Indicates the name of the output port.

Port Switch

Indicates the enabled/disabled state of the output port.
