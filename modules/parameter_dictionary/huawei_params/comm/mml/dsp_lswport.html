Display L2 LAN Switch Port Running Status (DSP LSWPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the operating status of a layer 2 LAN switch port.

Note

None.

Parameters

ID Name Description
PORTIDX Port Index

Meaning: Indicates the index of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

GUI Value Range: 0~32

Unit: None

Actual Value Range: 0~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L
CLEAR Clear Statistic

Meaning: Indicates whether to clear the current statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query L2 LAN Switch Port Running Status with the parameters as follows: Port Index: 0, run the following command:
DSP LSWPORT: PORTIDX=0;
The result is shown as follows:

Output Description

Field Description

Port Index

Indicates the index of a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Port Type

Indicates the port type used by a layer 2 LAN switch port on a layer 2 LAN switch of an NE.

Ethernet Port ID

Indicates the ID of the Ethernet port corresponding to an Ethernet-type layer 2 switching port controlled by a layer 2 LAN switch.

Cabinet No.

Indicates the number of the cabinet housing the board that carries the layer 2 LAN switch port of Ethernet type on the layer 2 LAN switch for an NE.

Subrack No.

Indicates the number of the subrack housing the board that carries the layer 2 LAN switch port of Ethernet type on the layer 2 LAN switch for an NE.

Slot No.

Indicates the number of the slot housing the board that carries the layer 2 LAN switch port of Ethernet type on the layer 2 LAN switch for an NE.

Port No.

Indicates the number of Ethernet port corresponding to the layer 2 LAN switch port of Ethernet type on the layer 2 LAN switch for an NE.

Switch Port State

Indicates the state of a layer 2 LAN switch port.

Received Non-Broadcast Packets(packet)

Indicates the number of packets received by a layer 2 LAN switch port.

Number of Transmitted Packets(packet)

Indicates the number of packets transmitted by a layer 2 LAN switch port.

Number of Packets Discarded in RX Direction due to MAC MISS(packet)

Indicates the number of packets discarded by a layer 2 LAN switch port in the receive direction due to MAC MISS. MAC MISS means that searching for the forwarding table based on the destination MAC address of the packets fails. This parameter is valid only for layer 2 switch ports of the Ethernet type.

Dropped Packets In Reception direction Due to Broad Cast forwarding Rate Limit Overflow(packet)

Indicates the number of broadcast packets discarded by a layer 2 port in the receive direction when the number of broadcast packets exceeds a specified threshold. This parameter is valid only for layer 2 switch ports of the Ethernet type.
