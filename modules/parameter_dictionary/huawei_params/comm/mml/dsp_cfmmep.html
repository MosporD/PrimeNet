Display CFM MEP Status (DSP CFMMEP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the local maintenance association end point (MEP).

Note

[Co-MPT,eNodeB,gNodeB]The BS measures the numbers of the following packets only on the active party instead of the passive party: transmitted loopback packets, received loopback packets, traced packets on TX links, and traced packets on RX links.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the MEP belongs.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the MD Name parameter in the CFMLOCALMEP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MEP.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of the local MEP with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, MEP ID: 1000, run the following command: 
DSP CFMMEP: MDNAME="CHINA", MANAME="SHANGHAI", MEPID=1000;

Output Description

Field Description

MD Name

Indicates the name of the MD to which the MEP belongs.

MD Level

Indicates the level of the CFM MD.

MA Name

Indicates the name of the MA to which the MEP belongs.

MEP ID

Indicates the MEP ID.

Binding VLAN

Indicates whether the MA to which the MEP belongs is bound to a VLAN.

VLAN ID

Indicates the ID of a VLAN of the MA to which the MEP belongs.

VLAN Priority

Indicates the priority of a VLAN of the MA to which the MEP belongs.

CC Switch

Indicates whether to enable the continuity check (CC) of the CFM.

Number of TX CCM PDUs(packet)

Indicates the number of transmitted connectivity check (CC) packets.

Number of RX CCM PDUs(packet)

Indicates the number of received connectivity check (CC) packets.

Number of TX Loopback PDUs(packet)

Indicates the number of transmitted loopback packets.

Number of RX Loopback PDUs(packet)

Indicates the number of received loopback packets.

Number of TX Link Trace PDUs(packet)

Indicates the number of trace packets transmitted on a link.

Number of RX Link Trace PDUs(packet)

Indicates the number of trace packets received on a link.

Number of TX Success CFM PDUs(packet)

Indicates the number of transmitted CFM packets.

Number of TX Dropped CFM PDUs(packet)

Indicates the number of CFM packets discarded during transmission discarded.

Number of RX Success CFM PDUs(packet)

Indicates the number of received CFM packets.

Number of RX Dropped CFM PDUs(packet)

Indicates the number of CFM packets discarded during reception.
