Modify the bind relation of the Mains Input Out of Range alarm (MOD NMSABIND)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the bind relation of the Mains Input Out of Range alarm. When the corresponding alarm is reported, some or all cells are shut down to reduce the power consumption of a base station, prolonging the operating time of storage batteries.

Note

  • A base station can process alarms related to mains cut-off only if the base station is bound with customized dry-contact ports. You can run the SET ALMPORT command to enable or disable customized dry-contact ports.

  • In a distributed power supply scenario, all the dry-contact ports used to report alarms related to mains cut-off must be configured with the same customized alarm ID. Other dry-contact ports must not be configured with this ID to prevent false alarms.

Example
