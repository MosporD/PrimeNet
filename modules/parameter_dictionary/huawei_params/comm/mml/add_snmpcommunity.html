Add SNMP Community (ADD SNMPCOMMUNITY)

Network Element: BTS3900, BTS5900

Function

Use this command to add an SNMP community name.

Note

[Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

Parameters

ID Name Description
COMMUNITYINDEX Community Index

Meaning: Indicates the index of an SNMP community.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R
KEY Community Name

Meaning: Indicates the name of an SNMP community. An SNMP community name is a 12-bit to 32-bit string that must contain the following types of characters: uppercase letters, lowercase letters, digits, and supported special characters (. - _ ~ @ $ ^ & ( ) ` # [ ] { }). No Chinese character is allowed in the name. The value of Character String Type cannot contain the following characters: 1. Such special characters as < > ! ? \ / : ; , = + % * " ' | or 2. Two or more percent signs (%), space, +++ (start character of an MML message), or --- (end character of an MML message).

GUI Value Range: 12~32 characters

Unit: None

Actual Value Range: 12~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To add SNMP community name parameters as follows: Community Index: 1, Community Name: "*****", run the following command: 
ADD SNMPCOMMUNITY: COMMUNITYINDEX=1, KEY="*****";
