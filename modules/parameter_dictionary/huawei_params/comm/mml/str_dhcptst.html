Enable the E2E DHCP Availability Test for the Entire System (STR DHCPTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to enable the E2E DHCP availability test for the entire system.

Note

  • If the base station or the transport network is configured with the packet filtering function, ensure that the configured packet filter can receive DHCP packets.

  • The E2E DHCP capability test for the entire system may take several minutes, and therefore you are advised to query the test results five minutes later.

  • The end-to-end DHCP availability detection supports a maximum of five DHCP server IP addresses in the entire system.

Parameters

ID Name Description
IPVERSION IP Version

Meaning: Indicates the IP protocol version. The old mode does not support DHCP availability detection of the IPv6 type.

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: IPv4(IPv4)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DESVLANID Designate VLAN ID

Meaning: Indicates whether to specify a VLAN ID for the E2E DHCP capability test packets for the entire system. When DHCPv4, If a VLAN ID is specified, the system sends the test packets according to the VLAN ID and also sends the test packets without a VLAN ID. If a VLAN ID is not specified, the system sends the test packets using the VLAN ID of OMCH packets and also sends the test packets without a VLAN ID. If the OMCH packets are not configured with any VLAN, the system sends test packets without a VLAN ID. When DHCPv6, If a VLAN ID is specified, the system sends the test packets according to the VLAN ID. If a VLAN ID is not specified, the system sends the test packets using the VLAN ID of OMCH packets and also sends the test packets without a VLAN ID. If the OMCH packets are not configured with any VLAN, the system sends test packets without a VLAN ID.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
TSTVLANID Test VLAN ID

Meaning: Indicates the VLAN ID specified for an E2E DHCP capability test of the entire system.

GUI Value Range: 1~4094

Unit: None

Actual Value Range: 1~4094

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when DESVLANID is set to YES.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Enable the E2E DHCP availability test for the entire system and do not designate a VLAN ID:
STR DHCPTST: DESVLANID=NO;
