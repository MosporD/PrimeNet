Modify PPP Link Configuration (MOD PPPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the parameters of the PPP links.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]This operation may interrupt the services or OM channels carried on the PPP link. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

AUTH Authentication Type

Meaning: Indicates the mode in which the local end of a PPP link authenticates the peer end. The authentication mode is classified into No authentication, Password Authentication Protocol(PAP) authentication, and Challenge and shake Authentication Protocol(CHAP) authentication. In PAP mode, user names and passwords are transmitted explicitly on the network. If they are intercepted during transmission, a great threat to network security is caused. Therefore, the PAP is applied only to the network environment with low security requirements. With three handshakes, the CHAP provides a more secure authentication. In CHAP mode, only user accounts rather than passwords are transmitted, enhancing security compared to the PAP.

GUI Value Range: NONAUTH(No Authentication), PAP(PAP Authentication), CHAP(CHAP Authentication)

Unit: None

Actual Value Range: NONAUTH, PAP, CHAP

MML Default Value: None

Recommended Value: CHAP(CHAP Authentication)

Parameter Relationship: None

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In the logical operation result of LOCALIP and IPMASK in a PPPLNK MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a PPPLNK MO, LOCALIP must be different from PEERIP.

Example

To modify the parameters of the PPP links with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Link No.: 0, Port No.: 0, IP Header Compression: Enable, IPHC SubOption: Enable, Maximum Receive Unit: 1500, run the following command:
MOD PPPLNK: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, PPPLNKN=0, PN=0, IPHC=ENABLE, IPHCSUBOPT=ENABLE, MRU=1500;
