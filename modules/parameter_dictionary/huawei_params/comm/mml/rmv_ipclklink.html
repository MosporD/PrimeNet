Remove IP Clock Link (RMV IPCLKLINK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a specified IP clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • A clock link cannot be removed if the value of the Clock Working Mode parameter is MANUAL and a HW_DEFINED or OC_SLAVE IP clock link compliant with IEEE 1588 V2 is configured and specified as the reference clock source. The clock link can be removed if the value of the Clock Working Mode parameter is AUTO. After the clock link is removed, a clock link switchover occurs. The clock of lower-level NEs may become abnormal after the removal of an OC_MASTER link.

  • If time synchronization is used, removing an IEEE 1588 V2 clock link from a UTRPc port interrupts all the services carried on the port for about 3s.

  • Ongoing services are affected if a clock source in use is removed, the NE does not obtain another reference clock within the holding period of the crystal oscillator, and the crystal oscillator running time exceeds the hold period.

  • [Co-MPT,NodeB,eGBTS]Turn off the ART switch if the IEEE 1588 ATR function is not required.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the IP clock link.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the IPCLKLNK MO, when the value of DEVTYPE is set to OC_SLAVE, the value of LN must be 0 or 1. When the value of DEVTYPE is set to OC_MASTER, the value of LN must be 2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove an IP clock link with IP Clock No. set to 0, run the following command:
RMV IPCLKLINK: LN=0;
