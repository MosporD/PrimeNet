Remove SCTP Peer IPv6 Address Block (RMV BLKSCTPPEERIPV6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to unblock SCTP links based on the peer IPv6 address. After a peer IPv6 address is unblocked, all SCTP links associated with the peer IPv6 address are unblocked.

Note

None.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
PEERIPV6 Peer IPv6 Address

Meaning: Indicates the peer IPv6 address of a blocked SCTP link.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In a BLKSCTPPEERIPV6 MO, PEERIPV6 must be a globally scoped unicast address.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

Remove SCTP Peer IPv6 Address Block: VRFIDX:0, Peer IPv6 Address: 2001:DB8::1;
RMV BLKSCTPPEERIPV6: VRFIDX=0, PEERIPV6="2001:DB8::1";
