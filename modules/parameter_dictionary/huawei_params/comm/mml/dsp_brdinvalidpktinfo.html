Display Invalid Board Packet Information (DSP BRDINVALIDPKTINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about invalid packets on a board to trace attack sources.

Note

  • The information about invalid packets can be queried only for boards that comply with eCPRI protocols.

  • Currently, only the information about the discarded packets of the flood attack defense type can be queried.

  • If the CPU usage is too high, the invalid packets will be dropped and the user cannot query or only query parts of invalid packets according to this command.

  • The information of each byte of the queried invalid packet data is displayed in hexadecimal form.

  • If you run the DSP INVALIDPKTINFO command on the board during the execution of this command, the query result is inaccurate.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.

Port Type

Indicates the type of ports. The value ALL indicates that the types of all the ports on the board are queried.

Port No.

Indicates the port number of the board where the port is located.

Drop Packet Type

Indicates the type of packet to be discarded.

Source MAC Address of Invalid Packet

Indicates the source MAC address of an invalid packet.

Destination MAC Address of Invalid Packet

Indicates the destination MAC address of an invalid packet.

VLAN ID of Invalid Packet

Indicates the VLAN ID of an invalid packet.

Protocol Type of MAC Layer

Indicates the type of MAC-layer protocol used by an invalid packet. A BS interprets only the supported MAC-layer protocols and only displays the protocol numbers of other MAC-layer protocols.

Source IP Address of Invalid Packet

Indicates the source IP address of an invalid packet.

Destination IP Address of Invalid Packet

Indicates the destination IP address of an invalid packet.

Protocol Type of IP Layer

Indicates the protocol used at the IP layer of an invalid packet. A BS interprets only the supported IP-layer protocols and only displays the protocol numbers of other IP-layer protocols.

Source Port of Invalid Packet

Indicates the source port number of an invalid packet.

Destination Port of Invalid Packet

Indicates the destination port number of an invalid packet.

Invalid Packet Data

Indicates at most the first 64 bytes of an invalid packet.
