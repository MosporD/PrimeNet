Modify BBP (MOD BBP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a baseband processing board (BBP).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • A baseband processing board is automatically reset if the value of Board Type, Work Mode, Hardware Capacity Enhance, CPRI Extension, CPRI Extension Mode, or Cell Channel Number Extension is modified and the value that takes effect changes.

  • The BLADEBBU does not support this function.

  • If an LBBPd (excluding LBBPd5) is installed in slot 4 or 5, the CPRI Extension Mode parameter can be set to BACKPANELEXTENSION. If an LBBPd (excluding LBBPd5) is installed in any of slots 0 to 5, the CPRI Extension Mode parameter can be set to FRONTPANELEXTENSION. Boards other than an LBBPd (excluding LBBPd5) do not support the CPRI Extension Mode parameter. If the value of the CPRI Extension Mode parameter for a board is modified and the parameter setting takes effect, the board will be automatically reset.

  • The CPRI interface type of UBBPei can be set only to XCI_QSFP.

  • The CPRI port type of a UBBPem, UBBPf1, or UBBPf0 must be set to CPRI_QSFP.

  • For an LCOP, only the baseband working mode and board specifications can be modified and its baseband working mode can only be LTE TDD.

  • When the board type is UBBP or UBBP-W, set the Base Band Work Standard parameter according to the onsite requirements. The interval for changing the baseband working standard must be longer than 3 minutes. Otherwise, the board may be reset.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the RRU chain/ring is configured on the UBBPei, UBBPem, UBBPf1, or UBBPf0 board, the networking mode must be the trunk chain. The trunk chain must be configured on the UBBP, UBBP-W, or UBRI. When the trunk chain is configured on the UBRI, only the UBRIb is supported. When the trunk chain is configured on the UBBP-W, it must be configured on port 3, 4, or 5 (except in QSA or QDA conversion scenarios).

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the board type is to be changed to UBBP or UBBP-W using this command, the Base Band Work Standard parameter must be specified based on the actual situation.

  • [Co-MPT,eNodeB,gNodeB]When the RRU chain/ring is configured on optical ports 3 to 5 of the BBP, the CPRI Extension parameter for a BBP cannot be set to ON.

  • [Co-MPT,NodeB]Among all baseband processing boards, only the WBBPd supports the hybrid working mode.

WM Work Mode

Meaning: Indicates the working mode of the baseband processing board. There are sixteen working modes: FDD, TDD, HYBRID, TDD_ENHANCE, TDD_8T8R, TDD_TL, FDD_ATG, FDD_NBIOT, NBIOT, FDD_NBIOT_ENHANCE , FDD_NBIOT_CUSTOM, NORMAL, HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, SPEC_MODE1. The Frequency Division Duplex (FDD) mode carries the traditional voice and data services. TDD is short for Time Division Duplex. The HYBRID mode is a combination of FDD and IMB modes. In Integrated Mobile Broadcasting (IMB) mode, the baseband processing board carries the mobile TV services. The value TDD_ENHANCE indicates the TDD mode integrated with the BeamForming (BF) function. The BF function provides the data transmission service in transmission modes 7 and 8 defined in protocols. For details, see 3GPP TS 36.213. In TDD_8T8R mode, the baseband processing board supports TD-LTE single-mode 8T8R. In addition, the baseband processing board supports the BF function and CPRI specifications are applied between the BBU and RRU. In TDD_TL mode, the baseband processing board supports the TD-LTE&TD-SCDMA dual mode and the TD-LTE single mode. In addition, the baseband processing board supports 8T8R BF and 2T2R Multiple-Input Multiple-Output (MIMO) and CMCC TD-LTE IR specifications are applied between the BBU and RRU. In FDD_ATG mode, the baseband processing board supports communication between Air and Ground. The FDD_ATG mode applies only to communication between air and ground. The value FDD_NBIOT indicates that the baseband processing board supports both LTE FDD and NB-IoT. The value NBIOT indicates that the baseband processing board supports NB-IoT. The value FDD_NBIOT_ENHANCE indicates that the baseband processing board supports both LTE FDD and NB-IoT and the NB-IoT capability is enhanced. The value FDD_NBIOT_CUSTOM indicates customized FDD&NB-IoT dual-mode specifications. NORMAL indicates the normal mode. HYBRID_BALANCE indicates the mixed configuration balancing mode. HYBRID_MMCELL_ENHANCE indicates the mixed configuration enhanced MM mode. HYBRID_NORMALCELL_ENHANCE indicates the mixed configuration enhanced common cell mode. SPEC_MODE1 indicates specification mode 1 of a specific BBP.

GUI Value Range: FDD(Frequency Division Duplex), TDD(Time Division Duplex), HYBRID(HYBRID), TDD_ENHANCE(Support TDD BF), TDD_8T8R(Support CPRI ports), TDD_TL(Support CMCC TDS and TDL dual modes), FDD_ATG(Support air-ground communication), FDD_NBIOT(FDD_NB-IoT), NBIOT(NB-IoT), FDD_NBIOT_ENHANCE(FDD_NB-IoT Multi-carrier), FDD_NBIOT_CUSTOM(FDD_NB-IoT Customization), NORMAL(Normal), HYBRID_BALANCE(Mixed configuration balancing), HYBRID_MMCELL_ENHANCE(Mixed configuration enhanced MM), HYBRID_NORMALCELL_ENHANCE(Mixed configuration enhanced common cell), SPEC_MODE1(BBP Specification Mode 1)

Unit: None

MML Default Value: None

CPRIEXMODE CPRI Extension Mode

Meaning: Indicates the CPRI extension mode. If this parameter is set to FRONTPANELEXTENSION, the transmission capability of a single fiber optic cable is enhanced. If this parameter is set to BACKPANELEXTENSION, the forwarding capability of the backplane is enhanced. This parameter takes effect only for LBBPd(excluding LBBPd5) boards. The value FRONTPANELEXTENSION can take effect for a board in any of slots 0 to 5, but the value BACKPANELEXTENSION can take effect only for a board in slot 4 or 5. If this parameter is set to BACKPANELEXTENSION, the board connected to the cable can only process baseband signals. If this parameter is set to BACKPANELEXTENSION, the cable can transmit data only for TDD cells when CPRI Compression is set to NORMAL_COMPRESSION. If this parameter is set to FRONTPANELEXTENSION, the cable can transmit data for TDD or FDD cells only when CPRI Compression is set to NORMAL_COMPRESSION. If the value of this parameter for a board is modified and the parameter setting takes effect, the board will be automatically reset.

GUI Value Range: FRONTPANELEXTENSION(FRONT PANEL EXTENSION), BACKPANELEXTENSION(BACK PANEL EXTENSION)

Unit: None

Actual Value Range: FRONTPANELEXTENSION, BACKPANELEXTENSION

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
BRDSPEC Board Specification

Meaning: Indicates the type of a board. If the user does not need to forcibly verify the board specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. If the user needs to forcibly verify the board specifications using the MAE-Deployment, this parameter must be set to the hardware type of the board. For example, this parameter must be set to UBBPd1 for a UBBPd1 board, this parameter must be set to UBBPe1 for a UBBPe1 board and be set to UBBPf1 for a UBBPf1 board. After this parameter is specified, the MAE-Deployment checks the configurations of the board based on the value of this parameter. This ensures that these configurations are correct before they take effect.

GUI Value Range: 0~15 characters

Unit: None

Actual Value Range: 0~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of the BRDSPEC parameter of a UBBP indicates that the UBBP may be a UBBPe or UBBPg, the BBWS parameter must not be GSM.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the value of BRDSPEC for a UBBP board contains UBBPg4 (case insensitive), BBWS can only be set to LTE_TDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of BRDSPEC of a UBBP includes UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 (case insensitive), the type of the subrack specified by SRN must not be BBU3900 or BBU3900-1U.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of BRDSPEC of a UBBP includes UBBPg3, UBBPg4, UBBPg6c or UBBPg9 (case insensitive) and the type of the subrack specified by SRN is BBU3910, SN must not be set to 4 or 5.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of BRDSPEC of a UBBP includes UBBPg3, UBBPg4, UBBPg6c or UBBPg9 (case insensitive), the type of the subrack specified by SRN is BBU3910, and SN is set to 0, BRDSPEC of the neighboring slot 4 must not include UBBPea, UBBPep, UBBPem, UBBPex2, UBBPg1a, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7, UBBPg9, UBBPf0, UBBPf1, or UBBPf3 (case insensitive).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of BRDSPEC of a UBBP includes UBBPg3, UBBPg4, UBBPg6c or UBBPg9 (case insensitive), the type of the subrack specified by SRN is BBU3910, and SN is set to 1, BRDSPEC of the neighboring slot 5 must not include UBBPea, UBBPep, UBBPem, UBBPex2, UBBPg1a, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7, UBBPg9, UBBPf0, UBBPf1, or UBBPf3 (case insensitive).

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
CCNE Cell Channel Number Extension

Meaning: Indicates the cell channel number extension switch. When this parameter is set to ON, more cell channels are supported and the distance between channels decreases. Only the UBBP supports this parameter and it takes effect only to the UBBPd9 or UBBPdc. In addition, the UBBPd9 or UBBPdc is reset after this parameter is modified. The parameter takes effect only in LTE.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the CCNE is set to ON for a BBP, the number of supported cell channels doubles and the capability of distance between channels reduces by half.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

SRT Standard Ratio

Meaning: Indicates the resource ratio of each mode. Currently, only UBBP boards support this parameter. If other baseband processing boards are used, this parameter is invalid. When the Working Standard parameter of a UBBP is set to multiple modes the Standard Ratio parameter is set to FDD_ENHANCE(FDD Enhance), TDD_ENHANCE(TDD Enhance), NBIOT_ENHANCE(NB-IoT Enhance), or NR_ENHANCE(NR Enhance), compared with the scenario where the Standard Ratio parameter is set to DEFAULT(Default), the cell specifications of this mode increase or remain unchanged and the cell specifications of other modes decrease or remain unchanged. For example, if the Working Standard parameter of a UBBPe6 is set to UMTS&LTE and the Standard Ratio parameter is set to FDD_ENHANCE(FDD Enhance), the specifications of LTE FDD cells increase and the specifications of UMTS cells decrease.

CPRIITFTYPE CPRI Interface Type

Meaning: When this parameter is set to CPRI_SFP, the port type is CPRI and the port is interconnected to the SFP module. If this parameter is set to XCI_QSFP, the port type is XCI and the port is interconnected to the QSFP module. If this parameter is set to CPRI_QSFP, the port type is CPRI_QSFP and the port is interconnected to the QSFP module. If this parameter is set to CPRI_SFPPLUS, the port type is CPRI and the port is interconnected to the DSFP module. If this parameter is set to CPRI_QSFPPLUS, the port type is CPRI and the port is interconnected to the DSFP module through a conversion connector.After the value of this parameter is changed, the board will reset.

LTEFLEXSPECSW LTE Flexible Specification Switch

Meaning: Indicates whether the specifications for LTE FDD and LTE TDD cells supported by a baseband processing board can be flexibly adjusted. When this switch is turned on, the RAT resource proportion can be flexibly allocated. In this case, a cell must be bound to a baseband processing board. When this switch is turned off, the RAT resource proportion needs to be configured. Currently, this parameter applies only to the UBBPg.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If WM in a BBP MO is set to HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, or SPEC_MODE1, LTEFLEXSPECSW must be set to OFF.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when BBWS is not set to a value which includes only LTE_FDD and LTE_TDD or includes only LTE_FDD, LTE_TDD and NBIOT, LTEFLEXSPECSW cannot be set to ON.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a BBP MO, when LTEFLEXSPECSW is set to ON, SRT cannot be set to FDD_ENHANCE, TDD_ENHANCE or NBIOT_ENHANCE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]Only the UBBP supports the LTEFLEXSPECSW parameter.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
