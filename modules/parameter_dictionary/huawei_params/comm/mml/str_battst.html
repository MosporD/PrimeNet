Start Battery Test (STR BATTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start the battery test immediately. The main purpose of the battery test is to test the capacity of the battery and to judge the quality of the battery based on the capacity.

Note

  • Before starting a battery test for the first time, you must run the MOD BATCTPA command to set parameters related to the test.

  • The purpose of the test is to check the aging level of the battery. The recommended interval of two tests is more than three months.

  • After a battery test is started, the system voltage becomes relatively low. This does not affect services. This command is applicable to both internal and external batteries.

  • An interval is required between a manually started battery test and the previous battery test. This interval can be set through the MOD BATCTPA command. If it is not specified, the default interval of 14 days is applied. If the battery test is specified to be started after power-off, a battery test is conducted by default after the AC supply to the BS is cut off. The interval between the test and the next manual battery test must also meet the preceding condition.

  • The battery test may fail to be started immediately when power supply system alarms are generated, except those related to sensor failure, abnormal cabinet temperature, and external Boolean value.

  • Before starting a battery test immediately, ensure that batteries have been added.

  • If the PMU that manages the batteries is unavailable, the command fails.

  • Run the DSP BATTR command to query the test result.

TYPE Battery Test Type

Meaning: Indicates the type of the battery test. There are two types of battery tests: STANDARD(Standard Test) and SIMPLE(Simple Test). Standard Test is used to calculate the efficiency of the battery. Simple Test is used only to judge the quality of the battery, but not to calculate the efficiency of the battery. This test takes a short time.

GUI Value Range: STANDARD(Standard Test), SIMPLE(Simple Test)

Unit: None

Actual Value Range: STANDARD, SIMPLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To start the battery test with parameters as follows: Cabinet No.: 0, Battery Test Type: STANDARD, run the following command:
STR BATTST: CN=0, TYPE=STANDARD;
