Display GPS (DSP GPS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic attributes of a specified GPS clock link.

Note

  • If the status of the satellite receiver is abnormal, you can only query part of the parameters.

  • The latitude, longitude, and altitude of the GPS antenna cannot be queried if the number of detected satellites fails to meet the requirement.

  • You are advised to run this command to query the status of different GPS clock links at an interval of no less than three minutes. This is because running this command to query the status of different GPS clock links will cause satellite card initialization, which takes a period of time (up to three minutes).

  • If the GPS clock link is not activated, the GPS working mode displayed in the execution result is invalid.

  • If the type of the satellite card is NGRU (OEM4), the values of the following parameters can also be queried: GPS Position Fixed, Fixed Position, Almanac Validity, Position Solution, Fixed Position, Clock Steering, and Clock Model Validity.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When GPS and TOD clock sources work in active/standby mode, running this command can query the status of the active clock source only. If you need to query the status of the standby clock source, switch the standby clock source to the active one and then run this command.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]If the GPS reference clock is working in standby mode, the status of the GPS reference clock will be updated 2 hours at most after the GPS reference clock is configured.

Output Description

Field Description

GPS Clock No.

Indicates the number of the GPS clock link.

GPS Card State

Indicates the physical status of the satellite card, which is specified by the value NOTEXIST (Inexistent), ANTENNASHORTED (Antenna Shorted), ANTENNAOPENED (Antenna Opened), SELF_CHECK_FAILURE (Self-check Failure), COMEXCEPTION (Star Card Communication Fault), NORMAL (Normal), UNKNOWN (Unknown Exception), USCUINVALID (USCU Invalid), or UNKNOWN_STAR_CARD (Unknown Star Card). The value of this parameter is inaccurate when the satellite card is being reset.

GPS Card Type

Indicates the physical type of the satellite card.

GPS Work Mode

Indicates the working mode of the satellite card. Satellite cards are classified into dual-mode satellite cards and single-mode satellite cards. A dual-mode satellite card supports two satellite searching modes. For example, the working mode of a BDS/GPS satellite card can be BDS prioritized or GPS prioritized. In BDS prioritized mode, the satellite card preferentially processes signals from BDS satellites. In GPS prioritized mode, the satellite card preferentially processes signals from GPS satellites. In addition, some satellite cards such as the UBOLX8M do not prioritize the BDS or GPS but process signals from both BDS satellites and GPS satellites. A single-mode satellite card supports only one satellite searching mode. For example, a GPS satellite card supports only the GPS mode.

Hold Status

Indicates the holding status of a satellite card.

GPS Satellites Traced

Indicates the number of traced GPS satellites.

GLONASS Satellites Traced

Indicates the number of traced GLONASS satellites.

BDS Satellites Traced

Indicates the number of traced BDS satellites.

GALILEO Satellites Traced

Indicates the number of traced GALILEO satellites.

Antenna Longitude(1e-6 degree)

Indicates the longitude of the GPS antenna. A negative value indicates the west longitude, and a positive value indicates the east longitude.

Antenna Latitude(1e-6 degree)

Indicates the latitude of the GPS antenna. A negative value indicates the south latitude, and a positive value indicates the north latitude.

Antenna Altitude[m(ft)]

Indicates the altitude of the GPS antenna. A negative value indicates that the GPS antenna is below the sea level, and a positive value indicates that the GPS antenna is above the sea level.

Antenna Angle(degree)

Indicates the antenna angle, which is the angle with the horizontal line. If the clock source has not been activated, the value NULL will be displayed. If the clock source has been activated, the value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Link Active State

Indicates the activation status of the GPS clock link. If the link is active, the GPS clock link is the current clock source of the system.

Feeder Delay(ns)

Indicates the feeder delay of the GPS clock link. The value is NULL when the clock source is not activated.

GPS Version

Indicates the software version and hardware version of the satellite card. NULL is displayed for the software or hardware version which does not support query. The software version and the hardware version are separated by a hyphen "-". If the connected satellite card does not support the version query or the query fails, the value is NULL.

GPS Position Fixed

Indicates whether the position of the GPS reference receiver is locked.

Almanac Validity

Indicates whether the calendar information of the GPS reference receiver is valid.

Position Solution

Indicates whether the GPS satellite positioned by the GPS reference receiver is valid.

Fixed Position

Indicates whether the position of the GPS satellite is set on the GPS reference receiver.

Clock Steering

Indicates the clock adjusting state of the GPS reference receiver, Enabled indicates that the clock adjusting state is enabled and Disabled indicates that the clock adjusting state is disabled.

Clock Model Validity

Indicates whether the clock mode of the GPS reference receiver is valid.

Position Check Switch

Indicates the position check switch of a satellite card. If this switch is turned on, the NE records the position where a satellite card is locked as the initial position and calculates the deviation between this initial position and the current position. If the deviation is excessively large, the NE regards the output signals of the satellite card unreliable and reports ALM-26120 GPS Clock Output Unavailable. The position check is applicable only when the NE position is fixed and the satellite card in the BBU supports this check.

Position Deviation[m(ft)]

Indicates the deviation between the current position and the initial position.
