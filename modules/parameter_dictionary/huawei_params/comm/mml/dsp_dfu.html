Display DFU Status (DSP DFU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the DFU status.

Note

None.

Parameters

ID Name Description
DSPMODE Display Mode

Meaning: Indicates the display mode.

GUI Value Range: BYSTATUS(By Status), BYUID(By Unit ID)

Unit: None

Actual Value Range: BYSTATUS, BYUID

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
UNITSTATUS Unit Status

Meaning: Indicates the status of the link between a DFU and its central function unit.

GUI Value Range: NORMAL(Normal), DISCONNECT(Disconnected)

Unit: None

Actual Value Range: NORMAL, DISCONNECT

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
UID Unit ID

Meaning: Indicates the ID of a DFU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To query the status of all DFUs, run the following command:
+++    0        2018-03-19 00:02:04
O&M    #805306380 
%%DSP DFU:;%%
RETCODE = 0  Operation succeeded.

Display Distributed Functional Unit Status
------------------------------------------
Unit ID  Local IP  Peer IP  Unit Status  Error Information

2        0.0.0.0   0.0.0.0  Disconnect   Invalid local IP and peer IP           
(Number of results = 1)


---    END

Output Description

Field Description

Unit ID

Indicates the ID of a DFU.

Unit Status

Indicates the status of the link between a DFU and its central function unit.

Local IP

Indicates the local IP address of the link between a DFU and its central function unit.

Peer IP

Indicates the peer IP address of the link between a DFU and its central function unit.

Error Information

Indicates the error information of the link between a DFU and its central function unit.
