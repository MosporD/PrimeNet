Remove Backplane Tunnel (RMV BACKTUNNEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a backplane tunnel.

Note

When the BACKTUNNEL MO on slot 6 or 7 is removed on the MAE-Deployment, its adaptive port transmission resource group is automatically removed, regardless of whether the transmission resource group is manually or automatically created.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of a backplane tunnel port.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove a backplane tunnel with Port ID set to 0, run the following command: 
RMV BACKTUNNEL: PORTID=0;
