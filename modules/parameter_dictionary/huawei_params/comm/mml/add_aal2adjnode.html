Add AAL2 Adjacent Node (ADD AAL2ADJNODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add an AAL2 adjacent node to a hub BS.

Multiple AAL2 adjacent nodes can be connected to a hub BS at the ATM adaptation layer type 2 (AAL2). It allows the hub BS to control access link control application part (ALCAP) processes of these AAL2 adjacent nodes.

Note

  • [Co-MPT,NodeB]Before running this command, ensure that a signaling ATM adaptation layer (SAAL) link, which is not referenced by any AAL2 node, AAL2 adjacent node, or Iub control port, has been configured.

  • [Co-MPT,NodeB]Before running this command, ensure that a HUB-type AAL2 node has been configured.

  • [Co-MPT,NodeB]The ATM address of an AAL2 adjacent node must be different from that of any other AAL2 adjacent node or of the AAL2 node.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT/UMDU is the main control board, a maximum of 32 AAL2 adjacent nodes can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 32 AAL2 adjacent nodes can be configured on a WMPT/UMPTa/UMPTb/UMDU/UTRP (subboard type: UAEC).

Parameters

ID Name Description
ANI Adjacent Node ID

Meaning: Indicates an AAL2 adjacent node ID.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ADDR ATM Address

Meaning: Indicates the ATM address of an AAL2 adjacent node. The value of this parameter is a 40-character hexadecimal character string with or without the prefix H' or h'. For example, H'3902030405060708090001020304050607080900. The ATM address must begin with 39, 45, 47, or 49 in compliance with the protocol.

GUI Value Range: Valid ATM address

Unit: None

Actual Value Range: Valid ATM address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In an AAL2ADJNODE MO, ADDR must be comprised of a 40-character hexadecimal string with or without the leading "H'" or "h'". Note that "H'" or "h'" is not included in the length of the string.
  • In the AAL2ADJNODE MO, ADDR can only contain digits (from 0 to 9), lower-case letters (from "a" to "f"), and upper-case letters (from "A" to "F"). In addition, it must begin with one of the following numerals: 39, 45, 47 and 49.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
LN SAAL Link No.

Meaning: Indicates the SAAL link number of an AAL2 adjacent node.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To add an AAL2 adjacent node with the parameters as follows: Adjacent Node ID: 0, ATM Address: H'3900000000000000000000000000000000000000, SAAL Link No.: 0, run the following command: 
ADD AAL2ADJNODE: ANI=0, ADDR="H'3900000000000000000000000000000000000000", LN=0;
