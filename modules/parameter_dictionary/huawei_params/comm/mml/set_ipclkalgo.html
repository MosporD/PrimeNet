Set Algorithm of IP Clock (SET IPCLKALGO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the clock algorithm parameters for an IP clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The clock algorithm takes effect only when frequency synchronization is used.

  • After the clock algorithm is modified, the filtering period changes and the IP clock maybe cannot synchronize.

  • The ATR function takes effect only when an IP clock source is configured on a UMPT, an LMPT or a UTRPc.

  • The ATR function takes effect only when time synchronization and layer-3 unicast are used, the clock protocol is IEEE 1588 V2, G.8275.2, or IEEE 1588 V2_16.1, and E2E delays are measured.

  • The performance of the ATR function varies with the sending intervals of different types of IP clock packets. It is recommended that the IP clock server and NE send clock packets at 128 packets per second. If this parameter is set to a small value, the performance of the ATR function will be affected.

  • If the networking requirements of the ATR function are not met but the ATR function is configured, the clock may fail to be locked.

Parameters

ID Name Description
ALGORITHM Algorithm

Meaning: Indicates the clock algorithm mode for the IP clock link. In DEFAULT mode that is also called the adaption mode, and the system adjusts the filtering period and sampling period based on the network quality in this mode. In CLASSA mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 2400, respectively. In CLASSB mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 4800, respectively. In CUSTOM mode, the filtering period and sampling period are set by the customer. The LTE currently does not support this function.

GUI Value Range: DEFAULT(DEFAULT), CLASSA(CLASSA), CLASSB(CLASSB), CUSTOM(CUSTOM)

Unit: None

Actual Value Range: DEFAULT, CLASSA, CLASSB, CUSTOM

MML Default Value: None

Recommended Value: DEFAULT(DEFAULT)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
FREECOUNT Free Count

Meaning: Indicates the adaptive scheduled recovery switch for an IP clock link. The function is used to make the BS and the IPCLK Server exchange handshake messages directly. The network between them transfers packages only and the packages will be filtered by the package delay vibrates which Adaptive Timing Recovery (ATR) of BS imported to the network. The time synchronization with the server will be realized.

Example

To set the algorithm of the IP clock with parameters as follows: Algorithm: CUSTOM, Free Count: 4, Search Count: 4, Hold Count: 4, Lock Count: 4, Sample Time: 16, run the following command:
SET IPCLKALGO: ALGORITHM=CUSTOM, FREECOUNT=4, SEARCHCOUNT=4, HOLDCOUNT=4, LOCKCOUNT=4, SAMPLETIME=16;
