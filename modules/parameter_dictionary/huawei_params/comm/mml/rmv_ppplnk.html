Remove PPP Link (RMV PPPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to remove a PPP link.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]After this command is executed, services are interrupted.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When a PPPLNK MO is removed on the MAE-Deployment, its adaptive port transmission resource group is automatically removed, regardless of whether the transmission resource group is manually or automatically created.

SBT Subboard Type

Parameter Relationship:

-Others:

Example

To remove a PPP link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 0, run the following command:
RMV PPPLNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PPPLNKN=0;
