Remove IPSec Policy (RMV IPSECPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an IPSec policy.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • An IPSec policy cannot be removed if it is the only policy in the IPSec policy group that is bound to a port.

  • An IPSec policy cannot be removed if it is referenced by an IPSec tunnel pair.

  • Before removing the IPSec policy of the master IKE peer, you must remove the IPSec policy of slave IKE peers corresponding to this master IKE peer.

  • When an IPSECPOLICY MO is removed, if the IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects, which the IPSECPOLICY MO directly or indirectly depends on, do not have a bearer MO (PACKETFILTER, PACKETFILTERING, IPSECBIND or IPSECBINDITF) on the board where the IPSECPOLICY MO has taken effect, the IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects will not take effect on the board.

Parameters

ID Name Description
SPGN Policy Group Name

Meaning: Indicates the name of the IPSec policy group.

GUI Value Range: 1~15 characters

Unit: None

Actual Value Range: 1~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of the Policy Group Name parameter is not case sensitive when an IPSec policy is added. The values of the Policy Group Name parameters are case sensitive for IPSec policies that are added to the same group. When an IPSec policy is to be removed, modified, queried, or referenced by other MOs or commands, the value of the Policy Group Name parameter is case sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The Policy Group Name parameter in a manually configured IPSECPOLICY MO cannot be set to a value with the SON_ prefix.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The parameter is valid only when PHASE is set to PHASE2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SPSN IPSec Sequence No.

Meaning: Indicates the sequence number (SN) of an IPsec policy. IPsec policies with an SN ranging from 1 to 10000 are configured by users. IPsec policies with an SN ranging from 10001 to 20000 are automatically generated by the system. When Direct IPSec Priorities Match Switch is set to DISABLE(Disable), the IPsec policy with a smaller SN is preferentially matched. When Direct IPSec Priorities Match Switch is set to ENABLE(Enable), the IPsec policy of the directly connected IPsec tunnel is preferentially matched. For details about the IPsec policy of the directly connected IPsec tunnel, see the meaning of the Direct IPSec Priorities Match Switch parameter.

GUI Value Range: 1~20000

Unit: None

Actual Value Range: 1~20000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of IPSec Sequence No. in IPSECPOLICY manually configured IPSECPOLICY MO must range from 1 to 10000.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The parameter is valid only when PHASE is set to PHASE2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove the IPSec policy with the parameters as follows: Policy Group Name: policy, IPSec Sequence No.: 1, run the following command:
RMV IPSECPOLICY: SPGN="policy", SPSN=1;
