List UNI Link Configuration (LST UNILNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configuration of the UNI link.

Note

None.

Parameters

None.

Example

To list the UNI link configuration, run the following command:
LST UNILNK:;
The result is shown as follows:
+++    0        2010-06-30 22:17:44                                        
O&M    #859                                                                     
%%LST UNILNK:;%%                                                                
RETCODE = 0  Operation succeeded.                                               
                                                                                
List UNI Link Configuration                                                     
---------------------------                                                     
           Cabinet No.  =  0                                                    
           Subrack No.  =  0                                                    
              Slot No.  =  6                                                    
         Subboard Type  =  Base Board                                           
              Link No.  =  1                                                    
         Scramble Mode  =  Enable                                               
16th Time Slot Support  =  Disable                                              
(Number of results = 1)                                                         
                                                                                
                                                                                
---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet housing the board where a UNI link is located.

Subrack No.

Indicates the number of the subrack housing the board where a UNI link is established.

Slot No.

Indicates the number of the slot holding the board where a UNI link is established.

Subboard Type

Indicates the type of sub-board on the board where a UNI link is established.

Link No.

Indicates the number of the UNI link, or indicates the E1/T1 port number of the board of the UNI link.

Scramble Mode

Indicates whether scrambling is applied to the UNI link.

16th Time Slot Support

Indicates whether a UNI link can use timeslot 16 among the 32 timeslots of an E1 port.
