List User Plane PLR Threshold Configuration (LST PLRTHRESHOLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the settings of the thresholds for generating and clearing user-plane excessive packet loss rate alarms of the BS.

Note

None.

Parameters

None.

Example

To list the settings of the thresholds for generating and clearing user-plane excessive packet loss rate alarms, run the following command: 
LST PLRTHRESHOLD:;
The result is shown as follows:
+++    0        2016-11-30 13:19:03
O&M    #167
%%LST PLRTHRESHOLD:;%%
RETCODE = 0  Operation succeeded.

List User Plane PLR Threshold Configuration
-------------------------------------------
   PLR Appear Threshold(per mill)  =  50
PLR Disappear Threshold(per mill)  =  10
(Number of results = 1)


---    END

Output Description

Field Description

PLR Appear Threshold(per mill)

Indicates the packet loss rate threshold above which the excessive packet loss rate alarm for the user plane is reported. When the packet loss rate on the user plane exceeds this threshold, the user-plane excessive packet loss rate alarm is reported.

PLR Disappear Threshold(per mill)

Indicates the packet loss rate threshold below which the excessive packet loss rate alarm for the user plane is cleared. When the packet loss rate on the user plane is lower than this threshold, the user-plane excessive packet loss rate alarm is cleared.
