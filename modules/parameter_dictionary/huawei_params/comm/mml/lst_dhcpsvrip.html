List IP Address of DHCP Server (LST DHCPSVRIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the DHCP server IP address.

Note

None.

Parameters

None.

Example

To list the setting of the DHCP server IP address, run the following command:
LST DHCPSVRIP:;
The result is shown as follows:
+++    0        2014-05-30 10:20:49
O&M    #2328
%%LST DHCPSVRIP:;%%
RETCODE = 0  Operation succeeded.

DHCP Server IP Address
----------------------
DHCP Server IP Address  =  10.174.146.88
  DHCP Relay IP Switch  =  Enable
         DHCP Relay IP  =  10.52.21.89
(Number of results = 1)


---    END

Output Description

Field Description

DHCP Server IP Address

Indicates the IP address of the DHCP server.

DHCP Relay IP Switch

Indicates whether to enable or disable the DHCP relay IP address. When this parameter is set to ENABLE, the DHCP relay IP address can be configured.

DHCP Relay IP

Indicates the DHCP relay IP address. When this parameter is configured, the base station uses it as the source IP address of the DHCP relay.
