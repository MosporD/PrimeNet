Display Ethernet Port Status (DSP ETHPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an Ethernet port, including the maximum transfer unit, speed, MAC address, duplex mode, physical layer status, and traffic information.

Note

  • Number of RX Packets(packet) indicates the number of correct packets received on the Ethernet port excluding that of clock packets. Number of RX Bytes(byte) indicates the number of the correct bytes received on the Ethernet port excluding that of clock packets.

  • TX Traffic and RX Traffic are calculated based on the MAC layer statistics.

  • When the Local Actual Negotiation Mode parameter is set to AUTO for an Ethernet port:

    1. If the Local Speed Parameter is set to 1000M, the value of the Peer Speed parameter is known and the values of the Peer Actual Negotiation Mode and Peer Duplex parameters are Unknown.

    2. If the Local Speed Parameter is not set to 1000M and the Local Duplex parameter is set to Full Duplex, the values of the Peer Speed and Peer Actual Negotiation Mode parameters are known and the value of the Peer Duplex parameter is Full Duplex.

    When the Speed Parameter is set to AUTO and the Local Actual Negotiation Mode parameter is set to FORCE for an electrical port, the values of the Peer Speed and Peer Actual Negotiation Mode parameters are known and the value of the Peer Duplex parameter is Unknown.

    In other cases, the values of the Peer Actual Negotiation Mode, Peer Duplex, and Peer Speed parameters are Unknown.

  • If Cabinet No., Subrack No., and Slot No. are not specified in active/standby mode, the Ethernet port information about all physical slots is displayed.

  • If Cabinet No., Subrack No., and Slot No. are specified in active/standby mode, the Ethernet port information about only the active and standby boards can be queried. The specified slot number is the logical slot number.

  • The value of Local Negotiation Mode is FORCE for the Ethernet port negotiated by the interconnection port.

  • This command can only be directly queried by ADD DEVIP to increase the address on ETHPORT, not directly by ADD IPADDR4/ADD IPADDR6 command added in INTERFACE Address on.

Example

To query the status of the Ethernet port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port No.: 0, Clear Statistic: NO, run the following command:  
DSP ETHPORT: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0, CLEAR=NO;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the Ethernet port is located.

Subrack No.

Indicates the subrack number of the board where the Ethernet port is located.

Slot No.

Indicates the slot number of the board where the Ethernet port is located.

Subboard Type

Indicates the type of sub-board on the board where the Ethernet port is located.

Port No.

Indicates the number of the Ethernet port.

Port ID

Indicates the ID of an Ethernet port, which uniquely identifies the Ethernet port. When the system automatically creates an Ethernet port, the most significant bit to the least significant bit of this parameter value indicate the cabinet number, subrack number, slot number, and port number of the Ethernet port, respectively. When Transmission Configuration Mode in the GTRANSPARA MO is set to OLD, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter is mandatory and must be unique in the system. If the ETHPORT MO is not configured, the default value 4294967295 of PORTID is displayed.

Port Attribute

Indicates whether an Ethernet port is an electrical port or optical port. When the system starts, the system binds an Ethernet port to an electrical port preferentially if the default value of the port attribute is AUTO. If the BS does not support cascading, the port attribute is set to AUTO. If this parameter is incorrectly set, services of a base station will be interrupted after the base station is reset.

Port Status

Indicates the status of the Ethernet port.

Physical Layer Status

Indicates the physical layer status of the Ethernet port.

Maximum Transmission Unit(byte)

Indicates the maximum IPv4 packet size (including the IP header) at the Ethernet port. For the UMPTa/b, UMDU, LMPT, UCCU, and UTRPc, the value of this parameter ranges from 46 to 1800. For the WMPT, GTMUb, GTMUc, UQEC, and UEOC, the value of this parameter ranges from 46 to 1500. For the UMPTe, the value of this parameter ranges from 46 to 2000. For the UMPTg and UMPTga, the value of this parameter ranges from 46 to 9000. If this parameter is set to a value greater than the maximum allowed value, the maximum allowed value takes effect. A value greater than or equal to 776 is recommended, because broadcast packets, such as DHCP packets, may experience reception or transmission failures if the maximum transmission unit is smaller than 776. If the Ethernet port is added to an Ethernet trunk, this parameter becomes invalid. The actual maximum transmission unit depends on the value set for the Ethernet trunk.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

ARP Proxy

Indicates whether to enable the ARP proxy function on the Ethernet port. If the ARP proxy function is enabled, the system serves as an ARP proxy for a loopback interface address of the base station or for an interface IP address of a lower-level base station. If this function is disabled, the system does not serve as an ARP proxy for the loopback interface IP address of the base station or for the interface IP address of a lower-level base station. To access either IP address in this case, an external device on the same subnet must be configured with a route. If the Ethernet port is added to an Ethernet trunk, this parameter becomes invalid. Whether the ARP proxy function is enabled is determined by the setting of this parameter for the Ethernet trunk.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

Flow Control

Indicates whether to enable flow control on the Ethernet port. Flow control is implemented to prevent congestion. When flow control is enabled, the RX end repeatedly sends PAUSE frames to the TX end, instructing the TX end to lower the TX rate if congestion occurs on the RX end. Upon receiving PAUSE frames, the TX end stops sending data during a period of time to prevent congestion.

MAC Address

Indicates the MAC address (six bytes) configured for the Ethernet port. The format is XXXX-XXXX-XXXX.

Loopback Status

Indicates the loopback status of the Ethernet port.

In Loopback Mode or Not

Indicates whether the Ethernet port is in the steady state of the OAM 3AH loopback response. For details, see IEEE 802.3ah.

Ethernet OAM 3AH Flag

Indicates whether the Ethernet OAM 3AH is enabled.

Number of RX Packets(packet)

Indicates the number of packets received at the Ethernet port.

Number of RX Bytes(byte)

Indicates the number of bytes received at the Ethernet port.

Number of RX CRC Error Packets(packet)

Indicates the number of CRC error packets received at the Ethernet port.

RX Traffic(byte/s)

Indicates the traffic received at the Ethernet port.

Number of TX Packets(packet)

Indicates the number of packets transmitted at the Ethernet port.

Number of TX Bytes(byte)

Indicates the number of bytes transmitted at the Ethernet port.

TX Traffic(byte/s)

Indicates the traffic transmitted at the Ethernet port.

Local Negotiation Mode

Indicates the negotiation mode of the Ethernet port.

Local Speed

Indicates the speed mode of the Ethernet port. This parameter must be set to the same value as that of the peer port.

Local Duplex

Indicates the duplex mode of the Ethernet port. If an Ethernet electrical port is used, this parameter is valid when SPEED is not set to AUTO. If an Ethernet optical port is used, this parameter must be set to FULL.

Peer Actual Negotiation Mode

Indicates the negotiation mode of the NE connecting to the Ethernet port.

Peer Speed

Indicates the speed mode of the NE connecting to the Ethernet port.

Peer Duplex

Indicates the duplex mode of the NE connecting to the Ethernet port.

Number of IPs

Indicates the number of IP addresses configured for the Ethernet port.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

IP Address List

Indicates the IP address and mask list configured for the Ethernet port.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

FEC Mode

Indicates the forward error correction (FEC) mode of the Ethernet port when it is a 25 Gbit/s optical port. When this parameter is set to RS-FEC, the transmit end adds error correction information to the data packet. The receive end uses the error correction information to correct the bit error generated during the transmission of the data packet, so as to improve the signal quality. When this parameter is set to NO-FEC, the FEC function is disabled and no error correction information is added to the transmitted packets.
