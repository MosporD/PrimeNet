Display the actual information of a baseband processing link (DSP BBPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the actual status of a baseband processing link.

Note

  • The BLADEBBU does not support this function.

  • If the interconnection is not configured or the configured interconnection is inconsistent with the physical connection, the output of this command cannot reflect the actual physical connection.

Display the actual information of a baseband processing link:
DSP BBPLNK:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board on the interconnection link.

Subrack No.

Indicates the subrack number of the board on the interconnection link.

Slot No.

Indicates the slot number of the board on the interconnection link.

Port No.

Indicates the port number of the board on the interconnection link. This port indicates the port HEI on the board panel.

Peer Cabinet No.

Indicates the cabinet number of the peer node at one end of the interconnection link. This parameter is set to NULL when there is no physical connection.

Peer Subrack No.

Indicates the subrack number of the peer node at one end of the interconnection link. This parameter is set to NULL when there is no physical connection.

Peer Slot No.

Indicates the slot number of the peer node at one end of the interconnection link. This parameter is set to NULL when there is no physical connection.

Peer Port No.

Indicates the port number of the peer node at one end of the interconnection link. This port indicates the port HEI on the board panel. This parameter is set to NULL when there is no physical connection.

CPRI Line Bit Rate(Gbit/s)

Indicates the transmission rate of the Common Public Radio Interface (CPRI). The parameter value NULL indicates that no CPRI rate is queried.

SRIO Line Bit Rate(Gbit/s)

Indicates the transmission rate of the Serial Rapid Input and Output (SRIO). The parameter value NULL indicates that no SRIO rate is queried.
