List Alarm Configuration (LST ALMCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration information of a specified alarm.

Note

  • The execution result of this command does not contain parameters related to the duration-based alarm filtering rule and times-based alarm filtering rule. To query the parameters, run the LST ALMFILTER command.

  • Use this command to list alarms in ascending order of the alarm ID.

Parameters

ID Name Description
STARTAID Start Alarm ID

Meaning: Indicates the start ID of alarms to be listed. An alarm ID specifies a type of alarms. It is the only index of an alarm item.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • STARTAID in the ALMCFGLST MO must not be greater than ENDAID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ENDAID End Alarm ID

Meaning: Indicates the end ID of alarms to be listed. An alarm ID specifies a type of alarms. It is the only index of an alarm item.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • STARTAID in the ALMCFGLST MO must not be greater than ENDAID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ALVL Alarm Level

Meaning: Indicates the alarm severity, that is the impact of the fault on services.If this parameter is not set, alarms of all levels are queried.

GUI Value Range: CRITICAL(Critical Alarm), MAJOR(Major Alarm), MINOR(Minor Alarm), WARNING(Warning)

Unit: None

Actual Value Range: CRITICAL, MAJOR, MINOR, WARNING

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SHLDFLG Shield Flag

Meaning: Indicates whether the alarm is shielded.

GUI Value Range: UNSHIELDED(Unshielded), SHIELDED(Shielded), ALL(All)

Unit: None

Actual Value Range: UNSHIELDED, SHIELDED, ALL

MML Default Value: ALL(All)

Recommended Value: ALL(All)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MODFLG Modification Flag

Meaning: Indicates whether the alarm configuration is modified, which helps query the modified configuration and restore the default configuration.

GUI Value Range: UNMODIFIED(Unmodified), MODIFIED(Modified), ALL(All)

Unit: None

Actual Value Range: UNMODIFIED, MODIFIED, ALL

MML Default Value: ALL(All)

Recommended Value: ALL(All)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CNT Count

Meaning: Indicates the number of returned records. By default, a maximum of 64 records can be listed upon each query. 0 indicates that the information about all alarms meets the requirement are reported.

GUI Value Range: 0~1000

Unit: None

Actual Value Range: 0~1000

MML Default Value: 64

Recommended Value: 64

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Example 1: To list the alarm configuration with the parameters as follows: Start Alarm ID: 1, End Alarm ID: 60000, Alarm Level: CRITICAL-1&WARNING-1, Shield Flag: UNSHIELDED, Modification Flag: ALL, Count: 3, run the following command:
LST ALMCFG: STARTAID=1, ENDAID=60000, ALVL=CRITICAL-1&WARNING-1, SHLDFLG=UNSHIELDED, CNT=3;

Output Description

Field Description

Alarm name

Indicates the alarm name.

Alarm shield flag

Indicates whether the alarm is shielded.

Modification Flag

Indicates whether the alarm configuration is modified, which helps query the modified configuration and restore the default configuration.

Original alarm severity

Indicates the alarm severity, that is the impact of the fault on services.

Original alarm shield flag

Indicates whether an alarm is shielded before modification.
