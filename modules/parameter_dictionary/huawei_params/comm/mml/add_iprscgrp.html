Add IP Transmission Resource Group (ADD IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IP transmission resource group.

Note

  • Before running this command, ensure that the physical port on which the IP transmission resource group is to be carried has already been configured.

  • The effect of running this command on boards that do not support dual rates is the same as that on boards that support only a single rate. Currently, the UMPT, UMDU, LMPT, and UTRPc support dual rates.

  • Board specifications: A maximum of 11 IP transmission resource groups can be configured on a WMPT. A maximum of 19 IP transmission resource groups can be configured on an LMPT. A maximum of 36 IP transmission resource groups can be configured on a UMPTa/UMPTb/UMDU. A maximum of 22 IP transmission resource groups can be configured on a UMPTe/UMPTg/UMPTga. If the GTMUb is the evolution scenario board, a maximum of 8 IP transmission resource groups can be configured on a GTMUb. If the GTMUc is the evolution scenario board, a maximum of 12 IP transmission resource groups can be configured on a GTMUc. A maximum of 24 IP transmission resource groups can be configured on a UTRPc. A maximum of 20 IP transmission resource groups can be configured on a UCCU. A maximum of 12 IP transmission resource groups can be configured on a UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/UBBPf0/LCOP/UBBPex2/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 10 IP transmission resource groups can be configured on a UTRP (subboard type: UEOC). A maximum of 12 IP transmission resource groups can be configured on a UTRP (subboard type: UQEC). A maximum of 24 IP transmission resource groups can be configured on a UTRP (subboard type: UAEC). A maximum of 24 IP transmission resource groups can be configured on a UTRP (subboard type: UIEC).

  • System specifications: If the WMPT is the main control board, a maximum of 64 IP transmission resource groups can be configured. If the LMPT/UMPT is the main control board, a maximum of 464 IP transmission resource groups can be configured. If the UMDU is the main control board, a maximum of 20 IP transmission resource groups can be configured.

  • Bandwidth-related parameters of an adaptive port IP transmission resource group cannot be modified, they take effect as the default values according to the board capacity. To remove the adaptive port IP transmission resource group and add a default port IP transmission resource group are needed in order to modify the bandwidth-related parameters.

  • IP transmission resource groups cannot be configured on a downlink tunnel.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth, 1 Gbit/s RX bandwidth, 1 Gbit/s TX committed burst size, 1 Gbit/s TX excessive burst size, 1 Gbit/s TX committed information rate, 1 Gbit/s RX committed information rate, 1 Gbit/s TX peak information rate, 1 Gbit/s RX peak information rate, and 1 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the UMPT/UMDU is the main control board, a maximum of two uplink tunnels can be configured with IP transmission resource groups. If the LMPT/WMPT is the main control board, a maximum of one uplink tunnel can be configured with IP transmission resource groups. For other transmission boards, no tunnel can be configured with IP transmission resource groups.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Currently, the base station supports a maximum of four modes, and therefore tunnel-based IP transmission resource groups are used only for rate limitation on uplink data streams. It is recommended that each base station with an uplink tunnel be configured with a tunnel-based IP transmission resource group whose rate configurations are the same as Port Rate Limits.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UMPTe/UMPTga can be configured with a maximum of 10 Gbit/s TX bandwidth, 10 Gbit/s RX bandwidth, 10 Gbit/s TX committed burst size, 10 Gbit/s TX excessive burst size, 10 Gbit/s TX committed information rate, 10 Gbit/s RX committed information rate, 10 Gbit/s TX peak information rate, 10 Gbit/s RX peak information rate, and 10 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth, 25 Gbit/s RX bandwidth, 25 Gbit/s TX committed burst size, 25 Gbit/s TX excessive burst size, 25 Gbit/s TX committed information rate, 25 Gbit/s RX committed information rate, 25 Gbit/s TX peak information rate, 25 Gbit/s RX peak information rate, and 25 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/UBBPf0/LCOP/UBBPex2/UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth, 40 Gbit/s RX bandwidth, 40 Gbit/s TX committed burst size, 40 Gbit/s TX excessive burst size, 40 Gbit/s TX committed information rate, 40 Gbit/s RX committed information rate, 40 Gbit/s TX peak information rate, 40 Gbit/s RX peak information rate, and 40 Gbit/s TX peak burst size. The UBBPf1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth, 100 Gbit/s RX bandwidth, 100 Gbit/s TX committed burst size, 100 Gbit/s TX excessive burst size, 100 Gbit/s TX committed information rate, 100 Gbit/s RX committed information rate, 100 Gbit/s TX peak information rate, 100 Gbit/s RX peak information rate, and 100 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one. The default values of these parameters are 1 Gbit/s. If the resource group is configured on a UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9, the bandwidth and rate need to be increased based on the actual networking.

  • [Co-MPT,NodeB,eNodeB]The UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth, 10 Gbit/s RX bandwidth, 10 Gbit/s TX committed burst size, 10 Gbit/s TX excessive burst size, 10 Gbit/s TX committed information rate, 10 Gbit/s RX committed information rate, 10 Gbit/s TX peak information rate, 10 Gbit/s RX peak information rate, and 10 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one. The default values of these parameters are 1 Gbit/s. If the resource group is configured on a UCCU, the bandwidth and rate need to be increased based on the actual networking.

  • [NodeB,eNodeB,gNodeB]In multi-mode scenarios, it is recommended that IP transmission resource groups whose PT is set to TUNNEL be configured for uplink tunnels.

  • [NodeB,eNodeB,gNodeB]The bandwidth and rate of an IP transmission resource group are calculated based on the data link layer statistics.

  • [Co-MPT,eNodeB]The LMPT board can be configured with a maximum of 360 Mbit/s TX bandwidth, 540 Mbit/s RX bandwidth, 400 Mbit/s TX committed burst size, 450 Mbit/s TX excessive burst size, 360 Mbit/s TX committed information rate, 540 Mbit/s RX committed information rate, 360 Mbit/s TX peak information rate, 540 Mbit/s RX peak information rate, and 400 Mbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,eGBTS]In the GTMUb/GTMUc board, the default port resource group of PPP link and MP group type does not support bandwidth restriction.

  • [Co-MPT,eGBTS]A maximum of four user-defined IP transmission resource groups with Bearing Port Type set to PPP(PPP Link) and MPGRP(Multi-link PPP Group) can be configured when a GTMUb board serves as a converted board.

  • [Co-MPT,NodeB]For UMTS, the system can perform flow control on a maximum of eight IP transmission resource groups.

  • [Co-MPT,eGBTS]The maximum specifications of a GTMUb are as follows: transmit bandwidth: 300 Mbit/s; receive bandwidth: 300 Mbit/s; transmit committed burst size: 600 Mbit/s; transmit excessive burst size: 600 Mbit/s; transmit committed information rate: 300 Mbit/s; transmit peak information rate: 300 Mbit/s; transmit peak burst size: 300 Mbit/s.   • [Co-MPT,eGBTS]The maximum specifications of a GTMUc are as follows: transmit bandwidth: 300 Mbit/s; receive bandwidth: 300 Mbit/s; transmit committed burst size: 600 Mbit/s; transmit excessive burst size: 600 Mbit/s; transmit committed information rate: 300 Mbit/s; transmit peak information rate: 300 Mbit/s; transmit peak burst size: 300 Mbit/s.   • [Co-MPT,NodeB]The UTRP can be configured with a maximum of 300 Mbit/s TX bandwidth and 300 Mbit/s RX bandwidth. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [NodeB]The WMPT can be configured with a maximum of 300 Mbit/s TX bandwidth and 300 Mbit/s RX bandwidth, 600 Mbit/s TX committed burst size, 600 Mbit/s TX excessive burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [NodeB]When configuring an IP transmission resource group whose bearing port type is Ethernet port or Ethernet trunk on a WMPT, set both the maximum TX and RX bandwidths of the IP transmission resource group to 100 Mbit/s. When configuring an IP transmission resource group whose bearing port type is TUNNEL on a WMPT, set both the maximum TX and RX bandwidths of the IP transmission resource group to 300 Mbit/s.

  • [eNodeB]When the main control board is an LMPT and the port type is set to PPP or MPGRP, an IP transmission resource group can be successfully added but the configuration cannot take effect.

The LMPT can be configured with a maximum of 360 Mbit/s TX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the ip transmission resource group that is carried on the PPP link.
