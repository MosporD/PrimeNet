List IP Uplink Flow Control Para (LST IPULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the parameters of the IP uplink flow control algorithm.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [NodeB]If IPULFLOWCTRLPARA are not set, their recommended values are used on physical ports.

Parameters

None.

Example

To list the settings of the IP uplink flow control parameters, run the following command: 
LST IPULFLOWCTRLPARA:;
The result is shown as follows:

Output Description

Field Description

IP Uplink Flow Control Algorithm ID

Indicates the ID of the IP UL flow control algorithm.

Port Type

Indicates the type of port where the IP UL flow control algorithm is configured.

Port ID

Indicates the ID of the port where the IP UL flow control algorithm is configured.

Bandwidth Adjustment Protection Switch

Indicates whether to adjust the IP available UL bandwidth. When this parameter is set to ON, the BS stops adjusting the available UL bandwidth of the physical port if the bit error rate (BER) on the transmission line exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

Congestion Control Switch

Indicates whether to perform congestion control. When this switch is turned on, the BS lowers the TX rate if the BS detects that links experience transmission delay or packet loss.

Congestion Control Enhancement Switch

Indicates the switch for the enhanced congestion control. When the switch is set to ON, the enhanced congestion control prevents uplink available bandwidth from sharply decreasing and uplink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

This feature requires the uplink FPDT IP GPM detection result. Before using this feature, run the ADD IPGPM or MOD IPGPM command to enable the uplink FPDT IP GPM detection function for the NodeB.

This switch can be configured only when the flow control function is enabled.

Minimum UL Available Bandwidth of Logical Port(kbit/s)

Indicates the minimum UL bandwidth of logic port.
