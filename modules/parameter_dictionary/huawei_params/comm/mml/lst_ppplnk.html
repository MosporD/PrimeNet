List PPP Link Configuration (LST PPPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the parameters of the PPP links.

Note

None.

Parameters

None.

Example

To list the configuration of the PPP links, run the following command:
LST PPPLNK:;
The result is shown as follows:

RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the PPP link is located.

Subrack No.

Indicates the subrack number of the board where the PPP link is located.

Slot No.

Indicates the slot number of the board where the PPP link is located.

Subboard Type

Indicates the type of sub-board on the board where a PPP link is located.

Link No.

Indicates the number of the PPP link.

Port ID

Indicates the ID of a PPP link, which uniquely identifies the PPP link. In the old model, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. In the new model, this parameter is mandatory and must be unique in the system.

Port No.

Indicates the number of the E1/T1 port that carries the PPP link.

Authentication Type

Indicates the mode in which the local end of a PPP link authenticates the peer end. The authentication mode is classified into No authentication, Password Authentication Protocol(PAP) authentication, and Challenge and shake Authentication Protocol(CHAP) authentication. In PAP mode, user names and passwords are transmitted explicitly on the network. If they are intercepted during transmission, a great threat to network security is caused. Therefore, the PAP is applied only to the network environment with low security requirements. With three handshakes, the CHAP provides a more secure authentication. In CHAP mode, only user accounts rather than passwords are transmitted, enhancing security compared to the PAP.

User Name

Indicates the authentication user name of the PPP link.

Password

Indicates the password for authenticating a PPP link.

Time Slot No.

Indicates the number of the ET/T1 timeslot that carries the PPP link.

Local IP

Indicates the local IP address. If this parameter is set to 0.0.0.0, this parameter needs to be negotiated.

Mask

Indicates the subnet mask of the local IP address. If this parameter is set to 0.0.0.0, it needs to be negotiated.

Peer IP

Indicates the peer IP address. If the BS is connected to an upper-level node, this address is specified according to the upper-level node. If the BS is cascaded to a lower-level node, this address must be specified. This parameter can be set to 0.0.0.0.

PPPMUX

Indicates whether to enable the PPP multiframe multiplexing function. If this parameter is set to ENABLE, multiple PPP frames are multiplexed on the PPP link to reduce the bandwidth overhead.

Maximum Length of PPP Mux Subframe (byte)

Indicates the maximum length of the PPP Multiplexing (MUX) subframe.

Maximum Length of PPP Muxframe (byte)

Indicates the maximum length of the PPP MUX frame.

PPP Muxframe Combination Timeout(ms)

Indicates the timeout duration of the PPP MUX combination.

IP Header Compression

Indicates whether to enable IP header compression.

IPHC SubOption

Indicates whether to enable IPHC suboption negotiation.

Maximum Receive Unit(byte)

Indicates the Maximum Receive Unit (MRU). If the size of a received packet is greater than the MRU value, the packet is discarded.

Protocol Field Compression

Indicates whether to enable protocol field compression.

Address and Control Field Compression

Indicates whether to enable the compression of the address field and control field.

Negotiation Time(ms)

Indicates the timeout duration for the PPP link negotiation.

PPP Fault Frame Occurrence Threshold(per mill)

Indicates the PPP frame error rate threshold above which the related alarm is generated.

PPP Fault Frame Clear Threshold(per mill)

Indicates the PPP frame error rate threshold below which the related alarm is cleared.
