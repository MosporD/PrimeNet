Add MEB (ADD MEB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a monitoring extension box (MEB). When an MEB is added, an MEB subrack and an MEB board are added at the same time.

Note

For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

Example

To add an MEB with the parameter as follows: Cabinet No.: 0, Manager Subrack No.: 60, run the following command:
ADD MEB: CN=0, MSRN=60;
