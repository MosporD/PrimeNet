Deactivate Ethernet OAM 3AH (DEA ETHOAM3AH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to deactivate the functions of the Ethernet OAM 3AH.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the Ethernet port is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the ETH3AH MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To deactivate the Ethernet OAM 3AH protocol with the parameters as follows: Slot No.: 7, Subboard Type: Base Board, Port Type: Ethernet Port, Port No.: 0, run the following command:
DEA ETHOAM3AH: SN=7, SBT=BASE_BOARD, PT=ETH, PN=0;
