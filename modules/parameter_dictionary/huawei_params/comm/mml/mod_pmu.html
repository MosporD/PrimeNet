Modify PMU (MOD PMU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a power monitoring unit (PMU).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The type of the power system cannot be changed. If the specified type of the power system differs from the original configuration, an error message is displayed.

  • The communication address 27 is used by a new monitoring device XMU. Therefore, do not set the communication address to 27 when running this command.

  • A temperature sensor and a humidity sensor monitor the temperature and humidity inside a cabinet, respectively. The PMU cannot report related alarms if it is not connected to a certain sensor. For details about whether a certain type of PMU is connected to a temperature or humidity sensor, see section "HPMI" in the related hardware description. In addition, the ATLTHD, ATUTHD, AHLTHD, and AHUTHD parameters need to be set to their default values.

  • When both the flag for power-off against time and the flag for power-off against low voltage are enabled, the load is powered off when the duration of AC power shutdown exceeds Load Shutdown Time or the battery voltage is less than Load Shutdown Voltage. After load low voltage disconnection (LLVD), the load is reconnected after AC power supply of the base station resumes or Load Shutdown Flag is set to DISABLE.

  • For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

ACCLF AC Current Limiting Flag

Meaning: Indicates whether the AC power system limits the AC input current. When this switch is turned on, the AC power system limits the AC input current to prevent the entire base station from being powered off due to the upper-level circuit breaker tripping. When this switch is turned off, the AC power system does not limit the AC input current. The maximum AC input current depends on the hardware capability of the AC power system. If the AC input current exceeds the rated current of the upper-level circuit breaker, the entire base station may be powered off.
