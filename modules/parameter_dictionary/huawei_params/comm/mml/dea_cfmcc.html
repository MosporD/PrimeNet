Deactivate CFM CC (DEA CFMCC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to deactivate continuity check (CC) for the local connectivity fault management (CFM) maintenance association end point (MEP).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The execution of this command terminates a continuity check.

  • After this command is executed, the route previously disabled because of interlock with CFM is enabled again.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the MEP belongs.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the MD Name parameter in the CFMLOCALMEP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MEP.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To deactivate CC for the local CFM MEP with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, MEP ID: 1000, run the following command: 
DEA CFMCC: MDNAME="CHINA", MANAME="SHANGHAI", MEPID=1000;
