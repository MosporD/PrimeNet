Display RRU/RFU carriers Information (DSP RXUCFGINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about carriers of an RRU or RFU.

Note

  • This operation is inapplicable when the IR protocol is used.

  • This command is supported by LampSite MPMUs and some FDD RF modules. For these FDD RF modules, the Description field value in the board manufacturing information includes "V3", "KUNLUN", or "WUYI." If this command is executed on a module other than the preceding ones, an error message is displayed.

  • The command output shows the configured power of an activated cell. In spectrum sharing scenarios, different carriers may share the same power. For details about the power sharing principles, see spectrum sharing feature description.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO where the RFU MO is located is set to BTS3900AL, the value of SN in the RFU MO ranges from 0 to 8. Otherwise, the value of SN in the RFU MO ranges from 0 to 5. When the value of SRN in the RRU MO is set to 60, SN in the RRU MO ranges from 0 to 5. When the value of SRN in the RRU MO ranges from 61 to 254, the value of SN in the RRU MO ranges from 0 to 3.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the RRU MO is set to a value greater than 0 and RT in the RRU MO is not set to MPRF, SRN in the RRU MO must be set to 60, and TYPE in the CABINET MO where the RRU MO is located must be set to RFC5906 or IFS5906.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RRU or RFU is located.

Subrack No.

Indicates the number of the subrack where the RRU or RFU is located.

Slot No.

Indicates the slot number of the RRU or RFU.

Channel No.

Indicates the number of the RRU/RFU channel. This parameter is set to 255 for the AAU which supports beamforming and such an AAU supports the query only by module.

Channel Type

Indicates the type of an RRU/RFU channel.

Carrier Index

Indicates the carrier index of the RRU/RFU.

Carrier RAT

Indicates the carrier RAT of the RRU/RFU.

Carrier Power(mW)

Indicates the carrier power of the RRU/RFU.

TRX Power Set(mW)

Indicates the TRX power set of the RRU/RFU.

Carrier UL Freq. Band Higher Limit(0.1MHz)

Indicates the upper limit of the uplink frequency band used by the carrier of the RRU/RFU.

Set of TRX UL Freq. Band Higher Limits(0.1MHz)

Indicates the set of the upper limits of the uplink frequency bands used by the TRXs of the RRU/RFU.

Carrier UL Freq. Band Lower Limit(0.1MHz)

Indicates the lower limit of the uplink frequency band used by the carrier of the RRU/RFU.

Set of TRX UL Freq. Band Lower Limits(0.1MHz)

Indicates the set of the lower limits of the uplink frequency bands used by the TRXs of the RRU/RFU.

Carrier DL Freq. Band Higher Limit(0.1MHz)

Indicates the upper limit of the downlink frequency band used by the carrier of the RRU/RFU.

Set of TRX DL Freq. Band Higher Limits(0.1MHz)

Indicates the set of the upper limits of the downlink frequency bands used by the TRXs of the RRU/RFU.

Carrier DL Freq. Band Lower Limit(0.1MHz)

Indicates the lower limit of the downlink frequency band used by the carrier of the RRU/RFU.

Set of TRX DL Freq. Band Lower Limits(0.1MHz)

Indicates the set of the lower limits of the downlink frequency bands used by the TRXs of the RRU/RFU.
