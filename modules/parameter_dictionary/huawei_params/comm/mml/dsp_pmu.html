Display PMU (DSP PMU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a power monitoring unit (PMU), which include the information about the PMU, PSU, and batteries.

Note

If the operational status of the PMU is unavailable, the query fails.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the PMU is located.

Subrack No.

Indicates the number of the subrack where the PMU is located.

Slot No.

Indicates the number of the slot where the PMU is located.

Current Limiting State

Indicates whether the batteries that are being charged are in the current limiting status.Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Secondary Load Power State

Indicates the power-on status of the secondary load. The secondary load can be set to automatically powered off in the following modes: HighTemperaturePowerOff(High temperature power off), LowTemperaturePowerOff(Low temperature power off), and LowVoltagePowerOff(Low voltage power off).

Load Shutdown Time Capability

Indicates whether the PMU supports powering off the load against time.

Power Distribution Slot No-Backup Capability

Indicates whether the power distribution slots support the no-backup capability.

Busbar Voltage(V)

Indicates the DC output voltage of the busbar.

Load Total Current(A)

Indicates the total load current. The total load current is the sum of current supplied by all the DC output terminals on the power subrack.

Battery Current(A)

Indicates the charging or discharging current of batteries.

Photovoltaic Array Total Current(A)

Indicates the total current of the photovoltaic array of the PMU.

Diesel Generator Current(A)

Indicates the current of the diesel generator which is managed by the PMU.

AC Voltage(V)

Indicates the current AC voltage, that is, the input mains voltage to the rectifier.

AC Current Limiting Capability

Indicates the capability of the PMU to limit the AC input current.

AC Current Limiting Flag

Indicates whether the AC power system limits the AC input current. When this switch is turned on, the AC power system limits the AC input current to prevent the entire base station from being powered off due to the upper-level circuit breaker tripping. When this switch is turned off, the AC power system does not limit the AC input current. The maximum AC input current depends on the hardware capability of the AC power system. If the AC input current exceeds the rated current of the upper-level circuit breaker, the entire base station may be powered off.

AC Air Switch Current Limiting Threshold(A)

Indicates the AC input current threshold of the AC power system. After the AC current limiting function takes effect, the AC power system limits the AC input current so that the AC input current does not exceed the AC current threshold.

AC Phase Type

Indicates the external AC phase type of the AC power system.

Temperature[degree Celsius(degree Fahrenheit)]

Indicates the internal ambient temperature of the cabinet. Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Cabinet Humidity(%)

Indicates the internal ambient humidity of the cabinet. Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Auxiliary Battery Cabinet Temperature[degree Celsius(degree Fahrenheit)]

Indicates the temperature of auxiliary battery cabinet which is connected to the PMU.Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Software Version

Indicates the software version of the PMU.

PCB Version

Indicates the PCB version of the PMU.

EPLD Version

Indicates the erasable programmable logic device version of the PMU.

Software Build Time

Indicate the software compiling time of the PMU.

Version Description

Indicates the version description of the PMU.

Produce Date

Indicates the manufacturing date of the PMU.

PSU Intelligent Shutdown Capability

Indicates the PSU intelligent shutdown capability of the PMU.

PSU Intelligent Shutdown Switch

Indicates the status of the PSU intelligent shutdown switch of the PMU.

Battery Intelligent Management Capability

Indicates the battery intelligent management capability of the PMU.

Battery Intelligent Management Mode

Indicates the battery intelligent management mode of the PMU.Value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

BDU Management Capability

Indicates the management capability of the BDU.

Inner Cycle Fan Average Speed(r/min)

Indicates the average rotation speed of the inner circulation fan per minute.The value 0 indicates that the fan stops rotating or the hardware is faulty. The value NULL indicates that the hardware capability query does not apply to this parameter.

Outer Cycle Fan Average Speed(r/min)

Indicates the average rotation speed of the outer circulation fan per minute.The value 0 indicates that the fan stops rotating or the hardware is faulty. The value NULL indicates that the hardware capability query does not apply to this parameter.
