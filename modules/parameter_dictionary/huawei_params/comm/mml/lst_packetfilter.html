List Packet Filter Configuration (LST PACKETFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of all packet filtering objects.

Note

None.

Parameters

None.

Example

To list the configuration of all packet filters, run the following command:
LST PACKETFILTER:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the packet filtering is used.

Subrack No.

Indicates the subrack number of the board where the packet filtering is used.

Slot No.

Indicates the slot number of the board where the packet filtering is used.

Subboard Type

Indicates the subboard type of the board where the packet filtering is used.

Port Type

Indicates the port type. This parameter cannot be set to SUBIF for UMTS.

Port No.

Indicates the port number.

Filter Mode

Indicates the packet filtering mode. The BS can filter packets based on the advanced ACL, layer-2 ACL, or both at the same time.

Advanced ACL ID

Indicates the ID of an advanced ACL. The value of this parameter ranges from 3000 to 3999.

Layer 2 ACL ID

Indicates the ID of an ACL at layer 2. The value of this parameter ranges from 4000 to 4999. The BS filters packets based on only VLAN IDs.

Match Behavior

Indicates whether to permit or reject access of the data that does not match the ACL rule. If this parameter is set to PERMIT, data that does not match the ACL rule is allowed to pass. If this parameter is set to DENY, data that does not match the ACL rule is discarded.

ACL Rule Automatic Setup and Deletion Switch

Indicates whether to enable the advanced ACL auto-setup function for packet filtering. After this switch is enabled, ACL rules in the ACL group referenced by a packet filtering object are automatically created and these ACL rules match the following data flows: OM channels, manually created SCTP links, manually created IP paths, time services, clock services, manually created IKE peers, and PKI. When the MOD PACKETFILTER command is executed to change the value of this parameter from ON(ON) to OFF(OFF), the system will automatically delete the advanced ACL rules that are automatically created in the ACL group referenced by the packet filtering object.

OMCH Peer IP Limit Switch

Indicates whether the peer IP address is limited by the ACL rules that have been automatically generated for the OM channel when the ACL rule automatic setup and deletion function is enabled. When this parameter is set to ON(ON), the peer IP address must be the IP address of the MAE. In this case, if any one of the NetEco, TraceServer, and NIC is independently deployed, the ACL rules must be manually configured before the preceding device can access the base station.
