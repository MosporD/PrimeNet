Display LLDP Remote Info (DSP LLDPNEIGHBORINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about an LLDP neighbor.

Note

LLDP IDs in the range of 0 to 47 are used for remote information associated with LLDP local entities that are configured by users. LLDP IDs greater than 47 are used for remote information associated with LLDP local entities that are automatically generated by the system.

Parameters

ID Name Description
LLDPID LLDP ID

Meaning: Indicates the ID of an LLDP local entity.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the LLDP Remote information with the parameters as follows: LLDP ID: 1, run the following command:
DSP LLDPNEIGHBORINFO: LLDPID=1;
The result is shown as follows:

Output Description

Field Description

LLDP ID

Indicates the ID of an LLDP local entity.

Ethernet Port ID

Indicates the ID of the Ethernet port on the board to which the LLDP local information belongs.

Cabinet No.

Indicates the cabinet number of the board where the LLDPLOCAL is located.

Subrack No.

Indicates the subrack number of the board where the LLDPLOCAL is located.

Slot No.

Indicates the slot number of the board where the LLDPLOCAL is located.

Port No.

Indicates the number of the Ethernet port where the LLDPLOCAL is located.

Chassis ID Subtype

Indicates the subtype of a chassis ID.

Chassis ID

Indicates the chassis ID of a device. The port that receives LLDP information can use Chassis ID and Port ID to identify a peer device.

Port ID Subtype

Indicates the subtype of a port ID.

Port ID

Indicates the ID of a port.

Port Description

Indicates the description of an LLDP port.

System Name

Indicates the system name.

System Description

Indicates the system description, such as the vendor, device name, hardware type, and version information about the software operating system. Such system data is useful in collecting the network traffic.

System Capabilities Supported

Indicates the capabilities supported by the system. The capabilities reflect the main functions of the system. A single system can provide multiple functions, such as routing, bridge, and relay.

System Capabilities Enabled

Indicates the enabled system capabilities.

Management Address Type

Indicates the type of a management address.

Management Address

Indicates the management address that the network management system uses to manage and identify a network device.

Port VLAN ID

Indicates the ID of the VLAN to which the port of a Layer 2 switch (bridge) belongs. A port can have at most one port VLAN ID. Value 0 indicates that the port does not support VLANs or the port is not configured with a VLAN.

Port and Protocol VLAN Supported

Indicates whether to support the port and protocol VLAN, which is an untagged VLAN for a port. This untagged VLAN can map packets to packets with specified VLANs according to specific rules. When a packet enters a port with an untagged VLAN, the packet is tagged with a specific VLAN. When the packet leaves the port with an untagged VLAN, the tagged VLAN is removed from the packet. The port and protocol VLAN can be configured for LLDP communication or not. However, the port and protocol VLAN helps users grasp the system configuration.

Port and Protocol VLAN Enabled

Indicates whether to enable port and protocol VLAN.

Auto-negotiation Supported

Indicates whether to support auto negotiation. In auto negotiation mode, a connection can be set up even if different duplex modes or data rates are configured at both ends.

Auto-negotiation Enabled

Indicates whether to enable automatic negotiation.

MAU

Indicates the medium attachment unit (MAU) of an Ethernet port. All MAUs are named according to IEEE standards. Value AUI indicates the attachment unit interface. Value Foirl indicates fiber optic inter repeater link. Value 10Broad36 indicates a 10 Mbit/s Ethernet that uses coaxial cables. All other MAUs are named in the format of "digits+Base+type", where, digits indicate the maximum transmit rate (for example, 10 indicates the maximum transmit rate of 10 Mbit/s), Base indicates that baseband transmission is used to transmit signals, and types have the following meanings: T indicates unshielded twisted pair (UTP) cables, 5 indicates thick coaxial cables, 2 indicates thin coaxial cables, X indicates the 8B/10B encoding scheme with 8-bit data and 2-bit error correction data, TX indicates category 5 twisted pair, FD indicates full duplex (for example, 1000BaseXFD indicates full duplex of 1000BaseX), and HD indicates half duplex. For details about other types, see RFC3636.

Link Aggregation Supported

Indicates whether an LLDP port has been added to an Ethernet trunk link.

Link Aggregation Enabled

Indicates whether to enable link aggregation.

Aggregation Port ID

Indicates the trunk number of the Ethernet trunk link to which an LLDP port has been added.

Maximum Frame Size(frame)

Indicates the maximum frame length. When the value of the Maximum Frame Size parameter is 0, the base station cannot detect any valid maximum frame size.

Expired Time(s)

Indicates the aging time of the information about the neighboring LLDP port. When the aging time is 0 and the local end does not receive update information about the neighboring LLDP port, the neighboring LLDP port information will be aging out.

Number of VLAN Name

Indicates the number of VLAN names recorded in the VLAN name list.

VLAN Name List

Indicates the list of VLAN names. A VLAN name list consists of three fields: VLAN ID, bracket, and VLAN name. A VLAN name list supports a maximum of 32 VLAN names.

Number of Port and Protocol VLAN ID

Indicates the number of port and protocol VLAN IDs.

Port and Protocol VLAN ID List

Indicates the list of port and protocol VLAN ID. The system supports a maximum of 16 port and protocol VLAN IDs.
