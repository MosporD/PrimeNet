List IMA Link Configuration (LST IMALNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the IMA link configuration.

Note

None.

Parameters

None.

Example

To list the IMA link configuration, run the following command:
LST IMALNK:;
The result is shown as follows:
+++    0        2010-06-30 19:49:09                                        
O&M    #245                                                                     
%%LST IMALNK:;%%                                                                
RETCODE = 0  Operation succeeded.                                               
                                                                                
List IMA Link Configuration                                                     
---------------------------                                                     
            Cabinet No.  =  0                                                   
            Subrack No.  =  0                                                   
               Slot No.  =  6                                                   
          Subboard Type  =  Base Board                                          
               Link No.  =  0                                                   
IMA Group Subboard Type  =  Base Board                                          
          IMA Group No.  =  0                                                   
(Number of results = 1)                                                         
                                                                                
                                                                                
---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board of the IMA link.

Subrack No.

Indicates the subrack number of the board of the IMA link.

Slot No.

Indicates the slot number of the board of the IMA link.

Subboard Type

Indicates the type of sub-board on the board where the IMA link is established.

Link No.

Indicates the number of the IMA link, or indicates the E1/T1 port number of the board of the IMA link.

IMA Group Subboard Type

Indicates the type of sub-board on the board where the IMA group containing an IMA link is established.

IMA Group No.

Indicates the IMA group number of the IMA link.
