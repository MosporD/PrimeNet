Display NTP Client State (DSP NTPC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the running state of a Network Time Protocol client (NTPC).

Note

  • If you run this command before the NE synchronizes the time initially, an "Unfinished the first synchronization." message is displayed.

  • If multiple NTPCs are configured, only the NTPC in use is displayed.

  • [Co-MPT,NodeB,eNodeB,gNodeB]In IPv4 scenarios, if no remote maintenance channel is configured, the IP address of the NTP client is displayed as NULL.

Parameters

None.

Example

To display the running state of an NTPC, run the following command:
DSP NTPC:;
The result is shown as follows:
+++    0        2011-10-20 15:31:55
O&M    #1444
%%DSP NTPC:;%%
RETCODE = 0  Operation succeeded.

Display NTP Client State
------------------------
Link State of Current NTP Server = Available
IP Address of Current NTP Server = 192.168.0.1
        IP Address of NTP Client = 192.168.0.2
(Number of results = 1)


---    END

Output Description

Field Description

Link State of Current NTP Server

Indicates the link state of the NTP server.

IP Address of Current NTP Server

Indicates the IP address for the current NTP server.

IP Address of NTP Client

Indicates the IP address for the NTP Client.
