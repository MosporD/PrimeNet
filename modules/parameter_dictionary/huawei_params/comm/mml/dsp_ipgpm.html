Display IP General Performance Management Status (DSP IPGPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the state of an IP GPM detection.

Note

None.

Parameters

ID Name Description
IPGPMID IP GPM Detection ID

Meaning: Indicates the ID of an IP GPM detection.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To query IP General Performance Management Status, run the following command: 
DSP IPGPM:;
The result is shown as follows:

Output Description

Field Description

IP GPM Detection ID

Indicates the ID of an IP GPM detection.

Detection Direction

Indicates the direction of an IP GPM detection.

Delay Detection Method

Indicates the delay detection method at the bottom layer used by the IP GPM detection.

Detection Object

Indicates the object to be detected by the IP GPM on the base station side. If the detection object is IPRSCGRP, the IP GPM detects congestion on transmission links of users in the IP transmission resource group.

Cabinet No.

Indicates the cabinet No. of the board where the IP transmission resource group detected by the IP GPM is located.

Subrack No.

Indicates the subrack No. of the board where the IP transmission resource group detected by the IP GPM is located.

Slot No.

Indicates the slot No. of the board where the IP transmission resource group detected by the IP GPM is located.

Port Type

Indicates the type of the port where an IP transmission resource group detected by the IP GPM is carried.

Port ID

Indicates the ID of the port where an IP transmission resource group detected by the IP GPM is carried.

IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group detected by the IP GPM.

Working State

Indicates the working state of an IP GPM detection. If the number of samples within an IP GPM detection period is 0, the working state of the IP GPM detection is "NO_MEASUREMENT". If the number of samples within an IP GPM detection period is greater than 0, the working state of the IP GPM detection is "IN_MEASUREMENT".
