Display IP Transmission Resource Group Status (DSP IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an IP transmission resource group.

Note

  • [eNodeB,gNodeB]In the execution result of this command, the returned bearing port No. is the number of the physical port that carries the IP transmission resource group. The value of this parameter is different from the previously configured one if there has been a resource group switchover.

  • [eNodeB,gNodeB]The real-time and non-real-time service traffic as well as non-real-time reserved TX and RX bandwidths of an IP transmission resource group are measured based on the statistics at the IP layer. Other TX and RX bandwidths, admission bandwidth, and actual traffic of the resource group are measured based on the statistics at the data link layer.

  • [eNodeB,gNodeB]In the execution result of this command, the real-time and non-real-time traffic measures traffic created by the real-time and non-real-time user plane packets carried on the IP transmission resource group, respectively. These user plane packets consist of the user plane packets on all IP paths associated with this IP transmission resource group, and do not include the forwarded packets.

  • [eNodeB,gNodeB]"Realtime TX Bandwidth", "Non-Realtime TX Bandwidth", "GBR Tx Bandwidth" specify the service traffic before traffic shaping. "Realtime Tx Traffic" specifies the service traffic after traffic shaping.

Parameters

ID Name Description
IPRSCGRPID IP Transmission Resource Group ID

Meaning: Indicates the ID of the IP transmission resource group.

GUI Value Range: 0~150014

Unit: None

Actual Value Range: 0~150014

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query Status of IP Transmission Resource Group with the parameters as follows: IP Transmission Resource Group ID: 10, run the following command:
DSP IPRSCGRP: IPRSCGRPID=10;
The result is shown as follows:

Output Description

Field Description

IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group.

Cabinet No.

Indicates the number of the cabinet that houses the board where an IP transmission resource group is established.

Subrack No.

Indicates the number of the subrack that houses the board where an IP transmission resource group is established.

Slot No.

Indicates the number of the slot corresponding to the board where an IP transmission resource group is established.

Subboard Type

Indicates the type of sub-board on the IP transmission group. The LTE and NR do not support UNCHANNELLED_COVERBOARD.

Bearing Port Type

Indicates the type of port where an IP transmission resource group is carried.

Bearing Port No.

Indicates the number of the bearing that houses the board where an IP transmission resource group is established.

Bearing Port ID

Indicates the ID of the port where the IP transmission resource group is configured.

Resource Group Number

Indicates the number of an IP transmission resource group on a port. When you use an MML command to add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, a tunnel, or a PPPoE link, the system automatically creates an IP transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port). When you remove any of the preceding objects, the system automatically removes the IP transmission resource group. When you add a PPP link, an MP group, an Ethernet port, an Ethernet trunk, or an uplink tunnel on the MAE-Deployment, if there is no default port and auto port IP transmission resource group, the system automatically creates an IP transmission resource group with Transmission Resource Group ID set to AUTOPORT(Autoport Port), The Transmission Resource Group ID is created by using the port type and port ID combination of the corresponding port, it is recommended to set the Transmission Resource Group ID of the user-defined resource group to 0 to 59999 to avoid Transmission Resource Group ID conflict. When you remove any of the preceding objects on the MAE-Deployment, the system automatically removes the IP transmission resource group.

Rate Unit

Indicates the rate unit of the TX bandwidth, RX bandwidth, TX CIR, RX CIR, TX PIR and RX PIR of the IP transmission resource group.

Realtime TX Bandwidth

Indicates the local real-time traffic that is transmitted in an IP transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE.

Realtime RX Bandwidth

Indicates the local real-time traffic that is received in an IP transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE.

Non-Realtime TX Bandwidth

Indicates the local non-real-time traffic that is transmitted in an IP transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE.

Non-Realtime RX Bandwidth

Indicates the local non-real-time traffic that is received in an IP transmission resource group. The local traffic includes only the local traffic stream exclusive of the passing-by data flow and non-traffic stream. The parameter takes effect only in LTE.

Non-Realtime Reserved TX Bandwidth

Indicates the TX bandwidth reserved for non-real-time services in an IP transmission resource group. The parameter takes effect only in LTE and NR.

Non-Realtime Reserved RX Bandwidth

Indicates the RX bandwidth reserved for non-real-time services in an IP transmission resource group. The parameter takes effect only in LTE and NR.

TX Bandwidth

Indicates the maximum uplink bandwidth of an IP transmission resource group at the MAC layer. This parameter value is used as the uplink transport admission bandwidth and TX traffic shaping bandwidth. The minimum rate supported by the UMPTa, UMPTb, UMDU, GTMUb or GTMUc is 64 kbit/s. The LMPT can be configured with a maximum of 360 Mbit/s TX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s TX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the ip transmission resource group that is carried on the PPP link.

RX Bandwidth

Indicates the RX bandwidth of an IP transmission resource group. To LTE, this parameter value is also used as the downlink transport admission bandwidth. The LMPT can be configured with a maximum of 540 Mbit/s RX bandwidth. The WMPT, GTMUb or GTMUc can be configured with a maximum of 300 Mbit/s RX bandwidth. The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s RX bandwidth. The UMPTe, UMPTga or UCCU can be configured with a maximum of 10 Gbit/s RX bandwidth. The UMPTg can be configured with a maximum of 25 Gbit/s RX bandwidth. The UBBPe, UBBPei, UBBPep, UBBPem, LCOP, UBBPex2, UBBPf0 or UBBPg1 can be configured with a maximum of 40 Gbit/s RX bandwidth. The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s RX bandwidth. The value of RX bandwidth is set to the maximum value of RX bandwidth supported by the board when it bigger than the maximum one.

TX Bandwidth Used

Indicates the TX bandwidth that is already used by an IP transmission resource group.

RX Bandwidth Used

Indicates the RX bandwidth that are already used by an IP transmission resource group.

TX Bandwidth Usable

Indicates the TX bandwidth that can be used by an IP transmission resource group.

RX Bandwidth Usable

Indicates the RX bandwidth that can be used by an IP transmission resource group.

GBR TX Bandwidth

Indicates the GBR service traffic that is transmitted by the IP transmission resource group. The parameter takes effect only in LTE and NR.

GBR RX Bandwidth

Indicates the GBR service traffic received by the IP transmission resource group. The parameter takes effect only in LTE and NR.

Rate Configuration Type

Indicates the rate configuration mode of the IP transmission resource group.

UL Admission Bandwidth

Indicates the uplink admission bandwidth of the IP transmission resource group. When Physical Port Up Link OverBooking Switch is ON in the command output of the LST TACALG command, the value of this parameter can exceed the uplink bandwidth of the physical port. The parameter takes effect only in LTE and NR.

DL Admission Bandwidth

Indicates the downlink admission bandwidth of the IP transmission resource group. When Physical Port Down Link OverBooking Switch is ON in the command output of the LST TACALG command, the value of this parameter can exceed the downlink bandwidth of the physical port. The parameter takes effect only in LTE and NR.

UL CIR Admission Bandwidth

Indicates the UL Committed Information Rate (CIR) admission bandwidth for the IP transmission resource group. The parameter takes effect only in LTE and NR.

DL CIR Admission Bandwidth

Indicates the CIR admission bandwidth of the IP transmission resource group in DL. The parameter takes effect only in LTE and NR.

UL PIR Admission Bandwidth

Indicates the UL PIR admission bandwidth of the IP transmission resource group. The parameter takes effect only in LTE and NR.

DL PIR Admission Bandwidth

Indicates the PIR admission bandwidth of the IP transmission resource group in DL. The parameter takes effect only in LTE and NR.

Realtime TX Traffic(byte/s)

Indicates the realtime traffic sent on an IP transmission resource group.
