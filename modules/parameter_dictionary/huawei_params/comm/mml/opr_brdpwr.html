Power On/Off Board (OPR BRDPWR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to perform power-on and power-off of a board. If a board in the BBU subrack is not carrying services, you can power off the board to save power. To use the board, you can power on it again. In a dual-mode BS, this command can be run to power on or off a board of the other mode. The service carried on the board is interrupted after the power-off.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only the boards (excluding the FAN unit, UPEU, and UEIU) in the BBUs housing the main control boards of the current mode can be powered on or off.

  • The configured UTRP and UCIU cannot be powered off.

  • The active main control or slave control boards of the local mode cannot be powered off.

  • To power on a board that is powered off through the OPR BRDPWR command, you must run the OPR BRDPWR command.

  • If a board is powered off, services carried on the board is interrupted.

  • If a board is powered off by running this command on one side of a multi-mode BS, it cannot be powered on by running this command on the other side.

  • If the multi-mode base station is in the co-transmission mode, powering off the MPT and UTRP of another mode will interrupt the transmission and connection between the base station and base station controller.

  • Forced Power-off Flag of the USCU can be set only to YES.

  • It is recommended that this command be not executed when ALM-26101 Inter-Board CANBUS Communication Failure is reported, as the user fails to power on/off the board or obtain the board electronic label. When the Forced Power-off Flag parameter is set to NO, it would be reset the board instead of power-off.

  • When ALM-25621 Power Supply DC Output Out of Range is reported and the active main control board is powered off or reset through power-off, boards that are powered off using this command may be powered on.

  • In a dual-mode base station, when running this command to power on or off a non-common board in the peer mode, set Forced Power-off Flag to YES.

SW Power Switch

Meaning: Indicates whether the board is powered on. Only the power-on status of the boards in the BBU can be precisely checked.

GUI Value Range: OFF(Off), ON(On)

Actual Value Range: OFF, ON

MML Default Value: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
FOCPWROFF Forced Power-off Flag

Meaning: Indicates whether to forcibly power off a board. When this parameter is set to NO, the system performs a security exit on this board and then powers off this board. When this parameter is set to YES, the system forcibly resets this board. It is recommended that this parameter be set to NO in normal scenarios.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(NO)

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To power off a board with parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 2, run the following command:
OPR BRDPWR: CN=0, SRN=0, SN=2, SW=OFF;
