Clear EMU Smoke and Burglar Alarms (CLR EMUALM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to clear an environment monitoring unit (EMU) smoke or burglary alarm. When an EMU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.

Note

After the command is executed, if the fault that triggers the alarm persists, the alarm is reported again. To actually clear the alarm, go to the site to observe the situation and perform troubleshooting.

Example

To clear an EMU smoke or burglar alarm, run the following command with all parameters set their default values:
