Modify IPv6 ACL Rule (MOD ACLRULE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify an IPv6 Access Control List (ACL) rule.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]Running this command may interrupt the services that reference the IPv6 ACL rule. For details, see "Service Interrupted After Modification" of each parameter.

  • [Co-MPT,eNodeB,gNodeB]If an ACLRULE6 can be queried by running the LST ACLRULE6 command and the value of the "Auto Config Flag" field is "Auto Created", the ACLRULE6 object is automatically created by the system and cannot be modified by users.

  • [Co-MPT,eNodeB,gNodeB]If an IPv6 ACL rule used by an IPSec policy has Protocol Type set to a non-IP type, Match Source Port set to Yes, or Match Destination Port set to Yes, ensure that the IPv6 ACL rule contains PMTU data flows. Otherwise, PMTU data flows will be discarded and PMTU discovery will fail.

Parameters

ID Name Description
ACLID IPv6 ACL ID

Meaning: Indicates the ID of an IPv6 access control list (ACL) to which the IPv6 access control rule belongs.

GUI Value Range: 3000~3999,7000~7999

Unit: None

Actual Value Range: 3000~3999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
RULEID IPv6 Rule ID

Meaning: Indicates the ID of an IPv6 ACL rule. The values 1 to 65535 indicate IPv6 ACL rules configured by users. The values 65431 to 65536 indicate the IPv6 ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate packet filtering IPv6 ACL rules configured by the system (packet filtering ACL rules are not supported in IPv6 configuration currently). The values 80000 to 89999 indicate IPv6 IPsec ACL rules configured by the system.

GUI Value Range: 1~65535,70000~89999

Unit: None

Actual Value Range: 1~65535,70000~79999,80000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify an IPv6 ACL rule with the parameters as follows: IPv6 ACL ID: 3000, IPv6 Rule ID: 10, Source IPv6 Address: 2001:DB8::2, Source Address Prefix Length: 32, Destination IPv6 Address: 2001:DB8::1, Destination Address Prefix Length: 32, run the following command: 
MOD ACLRULE6: ACLID=3000, RULEID=10, SIP="2001:DB8::2", SPFXLEN=32, DIP="2001:DB8::1", DPFXLEN=32;
