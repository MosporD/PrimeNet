Activate OM Channel Automatic Establishment Configuration (ACT DHCPCFG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to update the user configurations of the OMCH, IP route, and IPv6 route based on the automatic OMCH establishment result after the automatic OMCH establishment detection is successful. Other transmission parameter settings take effect based on the user configurations, and the base station exits from the automatic OMCH establishment status.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This operation may interrupt the local maintenance channel.

  • If Effect Type is set to CHKRSLT and the NE transmits data through Ethernet ports, the NE automatically checks whether the user configurations are consistent with the automatic OMCH establishment result. If they are inconsistent, the command execution will fail. In this case, run the DSP DHCPRSLT command to query the inconsistent data and then correct it. If you are sure that the OM channel can be set up based on the current configuration, run this command with Effect Type set to FORCE_EFT.

  • [Co-MPT,eNodeB,gNodeB]If the OMCH settings are manually added or modified after the OMCH is automatically established, user configurations of the OMCH, IP route, and IPv6 route will not be updated based on the automatic OMCH establishment result.

  • [Co-MPT,NodeB,eNodeB]After this command is executed, the configuration of the remote maintenance channel is refreshed automatically according to the results of automatic remote maintenance channel establishment. Before running this command, ensure that other related configurations of the remote maintenance channel are available. If the remote maintenance channel is carried on an Ethernet link or Ethernet link aggregation group, ensure that the device IP address or IPv4 address, or IPv6 address has been configured for the corresponding Ethernet port or Ethernet link aggregation group. If the remote maintenance channel is carried on a PPP link or MLPPP group, ensure that the corresponding PPP link or MLPPP group has been configured.

  • [NodeB,eGBTS]If the OMCH settings are manually added or modified after the OMCH is automatically established, user configurations of the OMCH, IP route will not be updated based on the automatic OMCH establishment result.

  • [gNodeB]After this command is executed, the configuration of the remote maintenance channel is refreshed automatically according to the results of automatic remote maintenance channel establishment. Before running this command, ensure that other related configurations of the remote maintenance channel are available. If the remote maintenance channel is carried on an Ethernet link or Ethernet link aggregation group, ensure that the device IP address or IPv4 address, or IPv6 address has been configured for the corresponding Ethernet port or Ethernet link aggregation group.

Parameters

ID Name Description
EFT Effect Type

Meaning: Indicates the effective mode of online configuration activation.

GUI Value Range: CHKRSLT(Check Result), FORCE_EFT(Force Effect)

Unit: None

Actual Value Range: CHKRSLT, FORCE_EFT

MML Default Value: CHKRSLT(Check Result)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To activate the online configuration after the OMCH auto-establishment detection succeeds, and set Effect Type to FORCE_EFT, run the following command: 
ACT DHCPCFG: EFT=FORCE_EFT;
