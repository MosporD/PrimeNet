Display GTP-U ECHO Status (DSP GTPUECHO)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the GTP-U ECHO status.

Note

  • [Co-MPT,eNodeB,gNodeB]The local and peer IPv4 addresses must be different. The local and peer IPv6 addresses must be different.

  • [Co-MPT,eNodeB,gNodeB]If IPv4 is used, the local and peer IP addresses must fall into class A, B and C, but cannot be 127.x.x.x or 0.x.x.x.

  • [Co-MPT,eNodeB,gNodeB]If IPv6 is used, the local and peer IP addresses must be globally scoped unicast addresses.

  • [Co-MPT,eNodeB,gNodeB]When the local addresses of two IP paths are the same or when the local addresses of one IP path and one user-plane link are the same and the peer addresses of them are also the same, the measurement values of GTP-U ECHO packets through this address pair may change if the link configuration changes.

Example

To query the status of the GTP-U ECHO test session with the parameters as follows: IP Version: IPv4, Local IPv4 Address: 192.168.2.2, Peer IPv4 Address: 192.168.2.3, run the following command:
DSP GTPUECHO: IPVER=IPv4, LOCALIP="192.168.2.2", PEERIP="192.168.2.3";

Indicates the index of a VRF instance.

Number of transmitted packets in a GTP-U ECHO test(packet)

This parameter indicates the number of transmitted packets in a GTP-U ECHO test.

Number of received packets in a GTP-U ECHO test(packet)

This parameter indicates the number of received packets in a GTP-U ECHO test.

Static GTP-U ECHO test switch

Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE(Enable), the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE(Disable), the GTP-U static detection function is disabled for a link. If the local and peer IP addresses specified using the DSP GTPUECHO command are the same as those of an IP path or user-plane link, the value of Static GTP-U ECHO test switch is the same as that of Static Check Switch for the IP path or user-plane link. If the local and peer IP addresses specified using the DSP GTPUECHO command do not match a corresponding IP path or user-plane link, the value of Static GTP-U ECHO test switch is the same as that of Static Check Switch in the GTPU MO.
