List Loss Measurement Configuration (LST ETHLM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of all measurement sessions for the Ethernet packet loss.

Note

None.

Parameters

None.

Example

To list the configuration of measurement session for the Ethernet packet loss, run the following command: 
LST ETHLM:;
The result is shown as follows:
+++    0        2014-11-05 17:47:34
O&M    #536870953
%%LST ETHLM:;%%
RETCODE = 0  Operation succeeded.

List Loss Measurement Configuration
-----------------------------------
      Session ID  =  0
         MD Name  =  aaa
         MA Name  =  aaa
            Mode  =  SLM
          MEP ID  =  1
Destination Type  =  RMEP
         RMEP ID  =  2
     MAC Address  =  NULL
     TX Interval  =  1000ms
(Number of results = 1)


---    END

Output Description

Field Description

Session ID

Indicates the number of a performance detection session.

MD Name

Indicates the name of the MD to which the MEP belongs.

MA Name

Indicates the name of the MA to which the MEP belongs.

Mode

Indicates packet loss measurement mode.

MEP ID

Indicates the MEP ID.

Destination Type

Indicates the ITU-T Y.1731 measurement destination type. The parameter value RMEP is the local MEP ID of the peer end. The parameter value MAC is the MAC address configured for the RMEP.

RMEP ID

Indicates the RMEP ID.

MAC Address

Indicates the configured destination MAC address in the format of XXXX-XXXX-XXXX.

TX Interval

Indicates the interval at which ITU-T Y.1731 performance detection packets (LMM/DMM) are transmitted.
