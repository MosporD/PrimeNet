Display CPU/DSP Usage (DSP CPUUSAGE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the CPU/DSP usage of a board. After the execution of this command, the usage of the master CPU, slave CPU, and DSP (if any) is displayed.

Note

The precision of the CPU/DSP usage of a board is 1% and the CPU/DSP usage changes rapidly when the system is running. For example, if the displayed CPU/DSP usage of a board is 10%, the actual CPU/DSP usage changes between 10.00% and 10.99%.

Example

To query the CPU/DSP usage of the board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, run the following command:
DSP CPUUSAGE: CN=0, SRN=0, SN=7;
The result is shown as follows:
+++    0        2011-10-30 16:06:20
O&M    #6890
%%DSP CPUUSAGE: CN=0, SRN=0, SN=7;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

Object Type

Indicates the object type of a board, which is CPU or DSP.

Object Number

Indicates the object number of a board.

CPU/DSP Usage(%)

Indicates the CPU usage or DSP usage of the board.
