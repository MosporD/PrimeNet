Display System Clock Status (DSP CLKSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the system clock.

Note

  • When the BS clock synchronization mode is set to frequency synchronization, the ALM-26262 External Clock Reference Problem alarm is reported if the clock stays in the fast tracking mode for a long time. The interval at which the alarm is reported varies with the clock source. When the clock is an IP clock, the maximum interval is 3200 minutes. When the clock is a E1/T1 line clock, the interval is 150 minutes. When the clock is a GPS clock on the UMPT board, the interval is 200 seconds. When the clock is any other clock, the interval is 320 seconds. This alarm does not affect services.

  • In the BBU, the system clock of the active main control board can be set to trace the external clock source or work in free-running status, and the system clock of the standby main control board must trace the system clock of the active main control board.

  • If an interconnection system clock is configured as the locked system clock source on a UMPTa or UMPTb and the configuration takes effect, the system follows the clock signal obtained from the interconnection port, not the local clock source. In this scenario, the queried clock source is Inter System Clock.

DSP CLKSTAT: SRN=0, SN=7;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Current Clock Source

Indicates the clock source that is being used by the NE.

Current Clock Source State

Indicates the status of the clock source that is currently traced by the board, which can be Normal, Lost, Unavailable, Jitter, Unknown, Frequency Deviation, Phaseoutscope, Inconsistent Clock References, or Current Clock Source Type and Clock Synchronization Mode Mismatch.

Clock Working Mode

Indicates the working mode of the system clock. Manual indicates that a clock source must be specified by the user. Auto indicates that the system automatically selects a clock source based on the priority and availability of the clock source. Free indicates that the system clock works in free-running mode, that is, the system clock does not trace any reference clock source.

PLL Status

Indicates the PLL status of the board. It also indicates whether the system clock is stable. The PLL status of the board can be Fast tracking, Locked, Holdover, or Free running.

Holding Time(min)

Indicates the duration in which the base station enters the holding state after the reference source is lost.The value of this parameter is NULL when PLL Status is not Holdover.

Clock Synchronization Mode

Indicates the clock synchronization mode of a BS, which can be frequency synchronization or time synchronization.

Loose Time Synchronization

Indicates whether to enable the loose time synchronization function. This function provides low-precision time synchronization for a base station. If this function is enabled, loose time synchronization is supported. If this function is disabled, loose time synchronization is not supported.

Frame Sync Switch

Indicates the frame synchronization switch. This switch applies to the Cloud BB that works in frequency synchronization mode. In addition, it can be set to on only for an NE that connects to the clock source indirectly to realize frame synchronization between this NE and the upper-level NE.

GSM Frame Bit Offset(1/8bit)

Indicates GSM frame bit offset. This parameter applies to GSM only.

GSM Frame Sync Switch

Indicates the GSM frame synchronization switch. This parameter controls the GSM adjustment frame number and frame phase. In addition, this parameter is valid only for GSM NEs.

Low Precision Frame No. Synchronization Switch

Indicates the switch of low-precision frame No. synchronization. When this switch is turned on, the frame No. synchronization function is enabled, and the SFN and HSFN are automatically aligned after the system clock is locked. When this switch is turned off, the frame No. synchronization function is disabled. This switch applies to NB-IoT and eDRX.
