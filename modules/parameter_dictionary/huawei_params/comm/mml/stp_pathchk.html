Stop Path Check (STP PATHCHK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to stop the following running commands: TRACERT, TRACERT6, PING, PING6, CFMTRACE, CFMPING, and UDPECHO.

Note

When the TRACERT, TRACERT6, PING, PING6, CFMTRACE, CFMPING, or UDPECHO command is being executed, the current user can press CTRL+Q to stop the command execution and other users who have logged in to the NE can run the STP PATHCHK command to stop the command execution.

Parameters

None.

Example

To stop the following running commands: TRACERT, TRACERT6, PING, PING6, CFMTRACE, CFMPING, and UDPECHO, run the following command: 
STP PATHCHK:;
