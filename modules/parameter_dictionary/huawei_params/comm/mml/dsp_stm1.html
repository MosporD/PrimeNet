Display STM-1 Work Mode (DSP STM1)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the work mode of an optical port.

Note

[Co-MPT,NodeB]If no object is carried on an optical port, the optical port is disabled for protection. In this case, the execution result of this command does not indicate the normal status of the port.

Example

To query the optical port work mode with the parameters as follows: Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, run the following command:
DSP STM1: SN=0, SBT=UNCHANNELLED_COVERBOARD;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a specified optical port is located.

Subrack No.

Indicates the number of the subrack that houses the board where a specified optical port is located.

Slot No.

Indicates the number of the slot corresponding to the board where a specified optical port is located.

Subboard Type

Indicates the type of sub-board on the board where a specified optical port is located.

Port No.

Indicates the number of the specified optical port.

STM1 Status

Indicates the status of a specified optical port.

Tx Clock

Indicates the clock source used for transmission on a specified optical port. If a specified optical port interconnects with the RNC or upper-level node, this parameter should be set to RECOVEDRX on the port but be set to EXT8K on the peer port of the upper-level node. If a specified optical port interconnects with the lower-level node, this parameter should be set to EXT8K at the port but set to RECOVEDRX for the peer port on the lower-level node.

Frame Mode

Indicates the frame format of a specified optical port.

Loop Mode

Indicates the loopback mode of a specified optical port.

Loss of Signal

Indicates the Loss of Signal alarm generated on a specified optical port.

Loss of Frame

Indicates the Loss of Frame alarm generated on a specified optical port.

Out of Frame

Indicates the Out of Frame alarm generated on a specified optical port.

Regenerator section trace indentifier mismatch

Indicates the Regeneration Section Trace Identifier Mismatch alarm generated on a specified optical port.

Multiplex section alarm indication signal

Indicates the Multiplex Section Alarm Indication Signal alarm generated on a specified optical port.

Multiplex section bit error ratio exceeds threshold

Multiplex section background block error

Multiplex section remote error indication

STM1 loss of cell delineation

Out of cell delineation

Indicates the Out of Cell Delineation alarm generated at a specified optical port.

Optical Interface Module Not in Position

Indicates the Optical Interface Module Not in Position alarm generated on a specified optical port.

Administrative unit alarm indication signal

Loss of administrative unit point
