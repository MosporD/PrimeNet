Set Clock Class (SET PRICLASS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set priorities for the four clock classes of the IP clock link. This command is applicable only when the IEEE 1588 OC_SLAVE standard is supported. The OC_MASTER link does not support the function.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If two OC_SLAVE IP clock links in compliance with IEEE 1588 V2 are configured, modification of the Priority Clock Class parameter takes effect for both the links.

  • The setting of priorities for the clock classes is valid only when the Profile Type parameter is set to 1588V2 or 1588V2_16.1 and the Priority Clock Class Identify Flag parameter is set to ON.

  • If Priority Clock Class Identify Flag is set to ON and the clock quality level of the IP server is beyond the priority clock class range, the IP clock will become unavailable.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the IP clock link.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the IPCLKLNK MO, when the value of DEVTYPE is set to OC_SLAVE, the value of LN must be 0 or 1. When the value of DEVTYPE is set to OC_MASTER, the value of LN must be 2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
CLASS0 Priority Clock Class0

Meaning: Indicates the priority configured by the user for the BMC (Best Master Clock) algorithm. The information about the priority can be collected from the upper-level clock equipment. This parameter specifies the clock quality that is anticipated by the user. The upper-level clock equipment with the matching clock quality is selected as the target server. Class0 has the highest priority, and Class0 to Class3 indicate priorities in descending order.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: 6

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The values of any two parameters among CLASS0, CLASS1, CLASS2, and CLASS3 in an IPCLKLNK must be different.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CLASSIDENTIFY in the IPCLKLNK MO is set to OFF, the BMC algorithm is disabled, and the setting of CLASS0 does not take effect. When CLASSIDENTIFY in the IPCLKLNK MO is set to ON, the BMC algorithm is enabled. If there are multiple clock servers at different clock quality levels, the server that meets the customer's requirements to the most extent is selected in descending order of priority.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set clock classes with parameters as follows: IPClk No.: 0, Priority Clock Class0: 6, Priority Clock Class1: 13, Priority Clock Class2: 7, Priority Clock Class3: 14, run the following command:
SET PRICLASS: CLASS0=6, CLASS1=13, CLASS2=7, CLASS3=14;
