Modify IMA Group (MOD IMAGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the configuration of an IMA group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]If an IMA group is to be configured on a main control board that provides four E1 ports, the value range of the IMA group number (IMAGRPN) is from 0 to 1. When the IMA group number is larger than 1, a message is displayed, indicating that the IMA group number is invalid.

  • [Co-MPT,NodeB]The modification of an IMA group may interrupt the service. For details, see the "Service Interrupted After Modification" of each parameter in this command.

  • [Co-MPT,NodeB]The execution of this command will automatically terminate the ongoing IMA group test.

  • [Co-MPT,NodeB]This operation may interrupt the services or OM channels carried on the IMA group. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IMAGRP MO, if SN is within the range from 0 to 5, this parameter must be set to E1_COVERBOARD.
  • When adding, querying, modifying, removing or resetting the IMAGRP MO, set this parameter to BASE_BOARD if SN is set to 6 or 7.
  • When querying or stopping a test on the IMAGRP MO whose SN is set to 6 or 7, set this parameter to BASE_BOARD.
  • When starting a test on the IMAGRP MO whose SN is set to 6 or 7, set this parameter to BASE_BOARD or BACK_BOARD.

VER IMA Protocol Version

Meaning: Indicates the version of the IMA protocol. If this parameter is set to V1.0, the position of RX link information in an IMA Control Protocol (ICP) cell is determined by the TX Link ID (LID) transmitted by the local end. If this parameter is set to V1.1, the position of RX link information in an ICP cell is determined by the TX LID transmitted by the peer end.

Unit: None

Example

To modify an IMA group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Group No.: 0, IMA Protocol Version: V1.0, run the following command: 
MOD IMAGRP: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, IMAGRPN=0, VER=V1.0;
