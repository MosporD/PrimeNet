Set ICMPv6 Protocol Parameters (SET ICMPV6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set ICMPv6 parameters.

Note

None.

Parameters

ID Name Description
ERRMSGSW ICMPv6 Error Message Sending Type

Meaning: Indicates whether to send ICMPv6 error messages. ICMPv6 error messages include Destination Unreachable message and Packet Too Big message. Both can be selected. The value DST_UNREACHABLE(Destination Unreachable) indicates that ICMPv6 Destination Unreachable messages will be sent. Generally, if a base station does not find the corresponding interface after receiving a TCP/UDP IPv6 packet, it sends an ICMPv6 Destination Unreachable message. Sending this message exposes the device or brings pressure on network devices. You can disable the transmission of Destination Unreachable messages by setting this parameter, avoiding network security risks. The value PTB(Packet Too Big) indicates that ICMPv6 Packet Too Big messages will be sent. In cascading or panel-based co-transmission scenarios, if the length of a forwarded IPv6 packet received by the base station exceeds the IPv6 MTU (specified by the INTERFACE.MTU6 parameter), the base station discards the packet and sends an ICMPv6 Packet Too Big message to the source end of the IPv6 packet. IPv6 allows the source end of an IPv6 packet to detect the MTU of the transmission link based on Packet Too Big messages and adjust the length of packets to be sent. This prevents packet discarding because the packet length exceeds the MTU of the transmission devices. Sending this error message also exposes devices or poses pressure on network devices. You can disable the sending of ICMPv6 Packet Too Big messages to prevent network security risks. If this option is deselected, ensure that the value of the INTERFACE.MTU6 parameter for the forwarding interface is greater than or equal to the maximum IPv6 packet length of the lower-level base station. If NULL is displayed in the command output, the ICMPv6 error messages specified by this parameter are not sent.

GUI Value Range: DST_UNREACHABLE(Destination Unreachable), PTB(Packet Too Big)

Unit: None

Actual Value Range: DST_UNREACHABLE, PTB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To set ICMPV6 protocol sending type with the parameters as follows: DST_UNREACHABLE: ENABLE, PTB: ENABLE, run the following command: 
SET ICMPV6: ERRMSGSW=DST_UNREACHABLE-1&PTB-1;
