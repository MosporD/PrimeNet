UDPEcho (UDPECHO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to test the network connectivity and transmission line quality when the destination IP address supports UDP loopback and UDP loopback is configured at the peer end. After this command is executed for a destination IP address that supports UDP loopback, the source host sends UDPECHO messages to the destination host, which loops back the messages to the source host. According to the looped back messages, the source host determines the network connectivity and transmission line quality.

Note

  • If CONTUDPECHO is set to ENABLE, press Ctrl+Q or run the STP PATHCHK command to terminate the UDPECHO command.

  • The PING, PING6, TRACERT, TRACERT6, CFMTRACE, CFMPING, and UDPECHO commands cannot be executed simultaneously on one board.

  • If port 64711 of the client is used during a DNS resolution, it is recommended that this port not be simultaneously used for the UDPECHO command and DNS resolution.

  • The destination UDP port number must be negotiated with the destination device and the port must be enabled in advance on the destination device. Generally, a base station controller supports ports 65040 and 7 that need to be configured in advance. The MAE uses the fixed port 31252 that is enabled by default and does not need to be configured.

Example

To perform a UDP loopback test with the parameters as follows: Slot No.: 6, Local IP Address: 192.168.2.2, Peer IP Address: 192.168.2.3, Source Port Number: 65041, Destination Port Number: 65040, Packet Size: 32, DSCP: 63, run the following command:
UDPECHO: SN=6, LOCALIP="192.168.2.2", PEERIP="192.168.2.3", SPN=65041, DPN=65040, PKTSIZE=32, DSCP=63;
