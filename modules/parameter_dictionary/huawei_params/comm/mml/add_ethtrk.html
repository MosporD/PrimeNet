Add Ethernet Trunk (ADD ETHTRK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an Ethernet trunk.

Note

  • The Ethernet trunk type at the peer end must be the same as that at the local end. Otherwise, the Ethernet trunk may fail to be activated.

  • Each Ethernet trunk can group only links on one board. Inter-board link aggregation is not supported.

  • The Ethernet trunk only applies to the scenario where the local end is directly connected to the nearest network equipment using the link aggregation protocol.

  • System specifications: If the WMPT/UMPT/LMPT is the main control board, a maximum of 24 Ethernet trunks can be configured. If the GTMUb/GTMUc/UMDU is the main control board, a maximum of 2 Ethernet trunks can be configured.

  • Board specifications: A maximum of 2 Ethernet trunks can be configured on a WMPT/UMPT/UMDU/LMPT. A maximum of 3 Ethernet trunks can be configured on a UTRPc. A maximum of 2 Ethernet trunks can be configured on a UTRP (subboard type: UEOC/UQEC). A maximum of 2 Ethernet trunks can be configured on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • When an ETHTRK MO is added on the MAE-Deployment, its adaptive port transmission resource group is automatically created. The bandwidth-related parameters of the transmission resource group take effect as the default values according to the board capability.

LACP Trunk Type

Meaning: Indicates the type of Ethernet trunk. When this parameter is set to DISABLE, the Ethernet trunk is in manual mode, and its status cannot be notified to the peer end. In this case, you need to manually configure the member ports of the Ethernet trunk. The base station considers these member ports as valid member ports of the Ethernet trunk. If this parameter is set to ENABLE, the Ethernet trunk is in static mode. In this case, the member ports added to the Ethernet trunk do not take effect immediately. The base station needs to negotiate with the peer end about the actual valid member ports through LACP.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Trunk Type parameter in the ETHTRUNK MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

MTU Max Transmission Unit

Meaning: Indicates the size of the IPv4 maximum transmission unit for an Ethernet trunk. For the UMPTa/b, UMDU, LMPT, UCCU, and UTRPc, the value of this parameter ranges from 46 to 1800. For the WMPT, UQEC, and UEOC, the value of this parameter ranges from 46 to 1500. For the UMPTe, the value of this parameter ranges from 46 to 2000. For the UMPTg and UMPTga, the value of this parameter ranges from 46 to 9000. If this parameter is set to a value greater than the maximum allowed value, the maximum allowed value takes effect. A value greater than or equal to 776 is recommended, because broadcast packets, such as DHCP packets, may experience reception or transmission failures if the maximum transmission unit is smaller than 776.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the IPv4 Maximum Transmission Unit parameter in the INTERFACE MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 46~9000

Unit: byte

Actual Value Range: 46~9000

MML Default Value: 1500

Recommended Value: 1500

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: An excessive large parameter value leads to packet loss or excessively-fragmented data packets on the transport network, resulting in a long delay and deteriorated performance. An excessive small parameter value leads to decreased available payloads for transmission, resulting in ineffective use of the transport network bandwidth and deteriorated performance.

Applicable Mode: G, U, L, N, R
ARPPROXY ARP Proxy

Meaning: Indicates whether to enable the ARP proxy function on the Ethernet trunk. If this parameter is set to ENABLE, the BS performs the ARP proxy on the IP addresses of its loopback interfaces (or of the lower-level BS). If this parameter is set to DISABLE, the BS does not perform the ARP proxy on the IP addresses of its loopback interfaces (or of the lower-level BS). The external device on the same subnet needs to access the IP address through a configured route.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the ARP Proxy parameter in the INTERFACE MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Example

To add an Ethernet trunk with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Trunk No.: 0, run the following command: 
ADD ETHTRK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, TN=0;
