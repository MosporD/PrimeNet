List TWAMP Sender Configuration (LST TWAMPSENDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of a TWAMP sender.

Note

None.

To list the configuration of a TWAMP Sender, run the following command:
LST TWAMPSENDER:;

Output Description

Field Description

Client Index

Indicates the client index of a TWAMP sender.

Sender Index

Indicates the index of a TWAMP sender.

TWAMP Architecture

Indicates the architecture of a TWAMP sender.

Light Architecture Mode

Indicates the working mode of a TWAMP sender deployed in the light architecture. The working mode of the TWAMP sender must be the same as that of the TWAMP responder. This parameter takes effect only when the TWAMP sender is deployed in the light architecture.

Local UDP Port No.

Indicates the local UDP port number of a TWAMP sender.

Peer UDP Port No.

Indicates the peer UDP port number of a TWAMP sender.

DSCP

Indicates the DSCP of UDP measurement packets sent by a TWAMP sender.

Packet Size Type

Indicates the type of the packet size sent by a TWAMP sender. If this parameter is set to RANDOM, the NE randomly selects a packet length ranging from 69 to 1500 bytes for sending measurement packets in IPv4 scenarios, and a packet length ranging from 89 to 1500 bytes to send measurement packets in IPv6 scenarios.

Packet Size(byte)

Indicates the length of a packet sent by a TWAMP sender, including the IP header. If the TWAMP sender uses the IPv6 protocol, the packet length including the IP header must be greater than 89 bytes.

Packet Send Interval Type

Indicates the type of the interval at which packets are sent by a TWAMP sender. If this parameter is set to RANDOM, the NE sends measurement packets at a random interval of 10 to 1000 ms.

Packet Send Interval(ms)

Indicates the interval at which packets are sent by a TWAMP sender.
