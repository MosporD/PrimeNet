Modify RAE (MOD RAE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a Remote eAntenna Extension (RAE).

Note

  • The antenna scenario must be set based on the hardware installation. In non-regular scenarios, the vendor code and serial number of the device must be specified. Otherwise, the system cannot communicate with the RAE properly. When modifying the vendor code or serial number of the device, ensure that neither of them is left blank. Otherwise, the command fails. To query the vendor code and the serial number of the device, run the SCN ALD command.

  • Before modifying the controlling RRU or RFU, ensure that the power switch at the control port is turned on. For details about how to query the port status, see the DSP ANTENNAPORT and DSP RETPORT commands. For details about how to modify the port status, see the MOD ANTENNAPORT and MOD RETPORT commands.

DEVICENAME Device Name

Meaning: Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

MOD RAE: DEVICENO=0, SCENARIO=REGULAR;
