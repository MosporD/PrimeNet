Start Hardware Online Test (STR HWOLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start a hardware online test on a board in order to locate or troubleshoot hardware faults.

Note

  • Before starting a hardware online test on a board, ensure that the following conditions are met:

    1. No software or file is being uploaded or downloaded.

    2. The board must be configured. The sub-boards, if any, must be configured.

    3. No hardware online test is being performed on the board.

    4. The specified board on an RRU chain/ring must support online hardware tests.

  • Run the DSP HWOLTSTRESULT command to query the test result.

  • This function occupies certain system resources. After this command is executed, the CPU usage increases temporarily.

Example

To start a hardware online test on a board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, run the following command:
STR HWOLTST: CN=0, SRN=0, SN=1;
