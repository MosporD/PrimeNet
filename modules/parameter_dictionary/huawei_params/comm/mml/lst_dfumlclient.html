List DFU Management Link Configuration (LST DFUMLCLIENT)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of DFU management link clients.

Note

None.

Parameters

ID Name Description
CLIENTID Client ID

Meaning: Indicates the ID of a DFU management link client.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To query the DFU management link configuration, run the following command:
LST DFUMLCLIENT:;
The result is shown as follows:
+++    0        2018-04-03 21:02:12
O&M    #978
%%LST DFUMLCLIENT:;%%
RETCODE = 0  Operation succeeded.

List DFU Management Link Configuration
--------------------------------------
          Client ID  =  1
          VRF Index  =  0
         IP Version  =  IPv4
Client IPv4 Address  =  192.168.1.1
            Unit ID  =  2
         User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

Client ID

Indicates the ID of a DFU management link client.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the IP protocol version of a DFU management link client.

Client IPv4 Address

Indicates the IPv4 address of a DFU management link client.

Unit ID

Indicates the ID of a DFU.

User Label

Indicates the user-defined information about a DFU management link client.
