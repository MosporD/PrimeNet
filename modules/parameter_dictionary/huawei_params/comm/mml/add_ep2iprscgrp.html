Add Mapping from End Point to IP Transmission Resource Group (ADD EP2IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add mapping from End Point to IP Transmission Resource Group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before adding a mapping between an end point and an IP transmission resource group, ensure that the IPRSCGRP MO has been added by running the ADD IPRSCGRP command.

  • A base station supports a maximum of 456 mappings between end points and IP transmission resource groups. If the GTMUb/GTMUc is the main control board, a base station supports a maximum of 64 mappings between end points and IP transmission resource groups.

  • A base station supports two types of mapping between an end point and an IP transmission resource group: end point group mapping and end point mapping.

    End point group mapping: Add all user plane peers in the EPGROUP to the specified IP transmission resource group.

    End point mapping: Add the specified user plane peer to the specified IP transmission resource group.

    If an end point added to the IP transmission resource group through the end point group mapping and end point mapping conflict, use the end point mapping to add end points to the IP transmission resource group. If no IP transmission resource group is specified for a user plane peer, the internal user plane path that is automatically set up between the local base station and the corresponding user plane peer joins the default IP transmission resource group.

  • In the two types of mapping between an end point and a transmission resource group, the same end point group or end point cannot be added to different IP transmission resource groups of the same physical port.

  • If the port type for the local IP address of a user-plane host is a loopback interface, the following principles are complied with when the automatically established user-plane link is added to the transmission resource group:

    1. If the loopback interface is on the same board as the actual service outbound interface and the outbound interface is the same as the IP transmission resource group interface configured in an EP2IPRSCGRP object, services are carried in the IP transmission resource group specified in the EP2IPRSCGRP object. If the loopback interface is on the same board as the actual service outbound interface but the outbound interface is different from the IP transmission resource group interface configured in an EP2IPRSCGRP object, services are carried in default IP transmission resource group with the actual service outbound interface.

    2. If the loopback interface is on a different board from the actual service outbound interface, services are carried in the default IP transmission resource group with the actual service outbound interface.

  • Running this command may interrupt ongoing services carried on the base station.

Parameters

ID Name Description
MAPID Mapping ID

Meaning: Indicates the ID of a mapping between end points and IP transmission resource groups.

GUI Value Range: 0~455

Unit: None

Actual Value Range: 0~455

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MT Mapping Type

Meaning: Indicates the mapping mode between the service and the IP transmission resource group. Two mapping modes are supported: endpoint group mode and endpoint mode. If this parameter is set to ENDPOINT_GROUP, all user-plane peer endpoints in the endpoint group can be added to the specified IP transmission resource group. If this parameter is set to ENDPOINT_NODE, the specified user-plane peer endpoints can be added to the specified IP transmission resource group. When both the endpoint group mode and the endpoint mode are available for mapping all service flows of the same EPPATH to the IP transmission resource group, the endpoint mode is preferentially used for the mapping.

GUI Value Range: ENDPOINT_GROUP(EndPoint Group), ENDPOINT_NODE(EndPoint Node)

Unit: None

Actual Value Range: ENDPOINT_GROUP, ENDPOINT_NODE

MML Default Value: ENDPOINT_GROUP(EndPoint Group)

Recommended Value: ENDPOINT_GROUP(EndPoint Group)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ENDPOINTID End Point ID

Meaning: Indicates the ID of the end point group or user plane peer to be added to the specified IP transmission resource group.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]When the MT parameter in the EP2IPRSCGRP MO is set to ENDPOINT_GROUP, this parameter uses the value of the End Point Group ID parameter (the value range of this parameter is 0~65535) in the EPGROUP MO. In this case, all data flows in the EP group whose destination addresses are generated by USERPLANEPEER MO can be mapped to the specified transmission resource group.
  • When the MT parameter in the EP2IPRSCGRP MO is set to ENDPOINT_NODE, this parameter uses the value of the User Plane Peer ID parameter (the value range of this parameter is 0~65535 and 70000~79999) in the USERPLANEPEER MO. In this case, all data flows whose destination addresses are generated by the USERPLANEPEER MO can be mapped to the specified transmission resource group.

Example

To add mapping from End Point to IP Transmission Resource with the parameters as follows: Mapping ID: 0, Mapping Type:EndPoint Group, End Point ID: 0, IP Transmission Resource Group ID: 0, run the following command:
ADD EP2IPRSCGRP: MAPID=0, MT=ENDPOINT_GROUP, ENDPOINTID=0, IPRSCGRPID=0;
