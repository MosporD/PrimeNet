Set Port Work Mode (SET PORTMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the working mode of a port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the board does not support the setting of the port working mode, the system displays a message after command execution, indicating that the board does not support the setting of the port working mode.

  • Modifying the working mode of a port may interrupt services.

  • When a message indicating that the working mode fails to be set is displayed after this command is executed, run the LST PORTMODE command to query the configuration of the working mode of a port and run the DSP PORTMODE command to query the working mode of a port. If the displayed working modes are inconsistent in the command outputs, the working mode of the port fails to take effect.

  • After the Port Mode parameter is set for a board, the board starts a negotiation. During the negotiation, if you run the DSP PORTMODE command, NULL is contained in the command output.

  • If the Port Mode parameter is set to AUTO for the port, negotiations will take a long period of time. The port mode can be reconfigured only after the negotiation is complete.

  • [Co-MPT,NodeB]If UBBPe and WBBPf or UBBPg3(UBBPg6b/UBBPg6c) and WBBPf are interconnected, only the value SCPRI/SRIO is supported.

Example

To set work mode with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Port No.: 6, Port Mode: SCPRI/SRIO, run the following command:
SET PORTMODE: CN=0, SRN=0, SN=1, PN=6, PM=SCPRI/SRIO;
