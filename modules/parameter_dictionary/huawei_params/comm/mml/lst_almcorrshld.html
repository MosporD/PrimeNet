List Alarm Correlation Shield Flag (LST ALMCORRSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the Report Flag of Son Alarm for an alarm.

Note

None.

Parameters

ID Name Description
AID Alarm ID

Meaning: Indicates the alarm ID. The alarm ID is the only index for alarms.

GUI Value Range: 1~65032

Unit: None

Actual Value Range: 1~65032

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Example 1: To query an unconfigured correlation shield flag of a specified alarm with the parameter as follows: Alarm ID: 26200, run the following command:
LST ALMCORRSHLD: AID=26200;
The result is shown as follows:
+++    0        2014-03-20 11:26:12
O&M    #9116
%%LST ALMCORRSHLD: AID=26200;%%
RETCODE = 0  Operation succeeded.

No matching result is found


---    END

Example 2: To query the configured correlation shield flag of a specified alarm with the parameter as follows: Alarm ID: 26235, run the following command:
LST ALMCORRSHLD: AID=26235;
The result is shown as follows:
+++    0        2014-03-20 11:27:37
O&M    #9123
%%LST ALMCORRSHLD: AID=26235;%%
RETCODE = 0  Operation succeeded.

                Alarm ID  =  26235
Report Flag of Son Alarm  =  Not Report
(Number of results = 1)


---    END

Example 3: To query configured correlation shield flags of all alarms, run the following command:
LST ALMCORRSHLD:;
The result is shown as follows:
+++    0        2014-03-19 10:22:38
O&M    #4437
%%LST ALMCORRSHLD:;%%
RETCODE = 0  Operation succeeded.

Alarm ID  Report Flag of Son Alarm

26235     Not Report    
26262     Report                          
(Number of results = 2)


---    END

Output Description

Field Description

Alarm ID

Indicates the alarm ID. The alarm ID is the only index for alarms.

Report Flag of Son Alarm

Indicates whether a correlative alarm can be reported.
