Remove BFD Session (RMV BFDSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a BFD session.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Removing a BFD session with the CATLOG parameter set to RELIABILITY enables the routes that were disabled by route interlock.

  • [Co-MPT,NodeB,eNodeB,gNodeB]A BFD session cannot be removed if it is referenced by an IPSec tunnel pair.

Example

To remove the BFD session with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Session ID: 0, run the following command:
RMV BFDSESSION: CN=0, SRN=0, SN=6, BFDSN=0;
