Display CXU (DSP CXU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a CXU.

Note

  • The length of the fiber optic cable between the BBU and CXU in the command output is inaccurate due to factors such as the refractive index. The longer the fiber optic cable, the larger the error. The relationship between the length of the fiber optic cable and the error is as follows and is for reference only: When the length of the fiber optic cable is smaller than 600 m, the error is large. When the length of the fiber optic cable ranges from 600 m to 2 km, the error is less than 10%. When the length of the fiber optic cable ranges from 2 km to 12 km, the error is less than 5%. When the length of the fiber optic cable is greater than 12 km, the error is less than 2.5%.

  • The fiber optic cable length displayed under Display CXU Dynamic Information refers to the length of the shortest fiber optic cable between the CXU and BBU. The lengths of all fiber optic cables between them are displayed under Display Length of Fiber Optic Cable Connecting to CXU.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the CXU is located.

Subrack No.

Indicates the number of the subrack where the CXU is located.

Slot No.

Indicates the number of the slot where the CXU is located.

Access Direction

Indicates the access direction of the service plane.

The length of the fiber optic cable[100m(100ft)]

Indicates the length of the fiber optic cable between the BBU and CXU. If the cable length cannot be obtained, the value NULL is displayed.

Current Maintenance Mode

Indicates the current maintenance mode of the CXU.

Cabinet No. of Interface Board

Indicates the number of the cabinet housing the interface board.

Subrack No. of Interface Board

Indicates the number of the subrack housing the interface board.

Slot No. of Interface Board

Indicates the number of the slot housing the interface board.

Port No. of Interface Board

Indicates the number of the port on the interface board.

SubPort No. of Interface Board

Indicates the sub-port number of the interface board.

Port No. of CXU

Indicates the number of the port on the CXU.
