Switching Over the CANBUS Master/Slave Status (SWP CANBUS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to manually initiate a master/slave CANBUS switchover on the main control board of the master CANBUS in intra-BBU separate-MPT multimode base stations.

Note

  • After this command is executed successfully, you can run the DSP CANSTATE command to check the CANBUS master/slave status to determine whether the CANBUS master/slave state switchover is successful.

  • When the peer main control board is being reset, the switchover fails after this command is executed. Perform the operation again 5 minutes later.

  • After a master/slave CANBUS switchover occurs, the CANBUS is reset. The statistics of the received and sent messages of the CANBUS are cleared, and the system starts to collect the statistics again.

Parameters

None.

Example

To perform the master/slave CANBUS swap, run the following command:
SWP CANBUS:;
The result is shown as follows:
+++    0        2019-04-13 09:41:07
O&M    #2384
%%SWP CANBUS:;%%
RETCODE = 0  Operation succeeded.
