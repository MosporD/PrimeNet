Clear PMU Smoke Alarm (CLR PMUALM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to clear a power monitoring unit (PMU) smoke alarm. When a PMU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.

Note

  • After the command is executed, if the fault that trigger the alarm persists, the alarm is reported again. To actually clear the alarm, go to the site to observe the situation and perform troubleshooting.

  • If the operational status of the PMU is unavailable, this operation fails.

Example

To clear the PMU smoke alarm in cabinet 0, run the following command:
CLR PMUALM: CN=0;
