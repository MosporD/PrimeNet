Modify Ethernet Trunk (MOD ETHTRUNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an Ethernet trunk.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The execution of this command may interrupt services carried on the member ports of the Ethernet trunk. For details, see the "Service Interrupted After Modification" of each parameter in this command.

  • This operation may interrupt the services or OM channels carried on this port. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the ID of the Ethernet trunk.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
LACP Trunk Type

Meaning: Indicates the type of Ethernet trunk. When this parameter is set to DISABLE, the Ethernet trunk is in manual mode, and its status cannot be notified to the peer end. In this case, you need to manually configure the member ports of the Ethernet trunk. The base station considers these member ports as valid member ports of the Ethernet trunk. If this parameter is set to ENABLE, the Ethernet trunk is in static mode. In this case, the member ports added to the Ethernet trunk do not take effect immediately. The base station needs to negotiate with the peer end about the actual valid member ports through LACP.

GUI Value Range: DISABLE(Disable LACP), ENABLE(Enable LACP)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable LACP)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To modify an Ethernet trunk with the parameter as follows: Port ID: 0, Trunk Type: Enable LACP run the following command: 
MOD ETHTRUNK: PORTID=0, LACP=ENABLE;
