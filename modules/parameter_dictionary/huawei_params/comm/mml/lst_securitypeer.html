List Security Peer Configuration (LST SECURITYPEER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of a security peer and whether the security peer is created by the system. If the value of Auto Config Flag is set to Manual Created, the security peer is configured by the user manually. If the value of Auto Config Flag is Auto Created, the security peer is created by the system.

Note

None.

Parameters

ID Name Description
SECURITYPEERID Security Peer ID

Meaning: Indicates the ID of a security peer. The value of SECURITYPEERID in the SECURITYPEER MOs configured by users ranges from 0 to 65535. The value of SECURITYPEERID in the SECURITYPEER MOs configured by the system ranges from 70000 to 89999.

GUI Value Range: 0~65535,70000~89999

Unit: None

Actual Value Range: 0~65535,70000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If SECURITYPEERID is set to a value in the range of 0 to 65535, CTRLMODE must be set to MANUAL_MODE, and AUTOCFGFLAG must be set to MANUAL_CREATED. If SECURITYPEERID is set to a value in the range of 70000 to 89999, CTRLMODE must be set to AUTO_MODE, and AUTOCFGFLAG must be set to AUTO_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

To list the configuration of security peers, run the following command:
LST SECURITYPEER:;

Output Description

Field Description

Security Peer ID

Indicates the ID of a security peer. The value of SECURITYPEERID in the SECURITYPEER MOs configured by users ranges from 0 to 65535. The value of SECURITYPEERID in the SECURITYPEER MOs configured by the system ranges from 70000 to 89999.

SeGW Switch

Indicates whether to enable the peer end to perform IPSec negotiation with the local end through an SeGW. When this parameter is set to DISABLE, the peer end performs IPSec negotiation with the local end directly. When this parameter is set to ENABLE, the peer end establishes an IPSec tunnel to the local end through an SeGW.

IP Version

Indicates the IP protocol version of a security peer.

Peer IKE IP Address

Indicates the IPv4 address of the IKE peer.

Peer IKE IPv6 Address

Indicates the IPv6 address of the IKE peer that corresponds to a service IP address. This parameter takes effect only in LTE and NR.

IKE Peer Name

Indicates the name of the IKE peer. The IKE peer is the SeGW that performs IKE negotiation with the local end.

IPSec Proposal Name

Indicates the name of the IPSec proposal used for IPSec negotiation between the local end and the SeGW.

Control Mode

Indicates whether the object can be automatically modified or removed by the system. If this parameter is set to MANUAL_MODE, only users can operate this object. If this parameter is set to AUTO_MODE, the system can modify or remove this object and users can only remove this object.

User Label

Indicates the description of a security peer.

Auto Config Flag

Indicates whether the object is created by the system. MANUAL_CREATED means that the object is configured by the user manually. AUTO_CREATED means that the object is created by the system.
