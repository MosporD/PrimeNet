Display RHUB Remote Power Supply State (DSP FARPWRINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the remote power state and power level of an RHUB.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RHUB is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [gNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Example

To query the remote power supply state of an RHUB, run the following command:
DSP FARPWRINFO: CN=0, SRN=200;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RHUB is located.

Subrack No.

Indicates the number of the subrack where the RHUB is located.

Slot No.

Indicates the number of the slot where the RHUB is located.

Port ID

Indicates the port number on the RHUB to which the PRRU is connected.

Power Status

Indicates the remote power supply state of a CPRI_ELECTRIC port on the RHUB. There are two remote power states: power on and power off.

Power Level

Indicates the remote power supply level of the CPRI electrical port on the RHUB. The remote power supply level ranges from 0 to 15. The value indicates internal implementation and is for reference only.
