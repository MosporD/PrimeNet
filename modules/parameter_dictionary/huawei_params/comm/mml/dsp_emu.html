Display EMU (DSP EMU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about an environment monitoring unit (EMU).

Note

If the operational status of the EMU is unavailable, the query fails.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the EMU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the EMU is located.

GUI Value Range: 40~59

Unit: None

Actual Value Range: 40~59

MML Default Value: 40

Recommended Value: 40

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the EMU is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the EMU status, run the following command:
DSP EMU:;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the EMU is located.

Subrack No.

Indicates the number of the subrack where the EMU is located.

Slot No.

Indicates the number of the slot where the EMU is located.

Ambient Temperature[degree Celsius(degree Fahrenheit)]

Indicates the current temperature of the environment.

Ambient Humidity(%)

Indicates the ambient humidity.

-48V Input Voltage(V)

Indicates the -48 V input voltage from the power supply cabinet.

Analog Port 1 Measurement Value

Indicates the current value measured by the external sensor that is connected to analog port 1.

Analog Port 2 Measurement Value

Indicates the current value measured by the external sensor that is connected to analog port 2.

Analog Port 3 Measurement Value

Indicates the current value measured by the external sensor that is connected to analog port 3.

Analog Port 4 Measurement Value

Indicates the current value measured by the external sensor that is connected to analog port 4.
