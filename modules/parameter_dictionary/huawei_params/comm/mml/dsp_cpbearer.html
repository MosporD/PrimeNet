Display CP Bear Status (DSP CPBEARER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of Control Port Bearer.

Note

None.

Parameters

ID Name Description
CPBEARID CP Bear No.

Meaning: Indicates the number of a Control Port (CP) bearer. The value of CPBEARID in the CPBEARER MOs configured by users ranges from 0 to 65535. The value of CPBEARID in the CPBEARER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of CP Bear No. in a manually configured CPBEARER MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FLAG Flag

Meaning: Indicates whether the transport channel carried on the CP bearer is a master or slave channel.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of CpBearer with the parameters, run the following command:
DSP CPBEARER:;
The result is shown as follows:

Output Description

Field Description

CP Bear No.

Indicates the number of a Control Port (CP) bearer. The value of CPBEARID in the CPBEARER MOs configured by users ranges from 0 to 65535. The value of CPBEARID in the CPBEARER MOs configured by the system ranges from 70000 to 79999.

Bear Type

Indicates the type of CP bearer. The LTE and NR do not support SAAL.

Link No.

Indicates the number of a link carried on the CP bearer.

Flag

Indicates whether the transport channel carried on the CP bearer is a master or slave channel.

Port Status

Indicates the status of a CP bearer.

Used Status

Indicates whether the CP bearer is in use.
