Add CFM MD (ADD CFMMD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a connectivity fault management (CFM) maintenance domain (MD).

Note

  • System specifications: If the WMPT/GTMUb/GTMUc is the main control board, only one CFM MD can be configured. If the LMPT/UMPT/UMDU is the main control board, a maximum of 8 CFM MDs can be configured.

  • Board specifications: Only one CFM MD can be configured on a WMPT/GTMUb/GTMUc. A maximum of 8 CFM MDs can be configured on a UCCU/UMPT/UMDU/LMPT/UTRPc/UTRP (subboard type: UEOC/UQEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the CFM MD.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MD.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MDNAME in a CFMMD MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
LEVEL MD Level

Meaning: Indicates the level of the CFM MD.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a CFM MD with the parameter as follows: MD Name: CHINA, run the following command: 
ADD CFMMD: MDNAME="CHINA";
