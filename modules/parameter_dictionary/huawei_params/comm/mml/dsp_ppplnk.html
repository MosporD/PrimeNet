Display PPP Link Status (DSP PPPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the status of a PPP link.

Note

[Co-MPT,NodeB,eGBTS,eNodeB]A PPP link can be set up successfully only if the link parameters are consistent at the two ends after negotiation. The execution result of this command may be inconsistent with the user-specified link attributes. The result of this command is the data that takes effect currently.

Example

To query the status of a PPP link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 0, run the following command:
DSP PPPLNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PPPLNKN=0;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the PPP link is located.

Subrack No.

Indicates the subrack number of the board where the PPP link is located.

Slot No.

Indicates the slot number of the board where the PPP link is located.

Subboard Type

Indicates the type of sub-board on the board where a PPP link is located.

Link No.

Indicates the number of the PPP link.

Port ID

Indicates the ID of a PPP link, which uniquely identifies the PPP link. In the old model, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. In the new model, this parameter is mandatory and must be unique in the system.

Local IP

Indicates the local IP address. If this parameter is set to 0.0.0.0, this parameter needs to be negotiated.

Mask

Indicates the subnet mask of the local IP address. If this parameter is set to 0.0.0.0, it needs to be negotiated.

Peer IP

Indicates the peer IP address. If the BS is connected to an upper-level node, this address is specified according to the upper-level node. If the BS is cascaded to a lower-level node, this address must be specified. This parameter can be set to 0.0.0.0.

PPPMUX

Indicates whether to enable the PPP multiframe multiplexing function. If this parameter is set to ENABLE, multiple PPP frames are multiplexed on the PPP link to reduce the bandwidth overhead.

IP Header Compression

Indicates whether to enable IP header compression.

Address and Control Field Compression

Indicates whether to enable the compression of the address field and control field.

Protocol Field Compression

Indicates whether to enable protocol field compression.

Maximum Receive Unit(byte)

Indicates the Maximum Receive Unit (MRU). If the size of a received packet is greater than the MRU value, the packet is discarded.

Link Status

Indicates the status of the PPP link.

LCP Status

Indicates the status of the Link Control Protocol (LCP) protocol.

IPCP Status

Indicates the status of the IP Control Protocol (IPCP).

PPPMUX Status

Indicates the status of the PPP MUX.

Local IP Negotiation Result

Indicates the local IP address negotiated with the peer end.

Local IP Mask Negotiation Result

Indicates the mask of the local IP address that is negotiated with the peer end.

Peer IP Negotiation Result

Indicates the peer IP address negotiated with the peer end.

IPHC Negotiation Result

Indicates the negotiation result of the IP header compression.

ACFC Negotiation Result

Indicates the negotiation result of the compression switch of the address field and control field.

PFC Negotiation Result

Indicates the negotiation result of the compression switch of the protocol field.

PPPMUX Negotiation Result

Indicates the negotiation result of the PPP MUX.

Maximum Receive Unit Negotiation Result(byte)

Indicates the negotiation result of the maximum RX unit.

Number of TX Packets(packet)

Indicates the number of packets transmitted on the PPP link.

Number of TX Bytes(byte)

Indicates the number of bytes transmitted on the PPP link.

Number of TX Drop Packets(packet)

Indicates the number of discarded packets transmitted on the PPP link.

Number of RX Packets(packet)

Indicates the number of packets received on the PPP link.

Number of RX Bytes(byte)

Indicates the number of bytes received on the PPP link.

Number of RX Drop Packets(packet)

Indicates the number of discarded packets received on the PPP link.

TX Flow(byte/s)

Indicates the TX traffic of the PPP link.

RX Flow(byte/s)

Indicates the RX traffic of the PPP link.

Number of IPs

Indicates the number of IP addresses of the PPP link.

IP Address List

Indicates the list of IP addresses of the PPP link.

Diagnosis Info

This parameter specifies the diagnosis information about a PPP link, including the start time, diagnosis result, and fault ID. When a PPP link is established or reset, the diagnosis is triggered automatically. The default diagnosis period is 60s and the diagnosis information is displayed in the command output.
