Display IKE SA Information (DSP IKESTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query basic information about an Internet Key Exchange (IKE) Security Association (SA).

Note

[NodeB]The WMPT does not support this function.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where an IKE SA is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board where an IKE SA is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the slot number of the board where an IKE SA is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query basic information about an IKE SA with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, run the following command: 
DSP IKESTAT: CN=0, SRN=0, SN=1;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where an IKE SA is located.

Subrack No.

Indicates the subrack number of the board where an IKE SA is located.

Slot No.

Indicates the slot number of the board where an IKE SA is located.

Number of IKE Peers

Indicates the number of IKE peers.

Number of IKE Proposals

Indicates the number of IKE proposals.

Number of IKEv1 SAs

Indicates the total number of Internet Key Exchange Version 1 (IKEv1) SAs (in phases 1 and 2).

Number of SAs in IKEv1 Phase 1

Indicates the number of SAs in IKEv1 phase 1.

Number of SAs in IKEv1 Phase 2

Indicates the number of SAs in IKEv1 phase 2.

Number of Established SAs in IKEv1 Phase 1

Indicates the number of established SAs in IKEv1 phase 1.

Number of Established SAs in IKEv1 Phase 2

Indicates the number of established SAs in IKEv1 phase 2.

Number of IKEv2 SAs

Indicates the number of Internet Key Exchange Version 2 (IKEv2) SAs.

Number of SAs in IKEv2 Phase 1

Indicates the number of SAs in IKEv2 phase 1.

Number of IKEv2 Child SAs

Indicates the number of IKEv2 child SAs.

Number of IKE Transmissions

Indicates the number of IKE transmissions.

Number of IKEv1 Exchanges

Indicates the number of IKEv1 exchanges.

Number of IKE-Related Connections

Indicates the number of IKE-related connections.
