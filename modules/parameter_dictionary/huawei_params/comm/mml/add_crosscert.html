Add Cross Certificate (ADD CROSSCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a cross-certificate.

Note

  • Before running this command, ensure that the corresponding cross-certificate file has been downloaded to the BS by running the DLD CERTFILE command.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, a maximum of 20 cross-certificates can be configured.

  • Board specifications: An LMPT/UMPT/UMDU/GTMUc/UTRPc/UCCU/UBBPe series (except UBBPe15)/LCOP/UBBPf series/UBBPF series/UBBPg series board supports a maximum of 20 cross-certificates.

  • The file size of the cross-certificate to be loaded must be less than 30KB.

  • If the number of certificates reaches 30, this command will return failure, manually delete the useless certificates.

Parameters

ID Name Description
CERTNAME Certificate File Name

Meaning: Indicates the name of the cross-certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CERTNAME in a CROSSCERT MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CROSSCERT MO is being added, the CERTNAME is case-insensitive; but when a CROSSCERT MO is referenced, the CERTNAME is case-sensitive.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a cross-certificate with parameters as follows: Certificate File Name: CACrossCert.pem, run the following command:
ADD CROSSCERT: CERTNAME="CACrossCert.pem";
