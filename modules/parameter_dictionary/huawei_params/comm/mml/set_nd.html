Set IPv6 Neighbor Discovery Protocol Parameters (SET ND)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set IPv6 ND parameters.

Note

[Co-MPT,eNodeB,gNodeB]The neighbor discovery time of this NE should be set according to the reachable time setting of the switch and router neighbors in the network.

Parameters

ID Name Description
NDREACHABLETIME Neighbor Discovery Reachable Time

Meaning: Indicates the length of the timer for the reachable status of the neighbor discovery protocol entry in IPv6 transmission.

GUI Value Range: 5000~3600000

Unit: ms

Actual Value Range: 5000~3600000

MML Default Value: None

Recommended Value: 1200000

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: A too short neighbor reachability time is not recommended. If the neighbor reachability time is reduced, neighbor reachability detection is accelerated, consuming network bandwidth and CPU resources of network equipment. This may cause CPU flow control or network congestion. As a result, neighbor discovery reachability detection fails, and service packet transmission is affected.

Applicable Mode: L, N

Example

To set neighbor discovery reachable time with the parameters as follows: NDREACHABLETIME: 5000, run the following command: 
SET ND: NDREACHABLETIME=5000;
