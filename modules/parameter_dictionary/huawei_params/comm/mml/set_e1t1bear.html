Set E1/T1 Bear Mode (SET E1T1BEAR)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the bearing mode of an E1/T1 port on a specified board.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]The bearing mode settings of an E1/T1 port on the WMPT and UTRP (subboard type is UAEC, excluding the UTRPa) does not take effect until the base station is reset. If the board is not reset within 10 minutes after the command is executed, ALM-26245 Configuration Data Inconsistency will be reported.

  • [Co-MPT,NodeB]Before running this command to set the E1/T1 bearing mode to IP, remove the ATM configuration related to the E1/T1 port.

  • [Co-MPT,NodeB]Before running this command to set the E1/T1 bearing mode to ATM, remove the IP configuration related to the E1/T1 port.

Example

To set the E1/T1 Bear Mode as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Bear Mode: ATM, run the following command: 
SET E1T1BEAR: CN=0, SRN=0, SN=6, MODE=ATM;
