Remove Device IP Address (RMV DEVIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a device IP address from a port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is used to remove only the device IP address that is added by running the ADD DEVIP command. The added device IP addresses can be listed by running the LST DEVIP command.

  • This operation may interrupt the services or OM channels carried on this device IP address. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • [NodeB,eNodeB,gNodeB]You cannot remove a device IP address used by a link such as an IP path, remote maintenance channel, and BFD session.

Example

Example 1: To remove a device IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, IP Address: 192.168.2.24, run the following command: 
RMV DEVIP: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, IP="192.168.2.24";
Example 2: To remove a device IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Subboard Type: E1_COVERBOARD, Port Type: MPGRP, Port No.: 1, IP Address: 192.168.11.23, run the following command: 
RMV DEVIP: CN=0, SRN=0, SN=1, SBT=E1_COVERBOARD, PT=MPGRP, PN=1, IP="192.168.11.23";
