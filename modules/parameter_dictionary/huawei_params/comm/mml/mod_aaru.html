Modify AARU Configuration (MOD AARU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the active antenna radio unit (AARU) configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS,eNodeB]Changing the settings of AARU Work Standard and Logical Switch of TX Channel may affect the services carried on this AARU.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The AARU may use different software versions when it works in different modes. Therefore, the software version of the AARU may change when its working mode is changed.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If an AARU is on an RRU chain/ring configured on an RMU port, the working mode of the AARU can be set only to LO, GO, GL, UO, UL, GU, or GUL.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When an AARU and a BBU are served by the same power supply system, set the Power Supply Group ID parameter of the AARU to 0.

Example

To modify an AARU with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 1, AARU Name: "AARU2", Intermediate Frequency Offset: 0, Logical Switch of TX Channel: "ON", run the following command: 
MOD AARU: CN=0, SRN=60, SN=1, AN="AARU2", IFOFFSET=0, TXSW=ON;
