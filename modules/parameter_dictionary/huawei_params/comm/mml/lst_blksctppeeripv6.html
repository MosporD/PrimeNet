List SCTP Peer IPv6 Address Block Information (LST BLKSCTPPEERIPV6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the SCTP peer IPv6 addresses that have been blocked.

Note

None.

Parameters

None.

Example

List SCTP Peer IPv6 Address Block Information:
LST BLKSCTPPEERIPV6:;
following:
+++    0        2018-09-08 20:13:53
O&M    #805306415
%%LST BLKSCTPPEERIPV6:;%%
RETCODE = 0  Operation succeeded.

List SCTP Peer IPv6 Address Block Information
---------------------------------------------
        VRF Index  =  0
Peer IPv6 Address  =  2001:DB8::1
(Number of results = 1)


---    END

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance.

Peer IPv6 Address

Indicates the peer IPv6 address of a blocked SCTP link.
