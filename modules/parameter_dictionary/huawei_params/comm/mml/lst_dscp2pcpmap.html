List DSCP-to-PCP Mapping Configuration (LST DSCP2PCPMAP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of mapping tables between DSCPs and VLAN priorities.

Note

None.

Parameters

ID Name Description
DSCP2PCPMAPID DSCP-to-PCP Mapping ID

Meaning: Indicates the ID of the mapping table between DSCPs and VLAN priorities.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The DSCP2PCPMAP MO with DSCP2PCPMAPID set to 0 cannot be removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the configuration of a DSCP-to-PCP Mapping Table, run the following command:
LST DSCP2PCPMAP:;
The result is as follows:

Output Description

Field Description

DSCP-to-PCP Mapping ID

Indicates the ID of the mapping table between DSCPs and VLAN priorities.

Default PCP

Indicates the default number of the queue used for non-mapped DSCPs.

User Label

Indicates the description of the mapping table between DSCPs and VLAN priorities.

DSCP List Mapping to PCP 0

Indicates the list of DSCPs mapping to VLAN priority 0 in the mapping table.

DSCP List Mapping to PCP 1

Indicates the list of DSCPs mapping to VLAN priority 1 in the mapping table.

DSCP List Mapping to PCP 2

Indicates the list of DSCPs mapping to VLAN priority 2 in the mapping table.

DSCP List Mapping to PCP 3

DSCP List Mapping to PCP 7

Indicates the list of DSCPs mapping to VLAN priority 7 in the mapping table.
