Set Periodic Integrity Check Task (SET INGCHKTSK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set periodic integrity check task.

Note

After modifying the local account information or user right information, or updating the key materials, you are advised to update the service configuration baseline in a timely manner.

Parameters

ID Name Description
FLINGCHKSW File Integrity Check Switch

Meaning: Indicates the file integrity check switch.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
FLINGCHKTM File Integrity Check Time

Meaning: Indicates the time of a daily file integrity check. The value must be an integer ranging from 00:00 to 23:00.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
FLINGCHKITEM File Integrity Check Item

Meaning: Indicates the file integrity check item.

GUI Value Range: SERVICESOFTWARE(Service Software), SERVICECONFIG(Service Configuration), OSFILE(OS File), THIRDPARTY(Third-Party Software), AUDITLOG(Audit Log)

Unit: None

Actual Value Range: SERVICESOFTWARE, SERVICECONFIG, OSFILE, THIRDPARTY, AUDITLOG

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid when file integrity check is enabled. In the INGCHKTSK MO, FLINGCHKITEM cannot be set to empty.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set periodic integrity check with the parameters as follows: File Integrity Check Switch: ON, File Integrity Check Time: 3, File Integrity Check Item: Audit Log, run the following command: 
SET INGCHKTSK: FLINGCHKSW=ON, FLINGCHKTM=3, FLINGCHKITEM=AUDITLOG-1;
