Test Activated Device Certificate (TST APPCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to test a device certificate. When a test on a device certificate starts, the BS attempts to use this device certificate to set up a secure channel to a peer device through negotiation and then returns the negotiation result.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only a device certificate that has taken effect can be tested by running this command.

  • To test a Secure Sockets Layer (SSL) device certificate, perform the corresponding operations on the Certificate Management window on the MAE. Note that SSL device certificates cannot be tested by running MML commands on the maintenance terminal.

  • After a test is started on an Internet Key Exchange (IKE) device certificate, if the BS fails to use this device certificate to negotiate with the peer end, the secure channel established between the BS and the peer end is temporarily interrupted. Upon completion of the test, the BS uses the preceding activated device certificate to negotiate with the peer end and to restore the secure channel.

  • This command cannot be executed in the following cases: (1) The value of SA Flag is Fading (you can run the DSP IKESA command to query the value of SA Flag). (2) SA renegotiation or SA re-authentication is to be performed. You can perform IKE tracing to observe whether the SA renegotiation or SA re-authentication is being performed.

  • When an Internet Key Exchange (IKE) device certificate is tested, the IKE peer name must be specified if a base station has multiple IKE peers that reference different device certificates.

Parameters

ID Name Description
APPTYPE Application Type

Meaning: Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS.

GUI Value Range: IKE(IKE), SSL(SSL), DTLS(DTLS)

Unit: None

Actual Value Range: IKE, SSL, DTLS

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
APPCERT Certificate File Name

Meaning: Indicates the file name of an activated device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]It is recommended that the value of APPCERT in an APPCERT MO be ASCII characters. A certificate file name can neither contain only space characters (including space and tab) nor contain the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks (""), left angle bracket (<), right angle bracket (>), and bar (|).

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
IKEPEER IKEPeer Name

Meaning: Indicates the IKE name of the peer device, which is used in IKE negotiation with the local end to test an activated device certificate.

GUI Value Range: 0~15 characters

Unit: None

Actual Value Range: 0~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the APPCERT MO, this parameter is valid only when APPTYPE is set to IKE.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SCTPNO SCTP Link No.

Meaning: Indicates the number of the SCTP link. The value of SCTPNO in the SCTPLNK MOs configured by users ranges from 0 to 65535. The value of SCTPNO in the SCTPLNK MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: 0

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the APPCERT MO, this parameter is valid only when APPTYPE is set to DTLS.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To test a connection to the certificate file with the parameters as follows: Application Type: IKE, Certificate File Name: appcert.pem, IKEPeer Name: peer, run the following command:
TST APPCERT: APPTYPE=IKE, APPCERT="appcert.pem", IKEPEER="peer";
