Remove LLDP Port Info (RMV LLDPPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove the configuration of an LLDP port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the LLDPLOCAL is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the LLDP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Unit: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SRN Subrack No.

Disuse statement: This parameter will be deleted in later versions. SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where the LLDPLOCAL is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the LLDP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. GUI Value Range: ETH_COVERBOARD(Ethernet Cover Board), BASE_BOARD(Base Board)

Unit: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the LLDPLOCAL MO, if SN is within the range from 0 to 5, this parameter must be set to ETH_COVERBOARD.
  • In the LLDPLOCAL MO, if SN is set to 6 or 7, this parameter can be set to BASE_BOARD or ETH_COVERBOARD.

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PN Port No.

Meaning: Indicates the number of the Ethernet port where the LLDPLOCAL is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the LLDP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the LLDPLOCAL MO, if SBT is set to BASE_BOARD, this parameter can be set to any value in the range from 0 to 3.
  • In the LLDPLOCAL MO, if SBT is set to ETH_COVERBOARD, this parameter can be set to any value in the range from 0 to 5.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove configuration of LLDP port as follows: Slot No.: 7, Subboard Type: Base Board, Port No.: 1, run the following command: 
RMV LLDPPORT: SN=7, SBT=BASE_BOARD, PN=1;
