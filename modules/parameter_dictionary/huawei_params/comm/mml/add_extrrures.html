Add Shared External RRU Resources (ADD EXTRRURES)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add shared external RRU resources that another NE provides for the local NE. When a DCU is connected with a BBU, the DCU shares its RRUs with the BBU. The RF resources provided by these RRUs are configured on the BBU so that the BBU can use the RF resources.

Note

None.

Example

Use this command to add a Shared External RRU Resources with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, RCS Server No: 0 and Server RRU Name:"NewRRU".
ADD EXTRRURES: CN=0, SRN=60, SN=0, RCSSERVERNO=0, SERVERRRUNAME="NewRRU";
