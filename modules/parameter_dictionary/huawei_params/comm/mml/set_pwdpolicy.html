Set Password Policy (SET PWDPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to configure the password security policy.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After the maximum validity period for the password expires, the user has to change the password when logging in to the LMT.

  • It is recommended that the default password policy or the password policy with a higher security level be used. If the password policy with a low security level is used, the created password may be cracked.

  • If the minimum length of a password is less than 8, the minimum password length of 8 takes effect.

  • [Co-MPT,NodeB,eNodeB,gNodeB]NR does not support the Wi-Fi maintenance function currently. The Wi-Fi access compliance principle in the password security policy parameter is not applicable to NR.

Meaning: Indicates the minimum length of the password. The default value of this parameter is 12.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) must comply with this policy.

WiFi users' passwords must comply with this policy.

Parameter Relationship: None

COMPLICACY Password Complicacy

Meaning: Indicates the minimum requirements for password complexity. This parameter is used to set the character types that a password must contain, which can be any combination of lowercase letters, uppercase letters, digits, and special characters. If NULL is displayed in the query result, there is no special limitation on the character type. A password contains lowercase letters, uppercase letters, digits, and special characters by default.

User passwords comply with this policy as follows:

Local users' passwords must comply with this policy.

NMS users' passwords (emscomm or emscommneteco user) must comply with this policy.

WiFi users' passwords must comply with this policy.

MAXCCUN Maximum Consecutive Characters from User Name

Meaning: Indicates the number of consecutive characters from a user name that cannot be contained in a password. Note that characters from a user name are case-insensitive in a password. The default value is 5. The value 0 indicates that the system does not check for consecutive characters.

For example, if a user name is userA123 and this parameter is set to 3, a password cannot contain three or more consecutive characters from userA123. That is, passwords, such as use5678, ser5678, and erA5678, cannot be used.

Example

To set the security policy related to password with the parameters as follows: 
Password Minimal Length: 10, Password Complicacy: LOWERCASE-1DIGIT-1, Password Max Miss Times: 3, Auto Unlock Time: 30, Reset Interval of Account Lock: 5, New Password Repeat Limit: 5, Password Validity: 30, Minimum Password Duration: 1440, Password Expiration Reminder: 10, Must Modify Password When First Login Switch: Off, Max Repeat Char Times: 2, Weak Dictionary Check Switch: Off, Maximum Consecutive Characters from User Name: 1, run the following command: 
SET PWDPOLICY: PWDMINLEN=10, COMPLICACY=LOWERCASE-1&DIGIT-1, MAXMISSTIMES=3, AUTOUNLOCKTIME=30, RESETINTERVAL=5, PASSREPLMT=5, MAXPERIOD=30, MINPERIOD=1440, PWDEXPRT=10, FirstLoginMustModPWD=OFF, MAXREPEATCHARTIMES=2, DICTCHKPWD=OFF, MAXCCUN=1;
