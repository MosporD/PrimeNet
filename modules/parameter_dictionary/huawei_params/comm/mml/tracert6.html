IPv6 Trace Route (TRACERT6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to obtain the information about gateways on a route between the host and the destination by sending IPv6 packets on the route. This command can be used to check whether a route is reachable and help locate the position where a network connection fault occurs.

Note

  • [Co-MPT,eGBTS,eNodeB,gNodeB]This command cannot be used together with the PING, PING6, TRACERT, CFMTRACE, CFMPING, or UDPECHO command.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When the TRACERT6 command is being executed, You can press Ctrl+Q or run the STP PATHCHK command to stop running the TRACERT6 command.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]In TRACERT6 packets, "*" indicates that the detection expires, "!" indicates that the port is unreachable, "!N" indicates that the network is unreachable, "!Y" indicates that the IP address is unreachable, "!P" indicates the protocol is unavailable, "!S" indicates that the source route fails, and "!H" indicates that the host is unreachable.

  • [Co-MPT,eNodeB,gNodeB]When the TRACERT6 command is executed, the destination IPv6 address cannot set to the local IPv6 address.

Example

To start IPv6 route tracing with the parameters as follows: Source IPv6 Address: "2001:DB8::1", Destination IPv6 Address: "2001:DB8::2", run the following command:
TRACERT6: SRCIPV6="2001:DB8::1", DSTIPV6="2001:DB8::2";
