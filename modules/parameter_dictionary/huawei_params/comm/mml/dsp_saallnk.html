Display SAAL Link Status (DSP SAALLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of an SAAL link.

Note

  • [Co-MPT,NodeB]The execution result indicates the negotiated data. It may be inconsistent with the configuration. The result of this command is the data that takes effect currently.

  • [Co-MPT,NodeB]The execution result shows the momentary status of an SAAL link. It is recommended that the status of the link be determined based on the execution result and alarm.

Parameters

ID Name Description
SAALNO Link No.

Meaning: Indicates the number of the SAAL link.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To query the status of an SAAL link whose Link No. is set to 0, run the following command:
DSP SAALLNK: SAALNO=0;
The result is shown as follows:
+++    0        2010-06-30 19:55:53                                        
O&M    #276                                                                     
%%DSP SAALLNK: SAALNO=0;%%                                                      
RETCODE = 0  Operation succeeded.                                               
                                                                                
Display SAAL Link Status                                                        
------------------------                                                        
       Link No.  =  0                                                           
SAAl Link State  =  Abnormal                                                    
(Number of results = 1)                                                         
                                                                                
                                                                                
---    END

Output Description

Field Description

Link No.

Indicates the number of the SAAL link.

SAAl Link State

Indicates the status of the SAAL link. The status is either normal or abnormal. If the status is normal, this link can receive and transmit upper-layer user data properly. If the status is abnormal, this link cannot receive or transmit upper-layer user data.
