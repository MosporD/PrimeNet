Display Board Manufacturing Information (DSP BRDMFRINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the manufacturing information about a board. Only one board can be queried at a time. Because there is only one backplane in the BBU subrack, the manufacturing information about the subrack can be obtained by the query of the manufacturing information about the backplane.

Note

  • Currently, only the BBU supports the query of the manufacturing information about the backplane.

  • When querying the manufacturing information about the backplane, set the slot number to 255.

  • The manufacturing information of an FAN board that has not been configured in a BBU cannot be queried.

  • This command may conflict with periodic electronic label tasks. If a conflict occurs, the system displays the following error message: "The e-label query process included in this operation conflicts with an existing e-label query process. Please try later." In this case, run this command one minute later.

Example

1. To query the manufacturing information about the board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, run the following command:
DSP BRDMFRINFO: CN=0, SRN=0, SN=7;

Output Description

Field Description

Type

Indicates the type of the board or the cabinet.

Serial Number

Indicates the bar code of the board or the cabinet.

Description

Indicates the description about the services and functions provided by the board or the cabinet.

Date of Manufacture

Indicates the manufacturing date of the board or the cabinet.

Vendor

Indicates the manufacturer of the board or the cabinet.

Issue Number

Indicates the issue number of the board.
