Display RF Card (DSP RFCPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about ports on RF cards.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet housing the RF card which provides the port.

Subrack No.

Indicates the number of the subrack housing the RF card which provides the port.

Slot No.

Indicates the number of the slot housing the RF card which provides the port.

Port No.

Indicates the downlink switch of the port on the RF card.

DL Input Power(0.1dBm)

Indicates the downlink input power of the port on the RF card. If all carriers on the port are deactivated, the value is invalid.

Attenuation of Power Adjustment(0.1dB)

Indicates the power attenuation value of the port on the RF card.

Upper Threshold of Power(0.1dBm)

Indicates the over-power threshold of the port on the RF card.

Lower Threshold of Power(0.1dBm)

Indicates the under-power threshold of the port on the RF card.

Start UL Frequency(0.1MHz)

Indicates the start uplink working frequency of the port on the RF card.

End UL Frequency(0.1MHz)

Indicates the end uplink working frequency of the port on the RF card.

Start DL Frequency(0.1MHz)

Indicates the start downlink working frequency of the port on the RF card.

End DL Frequency(0.1MHz)

Indicates the end downlink working frequency of the port on the RF card.
