Display Shared External RRU Resources Status (DSP EXTRRURES)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of shared external RRU resources.

Note

None.

Parameters

Meaning: Indicates the subrack number of shared external RRU resources.

GUI Value Range: 60~254

Unit: None

MML Default Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

GUI Value Range: 0

Example

To query the Status about a Shared External RRU Resources, run the following command:
DSP EXTRRURES:;
+++    0        2017-11-02 14:48:27
O&M    #3477
%%DSP EXTRRURES:;%%
RETCODE = 0  Operation succeeded.

Display Shared External RRU Resources Status
--------------------------------------------

0            60           0         0               NewRRU           Unavailable     
0            61           0         0               EXTRRU           Available     
(Number of results = 2)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of shared external RRU resources.

Subrack No.

Indicates the subrack number of shared external RRU resources.

Slot No.

Indicates the slot number of shared external RRU resources.

RCS Server No.

Indicates the number of the RCS server where an RRU entity providing the shared external RRU resources is located.

Server RRU Name

Indicates the name of an RRU entity providing the shared external RRU resources. This parameter must be set to the name of this RRU entity configured on the RCS server that provides the RRU.

User Label

Indicates the user-defined information about shared external RRU resources.

Resource Status

Indicates the availability status of an RRU entity providing shared external RRU resources.
