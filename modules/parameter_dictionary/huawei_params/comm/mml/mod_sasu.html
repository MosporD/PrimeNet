Modify SASU (MOD SASU)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the configuration of a same-band antenna sharing unit (SASU).

Note

  • [Co-MPT,NodeB,eGBTS]If the system is busy, the configuration may take effect beyond the specified time, and the configuration data will be sent to the SASU later. The execution result can be checked by running the DSP SASU command and querying the device running status.

  • [Co-MPT,NodeB,eGBTS]The SASU is available only when the ALD current alarm threshold is set and the ALD power supply switch is set to ON. For details about how to query the port status, see the DSP ANTENNAPORT and DSP RETPORT commands. For details about how to modify the port status, see the MOD ANTENNAPORT and MOD RETPORT commands.

  • [Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the ALD. The device number of the ALD must be unique.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

[Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENO in the RET MO, DEVICENO in the TMA MO, DEVICENO in the SASU MO, DEVICENO in the RAE MO, DEVICENO in the RVD MO, and DEVICENO in the RAS MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
DEVICENAME Device Name

Meaning: Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

GUI Value Range: 0~83 characters

Unit: None

Actual Value Range: 0~83 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

[Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the SASU MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
CTRLCN Control Port Cabinet No.

Meaning: Indicates the cabinet number of the RRU or RFU that controls the ALD.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
CTRLSRN Control Port Subrack No.

Meaning: Indicates the subrack number of the RRU or RFU that controls the ALD.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLCN in the ALD MO ranges from 0 to 15, the value of CTRLSRN can be 4, 5, or a number ranging from 60 to 254. When the value of CTRLCN in the ALD MO ranges from 16 to 62, CTRLSRN must be set to 4 or 5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
CTRLSN Control Port Slot No.

Meaning: Indicates the slot number of the RRU or RFU that controls the ALD.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLSRN in the ALD MO is set to 4 or 5, the value of CTRLSN ranges from 0 to 8 if TYPE in the CABINET MO where the ALD MO is located is set to BTS3900AL. The value of CTRLSN ranges from 0 to 5 if TYPE is not set to BTS3900AL. When the value of CTRLSRN in the ALD MO is set to 60, CTRLSN ranges from 0 to 5. When the value of CTRLSRN in the ALD MO ranges from 61 to 254, CTRLSN is set to 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
DCSWITCH DC Switch

Meaning: Indicates the status of the DC power supply switch for the antenna port. The value range of this parameter is BS (GSM antenna power supply), UMTS (UMTS antenna power supply), OFF (Off), or DEVICE_DEFAULT_VALUE (Device default value). If this parameter is set to DEVICE_DEFAULT_VALUE, it is invalid and the actual DC Load switch is not changed. When the SASU is connected to a TMA, this parameter must be set to BS or UMTS for powering the TMA. Otherwise, this parameter is set to OFF.

GUI Value Range: BS, UMTS, OFF

Unit: None

Actual Value Range: BS, UMTS, OFF

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the SASU is connected to a lower-level TMA, setting this parameter to OFF will power off the TMA. This increases the call drop rate and decreases the access success rate for users at the cell edge.

Applicable Mode: G, U
VENDORCODE Vendor Code

Meaning: Indicates the vendor code.

GUI Value Range: 0~2 characters

Unit: None

MML Default Value: None

[Co-MPT, NodeB, eGBTS]If SERIALNO in a SASU MO has been set, VENDORCODE in the SASU MO must be set.

VENDORCODE and SERIALNO in the SASU MO; 4. VENDORCODE and SERIALNO in the RAE MO; 5. VENDORCODE and SERIALNO in the RVD MO; 6. VENDORCODE and SERIALNO in the RAS MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

VENDORCODE and SERIALNO in the SASU MO; 4. VENDORCODE and SERIALNO in the RAE MO; 5. VENDORCODE and SERIALNO in the RVD MO; 6. VENDORCODE and SERIALNO in the RAS MO.

[Co-MPT, NodeB, eGBTS]If VENDORCODE in a SASU MO has been set, SERIALNO in the SASU MO must be set.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To modify the configuration of an SASU with the parameters of as follows: Device No.: 0, Device Name: PEOPLESQUARE_SEC1_SASU_02, run the following command:
MOD SASU: DEVICENO=0, DEVICENAME="PEOPLESQUARE_SEC1_SASU_02";
