Set Clock Output (SET TSTCLKOUT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the types of test clocks to be outputted.

Note

  • Before setting the Output Clock Type parameter on a UMPT board, run the DSP PHYPORT command to check whether the corresponding clock port is enabled. The setting of Output Clock Type takes effect only when the corresponding clock port is enabled.

  • Only the UMPT board supports the 1PPS+TOD test clock. A board does not support input of the TOD reference clock and output of the 1PPS+TOD test clock at the same time.

  • When the Output Clock Type parameter is CUR_REFCLK, the following reference clock sources do not support clock output: IPCLK, SYNCETH+IPCLK, RRU RGPS, and CGPS.

Example

To set clock output type with the parameters as follows: Slot No.: 6, Output Clock Type: CUR_REFCLK, run the following command:
SET TSTCLKOUT: SN=6, CLKOUTTYPE=CUR_REFCLK;
