Display SASU Device Data Dynamic Information (DSP SASUDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the dynamic information in the same-band antenna sharing unit (SASU) device data.

Note

[Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the SASU.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
SUBUNITNO Subunit No.

Meaning: Indicates the number of the subunit, which starts from 1.

GUI Value Range: 1~2

Unit: None

Actual Value Range: 1~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To query the dynamic information in the SASU device data with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP SASUDEVICEDATA: DEVICENO=0, SUBUNITNO=1;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the SASU.

Subunit No.

Indicates the number of the subunit, which starts from 1.

Connect Antenna Model Number

Indicates the model of the connected RET antenna.

Serial No.

Indicates the serial number of the antenna.

Real Subunit Type

Indicates the type of the subunit. It indicates whether the VSWR measurement and the bypass mode are supported.

Real Gain Resolution(0.25dB)

Indicates the step for the SASU gain change.

Max Supported Gain(0.25dB)

Indicates the maximum gain supported by the SASU.

Min Supported Gain(0.25dB)

Indicates the minimum gain supported by the SASU.

Real Received Max Frequency Band

Indicates the maximum RX frequency band supported by the SASU.

Real Received Min Frequency Band

Indicates the minimum RX frequency band supported by the SASU.

Real Transmit Max Frequency Band

Indicates the maximum TX frequency band supported by the SASU.

Real Transmit Min Frequency Band

Indicates the minimum TX frequency band supported by the SASU.
