Modify MDU (MOD MDU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configurations of Multimode Digital Unit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]You need to set Base Band Work Standard according to actual situations. Incorrect settings may interrupt ongoing services.

BBWS Base Band Work Standard

Meaning: Indicates the modes for which the UMDU provides baseband processing resources. If the UMDU provides only CPRI ports for a mode, you do not need to configure this mode for the UMDU.

GUI Value Range: GSM(GSM), UMTS(UMTS), LTE_FDD(LTE FDD), LTE_TDD(LTE TDD), NBIOT(NB-IoT), NR(NR)

Unit: None

Actual Value Range: GSM, UMTS, LTE_FDD, LTE_TDD, NBIOT, NR

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]For a UMDU board, the BBWS parameter can be set to a combination of LTE TDD and LTE FDD, and cannot be set to a combination of LTE TDD and a mode other than LTE FDD.
  • [Co-MPT, NodeB, eGBTS, eNodeB]A maximum of three options can be selected under the BBWS parameter for the UMDU.
  • [Co-MPT, NodeB, eGBTS, eNodeB]For the MDUC board, the BBWS parameter can be set to UMTS or LTE FDD.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
BRDSPEC Board Specification

Meaning: Indicates the type of a board. If the user does not need to forcibly verify the board specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. If the user needs to forcibly verify the board specifications using the MAE-Deployment, this parameter must be set to the hardware type of the board. For example, this parameter must be set to BBU3910a1 for a BBU3910a1 board and be set to BBU3910a2 for a BBU3910a2 board. After this parameter is specified, the MAE-Deployment checks the configurations of the board based on the value of this parameter. This ensures that these configurations are correct before they take effect.

GUI Value Range: 0~15 characters

Unit: None

Actual Value Range: 0~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CCNE Cell Channel Number Extension

Meaning: Indicates the cell channel number extension switch. When this parameter is set to ON, more cell channels are supported and the distance between channels decreases. The UMDU supports this parameter and it takes effect only to the BBU3910a9. In addition, the BBU3910a9 is reset after this parameter is modified. The parameter takes effect only in LTE.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify the configuration of the MDU with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Cell Channel Number Extension: ON, run the following command:
MOD MDU: CN=0, SRN=0, SN=6, CCNE=ON;
