Display SFP Module (DSP SFP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information of an optical or electrical module.

Note

  • If value of the field in the command output is NULL, the module does not support the query of this field or is faulty.

  • The type of an SFP port on a BBP is CPRI or HEI. The number of a CPRI port ranges from 0 to 5 (set the port number based on the board hardware capability, the number of a CPRI port on a UBBPem or UBBPf0 is 0 or 1, and the number of a CPRI port on a UBBPf1 or UBBPg4 ranges from 0 to 2). The number of the HEI port is 6 (set the port number based on the board hardware capability). The type of a UBBPei port is XCI or HEI. The number of an XCI port is 0 or 1. The number of the HEI port is 6. The type of an SFP port on a GTMU is CPRI or FE/GE/XGE/YGE. The number of a CPRI port ranges from 0 to 5. The number of the FE/GE/XGE/YGE port is 1. The type of an SFP port on a BRI is CPRI and the port number ranges from 0 to 5. The type of an SFP port on a UCCU or UCXU is M and the port number ranges from 0 to 5. The type of an SFP port on a UCIU is M or S. The number of an M port ranges from 0 to 4. The number of the S port is 8. The type of an SFP port on a UMDU is CPRI, FE/GE/XGE/YGE, or HEI. The number of a CPRI port ranges from 0 to 5. The number of the FE/GE/XGE/YGE port is 1. The number of an HEI port is 6 or 7. The type of an SFP port on an RRU, RFU, AAS, or CGPS is CPRI and the port number is 0 or 1. The type of an SFP port on a TRP is FE/GE/XGE/YGE and the port number is 0 or 1 (set the port number based on the board hardware capability). The type of the SFP port on a WMPT is FE/GE/XGE/YGE and the port number is 1. The type of the SFP port on an LMPT is FE/GE/XGE/YGE and the port number is 0 or 1. The type of an SFP port on a UMPTa or UMPTb is FE/GE/XGE/YGE or CI. The number of the FE/GE/XGE/YGE port is 1. The number of the CI port is 8. The type of an SFP port on a UMPTe, UMPTg or UMPTga is FE/GE/XGE/YGE or CI. The number of an FE/GE/XGE/YGE port is 1 or 3. The number of the CI port is 8. The type of an SFP port on an RMU is CPRI or XCI. The number of a CPRI port ranges from 0 to 11. The number of an XCI port is 0 or 1. The type of an SFP port on an RHUB is CPRI or CPRI_E/CPRI_O. The number of a CPRI port ranges from 0 to 3. The number of a CPRI_E/CPRI_O port is 0 to 15.

  • Only LampSite supports query optical link attenuation value.

  • When used to query optical link attenuation value, if CPRI MUX/eCPRI MUX is deployed in separate-MPT scenarios, the optical attenuation value between the baseband processing board port and the first-level RRU is NULL on the converged party.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the optical or electrical module.

Subrack No.

Indicates the subrack number of the optical or electrical module.

Slot No.

Indicates the slot number of the optical or electrical module.

Port Type

Indicates the type of the port.

Port No.

Indicates the number of the optical or electrical module.

Installed status

Indicates whether the optical or electrical module is in position.

SFP Module Type

Indicates the type of optical or electrical modules, including SFP optical port, ESFP optical port, SFP electrical port, QSFP optical port, QSFP electrical port, CPRI electrical port, DWDM fixed wavelength optical port, DWDM tunable wavelength optical port, and DSFP optical port. These types of optical modules are different in the supported transmission rates, transmission distance, and the number of channels. SFP_ELECTRIC indicates the module at either end of an SFP electrical cable. QSFP_ELECTRIC indicates the module at either end of a QSFP electrical cable. Electrical modules support a short transmission distance and therefore are used for connecting BBUs and RFUs. The SFP module is a small hot-swappable module, which can be connected to an optical or electrical module. The module indicated by ESFP_OPTICAL is different from that indicated by SFP_OPTICAL in the supported rate set. The QSFP module provides four bi-directional channels and the SFP module provides one bi-directional channel. CPRI_ELECTRIC indicates a module in an RJ45 connector and the module is used to connect the RHUB and MPMU, transmitting data through Ethernet cables. The DWDM fixed wavelength optical port uses the wavelength division multiplexing (WDM) and the wavelength after multiplexing is fixed. The DWDM tunable wavelength optical port uses the WDM and supports multiple wavelengths, with wavelengths dynamically switched. The DSFP optical port supports two SFP channels. Each channel can be connected to a single-fiber bidirectional optical module through a single-fiber bidirectional optical fiber. NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

Manufacturer name

Indicates the manufacturer of the optical or electrical module.

Version

Indicates the version of the optical module.

Transmission Mode

Indicates the transmission mode of the optical module, that is, single-mode or multi-mode.

Wavelength(0.01nm)

Indicates the wavelength of the optical module.

ITU Grid Channel

Indicates the ID of the ITU channel corresponding to the wavelength of the optical module.It is the channel number defined by the International Telecommunication Union (ITU) for wavelength.

Transmission code rate(100Mbit/s)

Indicates the transmission code rate of the optical or electrical module. Generally, the value of this parameter equals the maximum rate supported by an optical module. However, some optical modules support rates higher than this parameter value. This parameter under "Channels Carried over the Port" indicates the rate of a single channel.

Transmission distance of single-mode fiber[100m(100ft)]

Indicates the transmission distance of the single-mode fiber optic cable. The value NULL indicates that the optical module does not support this type of fiber optic cable.

Transmission distance of OM1 multi-mode fiber[10m(10ft)]

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM1. The value NULL indicates that the optical module does not support this type of fiber optic cable.

Transmission distance of OM2 multi-mode fiber[10m(10ft)]

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM2. The value NULL indicates that the optical module does not support this type of fiber optic cable.

Transmission distance of OM3 multi-mode fiber[10m(10ft)]

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM3. The value NULL indicates that the optical module does not support this type of fiber optic cable.

Transmission distance of OM4 multi-mode fiber[10m(10ft)]

Indicates the transmission distance of the multi-mode fiber optic cable supporting OM4. The value NULL indicates that the optical module does not support this type of fiber optic cable.

Temperature[0.1 degree Celsius(0.1 degree Fahrenheit)]

Indicates the observed temperature of the optical module.

Voltage(100microvolt)

Indicates the observed voltage of the optical module.

Current(2microampere)

Indicates the observed current of the optical module or channel.

TX optical power(0.1microwatt)

Indicates the TX optical power of the optical module or channel. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.

RX optical power(0.1microwatt)

Indicates the RX optical power of the optical module or channel. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.

Receive Power Upper Threshold(0.1microwatt)

Indicates the upper threshold for the receive power of an optical module.

Receive Power Lower Threshold(0.1microwatt)

Indicates the lower threshold for the receive power of an optical module.

Transmit Power Upper Threshold(0.1microwatt)

Indicates the upper threshold for the transmit power of an optical module.

Transmit Power Lower Threshold(0.1microwatt)

Indicates the lower threshold for the transmit power of an optical module.

Channel No.

Indicates the number of the channel carried over the port where the optical or electrical module is located.

Available Status

Indicates the status of the channel carried over the port where the optical or electrical module is located.

TX optical power(0.01dBm)

Indicates the TX optical power of the optical module. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.

RX optical power(0.01dBm)

Indicates the RX optical power of the optical module. If the command output for an optical module includes Channels Carried over the Port, the value of this parameter under Display SFP Module Dynamic Information is NULL and the actual value is displayed under Channels Carried over the Port.

Receive Power Upper Threshold(0.01dBm)

Indicates the upper threshold for the receive power of an optical module.

Receive Power Lower Threshold(0.01dBm)

Indicates the lower threshold for the receive power of an optical module.

Transmit Power Upper Threshold(0.01dBm)

Indicates the upper threshold for the transmit power of an optical module.

Transmit Power Lower Threshold(0.01dBm)

Indicates the lower threshold for the transmit power of an optical module.

Chain No.

Indicates the ID of the RRU chain/ring. It uniquely identifies a chain within a base station.

UpperLevelNodeCabinetNo

Indicates the cabinet number of the upper-level node of a CPRI link.

UpperLevelNodeSubrackNo

Indicates the subrack number of the upper-level node of a CPRI link.

UpperLevelNodeSlotNo

Indicates the slot number of the upper-level node of a CPRI link.

UpperLevelNodePortNo

Indicates the port number of the upper-level node of a CPRI link.

UpperLevelNodeSubPortNo

Indicates the subport number of the upper-level node of a CPRI link.

LowerLevelNodeCabinetNo

Indicates the cabinet number of the lower-level node of a CPRI link.

LowerLevelNodeSubrackNo

Indicates the subrack number of the lower-level node of a CPRI link.

LowerLevelNodeSlotNo

Indicates the slot number of the lower-level node of a CPRI link.

LowerLevelNodePortNo

Indicates the port number of the lower-level node of a CPRI link.

LowerLevelNodeSubPortNo

Indicates the subport number of the lower-level node of a CPRI link.

Direction

Indicates the direction of the CPRI link.

AttenuationValue(0.01dB)

Indicates the attenuation value of the CPRI link, If the value is 0, the attenuation calculated based on the optical power at both ends is small.

UpperLevelNodePortType

Indicates the port type of the upper-level node of a CPRI link.

LowerLevelNodePortType

Indicates the port type of the lower-level node of a CPRI link.
