Add IPv4 Address (ADD IPADDR4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IPv4 address for a port.

Note

  • In the same routing domain, the IPv4 addresses of different ports must be on different network segments, whereas the IPv4 addresses of the same port can be on the same network segment.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT is the main control board, a maximum of 128 IPv4 addresses can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 64 IPv4 addresses can be configured.

  • Board specifications: A maximum of 128 IPv4 addresses can be configured on a WMPT/UMPT/UMDU/LMPT/UTRP (subboard type: UAEC/UIEC). A maximum of 16 IPv4 addresses can be configured on a GTMUb/GTMUc. A maximum of 56 IPv4 addresses can be configured on a UTRPc. A maximum of 24 IPv4 addresses can be configured on a UTRP (subboard type: UEOC). A maximum of 40 IPv4 addresses can be configured on a UTRP (subboard type: UQEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • [Co-MPT,NodeB,eNodeB]A maximum of eight IPv4 addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, or a sub-interface. A maximum of seven IPv4 addresses can be configured on a port that carries a PPP link or an MP group. A maximum of two IPv4 addresses can be configured on a loopback interface.

  • [NodeB,eNodeB,gNodeB]It is recommended that the subnet mask be a 32-bit mask for the IPv4 address at a loopback interface.

  • [Co-MPT,eNodeB,gNodeB]It is recommended that a maximum of one IPv4 address be configured for an Ethernet CI port in the system.

  • [Co-MPT,eNodeB]If an error message indicating an IP address conflict is displayed during the configuration of an IPv4 address, search the existing IP address in the system that may conflict with the IPv4 address by running the following commands: LST IPADDR4, DSP IPADDR4, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, DSP MPGRP, LST IPROUTE4, DSP IPROUTE4, LST SRCIPROUTE4, DSP SRCIPROUTE4, LST BFD, DSP BFD, LST UDPSESSION, DSP UDPSESSION, LST TWAMPCLIENT, DSP TWAMPCLIENT, LST IPPATHRT, and DSP IPPATHRT. Then, manually resolve the IP address conflict. The conflicting IP address may be an IPv4 address, local IP address of a remote maintenance channel, local IP address of a PPP link, IP address for local maintenance, local IP address of an MP group, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session, peer IP address of a UDP session, peer IP address of a TWAMP client, or next-hop IP address of an IP path route.

  • [NodeB]If an error message indicating an IP address conflict is displayed during the configuration of an IPv4 address, search the existing IP address in the system that may conflict with the IPv4 address by running the following commands: LST IPADDR4, DSP IPADDR4, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, DSP MPGRP, LST IPROUTE4, DSP IPROUTE4, LST SRCIPROUTE4, DSP SRCIPROUTE4, LST BFD, DSP BFD, LST UDPSESSION, DSP UDPSESSION, LST TWAMPCLIENT, and DSP TWAMPCLIENT. Then, manually resolve the IP address conflict. The conflicting IP address may be an IPv4 address, local IP address of a remote maintenance channel, local IP address of a PPP link, IP address for local maintenance, local IP address of an MP group, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session, peer IP address of a UDP session, or peer IP address of a TWAMP client.

  • [NodeB]A maximum of four loopback interfaces can be configured on a board.

  • [eNodeB]If the LMPT is used as the main control board, the IPv4 address with the port type set to PPP or MPGRP can be successfully configured but will fail to take effect.

  • [gNodeB]If an error message indicating an IP address conflict is displayed during the configuration of an IPv4 address, search the existing IP address in the system that may conflict with the IPv4 address by running the following commands: LST IPADDR4, DSP IPADDR4, LST OMCH, DSP OMCH, LST LOCALIP, DSP LOCALIP, LST IPROUTE4, DSP IPROUTE4, LST SRCIPROUTE4, DSP SRCIPROUTE4, LST BFD, DSP BFD, LST TWAMPCLIENT, and DSP TWAMPCLIENT. Then, manually resolve the IP address conflict. The conflicting IP address may be an IPv4 address, local IP address of a remote maintenance channel, IP address for local maintenance, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session , or peer IP address of a TWAMP client.

  • [gNodeB]A maximum of eight IPv4 addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, or a sub-interface. A maximum of two IPv4 addresses can be configured on a loopback interface.

IP IP Address

Meaning: Indicates the IP address configured on the port.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the IPADDR4 MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical operation result of IP and MASK in an IPADDR4 MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the binary value into which MASK in the IPADDR4 MO is converted, 0 is not allowed to precede 1.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical operation result of IP and MASK in an IPADDR4 MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.

Example

To add an IPv4 address with the parameters as follows: Interface ID: 100, IP Address: 192.168.2.24, Mask: 255.255.255.0, run the following command: 
ADD IPADDR4: ITFID=100, IP="192.168.2.24", MASK="255.255.255.0";
