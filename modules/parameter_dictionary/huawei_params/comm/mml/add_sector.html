Add Sector (ADD SECTOR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a sector and antennas in the sector.

Note

  • When the UMPTa/UMPTb or UMDU is used as the main control board, a base station supports a maximum of 108 sectors. When the UMPTe, UMPTg, or UMPTga is used as the main control board, a base station supports a maximum of 192 sectors. When the GTMUb is used as the main control board, a base station supports a maximum of 12 sectors. When the GTMUc is used as the main control board, a base station supports a maximum of 108 sectors. Otherwise, a base station supports a maximum of 102 sectors.

  • When the UMPTa/UMPTb or UMDU is used as the main control board, a base station supports a maximum of 576 sector antennas. When the UMPTe, UMPTg, or UMPTga is used as the main control board, a base station supports a maximum of 1152 sector antennas. When the GTMUb is used as the main control board, a base station supports a maximum of 48 sector antennas. When the GTMUc is used as the main control board, a base station supports a maximum of 288 sector antennas. Otherwise, a base station supports a maximum of 216 sector antennas.

  • A sector can be added with a maximum of eight antennas. After a sector is added, operators can run the MOD SECTOR command to add more antennas.

  • If the sector equipment with Antenna Config Mode set to ANTENNAPORT is to be configured in a sector, the antennas must be configured for the sector and include all antennas of the corresponding to sector equipment.

  • If the sector equipment with Antenna Config Mode set to BEAM is to be configured in a sector, an antenna does not need to be configured for the sector equipment in the sector.

  • If both the sector equipment with Antenna Config Mode set to ANTENNAPORT and the sector equipment with Antenna Config Mode set to BEAM are to be configured in a sector, an antenna needs to be configured only for the sector equipment with Antenna Config Mode set to ANTENNAPORT in the sector.

  • When the sector antenna is the antenna connection port of the RF module, the channel number of the sector antenna is identified by R0A to R0P. When the sector antenna is the virtual antenna port of the AAS, the channel number of the sector antenna is identified by R0A to R7D.

  • An antenna belongs only to one sector.

  • When a sector is added, the value of Create Default Sector Equipment can be specified as required. The default value of Antenna Config Mode is ANTENNAPORT for the default sector equipment and all antennas in the sector are included. In addition, each antenna in the sector equipment works in TX and RX mode and is configured as a master antenna. The antennas added through the MOD SECTOR command will not be added to the default sector equipment.

  • The number of antennas cannot be set to 0, when default sector equipment is added.

  • You can run the ADD QUICKSECTOR command to quickly create sectors and sector equipment. The following are two example scenarios where this command is recommended:

    1. A sector or a set of sector equipment uses antennas of one RRU.

    2. A sector is served by multiple RRUs with the same receiving and sending mode.

  • If an antenna of a sector is configured in slot 255, a maximum of two antennas can be configured for the sector and the following conditions must be met:

    1. The cabinet and subrack numbers of two antennas must be the same.

    2. Each of the antennas is configured in slot 255.

    3. The channel number of each antenna must be R0A or R0B.

  • If the slot number of the antenna in a sector is not 255, the antennas in other sectors cannot have the same cabinet number or subrack number as the antenna in this sector, and the slot numbers of these antennas cannot be 255. If the slot number of the antenna in a sector is 255, the antennas in other sectors cannot have the same cabinet number or subrack number as the antenna in this sector.
