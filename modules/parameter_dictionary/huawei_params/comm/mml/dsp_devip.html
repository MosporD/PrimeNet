Display Device IP Address (DSP DEVIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the device IP addresses that take effect.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]If a device IP address is configured on a loopback interface and the inter-board ARP proxy is used for transmission, Address Status is always Valid.

  • [Co-MPT,NodeB,eNodeB]The local maintenance port and wireless local maintenance port have been isolated from service ports. Therefore, the IP address that is negotiated by the PPP or MP link on a service port can be the same as the IP address of the local maintenance port or wireless local maintenance port.

  • [Co-MPT,NodeB,eNodeB]The execution result shows all IP addresses (including user-configured and negotiated IP addresses) that are set on PPP ports, MLPPP ports, Ethernet ports, Ethernet trunk ports, Ethernet CI ports, loopback interfaces and Sub-interfaces.

  • [gNodeB]The execution result shows all IP addresses (including user-configured and negotiated IP addresses) that are set on Ethernet ports, Ethernet trunk ports, Ethernet CI ports, and loopback interfaces.

Example

To query device IP addresses with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, run the following command: 
DSP DEVIP: CN=0, SRN=0;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the port is located.

Subrack No.

Indicates the subrack number of the board where the port is located.

Slot No.

Indicates the slot number of the board where the port is located.

Subboard Type

Indicates the type of sub-board on the board where a port is located.

Port Type

Indicates the type of the port. The UMTS currently does not support SUBIF.

Port No.

Indicates the number of a port.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Address

Indicates the IP address configured for the port.

Mask

Indicates the subnet mask of the device IP address configured on the port.

Address Status

Indicates the status of the IPv4 address. If Valid is displayed, it indicates that the IP address is available. If Invalid is displayed, it indicates that the port corresponding to the IP address is not activated. If Duplicate is displayed, it indicates that the IP address conflicts with the IP address of an external device.
