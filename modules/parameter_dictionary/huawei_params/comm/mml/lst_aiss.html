List Air Interface Soft Synchronization Parameters (LST AISS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the air interface soft synchronization parameters.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]Only GSM and LTE FDD support the air interface soft synchronization function.

Parameters

None.

Example

To list Air Interface Soft Synchronization Parameters, run the following command:
LST AISS:;
The result is shown as follows:
+++    0        2012-10-08 14:19:17
O&M    #13532
%%LST AISS:;%%
RETCODE = 0  Operation succeeded.

List Air Interface Soft Synchronization Parameters
--------------------------------------------------
  Air Interface Soft Synchronization Switch  =  On
Air Interface Soft Synchronization Standard  =  GSM
    Soft-Synchronized Network Adaption Mode  =  Enhanced Mode
       Air Soft Syn Phase Adjustment Period  =  480 Seconds
(Number of results = 1)


---    END

Output Description

Field Description

Air Interface Soft Synchronization Switch

Indicates whether the Air interface Soft synchronization Phase Lock function is enabled on the NE, which can be set to ON or OFF. ON indicates that the switch for the Air interface soft synchronization phase lock function is set to on and OFF indicates that the Air interface soft synchronization phase lock function is set to off.

Air Interface Soft Synchronization Standard

Indicates the standard where the Air interface soft synchronization function is enabled.

Soft-Synchronized Network Adaption Mode

Indicates the adaption mode of the soft synchronous transport network. The value of this parameter depends on the synchronous status of the transport network.

Air Soft Syn Phase Adjustment Period

Indicates the adjustment period of the frame clock phase when the Air interface soft synchronization Phase Lock function is enabled on the NE.
