Display SASU Subunit Dynamic Information (DSP SASUSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the dynamic information about one or all same-band antenna sharing unit (SASU) subunits.

Note

[Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the SASU.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
SUBUNITNO Subunit No.

Meaning: Indicates the number of the subunit, which starts from 1.

GUI Value Range: 1~2

Unit: None

Actual Value Range: 1~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To query the dynamic information about the SASU subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP SASUSUBUNIT: DEVICENO=0, SUBUNITNO=1;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the SASU.

Subunit No.

Indicates the number of the subunit, which starts from 1.

Online Status

Indicates the status of the SASU subunit.

Realtime Work Mode

Indicates the actual working mode of an SASU, Value range: NORMAL(NORMAL), BYPASS(BYPASS).

Actual Sector ID

Indicates the sector ID of an SASU subunit.

GSM Realtime Gain(dB)

Indicates the gain on the BS channel.

UMTS Realtime Gain(dB)

Indicates the actual gain on the UMTS channel.

Realtime DC Load(20mA)

Indicates the real-time DC load for the SASU.

LNA DC Current(mA)

Indicates the DC current of the Low Noise Amplifier (LNA).

VSWR Current Alarm Occur Threshold(0.1)

Indicates the Voltage Standing Wave Ratio (VSWR) alarm occur threshold.

VSWR Current Alarm Clear Threshold(0.1)

Indicates the Voltage Standing Wave Ratio (VSWR) alarm clear threshold.

LNA Current Normal Alarm Occur Threshold(mA)

Indicates the normal alarm occur threshold for the Low Noise Amplifier (LNA) current.

LNA Current Normal Alarm Clear Threshold(mA)

Indicates the normal alarm clear threshold for the Low Noise Amplifier (LNA) current.

LNA Current Serious Alarm Occur Threshold(mA)

Indicates the serious alarm occur threshold for the Low Noise Amplifier (LNA) current.

LNA Current Serious Alarm Clear Threshold(mA)

Indicates the serious alarm clear threshold for the Low Noise Amplifier (LNA) current.
