Add VRF (ADD VRF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a virtual routing and forwarding (VRF). The IP addresses and routes in the same routing domain must be unique, whereas those in different routing domains are independent of each other.

Note

  • The VRF1-7 function takes effect only for LTE and NR.

  • Non-default VRF cannot be added when DEVIP port type is not a loopback interface or sub-interface.

  • [Co-MPT,eNodeB,gNodeB]The non-default VRF function is not supported in inter-board and inter-subrack scenarios.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance.

GUI Value Range: 1~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
USERLABEL User Label

Meaning: Indicates the description of a VRF instance.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a VRF with the parameters as follows: VRF Index: 1, User Label: "aaaa", run the following command:
ADD VRF: VRFIDX=1, USERLABEL="aaaa";
