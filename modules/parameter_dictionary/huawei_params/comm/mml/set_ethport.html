Set Ethernet Port (SET ETHPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to configure an Ethernet port. The configuration of an Ethernet port includes (but not limited to) the port rate, duplex mode, and port attribute.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When a MAC loopback is performed on a port, running this command will immediately terminate this loopback.

  • The settings of the SPEED and DUPLEX parameters must be the same between the local and peer ends. Otherwise, the negotiation may fail.

  • If the SPEED and DUPLEX parameters are both set to AUTO, the local port automatically adjusts its data rate based on the data rate and duplex mode at the peer end so that both ends work at the highest rate and the optimal duplex mode. Generally, it takes about 5 seconds for the negotiation to complete.

  • If an electrical module is used at the local end to connect to an electrical port at the peer end, it is recommended that PA of the peer electrical port be set to AUTO.

  • If the local end works in AUTO mode whereas the peer end works in non-AUTO mode, the duplex mode at the local end may be negotiated and set to HALF. In this case, packet loss and intermittent link disconnection may occur if links are activated, affecting the work performance.

  • The DUPLEX parameter at the local end must be set to AUTO to detect the configuration mode of the peer end. After the detection, the original configuration must be recovered.

  • If the SPEED and DUPLEX parameters of an Ethernet port at the local end are both set to AUTO, and those at the peer end are set to a fixed rate and FULL, respectively, the duplex mode at the local end may be negotiated and set to HALF. If this negotiation is achieved, the local end will forcibly change it to FULL. If the local end is inactive due to modifications at the peer end, SPEED and DUPLEX of the Ethernet port at the local end are changed back to AUTO.

  • When Port Attribute, Speed, and Duplex are all set to AUTO, you need to disable the optical port on the peer device or remove the fiber optic cable after modifying the attribute of the optical port on the peer device. Then wait about 1 minute and enable the optical port or insert the fiber optic cable again. This ensures that the automatic detection function can be triggered when the local optical port is in the inactive state.

  • All packets sent from the backplane of a board (excluding the packets forwarded by the board) are segmented into fragments of 1500 bytes.

  • The MTU setting of the peer equipment should not exceed the maximum allowed MTU value of the local Ethernet port.

  • A UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 provides six physical ports, and the last one includes four Ethernet ports. Each Ethernet port can only be set to the optical port of 10 Gbit/s and full duplex.

  • GE electrical ports support 1000 Mbit/s only when working in auto-negotiation mode. If SPEED is set to 1000M for a GE electrical port, this port works at 1000 Mbit/s in auto-negotiation mode.

  • Ensure that parameters settings are consistent with those at the peer end. Otherwise, the services or OM channels carried on this port may be interrupted. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • If the "Fiber Speed Match" is "ENABLE" for a UMPT board, the meaning of this parameter is described as follows:

    The base station uses the configured data rate by default when the optical port is activated but the data rate cannot be obtained. This configuration scenario is not recommended.

  • When an Ethernet port is an optical port, the optical modules at both ends must have the same capability. When a 10GE/25GE optical module is used at the local end, the optical module cannot be used at a reduced rate. It is recommended that the configured rate be consistent with the optical module capability.

  • If this command is executed during the validation of the port mode after the SET PORTMODE command is executed, a message indicating that configuration data fails to take effect will be displayed.

  • An optical port which uses a 10 Gbit/s optical module only supports a data rate of 10 Gbit/s during site deployment. An optical port which uses a 25 Gbit/s optical module only supports a data rate of 25 Gbit/s during site deployment.

  • If the transmission configuration mode is new and no ETHPORT object is configured, run the SET ETHPORT command with Port ID set to a valid value.

  • For the UMPTa/b, UMDU, LMPT, UCCU, and UTRPc, the value of this parameter ranges from 46 to 1800. For the WMPT, GTMUb, GTMUc, UQEC, and UEOC, the value of this parameter ranges from 46 to 1500. For the UMPTe, the value of this parameter ranges from 46 to 2000. For the UMPTg and UMPTga, the value of this parameter ranges from 46 to 9000. If this parameter is set to a value greater than the maximum allowed value, the maximum allowed value takes effect. A value greater than or equal to 776 is recommended, because broadcast packets, such as DHCP packets, may experience reception or transmission failures if the maximum transmission unit is smaller than 776. If the Ethernet port is added to an Ethernet trunk, this parameter becomes invalid. The actual maximum transmission unit depends on the value set for the Ethernet trunk.

  • [Co-MPT,NodeB,eNodeB,gNodeB]A WMPT/UMPTa/UMPTb/UMDU provides two physical ports: one optical port (port 1) and one electrical port (port 0). An LMPT provides four physical ports: two optical ports and two electrical ports. A UMPTe/UMPTg/UMPTga provides four physical ports: two optical ports (ports 1 and 3) and two electrical ports (ports 0 and 2). A UQEC provides four electrical ports. A UEOC provides two optical ports. A UTRPc provides six physical ports: two optical ports (ports 0 and 1) and four electrical ports (ports 2 to 5). A UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 provides four physical optical ports (ports 0 to 3) if its port mode is 4*10GE; a UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 provides one physical optical port (port 0) if its port mode is 40GE; a UBBPf1 provides one physical optical port (port 0) if its port mode is 100GE.

  • [Co-MPT,NodeB]The rate mode and duplex mode of optical ports on a WMPT must be set to 100 Mbit/s and full duplex, respectively. The peer end must also have the same settings.

  • [Co-MPT,eGBTS]The electrical port on a GTMUb supports negotiation only when the SPEED parameter is set to 10M or 100M.

  • [Co-MPT,eGBTS]The SPEED and DUPLEX parameters must be set to 100M and FULL, respectively, for optical ports on a GTMUb or GTMUc. The peer end must also have the same settings.

  • [Co-MPT,eGBTS]If the GTMUb/GTMUc is the main control board, the board provides one electrical port (port 0) and one optical port (port 1).

  • [Co-MPT,eGBTS]The GTMUb does not support fragment reassembly of signaling packers (excluding SCTP packets) and service packets. The MTU parameter always uses the default value of 1500 bytes (which is the size of the IP packet including the IP header).

  • [Co-MPT,NodeB]Electrical ports on a WMPT support rate negotiation for only 10 Mbit/s and 100 Mbit/s.

  • [NodeB]It is recommended that SPEED of a UEOC, UTRPc, UCCU or UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9/UBBPf0 be set to a fixed rate. In addition, SPEED and DUPLEX of the local end must be the same as those of the peer end, respectively.

  • [eNodeB]For Ethernet ports on an LMPT, port No. 0 consists of the electrical port No. 0 and the optical port No. 0, and port No. 1 consists of the electrical port No. 1 and the optical port No. 1. Although an Ethernet port on the LMPT can be either electrical or optical, the port can only be set to one type. That is, the same Ethernet port cannot be configured to be an electrical port and an optical port at the same time.

SPEED Speed

Meaning: Indicates the speed mode of the Ethernet port. This parameter must be set to the same value as that of the peer port. GE electrical ports of base board support 1000 Mbit/s only when working in auto-negotiation mode. When Port Attribute is set to FIBER and Speed is set to AUTO for a GE optical port, the port works at a rate of 1000 Mbit/s in auto-negotiation mode. In this case, the base station can only negotiate the duplex mode with the peer device at a fixed rate of 1000 Mbit/s. When Port Attribute is set to FIBER and Speed is set to 1000M for a GE optical port, the port works at a rate of 1000 Mbit/s in forced mode. If the Ethernet port corresponding to the optical port of the main control board is not configured, the system uses the 1000 Mbit/s auto-negotiation mode by default. If the non-default 1000 Mbit/s auto-negotiation mode is used, for example, 10 Gbit/s optical port is used, you need to run the ADD ETHPORT command to set parameters such as the rate.

ARPPROXY ARP Proxy

Meaning: Indicates whether to enable the ARP proxy function on the Ethernet port. If the ARP proxy function is enabled, the system serves as an ARP proxy for a loopback interface address of the base station or for an interface IP address of a lower-level base station. If this function is disabled, the system does not serve as an ARP proxy for the loopback interface IP address of the base station or for the interface IP address of a lower-level base station. To access either IP address in this case, an external device on the same subnet must be configured with a route. If the Ethernet port is added to an Ethernet trunk, this parameter becomes invalid. Whether the ARP proxy function is enabled is determined by the setting of this parameter for the Ethernet trunk.

This parameter is valid only when Transmission Configuration Mode in the GTRANSPARA MO is set to OLD.

This parameter is invalid when Transmission Configuration Mode in the GTRANSPARA MO is set to NEW.

Disuse statement: This parameter will be deleted in later versions.
