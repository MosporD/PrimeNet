Display MLPPP Link Status (DSP MPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the status of one or all MLPPP links on a board.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]The execution result indicates the negotiated data. It may be inconsistent with the execution result of the LST MPLNK command. The result of this command is the data that takes effect currently.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The UMPT/UMDU does not support MPLNK-related measurement.

Example

To query the attributes of an MLPPP link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: BASE_BOARD, Link No.: 0, run the following command:
DSP MPLNK: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, PPPLNKN=0;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the MLPPP link is located.

Subrack No.

Indicates the number of the subrack where the MLPPP link is located.

Slot No.

Indicates the number of the slot where the MLPPP link is located.

Subboard Type

Indicates the type of sub-board where an MLPPP link is established.

Link No.

Indicates the number of the MLPPP link.

MLPPP Group No.

Indicates the number of the MLPPP group.

Maximum Receive Unit(byte)

Indicates the Maximum Receive Unit (MRU). The received packet whose length is greater than this parameter value is discarded.

Protocol Field Compression

Indicates whether to enable protocol field compression.

Address and Control Field Compression

Indicates whether to enable the compression of the address field and control field.

MLPPP Link Status

Indicates the status of the MLPPP link.

LCP Status

Indicates the status of the Link Control Protocol (LCP) protocol.

Maximum Receive Unit Negotiation Result(byte)

Indicates the negotiation result of the maximum RX unit.

PFC Negotiation Result

Indicates the negotiation result of the protocol field compression.

ACFC Negotiation Result

Indicates the negotiation result of the Address-And-Control-Field-Compression (ACFC).

Number of TX Packets(packet)

Indicates the number of packets transmitted.

Number of TX Bytes(byte)

Indicates the number of bytes transmitted.

Number of TX Drop Packets(packet)

Indicates the number of discarded packets transmitted.

Number of RX Packets(packet)

Indicates the number of packets received.

Number of RX Bytes(byte)

Indicates the number of bytes received.

Number of RX Drop Packets(packet)

Indicates the number of discarded packets received.

Diagnosis Info

This parameter specifies the diagnosis information about an MLPPP link, including the start time, diagnosis result, and fault ID. When an MLPPP link is established or reset, the diagnosis is triggered automatically. The default diagnosis period is 60s and the diagnosis information is displayed in the command output.
