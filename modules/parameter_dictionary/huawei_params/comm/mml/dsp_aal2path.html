Display AAL2 Path Status (DSP AAL2PATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of an AAL2 path.

Note

[Co-MPT,NodeB]The output of this command is the data negotiated between the BS and the peer end. If the negotiated data is inconsistent with the actual configuration, the negotiated data prevails.

Parameters

ID Name Description
NT Node Type

Meaning: Indicates the type of an AAL2 path. If the local end node is selected, the AAL2 path is used by local services. If the switching node is selected, the AAL2 path is used to connect to the controller through the hub BS. If the adjacent node is selected, the AAL2 path is used to connect to the lower-level BS through the hub BS.

GUI Value Range: LOCAL(End Node), HUB(Switching Node), ADJNODE(Adjacent Node)

Unit: None

Actual Value Range: LOCAL, HUB, ADJNODE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
ANI Adjacent Node ID

Meaning: Indicates the adjacent node ID of an AAL2 path.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
PATHID Path ID

Meaning: Indicates the number of an AAL2 path.

GUI Value Range: 1~4294967295

Unit: None

Actual Value Range: 1~4294967295

MML Default Value: 1

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To list the status of an AAL2 path with the parameters as follows: Node Type: LOCAL, run the following command: 
DSP AAL2PATH: NT=LOCAL;

Output Description

Field Description

Node Type

Indicates the type of an AAL2 path. If the local end node is selected, the AAL2 path is used by local services. If the switching node is selected, the AAL2 path is used to connect to the controller through the hub BS. If the adjacent node is selected, the AAL2 path is used to connect to the lower-level BS through the hub BS.

Adjacent Node ID

Indicates the adjacent node ID of an AAL2 path.

Path ID

Indicates the number of an AAL2 path.

AAL2 Path Status

Indicates the status of an AAL2 path.
