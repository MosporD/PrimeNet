List E1/T1 Bear Mode Configuration (LST E1T1BEAR)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the bearing mode settings of E1/T1 ports.

Note

None.

Parameters

None.

Example

To list the bearing mode settings of E1/T1 ports, run the following command:

LST E1T1BEAR:;

The result is shown as follows:
+++    0        2010-09-13 15:14:13
O&M    #1007
%%LST E1T1BEAR:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet housing the board where the bearing mode of an E1/T1 port is configured.

Subrack No.

Indicates the number of the subrack housing the board where the bearing mode of an E1/T1 port is configured.

Slot No.

Indicates the number of the slot housing the board where the bearing mode of an E1/T1 port is configured.

Bear Mode

Indicates the bearing mode of the E1/T1 port on a board.
