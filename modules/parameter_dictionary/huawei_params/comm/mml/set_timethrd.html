Set Time Threshold (SET TIMETHRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set parameters related to the threshold value for an NE. EVT-26360 Time Source Switchover is reported, when Time Hopping Detection Switch is set to On, time synchronization succeeds, and the difference between the NE time and the time provided by the time source is greater than the threshold.

Note

  • Either Time Hopping Detection Switch or Threshold Value must be specified.

  • If Time Hopping Detection Switch is set to ON and Threshold Value is not specified, a previous valid Threshold Value takes effect. If Threshold Value has not ever been set, the default value of 10 minutes is used.

Parameters

ID Name Description
SWITCH Time Hopping Detection Switch

Meaning: Indicates whether to detect time hopping on the NE.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
THRD Threshold Value

Meaning: Indicates the threshold value for the difference between the NE time and the time provided by the time source.

GUI Value Range: 1~65535

Unit: min

Actual Value Range: 1~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set Time Threshold Information with the parameters as follows: Time Hopping Detection Switch: ON, Threshold Value: 10, run the following command:
SET TIMETHRD: SWITCH=ON, THRD=10;
