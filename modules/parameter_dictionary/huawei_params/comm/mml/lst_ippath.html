List IP Path Configuration (LST IPPATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of an IP path.

Note

None.

Parameters

ID Name Description
PATHID Path ID

Meaning: Indicates the ID of an IP path.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To list the parameters of an IP path, run the following command:
LST IPPATH:;

Output Description

Field Description

Path ID

Indicates the ID of an IP path.

Transmission Configuration Mode

Indicates the configuration mode of the transmission model. The transmission model can be configured in old or new mode.

In old mode, the transmission model contains information such as cabinet, subrack, and slot numbers. Transmission configurations are bound to device boards.

In new mode, the transmission model has decoupled transmission and device models. That is, transmission configuration removes unnecessary cabinet, subrack, and slot configurations.

Join IP Transmission Resource Group

Indicates whether the IP path is added to an IP transmission resource group. When this parameter is set to DISABLE, the IP path is established on the default IP transmission resource group on a specified physical port.

IP Transmission Resource Group ID

Indicates the ID of the IP transmission resource group to which the IP path belongs.

Bearing Port Type

Indicates the physical port type of the IP path.

Port ID

Indicates the ID of the port to which the IP path belongs.

Cabinet No.

Indicates the cabinet number of the board where the IP path is located.

Subrack No.

Indicates the subrack number of the board where the IP path is located.

Slot No.

Indicates the slot number of the board where the IP path is located.

Subboard Type

Indicates the type of sub-board on the board where the IP path is established.

Port Type

Indicates the physical port type of the IP path.

Port No.

Indicates the number of the port where the IP path is configured.

Join Transmission Resource Group

Indicates whether the IP path joins a transmission resource group. If this parameter is set to DISABLE, the IP path is established on the default IP transmission resource group on a specific physical port.

Transmission Resource Group ID

Indicates the ID of the transmission resource group established on an IP path.

Path Type

Indicates the type of the IP path. FIXED indicates that this IP path is used to carry the service with specified Quality of Service (QoS), that is, with a specified DSCP. ANY indicates that this IP path can be used to carry services of any QoS and hence is used to carry the service without a specified DSCP.

DSCP

Indicates the differentiated services code point (DSCP) of the services carried on an IP path.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Local IP Address

Indicates the local IP address of an IP path. The value 0.0.0.0 indicates that the local IP address needs to be negotiated.

Peer IP Address

Indicates the peer IP address of the IP path.

Transmission Resource Type

Indicates the type of transport resource for the IP path. The value HQ indicates high-quality transport resources, and the value LQ indicates low-quality transport resources. This parameter must be set in the hybrid transmission scenario. In other scenarios, the default value of this parameter is used. The parameter takes effect only in LTE.

IP MUX Switch

Indicates whether the IP MUX function is enabled on IP paths. LTE currently does not support this function.

Maximum Length of IP MUX Subframe(byte)

Indicates the maximum subframe length of IP MUX. The LTE currently does not support the IP MUX function.

Maximum Length of IP MUX Multiframe(byte)

Indicates the maximum multiframe length of IP MUX. The LTE currently does not support the IP MUX function.

MUX Timer(ms)

Indicates the length of the IP MUX timer, which defines the maximum buffer time for IP MUX packets. The LTE currently does not support the IP MUX function.

Static Check Switch

Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE, the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE, the GTP-U static detection function is disabled for a link. When this parameter is set to FOLLOW_GLOBAL, the setting of the switch for the GTP-U static detection function is the same as that of the base station-level GTP-U detection switch. This parameter takes effect only in LTE.

Description

Indicates the description about the peer of the IP path.
