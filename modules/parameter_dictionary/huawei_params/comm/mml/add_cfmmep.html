Add CFM MEP (ADD CFMMEP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a local maintenance association end point (MEP).

Note

  • Only one local MEP can be configured in an MA of the BS.

  • The CFMMA MO is configured before the MEP is configured. The VLAN related parameters (such as VLANID and VLANPRIO) of the MEP and the CCM TX period are inherited from the MA.

  • During the adding of a CFMMEP MO, if an error message, indicating that the MO cannot be added because its dependent MO does not exist, is displayed, check whether the CFMMA MO exists.

  • The MD level of the Ethernet-trunk-based CFM MEP must be greater than that of the trunk-link-based CFM MEP.

  • System specifications: If the WMPT/GTMUb/GTMUc is the main control board, a maximum of 8 local MEPs can be configured. If the LMPT/UMPT/UMDU is the main control board, a maximum of 32 local MEPs can be configured.

  • Board specifications: A maximum of 4 local MEPs can be configured on a WMPT/UTRP (subboard type: UEOC/UQEC). A maximum of 8 local MEPs can be configured on a GTMUb/GTMUc. A maximum of 32 local MEPs can be configured on a UMPT/UMDU/LMPT/UTRPc/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. If the WMPT is the main control board, a maximum of 4 local MEPs can be configured on one board.

  • [NodeB,eNodeB,gNodeB]The MD level of a non-VLAN MEP at a port must be lower than that of all single-VLAN MEPs. Only non-VLAN MEPs rather than single-VLAN MEPs can be configured on the Ethernet trunk member port.

  • [eNodeB,gNodeB]The MEPs in one MA must have identical settings of the MD name, MA name, and VLAN ID. Otherwise, the MEPs are not regarded to be in the same MA.

Example

To add a CFM MEP with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, MEP ID: 1000, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, run the following command: 
ADD CFMMEP: MDNAME="CHINA", MANAME="SHANGHAI", MEPID=1000, CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0;
