Clear FMU Smoke Alarm (CLR FMUALM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to clear a fan monitoring unit (FMU) smoke alarm. When an FMU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.

Note

After the command is executed, if the fault that triggers the alarm persists, the alarm is reported again. To actually clear the alarm, go to the site to observe the situation and perform troubleshooting.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the FMU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the FMU is located.

GUI Value Range: 11~12

Unit: None

Actual Value Range: 11~12

MML Default Value: 11

Recommended Value: 11

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the FMU is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To clear the FMU smoke alarm in cabinet 0 and with other parameters in the default values, run the following command:
CLR FMUALM: CN=0;
