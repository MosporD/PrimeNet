Display Client Information Of LOCALWAP (DSP LOCALWAPCLT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query information of the terminal connected to the local WAP.

Note

None.

Parameters

None.

Example

To query information of the terminal connected to the local WAP, run the following command:
DSP LOCALWAPCLT:;
The result is shown as follows:
+++    0        2014-07-17 05:41:12
O&M    #280
%%DSP LOCALWAPCLT:;%%
RETCODE = 0  Operation succeeded.

Query information of the terminal connected to the local WAP
------------------------------------------------------------
Client MAC Address  =  0042-3353-6768
(Number of results = 1)


---    END

Output Description

Field Description

Client MAC Address

Indicates the MAC address of the terminal connected to the LOCALWAP(Local Wireless Access Point).
