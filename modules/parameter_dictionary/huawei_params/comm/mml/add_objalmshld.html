Add Alarm Shield by Object Type (ADD OBJALMSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an alarm suppression condition by object.

Note

  • To query the alarm masking condition by object that has been configured, run the LST OBJALMSHLD command.

  • If an alarm meets a condition that is set after the alarm is generated, the alarm is cleared. If an alarm meets a condition that is set before the alarm is generated, the alarm is not reported (that is, suppressed).

  • Some alarms cannot be shielded by running this command, and "This alarm cannot be shielded" will be displayed.

Example

To add an alarm suppression condition with the parameters as follows: Object Type: BRD, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Alarm ID Select Type: ONEBYONE, Object Alarm ID: 26203, run the following command:
ADD OBJALMSHLD: OBJTP=BRD, CN=0, SRN=0, SN=6, AIDST=ONEBYONE, OBJAID=26203;
