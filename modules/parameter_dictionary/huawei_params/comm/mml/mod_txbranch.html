Modify TX Channel (MOD TXBRANCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set a TXBRANCH MO of the RRU or RFU.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before changing the cable connections of RF modules or checking the connections of the antenna system, run this command to set the switch of the TX channel to OFF to protect yourselves against the radiation of RF signals. After changing or checking the connections, run this command to set the switch of the TX channel to ON.

  • In normal conditions, the switch of the RRU or RFU TX channel is set to ON. If the switch is set to OFF, cells carried on the RRU or RFU are not functional.

  • For a separate-MPT multimode base station, RRU/RFU TX channel physical switches can be turned off only when the TX channel logical switches for all RATs are turned off. If this switch is turned on for any RAT, the RRU/RFU TX channel physical switches are turned on. On a co-MPT multimode base station, turning off the TX channel logical switches affects all RATs carried on the channel.

Meaning: Indicates the subrack number of the RRU or RFU where the TX channel is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CN and SRN in the TXBRANCH must meet the following conditions: 1. When CN is set to a value ranging from 0 to 15, SRN must be set to 4, 5, or a value ranging from 60 to 254; 2. When CN is set to a value ranging from 16 to 62, SRN must be set to 4 or 5.

Service Interrupted After Modification: N/A

SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU where the TX channel is located.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]SRN and SN in the TXBRANCH must meet the following conditions: 1. When SRN is set to 4 or 5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to a value ranging from 0 to 8; 2. When SRN is set to 4 or 5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to a value ranging from 0 to 5; 3. When the value of SRN in a TXBRANCH MO ranges from 60 to 254 and RT in the RRU MO is set to MPRF, the value of SN in the TXBRANCH MO ranges from 1 to 3; 4. When the value of SRN in a TXBRANCH MO is set to 60 and RT in the RRU MO is not set to MPRF, SN in the TXBRANCH MO ranges from 0 to 5. 5. When the value of SRN in a TXBRANCH MO ranges from 61 to 254 and RT in the RRU MO is not set to MPRF, SN in the TXBRANCH MO must be set to 0.
  • [eGBTS]SRN and SN in the TXBRANCH must meet the following conditions: 1. When SRN is set to 4 or 5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to a value ranging from 0 to 8; 2. When SRN is set to 4 or 5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to a value ranging from 0 to 5; 3. When SRN is set to 60, SN must be set to a value ranging from 0 to 5. 4. When SRN is set to a value ranging from 61 to 254, SN must be set to 0.

TXSW Logical Switch of TX Channel

Meaning: Indicates the logical switch of the TX channel of the RRU or RFU. This switch is used to open or close the TX channel. The logical switch of the TX channel and the ARFCNs(absolute radio frequency channel numbers) on the TX channel determine the state of the physical switch of the TX channel: When this switch is ON and the TX channel is configured with ARFCNs(absolute radio frequency channel numbers), the physical switch is ON. In other cases, the physical switch is OFF. The value NULL for the Logical Switch of TX Channel parameter indicates that the parameter setting remains unchanged.

GUI Value Range: ON(ON), OFF(OFF), NULL(NULL)

Unit: None

Actual Value Range: ON, OFF, NULL

MML Default Value: None

Recommended Value: ON(ON)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the parameters of the TX channel of the RRU as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, TX Channel No.: 0, Logical Switch of TX Channel: "ON", run the following command:
MOD TXBRANCH: CN=0, SRN=60, SN=0, TXNO=0, TXSW=ON;
