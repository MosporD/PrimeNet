Modify SCTP Link (MOD SCTPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configurations of an SCTP link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eNodeB,gNodeB]If an SCTP link can be queried by running the LST SCTPLNK command and the value of the "Auto Config Flag" is "Auto Created", the SCTP link is automatically created by the system and cannot be modified by users.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Modifying any of the following parameters interrupts services: First Local IP Address, Second Local IP Address, Local SCTP Port No., First Peer IP Address, Second Peer IP Address, Peer SCTP Port No, IP Version, and Maximum SCTP PDU Size.

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first and second peer IP addresses of an SCTP link are different from the peer IPv4 address in the BLKSCTPPEERIPV4 object and the value of Block Flag for the SCTP link is UNBLOCK, the SCTP link is unblocked. In the same routing domain, if the first or second peer IP address of an SCTP link is the same as the peer IPv4 address in the BLKSCTPPEERIPV4 object or the value of Block Flag for the SCTP link is BLOCK, the SCTP link is blocked.

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first and second peer IPv6 addresses of an SCTP link are different from the peer IPv6 address in the BLKSCTPPEERIPV6 object and the value of Block Flag for the SCTP link is UNBLOCK, the SCTP link is unblocked. In the same routing domain, if the first or second peer IPv6 address of an SCTP link is the same as the peer IPv6 address in the BLKSCTPPEERIPV6 object or the value of Block Flag for the SCTP link is BLOCK, the SCTP link is blocked.

AUTOSWITCH Switch Back Flag

Meaning: Indicates whether the SCTP link switches back to the primary path when it is restored and reachable. If the primary path is not reachable, the SCTP link switches to the secondary path. When this parameter is set to ENABLE, the SCTP link switches to the primary path if the primary path is restored and reachable. When this parameter is set to DISABLE and the primary path is restored and reachable, the SCTP link does not switch back to the primary path if the secondary path is also reachable, and the SCTP link switches back to the primary path if the secondary path is unreachable.

MAXSCTPPDUSIZE Maximum SCTP PDU Size

Meaning: Indicates the maximum size of an IPv4 SCTP PDU (Protocol Data Unit). It specifies the maximum length of an SCTP PDU (excluding the IP header) transmitted on an SCTP link. If the value of this parameter is greater than the size of the IP layer MTU of the base station or intermediate transmission equipment, SCTP packets are fragmented at the IP layer. This causes a large number of fragments and affects the transmission efficiency of the intermediate transmission equipment.

GUI Value Range: 580~1480

Unit: byte

Actual Value Range: 580~1480

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a value too large, a large number of packets are fragmented or lost on the transmission network. As a result, the transmission delay increases and the performance deteriorates. If this parameter is set to a value too small, the valid transmission payload decreases and the transmission network bandwidth cannot be effectively used. As a result, the transmission delay increases and the transmission performance deteriorates.

Applicable Mode: G, U, L, N

Example

To modify information about an SCTP link with the parameters as follows: Link No.: 0, IP Version: IPv4, First Local IP Address: 192.168.1.24, First Peer IP Address: 10.52.21.89, Peer SCTP Port No: 1025, run the following command:
MOD SCTPLNK: SCTPNO=0, IPVERSION=IPv4, LOCIP="192.168.1.24", PEERIP="10.52.21.89", PEERPORT=1025;
