List RCS Server (LST RCSSERVER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an RCS server, which provides shared external RRU resources.

Note

None.

Parameters

ID Name Description
RCSSERVERNO RCS Server No.

Meaning: Indicates the number of an RCS server.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

Example

To query an RCS server, run the following command:
LST RCSSERVER:;
The result is shown as follows:
+++    0        2018-01-26 15:55:06
O&M    #3213
%%LST RCSSERVER:;%%
RETCODE = 0  Operation succeeded.

List RCS Server Configuration
-----------------------------
 RCS Server No.  =  0
RCS Server Name  =  RCStest
(Number of results = 1)


---    END

Output Description

Field Description

RCS Server No.

Indicates the number of an RCS server.

RCS Server Name

Indicates the name of an RCS server. An RCS client searches for the RCS server on the network based on this RCS server name. Upon finding the RCS server, the RCS client establishes a connection with the RCS server. If the RCS server is a DCU, this parameter must be set to the NE name of the DCU.

PORT ID

Indicates the ID of a port that is connected to an external NE.
