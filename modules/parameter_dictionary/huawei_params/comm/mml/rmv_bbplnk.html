Remove Base Band Processor Link (RMV BBPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to delete a baseband processing link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The BLADEBBU does not support this function.

  • Running this command may affect the transmission of baseband data and signaling between the BBUs, and make the mode where the alarm is reported fail to provide services or degrade its service processing capability.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the interconnection link.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To delete a baseband processing link with the parameters as follows: Link No.: 0, run the following command:
RMV BBPLNK: LN=0;
