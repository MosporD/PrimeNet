Display DNS (DSP DNS)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the DNS information of a base station.

Note

  • [Co-MPT,eGBTS,eNodeB,gNodeB]A maximum of 200 DNS information can be displayed by the command.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The DNS server may be unloaded because of validation failure of the client IP address on the server.

Parameters

ID Name Description
QRYFLG Query Flag

Meaning: Indicates the DNS query flag.

GUI Value Range: ALL(All), FAIL(Fail), SUCCESS(Success)

Unit: None

Actual Value Range: ALL, FAIL, SUCCESS

MML Default Value: ALL(All)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To query the DNS information, run the following command:
DSP DNS:;
The result is shown as follows:

Output Description

Field Description

Initial Domain Name

Indicates the initial domain name during a DNS query.

Fully Qualified Domain Name

Indicates the full domain name returned by the DNS server during a DNS query.

IP

Indicates the IP address returned by the DNS server during a DNS query.

DNS Server

Indicates the IP address of the DNS server used during a DNS query.

Resolution Result

Indicates whether the DNS resolution succeeds. If the value of this parameter is Success, the DNS of the initial domain name is successfully resolved. If the value of this parameter is Fail, the DNS of the initial domain name fails to be resolved.

Fail Reason

Indicates the cause of the failed DNS resolution.

Resolution Time

Indicates the time of the DNS resolution.
