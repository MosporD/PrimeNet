Start Transmission Quality Report (STR TRANSQUALITYRPT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start counting transmission quality reports. The transmission quality report collects information about packet reception and transmission on a transmission link, packet loss, error bits, and delay. The report is used for monitoring the transmission performance of a BS.

Note

  • [NodeB]If the number of transmission quality reports reaches the user-defined statistical threshold or the STP TRANSQUALITYRPT command is executed during statistics collection, the statistical task stops.

  • [NodeB]You cannot modify the statistical period and number of measurement times when transmission quality reports are being counted. You must run the STP TRANSQUALITYRPT command to stop counting the number of transmission quality reports.

  • [NodeB]You cannot start an E1/T1 online performance test, E1/T1 offline performance test, E1/T1 routine test, STM-1 online performance test, STM-1 offline performance test, STM-1 routine test, or an IMA test when the number of transmission quality reports is being counted.

  • [NodeB]When the number of transmission quality reports is being counted, do not use the CLEAR function of the following DSP commands to reset a parameter to 0: DSP ETHPORT, DSP ETHTRK, DSP FRAATM, DSP IMAGRP, DSP IMALNK, DSP MPGRP, DSP PPPLNK, and DSP UNILNK. Otherwise, the statistics may be incorrect.

  • [NodeB]To upload the transmission quality report, run the ULD FILE command with SRCF set to BRDLOG.

  • [NodeB]Measuring packet loss on IP paths is implemented based on IP PM detection. IP PM detection is a method for monitoring IP transmission quality by using forward monitoring (FM) and backward reporting (BR) packets. The detection result is the packet loss on uplink IP paths.

Parameters

ID Name Description
INTV Statistic Interval

Meaning: Indicates the time interval for collecting statistics about the transmission quality report.

GUI Value Range: 5MIN(5 Minutes), 15MIN(15 Minutes), 30MIN(30 Minutes), 1H(1 Hour), 12H(12 Hours), 24H(24 Hours)

Unit: None

Actual Value Range: 5MIN, 15MIN, 30MIN, 1H, 12H, 24H

MML Default Value: 24H(24 Hours)

Recommended Value: 24H(24 Hours)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
COUNT Statistic Times

Meaning: Indicates the number of times that transmission quality reports are counted. If the number of times that transmission quality reports are counted reaches this parameter value, the statistical task stops automatically.

GUI Value Range: 1~288

Unit: None

Actual Value Range: 1~288

MML Default Value: 1

Recommended Value: 1

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If INTV is set to 5MIN, the parameter can be set to any value in the range of 1 to 288. If INTV is set to 15MIN, the parameter can be set to any value in the range of 1 to 96. If INTV is set to 30MIN, the parameter can be set to any value in the range of 1 to 48. If INTV is set to 1H, the parameter can be set to any value in the range of 1 to 24. If INTV is set to 12H, the parameter can be set to 1 or 2. If INTV is set to 24H, the parameter must be set to 1.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To start collecting statistics about the transmission quality report with the parameters as follows: Statistic Interval: 5MIN, Statistic Times: 10, run the following command:
STR TRANSQUALITYRPT:INTV=5MIN, COUNT=10;
