Display SASU Dynamic Information (DSP SASU)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the dynamic information about one or all same-band antenna sharing units (SASUs).

Note

[Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the ALD. The device number of the ALD must be unique.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

[Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENO in the RET MO, DEVICENO in the TMA MO, DEVICENO in the SASU MO, DEVICENO in the RAE MO, DEVICENO in the RVD MO, and DEVICENO in the RAS MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To query the dynamic information about the SASU whose device number is 0, run the following command:
DSP SASU: DEVICENO=0;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the ALD. The device number of the ALD must be unique.

Actual Vendor Code

Indicates the vendor code of the device in the scanning result.

Actual Device Serial No.

Indicates the serial number of the device in the scanning result.

Actual Number of Subunits

Indicates the total number of ALD subunits.

Realtime DC Switch

Indicates the status of the DC power supply switch for the antenna port. The value range of this parameter is BS (GSM antenna power supply), UMTS (UMTS antenna power supply), or OFF (Off).

Control Port Cabinet No.

Indicates the cabinet number of the RRU or RFU that controls the ALD.

Control Port Subrack No.

Indicates the subrack number of the RRU or RFU that controls the ALD.

Control Port Slot No.

Indicates the slot number of the RRU or RFU that controls the ALD.

Control Port No.

Indicates the port number of the RRU or RFU that controls the ALD. It will be NULL if the RRU or RFU is not able to report this parameter.
