Add Baseband Equipment (ADD BASEBANDEQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a set of uplink, downlink, or uplink and downlink baseband equipment. Baseband processing units are added with the baseband equipment.

Note

  • Uplink services can be processed by uplink baseband equipment or uplink and downlink combined baseband equipment. Downlink services can be processed by downlink baseband equipment or uplink and downlink combined baseband equipment.

  • A maximum of 24 sets of baseband equipment that are capable of processing uplink services can be configured. A maximum of 12 sets of baseband equipment that are capable of processing downlink services can be configured. A base station supports a maximum of 36 baseband processing units.

  • In UMTS mode, only the WBBPf4 can be simultaneously added to two sets of baseband equipment that is capable of processing uplink services. If another type of baseband processing unit is simultaneously added to two sets of baseband equipment that is capable of processing uplink services, this type of baseband processing unit is unavailable in the second set.

  • If the baseband processing unit is the WBBP, before adding a baseband processing unit to a second set of baseband equipment that is capable of processing uplink services, run the BLK BRD command to block the baseband processing unit.

  • The baseband processing units in a set of uplink baseband equipment or uplink and downlink combined baseband equipment must be configured in the same subrack. The baseband processing units in a set of downlink baseband equipment can be configured in different subracks.

  • If a set of baseband equipment capable of processing uplink services (or combined uplink and downlink services) uses the adaptive UMTS demodulation mode in the uplink, WBBP series boards cannot be added to this baseband equipment set.

  • The ID of a set of uplink and downlink combined baseband equipment must differ from the ID of a set of uplink or downlink baseband equipment.

UMTSDEMMODE UMTS UL Demodulation Mode

Meaning: Indicates the demodulation mode of uplink baseband equipment for UMTS mode. When uplink (or uplink and downlink) baseband equipment is added, its demodulation mode must be specified. Different demodulation modes can be specified for different sets of uplink (or uplink and downlink) baseband equipment. This parameter cannot be set to NULL for UMTS. This parameter is not used for other modes, and it is recommended that this parameter be set to NULL.

GUI Value Range: NULL(NULL), DEM_4_CHAN(4-Channels Demodulation Mode), DEM_ECON_4_CHAN(Economical 4-Channels Demodulation Mode), DEM_2_CHAN(2-Channels Demodulation Mode), DEM_ADPT_CHAN(Self-adaption Demodulation Mode)

Example

To add a set of baseband equipment with the parameters as follows: Baseband Equipment ID: 0, Baseband Equipment Type: DL, Slot No. of Process Unit 1: 2, and Slot No. of Process Unit 2: 1, run the following command:
ADD BASEBANDEQM: BASEBANDEQMID=0, BASEBANDEQMTYPE=DL, SN1=2, SN2=1;
