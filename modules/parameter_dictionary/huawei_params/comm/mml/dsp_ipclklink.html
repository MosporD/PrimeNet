Display IP Clock Link (DSP IPCLKLINK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an IP clock link. If the link number is not specified, the status of all IP clock links is displayed.

Note

If the link number is not specified, only the following basic operation status information of IP clock links is displayed: IP Clock No., Link Available State, and Link Active State.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the IP clock link.

GUI Value Range: 0~2

Unit: None

Actual Value Range: 0~2

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the IPCLKLNK MO, when the value of DEVTYPE is set to OC_SLAVE, the value of LN must be 0 or 1. When the value of DEVTYPE is set to OC_MASTER, the value of LN must be 2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
CLEAR Clear Statistic

Meaning: Indicates whether the statistics are cleared, including the number of received packets, lost packets, and out-of-order packets. If this parameter is set to YES, the statistics are cleared. The LTE currently does not support this function.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(NO)

Recommended Value: NO(NO)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Output Description

Field Description

Link No.

Indicates the number of the IP clock link.

IP mode

Indicates the mode of the IP address.

Client IPv4

Indicates the client IPv4 address of the IP clock link.

Client IPv6

Indicates the client IPv6 address of the IP clock link. The UMTS currently does not support this function.

Link Available State

Indicates whether an IP clock link is available. If the HW_DEFINED or 1588 OC_SLAVE link is shown as available, it only indicates that the link between the base station and the clock server is connected. An available IP clock link may not be normally locked. Only an available clock link can serve as the current clock source. An unavailable clock link may not be normally locked even if it is activated. For the MASTER link, if the NE is configured with an external reference clock source for supplying reference clock signals, the OC_MASTER link is available only when the external reference clock source is locked.

Link Active State

This parameter indicates whether an IP clock link is activated. If an IP clock link is activated, it works as the reference clock source. For the HW_DEFINED IP clock link or OC_SLAVE IP clock link compliant with IEEE 1588 V2, this parameter is valid. For the OC_MASTER link, this parameter is invalid.

Step Mode

Indicates the step mode, which can be One Step or Two Step.

VLAN ID

Indicates the self-acquired VLAN ID of the IP clock server.

Number of Received Packets

Indicates the number of synchronization packets received over the IP clock link. The LTE currently does not support this function.

Number of Dropped Packets

Indicates the number of packets lost over the IP clock link. The LTE currently does not support this function.

Number of Disorder Packets

Indicates the number of out-of-order packets over the IP clock link. The LTE currently does not support this function.

Clock Source MAC Address

Indicates the MAC address of the clock source for the IP clock server. The MAC address must be in the format of XXXX-XXXX-XXXX.

Clock Server Description

Indicates the description of the clock server at the peer end of the clock link.

Grandmaster Quality Class

Indicates the clock quality level of the 1588 clock server. This parameter can be displayed in the command output only for an activated IEEE 1588v2-compliant OC_SLAVE clock link in IPv4 mode.

Grandmaster Clock ID

Indicates the ID of the 1588 clock server. This parameter can be displayed in the command output only for an activated IEEE 1588v2-compliant OC_SLAVE clock link in IPv4 mode.

Parent Port ID

Indicates the ID of the port on the upper-level clock device. This parameter can be displayed in the command output only for an activated IEEE 1588v2-compliant OC_SLAVE clock link in IPv4 mode.

Step from Grandmaster

Indicates the number of clock nodes between the 1588 clock server and NE. This parameter can be displayed in the command output only for an activated IEEE 1588v2-compliant OC_SLAVE clock link in IPv4 mode.

Client Clock ID

Indicates the clock ID of the base station functioning as the client (in OC_SLAVE mode).

VRF Index

Indicates the index of a virtual routing domain.
