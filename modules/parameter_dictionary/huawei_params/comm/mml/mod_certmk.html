Modify Device Certificate (MOD CERTMK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the binding relationship between device certificates and a CA.

Note

None.

Parameters

ID Name Description
APPCERT Certificate File Name

Meaning: Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in a CERTMK MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CERTMK MO is being added, the APPCERT is case-insensitive; but when a CERTMK MO is referenced, the APPCERT is case-sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery. There is only one such MO on an NE and this MO cannot be added or removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CASW CA Switch

Meaning: Indicates whether a CA server is specified for a device certificate. When this parameter is set to OFF, only one CA is configured or no CA is configured (the device certificate can be configured only in the offline mode). When this parameter is set to ON, a CA needs to be specified.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery, and CASW in the CERTMK MO must be set to OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CANAME Certificate Authority Name

Meaning: Indicates the name of the CA server specified by the certificate.

GUI Value Range: 1~127 characters

Unit: None

Actual Value Range: 1~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CERTMK MO, this parameter is valid only when CASW is set to ON.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes to CERTMK objects are made. When this parameter is set to YES, forcible changes to the CERTMK objects are made. When this parameter is set to NO, forcible changes to the CERTMK objects that affect associated objects are not allowed. When forcible changes are not allowed, only the local IP address is checked.

The associated objects include CA, CERTREQ, and IKEPEER. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when setting this parameter:

1. The system checks whether forcible changes to CERTMK objects affect associated objects based on the object configuration data instead of the actual object running status.

2. If an NE is configured with an SRCIPRT, SRCIPROUTE4, PPPLNK, or MPGRP object, the system will not check whether forcible changes to CERTMK objects affect associated objects.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify a device certificate file with the parameters as follows: Certificate File Name: eNodeBCert.pem, CA Switch: OFF, run the following command:
MOD CERTMK: APPCERT="eNodeBCert.pem", CASW=OFF;
