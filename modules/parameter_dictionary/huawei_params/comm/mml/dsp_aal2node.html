Display AAL2 Node Status (DSP AAL2NODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of an AAL2 node.

Note

None.

Parameters

ID Name Description
NT Node Type

Meaning: Indicates the type of an AAL2 node. If this parameter is set to LOCAL, the AAL2 node is used to control the local services on the BS. If this parameter is set to HUB, the AAL2 node is used to control services of the lower-level BS cascaded to the hub BS.

GUI Value Range: LOCAL(End Node), HUB(Switching Node)

Unit: None

Actual Value Range: LOCAL, HUB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the type of controller to which an AAL2 node is connected. The controller is either a master controller or a slave controller.

GUI Value Range: MASTER(MASTER), SLAVE(SLAVE)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(MASTER)

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
FLAG Transport Channel Flag

Meaning: Indicates the transport channel of an AAL2 node, which can be master or slave.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: MASTER(Master)

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To query the status of the AAL2 node with the parameters as follows: Node Type: LOCAL, run the following command:
DSP AAL2NODE: NT=LOCAL;
The result is shown as follows:

Output Description

Field Description

Node Type

Indicates the type of an AAL2 node. If this parameter is set to LOCAL, the AAL2 node is used to control the local services on the BS. If this parameter is set to HUB, the AAL2 node is used to control services of the lower-level BS cascaded to the hub BS.

Belong Flag

Indicates the type of controller to which an AAL2 node is connected. The controller is either a master controller or a slave controller.

Transport Channel Flag

Indicates the transport channel of an AAL2 node, which can be master or slave.

AAL2 Node State

Indicates the state of an AAL2 node.

Used Status

Indicates whether an AAL2 node is in use.
