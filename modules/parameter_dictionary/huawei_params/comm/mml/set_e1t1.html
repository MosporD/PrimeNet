Set E1/T1 Port (SET E1T1)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to set an E1/T1 port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the LNCODE is set to AMI, the E1/T1 port and the service on it will be affected due to the defective coding mode. In this case, the AMI line coding mode is not recommended.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When a link is carried on an E1/T1 port or a backplane E1/T1 port, if the working mode of the E1/T1 port is modified, the modification takes effect only after the board that provides the port is reset. If the board is not reset within 10 minutes after the command is executed, ALM-26245 Configuration Data Inconsistency will be reported.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In scenarios with inter-board MLPPP group, the E1 clock (line clock) must be used as the system clock.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If an inter-board MP group is configured in non-TDD mode, the E1 line clock must be used as the system clock.

  • [Co-MPT,NodeB,eGBTS,eNodeB]It is recommended that the Frame Format parameter be set to E1_HYBRID_FRAME(E1 Hybrid Frames) only in GTMUb/GTMUc. When the Frame Format parameter is set to E1_HYBRID_FRAME(E1 Hybrid Frames), the transmit and receive frame formats of the base station should be set to E1_CRC4_MULTI_FRAME(E1 CRC4 Multiple Frames) and E1_DOUBLE_FRAME(E1 Double Frames), respectively.

  • [Co-MPT,NodeB,eGBTS,eNodeB]This operation may interrupt the services or OM channels carried on this port. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

WORKMODE Work Mode

Meaning: Indicates the working mode of the E1/T1 port. This parameter must be set to the same value as that at the peer end.

GUI Value Range: E1_UNBA(E1 Unbalance), E1_BA(E1 Balance), T1(T1)

Unit: None

Actual Value Range: E1_UNBA, E1_BA, T1

MML Default Value: None

Recommended Value: E1_UNBA(E1 Unbalance)

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]When bearer link is PPPLNK, in the E1T1 MO, if WORKMODE is set to E1_BA or E1_UNBA, TSN must be set to a value within the range of TS1 to TS31; if WORKMODE is set to T1, TSN must be set to a value within the range of TS1 to TS24, other timeslots are not used.
  • [Co-MPT, NodeB, eGBTS, eNodeB]When bearer link is MPLNK, in the E1T1 MO, if WORKMODE is set to E1_BA or E1_UNBA, TSN must be set to a value within the range of TS1 to TS31; if WORKMODE is set to T1, TSN must be set to a value within the range of TS1 to TS24, other timeslots are not used.
  • [Co-MPT, NodeB, eGBTS]If WORKMODE in the E1T1 MOs corresponding to SRCPN and DSTPN in a TSCROSS MO is set to T1, SRCTSN and DSTTSN only timeslots 1 to 24 can be configured, other timeslots are not used.
  • [Co-MPT, NodeB]When bearer link is FRAATM, in the E1T1 MO, if WORKMODE is set to E1_BA or E1_UNBA, TSN must be set to a value within the range of TS1 to TS31; if WORKMODE is set to T1, TSN must be set to a value within the range of TS1 to TS24, other timeslots are not used.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
FRAME Frame Format

Meaning: Indicates the frame format used by the E1/T1 port.

GUI Value Range: E1_DOUBLE_FRAME(E1 Double Frames), E1_CRC4_MULTI_FRAME(E1 CRC4 Multiple Frames), E1_HYBRID_FRAME(E1 Hybrid Frames), T1_SUPER_FRAME(T1 Super Frames), T1_EXTENDED_SUPER_FRAME(T1 Extended Super Frames)

Unit: None

Actual Value Range: E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME, E1_HYBRID_FRAME, T1_SUPER_FRAME, T1_EXTENDED_SUPER_FRAME

MML Default Value: None

Recommended Value: E1_CRC4_MULTI_FRAME(E1 CRC4 Multiple Frames)

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an E1T1 MO, if PS is set to ALLPORT and WORKMODE is set to E1_UNBA or E1_BA, FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME.
  • In an E1T1 MO, if PS and WORKMODE are set to ALLPORT and T1, respectively, FRAME can be set to T1_SUPER_FRAME or T1_EXTENDED_SUPER_FRAME.
  • If WORKMODE in an all-port E1T1 MO is set to E1_UNBA or E1_BA, FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME in each single-port E1T1 MO. If WORKMODE in an all-port E1T1 MO is set to T1, FRAME can be set to T1_SUPER_FRAME or T1_EXTENDED_SUPER_FRAME in each single-port E1T1 MO. If no all-port E1T1 MO is configured, the default value of WORKMODE in each single-port E1T1 MO is E1_UNBA, and FRAME can be set to E1_DOUBLE_FRAME, E1_CRC4_MULTI_FRAME or E1_HYBRID_FRAME.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Meaning: Indicates the line coding mode of an E1/T1 port.

Unit: None

Actual Value Range: HDB3, AMI, B8ZS

Recommended Value: If an E1/T1 port is carried over IP, the AMI line coding mode is not recommended.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an E1T1 MO, if PS is set to ALLPORT and WORKMODE is set to E1_UNBA or E1_BA, LNCODE can be set to AMI or HDB3.
  • In an E1T1 MO, if PS and WORKMODE are set to ALLPORT and T1, respectively, LNCODE can be set to AMI or B8ZS.
  • If WORKMODE in an all-port E1T1 MO is set to E1_UNBA or E1_BA, LNCODE can be set to AMI or HDB3 in each single-port E1T1 MO. If WORKMODE in an all-port E1T1 MO is set to T1, LNCODE can be set to AMI or B8ZS in each single-port E1T1 MO. If no all-port E1T1 MO is configured, the default value of WORKMODE in each single-port E1T1 MO is E1_UNBA, and LNCODE can be set to AMI or HDB3.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

CLKM Clock Mode

Meaning: Indicates the clock mode of the E1/T1 port.

1. If the BS extracts the line clock from the E1/T1 port, the clock mode of the E1/T1 port must be set to SLAVE. If the BS provides the line clock for the lower-level equipment through the E1/T1 port, the clock mode of the E1/T1 port must be set to MASTER. Otherwise, the line clock may fail to work properly.

2. When the E1/T1 port provides an 8K clock reference for the transmission interface board, the clock mode of the E1/T1 port must be set to SLAVE.

3. The clock modes of E1/T1 ports used by an inter-board MLPPP group cannot be all set to SLAVE.

GUI Value Range: MASTER(Master Mode), SLAVE(Slave Mode)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: SLAVE(Slave Mode)

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

Example 1: To set the properties of the E1/T1 port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Selection: ALLPORT, Work Mode: E1_UNBA, Frame Format: E1_DOUBLE_FRAME, Line Code: HDB3, run the following command: 
SET E1T1: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PS=ALLPORT, WORKMODE=E1_UNBA, FRAME=E1_DOUBLE_FRAME, LNCODE=HDB3;
Example 2: To set the properties of an E1/T1 port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Selection: SINGLEPORT, Port No.: 0, Frame Format: E1_DOUBLE_FRAME, Line Code: HDB3, run the following command: 
SET E1T1: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PS=SINGLEPORT, PN=0, FRAME=E1_DOUBLE_FRAME, LNCODE=HDB3;
