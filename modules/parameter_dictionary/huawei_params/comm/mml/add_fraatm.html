Add FRAATM Link (ADD FRAATM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a fractional ATM link.

Note

  • [Co-MPT,NodeB]The total number of IMA groups, UNI links, and fractional ATM links on a board must be smaller than or equal to the number of E1/T1 ports supported on the board.

  • [Co-MPT,NodeB]The total number of IMA links, UNI links, and fractional ATM links on a board must be smaller than or equal to the number of E1/T1 ports supported on the board.

  • [Co-MPT,NodeB]When LNCODE (line coding mode) of the E1/T1 port that carries the fractional ATM link to be added is set to AMI, the fractional ATM link must be scrambled.

  • [Co-MPT,NodeB]The timeslots at the E1/T1 ports used by IMA links, UNI links, FRAATM links, and timeslot cross connections must be mutually different.

  • [Co-MPT,NodeB]Fractional ATM links on different types of subboards in the same slot must have different port numbers.

  • [Co-MPT,NodeB]The E1/T1 port that carries an FRAATM link must not be associated with any port security, or SWITCH of the associated port security must be set to ENABLE.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT is the main control board, a maximum of 64 FRAATM links can be configured. If the UMDU is the main control board, a maximum of 4 FRAATM links can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 4 FRAATM links can be configured on a WMPT/UMPTa/UMPTb/UMDU. A maximum of 8 FRAATM links can be configured on a UTRP (subboard type: UAEC).

  • [Co-MPT,NodeB]When local loopback is set for the underlying bearer link, the IMA group, IMA link, UNI link, and FRAATM link succeed in the self-negotiation based on related protocols.

Example

To add a fractional ATM link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 3, E1/T1 Port No.: 0, Scramble Mode: ENABLE, E1/T1 Timeslot No.: TS1-1, run the following command: 
ADD FRAATM: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, FRAATM=3, PN=0, SCRAM=ENABLE, TSN=TS1-1;
