Remove Subrack (RMV SUBRACK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a subrack.

Note

  • Before removing a subrack, ensure that the electromagnetic equipment managed by the subrack is removed. The electromagnetic equipment can be an EMU, PMU, or TCU.

  • Before removing a subrack, remove boards in the subrack.

  • Before removing a subrack, remove control links configured for the subrack.

  • If a leaf BBU is configured, the leaf BBU must be removed before removing the root BBU.

  • If a control link depending on a root BBU is configured, you must remove the control link by running the RMV CTRLLNK command before removing the root BBU.

  • A PMU, TCU, FMU, EMU, or CCU subrack can be removed when no electromagnetic equipment managed by this subrack.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the subrack.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to BBU5900 or BBU5900A, CN must be smaller than or equal to 7.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a SUBRACK MO, CN must be set to a value less than or equal to 7 if TYPE is set to BBU3900, BBU3900-1U, BBU3910, BLADEBBU, BBU5900A, BBU5900, DCU3911, or DCU5900.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a SUBRACK MO, the value of CN must be set to a value less than or equal to 7 if TYPE is set to BBU3910C.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack.

GUI Value Range: 0~1,4~5,7~8,11~12,14~15,17~18,40~59

Unit: None

Actual Value Range: 0~1,4~5,7~8,11~12,14~15,17~18,40~59

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to TCU, SRN must be set to 8 or 14.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to FMU, SRN must be set to 11 or 12.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to EMU, the value of SRN must range from 40 to 59.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to RFU, SRN must be set to 4 or 5.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to PMU, SRN must be set to 7,17 or 18.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to BBU5900, SRN must be set to 0 or 1.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a SUBRACK MO, SRN must be set to 0 or 1 if TYPE is set to BBU3900, BBU3900-1U, BBU3910, BLADEBBU, BBU5900, DCU3911, or DCU5900.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In a SUBRACK MO, the value of SRN must be set to 0 or 1 if TYPE is set to BBU3910C.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRN in a SUBRACK MO must be set to 0 when TYPE in the SUBRACK MO is set to BBU3900, BBU3910, BBU5900, DCU3911, or DCU5900, and TYPE in the associated CABINET MO is set to OMB or BTS3900D.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the SUBRACK MO is set to BBU5900A and TYPE in the CABINET MO is set to OBU5900A, SRN in the SUBRACK MO must be set to 0.
  • [NodeB]SRN in the SUBRACK MO must be set to 0 when TYPE is set to BBU3900-1U, and TYPE in the CABINET MO is set to one of the following values: OMB, BTS3900D.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]TYPE must be set to BBU3900, BBU3910, or BBU5900 when TYPE in the CABINET MO is set to IBC10 and SRN in the SUBRACK MO is set to 0 or 1.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a SUBRACK MO, when TYPE is set to CCU, SRN must be set to 15.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove a subrack with the parameters as follows: Cabinet No: 0, Subrack No: 0, run the following command:
RMV SUBRACK: CN=0, SRN=0;
