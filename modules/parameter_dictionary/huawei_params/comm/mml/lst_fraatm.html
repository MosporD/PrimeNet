List FRAATM Link Configuration (LST FRAATM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the fractional ATM link configuration.

Note

None.

Parameters

None.

Example

To list the fractional ATM link configuration, run the following command:
LST FRAATM:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the FRAATM link is located.

Subrack No.

Indicates the subrack number of the board where the FRAATM link is located.

Slot No.

Indicates the slot number of the board where the FRAATM link is located.

Subboard Type

Indicates the type of sub-board on the board where the FRAATM link is located.

Link No.

Indicates the number of the fractional ATM link.

E1/T1 Port No.

Indicates the number of the E1/T1 port that carries the FRAATM link.

Scramble Mode

Indicates whether scrambling is applied to the fractional ATM link.

E1/T1 Timeslot No.

Indicates the number of the ET/T1 timeslot that carries the fractional ATM link.
