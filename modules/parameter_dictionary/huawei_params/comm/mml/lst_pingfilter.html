List Ping Filter IP/Segment Configuration (LST PINGFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list configurations of the ping filter on a BS.

Note

None.

Parameters

None.

Example

To list the information of the PINGFILTER MOs configured in the database, run the following command:
LST PINGFILTER:; 
The result is shown as follows:                        
+++    0        2009-02-19 18:39:55      
O&M    #29                                
%%LST PINGFILTER:;%%                          
RETCODE = 0  Operation succeeded.

List Ping Filter IP/Segment Configuration
-----------------------------------------                         
 VRF Index  =  0
IP Address  =  10.10.11.0          
      Mask  =  255.255.255.0                 
(Number of results = 1)                       
                                              
                                              
---    END

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Address

Indicates the IP address in a ping filter entry. This address must be a valid IP address of class A, B, or C. It can also be a network segment address.

Mask

Indicates the subnet mask corresponding to the IP address in a ping filter entry. The subnet mask cannot be 0.0.0.0.
