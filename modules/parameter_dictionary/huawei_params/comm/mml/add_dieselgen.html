Add Diesel Generator (ADD DIESELGEN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a diesel generator. The diesel generator is compatible only with the SC48200 power monitoring unit (PMU).

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the PMU managing the diesel generator is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the PMU managing the diesel generator is located.

GUI Value Range: 7

Unit: None

Actual Value Range: 7

MML Default Value: 7

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the PMU managing the diesel generator is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
ICF Intelligent Control Flag

Meaning: Indicates whether intelligent control of the diesel generator is enabled. When intelligent control is enabled, the PMU automatically controls the diesel generator according to the preset parameters, thus reducing the operation cost of the diesel generator.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
POWER Rated Power

Meaning: Indicates the maximum rated output power of the diesel generator. It should be configured according to the rated output power printed on the nameplate of the diesel generator.

GUI Value Range: 1~1000

Unit: 0.1kVA

Actual Value Range: 0.1~100.0, step: 0.1

MML Default Value: 125

Recommended Value: 125

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To add a diesel generator whose PMU is located in cabinet 0, run the following command:
ADD DIESELGEN: CN=0;
