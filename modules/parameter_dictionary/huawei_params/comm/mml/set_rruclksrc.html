Set RRU Clock Source (SET RRUCLKSRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to specify the number of the RRU port through which clock signals are obtained. The clock signals used by dual-mode RRUs can be obtained through either of the two (CPRI) ports.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the specified CPRI port is not connected to a fiber optic cable or the CPRI link carried on the specified CPRI port is faulty, this command fails to take effect.

  • If the CPRI port through which the RRU clock signals are obtained has a status change, the RRU automatically switches to another clock source.

  • This command does not apply to the CXU or AAS.

  • This command does not apply to RRU working in TDL_IR or eCPRI protocol.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the RRU MO, when RFCONNTYPE is set to INTRA_SYS_INTERCONN, the combination of CN, SRN, SN cannot be the same as the combination of RFCONNCN2, RFCONNSRN2, RFCONNSN2.
  • [Co-MPT, NodeB, eNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [eGBTS]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, AAMU, CXU.
  • [gNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Example

To set the reference clock for the RRU with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, Rru Port No.: 1, run the following command:
SET RRUCLKSRC: CN=0, SRN=60, SN=0, RPN=1;
