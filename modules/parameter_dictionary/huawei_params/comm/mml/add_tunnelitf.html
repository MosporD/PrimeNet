Add Tunnel Interface (ADD TUNNELITF)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a tunnel interface.

Note

  • [Co-MPT,eNodeB,gNodeB]The current tunnel interface supports only the IPsec IPv6 mode.

  • [Co-MPT,eNodeB,gNodeB]After adding a tunnel interface, you need to add an INTERFACE object with the port type set to tunnel interface and then bind the tunnel interface to the IPsec policy group.

  • [Co-MPT,eNodeB,gNodeB]System specifications: When the UMPTa/UMPTb/UMDU is used as the main control board, a maximum of 128 tunnel interfaces can be configured for a base station. When the UMPTe is used as the main control board, a maximum of 392 tunnel interfaces can be configured for a base station. When the UMPTg/UMPTga is used as the main control board, a maximum of 520 tunnel interfaces can be configured for a base station. When the UMPT/UMDU is used as the main control board, a maximum of 128 tunnel interfaces can be manually configured for a base station.

  • [Co-MPT,eNodeB,gNodeB]Board specifications: A maximum of 128 tunnel interfaces can be configured on a UMPTa/UMPTb/UMDU. A maximum of 392 tunnel interfaces can be configured on a UMPTe. A maximum of 520 tunnel interfaces can be configured on a UMPTg/UMPTga.

  • [Co-MPT,eNodeB,gNodeB]If the local IPv6 address and peer IPv6 address of the tunnel interface belong to different network segments, two routes must be added. The destination address of one route is the IPsec inner address and the outbound interface is the tunnel interface. The destination address of the other route is the peer address of the tunnel interface and the next hop is the gateway address. If there are too many tunnel interfaces with the local and peer IPv6 addresses belonging to different network segments, the number of IPv6 routes may exceed the system specifications. Therefore, the specifications of tunnel interfaces must match the specifications of IPv6 routes in the networking scenario.

  • [Co-MPT,eNodeB,gNodeB]To protect the inner network, you are advised to set VRFIDX of a TUNNELITF MO to be different from VRFIDX of the INTERFACE MO corresponding to the TUNNELITF MO.

Parameters

ID Name Description
PORTID Port ID

Meaning: Indicates the port ID of a tunnel interface. The value of PORTID in the TUNNELITF MOs configured by users ranges from 0 to 127. The value of PORTID in the TUNNELITF MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~127,10000~19999

Unit: None

Actual Value Range: 0~127,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In a TUNNELITF MO, if PORTID is within the range from 0 to 127, CTRLMODE must be set to MANUAL_MODE. In a TUNNELITF MO, if PORTID is within the range from 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
MODE Mode

Meaning: Indicates the mode of the tunnel interface.

GUI Value Range: IPSEC_IPV6(IPsec IPv6)

Unit: None

Actual Value Range: IPSEC_IPV6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
LOCALIP6 Local IPv6 Address

Meaning: Indicates the local IPv6 address of the tunnel interface.

GUI Value Range: Valid IP address

  • [Co-MPT, eNodeB, gNodeB]In the TUNNELITF MO, LOCALIP6 cannot be the same as REMOTEIP6.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Service Interrupted After Modification: Yes

Example

To add a tunnel interface with the parameters as follows: Port ID: 0, Mode: IPsec IPv6, Local IPv6 Address: 2001:DB8::1, Remote IPv6 Address: 2001:DB8::2, run the following command:
ADD TUNNELITF: PORTID=0, MODE=IPSEC_IPV6, LOCALIP6="2001:DB8::1", REMOTEIP6="2001:DB8::2";
