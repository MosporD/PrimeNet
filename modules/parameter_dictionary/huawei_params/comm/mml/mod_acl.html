Modify ACL (MOD ACL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an ACL.

Note

[Co-MPT,eNodeB,gNodeB]If an ACL can be queried by running the LST ACL command and the value of the "Auto Config Flag" field is "Auto Created", the ACL object is automatically created by the system and cannot be modified by users.

Parameters

ID Name Description
ACLID ACL ID

Meaning: Indicates the ID of the access control list (ACL) to which an access control rule belongs. An ACL rule with an ACL ID ranging from 3000 to 3999 indicates a high-level rule based on the layer 3 and layer 4 information configured by users. An ACL rule with an ACL ID ranging from 4000 to 4999 indicates a layer 2 rule based on the MAC layer information configured by users. An ACL rule with an ACL ID ranging from 7000 to 7999 indicates a high-level rule based on the layer 3 and layer 4 information configured by the system.

GUI Value Range: 3000~4999,7000~7999

Unit: None

Actual Value Range: 3000~4999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]The ID of an ACL that is manually configured must range from 3000 to 4999.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ACLDESC Description

Meaning: Indicates the brief description of an ACL.

GUI Value Range: 0~127 characters

Unit: None

Actual Value Range: 0~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify an ACL with the parameters as follows: ACL ID: 3000, Description: Acl Group is modified, run the following command: 
MOD ACL: ACLID=3000, ACLDESC="Acl Group is modified";
