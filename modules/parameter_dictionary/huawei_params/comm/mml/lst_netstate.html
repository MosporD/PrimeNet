List Process Ports Information (LST NETSTATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list information about the working ports on a device.

Note

  • Board specifications: The LMPT/UMPT/UMDU/WMPT/UTRPc/UCCU/UBBPe/LCOP/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 supports a maximum of 2048 TCP and UDP records, and the GTMU supports a maximum of 128 TCP records and 128 UDP records.

  • After a protocol is bound to an IP address, information about the source port and source IP address can be queried. After a connection is set up, information about the destination IP address and destination port can be queried only when TCP is used for the communication.

  • An asterisk (*) in the execution results indicates that the corresponding information fails to be queried.

Parameters

None.

Example

To list information about the working ports on a device, run the following command: 
LST NETSTATE:;
The result is shown as follows:

Output Description

Field Description

Cabinet

Indicates the cabinet number of the board where a port is located.

Subrack

Indicates the subrack number of the board where a port is located.

Slot

Indicates the slot number of the board where a port is located.

Protocol

Indicates the protocol type of a port.

Source Port

Indicates the source port.

Source IP

Indicates the source IP address of a port.

Destination Port

Indicates the destination port.

Destination IP

Indicates the destination IP address of a port.

VRF Index

Indicates the index of a VRF instance.
