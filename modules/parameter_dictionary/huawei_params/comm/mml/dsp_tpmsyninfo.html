Display TPM Synchronization Information (DSP TPMSYNINFO)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

This command is used to query the configuration information on the NE synchronized from the USU. The information includes the DEVIP, IPADDR4 and SUBNETVLAN MOs.

Note

[Co-MPT,NodeB,eGBTS,eNodeB]Currently, only when the port on the UBBPe/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 is in AUTO mode and the negotiated data rate over this port is 1*40GE, the synchronization Information query is supported.

Example

To query the TPM synchronization information entry with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 5, run the following command:
DSP TPMSYNINFO: CN=0, SRN=0, SN=5;
