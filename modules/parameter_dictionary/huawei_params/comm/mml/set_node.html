Set Node Configuration (SET NODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set Working Mode, LTE Mode and Product Type of an NE.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The working mode of an NE can be modified only when the product type of this NE is DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900 LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900 LampSite.

  • Ensure that only one application is configured before setting the Working Mode parameter to NON-CONCURRENT.

  • After the Working Mode or Working Mode Extension of a base station is modified, the base station will be automatically reset to make the modification take effect.

  • If LTE Mode and Product Type of an NE are modified, the new settings take effect only after this NE is reset. If the NE is not reset within 10 minutes after these parameters are modified, ALM-26245 Configuration Data Inconsistency is reported.

  • After an NE is successfully changed to a non-multimode concurrency NE, a maximum of one application can exist.

  • The value of Product Type can only be changed from a base station to another base station with the same RAT. In addition, the value of Product Type cannot be changed from a base station using a 1 U-high BBU to a base station using a 2 U-high BBU.

  • You can modify the value of Product Type only when the base station system is stable. During base station deployment by PnP, you cannot modify the value of Product Type.

  • The value of Product Type can only be changed within the 3900 series base station models or within the 5900 series base station models.

  • When Working Mode Extension is set to COMM or COMM2, different main control boards support different apps. For details, see the note in the ADD APP command description.

This parameter is valid when either of the following conditions is met: (1) Product Type is set to DBS3900, BTS3900, BTS3900A, BTS3900L, BTS3900AL, DBS3900_LampSite, DBS5900, BTS5900, BTS5900A, BTS5900L, BTS5900AL, or DBS5900_LampSite, Working Mode is set to NON-CONCURRENT, and Application Type is set to eNodeB. WMEXTENSION Working Mode Extension

Meaning: Indicates the extended deployment type of an NE. COMM and COMM2 are used when two SingleRAN base stations form a separate-MPT base station. For example, if a GU co-MPT base station and an LNR co-MPT base station form a separate-MPT base station, set the NE deployment type to COMM and COMM2 respectively. For details about the mapping between extended deployment types and apps, see the note in the ADD APP command help.

Example

To set Working Mode of an NE to NON-CONCURRENT, LTE Mode to LTE_TDD and Product Type to BTS3900, run the following command:
SET NODE: WM=NON-CONCURRENT, LTEMODE=LTE_TDD, PRODUCTTYPE=BTS3900;
