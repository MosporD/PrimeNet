Set OM Channel Automatic Establishment Switch (SET DHCPSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set parameters for automatic establishment of a remote maintenance channel.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the remote maintenance channel between a BS and the element management system has been disconnected for over 30 minutes, the BS will not trigger the DHCP Detect function of the Automatic OMCH Establishment feature even though both the remote maintenance channel and services are interrupted. However, if Delay Establishment Switch is set to ENABLE(Enable) in this case, the BS will trigger the DHCP Detect function on Ethernet ports when the remote maintenance channel and services have been interrupted for two hours.

  • The Delay Establishment Switch parameter applies only to scenarios where a new link needs to be reestablished when the bearer network is faulty. It has the following risks when used in other scenarios and you need to be cautious about it:

    1. If a base station is disconnected from the element management system due to the bearer network faults, the base station uses the new link on the bearer network to automatically establish a remote maintenance channel. In this case, the element management system needs to redeliver the configurations of the new link to the base station for recovering services.

    2. If a base station is disconnected from the element management system due to the bearer network faults and the base station performs automatic establishment of a remote maintenance channel, services on this base station cannot immediately recover until the automatic establishment of the remote maintenance channel is complete, even though the bearer network has recovered.

    3. If a base station is disconnected from the element management system due to the bearer network faults in separate-MPT co-transmission multimode base stations or cascaded base stations, services of other modes or on other cascaded base stations will be interrupted when this base station performs automatic establishment of the remote maintenance channel.

  • [Co-MPT,NodeB,eNodeB,gNodeB]After the VLAN scanning function of the base station is enabled, When the base station is in IPv4 networking sends a large number of DHCP broadcast packets with different VLAN IDs in the VLAN scanning process. If VLANs are not separated, broadcast storms may occur.

  • [NodeB,eNodeB,gNodeB]If OMCH Auto-Establishment Switch is set to DISABLE and the remote maintenance channel is disconnected, the base station attempts to restore the channel based on the current transmission configurations. If the remote maintenance channel is disconnected due to modification of transmission configurations at the peer end and the services on the base station are normal or stable, the restoration may fail. Therefore, exercise caution when setting this parameter to DISABLE.

Parameters

ID Name Description
SWITCH OMCH Auto-Establishment Switch

Meaning: Indicates whether to enable DHCP detection during automatic establishment of the remote maintenance channel. If this parameter is set to DISABLE, DHCP listening is performed instead of DHCP detection.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VLANSCANSW Vlanscan Switch

Meaning: Indicates whether to turn on the base station VLAN scan function, the VLAN scanning function is refers, when the network element enters the detect detection, on the Ethernet port, carries on the IPv4 DHCP detection to the VLAN identity range to 0~4094.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DELAYSW Delay Establishment Switch

Meaning: Indicates whether to enable the function of reestablishing the base station's remote maintenance channel after a specified period.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the switch for the auto-establishment of the remote maintenance channel with OMCH Auto-Establishment Detect Switch set to ENABLE, Vlanscan Switch set to DISABLE and Delay Establishment Switch set to DISABLE, run the following command: 
SET DHCPSW: SWITCH=ENABLE, VLANSCANSW=DISABLE, DELAYSW=DISABLE;
