Display FRAATM Link Status (DSP FRAATM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the status of a fractional ATM link.

Note

  • [Co-MPT,NodeB]The command execution result indicates the data negotiated with the lower layer. It may be inconsistent with the configuration. The execution result of this command is the data that takes effect currently.

  • [Co-MPT,NodeB]The command execution result shows the status of the fractional ATM link only on the BS side. The normal state indicated in the execution result of this command does not necessarily mean the normal state of the link at the peer end.

Example

To query the status of a fractional ATM link with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Link No.: 3, Clear Statistic: YES, run the following command: 
DSP FRAATM: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, FRAATM=3, CLEAR=YES;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the FRAATM link is located.

Subrack No.

Indicates the subrack number of the board where the FRAATM link is located.

Slot No.

Indicates the slot number of the board where the FRAATM link is located.

Subboard Type

Indicates the type of sub-board on the board where the FRAATM link is located.

Link No.

Indicates the number of the fractional ATM link.

FRAATM State

Indicates the status of the fractional ATM link.

Number of Tx Cells(cell)

Indicates the number of cells transmitted by the fractional ATM link.

Number of Rx Cells(cell)

Indicates the number of cells received by the fractional ATM link.

Number of Rx Dropped Cells(cell)

Indicates the number of discarded user cells of the fractional ATM link due to the congestion at the ATM layer.

Number of HCS Failure Cells(cell)

Indicates the number of HCS failure cells received by the fractional ATM link.
