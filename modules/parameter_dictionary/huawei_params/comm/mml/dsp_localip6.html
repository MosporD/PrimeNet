Display Local OM IPv6 Address (DSP LOCALIP6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the IPv6 address of the local maintenance channel that takes effect.

Note

None.

Parameters

None.

Example

To list the IPv6 address of the local maintenance channel, run the following command:
DSP LOCALIP6:;
The result is shown as follows:
+++    0        2018-08-08 16:13:16
O&M    #4677
%%DSP LOCALIP6:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

IPv6 Address

Indicates the IPv6 address of an OM channel. This IPv6 address must be a link-local address.

Prefix Length

Indicates the prefix length of the IPv6 address of a local maintenance channel.

Address Status

Indicates the status of the IPv6 address of the local maintenance channel.

Valid Lifetime(s)

Indicates the time period during which the IPv6 address of the local maintenance channel is in valid state.

Preferred Lifetime(s)

Indicates the time period during which the IPv6 address of the local maintenance channel is in preferred state. The valid state is categorized into the preferred state and the deprecated state. In preferred state, the address can be freely used. In deprecated state, the connections previously established through this address are still usable, whereas any connection newly established through this address is not usable.
