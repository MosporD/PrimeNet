List Current Software Version (LST VER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the information about the software version and the application version running on the NE.

Note

The output of this command does not contain information about the version of an application that is not configured but whose software has been activated. If no application is configured, the output of this command does not contain information about the version. Users can run the LST SOFTWARE command to query the software version of an application whose version has been activated.

Parameters

None.

Example

To list the current version of the software, run the following command:
LST VER:;
The result is shown as follows:

Output Description

Field Description

Current Software Version

Indicates the current software version.

Current Software Status

Indicates the current software status. The software status can be "Normal" or "Fractional". "Normal" indicates that the active software is running on all boards on the NE. "Fractional" indicates that the software running on some boards does not match the active version of the main control board. Run the DSP BRDVER command to check for the boards that have versions inconsistent with the main control board.

Current Hot Patch Version

Indicates the version of the current hot patch. The field is not displayed if there is no effective hot patch in the main area on the NE.

Application Type

Indicates the type of application software in the NE.

Application Version

Indicates the application version.

Application Hot Patch Version

Indicates the version of the application hot patch.

Software Type

Indicates the software type.

Software Version

Indicates the software version.

Software Hot Patch Version

Indicates the version of the software hot patch.

Running Mode

Indicates the running mode of the application.
