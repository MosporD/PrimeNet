Set CPRI Threshold (SET CPRITHRESHOLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the bit error rate (BER) threshold for the CPRI BER Monitoring function.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]If eCPRI protocols are used, the CPRI bit error rate monitoring function is not supported.

Parameters

ID Name Description
SETTYPE Set Type

Meaning: Indicates the set type.

GUI Value Range: USERDEFINE(USERDEFINE), DEFAULT(DEFAULT)

Unit: None

Actual Value Range: USERDEFINE, DEFAULT

MML Default Value: DEFAULT(DEFAULT)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
THRESHOLD Threshold

Meaning: Indicates the BER threshold.

GUI Value Range: 0~1000000000

Unit: 1e-9

Actual Value Range: 0~1, step: 0.000000001

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the online CPRI BER threshold with Set Type set to USERDEFINE and Threshold to 2, run the following command:
SET CPRITHRESHOLD: SETTYPE=USERDEFINE, THRESHOLD=2;
