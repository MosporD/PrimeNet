Add CFM RMEP (ADD CFMRMEP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a remote maintenance association end point (RMEP).

Note

  • Before running this command, ensure that the associated CFM MA and CFM MEP have been configured.

  • Before performing continuity check between the BS and an RMEP, ensure that the RMEP has been configured on the BS.

  • If multiple RMEPs are configured under a CFM MA, you are advised to set the MAC addresses of these RMEPs to different values. Otherwise, the CFM loopback test fails.

  • In an MA, the ID of the MEP and the ID of the RMEP must be different.

  • Board specifications: The following boards support the CFMRMEP whitelist: WMPT/UMPT/UMDU/LMPT/GTMUb/GTMUc/UTRPc/UCCU/UTRP (the subboard type is UEOC/UQEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 16 RMEPs can be configured on a UMPT/UMDU/LMPT/UTRPc/UCCU/UTRP (the subboard type is UEOC/UQEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 8 RMEPs can be configured on a WMPT/GTMUb/GTMUc. If the WMPT is the main control board, a maximum of 8 RMEPs can be configured on one board.

  • System specifications: If the WMPT/GTMUb/GTMUc is the main control board, a maximum of 16 RMEPs can be configured. If the LMPT/UMPT is the main control board, a maximum of 64 RMEPs can be configured. If the UMDU is the main control board, a maximum of 16 RMEPs can be configured.

  • [eNodeB,gNodeB]The MD name and MA name of the RMEP must be the same as those of the associated MEP in the peer system. In addition, the RMEP ID must be the same as the MEP ID of the associated MEP in the peer system. Otherwise, the RMEP does not function.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the RMEP belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM RMEP.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMRMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MANAME MA Name

Meaning: Indicates the name of the MA to which the RMEP belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MANAME value of a CFM RMEP.

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MANAME in a CFMRMEP MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMRMEP MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
RMEPID RMEP ID

Meaning: Indicates the RMEP ID.

GUI Value Range: 1~8191

Unit: None

Actual Value Range: 1~8191

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MAC MAC Address

Meaning: Indicates the MAC address of the RMEP. It must be a valid unicast address in the format of XXXX-XXXX-XXXX. The MAC address of the RMEP can be obtained from the MAC address field carried in the CCM message. If the MAC address configured by the user is different from that carried in the CCM message, the MAC address carried in the MAC message prevails.

GUI Value Range: 14 characters

Unit: None

Actual Value Range: 14 characters

MML Default Value: 0000-0000-0000

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MAC in the CFMRMEP MO is expressed in the format of XXXX-XXXX-XXXX. It cannot be set to the broadcast MAC address (FFFF-FFFF-FFFF). It also cannot be set to a multicast MAC address, which the first left byte in the Destination Address field is an odd number.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a CFM RMEP with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, RMEP ID: 2000, MAC Address: 0023-8956-7895, run the following command: 
ADD CFMRMEP: MDNAME="CHINA", MANAME="SHANGHAI", RMEPID=2000, MAC="0023-8956-7895";
