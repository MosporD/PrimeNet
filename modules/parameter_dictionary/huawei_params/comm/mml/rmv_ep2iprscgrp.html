Delete Mapping from End Point to IP Transmission Resource Group (RMV EP2IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove mapping from End Point to IP Transmission Resource Group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed, the internal user plane path automatically set up between the base station and the corresponding peer end will be added to the default IP transmission resource group.

  • Running this command may interrupt ongoing services carried on the base station.

Parameters

ID Name Description
MAPID Mapping ID

Meaning: Indicates the ID of a mapping between end points and IP transmission resource groups.

GUI Value Range: 0~455

Unit: None

Actual Value Range: 0~455

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove mapping from End Point to IP Transmission Resource with the parameters as follows: Mapping ID: 0, run the following command:
RMV EP2IPRSCGRP: MAPID=0;
