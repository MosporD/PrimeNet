Set FTP Client Parameter (SET FTPSCLT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the configurations of the FTP client.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The configurations using this command take effect in the next FTP operation.

  • If the certificate fails to be authenticated, session-based FTP connections will frequently occur in the base station and certificate alarms will not be reported.

  • Before referencing a TLS configuration policy, ensure that the TLS configuration policy exists.

Parameters

ID Name Description
ENCRYMODE Transport Encrypted Mode

Meaning: Indicates the transmission encryption mode of the FTP client. If this parameter is set to Auto, the FTP client first attempts to transmit data in ciphertext. If the attempt fails, the FTP client automatically switches the encryption mode to retransmit data in plaintext. Therefore, setting this parameter to Auto may pose security risks. However, if there are faults in transmission equipment, the FTP client does not attempt to retransmit data in plaintext even if the FTP server supports encrypted transmission. In this case, the FTP connection setup fails.

GUI Value Range: Auto(Auto), Plaintext(Plaintext), Encrypted(SSL Encrypted)

Unit: None

Actual Value Range: Auto, Plaintext, Encrypted

MML Default Value: None

Recommended Value: Encrypted(SSL)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SPTSTATEFWL Support State Firewall

Meaning: Indicates whether FTP connections in encrypted mode can be established when there is a state firewall. In encrypted mode, if this parameter is set to Yes, the FTP client delivers a command to switch the transmission mode of the control connection channel to plaintext. In this way, the state firewall can identify and dynamically open the port required for FTP transmission; if this parameter is set to No, the FTP connection may fail to be set up due to port restrictions imposed by the state firewall. If security requirements are met, it is recommended that this parameter be set to Yes.

GUI Value Range: No(No), Yes(Yes)

Unit: None

Actual Value Range: No, Yes

MML Default Value: None

Recommended Value: Yes(Yes)

Parameter Relationship:

-Others:

  • This parameter is invalid when ENCRYMODE is set to Plaintext.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SSLCERTAUTH Support SSL Certificate Authentication

Meaning: Indicates whether the certificate authentication mode is supported when data is transmitted in encrypted mode. This parameter takes effect only for TLS1.2 and earlier versions.

GUI Value Range: No(No), Yes(Yes)

Unit: None

Actual Value Range: No, Yes

MML Default Value: None

Recommended Value: Yes(Yes)

Parameter Relationship:

-Others:

  • This parameter is invalid when ENCRYMODE is set to Plaintext.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MINDHLEN Minimum DH length of FTPS

Meaning: Indicates the minimum Diffie-Hellman group length on the NE side during an FTPS negotiation. When the key exchange algorithm DH is used in FTPS negotiation algorithms, if the length of the DH key sent by the FTP server is less than the value of this parameter, the FTPS negotiation fails. A longer DH key provides higher security. When this parameter is set to DH_0, DH keys of any length can be used for SSL negotiations between the FTP client and FTP servers. This parameter takes effect only for TLS1.2 and earlier versions.

Disuse statement: In later versions, the values DH_0, DH_512, and DH_1024 will be removed from the value range of this parameter. In the current version, the configuration of these values can still be synchronized and delivered, and these values can take effect. Therefore, you are advised not to use the values DH_0, DH_512, and DH_1024.

GUI Value Range: DH_0(Auto Diffie-Hellman), DH_512(512-bit Diffie-Hellman Group), DH_1024(1024-bit Diffie-Hellman Group), DH_2048(2048-bit Diffie-Hellman Group), DH_3072(3072-bit Diffie-Hellman Group), DH_4096(4096-bit Diffie-Hellman Group)

Unit: None

Actual Value Range: DH_0, DH_512, DH_1024, DH_2048, DH_3072, DH_4096

MML Default Value: None

Recommended Value: DH_2048(2048-bit Diffie-Hellman Group)

Parameter Relationship:

-Others:

  • This parameter is invalid when ENCRYMODE is set to Plaintext.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
POLICYID Policy ID

Meaning: Indicates the ID of a TLS configuration policy.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • This parameter is invalid when ENCRYMODE is set to Plaintext.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
TLSSECCSSW TLS Secure Cipher Suite Switch

Meaning: Indicates the TLS security algorithm switch. When this switch is turned off, weak security algorithm suites other than authenticated encryption with associated data (AEAD) or perfect forward secrecy (PFS) are supported, which poses security risks. When this switch is turned on, the TLS does not support weak security algorithm suites other than AEAD and PFS. Instead, the TLS negotiates only security algorithm suites.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(ON)

Parameter Relationship:

-Others:

  • This parameter is invalid when ENCRYMODE is set to Plaintext.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

Example

To set the parameters of the FTP client as follows: Transport Encrypted Mode: Auto, Support State Firewall: Yes, Support SSL Certificate Authentication: Yes, Minimum DH length of FTPS: DH_2048, Policy ID: 0, TLS Secure Cipher Suite Switch: ON, run the following command:
SET FTPSCLT: ENCRYMODE=Auto, SPTSTATEFWL=Yes, SSLCERTAUTH=Yes, MINDHLEN=DH_2048, POLICYID=0, TLSSECCSSW=ON;
