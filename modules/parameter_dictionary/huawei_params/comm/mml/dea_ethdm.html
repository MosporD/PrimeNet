Deactivating Delay Measurement (DEA ETHDM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to deactivate the measurement of bidirectional delay and jitter on the Ethernet.

Note

None.

Parameters

ID Name Description
SESSIONID Session ID

Meaning: Indicates the number of a performance detection session.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To deactivate delay measurement with the parameters as follows: Session ID: 0, run the following command:
DEA ETHDM: SESSIONID=0;
