Display DFU Management Link Client Status (DSP DFUMLCLIENT)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a DFU management link client.

Note

None.

Parameters

ID Name Description
CLIENTID Client ID

Meaning: Indicates the ID of a DFU management link client.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To query the DFU management link status, run the following command:
DSP DFUMLCLIENT:;
The result is shown as follows:
+++    0        2018-04-03 21:00:29
O&M    #974
%%DSP DFUMLCLIENT:;%%
RETCODE = 0  Operation succeeded.

Display DFU Management Link Client Status
-----------------------------------------
          Client ID  =  1
Server IPv4 Address  =  255.255.255.255
(Number of results = 1)


---    END

Output Description

Field Description

Client ID

Indicates the ID of a DFU management link client.

Server IPv4 Address

Indicates the IPv4 address of a DFU management link server.
