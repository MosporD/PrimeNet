Modify RVD Device Data (MOD RVDDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration in the remote vendor-defined antenna line device (RVD) data.

Note

  • Whether the values of the parameters in this command can be modified depends on the device model.

  • The bands in the device data of an RVD must differ from each other.

  • If an RVD is being calibrated or its vertical beamwidth is being adjusted, the execution of this command takes 2 to 4 minutes. Therefore, you are advised to run this command when no operation is performed on the RVD.

Example

To modify the RVD device data with the parameters as follows: Device No.: 0, Subunit No.: 1, Band1: Band1, Beamwidth1: 60, Gain1: 100, Band2: Band2, Beamwidth2: 10, Gain2: 50, Band3: Band3, Beamwidth3: 10, Gain3: 10, Band4: Band4, Beamwidth4: 20, Gain4: 30, run the following command:
MOD RVDDEVICEDATA: DEVICENO=0, SUBUNITNO=1, BAND1=Band1, BEAMWIDTH1=60, GAIN1=100, BAND2=Band2, BEAMWIDTH2=10, GAIN2=50, BAND3=Band3, BEAMWIDTH3=10, GAIN3=10, BAND4=Band4, BEAMWIDTH4=20, GAIN4=30;
