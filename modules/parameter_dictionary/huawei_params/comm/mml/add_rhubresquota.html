Add RHUB Resource Quota (ADD RHUBRESQUOTA)

Network Element: BTS3900, BTS5900

Function

Use this command to add an RHUB resource quota. Each client NE can correspond to multiple quotas and each quota corresponds to different RHUBs.

Note

None.

Example

Example 1: To add RHUB Resource Quota with the parameters as follows: RHUB Resource Quota ID: 0, RCS Client No.: 0, RF Combination Capacity: 2, Inter-RHUB RF Combination Capacity: 2, RHUB Scope: "ALL", run the following command: 
ADD RHUBRESQUOTA: RHUBRESQUOTAID=0, RCSCLIENTNO=0, RFCOMBCAPC=2, INTERRHUBRFCOMBCAPC=2, SCOPE=ALL;

Example 2: To add RHUB Resource Quota with the parameters as follows: RHUB Resource Quota ID: 0, RCS Client No.: 0, RF Combination Capacity: 2, Inter-RHUB RF Combination Capacity: 2, RHUB Scope: "SPECIFIC_RHUB", Number of RHUBs: 1, Cabinet No. of RHUB 1: 0, Subrack No. of RHUB 1: 60, Slot No. of RHUB 1: 0, run the following command:
ADD RHUBRESQUOTA: RHUBRESQUOTAID=0, RCSCLIENTNO=0, RFCOMBCAPC=2, INTERRHUBRFCOMBCAPC=2, SCOPE=SPECIFIC_RHUB, RHUBNUM=1, RHUB1CN=0, RHUB1SRN=60, RHUB1SN=0;
