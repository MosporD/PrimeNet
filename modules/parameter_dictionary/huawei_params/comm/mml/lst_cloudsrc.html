List the Setting of Cloud BB Clock Reference Source (LST CLOUDSRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of Cloud BB Clock Reference Source Flag.

Note

None.

Parameters

None.

Example

To list the configuration information of Cloud BB Clock Reference Source Flag, run the following command:
LST CLOUDSRC:;
The result is shown as follows:
+++    0        2013-05-27 12:47:42
O&M    #3503
%%LST CLOUDSRC:;%%
RETCODE = 0  Operation succeeded.

List the Setting of Cloud BB Clock Reference Source
---------------------------------------------------
Cloud BB Clock Reference Source Flag  =  ENABLE
(Number of results = 1)


---    END

Output Description

Field Description

Cloud BB Clock Reference Source Flag

Indicates whether the local BBU serves as the clock reference source in the Cloud BB.
