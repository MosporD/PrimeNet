Add Timeslot Cross (ADD TSCROSS)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add a timeslot cross connection between two E1/T1 ports.

In a dual-mode BS, after an E1/T1 port on the backplane is configured on a board, a timeslot cross connection from the panel of the board to the backplane must be created so that the source board can use the E1/T1 port shared by the destination board.

In a dual-mode co-site base station, a timeslot cross connection from the panel of the source board to that of the destination board must be created so that transparent transmission of E1/T1 signals is available or E1/T1 ports are shared.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]Only the following types of timeslot cross connections can be configured:

    (1) Intra- or inter-board panel-to-panel timeslot cross connection;

    (2) Intra-board panel-to-backplane timeslot cross connection;

    (3) Intra-board backplane-to-panel timeslot cross connection.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The number of source timeslots must be the same as that of destination timeslots in a timeslot cross connection.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In an intra-board panel-to-backplane timeslot cross connection, both the source timeslots and destination timeslots must be available on the ports.

  • [Co-MPT,NodeB,eGBTS,eNodeB]One timeslot cross connection can carry only one upper-layer link.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The source and destination E1/T1 ports of a timeslot cross connection must be mutually different.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Ensure that the clocks used on two E1/T1 ports of one timeslot cross connections have the same frequency.

  • [Co-MPT,NodeB,eGBTS,eNodeB]One board has 8 internal TOP resources. One TOP resource can be used by only one E1/T1 port on the backplane, inter-board timeslot cross connection, or inter-board MLPPP group. During configuration of an inter-board timeslot cross connection (see the LST TSCROSS command), the idle internal TOP resources with the same number are occupied on the boards in the source and destination slots. During configuration of an E1/T1 port on the backplane (see the LST BACKE1T1 command), the internal TOP resources that have the same number as the E1/T1 port number are occupied on the board. During configuration of an inter-board MP group (see the LST MPLNK command), the idle internal TOP resources with the same number are occupied on the boards in the source and destination slots.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the WMPT/UMPT/GTMUb/GTMUc is the main control board, a maximum of 16 timeslot cross connections can be configured. If the UMDU is the main control board, a maximum of 8 timeslot cross connections can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum of 8 timeslot cross connections can be configured on a WMPT/UMPTa/UMPTb/UMDU/GTMUb/GTMUc. A maximum of 16 timeslot cross connections can be configured on a UTRP (subboard type: UAEC/UIEC).

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS]In the TSCROSS MO, SRCSBT and DSTSBT cannot be both set to BACK_BOARD.
  • [Co-MPT, NodeB, eGBTS]Inter-board timeslot cross-connection on the backplane is not supported. That is, in the TSCROSS MO, if SRCSN is different from DSTSN, SRCSBT and DSTSBT cannot be set to BACK_BOARD.
  • [Co-MPT, NodeB, eGBTS]For the TSCROSS MO configured on the panel of one board, if neither SRCSBT nor DSTSBT is set to BACK_BOARD, they must have the same value.

-Others:

  • [Co-MPT, NodeB]In the TSCROSS MO, if SRCSN is within the range from 0 to 5, this parameter can be set to E1_COVERBOARD or BACK_BOARD.
  • In the TSCROSS MO, if SRCSN is set to 6 or 7, this parameter can be set to BASE_BOARD or BACK_BOARD.

Example

To add a timeslot cross-connection from one panel to another panel with the parameters as follows: TS Cross No.: 1, Source Slot No.: 7, Source Subboard Type: BASE_BOARD, Source Port No.: 3, Source Time Slot No.: TS24-1&TS25-1, Destination Slot No.: 7, Destination Subboard Type: BASE_BOARD, Destination Port No.: 2, Destination Time Slot No.: TS5-1&TS7-1, Description: For GSM, run the following command:
ADD TSCROSS: NO=1, SRCSN=7, SRCSBT=BASE_BOARD, SRCPN=3, SRCTSN=TS24-1&TS25-1, DSTSN=7, DSTSBT=BASE_BOARD, DSTPN=2, DSTTSN=TS5-1&TS7-1, DESCRI="For GSM";
