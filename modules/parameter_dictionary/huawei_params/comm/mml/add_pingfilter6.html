Add IPv6 Ping Filter IPv6/Prefix Length (ADD PINGFILTER6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IPv6 ping filter. After a ping filter is added, operators can ping only the host IP address or IP addresses of network segments that meet the IPv6 ping filtering conditions on the BS if the ping filtering mode is set to whitelist. If the ping filtering mode is set to blacklist, operators cannot ping the host IP address or IP addresses of network segments that meet the IPv6 ping filtering conditions on the BS.

Note

  • [Co-MPT,eNodeB,gNodeB]The IPv6 addresses in different IPv6 ping filters must be on different network segments.

  • [Co-MPT,eNodeB,gNodeB]In the same routing domain, when no IPv6 ping filter is configured, the IPv6 ping filtering function is disabled by default. After an IPv6 ping filter is added, the IPv6 ping filtering function is enabled automatically.

  • [Co-MPT,eNodeB,gNodeB]The setting of an IPv6 ping filter may have an impact on an object (such as an IPv6 user plane channel or a remote maintenance channel) that may use the IPv6 ping function. Take these objects into consideration when this command is used together with the SET PINGFILTERMODE command.

  • [Co-MPT,eNodeB,gNodeB]System specifications: If the UMPT/UMDU is the main control board, a maximum of 8 ping filter entries can be configured. Ping Filter table entries for IPv6 are not supported when others.

  • [Co-MPT,eNodeB,gNodeB]Board specifications: A maximum of 8 IPv6 ping filter entries can be configured on a UMPT/UMDU. Ping Filter table entries for IPv6 are not supported when others.

Example

To add an IPv6 ping filter with the parameters as follows: IPv6 Address: 2001:DB8::1, Prefix Length: 32, run the following command:
ADD PINGFILTER6: IP6="2001:DB8::1", PFXLEN=32;
