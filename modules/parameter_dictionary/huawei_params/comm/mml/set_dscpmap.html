Set the DSCP to VLAN Priority Mapping Configuration (SET DSCPMAP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the mapping between a DSCP and a VLAN priority.

Note

  • If the VLAN priority in the VLANMAP mapped to the packet is disabled, use the VLAN priority in the DSCPMAP mapped to the DSCP of the packet.

  • The following describes the default mapping between DSCP values and VLAN priorities:

    If the DSCP is within the range from 0 to 7, the default priority is 0;

    If the DSCP is within the range from 8 to 15, the default priority is 1;

    If the DSCP is within the range from 16 to 23, the default priority is 2;

    If the DSCP is within the range from 24 to 31, the default priority is 3;

    If the DSCP is within the range from 32 to 39, the default priority is 4;

    If the DSCP is within the range from 40 to 47, the default priority is 5;

    If the DSCP is within the range from 48 to 55, the default priority is 6;

    If the DSCP is within the range from 56 to 63, the default priority is 7.

  • System specifications: If the WMPT/GTMUb/GTMUc is the main control board, a maximum of 64 mappings between a DSCP and a VLAN priority can be configured. If the UMPT/UMDU/LMPT is the main control board, a maximum of 512 mappings between a DSCP and a VLAN priority can be configured.

  • Board specifications: A maximum of 64 mappings between a DSCP and a VLAN priority can be configured on a WMPT/GTMUb/GTMUc/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 512 mappings between a DSCP and a VLAN priority can be configured on a UMPT/UMDU/LMPT.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP parameters must be set to different values if VRFIDX parameters are same in two DSCPMAP MOs.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DSCP Differentiated Service Codepoint

Meaning: Indicates the priority of a DSCP. A larger value of this parameter indicates a higher priority.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Differentiated Services Code Point parameter in the DSCP2PCPREF MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]DSCP parameters must be set to different values if VRFIDX parameters are same in two DSCPMAP MOs.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VLANPRIO VLAN Priority

Meaning: Indicates the priority of a VLAN. A larger value of this parameter indicates a higher priority.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Priority Code Point parameter in the DSCP2PCPREF MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set a DSCP to VLAN priority mapping with the following parameters: VRF Index: 0, Differentiated Service Codepoint: 0, VLAN Priority: 0, run the following command:
SET DSCPMAP: VRFIDX=0, DSCP=0, VLANPRIO=0;
