Display Loss Measurement Status (DSP ETHLM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the packet loss information on the Ethernet.

Note

None.

Parameters

ID Name Description
SESSIONID Session ID

Meaning: Indicates the number of a performance detection session.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the loss measurement with the parameters as follows: Session ID: 0, run the following command: 
DSP ETHLM: SESSIONID=0;
The result is shown as follows:

Output Description

Field Description

Session ID

Indicates the number of a performance detection session.

MEP ID

Indicates the MEP ID.

Destination Type

Indicates the ITU-T Y.1731 measurement destination type. The parameter value RMEP is the local MEP ID of the peer end. The parameter value MAC is the MAC address configured for the RMEP.

RMEP ID

Indicates the RMEP ID.

MAC Address

Indicates the configured destination MAC address in the format of XXXX-XXXX-XXXX.

Measurement State

Indicates the state of ITU-T Y.1731 performance measurement.

Local Tx Frames(frame)

Indicates the number of frames sent by the local end in the activation period. When the TX and RX frame counters flip or the counters are reset, the measurement result of this parameter is lost by one time.

Remote Rx Frames(frame)

Indicates the number of frames received by the peer end in the activation period. When the TX and RX frame counters flip or the counters are reset, the measurement result of this parameter is lost by one time.

Upper Lost Frames(frame)

Indicates the absolute difference between the number of frames sent by the local end and the number of frames received by the peer end in the activation period. Generally, the number of frames sent is greater than or equal to the number of frames received, and this parameter indicates the severity of packet loss. In the case of transmission disorder, abnormal measurement result of the local or peer end, inconsistent monitoring policy, multiple communication nodes on the peer monitoring port, packets on multiple nodes of the peer equipment matching the monitoring policy, the number of frames sent may be smaller than the number of frames received. In this case, this parameter indicates the severity of abnormal measurement.

Remote Tx Frames(frame)

Indicates the number of frames sent by the peer end in the activation period. When the TX and RX frame counters flip or the counters are reset, the measurement result of this parameter is lost by one time.

Local Rx Frames(frame)

Indicates the number of frames received by the local end in the activation period. When the TX and RX frame counters flip or the counters are reset, the measurement result of this parameter is lost by one time.

Down Lost Frames(frame)

Indicates the absolute difference between the number of frames sent by the peer end and the number of frames received by the local end in the activation period. Generally, the number of frames sent is greater than or equal to the number of frames received, and this parameter indicates the severity of packet loss. In the case of transmission disorder, abnormal measurement result of the local or peer end, or monitoring policy inconsistency, the number of frames sent may be smaller than the number of frames received. In this case, this parameter indicates the severity of abnormal measurement.

Tx LMM Frames(frame)

Indicates the number of transmitted loss measurement message (LMM) frames.

Rx LMR Frames(frame)

Indicates the number of received loss measurement reply (LMR) frames.
