Display SCTP Link Status (DSP SCTPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an SCTP link.

Note

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if neither the first peer IP address nor the second peer IP address of the SCTPPEER object is the same as the peer IPv4 address of the BLKSCTPPEERIPV4 object and the Block Flag of the SCTPPEER object is UNBLOCK, the Block Flag value in the DSP SCTPLNK command output is UNBLOCK. In the same routing domain, if either the first peer IP address or the second peer IP address of the SCTPPEER object is the same as the peer IPv4 address of the BLKSCTPPEERIPV4 object or the Block Flag of the SCTPPEER object is BLOCK, the Block Flag value in the DSP SCTPLNK command output is BLOCK.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the SCTP link is disconnected, the working local and peer IP addresses of the SCTP link are NULL.

  • [NodeB,eGBTS,eNodeB]In the same routing domain, if neither the first peer IP address nor the second peer IP address of the SCTPLNK object is the same as the peer IPv4 address of the BLKSCTPPEERIPV4 object and the Block Flag of the SCTPLNK object is UNBLOCK, the Block Flag value in the DSP SCTPLNK command output is UNBLOCK. In the same routing domain, if either the first peer IP address or the second peer IP address of the SCTPLNK object is the same as the peer IPv4 address of the BLKSCTPPEERIPV4 object or the Block Flag of the SCTPLNK object is BLOCK, the Block Flag value in the DSP SCTPLNK command output is BLOCK.

  • [eNodeB,gNodeB]In the same routing domain, if neither the first peer IPv6 address nor the second peer IPv6 address of the SCTPPEER object is the same as the peer IPv6 address of the BLKSCTPPEERIPV6 object and the Block Flag of the SCTPPEER object is UNBLOCK, the Block Flag value in the DSP SCTPLNK command output is UNBLOCK. In the same routing domain, if either the first peer IPv6 address or the second peer IPv6 address of the SCTPPEER object is the same as the peer IPv6 address of the BLKSCTPPEERIPV6 object or the Block Flag of the SCTPPEER object is BLOCK, the Block Flag value in the DSP SCTPLNK command output is BLOCK.

  • [eNodeB]In the same routing domain, if neither the first peer IPv6 address nor the second peer IPv6 address of the SCTPLNK object is the same as the peer IPv6 address of the BLKSCTPPEERIPV6 object and the Block Flag of the SCTPLNK object is UNBLOCK, the Block Flag value in the DSP SCTPLNK command output is UNBLOCK. In the same routing domain, if either the first peer IPv6 address or the second peer IPv6 address of the SCTPLNK object is the same as the peer IPv6 address of the BLKSCTPPEERIPV6 object or the Block Flag of the SCTPLNK object is BLOCK, the Block Flag value in the DSP SCTPLNK command output is BLOCK.

Parameters

ID Name Description
SCTPNO Link No.

Meaning: Indicates the number of the SCTP link. The value of SCTPNO in the SCTPLNK MOs configured by users ranges from 0 to 65535. The value of SCTPNO in the SCTPLNK MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]The value of Link No. in a manually configured SCTPLNK MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Output Description

Field Description

Link No.

Indicates the number of the SCTP link. The value of SCTPNO in the SCTPLNK MOs configured by users ranges from 0 to 65535. The value of SCTPNO in the SCTPLNK MOs configured by the system ranges from 70000 to 79999.

Deployment Cabinet No.

Indicates the deployment cabinet number of an SCTP link.

Deployment Subrack No.

Indicates the deployment subrack number of an SCTP link.

Deployment Slot No.

Indicates the deployment slot number of an SCTP link.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the IP protocol version.

First Local IP Address

Indicates the first local IP address of the SCTP link.

Second Local IP Address

Indicates the second local IP address of the SCTP link.

First Local IPv6 Address

Indicates the first local IPv6 address of an IPv6 SCTP link.

Second Local IPv6 Address

Indicates the second local IPv6 address of an IPv6 SCTP link.

Local SCTP Port No.

Indicates the local port number of the SCTP link.

First Peer IP Address

Indicates the first peer IP address of the SCTP link.

Second Peer IP Address

Indicates the second peer IP address of the SCTP link.

First Peer IPv6 Address

Indicates the first peer IPv6 address of an IPv6 SCTP link.

Second Peer IPv6 Address

Indicates the second peer IPv6 address of an IPv6 SCTP link.

Peer SCTP Port No.

Indicates the peer port number of the SCTP link.

Out Stream Number

Indicates the number of outbound streams negotiated for the SCTP link.

In Stream Number

Indicates the number of inbound streams negotiated for the SCTP link.

Work Address Flag

Indicates the working address flag of the SCTP link.

Working Local IP Address

Indicates the working local IP address of an SCTP link.

When IP Version of the SCTP link is set to IPv4, the working local IP address is an IPv4 address.

When IP Version of the SCTP link is set to IPv6, the working local IP address is an IPv6 address.

Working Peer IP Address

Indicates the working peer IP address of an SCTP link.

When IP Version of the SCTP link is set to IPv4, the working peer IP address is an IPv4 address.

When IP Version of the SCTP link is set to IPv6, the working peer IP address is an IPv6 address.

Block Flag

Indicates whether the SCTP link is blocked or not.

SCTP Link Status

Indicates the status of the SCTP link.

DTLS Link Status

Indicates the DTLS link status. The parameter takes effect only in NR.

Status Change Cause

Indicates the reason why the operational state of the SCTP or DTLS link changes from available to unavailable or from unavailable to available for the last time.

Status Change Time

Indicates the last time when the operational state of the SCTP or DTLS link changes from available to unavailable or from unavailable to available.

Maximum SCTP PDU Size(byte)

Indicates the maximum size of an IPv4 SCTP PDU (Protocol Data Unit). It specifies the maximum length of an SCTP PDU (excluding the IP header) transmitted on an SCTP link. If the value of this parameter is greater than the size of the IP layer MTU of the base station or intermediate transmission equipment, SCTP packets are fragmented at the IP layer. This causes a large number of fragments and affects the transmission efficiency of the intermediate transmission equipment.
