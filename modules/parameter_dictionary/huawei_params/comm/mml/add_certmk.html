Add Device Certificate (ADD CERTMK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a device certificate. The binding relationship between device certificates and a CA can be specified in the multi-PKI scenario.

Note

  • Before running this command, ensure that the corresponding device certificate file has been downloaded to the BS by running the DLD CERTFILE command.

  • After this command is executed, the BS checks for the device certificate whether the private key matches the public key. This command can be successfully executed only when they match each other.

  • Board specifications: A UMPT/UMDU/LMPT/UTRPc/UCCU/GTMUc/UBBPe series (except UBBPe15)/LCOP/UBBPf series/UBBPF series/UBBPg series board supports a maximum of 20 device certificates.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, a maximum of 20 device certificates can be configured.

  • If certificate number reaches 30, this command will return failure, please manually delete the certificates which are useless.

  • The file size of the device certificate to be loaded must be less than 3KB.

  • The interval between the effective time/ineffective time of the device certificate to be loaded and the current system time must be less than 68 years.

Parameters

ID Name Description
APPCERT Certificate File Name

Meaning: Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in a CERTMK MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CERTMK MO is being added, the APPCERT is case-insensitive; but when a CERTMK MO is referenced, the APPCERT is case-sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery. There is only one such MO on an NE and this MO cannot be added or removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CASW CA Switch

Meaning: Indicates whether a CA server is specified for a device certificate. When this parameter is set to OFF, only one CA is configured or no CA is configured (the device certificate can be configured only in the offline mode). When this parameter is set to ON, a CA needs to be specified.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery, and CASW in the CERTMK MO must be set to OFF.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CANAME Certificate Authority Name

Meaning: Indicates the name of the CA server specified by the certificate.

GUI Value Range: 1~127 characters

Unit: None

Actual Value Range: 1~127 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CERTMK MO, this parameter is valid only when CASW is set to ON.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a device certificate file with the parameters as follows: Certificate File Name: eNodeBCert.pem, CA Switch: ON, Certificate Authority Name: C=cn,S=sc,L=cd,O=Huawei,OU=Wireless,CN=enbca, run the following command:
ADD CERTMK: APPCERT="eNodeBCert.pem", CASW=ON, CANAME="C=cn,S=sc,L=cd,O=Huawei,OU=Wireless,CN=enbca";
