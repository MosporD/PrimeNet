Set NE Status (SET MNTMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the maintenance status of the NE. When the NE is in the maintenance status, the way of alarm reporting is changed and the performance measurement is unbelievable.

Note

  • After the MPT is restarted, the base station will be in the same maintenance status as it is before the restart.

  • In a separate-MPT multimode base station, if a UBBP or UBBP-W is configured with multiple modes and MNTMODE of a mode is not set to NORMAL, the mode may stop managing the UBBP or UBBP-W.

  • It is recommended that the MNTMODE parameter be set to INSTALL(INSTALL) or TESTING(TESTING) only in NE deployment. If MNTMODE is set to a value other than INSTALL(INSTALL) or TESTING(TESTING), the value of MNTMODE cannot not be changed to INSTALL(INSTALL) or TESTING(TESTING).

Parameters

ID Name Description
MNTMODE Maintenance Mode

Meaning: Indicates the maintenance mode of an NE. The normal state indicates that the NE is in the normal service operation state and does not carry out any engineering maintenance activities. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. The maintenance mode of a device is set to TESTING by default before delivery. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes.

GUI Value Range: NORMAL(NORMAL), INSTALL(INSTALL), EXPAND(EXPAND), UPGRADE(UPGRADE), TESTING(TESTING), ExpandStatus1(ExpandStatus1), ExpandStatus2(ExpandStatus2), ExpandStatus3(ExpandStatus3), ExpandStatus4(ExpandStatus4), ExpandStatus5(ExpandStatus5), ExpandStatus6(ExpandStatus6), ExpandStatus7(ExpandStatus7), ExpandStatus8(ExpandStatus8), ExpandStatus9(ExpandStatus9), ExpandStatus10(ExpandStatus10)

Unit: None

Actual Value Range: NORMAL, INSTALL, EXPAND, UPGRADE, TESTING, ExpandStatus1, ExpandStatus2, ExpandStatus3, ExpandStatus4, ExpandStatus5, ExpandStatus6, ExpandStatus7, ExpandStatus8, ExpandStatus9, ExpandStatus10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
ST Start Time of Status Setting

Meaning: Indicates the start time of the NE maintenance mode. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the start time of the maintenance mode is 2000-01-01 00:00:00.

GUI Value Range: 2000-01-01T00:00:00+00:00~2037-12-31T23:59:59+00:00

Unit: None

Actual Value Range: 2000-01-01T00:00:00+00:00~2037-12-31T23:59:59+00:00

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When MNTMODE in the NEMNT MO is not set to NORMAL, ET in the NEMNT MO must be later than ST.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
ET End Time of Status Setting

Meaning: Indicates the end time of maintenance status of the NE. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the maintenance status ends at 2037-12-31 23:59:59.

GUI Value Range: 2000-01-01T00:00:00+00:00~2037-12-31T23:59:59+00:00

Example

To set the special alarm status of the NE with parameters as follows: current maintenance mode: testing, start time:2011-10-20 15:00, end time: 2011-10-21 15:00, maintenance setting remarks: Device maintenance, run the following command:
SET MNTMODE: MNTMODE=TESTING, ST=2011&10&20&15&00&00, ET=2011&10&21&15&00&00, MMSETREMARK="Device maintenance";
