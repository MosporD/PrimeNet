Remove IP PM Session (RMV IPPMSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an IP PM session.

Note

None.

Parameters

ID Name Description
IPPMSN Session ID

Meaning: Indicates the ID of an IP PM session of an NE. An IP PM session with an ID ranging from 0 to 65535 is configured by users. An IP PM session with an ID ranging from 70000 to 79999 is configured by the system.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of Session ID in a manually configured IPPMSESSION MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove an IP PM session whose ID is 0, run the following command:
RMV IPPMSESSION: IPPMSN=0;
