Display Diagnose Information (DSP DIAGNOSE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

If the Diagnose Type is set to IKENEGO, use this command to query IKE/IPSec negotiation errors in security networking scenarios. If the Diagnose Type is set to SCTP, use this command to query information about disconnected SCTP links.If the Diagnose Type is set to ENDPOINT, use this command to query error information about an automatic setup procedure of end point MOs.

Note

  • If an IKE peer or IPSec policy is modified by running the MOD IKEPEER or MOD IPSECPOLICY command, respectively, the IKE or IPSec negotiation error messages pertaining to the IKE peer or IPSec policy will be deleted.

  • When Diagnose Type is set to IKENEGO, a maximum of 128 records of diagnosis information can be displayed and it is recommended that filtering conditions be specified before this command is executed. When Diagnose Type is set to SCTP, a maximum of five records of diagnosis information can be displayed. When Diagnose Type is set to ENDPOINT, only the last record of diagnosis information is displayed for the same records of diagnosis information and a maximum of 20 records of diagnosis information can be displayed.

  • If the diagnosis type is IKENEGO, this operation is time-consuming. After this command is executed, if the execution of another MML command times out or the board does not respond, wait 15 seconds until the execution of this command is complete and then run the next MML command again.

  • When the base station serves as the responder and Diagnose Type is set to IKENEGO, some IPSec negotiation errors cannot be queried by filtering IPSec policy groups.

PT Port Type

Meaning: Indicates the port type. In the old model, the query using the DSP DIAGNOSE command with Port Type set to INTERFACE is not supported. In the new model, only the query using the DSP DIAGNOSE command with Port Type set to INTERFACE is supported. When the DSP DIAGNOSE command is executed with Port Type set to INTERFACE to query the IKE/IPsec negotiation error information, the correct cabinet, subrack, and slot information is required. When IPSec Bind Mode in the IKECFG MO is set to ALL and the DSP DIAGNOSE command is executed with Port Type set to the normal interface bound to the IPSECBINDITF MO, the corresponding IKE/IPsec negotiation error information can be queried.

Example

To query the diagnosis information with the parameters as follows: Diagnose Type: SCTP, run the following command:
DSP DIAGNOSE: DIAGNOSETYPE=SCTP;
The result is shown as follows:
