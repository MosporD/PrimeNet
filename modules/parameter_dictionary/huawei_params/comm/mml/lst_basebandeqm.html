List Baseband Equipment Configuration (LST BASEBANDEQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of baseband equipment.

Note

If Baseband Equipment ID is not specified, the basic configuration of all baseband equipment is displayed, but the configuration of baseband processing units is not displayed. If Baseband Equipment ID and Baseband Equipment Type are specified, configuration of baseband equipment and baseband processing units is displayed.

Parameters

ID Name Description
BASEBANDEQMID Baseband Equipment ID

Meaning: Indicates the number of the baseband equipment.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
BASEBANDEQMTYPE Baseband Equipment Type

Meaning: Indicates the type of baseband equipment.

GUI Value Range: UL(UL), DL(DL), ULDL(Combined UL and DL)

Unit: None

Actual Value Range: UL, DL, ULDL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To list the configuration of baseband equipment with the parameters as follows: Baseband Equipment ID: 0 and Baseband Equipment Type: ULDL, run the following command:
LST BASEBANDEQM: BASEBANDEQMID=0, BASEBANDEQMTYPE=ULDL;
The result is as follows:

Output Description

Field Description

Baseband Equipment ID

Indicates the number of the baseband equipment.

Baseband Equipment Type

Indicates the type of baseband equipment.

UMTS UL Demodulation Mode

Indicates the demodulation mode of uplink baseband equipment for UMTS mode. When uplink (or uplink and downlink) baseband equipment is added, its demodulation mode must be specified. Different demodulation modes can be specified for different sets of uplink (or uplink and downlink) baseband equipment. This parameter cannot be set to NULL for UMTS. This parameter is not used for other modes, and it is recommended that this parameter be set to NULL.

Cabinet No.

Indicates the number of a cabinet that houses a baseband processing unit.

Subrack No.

Indicates the number of a subrack that houses a baseband processing unit.

Slot No.

Indicates the number of a slot that houses a baseband processing unit. If a BLADEBBU is configured, this parameter cannot be set to a value from 0 to 5. If a subrack other than BLADEBBU is configured, this parameter cannot be set to 6.
