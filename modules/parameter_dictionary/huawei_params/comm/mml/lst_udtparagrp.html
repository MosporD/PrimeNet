List Parameter Group for A User Data Type (LST UDTPARAGRP)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list a transport parameter group for a user data type.

Note

[Co-MPT,eGBTS,eNodeB,gNodeB]This command takes effect only for LTE and NR.

Parameters

ID Name Description
UDTPARAGRPID User Data Type Transfer Parameter Group ID

Meaning: Indicates the ID of a transport parameter group of services corresponding to a user data type. User data types numbered from 1 to 9, 65, 66, 69, 70, 75, 79, 80, and 85 are standard user data types. User data types numbered from 1 to 9 correspond to transport parameter groups with IDs 40 to 48, user data types numbered 65, 66, 75, and 85 correspond to the transport parameter group with ID 40, user data types numbered 69 correspond to the transport parameter group with ID 44, and user data types numbered 70, 79, and 80 correspond to the transport parameter group with ID 45. All of these IDs are automatically configured by a base station.

GUI Value Range: 0~48

Unit: None

Actual Value Range: 0~48

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, L, N

Example

To list the configuration of a parameter group for a user data type, run the following command:
LST UDTPARAGRP:;

Output Description

Field Description

User Data Type Transfer Parameter Group ID

Indicates the ID of a transport parameter group of services corresponding to a user data type. User data types numbered from 1 to 9, 65, 66, 69, 70, 75, 79, 80, and 85 are standard user data types. User data types numbered from 1 to 9 correspond to transport parameter groups with IDs 40 to 48, user data types numbered 65, 66, 75, and 85 correspond to the transport parameter group with ID 40, user data types numbered 69 correspond to the transport parameter group with ID 44, and user data types numbered 70, 79, and 80 correspond to the transport parameter group with ID 45. All of these IDs are automatically configured by a base station.

Priority Rule

Indicates the rule for prioritizing traffic to meet service requirements. If this parameter is set to IPPRECEDENCE, the protocol stack of the earlier version is adopted, which firstly converts a Type of Service (TOS) to a DSCP and then prioritizes traffic.

Priority

Indicates the priority of the service data, which is identified by a DSCP value. The priority of the service data has a positive correlation with the DSCP value.

Act Factor(%)

Indicates the activity factor of the services corresponding to a QCI.

Primary Transport Resource Type

Indicates the type of primary transport resource used to transmit the user data when hybrid transmission is adopted. HQ indicates that high-quality transport resources are used, while LQ indicates that low-quality transport resources are used. When a new service requests admission and admission control is performed, one of the IP path routes with transport resources of the same quality is used as the primary transport path.

Primary Port Load Threshold(%)

Indicates the primary port load threshold of the user data in the hybrid transmission scenario. A larger value indicates that services are more likely to be admitted to the primary path.

Primary To Secondary Port Load Ratio Threshold(%)

Indicates the primary-to-secondary port load ratio threshold of user data in the hybrid transmission scenario. A smaller value indicates that services are more likely to be admitted to the primary path.
