Add Wireless Local IP Address (ADD WLOCALIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add the wireless local maintenance IP address.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: When a UMDU serves as the main control board, the base station supports only one wireless local maintenance IP address. When a WMPT/UMPT/LMPT serves as the main control board, the base station does not support wireless local maintenance IP address.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In deployment scenarios, the base station does not validate the wireless local maintenance IP address when the local IP address of the remote OM channel obtained by the DHCP conflicts with the wireless local maintenance IP address.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When a WMPT/UMPT/LMPT serves as the main control board, the base station does not validate the wireless local maintenance IP address that you have added. In addition, the base station automatically removes this IP address after a reset.

  • [Co-MPT,NodeB,eGBTS,eNodeB]This operation may interrupt the local maintenance channel.

Parameters

ID Name Description
IPIDX IP Index

Meaning: Indicates the index of the wireless local maintenance IP address.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R
IP IP Address

Meaning: Indicates the wireless local maintenance IP address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]In the WLOCALIP MO, IP must be set to a valid IP address of Class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the WLOCALIP MO, neither the network ID nor the host ID can be all 0 or all 1 after IP matches MASK.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R
MASK Mask

Meaning: Indicates the subnet mask of the wireless local maintenance IP address.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]After the value of MASK in the WLOCALIP MO is converted to a binary value, 0 cannot exist before 1, and 1 cannot exist after 0. In addition, the value cannot be 0.0.0.0 or 255.255.255.255.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the WLOCALIP MO, neither the network ID nor the host ID can be all 0 or all 1 after IP matches MASK.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R

Example

To add a wireless local IP address with the parameters as follows: IP Index: 0, IP Address: 192.168.11.32, Mask: 255.255.255.0, run the following command: 
ADD WLOCALIP: IPIDX=0, IP="192.168.11.32", MASK="255.255.255.0";
