Set Ping Filter Mode (SET PINGFILTERMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the ping filtering mode.

Note

  • [Co-MPT,eNodeB,gNodeB]When the ping filtering entries defined by the PINGFILTER and PINGFILTER6 objects are both empty, the ping filtering mode does not take effect and the ping filtering function is disabled. When the ping filtering entry defined by either the PINGFILTER or PINGFILTER6 object is not empty, the ping filtering mode takes effect, and the ping filtering function is enabled for both the PINGFILTER and PINGFILTER6 objects.

  • [Co-MPT,NodeB]If there are no ping filter entries, the ping filtering mode fails to take effect and thus the ping filtering function is disabled.

Parameters

ID Name Description
MODE Ping Filter Mode

Meaning: Indicates the mode of the ping filtering. When the whitelist is used, only the network segments or hosts specified by the ping filter can ping the NE. When the blacklist is used, the network segments or hosts specified by the ping filter cannot ping the NE.

GUI Value Range: WHITELIST(Whitelist), BLACKLIST(Blacklist)

Unit: None

Actual Value Range: WHITELIST, BLACKLIST

MML Default Value: None

Recommended Value: WHITELIST(Whitelist)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Set the PINGFILTER Mode Whitelist.
SET PINGFILTERMODE: MODE=WHITELIST;
