Display IPSec SA Status (DSP IPSECSA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the IPSec SA.

Note

  • The information about a maximum of 1024 SAs can be displayed by the command.

  • [NodeB]The WMPT does not support this function.

Example

To query the IPSec SA status with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, IPSec Policy Group Name: policy4, IPSec Sequence No.: 4, run the following command:
DSP IPSECSA: SN=7, SPGN="policy4", SPSN=4;

Output Description

Field Description

IPSec Policy Group Name

Indicates the name of the IPSec policy group used by the IPSec SA.

IPSec Sequence No.

Indicates the sequence number of the IPSec policy.

Configuration Mode

Indicates the mode of the IPSec policy negotiation.

Connection ID

Indicates the channel identifier of the IPSec SA.

Encapsulation Mode

Indicates the encapsulation mode.

VRF Index

Indicates the index of a VRF instance.

IPv4 Source IP

Indicates the local IP address of the IPSec tunnel.

IPv6 Source IP

Indicates the local IPv6 address of an IPv6 IPSec tunnel.

IPv4 Destination IP

Indicates the peer IP address of the IPSec tunnel.

IPv6 Destination IP

Indicates the peer IPv6 address of an IPv6 IPSec tunnel.

Outgoing Protocol 1 SA

Indicates the TX Protocol 1 SA.

Outgoing Protocol 1 SA SPI

Indicates the security parameter index of a transmitted Protocol 1 SA.

Outgoing Protocol 1 SA Remaining Time(s)

Indicates the remaining living time of a transmitted Protocol 1 SA.

Outgoing Protocol 1 SA Remaining Flow(kB)

Indicates the remaining flow of a transmitted Protocol 1 SA.

Outgoing Protocol 1 SA Encrypted Flow(kB)

Indicates the traffic volume of bytes that have been sent by the outgoing Protocol 1 SA before encryption.

Outgoing Protocol 1 SA Generation Time

Indicates the generation time of the outgoing Protocol 1 SA.

Incoming Protocol 1 SA

Indicates the RX Protocol 1 SA.

Incoming Protocol 1 SA SPI

Indicates the security parameter index of a received Protocol 1 SA.

Incoming Protocol 1 SA Remaining Time(s)

Indicates the remaining living time of a received Protocol 1 SA.

Incoming Protocol 1 SA Remaining Flow(kB)

Indicates the remaining flow of a received Protocol 1 SA.

Incoming Protocol 1 SA Decrypted Flow(kB)

Indicates the traffic volume of bytes that have been received by the incoming Protocol 1 SA after decryption.

Incoming Protocol 1 SA Generation Time

Indicates the generation time of the incoming Protocol 1 SA.

Outgoing Protocol 2 SA

Indicates the TX Protocol 2 SA.

Outgoing Protocol 2 SA SPI

Indicates the security parameter index of a transmitted Protocol 2 SA.

Outgoing Protocol 2 SA Remaining Time(s)

Indicates the remaining living time of a transmitted Protocol 2 SA.

Outgoing Protocol 2 SA Remaining Flow(kB)

Indicates the remaining flow of a transmitted Protocol 2 SA.

Outgoing Protocol 2 SA Encrypted Flow(kB)

Indicates the traffic volume of bytes that have been sent by the outgoing Protocol 2 SA before encryption.

Outgoing Protocol 2 SA Generation Time

Indicates the generation time of the outgoing Protocol 2 SA.

Incoming Protocol 2 SA

Indicates the RX Protocol 2 SA.

Incoming Protocol 2 SA SPI

Indicates the security parameter index of a received Protocol 2 SA.

Incoming Protocol 2 SA Remaining Time(s)

Indicates the remaining living time of a received Protocol 2 SA.

Incoming Protocol 2 SA Remaining Flow(kB)

Indicates the remaining flow of a received Protocol 2 SA.

Incoming Protocol 2 SA Decrypted Flow(kB)

Indicates the traffic volume of bytes that have been received by the incoming Protocol 2 SA after decryption.

Incoming Protocol 2 SA Generation Time

Indicates the generation time of the incoming Protocol 2 SA.

Protected Flow Source IP Address

Indicates the source address of the data flow protected by the IPSec SA.

Protected Flow Source Wildcard

Indicates the source address wildcard of the data flow protected by the IPSec SA. The wildcard is used to determine which bits can be neglected when IP address matching is being performed. It can be considered as the inverse of the corresponding subnet mask.

Protected Flow Destination IP Address

Indicates the destination address of the data flow protected by the IPSec SA.

Protected Flow Destination Wildcard

Indicates the destination address wildcard of the data flow protected by the IPSec SA. The wildcard is used to determine which bits can be neglected when IP address matching is being performed. It can be considered as the inverse of the corresponding subnet mask.

IPv6 Protected Flow Source IP Address

Indicates the source IPv6 address of the data flow protected by the IPSec SA.

Prefix Length of IPv6 Protected Flow Source IP Address

Indicates the prefix length of the source IPv6 address of the data flow protected by the IPSec SA.

IPv6 Protected Flow Destination IP Address

Indicates the destination IPv6 address of the data flow protected by the IPSec SA.

Prefix Length of IPv6 Protected Flow Destination IP Address

Indicates the prefix length of the destination IPv6 address of the data flow protected by the IPSec SA.
