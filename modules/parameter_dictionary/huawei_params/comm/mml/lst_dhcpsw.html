List OM Channel Automatic Establishment Switch (LST DHCPSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list configurations of parameters for automatic establishment of a remote maintenance channel.

Note

None.

Parameters

None.

Example

To list configurations of parameters for automatic establishment of the remote maintenance channel, run the following command: 
LST DHCPSW:;
The result is shown as follows:
+++    0        2008-02-08 22:03:02
O&M    #86
%%LST DHCPSW:;%%
RETCODE = 0  Operation succeeded.

List DHCP Switch Configuration Data
-----------------------------------
OMCH Auto-Establishment Switch  =  Enable
               Vlanscan Switch  =  Disable
    Delay Establishment Switch  =  Disable
(Number of results = 1)


---    END

Output Description

Field Description

OMCH Auto-Establishment Switch

Indicates whether to enable DHCP detection during automatic establishment of the remote maintenance channel. If this parameter is set to DISABLE, DHCP listening is performed instead of DHCP detection.

Vlanscan Switch

Indicates whether to turn on the base station VLAN scan function, the VLAN scanning function is refers, when the network element enters the detect detection, on the Ethernet port, carries on the IPv4 DHCP detection to the VLAN identity range to 0~4094.

Delay Establishment Switch

Indicates whether to enable the function of reestablishing the base station's remote maintenance channel after a specified period.
