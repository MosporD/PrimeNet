Modify BFD (MOD BFD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a BFD.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed to change the value of the CATLOG parameter to RELIABILITY, route interlock is triggered.

  • After a BFD session with the CATLOG parameter set to RELIABILITY is added, the effect of the previous route interlock is eliminated if the value of the CATLOG parameter is changed to MAINTENANCE.

  • [Co-MPT,NodeB,eNodeB,gNodeB]During the modification of a BFD session, the source and destination IP addresses of the session cannot be changed if the session is referenced by an IPSec tunnel pair.

SRCIP Source IP

Meaning: Indicates the source IP address of a BFD. The source IP address of a BFD must be a device IP address of a specified board (for example, the IP address of an Ethernet port or a port that carries a PPP link or MP group) or a logical IP address (for example, the IP address of a loopback port), but cannot be set to the same value as the IP address of a remote maintenance channel or a negotiated IP address. Note that a BFD cannot be configured as a single-hope session if its source IP address is a logical IP address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRCIP in a BFD MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x (including 0.0.0.0).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRCIP must be different from DSTIP in a BFD MO.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

CATLOG Session Catalog

Meaning: Indicates the type of a BFD. If this parameter is set to MAINTENANCE, this BFD is used only for continuity check (CC). If this parameter is set to RELIABILITY, the BFD is used to trigger route interlock. Route interlock enables the standby route to take over once the active route becomes faulty, and therefore prevents service interruption caused by route failures.

Example

To modify the configuration of the BFD with the parameters as follows: Session ID: 100, VRF Index: 0, Source IP: 192.168.5.5, Destination IP: 192.168.5.6, Local Discriminator: 2, Min TX Interval: 100, Min RX Interval: 100, Detection Multiplier: 3, Session Catalog: RELIABILITY, Protocol Version: DRAFT4, BFD Authentication Switch: OFF, run the following command:  
MOD BFD: BFDSN=100, VRFIDX=0, SRCIP="192.168.5.5", DSTIP="192.168.5.6", MYDISCREAMINATOR=2, HT=SINGLE_HOP, MINTI=100, MINRI=100, DM=3, CATLOG=RELIABILITY, VER=DRAFT4, BFDAUTHSW=OFF;
