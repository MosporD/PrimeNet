List Cabinet (LST CABINET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a cabinet. If the cabinet number is not specified, the system would list the configuration of all cabinets.

Note

When the user does not set the description about a cabinet, the description about the cabinet is displayed as NULL.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
LOCATIONNAME Location Name

Meaning: Indicates the location information of a cabinet. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To list the information about the cabinet, run the following command:
LST CABINET:;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number.

Cabinet Type

Type of a cabinet. This parameter is set to VIRTUAL when the type of a cabinet is not within the value range of this parameter.

Cabinet Description

Indicates a brief description of the cabinet, which can be the function, location, and some other information of the cabinet. If the value of this parameter for the cabinet housing the root BBU includes tlmmpsw, both the MLPPP group fault detection period and PPP link fault detection period are automatically set to 1s.

Location Name

Indicates the location information of a cabinet. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.
