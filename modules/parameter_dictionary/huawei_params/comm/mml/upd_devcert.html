Update Device Certificate (UPD DEVCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to update a device certificate by starting a Certificate Management Protocol (CMP) session. After a CMP session is started, its status can be queried by running the DSP CMPSESSION command.

Note

  • The certificate to be updated must be a configured device certificate. Note that the certificate configured on the BS before delivery cannot be updated.

  • If a Certificate Management Protocol (CMP) session ends normally but the certificate test fails, the slave CA URL will not be used to update the certificate.

  • In multi-interface IPsec scenarios, if a certificate to be updated is referenced by an IPsec policy group bound to a board where the certificate is not deployed, the IPsec policy group bound to the board where the certificate is deployed must reference the same certificate.

Parameters

ID Name Description
APPCERT Certificate File Name

Meaning: Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]APPCERT in a CERTMK MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CERTMK MO is being added, the APPCERT is case-insensitive; but when a CERTMK MO is referenced, the APPCERT is case-sensitive.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The CERTMK MO with APPCERT set to appcert.pem defines a certificate configured on an NE before delivery. There is only one such MO on an NE and this MO cannot be added or removed.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
REKEY Renew Key

Meaning: Indicates whether to generate a new key pair.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: YES(YES)

Recommended Value: YES(YES)

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]This parameter is valid only when REQMODE is set to UPDATE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To update device certificate with Certificate File Name: basestationCert.pem, Renew Key: YES, run the following command:
UPD DEVCERT: APPCERT="basestationCert.pem", REKEY=YES;
