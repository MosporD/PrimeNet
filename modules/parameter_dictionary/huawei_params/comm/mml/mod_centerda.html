Modify Clock Center DA (MOD CENTERDA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to change the center DA value of an NE.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

An inappropriate setting of the center DA value will result in the failure to lock the reference clock.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the system clock is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the system clock is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the system clock is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
DA Center DA

Meaning: Indicates the center DA (Digital to Analog) value. After the reference clock is locked for 96 hours, the average of current DA values in this period is used as the center DA value.

GUI Value Range: 255~65520

Unit: None

Actual Value Range: 255~65520

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the clock center DA in slot 7, CenterDA: 12222, run the following command:
MOD CENTERDA: SN=7, DA=12222;
