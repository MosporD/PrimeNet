Stop STM-1 Out-of-Service Performance Test (STP STM1OFFLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to stop the STM-1 offline performance test.

Note

  • [Co-MPT,NodeB]You can run this command only after an STM-1 offline performance test is started.

  • [Co-MPT,NodeB]After the offline BER test is disabled, you must remove the optical fiber loopback or LM configurations if a loopback is configured. If a loopback is configured at the peer end, the loopback configurations must be removed. Otherwise, services will be disrupted.

Example

To stop the STM-1 offline performance test with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, Port No.: 0, run the following command:
STP STM1OFFLTST: CN=0, SRN=0, SN=0, SBT=UNCHANNELLED_COVERBOARD, STM1N=0;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a specified optical port is located.

Subrack No.

Indicates the number of the subrack that houses the board where a specified optical port is located.

Slot No.

Indicates the number of the slot corresponding to the board where a specified optical port is located.

Subboard Type

Indicates the type of sub-board where a specified optical port is located.

Port No.

Indicates the number of a specified optical port.

Remain Time

Indicates the remaining time during an STM-1 test.

Duration

Indicates the duration during which the STM-1 test lasts.

Frame Error Rate

Indicates the bit error rate in the test result.
