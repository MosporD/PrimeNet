List Source IP Route Configuration (LST SRCIPRT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a source IP route.

Note

None.

Parameters

None.

Example

To list the information of source IP routes in the database, run the following command:
LST SRCIPRT:;
The result is shown as follows:

Output Description

Field Description

Source Route Index

Indicates the index of the source IP route.

Cabinet No.

Indicates the number of the cabinet that houses the board where the source IP route is configured.

Subrack No.

Indicates the number of the subrack that houses the board where the source IP route is configured.

Slot No.

Indicates the number of the slot that houses the board where the source IP route is configured.

Subboard Type

Indicates the subboard type of the board where the source IP route is configured.

Source IP Address

Indicates the source IP address of the source IP route.

Route Type

Indicates the type of the source IP route. NEXTHOP means that all IP packets that meet the route direction are first forwarded to the specified next hop IP address. IF means that all IP packets that meet the route direction are first forwarded to the specified egress port.

Next Hop IP

Indicates the next-hop IP address of the source IP route.

Interface Type

Indicates the type of the port that carries the source IP route.

Port No.

Indicates the number of the port that carries the source IP route.

Priority

Indicates the priority of the source IP routing entry. A smaller parameter value indicates a higher priority.

User Label

Indicates the user-defined information of the source IP route.
