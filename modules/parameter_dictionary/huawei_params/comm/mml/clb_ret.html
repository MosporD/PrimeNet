Calibrate RET (CLB RET)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to calibrate a remote electrical tilting (RET) unit. The calibration is to ensure that all antenna tilts supported by the RET unit are configured correctly and consistent with the actual configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • During the calibration, do not perform any other operations on the RET antenna.

  • Calibration must be performed after the installation of an RET antenna. If this operation is skipped, the network coverage might be affected by an improper tilt.

  • It takes less than 8 minutes to calibrate an RET subunit. After the calibration, the tilt is adjusted automatically according to the configured value.

  • After an RET antenna is reset or powered off, it does not need to be calibrated again. If an ALM-26753 RET Antenna Not Calibrated alarm is reported, run the CLB RET command to clear this alarm.

  • During the calibration, the antenna tilt will be adjusted, affecting the network coverage.

  • If an unavailable RPCU exists on the base station, the execution of this command fails.

Example

To calibrate the tilt of the RET antenna in the operation mode of SITE, run the following command:
CLB RET: OPMODE=SITE;
