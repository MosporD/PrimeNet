Set Cascade Port (SET CASCADEPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the alarm detection state of a specified cascading port.

Note

  • If the board where the cascading port is located is unavailable, the command will be executed successfully but the configuration will not take effect.

  • The cascading ports can be configured only on the UMPT, UCIU, WBBPf, LBBPd, UBBP, UCCU and LCOP boards.

  • This command applies only to Cloud BB scenarios. If Switch is set to ON in non-Cloud BB scenarios, ALM-26314 Inter-BBU Port Failure may be incorrectly reported.

  • The BLADEBBU does not support this command.

  • [eNodeB,gNodeB]The LMPT, LPMP and LBBPc boards have no cascading ports. However, the cascading ports can be configured on these boards, and the cascading port alarm detection is not started after the configuration takes effect.

Example

To set the alarm detection state of a specified cascading port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Port No.: 0, Switch: ON, run the following command:
SET CASCADEPORT: CN=0, SRN=0, SN=0, PN=0, SW=ON;
