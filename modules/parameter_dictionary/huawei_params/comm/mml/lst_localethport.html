List Local Ethport Configuration (LST LOCALETHPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the local maintenance Ethernet port.

Note

None.

Parameters

None.

Example

To list the Configuration of the local maintenance Ethernet port, run the following command:
LST LOCALETHPORT:;
The result is as follows:
+++    0        2015-12-20 22:16:59
O&M    #1484
%%LST LOCALETHPORT:;%%
RETCODE = 0  Operation succeeded.

List Local Ethport Configuration
--------------------------------
          Enable Flag  =  Disable
Gratuitous ARP Switch  =  Disable
          IPv6 Switch  =  Disable
(Number of results = 1)


---    END

Output Description

Field Description

Enable Flag

Indicates whether to enable the local maintenance Ethernet port. When the parameter is set to DISABLE, the local maintenance Ethernet port is disabled if the remote OM channel is working properly, but is enabled if the remote OM channel is faulty. When the parameter is set to ENABLE, the local maintenance Ethernet port is permanently enabled.

Gratuitous ARP Switch

Indicates whether a local maintenance port sends gratuitous ARP packets. When this switch is turned on, a local maintenance port sends gratuitous ARP packets. When this switch is turned off, a local maintenance port does not send gratuitous ARP packets.

IPv6 Switch

Indicates whether to enable IPv6 on a local maintenance Ethernet port. When this switch is turned on, a local maintenance IPv6 address can be used to maintain a base station and the local maintenance Ethernet port actively sends IPv6 packets. When this switch is turned off, a local maintenance IPv6 address cannot be used to maintain a base station and the local maintenance Ethernet port does not actively send IPv6 packets. The parameter takes effect only in LTE and NR.
