Add Subrack (ADD SUBRACK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a BBU subrack or an RFU subrack. This command is not applicable to other types of subracks. Those subracks are added automatically while the devices are added.

Note

  • Before a subrack is added, ensure that the cabinet that houses the subrack exists.

  • An RRU subrack is added by running the ADD RRU command.

  • An RF subrack must be added before an RFU is added by running the ADD RRU command.

  • A root BBU must have been configured before you configure a leaf BBU.

  • Before a leaf BBU is configured, a control link must have been configured between the root BBU and the leaf BBU by running the ADD CTRLLNK command.

  • A base station can be configured with a maximum of two BBU3900, BBU3910, BBU5900, BBU5900A, or BLADEBBU subracks.

  • A maximum of one RFU subrack can be configured in such a cabinet: 1. RFC; 2. BTS3900; 3. BTS3012_SRAN; 4. BTS3012AE_SRAN; 5. BTS3900AL; 6. BTS5900.
