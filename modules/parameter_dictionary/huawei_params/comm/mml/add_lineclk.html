Add E1/T1 Line Clock (ADD LINECLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an E1/T1 line clock link. If the NE can properly obtain synchronization signals from the E1/T1 line clock, this link becomes available.

Note

  • The E1/T1 line clock link must be configured on a board with the E1/T1 port.

  • After a reference clock source for a line clock is added, the line clock is only an optional reference clock source for the system.

  • When clock signals are extracted from an E1/T1 port, the E1/T1 port must work in slave mode.

  • When clock signals are extracted from an E1/T1 port on a board other than a UMPT or UMDU, port 0 must work in slave mode if the number of the E1/T1 port ranges from 1 to 3; port 4 must also work in slave mode if the number of the E1/T1 port ranges from 5 to 7.

  • You can run the SET E1T1 command to specify the working mode (active or slave) for a port and run the DSP E1T1 command to query the working mode of a port.

  • [Co-MPT,NodeB,eGBTS]Only the UTRP (supporting STM-1) supports the STM-1 parameter configuration.

  • [eNodeB]The LTE currently does not support STM-1 function.

Example

To add an E1/T1 line clock link with the parameters as follows: Slot No.: 6, Port Type: E1T1, Port No.: 0, run the following command:
ADD LINECLK: SN=6, PT=E1T1, PN=0;
