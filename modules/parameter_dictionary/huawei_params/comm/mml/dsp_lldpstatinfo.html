Display LLDP Statistic Info (DSP LLDPSTATINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query statistics on an LLDP port.

Note

None.

Parameters

ID Name Description
LLDPID LLDP ID

Meaning: Indicates the ID of an LLDP local entity.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CLEAR Clear Statistic

Meaning: Indicates whether to delete the current statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To query the LLDP statistic information with the parameters as follows: LLDP ID: 1, run the following command:
DSP LLDPSTATINFO: LLDPID=1;
The result is shown as follows:

Output Description

Field Description

LLDP ID

Indicates the ID of an LLDP local entity.

Ethernet Port ID

Indicates the ID of the Ethernet port on the board to which the LLDP local information belongs.

Cabinet No.

Indicates the cabinet number of the board where the LLDPLOCAL is located.

Subrack No.

Indicates the subrack number of the board where the LLDPLOCAL is located.

Slot No.

Indicates the slot number of the board where the LLDPLOCAL is located.

Port No.

Indicates the number of the Ethernet port where the LLDPLOCAL is located.

The Number Of LLDP Frames Transmitted(frame)

Indicates the total number of sent LLDP frames.

The Number Of LLDP Frames Received(frame)

Indicates the total number of received LLDP frames.

The Number Of Rx LLDP Frames Discarded(frame)

Indicates the total number of discarded LLDP frames.

The Number Of Rx LLDP Error Frames(frame)

Indicates the total number of received erroneous LLDP frames.

The Number Of Rx LLDP TLVs Discarded

Indicates the total number of discarded LLDP type-length-values (TLVs).

The Number Of LLDP TLVs Unrecognized

Indicates the total number of unrecognizable LLDP type-length-values (TLVs).

The Number Of LLDP Neighbor Information Aged Out

Indicates the total number of aged LLDP neighbors.
