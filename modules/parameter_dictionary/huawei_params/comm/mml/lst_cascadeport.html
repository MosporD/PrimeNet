List Cascade Port Configuration (LST CASCADEPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of one or all cascade ports.

Note

None.

Example

To list the configuration of one or all cascading ports, run the following command:
LST CASCADEPORT:;
The result is shown as follows:
+++    0        2013-11-29 11:24:01
O&M    #82
%%LST CASCADEPORT:;%%
RETCODE = 0  Operation succeeded.

List Cascade Port Configuration
-------------------------------

0            0            6         8         Basic Cascade Port     OFF   
(Number of results = 2)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the interconnection port is located.

Subrack No.

Indicates the subrack number of the board where the interconnection port is located.

Slot No.

Indicates the slot number of the board where the interconnection port is located.

Port No.

Indicates the number of the port that carries the interconnection link.

Port Type

Indicates the type of the cascading port.

Switch

Indicates the enabled/disabled state of the port. Alarms (except interconnection port failure alarms caused by abnormal port negotiations) can be detected and reported for a port only if the port is enabled.
