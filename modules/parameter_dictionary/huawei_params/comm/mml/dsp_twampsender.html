Display TWAMP Sender Statistic (DSP TWAMPSENDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of a TWAMP sender.

Note

The following parameters specify the accumulated number of packets from the time of a successful TWAMP session setup to the current time: Number of Packets Received by the Local End, Number of Packets Sent by the Local End, Number of Packets Received by the Peer End, and Number of Packets Sent by the Peer End.

Parameters

ID Name Description
CLIENTID Client Index

Meaning: Indicates the client index of a TWAMP sender.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SENDERID Sender Index

Meaning: Indicates the index of a TWAMP sender.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

To query the dynamic information about the TWAMP Sender, run the following command:  
DSP TWAMPSENDER:;

Output Description

Field Description

Client Index

Indicates the client index of a TWAMP sender.

Sender Index

Indicates the index of a TWAMP sender.

Local IP Address

Indicates the local IP address of a TWAMP sender.

Peer IP Address

Indicates the peer IP address of a TWAMP sender.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

TWAMP Architecture

Indicates the architecture of a TWAMP sender.

Light Architecture Mode

Indicates the working mode of a TWAMP sender deployed in the light architecture. The working mode of the TWAMP sender must be the same as that of the TWAMP responder. This parameter takes effect only when the TWAMP sender is deployed in the light architecture.

Negotiation Status

Indicates the negotiation status of a TWAMP sender. This parameter is valid only when the TWAMP sender is deployed in the full architecture.

Negotiation Failure Cause

Indicates the negotiation failure cause of a TWAMP sender. This parameter is valid only when the TWAMP sender is deployed in the full architecture.

Local UDP Port No.

Indicates the local UDP port number of a TWAMP sender.

Peer UDP Port No.

Indicates the peer UDP port number of a TWAMP sender.

Initial DSCP Value

Indicates the initial DSCP value of a TWAMP sender.

Changed DSCP Value

Indicates the changed DSCP value of a TWAMP sender. If the DSCP value has not been changed, the value of this parameter is displayed as NULL.

Number of Packets Received by the Local End(packet)

Indicates the number of packets received by a TWAMP sender.

Number of Packets Sent by the Local End(packet)

Indicates the number of packets sent by a TWAMP sender.

Number of Packets Received by the Peer End(packet)

Indicates the number of packets received by the peer of a TWAMP sender. This parameter is valid only when the TWAMP sender is deployed in the full architecture, or stateful mode in the light architecture.

Number of Packets Sent by the Peer End(packet)

Indicates the number of packets sent by the peer of a TWAMP sender. This parameter is valid only when the TWAMP sender is deployed in the full architecture, or stateful mode in the light architecture.

Average Round-Trip Delay(ms)

Indicates the average round trip delay on a TWAMP sender in the last sampling period. The sampling period is 5s. The value of this parameter in the current sampling period indicates the average round trip delay in the last sampling period.

Average Forward Jitter(ms)

Indicates the average forward jitter on a TWAMP sender in the last sampling period. The sampling period is 5s. The value of this parameter in the current sampling period indicates the average forward jitter in the last sampling period.

Average Backward Jitter(ms)

Indicates the average backward jitter on a TWAMP sender in the last sampling period. The sampling period is 5s. The value of this parameter in the current sampling period indicates the average backward jitter in the last sampling period.

Forward Average Packet Loss Rate(per mill)

Indicates the average forward packet loss rate of a TWAMP sender in the last sampling period. The sampling period is 30 seconds. In the current sampling period, this parameter indicates the average forward packet loss rate in the previous sampling period. This parameter is valid only when the TWAMP sender is deployed in the full architecture, or stateful mode in the light architecture.

Backward Average Packet Loss Rate(per mill)

Indicates the average backward packet loss rate of a TWAMP sender in the last sampling period. The sampling period is 30 seconds. In the current sampling period, this parameter indicates the average backward packet loss rate in the previous sampling period. This parameter is valid only when the TWAMP sender is deployed in the full architecture, or stateful mode in the light architecture.

Round-Trip Average Packet Loss Rate(per mill)

Indicates the average round-trip packet loss rate of a TWAMP sender in the last sampling period. The sampling period is 30 seconds. In the current sampling period, this parameter indicates the average round-trip packet loss rate in the previous sampling period. This parameter is valid only when the TWAMP sender is deployed in stateless mode in the light architecture.
