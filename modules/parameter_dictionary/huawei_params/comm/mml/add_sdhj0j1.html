Add J0/J1 Information (ADD SDHJ0J1)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to add the content of J0 or J1 on an optical interface board.

Note

None.

Example

To add J0/J1 information on the optical interface board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, Port No.: 0, Trace Byte: J0, Tx Type: TRACE_16BYTE, Tx Information: test, Tx Protocol Version: REVISION_2ND, Expected Rx Type: TRACE_16BYTE, Expected Rx Information: test, Rx Protocol Version: REVISION_2ND, run the following command:
ADD SDHJ0J1: CN=0, SRN=0, SN=0, SBT=UNCHANNELLED_COVERBOARD, STM1N=0, TB=J0, TXT=TRACE_16BYTE, TXV="test", TXVER=REVISION_2ND, RXT=TRACE_16BYTE, RXV="test", RXVER=REVISION_2ND;
