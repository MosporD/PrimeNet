Display TMA Subunit (DSP TMASUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about one or all tower mounted amplifier (TMA) subunit.

Note

  • In bypass mode, the TMA does not provide the amplification function.

  • When this command is used to execute batch operations on an AISG1.1-based TMA that is configured with two devices, one device returns failure if the TMA fails to response to the request for the device due to a TMA device software defect. In this case, run this command on the two devices one by one.

Meaning: Indicates the number of the TMA subunit, which starts from 1.

Example

To query the dynamic information about the TMA subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP TMASUBUNIT: DEVICENO=0, SUBUNITNO=1;

Output Description

Field Description

Device No.

Indicates the device number of the TMA.

Device Name

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

Subunit No.

Indicates the number of the TMA subunit, which starts from 1.

Online Status

Indicates the online status of the TMA subunit.

Actual Work Mode

Indicates the actual working mode of the TMA subunit.

Actual Gain(0.25dB)

Indicates the actual gain of the TMA subunit.

Actual Sector ID

Indicates the sector ID of the TMA subunit.
