Acting Delay Measurement (ACT ETHDM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to activate the measurement of bidirectional delay and jitter on the Ethernet.

Note

  • If the MAC address configured on the remote MEP is all zeros and the remote MEP does not learn the actual MAC address, the bidirectional delay and jitter measurement function fails to be activated on the Ethernet.

  • If the Ethernet OAM Type parameter is modified by running the SET ETHOAM command, the delay measurement function will become invalid.

  • System specifications: A maximum of 8 ETHDM objects can be configured.

  • Board specifications: A maximum of 8 ETHDM objects can be configured on a UCCU/UMPT/UMDU/LMPT/GTMUc/UTRPc/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • When the DSTTYPE parameter is set to RMEP, the CFMRMEP MO reference by the ETHDM MO must have been configured. When the DSTTYPE parameter is set to MAC, the CFMRMEP MO reference by the ETHDM MO must have been configured.

Example

To activate delay measurement with the parameters as follows: Session ID: 0, MD Name: aaa, MA Name: aaa, MEP ID: 1, Destination Type: RMEP, RMEP ID: 2, TX Interval: 1000ms, run the following command:
ACT ETHDM: SESSIONID=0, MDNAME="aaa", MANAME="aaa", MEPID=1, DSTTYPE=RMEP, RMEPID=2, INTERVAL=1000MS;
