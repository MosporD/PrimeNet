Remove IP to IP Transmission Resource Group Mapping Configuration (RMV IP2IPRSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a mapping between the IP address and the IP transmission resource group.

Note

  • Deleting the IP2RSCGRP MO during service operation affects the actual ip transmission resource group selected by the service and may cause service interruption during resource group switching.

  • [Co-MPT,eNodeB,gNodeB]After this command is executed, the internal IPv4 user plane path automatically set up between the base station and the peer end will be added to the default ip transmission resource group.

  • [Co-MPT,eNodeB,gNodeB]After this command is executed, the internal IPv6 user plane path automatically set up between the base station and the peer end will be added to the default ip transmission resource group.

Parameters

ID Name Description
IP2IPRSCGRPID IP to IP Transmission Resource Group ID

Meaning: Indicates the ID of the mapping between an IP address and an IP transmission resource group.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove a mapping between the IP address and the IP transmission resource group with the parameters as follows: IP to IP Transmission Resource Group ID: 0, run the following command:
RMV IP2IPRSCGRP: IP2IPRSCGRPID=0;
