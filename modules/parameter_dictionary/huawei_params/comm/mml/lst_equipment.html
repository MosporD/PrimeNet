List NE Equipment Configuration (LST EQUIPMENT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list NE equipment configuration.

Note

None.

Parameters

None.

Example

List NE Equipment Configuration: 
LST EQUIPMENT:;
The result is shown as follows:

Output Description

Field Description

Battery Intelligent Management Switch

Indicates the battery intelligent management switch status, which can be set to ON or OFF. ON indicates that this switch is set to on and OFF indicates that this switch is set to off. Intelligent battery power management prolongs the lifespan of a battery.

Power Lose Redundancy Alarm Enabled

Indicates whether the base station reports ALM-25636 Loss of Power Supply Redundancy. The base station reports ALM-25636 Loss of Power Supply Redundancy if the PSUs are not configured in N+1 backup mode and this parameter is set to ON.

DCU SDR Enhanced Switch

Indicates whether to support the DCU 3900/3910 and inter-BBU co-SDR enhanced networking. When this switch is turned on, DCU 3900/3910 and inter-BBU co-SDR enhanced networking is supported. When this switch is turned off, this networking is not supported.

Hardware Fault Self-healing Switch

Indicates whether to enable the hardware fault self-healing function. When a hardware fault that may affect services or functions is detected, the base station is authorized to perform self-healing actions at different levels to quickly rectify the fault. This helps reduce the fault duration and maintenance workload caused by manual intervention and shortens the fault impact duration. This parameter does not apply to self-healing operations for hardware faults that inevitably affect services or functions. For such hardware faults, the base station directly performs self-healing. When the LEVEL1 option is selected, the base station is allowed to reset the main control board when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL2 option is selected, the base station is allowed to reset the baseband processing board when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL3 option is selected, the base station is allowed to reset the RF unit when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL4 option is selected, the base station is allowed to re-load the application or certain components when detecting a hardware fault that can may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL5 option is selected, the base station is allowed to perform self-healing that requires cooperation of the peer end when detecting a hardware fault that can may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed.

Open DU Interface ID

Indicates the ID of the open DU interface (ODI). If this parameter is set to 0, no ID is configured for the ODI and this base station cannot communicate with other base stations. This parameter applies only to Cloud BB scenarios. In non-Cloud BB scenarios, the parameter should be set to 0.

RF DC Power Off Alarm Enhanced Detect Switch

Indicates whether to enable the enhanced DC power failure detection function for RF modules. When this switch is turned on, the system checks the power supply of RF modules based on the power failure characteristics. If the system detects that the RF modules experience power failure, the system reports ALM-26564 Unit DC Input Power Failure to notify the user to preferentially perform troubleshooting for the power failure. It is recommended that this function be enabled when the power system is unstable, the power supply cannot be directly estimated (for example, dry-contact ports are not configured), and RF modules frequently experience power failure. Since the system checks the power supply of RF modules based on the power failure characteristics, false alarms may be generated. If the percentage of false alarms is high, turn off this switch.

Abnormal Power Supply Thld(0.1V)

Indicates the abnormal power supply threshold in the algorithm for abnormal power supply. When the voltage decreases to a value less than this threshold, the system considers power supply abnormal. NULL is displayed in the output of the LST EQUIPMENT command when the parameter is set to 65535 and the system calculates the threshold based on the onsite running status.

Normal Power Supply Thld(0.1V)

Indicates the normal power supply threshold in the algorithm for abnormal power supply. When the voltage increases to a value greater than this threshold, the system considers power supply normal. NULL is displayed in the output of the LST EQUIPMENT command when the parameter is set to 65535 and the system calculates the threshold based on the onsite running status.

SDR Connection Switch

Indicates the BBU interconnection switch when SDR is enabled for an RF module connecting to two BBUs. If this switch is turned on, the BBUs are interconnected. If this switch is turned off, the BBUs are not interconnected. This switch is turned on when the RF module connects to only one BBU. During the reconstruction of the SDR interconnection mode, set this parameter to ADJUSTING to reduce the impact of the reconstruction on the base station.

Auto CPRI Resource Defragment Switch

Indicates the CPRI resource defragment switch. If this switch is turned on, the system automatically defragments CPRI resources in specific scenarios. CPRI resource defragmentation may temporarily interrupt ongoing services of the system. This parameter does not take effect in eCPRI scenarios.

Enhanced OM Link Setup Switch for Power Failure

Indicates the OMCH setup enhancement switch upon abnormal power supply. If this switch is turned on, OMCH setup is delayed after an abnormal power-off reset which is not caused by manual operations.

Time Controlled by Enhanced OM Link Setup SW(min)

Indicates the time controlled by the OMCH setup enhancement switch. This parameter is valid only if the switch controlling OMCH setup enhancement upon abnormal power supply is turned on. After an NE experiences an abnormal power-off reset which is not caused by manual operations, the OMCH between the NE and the EMS are not set up within the time specified by the value of this parameter.

Equipment Type

Indicates the physical state of the NE.

PSU Fault Shutdown TRX Enabled

Indicates whether the BS enters the energy saving mode when some PSUs become faulty. If this parameter is set to ON, the BS enters the energy saving mode to reduce power consumption when some PSUs become faulty and the remaining PSUs cannot meet the BS's power requirements.

Protocol Type

Indicates the communication protocol used between the BBU and RF units. CPRI indicates the common public radio interface, and TDL_IR indicates the IR communication protocol defined by China Mobile Communication Corporation (CMCC). This parameter must be correctly set according to the network plan. Otherwise, the base station services may be unavailable.

Smart TRX Switch

Indicates whether to enable the smart TRX energy saving function. This function is supported only when an XMU is installed or when a board is installed to monitor primary power supply. If this function is disabled, the base station does not process signals of the smart TRX function provided by the XMU or primary power supply. For a separate-MPT base station, to make this function effective, ensure that this function is enabled for all RATs; to make this function ineffective, ensure that this function is disabled for all RATs.

Shut Down BBU Boards in Load Power Off

Indicates whether BBU boards are shut down when load power-off is performed on a base station. BBU boards include baseband processing boards and UBRI. If BBU boards are shut down, the power consumption is reduced and the power backup duration of storage batteries is prolonged.

RF Abnormal Power Supply Protect Switch

Indicates the power supply protection switch for an RF module. This switch is turned on to protect the RF module against power failures and other exceptions.

Inter Subrack Clock Alignment Mode

Indicates the inter-BBU clock synchronization mode when the SDR interconnection switch is turned off. This parameter is valid only when the SDR interconnection switch is turned off. If this parameter is set to INDEPENDENT_GNSS_CLK, two BBUs use their own GNSS clock sources to ensure clock alignment. This parameter applies to C+L scenarios where CI interconnection is not used. If this parameter is set to PEER_RF_CLK, two BBUs use RFs to transmit clock signals to ensure clock alignment. This parameter applies to U+L, U+N, U+L*N, and U+L&N scenarios where CI interconnection is not used.
