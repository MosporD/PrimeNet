Set Downlink Flow Control Para (SET DLFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the parameters of the downlink flow control algorithm.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]When Min Fair Protection Ratio is set to 100%, UMTS services may occupy all transmission bandwidth. In this case, services of other modes will have a low transmission rate, or even be interrupted.

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

SWITCH Flow Control Switch

Meaning: Indicates the switch for the DL flow control algorithm. If this parameter is set to STATIC_BW_SHAPING, the available HSDPA bandwidth equals the total bandwidth minus the R99 bandwidth. If this parameter is set to DYNAMIC_BW_SHAPING, flow allocation for HSDPA users is performed according to the delay and packet loss of the transmission interface board in STATIC_BW_SHAPING mode. This function requires the network controller using the 3GPP R6 protocol. Therefore, you are advised to use this function with the RNC that complies with the 3GPP R6 protocol. If this parameter is set to NO_BW_SHAPING, the BS does not allocate bandwidth according to the configuration and delay of the transmission interface board. The BS reports the air interface conditions to the controller, and then the controller allocates bandwidth. When this parameter is set to NO_BW_SHAPING, the backpressure function must be enabled on the controller side. If this parameter is set to BW_SHAPING_ONOFF_TOGGLE, the BS automatically selects either DYNAMIC_BW_SHAPING or NO_BW_SHAPING during a flow control congestion detection on a port. That is, DYNAMIC_BW_SHAPING is selected if congestion is detected; NO_BW_SHAPING is selected if congestion is not detected for a certain period of time.

GUI Value Range: STATIC_BW_SHAPING(STATIC_BW_SHAPING), DYNAMIC_BW_SHAPING(DYNAMIC_BW_SHAPING), NO_BW_SHAPING(NO_BW_SHAPING), BW_SHAPING_ONOFF_TOGGLE(BW_SHAPING_ONOFF_TOGGLE)

Unit: None

Actual Value Range: STATIC_BW_SHAPING, DYNAMIC_BW_SHAPING, NO_BW_SHAPING, BW_SHAPING_ONOFF_TOGGLE

MML Default Value: BW_SHAPING_ONOFF_TOGGLE(BW_SHAPING_ONOFF_TOGGLE)

Recommended Value: BW_SHAPING_ONOFF_TOGGLE(BW_SHAPING_ONOFF_TOGGLE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of this parameter affects KPIs. For details, see the meaning of this parameter.

Applicable Mode: G, U

DLFLOWCTRLENHSW Downlink Flow Control Enhancement Switch

Meaning: Indicates the switch for controlling the enhanced downlink flow control feature. When the switch is set to on, the enhanced downlink flow control prevents downlink available bandwidth from sharply decreasing and downlink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

The enhanced downlink flow control feature requires the downlink FPDT GPM detection results. Before using this feature, run the ADD GPM or MOD GPM command to enable the downlink FPDT GPM detection function for the NodeB.

This switch can be configured only when flow control is set to dynamic flow control or self-selection flow control. This configuration takes effect only in IP transmission, but cannot take effect in ATM transmission even though the configuration succeeds.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the cell supports the enhanced HSDPA traffic control. This feature improves the downlink throughput of the cell when packet loss occurs due to bit errors in the transport network.

When this parameter is set to OFF, the network is not affected.

Applicable Mode: G, U
BWPRTSWITCH BW Adjust Protection Switch

Meaning: Indicates the adjustment protection switch for the available DL bandwidth. When this parameter is set to ON, the BS stops adjusting the available DL bandwidth of the physical port if bit error occurs on the transmission line and the bit error rate (BER) exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(On)

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
FAIRSWITCH Fair Switch

Meaning: Indicates the switch for the downlink fairness flow control. If multiple modes share transmission bandwidth and congestion occurs, the UMTS data rate may decrease due to downlink flow control and the LTE data rate may increase due to bandwidth preemption when the Flow Control Switch parameter is set to DYNAMIC_BW_SHAPING or is set to BW_SHAPING_ONOFF_TOGGLE but actually takes effect using the DYNAMIC_BW_SHAPING value. When this switch is turned on, the system guarantees the minimum downlink transmission bandwidth of the UMTS mode. This switch applies only to Ethernet ports, Ethernet trunks, and loop interfaces with Port Type set to ETH or ETHTRK.

Unit: kbit/s

DLIUBBWMINPRORATIO Min Protection Ratio of IUB Port DL Bandwidth

Meaning: Indicates the minimum ratio of reducing the available downlink bandwidth over the Iub interface.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: 50

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the available physical port bandwidth on the transmission network is small and the transmission network is congested, the larger the value of this parameter, the less the downlink bandwidth over the Iub interface is reduced. Insufficient bandwidth reduction will cause packet loss, affecting the bandwidth usage. When the available physical port bandwidth on the transmission network is large, and bit error, packet loss, or other exceptions occur on the transmission network, the smaller the value of this parameter, the more the downlink bandwidth over the Iub interface is reduced. Incorrect bandwidth reduction will severely affect the system capacity.

Applicable Mode: G, U

Example

To set a configuration of the downlink flow control algorithm with the parameters as follows: Slot No.: 7, Subboard Type: BASE_BOARD, Bear Type: IP, Port Type: ETH, Flow Control Switch: BW_SHAPING_ONOFF_TOGGLE, Min DL Avail Bandwidth of Logical Port: 600, Min Protection Ratio of IUB Port DL Bandwidth(%): 50, run the following command:
SET DLFLOWCTRLPARA: SN=7, SBT=BASE_BOARD, BEAR=IP, PT=ETH, SWITCH=BW_SHAPING_ONOFF_TOGGLE, DLIUBMINBW=600, DLIUBBWMINPRORATIO=50;
