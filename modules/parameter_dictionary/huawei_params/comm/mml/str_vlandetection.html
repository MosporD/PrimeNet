Start VLAN Detection (STR VLANDETECTION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start VLAN detection, which is used to check whether the peer transmission device connected to the base station uses the same VLAN ID for transmission and reception. This command is used only when the base station uses VLANMAP configuration mode. After this command is executed, the base station sends ARP packets to the next hop of the route and the peer IP addresses of the following types of packets in layer 2 networking: IKEPEER, OMCH, IPPATH, USERPLANEPEER, IPCLK, IPPMSESSION, TWAMP, BFDSSESION, BFD, DNSSRV, CA, DHCPSVRIP, FTP, NTP, and PTP. The base station checks whether the VLAN ID of the received ARP response packet is consistent with the VLAN ID of the sent ARP packet.

Note

  • If VLANCLASS is used to configure a VLAN, TRAFFIC must be set to OTHER because ARP request packets are other data packets. Otherwise, the detection result may be incorrect.

  • [Co-MPT]This command is not supported when the GTMU supports SingleOM.

Parameters

None.

Example

To start VLAN detection, run the following command:
STR VLANDETECTION:;
The result is shown as follows: 
+++    BBU1        2018-09-14 22:03:05
O&M    #805306424
%%STR VLANDETECTION:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Next-Hop IPv4 Address

Indicates the next-hop IP address for VLAN mapping.

Transmit VLAN ID

Indicates the VLAN ID carried in the transmit direction of the base station.

Receive VLAN ID

Indicates the VLAN ID carried in the receive direction of the base station.

TX and RX VLAN ID Consistency Flag

Indicates whether the VLAN ID carried in the transmit direction is the same as that in the receive direction for the base station.

NE Name

Indicates the name of the base station.

VLAN Reconstruction Switch

Indicates whether the VLANMAP configuration mode can be reconstructed to the VLAN subinterface configuration mode by using the reconstruction tool.
