Set Log Management Policy (SET LOGPOLICY)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set a log management policy to determine whether operation logs and security logs are encrypted for storage.

Note

  • ENCRYPTSTORESW is ON by default. The log encryption and decryption function takes effect only when the main control board is UMPT or UMDU.

  • During log encryption and decryption, if you run the LST OPTLOG or LST SECLOG command, the system displays a message indicating that the system is busy. In this case, try again later.

  • Modifying the ENCRYPTSTORESW parameter will trigger the encryption or decryption of operation logs and security logs. If you upload these logs immediately after the preceding operations, the logs may fail to be uploaded due to encryption or decryption. In this case, try again later.

  • In a base station where the GTMU supports SingleOM, this command cannot be executed.

Parameters

ID Name Description
ENCRYPTSTORESW Local Log Encryption Switch

Meaning: Indicates whether to encrypt the operation logs and security logs stored on a base station.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To turn off the local log encryption switch, run the following command:
SET LOGPOLICY: ENCRYPTSTORESW=OFF;
