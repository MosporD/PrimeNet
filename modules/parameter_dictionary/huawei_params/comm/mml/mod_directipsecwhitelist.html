Modify Whitelist for Direct IPsec Tunnel (MOD DIRECTIPSECWHITELIST)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a direct IPsec whitelist.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eNodeB,gNodeB]After a direct IPsec whitelist is modified, the direct IPsec tunnels that meet both of the following conditions are disconnected: the direct IPsec tunnels are not in the direct IPsec whitelist; Control Mode in the corresponding SCTPPEER or USERPLANEPEER object is set to AUTO_MODE.

Parameters

ID Name Description
DIRECTIPSECWHITELISTID ID of Whitelist for Direct IPsec Tunnel

Meaning: Indicates the ID of a direct IPsec whitelist.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
IPVERSION IP Version

Meaning: Indicates the IP version of a direct IPsec whitelist.

GUI Value Range: IPV4(IPv4), IPV6(IPv6)

Unit: None

Actual Value Range: IPV4, IPV6

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECWHITELIST MO is set to IPv6, IPV6PFXLEN in the DIRECTIPSECWHITELIST MO must be between 1 to 128.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
SECURITYPEERIPV4 Security Peer IPv4 Address

Meaning: Indicates the security peer IP address of a direct IPsec whitelist. This address must be a valid IP address of class A, B, or C. It can also be a network segment address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]SECURITYPEERIPV4 in the DIRECTIPSECWHITELIST MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
MASK Mask

Meaning: Indicates the subnet mask of the security peer IP address of a direct IPsec whitelist. The subnet mask cannot be 0.0.0.0.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In the binary value into which MASK in a DIRECTIPSECWHITELIST MO is converted, 0 cannot precede 1. In addition, MASK can be 255.255.255.255, but cannot be 0.0.0.0.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
SECURITYPEERIPV6 Security Peer IPv6 Address

Meaning: Indicates the security peer IPv6 address of a direct IPsec whitelist. This IPv6 address must be set to a globally scoped unicast address. It can also be a network segment address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]SECURITYPEERIPV6 in a DIRECTIPSECWHITELIST MO must be set to a globally scoped unicast address.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
IPV6PFXLEN IPv6 Address Prefix Length

Meaning: Indicates the security peer IPv6 address prefix length of a direct IPsec whitelist.

GUI Value Range: 1~128

Unit: None

Actual Value Range: 1~128

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a DIRECTIPSECWHITELIST MO is set to IPv6, IPV6PFXLEN in the DIRECTIPSECWHITELIST MO must be between 1 to 128.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify the configurations of the whitelist for direct IPSec tunnels with the parameters as follows: ID of Whitelist for Direct IPsec Tunnel: 0, IP Version: IPv4, Security Peer IPv4 Address: 192.168.10.10, Mask: 255.255.255.0, run the following command:
MOD DIRECTIPSECWHITELIST: DIRECTIPSECWHITELISTID=0, IPVERSION=IPv4, SECURITYPEERIPV4="192.168.10.10", MASK="255.255.255.0";
