Add DFU Management Link (ADD DFUMLCLIENT)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a DFU management link client.

Note

None.

Parameters

ID Name Description
CLIENTID Client ID

Meaning: Indicates the ID of a DFU management link client.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
IPVERSION IP Version

Meaning: Indicates the IP protocol version of a DFU management link client.

GUI Value Range: IPv4(IPv4)

Unit: None

Actual Value Range: IPv4

MML Default Value: IPv4(IPv4)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
CLIENTIPV4 Client IPv4 Address

Meaning: Indicates the IPv4 address of a DFU management link client.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
UID Unit ID

Meaning: Indicates the ID of a DFU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Applicable Mode: L, N
USERLABEL User Label

Meaning: Indicates the user-defined information about a DFU management link client.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255

Example

To add a DFU management link client with the parameters as follows: Client ID: 1, VRF Index: 2, IP Version: IPv4, Client IPv4 Address: 192.168.1.1, Unit ID: 1, User Label: sdfs, run the following command:
ADD DFUMLCLIENT: CLIENTID=1, VRFIDX=2, IPVERSION=IPv4, CLIENTIPV4="192.168.1.1", UID=1, USERLABEL="sdfs";
