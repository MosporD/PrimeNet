Modify DFU (MOD DFU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify DFU configurations.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Currently, this command can be used only to modify the DFU name and network ID.

  • Modifying the network ID will lead to re-establishment of the DFU maintenance link.

Parameters

ID Name Description
UID Unit ID

Meaning: Indicates the ID of a DFU.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
NETWORKID NetWork ID

Meaning: Indicates the network ID of a DFU. The network ID is unique for each application type on the entire network.

GUI Value Range: 0~68719476735

Unit: None

Actual Value Range: 0~68719476735

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If the APPTYPE parameters in different DFU MOs are set to the same value, the NETWORKID parameters in these DFU MOs must be set to different values.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
UNITNAME Unit Name

Meaning: Indicates the name of a DFU.

GUI Value Range: 1~31 characters

Unit: None

Actual Value Range: 1~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify the configuration of a DFU with the parameters as follows: Unit ID: 2, NetWork ID: 17, Unit Name: eNodeb_B, run the following command:
MOD DFU: UID=2, NETWORKID=17, UNITNAME="eNodeb_B";
