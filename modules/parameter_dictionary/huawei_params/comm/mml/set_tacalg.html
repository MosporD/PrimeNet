Set Admission Control Algorithm (SET TACALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the parameters of the admission control algorithm.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eGBTS,eNodeB]This command takes effect only for LTE.

Parameters

ID Name Description
RSCGRPULCACSWITCH Resource Group Uplink Admission Control Algorithm Switch

Meaning: Indicates whether to apply UL admission control to a resource group.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, handover services or new services are admitted according to the UL transport resources. Therefore, excessive admitted services can be avoided and the QoS of ongoing services can be ensured.

If this parameter is set to OFF, handover services or new services are not admitted according to the UL transport resources. Therefore, the QoS of ongoing services cannot be ensured if excessive services are admitted.

Applicable Mode: G, L

TRMULHOCACTH Uplink Handover Service Admission Threshold

Meaning: Indicates the UL admission threshold for handover services. A large value of this parameter will result in a high UL admission success rate of handed-over services.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 90

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eGBTS, eNodeB]In a TACALG MO, TRMULHOCACTH must be greater than or equal to TRMULGOLDCACTH.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: A larger value indicates a higher admission success rate of handover services but a higher probability of overloaded transport due to the actual traffic fluctuation of real-time services.

A smaller value indicates a lower admission success rate of handover services but a lower probability of overloaded transport due to the traffic fluctuation of real-time services.

TRMULPRESW Uplink Pre-emption Algorithm Switch

Meaning: Indicates whether to enable the UL pre-emption algorithm. If this parameter is set to ON, the UL pre-emption algorithm is enabled. In this case, the service with a higher priority that requests for admission may pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient. If this parameter is set to OFF, the UL pre-emption algorithm is disabled. In this case, the service with a higher priority that requests for admission cannot pre-empt the resources of admitted services with lower priorities when UL transmission bandwidth is insufficient.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the UL transport bandwidth is insufficient and this parameter is set to ON, the admission success rate of high-priority services may rise, but the call drop rate of low-priority services may also increase.

If the UL transport bandwidth is insufficient and this parameter is set to OFF, the call drop rate of low-priority services is not affected, but the admission success rate of high-priority services is not guaranteed.

Applicable Mode: G, L

If this parameter is set to OFF, the UL pre-emption algorithm is disabled. If this parameter is set to OFF when the DL transport bandwidth is insufficient, the admission success rate of high-priority services might not increase. The service drop rate of low-priority services, however, is not affected.

Applicable Mode: G, L
PORTULOBSW Physical Port Up Link OverBooking Switch

Meaning: Indicates whether to enable UL overbooking admission control. It is used to determine the admission bandwidth of the resource group and facilitate admission control.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, total uplink admission bandwidth of all logical ports carried on a physical port is allowed to be greater than the uplink bandwidth of the physical port. In this case, however, there is a risk of excessive admitted services if PORTULCACSW is set to ON.

If this parameter is set to OFF, total uplink admission bandwidth of all logical ports carried on a physical port is not allowed to be greater than the uplink bandwidth of the physical port. In this case, there is no risk of excessive admitted services regardless of whether PORTULCACSW is set to ON.

Applicable Mode: G, L

EMCTACPSW Emergency Call Preferential Admission Switch

Meaning: Indicates whether to preferentially admit emergency calls. When this parameter is set to ON, transmission admission control is not performed for emergency calls and emergency calls will be successfully admitted. When this parameter is set to OFF and the transmission admission algorithm switch is turned on, transmission admission control is performed for emergency calls. When this switch is set to OFF and the transmission admission algorithm switch is turned off, transmission admission control is not performed for emergency calls.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the transmission admission algorithm switch is turned on and this parameter is set to ON, the access success rate of emergency calls increases in limited bandwidth but the quality of accessed services will be affected. When the transmission admission algorithm switch is turned on and this parameter is set to OFF, the access success rate of emergency calls decreases in limited bandwidth and the quality of accessed services will not be affected.

When the transmission admission algorithm parameter is turned off, this parameter does not affect network performance.

Applicable Mode: L

Example

To set the admission control algorithm with the parameters as follows: Resource Group Uplink Admission Control Algorithm Switch: ON, Resource Group Downlink Admission Control Algorithm Switch: ON, run the following command:
SET TACALG: RSCGRPULCACSWITCH=ON, RSCGRPDLCACSWITCH=ON;
