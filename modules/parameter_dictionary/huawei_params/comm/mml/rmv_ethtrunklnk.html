Remove Ethernet Trunk Member (RMV ETHTRUNKLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a member port from an Ethernet trunk.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • You must remove the secondary port before the primary port when removing a member port from an Ethernet trunk.

  • This operation may interrupt the services or OM channels carried on this port. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
ETHTRKPORTID Ethernet Trunk Port ID

Meaning: Indicates the ID of the Ethernet trunk to which an Ethernet trunk member port belongs.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ETHTRUNKLNKID Ethernet Trunk Link ID

Meaning: Indicates the ID of an Ethernet trunk member port. This parameter value must be unique at the system level.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove a member port from an Ethernet trunk with the parameters as follows: Ethernet Trunk Port ID: 2, Ethernet Trunk Link ID: 0, run the following command: 
RMV ETHTRUNKLNK: ETHTRKPORTID=2, ETHTRUNKLNKID=0;
