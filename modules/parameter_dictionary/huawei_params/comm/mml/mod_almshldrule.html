Modify Alarm Shielding Rule (MOD ALMSHLDRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify an alarm shielding rule.

Note

  • You can run the LST ALMSHLDRULE command to query the configured alarm shielding rules.

  • After an alarm shielding rule is modified, the NE will operate as follows: If the alarm is generated and the alarm shielding rule is met, the NE will shield the alarm from the active alarm list and the alarm log shows that the alarm is manually cleared. If the alarm is generated and the remaining alarm shielding rules are not met, the NE regards the time when the alarm is unshielded as the time when the alarm is generated, and the NE will report the alarm again. In this case, the alarm can be displayed in the active alarm list and the alarm log shows that the alarm is not cleared. If the alarm is not generated, no operation is required. If this alarm is generated again and the alarm shielding rule is met, the alarm will be shielded and not displayed on the alarm console.

  • The NE will attempt to match the alarm with the alarm shielding rule in both Chinese and English formats. If they are matched in either of the formats, the alarm will be shielded.

  • Some alarms cannot be shielded by running this command (such as ALM-26817 License on Trial), and "This alarm cannot be shielded" will be displayed.

PARA1NAME Name of Parameter 1

Meaning: Indicates the name of the first matching parameter. It can be the name of any parameter in alarm location information. The name must be complete. Otherwise, the alarm cannot be shielded.

GUI Value Range: 0~55 characters

Unit: None

Actual Value Range: 0~55

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ALMSHLDRULE MO must meet the following condition 1: There is at least one of the following five parameter combinations whose parameter values are both specified: combination 1 (PARA1NAME, PARA1VALUE), combination 2 (PARA2NAME, PARA2VALUE), combination 3 (PARA3NAME, PARA3VALUE), combination 4 (PARA4NAME, PARA4VALUE), and combination 5 (PARA5NAME, PARA5VALUE).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The ALMSHLDRULE MO must meet the following condition 2: If one of the parameter values in a parameter combination is specified, the other parameter value must be specified. The parameter combinations include the following: combination 1 (PARA1NAME, PARA1VALUE), combination 2 (PARA2NAME, PARA2VALUE), combination 3 (PARA3NAME, PARA3VALUE), combination 4 (PARA4NAME, PARA4VALUE), and combination 5 (PARA5NAME, PARA5VALUE).
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the values of the PARA1NAME, PARA2NAME, PARA3NAME, PARA4NAME, and PARA5NAME parameters in the ALMSHLDRULE MO are all specified, these parameters cannot be set to the same value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Example

To modify the alarm shielding rule with the parameters as follows: Index: 0, Alarm ID: 25901, Name of Parameter 3: Slot No., Value of Parameter 3: 2, run the following command:
MOD ALMSHLDRULE: INDEX=0, AID=25901, PARA3NAME="Slot No.", PARA3VALUE="2";
