Set Manually Cleared Alarm Reporting Switch (SET MANRESALMRPT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Used to set the switch for reporting manually cleared alarms again. When this switch is turned on, the manually cleared alarms that persist ten minutes after the clearance will be reported again. When the switch is turned off, the manually cleared alarms will not be reported again.

Note

  • [Co-MPT,eNodeB]This command takes effect only for the following alarms: ALM-26121 GPS Antenna Fault, ALM-26235 RF Unit Maintenance Link Failure, ALM-29248 RF Out of Service, ALM-29240 Cell Unavailable, ALM-29243 Cell Capability Degraded, ALM-29249 eNodeB Out of Service, ALM-26532 RF Unit Hardware Fault, ALM-25621 Power Supply DC Output Out of Range, ALM-26200 Board Hardware Fault, ALM-26250 Active Workspace Version Unavailable, ALM-26270 Inter-System Communication Failure, ALM-26272 Inter-System RF Unit Parameter Settings Conflict, ALM-26274 Inter-System Board Object Configuration Conflict, ALM-26279 Inter-System Board Installation and Configuration Mismatch, ALM-26912 Inter-System CXU Parameter Settings Conflict.

  • [NodeB,eGBTS]This command takes effect only for the following alarms: ALM-26121 GPS Antenna Fault, ALM-26235 RF Unit Maintenance Link Failure, ALM-26532 RF Unit Hardware Fault, ALM-25621 Power Supply DC Output Out of Range, ALM-26200 Board Hardware Fault, ALM-26250 Active Workspace Version Unavailable, ALM-26270 Inter-System Communication Failure, ALM-26272 Inter-System RF Unit Parameter Settings Conflict, ALM-26274 Inter-System Board Object Configuration Conflict, ALM-26279 Inter-System Board Installation and Configuration Mismatch, ALM-26912 Inter-System CXU Parameter Settings Conflict.

  • [gNodeB]This command takes effect only for the following alarms: ALM-26121 GPS Antenna Fault, ALM-26235 RF Unit Maintenance Link Failure, ALM-29248 RF Out of Service, ALM-25621 Power Supply DC Output Out of Range, ALM-26200 Board Hardware Fault, ALM-26250 Active Workspace Version Unavailable, ALM-26270 Inter-System Communication Failure, ALM-26272 Inter-System RF Unit Parameter Settings Conflict, ALM-26274 Inter-System Board Object Configuration Conflict, ALM-26279 Inter-System Board Installation and Configuration Mismatch.

Parameters

ID Name Description
SWITCH Switch

Meaning: Indicates the switch for reporting manually cleared alarms again.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Setting Manually Cleared Alarm Reporting Switch to ON,  run the following command:
SET MANRESALMRPT: SWITCH = ON;
