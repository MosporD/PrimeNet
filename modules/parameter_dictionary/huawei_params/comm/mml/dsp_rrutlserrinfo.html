Display RRU TLS Information (DSP RRUTLSERRINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command on BBUs to query the TLS information of RRUs. In the query result, a maximum of three latest records (including historical data) can be displayed for an RRU.

Note

The query of the TLS information is supported only for RRUs that comply with eCPRI protocols.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where a board is located.

Unit: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where a board is located.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where a board is located.

GUI Value Range: 0~5

Unit: None

Impact on Radio Network Performance: None

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.

TLS Connection State

Indicates the TLS connection state.

TLS Version

Indicates the TLS version supported by the NE.TLS(Transport Layer Security).

TLS Protocol

Indicates the name of the TLS cipher suite in use.

TLS Authentication Mode

Indicates the authentication mode of the TLS connection.

Error Code

Indicates the error code for the TLS connection authentication failure.

Error Description

Indicates the description of the TLS connection authentication failure.

Certificate Verify Result

Indicates the error code for a certificate authentication failure when a TLS connection uses certificates for authentication.

Certificate Verify Result Description

Indicates the description for a certificate authentication failure of a TLS connection when a TLS connection uses certificates for authentication.

Occurrence Time

Indicates the time when the TLS connection authentication succeeds or fails.
