Scan ALD (SCN ALD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to scan for the antenna line devices (ALDs) connected to the RRU or RFU. This command can also be used to check the serial number of the device. The scanning result contains the information about all ALDs that are physically connected to the BS, regardless of whether the ALDs are configured.

Note

  • Before the scanning, the power switch of the control port must be set to ON for the ALD connected to the control port. Otherwise, no ALD can be found. For details about how to query the status of the ALD power switch, see the DSP ANTENNAPORT and DSP RETPORT commands. For details about how to modify the status of the ALD power switch, see the MOD ANTENNAPORT and MOD RETPORT commands.

  • When this command is executed to scan a whole BS, all RRUs or RFUs are scanned at the same time. If a TMA is connected to multiple RRUs or RFUs, the TMA and its cascading RET devices may not be found or the scanning times out. In this case, run this command on a single RRU or RFU.

  • In RF interconnection mode, if only one RF module is configured with the ALD, scanning the RF module not configured with the ALD will time out.

  • The execution of this command takes a maximum of 20 minutes. The time depends on the RRU or RFU type and the number of ALDs connected to the base station. During ALD scanning, other operations related to the ALD cannot be performed. Therefore, run this command only when required.

  • If there are any invisible characters in the serial number, the serial number will be converted into visible ASCII codes and added with the prefix preamble @@.

  • If an ALD that has been configured on an RRU cannot be found, run the RST ALDPWRSW command and then run the SCN ALD command immediately.

  • The vendor code is case sensitive, and it must be used based on the scanning result.

  • [Co-MPT,NodeB,eGBTS]If an SASU is cascaded with a TMA, the TMA can be detected through scanning only when the SASU runs properly and the DC power supply switch for the antenna port is turned on.

Parameters

ID Name Description
CTRLCN Control Port Cabinet No.

Meaning: Indicates the cabinet number of the RRU or RFU that controls the ALD.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CTRLSRN Control Port Subrack No.

Meaning: Indicates the subrack number of the RRU or RFU that controls the ALD.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLCN in the ALD MO ranges from 0 to 15, the value of CTRLSRN can be 4, 5, or a number ranging from 60 to 254. When the value of CTRLCN in the ALD MO ranges from 16 to 62, CTRLSRN must be set to 4 or 5.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CTRLSN Control Port Slot No.

Meaning: Indicates the slot number of the RRU or RFU that controls the ALD.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CTRLSRN in the ALD MO is set to 4 or 5, the value of CTRLSN ranges from 0 to 8 if TYPE in the CABINET MO where the ALD MO is located is set to BTS3900AL. The value of CTRLSN ranges from 0 to 5 if TYPE is not set to BTS3900AL. When the value of CTRLSRN in the ALD MO is set to 60, CTRLSN ranges from 0 to 5. When the value of CTRLSRN in the ALD MO ranges from 61 to 254, CTRLSN is set to 0.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Output Description

Field Description

Control Port Cabinet No.

Indicates the cabinet number of the RRU or RFU that controls the ALD.

Control Port Subrack No.

Indicates the subrack number of the RRU or RFU that controls the ALD.

Control Port Slot No.

Indicates the slot number of the RRU or RFU that controls the ALD.

Control Port No.

Indicates the number of the port through which the ALD is controlled.

Result

Indicates the returned result value after the maintenance command is executed.

ALD Device Type

Indicates the device type of the ALD, which can be SINGLE_RET, STMA, SASU, MULTI_RET, RAE, RVD or RAS.

Vendor Code

Indicates the vendor code. It contains 2 characters.

Serial No.

Indicates the serial number of the ALD. Its maximum length is 36 characters.

Protocol Version

Indicates the protocol version supported by the ALD. The protocol versions include AISG1.1, AISG2.0, 3GPP, and NULL. NULL indicates an unknown protocol version.

Configure Status

Indicates the configuration status of the ALD.

Number of Subunits

Indicates the number of ALD subunits.

Failure Cause

Indicates the cause of the scanning failure.
