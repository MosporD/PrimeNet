Add User Plane Host (ADD USERPLANEHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a user-plane host.

Note

  • When security automatic establishment is enabled on a user plane host, the IPSec Auto Configure Switch is enabled for the user plane host and a security host is referenced. Therefore, before enabling this feature, ensure that the security host to be referenced has been added by using the ADD SECURITYHOST command.

  • The local IP addresses or local IPv6 addresses configured in this MO must be mutually reachable with the IP addresses of base station controllers or core network equipment. If some IP addresses are unreachable, services setup will fail on the corresponding equipment.

  • If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the IPv4 user-plane link:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the IPv4 user-plane link:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch is set to DISABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • User plane automatic setup does not support the internal user plane path with the type of FIXED.

  • When the user plane is set up automatically, the base station automatically sets up an internal user plane path with the type of ANY.

  • The scenario that meets the following conditions is not supported: the local IP address of the user plane host is configured as the IP address of the main control board; the transmission extension board provides the transmission port.

  • System specifications: If the LMPT/UMPT/GTMUb/GTMUc/UMDU is the main control board, a maximum of 32 user plane hosts can be configured. If the WMPT is the main control board, a maximum of 4 user plane hosts can be configured.

  • Board specifications: A maximum of 32 user plane hosts can be configured on an LMPT/UMPT/GTMUb/GTMUc/UTRPc/UTRP (subboard type: UEOC/UIEC/UQEC/UAEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UMDU/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 4 user plane hosts can be configured on a WMPT.

  • The user plane host cannot reference the DEVIP or IPADDR4 MO whose Port Type is ETHCI.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The local IP address of the user plane host cannot be the IP address acquired by PPP or MP negotiation.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Services may be interrupted when the following conditions are met: (1) The UP local IP address or local IPv6 address is of loopback type. (2) An internal UP link has been established. (3) The outgoing port changes because the route is modified.

  • [Co-MPT,eNodeB,gNodeB]The scenario that meets the following conditions is not supported: the local IPv6 address of the user plane host is configured as the IPv6 address of the main control board; the transmission extension board provides the transmission port.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met during setup of an IPv6 user-plane link, the system will automatically configure the TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects and set up an IPsec tunnel for the IPv6 user-plane link:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • [Co-MPT,eNodeB]Local IP Address or local IPv6 address in a USERPLANEHOST object must have been configured using the ADD DEVIP, ADD IPADDR4, ADD IPADDR6, ADD PPPLNK, or ADD MPGRP command.

  • [NodeB,eGBTS]Local IP Address in a USERPLANEHOST object must have been configured using the ADD DEVIP, ADD IPADDR4, ADD PPPLNK, or ADD MPGRP command.

  • [gNodeB]Local IP Address or local IPv6 address in a USERPLANEHOST object must have been configured using the ADD DEVIP, ADD IPADDR4, ADD IPADDR6 command.

IPSECSWITCH IPSec Auto Configure Switch

Meaning: Indicates whether to enable automatic user-plane IPsec tunnel setup based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. If this parameter is set to ENABLE, an IPsec tunnel is automatically set up to encrypt transmitted data. If this parameter is set to DISABLE, no IPsec tunnel is automatically set up. If the value of this parameter is changed from ENABLE to DISABLE using the MOD USERPLANEHOST command, the system deletes the automatically set up IPsec tunnel.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Recommended Value: None

Example

To add a user-plane host with the parameters as follows: User Plane Host ID: 0, IP Version: IPv4, Local IP Address: 192.168.1.1, IPSec Auto Configure Switch: DISABLE, run the following command:
ADD USERPLANEHOST: UPHOSTID=0, IPVERSION=IPv4, LOCIPV4="192.168.1.1", IPSECSWITCH=DISABLE;
