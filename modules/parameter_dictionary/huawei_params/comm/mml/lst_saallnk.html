List SAAL Link Configuration (LST SAALLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the SAAL link configuration.

Note

None.

Parameters

None.

Example

To list the SAAL link configuration, run the following command:
LST SAALLNK:;

Output Description

Field Description

Link No.

Indicates the number of the SAAL link.

Cabinet No.

Indicates the cabinet number of the SAAL link.

Subrack No.

Indicates the subrack number of the SAAL link.

Slot No.

Indicates the slot number of the SAAL link.

Subboard Type

Indicates the type of subboard where an SAAL link is established.

Bearer Port Type

Indicates the port type of the SAAL link.

Bearer Port No.

Indicates the number of the port that carries the SAAL link.

Join Transmission Resource Group

Indicates whether the SAAL link joins a transmission resource group.

Transmission Resource Group ID

Indicates the number of the transmission resource group to which the SAAL link is added.

VPI

Indicates the Virtual Path Identifier (VPI), which is used for VP routing. A virtual path contains multiple virtual channels.

VCI

Indicates the Virtual Channel Identifier (VCI), which is used for VC routing.

Bearer Service Type

Indicates the type of the service carried by the SAAL link. In flow control, services are classified into five categories: the Constant Bit Rate (CBR) service, Real-Time Variable Bit Rate (RTVBR) service, Non-Real-Time Variable Bit Rate (NRTVBR) service, Unspecified Bit Rate Plus (UBR+) service, and Unspecified Bit Rate (UBR) service.

If this parameter is set to CBR, the bandwidth is calculated based on the PCR.

If this parameter is set to VBR, the bandwidth is calculated based on the SCR.

If this parameter is set to UBR, the bandwidth is calculated based on the PCR.

If this parameter is set to UBR+, the bandwidth is calculated based on the MCR.

Rate Unit

Indicates the unit of the Peak Cell Rate (PCR), Minimum Cell Rate (MCR), and Sustainable Cell Rate (SCR). Rate units are converted according to the following principle: 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted into 30 kbit/s.

Peak Cell Rate

Indicates the Peak Cell Rate (PCR) of the SAAL link. The PCR is an ATM service-related parameter defined by the ATM forum for ATM communication management. In CBR transmission, the PCR value determines the frequency at which sampled data is transmitted. In ABR transmission, the PCR value determines the maximum value of Allowed Cell Rate (ACR).

Min Cell Rate

Indicates the Minimum Cell Rate (MCR) of the SAAL link. The MCR is the minimum cell transmission rate acceptable by the user.

Sustain Cell Rate

Indicates the Sustainable Cell Rate (SCR) of the SAAL link. The SCR value determines the average rate at which cells are transmitted over a Variable Bit Rate (VBR) connection.

Timer_CC(ms)

Indicates the length of the SSCOP timer Timer_Cc. This timer specifies the time interval between transmissions of an SAAL PDU during link establishment or connection release. An SAAL PDU is retransmitted if no ACK to the PDU is received.

Timer_Poll(ms)

Indicates the length of the SSCOP timer Timer_Poll. If this timer expires, the SAAL protocol stack must send a POLL PDU to the peer end. The POLL PDU is used to query the status information about the peer end through an SSCOP connection.

Timer_Idle(ms)

Indicates the duration of the SSCOP timer Timer_Idle based on the SAAL protocol. This timer is used to guarantee the duration during which the SAAL protocol is in IDLE mode.

Timer_No_Response(ms)

Indicates the length of the SSCOP timer Timer_No_Response. This timer specifies the maximum time interval for receiving STAT PDUs.

Timer_Keep_Alive(ms)

Indicates the length of the SSCOP timer Timer_Keep_Alive. This timer is used to guarantee the inactivity duration for the SAAL link.

Max Connection Control Count

Indicates the maximum number of SAAL PDUs that are sent during SAAL link establishment or release.

Max Poll Data Count

Indicates the maximum number of data transmissions during a polling period of the SAAL protocol.

Max STAT Count

Indicates the maximum number of elements in an STAT PDU. This parameter must be set to an odd number within the range of 3 to 65535. STAT PDUs are used to respond to POLL PDUs.
