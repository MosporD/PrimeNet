List Sector Configuration (LST SECTOR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list configuration of a sector or all sectors.

Note

If Sector ID is not specified, the basic information about all sectors is displayed. The basic information does not include information about the sector antennas. If Sector ID is specified, information about the sector, sector antennas, and sector equipment IDs is displayed.

Parameters

ID Name Description
SECTORID Sector ID

Meaning: Indicates the number of the sector.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Output Description

Field Description

Sector ID

Indicates the number of the sector.

Sector Name

Indicates the name of the sector.

Location Name

Indicates the location name of the base station. Generally, the LocationName parameter is set to the same value for all sectors in an RF site, and base station can acquire the location information of RF modules through this parameter. However, if the LocationName parameter of the RF module is set in the RRU or AAS MO, the base station will acquire the location information of RF modules through the RRU or AAS MO.

User Label

Indicates the user-defined information of a sector. The value of this parameter consists of xx::yy and common character strings, which are separated by percentage signs (%), for example, %tel::88888888%owner::huawei%20130101. xx::yy indicates that the value of xx is yy.

Antenna Azimuth(0.1degree)

Indicates the azimuth of the sector antenna main lobe, which is an angle rotating clockwise from the due north to the direction of the sector antenna main lobe. For example, this parameter is set to 0 for the due north and to 900 for the due east (the unit is 0.1 degrees). This parameter is only for directional antennas. The value 65535 indicates that this parameter is invalid.

Cabinet No.

Indicates the cabinet number of the RRU to which a sector antenna is connected.

Subrack No.

Indicates the subrack number of the RRU to which a sector antenna is connected.

Slot No.

Indicates the slot number of the RRU to which a sector antenna is connected.

Antenna Channel No.

Indicates the channel number of a sector antenna on an RRU.

Sector Equipment ID

Indicates the number of the sector equipment.
