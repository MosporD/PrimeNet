List SASU Subunit Configuration (LST SASUSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configuration of one or all same-band antenna sharing unit (SASU) subunits.

Note

  • [Co-MPT,NodeB,eGBTS]When the cabinet number of an SASU subunit is 255, the connection between the SASU subunit and the RRU or RFU is not configured. In this case, the subrack number and slot number of this SASU subunit are set to 255.

  • [Co-MPT,NodeB,eGBTS]This command applies only to UMTS.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the SASU.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U
SUBUNITNO Subunit No.

Meaning: Indicates the number of the subunit, which starts from 1.

GUI Value Range: 1~2

Unit: None

Actual Value Range: 1~2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To list the configuration of the SASU subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
LST SASUSUBUNIT: DEVICENO=0, SUBUNITNO=1;
The result is shown as follows:

Output Description

Field Description

Device No.

Indicates the device number of the SASU.

Subunit No.

Indicates the number of the subunit, which starts from 1.

Connect Port Cabinet No.

Indicates the cabinet number of the RRU or RFU to which the SASU subunit is connected.

Connect Port Subrack No.

Indicates the subrack number of the RRU or RFU to which the SASU subunit is connected.

Connect Port Slot No.

Indicates the slot number of the RRU or RFU to which the SASU subunit is connected.

Connect Port No.

Indicates the number of the antenna port to which the SASU subunit is connected.

Work Mode

Indicates the working mode of an SASU. If this parameter is set to DEVICE_DEFAULT_VALUE, it is invalid and the actual mode is not changed.

GSM Gain(dB)

Indicates the gain on the GSM channel. Uplink signals (indicated by amplification multiples) can be amplified by the SASU, and the gain of the uplink signals is configurable. If this parameter is set to 65535, it is invalid and the actual gain is not changed.

UMTS Gain(dB)

Indicates the gain on the UMTS channel. Uplink signals can be amplified by the SASU, and the gain of the uplink signals is configurable. If this parameter is set to 65535, it is invalid and the actual gain is not changed.

DC Load(20mA)

Indicates the DC-powered load of the SASU subunit. If this parameter is set to 65535, it is invalid and the actual DC load is not changed.
