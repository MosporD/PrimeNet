Modify Authorized Downlink Frequency Band (MOD AUTHDLFREQRANGE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a downlink frequency band that the operator has been authorized to use.

Note

  • Authorized frequency bands must not overlap. If two authorized frequency bands overlap, the user needs to combine these two frequency bands into one.

  • It is recommended that the start and end frequencies of each authorized frequency band to be added be in the same 3GPP frequency band.

  • The start frequency of each authorized frequency band must be less than the end frequency.

  • If the frequency range supported by the RF unit is greater than that supported by the antenna system componens, it is advised to configure the authorized downlink frequency band before activating the cells or performing maintenance functions (such as VSWR Test, Detecting Crossed Pairs, and Detecting Intermodulation Interference, etc). Otherwise, the fause VSWR threshold crossed alarm may be reported and the test result of some maintenance functions may be abnormal. The components of the antenna system include antennas, feeders, jumpers, combiner-dividers, filters, tower-mounted amplifiers (TMAs) and POIs.

Parameters

ID Name Description
INDEX Index

Meaning: Indicates the index of a downlink frequency that the operator has been authorized to use.

GUI Value Range: 0~14

Unit: None

Actual Value Range: 0~14

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
STARTFREQ Start Frequency

Meaning: Indicates the start frequency of a downlink frequency band that the operator has been authorized to use.

GUI Value Range: 0~4294967295

Unit: 0.1MHz

Actual Value Range: 0~429496729.5, step: 0.1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an AUTHDLFREQRANGE MO, the value of STARTFREQ must be less than that of ENDFREQ specified by the same INDEX.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ENDFREQ End Frequency

Meaning: Indicates the end frequency of a downlink frequency band that the operator has been authorized to use.

GUI Value Range: 0~4294967295

Unit: 0.1MHz

Actual Value Range: 0~429496729.5, step: 0.1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an AUTHDLFREQRANGE MO, the value of STARTFREQ must be less than that of ENDFREQ specified by the same INDEX.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify an AUTHDLFREQRANGE with the parameters as follows:INDEX:0, STARTFREQ:9250, ENDFREQ:9600, run the following command:
MOD AUTHDLFREQRANGE: INDEX=0, STARTFREQ=9250, ENDFREQ=9600;
