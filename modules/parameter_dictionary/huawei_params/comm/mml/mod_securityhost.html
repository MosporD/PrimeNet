Modify Security Host (MOD SECURITYHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configurations of a security host.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The IPSec redundancy function is not supported in security object automatic setup scenarios. That is, the Redundancy Flag parameter in the IPv4 IKE peer of the security host must be NONE(Non-redundancy).

  • If the DEVIP, or IPADDR4 object on which a SECURITYHOST object depends is modified, the following security link objects that reference the SECURITYHOST object will be removed and then added: ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If one or more of the following parameters in a SECURITYHOST object are modified, the security link objects that reference the SECURITYHOST object will be removed and then added: Local IKE IP Address, SeGW Switch, SeGW Config Mode, IKE Peer Name, IPSec Proposal Name, and Security Parameters Template ID. Security link objects include ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • [Co-MPT,eNodeB,gNodeB]Modifying any of the following parameters interrupts service that references this security host: Local IKE IP Address, Local IKE IPv6 Address, SeGW Switch, SeGW Config Mode, IKE Peer Name, IPSec Proposal Name and Security Parameters Template ID.

  • [Co-MPT,eNodeB,gNodeB]If one or more of the following parameters in a SECURITYHOST object are modified, the security link objects that reference the SECURITYHOST object will be removed and then added: Local IKE IPv6 Address, SeGW Switch, SeGW Config Mode, IKE Peer Name, IPSec Proposal Name, and Security Parameters Template ID. Security link objects include TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6.

  • [NodeB]Modifying any of the following parameters interrupts service that references this security host: Local IKE IP Address, SeGW Switch, SeGW Config Mode, IKE Peer Name, IPSec Proposal Name and Security Parameters Template ID.

SEGWSWITCH SeGW Switch

Meaning: Indicates whether to enable the peer end to perform IPSec negotiation with the local end through an SeGW. When this parameter is set to DISABLE, the peer end performs IPSec negotiation with the local end directly. When this parameter is set to ENABLE, the peer end establishes an IPSec tunnel to the local end through an SeGW.

Example

To modify the configuration of a security host with the parameters as follows: Security Host ID: 0, SeGW Switch: ENABLE, SeGW Config Mode: SEGW_CONFIG_ON_PEER, Security Parameters Template ID: 1, run the following command:
MOD SECURITYHOST: SECURITYHOSTID=0, SEGWSWITCH=ENABLE, SEGWCONFIGMODE=SEGW_CONFIG_ON_PEER, SECURITYTEMPLATEID=1;
