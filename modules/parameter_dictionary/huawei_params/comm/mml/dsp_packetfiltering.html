Display Packet Filtering Policy Statistics (DSP PACKETFILTERING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of the packets that are matched with the ACL rules after the packet filtering policy is bound to the Ethernet port.

Note

  • When CATALOG is set to ACLGRP or ACLRULE, statistics of the packets on all bound ports of the corresponding board are displayed.

  • When CATALOG is set to PORT, the query results of all packet filtering policies display the actual packet receiving and sending statistics of the port.

Example

To query the status of packet filtering policy with the parameters as follows: Packet Filtering ID: 0, Catalog: ACLGRP, ACL Type: IPV4, ACL ID: 3000, run the following command:
DSP PACKETFILTERING: PACKETFILTERINGID=0, CATALOG=ACLGRP, ACLTYPE=IPV4, ACLID=3000;

Output Description

Field Description

Packet Filtering ID

Indicates the ID of the packet filtering policy.

Filter Mode

Indicates the packet filtering policy mode. The NE can filter packets based on the advanced ACL or layer-2 ACL.

ACL Type

Indicates the type of the ID of the access control list.

Port Type

Indicates the port type on which the packet filtering policy depends.

Port ID

Indicates the port ID or interface ID. When Port Type is set to Interface, this parameter indicates the interface ID. When Port Type is set to other values, this parameter indicates the port ID. When Port Type is set to Interface, the following are true: if IPsec Policy Group Binding Mode in the IKECFG MO is set to ALL, packet filtering policies can be bound only to a normal interface and take effect on the normal interface and all VLAN subinterfaces in the default routing domain of the physical port to which the normal interface belongs; if IPsec Policy Group Binding Mode in the IKECFG MO is set to SINGLE, packet filtering policies take effect only on the interface bound to the IPsec policies.

ACL ID

Indicates the ID of an ACL. The value of this parameter ranges from 3000 to 4999. A value in the range of 3000 to 3999 indicates that the ACL rules in this ACL are advanced ACL rules. A value in the range of 4000 to 4999 indicates that the ACL rules in this ACL are layer 2 ACL rules.

Match Behavior

Indicates whether to permit or reject access of the data that does not match the ACL rule. If this parameter is set to PERMIT, data that does not match the ACL rule is allowed to pass. If this parameter is set to DENY, data that does not match the ACL rule is discarded.

Cabinet No.

Indicates the cabinet number of the board where the packet filtering policy is used.

Subrack No.

Indicates the subrack number of the board where the packet filtering policy is used.

Slot No.

Indicates the slot number of the board where the packet filtering policy is used.

Number of TX Packets(packet)

Indicates the number of transmitted packets. This parameter is reserved for further extension.

Number of RX Packets(packet)

Indicates the number of received packets.

Number of TX Permit Packets(packet)

Indicates the number of permitted packets on the TX channel. This parameter is reserved for further extension.

Number of TX Deny Packets(packet)

Indicates the number of rejected packets on the TX channel. This parameter is reserved for further extension.

Number of RX Permit Packets(packet)

Indicates the number of permitted packets on the RX channel.

Number of RX Deny Packets(packet)

Indicates the number of rejected packets on the RX channel.

Number of RX Packets Matched Default Behavior(packet)

Indicates the number of the packets that do not match the ACL rules for packet filtering policy. If MB is set to PERMIT, this parameter measures the number of accessed packets. If MB is set to DENY, this parameter measures the number of discarded packets. This parameter is valid only when CATALOG is set to PORT.

Bytes of TX Packets(byte)

Indicates the number of bytes contained in transmitted packets. This parameter is reserved for further extension.

Bytes of RX Packets(byte)

Indicates the number of bytes contained in received packets.

Bytes of TX Permit Packets(byte)

Indicates the number of bytes contained in permitted packets on the TX channel. This parameter is reserved for further extension.

Bytes of TX Deny Packets(byte)

Indicates the number of bytes contained in rejected packets on the TX channel. This parameter is reserved for further extension.

Bytes of RX Permit Packets(byte)

Indicates the number of bytes contained in permitted packets on the RX channel.

Bytes of RX Deny Packets(byte)

Indicates the number of bytes contained in rejected packets on the RX channel.

Bytes of RX Packets Matched Default Behavior(byte)

Indicates the number of bytes contained in the packets that do not match the ACL rules for packet filtering policy. If MB is set to PERMIT, this parameter measures the number of bytes contained in the accessed packets. If MB is set to DENY, this parameter measures the number of bytes contained in the discarded packets. This parameter is valid only when CATALOG is set to PORT.
