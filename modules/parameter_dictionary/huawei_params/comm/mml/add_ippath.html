Add IP Path (ADD IPPATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add an IP path.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]In the same routing domain, any two IP paths whose PATHTYPE is set to ANY(Any QoS) must have different address pairs. In the same routing domain, any two IP paths whose PATHTYPE is set to FIXED(Fixed QoS) can have the same address pair, but they must have different DSCP values.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before adding an IP path, ensure that the local IP address (excluding 0.0.0.0) of the IP path is configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the WMPT is the main control board, a maximum of 128 IP paths can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 32 IP paths can be configured. If the LMPT/UMPT/UMDU is the main control board, a maximum of 320 IP paths can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum of 320 IP paths can be configured on an LMPT/UMPT/UMDU/UTRPc/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 64 IP paths can be configured on a WMPT/UTRP (subboard type: UEOC/UIEC/UQEC/UAEC). A maximum of 24 IP paths can be configured on a GTMUb/GTMUc.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The IP path does not support the scenario that meets the following conditions: the local IP address of the IP path is configured as the IP address of the main control board; the transmission extension board provides the transmission port.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When configuring or modifying an IP path, if the VRF index, local IP address and peer IP address of the IP path are same as the VRF index, the RX destination IP address and the RX source IP address of a running loopback by executing the command SET UDPLOOP whose loopback mode is SPECIALIPUDPPORTREMOTE and the RX destination port number is 65040, if the loopback and the IP path are on the same board, the loopback will be stopped automatically.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When you configure an IP path MO: If Port Type is set to ETH or ETHTRK, Local IP in the IP path MO must use the device IP address configured on the corresponding port; if Port Type is set to PPP or MPGRP, Local IP in the IP path MO must use the device IP address configured on the corresponding port or must use the value of Local IP in the corresponding PPPLNK or MPGRP MO.

  • [Co-MPT,eGBTS,eNodeB]An IP path with Path Type set to ANY(Any QoS) must have different address pairs from an IP path with Path Type set to FIXED(Fixed QoS).

  • [Co-MPT,eNodeB]To achieve hybrid transmission, two IP paths in the same routing domain whose PEERIP is the same and whose PATHTYPE is both set to ANY(Any QoS) must have different QT values.

  • [Co-MPT,eNodeB]To achieve hybrid transmission, two IP paths in the same routing domain whose PEERIP and DSCP are the same and whose PATHTYPE is both set to FIXED(Fixed QoS) must have different QT values.

  • [eNodeB]If the main control board is an LMPT, the IP paths whose port type is set to PPP or MPGRP can be successfully configured but cannot take effect.

TRANSCFGMODE Transmission Configuration Mode

Meaning: Indicates the configuration mode of the transmission model. The transmission model can be configured in old or new mode.

In old mode, the transmission model contains information such as cabinet, subrack, and slot numbers. Transmission configurations are bound to device boards.

In new mode, the transmission model has decoupled transmission and device models. That is, transmission configuration removes unnecessary cabinet, subrack, and slot configurations.

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

GUI Value Range: OLD(Old), NEW(New)

Unit: None

Actual Value Range: OLD, NEW

MML Default Value: OLD(Old)

Recommended Value: None

  • [Co-MPT, NodeB, eGBTS, eNodeB]In an IPPATH MO, if TRANSCFGMODE is set to NEW, and BPT is set to LOOPINT, JNIPRSCGRP cannot be set to ENABLE.
