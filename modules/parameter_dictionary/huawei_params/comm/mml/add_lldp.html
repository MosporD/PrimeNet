Add LLDP Port Info (ADD LLDP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a Link Layer Discovery Protocol (LLDP) port. When this command is executed, the system automatically configures local LLDP information using the default values. For details about the default settings, see Note of this command.

Note

  • System specifications: If the WMPT/UMPT/LMPT/GTMUb/GTMUc is the main control board, a maximum of 48 LLDP ports can be configured. If the UMDU is the main control board, a maximum of 2 LLDP ports can be configured.

  • Board specifications: A maximum of 2 LLDP Ports can be configured on a WMPT/UMPTa/UMPTb/UMDU/LMPT/GTMUc. A maximum of 4 LLDP Ports can be configured on a UMPTe/UMPTg/UMPTga. A maximum of 6 LLDP Ports can be configured on a UTRPc. A maximum of 2 LLDP Ports can be configured on a UTRP (subboard type: UEOC). A maximum of 4 LLDP Ports can be configured on a UTRP (subboard type: UQEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • The value of Chassis ID Subtype is MAC Address.

  • The chassis ID is the MAC address of the LLDP port.

  • The value of Port ID Subtype is Interface Name.

  • Both the values of Port ID and Port Description consist of the Ethernet and the cabinet, subrack, slot, and port number for the LLDP port.

  • The system name is the same as the NE name.

  • System Description consists of the vendor, product family, and base station model.

  • Both System Capabilities Supported and System Capabilities Enabled are set to Router.

  • If an OMCH is configured, the management address is the OM IP address. Otherwise, the management address is empty.

  • The BS does not support port VLANs.

  • The system does not support or enable ports and protocol VLANs.

  • By default, the system supports auto negotiation and Ethernet trunk.

  • The maximum frame size is the sum of the MAC header and MAC check bit length (18 bytes in total), VLAN header length (4 bytes when a VLAN is configured or 0 bytes when VLANs are not configured), and maximum transmission unit (MTU) length. If the LLDP port has been added to an Ethernet trunk link, the MTU is that of the Ethernet trunk. Otherwise, the MTU is that of the LLDP port.

  • The VLAN name consists of the string "VLAN" and the VLAN ID. The VLAN ID can be that in the ADD VLANMAP command, that in the ADD VLANCLASS command, or that in the ADD SUBNETVLAN command. The same VLAN ID in these commands is processed for only once. The system supports a maximum of 32 VLAN names.

  • The value of Management Address Type is set to IPv4.

Example

To add the configuration of LLDP port as follows: LLDP ID: 1, Ethernet Port ID: 100, Binding VLAN: YES, VLAN ID: 3, VLAN Priority: 4, run the following command:  
ADD LLDP: LLDPID=1, ETHPORTID=100, BNDVLAN=YES, VLANID=3, VLANPRI=4;
