Modify TMA (MOD TMA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a tower mounted amplifier (TMA).

Note

  • The TMA is available only when the ALD current alarm threshold is set and the ALD power supply switch is set to ON. For details about how to query the port status, see the DSP ANTENNAPORT command. For details about how to modify the port status, see the MOD ANTENNAPORT command.

  • In the scenario where two RRUs/RFUs share a TMA, if the controller of an RVD is changed from RRU/RFU 1 to RRU/RFU 2, the controller of other ALDs must also be changed from RRU/RFU 1 to RRU/RFU 2. The change of the controller is implemented by reconfiguring CTRLCN, CTRLSRN, and CTRLSN. The period of time required by the control port switchover varies with the TMA model. If the TMA software does not switch over the control port within a period of time after this command is executed, ALM-26541 ALD Maintenance Link Failure will be generated. In this case, wait for 5 to 10 minutes after all the controllers are changed, and then run the SCN ALD command to scan the RRU/RFU controlling the ALDs. After the scanning completes, the RVD maintenance link will recover and the alarm will be cleared. If the alarm persists, clear the alarm with recommended actions.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the ALD. The device number of the ALD must be unique.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

[Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENO in the RET MO, DEVICENO in the TMA MO, DEVICENO in the SASU MO, DEVICENO in the RAE MO, DEVICENO in the RVD MO, and DEVICENO in the RAS MO.

[eNodeB, gNodeB]The following parameters cannot be set to the same value: DEVICENO in the RET MO, DEVICENO in the TMA MO, DEVICENO in the RAE MO, DEVICENO in the RVD MO, and DEVICENO in the RAS MO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DEVICENAME Device Name

Meaning: Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

GUI Value Range: 0~83 characters

Unit: None

Actual Value Range: 0~83 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

[Co-MPT, NodeB, eGBTS]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the SASU MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

[eNodeB]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the VRET MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

[gNodeB]The following parameters cannot be set to the same value: DEVICENAME in the RET MO, DEVICENAME in the TMA MO, DEVICENAME in the RAE MO, DEVICENAME in the RVD MO, and DEVICENAME in the RAS MO.

Example

To modify the configuration of a TMA with the parameters as follows: Device No.: 0, Device Name: PEOPLESQUARE_SEC1_TMA_02, Number of TMA Subunits: 1, run the following command:
MOD TMA: DEVICENO=0, DEVICENAME="PEOPLESQUARE_SEC1_TMA_02", SUBUNITNUM=1;
