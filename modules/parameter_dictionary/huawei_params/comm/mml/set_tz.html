Set Time Zone and DST Parameter (SET TZ)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the time zone and the daylight saving time (DST) information about the NE.

This command can also be used to set the time zone and DST information about the southern hemisphere. That is, the start time can be later than the end time.

The start time and the end time can be specified in different formats while setting DST information.

The command can be used to self-define a time zone precise to the minute.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The DST start month and end month must be different and separate.

  • If the DST start date is later than the end date, it indicates that DST ends in the next year. For example, when the start date is June 1 and the end date is August 1, the DST is from June 1 to August 1 every year. When the start date is August 1 and the end date is June 1, the DST is from August 1 of one year to June 1 of the next year. The period between June 1 and August 1 every year is not the DST.

  • The time zone or DST information can be set separately.

  • If both the date and the day of the week are specified, the DST start day is determined as follows: If the specified date falls on the specified day of the week, DST starts on that date. Otherwise, DST starts on the first specified day of the week after the date. For example, when the specified date and day of the week are January 5 and Wednesday, respectively, DST starts on January 5 if it is Wednesday on that date, or starts on the first Wednesday after January 5 if January 5 does not fall on Wednesday.

  • If the DST start day or end day is specified in the mode of date plus day of the week, the specified date plus six days cannot be later than the last day of the month. That is, the start date or end date must be in the same month as the specified date. Note that February 28 is the last day of February.

  • The start time specified by running this command observes standard time, and the end time observes DST. For example, if the DST end time is set to 03:00 and the difference between standard time and DST is 60 minutes, then the local time jumps to 02:00 standard time when DST ends at 03:00.

  • Neither the start date nor the end date of the DST can be set to February 29 in DATE or DATEWEEK mode. If the DST start date or end date is set to February 29, the local time cannot jump based on the DST start day or end day. This is because there is February 29 only in a leap year.

  • The standard time to which the local time jumps when DST ends must be in the same year.

  • If SM of the DST is set to WEEK, SWSEQ and SWEEK indicate the week and the day, respectively. For example, if SWSEQ is set to LAST and SWEEK is set to MON, they indicate the last Monday in a month instead of Monday of the last week. If EM is set to WEEK, the same principle applies to this case.

Example

Example 1: To set the time zone and DST information with the parameters as follows: Time Zone: GMT+0800, DST Tag Information: NO, run the following command: 
SET TZ: ZONET=GMT+0800, DST=NO;

Example 2: To set the time zone and DST information with the parameters as follows: Time Zone: GMT+0800, DST Tag Information: YES, DST Start Mode: DATE, DST Start Month: JAN, DST Start Day: 2, DST Start Time: 10&49&00, DST End Mode: DATE, DST End Month: FEB, DST End Day: 26, DST End Time: 10&49&00, DST Offset: 30, run the following command: 
SET TZ: ZONET=GMT+0800, DST=YES, SM=DATE, SMONTH=JAN, SDAY=2, ST=10&49&00, EM=DATE, EMONTH=FEB, EDAY=26, ET=10&49&00, TO=30;

Example 3: To set the time zone and DST information with the parameters as follows: Time Zone: GMT+0800, DST Tag Information: YES, DST Start Mode: WEEK, DST Start Month: JAN, DST Start Week Sequence: LAST, DST Start Weekday: TUE, DST Start Time: 10&49&00, DST End Mode: DATE, DST End Month: FEB, DST End Day: 26, DST End Time: 10&49&00, DST Offset: 30, run the following command: 
SET TZ: ZONET=GMT+0800, DST=YES, SM=WEEK, SMONTH=JAN, SWSEQ=LAST, SWEEK=TUE, ST=10&49&00, EM=DATE, EMONTH=FEB, EDAY=26, ET=10&49&00, TO=30;

Example 4: To set the time zone and DST information with the parameters as follows: Time Zone: GMT+0800, DST Tag Information: YES, DST Start Mode: DATEWEEK, DST Start Month: JAN, DST Start Day: 1, DST Start Weekday: TUE, DST Start Time: 10&49&00, DST End Mode: DATE, DST End Month: FEB, DST End Day: 26, DST End Time: 10&49&00, DST Offset: 30, run the following command: 
SET TZ: ZONET=GMT+0800, DST=YES, SM=DATEWEEK, SMONTH=JAN, SDAY=1, SWEEK=TUE, ST=10&49&00, EM=DATE, EMONTH=FEB, EDAY=26, ET=10&49&00, TO=30;
