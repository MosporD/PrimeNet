Remove IPSec Proposal (RMV IPSECPROPOSAL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an IPSec proposal.

Note

If an IPSec proposal is referenced by an IPSec policy, you must remove the IPSec policy before removing the IPSec proposal.

Parameters

ID Name Description
PROPNAME IPSec Proposal Name

Meaning: Indicates the name of the IPSec proposal.

GUI Value Range: 1~15 characters

Unit: None

Actual Value Range: 1~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When an IPSECPROPOSAL MO is added, the PROPNAME is case-insensitive. When an IPSECPROPOSAL MO is referenced by other objects, however, the name is case-sensitive.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To delete the IPSec proposal with the Proposal Name of prop1, run the following command:
RMV IPSECPROPOSAL: PROPNAME="prop1";
