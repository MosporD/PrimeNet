List SNMP User (LST SNMPUSER)

Network Element: BTS3900, BTS5900

Function

Use this command to query an SNMP user.

Note

[Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

Parameters

ID Name Description
USERNAME User Name

Meaning: Indicates the name of an SNMP user.

GUI Value Range: 1~32 characters

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R

Example

To query SNMP user configuration in the database, run the following command:
LST SNMPUSER:;
The result is shown as follows:
+++    0        2019-07-05 09:59:46
TRAFFIC    #1818
%%LST SNMPUSER:;%%
RETCODE = 0  Operation succeeded.

List SNMP User
--------------
User Name  Authentication Protocol  Private Protocol

user0      SHA                      AES             
user1      SHA                      DES             
(Number of results = 2)


---    END

Output Description

Field Description

User Name

Indicates the name of an SNMP user.

Authentication Protocol

Indicates the authentication mode of an SNMP user, MD5(HMAC-MD5), SHA(HMAC-SHA). NONE, MD5 have security risks and are not recommended.

Disuse statement: In later versions, the value MD5(MD5) will be removed from the value range of this parameter. In the current version, this value can still be configured and take effect.Therefore, you are not advised to use the value MD5(MD5).

Private Protocol

Indicates the encryption mode of an SNMP user, DES(DES-CBC), AES(AES-128). NONE, DES have security risks and are not recommended.

Disuse statement: In later versions, the value DES(DES) will be removed from the value range of this parameter. In the current version, this value can still be configured and take effect.Therefore, you are not advised to use the value DES(DES).
