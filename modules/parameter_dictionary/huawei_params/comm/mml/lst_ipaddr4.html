List IPv4 Address Configuration (LST IPADDR4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the IPv4 addresses that have been configured.

Note

None.

Parameters

None.

Example

To list the configuration of an IPv4 addresses, run the following command:
LST IPADDR4:;
The result is shown as follows:
+++    0        2016-11-04 11:18:58
O&M    #171
%%LST IPADDR4:;%%
RETCODE = 0  Operation succeeded.

List IPv4 Address Configuration
-------------------------------
Interface ID  =  100
  IP Address  =  172.16.81.122
        Mask  =  255.255.255.0
   VRF Index  =  0
  User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

Interface ID

Indicates the ID of an interface.

IP Address

Indicates the IP address configured on the port.

Mask

Indicates the subnet mask for the IP address configured on the port.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

User Label

Indicates the user-defined information of an IP address.
