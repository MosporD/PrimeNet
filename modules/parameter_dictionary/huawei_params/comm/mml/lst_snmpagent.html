List SNMP Agent (LST SNMPAGENT)

Network Element: BTS3900, BTS5900

Function

Use this command to query SNMP agent information.

Note

[Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

Parameters

None.

Example

To query the SNMP AGENT configuration in the database, run the following command:
LST SNMPAGENT:;
The result is shown as follows:
+++    0        2019-07-05 09:19:48
TRAFFIC    #1693
%%LST SNMPAGENT:;%%
RETCODE = 0  Operation succeeded.

List SNMP Agent
---------------
             Port  =  161
SNMP Agent Switch  =  ENABLE
          Version  =  V2C
       IP Address  =  10.157.164.11
             Mask  =  255.255.255.0
(Number of results = 1)


---    END

Output Description

Field Description

Port

Indicates the port number of an SNMP agent. By default, port 161 is used. To use a non-default port, ensure that the port is not being used.

SNMP Agent Switch

Indicates whether to enable SNMP agent.

Version

Indicates the version of an SNMP agent.You are not advised to use V2C(V2C) because it has security risks.

IP Address

Indicates the IP address used by an SNMP agent.

Mask

Indicates the subnet mask used by an SNMP agent.
