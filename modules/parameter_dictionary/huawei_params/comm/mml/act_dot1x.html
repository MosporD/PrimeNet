Activate IEEE 802.1X Authentication (ACT DOT1X)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to activate the 802.1X authentication.

Note

  • 802.1x authentication uses the SSL certificate. For detailed settings, see the command MOD APPCERT. When the SSL certificate specified in the MOD APPCERT command does not exist, the system automatically uses the preset certificate of the board deployed with 802.1x for authentication. Run the LST CERTFILE command with Certificate File Type set to DEVCERT. The certificate file named appcert.pem in the command output is the preset certificate.

  • Board specifications: A maximum of 2 802.1X authentications can be activated on an LMPT/UMPTa/UMPTb/GTMUc/UMDU/UTRP (subboard type: UEOC). A maximum of 4 802.1X authentications can be activated on a UMPTe/UMPTg/UMPTga/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. A maximum of 6 802.1X authentications can be activated on a UTRPc.

  • System specifications: If the LMPT/UMPT/GTMUc is the main control board, a maximum of 48 802.1X authentications can be activated. If the WMPT is the main control board, a maximum of 16 802.1X authentications can be activated. If the UMDU is the main control board, a maximum of 2 802.1X authentications can be activated.

  • Besides activated by running this command, an IEEE 802.1X authentication will also be activated if a DHCP detection attempt is performed on a port when the base station fails to be managed by the MAE.

Meaning: Indicates the number of the cabinet that provides the port on which IEEE 802.1X authentication is configured.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Port ID and Port Type parameter in the DOT1XAUTH MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To act the 802.1x authentication with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: Base Board, Port No.: 0, Authentic Method: EAP-TLS authentic method, run the following command: 
ACT DOT1X: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PN=0, AM=EAP-TLS;
