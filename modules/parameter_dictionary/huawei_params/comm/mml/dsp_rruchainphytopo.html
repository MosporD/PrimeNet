Display RRU Chain/Ring Physical Information (DSP RRUCHAINPHYTOPO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the topology and hardware information about the RRU chain/ring connected to a CPRI port.

Note

  • The query result may be incorrect if the RRU topology is changed or adjusted due to removal of breakpoints by running the MOD RRUCHAIN command. In this situation, wait for 1 minute and then run this command to obtain the correct topology. If the BBP and RRU are connected in the form of ring or load sharing topology, the information of the RRU or RFU can be queried only on one connected CPRI port.

  • In the command output, BOM and Description are displayed for only specific RF modules.

Output Description

Field Description

Topo Type

Indicates the type of the topology. In a ring topology, service data is transmitted on the fiber optic cable that carries the HDLC link. In a load sharing topology, service data is transmitted on two fiber optic cables simultaneously, which enhances the transmission capability. The physical connection in the ring topology is similar to that in the load sharing topology. The trunk chain enables multiple CPRI fiber optic cables to simultaneously transmit service data.

Head Cabinet No.

Indicates the cabinet number of the board where the head CPRI port is located.

Head Subrack No.

Indicates the subrack number of the board where the head CPRI port is located.

Head Slot No.

Indicates the slot number of the board where the head CPRI port is located.

Head Port No.

Indicates the number of the head CPRI port.

Head SubPort No.

Indicates the number of the head CPRI sub-port.

Tail Cabinet No.

Indicates the cabinet number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Subrack No.

Indicates the subrack number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Slot No.

Indicates the slot number of the board where the tail CPRI port is located. If there is no tail, the value of this parameter is NULL.

Tail Port No.

Indicates the number of the tail CPRI port. If there is no tail, the value of this parameter is NULL.

Tail SubPort No.

Indicates the number of the tail CPRI sub-port. If there is no tail or the tail has no sub-ports, the value of this parameter is NULL.

Cabinet No.

Indicates the cabinet number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.

Subrack No.

Indicates the subrack number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.

Slot No.

Indicates the slot number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. The CPRI port is used for the configuration check when an RRU chain/ring is added.

Port No.

Indicates the port number of the board where the CPRI port is located. This parameter is configured automatically when the CPRI port is created. A CPRI port is created automatically when a board with CPRI ports is added by running the ADD BRD command. The CPRI port is used for the configuration check when an RRU chain/ring is added.

Sub Port No.

Indicates the number of a sub-port on a CPRI port. This parameter is valid only when the port mode of XCI on the RMU is 2x10GE or the port is on the baseband processing board. The value NULL indicates that the connected port of the device has no subport.

Topo Position

Indicates the position where the RRU or RFU is installed in the topology. There are two types of positions for the RRU or RFU: TRUNK and BRANCH. BRANCH indicates that the RRU is connected to the RHUB. TRUNK indicates that the RRU or RFU is located on the main chain/ring. The main chain/ring is connected to the optical port on the baseband processing board.The LampSite high-power modules must be configured as the main chain/ring (TRUNK), and the LampSite low-power modules must be configured as a branch (BRANCH).

Trunk Level

Indicates the RRU/RFU level on the trunk of the chain/ring.

Standard Capability

Indicates the standards that are supported by the RRU or RFU. The value NULL indicates that obtaining the supported modes fails or the board does not support the query of supported modes. The parameter values consist of different RATs. LO, LF, and L indicate LTE-FDD, T and TD indicate LTE-TDD, W and WO indicate WiMAX, C and CO indicate CDMA, G and GO indicate GSM, U and UO indicate UMTS, R and RO indicate RFA, M and MO indicate NB-IoT, NF indicates NR-FDD, and NTD indicates NR-TDD.

Physical device serial No.

Indicates the equipment serial number (ESN) of the board on the RRU chain/ring. Value NULL indicates obtaining the ESN fails. A maximum of 16 digits of the ESN can be displayed for a module compliant with the IR protocol.

Uplink Port No.

Indicates a slave CPRI port of a board. In load sharing or hot ring topology, the value of this parameter indicates a port used for setting up a maintenance link of a board. The value NULL indicates that no maintenance link is set up for a board, and therefore information about the port cannot be queried.

Uplink Subport No.

Indicates a subport of the connected port on a device. The value NULL indicates that the connected port of the device has no subport.

Port 1 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 1 of the trunk chain.

Port 1 Subrack No.

Indicates the subrack number of the board a port of which works as port 1 of the trunk chain.

Port 1 Slot No.

Indicates the slot number of the board a port of which works as port 1 of the trunk chain.

Port 1 Port No.

Indicates the port number of the board a port of which works as port 1 of the trunk chain.

Port 2 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Subrack No.

Indicates the subrack number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Slot No.

Indicates the slot number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 2 Port No.

Indicates the port number of the board a port of which works as port 2 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Subrack No.

Indicates the subrack number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Slot No.

Indicates the slot number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 3 Port No.

Indicates the port number of the board a port of which works as port 3 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Cabinet No.

Indicates the cabinet number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Subrack No.

Indicates the subrack number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Slot No.

Indicates the slot number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Port 4 Port No.

Indicates the port number of the board a port of which works as port 4 of the trunk chain. The value of this parameter is NULL if the current port is not used.

Configure Status

Indicates whether the board on the RRU chain/ring is configured.

BOM

Indicates the BOM number of a board on the RRU chain/ring. The value NULL indicates that the query fails or the board does not support the query. The value UNCERTAIN indicates that the board is in an unstable state between resets and you can retry querying the information after 20 minutes within 30 minutes.

Description

Indicates description of a board on the RRU chain/ring. The value NULL indicates that the query fails or the board does not support the query. The value UNCERTAIN indicates that the board is in an unstable state between resets and you can retry querying the information after 20 minutes within 30 minutes.
