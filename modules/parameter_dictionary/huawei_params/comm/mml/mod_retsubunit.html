Modify RET Subunit (MOD RETSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a remote electrical tilting (RET) subunit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The port to be set in this command must be an RRU/RFU port that has been configured. Otherwise, the execution result of this command indicates that the antenna port is not configured.

  • Ensure that the numbers of the cabinet, subrack, slot, and antenna port to be set are consistent with those of the RF port to which the RET unit is connected, because the system is unable to identify the inconsistency. If there is inconsistency and another command is executed with "operating by sector" selected, the command will be executed for a wrong MO.

  • Two subunits cannot be connected to the same port in non-sector-splitting scenarios.

  • After you modify the tilt of a subunit, the system automatically changes the tilt based on your modification, which affects the network coverage. Changing the tilt takes 4 minutes at most. If the tilt fails to be changed, the system reports ALM-26757 RET Antenna Running Data and Configuration Mismatch.

  • There is an offset during the tilt calibration or tilt adjusting of the RET unit. The offset varies according to the manufacturer and is often smaller than 0.5 degrees, because an offset smaller than 0.5 degrees has no insignificant impact on the network coverage and is acceptable. Therefore, you are advised to set the tilt inconsistency alarm threshold to a value not smaller than 5.

  • When the cabinet number of the port to which the RET subunit is connected is 255, the port is not connected. In this case, the corresponding subrack number and slot number are also set to 255.

  • The range of the tilt angle varies according to the manufacturer and RET unit model. Before modifying the tilt angle, you are advised to run the DSP RETDEVICEDATA command to check the tilt angle range supported by the antenna.

  • For an AAU supporting beamforming, the tilts of the inner and outer RET antennas must be valid and the tilt of the inner RET antenna must be greater than or equal to that of the outer RET antenna.

  • If an unavailable RPCU exists on the base station, the configured data cannot take effect and ALM-26757 RET Antenna Running Data and Configuration Mismatch is reported. This alarm is automatically cleared when all RPCUs are running properly.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SCENARIO in the RET MO corresponding to all RETSUBUNIT MOs configured on the same ANTENNAPORT MO must be set to SECTOR_SPLITTING.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an RETSUBUNIT MO, the combination of CONNCN1, CONNSRN1, CONNSN1, and CONNPN1 cannot be the same as the combination of CONNCN2, CONNSRN2, CONNSN2, and CONNPN2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When CONNCN1 in an RETSUBUNIT MO is set to a value other than 255, CONNSRN1 and CONNSN1 must all be set to a value other than 255. Similarly, when CONNCN2 in an RETSUBUNIT MO is set to a value other than 255, CONNSRN2 and CONNSN2 must all be set to a value other than 255.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When POLARTYPE and RETTYPE in an RET are set to SINGLE and SINGLE_RET, respectively, only one of CONNCN1 and CONNCN2 in the RETSUBUNIT MO needs to be configured.

Example

To modify an RET subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, Connect Port 1 Cabinet No.: 0, Connect Port 1 Subrack No.: 60, Connect Port 1 Slot No.: 0, Connect Port 1 Port No.: R0A, run the following command:
MOD RETSUBUNIT: DEVICENO=0, SUBUNITNO=1, CONNCN1=0, CONNSRN1=60, CONNSN1=0, CONNPN1=R0A;
