Stop Clock Quality Test Monitoring (STP CLKTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to stop the clock quality test monitoring.

Note

  • If there is no ongoing clock source quality test, the execution of this command fails.

  • It is meaningless to execute this command on a standby main control board.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the system clock is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the system clock is located.

GUI Value Range: 0~1,60~254

Unit: None

Actual Value Range: 0~1,60~254

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the system clock is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To stop the clock quality test monitoring in slot 7, run the following command:
STP CLKTST: SRN=0, SN=7;
