Display J0/J1 Information (DSP SDHJ0J1)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the content of J0 or J1 on an optical interface board.

Note

None.

Example

To query J0/J1 information with the parameters as follows: Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, run the following command:
DSP SDHJ0J1: SN=0, SBT=UNCHANNELLED_COVERBOARD;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a specified optical port is located.

Subrack No.

Indicates the number of the subrack that houses the board where a specified optical port is located.

Slot No.

Indicates the number of the slot that houses the board where a specified optical port is located.

Subboard Type

Indicates the type of the sub-board on the board where a specified optical port is located.

Port No.

Indicates the number of a specified optical port.

Trace Byte

Indicates the type of the trace byte configured at a specified optical port.

Tx Type

Indicates the type of J0 or J1 transmitted at a specified optical port.

Tx Information

Indicates the content of J0 or J1 transmitted at a specified optical port.

Expected Rx Type

Indicates the type of J0 or J1 received at a specified optical port.

Expected Rx Information

Indicates the content of J0 or J1 received at a specified optical port.

Actual Rx Information

Indicates the actual content of J0 or J1 received at a specified optical port.
