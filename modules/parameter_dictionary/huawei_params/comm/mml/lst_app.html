List Maintenance Status of Application (LST APP)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the maintenance mode of the application.

Note

[Co-MPT]In a base station where the GTMU supports SingleOM, this command cannot be executed.

Parameters

None.

Example

To query the current application, run the following command:
LST APP:;
The result is as follows:

Output Description

Field Description

Application ID

Indicates the application ID.

Application Type

Indicates the application type.

Application Name

Indicates the application name.

Software Version

Indicates the application software version.

Hot Patch Version

Indicates the hot patch version of the software for the application.

Application Version

Indicates the application version.

Application Hot Patch Version

Indicates the hot patch version of the application.

Application Maintenance Mode

Indicates the maintenance mode of the application. This parameter is set to NORMAL by default by the manufacturers. ExpandStatus1 to ExpandStatus10 can be self-defined.

Start Time of Application Status Setting

Indicates the start time of maintenance mode of the application. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the start time of the maintenance mode is 2000-01-01 00:00:00.

End Time of Application Status Setting

Indicates the end time of maintenance mode of the application. This time refers to the local time (including the DST offset) on the NE. If this parameter is not specified, the maintenance mode ends at 2037-12-31 23:59:59.

Application Maintenance Mode Setting Remark

Indicates the remarks of maintenance mode of the application.

Extended Application Type

Indicates the extended application type.

Running Mode

Indicates the running mode of the application.
