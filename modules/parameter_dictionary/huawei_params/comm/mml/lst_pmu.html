List PMU (LST PMU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of a power monitoring unit (PMU).

Note

  • For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The SC48200 PMU does not support the query of AC voltage thresholds.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the PMU is located.

Subrack No.

Indicates the number of the subrack where the PMU is located.

Slot No.

Indicates the number of the slot where the PMU is located.

Manager Cabinet No.

Indicates the cabinet number of the manager. The manager of the PMU is usually a BBU, RRU or CCU.

Manager Subrack No.

Indicates the subrack number of the manager. The manager of the PMU is usually a BBU, RRU or CCU.

Manager Port No.

Indicates the number of the serial port where the PMU is connected. The serial port is the port through which the PMU is connected to the manager unit.

Address

Indicates the communication address of the PMU, which is determined by the settings of the 4-bit dual in-line package (DIP) switch on the PMU. The communication address is used by the PMU to communicate with the main control and transmission board. The value of this parameter must be consistent with the actual settings of the DIP switch. The 4-bit DIP switch can be treated as a 4-bit binary number. The settings of ON and OFF are represented by 1 and 0 respectively. Convert the 4-bit number from binary to decimal, and then the decimal number is used as the value of this parameter.

Power System Type

Indicates the type of the power system for the PMU.

AC Voltage Alarm Lower Threshold(V)

Indicates the lower threshold of AC input voltage. When the AC input voltage is lower than the value, an ALM-25622 Mains Input Out of Range alarm is reported.

AC Voltage Alarm Upper Threshold(V)

Indicates the higher threshold of AC input voltage. When the AC input voltage is higher than the value, an ALM-25622 Mains Input Out of Range alarm is reported.

DC Voltage Alarm Lower Threshold(0.1V)

Indicates the lower threshold of the DC voltage. When the output voltage of the busbar is lower than the value, an ALM-25621 Power Supply DC Output Out of Range alarm is reported.

DC Voltage Alarm Upper Threshold(0.1V)

Indicates the upper threshold of the DC voltage. When the output voltage of the busbar is higher than the value, an ALM-25621 Power Supply DC Output Out of Range alarm is reported.

Load Shutdown Flag

Indicates the flag for power-off against low voltage, which determines whether the load is powered off in the case of low voltage.

Load Shutdown Voltage(0.1V)

Indicates the load voltage below which the load is powered off automatically when load power-off against low voltage is enabled.

Load Shutdown Time Flag

This parameter determines whether the load is powered off based on time in a base station. When this parameter is set to DISABLE, the load is powered off only when the battery voltage is less than Load Shutdown Voltage. When this parameter is set to ENABLE, the load is powered off when the duration of AC power shutdown exceeds Load Shutdown Time or the battery voltage is less than Load Shutdown Voltage.

Load Shutdown Time(min)

Indicates the duration after which the load is powered off. When both the flag for power-off against time and the flag for power-off against low voltage are enabled, the load is powered off when the duration of AC power shutdown exceeds Load Shutdown Time or the battery voltage is less than Load Shutdown Voltage.

Power Distribution Slot No-Backup Flag

Indicates whether to enable the no-backup capability of the power distribution slots for a power system.If this parameter is set to DISABLE, the power system retains the backup power capability of the storage batteries in the power distribution slots when an AC power failure occurs. If this parameter is set to ENABLE, the power system powers off the load that is powered by the power distribution slots when an AC power failure occurs.

Cabinet Temperature Alarm Lower Threshold[degree Celsius(degree Fahrenheit)]

Indicates the lower threshold of the cabinet temperature. If the cabinet temperature is lower than the value, an ALM-25652 Cabinet Temperature Unacceptable alarm is reported. This parameter is valid only for the APM100 and APM200 cabinets.

Cabinet Temperature Alarm Upper Threshold[degree Celsius(degree Fahrenheit)]

Indicates the upper threshold of the cabinet temperature. If the cabinet temperature is higher than the value, an ALM-25652 Cabinet Temperature Unacceptable alarm is reported. This parameter is valid only for the APM100 and APM200 cabinets.

Cabinet Humidity Alarm Lower Threshold(%)

Indicates the lower threshold of the cabinet humidity. If the cabinet humidity is lower than the value, an ALM-25653 Cabinet Humidity Unacceptable alarm is reported.

Cabinet Humidity Alarm Upper Threshold(%)

Indicates the upper threshold of the cabinet humidity. If the cabinet humidity is higher than the value, an ALM-25653 Cabinet Humidity Unacceptable alarm is reported.

Special Analog Alarm Flag

Indicates whether to allow the report of a dedicated analog alarm. If the shield flag for an analog alarm is enabled, the analog alarm cannot be reported.

Special Boolean Alarm Flag

Indicates whether to allow the reporting of a dedicated Boolean alarm. If the shield flag for a Boolean alarm is enabled, the Boolean alarm cannot be reported.

HVDU Number

Indicates the number of 225-400 V DC power distribution units (HVDUs). Set this parameter based on site conditions. An incorrect configuration will affect the reporting of the alarm related to the safety of 225-400 V DC power distribution..

HVDC Insulation Resistance Alarm Threshold(kohm)

Indicates the insulation resistance alarm threshold. The insulation resistance is that between the positive/negative bus bar and the ground, which retains the default value. If the load resistance value is less than the threshold, contact Huawei technical support to check the threshold.

HVDC Output Voltage(V)

Indicates the 225-400 V direct current (DC) output voltage. Set this parameter based on site conditions. An incorrect parameter value may lead to overvoltage protection or even damage. If this parameter is set to a value greater than 300 V, disable the DC output of the DC power supply unit (HSU) and then enable the DC output to make the parameter setting take effect.

AC Current Limiting Flag

Indicates whether the AC power system limits the AC input current. When this switch is turned on, the AC power system limits the AC input current to prevent the entire base station from being powered off due to the upper-level circuit breaker tripping. When this switch is turned off, the AC power system does not limit the AC input current. The maximum AC input current depends on the hardware capability of the AC power system. If the AC input current exceeds the rated current of the upper-level circuit breaker, the entire base station may be powered off.

AC Air Switch Current Limiting Threshold(A)

Indicates the AC input current threshold of the AC power system. After the AC current limiting function takes effect, the AC power system limits the AC input current so that the AC input current does not exceed the AC current threshold.

AC Phase Type

Indicates the external AC phase type of the AC power system.
