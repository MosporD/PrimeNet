Add TLS Configuration Policy (ADD TLSPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a TLS configuration policy.

Note

None.

Parameters

ID Name Description
POLICYID POLICY ID

Meaning: Indicates the ID of a TLS configuration policy.

GUI Value Range: 0~16

Unit: None

Actual Value Range: 0~16

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]POLICYID in a CA MO must be set to a configured value of POLICYID in an TLSPOLICY MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]POLICYID in a CRLTSK MO must be set to a configured value of POLICYID in an TLSPOLICY MO.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CRLTSK MO, this parameter is valid only when CRLGETMETHOD is set to LDAP, CONNMODE is set to SSL.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
KEYUPDATESW Key Update Switch

Meaning: Indicates whether to enable the TLS key update function. This function updates the key in current use. For details, see RFC 8446.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(ON)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
KEYUPDATELT Key Update Lifetime

Meaning: Indicates the TLS key update period.

GUI Value Range: 5~10080

Unit: min

Actual Value Range: 5~10080

MML Default Value: 60

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DHGRP Diffie-Hellman Group

Meaning: Indicates the Diffie-Hellman group for TLS key negotiation.

GUI Value Range: X25519(X25519), X448(X448), SECP256R1(SECP256R1), SECP384R1(SECP384R1)

Unit: None

Actual Value Range: X25519, X448, SECP256R1, SECP384R1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The SECP256R1 cannot be disabled for DHGRP in the TLSPOLICY MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SIGALG Signature Algorithm

Meaning: Indicates the TLS signature algorithm.

GUI Value Range: RSA_PSS_RSAE_SHA256(RSA_PSS_RSAE_SHA256), RSA_PSS_RSAE_SHA384(RSA_PSS_RSAE_SHA384), ECDSA_SECP256R1_SHA256(ECDSA_SECP256R1_SHA256), ECDSA_SECP384R1_SHA384(ECDSA_SECP384R1_SHA384), ED25519(ED25519)

Unit: None

Actual Value Range: RSA_PSS_RSAE_SHA256, RSA_PSS_RSAE_SHA384, ECDSA_SECP256R1_SHA256, ECDSA_SECP384R1_SHA384, ED25519

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The RSA_PSS_RSAE_SHA256 cannot be disabled for SIGALG in the TLSPOLICY MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CIPHERSUITE Cipher Suite

Meaning: Indicates the TLS cipher suite.

GUI Value Range: TLS_AES_128_GCM_SHA256(TLS_AES_128_GCM_SHA256), TLS_AES_256_GCM_SHA384(TLS_AES_256_GCM_SHA384), TLS_CHACHA20_POLICY1305_SHA256(TLS_CHACHA20_POLICY1305_SHA256)

Unit: None

Actual Value Range: TLS_AES_128_GCM_SHA256, TLS_AES_256_GCM_SHA384, TLS_CHACHA20_POLICY1305_SHA256

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TLS_AES_128_GCM_SHA256 cannot be disabled for CIPHERSUITE in the TLSPOLICY MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To add a TLS configuration policy with the parameters as follows:
Policy ID: 0, Key Update Switch: ON, Key Update Lifetime: 60, Diffie-Hellman Group: SECP256R1, Signature Algorithm: RSA_PSS_RSAE_SHA256, Cipher Suite: TLS_AES_128_GCM_SHA256, run the following command:
ADD TLSPOLICY: POLICYID=0, KEYUPDATESW=ON, KEYUPDATELT=60, DHGRP=X25519-0&X448-0&SECP256R1-1&SECP384R1-0, SIGALG=RSA_PSS_RSAE_SHA256-1&RSA_PSS_RSAE_SHA384-0, CIPHERSUITE=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-0&TLS_CHACHA20_POLICY1305_SHA256-0;
The result is shown as follows:
+++    0        2019-08-20 21:54:20
O&M    #178
%%ADD TLSPOLICY: POLICYID=0, KEYUPDATESW=ON, KEYUPDATELT=60, DHGRP=X25519-0&X448-0&SECP256R1-1&SECP384R1-0, SIGALG=RSA_PSS_RSAE_SHA256-1&RSA_PSS_RSAE_SHA384-0, CIPHERSUITE=TLS_AES_128_GCM_SHA256-1&TLS_AES_256_GCM_SHA384-0&TLS_CHACHA20_POLICY1305_SHA256-0;%%
RETCODE = 0  Operation succeeded.
