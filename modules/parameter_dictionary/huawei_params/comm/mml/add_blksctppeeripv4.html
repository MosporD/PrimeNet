Add SCTP Peer IPv4 Address Block (ADD BLKSCTPPEERIPV4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to block SCTP links based on the peer IPv4 address.After a peer IPv4 address is blocked, all SCTP links associated with the peer IPv4 address are blocked accordingly.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first or second peer IP address of an SCTP link is the same as the peer IPv4 address in the BLKSCTPPEERIPV4 object, the SCTP link is blocked.

  • [NodeB,eGBTS,eNodeB,gNodeB]This command will interrupt services carried on the SCTP link that is automatically generated using an SCTP peer.

  • [NodeB,eGBTS,eNodeB,gNodeB]System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMU is the main control board, a maximum of 16 BLKSCTPPEERIPV4s can be configured.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PEERIPV4 Peer IPv4 Address

Meaning: Indicates the peer IPv4 address of a blocked SCTP link.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]PEERIPV4 in a BLKSCTPPEERIPV4 MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x (including 0.0.0.0).

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Add SCTP Peer IPv4 Address Block: VRFIDX:0, Peer IPv4 Address: 192.168.2.24;
ADD BLKSCTPPEERIPV4: VRFIDX=0, PEERIPV4="192.168.2.24";
