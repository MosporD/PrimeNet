Display ARP Table Entry (DSP ARP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the active Address Resolution Protocol (ARP) table entries of the system. An ARP table entry records mapping from the IP address of the peer port acquired by the BS to a MAC address.

Note

None.

Parameters

ID Name Description

GUI Value Range: 0~1

Unit: None

Example

To list the ARP entry with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, run the following command:
DSP ARP: CN=0, SRN=0, SN=7;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

VRF Index

Indicates the index of a VRF instance.

IP Address

Indicates the IP address in the ARP table.

MAC Address

Indicates the destination MAC address in the ARP table. The format is XXXX-XXXX-XXXX.

ARP Type

Indicates the type of ARP table, including the dynamic resolved ARP and dynamic ARP that is being resolved.

Age(min)

Indicates the remaining period before the ARP table becomes worn out.
