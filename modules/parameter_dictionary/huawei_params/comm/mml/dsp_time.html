Display Time (DSP TIME)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the current time of the NE.

Note

None.

Parameters

None.

Example

To query the time of the NE, run the following command:
DSP TIME:;
The result is shown as follows:
+++    0        2009-09-08 12:51:00 DST
O&M    #19
%%DSP TIME:;%%
RETCODE = 0  Operation succeeded.

Time Information
----------------
Time  =  2009-09-08 12:51:00 GMT+08:00 DST

---    END

Output Description

Field Description

Time

Indicates the current date and time of the NE. The query result is the local time of the NE, including the year, month, day, hour, minute, second, and time zone. If the DST of the NE is effective, the query result contains a DST flag (the flag used to indicate whether the DST is applied). The format is as follows: YYYY-MM-DD HH:MM:SS.
