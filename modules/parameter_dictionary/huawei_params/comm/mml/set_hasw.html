Set HA Switch (SET HASW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the switch for switchover between active and standby main control boards (referred to as HA switch).

Note

  • When the HA switch is turned off, switchovers cannot be performed between active and standby main control boards.

  • This command is applicable only when the active main control board is a UMPTe, UMPTg or UMPTga

  • The HA switch is turned on by default.

Parameters

ID Name Description
HASW HA Switch

Meaning: Indicates the HA switch. When this switch is turned off, switchovers cannot be performed between active and standby main control boards.

GUI Value Range: ON(ON), OFF(OFF)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To turn on the HA switch, run the following command:
SET HASW: HASW=ON;
