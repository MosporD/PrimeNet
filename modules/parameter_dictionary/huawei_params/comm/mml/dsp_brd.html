Display Board (DSP BRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a board.

Note

  • If the cabinet number, subrack number, or slot number is not specified, the information about boards contained in all cabinets, subracks, or slots is displayed.

  • The standby status of a UMPT, LMPT, or WMPT can be queried by running this command. The standby status of any other board is displayed as NULL.

  • Boards in a power distribution box (PDB) do not need to be configured.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When the UMPT and LMPT are configured in the same BBU subrack and same mode, the LMPT can only function as a transmission board for load sharing and cannot function as a standby main control board.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the subrack number of the board.

Slot No.

Indicates the slot number of the board.

Config Type

Indicates the type of a board.

SubBoard Type

Indicates the type of a subboard.

Administrative State

Indicates the administrative state of the board. The administrative state of the board can be blocked, unblocked, or shutting down. This parameter is valid only for baseband processing boards and RF modules, and the value of this parameter is NULL for all other types of boards.

Standby Status

Indicates the active, standby or slave status of the main control and transmission board. The active or standby status is available only to the main control and transmission board. This parameter for other types of board is set to NULL. When a board is in an abnormal state, Unknown is displayed.

Operational State

Indicates the operational state of the board, which can be set to Enabled or Disabled. Enabled indicates that services can be carried on the board. Disabled indicates that no service can be carried on the board.

Alarm Status

Indicates the alarm status of the board hardware, which can be set to Normal, Warning, Minor, Major, or Critical. The alarm status of the PSU, PDB, and BDU is in the alarm status of the PMU.

Availability Status

Indicates the physical status of a board, which can be Uninstalled, Starting up, Normal, Inconsistent, Unconfigured, Power off, Fault, Communication lost, In test, or the combination of multiple states. For example, if a board is not configured and fails to communicate with the main control and transmission board, the availability status of the board is "Unconfigured, Communication lost." If a board is under management of the peer end, the availability status of the board may be Starting up, Communication lost, or Fault.

WorkMode

Indicates the working mode of the board. the value SINGLEOM indicates that the GTMU works as the main control board and provides the main control, transmission, and RF port functions. The value EVOLUTION indicates that the GTMU works as the evolved board and provides the transmission and RF port functions. NORMAL indicates that the main control and transmission board works in normal mode. TDS-EVOLUTION indicates that the main control and transmission board works in TDS evolution mode. NULL is displayed for boards other than GTMU or when the working mode cannot be queried.
