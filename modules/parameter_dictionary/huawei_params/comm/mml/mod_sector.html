Modify Sector (MOD SECTOR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the name and location name of a sector. You can also use this command to add antennas to or remove antennas from this sector.

Note

The sector antenna referred by a set of sector equipment cannot be removed.

LOCATIONNAME Location Name

Meaning: Indicates the location name of the base station. Generally, the LocationName parameter is set to the same value for all sectors in an RF site, and base station can acquire the location information of RF modules through this parameter. However, if the LocationName parameter of the RF module is set in the RRU or AAS MO, the base station will acquire the location information of RF modules through the RRU or AAS MO.

ANTAZIMUTH Antenna Azimuth

Meaning: Indicates the azimuth of the sector antenna main lobe, which is an angle rotating clockwise from the due north to the direction of the sector antenna main lobe. For example, this parameter is set to 0 for the due north and to 900 for the due east (the unit is 0.1 degrees). This parameter is only for directional antennas. The value 65535 indicates that this parameter is invalid.

ANTNUM Antenna Number

Meaning: Indicates the number of antennas to be added to or removed. In the ADD SECTOR command, the default operation mode is adding antennas. In the MOD SECTOR command, whether to add or remove antennas depends on the operation mode.
