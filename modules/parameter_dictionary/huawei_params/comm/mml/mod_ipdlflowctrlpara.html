Modify IP Downlink Flow Control Para (MOD IPDLFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify the parameters of the IP downlink flow control algorithm.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]When Min Fair Protection Ratio is set to 100%, UMTS services may occupy all transmission bandwidth. In this case, services of other modes will have a low transmission rate, or even be interrupted.

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

SWITCH Flow Control Switch

Meaning: Indicates the switch for the IP DL flow control algorithm. If this parameter is set to STATIC_BW_SHAPING, the available HSDPA bandwidth equals the total bandwidth minus the R99 bandwidth. If this parameter is set to DYNAMIC_BW_SHAPING, flow allocation for HSDPA users is performed according to the delay and packet loss of the transmission interface board in STATIC_BW_SHAPING mode. This function requires the network controller using the 3GPP R6 protocol. Therefore, you are advised to use this function with the RNC that complies with the 3GPP R6 protocol. If this parameter is set to NO_BW_SHAPING, the BS does not allocate bandwidth according to the configuration and delay of the transmission interface board. The BS reports the air interface conditions to the controller, and then the controller allocates bandwidth. When this parameter is set to NO_BW_SHAPING, the backpressure function must be enabled on the controller side. If this parameter is set to BW_SHAPING_ONOFF_TOGGLE, the BS automatically selects either DYNAMIC_BW_SHAPING or NO_BW_SHAPING during a flow control congestion detection on a port. That is, DYNAMIC_BW_SHAPING is selected if congestion is detected; NO_BW_SHAPING is selected if congestion is not detected for a certain period of time.

GUI Value Range: STATIC_BW_SHAPING(STATIC_BW_SHAPING), DYNAMIC_BW_SHAPING(DYNAMIC_BW_SHAPING), NO_BW_SHAPING(NO_BW_SHAPING), BW_SHAPING_ONOFF_TOGGLE(BW_SHAPING_ONOFF_TOGGLE)

Unit: None

Actual Value Range: STATIC_BW_SHAPING, DYNAMIC_BW_SHAPING, NO_BW_SHAPING, BW_SHAPING_ONOFF_TOGGLE

MML Default Value: None

Recommended Value: BW_SHAPING_ONOFF_TOGGLE(BW_SHAPING_ONOFF_TOGGLE)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The setting of this parameter affects KPIs. For details, see the meaning of this parameter.

Applicable Mode: G, U
TD Delay Variation Noise Floor Threshold

Meaning: Indicates the background noise threshold of the delay jitter above which the IP DL flow control algorithm is enabled. A link is considered to be non-congested if the delay jitter on the link is below the threshold.

GUI Value Range: 0~100

Unit: 5ms

Actual Value Range: 0~500, step: 5

MML Default Value: None

Recommended Value: 4

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If the delay jitter of the link is less than or equal to the value of this parameter, the bandwidth is not adjusted.

If the delay jitter of the link is greater than the value of this parameter, the bandwidth is adjusted based on the user configuration.

Applicable Mode: G, U
DR Frame Loss Rate Threshold

Meaning: Indicates the port frame loss rate threshold of the IP DL flow control algorithm switch. When the frame loss rate is less than or equal to this threshold, the base station determines that the link is not congested.

GUI Value Range: 0~1000

Unit: per mill

Actual Value Range: 0~1000

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the frame loss rate is smaller than or equal to the value of this parameter, bandwidth adjustment is not performed.

When the frame loss rate is greater than the value of this parameter, bandwidth adjustment is performed based on the user configuration.

Applicable Mode: G, U
ITM Transmission Mode

Meaning: Indicates the transport mode of the port.

GUI Value Range: TERRESTRIAL(TERRESTRIAL), SATELLITE(SATELLITE)

MML Default Value: None

When this parameter is set to SATELLITE, the network has high tolerance of frame loss rate, delay, and jitter.

Applicable Mode: G, U
DLFLOWCTRLENHSW Downlink Flow Control Enhancement Switch

Meaning: Indicates the switch for controlling the enhanced IP downlink flow control feature. When the switch is set to on, the enhanced downlink flow control prevents downlink available bandwidth from sharply decreasing and downlink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

The enhanced downlink flow control feature requires the downlink FPDT IP GPM detection results. Before using this feature, run the ADD IPGPM or MOD IPGPM command to enable the downlink FPDT IP GPM detection function for the NodeB.

This switch can be configured only when flow control is set to dynamic flow control or self-selection flow control.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: OFF(Off)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this parameter is set to ON, the cell supports the enhanced HSDPA traffic control. This feature improves the downlink throughput of the cell when packet loss occurs due to bit errors in the transport network.

When this parameter is set to OFF, the network is not affected.

Applicable Mode: G, U
BWPRTSWITCH Bandwidth Adjustment Protection Switch

Meaning: Indicates the adjustment protection switch for the IP available DL bandwidth. When this parameter is set to ON, the BS stops adjusting the available DL bandwidth of the physical port if bit error occurs on the transmission line and the bit error rate (BER) exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
FAIRSWITCH Fair Flow Control Switch

Meaning: Indicates the switch for the IP downlink fairness flow control. If multiple modes share transmission bandwidth and congestion occurs, the UMTS data rate may decrease due to downlink flow control and the LTE data rate may increase due to bandwidth preemption when the Flow Control Switch parameter is set to DYNAMIC_BW_SHAPING or is set to BW_SHAPING_ONOFF_TOGGLE but actually takes effect using the DYNAMIC_BW_SHAPING value. When this switch is turned on, the system guarantees the minimum downlink transmission bandwidth of the UMTS mode. This switch applies only to Ethernet ports, Ethernet trunks, and loop interfaces with Port Type set to ETH or ETHTRK.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
FAIRRATIO Minimum Fair Flow Control Protection Ratio

Meaning: Indicates the minimum protection ratio of IP downlink fairness flow control. When the fairness flow control switch is turned on whereas the flow control is based on unfairness, the system guarantees the minimum UMTS transmission bandwidth based on the value of this parameter.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U
DLIUBMINBW Minimum DL Available Bandwidth of Logical Port

Meaning: Indicates the minimum DL bandwidth of a logical port.

GUI Value Range: 0~1000000

Unit: kbit/s

Actual Value Range: 0~1000000

MML Default Value: None

Recommended Value: 600

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the transport network provides small available bandwidth over the physical port, congestion on the transport network causes the bandwidth to fail to decrease and therefore packets are discarded and the bandwidth is not effectively used if the parameter is set to a large value. When the transport network provides large available bandwidth over the physical port, incorrect bandwidth adjustment decreases system capacity if packets are discarded due to error codes or other exceptions occur during the transmission.

Applicable Mode: G, U
DLIUBBWMINPRORATIO Min DL BW Protection Ratio of Iub Interface

Meaning: Indicates the minimum ratio of reducing the available downlink bandwidth over the Iub interface.

GUI Value Range: 0~100

Unit: %

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When the available physical port bandwidth on the transmission network is small and the transmission network is congested, the larger the value of this parameter, the less the downlink bandwidth over the Iub interface is reduced. Insufficient bandwidth reduction will cause packet loss, affecting the bandwidth usage. When the available physical port bandwidth on the transmission network is large, and bit error, packet loss, or other exceptions occur on the transmission network, the smaller the value of this parameter, the more the downlink bandwidth over the Iub interface is reduced. Incorrect bandwidth reduction will severely affect the system capacity.

Applicable Mode: G, U

Example

To modify the IP downlink flow control algorithm with the parameters as follows: IP Downlink Flow Control Algorithm ID: 2, Port Type: ETH, Port ID: 1, Bandwidth Adjustment Protection Switch: ON, Minimum DL Available Bandwidth of Logical Port: 600, run the following command:
MOD IPDLFLOWCTRLPARA: IPDLFLOWCTRALGID=2, PT=ETH, PORTID=1, BWPRTSWITCH=ON, DLIUBMINBW=600;
