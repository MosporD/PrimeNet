Add Ethernet Trunk Member (ADD ETHTRUNKLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an Ethernet trunk link in the Ethernet trunk.

Note

  • Before running this command, ensure that the parent Ethernet trunk is configured.

  • If a port added to an Ethernet trunk works in AUTO negotiation mode, ensure that the port with a higher transmission rate has a higher priority.

  • Only four member ports in an Ethernet trunk on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 can take effect. Only two member ports in an Ethernet trunk on other boards can take effect.

  • Before adding an Ethernet trunk link, ensure that the associated Ethernet port has not joined any other Ethernet trunk.

  • All links contained in one Ethernet trunk must have the same rate and duplex mode. Therefore, before adding an Ethernet trunk link, ensure that its rate and duplex mode that take effect are the same as those of other links in the Ethernet trunk.

  • Before adding an Ethernet trunk link, ensure that the associated Ethernet trunk has only one primary port. The associated Ethernet trunk uses the MAC address which belongs to the Ethernet port configured as primary port.

  • Before adding an Ethernet trunk link to an Ethernet trunk as a secondary port, ensure that the Ethernet trunk has already been configured with a primary port.

  • System specifications: If the WMPT/UMPT/LMPT is the main control board, a maximum of 48 Ethernet trunk links can be configured. If the UMDU is the main control board, a maximum of 2 Ethernet trunk links can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 32 Ethernet trunk links can be configured.

  • Board specifications: A maximum of 2 Ethernet trunk links can be configured on a WMPT/UMPTa/UMPTb/UMDU/LMPT. A maximum of 4 Ethernet trunk links can be configured on a UMPTe/UMPTg/UMPTga. A maximum of 6 Ethernet trunk links can be configured on a UTRPc. A maximum of 2 Ethernet trunk links can be configured on a UTRP (subboard type: UEOC). A maximum of 4 Ethernet trunk links can be configured on a UTRP (subboard type: UQEC). A maximum of 4 Ethernet trunk links can be configured on a UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPf1/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • An ETHTRUNKLNK MO cannot be configured when an ETHPORT MO has a default port IP transmission resource group, to configure an ETHTRUNKLNK MO, remove the default port IP transmission resource group and algorithm. This limitation does not take effect on an adaptive port IP transmission resource group.

  • An Ethernet trunk takes effect when a member port is added to the Ethernet trunk. When a member port is added to an Ethernet trunk, if the dependent Ethernet trunk fails to take effect, the member port also fails to take effect.

Parameters

ID Name Description
ETHTRKPORTID Ethernet Trunk Port ID

Meaning: Indicates the ID of the Ethernet trunk to which an Ethernet trunk member port belongs.

GUI Value Range: 0~23

Unit: None

Actual Value Range: 0~23

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ETHTRUNKLNKID Ethernet Trunk Link ID

Meaning: Indicates the ID of an Ethernet trunk member port. This parameter value must be unique at the system level.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ETHPORTID Ethernet Port ID

Meaning: Indicates the Ethernet port ID associated with an Ethernet trunk member port.

GUI Value Range: 0~9999

Unit: None

Actual Value Range: 0~9999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PRI Port Priority

Meaning: Indicates the priority of the member port in an Ethernet trunk. A smaller parameter value indicates a higher priority.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: 255

Recommended Value: 255

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
FLAG Master Port Flag

Meaning: Indicates whether the member port is the primary port of an Ethernet trunk. Each Ethernet trunk has only one primary port. The primary port must be the first port added to an Ethernet trunk and the last port removed from the Ethernet trunk.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To add a member port to an Ethernet trunk with the parameters as follows: Ethernet Trunk Port ID: 2, Ethernet Trunk Link ID: 0, Ethernet Port ID: 6, Port Priority: 255, Master Port Flag: Yes, run the following command: 
ADD ETHTRUNKLNK: ETHTRKPORTID=2, ETHTRUNKLNKID=0, ETHPORTID=6, PRI=255, FLAG=YES;
