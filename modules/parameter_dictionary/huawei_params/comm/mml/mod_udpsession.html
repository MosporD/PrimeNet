Modify UDP Session (MOD UDPSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configuration of a UDP session.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before modifying a UDP session, ensure that the local IP address is the configured DEVIP or IPADDR4 or the local IP address of PPPLNK or MPGRP.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before modifying a UDP session, ensure that the peer IP address is not the configured DEVIP or IPADDR4 in the same routing domain, the local IP address of PPPLNK or MPGRP, the IP address of the proximal maintain or the local IP address of OMCH.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If a UDP session is bound to a remote maintenance channel, modifying the UDP session may interrupt the remote maintenance channel.

Example

To modify the configuration of the UDP session with the parameters as follows: UDP Session ID: 0, UDP Session Group ID: 0, Cabinet No.: 0, Subrack No.: 0: Slot No.: 6, Local IP Address: 172.16.177.2, Peer IP Address: 172.16.177.3, DSCP: 50, Interval: 3, Check Count: 3, run the following command: 
MOD UDPSESSION: UDPSN=0, UDPSESSIONGRPID=0, CN=0, SRN=0, SN=6, LOCALIP="172.16.177.2", PEERIP="172.16.177.3", DSCP=50, INTERVAL=3, CHECKCOUNT=3;
