Remove Subnet VLAN Mapping (RMV SUBNETVLAN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a subnet VLAN mapping relationship.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Running this command leads to interruption of service flow in the VLAN network.

  • This operation may interrupt the services or OM channels that rely on this VLAN ID. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
IP IP Address

Meaning: Indicates the source IP address used for mapping the VLAN.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the SUBNETVLAN MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 127.x.x.x or 0.x.x.x.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MASK Mask

Meaning: Indicates the subnet mask of the source IP address used for mapping the VLAN.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: 255.255.255.255

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MASK in the SUBNETVLAN MO must be 255.255.255.255.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove a subnet VLAN mapping with the parameters as follows: IP Address: 192.168.1.24, Mask: 255.255.255.255, run the following command:
RMV SUBNETVLAN: IP="192.168.1.24", MASK="255.255.255.255";
