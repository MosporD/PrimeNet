Modify Source IP Route (MOD SRCIPRT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a source IP route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifying parameters of a route except User Label may intermittently interrupt or disconnect the services or OMCH that is carried on this route.

Meaning: Indicates the index of the source IP route.

Disuse statement: This parameter will be deleted in later versions. Therefore, avoid using this parameter.

RTTYPE Route Type

Meaning: Indicates the type of the source IP route. NEXTHOP means that all IP packets that meet the route direction are first forwarded to the specified next hop IP address. IF means that all IP packets that meet the route direction are first forwarded to the specified egress port.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Route Type parameter in the SRCIPROUTE4 MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Parameter Relationship:

-Configuration constraints:

  • [gNodeB]If the value of RTTYPE in an SRCIPRT MO is set to IF, the value of IFT cannot be set to MPGRP.

-Others:

  • In an SRCIPRT MO, this parameter must be set to IF if SBT is set to E1_COVERBOARD.
  • In an SRCIPRT MO, this parameter can be set to NEXTHOP or IF if SBT is set to BASE_BOARD.
  • In an SRCIPRT MO, this parameter must be set to IF if SBT is set to BACK_BOARD.

Example

To modify the parameter settings of the source IP route with the parameters as follows: Source Route Index: 0, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Source IP Address: 192.168.10.1, Route Type: NEXTHOP, Next Hop IP: 192.168.10.20, Priority: 10, User Label: 1234, run the following command:
MOD SRCIPRT: SRCRTIDX=0, CN=0, SRN=0, SN=6, SBT=BASE_BOARD, SRCIP="192.168.10.1", RTTYPE=NEXTHOP, NEXTHOP="192.168.10.20", PREF=10, USERLABEL="1234";
