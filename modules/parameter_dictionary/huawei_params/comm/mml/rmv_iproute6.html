Remove IPv6 Route (RMV IPROUTE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a static IPv6 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,eNodeB,gNodeB]Running this command leads to interruption of services and maintenance channel depending on the IP route. It is recommended that you enable the automatic configuration data rollback function based on situations. For details, see the help description for the CFM CB command.

  • [Co-MPT,eNodeB,gNodeB]A route that is already configured can be removed.

Parameters

ID Name Description
RTIDX Route Index

Meaning: Indicates the index of a static IPv6 route. The value of RTIDX in the IPROUTE6 MOs configured by users ranges from 0 to 127. The value of RTIDX in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~127,10000~19999

Unit: None

Actual Value Range: 0~127,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If RTIDX is set to a value in the range of 0 to 127, CTRLMODE must be set to MANUAL_MODE. If RTIDX is set to a value in the range of 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether a forcible change of an IPv6 route is made. When this parameter is set to NO(No), the system checks whether the change affects upper-layer services. If the change affects upper-layer services, the forcible change will fail. When this parameter is set to YES(Yes), the system does not check whether the change affects upper-layer services. Upper-layer services include the following: active OM channel (OMCH), DNS service (DNSSRV), security link (IKEPEER), certificate authority (CA), CRL update (CRLTSK), IP clock link (IPCLKLINK), NTP (NTPC), Abis CP/Iub CP/S1 CP/X2 CP/M2 CP/ECO CP/eX2 CP/SO CP/uX2 CP/Xw CP/gNBCUX2 CP/gNBCUNg CP/gNBCUXn CP (SCTPLNK/SCTPPEER), and Abis UP/IP path of an unknown service type/Iub UP/uX2 UP/S1 UP/X2 UP/eX2 UP/Xw UP/gNBCUX2 UP/gNBCUS1 UP/gNBCUNg UP/gNBCUXn UP (USERPLANEPEER).

Pay attention to the following when using this parameter:

1. The system checks whether a forcible change affects upper-layer services based on the configuration data instead of based on the actual running status of these services.

2. If an NE is configured with an SRCIPROUTE6 MO, the system does not check whether a forcible change of an IPv6 route affects upper-layer services.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To remove a static IPv6 route with the parameters as follows: RTIDX: 0, run the following command:
RMV IPROUTE6: RTIDX=0;
