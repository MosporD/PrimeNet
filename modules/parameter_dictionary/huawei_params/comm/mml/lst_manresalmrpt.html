List Manually Cleared Alarm Reporting Switch (LST MANRESALMRPT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Used to query the switch for reporting manually cleared alarms again.

Note

None.

Parameters

None.

Example

Querying the configuration of the manually cleared alarms reporting switch, run the following command:
LST MANRESALMRPT:;
The result is shown as follows:
+++    0        2016-02-27 20:01:27
O&M    #610
%% LST MANRESALMRPT:;%%
RETCODE = 0  Operation succeeded.

Manually Cleared Alarms Reporting Switch
----------------------------------------
Switch = Off
(Number of results = 1)


---    END

Output Description

Field Description

Switch

Indicates the switch for reporting manually cleared alarms again.
