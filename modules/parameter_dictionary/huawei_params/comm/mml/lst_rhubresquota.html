List RHUB Resource Quota Configuration (LST RHUBRESQUOTA)

Network Element: BTS3900, BTS5900

Function

Use this command to list configuration of RHUB resource quotas.

Note

None.

Parameters

ID Name Description
RHUBRESQUOTAID RHUB Resource Quota ID

Meaning: Indicates the quota ID of RHUB resources.

GUI Value Range: 0~31

Unit: None

Actual Value Range: 0~31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: R, N

Example

Example 1: To list the configuration of all RHUB Resource Quota, run the following command:
LST RHUBRESQUOTA:;
+++    0      
O&M    #805306427
%%LST RHUBRESQUOTA:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

RHUB Resource Quota ID

Indicates the quota ID of RHUB resources.

RCS Client No.

Indicates the number of the client NE to which the quota is allocated.

RF Combination Capacity

Indicates the number of cells that use RF combination.

Inter-RHUB RF Combination Capacity

Indicates the number of cells that use inter-RHUB RF combination.

RHUB Scope

Indicates the scope of RHUBs to which the quota is allocated.

Cabinet No.

Indicates the number of the cabinet that houses the RHUB.

Subrack No.

Indicates the number of the subrack that houses the RHUB.

Slot No.

Indicates the number of the slot that houses the RHUB.
