List AAS Configuration (LST AAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the Active Antenna System (AAS) configuration.

Note

None.

To list the configuration of all AASs, run the following command:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the AAS is located.

Subrack No.

Indicates the number of the subrack where the AAS is located.

AAS Name

Indicates the AAS name.

Topo Position

Indicates the position where the AAS is installed in the topology.

AAS Chain No.

Indicates the ID of an RRU chain/ring which the AAS is inserted in.

AAS Position

Indicates where the AAS is inserted in an RRU chain/ring. It is calculated from the start port one by one.

AAU Specification

Indicates the type of an AAS. This parameter must be set to the hardware type of the AAS. After this parameter is specified, the MAE-Deployment checks the configurations of power, carrier, and receive and transmit capabilities based on the value of this parameter. This ensures that these configurations are correct before they take effect. If the user does not need to forcibly verify the AAS specifications using the MAE-Deployment, this parameter can be left unspecified. Leaving this parameter unspecified has no impact on the base station. For example, this parameter must be set to AAU3902 for AAU3902.

Location Name

Indicates the location information of an AAS. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. LocationName must be set to the same value for RF modules serving the same sector.
