List ModelSelect (LST MODELSELECT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the selection of models.

Note

None.

Parameters

None.

Example

To list the selection of models, run the following command:
LST MODELSELECT:;
The result is shown as follows:
+++    0        2016-10-29 15:51:40
O&M    #3121
%%LST MODELSELECT:;%%
RETCODE = 0  Operation succeeded.

----------------

Output Description

Field Description

Model Select

Indicates which transmission configuration MOs and parameters are to be used. When the system supports extended NEs or when the OM model must be consistent with that of extended NEs, set this parameter to HOSTGW(Host-Gateway Mode). In other scenarios, set this parameter to TRADITION(Traditional Mode) (default value).

When Transmission Configuration Mode is set to OLD(Old):

The following MOs or parameters are controlled in traditional mode:

- DEVIP MO

- Resource Group Scheduling Weight Switch, Rate Config Type, Switch Back Time, ARP Aging Time, Ping Filter Mode, Number of Packets Discarded Due to Fragmentation Failures, Ethernet OAM Type, Monitor Policy, IP Frame Error Rate Alarm Switch, IP Frame Error Rate Occur Threshold, IP Frame Error Rate Clear Threshold, Forward Mode, Same Port Forward Switch, and Port Mode Auto Switch in the GTRANSPARA MO

- IP Clock Priority in the DIFPRI MO

- Physical Port Up Link OverBooking Switch, Physical Port Down Link OverBooking Switch, Physical Port Up Link Admission Switch, and Physical Port Down Link Admission Switch in the TACALG MO

Only in traditional mode, a non-loopback DEVIP MO can be configured and the preceding parameters in other MOs can take effect.

The IFIP and GTRANSPARAGW MOs are controlled in host-gateway mode. Only in this mode, an IFIP MO can be configured and the parameters in the GTRANSPARAGW MO can take effect.

After this parameter value is modified, the NE must be reset to validate the controlled parameters.

When Transmission Configuration Mode is set to NEW(New), the DEVIP and IFIP MOs are no longer controlled. Other controlled MOs and parameters are the same as those when Transmission Configuration Mode is set to OLD(Old).
