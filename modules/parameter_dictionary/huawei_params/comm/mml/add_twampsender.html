Add TWAMP Sender (ADD TWAMPSENDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a TWAMP sender.

Note

  • TWAMP uses intrusive measurement. A TWAMP sender actively sends packets to perform the intrusive measurement, which consumes the bandwidth.

  • Board specifications: A UMPTe/UMPTg/UMPTga supports a maximum of 32 TWAMP senders, and an LMPT/UMPTa/UMPTb/UMDU/WMPT/GTMUc/UTRPc/UCCU/UBBPe (except UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 supports a maximum of 16 TWAMP senders.

  • System specifications: When a WMPT/LMPT is used as the main control board, the base station supports a maximum of 16 TWAMP senders. When a UMPTa/UMPTb/UMDU is used as the main control board, the base station can be configured with a maximum of 32 TWAMP senders, but only 16 TWAMP senders of them take effect. When a UMPTe/UMPTg/UMPTga is used as the main control board, the base station supports a maximum of 32 TWAMP senders.

  • The value of Light Architecture Mode must be the same as that of the corresponding parameter on the responder. Otherwise, the local packet loss rate will be abnormal.

Example

To add a TWAMP Sender with the parameters as follows: Client Index: 0, Sender Index: 0, TWAMP Architecture: Full Architecture, DSCP: 48, Packet Size Type: FIXED, Packet Send Interval Type: FIXED, run the following command: 
ADD TWAMPSENDER: CLIENTID=0, SENDERID=0, TWAMPARCH=FULL, DSCP=48, PKTSIZETYPE=FIXED, PKTINTTYPE=FIXED;
