Set Clock Class Identify Flag (SET CLASSIDENTIFY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the flag for the priority clock class of the IP clock link. If the IP clock link complies with the Precision Time Protocol (PTP) but the peer clock server does not support standardized priority clock classes, you can run this command to set the identifier for the priority clock class to OFF. This command is only valid for 1588 OC_SLAVE.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If two OC_SLAVE IP clock links in compliance with IEEE 1588 V2 are configured, modification of the Priority Clock Class Identify Flag parameter takes effect for both the links.

  • Modifications on the Priority Clock Class Identify Flag parameter are valid only when the Profile Type parameter is set to 1588V2 or 1588V2_16.1.

  • If Priority Clock Class Identify Flag is set to ON and the clock quality level of the IP server is beyond the priority clock class range, the IP clock will become unavailable.

Parameters

ID Name Description
LN Link No.

Meaning: Indicates the number of the IP clock link.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the IPCLKLNK MO, when the value of DEVTYPE is set to OC_SLAVE, the value of LN must be 0 or 1. When the value of DEVTYPE is set to OC_MASTER, the value of LN must be 2.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
CLASSIDENTIFY Priority Clock Class Identify Flag

Meaning: Indicates whether the BMC (Best Master Clock) algorithm is enabled or not. ON indicates that the BMC algorithm is enabled, and OFF indicates that the BMC algorithm is disabled.

GUI Value Range: OFF, ON

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON

Recommended Value: ON(ON)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set the flag for the priority clock class to ON, run the following command:
SET CLASSIDENTIFY: CLASSIDENTIFY=ON;
