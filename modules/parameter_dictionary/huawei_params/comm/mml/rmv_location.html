Remove Location (RMV LOCATION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to delete a record of the location.

Note

None.

Parameters

ID Name Description
LOCATIONNAME Location Name

Meaning: Indicates the location name of the base station.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove the location information with the parameter as follows: LOCATIONNAME: "hangzhou_NODE_ONE", run the following command:
RMV LOCATION: LOCATIONNAME="hangzhou_NODE_ONE";
