List LLDP Global Configuration Info (LST LLDPGLOBALINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list global LLDP configurations of a board.

Note

None.

Parameters

None.

Example

To query the configuration of LLDP global information, run the following command: 
LST LLDPGLOBALINFO:;
The result is shown as follows:
+++    0        2012-11-28 13:26:24
O&M    #559
%%LST LLDPGLOBALINFO:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

LLDPDU Tx Interval(s)

Indicates the interval at which the local end sends LLDP packets to neighboring nodes. If the status of the local LLDP does not change, the interface module of the LLDP port sends LLDP packets to neighboring nodes at a regular interval specified by this parameter. The network topology discovery frequency can be adjusted by changing the setting of this parameter.

LLDP Hold Multiplier

Indicates a multiple of the time period during which the local LLDP information is stored in neighboring nodes. The time period (time to live, TTL for short) during which the local LLDP information is stored in neighboring nodes is calculated with the following formula:

TTL = Min(65535,(TXINTVAL×HOLDMULTI)+1)

That is, TTL is the smaller one of 65535 and (TXINTVAL×HOLDMULTI)+1. The validity period (TTL) of storing the local LLDP information in neighboring nodes can be adjusted by changing the value of this parameter. After a neighboring node receives an LLDP packet, it updates the information aging time of the transmit end based on this validity period. If the value of TTL is 0, the receive end needs to remove the LLDP information about the transmit end immediately.

Reinit Delay(s)

Indicates the delay in reinitializing the LLDP state machine when the interface LLDP module state is changed from RxTx or Tx to Rx or Disabled. Interface LLDP modules have four states: transmit and receive state (RxTx), transmit state (Tx), receive state (Rx), and neither transmit nor receive state (Disabled). When the interface LLDP module state changes, the interface LLDP module state machine needs to be reinitialized. When the interface LLDP module state changes from RxTx or Tx to Rx or Disabled, the system needs to wait for a period specified by this parameter before reinitializing the internal state machine. By default, the interface LLDP modules of the system are in the RxTx state and the state cannot be changed.

Transmission Delay(s)

Indicates the delay in transmitting LLDP packets. This parameter specifies the minimum delay for an interface LLDP module to send LLDP packets to neighboring nodes after the LLDP module discovers a new neighboring node. Under normal conditions, an interface LLDP module sends LLDP packets to neighboring nodes at an interval. When the LLDP module discovers a new neighboring node, the local end enters the fast transmit mode and the system sends LLDP information to neighboring nodes at an interval specified by this parameter. The state of the local interface LLDP module becomes normal only after the local interface LLDP module has sent LLDP information to neighboring nodes for four consecutive times. If the LLDP module discovers another new neighboring node in the fast transmit mode, the system immediately sends LLDP packets to neighboring nodes and then continues sending LLDP packets at the interval specified by this parameter until this fast transmit ends.

LLDP Notify Switch

Indicates whether to report LLDP change events to the network management system. When this switch is turned on and the network management system has subscribed to LLDP change events, the system reports LLDP change information to the network management system if the local or neighboring LLDP information changes. The purpose is to instruct the network management system to update network topology information. When the system changes from the state that the system does not need to report LLDP change events to the network management system (that is, this switch is turned off or the network management system has not subscribed to LLDP change events) to the state that the system needs to report LLDP change events (that is, this switch is turned on and the network management system has subscribed to LLDP change events), the system immediately reports all the current local and neighboring LLDP information to the network management system. The parameters set by running this command take effect for the whole base station, that is, the parameter settings control the capabilities of all LLDP ports to send LLDP change events.

Notify Interval(s)

Indicates the minimum delay in reporting a neighboring LLDP information change notification to the element management system (EMS) by the base station when LLDP Notify Switch is set to ENABLE and the EMS subscribes the LLDP information change notification. This delay takes effect only for such neighboring LLDP information change events as adding, removing, and aging a neighboring node. If neighboring LLDP information changes frequently, this parameter can be set to a large value to reduce the frequency of sending neighboring LLDP information to the network management system and minimize network topology flapping.

LLDP Port Configuration Mode

Indicates the configuration mode of all LLDP ports. When this parameter is set to MANUAL, LLDP ports must be manually configured. When this parameter is set to AUTO, LLDP ports are automatically generated by the system. When the value of this parameter is changed from AUTO to MANUAL, the automatically generated LLDP ports are removed by the system.
