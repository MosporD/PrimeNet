Display RET Port (DSP RETPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a remote electrical tilting (RET) port.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the RRU where the RET port is located.

GUI Value Range: 0~15

Unit: None

GUI Value Range: 60~254

Example

To query the dynamic information about the RET port with the parameters as follows: Cabinet No.: 0, Subrack No.: 63, Slot No.: 0, Port No.: RET_PORT, run the following command:
DSP RETPORT: CN=0, SRN=63, SN=0, PN=RET_PORT;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU where the RET port is located.

Subrack No.

Indicates the subrack number of the RRU where the RET port is located.

Slot No.

Indicates the slot number of the RRU where the RET port is located.

Port No.

Indicates the number of the RET port on an RRU. This parameter is set to RET_PORT.

ALD Actual Power Switch

Indicates the actual status of the ALD power supply switch, which can be set to ON or OFF. ON indicates that this switch is set to on and OFF indicates that this switch is set to off.

ALD Current Value(mA)

Indicates ALD current value. Value NULL indicates that this parameter fails to be queried or the ALD Actual Power Switch is OFF.
