Modify MPT Configurations (MOD MPT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify MPT configurations.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the main control and transmission board.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the main control and transmission board.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a base station configured with an EXTCONNPORT MO, TYPE in an MPT MO must be set to UMPT.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]For a base station configured with an RCSSERVER MO, TYPE in an MPT MO must be set to UMPT.
  • [Co-MPT, NodeB, eGBTS, eNodeB]For a base station configured with an RFC MO, TYPE in an MPT MO must be set to UMPT.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the main control and transmission board.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
BRDSPEC Board Specification

Meaning: Indicates the type of a board. If this parameter is not specified, the base station and MAE-Deployment check board configurations based on the maximum specifications of a configured board. If this parameter is specified, the base station and MAE-Deployment check board configurations based on the specifications of the specified board so that the MAE-Deployment can identify incorrect configurations before delivering configurations to the base station. This parameter must be specified based on the actual hardware type of the board. For example, if the hardware type of a board is UMPTa, this parameter can be set to UMPTa or UMPTa/b. If the hardware type of a board is UMPTb, this parameter can be set to UMPTb or UMPTa/b. If the configured type of a board is WMPT or LMPT or this parameter is not specified, the value of this parameter is NULL. The values are case insensitive.

GUI Value Range: 0~15 characters

Unit: None

Actual Value Range: 0~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the MPT MO is UMPT, the value of BRDSPEC in the MPT MO must be UMPTa, UMPTb, UMPTa/b, UMPTe, UMPTg, UMPTga(case insensitive), or null.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the MPT MO is not UMPT, the value of BRDSPEC in the MPT MO must be null.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in the SUBRACK MO housing the MPT MO is set to BBU5900A, SN in the MPT MO must be set to 6.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an MPT MO, if the values of TYPE and BRDSPEC are UMPT and UMPTg (case insensitive), respectively, the type of the subrack specified by SRN must not be BBU3900 or BBU3900-1U.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If TYPE in an MPT MO is set to UMPT and BRDSPEC in the MPT MO is set to UMPTga (case-insensitive), the type of the subrack identified by SRN cannot be set to BBU3900-1U.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the SUBRACK MO housing the MPT MO is set to BBU5900A, TYPE in the MPT MO must be set to UMPT. In addition, BRDSPEC in the MPT MO must be set to UMPTe, UMPTg, or UMPTga (case-insensitive) or left blank.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When BRDASSIGNMENT in the BRDRESASSIGNMENT MO is set to MODE2, any of the following conditions must be met:
  • 1. If AT in the APPLICATION MO is set to eNodeB and WM in the NODE MO is set to NON-CONCURRENT, BRDASSIGNMENT in the MPT MO is set to MODE2.
  • 2. When WM in the NODE MO is set to CONCURRENT, WMEXTENSION is set to COMM2, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTe (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 3. When WM in the NODE MO is set to CONCURRENT, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTg, or UMPTga (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTg, or UMPTga (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 4. When WM in the NODE MO is set to CONCURRENT, WMEXTENSION is set to COMM2, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • 5. When WM in the NODE MO is set to CONCURRENT, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTg, or UMPTga (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) is set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When AT in the APPLICATION MO is set to eNodeB, WM in the NODE MO is set to NON-CONCURRENT, the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) is configured in different subracks with the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), and the MPT MO with BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) acts as the master main control board, then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) cannot be set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When AT in the APPLICATION MO is set to eNodeB, WM in the NODE MO is set to NON-CONCURRENT, and the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTe, UMPTg, or UMPTga (case insensitive) is configured in the same subrack as the MPT MO with TYPE set to UMPT and BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive), then BRDASSIGNMENT corresponding to the MPT MO with BRDSPEC set to UMPTa, UMPTb, or UMPTa/b (case-insensitive) cannot be set to MODE2.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an MPT MO, if TYPE is set to UMPT and BRDSPEC is set to UMPTga (case-insensitive), BRDASSIGNMENT in the BRDRESASSIGNMENT MO must be set to MODE1.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If the value of TYPE in the GTMU MO is GTMU, the value of BRDSPEC in the GTMU MO must be GTMUb, GTMUc(case insensitive), or null.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the configuration of the MPT with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, BRDSPEC: UMPTe, run the following command:
MOD MPT: CN=0, SRN=0, SN=7, BRDSPEC="UMPTe";
