Display IPv6 Route Table (DSP IPROUTE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the IPv6 routing table.

Note

[Co-MPT,eNodeB,gNodeB]The IPv6 route index cannot be used to query a single manually configured route that does not take effect.

Parameters

ID Name Description
RTIDX Route Index

Meaning: Indicates the index of a static IPv6 route. The value of RTIDX in the IPROUTE6 MOs configured by users ranges from 0 to 127. The value of RTIDX in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~127,10000~19999

Unit: None

Actual Value Range: 0~127,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]If RTIDX is set to a value in the range of 0 to 127, CTRLMODE must be set to MANUAL_MODE. If RTIDX is set to a value in the range of 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

To query the IPv6 routing table, run the following command:
DSP IPROUTE6:;

Output Description

Field Description

Route Index

Indicates the index of a static IPv6 route. The value of RTIDX in the IPROUTE6 MOs configured by users ranges from 0 to 127. The value of RTIDX in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.

VRF Index

Indicates the index of a VRF instance.

Destination IPv6 Address

Indicates the destination IPv6 address of a static IPv6 route.

Prefix Length

Indicates the prefix length of the destination IPv6 address of a static IPv6 route.

Route Type

Indicates the type of IPv6 route. If this parameter is set to NEXTHOP, all the IP packets that meet the route direction are first forwarded to the specified next-hop IPv6 address. If this parameter is set to IF, all the IP packets that meet the route direction are first forwarded to the specified egress port.In IPv6 secure encryption and decryption scenarios, the outbound tunnel interface for incoming packets must be specified.

Next-Hop IPv6 Address

Indicates the next-hop IPv6 address of a static IPv6 route.

Interface ID

Indicates the ID of the IPv6 interface to which a static IPv6 route belongs. The value of ITFID in the IPROUTE6 MOs configured by users ranges from 0 to 1499. The value of ITFID in the IPROUTE6 MOs configured by the system ranges from 10000 to 19999.

Preference

Indicates the priority of a static IPv6 route. A smaller parameter value indicates a higher priority.

Cabinet No.

Indicates the cabinet number of the board to which an IPv6 route belongs.

Subrack No.

Indicates the subrack number of the board to which an IPv6 route belongs.

Slot No.

Indicates the slot number of the board to which an IPv6 route belongs.

Actual Port Type

Indicates the type of the actual port.

Actual Port No.

Indicates the number of the actual port.

Route Protocol

Indicates the type of the static IPv6 route. A static host route is a manually configured route with a 128-bit prefix. A static gateway route is a manually configured route with a non-128-bit prefix, with the next hop IP address on a different network segment from the egress port IP address. A dynamic host route is a dynamically learned (not manually configured) route with a 128-bit prefix. A dynamic gateway route is a dynamically learned (not manually configured) route with a non-128-bit prefix, with the next hop IP address on a different segment from the egress port IP address.

Route Status

Indicates the status of an IPv6 route.
