List IPv6 Address Configuration (LST IPADDR6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configured IPv6 addresses.

Note

None.

Parameters

None.

Example

To list the configured IPv6 addresses, run the following command: 
LST IPADDR6:;
The result is shown as follows:
+++    0        2019-03-23 14:00:42
O&M    #3738
%%LST IPADDR6:;%%
RETCODE = 0  Operation succeeded.

List IPv6 Address Configuration
-------------------------------

   Interface ID  =  0
   IPv6 Address  =  2001:DB8::1
  Prefix Length  =  32
      VRF Index  =  0
     User Label  =  NULL
(Number of results = 1)


---    END

Output Description

Field Description

IPv6 Address ID

Indicates the IPv6 Address ID of an interface.

Interface ID

Indicates the interface number. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter indicates the interface number (0 to 1499) of the INTERFACE MO.

IPv6 Address

Indicates the IPv6 address.

Prefix Length

Indicates the length of the prefix of the IPv6 address, the prefix length of a loopback address is internally fixed to 128 bits.

VRF Index

Indicates the index of a VRF instance.

User Label

Indicates the user-defined information about an IPv6 address.
