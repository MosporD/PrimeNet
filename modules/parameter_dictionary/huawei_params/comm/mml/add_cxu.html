Add CXU (ADD CXU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a CXU to a specified RRU chain/ring.

Note

  • Before a CXU is added, an RRU chain/ring must be added by running the ADD RRUCHAIN command.

  • The CGPS supports the chain topology and cold backup ring topology only.

  • The RPCU supports the chain topology only.

  • If a CGPS or RPCU is to be added to the chain, the CGPS or RPCU must be located at the chain tail or any position behind the breakpoint.

  • If a CGPS is to be added to the cold backup ring, the CGPS can be located at any position between the two breakpoints if the configured breakpoints do not coincide. If the configured breakpoints coincide, the CGPS can be located only at the coincident position.

  • After a CGPS is added between two breakpoints on the cold backup ring, the value of the second breakpoint and the level of the board before the CGPS increase by 1 automatically.

  • After a CXU is added to an RRU chain/ring, the original board in a position farther than or same as the position of the newly added CXU is automatically moved backwards.

  • After a CXU is added, if links cannot be set up for the CXU or links cannot work at the highest CPRI line rate, run the STR CPRILBRNEG command to initiate negotiation.

  • If CXU Type is set to RMU, the RRU chain/ring supports only one level of RMUs. If CXU Type is set to CGPS, the RRU chain/ring supports a maximum of four levels of CGPSs.

  • The RMU supports the trunk chain topology only.

MNTMODE Maintenance Mode

Meaning: Indicates the maintenance mode of a CXU. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes. The default value of this parameter is Normal.

Example

To add a CXU with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, CXU Type: CGPS, Chain/Ring No.: 0, CXU Position: 0, run the following command:
ADD CXU: SRN=60, CXUTYPE=CGPS, PS=0, RCN=0;
