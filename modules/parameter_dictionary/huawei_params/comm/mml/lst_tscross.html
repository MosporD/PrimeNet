List Timeslot Cross Configuration (LST TSCROSS)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the configurations of all timeslot cross-connections.

Note

None.

Parameters

None.

Example

To list the timeslot cross-connection configuration, run the following command:
LST TSCROSS:;
The result is shown as follows:

O&M    #252

Output Description

Field Description

TS Cross No.

Indicates the number of a timeslot cross-connection.

Cabinet No.

Indicates the number of the cabinet that houses the board where timeslot cross-connections are established.

Subrack No.

Indicates the number of the subrack that houses the board where timeslot cross-connections are established.

Source Slot No.

Indicates the number of the slot that houses the board where the source ports of timeslot cross-connections are located.

Source Subboard Type

Indicates the type of sub-board on the board where the source ports of timeslot cross-connections are located.

Source Port No.

Indicates the number of the source port of a timeslot cross connection.

Source Time Slot No.

Indicates the number of the source timeslot of a timeslot cross connection.

Destination Slot No.

Indicates the number of the slot that houses the board where the destination ports of timeslot cross-connections are located.

Destination Subboard Type

Indicates the type of sub-board on the board where the destination ports of timeslot cross-connections are located.

Destination Port No.

Indicates the number of the destination ports of timeslot cross-connections.

Destination Time Slot No.

Indicates the destination timeslot of a timeslot cross-connection.

Description

Indicates the brief description about the timeslot cross connection.
