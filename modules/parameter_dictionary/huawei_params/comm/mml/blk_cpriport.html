Block CPRI Port (BLK CPRIPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to block a CPRI port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the CPRI port is blocked, the services carried by the boards on the RRU chain/ring which connects to the CPRI port are interrupted. Run the UBL CPRIPORT command to unblock the CPRI port.

  • The boards supporting block CPRI port include the BBP, UBRI, GTMU, UMDU, RHUB and RMU.

  • The port can be blocked only when the port type of the RHUB is CPRI_E/CPRI_O.

  • If a CPRI link loopback or a CPRI link performance test is started and the specified upper-level port is to be blocked, this port can be blocked only after the CPRI link loopback or CPRI link performance test completes.

  • LCOP board does not support block CPRI port.

  • The SFPSW parameter supports only the laser switch of the SFP optical module on the baseband processing board. Other types such as QSFP do not support this function. If this parameter is not configured, the switch status remains unchanged.

  • If SFP Switch is set to OFF, ALM-26230 BBU CPRI Optical Module Fault or ALM-26320 BBU IR Optical Module Fault may be generated.

SFPSW SFP Switch

Meaning: Indicates whether to enable the TX function of the optical module on the port. When this switch is turned on, the optical laser of the optical module works properly. When this switch is turned off, the optical laser of the optical module stops transmitting optical signals. This parameter is invalid when the board type is RHUB or RMU.

Example

To block a CPRI port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, Port No.: 0, run the following command:
BLK CPRIPORT: CN=0, SRN=0, SN=3, OPTN=0;
