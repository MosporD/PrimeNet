List Port Rate Limit Configuration (LST PORTLR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of all the port rates.

Note

None.

Parameters

None.

Example

To list the configuration of Port Rate Limit, run the following command: 
LST PORTLR:;
The result is shown as follows:

+++    0        2010-07-19 14:00:59
O&M    #56
%%LST PORTLR:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Port Rate Limit ID

Indicates the port rate limit ID.

Port Type

Indicates the port type.

Port ID

Indicates the port ID.

UL Committed Information Rate(kbit/s)

Indicates the UL committed information rate after rate limitation is configured at a port. The precision of the UL committed information rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s, the precision supported by the other board is 32 kbit/s. If the configured UL committed information rate is not a multiple of the precision, the UL committed information rate is rounded up. For the GTMUb, the value of CIR ranges from 64 to 100000. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.

Committed Burst Size(kbit)

Indicates the Committed Burst Size (CBS) after rate limitation is configured at a port. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga, UMDU or GTMUc is 64 kbit/s. For the GTMUb, the value of CBS ranges from 63 kbit to 256 kbit. If this parameter is set to a value greater than the maximum allowed value or less than the minimum allowed value, the maximum or the minimum allowed value takes effect.

Excessive Burst Size(kbit)

Indicates the Excess Burst Size (EBS) after rate limitation is configured at a port.

DL Committed Information Rate(kbit/s)

Indicates the DL committed information rate after rate limitation is configured at a port. The parameter does not take effect in GSM and NR. For UMTS, if the downlink flow control switch is set to DYNAMIC_BW_SHAPING or STATIC_BW_SHAPING, this parameter is valid. If the downlink flow control switch is set to BW_SHAPING_ONOFF_TOGGLE, this parameter is valid when traffic congestion is detected. In other cases, this parameter is invalid. For LTE, this parameter computes the value of Physical Port Down Link Admission. The minimum rate supported by the UMPTa, UMPTb, UMPTe, UMPTg, UMPTga or UMDU is 64 kbit/s.
