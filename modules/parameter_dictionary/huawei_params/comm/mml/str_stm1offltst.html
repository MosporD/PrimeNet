Start STM-1 Out-of-Service Performance Test (STR STM1OFFLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start an STM-1 offline performance test.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]This command is applicable to only the unchannelized optical port.

  • [Co-MPT,NodeB]Services are interrupted when you start a test, because you must set a loopback at a port before the test.

  • [Co-MPT,NodeB]The STM-1 offline performance test involves two commands respectively used for enabling and disabling the test.

  • [Co-MPT,NodeB]This command can be executed successfully only when the unchannelized optical sub-board to be queried works properly.

  • [Co-MPT,NodeB]The SW parameter indicates whether to report the test result every other second. If SW is set to ON, the test result is reported every other second after the test starts. If SW is set to OFF, the test result is reported only after you run the STP STM1OFFLTST command or the test duration expires. For details about the report, see the execution result of the STP STM1OFFLTST command.

  • [Co-MPT,NodeB]The online test and offline test cannot be performed simultaneously at an optical port.

  • [Co-MPT,NodeB]Before ATM cells are transmitted from the CPU to the optical port chip on a transmission interface board, you must set a loopback for the optical port chip (set LM to LOCAL), optical fiber, or RNC (set LM to REMOTE). If no loopback is configured, this test is invalid.

Example

To enable the STM1 offline performance test with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, Port No.: 0, Test Channel Band Width: 2048, Period Report Switch: OFF, Test Time: 1, run the following command:
STR STM1OFFLTST: CN=0, SRN=0, SN=0, SBT=UNCHANNELLED_COVERBOARD, STM1N=0, BW=2048, SW=OFF, TM=1;
