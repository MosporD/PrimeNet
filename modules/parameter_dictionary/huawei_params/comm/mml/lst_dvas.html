List Direct Voltage Alarm Switch Status (LST DVAS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the alarm switch status of the DC.

Note

None.

Parameters

None.

Example

To list the configuration of a DVAS, run the following command:
LST DVAS:;       
The result is shown as follows:
+++    0        2011-11-15 11:19:47
O&M    #22
%%LST DVAS:;%%
RETCODE = 0  Operation succeeded.

List Direct Voltage Alarm Switch Status
---------------------------------------
                  Direct Voltage Alarm Switch  =  Enable
Direct Voltage Alarm Occurred Threshold(0.1V)  =  450
Direct Voltage Alarm Restored Threshold(0.1V)  =  455
(Number of results = 1)


---    END

Output Description

Field Description

Direct Voltage Alarm Switch

Indicates the direct voltage alarm switch. The switch controls whether to report the ALM-26113 Base Station DC Power Supply Abnormal in the case of low DC input voltage.

Direct Voltage Alarm Occurred Threshold(0.1V)

Indicates the DC voltage alarm occurrence threshold. When the load voltage is lower than the DC voltage alarm occurred threshold and the direct voltage alarm switch is set to ENABLE, ALM-26113 Base Station DC Power Supply Abnormal is reported.

Direct Voltage Alarm Restored Threshold(0.1V)

Indicates the DC voltage alarm Restoration threshold. When the load voltage is higher than the DC voltage alarm restored threshold and the direct voltage alarm switch is set to ENABLE, an ALM-26113 Base Station DC Power Supply Abnormal is cleared.
