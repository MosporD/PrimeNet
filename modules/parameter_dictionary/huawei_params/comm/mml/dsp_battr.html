Display Battery Test Result (DSP BATTR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the test result of a specified battery.

Note

  • Before querying the test result of a battery, ensure that the battery has been added.

  • If the operational status of the PMU that manages the battery is unavailable, the query fails.

Meaning: Indicates the result number of the battery test to be queried. The battery test results are saved as 10 groups, according to the test date. Group 1 is the latest result. To query the battery test result with the following parameters: Cabinet No.: 0, Test Result No.: 10, run the following command:
DSP BATTR: CN=0, TRN=10;

Output Description

Field Description

Battery Test Type

Indicates the type of the battery test. There are two types of battery tests: STANDARD(Standard Test) and SIMPLE(Simple Test). Standard Test is used to calculate the efficiency of the battery. Simple Test is used only to judge the quality of the battery, but not to calculate the efficiency of the battery. This test takes a short time.

Test Start Time

Indicates the test start date, which is in the format of YYYY/MM/DD.

Test Result

Indicates the result of the battery test.

Battery Efficiency(%)

Indicates the battery efficiency. The battery is normal when the result is between 80% and 100%.

Discharge Last Time(h)

Indicates the continued discharge duration of the battery.

Discharge End Voltage(V)

Indicates the voltage of the battery when the discharge is ended.

Discharge Average Current(A)

Indicates the average current in the process of the battery discharge.

Discharge AH(Ah)

Indicates the accumulated discharged power (Ah) from the beginning of discharge.

Battery Temperature[degree Celsius(degree Fahrenheit)]

Indicates the current temperature of the battery.

Test End Cause

Indicates the end reason of the battery test.
