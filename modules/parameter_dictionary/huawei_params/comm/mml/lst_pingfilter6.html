List IPv6 Ping Filter IP/Prefix Length Configuration (LST PINGFILTER6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list configurations of the ping6 filter on a BS.

Note

None.

Parameters

None.

Example

To list IPv6 Ping Filter IP/Prefix Length Configuration, run the following command:
LST PINGFILTER6:;
The result is shown as follows:
+++    0        2018-10-12 12:02:52
O&M    #1307
%%LST PINGFILTER6:;%%
RETCODE = 0  Operation succeeded.

List IPv6 Ping Filter IP/Prefix Length Configuration
----------------------------------------------------
    VRF Index  =  0
 IPv6 Address  =  2001:DB8::1
Prefix Length  =  32
(Number of results = 1)


---    END

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance.

IPv6 Address

Indicates the IPv6 address that Ping6 filtering needs to filter.

Prefix Length

Indicates the prefix length of the IPv6 address. Used to determine which bits must match when an IPv6 address matches.
