Set CIoT Frame No. Parameters (SET FNSYNCTIME)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the Cellular Internet of Thing (CIoT) Frame No. parameters, including the time when the hyper system frame No. (HSFN) is 0 and the status of the frame No. synchronization switch.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eNodeB,gNodeB]The frame number synchronization time must be consistent with that on the MME.

Parameters

ID Name Description
FNSYNCSW CIoT Frame No. Synchronization Switch

Meaning: Indicates whether to enable the CIoT frame No. synchronization function. The value ON indicates that this function is enabled. The value OFF indicates that this function is disabled. This parameter takes effect only when frequency synchronization is used.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the TASM MO, if FNSYNCSW is set to ON, DATE in the MO cannot be earlier than 1980-1-6.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the TASM, when LPFNSYNCSW is set to ON, FRAMESYNCSW cannot be set to ON and FNSYNCSW cannot be set to ON.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
DATE Date

Meaning: Indicates the date to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.

GUI Value Range: 1900-01-01~2099-12-31

Unit: None

Actual Value Range: 1900-01-01~2099-12-31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
TIME Time

Meaning: Indicates the time to be set for the CIoT Frame No. This parameter is set in compliance with the GPS. The format is as follows: HH:MM:SS. For example, 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To set parameters when HSFN is 0 for CIoT with the parameters as follows: CIoT Frame No. Synchronization: ON, Switch:Date: 2006-09-08, Time: 10:05:20, run the following command:
SET FNSYNCTIME: FNSYNCSW=ON, DATE=2006&09&08, TIME=10&05&20;
