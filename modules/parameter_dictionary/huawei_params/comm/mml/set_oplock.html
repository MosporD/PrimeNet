Set Locking Status of Non-default Local Account (SET OPLOCK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the locking states of all non-default local accounts. Only admin is the default local account.

Note

  • When non-default local accounts are locked and MAE is on-line, only the default account can be used to log in to the system, and non-default local accounts that have logged in to the system cannot perform any operations.

  • When the default administrator account is disabled, this policy allows the temporary emergency login of a valid local administrator-level account during the MAE service interruption.

Parameters

ID Name Description
LOCKST Non-default Local Users Lock Policy

Meaning: Indicates the status of the local non-default account switch.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(On)

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set all the non-default local accounts to the unlocked state, run the following command:
SET OPLOCK: LOCKST=OFF;
