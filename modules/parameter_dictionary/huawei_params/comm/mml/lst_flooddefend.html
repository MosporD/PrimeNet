List Flood Attack Defense and Alarm Configuration (LST FLOODDEFEND)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list all configurations of flood attack defense and excessive flood packet alarms.

Note

None.

Parameters

None.

Example

To list the configuration of flood attack defense and excessive flood packet alarms, run the following command:
LST FLOODDEFEND:;
The result is shown as follows:
+++    0        2011-03-21 17:20:54
O&M    #59
%%LST FLOODDEFEND:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Flood Type

Indicates the type of the flood packet. If the control bits are all 0 or both the Synchronize bit and No More Data bit are 1 in TCP packets, the packets are directly discarded and flood attack defense is not performed. SYN packets refer to packets whose Synchronize bit is 1 and Acknowledgement bit is 0. When the defenses against attacks of the SYN and TCP packets are both enabled but the SYN packet data rate does not reach the flood attack defense threshold for SYN packets, the flood attack defense threshold for TCP packets is used to trigger the defense. When the data rate of some SYN packets reaches the flood attack defense threshold for SYN packets, this threshold is used to trigger the defense against the attack of these SYN packets and the flood attack defense threshold for TCP packets is used to defend against the attack of SYN packets of which the rate does not reach the flood attack defense threshold for SYN packets.

Defend Switch

Indicates whether to enable the protection against excessive flood packets.

Defend Threshold(packet/s)

Indicates the threshold for starting the protection against excessive flood packets. If the DFDSW parameter is set to ENABLE, the system discards the extra packets when the RX rate of flood packets exceeds the threshold. It is recommended that the difference between Defend Threshold and Alarm Threshold is greater than 3% of Defend Threshold.

Alarm Switch

Indicates whether to report an alarm when the local end receives excessive flood packets from the peer end.

Alarm Threshold(packet/s)

Indicates the threshold for the excessive flood packet alarm. If the ALMSW parameter is set to ENABLE, the system measures the RX rate of flood packets every 10 seconds. If the measured value exceeds the threshold, an excessive flood packet alarm is reported. The alarm is cleared if the RX rate of flood packets keeps below the threshold for five consecutive minutes. It is recommended that the difference between Defend Threshold and Alarm Threshold is greater than 3% of Defend Threshold.
