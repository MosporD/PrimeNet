Modify RCS Server (MOD RCSSERVER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an RCS server and to modify the configuration of local NE ports that are connected to the RCS server. The RCS server provides shared external RRU resources for the local NE.

Note

None.

Parameters

ID Name Description
RCSSERVERNO RCS Server No.

Meaning: Indicates the number of an RCS server.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N
RCSSERVERNAME RCS Server Name

Meaning: Indicates the name of an RCS server. An RCS client searches for the RCS server on the network based on this RCS server name. Upon finding the RCS server, the RCS client establishes a connection with the RCS server. If the RCS server is a DCU, this parameter must be set to the NE name of the DCU.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of RCSSERVERNAME in the RCSSERVER MO must be unique.

Impact on Radio Network Performance: None

Example

To modify the cabinet with the parameters as follows: RCS Server No.: 0, RCS Server Name: "Rcstest", run the following command:
MOD RCSSERVER: RCSSERVERNO=0, RCSSERVERNAME="Rcstest";
