Add SCTP Parameters Template (ADD SCTPTEMPLATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an SCTP parameter template.

Note

System specifications: If the LMPT/UMPT/UMDU is the main control board, a maximum of 12 SCTPTEMPLATEs can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 1 SCTPTEMPLATE can be configured.

Parameters

RTOMIN RTO Min Value

Meaning: Indicates the minimum RTO value of an SCTP link. According to the SCTP protocol, if the calculated RTO is less than the value of this parameter, the round trip delay is set to the value of this parameter to reduce the probability of retransmission timeout.

GUI Value Range: 10~59999

Unit: ms

Actual Value Range: 10~59999

MML Default Value: 1000

Recommended Value: 1000

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPTEMPLATE MO, RTOINIT must be greater than or equal to RTOMIN and be less than RTOMAX.
  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SCTPTEMPLATE MO, RTOMIN must be less than RTOMAX.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

RTOALPHA RTO Alpha Value

Meaning: Indicates the RTO alpha value of an SCTP link. A larger value indicates less sensitivity to the link delay. For details, see RFC4960. According to the SCTP protocol, this parameter is used as the smooth factor for calculating round-trip delay. In a new estimation, (RtoAlpha/100) is obtained based on a new measurement and 1-(RtoAlpha/100) is obtained based on the last estimation.

Meaning: Indicates the RTO beta value of an SCTP link. This parameter is used to calculate the round trip time variation (RTTVAR). A larger value indicates that the latest change is more important. For definitions of the beta value, see RFC4960.

Meaning: Indicates the maximum number of retransmissions over a path of an SCTP link. If no heartbeat response is received from the peer end when the number of retransmissions over a path exceeds the value of this parameter, the current path cannot be reached. If multiple paths are used on the SCTP link, path switching is automatically performed.

SWITCHBACKFLAG Switch Back Flag

Meaning: Indicates whether the automatically established SCTP link switches back to the primary path when the primary path is restored and reachable. If the primary path is not reachable, the SCTP link switches to the secondary path. When this parameter is set to ENABLE, the SCTP link switches to the primary path if the primary path is restored and reachable. When this parameter is set to DISABLE and the primary path is restored and reachable, the SCTP link does not switch back to the primary path if the secondary path is also reachable, and the SCTP link switches back to the primary path if the secondary path is unreachable.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: ENABLE(Enable)

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

MAXSCTPPDUSIZE Maximum SCTP PDU Size

Meaning: Indicates the maximum size of of an IPv4 SCTP PDU (Protocol Data Unit). It specifies the maximum length of an SCTP PDU (excluding the IP header) transmitted on an SCTP link, which is set using the parameter template. If the value of this parameter is greater than the size of the IP layer MTU of the base station or intermediate transmission equipment, SCTP packets are fragmented at the IP layer. This causes a large number of fragments and affects the transmission efficiency of the intermediate transmission equipment.

GUI Value Range: 580~1480

Unit: byte

Actual Value Range: 580~1480

MML Default Value: 1464

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a value too large, a large number of packets are fragmented or lost on the transmission network. As a result, the transmission delay increases and the performance deteriorates. If this parameter is set to a value too small, the valid transmission payload decreases and the transmission network bandwidth cannot be effectively used. As a result, the transmission delay increases and the transmission performance deteriorates.

Applicable Mode: U, L, N

Example

To add an SCTP parameter template with the parameters as follows: SCTP Parameters Template ID: 5, Switch Back Flag: DISABLE, run the following command:
ADD SCTPTEMPLATE: SCTPTEMPLATEID=5, SWITCHBACKFLAG=DISABLE;
