Add SNMP NMS (ADD SNMPNMS)

Network Element: BTS3900, BTS5900

Function

Use this command to add an SNMP NMS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT]This command is supported only when the subrack type is DCU3911 or DCU5900.

  • [Co-MPT]Community Index (available when Version is set to V2C) and Security Name (available when Version is set to V3) can be specified to control trap packet transmissions.

Example

To add SNMP NMS parameters as follows: IP Address: "192.168.0.10", Port: 162, Version: V2C, Community Index: 0, run the following command: 
ADD SNMPNMS: IPADDRESS="192.168.0.10", PORT=162, VERSION=V2C, SECURITYINDEX=0;
