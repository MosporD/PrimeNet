Display Multicast IP Address (DSP MULTICASTIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the multicast IP address and the corresponding device IP address.

Note

The multicast IP address supports default routes domain only.

Parameters

None.

Example

To query the multicast IP address, run the following command:
DSP MULTICASTIP:;
The result is shown as follows:

Output Description

Field Description

Local IPv4 Address

Indicates the IPv4 address configured for the port. The parameter takes effect only in LTE.

Multicast IPv4 Address

Indicates a multicast IPv4 address supported by the base station. The parameter takes effect only in LTE.

Local IPv6 Address

Indicates the IPv6 address configured for the port. The parameter takes effect only in LTE.

Multicast IPv6 Address

Indicates a multicast IPv6 address supported by the base station. The parameter takes effect only in LTE.
