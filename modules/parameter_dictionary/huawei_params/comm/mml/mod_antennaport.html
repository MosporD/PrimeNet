Modify Antenna Port (MOD ANTENNAPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an antenna port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command can be executed only when the RRU or RFU corresponding to the specified port works properly.

  • The power switches of the antenna port and the remote electrical tilt (RET) port on an RRU cannot be both turned on. Otherwise, the execution of this command fails.

  • Before modifying the uplink or downlink delay, run the DSP RRU command to query the maximum antenna delay supported by the RF module. This ensures that the new uplink or downlink delay is supported by the RF module and is the same as the engineering measurement result. If the new delay is not supported by the RF module or is different from the engineering measurement result, cell services will be affected.

  • When the power supply switch is set to ON, the links of ALDs that are working properly will be intermittently interrupted if this command is executed to modify a current alarm threshold or reset the power supply switch to on.

  • For a port on an RF module in a multimode base station, turning off the ALD power supply switch takes effect only when the ALD Power Switch parameter is set to OFF for every mode.

  • When the RRU type is MRIU, the following parameters are invalid: ALD Power Switch, Current Alarm Threshold Type, Undercurrent Alarm Occur Threshold, Undercurrent Alarm Clear Threshold, Overcurrent Alarm Occur Threshold, and Overcurrent Alarm Clear Threshold.

  • [Co-MPT,NodeB,eGBTS]The undercurrent alarm occur threshold is usually set to 20% to 30% of the normal working current of the equipment. The overcurrent alarm occur threshold is set to 150% to 200% of the normal working current of the equipment. If an antenna is used in a non-regular installation scenario, the alarm threshold type must be set to UER_SELF_DEFINE. In general, the threshold for reporting or clearing a current alarm for a port is the sum of the thresholds for all ALDs connected to the port. Take the threshold for reporting an overcurrent alarm as an example. If there are N ALDs connected to the port, then: Threshold for reporting an overcurrent alarm for the port = Threshold for ALD 1 + Threshold for ALD 2 + ... + Threshold for ALD N. If the ALD model is not a recommended one, you are advised to set the alarm threshold type to UER_SELF_DEFINE. If the antenna port is connected to an SASU, set the alarm threshold type to UER_SELF_DEFINE.

  • [eNodeB,gNodeB]The undercurrent alarm threshold is usually set to 20% to 30% of the normal working current of the equipment. The overcurrent alarm threshold is set to 150% to 200% of the normal working current of the equipment. If an antenna is used in a non-regular installation scenario, the alarm threshold type must be set to UER_SELF_DEFINE. In general, the threshold for reporting or clearing a current alarm for a port is the sum of the thresholds for all ALDs connected to the port. Take the threshold for reporting an overcurrent alarm as an example. If there are N ALDs connected to the port, then: Threshold for reporting an overcurrent alarm for the port = Threshold for ALD 1 + Threshold for ALD 2 + ... + Threshold for ALD N. If the ALD model is not a recommended one, you are advised to set the alarm threshold type to UER_SELF_DEFINE.

  • [NodeB]For details about how to connect an antenna port to an ALD and how to set an antenna port, see section "ALD Management" in 3900 Series Base Station Initial Configuration Guide.

ULTRADELAYSW Switch of Configuring Ultra Delay

Meaning: Indicates the ultra-large antenna delay switch. This switch determines the configurable range of uplink delay and downlink delay. When this parameter is set to OFF, the configurable range of both uplink delay and downlink delay is 0 to 4000 ns. When this parameter is set to ON, the configurable range of both uplink delay and downlink delay is 0 to 100, 000 ns. In normal sites, it is recommended that this parameter be set to OFF because the feeder delay is less than 4000 ns. In special sites such as optical fiber repeaters, it is recommended that this parameter be set to ON because the ultra-large delay is required.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an ANTENNAPORT MO, when ULTRADELAYSW is set to OFF, the value of ULDELAY must be less than or equal to 4000.

Service Interrupted After Modification: Yes

DLDELAY DL Time Delay

Meaning: Indicates the downlink delay of the antenna, that is, the propagation delay from the output port of an RF unit to the antenna port. If no TMA is configured, this parameter is set to the propagation delay of the feeder. In typical scenarios, the transmission speed of signals in feeders is 0.88 times the speed of light, and therefore the propagation delay of feeders can be calculated using the following formula: (feeder length x 10 x 100)/(3 x 88). In this formula, the propagation delay of feeders is in units of ns and the feeder length is in units of m. If the TMA is configured, the value of this parameter also includes the delay of the TMA. For details about the delay of the TMA, see the document provided by the TMA manufacturer.

GUI Value Range: 0~120000

Unit: ns

Actual Value Range: 0~120000

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an ANTENNAPORT MO, when ULTRADELAYSW is set to OFF, the value of DLDELAY must be less than or equal to 4000.

Service Interrupted After Modification: Yes

Applicable Mode: G, U, L, N

PWRSWITCH ALD Power Switch

Meaning: Indicates the state of the ALD power supply switch. The ALD power supply switches for the SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), STMA (Smart Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit) must be set to ON. In actual cases, the RRU/RFU automatically sets this switch to OFF for an Antenna port when the ALM-26530 RF Module ALD Current Abnormal alarm is reported due to overcurrent, overcurrent protection, or undercurrent protection (the RRU/RFU supports undercurrent protection and Low Current Protect Switch is set to ON for the RRU/RFU) on the Antenna port. For details, see ALM-26530 RF Module ALD Current Abnormal.

GUI Value Range: ON(ON), OFF(OFF)

Unit: None

Actual Value Range: ON, OFF

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the same RRU MO, PWRSWITCH in the RETPORT MO and PWRSWITCH in the ANTENNAPORT MO cannot be set to ON at the same time.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If all the ALD power supply switches that control the power supply to a TMA are turned off, the TMA will fail to work properly. This will increase the call drop rate and decrease the access success rate for users at the cell edge.

Applicable Mode: G, U, L, N
THRESHOLDTYPE Current Alarm Threshold Type

Meaning: Indicates the type of the ALD current alarm threshold. This parameter is valid only if the ALD power supply switch is turned on. If this parameter is not set to UER_SELF_DEFINE, the value of this parameter must be set according to the ALD type and connection mode, and this parameter value determines the current alarm thresholds.

1. For 12 dB non-AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 170 mA. Overcurrent Alarm Clear Threshold must be set to 150 mA.

2. For 24 dB non-AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 310 mA. Overcurrent Alarm Clear Threshold must be set to 280 mA.

3. For RET antennas (coaxial) only: Undercurrent Alarm Occur Threshold must be set to 25 mA. Undercurrent Alarm Clear Threshold must be set to 33 mA. Overcurrent Occur Alarm Threshold must be set to 150 mA. Overcurrent Alarm Clear Threshold must be set to 120 mA.

4. For 12 dB TMAs and RETs or 12 dB AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 450 mA. Overcurrent Alarm Clear Threshold must be set to 400 mA.

5. For 24 dB TMAs and RETs or 24 dB AISG TMAs only: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 850 mA. Overcurrent Alarm Clear Threshold must be set to 750 mA.

6. For 12 dB TMAs and AISUs: Undercurrent Alarm Occur Threshold must be set to 30 mA. Undercurrent Alarm Clear Threshold must be set to 40 mA. Overcurrent Occur Alarm Threshold must be set to 500 mA. Overcurrent Alarm Clear Threshold must be set to 450 mA.

7. For 24 dB TMAs and AISUs: Undercurrent Alarm Occur Threshold must be set to 40 mA. Undercurrent Alarm Clear Threshold must be set to 60 mA. Overcurrent Occur Alarm Threshold must be set to 650 mA. Overcurrent Alarm Clear Threshold must be set to 580 mA.

8. For AISUs only: Undercurrent Alarm Occur Threshold must be set to 10 mA. Undercurrent Alarm Clear Threshold must be set to 15 mA. Overcurrent Occur Alarm Threshold must be set to 350 mA. Overcurrent Alarm Clear Threshold must be set to 300 mA.

GUI Value Range: UER_SELF_DEFINE(USER_DEFINED), TMA12DB_ONLY_NON_AISG(TMA12DB_ONLY_NON_AISG), TMA24DB_ONLY_NON_AISG(TMA24DB_ONLY_NON_AISG), RET_ONLY_COAXIAL(RET_ONLY_COAXIAL), TMA12DB_AISG(TMA12DB_AISG), TMA24DB_AISG(TMA24DB_AISG), TMA12DB_AISU(TMA12DB_AISU), TMA24DB_AISU(TMA24DB_AISU), AISU_ONLY(AISU_ONLY)

Unit: None

Meaning: Indicates the overcurrent alarm occur threshold. When the ALD current value is greater than this threshold, an ALM-26530 RF Unit ALD Current Out of Range alarm is reported. The specific problem is overcurrent. When this threshold is lower than the maximum current supported by the hardware, the overcurrent alarm occur threshold prevails. When this threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm occur threshold.

OCTHD Overcurrent Alarm Clear Threshold

Meaning: Indicates the overcurrent alarm clear threshold. When the overcurrent alarm clear threshold is lower than the maximum current supported by the hardware, the overcurrent alarm clear threshold prevails. In this case,when the ALD current value is lower than this threshold, ALM-26530 RF Unit ALD Current Out of Range is cleared. When the overcurrent alarm clear threshold is higher than the maximum current supported by the hardware, the maximum current supported by the hardware serves as the overcurrent alarm clear threshold. In this case, when the ALD current value is lower than the maximum current supported by the hardware, ALM-26530 RF Unit ALD Current Out of Range is cleared.

Example

To modify the configuration of an antenna port with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 0, Antenna Port No.: R0A, Power Switch: ON, THRESHOLDTYPE: TMA12DB_ONLY_NON_AISG, run the following command:
MOD ANTENNAPORT: CN=0, SRN=60, SN=0, PN=R0A, PWRSWITCH=ON, THRESHOLDTYPE=TMA12DB_ONLY_NON_AISG;
