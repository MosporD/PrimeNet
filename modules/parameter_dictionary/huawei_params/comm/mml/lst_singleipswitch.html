List SingleIP Configuration (LST SINGLEIPSWITCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the single IP configuration.

Note

None.

Parameters

None.

Example

To query the singleIP configuration in the database, run the following command:
LST SINGLEIPSWITCH:;
The result is shown as follows:
+++    0        2012-11-15 10:05:58
O&M    #5443
%%LST SINGLEIPSWITCH:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

SingleIP Switch

Indicates whether to enable single IP.

Connection Mode

Indicates the connection mode of the MPT.

Nodeb Inner IP

Indicates the IP address configured for the NodeB internal port.

Nodeb Outer IP

Indicates the IP address configured for the NodeB external port.

GBTS Inner IP

Indicates the IP address configured for the GBTS internal port.

GBTS Inner Mask

Indicates the subnet mask of the IP address configured for the GBTS internal port.

GBTS Peer IP

Indicates the peer IP address of the GBTS.

GBTS Interconnect Port No.

Indicates the number of the Ethernet port for GBTS interconnection.

GBTS Interconnect Speed

Indicates the rate mode of the Ethernet port for GBTS interconnection.
