Remove Application (RMV APP)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an application. An application provides the operating environment for the functions of an NE of a certain RAT. If an MBTS needs to stop providing the functions of a certain RAT, operators can delete the application for the RAT. The application does not exist after it is deleted. For example, if GSM is removed from an MBTS after evolution, operators need to remove the application for the GBTS.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before removing an application, you can run the DSP APP command to query the ID of the application.

  • When an application is removed, the configuration data, license, and dynamically generated data of the application will also be removed. Services carried by the application will no longer go.

  • [Co-MPT,eNodeB,gNodeB]If Working Mode is set to NON-CONCURRENT, only one application can be configured, but multiple extended applications can be configured. Run the LST NODE command to check the node work mode.

  • [NodeB,eGBTS]Only one application is allowed when the node work mode is NON-CONCURRENT.

    Run the LST NODE command to check the node work mode.

  • [Co-MPT]The remove of an application may cause the related board to reset.

  • [Co-MPT]For a multi-mode BS in CPRI-Sharing topology, if the local mode aggregates data, removing the application of the local mode that aggregates data will interrupt the services of the peer mode.

  • [Co-MPT]In a base station where the GTMU supports SingleOM, this command cannot be executed.

Parameters

ID Name Description
AID Application ID

Meaning: Indicates the application ID.

GUI Value Range: 1~255

Unit: None

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an application with the parameters as follows: Application ID: 6, run the following command:
RMV APP: AID=6;
