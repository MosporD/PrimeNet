Modify RAE Device Data (MOD RAEDEVICEDATA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration in the Remote eAntenna Extension (RAE) device data.

Note

  • The bands in the device data of an RAE antenna must differ from each other.

  • Some parameters in this command cannot be modified. For details about which parameters can be modified and which cannot, see the documents provided by the RAE manufacturer.

  • Some frequency bands do not take effect for the antenna device. Run the DSP RAEDEVICEDATA command to check whether the frequency band takes effect.

ALTITUDE Altitude

Meaning: Indicates the altitude of the location where the antenna equipment is located. The RAE complies with the AISG2.1 specification. The unit of this parameter in the specification is 0.1 m. If the imperial system is used, the base station converts the input imperial value into a metric value using the 0.3048 x input imperial value formula, rounds off the calculated value, and then applies the result to the RAE. When you query the altitude of the antenna, the base station coverts the metric value stored on the RAE into an imperial value using the 3.2808 x metric value stored on the RAE formula, rounds off the calculated value, and then displays the result. If this parameter is set to 4000000 in the metric system or 13123200 in the imperial system, the parameter value is not delivered to the device. In this case, the parameter value in the LST RAEDEVICEDATA command output is NULL.

GUI Value Range: -327670~327670,4000000(metric system);-1075020~1075020,13123200(imperial system)

Unit: 0.1m(metric system);0.1ft(imperial system)

Actual Value Range: -32767~32767,400000(metric system);-107502~107502,1312320(imperial system)

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None
