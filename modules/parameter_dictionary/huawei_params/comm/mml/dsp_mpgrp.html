Display MLPPP Group Status (DSP MPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the status of an MLPPP group.

Note

None.

Example

To query the status of an MLPPP group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Group No.: 0, run the following command:
DSP MPGRP: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, MPGRPN=0;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the MLPPP group is located.

Subrack No.

Indicates the number of the subrack where the MLPPP group is located.

Slot No.

Indicates the number of the slot where the MLPPP group is located.

Subboard Type

Indicates the type of sub-board on the board where an MLPPP group is established.

Group No.

Indicates the number of the MLPPP group.

Port ID

Indicates the ID of an MLPPP group, which uniquely identifies the MLPPP group. In the old model, this parameter is optional. If this parameter is not set, the default value 4294967295 is used. In the new model, this parameter is mandatory and must be unique in the system.

Local IP

Indicates the local IP address. If this parameter is set to 0.0.0.0, this IP address needs to be negotiated. If this parameter is not set to 0.0.0.0, it must be set to a valid IP address of class A, B, or C but must not be the reserved address 0.x.x.x or 127.x.x.x.

Mask

Indicates the subnet mask of the local IP address. If this parameter is set to 0.0.0.0, it needs to be negotiated.

Peer IP

Indicates the peer IP address. When the BS is connected to a peer equipment, the peer IP address can be either user-specified or set to 0.0.0.0. If this parameter is set to 0.0.0.0, this IP address is obtained by means of negotiation.

PPPMUX

Indicates whether to enable PPP multi-frame multiplexing.

IP Header Compression

Indicates whether to enable IP header compression.

Multi-Class PPP

Indicates whether an MLPPP group supports the multi-class feature.

If this parameter is set to ENABLE, the MLPPP group supports the Class of Service (CoS) feature and four or eight service types of different priorities.

MLPPP Group Status

Indicates the status of an MLPPP group.

IPCP Status

Indicates the status of the IPCP protocol.

PPPMUX Status

Indicates the status of the PPP MUX.

Local IP Negotiation Result

Indicates the negotiation result of the local IP address.

Local IP Mask Negotiation Result

Indicates the negotiation result of the local IP mask.

Peer IP Negotiation Result

Indicates the negotiation result of the peer IP address.

Multi-Class PPP Negotiation Result

Indicates the negotiation result of the multi-class PPP.

PPPMUX Negotiation Result

Indicates the negotiation result of the PPP MUX.

Maximum Receive Unit Negotiation Result(byte)

Indicates the negotiation result of the maximum RX unit.

ACFC Negotiation Result

Indicates the negotiation result of the address field and control field.

PFC Negotiation Result

Indicates the negotiation result of the protocol field compression.

IPHC Negotiation Result

Indicates the negotiation result of the IPHC.

Number of TX Packets(packet)

Indicates the number of packets sent.

Number of TX Bytes(byte)

Indicates the number of bytes transmitted.

Number of TX Drop Packets(packet)

Indicates the number of discarded packets transmitted.

Number of RX Packets(packet)

Indicates the number of packets received.

Number of RX Bytes(byte)

Indicates the number of bytes received.

Number of RX Drop Packets(packet)

Indicates the number of discarded packets received.

TX Flow(byte/s)

Indicates the TX traffic.

RX Flow(byte/s)

Indicates the RX traffic.

Number of IPs

Indicates the number of IP addresses of an MLPPP group.

IP Address List

Indicates the list of IP addresses of an MLPPP group.

Diagnosis Info

This parameter specifies the diagnosis information about an MLPPP group, including the start time, diagnosis result, and fault ID. When an MLPPP group is established or reset, the diagnosis is triggered automatically. The default diagnosis period is 60s and the diagnosis information is displayed in the command output.
