List UDP Session Configuration (LST UDPSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of a UDP session.

Note

None.

Parameters

ID Name Description
UDPSN UDP Session ID

Meaning: Indicates the UDP session number.

Disuse statement: This parameter will be deleted from UMTS/LTE/NR single-mode base stations in later versions (it does not take effect on UMTS/LTE/NR single-mode base stations in the current version). Therefore, you are not advised to use this parameter in UMTS/LTE/NR single-mode scenarios.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the UDP session configuration, run the following command:
LST UDPSESSION:;
The result is shown as follows:

Output Description

Field Description

UDP Session ID

Indicates the UDP session number.

UDP Session Group ID

Indicates the UDP session group number.

Cabinet No.

Indicates the cabinet number of the board where UDP detection is performed.

Subrack No.

Indicates the subrack number of the board where UDP detection is performed.

Slot No.

Indicates the slot number of the board where UDP detection is performed.

Local IP Address

Indicates the local IP address. The local IP address must be the device IP address configured on the board such as the Ethernet port IP address, or logical IP address such as the IP address on the loopback port. The address of the local maintenance Ethernet port cannot be used.

Peer IP Address

Indicates the peer IP address. The IP address cannot be 0.0.0.0, broadcast IP address, multicast IP address, loopback IP address, or any existing IP address in the system.

DSCP

Indicates the differentiated services code point (DSCP) of a packet. The priority has a positive correlation with the value of this parameter.

Interval(s)

Indicates the interval at which UDP session detection packets are sent.

Check Count

Indicates the number of times that UDP ping packets time out. If this number is greater than the number of times that detection packets time out, the UDP session detection is considered faulty.
