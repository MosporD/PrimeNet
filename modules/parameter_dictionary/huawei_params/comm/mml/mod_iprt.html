Modify IP Route (MOD IPRT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an IP route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Active/standby routes indicate routes with the same destination IP address and subnet mask but different priorities in the same routing domain.

  • This operation may interrupt the services or OM channels carried on this IP route. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • After an DEVIP MO is configured, the system automatically generates a direct gateway route. A direct gateway route takes precedence over other routes. Therefore, after an IPRT MO is configured, if the network address part of the destination IP address of the IPRT MO is the same as that of the direct gateway route, the IPRT MO is invalid.

  • [Co-MPT,NodeB,eNodeB]Equal-cost routes indicate routes with the same destination IP address, subnet mask, and priority in the same routing domain.

  • [Co-MPT,eNodeB,gNodeB]When changing the priority of an IP route on a base station, ensure that the relative priority of the IP route remains unchanged.

FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether a forcible change of an IP route is made. When this parameter is set to NO(No), the system checks whether the change affects upper-layer services. If the change affects upper-layer services, the forcible change will fail. When this parameter is set to YES(Yes), the system does not check whether the change affects upper-layer services. Upper-layer services include the following: active/standby OM channel (OMCH), DNS service (DNSSRV), security link (IKEPEER), certificate issuance (CA), CRL update (CRLTSK), IP clock link (IPCLKLINK), NTP (NTPC), Abis CP/Iub CP/S1 CP/X2 CP/M2 CP/ECO CP/eX2 CP/SO CP/uX2 CP/Xw CP/gNBCUX2 CP/gNBCUNg CP/gNBCUXn CP (SCTPLNK/SCTPPEER), and Abis UP/IP path of an unknown service type/Iub UP/uX2 UP/S1 UP/X2 UP/eX2 UP/Xw UP/gNBCUX2 UP/gNBCUS1 UP/gNBCUNg UP/gNBCUXn UP (IPPATH/USERPLANEPEER). This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when using this parameter:

1. The system checks whether a forcible change of an IP route affects upper-layer services based on the configuration data instead of based on the actual running status of these services.

2. If an NE is configured with an SRCIPRT, PPPLNK, or MPGRP MO, the system does not check whether a forcible change of an IP route affects upper-layer services.

3. If Port Type is set to IPOA(IP Over ATM Interface) or AIRLNK(Air Link) for the IP route to be added or removed, the system does not check whether the addition or removal affects upper-layer services.

4. If Port Type is set to IPOA(IP Over ATM Interface) or AIRLNK(Air Link) for both the IP routes before and after the modification, the system does not check whether the modification affects upper-layer services.

5. If Port Type is set to IPOA(IP Over ATM Interface) or AIRLNK(Air Link) for an IP route, the system does not check whether the IP route forms a pair of equal-cost routes with another route and whether the IP route is included in the network segment of another route.

Example

1. To modify the parameter settings of the IP static route with the parameters as follows: Route Index: 0, Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Destination IP: 192.168.100.0, Mask: 255.255.255.0, Route Type: NEXTHOP, Next Hop IP: 192.168.1.25, MTU Switch: OFF, Description Info: 123456, run the following command:
MOD IPRT: RTIDX=0, CN=0, SRN=0, SN=7, SBT=BASE_BOARD, DSTIP="192.168.100.0", DSTMASK="255.255.255.0", RTTYPE=NEXTHOP, NEXTHOP="192.168.1.25", MTUSWITCH=OFF, DESCRI="123456";
2. To modify the parameter settings of the IP static route with the parameters as follows: Route Index: 0, Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Destination IP: 192.168.200.0, Mask: 255.255.255.0, Route Type: IF, Port Type: MPGRP, Port No.: 0, Description Info: 123, run the following command: 
MOD IPRT: RTIDX=0, CN=0, SRN=0, SN=7, SBT=BASE_BOARD, DSTIP="192.168.200.0", DSTMASK="255.255.255.0", RTTYPE=IF, IFT=MPGRP, IFNO=0, DESCRI="123";
