Reset MLPPP Group (RST MPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to reset a specified MLPPP group and restart negotiation.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]Running this command interrupts services carried on the MLPPP group.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the MLPPP group is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Meaning: Indicates the number of the subrack where the MLPPP group is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Meaning: Indicates the number of the slot where the MLPPP group is located.

GUI Value Range: 0~7

Unit: None

MML Default Value: None

Service Interrupted After Modification: N/A

Applicable Mode: G, U, L

Meaning: Indicates the type of sub-board on the board where an MLPPP group is established.

Actual Value Range: E1_COVERBOARD, BASE_BOARD

MML Default Value: None

Example

To reset the MLPPP group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: Base Board, Group No.: 0, run the following command:
RST MPGRP: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, MPGRPN=0;
