Display Interconnection Clock Input Port Switchover Records (DSP INTERCLKPTSWLOG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query switchover logs of the interconnection clock input port. Interconnection clock signals can be input into, output by, or transferred by the system. When the interconnection clock is configured as the current reference clock source of the system, the local NE is configured as the reference clock source for the Cloud BB, or the interconnection clock is faulty, the system obtains interconnection clock signals from an available interconnection clock port and records the switchover if the interconnection clock input port is changed.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]The system records latest 10 switchover logs of the interconnection clock input port at most.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When the system is reset, switchover logs recorded in the system will be cleared and the new switchover will be recorded.

Parameters

None.

Example

Display Interconnection Clock Input Port Switchover Records:
DSP INTERCLKPTSWLOG:;
The result is shown as follows:
+++    0        2014-10-10 10:18:29
O&M    #227
%%DSP INTERCLKPTSWLOG:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Time

Indicates the time when the input port is changed.

Cabinet No

Indicates the cabinet number of the board where the interconnection clock is located.

Subrack No

Indicates the subrack number of the board where the interconnection clock is located.

Slot No

Indicates the slot number of the board where the interconnection clock is located.

Port No

Indicates the input port of the interconnection clock. When an NE serves as the reference clock source for the Cloud BB, the NE outputs interconnection clock signals. In this case, the interconnection clock signals are from a non-interconnection reference clock source and there is no input port, and therefore the parameter value is NULL.
