Display SSL Connection Capability (DSP SSLCPB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the Secure Sockets Layer (SSL) version supported by an NE. The version information provides the SSL connection capability of the NE.

Note

None.

Parameters

None.

Example

To query the SSL connection capability of an NE, run the following command:
DSP SSLCPB:;
The result is shown as follows:
+++    0        2008-01-03 10:02:55
O&M    #7
%%DSP SSLCPB:;%%
RETCODE = 0  Operation succeeded.

TLS/SSL Version  =  TLS1.1
                 =  TLS1.2
                 =  TLS1.3
(Number of results = 1)


---    END

Output Description

Field Description

TLS/SSL Version

Indicates the TLS or SSL version supported by the NE.TLS(Transport Layer Security). The TLS1.2 and TLS1.3 version are enabled eternally in the system, and therefore they cannot be disabled currently. You are not advised to use SSL3.0, TLS1.0 and TLS1.1 because they have security risks.
