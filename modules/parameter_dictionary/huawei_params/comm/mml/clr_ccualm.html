Clear CCU Smoke Alarm (CLR CCUALM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to clear a cabinet control unit (CCU) smoke alarm. When a CCU smoke alarm is reported, you must clear the fault that triggers the alarm, and then run this command to clear the alarm.

Note

After the command is executed, if the fault that triggers the alarm persists, the alarm is reported again. To clear the alarm for sure, visit site to observe the situation and perform troubleshooting.

Example

To clear CCU Smog Alarm as follows: Cabinet No.: 0, run the following command:
CLR CCUALM: CN=0;
