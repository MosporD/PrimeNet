Add Tree Link PVC (ADD TREELNKPVC)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to dynamically add a treelink permanent virtual channel (PVC).

Note

  • [Co-MPT,NodeB]Before running this command, ensure that the physical port that carries the tree link PVC has been configured. The type of the physical port can be IMA group, UNI link, fractional ATM link, or STM1. In addition, the tree link PVC to be added must have a different combination of VPI and VCI from any existing PVC on the same physical port.

  • [Co-MPT,NodeB]When configuring logical resources, the BS checks bandwidths according to bandwidth configuration rules. For details, see the notes of the ADD AAL2PATH command.

  • [Co-MPT,NodeB]The bandwidth of a tree link PVC must be narrower than or equal to the physical bandwidth of the physical port that carries the tree link PVC. The type of the physical port can be IMA group, UNI link, fractional ATM link, or STM1.

  • [Co-MPT,NodeB]If ST (type of the service carried by the PVC) is set to CBR, a waste of bandwidth may occur and the aggregation efficiency of HUB-type nodes may be affected, because the constant bit rate (CBR) service is assigned a fixed bandwidth. Therefore, ST cannot be set to CBR.

  • [Co-MPT,NodeB]If VST (switching type) of a tree link PVC is set to VP_SWITCH, neither VPI of the source port nor that of the destination port can be set to 1.

  • [Co-MPT,NodeB]If the PVC of a lower-level node needs to be configured to carry the CBR service, either of the following settings of SCR (sustainable cell rate) of the PVC on the HUB-type node is recommended: (1) If RU (rate unit) is set to KBPS, SCR = PCR - 1, where PCR is the peak cell rate of the PVC on the lower-level node; (2) If RU is set to CELL/S, SCR = PCR - 3.

  • [Co-MPT,NodeB]Before adding a treelink PVC to a transmission resource group, ensure that the transmission resource group has been configured.

  • [Co-MPT,NodeB]The source port must be different from the destination port.

  • [Co-MPT,NodeB]The sum of the following numbers cannot exceed 200: (1) Twice the number of the Tree Link PVC objects configured on this board (2) Total number of the following objects configured on this board: OMCH in which the Bearer Type parameter is set to ATM(ATM), AAL2PATH, and SAALLNK.

  • [Co-MPT,NodeB]System specifications: If the WMPT/UMPT/UMDU is the main control board, a maximum of 96 PVCs can be configured.

  • [Co-MPT,NodeB]Board specifications: A maximum of 96 PVCs can be configured on a WMPT/UMPTa/UMPTb/UMDU/UTRP (subboard type: UAEC).

PCR Peak Cell Rate

Meaning: Indicates the peak rate of transmitting cells on an ATM connection, such as a VPC or VCC.

GUI Value Range: 30~49529

Unit: None

Actual Value Range: 30~49529

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST and RU are set to UBR+ and KBPS, respectively, MCR must be less than PCR.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to UBR+ and RU is set to CELL/S, MCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to RTVBR or NRTVBR and RU is set to KBPS, SCR must be less than PCR.
  • [Co-MPT, NodeB]In a TREELNKPVC MO, if ST is set to RTVBR or NRTVBR and RU is set to CELL/S, SCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.

-Others:

  • [Co-MPT, NodeB]In a TREELNKPVC MO, this parameter can be set to any value within the range of 31 to 21000 if RU is set to KBPS and ST is set to RTVBR, NRTVBR, or UBR+.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 30 to 21000 if RU is set to KBPS and ST is set to UBR.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 74 to 49529 if RU is set to CELL/S and ST is set to RTVBR, NRTVBR, or UBR+.
  • In a TREELNKPVC MO, this parameter can be set to any value within the range of 71 to 49529 if RU is set to CELL/S and ST is set to UBR.
  • [Co-MPT, NodeB]In the TREELNKPVC MO, if ST is set to UBR+, the value of this parameter must be greater than that of MCR.
  • [Co-MPT, NodeB]In the TREELNKPVC MO, if ST is set to RTVBR or NRTVBR, the value of this parameter must be greater than that of SCR.

Example

To add a tree link PVC with the parameters as follows: Tree Link PVC No.: 0, Join Transmission Resource Group: DISABLE, Tree Link PVC Switch Type: VC_SWITCH, Cabinet No.: 0, Source Subrack No.: 0, Source Slot No.: 6, Source Subboard Type: BASE_BOARD, Source Port Type: UNI, Source Port No.: 1, Source Port VPI: 1, Source Port VCI: 33, Destination Subrack No.: 0, Destination Slot No.: 5, Destination Subboard Type: E1_COVERBOARD, Destination Port Type: UNI, Destination Port No.: 2, Destination Port VPI: 35, Destination Port VCI: 35, Rate Unit: KBPS, Bearer Service Type: RTVBR, Peak Cell Rate: 31, Sustain Cell Rate: 30, run the following command: 
ADD TREELNKPVC: NO=0, JNRSCGRP=DISABLE, VST=VC_SWITCH, CN=0, SRCSRN=0, SRCSN=6, SRCSBT=BASE_BOARD, SRCPT=UNI, SRCPN=1, SRCVPI=1, SRCVCI=33, DSTSRN=0, DSTSN=5, DSTSBT=E1_COVERBOARD, DSTPT=UNI, DSTPN=2, DSTVPI=35, DSTVCI=35, RU=KBPS, ST=RTVBR, PCR=31, SCR=30;
