Remove Synchronous Ethernet Clock (RMV SYNCETH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a specified synchronous-Ethernet clock link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the working mode of the clock is manual and the synchronous-Ethernet clock is specified as the reference clock, this clock link cannot be removed. If the working mode of the clock is automatic, the clock link can be removed. After removal of the clock link, the system clock is switched to another reference clock.

  • Deleting an input link affects the 1000M electrical port. The 1000M electrical port may be temporarily interrupted for about 3s. During the interruption, the ETHPORT-related operations may fail.

  • Removing the synchronous Ethernet output link will temporarily interrupt the port where the original output link is located for 3 to 15 seconds. During the interruption, operations related to the ETHPORT may fail.

  • If a synchronous Ethernet output link has been configured and the synchronous Ethernet input link is removed, the port where the original input link is located is temporarily interrupted for 3 to 15 seconds. During the interruption, operations related to the ETHPORT may fail.

Parameters

ID Name Description
LN SyncEth Clock No.

Meaning: Indicates the number of the synchronous-Ethernet clock link. A maximum of two links can be configured currently.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SYNCETH MO, when the value of TYPE is set to IN, the value of LN must be 0. When the value of TYPE is set to OUT, the value of LN must be 1.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To remove a synchronous-Ethernet clock, run the following command:
RMV SYNCETH:;
