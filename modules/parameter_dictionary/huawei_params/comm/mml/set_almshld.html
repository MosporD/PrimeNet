Set Alarm Shielding Flag (SET ALMSHLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the Shield Flag for the specified alarm (identified by the alarm ID) so that the alarm is shielded or unshielded.

Note

  • After the Shield Flag of an alarm is set to SHIELDED, the NE operates as follows: If the alarm was generated, the NE shields it to exclude it from the active alarm list and the alarm log shows that the alarm is cleared manually. If the alarm was not generated, the NE does not handle it. If the alarm is generated later, the alarm will be shielded and not displayed on the alarm console.

  • When the Shield Flag of an alarm is set to UNSHIELDED, the NE operates as follows: If the alarm was generated, the NE regards the time the alarms is unshielded as the time the alarm is generated and reports the alarm again, so that it is displayed on the active alarm list and the alarm log shows that the alarm is not cleared. If the alarm was not generated, the NE does not handle it.

  • After the Shield Flag of an alarm is set to UNSHIELDED, the NE performs normal operations on the alarm. The NE reports the alarm when it is generated and removes it from the active alarm list when it is cleared.

  • To query whether the setting has taken effect after execution of this command, run the LST ALMCFG command.

  • After the execution of this command, run the RST ALMCFG command to initialize the settings.

  • Some alarms cannot be shielded by running this command, and "This alarm cannot be shielded" will be displayed.

Parameters

ID Name Description
AID Alarm ID

Meaning: Indicates the alarm ID. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SHLDFLG Shield Flag

Meaning: Indicates whether to shield the alarm.

GUI Value Range: UNSHIELDED(Unshielded), SHIELDED(Shielded)

Unit: None

Actual Value Range: UNSHIELDED, SHIELDED

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the Shield Flag for the specified alarm with the parameters as follows: Alarm ID: 26812, Shield Flag: unshielded, run the following command:
SET ALMSHLD: AID=26812, SHLDFLG=UNSHIELDED;
