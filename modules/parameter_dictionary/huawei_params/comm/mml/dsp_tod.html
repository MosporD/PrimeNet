Display TOD (DSP TOD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the running status of a specified Time of Day (TOD) clock link.

Note

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The feeder delay cannot be queried if the TOD clock link is not activated.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When GPS and TOD clock sources work in active/standby mode, running this command can query the status of the active clock source only. If you need to query the status of the standby clock source, switch the standby clock source to the active one and then run this command.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When the TOD clock source is working in standby mode, the status of TOD clock source will be updated within 2 hours after configuration.

  • [NodeB]The UMTS currently does not support this function.

Parameters

ID Name Description
TN TOD Clock No.

Meaning: Indicates the number of a TOD clock link. When TOD clock links are configured on a USCUb board, the numbers of the TOD clock links have a one-to-one relationship with the numbers of the TOD ports on the USCUb. For example, TOD clock link 0 corresponds to port 0, and TOD clock link 1 to port 1.

Example

To display the status of a TOD clock link, run the following command:
DSP TOD:;
The result is shown as follows:

O&M    #2016

Output Description

Field Description

TOD Clock No.

Indicates the number of a TOD clock link. When TOD clock links are configured on a USCUb board, the numbers of the TOD clock links have a one-to-one relationship with the numbers of the TOD ports on the USCUb. For example, TOD clock link 0 corresponds to port 0, and TOD clock link 1 to port 1.

TOD Type

Indicates the type of a TOD clock link. It indicates whether the corresponding TOD port is an input or output port. An input port is used to input clock signals to the NE, and an output port is used to provide clock signals for other NEs. Only the TOD clock of input type can serve as a clock source.

Link Available State

Indicates the availability of a TOD clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.

Link Active State

Indicates the activation status of a TOD clock link. If the link is active, the TOD clock link is the current clock source of the system.

Delay(ns)

Indicates the feeder delay of the TOD clock link. The value is NULL when the clock source is not activated.
