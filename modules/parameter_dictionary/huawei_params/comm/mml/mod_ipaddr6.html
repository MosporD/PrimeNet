Modify IPv6 Address (MOD IPADDR6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an IPv6 address.

Note

None.

Parameters

ID Name Description
IPADDR6ID IPv6 Address ID

Meaning: Indicates the IPv6 Address ID of an interface.

GUI Value Range: 1~15 characters

Unit: None

Actual Value Range: 1~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]When the IPADDR6 MO is added, the value of IPADDR6ID is case insensitive but is case sensitive when being referenced by other MOs.
  • [Co-MPT, eNodeB, gNodeB]The value of IPADDR6ID in the IPADDR6 MO cannot be prefixed with SON_, _SON, AUTO_, or _AUTO.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
ITFID Interface ID

Meaning: Indicates the interface number. When Transmission Configuration Mode in the GTRANSPARA MO is set to NEW, this parameter indicates the interface number (0 to 1499) of the INTERFACE MO.

GUI Value Range: 0~1499

Unit: None

Actual Value Range: 0~1499

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
IPV6 IPv6 Address

Meaning: Indicates the IPv6 address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In an IPADDR6 MO, IPV6 must be a globally scoped unicast address.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
PFXLEN Prefix Length

Meaning: Indicates the length of the prefix of the IPv6 address, the prefix length of a loopback address is internally fixed to 128 bits.

GUI Value Range: 1~128

Unit: None

Actual Value Range: 1~128

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: L, N
USERLABEL User Label

Meaning: Indicates the user-defined information about an IPv6 address.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To modify an IPv6 address with the parameters as follows: IPv6 Address ID: 0, PFXLEN: 32, VRF Index: 0, run the following command: 
MOD IPADDR6: IPADDR6ID="0", PFXLEN=32, VRFIDX=0;
