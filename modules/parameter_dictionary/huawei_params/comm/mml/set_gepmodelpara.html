Set Global EP Model Parameters (SET GEPMODELPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the global EP model parameters.

Note

[Co-MPT,NodeB,eNodeB,gNodeB]When the value of Direct IPsec Automatic Deletion Switch is changed from DISABLE(Disable) to ENABLE(Enable), the timer for deleting an existing faulty direct IPsec tunnel starts over after the change, and the timer for deleting a newly faulty direct IPsec tunnel starts after the fault occurs.

Parameters

ID Name Description
STATICCHKMODE Static Check Mode

Meaning: Indicates the effective mode of the GTP-U static detection switch in the EP model. When this parameter is set to UPPEERSTATICCHK(User-Plane Peer Static Check), the user-plane peer static detection switch takes effect. When this parameter is set to EPSTATICCHK(Endpoint Group Static Check), the endpoint group static detection switch takes effect. This parameter is valid only for the link-level GTP-U static detection in the EP model configured on a base station. This parameter takes effect only for LTE and NR.

GUI Value Range: UPPEERSTATICCHK(User-Plane Peer Static Check), EPSTATICCHK(Endpoint Group Static Check)

Unit: None

Actual Value Range: UPPEERSTATICCHK, EPSTATICCHK

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DIRIPSECAUTODELSW Direct IPsec Automatic Deletion Switch

Meaning: Indicates whether to enable the direct IPsec automatic deletion function. When this parameter is set to ENABLE, the direct IPsec automatic deletion function is enabled. If IKE negotiation for a direct IPsec tunnel fails, the SECURITYPEER, IKEPEER, IPSECPOLICY, and IPSECBINDITF MOs that correspond to the IPsec tunnel are automatically deleted. In IPv4 scenarios, the corresponding IPSECBIND, ACL, and ACLRULE MOs are also automatically deleted. In IPv6 scenarios, the corresponding ACL6, ACLRULE6, TUNNELITF, INTERFACE, and IPROUTE6 MOs are also automatically deleted. When this parameter is set to DISABLE, the direct IPsec automatic deletion function is disabled. This switch takes effect only for IPsec tunnels that are automatically established in endpoint configuration mode.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DIRIPSECAUTODELTIMER Direct IPsec Automatic Deletion Timer

Meaning: Indicates the timer for deleting a direct IPsec tunnel that is faulty due to failed IKE negotiations. After a direct IPsec tunnel is faulty due to IKE negotiation failures, the following are true: - When this parameter is set to 0, the faulty IPsec tunnel is deleted without alarm reporting. - When this parameter is set to a value greater than 0, the fault alarm is reported. If the IKE negotiation failures persist after the timer specified by this parameter expires, the faulty IPsec tunnel is deleted and the fault alarm is cleared.

GUI Value Range: 0~50400

Unit: min

Actual Value Range: 0~50400

MML Default Value: None

Recommended Value: 10080

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DIRIPSECUPDATESW Direct IPsec Update Switch

Meaning: Indicates whether to enable the direct IPsec automatic update function. When IPSec Auto Configure Switch in the USERPLANEHOST MO is changed from DISABLE to ENABLE, the local IKE IP address in the SECURITYHOST MO is changed, SeGW Switch in the SECURITYHOST MO is changed from ENABLE to DISABLE, or an X2/Xn interface is added, the following are true: (1) If this parameter is set to ENABLE, a direct IPsec self-update procedure will be automatically triggered, during which the direct IPsec link is updated. (2) If this parameter is set to DISABLE, a direct IPsec self-update procedure will not be automatically triggered and the direct IPsec link will not be updated. If the value of this parameter is changed from DISABLE to ENABLE, automatic update of the direct IPsec link is also triggered.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set the global EP model parameters with Static Check Mode set to EPSTATICCHK, run the following command:
SET GEPMODELPARA: STATICCHKMODE=EPSTATICCHK;
