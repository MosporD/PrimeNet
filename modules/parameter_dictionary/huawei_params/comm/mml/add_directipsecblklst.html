Add Blacklist for Direct IPSec Tunnel (ADD DIRECTIPSECBLKLST)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an IP address to the blacklist for direct IPSec tunnels.

Note

[Co-MPT,eNodeB,gNodeB]System specifications: When the UMPTa/UMPTb/UMDU/UMPTe/UMPTg/UMPTga is used as the main control board, a base station supports a maximum of 384 blacklists. When the LMPT is used as the main control board, a base station supports a maximum of 128 blacklists. The blacklists configured in both the DIRECTIPSECBLACKLIST and DIRECTIPSECBLKLST MOs are counted in.

Parameters

ID Name Description
SECURITYPEERIP Security Peer IP Address

Meaning: Indicates the IP address of a security peer in the IPSec blacklist. When an IP address of a security peer is added to the blacklist, no more IPSec tunnels to the security peer are automatically set up.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter and is replaced by the Security Peer IPv4 Address parameter in the DIRECTIPSECBLACKLIST MO. Therefore, avoid using this parameter.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
USERLABEL User Label

Meaning: Indicates the description of a security peer.

Disuse statement: This parameter will be deleted in later versions. Although the configuration interface in this version supports synchronization and delivery of the setting of this parameter, the system does not use this parameter. Therefore, avoid using this parameter.

GUI Value Range: 0~256 characters

Unit: None

Actual Value Range: 0~256 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To add an IP address to the blacklist for direct IPSec tunnels with the parameters as follows: Security Peer IP Address: 172.16.1.1, User Label: eNodeBId_38601, run the following command:
ADD DIRECTIPSECBLKLST: SECURITYPEERIP="172.16.1.1", USERLABEL="eNodeBId_38601";
