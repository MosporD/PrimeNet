List Port Work Mode (LST PORTMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the working mode of a port.

Note

Only the working mode of a port on a UBBP, UBBP-W or LCOP board can be displayed.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the interconnection port is located.

Unit: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

GUI Value Range: 0~1

Unit: None

MML Default Value: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Example

To list the information about word mode with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Port No.: 6, run the following command:
LST PORTMODE: CN=0, SRN=0, SN=1, PN=6;
The result is shown as follows:
+++    0        2014-04-12 14:32:51
O&M    #3608
%%LST PORTMODE: CN=0, SRN=0, SN=1, PN=6;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the interconnection port is located.

Subrack No.

Indicates the subrack number of the board where the interconnection port is located.

Slot No.

Indicates the slot number of the board where the interconnection port is located.

Port No.

Indicates the number of the port that carries the interconnection link.

Port Mode

Indicates the application mode of the port. The application mode is set based on the actual physical networking. Value NULL indicates that a negotiation is being performed over the port or the negotiation is failed.
