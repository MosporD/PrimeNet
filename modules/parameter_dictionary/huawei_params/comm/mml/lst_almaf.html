List Active Alarm (LST ALMAF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list active alarms on the NE. Active alarms are uncleared alarms.

The sync serial numbers (SSNs) of alarms specify the sequence in which the alarms are reported to the EMS.

The serial numbers (CSNs) of alarms specify the sequence in which the alarms are generated. The CSN is the only index for an alarm in alarm logs, and it remains unchanged throughout the process of alarm generating, clearing, and changing.

Note

  • The sequence of alarms displayed in the LST ALMAF command output is the same as the sequence in which alarms are reported to the EMS.

  • There could be a delay between the actual alarm generated time (displayed in the LST ALMAF command output) and the time when the alarm is reported to the EMS. The delay may be caused by the mechanism of filtering out intermittent alarms, alarm correlation, duration-based alarm filtering rule, and times-based alarm filtering rule.

  • Alarms of the NE are classified into two types: fault alarm and event alarm. This command is used to list fault alarms that are not cleared.

  • If you query alarms by both the CSN and SSN, the displayed alarms meet both the following conditions:

    - The CSN of each displayed alarm is within the CSN range.

    - The SSN of each displayed alarm is within the SSN range.

Output Description

Field Description

Sync serial No.

Indicates the synchronous number of the alarm.

Alarm name

Indicates the alarm name.

Alarm raised time

Indicates the time when the alarm is generated.

Alarm changed time

Indicates the time when the alarm is changed. Only a changed alarm has the change time.

Location info

Indicates the information for locating the alarm.

Function

Indicates the mode in which an alarm is generated in an NE. Only a product alarm has this field.

Root alarm CSN

Indicates the sequence number of the source alarm.

Common alarm

Indicates the mode in which a common alarm is generated. Only a common alarm has this field.

Special Alarm Flag

Indicates the state of an NE in engineering mode, such as commissioning, upgrade, and capacity expansion. This parameter is not displayed for NEs not in engineering mode.

Special info

Indicates the special information of the alarm.

Special info1

Indicates the special information 1 of the alarm. Pay no attention to Special info1 field.

Auto clear

Indicates that the alarm can be automatically cleared or not.

Root Cause Flag

Indicates whether the alarm is primary alarm: secondary=0, primary=1, single=2.

Correlative label type

Indicates the alarm correlative label style: CorrelativeKey=0, NotificationIdSet=1, Both=2.

LCK

Indicates local correlative key of the alarm.

FCK

Indicates father correlative key of the alarm, equals to LCK of the source alarm.

FMCK

Indicates family correlative key of the alarm, equals to FCK of this alarm.
