List TCPACK Limit Algorithm (LST TCPACKLIMITALG)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations of the TCP ACK limit algorithm.

Note

[Co-MPT,eNodeB]This command applies only to LTE, but in co-MPT scenarios, this command applies to both LTE and NR.

Parameters

None.

Example

To list the configuration of the TCP ACK limit algorithm, run the following command: 
LST TCPACKLIMITALG:;
The result is shown as follows:
+++    0        2013-11-13 22:58:27  
O&M    #806355191       
%%LST TCPACKLIMITALG:;%%   
RETCODE = 0  Operation succeeded. 

List TCPACK Limit Algorithm          
---------------------------  
           TCP ACK Limit Switch  =  On
DL Throughput Threshold(kbit/s)  =  714
(Number of results = 1)  


---    END

Output Description

Field Description

TCP ACK Limit Switch

Indicates whether to enable the TCP ACK limit algorithm. When this switch is set to on, the base station limits the ACK data rate of downlink TCP services based on the value of DL Throughput Threshold. In this case, the ACK burst of downlink TCP services is prevented and the KPIs related to the downlink throughput rate are improved, but the packet forwarding capability of boards is affected. When this switch is set to off, the base station does not limit the ACK data rate of downlink TCP services.

DL Throughput Threshold(kbit/s)

Indicates the maximum downlink service throughput that can be set by the TCP ACK limit algorithm. When this switch is set to on, the ACK burst of downlink TCP services is prevented and the KPIs related to the downlink throughput are improved.
