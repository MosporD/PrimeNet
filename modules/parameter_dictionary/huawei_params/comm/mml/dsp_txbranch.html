Display TX Channel (DSP TXBRANCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic attributes of the TX channel of the RRU or RFU. The dynamic attributes include information such as the hardware maximum output power and maximum output power of the TX Channel, maximum output power of TX unit, frequency band, and bandwidth.

Note

  • The power of each frequency band of a single mode on a single channel is added up to obtain the maximum power of the mode on the channel. The maximum power of a single mode of all channels is reported as the maximum output power of the TX channel, which is the queried power of the LampSite pRRU.

  • In a multimode base station, the downlink bandwidth (MHz) of an RRU or RFU indicates the maximum downlink bandwidth supported by the RRU or RFU.

  • Channel information of an AAU supporting beamforming cannot be queried using this command. Run the DSP RRU command to query the uplink and downlink frequency bands of this AAU.

  • The maximum TX power of some RRUs cannot be queried by running this command. If the query result shows that the maximum TX power is an invalid value, you can run the DSP RRU command to query the maximum TX power.

  • [Co-MPT,eNodeB,gNodeB]For some RRUs working in LTE TDD mode, the actual physical status of the TX channel must be consistent with that of the RX channel. That is, setting Physical Switch of TX Channel to off will also set Physical Switch of RX Channel to off at the same time.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the TX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the TX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the TX channel is located.

TX Channel No.

Indicates the number of the TX channel of the RRU or RFU.

Logical Switch of TX Channel

Indicates the logical switch of the TX channel of the RRU or RFU. This switch is used to open or close the TX channel. The logical switch of the TX channel and the ARFCNs(absolute radio frequency channel numbers) on the TX channel determine the state of the physical switch of the TX channel: When this switch is ON and the TX channel is configured with ARFCNs(absolute radio frequency channel numbers), the physical switch is ON. In other cases, the physical switch is OFF. The value NULL for the Logical Switch of TX Channel parameter indicates that the parameter setting remains unchanged.

VSWR(0.01)

Indicates the current VSWR of the TX channel. When the TX power is relatively low , the S/N of the reflected signal passing through the detector channel is relatively low, which leads to the inaccuracy of the VSWR calculation, the value of this field will be displayed as NULL.

Physical Switch of TX Channel

Indicates the actual physical status of the TX channel of the RRU or RFU. The logical switch of the TX channel and the ARFCN on the TX channel determine the state of the physical switch of the TX channel: If the logical switch of a TX channel is ON and the ARFCN is configured for the TX channel, the physical switch of the TX channel is ON. In other cases, the physical switch is OFF.

Hardware Maximum Output Power of the TX Channel(mW)

Indicates the maximum output power supported by the TX channel hardware. This parameter value can have a 0.5 dB difference from the actual maximum output power.

Maximum Output Power of the TX Channel(mW)

Indicates the maximum output power supported by the TX channel after the maximum output power locking is enabled for this TX channel or the circuit breaker value is configured for the corresponding RF module. When the maximum output power locking is disabled for this TX channel, the value of this parameter is the same as that of Hardware Maximum Output Power of the TX Channel. If this TX channel belongs to an RF module which supports configuration of the circuit breaker value, the parameter value varies according to the effective circuit breaker value, which can be queried using the DSP RRU command. The parameter value can be 0.5 dB higher or lower than the actual maximum output power.

Maximum Output Power of TX Unit (Single Carrier)(0.1dBm)

Indicates the maximum output power of the RRU or RFU TX unit (single carrier).

Maximum Output Power of TX Unit (Multiple Carriers)(0.1dBm)

Indicates the maximum output power of the RRU or RFU TX unit (multiple carriers).

Band 1 DL Minimum Frequency(0.1MHz)

Indicates the minimum downlink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9650, the minimum downlink frequency of the RRU or RFU is 9650 x 0.1 MHz, which equals to 965 MHz.

Band 1 DL Maximum Frequency(0.1MHz)

Indicates the maximum downlink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9850, the maximum downlink frequency of the RRU or RFU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 1 DL Bandwidth(MHz)

Indicates the bandwidth in band 1 supported by each TX channel in the downlink. This bandwidth is an instantaneous bandwidth.

Band 1 Carrier Number

Indicates the number of carriers operating on band 1.

Band 2 DL Minimum Frequency(0.1MHz)

Indicates the minimum downlink frequency supported by the RRU or RFU band 2. This parameter is NULL, when the RRU or RFU does not support multiple bands. For example, if this parameter is set to 9650, the minimum downlink frequency of the RRU is 9650 x 0.1 MHz, which equals to 965 MHz.
