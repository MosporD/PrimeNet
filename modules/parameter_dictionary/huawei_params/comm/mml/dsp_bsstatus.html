Display NE Status (DSP BSSTATUS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the NE status.

Note

None.

Parameters

None.

Example

To query the status of the NE, run the following command:
DSP BSSTATUS:;
The result is shown as follows:
+++    0       2016-02-20 13:00:05
O&M    #79
%%DSP BSSTATUS:;%%
RETCODE = 0  Operation succeeded. 
                               
Display NE Status
----------------- 
Local Standard  =  LTE
  Local Status  =  EXPAND
Local NE Name   =  0
 Peer Standard  =  UMTS
   Peer Status  =  INSTALL
Peer NE Name    =  0
Peer App Type   =  NodeB
(Number of results = 1) 

                                                                                                                                
---    END

Output Description

Field Description

Local Standard

Indicates the RAT of the local end. The RATs include UMTS, GSM, LTE, LTE TDD, NR, COMM, and COMM2. COMM and COMM2 are the RATs of co-MPT base stations.

Local Status

Indicates the NE status in the local standard. The NE status is specified by values including NORMAL, INSTALL, EXPAND, UPGRADE, TESTING, and ExpandStatus1~10.

Local NE Name

Indicates the name of the local NE.

Peer Standard

Indicates the RAT of the peer end. The RATs include UMTS, GSM, LTE, LTE TDD, NR, COMM, and COMM2. COMM and COMM2 are the RATs of co-MPT base stations. The peer standard for a single-mode equipment is set to NULL.

Peer Status

Indicates the NE status in the peer standard. The NE status is specified by values including NORMAL, INSTALL, EXPAND, UPGRADE, TESTING, and ExpandStatus1~10. The peer status for a single-mode NE is set to NULL.

Peer NE Name

Indicates the name of the peer NE. The value NULL indicates that the peer NE does not support the report of this field or the peer NE does not exist.

Peer App Type

Indicates the application type of the peer NE. The value NULL indicates that the peer NE has no applications, cannot report this field, or does not exist.
