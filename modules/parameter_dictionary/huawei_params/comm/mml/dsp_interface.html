Display Interface Status (DSP INTERFACE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about effective interfaces.

Note

When the following conditions are met, the value of VLAN Tagged Switch for a normal interface is changed to ENABLE to allow processing of VLAN tagged packets and will be restored to DISABLE after the DHCP detection is complete: VLAN Tagged Switch for the normal interface is set to DISABLE; automatic OM channel establishment is triggered due to an OM channel fault; DHCP detection is started on the Ethernet port or Ethernet trunk port.

Parameters

ID Name Description
ITFID Interface ID

Meaning: Indicates the ID of an interface. The value of ITFID in the INTERFACE MOs configured by users ranges from 0 to 1499. The value of ITFID in the INTERFACE MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~1499,10000~19999

Unit: None

Actual Value Range: 0~1499,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In an INTERFACE MO, if ITFID is within the range from 0 to 1499, CTRLMODE must be set to MANUAL_MODE. In an INTERFACE MO, if ITFID is within the range from 10000 to 19999, CTRLMODE must be set to AUTO_MODE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

To query the status of interface, run the following command:
DSP INTERFACE:;

Output Description

Field Description

Interface ID

Indicates the ID of an interface. The value of ITFID in the INTERFACE MOs configured by users ranges from 0 to 1499. The value of ITFID in the INTERFACE MOs configured by the system ranges from 10000 to 19999.

Interface Type

Indicates the type of an interface, which can be normal or VLAN.

Port Type

Indicates the type of the port to which an interface belongs.

Port ID

Indicates the ID of the port to which an interface belongs.

VLAN Tagged Switch

Indicates whether the interface processes VLAN tagged packets. When this parameter is set to DISABLE, the interface of the normal type can receive only untagged packets. When this parameter is set to ENABLE, the interface of the normal type can receive both untagged and tagged packets.

VLAN ID

Indicates the VLAN ID of an interface.

DSCP-to-PCP Mapping ID

Indicates the ID of a mapping between DSCP values and VLAN priorities, which is used by an interface.

DSCP-to-Queue Mapping ID

Indicates the ID of a mapping between DSCP values and queue, which is used by an interface.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IPv4 Maximum Transmission Unit(byte)

Indicates the maximum IPv4 transmission unit supported by an interface.

IPv6 Maximum Transmission Unit(byte)

Indicates the maximum IPv6 transmission unit supported by an interface.

ARP Proxy

Indicates whether to enable the ARP proxy function. If the ARP proxy function is enabled, the base station serves as an ARP proxy for a loopback interface address included in the interface address segment of the base station or for an interface IP address of a lower-level base station. If this function is disabled, the base station does not serve as an ARP proxy for the loopback interface IP address of the base station or for the interface IP address of a lower-level base station. To access either IP address in this case, an external device on the same subnet must be configured with a route.

Control Mode

Indicates whether the object can be automatically modified or removed by the system. When this parameter is set to MANUAL_MODE, only users can perform operations on the object. When this parameter is set to AUTO_MODE, only the system can perform operations on the object.

Cabinet No.

Indicates the cabinet number of the board to which an interface belongs.

Subrack No.

Indicates the subrack number of the board to which an interface belongs.

Slot No.

Indicates the slot number of the board to which an interface belongs.

Interface Status

Indicates whether an interface is activated. The status of an interface which bears on Tunnel Interface is up only after it is binded with an IPSec Policy Group.

Number of IPv4 Addresses

Indicates the number of IPv4 addresses that have taken effect on the interface.

IPv4 Address List

Indicates the list of IPv4 addresses and masks that have taken effect on the interface.

Link-Local Address

Indicates the link-local address that has taken effect on the interface.

Number of Globally Scoped Unicast Addresses

Indicates the number of globally scoped unicast addresses that have taken effect on the interface.

Globally Scoped Unicast Address List

Indicates the list of globally scoped unicast addresses that have taken effect on the interface.

Number of Multicast Addresses

Indicates the number of multicast addresses that have taken effect on the interface.

Multicast Address List

Indicates the list of multicast addresses that have taken effect on the interface.

IPv6 Switch

This parameter indicates whether the ability to interface IPV6 functionality is enabled.
