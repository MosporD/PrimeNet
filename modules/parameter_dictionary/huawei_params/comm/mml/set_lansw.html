Set L2 LAN Switch Global Parameter Configuration (SET LANSW)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to set the global parameters of the L2 LAN switch.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eNodeB]The global parameters of the L2 LAN switch function take effect only for the UMPT/UMDU that serves as a main control board.

Parameters

ID Name Description
BCPKTRATETHD Broadcast Packet Rate Threshold

Meaning: Indicates the threshold limiting the data rate for forwarding broadcast packets by the layer 2 LAN switch of an NE.

GUI Value Range: 50~200

Unit: packet/s

Actual Value Range: 50~200

MML Default Value: None

Recommended Value: 100

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
MACAGINGTIME MAC Aging Time

Meaning: Indicates the aging time of entries in a MAC forwarding table that is learned by a layer 2 LAN switch of an NE.

GUI Value Range: 5~30

Unit: min

Actual Value Range: 5~30

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
DYNAMICMACLRNSW Dynamic MAC Learn Switch

Meaning: Indicates whether to enable the function of dynamically learning the MAC forwarding table by the layer 2 LAN switch of an NE.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SRCMACATTACKCHKSW Source MAC Attack Check Switch

Meaning: Switch for checking the source MAC address attack to the layer 2 LAN switch of an NE. When this parameter is set to ENABLE, the related alarm is reported when a layer 2 LAN switch is attacked by the source MAC address. When this parameter is set to DISABLE, the related alarm is not reported when the layer 2 LAN switch is attacked by the source MAC address.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L
SRCMACATTACKALMTHD Source MAC Attack Alarm Threshold

Meaning: Indicates the threshold for generating the source MAC attack-caused alarm on the layer 2 LAN switch of an NE. When this switch is turned on and a MAC forwarding table has been configured with the maximum number of entries, the Base Station Being Attacked alarm is reported if the number of the dynamic forwarding table update attempts exceeds a specified threshold within 1 minute, and the specific problem is source MAC address attack. If there is no dynamic update request within five consecutive minutes after the source MAC attack-caused alarm is reported, the alarm is cleared.

GUI Value Range: 1~1000

Unit: None

Actual Value Range: 1~1000

MML Default Value: None

Recommended Value: 1

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To set L2 LAN switch global parameter configuration with the parameters as follows: Broadcast Packet Rate Threshold: 100, MAC Aging Time: 10, Dynamic MAC Learn Switch: Enable, Source MAC Attack Check Switch: Enable, Source MAC Attack Alarm Threshold: 1, run the following command:
SET LANSW: BCPKTRATETHD=100, MACAGINGTIME=10, DYNAMICMACLRNSW=ENABLE, SRCMACATTACKCHKSW=ENABLE, SRCMACATTACKALMTHD=1;
