Reset Connected NE (RST CONNNE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to reset the other USU3910s in the Cloud BB network or reset the peer USU3900 connected through CI ports.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Only users with administrator permissions can reset a faulty NE.

  • This command cannot be used during deployment.

Example

To reset the connected NE with the parameters as follows: OM IP Address: 192.168.70.150, Operator Name: admin, Operator Password: ******, Reset Cause: Test, Reset Mode: NORMALRESET, run the following command:
RST CONNNE: OMIP="192.168.70.150", OP="admin", PWD="*****", RESETCAUSE="Test", RESETMODE=NORMALRESET;
