Set User Plane PLR Threshold (SET PLRTHRESHOLD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the thresholds for generating and clearing user-plane excessive packet loss rate alarms of the BS.

Note

The thresholds for generating and clearing excessive packet loss rate alarms are global parameters. All the user-plane excessive packet loss rate alarms in a BS have the same thresholds.

Parameters

ID Name Description
PLRAT PLR Appear Threshold

Meaning: Indicates the packet loss rate threshold above which the excessive packet loss rate alarm for the user plane is reported. When the packet loss rate on the user plane exceeds this threshold, the user-plane excessive packet loss rate alarm is reported.

GUI Value Range: 0~100

Unit: per mill

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 50

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a PLRTHRESHOLD MO, PLRDT must be less than or equal to PLRAT.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PLRDT PLR Disappear Threshold

Meaning: Indicates the packet loss rate threshold below which the excessive packet loss rate alarm for the user plane is cleared. When the packet loss rate on the user plane is lower than this threshold, the user-plane excessive packet loss rate alarm is cleared.

GUI Value Range: 0~100

Unit: per mill

Actual Value Range: 0~100

MML Default Value: None

Recommended Value: 10

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a PLRTHRESHOLD MO, PLRDT must be less than or equal to PLRAT.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set the thresholds for generating and clearing user-plane excessive packet loss rate alarms with the parameters as follows: PLR Appear Threshold: 50, PLR Disappear Threshold: 10, run the following command: 
SET PLRTHRESHOLD: PLRAT=50, PLRDT=10;
