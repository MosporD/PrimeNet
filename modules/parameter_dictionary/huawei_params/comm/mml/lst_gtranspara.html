List Base Station Global Transport Parameters (LST GTRANSPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the global transport-related parameters within a BS.

Note

None.

Parameters

None.

Example

To list the global transport-related parameters within a BS, run the following command:
LST GTRANSPARA:;
The result is shown as follows:

Output Description

Field Description

Resource Group Scheduling Weight Switch

Indicates the switch used to control whether to allocate bandwidths to transmission resource groups on the physical port based on their scheduling weights. When RATECFGTYPE (the rate configuration type) is set to SINGLE_RATE and Physical Port Up Link OverBooking Switch or Physical Port Down Link OverBooking Switch is set to OFF, different values of this parameter lead to different bandwidth allocation methods as follows: (1) If this parameter is set to DISABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its configured TX bandwidth; (2) If this parameter is set to ENABLE and the sum of TX bandwidths of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a bandwidth that is directly proportional to its scheduling weight. When RATECFGTYPE (the rate configuration type) is set to DUAL_RATE, different values of this parameter lead to different CIR allocation methods as follows: (1) If the sum of CIRs of the associated resource groups exceeds the bandwidth of the physical port, each resource group is allocated a CIR that is directly proportional to its configured CIR; (2) If the sum of CIRs of the associated resource groups is smaller than the bandwidth of the physical port, each resource group is allocated a non-CIR that is directly proportional to its scheduling weight. In this case, the PIR of a resource group is the sum of the CIR and the non-CIR.

Rate Config Type

Indicates the rate configuration mode of transmission resource groups in the BS, which can be set to SINGLE_RATE or DUAL_RATE. The dual rate configuration refers to the hybrid of the peak information rate (PIR) and committed information rate (CIR). If this parameter is set to SINGLE_RATE, the transmission resource group performs traffic shaping based on its transmit bandwidth. If this parameter is set to DUAL_RATE, the transmission resource group performs traffic shaping based on PIR and the transmission admission algorithm ensures that the non-flow-controllable traffic does not exceed CIR.

Switch Back Time(s)

Indicates the period during which the active and standby routes are switched over twice. This period indicates the interval between the time single-hop BFD detects that an active route changes from DOWN to UP and the time the active route becomes available. During the switchover, if the previous standby route becomes faulty, the system waits for 10 seconds and then switches back to the active route.

ARP Aging Time(min)

Indicates the aging time of a dynamic ARP item of the BS. This parameter does not change the ARP aging time of the local maintenance Ethernet port.

OMCH Switch Back

Indicates whether the OM channel supports switchback. This parameter is valid only when the OM channel is bound to a UDP session, UDP session group, or automatic UDP session detection. If this parameter is set to ENABLE and a switchover from the active OM channel to the standby OM channel has been triggered, an OM channel switchback is automatically triggered after a UDP session, UDP session group, or automatic UDP session detects that the active channel recovers. If this parameter is set to DISABLE and a switchover from the active OM channel to the standby OM channel has been triggered, an OM channel switchback will not be automatically triggered.

OMCH Switch Back Wait Time(s)

Indicates the duration for the detection switching from the standby remote maintenance channel to the active remote maintenance channel.

Control Port Load Balance Switch

Indicates whether load sharing is enabled among control ports on multiple multi-core transmission boards. When this parameter is set to ENABLE and the base station is configured with multiple multi-core transmission boards, the base station assigns the SCTP associations to the boards based on their processing capabilities, but a UMPTe board can only share load with another UMPTe board, a UMPTg board can only share load with another UMPTg board, a UMPTga board can only share load with another UMPTga board.

Control Port Listening Mode

Indicates whether the control port supports the listening mode. If this parameter is set to ENABLE, the base station listens to the initial link establishment request of the peer SCTP for creating the control plane link. This parameter needs to be used with the EndPoint.

SCTP Fault Real-time Reporting Switch

Indicates whether to report an SCTP link fault alarm in real time. If this parameter is set to ENABLE, the base station considers an SCTP link faulty when it detects that the SCTP link is disconnected. If this parameter is set to DISABLE, the base station starts a timer once it detects that an SCTP link is disconnected. If the base station detects that the SCTP link is disconnected for 18 seconds in the 30-second period, the base station considers that the SCTP link is faulty. Whether an alarm is reported is also determined by the alarm filtering parameter settings.

IP Frame Error Rate Alarm Switch

Indicates the switch controlling ALM-25897 IP Excessive Frame Error Rate. When this switch is set to ENABLE, this alarm is detected and reported when the reporting conditions are met.

IP Frame Error Rate Occur Threshold(per mill)

Indicates the generation threshold of ALM-25897 IP Excessive Frame Error Rate. If IP Frame Error Rate Alarm Switch is set to ENABLE, this alarm is reported when the number of errored IP frames exceeds this threshold within ten minutes.

IP Frame Error Rate Clear Threshold(per mill)

Indicates the clearance threshold of ALM-25897 IP Excessive Frame Error Rate. If this alarm is reported, this alarm is cleared when the number of errored IP frames is less than this threshold within ten minutes.

VLAN ID

Indicates the VLAN tag used by an NE in the Cloud BB network for communicating with other NEs.

Forward Mode

Indicates the forwarding mode flag. If this parameter is set to HOST, inter-port data routing and forwarding is disabled on the panel, and intra-port data routing and forwarding is also disabled on the panel. If this parameter is set to ROUTE, inter-port data routing and forwarding is enabled on the panel.

Same Port Forward Switch

Indicates whether to enable intra-port data routing and forwarding on the panel. Intra-port forwarding means that after being routed and forwarded, the packets received through a port are transmitted from the same port.

DNS Period(h)

Indicates the period of DNS check. If this parameter value is not 0, the system adds a random time of 0 minutes to 30 minutes to the DNS check period. If this parameter value is 0, the system does not perform DNS check. This parameter takes effect only for LTE and NR.

Endpoint Object Auto-configure Switch

Indicates whether to enable the automatic configuration function of the end point-related MOs.

End Point Configure Mode

Indicates the configuration mode of an end point object, including S1SIMPLE_MODE(S1 Simple Mode), X2SIMPLE_MODE(X2 Simple Mode) and EX2SIMPLE_MODE(eX2 Simple Mode). This parameter can be set to one or multiple values. The parameter takes effect only in LTE.

Port Mode Auto Switch

Indicates whether to enable the port mode (data rate and duplex mode) adaptation function for an optical Ethernet port that carries traffic through the remote maintenance channel. When this switch is enabled, the base station uses the port mode adaptation function to restore the remote maintenance channel if the inconsistent port modes between the local and peer ends cause the remote maintenance channel interruption after a base station reset.

Direct IPSec Priorities Match Switch

Indicates the switch for preferentially matching the IPSec policy of the directly connected IPv4 IPSec in end point mode. The IPSec policy of a direct IPSec tunnel is automatically generated and the IKE peer on which the IPSec policy depends is also automatically generated. Other types of IPSec policies belong to non-direct IPSec tunnels. When this parameter is set to ENABLE(Enable), the IPSec policy of a direct IPSec tunnel is preferentially matched. If the direct IPSec tunnel corresponding to the IPSec policy is faulty in this case, IPSec policies of other non-direct IPSec tunnels are preferentially matched. When this parameter is set to DISABLE(Disable), the matching is performed based on the default priorities, that is, the IPSec policy with a smaller sequence number is preferentially matched. This parameter takes effect only for LTE and NR.

Transmission Configuration Mode

Indicates the configuration mode of the transmission model. The transmission model can be configured in old or new mode.

In old mode, the transmission model contains information such as cabinet, subrack, and slot numbers. Transmission configurations are bound to device boards.

In new mode, the transmission model has decoupled transmission and device models, That is, transmission configurations are not bound to device boards. This facilitates the addition of new transmission functions and reduces transmission configuration parameters.
