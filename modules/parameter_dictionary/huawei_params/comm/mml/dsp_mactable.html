Display MAC Table (DSP MACTABLE)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to query the entries in the MAC forwarding table that takes effect on one or all switch ports.

Note

[Co-MPT,eNodeB]This command can query only MAC forwarding tables that take effect on switch ports of the air-interface link type with port index ranging from 1 to 32.

Parameters

ID Name Description
SWPORTIDX Switch Port Index

Meaning: Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.

GUI Value Range: 1~32

Unit: None

Actual Value Range: 1~32

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L

Example

To query mac table information, run the following command:
DSP MACTABLE:;
The result is shown as follows:
+++    0        2015-05-17 21:55:25

Output Description

Field Description

Switch Port Index

Indicates the index of the switch port corresponding to an entry in a MAC forwarding table.

Destination MAC Address

Indicates the destination MAC address of an entry in a MAC forwarding table. The format must be "XXXX-XXXX-XXXX".

MAC Type

Indicates the type of effective MAC addresses. The value of this parameter can be STATIC, DYNAMIC, or AUTO.

MAC Aging Time(min)

Indicates the remaining aging time of an entry in a MAC forwarding table.
