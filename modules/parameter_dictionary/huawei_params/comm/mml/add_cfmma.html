Add CFM MA (ADD CFMMA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a connectivity fault management (CFM) maintenance association (MA).

Note

  • Before running this command, ensure that the associated CFM maintenance domain (MD) has been configured.

  • A VLAN must be bound to a CFM MA if the MA is used for continuity check (CC) on Ethernet ports or Ethernet trunks. VLANs cannot be bound to a CFM MA if the MA is used for CC on ports in Ethernet trunks.

  • When adding a CFM MA, if an error message is displayed, indicating that the object on which the CFM MA depends has not been configured and the addition is prohibited, check whether the associated CFM MD has been configured.

  • System specifications: If the WMPT/GTMUb/GTMUc is the main control board, a maximum of 8 CFM MAs can be configured. If the LMPT/UMPT/UMDU is the main control board, a maximum of 32 CFM MAs can be configured.

  • The CCM TX Interval of Maintenance Association between the two ends must be the same. Otherwise, the configuration data inconsistency fault will not appear on the local station.

  • Board specifications: A maximum of 4 CFM MAs can be configured on a WMPT/UTRP (subboard type: UEOC/UQEC). A maximum of 8 CFM MAs can be configured on a GTMUb/GTMUc. A maximum of 32 CFM MAs can be configured on a UMPT/UMDU/LMPT/UTRPc/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • The CCM TX Interval parameter cannot be set to 10 ms for a GTMUb board. If this parameter is set to 10 ms, the parameter value that actually takes effect is 100 ms.

  • [NodeB]The VLANs that are bound to MAs must each be unique. That is, a VLAN cannot be bound to two MAs.

Example

To add a CFM MA with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Binding VLAN: YES, VLAN ID: 3, run the following command: 
ADD CFMMA: MDNAME="CHINA", MANAME="SHANGHAI", CN=0, SRN=0, SN=6, BNDVLAN=YES, VLANID=3;
