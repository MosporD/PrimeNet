Display Port Security Switch Status (DSP PORTSECURITY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a port security switch.

Note

None.

Parameters

Meaning: Indicates the number of the cabinet that houses the board where port security is enabled.

Meaning: Indicates the number of the subrack that houses the board where port security is enabled.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SN Slot No.

Meaning: Indicates the number of the slot corresponding to the board where port security is enabled.

GUI Value Range: 0~7

SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where port security is enabled.

GUI Value Range: BASE_BOARD(Base Board), ETH_COVERBOARD(Ethernet Cover Board), E1_COVERBOARD(E1 Cover Board)

Unit: None

Actual Value Range: BASE_BOARD, ETH_COVERBOARD, E1_COVERBOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In a PORTSECURITY MO, this parameter can be set to E1_COVERBOARD or ETH_COVERBOARD if SN is set to a value within the range of 0 to 5.
  • In a PORTSECURITY MO, this parameter can be set to BASE_BOARD or ETH_COVERBOARD if SN is set to 6 or 7.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PT Port Type

Meaning: Indicates the type of port on which port security is enabled.

GUI Value Range: ETH(Ethernet Port), E1T1(E1/T1 Port), ETHCI(Ethernet CI Port)

Unit: None

Actual Value Range: ETH, E1T1, ETHCI

MML Default Value: None

Recommended Value: ETH(Ethernet Port)

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In a PORTSECURITY MO, this parameter can be set to ETH, E1T1, or ETHCI if SBT is set to BASE_BOARD.
  • In a PORTSECURITY MO, this parameter must be set to E1T1 if SBT is set to E1_COVERBOARD.
  • In a PORTSECURITY MO, this parameter must be set to ETH if SBT is set to ETH_COVERBOARD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PN Port No.

Meaning: Indicates the number of the port on which port security is configured.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the PORTSECURITY MO, this parameter can be set to 0 to 3 if SBT is set to BASE_BOARD and PT is set to ETH.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 3 if SBT is set to BASE_BOARD and PT is set to E1T1.
  • In the PORTSECURITY MO, this parameter can be set to 0 if SBT is set to BASE_BOARD and PT is set to ETHCI.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 7 if SBT is set to E1_COVERBOARD and PT is set to E1T1.
  • In the PORTSECURITY MO, this parameter can be set to a value within the range from 0 to 5 if SBT is set to ETH_COVERBOARD and PT is set to ETH.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of a port security switch with the parameters as follows: Slot No.: 7, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, run the following command:
DSP PORTSECURITY: SN=7, SBT=BASE_BOARD, PT=ETH, PN=0;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where port security is enabled.

Subrack No.

Indicates the number of the subrack that houses the board where port security is enabled.

Slot No.

Indicates the number of the slot corresponding to the board where port security is enabled.

Subboard Type

Indicates the type of sub-board on the board where port security is enabled.

Port Type

Indicates the type of port on which port security is enabled.

Port No.

Indicates the number of the port on which port security is configured.

Enable Flag

Indicates whether to enable services on a specified port to implement port security. If this parameter is set to DISABLE, running services on the port is prohibited, thereby guaranteeing the security of the port.
