Display IPv4 Address (DSP IPADDR4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about IPv4 addresses that have taken effect.

Note

  • [Co-MPT,NodeB,eNodeB,gNodeB]The Address Status field is always displayed as Valid for the IPv4 address that is configured on the loopback interface and uses the inter-board ARP proxy for transmission.

  • [Co-MPT,NodeB,eNodeB]The local maintenance port and wireless local maintenance port have been isolated from service ports. Therefore, the IPv4 address that is negotiated by the PPP or MP link on a service port can be the same as the IP address of the local maintenance port or wireless local maintenance port.

  • [Co-MPT,NodeB,eNodeB]The execution result shows all IPv4 addresses (including user-configured and negotiated IPv4 addresses) that are set on PPP ports, MLPPP ports, Ethernet ports, Ethernet trunk ports, Ethernet CI ports, and loopback interfaces.

  • [gNodeB]The execution result shows all IPv4 addresses (including user-configured and negotiated IPv4 addresses) that are set on Ethernet ports, Ethernet trunk ports, Ethernet CI ports, and loopback interfaces.

Example

To query IPv4 addresses, run the following command:
DSP IPADDR4:;

Output Description

Field Description

Interface ID

Indicates the ID of an interface.

IP Address

Indicates the IP address configured on the port.

Mask

Indicates the subnet mask for the IP address configured on the port.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Address Status

Indicates the status of the IPv4 address. If Valid is displayed, it indicates that the IP address is available. If Invalid is displayed, it indicates that the port corresponding to the IP address is not activated. If Duplicate is displayed, it indicates that the IP address conflicts with the IP address of an external device.

Cabinet No.

Indicates the cabinet number of the board to which the IP address belongs.

Subrack No.

Indicates the subrack number of the board to which the IP address belongs.

Slot No.

Indicates the slot number of the board to which the IP address belongs.

Port Type

Indicates the type of the port.

Port No.

Indicates the number of the port.
