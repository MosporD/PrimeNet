Display TWAMP Responder Statistic (DSP TWAMPRESPONDERSTA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of negotiation packets for TWAMP responders. This command takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Note

None.

Parameters

ID Name Description
RESPONDERID Responder Index

Meaning: Indicates the index of a TWAMP responder.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CLEAR Clear Statistic

Meaning: Indicates whether to delete the historical statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the statistic about the TWAMP Responder, run the following command:  
DSP TWAMPRESPONDERSTA:;
The result is shown as follows:

Output Description

Field Description

Responder Index

Indicates the index of a TWAMP responder.

Number of TCP Setup Request Packets Received(packet)

Indicates the number of TCP packets received by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of TCP Rejection Packets Sent(packet)

Indicates the number of packets sent by a TWAMP responder to reject TCP connection requests. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Greeting Message Packets Sent(packet)

Indicates the number of Greeting Message packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Set-up-response Packets Received(packet)

Indicates the number of Set-up-response packets received by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Set-up-response Rejection Packets Sent(packet)

Indicates the number of packets sent by a TWAMP responder to reject Set-up-response packets. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Server-start Packets Sent(packet)

Indicates the number of Server-start packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Request-TW-Session Packets Received(packet)

Indicates the number of Request-TW-Session packets received by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Request-TW-Session Rejection Packets Sent(packet)

Indicates the number of packets sent by a TWAMP responder to reject Request-TW-Session packets. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Accept-Session Packets Sent(packet)

Indicates the number of Accept-Session packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Start-Session Packets Received(packet)

Indicates the number of Start-Session packets received by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Start-Session Rejection Packets Sent(packet)

Indicates the number of packets sent by a TWAMP responder to reject Start-Session packets. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Start-session Ack Packets Sent(packet)

Indicates the number of Start-session Ack packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Number of Stop-Session Packets Received(packet)

Indicates the number of Stop-Session packets received by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.
