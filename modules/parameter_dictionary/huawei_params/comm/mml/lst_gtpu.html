List GTP-U Configuration (LST GTPU)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query GTP-U global parameters.

Note

None.

Parameters

None.

Example

To list the configurations of the GTP-U control message, run the following command:
LST GTPU:;
The result is shown as follows:
+++    0        2017-02-16 14:19:55
O&M    #40

Output Description

Field Description

ECHO Frame Timeout(ms)

Indicates the maximum wait time for an echo response. If no echo response is received during the period specified by this parameter, the timer has expired.

ECHO Frame Timeout Count

Indicates the maximum number of timeouts of the echo response waiting timer. If no echo response is received after the number specified by this parameter is reached, the GTP-U path in use fails.

DSCP

Indicates the differentiated services code point (DSCP) of a GTP-U control packet.

Static Check Switch

Indicates whether to enable static detection in compliance with GPRS Tunneling Protocol for User Plane (GTP-U). If this parameter is set to ENABLE, the GTP-U static check is enabled. If this parameter is set to DISABLE, the GTP-U static check is disabled.

Uplink GTP-U Sequence Number Padding Switch

Indicates the switch for padding the sequence numbers of uplink GTP-U service packets. If this parameter is set to ENABLE(Enable), consecutive sequence numbers in ascending order will be padded for uplink GTP-U service packets sent by the local end. If this parameter is set to DISABLE(Disable), the padding function will not take effect. This parameter is valid for the S1 interface only and its setting takes effect on the UMPT/UMDU board only.

Downlink GTP-U Sequence Number Check Switch

Indicates the switch for checking the sequence numbers of downlink GTP-U service packets. If this parameter is set to ENABLE(Enable), the local end performs statistics on the disorders and discontinuous sequence numbers on downlink GTP-U service packets. If this parameter is set to DISABLE(Disable), the check function will not take effect and the values of corresponding performance counters are invalid. This parameter is valid only for the UMPT/UMDU board. The values of corresponding performance counters reported for boards that do not support this parameter are invalid.
