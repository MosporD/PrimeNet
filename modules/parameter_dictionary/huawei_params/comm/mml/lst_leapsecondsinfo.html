Query the information of the leap second offset between the UTC and the GPS. (LST LEAPSECONDSINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information of the leap second offset between the UTC and the GPS.

Note

None.

Parameters

None.

Example

Query the information of the leap second offset between the UTC and the GPS:
LST LEAPSECONDSINFO:;
The result is shown as follows:
+++    0        2018-04-19 15:34:39
O&M    #74
%%LST LEAPSECONDSINFO:;%%
RETCODE = 0  Operation succeeded.

Query the information of the leap second offset between the UTC and the GPS
---------------------------------------------------------------------------
                      Leap Seconds Change Date  =  2017-1-1
                      Leap Seconds Change Time  =  07:59:59
Current Leap Second Offset Between UTC and GPS  =  17
   Next Leap Second Offset Between UTC and GPS  =  18
(Number of results = 1)


---    END

Output Description

Field Description

Leap Seconds Change Date

Indicates the date when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.

Leap Seconds Change Time

Indicates the time when the leap seconds changed. This parameter is set in compliance with the UTC. The format is as follows: HH:MM:SS. For example, 10:20:05.

Current Leap Second Offset Between UTC and GPS

Indicates the current leap second offset between the UTC and the GPS.

Next Leap Second Offset Between UTC and GPS

Indicates the next leap second offset between the UTC and the GPS.
