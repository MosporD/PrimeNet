List SRIO Port Configuration (LST SRIOPORT)

Network Element: BTS3900, BTS3900 LTE, BTS5900, BTS5900 LTE

Function

Use this command to list the configurations about an SRIO port.

Note

None.

Parameters

None.

Example

To list the SRIO port configuration, run the following command:
LST SRIOPORT:;
The result is shown as follows:
+++    0        2015-04-17 12:36:19
O&M    #826
%%LST SRIOPORT:;%%
RETCODE = 0  Operation succeeded.

List SRIO Port Configuration
----------------------------
Cabinet No.  Subrack No.  Slot No.  Port No.

0            0            1         0       
0            0            2         0       
(Number of results = 2)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the SRIO port is located.

Subrack No.

Indicates the subrack number of the board where the SRIO port is located.

Slot No.

Indicates the slot number of the board where the SRIO port is located.

Port No.

Indicates the number of the SRIO port.
