Display UDP Loopback Status (DSP UDPLOOP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the parameters of the User Datagram Protocol (UDP) loopback.

Note

None.

Parameters

Applicable Mode: G, U, L, N, R

GUI Value Range: 0~1

Unit: None

Example

To query the UDP loopback status with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, run the following command:
DSP UDPLOOP: CN=0, SRN=0, SN=7;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board that the UDP loopback belongs to.

Subrack No.

Indicates the subrack number of the board that the UDP loopback belongs to.

Slot No.

Indicates the slot number of the board that the UDP loopback belongs to.

Loopback Mode

Indicates the UDP loopback mode.

If this parameter is set to SPECIALIPUDPPORTREMOTE, the UDP packets from a BS that meet the specified conditions are looped back to the peer device.

If this parameter is set to ALLIPREMOTE, all the UDP packets received on a BS are looped back to the peer device.

If this parameter is set to SPECIALIPREMOTE, the UDP packets received on a BS, whose local and peer IP addresses are the same as the specified address couple, are looped back to the peer device.

VRF Index

Indicates the index of a VRF instance.

RX Source IP Address

Indicates the source IP address contained in loopback packets received by the local end.

RX Destination IP Address

Indicates the destination IP address contained in loopback packets received by the local end.

RX Source Port Number

Indicates the source UDP port number contained in loopback packets received by the local end. The destination UDP ports should not be reserved ports, such as ports 2152, 2231 and 65534.

RX Destination Port Number

Indicates the destination UDP port number contained in loopback packets received by the local end. The destination UDP ports should not be reserved ports, such as ports 2152 and 2231.

TX Source IP Address

Indicates the source IP address contained in loopback packets transmitted by the local end.

TX Destination IP Address

Indicates the destination IP address contained in loopback packets transmitted by the local end.

TX Source Port Number

Indicates the source UDP port number contained in loopback packets transmitted by the local end. The destination UDP ports can not be reserved ports, such as ports 2152 and 2231.

TX Destination Port Number

Indicates the destination UDP port number contained in loopback packets transmitted by the local end. The destination UDP ports can not be reserved ports, such as ports 2152, 2231 and 65534.

Local IP Address

Indicates the local IP address.

Peer IP Address

Indicates the peer IP address.

Loopback Time(min)

Indicates the duration of the UDP loopback.

Appoint Interface

Indicates whether the UDP loopback packet is transmitted through the specified port.

Subboard Type

Indicates the type of the subboard where the port for transmitting the UDP loopback packet is located.

Port Type

Indicates the type of the port for transmitting the UDP loopback packet.

Port No.

Indicates the number of the port for transmitting the UDP loopback packet.
