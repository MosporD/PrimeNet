Add IPv6 Destination Port for FTP Client (ADD FTPSCLTDPORT6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a destination port of IPv6 address that the FTP client accesses (that is, a listening port on the FTP server). The ports have a one-to-one relationship with destination IP addresses.

Note

  • [Co-MPT,eNodeB,gNodeB]There is a one-to-one mapping relationship between an IP address and a destination port. A maximum of 20 mapping relationships can be configured.

  • [Co-MPT,eNodeB,gNodeB]0:0:0:0:0:0:0:0 is a wildcard IPv6 address. Ports added to 0:0:0:0:0:0:0:0 take effect for all IPv6 addresses that are not configured.

Parameters

ID Name Description
SERVERIPV6 FTP Server IPv6 Address

Meaning: Indicates the IPv6 address of the FTP server.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
PORT Destination Port

Meaning: Indicates the port of the FTP server. If no port is added to an IP address using the ADD FTPSCLTDPORT6 command, port 21 is used for the IP address by default. If a port is added to an IP address using the ADD FTPSCLTDPORT6 command, the default port 21 is no longer valid for the IP address.

GUI Value Range: 21~65535

Unit: None

Actual Value Range: 21~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To add a destination port of IPv6 address with the parameters as follows: FTP Server IPv6 Address: 2001::2, Destination Port: 5001, run the following command:
ADD FTPSCLTDPORT6: SERVERIPV6="2001::2", PORT=5001;
