Remove Interface IP Address (RMV IFIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an interface IP address from a port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command is used to remove only the interface IP address that is added by running the ADD IFIP command. The added interface IP addresses can be listed by running the LST IFIP command.

  • The operation will interrupt the services or OM channels carried on the interface IP address. You are advised to run the CFM CB command to enable configuration data rollback.

  • [NodeB,eNodeB,gNodeB]You cannot remove an interface IP address used by a link such as a remote maintenance channel or BFD session.

Example

Example 1: To remove an interface IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, IP Address: 192.168.2.24, run the following command: 
RMV IFIP: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, IP="192.168.2.24";
Example 2: To remove an interface IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Subboard Type: E1_COVERBOARD, Port Type: MPGRP, Port No.: 1, IP Address: 192.168.11.23, run the following command: 
RMV IFIP: CN=0, SRN=0, SN=1, SBT=E1_COVERBOARD, PT=MPGRP, PN=1, IP="192.168.11.23";
