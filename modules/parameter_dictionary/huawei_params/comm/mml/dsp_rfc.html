Display RF Card (DSP RFC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the information about RF cards.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet housing the RF card.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]For a base station configured with an RFC MO, TYPE in an MPT MO must be set to UMPT.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack housing the RF card.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot housing the RF card.

GUI Value Range: 0~5

Unit: None

Actual Value Range: 0~5

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the dynamic information about Radio Frequency Card in cabinet 0, subrack 0, slot 0, run the following command:
DSP RFC: CN=0, SRN=0, SN=0;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet housing the RF card.

Subrack No.

Indicates the number of the subrack housing the RF card.

Slot No.

Indicates the number of the slot housing the RF card.

Start UL Frequency 0(0.1MHz)

Indicates the start uplink frequency of band 0 of the RF card.

End UL Frequency 0(0.1MHz)

Indicates the end uplink frequency of band 0 of the RF card.

Start DL Frequency 0(0.1MHz)

Indicates the start downlink frequency of band 0 of the RF card.

End DL Frequency 0(0.1MHz)

Indicates the end downlink frequency of band 0 of the RF card.

Indicates the end uplink frequency of band 1 of the RF card.

Indicates the end downlink frequency of band 1 of the RF card.

End UL Frequency 2(0.1MHz)

Indicates the end uplink frequency of band 2 of the RF card.

Indicates the end uplink frequency of band 3 of the RF card.

Start DL Frequency 3(0.1MHz)

Indicates the start downlink frequency of band 3 of the RF card.

Carrier Capability
