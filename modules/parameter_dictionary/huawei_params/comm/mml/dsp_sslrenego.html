Display SSL Renegotiation logs (DSP SSLRENEGO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query SSL renegotiation records, including the SSL renegotiation time, source IP address, destination IP address, receive port, and SSL renegotiation result.

Note

  • When the Renegotiation Response Type parameter is set to ALL, a maximum of 90 SSL renegotiation records can be queried. When the Renegotiation Response Type parameter is set to a value other than ALL, a maximum of 30 SSL renegotiation records can be queried.

  • After the base station is reset, the SSL renegotiation records will be cleared.

Parameters

ID Name Description
RENEGORESPTYPE Response Type

Meaning: Indicates the type of a response to an SSL renegotiation request.

GUI Value Range: ALL(All Type), SUCCESS(SUCCESS), DENY(DENY), FAILURE(FAILURE)

Unit: None

Actual Value Range: ALL, SUCCESS, DENY, FAILURE

MML Default Value: ALL(All Type)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
DSPNUM DSPNUM

Meaning: Indicates the maximum number of SSL renegotiation records that can be queried. The default value is 90.

GUI Value Range: 1~90

Unit: None

Actual Value Range: 1~90

MML Default Value: 90

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

Display SSL Renegotiation Logs:
+++    0        2014-09-07 01:31:53                                             
O&M    #536870927                                                               
%%DSP SSLRENEGO: RENEGORESPTYPE=3, DSPNUM=90;%%                                  

RETCODE = 0  Operation succeeded.                                               
                                                                                
List SSL Renegotiation Logs                                                     
---------------------------                                                     
Renegotiation Time   Source IP      Service IP      Service Port    Response Type         
                                                                                
2014-09-07 01:31:45  10.174.167.248  10.110.178.110   6007            SUCCESS
2014-09-07 01:31:22  10.174.167.248  10.110.178.110   6007            DENY               
2014-09-07 01:31:02  10.174.167.248  10.110.178.110   6007            FAILURE               
(Number of results = 3)                                                         
                                                                                
                                                                                
---    END

Output Description

Field Description

Renegotiation Time

Indicates the SSL renegotiation time.

Source IP

Indicates the source IP address of an SSL renegotiation request.

Service IP

Indicates the destination IP address of an SSL renegotiation request.

Service Port

Indicates the number of the port receiving an SSL renegotiation request.

Response Type

Indicates the type of a response to an SSL renegotiation request.
