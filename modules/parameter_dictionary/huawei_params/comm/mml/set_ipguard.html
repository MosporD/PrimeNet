Set Policy Against IP Attack (SET IPGUARD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the global parameters related to ARP spoofing detection, ARP strict learning, illegal packet detection, IPSec replay alarm detection, DOS attack, and ND Spoofing detection.

Note

  • ARP spoofing detection is enabled by default, but the default alarm threshold is 120. You need to manually adjust the threshold. If the ARP spoofing alarm threshold in the IP firewall attack defense policy is lower than the ARP packet flood threshold in flood attack defense, an ARP spoofing alarm cannot be reported.

  • [Co-MPT,eNodeB,gNodeB]ND spoofing detection is enabled by default, but the default alarm threshold is 120. You need to manually adjust the threshold. If the ND spoofing alarm threshold in the IP firewall attack defense policy is lower than the ND packet flood threshold in flood attack defense, an ND spoofing alarm cannot be reported.

Parameters

ID Name Description
ARPSPOOFCHKSW ARP Spoofing Check Switch

Meaning: Indicates whether to perform an ARP spoofing check. If this parameter is set to ENABLE, an alarm is reported when an ARP spoofing attack occurs. If this parameter is set to DISABLE, no alarm is reported when an ARP spoofing attack occurs.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ARPSPOOFALMTHD ARP Spoofing Alarm Threshold

Meaning: Indicates the ARP spoofing alarm threshold. When the ARP spoofing check switch is turned on, an ARP spoofing alarm is reported if the number of ARP update attempts reaches this threshold within one minute. Note that the number of ARP update attempts from trusted MAC addresses is not counted. This alarm is cleared if no request for updating the MAC address mapping to the IP address indicated by the alarm is received within one or two minutes.

GUI Value Range: 10~1000

Unit: None

Actual Value Range: 10~1000

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ARPLRNSTRICTSW ARP Learning Strict Switch

Meaning: Indicates whether to enable ARP strict learning. ARP learning strict is a function that enables a BS to learn the acknowledgement packets in response to only ARP request packets sent by itself. With ARP strict learning, the BS can reject most ARP request and acknowledge packet attacks.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
INVALIDPKTCHKSW Invalid Packet Check Switch

Meaning: Indicates whether to report an alarm when the number of invalid packets received by a BS exceeds a specified threshold. If this parameter is set to ENABLE, an alarm is reported when the number of invalid packets received by a BS exceeds the specified threshold. If this parameter is set to DISABLE, no alarm is reported when the number of invalid packets received by a BS exceeds the specified threshold. Invalid packets are those filtered according to the packet filter criteria.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
INVALIDPKTALMTHD Invalid Packet Alarm Threshold

Meaning: Indicates the threshold for the excessive flood packet alarm. When Invalid Packet Check Switch is set to ENABLE, the system measures the RX rate of invalid packets every 10 seconds. If the measured value exceeds this threshold, an excessive invalid packet alarm is reported. The alarm is cleared if the RX rate of invalid packets keeps below the threshold for 5 consecutive minutes.

Actual Value Range: 20~200000

REDIRECTDOSCHKSW IKEv2 Redirect DOS Check Switch

Meaning: Indicates the switch for checking IKEv2 redirection DOS attacks. When this parameter is set to ENABLE, ALM-25950 Base Station Being Attacked is reported when the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold in 300 consecutive seconds, with Specific Problem set to DOS Attack. After the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold, the base station does not respond to IKEv2 redirection packets. When this parameter is set to DISABLE, DOS attacks are not processed.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Impact on Radio Network Performance: None

MAXREDIRECTS Max Redirects Number

Meaning: Indicates the IKEv2 redirection DOS attack threshold. ALM-25950 Base Station Being Attacked is reported when the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold in 300 consecutive seconds, with Specific Problem set to DOS Attack. After the number of IKEv2 redirections received by the base station exceeds the IKEv2 redirection DOS attack threshold, the base station does not respond to IKEv2 redirection packets. This alarm is cleared when the number of IKEv2 redirections received by the base station is less than or equal to the IKEv2 redirection DOS attack threshold in 300 consecutive seconds.

Meaning: Indicates whether to detect ND spoofing. If this parameter is set to ENABLE, an alarm is reported when ND spoofing occurs. If this parameter is set to DISABLE, no alarm is reported when ND spoofing occurs.

NDSPOOFALMTHD ND Spoofing Alarm Threshold

Meaning: Indicates the threshold for reporting an ND spoofing alarm. When the number of ND spoofing times reaches the threshold, an alarm is reported. After ND spoofing detection is enabled, an ND spoofing alarm is reported if the number of ND update attempts exceeds the threshold within one minute. If any trusted MAC address exists, the update requests initiated by the trusted MAC address is not counted. This alarm is cleared when the IP address for which the alarm is generated does not receive any MAC address request within 1 minute to 2 minutes.

Example

To set policies for defense of IP firewall attacks with the parameters as follows: ARP Spoofing Check Switch: ENABLE, ARP Spoofing Alarm Threshold: 120, ARP Learning Strict Switch: ENABLE, Invalid Packet Check Switch: ENABLE, Invalid Packet Alarm Threshold: 2000, IPSec Replay Alarm Switch: ENABLE, IPSec Replay Alarm Threshold: 100, IKEv2 Redirect DOS Check Switch: ENABLE, Max Redirects Number: 5, ND Spoofing Check Switch: ENABLE, ND Spoofing Alarm Threshold: 10, run the following command: 
SET IPGUARD: ARPSPOOFCHKSW=ENABLE, ARPSPOOFALMTHD=120, ARPLRNSTRICTSW=ENABLE, INVALIDPKTCHKSW=ENABLE, INVALIDPKTALMTHD=2000, IPSECREPLAYCHKSW=ENABLE, IPSECREPLAYALMTHD=100, REDIRECTDOSCHKSW=ENABLE, MAXREDIRECTS=5, NDSPOOFCHKSW=ENABLE, NDSPOOFALMTHD=10;
