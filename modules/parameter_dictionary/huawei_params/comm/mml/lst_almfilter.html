List Alarm Filter (LST ALMFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the duration-based alarm filtering settings and times-based alarm filtering settings by alarm ID.

Note

None.

Parameters

ID Name Description
STARTAID Start Alarm ID

Meaning: Indicates the start ID of alarms to be listed. An alarm ID identifies a type of alarms, which indicates a specific fault or event. The alarm ID is the only index for alarms.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • STARTAID in the ALMFILTER MO must not be greater than ENDAID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
ENDAID End Alarm ID

Meaning: Indicates the end ID of alarms to be listed. An alarm ID identifies a type of alarms and indicates a specific fault or event. The alarm ID is the only index for alarms.

GUI Value Range: 1~65533

Unit: None

Actual Value Range: 1~65533

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • STARTAID in the ALMFILTER MO must not be greater than ENDAID.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
CNT Count

Meaning: Indicates the number of records to be displayed.

If this parameter is set to 0, all records are displayed.

GUI Value Range: 0~1000

Unit: None

Actual Value Range: 0~1000

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To list the filter configuration of the alarms numbered from 26202 to 26203, Count: 2, run the following command:
LST ALMFILTER: STARTAID=26202, ENDAID=26203, CNT=2;

Output Description

Field Description

Alarm ID

Indicates the alarm ID.The alarm ID is the only index for alarms.

Window for Raising Alarm(s)

Indicates the time window of alarm generating.

Threshold for Raising Alarm(s)

Indicates the accumulated fault persistence duration in the alarm generating time window.

Window for Ceasing Alarm(s)

Indicates the time window of alarm clearing.

Threshold for Ceasing Alarm(s)

Indicates the accumulated fault persistence duration in the alarm clearing time window.

Alarm Stat Time Window(s)

Indicates the time window in which alarms are measured.

Alarm Raise Frequency Threshold(time)

Indicates the accumulated number of fault occurrences in the alarm stat time window (STATTW).

Alarm Cease Frequency Threshold(time)

Indicates the accumulated number of fault recoveries in the alarm stat time window (STATTW).
