List IPv6 parameters of interface (LST INTERFACEPARA6)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list IPv6 parameters of interface.

Note

None.

Parameters

None.

Example

To list IPv6 parameters of interface, run the following command:
LST INTERFACEPARA6:;
The result is shown as follows:
+++    0        2018-11-08 23:06:38
O&M    #164
%%LST INTERFACEPARA6:;%%
RETCODE = 0  Operation succeeded.

List IPv6 parameters of interface
---------------------------------
       Interface ID  =  0
        SEND Switch  =  Enable
      SEND Delta(s)  =  300
         SEND Drift  =  1
SEND Fuzz-Factor(s)  =  1
DHCPv6 Relay Switch  =  Disable
(Number of results = 1)


---    END

Output Description

Field Description

Interface ID

Indicates the ID of an interface.

SEND Switch

Indicates whether the interface opens the Send protocol and currently only supports the Nonce and Timestamp mechanisms.

SEND Delta(s)

Indicates the maximum difference between the moment when the ND message is received by the local side and the time at which the ND message is sent to the peer.

SEND Drift

Indicates the percentage of the maximum value of the receiver-to-sender system time difference value.

SEND Fuzz-Factor(s)

Indicates the maximum time to live for a message.if the time at which the ND message is received by the local side is greater than delta-value, but within the Fuzz-value time range, it can still be received by the interface.

DHCPv6 Relay Switch

Indicates whether to enable the DHCPv6 relay function on an interface. If this parameter is set to ON, the interface can receive multicast packets of DHCPv6 requests sent by lower-level base stations.
