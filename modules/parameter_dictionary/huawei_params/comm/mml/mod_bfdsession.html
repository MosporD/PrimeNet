Modify BFD Session (MOD BFDSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a BFD session.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed to change the value of the CATLOG parameter to RELIABILITY, route interlock is triggered.

  • After a BFD session with the CATLOG parameter set to RELIABILITY is added, the effect of the previous route interlock is eliminated if the value of the CATLOG parameter is changed to MAINTENANCE.

  • Changing the source IP address, destination IP address, hop type, or protocol version of a BFD session will result in the reestablishment of the BFD session, which may interrupt services. For details, see "Service Interrupted After Modification" of each parameter.

  • Modifying the BFD Authentication Switch, BFD Authentication Algorithm or BFD Authentication Key Chain ID may result in an abnormal BFD session and service or OMCH interruption. For details, see "Service Interrupted After Modification" of each parameter.

  • [Co-MPT,NodeB,eNodeB,gNodeB]During the modification of a BFD session, the source and destination IP addresses of the session cannot be changed if the session is referenced by an IPSec tunnel pair.

SRCIP Source IP

Meaning: Indicates the source IP address of a BFD session. The source IP address of a BFD session must be a device IP address of a specified board (for example, the IP address of an Ethernet port or a port that carries a PPP link or MP group) or a logical IP address (for example, the IP address of a loopback port), but cannot be set to the same value as the IP address of a remote maintenance channel or a negotiated IP address. Note that a BFD session cannot be configured as a single-hope session if its source IP address is a logical IP address.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Source IP parameter in the BFD MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

MML Default Value: None

Recommended Value: None

CATLOG Session Catalog

Meaning: Indicates the type of a BFD session. If this parameter is set to MAINTENANCE, this BFD session is used only for continuity check (CC). If this parameter is set to RELIABILITY, the BFD session is used to trigger route interlock. Route interlock enables the standby route to take over once the active route becomes faulty, and therefore prevents service interruption caused by route failures.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Session Catalog parameter in the BFD MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Example

To modify the configuration of the BFD session with the parameters as follows: Cabinet No.: 0, Subrack No.: 0: Slot No.: 6, Session ID: 0, Source IP: 192.168.5.5, Destination IP: 192.168.5.6, Min TX Interval: 10, Min RX Interval: 10, Detection Multiplier: 3, Session Catalog: MAINTENANCE, run the following command: 
MOD BFDSESSION: CN=0, SRN=0, SN=6, BFDSN=0, SRCIP="192.168.5.5", DSTIP="192.168.5.6", MINTI=10, MINRI=10, DM=3, CATLOG=MAINTENANCE;
