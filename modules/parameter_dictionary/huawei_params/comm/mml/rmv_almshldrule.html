Remove Alarm Shielding Rule (RMV ALMSHLDRULE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an alarm shielding rule.

Note

  • You can run the LST ALMSHLDRULE command to query the configured alarm shielding rules.

  • After an alarm shielding rule is removed, the NE will operate as follows: If the alarm is generated and the remaining alarm shielding rules are not met, the NE regards the time when the alarm is unshielded as the time when the alarm is generated, and the NE will report the alarm again. In this case, the alarm can be displayed in the active alarm list and the alarm log shows that the alarm is not cleared. If the alarm is not generated, no operation is required.

Parameters

ID Name Description
INDEX Index

Meaning: Indicates the ID of an alarm shielding rule.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove an alarm shielding rule with Index set to 0, run the following command:
RMV ALMSHLDRULE: INDEX=0;
