Display RX Channel (DSP RXBRANCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic attributes of the RX channel of the RRU or RFU. The dynamic attributes include information such as the attenuation, initial correction value of the Received Total Wideband Power (RTWP), frequency band, and bandwidth.

Note

  • Channel information of an AAU supporting beamforming cannot be queried using this command. Run the DSP RRU command to query the uplink and downlink frequency bands of this AAU.

  • [Co-MPT,eNodeB,gNodeB]For some RRUs working in LTE TDD mode, the actual physical status of the TX channel must be consistent with that of the RX channel. That is, setting Physical Switch of TX Channel to off will also set Physical Switch of RX Channel to off at the same time.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the RX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the RX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the RX channel is located.

RX Channel No.

Indicates the number of the RX channel of the RRU or RFU.

Logical Switch of RX Channel

Indicates the logical switch of the RX channel of the RRU or RFU, which can be set to ON or OFF. ON indicates that the logical switch of the RX channel is set to on and OFF indicates that the logical switch of the RX channel is set to off. This parameter is set to ON by default. The switch can be set by running the MOD RXBRANCH command.

Physical Switch of RX Channel

Indicates the actual physical status of the RX channel of the RRU or RFU, the switch of which is set to ON by default. When the logical switch of the RX channel is OFF, the physical switch of the RX channel must be OFF. When the logical switch of the RX channel is ON and the RRU is running properly, the physical switch of the RX channel of the RRU can be ON.

LNA Switch of RX Channel

Indicates the low noise amplifier (LNA) switch for the RRU receive channel. If this parameter is set to ON, the switch is turned on. If this parameter is set to OFF, the switch is turned off. NULL indicates that the query fails or the board does not support the query.

Attenuation(0.5dB)

Indicates the attenuation of the RX channel of the RRU or RFU.

RTWP Initial0(0.1dB)

Indicates the initial correction value of the Received Total Wideband Power (RTWP) for carrier 0. The big offset between the RTWP in empty load and the theoretical background noise can be adjusted through the setting of initial correction value of the RTWP.

RTWP Initial1(0.1dB)

Indicates the initial correction value of the RTWP for carrier 1.

RTWP Initial2(0.1dB)

Indicates the initial correction value of the RTWP for carrier 2.

RTWP Initial3(0.1dB)

Indicates the initial correction value of the RTWP for carrier 3.

RTWP Initial4(0.1dB)

Indicates the initial correction value of the RTWP for carrier 4.

RTWP Initial5(0.1dB)

Indicates the initial correction value of the RTWP for carrier 5.

RTWP Initial6(0.1dB)

Indicates the initial correction value of the RTWP for carrier 6.

RTWP Initial7(0.1dB)

Indicates the initial correction value of the RTWP for carrier 7.

Band 1 UL Minimum Frequency(0.1MHz)

Indicates the minimum uplink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9250, the minimum uplink frequency of the RRU is 9250 x 0.1 MHz, which equals to 925 MHz.

Band 1 UL Maximum Frequency(0.1MHz)

Indicates the maximum uplink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9450, the maximum uplink frequency of the RRU is 9450 x 0.1 MHz, which equals to 945 MHz.

Band 1 UL Bandwidth(MHz)

Indicates the bandwidth supported by each RX channel band 1 in the uplink. This bandwidth is an instantaneous bandwidth.

Band 1 Carrier Number

Indicates the number of carriers operating on band 1.

Band 2 UL Minimum Frequency(0.1MHz)

Indicates the minimum uplink frequency supported by the RRU or RFU band 2.This parameter is NULL,when the RRU does not support multiple bands. For example, if this parameter is set to 9250, the minimum uplink frequency of the RRU is 9250 x 0.1 MHz, which equals to 925 MHz.
