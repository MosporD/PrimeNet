Add MLPPP Link (ADD MPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add an MLPPP link to an MLPPP group.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]One MLPPP link can be added to only one MLPPP group.

  • [Co-MPT,NodeB,eGBTS,eNodeB]One board has eight internal TOP resources. One TOP resource can be used by only one E1/T1 port on the backplane, inter-board timeslot cross connection, or inter-board MLPPP link. During configuration of an inter-board timeslot cross connection (refer to the LST TSCROSS command), the idle internal TOP resources with the same number are occupied on the boards in the source and destination slots. During configuration of an E1/T1 port on the backplane (refer to the LST BACKE1T1 command), the internal TOP resource that has the same number as the E1/T1 port number on the board is occupied. During configuration of an inter-board MLPPP link (see the LST MPLNK command), the idle internal TOP resources with the same number are occupied on the boards in the source and destination slots.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before adding an MLPPP link to an MP group, ensure that the MP group has been configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]MLPPP links in one MP group must have the same configuration.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the LMPT/UMPT/WMPT/UMDU/GTMUb/GTMUc is the main control board, a maximum of 128 MP links can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum of 12 MP links can be configured on a WMPT and the link number must range from 0 to 11. A maximum of 16 MP links can be configured on a UMPTa/UMPTb/UMDU/UTRP (subboard type: UIEC/UAEC). A maximum of 4 MP links can be configured on a GTMUb/GTMUc.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Currently, the HDLC CRC16 check is used on the base station side.

  • [Co-MPT,eGBTS]In the GTMUb/GTMUc board, a maximum of 4 MLPPP links can be configured, and the total number of MLPPP links and PPP links cannot exceed 4.

  • [Co-MPT,eGBTS]For a GTMUb or GTMUc, the link number must range from 0 to 3.

  • [eNodeB]When the main control board is an LMPT, the MLPPP link can be successfully configured but fail to take effect.
