Clear 225-400 V DC Power Distribution Unit Output Protection (CLR HVDCOUTPUTPROTECT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to close the circuit breaker in a 225-400 V DC power distribution unit (HVDU). If no alarm related to the safety of 225-400 V DC power distribution is reported, the 225-400 V DC power output to the load is resumed. If an alarm related to the safety of 225-400 V DC power distribution is reported, the circuit breaker is still open and the 225-400 V DC power distribution is under protection.

Note

  • You can specify the subboard number in this command. The subboard number can be queried using the DSP HVDCSTATE command.

  • This command is applicable only to 225-400 V DC power distribution units. Executing this command fails if the PMU managing the HVDU does not support this command or the specified object of a 225-400 V DC power distribution unit does not exist.

Example

To close the circuit breaker in a 225-400 V DC power distribution unit with parameters as follows: Cabinet No.: 0, Subrack No.: 7, Slot No.: 0, Subboard No.: 50:
CLR HVDCOUTPUTPROTECT: CN=0, SRN=7, SN=0, SubNo=50;
