Block Board (BLK BRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to block a specified board.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the board is blocked, the resource logic of the board is unavailable. In a multi-mode base station, the services of the peer mode will not be interrupted if the common board is blocked.

  • The boards supporting block include the BBP, RRU, RFU, UBRI, MERC, AARU, GTMU, UMDU, MPMU, MPRF and RMU.

  • After a UMDU board is blocked, its baseband services become unavailable.

  • The RMU and MERC can only be blocked immediately.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]After a board is blocked, if links cannot be set up for the associated RRUs/RFUs or links cannot work at the maximum CPRI line rate, you need to run the STR CPRILBRNEG command to initiate negotiation.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The parameter value DELAY or SHUTDOWN takes effect only when the board carries services. Otherwise, the board is blocked immediately even when the Block Type parameter is set to DELAY or SHUTDOWN.

BLKTP Block Type

Meaning: Indicates the block type of the board. IMMEDIATE(Immediate) means that the board is blocked and services carried on the board are interrupted immediately after the command is executed. SHUTDOWN(Shutdown) means that the board is blocked when no service is carried on the board. DELAY(Delay) means that the board is blocked when no service is carried on the board or after the time specified by the Duration of the shutting down state parameter is reached. In LTE mode, all the three block types are supported. In UMTS or NR mode, only the IMMEDIATE type is supported, and the IMMEDIATE type takes effect even when this parameter is set to SHUTDOWN or DELAY. In GSM mode, only the IMMEDIATE type is supported, and the board is blocked 10s after the system tries to hand over traffic on this board when this parameter is set to SHUTDOWN or DELAY.

Example

To block a board with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 3, Block Type: IMMEDIATE, run the following command:
BLK BRD: CN=0, SRN=0, SN=3, BLKTP=IMMEDIATE;
