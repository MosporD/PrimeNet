Add User Plane Peer (ADD USERPLANEPEER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a user-plane peer end.

Note

  • When security automatic establishment is enabled on a user plane peer, the IPSec Auto Configure Switch is enabled for the user plane peer and a security peer is referenced. Therefore, before enabling this feature, ensure that the security peer to be referenced has been added by using the ADD SECURITYPEER command.

  • If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the IPv4 user-plane link:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during setup of an IPv4 user-plane link, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the IPv4 user-plane link:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

    If IPSec Auto Configure Switch is set to DISABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group, an IPsec tunnel can be set up by manually configuring all the preceding IPsec-related objects.

  • User plane automatic setup does not support the internal user plane path with the type of FIXED.

  • When the user plane is set up automatically, the base station automatically sets up an internal user plane path with the type of ANY.

  • When the user plane is set up automatically, if the VRF index, local IP address and peer IP address of the internal user plane path set up automatically are same as the VRF index, RX destination IP address and RX source IP address of a running loopback by executing the command SET UDPLOOP whose loopback mode is SPECIALIPUDPPORTREMOTE and the RX destination Port Number is 65040, if the loopback and the internal user plane path are on the same board, the loopback will be stopped automatically.

  • A user-plane peer that is automatically created by the system will be written into the database two minutes after it takes effect. During this period, if a new user-plane peer is manually created with the same peer IP address as the user-plane peer to be written into the database, the system deletes the user-plane peer that is automatically created and releases the services carried on the user-plane peer. Then the manually configured user-plane peer data takes effect.

  • System specifications: When a UMPTg/UMPTga board serves as the main control board, a base station supports a maximum of 3300 user-plane peers. When a WMPT/LMPT/UMPTa/UMPTb/UMDU board serves as the main control board, a base station supports a maximum of 1024 user-plane peers. When UMPTe board serves as the main control board, a base station supports a maximum of 1536 user-plane peers.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The IP address of the user plane peer cannot be the same as any configured DEVIP, IPADDR4 or any IP address configured by running the ADD PPPLNK or ADD MPGRP command.

  • [Co-MPT,eNodeB,gNodeB]The IPv6 address of the user plane peer cannot be the same as any configured IPADDR6.

  • [Co-MPT,eNodeB,gNodeB]A user-plane peer that is automatically created by the system will be written into the database two minutes after it takes effect. During this period, if a new user-plane peer is manually created with the same peer IPv6 address as the user-plane peer to be written into the database, the system deletes the user-plane peer that is automatically created and releases the services carried on the user-plane peer. Then the manually configured user-plane peer data takes effect.

  • [gNodeB]The IP address of the user plane peer cannot be the same as any configured DEVIP, IPADDR4.

Parameters

ID Name Description
UPPEERID User Plane Peer ID

Meaning: Indicates the ID of the user-plane peer. The value of UPPEERID in the user-plane peer configured by users ranges from 0 to 65535. The value of UPPEERID in the USERPLANEPEER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]If UPPEERID is set to a value in the range of 0 to 65535, CTRLMODE must be set to MANUAL_MODE, and AUTOCFGFLAG must be set to MANUAL_CREATED. If UPPEERID is set to a value in the range of 70000 to 79999, CTRLMODE must be set to AUTO_MODE, and AUTOCFGFLAG must be set to AUTO_CREATED.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the USERPLANEPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to any value in the range of 1 to 7, IPSECSWITCH cannot be set to ENABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
IPVERSION IP Version

Meaning: Indicates the version of the user-plane peer IP address.

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: IPv4(IPv4)

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the USERPLANEPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to any value in the range of 1 to 7, IPSECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the USERPLANEPEER MO, if IPVERSION is set to IPv6 and CTRLMODE is set to MANUAL_MODE, IPSECSWITCH must be set to DISABLE.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

IPSECSWITCH IPSec Auto Configure Switch

Meaning: Indicates whether to enable automatic user-plane IPsec tunnel setup based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. If this parameter is set to ENABLE, an IPsec tunnel is automatically set up to encrypt transmitted data. If this parameter is set to DISABLE, no IPsec tunnel is automatically set up. If the value of this parameter is changed from ENABLE to DISABLE using the MOD USERPLANEPEER command, the system deletes the automatically set up IPsec tunnel.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: If the networking mode does not support IPSec or IPSec tunnels are to be set up by manually configuring IPSec MOs, this parameter must be set to DISABLE.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the USERPLANEPEER MO, if IPVERSION is set to IPv4 and VRFIDX is set to any value in the range of 1 to 7, IPSECSWITCH cannot be set to ENABLE.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the USERPLANEPEER MO, if IPVERSION is set to IPv6 and CTRLMODE is set to MANUAL_MODE, IPSECSWITCH must be set to DISABLE.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: The base station cannot access the network if this parameter is set to DISABLE and no IPSec tunnel has been set up between the user-plane host and user-plane peer for the internal user-plane paths in an IPSec-protected network.

Applicable Mode: G, U, L, N

STATICCHK Static Check Switch

Meaning: Indicates whether to enable the GTP-U static detection function for a link. When this parameter is set to ENABLE, the GTP-U static detection function is enabled for a link. When this parameter is set to DISABLE, the GTP-U static detection function is disabled for a link. When this parameter is set to FOLLOW_GLOBAL, the setting of the switch for the GTP-U static detection function is the same as that of the base station-level GTP-U detection switch. This parameter is valid only when STATICCHKMODE is set to UPPEERSTATICCHK(User-Plane Peer Static Check) in the GEPMODELPARA MO. This parameter takes effect only in LTE and NR.

GUI Value Range: DISABLE(Disable), ENABLE(Enable), FOLLOW_GLOBAL(Same as the GTP-U static detection switch)

Unit: None

Actual Value Range: DISABLE, ENABLE, FOLLOW_GLOBAL

MML Default Value: FOLLOW_GLOBAL(Same as the GTP-U static detection switch)

Recommended Value: FOLLOW_GLOBAL(Same as the GTP-U static detection switch)

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a user-plane peer with the parameters as follows: User Plane Peer ID: 0, IP Version: IPv4, Peer IP Address: 192.168.1.28, IPSec Auto Configure Switch: DISABLE, run the following command:
ADD USERPLANEPEER: UPPEERID=0, IPVERSION=IPv4, PEERIPV4="192.168.1.28", IPSECSWITCH=DISABLE;
