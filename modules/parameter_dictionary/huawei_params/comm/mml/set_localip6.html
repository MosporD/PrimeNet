Set Local OM IPv6 Address (SET LOCALIP6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the IPv6 address of a local maintenance channel.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [eNodeB,gNodeB]After this command is executed at the local end, if the new IPv6 address for the local maintenance channel is different from the currently used IPv6 address for the local maintenance channel, the local maintenance channel becomes unavailable. When this occurs, the message indicating operation succeeded cannot be reported.

  • [eNodeB,gNodeB]The IPv6 function is supported only when a UMPT/UMDU board functions as the active main control board.

Parameters

ID Name Description
IP6 IPv6 Address

Meaning: Indicates the IPv6 address of an OM channel. This IPv6 address must be a link-local address.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]In a LOCALIP6 MO, IP6 must be a link-local address whose prefix is greater than or equal to 10.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N
PFXLEN Prefix Length

Meaning: Indicates the prefix length of the IPv6 address of a local maintenance channel.

GUI Value Range: 1~128

Unit: None

Actual Value Range: 1~128

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To set the IPv6 address of the local maintenance channel with the following parameters: IP Address: FE80::200:200, Prefix Length: 64, run the following command:
SET LOCALIP6: IP6="FE80::200:200", PFXLEN=64;
