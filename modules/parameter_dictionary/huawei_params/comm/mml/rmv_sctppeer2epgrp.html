Delete SCTP Peer from End Point Group (RMV SCTPPEER2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an SCTP peer from an end point group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB,eNodeB,gNodeB]If an end point with transmission bearer established is removed from an endpoint group, services will be interrupted.

  • [Co-MPT,NodeB,eNodeB,gNodeB]This command takes effect only for UMTS, LTE, and NR.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If this command is executed, a base station will remove the SCTP link and CP bearer that have been automatically created for an SCTP peer.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met, this command will cause the system to remove the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects that have been automatically configured for an SCTP link:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group and the SCTPPEER object.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met, this command will cause the system to remove the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects that have been automatically configured for an SCTP link:

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the SCTPHOST object in the same end point group and the SCTPPEER object.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • [Co-MPT,eNodeB,gNodeB]If this command is executed, a base station will remove the IPv6 SCTP link and CP bearer that have been automatically created for an SCTP peer.

Example

To remove an SCTP peer from an end point group with the parameters as follows: End Point Group ID: 0, SCTP Peer ID: 0, run the following command:
RMV SCTPPEER2EPGRP: EPGROUPID=0, SCTPPEERID=0;
