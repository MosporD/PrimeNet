Display Backup Status (DSP BKPSTATUS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query information about the backup status, including software packages, configuration data, and logs.

Note

The slot number in this command is set to the slot number of the first board in the HA group. For example, if the HA group consists of the main control boards configured in slot 6 and slot 7, the slot number is set to 6.

Example

To query information about backup status with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, run the following command:
DSP BKPSTATUS: CN=0, SRN=0, SN=6;
The result is shown as follows:

Output Description

Field Description

Backup Switch

Indicates the backup switch which cannot be set by the MML command. The switch is controlled dynamically by the BS. If the switch is turned on, the backup is allowed. If the switch is turned off, the backup is prohibited.

Backup Status

Indicates the backup status. There are four types of backup status. Ready indicates that the initial backup is not started. Initial backup is the first backup after the startup of the system, and all files are backed up. Daily backup is to back up the configuration files and software packages every five minutes. Idle indicates that the backup is not performed currently.

Backup Start Time

Indicates the start time of backup.

Backup Progress

Indicates the current backup progress.

Backup Failure Times After Startup

Indicates the number of backup failures. Periodical backups do not affect the operation of the BS.
