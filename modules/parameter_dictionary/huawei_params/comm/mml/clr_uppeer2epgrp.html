Clear Automatically Established User Plane Peer from End Point Group (CLR UPPEER2EPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a user-plane peer that is automatically established from an end point group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If an automatically established end point that has set up a transmission bearer is removed from an end point group, services are interrupted.

  • After this command is executed, the base station removes the internal user-plane paths that are automatically created for the automatically established the user-plane peer.

  • If the USERPLANEPEER and SECURITYPEER objects that are automatically established are removed from the specified EPGROUP object and are no longer referenced by any other object, the USERPLANEPEER and SECURITYPEER objects will be automatically removed.

OPTYPE Operation Type

Meaning: Indicates whether to clear user-plane peers based on IDs or IP addresses. If this parameter is set to UPPEERID, the user-plane peer ID is specified to clear data. If this parameter is set to PEERIP, the user-plane peer IP address is specified to clear data.

Example

To clear the automatically established user-plane peer from an end point group with parameters as follows: End Point Group ID: 0, Operation Type: UPPEERID, User Plane Peer ID: 70000, run the following command:
CLR UPPEER2EPGRP: EPGROUPID=0, OPTYPE=UPPEERID, UPPEERID=70000;
