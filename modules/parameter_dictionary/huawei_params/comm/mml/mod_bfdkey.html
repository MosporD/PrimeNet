Modify BFD Key (MOD BFDKEY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a key in the BFD key chain.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Modifying the index and key of BFD authentication may result in an abnormal BFD session and service or OMCH interruption.

  • If the base station is interconnected with a router provided by Cisco to establish a BFD session, it is recommended that the local key length not exceed 15 characters. Otherwise, the BFD session negotiation may fail.

Parameters

ID Name Description
KEYCHAINID BFD Authentication Key Chain ID

Meaning: Indicates the ID of a configured BFD key chain.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
KEYID KEY Identity

Meaning: Indicates the index of a key in a BFD key chain, which must be consistent with the index of the key at the peer end.

GUI Value Range: 0~255

Unit: None

Actual Value Range: 0~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
KEY KEY String

Meaning: Indicates the key settings in a BFD key chain, which must be consistent with the key settings at the peer end.

GUI Value Range: 1~20 characters

Unit: None

Actual Value Range: 1~20 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify the configuration of the BFD key with the parameters as follows: BFD Authentication Key Chain ID: 0, KEY Identity: 0, KEY String: *****:
MOD BFDKEY: KEYCHAINID=0, KEYID=0, KEY="*****";
