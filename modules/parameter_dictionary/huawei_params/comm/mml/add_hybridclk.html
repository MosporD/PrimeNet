Add Hybrid Reference Clock (ADD HYBRIDCLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a hybrid reference clock.

Note

  • Before adding a hybrid clock source, configure the time synchronization clock source and frequency synchronization clock source.

  • The hybrid clock source added by running this command takes effect only in automatic clock source selection mode and inherits the priority of the IPCLK clock source.

  • When a hybrid clock source is added, the IP clock link must be a 1588 OC_SLAVE link if the time synchronization clock source type is IPCLK.

To add a hybrid reference clock source with the clock number of 0, run the following command:
ADD HYBRIDCLK: TCLKSRC=IPCLK, FCLKSRC=SYNCETH;
