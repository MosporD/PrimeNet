Set Scramble Mode (SET SCRAM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the scramble mode of the Inverse Multiplexing on ATM (IMA) group, User-Network Interface (UNI) link, or fractional ATM link.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]The associated IMA group, UNI link, or fractional ATM link has been configured.

  • [Co-MPT,NodeB]The scramble mode of the ATM link must be the same as that of the E1/T1 port that carries the ATM link. If LNCODE (line code) of the E1/T1 port is set to AMI, the ATM link must be scrambled.

  • [Co-MPT,NodeB]The execution of this command will automatically terminate the ongoing IMA group test.

  • [Co-MPT,NodeB]This operation may interrupt the services or OM channels carried. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Example

To modify the scramble mode of an IMA group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: IMA, Port No.: 0, Scramble Mode: DISABLE, run the following command:
SET SCRAM: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=IMA, PN=0, SCRAM=DISABLE;
