Remove MO Instance Reserved Parameter (RMV MOCRSVDPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove MO instance reserved parameter.

Note

  • The configurations of reserved parameters must strictly comply with the definition and declaration of the reserved parameter list released with the version. Configurations that do not comply with the declaration do not take effect. If a non-declared reserved parameter definition is delivered through configuration activation, the configuration activation will fail.

  • Reserved parameters exist only in specific versions. After an upgrade, reserved parameters are automatically migrated to formal parameters or deleted. For details, see the version declaration.

Parameters

ID Name Description
MOCNAME MO Class Name

Meaning: Indicates the name of the MOC object whose reserved parameter definition is to be added.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MOIKEY MO Instance Key

Meaning: Indicates the keyword description of the MOI object corresponding to the reserved parameter. The information must match the specific MOI object keyword.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
RSVDPARAID MO Instance Reserved Parameter ID

Meaning: Indicates the ID of the reserved parameter to be added.

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove MO instance reserved parameter with the parameters as follows: MO Class Name: "RRUCHAIN", MO Instance Key: "0", MO Instance Reserved Parameter ID: "CATE", run the following command:
RMV MOCRSVDPARA: MOCNAME="RRUCHAIN", MOIKEY="0", RSVDPARAID="CATE";
