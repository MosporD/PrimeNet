Modify Web LMT Login Policy (SET WEBLOGINPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the policy for logging in to the LMT.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Modifying the policy for logging in to the Web LMT cause the Web LMT to reset.

  • This command takes no effect to local Web LMT.

  • Before modifying the TLS/SSL version, ensure that the browser supports the configured TLS/SSL version. Otherwise, you cannot log in to the NE using the Web LMT.

  • When setting the TLS/SSL version, you are advised to use TLS1.2/TLS1.3 for SSL connection. SSL3.0, TLS1.0 and TLS1.1 are reserved to be compatible with the browser of earlier versions.

  • If session idle timeout is set to a value less than the idle duration of an existing session, the session idleness times out immediately.

  • If session maximum lifetime is set to a value less than the lifetime of an existing session, the session times out immediately.

Parameters

ID Name Description
POLICY WebLMT Login Policy

Meaning: Indicates the policy for logging in to the Web LMT.

The value COMPATIBLE indicates that if http is entered in the address bar of a browser, the HTTP is used for and after the login. If https is entered in the address bar of a browser, the HTTPS is used for and after the login.

The value HTTPS_ONLY indicates that no matter whether http or https is entered in the address bar of a browser, the HTTPS is used for and after the login.

The value LOGIN_HTTPS_ONLY indicates that no matter whether http or https is entered in the address bar of a browser, the HTTPS is used for login and the HTTP is used after the login.

GUI Value Range: COMPATIBLE(Compatible), HTTPS_ONLY(Https_only), LOGIN_HTTPS_ONLY(Login_https_only)

Unit: None

Actual Value Range: COMPATIBLE, HTTPS_ONLY, LOGIN_HTTPS_ONLY

MML Default Value: None

Recommended Value: HTTPS_ONLY(Https_only)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SSLVER TLS/SSL Version

Meaning: Indicates the TLS/SSL version supported by the Web LMT. You are not advised to use SSL3.0, TLS1.0 and TLS1.1 because they have security risks.

Disuse statement: In the later versions, the value SSLV3(SSL3.0) and TLSV10(TLS1.0) will be removed from the value range of this parameter. In the current version, the value can still be configured, but the value SSLV3(SSL3.0) can not take effect, the value TLSV10(TLS1.0) can take effect. Therefore, you are not advised to use the value SSLV3(SSL3.0) and TLSV10(TLS1.0).

GUI Value Range: SSLV3(SSL3.0), TLSV10(TLS1.0), TLSV11(TLS1.1), TLSV12(TLS1.2), TLSV13(TLS1.3)

Unit: None

Actual Value Range: SSLV3, TLSV10, TLSV11, TLSV12, TLSV13

MML Default Value: None

Recommended Value: TLSV12(TLS1.2),TLSV13(TLS1.3)

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TLS1.2 version cannot be disabled for SSLVER in the WEBLMT MO.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TLS1.3 version cannot be disabled for SSLVER in the WEBLMT MO.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
IDLETIMEOUT Session Idle Timeout

Meaning: Indicates the timeout duration of session idleness. When the idleness duration of a Web LMT session exceeds the value of this parameter, the Web LMT server automatically clears the session. If this parameter is set to 0, the timeout of session idleness is not allowed, which reduces the session security. You are not advised to set this parameter to 0.

GUI Value Range: 0~1440

Unit: min

Actual Value Range: 0~1440

MML Default Value: None

Recommended Value: 10

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The smaller the value of this parameter, the faster the session idleness times out. If this parameter is set to a value too large, the session is idle for a long time and is not cleared, which reduces the session security.

Applicable Mode: G, U, L, N, R
MAXLIFETIME Session Maximum Lifetime

Meaning: Indicates the maximum lifetime of a session. When the lifetime of a Web LMT session exceeds the value of this parameter, the Web LMT server automatically clears the session in a forcible manner.If this parameter is set to 0, the session lifetime is infinitely long, which reduces the session security. You are not advised to set this parameter to 0.

GUI Value Range: 0~10080

Unit: min

Actual Value Range: 0~10080

MML Default Value: None

Recommended Value: 480

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: The smaller the value of this parameter, the shorter the lifetime of a session. If this parameter is set to a value too small, the session is cleared within a short period of time. As a result, user tasks are interrupted. If this parameter is set to a value too large, the maximum lifetime of a session is long. As a result, the attack probability and security risk increase. Therefore, set this parameter to a proper value.

Applicable Mode: G, U, L, N, R
IDLEFORCESW Session Idle Force Timeout Switch

Meaning: Indicates how the idle session detection mechanism on the Web LMT is implemented. If this switch is turned on, a session without any user operations enters the idle state. If this switch is turned off, a session enters the idle state only when no user is performing operations on the session and no tracing, monitoring, or batch processing task is running.

GUI Value Range: OFF(OFF), ON(ON)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: When this switch is turned on, a session without any user operations enters the idle state. After the session times out, all tasks on the Web LMT are interrupted. When this switch is turned off, a session with an ongoing tracing, monitoring, or batch processing task does not enter the idle state even if no user operation is performed. In this case, the session does not exit due to timeout.

Applicable Mode: G, U, L, N, R

Example

To modify the WEBLOGINPOLICY configuration with the parameters as follows: WebLMT Login Policy:"LOGIN_HTTPS_ONLY", TLS/SSL Version:"SSLVER=SSLV3-0&TLSV10-0&TLSV11-1&TLSV12-1&TLSV13-1", run the following command:
SET WEBLOGINPOLICY: POLICY=LOGIN_HTTPS_ONLY, SSLVER=SSLV3-0&TLSV10-0&TLSV11-1&TLSV12-1&TLSV13-1;
