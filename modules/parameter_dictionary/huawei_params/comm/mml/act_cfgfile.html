Activate Configuration Data (ACT CFGFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to activate a configuration file. After the configuration file is successfully activated, configuration data in this file is used as system configuration. The configuration file to be activated can be the minimum configuration file that is issued with the NE software or the configuration file that matches with the NE version software backed up in the system or downloaded from the MAE.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When a configuration file is activated repeatedly without any modification on the configuration file, a message indicating operation success is displayed after the command is executed, but the file is not activated again.

  • The configurations of different software versions are incompatible with each other. Therefore, you can only activate the configuration file that is backed up on the current version software. The configuration takes effect during the system initialization after reset. If an incompatible configuration file is activated, the system initialization fails, and therefore the system configuration is restored to the status before activation.

  • Execution of this command will increase the CPU usage, and CPU overload may affect UE access. Therefore, it is recommended that you run this command when the system has a light load.

  • After a base station is reset, the system checks the validity of a file to be activated. If the file is invalid, the system restores its pre-activation configurations.

  • After this command is executed, the current configuration data is overwritten, which may interrupt the connection with the client. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

  • Execution of this command will delete all configuration files that are not activated.

  • The value of the PRODUCTTYPE parameter can be changed only for main control boards supporting multimode concurrency. If the PRODUCTTYPE parameter is not specified, the system uses the current site type by default.

  • If the EFT parameter is set to AFTER_RESET, the NE is not reset immediately. After the command is executed, all configuration operations fail. If the NE is not reset within 10 minutes, ALM-26245 Configuration Data Inconsistency will be reported. If the EFT parameter is set to IMMEDIATELY, the NE is reset immediately so that the configuration takes effect. If the services of the peer mode are set up on a local board that is to be reset, the peer services are unavailable when the board is being reset.

Unit: None

MML Default Value: XML(XML Mode)

Recommended Value: XML (XML mode)

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
EFT Effect Type

Meaning: Indicates the mode in which the configuration takes effect. If this parameter is set to AFTER_RESET(After Reset), the configuration takes effect after boards are reset, which does not occur immediately after this command is executed. In this case, configuration operations are not allowed until the boards are reset manually or through other commands (for example, RST BRD and ACT SOFTWARE). If this parameter is set to IMMEDIATELY, the board is immediately reset.

GUI Value Range: IMMEDIATELY(Immediately), AFTER_RESET(After Reset)

Unit: None

Actual Value Range: IMMEDIATELY, AFTER_RESET

MML Default Value: None

Recommended Value: IMMEDIATELY(Immediately)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PRODUCTTYPE Product Type

Meaning: Indicates the type of base station. When you run the ACT CFGFILE command with Mode set to LEAST and Effect Type set to IMMEDIATELY, the minimum configuration file is used during the base station startup and the value of this parameter is changed to a specified type of base station after the base station is reset.

ACT CFGFILE: EFT=IMMEDIATELY;
