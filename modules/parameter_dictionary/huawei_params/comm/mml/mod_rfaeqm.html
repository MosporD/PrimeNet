Modify RF Access Equipment (MOD RFAEQM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of RF access equipment.

Note

None.

Example

To modify a set of RFA equipment with the parameters as follows: RFA Equipment ID: 0, Port Num: 1, Cabinet No. of Port 1: 0, Subrack No. of Port 1: 0, Slot No. of Port 1: 3, Port No. of Port 1: 0, and Transmission Mode of Port 1: UL,run the following command:
MOD RFAEQM: RFAEQMID=0, PORTNUM=1, CN1=0, SRN1=0, SN1=3, PN1=0, DLULMODE1=UL;
