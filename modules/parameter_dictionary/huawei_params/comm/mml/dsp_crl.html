Display CRL Status (DSP CRL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of CRLs.

Note

This command performs operations to files, which may cause query failures when the system is busy. In this case, try again later.

Parameters

ID Name Description
CERTNAME CRL File Name

Meaning: Indicates the file name of a CRL. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CERTNAME in a CRL MO is recommended to enter ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: \ / : * ? " < > |.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a CRL MO is being added, the CERTNAME is case-insensitive; but when a CRL MO is referenced, the CERTNAME is case-sensitive.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the information about all CRLs, run the following command:
DSP CRL:;
+++    0        2011-11-08 13:06:52
O&M    #4915
%%DSP CRL:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

CRL File Name

Indicates the file name of a CRL. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

Issuer

Indicates the issuer of a CRL.

This Update

Indicates the current update time of the CRL.

Next Update

Indicates the next update time of the CRL.

CRL Server IP Address Last Used

Indicates the CRL server IP address used to successfully apply or update the certificate for the last time. After a system reset, version upgrade, or manually configuration of the CRL file, the value of this parameter is NULL.

Last Update Time of CRL

Indicates the time when the certificate is successfully applied or updated. After a system reset, version upgrade, or manually configuration of the CRL file, the value of this parameter is NULL.

Status

Indicates the loading status of a CRL.
