Set Time Source (SET TIMESRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the time source and automatic switch.

Note

  • If the time derived from the time source is later than the year 2033, the time setting does not take effect.

  • If the time source is a GPS clock, its clock mode cannot be free-running.

  • In the dual-mode scenario, if Time Source is set to GPS, clock signals are obtained from the local GPS rather than the peer GPS.

  • If the NE time is not accurate and the time needs to be manually adjusted, set the Time Source parameter to NONE. In this case, the NE does not synchronize time with external time sources.

  • If TIMESRC is set to SYSCLK, the BS synchronizes time with a system clock only when the clock synchronization mode is time synchronization and the system clock is available.

  • Only GPS and NTP support the automatic time source switchover function.

Parameters

ID Name Description
TIMESRC Time Source

Meaning: Indicates the external reference time source of the NE.

GUI Value Range: NTP(NTP), GPS(GPS), NONE(None), SYSCLK(SYSCLK)

Unit: None

Actual Value Range: NTP, GPS, NONE, SYSCLK

MML Default Value: None

Recommended Value: NTP(NTP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
AUTOSWITCH Automatic Switch

Meaning: Indicates whether to enable automatic time source switchover. When the switch is turned on, the system switches over the time source when time synchronization fails. When the switch is turned off, the system does not switch over the time source.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the time source to NTP and autoswitch to ON, run the following command:
SET TIMESRC: TIMESRC=NTP, AUTOSWITCH=ON;
