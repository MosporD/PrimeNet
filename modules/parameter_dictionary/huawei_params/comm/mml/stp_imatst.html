Stop IMA Group Test (STP IMATST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to stop an IMA group test.

Note

[Co-MPT,NodeB]A user cannot stop an IMA group test started by another user.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the board where the IMA group is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SRN Subrack No.

Meaning: Indicates the subrack number of the board where the IMA group is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SN Slot No.

Meaning: Indicates the slot number of the board where the IMA group is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
SBT Subboard Type

Meaning: Indicates the type of sub-board on the board where the IMA group is established.

GUI Value Range: E1_COVERBOARD(E1 Cover Board), BASE_BOARD(Base Board)

Unit: None

Actual Value Range: E1_COVERBOARD, BASE_BOARD

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IMAGRP MO, if SN is within the range from 0 to 5, this parameter must be set to E1_COVERBOARD.
  • When adding, querying, modifying, removing or resetting the IMAGRP MO, set this parameter to BASE_BOARD if SN is set to 6 or 7.
  • When querying or stopping a test on the IMAGRP MO whose SN is set to 6 or 7, set this parameter to BASE_BOARD.
  • When starting a test on the IMAGRP MO whose SN is set to 6 or 7, set this parameter to BASE_BOARD or BACK_BOARD.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
IMAGRPN Group No.

Meaning: Indicates the number of the IMA group.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB]In the IMAGRP MO, if SBT is set to BASE_BOARD, this parameter can be set to 0 or 1.
  • In the IMAGRP MO, if SBT is set to E1_COVERBOARD, the value range of this parameter is from 0 to 3.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To stop an IMA group test with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Group No.: 0, run the following command: 
STP IMATST: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, IMAGRPN=0;
