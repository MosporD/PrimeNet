Display Diesel Generator (DSP DIESELGEN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a diesel generator.

Note

If the operational status of the PMU that manages the diesel generator is unavailable, the query fails.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the PMU managing the diesel generator is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the PMU managing the diesel generator is located.

GUI Value Range: 7

Unit: None

Actual Value Range: 7

MML Default Value: 7

Recommended Value: 7

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the PMU managing the diesel generator is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the dynamic information about the diesel generator with the cabinet number of 0, run the following command:
DSP DIESELGEN: CN=0;
The result is shown as follows:
+++    0        2009-06-24 11:25:43
O&M    #35
%%DSP DIESELGEN: CN=0;%%
RETCODE = 0  Operation succeeded.

      Total Running Time(h)  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the PMU managing the diesel generator is located.

Subrack No.

Indicates the number of the subrack where the PMU managing the diesel generator is located.

Slot No.

Indicates the number of the slot where the PMU managing the diesel generator is located.

Oil Level[cm(0.1in.)]

Indicates the oil level of the diesel generator.

Diesel Generator Current(A)

Indicates the current of the diesel generator.

Total Running Time(h)

Indicates the total running time of the diesel generator.
