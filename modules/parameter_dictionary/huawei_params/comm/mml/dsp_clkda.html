Display Clock DA (DSP CLKDA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the initial DA value, center DA value, and current DA value of a clock.

Note

None.

Example

To query the DA values of a clock in slot 7, run the following command:
DSP CLKDA: SN=7;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Initial DA

Indicates the initial DA (Digital to Analog) value. It is the center DA value of the main control board before delivery.

Center DA

Indicates the center DA (Digital to Analog) value. After the reference clock is locked for 96 hours, the average of current DA values in this period is used as the center DA value.

Current DA

Indicates the current DA (Digital to Analog) value. The current DA value equals to the center DA value after the system resets. The current DA value corresponds to the control voltage of the oven controlled crystal oscillator (OCXO) on the main control board. The output frequency of the OCXO is adjusted by adjusting the current DA value until the system clock is exact.
