Add IP Address of DHCP Server (ADD DHCPSVRIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add the IP address of a DHCP server.

Note

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUb/GTMUc is the main control board, a maximum of 4 DHCPSVRIP objects can be configured.

  • The user-configured DHCP Relay IP parameter takes effect as the DHCP relay IP address in co-transmission implemented through backplane interconnection regardless of whether the route is configured using the destination IP address or source IP address. However, in panel cascading or co-transmission implemented through panel interconnection, the IP address of the port on the panel and the OM IP address are used as the DHCP relay IP addresses instead of the user-configured DHCP Relay IP parameter.

Parameters

ID Name Description
DHCPSVRIP DHCP Server IP Address

Meaning: Indicates the IP address of the DHCP server.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]DHCPSVRIP in a DHCPSVRIP MO must be a valid IP address of class A, B, or C. In addition, it cannot be 0.x.x.x or 127.x.x.x.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DHCPRELAYIPSW DHCP Relay IP Switch

Meaning: Indicates whether to enable or disable the DHCP relay IP address. When this parameter is set to ENABLE, the DHCP relay IP address can be configured.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: DISABLE(Disable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
DHCPRELAYIP DHCP Relay IP

Meaning: Indicates the DHCP relay IP address. When this parameter is configured, the base station uses it as the source IP address of the DHCP relay.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add the DHCP server IP address "10.19.19.11" with DHCP relay IP switch disabled, run the following command: 
ADD DHCPSVRIP: DHCPSVRIP="10.19.19.11", DHCPRELAYIPSW=DISABLE;
