Start CFM Ping (CFMPING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start the CFM link loopback.

Note

  • Before running this command, ensure that the MD, MA, MEPs, and RMEP are configured.

  • The PING, PING6, TRACERT, TRACERT6, CFMTRACE, CFMPING, and UDPECHO commands cannot be executed simultaneously on one board.

  • Before performing continuity check between the BS and an RMEP, ensure that the RMEP is configured on the BS.

  • To stop the execution of this command, press Ctrl+Q or run the STP PATHCHK command.

  • If the Ethernet OAM Type parameter is modified when the SET ETHOAM command is executed, the CFM link loopback will be stopped automatically.

Example

To start the CFM loopback test with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, Destination Type: MAC, MAC Address: 00E2-FC00-57B7, run the following command:
CFMPING: MDNAME="CHINA", MANAME="SHANGHAI", DSTTYPE=MAC, MAC="00E2-FC00-57B7";
