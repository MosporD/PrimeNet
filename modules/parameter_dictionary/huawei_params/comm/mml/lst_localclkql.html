List Clock Quality Level (LST LOCALCLKQL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the clock quality level of a BS.

Note

None.

Parameters

None.

Example

To list the clock quality level of a BS, run the following command:
LST LOCALCLKQL:;
The result is shown as follows:
+++    0        2011-01-24 19:56:21
O&M    #1389
%%LST LOCALCLKQL:;%%
RETCODE = 0  Operation succeeded.

List Clock Quality Level
------------------------
Quality Level  =  QL-SSU-B
(Number of results = 1)


---    END

Output Description

Field Description

Quality Level

Indicates the clock quality level of the BS. The values for this parameter are listed in quality descending order. QL-PRC indicates the highest quality level.
