List Global EP Model Parameters (LST GEPMODELPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the global EP model parameters.

Note

None.

Parameters

None.

Example

To list the global EP model parameters, run the following command:
LST GEPMODELPARA:;
The result is as follows:
+++      0            2017-05-03 17:04:41
O&M    #7052
%%LST GEPMODELPARA:;%%
RETCODE = 0  Operation succeeded.

    Direct IPsec Automatic Deletion Switch  =  Enable

Output Description

Field Description

Static Check Mode

Indicates the effective mode of the GTP-U static detection switch in the EP model. When this parameter is set to UPPEERSTATICCHK(User-Plane Peer Static Check), the user-plane peer static detection switch takes effect. When this parameter is set to EPSTATICCHK(Endpoint Group Static Check), the endpoint group static detection switch takes effect. This parameter is valid only for the link-level GTP-U static detection in the EP model configured on a base station. This parameter takes effect only for LTE and NR.

Direct IPsec Automatic Deletion Switch

Indicates whether to enable the direct IPsec automatic deletion function. When this parameter is set to ENABLE, the direct IPsec automatic deletion function is enabled. If IKE negotiation for a direct IPsec tunnel fails, the SECURITYPEER, IKEPEER, IPSECPOLICY, and IPSECBINDITF MOs that correspond to the IPsec tunnel are automatically deleted. In IPv4 scenarios, the corresponding IPSECBIND, ACL, and ACLRULE MOs are also automatically deleted. In IPv6 scenarios, the corresponding ACL6, ACLRULE6, TUNNELITF, INTERFACE, and IPROUTE6 MOs are also automatically deleted. When this parameter is set to DISABLE, the direct IPsec automatic deletion function is disabled. This switch takes effect only for IPsec tunnels that are automatically established in endpoint configuration mode.

Direct IPsec Automatic Deletion Timer(min)

Indicates the timer for deleting a direct IPsec tunnel that is faulty due to failed IKE negotiations. After a direct IPsec tunnel is faulty due to IKE negotiation failures, the following are true: - When this parameter is set to 0, the faulty IPsec tunnel is deleted without alarm reporting. - When this parameter is set to a value greater than 0, the fault alarm is reported. If the IKE negotiation failures persist after the timer specified by this parameter expires, the faulty IPsec tunnel is deleted and the fault alarm is cleared.

Direct IPsec Update Switch

Indicates whether to enable the direct IPsec automatic update function. When IPSec Auto Configure Switch in the USERPLANEHOST MO is changed from DISABLE to ENABLE, the local IKE IP address in the SECURITYHOST MO is changed, SeGW Switch in the SECURITYHOST MO is changed from ENABLE to DISABLE, or an X2/Xn interface is added, the following are true: (1) If this parameter is set to ENABLE, a direct IPsec self-update procedure will be automatically triggered, during which the direct IPsec link is updated. (2) If this parameter is set to DISABLE, a direct IPsec self-update procedure will not be automatically triggered and the direct IPsec link will not be updated. If the value of this parameter is changed from DISABLE to ENABLE, automatic update of the direct IPsec link is also triggered.
