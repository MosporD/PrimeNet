Modify RAE Subunit (MOD RAESUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a Remote eAntenna Extension (RAE) subunit.

Note

  • The port to be set in this command must already be configured on an RRU or RFU. Otherwise, the execution result of this command indicates that the RF module is not configured.

  • Ensure that the numbers of the cabinet, subrack, and slot to be set are consistent with those of the RRU or RFU, because the system is unable to identify the inconsistency.

  • When the cabinet number of an RAE subunit is 255, the connection between the RAE subunit and the RRU or RFU is not configured. In this case, the subrack number and slot number of this RAE subunit are set to 255.

Example

To modify an RAE subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, Subunit Name: RAE_01, Connect Port Cabinet No.: 0, Connect Port Subrack No.: 60, Connect Port Slot No.: 0, run the following command:
MOD RAESUBUNIT: DEVICENO=0, SUBUNITNO=1, SUBNAME="RAE_01", CONNCN=0, CONNSRN=60, CONNSN=0;
