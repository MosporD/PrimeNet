Modify GPS Position (MOD GPSPOS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the location information of a GPS antenna.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the configured location information is inconsistent with the actual location of the GPS antenna, the GPS antenna may fail to track the GPS satellite.

  • The location of a GPS clock source on an RRU or CGPS cannot be configured.

  • When the satellite card does not support setting the location information or AGL(Antenna Angle), this command fails to be executed.

Parameters

ID Name Description
WPOS Way to Get Position

Meaning: Indicates the method of obtaining the position of the GPS satellite.

GUI Value Range: USER_CONFIG(User Config), SEARCH_WITH_DURATION(Search with duration), SEARCH_WITH_PRECISION(Search with precision), AUTO_SEARCH(Auto Search)

Unit: None

Actual Value Range: USER_CONFIG, SEARCH_WITH_DURATION, SEARCH_WITH_PRECISION, AUTO_SEARCH

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
LONG Antenna Longitude

Meaning: Indicates the longitude of the GPS antenna. A negative value indicates the west longitude, and a positive value indicates the east longitude.

GUI Value Range: -180000000~180000000

Unit: 1e-6 degree

Actual Value Range: -180~180, step: 1e-6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter setting must be consistent with the network plan. Otherwise, the location precision decreases.

Applicable Mode: G, U, L, R, N
LAT Antenna Latitude

Meaning: Indicates the latitude of the GPS antenna. A negative value indicates the south latitude, and a positive value indicates the north latitude.

GUI Value Range: -90000000~90000000

Unit: 1e-6 degree

Actual Value Range: -90~90, step: 1e-6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: This parameter setting must be consistent with the network plan. Otherwise, the location precision decreases.

Applicable Mode: G, U, L, R, N

Meaning: Indicates the altitude of the GPS antenna. A negative value indicates that the GPS antenna is below the sea level, and a positive value indicates that the GPS antenna is above the sea level.

GUI Value Range: -1000~10000(metric system);-3281~32808(imperial system)

Unit: m(metric system);ft(imperial system)

Actual Value Range: -1000~10000(metric system);-3281~32808(imperial system)

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Meaning: Indicates the duration for tracing the position of the GPS satellite.

GUI Value Range: 1~2880

Unit: min

MML Default Value: None

Meaning: Indicates the precision requirement for tracing the position of the GPS satellite.

GUI Value Range: 1~100(metric system);3~328(imperial system)

Actual Value Range: 1~100(metric system);3~328(imperial system)

AGL Antenna Angle

Meaning: Indicates the antenna angle, which is the angle with the horizontal line. If the clock source has not been activated, the value NULL will be displayed. If the clock source has been activated, the value NULL indicates that this parameter is not supported by the hardware or the hardware is faulty.

GUI Value Range: 0~89

Unit: degree

Actual Value Range: 0~89

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
POSCHECKSW Position Check Switch

Meaning: Indicates the position check switch of a satellite card. If this switch is turned on, the NE records the position where a satellite card is locked as the initial position and calculates the deviation between this initial position and the current position. If the deviation is excessively large, the NE regards the output signals of the satellite card unreliable and reports ALM-26120 GPS Clock Output Unavailable. The position check is applicable only when the NE position is fixed and the satellite card in the BBU supports this check.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the GPS location information with the parameters as follows: Way to Get Position: USER_CONFIG, Antenna Longitude: 160000000, Antenna Latitude: 80000000, Antenna Altitude: 900, run the following command:
MOD GPSPOS: WPOS=USER_CONFIG, LONG=160000000, LAT=80000000, ALT=900;
