List IPv6 Destination Port for FTP Client (LST FTPSCLTDPORT6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the list of server ports and IPv6 addresses configured for the FTP client.

Note

  • [Co-MPT,eNodeB,gNodeB]In the case of access to an FTP server whose IP address is not included in the list, port 21 is used by default.

  • [Co-MPT,eNodeB,gNodeB]0:0:0:0:0:0:0:0 is a wildcard IPv6 address. Ports added to 0:0:0:0:0:0:0:0 take effect for all IPv6 addresses that are not configured.

Parameters

None.

Example

To list the server port and IPv6 address list, run the following command:
LST FTPSCLTDPORT6:;
The result is shown as follows:
+++    0        2014-11-26 15:30:13
O&M    #28
%% LST FTPSCLTDPORT6:;%%
RETCODE = 0  Operation succeeded.

FTP Server IP and Port List
---------------------------
FTP Server IPv6 Address  Destination Port

2001::2                5001
(Number of results = 1)


---    END

Output Description

Field Description

FTP Server IPv6 Address

Indicates the IPv6 address of the FTP server.

Destination Port

Indicates the port of the FTP server. If no port is added to an IP address using the ADD FTPSCLTDPORT6 command, port 21 is used for the IP address by default. If a port is added to an IP address using the ADD FTPSCLTDPORT6 command, the default port 21 is no longer valid for the IP address.
