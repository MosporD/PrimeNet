Export Inventory File (EXP DEVFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to export a device file. You can export the device file containing one table or all tables.

Note

Only the latest exported device file is saved on the NE. Therefore, the device file exported by running this command needs to be uploaded immediately.

Parameters

ID Name Description
FN File Name

Meaning: Indicates the name of the exported device file.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
TB Export Table No.

Meaning: Indicates the number of the output segment. The value 0 indicates all segments. The value 1 indicates the device basic information description segment. The value 2 indicates the link description segment. The value 3 indicates the module description segment. The value 4 indicates the configuration description segment. The value 5 indicates the peer device description segment. The value 6 indicates the host version description segment. The value 7 indicates the cabinet description segment. The value 8 indicates the subrack description segment. The value 9 indicates the board and flash electronic label description segment. The value 10 indicates the slot description segment. The value 11 indicates the port description segment. The value 12 indicates the antenna description segment. The value 13 indicates the license description segment.

GUI Value Range: 0~13

Unit: None

Actual Value Range: 0~13

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To export the device file of Export Table No. 5, run the following command:
EXP DEVFILE: TB=5;
