Display Ethernet OAM 3AH Status (DSP ETH3AH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the IEEE802.3ah Ethernet OAM.

Note

None.

Parameters

ID Name Description
ETH0AM3AHID Ethernet OAM 3AH Object ID

Meaning: Indicates the ID of the ETHOAM3AH MO.

GUI Value Range: 0~47

Unit: None

Actual Value Range: 0~47

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CLEAR Clear Statics

Meaning: Indicates whether to delete the historical statistics. If this parameter is set to YES, the historical statistics are deleted and a new round of statistics collecting starts upon completion of the query.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: NO(No)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of the IEEE802.3ah Ethernet OAM with the parameters as follows: Ethernet OAM 3AH Object ID: 1, run the following command: 
DSP ETH3AH: ETH0AM3AHID=1;
The result is shown as follows:

Output Description

Field Description

Ethernet OAM 3AH Object ID

Indicates the ID of the ETHOAM3AH MO.

Ethernet Port ID

Indicates the ID of an Ethernet port.

Cabinet No.

Indicates the cabinet number of the board where the Ethernet port is located.

Subrack No.

Indicates the subrack number of the board where the Ethernet port is located.

Slot No.

Indicates the slot number of the board where the Ethernet port is located.

Subboard Type

Indicates the type of sub-board on the board where the Ethernet port is located.

Current State

Indicates the Finite State Machine (FSM) status of an Ethernet OAM 3AH.

Number of TX Information OAMPDUs(packet)

Indicates the number of transmitted Info OAM Protocol Data Units (PDUs). The Info OAM PDUs are used to finish the search process.

Number of TX Event OAMPDUs(packet)

Indicates the number of transmitted Event OAM PDUs. The Event OAM PDUs are used to notify the peer end of a link event.

Number of TX Fault OAMPDUs(packet)

Indicates the number of transmitted Fault OAM PDUs. The Fault OAM PDUs are used to notify the peer end of a link failure.

Number of TX Loopback Control OAMPDUs(packet)

Indicates the number of transmitted loopback OAM PDUs. The loopback OAM PDUs are used for remote loopback control.

Number of TX Dropped OAMPDUs(packet)

Indicates the number of discarded OAM PDUs on the TX channel.

Total Number of TX OAMPDUs(packet)

Indicates the total number of transmitted OAM PDUs, including the information OAM PDUs, event OAM PDUs, loopback OAM PDUs, and discarded OAM PDUs.

Number of RX Information OAMPDUs(packet)

Indicates the number of Info OAM PDUs received on a port.

Number of RX Event OAMPDUs(packet)

Indicates the number of received Event OAM PDUs.

Number of RX Fault OAMPDUs(packet)

Indicates the number of received Fault OAM PDUs.

Number of RX Loopback Control OAMPDUs(packet)

Indicates the number of received Loopback Control OAM PDUs.

Number of RX Dropped OAMPDUs(packet)

Indicates the number of discarded OAM PDUs on the RX channel.

Total Number of RX OAMPDUs(packet)

Indicates the total number of received OAM PDUs, including the information OAM PDUs, event OAM PDUs, loopback OAM PDUs, and discarded OAM PDUs.
