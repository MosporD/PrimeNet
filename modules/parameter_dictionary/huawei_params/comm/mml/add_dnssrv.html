Add DNS Server (ADD DNSSRV)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a DNS server.

Note

  • [Co-MPT,eGBTS,eNodeB,gNodeB]When the ACL rule automatic setup and deletion function is enabled for packet filtering and a DNS server of the IPv4 version is added, the system automatically generates ACL rules of the TCP and UDP protocols; when a DNS server of the IPv6 version is added, the system does not generate the ACL rule for the corresponding DNS server.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]The client UDP port is 64711 during DNS resolution. It is recommended that this UDP port not be simultaneously used for other services during DNS resolution.

Example

To add DNS server with the parameters as follows: DNS SERVER ID.: 0, IP Version: IPv4, DNS Client IPv4: 192.168.2.24, DNS Server IPv4: 192.168.2.25, DNS Server Port No.: 53, DSCP: 48, run the following command: 
ADD DNSSRV: DNSSRVID=0, IPVER=IPv4, DNSCIP4="192.168.2.24", DNSSIP4="192.168.2.25", PN=53, DSCP=48;
