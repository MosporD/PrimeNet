List Security Log (LST SECLOG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the security log online. You can set Source, Operator, Domain, IP Mode, Workstation, Start Time, End Time, Event Type, Event, Event Level, Result, or Maximum Return Records during the execution of this command to filter the query results.

Note

  • The command lists 64 logs from 00:00:00 of that day in default parameter settings.

  • The value emscomm of Operator indicates that this log is generated due to interaction between the network management system (NMS) and the NE.

  • The value emscommts of Operator indicates that this log is generated due to interaction between the trace server in the NMS and the NE.

  • If the security log query result shows that the operator is "System", the security logs are recorded by the base station system.

  • During log encryption and decryption, if you run the LST SECLOG command, the system displays a message indicating that the system is busy. In this case, try again later.

  • The value emscommneteco of Operator indicates that this log is generated due to interaction between the NetEco and the NE.

Example

To list the security logs (maximum number: 64) saved on an NE from 00:00:00 of that day, run the following command:
LST SECLOG:;
The result is shown as follows:
