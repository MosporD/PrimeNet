List SCTP Host Configuration (LST SCTPHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of an SCTP hosts.

Note

None.

Parameters

ID Name Description
SCTPHOSTID SCTP Host ID

Meaning: Indicates the ID of the SCTP host.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, N

Example

To list the configuration of SCTP hosts, run the following command:
LST SCTPHOST:;
The result is as follows:

Output Description

Field Description

SCTP Host ID

Indicates the ID of the SCTP host.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the IP protocol version of an SCTP host.

First Local IP Address

Indicates the first local SCTP IPv4 address, which is used by the base station to establish a signaling channel. That is, this address is the first local IPv4 address for automatically establishing an SCTP link.

First Local IPv6 Address

Indicates the first local SCTP IPv6 address, which is used by the base station to establish a signaling channel. That is, this address is the first local IPv6 address for automatically establishing an SCTP link.

IPSec Auto Configure Switch for First Local IP

Indicates whether to use the first local IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the first local IP address of the SCTP host. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPHOST command, the system automatically deletes the IPsec tunnel that has been automatically set up.

Security Host ID for First Local IP

Indicates the ID of the security host referenced by the first IP address of the SCTP host.

Second Local IP Address

Indicates the second local SCTP IPv4 address, which is used by the base station to establish a signaling channel. That is, this address is the second local IPv4 address for automatically establishing an SCTP link.

Second Local IPv6 Address

Indicates the second local SCTP IPv6 address, which is used by the base station to establish a signaling channel. That is, this address is the second local IPv6 address for automatically establishing an SCTP link.

IPSec Auto Configure Switch for Second Local IP

Indicates whether to use the second local IP address to automatically set up an IPsec tunnel between the local and peer ends based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. The IPsec tunnel is used to encrypt data to be transmitted on the SCTP link that is set up using the second local IP address of the SCTP host. When the value of this parameter is changed from ENABLE to DISABLE using the MOD SCTPHOST command, the system automatically deletes the IPsec tunnel that has been automatically set up.

Security Host ID for Second Local IP

Indicates the ID of the security host referenced by the second IP address of the SCTP host.

Local SCTP Port No.

Indicates the number of the local SCTP port used in automatic setup of an SCTP link.

SCTP Parameters Template ID

Indicates the ID of the SCTP parameter template referenced by the SCTP link that is automatically set up.

DTLS Policy ID

Indicates the sequence number of a DTLS configuration policy, if this parameter is set to a valid value, the DTLS function is enabled on the SCTP link. Currently, only NR supports the DTLS function. If this function is enabled on other modes, the SCTP link will be faulty.

DTLS Connection Policy

Indicates the DTLS connection policy. DTLS_ONLY indicates that the local end uses only DTLS connections. If the peer end does not support or is not configured with DTLS, the negotiation fails. DTLS_PRIORITY indicates that the local end attempts to establish a DTLS connection for the first time. If the peer end does not support or is not configured with DTLS, the local end uses the SCTP connection. If this parameter is set to DTLS_PRIORITY, the security is reduced. Therefore, you are advised not to set this parameter to DTLS_PRIORITY. This parameter applies only to NR.

SCTP Authentication Chunk List

Indicates the list of SCTP chunk types for which the local end requires the peer end to support authentication. The IDs of SCTP chunks that can be authenticated by the base station are 0, and 3 to 9. For details, see RFC4895 and RFC4960. Currently, SCTP block authentication is supported only in DTLS over SCTP scenarios. This parameter applies only to NR.

User Label

Indicates the description of the SCTP host.

Simple Mode Switch

Indicates the simplified mode switch of an SCTP host. When this parameter is set to SIMPLE_MODE_OFF, the SCTP host is not used for simplified configuration. When this parameter is set to S1SIMPLE_MODE_ON, the SCTP host is used for S1 interface simplified configuration. When this parameter is set to X2SIMPLE_MODE_ON, the SCTP host is used for X2 interface simplified configuration. When this parameter is set to EX2SIMPLE_MODE_ON, the SCTP host is used for eX2 interface simplified configuration. The parameter takes effect only in LTE.

First End Point Group ID for Control Plane

Indicates the control-plane end point group ID of the first operator corresponding to an SCTP host. This parameter takes effect only on LTE.

First End Point Group ID for User Plane

Indicates the user-plane end point group ID of the first operator corresponding to an SCTP host. This parameter takes effect only on LTE.

First End Point Group Type for User Plane

Indicates the user-plane end point group type of the first operator corresponding to an SCTP host. When this parameter is set to COMMON, the user-plane end point group of the first operator is a common group. When this parameter is set to CENTRALIZED_EX2, the user-plane end point group of the first operator is a dedicated group for the centralized eX2. This parameter takes effect only in LTE.

Operator Sharing Switch

Indicates whether multiple operators can share an SCTP host. This parameter takes effect only on LTE.

Second End Point Group ID for Control Plane

Indicates the control-plane end point group ID of the second operator corresponding to an SCTP host. This parameter takes effect only on LTE.

Second End Point Group ID for User Plane

Indicates the user-plane end point group ID of the second operator corresponding to an SCTP host. This parameter takes effect only on LTE.
