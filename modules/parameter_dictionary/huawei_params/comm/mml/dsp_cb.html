Display CB Information (DSP CB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the information about the confirmed Configuration Baselines (CBs). When the CB name is not specified, all detailed information about the CB will be queried, including the currently used CBs and CBs for confirmation, are displayed. If a CB name is specified, the detailed information of the CB is displayed.

Note

None.

Parameters

ID Name Description
NAME Name of CB

Meaning: Indicates the name of the CB. The name of each CB must be unique, and is case insensitive. The name cannot contain any of the following characters: question mark (?), exclamation mark (!), right angle bracket (>), left angle bracket (<), bar (|), slash (/), backslash (\), colon (:), and asterisk (*). It is not recommended that the name contain any space, because an error message will be displayed when the name containing spaces is not supported by a file system in the BS. Different file systems differ from one another in their support for the CB name containing spaces.

GUI Value Range: 1~48 characters

Unit: None

Actual Value Range: 1~48 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Output Description

Field Description

Current CB Status

Indicates the CB confirmation status.

Current Active CB

Indicates the name of the active CB.

Name of CB

Indicates the name of the CB. The name of each CB must be unique, and is case insensitive. The name cannot contain any of the following characters: question mark (?), exclamation mark (!), right angle bracket (>), left angle bracket (<), bar (|), slash (/), backslash (\), colon (:), and asterisk (*). It is not recommended that the name contain any space, because an error message will be displayed when the name containing spaces is not supported by a file system in the BS. Different file systems differ from one another in their support for the CB name containing spaces.

Application Type

Indicates the extend type of application software in the NE.

Software Version

Indicates the software version.

Valid Flag

Indicates whether the CB is valid. If the software version or configuration file associated with a CB cannot be found, the CB is invalid.

Automatic Roll Back Switch

Indicates whether to enable the automatic rollback function.

Create Time

Indicates the time when the CB is confirmed.

Roll Back Time(min)

Indicates the time between opening Automatic Roll Back Switch of CB and triggering Automatic Roll Back Condition.

Latest Active Time

Indicates the latest time the CB is successfully activated. The time is updated when the CB is confirmed, activated, or rolled back.

Comment of CB

Indicates the brief description of the CB.

The value NULL indicates that there is no brief description of the CB.

Roll Back Condition

Indicates the condition of triggering Automatic Roll Back, including OMCH FAULT and OMCH AND SERVICE FAULT.

Roll Back Remaining Time

Indicates the remaining time before the system checks whether automatic rollback needs to be performed. If the value of this parameter contains an asterisk (*), the link does not meet rollback conditions at the expiry of the rollback duration. In this case, the remaining rollback time starts over from five minutes and the system checks rollback conditions again. For details about the rollback conditions rechecking mechanism, see Note in the CFM CB command.
