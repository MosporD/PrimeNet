Display CMP Session (DSP CMPSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of CMP sessions. A CMP session is used by the BS to apply for a new device certificate or to update a device certificate.

Note

  • The CMPSESSION MO whose session ID is 1, 3, 5, 7, 9, 11 or 17 is used for applying for a device certificate. The CMPSESSION MO whose session ID is 2, 4, 6, 8, 10, 12, 14, 16 or 18 is used for updating a device certificate. The CMPSESSION MO whose session ID is 13 ,15 or any value from 19 to 65535 is reserved.

  • When the REQ DEVCERT command is executed to apply for a device certificate, the CMPSESSION MO whose session ID is 1 is always used. When the system automatically applies for a certificate, the system chooses an available CMPSESSION with the minimum session ID from the CMPSESSION objects whose session IDs are 1, 3, 5, 7, 9 and 11. When the UPD DEVCERT command is executed to update a device certificate, the CMPSESSION MO whose session ID is 2 is always used. When the system automatically updates a certificate, the system chooses an available CMPSESSION MO with the minimum session ID from the CMPSESSION objects whose session IDs are 2, 4, 6, 8, 10, 12, 14 and 16.

  • In the multi-PKI scenario where device certificates are applied for and updated, the system automatically selects the minimum available session ID.

  • This command is used to query the status of a CMP session that is applying for or updating a device certificate. When the system is busy, the query may fail. Try again later in this case.

  • In the command output, devcert.cer in the 17th and 18th sessions is the name of the temporary certificate file applied for the RRU agent.

Output Description

Field Description

Session ID

Indicates the ID of a CMP session. It uniquely identifies a CMP session within a BS.

Method to Get Cert

Indicates the method using which a CMP session obtains a certificate. There are two methods: applying for a new certificate or updating an existing certificate.

Certificate File Name

Indicates the file name of a device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

Status of CMPSession

Indicates the status of a Certificate Management Protocol (CMP) session. There are six types of status: INITIAL, RUNNING, PENDING, DONE, CLOSED, and STOPPED.

Start Time

Indicates the time when a session starts.
