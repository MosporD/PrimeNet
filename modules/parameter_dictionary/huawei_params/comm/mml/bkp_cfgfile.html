Back Up Configuration Data (BKP CFGFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to back up the current configuration of the BS. The system can be restored to the backed up configuration file.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Files backed up using the BKP CFGFILE command and uploaded using the DLD CFGFILE command are saved in the same directory on an NE. An existing file will be overwritten by a new file with the same file name.

  • If a configuration file generated by using this command is not activated within 24 hours, it will be automatically deleted.

  • Execution of this command will increase the CPU usage, and CPU overload may affect UE access. Therefore, it is recommended that you run this command when the system has a light load.

  • If a backup configuration file is encrypted after being backed up, you need to decrypt the file during the execution of the DLD CFGFILE command before running the ACT CFGFILE command to activate the file.

  • A file encryption password must be a combination of at least two of the following four types: lowercase letters, uppercase letters, digits, and special characters.

  • If the backup configuration file is encrypted, it cannot be downloaded and activated in earlier R versions.

  • You are not advised to back up the configuration file when ALM-26247 Configuration Failure or ALM-26255 Automatic Version Rollback is reported.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If a version of one or multiple RATs does not support compression and decompression, configuration files cannot be backed up in the compressed format regardless of whether compression backup is used.

  • [Co-MPT]Configuration files backed up on the MAE and LMT are both named CFGDATA.XML.

  • [NodeB]Configuration files backed up on the MAE and LMT are both named NodeBCfg.xml.

  • [eNodeB]Configuration files backed up on the MAE and LMT are both named ENBCFG.XML.

  • [gNodeB]Configuration files backed up on the MAE and LMT are both named GNBCFG.XML.

ENCRYPTMODE Encrypted Mode

Meaning: Indicates the encryption mode of a file. If this parameter is set to UNENCRYPTED, a file to be downloaded is in plaintext. Therefore, setting this parameter to UNENCRYPTED may pose security risks. If this parameter is set to PWD_ENCRYPTED for a file, the system encrypts or decrypts a file based on the entered password after the file is downloaded. Encrypting or decrypting a file needs to consume resources, which may affect ongoing services. In addition, encryption or decryption prolongs the command execution.

Example

Example 1: To back up the current configuration data of the base station with the parameters as follows: Encrypted Mode: UNENCRYPTED, run the following command:
BKP CFGFILE: ENCRYPTMODE=UNENCRYPTED;

Example 2: To back up the current configuration data of the base station with the parameters as follows: Encrypted Mode: PWD_ENCRYPTED, File Encryption Password: Abc@123, run the following command:
BKP CFGFILE: ENCRYPTMODE=PWD_ENCRYPTED, FILEPWD="*****";
