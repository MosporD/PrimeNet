Activate VCL Performance Monitoring (ACT VCLPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to activate the virtual channel link (VCL) performance monitoring (PM) function. This function performs end-to-end detection of VCL quality, such as measuring the number of lost cells and the number of misinserted cells. You can run the DSP VCLPM command to query the PM result.

Note

[NodeB]Before activating the VCL PM function, ensure that the VCL is normal. You can check the VCL status by running the DSP OMCH, DSP AAL2PATH, or DSP SAALLNK command.

Example

To activate VCL PM with the parameters as follows: Type of the VCL: SAALLINK, SAAL Link No.: 0, Activation Direction: SINK, PM Frame Interval: D128, run the following command: 
ACT VCLPM: LNKT=SAALLINK, SAALNO=0, DIR=SINK, BS=D128;
