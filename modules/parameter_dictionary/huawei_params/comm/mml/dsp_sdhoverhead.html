Display the SDH S1/C2/V5 Received (DSP SDHOVERHEAD)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the content of S1 or C2 received on a chip that provides optical ports and is located on an unchannelized optical sub-board.

Note

None.

Example

To query the content of the overhead byte for an optical port with the parameters as follows: Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, run the following command:
DSP SDHOVERHEAD: SN=0, SBT=UNCHANNELLED_COVERBOARD;
The result is shown as follows:
+++    0        2010-06-28 18:48:29
O&M    #296
%%DSP SDHOVERHEAD: SN=0, SBT=UNCHANNELLED_COVERBOARD;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a specified optical port is located.

Subrack No.

Indicates the number of the subrack that houses the board where a specified optical port is located.

Slot No.

Indicates the number of the slot that houses the board where a specified optical port is located.

Subboard Type

Indicates the type of the sub-board on the board where a specified optical port is located.

Port No.

Indicates the number of a specified optical port.

Overhead Byte

Indicates the overhead byte of a specified optical port. In this MO, this parameter indicates the clock quality class S1 or higher order path signal identifier C2.

S1 Value

Indicates the clock quality class S1 of a specified optical port. This parameter is used to describe the SDH quality class.
