Set power supply mode of power supply port (SET PWRPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set power supply mode of power supply port.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If power type is set to FORCE, please make sure the device connected supports POE force mode, or it will damage the device connected

  • You can run the DSP PWRPORT command to query whether a board supports the power supply capability and the effective PoE power supply mode.

Example

To set the power supply mode of a port with Port No. being 0 and Power Supply Mode being FORCE, run the following command:
SET PWRPORT: CN=0, SRN=0, SN=18, PN=0, POWERTYPE=FORCE;
