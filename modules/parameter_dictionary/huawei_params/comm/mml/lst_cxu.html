List CXU (LST CXU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configurations of a CXU.

Note

None.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the CXU is located.

Subrack No.

Indicates the number of the subrack where the CXU is located.

Slot No.

Indicates the number of the slot where the CXU is located.

CXU Type

Indicates the type of the CXU.

Chain/Ring No.

Indicates the ID of the RRU or RFU chain/ring where the CXU is located.

CXU Position

Indicates the position of the CXU on the RRU chain/ring. It is calculated from the start port one by one.

CXU Name

Indicates the CXU name.

Remote Flag

Indicates whether a CXU is far away from the BBU. You can define whether a CXU is far away from the BBU as required. If you do not need to define this information, use the default value.

User Label

Indicates the user-defined CXU descriptions. You can use this parameter to record the information about the CXU.

CXU Work Standard

Indicates the working standard of the CXU. This parameter takes effect only for the RMU.

Maintenance Mode

Indicates the maintenance mode of a CXU. The value INSTALL indicates device creation caused by network capability expansion, device reparenting, or access of a new device to the network. The value EXPAND indicates the subrack or carrier capacity expansion of a device. The value UPGRADE indicates a device upgrade. The value TESTING indicates that an installed device is being commissioned. ExpandStatus1 to ExpandStatus10 can be used by users to define maintenance modes. The default value of this parameter is Normal.

Start Time of Status Setting

Indicates the start time of maintenance status of the CXU. If this parameter is not specified, the start time of the maintenance status is 2000-01-01 00:00:00.

End Time of Status Setting

Indicates the end time of the maintenance mode for the CXU. If this parameter is not specified, the maintenance mode ends at 2037-12-31 23:59:59.

Maintenance Mode Setting Remark

Indicates the remarks of maintenance status of the CXU.

Administrative State

Indicates the administrative state of the CXU. The CGPS does not support the value BLOCKED(Blocked).

Location Name

Indicates the location information of a CXU. Set this parameter to the location name of the site. The location name of the site is configured in the Location object. This parameter must be set to the same value for RF modules serving the same sector.
