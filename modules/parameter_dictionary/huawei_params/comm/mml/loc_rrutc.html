Lock Maximum RRU/RFU Channel TX Power (LOC RRUTC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set and lock the maximum TX power of a TX channel on an RRU or RFU.

Note

  • This command is a maintenance command. The power of an RRU/RFU is locked after this command is executed. The power will not be changed even when this RRU/RFU is powered off, reset, removed to another site, or when the base station configuration file is updated. You can run the DSP TXBRANCH or DSP RRU command to query the maximum TX power of a TX channel on an RRU/RFU. You need to set the Maximum Output Power Support Setting of the TX Channel parameter to 0 to unlock the power.

  • When an RRU/RFU works in multimode, you can run this command in any mode. The TX power of a TX channel on an RRU/RFU is set according to the latest command.

  • This command takes effect after the RRU or RFU is reset.

  • If you run this command to lock the maximum TX power for any channel of an AARU, the maximum TX power for all channels of the AARU will change to the locked TX power.

  • If you run this command to lock the maximum TX power for any channel of an AAU supporting beamforming, the channel number will not be checked. If the maximum TX power for any channel is locked, the maximum TX power for all channels of the AAU supporting beamforming will change to the locked TX power.

  • [NodeB]It is recommended that you run the LST ULOCELL command to query the cell power before running this command. The maximum TX power on an RRU/RFU must be larger than or equal to the cell power. If the cell power of the RRU/RFU is larger than the power to be locked, ALM-28211 Cell Configuration Abnormal is reported.

  • [eGBTS]Before executing this command, you are advised to run the LST GTRXDEV command on the BSC LMT to query the output power of each carrier and ensure that the maximum output power of a TX channel to be configured is equal to or greater than the total power of all carriers on this TX channel. If the maximum output power of a TX channel is less than the total power of all carriers on this TX channel, ALM-28010 Carrier Configuration Error is reported.

  • [eNodeB]It is recommended that you run the LST PDSCHCFG command to query the cell power before running this command. The maximum TX power on an RRU/RFU must be larger than or equal to the cell power. If the cell power of the RRU/RFU is larger than the power to be locked, ALM-29240 Cell Unusable is reported.

  • [gNodeB]It is recommended that you run the LST NRDUCELLTRP command to query the cell power before running this command. The maximum TX power on an RRU/RFU must be larger than or equal to the cell power. If the cell power of the RRU/RFU is larger than the power to be locked, ALM-29240 Cell Unusable is reported.

SRN Subrack No.

Meaning: Indicates the subrack number of the RRU or RFU where the TX channel is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CN and SRN in the TXBRANCH must meet the following conditions: 1. When CN is set to a value ranging from 0 to 15, SRN must be set to 4, 5, or a value ranging from 60 to 254; 2. When CN is set to a value ranging from 16 to 62, SRN must be set to 4 or 5.

Service Interrupted After Modification: N/A

SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU where the TX channel is located.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]SRN and SN in the TXBRANCH must meet the following conditions: 1. When SRN is set to 4 or 5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to a value ranging from 0 to 8; 2. When SRN is set to 4 or 5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to a value ranging from 0 to 5; 3. When the value of SRN in a TXBRANCH MO ranges from 60 to 254 and RT in the RRU MO is set to MPRF, the value of SN in the TXBRANCH MO ranges from 1 to 3; 4. When the value of SRN in a TXBRANCH MO is set to 60 and RT in the RRU MO is not set to MPRF, SN in the TXBRANCH MO ranges from 0 to 5. 5. When the value of SRN in a TXBRANCH MO ranges from 61 to 254 and RT in the RRU MO is not set to MPRF, SN in the TXBRANCH MO must be set to 0.
  • [eGBTS]SRN and SN in the TXBRANCH must meet the following conditions: 1. When SRN is set to 4 or 5 and TYPE in the CABINET is equal to BTS3900AL, SN must be set to a value ranging from 0 to 8; 2. When SRN is set to 4 or 5 and TYPE in the CABINET is not equal to BTS3900AL, SN must be set to a value ranging from 0 to 5; 3. When SRN is set to 60, SN must be set to a value ranging from 0 to 5. 4. When SRN is set to a value ranging from 61 to 254, SN must be set to 0.

Meaning: Indicates the maximum output power on the TX channel. The adjustment step is 1 W (1000 mW). When the output power is set to 0 mW, the maximum output power is unlocked and restored.

Example

Fix the maximum TX power of No.0 channel carried by the board in slot 0 of subrack 60 in cabinet 0 to 50 W, run the following command:
LOC RRUTC: CN=0, SRN=60, SN=0, TXNO=0, TXMAXPWR=5000;
