Set MBTS Major Standard for Clock Mutual Lock (SET CLKMUTUALLOCK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the major standard for clock mutual lock on a multimode base station. The clock on the major standard side is used as the standard clock.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • This command does not take effect in scenarios where clock mutual lock is not used. Clock mutual lock is used in scenarios such as multimode RRU and CPRI MUX/eCPRI MUX.

  • If clock mutual lock involves GSM that uses a GTMU as the main control board and any involved standard does not support transmission of GSM clock signals, the major standard can be changed only to GSM.

  • If clock mutual lock involves only CDMA and LTE, the major standard cannot be changed to LTE.

  • If clock mutual lock involves standards for which D-MIMO is deployed, the major standard can be changed only to one of these standards.

  • If clock mutual lock involves standards deployed in different BBUs that are interconnected, the major standard cannot be changed to any standard that is deployed only in the leaf BBU.

  • If an RAT involved in clock lock uses time synchronization but not loose time synchronization, the RAT using loose time synchronization or frequency synchronization cannot be changed as the major standard for clock lock.

  • If multiple RATs involved in clock lock use time synchronization but not loose time synchronization, the RAT using time synchronization but with an unavailable system clock cannot be changed as the major standard for clock lock.

  • If an RAT involved in clock lock uses loose time synchronization, the RAT using frequency synchronization cannot be changed as the major standard for clock lock.

  • If multiple RATs involved in clock lock use loose time synchronization, the RAT using loose time synchronization but with an unavailable system clock cannot be changed as the major standard for clock lock.

  • If clock mutual lock involves only LTE and TD-SCDMA or involves only co-MPT standards and TDS, the major standard cannot be changed to TD-SCDMA.

  • If clock mutual lock involves standards that apply frame synchronization, the major standard cannot be changed to any standard that applies frequency synchronization.

  • If clock mutual lock involves multiple standards that apply frame synchronization, the major standard cannot be changed to any of these standards whose system clock is unavailable.

  • If clock mutual lock involves multiple standards that apply frequency synchronization, the major standard cannot be changed to any of these standards whose system clock is unavailable.

  • If clock mutual lock involves standards for which a CGPS clock source is configured, the major standard can be changed only to one of these standards.

  • If clock mutual lock involves standards for which air interface soft synchronization is configured, the major standard can be changed only to one of these standards.

  • If clock mutual lock involves co-site GSM and UMTS/LTE that apply spectrum sharing and any involved standard does not support transmission of GSM clock signals, the major standard can be changed only to GSM.

  • If clock mutual clock involves standards deployed on different UMPT boards that are interconnected, the major standard can be changed only to one of these standards.

  • If clock mutual lock involves multiple standards in a subrack and one standard detects that the system clock of the peer standard is abnormal, the peer standard cannot be changed to the major standard.

  • If clock mutual lock involves GSM that uses a GTMU as the main control board and all involved standards support transmission of GSM clock signals, the major standard cannot be changed to GSM.

  • Manual modification of the major standard for clock mutual lock takes effect for only once and does not affect the automatic switchover between the major and minor standards.

  • Running this command may interrupt the services of the multimode base station for a short period.

Parameters

ID Name Description
MS Major Standard for Clock Mutual Lock

Meaning: Indicates the standard on which side the clock is used as the criterion clock when clock mutual lock is implemented on an MBTS. The value is NULL when the standard is not existed.

GUI Value Range: UMTS(UMTS), GSM(GSM), WiMAX(WiMAX), LTE(LTE), LTE_TDD(LTE TDD), TDS(TD-SCDMA), COMM(COMM), NR(NR), COMM2(COMM2)

Unit: None

Actual Value Range: UMTS, GSM, WiMAX, LTE, LTE_TDD, TDS, COMM, NR, COMM2

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To Set MBTS Major Standard for Clock Mutual Lock with parameters as follows:Major Standard for Clock Mutual Lock: UMTS, run the following command: 
SET CLKMUTUALLOCK: MS=UMTS;
