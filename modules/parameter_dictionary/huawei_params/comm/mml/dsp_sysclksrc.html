Display the dynamic information of the locked system clock source (DSP SYSCLKSRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to query the locked system clock source and the equipment serial number (ESN) of the NE where the locked source is located.

Note

None.

Parameters

None.

Example

To display the dynamic information of the locked system clock source, run the following command:
DSP SYSCLKSRC:;
The result is shown as follows:
+++    0        2016-05-04 20:19:13
O&M    #39
%%DSP SYSCLKSRC:;%%
RETCODE = 0  Operation succeeded.

Display System Reference Clock
------------------------------
              Locked System Clock Source  =  Local Standard Clock
ESN of NE Where Locked Source Is Located  =  2102112722P0D8014740
(Number of results = 1)


---    END

Output Description

Field Description

Locked System Clock Source

Indicates the locked system clock source, which is obtained from the local standard clock or interconnection system clock. The local standard clock is a clock synchronized with the reference clock of the local NE or multimode base station. The interconnection system clock is the standard clock obtained from the interconnection port.

ESN of NE Where Locked Source Is Located

Indicates the ESN of the NE where the locked clock source is located. If frequency synchronization is used, the value of this parameter is NULL.
