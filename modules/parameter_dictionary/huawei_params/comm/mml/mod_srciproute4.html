Modify Source IPv4 Route (MOD SRCIPROUTE4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a source IPv4 route.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

Modifying parameters of a source IPv4 route except User Label may intermittently interrupt or disconnect the services or OMCH that is carried on this route.

Parameters

ID Name Description
SRCRTIDX Source Route Index

Meaning: Indicates the index of a source IPv4 route.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SRCIPROUTE4 MO, if VRFIDX is set to a value in the range of 1 to 7, PT in the referenced SRCIPROUTE4 MO cannot be set to PPP, MPGRP, and TUNNEL.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SRCIP Source IP Address

Meaning: Indicates the source IPv4 address of a source IPv4 route.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]SRCIP in an SRCIPROUTE4 MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
RTTYPE Route Type

Meaning: Indicates the type of a source IPv4 route. The value NEXTHOP indicates that IP packets transmitted through the route are forwarded to a specified next-hop IP address. The value IF indicates that IP packets transmitted through the route are forwarded to a specified outbound interface.

GUI Value Range: NEXTHOP(Next Hop), IF(Exit Interface)

Unit: None

Actual Value Range: NEXTHOP, IF

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to PPP.
  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to MPGRP.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
NEXTHOP Next Hop IP

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]NEXTHOP in an SRCIPROUTE4 MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

Service Interrupted After Modification: Yes

Applicable Mode: G, U, L, N, R
PT Port Type

Meaning: Indicates the port type of a source IPv4 route.

GUI Value Range: PPP(PPP Link), MPGRP(Multi-link PPP Group), TUNNEL(Tunnel), INTERFACE(Interface)

Unit: None

Actual Value Range: PPP, MPGRP, TUNNEL, INTERFACE

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the SRCIPROUTE4 MO, if VRFIDX is set to a value in the range of 1 to 7, PT in the referenced SRCIPROUTE4 MO cannot be set to PPP, MPGRP, and TUNNEL.
  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to PPP.
  • [gNodeB]If the value of RTTYPE in an SRCIPROUTE4 MO is set to IF, the value of PT cannot be set to MPGRP.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
PORTID Port ID

Meaning: Indicates the port ID of a source IPv4 route.

GUI Value Range: 0~1499

Unit: None

Actual Value Range: 0~1499

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the SRCIPROUTE4 MO, if PT is set to INTERFACE, this parameter can be set to any value in the range of 0 to 1499.
  • In the SRCIPROUTE4 MO, if PT is set to PPP, this parameter can be set to any value in the range of 0 to 127.
  • In the SRCIPROUTE4 MO, if PT is set to MPGRP, this parameter can be set to any value in the range of 0 to 31.
  • In the SRCIPROUTE4 MO, if PT is set to TUNNEL, this parameter can be set to any value in the range of 0 to 14.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To modify a Source IPv4 Route with the parameters as follows: SRCRTIDX:0, SRCIP:"192.168.100.25", RTTYPE:NEXTHOP, NEXTHOP:"192.168.100.254", run the following command:
MOD SRCIPROUTE4: SRCRTIDX=0, SRCIP="192.168.100.25", RTTYPE=NEXTHOP, NEXTHOP="192.168.100.254";
