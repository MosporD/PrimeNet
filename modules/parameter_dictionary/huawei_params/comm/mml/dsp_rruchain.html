Display RRU Chain/Ring (DSP RRUCHAIN)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query running information about RRU chains/rings..

Note

None.

Parameters

ID Name Description
RCN Chain No.

Meaning: Indicates the ID of the RRU chain/ring. It uniquely identifies a chain within a base station.

GUI Value Range: 0~249

Unit: None

Actual Value Range: 0~249

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Example 1: To query the running information about the RRU chain numbered 0, run the following command:
DSP RRUCHAIN: RCN=0;
The result is shown as follows:
+++    0        2016-03-26 10:44:43
O&M    #411
%%DSP RRUCHAIN: RCN=0;%%
RETCODE = 0  Operation succeeded.

Display RRUCHAIN Running Information
------------------------------------
   Chain No.  =  0
 Chain Level  =  1
Board Number  =  6
(Number of results = 1)


---    END

Example 2: To query the running information about all RRU chains, run the following command:
DSP RRUCHAIN:;
+++    0        2016-03-26 10:44:43
O&M    #407
%%DSP RRUCHAIN:;%%
RETCODE = 0  Operation succeeded.

Display RRUCHAIN Running Information
------------------------------------
Chain No.  Chain Level  Board Number

0          1            6           
100        3            3           
110        1            1           
111        1            1           
(Number of results = 4)


---    END

Output Description

Field Description

Chain No.

Indicates the ID of the RRU chain/ring. It uniquely identifies a chain within a base station.

Chain Level

Indicates the level of the RRU chain.

Board Number

Indicates the number of boards on the RRU chain/ring.
