Start IMA Group Test (STR IMATST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to start a test on an IMA group. The test is conducted to check whether an IMA group at the local end is connected to multiple IMA groups at the peer end. An IMA test is performed on an IMA group. That is, when an IMA test is started on an IMA link, the IMA test is actually started on the IMA group to which the IMA link belongs.

Note

[Co-MPT,NodeB]After this command is executed, services are not interrupted.

Meaning: Indicates the picture of the IMA test. When this parameter is not specified, the user-defined IMA group number plus 1 is used as the test picture by default. You can set this parameter to any number from 1 to 254.

Example

To start an IMA group test with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, IMA Link No.: 0, IMA Group Subboard Type: BASE_BOARD, Group No.: 0, Test Picture: 1, run the following command: 
STR IMATST: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, IMALNKN=0, IMAGRPSBT=BASE_BOARD, IMAGRPN=0, TSTPATN=1;
