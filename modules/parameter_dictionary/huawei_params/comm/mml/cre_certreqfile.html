Create Certificate Request File (CRE CERTREQFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to create or update the request file for a device certificate based on the configured registration information. After the request file is created, you can run the ULD CERTFILE command to upload the request file to a specified FTP server.

Note

None.

Parameters

ID Name Description
FILENAME Certificate Request File Name

Meaning: Indicates the name of a certificate request file. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
REQFORMAT Certificate Request File Format

Meaning: Indicates the format of a certificate request file. The file supports the formats of Public Key Cryptography Standards (PKCS) and Certificate Request Message Format (CRMF).

GUI Value Range: PKCS(PKCS10), CRMF(CRMF)

Unit: None

Actual Value Range: PKCS, CRMF

MML Default Value: PKCS(PKCS10)

Recommended Value: PKCS(PKCS10)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

GUI Value Range: NEW(NEW), UPDATE(UPDATE)

Example

To create a certificate request file with the parameter as follows: Certificate Request File Name: basestationCert.req, Request Type: NEW, run the following command:
CRE CERTREQFILE: FILENAME="basestationCert.req", REQMODE=NEW, CERTREQPOLICY=DEFAULT;
