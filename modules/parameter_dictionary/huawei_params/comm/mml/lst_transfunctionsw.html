List Transmission Function Switch (LST TRANSFUNCTIONSW)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the transmission function switch.

Note

None.

Parameters

None.

Example

To list the transmission function switch, run the following command:
LST TRANSFUNCTIONSW:;
The result is as follows:
+++    0        2019-08-01 21:50:38
O&M    #122
%%LST TRANSFUNCTIONSW:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

IP PM Passive Activation Switch

Indicates whether to support IP PM passive activation. When this parameter is set to ENABLE, only user-plane IP addresses can respond to IP PM activation requests sent from the peer end and the peer end can activate IP PM sessions. When this parameter is set to DISABLE, none of IP addresses can respond to IP PM activation requests sent from the peer end and the peer end cannot activate IP PM sessions.

IP MUX Demultiplexing Switch

Indicates whether to support IP MUX demultiplexing. When this parameter is set to ENABLE, only user-plane IP addresses support demultiplexing of IPMUX frames. When this parameter is set to DISABLE, none of IP addresses support demultiplexing of IPMUX frames. This parameter takes effect only for UMTS and GSM.

IP Loopback Detection Response Switch

Indicates whether to support the IP loopback detection response function. If this parameter is set to ENABLE, only the IP addresses used by the IPPATH or EPGROUP MOs subscribed to by GSM and UMTS support responding to IP loopback detection UDP packets sent by the peer end. The destination UDP port number is 65040. If this parameter is set to DISABLE, none of the IP addresses support responding to IP loopback detection UDP packets sent from the peer end. This parameter takes effect only for UMTS and GSM.

Path Ping Detection Response Switch

Indicates whether to support the UDP path ping detection response function. If this parameter is set to ENABLE, only the IP addresses used by the IPPATH or EPGROUP MOs subscribed to by GSM and UMTS support responding to path ping detection packets sent by the peer end. The destination UDP port number is 65042. If this parameter is set to DISABLE, none of the IP addresses support responding to path ping detection packets sent from the peer end. This parameter takes effect only for UMTS and GSM.

ICMP Port Unreachable Send Switch

Indicates whether to send ICMP destination unreachable response packets. Generally, if the base station fails to find the corresponding interface after receiving the TCP/UDP packets, it sends ICMP destination unreachable response packets. The response packets will expose the equipment. If a large number of ICMP response packets are sent to the network, the network equipment may be overloaded. You can use this parameter to disable the sending of ICMP response packets to prevent network security risks. By default, the base station does not send destination unreachable response packets.

SCTP Server Switch

Indicates whether the server function is supported for SCTP of any of the following service types: RSL, NCP, CCP, S1-AP, R6-AP, R8-AP, ALCAP-AP, M2-AP, Se-AP, So-AP, gNodeB NG-AP, DSA S1-AP, and M3-AP. When this switch is turned on, the SCTP server function is supported. When this switch is turned off, the SCTP server function is disabled.

Downlink Rate Limiting Switch

Indicates whether to support priority-based downlink rate limiting. If this parameter is set to ENABLE, the rate of downlink data flows is limited based on the default priority. If this parameter is set to DISABLE, the rate of downlink data flows is not limited. This parameter is valid only for the UMPTe board.

Downlink Transmission Algorithm Optimization Switch

Indicates whether to optimize the scheduling algorithm for downlink transmission services to support higher downlink throughput. This parameter is valid only for the UMPTe board.

IP Receive Switch

Indicates whether the interface receives IP packets when the IPv4 address is not configured. If this parameter is set to ENABLE, the interface can receive IPv4 packets when the IPv4 address is not configured. If this parameter is set to DISABLE, the interface cannot receive IPv4 packets when the IPv4 address is not configured. This parameter is valid only for the UMPT board.
