Display AARU Dynamic Information (DSP AARU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the dynamic information about an active antenna radio unit (AARU). The information to be queried is as follows: the number of RX and TX channels, Maximum output power on the TX channel, the uplink channel gain, and other information about the AARU.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]The length of the fiber optic cable between the BBU and RF module in the command output is inaccurate due to factors such as the refractive index. The longer the fiber optic cable, the larger the error. The relationship between the length of the fiber optic cable and the error is as follows and is for reference only: When the length of the fiber optic cable is smaller than 600 m, the error is large. When the length of the fiber optic cable ranges from 600 m to 2 km, the error is less than 10%. When the length of the fiber optic cable ranges from 2 km to 12 km, the error is less than 5%. When the length of the fiber optic cable is greater than 12 km, the error is less than 2.5%.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The length of a fiber optic cable between an AARU and a BBU displayed under Display AARU Dynamic Information refers to the length of the shorter fiber optic cable. The lengths of both fiber optic cables between them are displayed under Display Length of Fiber Optic Cable Connecting to AARU. An AAMU can be configured with multiple AARUs, and the cabinet number, subrack number, and slot number of the AAMU are also displayed under Display Length of Fiber Optic Cable Connecting to AARU.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the AARU is located.

Subrack No.

Indicates the number of the subrack where the AARU is located.

Slot No.

Indicates the slot number of the AARU.

Number of RX channels

Indicates the number of logical RX channels of the AARU. For details, see AAS Feature Parameter Description.

Number of TX channels

Indicates the number of logical TX channels of the AARU. For details, see AAS Feature Parameter Description.

Number of carriers on the RX channel

Indicates the number of carriers on each RX channel.

Number of carriers on the TX channel

Indicates the number of carriers on each TX channel.

Maximum output power on the TX channel(0.1dBm)

Indicates the total output power of TX channels in the RRU/RFU. The precision deviation is ±0.5 dB. For details, see the description of Output Power in the product description of the corresponding RRU/RFU.

UL channel gain(0.1dB)

Indicates the UL channel gain.

UL Support Feature

Indicates whether the RRU or RFU supports the UL features. This parameter takes effect for UMTS only.

Logical Switch of TX Channel

Indicates whether to enable TX channels on the AARU, ON indicates that TX channels are enabled and OFF indicates that TX channels are disabled. On the AARU, all TX channels must be simultaneously enabled or disabled.

Max Tilt Difference Between Carriers(0.1degree)

Indicates the maximum tilt difference between carriers supported by the virtual antenna subunit corresponding to the AARU.

Max Tilt(0.1degree)

Indicates the maximum tilt supported by the virtual antenna subunit corresponding to the AARU.

Min Tilt(0.1degree)

Indicates the minimum tilt supported by the virtual antenna subunit corresponding to the AARU.

Max Beam Azimuth(0.1degree)

Indicates the maximum horizontal azimuth supported by the virtual antenna subunit corresponding to the AARU.

Min Beam Azimuth(0.1degree)

Indicates the minimum horizontal azimuth supported by the virtual antenna subunit corresponding to the AARU.

Max Beam Width(0.1degree)

Indicates the maximum horizontal beamwidth supported by the virtual antenna subunit corresponding to the AARU.

Min Beam Width(0.1degree)

Indicates the minimum horizontal beamwidth supported by the virtual antenna subunit corresponding to the AARU.

The length of the fiber optic cable between the BBU and RF module[100m(100ft)]

Indicates the length of the fiber optic cable between the BBU and RF module. When the RF module works in cold backup mode, the parameter indicates the length of the fiber optic cable that carries RF data. When the RF module works in hot backup or load sharing mode, there are two fiber optic cables between the BBU and RF module, and the parameter indicates the length of the shorter one. The parameter is inaccurate due to factors such as the refractive index. The longer the fiber optic cable, the smaller the error. The relationship between the length of the fiber optic cable and the error is as follows: When the length of the fiber optic cable is smaller than 600 m, the error is large and the parameter is for your reference only. When the length of the fiber optic cable ranges from 600 m to 2000 m, the error is less than 10%. When the length of the fiber optic cable ranges from 2000 m to 12000 m, the error is less than 5%. When the length of the fiber optic cable is greater than 12000 m, the error is less than 2.5%.

Cabinet No. of Interface Board

Indicates the number of the cabinet housing the interface board.

Subrack No. of Interface Board

Indicates the number of the subrack housing the interface board.

Slot No. of Interface Board

Indicates the number of the slot housing the interface board.

Port No. of Interface Board

Indicates the number of the port on the interface board.

SubPort No. of Interface Board

Indicates the sub-port number of the interface board.

Port No. of RF Module

Indicates the number of the port on the RF unit.
