Display CANBUS Status (DSP CANSTATE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of the controller area network BUS (CANBUS).

Note

None.

Example

To query the status of the CANBUS with the parameter as follows: Slot NO.: 7, run the following command:
DSP CANSTATE: SN=7;
The result is shown as follows:

Output Description

Field Description

CANbus Received FE Messages

Indicates the total number of messages that the CAN bus receives from the CPU of the main control board through the FE bus.

CANbus Received IPMB Messages

Indicates the total number of messages that the CAN bus receives from the Intelligent Platform Management Bus (IPMB) through the FE bus.

CANbus Received 485 Messages

Indicates the total number of 485 messages received by the CAN bus through the FE bus.

CANbus Received Illegal Messages

Indicates the total number of invalid messages received by the CAN bus through the FE bus.

CANbus Send FE Messages

Indicates the total number of messages that the CAN bus sends to the CPU of the main control board through the FE bus.

CANbus Send IPMB Messages

Indicates the total number of messages that the CAN bus sends to the Intelligent Platform Management Bus (IPMB) through the FE bus.

CANbus Send 485 Messages

Indicates the total number of 485 messages sent by the CAN bus through the FE bus.

CANbus Received CANbus Messages

Indicates the total number of CAN bus messages received by the CAN bus between main control boards and service boards.

CANbus Send CANbus Messages

Indicates the total number of CAN bus messages sent by the CAN bus between main control boards and service boards.

CANbus Send Failed CANbus Messages

Indicates the total number of CAN bus messages that fail to be sent by the CAN bus between main control boards and service boards.

CANbus Master/Slave Status

Indicates the master/slave status of the CAN bus on the main control board. This parameter is displayed as NULL for the boards other than main control boards.
