Add Binding from IPSec Policy Group to Interface (ADD IPSECBINDITF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to bind an IPSec policy group to an interface. IPSec tunnels are negotiated to protect the data streams flowed through an interface only after an IPSec policy group is bound to the interface.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • An IPSec policy can be bound to only one port.

  • Only one IPSec policy created by user and one IPSec policy created by the system can be bound to a port.

  • After an IPSec policy group is bound to a port, if packets comply with ACL rules in the group and IPSec SAs are available, the packets will be encapsulated by IPSec and be routed and forwarded based on the destination IP addresses after encapsulation.

  • Before this command is executed, if the IPSECPOLICY, IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects, which the IPSECBINDITF MO directly or indirectly depends on, do not have a bearer MO (PACKETFILTERING, IPSECBINDITF), on the board for which the IPSECBINDITF MO is configured, the IPSECPOLICY, IPSECPROPOSAL, ACL, IKEPEER and IKEPROPOSAL objects will try to take effect. If these objects fail to take effect, the IPSECBINDITF MO will also fail to take effect.

  • [Co-MPT,NodeB,eNodeB,gNodeB]System specifications: When a WMPT/LMPT board serves as the main control board, the base station supports a maximum of 108 IPSECBINDITF objects. When a UMPTa/UMPTb/UMDU board serves as the main control board, the base station supports a maximum of 236 IPSECBINDITF objects. When a UMPTe board serves as the main control board, the base station supports a maximum of 392 IPSECBINDITF objects. When a UMPTg/UMPTga board serves as the main control board, the base station supports a maximum of 520 IPSECBINDITF objects. When a UMPT/UMDU board serves as the main control board, a maximum of 108 IPv4 IPSECBINDITF can be manually configured for a base station, and a maximum number of 128 IPv6 IPSECBINDITF can be manually configured for a base station.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Board specifications: An LMPT board supports a maximum of 12 IPSECBINDITF objects. A UCCU/UBBPe/UBBPei/UBBPep/UBBPem/UBBPf0/UBBPex2/LCOP/UBBPg1 board supports a maximum of 8 IPSECBINDITF objects. A UMPTa/UMPTb/UMDU board supports a maximum of 236 IPSECBINDITF objects. A UMPTe board supports a maximum of 392 IPSECBINDITF objects. A UMPTg/UMPTga board supports a maximum of 520 IPSECBINDITF objects. A UTRPc board supports a maximum of 108 IPSECBINDITF objects.

  • [Co-MPT,eNodeB,gNodeB]In the IPv6 IPSec scenario, the VRF index of the matched data flow comes from the INTERFACE MO of the tunnel type referenced by the interface bound to the IPsec policy group.

Parameters

ID Name Description
IPSECBINDITFID IPSec Bind Interface ID

Meaning: Indicates the ID of an IPSECBINDITF object. The value of IPSECBINDITFID in the IPSECBINDITF MOs configured by users ranges from 0 to 235. The value of IPSECBINDITFID in the IPSECBINDITF MOs configured by the system ranges from 10000 to 19999.

GUI Value Range: 0~235,10000~19999

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SPGN Policy Group Name

Meaning: Indicates the name of the IPSec policy group.

GUI Value Range: 1~15 characters

Unit: None

Actual Value Range: 1~15 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ITFID Interface ID

Meaning: Indicates the ID of the interface to which the IPsec policy group is bound. When IPsec Policy Group Binding Mode in the IKECFG MO is set to ALL, an IPsec policy group can be bound only to a common interface and the IPsec policies take effect on the common interface and all VLAN subinterfaces in the default routing domain of the physical port on which the common interface is located. When IPsec Policy Group Binding Mode in the IKECFG MO is set to SINGLE, the IPsec policies take effect only on the interface bound to the IPsec policy group. The interface IDs in the range of 0 to 1499 are used for user-configured interfaces, and the interface IDs in the range of 10000 to 19999 are used for system-configured interfaces.

GUI Value Range: 0~1499,10000~19999

Unit: None

Actual Value Range: 0~1499,10000~19999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes to IPSECBINDITF objects are made. When this parameter is set to YES, forcible changes to IPSECBINDITF objects are made. When this parameter is set to NO, forcible changes to the IPSECBINDITF objects that affect associated objects are not allowed.

The associated objects include CA, CERTREQ, and IKEPEER. This parameter is invalid when a WMPT or LMPT serves as the main control board.

Pay attention to the following when setting this parameter:

1. The system checks whether forcible changes to IPSECBINDITF objects affect associated objects based on the object configuration data instead of the actual object running status.

2. If the NE is configured with an SRCIPROUTE4, PPPLNK, or MPGRP MO, the system does not check whether the modification of the local IP address affects the associated MOs of the IPSECBINDITF MO.

3. If the NE is configured with an SRCIPROUTE6 MO, the system does not check whether the modification of the local IPv6 address affects the associated objects of the IPSECBINDITF MO.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To bind an IPSec policy group to an interface with the parameters as follows: IPSec Bind Interface ID: 2, Policy Group Name: "policy", Interface ID: 2, run the following command:
ADD IPSECBINDITF: IPSECBINDITFID=2, SPGN="policy", ITFID=2;
