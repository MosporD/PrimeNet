Modify User Plane Host (MOD USERPLANEHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a user-plane host.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The user plane host cannot reference the DEVIP MO or IPADDR4 whose Port Type is ETHCI.

  • This operation may interrupt the services carried on the transmission link.

  • If one or more of the following parameters in a USERPLANEHOST object are modified, the link objects that are automatically created for the USERPLANEHOST object and are automatically created will be modified, or removed and then added: Local IP Address, IPSec Auto Configure Switch, Security Host ID, and VRF Index. Link objects include ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects that are automatically configured for a user-plane link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the USERPLANEHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEPEER object in the same end point group.

    - SeGW Switch is set to ENABLE(Enable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    If the following conditions are met, the system will remove the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects that are automatically configured for a user-plane link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the USERPLANEHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEPEER object in the same end point group.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

  • If the DEVIP, IPADDR4 object on which a USERPLANEHOST object depends is modified, the following link objects that are automatically created for the USERPLANEHOST object will be modified: ACL, ACLRULE, IKEPEER, IPSECBIND or IPSECBINDITF, and IPSECPOLICY.

  • [Co-MPT,eNodeB,gNodeB]Modifying any of the following parameters interrupts service that references this user plane host: Local IP Address, Local IPv6 Address, IPSec Auto Configure Switch, Security Host ID and VRF Index.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met, the system will remove the TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects that are automatically configured for a user-plane link:

    - The value of IPSec Auto Configure Switch is changed from to ENABLE(Enable) to DISABLE(Disable) for the USERPLANEHOST object.

    - IPSec Auto Configure Switch is set to ENABLE(Enable) for the USERPLANEPEER object in the same end point group.

    - SeGW Switch is set to DISABLE(Disable) for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

  • [NodeB,eGBTS]Modifying any of the following parameters interrupts service that references this user plane host: Local IP Address, IPSec Auto Configure Switch, Security Host ID and VRF Index.

IPSECSWITCH IPSec Auto Configure Switch

Meaning: Indicates whether to enable automatic user-plane IPsec tunnel setup based on the parameter values in the SECURITYHOST and SECURITYPEER MOs. If this parameter is set to ENABLE, an IPsec tunnel is automatically set up to encrypt transmitted data. If this parameter is set to DISABLE, no IPsec tunnel is automatically set up. If the value of this parameter is changed from ENABLE to DISABLE using the MOD USERPLANEHOST command, the system deletes the automatically set up IPsec tunnel.

Example

To modify the configuration of a user-plane host with the parameters as follows: User Plane Host ID: 0, IP Version: IPv4, Local IP Address: 192.168.1.2, run the following command:
MOD USERPLANEHOST: UPHOSTID=0, IPVERSION=IPv4, LOCIPV4="192.168.1.2";
