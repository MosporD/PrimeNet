Modify RVD Subunit (MOD RVDSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a remote vendor-defined antenna line device (RVD) subunit.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The port to be set in this command must be an RRU/RFU port that has been configured. Otherwise, the execution result of this command indicates that the antenna port is not configured.

  • Ensure that the numbers of the cabinet, subrack, slot, and antenna port to be set are consistent with those of the RF port to which the RVD is connected, because the system is unable to identify the inconsistency. If there is inconsistency and this command is executed with "operating by sector" selected, it will be executed for a wrong MO.

  • After the vertical beamwidth is reconfigured, the system automatically changes the vertical beamwidth, which affects the network coverage. Changing the vertical beamwidth takes a maximum of 4 minutes. If changing the vertical beamwidth fails, the system reports ALM-26757 RET Antenna Running Data and Configuration Mismatch.

  • When the cabinet number of the port to which the RVD subunit is connected is 255, the port is not connected. In this case, the corresponding subrack number and slot number are also set to 255.

  • The range of the supported vertical beamwidth varies according to the RVD model. Before configuring the vertical beamwidth, run the DSP RVDSUBUNIT command to check the vertical beamwidth supported by the RVD.

  • If an unavailable RPCU exists on the base station, the configured data cannot take effect and ALM-26757 RET Antenna Running Data and Configuration Mismatch is reported. This alarm is automatically cleared when all RPCUs are running properly.

Example

To modify an RVD subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, Connect Port 1 Cabinet No.: 0, Connect Port 1 Subrack No.: 60, Connect Port 1 Slot No.: 0, Connect Port 1 Port No.: R0A, run the following command:
MOD RVDSUBUNIT: DEVICENO=0, SUBUNITNO=1, CONNCN1=0, CONNSRN1=60, CONNSN1=0, CONNPN1=R0A;
