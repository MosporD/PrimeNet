Display RHUB Status (DSP RHUB)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the running status about an RHUB.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RHUB is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [gNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the RHUB is located.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [gNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the RHUB is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [gNodeB]Each RHUB MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U, L, R, N
LOCATIONNAME Location Name

Meaning: Indicates the location information of an RHUB. Set this parameter to the location name of the site. The location name of the site is configured in a Location MO. Location names must be set to the same value for RF modules serving the same sector.

GUI Value Range: 0~64 characters

Unit: None

Actual Value Range: 0~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: U, L, R, N

Example

To query the running status of an RHUB, run the following command:
DSP RHUB:;
+++    0        2018-07-19 16:47:26
O&M    #17388
%%DSP RHUB:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RHUB is located.

Subrack No.

Indicates the number of the subrack where the RHUB is located.

Slot No.

Indicates the number of the slot where the RHUB is located.

Access Direction

Indicates the access direction of the service plane.
