Set Transmission Resource Group Algorithm (SET RSCGRPALG)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the algorithm of a transmission resource group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the corresponding transmission resource group has been configured.

  • If the port type of IP path is set to LOOPINT, it is not recommended that flow control be configured for the transmission resource group that the IP path uses by default.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]Bandwidth-related parameters of an adaptive port transmission resource group cannot be modified, they take effect as the default values according to the board capacity. Before modifying the algorithm of a transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port), remove the transmission resource group with Transmission Resource Group ID set to AUTOPORT(Auto Port), and add a transmission resource group with Transmission Resource Group ID set to DEFAULTPORT(Default Port).

  • [Co-MPT,eGBTS,eNodeB]When RXBWASW or TXBWASW is set to ON, the estimated available transport bandwidth will not be reduced if the average delay variation detected by an IP PM session is greater than the Delay Variation Down Threshold parameter and no packet loss is detected by the IP PM session; the estimated available transport bandwidth will be reduced if the average delay variation detected by an IP PM session is greater than the Delay Variation Down Threshold parameter and packet loss is detected by the IP PM session.

TXBWASW TX Bandwidth Adjustment Switch

Meaning: Indicates whether to enable the dynamic adjustment of the TX bandwidth of a transmission resource group. If this parameter is set to ON, the TX bandwidth is adjusted according to the network performance and dynamic bandwidth adjustment parameters (Packet Loss Ratio Down Threshold and Delay Variation Down Threshold). If mapping between the transmission resource group and a NodeB IP path or an IP path for no RAT is configured, this parameter does not take effect on the transmission resource group even though the parameter is set to ON. This parameter does not take effect in UMTS and NR.

If this parameter is set to ON, fewer packets are lost because the TX bandwidth is adjusted dynamically.

TCSW Traffic Control Switch

Meaning: Indicates whether to enable the backpressure algorithm of a transmission resource group.

The BS monitors the data buffered in the queues of each transmission resource group, determines whether the transmission resource group is congested, and transmits the backpressure signals (number and congestion status of the transmission resource group) to each flow control service.

If the size of buffered data packets in any backpressure queue exceeds 75% of the queue capacity, the BS regards this transmission resource group as congested and transmits congestion signals.

If the size of buffered data packets in each backpressure queue is less than 50% of the corresponding buffer capacity, the BS decides that the transmission resource group is not congested. In this situation, no congestion signal or congestion release signal is transmitted.

When this parameter is set to ENABLE, both intra-mode traffic control and inter-mode traffic control are supported.

The inter-mode traffic control for transmission resource groups applies only to separate-MPT base stations with co-transmission implemented through backplane interconnection. However, it does not apply to cascaded base stations, base stations with co-transmission implemented through panel interconnection, or base stations enabled with route load sharing.

When the inter-mode traffic control function is enabled for a separate-MPT base station with co-transmission implemented through backplane interconnection, the Tunnel Type parameter must be set to DL(DL) for the tunnel of the mode providing transmission ports and must be set to UL(UL) for the tunnel of the mode providing no transmission port.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: ENABLE(Enable)

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ENABLE, congestion of transmission resource groups can be avoided. Therefore, fairness and differentiation of non-real-time services are ensured.

If this parameter is set to DISABLE, packet loss is easy to occur. In this case, fairness and differentiation of non-real-time services cannot be ensured.

Applicable Mode: G, U, L, N
PQN PQ Number

Meaning: Indicates the number of PQs in a transmission resource group. The queues in a transmission resource group are classified into PQs and non-PQs. The scheduling priority of any PQ is higher than that of any non-PQ. The queues numbered from 0 to the result after this parameter value minus 1 are PQs. PQ scheduling is used between PQs. A smaller PQ number indicates a higher scheduling priority. The queues numbered from this parameter value to 6 are non-PQs. WPR scheduling is used between non-PQs.

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: 3

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: Real-time services should be in a PQ, and non-real-time services should be in a non-PQ. Otherwise, preferential transmission of real-time service data cannot be ensured.

DROPPKTNUM Drop Packet Number Threshold

Meaning: Indicates the number threshold of discarded packets. This parameter indicates the capability of the queue in an enhanced transmission resource group to buffer packets. A greater parameter value indicates a stronger capability. If this parameter is set to 0, the queue in an enhanced transmission resource group cannot buffer packets, and therefore all the delayed packets on the TX channel are discarded. The number threshold of discarded packets determines the maximum amount of data that can be buffered in an enhanced transmission resource group. The congestion time threshold of an enhanced transmission resource group determines the amount of data that is buffered when the enhanced transmission resource group is congested. Ensure that the maximum amount of data that can be buffered is not less than the amount of data that is buffered during congestion. When the board type is UMPTg or UMPTga, the configuration is not effective. The capacity of the UMPTg and UMPTga queue cache packet is dynamically allocated by the system.

Recommended Value: 1000

TXSSW TX Traffic Shaping Switch

Meaning: Indicates whether to enable traffic shaping for a transmission resource group. If this parameter is set to ON, traffic shaping is performed according to the TX bandwidth so that the transmit traffic would not exceed the capability of downstream routers, therefore avoiding unnecessary packet loss and congestion. If this parameter is set to OFF, traffic shaping is not performed during data transmission.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: ON(On)

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: If this parameter is set to ON, the TX rate of a transmission resource group can be kept less than or equal to the configured TX bandwidth. Therefore, congestion is avoided and QoS is ensured.

If this parameter is set to OFF, the TX rate of a transmission resource group can exceed the configured TX bandwidth. In this case, packet loss is easy to occur on the transport network, affecting the QoS of services.

Applicable Mode: G, U, L, N

Example

To modify the algorithm of a transmission resource group with the parameters as follows: Slot No.: 7, Subboard Type: BASE_BOARD, Transmission Resource Group Bear Type: IP, Bearing Port Type: ETH, Transmission Resource Group ID: 0, TX Traffic Shaping Switch: ON, run the following command:
SET RSCGRPALG: SN=7, SBT=BASE_BOARD, BEAR=IP, PT=ETH, RSCGRPID=0, TXSSW=ON;
