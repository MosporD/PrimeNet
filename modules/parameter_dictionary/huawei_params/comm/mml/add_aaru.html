Add AARU (ADD AARU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add an active antenna radio unit (AARU).

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]Before adding an AARU, ensure that the AAS that supports this AARU has been configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]After an AARU is added, the system creates a corresponding VRET for the AARU. There are several VRET subunits under the VRET. In this case, all the values of the parameters for the VRET subunits are invalid and you need to modify the setting of these parameters using the MOD VRETSUBUNIT command.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If an AARU is on an RRU chain/ring configured on an RMU port, the working standard of the AARU can be set only to LO, GO, GL, UO, UL, GU, or GUL.

  • [Co-MPT,NodeB,eGBTS,eNodeB]When an AARU and a BBU are served by the same power supply system, set the Power Supply Group ID parameter of the AARU to 0.

Example

To add an AARU with the parameters as follows: Cabinet No.: 0, Subrack No.: 70, Slot No.: 1, AARU Work Standard: UO, AARU Name: AARU1, Number of RX channels: 2, Number of TX channels: 2, Intermediate Frequency Offset: 0, VRET No.: 70, run the following command:
ADD AARU: CN=0, SRN=70, SN=1, RS=UO, AN="AARU1", RXNUM=2, TXNUM=2, IFOFFSET=0, VRETNO=70;
