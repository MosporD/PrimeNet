Display Current NE Status (DSP MNTMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the current maintenance status of an NE.

Note

None.

Parameters

None.

Example

To list the current status of the NE, run the following command:
DSP MNTMODE:;  
The result is shown as follows: 
+++    0        2011-10-17 14:51:39
O&M    #7126
%%DSP MNTMODE:;%%
RETCODE = 0  Operation succeeded.

Display Current NE Status
-------------------------
Current Maintenance Mode  =  INSTALL
(Number of results = 1)


---    END

Output Description

Field Description

Current Maintenance Mode

Indicates the current maintenance mode of the network element (NE).
