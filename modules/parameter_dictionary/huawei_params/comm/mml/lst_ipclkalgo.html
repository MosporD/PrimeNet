List Algorithm of IP Clock (LST IPCLKALGO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the configuration of the clock algorithm for an IP clock link.

Note

None.

Parameters

None.

Example

To list the algorithm of the IP clock, run the following command:
LST IPCLKALGO:;
The result is shown as follows:
+++    0        2015-04-14 11:38:30
O&M    #30602
%%LST IPCLKALGO:;%%
RETCODE = 0  Operation succeeded.

-----------------------

                     Free Count  =  4
                   Search Count  =  4
                     Hold Count  =  4
                     Lock Count  =  4
                 Sample Time(s)  =  16
Adaptive Timing Recovery Switch  =  OFF
(Number of results = 1)


---    END

Output Description

Field Description

Algorithm

Indicates the clock algorithm mode for the IP clock link. In DEFAULT mode that is also called the adaption mode, and the system adjusts the filtering period and sampling period based on the network quality in this mode. In CLASSA mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 2400, respectively. In CLASSB mode, the Free Count, Search Count, Hold Count, Lock Count, and Sample Time parameters are set to 4, 4, 4, 10, and 4800, respectively. In CUSTOM mode, the filtering period and sampling period are set by the customer. The LTE currently does not support this function.

Free Count

Indicates the filtering period of the IP clock link when the IP clock works in free-running mode. The LTE currently does not support this function.

Search Count

Indicates the filtering period of the IP clock link when the IP clock works in fast-tracking mode. The LTE currently does not support this function.

Hold Count

Indicates the filtering period of the IP clock link when the IP clock works in hold mode. The LTE currently does not support this function.

Lock Count

Indicates the filtering period of the IP clock link when the IP clock works in locked mode. The LTE currently does not support this function.

Sample Time(s)

Indicates the sampling period of the IP clock link. The LTE currently does not support this function.

Adaptive Timing Recovery Switch

Indicates the adaptive scheduled recovery switch for an IP clock link. The function is used to make the BS and the IPCLK Server exchange handshake messages directly. The network between them transfers packages only and the packages will be filtered by the package delay vibrates which Adaptive Timing Recovery (ATR) of BS imported to the network. The time synchronization with the server will be realized.
