Add RRU/RFU (ADD RRU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add an RRU or RFU on a specified chain/ring.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before an RRU or RFU is added, an RRU or RFU chain/ring must be added by running the ADD RRUCHAIN command.

  • Before adding an RFU, ensure that the corresponding subrack is added.

  • If an RRU or RFU is added to the chain, the RRU or RFU must be added to the chain tail or any position behind the breakpoint.

  • If an RRU or RFU is to be added to the ring, the RRU or RFU can be added to any position between the two breakpoints if the configured breakpoints do not coincide. If the configured breakpoints coincide, the RRU or RFU can be added only to the coincident position.

  • After an RRU or RFU is added between two breakpoints on the ring, the value of the second breakpoint and the RRU or RFU level increases by 1 automatically.

  • After an RRU or RFU is added to the chain/ring, the original RRU or RFU with a position equal to or greater than the position of the newly added RRU or RFU is automatically moved backwards.

  • The number of RRUs in a chain/ring should be in the range of the maximum specifications that RRU supported.

  • In the hot backup ring topology, only one RRU or RFU can be configured on the chain or ring, and the the RRU or RFU can work only in UO or LO mode.

  • In load sharing mode, the working standard of an RRU on the main chain/ring cannot be set to GO or UO.

  • When the RRU type is PRRU(PRRU3801), the parameter VSWR alarm post-processing switch, VSWR alarm post-processing threshold and VSWR alarm threshold are invalid.

  • If the RRU is in TDS/TDL/TL mode, the VSWR alarm post-processing threshold parameter can be set to a value greater than or equal to that of the VSWR alarm threshold parameter. For RRU/RFUs in other modes, the VSWR alarm post-processing threshold parameter must be set to a value greater than that of the VSWR alarm threshold parameter.

  • After an RRU or RFU is added, if links cannot be set up for the associated RRUs or RFUs or links cannot work at the highest CPRI line rate, you need to run the STR CPRILBRNEG command to initiate negotiation.

  • If Protocol Type of EQUIPMENT is set to TDL_IR and Protocol Type of the chain/ring carrying RF modules is set to CPRI, and if VSWR alarm threshold and VSWR alarm post-processing threshold are set to the same value, these thresholds cannot take effect on the RF modules.

  • If an RRU or RFU is in maintenance mode, the RRU-related or RFU-related alarm reporting mechanism will change and the RRU or RFU performance data is identified as untrusted data.

  • If the RRU type parameter is set to MPMU, the Maintenance Mode parameter must be set to NORMAL.

  • When an RRU/RFU and a BBU are served by the same power supply system, set the Power Supply Group ID parameter of the RRU/RFU to 0.

  • The WiFi Switch parameter takes effect only for the MPMUs which support Wi-Fi and does not take effect for other RRUs.

  • In load sharing mode, breakpoints are not required when an RRU is to be added to a branch chain connecting to an RHUB.

  • When the RRU type is MRIU, the following parameters are invalid: VSWR alarm post-processing switch, VSWR alarm post-processing threshold, VSWR alarm threshold, RF Desensitivity, Low Current Protect Switch, ALD Reuse Flag, PA Efficiency Improvement Switch, Interference Frequency, Receive Frequency Band Mutual Aid Switch, RF DC Power Off Alarm Detect Switch, Battery Output Undervoltage Threshold, LED Switch, WiFi Switch, DL Signal Quality Detection Switch, DL Signal Quality Detection Period, DL Signal Quality Detection Sensitivity, RF Specifications Customization Switch, and The Value of The Circuit Breaker.

  • When the system is being upgraded, the RRU enters or exits the dormancy mode at the specified time after the upgrade is complete.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If multiple modes of a separate-MPT base station share an RMU, the chains/rings connecting to the RMU work at the same line rate as the chain/ring with the maximum number of board cascading levels. If links cannot be set up for the associated RRUs or links cannot work at the expected CPRI line rate, run the STR CPRILBRNEG command to initiate negotiation.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]In load sharing mode, only one RRU/RFU can be added to the chain/ring.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the RRU type is MPMU(pRRU3901), the system adds in-position RRUs of the MPRF type and the following parameters are invalid for these RRUs: VSWR alarm post-processing switch, VSWR alarm post-processing threshold, VSWR alarm threshold, RF Desensitivity, Low Current Protect Switch, ALD Reuse Flag, RU Specification, and PA Efficiency Improvement Switch.

  • [Co-MPT,NodeB,eNodeB,gNodeB]If an RRU is to be added to a branch chain/ring which connects to an RHUB, the RRU type must be MPMU and the branch chain/ring must have been configured.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the RRU type is MPMU, the following parameters are invalid: RF Desensitivity, Low Current Protect Switch, ALD Reuse Flag, RU Specification, and PA Efficiency Improvement Switch.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the RRU type is MPMU(pRRU3901), the following parameters are invalid: Number of RX channels and Number of TX channels.

ALMPROCSW VSWR alarm post-processing switch

Meaning: Indicates the VSWR alarm post-processing switch. The pRRU (pRRU3801) does not support this parameter.

When the switch is set to on and the VSWR is greater than the VSWR alarm post-processing threshold: (1) The TX channel will be shut down if the transmit power is greater than or equal to the hardware maximum output power of the TX channel minus 3 dB. (2) The TX channel will not be shut down if the transmit power is less than the hardware maximum output power of the TX channel minus 3 dB.

When the switch is set to off and the VSWR is greater than the VSWR alarm post-processing threshold, the RF module will reduce the total transmit power of TX channels by 3 dB to avoid damage caused by high VSWR and provide as many services as possible. Different scenarios are described as follows:

(1) An RF module degrades its power by decreasing the TX power of carriers sharing TX channels by 3 dB. In GSM mode, non-BCCH carriers on the TX channel are shut down to degrade the RF module's power. If there is only a BCCH carrier on the TX channel where a severe VSWR alarm is generated, to ensure services, the transmit power of the BCCH carrier is reduced so that the TX channel power is reduced by 3 dB.

(2) In the scenario where two TX channels are configured with transmit diversity and MIMO, the TX power of one channel is decreased by 3 dB if a major VSWR alarm is generated in this channel. Meanwhile, the TX power of the other channel also needs to be decreased by 3 dB for the power balance of TX channels.

(3) In the scenario where multiple modes share TX channels and a major VSWR alarm is generated in one channel, this TX channel is shut down if the switch is set to ON in any mode. The power of this channel is degraded if this switch is set to OFF in all the modes.

ALMTHRHLD VSWR alarm threshold

Meaning: Indicates the VSWR alarm threshold. When the current VSWR is greater than the threshold, a VSWR Abnormal alarm is reported.

It is recommended that the VSWR alarm threshold be set according to the VSWR required by the engineering quality to reduce the probability that the VSWR alarm is reported falsely.

To stabilize the false alarm probability to 1%, 0.1%, and 0.01%, you need to set the VSWR alarm threshold to the following recommended values:

When the VSWR required by the engineering quality is smaller than or equal to 1.4, the recommended thresholds are 1.8, 2.0, and 2.4, respectively.

When the VSWR required by the engineering quality is smaller than or equal to 1.5, the recommended thresholds are 2.0, 2.2, and 2.6, respectively.

If this parameter is set to different values in different modes of a multimode base station, the smallest value takes effect in all the modes.

RFDS RF Desensitivity

Meaning: Indicates the RF desensitization intensity of the RRU or RFU. Meaning: Indicates whether the RF module allows the configuration of the cell with PIM3 hit. If this switch is turned on, the configuration of the cell with PIM3 hit takes effect. If this switch is turned off, the configuration of the cell with PIM3 hit does not take effect. In the PIM3 hit scenario, the third-order intermodulation products of downlink signals of cells configured on the same antenna port of the RF module fall in the uplink frequencies of some cells. In the PIM3 hit scenario, the size of the intermodulation products is affected by the PIM3 specifications of the antenna system (including but not limited to the antenna, feeder/jumper, combiner, TMA, anti-interference filter, surge protector, and RET device). After this switch is turned on, the receiver sensitivity of the hit uplink frequency may deteriorate, and in some cases uplink services may even be unavailable. The impact is directly related to the size of the intermodulation products of the antenna system. For example, when the PIM3 is -140 dBc@2x43 dBm, the static receiver sensitivity of a single RRU channel deteriorates by 22 dB or less for GSM and by 9 dB or less for ULN. After this switch is turned on, alarms, such as ALM-26522 RF Unit RX Channel RTWP/RSSI Unbalanced, may be reported.
