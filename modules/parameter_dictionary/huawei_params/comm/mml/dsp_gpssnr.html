Display Signal Noise Ratio (DSP GPSSNR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the signal-to-noise ratio (SNR) of satellite signals. The SNR indicates the strength of carrier signals received by a GPS satellite card.

Note

None.

Parameters

ID Name Description
GN GPS Clock No.

Meaning: Indicates the number of the GPS clock link.

GUI Value Range: 0~17

Unit: None

Actual Value Range: 0~17

MML Default Value: None

Recommended Value: 0

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When a GPS MO is configured on a BBU subrack, GN must be set to 0 or 1.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the SNR of satellites, run the following command:
DSP GPSSNR:;
The result is shown as follows:

Output Description

Field Description

GPS Clock No.

Indicates the number of the GPS clock link.

Sat Type

Indicates the type of the satellite traced by the GPS.

Sat No.

Indicates the number of the satellite traced by the GPS.

Signal Noise Ratio(dB)

Indicates the signal-to-noise ratio of GPS satellite signals.
