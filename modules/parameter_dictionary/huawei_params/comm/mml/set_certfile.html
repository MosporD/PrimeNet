Set Certificate File (SET CERTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to configure NE certificate files to be loaded. The files are the root certificate, certificate revocation list (CRL), certificate chain, public key, and private key. These certificate files are used for digital connection authentication during the Secure Sockets Layer (SSL) handshake. This command can be used to remove the certificates for the certificate revocation list(CRL),certificate chains, and private key password.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the connection type is ALL. If the connection type is SSL, a certificate not matching the NE can be configured successfully but the NE cannot be managed by the MAE.

  • The certificate configuration modified by running this command will take effect during the next connection setup.

  • If the private key corresponding to the certificate is saved in a password-based encrypted file, the password must be set so that the file information can be read correctly.

  • The CRL, certificate chain file, and private key password must be specified when and only when they are required.

  • Before running this command, run the DLD GENFILE command to download the certificate file.

  • If an NE fails to load a certificate, the NE may start the bypass. The bypass policy is as follows: 1. If the NE fails to load the CA certificate or CA certificate chain, the value of Authentication Mode is changed to Verify None. 2. If the NE fails to load the public key certificate or private key certificate, the value of Connection Type is changed to Compatible Mode and the value of Authentication Mode is changed to Verify None.

  • [Co-MPT,NodeB]Before loading certificates not including any certificate chains to a BS loaded with a certificate chain, set Certificate Chain File Enabled State to DISABLE.

Example

To set certificate files with the parameters as follows: Root Certificate File Name: rootcert.pem, Certificate File Name: servercert.pem, Private Key File Name: serverkey.pem, Private Key Password Enabled State: DISABLE, Certificate Revocation List File Enabled State: ENABLE, Certificate Revocation List File Name: crl.pem, Certificate Chain File Enabled State: ENABLE, Certificate Chain File Name: certchain.pem, run the following command:
SET CERTFILE: ROOTCERT="rootcert.pem", PUBCERT="servercert.pem", PRIVKEY="serverkey.pem", PKPENABLESTA=DISABLE, CRLENABLESTA=ENABLE, CRL="crl.pem", CCAENABLESTA=ENABLE, CERTCHAIN="certchain.pem";
