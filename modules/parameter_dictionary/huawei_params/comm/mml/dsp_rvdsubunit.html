Display RVD Subunit (DSP RVDSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a remote vendor-defined antenna line device (RVD) subunit.

Note

Querying the information about the vertical beamwidth fails and the value NULL is displayed if ALM-26753 RET Antenna Not Calibrated is reported for an RVD.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the RVD.

GUI Value Range: 0~1023

Unit: None

Actual Value Range: 0~1023

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SUBUNITNO Subunit No.

Meaning: Indicates the number of the RVD subunit, which starts from 1.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

1.To query the dynamic information about the RVD subunit with the parameters as follows: Device No.: 0, Subunit No.: 1, run the following command:
DSP RVDSUBUNIT: DEVICENO=0, SUBUNITNO=1;

Output Description

Field Description

Device No.

Indicates the device number of the RVD.

Device Name

Indicates the device name of the ALD, which identifies the ALD. It is recommended that you set the device name in the following format: sector_device type_network type. The meanings of the parts are as follows: Sector indicates the number of the sector. Device type indicates the type of currently connected device. The device type can be SINGLE_RET (Single-antenna Remote Electrical Tilt Unit), MULTI_RET (Multi-antenna Remote Electrical Tilt Unit), TMA (Tower-mounted Amplifier), SASU (Same-band Antenna Sharing Unit), RAE (Remote eAntenna Extension), RVD (Remote Vendor Defined Antenna Line Device), or RAS (Remote Azimuth Steering Unit). Network type indicates whether the current ALD is used for a 2G network or 3G/LTE network. The device name is optional, but the device name configured for each ALD must be unique.

Subunit No.

Indicates the number of the RVD subunit, which starts from 1.

Subunit Name

Indicates the name of the RVD subunit. The name of the RVD subunit is optional, but the name configured for each RVD subunit must be unique.

Online Status

Indicates the online status of the subunit.

Actual Vertical BeamWidth(0.1degree)

Indicates the actual vertical beamwidth of RVD subunit.

Available Range of Vertical Beamwidth(0.1degree)

Indicates the vertical beamwidth range supported by the RVD subunit.

Actual Software-defined Antenna Mode

Indicates the operating mode actual value of the programmable antenna.

Supported SDA Mode

The working mode supported by the programmable antenna.

Actual Sector ID

Indicates the sector ID of the RVD subunit.

RVD Configuration Data File Name

Indicates the name of the RVD configuration data file that is loaded last time.

Configuration Data File Load Time

Indicates the time when the RVD configuration data file is loaded last time.
