Add Device IP Address (ADD DEVIP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a device IP address.

Note

  • In the same routing domain, the IP addresses of different ports must be on different network segments, whereas the IP addresses of the same port can be on the same network segment.

  • System specifications: If the WMPT/UMPT/UMDU/LMPT is the main control board, a maximum of 128 device IP addresses can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 64 device IP addresses can be configured.

  • Board specifications: A maximum of 128 device IP addresses can be configured on a WMPT/UMPT/UMDU/LMPT/UTRP (subboard type: UAEC/UIEC). A maximum of 16 device IP addresses can be configured on a GTMUb/GTMUc. A maximum of 56 device IP addresses can be configured on a UTRPc. A maximum of 24 device IP addresses can be configured on a UTRP (subboard type: UEOC). A maximum of 40 device IP addresses can be configured on a UTRP (subboard type: UQEC)/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9.

  • [Co-MPT,NodeB,eNodeB]A maximum of eight device IP addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, or a sub-interface. A maximum of seven device IP addresses can be configured on a port that carries a PPP link or an MP group. A maximum of two device IP addresses can be configured on a loopback interface.

  • [NodeB,eNodeB,gNodeB]It is recommended that the subnet mask be a 32-bit mask for the device IP address at a loopback interface.

  • [Co-MPT,eNodeB,gNodeB]It is recommended that a maximum of one device IP address be configured for an Ethernet CI port in the system.

  • [Co-MPT,eNodeB]If an error message indicating an IP address conflict is displayed during the configuration of a device IP address, search the existing IP address in the system that may conflict with the device IP address by running the following commands: LST DEVIP, DSP DEVIP, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, DSP MPGRP, LST IPRT, DSP IPRT, LST SRCIPRT, and DSP SRCIPRT, LST BFDSESSION, DSP BFDSESSION, LST UDPSESSION, DSP UDPSESSION, LST TWAMPCLIENT, DSP TWAMPCLIENT, LST IPPATHRT, and DSP IPPATHRT. Then, manually resolve the IP address conflict. The conflicting IP address may be a device IP address, local IP address of a remote maintenance channel, local IP address of a PPP link, IP address for local maintenance, local IP address of an MP group, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session, peer IP address of a UDP session, peer IP address of a TWAMP client, or next-hop IP address of an IP path route.

  • [NodeB]If an error message indicating an IP address conflict is displayed during the configuration of a device IP address, search the existing IP address in the system that may conflict with the device IP address by running the following commands: LST DEVIP, DSP DEVIP, LST OMCH, DSP OMCH, LST PPPLNK, DSP PPPLNK, LST LOCALIP, DSP LOCALIP, LST MPGRP, DSP MPGRP, LST IPRT, DSP IPRT, LST SRCIPRT, and DSP SRCIPRT, LST BFDSESSION, DSP BFDSESSION, LST UDPSESSION, DSP UDPSESSION, LST TWAMPCLIENT, and DSP TWAMPCLIENT. Then, manually resolve the IP address conflict. The conflicting IP address may be a device IP address, local IP address of a remote maintenance channel, local IP address of a PPP link, IP address for local maintenance, local IP address of an MP group, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session, peer IP address of a UDP session, or peer IP address of a TWAMP client.

  • [NodeB]A maximum of four loopback interfaces can be configured on a board.

  • [eNodeB]If the LMPT is used as the main control board, the device IP address with the port type set to PPP or MPGRP can be successfully configured but will fail to take effect.

  • [gNodeB]A maximum of eight device IP addresses can be configured on an Ethernet port, a port that carries an Ethernet trunk, or a sub-interface. A maximum of two device IP addresses can be configured on a loopback interface.

  • [gNodeB]If an error message indicating an IP address conflict is displayed during the configuration of a device IP address, search the existing IP address in the system that may conflict with the device IP address by running the following commands: LST DEVIP, DSP DEVIP, LST OMCH, DSP OMCH, LST LOCALIP, DSP LOCALIP, LST IPRT, DSP IPRT, LST SRCIPRT, DSP SRCIPRT, LST BFDSESSION, DSP BFDSESSION, LST TWAMPCLIENT, and DSP TWAMPCLIENT. Then, manually resolve the IP address conflict. The conflicting IP address may be a device IP address, local IP address of a remote maintenance channel, IP address for local maintenance, next-hop IP address of an IP route, next-hop IP address of a source IP route, destination IP address of a BFD session, or peer IP address of a TWAMP client.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the DEVIP MO, if PT is not set to SUBIF or LOOPINT, VRFIDX must be set to 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the DEVIP MO, if PT and VRFIDX are set to LOOPINT and 0, respectively, PN can be set to any value in the range of 0 to 3.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the DEVIP MO, if PT is set to LOOPINT, and VRFIDX is not set to 0, PN can be set to any value in the range of 4(VRFIDX)+4 to 4(VRFIDX)+7.
  • [gNodeB]The value of PT in a DEVIP MO cannot be set to MPGRP.
  • [gNodeB]The value of PT in a DEVIP MO cannot be set to PPP.
  • [gNodeB]The value of PT in a DEVIP MO cannot be set to ETHCI.

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the DEVIP MO, if SBT is set to BASE_BOARD, this parameter can be set to PPP, MPGRP, ETH, ETHTRK, LOOPINT, SUBIF, or ETHCI.
  • In the DEVIP MO, if SBT is set to BACK_BOARD, this parameter must be set to PPP.
  • In the DEVIP MO, if SBT is set to E1_COVERBOARD, this parameter can be set to PPP, MPGRP, or LOOPINT.
  • In the DEVIP MO, if SBT is set to ETH_COVERBOARD, this parameter can be set to ETH, ETHTRK, or LOOPINT.

Example

Example 1: To add a device IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, IP Address: 192.168.2.24, Mask: 255.255.255.0, run the following command: 
ADD DEVIP: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0, IP="192.168.2.24", MASK="255.255.255.0";
Example 2: To add a device IP address with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 1, Subboard Type: E1_COVERBOARD, Port Type: MPGRP, Port No.: 1, IP Address: 192.168.11.23, Mask: 255.255.255.0, run the following command: 
ADD DEVIP: CN=0, SRN=0, SN=1, SBT=E1_COVERBOARD, PT=MPGRP, PN=1, IP="192.168.11.23", MASK="255.255.255.0";
