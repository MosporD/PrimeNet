List LLDP Local Global Info (LST LLDPPORT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an LLDP port.

Note

LLDP ports that are automatically generated cannot be queried using this command but can be queried using the DSP LLDPPORT command.

Parameters

None.

Example

To list the configuration of the LLDP port information, run the following command: 
LST LLDPPORT:;
The result is shown as follows:
+++    0        2012-11-28 13:26:20
O&M    #558
%%LST LLDPPORT:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where the LLDPLOCAL is located.

Subrack No.

Indicates the subrack number of the board where the LLDPLOCAL is located.

Slot No.

Indicates the slot number of the board where the LLDPLOCAL is located.

Subboard Type

Indicates the type of sub-board on the board where the LLDPLOCAL is located.

Port No.

Indicates the number of the Ethernet port where the LLDPLOCAL is located.

Binding VLAN

Indicates whether the local LLDP port is associated with the VLAN. If the local LLDP port is bound to a VLAN, LLDP packets sent by the local end carry the VLAN ID.

VLAN ID

Indicates the VLAN ID of local LLDP port.

VLAN Priority

Indicates the VLAN priority of local LLDP port.
