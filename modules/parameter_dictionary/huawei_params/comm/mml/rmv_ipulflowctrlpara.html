Remove IP Uplink Flow Control Para (RMV IPULFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove the user-defined configuration of an IP uplink flow control algorithm. The execution of this command restores the default configuration of the algorithm.

Note

[Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

Parameters

ID Name Description
IPULFLOWCTRALGID IP Uplink Flow Control Algorithm ID

Meaning: Indicates the ID of the IP UL flow control algorithm.

GUI Value Range: 0~143

Unit: None

Actual Value Range: 0~143

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U

Example

To remove the user-defined configuration of the IP uplink flow control algorithm with the parameters as follows: IP Uplink Flow Control Algorithm ID: 0, run the following command:
RMV IPULFLOWCTRLPARA: IPULFLOWCTRALGID=0;
