Download Certificate File (DLD CERTFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to download a certificate file from an FTP server to the directory that the BS uses to store all certificate files downloaded from FTP servers.

Note

  • Run this command to download the certificate file to the base station before running the ADD CERTMK, ADD TRUSTCERT, ADD CROSSCERT, or ADD CRL command to add certificate configurations or running the ACT CERTWHITELSTFILE command to activate the digital certificate whitelist.

  • After this command has been executed to add certification configuration or activate a whitelist file, the base station automatically removes the certificate files from the download area and manages the certificate files.

  • A maximum of 16 certificates can be stored in the download directory.

  • If an error message, indicating insufficient flash memory, is displayed, it is recommended to remove the files that are no longer used by running RMV CERTFILE or CLR FILE.

  • The size of a certificate file to be downloaded must be less than 2 MB (excluding a file in the .xml format). If a certificate file to be download is in the .xml format, the size of its compressed package must be less than 2 MB.

SRCF Source File Name

Meaning: Indicates the file name of a source certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|). At present, only files with the following file name extensions (case-insensitive) are supported: .pem, .cer, .crt, .der, .p7b, .crl, .gz and .xml. When a source file name extension is .xml, the system automatically compresses the downloaded file, adds .gz to the end of the destination file name entered by a user, and uses this name as the final destination file name. In this case, the maximum length of the destination file name entered by the user is the maximum length of a file name allowed on the interface minus 3 characters (the length of the file name extension .gz).

Example

To download a file using IPv4 with the parameters as follows: IP Mode: IPv4, FTP Server IP: 192.168.58.118, User Name: admin, Password: *****, Source File Name: Certificate.pem, Destination File Name: Certificate.pem, run the following command:
DLD CERTFILE: MODE=IPV4, IP="192.168.58.118", USR="admin", PWD="*****", SRCF="Certificate.pem", DSTF="Certificate.pem";
To download a file using IPv6 with the parameters as follows: IP Mode: IPv6, FTP Server IP: 2001:DB8::1, User Name: admin, Password: *****, Source File Name: Certificate.pem, Destination File Name: Certificate.pem, run the following command:
DLD CERTFILE: MODE=IPV6, IP="2001:DB8::1", USR="admin", PWD="*****", SRCF="Certificate.pem", DSTF="Certificate.pem";
