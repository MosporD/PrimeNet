List MPT Configurations (LST MPT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list MPT configurations.

None.

LST MPT:;
The result is shown as follows:

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the main control and transmission board.

Subrack No.

Indicates the subrack number of the main control and transmission board.

Slot No.

Indicates the slot number of the main control and transmission board.

Board Type

Indicates the type of the board. This parameter is the logical type rather than the physical type of the board.

Board Specification

Indicates the type of a board. If this parameter is not specified, the base station and MAE-Deployment check board configurations based on the maximum specifications of a configured board. If this parameter is specified, the base station and MAE-Deployment check board configurations based on the specifications of the specified board so that the MAE-Deployment can identify incorrect configurations before delivering configurations to the base station. This parameter must be specified based on the actual hardware type of the board. For example, if the hardware type of a board is UMPTa, this parameter can be set to UMPTa or UMPTa/b. If the hardware type of a board is UMPTb, this parameter can be set to UMPTb or UMPTa/b. If the configured type of a board is WMPT or LMPT or this parameter is not specified, the value of this parameter is NULL. The values are case insensitive.

Work Mode of MPT

Indicates the main control working mode of the main control and transmission board. NORMAL indicates that the main control and transmission board works in normal mode. TDS-EVOLUTION indicates that the main control and transmission board works in TDS evolution mode, which applies only to China Mobile TDS-TDL dual-mode scenarios and does not apply to other operators. If this parameter is set to TDS-EVOLUTION for other operators, the main control and transmission function of the board will be invalid and the ongoing services will be interrupted.
