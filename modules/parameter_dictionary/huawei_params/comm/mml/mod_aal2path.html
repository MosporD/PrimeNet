Modify AAL2 Path (MOD AAL2PATH)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to modify an AAL2 path.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB]The operation may interrupt the services carried on the path.

Parameters

ID Name Description
NT Node Type

Meaning: Indicates the type of an AAL2 path. If the local end node is selected, the AAL2 path is used by local services. If the switching node is selected, the AAL2 path is used to connect to the controller through the hub BS. If the adjacent node is selected, the AAL2 path is used to connect to the lower-level BS through the hub BS.

GUI Value Range: LOCAL(End Node), HUB(Switching Node), ADJNODE(Adjacent Node)

Unit: None

Actual Value Range: LOCAL, HUB, ADJNODE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

RU Rate Unit

Meaning: Indicates the unit of the peak cell rate (PCR), minimum cell rate (MCR), sustainable cell rate (SCR), and receive cell rate (RCR). 1 cell/s is equal to 0.424 kbit/s. If the rate is converted from cell/s to kbit/s, the result value must be rounded down to the nearest integer. For example, 73 cell/s is converted to 30 kbit/s.

GUI Value Range: KBPS(kbit/s), CELL/S(cell/s)

Unit: None

Actual Value Range: KBPS, CELL/S

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
ST Bearer Service Type

Meaning: Indicates the type of the service carried on an AAL2 path. From the perspective of flow control, services carried by an AAL2 path are classified into five categories: the constant bit rate (CBR) service, real-time variable bit rate (RTVBR) service, non-real-time variable bit rate (NRTVBR) service, unspecified bit rate plus (UBR+) service, and unspecified bit rate (UBR) service.

GUI Value Range: CBR(CBR), RTVBR(RTVBR), NRTVBR(NRTVBR), UBR+(UBR+), UBR(UBR)

Unit: None

Actual Value Range: CBR, RTVBR, NRTVBR, UBR+, UBR

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U
PCR Peak Cell Rate

Meaning: Indicates the peak cell rate (PCR) of an AAL2 path, which is the maximum cell burst rate supported by the AAL2 path. The value of this parameter is subject to the actual network. Setting the parameter to an improper value affects the service quality.

GUI Value Range: 30~49529

Unit: None

Actual Value Range: 30~49529

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST and RU are set to UBR+ and KBPS, respectively, MCR must be less than PCR.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to UBR+ and RU is set to CELL/S, MCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to RTVBR or NRTVBR and RU is set to KBPS, SCR must be less than PCR.
  • [Co-MPT, NodeB]In an AAL2PATH MO, if ST is set to RTVBR or NRTVBR and RU is set to CELL/S, SCR must be less than PCR after the rate unit is changed to kbit/s and both rates are rounded down.

-Others:

  • [Co-MPT, NodeB]In an AAL2PATH MO, if SBT is set to BASE_BOARD, BACK_BOARD, or E1_COVERBOARD, RU is set to KBPS, and ST is set to RTVBR, NRTVBR, or UBR+, the value range of this parameter is from 31 to 15800.
  • In an AAL2PATH MO, if SBT is set to BASE_BOARD, BACK_BOARD, or E1_COVERBOARD, RU is set to KBPS, and ST is set to CBR or UBR, the value range of this parameter is from 30 to 15800.
  • In an AAL2PATH MO, if SBT is set to BASE_BOARD, BACK_BOARD, or E1_COVERBOARD, RU is set to CELL/S, and ST is set to RTVBR, NRTVBR, or UBR+, the value range of this parameter is from 74 to 37265.
  • In an AAL2PATH MO, if SBT is set to BASE_BOARD, BACK_BOARD, or E1_COVERBOARD, RU is set to CELL/S, and ST is set to CBR or UBR, the value range of this parameter is from 71 to 37265.
  • In an AAL2PATH MO, if SBT is set to UNCHANNELLED_COVERBOARD, RU is set to KBPS, and ST is set to RTVBR, NRTVBR, or UBR+, the value range of this parameter is from 31 to 21000.
  • In an AAL2PATH MO, if SBT is set to UNCHANNELLED_COVERBOARD, RU is set to KBPS, and ST is set to CBR or UBR, the value range of this parameter is from 30 to 21000.
  • In an AAL2PATH MO, if SBT is set to UNCHANNELLED_COVERBOARD, RU is set to CELL/S, and ST is set to RTVBR, NRTVBR, or UBR+, the value range of this parameter is from 74 to 49529.
  • In an AAL2PATH MO, if SBT is set to UNCHANNELLED_COVERBOARD, RU is set to CELL/S, and ST is set to CBR or UBR, the value range of this parameter is from 71 to 49529.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To modify an AAL2 path with the parameter as follows: Node Type: LOCAL, Path ID: 1, Rate Unit: KBPS, Bearer Service Type: RTVBR, Peak Cell Rate: 36, Sustain Cell Rate: 33, Receive Cell Rate: 32, Max Burst Size: 1500, Cell Delay Variation Tolerance: 1025, run the following command: 
MOD AAL2PATH: NT=LOCAL, PATHID=1, RU=KBPS, ST=RTVBR, PCR=36, SCR=33, RCR=32, MBS=1500, CDVT=1025;
