Display OM Channel Status (DSP OMCH)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a remote maintenance channel.

Note

  • After a remote maintenance channel is automatically established on a BS, the execution result of this command indicates the information about the automatically established channel, which may be inconsistent with the execution result of the LST OMCH command. The result of this command is the data that takes effect currently. If detection for automatic establishment of a remote maintenance channel is in progress on a BS, the information related to a remote maintenance channel cannot be queried.

  • If the bearer type of the OM channel is IPv4, the value of Binding Route is YES, and the value of Route Index is NULL, the active route for the remote maintenance channel is created by the function automatic establishment of a remote maintenance channel, and the destination IP address and subnet mask of the route are the peer network segment IP address and the peer subnet mask, respectively. When Route Type is set to NEXTHOP, the next hop IP address of the route is the default gateway IP address in the DSP DHCPRSLT command. When Route Type is set to IF, the actual port type and port number of the route are the port type and port number, respectively, in the DSP DHCPRSLT command.

  • If the configuration file delivered by the MAE contains configurations for active and standby O&M channels and both channels are available, the base station can use either channel after the base station resets.

  • [Co-MPT,eNodeB,gNodeB]If the bearer type of the OM channel is IPv6, the value of Binding Route is Yes, and the value of Route Index is NULL, this indicates the route that takes effect for the OM channel is generated through the automatic OMCH establishment function. The destination IPv6 address and prefix length of the route are the network segment address and prefix length of the peer IPv6 address of the OM channel, and the route type is next hop. The next-hop IPv6 address of the route is the default gateway IPv6 address shown in the DSP DHCPRSLT command output.

  • [Co-MPT,eNodeB,gNodeB]When an NE automatically establishes an OMCH, the OMCH uses only the default VRF.

Parameters

FLAG Standby Status

GUI Value Range: MASTER(Master), SLAVE(Slave)

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In an OMCH MO, if CHECKTYPE is set to AUTO_UDPSESSION, FLAG must be set to MASTER.

To query the status of the OM channel, run the following command:

Output Description

Field Description

Standby Status

Indicates the master/slave flag of the remote maintenance channel.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Bearer Type

Indicates the bearer type of an OM channel. If this parameter is set to ATM, the element management system (EMS) uses the ATM-based transmission network to maintain the device. If this parameter is set to IPV4, the EMS uses the IPv4-based transmission network to maintain the device. If this parameter is set to IPV6, the EMS uses the IPv6-based transmission network to maintain the device. ATM does not apply to LTE and NR networks. IPv6 does not apply to GSM and UMTS networks.

Local IP

Indicates the local IP address of a remote maintenance channel.

Local Mask

Indicates the local subnet mask of a remote maintenance channel.

Peer IP

Indicates the peer IP address of the remote maintenance channel. Indicates the IP address of the MAE in an IP network and the device IP address of the RNC in an ATM network.

Peer Mask

Indicates the subnet mask of the peer IP address for the remote maintenance channel.

Local IPv6 Address

Indicates the local IPv6 address of an OM channel. This address must be a globally scoped unicast address.

Peer IPv6 Address

Indicates the peer IPv6 address of an OM channel. This address must be a globally scoped unicast address.

Peer IPv6 Address Prefix Length

Indicates the prefix length of the peer IPv6 address of an OM channel.

Binding Route

Indicates whether a route is bound to the remote maintenance channel. If the peer IP address of the remote maintenance channel and device IP addresses are not in the same network segment and the network segment of the device IP address cannot cover that of the peer IP address, run the ADD IPRT or ADD IPROUTE4 command to add a route to the remote maintenance channel. If the peer IPv6 address of the remote maintenance channel and IPv6 addresses are not in the same network segment and the network segment of the IPv6 address cannot cover that of the peer IPv6 address, run the ADD IPROUTE6 command to add a route to the remote maintenance channel.

If this parameter is set to YES, a route is bound to the remote maintenance channel and the route does not take effect when the remote maintenance channel does not take effect (except when an OMCH whose bearer type is IPv4 and an OMCH whose bearer type is IPv6 form an active/standby relationship). If this parameter is set to NO, no route is bound to the remote maintenance channel, and a remote maintenance channel switchover does not trigger a route status switchover.

Route Index

Indicates the index of the active route bound to the remote maintenance channel.

Binding Secondary Route

Indicates whether a standby route needs to be bound to the remote maintenance channel. If the remote HA system is applied to the MAE and no destination IP address network segment for the route covers the MAE destination IP address network segment, run the ADD IPRT, ADD IPROUTE4, or ADD IPROUTE6 command to add a route to the MAE.

If this parameter is set to YES, a standby route is bound to the remote maintenance channel and the route does not take effect when the remote maintenance channel does not take effect (except when an OMCH whose bearer type is IPv4 and an OMCH whose bearer type is IPv6 form an active/standby relationship). If this parameter is set to NO, no route is bound to the remote maintenance channel, and a remote maintenance channel switchover does not trigger a route status switchover.

Secondary Route Index

Indicates the index of the standby route bound to the remote maintenance channel.

Check Type

Indicates the type of detection mechanism bound to the remote maintenance channel. If this parameter is set to NONE, no detection mechanism is bound to the remote maintenance channel and an active/standby remote maintenance channel switchover is triggered by switchover message sent by the MAE. If this parameter is set to UDPSESSION, the UDP ping detection is bound to the remote maintenance channel and an active/standby remote maintenance channel switchover depends on the UDP session detection, only GSM currently supports this function. If this parameter is set to UDPSESSIONGRP, the UDP ping detection is bound to the remote maintenance channel and an active/standby remote maintenance channel switchover depends on the UDP session group detection, only GSM currently supports this function. If this parameter is set to AUTO_UDPSESSION, automatic UDP session detection is performed on the OM channel. When the standby OM channel is connected to the EMS, the base station automatically creates a UDP session from the local IP address of the active OM channel to the EMS. If the OM channel switchback function is required, set CHECKTYPE for the active OM channel to AUTO_UDPSESSION.

UDP Session ID

Indicates the session number of the UDP ping detection bound to the remote maintenance channel.

UDP Session Group ID

Indicates the session group number of the UDP ping detection bound to the remote maintenance channel.

OMIP Switch

Indicates whether to set the OMIP as the remote maintenance IP address when the remote maintenance channel uses ATM transport channel. If this parameter is set to ON, the OMIP will be set as the remote maintenance IP address. That time the remote maintenance channel auto-setup function will not be enabled. If this parameter is set to OFF, the Local IP will be set as the remote maintenance IP address.

OMIP

Indicates the remote maintenance IP address when the remote maintenance channel uses ATM transport channel.

OMIP MASK

Indicates mask of the remote maintenance IP address when the remote maintenance channel uses ATM transport channel.

Cabinet No.

Indicates the cabinet number of the board where the remote maintenance channel is located.

Subrack No.

Indicates the subrack number of the board where the remote maintenance channel is located.

Slot No.

Indicates the slot number of the board where the remote maintenance channel is located.

Subboard Type

Indicates the type of sub-board on the board where a remote maintenance channel is established.

Port Type

Indicates the type of physical port that carries a remote maintenance channel.

According to the configuration of the physical layer, a remote maintenance channel can be carried on the STM-1 optical port, IMA group, UNI link, or fractional ATM link.

Port No.

Indicates the number of the port carrying the link on which a remote maintenance channel is carried.

Join Transmission Resource Group

Indicates whether to add a remote maintenance channel to a transmission resource group.

If a remote maintenance channel is added to a resource group, bandwidth management of the remote maintenance channel is subject to the bandwidth of the resource group.

If a remote maintenance channel is not added to any resource group, bandwidth management of the remote maintenance group is subject to the physical bandwidth.

Transmission Resource Group ID

Indicates the ID of the transmission resource group to which a remote maintenance channel is added.

VPI

Indicates the Virtual Path Identifier (VPI) of a remote maintenance channel.

VCI

Indicates the Virtual Channel Identifier (VCI) of a remote maintenance channel.

Rate Unit

Indicates the rate unit of the peak cell rate (PCR), minimum cell rate (MCR), and sustain cell rate (SCR). If the rate unit is set to kbit/s, it cannot be changed to cell/s. 1 cell/s is equal to 0.424 kbit/s. The rate is converted from cell/s to kbit/s. The converted value needs to be rounded down. For example, 73 cell/s is converted to 30 kbit/s.

Service Type

Indicates the service type of data carried on a remote maintenance channel.

Sustainable Cell Rate

Indicates the Sustainable Cell Rate (SCR) of a remote maintenance channel.

Peak Cell Rate

Indicates the Peak Cell Rate (PCR) of the remote maintenance channel.

Min Cell Rate

Indicates the Minimum Cell Rate (MCR) of a remote maintenance channel. If the cell rate of the remote maintenance channel is less than the MCR, a cell rate error alarm is reported.

OM Channel Status

Indicates the status of a remote maintenance channel.

Used State

Indicates whether the remote maintenance channel is being used.
