Remove IPv6 ACL6 Rule (RMV ACLRULE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove an ACL rule from an IPv6 ACL.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,eNodeB,gNodeB]If an IPv6 ACL is referenced by an IPv6 IPSec policy or a packet filtering policy, the last IPv6 rule in the ACL cannot be removed.

Parameters

ID Name Description
ACLID IPv6 ACL ID

Meaning: Indicates the ID of an IPv6 access control list (ACL) to which the IPv6 access control rule belongs.

GUI Value Range: 3000~3999,7000~7999

Unit: None

Actual Value Range: 3000~3999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
RULEID IPv6 Rule ID

Meaning: Indicates the ID of an IPv6 ACL rule. The values 1 to 65535 indicate IPv6 ACL rules configured by users. The values 65431 to 65536 indicate the IPv6 ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate packet filtering IPv6 ACL rules configured by the system (packet filtering ACL rules are not supported in IPv6 configuration currently). The values 80000 to 89999 indicate IPv6 IPsec ACL rules configured by the system.

GUI Value Range: 1~65535,70000~89999

Unit: None

Actual Value Range: 1~65535,70000~79999,80000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether a forcible change of an IPv6 ACL rule is made. When this parameter is set to NO(No), the system checks whether the change affects upper-layer services. If the change affects upper-layer services, the forcible change will fail. When this parameter is set to YES(Yes), the system does not check whether the change affects upper-layer services. Upper-layer services include the following: active OM channel (OMCH), DNS service (DNSSRV), certificate authority (CA), CRL update (CRLTSK), IP clock link (IPCLKLINK), NTP (NTPC), ABIS CP/IUB CP/S1 CP/X2 CP/M2 CP/ECO CP/eX2 CP/SO CP/UX2 CP/XW CP/gNBCUX2 CP/gNBCUNg CP/gNBCUXn CP (SCTPLNK/SCTPPEER), and ABIS UP/IPPATH of unknown service type/IUB UP/UX2 UP/S1 UP/X2 UP/eX2 UP/XW UP/gNBCUX2 UP/gNBCUS1 UP/gNBCUNg UP/gNBCUXn UP (USERPLANEPEER).Only the change of the IPv6 ACL rule that is manually configured with Protocol Type set to IPv6 and Match DSCP set to NO in IPsec networking is checked.

Pay attention to the following when using this parameter:

1. The system checks whether a forcible change affects upper-layer services based on the configuration data instead of based on the actual running status of these services.

2. If an NE is configured with an SRCIPROUTE6 MO, the system does not check whether a forcible change of an IPv6 ACL rule affects upper-layer services.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Example

To remove an IPv6 ACL rule with the parameters as follows: IPv6 ACL ID: 3000, IPv6 Rule ID: 10, run the following command: 
RMV ACLRULE6: ACLID=3000, RULEID=10;
