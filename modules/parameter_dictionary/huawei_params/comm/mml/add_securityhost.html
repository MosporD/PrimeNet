Add Security Host (ADD SECURITYHOST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a security host required by an automatic security setup.

Note

  • System specifications: If the LMPT/UMPT/GTMUb/GTMUc/UMDU/WMPT is the main control board, a maximum of 32 security hosts can be configured.

  • Ensure that the local IKE IP address of the security host has been configured by using the ADD DEVIP or ADD IPADDR4 command.

  • Ensure that the IPSec proposal name of the security host has been configured by using the ADD IPSECPROPOSAL command.

  • Ensure that the IKE peer name of the security host has been configured by using the ADD IKEPEER command.

  • Ensure that the security parameters template ID of the security host has been configured by using the ADD SECURITYTEMPLATE command.

  • If the following conditions are met during automatic setup of an IPv4 user-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the user plane:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during automatic setup of an IPv4 user-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the user plane:

    - IPSec Auto Configure Switch is set to ENABLE for both the USERPLANEHOST and USERPLANEPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • The IPSec redundancy function is not supported in security object automatic setup scenarios. That is, the Redundancy Flag parameter in the IPv4 IKE peer of the security host must be NONE(Non-redundancy).

  • [Co-MPT,NodeB,eNodeB,gNodeB]If the following conditions are met during automatic setup of an IPv4 control-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECBIND or IPSECBINDITF, and IPSECPOLICY objects and set up an IPsec tunnel for the control plane:

    - IPSec Auto Configure Switch for First Local IP and IPSec Auto Configure Switch for Second Local IP are set to ENABLE for both the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to ENABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPEER, IKEPROPOSAL, and IPSECPROPOSAL objects have been configured.

    If the following conditions are met during automatic setup of an IPv4 control-plane IPsec tunnel, the system will automatically configure the ACL, ACLRULE, IPSECPOLICY, IPSECBIND or IPSECBINDITF, and IKEPEER objects and set up an IPsec tunnel for the control plane:

    - IPSec Auto Configure Switch for First Local IP and IPSec Auto Configure Switch for Second Local IP are set to ENABLE for both the SCTPHOST and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

  • [Co-MPT,eNodeB,gNodeB]Ensure that the local IKE IPv6 address of the security host has been configured by using the ADD IPADDR6 command.

  • [Co-MPT,eNodeB,gNodeB]If the following conditions are met during automatic setup of an IPv6 IPsec tunnel, the system will automatically configure the SCTPLNK, TUNNELITF, ACL6, ACLRULE6, IPSECBINDITF, IPSECPOLICY, IKEPEER, INTERFACE, and IPROUTE6 objects and set up an IPsec tunnel:

    - IPSec Auto Configure Switch is set to ENABLE for the USERPLANEHOST, SCTPHOST, USERPLANEPEER, and SCTPPEER objects in the same endpoint group.

    - SeGW Switch is set to DISABLE for the SECURITYHOST, SECURITYPEER, and SECURITYTEMPLATE objects.

    - The IKEPROPOSAL and IPSECPROPOSAL objects have been configured.

SEGWSWITCH SeGW Switch

Meaning: Indicates whether to enable the peer end to perform IPSec negotiation with the local end through an SeGW. When this parameter is set to DISABLE, the peer end performs IPSec negotiation with the local end directly. When this parameter is set to ENABLE, the peer end establishes an IPSec tunnel to the local end through an SeGW.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: DISABLE(Disable)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Example

To add a security host with the parameters as follows: Security Host ID: 0, SeGW Switch: Disable, IP Version: IPv4, Local IKE IP Address: 192.168.1.2, Security Parameters Template ID: 0, run the following command:
ADD SECURITYHOST: SECURITYHOSTID=0, SEGWSWITCH=DISABLE, IPVERSION=IPv4, LOCIKEIPV4="192.168.1.2", SECURITYTEMPLATEID=0;
