List IPv6 ACL Rule Configuration (LST ACLRULE6)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of an IPv6 access control list (ACL) rule.

Note

None.

Parameters

ID Name Description
ACLID IPv6 ACL ID

Meaning: Indicates the ID of an IPv6 access control list (ACL) to which the IPv6 access control rule belongs.

GUI Value Range: 3000~3999,7000~7999

Unit: None

Actual Value Range: 3000~3999,7000~7999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N
RULEID IPv6 Rule ID

Meaning: Indicates the ID of an IPv6 ACL rule. The values 1 to 65535 indicate IPv6 ACL rules configured by users. The values 65431 to 65536 indicate the IPv6 ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate packet filtering IPv6 ACL rules configured by the system (packet filtering ACL rules are not supported in IPv6 configuration currently). The values 80000 to 89999 indicate IPv6 IPsec ACL rules configured by the system.

GUI Value Range: 1~65535,70000~89999

Unit: None

Actual Value Range: 1~65535,70000~79999,80000~89999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, eNodeB, gNodeB]The values of ACL ID and Rule ID in a manually configured ACLRULE6 MO must range from 3000 to 3999 and from 1 to 65535, respectively.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: L, N

Output Description

Field Description

IPv6 ACL ID

Indicates the ID of an IPv6 access control list (ACL) to which the IPv6 access control rule belongs.

IPv6 Rule ID

Indicates the ID of an IPv6 ACL rule. The values 1 to 65535 indicate IPv6 ACL rules configured by users. The values 65431 to 65536 indicate the IPv6 ACL rules automatically generated during DHCP detection. The values 70000 to 79999 indicate packet filtering IPv6 ACL rules configured by the system (packet filtering ACL rules are not supported in IPv6 configuration currently). The values 80000 to 89999 indicate IPv6 IPsec ACL rules configured by the system.

IPv6 ACL Action

Indicates the action taken on the data that matches an IPv6 ACL rule. When the IPv6 ACL rule is referenced by an IPv6 IPSec policy, the BS encrypts or decrypts the data that matches the rule if this parameter is set to PERMIT, and does not encrypt or decrypt the data if this parameter is set to DENY.

Protocol Type

Indicates the protocol type of the data to which an IPv6 ACL rule is applied.

Source IPv6 Address

Indicates the source IPv6 address of data to which an IPv6 ACL rule is applied.

Source Address Prefix Length

Indicates the prefix length of a source IPv6 address. The prefix length is used to determine which bits must be compared for matching when IPv6 address matching is being performed.

Match Source Port

Indicates whether to check the source port number of each data stream before applying an ACL rule.

Source Port Operate

Indicates the filter criteria for a source port. If this parameter is set to OP_LT, the ACL rule is applied to the data stream whose source port number is smaller than or equal to the configured port number. If this parameter is set to OP_GT, the ACL rule is applied to the data stream whose source port number is larger than or equal to the configured port number. If this parameter is set to OP_EQ, the ACL rule is applied to the data stream whose source port number is equal to the configured port number. If this parameter is set to OP_NEQ, the ACL rule is applied to the data stream whose source port number is not equal to the configured port number. If this parameter is set to OP_RANGE, the ACL rule is applied to the data stream whose source port number is within the configured range.

Source Port 1

Indicates the source port number used when SMPT is set to YES. If SOP is set to OP_RANGE, this parameter indicates the smallest source port number. If SOP is not set to OP_RANGE, this parameter indicates a specific source port number.

Source Port 2

Indicates the source port number used when SMPT is set to YES. If SOP is set to OP_RANGE, this parameter indicates the largest source port number. This parameter is valid only when SOP is set to OP_RANGE.

Destination IPv6 Address

Indicates the destination IPv6 address of the data to which an IPv6 ACL rule is applied.

Destination Address Prefix Length

Indicates the prefix length of a destination IPv6 address. The prefix length is used to determine which bits must be compared for matching when IPv6 address matching is being performed.

Match Destination Port

Indicates whether to check the destination port number of each data stream before applying an ACL rule.

Destination Port Operate

Indicates the filter criteria for a destination port. This parameter is valid only when DMPT is set to YES. If this parameter is set to OP_LT, the ACL rule is applied to the data stream whose destination port number is smaller than or equal to the configured port number. If this parameter is set to OP_GT, the ACL rule is applied to the data stream whose destination port number is larger than or equal to the configured port number. If this parameter is set to OP_EQ, the ACL rule is applied to the data stream whose destination port number is equal to the configured port number. If this parameter is set to OP_NEQ, the ACL rule is applied to the data stream whose destination port number is not equal to the configured port number. If this parameter is set to OP_RANGE, the ACL rule is applied to the data stream whose destination port number is within the configured range.

Destination Port 1

Indicates the destination port number used when DMPT is set to YES. If DOP is set to OP_RANGE, this parameter indicates the smallest destination port number. If DOP is not set to OP_RANGE, this parameter indicates a specific destination port number.

Destination Port 2

Indicates the destination port number used when DMPT is set to YES. If DOP is set to OP_RANGE, this parameter indicates the largest destination port number. This parameter is valid only when DOP is set to OP_RANGE.

Match DSCP

Indicates whether to check the DSCP of each data stream before applying an IPv6 ACL rule.

DSCP

Indicates the DSCP that complies with an IPv6 ACL rule.

Control Mode

Indicates whether an object can be modified or deleted by the system. The value MANUAL_MODE means that only the user can modify or delete the object. The value AUTO_MODE means only the system can modify or delete the object.

Auto Config Flag

Indicates whether the object is created by the system. MANUAL_CREATED means that the object is configured by the user manually. AUTO_CREATED means that the object is created by the system.
