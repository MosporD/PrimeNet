Modify RET Tilt (MOD RETTILT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the remote electrical tilt (RET).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before running this command, ensure that the RET tilt is calibrated. For details about calibration, see the CLB RET command.

  • The range of the RET tilt varies according to the manufacturer and RET model. Before setting the tilt, you are advised to run the DSP RETDEVICEDATA command to check the tilt range supported by the antenna.

  • After you modify the RET tilt, the system automatically changes the tilt based on your modification, which affects the network coverage. Changing the tilt takes 4 minutes at most. If the tilt fails to be changed, the system reports ALM-26757 RET Antenna Running Data and Configuration Mismatch.

  • Setting an RET Subunit tilt takes a maximum of 4 minutes.

  • The antenna tilt of an AAU supporting beamforming cannot be modified by sector.

  • For an AAU supporting beamforming, the tilt angles of the inner and outer RET antennas must be valid and the tilt angle of the inner RET antenna must be greater than or equal to that of the outer RET antenna.

  • If an unavailable RPCU exists on the base station, the configured data cannot take effect and ALM-26757 RET Antenna Running Data and Configuration Mismatch is reported. This alarm is automatically cleared when all RPCUs are running properly.

Example

To modify the RET tilt with the parameters as follows: RET Class: RET, Operate Mode: DEVICENO, Device No.: 0, Tilt: 100, run the following command:
MOD RETTILT: RETCLASS=RET, OPMODE=DEVICENO, DEVICENO=0, TILT=100;
