Add Mapping from End Point to Transmission Resource Group (ADD EP2RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add mapping from End Point to Transmission Resource Group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before adding a mapping between an end point and a transmission resource group, ensure that the RSCGRP MO has been added by running the ADD RSCGRP command.

  • A base station supports a maximum of 456 mappings between end points and transmission resource groups. If the GTMUb/GTMUc is the main control board, a base station supports a maximum of 64 mappings between end points and transmission resource groups.

  • A base station supports two types of mapping between an end point and a transmission resource group: end point group mapping and end point mapping.

    End point group mapping: Add all user plane peers in the EPGROUP to the specified transmission resource group.

    End point mapping: Add the specified user plane peer to the specified transmission resource group.

    If an end point added to the transmission resource group through the end point group mapping and end point mapping conflict, use the end point mapping to add end points to the transmission resource group. If no transmission resource group is specified for a user plane peer, the internal user plane path that is automatically set up between the local base station and the corresponding user plane peer joins the default transmission resource group.

  • In the two types of mapping between an end point and a transmission resource group, the same end point group or end point cannot be added to different transmission resource groups of the same physical port.

  • If the port type for the local IP address of a user-plane host is a loopback interface, the following principles are complied with when the automatically established user-plane link is added to the transmission resource group:

    1. If the loopback interface is on the same board as the actual service outbound interface and the outbound interface is the same as the transmission resource group interface configured in an EP2RSCGRP object, services are carried in the transmission resource group specified in the EP2RSCGRP object. If the loopback interface is on the same board as the actual service outbound interface but the outbound interface is different from the transmission resource group interface configured in an EP2RSCGRP object, services are carried in default transmission resource group with the actual service outbound interface.

    2. If the loopback interface is on a different board from the actual service outbound interface, services are carried in the default transmission resource group with the actual service outbound interface.

  • Running this command may interrupt ongoing services carried on the base station.

Parameters

ID Name Description
MT Mapping Type

Meaning: Indicates the mapping mode between the service and the transmission resource group. Two mapping modes are supported: endpoint group mode and endpoint mode. If this parameter is set to ENDPOINT_GROUP, all user-plane peer endpoints in the endpoint group can be added to the specified transmission resource group. If this parameter is set to ENDPOINT_NODE, the specified user-plane peer endpoints can be added to the specified transmission resource group. When both the endpoint group mode and the endpoint mode are available for mapping all service flows of the same EPPATH to the transmission resource group, the endpoint mode is preferentially used for the mapping.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Mapping Type parameter in the EP2IPRSCGRP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Unit: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When the MT parameter in the EP2RSCGRP MO is set to ENDPOINT_GROUP, this parameter uses the value of the End Point Group ID parameter (the value range of this parameter is 0~65535) in the EPGROUP MO. In this case, all data flows in the EP group whose destination addresses are generated by USERPLANEPEER MO can be mapped to the specified transmission resource group.
  • When the MT parameter in the EP2RSCGRP MO is set to ENDPOINT_NODE, this parameter uses the value of the User Plane Peer ID parameter (the value range of this parameter is 0~65535 and 70000~79999) in the USERPLANEPEER MO. In this case, all data flows whose destination addresses are generated by the USERPLANEPEER MO can be mapped to the specified transmission resource group.

Example

To add mapping from End Point to Transmission Resource with the parameters as follows: End Point ID: 0, Slot No.: 7, Subboard Type: Base Board, Bearing Port Type: Ethernet Port, Transmission Resource Group ID: 0, run the following command:
ADD EP2RSCGRP: ENDPOINTID=0, SN=7, SBT=BASE_BOARD, PT=ETH, RSCGRPID=0;
