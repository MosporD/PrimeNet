Display BDU (DSP BDU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about a boost distribution unit (BDU).

Note

If the operational status of the PMU that manages the BDU is unavailable, the query fails.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the BDU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the BDU is located.

GUI Value Range: 7,17~18

Unit: None

Actual Value Range: 7,17~18

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the BDU is located.

GUI Value Range: 1~10

Unit: None

MML Default Value: None

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the BDU is located.

Subrack No.

Indicates the number of the subrack where the BDU is located.

Slot No.

Indicates the number of the slot where the BDU is located.

BDURunType

Indicates the type of the BDU in use. The value NULL indicates that the type of the BDU in use cannot be obtained.

Running Status

Indicates the running status of the BDU.

Output Voltage(0.1V)

Indicates the output voltage of the BDU. When the output voltage is displayed by port, for example, 0:570 and 1:570, the number before the colon (:) indicates the output port number, and the number after the colon indicates the output voltage (0.1 V) of the port.

Output Current(0.1A)

Indicates the output current of the BDU. When the value of BDURunType is BDU, the value NULL is displayed for this parameter.

Software Version

Indicates the software version of the board.

PCB Version

Indicates the PCB version of the BDU.

EPLD Version

Indicates the erasable programmable logic device (EPLD) version of the BDU.
