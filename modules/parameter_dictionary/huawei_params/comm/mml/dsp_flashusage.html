Display Flash Usage (DSP FLASHUSAGE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the flash usage.

Note

This command applies only to the MPT, BBP, GTMU, UBRI, MERC, UTRP, UCIU, UMDU, UCCU, RRU, RFU, CXU, AARU, and RHUB.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the board is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the board.

GUI Value Range: 0~1,4~5,60~254

Unit: None

Actual Value Range: 0~1,4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the board.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the flash usage information about the board in slot 7 of subrack 0 in cabinet 0:
DSP FLASHUSAGE: CN=0, SRN=0, SN=7;
The result is shown as follows:
+++    0        2010-06-01 18:05:05
O&M    #518
%%DSP FLASHUSAGE: CN=0, SRN=0, SN=7;%%
RETCODE = 0  Operation succeeded.

Display Flash Usage
-------------------
Flash Usage  =  47%
(Number of results = 1)


---    END

Output Description

Field Description

Flash Usage

Indicates the usage of the flash memory.
