Display Board Remain Time (DSP BRDREMAINTIME)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the remaining time of board.

Note

None.

Parameters

None.

Example

To query the remaining time of board, run the following command:
DSP BRDREMAINTIME:;
The result is as follows:
+++    0        2017-6-24 15:56:56
O&M    #6890
%%DSP BRDREMAINTIME:;%%
RETCODE = 0  Operation succeeded.

---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the board is located.

Subrack No.

Indicates the number of the subrack where the board is located.

Slot No.

Indicates the number of the slot where the board is located.

Config Type

Indicates the type of a board.

Restriction

Indicates the usage restriction status of a board. The value Unrestricted indicates that the board is normal. The value Restricted indicates that the board is blacklisted.

Remain Days

Indicates the remaining days of a board. The value NULL indicates that the board is normal.
