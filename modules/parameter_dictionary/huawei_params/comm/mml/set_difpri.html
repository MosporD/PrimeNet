Set Differentiated Service Priority (SET DIFPRI)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the priorities for differentiated services.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may interrupt ongoing services or disconnect OM channels.

Parameters

ID Name Description
PRIRULE Priority Rule

Meaning: Indicates the rule for prioritizing traffic. If this parameter is set to IPPRECEDENCE, the protocol stack of the earlier version is adopted and the base station converts TOSs to DSCPs and then prioritizes traffic.

GUI Value Range: IPPRECEDENCE(IP Precedence), DSCP(DSCP)

Unit: None

Actual Value Range: IPPRECEDENCE, DSCP

MML Default Value: DSCP(DSCP)

Recommended Value: DSCP(DSCP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
SIGPRI Signaling Priority

Meaning: Indicates the priority of signaling. The priority has a positive correlation with the value of this parameter.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 48

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller parameter value indicates a lower transmission priority of signaling data and affects the QoS.

Applicable Mode: G, U, L, N
OMHIGHPRI OM High Priority

Meaning: Indicates the priority of the high-level OM data. The priority has a positive correlation with the value of this parameter.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 46

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a DIFPRI MO, OMLOWPRI must be less than or equal to OMHIGHPRI.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller parameter value indicates a lower transmission priority of high-level OM service data and affects the QoS.

Applicable Mode: G, U, L, N
OMLOWPRI OM Low Priority

Meaning: Indicates the priority of the low-level OM data, such as the data to be uploaded or downloaded. The priority has a positive correlation with the value of this parameter. The low-level OM data includes the packets related to File Transfer Protocol (FTP).

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 18

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a DIFPRI MO, OMLOWPRI must be less than or equal to OMHIGHPRI.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: This parameter value must be different from the priorities of other services, so that low-level OM service data (such as upload and download data) is allocated the minimal bandwidth through scheduling.

Applicable Mode: G, U, L, N
IPCLKPRI IP Clock Priority

Meaning: Indicates the priority of the IP clock. If the IP clock that follows the PTP is used, this parameter is set to the DSCP of the PTP packets. If the IP clock that follows the Huawei proprietary protocol is used, this parameter is set to the DSCP of these packets that follow the Huawei proprietary protocol.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 46

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: A smaller value of this parameter indicates a lower priority of IPCLK packets, which affects their transmission quality.

Applicable Mode: G, U, L, N

Example

To set the mapping from traffic types to priorities with the parameters as follows: Priority Rule: DSCP, Signaling Priority: 48, OM High Priority: 48, OM Low Priority: 14, IP Clock Priority: 48, run the following command:
SET DIFPRI: PRIRULE=DSCP, SIGPRI=48, OMHIGHPRI=48, OMLOWPRI=14, IPCLKPRI=48;
