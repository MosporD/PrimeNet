Modify MLPPP Group Configuration (MOD MPGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configuration of the MLPPP group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]This operation may interrupt the services or OM channels carried on the MLPPP group. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

LOCALIP Local IP

Meaning: Indicates the local IP address. If this parameter is set to 0.0.0.0, this IP address needs to be negotiated. If this parameter is not set to 0.0.0.0, it must be set to a valid IP address of class A, B, or C but must not be the reserved address 0.x.x.x or 127.x.x.x.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB]LOCALIP in an MPGRP MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to the reserved IP addresses 0.x.x.x or 127.x.x.x but can be set to 0.0.0.0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the MPGRP MO, IPMASK cannot be all 0 if LOCALIP is not all 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In the MPGRP MO, IPMASK must be all 0 if LOCALIP is all 0.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an MPGRP MO, neither the network ID nor the host ID can be all 0 or 1 in the logical operation result of LOCALIP and IPMASK.
  • [Co-MPT, NodeB, eGBTS, eNodeB]In an MPGRP MO, LOCALIP must be different from PEERIP.

Example

To modify the configuration of the MLPPP group with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: BASE_BOARD, Group No.: 0, IP Header Compression: Enable, IPHC SubOption: Enable, run the following command:
MOD MPGRP: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, MPGRPN=0, IPHC=ENABLE, IPHCSUBOPT=ENABLE;
