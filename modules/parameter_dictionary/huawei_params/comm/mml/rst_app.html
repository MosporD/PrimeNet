Reset Application (RST APP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to restart an application based on a specified application ID. An application provides the operating environment for the functions of an NE of a certain RAT. When an application cannot work properly, the NE can reset the application to restore the functions provided by the application.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before resetting an application, you can run the DSP APP command to query the ID of the application.

  • If the main control board is UMPT, UMDU or GTMUc, executing the RST APP will reset the corresponding mode,This command cannot be executed when a main control board is being activated. Otherwise, it will reset the main control board.

  • If a forcible reset is performed when software is being downloaded, supplemented, or activated, board files may be damaged and the service recovery time may be affected.

  • [Co-MPT,eNodeB,gNodeB]If Board Resource Assignment Mode of the board is set to MODE 2, running the RST APP command will reset the board. Board Resource Assignment Mode can be queried by running the DSP BRDRESASSIGNMENT command.

  • [Co-MPT]For a multi-mode BS in CPRI-Sharing topology, if the local mode aggregates data, resetting the application of the local mode that aggregates data will interrupt the services of the peer mode.

  • [Co-MPT]During the reset process of an application, running the MML commands related to this application may fail.

  • [Co-MPT]A "System busy." message is displayed when an application is reset frequently. Do not run this command frequently.

  • [Co-MPT]The reset of an application may cause the related board to reset.

Parameters

ID Name Description
AID Application ID

Meaning: Indicates the application ID.

GUI Value Range: 1~255

Unit: None

Actual Value Range: 1~255

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
FOCRST Forced Reset Flag

Meaning: Indicates whether to perform a forcible reset.

GUI Value Range: NO(NO), YES(YES)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(NO)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To restart an application (AID = 33), run the following command:
RST APP: AID=33, FOCRST=NO;
