List Port Access Security Policy Configuration (LST PORTPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the security policy of a port.

Note

None.

Parameters

None.

Example

List Port Access Security Policy Configuration: 
LST PORTPOLICY:;
The result is shown as follows:
+++    0        2014-01-02 17:25:29
O&M    #1554
%%LST PORTPOLICY:;%%
RETCODE = 0  Operation succeeded.

List Port Access Security Policy Configuration
----------------------------------------------
USB Access Security Policy  =  DISABLE
(Number of results = 1)


---    END

Output Description

Field Description

USB Access Security Policy

Indicates the access security policy of a USB port. When the USB Access Security Policy parameter is set to DISABLE, all USB ports are disabled but the enable flag configuration of each port remains unchanged. When the parameter is set to ENABLE, the enable flag configuration of each port prevails.
