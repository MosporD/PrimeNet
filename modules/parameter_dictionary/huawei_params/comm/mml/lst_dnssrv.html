List DNS Server Configuration (LST DNSSRV)

Network Element: BTS3900, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configurations of DNS servers.

Note

None.

Parameters

None.

Example

To list the configurations of DNS servers, run the following command: 
LST DNSSRV:;
The result is shown as follows:
+++    0        2015-03-24 01:17:12
O&M    #805306805
%%LST DNSSRV:;%%
RETCODE = 0  Operation succeeded.

List DNS Server Configuration
-----------------------------
     DNS SERVER ID.  =  0
          VRF Index  =  0
         IP Version  =  IPv4
    DNS Client IPv4  =  192.168.2.24
    DNS Server IPv4  =  192.168.2.25
    DNS Client IPv6  =  NULL
    DNS Server IPv6  =  NULL
DNS Server Port No.  =  53
               DSCP  =  48
(Number of results = 1)


---    END

Output Description

Field Description

DNS SERVER ID.

Indicates the DNS server ID.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

IP Version

Indicates the IP protocol version.

DNS Client IPv4

Indicates the IPv4 address of the DNS client.

DNS Server IPv4

Indicates the IPv4 address for the DNS server.

DNS Client IPv6

Indicates the IPv6 address of the DNS client.

DNS Server IPv6

Indicates the IPv6 address for the DNS server.

DNS Server Port No.

Indicates the number of the port on the DNS server. The port number must be the same as that configured on the peer DNS server.

DSCP

Indicates the DSCP of the DNS packet.
