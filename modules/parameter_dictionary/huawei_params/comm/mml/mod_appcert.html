Modify Activated Device Certificate (MOD APPCERT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the device certificate used by a base station to negotiate with the peer end about security channels. When Application Type is set to SSL, this command can be used to specify whether an RRU needs to apply for an operator-issued device certificate.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Running this command can only change the device certificate in the CERTMK object to the activated device certificate.

  • Before running this command, ensure that the BS can set up a secure channel to a peer device by using this device certificate. Otherwise, the secure channel fails to be set up or the existing channel becomes disconnected.

  • When you run this command to modify the configuration, the certificate file name must be the same as the device certificate file name in the CERTMK MO, including the file name extension. You can run the DSP CERTMK command to query the existing certificate files and their names.

  • When this command is used to modify the device certificate whose application type is SSL, the Web LMT may be disconnected.

  • When a device certificate is being updated or a device certificate is being tested, this command cannot be executed to modify the device certificate. Otherwise, the device certificate may not be normally updated again or the certificate test fails.

  • Before running this command to modify configurations, run the TST APPCERT command to test whether the certificate to be used can work for the normal IKE or SSL connection and ensure that the device certificate can be successfully used for establishing the secure channel between the network element and the peer end. Otherwise, the secure channel fails to be established or is interrupted. It is recommended that the automatic configuration rollback function be enabled before this command is executed. For details, see MML online help for CFM CB.

Parameters

ID Name Description
APPTYPE Application Type

Meaning: Indicates the application type of activated device certificate. The application type of a device certificate can be IKE, SSL, or DTLS. When APPTYPE is set to IKE and CERTSOURCE in the IKEPEER object is set to Appcert, the device certificate being used during IKE negotiation is the certificate configured in the APPCERT object. When APPTYPE is set to SSL, the device certificate being used is the certificate used during SSL connection, 802.1x-based, or inter-BBU interconnection authentication. When APPTYPE is set to DTLS, the device certificate being used is the certificate used during DTLS connection authentication.

GUI Value Range: IKE(IKE), SSL(SSL), DTLS(DTLS)

Unit: None

Actual Value Range: IKE, SSL, DTLS

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]On a BS, there is only one activated device certificate for each application type.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
APPCERT Certificate File Name

Meaning: Indicates the file name of an activated device certificate. The file name cannot include any of the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks ("), left angle bracket (<), right angle bracket (>), and bar (|).

GUI Value Range: 1~64 characters

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]It is recommended that the value of APPCERT in an APPCERT MO be ASCII characters. A certificate file name can neither contain only space characters (including space and tab) nor contain the following characters: backslash (\), slash (/), colon (:), asterisk (*), question mark (?), double quotation marks (""), left angle bracket (<), right angle bracket (>), and bar (|).

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
RRUCERTREQSW RRU Certificate Request Switch

Meaning: Indicates whether an RRU needs to apply for an operator-issued device certificate. When an operator-issued device certificate is used for SSL application type and this switch is turned on, the RRU with the eCPRI port applies for a certificate to the CA.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: OFF(Off)

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the APPCERT MO, this parameter is valid only when APPTYPE is set to SSL.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes to APPCERT objects are made. When this parameter is set to YES, forcible changes to APPCERT objects are made. When this parameter is set to NO, forcible changes to the APPCERT objects that affect associated objects are not allowed. When forcible changes are not allowed, only the local IP address is checked.

The associated objects include CA, CERTREQ, and IKEPEER. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

Pay attention to the following when setting this parameter:

1. The system checks whether forcible changes to APPCERT objects affect associated objects based on the object configuration data instead of the actual object running status.

2. If an NE is configured with an SRCIPRT, SRCIPROUTE4, PPPLNK, or MPGRP object, the system will not check whether forcible changes to APPCERT objects affect associated objects.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify a device certificate file with the parameters as follows: Application Type: IKE, Certificate File Name: eNodeBCert.pem, run the following command:
MOD APPCERT: APPTYPE=IKE, APPCERT="eNodeBCert.pem";
