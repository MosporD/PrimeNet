Set SSL Authentication Mode (SET SSLAUTHMODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the authentication mode for the NE to be used during the Secure Sockets Layer (SSL) handshake.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • After this command is executed, the NE uses the new authentication mode during the next SSL connection. This operation does not affect existing connections.

  • Before setting the Authentication Mode parameter to PEER, ensure that the required certificates have been obtained and the SSL connection certificate test succeeds. Otherwise, might interrupt the connection with the client and the connection cannot be restored remotely.

Parameters

ID Name Description
AUTHMODE Authentication Mode

Meaning: Indicates the authentication mode of the SSL connection. If Authentication Mode is set to NONE(Verify None), it indicates that the NE does not need to verify the certificate on the MAE or LMT. If Authentication Mode is set to PEER(Verify Peer Certificate), the NE must verify the certificate of the MAE or LMT during SSL connection setup. If the certificate verification fails, the SSL connection cannot be set up. When the authentication mode is set to NONE(Verify None), NEs will not verify the peer certificate, so that unauthorized clients are more likely to access NEs. Set this parameter to a proper value.

GUI Value Range: NONE(Verify None), PEER(Verify Peer Certificate)

Unit: None

Actual Value Range: NONE, PEER

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the authentication mode to NONE, run the following command:
SET SSLAUTHMODE: AUTHMODE=NONE;
