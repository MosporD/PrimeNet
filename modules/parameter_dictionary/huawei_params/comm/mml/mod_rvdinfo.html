Modify RVD Info (MOD RVDINFO)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of vertical beamwidth or Software-defined Antenna Mode for the remote vendor-defined antenna line device (RVD).

Note

  • Before configuring the vertical beamwidth of an RVD, ensure that the RVD has been calibrated by using the CLB ALD command.

  • The range of the supported vertical beamwidth varies according to the RVD model. Before configuring the vertical beamwidth, run the DSP RVDSUBUNIT command to check the vertical beamwidth supported by the RVD.

  • After the vertical beamwidth is reconfigured, the system automatically changes the vertical beamwidth, which affects the network coverage. Changing the vertical beamwidth takes a maximum of 4 minutes. If changing the vertical beamwidth fails, the system reports ALM-26757 RET Antenna Running Data and Configuration Mismatch.

  • Configuring the vertical beamwidth of an RVD subunit takes a maximum of 4 minutes.

  • If an unavailable RPCU exists on the base station, the configured data cannot take effect and ALM-26757 RET Antenna Running Data and Configuration Mismatch is reported. This alarm is automatically cleared when all RPCUs are running properly.

Example

To modify the RVD Info with the parameters as follows: Operate Mode: DEVICENO, Device No.: 0, Vertical BeamWidth: 100, run the following command:
MOD RVDINFO: OPMODE=DEVICENO, DEVICENO=0, VBEAMWIDTH=100;
