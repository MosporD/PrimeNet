Restart PMU (RST PMUPWR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to shut down the DC output of the power system and then resume the DC output after a specified period of time.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The APM100, APM200, and SC48200 power system do not support this function.

  • After this command is executed, -48 V DC outputs of PSUs managed by the PMU are cut off. In addition, power supplies to storage batteries and all devices supported by the power system are also cut off. Devices supported by the power system include the PMU in the power system, RRUs or RFUs, transmission equipment, and the BBU. After a specified period of time, the power system is powered back on and restarted. If the mains supply is unavailable within a specified period, the devices powered by the power system will be powered on again only after the mains supply recovers.

  • This command is not recommended if the BBU is powered by the PMU. Otherwise, the BBU will be powered off immediately, leading to system failures.

Example

To shut down the DC output of the power system and then resume the DC output after a specified period of time, Cabinet No.: 0, Subrack No.: 7, run the following command:
RST PMUPWR: CN=0, SRN=7;
