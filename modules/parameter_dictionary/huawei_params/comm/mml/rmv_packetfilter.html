Remove Packet Filter (RMV PACKETFILTER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a packet filtering object.

Note

  • When a packet filtering object is removed, the ACL rules automatically created by the packet filtering object are removed. The corresponding ACL can be removed only when all these ACL rules are automatically removed.

  • When a packet filtering object is removed, if the ACL on which the packet filtering object depends does not have a bearer object (packet filtering, IPsec policy group binding, or IPv6 security policy group binding) on the board where the packet filtering object has taken effect, the ACL will not take effect on the board.

  • [NodeB]When a packet filtering object is removed from a UTRP (subboard type: UEOC/UQEC) by running this command, and the ACL is referenced only by this packet filtering object, the effective ACL rules in this ACL will automatically become ineffective.

Example

To remove a PacketFilter MO with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Port Type: ETH, Port No.: 0, run the following command: 
RMV PACKETFILTER: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, PT=ETH, PN=0;
