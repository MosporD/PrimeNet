Set E1/T1 BER Threshold (SET E1T1BER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to set the high BER threshold for an E1/T1 port. The E1/T1 BER alarm is determined based on the value of bit errors for the Frame Alignment Signal (FAS) and Cyclic Redundancy Check (CRC) accumulated within 15 minutes. If the value exceeds the threshold, the alarm is reported. If the value falls to a level 20% lower than the threshold, the alarm is cleared.

Note

[Co-MPT,NodeB,eNodeB]The BER thresholds for different E1/T1 ports in a BS are the same.

Parameters

ID Name Description
BTL E1/T1 BER Threshold Level

Meaning: Indicates the BER threshold.

GUI Value Range: 1E-3(1E-3), 1E-4(1E-4), 1E-5(1E-5), 1E-6(1E-6)

Unit: None

Actual Value Range: 1E-3, 1E-4, 1E-5, 1E-6

MML Default Value: None

Recommended Value: 1E-5(1E-5)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To set E1/T1 BER threshold to 1E-4, run the following command:
SET E1T1BER: BTL=1E-4;
