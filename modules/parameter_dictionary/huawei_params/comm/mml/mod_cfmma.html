Modify CFM MA (MOD CFMMA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a CFM Maintenance Association (MA).

Note

  • If a CFM MA is not bound to any VLAN, the modification of VLAN priority will not take effect.

  • The CCM TX Interval parameter cannot be set to 10 ms for a GTMUb board. If this parameter is set to 10 ms, the parameter value that actually takes effect is 100 ms.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the MA belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MA.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMA MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MANAME MA Name

Meaning: Indicates the name of the MA.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MANAME value of a CFM MA.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MANAME in a CFMMA MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMA MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
VLANPRI VLAN Priority

Meaning: Indicates the priority of the VLAN with which the MA is associated.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
CCMINTL CCM TX Interval

Meaning: Indicates the interval at which the CFM MA transmits continuity check messages (CCMs).

GUI Value Range: 10ms(10ms), 100ms(100ms), 1s(1s), 10s(10s), 1min(1min), 10min(10min)

Unit: None

Actual Value Range: 10ms, 100ms, 1s, 10s, 1min, 10min

MML Default Value: None

Recommended Value: 1s(1s)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

Example 1: To modify the CFM MA with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, VLAN Priority: 6, run the following command: 
MOD CFMMA: MDNAME="CHINA", MANAME="SHANGHAI", VLANPRI=6;
Example 2: To modify the CFM MA with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, VLAN Priority: 6, CCM TX Interval: 10ms, run the following command: 
MOD CFMMA: MDNAME="CHINA", MANAME="SHANGHAI", VLANPRI=6, CCMINTL=10ms;
