Modify UTRP (MOD UTRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the subboard type of a universal transmission processing unit (UTRP).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The BLADEBBU does not support this command.

  • The sub-board type must comply with the hardware plan. Otherwise, the ongoing services of the base station or the remote maintenance channel may be interrupted.

  • [Co-MPT,NodeB,eGBTS]The relationships between the subboard types and ports are as follows: UAEC supports eight ATM over E1/T1 ports; UIEC supports eight IP over E1/T1 ports; UUAS supports one unchannelized STM-1/OC-3 port; UQEC supports four FE/GE electrical ports; UEOC supports two FE/GE optical ports; UTRPc supports two optical ports and four electrical ports.

Parameters

ID Name Description

Meaning: Indicates the cabinet number of the extension transmission board.

Recommended Value: None

Parameter Relationship: None

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the extension transmission board.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TYPE of the SUBRACK where the TRP is located must be BBU3900, BBU3900-1U, BBU3910, or DCU3911.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the extension transmission board.

GUI Value Range: 0~6

Unit: None

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SUBTYPE SubBoard Type

Meaning: Indicates the type of the subboard.

GUI Value Range: UAEC, UIEC, UUAS, UQEC, UEOC, UIEB, UTRPc

Unit: None

Actual Value Range: UAEC, UIEC, UUAS, UQEC, UEOC, UIEB, UTRPc

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the TRP MO, the SUBTYPE must be set to one of the following values: 1. UAEC; 2. UIEC; 3. UUAS; 4. UQEC; 5. UEOC; 6. UTRPc; 7. UIEB.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the SUBRACK MO where the TRP MO is located is set to BBU3910, SUBTYPE in the TRP MO must be set to UAEC or UTRPc.

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To modify the configuration of the UTRP as follows: Cabinet NO.: 0, Subrack No.: 0, Slot No.: 3, Sub-board type: "UTRPc", run the following command:
MOD UTRP: CN=0, SRN=0, SN=3, SUBTYPE=UTRPc;
