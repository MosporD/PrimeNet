Remove Ethernet Trunk Member (RMV ETHTRKLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a member port from an Ethernet trunk.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • You must remove the secondary port before the primary port when removing a member port from an Ethernet trunk.

  • This operation may interrupt the services or OM channels carried on this port. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Meaning: Indicates the number of the cabinet housing the board where the member port of an Ethernet trunk is located.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the Ethernet Port ID parameter in the ETHTRUNKLNK MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

Example

To remove an Ethernet trunk member port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 6, Subboard Type: BASE_BOARD, Trunk No.: 0, Port No.: 0, run the following command:
RMV ETHTRKLNK: CN=0, SRN=0, SN=6, SBT=BASE_BOARD, TN=0, PN=0;
