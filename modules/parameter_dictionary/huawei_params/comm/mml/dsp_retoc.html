Display RRU Cabinet Top (DSP RETOC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the connection status of the cabinet top of the RRU.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU is located.

GUI Value Range: 0~15

Unit: None

Actual Value Range: 0~15

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]In the RRU MO, when RFCONNTYPE is set to INTRA_SYS_INTERCONN, the combination of CN, SRN, SN cannot be the same as the combination of RFCONNCN2, RFCONNSRN2, RFCONNSN2.
  • [Co-MPT, NodeB, eNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, AAMU, CXU.
  • [eGBTS]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, AAMU, CXU.
  • [gNodeB]Each RRU MO must have a unique combination of CN, SRN, and SN among all MOs as follows: RRU, RHUB, CXU.

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RRU is located.

Subrack No.

Indicates the number of the subrack where the RRU is located.

Slot No.

Indicates the number of the slot where the RRU is located.

Cabinet Top ID

Indicates the ID of the cabinet top of the RRU.

Cabinet Top Connection Status

Indicates the connection status of the cabinet top of the RRU. The value Normal indicates that the connection between the external feeder of the RF module and the antenna is normal. The value Abnormal indicates that the connection between the external feeder of the RF module and the antenna is abnormal. The possible causes are as follows: 1. The RF module does not detect the antenna connection because the feeder is not properly installed to the antenna or due to other causes. 2. The antenna does not support connection status detection. 3. There is a DC blocking device between the RF module and the antenna. The value Unknown indicates that the RF module does not support this function or the RF module does not involve external antenna detection.
