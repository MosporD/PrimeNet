Deactivate VCL Performance Monitoring (DEA VCLPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to deactivate the VCL PM function.

Note

[NodeB]This command is used only for links whose VCL PM functions are already activated, including the IPoA PVC, SAAL link, and AAL2 path.

Example

To deactivate VCL PM with the parameters as follows: Type of the VCL: SAALLINK, SAAL Link No.: 0, Deactivation confirmed: DISABLE, run the following command:
DEA VCLPM: LNKT=SAALLINK, SAALNO=0, CONF=DISABLE;
