Set STM-1 Loopback (SET STM1LOP)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to set the STM-1 loopback mode.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]After a new loopback mode is set for an optical port, the previously configured loopback mode becomes invalid.

  • [Co-MPT,NodeB]You can run the DSP STM1 command to list the configured loopback mode of an optical port.

  • [Co-MPT,NodeB]After the board is reset, the loop mode (LM) is automatically switched to NOLOOP.

Example

To set the STM1 loopback with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, Port No.: 0, Loop Mode: REMOTE, run the following command:
SET STM1LOP: CN=0, SRN=0, SN=0, SBT=UNCHANNELLED_COVERBOARD, STM1N=0, LM=REMOTE;
