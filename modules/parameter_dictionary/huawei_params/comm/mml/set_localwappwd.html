Set LOCALWAP Password (SET LOCALWAPPWD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to configure the password of the local WAP.

Note

  • The New Password must be the same with the Confirm Password.

  • This command applies only to MAE.

Parameters

ID Name Description
NEW New Password

Meaning: Indicates the new password of the LOCALWAP(Local Wireless Access Point). Passwords are case sensitive. The minimum and maximum lengths of a password are 8 characters and 64 characters, respectively. Passwords must meet the requirements specified by the Password Minimal Length, Password Complicacy, and New Password Repeat Limit parameters in the SET PWDPOLICY command.

GUI Value Range: 8~64 characters

Unit: None

Actual Value Range: 8~64

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R
CFM Confirm Password

Meaning: Indicates the confirmed password of the LOCALWAP(Local Wireless Access Point), which must be consistent with the new password. Passwords are case sensitive. The minimum and maximum lengths of a password are 8 characters and 64 characters, respectively. Passwords must meet the requirements specified by the Password Minimal Length, Password Complicacy, and New Password Repeat Limit parameters in the SET PWDPOLICY command.

GUI Value Range: 8~64 characters

Unit: None

Actual Value Range: 8~64

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R

Example

To set the WLAN AP Password with the parameters as follows: New Password: "hwbs@123", Confirm Password: "hwbs@123", run the following command:
SET LOCALWAPPWD: NEW="********", CFM="********";
