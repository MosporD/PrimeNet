Set NE Equipment Configuration (SET EQUIPMENT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the equipment configuration.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • If the OMCH setup enhancement switch is turned on, OMCH setup is delayed after an abnormal power-off reset which is caused by remote command execution.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The MDUC does not support the TDL-IR protocol.

  • [Co-MPT,eNodeB,gNodeB]Changes in the protocol type or Open DU Interface (ODI) ID take effect only after the NE is reset. If the NE is not reset within 10 minutes after these parameters are modified, ALM-26245 Configuration Data Inconsistency is reported.

  • [NodeB]The change of ODI(Open DU Interface) ID takes effect only after the NE is reset. If the NE is not reset within 10 minutes after these parameters are modified, ALM-26245 Configuration Data Inconsistency is reported.

HWFLTSELFHEALSW Hardware Fault Self-healing Switch

Meaning: Indicates whether to enable the hardware fault self-healing function. When a hardware fault that may affect services or functions is detected, the base station is authorized to perform self-healing actions at different levels to quickly rectify the fault. This helps reduce the fault duration and maintenance workload caused by manual intervention and shortens the fault impact duration. This parameter does not apply to self-healing operations for hardware faults that inevitably affect services or functions. For such hardware faults, the base station directly performs self-healing. When the LEVEL1 option is selected, the base station is allowed to reset the main control board when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL2 option is selected, the base station is allowed to reset the baseband processing board when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL3 option is selected, the base station is allowed to reset the RF unit when detecting a hardware fault that may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL4 option is selected, the base station is allowed to re-load the application or certain components when detecting a hardware fault that can may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed. When the LEVEL5 option is selected, the base station is allowed to perform self-healing that requires cooperation of the peer end when detecting a hardware fault that can may be rectified by self-healing and may affect services or functions. When this option is deselected, this operation is not allowed.

Unit: None

DCALMSW RF DC Power Off Alarm Enhanced Detect Switch

Meaning: Indicates whether to enable the enhanced DC power failure detection function for RF modules. When this switch is turned on, the system checks the power supply of RF modules based on the power failure characteristics. If the system detects that the RF modules experience power failure, the system reports ALM-26564 Unit DC Input Power Failure to notify the user to preferentially perform troubleshooting for the power failure. It is recommended that this function be enabled when the power system is unstable, the power supply cannot be directly estimated (for example, dry-contact ports are not configured), and RF modules frequently experience power failure. Since the system checks the power supply of RF modules based on the power failure characteristics, false alarms may be generated. If the percentage of false alarms is high, turn off this switch.
