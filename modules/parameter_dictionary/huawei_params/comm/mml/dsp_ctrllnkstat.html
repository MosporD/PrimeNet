Display Control and Clock Signal Link Quality Statistics Between BBUs (DSP CTRLLNKSTAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the statistics of control and clock signal links between BBUs. The statistics mainly include the number of received packets, number of error packets, total packet receiving time, and the loss of signal (LOS) duration, reflecting the link transmission quality. If the port supports MACsec, the MACsec negotiation statistics are displayed. For the UCIU, the rates of error packets on ports 0 to 4 and port 8 are displayed. For the UMPT, the rate of error packets on port 8 is displayed. For the UMDU, the rates of error packets on ports 6 and 7 are displayed.

Note

  • If two BBU subracks of different modes are cascaded, the local node refers to the local BBU and this command can only be used to query the control link of the local BBU. If two BBU subracks of the same mode are cascaded, the local node can be either the local BBU or the secondary BBU. That is, this command can be used to query the control link of either the local BBU or the secondary BBU.

  • The UMDU supports measurement of only the number of received packets, number of error packets, error packet rate, and measurement duration on a link. It does not support measurement of the port rate, LOS duration, and LOS rate of the local node, and they are displayed as NULL in the result.

  • When UMPTe boards are connected to UMPTe or UMPTg/UMPTga boards, or when UMPTg/UMPTga boards are connected to UMPTe or UMPTg/UMPTga boards, pay attention only to the number of received packets, number of error packets, and the rate of error packets. The LOS duration and the ratio of LOS duration may be measured during negotiation and cannot reflect the link transmission quality.

  • This command applies only if it is executed in the supported RAT and interconnection boards are configured.

  • The system updates the statistics every hour.

Output Description

Field Description

Local Cabinet No.

Indicates the cabinet number of the local node at one end of the control link.

Local Subrack No.

Indicates the subrack number of the local node at one end of the control link.

Local Slot No.

Indicates the slot number of the local node at one end of the control link.

Port No.

Indicates the number of the port whose control link status is queried. When this parameter is set to a value within the range from 0 to 4, this parameter indicates the ports M0 to M4 on the UCIU. When this parameter is set to a value within the range from 6 to 7, this parameter indicates the ports HEI0 to HEI1 on the UMDU. When this parameter is set to 8, this parameter indicates the S port on the UCIU or the CI port on the UMPT.

Local Port Rate(Gbit/s)

Indicates the port rate of the local node. NULL indicates that the link is disconnected over the port.

Measurement Start Time

Indicates the start time of the measurement.

Total Error Package Number(packet)

Indicates the total number of error packets within the measurement periods.

Total Receive Package Number(packet)

Indicates the total number of received packets within the measurement periods.

Total LOS Time(s)

Indicates the total Loss Of Signal (LOS) duration within the measurement periods.

Total Measurement Time(s)

Indicates the total length of measurement periods.

1 Hour LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one hour. The LOS duration is measured within the measurement periods in the latest one hour.

1 Hour LOS Time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one hour.

1 Hour Error Package Rate(per mill)

Indicates the ratio of the number of error packets to that of received packets within the measurement periods in the latest one hour.

1 Hour Error Package Number(packet)

Indicates the number of error packets within the measurement periods in the latest one hour.

1 Day LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one day. The LOS duration is measured within the measurement periods in the latest one day.

1 Day LOS time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one day.

1 Day Error Package Rate(per mill)

Indicates the ratio of the number of error packets to that of received packets within the measurement periods in the latest one day.

1 Day Error Package Number(packet)

Indicates the number of error packets within the measurement periods in the latest one day.

1 Week LOS Rate(per mill)

Indicates the ratio of the Loss Of Signal (LOS) duration to one week. The LOS duration is measured within the measurement periods in the latest one week. Value NULL is invalid, indicating that the total measurement period is less than one week.

1 Week LOS time(s)

Indicates the Loss Of Signal (LOS) duration measured within the measurement periods in the latest one week. Value NULL is invalid, indicating that the total measurement period is less than one week.

1 Week Error Package Rate(per mill)

Indicates the ratio of the number of error packets to that of received packets within the measurement periods in the latest one week. Value NULL is invalid, indicating that the total measurement period is less than one week.

1 Week Error Package Number(packet)

Indicates the number of error packets within the measurement periods in the latest one week. Value NULL is invalid, indicating that the total measurement period is less than one week.

MACSec Negotiation State

Indicates the states of MACSec (MAC Security) negotiations. The values of this parameter include Succeeded, Failed, and None.

MACSec Negotiation Failure Phase

Indicates the phase in which the latest failed MACSec negotiation occurs. The values of this parameter include Identity Authentication, MKA Negotiation, and NULL. MKA is short for MACsec key agreement protocol. The value NULL indicates that a negotiation succeeds or no negotiation is performed.

MACSec Negotiation Failure Times

Indicates the number of failed MACSec (MAC Security) negotiations. The number is counted from the time a link becomes normal. The number falls to zero after the link becomes abnormal but is counted again after the link becomes normal.

MACSec Negotiation Success Times

Indicates the number of successful MACSec (MAC Security) negotiations. The number is counted from the time a link becomes normal. The number falls to zero after the link becomes abnormal but is counted again after the link becomes normal.
