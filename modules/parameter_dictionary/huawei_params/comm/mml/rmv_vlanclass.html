Remove Mapping from Traffic Type to VLAN (RMV VLANCLASS)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a VLAN priority mapping from the VLAN group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • The execution of this command interrupts the services relying on this VLAN ID.

  • This operation may interrupt the services or OM channels that rely on this VLAN ID. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Parameters

ID Name Description
VLANGROUPNO VLAN Group No.

Meaning: Indicates the VLAN group that the added VLAN mapping belongs to. Multiple VLAN groups are used in the scenario in which telecom operators share transport resources and use different VLAN policies.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: 0

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
TRAFFIC Traffic Type

Meaning: Indicates the traffic type. Traffic of different types is transmitted through different VLANs. OTHER data is the data except the user data, signaling, high-priority OM data, and low-priority OM data. OTHER data includes the data of the IEEE 1588 V2 clock, clock over IP, and Address Resolution Protocol (ARP) services. OM_HIGH data includes the data of the NTP, switchover between remote maintenance channels, and TCP services.

GUI Value Range: USERDATA(User Data), SIG(Signaling Data), OM_HIGH(High Level Maintenance Data), OM_LOW(Low Level Maintenance Data), OTHER(Other Data)

Unit: None

Actual Value Range: USERDATA, SIG, OM_HIGH, OM_LOW, OTHER

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
SRVPRIO User Data Service Priority

Meaning: Indicates the DSCP priority of user data.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: It is recommended that the value of this parameter be consistent with the implementation of the differentiated service.

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
FORCEEXECUTE Support Forcible Execution

Meaning: Indicates whether forcible changes of VLANCLASS configurations are made. When this parameter is set to NO(No), forcible changes of VLANCLASS configurations affecting upper-layer objects are not allowed. When this parameter is set to YES(Yes), forcible changes of VLANCLASS configurations are made. This parameter is invalid when a WMPT, LMPT, GTMUb, or GTMUc serves as the main control board.

GUI Value Range: NO(No), YES(Yes)

Unit: None

Actual Value Range: NO, YES

MML Default Value: NO(No)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To remove the VLAN group mapping with the parameters as follows: VLAN Group No.: 0, Traffic Type: USERDATA, User Data Service Priority: 46, run the following command:
RMV VLANCLASS: VLANGROUPNO=0, TRAFFIC=USERDATA, SRVPRIO=46;
