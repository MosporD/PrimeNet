Display IP PM Session Status (DSP IPPMSESSION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of an IP PM session. The status information includes parameters such as the transmission line delay, jitter, and packet loss rate.

Note

  • The system measures the high-precision round trip time only when the negotiated IP PM protocol runs V15 or V14.

  • The system measures the one-way delay only when the negotiated IP PM protocol runs V14.

  • If the IP PM protocol version is V15, the system does not measure the uplink jitter or downlink jitter.

Parameters

ID Name Description
IPPMSN Session ID

Meaning: Indicates the ID of an IP PM session of an NE. An IP PM session with an ID ranging from 0 to 65535 is configured by users. An IP PM session with an ID ranging from 70000 to 79999 is configured by the system.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of Session ID in a manually configured IPPMSESSION MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Output Description

Field Description

Session ID

Indicates the ID of an IP PM session of an NE. An IP PM session with an ID ranging from 0 to 65535 is configured by users. An IP PM session with an ID ranging from 70000 to 79999 is configured by the system.

IP PM Type

Indicates the type of IP PM session. A triplet consists of the local IP address, peer IP address, and protocol type; a quad bit consists of the local IP address, peer IP address, protocol type, and DSCP. The WMPT and UTRP do not support the triplets configuration mode.

Bind IP Path

Indicates whether to bind the IP PM session to an IP path. If the IP PM session is bound to an IP path, the IP PM session uses the local and peer IP addresses of the IP path in data transmission. In addition, if TXBWASW or RXBWASW is set to ON and TCSW is set to ENABLE in the algorithm for the transmission resource group associated with the IP path, the system dynamically adjusts the TX or RX bandwidth of the transmission resource group based on the IP PM detection result. The IP PM dynamic bandwidth adjustment function is available for LTE but unavailable for UMTS. The function of binding the IP PM session to an IP path is unavailable for NR.

IP Path ID

Indicates the ID of the IP path to which an IP PM session is bound.

Local IP

Indicates the local IP address of an IP PM session. This IP address must be configured on an Ethernet port, an Ethernet trunk, a PPP link, an MP link or a loopback port, and cannot be set to 0.0.0.0.

Peer IP

Indicates the peer IP address of an IP PM session. This IP address must be a valid IP address of Class A, B, or C and different from any existing IP address of the local end. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

DSCP

Indicates the differentiated services code point (DSCP) of an IP PM session.

Activate Direction

Indicates that the activation direction of an IP PM session. For this parameter to be valid, the peer must also support the IP PM session. If this parameter is set to UP, the IP PM session initiated by the BS is activated. If this parameter is set to BIDIR, the IP PM sessions initiated by BS and the peer are activated. The activation direction is specified by the DIR parameter. The WMPT and UTRP do not support bidirectional activation. The DIR parameter determines the activation direction.

Associate with UP Path Packet Loss Rate Alarm

Indicates whether an IP PM session is associated with ALM-25959 User Plane Path Excessive Packet Loss Rate. If this parameter is set to YES and the local and peer IP addresses of an IP PM session are the local and peer IP addresses of a user-plane link in the endpoint model, the packet loss rate measured during the IP PM session is used to determine whether the packet loss rate for the user-plane link exceeds the threshold and an alarm needs to be reported.

High Precision Round Trip Time(microsecond)

Indicates the high-precision round-trip delay calculated by an IP PM session detection. The high-precision round-trip delay is the time consumed to transmit IP PM detection packets to and fro between the local and peer ends. This parameter is valid only when Activate State(UP) is set to IP PM UP and the protocol version for an IP PM session supports high-precision delay detection.

One Way Delay(microsecond)

Indicates the one-way delay calculated by an IP PM session detection. The one-way delay is the time consumed to transmit IP PM detection packets from the local end to the peer end. This parameter is valid only when Active State(UP) is set to IP PM UP and the protocol version for an IP PM session supports one-way delay detection. This parameter is valid only when the time is synchronized between both ends of an IP PM session.

Round Trip Time(ms)

Indicates the round-trip delay calculated by an IP PM session detection. The round-trip delay is the time consumed to transmit IP PM detection packets to and fro between the local and peer ends. This parameter is valid only when Activate State(UP) is set to IP PM UP.

RX Jitter(ms)

Indicates the DL jitter calculated by an IP PM session detection. This parameter is valid only when Activate State(Down) is set to IP PM UP.

TX Jitter(ms)

Indicates the UL jitter calculated by an IP PM session detection. This parameter is valid only when Activate State(UP) is set to IP PM UP.

RX Loss Rate(per mill)

Indicates the DL packet loss rate calculated by an IP PM session detection. This parameter is valid only when Activate State(Down) is set to IP PM UP.

TX Loss Rate(per mill)

Indicates the UL packet loss rate calculated by an IP PM session detection. This parameter is valid only when Activate State(UP) is set to IP PM UP.

Activate State(Up)

Indicates the UL activation status of an IP PM session. The UL activation status of an IP PM session can be IDLE, ACTING, IP PM UP, DEACTING, or UNKNOWN.

DSCP Change Flag(Up)

Indicates whether the DSCP value of an UL IP PM session changes.

DSCP Initial Value(Up)

Indicates the initial DSCP value of an UL IP PM session.

DSCP Changed Value(Up)

Indicates the modified DSCP value of an UL IP PM session.

DSCP Changed Date And Time(Up)

Indicates the time when the DSCP value of an UL IP PM session changes.

Activate State(Down)

Indicates the DL activation status of an IP PM session. The DL activation status of an IP PM session can be IDLE, ACTING, IP PM UP, DEACTING, or UNKNOWN.

DSCP Change Flag(Down)

Indicates whether the DSCP value of a DL IP PM session changes.

DSCP Initial Value(Down)

Indicates the initial DSCP value of a DL IP PM session.

DSCP Changed Value(Down)

Indicates the modified DSCP value of a DL IP PM session.

DSCP Changed Date And Time(Down)

Indicates the time when the DSCP value of a DL IP PM session changes.

IP PM Protocol Version

Indicates the version of the negotiated data, when the status of IP PM is UP.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).
