Modify TWAMP Responder Configuration (MOD TWAMPRESPONDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a TWAMP responder.

Note

  • TWAMP uses intrusive measurement. A TWAMP sender actively sends packets to perform the intrusive measurement, which consumes the bandwidth.

  • The local TCP port number used by a TWAMP responder in the full architecture cannot be set to 4443 or any value ranging from 6000 to 6007.

  • Modifying the configuration of a TWAMP responder in the full architecture may cause re-negotiation of the corresponding TWAMP client and all the TWAMP senders under this client.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The IPv4 address used by a TWAMP responder must be an IPv4 address configured using the ADD DEVIP, ADD IPADDR4, ADD PPPLNK, or ADD MPGRP command and cannot be an auto-negotiated IPv4 address or an IPv4 address of an OMCH (except that OMIPv4 and DEVIP/IPADDR4 share an IP address).

  • [eNodeB,gNodeB]The IPv6 address used by a TWAMP responder must be an IPv6 address configured using the ADD IPADDR6 command and cannot be an auto-negotiated IPv6 address or an IPv6 address of an OMCH (except that OMIPv6 and IPADDR6 share an IPv6 address).

  • [gNodeB]The IPv4 address used by a TWAMP responder must be an IPv4 address configured using the ADD DEVIP or ADD IPADDR4 command and cannot be an auto-negotiated IPv4 address or an IPv4 address of an OMCH (except that OMIPv4 and DEVIP/IPADDR4 share an IP address).

Example

To modify the configuration of a TWAMP Responder with the parameters as follows: Responder Index: 0, IP Version: IPv4, Local IP Address: 172.16.81.207, run the following command: 
MOD TWAMPRESPONDER: RESPONDERID=0, IPVERSION=IPv4, LOCALIP="172.16.81.207";
