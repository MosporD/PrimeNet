Add SCTP Link (ADD SCTPLNK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to add an SCTP link.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]In the same routing domain, each IPv4 SCTP link must have a unique combination of the following parameters: the first or second local IP address (not set to 0.0.0.0), the first or second peer IP address (not set to 0.0.0.0), local SCTP port number, and peer SCTP port number.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In IPv4 scenarios, before running this command, ensure that a route to the peer IP address has been added by running the ADD IPRT, or ADD IPROUTE4, or ADD SRCIPRT, or ADD SRCIPROUTE4 command.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The first and second local IP addresses of an SCTP link must be configured in the same subrack. If they are configured on different boards, the value of Subboard Type must be BASE_BOARD, and the port type must be ETH, ETHTRK, or LOOPINT.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the local and peer IP addresses of an SCTP link are set to valid IP addresses and the two local IP addresses are on the same board, the base station does not make cross-link attempts. That is, the base station does not support the SCTP link between the first local IP address and the second peer IP address or the link between the second local IP address and the first peer IP address. The base station makes cross-link attempts only when the two local IP addresses are valid and are configured on different boards. This requires that the peer device should support this multi-homing mode.

  • [Co-MPT,NodeB,eGBTS,eNodeB]An SCTP packet can be divided into at most two fragments. If MTU is set to a small value, packet reassembly fails. Therefore, it is recommended that MTU be set to a value greater than 600.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In the same routing domain, PEERIP for a remote maintenance channel must be different from LOCIP and SECLOCIP for an IPv4 SCTP link.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In the same routing domain, before adding an SCTP link, ensure that either of the following is true:

    -An MLPPP group or PPP link has been configured.

    -LOCIP or SECLOCIP of the expected SCTP link is the same as IP of a DEVIP MO or an IPADDR4 MO, LOCALIP of an existing MLPPP group, or LOCALIP of an existing PPP link.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The BS uses the first local IP address and the first and second peer IP addresses for SCTP multi-homing when the following conditions are met:

    -The first local IP address of the SCTP link and the first and second peer IP addresses are valid.

    -The second local IP address is set to 0.0.0.0.

    This is true when the peer device supports SCTP multi-homing.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The BS uses the first and second local IP addresses and the first peer IP address for SCTP multi-homing when the following conditions are met:

    -The first and second local IP addresses of the SCTP link and the first peer IP address are valid.

    -The second peer IP address is set to 0.0.0.0.

    This is true when the peer device supports SCTP multi-homing.

  • [Co-MPT,NodeB,eGBTS,eNodeB]System specifications: If the WMPT is the main control board, a maximum of 20 SCTP links can be configured. If the LMPT is the main control board, a maximum of 112 SCTP links can be configured. If the GTMUb/GTMUc is the main control board, a maximum of 4 SCTP links can be configured. If the UMPTa/UMPTb/UMDU is the main control board, a maximum of 1024 SCTP links can be configured, but only a maximum of 384 SCTP links can take effect. If the UMPTe/UMPTg/UMPTga is the main control board, a maximum of 1024 SCTP links can be configured.

  • [Co-MPT,NodeB,eGBTS,eNodeB]Board specifications: A maximum number of 384 SCTP links can take effect on a UMDU. If the UMPTa/UMPTb is the main control board, a maximum of 384 SCTP links can take effect on a UMPTa/UMPTb/UTRPc/UCCU/LMPT/GTMUb/GTMUc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. If the UMPTe is the main control board, a maximum of 1024 SCTP links can take effect on a UMPTa/UMPTb/UMPTe/UTRPc/UCCU/LMPT/GTMUb/GTMUc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. If the UMPTg/UMPTga is the main control board, a maximum of 1024 SCTP links can take effect on a UMPTa/UMPTb/UMPTe/UMPTg/UMPTga/UTRPc/UCCU/LMPT/GTMUb/GTMUc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC)/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9. If the LMPT is the main control board, a maximum of 112 SCTP links can take effect on an LMPT/UTRPc. If the WMPT is the main control board, a maximum of 20 SCTP links can take effect on a WMPT/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC). If the GTMUb/GTMUc is the main control board, a maximum of 4 SCTP links can take effect on a GTMUb/GTMUc/UTRPc.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If two SCTP links have the same local port number, their local IP addresses must be totally the same or totally different. In the latter case, their local IP address pairs cannot overlap.

  • [Co-MPT,NodeB,eGBTS,eNodeB]A UMPTa/UMPTb/UMDU/UTRPc supports associations among a maximum of 384 SCTP links. A UMPTe/UMPTg/UMPTga supports associations among a maximum of 1024 SCTP links. A UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 supports associations among a maximum of 300 SCTP links. An LMPT supports associations among a maximum of 112 SCTP links. A WMPT supports associations among a maximum of 20 SCTP links. A UTRP supports associations among a maximum of 20 SCTP links. A GTMUb/GTMUc supports associations among a maximum of 4 SCTP links.

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first and second peer IP addresses of an SCTP link are different from the peer IPv4 address in the BLKSCTPPEERIPV4 object and the value of Block Flag for the SCTP link is UNBLOCK, the SCTP link is unblocked. In the same routing domain, if the first or second peer IP address of an SCTP link is the same as the peer IPv4 address in the BLKSCTPPEERIPV4 object or the value of Block Flag for the SCTP link is BLOCK, the SCTP link is blocked.

  • [NodeB,eGBTS,eNodeB,gNodeB]In the same routing domain, if the first and second peer IPv6 addresses of an SCTP link are different from the peer IPv6 address in the BLKSCTPPEERIPV6 object and the value of Block Flag for the SCTP link is UNBLOCK, the SCTP link is unblocked. In the same routing domain, if the first or second peer IPv6 address of an SCTP link is the same as the peer IPv6 address in the BLKSCTPPEERIPV6 object or the value of Block Flag for the SCTP link is BLOCK, the SCTP link is blocked.

  • [Co-MPT,eNodeB,gNodeB]The IPv6 SCTP link cannot be manually configured.

  • [Co-MPT,eNodeB,gNodeB]In IPv6 scenarios, before running this command, ensure that a route to the peer IPv6 address has been added by running the ADD IPROUTE6, or ADD SRCIPROUTE6 command.

  • [NodeB,eNodeB]In the same routing domain the value of PEERIP for a multi-link PPP group must be different from the values of LOCIP and SECLOCIP for an IPv4 SCTP link. In the same routing domain the value of PEERIP for a PPP link must be different from the values of LOCIP and SECLOCIP for an IPv4 SCTP link.

  • [Co-MPT,eNodeB]When the local ip and peer ip for inside sctplnk is configured on the loopback interface, the corresponding port failure will cause the SCTP link fault.

  • [Co-MPT,eGBTS]Because the processing capability of the GTMUb/GTMUc is limited, protocols for SCTP links configured on this board are processed by the main control board. If SCTP links are configured only on the GTMUb/GTMUc, its SCTP specifications are the same as those on the corresponding main control board. If SCTP links are configured on both the GTMUb/GTMUc and main control board, the SCTP specifications on the GTMUb/GTMUc are the same as those on the corresponding main control board.

MAXSCTPPDUSIZE Maximum SCTP PDU Size

Meaning: Indicates the maximum size of an IPv4 SCTP PDU (Protocol Data Unit). It specifies the maximum length of an SCTP PDU (excluding the IP header) transmitted on an SCTP link. If the value of this parameter is greater than the size of the IP layer MTU of the base station or intermediate transmission equipment, SCTP packets are fragmented at the IP layer. This causes a large number of fragments and affects the transmission efficiency of the intermediate transmission equipment.

GUI Value Range: 580~1480

Actual Value Range: 580~1480

MML Default Value: 1464

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: If this parameter is set to a value too large, a large number of packets are fragmented or lost on the transmission network. As a result, the transmission delay increases and the performance deteriorates. If this parameter is set to a value too small, the valid transmission payload decreases and the transmission network bandwidth cannot be effectively used. As a result, the transmission delay increases and the transmission performance deteriorates.
