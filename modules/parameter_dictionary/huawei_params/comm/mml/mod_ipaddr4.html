Modify IPv4 Address (MOD IPADDR4)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of an IPv4 address.

Note

None.

Parameters

ID Name Description
ITFID Interface ID

Meaning: Indicates the ID of an interface.

GUI Value Range: 0~1499

Unit: None

Actual Value Range: 0~1499

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
IP IP Address

Meaning: Indicates the IP address configured on the port.

GUI Value Range: Valid IP address

Unit: None

Actual Value Range: Valid IP address

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]IP in the IPADDR4 MO must be set to a valid IP address of Class A, B, or C. In addition, it cannot be 127.x.x.x or 0.x.x.x.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical operation result of IP and MASK in an IPADDR4 MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
MASK Mask

Meaning: Indicates the subnet mask for the IP address configured on the port.

GUI Value Range: Valid subnet mask

Unit: None

Actual Value Range: Valid subnet mask

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the binary value into which MASK in the IPADDR4 MO is converted, 0 is not allowed to precede 1.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the logical operation result of IP and MASK in an IPADDR4 MO, neither the network ID nor host ID can be all 0 or 1 after being converted into a binary value.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
USERLABEL User Label

Meaning: Indicates the user-defined information of an IP address.

GUI Value Range: 0~255 characters

Unit: None

Actual Value Range: 0~255 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To modify an IPv4 address with the parameters as follows: Interface ID: 100, IP Address: 192.168.2.24, Mask: 255.255.255.0, User Label: Modify IPADDR4, run the following command: 
MOD IPADDR4: ITFID=100, IP="192.168.2.24", MASK="255.255.255.0", USERLABEL="Modify IPADDR4";
