Display Sector State (DSP SECTOR)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to display the state of a sector.

Note

  • If the Sector ID is not specified, basic information about all sectors, excluding the license status, is displayed.

  • If the Sector ID is specified, the license status of the corresponding sector is displayed. If the license status of a sector is not displayed, the sector does not require the license.

  • When the Antenna Channel No. parameter is set to NULL, RRU frequency ranges are displayed.

Parameters

ID Name Description
SECTORID Sector ID

Meaning: Indicates the number of the sector.

GUI Value Range: 0~65535

Unit: None

Actual Value Range: 0~65535

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Output Description

Field Description

Sector ID

Indicates the number of the sector.

Mode

Indicates the mode in which the RRU channel connected to a sector antenna is working.

Cabinet No.

Indicates the cabinet number of the RRU to which a sector antenna is connected.

Subrack No.

Indicates the subrack number of the RRU to which a sector antenna is connected.

Slot No.

Indicates the slot number of the RRU to which a sector antenna is connected.

Antenna Channel No.

Indicates the channel number of a sector antenna on an RRU.

RX Frequency Range(0.1MHz)

Indicates the range of RX frequencies supported by the RRU channel connected to a sector antenna.

TX Frequency Range(0.1MHz)

Indicates the range of TX frequencies supported by the RRU channel connected to a sector antenna.

Sector License

Indicates the license to be requested for a sector.

License State

Indicates the license status of a sector.
