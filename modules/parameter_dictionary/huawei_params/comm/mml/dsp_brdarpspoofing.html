Display Board ARP Blacklist (DSP BRDARPSPOOFING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the ARP anti-spoofing information of boards.

Note

  • The query of the ARP anti-spoofing information is supported only for boards that comply with eCPRI protocols.

  • After the system learns the ARP table entries for 1 min, ARP spoofing is performed on the system.

  • This command lists a maximum of 10 IP addresses that have more than one MAC addresses. For each of the IP addresses, this command records the top 10 MAC addresses from which the IP address receives the most attacks.

  • The ARP blacklist records the IP address and MAC address deemed performing ARP spoofing attacks to NEs. In addition, the security log of the base station records historical information about ARP spoofing. There is a lot of ARP spoofing attack sources. Therefore, to ensure information effectiveness, the security log of the base station records only the following information: IP address and MAC address that perform the most ARP spoofing attacks in each detection period, date and time of the first attack, and number that the ARP spoofing-related alarm is reported.

  • If CLEAR in this command is set to YES, the blacklists in the ARP tables of all Ethernet links on the board, including HEI and eCPRI ports, are cleared after the query.

  • The query result of this command is affected by the ARPSPOOFCHKSW and ARPSPOOFALMTHD parameters in the SET IPGUARD command.

Example

To query the ARP anti-spoofing information of boards with the parameters as follows: Cabinet No.: 0. Subrack No.: 0, Slot No.: 2, run the following command:
+++    0        2018-05-04 16:49:22
O&M    #133
%%DSP BRDARPSPOOFING: CN=0, SRN=0, SN=2;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.

IP Address

Indicates the IP address in an ARP table.

Mac Address Number

Indicates the number of MAC addresses in the black list of an ARP table.

Mac Address

Indicates the MAC address list in the black list of an ARP table.
