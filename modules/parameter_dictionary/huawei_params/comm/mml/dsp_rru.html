Display RRU/RFU (DSP RRU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the dynamic information about an RRU or RFU. The information to be queried is as follows: the number of RX and TX channels, the number of carriers on each RX channel and TX channel, Maximum output power on the TX channel, the uplink channel gain, and other information about the RRU or RFU.

Note

  • If two or more RRUs or RFUs are displayed in the command output, the corresponding cabinet number, subrack number, and slot number must be specified to query the information of a single RRU or RFU.

  • The length of the fiber optic cable between the BBU and RF module in the command output is inaccurate due to factors such as the refractive index. The longer the fiber optic cable, the smaller the error. The relationship between the length of the fiber optic cable and the error is as follows and is for reference only: When the length of the fiber optic cable is smaller than 600 m, the error is large. When the length of the fiber optic cable ranges from 600 m to 2 km, the error is within 10%. When the length of the fiber optic cable ranges from 2 km to 12 km, the error is within 5%. When the length of the fiber optic cable is greater than 12 km, the error is within 2.5%. In eCPRI scenarios, when the optical fiber length is less than 1 km, the error rate is high. When the optical fiber length is greater than 1 km, the error rate is about 10%. When the optical fiber length is greater than 10 km, the error rate is about 5%. When the optical fiber length is greater than 20 km, the error rate is about 3%.

  • If an RF module works in cold backup mode, the fiber optic cable length displayed under Display RRU/RFU Dynamic Information or Display Length of Fiber Optic Cable Connecting to RRU/RFU refers to the length of the fiber optic cable in use between the BBU and RF module.

  • If an RF module works in load sharing or hot backup mode, the fiber optic cable length displayed under Display RRU/RFU Dynamic Information refers to the length of the shorter fiber optic cable between the RF module and BBU. The lengths of both fiber optic cables between them are displayed under Display Length of Fiber Optic Cable Connecting to RRU/RFU.

  • If an MPMU supports MPRFs, the length of fiber optic cables between the base station and RF modules is the same as that of fiber optic cables between the base station and MPRFs. In the queried dynamic information about an MPMU or MPRF, the length of fiber optic cables measured between the base station and RF modules is inaccurate and used for reference only because the MPMU is connected to an RHUB using a cable other than a fiber optic cable.

  • In a multimode base station, when the RF Desensitivity(dB) parameter is set to different values in different modes, the maximum value takes effect. Therefore, the value of the RF Desensitivity(dB) parameter displayed in the output of the DSP RRU command may be different from the configured value.

  • When the BLK BRD command is executed to block an RF unit using the eCPRI protocol, the length of optical fiber between the base station and the RF unit cannot be queried.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the RRU or RFU is located.

Subrack No.

Indicates the number of the subrack where the RRU or RFU is located.

Slot No.

Indicates the slot number of the RRU or RFU.

Access Direction

Indicates the access direction of the service plane.

Number of RX channels

Indicates the number of RX channels of the RRU or RFU. Set this parameter to the number of antenna ports on the RF module. The system creates RX channels based on the number of configured channels. For 8-channel TDD or FDD RRUs, the RX channels are numbered from 1 in ascending order, and channels 1 to 8 corresponds to antenna ports A to H. For other RRUs/RFUs, RX channels are numbered from 0 in ascending order, and channels 0 to 15 correspond to antenna ports A to P. Ensure that sufficient RX channels are configured before using an RX channel No. For example, if R0D is used, at least four RX channels must have been configured. Operations cannot be performed on a single channel for AAUs capable of beamforming. Therefore, this parameter does not take effect on such AAUs and the recommended value is 0.

Number of TX channels

Indicates the number of TX channels of the RRU or RFU. Set this parameter to the number of antenna ports on the RF module. The system creates TX channels based on the number of configured channels. For 8-channel TDD or FDD RRUs, the TX channels are numbered from 1 in ascending order, and channels 1 to 8 corresponds to antenna ports A to H. For other RRUs/RFUs, TX channels are numbered from 0 in ascending order, and channels 0 to 15 correspond to antenna ports A to P. Ensure that sufficient TX channels are configured before using an TX channel No. For example, if R0D is used, at least four TX channels must have been configured. Operations cannot be performed on a single channel for AAUs capable of beamforming. Therefore, this parameter does not take effect on such AAUs and the recommended value is 0.

Number of carriers on the RX channel

Indicates the number of carriers on each RX channel.

Number of carriers on the TX channel

Indicates the number of carriers on each TX channel.

Maximum output power on the TX channel(0.1dBm)

Indicates the total output power of TX channels in the RRU/RFU. The precision deviation is ±0.5 dB. For details, see the description of Output Power in the product description of the corresponding RRU/RFU.

UL channel gain(0.1dB)

Indicates the UL channel gain.

UL Support Feature

Indicates whether the RRU or RFU supports the UL features. This parameter takes effect for UMTS only.

Low Current Protect Switch

Indicates the undercurrent protection switch. If an undercurrent alarm is generated, the ALD power switch for this RRU or RFU is automatically turned off only when this parameter is set to ENABLE. If this parameter is set to NULL, the RRU/RFU undercurrent protection function setting is not changed. If NULL is displayed in the DSP RRU command output, the RRU/RFU does not support undercurrent protection. Only UMTS currently supports this function.

Antenna ID

Indicates the serial number of the RU in the AAU. The serial numbers of antennas on other RF modules are invalid.

Antenna Location

Indicates the slot number of the RU in the AAU. The value of this parameter is NULL for other RF modules. The slots of RUs are numbered from 0 in ascending order from bottom to top.

PA Efficiency Improvement Capability

Indicates whether an RF module supports the power amplifier efficiency improvement. This parameter takes effect in UMTS, LTE or NR.

The length of the fiber optic cable between the BBU and RF module[100m(100ft)]

Indicates the length of the fiber optic cable between the BBU and RF module. NULL indicates an invalid value.

RRU/RFU Maximum Delay of Its Channel(ns)

Indicates the maximum compensation in antenna delay supported by an RF module. The propagation delay from the output port of an RF unit to the antenna port is compensated. If no TMA is configured, this parameter is set to the propagation delay of the feeder. If the TMA is configured, this parameter also includes the delay of the TMA. NULL indicates that the compensation in antenna delay cannot be queried.

RF Desensitivity(dB)

Indicates the RF desensitization intensity of the RRU or RFU. When the air interface is under the impact of strong blocking or interference, the anti-interference capability of RF modules can be improved by decreasing the gain on RX channels and lowering the receiver sensitivity. For example, when the parameter is set to 10 dB, the uplink receiver sensitivity is lowered by 10 dB. Therefore, the anti-interference capability is improved. Currently, this parameter can only be set to 0 dB or 10 dB for RRU3804 and WRFU. The RRU3808, RRU3201, RRU3203, and LRFU do not support this function.

Current Maintenance Mode

Indicates the current maintenance mode of the RRU.

ALD Reuse Flag

Indicates whether the ALD is reused. Value 0 indicates that the ALD is not reused. Value 1 indicates that the ALD is reused. This parameter takes effect only to UMTS.

RF DC Power Off Alarm Detect Switch

Indicates the switch for detecting the abnormal input of the power supply. Some RF modules need to check the DC voltage to determine whether they are about to be powered off. If this switch is turned on, RF modules detect the voltage. If the voltage is abnormal, ALM-26564 RF Unit DC Input Power Failure is reported. This parameter takes effect only for the RF modules for which the value of DC Input Voltage is not NULL in the output of the DSP RRU command.

Battery Output Undervoltage Threshold(0.1V)

Indicates the output undervoltage threshold of storage batteries. This parameter is valid only if the switch controlling the detection of the RF Unit DC Input Power Failure alarm. The value NULL indicates that RF modules do not support this parameter. This parameter takes effect only for the RF modules for which the value of DC Input Voltage is not NULL in the output of the DSP RRU command.

Power Supply Type

Indicates the power supply type of the RF module. The value UNKNOWN indicates that the power supply type of the RF module cannot be queried.

DC Input Voltage(0.1V)

Indicates the DC input voltage of the RF module. The value NULL indicates that the DC input voltage of the RF module cannot be queried.

Fan Installation Status

Indicates the installation status of the fan in the RF module, which can be Uninstalled, Installed, and Unknown. When the base station supports the fan installation but the fan is not installed, Uninstalled is displayed. When the base station supports the fan installation and the fan is installed, Installed is displayed. When the RF module does not support the fan, or the base station does not support the fan function, Unknown is displayed.

Install Type

Indicates the AAU installation mode, including horizontal installation and vertical installation. The value NULL indicates that the installation mode of the AAU cannot be queried.

The Value of The Circuit Breaker

Indicates the circuit breaker value of the power module that is connected to an RF module. The value NULL indicates that the queried RF module does not support querying of this parameter and is displayed only in the DSP RRU command output.

Configuration Exceed Specification Flag

Indicates whether the configuration of an RF module has exceeded specifications. If the value of this parameter is YES, view Configuration Exceed Specification Info for detailed information. The value of this parameter is UNKNOWN when the base station version is not supported or detailed specification information cannot be obtained.

Configuration Exceed Specification Info

Indicates that configuration of an RF module has exceeded specifications. Configuration exceeding specifications indicates that multimode data configuration of an RF module has exceeded hardware specifications, including the specifications for power, bandwidth, and number of carriers. This will lead to service exception of certain RATs that are configured on this module.

Band 1 DL Minimum Frequency(0.1MHz)

Indicates the minimum downlink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9650, the minimum downlink frequency of the RRU or RFU is 9650 x 0.1 MHz, which equals to 965 MHz.

Band 1 DL Maximum Frequency(0.1MHz)

Indicates the maximum downlink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9850, the maximum downlink frequency of the RRU or RFU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 1 DL Bandwidth(MHz)

Indicates the bandwidth in band 1 supported by each TX channel in the downlink. This bandwidth is an instantaneous bandwidth.

Band 2 DL Minimum Frequency(0.1MHz)

Indicates the minimum downlink frequency supported by the RRU or RFU band 2. This parameter is NULL, when the RRU or RFU does not support multiple bands. For example, if this parameter is set to 9650, the minimum downlink frequency of the RRU is 9650 x 0.1 MHz, which equals to 965 MHz.

Band 2 DL Maximum Frequency(0.1MHz)

Indicates the maximum downlink frequency supported by the RRU or RFU band 2. This parameter is NULL, when the RRU or RFU does not support multiple bands. For example, if this parameter is set to 9850, the maximum downlink frequency of the RRU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 2 DL Bandwidth(MHz)

Indicates the bandwidth in band 2 supported by each TX channel in the downlink. This bandwidth is an instantaneous bandwidth. This parameter is NULL when the RRU or RFU does not support multiple bands.

Band 3 DL Minimum Frequency(0.1MHz)

Indicates the minimum downlink frequency supported by the RRU or RFU band 3. This parameter is NULL, when the RRU or RFU does not support multiple bands. For example, if this parameter is set to 9650, the minimum downlink frequency of the RRU is 9650 x 0.1 MHz, which equals to 965 MHz.

Band 3 DL Maximum Frequency(0.1MHz)

Indicates the maximum downlink frequency supported by the RRU or RFU band 3. This parameter is NULL, when the RRU or RFU does not support multiple bands. For example, if this parameter is set to 9850, the maximum downlink frequency of the RRU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 3 DL Bandwidth(MHz)

Indicates the bandwidth in band 3 supported by each TX channel in the downlink. This bandwidth is an instantaneous bandwidth. This parameter is NULL when the RRU or RFU does not support multiple bands.

Band 1 UL Minimum Frequency(0.1MHz)

Indicates the minimum uplink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9250, the minimum uplink frequency of the RRU is 9250 x 0.1 MHz, which equals to 925 MHz.

Band 1 UL Maximum Frequency(0.1MHz)

Indicates the maximum uplink frequency supported by the RRU or RFU band 1. For example, if this parameter is set to 9450, the maximum uplink frequency of the RRU is 9450 x 0.1 MHz, which equals to 945 MHz.

Band 1 UL Bandwidth(MHz)

Indicates the bandwidth supported by each RX channel band 1 in the uplink. This bandwidth is an instantaneous bandwidth.

Band 2 UL Minimum Frequency(0.1MHz)

Indicates the minimum uplink frequency supported by the RRU or RFU band 2.This parameter is NULL,when the RRU does not support multiple bands. For example, if this parameter is set to 9250, the minimum uplink frequency of the RRU is 9250 x 0.1 MHz, which equals to 925 MHz.

Band 2 UL Maximum Frequency(0.1MHz)

Indicates the maximum uplink frequency supported by the RRU or RFU band 2.This parameter is NULL,when the RRU does not support multiple bands. For example, if this parameter is set to 9850, the maximum uplink frequency of the RRU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 2 UL Bandwidth(MHz)

Indicates the bandwidth supported by each RX channel band 2 in the uplink. This bandwidth is an instantaneous bandwidth. This parameter is NULL when the RRU does not support multiple bands.

Band 3 UL Minimum Frequency(0.1MHz)

Indicates the minimum uplink frequency supported by the RRU or RFU band 3.This parameter is NULL,when the RRU does not support multiple bands. For example, if this parameter is set to 9250, the minimum uplink frequency of the RRU is 9250 x 0.1 MHz, which equals to 925 MHz.

Band 3 UL Maximum Frequency(0.1MHz)

Indicates the maximum uplink frequency supported by the RRU or RFU band 3.This parameter is NULL,when the RRU does not support multiple bands. For example, if this parameter is set to 9850, the maximum uplink frequency of the RRU is 9850 x 0.1 MHz, which equals to 985 MHz.

Band 3 UL Bandwidth(MHz)

Indicates the bandwidth supported by each RX channel band 3 in the uplink. This bandwidth is an instantaneous bandwidth. This parameter is NULL when the RRU does not support multiple bands.

Dormancy Switch

Indicates the RRU deep dormancy switch. RRU deep dormancy is enabled if this switch is turned on. RRU deep dormancy is disabled if this switch is turned off. This parameter is NULL when the RRU does not support deep dormancy. The effective status of RRU deep dormancy can be queried using the DSP RRU command. When Dormancy Switch is set to ON, you need to set the start time and end time of the dormancy period. If you do not set the start time and end time, the dormancy period is 00:00:00 to 06:00:00. This parameter is valid only when RRU type is set to MPMU, MRRU, or AIRU.

Reserved Bandwidth

Indicates the bandwidth reserved for other applications.

Cabinet No. of Interface Board

Indicates the number of the cabinet housing the interface board.

Subrack No. of Interface Board

Indicates the number of the subrack housing the interface board.

Slot No. of Interface Board

Indicates the number of the slot housing the interface board.

Port No. of Interface Board

Indicates the number of the port on the interface board.

SubPort No. of Interface Board

Indicates the sub-port number of the interface board.

Port No. of RF Module

Indicates the number of the port on the RF unit.

Latest Start Time of High Temperature Mode

Indicates the latest start time of the high temperature mode for an RF module. In high temperature mode, the RF module works within the claimed maximum supported temperature range. The format of the parameter value is YYYY-MM-DD HH:MM:SS.

Latest End Time of High Temperature Mode

Indicates the latest end time of the high temperature mode for an RF module. The format of the parameter value is YYYY-MM-DD HH:MM:SS. If the RF module is still in high temperature mode, the parameter value is "Uncompleted."

Cable Length[m(ft)]

Indicates the length of the power cable for the RF module. The value is displayed only after the result is obtained using the STR RXUCABLETEST command. The calculation results are displayed separately according to the signal propagation speeds defined by the European standard and American standard. Users can query this parameter value to obtain the power cable length based on the types of cables used onsite. The value AVG indicates that the system cannot accurately obtain the length of the power cable of the RF module. According to the calculation result of the average algorithm, the length of the cable between the RF module and the power module cannot be accurately expressed. The value NULL indicates that the length of the power cable is not queried or is not supported.

Calibration Type

Indicates the effective channel calibration mode of the RF module. The value NULL indicates that the RF units do not support the query of this parameter.

Peer Standard

Indicates the RAT of the peer end. The RATs include UMTS, GSM, LTE, LTE TDD, NR, COMM, and COMM2. COMM and COMM2 are the RATs of co-MPT base stations.

Peer NE Name

Indicates the name of the peer NE. The value NULL indicates that the peer NE does not support the report of this field.

Peer App Type

Indicates the application type of the peer NE. The value NULL indicates that the peer NE has no applications, or does not support the report of this field.

Peer Cabinet No.

Indicates the cabinet number of the RRU on the peer NE.

Peer Subrack No.

Indicates the subrack number of the RRU on the peer NE.

Peer Slot No.

Indicates the slot number of the RRU on the peer NE.
