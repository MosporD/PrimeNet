Display Downlink Flow Control Para (DSP DLFLOWCTRLPARA)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to query the effective settings of downlink flow control parameters.

Note

  • [Co-MPT,NodeB,eGBTS]This command takes effect only for UMTS.

  • [Co-MPT,NodeB,eGBTS]When the Port Type parameter is set to LOOPINT(Loop Interface), the command output displays the settings of the downlink flow control parameters for boards that provide Ethernet ports.

  • [Co-MPT,NodeB,eGBTS]Only the effective settings of downlink flow control parameters for a WMPT/UMPT/UMDU/UTRPc/UTRP board can be queried using this command.

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the DL flow control algorithm switch.

Subrack No.

Indicates the subrack number of the DL flow control algorithm switch.

Slot No.

Indicates the slot number of the DL flow control algorithm switch.

Subboard Type

Indicates the type of sub-board having the port on which the DL flow control algorithm switch is configured.

Bear Type

Indicates the bearer type of the physical port where the DL flow control algorithm is configured.

Port Type

Indicates the type of port where the DL flow control algorithm is configured.

Port No.

Indicates the number of a port where the DL flow control algorithm is configured.

Flow Control Switch

Indicates the switch for the DL flow control algorithm. If this parameter is set to STATIC_BW_SHAPING, the available HSDPA bandwidth equals the total bandwidth minus the R99 bandwidth. If this parameter is set to DYNAMIC_BW_SHAPING, flow allocation for HSDPA users is performed according to the delay and packet loss of the transmission interface board in STATIC_BW_SHAPING mode. This function requires the network controller using the 3GPP R6 protocol. Therefore, you are advised to use this function with the RNC that complies with the 3GPP R6 protocol. If this parameter is set to NO_BW_SHAPING, the BS does not allocate bandwidth according to the configuration and delay of the transmission interface board. The BS reports the air interface conditions to the controller, and then the controller allocates bandwidth. When this parameter is set to NO_BW_SHAPING, the backpressure function must be enabled on the controller side. If this parameter is set to BW_SHAPING_ONOFF_TOGGLE, the BS automatically selects either DYNAMIC_BW_SHAPING or NO_BW_SHAPING during a flow control congestion detection on a port. That is, DYNAMIC_BW_SHAPING is selected if congestion is detected; NO_BW_SHAPING is selected if congestion is not detected for a certain period of time.

Time Delay(5ms)

Indicates the background noise threshold of the delay jitter above which the DL flow control algorithm is enabled. A link is considered to be non-congested if the delay jitter on the link is below the threshold.

Discard Rate(per mill)

Indicates the port frame loss rate threshold of the DL flow control algorithm switch. When the frame loss rate is less than or equal to this threshold, the base station determines that the link is not congested.

Transport Mode

Indicates the transport mode of the port.

BW Adjust Protection Switch

Indicates the adjustment protection switch for the available DL bandwidth. When this parameter is set to ON, the BS stops adjusting the available DL bandwidth of the physical port if bit error occurs on the transmission line and the bit error rate (BER) exceeds the specified alarm threshold. This parameter does not take effect for loopback ports or tunnels because the error MAC frame reporting function is not implemented for loopback ports and tunnels.

Fair Switch

Indicates the switch for the downlink fairness flow control. If multiple modes share transmission bandwidth and congestion occurs, the UMTS data rate may decrease due to downlink flow control and the LTE data rate may increase due to bandwidth preemption when the Flow Control Switch parameter is set to DYNAMIC_BW_SHAPING or is set to BW_SHAPING_ONOFF_TOGGLE but actually takes effect using the DYNAMIC_BW_SHAPING value. When this switch is turned on, the system guarantees the minimum downlink transmission bandwidth of the UMTS mode. This switch applies only to Ethernet ports, Ethernet trunks, and loop interfaces with Port Type set to ETH or ETHTRK.

Min Fair Protection Ratio(%)

Indicates the minimum protection ratio of downlink fairness flow control. When the fairness flow control switch is turned on whereas the flow control is based on unfairness, the system guarantees the minimum UMTS transmission bandwidth based on the value of this parameter.

Min DL Avail Bandwidth of Logical Port(kbit/s)

Indicates the minimum DL bandwidth of a logical port.

Downlink Flow Control Enhancement Switch

Indicates the switch for controlling the enhanced downlink flow control feature. When the switch is set to on, the enhanced downlink flow control prevents downlink available bandwidth from sharply decreasing and downlink throughput from abruptly deteriorating when bit-error packet loss occurs on the transport network. The packet loss rate may increase when the incoming port is congested. However, this seldom occurs.

The enhanced downlink flow control feature requires the downlink FPDT GPM detection results. Before using this feature, run the ADD GPM or MOD GPM command to enable the downlink FPDT GPM detection function for the NodeB.

This switch can be configured only when flow control is set to dynamic flow control or self-selection flow control. This configuration takes effect only in IP transmission, but cannot take effect in ATM transmission even though the configuration succeeds.

Min Protection Ratio of IUB Port DL Bandwidth(%)

Indicates the minimum ratio of reducing the available downlink bandwidth over the Iub interface.
