List UTRP (LST UTRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the configuration of the universal transmission processing unit (UTRP).

Note

The BLADEBBU does not support this command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the extension transmission board.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the extension transmission board.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TYPE of the SUBRACK where the TRP is located must be BBU3900, BBU3900-1U, BBU3910, or DCU3911.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the extension transmission board.

GUI Value Range: 0~6

Unit: None

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Example 1: To list the configuration of the UTRP, run the following command:
LST UTRP:;
The result is shown as follows:
+++    0        2010-07-14 18:55:03
O&M    #20
%%LST UTRP:;%%
RETCODE = 0  Operation succeeded.

List UTRP
---------
  Cabinet No.  =  0
  Subrack No.  =  0
     Slot No.  =  3
SubBoard Type  =  UTRPc
(Number of results = 1)


---    END

Example 2: To list the configuration of the UTRP in slot 3 of subrack 0 in cabinet 0, run the following command:
LST UTRP: CN=0, SRN=0, SN=3;
The result is shown as follows:
+++    0        2010-07-14 18:58:36
O&M    #40
%%LST UTRP: CN=0, SRN=0, SN=3;%%
RETCODE = 0  Operation succeeded.

List UTRP
---------
  Cabinet No.  =  0
  Subrack No.  =  0
     Slot No.  =  3
SubBoard Type  =  UTRPc
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the extension transmission board.

Subrack No.

Indicates the subrack number of the extension transmission board.

Slot No.

Indicates the slot number of the extension transmission board.

SubBoard Type

Indicates the type of the subboard.
