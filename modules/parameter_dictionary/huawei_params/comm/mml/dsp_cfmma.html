Display CFM MA Status (DSP CFMMA)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of a maintenance association (MA).

Note

None.

Parameters

ID Name Description
MDNAME MD Name

Meaning: Indicates the name of the MD to which the MA belongs.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MDNAME value of a CFM MA.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMA MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
MANAME MA Name

Meaning: Indicates the name of the MA.

GUI Value Range: 1~43 characters

Unit: None

Actual Value Range: 1~43 characters

MML Default Value: None

Recommended Value: Digits 0 to 9 and letters a to z and A to Z are recommended for the MANAME value of a CFM MA.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]MANAME in a CFMMA MO can contain only ASCII characters. The name cannot be composed of only space characters (including space and tab) or contain the following characters: ', ", !, ?, <, >, and \.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In the CFMMA MO, the total length of MANAME and MDNAME cannot exceed 44 characters.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the status of a CFM MA with the parameters as follows: MD Name: CHINA, MA Name: SHANGHAI, run the following command:
DSP CFMMA: MDNAME="CHINA", MANAME="SHANGHAI";

Output Description

Field Description

MD Name

Indicates the name of the MD to which the MA belongs.

MD Level

Indicates the level of the CFM MD.

MA Name

Indicates the name of the MA.

Binding VLAN

Indicates whether the MA is associated with the VLAN.

VLAN ID

Indicates the ID of the VLAN with which the MA is associated.

VLAN Priority

Indicates the priority of the VLAN with which the MA is associated.

CCM TX Interval

Indicates the interval at which the CFM MA transmits continuity check messages (CCMs).

Number of MEPs

Indicates the number of local MEPs in an MA.

Number of RMEPs

Indicates the number of RMEPs in an MA.

MEP List

Indicates the list of local MEPs in an MA.

RMEP List

Indicates the list of RMEPs in an MA.
