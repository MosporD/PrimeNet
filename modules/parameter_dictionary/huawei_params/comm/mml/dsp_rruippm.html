Display RRU IP PM Status (DSP RRUIPPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the IP PM information of RRUs.

Note

  • The query of the IP PM information is supported only for RRUs that comply with eCPRI protocols.

  • The system measures the high-precision round trip time only when the negotiated IP PM protocol runs V15 or V14.

  • The system measures the one-way delay and uplink and downlink jitter only when the negotiated IP PM protocol runs V14.

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where a board is located.

Subrack No.

Indicates the number of the subrack where a board is located.

Slot No.

Indicates the number of the slot where a board is located.

Port No.

Indicates the CPRI port number of the RRU involved in an IP PM session.

Local IP

Indicates the BBU IP address used in an IP PM session.

Peer IP

Indicates the RRU IP address used in an IP PM session.

BBP Cabinet No.

Indicates the cabinet number of the baseband processing board involved in an IP PM session.

BBP Subrack No.

Indicates the subrack number of the baseband processing board involved in an IP PM session.

BBP Slot No.

Indicates the slot number of the baseband processing board involved in an IP PM session.

BBP Port No.

Indicates the CPRI port number of the baseband processing board involved in an IP PM session.

High Precision Round Trip Time(microsecond)

Indicates the high-precision round-trip delay calculated by an IP PM session detection.

One Way Delay(microsecond)

Indicates the one-way delay calculated based on an IP PM session. The value NULL indicates that the IP PM protocol version does not support one-way delay calculation.

DL Jitter(microsecond)

Indicates the DL jitter calculated by an IP PM session detection.

UL Jitter(microsecond)

Indicates the UL jitter calculated by an IP PM session detection.

UL Loss Rate(per mill)

Indicates the UL packet loss rate calculated by an IP PM session detection.

Number of UL Lost Packets

Indicates the number of UL lost packets calculated by an IP PM session detection.

Number of UL Sent Packets

Indicates the number of UL sent packets calculated by an IP PM session detection.

DL Loss Rate(per mill)

Indicates the DL packet loss rate calculated by an IP PM session detection.

Number of DL Lost Packets

Indicates the number of DL lost packets calculated by an IP PM session detection.

Number of DL Sent Packets

Indicates the number of DL sent packets calculated by an IP PM session detection.

IP PM Protocol Version

Indicates the protocol version negotiated in an IP PM session.
