List VRET Subunit Configuration (LST VRETSUBUNIT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to list the configuration of one or all virtual remote electrical tilting (VRET) subunits.

Note

None.

Parameters

ID Name Description
DEVICENO Device No.

Meaning: Indicates the device number of the VRET antenna where the VRET subunit is contained. The device number of the VRET antenna must be unique.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SUBUNITNO Subunit No.

Meaning: Indicates the number of the VRET subunit, which starts from 1.

GUI Value Range: 1~8

Unit: None

Actual Value Range: 1~8

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Output Description

Field Description

Device No.

Indicates the device number of the VRET antenna where the VRET subunit is contained. The device number of the VRET antenna must be unique.

Subunit No.

Indicates the number of the VRET subunit, which starts from 1.

Subunit Name

Indicates the name of the VRET subunit. The name of the VRET subunit is optional, but the name configured for each VRET subunit must be unique.

Connected Port 1

Indicates the number of the first virtual antenna port to which the VRET subunit is connected.

Polar Type1

Indicates the polarization type of the virtual antenna port 1 to which the VRET subunit is connected. This parameter is valid only if the virtual antenna port 1 is in use.

Connected Port 2

Indicates the number of the second virtual antenna port to which the VRET subunit is connected.

Polar Type2

Indicates the polarization type of the virtual antenna port 2 to which the VRET subunit is connected. This parameter is valid only if the virtual antenna port 2 is in use.

Connected Port 3

Indicates the number of the third virtual antenna port to which the VRET subunit is connected.

Polar Type3

Indicates the polarization type of the virtual antenna port 3 to which the VRET subunit is connected. This parameter is valid only if the virtual antenna port 3 is in use.

Connected Port 4

Indicates the number of the fourth virtual antenna port to which the VRET subunit is connected.

Polar Type4

Indicates the polarization type of the virtual antenna port 4 to which the VRET subunit is connected. This parameter is valid only if the virtual antenna port 4 is in use.

Uplink Tilt(0.1degree)

Indicates the uplink downtilt of the VRET subunit. If this parameter is set to 32767, the downtilt automatically calculated by the AARU is used.

Downlink Tilt(0.1degree)

Indicates the downlink downtilt of the VRET subunit. If this parameter is set to 32767, the downtilt automatically calculated by the AARU is used.

BeamAzimuth(0.1degree)

Indicates the horizontal azimuth of the VRET subunit. If this parameter is set to 32767, the default value of the VRET subunit is used.

BeamWidth(0.1degree)

Indicates the horizontal beamwidth of the VRET subunit. If this parameter is set to 65535, the default value of the VRET subunit is used.
