Stop STM-1 Online Performance Test (STP STM1ONLTST)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to stop the STM-1 online performance test.

Note

[Co-MPT,NodeB]You can run this command only after an STM-1 online performance test is started.

Example

To stop an STM-1 online performance test with the parameters as follows: Slot No.: 0, Subboard Type: UNCHANNELLED_COVERBOARD, run the following command: 
STP STM1ONLTST: SN=0, SBT=UNCHANNELLED_COVERBOARD;

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet that houses the board where a specified optical port is located.

Subrack No.

Indicates the number of the subrack that houses the board where a specified optical port is located.

Slot No.

Indicates the number of the slot corresponding to the board where a specified optical port is located.

Subboard Type

Indicates the type of sub-board where a specified optical port is located.

Port No.

Indicates the number of a specified optical port.

Duration

Indicates the duration during which the STM-1 test lasts.

Framing Error Rate

Indicates the out-of-frame rate in the test result.

Section BIP Rate

Indicates the proportion of erroneous blocks on the regeneration section in the test result.

Line BIP Rate

Indicates the proportion of erroneous blocks on the multiplex section in the test result.

Line FEBE Rate

Indicates the proportion of remote erroneous blocks on the multiplex section in the test result.

Path BIP Rate

Indicates the proportion of erroneous blocks on a higher-order path in the test result.

Path FEBE Rate

Indicates the proportion of erroneous blocks at the far end of a higher-order path in the test result.

Locd Event Rate

Indicates the proportion of cell delineation losses in the test result.

Hec Correctable Error Rate

Indicates the proportion of corrected HEC errors in the test result.

Hec Uncorrectable Error Rate

Indicates the proportion of uncorrectable HEC errors in the test result.

Non Matching Rate

Indicates the proportion of mismatched cells in the test result.

Number of Tx Cells

Indicates the number of transmitted cells.

Number of Rx Cells

Indicates the number of received cells.

Path Rx Errored Second

Indicates the number of seconds for receiving error bits on the higher order path.

Path Rx Errored Second Rate

Indicates the ratio of the seconds for bit errors received on the higher order path to the total receive seconds.

Path Rx Severely Errored Second

Indicates the number of seconds for receiving bits containing serious errors on the higher order path.

Path Rx Severely Errored Second Rate

Indicates the ratio of the seconds for serious bit errors received on the higher order path to the total receive seconds.

Path Rx Background Block Error Count

Indicates the number of background block errors received on the higher order path.

Path Rx Background Block Error Rate

Indicates the ratio of the background blocks with bit errors received on the higher order path to the total blocks.

Path Rx Unusable Second

Indicates the number of seconds for which packets cannot be received on the higher order path.

Path Tx Errored Second

Indicates the number of seconds for transmitting error bits on the higher order path.

Path Tx Errored Second Rate

Indicates the ratio of the seconds for bit errors transmitted on the higher order path to the total transmit seconds.

Path Tx Severely Errored Second

Indicates the number of seconds for transmitting bits containing serious errors on the higher order path.

Path Tx Severely Errored Second Rate

Indicates the ratio of the seconds for serious bit errors transmitted on the higher order path to the total transmit seconds.

Path Tx Background Block Error Count

Indicates the number of background block errors transmitted on the higher order path.

Path Tx Background Block Error Rate

Indicates the ratio of the background blocks with bit errors transmitted on the higher order path to the total blocks.

Path Tx Unusable Second

Indicates the number of seconds for which packets cannot be transmitted on the higher order path.
