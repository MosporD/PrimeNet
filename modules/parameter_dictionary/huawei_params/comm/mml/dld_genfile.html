Download Generic File (DLD GENFILE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to download the generic file from the FTP server to the NE.

Note

  • During the download, if a file with the same name already exists in the save path, the new file will overwrite the existing file.

  • If there is insufficient disk space, it is recommended that you run related remove commands or the CLR FILE command to delete files that are no longer in use.

  • If Type is set to PRECFG, the name of the file to be downloaded must be precfg.ini. If it is set to SWSCRL, the file name must be SWSCRL.crl. If it is set to SCRULEFILE, the file name must be ScRuleFile.zip.

  • The SCRULEFILE value can take effect only for LTE or SingleOM base stations where available APPs are working in LTE mode (except on the UMDU and LMPT boards).

  • [Co-MPT,NodeB]When Downloading the SSL file, the mapping between the NE name and the certificate name must be obtained before this command is executed.

Parameters

ID Name Description
SRCF Source File Name

Meaning: Indicates the source file name, which can includes the file path when a file is downloaded. The length of the file name including the file path cannot exceed the maximum length of a file name supported by the FTP server and cannot exceed 230 characters. Some FTP servers do not support a full-path file name of 230 characters. For details, see the related FTP server manual.

In the case of file upload, this parameter indicates the name (wildcard characters not supported) of the file to be uploaded.

In the case of file download, this parameter indicates the name (wildcard characters not supported) of the file to be downloaded from the FTP server.

GUI Value Range: 1~230 characters

Unit: None

Actual Value Range: 1~230 characters

Recommended Value: None

Impact on Radio Network Performance: None

DSTF Destination File Name

Meaning: Indicates the name of the destination file.

For file uploading operations, this parameter indicates the name of the destination file saved to the FTP server, which can include the path of the file. If the path is not included in the file name, the file is saved in the default path on the FTP server. The maximum length of the file name plus the path cannot be greater than the maximum length of file name supported by the FTP server and cannot contain more than 248 characters. (Some servers do not support a full-path file name consisting of 248 characters. For details, see the related FTP server manual.)

For file downloading operations, this parameter indicates the name of the destination file downloaded to a board, which does not include any paths.

If the parameter contains only the file name, the length of the file name cannot exceed 64 characters.

Example

Example 1: To download the preconfiguration file to the NE with the parameters as follows: Source File Name that contains the relative path of the FTP server: \files\precfg.ini, TYPE: PRECFG, Destination File Name: precfg.ini, IP Mode: IPV4, FTP Server IP: 192.168.4.8, User Name: mpta, Password: 123456, Guage Option: Y, run the following command: 
DLD GENFILE: SRCF="\files\precfg.ini", TYPE=PRECFG, DSTF="precfg.ini", MODE=IPV4, IP="192.168.4.8", USR="mpta", PWD="*****", GA=Y;
