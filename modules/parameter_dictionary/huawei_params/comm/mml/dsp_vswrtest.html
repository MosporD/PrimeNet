Display VSWR Test (DSP VSWRTEST)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query an ongoing VSWR test.

Note

If the STR VSWRTEST command is executed with Cabinet No., Subrack No., and Slot No. unspecified, VSWR test is started on the whole base station. In this case, the values of Cabinet No., Subrack No., and Slot No. in the DSP VSWRTEST command output are NULL.

Parameters

None.

Example

1.If you run the DSP VSWRTEST command to query the ongoing single-frequency VSWR test on the whole base station, The result is shown as follows:
DSP VSWRTEST:;
The result is shown as follows:
+++    0        2012-12-20 14:40:01
O&M    #242
%%DSP VSWRTEST:;%%
RETCODE = 0  Operation succeeded.

Display VSWR Test
-----------------
Cabinet No.  =  NULL
Subrack No.  =  NULL
   Slot No.  =  NULL
  Test Mode  =  SINGLE_ARFCN
  SessionID  =  65539
(Number of results = 1)


---    END

2.If you run the DSP VSWRTEST command to query the ongoing VSWR tests after starting a single-frequency VSWR test on the WRFU in slot 0, subrack 4, and cabinet 0, and starting a multi-frequency VSWR test on the MRRU in slot 0, subrack 60, and cabinet 0, the result is shown as follows:
DSP VSWRTEST:;
The result is shown as follows:
+++    0        2012-12-20 15:00:03
O&M    #484
%%DSP VSWRTEST:;%%
RETCODE = 0  Operation succeeded.

Display VSWR Test
-----------------
Cabinet No.  Subrack No.  Slot No.  Test Mode     SessionID

0            60           0         MULTI_ARFCN   65546    
0            4            0         SINGLE_ARFCN  65547    
(Number of results = 2)


---    END

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the RRU or RFU where the TX channel is located.

Subrack No.

Indicates the subrack number of the RRU or RFU where the TX channel is located.

Slot No.

Indicates the slot number of the RRU or RFU where the TX channel is located.

Test Mode

Indicates the mode of the VSWR test.

SessionID

Indicates the session ID of the VSWR test.
