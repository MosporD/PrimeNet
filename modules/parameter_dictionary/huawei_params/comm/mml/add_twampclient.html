Add TWAMP Client (ADD TWAMPCLIENT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a TWAMP client.

Note

  • Board specifications: A UMPTe/UMPTg/UMPTga supports a maximum of 24 TWAMP clients, and an LMPT/UMPTa/UMPTb/UMDU/WMPT/GTMUc/UTRPc/UCCU/UBBPe (except UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 supports a maximum of 16 TWAMP clients.

  • System specifications: When a WMPT/LMPT/GTMUc is used as the main control board, the base station supports a maximum of 16 TWAMP clients. When a UMPTa/UMPTb/UMDU is used as the main control board, the base station can be configured with a maximum of 24 TWAMP clients, but only 16 TWAMP clients of them take effect. When a UMPTe/UMPTg/UMPTga is used as the main control board, the base station supports a maximum of 24 TWAMP clients.

  • When a TWAMP client works in the full architecture, the TCP keepalive time is 75 seconds. That is, when no TCP packet is transmitted on a TCP link for a long time, the TWAMP client sends keepalive packets to the peer every 75 seconds to indicate that the TCP link is still available. Therefore, the TCP aging time configured on the intermediate transmission devices must be longer than 75 seconds. That is, the intermediate transmission devices must be capable of transmitting TCP packets for at least 75 seconds.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The IPv4 address used by a TWAMP client must be an IPv4 address configured using the ADD DEVIP, ADD IPADDR4, ADD PPPLNK, or ADD MPGRP command and cannot be an auto-negotiated IPv4 address or an IPv4 address of an OMCH (except that OMIPv4 and DEVIP/IPADDR4 share an IP address).

  • [eNodeB,gNodeB]The IPv6 address used by a TWAMP client must be an IPv6 address configured using the ADD IPADDR6 command and cannot be an auto-negotiated IPv6 address or an IPv6 address of an OMCH (except that OMIPv6 and IPADDR6 share an IPv6 address).

  • [gNodeB]The IPv4 address used by a TWAMP client must be an IPv4 address configured using the ADD DEVIP or ADD IPADDR4 command and cannot be an auto-negotiated IPv4 address or an IPv4 address of an OMCH (except that OMIPv4 and DEVIP/IPADDR4 share an IP address).

IPVERSION IP Version

Meaning: Indicates the IP protocol version of a TWAMP client.

GUI Value Range: IPv4(IPv4), IPv6(IPv6)

Unit: None

Actual Value Range: IPv4, IPv6

MML Default Value: IPv4(IPv4)

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv4, LOCALIP in a TWAMPCLIENT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, NodeB, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv4, PEERIP in a TWAMPCLIENT MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.
  • [Co-MPT, NodeB, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv4, TWAMPARCH in the TWAMPCLIENT MO must be deployed in the full architecture.
  • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv6, TWAMPARCH in the TWAMPCLIENT MO must be deployed in the light architecture.
  • [Co-MPT, eNodeB, gNodeB]If IPVERSION in a TWAMPCLIENT MO is set to IPv6, PEERIPV6 in the TWAMPCLIENT MO must be set to a global unicast address.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a TWAMP Client with the parameters as follows: Client Index: 0, IP Version: IPv4, Local IP Address: 172.16.90.34, Peer IP Address: 172.16.88.134, TWAMP Architecture: Full Architecture, run the following command: 
ADD TWAMPCLIENT: CLIENTID=0, IPVERSION=IPv4, LOCALIP="172.16.90.34", PEERIP="172.16.88.134", TWAMPARCH=FULL;
