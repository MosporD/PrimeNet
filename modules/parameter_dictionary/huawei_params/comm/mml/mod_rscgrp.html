Modify Transmission Resource Group (MOD RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the configuration of a transmission resource group.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Modifying a transmission resource group may interrupt services. For details, see the "Service Interrupted After Modification" of each parameter in this command.

  • The bandwidth and rate of a transmission resource group are calculated based on the data link layer statistics.

  • Bandwidth-related parameters of an auto port transmission resource group cannot be modified, they take effect as the default values according to the board capacity. To remove the auto port resource group and add a default port transmission resource group are needed in order to modify the bandwidth-related parameters.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf0/UBBPg1 can be configured with a maximum of 40 Gbit/s TX bandwidth, 40 Gbit/s RX bandwidth, 40 Gbit/s TX committed burst size, 40 Gbit/s TX excessive burst size, 40 Gbit/s TX committed information rate, 40 Gbit/s RX committed information rate, 40 Gbit/s TX peak information rate, 40 Gbit/s RX peak information rate, and 40 Gbit/s TX peak burst size. The UBBPf1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth, 100 Gbit/s RX bandwidth, 100 Gbit/s TX committed burst size, 100 Gbit/s TX excessive burst size, 100 Gbit/s TX committed information rate, 100 Gbit/s RX committed information rate, 100 Gbit/s TX peak information rate, 100 Gbit/s RX peak information rate, and 100 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one. The default values of these parameters are 1 Gbit/s. If the resource group is configured on a UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9, the bandwidth and rate need to be increased based on the actual networking.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UMPTa, UMPTb, UMDU or UTRPc can be configured with a maximum of 1 Gbit/s TX bandwidth, 1 Gbit/s RX bandwidth, 1 Gbit/s TX committed burst size, 1 Gbit/s TX excessive burst size, 1 Gbit/s TX committed information rate, 1 Gbit/s RX committed information rate, 1 Gbit/s TX peak information rate, 1 Gbit/s RX peak information rate, and 1 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The UMPTe/UMPTga can be configured with a maximum of 10 Gbit/s TX bandwidth, 10 Gbit/s RX bandwidth, 10 Gbit/s TX committed burst size, 10 Gbit/s TX excessive burst size, 10 Gbit/s TX committed information rate, 10 Gbit/s RX committed information rate, 10 Gbit/s TX peak information rate, 10 Gbit/s RX peak information rate, and 10 Gbit/s TX peak burst size. The UMPTg can be configured with a maximum of 25 Gbit/s TX bandwidth, 25 Gbit/s RX bandwidth, 25 Gbit/s TX committed burst size, 25 Gbit/s TX excessive burst size, 25 Gbit/s TX committed information rate, 25 Gbit/s RX committed information rate, 25 Gbit/s TX peak information rate, 25 Gbit/s RX peak information rate, and 25 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [Co-MPT,NodeB,eNodeB]The UCCU can be configured with a maximum of 10 Gbit/s TX bandwidth, 10 Gbit/s RX bandwidth, 10 Gbit/s TX committed burst size, 10 Gbit/s TX excessive burst size, 10 Gbit/s TX committed information rate, 10 Gbit/s RX committed information rate, 10 Gbit/s TX peak information rate, 10 Gbit/s RX peak information rate, and 10 Gbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one. The default values of these parameters are 1 Gbit/s. If the resource group is configured on a UCCU, the bandwidth and rate need to be increased based on the actual networking.

  • [NodeB,eNodeB,gNodeB]If the physical port overbooking switch is set to OFF, the updated bandwidth of a transmission resource group must be narrower than or equal to the physical bandwidth of the physical port on which the transmission resource group is carried.

  • [Co-MPT,NodeB]The UTRP can be configured with a maximum of 300 Mbit/s TX bandwidth and 300 Mbit/s RX bandwidth. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [eNodeB,gNodeB]If the LPSCHSW parameter is set to ENABLE, the physical port allocates a bandwidth to each of the associated resource groups based on their scheduling weights.

  • [eNodeB,gNodeB]If the UMPT/UMDU is the main control board, a maximum of two uplink tunnels can be configured with transmission resource groups. If the LMPT is the main control board, a maximum of one uplink tunnel can be configured with transmission resource groups. For other transmission boards, no tunnel can be configured with transmission resource groups.

  • [Co-MPT,eGBTS]If the UMPT/UMDU is the main control board, a maximum of two uplink tunnels can be configured with transmission resource groups. For other transmission boards, no tunnel can be configured with transmission resource groups.

  • [Co-MPT,eGBTS]The maximum specifications of a GTMUb are as follows: transmit bandwidth: 300 Mbit/s; receive bandwidth: 300 Mbit/s; transmit committed burst size: 600 Mbit/s; transmit excessive burst size: 600 Mbit/s; transmit committed information rate: 300 Mbit/s; transmit peak information rate: 300 Mbit/s; transmit peak burst size: 300 Mbit/s. If this parameter is set to a value greater than the maximum specifications, the maximum specifications take effect.

  • [Co-MPT,eGBTS]The maximum specifications of a GTMUc are as follows: transmit bandwidth: 300 Mbit/s; receive bandwidth: 300 Mbit/s; transmit committed burst size: 600 Mbit/s; transmit excessive burst size: 600 Mbit/s; transmit committed information rate: 300 Mbit/s; transmit peak information rate: 300 Mbit/s; transmit peak burst size: 300 Mbit/s. If this parameter is set to a value greater than the maximum specifications, the maximum specifications take effect.

  • [NodeB]The WMPT can be configured with a maximum of 300 Mbit/s TX bandwidth and 300 Mbit/s RX bandwidth, 600 Mbit/s TX committed burst size, 600 Mbit/s TX excessive burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

  • [NodeB]The rate unit of the transmission resource group to be added must be the same as those of other ATM-type transmission objects.

  • [NodeB]If BEAR of a transmission resource group is set to ATM, the bandwidth of the modified resource group must fulfill the bandwidth check rules. For details about how to check bandwidths, see the notes for the ADD AAL2PATH command.

  • [NodeB]If the UMPT/UMDU is the main control board, a maximum of two uplink tunnels can be configured with transmission resource groups. If the WMPT is the main control board, a maximum of one uplink tunnel can be configured with transmission resource groups. For other transmission boards, no tunnel can be configured with transmission resource groups.

  • [NodeB]If BEAR of a transmission resource group is set to IP, the bandwidth of the modified transmission resource group must be wider than or equal to the bandwidth of any IP path contained in the transmission resource group.

  • [NodeB]When configuring a transmission resource group whose bearing port type is Ethernet port or Ethernet trunk on a transmission board other than a UTRPc/UCCU/UBBPe/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9, set both the maximum TX and RX bandwidths of the transmission resource group to 300 Mbit/s.

  • [eNodeB]The LMPT board can be configured with a maximum of 360 Mbit/s TX bandwidth, 540 Mbit/s RX bandwidth, 400 Mbit/s TX committed burst size, 450 Mbit/s TX excessive burst size, 360 Mbit/s TX committed information rate, 540 Mbit/s RX committed information rate, 360 Mbit/s TX peak information rate, 540 Mbit/s RX peak information rate, and 400 Mbit/s TX peak burst size. The value is set to the maximum value supported by the board when it bigger than the maximum one.

The UBBPf1, UBBPg2, UBBPg3, UBBPg4, UBBPg5, UBBPg6, UBBPg7 or UBBPg9 can be configured with a maximum of 100 Gbit/s TX bandwidth. If the parameter is set to a value greater than the maximum TX bandwidth supported by a board, the maximum TX bandwidth supported by the board takes effect. For a WMPT and a UTRP (excluding UTRPa), this parameter does not specify the TX traffic shaping bandwidth of the transmission resource group that is carried on the PPP link.
