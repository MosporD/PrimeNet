Display E1/T1 Line Clock (DSP LINECLK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the running status of a specified E1/T1 line clock link.

Note

None.

Parameters

ID Name Description
LN Line Clock No.

Meaning: Indicates the number of the E1/T1 line clock link.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To query the status of an E1/T1 line clock link, run the following command:
DSP LINECLK:;
The result is shown as follows:
+++    0        2010-05-07 14:28:01
O&M    #631
%%DSP LINECLK:;%%
RETCODE = 0  Operation succeeded.

Display E1/T1 Line Clock State
------------------------------
      Line Clock No.  =  0
Link Available State  =  Unavailable
   Link Active State  =  Deactivated
           Port Type  =  E1T1
            Port No.  =  0
(Number of results = 1)


---    END

Output Description

Field Description

Line Clock No.

Indicates the number of the E1/T1 line clock link.

Link Available State

Indicates the availability of the E1/T1 line clock link. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.

Link Active State

Indicates the activation status of the E1/T1 line clock link. If the link is active, the E1/T1 line clock link is the current clock source of the system.

Port Type

Indicates the type of the port where the line clock link is located. The LTE currently does not support STM1 function.

Port No.

Indicates the number of the port where the E1/T1 line clock link is configured.
