Modify Location (MOD LOCATION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify the data record of the location.

Note

None.

Parameters

ID Name Description
LOCATIONNAME Location Name

Meaning: Indicates the location name of the base station.

Unit: None

Actual Value Range: 1~64 characters

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
MODE Mode

Meaning: Indicates the configuration mode of the base station longitude and altitude. This parameter can be set to AUTO or MANUAL. In automatic mode, the base station longitude and altitude are obtained from the GPS antenna or UE, and the configured longitude and latitude information is overwritten. In manual mode, the base station longitude and altitude are configured manually.

GUI Value Range: AUTO(Auto), MANUAL(Manual)

Unit: None

Actual Value Range: AUTO, MANUAL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

-Configuration constraints:

Dd indicates the degree ranging from -90 to +90, mm indicates the minute ranging from 0 to 59, and ss.ssss indicates the second ranging from 0 to 59.9999.
