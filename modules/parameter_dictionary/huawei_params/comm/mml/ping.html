Ping (PING)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to verify a connection or to check the quality of a connection.

Note

  • The PING, PING6, TRACERT, TRACERT6, CFMTRACE, CFMPING, and UDPECHO commands cannot be executed simultaneously on one board.

  • If CONTPING is set to ENABLE, press Ctrl+Q or run the STP PATHCHK command to terminate the PING command.

  • When the Appoint Interface parameter is set to YES(Yes), the Port Type parameter can be set to TUNNEL(Tunnel) only for the WMPT, UMDU and UMPT boards.

  • In the same routing domain, if the Destination IP parameter is set to the local IP address when the PING command is executed, the source IP route meeting the following condition cannot be configured: The source IP address of this source IP route is the same as the Source IP or Destination IP parameter in the PING command.

  • When the PING command is executed to the specified egress port, the specified egress port must be configured on the same board as the source IP address.

  • If Next Hop IP is set to 255.255.255.255 in a PING command, the next-hop IP address is not specified during execution of the PING command.

  • When the PING command is executed, the egress port displayed on the GUI of the first packet prevails.

  • If the source IP address in the PING command and the egress port for transmitting a PING packets are not deployed on the same board, the PING packets is forwarded to the board providing the egress port through the backplane, and therefore the information about the port for transmitting the PING packets is not displayed.

  • If the source IP address and destination IP address are configured on the same board in the PING command, PING packets are processed according to the board internal communication mechanism, and therefore information about the egress port for transmitting PING packets is not displayed.

  • If the egress port is specified in the PING command, the specified egress port information is consistent with the displayed information about the external port for PING packets.

  • The ping packet length for a successful ping depends on the maximum transmit unit size, fragment reassembly capability, maximum receive unit size, and difference in ICMP outer protocol encapsulation. The ping packet length for a successful ping varies with hardware and scenario.

  • When the Ethernet CI port is used as the transmission port (that is, the port directly connecting the base station to an external device), packets are fragmented based on the maximum transmission unit of the Ethernet CI port. In other cases, packets are fragmented based on the maximum transmission unit of the transmission port, and you are advised not to enable the DFSwitch when running the PING command. Otherwise, the PING command may time out when the packet length exceeds the maximum transmission unit of the Ethernet CI port or tunnel.

  • [NodeB,eNodeB,gNodeB]If the route corresponding to the destination IP address is a tunnel route, the source IP address must be specified.

  • [NodeB,eNodeB,gNodeB]If the local IP address of a remote maintenance channel is the same as a device IP address and is used as the source IP address for a PING operation, the slot number for the PING operation must be the same as that of the board where the device IP address is configured.

  • [Co-MPT,eNodeB,gNodeB]If a base station uses the sub-interface networking, the enhanced PING connectivity check is not supported.

Meaning: Indicates whether a packet is segmented when its size exceeds the maximum transmission unit (MTU). If the total length of the ping packet exceeds the maximum transmission unit allowed by the base station, this ping packet fails to be transmitted.

Example

To perform PING detection with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Source IP: 192.168.2.2, Destination IP: 192.168.2.3, Continuing Ping: DISABLE, Appoint Interface: NO:
PING: SN=7, SRCIP="192.168.2.2", DSTIP="192.168.2.3", CONTPING=DISABLE, APPTIF=NO;
