Add BDU (ADD BDU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a boost distribution unit (BDU).

Note

  • If the SC48200 or EPS4815 is configured, do not install a BDU. If other power systems are configured, ten BDUs are installed in slots 1 to 10.

  • Before adding a BDU, ensure that a PMU in the same cabinet and subrack is configured. If there is no such PMU, run the ADD PMU command to add a PMU. Otherwise, the ADD BDU command fails to be executed.

  • If the BDU to be added cannot be managed by the PMU, execution of this command will fail. The BDU management capability of a PMU can be queried by running the DSP PMU command.

Meaning: Indicates the number of the subrack where the BDU is located.

Unit: None

Meaning: Indicates the number of the slot where the BDU is located.

GUI Value Range: 1~10

Unit: None

Actual Value Range: 1~10

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
BDUTYPE BDU Type

Meaning: Indicates the device type of the BDU. If this parameter is set to DEFAULT, the system does not check the consistency between the configuration type and the physical type of the device. The device runs according to the actual type. If this parameter is set to SDU, HSU, or BDU, the system checks whether the type of the SDU, HSU or BDU in use is consistent with the configuration.

GUI Value Range: DEFAULT(DEFAULT), BDU(BDU), HSU(HSU), SDU(SDU)

Unit: None

Actual Value Range: DEFAULT, BDU, HSU, SDU

MML Default Value: DEFAULT(DEFAULT)

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
VOLADJMODE Voltage Adjustment Mode

Meaning: Indicates the voltage adjustment mode of the SDU. The value ADAPTIVE indicates that the system adaptively adjusts the output voltage based on the actual load of the system. The value FIXED indicates that the output voltage is always 57 V.

GUI Value Range: ADAPTIVE(ADAPTIVE), FIXED(FIXED)

Unit: None

Actual Value Range: ADAPTIVE, FIXED

MML Default Value: ADAPTIVE(ADAPTIVE)

Recommended Value: ADAPTIVE(Adaptive)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Example 1. To add a BDU with the parameters as follows: Cabinet No.: 0, Subrack No.: 7, Slot No.: 1, BDU Type: BDU, run the following command:
ADD BDU: CN=0, SRN=7, SN=1, BDUTYPE=BDU;

Example 2. To add a BDU with the parameters as follows: Cabinet No.: 0, Subrack No.: 7, Slot No.: 1, BDU Type: SDU, Voltage Adjustment Mode: FIXED, run the following command:
ADD BDU: CN=0, SRN=7, SN=2, BDUTYPE=SDU, VOLADJMODE=FIXED;
