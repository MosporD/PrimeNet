Set Connection Type (SET CONNTYPE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the type of connection between an NE and a client.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • Before setting Connection Type to SSL(Only SSL Connection), initiate an SSL connection to the NE. If the SSL connection succeeds, you can set Connection Type to SSL(Only SSL Connection). If the SSL connection fails, setting Connection Type to SSL(Only SSL Connection) may interrupt the maintenance channel.

  • The operation might interrupt the connection with the client when the connection type of destination NE is not consistent with the connection type of MAE.

  • It is recommended that CFM CB be executed to enable the rollback function.

Parameters

ID Name Description
CONNTYPE Connection Type

Meaning: Indicates the connection type supported by the NE. Compatible connection mode indicates that the NE supports both the common connection mode and the SSL connection mode. When the connection type is set to ALL(Compatible Connection), NE security risks will be increased if a client accesses the NE in the plaintext mode. Set this parameter to a proper value.

GUI Value Range: ALL(All Type), SSL(Only SSL Connection)

Unit: None

Actual Value Range: ALL, SSL

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the connection type to ALL, run the following command:
SET CONNTYPE: CONNTYPE=ALL;
