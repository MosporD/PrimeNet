Set Certificate Validity Check Task (SET CERTCHKTSK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the certificate validity checking task.

Note

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, Only one CERTCHKTSK MO can be configured.

  • Board specifications: A UMPT/UMDU/LMPT/GTMUc/UTRPc/UCCU/UBBPe series (except UBBPe15)/LCOP/UBBPf series/UBBPF series/UBBPg series board supports a maximum of one certificate validity check task.

  • Do not frequently execute this command. Before running this command, ensure that the value of the Status of CMP session parameter is neither RUNNING nor PENDING. Otherwise, certificates cannot be updated. You can run the DSP CMPSESSION command to query the value of the Status of CMP session parameter.

  • This command is executed to check the validity of trust certificates, cross certificates, and device certificates.

  • The certificate validity check is restarted when this command is executed to change settings of parameters.

  • A certificate that is being used in an IKE negotiation cannot be updated.

  • In the multi-PKI scenario, using the PROXY method to update a certificate is not supported.

  • For a device certificate that is about to expire and is being used, this command can be executed to update this device certificate using the corresponding update method.

  • When this parameter is set to OFF, the system does not check whether a preconfigured Huawei factory certificate is about to expire or has expired, and no alarm is reported even if a preconfigured Huawei factory certificate is about to expire or has expired.

  • [Co-MPT,NodeB,eNodeB,gNodeB]Do not execute this command to trigger an automatic certificate update within 2 minutes after the MOD APPCERT command has been executed. Otherwise, the automatic certificate update may fail.

Parameters

ID Name Description
ISENABLE Certificate Validity Period Checking

Meaning: Indicates whether a task of certificate validity checking is started.

Disuse statement: This parameter will be deleted in later versions. (In the current version, configuration synchronization and configuration delivery are still supported but this parameter does not take effect any more.) The certificate validity check function is enabled by default. To mitigate the risk, do not set the Certificate Validity Period Checking parameter in the CERTCHKTSK MO to DISABLE(Disable). If this parameter is set to DISABLE, the values of other parameters remain the same as the settings that have taken effect the last time.

GUI Value Range: DISABLE(Disable), ENABLE(Enable)

Unit: None

Actual Value Range: DISABLE, ENABLE

MML Default Value: None

Recommended Value: ENABLE(Enable)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
PERIOD Checking Period

Meaning: Indicates the interval between certificate validity checking tasks.

GUI Value Range: 1~15

Unit: day

Actual Value Range: 1~15

MML Default Value: None

Recommended Value: 7

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a CERTCHKTSK MO, PERIOD must be less than ALMRNG.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a CERTCHKTSK MO, PERIOD must be less than VENDORALMRNG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
ALMRNG Alarm Threshold

Meaning: Indicates the threshold for a certificate expiration alarm. If the base station detects that the interval between its current time and the expiration date of an activated device certificate is shorter than the threshold, an Imminent Certificate Expiry alarm is reported.

GUI Value Range: 7~180

Unit: day

Actual Value Range: 7~180

MML Default Value: None

Recommended Value: 30

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a CERTCHKTSK MO, PERIOD must be less than ALMRNG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
UPDATEMETHOD Update Method

Meaning: Indicates the method for updating a certificate that has expired or is about to expire. There are three methods: PROXY, CMP and MANUAL. If the PROXY method is used, the BS uses the MAE as the proxy to update the certificate from the Certificate Authority (CA). If the CMP method is used, the BS directly updates the certificate from the CA. If the MANUAL method is used, the certificate needs to be updated manually instead of automatically.

GUI Value Range: PROXY(Proxy), CMP(CMP), MANUAL(Manual)

Unit: None

Actual Value Range: PROXY, CMP, MANUAL

MML Default Value: None

Recommended Value: CMP(CMP)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
AUTOREAPPLYSW Automatic Certificate Reapplication Switch

Meaning: Indicates whether automatic certificate application is supported during a certificate server switchover. If this switch is turned on, the base station automatically applies for a certificate when detecting a certificate server switchover in the case of site deployment or IKE negotiation failure.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
VENDORALMRNG Preconfigured Certificate Expire Threshold

Meaning: Indicates the threshold for the preconfigured certificate to expire. When the interval between the expiration time of a preconfigured device certificate in use and the current time of the base station is less than the threshold, the base station reports an alarm indicating that the certificate is about to expire.

GUI Value Range: 7~180

Unit: day

Actual Value Range: 7~180

MML Default Value: None

Recommended Value: 180

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]In a CERTCHKTSK MO, PERIOD must be less than VENDORALMRNG.

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
VENDORCERTCHKSW Preconfigured Certificate Verification Switch

Meaning: Indicates whether to perform a validity check on a Huawei preconfigured certificate. For example, check whether a preconfigured certificate is about to expire, has expired, is damaged, or is lost, and whether the certificate on an RRU is about to expire. When this parameter is set to OFF, the system does not check the validity of a preconfigured certificate. The system does not report an alarm indicating that a preconfigured certificate is about to expire or has expired even if the preconfigured certificate is about to expire or has expire. If an alarm indicating that a preconfigured certificate is about to expire or has expired already exists, the system automatically clears the alarm. When this parameter is set to ON, verification is required. When the threshold is reached, an alarm indicating that a preconfigured certificate is about to expire or has expired is reported.

GUI Value Range: OFF(Off), ON(On)

Unit: None

Actual Value Range: OFF, ON

MML Default Value: None

Recommended Value: ON(On)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To add a CERTCHKTSK with the parameters as follows: Checking Period: 7, Alarm Threshold: 30, Update Method: CMP, Automatic Certificate Reapplication Switch: ON, Preconfigured Certificate Expire Threshold(day):180, Preconfigured Certificate Verification Switch:ON, run the following command:
SET CERTCHKTSK: PERIOD=7, ALMRNG=30, UPDATEMETHOD=CMP, AUTOREAPPLYSW=ON, VENDORALMRNG=180, VENDORCERTCHKSW=ON;
