Remove Mapping from IP to Transmission Resource Group (RMV IP2RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to remove a mapping between the IP address and the transmission resource group.

Note

Deleting the IP2RSCGRP MO during service operation affects the actual transmission resource group selected by the service and may cause service interruption during resource group switching.

Parameters

ID Name Description
MAPIDX Mapping Index

Meaning: Indicates the mapping between IP addresses and Transport Resource Groups.

Disuse statement: This parameter will be deleted in later versions. In the current version, this parameter can be configured and takes effect when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to OLD, and this parameter cannot be configured and is replaced by the IP Transmission Resource Group ID parameter in the IP2IPRSCGRP MO when the Transmission Configuration Mode parameter in the GTRANSPARA MO is set to NEW. Therefore, avoid using this parameter.

GUI Value Range: 0~127

Unit: None

Actual Value Range: 0~127

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To remove a mapping between the IP address and the transmission resource group with the parameters as follows: Mapping Index: 0, run the following command: 
RMV IP2RSCGRP: MAPIDX=0;
