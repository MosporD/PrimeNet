Add Location (ADD LOCATION)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a record of the location.

Note

  • The longitude and altitude of a location cannot be automatically configured using the GPS of the RRU or CGPS.

  • When the positioning method is GPS, the base station needs to periodically query the longitude and latitude information from the GPS antenna. It takes a maximum of 20 minutes to obtain the correct longitude and latitude information. When the longitude and latitude information changes, the database needs to be updated. In this case, the value of the Current CB Status parameter in the output of the DSP CB command is NOT_CONFIRM.

  • If the positioning method is GPS, ensure the value of the PosStandard parameter is included in the modes using the GPS clock. Otherwise, the base station cannot automatically obtain its longitude and altitude from the GPS antenna.

  • If the positioning method is POSITIONING_BY_UE, the LOCATION MO will be deleted 24 hours later when no location name in the RRU MO can correspond to the LOCATION MO or its corresponded RRU MO is deleted.

  • When the MDT UE-based RRU positioning is started, if the corresponding RRU MO is not bound to the LOCATION MO, a LOCATION MO is automatically created and the RRU MO is bound to the LOCATION MO. If the corresponding RRU MO has been bound to the LOCATION MO, the RRU location information is updated to the LOCATION MO. The database needs to be updated. In this case, the value of the Current CB Status parameter in the output of the DSP CB command is NOT_CONFIRM.

MODE Mode

Meaning: Indicates the configuration mode of the base station longitude and altitude. This parameter can be set to AUTO or MANUAL. In automatic mode, the base station longitude and altitude are obtained from the GPS antenna or UE, and the configured longitude and latitude information is overwritten. In manual mode, the base station longitude and altitude are configured manually.

Example

To add location information with the parameter as follows: LOCATIONNAME: "binjiang", MODE: MANUAL, GCDF: Degree, LATITUDEDEGFORMAT: 11, LONGITUDEDEGFORMAT: 11, run the following command:
ADD LOCATION: LOCATIONNAME="binjiang", MODE=MANUAL, GCDF=Degree, LATITUDEDEGFORMAT=11, LONGITUDEDEGFORMAT=11;
