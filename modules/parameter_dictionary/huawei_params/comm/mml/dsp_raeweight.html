Display RAE Weighting Factor Information (DSP RAEWEIGHT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the weighting factor information of the Remote eAntenna Extension (RAE).

Note

  • The DSP RAEWEIGHT command fails to be executed when the RAE weighting factor files are damaged or do not exist. If you need to query information about the RAE weighting factor files, run the DSP RAEFILE command.

  • You can set the Protocol Type parameter by following the instructions in the related documentation provided by antenna manufacturers. Before setting other parameters, you must run this command with the Query Type parameter set to the value corresponding to a parameter to be set.

  • When the Version parameter is set to 2-DANT, the values of the Vertical BeamWidth(0.1degree) or Weight Factor Group ID fields is NULL if RAE subunits do not support the query by weight group and port information or the query of the vertical bandwidth. You can enter any values for the vertical bandwidth and weight factor group ID if necessary when you want to query by factors other than the vertical beamwidth and weight factor group.

Output Description

Field Description

Device No.

Indicates the device number of the RAE.

Subunit No.

Indicates the number of the RAE subunit, which starts from 1.

Subunit Name

Indicates the name of the RAE subunit. The name of the RAE subunit is optional, but the name configured for each RAE subunit must be unique.

Minimum frequency(0.1 MHz)

Indicates the minimum frequency in the specified frequency band.

Maximum frequency(0.1 MHz)

Indicates the maximum frequency in the specified frequency band.

Vertical BeamWidth(0.1degree)

Indicates the vertical beamwidth of RAE subunit.

Horizontal BeamWidth(degree)

Indicates the horizontal beamwidth of RAE subunit.

MinAzimuth(degree)

Indicates the minimum horizontal azimuth of RAE subunit.

MaxAzimuth(degree)

Indicates the maximum horizontal azimuth of RAE subunit.

StepAzimuth(degree)

Indicates the stepping horizontal azimuth of RAE subunit.

MinTilt(0.1degree)

Indicates the minimum antenna tilt of the RAE subunit.

MaxTilt(0.1degree)

Indicates the maximum antenna tilt of the RAE subunit.

StepTilt(0.1degree)

Indicates the stepping antenna tilt of the RAE subunit.

Azimuth(degree)

Indicates the horizontal azimuth of RAE subunit.

Tilt(0.1degree)

Indicates the antenna tilt of the RAE subunit.

Weight Factor Group

Indicates the number of weighting factor groups of a remote antenna extension (RAE) subunit. The value of this parameter is defined by RAE manufactures and provided in antenna-related documents.

Weight Factor Group ID

Indicates the weighting factor group ID of RAE subunit.

Port No.

Indicates the sequence number of the port information reported by the RAE.

Amplitude(%)

Indicates the amplitude of antenna signals.

Phase(0.1degree)

Indicates the phase of antenna signals.

Polar Type

Indicates the polarization type of the virtual antenna port to which the RAE subunit is connected.

Port Flag

Indicates the port flag of RAE subunit.
