Display E1T1 Port Status (DSP E1T1)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to query the E1/T1 port status.

Note

  • [Co-MPT,NodeB,eGBTS,eNodeB]If the clock modes at the E1/T1 ports of two cascaded BSs do not meet the rules specified in the meaning of the clock mode, the link running status will be reported as abnormal.

  • [Co-MPT,NodeB,eGBTS,eNodeB]In T1 working mode, when the FrameFormat parameter is set to T1_SUPER_FRAME, the physical loopback status cannot be correctly detected.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If Cabinet No., Subrack No., and Slot No. are not specified in active/standby mode, the E1/T1 port information about all physical slots is displayed.

  • [Co-MPT,NodeB,eGBTS,eNodeB]If Cabinet No., Subrack No., and Slot No. are specified in active/standby mode, the E1/T1 port information about only the active and standby boards can be queried. The specified slot number is the logical slot number.

  • [Co-MPT,NodeB,eGBTS,eNodeB]On the same board, the working mode configured for all ports can take effect for single-port E1/T1.

  • [Co-MPT,NodeB,eGBTS,eNodeB]The working mode queried by the LST E1T1 command may differ from that queried by the DSP E1T1 command. ‎

Example

To list the status of the E1/T1 port with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 7, Subboard Type: BASE_BOARD, Port Selection: ALLPORT, run the following command: 
DSP E1T1: CN=0, SRN=0, SN=7, SBT=BASE_BOARD, PS=ALLPORT;

Output Description

Field Description

Cabinet No.

Indicates the cabinet number of the board where an E1/T1 port is located.

Subrack No.

Indicates the subrack number of the board where an E1/T1 port is located.

Slot No.

Indicates the slot number of the board where an E1/T1 port is located.

Subboard Type

Indicates the type of sub-board on the board where the E1/T1 port is located.

Port No.

Indicates the number of the E1/T1 port.

Link Running Status

Indicates the link running status. The link running status is classified into Available, Local Loop, Remote Loop, Physical Loop, Remote Time Slot Loop, Loss of Signal, Alarm Indication Signal, Remote Alarm Indication, Loss of Frame Alignment, Loss of Multiframe Alignment, Slip, Backup, and Other Fault.

Actual Work Mode

Indicates the actual work mode of the E1/T1 port.

Actual Frame Format

Indicates the actual frame format of the E1/T1 port.

Actual Line Code

Indicates the actual line coding mode of the E1/T1 port.

Clock Mode

Indicates the clock mode of the E1/T1 port.

1. If the BS extracts the line clock from the E1/T1 port, the clock mode of the E1/T1 port must be set to SLAVE. If the BS provides the line clock for the lower-level equipment through the E1/T1 port, the clock mode of the E1/T1 port must be set to MASTER. Otherwise, the line clock may fail to work properly.

2. When the E1/T1 port provides an 8K clock reference for the transmission interface board, the clock mode of the E1/T1 port must be set to SLAVE.

3. The clock modes of E1/T1 ports used by an inter-board MLPPP group cannot be all set to SLAVE.

Link Test Execution Status

Indicates whether to perform the link test and the test type. The test types are classified into No Test, Offline Test, and Online Test.

Used Flag

Indicates whether the E1/T1 port is used.

Loop Left Time(min)

Indicates the remaining loop time of the E1/T1 port.
