Add Board (ADD BRD)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add a board. Only the boards in the BBU can be added by running this command. When the type of the board to be added is FAN, the temperature control mode ID for fan speed adjustment can be configured.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • A board is automatically reset after being added.

  • If the subrack housing the board does not exist, the board fails to be added.

  • Only one USCU board can be configured for a BS.

  • Only one UTRPc board can be configured for a BS.

  • Only one UCCU board can be configured for a BS.

  • The Cell Channel Number Extension parameter is supported only by the UBBP and UMDU and this parameter takes effect only for the UBBPd9, UBBPdc and BBU3910a9. In addition, the UBBPd9, UBBPdc and BBU3910a9 are reset after this parameter is modified.

  • Board to be added must comply with the base station hardware plan. Otherwise, the ongoing services of the base station or the remote maintenance channel may be interrupted.

  • The CPRI port type of a UBBPei must be set to XCI_QSFP.

  • The CPRI port type of a UBBPem, UBBPf1, or UBBPf0 must be set to CPRI_QSFP.

  • In a BBU3900, the UBBPei board can be configured only in slots 0 to 3.

  • When the main control working mode of a TD-SCDMA main control board is the TDS evolution mode, the TD-SCDMA main control board will be converted to a clock board and TDS services will remain interrupted. The conversion takes a long time.

  • Ensure that the TD-SCDMA main control board is available before adding a main control board working in TDS evolution mode.

  • The UBBPem, UBBPf series or UBBPF series cannot be installed in slot 4 or 5 of the BBU3910 subrack in high-temperature countries or outdoor areas (maximum outdoor temperature > 45 degree Celsius). This prevents alarms or power-off protection caused by high board temperature.

  • The temperature control mode ID for fan speed adjustment can be configured only when the board type is FAN.

  • The fan board can be configured in slot 17 only when the subrack type is BBU5900A.

  • After the peer main control board is added, the system may enter the active/standby state, and the data on local main control board may override that on the peer main control board. When the system is performing active/standby backup, do not delete, remove, insert, or reset the standby board. You can run the DSP BKPSTATUS command to query the active/standby backup status of boards.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When a UTRP is being added, note the following mappings between the barcode and sub-board of the UTRP: UTRP2 to UEOC, UTRP3/UTRPa to UAEC, UTRP4 to UIEC, UTRP6 to UUAS, UTRP9 to UQEC, and UTRPc to UTRPc. The UTRPa and UTRPc do not have any sub-board in terms of hardware, but SubBoard Type must be configured for them. Set this parameter to UAEC for a UTRPa and UTRPc for a UTRPc.

  • [Co-MPT,NodeB]Among all baseband processing boards, only the WBBPd supports the hybrid working mode.

WM Work Mode

Meaning: Indicates the working mode of the baseband processing board. There are sixteen working modes: FDD, TDD, HYBRID, TDD_ENHANCE, TDD_8T8R, TDD_TL, FDD_ATG, FDD_NBIOT, NBIOT, FDD_NBIOT_ENHANCE , FDD_NBIOT_CUSTOM, NORMAL, HYBRID_BALANCE, HYBRID_MMCELL_ENHANCE, HYBRID_NORMALCELL_ENHANCE, SPEC_MODE1. The Frequency Division Duplex (FDD) mode carries the traditional voice and data services. TDD is short for Time Division Duplex. The HYBRID mode is a combination of FDD and IMB modes. In Integrated Mobile Broadcasting (IMB) mode, the baseband processing board carries the mobile TV services. The value TDD_ENHANCE indicates the TDD mode integrated with the BeamForming (BF) function. The BF function provides the data transmission service in transmission modes 7 and 8 defined in protocols. For details, see 3GPP TS 36.213. In TDD_8T8R mode, the baseband processing board supports TD-LTE single-mode 8T8R. In addition, the baseband processing board supports the BF function and CPRI specifications are applied between the BBU and RRU. In TDD_TL mode, the baseband processing board supports the TD-LTE&TD-SCDMA dual mode and the TD-LTE single mode. In addition, the baseband processing board supports 8T8R BF and 2T2R Multiple-Input Multiple-Output (MIMO) and CMCC TD-LTE IR specifications are applied between the BBU and RRU. In FDD_ATG mode, the baseband processing board supports communication between Air and Ground. The FDD_ATG mode applies only to communication between air and ground. The value FDD_NBIOT indicates that the baseband processing board supports both LTE FDD and NB-IoT. The value NBIOT indicates that the baseband processing board supports NB-IoT. The value FDD_NBIOT_ENHANCE indicates that the baseband processing board supports both LTE FDD and NB-IoT and the NB-IoT capability is enhanced. The value FDD_NBIOT_CUSTOM indicates customized FDD&NB-IoT dual-mode specifications. NORMAL indicates the normal mode. HYBRID_BALANCE indicates the mixed configuration balancing mode. HYBRID_MMCELL_ENHANCE indicates the mixed configuration enhanced MM mode. HYBRID_NORMALCELL_ENHANCE indicates the mixed configuration enhanced common cell mode. SPEC_MODE1 indicates specification mode 1 of a specific BBP.

GUI Value Range: FDD(Frequency Division Duplex), HYBRID(HYBRID), TDD(Time Division Duplex), TDD_ENHANCE(Support TDD BF), TDD_8T8R(Support CPRI ports), TDD_TL(Support CMCC TDS and TDL dual modes), FDD_ATG(Support air-ground communication), FDD_NBIOT(FDD_NB-IoT), NBIOT(NB-IoT), FDD_NBIOT_ENHANCE(FDD_NB-IoT Multi-carrier), FDD_NBIOT_CUSTOM(FDD_NB-IoT Customization), NORMAL(NORMAL), HYBRID_BALANCE(HYBRID_BALANCE), HYBRID_MMCELL_ENHANCE(HYBRID_MMCELL_ENHANCE), HYBRID_NORMALCELL_ENHANCE(HYBRID_NORMALCELL_ENHANCE), SPEC_MODE1(SPEC_MODE1)

Meaning: Indicates the CPRI extension mode. If this parameter is set to FRONTPANELEXTENSION, the transmission capability of a single fiber optic cable is enhanced. If this parameter is set to FRONTPANELEXTENSION, the cable can transmit data for TDD or FDD cells only when CPRI Compression is set to NORMAL_COMPRESSION. If the value of this parameter for a board is modified and the parameter setting takes effect, the board will be automatically reset.

For example, if the Working Standard parameter of a UBBPe6 is set to UMTS&LTE and the Standard Ratio parameter is set to FDD_ENHANCE(FDD Enhance), the specifications of LTE FDD cells increase and the specifications of UMTS cells decrease.

TCMODE Temperature Control Mode

Meaning: Indicates the mode that the fan speed adjustment adopts.

Mode 0 is the default mode, which achieves balance in system power consumption, noise, and temperature control. It applies to most scenarios.

Inappropriate configuration of this parameter may lead to serious results such as high noise or service interruption on the RF modules due to overtemperature. You need to contact Huawei technical support before configuring this parameter.

You can run the DSP TCMODE command to query the number and description of the temperature control modes supported by the base station.

After configuring this parameter, you can run the DSP FAN command to check whether the temperature control mode in the command output is consistent with the configuration.

If yes, the configuration is successful. If no, the configuration fails and the system adopts the default mode (mode 0).

The reasons for the configuration failure and countermeasures are as follows:

1. The FAN version does not support the temperature control mode configuration.

2. The curve corresponding to the configured temperature control mode is incorrect and the configuration cannot take effect on the FAN. You need to contact the Huawei technical support.
