Add Mapping from IP to Transmission Resource Group (ADD IP2RSCGRP)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to add mapping between an IP address and a transmission resource group. The mapping between an IP address and a transmission resource group is the mapping between the destination IP address of the passing-by data or local OM data (over IP transmission)/signaling data and a transmission resource group.

Note

  • System specifications: If the WMPT/UMPT/LMPT/GTMUb/GTMUc is the main control board, a maximum of 128 entries of mapping from IP addresses to transmission resource groups can be configured. If the UMDU is the main control board, a maximum of 32 entries of mapping from IP addresses to transmission resource groups can be configured.

  • Board specifications: A maximum of 32 entries of mapping from IP addresses to transmission resource groups can be configured on a UMPT/UMDU/LMPT/UTRPc/UTRP (subboard type: UEOC/UQEC/UIEC/UAEC). A maximum of 16 entries of mapping from IP addresses to transmission resource groups can be configured on a WMPT. A maximum of 8 entries of mapping from IP addresses to transmission resource groups can be configured on a GTMUb/GTMUc.

  • OM flow cannot be joined into the backplane transmission resource group on the UMPT board.

  • In a security scenario, the passing-by data or local OM/signaling data (over IP transmission) is encrypted and sent to the security gateway and therefore the destination IP address can only be the address of the peer security gateway.

  • When the user does not add mapping between an IP address and a transmission resource group, data are carried in the default ip transmission resource group with the actual service outbound interface.

  • [Co-MPT,eGBTS,eNodeB,gNodeB]System specifications: A maximum of 32 IP-to-transmission-resource-group mapping relations can be configured in each transmission resource group.

  • [Co-MPT,NodeB,eGBTS]OM flow cannot be joined into the transmission resource group on the WMPT/UTRP/GTMUb board.

  • [NodeB]A maximum of 16 IP-to-transmission-resource-group mapping relations can be configured in each transmission resource group.

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]DSTIP in an IP2RSCGRP MO must be a valid IP address of class A, B, or C. In addition, it cannot be set to 0.x.x.x or 127.x.x.x.

Example

To add mapping between an IP address and a transmission resource group with the parameters as follows: Mapping Index: 0, Slot No.: 7, Subboard Type: BASE_BOARD, Bearing Port Type: ETH, Destination IP: 10.52.21.0, Mask: 255.255.255.0, run the following command: 
ADD IP2RSCGRP: MAPIDX=0, SN=7, SBT=BASE_BOARD, PT=ETH, DSTIP="10.52.21.0", DSTMASK="255.255.255.0";
