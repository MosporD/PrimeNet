Modify Backplane Tunnel (MOD BACKTUNNEL)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to modify a backplane tunnel.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

This operation may interrupt the services or OM channels carried on this backplane tunnel. It is recommended that you determine whether to enable the automatic configuration data rollback function depending on scenarios. For details, see the help of the CFM CB command.

Example

To modify the configurations of a backplane tunnel with the parameters as follows: Port ID: 0, Source Cabinet No.: 0, Source Subrack No.: 0, Source Slot No.: 7, Destination Cabinet No.: 0, Destination Subrack No.: 0, Destination Slot No.: 6, run the following command: 
MOD BACKTUNNEL: PORTID=0, SCN=0, SSRN=0, SSN=7, DCN=0, DSRN=0, DSN=6;
