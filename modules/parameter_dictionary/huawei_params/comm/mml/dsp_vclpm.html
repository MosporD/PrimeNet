Display VCL Performance Measurement Result (DSP VCLPM)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to list the VCL Performance Monitoring (PM) result, including information about the PM activation state, statistics about lost cells, statistics about miss-inserted cells, and VCL application information.

Note

  • [NodeB]If a VCL to be queried is not activated, no information can be obtained.

  • [NodeB]Only the PM result of a VCL that carries an SAAL link, IPoA PVC, or AAL2 path can be queried.

  • [NodeB]Only the VCL whose PM function is activated either actively or passively can be queried by this command.

  • [NodeB]VCLs whose PM functions are activated actively can be queried in batch. Those VCLs whose PM functions are activated passively can only be queried by the user-specified criteria.

Example

To list the status of VCL PM with the parameters as follows: Type of the VCL: SAALLINK, SAAL Link No.: 0, Clear Statistic: YES, run the following command:
DSP VCLPM: LNKT=SAALLINK, SAALNO=0, CLEAR=YES;
The result is shown as follows:

Output Description

Field Description

Type of the VCL

Indicates the type of VCL.

SAAL Link No.

Indicates the number of the SAAL link.

Status

Indicates the state of VCL PM.

Activation Direction

Indicates the activation direction of VCL PM.

PM Frame Interval

Indicates the time interval between PM frames of VCL PM.

Number of Cells Tx

Indicates the VCL PM statistics about the number of cells on the TX channel.

Number of Discarded Cells Tx

Indicates the VCL PM statistics about the number of discarded cells on the TX channel.

Number of Disinserted Cells Tx

Indicates the VCL PM statistics about the number of mis-inserted cells on the TX channel.

Number of Error Cells Tx Checked by BIP16

Indicates the VCL PM statistics about the number of error cell blocks checked by BIP16 on the TX channel.

Number of Cells Rx

Indicates the VCL PM statistics about the number of cells on the RX channel.

Number of Discarded Cells Rx

Indicates the statistics about the number of discarded cells on the RX channel.

Number of Disinserted Cells Rx

Indicates the statistics about the number of mis-inserted cells on the RX channel.

Number of Error Cells Rx Checked by BIP16

Indicates the VCL PM statistics about the number of error cell blocks checked by BIP16 on the RX channel.
