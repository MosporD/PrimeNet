Set Time (SET TIME)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the current date and time of the NE. The date and time can be modified separately.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • When executing this command, set either DATE or TIME, or both the parameters.

  • Exercise caution when changing the time of the NE. Set the time of the NE only when no external time source is available because changes of the time affect the time of alarm recording, log recording, and performance data.

  • When time synchronization is enabled, the time set by this command will be updated automatically.

  • If DATE or TIME is not specified, the local date or time of the NE is used by default.

Parameters

ID Name Description
DATE Date

Meaning: Indicates the date to be set for the NE.

The format is as follows: YYYY-MM-DD. For example, 2006-09-08 indicates September 8th of 2006.

GUI Value Range: 2000-01-01~2033-12-31

Unit: None

Actual Value Range: 2000-01-01~2033-12-31

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R
TIME Time

Meaning: Indicates the time to be set for the NE.

The format is as follows: HH:MM:SS. For example, 10:20:05.

GUI Value Range: 00:00:00~23:59:59

Unit: None

Actual Value Range: 00:00:00~23:59:59

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N, R

Example

To set the time of the NE with the parameters as follows: Date: 2009-09-08, Time: 11:05:02, run the following command:
SET TIME: DATE=2009&09&08, TIME=11&05&02;
