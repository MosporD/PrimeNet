Start RRU/RFU Health Check (STR RRUCHK)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to start a health check on a board on an RRU chain/ring. The health check involves the internal capability, external configurations, and current status of the board.

Note

  • To view the results of a health check on a board on an RRU chain/ring, upload the one-click log of the board ten minutes after running this command. For details about how to upload the one-click log of a board, see the help information about ULD FILE command.

  • [Co-MPT,eNodeB,gNodeB]If a board on an RRU chain/ring is not working in LTE TDD mode, the health check results are included in the one-click log of the RRU/RFU. For details about how to upload the one-click log of a board, see the help information about ULD FILE command.

  • [Co-MPT,eNodeB,gNodeB]If a board on an RRU chain/ring is working in LTE TDD mode, the health check results are included in the RF test log of the RRU. In this case, run the ULD FILE command with the Source File Type parameter set to RFSTUFF and the Cabinet No., Subrack No., and Slot No. parameters specified to upload the RF test log.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the RRU or RFU is located.

GUI Value Range: 0~62

Unit: None

Actual Value Range: 0~62

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]CN in the RRU MO is set to 0~15.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the RRU or RFU is located.

GUI Value Range: 4~5,60~254

Unit: None

Actual Value Range: 4~5,60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of SRN in the RRU MO ranges from 60 to 254. The value of SRN in the RFU MO ranges from 4 to 5.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the RRU or RFU.

GUI Value Range: 0~8

Unit: None

Actual Value Range: 0~8

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Others:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When TYPE in the CABINET MO where the RFU MO is located is set to BTS3900AL, the value of SN in the RFU MO ranges from 0 to 8. Otherwise, the value of SN in the RFU MO ranges from 0 to 5. When the value of SRN in the RRU MO is set to 60, SN in the RRU MO ranges from 0 to 5. When the value of SRN in the RRU MO ranges from 61 to 254, the value of SN in the RRU MO ranges from 0 to 3.
  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]When SN in the RRU MO is set to a value greater than 0 and RT in the RRU MO is not set to MPRF, SRN in the RRU MO must be set to 60, and TYPE in the CABINET MO where the RRU MO is located must be set to RFC5906 or IFS5906.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To start a healthy check on an RRU in cabinet No.:0, Subrack No.: 60, Slot No.: 0, run this command:
STR RRUCHK: CN=0, SRN=60, SN=0;
