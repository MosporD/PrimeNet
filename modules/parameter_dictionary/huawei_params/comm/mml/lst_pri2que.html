List Mapping from Priority to Inner Queue (LST PRI2QUE)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to list the mapping from the transport bearer priority to the inner queue.

Note

  • There are a maximum of seven queues for service scheduling.

  • If the lowest priorities of neighboring queues x and x+1 are the same, that is, the values of PRI(x) and PRI(x+1) are the same, it indicates that no priority is mapped to queue x+1.

Parameters

ID Name Description
VRFIDX VRF Index

Meaning: Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

Disuse statement: This parameter will be deleted in later versions. To mitigate the risk, it is recommended that this parameter not be used.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To list the mapping between priorities and internal queues, run the following command:
LST PRI2QUE:;
The result is shown as follows:
+++    0        2008-01-04 18:01:43
O&M    #589

Output Description

Field Description

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

PriOfQue0

Indicates the lowest priority of queue 0. If the Differentiated Services Code Point (DSCP) value of a service packet is greater than or equal to this parameter value, the service packet is assigned to queue 0.

PriOfQue1

Indicates the lowest priority of queue 1. If the DSCP value of a service packet is less than the PRI0 value but greater than or equal to this parameter value, the service packet is assigned to queue 1.

PriOfQue2

Indicates the lowest priority of queue 2. If the DSCP value of a service packet is less than the PRI1 value but greater than or equal to this parameter value, the service packet is assigned to queue 2.

PriOfQue3

Indicates the lowest priority of queue 3. If the DSCP value of a service packet is less than the PRI2 value but greater than or equal to this parameter value, the service packet is assigned to queue 3.

PriOfQue4

Indicates the lowest priority of queue 4. If the DSCP value of a service packet is less than the PRI3 value but greater than or equal to this parameter value, the service packet is assigned to queue 4.

PriOfQue5

Indicates the lowest priority of queue 5. If the DSCP value of a service packet is less than the PRI4 value but greater than or equal to this parameter value, the service packet is assigned to queue 5.

PriOfQue6

Indicates the lowest priority of queue 6. If the DSCP value of a service packet is less than the PRI5 value but greater than or equal to this parameter value, the service packet is assigned to queue 6. If the DSCP value of a service packet is less than this parameter value, the service packet is assigned to an internal reserved queue.
