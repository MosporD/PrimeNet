List DTLS Configuration Policy (LST DTLSPOLICY)

Network Element: BTS3900, BTS3900 5G, BTS5900, BTS5900 5G

Function

Use this command to list DTLS configuration policies.

Note

[Co-MPT,eGBTS,gNodeB]This command applies only to the UMPTe/UMPTg/UMPTga board.

Parameters

ID Name Description
DTLSPOLICYID DTLS Policy ID

Meaning: Indicates the sequence number of a DTLS configuration policy.

GUI Value Range: 0(0)

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, N

Example

To list the DTLS configuration policies: DTLS Policy ID: 0, run the following command:
LST DTLSPOLICY: DTLSPOLICYID=0;
The result is shown as follows:
+++    0        2019-08-28 21:32:45
