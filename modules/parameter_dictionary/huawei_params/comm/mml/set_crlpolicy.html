Set CRL Check Policy (SET CRLPOLICY)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the policy to use CRLs.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • System specifications: If the WMPT/UMPT/UMDU/LMPT/GTMUc is the main control board, Only one CRLPOLICY MO can be configured.

  • Board specifications: A UMPT/UMDU/LMPT/GTMUc/UTRPc/UCCU/UBBPe series (except UBBPe15)/LCOP/UBBPf series/UBBPF series/UBBPg series board supports a maximum of one CRL check policy.

  • This function supports CRL check only for peer digital certificates during session establishment, re-authentication, or renegotiation.

Parameters

ID Name Description
CRLPOLICY CRL Using Policy

Meaning: Indicates the policy type. There are three policies using CRLs: NOVERIFY(No Verifying), ALARM(Send an Alarm If Verifying CRL Failed), and DISCONNECT(Disconnect If Verifying CRL Failed). The value NOVERIFY indicates that the BS does not perform CRL-based certificate checks on the peer device. The value ALARM indicates that the BS performs CRL-based certificate checks on the peer device and reports ALM-26832 Peer Certificate Expiry if the peer certificate has been revoked. The value DISCONNECT indicates that the BS performs CRL-based certificate checks on the peer device. If the BS finds that the peer certificate has been revoked, the BS stops the link negotiation with the peer device and reports ALM-26832 Peer Certificate Expiry. If the BS finds that the CRL expires, the BS stops the link negotiation with the peer device.

GUI Value Range: NOVERIFY(No Verifying), ALARM(Send an Alarm If Verifying CRL Failed), DISCONNECT(Disconnect If Verifying CRL Failed)

Unit: None

Actual Value Range: NOVERIFY, ALARM, DISCONNECT

MML Default Value: None

Recommended Value: ALARM(Send an Alarm If Verifying CRL Failed)

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To set a CRLPOLICY with the parameters as follows: CRL Using Policy: Send an Alarm If Verifying CRL Failed, run the following command:
SET CRLPOLICY: CRLPOLICY=ALARM;
