MOD CP Bearer (MOD CPBEARER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to modify the configuration of a Control Port Bearer.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]If a CPBEARER can be queried by running the LST CPBEARER command and the value of the "Auto Config Flag" is "Auto Created", the CPBEARER MO is automatically created by the system and cannot be modified by users.

Parameters

ID Name Description
CPBEARID CP Bear No.

Meaning: Indicates the number of a Control Port (CP) bearer. The value of CPBEARID in the CPBEARER MOs configured by users ranges from 0 to 65535. The value of CPBEARID in the CPBEARER MOs configured by the system ranges from 70000 to 79999.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The value of CP Bear No. in a manually configured CPBEARER MO must range from 0 to 65535.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
BEARTYPE Bear Type

Meaning: Indicates the type of CP bearer. The LTE and NR do not support SAAL.

GUI Value Range: SAAL(SAALLNK), SCTP(SCTPLNK)

Unit: None

Actual Value Range: SAAL, SCTP

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
LINKNO Link No.

Meaning: Indicates the number of a link carried on the CP bearer.

GUI Value Range: 0~65535,70000~79999

Unit: None

Actual Value Range: 0~65535,70000~79999

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: Yes

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N
FLAG Flag

Meaning: Indicates whether the transport channel carried on the CP bearer is a master or slave channel.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To modify the configuration of a CP bearer with the parameters as follows: CP Bear No.: 0, Bear Type: SCTP, Link No.: 0, Flag: MASTER, run the following command:
MOD CPBEARER: CPBEARID=0, BEARTYPE=SCTP, LINKNO=0, FLAG=MASTER;
