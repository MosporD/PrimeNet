Display Reference Clock (DSP CLKSRC)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the status of all configured clock sources. The status of each clock source depends on the availability of its associated clock link.

Note

  • [Co-MPT,eGBTS,eNodeB,gNodeB]Because the status of GPS and TOD is not updated in real time, the availability of GPS and TOD that is queried through the DSP CLKSRC command may be inconsistent with the actual situation.

  • [NodeB]Because the status of GPS is not updated in real time, the availability of GPS queried through the DSP CLKSRC command may be inconsistent with the actual situation.

Parameters

None.

Example

To query the status of clock sources, run the following command:
DSP CLKSRC:; 
The result is shown as follows:                  
+++    0        2010-01-06 02:53:17
O&M    #84
%%DSP CLKSRC:;%%
RETCODE = 0  Operation succeeded.

Output Description

Field Description

Clock Source No.

Indicates the clock link number of the reference clock source. When the Selected Clock Source parameter is set to GPS+SYNCETH, this parameter indicates the number of the GPS clock link. When the Selected Clock Source parameter is set to SYNCETH+IPCLK, this parameter indicates the number of the IP clock link. When this parameter is set to AUTO, the system selects an available clock link from those of the specified reference clock source. If there is more than one clock link and the selected clock link fails, another available clock link will be used.

Clock Source Type

Indicates the type of the clock source.

Clock Source Priority

Indicates the priority of the clock source. The value 1 indicates that the current clock source has the highest priority, and the value 4 indicates that the current clock source has the lowest priority.

Clock Source State

Indicates the availability of the clock source. Only an available clock link can serve as the current clock source. Otherwise, the clock link cannot be locked even if it is activated.

Clock Source Active State

Indicates the activation status of the clock source. If the clock source is active, the clock link is the current clock source of the system.

License Authorized

Indicates whether a clock source is licensed to be used. Only a licensed clock source can serve as the current clock source.
