Set UDP Ping Configurations (SET UDPPING)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

This command is used to set the parameters for UDP Ping detection of echo packets.

Note

None.

Parameters

ID Name Description
TIMEOUTTHD Timeout Duration of Echo Frames

Meaning: Indicates the timeout duration of waiting for echo responses in the UDP Ping detection mechanism. If no echo response is received after the duration specified by this parameter, echo response times out.

GUI Value Range: 5000~60000

Unit: ms

Actual Value Range: 5000~60000

MML Default Value: None

Recommended Value: 5000

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
TIMEOUTCNT Number of Echo Frame Timeouts

Meaning: Indicates the maximum number of echo response timeouts during UDP Ping detection. When the number of times that echo responses time out reaches the value of this parameter, the UDP Ping detection path is considered faulty.

GUI Value Range: 3~6

Unit: None

Actual Value Range: 3~6

MML Default Value: None

Recommended Value: 3

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U
DSCP DSCP

Meaning: Indicates the differentiated services code point (DSCP) for UDP Ping control packets.

GUI Value Range: 0~63

Unit: None

Actual Value Range: 0~63

MML Default Value: None

Recommended Value: 48

Parameter Relationship: None

Service Interrupted After Modification: No

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To set the parameters of the UDPPING control message with the parameters as follows: ECHO Frame Timeout: 6000, ECHO Frame Timeout Count: 3, DSCP: 45:
SET UDPPING: TIMEOUTTHD=6000, TIMEOUTCNT=3, DSCP=45;
