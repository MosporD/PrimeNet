Display the phase offset between the active and standby reference clock sources (DSP PHASEDIFF)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

This command is used to query the phase offset between the active and standby reference clock sources when both the clock sources are configured.

Note

  • An IEEE 1588 clock source supports the query of the phase difference only if its clock signals are introduced by the local subrack.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The value of Phase Discrimination(ns) in the command output may be large due to the jitter of the system clock when board hardware is faulty, the reference clock source is abnormal, the clock of the upper-level system is faulty, or the system clock is changed using MML commands.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The phase difference of a standby reference clock source cannot be queried if a conflict exists in the clock resources of this standby reference clock source.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The phase difference of an active or standby reference clock source cannot be queried if this reference clock source is introduced by a leaf BBU.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The offset can be queried only between the phases of GPS clock sources, interconnection clock sources, TOD clock sources configured on a USCU, IP clock sources and peer clock sources. Query of the phase offset is supported only when the standby clock source is available.

  • [Co-MPT,NodeB,eNodeB,gNodeB]When the active reference clock source is a TOD clock introduced by a USCU, the phase difference can be queried only if the standby reference clock source is a GPS clock introduced by a standby board or an evolved TD-SDCMA board.

  • [Co-MPT,NodeB,eNodeB,gNodeB]The phase offset cannot be queried if a clock source is not initialized.

  • [Co-MPT,NodeB,eNodeB,gNodeB]For a hybrid clock source, only the phase difference between it and the GPS clock source can be queried.

  • [NodeB]When the WMPT is the main control board, the suspicious status information cannot be queried.

Parameters

None.

Example

To query the phase offset between the active and standby reference clock sources, run the following command:
DSP PHASEDIFF:;
The result is shown as follows:

Output Description

Field Description

Clock Source Type

Indicates the type of the clock source.

Clock Source No.

Indicates the clock link number of the reference clock source. When the Selected Clock Source parameter is set to GPS+SYNCETH, this parameter indicates the number of the GPS clock link. When the Selected Clock Source parameter is set to SYNCETH+IPCLK, this parameter indicates the number of the IP clock link. When this parameter is set to AUTO, the system selects an available clock link from those of the specified reference clock source. If there is more than one clock link and the selected clock link fails, another available clock link will be used.

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Phase Discrimination(ns)

Indicates the phase offset of clock references. NULL indicates that the phase offset value is invalid.

Clock Source Active State

Indicates the activation status of the clock source. If the clock source is active, the clock link is the current clock source of the system.

Suspicious State

Indicates the suspicious status of the reference clock source. Grouping is based on the phase offset between the current source and the backup source. If the phase offset between two sources is less than Phase Deviation Alarm Threshold, such sources form a group. If the number of reference sources in a group is the largest among all groups and no group with the same number exists, the reference sources in the group is regarded as non-suspicious. Otherwise, they are regarded as suspicious. If the phase value cannot be obtained, the status is regarded as unknown.
