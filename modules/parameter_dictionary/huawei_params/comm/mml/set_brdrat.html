Set UTRP RAT (SET BRDRAT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to set the mode negotiation flag of the extension transmission board.

Note

  • After execution of this command, reset the UTRPc for the updated configuration to take effect.

  • This command can only be executed on the UTRPc.

  • The BLADEBBU does not support this command.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the cabinet number of the extension transmission board.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the subrack number of the extension transmission board.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: None

Recommended Value: None

Parameter Relationship:

-Configuration constraints:

  • [Co-MPT, NodeB, eGBTS, eNodeB, gNodeB]The TYPE of the SUBRACK where the TRP is located must be BBU3900, BBU3900-1U, BBU3910, or DCU3911.

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the slot number of the extension transmission board.

GUI Value Range: 0~6

Unit: None

Actual Value Range: 0~6

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
NEGMODE NegModeFlag

Meaning: Indicates the mode negotiation flag of the extension transmission board.

GUI Value Range: NEG(Negotiate), LOCK(Lock)

Unit: None

Actual Value Range: NEG, LOCK

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: No (And no impact on the UE in idle mode)

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

Set Supervisor of UTRPc with the parameters as follows: Cabinet No.: 0, Subrack No.: 0, Slot No.: 2, NegModeFlag: NEG, run the following command:
SET BRDRAT: CN=0, SRN=0, SN=2, NEGMODE=NEG;
