Display TWAMP Responder Status (DSP TWAMPRESPONDER)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the negotiation results and statistics of measurement packets for TWAMP responders.

Note

The LMPT/UMPT/UMDU/GTMUc/UTRPc board supports query of measurement packet statistics when serving as a TWAMP responder in the full architecture. The WMPT/UCCU/UBBPe (excluding UBBPe15)/UBBPei/UBBPep/UBBPem/LCOP/UBBPex2/UBBPf1/UBBPf0/UBBPg1/UBBPg2/UBBPg3/UBBPg4/UBBPg5/UBBPg6/UBBPg7/UBBPg9 board can serve as a TWAMP responder in the full architecture but does not support query of measurement packet statistics.

Parameters

ID Name Description
RESPONDERID Responder Index

Meaning: Indicates the index of a TWAMP responder.

GUI Value Range: 0~3

Unit: None

Actual Value Range: 0~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, N

Example

To query the dynamic information about the TWAMP Responder with the parameters as follows: Responder Index: 0, run the following command:  
DSP TWAMPRESPONDER: RESPONDERID=0;
The result is shown as follows:

Output Description

Field Description

Responder Index

Indicates the index of a TWAMP responder.

TWAMP Architecture

Indicates the architecture of a TWAMP responder.

IP Version

Indicates the IP version of a TWAMP responder.

Local IP Address

Indicates the local IPv4 address of a TWAMP responder.

Peer IP Address

Indicates the peer IPv4 address of a TWAMP responder.

Local IPv6 Address

Indicates the local IPv6 address of a TWAMP responder.

Peer IPv6 Address

Indicates the peer IPv6 address of a TWAMP responder.

VRF Index

Indicates the index of a VRF instance. UMTS currently supports the default routing domain only (the VRF index is 0).

DSCP for TCP Packets

Indicates the DSCP of TCP negotiation packets sent by a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Negotiation Status

Indicates the negotiation status of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Negotiated Working Mode

Indicates the negotiated working mode of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Session Start Time

Indicates the start time of a session for a TWAMP responder.

Local TCP Port No.

Indicates the local TCP port number of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Peer TCP Port No.

Indicates the peer TCP port number of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL.

Local UDP Port No.

Indicates the local UDP port number of a TWAMP responder.

Peer UDP Port No.

Indicates the peer UDP port number of a TWAMP responder.

Initial DSCP Value

Indicates the DSCP value of a TWAMP responder in light-architecture mode or the initial DSCP value of a TWAMP responder in full-architecture mode.

Changed DSCP Value

Indicates the changed DSCP value of a TWAMP responder. This parameter takes effect only when TWAMPARCH for TWAMP responders is set to FULL. If the DSCP value has not been changed, the value of this parameter is displayed as NULL.

Number of Received Measurement Packets(packet)

Indicates the number of UDP packets received by a TWAMP responder from measurement session.

Number of Sent Measurement Packets(packet)

Indicates the number of UDP packets sent by a TWAMP responder to measurement session.

Light Architecture Mode

Indicates the working mode of a TWAMP responder deployed in the light architecture. The working mode of the TWAMP responder must be the same as that of the TWAMP sender. This parameter takes effect only when the TWAMP responder is deployed in the light architecture.
