Display Clock Output (DSP TSTCLKOUT)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to query the types of outputted test clocks.

Note

None.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the system clock is located.

GUI Value Range: 0~7

Unit: None

Actual Value Range: 0~7

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SRN Subrack No.

Meaning: Indicates the number of the subrack where the system clock is located.

GUI Value Range: 0~1

Unit: None

Actual Value Range: 0~1

MML Default Value: 0

Recommended Value: 0

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N
SN Slot No.

Meaning: Indicates the number of the slot where the system clock is located.

GUI Value Range: 6~7

Unit: None

Actual Value Range: 6~7

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L, R, N

Example

To display clock output type in slot 6, run the following command:
DSP TSTCLKOUT: SN=6;
The result is shown as follows:
+++    0        2014-11-05 14:56:51
O&M    #166
%%DSP TSTCLKOUT: SN=6;%%
RETCODE = 0  Operation succeeded.

Display Clock Output
--------------------
      Cabinet No.  =  0
      Subrack No.  =  0
         Slot No.  =  6
Output Clock Type  =  10MS_FRAME_TIMING
      TstTodOutSW  =  OFF
(Number of results = 1)


---    END

Output Description

Field Description

Cabinet No.

Indicates the number of the cabinet where the system clock is located.

Subrack No.

Indicates the number of the subrack where the system clock is located.

Slot No.

Indicates the number of the slot where the system clock is located.

Output Clock Type

Indicates the clock output type.

TstTodOutSW

Indicates the output switch for the 1PPS+TOD test clock.
