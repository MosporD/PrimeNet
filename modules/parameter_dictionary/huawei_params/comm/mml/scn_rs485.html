Scan RS485 Bus (SCN RS485)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS3900 5G, BTS5900, BTS5900 WCDMA, BTS5900 LTE, BTS5900 5G

Function

Use this command to scan an RS485 bus to check the types and status of monitoring devices connected on the bus. This command can also help the OM engineers to locate and rectify connection or configuration faults on the RS485 bus.

This command can also be used to start eBAT scan and pairing when there are installed but offline eBATs. This command enables them to pair and access eBOX. After the scan and pairing are complete, you can run the DSP CCUBATSENSORSTATE command to query the results.

Note

  • The RS485 bus scan lasts for about 3 minutes after starting. Ensure that the command for obtaining a scanning result is executed after 3 minutes.

  • The eBAT scan and pairing take about 10 minutes. Ensure that the command for obtaining a scanning result is executed after 10 minutes. If scanning results are queried during scanning, the eBAT status in the query results is not the latest.

  • You cannot simultaneously scan multiple RS485 buses by using this command.

  • For the RRUs, only the RRU in slot 0 can be connected to a monitoring device.

Output Description

Field Description

Manager Cabinet No.

Indicates the cabinet number of the manager unit of the electromechanical device. This parameter is invalid and displayed as NULL if no manager unit is configured for the electromechanical device.

Manager Subrack No.

Indicates the subrack number of the manager unit of the electromechanical device. This parameter is invalid and displayed as NULL if no manager unit is configured for the electromechanical device.

Manager Cascade No.

Indicates the cascaded level of the CCU, which serves as a manager unit for the electromechanical device. This parameter is valid only when the manager unit of the electromechanical device is a CCU. In other cases, this parameter is displayed as NULL.

Port No.

Indicates the number of the serial port where the RS485 bus is connected. The serial port is the port through which mechanical device is connected to the BBU or CCU.

Address/Cascade No.

Indicates the communication address of the RS485 bus port or the cascaded level of the CCU. For a CCU, this parameter indicates the cascaded level of the CCU on a CCU chain. For other electromechanical devices, this parameter indicates the communication address of the device on the RS485 bus port communication bus.

Connected Board Type

Indicates the types of monitoring devices which have been scanned and are connected on the RS485 bus.

Status

Indicates the status of monitoring devices which have been scanned and are connected on the RS485 bus.

Whether to Connect to BBU/RRU

Indicates whether the electromechanical device is directly connected to a BBU or RRU. This parameter can be set to YES or NO only when the electromechanical component is a CCU. In other cases, this parameter is displayed as NULL.
