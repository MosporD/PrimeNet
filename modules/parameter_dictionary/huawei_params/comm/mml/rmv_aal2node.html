Remove AAL2 Node (RMV AAL2NODE)

Network Element: BTS3900, BTS3900 WCDMA, BTS5900, BTS5900 WCDMA

Function

Use this command to remove an AAL2 node.

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

  • [Co-MPT,NodeB]Before removing an AAL2 node, ensure that all AAL2 paths carried on the AAL2 node have been removed. You can list the configured AAL2 paths by running the LST AAL2PATH command.

  • [Co-MPT,NodeB]Running this command interrupts services carried on the AAL2 node.

  • [Co-MPT,NodeB]Before removing a master AAL2 node, ensure that the corresponding slave AAL2 node has been removed.

Parameters

ID Name Description
NT Node Type

Meaning: Indicates the type of an AAL2 node. If this parameter is set to LOCAL, the AAL2 node is used to control the local services on the BS. If this parameter is set to HUB, the AAL2 node is used to control services of the lower-level BS cascaded to the hub BS.

GUI Value Range: LOCAL(End Node), HUB(Switching Node)

Unit: None

Actual Value Range: LOCAL, HUB

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
BELONG Belong Flag

Meaning: Indicates the type of controller to which an AAL2 node is connected. The controller is either a master controller or a slave controller.

GUI Value Range: MASTER(MASTER), SLAVE(SLAVE)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U
FLAG Transport Channel Flag

Meaning: Indicates the transport channel of an AAL2 node, which can be master or slave.

GUI Value Range: MASTER(Master), SLAVE(Slave)

Unit: None

Actual Value Range: MASTER, SLAVE

MML Default Value: None

Recommended Value: MASTER(Master)

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: U

Example

To remove an AAL2 node with the parameters as follows: Node Type: LOCAL, Belong Flag: MASTER, Transport Channel Flag: MASTER, run the following command: 
RMV AAL2NODE: NT=LOCAL, BELONG=MASTER, FLAG=MASTER;
