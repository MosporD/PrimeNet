Remove AARU (RMV AARU)

Network Element: BTS3900, BTS3900 WCDMA, BTS3900 LTE, BTS5900, BTS5900 WCDMA, BTS5900 LTE

Function

Use this command to remove an active antenna radio unit (AARU).

Note

This is a high-risk MML command. Pay attention to the following precautions before running this command:

[Co-MPT,NodeB,eGBTS,eNodeB]Services carried on the AARU will be interrupted after the AARU is removed.

Parameters

ID Name Description
CN Cabinet No.

Meaning: Indicates the number of the cabinet where the AARU is located.

GUI Value Range: 0

Unit: None

Actual Value Range: 0

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SRN Subrack No.

Meaning: Indicates the number of the subrack where the AARU is located.

GUI Value Range: 60~254

Unit: None

Actual Value Range: 60~254

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L
SN Slot No.

Meaning: Indicates the slot number of the AARU.

GUI Value Range: 1~3

Unit: None

Actual Value Range: 1~3

MML Default Value: None

Recommended Value: None

Parameter Relationship: None

Service Interrupted After Modification: N/A

Impact on Radio Network Performance: None

Applicable Mode: G, U, L

Example

To remove an AARU with the parameters as follows: Cabinet No.: 0, Subrack No.: 60, Slot No.: 1, run the following command:
RMV AARU: CN=0, SRN=60, SN=1;
